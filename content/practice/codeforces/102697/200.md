 ## 解决方案
 ## 问题理解

 我们最多有七个固定在平面中整数坐标的销钉。 我们选择其中一些别针，并在所选组周围拉伸橡皮筋。 围绕一组点的拉紧橡皮筋沿着其凸包的边界。 所选引脚必须全部与带接触，并且带内严格不能有任何其他引脚。 直接位于表带上的针脚是无害的，因为它们会接触表带。 

任务是最大化满足这两个几何条件的所选引脚的数量。 官方输入限制仅为(n \le 7)，时间限制为1秒，内存为256 MB。 这是非常小的，因此子集上的指数算法是完全合理的。 最多有 (2^7=128) 个子集，甚至对每个子集进行几次 (O(n^2)) 几何检查也是可以忽略不计的。 

主要边缘情况来自共线或严格位于凸包内的点。 例如，```
3
0 0
1 0
2 0
```有答案`3`。 所有三个销都位于退化凸包的边界上，因此带可以接触所有销。 

更危险的情况是内点：```
5
0 0
4 0
2 2
2 -2
2 0
```除此以外的四点`(2, 0)`形成外部菱形，同时`(2, 0)`严格地在其内部。 选择所有五个销钉是不可能的，因为内部销钉不会接触表带。 正确答案是`4`。 

船体边缘上的点不得与内部点混淆。 例如，```
6
0 0
2 0
4 0
2 2
2 -2
3 -1
```有答案`5`。 重点`(3, -1)`位于边缘`(4, 0)`到`(2, -2)`，因此橡皮筋接触到它。 将标准凸包实现的每个非顶点视为内点会错误地拒绝此配置。 

## 方法

 直接暴力破解已经是正确的方法，因为输入很小。 我们可以枚举引脚的每个子集，假设这是我们拉伸橡皮筋的集合，计算其凸包，并检查该子集是否有效。 

为了使子集起作用，每个选定的点必须位于其凸包的边界上。 否则，所选点将严格位于橡皮筋内，不会被触及。 我们还检查每个未选择的引脚。 如果这样的销钉严格位于凸包内部，则该子集无效，因为橡皮筋将销钉包围但不接触它。 即使我们没有明确选择边界上的引脚，也是允许的。 

暴力搜索考虑 (2^n) 个子集。 对于每个子集，可以在 (O(n\log n)) 中构造一个外壳，并且因为 (n\le7)，即使是更简单的 (O(n^2)) 几何检查也足够快。 在最坏的情况下，我们只执行几千次原始方向测试。 

有用的观察是，无需搜索橡皮筋的无限多种可能形状。 一旦选定的销钉被固定，拉紧的带子就完全由其凸包表征。 几何将原始物理描述简化为两个有限检查：选定的点必须位于船体边界上，并且任何未选定的点都不能严格位于船体内部。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对子集的暴力破解 | (O(2^n n^2)) | (O(n)) | (O(n)) | 已接受 |
 | 带有凸包检查的最优子集枚举 | (O(2^n n^2)) | (O(n)) | (O(n)) | 已接受 |

 对于这个问题，第二行实际上是预期的解决方案。 不需要更复杂的渐近技术，因为 (n) 至多为七。 

## 算法演练

 1. 读取所有引脚坐标并通过其索引及其坐标对来表示每个引脚。 保持索引很重要，因为两个不同的引脚可能占据相同的坐标。 
2. 枚举 (n) 个引脚的每个非空子集。 由于 (n\le7)，最多有 127 个子集需要检查。 
3. 提取属于当前子集的点并计算它们的凸包。 使用单调链外壳，但保留外壳边缘上的共线点而不是丢弃它们。 边缘上的点被橡皮筋物理接触，因此它必须算作边界点。 
4. 根据船体边界检查每个选定的点。 如果甚至有一个选定点严格位于船体内部，则拒绝该子集。 对于单点子集，点本身就是边界。 对于两个或多个共线点，外壳是一个线段，并且该线段上的每个点都在边界上。 
5. 检查每个未选择的引脚。 如果它严格位于凸包内，则拒绝该子集。 如果它在船体边界之外或位于船体边界上，则不违反条件。 
6. 如果两项检查都通过，则用子集的大小更新答案。 由于子集是独立的，因此保持最大有效大小直接给出所需的最大值。 

### 为什么它有效

 对于固定的选定集 (S)，拉紧的橡皮筋是 (\operatorname{conv}(S)) 的边界。 当所选点位于该边界上时，该点将被准确触摸。 当未选择的销严格位于凸包内部时，它就违反了条件，因为此时带将其包围而不接触它。 该算法为每个可能的选择集精确地检查这两个必要且充分的属性。 由于检查了每个候选子集，因此最大的可接受子集就是最佳答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(a, b, c):
    return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

def convex_hull(points):
    """Return the hull boundary as an ordered list.

    Collinear points on an edge are kept.
    Duplicate coordinates are removed for geometric construction.
    """
    points = sorted(set(points))

    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) < 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) < 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def on_segment(a, b, p):
    return (
        cross(a, b, p) == 0
        and min(a[0], b[0]) <= p[0] <= max(a[0], b[0])
        and min(a[1], b[1]) <= p[1] <= max(a[1], b[1])
    )

def on_boundary(hull, p):
    if len(hull) == 0:
        return False

    if len(hull) == 1:
        return p == hull[0]

    for i in range(len(hull)):
        if on_segment(hull[i], hull[(i + 1) % len(hull)], p):
            return True

    return False

def strictly_inside(hull, p):
    """Whether p lies strictly inside the polygonal hull."""
    if len(hull) < 3:
        return False

    if on_boundary(hull, p):
        return False

    sign = 0
    m = len(hull)

    for i in range(m):
        c = cross(hull[i], hull[(i + 1) % m], p)

        if c == 0:
            return False

        if sign == 0:
            sign = 1 if c > 0 else -1
        elif (c > 0 and sign < 0) or (c < 0 and sign > 0):
            return False

    return True

def solve():
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n)]

    answer = 1

    for mask in range(1, 1 << n):
        chosen = [points[i] for i in range(n) if mask & (1 << i)]

        if len(chosen) <= answer:
            continue

        hull = convex_hull(chosen)

        # Every selected pin must be on the rubber band's boundary.
        valid = True
        for p in chosen:
            if not on_boundary(hull, p):
                valid = False
                break

        if not valid:
            continue

        # An unselected pin may be outside or on the band,
        # but never strictly inside it.
        for i, p in enumerate(points):
            if mask & (1 << i):
                continue

            if strictly_inside(hull, p):
                valid = False
                break

        if valid:
            answer = len(chosen)

    print(answer)

if __name__ == "__main__":
    solve()
```这`cross`函数计算由三个点形成的三角形的有符号面积。 它的符号告诉我们第三个点是在有向边的左侧还是右侧，零表示这三个点共线。 

船体构造对坐标进行排序并构建下部和上部链条。 通常的单调链实现经常使用`<= 0`删除点时，会丢弃共线点。 在这里这是错误的，因为位于橡皮筋直线部分上的销钉仍然会被触摸。 因此，仅当严格顺时针旋转时，该实现才会删除一个点。 

这`on_boundary`函数故意检查实际的船体段，而不是询问某个点是否是船体顶点之一。 这可以正确处理共线引脚，还可以处理退化的单点和两点情况。 

这`strictly_inside`函数仅对二维船体有意义。 对于线段或单个点，没有正区域内部，因此返回 false。 对于多边形，当一个点位于每个有向外壳边的同一严格侧时，该点严格位于内部。 内部测试明确拒绝边界点。 

子集循环跳过不大于当前答案的子集。 这样的子集无法改善结果，因此没有理由执行其几何检查。 所有算术都使用Python整数，因此无论坐标大小如何，都不存在溢出问题。

 ## 边缘情况

 对于单个引脚，```
1
7 -3
```所选集合有一个点，其凸包就是该点。 不存在正面积内部，所以该点是有效的，答案是`1`。 

对于共线点，```
5
0 0
1 0
2 0
3 0
4 0
```船体退化为从`(0,0)`到`(4,0)`。 边界检查将该段上的每个点都视为已触摸，因此可以选择所有五个引脚，答案是`5`。 

对于重合的引脚，```
4
3 3
3 3
3 3
3 3
```几何外壳仅包含一个坐标，但原始引脚仍然是四个不同的可选引脚。 边界检查比较坐标而不需要不同的外壳顶点，因此所有四个引脚都被接受。 

对于内点，```
5
0 0
4 0
2 2
2 -2
2 0
```四个外点形成菱形，`(2,0)`严格地在其内部。 如果选择了所有五个引脚，则选定的内部引脚将无法通过边界检查。 仅选择四个外部点成功，给出答案`4`。

5
0 0
4 0
4 4
0 4
2 0
```重点`(2,0)`与 共线`(0,0)`和`(4,0)`。 它位于橡皮筋的边界上而不是内部。 船体实现保留了这个共线点，并且`on_segment`将其识别为边界，因此所有五个引脚均有效，答案为`5`。
