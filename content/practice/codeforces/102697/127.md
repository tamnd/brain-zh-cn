 ## 解决方案
 ## 问题理解

 任务是计算一个部分填充的 4×4 网格有多少种方式可以组成拉丁方。 每个单元格必须包含从 1 到 4 的数字，并且每个数字必须在每行中恰好出现一次，在每列中恰好出现一次。 零代表一个空单元格，其值可以选择。 

输入始终由四行组成，每行包含四个数字。 输出是与每个已填充单元格一致的不同完整拉丁方格的数量。 

网格的固定大小完全改变了问题的性质。 没有变量 n 可以增长到 10 5，因此在这个微小的常数大小中使用指数算法是可能的。 关键是避免不必要的大指数搜索。 将四个值之一独立地分配给所有 16 个单元给出 4 16 =4,294,967,296 个完整网格，这对于简单的实现来说已经太多了。 相反，我们可以在构建网格时使用拉丁方限制，立即消除无效的部分网格。 

一个特别有用的观察是有效行必须是以下排列`1, 2, 3, 4`。 只有 4!=24 可能的行。 我们可以生成这些行一次，并逐行构建正方形，只要候选行与其中一列中已使用的值冲突，就拒绝候选行。 

有两种微妙的输入情况值得明确处理。 首先，输入可以包含完全空的正方形：```
0000000000000000
```正确的输出是：```
576
```一个粗心的解决方案，将它找到的第一个有效方块视为将产生的答案`1`，但问题要求的是所有完成的数量。 有 576 个不同的 4 阶拉丁方。 

其次，线索本身已经可以与拉丁方条件相矛盾：```
4311000000000000
```第一行包含两个`1`s，所以不可能完成。 正确答案是`0`。 仅检查每个填充单元格是否单独包含从 1 到 4 的值的实现可能会忽略此矛盾。 

第三个例子说明了另一种矛盾：```
1234234134124311
```前三行将特定值强制写入每一列，而最后一行重复`1`。 答案又是`0`。 

## 方法

 最直接的暴力方法将四个值之一分配给 16 个单元格中的每一个，并在最后检查完整的网格。 这是正确的，因为每个可能的网格都会被考虑，并且当网格满足线索和拉丁方条件时，它就会被准确地计数。 然而，在最坏的情况下它会检查 4 16 =4,294,967,296 个网格。 尽管董事会规模很小，但 40 亿候选人的成本却是不必要的。 

暴力破解之所以有效，是因为它详尽地考虑了每一个可能的分配，但它失败了，因为它推迟了所有有效性检查，直到所有 16 个单元都被分配完毕。 有用的观察是拉丁方约束是局部的。 当我们在单元格中放置一个值时，我们立即知道相同的值不能再次出现在其行或列中。 我们还可以将每一行构造为以下排列`1, 2, 3, 4`，将一行的选择从 4 4 =256 个任意序列减少到只有 4!=24 个有效序列。 

我们可以生成这 24 行排列，根据给定的线索过滤它们，然后递归地选择四行。 在接受行之前，我们会根据已选择的行检查每个列的位置。 由于每个候选行已经包含每个数字一次，因此自动满足行条件。 列检查足以保证任何数字不会在列中出现两次。 

在考虑从线索和列冲突进行修剪之前，完整的搜索最多有 24 4 =331,776 个行组合。 每个组合仅涉及四列，因此很小。 实际上，列检查会更早地修剪大多数组合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(4 16 ⋅16) | O(4 16 ⋅16) | O(16) | 太慢了 |
 | 行排列 DFS | O(4!4 ⋅4) | O(4!4 ⋅4) | O(4 2 ) | 已接受 |

 ## 算法演练

 1. 生成所有 24 个排列`[1, 2, 3, 4]`。 每个有效的拉丁方行都必须是这些排列之一，因此没有理由考虑包含重复数字的行。 
2. 将四个输入行读取为四个字符串。 一个角色`0`表示位置不受限制，而另一个字符将该单元格固定为相应的值。 
3. 对于每个行排列，检查它是否与该输入行中的所有非零线索一致。 仅保留兼容的排列。 这可以防止 DFS 放置与给定单元格相矛盾的值。 
4. 一次一排地搭建正方形。 考虑行的候选排列时`r`，检查每一列`c`并将候选值与已放置的值进行比较`(0, c), (1, c), ..., (r-1, c)`。 如果任何值在列中重复，则拒绝该候选值。 
5. 一旦选择了四行，就构建了一个完整的拉丁方。 将答案加一。 行排列保证每行包含所有四个值一次，列检查保证每列具有相同的属性。 
6. 打印累计计数。 不需要对已完成的方块进行单独验证，因为每个约束都是在施工过程中强制执行的。 

### 为什么它有效

 不变的是 DFS 生成的每个部分网格完全由有效行组成，并且在任何列中都没有重复值。 因此，只有当其余行满足相同的列限制时，每个部分网格仍然可以扩展。 当放置第四行时，所有四行都是排列`1, 2, 3, 4`，并且每列包含来自同一组的四个不同值，因此每列也只包含每个数字一次。 由于候选者在放置之前会根据原始线索进行过滤，因此每个计数的网格都与输入一致。 相反，每个有效的完成都由四个有效的行排列组成，并通过每个列检查，因此 DFS 只到达并计数一次。 

## Python 解决方案```python
Pythonimport sysinput = sys.stdin.readline
from itertools import permutations

def solve():    grid = [input().strip() for _ in range(4)]
    perms = list(permutations((1, 2, 3, 4)))
    allowed = []    for r in range(4):        rows = []        for p in perms:            ok = True            for c in range(4):                if grid[r][c] != '0' and int(grid[r][c]) != p[c]:                    ok = False                    break            if ok:                rows.append(p)        allowed.append(rows)
    chosen = []    answer = 0
    def dfs(r):        nonlocal answer
        if r == 4:            answer += 1            return
        for row in allowed[r]:            ok = True
            for c in range(4):                for previous in chosen:                    if previous[c] == row[c]:                        ok = False                        break                if not ok:                    break
            if not ok:                continue
            chosen.append(row)            dfs(r + 1)            chosen.pop()
    dfs(0)    print(answer)

if __name__ == "__main__":    solve()
```这`permutations`调用创建完整的可能有效行集。 只有 24 个，因此显式存储它们比手动构造行更简单、更安全。 

这`allowed`array 执行步骤 3 中描述的线索过滤。例如，如果输入行是`1 2 0 4`，仅排列`(1, 2, 3, 4)`幸存下来。 由于输入使用字符而不是空格分隔的整数，因此代码将每一行作为字符串读取，并且仅当字符非零时才将其转换为整数。 

这`chosen`列表包含到目前为止选择的行。 在添加候选行之前，DFS 将每列中的值与所有先前选择的行进行比较。 由于只有四行和四列，因此这种嵌套检查的成本是恒定的。 

这`append`，递归调用，以及`pop`形成标准的回溯模式。 这`pop`这是至关重要的，因为在探索一个候选行之后，下一个候选者必须准确地看到较早的行，而不是前一个分支中的行。 

Python 中不存在整数溢出问题。 答案最多是4阶拉丁方的总数，只有576个。

 ## 边缘情况

 完全空的输入是最大的搜索情况，因为没有线索可用于修剪候选行：```
0000000000000000
```该算法从所有 24 行可能的行开始。 它递归地选择兼容的行并计算每个完成的拉丁方。 最终计数为`576`。 

包含重复固定值的行不能出现在拉丁方中。 例如：```
1111000000000000
```当处理第一行时，不进行排列`(1, 2, 3, 4)`可以匹配`1111`， 所以`allowed[0]`是空的。 DFS没有分支可供探索并立即产生`0`。 

即使每个单独的行都有效，不同行之间也可能出现矛盾。 考虑：```
1234123400000000
```第一排位置`1`在第一列，第二行尝试放置另一个`1`在同一列中。 当考虑第二行时，列检查会拒绝它。 答案是`0`。 

最后，一个完全固定的有效正方形只有一个完成：```
1234234134124123
```每行都是 24 种允许的排列之一，每列包含四个不同的值。 DFS 遵循唯一可能的分支，并将答案恰好递增一次，产生：```
1
```中心思想是棋盘足够小，可以进行详尽的搜索，但前提是要利用拉丁方的结构。 首先生成完整的有效行将原本的 4 16 搜索变成最多 24 4 行组合的小型搜索，无效列重复一旦出现就会被丢弃。
