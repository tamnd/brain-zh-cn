 ## 解决方案
 ## 问题理解

 输入描述笛卡尔平面中三角形的三个顶点。 每个顶点由一个整数对给出`(x, y)`，并且三个顶点可以以任意顺序出现。 任务是将三角形的面积计算为十进制值。 该问题明确描述了 Heron 公式，因此预期的路线是首先从坐标恢复三个边长，然后将它们代入该公式。 

对于两点`(x1, y1)`和`(x2, y2)`，他们的欧几里德距离是`√((x1 - x2)² + (y1 - y2)²)`。 

求出三边长后`A`,`B`， 和`C`， 让`S = (A + B + C) / 2`。 

海伦公式给出的面积为`√(S(S - A)(S - B)(S - C))`。 

The order of the input points does not matter because every pair of vertices defines one of the three sides. 该公式对称地使用所有三个边长。 

没有大的`n`这里。 输入始终包含恰好三个点，并且发布的语句不会给出大的坐标计数约束，因为没有要处理的可变大小集合。 即使坐标本身非常大，该算法也仅执行恒定数量的算术运算。 不存在这样的可能性`O(n²)`或者`O(n³)`算法变得有问题，因为没有增长`n`在这个问题中。 

第一个边缘情况是一个三角形，即使其边长是无理数，其面积也是整数。 例如，```
0 0
4 0
0 3
```有侧面`4`,`3`， 和`5`，所以正确的输出是`6.0`。 假设区域必须具有与坐标相同的数字类型的粗心实现可能会错误地执行整数除法，并在其他情况下丢失小数部分。 

第二个边缘情况是具有小数部分的区域。 为了```
1 1
5 4
2 8
```正确的输出是`12.5`。 将所有中间值视为整数无法正确表示此结果。 

第三种边缘情况是三个共线点的简并集。 例如，```
0 0
1 1
2 2
```有面积`0.0`。 Heron 的表达式在数学上为零，尽管浮点运算有时会因舍入而在平方根内产生微小的负值。 将表达式钳位为`max(0.0, expression)`使实施更加稳健。 

## 方法

 字面上的强力方法可以枚举三个输入点的所有六种排列，将每种排列解释为三角形顶点的排序，计算其三个边长，并应用海伦公式。 这是正确的，因为每个排列仍然包含完全相同的三个无序顶点对，因此每个排列都会产生相同的三个边长。 它执行六个恒定大小的计算，或者`6 × 3 = 18`最多计算距离，所以已经有效`O(1)`。 没有有意义的输入大小，在该大小下，这种蛮力会变得太慢。 

有用的观察是排列搜索是不必要的。 海伦公式仅取决于三个边长，并且这些长度直接由三对无序点确定。 我们可以精确计算一次点 1 和 2、点 2 和 3 以及点 1 和 3 之间的距离。 输入提供的点顺序无关。 

这就是这个问题的整个优化过程。 不要尝试可能的排序，而是直接计算三个成对距离并应用一次公式。 结果算法仍然是`O(1)`，但它更简单并且避免了六次相同的计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(1)，最多 18 次距离计算 | O(1) | O(1) | 已接受，但没有必要 |
 | 最佳 | O(1)，3 次距离计算 | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取三个坐标对并存储为`(x, y)`点。 正好有三个点，因此不需要超过三个小元组的数据结构。 
2. 计算点 1 和 2、点 2 和 3 以及点 1 和 3 之间的距离。对于每一对，使用欧几里得距离公式。 无论提供顶点的顺序如何，这些正是三角形的三条边。 
3. 将三个边长相加并除以二以获得半周长`S`。 这里使用浮点除法是必要的，因为半周长不一定是整数。 
4. Evaluate`S(S - A)(S - B)(S - C)`。 这是海伦公式中平方根下的量。 
5. 取该数量的平方根并将结果以十进制数形式打印。 如果浮点舍入为简并三角形产生微小的负值，请在求平方根之前将其替换为零。 

### 为什么它有效

 这三个顶点恰好确定了三个无序对，每对对应于三角形的一条边。 该算法计算所有三个成对距离，因此它准确地获得了 Heron 公式所需的边长。 然后，海伦公式根据这三个长度计算面积。 由于该公式是对称的`A`,`B`， 和`C`，顶点的原始顺序不会影响结果。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def distance(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return math.hypot(dx, dy)

def solve():
    points = [tuple(map(int, input().split())) for _ in range(3)]

    a = distance(points[0], points[1])
    b = distance(points[1], points[2])
    c = distance(points[0], points[2])

    s = (a + b + c) / 2.0

    value = s * (s - a) * (s - b) * (s - c)
    area = math.sqrt(max(0.0, value))

    print(area)

if __name__ == "__main__":
    solve()
```这`distance`函数隔离了坐标计算，以便主算法直接反映数学解。`math.hypot(dx, dy)`计算`sqrt(dx² + dy²)`优于手动编写平方根表达式，因为它是为欧几里得距离计算而设计的。 

这三个调用使用对`(0, 1)`,`(1, 2)`， 和`(0, 2)`。 这些都是三对可能的顶点，因此没有遗漏任何边，也没有边被计算两次。 

划分由`2.0`使浮点运算的使用更加明确。 蟒蛇的`/`运算符已经执行浮点除法，但十进制文字使预期的数字表示变得清晰。 

这`max(0.0, value)`is a defensive measure for degenerate or nearly degenerate triangles. 从数学上来说，对于有效的三角形，Heron 的表达式不能为负，但是浮点舍入可以将应该恰好为零的值变成类似的值`-1e-15`。 呼唤`sqrt`直接在该值上会引发域错误。 

Python整数不会溢出，距离计算通过以下方式转换为浮点数`math.hypot`，因此不需要单独的整数溢出处理。

 ## 边缘情况

 对于分数面积情况```
-1 0
2 0
0 1
```边长是`3`,`√2`， 和`√2`。 半周长约为`2.9142`，海伦公式给出`1.5`。 该算法将半周长和所有四个因子保留为浮点值，因此不会丢失分数信息。 

对于共线情况```
0 0
1 1
2 2
```边长是`√2`,`√2`， 和`2√2`。 半周长是`2√2`，使因子`S - C`数学上为零。 预期区域是`0.0`。 因为浮点计算可能会产生一个微小的负值，`max(0.0, value)`保证平方根收到有效的非负参数。 

对于大坐标情况```
1000000000 1000000000
1000000004 1000000000
1000000000 1000000003
```翻译后的形状是`4 × 3`直角三角形，其面积为`6.0`。 该算法在计算距离之前使用坐标差，因此大的绝对坐标值不会改变几何形状。 Python 的任意精度整数还可以防止在形成这些差异时出现整数溢出。 

任意输入顺序会自动处理，因为算法会计算所有三个可能的对。 For example, swapping the first and third points changes which pair is called`a`或者`c`，但 Heron 公式将三个边长对称处理，因此最终面积保持不变。
