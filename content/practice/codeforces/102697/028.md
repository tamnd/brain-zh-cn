 ## 解决方案
 ## 问题理解

 该问题要求我们判断给定的正整数是否是“有趣的数字”。 仅当一个数字可以被 5 和 7 整除时，该数字才会收到此标签。输入包含一个整数，输出应为`YES`如果条件满足并且`NO`否则。 

我们唯一需要的操作是检查整除性。 由于该数字是针对两个固定值进行测试的，因此该算法除了读取之外，不依赖于输入数字的大小。 即使该值非常大，恒定数量的算术运算就足够了。 尝试搜索倍数或重复减去值的解决方案会增加不必要的工作，并且可能比直接整除性检查慢得多。 

主要的边缘情况来自于忘记了这两个条件都是必需的。 仅仅能被 5 整除的数是不够的。 例如：

 输入：```
25
```正确的输出是：```
NO
```因为 25 可以被 5 整除，但不能被 7 整除。如果不小心只检查一个除数，就会错误地打印`YES`。 

另一种情况是可以被 7 整除但不能被 5 整除的数字。 

输入：```
14
```正确的输出是：```
NO
```因为14只满足了要求的一半。 

最小的有效情况是 5 和 7 的最小公倍数。 

输入：```
35
```正确的输出是：```
YES
```因为 35 可以被这两个数字整除。 

## 方法

 最简单的暴力破解思路是反复测试是否可以通过减去 5 或 7 来减少数字，直到达到零。 这最终会揭示该数字是否是任一值的倍数，但对于此问题来说，这是错误的模型。 对于较大的输入值，这可能需要许多不必要的迭代，并且它仍然不能自然地结合两个整除条件。 

关键的观察结果是余数运算已经提供了整除性。 一个数字`x`能被另一个数整除`y`恰好在什么时候`x % y`等于零。 由于问题要求能被两个固定值整除，因此我们只需要两次余数检查。 

暴力方法之所以有效，是因为它试图发现该数字是否属于除数的倍数集合。 余数直接回答该集合中的成员资格的观察将整个问题减少到恒定时间。

 ## 算法演练

 1. 从输入中读取给定的数字。 数字是唯一需要的信息，因为条件仅取决于它的整除性。 
2. 检查数字除以 5 和除以 7 时余数是否为零。这两项检查都必须成功，因为定义同时需要这两个属性。 
3. 打印`YES`如果两个余数都为零。 否则打印`NO`。 

为什么它有效

 该算法背后的不变量很简单：在每次整除性检查之后，我们知道输入是否属于该除数的倍数。 当一个数字同时属于 5 和 7 的倍数时，它就很有趣，因此最终条件直接与定义匹配。 不存在缺失情况，因为每个整数除以每个除数时要么余数为零，要么余数非零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    if n % 5 == 0 and n % 7 == 0:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```该解决方案读取单个整数并应用两个模运算。 表达式`n % 5 == 0`检查 5 是否能整除该数字，而`n % 7 == 0`对 7 执行相同的检查。逻辑`and`是必要的，因为仅满足一个条件的数字并不好笑。 

Python 中不存在溢出问题，因为整数算术会自动处理大值。 条件顺序也不会产生边界问题，因为两个除数都是常数，并且每个正整数都由相同的两个检查处理。

## 测试用例```python
import sys
import io

def solve(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    ans = "YES" if n % 5 == 0 and n % 7 == 0 else "NO"

    sys.stdin = old_stdin
    return ans + "\n"

 ## 边缘情况

 可以被 5 整除但不能被 7 整除的数字必须被拒绝。 用于输入`25`，算法计算`25 % 5 = 0`和`25 % 7 = 4`，所以第二个条件失败，输出为`NO`。 

能被 7 整除但不能被 5 整除的数字也必须被拒绝。 用于输入`14`，算法发现`14 % 5 = 4`和`14 % 7 = 0`，所以第一个条件失败，输出为`NO`。 

第一个有效数字是 35。用于输入`35`，两个余数都为零，因此算法到达接受分支并打印`YES`。
