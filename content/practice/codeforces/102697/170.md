 ## 解决方案
 ## 问题理解

 该问题模拟了在环境温度为 70 度的房间中一杯咖啡的温度为 210 度。 其温度遵循牛顿冷却定律，

 [
 T(t)=T_s+(T_0-T_s)e^{-kt}。 
]

 这里，(T_s=70)，(T_0=210)，未知的冷却常数(k)由给定的校准点确定：15分钟后，咖啡冷却到120度。 对于每个测试用例，我们都会给出一个目标温度 (T(t))，并且我们必须输出咖啡达到该温度时的时间（以分钟为单位）。 官方声明准确地给出了这些数量和样本输出。 

从算法的角度来看，有用的输入大小非常小。 只有 (n) 个独立的温度查询，每个查询都需要恒定数量的算术和对数运算。 时间限制为 1 秒，内存限制为 256 MB，因此即使线性传递大量测试用例也是微不足道的。 当方程可以直接反演时，没有理由使用数值模拟或任何迭代方法。 

物理上有意义的目标温度位于初始温度和环境温度之间。 对于 (T=210)，答案恰好是 0，因为咖啡从那里开始。 对于诸如 (T=120) 的目标，根据校准条件答案为 15。 低于 70 的目标永远不会在有限时间内达到，因为模型从上方逼近 70。 类似地，仅渐近地接近等于 70 的目标。 该声明仅将每个测试值描述为正整数，因此这些非物理值最好理解为在冷却模型的预期范围之外。 

例如，输入```
1
210
```输出为 0，因为不需要冷却时间即可达到起始温度。 假设对数参数始终严格大于 1 的粗心实现仍然可以正确计算，但可能会意外地通过不正确的公式引入特殊情况。 

对于输入```
1
120
```正确的输出是 15。校准点本身必须保留。 使用四舍五入小数过早近似 (k) 的公式可能会产生略有不同的值，并不必要地损失精度。 

对于接近室温的目标，例如```
1
71
```答案远大于样本值，因为指数曲线在接近 70 时变得越来越慢。假设冷却时间受小常数限制或逐分钟模拟温度的实现无法准确获得所需的实值答案。 

## 方法

 强力数值方法可以以小时间增量模拟冷却过程，重复评估 (T(t))，并在模拟温度足够接近目标时停止。 这在概念上很简单，因为牛顿公式直接告诉我们任何选定时间的温度。 问题在于答案是实数，因此没有自然的离散时间步长可以提供所需的精度。 如果我们尝试 (10^{-6}) 分钟的步骤，并且需要在接近 71 度的温度下进行大约 72 分钟，则一次测试可能需要大约 7200 万次评估。 对于 (n) 个测试用例，这很快就会变得太慢，并且进一步减少步骤只会使情况变得更糟。 

更复杂的数值暴力将按时使用二分搜索。 由于温度是单调下降的，我们可以通过反复检查中点来找到目标温度对应的时间。 对于双精度来说，大约 60 到 100 次迭代就足够了，因此这种方法实际上足够快。 然而，它正在求解一个具有精确代数逆元的方程，使得迭代机制变得不必要。 

关键的观察结果是未知数 (k) 不需要进行数值估计。 校准点以对数形式精确给出它。 代入 (T_s=70)、(T_0=210) 和 (T(15)=120) 得出

 [
 120=70+140e^{-15k},
 ]

 所以

 [
 50=140e^{-15k},
 ]

 因此

 [
 e^{-15k}=\frac{5}{14}。 
]

 取自然对数，

 [
 k=\frac{\ln(14/5)}{15}。 
]

 现在对于任意目标温度 (T)，

 [
 T=70+140e^{-kt}。 
]

 重新排列，

 [
 e^{-kt}=\frac{T-70}{140}。 
]

 再次取对数，

 [
 -kt=\ln\left(\frac{T-70}{140}\right),
 ]

 所以

 [
 t=\frac{\ln\left(\frac{140}{T-70}\right)}{k}。 
]

 代入 (k) 的值，

 [
 \盒装{
 时间=
 15\frac{\ln\left(\frac{140}{T-70}\right)}
 {\ln(14/5)}
 }。 
]

 暴力方法之所以有效，是因为温度函数是单调的，但它需要通过计算来搜索代数可以直接提供的值。 指数方程可以逆的观察结果将每个测试用例的工作量减少到恒定量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | P 个数值步骤的 O(n·P) | O(1) | O(1) | 太慢，无法实现高精度 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取温度查询次数。 每个查询都是独立的，因此测试用例之间无需维护状态。 
2. 读取目标温度（T）。 固定的物理常数是已知的：房间温度为 70 度，咖啡开始温度为 210 度，15 分钟后校准点为 120 度。 
3. 直接计算时间

 [
 时间=
 15\压裂{\ln(140/(T-70))}
 {\ln(14/5)}。 
]

 分子来自于所需温度的冷却方程的反演，而分母则来自用于确定冷却常数的校准测量。 

1. 打印生成的浮点值。 不需要四舍五入到固定的小数位数，因为法官接受足够准确的实数。 

原理：重新排列牛顿方程后，每个目标温度恰好对应一个有限时间，因为指数项从 1 向 0 连续递减。校准点确定唯一的未知参数 (k)，第二个对数隔离 (t)。 因此，为每个查询打印的值正是给定冷却模型所表示的时间。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n = int(input())

    denominator = math.log(14 / 5)

    for _ in range(n):
        temperature = int(input())

        time = 15 * math.log(140 / (temperature - 70)) / denominator
        print(time)

if __name__ == "__main__":
    solve()
```每个测试用例的分母都是恒定的，因此它只计算一次而不是重复计算。 它表示校准测量的对数形式。 

对于每个目标温度，`temperature - 70`是咖啡温度高于室温的量。 将 140 除以该数量即可得出指数因子的倒数。 取其自然对数即可分离出与时间相关的指数。 

乘以 15 并除以`log(14 / 5)`合并已知的校准点。 保持浮点计算可以避免因手动近似冷却常数而引入舍入误差。 

不存在整数溢出问题，因为Python整数具有任意精度，主要计算使用Python的双精度浮点`float`。 数学上唯一重要的边界是`temperature - 70 > 0`，因为对数必须接受正参数。

def solve():

def run(inp: str) -> str:

 ## 边缘情况

 起始温度是最干净的边界情况。 为了```
1
210
```我们有 (T-70=140)，所以对数得到 (140/140=1)。 其对数为零，即 (t=0)。 该算法自然地处理这个问题，没有特殊情况。 

校准温度是另一个有用的边界。 为了```
1
120
```表达式变为

 # 15\压裂{\ln(14/5)}{\ln(14/5)}

 1.

 ]

 因此，用于确定冷却常数的输入也由最终公式再现。
