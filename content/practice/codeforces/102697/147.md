 ## 解决方案
 ## 问题理解

 我们按照边界顺序给出了凸多边形的顶点。 每个顶点都有整数坐标，多边形可以有任意的边长和角度。 任务是计算多边形的精确面积并将其打印为十进制数。 该存档问题的官方约束并未给出 n 的数值上限，但时间限制仅为 1 秒，内存限制为 256 MB。 多边形有三个以上的顶点，且没有多边形的边是完全垂直的。 凸性保证意味着每个边界转弯具有相同的方向，因此顶点描述一个简单的凸区域而不是自相交的多边形。 

缺乏规定的坐标界限意味着只要可以进行精确的整数计算，我们就应该避免使用浮点几何。 对于整数坐标，多边形的加倍面积始终是整数，因此我们可以使用整数算术计算该数量，并仅在格式化答案时除以二。 Python 整数还消除了固定宽度语言中坐标较大时可能出现的溢出问题。 

主要的边缘情况是由答案可能是整数或半整数这一事实引起的。 例如，```
40 02 02 10 1
```面积为 2，所以正确的输出是`2.0`。 始终将答案视为整数的实现将丢失所需的十进制表示形式。 

第二个例子是第一个样本中的钻石：```
40 55 00 -5-5 0
```它的面积是 50，所以正确的输出是`50.0`。 如果顶点是顺时针方向而不是逆时针方向给出，则粗心的实现可能会获得负符号区域。 多边形在任一方向都有效，因此需要有符号面积的绝对值。 

第三个有用的情况是面积加倍为奇数的多边形：```
56 64 32 11 53 7
```正确的输出是`15.5`。 使用整数倍面积进行计算可以避免任何舍入问题。 

## 方法

 直接三角测量方法很容易推导。 选择一个顶点，例如 P 0 ​，并将凸多边形分割为三角形 (P 0 ​ ,P 1 ​ ,P 2 ​ ), (P 0 ​ ,P 2 ​ ,P 3 ​ ) 等。 由于多边形是凸多边形，因此这些三角形中的每一个都位于多边形内部，并且它们一起精确地覆盖多边形。 我们可以用叉积计算每个三角形的面积并将结果相加。 

该方法的复杂度已经是 O(n)，因为具有 n 个顶点的多边形恰好生成 n−2 个三角形。 尝试每一种可能的三角剖分的真正暴力方法会更糟糕，因为 n 边形的三角剖分数量是加泰罗尼亚数 C n−2 ​，它呈指数增长。 没有理由去探索这些可能性，因为凸性免费为我们提供了一种特别简单的三角测量。 

有一种更简洁的方式来表达相同的几何形状。 三角形 ABC 的两倍有符号面积是

 (x A ​ y B ​ +x B ​ y C ​ +x C ​ y A ​ )−(y A ​ x B ​ +y B ​ x C ​ +y C ​ x A ​ )。 

如果我们从 P 0 ​开始对多边形进行三角剖分，则添加三角形区域时涉及 P 0 望远镜的所有项。 剩下的正是

 i=0 Σ n−1 ​ (x i ​ y i+1 ​ −y i ​ x i+1 ​ ),

 其中 P n ​ =P 0 ​。 这就是鞋带公式。 

重要的见解是三角测量不需要我们显式地构造三角形。 它们的签名区域可以逐边累积。 这将实现减少为一次遍历多边形，同时保留三角剖分参数的精确整数算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 显式扇形三角测量 | O(n) | O(n) | 已接受 |
 | 鞋带配方| O(n) | O(n) | 已接受 |

 鞋带实现是更可取的，因为它只需要连续的边缘并且索引错误的机会更少。 

## 算法演练

 1. 按照 n 个顶点在多边形周围出现的顺序读取它们。 存储它们的坐标，以便可以处理从最后一个顶点回到第一个顶点的最终边。 
2. 初始化一个整数累加器`twice_area`为零。 我们故意存储两倍的有符号区域，因为叉积自然会产生这个值并避免浮点运算。 
3. 对于每个顶点 P i ​ =(xi ​ ,y i ​ )，令 P j ​为下一个顶点，其中 j=(i+1)modn。 添加

 x i ​ y j ​ −y i ​ x j ​

 到`twice_area`。 这是两个位置向量的有符号叉积，表示边缘的有符号面积贡献的两倍。 
4. 取绝对值`twice_area`。 顺时针输入给出负和，而逆时针输入给出正和，但两者描述相同的几何面积。 
5. 打印`abs(twice_area) / 2`。 由于加倍的区域是整数，因此结果始终是整数或以整数结尾`.5`。 在小数点后打印一位数字即可给出所需的十进制表示形式。 

### 为什么它有效

 考虑通过将每个多边形顶点连接到原点而形成的三角形。 每个边界边的叉积给出了相应三角形的有符号面积。 当这些带符号的三角形在多边形外部重叠时，它们的贡献会成对抵消。 唯一未取消的签名区域是多边形本身。 同样，鞋带总和恰好是扇形三角剖分的有符号面积之和，所有项都涉及所选扇形顶点取消。 取绝对值消除了对顶点是顺时针还是逆时针列出的依赖性。 

## Python 解决方案```python
Pythonimport sysinput = sys.stdin.readline

def solve():    n = int(input())    points = [tuple(map(int, input().split())) for _ in range(n)]
    twice_area = 0
    for i in range(n):        x1, y1 = points[i]        x2, y2 = points[(i + 1) % n]        twice_area += x1 * y2 - y1 * x2
    twice_area = abs(twice_area)
    print(f"{twice_area / 2:.1f}")

if __name__ == "__main__":    solve()
```第一部分读取并存储顶点。 保留整个列表使环绕边缘变得简单：`(i + 1) % n`将最终顶点映射回顶点零。 

主循环直接实现鞋带求和。 表达式`x1 * y2 - y1 * x2`不得用每条边的绝对值替换。 各个边可以具有正或负的签名贡献，这些签名是使取消起作用的原因。 

仅在计算出完整总和后才应用绝对值。 在循环内应用它会计算出不同的数量，并且通常会给出错误的面积。 

Python 整数可以根据需要增长，因此即使坐标积很大，累加器也不会溢出。 最终的除法是安全的，因为在格式化之前该值已经是准确的。 该问题要求输入一个十进制数，所以`f"{twice_area / 2:.1f}"`打印两者`50.0`和`15.5`正确。

## 边缘情况

 第一个边缘情况是最小的合法多边形。 为了```
40 01 01 10 1
```交叉贡献是`0`,`1`,`1`， 和`0`，面积增加一倍`2`和输出`1.0`。 模表达式`(i + 1) % n`是正确包含最终边缘的内容`(0,1)`回到`(0,0)`。 

第二个边缘情况是奇数倍区域。 为了```
40 03 02 10 1
```贡献是`0`,`3`,`2`， 和`0`，所以面积加倍为`5`。 算法打印`5 / 2 = 2.5`，展示了为什么使用整数加倍区域比过早将坐标或部分区域转换为浮点数更可取。 

第三种边缘情况是顺时针输入。 为了```
40 00 23 23 0
```鞋带总和是`-12`，即使几何面积为正。 该算法计算`abs(-12) = 12`和打印`6.0`。 假设输入必须是逆时针方向的解决方案将错误地打印负值区域。 

最后一个微妙的情况是结束边缘。 如果实现仅处理对`(P_i,P_{i+1})`为了`i < n-1`，它会默默地忽略从最后一个顶点到第一个顶点的边。 对于上面的单位正方形，这三个处理过的边仅贡献`1`, 给予`0.5`而不是`1.0`。 模索引精确地包含缺失的边并避免了特殊情况的分支。
