 ## 解决方案
 ## 问题理解

 我们有一个长方形的大厅，由`n × m`网格。 网格包含空单元格，对角镜表示为`/`或者`\`，以及特殊的`*`细胞。 激光从下方的柱子进入大厅`x`，所以它的初始方向是向上的。 

空单元只是让激光继续沿同一方向前进。 对角镜根据其方向改变方向。 一个`/`镜子以通常的反射模式交换垂直和水平运动，而`\`镜子则起到相反的作用。 一个`*`不同的是：当光到达它时，光会继续沿所有四个基本方向传播，因此单个激光路径变成了多个路径。 

输出保持每个镜子和星星不变。 水平交叉的空单元格变成`-`，垂直交叉的空单元格变成`|`，并且在两个方向上交叉的空单元格变为`+`。 

官方声明给出了 1 秒的时间限制和 256 MB 的内存限制，但发布的版本没有公开数值上限`n`和`m`在其可见的限制中。 因此，预期的方法必须随着网格单元的数量线性扩展。 可能无限期地重新访问相同激光状态的模拟是不安全的，因为镜子可以产生循环。 解决方案围绕`O(nm)`是自然目标，因为它每个单元仅处理恒定数量的方向状态。 

第一个边缘情况是尽可能小的大厅。 为了```
1 1 0
.
```激光立即垂直进入唯一的单元，所以答案是```
|
```在处理当前单元格之前首先移动到下一行的粗心实现会错误地产生`.`。 

第二个边缘情况是入口单元上的镜子：```
1 1 0
/
```答案是```
/
```激光到达镜子，反射，然后立即离开大厅。 镜子本身绝不能被替换`|`或者`-`。 

第三种边缘情况是激光到达的恒星：```
1 3 1
.*.
```答案是```
-*-
```入射的垂直光束到达恒星，然后恒星将光水平发送到两个相邻的细胞。 一种解决方案可以治疗`*`因为普通的直通单元会错过两个水平光束。 

最后的危险情况是一个循环。 镜子可以将光束发送回它已经访问过的位置。 如果实现仅跟踪光线直到它们离开板，则它可能会永远循环。 正确的状态单位不仅仅是一个单元，而是一个单元以及光束当前行进的方向。 

## 方法

 最直接的方法是独立模拟每个光束。 从入口开始，我们一次一个细胞地沿着当前方向，在镜子中反射，并在星星处分支。 这在概念上是正确的，因为程序执行的每个操作都直接对应于灯光在大厅中的作用。 

问题是同一物理状态可以多次达到。 状态由单元和方向组成，并且只有`4nm`这样的状态，但天真的路径枚举不知道这一点。 在一颗恒星上，可以创建四个新路径，因此独立探索每条可能的路径可以随着恒星数量呈指数增长。 和`s`分支星，路径选择可以达到的数量`4^s`，在考虑这些路径的长度之前。 更糟糕的是，镜像循环可以使不受保护的模拟永远运行，而不仅仅是变慢。 

关键的观察是，激光器的未来行为仅取决于其当前的单元和方向。 如果我们第二次以相同的方向到达同一个单元格，那么之后发生的一切都已经被模拟了。 没有理由再去探索它。 

这将问题转化为一个小的有向状态图。 每个州都是`(row, column, direction)`。 普通的空单元有一种出射状态，镜子有一种反射出射状态，星形有最多四种出射状态。 我们从初始状态开始进行图遍历，并在处理后立即标记每个状态。 

输出中还有一项附加详细信息。 同一空单元格可以水平地被一个分支交叉并且垂直地被另一分支交叉。 因此，我们为每个单元保留两个独立的位，一个表示水平光穿过它，另一个表示垂直光穿过它。 最后一个字符直接来自这两位。 

蛮力方法可以以指数方式多次重新访问状态或无限循环。 基于状态的遍历最多处理每个`4nm`状态一次，给出网格大小的线性复杂度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 分支路径的数量呈指数级增长，并且可能不会以循环结束 | 潜在指数 | 太慢了 |
 | 最佳 |`O(nm)`|`O(nm)`| 已接受 |

 ## 算法演练

 1. 完全按照给定的方式存储网格。 我们保留原始字符，因为输出标记例如`-`,`|`， 和`+`不得改变后续激光分支解释细胞的方式。 
2. 将四个方向表示为上、右、下、左。 每个方向都有行和列增量，因此移动一步是一个恒定时间操作。 
3. 开始状态遍历`(n - 1, x, up)`。 激光进入列的底部行单元`x`向上移动时，该单元格是第一个必须处理的网格位置。 
4. 为每个保持已访问状态`(row, column, direction)`。 在处理一个状态之前，检查它是否已经被访问过。 如果有，则丢弃它，因为它的整个延续已经被探索过。 
5. 当当前单元格为空时，记录光束是水平移动还是垂直移动。 不要更改实际的网格字符，因为另一束光束稍后可能会到达同一单元格。 
6. 当当前单元格包含`/`，使用反映方向`up ↔ right`和`down ↔ left`。 当它含有`\`， 使用`up ↔ left`和`down ↔ right`。 反射的方向决定了下一个状态。 
7. 当当前单元格包含`*`，将来自同一单元格的所有四个方向排队。 星形是一个分支点，因此将遍历限制在传入方向会丢失有效光束。 
8. 在每个选定的方向上移动一个单元格。 如果该位置位于大厅之外，则丢弃该状态，因为相应的光束已离开镜厅。 
9. 遍历结束后，将每个原来为空的单元格根据其两个遍历位进行转换。 没有一点意思`.`, 仅水平表示`-`, 仅垂直表示`|`，两位都表示`+`。 

### 为什么它有效

 不变的是每个可到达的激光状态`(row, column, direction)`只被处理一次，并且在处理之后，从该状态开始的每个可能的激光延续都已被安排。 空单元格保留方向，镜子确定性地反射它，而星星生成所有四个允许的方向。 因此，不会遗漏任何可到达的光束段。 

相反，一旦一个状态已经被处理，再次达到相同的状态就不能产生任何新的行为。 网格是静态的，因此每次达到状态时其输出转换都是相同的。 因此，标记访问的状态只会删除重复的工作，而不会删除激光路径的明显部分。 由于每个交叉的空单元都独立记录其水平和垂直遍历，因此最终的字符准确地描述了到达大厅的所有光线。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, x = map(int, input().split())
    grid = [list(input().strip()) for _ in range(n)]

    # Directions: 0 = up, 1 = right, 2 = down, 3 = left.
    dr = (-1, 0, 1, 0)
    dc = (0, 1, 0, -1)

    # For every cell:
    # bit 0 means horizontal light passed through it.
    # bit 1 means vertical light passed through it.
    marks = bytearray(n * m)

    # Four possible directions for every cell.
    visited = bytearray(4 * n * m)

    stack = [(n - 1, x, 0)]

    while stack:
        r, c, d = stack.pop()

        if not (0 <= r < n and 0 <= c < m):
            continue

        state = ((r * m + c) << 2) | d
        if visited[state]:
            continue
        visited[state] = 1

        cell = grid[r][c]

        if cell == '.':
            idx = r * m + c
            if d == 0 or d == 2:
                marks[idx] |= 2
            else:
                marks[idx] |= 1

        if cell == '*':
            for nd in range(4):
                nr = r + dr[nd]
                nc = c + dc[nd]
                if 0 <= nr < n and 0 <= nc < m:
                    stack.append((nr, nc, nd))
            continue

        if cell == '/':
            if d == 0:
                d = 1
            elif d == 1:
                d = 0
            elif d == 2:
                d = 3
            else:
                d = 2

        elif cell == '\\':
            if d == 0:
                d = 3
            elif d == 3:
                d = 0
            elif d == 2:
                d = 1
            else:
                d = 2

        nr = r + dr[d]
        nc = c + dc[d]

        if 0 <= nr < n and 0 <= nc < m:
            stack.append((nr, nc, d))

    for r in range(n):
        row = []
        for c in range(m):
            cell = grid[r][c]

            if cell != '.':
                row.append(cell)
                continue

            value = marks[r * m + c]

            if value == 0:
                row.append('.')
            elif value == 1:
                row.append('-')
            elif value == 2:
                row.append('|')
            else:
                row.append('+')

        print(''.join(row))

if __name__ == "__main__":
    solve()
```这`grid`阵列仅包含原始大厅。 这种分离是必要的，因为空单元格已在概念上更改为`-`或者`|`对于另一个光束来说，物理上仍然是一个空单元。 

这`marks`数组每个单元使用两位。 少量`1`代表水平遍历和位`2`代表垂直遍历。 值为`3`自然对应于`+`。 

这`visited`数组的每个单元格有四个条目，每个条目对应一个传入方向。 一个`bytearray`使用而不是 Python 元组集，因为状态数量可能很大，并且每个状态一个字节可提供可预测的内存使用情况。 

镜像转换是明确写入的。 为了`/`，向上的光束变为向右，向右的光束变为向上，向下的光束变为向左，而向左的光束变为向下。 为了`\`，对应的对是上和左，下和右。 

星形在普通方向转换之前进行处理，因为它不反射单个光束。 它产生四个出射光束。 当前的星形单元本身永远不会被标记，因为输出必须保留`*`。 

边界检查发生在处理状态之前，并在创建下一个状态时再次发生。 第一个检查处理可以推送外部状态的防御情况，而第二个检查则阻止外部坐标进入堆栈。 

使用迭代 DFS 而不是递归 DFS。 长直梁可以包含许多单元，即使算法本身是线性的，递归也可能会超出 Python 的递归限制。

 对于一间空荡荡的大厅来说，```
1 1 0
.
```堆栈最初包含`(0, 0, up)`。 该状态位于网格内部，因此空单元接收垂直位。 下一个位置在网格之外，因此不再添加更多状态。 最终的评分值为`2`，这变成`|`。 输出正是`|`。 

镜子直接放在入口处，```
1 1 0
/
```状态达到`/`向上移动的同时。 反射将方向改变为向右，之后下一个坐标位于一柱大厅之外。 因为当前单元是镜像而不是空单元，所以没有输出标记写入那里。 原来的`/`被保留。 

对于入口处的明星来说，```
1 3 1
.*.
```激光第一道工序`(0, 1, up)`。 由于细胞是`*`，遍历推动所有四个方向。 左边的分支进入`(0, 0)`水平并标记它`-`。 右侧分支进入`(0, 2)`水平并标记它`-`。 向上和向下的分支离开网格。 恒星保持不变，产生`-*-`。 

更微妙的边缘情况是在两个方向上都达到的单元格。 假设一个分支水平标记一个空单元格，并赋予它标记值`1`。 如果另一个分支垂直到达它，该算法执行`marks[idx] |= 2`，将值更改为`3`。 最终转换图`3`到`+`。 当第二个分支到达时，仅在网格中直接存储一个字符的解决方案很容易丢失第一个方向。 

循环由方向状态处理，而不是由单元单独处理。 如果激光返回到`(r, c)`从同一方向，相应的访问字节已被设置并且状态被丢弃。 如果它从不同的方向返回，那就是一个真正不同的状态并被处理。 这种区别正是所需要的，因为同一单元可以参与水平和垂直路径，而不意味着第二次访问是多余的。
