 ## 解决方案
 ## 问题理解

 任务是总结参加 Zoom 会议的国家/地区。 有 (n) 名与会者，每位与会者贡献一个国家/地区名称。 我们需要计算有多少与会者属于每个不同的国家/地区，然后通过减少与会者数量对国家/地区进行排序。 当两个国家/地区的计数相同时，将按字母顺序比较它们的名称。 

Only the first five countries in this ordering are printed. 如果存在的不同国家/地区少于五个，则打印所有不同的国家/地区。 每个输出行包含国家/地区名称及其频率。 

官方说法没有给出（n）的数值上限，但时间限制只有1秒，内存限制为256 MB。 这使得二次工作的解决方案对于大输入来说不安全。 我们的目标应该是对与会者进行线性传递，然后对不同的国家/地区进行排序。 如果有 (k) 个不同的国家，则给出 (O(n + k\log k)) 和 (k\le n)，因此最坏的情况是 (O(n\log n))。 

有两种微妙的情况很容易导致错误的输出。 首先，即使在 (n\ge5) 时，也可能出现少于五个不同的国家。 例如，```
9
USA
Germany
Brazil
China
USA
China
China
USA
USA
```只有四个不同的国家，所以正确的输出是```
USA 4
China 3
Brazil 1
Germany 1
```总是打印五行的粗心实现将尝试打印不存在的第五个国家。 

其次，必须按字母顺序解决相同的频率。 例如，```
4
USA
USA
Mexico
Mexico
```产生```
Mexico 2
USA 2
```尽管这两个国家都出现过两次。 仅按频率排序会使它们的相对顺序未指定，并且可能会产生错误的答案。 

## 方法

 直接的暴力方法是检查每个国家并计算它在完整与会者列表中出现的次数。 如果我们为每位与会者独立执行此操作，最坏的情况是所有 (n) 个国家/地区名称都不同。 第一个国家需要 (n) 次比较，第二个国家需要另一个 (n) 次比较，依此类推，在最坏的情况下进行 (n^2) 次比较。 更准确地说，如果我们避免重新计算已处理的国家/地区，则比较次数仍约为 (n^2)，检查次数约为 (n(n+1)/2)。 这是不必要的工作，因为相同的名称会被重复比较。 

关键的观察结果是，每位与会者都为一个国家/地区的计数做出了贡献。 字典可以存储每个国家/地区的当前频率，因此每个输入名称会在预期 (O(1)) 时间内更新其计数。 在此过程之后，字典将准确包含输出所需的信息。 

然后，我们使用由负频率和国家/地区名称组成的键对不同的国家/地区进行排序。 负值使得较大的频率排在第一位，而名称自然提供了所需的字母顺序决胜局。 

蛮力之所以有效，是因为反复扫描原始列表最终会发现每个国家/地区的确切频率，但它会失败，因为它会重新计算已经发现的信息。 字典改变了重复询问“这个名字出现了多少次？”的过程。 在每位与会者阅读时保留答案。 一旦知道计数，仅对不同的国家/地区进行排序即可完成任务。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(n^2)) | (O(n)) | (O(n)) | 对于大 (n) 来说太慢 |
 | 字典+排序 | (O(n+k\log k))，其中 (k) 是不同国家/地区的数量 | (O(k)) | 已接受 |

 ## 算法演练

 1. 读取 (n)，然后一次处理下一个 (n) 个国家/地区名称。 将每个名称存储在字典中并增加其关联的频率。 以前从未出现过的国家以零频率开始，因此更新自然会创建其第一个条目。 
2. 将字典条目转换为包含国家名称及其频率的对。 此时，每个不同的国家/地区都有一对，因此无需再次扫描与会者信息。 
3. 按频率递减对这些对进行排序，对于相同的频率，按国家名称递增对这些对进行排序。 使用钥匙`(-count, country)`直接表达两个排序规则。 
4. 最多取前五个排序对。 如果不同的国家/地区少于五个，切片会自动返回每个可用的国家/地区，而不是创建额外的输出行。 
5. 打印每个选定的国家/地区及其计数。 排序后的顺序已经符合所需的排名，因此不需要进行额外的处理。 

不变的是，在处理与会者列表的任何前缀后，字典包含该前缀中出现的每个国家/地区的确切出现次数。 当整个输入被处理后，每个国家的频率都是准确的。 使用指定的决胜局对这些确切的频率进行排序可以精确地产生所需的排名，并取前五个给出所需的输出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    count = {}

    for _ in range(n):
        country = input().strip()
        count[country] = count.get(country, 0) + 1

    ranking = sorted(count.items(), key=lambda item: (-item[1], item[0]))

    for country, frequency in ranking[:5]:
        print(country, frequency)

if __name__ == "__main__":
    solve()
```字典`count`实现前两个算法步骤。`get(country, 0)`处理这两种情况，无论该国已经出现过还是第一次遇到。 

排序键是中心实现细节。 对于诸如这样的条目`("USA", 4)`，关键变成`(-4, "USA")`。 Python 按字典顺序对元组进行排序，因此较小的第一个组件意味着较大的原始频率排在第一位。 如果两个频率相等，则它们的第一个分量相等，并且 Python 按字母顺序比较国家/地区名称。 

切片`ranking[:5]`也是故意的。 它既处理至少有五个不同国家的正常情况，也处理少于五个不同国家的情况。 特别是，它不会将与会者人数与不同国家/地区的数量混淆。 

Python 整数不会溢出，最大可能频率就是 (n)。 输入被读取`sys.stdin.readline`，这对于潜在大量的国家/地区线路来说已经足够了。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | (O(n+k\log k)) | (O(n+k\log k)) | 计数需要 (O(n))，对 (k) 个不同国家进行排序需要 (O(k\log k))。 |
 | 空间| (O(k)) | 字典和排序列表为每个不同的国家/地区存储一个条目。 |

 由于 (k\le n)，最坏情况总时间为 (O(n\log n))，辅助空间为 (O(n))。 这轻松地避免了重复扫描与会者列表的二次行为，并符合预期输入大小的 1 秒、256 MB 限制。

 ## 边缘情况

 单个与会者是最小的有意义的输入。 为了```
1
Canada
```字典变成`{"Canada": 1}`。 排序使唯一的条目保持不变，切片为五个条目仍返回一个条目。 输出是```
Canada 1
```因此，实施并不假设五个国家总是存在。 

当每个与会者都具有相同的国家/地区时，无论 (n) 有多大，都只有一个不同的条目。 为了```
5
Japan
Japan
Japan
Japan
Japan
```五次词典更新离开`Japan`频率为 5。排序列表的长度为 1，因此`[:5]`仅返回该条目，输出为`Japan 5`。 这捕获了每当 (n\ge5) 时错误地打印五行的实现。 

相同的频率需要二次字母顺序。 为了```
4
USA
USA
Mexico
Mexico
```两个字典条目都以频率 2 结尾。它们的排序键是`(-2, "USA")`和`(-2, "Mexico")`。 自从`"Mexico"`按字母顺序排列较小，它排在第一位，给出`Mexico 2`其次是`USA 2`。 

最能说明问题的边界情况是，有超过五个不同的国家，但应打印的国家少于五个，因为排名是有上限的。 考虑```
8
Zulu
Alpha
Bravo
Charlie
Delta
Echo
Alpha
Bravo
```最终计数为 Alpha 2、Bravo 2 和频率为 1 的其他四个国家。排序给出 Alpha、Bravo、Charlie、Delta、Echo、Zulu，切片到 5 个条目仅删除 Zulu。 输出是```
Alpha 2
Bravo 2
Charlie 1
Delta 1
Echo 1
```这可以同时发现两个常见错误：对频率相同的国家/地区进行错误排序，并打印超过所需的五个排名国家/地区。
