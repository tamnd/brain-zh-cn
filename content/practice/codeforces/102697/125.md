 ## 解决方案
 ## 问题理解

 我们收到构成大三和弦的三个音符。 注释可以按任何顺序书写，并且注释可以使用锐记号，例如`C#`或扁平符号，例如`Df`。 我们需要确定三个音符中哪一个是根音。 

一个八度内的十二个音级可以分配整数值`0`通过`11`:`C, C#, D, D#, E, F, F#, G, G#, A, A#, B`。 

相距半步的两个音符具有连续的值，八度音阶环绕从`B`回到`C`。 根音有价值的大和弦`r`包含三个音级`r`,`r + 4`， 和`r + 7`，所有算术都取模`12`。 输入可以包含任意排列的这三个音符。 

该符号创建了一个很容易被忽略的实现细节。`C#`和`Df`代表相同的音级，就像`D#`和`Ef`,`F#`和`Gf`,`G#`和`Af`， 和`A#`和`Bf`。 我们必须将两种拼写转换为相同的数值进行比较，但是当我们输出词根时，我们应该打印输入中出现的原始拼写。 

只有三个音符和十二个可能的音级。 因此，约束很小，因此不存在传统线性或二次算法太慢的风险。 即使对每个可能的根进行详尽的搜索也仅执行恒定数量的操作。 这里有用的目标不是渐近优化，而是将问题简化为很难出错的干净区间检查。 

第一种边缘情况是根音不是第一个输入音符的和弦。 例如，```
E G C
```有价值观`4, 7, 0`。 正确的输出是`C`。 假设第一个音符是根音的实现将错误地打印`E`。 

第二种边缘情况是音级的扁平拼写。 例如，```
Bf Ef G
```代表值`10, 3, 7`，这是降 E 大调和弦的音符。 正确的输出是`Ef`。 如果`Bf`和`Ef`被视为不相关的弦，而不是将降音转换为其音级，音程测试无法正常工作。 

第三种边缘情况发生在八度音阶边界上。 例如，```
B D# F#
```代表价值观`11, 3, 6`。 根是`B`， 因为`11 + 4 = 15`，即`3`模数`12`， 和`11 + 7 = 18`，即`6`模数`12`。 使用普通整数差而不进行模运算的粗心实现可能会拒绝该有效和弦。 

第四种边缘情况是另一种反转，其中第五种情况首先出现：```
G C E
```正确的输出是`C`。 按数字对音符进行排序并假设最小音高是根音在其他反转中也会失败，因为根音是音乐音高类别而不一定是第一个或最小输入值。 

## 方法

 最直接的强力解决方案是尝试十二个音级中的每一个作为可能的根音。 对于候选根`r`，相应的大和弦必须恰好包含`r`,`(r + 4) mod 12`， 和`(r + 7) mod 12`。 我们将这三个值与三个输入音符进行比较。 由于有 12 个候选和 3 个音符，最坏的情况最多执行 36 次基本隶属度比较，加上构建每个候选和弦所需的少量算术。 这已经是常数时间并且很容易足够快。 

蛮力方法是正确的，因为该问题保证输入是大和弦，并且其根音是提供的三个音符之一。 因此，恰好一个候选根描述了给定的一组音级。 

我们可以通过使用最终保证来缩小搜索范围。 不必尝试所有十二个音级，只需三个输入音符可以作为根音。 对于这三个候选者中的每一个，我们检查其他两个音符是否正好比它高四个和七个半音。 候选根`r`当输入音级集等于时精确有效`{r, r + 4, r + 7}`模数`12`。 

大三和弦具有固定音程模式的观察结果是关键的简化。 我们不需要推理提供音符的顺序，也不需要区分不同的倒置。 一旦每个拼写都被映射到音级，和弦就只是一个具有已知模式的三元素集。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解全部 12 个根 | O(1) | O(1) | O(1) | O(1) | 已接受 |
 | 测试提供的 3 个音符作为根音 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 第二种方法更可取，因为它直接使用输入所承诺的结构，并使正确性论证变得简单。 

## 算法演练

 1. 创建从每个可能的输入拼写到其音级数字的映射`0`到`11`。 例如，`C`映射到`0`,`C#`和`Df`两者都映射到`1`， 和`B`映射到`11`。 
2. 读取三个音符字符串并将每个音符转换为其数字音级。 也保留原始字符串，因为所需的输出应使用为根提供的拼写。 
3. 将三个数值放入一个集合中。 输入描述了大和弦的三个不同音符，因此该集合代表和弦中音级的完整集合。 
4. 尝试将三个输入音符中的每一个作为可能的根音。 对于候选值`r`，构建预期的大三和弦`{r, (r + 4) % 12, (r + 7) % 12}`。 
5. 将预期三元组与输入集进行比较。 如果它们相等，则候选者是根，因此输出其原始输入拼写。 
6. 由于输入保证是有效的大和弦，因此三个候选者之一必须成功。 有效的判断数据不需要后备案例。 

### 为什么它有效

 对于每一位候选人`r`，当三个输入音级为`{r, r + 4, r + 7}`模数`12`。 这正是具有根音的大三和弦的定义`r`。 实际的根音保证位于三个输入音符之间，因此算法最终会对其进行测试并接受它。 非根音输入音符无法通过相同的测试，因为将该音符移动四个和七个半音会产生不同的大三和弦模式。 因此，返回的候选是根，附加到该候选的原始拼写是所需的输出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

NOTE_VALUE = {
    "C": 0,
    "C#": 1,
    "Df": 1,
    "D": 2,
    "D#": 3,
    "Ef": 3,
    "E": 4,
    "F": 5,
    "F#": 6,
    "Gf": 6,
    "G": 7,
    "G#": 8,
    "Af": 8,
    "A": 9,
    "A#": 10,
    "Bf": 10,
    "B": 11,
}

def solve():
    notes = input().split()
    values = [NOTE_VALUE[note] for note in notes]
    chord = set(values)

    for i, root in enumerate(values):
        expected = {
            root,
            (root + 4) % 12,
            (root + 7) % 12,
        }

        if expected == chord:
            print(notes[i])
            return

if __name__ == "__main__":
    solve()
```这`NOTE_VALUE`字典可以处理锐利拼写和扁平拼写。 多个字符串可以映射到相同的整数，因为对于此问题，等音音符具有相同的音级。 

原来的`notes`列表单独保存`values`。 这是必要的，因为如果输入包含`Ef`，所需答案是`Ef`，不是一些规范的拼写，例如`D#`。 

套装`chord`从输入中删除排序。 对于候选根音，预期的大和弦也表示为一个集合，因此比较不依赖于输入是在根音位置、第一转位还是第二转位中给出的。 

新增内容由`4`和`7`执行模`12`。 这处理从以下位置交叉的和弦`B`回到`C`，例如B大调和弦`B D# F#`。 

不存在整数溢出问题，因为每个值都在`0`和`11`，Python 整数也可以处理任意精度。 该循环正好有 3 次迭代，因此不需要额外的优化。

## 边缘情况

 第一个边缘情况是反转。 和```
E G C
```值为`4, 7, 0`。 算法首先测试`E`, 期待`{4, 8, 11}`，这不匹配。 然后它测试`G`, 期待`{7, 11, 2}`，这也失败了。 最后测试了`C`, 期待`{0, 4, 7}`，正是输入集。 它输出`C`。 关键的属性是该算法将三个音符视为一个集合，因此它们的输入顺序没有影响。 

第二种边缘情况是等音拼写。 和```
Bf Ef G
```字典转换`Bf`到`10`,`Ef`到`3`， 和`G`到`7`。 测试`Ef`给出`(3 + 4) % 12 = 7`和`(3 + 7) % 12 = 10`，生产`{3, 7, 10}`。 这等于输入集，因此算法输出原始字符串`Ef`。 将注释转换为数字，同时保留其原始字符串可以正确处理比较和输出。 

第三个边缘情况穿过八度音阶的末尾。 和```
B D# F#
```根候选者`B`有价值`11`。 它的第三个是`(11 + 4) % 12 = 3`，即`D#`，它的第五个是`(11 + 7) % 12 = 6`，即`F#`。 预期的集合是`{11, 3, 6}`，正是输入。 如果没有模运算，第三个和第五个将错误地出现在八度音阶之外。 

第四种边缘情况涉及的根音既不是第一个也不是最小的数字音符。 和```
G C E
```值为`7, 0, 4`。 候选人`G`失败是因为它的预期大三和弦是`{7, 11, 2}`。 候选人`C`成功与`{0, 4, 7}`，所以答案是`C`。 这就是为什么对值进行排序并假设第一个排序的值是根将是无效的快捷方式的原因。 

该算法也自然地处理根已经是第一个的情况，例如```
C E G
```这里第一个候选人立即产生`{0, 4, 7}`， 所以`C`被返回。 无论输入顺序如何，都使用相同的不变量：仅当候选者的四个半音和七个半音间隔准确生成三个提供的音级时，才接受候选者。
