 ## 解决方案
 ## 问题理解

 该问题描述了几位前来理发的顾客。 对于每个客户，我们都知道他们当前的头发长度以及理发后他们想要的长度。 我们需要计算必须去除多少英寸的头发才能将当前长度更改为要求的长度。 

对于当前长度的客户`a`和所需的长度`b`， 切割`x`英寸叶子`a - x`英寸。 我们想要`a - x = b`。 

解决`x`给出`x = a - b`。 

所以每个测试用例都是完全独立的，客户端之间没有交互。 官方输入包含`n`测试用例，后跟每个客户端的一对整数。 官方声明没有给出整数值的明确上限，但由于每个测试用例只需要一次减法，因此值的大小不会影响算法复杂度。 Python 整数还可以避免固定宽度溢出。 

主要的边缘情况是客户端已经完全具有所请求的长度。 例如，```
1
10 10
```需要输出```
0
```假设每个客户都需要正数削减的粗心解决方案可能会错误地产生`1`否则无法处理零情况。 

另一种边界情况是仅存在一个测试用例时。 例如，```
1
1 0
```需要输出```
1
```多种情况不需要特殊的初始化，因此相同的减法可以正确处理这个问题。 

该语句没有明确说明如果请求的长度大于当前长度会发生什么。 这种情况是通过剪发无法实现的，因为剪发只能减少长度。 数学量`current - desired`那么就会是负数。 预期的问题上下文是通过切割可以达到所请求的最终长度，因此解决方案直接计算所需的差值。 

原问题的时间限制为一秒，内存限制为 256 MB。 由于每个测试用例仅需要持续的工作，因此即使非常大量的测试用例也可以在相对于输入对的数量呈线性的时间内处理。 没有理由使用排序、动态编程、图形算法或任何数据结构。 

## 方法

 暴力方法可能会尝试一次模拟一英寸的理发。 例如，如果客户的头发长 1,000,000 英寸，所需长度为 1 英寸，则此类模拟将执行 999,999 次单独的切割操作。 更一般地，如果要去除的量是`d`，模拟执行`d`操作，因此其运行时间取决于数值而不是测试用例的数量。 如果输入值很大，这可能会变得不必要的慢。 

蛮力之所以有效，是因为每次模拟切割都会将当前长度恰好减少一，直到达到所需的长度。 不过，这个问题实际上并不需要我们模拟这些中间状态。 我们只需要移除的总金额。 

关键的观察结果是，移除的量恰好是初始长度和最终长度之间的差值。 如果初始长度是`a`最终长度是`b`，然后删除`a - b`英寸直接改变长度`a`到`b`。 因此整个过程可以用一个减法来代替。 

蛮力之所以有效，是因为它最终计算出相同的差异，但当差异很大时会失败。 只有初始和最终长度重要的观察结果让我们可以将每个测试用例简化为常数时间算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 每个案例 O(a - b) | O(1) | O(1) | 当长度很大时太慢 |
 | 最佳 | 每个案例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取号码`n`的客户。 我们独立处理每位客户，因为一位客户的理发不会影响任何其他客户。 
2. 对于每个客户端，读取当前长度`a`并要求最终长度`b`。 这是确定答案所需的唯一两个值。 
3. 计算`a - b`。 这是必须去除的量，因为方程`a - removed = b`有独特的解决方案`removed = a - b`。 
4. 立即打印计算出的差值。 不需要存储以前的测试用例或维护任何全局状态。 

### 为什么它有效

 对于每一位客户，让`x`是剪掉头发的量。 剪完后的头发长度是`a - x`，所需的最终长度为`b`。 因此，有效的发型必须满足`a - x = b`。 重新排列给出`x = a - b`，因此算法准确地输出每个测试用例所需的数量。 由于案例是独立的，因此逐一处理它们会产生所有必需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    ans = []

    for _ in range(n):
        current, desired = map(int, input().split())
        ans.append(str(current - desired))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```第一行被解读为独立客户端的数量。 然后，循环对每个输入对执行一次。 

在循环内部，`current - desired`直接实现算法演练中导出的方程。 答案将转换为字符串并收集起来，以便程序可以一次将它们全部写入。 

不存在相差一的问题，因为问题要求的是去除的毛发量，而不是访问的中间长度的数量。 例如，从 14 到 8 需要恰好`14 - 8 = 6`英寸，而不是 5 或 7 英寸。 

Python 的整数表示也意味着不存在整数溢出问题。 该程序一次仅使用几个变量，因此除了输出列表之外，其辅助内存保持不变。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个`n`客户需要一次减法和恒定的输入/输出工作。 |
 | 空间| O(n) | 该实现存储了`n`在写入字符串之前输出它们。 |

 该算法对于规定的一秒限制来说足够快，因为它只为每个客户端执行恒定的工作。 该问题没有提供明确的最大值`n`在声明中，但即使是大的输入大小也只需要线性扫描。 如果需要，还可以通过立即打印每个答案来避免存储的输出，从而将辅助空间减少到 O(1)。

import io

    old_stdout = sys.stdout

        solve()
        return sys.stdout.getvalue()
    finally:

        sys.stdout = old_stdout

## 边缘情况

 当当前长度和所需长度相等时，考虑精确输入```
1
10 10
```算法读取`current = 10`和`desired = 10`，然后计算`10 - 10 = 0`。 它输出`0`，正确表示不需要剪头发。 

对于最小自然值的单个客户，请考虑```
1
1 0
```该算法计算`1 - 0 = 1`，所以输出是`1`。 没有特殊情况`n = 1`，因为每个测试用例都遵循相同的方程。 

对于较大的数值差异，请考虑```
1
1000000000 1
```所需金额为`1000000000 - 1 = 999999999`。 该算法通过一次算术运算即可获得这一结果，而不是模拟近十亿次单独的切割。
