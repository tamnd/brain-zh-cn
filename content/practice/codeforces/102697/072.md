 ## 解决方案
 ## 问题理解

 我们在平面上恰好给出了三个点，代表等腰三角形的顶点。 三个输入行可以按任意顺序出现。 任务是确定三角形指向的方向，即其对称轴从等底中点向对角顶点的方向。 

例如，用点`(-1, 0)`,`(0, 1)`， 和`(-2, 2)`，等边相交于`(-2, 2)`。 另外两点的中点是`(-0.5, 0.5)`，所以对称轴指向`( -1.5, 1.5 )`，有方向`135`距正 x 轴的度数。 因此所需的答案是`135.0`。 

坐标是浮点值，声明中没有给出有意义的大值`n`或重复的测试用例参数。 总是恰好有三个点，因此即使是检查顶点的每种可能选择的方法也仅执行恒定数量的算术运算。 不存在这样的可能性`O(n^2)`或类似的渐近问题。 主要困难是顶点的几何识别以及由返回的角度的正确处理`atan2`。 

第一个边缘情况是一个三角形，其对称轴恰好指向 x 轴正方向。 例如，```
0 02 01 1
```顶点是`(1, 1)`，基中点为`(1, 0)`，方向是`(0, 1)`，所以正确的输出是`90.0`。 粗心的实现测量从顶点到底部的向量角度会输出`270.0`，反转所需方向。 

当方向具有负 y 分量时，会出现第二种边缘情况。 例如，```
0 02 01 -1
```方向是向下的，所以数学角度是`-90`直接返回时的度数`atan2`。 所需的表示形式介于`0`和`360`，所以正确的输出是`270.0`。 忘记标准化负角度会产生错误的结果。 

第三种边缘情况是输入点以任意顺序呈现。 例如，```
-2 2-1 00 1
```答案依然是`135.0`。 假设第一个点是顶点的实现会意外地使用错误的对称轴。 

一个堕落的案例值得单独关注。 等边三角形有三种可能的顶点选择，因为所有三边都相等，因此它没有唯一的指向方向。 因此，问题的预期等腰三角形输入必须提供唯一的顶点。 下面的算法依赖于该属性。 

## 方法

 直接的方法是尝试将这三个点中的每一个作为可能的顶点。 对于选定的点`A`，另外两点`B`和`C`必须同样远离`A`如果`A`是等腰三角形的顶点。 我们可以比较平方距离`AB²`和`AC²`，完全避免平方根。 一旦找到正确的顶点，中点`BC`给出对称轴上的一个点，以及从中点向`A`给出所请求的方向。 

这种蛮力方法已经是常数时间了，因为只有三个可能的顶点。 在最坏的情况下，我们检查所有三个候选对象，并对每个候选对象执行两次平方距离计算，最多进行六次距离比较加上恒定数量的几何图形。 不存在实际性能问题。 

有用的几何观察结果是，顶点的特征完全是与其他两个顶点的距离相等。 我们不需要计算任何三角形角度或首先确定哪条边是底边。 一旦知道等边端点，通过该端点和对边中点的线正是三角形的对称轴。 

一个稍微简洁的公式是计算所有三个平方边长。 在非等边的等腰三角形中，其中两条边相等，剩下的一条边是底边。 如果`AB = AC`， 然后`A`是顶点。 如果`AB = BC`， 然后`B`是顶点。 否则`C`是顶点。 对于浮点输入，比较应使用较小的相对容差，而不是要求精确的二进制相等。 

蛮力方法和几何方法具有相同的渐近复杂性，因为输入本身仅包含三个点。 第二种公式更可取，因为它使几何不变量变得明确，并避免了任何不必要的排列搜索。

 ## 算法演练

 1. 阅读三点`A`,`B`， 和`C`。 它们的顺序不具有任何几何意义，因此我们必须自己确定顶点。 
2. 计算三个边长的平方`AB²`,`AC²`， 和`BC²`。 平方距离就足够了，因为正距离相等相当于它们的平方相等，并且避免平方根可以使算术更简单、更稳定。 
3. 确定哪一点是顶点。 如果`AB²`和`AC²`相等，那么`A`与其他两点等距，是顶点。 否则，如果`AB²`和`BC²`是平等的，`B`是顶点。 剩下的情况使得`C`顶点。 
4.让`A`是确定的顶点并且`B`,`C`是基本端点。 计算底边的中点为`M = ((Bx + Cx) / 2, (By + Cy) / 2)`。 

对称轴穿过顶点和中点，因为等腰三角形绕其底边的垂直平分线对称。 
5. 构造从底中点到顶点的方向向量：`v = A - M`。 

方向必须指向顶点，而不是远离顶点，因为问题是问三角形指向哪个方向。 
6. 使用`atan2(vy, vx)`获取距正 x 轴的带符号角度。 将其从弧度转换为度数。 
7. 如果角度为负，则加上`360`。 结果值位于所需的值中`[0, 360)`范围。 

### 为什么它有效

 等腰三角形的顶点正是通过等长边连接到其他两个顶点的顶点。 因此，比较三个平方边长可以唯一地识别每个有效的非等边输入的顶点。 一旦知道顶点和底边，底边的中点就位于底边的垂直平分线上，这也是三角形的对称轴。 因此，从中点到顶点的矢量恰好具有所请求的方向。 最后，`atan2`测量相对于正 x 轴的向量，并添加`360`to a negative result 将有符号表示转换为所需的正表示而不改变其方向。 

## Python 解决方案```python
Pythonimport sysimport math
input = sys.stdin.readline

def equal(a, b):    return math.isclose(a, b, rel_tol=1e-9, abs_tol=1e-9)

def solve():    points = [tuple(map(float, input().split())) for _ in range(3)]    A, B, C = points
    def dist2(P, Q):        dx = P[0] - Q[0]        dy = P[1] - Q[1]        return dx * dx + dy * dy
    ab = dist2(A, B)    ac = dist2(A, C)    bc = dist2(B, C)
    if equal(ab, ac):        apex = A        base1 = B        base2 = C    elif equal(ab, bc):        apex = B        base1 = A        base2 = C    else:        apex = C        base1 = A        base2 = B
    mid_x = (base1[0] + base2[0]) / 2.0    mid_y = (base1[1] + base2[1]) / 2.0
    vx = apex[0] - mid_x    vy = apex[1] - mid_y
    angle = math.degrees(math.atan2(vy, vx))
    if angle < 0:        angle += 360.0
    print(angle)

if __name__ == "__main__":    solve()
```这`dist2`函数计算欧氏距离平方。 由于在确定等边时只有相等才重要，因此求平方根会增加工作量而不增加信息。 

这`equal`帮助者使用`math.isclose`因为坐标被读取为浮点值。 直接比较例如`ab == ac`当数学上相等的量获得略有不同的浮点表示时，可能会失败。 

这三个比较编码了三个可能的顶点。 如果`AB = AC`，双方发生事件`A`是平等的。 如果`AB = BC`，两条相等的边相交于`B`。 如果两个条件都不成立，则相等的双方必须在`C`。 

在构造方向向量之前计算中点。 减法顺序是经过深思熟虑的：`apex - midpoint`从底边中心到三角形尖端的点。 反转减法将使答案精确旋转`180`度。`atan2`处理所有四个象限，包括普通向量的垂直向量`atan(y / x)`将除以零。 其结果以弧度和间隔为单位`[-180, 180]`转换为度数后。 添加`360`仅当值为负时才将其映射到所需的正范围。 

Python 整数不会溢出，但坐标无论如何都是浮点值，因此所有几何计算自然都使用 Python 的浮点表示。

 ## 边缘情况

 对于水平零度的情况，```
0 00 21 1
```相等的边相遇于`(1, 1)`。 基准中点为`(0, 1)`，所以方向向量是`(1, 0)`。`atan2(0, 1)`回报`0`，算法打印`0.0`。 零本身不需要特殊情况，因为归一化仅改变负角度。 

对于向下的方向，```
0 02 01 -1
```相等的边相遇于`(1, -1)`。 基准中点为`(1, 0)`, 生产`(0, -1)`。`atan2(-1, 0)`给出`-90`度。 该算法添加`360`, 生产`270.0`。 这是最有可能暴露忘记所需正角度范围的实现的边界情况。 

对于任意排序的情况，```
-1 0-2 20 1
```平等双方仍会面于`(-2, 2)`，即使该点位于输入的中间。 距离的平方`(-2, 2)`另外两点都是`5`，因此第二次比较将其识别为顶点。 得到的向量是`(-1.5, 1.5)`, 给予`135.0`。 

对于垂直方向，```
-1 01 00 2
```基中点是`(0, 0)`顶点是`(0, 2)`。 方向向量为`(0, 2)`， 所以`atan2`回报`90.0`。 这也说明了为什么`atan2`优于手动计算`atan(vy / vx)`，因为 x 分量恰好为零。 

对于朝左的方向，```
0 00 2-1 1
```基中点是`(0, 1)`顶点是`(-1, 1)`。 方向向量为`(-1, 0)`，准确给出`180.0`。 该算法保持该值不变，因为它已经在所需的范围内。
