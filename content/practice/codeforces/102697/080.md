 ## 解决方案
 ## 问题理解

 任务是逐个字符翻译成 leet 语言的基本形式。 输入是一个包含任意文本的字符串。 对于每个具有指定 leet 替换的小写字母，我们替换相应的数字。 转换表中不存在的所有其他字符（包括空格、标点符号、数字和字母）保持不变。 

所需的转换是`a -> 4`,`b -> 8`,`e -> 3`,`i -> 1`,`l -> 1`,`o -> 0`,`s -> 5`,`t -> 7`， 和`z -> 2`。 例如，这个词`test`变成`7357`， 因为`t`,`e`,`s`， 和`t`均独立翻译。 

输入包含单个字符串，因此没有测试用例计数，也不需要除了读取一整行之外进行任何解析。 官方给出了1秒的时间限制和256MB的内存。 由于输入可以被视为一个长度的字符串`n`， 一个`O(n)`解决方案是自然的目标。 即使语句中没有有用的明确最大长度，读取和处理每个字符一次也是最佳选择，因为每个字符都可能影响输出。 

在一些小情况下，实现可能会默默地出错。 考虑输入`a`。 正确的输出是`4`。 仅处理出现在例句中的字符的实现可能会意外地使其保持不变。 

对于输入`all`，正确的输出是`411`。 两次出现`l`必须成为`1`，并且两次替换是独立发生的。 

对于输入`hello!`，正确的输出是`h3110!`。 感叹号必须保持不变。 如果不小心实现重建单词而不是处理原始字符，可能会意外丢失空格或标点符号。 

对于输入`123`，正确的输出是`123`。 现有数字不会再次翻译。 特别是，`1`输入与规则无关`i -> 1`，因为该规则适用于字母`i`, 不为数字`1`。 

## 方法

 直接的暴力实现可以检查每个输入字符，并且对于每个字符，将其与所有九个源字母进行比较，直到找到匹配项。 这是正确的，因为每个字符都根据完整的转换表进行测试，并且不匹配的字符将被原封不动地复制。 在最坏的情况下，如果输入有长度`n`，这执行到`9n`人物比较。 为了`n = 100000`，也就是最多900000次比较，这里仍然可以轻松通过，但重复搜索是不必要的。 

关键的观察是转换规则是从一个字符到一个字符的固定映射。 相邻字符之间没有依赖性，不需要记住先前的输入，也不需要改变字符串长度的转换。 我们可以将九个替换存储在字典中并执行平均`O(1)`查找每个输入字符。 

暴力破解之所以有效，是因为转换表很小，但它会重复搜索永远不会改变的信息。 每个字符都有一个独立的固定替换的观察结果使我们可以将每个字符的工作减少到一次字典查找。 因此，完整的平移与输入长度呈线性关系。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(9n) = O(n) | O(9n) = O(n) | O(1) | O(1) | 已接受，但不必要的工作 |
 | 最佳| O(n) | 输出 | O(n) 已接受 |

 ## 算法演练

 1. 读取完整的输入行，不删除内部空格。 应删除标准输入添加的换行符，但文本内的空格是字符串的一部分，必须保留在输出中。 
2. 创建包含九个指定字母到数字转换的映射。 字典是一种自然的表示形式，因为当前输入的字符直接标识查找键。 
3. 只访问输入字符串中的每个字符一次。 如果映射中存在该字符，则将其替换附加到输出中。 否则附加原始字符。 
4. 打印构建的输出字符串。 由于每个输入字符恰好贡献一个输出字符，因此输出的长度与输入的长度相同。 

### 为什么它有效

 不变量是在处理完第一个之后`k`输入字符，输出完全包含这些相同字符的正确 leet 翻译`k`人物。 最初，没有处理任何字符，因此不变量不成立。 当处理下一个字符时，算法如果存在指定的替换，则使用指定的替换，否则复制该字符不变，这正是所需的翻译规则。 因此，在每个字符之后，不变量仍然为真，并且在最后一个字符之后，完整的输出是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().rstrip('\n')

    mapping = {
        'a': '4',
        'b': '8',
        'e': '3',
        'i': '1',
        'l': '1',
        'o': '0',
        's': '5',
        't': '7',
        'z': '2',
    }

    result = ''.join(mapping.get(ch, ch) for ch in s)
    print(result)

if __name__ == "__main__":
    solve()
```第一行`solve`读出整个句子。 使用`rstrip('\n')`仅删除行终止符，而不是调用`strip()`，这可以从输入的开头或结尾删除有意义的空格。 

该词典准确地包含了该问题的九个规则。 这`get`call 很有用，因为当字符不是九个键之一时，它会提供原始字符作为默认字符。 

生成器从左到右处理字符，并为每个输入字符生成一个输出字符。`''.join(...)`有效地将它们组合成最终字符串，而不是在循环内重复连接字符串。 

没有索引计算或明确的边界，因此不存在相差一的问题。 Python 整数与计算无关，因为替换是作为字符而不是数字算术处理的。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个输入字符都被处理一次，并且对于这个固定映射来说字典查找是恒定的时间。 |
 | 空间| O(n) | 翻译后的字符串对于每个输入字符都包含一个输出字符。 |

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    s = input().rstrip('\n')

    mapping = {
        'a': '4',
        'b': '8',
        'e': '3',
        'i': '1',
        'l': '1',
        'o': '0',
        's': '5',
        't': '7',
        'z': '2',
    }

    return ''.join(mapping.get(ch, ch) for ch in s)

def run(inp: str) -> str:
    old_stdin = sys.stdin
    try:
        sys.stdin = io.StringIO(inp)
        return solve() + '\n'
    finally:
        sys.stdin = old_stdin

# Provided sample
assert run("this is a test input\n") == "7h15 15 4 7357 1npu7\n", "sample 1"

# Minimum-size input
assert run("a\n") == "4\n", "single replaceable character"

# All characters that have replacements
assert run("abeilos tz\n") == "4831105 72\n", "all mappings"

# Characters that must remain unchanged
assert run("123! XYZ\n") == "123! XYZ\n", "non-mapped characters"

# Repeated mappings and punctuation
assert run("all!!!\n") == "411!!!\n", "repeated l and punctuation"

# Large input
large_input = "a" * 100000 + "\n"
assert run(large_input) == "4" * 100000 + "\n", "large input"

 ## 边缘情况

 对于单字符输入，例如`a`，该算法执行一次字典查找，找到`4`，并产生`4`。 对于长度一没有特殊处理，这很有用，因为它意味着通用循环已经正确覆盖了最小情况。 

对于重复更换，请考虑`all`。 第一个`a`变成`4`，以及两者`l`人物独立成为`1`, 给予`411`。 该算法从不将连续的相等字符视为一个单元，因此不会丢失任何出现的字符。 

对于映射之外的字符，请考虑`123!`。 这些字符都不是字典键，因此每次查找都会回溯到原始字符。 结果依然`123!`。 这也可以防止现有数字，例如`1`由于另一个规则碰巧产生数字而被意外转换`1`。 

对于空格和标点符号，请考虑`hello! world`。 翻译字母的同时复制空格和感叹号。 使用`rstrip('\n')`而不是`strip()`保留实际的文本内容，并且逐个字符的转换永远不会修改输入中间的空格。 

对于较大的输入，算法仍然对每个字符执行一次翻译尝试。 一串100000`a`因此，字符需要 100000 次字典查找并生成 100000`4`字符，没有嵌套搜索或重复的字符串重建。
