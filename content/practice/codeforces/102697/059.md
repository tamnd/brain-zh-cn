 ## 解决方案
 ## 问题理解

 我们得到一个小写字符串。 大多数字符应保持原样，但三个字符具有特殊的多重性。 每一个`c`必须在输出中出现两次，每次`h`必须出现五次，并且每次`z`必须出现十二次。 任何其他字符都会出现一次。 字符的顺序不变，因此每个输入字符都会独立转换，并且其副本保持在一起。 

例如，`c`在`schizophrenia`变成`cc`， 这`h`变成`hhhhh`，以及`z`成为连续十二个`z`人物。 所需的输出只是转换后的字符串。 

原始问题没有发布输入长度的明确上限。 时间限制为 1 秒，内存限制为 256 MB。 由于输出可能比输入长十二倍，因此任何可接受的解决方案都必须在生成输出的大小上至少花费线性时间。 处理每个输入字符一次并在缓冲区中构建结果的算法是自然目标，长度为 n 的输入需要 O(n) 时间，输出需要 O(n) 额外空间。 

有几个小案例可能会暴露粗心的实现。 如果输入不包含特殊字符，例如`abc`，输出也必须是`abc`。 假设每个字符都有替换计数的解决方案可能会意外更改普通字母。 

如果输入是`c`，正确的输出是`cc`。 将所述数量视为附加副本数而不是总副本数将产生`ccc`。 

如果输入是`h`，正确的输出是`hhhhh`，如果输入是`z`，正确的输出是十二`z`人物。 一个常见的边界错误是使用以乘数本身结尾的范围，从而减少生成一个副本。 

特殊字符也可以连续出现。 用于输入`chz`，输出是`cchhhhhzzzzzzzzzzzz`。 每个字符必须独立扩展，不能改变它们的顺序。 

## 方法

 一种简单的实现方式是扫描字符串并一次构建一个字符的答案。 对于每个输入字符，它确定其乘数并将该字符附加到所需的次数。 这个逻辑是直接正确的，因为一个位置的变换不依赖于任何其他位置。 

当使用不可变字符串重复扩展答案时，就会出现微妙的性能问题。 如果当前结果的长度为 k，则附加另一个字符可能需要复制现有的 k 个字符。 对于 n 个输入字符，在最坏的情况下，重复串联可以复制大约 1 + 2 + 3 + ... + n 个字符，即 O(n²)。 确切的常数取决于Python的实现和特殊字符的分布，但二次增长是问题所在。 

关键的观察结果是角色之间没有互动。 我们可以将转换后的片段收集到一个列表中，并在最后将它们加入一次。 每个输入字符贡献固定数量的副本，最大乘数仅为 12。产生的总长度最多为 12n，因此构建所有片段并连接它们需要 O(n) 时间。 

暴力破解之所以有效，是因为每个字符都有独立的替换规则，但当字符串连接重复复制已构建的前缀时，暴力破解可能会失败。 观察到最终的字符串只是一系列独立的转换片段，让我们首先存储这些片段并执行一个最终连接。

 ## 算法演练

 1. 读取单个输入字符串并删除尾随换行符。 只有一个测试用例，因此不需要测试用例计数器。 
2. 创建一个空列表，用于保存每个输入字符的转换版本。 使用列表是因为附加到列表不会重复复制整个结果。 
3. 从左到右处理输入。 如果当前字符是`c`, 追加`c * 2`。 如果是的话`h`, 追加`h * 5`。 如果是的话`z`, 追加`z * 12`。 对于每个其他小写字符，附加该字符本身。 
4. 将所有存储的片段连接成一个字符串并打印它。 这些片段已经以与其对应的输入字符完全相同的顺序出现，因此将它们连接起来可以保留所需的顺序。 

### 为什么它有效

 处理前 i 个输入字符后，列表将按其原始顺序准确包含这 i 个字符所需的输出。 这是整个扫描过程中保持的不变量。 当处理下一个字符时，算法会精确地添加为该字符规定的副本数量，因此不变量仍然为真。 在最后一个字符之后，列表表示完整的转换后的字符串，连接其元素不能改变它们的顺序或内容。 因此打印的字符串正是所需的输出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()

result = []

for ch in s:
    if ch == 'c':
        result.append(ch * 2)
    elif ch == 'h':
        result.append(ch * 5)
    elif ch == 'z':
        result.append(ch * 12)
    else:
        result.append(ch)

print(''.join(result))
```输入被读取`input()`和`strip()`删除标准输入添加的换行符。 字符串本身仅包含小写字符，因此检查三种特殊情况就足够了。 

该循环遵循算法中从左到右的处理。 Python的字符串重复，比如`ch * 12`，正好创建 12 个副本，因此无需手动循环，也不会出现重复次数相差一错误的风险。 

转换后的片段存储在`result`。 决赛`''.join(result)`故意只执行一次。 反复书写`answer += piece`可以重复复制现有答案，而`join`使用已知的片段集合分配最终字符串。 

Python 整数在这里不会溢出，因为数值不依赖于输入大小。 唯一的乘数是 2、5 和 12。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline
    s = input().strip()

    result = []
    for ch in s:
        if ch == 'c':
            result.append(ch * 2)
        elif ch == 'h':
            result.append(ch * 5)
        elif ch == 'z':
            result.append(ch * 12)
        else:
            result.append(ch)

    return ''.join(result)

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    try:
        return solve() + "\n"
    finally:
        sys.stdin = old_stdin

# provided sample
assert run("schizophrenia\n") == "scchhhhhizzzzzzzzzzzzophhhhhrenia\n", "sample 1"

# custom: minimum-size input
assert run("a\n") == "a\n", "ordinary single character"

# custom: each special character exactly once

    "hhhhhhhhhhhhhhh"
    "zzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzz"
    "\n"
), "repeated special characters"

# custom: only ordinary characters

 ## 边缘情况

 对于仅包含普通字符的输入，例如`a`，循环到达最后`else`分支并精确追加一个`a`。 输出是`a`。 在这种情况下，使用默认乘数而不是乘数的解决方案将失败。 

对于输入`c`，算法选择乘数 2 并附加`c * 2`，生产`cc`。 除了这两个字符之外没有额外的副本，因此乘数被解释为出现的总数。 

对于输入`h`，算法附加`h * 5`, 给予`hhhhh`。 Python 的重复运算符直接处理精确计数，避免了循环边界，例如`range(5)`不小心被写成`range(4)`。 

对于输入`z`，算法附加`z * 12`, 给予`zzzzzzzzzzzz`。 这是问题中最大的扩展因子，因此它也代表了固定输入长度的最大输出增长。 

对于连续的特殊字符，输入`chz`被处理为三个独立的位置。 第一个产生`cc`，第二个产生`hhhhh`，第三个产生十二个`z`人物。 该列表按确切的顺序包含这三个部分，最终的连接产生`cchhhhhzzzzzzzzzzzz`。 任何角色都不能影响另一个角色的乘数或位置。 

对于没有特殊字符的输入，例如`abc`，每次迭代都使用普通字符分支。 结果列表变为`["a", "b", "c"]`，加入它会产生`abc`，确认转换仅更改三个指定字符。
