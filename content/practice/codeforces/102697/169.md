 ## 解决方案
 ## 问题理解

 问题是来自 Codeforces Gym 101775 的游戏 **SOS**，问题 L。棋盘是一排 (N) 个空单元格。 熊猫首先移动，玩家轮流选择一个空单元格并写入`S`或者`O`进入其中。 移动创建三个连续单元格拼写的那一刻`SOS`，做出该举动的玩家获胜。 如果每个细胞都被填满而不产生`SOS`，结果是平局。 

输入最多包含(1000)个独立游戏，(N)最多为(1000)。 由于答案仅取决于 (N)，而不取决于实际的移动顺序，因此预期的解决方案应该基本上是每个测试用例的恒定时间。 任何探索博弈树的模拟都是没有希望的。 即使我们只计算完整的移动序列，也可能有 (2^N N!) 个，因为每次移动都会选择剩余的单元格之一和两个字母之一。 一旦理解了游戏的结构，两秒的限制甚至使得多项式模拟变得不必要。 

关键的边缘情况是非常小的电路板。 对于（N=3），熊猫无法强行获胜，因为熊猫只能先走一步，而羊总是可以阻止最后三个单元格成为`SOS`。 正确的结果是`Draw`。 例如，输入```
1
3
```产生```
Case #1: Draw
```一种粗心的方法，假设三个细胞就足以制造`SOS`会错误地宣布熊猫获胜，而忽略绵羊获得第二步。 

另一个边界出现在 (N=7)。 这里Panda可以强行获胜，而（N=6）仍然是平局。 因此```
1
6
```产生```
Case #1: Draw
```但```
1
7
```产生```
Case #1: Panda
```区别不仅仅是（N）的奇偶性。 董事会需要至少七个连续的可用职位才能使中央获胜结构发挥作用。 

(N=16) 处还有第二个不太明显的边界。 即使棋盘长度从 (8) 到 (14) 都是平局，但 (16) 是羊获胜。 因此```
1
14
```给出`Draw`， 然而```
1
16
```给出`Sheep`。 均匀棋盘上的第一步必须避免给对手带来获胜结构，最后（16）羊在熊猫的防御棋步之后终于有足够的空间来创建七格获胜区域。 

## 方法

 直接的解决方案将对整个游戏进行建模。 在每个位置，尝试每个空单元格和两个可能的字母，递归确定当前玩家是否可以强行获胜，当`SOS`出现。 这是正确的，因为每一个合法的举动都会被考虑，所以极小极大可以区分获胜、失败和平局。 问题在于树的大小。 没有剪枝的情况下，完整的播放序列的数量是（2^N N！）。 即使棋盘的记忆表示也最多具有 (3^N) 个状态，因为每个单元格都可以为空，`S`， 或者`O`。 对于 (N=1000)，这两种方法都不太可行。 

有用的观察是游戏有一个很小的局部获胜模式。 考虑表单中的四个连续单元格`S__S`，其中两个中间单元格为空。 在这个位置上，谁先动了，谁就输了。 如果该玩家写道`O`在任一空单元格中，对手写入`S`在另一个单元格中并获得`SOS`。 如果该玩家写道`S`在一个空单元格中，对手写道`O`在另一个并再次获得`SOS`。 因此`S__S`对于轮到的玩家来说是一个陷阱。 

接下来的问题是如何强制这个陷阱。 七个连续的空单元格就足够了。 放`S`在第四个牢房里。 无论对手在这七个单元格内移动，选择对面的端点并放置另一个端点`S`那里。 两者之间的两个单元格`S`字符保持为空，产生`S__S`。 如果对手在七单元区域之外进行比赛，则相同的构造甚至更容易，因为可以选择任一端点。 

这种七单元结构解释了奇怪的板结果。 在长度至少为 7 的奇数棋盘上，熊猫可以首先创建这样一个区域，并利用剩余动作的平价来迫使羊面对陷阱。 因此，每个奇数 (N\ge7) 都是熊猫获胜。 

对于偶数 (N)，Panda 不能安全地使用相同的获胜结构，因为奇偶性逆转了谁最终必须在陷阱中移动。 熊猫开始于`O`，将板分成两侧。 对于(N<16)，Panda可以选择该位置`O`这样两边的单元格都少于七个。 羊不能再创建七格强制区域，并且任何玩家都不能强制获胜，从而获得平局。 

在 (N=16) 时，Panda 无法再将棋盘分成两个都小于 7 的区域。 无论第一个在哪里`O`放置时，一侧至少包含七个单元。 绵羊可以使用相同的七单元结构来利用这一面。 同样的论点适用于每个更大的偶数 (N)，因此羊在所有偶数 (N\ge16) 中获胜。 这产生了完整的分类

 [
 \text{Panda 如果 }N\text{ 是奇数并且 }N\ge7，
 ]

 [
 \text{羊，如果 }N\text{ 是偶数且 }N\ge16，
 ]

 和`Draw`否则。 这种分类也是该问题的公认解决方案所使用的分类。

 ## 算法演练

 1. 阅读（N）。 实际的棋盘永远不需要建造，因为获胜者仅由棋盘的长度决定。 
2. 如果(N)为奇数且(N\ge7)，则输出`Panda`。 七个单元格区域让第一个玩家可以创建`S__S`陷阱，奇数奇偶性使陷阱对创建它的玩家有利。 
3. 否则，如果 (N) 为偶数且 (N\ge16)，则输出`Sheep`。 熊猫的第一次防御`O`无法将这种大小的板分成两个小于七个的区域，因此羊可以获得七个单元的区域并反转相同的结构。 
4. 对于(N)的每个剩余值，输出`Draw`。 这涵盖了每个（N \ le6），其中获胜的结构不适合，以及从（8）到（14）的每个偶数（N），其中Panda可以阻止任何一个玩家获得足够大的区域。 

分类起作用的原因是`S__S`不变的。 一旦球员被迫进入内线`S__S`，每一个可能的字母都会在对手的下一步行动中立即丢失。 尽管对手有一个动作，但七个连续的空单元格足以创建这种结构，这使得阈值为七。 然后棋盘的平价决定了哪位玩家可以迫使对手成为在陷阱中移动的人。 偶数情况需要 Panda 的第一个防御动作两侧都有足够的空间，从而在 16 处产生第二个阈值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for case in range(1, t + 1):
        n = int(input())

        if n >= 7 and n % 2 == 1:
            result = "Panda"
        elif n >= 16 and n % 2 == 0:
            result = "Sheep"
        else:
            result = "Draw"

        print(f"Case #{case}: {result}")

if __name__ == "__main__":
    solve()
```该解决方案首先读取游戏数量，然后独立处理每个棋盘。 第一个条件检查奇数获胜范围 (7,9,11,\ldots)。 第二个条件检查偶数获胜范围 (16,18,20,\ldots)。 任何一个条件都没有涵盖的每个值都是平局。 

条件的顺序在技术上并不危险，因为这两个范围是不相交的，但直接从数学分类中编写它们使得实现易于验证。 没有数组、递归或板模拟，因此没有需要管理的边界索引，也没有整数溢出问题。 Python 的整数类型对于输入范围来说绰绰有余。 

输出使用所需的`Case #x: result`格式，案例编号从 1 开始，与原始问题所指定的完全相同。 

## 工作示例

 对于样本 1，输入包含 (N=3)。 棋盘太短，无法容纳七格结构，因此两个玩家都无法强制游戏。 结果是平局。 

| 步骤| (N)| 状况 | 结果 |
 | ---| ---| ---| ---|
 | 1 | 3 | (N<7) |`Draw`|

 该迹线行使样本中最小的有意义的边界。 三个单元足以拼写`SOS`，但不足以让熊猫迫使绵羊做出失败的反应。 

对于样品 2，(N=7)。 Panda 可以使用整个板作为七单元区域。 熊猫先写`S`在中心。 无论羊做什么，熊猫都能写`S`在另一侧的端点处，留下一个`S__S`陷阱。 

| 步骤| (N)| 平价| 门槛| 结果 |
 | ---| ---| ---| ---| ---|
 | 1 | 7 | 奇数| (N\ge7) | (N\ge7) |`Panda`|

 例如，Panda 可以从```
___S___
```如果绵羊在左边某个地方玩耍，熊猫就在左边玩耍`S`在右端点。 如果绵羊在右侧某处玩耍，则熊猫在右侧玩耍`S`在左端点。 所得的四单元段具有以下形式`S__S`，所以羊不能安全地在两个空的牢房里玩耍。 七格区域的奇偶性使陷阱中正确的玩家能够移动，从而使 Panda 获胜。 这正是示例答案背后的结构。

 ## 边缘情况

 对于（N=1），棋盘仅包含一个单元格，因此不可能形成三个连续的字符。 该算法没有达到获胜条件并打印`Draw`。 

对于 (N=6)，电路板仍然太短，无法容纳七单元强制区域。 算法检查`n >= 7`，发现错误，并打印`Draw`。 这捕获了使用 (N>7) 而不是 (N\ge7) 或将 (N=6) 视为获胜位置的常见差一错误。 

对于 (N=7)，Panda 恰好获得了中心构建所需的七个单元格。 熊猫可以放置`S`在第四个单元格中，羊移动后，熊猫选择相反的端点来创建`S__S`。 因为该陷阱中的任何一个动作都可以让对手完成`SOS`，羊无法逃脱失败的局面。 因此该算法打印`Panda`。 

对于 (N=14)，棋盘是平的，但仍低于羊阈值。 熊猫可以从`O`位于合适的中心位置，以便其余部分太短，绵羊无法建立七格强迫结构。 结果是`Draw`。 

对于 (N=16)，该防御策略不再起作用。 无论 Panda 将初始位置放在哪里`O`，至少一侧有七个或更多单元格。 羊可以利用这样的区域来重现七格结构，因此第二个玩家强制获胜。 算法打印`Sheep`。 

对于 (N=1000)，棋盘是均匀的且远高于 16，所以答案也是`Sheep`。 没有进行模拟，这就是为什么大输入并不比（N=16）更难。
