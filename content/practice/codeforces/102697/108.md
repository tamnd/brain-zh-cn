 ## 解决方案
 ## 问题理解

 网格是一个长方形的大厅，里面有空的瓷砖和对角的镜子。 激光从立柱底部进入`x`并最初向上移动。 每当它到达空瓷砖时，就必须根据激光穿过该瓷砖的方向对该瓷砖进行标记。 垂直通道变成`|`，水平通道变为`-`，并且以两种方式遍历的图块变为`+`。 镜子瓷砖保持不变。 

镜子决定了新的方向。 为了`/`，向上的光束向右转，向右的光束向上，向下的光束向左转，向左的光束向下。 为了`\`，向上的梁向左转，向左的梁向上，向下的梁向右转，向右的梁向下。 

入口边缘有一个特殊之处。 如果光束在向下行进时到达最下面一排，则不会离开大厅。 它沿着底行左转。 这就是第二个样本形成循环的原因。 在其他三个边界处，到达网格之外的光束结束。 官方声明给出`n`,`m`，以及从零开始的起始列`x`，然后是网格，并要求绘制有激光路径的网格。 

当前的 Codeforces 语句指定了一秒限制和 256 MB 内存，但没有公开明确的数值范围`n`和`m`。 这使得与网格状态数量成比例的算法成为自然目标。 状态由一个单元和四个方向之一组成，因此只有`4nm`可能的状态。 即使隐藏尺寸很大，执行与网格大小成比例的工作的解决方案也是安全的，而重复扫描长行和列可能会导致网格尺寸呈二次方。 

一些边缘情况很容易被错误处理。 首先，起始瓦片本身属于激光路径。 例如，```
1 1 0
.
```产生```
|
```因为激光在从顶部离开之前只能垂直进入该瓷砖。 粗心的实现如果先移动一次然后才标记单元格，则会错误地将图块保留为`.`。 

其次，一块瓷砖可以在两个方向上交叉。 第一个样本在底行第 5 列包含这样的交集。正确的字符是`+`，而不是最后处理的方向。 一个粗心的实现，简单地赋值`|`或者`-`将失去两条路径之一。 

第三，底部边界的处理方式与其他三个边界不同。 在第二个示例中，光束在向下行进时最终到达底行，然后继续向左移动。 将每个边界视为出口会导致样本路径的整个后半部分消失。 

最后，镜子本身绝对不能更换。 如果光束进入镜面砖，则该砖仍然保留`/`或者`\`，并且只有方向改变。 用路径字符替换每个访问过的图块会破坏输入几何体。 

## 方法

 最直接的暴力模拟是保持当前的位置和方向，然后沿着该行或列搜索，直到找到下一个镜像。 找到镜子后，标记当前位置和镜子之间的每个空瓷砖并应用相应的反射。 这是正确的，因为当光束穿过空的瓷砖时，没有任何东西可以改变光束的方向。 

问题是通过扫描找到下一个镜子会重复大量的工作。 让`L = max(n, m)`。 最多有`4nm`不同的位置方向状态，并且扫描下一个障碍物可以检查最多`L`细胞。 因此，最坏情况下的电池检查量受以下限制：`4nmL`，即`O(nm max(n,m))`。 对于大网格，这个额外因素是不必要的。 

关键的观察是没有理由从一个镜子跳到另一个镜子。 穿过一个空单元格已经需要恒定的时间，并且每个单元格只能从四个可能的方向访问。 我们可以一次模拟一个细胞的光束并记住每一个`(row, column, direction)`已经发生的状态。 一旦状态重复，未来就被迫与之前的访问相同，因此路径进入了循环，并且不会出现新的输出字符。 

这将模拟转变为有限状态过程。 镜像规则提供从一种状态到下一种状态的转换，而访问状态数组则保证无限的反射循环不会使程序永远运行。

 | ---| ---| ---| ---|
 | 蛮力 |`O(nm max(n,m))`|`O(nm)`| 对于大型网格来说太慢 |
 | 最佳 |`O(nm)`|`O(nm)`| 已接受 |

 ## 算法演练

 1. 读取网格并为输出创建可变副本。 原始镜像字符必须保持不变，而空单元格可能会变成`|`,`-`， 或者`+`。 
2. 开始于`(n - 1, x)`有方向`up`。 起始图块位于网格内部，因此必须像其他图块一样对其进行处理。 
3. 在处理状态之前，检查是否`(row, column, direction)`已经被访问过。 如果有，请停止。 移动规则是确定性的，因此再次达到相同的状态意味着未来状态的完全相同的序列将重复。 
4. 如果当前单元格为空，则标记当前单元格。 垂直方向有贡献`|`，水平方向贡献`-`，如果单元格已包含其他路径字符，请将其更改为`+`。 镜像细胞保持不变。 
5. 如果当前单元格包含`/`，使用改变方向`/`反射规则。 如果它包含`\`，使用相应的`\`规则。 否则，继续朝同一方向移动。 
6、特别处理底部边界。 如果横梁位于底行并且向下行进，请将其向左转动而不是离开网格。 这是由问题的几何形状表示的入口侧反射。 
7. 对于每隔一次的移动，计算下一行和下一列。 如果下一个位置在网格之外，则光束已离开大厅，模拟结束。 否则，移至此处并从步骤 3 继续。 

### 为什么它有效

 不变量是在每次迭代之前，`(row, column, direction)`准确地描述了真实激光束的位置和方向，并且到目前为止穿过的每个空瓷砖都已经标记了光束穿过它的所有方向。 

对于空图块，光束不会改变方向，因此移动一个单元格完全等同于直接移动到下一个事件。 对于镜子，实现应用相应的反射规则，因此下一个状态也是准确的。 底部边界根据特殊入口行为进行处理，而所有其他出口则终止梁。 

如果一个状态重复，决定论意味着光束将从该点开始遵循相同的转变。 这样的循环不能添加任何新的单元或路径方向，因此停在那里可以保留完整的输出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, x = map(int, input().split())
    grid = [list(input().rstrip("\n")) for _ in range(n)]

    # Directions: 0 = up, 1 = right, 2 = down, 3 = left.
    dr = (-1, 0, 1, 0)
    dc = (0, 1, 0, -1)

    # Reflection tables.
    # '/'  : up->right, right->up, down->left, left->down
    # '\'  : up->left, left->up, down->right, right->down
    slash = (1, 0, 3, 2)
    backslash = (3, 2, 1, 0)

    seen = [[[False] * 4 for _ in range(m)] for _ in range(n)]

    r, c, d = n - 1, x, 0

    while True:
        if seen[r][c][d]:
            break
        seen[r][c][d] = True

        # Mark the empty cell according to the current direction.
        if grid[r][c] == '.':
            if d == 0 or d == 2:
                if grid[r][c] == '.':
                    grid[r][c] = '|'
            else:
                grid[r][c] = '-'
        elif grid[r][c] == '|':
            if d == 1 or d == 3:
                grid[r][c] = '+'
        elif grid[r][c] == '-':
            if d == 0 or d == 2:
                grid[r][c] = '+'

        # Mirrors change the direction.
        if grid[r][c] == '/':
            d = slash[d]
        elif grid[r][c] == '\\':
            d = backslash[d]

        # The bottom edge is the entrance edge. A downward beam
        # reaching it turns left instead of leaving the hall.
        if r == n - 1 and d == 2:
            d = 3
            continue

        nr = r + dr[d]
        nc = c + dc[d]

        # The other three boundaries are exits.
        if not (0 <= nr < n and 0 <= nc < m):
            break

        r, c = nr, nc

    sys.stdout.write("\n".join("".join(row) for row in grid))

if __name__ == "__main__":
    solve()
```方向数组以固定的顺时针顺序对四种可能的运动进行编码。 这使得镜像转换成为一个小型查找，而不是嵌套条件的集合。 

这`seen`数组对于每个单元方向对都有一个布尔值。 单独的单元不足以检测循环，因为从不同方向进入同一单元可能会导致不同的未来路径。 

标记代码区分三种情况。 先前未接触过的单元格得到`|`或者`-`。 已经包含相反路径字符的单元格变为`+`。 镜像角色永远不会被修改。 显式检查`|`和`-`是允许稍后的垂直通道正确转换交叉点的因素。 

底边检查发生在镜面反射之后。 这种顺序很重要，因为在边界规则相关之前，底排上的镜子本身可以重定向向下的光束。 一旦知道底部行的方向是向下的，将其更改为左侧并从同一单元格继续再现入口边缘行为。 

Python 中不存在整数溢出问题。 最大的辅助结构是`seen`数组，与每个网格单元的四个状态成比例。

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |`O(nm)`| 有`4nm`可能的细胞方向状态，并且每个状态需要恒定的时间 |
 | 空间|`O(nm)`| 网格和四向访问状态数组都与单元格数量成正比 |
