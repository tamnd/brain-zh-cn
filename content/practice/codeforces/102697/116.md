 ## 解决方案
 ## 问题理解

 当每个字符后面紧接着有一个不同的字符时，字符串被称为多样化。 换句话说，对于除最后一个位置之外的每个位置，该位置处的字符不得等于下一个位置处的字符。 

输入包含一个不带空格的字符串。 所需的输出是`YES`当字符串到处满足条件时，并且`NO`只要存在至少一对相等的相邻字符。 原问题有 1 秒的时间限制和 256 MB 的内存限制。 

该算法的关键约束是字符串的长度。 该语句没有给出有用的小上限，因此解决方案应随输入大小线性缩放。 对于大字符串，O(n²) 方法将变得不切实际，而 O(n) 扫描只需要检查每个字符恒定的次数。 

在一些小情况下，粗心的实施可能会失败。 用于输入`a`，正确的输出是`YES`，因为根本不存在相邻对。 假设总是有下一个字符的代码可以访问字符串之外。 

用于输入`aa`，正确的输出是`NO`。 第一个字符等于第二个字符，因此这是可能的最小反例。 在比较最后一个相邻对之前意外停止的循环可能会错误地打印`YES`。 

用于输入`aba`，正确的输出是`YES`。 第一对是`ab`第二个是`ba`，因此两对都包含不同的字符。 即使允许重复的非相邻字符，检查所有字符是否全局不同的实现也会错误地拒绝该字符串。 

用于输入`abb`，正确的输出是`NO`。 第一对有效，但最后一对`bb`不是。 这会捕获一个相差一的错误，其中仅检查最后两个位置之前开始的对。 

## 方法

 直接的暴力方法可以检查每一对位置`(i, j)`并测试它是否是相邻对，意思是`j = i + 1`。 如果这样的一对包含相同的字符，则答案是`NO`; 否则答案是`YES`。 这是正确的，因为每个可能无效的对都会被检查。 

问题是这个方法检查了所有`n(n-1)/2`成对，尽管只有`n-1`其中可能很重要。 在最坏的情况下，大约是`n²/2`配对检查。 对于长度为 100,000 的字符串，这大约是 4,999,950,000 次检查，远远超出了 1 秒限制的合理范围。 

条件的结构为我们提供了更小的搜索空间。 字符串是否多样化仅取决于相邻对，因此没有理由检查任何非相邻对。 我们可以简单地从左向右走，并将每个字符与其前面的字符进行比较。 

第一个相等的相邻对证明答案是`NO`，因此扫描可以立即停止。 如果遍历整个字符串而没有找到这样的一对，则每次所需的比较都成功，答案是`YES`。

 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取字符串。 少于两个字符的字符串会自动多样化，因为它不包含可能违反条件的相邻对。 
2. 从第二个字符开始，将其与其前一个字符进行比较。 这些正是需要检查的第一对相邻对。 
3. 如果两个字符相等，则打印`NO`并停止。 一个无效的相邻对足以取消整个字符串的资格。 
4. 对剩余的每个字符继续进行相同的比较。 每次迭代都会检查一个新的相邻对，因此每个相关对都会检查一次。 
5. 如果循环结束时没有找到相等的相邻字符，则打印`YES`。 此时，字符串中的每个相邻对都已被验证包含不同的字符。 

### 为什么它有效

 加工后位置`i`，每个相邻对结束于或之前`i`已检查并发现有效。 该不变量从第一对开始并被保留，因为每次迭代都会检查下一个相邻对。 如果存在相等的对，则包含该对的迭代将打印`NO`; 如果不存在这样的迭代，则每个相邻对都是不同的，这正是多样化字符串的定义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()

    for i in range(1, len(s)):
        if s[i] == s[i - 1]:
            print("NO")
            return

    print("YES")

if __name__ == "__main__":
    solve()
```循环从索引处开始`1`因为索引`0`前面没有字符。 对于每个`i`，表达式`s[i] == s[i - 1]`精确检查一对相邻的。 

找到平等后立即返回可以避免不必要的工作。 它在逻辑上也是安全的，因为一对无效对的存在完全决定了答案。 

循环条件`i < len(s)`由 Python 自然处理`range(1, len(s))`。 对于单字符字符串，这变为`range(1, 1)`，它是空的，因此程序正确打印`YES`。 

不需要辅助数组、集合或频率表。 该条件对于相邻字符来说是局部的，因此恒定的额外空间就足够了。

import io

def solve():
    s = input().strip()

    for i in range(1, len(s)):
        if s[i] == s[i - 1]:
            print("NO")
            return

    print("YES")

def run(inp: str) -> str:
    global input

    old_stdin = sys.stdin
    old_input = input

    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    try:
        from contextlib import redirect_stdout
        output = io.StringIO()
        with redirect_stdout(output):
            solve()
        return output.getvalue()
    finally:
        sys.stdin = old_stdin
        input = old_input

 ## 边缘情况

 对于单字符输入`a`，该算法不执行迭代，因为不存在相邻对。 已经进入决赛了`print("YES")`，这是正确的，因为条件是空洞地满足的。 

为了`aa`，循环开始于`i = 1`。 它比较`s[1]`，即`a`， 和`s[0]`， 还`a`，并立即打印`NO`。 这确认检测到第一个可能的相邻违规。 

为了`aba`，比较是`a`相对`b`， 其次是`b`相对`a`。 两者不同，因此扫描完成并打印`YES`。 重复的`a`位置 0 和 2 并不重要，因为这些位置不相邻。 

为了`abb`，第一个比较，`a`相对`b`，成功。 第二个比较，`b`相对`b`，失败，因此算法打印`NO`。 这专门验证了循环的上边界，因为包含了涉及最终字符的对。 

对于大的交替字符串，例如`abababab`，每次比较都成功。 该算法从不构造或检查不相关的对，因此其运行时间与字符串长度成正比。 如果最后的字符改为`bb`，算法仍然检查最终对并报告`NO`，展示线性行为和正确的边界处理。
