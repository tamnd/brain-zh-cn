 ## 解决方案
 ## 问题理解

 教室是一个由子房间组成的 (n \times n \times n) 立方体。 每个子房间包含一个学生的年龄，输入将年龄逐层给出为（n）个方格（n \times n）网格。 当两个子房间的三个坐标在每个维度最多相差一时，两个子房间是相邻的，但不包括子房间本身。 因此，内部子房间有 26 个邻居，而靠近面、边缘或角落的子房间则较少。 

当学生的年龄严格大于每个相邻子房间的年龄时，该学生就是领导者。 平等是不够的，因此两个年龄相同的学生无法成为领导者。 麻烦制造者必须满足相反的条件，必须有一个年龄至少相同的相邻学生，并且该学生的相邻分室中不得有领导者。 所需的输出只是满足这两个条件的子房间的数量。 

此问题的可用陈述并未公开 (n) 的数值上限，但时间限制为 1 秒，并且教室包含 (n^3) 个值。 单独读取输入已经需要 (\Omega(n^3)) 工作，因此预期的解决方案应该仅处理每个子房间恒定的次数。 (O(n^6)) 方法随着 (n) 的增长而变得不合适，而 (O(n^3)) 方法则与必须检查的输入量相匹配。 

第一个边缘案例是一间只有一个小房间的教室。 用于输入`1`其次是`7`，正确的输出是`0`。 唯一的学生没有相邻的子房间，因此他们比所有相邻的学生都大，并且是领导者。 如果不小心将“没有找到更大的邻居”视为学生不是领导者的证据，则会错误地计算该单元格。 

第二个边缘情况是平等。 对于输入```
2
4 4
4 4
5 5
5 5
```正确的输出是`8`。 每个学生至少有一个年龄相同或更大的邻居，所以没有人是领导者。 由于也没有任何领导者，所以八名学生中的每一位都满足了麻烦制造者的条件。 使用`>=`当测试一个单元格是否是领导者时，会错误地将一些同等值的单元格分类为领导者。 

第三种边缘情况是边界单元。 当 (n=2) 时，角点只有 7 个可能的相邻位置，而不是 26 个。```
2
1 0
0 0
0 0
0 0
```正确的输出是`0`。 Age-1 角是领导者，其他所有单元都与其相邻。 假设所有 26 个偏移都存在的解决方案可以访问立方体外部，或者意外地与不相关的单元进行比较。 

## 方法

 直接的强力解释可以比较每对子房间，确定这对子房间是否相邻，然后使用这些比较来找到领导者和麻烦制造者。 这是正确的，因为每个相关关系都是在两个子房间之间，因此最终会发现每个邻接关系。 然而，有 (n^3) 个子房间，在最坏的情况下检查所有对需要 (n^3 \cdot n^3 = n^6) 对检查。 即使在考虑这两个条件的额外工作之前，这也远远超出了 1 秒限制所能支持的范围。 

问题的结构为我们提供了一个更小的邻域来检查。 对于固定的子房间，每个可能的邻居都由从 (-1) 到 (1) 的三个坐标偏移来描述。 这样的偏移量只有 (3^3-1=26) 个，并且边界位置只是丢弃离开立方体的偏移量。 因此，无论 (n) 是多少，确定一个学生是否是领导者都需要恒定的时间。 

还有第二个重要的依赖关系。 一个学生是否是一个麻烦制造者，不仅取决于他自己的年龄，还取决于邻居的学生是否是一个领导者。 我们应该首先计算完整的领导者集。 一旦存储了该信息，第二次本地扫描就可以确定每个非领导者是否接触了领导者。 这将整个问题转化为两次遍历 (n^3) 个单元，每次最多考虑 26 个相邻单元。 

蛮力方法之所以有效，是因为它明确地发现了每个邻接，但失败了，因为它发现了许多永远不可能相邻的对。 通过观察邻接是固定半径的三维邻域，我们可以用每个单元的恒定量的局部工作来代替全对比较。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(n^6)) | (O(n^3)) | 太慢了 |
 | 最佳| (O(n^3)) | (O(n^3)) | 已接受 |

 ## 算法演练

 1.将(n^3)个年龄读入三维数组`a[z][r][c]`。 保持坐标明确使得三维邻域测试变得简单，并且输入自然地以 (n) 个二维层的形式到达。 
2.分配一个三维布尔数组`leader`具有相同的尺寸。 最初，每个职位都被认为不是领导者。 
3. 对于每个位置`(z, r, c)`，检查每个偏移量`(dz, dr, dc)`每个偏移量属于`{-1, 0, 1}`并且三个偏移量不全为零。 如果生成的坐标离开立方体，则忽略偏移量。 这些正是有效的相邻子房间。 
4. 马克`(z, r, c)`如果其年龄严格大于每个有效邻居的年龄，则作为领导者。 边界位置的邻居较少，但相同的比较有效，因为仅检查有效坐标。 
5. 对每个位置进行第二次检查。 如果是领导者则跳过该职位，因为领导者无法满足第一个麻烦者条件。 
6. 对于每个剩余位置，再次检查其相同的 26 个可能的相邻偏移。 如果至少有一个有效邻居被标记为领导者，则该学生不是麻烦制造者。 如果没有找到相邻的领导者，则增加答案。 
7. 打印最终计数。 

为什么它有效：在第一次通过后，`leader[z][r][c]`当该学生的年龄严格大于每个相邻年龄时，这正是正确的。 在第二遍中，每个候选者都已知为非领导者，并且扫描准确地检查没有相邻小区是领导者的条件。 因此，当两个必需条件都满足时，细胞就会被精确计数，并且每个有效细胞都会被检查一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    a = []
    for _ in range(n):
        layer = []
        for _ in range(n):
            layer.append(list(map(int, input().split())))
        a.append(layer)

    leader = [
        [[False] * n for _ in range(n)]
        for _ in range(n)
    ]

    for z in range(n):
        for r in range(n):
            for c in range(n):
                age = a[z][r][c]
                is_leader = True

                for dz in (-1, 0, 1):
                    nz = z + dz
                    if nz < 0 or nz >= n:
                        continue

                    for dr in (-1, 0, 1):
                        nr = r + dr
                        if nr < 0 or nr >= n:
                            continue

                        for dc in (-1, 0, 1):
                            nc = c + dc
                            if nc < 0 or nc >= n:
                                continue

                            if dz == 0 and dr == 0 and dc == 0:
                                continue

                            if a[nz][nr][nc] >= age:
                                is_leader = False
                                break

                        if not is_leader:
                            break

                    if not is_leader:
                        break

                leader[z][r][c] = is_leader

    answer = 0

    for z in range(n):
        for r in range(n):
            for c in range(n):
                if leader[z][r][c]:
                    continue

                has_adjacent_leader = False

                for dz in (-1, 0, 1):
                    nz = z + dz
                    if nz < 0 or nz >= n:
                        continue

                    for dr in (-1, 0, 1):
                        nr = r + dr
                        if nr < 0 or nr >= n:
                            continue

                        for dc in (-1, 0, 1):
                            nc = c + dc
                            if nc < 0 or nc >= n:
                                continue

                            if dz == 0 and dr == 0 and dc == 0:
                                continue

                            if leader[nz][nr][nc]:
                                has_adjacent_leader = True
                                break

                        if has_adjacent_leader:
                            break

                    if has_adjacent_leader:
                        break

                if not has_adjacent_leader:
                    answer += 1

    print(answer)

if __name__ == "__main__":
    solve()
```输入循环构造`a`作为`a[z][r][c]`， 在哪里`z`是层，`r`是该层内的行，并且`c`是列。 该语句连续给出各层，因此不需要对输入进行转换。 

第一个三重循环实现了领导者传递。 比较使用`>=`， 不是`>`，因为学生必须比每个邻居严格年龄大。 找到一个具有相同或更大年龄的邻居足以拒绝领导者状态，因此嵌套循环可以提前终止。 

边界检查发生在访问之前`a[nz][nr][nc]`。 这使得同一组 26 个偏移可用于内部单元和边界单元，而无需面、边或角的特殊情况。 

第二个三重循环从拒绝每个领导者开始。 对于每个非领导者，它都会搜索相同的邻居，但这次它会读取预先计算的`leader`数组而不是比较年龄。 单个相邻领导者足以拒绝候选者，因此该传递也使用提前终止。 

Python整数不会溢出，答案最多是(n^3)。 主要内存成本是年龄数组加上每个单元格的一个布尔值。 使用`input = sys.stdin.readline`当教室包含许多整数时，避免不必要的开销。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | (O(n^3)) | 有 (n^3) 个单元，每个单元在两次遍历中最多检查 26 个邻居。 |
 | 空间| (O(n^3)) | 年龄数组和领导者数组各包含 (n^3) 个条目。 |

 常数因子很小，因为邻域最多包含 26 个单元。 由于输入本身包含 (n^3) 个年龄，因此 (O(n^3)) 算法对于此表示是渐近最优的。 语句源指定 1 秒时间限制和 256 MB 内存限制，因此避免 (O(n^6)) 全对方法是关键要求。

1

```没有有效的邻居偏移。 领导者扫描从未找到年龄至少为 7 岁的邻居，因此该单元仍然是领导者。 第二遍跳过领导者，产生`0`。 该算法不需要特殊情况，因为空邻域自然满足严格大于条件。

2
5 5

5 5
```对于每个单元格，至少有一个相邻单元格的年龄为 5。`neighbor >= age`因此拒绝对每个细胞进行领导。 领导者数组仅包含`False`，因此第二遍找不到相邻的领导者并计算所有八个单元格。 结果是`8`。

```年龄为 1 的单元格位于角落。 边界检查丢弃将离开立方体的偏移量，并且其七个真正邻居中的每一个的年龄均为 0，因此它成为领导者。 每个其他单元格都与该角相邻，并且已经是非领导者，因此每个单元格都未满足“无相邻领导者”条件。 答案是`0`。

最后，即使对于简单的边界情况，邻接的三维性质也很重要。 学生可以在紧邻其上方或下方的层中设置引线，包括在该层内的对角位置。 三个嵌套的偏移循环同时覆盖所有三个坐标的变化，因此垂直、水平和三维对角邻居由相同的逻辑处理。
