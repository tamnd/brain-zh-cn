 ## 解决方案
 ## 问题理解

 我们有几个可以写在霓虹灯上的候选字符串。 每个字符串包含小写英文字母和空格。 对于每个候选者，我们只关心其中出现哪些不同的字母。 空格不算作字母，相同字母重复出现仅算一次。 

所需的输出是包含最大数量的不同小写字母的候选者。 如果多个候选包含相同数量的不同字母，则必须打印输入中最早的一个。 原始语句给出了 1 秒的时间限制和 256 MB 的内存限制。 

关键的限制实际上是字母表的大小而不是大的数字界限。 仅有 26 个可能的小写字母。 我们可以检查每个字符一次并记录它的字母是否已经出现。 由于该语句没有公开字符串长度的有用上限，因此最安全的复杂性目标与输入字符总数呈线性关系。 当字符串很长时，每个字符串的二次扫描可能会变得太慢，而与输入大小成比例的方法适合一秒的限制。 

在一些小情况下，粗心的代码可能会选择错误的字符串。 例如，仅包含空格的字符串有零个不同的字母`3`其次是`abc`，仅包含空格的行，以及`ab`; 答案是`abc`，因为它具有三个不同的字母。 计算每个字符而不是每个不同字母的解决方案会错误地偏向于字符串，例如`aaaaaaaa`超过`abcdef`。 

空格也需要排除。 例如，使用输入`2`， 其次是`abc`和`a b`，两个字符串均包含三个不同的字母，因此第一个字符串必须保留答案，因为关系会指向最早的输入。 将空格视为另一个字符的粗心实现会错误地给出`a b`数到四。 

最后，关系不能取代当前的答案。 用于输入`3`和`abcde`,`edcba`， 和`abc`，前两个字符串都包含五个不同的字母，因此正确的输出是`abcde`。 每当计数大于或等于最佳计数时替换答案将错误地输出`edcba`。 

## 方法

 最直接的暴力方法是通过将每个字符与同一字符串中所有较早的字符进行比较来确定每个字符串的不同字母。 对于长度为 L 的字符串，在最坏的情况下可以执行大约 L(L−1)/2 个字符比较，从而给出 O(L 2 ) 时间。 在所有候选人中，最坏情况的工作是 Σ i ​ O(L i 2 ​ )。 该方法是正确的，因为当一个字符前面没有出现相同的字符时，该字符就被精确地计数，并且不需要重复比较。 

蛮力方法之所以有效，是因为它明确地回答了“这封信以前出现过吗？”的问题。 由于观察到只有 26 个可能的字母，我们可以直接存储该答案。 我们保留一个大小为 26 的布尔数组，索引为`ord(c) - ord('a')`。 当第一次遇到某个字母时，我们会对其进行标记并增加不同字母的计数。 后来的每一次发生都会花费恒定的时间并且不会改变计数。 

这将长度为 L 的字符串的功从二次变为线性。 然后，我们维护迄今为止看到的最佳字符串，并仅在新的不同字母计数严格更大时才替换它。 使用严格比较会自动保留最早的字符串。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(ΣL i 2 ​ ) | O(1) | O(1) | 对于长字符串来说太慢 |
 | 最佳 | O(ΣL i ​ ) | O(1) | O(1) | 已接受 |

 官方问题页面给出了三个示例案例，并确认空格是输入字符串的一部分，而目标则对不同的字母进行计数。 

## 算法演练

 1. 读取候选字符串的个数。 我们按输入顺序处理它们，因为平局打破规则取决于该顺序。 
2. 对于每个字符串，创建一个长度为 26 的布尔数组，最初全部为 false。 每个位置代表当前字符串中是否出现过一个小写字母。 
3. 逐个字符扫描字符串。 如果字符是空格，请忽略它，因为空格不是字母。 否则将字符转换为从 0 到 25 的索引。 
4. 如果该字母以前没有见过，则将其标记为已见过并增加当前的不同字母计数。 重复发生没有任何作用。 
5. 将当前计数与迄今为止找到的最佳计数进行比较。 仅当当前计数严格大于时才替换存储的答案。 平等必须保持旧答案不变，因为旧候选人出现得更早。 
6. 处理完所有字符串后，打印存储的候选值。 

### 为什么它有效

 对于每个已处理的字符串，布尔数组恰好包含该字符串中出现的小写字母集。 每个字母在第一次出现时都会为计数贡献 1，因此最终计数正是不同字母的数量。 全局最佳值仅针对严格更大的计数进行更新，这意味着它始终代表达到最大计数的所有字符串中最早的候选者。 因此，打印的字符串满足主要条件和打破平局条件。 

## Python 解决方案```python
Pythonimport sysinput = sys.stdin.readline

def solve():    n = int(input())
    best_string = ""    best_count = -1
    for _ in range(n):        s = input().rstrip("\n")
        seen = [False] * 26        count = 0
        for ch in s:            if ch == ' ':                continue
            idx = ord(ch) - ord('a')            if not seen[idx]:                seen[idx] = True                count += 1
        if count > best_count:            best_count = count            best_string = s
    print(best_string)

if __name__ == "__main__":    solve()
```输入被读取`readline`因此每个候选字符串内的空格都会被保留。 我们只删除尾随的换行符`rstrip("\n")`。 使用`strip()`还将删除前导和尾随空格，这会更改原始字符串并且是不必要的。 

这`seen`为每个候选者重新创建数组，因为每个字符串的独特性是独立测量的。 表达式`ord(ch) - ord('a')`地图`a`到 0 和`z`到 25，与 26 元素数组完全匹配。 

比较使用`>`而不是`>=`。 这是平局决胜规则的实现，改变它是错误答案的常见来源。 

Python 中不存在整数溢出问题。 无论如何，计数永远不会超过 26，因为只有 26 个小写字母。

 ## 边缘情况

 仅包含空格的候选项没有明显的字母。 例如，使用输入`2`其次是`   `和`a`，第一个候选者收到计数 0，第二个候选者收到计数 1，所以答案是`a`。 该算法会跳过每个空格并正确地将第一个计数保留为零。 

一个字母有许多重复副本的字符串不得因其长度而受到奖励。 用于输入`3`， 其次是`aaaaaaaa`,`bbbb`， 和`abc`，计数为 1、1 和 3，因此输出为`abc`。 布尔数组记录`a`无论发生多少次，都只发生一次。 

字母之间的空格也是无害的。 用于输入`2`， 其次是`a b c`和`abc`，两个候选者都包含恰好三个不同的字母。 第一个候选仍然是答案，因为更新条件严格大于，而不是大于或等于。 

最后，两个不同的字符串可以以不同的顺序包含完全相同的一组字母。 和`3`,`abcde`,`abc`， 和`edcba`，第一和第三个候选人都有五个不同的字母。 第三个候选永远不会取代第一个，因为它的计数相等而不是更大，给出了所需的输出`abcde`。
