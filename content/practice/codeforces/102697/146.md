 ## 解决方案
 ## 问题理解

 网格是一个 (n \times n) 的方板。 有些细胞含有金，标记为`X`，其他所有单元格都是空的，标记为`.`。 从任何单元格开始，只允许水平或垂直移动，因此移动到相邻单元格只需花费一步。 禁止对角移动。 

对于每个空单元格，我们需要到最近的黄金单元格的曼哈顿距离。 如果该距离是从 1 到 9，则该单元格将替换为该数字。 如果最近的黄金距离为 10 或更远，则单元格保持不变`.`。 金细胞本身仍然存在`X`。 已发布的 Codeforces 声明并未指定 (n) 的明确上限，但时间限制为 1 秒，内存限制为 256 MB，因此工作量随单元数量呈二次方增长的算法是自然的目标。 

主要边缘情况是距离 10 处的截止。例如，```
2
X.
..
```有输出```
X1
21
```因为每个非金细胞最多距离金细胞两步。 一个粗心的实现使用了`distance <= 10`会错误地打印`10`当牢房恰好距离十步远时。 该声明要求牢房之间至少保持 10 步距离才能停留`.`。 

另一个容易犯的错误是将对角线移动视为一步。 例如，```
2
X.
..
```右下单元格的距离为 2，而不是 1，因为路径必须包含一次水平移动和一次垂直移动。 

当有许多金单元时，会出现第三种边缘情况。 例如，```
3
X..
...
..X
```中心单元与任一金单元的距离为 2。 独立于一个特定金细胞计算距离会给更靠近另一个金细胞的细胞带来错误的结果。 

## 方法

 直接方法将从每个单元格开始搜索，并在到达第一个金块时停止。 在最坏的情况下，从一个单元格进行广度优先搜索需要 (O(n^2)) 时间，并且对所有 (n^2) 个起始单元格重复该搜索会给出 (O(n^4)) 工作。 如果 (n=1000)，则约为 (10^{12}) 次单元格访问，远远超出一秒的限制。 该方法是正确的，因为 BFS 找到了从其起始单元开始的最短路径，但它对相邻起始单元重复了几乎所有相同的工作。 

有用的观察是所有金细胞都是相同的目的地。 不要问“这个单元格距离最近的黄金有多远？” 对于每个单元格，我们可以反转问题并从每个黄金单元格同时启动 BFS。 当 BFS 第一次到达某个单元时，它已经从最近的金源到达该单元，因为 BFS 按非递减距离顺序处理状态。 

这是标准的多源 BFS 模式。 我们把每一个`X`进入队列，距离为零。 他们的邻居接收距离一，然后下一层接收距离二，依此类推。 由于输出仅将小于 10 的距离与其他距离区分开来，因此没有理由将搜索扩展到距离 9 之外。此有界 BFS 到达的每个单元都可以直接写入，而每个未到达的单元都可以直接写入`.`保持不变。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(n^4)) | (O(n^2)) | 太慢了 |
 | 最佳 | (O(n^2)) | (O(n^2)) | 已接受 |

 ## 算法演练

 1. 读取网格并收集每个黄金单元格的坐标。 将所有这些坐标放入队列中并将它们的距离设置为零。 从所有黄金单元开始，让一个 BFS 表示到最近黄金单元的距离，而不是到任意一个黄金单元的距离。 
2. 维护一个初始化为未访问值的距离数组。 将每个金色单元标记为距离零。 单独的距离数组可以避免意外地将未访问的单元格与距离为零的单元格混淆。 
3. 重复从队列中删除下一个单元。 对于其四个有效邻居中的每一个，检查该邻居是否已被访问过。 如果没有，则为其分配当前距离加一并将其入队。 
4. 不要将新距离为 10 的单元格入队。输出永远不需要距离 10 或更大，因此停在那里可以减少不必要的工作，而无需更改任何所需的字符。 
5. BFS完成后，扫描原始网格。 保留每一个`X`不变。 对于距离为 1 到 9 的空单元格，将该距离输出为字符。 如果从未到达单元格，则输出`.`。 

工作原理：BFS 不变量是，每当一个单元从队列中删除时，其存储的距离就是从该单元到任何黄金源的最小可能距离。 最初这是正确的，因为每个金单元的距离都为零。 如果距离 (d) 处的单元发现未访问过的邻居，则可以在 (d+1) 步内从黄金单元到达该邻居。 任何较早到达它的替代路线都必须来自较早处理的 BFS 层，因此邻居不可能仍然未被访问。 因此，每个记录的距离都是真正的最近黄金距离。 超过距离 9 的单元格被故意忽略，而这些正是必须保留的单元格`.`。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n = int(input())
    grid = [input().strip() for _ in range(n)]

    # -1 means that the cell has not been reached.
    dist = [[-1] * n for _ in range(n)]
    q = deque()

    # Multi-source BFS: every gold cell is a source at distance 0.
    for r in range(n):
        row = grid[r]
        for c in range(n):
            if row[c] == 'X':
                dist[r][c] = 0
                q.append((r, c))

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while q:
        r, c = q.popleft()
        nd = dist[r][c] + 1

        if nd >= 10:
            continue

        for dr, dc in directions:
            nr = r + dr
            nc = c + dc

            if 0 <= nr < n and 0 <= nc < n and dist[nr][nc] == -1:
                dist[nr][nc] = nd
                q.append((nr, nc))

    answer = []

    for r in range(n):
        out = []
        for c in range(n):
            if grid[r][c] == 'X':
                out.append('X')
            elif 1 <= dist[r][c] < 10:
                out.append(str(dist[r][c]))
            else:
                out.append('.')
        answer.append(''.join(out))

    sys.stdout.write('\n'.join(answer))

if __name__ == "__main__":
    solve()
```第一次扫描会识别每个黄金单元并将其放入 BFS 队列中。 所有这些单元在搜索开始之前接收距离为零，这是与普通单源 BFS 的主要区别。 

BFS 商店`-1`对于未访问过的单元格。 由于金细胞的距离为零，因此该哨兵不能与合法距离混淆。 四个方向对准确地代表允许的水平和垂直移动。 

这`nd >= 10`检查是在扩展邻居之前故意执行的。 距离 9 处的单元仍可能发现距离 10 处的单元，但输出中不需要这些单元，因此搜索在距离 9 层停止。 严格的界限符合声明中“10岁以下”和“至少10岁”之间的区别。 

最终扫描使用原始网格，而不是将距离零视为通用输出值。 金细胞必须保留`X`，而只有小于 10 的正距离才会变成数字。 

Python整数不会溢出，最大存储距离仅为9。队列包含坐标对，因此其大小与某个黄金单元格九步内到达的单元格数量成正比。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | (O(n^2)) | 每个网格单元都会在 BFS 期间初始化、最多检查一次，并在输出构建期间处理一次。 |
 | 空间| (O(n^2)) | 距离矩阵和 BFS 队列都可以包含 (O(n^2)) 个单元的信息。 |

 已发布的问题给出了 1 秒的时间限制和 256 MB 的内存限制，但没有公开 (n) 的数值上限。 与 (O(n^4)) 重复搜索方法不同，该解决方案每个网格单元仅执行恒定量的工作，并且距离值上限为 9。

 对于确切的截止，请考虑```

X..........
...........

对于对角线移动，请考虑```
2
X.
..
```细胞`(1,1)`不能从对角线移动`(0,0)`。 它需要两次移动，比如向下然后向左，所以输出是```
X1
21
```BFS 中的四个方向转换正是这些合法动作的模型。 

对于几种黄金来源，请考虑```
3
X..
...
..X
```中心单元与两个金单元的距离均为 2。 细胞`(0,1)`和`(1,0)`距左上角黄金的距离为 1，而`(1,2)`和`(2,1)`与右下黄金的距离为 1。 由于两个黄金单元在队列中均以距离零开始，因此 BFS 同时扩展两个前沿，并为每个单元分配其真正的最小距离。 

最后，当一个单元距离每个金块至少十步时，有界 BFS 永远不会到达它。 它的距离依然存在`-1`，输出阶段将该状态转换回`.`，完全符合问题的要求。
