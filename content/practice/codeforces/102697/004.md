 ## 解决方案
 ## 问题理解

 该问题要求在已知边数的情况下求出多边形内角的总和。 对于每个测试用例，输入给出多边形边数，输出应该是具有那么多边的多边形的所有内角之和。 该问题来自基本的几何观察：向多边形添加一条额外的边，使角和正好增加 180 度。 

一个多边形与`n`边可以分为`n - 2`通过从一个顶点绘制对角线来绘制三角形。 由于每个三角形贡献 180 度，因此总角度和为`(n - 2) * 180`。 输入包含多个独立的测试用例，因此算法必须将此公式单独应用于每个多边形。 

约束很小，边数限制为 100。这意味着即使直接模拟也足够快，但预期的解决方案应该使用数学关系，而不是重复添加角度。 每个测试用例所需的工作量是恒定的，因此即使非常大量的测试用例也只需要测试用例数量的线性时间。 

主要的边缘情况来自于错误地使用公式。 一个常见的错误是将边数视为三角形的数量，而忘记了具有`n`双方只创造`n - 2`三角形。 

例如，如果输入是：```
1
3
```正确的输出是：```
180
```粗心的实施会成倍增加`n`除以 180 将输出 540，因为它忽略了三角形没有对角线且仅由一个三角形组成。 

另一种情况是四边形：```
1
4
```正确的输出是：```
360
```多边形被分成两个三角形，而不是四个，所以答案来自`(4 - 2) * 180`。 

## 方法

 蛮力方法是从一个角和为 180 度的三角形开始，并为每个附加边重复添加 180 度，直到达到所需的边数。 这种方法是正确的，因为每条新边都为三角测量贡献了一个额外的三角形。 对于一个多边形`n`双方，这执行`n - 2`补充。 

给定的界限`n <= 100`，这已经足够快了。 然而，它重复了可以压缩的工作。 如果我们以数学方式扩展加法，总和变为：`180 + 180 + ... + 180`恰好与`n - 2`术语，简单来说就是`(n - 2) * 180`。 

观察到每个多边形都可以精确地三角剖分`n - 2`三角形消除了迭代的需要。 该解决方案成为每个测试用例的单个乘法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个测试用例 O(n) | O(1) | O(1) | 已接受，但没有必要 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 每个测试用例独立地描述一个多边形。 
2. 对于每个多边形，读取边数`n`。 一个多边形与`n`边可以分为`n - 2`通过从一个顶点绘制对角线来绘制三角形。 每个三角形的内角和都是 180 度。 
3. 计算`(n - 2) * 180`并输出结果。 乘法直接表示三角形的数量乘以每个三角形的贡献。 

为什么它有效：

 该算法依赖于一个固定的几何属性：每个简单的多边形`n`边可以精确地分为`n - 2`三角形。 由于每个三角形内角的总和始终为 180 度，因此多边形的总内角和必须是三角形的数量乘以 180。该公式考虑了每个可能的有效多边形大小，因此不需要特殊的构造或模拟。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        ans.append(str((n - 2) * 180))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```程序首先读取`t`，要处理的多边形数量。 然后它独立处理每一面的计数。 

表达式`(n - 2) * 180`是整个数学解。 减法必须在乘法之前进行，因为多边形不代表`n`三角形，它代表`n - 2`三角形。 

由于最大边数很小，输出值很容易落在正常整数范围内。 Python 整数还消除了对溢出的任何担忧。

 ## 边缘情况

 对于三角形：```
1
3
```该算法计算`(3 - 2) * 180`，只留下一个三角形。 输出是`180`，这避免了将边数本身相乘的常见错误。 

对于四边形：```
1
4
```该算法计算`(4 - 2) * 180`，生产`360`。 一个四边形分成两个三角形，因此结果来自两个 180 度的贡献。 

对于允许的最大多边形：```
1
100
```该算法计算`(100 - 2) * 180 = 17640`。 无需额外处理即可应用相同的公式，这表明该实现不依赖于小多边形尺寸。
