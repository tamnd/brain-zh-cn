 ## 解决方案
 ## 问题理解

 该任务是直接的三维几何计算。 宇宙飞船有一个固定位置`(X, Y, Z)`，以及雷达报告`n`外星人的立场。 对于每个外星人，我们需要计算其与宇宙飞船的欧几里德距离，并按照外星人给出的顺序打印距离。 

对于一个外星人来说`(x, y, z)`，三个坐标差为`x - X`,`y - Y`， 和`z - Z`。 对它们进行平方可去除它们的符号，将三个平方差相加即可得到平方距离，开平方即可得到实际距离：`distance = sqrt((x-X)^2 + (y-Y)^2 + (z-Z)^2)`。 

官方声明指定了1秒的时间限制和256MB的内存。 它不公开坐标的数字上限或`n`在当前问题页面上，因此最安全的解释是将解决方案设计为与外星人数量线性扩展。 由于输出本身包含每个外星人的一个值，因此为每个外星人花费恒定工作的算法是渐近最优的。 二次算法将变得不可用，因为`n`增长，同时`O(n)`解决方案仅对每个输入点执行一次固定大小的计算。 Python 整数还避免了中间平方差的溢出，尽管正常的坐标边界将使溢出在具有足够宽整数类型的语言中不成问题。 

在一些小情况下，实现可能会默默地出错。 当外星人正好在飞船上时，答案一定是零。 例如，```
1 2 3
1
1 2 3
```产生```
0.0
```忘记平方根的粗心实现会打印`0`，它在数值上相等，但不遵循所需的十进制输出格式。 

负坐标差也必须正确平方。 例如，```
2 4 6
1
-2 -4 -6
```产生```
14.966629547095765
```在平方之前取绝对值会得到相同的结果，但仅使用差值的原始总和会错误地允许正坐标和负坐标取消。 

外星人的顺序很重要。 例如，```
0 0 0
2
3 0 0
0 4 0
```产生```
3.0
4.0
```在处理外星人之前对其进行排序的实现将改变所需的输出顺序。 

## 方法

 最直接的方法已经是最佳的方法。 对于每个外星人，计算三个坐标差，求平方，将三个值相加，取平方根，然后打印结果。 这是正确的，因为该公式正是三维空间中的欧几里得距离定义，因此每个外星人都可以独立于其他外星人进行处理。 

如果有`n`外星人，每个外星人需要 3 次减法、3 次乘法、2 次加法和 1 次平方根运算。 忽略输入和输出成本，即每个外星人九次固定算术运算，或`9n`对整个输入进行此类操作。 平方根的确切机器级成本取决于实现，但相对于`n`。 

更复杂的强力解释可能会尝试将每个外星人与其他每个点进行比较，搜索几何关系，或者反复重新计算距离。 这些在这里都没有用，因为请求的距离仅取决于宇宙飞船和当前的外星人。 外星人之间不存在任何需要被发现的相互作用。 

关键的观察结果是该问题是完全可分离的。 一旦知道了宇宙飞船的坐标，外星人的答案`i`可以在不了解外星人的情况下进行计算`j`。 这意味着无需维护动态编程状态、图形遍历、排序或几何数据结构。 我们只需对每个外星人执行一次恒定大小的公式。 

输出要求还给出了下限`Omega(n)`，因为程序必须产生`n`单独的答案。 最后，`O(n)`时间是渐近最优的。 因此，最佳解决方案是与暴力基线相同的简单计算，其关键区别在于没有引入不必要的成对工作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 当作为每个外星人的一次距离计算来实现时，O(n) | O(1) | O(1) | 已接受 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取飞船坐标`X`,`Y`， 和`Z`。 对于每次距离计算，这些坐标保持不变。 
2. 阅读`n`，检测到的外星人数量。 我们只需要为其中每一个输出值`n`职位。 
3. 对于每个外星人，读取其坐标`(x, y, z)`。 计算`dx = x - X`,`dy = y - Y`， 和`dz = z - Z`。 保留差异的签名是可以的，因为下一个操作将对它们进行平方。 
4. 计算`dx * dx + dy * dy + dz * dz`。 这是欧氏距离的平方，因此它避免了最终平方根之前的任何几何近似。 
5. 计算该总和的平方根并立即打印。 不需要存储以前的外星人或他们的距离，因为每个答案都是独立的。 
6. 对所有的重复计算`n`外星人，在输出中保留他们的输入顺序。 

### 为什么它有效

 对于每一个外星人，算法都会准确计算出外星人与宇宙飞船之间的三个坐标差。 将这些差值平方并相加就可以得到欧几里德距离的平方，而开平方就可以得到欧几里德距离本身。 由于计算是对每个外星人独立执行的，并且外星人是按输入顺序处理的，因此每个打印值都是所需位置处所需的距离。 来自其他外星人的信息不会影响结果，因此独立处理点不会错过条件或产生不同的有效解释。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    X, Y, Z = map(int, input().split())
    n = int(input())

    out = []

    for _ in range(n):
        x, y, z = map(int, input().split())

        dx = x - X
        dy = y - Y
        dz = z - Z

        distance = math.sqrt(dx * dx + dy * dy + dz * dz)
        out.append(str(distance))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```第一个输入行被存储一次，因为宇宙飞船永远不会移动。 下一行给出了所需的迭代次数。 

对于每个外星人，代码分别计算三个差异。 这使得公式易于验证，并避免意外地将宇宙飞船坐标与外星坐标混合。 

里面的表情`math.sqrt`是整数平方距离。 Python 的任意精度整数使得中间计算安全，即使坐标大于固定宽度 C++ 的范围`int`。`math.sqrt`然后将非负值转换为浮点距离。 

答案已累积在`out`并写在一起。 这避免了为每个外星人进行单独的系统调用，这在以下情况下是更好的：`n`很大。 除了输出字符串之外，计算本身仅使用恒定量的工作内存。 

没有舍入代码，因为该语句明确表示不需要舍入。 Python 的浮点转换产生法官所期望的通常的十进制表示形式。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个外星人都需要恒定数量的算术运算和一个平方根。 |
 | 空间| O(n) | 该实现存储了`n`在写入字符串之前输出它们。 |

 该算法仅对每个检测到的外星人执行一次固定大小的计算，因此其运行时间随输入大小线性增长。 由于输出本身有`n`线，线性时间是渐近最优的。 数学工作状态为`O(1)`，并且实现使用`O(n)`内存只是因为它批处理输出。 如果内存极其有限，则可以立即打印每个答案，从而将辅助内存减少到`O(1)`。

    for _ in range(n):
        x, y, z = map(int, input().split())

        dx = x - X

## 边缘情况

 当外星人和飞船占据同一点时，输入```
1 2 3
1
1 2 3
```给出`dx = 0`,`dy = 0`， 和`dz = 0`。 距离的平方为`0`， 所以`math.sqrt(0)`产生`0.0`。 不需要特殊的分支，输出就是准确的```
0.0
```负坐标直接通过减法和平方处理。 为了```
2 4 6
1
-2 -4 -6
```差异是`-4`,`-8`， 和`-12`。 他们的正方形是`16`,`64`， 和`144`，给出平方距离`224`。 平方根是`14.966629547095765`，所以算法产生```
14.966629547095765
```一维或二维的零差异也是自然处理的。 为了```
10 20 30
1
-5 20 30
```差异是`-15`,`0`， 和`0`。 距离的平方为`225`, 给予```
15.0
```这会捕获意外遗漏坐标或错误处理零差异的实现。 

最后，每个外星人都必须独立处理，同时保留输入顺序。 和```
0 0 0
3
3 0 0
0 4 0
0 0 5
```三个距离是`3.0`,`4.0`， 和`5.0`，所以输出是```
3.0
4.0
5.0
```该算法在读取外来数据的同一迭代中打印每个结果，因此不存在可以对答案重新排序的排序或索引步骤。
