 ## 解决方案
 ## 问题理解

 输入包含两个线性方程，每个方程都已以斜截形式编写，`y=mx+b`。 系数`m`是线的斜率，而`b`仅确定线与 y 轴相交的位置。 任务是判断两条线是否平行并打印`PARALLEL`如果是的话，或者`NOT PARALLEL`否则。 官方声明明确保证了系数`x`出现在之前`x`项，包括当系数为`1`。 

当两条非垂直线的斜率相等时，它们完全平行。 因此，对于方程`y=m1x+b1`和`y=m2x+b2`，我们需要比较的唯一值是`m1`相对`m2`。 拦截次数`b1`和`b2`不影响线条的方向。 

这个问题中没有隐藏大数组或图。 输入恰好由两个方程组成，因此无论系数有多大，计算量都是恒定的。 因此，一秒的时间限制对于 O(1) 算法来说绰绰有余。 当系数很大时，Python 整数还可以避免溢出。 

主要解析边缘情况是负斜率。 例如：```
y=-8x+3
y=-8x+1
```正确的输出是：```
PARALLEL
```粗心的解析器假设系数仅由正数组成，可能无法读取`-8`正确。 提取之前的子串时必须包含减号`x`。 

另一个边缘情况是斜率`1`:```
y=1x+5
y=1x-20
```正确的输出是：```
PARALLEL
```该声明特别允许`m=1`明确写为`1x`，因此解析器不能期望系数被省略。 

截距也可以为负数而不影响答案：```
y=7x-100
y=7x+200
```正确的输出是：```
PARALLEL
```比较完整方程而不是其斜率的解决方案会错误地拒绝这种情况。 不同的截距只是意味着两条平行线位于不同的位置。 

最后，方程可以具有非常大的系数。 例如：```
y=1000000000000000000x+7
y=1000000000000000000x-9
```答案依然是`PARALLEL`。 不需要浮点运算，因此不存在精度问题。 

## 方法

 字面上的蛮力方法会尝试通过检查两条线上的点来确定两条线是否具有相同的方向。 例如，可以选择多个值`x`,计算对应的`y`两条线上的值，并尝试推断两个图形是否保持恒定的垂直距离。 问题是一条线包含无限多个点，因此文字搜索没有有限的最坏情况操作计数。 即使我们在某个固定数量的 x 值之后任意停止，也不能构成直线平行的数学证明。 

蛮力的想法失败了，因为它正在检查斜率的后果而不是斜率本身。 这些方程已经直接给出了精确的斜率。 在`y=mx+b`,`m`是线的方向，平行线的方向完全相同。 观察结果将整个问题简化为提取之前的系数`x`从每个方程并比较这两个整数。 

由于只有两个输入字符串，因此解析工作与这些字符串的长度成正比。 如果输入字符串有长度`L`，运行时间为 O(L)，对于该问题来说它实际上是常数。 该算法除了两个输入字符串之外还使用 O(1) 的额外空间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 无界| O(1) | O(1) | 太慢/不是有限算法 |
 | 最佳 | O(L)，其中 L 是输入长度 | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将两个方程作为字符串读取。 我们将它们保留为字符串，因为输入被格式化为方程，例如`y=-8x+3`，而不是作为空格分隔的整数序列。 
2.找到角色的位置`x`在每个方程中。 最初之间的一切`y=`和`x`是坡度。 
3. 将提取的子字符串转换为整数。 蟒蛇的`int`正确处理正系数和负系数，因此诸如`17`和`-8`成为相应的整数斜率。 
4. 比较两个斜率。 如果它们相等，则两个方程描述的线方向相同，因此打印`PARALLEL`。 否则，打印`NOT PARALLEL`。 

### 为什么它有效

 对于写为的行`y=mx+b`, 系数`m`是它的斜率。 当斜率相等时，这种形式的两条直线完全平行。 该算法从两个方程中准确提取该系数并进行比较，而不对其进行修改或近似。 拦截被故意忽略，因为改变`b`垂直平移一条线但不改变其方向。 因此算法打印`PARALLEL`正是针对问题所需的情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def slope(equation):
    x_pos = equation.index('x')
    return int(equation[2:x_pos])

def main():
    line1 = input().strip()
    line2 = input().strip()

    m1 = slope(line1)
    m2 = slope(line2)

    if m1 == m2:
        print("PARALLEL")
    else:
        print("NOT PARALLEL")

if __name__ == "__main__":
    main()
```这`slope`函数搜索`x`，因为该语句保证了系数`x`出现在该字符之前。 前缀`y=`占据位置`0`和`1`， 所以`equation[2:x_pos]`恰好包含斜率。 

使用`int`而不是浮点转换是故意的。 给定格式的斜率表示为整数系数，并且整数比较是精确的。 没有理由在仅询问两个精确系数是否相等的问题中引入浮点舍入。 

比较发生在提取两个斜率之后。 截距永远不会被解析，因为它不会影响并行性。 这`.strip()`调用删除从标准输入读取的换行符，尽管子字符串提取在没有它的情况下也可以工作，因为换行符出现在`x`项，因此不会进入斜坡。

 ## 边缘情况

 对于负斜率，请考虑：```
y=-8x+3
y=-8x+1
```第一个`x`发生在之后`y=-8`，所以提取的子串是`-8`。 第二个方程产生相同的整数。 比较成功，输出为`PARALLEL`。 这会捕获意外丢弃减号的解析器。 

对于显式斜率`1`， 考虑：```
y=1x+5
y=1x-20
```之前的子串`x`是`1`在两个方程中。 该算法没有对系数进行特殊处理，因此它自然会产生`PARALLEL`。 这遵循输入格式，明确保留`1`前`x`。 

对于不同的截距，请考虑：```
y=7x-100
y=7x+200
```提取的斜率都是`7`。 该算法从不读取截距，因此它打印`PARALLEL`。 从几何角度来看，这两条线具有相同的方向并且相对于彼此偏移。 

对于非常大的系数，请考虑：```
y=1000000000000000000x+7
y=1000000000000000000x-9
```两个斜率子字符串都转换为相同的 Python 整数。 Python 整数具有任意精度，因此比较保持精确并且输出为`PARALLEL`。 该算法不执行乘法或除法，这也使实现比尝试推理数值溢出更简单。 

对于具有其他类似方程的不同斜率，请考虑：```
y=-1x+100
y=1x-100
```提取的值是`-1`和`1`。 由于它们不同，输出为`NOT PARALLEL`。 这证实了该算法比较带符号的斜率而不是仅仅比较其绝对值。
