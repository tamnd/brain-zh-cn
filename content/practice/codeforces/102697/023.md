 ## 解决方案
 ## 问题理解

 该问题描述了火箭发射，其中唯一的测量值是初始向上速度。 我们需要预测火箭在开始坠落之前达到的最大高度。 当火箭的速度为零时，火箭到达最高点，因此任务是使用给定的初速度和重力引起的恒定加速度来计算向上行驶的距离。 

输入包含一个浮点值，即火箭的初始速度（以米每秒为单位）。 输出应该是浮点数形式的最大高度（以米为单位）。 速度、加速度和距离之间的关系由运动学方程给出：$$V_f^2 = V_i^2 + 2ad$$在最高点，$V_f = 0$，重力给出$a = -9.8$。 求解高度可得出：$$d = \frac{V_i^2}{19.6}$$输入是单个双精度值，因此不需要处理大型数据结构或许多测试用例。 该算法只需要常数时间运算。 飞行模拟是不必要的，并且可能会引入精度问题，而直接公式给出了问题所期望的精确数学结果。 

主要的边缘情况来自正确处理浮点值。 起始速度为零的火箭应该产生零高度，因为它永远不会离开起始位置。 用于输入`0`，正确的输出是`0.0`，而始终假设向上运动的解决方案可能会产生不正确的正值。 

非常小的初始速度也很重要。 用于输入`0.1`，答案大约是`0.0005102040816326531`。 过早舍入或将输入转换为整数会错误地输出零。 

较大的速度仍应使用浮点运算来处理。 用于输入`100`，答案大约是`510.2040816326531`。 使用整数除法的粗心实现可能会丢失小数部分。 

## 方法

 强力方法是模拟火箭随时间的运动。 我们可以通过添加加速度和添加行驶距离来重复更新速度，直到速度达到零。 这最终将近似最大高度，但结果取决于所选的时间步长。 非常小的时间步长可以提高精度，同时增加迭代次数。 对于高速，可能需要数千或数百万个模拟步骤，并且浮点误差会累积。 

更好的方法来自于认识到问题已经给出了描述运动的精确方程。 最高点是最终速度为零的特定状态。 我们可以直接求解未知高度的方程，而不是重新创建飞行的每个时刻。 

蛮力方法之所以有效，是因为它遵循物理过程，但它失败了，因为连续运动没有自然数量的模拟步骤。 最终速度已知的观察结果让我们将整个问题简化为一个公式评估。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k)，其中 k 是模拟步骤数 | O(1) | O(1) | 太慢而且不精确|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取浮点数形式的火箭初速度。 
2. 将已知值代入运动方程。 由于最高点的最终速度为零，加速度为`-9.8`，方程变为：$$0 = V_i^2 - 19.6d$$重新排列给出：$$d = \frac{V_i^2}{19.6}$$1. 使用公式计算高度并打印结果。 

该计算直接模拟火箭停止向上运动的时刻。 无需跟踪发射和最高点之间的路径。 

### 为什么它有效

 该公式来自于恒定加速度下速度、加速度和位移之间的精确关系。 在上升过程中，重力是唯一的加速度，因此方程始终成立。 在最大高度，火箭的向上速度变为零。 替换该条件只留下一个未知数，即算法计算的高度。 由于数学模型与问题描述完全匹配，因此返回值是最大高度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    v = float(input())
    height = v * v / 19.6
    print(height)

if __name__ == "__main__":
    solve()
```该解决方案将速度读取为`float`因为输入不限于整数，并且输出需要小数精度。 

乘法`v * v`根据方程计算初始速度的平方。 除以`19.6`应用重新排列的运动学公式。 Python 浮点运算在这里就足够了，因为问题只需要正常的打印十进制表示。 

不存在边界索引或整数溢出问题，因为整个计算使用单个浮点值。

 这说明了火箭没有向上运动并且最大高度保持在起点的情况。

 ## 边缘情况

 对于零速度，输入为：```
0
```该算法计算`0 * 0 / 19.6`，这给出了`0.0`。 这正确地代表了火箭永远不会增加高度。 

对于非常小的速度，输入为：```
0.1
```该算法将值保留为浮点数，计算`0.01 / 19.6`，并返回大约`0.0005102040816326531`。 整数转换会错误地删除整个结果。 

对于较大的发射速度，输入为：```
100
```计算变为`10000 / 19.6`，大约产生`510.2040816326531`。 恒定时间公式避免了取决于火箭高度的任何循环计数，因此计算保持准确和快速。
