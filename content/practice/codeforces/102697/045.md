 ## 解决方案
 ## 问题理解

 该问题给出了三个物理量来描述落在 Omicron Persei VIII 行星上的物体。 第一个值是作用在人身上的重力 (F_g)，第二个值是人的质量 (M)，第三个值是物体下落的距离 (D)。 物体从静止开始，因此其初速度为零。 我们需要计算下降时间 (T)，然后将其与距离一起打印，两个数值均显示为小数点后一位。 原始问题指定 1 秒时间限制和 256 MB 内存限制。 

第一个方程直接给出重力加速度：

 [
 F_g = MG
 ]

 所以

 [
 G = \frac{F_g}{M}。 
]

 第二个方程描述了物体的位移：

 [
 D = V_iT + \frac12GT^2。 
]

 因为对象从静止状态释放，(V_i=0)。 方程变为

 [
 D = \frac12GT^2。 
]

 求解正时间给出

 [
 T = \sqrt{\frac{2D}{G}}。 
]

 代入 (G=F_g/M) 给出最方便的实现形式：

 [
 T = \sqrt{\frac{2DM}{F_g}}。 
]

 已发布的声明中没有明确的 (F_g)、(M) 或 (D) 数值范围。 这意味着这里不存在有意义的输入大小复杂性问题。 该算法执行固定数量的算术运算和一个平方根，因此很容易满足一秒的限制。 

一个微妙的边缘情况是初始速度必须被视为零。 例如，使用输入```
500
70
10
```正确的输出是```
It will take the object 1.7 seconds to fall 10.0 meters
```因为物体是从静止开始的。 将未指定的 (V_i) 保留为非零值的粗心实现将解决不同的物理情况。 这也是问题提供的样本。 

另一个常见错误是仅格式化计算出的时间。 用于输入```
100
50
5
```我们有 (G=2) 和 (T=\sqrt{5}\approx2.236)，所以所需的输出是```
It will take the object 2.2 seconds to fall 5.0 meters
```距离本身也必须在小数点后打印一位数字。 印刷`5`而不是`5.0`与所需的格式不匹配。 

第三种边缘情况是距离已经非常小。 例如，```
10
2
0.1
```给出 (G=5) 和 (T=\sqrt{0.04}=0.2)，因此输出为```
It will take the object 0.2 seconds to fall 0.1 meters
```粗心地进行截断而不是舍入的实现可能会在十分之几之间的值上失败。 

## 方法

 思考这个问题的一种强力方法是以十分之一秒的增量模拟可能的时间。 对于每个候选者（t），我们可以计算距离

 [
 D(t)=\frac12Gt^2
 ]

 当候选人达到要求的距离时停止。 如果按升序检查候选者并且结果适当舍入，则这是正确的。 然而，如果真实答案是 (T)，则需要大约 (10T) 检查。 更准确地说，检查 (0.0,0.1,\ldots,\lceil10T\rceil/10) 需要 (\lceil10T\rceil+1) 个候选评估。 由于该语句没有提供 (T) 的上限，因此该模拟没有有限的最坏情况操作计数。 即使存在界限，对于方程可以精确求解的问题来说，也不需要数值搜索。 

蛮力方法之所以有效，是因为距离是时间的单调函数，但它失败了，因为它重复评估一个未知数可以用代数方法隔离的方程。 关键的观察是物体从静止开始，因此速度项完全消失。 一旦（V_i=0），剩余方程仅包含（T^2），允许我们直接求解（T）。 

首先根据力和质量计算重力加速度。 然后将该加速度代入下落距离方程并分离出正平方根。 这将整个问题简化为常数时间算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(T)) 候选人检查 | (O(1)) | (O(1)) | 原则上太慢|
 | 最佳 | (O(1)) | (O(1)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 读取（F_g）、（M）和（D）。 这些是引力、用于确定行星引力加速度的质量以及下落距离。 
2. 计算重力加速度为

 [
 G=\frac{F_g}{M}。 
]

 这直接从 (F_g=MG) 得出，因此无需事先知道行星的重力。 
3. 将初始速度设置为零，因为对象已从静止状态释放。 因此，一般方程 (D=V_iT+\frac12GT^2) 简化为

 [
 D=\frac12GT^2。 
]
 4. 重新整理方程得到

 [
 T^2=\frac{2D}{G}。 
]

 时间不能为负，所以我们取正的平方根。 
5. 将表达式代入 (G) 并计算

 [
 T=\sqrt{\frac{2DM}{F_g}}。 
]

 这避免了不必要的中间变量并使实现更短。 
6. (T) 和 (D) 都使用一位小数打印出所需的句子。 Python 的浮点格式化`.1f`执行所需的小数舍入。 

关键的不变量是（T）的每个计算值都是在应用条件（V_i=0）后从精确的物理方程获得的。 计算的加速度满足（F_g=MG），并且得到的时间满足（D=\frac12GT^2）。 由于物理时间是非负的，因此选择正平方根给出唯一有效的解。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    fg = float(input())
    mass = float(input())
    distance = float(input())

    time = math.sqrt(2.0 * distance * mass / fg)

    print(
        f"It will take the object {time:.1f} seconds "
        f"to fall {distance:.1f} meters"
    )

if __name__ == "__main__":
    solve()
```前三个读取直接对应于输入中的三个物理量。 它们被解析为浮点数，因为该语句不将值限制为整数。 

表达式`2.0 * distance * mass / fg`正是重新排列后的公式 (2DM/F_g)。 使用`math.sqrt`然后得出 (T) 的正解。 

输出使用`{time:.1f}`和`{distance:.1f}`。 第一个格式化操作将计算出的下降时间四舍五入到一位小数，而第二个格式化操作则保证提供的距离以所需的格式显示，即使输入是整数，例如`10`。 

没有循环、递归、数组或其他数据结构。 该计算使用恒定内存并仅执行固定量的工作。

## 边缘情况

 第一个边缘情况是初始速度。 和```
500
70
10
```该对象显式地从静止状态释放，因此 (V_i=0)。 该算法在求解方程之前删除整个 (V_iT) 项。 将该项保留为任意非零速度将产生物理上不同的答案。 

第二个边缘情况涉及输出格式。 为了```
100
50
5
```计算出的时间约为 (2.2360679)。 所需的结果是`2.2`， 不是`2`而不是`2.3`。 这`:.1f`格式说明符执行舍入，同时还保证小数点后恰好一位数字。 距离被单独格式化，产生`5.0`。 

第三种边缘情况是分数距离：```
10
2
0.1
```这里

 [
 T=\sqrt{\frac{2(0.1)(2)}{10}}
 =\sqrt{0.04}
 =0.2。 
]

 程序打印出```
It will take the object 0.2 seconds to fall 0.1 meters
```这捕获了假设距离是整数的实现。 

最后，大数值不会改变算法。 为了```
1000000000000
1000000000000
1000000000000
```质量和重力在公式中抵消，留下 (T=\sqrt{2\cdot10^{12}})，大约为 (1414213.562)。 程序打印出`1414213.6`。 无论输入值的大小如何，计算仍然仅使用恒定内存和恒定时间。
