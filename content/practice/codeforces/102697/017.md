 ## 解决方案
 ## 问题理解

 该问题模拟了一种称为“交叉电荷”的化学规则。 两个离子具有由两个整数表示的电荷。 为了找到分子系数，这些值被交叉，这意味着第一个离子接收第二个离子的电荷，第二个离子接收第一个离子的电荷。 

输入包含两个代表原始电荷的整数。 应用交叉运算后，输出应包含两个系数。 

约束很小，因为唯一需要的操作是移动两个值。 不需要搜索、迭代或数据结构。 任何比常数时间更复杂的算法都是不必要的。 

唯一值得考虑的边缘情况是两种费用相同。 例如：

 输入：```
5 5
```输出：```
5 5
```尝试删除重复项或假设值必须更改的解决方案将在此处失败。 穿过两个相等的电荷使该对保持不变。 

## 方法

 一种直接的方法是读取这两个数字，存储它们，然后以相反的顺序打印它们。 该操作是正确的，因为交叉电荷的定义正是交换。 

没有有意义的强力解决方案，因为没有可供探索的选择。 任何执行额外工作的方法只会增加复杂性，而无法解决更困难的问题。 

整个任务简化为交换两个变量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 直接互换 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 从输入读取两个电荷值。 
2. 首先输出第二个值，然后输出第一个值，因为交叉电荷会交换它们的位置。 

为什么它有效：

 所需的变换是两个元素的排列。 交换保留两个原始值并将每个值置于另一个离子的系数位置，这与交叉操作的定义完全匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, b = map(int, input().split())
print(b, a)
```该程序在一行中读取两个电荷并将它们存储为整数。 输出语句颠倒它们的顺序，从而执行所需的交叉。 

不需要循环、数组或额外的变量，因为输入大小固定为两个值。 Python 整数对于所涉及的算术来说也绰绰有余，因为程序从不对值执行计算。 

## 工作示例

 对于输入：```
2 3
```内部状态是：

 | 步骤| 一个 | 乙| 输出|
 | --- | --- | --- | --- |
 | 读取输入| 2 | 3 | |
 | 交换位置 | 3 | 2 | 3 2 |

 结果表明，第二个电荷成为第一个系数。 

对于输入：```
7 7
```该州是：

 | 步骤| 一个 | 乙| 输出|
 | --- | --- | --- | --- |
 | 读取输入| 7 | 7 | |
 | 交换位置 | 7 | 7 | 7 7 | 7

 相等的值在交叉后保持不变。

## 测试用例```python
import sys
import io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline
    a, b = map(int, input().split())
    return f"{b} {a}\n"

assert solve("2 3\n") == "3 2\n", "sample"
assert solve("4 3\n") == "3 4\n", "different charges"
assert solve("5 5\n") == "5 5\n", "equal charges"
assert solve("1 1000000000\n") == "1000000000 1\n", "large values"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 |`2 3`|`3 2`| 基本交换行为 |
 |`4 3`|`3 4`| 值被放置在相反的位置 |
 |`5 5`|`5 5`| 同等收费不变|
 |`1 1000000000`|`1000000000 1`| 大整数处理 |

 ## 边缘情况

 当两个电荷相同时，交换它们会产生相同的输出。 对于输入：```
8 8
```算法读取`a = 8`和`b = 8`，然后打印`b a`， 导致：```
8 8
```正确的实现不需要特殊条件，因为普通交换已经处理这种情况。 

当一个值远大于另一个值时，适用相同的规则。 对于输入：```
1 999999999
```程序打印：```
999999999 1
```该算法仅改变位置，因此电荷的大小对正确性没有影响。
