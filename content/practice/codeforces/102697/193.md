 ## 解决方案
 ## 问题理解

 我们给出三个正整数 (a)、(b) 和 (c)，描述二次多项式

 [
 y=ax^2+bx+c。 
]

 我们必须找到各种方法将该多项式写为两个具有正整数系数的二项式的乘积：

 [
 (ax^2+bx+c)=(px+q)(rx+s),
 ]

 其中 (p,q,r,s) 均为正整数。 每个因式分解必须以表格形式打印`(px + q)(rx + s)`，省略系数 (1)，并且完整的因式分解集必须按 ASCII 顺序排序。 如果不存在这样的分解，我们打印`-1`。 这些是当前 Codeforces Gym 声明中给出的要求。 

展开两个二项式可得

 [
 (px+q)(rx+s)=prx^2+(ps+qr)x+qs。 
]

 因此，每个有效的因式分解必须满足

 [
 pr=a,\qquad ps+qr=b,\qquad qs=c。 
]

 该语句没有发布 (a,b,c) 的数字上限，因此推理约束的有用方法是通过算法执行的算术工作。 对所有可能系数的直接搜索可能需要与值本身成比例的工作，随着系数的增长，这变得不合适。 最佳方法将搜索减少为查找一个整数的除数，在下面的实现中只需要 (O(\sqrt a)) 除数检查。 

有几种边缘情况可能会悄悄地破坏简单的实现。 首先，这两个因素在输出中是有序的，因此两者`(2x + 2)(x + 3)`和`(x + 3)(2x + 2)`是不同的所需输出。 用于输入`2 8 6`，两者都会发生，并且将其中一个作为重复项删除会产生不完整的答案。 

其次，等于 (1) 的系数必须打印为`x`， 不是`1x`。 用于输入`1 17 60`，正确的输出包含`(x + 12)(x + 5)`而不是`(1x + 12)(x + 5)`。 粗心的格式化程序可能会生成与所需输出不匹配的数学等效文本。 

第三，当辅助二次根重合时，重复因式分解不得打印两次。 例如，如果相关值为 (t) 并且判别式为零，则 (t) 的两个可能值相同。 将两者视为单独的情况会重复每个结果因式分解。 

最后，二次方程可以具有整数根，但仍然无法满足正系数要求。 这里的条件不仅仅是多项式有有理根或整数根。 两个二项式中的每个系数都必须为正。 用于输入`3 7 11`，所需的输出是`-1`，因为没有正整数 (p,q,r,s) 满足所有三个系数方程。 

## 方法

 最直接的方法是选择两个因子的四个系数并测试它们的乘积是否等于原始多项式。 由于(pr=a)，我们可以尝试(a)的每个正除数(p)，导出(r=a/p)，然后尝试常数系数的可能值并检查中间系数。 更简单的暴力实现可以尝试从 (1) 到 (a) 的每个 (p)、从 (1) 到 (c) 的每个 (q)，并测试结果分解。 在最坏的情况下，这需要 (O(ac)) 运算，对于即使是中等大的系数来说，这也已经太大了。 独立搜索所有四个系数会更糟。 

三个系数方程的结构给出了更强的观察结果。 定义

 [
 t=ps。 
]

 对中间系数的另一个贡献是（qr），所以

 [
 qr=b-t。 
]

 现在将这两个量相乘：

 [
 (ps)(qr)=pqrs。 
]

 因为 (pr=a) 和 (qs=c)，

 [
 pqrs=(pr)(qs)=ac。 
]

 因此 (t) 必须满足

 [
 t(b-t)=ac。 
]

 重新排列给出仅涉及 (t) 的二次方程：

 [
 t^2-bt+ac=0。 
]

 其判别式为

 [
 D=b^2-4ac。 
]

 这是关键的减少。 我们首先确定 (t=ps) 的唯一可能值，而不是搜索四个未知系数。 他们是

 [
 t=\frac{b\pm\sqrt D}{2}。 
]

 如果 (D<0)，则 (t) 没有实数值，因此不存在因式分解。 如果 (D) 不是完全平方，则 (t) 不能是整数，因此同样不存在正整数分解。 如果(b+\sqrt D)的奇偶性是奇数，则候选(t)也不是整数。 

一旦知道了有效的 (t)，我们需要将其拆分为 (p) 和 (s)，同时尊重 (p\mid a) 和 (s\mid c)。 我们可以枚举 (t) 的约数 (p)。 对于每个这样的 (p)，设置

 [
 r=\frac ap,\qquad s=\frac tp。 
]

 当 (r) 是整数并且 (s) 除以 (c) 时，候选值恰好有效，在这种情况下 (q=c/s)。 因式分解的结果是

 [
 (px+q)(rx+s)。 
]

 无需单独检查中间系数。 由于(ps=t)和(qr=ac/t=b-t)，中间系数自动为(b)。 

我们只需要找到 (t) 的除数，并且可以通过检查 (\sqrt t) 之前的整数来找到每个除数。 由于 (t\le ac)，在使用 (a) 的除数之后使用 (\sqrt a) 作为除数搜索界限给出了特别方便的实现。 对于每个候选 (t)，我们枚举 (a) 到 (\sqrt a) 的除数，对于每个除数 (p)，检查是否 (p\mid t) 和 (t/p\mid c)。 每个有效的有序分解都只出现一次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(ac)) | (O(1)) 除了输出 | 太慢了 |
 | 最佳| (O(\sqrt a)) | (O(k))，其中 (k) 是答案的数量 | 已接受 |

 ## 算法演练

 1. 阅读(a)、(b)、(c)。 我们想要找到满足 (pr=a)、(qs=c) 和 (ps+qr=b) 的所有正整数 (p,q,r,s)。 
2. 计算判别式 (D=b^2-4ac)。 如果(D<0)，则(t=ps)不可能有任何整数值，所以答案是`-1`。 
3. 计算整数平方根 (d=\lfloor\sqrt D\rfloor)。 如果 (d^2\ne D)，判别式不是完全平方，因此 (t) 的可能值不是整数，并且不存在有效的因式分解。 
4. 检查(b+d)的奇偶性。 如果是奇数，则 ((b+d)/2) 和 ((b-d)/2) 都不是整数，因此不存在有效的因式分解。 
5.构造两个可能的值

 [
 t_1=\frac{b+d}{2},\qquad t_2=\frac{b-d}{2}。 
]

 只保留积极的价值观。 如果（D=0），这两个候选者相等，因此只保留一份副本。 

1. 对于每个候选 (t)，枚举 (a) 的约数 (p)。 我们只需要检查 (p) 到 (\sqrt a)，因为每个大于平方根的除数都与一个较小的除数配对。 每当 (p\mid a) 时，也将 (a/p) 视为除数。 
2. 对于每个除数 (p)，要求 (p\mid t)。 然后设置

 [
 s=\frac tp.
 ]

 我们需要 (s\mid c)，因为 (s) 是乘积为 (c) 的两个正因子之一。 

1. 如果两个整除条件都成立，计算

 [
 r=\frac ap,\qquad q=\frac cs。 
]

 现在四个系数满足 (pr=a) 和 (qs=c)。 由于(t)被构造为(t(b-t)=ac)的根，所以剩余的交叉项也满足(ps+qr=b)。 

1. 当两个除数方向不同时，将它们相加。 如果 (p) 是通过平方根枚举找到的除数，则其配对除数 (a/p) 代表一个单独的可能的主系数，也必须进行测试。 这就是允许算法产生两者的原因`(2x + 2)(x + 3)`和`(x + 3)(2x + 2)`。 
2. 将每个有效分解转换为其所需的字符串表示形式，省略系数`1`前`x`，并按字典顺序对所有字符串进行排序。 Python 的字符串排序与此处使用的字符的 ASCII 排序相匹配。 
3. 打印排序后的字符串。 如果没有生成候选人，则打印`-1`。 

### 为什么它有效

 每个有效的分解 ((px+q)(rx+s)) 都定义 (t=ps)。 其中间系数给出 (ps+qr=b)，而将两个交叉项相乘得出 ((ps)(qr)=ac)。 因此 (t) 必须满足 (t^2-bt+ac=0)，因此判别测试不能丢弃有效的因式分解。 

相反，假设正整数(t)满足(t(b-t)=ac)。 如果我们选择一个除数 (p)，使得 (p\mid a)、(p\mid t) 和 (t/p\mid c)，则设置 (r=a/p)、(s=t/p) 和 (q=c/s) 会给出正整数 (pr=a) 和 (qs=c)。 此外，

 [
 qr=\frac ac\cdot s
 ]

 可以更直接地表示为

 [
 qr=\frac{ac}{ps}=\frac{ac}{t}=b-t,
 ]

 因为(t(b-t)=ac)。 因此 (ps+qr=b)，因此构造的因子乘以原始多项式。 每个有效的因式分解都恰好有这样一个 (t) 和这样一个除数 (p)，因此枚举是完整的。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def format_factor(coef_x, const):
    if coef_x == 1:
        return f"(x + {const})"
    return f"({coef_x}x + {const})"

def solve():
    a, b, c = map(int, input().split())

    disc = b * b - 4 * a * c

    if disc < 0:
        print(-1)
        return

    root = math.isqrt(disc)

    if root * root != disc:
        print(-1)
        return

    if (b + root) & 1:
        print(-1)
        return

    t1 = (b + root) // 2
    t2 = (b - root) // 2

    candidates = [t1]
    if t2 != t1:
        candidates.append(t2)

    answers = set()

    limit = math.isqrt(a)

    for t in candidates:
        if t <= 0:
            continue

        for d in range(1, limit + 1):
            if a % d != 0:
                continue

            p1 = d
            p2 = a // d

            for p in (p1, p2):
                if t % p != 0:
                    continue

                s = t // p

                if c % s != 0:
                    continue

                r = a // p
                q = c // s

                left = format_factor(p, q)
                right = format_factor(r, s)

                answers.add(left + right)

    if not answers:
        print(-1)
        return

    print("\n".join(sorted(answers)))

if __name__ == "__main__":
    solve()
```判别式计算实现了从四因子系数到单一量（t=ps）的集中约简。 Python 整数具有任意精度，因此诸如`b * b`和`4 * a * c`即使输入系数很大也不会溢出。`math.isqrt`使用浮点代替`sqrt`。 浮点平方根可以对略高于或低于其真实值的大整数进行舍入，这可能会错误地将判别式分类为完美平方。`isqrt`给出精确的整数平方根，因此检查`root * root == disc`是可靠的。 

奇偶校验是必要的，因为二次公式除以（2）。 单独的完全平方判别式并不能保证 (t) 是整数。 例如，(b=5) 和 (d=2) 将给出 ((5+2)/2=3.5)。 

除数循环只经过`isqrt(a)`。 每当`d`划分`a`， 两个都`d`和`a // d`被测试。 这避免了仅考虑小除数的简单完整性错误。 相同的因式分解可以首先用任一二项式表示，因此两个方向都必须保持可用。 

这`answers`set 删除意外的重复项。 当可以通过两个除数枚举路径达到相同的因式分解时，这非常有用。 我们仅在生成所有候选后才进行排序，因为所需的排序是文本 ASCII 顺序而不是系数的数字顺序。

            solve()
            return sys.stdout.getvalue()
        finally:

    finally:

        input = old_input

## Edge Cases

A zero discriminant is handled by constructing only one candidate \(t\). For input `4 4 1`, we have

\[
D=4^2-4(4)(1)=0,
\]

so \(t=2\). The only valid split is \(p=2,s=1\), giving \(r=2,q=1\). The result is `(2x + 1)(2x + 1)`. If both quadratic-formula branches were processed without deduplication, the same answer would be generated twice.

For input `1 2 1`, the discriminant is \(0\) and \(t=1\). The only possible coefficients are \(p=r=q=s=1\), giving

\[
(x+1)(x+1)=x^2+2x+1.
\]

The formatter prints `x` instead of `1x`, which matches the required representation.

For input `3 7 11`, the discriminant is

\[
7^2-4(3)(11)=-83.
\]

The algorithm stops immediately because a negative discriminant cannot produce an integer \(t\). The output is `-1`.

For input `5 5 5`, the values are all equal, but the discriminant is

\[
25-100=-75.
\]

Again there is no possible positive-integer factorization, so the answer is `-1`. This catches the common mistake of assuming that similar or equal coefficients imply a factorization.

For input `2 8 6`, the algorithm deliberately considers both divisors in each divisor pair. Choosing \(p=2,s=3\) gives `(2x + 2)(x + 3)`, while choosing \(p=1,s=6\) gives `(x + 1)(2x + 6)`. Reversing the factor roles gives the other two required strings. The final sort puts these four strings into exactly the required ASCII order.
```
