 ## 解决方案
 ## 问题理解

 当字符串中的每个字符都是以下任一字符时，该字符串被称为无聊：`a`或者`b`。 给定一个非空字符串，我们必须确定它是否满足该规则。 输出是`YES`如果没有其他字符出现，并且`NO`一旦至少有一个字符在外面`a`和`b`出现。 原问题有 1 秒时间限制和 256 MB 内存限制。 

关于约束的关键观察是该任务只要求我们检查一个字符串的字符。 即使字符串很长，处理每个字符一次的算法在其长度上也是线性的，并且非常适合 1 秒的限制。 没有理由建造辅助结构或比较每一对位置。 在最坏的情况下，二次算法将执行大约 (n^2/2) 个字符检查，随着字符串的增长，这很快就会变得不切实际。 

有一些小情况通常会导致错误。 例如，输入```
a
```必须产生```
YES
```因为唯一的字符是允许的。 一个意外需要两者的解决方案`a`和`b`发生会错误地拒绝它。 

输入```
baaaaabba
```必须产生```
YES
```因为重复的字符和任何顺序`a`和`b`是允许的。 条件是关于出现哪些字符，而不是关于它们的排列。 这也是官方的例子之一。 

输入```
baaaaabad
```必须产生```
NO
```因为决赛`d`被禁止，即使每个前面的字符都是有效的。 仅检查字符串开头的粗心实现可能会错过此违规行为。 

最后，```
ccabbabbdd
```必须产生```
NO
```因为两者`c`和`d`超出了允许的字母表。 我们只需要一个无效字符就可以拒绝整个字符串。 

## 方法

 一种简单的暴力解释是重复验证较大的前缀。 从第一个字符开始，检查该前缀是否仅包含`a`和`b`，然后检查前两个字符，然后检查前三个字符，依此类推，直到检查完整个字符串。 这是正确的，因为当它的每个前缀都无聊时，整个字符串就变得无聊。 然而，从头开始检查前缀几乎重复了之前的所有工作。 对于长度为 (n) 的字符串，字符检查总数为

 [
 1 + 2 + 3 + \dots + n = \frac{n(n+1)}2,
 ]

 即 (O(n^2))。 对于 (n=10^5)，大约是 (5\times10^9) 个字符检查，远远超出 1 秒限制所能支持的范围。 

消除这种重复的观察要简单得多：该属性对于每个字符来说都是本地的。 我们不需要重新考虑已经检查过的字符。 从左到右扫描时，如果当前字符是`a`或者`b`，它不能使字符串无效，所以我们继续。 如果是其他的话，答案已经是已知的`NO`，并且扫描可以立即停止。 

这将重复的前缀验证转变为一次线性传递。 暴力方法之所以有效，是因为它最终会检查每个字符，但会失败，因为它会多次检查同一字符。 单遍方法准确地保留了重要的信息，无论到目前为止看到的每个字符是否属于允许的集合`{a, b}`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 对于大 n 来说太慢 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取字符串并使用删除尾随换行符`strip()`。 输入不包含空格，因此这准确地给出了必须检查的字符串。 
2. 从左到右扫描字符。 对于每个字符，测试它是否是`a`或者`b`。 这已经足够了，因为定义对位置、频率或两个允许的字符之间的转换没有限制。 
3. 如果一个字符与两个字符不同`a`和`b`，立即打印`NO`并停止。 一旦存在无效字符，添加或检查其他字符无法使现有字符串有效。 
4. 如果扫描到达末尾没有发现无效字符，则打印`YES`。 然后，每个字符都被验证是否属于允许的字母表，这正是无聊字符串的定义。 

### 为什么它有效

 扫描期间的不变性是到目前为止检查的每个字符都属于`{a, b}`。 如果当前字符也是`a`或者`b`，不变量仍然成立。 如果当前字符是其他字符，则该字符串包含禁止字符并且不能无聊，因此返回`NO`是正确的。 如果循环结束，则不变量覆盖整个字符串，证明每个字符都是允许的，正确答案是`YES`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()

    for ch in s:
        if ch != 'a' and ch != 'b':
            print("NO")
            return

    print("YES")

solve()
```输入被读取一次，并且`strip()`删除由产生的换行符`readline()`。 由于指定字符串不包含空格，因此使用时不会产生歧义`strip()`这里。 

该循环直接实现了算法的第二步和第三步。 该条件使用两次比较而不是依赖于更大的字符范围，因为只有确切的字符`a`和`b`是有效的。 一个字符，例如`c`,`A`， 或者`1`必须全部拒绝。 

这`return`打印后`NO`也是故意的。 一旦发现禁用字符，继续扫描就不能改变答案。 如果没有发生提前返回，则循环已检查每个字符，因此打印`YES`是有道理的。 

没有整数计算，因此整数溢出是无关紧要的。 除了字符串本身之外，该实现也不会分配与输入长度成比例的任何结构。

    old_stdout = sys.stdout

 ## 边缘情况

 单字符输入`a`由检查一个字符、发现它有效并到达末尾的循环来处理，这会产生`YES`。 同样的推理给出`YES`为了`b`。 不需要两个角色都出现。 

对于输入```
baaaaabba
```该算法检查`b`，然后是一个序列`a`字符和`b`字符，并且每个字符都通过了允许字符测试。 循环结束并打印`YES`。 顺序和重复并不重要，因为属性仅取决于成员资格`{a, b}`。 

对于输入```
baaaaabad
```该算法接受初始`b`以及以下所有内容`a`人物。 当它达到`d`，条件`ch != 'a' and ch != 'b'`变为 true，因此立即打印`NO`。 无效字符接近末尾，但从左到右扫描仍然可以正确捕获它。 

对于输入```
ccabbabbdd
```第一个字符，`c`，已经被禁止了。 因此该算法打印`NO`一次迭代后。 后期就不需要检查了`a`和`b`字符，因为即使包含一个禁止字符的字符串也不能满足定义。 

对于边界情况```
aaac
```前三个字符保留不变式，而第四个字符则违反不变式。 该算法检查最终位置而不是在索引处停止`n - 2`，所以它正确打印`NO`。 对应有效案例`aaab`到达末尾并打印`YES`。
