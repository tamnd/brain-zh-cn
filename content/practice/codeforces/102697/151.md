 ## 解决方案
 ## 问题理解

 尽管有这个名字，这个问题并不需要构建或分析三角形。 该任务只是针对所提供的浮点参数计算一个三角函数。 第一个输入行使用以下之一标识该函数`sin`,`cos`,`tan`,`cosec`,`sec`， 或者`cotan`，第二行给出了应该评估该函数的值。 所需的输出是生成的浮点值。 存档的语句确认输入恰好由一个运算关键字后跟一个浮点值组成，并且输出是一个浮点结果。 

这六个操作对应于通常的定义

 [
 \sin(x)=\sin(x),
 ]

 [
 \cos(x)=\cos(x),
 ]

 [
 \tan(x)=\frac{\sin(x)}{\cos(x)},
 ]

 [
 \cosec(x)=\frac{1}{\sin(x)},
 ]

 [
 \sec(x)=\frac{1}{\cos(x)},
 ]

 和

 [
 \cotan(x)=\frac{\cos(x)}{\sin(x)}。 
]

 该参数以弧度解释，因为 Python 的`math.sin`,`math.cos`， 和`math.tan`函数使用弧度。 样本输入`sin`其次是`2`大约产生`0.9092974268256817`，这正是 (\sin(2)) 的弧度值。 

这里没有有意义的大输入限制。 仅评估一个操作，因此即使输入具有大量数字，也不会产生组合问题（假设该值可以由浮点解析器表示）。 因此，一秒的时间限制对于恒定数量的算术运算来说是绰绰有余的。 没有理由考虑范围迭代、动态规划或数值搜索等算法。 

主要的边缘情况涉及倒三角函数。 例如，与```
cosec
0
```数学值未定义，因为 (\sin(0)=0)。 盲目计算的粗心实现`1 / math.sin(x)`将引发被零除错误而不是产生有效的数字答案。 该语句没有为未定义的值指定特殊的输出，因此此类输入应被视为在预期的有效域之外。 

类似的问题发生在```
sec
1.5707963267948966
```因为参数大约为 (\pi/2)，其中 (\cos(x)=0)。 数学正割在那里未定义。 同样，语句中没有无穷大或未定义值的特殊表示，因此正确的实现遵循规定的数学域，而不是发明输出约定。 

另一个微妙的情况是非常接近奇点的值。 例如，```
tan
1.5707963267948965
```接近 (\pi/2)，但不完全相同的浮点值。 结果是一个非常大的有限浮点数。 将输入与硬编码值进行比较，例如`pi / 2`将附近的值视为未定义是不正确的。 

## 方法

 直接方法已经是解决这个问题的最佳方法。 强力解释是尝试寻找所请求的三角值的某种替代表示，也许通过重复应用恒等式或以数值方式逼近函数。 这种方法是不必要的，因为该语言的标准数学库已经直接计算了六个所需的函数。 

直接法的精确操作计数是恒定的。 我们执行一次字符串比较或字典查找，一次调用标准三角函数`sin`,`cos`， 或者`tan`，或一个倒数函数的附加除法。 因此运行时间是(O(1))，辅助空间是(O(1))。 

通常的强力与优化的区别在这里并没有真正出现。 没有输入大小导致直接计算变得太慢。 例如，如果我们尝试使用泰勒级数来近似三角函数，则项数将取决于所需的精度，并且会引入不必要的工作。 关键的观察结果很简单，所请求的操作正是标准浮点数学库提供的操作。 

唯一的设计选择是如何将关键字映射到其数学运算。 一条链`if`语句可以工作，但是字典使每个关键字及其计算之间的关系变得明确，并保持实现的紧凑性。

 | 直接标准库评估 | (O(1)) | (O(1)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 从第一行读取操作关键字并删除周围的空格。 关键字完全决定了必须评估哪个数学函数。 
2. 从第二行读取浮点参数并将其转换为`float`。 Python 的三角函数需要以弧度测量的浮点值。 
3. 选择请求的操作。 为了`sin`,`cos`， 和`tan`，调用相应的函数`math`。 为了`cosec`, 除以`sin(x)`， 为了`sec`, 除以`cos(x)`，并且对于`cotan`, 除`cos(x)`经过`sin(x)`。 这些倒数函数不是直接在所需名称下提供的，因此它们必须由正弦和余弦构造。 
4. 打印生成的浮点值。 Python默认的浮点格式为法官的浮点比较提供了足够的数字。 

不变的是，选择操作后，存储的结果正是输入关键字所请求的数学函数，并使用所提供参数的相同浮点表示形式进行计算。 每个可能的有效关键字都映射到六个定义之一，因此不需要处理其他情况。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    operation = input().strip()
    x = float(input())

    if operation == "sin":
        result = math.sin(x)
    elif operation == "cos":
        result = math.cos(x)
    elif operation == "tan":
        result = math.tan(x)
    elif operation == "cosec":
        result = 1.0 / math.sin(x)
    elif operation == "sec":
        result = 1.0 / math.cos(x)
    else:  # cotan
        result = math.cos(x) / math.sin(x)

    print(result)

if __name__ == "__main__":
    solve()
```第一行被读取为字符串，因为它是操作名称而不是数值。 呼唤`.strip()`删除换行符`readline()`离开在最后。 

第二行转换为`float`，这是必要的，因为输入可以包含十进制值。 三角函数在`math`对弧度进行运算，匹配问题所使用的数学解释。 

互逆操作有意使用定义，而不是试图找到替代的库函数。`cosec`是`1 / sin(x)`,`sec`是`1 / cos(x)`， 和`cotan`是`cos(x) / sin(x)`。 操作顺序很重要`cotan`，因为反转分子和分母将计算正切。 

不需要整数算术、模算术、数组、循环或特殊的数值迭代。 Python 整数也永远不会溢出，但这在这里无关紧要，因为所有计算都是作为浮点值执行的。 

决赛`else`把手`cotan`，因为该语句将关键字限制为六个指定名称。 如果可能存在无效关键字，则最好使用显式的最终分支，但输入格式保证操作是这六个操作之一。

## 边缘情况

 对于`sin(0)`，算法直接调用`math.sin(0.0)`并获得`0.0`。 例如，```
sin
0
```产生```
0.0
```不涉及除法，因此零对于正弦运算是完全安全的。 

为了`cosec(0)`，情况有所不同：```
cosec
0
```该算法首先计算 (\sin(0)=0)，然后尝试 (1/0)。 数学表达式未定义，Python 会引发除零异常。 问题陈述没有定义这种情况的输出，因此解决方案不应该发明正确的特殊值。 

同样的推理也适用于余弦为零处的割线。 和```
sec
1.5707963267948966
```参数是 (\pi/2) 的浮点表示形式，并且`math.cos`返回一个极其接近零的值，而不一定返回恰好为零。 因此，Python 可能会产生非常大的有限结果，而不是引发异常。 这是浮点运算的正常结果，而不是算法中的错误。 

最后，接近奇点的值不能仅仅因为它们在数值上接近而被视为奇点。 例如，```
tan
1.5707963267948965
```是一个有效的浮点输入，与精确的数学 (\pi/2) 表示不同。 该实现将计算委托给`math.tan`而不是引入任意的 epsilon 检查。 这保留了所提供的浮点值的语义，并避免错误地拒绝合法输入。
