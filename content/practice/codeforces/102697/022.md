 ## 解决方案
 ## 问题理解

 该任务是围绕 Steinhart-Hart 方程构建的一个小型数值代数问题。 我们有三个校准测量。 每次测量都会将电阻 (R_i) 与温度 (T_i) 配对，模型表示

 [
 \frac{1}{T}=A+B\ln R+C(\ln R)^3。 
]

 这三个测量值确定了三个未知常数 (A)、(B) 和 (C)。 我们只需要打印(A)。 输入包含 (T_1,T_2,T_3,R_1,R_2,R_3)，每个在其自己的行上作为浮点值。 官方声明明确给出了一系列用于计算常量的中间公式，因此编程任务主要是按照正确的顺序评估这些公式。 

这里没有大的（n）、数组、图形或重复的测试用例。 输入大小始终为 6 个浮点数，时间限制为 1 秒，内存为 256 MB。 因此，渐近优化不是问题。 任何执行固定数量算术运算的解决方案实际上都是瞬时的。 真正关心的是使用自然对数、保留浮点精度以及按预期顺序评估除法。 

校准点必须适合提供的公式。 特别是，对数需要正电阻，并且对于要定义的公式，分母 (L_2-L_1)、(L_3-L_1)、(L_3-L_2) 和 (L_1+L_2+L_3) 不得为零。 

一个有用的边界情况是电阻恰好为 (1)。 例如，```
1
1
1
1
2
4
```有 (L_1=\ln 1=0)。 如果三个温度均为 (1)，则每个 (Y_i) 均为 (1)，因此两个斜率均为零，给出 (C=0)、(B=0)，最后给出 (A=1)。 正确的输出是（1）。 假设对数始终非零的粗心实现可能会错误地将其视为特殊情况或引入不必要的除以 (L_1)。 

另一种极端情况是所有三个温度相等而电阻不同。 为了```
1
1
1
1
2
4
```同样的计算得出 (A=1)、(B=0)、(C=0)。 假设需要不同温度的方法将拒绝完全有效的数学案例。 

更危险的情况是反复抵抗。 例如，```
1
1
1
2
2
4
```使得 (L_2-L_1=0)，因此 (\gamma_2) 未定义。 提供的公式无法根据此类数据确定校准常数。 粗心的实现会尝试除法并产生异常或无效的浮点结果。 有效的测试数据必须避免这种奇异的情况。 

## 方法

 思考该问题的通用方法是将三个测量值视为三个未知数 (A、B、C) 中的三个方程。 写完后

 [
 Y_i=\frac1{T_i},\qquad L_i=\ln R_i,
 ]

 每次测量都变成

 [
 Y_i=A+B L_i+C L_i^3。 
]

 简单的代数实现可以将其构建为 (3\times3) 线性系统并执行高斯消除。 这种方法是完全可行的，因为矩阵始终具有三行三列。 它仅执行恒定数量的算术运算，因此与通常的大输入蛮力不同，不存在输入大小使其渐近变得太慢的情况。 最坏的情况仍然只是固定大小的消除，远低于几百次算术运算。 

更自然的解决方案来自于观察问题已经提供了专门针对该精确系统的消除序列。 求方程之间的差可以消除 (A)。 将这些差值除以 (L) 中的相应差值即可得到两个正割斜率 (\gamma_2) 和 (\gamma_3)。 它们的差异隔离了三次系数 (C)，紧随其后的是 (B)。 最后，代入第一个校准点恢复 (A)。 

这比一般高斯消去法更可取，因为代数已经利用了基函数 (1,L,L^3) 的特殊结构。 无需实施矩阵构造、旋转或通用消除。 整个计算是一个固定的对数、加法、乘法和除法序列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 通用 3x3 高斯消除 | (O(1)) | (O(1)) | (O(1)) | (O(1)) | 已接受 |
 | 直接 Steinhart-Hart 公式 | (O(1)) | (O(1)) | (O(1)) | (O(1)) | 接受，更简单|

 ## 算法演练

 1. 按输入顺序读取六个浮点值。 该语句给出的顺序为 (T_1,T_2,T_3,R_1,R_2,R_3)，因此前三个值必须解释为温度而不是电阻。 
2. 计算 (L_1=\ln R_1)、(L_2=\ln R_2) 和 (L_3=\ln R_3)。 这些是 Steinhart-Hart 方程使用的自变量值。 
3. 计算(Y_1=1/T_1)、(Y_2=1/T_2) 和(Y_3=1/T_3)。 原始方程以 (1/T) 表示，因此这些值将测量值转换为代数所需的形式。 
4. 计算

 [
 \gamma_2=\frac{Y_2-Y_1}{L_2-L_1}
 ]

 和

 [
 \gamma_3=\frac{Y_3-Y_1}{L_3-L_1}。 
]

 这些量表示转换数据后第一个校准点与其他两点之间的斜率。 

1. 计算

 [
 C=
 \frac{\gamma_3-\gamma_2}{L_3-L_2}
 \c点
 \frac{1}{L_1+L_2+L_3}。 
]

 两个斜率之间的差异消除了 (L) 中线性表现的贡献，留下足够的信息来确定三次系数。 

1. 计算

 [
 B=\gamma_2-C(L_1^2+L_1L_2+L_2^2)。 
]

 这从第一个割线斜率中减去三次贡献，留下系数 (L)。 

1. 使用第一个校准点恢复 (A)：

 [
 A=Y_1-L_1(B+L_1^2C)。 
]

 这只是重新排列原始方程以分离 (A)。 

1. 将 (A) 作为浮点值打印。 法官使用公差，因此不需要精确的小数再现。 官方声明还明确表示不用担心精确舍入。

整个计算过程中的不变性是（L_i）和（Y_i）始终代表原始校准测量的变换坐标，而（C），然后（B），最后（A）按照每个新计算的系数仅取决于已知值的顺序恢复。 由于这些公式是从三个原始方程通过代数推导出来的，因此所得的 (A) 是属于生成校准数据的同一模型的系数。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve(values):
    T1, T2, T3, R1, R2, R3 = values

    L1 = math.log(R1)
    L2 = math.log(R2)
    L3 = math.log(R3)

    Y1 = 1.0 / T1
    Y2 = 1.0 / T2
    Y3 = 1.0 / T3

    gamma2 = (Y2 - Y1) / (L2 - L1)
    gamma3 = (Y3 - Y1) / (L3 - L1)

    C = ((gamma3 - gamma2) / (L3 - L2)) / (L1 + L2 + L3)

    B = gamma2 - C * (L1 * L1 + L1 * L2 + L2 * L2)

    A = Y1 - L1 * (B + L1 * L1 * C)

    return A

def main():
    values = [float(input()) for _ in range(6)]
    print(solve(values))

if __name__ == "__main__":
    main()
```这`solve`函数直接反映了数学推导。 将 (L_i) 和 (Y_i) 保留为单独的变量可以使依赖顺序明确，并防止意外地将温度与其倒数混合。`math.log`计算 Steinhart-Hart 方程所需的自然对数。 蟒蛇的`float`就足够了，因为法官接受数字容差范围内的答案。 

(C) 的表达式写为两除法，而不是使用显式负指数。 两种形式在数学上是等效的，并且所选择的版本使分母结构更易于检查。 (B) 的表达式使用 (L_1^2)、(L_1L_2) 和 (L_2^2) 与推导中给出的完全相同。 

不存在整数溢出问题，因为所有计算都使用Python浮点值。 也不需要特殊的格式，例如固定的小数位数。 打印完整的 Python 浮点表示形式可以为规定的容差提供足够的精度。

## 边缘情况

 当(R_1=1)时，我们得到(L_1=0)。 为了```
1
1
1
1
2
4
```变换后的值为 (L=(0,\ln2,\ln4)) 和 (Y=(1,1,1))。 两个伽马值均为零，因此 (C=0)，然后 (B=0)，最终计算得出 (A=1)。 不需要特殊的分支，因为该公式自然可以处理 (L_1=0)。 

当所有温度都相等时，三个 (Y_i) 值也相等。 对于相同的输入，两个割线斜率都为零。 因此 (C=0) 和 (B=0)，留下 (A=Y_1)。 这说明了为什么仅仅相同的温度并不是问题。 重要的是转换后的校准点是否使所需的分母为零。 

反复的阻力是不同的。 为了```
1
1
1
2
2
4
```我们有 (L_1=L_2)，因此 (\gamma_2) 的表达式包含零分母。 所提供的该数据的校准公式没有有效的结果。 该实现故意不通过任意 epsilon 调整来隐藏此条件，因为将零分母更改为近似分母会产生问题未提供的校准数据。 

最后，非常大的电阻，例如 (10^{100})、(10^{200}) 和 (10^{300}) 仍然在 Python 的浮点范围内。`math.log`直接对这些值进行运算并产生有限对数。 该算法本身并不依赖于电阻是否小，仅依赖于电阻为正且所得校准方程是非奇异的。
