 ## 解决方案
 ## 问题理解

 我们给出三个整数边长，`a`,`b`， 和`c`。 任务是确定这三个线段是否可以是非退化三角形的边。 所需的输出是`VALID`当他们可以形成这样一个三角形并且`INVALID`否则。 官方问题使用单个测试用例，没有测试用例计数。 

对于三个正边长，三角形不等式表示每条边必须严格短于其他两条边的总和：`a + b > c`,`a + c > b`， 和`b + c > a`。 

输入很小：只有三个数字，因此即使是恒定数量的算术运算也足够了。 没有大的`n`这将使二次或三次算法变得相关。 因此，一秒的时间限制和 256 MB 的内存限制远远超出了必要的范围。 

粗心的实施可能会导致平等失败。 例如，与```
1 2 3
```答案是```
INVALID
```因为`1 + 2 = 3`。 这三段只能构成一条直线，不能构成非退化三角形。 使用`>=`而不是`>`方向错误可能会无意中接受这种情况。 

另一个边缘情况是明显占主导地位的一方：```
1 5 1
```答案是```
INVALID
```因为`1 + 1 < 5`。 两个短边无法达到足够远以闭合形状。 这是第一个官方样本。 

当长度为正时，等边完全有效。 例如，```
5 5 5
```产生```
VALID
```因为每一对的总和为`10`，它严格大于剩余边。 假设所有三个长度必须不同的解决方案是不正确的。 

## 方法

 最直接的方法是从字面上检查定义。 我们评估所有三个三角形不等式，`a + b > c`,`a + c > b`， 和`b + c > a`，并在这三个都为真时准确接受。 这是正确的，因为三角形不等式对于三个正长度形成非退化三角形来说既是必要的又是充分的。 最坏的情况恰好执行三个加法和三个比较，然后执行恒定量的布尔逻辑。 

我们可以通过观察只需要检查最大的边来进一步简化相同的推理。 假设三个长度排序为`x <= y <= z`。 自从`z`是最大的一边，潜在困难的不等式是`x + y > z`。 另外两个不等式自动成立，因为`z >= y`和`z >= x`，而所有边长均为正值。 因此，问题就简化为找到最大的边并检查其他两侧的总和是否严格大于它。 

因为只有三个值，所以排序也需要常数时间。 在 Python 中，对三个整数进行排序实际上是一项持续的工作，并且生成的代码很紧凑并且可以防止排序错误。 

蛮力方法和最优方法具有以下成本。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(1) | O(1) | O(1) | O(1) | 已接受 |
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 这里的区别与渐近复杂性无关。 这两种方法都足够快。 优化的公式更可取，因为它揭示了三角不等式的数学结构，并将三个单独的条件减少为一个。 

## 算法演练

 1.读取三边长`a`,`b`， 和`c`。 只有一个测试用例，因此不需要外部测试用例循环。 
2. 找到三个长度中最大的一个并称其为`z`。 剩下的两个长度分别是`x`和`y`。 
3. 检查是否`x + y > z`。 这是唯一一个一旦边已排序就可能失败的三角形不等式，因为`z`是最难满足的一面。 
4. 打印`VALID`如果不等式为真。 否则打印`INVALID`。 比较必须严格，因为相等会产生退化直线而不是三角形。 

### 为什么它有效

 将侧面订购为`x <= y <= z`，考虑涉及较小边的两个不等式。 自从`x`和`y`是积极的，`y + z > x`自动为真，因为`z >= x`并添加积极的`y`使左侧严格变大。 相似地，`x + z > y`自动为真，因为`z >= y`和`x`是积极的。 唯一包含右侧最大边的不等式是`x + y > z`。 因此，检查这个单一条件相当于检查所有三个三角形不等式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, b, c = map(int, input().split())

x, y, z = sorted((a, b, c))

if x + y > z:
    print("VALID")
else:
    print("INVALID")
```输入行的读取方式为`input`，即使输入只有三个整数，也遵循所需的快速 I/O 模式。`map(int, ...)`将三个标记直接转换为整数。 

分选产品`x <= y <= z`，这使得`z`最大的一面。 那么唯一不平凡的条件是`x + y > z`。 

严格的`>`比较是必要的。 和`1 2 3`，表达式变为`1 + 2 > 3`，这是错误的，正确产生`INVALID`。 使用`>=`会错误地接受退化三角形。 

Python 整数不会溢出，所以加法`x + y`即使对于非常大的整数输入也是安全的。

 ## 边缘情况

 平等案例`1 2 3`通过将值排序来处理`1, 2, 3`和测试`1 + 2 > 3`。 比较是错误的，因为两侧仅等于第三侧。 程序打印出`INVALID`，正确拒绝退化形状。 

占主导地位的案件`1 5 1`变成`1, 1, 5`。 该算法计算`1 + 1 = 2`， 所以`2 > 5`是假的并且打印`INVALID`。 不需要单独检查其他两个不等式，因为最大的一边已经已知。 

对于所有平等的情况`5 5 5`，排序没有任何改变。 算法检查`5 + 5 > 5`，这是正确的，所以答案是`VALID`。 相等的长度并不是特殊的失效条件。 

输入`4 5 6`演示有效案例。 排序后，`4 + 5 = 9`， 和`9 > 6`成立。 算法打印`VALID`，其余的不平等是由以下事实保证的：`6`是最大的积极面。 

最后，带有边的大输入`10^18`,`10^18`， 和`1999999999999999999`提供有用的边界检查。 较小边的总和恰好是`2000000000000000000`，它大于最大的并排`1`，所以输出是`VALID`。 Python 的任意精度整数使计算安全，无需任何特殊的溢出处理。
