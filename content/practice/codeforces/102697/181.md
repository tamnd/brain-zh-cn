 ## 问题理解

 我们正好给出了三个整数，代表序列的三个位置。 任务是判断序列是否严格递增。 换句话说，第一个值必须小于第二个值，第二个值必须小于第三个值。 

输出是`SORTED`当两个比较都成立时。 如果任一比较失败，包括两个相邻值相等的情况，则输出为`UNSORTED`。 官方的问题有 1 秒的时间限制和 256 MB 的内存限制，输入中只有三个整数。 

由于序列始终包含恰好三个值，因此不存在有意义的大输入性能问题。 任何恒定时间解决方案都在限制范围内，甚至基于通用排序的解决方案也足够快。 更有用的算法观察是排序是不必要的：所需的条件直接表述为两个严格的不等式。 

主要的边缘情况是平等。 例如，```
6 6 7
```必须产生```
UNSORTED
```因为第一个值并不严格小于第二个值。 粗心的实现使用`<=`而不是`<`会错误地接受这个序列。 这也是官方的第二个样品。 

另一种边缘情况是仅在第二次比较时减少的序列。 例如，```
1 5 3
```必须产生```
UNSORTED
```虽然`1 < 5`为真，条件`5 < 3`是假的。 仅检查第一对将默默地接受无效序列。 

相反的情况也是可能的：```
5 2 8
```必须产生```
UNSORTED
```因为第一次比较已经失败了。 一旦所需的不等式为假，则无需检查第三个值。 

## 方法

 一种简单的暴力方法将生成三个值的所有可能的排序，并寻找递增的排列。 只有`3! = 6`排列，因此这将执行恒定数量的操作，并且如果仔细实施的话将是正确的。 然而，对于这个特定问题，它解决了一个比必要的更普遍的问题。 没有输入大小阈值，因为值的数量固定为三个，所以这种强力变得太慢。 在通用版本中`n`值，同样的策略需要`n!`排列，达到`3,628,800`可能性已经在`n = 10`并很快变得无法使用。 

更直接的方法是从字面上阅读排序顺序的定义。 顺序`[a, b, c]`严格增加恰好当`a < b`和`b < c`。 我们可以直接测试这两个条件并打印相应的结果。 这两种方法对于实际问题来说都是常数时间的，但直接比较没有不必要的工作，并且准确地表达了所需的条件。

 | 蛮力 | O(3!) = O(1) | O(3!) = O(1) | O(1) | O(1) | 已接受，但没有必要 |

 ## 算法演练

 1.读取三个整数`a`,`b`， 和`c`。 它们是必须检查顺序的值。 
2、测试是否`a < b`和`b < c`。 两个比较都必须为真，因为该问题需要严格的递增顺序，而不是非递减顺序。 
3. 打印`SORTED`如果两个比较都为真。 否则打印`UNSORTED`。 一次失败的比较就足以拒绝该序列。 

### 为什么它有效

 该算法精确检查定义长度为 3 的严格递增序列的两个条件。 如果两者都`a < b`和`b < c`保持，每个连续的对都按所需的顺序排列，因此整个序列已排序。 如果任一条件失败，则至少有一个连续的对违反了严格排序，因此无法对序列进行排序。 平等被正确拒绝，因为`<`被使用而不是`<=`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b, c = map(int, input().split())

    if a < b and b < c:
        print("SORTED")
    else:
        print("UNSORTED")

if __name__ == "__main__":
    solve()
```输入行被读取一次并分成三个整数值。 由于问题只包含一个测试用例，因此不存在测试用例循环。 

该条件使用由以下连接的两个比较`and`。 仅当两个不等式都成立时，Python 才会将其评估为 true，符合严格递增顺序的数学定义。 使用`<=`这将是一个离一式的逻辑错误，因为此问题不认为相等的相邻值已排序。 

不需要排序操作，也不需要额外的数据结构。 Python 整数也具有任意精度，因此无论输入允许的大小如何，都不存在整数溢出问题。

 ## 边缘情况

 平等案例`6 6 7`被处理是因为第一个比较的计算结果是`6 < 6`，这是错误的。 算法立即选择`UNSORTED`。 非严格比较，例如`6 <= 6`会产生错误的结果，因此操作员的选择至关重要。 

案例`1 5 3`演示为什么必须检查两个相邻对。 第一个比较，`1 < 5`，成功，但第二个比较，`5 < 3`，失败。 该算法结合了这两个条件`and`，所以它正确打印`UNSORTED`。 

案例`5 2 8`第一次比较时练习失败。 自从`5 < 2`为 false 时，无论第三个元素的值如何，完整序列都不能递增。 该算法仍然正确评估完整的布尔表达式并打印`UNSORTED`。 

最后，`1 2 3`证明了产生的唯一情况`SORTED`：两个相邻的比较都是正确的。 该算法不要求值有任何特定的差异，只要求连续元素之间的严格排序。
