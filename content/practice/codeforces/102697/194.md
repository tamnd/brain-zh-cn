 ## 解决方案
 ## 问题理解

 我们给定了一个上限`m`， 和`m < 10^6`，并且需要构造最好的RSA公钥`(n, e)`在这个界限之下。 模数`n`必须是半素数，这意味着在计算重数时它恰好有两个素数因子。 因此`4 = 2 × 2`,`6 = 2 × 3`， 和`25 = 5 × 5`是有效的，同时`12 = 2 × 2 × 3`不是。 指数`e`必须满足`1 < e < n`,`e <= m`， 和`gcd(n, e) = 1`。 在所有有效键中，我们首先最大化`n`，然后最小化`e`。 原来的问题仅指定`m`是正数，但有效密钥首先存在于`m = 4`，因此预期的测试数据必然具有足够大的`m`。 

一百万以下的界限是核心算法线索。 在最坏的情况下，直接分解每个候选者的成本太高。 通过试除法测试一个数字大约需要大约`sqrt(m)`除数检查，对大量候选人进行除数检查，大致得出`O(m sqrt(m))`工作。 在`m = 10^6`，那就是数亿次试划分的量级，不适合一秒的限制。 该问题只有一个输入值，因此我们可以在整个范围内进行预处理。 官方限制为 1 秒和 256 MB。 

有几种小情况可能会欺骗仅基于奇偶校验的解决方案。 例如，使用输入`4`，答案是`4 3`。 数量`4`是`2 × 2`， 但`e = 2`与它不互质，所以第一个有效指数是`3`。 有输入`6`，答案是`6 5`。 这里两个`2`和`3`划分`6`，所以两者都不能用作`e`;`5`是第一个有效的选择。 一个粗心的实现总是使用`3`对于甚至`n`会错误输出`6 3`。 

另一个边缘情况是素数的平方。 用于输入`25`，答案是`25 2`， 因为`25 = 5 × 5`恰好有两个素因数并且`2`与它互质。 需要两个不同素因子的因子计数例程会错误地拒绝`25`。 该定义明确允许两个素因数相等。 

这些样本还说明了为什么在选择之前必须找到最大的半素数`e`。 用于输入`197`，最大有效`n`是`194 = 2 × 97`, 给予`e = 3`。 选择较小的奇半素数仅仅是因为它具有方便的指数`2`会违反主要优化标准。 

## 方法

 最简单的解决方案是从`m`并向下移动。 对于每位候选人`n`，我们可以通过重复尝试除数来测试它是否是半素数`sqrt(n)`并计算素因数。 遇到的第一个半素数必然是最大可能的`n`，因为每个较大的值都已被拒绝。 一次`n`是固定的，我们可以测试一下`e = 2, 3, 4, ...`直到找到一个与`gcd(n, e) = 1`。 这是正确的，因为这两个选择都是完全按照所需的优先级顺序做出的。 

问题在于重复因式分解。 在最坏的情况下，测试附近的每个候选人`10^6`需要最多`sqrt(10^6) = 1000`各试除数。 对一定范围内的大小进行求和`m`，工作大约是`1 + sqrt(2) + ... + sqrt(m) = O(m sqrt(m))`,

 这是关于`6.7 × 10^8`除数检查何时`m = 10^6`，忽略额外的循环和算术开销。 这远远超出了一秒 Python 解决方案应该尝试的范围。 

关键的观察是我们不需要从头开始分解任何单个大数。 我们对每个候选人提出的唯一问题是它有多少个质因数，计算重数。 由于所有候选者最多为一百万，因此我们可以使用筛子计算整个范围的信息。 

表示信息的一种特别方便的方法是`Omega(n)`，质因数的总数`n`具有多样性。 例如，`Omega(12) = 3`因为`12 = 2 × 2 × 3`， 尽管`Omega(25) = 2`因为`25 = 5 × 5`。 正是这些数字`Omega(n) = 2`是半素数。 

我们可以首先使用埃拉托斯特尼筛来识别每个素数。 对于每个素数`p`, 每个倍数`p`至少包含一个因素`p`，所以我们加一`Omega`对于所有的倍数`p`。 计算重复的副本`p`，我们重复相同的操作`p^2`,`p^3`， 等等。 因此一个数可以被`p^k`每人收到一份贡献`p`,`p^2`, ...,`p^k`，完全匹配的指数`p`在其因式分解中。 

预处理后，从`m`直到`Omega[n] == 2`立即给出最大的有效模数。 

还有一个有用的结构快捷方式`e`。 如果`n`是奇数，那么`2`自动互质于`n`，所以最小可能的指数是`2`。 如果`n`是偶数，半素数必定是`2p`。 通常`3`互质于`n`， 所以`e = 3`。 唯一的例外是`n = 6`，其中两者`2`和`3`划分`n`， 所以`e = 5`。 这也处理`n = 4`， 在哪里`3`是有效的。 由于半素数不能有两个以上素数因子，因此没有其他情况。 

蛮力之所以有效，是因为它直接检查定义，但当对许多候选者重复相同的昂贵因式分解时，它就会失败。 观察到上限仅为`10^6`让我们对整个范围的因子计数进行一次筛选，将搜索转向`n`成线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |`O(m sqrt(m))`|`O(1)`| 太慢了 |
 | 最佳|`O(m log log m)`|`O(m)`| 已接受 |

 ## 算法演练

 1. 阅读`m`并分配一个质数筛和一个字节数组`omega`为以重数计算的质因数的数量。 
2. 运行埃拉托色尼筛至`m`。 经过筛子后仍标记为素数的数字正是可以为后面的数字提供因子的素数。 
3. 对于每个素数`p`，访问所有倍数`p`并将其因子计数加一。 然后访问多个`p^2`,`p^3`，以及更高的权力，而他们至多`m`，在每一次幂上再添加一个。 这会计算每次出现的情况`p`进行因式分解，而不仅仅是计算不同的素因数。 
4. 开始于`n = m`，向下移动直到`omega[n] == 2`。 这是从顶部遇到的第一个半素数，因此它必然是允许的最大值`n`。 
5. 选择`e`从这个半素数的结构。 如果`n`是奇怪的，使用`e = 2`。 如果`n`是偶数并且可被`3`，那么在这种情况下唯一可能的半素数是`n = 6`，所以使用`e = 5`。 否则使用`e = 3`。 
6. 打印`n`和`e`。 所选指数小于`n`，至少是`2`，并且互质于`n`。 

为什么它有效：`omega[x]`正是质因数的个数`x`，计算重复因素。 因此`omega[x] == 2`当且仅当`x`是问题定义下的半素数。 向下扫描因此返回最大的有效模数。 对于奇数半素数，`2`不能与其共享素因数。 对于偶数半素数，`n = 2p`; 如果`p != 3`， 然后`3`互质于`n`， 尽管`n = 6`需要`5`。 这些是每种情况下可能的最小有效指数，因此所得的对满足两个优化标准。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    m = int(input())

    # Sieve of Eratosthenes.
    is_prime = bytearray(b'\x01') * (m + 1)
    if m >= 0:
        is_prime[0] = 0
    if m >= 1:
        is_prime[1] = 0

    p = 2
    while p * p <= m:
        if is_prime[p]:
            start = p * p
            count = (m - start) // p + 1
            is_prime[start:m + 1:p] = b'\x00' * count
        p += 1

    # omega[x] = total number of prime factors of x,
    # counting multiplicity.
    omega = bytearray(m + 1)

    for p in range(2, m + 1):
        if not is_prime[p]:
            continue

        power = p
        while power <= m:
            for x in range(power, m + 1, power):
                omega[x] += 1

            if power > m // p:
                break
            power *= p

    # Find the largest semiprime.
    n = m
    while n >= 4 and omega[n] != 2:
        n -= 1

    # Find the smallest valid e.
    if n & 1:
        e = 2
    elif n % 3 == 0:
        # The only even semiprime divisible by 3 is 6.
        e = 5
    else:
        e = 3

    print(n, e)

if __name__ == "__main__":
    solve()
```第一部分构建素性筛。 切片分配标记了从以下位置开始的已发现素数的所有倍数`p * p`，这是标准优化，因为较小的倍数已经具有较小的素因数。 

这`omega`数组使用`bytearray`因为一百万以下的数不可能有很多质因数。 通过重复乘以得到最大可能的值`2`，所以如下`20`。 一个字节就足够了，并且内存使用量非常小。 

对于每个素数`p`，循环结束`power = p, p^2, p^3, ...`这就是它与不同质因数筛选的区别。 例如，当`p = 2`, 数量`12`被访问于`2`,`4`，而不是`8`，所以它收到了来自素数的两个贡献`2`。 素数`3`贡献一次，给予`omega[12] = 3`。 

向下搜索正好开始于`m`，因为主要目标是最大化`n`。 条件`omega[n] == 2`直接编码半素数定义，包括正方形，例如`25`。 

指数选择避免了通用 GCD 循环。 对于奇数`n`,`e = 2`始终有效。 对于甚至`n`，半素数的形式为`2p`。 如果它能被整除`3`， 然后`p = 3`和`n = 6`， 制作`5`第一个有效指数。 否则`3`互质于`n`。 在每种情况下所选择的`e`严格小于`n`。 

## 工作示例

 对于示例 1，输入为`197`。 最大的半素数等于或小于`197`是`194 = 2 × 97`。 因为它是偶数但不能被整除`3`，最小有效指数是`3`。 

|`n`|`omega[n]`| 行动|
 | ---| ---| ---|
 | 197 | 197 1 | 总理，拒绝|
 | 196 | 196 4 |`2 × 2 × 7 × 7`, 拒绝 |
 | 195 | 195 3 |`3 × 5 × 13`, 拒绝 |
 | 194 | 194 2 |`2 × 97`, 接受 |

 找到后`n = 194`，指数候选者开始于`2`， 但`gcd(194, 2) != 1`。 下一个候选人是`3`， 和`gcd(194, 3) = 1`，所以输出是`194 3`。 

该跟踪表明最大化`n`优先于最小化`e`。 即使许多较小的奇数半素数可以使用`e = 2`，没有一个可以替代`194`。 

对于示例 2，输入为`259`。 数字本身是`7 × 37`，所以它已经是半素数了。 

|`n`|`omega[n]`| 行动|
 | ---| ---| ---|
 | 259 | 259 2 |`7 × 37`, 接受 |

 因为`259`是奇数，`2`自动与它互质，给出输出`259 2`。 

该跟踪演示了最直接的情况：当`m`已经是半素数了，扫描根本不需要移动，奇数模数立即得到尽可能小的指数。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |`O(m log log m)`| 素数筛和素数功率因数计数需要近线性筛选工作，然后是线性向下扫描。 |
 | 空间|`O(m)`| 素性和`omega`数组每个包含`m + 1`条目。 |

 和`m < 10^6`，对于基于筛子的解决方案来说，预处理范围足够小。 使用`bytearray`使实际内存占用量远低于 256 MB 限制，并且该算法避免了重复因式分解所需的数亿次试除法。 一秒限制与近线性筛一致，而每个数字的平方根分解则不然。

 ## 边缘情况

 对于`m = 4`，输入已经是具有有效密钥的最小可能情况。 因子数为`omega[4] = 2`， 因为`4 = 2 × 2`，因此扫描立即停止。 自从`4`是偶数并且不能被整除`3`，算法选择`e = 3`。 输出是`4 3`。 需要两个不同质因数的解决方案将错误地拒绝该模数。 

为了`m = 6`，扫描再次立即停止，因为`6 = 2 × 3`和`omega[6] = 2`。 通常的偶数规则无法选择`3`， 因为`gcd(6, 3) = 3`， 和`2`也无效。 特殊情况检测到`6 % 3 == 0`并选择`e = 5`。 输出是`6 5`。 这是通用偶数规则需要额外例外的唯一半素数。 

为了`m = 25`，算法发现`25 = 5 × 5`，因此重复因子计数正确给出`omega[25] = 2`。 因为`25`是奇数，`2`与它互质，并且是可能的最小指数。 输出是`25 2`。 这证实了筛子计算的是多重性，而不仅仅是不同的素数。 

为了`m = 197`，值`197`,`196`， 和`195`被拒绝，因为它们的因子计数是`1`,`4`， 和`3`， 分别。 在`194`，计数变为`2`， 自从`194 = 2 × 97`。 算法到此为止，证明没有跳过更大的有效模数。 自从`194`是偶数并且不能被整除`3`,`e = 3`被选择，给出`194 3`，完全符合样品的要求。
