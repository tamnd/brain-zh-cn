 ## 解决方案
 ## 问题理解

 当一个数因式分解中出现的每个质因数都是 2 或 3 时，该数被称为令人满意的数。同样，该数必须具有以下形式

 [
 2^a3^b
 ]

 对于一些非负整数 (a) 和 (b)。 值 1 也符合条件，因为它根本没有素因数。 

例如，18 令人愉悦，因为 (18=2\cdot3^2)，而 35 则不令人愉悦，因为 (35=5\cdot7)。 任务只是判断给定的正整数是否具有这个属性并打印`YES`或者`NO`。 原始问题有一个整数输入，具有 (n\le1000)、1 秒时间限制和 256 MB 内存限制。 

1000 的界限使得即使是简单的试除解决方案也足够快。 检查每个可能除数的循环最多执行约 1000 次迭代，因此不需要高级数论。 尽管如此，还是有一个直接遵循定义的更简洁的解决方案：重复删除 2 的每个因数和 3 的每个因数。如果剩下任何大于 1 的东西，则该余数包含一个禁止的质因数。 

在一些小情况下，实施可能会默默地出错。 用于输入`1`，正确的输出是`YES`，因为 1 没有质因数。 坚持找到 2 或 3 中至少一个因子的解决方案会错误地拒绝它。 

用于输入`6`，正确的输出是`YES`，因为 (6=2\cdot3)。 检查该数字是否能被 2 和 3 之一整除的粗心解决方案可能会拒绝该数字，即使这两个因素都被允许。 

用于输入`12`，正确的输出是`YES`，因为 (12=2^2\cdot3)。 必须重复划分，直到没有任何因素为止。 仅除以 2 一次将得到 6，并且可能会错误地得出结论：6 包含不需要的因子。 

用于输入`1000`，正确的输出是`NO`。 我们可以去掉 2 的三个因数，得到 125，但 125 包含素因数 5。仅检查是否能被 2 整除并在找到后停止的解决方案会错误地接受该数字。 

## 方法

 最直接的暴力方法是测试 (n) 是否有除 2 或 3 以外的素数。我们可以尝试从 2 到 (n) 的每个整数 (d)，确定 (d) 是否整除 (n)，如果是，则确定 (d) 是否是素数且不同于 2 和 3。如果存在这样的除数，则答案为`NO`; 否则就是`YES`。 这是正确的，因为每个合数都有一个质因数，因此最终必须发现一个禁止的质因数。 

对于 (n=1000)，这种强力方法最多需要 999 个除数检查，加上用于这些除数的任何素性工作。 这已经完全在限制范围内，因此这个问题实际上不需要优化即可接受。 

更有用的观察是，我们不需要一一发现素因数。 定义表明每个因素都必须是 2 或 3，因此我们可以准确删除这些因素并检查剩下的因素。 从 (n) 开始，尽可能重复除以 2，然后尽可能重复除以 3。 如果最终值为 1，则整个因式分解由 2 和 3 组成。 如果最终值大于 1，则剩余值必须至少包含一个除 2 或 3 之外的质因数。 

暴力破解之所以有效，是因为它明确地搜索禁止因素，但未能使用允许因素的特殊结构。 观察到唯一允许的素数是 2 和 3，让我们可以直接去掉这些因子，从而将工作减少到对数倍数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) 除数检查，如果测试素数则需要额外工作 | O(1) | O(1) | 已接受 (n\le1000) |
 | 最佳| O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取正整数（n）。 我们保留数字本身，而不是构建其完整的素因数分解，因为只有禁止因子的存在才重要。 
2. 当(n)能被2整除时，将其除以2。每次这样的除法都会删除一个允许的质因数，并且不能改变原始数字是否令人满意。 
3. 当 (n) 能被 3 整除时，将其除以 3。重复该操作将删除所有剩余的允许因数 3。 
4. 检查剩余金额。 如果正好是 1，则原数的每个质因数都是 2 或 3，所以打印`YES`。 否则，除了 2 或 3 之外的其他因子仍然存在，因此打印`NO`。 

为什么有效：在前两个循环之后，当前值没有 2 的因数，也没有 3 的因数。之前执行的每次除法都只删除了允许的因数。 如果剩余的值大于1，它的质因数分解必须包含除2或3以外的质数，这使得原始数字不那么令人愉快。 如果剩余值为1，则除了2和3的因子之外不需要任何因素来构造原始数字，因此该数字是令人满意的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

while n % 2 == 0:
    n //= 2

while n % 3 == 0:
    n //= 3

print("YES" if n == 1 else "NO")
```第一个循环删除所有出现的质因数 2。它必须是`while`循环而不是`if`，因为像 16 这样的数字包含 2 的四个因数。 

第二个循环对 3 执行相同的操作。这两个循环的顺序不会影响结果，因为素数因子的乘法是可交换的，因此 2 和 3 的所有因子都可以按任一顺序删除。 

最终与1的比较是关键的边界条件。 达到 1 意味着不再有任何禁忌。 特别是，输入`1`不进入任何循环并立即被接受。 

Python整数在这里不存在溢出问题，并且输入界限只有1000。实现也不需要数组或辅助数据结构。

 | ---| ---| ---| ---|

### 示例 2

 对于输入`35`，2 和 3 都不能整除这个数。 

| 步骤| (n) 之前 | 运营| (n) 之后|
 | ---| ---| ---| ---|
 | 1 | 35 | 35 不能被 2 整除 | 35 | 35
 | 2 | 35 | 35 不能被 3 整除 | 35 | 35

 输出是`NO`。 剩下的 35 个质因数为 5 和 7，这两个质因数都是被禁止的。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(log n) | 每次成功的除法都会使值至少减少 2 倍。 
| 空间| O(1) | O(1) | 仅存储整数 (n)。 |

 对于 (n\le1000)，成功除法的数量很少，对于因数 2 的除法加上相应的因数 3 的除法最多至多 (O(\log_2 1000))。 该解决方案远低于 1 秒的时间限制，并且使用常量内存。 

## 测试用例```python
import sys
import io

def solve():
    input = sys.stdin.readline
    n = int(input())

    while n % 2 == 0:
        n //= 2

    while n % 3 == 0:
        n //= 3

    print("YES" if n == 1 else "NO")

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()
    result = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return result

assert run("18\n") == "YES\n", "sample 1"
assert run("35\n") == "NO\n", "sample 2"

assert run("1\n") == "YES\n", "1 has no prime factors"
assert run("2\n") == "YES\n", "single allowed factor"
assert run("72\n") == "YES\n", "72 = 2^3 * 3^2"
assert run("1000\n") == "NO\n", "1000 = 2^3 * 5^3"
assert run("999\n") == "NO\n", "999 has a forbidden factor"
assert run("648\n") == "YES\n", "648 = 2^3 * 3^4"
```| 测试输入| 预期产出 | 它验证了什么 |

 ## 边缘情况

 输入`1`是最重要的特殊情况。 该算法从 (n=1) 开始，因此跳过两个整除循环。 最终值已经是 1，产生`YES`。 这符合数学定义，因为 1 没有素数因子，因此它不包含任何禁止素数。 

用于输入`6`，执行过程是`6 -> 3`去除因子 2 后，接着是`3 -> 1`去除因子 3 后，输出为`YES`。 这证实了两个允许的素数是完全有效的。 

用于输入`12`，执行过程是`12 -> 6 -> 3 -> 1`。 第一个循环删除 2 的两个因子，然后第二个循环删除 3 的因子。结果是`YES`，说明为什么每个可分性测试必须重复而不是只执行一次。 

用于输入`1000`，因子 2 循环产生`1000 -> 500 -> 250 -> 125`。 Factor-3 循环不做任何改变，因为 125 不能被 3 整除。由于 125 大于 1，算法打印`NO`。 幸存值包含禁止素数5，因此拒绝是正确的。 

用于输入`35`，两个循环都不会更改该值。 它仍然是 35，大于 1，所以输出是`NO`。 这是最简单的情况，其中从一开始就存在禁止素因数。
