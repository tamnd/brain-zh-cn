 ## 解决方案
 ## 问题理解

 该问题要求我们计算篮球运动员当前每场比赛的得分。 输入给出迄今为止得分的总分以及迄今为止进行的比赛总数。 所需的输出是一场比赛中得分的平均得分，计算方式为得分除以场数。 

约束足够小，算法挑战不在于效率，而在于正确执行计算。 由于仅处理两个整数，因此即使恒定时间解也绰绰有余。 主要关注的是保持除法的精度。 整数除法会丢弃小数部分，因此必须使用浮点运算来完成计算。 

最常见的错误是将值视为整数或不必要地格式化答案。 例如，如果输入是：```
78
7
```正确的输出是：```
11.142857142857142
```使用整数除法的粗心实现会输出`11`，完全丢失小数部分。 

另一个边缘情况是积分数量小于游戏数量。 例如：```
5
10
```正确的输出是：```
0.5
```假设答案始终大于 1 或将结果转换回整数的实现将产生不正确的值。 

## 方法

 直接的暴力方法会尝试模拟游戏并在计算平均值之前计算每场游戏的分数。 这种方法是不必要的，因为问题已经提供了总分和总比赛数。 如果有很多游戏，模拟每个游戏将需要存储或处理输入中不存在的信息，并且不会改善结果。 

关键的观察结果是每场比赛的得分只是两次总得分的比率。 没有隐藏的结构可供发现，无需搜索，也无需迭代。 整个任务简化为读取两个数字并执行一次浮点除法。 

暴力破解的想法失败了，因为它解决的问题比所需的更详细。 只有最终总数才重要的观察结果让我们可以用单个算术运算代替任何模拟。

 ## 算法演练

 1. 读取玩家的总得分并将其存储为整数。 读取所玩游戏的总数并将其存储为另一个整数。 这两个值包含计算所需的所有信息。 
2. 使用浮点除法将总分除以总比赛数。 除法必须保留小数部分，因为每场比赛的分数不一定是整数。 
3. 直接打印结果值。 所需的输出接受正常的浮点表示，因此不需要手动舍入。 

为什么它有效：

 每场比赛得分的定义是总得分除以比赛总场次。 该算法使用两个给定的总计来精确执行此操作。 由于没有其他信息影响平均值，因此计算值始终是所需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    p = int(input())
    g = int(input())
    print(p / g)

if __name__ == "__main__":
    solve()
```该解决方案分别读取两个输入值，因为每个值都出现在自己的行上。 表达式`p / g`与整数除法不同，使用 Python 的浮点除法，因此保留小数点后的值。 

溢出不需要特殊处理，因为 Python 整数可以增长超出固定的整数限制，并且计算仅使用两个数字。 该程序还避免格式化答案，因为法官接受 Python 生成的标准十进制表示形式。

## 测试用例```python
import sys
import io

def solution(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    try:
        p = int(sys.stdin.readline())
        g = int(sys.stdin.readline())
        return str(p / g) + "\n"
    finally:
        sys.stdin = old_stdin

 ## 边缘情况

 当分数不能被比赛场数整除时，答案包含小数部分。 对于输入：```
78
7
```该算法计算`78 / 7`作为浮点除法并打印完整的十进制值。 整数除法实现会错误地丢失小数部分。 

当玩家的得分少于所参加的比赛时，平均值可能会小于 1。 对于输入：```
5
10
```该算法计算`5 / 10`, 给予`0.5`。 它并不假设答案必须大于 1，因此结果仍然正确。 

当总数相等时，除法恰好产生一。 对于输入：```
100
100
```算法输出`1.0`。 这证实了相同的计算适用于整数答案和小数答案。
