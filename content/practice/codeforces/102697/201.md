 ## 解决方案
 ## 问题理解

 这里的 Ken Ken 板始终是 5 x 5 网格。 每个单元格必须包含 1 到 5 之间的整数，并附加拉丁方条件，即行或列中没有数字重复。 

板上分为笼子。 笼子是一组连接的单元，其按读取顺序的第一个单元包含目标和操作。 将单细胞笼简单地固定在该目标上。 对于较大的笼子，加法和乘法适用于笼子中的所有细胞，而减法和除法仅适用于恰好两个细胞。 对于减法，只要绝对差等于目标，任一顺序都是有效的。 对于除法，只要较大的值除以较小的值等于目标，任何一种排序都是有效的。 

输入有点不寻常，因为笼结构被编码为 ASCII 绘图。 每个单元格在该图中占据 2 x 2 的位置。 一个垂直的`|`两个牢房之间意味着牢房是分开的，而缺少垂直墙则意味着它们属于同一个笼子。 同样的想法也适用于水平方向`-`。 操作文本出现在每个笼子最上面、然后最左边的单元格内。 

输出是完整的 5 x 5 网格。 由于每个值都在 1 到 5 之间，因此每行可以直接打印为五位数字。 

固定尺寸为`n = 5`极大地改变了算法的权衡。 对 25 个单元格进行一般拉丁方搜索最多可达`5^25`作业，大致是`3 × 10^17`，所以盲目枚举板子是不可能的。 同时，每个单元格的域仅包含五个值，而一个笼子最多包含25个单元格。 这使得基于约束的回溯变得实用，特别是当有足够的信息可用时立即检查笼算法时。 

有几个细节可能会使天真的实现默默地变得错误。 减法笼是无序的。 例如，描述的笼子`2-`可以包含`1,3`或者`3,1`，所以只检查`a - b == 2`会拒绝有效的解决方案。 同样，一个`2/`笼子接受`1,2`,`2,1`,`2,4`， 和`4,2`; 仅检查第一个单元格除以第二个单元格是错误的。 

笼子还可以包含重复值。 例如，三单元`6+`笼子可以合法容纳`1,2,3`或者`2,2,2`。 拉丁约束适用于行和列，而不适用于笼子。 强制笼子内的所有单元都不同的实现可能会拒绝有效的解决方案。 

最后，笼子可以跨越多行或多列，并且不需要是矩形的。 连接的 L 形保持架有效。 例如，第一个样本包含笼子，其单元格通过缺失的墙壁连接，而不是简单地连续间隔。 将每个视觉上的矩形区域视为一个笼子会构造错误的约束。 

## 方法

 最直接的暴力解决方案为每个空单元分配五个值之一，并在构建完整的板后检查拉丁方和笼条件。 这是正确的，因为最终会考虑所有可能的棋盘，并且第一个有效的棋盘就是一个解决方案。 问题在于搜索空间：25 个单元格，每个单元格有 5 个选项`5^25 = 298,023,223,876,953,125`使用约束之前可能的分配。 

自然的改进是将问题转化为约束搜索。 一旦分配了值，行和列就会立即限制其他单元格可用的值。 更重要的是，笼操作给出了另一个约束，通常可以在笼完成之前很久就拒绝部分分配。 

对于加法笼，可以将部分总和与仍然可实现的最小和最大总和进行比较。 对于乘法笼来说，同样的想法也适用于乘积。 假设一个`12+`笼子有五个单元格，前三个单元格当前总和为 10。其余两个单元格的总和必须恰好为 2，这是不可能的，因为每个单元格至少为 1。我们可以立即停止探索该分支。 

对于减法和除法笼，正好有两个单元，因此在分配两个值时检查操作就足够了。 单例笼子甚至更简单，因为它的值在搜索开始之前是固定的。 

由此产生的搜索在技术上仍然是指数级的，但在经过强力修剪的小域中它是指数级的。 蛮力之所以有效，是因为检查每个板在逻辑上就足够了，但会失败，因为几乎所有板都在许多不相关的任务之后才被拒绝。 观察到行、列和笼子可以拒绝部分分配，这让我们可以在这些分支变得不可能时切断它们。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(5^25)`|`O(25)`| 太慢了|
 | 约束回溯|`O(5^25)`最坏的情况，实际上要小得多|`O(25 + C)`| 已接受 |

 最坏情况的渐近界限仍然是指数的，因为 Ken Ken 是一个约束满足问题。 实际的区别在于，搜索很少达到接近所有内容的程度。`5^25`这些 5 x 5 谜题的作业。 

## 算法演练

 1. 读取 ASCII 板并确定哪些网格单元属于同一笼子。 对于每对水平相邻的单元格，检查相应绘图线上它们之间的字符。 如果没有`|`，合并两个单元格。 对于垂直相邻的单元格，检查水平边界线上它们之间的字符。 如果没有`-`，合并它们。 不相交集并集结构是执行这些合并的便捷方法。 
2. 所有合并后，按 DSU 根对单元进行分组。 每组一个笼子。 按行优先顺序对其单元格进行排序，以便第一个单元格恰好是谜题指定写入操作的单元格。 
3. 从每个笼子的第一个单元格读取操作。 单例笼包含一个固定整数，例如`2`。 多细胞笼包含一个数字，后跟`+`,`x`,`-`， 或者`/`。 将目标和操作与笼子一起存放。 
4. 维护当前棋盘以及每行每列两组。 当赋值给`(r, c)`，如果该值已出现在行中，则立即拒绝它`r`或列`c`。 这会逐步强制执行拉丁方条件，而不是在整个棋盘都被猜出之后。 
5. 跟踪每个笼子的分配值、总和和乘积。 对于加法笼，计算当前总和并将其与其未分配单元格可能的最小和最大总和进行比较。 如果目标位于该区间之外，则该分支不可能工作。 对于乘法笼，执行等效的乘积界。 
6. 当减法或除法笼完成后，直接评估其操作。 对于减法，使用绝对差。 对于除法，首先取较大的值除以较小的值，要求精确的整除性和目标商。 
7. 当笼子完成后，准​​确验证其操作。 这捕获了不能用简单的部分和或乘积界限表示的约束。 
8. 选择下一个未分配的单元格并尝试从 1 到 5 的值。对于这个固定的 5 x 5 问题，行主遍历就足够了，因为每个尝试的值都很便宜，而且笼剪枝很强。 分配值，更新所有受影响的状态，递归，并在分支失败时撤消分配。 
9. 一旦所有 25 个单元都被分配完毕，就停止。 此时，每一行和每一列都是不同的，并且每个笼子都已经通过了其算术约束，因此该板是一个有效的 Ken Ken 解决方案。 

### 为什么它有效

 回溯过程中的不变性是每个分配的单元都满足其行和列约束，并且每个部分分配的笼子仍然能够达到其目标。 当分支被拒绝时，行或列已经包含重复项，笼子无法再达到其算术目标，或者已完成的笼子违反了其操作。 在每种情况下，该分支都没有有效完成，因此修剪它不能丢弃解决方案。 当搜索到达完全分配的板时，不变量给出有效的行和列，同时每个笼子都根据其所需的操作进行检查。 因此，返回的板是一个有效的解决方案。

import sys
import re

input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]

            if wall != '|':

    # are in the same cage.
    for r in range(n - 1):

        for c in range(n):
