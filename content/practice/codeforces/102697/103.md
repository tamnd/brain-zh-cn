 ## 解决方案
 ## 问题理解

 任务是对写成单行文本的多项式进行符号微分。 多项式由以下项组成`5x^5`,`x`,`8x^2`， 或者`10`，相邻项由以下任一分隔`+`或者`-`。 第一项保证不是常数。 

对于一个学期`kx^n`和`n >= 2`，微分将其变为`knx^(n-1)`。 诸如此类的术语`7x`有导数`7`，而常数的导数为零并从所得多项式中消失。 所需的输出是导数，使用相同的间距风格和`+`或者`-`分隔符。 

语句中没有给出明确的最大多项式长度，因此自然目标是输入长度的线性时间。 解决方案应读取表达式一次，识别每个带符号项，解析其系数和指数，对其进行微分，并构造答案。 任何重复重新扫描整个表达式的方法都可能使其长度成二次方，并且是不必要的。 

主要的边缘情况来自术语可以具有的不同文本形式。 系数可以省略，如`x^5`，这意味着系数是`1`。 指数可以省略，如`9x`，这意味着指数是`1`。 一个常数，例如`10`没有`x`根本没有，而且必须消失。 例如，输入`x + 10`有输出`1`，因为导数`x`是`1`并且常数消失。 一个粗心的实现，假设每个术语都包含`x`处理时会失败`10`。 

标志还需要附在正确的术语上。 例如，`5x^2 - 3x`变成`10x - 3`， 不是`10x + 3`。 减法分隔符属于它后面的项，因此仅提取无符号项的解析器可能会默默地丢失符号。 

第二个边界情况是省略系数。 例如，`x^3 + 2x`变成`3x^2 + 2`。 将缺失系数视为零会错误地删除第一项，而处理文本`x`因为数字会导致解析失败。 

最后，常数项可以出现在非常量项之间。 输入`x + 10 + 3x`变成`1 + 3`。 中间的常数一定要去掉，不留多余的`+`，并且必须从幸存的导数项重建输出，而不是通过就地修改原始字符串。 

## 方法

 简单的暴力实现可以重复扫描整个剩余表达式以查找下一个分隔符，提取相应的术语，然后开始另一次扫描下一个术语。 这是正确的，因为每个项最终都会根据幂律被隔离和区分。 问题在于相同的字符会被检查多次。 如果表达式有长度`L`并且有很多短期术语，扫描可以检查大约`1 + 2 + 3 + ... + L = L(L+1)/2`最坏情况下的字符，即 θ(L²)。 

使解决方案变得更简单的观察结果是分隔符已经为我们提供了准确的术语边界。 由于每个分隔符都是`+`或者`-`，将表达式拆分为标记可以让我们仅处理每个术语一次。 我们仍然需要它的符号，但这可以通过分割空格来处理：多项式，例如`5x^5 + 3x^4 - 2x`成为令牌序列`5x^5`,`+`,`3x^4`,`-`,`2x`。 然后我们可以从左到右遍历这些标记，并带有每个项的符号。 

对于每个术语，我们只需要区分两种情况。 如果它不包含`x`，它是一个常数，没有任何贡献。 否则，前面的部分`x`是系数，默认为`1`当为空时，以及之后的部分`x`确定指数，默认为`1`当空的时候。 应用导数规则会产生一个输出项。 常量被简单地跳过。 

结果自然地构建为格式化导数项的列表。 加入该列表`" + "`无法正确保留负项，因此最干净的实现存储每个导数系数及其符号，并从左到右格式化最终表达式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(L²) | O(L) | 对于大型表达式来说太慢 |
 | 最佳 | O(L) | O(L) | 已接受 |

 这里`L`是多项式串的长度。 

## 算法演练

 1. 将完整的多项式作为一行读取，并仅删除尾随的换行符。 表达式内的空格是有意义的，因为它们将术语与它们的含义分开`+`或者`-`运营商。 
2. 用空格分割表达式。 这会产生交替的术语和运算符标记，因为输入保证了每个字符两侧都有空格`+`或者`-`。 
3. 单独处理带有正号的第一项。 该声明保证该项不是常数，因此它的导数肯定会对答案有所贡献。 
4. 对于以下每个运算符和术语对，解释`+`分配`+1`和`-`分配`-1`。 在区分该术语之前将该符号附加到该术语上。 
5. 如果一个术语不包含`x`，跳过它。 这样的项是常数，其导数为零。 
6. 如果一个术语包含`x`，从概念上将其拆分为`x`。 系数是前面的文本`x`，空系数解释为`1`。 指数是后面的文本`x`，空指数解释为`1`。 
7. 将系数乘以指数以获得新系数，然后将指数减一。 对于指数`1`，结果项是常数，因此仅打印其系数。 
8. 忽略任何系数为零的导数项。 在给定的输入保证下，这主要与一般解析逻辑相关，因为第一项不能是常数并且输入系数是普通多项式系数。 
9. 将每个幸存的导数项附加到结果中，同时保留其符号。 第一个幸存的术语打印时没有前导`+`。 
10. 用空格连接格式化的片段并打印结果。 由于第一个原项是非常数，导数至少包含一个非零项，因此不需要特殊`0`需要输出指定的输入格式。 

### 为什么它有效

 不变的是，在处理输入的任何前缀之后，结果列表准确地包含来自该前缀的所有非常量项的导数，以其原始顺序和原始符号。 常数贡献为零并且被正确地省略。 每个非常数项都被解析为它的系数和指数，幂律精确地产生它的数学导数。 由于多项式中的项是独立微分的，因此处理每一项一次就可以准确地给出完整多项式的导数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def differentiate_term(term):
    if 'x' not in term:
        return None

    x_pos = term.index('x')

    coefficient_text = term[:x_pos]
    exponent_text = term[x_pos + 1:]

    coefficient = int(coefficient_text) if coefficient_text else 1
    exponent = int(exponent_text[1:]) if exponent_text.startswith('^') else 1

    new_coefficient = coefficient * exponent
    new_exponent = exponent - 1

    if new_exponent == 0:
        return str(new_coefficient)

    if new_exponent == 1:
        if new_coefficient == 1:
            return 'x'
        return f'{new_coefficient}x'

    if new_coefficient == 1:
        return f'x^{new_exponent}'

    return f'{new_coefficient}x^{new_exponent}'

def solve():
    expression = input().strip()
    tokens = expression.split()

    result = []

    # The first term is guaranteed to be non-constant.
    first = differentiate_term(tokens[0])
    if first is not None:
        result.append((1, first))

    i = 1
    while i < len(tokens):
        sign = 1 if tokens[i] == '+' else -1
        term = tokens[i + 1]

        derivative = differentiate_term(term)

        if derivative is not None:
            result.append((sign, derivative))

        i += 2

    output = []

    for index, (sign, term) in enumerate(result):
        if index == 0:
            if sign == -1:
                output.append('-')
            output.append(term)
        else:
            output.append('+' if sign == 1 else '-')
            output.append(term)

    print(' '.join(output))

if __name__ == "__main__":
    solve()
```这`differentiate_term`函数处理实际的代数。 检查`x`首先将常数与幂项分开。 对于诸如这样的术语`x^5`, 之前的文字`x`为空，所以系数变为`1`。 为了`7x`，之后的文字`x`为空，因此指数变为`1`。 这两个默认值是主要的解析细节，可防止特殊情况在程序的其余部分传播。 

微分后，指数为零意味着结果是常数，因此仅打印系数。 1 的指数表示`^1`不需要符号，因此结果打印为`kx`。 对于较大的指数，通常`kx^n`使用形式。 包含以下项的系数 1 也被省略`x`， 所以`1x^4`变成`x^4`。 

主要功能使用`split()`而不是试图找到`" + "`和`" - "`手动。 由于输入保证每个运算符周围都有空格，因此生成的序列具有可预测的形式 term,operator,term,operator,term。 每次迭代时前进两个标记可以防止运算符被意外解释为术语。 

结果将符号与术语文本分开存储。 这可以避免常量消失时出现格式错误的表达式。 例如，`x + 10 - 3x`生产衍生品`1`和`-3`，并且丢弃的常量永远不会创建不需要的分隔符。 

Python 整数具有任意精度，因此诸如高次项的导数系数之类的系数不会溢出。 该算法仅对每个字符或标记执行恒定量的工作，从而在输入长度中给出线性时间。

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return output

 ## 边缘情况

 第一个边缘情况是单变量项。 对于准确的输入`x`，源中省略了系数，因此解析器分配系数`1`。 指数也被省略，因此它分配指数`1`。 导数变成常数`1`，算法打印`1`。 

第二个边缘情况是两个变量项之间的常数。 为了`7x + 100 + 3x`，第一项产生`7`，常数`100`被跳过，最后一项产生`3`。 结果是`7 + 3`。 由于输出项在格式化之前是独立存储的，因此删除常量不会留下额外的分隔符。 

第三个边缘情况是减法。 为了`5x^2 - 3x - 10`，第一项变为`10x`，第二项变为`-3`，最后的常数消失。 格式化后的结果是`10x - 3`。 该符号是在项之前从运算符标记中读取的，因此即使项从变量表达式变为常量，减法也会保留。 

第四种边缘情况是高次项中的系数为一。 为了`x^5`，解析后的系数为`1`指数是`5`，生产`5x^4`。 格式化程序故意省略系数`1`仅在微分之后，所以输出是`5x^4`而不是看起来无效的`5*1x^4`。 

第五个边缘情况是一个非常大的指数。 为了`300x^200`，计算很简单`300 * 200 = 60000`新的指数是`199`，生产`60000x^199`。 Python 的任意精度整数处理系数时不会出现溢出问题。 

最终的边缘情况是一个包含许多项的长多项式。 该算法从不通过重新扫描先前的字符来搜索下一个分隔符。`split()`识别一次令牌，每个令牌被消耗一次，因此运行时间随着输入长度线性增长。
