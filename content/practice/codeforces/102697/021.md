 ## 问题理解

 该问题描述了一艘气垫船，它从一个角穿过一堆矩形盒子到另一个角。 它飞行的距离是矩形的对角线。 One side length of the rectangle is known, and the task is to find the walking distance needed to go around the outside of the rectangle and reach the hovercraft. 所需的距离是矩形的两条边长之和。 

输入包含对角线长度`n`矩形的和一条边的长度`m`。 输出是添加到的剩余边的长度`m`。 由于对角线、宽度和高度形成直角三角形，因此可以使用毕达哥拉斯定理找到缺失的边。 

约束足够小，主要挑战不是性能而是识别几何关系。 即使值非常大，解决方案仍然只需要恒定数量的算术运算。 任何涉及模拟、搜索可能的边长或迭代距离的方法都将解决比必要的困难得多的问题。 

主要的边缘情况来自于正确处理几何图形。 如果给定的边等于对角线，则输入将描述一个缺少边长为零的矩形，因此盲目地取负值的平方根的粗心实现将会失败。 例如，输入`5 5`给出剩余边为`0`，所以答案是`5.0`。 

另一个常见的错误是返回对角线而不是步行路径。 对于输入：```
10
6
```对角线是`10`，但另一边是`8`，所以步行距离为`6 + 8 = 14.0`。 打印飞行距离的解决方案会产生错误的答案。 

浮点格式是另一个可能的问题。 对于输入：```
14
13
```缺失的一面是`sqrt(27)`，这大约是`5.1961524227`，所以答案大约是`18.1961524227`。 整数运算会失去所需的精度。 

## 方法

 思考问题的强力方法是尝试未知一侧的可能值。 对于每个候选长度`x`，我们可以检查是否`m^2 + x^2 = n^2`。 一旦我们找到有效的一面，我们将其添加到`m`。 这种方法是正确的，因为每个矩形都必须满足毕达哥拉斯定理。 

然而，这种方法是不必要的，而且可能很慢。 如果对角线可能很大，则检查每个可能的边长需要`O(n)`尝试，并且每次尝试都会执行算术检查。 最坏的情况会变得比问题所需的工作量多得多。 

关键的观察结果是矩形的对角线已经为我们提供了所需的确切关系。 三个长度形成一个直角三角形，因此直接确定未知边：$$x^2 + m^2 = n^2$$重新排列给出：$$x = \sqrt{n^2 - m^2}$$蛮力方法之所以有效，是因为它正在寻找满足该方程的值，但该方程已经有直接解。 矩形缩小为直角三角形的观察结果完全消除了搜索。

 ## 算法演练

 1.读取对角线长度`n`和已知边长`m`。 这两个值定义了由矩形的边和对角线形成的直角三角形。 
2. 使用以下方法计算未知边`sqrt(n * n - m * m)`。 减法给出了缺失边的平方，因为对角线是三角形的斜边。 
3.添加已知边`m`和计算边在一起。 绕矩形行走意味着沿着两个垂直的边行走，而不是沿着对角线行走。 
4. 将结果打印为浮点数。 平方根可能不是整数，因此输出必须保留小数精度。 

该算法背后的不变性是对角线始终保持矩形形成的直角三角形的斜边。 计算出的值是缺失边的唯一可能长度，因此将其添加到已知边可以准确地给出到达气垫船的矩形周围的路径。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n = float(input())
    m = float(input())

    other = math.sqrt(n * n - m * m)
    ans = m + other

    print(ans)

if __name__ == "__main__":
    solve()
```该程序将两个长度读取为浮点值，因为最终答案可以包含小数。 尽管该语句将输入描述为正整数，但使用`float`确保平方根运算和输出格式化的实现安全。 

表达式`n * n - m * m`计算未知边的长度平方。 然后求平方根即可得出实际边长。 运算顺序在这里很重要：在减法之前取平方根并不代表几何形状。 

最后的添加使用了矩形的两侧，因为步行路线绕过了一堆盒子。 没有循环、搜索或存储数组，因此实现的大小保持不变。

 ## 边缘情况

 当已知边等于对角线时，剩余边为零。 对于输入：```
5
5
```计算变为`sqrt(25 - 25) = 0`，答案是`5.0`。 该算法自然地处理这个问题，因为它允许平方根为零。 

当矩形的边长不是整数时，解决方案必须避免整数截断。 对于输入：```
14
13
```缺失的一面是`sqrt(27)`， 不是`5`。 该算法保留小数值并返回正确的步行距离。 

当步行距离与气垫船的飞行距离混淆时，错误会出现在简单的情况下。 对于输入：```
10
6
```气垫船行驶了`10`脚对角线行走，但人必须沿着两侧行走：`6 + 8 = 14`。 该算法使用矩形边而不是对角线，因此它返回正确的路线。
