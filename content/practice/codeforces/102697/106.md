 ## 解决方案
 ## 问题理解

 我们有一个`n × m`迷宫。 每个单元格包含一个数字`0`到`9`，代表该细胞的辐射水平。 我们从左上角的单元格开始，需要到达底行。 共享一侧的单元格之间允许移动，因此我们可以向上、向下、向左或向右移动。 

路径的成本不是辐射水平的总和。 相反，它是该路径上任何地方遇到的最大值。 我们需要最大像元值尽可能小的路径，并输出最小可能的最大值。 

这些约束使图形解释变得有用。 两个都`n`和`m`在下面`100`，所以少于`10,000`细胞。 穿越整个迷宫的速度在一秒之内是足够快的。 不可行的是检查指数数量的可能路径。 迷宫是有循环的，即使在观察到重新访问单元格是不必要的之后，简单路径的数量仍然可以随着单元格的数量呈指数增长。 

在几种边界情况下，粗心的实施可能会失败。 如果迷宫由一个单元格组成，例如```
1 1
7
```唯一可能的路径从那里开始和结束，所以答案是`7`。 初始化其答案的实现`0`并且仅检查相邻单元格可能会错误地返回`0`。 

起始单元本身也有助于路径的辐射。 例如，```
1 2
82
```只有一条可能的路径，所以答案是`8`。 仅检查开始后输入的单元格的实现可能会错误地返回`2`。 

路径不必是几何最短路径。 考虑```
3 3
159
189
111
```通过上排的直视路线到达`9`，但底部周围的路线最多只使用值`1`离开起始牢房后。 由于起始单元格是`1`，正确答案是`1`。 首先最小化移动次数然后评估该路径的算法可能会返回错误的值。 

相等的值是另一个有用的健全性检查。 为了```
2 3
555
555
```每条可能的路径都有最大辐射`5`，所以答案是`5`。 算法不得假设答案在移动到另一个单元格时会发生变化。 

## 方法

 直接暴力解决方案将来自左上角单元格的所有可能路线视为候选路线。 在深度优先搜索期间，我们可以保持迄今为止遇到的最大辐射，并在到达底行时更新全局答案。 由于重新访问单元格没有任何帮助，因此我们可以将单元格标记为在当前路径期间访问过并枚举简单路径。 

这是正确的，因为最终会生成每条有效路线，并且精确地使用该路线沿线的最大像元值来评估每条路线。 问题是路线的数量。 如果迷宫有`V = n*m`单元格中，一个简单的上限来自于为第一次移动选择最多四个方向，并在以后的每次移动中选择最多三个新方向，给出`O(4 * 3^(V-1))`在考虑简单路径限制之前可能的行走。 因此，最坏情况的工作是指数级的`V`。 DFS 处理每个生成的路径一次`Θ(P)`当当前最大值增量保持时，路径扩展起作用，其中`P`是简单路径的数量。 与近`10,000`细胞，这是完全不切实际的。 

关键的观察是目标是最小可能的最大值。 我们可以猜测我们愿意忍受的最大辐射，而不是直接询问最佳路径。 

假设我们选择一个阈值`x`。 现在禁止每个辐射大于的细胞`x`。 问题变得更加简单：我们可以仅使用允许的单元格从起始单元格移动到底行吗？ 

这是一个普通的图可达性问题。 BFS 或 DFS 可以回答这个问题`O(nm)`时间。 更重要的是，可行性属性是单调的。 如果有一个阈值`x`允许一条路径，那么每个较大的阈值也允许该路径，因为增加阈值只会使更多的小区可用。 

只有十个可能的阈值，因为每个单元格都包含来自`0`通过`9`。 我们可以简单地按升序测试阈值，并在第一个允许到达底行的阈值处停止。 这甚至避免了二分搜索的需要，并使实现非常小。 

暴力破解之所以有效，是因为它明确地考虑了每条候选路线，但当路线数量呈指数级增长时，暴力破解就会失败。 阈值观察让我们可以用重复的图可达性代替路由优化，将问题减少到最多十次遍历包含少于`10,000`顶点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数，`Θ(P)`为了`P`简单的路径|`O(nm)`| 太慢了 |
 | 阈值 BFS |`O(10nm) = O(nm)`|`O(nm)`| 已接受 |

 ## 算法演练

 1. 读取迷宫并将每个数字存储为整数。 我们需要与候选辐射阈值进行整数比较。 
2. 尝试阈值`0`通过`9`按递增顺序。 一个门槛`t`表示最多受辐射的细胞`t`可以输入，而单元格大于`t`被视为被阻止。 
3. 在针对阈值运行 BFS 之前，检查起始小区的辐射是否大于`t`。 如果是这样，则任何路径都无法工作，因为每条路径都包含起始单元格。 
4. 运行 BFS`(0, 0)`。 对于每个单元格，检查其四个正交邻居，并在邻居位于迷宫内时将其排入队列，最多有辐射`t`，并且尚未被访问过。 
5. 一旦 BFS 到达最后一行中的任何单元格，当前阈值就是可行的。 因为阈值是从小到大测试的，所以这是最小可能的最大辐射，所以立即输出。 
6. 如果阈值无法到达底行，则丢弃它并继续下一个阈值。 由于最大的单元格值最多为`9`，某个阈值总是会成功，即`9`。 

### 为什么它有效

 对于固定阈值`t`，在所有辐射大于的单元之后，BFS 恰好访问属于起始单元连通分量的单元`t`已被删除。 因此，BFS 到达底行当且仅当存在一条路径，其中每个单元的辐射最多`t`。 

设最优答案为`k`。 每个阈值小于`k`这是不可能的，因为这样的阈值意味着存在最大辐射小于最佳辐射的路径。 临界点`k`通过定义最优路径是可能的。 由于该算法按升序检查阈值并返回第一个可行的阈值，因此它准确地返回`k`。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [list(map(int, input().strip())) for _ in range(n)]

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    for limit in range(10):
        if grid[0][0] > limit:
            continue

        visited = [[False] * m for _ in range(n)]
        visited[0][0] = True

        q = deque([(0, 0)])

        while q:
            r, c = q.popleft()

            if r == n - 1:
                print(limit)
                return

            for dr, dc in directions:
                nr = r + dr
                nc = c + dc

                if not (0 <= nr < n and 0 <= nc < m):
                    continue
                if visited[nr][nc]:
                    continue
                if grid[nr][nc] > limit:
                    continue

                visited[nr][nc] = True
                q.append((nr, nc))

if __name__ == "__main__":
    solve()
```网格存储为整数，以便`grid[r][c] > limit`直接表示当前BFS是否禁止某个小区。 

外循环按排序顺序考虑所有可能的答案。 不需要去外面搜索值`0`通过`9`，因为这是迷宫中出现的唯一辐射水平。 

对于每个阈值，`visited`记录已经到达的单元格。 单元在插入队列时而不是删除时被标记。 这可以防止同一个单元通过不同的邻居多次排队。 

支票`r == n - 1`足以检测成功，因为到达最后一行中的任何单元格都意味着已到达所需的目的地。 在那之后我们不需要继续搜索。 

边界条件在访问网格之前检查行和列范围。 这避免了 Python 中的负索引行为，这种行为特别容易被忽视，因为诸如`grid[-1][c]`是有效的 Python，但引用最后一行而不是被拒绝。 

不存在整数溢出问题，因为所有值都是数字，而且 Python 整数无论如何都具有任意精度。 队列最多包含`n*m`一个 BFS 的单元格。

 ## 边缘情况

 单细胞迷宫```
1 1
7
```被处理，因为阈值`7`允许起始单元格，并且第一个 BFS 操作看到它的行已经是底部行。 算法打印`7`。 单细胞迷宫没有特殊情况的代码，因为一般的可达性逻辑已经涵盖了它。 

起始单元边界```
1 2
82
```显示为什么阈值检查必须包括`(0, 0)`。 阈值`0`通过`7`立即被拒绝，因为起始单元格具有值`8`。 处于阈值`8`，两个单元格都被允许并且 BFS 立即到达唯一的行，给出`8`。 

绕道案例```
3 3
159
189
111
```显示最小化路径长度和最小化最大像元值之间的差异。 处于阈值`1`，单元格形成一条从起点向下穿过底行的路线。 BFS 发现连接的组件并到达目的地而不触及任何一个`5`,`8`， 或者`9`，所以答案是`1`。 

一切平等的情况```
2 3
555
555
```以下每个阈值均失败`5`，因为在这些阈值下无法输入任何单元格。 处于阈值`5`，每个单元格都变得可达，因此 BFS 到达底行并返回`5`。 该算法不依赖于不同的辐射值。 

最大尺寸的情况下使用`99 × 99`充满零的迷宫。 临界点`0`已经允许每个单元格，因此 BFS 在第一次遍历时到达底行并返回`0`。 仅有的`9,801`细胞需要被处理，这证明了为什么重复阈值方法在给定的范围内仍然足够快。 

每一种情况的中心不变量都是相同的：在阈值的 BFS 期间`t`，每个被访问的小区从一开始就可以通过辐射最多的小区到达`t`，并且最终会访问在该限制下可以到达的每个单元格。 这将原始的极小极大路径问题转变为一系列普通的可达性检查。
