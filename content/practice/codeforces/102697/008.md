 ## 解决方案
 ## 问题理解

 输入描述了 D 维空间中的两个点。 每个点不是只有一个 x 坐标和一个 y 坐标，而是对于从 1 到 D 的每个维度都有一个坐标。目标是计算这两点之间的直线距离。 

对于每个维度，我们比较两个坐标，找到它们的差异，计算平方，然后将其添加到总数中。 在所有维度都贡献之后，取该总和的平方根即可得出最终距离。 

维度可以达到500，这意味着算法本质上必须是线性的。 任何试图生成维度组合或模拟空间的方法都是不必要的，并且很快就会变得不可能。 一次传递坐标就足够了，因此运行时间仅随着输入大小的增加而增长。 

坐标值可以为负数，因此将差值视为无符号值或忘记平方运算可能会产生不正确的结果。 例如，考虑二维情况，其中点是`(1, -1)`和`(-1, 1)`。 正确的距离是：```
sqrt((-1 - 1)^2 + (1 - (-1))^2)
= sqrt(4 + 4)
= 2.828427...
```粗心的实现会增加原始差异`0`，因为正向变化和负向变化相互抵消。 

另一种边缘情况是两个点相同。 对于输入：```
2
5
5
5
5
```答案一定是：```
0.0
```假设点之间始终存在一些移动的实现可能会意外地产生非零值或失败，因为它不处理零平方根结果。 

## 方法

 直接蛮力的想法是完全按照所写的距离公式计算。 对于每个维度，我们计算两个坐标之间的差，对其求平方，然后将其添加到运行总和中。 由于每个坐标都必须影响答案，因此这已经是所需的最小工作量。 

较慢的解释可能会反复重新计算公式或构建不必要的中间结构。 如果维度是 500，甚至不需要一些额外的遍。 最佳解决方案对每个维度执行一次计算。 

使问题变得简单的观察是距离公式在维度上是独立的。 每个坐标对为最终总和贡献一项，因此维度之间不存在交互作用。 我们可以在读取输入时累积平方差，最后只计算一次平方根。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(D) | O(D) | 如果直接实施则接受 |
 | 最佳| O(D) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取维数。 该值告诉我们有多少个坐标对对距离有贡献。 
2. 读取第一个点的每个坐标和第二个点的匹配坐标。 对于该维度，计算差值，对其进行平方，然后将其添加到累积的平方距离中。 

正方形消除了符号，因此沿负方向移动的坐标与沿正方向移动的坐标贡献的量相同。 
3. 所有维度处理完毕后，对累加值取平方根。 这是两点之间的欧几里得距离。 

为什么它有效：

 该算法保持平方根内表达式的精确值。 每个维度只贡献一项`(q[i] - p[i])^2`，并且该算法将每个此类项添加一次。 由于最终的距离公式是该完整总和的平方根，因此生成的答案正是所需的距离。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    d = int(input())
    
    first = [int(input()) for _ in range(d)]
    
    total = 0
    for i in range(d):
        second = int(input())
        diff = second - first[i]
        total += diff * diff
    
    print(math.sqrt(total))

if __name__ == "__main__":
    solve()
```第一个列表存储第一个点的坐标，因为输入在第二个点开始之前给出了所有这些坐标。 然后，该算法一次读取第二个点的一个坐标，并立即将其与存储点中的匹配坐标相结合。 

变量`total`存储平方距离，而不是最终距离。 将值保留为整数可以避免在求和时进行不必要的浮点运算。 在知道完整的总和后，平方根仅应用一次。 

Python 整数不会溢出，因此最大可能的平方和是安全的。 唯一的浮点运算是最终的平方根，它与所需的输出格式相匹配。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(D) | 每个维度都被处理一次 |
 | 空间| O(D) | 第一个点的坐标被存储 |

 维度限制足够小，存储一个点是安全的。 该算法不会创建与空间中可能位置数量相关的任何结构，因此它很容易符合限制。

 ## 边缘情况

 当坐标具有相反符号时，必须在平方之前进行减法。 对于输入：```
2
1
-1
-1
1
```该算法计算`(-1 - 1)^2 + (1 - (-1))^2`，这变成`4 + 4`。 最终的答案是`2.8284271247461903`。 在减法之前忽略符号的方法会丢失此信息。 

当两个点相同时，每个差异都为零。 为了：```
2
5
5
5
5
```每次迭代中累积的平方距离保持为零。 最终的平方根是`0.0`，因此无需特殊处理。 

当维度大于二时，相同的公式仍然适用，无需修改。 对于每个坐标变化 1 的五维输入，累加值为`1 + 1 + 1 + 1 + 1 = 5`，输出是`sqrt(5)`。 循环自然地处理这个问题，因为它从不假设固定数量的坐标。
