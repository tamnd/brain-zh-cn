 ## 解决方案
 ## 问题理解

 棋盘是一个 n×m 的矩形，其单元格包含三个符号之一。`*`是一个活的细胞，`.`已经死了，并且`X`是一个障碍。 每回合都使用当前的棋盘并同时更换单元格。 

非屏障细胞，无论`*`或者`.`，变成`.`一旦其八个相邻位置中至少有一个是`.`。 八个邻居包括水平、垂直和对角位置。 屏障的行为有所不同：`X`变成`.`仅当它严格位于棋盘内部并且其所有相邻位置也都在棋盘内时`X`。 一个`X`外缘永远不会消失。 

所需的输出是工艺稳定后的电路板，而不是指定的匝数后的输出。 官方声明保证最终会实现稳定。 

该声明没有提供 n 和 m 的明确数值范围，但时间限制仅为一秒，并且板显然足够大，以至于不希望对每一代重复扫描它。 解决方案的目标应该是 O(nm)，其中每个细胞仅被处理恒定的次数。 在长矩形板上进行 O(nmmax(n,m)) 的模拟可能会变得过于昂贵。 

第一个微妙的情况是一块不包含初始死细胞的板。 例如，```
1 1*
```正确的输出是```
*
```粗心的实现可能会假设每个活细胞最终都会死亡，但这里什么也没有发生，因为没有与唯一细胞相邻的死细胞。 

第二个边缘情况是`X`在边界上。 例如，```
1 1X
```正确的输出是```
X
```该单元没有周围的障碍，但第二条规则明确排除边缘单元。 将边缘单元视为普通的内部屏障会错误地将其变成`.`。 

第三种情况区分对角邻接和仅四方向邻接。 例如，```
2 2.*..
```正确的输出是```
....
```这`*`与死亡细胞对角相邻，因此它会立即死亡。 仅检查向上、向下、向左和向右的实现会错误地使其保持活动状态。 

第四种情况是完全实心的阻隔板：```
3 4XXXXXXXXXXXX
```正确的输出是```
XXXXX..XXXXX
```两个内部细胞只有屏障邻居，因此它们变得死亡。 边界障碍仍然是永久性的。 这个例子也是由问题提供的。 

## 方法

 直接的方法是一次模拟棋盘一圈。 对于每个细胞，检查它的八个邻居并决定它是否死亡。 由于所有更新都是同时进行的，因此下一代需要第二块板。 这是正确的，因为每次转变都完全由上一代决定。 

问题是世代数。 一旦存在死亡细胞，死亡就可以每代传播一个切比雪夫步，因此尺寸为 n 和 m 的棋盘可能需要 O(max(n,m)) 代，然后所有可死亡的细胞都死亡。 因此，完整的模拟会执行 O(nmmax(n,m)) 单元更新，每次更新最多进行八次邻居检查。 在最坏的情况下，在考虑构建每个新板的开销之前，这大约是 8nmmax(n,m) 邻居检查。 

暴力模拟之所以有效，是因为死亡是不可逆转的，但它失败了，因为它重复地发现了图遍历一次可以发现的相同传播。 

关键的观察是，细胞死亡后，它就不会再发生变化。 这个过程确实是一个洪水填满的过程。 最初的`.`细胞已经是这场洪水的源头。 还有另一种来源：内部`X`其整个八单元邻域由`X`细胞。 这样一个`X`即使没有初始的，也会在第一回合死亡`.`细胞。 

在确定了这些来源之后，每个最终可能死亡的细胞都恰好是从其中一个细胞可以通过本身可以死亡的位置到达的细胞。 内部的`X`细胞是可穿越的，因为一旦波到达它们，它们就会死亡。 无屏障细胞也是可穿越的。 边界`X`细胞是唯一不能被遍历的细胞，因为它们仍然存在`X`永远。 

这将无限模拟变成了多源 BFS。 BFS 不需要每一代都进行复制。 它直接找到不断扩大的死亡区域最终会到达的每一个细胞。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(nmmax(n,m)) | O(纳米) | 太慢了 |
 | 多源BFS | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1. 阅读黑板并保留其原始内容。 在识别自发死亡的细胞时，我们需要原始状态，因为在任何新创建的死亡细胞存在之前就评估了该条件。 
2. 创建一个队列并添加最初的每个单元`.`。 这些细胞在零时间死亡，因此它们是死亡传播的最初来源。 
3.检查每个内部`X`。 如果所有八个相邻小区也都是`X`，将此单元作为另一个源添加到队列中。 根据障碍规则，它在第一回合就死了，因此在计算最终状态时将其视为距离为零的源就足够了。 
4. 同时使用所有源运行 BFS。 对于每个出队的单元，检查其八个相邻位置。 如果邻居位于棋盘内部且不是边界，则可以到达该邻居`X`。 将其标记为死亡，如果尚未到达，则将其排队。 
5. 将每个到达的单元格替换为`.`。 从未到达的单元格保留其原始符号。 唯一能留下来的细胞`X`是阻止传播的边界障碍，而`*`到达区域之外的细胞将永远存活，因为没有相邻的死亡细胞，任何规则都无法杀死它们。 

BFS 不变量是，每个已标记为已达到的单元格都是最终会死亡的单元格。 相反，当未到达的小区有已到达的邻居并且不是永久边界时`X`，规则最终使该单元死亡，因此 BFS 必须到达它。 因为唯一永久的障碍是边界`X`细胞，遍历恰好到达最终死亡的细胞。 

## Python 解决方案```python
Pythonimport sysfrom collections import deque
input = sys.stdin.readline
def solve():    n, m = map(int, input().split())    board = [list(input().strip()) for _ in range(n)]
    q = deque()    dead = [[False] * m for _ in range(n)]
    # Initial dead cells are sources.    for r in range(n):        for c in range(m):            if board[r][c] == '.':                dead[r][c] = True                q.append((r, c))
    # Interior X cells surrounded entirely by X are also sources.    for r in range(1, n - 1):        for c in range(1, m - 1):            if board[r][c] != 'X':                continue
            all_barriers = True            for dr in (-1, 0, 1):                for dc in (-1, 0, 1):                    if dr == 0 and dc == 0:                        continue                    if board[r + dr][c + dc] != 'X':                        all_barriers = False                        break                if not all_barriers:                    break
            if all_barriers and not dead[r][c]:                dead[r][c] = True                q.append((r, c))
    # Multi-source BFS.    while q:        r, c = q.popleft()
        for dr in (-1, 0, 1):            for dc in (-1, 0, 1):                if dr == 0 and dc == 0:                    continue
                nr = r + dr                nc = c + dc
                if not (0 <= nr < n and 0 <= nc < m):                    continue
                # Boundary X cells never become dead.                if board[nr][nc] == 'X':                    if nr == 0 or nr == n - 1 or nc == 0 or nc == m - 1:                        continue
                if dead[nr][nc]:                    continue
                dead[nr][nc] = True                q.append((nr, nc))
    for r in range(n):        for c in range(m):            if dead[r][c]:                board[r][c] = '.'
    sys.stdout.write('\n'.join(''.join(row) for row in board))

if __name__ == "__main__":    solve()
```第一次扫描添加所有原件`.`到 BFS。 这些细胞已经满足杀死邻居所需的条件，因此它们是自然的起点。 

第二次扫描发现内部障碍物中自发死亡。 仅检查行`1`通过`n - 2`和列`1`通过`m - 2`直接强制执行要求`X`不在边缘。 八邻环使用原始板，这很重要，因为一回合中的所有变化都是同时发生的。 

在 BFS 期间，边界`X`被明确拒绝。 内部的`X`细胞被允许穿过，因为一旦死亡波到达它们，它们就会死亡。 这`dead`矩阵可防止同一单元多次进入队列，从而提供遍历的线性复杂度。 

除了索引之外没有整数运算，因此整数溢出不是问题。 八方向循环还直接处理对角线，避免了仅实现四方向邻接的常见错误。

 ## 边缘情况

 最小电路板尺寸由内部源循环直接处理。 为了```
1 1X
```没有内部坐标，因此不会创建自发的屏障死亡。 BFS队列为空，输出保留`X`，完全按照要求。

```四向遍历会错过对角线关系。
