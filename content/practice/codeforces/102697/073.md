 ## 解决方案
 ## 问题理解

 任务故意简单。 输入是一个句子片段，例如`It's a me,`，所需的输出是相同的文本，后跟文字字符串` Mario!`。 原文必须保持不变，包括标点符号和空格。 官方问题指定了 1 秒时间限制和 256 MB 内存限制。 

这里没有隐藏数值算法。 唯一重要的数据是输入字符串及其确切的字符顺序。 如果输入包含`It's a me,`，答案是`It's a me, Mario!`。 如果它包含`Hello`，答案是`Hello Mario!`。 

缺乏有意义的数值约束意味着相关参数只是输入长度，例如 (L)。 (O(L)) 解决方案是自然目标，因为必须读取每个输入字符，而 (O(L^2)) 构造对于长字符串可能会变得不必要的昂贵。 对于预期的输入大小来说，Python 的字符串操作足够快。 

主要的边缘情况是准确保留输入。 例如，与```
Hello
```正确的输出是```
Hello Mario!
```总是打印固定短语的粗心解决方案，例如`It's a me, Mario!`会失败，因为输入的句子不一定是确切的文本。 

另一个微妙的情况是输入末尾已经存在标点符号。 为了```
It's a me,
```逗号属于输入，所以结果一定是```
It's a me, Mario!
```删除标点符号或在逗号之前插入另一个空格的解决方案会更改原始句子并产生错误的结果。 

在正常标准输入中，输入以换行符终止。 该换行符不是句子的一部分，因此应在附加之前将其删除` Mario!`。 使用`rstrip('\n')`而不是一般的`strip()`还可以避免意外地从实际句子中删除有意义的前导或尾随空格。 

## 方法

 思考该任务的一种强力方法是通过重复创建一个包含到目前为止构建的所有内容以及下一个字符的新字符串，一次构建一个字符的答案。 结果是正确的，因为每次迭代都保留了先前构造的前缀。 但是，构造新字符串每次都会复制现有前缀。 对于长度为 (L) 的输入，这可以大致复制 (1 + 2 + \dots + L = L(L+1)/2) 个字符，在最坏的情况下给出 (O(L^2)) 工作。 

这个问题的结构给了我们一个更简单的观察。 没有搜索，也没有做出决定。 期望的结果正是输入字符串后跟一个固定后缀，` Mario!`。 Python 可以直接连接两个字符串，从而对结果字符串的大小进行线性运算。 

蛮力方法之所以有效，是因为它最终构造了答案的每个字符，但它会反复重新访问已经复制的字符。 观察到整个后缀是固定的，我们可以通过单个串联来执行构造。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(L^2)) | (O(L)) | 不必要的缓慢 |
 | 最佳 | (O(L)) | (O(L)) | 已接受 |

 ## 算法演练

 1. 读取完整的输入行并仅删除其终止换行符。 否则，必须准确保留句子本身。 
2.追加固定字符串` Mario!`到这句话。 前导空格是所需后缀的一部分，因此生成的句子完全具有所需的格式。 
3. 打印结果字符串。 不需要额外的转换、解析或验证。 

### 为什么它有效

 该算法准确地从输入提供的句子开始，并且不改变该句子内的任何内容。 然后它准确地附加所需的后缀，` Mario!`。 因此，原始句子的每个字符都以相同的顺序出现，紧接着是所需的文本，这正是所需的输出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().rstrip('\n')
print(s + " Mario!")
```致电给`input()`将句子作为一个完整的行来读。`rstrip('\n')`删除由标准输入处理插入的换行符，同时保持其他字符不变。 这比`strip()`， 因为`strip()`还将删除可能属于输入句子的前导或尾随空格。 

连接`s + " Mario!"`执行问题所需的唯一转换。 后缀开头的空格是故意的。 如果没有它，输入如`It's a me,`会错误地变成`It's a me,Mario!`。 

决赛`print()`提供输出换行符。 没有整数计算，因此整数溢出和数值精度无关。

## 测试用例```python
import sys
import io

def solve():
    input = sys.stdin.readline
    s = input().rstrip('\n')
    print(s + " Mario!")

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

# Provided sample
assert run("It's a me,\n") == "It's a me, Mario!\n", "sample 1"

# Minimum-size style case
assert run("A\n") == "A Mario!\n", "single-character sentence"

# All characters are punctuation
assert run("!!!\n") == "!!! Mario!\n", "punctuation preservation"

# Leading and trailing spaces must remain part of the input
assert run("  Hi  \n") == "  Hi   Mario!\n", "space preservation"

# Longer input
assert run("Hello, this is a longer sentence.\n") == \
       "Hello, this is a longer sentence. Mario!\n", "long sentence"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 |`A`|`A Mario!`| 最小的实际输入和基本串联 |
 |`!!!`|`!!! Mario!`| 标点符号被保留 |
 |` Hi `|`  Hi   Mario!`| 现有空间未被剥离 |
 |`Hello, this is a longer sentence.`|`Hello, this is a longer sentence. Mario!`| 较长输入的一般处理 |

 ## 边缘情况

 对于标点符号情况，输入是`!!!`。 仅删除换行符后，工作字符串仍然是`!!!`。 追加` Mario!`产生`!!! Mario!`。 算法中没有任何内容假设句子包含字母或特定短语。 

对于逗号情况，输入是`It's a me,`。 工作字符串以逗号结尾，后缀以空格开头。 连接因此产生`It's a me, Mario!`，完全匹配所需的句子。 对示例短语进行硬编码的解决方案恰好可以通过这种情况，但一旦输入句子发生变化就会失败。 

对于空白情况，考虑输入` Hi `。 后`rstrip('\n')`，两个前导空格和两个尾随空格仍然存在。 追加` Mario!`产生`  Hi   Mario!`，之间有三个连续的空格`Hi`和`Mario!`来自两个原始尾随空格加上后缀所需的空格。 这就是为什么`strip()`将是一个不安全的选择。 

对于空行，如果输入是空句子，相同的构造将产生` Mario!`。 该算法不需要特殊的分支，因为附加固定字符串适用于每个输入长度。
