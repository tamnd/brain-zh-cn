 ## 解决方案
 ## 问题理解

 该问题要求我们确定正在测试重力飞行器的行星的重力值。 输入是描述行星（地球或火星）的单个单词，输出是相应的引力常数。 地球使用的重力值为 9.807 m/s²，而火星使用的重力值为 3.711 m/s²。 

输入大小是恒定的，因为只有一个字符串具有两个可能值之一。 这立即排除了对任何高级算法或数据结构的需要。 整个任务是直接查找，因此即使是具有恒定时间复杂度的解决方案也绰绰有余。 

主要的边缘情况来自正确处理确切的输入值。 比较错误拼写或打印缺少数字的值的程序将会失败。 

例如，如果输入是：```
EARTH
```正确的输出是：```
9.807
```粗心的实现会打印`9.8`失去所需的精度并给出错误的答案。 

另一种情况是：```
MARS
```具有正确的输出：```
3.711
```在这种情况下，假设地球作为默认答案而不检查输入的解决方案将默默地失败。 

## 方法

 蛮力方法是模拟某种重力计算或尝试从物理公式中得出值。 这是不必要的，因为问题已经给出了两个可能的常数。 这种方法将在不使用任何附加信息的情况下执行额外的工作，并且确切的操作计数取决于所选择的不必要的模拟。 

关键的观察结果是输入只是一个标签，而不是测量结果。 由于恰好有两个可能的标签，并且每个标签都有固定的答案，因此问题简化为在两个存储值之间进行选择。 一个简单的条件检查就足够了。 

蛮力之所以有效，是因为任何最终识别行星的方法都可以产生答案，但它会失败，因为它解决的问题比所需的更难。 从行星名称到重力值的映射是固定的，我们可以用恒定时间查找替换所有计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k)，其中 k 取决于不必要的模拟 | O(1) | O(1) | 原则上太慢而且没有必要 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 从输入中读取行星名称。 唯一需要的信息是车辆是否正在地球或火星上进行测试。 
2. 比较名称`"EARTH"`。 如果匹配则输出`9.807`因为这是地球的固定重力常数。 
3. 否则，唯一剩下的有效可能性是`"MARS"`，所以输出`3.711`。 

其工作原理：输入域仅包含两个有效状态，并且每个状态恰好有一个所需的输出。 该算法直接检查这些状态，因此不可能为有效输入选择错误的值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    planet = input().strip()

    if planet == "EARTH":
        print("9.807")
    else:
        print("3.711")

if __name__ == "__main__":
    solve()
```该程序读取单个输入字符串并使用删除尾随换行符`strip()`。 由于问题使用大写行星名称，所以比较是准确的。 

条件分支明确处理地球。 由于唯一的其他有效输入是火星，`else`分支可以安全地打印 Mars 值。 输出存储为字符串而不是浮点数，因此保留了精确的三位小数。

 ## 边缘情况

 第一个边缘情况是需要精确格式化的地球值。 对于输入：```
EARTH
```该算法成功比较字符串并打印：```
9.807
```将值转换为浮点数并使用默认格式打印它的解决方案可能会产生不同的表示形式，因此直接存储输出可以避免格式错误。 

第二个边缘情况是火星分支。 对于输入：```
MARS
```第一个条件失败，因此算法到达第二种情况并打印：```
3.711
```这证实了该解决方案并不依赖于地球作为常见情况。 每个有效输入都直接映射到其所需的答案。
