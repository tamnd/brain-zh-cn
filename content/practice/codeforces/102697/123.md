 ## 解决方案
 ## 问题理解

 任务是使用仿射密码对小写字符串进行编码。 两个整数`a`和`b`定义密码。 对于每个字母，我们首先转换`a`到`z`进入数字`0`通过`25`, 申请

 [
 y=(x+b)\bmod 26,
 ]

 并转换`y`回到小写字母。 空格被原封不动地复制。 

例如，如果`a = 7`,`b = 5`，当前字符为`x`，其数值为`23`。 加密后的值为`(7 * 23 + 5) % 26 = 10`，对应于`k`。 

输入在第一行包含两个密码参数，在第二行包含明文。 输出是完整的编码字符串，包括每个原始空格。 

官方给出的问题是一秒的时间限制和256MB的内存。 该语句没有为字符串长度提供单独的显式上限，因此自然目标是字符数的线性时间。 重复搜索字母表中每个字符的算法会引入不必要的因子 26。直接算术转换只需要每个字符进行恒定的工作，并且无论确切的长度限制如何，都是适当的方法。 

在某些情况下，粗心的实现可能会默默地产生错误的字符串。 空间不得改变。 例如，```
11 1
a b
```变成```
l m
```因为`a`映射到`b`数字上和`b`映射到`m`，而中间的空间仍然是一个空间。 处理每个字符的实现`ord(c) - ord('a')`会错误地将空格视为负字母索引。 

模运算也必须应用于整个表达式。 和```
7 5
x
```值为`(7 * 23 + 5) % 26 = 10`，所以输出是```
k
```如果不小心将乘法结果直接转换为字符而不取模 26，可能会在外部产生一个字符`a`通过`z`。 

最后，第一个和最后一个字母位置是普通值，而不是特殊情况。 和```
0 0
z
```该值变为`(0 * 25 + 0) % 26 = 0`，所以答案是```
a
```这会捕获在以下情况下意外保留输入的实现：`a`为零或错误处理字母表末尾的环绕。 

## 方法

 最直接的暴力方法会处理每个字符并尝试 26 个可能的输出字母中的每一个，直到找到数值满足仿射公式的字母。 这是正确的，因为每个候选输出都有一个从 0 到 25 的已知值，因此测试所有 26 种可能性最终必须找到所需的一种。 对于一个长度的字符串`n`，但是，这最多执行`26n`候选人在最坏的情况下进行检查。 这项工作在技术上仍然是线性的，因为 26 是一个常数，但它是不必要的，并且模糊了问题的简单算术结构。 

暴力破解之所以有效，是因为字母表很小，但密码本身已经给了我们答案的精确数值。 一旦字符被转换为`x`，没有要执行的搜索。 我们可以计算`(a * x + b) % 26`直接将该数字转换回字符。 

关键的观察结果是每个角色的变换都是独立的。 一个字母的加密值不依赖于前一个字母、后一个字母或该字母在字符串中的位置。 这意味着我们可以扫描一次输入，立即转换字母，并不变地复制空格。 

因此，最佳解决方案对每个输入字符执行恒定的工作。 其运行时间为`O(n)`， 在哪里`n`是输入字符串的长度，需要`O(n)`如果我们将输出构造为新字符串，则使用空格。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(26n) = O(n) | O(26n) = O(n) | O(n) | 已接受，但不必要的工作 |
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读`a`和`b`从第一行开始，然后将整个第二行作为明文读取。 读取整行是必要的，因为空格是数据的一部分。 
2. 创建输出缓冲区。 逐个字符处理字符串可以让我们精确保留空格，同时仅替换小写字母。 
3. 对于每个字符，检查是否为空格。 如果是，则附加空格不变，因为密码仅应用于字母。 
4. 对于小写字母，将其转换为数值：`ord(c) - ord('a')`。 这张地图`a`到`0`,`b`到`1`， 和`z`到`25`。 
5. 计算`(a * x + b) % 26`。 模运算将结果放回到有效的字母范围内`0`通过`25`，包括算术环绕的情况`z`回到`a`。 
6. 将结果数字转换回小写字符：`chr(value + ord('a'))`，然后将其附加到输出缓冲区。 
7. 打印完整的输出字符串。 字符的显示顺序与输入完全相同，仅小写字母被其加密值替换。 

### 为什么它有效

 对于每个输入字母，算法首先精确地获取其规定的字符代码`x`。 然后应用密码的定义公式`(a * x + b) % 26`，因此产生的数值正是所需的加密字符代码。 复制空格时无需修改，符合从密码中排除空格的规则。 由于该算法独立地对每个字符执行正确的转换并且从不改变它们的顺序，因此生成的字符串正是所需的加密。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b = map(int, input().split())
    s = input().rstrip('\n')

    result = []

    for c in s:
        if c == ' ':
            result.append(c)
        else:
            x = ord(c) - ord('a')
            y = (a * x + b) % 26
            result.append(chr(y + ord('a')))

    print(''.join(result))

if __name__ == "__main__":
    solve()
```前两个值被读取为整数，因为它们直接参与仿射公式。 第二行读取为`input()`，而不是基于标记的输入，因为空格必须保留为明文的一部分。 

致电给`rstrip('\n')`仅删除通过读取行​​添加的换行符。 它不会删除空格，因此前导、尾随或连续空格保持不变。 这比`strip()`，这也会从明文中删除有意义的空格。 

字符测试发生在数字转换之前。 呼唤`ord()`空格上不会产生字母表索引，因此单独处理空格可以防止无效的转换。 

为了一封信，`ord(c) - ord('a')`给出 0 到 25 之间的值。Python 整数不会溢出，因此即使异常大的值`a`和`b`不会造成整数溢出问题。 模 26 运算在完整的仿射表达式之后应用，完全按照指定。 

输出累积在列表中并在最后连接一次。 这避免了重复构建较大的中间字符串并提供线性的总构建时间。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 明文的每个字符都被检查一次。 |
 | 空间| O(n) | 输出缓冲区为每个输入字符存储一个结果字符。 |

 这里`n`是明文行的长度。 由于该算法仅对每个输入字符执行恒定量的算术和字符处理，因此它会随实际输入大小线性缩放，并且完全符合规定的 1 秒和 256 MB 限制。

## 边缘情况

 绝不能将空格视为字母。 对于输入```
11 1
a b
```该算法转换`a`到`0`，生产`(11 * 0 + 1) % 26 = 1`， 或者`b`。 它保持空间不变，然后转换`b`，其值为`1`， 到`(11 * 1 + 1) % 26 = 12`， 或者`m`。 输出是```
b m
```仿射表达式可以环绕字母表。 为了```
1 1
z
```的数值`z`是25，所以加密后的值为`(1 * 25 + 1) % 26 = 0`。 该算法将零转换回`a`，生产```
a
```这是暴露忘记模运算的实现的边界。 

零乘数也是有效的。 和```
0 5
abc
```每个字母都有加密值`(0 * x + 5) % 26 = 5`，所以输出是```
fff
```该算法自然地处理这个问题，因为它不假设转换是一对一的或`a`有一个模 26 的倒数。 

输入可以包含连续的空格。 为了```
1 1
a  z
```第一个`a`变成`b`，两个空格仍然是空格，并且`z`环绕到`a`。 输出是```
b  a
```将明文作为完整的行读取并显式检查空格以保留精确的间距。 

字母表的端点不需要特殊的分支。 和```
25 25
az
```

`a`值为 0 并映射到`(25 * 0 + 25) % 26 = 25`，即`z`。 的价值`z`是 25 并映射到`(25 * 25 + 25) % 26 = 0`，即`a`。 结果是```
za
```这证明了算术解决方案的主要优点：所有字母表边界和环绕情况都由相同的公式处理，因此不存在可能变得不一致的特殊情况的集合。
