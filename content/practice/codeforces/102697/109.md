 ## 解决方案
 ## 问题理解

 该任务是一个小的输出构建问题。 我们给定一个整数`n`，它指定大写字母每个部分的大小`H`。 每个垂直腿包含`n`字符，水平条的长度与两条腿之间的距离相同。 所需图纸有`n`单杠上方的行，中间一行包含整个单杠，以及`n`它下面的行。 

例如，当`n = 3`，两条垂直腿占据列`0`和`4`，而中间的栏占据了所有五列。 因此最终的图有`2n + 1`行和`2n - 1`列。 输出就是这个矩形字符模式，其中`H`在非中间行的两个外列和`H`在中间行的每个位置。 

该声明没有给出明确的上限`n`在可用版本中。 因此，相关的约束就是产出量本身。 一张图包含`(2n + 1)(2n - 1) = 4n² - 1`计算换行符之前的字符位置，因此没有解决方案可以渐近地使用小于`O(n²)`如果明确打印绘图，则需要时间。 一秒的限制还意味着没有理由执行比直接构造所需行更昂贵的操作。 

主要的边缘情况是`n = 1`。 在这种情况下，两条腿和中间的条都重合，所以答案是三行，其中包含一个`H`，而不是具有两个分离的列的形状。 确切的输入和输出是：```
1
```

```
H
H
H
```总是假设两条腿占据不同列的粗心实现可能会意外地产生额外的空间或空白间隙。 

另一个边界情况是中间行。 为了`n = 2`，输出为：```
H H
HHH
H H
```中间行必须包含`2n - 1 = 3`连续的`H`人物。 打印每一行的垂直腿模式的实现将产生`H H`在中心并完全错过单杠。 

## 方法

 直接的暴力方法是考虑输出矩形中的每个位置。 对于一个职位`(r, c)`， 打印`H`什么时候`r`是中间行或者当`c`是两个外列之一。 否则打印一个空格。 由于输出正好`(2n + 1)(2n - 1) = 4n² - 1`位置，这完全执行`4n² - 1`位置检查。 这是正确的，因为字母的定义`H`完全由这三条线来表征：左腿、右腿和水平中条。 

蛮力版本已经在时间上渐近最优，因为输出本身具有二次大小。 没有隐藏的算法挑战可以让我们避免产生这些字符。 有用的改进是避免存储整个绘图。 我们可以一次构造一行并立即将其附加到输出中。 非中间行只是`H`其次是`2n - 3`空格和另一个`H`，而中间行由`2n - 1` `H`人物。 

这也处理`n = 1`当然，如果仔细选择行结构的话。 在这种情况下，只有一列，因此非中间行公式不应尝试生成两条单独的边。 最简单的实现是生成第一个`n`rows 作为垂直模式，生成中间行，然后生成剩余的行`n`行。 什么时候`n = 1`，垂直图案只是`H`，中间一排也是`H`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |`O(n²)`|`O(1)`额外 | 已接受 |
 | 最佳 |`O(n²)`|`O(n)`输出缓冲器| 已接受 |

 这两种方法具有相同的渐近时间，因为打印在问题中占主导地位。 最佳实现更干净，因为它直接构造完整的行而不是检查每个单独的单元格。 

## 算法演练

 1. 阅读`n`。 最终的图有`2n + 1`行和`2n - 1`列，因此这些维度完全决定了输出。 
2. 构造非中间行的图案。 如果`n = 1`，该行很简单`H`。 否则它包括`H`， 其次是`2n - 3`空格，然后是另一个`H`。 两人`H`人物正是两条垂直的腿。 
3.输出这一竖行`n`次。 这些行形成字母的上半部分，并且不包含水平条。 
4. 输出一行由`2n - 1`连续的`H`人物。 这是单杠，正好是一行宽。 
5. 再次输出相同的垂直行`n`次。 这些行构成了字母的下半部分。 

整个构造的不变性是每个发出的行正是其位置所需的行。 第一个和最后一个`n`行仅包含两个垂直腿，而唯一的中间行包含完整的水平条。 既然这些都是`2n + 1`行，所需绘图中的每个位置都只生成一次并且具有正确的字符。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    if n == 1:
        row = "H"
    else:
        row = "H" + " " * (2 * n - 3) + "H"

    middle = "H" * (2 * n - 1)

    out = []
    out.extend([row] * n)
    out.append(middle)
    out.extend([row] * n)

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```第一个分支处理唯一的退化维度。 为了`n > 1`，两垂直线之间的距离`H`字符是`2n - 3`空间。 包括两个端点字符得出的总宽度为`2 + (2n - 3) = 2n - 1`。 

名单`out`存储完整的行而不是单个字符。 第一个`n`条目代表大腿，下一个条目是中间条，最后一条`n`条目代表小腿。 使用`"\n".join(out)`避免添加不必要的尾随换行符并在一次操作中执行输出。 

Python 中不存在整数溢出问题，也不存在涉及输入数组的索引计算。 唯一需要注意的算术是`2n - 3`，这对于单独的`n = 1`以上处理过的案件。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |`O(n²)`| 该程序产生`2n + 1`行宽`2n - 1`，所以打印的数据量为`Θ(n²)`。 |
 | 空间|`O(n²)`| 这`out`list 在写入之前存储完整的输出。 |

 二次时间是不可避免的，因为所需的输出本身包含`Θ(n²)`人物。 除了字符串构造之外，该实现仅对每个输出字符执行恒定的工作，因此除了所需的打印之外没有算法开销。 

如果需要严格的流输出，相同的结构可以立即打印每一行并将辅助内存减少到`O(n)`，因为单行有长度`O(n)`。 提交的版本在内存中保留完整的行，以使输出操作简单高效。

 ## 边缘情况

 对于`n = 1`，输入为：```
1
```算法选择`row = "H"`而不是应用一般的两条腿公式。 然后，它将该行输出一次在中间行上方，一次作为中间行，一次在中间行下方。 结果是：```
H
H
H
```这避免了计算两条据称不同的腿之间的负宽度或零宽度间隙的常见错误。 

为了`n = 2`，输入为：```
2
```垂直行变成`H H`， 因为`2n - 3 = 1`。 中间一排就变成了`HHH`， 因为`2n - 1 = 3`。 该算法发出两行垂直行、一行中间行和另外两行垂直行，给出：```
H H
H H
HHH
H H
H H
```这可以捕获两个常见的相差一错误：使用`2n - 2`而不是`2n - 3`对于内部空间，并使用`2n`而不是`2n - 1`对于中间的栏。 

对于较大的值，例如`n = 1000`，输出有`2001`行并且每行都有宽度`1999`。 中间行正好包含`1999` `H`字符，而每隔一行恰好包含两个`H`其边界处的字符。 由于该算法直接从两个维度导出`n`，同样的推理适用，无需对大值进行任何特殊处理。 

关键边界条件始终是中间行和其他所有行之间的区别。 正好有一个中间行，位于 位置`n`当行从零开始计数时。 该实现通过精确​​发出来避免显式行索引`n`垂直行，然后中间一行，然后正好`n`更多垂直行，这使得行数和对称性更加明确。
