 ## 解决方案
 ## 问题理解

 世界是由 Minecraft 块组成的固定 20 x 20 网格。 每个细胞要么是已知的针叶林（`T`）， 沙漠 （`D`）， 森林 （`F`），或未探索的（`.`）。 至少有一种针叶林细胞是已知的，并且现实世界恰好包含一种针叶林生物群落。 

生物群落的相关定义是通过侧面相邻细胞的连接。 如果两个针叶林细胞之间存在一条仅使用针叶林细胞并向上、向下、向左或向右移动的路径，则它们属于同一生物群落。 

对于每一个未探索的细胞，我们想要确定它是否可能是针叶林，同时保持世界一致，只有一个针叶林生物群落。 输出是原始地图，其中每个可能的单元格都从`.`到`T`。 

关键的限制是已知的沙漠或森林细胞永远不能成为针叶林。 当一个未探索的细胞可以通过其他未探索的细胞与已知的针叶林细胞连接时，它就可以成为针叶林。 如果它在不穿越已知的沙漠或森林的情况下无法到达任何已知的针叶林细胞，则将其分配给针叶林将创建一个单独的针叶林组成部分，这与世界上只有一个针叶林生物群系的事实相矛盾。 这直接来自语句中的连接定义。 

网格大小始终为 20 x 20，因此只有 400 个单元格。 即使每个单元需要数百次操作的算法在一秒的限制下也很容易足够快。 不需要复杂的渐近优化，但自然图遍历比独立地重复搜索每个单元更简单、更高效。 

第一个边缘情况是一个孤立的已知针叶林单元。 例如，考虑一张地图，其左上角包含`T`， 和`D`紧邻其右侧和下方。 这两个沙漠细胞完全阻止了针叶林细胞的运动，因此正确的输出使其他所有细胞保持不变。 如果不小心将每个未探索的单元视为潜在的针叶林，则会错误地将整个板变成`T`。 

第二种边缘情况是连接两个独立的已知针叶林区域的未探索区域。 如果有人知道`T`位于`(0,0)`，另一个位于`(0,2)`， 和`(0,1)`是`.`， 然后`(0,1)`必须考虑可能的大河。 最终的生物群落可以是`T T T`，因此两个已知的部分成为同一生物群系的一部分。 仅检查点是否与现有点直接相邻的实现`T`会错过连接路径上更远的单元。 

第三种边缘情况发生在边界处。 从第一行的单元格开始，其上方没有邻居，从最后一列的单元格开始，右侧没有邻居。 例如，如果唯一已知的针叶林细胞位于`(0,0)`，遍历不能访问行`-1`或列`-1`。 在 Python 中，负索引是有效的语法，并且默默地引用数组的另一侧，因此忘记边界检查可能会产生完全错误的映射，而不是异常。 

## 方法

 直接暴力方法是单独考虑每个未探索的单元，并询问是否存在从该单元到任何已知的针叶林单元的路径，而无需穿过沙漠或森林。 一个单元的 DFS 或 BFS 可以访问多达 400 个单元。 重复搜索所有 400 个单元格最多给出`400 * 400 = 160,000`细胞访问，对于这个问题来说已经很小了，而且实际上会很顺利地通过。 

更自然的方法是颠倒问题。 不要独立地询问每个点是否可以到达针叶林，而是从已知的针叶林细胞开始，找到针叶林可以到达的每个细胞。 两者皆宜`T`和`.`作为可穿越的，同时治疗`D`和`F`被阻止。 然后，单个多源 BFS 或 DFS 访问可以属于唯一 Taiga 组件的每个单元。 

蛮力之所以有效，是因为每个单独的可达性查询都很小，但它会多次重复本质上相同的探索。 所有有效单元格都是从已知针叶林区域可到达的单元格这一观察结果让我们可以执行一次遍历。 由于每个单元最多被处理一次，因此算法在网格单元数量的线性时间内运行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((纳米)^2) | O(纳米) | 接受 20 by 20 |
 | 最佳 | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1. 将世界地图的 20 行读取到可变网格中。 每一个现有的`T`是独特的针叶林生物群系的可能起点。 
2. 将所有已知的`T`将单元格放入 DFS 堆栈并将其标记为已访问。 立即从所有已知的针叶林细胞开始很方便，因为它们已经被要求属于相同的最终生物群系。 
3. 当堆栈非空时，移除一个单元并检查其四个侧面相邻的邻居。 如果邻居位于 20 x 20 网格内并且其原始字符是以下任一者，则认为该邻居是可遍历的：`T`或者`.`。 

沙漠和森林细胞永远无法穿越，因为它们的生物群落是已知的并且无法更改。 
4. 当找到未访问的可遍历邻居时，将其标记为已访问并将其压入堆栈。 如果那个邻居是`.`，将其更改为`T`立即地。 

每个这样的单元都可以分配给针叶林，因为遍历仅使用可以合法成为针叶林的单元明确地找到了从已知针叶林单元到它的路径。 
5. 遍历结束后，打印修改后的网格。 每个访问过的点都变成了`T`，而每个无法到达的点、沙漠、森林和原始针叶林单元格都保留其所需的值。 

### 为什么它有效

 不变的是，每个被访问的单元都可以仅使用原始的从至少一个已知的针叶林单元到达`T`细胞和未探索的细胞。 因此，每个访问点都可以安全地分配给针叶林，并且遍历到达的所有已知针叶林单元都属于一个连接的组件。 

相反，假设一个未探索的细胞可能是某个有效的最终世界中的针叶林。 由于恰好存在一个针叶林生物群落并且至少存在一个已知的针叶林细胞，因此该细胞必须通过已经存在的细胞连接到已知的针叶林细胞。`T`或者最初未被探索过。 这样的路径不包含`D`或者`F`，因此遍历将沿着整个路径并访问单元格。 因此，该算法准确地标记了可能属于独特针叶林生物群落的细胞。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    grid = [list(input().strip()) for _ in range(20)]

    visited = [[False] * 20 for _ in range(20)]
    stack = []

    for r in range(20):
        for c in range(20):
            if grid[r][c] == 'T':
                visited[r][c] = True
                stack.append((r, c))

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while stack:
        r, c = stack.pop()

        for dr, dc in directions:
            nr = r + dr
            nc = c + dc

            if not (0 <= nr < 20 and 0 <= nc < 20):
                continue

            if visited[nr][nc]:
                continue

            if grid[nr][nc] == 'D' or grid[nr][nc] == 'F':
                continue

            visited[nr][nc] = True
            grid[nr][nc] = 'T'
            stack.append((nr, nc))

    sys.stdout.write('\n'.join(''.join(row) for row in grid))

if __name__ == "__main__":
    solve()
```第一个嵌套循环找到每个已知的 Taiga 单元并将其插入 DFS 堆栈中。 多个起点非常有用，因为输入可能包含几个独立的已知针叶林区域，这些区域必须通过最终地图中的未探索单元格进行连接。 

DFS 使用四个方向向量，与允许的网格移动完全对应。 当邻居离开网格、已经被访问过或者是已知的沙漠或森林单元时，该邻居将被拒绝。 

一个点被转换为`T`此刻它被发现了。 这是安全的，因为发现意味着已经存在一条从已知针叶林细胞到该点的路径，通过可以合法成为针叶林的细胞。 

边界检查必须在访问之前进行`grid[nr][nc]`。 这在 Python 中尤其重要，因为诸如此类的表达式`grid[-1]`是合法的，指的是最后一行，这会默默地将出界运动变成不正确的环绕运动。 

不涉及整数运算，因此整数溢出无关紧要。 整个网格仅包含 400 个单元，每个单元最多被压入堆栈一次。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(纳米) | 400 个单元格中的每个单元格最多被访问一次，每次访问都会检查四个邻居 |
 | 空间| O(纳米) | 访问的矩阵和 DFS 堆栈都可以包含 O(nm) 个单元 |

对于由未探索的细胞分隔的多个已知针叶林细胞，想象一行包含`T...T`。 第一个大河开始遍历，穿过三个点并到达第二个大河。 所有三个点都转换为`T`，生产`TTTTT`。 这是必需的，因为最终世界必须包含一个针叶林生物群系，并且未探索的细胞在已知部分之间提供了有效的连接。

对于一个拥有已知针叶林的完全开放的世界，每个细胞都与该针叶林相连。 遍历最终访问了所有 400 个单元格，并将所有 399 个未知单元格转换为`T`。 这是最大可能的针叶林生物群落，也证实了算法在已知针叶林周围仅扩展一层后不会停止。 

对于已知的森林和沙漠细胞，考虑一堵墙`F`或者`D`将针叶林与大片未开发区域分开的细胞。 遍历在那堵墙处停止，因为这些单元永远不会被推入堆栈。 即使未探索的区域相对于大河地区来说是巨大的，但除非有另一条路径绕着城墙，否则都不能分配给大河。 该算法通过普通的四向可达性准确地发现了这种区别。
