 ## 解决方案
 ## 问题理解

 我们在垂直墙的一侧有一个弹射器，另一侧有一个目标。 弹射器距墙 (a) 米，目标距墙外 (c) 米，距地面 (b) 米。 墙本身的高度 (d)，且 (b<d)。 我们需要在击中目标并穿过墙壁的所有轨迹中，射弹达到的最高点的最小可能值。 官方问题证实只需要代数，而无需明确处理抛射运动方程。 

将弹射器放置在水平坐标 (x=0) 处，将墙壁放置在 (x=a) 处，将目标放置在 (x=a+c) 处。 让

 [
 L=a+c。 
]

 射弹从 ((0,0)) 开始，到 ((L,b)) 结束。 由于轨迹是一条向下开口的抛物线，因此可以写为

 [
 y(x)=kx(L-x)+\frac{b}{L}x,
 ]

 其中 (k>0) 确定抛物线向下弯曲的强度。 这种形式很方便，因为两个端点条件已经内置：

 [
 y(0)=0,\qquad y(L)=b。 
]

 在墙壁处，轨迹必须满足

 [
 y(a)\ge d． 
]

 输入仅包含四个整数，因此不需要处理大型数组、图形或测试用例集合。 挑战完全是数学上的。 由于所需的答案是实数，因此实现需要浮点运算，但计算本身的大小是恒定的。 任何依赖于迭代大范围候选轨迹的算法都是不必要的。 

有几种边缘情况可能会暴露出不正确的实现。 第一个是当目标在地面上时。 例如，```
5 0 9 7
```大约有正确答案```
7.62222191701435
```除以 (b) 的粗心推导将会失败，因为 (b=0)。 上面的轨迹公式不存在这个问题，因为 (k) 仍然定义良好。 

另一个有用的情况是当墙壁正好位于轨迹最高点下方时。 为了```
5 0 5 7
```墙位于发射点和目标之间的中间，因此尽可能低的最大高度正好是 (7)。 正确的输出大约是```
7.0000000000000195
```浮点实现不应使用精确相等的方式将其结果与 (7) 进行比较。 

第三种边界情况是当目标很高但仍然严格低于墙壁时。 为了```
5 6 1 12
```正确答案约为 (15.778572363190715)。 这里，墙壁在水平方向上非常接近目标，因此轨迹在下降到目标之前必须大幅上升。 

## 方法

 一种强力方法是生成许多连接发射点和目标的可能的抛物线，测试每个抛物线是否达到墙壁至少 (d) 的高度，并保持最小的最大高度。 如果测试抛物线参数的(P)个候选值，则最坏情况采取(P)个轨迹评估。 问题在于参数是连续的，因此不存在保证精确最优的自然有限候选集。 使离散化更精细可以改善答案，但永远不会将该方法变成数学上精确的解决方案。 

蛮力想法之所以有效，是因为可以直接检查每个候选轨迹，但它失败了，因为我们正在对连续的抛物线族进行优化。 关键的观察结果是，一旦端点固定，只有一个参数保持空闲。 我们可以使用单个参数 (k) 编写整个轨迹，将壁条件表示为 (k) 的下限，然后直接将最大高度表示为 (k) 的函数。 

墙体条件实际上使优化变得特别简单。 由于目标位于墙壁下方，因此最佳轨迹是精确穿过墙壁顶部边缘的轨迹。 任何在墙上升高的轨迹都可以向目标减少，同时降低其最大高度。 这立即给出了 (k) 的最优值，之后顶点公式在恒定时间内给出了答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(P)) for (P) 候选轨迹 | (O(1)) | (O(1)) | 太慢或太近似 |
 | 最佳| (O(1)) | (O(1)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 令 (L=a+c) 为弹射器到目标的总水平距离。 我们使用弹射器位于 (x=0)、墙壁位于 (x=a) 和目标位于 (x=L) 的坐标系。 
2. 将到达目标的每个可能的轨迹表示为

 [
 y(x)=kx(L-x)+\frac{b}{L}x。 
]

 项 (kx(L-x)) 在两个端点处均为零，因此更改 (k) 可保留发射点和目标。 线性项使轨迹在 (x=L) 处达到高度 (b)。 
3. 评估墙壁处的轨迹：

 [
 y(a)=ka(L-a)+\frac{ab}{L}。 
]

 由于 (L-a=c)，

 [
 y(a)=kac+\frac{ab}{L}.
 ]

 为了清理墙壁，最佳轨迹满足 (y(a)=d)。 求解 (k) 给出

 [
 k=\frac{d-\frac{ab}{L}}{ac}。 
]

 分子为正，因为 (d>b) 且 (\frac{a}{L}<1)，因此这是一条有效的下开抛物线。 
4. 将轨迹重写为标准二次形式：

 [
 y(x)=-kx^2+\left(kL+\frac{b}{L}\right)x。 
]

 它的顶点出现在

 [
 x_v=\frac{kL+\frac{b}{L}}{2k}。 
]

 顶点处的值为

 [
 h=\frac{\left(kL+\frac{b}{L}\right)^2}{4k}。 
]

 这是最小可能的最大高度，因为我们已经选择了最小的可行值 (k)，即精确接触墙壁的轨迹。 
5. 将 (h) 作为浮点值打印。 不需要迭代搜索或特殊舍入，因为法官接受数字容差范围内的答案。 

### 为什么它有效

 对于每个可行轨迹，端点固定在 ((0,0)) 和 ((L,b))，因此轨迹只能通过系数 (k) 有所不同。 增加 (k) 会提高端点之间的轨迹，包括墙壁处的轨迹。 由于 (d>b)，(k) 的可行值位于增加 (k) 也会增加抛物线最大高度的一侧。 因此，最小高度可行轨迹恰好是壁面高度为 (d) 且不大于 (d) 的轨迹。 (k) 的公式精确地构造了该轨迹，然后顶点公式给出了其真实的最大高度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b, c, d = map(int, input().split())

    L = a + c

    # The optimal trajectory passes exactly through the top
    # of the wall.
    k = (d - a * b / L) / (a * c)

    # Maximum value of
    # y(x) = k*x*(L-x) + (b/L)*x
    h = (k * L + b / L) ** 2 / (4 * k)

    print(f"{h:.15f}")

if __name__ == "__main__":
    solve()
```第一个计算形成完整的水平距离 (L=a+c)。 保持该值明确可以使几何图形更易于理解，并避免重复写入相同的总和。 

下一行直接求解壁方程。 表达式`a * b / L`是壁面抛物线线性部分的贡献，而`a * c`是系数乘法 (k)。 这些操作的顺序很重要，因为除以 (L) 必须在从所需墙高中减去贡献之前进行。 

最终的表达式是二次函数在其顶点的值。 最好直接计算顶点高度，而不是先计算顶点坐标，然后将其代入抛物线。 这使用更少的操作并避免不必要的中间值。 

所有输入值都是整数，但是`/`故意产生浮点值。 Python 整数本身不会溢出，其余算术使用 Python 的双精度浮点表示。 

输出使用小数点后十五位数字。 官方声明允许数值容差，因此无需匹配样本的精确浮点表示。

 ## 边缘情况

 对于地面目标情况```
5 0 9 7
```计算得出 (L=14) 和

 [
 k=\frac{7}{5\cdot9}=\frac{7}{45}。 
]

 最大值为

 [
 h=\frac{(14k)^2}{4k}=49k=\frac{343}{45}\approx7.622222。 
]

 算法中没有任何内容能除以 (b)，因此零目标高度不会导致特殊情况。 

对于对称情况```
5 0 5 7
```我们得到 (L=10) 和 (k=7/25=0.28)。 顶点出现在 (x=5) 处，正好是墙所在的位置，其高度为 (7)。 因此，该算法返回 (7.000000000000000) 直至浮点表示形式。 

对于靠近墙壁的高目标，请考虑```
5 9 1 10
```其中（L=6）。 壁方程给出

 [
 k=\frac{10-\frac{45}{6}}{5}
 =\frac{1}{2}。 
]

 最大高度为

 [
 h=\frac{(3+1.5)^2}{2}=10.125。 
]

 该计算说明了为什么目标高度必须包含在墙约束和顶点公式中。 将轨迹视为两个端点都位于地面会产生不同且不正确的结果。 

最后，约束 (b<d) 保证目标位于墙壁下方。 这就是使最佳轨迹恰好在高度 (d) 处接触墙壁的原因。 如果一个实现不小心使用了`>`而不是`>=`从概念上讲，在推导壁条件时，它可能会选择不必要地高于所需的轨迹，从而无法最小化最大高度。
