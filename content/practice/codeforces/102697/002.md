 ## 问题理解

 任务是计算将两个给定的正整数相乘，然后将结果乘以三所产生的值。 输入分别包含两个因子，输出是表示这个三重乘积的单个整数。 

这两个数字都比较小，最多都是2000，直接算术运算就足够了。 不需要先进的数据结构或算法，因为整个计算是恒定时间的。 主要关心的是正确执行乘法并打印结果。 

一些边缘情况可能会在不小心的实施中导致错误。 如果两个数字都是可能的最小值，则程序仍必须正常处理乘法。 

例如：```
Input:
1
1

Output:
3
```忘记最终乘以三的解决方案将错误地打印`1`。 

另一个常见错误是错误地更改操作顺序。 表达式应该是`a * b * 3`，这相当于`(a * b) * 3`。```
Input:
2000
2000

Output:
12000000
```在某些语言中，答案不适合小整数类型，因此实现应该使用能够容纳乘积的整数类型。 Python 整数会自动处理这个问题。 

## 方法

 这个问题的暴力解释是寻找数字之间的一些更复杂的关系，但没有隐藏的结构可以发现。 所需值直接由算术表达式定义。 尝试不同组合或模拟乘法的暴力方法只会增加不必要的工作，同时仍然产生相同的结果。 

关键的观察结果是该问题需要一次确定性计算。 一旦读取了两个输入值，答案就完全确定了。 整个解决方案简化为读取两个整数，将它们相乘，再乘以三，然后打印结果。 

暴力方法是不必要的，而直接算术求解可以在常数时间内完成。

 ## 算法演练

 1. 从输入中读取两个整数。 每个值代表产品的一个因素。 
2. 将两个值相乘。 这给出了两个数字的正常乘积。 
3. 将结果乘以三并打印。 额外的乘法是问题的全部要求。 

为什么它有效：

 该算法完全遵循所需输出的数学定义。 由于每对输入值只有一个可能的答案，因此直接计算表达式不会错过任何情况。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

def solve():
    a = int(input())
    b = int(input())
    print(a * b * 3)

if __name__ == "__main__":
    solve()
```程序将这两行读取为整数并将它们存储在`a`和`b`。 乘法的执行顺序与问题中的公式相同，这样可以避免意外遗漏三倍。 

Python 的整数实现支持任意精度，因此即使输入为其最大值，也不存在溢出问题。 

该解决方案不需要数组、循环或额外的内存，因为输入仅包含两个数字。

 ## 边缘情况

 对于尽可能最小的输入：```
1
1
```该算法读取两个值，计算`1 * 1 * 3`，并打印`3`。 仅将两个输入相乘的解决方案将会失败，因为它会忽略所需的因子三。 

对于最大可能的输入：```
2000
2000
```该算法计算`2000 * 2000 * 3 = 12000000`。 直接计算避免了Python中的溢出问题，并且无需任何特殊处理即可产生正确的结果。 

对于一个数字远小于另一个数字的情况：```
1
2000
```该算法仍然应用相同的公式和输出`6000`。 不需要特殊情况，因为乘以一个因子自然会保留另一个因子。
