 ## 解决方案
 ## 问题理解

 我们有`n`并联正电阻。 如果两个电阻的阻值`a`和`b`，它们的等效电阻为

 [
 R=\frac{ab}{a+b}。 
]

 对于两个以上的电阻器，该语句通过将迄今为止获得的等效电阻与下一个电阻器重复组合来定义结果。 我们需要将最终的等效电阻打印为十进制数，而不需要手动四舍五入。 官方声明给出了1秒的时间限制和256MB的内存限制。 

重新解释并联电路的最有用的方法是通过电导。 电阻器的电导与电阻`r`是`1/r`。 并联电导相加，因此对于电阻`r1, r2, ..., rn`最终阻力为

 [
 R=\frac{1}{\frac1{r_1}+\frac1{r_2}+\cdots+\frac1{r_n}}。 
]

 该语句没有公开数字上限`n`，所以我们应该避免依赖特定的最大值。 所有电阻器的线性传递是适当的目标，因为输入本身包含`n`电阻值。 任何执行与每对、每个子集或每个排序成比例的工作的方法都会比输入大小增长得更快。 

有两种边缘情况值得关注。 首先，最小的有效输入恰好有两个电阻。 例如，```
2
11 19
```给出```
6.966666666666667
```粗心的实现将累积阻力初始化为零并立即应用`(a * b) / (a + b)`当第一个电阻被处理时会产生一个无效的中间值。 仅当我们使用倒数公式时，从零开始才有意义。 

其次，相同的电阻是完全有效的。 例如，```
3
10 10 10
```具有总电导

 [
 \frac1{10}+\frac1{10}+\frac1{10}=\frac3{10}，
 ]

 所以答案是```
3.333333333333333
```假设电阻值必须不同的实现将拒绝有效电路。 输入仅表示电阻为正整数。 

第三种浮点边缘情况是，答案通常不是整数，并且预计不会四舍五入到固定的小数位数。 例如，`11`和`19`产生循环小数。 打印普通的 Python 浮点表示是合适的，因为判断器接受十进制近似值，而不需要符号有理数输出。 

## 方法

 直接模拟遵循语句中的递归定义。 从第一个电阻开始，反复组合当前等效电阻`R`与下一个阻力`x`使用

 [
 R\leftarrow\frac{Rx}{R+x}。 
]

 这已经是一个线性时间算法。 处理完第一个电阻后，有`n-1`更新，并且每次更新执行恒定数量的算术运算。 因此它的总工作量是`O(n)`，因此与许多问题不同，直接模拟实际上并不算太慢。 

真正的强力方法可以更进一步，在评估结果之前尝试电阻的每种排序，或者成对组合的每种可能的括号。 有`n!`单独可能的排序，即使有固定的排序，也有`C(n-1)`可能的二元括号，其中`C`是一个加泰罗尼亚号码。 这会产生比输入大小多得多的工作，并且是不必要的，因为并联电阻在数学上与电阻器组合的顺序无关。 

有用的观察比仅仅说该操作是结合的更有效。 开始于

 [
 R=\frac{ab}{a+b},
 ]

 取其倒数：

 [
 \frac1R=\frac{a+b}{ab}=\frac1a+\frac1b。 
]

 这意味着每个并联电阻器独立地贡献相同的总和。 我们可以简单地积累，而不是重复构建新的阻力并将其与下一个阻力相结合

 [
 S=\sum_{i=1}^{n}\frac1{r_i}
 ]

 并返回`1 / S`。 

直接模拟和倒数公式都是`O(n)`。 倒数公式是优选的，因为它直接遵循并联电路的物理结构，避免了重复的乘法和除法，并且使得正确性特别容易证明。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解排序/括号 | 超线性，至少`O(n!)`|`O(n)`| 太慢了 |
 | 直接顺序模拟|`O(n)`|`O(1)`| 已接受 |
 | 倒数总和 |`O(n)`|`O(1)`| 已接受 |

 ## 算法演练

 1. 阅读`n`和`n`正电阻值。 这些值本身就是所需要的，因此不需要构建电路图或存储任何额外的结构。 
2. 初始化浮点变量`conductance`为零。 该变量表示迄今为止处理的电阻器累积的总电导。 
3. 对于每一个阻力`r`， 添加`1.0 / r`到`conductance`。 有电阻的电阻`r`准确贡献`1/r`电导，并联组件的电导相加。 
4. 处理完所有电阻后，计算`1.0 / conductance`。 总电导的倒数是完整并联电路的等效电阻。 
5. 直接打印结果浮点值。 该问题不要求固定位数或手动舍入，因此 Python 的正常十进制表示就足够了。 

不变量是在处理完第一个之后`k`电阻器，`conductance`等于

 [
 \sum_{i=1}^{k}\frac1{r_i}。 
]

 最初这个总和为零，这对于没有处理的电阻器来说是正确的。 添加`1/r`当处理下一个电阻器时，将总和扩展为该电阻器的电导。 最后一个电阻之后，累加的值为总并联电导，其倒数正是所需的等效电阻。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    resistances = list(map(int, input().split()))

    conductance = 0.0

    for r in resistances:
        conductance += 1.0 / r

    answer = 1.0 / conductance
    print(answer)

if __name__ == "__main__":
    solve()
```前两行读取电阻器的数量和电阻阵列。 由于输入包含下一行的所有电阻，因此单个`split()`对于指定的格式就足够了。`conductance`被初始化为`0.0`，而不是`0`，使预期的浮点运算变得明确。 每个`1.0 / r`是浮点值，因此累加和保留分数电导。 

仅在每个电阻器做出贡献后才取最终的倒数。 颠倒顺序并尝试重复取倒数会改变数学表达式，因此累加必须首先发生在电导空间中。 

Python 整数不会溢出，并且电阻值为正，因此不会发生被零除的情况。 该问题没有多测试用例结构，因此只有一次调用`solve()`。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |`O(n)`| 每个电阻器恰好贡献一个倒数和一个加法。 |
 | 空间|`O(n)`使用所示的输入存储，`O(1)`辅助| 该列表存储输入电阻； 计算本身仅使用一个累加器。 |

 就输入大小而言，线性运行时间是最佳的，因为必须读取每个电阻。 计算本身使用恒定的额外状态。 官方限制为一秒和 256 MB，并且这种方法仅对每个电阻执行一次简单的算术更新。 

也可以通过直接处理来自输入标记的电阻值来避免该列表，但保留该列表使实现变得简单并且不会影响渐近结果。

import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    resistances = list(map(int, input().split()))

    conductance = 0.0
    for r in resistances:
        conductance += 1.0 / r

    print(1.0 / conductance)

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

# Provided sample 1
assert run(

# Provided sample 2

# Minimum-size input

    "2\n"
    "1 1\n"
) == "0.5\n"

# All equal values

# Boundary-style case with very different resistance magnitudes

## 边缘情况

 对于恰好两个电阻器，```
2
11 19
```电导累加器从零开始，接收`1/11`，然后收到`1/19`，最后变成`1/(1/11 + 1/19)`。 结果是`6.966666666666667`。 两个电阻器没有特殊情况，这消除了常见的相差一风险。 

对于相等的电阻，```
3
10 10 10
```累加器变成`0.1`， 然后`0.2`， 然后`0.3`。 其倒数为`3.333333333333333`。 每个电阻器都是独立处理的，因此重复的电阻器不需要特殊处理。 

对于截然不同的价值观，```
4
1 2 4 8
```电导是

 [
 1+\frac12+\frac14+\frac18=1.875,
 ]

 所以等效电阻是

 [
 \frac1{1.875}=0.5333333333333333。 
]

 这会捕获意外增加电阻而不是电导的实现。 

最后，考虑大量相同单位电阻器：```
100000
1 1 1 ... 1
```和`100000`的出现次数`1`。 每个电阻器贡献一个单位的电导，因此总计为`100000`等效电阻为`0.00001`。 该算法对每个电阻器执行一次更新，因此运行时间随着输入量而不是电阻器对的数量线性增长。 

每个案例背后的关键思想都是相同的：对于并联组件，电阻本身不是相加的，但电导可以。 一旦电路被表示为倒数之和，问题就简化为一次线性扫描。
