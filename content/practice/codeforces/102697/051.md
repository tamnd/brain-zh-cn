 ## 解决方案
 ## 问题理解

 我们有两个轴对齐的矩形。 每个矩形由两个对角描述，因此一行包含四个整数`x1 y1 x2 y2`对于第一个矩形，下一行包含第二个矩形的相同信息。 坐标可以按任一顺序给出，因此解决方案应该做的第一件事是将每个矩形转换为其左、右、下和上边界。 

所需答案是`YES`当两个矩形周长至少有一个公共点时，并且`NO`否则。 这种解释遵循问题的特殊条件，即两个相同的矩形相交，而当它们的周长不相交时，严格位于另一个矩形内部的矩形不会相交。 

官方说法给出了1秒的时间限制和256MB的内存。 它不发布显式坐标边界，因此没有有用的大坐标`n`来优化。 输入本身始终仅包含两个矩形，这意味着预期的解决方案应该是恒定时间并且应该仅取决于八个坐标。 

主要的边缘情况是严格遏制。 考虑```
0 0 10 10
2 2 8 8
```正确的输出是```
NO
```第二个矩形完全位于第一个矩形内部，并且它们的周长从不接触。 仅检查两个矩形的 x 和 y 间隔是否重叠的粗心解决方案将打印`YES`，因为两个投影完全重叠。 

相反的情况是具有接触边界的遏制：```
0 0 10 10
0 2 8 8
```正确的输出是```
YES
```第二个矩形沿左侧与第一个矩形相接触。 由于两个矩形共享边界点，因此包含并不严格。 在检测遏制时使用严格的不等式可以正确处理这种情况。 

另一个重要的情况是两个相同的矩形：```
0 0 5 5
0 0 5 5
```正确的输出是```
YES
```严格包含测试不得将相同的矩形分类为包含，因为每个对应的边界点都属于两个矩形。 该声明明确表示重叠的相同矩形算作相交。 

最后，矩形可以恰好在一个角处相交：```
0 0 2 2
2 2 5 5
```正确的输出是```
YES
```区间比较必须包含在内。 更换`<=`经过`<`会错误地拒绝此案。 

## 方法

 一个直接的暴力想法是检查两个矩形的组合边界框中的每个整数点，并检查该点是否位于两个周长上。 由于所有输入坐标都是整数，并且矩形是轴对齐的，因此它们边界之间的任何交点都具有整数坐标。 对于包含以下内容的边界框`W + 1`可能的整数 x 坐标和`H + 1`可能的整数 y 坐标，最坏的情况精确检查`(W + 1)(H + 1)`点。 对于大的坐标范围，这可能变得任意昂贵，并且问题没有给出使这种枚举合理的坐标界限。 

更几何的强力方法可以检查所有成对的边界段。 每个矩形有 4 个边，正好有 16 个线段对。 该方法已经是恒定时间并且将被接受，但它需要比必要的更多的几何代码。 

关键的观察是轴对齐的矩形完全由两个一维间隔描述。 如果矩形的 x 范围重叠且 y 范围重叠，则矩形只能具有相交的周长。 然而，仅间隔重叠是不够的，因为严格遏制也会在周界保持分离的情况下产生重叠投影。 

有用的减少是执行两个测试。 首先，检查矩形是否具有重叠的 x 和 y 间隔，包括接触端点。 其次，检查两个矩形是否严格位于另一个矩形内部。 如果这两个条件都成立，则周长必须在某处相交。 如果任一间隔不相交，则矩形将被分开。 如果一个矩形严格位于另一个矩形内部，则两个周长不相交。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 整数点枚举 | O(宽·高) | O(1) | O(1) | 对于大坐标来说太慢 |
 | 成对边相交 | O(1) | O(1) | O(1) | O(1) | 已接受 |
 | 区间重叠+遏制| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取每个矩形的两个对角并将其归一化。 对于有角的矩形`(x1, y1)`和`(x2, y2)`， 定义`left = min(x1, x2)`,`right = max(x1, x2)`,`bottom = min(y1, y2)`， 和`top = max(y1, y2)`。 这消除了对首先列出哪个对角的任何依赖。 
2. 检查 x 投影是否重叠`max(left1, left2) <= min(right1, right2)`。 该不等式具有包容性，因为共享垂直边界或单个 x 坐标仍然与交集兼容。 
3. 检查 y 投影是否以相同的方式重叠，使用`max(bottom1, bottom2) <= min(top1, top2)`。 如果任一投影不相交，则矩形不能具有公共边界点。 
4. 检查第一个矩形是否严格位于第二个矩形内部。 这恰好发生在`left2 < left1`,`right1 < right2`,`bottom2 < bottom1`， 和`top1 < top2`。 
5. 检查第二个矩形严格位于第一个矩形内部的对称条件。 
6. 打印`YES`恰好当投影重叠并且严格包含条件都不成立时。 严格的不平等是真正的遏制与仅沿着边缘或角落接触的矩形的区别。 

**为什么它有效。** 假设算法打印`YES`。 x 和 y 投影重叠，因此两个矩形占据平面的公共区域或在其边界处接触。 由于两个矩形都没有严格包含在另一个矩形内，因此它们的边界不能完全分开。 因此，它们的周长必须至少共享一个点。 

相反，假设矩形的周长相交。 它们的 x 和 y 投影必然重叠，因为公共边界点在两个矩形中具有相同的 x 坐标和 y 坐标。 此外，两个矩形都不能严格位于另一个矩形内部，因为严格的包含会使内周完全远离外周。 因此，每个真正的交叉点都会通过这两项测试，并且算法会打印`YES`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def normalize(rect):
    x1, y1, x2, y2 = rect
    left = min(x1, x2)
    right = max(x1, x2)
    bottom = min(y1, y2)
    top = max(y1, y2)
    return left, right, bottom, top

def solve():
    r1 = normalize(list(map(int, input().split())))
    r2 = normalize(list(map(int, input().split())))

    left1, right1, bottom1, top1 = r1
    left2, right2, bottom2, top2 = r2

    x_overlap = max(left1, left2) <= min(right1, right2)
    y_overlap = max(bottom1, bottom2) <= min(top1, top2)

    first_inside = (
        left2 < left1 and
        right1 < right2 and
        bottom2 < bottom1 and
        top1 < top2
    )

    second_inside = (
        left1 < left2 and
        right2 < right1 and
        bottom1 < bottom2 and
        top2 < top1
    )

    if x_overlap and y_overlap and not first_inside and not second_inside:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```这`normalize`函数将每对对角转换为规范表示`(left, right, bottom, top)`。 如果没有此步骤，比较将必须处理每个输入矩形的四个可能的方向。 

这`x_overlap`和`y_overlap`表达式使用包含比较。 这是必要的，因为触摸边缘或角落算作交叉点。 例如，`[0, 2]`和`[2, 5]`在端点处重叠`2`。 

遏制检查使用严格的不等式。 如果边界坐标相等，则矩形接触且包含不严格。 这正是我们所需要的情况，例如一个矩形共享外部矩形的左边缘。 

Python 整数不会溢出，因此即使坐标远大于 32 位整数的范围，该解决方案仍然是安全的。 不需要循环或辅助数据结构。 

## 工作示例

 对于提供的示例，输入是```
-5 -5 5 5
4 4 8 8
```归一化后，第一个矩形是`[-5, 5] × [-5, 5]`，而第二个是`[4, 8] × [4, 8]`。

对于严格遏制的例子，```
0 0 10 10
2 2 8 8
```标准化的矩形已经按照所需的顺序排列。 

| 步骤| 矩形 1 | 矩形 2 | x 重叠 | y 重叠 | 严格遏制| 结果 |

 ## 边缘情况

 为了严格遏制，```
0 0 10 10
2 2 8 8
```标准化使两个矩形保持不变。 x 范围`[0,10]`和`[2,8]`重叠，y 范围也是如此。 第二个矩形满足`0 < 2`,`8 < 10`,`0 < 2`， 和`8 < 10`，所以它严格位于第一个内部。 该算法拒绝该对并打印`NO`。 

对于边界接触，```
0 0 10 10
0 2 8 8
```x 范围在多个点处重叠，y 范围重叠。 第二个矩形并不严格位于第一个矩形内，因为它的左边界等于第一个矩形的左边界。 因此该算法打印`YES`，正确地将共享垂直边视为交集。 

对于相同的矩形，```
0 0 5 5
0 0 5 5
```两个包含测试都是错误的，因为所有相应的边界都是相等的而不是严格嵌套的。 投影重叠，因此算法打印`YES`。 

对于单角路口，```
0 0 2 2
2 2 5 5
```x 范围相交于`x = 2`，y 范围相交于`y = 2`。 两种比较都使用`<=`，所以共享点`(2, 2)`被接受。 两个矩形都没有严格包含在另一个矩形中，从而给出正确的输出`YES`。 

对于反向角顺序，```
5 5 0 0
8 8 4 4
```标准化将矩形转换为`[0,5] × [0,5]`和`[4,8] × [4,8]`。 该算法的其余部分与普通方向相同并产生`YES`。 这就是为什么在开始时标准化坐标比尝试单独处理每个可能的输入方向更可取的原因。
