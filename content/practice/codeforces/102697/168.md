 ## 解决方案
 ## 问题理解

 任务是打印第一个`n`帕斯卡三角形的行。 排`i`恰好包含`i`整数。 每行的第一个和最后一个值是`1`，而每个内部值都是通过将前一行中其正上方的两个值相加而获得的。 例如，前四行构建完成后，下一行是`1 4 6 4 1`。 

输入由一个正整数组成`n`，并且输出必须准确包含`n`行，有行`i`含有`i`属于三角形该行的值。 这是问题给出的完整规范。 官方声明并没有给出上限`n`，所以自然约束来自输出本身：打印`n`行需要打印`1 + 2 + ... + n = n(n+1)/2`整数。 任何可接受的解决方案都必须花费至少 Ω(n²) 时间来简单地生成这些整数。 

该输出下限立即排除了其工作量为三次或指数的算法`n`一次`n`变得适度大。 二次算法是正确的目标，因为它与必须打印的数据量相匹配。 如果一次生成一行而不是存储整个三角形，那么内存也可以保持线性。 

有一些边界情况很容易处理不当。 为了`n = 1`，输出只是一行包含`1`。 通过构造“前一行”开始然后仅打印新生成的行的解决方案可能会意外地不打印任何内容。 

例如，输入```
1
```必须产生```
1
```因为第一行由一个`1`。 

前两行还暴露了索引错误：```
2
```必须产生```
1
1 1
```两排都没有内部元素。 假设每行都有一个内部部分的循环可能会意外地省略第二行的值或访问不存在的元素。 

另一个常见的错误是忘记最后一个值始终是`1`。 为了```
5
```第五行是```
1 4 6 4 1
```不是`1 4 6 4`。 递归仅计算内部位置，因此必须显式添加两个边界。 

## 方法

 简单的强力解决方案可以将每个值独立计算为二项式系数。 行中的值`r`，使用从零开始的索引，是`C(r, k)`。 不依赖预先计算的三角形来计算它的一种方法是分别计算每个系数的乘法公式。 即使使用对称性，只有`k <= r/2`计算出位置处的系数`k`需要 θ(k) 算术步骤。 在所有行中这给出`Σ(r=0..n-1) Σ(k=1..floor(r/2)) Θ(k) = Θ(n³)`,

 因此，算术量呈立方增长，而所需的输出仅包含 θ(n²) 值。 该方法在数学上是正确的，但它重复了相邻系数可以共享的工作。 

有用的结构是帕斯卡三角形已经由局部递归定义。 一次排`r - 1`已知，行的每个内部值`r`从上一行中的两个相邻值获得。 没有理由从头开始重新计算这些值。 

我们可以将当前行保留在数组中。 下一行开始和结束于`1`，它们之间的每个位置都是当前行的两个相邻元素的总和。 打印新行后，它将成为下一次迭代的当前行。 每行需要与其长度成正比的工作，因此构造所有行需要 θ(n²)，与必须打印的值的数量完全匹配。 

蛮力之所以有效，是因为每个位置实际上都是一个二项式系数，但它会因为重复地重新发现相同的信息而失败。 相邻行通过简单的二值递归连接的观察结果将工作量减少到不可避免的输出大小。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(n) | 对于大型来说太慢`n`|
 | 最佳 | O(n²) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读`n`，必须打印的行数。 每次迭代我们将生成一行，因此循环自然对应于所需的输出行。 
2. 从空的前一行开始。 在生成第一行之前，其上方没有任何值。 
3.对于行长`length`从`1`通过`n`，创建一个新行，其第一个和最后一个值为`1`。 无论已经构造了多少行，这些始终是帕斯卡三角形的边界值。 
4. 对于每个内部位置，添加上一行中的两个相邻值。 如果上一行是`[1, 3, 3, 1]`，例如，下一行的内部变成`1 + 3`,`3 + 3`， 和`3 + 1`, 给予`[1, 4, 6, 4, 1]`。 
5. 打印新构造的行并用它替换前一行。 构造下一行只需要紧邻的前一行，因此保留较旧的行会浪费内存。 

### 为什么它有效

 不变量是在构造行之前`i`,`previous`恰好包含行`i - 1`帕斯卡三角形。 新行位置`1`在两个边界上，这与三角形的定义一致。 每个内部位置都被计算为其正上方的两个值的总和，因此每个内部值也符合定义。 因此新构造的行正是 row`i`，并将其分配给`previous`恢复下一次迭代的不变量。 由于该算法从第一行开始并通过行重复此参数`n`，每行打印都是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    previous = []

    for length in range(1, n + 1):
        if length == 1:
            current = [1]
        else:
            current = [1] * length

            for j in range(1, length - 1):
                current[j] = previous[j - 1] + previous[j]

        sys.stdout.write(" ".join(map(str, current)) + "\n")
        previous = current

if __name__ == "__main__":
    solve()
```这`previous`数组恰好存储一个完整的行。 对于第一行，特殊情况`length == 1`创造`[1]`。 对于后面的每一行，用以下命令初始化整个数组`1`立即处理两个边界。 

循环结束`j`开始于`1`并在之前停止`length - 1`，因为这些正是内部位置。 对于职位`j`，上面的两个值是`previous[j - 1]`和`previous[j]`。 该索引是实现中的核心逐一细节。 

打印后，`previous = current`使新行可用于下一次迭代。 不需要前面的行，因此该算法永远不会构造二维三角形。 

Python 整数不会在固定机器宽度上溢出，这避免了使用固定宽度整数类型的语言中出现的整数溢出问题。 值本身变得很大`n`随着尺寸的增大，它们的尺寸自然会反映在打印它们所需的工作量上。 

使用`sys.stdout.write`避免重复调用更高开销的`print`每行的函数。 输入仅包含一个整数，因此即使输入处理不是瓶颈，标准的快速输入模式也足够了。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n²) | 排`i`需要 O(i) 工作，并且有`n`行。 打印本身也需要 θ(n²) 值。 |
 | 空间| O(n) | 只保留当前行和前一行，每行最多包含`n`价值观。 |

 就输出元素的数量而言，二次运行时间是最佳的，因为所需的输出本身包含`n(n+1)/2`整数。 线性辅助空间也足够了，因为递归仅取决于紧邻的前一行。 官方问题给出了 1 秒的时间限制和 256 MB 的内存限制，因此避免任何三次重新计算是关键的性能要求。

 ## 边缘情况

 对于`n = 1`，算法输入`length == 1`分支和构造`[1]`。 它立即打印该行并完成。 没有尝试访问`previous[j]`，因此空的前一行不会导致索引错误。 确切的输出是`1`。 

为了`n = 2`，第一次迭代产生`[1]`。 第二次迭代初始化`[1, 1]`并且内部循环没有迭代，因为没有内部位置。 因此输出是```
1
1 1
```这处理一行恰好有两个元素的边界。 

为了`n = 3`，第三行开始为`[1, 1, 1]`。 它唯一的内部位置是索引`1`，它被替换为`previous[0] + previous[1] = 1 + 1 = 2`。 最后一行变成`[1, 2, 1]`，确认内部循环的边界仅包含每个内部元素一次。 

对于样品`n = 5`，第五次迭代收到`[1, 3, 3, 1]`作为`previous`。 它将三个内部值计算为`1 + 3 = 4`,`3 + 3 = 6`， 和`3 + 1 = 4`，同时两个边界值保持不变`1`。 结果正是`1 4 6 4 1`。 

对于大输入，例如`n = 1000`，该算法仍然只存储前一行和当前行。 生成值的数量是 θ(n²)，这是不可避免的，因为必须将所有值打印出来。 该实现不会递归地重新计算系数或保留整个三角形，因此其工作和辅助存储器遵循预期的二次和线性边界。
