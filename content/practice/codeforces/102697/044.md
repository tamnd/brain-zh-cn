 ## 解决方案
 ## 问题理解

 任务故意简单。 我们收到一个句子作为一行，并且该句子包含偶数个单词。 我们必须将单词序列分成相等的两半，然后将后半部分放在前半部分之前。 

例如，这些词`reverse this sentence you have to`分为`reverse this sentence`和`you have to`所以翻译后的句子就变成了`you have to reverse this sentence`。 

官方问题指定了1秒的时间限制和256MB的内存，并保证字数为偶数。 该语句没有提供句子长度的数字上限，因此最安全的设计是单词数量呈线性。 阅读、拆分和重建句子自然都需要 O(n) 时间，其中 n 是单词数。 任何重复扫描或移动句子大部分的方法都可能不必要地变得二次。 

有一些小情况可能会暴露粗心的实现。 只有两个字，比如`hello world`，每一半包含一个单词，所以正确的输出是`world hello`。 假设两半都包含多个单词的实现可能会错误地处理中点。 

另一个边界情况是含有重复单词的句子。 用于输入`go go stay stay`，正确的输出是`stay stay go go`。 这两半必须根据它们的位置来处理，而不是根据不同的单词值来处理，因此使用集合或任何删除重复项的操作都是不正确的。 

最后一个常见错误是忘记输入是完整的行而不是整数序列。 用于输入`reverse this sentence you have to`, 呼叫`input().split()`是合适的，因为它将行分成单词，而仅处理一个标记将丢失句子的其余部分。 

## 方法

 考虑转换的一种强力方法是构建所有可能的单词顺序，并搜索后半部分首先出现的顺序。 这是正确的，因为所需的答案是这些排列之一，但它完全不切实际。 有n个单词，就有n个！ 可能的排列，所以即使 n = 10 也已经给出了 3,628,800 个候选，而且这个数字增长得太快而没有用处。 

蛮力方法之所以有效，是因为它最终会考虑所需的排列，但会失败，因为问题并不要求我们发现未知的排列。 需要移动的位置已经完全由中点决定了。 

关键的观察结果是，所需的输出只是将单词序列旋转其长度的一半。 如果这些话是`w[0], w[1], ..., w[n-1]`，答案是`w[n/2], ..., w[n-1], w[0], ..., w[n/2-1]`。 

一旦单词存储在列表中，Python 就可以通过切片获得两半并将它们连接起来。 每个单词都会被复制固定次数，从而获得线性时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·n!) | O(n·n!) | 每个候选人 O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取完整的输入行并将其拆分为单词列表。 我们需要单词本身，因为转换是针对单词位置而不是单个字符进行的。 
2. 计算中点为`n // 2`， 在哪里`n`是单词数。 该语句保证单词数为偶数，因此这个中点将句子分为两个大小相等的部分。 
3. 从中间到结尾取出单词。 这些构成后半部分，并且必须出现在翻译句子的前面。 
4. 从开头到中点之前的位置取出单词。 这些构成上半场，并且必须在下半场之后出现。 
5. 将两个部分连接起来（中间有一个空格）并打印结果句子。 加入列表而不是手动添加空格可以避免丢失空格和不需要的尾随空格。 

为什么它有效：不变的是两个切片按照其原始内部顺序准确包含原始前半部分和原始后半部分。 该算法输出第二个切片，然后输出第一个切片，这正是所需的转换。 由于每个原始单词恰好属于一半，只出现一次，并保持其相对于同一半中其他单词的位置，因此任何单词都不会丢失、重复或错误地重新排序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    words = input().split()
    mid = len(words) // 2

    answer = words[mid:] + words[:mid]
    print(" ".join(answer))

if __name__ == "__main__":
    solve()
```第一行读取整个句子，`split()`将其转换为算法使用的单词序列。 多个空格（如果存在）自然由`split()`，而所需的输出是在连续单词之间恰好有一个空格来重建的。`mid = len(words) // 2`是安全的，因为该问题保证单词数为偶数。 表达式`words[mid:]`正好从后半部分的第一个单词开始，而`words[:mid]`恰好包含前半部分。 

这两个列表按所需的顺序连接起来。 最后，`" ".join(answer)`创建不带尾随空格的输出句子。 不存在整数溢出问题，因为唯一的算术运算是将字数除以二。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 拆分、切片、连接和连接过程的总单词数为 O(n)。 |
 | 空间| O(n) | 单词列表和结果列表包含 O(n) 个单词。 |

 时间限制为 1 秒，内存限制为 256 MB。 由于输入本身包含 n 个单词，因此 O(n) 处理是渐近最优的：算法必须至少读取这些单词。 因此，该实现直接随着输入的大小进行缩放，而不是引入不必要的重复扫描或排列生成。 

## 测试用例```python
import sys
import io

def solve():
    words = input().split()
    mid = len(words) // 2
    answer = words[mid:] + words[:mid]
    print(" ".join(answer))

def run(inp: str) -> str:
    global input
    old_stdin = sys.stdin
    old_input = input

    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    try:
        output = io.StringIO()
        old_stdout = sys.stdout
        sys.stdout = output
        try:
            solve()
        finally:
            sys.stdout = old_stdout
        return output.getvalue()
    finally:
        sys.stdin = old_stdin
        input = old_input

# Provided sample
assert run("reverse this sentence you have to\n") == \
       "you have to reverse this sentence\n", "sample 1"

# Minimum-size input
assert run("hello world\n") == \
       "world hello\n", "minimum size"

# All words equal
assert run("go go go go\n") == \
       "go go go go\n", "all equal values"

# Boundary case with exactly two words in each half
assert run("one two three four\n") == \
       "three four one two\n", "half boundary"

# Larger input
large_words = [f"w{i}" for i in range(10000)]
large_input = " ".join(large_words) + "\n"
large_expected = " ".join(large_words[5000:] + large_words[:5000]) + "\n"
assert run(large_input) == large_expected, "large input"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 |`hello world`|`world hello`| 最小偶数字数和中点处理 |
 |`go go go go`|`go go go go`| 重复的值被保留而不是去重 |
 |`one two three four`|`three four one two`| 两半之间的正确边界 |
 | 10,000 个不同的单词 | 下半场接着上半场| 大输入的线性处理 |

 ## 边缘情况

 最小的情况是`hello world`。 该列表的长度为二，所以`mid = 2 // 2 = 1`。 切片`words[1:]`是`["world"]`， 和`words[:1]`是`["hello"]`。 他们的串联是`["world", "hello"]`, 生产`world hello`。 这会捕获一个差一错误，其中实现可能会意外使用`n // 2 - 1`或者下半场开始过早一个位置。 

重复的单词不需要特殊处理。 为了`go go go go`，中点是二，给出`["go", "go"]`对于两半。 连接它们会产生相同的四字序列。 该算法之所以有效，是因为它对位置进行操作，而不是对单词标识进行操作。 

对于边界情况`one two three four`，中点为二。 下半场是`three four`，上半部分是`one two`，所以答案是`three four one two`。 这证实了索引处的单词`mid`属于后半部分，而索引处的单词`mid - 1`属于上半场。 

对于包含 10,000 个单词的大句子，中点为 5,000。 该算法复制两半并将它们连接一次，因此其工作量与输入大小成比例增长。 基于排列的蛮力策略最多需要考虑 10,000 个！ 安排并且是遥不可及的，而直接旋转保持线性。
