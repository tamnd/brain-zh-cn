 ## 解决方案
 ## 问题理解

 我们被要求计算无向图中简单循环的数量。 简单循环是一个闭环，其中没有重复的顶点或边。 输入给我们顶点的数量`n`和边数`m`， 其次是`m`描述连接哪些顶点的整数对。 输出是一个整数，表示简单周期的总数。 

这里的关键限制是`n`最多 19。这足够小，基于顶点子集的指数算法是可行的，因为$2^{19}$大约是50万。 边数`m`在问题陈述中是无界的，但实际上它不能超过$n(n-1)/2$因为图很简单。 这意味着由于阶乘增长，检查所有可能的顶点序列的强力方法将很快变得不可行。 尝试枚举顶点的每个排列并检查它是否形成循环的粗心方法即使对于`n=10`。 

要考虑的边缘情况是没有边或单个顶点的图。 例如，`n=1, m=0`应输出 0，因为不存在循环。 另一个微妙的边缘情况是形成树的图。 树没有循环，并且在没有适当簿记的情况下检查路径的简单算法可能会错误地将自身循环的路径视为循环。 派系也值得检查，因为它们可以最大化循环次数。 

## 方法

 蛮力方法是尝试每个顶点子集，生成每个子集的所有排列，并检查它是否形成循环。 这是正确的，因为任何简单的循环都必须对应于顶点子集的某种排列。 然而，排列的数量随着`n!`，甚至对于`n=10`每个子集超过 300 万次操作，使其无法工作。 

关键的见解是我们可以利用两个事实。 首先，图很小（`n <= 19`），它允许我们将顶点子集表示为位掩码。 其次，循环是闭合路径，其中每个顶点仅被访问一次，动态规划可以有效地计算子集上顶点之间的路径。 我们可以定义`dp[mask][v]`作为到达顶点的方式数`v`精确访问 中的顶点`mask`从最小的顶点开始`mask`。 那么，循环只是一个子集，其中`dp[mask][v]`可以通过一条边回到起始顶点，通过固定最小的顶点作为起始点，可以保证每个循环都被精确计数一次。 

蛮力之所以有效，是因为它保证了构造的正确性，但由于阶乘增长而失败。 位掩码动态编程方法之所以有效，是因为它将阶乘复杂度降低到`O(n * 2^n)`，这是可以管理的`n = 19`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n! * n) | O(n! * n) | O(n) | 太慢了|
 | 位掩码 DP | O(n * 2^n) | O(n * 2^n) | O(n * 2^n) | O(n * 2^n) | 已接受 |

 ## 算法演练

 1.读取顶点数`n`和边缘`m`并建立邻接矩阵`adj`这样`adj[u][v] = True`如果之间有一条边`u`和`v`。 邻接矩阵允许恒定时间检查连接性。 
2.初始化DP表`dp[mask][v]`在哪里`mask`是一个位掩码，表示访问的顶点集，并且`v`是路径中的最后一个顶点。 该表存储了恰好访问以下顶点的路径数`mask`结束于`v`，从最小的顶点开始`mask`。 
3. 对于每个顶点`v`， 放`dp[1 << v][v] = 1`。 这表示从顶点开始一条路径`v`仅与`v`在路径中。 
4. 迭代所有`mask`从 1 到`(1 << n) - 1`。 对于每个顶点`u`在`mask`，考虑每个邻居`v`的`u`。 如果`v`尚未进入`mask`和`v`大于中的最小顶点`mask`（防止重复计算循环），更新`dp[mask | (1 << v)][v] += dp[mask][u]`。 这将扩展所有结束于的路径`u`通过添加`v`。 
5. 填充 DP 表后，计算周期数。 对于每个子集`mask`至少有 3 个顶点，找到最小的顶点`s`。 对于每个顶点`v`在`mask`以外`s`，如果之间有一条边`v`和`s`， 添加`dp[mask][v]`到答案。 每个周期只计算一次，因为我们固定了`s`作为循环中的最小顶点。 
6. 输出总计数。 

这里的不变量是`dp[mask][v]`正确计算从最小顶点开始的所有路径`mask`到`v`完全使用中的顶点`mask`。 通过仅将路径延伸到大于起点的顶点，我们可以防止在不同的旋转中多次计算相同的循环。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[False] * n for _ in range(n)]
for _ in range(m):
    a, b = map(int, input().split())
    a -= 1
    b -= 1
    adj[a][b] = adj[b][a] = True

dp = [[0] * n for _ in range(1 << n)]
for v in range(n):
    dp[1 << v][v] = 1

for mask in range(1, 1 << n):
    # find smallest vertex in mask
    s = (mask & -mask).bit_length() - 1
    for u in range(n):
        if not (mask & (1 << u)):
            continue
        for v in range(n):
            if adj[u][v] and not (mask & (1 << v)) and v > s:
                dp[mask | (1 << v)][v] += dp[mask][u]

ans = 0
for mask in range(1, 1 << n):
    if bin(mask).count("1") < 3:
        continue
    s = (mask & -mask).bit_length() - 1
    for v in range(n):
        if v != s and (mask & (1 << v)) and adj[v][s]:
            ans += dp[mask][v]

print(ans)
```邻接矩阵允许恒定时间邻居检查。 DP 初始化设置从每个顶点开始的路径。 我们小心地只扩展到大于掩模中最小的顶点，以避免重复计数。 最后的循环仅计算长度至少为 3 的循环，对可以返回起始顶点的路径进行求和。
