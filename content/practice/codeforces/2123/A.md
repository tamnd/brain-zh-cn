 ## 解决方案
 ## 问题理解

 黑板最初包含来自`0`到`n - 1`。 

一轮总是有两个动作。 首先爱丽丝删除一些数字`a`。 那么鲍勃必须删除一个不同的号码`b`这样$$a+b \equiv 3 \pmod 4.$$如果鲍勃找不到这样的数字，游戏立即结束，鲍勃输了。 鲍勃删除他的号码后，下一轮开始。 玩家们继续进行，直到有人无法做出所需的动作为止。 

我们被赋予了几个值`n`，对于每一个，我们必须确定哪位玩家获胜，假设两人都表现完美。 

约束很小。 最多有 100 个测试用例`n ≤ 100`。 暴力游戏搜索已经是可行的，但真正的目标是发现游戏背后的数学结构。 一旦理解了该结构，就可以在恒定时间内计算出每个测试用例的答案。 

微妙之处在于鲍勃不会选择任意数字。 他的选择完全由Alice的数模4的余数类别决定。 

有效的配对是：$$0 \leftrightarrow 3$$和$$1 \leftrightarrow 2.$$任意数字一致`0 (mod 4)`必须与一个一致的数字相匹配`3 (mod 4)`，以及任何符合的数字`1 (mod 4)`必须与一个一致的数字相匹配`2 (mod 4)`。 

一个常见的错误是关注精确值而不是模 4 的余数。例如，当`n = 5`，数字是：$$0,1,2,3,4.$$数量`4`行为完全像`0`因为两者一致`0 (mod 4)`。 

另一个容易犯的错误是假设偶数个整数自动对鲍勃有利。 为了`n = 2`，有两个数字，但集合是`{0,1}`。 这两种选择都不存在有效的合作伙伴，因此爱丽丝立即获胜。 

输入：```
1
2
```输出：```
Alice
```鲍勃第一步就失败了。 

## 方法

 暴力方法将对当前的剩余数字集进行建模，并递归地尝试每一个合法的动作。 爱丽丝会努力达到获胜状态，而鲍勃会努力避免失败。 

这是可行的，因为当`n ≤ 100`，但却完全忽略了游戏的结构。 即使对于中等`n`，可能的游戏状态数量呈指数增长。 

关键的观察结果是只有模 4 的留数才是重要的。 

每个数字都属于四组之一：$$0,\ 1,\ 2,\ 3 \pmod 4.$$鲍勃的回应必须来自特定的互补群体：

 | 爱丽丝选择 | 鲍勃必须选择 |
 | ---| ---|
 | 0 模 4 | 3 模 4 |
 | 3 模 4 | 0 模 4 |
 | 1 模 4 | 2 模 4 |
 | 2 模 4 | 1 模 4 |

 这意味着游戏分为两个完全独立的池：

 1. 残留物`0`和`3`。 
2. 残留物`1`和`2`。 

让$$c_0,c_1,c_2,c_3$$是具有每个残数的数字的计数。 

第一个池中的移动总是会从其中删除一个元素`c_0`和一个来自`c_3`。 

第二个池中的移动总是会从其中删除一个元素`c_1`和一个来自`c_2`。 

只要所选池中的两个计数保持为正，Bob 就可以继续响应。 

对于数字`0`通过`n-1`，残差计数最多相差一。 检查前几个值揭示了该模式：

 | n | 获胜者 |
 | ---| ---|
 | 1 | 爱丽丝|
 | 2 | 爱丽丝|
 | 3 | 爱丽丝|
 | 4 | 鲍勃 |
 | 5 | 爱丽丝|
 | 6 | 爱丽丝|
 | 7 | 爱丽丝|
 | 8 | 鲍勃 |

 每四个数字组成的块恰好贡献一个完整的`(0,3)`一对且完整`(1,2)`一对。 

什么时候`n`是 4 的倍数，则每个残基类别出现的频率相同。 所有数字都可以分为有效对。 无论爱丽丝做什么，鲍勃总是有回应。 所有数字都被移除后，爱丽丝是第一个无法移动的玩家，所以鲍勃获胜。 

什么时候`n`不是 4 的倍数，一个或多个残基类有一个额外的元素。 爱丽丝最终可以从不匹配的残基中进行选择，而让鲍勃没有得到法律回应。 鲍勃无法阻止这种情况，因为初始位置已经存在不平衡。 

获胜者很简单：

 - 鲍勃如果`n % 4 == 0`- 爱丽丝否则

 ## 算法演练

 1. 阅读`n`。 
2. 计算`n % 4`。 
3. 如果余数是`0`， 输出`"Bob"`。 

在这种情况下，每个残基类出现的频率相同，因此每个数字都属于某个有效的匹配对。 
4.否则输出`"Alice"`。 

至少有一种残基类别是不匹配的。 爱丽丝可以利用这种不平衡，最终迫使鲍勃陷入没有法律回应的境地。 

### 为什么它有效

 游戏完全由模 4 的残基计数决定。有效的移动总是消耗一对互补的残基类别中的一个数字，或者`(0,3)`或者`(1,2)`。 

什么时候`n`能被 4 整除，则所有四个残基类别的计数相等。 每个元素都可以匹配，因此鲍勃总是对爱丽丝的移动做出反应，直到棋盘变空。 然后，爱丽丝面对第一个没有合法动作的位置并失败。 

什么时候`n`不能被 4 整除，则至少有一个残基类比其补类具有更多元素。 这些额外的元素永远无法匹配。 Alice 可以强制进行游戏，直到只剩下不匹配的元素，此时 Bob 无法做出响应。 因此爱丽丝获胜。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    print("Bob" if n % 4 == 0 else "Alice")
```实现直接遵循数学特征。 

唯一重要的价值是`n % 4`。 如果余数为零，则剩余类别完全平衡，鲍勃获胜。 其他所有余数都会产生有利于爱丽丝的不平衡。 

不需要模拟。 无需存储游戏状态。 每个测试用例在恒定时间内独立处理。

## 测试用例```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline
    t = int(input())
    ans = []
    for _ in range(t):
        n = int(input())
        ans.append("Bob" if n % 4 == 0 else "Alice")
    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out

# provided sample
assert run("5\n2\n4\n5\n7\n100\n") == \
       "Alice\nBob\nAlice\nAlice\nBob"

# minimum n
assert run("1\n1\n") == "Alice"

# first Bob position
assert run("1\n4\n") == "Bob"

# just above multiple of 4
assert run("1\n9\n") == "Alice"

# maximum constraint
assert run("1\n100\n") == "Bob"
