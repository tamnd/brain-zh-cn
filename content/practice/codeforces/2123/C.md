 ## 解决方案
 ## 问题理解

 我们得到了一个不同整数的数组和一组操作：您可以用其最小值替换前缀，也可以用其最大值替换后缀。 目标是确定对于数组中的每个元素，是否可以使用一系列操作将数组缩减为仅包含该元素的单元素数组。 输出是一个二进制字符串，其中`1`表明这是可能的并且`0`否则。 

输入保证数组具有不同的整数，并且每个测试用例最多可包含 200,000 个元素，多个测试用例总计最多可包含 200,000 个元素。 这排除了对所有操作序列的任何强力模拟，因为可能的序列数量随着数组大小呈指数增长。 因此，我们的算法必须在每个测试用例的线性时间内计算答案。 

问题的棘手部分在于了解哪些元素是可访问的。 人们很容易认为，只要出现在数组中的任何位置，就可以到达任何元素，但操作受到限制：前缀替换总是向左侧的最小元素移动，而后缀替换总是向右侧的最大元素移动。 例如，在数组中`[3, 1, 4, 2]`, 元素`3`不能简化为单独的，因为任何操作都会拉动`1`到前面或`4`到后面，从不孤立`3`。 

## 方法

 一种简单的方法是模拟每个元素的每个可能的前缀和后缀操作序列，并查看数组是否可以折叠到该元素。 这是可行的，因为操作是确定性的，但序列的数量呈指数增长（`O(2^n)`），这对于`n = 2*10^5`。 

关键的观察是，只有在数组的某些前缀中最小或在某些后缀中最大的元素才有可能生存到最终位置。 具体来说，如果我们从左到右扫描数组，跟踪运行最小值，并从右到左扫描数组，跟踪运行最大值，我们可以立即确定哪些元素可以作为最终的单元素数组出现。 第一个元素必须始终可减少到整个数组的最小值才能生存，最后一个元素必须可减少到最大值。 任何不在从最小值到最大值严格递增序列上的元素都无法被隔离，因为操作要么将较小的元素推到左侧，要么将较大的元素推到右侧。 

这一观察结果将问题简化为从阵列两端进行单次传递，从而得到线性时间解决方案。

 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组`a`并确定其长度`n`。 初始化一个长度为二进制的字符串`n`充满零。 
2.维护两个数组：`prefix_min`和`suffix_max`。`prefix_min[i]`存储最小值`a[0..i]`， 和`suffix_max[i]`存储最大的`a[i..n-1]`。 
3. 填充`prefix_min`从左到右扫描数组。 在每个索引处`i`， 放`prefix_min[i]`作为`min(prefix_min[i-1], a[i])`。 这会跟踪可以传播到前面的最小元素。 
4. 填充`suffix_max`从右到左扫描数组。 在每个索引处`i`， 放`suffix_max[i]`作为`max(suffix_max[i+1], a[i])`。 这跟踪可以传播到后面的最大元素。 
5. 迭代每个索引`i`数组的。 一个元素`a[i]`可以被孤立当且仅当它等于`prefix_min[i]`或者`suffix_max[i]`。 将二进制串中对应的位置设置为`1`如果这个条件成立。 
6. 打印生成的二进制字符串。 

工作原理：任何长度为 1 的最终数组都必须来自连续将较小元素推到左侧或将较大元素推到右侧的序列。 通过维护前缀最小值和后缀最大值，我们确定了在每个位置上能够在此类序列中幸存下来的唯一元素。 这准确地捕获了可以成为最终单元素数组的元素集。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        prefix_min = [0] * n
        suffix_max = [0] * n
        
        prefix_min[0] = a[0]
        for i in range(1, n):
            prefix_min[i] = min(prefix_min[i-1], a[i])
        
        suffix_max[-1] = a[-1]
        for i in range(n-2, -1, -1):
            suffix_max[i] = max(suffix_max[i+1], a[i])
        
        result = ['0'] * n
        for i in range(n):
            if a[i] == prefix_min[i] or a[i] == suffix_max[i]:
                result[i] = '1'
        print(''.join(result))

solve()
```第一部分读取输入并设置前缀最小值和后缀最大值的存储。 两次线性扫描计算这些数组。 最后的循环通过根据前缀最小值或后缀最大值检查当前元素是否可以生存到最终数组来构造二进制字符串。 通过仔细初始化第一个和最后一个元素可以避免差一错误`prefix_min`和`suffix_max`。 该解决方案在时间和空间上都是线性的，可以有效地处理最大的约束。
