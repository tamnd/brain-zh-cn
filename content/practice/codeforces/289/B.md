 ## 解决方案
 ## 问题理解

 我们得到一个整数的矩形网格，并且允许我们执行非常具体的操作：选择一个单元格并添加或减去一个固定值`d`到它。 每一次这样的操作都需要花费一次移动。 目标是使用尽可能少的移动来变换整个网格，使每个单元格包含完全相同的数字，或者确定这是不可能的。 

从一开始的关键观察是该操作不允许我们任意更改值。 每个单元格值只能在其算术级数模内移动`d`。 如果一个值开始于`x`，那么经过任意次数的运算后，它只能变成以下形式的数字`x + k·d`。 这立即意味着结构约束：所有单元必须全等模`d`，否则任何操作序列都无法对齐它们。 

约束很小：最多 100 x 100 网格，因此最多 10,000 个值。 这允许`O(nm log(nm))`方法很舒服，因为多次排序或扫描所有值都很便宜。 每个单元格的任何二次或三次都可以，但我们不需要任何接近的东西。 

一些边缘情况很容易被忽略。 

如果所有数字都不相同`d`，答案是不可能的。 例如，如果`d = 2`并且网格包含两者`1`和`2`， 然后`1`只能达到奇数，而`2`只能达到偶数。 不存在共同目标。 

如果所有值都相等，则答案为零。 这是微不足道的，但在实施中不应忽视。 

另一个微妙的情况是当值不同但模数对齐时`d`， 例如`[1, 5, 9]`和`d = 4`。 这些都等效于模 4，因此即使值相距很远，也存在解。 天真的“让一切都等于平均值​​”的直觉在这里会失败，因为在受限制的走势下，平均值是无关紧要的。 

## 方法

 蛮力的想法是尝试每一个可能的最终值并计算将所有元素转换为它的成本。 由于每个操作都会精确地更改一个值`d`，任何有效的最终值必须位于与所有元素相同的模类中。 因此，我们可以从网格中选择每个候选值作为潜在目标，并计算将每个单元格转换为该目标所需的总步骤数。 

对于选定的目标`t`, 每个元素`a[i][j]`贡献`|a[i][j] - t| / d`移动，假设整除性成立。 我们将所有单元格的结果相加。 这给出了正确性，因为每次转换都是独立的。 

然而，候选者多达 10,000 个，单元格多达 10,000 个，因此这变成了大约 1 亿次操作，这仍然是临界值，但没有必要。 更重要的是，我们对许多等效的候选者重复基本上相同的计算。 

关键的见解是所有值都在一个算术级数类模中`d`，这样我们就可以将它们标准化。 如果我们将所有值除以`d`在移位公共余数后，问题简化为选择一个最小化绝对偏差的整数目标。 这是一个经典的“最小化绝对差异之和”问题，通过中位数来最佳解决。 

所以我们将每个值转换为`b[i] = a[i] // d`（在确保可行性后）。 最优目标是中位数`b`，因为绝对偏差之和在中位数处最小。 一旦选择了中位数，答案就是到它的总距离。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对目标进行暴力破解 | O(n²m²) | O(1) | O(1) | 太慢了 |
 | 排序+中值缩减 | O(nm log(nm)) | O(nm log(nm)) | O(纳米) | 已接受 |

 ## 算法演练

 1. 读取矩阵并将所有值展平为一个列表。 这简化了推理，因为我们不再需要行列结构。 
2. 通过确保所有值共享相同的余数来检查可行性`d`。 如果有一个值不同，我们会立即返回`-1`因为没有±d 操作序列可以桥接不同的残基类别。 
3. 通过除以对每个值进行归一化`d`。 这会将问题转换为一条线上的整数步，其中每个操作都是±1。 
4. 对标准化值进行排序。 排序是必要的，因为最佳交汇点取决于顺序统计，而不是算术平均值。 
5. 选择中值作为目标。 这是可行的，因为将所有点移动到中位数可以最大限度地减少一维数组中的总绝对偏差。 
6. 通过将与中位数的绝对差相加来计算总成本。 

### 为什么它有效

 每一次移动都会使单个细胞在标准化空间中移动一个单位，因此每个细胞都沿着一条线独立进化。 总成本是到所选点的距离之和。 在一维中，绝对偏差形成的函数是凸且分段线性的，并且其最小值总是位于中值处。 由于我们在共享约束下将网格简化为独立的一维点，因此单元之间的相互作用不会影响最优性，并且全局选择中值可以最小化总移动量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, d = map(int, input().split())
    vals = []

    for _ in range(n):
        row = list(map(int, input().split()))
        vals.extend(row)

    # feasibility check: all must share same mod d
    r = vals[0] % d
    for v in vals:
        if v % d != r:
            print(-1)
            return

    # normalize
    vals = [v // d for v in vals]
    vals.sort()

    median = vals[len(vals) // 2]

    ans = 0
    for v in vals:
        ans += abs(v - median)

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先将矩阵展平，以便所有推理都可以在单个数组上完成。 模检查确保我们永远不会尝试不可能的转换。 划分由`d`减少操作空间，以便每次移动对应一个单位步骤，这对于干净地应用中值参数至关重要。 

排序是关键步骤：如果没有排序，我们就无法有效地识别中位数。 最后一个循环计算总距离，它直接对应于标准化空间中所需的 ±1 步数。

 ## 边缘情况

 完全统一的网格，例如`[[7,7],[7,7]]`证明该算法在归一化后正确短路：所有值都匹配，中值等于值，并且成本总和为零。 

含有不相容残基的网格，例如`[[1,2],[3,4]]`什么时候`d=2`立即引发拒绝。 模检查在任何排序之前捕获这一点，避免不必要的计算。 

单细胞网格显示中值步骤完全退化：唯一的元素已经是目标，并且算法正确返回零，而无需超出标准逻辑的特殊外壳。
