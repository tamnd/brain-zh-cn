 ## 解决方案
 ## 问题理解

 我们被要求构造三个不同的正整数$a$,$b$， 和$c$使得它们的总和等于给定的整数$n$前两个数的最大公约数等于第三个数：$\gcd(a, b) = c$。 输入由多个测试用例组成，每个测试用例指定一个值$n$。 我们每个测试用例的输出是任何有效的三元组$a, b, c$。 

约束条件允许$n$一样大$10^9$以及要达到的测试用例数量$10^5$。 这意味着任何复杂度与$n$会太慢，因为$10^9 \times 10^5$操作是不可行的。 因此，我们需要一种在每个测试用例的时间内运行基本恒定的方法。 

一种天真的方法会尝试枚举所有三元组$(a, b, c)$和$a + b + c = n$并检查$\gcd(a, b) = c$。 对于小$n$这可行，但对于大$n$这变得不可能了。 对于小型企业来说，会出现不明显的边缘情况$n$喜欢$n = 10$在哪里$c = 1$可能需要，或者当$n$是偶数还是奇数，因为简单的固定模式可能需要调整以保持清晰度。 

例如，如果$n = 11$，选择$c = 1$力量$a + b = 10$。 采摘$a = 2$,$b = 8$失败是因为$\gcd(2, 8) = 2 \neq c$。 粗心的解决方案，在不检查奇偶性或小因素的情况下修复模式$n$会产生无效的答案。 

## 方法

 蛮力法迭代所有可能的方法$c$从 1 到$n-2$然后一切可能$a$从 1 到$n-c-1$， 环境$b = n - c - a$。 然后我们检查是否$\gcd(a, b) = c$。 这保证能找到答案，因为答案始终存在，但需要最多$O(n^2)$每个测试用例都进行检查，考虑到限制，这是不可接受的。 

关键的洞察力是选择$c$作为一个小除数$n$或 1，然后构造$a$和$b$作为$c$保证$\gcd(a, b) = c$。 如果$c$将两者分开$a$和$b$，那么它们的最大公约数至少是$c$。 选择$a = c$和$b = n - 2c$确保$a + b + c = n$，并且因为$a$和$b$是的倍数$c$,$\gcd(a, b) = c$。 我们只需要保证$a$,$b$， 和$c$是明确和积极的，这可以通过小的调整来完成。 通常，设置$c = 1$对于奇数$n$和$c = 2$对于甚至$n$产生简单、有效的三元组。 

这种方法将问题简化为每个测试用例的恒定时间计算，因为我们只执行一些算术运算和 GCD 计算。

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，读取整数$n$。 
3.如果$n$能被2整除但不能被4整除，选择$c = 2$,$a = n/2 - 1$,$b = n/2 + 1$。 这确保了$a + b + c = n$和$\gcd(a, b) = c$。 
4.如果$n$能被4整除，选择$c = n/2$,$a = n/4$,$b = n/4$。 调整$b$到$b = n/4 * 3$以保持独特性。 现在$a + b + c = n$和$\gcd(a, b) = c$。 
5. 如果$n$很奇怪，选择$c = 1$,$a = (n-1)/2$,$b = (n-1)/2$。 调整$b = b + 1$以确保清晰度。 然后$a + b + c = n$和$\gcd(a, b) = 1$。 
6. 打印三元组$a, b, c$。 

为什么它有效：关键属性是挑选$a$和$b$作为$c$保证$\gcd(a, b)$正是$c$如果我们确保$a \neq b$。 选择$c = 1$对于奇数或小偶数因数对于偶数涵盖所有可能$n \ge 10$，确保积极性和独特性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n % 2 == 1:
            # odd n: use 1 as gcd
            c = 1
            a = n // 2
            b = n // 2
            b += 1  # make distinct
        elif n % 4 == 0:
            # divisible by 4
            c = n // 2
            a = n // 4
            b = n // 4 * 3
        else:
            # even but not divisible by 4
            c = 2
            a = n // 2 - 1
            b = n // 2 + 1
        print(a, b, c)

if __name__ == "__main__":
    solve()
```该解决方案使用快速 I/O 并有效处理多个测试用例。 每个案例都会在恒定时间内处理。 这些调整确保$a, b, c$是积极和独特的，并且选择$c$保证$\gcd(a, b) = c$。 整数除法时要小心以避免舍入错误。
