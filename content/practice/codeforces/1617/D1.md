 ## 解决方案
 ## 问题理解

 我们有一组玩家，每个人要么是冒名顶替者，要么是队友。 玩家总数，$n$，能被三整除。 这些玩家当中，冒充者的数量，$k$，未知，但保证严格在玩家总数的三分之一到三分之二之间。 挑战在于通过重复查询三元组玩家来准确识别哪些玩家是冒名顶替者。 每个查询都会告诉我们选定的三人组是否包含比冒名顶替者更多的冒名顶替者（返回 0），或者包含比冒名顶替者更多的船员（返回 1）。 

输入由多个测试用例组成，每个测试用例仅给出$n$，每个测试用例的输出是冒名顶替者的确切数量$k$及其索引列表。 我们必须以交互方式执行此操作，进行查询并阅读他们的响应，同时决不超过$2n$每个测试用例的查询。 由于查询的数量是有限的，并且陪审团可以自适应地放置冒名顶替者，因此查询所有可能的三元组的强力方法是不可行的。 我们必须从精心选择的三元组中提取足够的信息，以可靠地对每个玩家进行分类。 

主要的微妙之处来自于响应的适应性。 例如，如果我们查询三名恰好都是船员或都是冒名顶替者的玩家，我们可能无法单独了解每个玩家的身份。 因此，算法必须仔细选择查询，以确保尽早识别出至少一名特定的船员和一名特定的冒名顶替者。 一旦我们有了其中一个，我们就可以通过构建包含这些已知玩家的三元组来对剩余的玩家进行分类，因为包含已知玩家的三元组中的大多数响应是可以预测的。 

边缘情况包括最少数量的玩家$n=6$，需要从很少的查询中提取最大的信息，以及已知的船员或冒名顶替者出现在多个三元组中的情况，如果算法没有正确考虑多数规则，这可能会导致粗心的逻辑错误地分类其他玩家。 

## 方法

 一种幼稚的方法是查询所有可能的三元组，并尝试从 0 和 1 的计数中推断出冒名顶替者。 这是有效的，因为每个三元组都给出了冒名顶替者与船员的部分计数。 然而，三元组的数量随着$\binom{n}{3}$，这大约是$n^3/6$对于大$n$，使得这种方法完全不切实际$n$靠近$10^4$。 

解锁最佳解决方案的关键观察是将玩家划分为连续的三元组，对每个三元组提出一个查询，然后关注产生冲突结果的三元组。 通过比较相邻的三元组，我们可以识别至少一名冒名顶替者和一名特定的船员。 一旦我们有了一名已知的冒名顶替者和一名已知的队友，我们就可以通过形成包含已知玩家的三元组来对所有剩余的玩家进行分类。 这将查询数量减少到线性$n$，很好地拟合在$2n$查询限制。 

蛮力方法在概念上更简单，但扩展性较差。 最佳方法利用了多数响应和保证界限$k$系统地发现第一个已知的冒名顶替者和船员，然后有效地推断其余的人。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将所有玩家划分为$n/3$连续的三元组。 查询每个三元组以获得多数响应（如果冒充者占主导地位则为 0，如果船员占主导地位则为 1）。 存储响应。 
2. 识别具有不同响应的第一对连续三元组。 让这些三元组成为$T_i$和$T_{i+1}$。 根据定义，$T_i$拥有多数票并且$T_{i+1}$则相反。 
3. 查询四名球员的组合，其中包括三名球员$T_i$和一个来自$T_{i+1}$在所有四轮旋转中。 这将揭露一名特定的船员和一名特定的冒名顶替者。 具体来说，检查重叠组中哪个玩家改变了多数； 负责翻转结果的是三人组中的少数人。 
4. 一旦我们有了一名已知的队友和一名已知的冒名顶替者，就可以通过形成三元组对剩余的玩家进行分类，其中三元组包括一名已知的队友和两名未知的队员，或者一名已知的冒名顶替者和两名未知的队员。 大多数响应将直接表明未知玩家的身份。 
5. 收集所有被归类为冒名顶替者的玩家并统计人数。 以所需格式打印总数及其索引。 

正确性依赖于这样一个不变量：一旦识别出已知的队友和已知的冒名顶替者，任何已知玩家的三元组中的多数规则都保证了对任何未知数的正确分类。 任何玩家都不会被错误分类，因为每个分类查询都包含一个身份确定的参考。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case():
    n = int(input())
    triples = []
    results = []
    
    # Step 1: form triples and query them
    for i in range(0, n, 3):
        print("?", i+1, i+2, i+3)
        sys.stdout.flush()
        res = int(input())
        triples.append([i, i+1, i+2])
        results.append(res)
    
    # Step 2: find two consecutive triples with differing results
    for i in range(len(results)-1):
        if results[i] != results[i+1]:
            t0, t1 = triples[i], triples[i+1]
            r0, r1 = results[i], results[i+1]
            break
    
    # Step 3: identify one certain crewmate and one impostor
    known = {}
    for j in range(3):
        print("?", t0[j]+1, t1[0]+1, t1[1]+1)
        sys.stdout.flush()
        res = int(input())
        if res == r1:
            known[t0[j]] = r0
            for k in t0:
                if k != t0[j]:
                    known[k] = r0 ^ 1
            break
    # find a known impostor and crewmate
    crewmate = next(p for p,v in known.items() if v == 1)
    impostor = next(p for p,v in known.items() if v == 0)
    
    # Step 4: classify remaining players
    for i in range(n):
        if i in known:
            continue
        print("?", crewmate+1, impostor+1, i+1)
        sys.stdout.flush()
        res = int(input())
        known[i] = res
    
    # Step 5: output impostors
    impostors = [i+1 for i,v in known.items() if v == 0]
    print("!", len(impostors), *impostors)
    sys.stdout.flush()

t = int(input())
for _ in range(t):
    solve_case()
```该解决方案首先将玩家划分为三元组以收集初始多数信息。 识别两个连续三元组之间的差异可以保证联盟中至少存在一名冒名顶替者和一名船员。 对这些三元组进行仔细查询，提取出第一个已知的船员和冒名顶替者。 最终分类阶段利用这些已知的身份来确定其余的身份。 边缘情况，例如最小值$n=6$自然地得到处理，因为第一个冲突的三元组是由上的界限保证的$k$。
