 ## 问题理解

 给定一个偶数长度的数组，我们将其视为一组镜像对：第一个元素与最后一个元素配对，第二个元素与倒数第二个元素配对，依此类推。 对于每个这样的对，我们可以更改元素，以便每个镜像对的总和在所有对中变得相同。 

单个操作允许用 1 到 k 之间的任何值替换任何元素，目标是使所有对和相等，同时执行尽可能少的替换。 

核心困难在于我们不是直接构建最终的数组。 相反，我们选择一个目标和 x，然后确保每一对都贡献相同的总和，可能会修改每对中的一个或两个元素。 

约束足够大，以至于对成对和所有可能的和进行任何二次推理都会太慢。 每个测试用例总共最多可以有 2e5 个元素，因此对对或和的 O(n^2) 方法是不可行的。 在最坏的情况下，即使每次测试进行 O(nk) 次扫描也会太慢。 

一个幼稚的错误通常来自于独立地对待每一对而不考虑通过 x 的全局耦合。 例如，如果一对可以便宜地形成和 5，而另一对更喜欢和 6，则独立选择会导致不一致的答案。 

当多个对已经共享支持相同总和的值时，会出现另一个微妙的失败情况，但贪婪的局部决策破坏了该共享结构。 

陷阱示例：

 输入：

 n = 4，k = 5

 a = [1, 4, 2, 3]

 对是 (1,3) 和 (4,2)。 两者之和已分别为 4 和 6。 一种幼稚的方法可能会认为独立地修复每一对会导致 2 个更改，但选择 x = 5 会使两对都可以修复，每个仅需要一个更改，这比协调的最佳选择更糟糕。 

关键问题是成本取决于有多少对可以通过 0 或 1 修改达到给定的总和，并且这些贡献必须在全球范围内汇总。 

## 方法

 暴力方法会尝试从 2 到 2k 的所有可能的目标总和 x。 对于每个 x，它将扫描所有 n/2 对并计算该对达到总和 x 所需的更改数量。 每对贡献 0、1 或 2 个更改，具体取决于它是否已经与 x 匹配，可以通过更改一个元素来匹配，还是需要两个更改。 

这是正确的，但在简单的实现中每个测试用例的成本为 O(nk)，因为评估每个 x 需要扫描所有对。 当 k 达到 2e5 并且总 n 达到 2e5 时，这会变得太慢。 

关键的观察是每对 (a[i], a[n-i+1]) 不会以复杂的方式独立地对每个 x 做出贡献。 相反，它以结构化的间隔形式做出贡献。 

对于一对 (u, v)，令 mn = min(u, v) 且 mx = max(u, v)。 然后：

 - 如果 x = u + v，则成本为 0。 
- 如果 x 在 [mn+1, mx+k-1] 中，则更改一次就足够了。 
- 否则，需要进行两次更改。 

关键的洞察力是反转问题。 我们不是评估每对的每个 x，而是累积相对于每对 2 次更改的基线而言有多少对可以节省成本。 每对都贡献一个“效益范围”，我们可以将成本从 2 降低到 1，并且在一个点上，成本从 2 降低到 0。 

这将问题转化为对可能的和进行差分数组扫描的问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力战胜一切 x | O(nk) | O(nk) | O(1) | O(1) | 太慢了 |
 | 差异数组与总贡献 | O(n + k) | O(k) | 已接受 |

 ## 算法演练

 我们修复所有对并计算为每个可能的目标和 x 保存了多少次操作。

1. 对于每对 (u, v)，计算 mn = min(u, v) 和 mx = max(u, v)。 这决定了该对的有效和的结构。 
2. 初始化一个大小约为 2k + 2 的数组 Gain[]。这将跟踪对于每个可能的总和 x 有多少对变得更便宜。 
3. 对于每一对，我们首先假设基线成本是 2 次操作。 然后，我们确定该对在哪里可以改进为成本 1 而不是 2。区间 [mn + 1, mx + k] 中的所有总和都会发生这种情况。 我们在差异数组中增加这个间隔。 
4. 接下来，我们确定特殊和 x = u + v，其中成本变为 0 而不是 2。我们将其标记为单点的额外改进。 
5. 处理完所有对后，我们计算增益[]上的前缀和。 对于每个 x，gain[x] 告诉我们有多少对可以从成本 2 改进到成本 1 或 0。 
6. 对于每个 x，将总成本计算为：

 n/2 * 2 - 增益[x]，但要进行调整，因为达到精确总和的对会额外节省 1 个单位。 
7. 跟踪所有 x 的最小值。 

这样做的原因是每对独立地贡献仅取决于 x 的附加节省。 一旦贡献被转换为间隔更新，全局最优就是最好的聚合总和。 

## 为什么它有效

 每对贡献 2 次操作的固定基线成本。 任何改进仅取决于所选目标和 x 是否落入完全由该对确定的两个区域之一。 除了通过加法之外，这些区域不会跨对相互作用。 这使得目标函数成为 x 上独立分段常数贡献的总和。 由于这种可分离性，用累积的贡献扫描 x 会产生全局最优值，而无需重复重新计算对成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        max_x = 2 * k + 2
        diff = [0] * (max_x + 2)
        freq = {}

        pairs = n // 2

        for i in range(pairs):
            u = a[i]
            v = a[n - i - 1]
            if u > v:
                u, v = v, u

            freq[u + v] = freq.get(u + v, 0) + 1

            l = u + 1
            r = v + k

            diff[l] += 1
            if r + 1 <= max_x:
                diff[r + 1] -= 1

        best = float('inf')
        cur = 0

        for x in range(2, 2 * k + 1):
            cur += diff[x]

            zero_cost = freq.get(x, 0)

            total_cost = pairs * 2 - cur - zero_cost
            best = min(best, total_cost)

        print(best)

if __name__ == "__main__":
    solve()
```该实现对每对进行一次处理，并根据可能的和构建一个差异数组。 该字典跟踪有多少对已经与给定的总和完全匹配，因为这些对除了基于间隔的减少之外还提供了额外的改进。 

然后，扫描针对每个候选总和计算有多少对可以改进，并从基线成本中减去该值。 所有总和中的最小值给出了答案。 

一个微妙的点是处理边界：可能的和的范围达到 2k，并且差异数组必须足够大才能安全地应用 r + 1 更新而不会溢出。 另一个重要的细节是分离精确匹配对，因为它们提供了超出一般“一次替换”间隔的额外改进。

 对：(1,1)、(2,2)

这证实了相同的对创建了多个最佳目标总和，并且算法对所有目标总和进行了一致的评估。 

### 示例 2

 输入：

 n = 6，k = 5

 a = [1, 5, 2, 4, 3, 3]

 对：(1,3)、(5,4)、(2,3)

 我们考虑每个 x 可以改进多少对。 扫描会累积贡献，以便最好的 x 自动出现。 

该轨迹显示，重叠的改进范围不是单独评估每一对，而是确定一个最佳对齐点。

 ## 边缘情况

 关键的边缘情况是每对的总和已经达到相同的值。 在这种情况下，最佳答案是零。 该算法处理此问题是因为频率图为该总和分配了最大节省，并且差分数组贡献不会对其进行惩罚。 

另一种情况是当 k = 1 时。每个元素都必须为 1，因此所有对都已匹配和 2。扫描仍会运行，但只有 x = 2 才能产生全部节省。 

最后一个微妙的情况是当对是对称的但产生不同的自然和时。 间隔结构确保重叠仍然被正确计算，并且最好的全局 x 出现，除了精确匹配跟踪之外，任何对都不需要特殊的外壳。
