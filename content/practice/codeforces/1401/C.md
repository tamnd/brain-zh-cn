 ## 解决方案
 ## 问题理解

 我们得到一个正整数数组。 如果两个元素的最大公约数 (GCD) 等于数组的最小元素，则允许的操作是两个元素之间的交换。 目标是确定我们是否可以使用这些交换将数组重新排列为非递减顺序。 

输入由多个测试用例组成。 每个测试用例都有一个长度`n`和一个数组`n`整数。 如果数组可以根据规则按非递减顺序排序，则每个测试用例的输出为“YES”，否则为“NO”。 

关键约束是总和`n`所有测试用例最多为 100,000 个。 这排除了任何尝试显式模拟交换的解决方案，因为这可能需要每个测试用例最多 O(n^2) 次操作，这太慢了。 

当数组已经是非递减数组或包含最小元素的多个副本时，就会出现微妙的边缘情况。 例如，如果数组是`[2, 2, 3]`，已经排序了。 如果数组是`[3, 6, 2, 9]`，则只能交换能被最小值 (2) 整除的元素。 天真地尝试排序而不考虑整除性限制会产生不正确的“是”或“否”。 

另一个棘手的情况是当一个元素小于最小值但出现较晚时。 考虑`[4, 6, 2, 5]`。 5 不能与任何有助于它到达排序位置的元素交换，因为`gcd(5, any other number)`永远不会是 2，所以答案一定是“NO”。 

## 方法

 暴力方法是尝试所有可能的有效交换，但这是不可行的，因为最多可以有 10^5 个元素，而交换次数可能是 O(n^2)。 由于交换可以传播，因此确保终止也非常困难。 

关键的见解是最小元素定义了“可交换组”。 任何可被最小值整除的元素都可以通过一系列允许的交换相互自由交换。 因此，唯一的限制发生在不能被最小值整除的元素上。 与不能被最小值整除的其他元素相比，这些元素在数组中必须已经处于正确的相对顺序。 

根据这一观察结果，最佳方法是：

 1. 计算数组的排序版本。 
2. 迭代数组，对于任何不能被最小值整除的元素，检查它是否已经位于其排序位置。 如果没有，则无法将其移动到位，答案为“否”。 
3. 如果所有元素均可被最小值整除或已处于其排序位置，则可以使用涉及最小值的交换对数组进行排序。 

这将问题简化为简单的扫描和 GCD/整除性检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 排序+整除性检查| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和数组`a`。 
2. 计算最小元素`mn`在`a`。 
3. 构造一个排序副本`a`，称之为`sorted_a`。 
4. 迭代索引`a`。 

1.如果`a[i]`等于`sorted_a[i]`， 继续。 
2.如果`a[i]`可以整除`mn`，可以自由移动，继续。 
3.否则，`a[i]`不能被整除`mn`并且没有到位。 对此测试用例返回“NO”。 
5. 如果循环完成但未返回“NO”，则返回“YES”。 

为什么它有效：不变量是任何可被最小值整除的元素都可以通过涉及最小值的交换链任意交换。 不能被最小值整除的元素必须已经位于正确的排序位置，因为没有有效的交换来移动它们。 这保证了正确性，因为任何需要的重新排列仅涉及可交换元素，并且所有限制都被显式检查。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_sort(a):
    mn = min(a)
    sorted_a = sorted(a)
    for original, target in zip(a, sorted_a):
        if original != target and original % mn != 0:
            return "NO"
    return "YES"

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(can_sort(a))

if __name__ == "__main__":
    main()
```该解决方案首先计算最小值。 排序后的版本作为目标配置。 该循环确保不在正确位置的任何元素都必须能被最小值整除； 否则，排序是不可能的。 使用`zip`允许干净的成对比较。 由于排序，每个测试用例使用 O(n log n) ，在给定约束的情况下这是有效的。
