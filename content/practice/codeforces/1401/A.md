 ## 解决方案
 ## 问题理解

 我们得到一个点$A$放置在整数轴坐标处$n$。 每次移动我们都可以将这个点向左或向右调整一个单位。 调整到最终位置后$n'$，我们要选择另一个整数点$B$在同一条线上，从原点到原点的距离的绝对差$B$，以及距离$A$到$B$, 等于固定值$k$。 

用更简单的几何术语来说，一旦我们选择$n'$，我们询问是否存在一个整数$b$这样：$$\big||b| - |b - n'|\big| = k$$如果有这样一个$b$存在，说明配置有效。 否则我们就必须搬家$A$直到它成为可能，并且我们想要最少的移动次数。 

关键的困难在于有效性仅取决于之间的关系$n'$和$k$，不在$b$直接地。 所以真正的任务是了解哪些值$n'$存在解决方案。 

约束条件很大，最多可达$6000$测试用例和坐标最多$10^6$。 这立即排除了任何模拟可能位置的尝试$B$或尝试所有配置。 如果每个测试用例的线性扫描取决于$n$或者$k$。 

一个常见的失败案例来自于对表达式对称性的误解。 例如，假设仅$b = 0$或者$b = n'$问题会导致错误的结论，因为最优的$b$取决于相对顺序$0$,$b$， 和$n'$。 

另一个微妙的问题是将表达式视为线性。 绝对值的存在会产生分段行为，因此条件会分成多个几何区域。 

## 方法

 我们首先尝试理解暴力破解的想法。 确定候选人位置$n'$。 然后我们尝试所有可能的整数值$b$并检查是否：$$\big||b| - |b - n'|\big| = k$$对于每个$b$，计算这是常数时间，所以对于一个$n'$这是$O(M)$， 在哪里$M$是我们考虑的可能坐标范围。 自从$n'$其本身最多可以变化$10^6$，对两者进行全面的暴力破解$n'$和$b$变为以下顺序$10^{12}$，这是完全不可行的。 

关键的观察是我们实际上不需要搜索$b$。 该表达式表示相对于原点和点的距离不平衡$n'$，并且该结构具有已知的简化：取决于$b$，表达式折叠成线性形式。 这导致了解决方案何时纯粹以以下方式存在的特征：$n'$和$k$。 

如果我们分析几何形状，我们会发现有效的配置取决于我们是否可以放置$n'$因此与相比，它并不算“太小”$k$。 具体来说，条件简化为：$$n' \ge k \quad \text{or} \quad n' \equiv k \pmod{2}$$更准确地说，标准简化产生的最小调整仅取决于多远$n$来自集合中最接近的有效值：$$\{x \mid x \ge k \text{ and } x \equiv k \ (\mathrm{mod}\ 2)\}$$这将问题简化为整数线上的简单最近点调整。 

所以与其探索$b$，我们将问题简化为检查是否$n$已经满足结构约束，否则将其最小化到最接近的有效整数。

 ## 算法演练

 正确的解决方案可以从两个约束导出：下界条件和奇偶校验条件。 

1. 计算当前位置是否$n$已经满足$n \ge k$。 

如果是的话，我们只需要检查奇偶校验兼容性。 如果没有，我们已经知道我们必须至少向上移动$k$，因为任何有效的配置都需要足够的“距离预算”来实现绝对差异。 
2.如果$n < k$，最接近的有效候选者是$k$本身，所以答案很简单$k - n$。 

这是因为增加$n$保留奇偶校验逐一变化，因此最短路径是直接移动到阈值。 
3.如果$n \ge k$，计算奇偶校验$n$并将其与$k \mod 2$。 

如果它们匹配，我们就可以选择合适的$b$无需进一步调整，所以答案是$0$。 
4. 如果奇偶校验不匹配，我们需要一个额外的步骤来翻转奇偶校验，同时保持高于或等于$k$。 最接近的此类值是$n-1$或者$n+1$，并且都使我们保持在有效区域内。 因此答案是$1$。 

### 为什么它有效

 表达式$\big||b| - |b - n|\big|$产生分段线性结构，具体取决于位置$b$相对于而言的谎言$0$和$n$。 什么时候$n$与相比足够大$k$，系统总是承认一个解，但前提是奇偶校验对齐允许绝对值对称性完全匹配$k$。 否则，转移$n$通过 1 来切换奇偶校验而不破坏可行性，并且不可能进行更小的调整，因为奇偶校验翻转仅发生在单位步骤中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())

    if n < k:
        print(k - n)
    else:
        if (n - k) % 2 == 0:
            print(0)
        else:
            print(1)
```直接按照导出的条件执行。 第一个分支处理以下情况$n$低于可行性阈值，强制线性增加。 第二个分支依赖于奇偶校验对齐，它确定是否有效$b$已经可以构建了。 

一个微妙的点是我们检查$(n - k) \% 2$而不是单独检查$n \% 2$和$k \% 2$，因为只有它们的相对平等才重要。 这避免了冗余逻辑并保持条件对称。

这个例子证实了一旦$n \ge k$，可行性仅取决于结构兼容性，而不取决于大小。

 ## 边缘情况

 一个重要的界限是何时$k = 0$。 在这种情况下，条件简化为找到一个点$b$这样$|b| = |b - n|$，对于某个整数始终成立$b$什么时候$n$是等距离平衡的。 根据该算法，如果$n \ge 0$，我们直接检查奇偶校验$k = 0$。 如果$n$为偶数，则答案为零； 否则，一步棋就足以翻转平价。 

另一个边缘情况是当$n = 0$。 如果$k > 0$，我们陷入$n < k$分支并直接移动到$k$。 例如，$n = 0, k = 1000000$产生答案$1000000$，匹配达到最小可行区域的需要。 

最后一个边缘情况是$n = k$。 该算法将其视为零成本，因为奇偶校验条件自动满足，并且配置已经位于有效的边界上$b$可以选择。
