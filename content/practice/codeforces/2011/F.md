 ## 解决方案
 ## 问题理解

 我们被要求对给定整数数组的所有连续子数组进行计数，以便每个子数组都可以通过从单个整数开始的过程生成，并重复附加与数组中已有元素相同的数字、少一个或多一个。 简单地说，如果子数组中任意两个元素之间的差异至多为 1，并且可以通过从该子数组中先前看到的数字向上或向下递增 1 来达到每个中间数字，则该子数组是“好”的。 

输入由多个测试用例组成，每个测试用例都有一个大小最多为 300,000 的整数数组，并且所有测试用例的所有数组大小之和不超过 300,000。 由于时间限制为 3 秒，这意味着任何每个元素的线性时间差的算法都可能会太慢。 显式检查所有可能子数组的蛮力方法将大致涉及$O(n^2)$每个测试用例的操作，考虑到上限是不可行的。 

一些边缘情况很微妙。 具有重复元素的数组、形成严格递增或递减序列的数组或突然跳跃大于 1 的数组都会影响子数组是否良好。 例如，在数组中`[1, 3]`，子数组`[1, 3]`不好，因为缺少 2。 仅检查相邻差异而不考虑中间数字是否出现的简单方法会对此类子数组进行错误分类。 

## 方法

 暴力方法很简单：对于每个起始索引，将子数组向右扩展，同时检查所有所需的中间值是否都存在并且彼此最多相差 1。 这是有效的，因为它直接反映了“好”子数组的定义。 问题是有$\frac{n(n+1)}{2}$总共子数组，大约可以达到$4.5 \cdot 10^{10}$操作时$n=3 \cdot 10^5$。 这是远远超出可接受范围的。 

优化的关键见解来自于观察“好”子数组的最大长度受到它包含的不同值的数量的限制。 由于好的子数组只能包含彼此最多相差 1 的值，因此好的子数组不能跨越三个以上的连续整数。 这使我们能够将注意力限制在不同元素集大小最多为 3 的子数组上。 

此外，如果我们检查长度大于三的数组，则好的子数组的内部结构受到高度限制。 最小值和最大值之间最多只能有一个“中间”值，否则无法通过允许的运算生成。 这将问题转化为滑动窗口任务：我们可以维护一个窗口，跟踪最小值、最大值以及任何中间值的存在，向右扩展直到窗口无效，然后向前移动左边界。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 滑动窗口+价值追踪| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.初始化一个计数器`ans`为零。 这将存储当前测试用例的良好子数组的总数。 
2.使用两个指针，`l`和`r`，表示正在考虑的数组的当前窗口。 两者都从数组的开头开始。 
3. 维护一个小的频率字典或数组来统计当前窗口内每个数字的出现次数。 跟踪窗口中的最小和最大数字。 
4. 展开右侧指针`r`一次一个元素。 更新频率图并调整`min_val`和`max_val`因此。 
5. 添加元素后，检查当前窗口是否仍然有效。 如果两者之间的差异，则该窗口无效`max_val`和`min_val`超过 2，或者如果该范围内的所有三个可能值`[min_val, max_val]`未以允许使用允许的操作生成数组的方式排列。 
6、如果无效，则移动左指针`l`向右移动，直到窗口再次有效，随着元素被删除而减少频率图。 
7. 每一步之后`r`，所有以`r`并从之间的任何索引开始`l`和`r`保证是好的。 添加`r - l + 1`到`ans`。 
8. 处理完整个数组后，存储或打印`ans`作为测试用例的结果。 

工作原理：该算法维护一个滑动窗口，该窗口始终表示以当前右边界结束的最大连续良好子数组。 不变的是，该窗口中包含的所有子数组都是好的，因为窗口会贪婪地扩展，并且仅在必要时才缩小。 通过计算以每个结尾的所有子数组`r`，我们只考虑一次所有可能的连续好的子数组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def count_good_subarrays(a):
    n = len(a)
    ans = 0
    l = 0
    freq = {}
    
    for r in range(n):
        freq[a[r]] = freq.get(a[r], 0) + 1
        while True:
            keys = list(freq.keys())
            if max(keys) - min(keys) > 2:
                freq[a[l]] -= 1
                if freq[a[l]] == 0:
                    del freq[a[l]]
                l += 1
            else:
                break
        ans += r - l + 1
    return ans

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(count_good_subarrays(a))
```该代码使用字典来跟踪当前滑动窗口中元素的频率。 对于每个新元素，它更新频率图并检查值的范围是否超过 2。如果超过，则左边界递增，直到窗口再次有效。 计算以每个结尾的所有子数组`r`完成了`r - l + 1`。 使用字典确保我们可以处理任意值范围，尽管对于这个问题`1 ≤ a[i] ≤ n`，固定大小的数组也可以工作。
