 ## 解决方案

 ## 问题理解

 该任务描述了一个边长为整数的矩形宿舍房间。 最初，房间测量$a \times b$。 我们可以通过添加任何非负整数来独立地放大任一侧。 扩建后房间变成$a_1 \times b_1$和$a_1 \ge a$和$b_1 \ge b$。 

我们必须准确地放置$n$学生，严格规定每个学生至少需要6平方米的空间。 这转化为对最终区域的限制：产品$a_1 \cdot b_1$必须至少是$6n$。 在所有有效的放大矩形中，我们想要面积最小的矩形。 

关键结构是我们没有选择任意的实际维度。 我们被整数困住了，只能从初始维度向上移动。 该限制在第一象限的整数格点上产生了约束最小化问题，我们在其中搜索最小的可行矩形占主导地位$(a,b)$。 

约束条件达到$10^9$，因此任何试图探索所有候选维度对的解决方案都是不可能的。 即使线性迭代所有可能的宽度或高度也会超出任何合理的时间限制。 唯一可行的方法是将搜索空间减少到大约$\sqrt{6n}$，最多大约是$10^5$。 

当初始维度之一已经很大时，会出现微妙的边缘情况。 认为$a$远大于$\sqrt{6n}$。 天真的“围绕平方根搜索”方法可能会忽略我们被迫从$a$，而不是来自 1。另一种边缘情况是当一侧非常小时，最佳配置来自于仅大量增加一个维度，同时保持另一侧固定在最小值。 例如，如果$b$已经很大了，最优解可能是$a_1 = \lceil 6n / b \rceil$，这可能远远超出了朴素的有界循环。 

## 方法

 暴力方法会尝试每一个可能的对$(a_1, b_1)$这样$a_1 \ge a$,$b_1 \ge b$， 和$a_1 b_1 \ge 6n$，然后选择最小面积。 这是正确的，但立即无法使用。 甚至限制$a_1, b_1 \le 10^9$留下最多$10^{18}$最坏的情况下的可能性，这是完全不可行的。 

关键的观察结果是，在最佳解决方案中，其中一个维度接近所需面积的平方根。 让$S = 6n$。 如果我们忽略下限$a$和$b$，在约束下最小化具有整数边的面积的最佳矩形$xy \ge S$发生在$x$就在附近$\sqrt{S}$和$y$接近于$S/x$。 这来自于持续的放松$xy = S$在平等和对称性上被最小化意味着平衡双方。 

有下界$a$和$b$，我们只是限制可行区域。 最佳解决方案必须位于平方根区域附近或受到约束之一的强制$x \ge a$或者$y \ge b$。 这意味着我们只需要在以下情况下测试候选人：

 1.$x$就在附近$\sqrt{S}$, 或
 2.$y$恰好处于最小值$b$，这迫使$x = \lceil S / b \rceil$, 或
 3.$x$恰好处于最小值$a$，这迫使$y = \lceil S / a \rceil$。 

这将问题从二维搜索简化为一小组一维候选。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(10^{18})$|$O(1)$| 太慢了|
 | 最佳 |$O(\sqrt{n})$|$O(1)$| 已接受 |

 ## 算法演练

 让$S = 6n$。 

1. 计算$S = 6n$。 这是我们必须覆盖的最小所需区域。 
2. 从探索宽度开始$x$从原始约束开始$a$直到周围的一个小区域$\sqrt{S}$。 原因是如果$x$远远超出了$\sqrt{S}$，相应的高度变小，并且乘积通常会再次增加。 
3.对于每个候选宽度$x$，计算最小有效高度$y = \max(b, \lceil S / x \rceil)$。 这确保了学生的要求和原始房间的限制都得到满足。 
4. 计算面积$x \cdot y$并跟踪所有候选者的最小值。 
5.独立考虑高度固定为原来最小值的情况$b$。 在这种情况下，宽度必须是$x = \max(a, \lceil S / b \rceil)$。 这捕获了最佳配置位于平方根搜索窗口之外的解决方案。 
6. 同样，考虑宽度固定为的对称情况$a$，高度变为$y = \max(b, \lceil S / a \rceil)$。 
7. 在所有计算出的候选者中，输出面积最小的候选者。 

为什么它有效：可行区域在两个维度上都是单调的，并且乘积约束迫使最优解要么接近“平衡”点，$x \approx y \approx \sqrt{S}$，或在一个维度固定为其最小允许值的边界上。 任何最佳解决方案都必须依赖于这些结构形式之一； 否则，稍微改变一个维度以达到平衡会在保持可行性的同时减少面积，这与最优性相矛盾。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def solve():
    n, a, b = map(int, input().split())
    S = 6 * n

    best = float('inf')
    best_a = best_b = 0

    def relax(x, y):
        nonlocal best, best_a, best_b
        if x < a or y < b:
            return
        area = x * y
        if area < best:
            best = area
            best_a = x
            best_b = y

    limit = int(math.isqrt(S)) + 5

    x = a
    while x <= limit:
        y = (S + x - 1) // x
        relax(x, y)
        x += 1

    y = b
    while y <= limit:
        x = (S + y - 1) // y
        relax(x, y)
        y += 1

    x = max(a, (S + b - 1) // b)
    relax(x, b)

    y = max(b, (S + a - 1) // a)
    relax(a, y)

    print(best)
    print(best_a, best_b)

if __name__ == "__main__":
    solve()
```功能`relax`集中可行性检查并保留当前最佳答案。 这避免了候选生成策略之间的重复逻辑，并降低了错过约束的风险，例如$a_1 \ge a$或者$b_1 \ge b$。 

平方根区域周围的两个短环捕获平衡解。 这两个边界检查明确处理强制最优值的情况$a$或者$b$，这是单纯的仅平方根实现的主要失败点。 

一个常见的陷阱是在计算上限后忘记应用下限。 即使$\lceil S/x \rceil$虽小，实际高度还是要尊重$b$，否则解违反了原始房间约束。

| x| y = ceil(18/x) | 调整 y | 地区 |
 | ---| ---| ---| ---|
 | 3 | 6 | 6 | 18 | 18
 | 4 | 5 | 5 | 20 |
 | 5 | 4 | 5（由于 b=5）| 25 | 25

 边界情况：

 -$x = 3$,$y = max(5, 6) = 6$，面积 = 18

 最好是 18，尺寸为 (3, 6)。 

该迹线表明，当一侧保持在原始最小值，而另一侧扩展刚好足以满足约束时，即可实现最佳效果。

 ## 边缘情况

 当一维与最佳平方根区域相比已经非常大时，就会出现关键的边缘情况。 例如，如果$a = 10^9$和$n$很小，平方根循环永远不会考虑接近的值$a$。 该算法处理这个问题是因为它显式地评估配置，其中$x = a$并计算相应的$y = \lceil S/a \rceil$，确保不会错过边界支配的最优值。 

当两个尺寸均低于有效配置时，会出现另一种边缘情况。 认为$a = b = 2$和$n = 1$。 所需面积为 6，自然平衡对为 (2, 3)。 该算法评估平方根邻域和边界情况，确保直接发现 (2, 3)，而不是依赖于可能会错过的渐进增量。 

第三种情况是舍入效应占主导地位时。 自从$y = \lceil S/x \rceil$，小变化$x$可能会导致跳入$y$，但单调结构保证任何错过的局部改进都将由搜索窗口中的附近候选者或边界评估之一来补偿。
