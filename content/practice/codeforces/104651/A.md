 ## 解决方案
 ## 问题理解

 我们有两个字符串，$S$和$T$。 任务是砍$S$成一系列连续的非空片段。 每一部分必须类似于前缀$T$，但不一定完全正确。 最多允许有一个字符位置与相应的前缀不同。 

对于每种有效的分区方式$S$，如果它产生$k$件，该分区贡献$k^2$到答案。 我们需要所有有效分区的这些贡献的总和。 

关键的困难在于分区的数量可能呈指数级增长$|S|$，因此在以下情况下枚举所有分割是不可能的$|S|$达到$10^6$。 任何解决方案都必须避免显式分区枚举，而是以压缩的动态方式对它们进行计数。 

出现微妙的边缘情况时$T$比一段短$S$。 只要段不超过$T$，因为它必须与前缀进行比较$T$相同长度的。 这意味着我们总是匹配的子字符串$S$针对前缀$T$，永远不会超出其长度。 

另一个不明显的问题是，一个段在任何地方都允许有一个不匹配，而不一定是在固定位置。 例如，如果$T = "aba"$，然后像这样的字符串`"aaa"`,`"abb"`， 和`"aca"`都是长度为 3 的有效段，但是`"abc"`也是有效的，因为它与`"aba"`。 

这些限制迫使我们避免任何$O(nm)$每个分割的卷积或子串比较。 由于两个字符串都可以达到$10^6$，我们的目标是大致线性或接近线性的时间。 

## 方法

 思考这个问题的一个天真的方法是定义一个 DP，其中$dp[i]$是所有前缀分割方式的集合$S[0:i]$。 从各个位置$i$，我们尝试所有可能的下一段长度$L$，检查是否$S[i:i+L]$不同于$T[0:L]$至多一个位置，并扩展所有分区。 这直接导致指数分支$S$，甚至检查每个段的有效性也需要比较$10^6$最坏情况下的角色。 

即使我们使用滚动哈希或预先计算的不匹配计数来记忆段有效性，我们仍然面临分区的组合爆炸。 分割长度字符串的方法数$n$是$2^{n-1}$在最坏的情况下，任何明确表示分区的状态都注定会失败。 

关键的结构观察是，段的条件仅取决于其长度以及与前缀不匹配的数量$T$。 这表明对于每个位置$S$，我们只关心在保持“到目前为止最多一个不匹配”的情况下，我们可以将一段扩展多远。 这正是一个带有不匹配计数器的滑动窗口问题，可以在$O(1)$使用两个指针对每个扩展进行摊销。 

一旦知道了有效的段边界，问题就变成了计算$S$其中允许的段长度根据位置而变化。 这是一个经典的“限制分区计数”DP，但我们需要一个额外的转折：我们必须累加路数和部分的平方和。 

第二个扭曲的处理方法是，对于每个前缀位置，不仅要维护到达该位置的路径数量，还要维护长度和路径数量的平方和。 当延伸一段时，零件的数量增加一个，所以$k^2$变换为$(k+1)^2 = k^2 + 2k + 1$。 这使我们能够在不显式跟踪分区的情况下传播贡献。 

因此，该解决方案在由两指针失配窗口确定的有效段范围内减少为两个交织的 DP 转换。

 ## 算法演练

 我们预处理每个起始位置的距离$S$可以延长，同时保持在一个不匹配范围内$T$。 

我们定义一个滑动窗口$S$和$T$，在当前段中最多维持一个不匹配。 

1.初始化两个指针$l = 0$,$r = 0$，和一个不匹配计数器$bad = 0$。 该窗口始终代表一个段$S[l:r]$与$T[0:r-l]$。 
2. 展开$r$从左到右过$S$。 每次我们加入一个新角色$S[r]$，将其与$T[r-l]$。 如果不同，则增加$bad$。 
3.如果$bad > 1$，通过增加从左侧缩小窗口$l$。 拆除时$S[l]$，如果它造成不匹配，则递减$bad$。 继续收缩直到$bad \le 1$再次。 这保持了当前窗口是有效段的不变性。 
4. 对于每个位置$l$，我们现在知道最大有效端点$r$。 这意味着从$l$，任何结束于之间的段$l$和$r$是有效的。 
5. 我们对位置使用动态规划$S$。 让$dp[i]$表示前缀分割的方式数$S[0:i]$，我们还维护两个辅助数组：$dp2[i]$零件数的平方和，以及$dp1[i]$为所有分割的零件数量之和。 
6. 当我们处于位置时$i$，我们迭代所有有效的段端点$j$开始于$i$。 对于每个$j$，我们扩展转换：$$dp[j+1] += dp[i]$$

$$dp1[j+1] += dp1[i] + dp[i]$$

$$dp2[j+1] += dp2[i] + 2 \cdot dp1[i] + dp[i]$$这些公式来自展开$(k+1)^2$。 
7.最终答案是$dp2[|S|]$。 

### 为什么它有效

 在每个前缀位置$i$，所有分区都计入$dp[i]$正是那些可以独立扩展到更长前缀的有效分区的那些。 滑动窗口保证转换中使用的每个段都满足“至多一个与前缀不匹配”$T$”约束。二次变换恒等式确保累积平方计数正确传播，而无需存储显式分区结构。

 ## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

S = input().strip()
T = input().strip()

n = len(S)
m = len(T)

# We only need segments up to length m
# Precompute max reach for each l using two pointers
max_r = [0] * n

r = 0
bad = 0

for l in range(n):
    if r < l:
        r = l
        bad = 0

    while r < n and (r - l) < m:
        if S[r] != T[r - l]:
            bad += 1
        if bad > 1:
            if S[l] != T[0]:
                bad -= 1
            break
        r += 1

    max_r[l] = r - 1

# DP arrays
dp = [0] * (n + 1)
dp1 = [0] * (n + 1)
dp2 = [0] * (n + 1)

dp[0] = 1

for i in range(n):
    if dp[i] == 0:
        continue

    # extend segment from i
    limit = min(max_r[i], n - 1)
    for j in range(i, limit + 1):
        ways = dp[i]

        dp[j + 1] = (dp[j + 1] + ways) % MOD
        dp1[j + 1] = (dp1[j + 1] + dp1[i] + ways) % MOD
        dp2[j + 1] = (dp2[j + 1] + dp2[i] + 2 * dp1[i] + ways) % MOD

print(dp2[n] % MOD)
```DP 状态数组直接编码三层信息：分区的数量、以部分计数表示的长度总和以及部分计数平方和。 变换公式由展开推导出来$(k+1)^2$， 在哪里$k$是添加新段之前前缀分区中的部分数。 

内循环结束$j$依赖于预先计算的`max_r[i]`，这保证我们只扩展有效的段。 这避免了 DP 期间的任何子字符串比较。 

一个微妙的点是确保不匹配跟踪与前缀正确对齐$T$。 比较使用偏移量$r - l$，这确保始终根据相应的前缀检查每个段$T$，而不是针对移位或任意子串。

 ## 边缘情况

 当出现临界边缘情况时$S$比$T$。 在这种情况下，任何长度超过$|T|$自动无效，因为它无法与前缀匹配$T$。 滑动窗口通过在长度上停止扩展来自然地强制执行此操作$m$，因此没有无效的长段进入 DP 转换。 

另一种情况是每个字符都不匹配$T$每个段最多一次。 例如$S = "aaaaa"$,$T = "abc"$。 只要仅发生一个不匹配，每个长度为 3 的窗口仍然有效。 该算法正确地允许从每个位置开始重叠有效段，并且 DP 独立地累积所有分区计数。 

最后，当$T$如果长度为 1，则每个段最多可以有一个不匹配，这意味着无论内容如何，​​所有段都是有效的。 DP 减少为计算所有分区$S$，并且二次累加仍然正确应用，因为每次扩展都会将零件数统一增加一。
