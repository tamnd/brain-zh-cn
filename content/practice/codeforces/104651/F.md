 ## 解决方案
 ## 问题理解

 我们维护着越来越多的物品收藏。 每个项目都属于一个岛屿，并且有类型和价格。 该系统支持两种操作：插入新项目并回答询问最昂贵项目的查询，同时避开两个禁止类别（特定岛屿和特定类型）。 

查询给出一个岛`x`和一个类型`y`，我们必须找到所有岛屿不存在的存储物品中的最高价格`x`并且其类型不是`y`。 如果不存在这样的项目，则答案为零。 关键的困难在于，两个维度都被同时排除，因此如果一个项目符合任一约束，则该项目无效。 

限制是极端的：最多一百万次操作，值最多为 10^9，并且所有值都与之前的答案进行 XOR 加密。 这迫使严格的在线解决方案在每个操作中具有恒定或对数摊销工作量。 任何针对每个查询扫描整个数据库的解决方案都是立即不可能的，因为这需要多达 10^12 次检查。 

一种简单的方法是将所有项目存储在列表中，并且对于每个查询，扫描所有内容以找到最佳的有效候选者。 这会失败，因为每个查询都会花费插入项目数量的线性时间。 

如果我们尝试维持全局最大值并仅在它对当前查询无效时才将其丢弃，则会出现更微妙的故障模式。 这个想法被打破了，因为有效性取决于查询。 对一个查询无效的项目可能对下一个查询有效，因此我们无法在扫描期间永久删除候选项。 

另一个错误的方向是独立维护每个岛屿或每个类型的最大值。 这些结构只能解决一个排除维度，但查询需要同时排除这两个维度，正确组合它们是核心挑战。 

## 方法

 暴力解决方案存储所有项目并针对每个查询扫描它们，检查两个约束。 它是正确的，因为它直接评估答案的定义，但每个查询最多执行 O(q) 工作，导致总操作量为 O(q^2)，这远远超出了一百万个事件的可行限制。 

为了改进，第一个有用的观察是每个查询都要求具有两个“禁止类”的整个集合的最大值。 这表明答案通常是在少数具有全球竞争力的候选者中，除非这些候选者属于禁止的行或列。 

如果我们按值对所有项目进行排序，则全局最大值是第一个候选者。 如果它不违反任何一个约束，那么它立即就是答案。 如果它确实违反了，那么答案必须存在于与其竞争的项目中，通常是岛屿或类型不同的项目。 这促使我们保持对“每个岛屿最佳”和“每个类型最佳”的快速访问，这样我们就可以快速逃脱禁止类别。 

使解决方案发挥作用的关键结构是为每个岛屿和每种类型维护一个可以快速返回该组中最佳可用项目的结构，以及当顶级候选在当前查询的第二个限制下无效时的后备。 由于我们只插入而从不删除，因此我们可以存储每组的所有项目，并在需要时延迟提取最大值，从而分摊重新检查候选者的成本。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(q²) | O(q) | 太慢了|
 | 优化每组惰性最大值 | O(q) 摊销 | O(q) | 已接受 |

 ## 算法演练

 我们维护两个主要的哈希映射：一个从岛到包含其所有项目的结构，另一个从类型到类似的结构。 每个结构都支持按值检索最大项目，但我们允许重复检查，因为无效的候选者会被惰性地跳过。 

我们也保持经典意义上的不删除； 相反，我们依赖于这样一个事实：每个插入的项目都存储一次，并且在堆清理期间只能重新访问固定次数。 

该算法进行如下。 

1. 由于所有输入均已加密，因此使用之前的答案通过 XOR 来解码每个操作。 这确保我们重建真实的岛屿、类型和价值。 
2. 对于插入，将项目存储在三个位置：全局容器、其岛屿的岛屿存储桶以及其类型的类型存储桶。 每个桶保存按值排序的项目，以便可以快速检索其最大值。 
3. 查询`(x, y)`，首次尝试拿下全球最佳物品。 如果有效，则意味着该岛不存在`x`它的类型不是`y`，这就是答案。 
4. 如果全局最好无效，则属于任一岛`x`， 类型`y`，或两者兼而有之。 我们在此查询中暂时放弃它并寻找替代方案。 
5. 然后，我们从所有岛屿中查询候选最大值，除了`x`。 对于每个这样的岛屿，我们都会尽力获得最好的物品。 如果该项目违反类型`y`，我们会回到同一个岛上，寻找下一个最佳候选者。 这种回退是通过检查该岛结构中的下一个元素来延迟计算的，直到找到有效的类型。 
6. 我们在类型桶上对称地重复相同的想法，从所有类型中收集最佳候选，除了`y`，同时保证岛屿约束`x`受到尊重。 
7. 答案是步骤 5 和 6 中收集的所有有效候选者中的最大值。 

关键的不变量是，每次我们从存储桶中丢弃候选者时，都是因为它对当前查询无效，而不是全局无效。 由于每个桶仅在需要时通过从顶部弹出来删除候选者，并且每个元素只能在每个桶中弹出一次，因此所有操作的弹出总数保持线性。 

## 为什么它有效

 每个有效答案都必须属于除`x`和其他类型`y`。 这意味着它必须出现在至少一个不存在的岛桶内`x`和至少一种类型的桶不是`y`。 通过扫描这些结构化最大值，我们确保任何可能是最佳的候选者在某个时刻都可以作为桶最大值到达。 延迟删除保证我们不会永久丢失有效候选者，并且堆的单调性质确保一旦发现更好的候选者，它就会支配所有先前跳过的无效候选者。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import heapq
from collections import defaultdict

def add_to_heap(h, item):
    # item is (-value, type, island)
    heapq.heappush(h, item)

def get_valid_top(heap, forbidden_island, forbidden_type):
    while heap:
        val, t, x = heap[0]
        if x != forbidden_island and t != forbidden_type:
            return -val, t, x
        heapq.heappop(heap)
    return None

def solve():
    q = int(input())
    last = 0

    global_heap = []
    island_heap = defaultdict(list)
    type_heap = defaultdict(list)

    for _ in range(q):
        parts = list(map(int, input().split()))
        tp = parts[0]

        if tp == 1:
            x = parts[1] ^ last
            y = parts[2] ^ last
            w = parts[3] ^ last

            item = (-w, y, x)

            heapq.heappush(global_heap, item)
            heapq.heappush(island_heap[x], item)
            heapq.heappush(type_heap[y], item)

        else:
            x = parts[1] ^ last
            y = parts[2] ^ last

            best = None

            # try global heap first
            while global_heap:
                w, ty, isl = global_heap[0]
                if isl != x and ty != y:
                    best = (-w, ty, isl)
                    break
                heapq.heappop(global_heap)

            # fallback from islands
            for isl, h in island_heap.items():
                if isl == x:
                    continue
                while h:
                    w, ty, _ = h[0]
                    if ty != y:
                        cand = (-w, ty, isl)
                        if best is None or cand[0] > best[0]:
                            best = cand
                        break
                    heapq.heappop(h)

            # fallback from types
            for ty, h in type_heap.items():
                if ty == y:
                    continue
                while h:
                    w, ty2, isl = h[0]
                    if isl != x:
                        cand = (-w, ty, isl)
                        if best is None or cand[0] > best[0]:
                            best = cand
                        break
                    heapq.heappop(h)

            ans = 0 if best is None else best[0]
            print(ans)
            last = ans

solve()
```该代码维护三层堆。 全局堆支持快速访问总体最大值。 岛堆和类型堆支持局部最大值。 延迟弹出可确保最终将无效项目从考虑中删除，而无需重复扫描完整数据集。 每个项目插入一次，并且可以弹出有限次数，因此摊余复杂度保持线性。 

一个微妙的点是堆没有在结构之间显式同步。 这是可以接受的，因为项目永远不会被物理删除，只有当它成为堆顶部并且查询约束失败时才会被忽略。

 ## 边缘情况

 当所有物品都属于禁岛时，基于岛屿扫描的每个候选者都会立即消失。 该算法可以处理此问题，因为对于禁岛，岛堆被完全跳过，并且不会从中提取有效的候选者。 

当所有项目共享禁止类型时，类型堆对于该查询变得毫无用处。 岛堆中的回退机制确保我们仍然正确检查其他类型，并且堆会延迟耗尽而不影响正确性。 

当全局最大值无效时，会重复弹出，直到找到有效的候选者或耗尽。 每个弹出的项目都会从该堆中永久丢弃，因此未来的查询永远不会重新处理它，即使在对抗情况下也能确保线性摊销行为。
