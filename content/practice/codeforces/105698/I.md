 ## 解决方案
 ## 问题理解

 给定一个正整数序列，我们想要计算有多少个非空子序列是“安全的”，因为它们从不包含可以形成三角形的元素三元组。 

如果将三元组排序为：$a \le b \le c$，它满足$a + b > c$。 关键点是我们不是选择连续的段，而是子序列，因此可以有间隙地选取元素，并且我们只关心相对顺序。 

任务是计算所有三个选定元素不能满足该三角形条件的子序列。 

约束条件$n \le 7000$已经排除了任何指数$n$，比如枚举所有$2^n$子序列。 甚至$O(n^2 \log n)$或者$O(n^2)$处于临界点但可以接受。 这强烈表明我们必须将问题简化为可以通过某种结构而不是值来增量更新的问题。 

一个微妙的问题立即出现：三角形的形成仅取决于值的相对顺序，而不取决于位置。 这意味着排序或基于值的分组可能会成为核心。 

一个天真的陷阱是假设检查局部约束或成对约束就足够了。 例如，人们可能认为避免两个小元素超过三分之一的三元组就足够了，但子序列可以选择相距较远的元素并任意组合它们，因此局部检查会失败。 

另一个常见的错误是将其视为“没有三个递增索引形成一个条件”，这是不正确的，因为三角形条件是纯数字的并且完全忽略位置。 

## 方法

 暴力解决方案将枚举每个子序列并检查它是否包含有效的三角形三元组。 对于每个子序列，我们需要检查所有$\binom{k}{3}$三元组，对它们进行排序，并测试不等式。 由于有$2^n$子序列，这种方法立即变得不可行，即使对于$n = 30$，更不用说$7000$。 瓶颈是子序列的指数增长。 

关键的观察结果是，三角形条件对于三元组来说完全是局部的，并且仅取决于值。 一旦我们对选定的子序列进行排序，“不存在三角形”的条件就会施加很强的结构限制：太多较小的元素不能支持大元素。 事实上，一旦我们考虑排序的选定值，任何违规都是由一对较小元素的总和超过较大元素决定的。 

这表明要扭转观点。 我们不检查子序列，而是考虑构建它们，同时跟踪添加新元素是否会允许错误的三元组。 关键的结构见解是，无三角形集合的行为类似于受约束的集合，其中当对元素进行排序时，每个元素都太大而无法被任何两个较小的所选元素“覆盖”。 

这使我们能够将问题重新解释为具有有限交互窗口的排序值上的 DP。 因为$n$足够小$O(n^2)$，我们可以根据元素之间的配对约束来维护转换。 

强制执行“不基于二之和的三形成条件”的标准方法是确保每当我们固定子序列的最大元素时，其余选定的元素必须满足相对于它的成对和约束。 这自然会导致考虑对并维护描述最后一个或两个选定元素的给定“状态”存在多少个有效子序列。 

由此产生的 DP 简化为跟踪子序列，其中我们确保所选元素中没有一对可以共同超过后来选择的元素。 这将禁止的模式折叠成排序顺序上的可管理的转换。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n \cdot n^3)$|$O(n)$| 太慢了 |
 | 对排序值进行配对/DP |$O(n^2)$|$O(n)$| 已接受 |

 ## 算法演练

 我们首先对序列进行排序，因为三角形条件仅取决于相对大小，并且排序允许我们以结构化方式推理有效性。 

然后，我们使用动态编程，以元素递增的顺序构建子序列。 

1. 对数组进行非降序排序。 这确保了当我们扩展子序列时，所有先前的元素都小于或等于新的元素，这使得三角形条件更容易推理。 
2. 定义一个 DP 状态，通过最后一个或两个选择的元素来跟踪子序列。 我们最多需要两个的原因是任何三角形条件都涉及三个元素，并且排序子序列中的最大元素始终是完成三角形的最后一个候选元素。 
3. 用空子序列初始化DP，单元素子序列始终有效，因为三角形需要三个元素。 
4. 对于每个元素$x$按照排序顺序，我们决定是跳过它还是包含它。 跳过会保留所有现有状态。 包含它需要检查它是否可以与任何已经在 DP 状态中隐式表示的对形成三角形。 
5、添加时$x$，我们更新代表最后一个元素的状态。 如果我们维护由最后两个选定元素索引的 DP，则添加$x$形成新的对，并且我们必须确保没有对$(a, b)$则后续满足$a + b > x$。 由于数组已排序，因此仅检查 DP 转换中的边界对就足够了。 
6. 处理完所有元素后累加所有 DP 状态，对所有有效非空子序列求和。 

### 为什么它有效

 正确性取决于这样一个事实：在序列排序时，任何三角形都是由其最大元素唯一确定的。 如果存在违规，则必须存在最大元素$c$在三元组中，使得两个较早的元素$a, b$满足$a + b > c$。 通过按升序处理元素并确保我们永远不允许这样的一对与更大的元素共存，我们保证不会形成无效的三元组。 DP 状态就足够了，因为任何禁止的配置仅取决于排序子序列中最新元素和最后两个相关贡献者之间的交互。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    # dp[i][j] = number of valid subsequences whose last two elements are i, j indices
    # We compress values by index; we also allow "no second element" as -1 state.

    dp = [[0] * n for _ in range(n)]
    single = [0] * n

    ans = 0

    for i in range(n):
        x = a[i]

        new_dp = [[0] * n for _ in range(n)]
        new_single = single[:]

        # start new subsequence with x
        new_single[i] = (new_single[i] + 1) % MOD

        # extend single-element subsequences
        for j in range(i):
            new_dp[j][i] = (new_dp[j][i] + single[j]) % MOD

        # extend pair states
        for j in range(i):
            for k in range(j):
                if a[k] + a[j] <= x:
                    new_dp[j][i] = (new_dp[j][i] + dp[k][j]) % MOD

        dp = new_dp
        single = new_single

        # add all states ending at i
        for j in range(i):
            ans = (ans + dp[j][i]) % MOD
        ans = (ans + single[i]) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```该实现依赖于按排序顺序的最后一个或两个选择的元素来显式跟踪子序列。 这`single`数组计算以每个索引结尾的大小为 1 的子序列，而`dp[j][i]`计算最后两个元素为的子序列`a[j]`和`a[i]`。 

处理新元素时`i`，我们首先创建新的 DP 容器，这样我们就不会重用部分更新的状态。 We always allow starting a new subsequence with`a[i]`。 然后我们将所有先前的单元素子序列扩展为对。 Finally, we extend existing pairs only if adding`a[i]`不创建三角形，通过验证来检查`a[k] + a[j] <= a[i]`。 

The final answer is accumulated from all valid states ending at each position.

 ## 边缘情况

 一种重要的边缘情况是所有值都相同，例如`[5, 5, 5, 5]`。 任何三元组都可以形成三角形，因为$5 + 5 > 5$。 该算法必须确保对所有大小最多为 2 的子序列进行计数，同时排除所有较大的子序列。 在 DP 中，任何扩展对状态的尝试都将无法通过条件检查，因此只有单例和对存活，这与正确的组合计数相匹配。 

另一个边缘情况是当值呈指数增长时，例如`[1, 2, 4, 8, 16]`。 不存在三角形，因为没有两个较小的值之和等于较大的值。 DP 允许所有转换，因为不等式`a[k] + a[j] <= a[i]`始终成立，因此答案变为所有非空子序列，即$2^n - 1$，算法正确地累积。 

最终的边缘情况是重复的小值与大异常值混合，例如`[1, 1, 1, 1000]`。 唯一的潜在三角形涉及小值，但它们太小而无法达到 1000，因此大元素永远不会创建无效的三元组。 DP 通过始终根据最新元素检查对和来干净地分离这些贡献。
