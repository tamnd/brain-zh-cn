 ## 解决方案
 ## 问题理解

 我们从两个非常大的整数开始，称它们为$a$和$b$。 我们最多可以表演$k$操作，其中每个操作独立地增加$a$由一或$b$一个。 花费不超过后$k$总计增量后，我们停下来看看结果的数字对。 目标是选择如何分配这些增量，以便两个数字的最终乘积尽可能大。 

输出不是产品本身而是最终值$c$和$d$，对应更新后的$a$和$b$，约束条件是使用的增量总数最多为$k$。 

约束条件达到$10^{18}$，这会立即排除任何模拟或贪婪的逐步分配。 任何解决方案都必须在每个测试用例的恒定或对数时间内工作。 这也表明目标函数的结构足够简单和平滑，可以通过分析而不是通过离散搜索进行优化。 

天真的尝试会尝试一个一个地分配增量，总是将下一个增量分配给增加乘积更多的一方。 这会以一种微妙的方式失败，因为边际增益在每一步之后都会发生变化，因此局部最优选择可能会偏离全局最优。 

例如，假设$a = 1$,$b = 100$,$k = 2$。 贪婪策略可能会立即增加$a$因为它可以改善平衡，但根据具体的顺序，它最终可能比不同分配更糟糕。 关键问题是，这个决定取决于未来的分配，而不仅仅是眼前的收益。 

Another failure case appears when$k = 0$。 任何假设至少有一步棋或通过分裂进行归一化的算法$k$除非明确允许零增量并返回原始对，否则将中断。 

## 方法

 暴力方法会枚举所有分发方式$k$两个变量之间的增量。 如果我们分配$x$增加到$a$， 然后$k-x$去$b$，我们评估所有$k+1$的可能性。 这是正确的，因为每个有效的操作序列都与这样的一个拆分完全对应。 然而，这种方法是线性的$k$，这取决于$10^{18}$，使其完全不可行。 

当我们将最终值重写为$c = a + x$和$d = b + (k - x)$。 目标变成最大化单变量函数：$$f(x) = (a + x)(b + k - x)$$展开它揭示了一个二次函数$x$，特别是凹抛物线。 凹性意味着最大值是在顶点附近实现的，而不是在任意点处。 这将问题从搜索巨大的离散空间转变为仅评估顶点周围恒定数量的候选者。 

抛物线的顶点给出实值最优值，并且整数最优值必须非常接近它。 因此，检查顶点周围的小邻域足以保证最佳整数解。

 ## 算法演练

 我们将问题简化为选择多少增量$x$去$a$，与剩余的$k-x$应用于$b$。 

1. 将最终状态解释为$c = a + x$和$d = b + k - x$， 在哪里$x$范围从$0$到$k$。 这种重新参数化捕获了每个有效的操作序列。 
2. 定义目标函数$f(x) = (a + x)(b + k - x)$。 这将二维决策转变为单变量优化问题。 
3. 展开表达式查看其结构：$$f(x) = -x^2 + x(a - b - k) + a(b + k)$$负系数$x^2$显示该函数是凹函数，这意味着在实线上恰好存在一个全局最大值。 
4. 计算抛物线的实值顶点：$$x^* = \frac{(b + k) - a}{2}$$这是任何一方增加的边际收益平衡的点。 
5. 自从$x$必须是整数并且位于$[0, k]$，将注意力限制在顶点周围的候选值上。 唯一有意义的候选人是$x = \lfloor x^* \rfloor$和$x = \lceil x^* \rceil$，将它们钳位到有效范围后。 
6. 评估两个候选产品并选择产生较大价值的产品。 
7.输出对应的$c = a + x$和$d = b + (k - x)$。 

### 为什么它有效

 功能$f(x)$是连续域上的凹二次方程，因此任何局部最大值也是全局的。 当限制为整数时，最佳值必须位于最接近真实顶点的整数处。 由于凹二次方程恰好改变单调方向一次，因此不存在可以隐藏远离顶点邻域的更好解的次级峰值。 这保证了检查最多两个整数就足以找到最佳分割。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a = int(input().strip())
    b = int(input().strip())
    k = int(input().strip())

    def value(x):
        return (a + x) * (b + (k - x))

    # vertex of concave quadratic
    # x* = ( (b+k) - a ) / 2
    x_star = ((b + k) - a) / 2

    candidates = set()

    for x in [int(x_star), int(x_star) + 1]:
        if 0 <= x <= k:
            candidates.add(x)

    # also clamp boundaries (important for extreme cases)
    candidates.add(0)
    candidates.add(k)

    best_x = 0
    best_val = -1

    for x in candidates:
        v = value(x)
        if v > best_val:
            best_val = v
            best_x = x

    c = a + best_x
    d = b + (k - best_x)
    print(c, d)

if __name__ == "__main__":
    solve()
```解决方案首先读取三个整数。 然后它将决策重新定义为选择$x$，分配给的增量数$a$。 辅助函数直接计算给定分割的结果乘积。 

核心思想是使用闭式表达式计算抛物线顶点。 由于浮点舍入可能会错过边界情况，因此该实现会检查顶点的下限和上限，并且还包括端点$0$和$k$，它安全地覆盖了顶点位于有效区间之外的所有退化情况。 

最后，最佳分割被转换回所需的输出值。

 ## 边缘情况

 当$k = 0$，候选集仍必须包括$x = 0$。 该算法显式插入两个边界，因此它立即返回$(a, b)$不依赖于顶点计算。 

当顶点位于外侧时$[0, k]$，例如当$a$远大于$b + k$，计算出的$x^*$变为负值。 在这种情况下，双方$int(x^*)$和$int(x^*) + 1$被有效性检查忽略，只留下边界候选。 因此，该算法正确地将所有操作转移到较小的一侧。 

当值非常大时，中间产品适合 Python 整数，因此溢出不是问题。 在固定宽度语言中，出于安全考虑，需要 64 位乘法，但逻辑保持不变。
