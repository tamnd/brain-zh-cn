 ## 解决方案
 ## 问题理解

 我们得到了一系列的柱子，每个柱子都有一个高度。 青蛙从某根柱子开始，想到达右边的另一根柱子，但它只能向前跳，每次跳最多只能跳过`k`职位。 

对于任何索引区间`[l, r]`，青蛙考虑从以下位置开始的所有有效路径`l`，结束于`r`，并且仅向前移动最多跳跃长度`k`。 沿着每条这样的路径，我们都会查看所有访问过的柱子中的最小高度，青蛙希望最大化这个最小值。 该值表示为`f(l, r)`。 

任务是计算总和`f(l, r)`在所有对上`l ≤ r`。 

约束允许最多 200,000 个支柱，这立即排除了任何检查所有对的解决方案`(l, r)`明确地。 一个简单的方法已经需要 O(n²) 对，甚至计算每个`f(l, r)`在最坏的情况下，单独将使其变为立方体。 这远远超出了任何可行的限制。 

隐藏的困难在于`f(l, r)`不仅仅是端点的函数。 它取决于最佳约束路径结构，这使得直接区间 DP 成本高昂，除非我们找到全局结构重构。 

出现微妙的边缘情况时`k`很大。 如果`k ≥ n`，青蛙总是可以直接从`l`到`r`， 所以`f(l, r)`变得简单`min(a[l..r])`。 在这种情况下，任何正确的解决方案都必须优雅地简化为经典的“子数组最小值之和”问题。 

另一个边缘情况是`k = 1`。 然后青蛙被迫一步一步地走，所以每个区间都有一条路径，`f(l, r)`成为段上的最小值，但仅沿着连续路径，这再次将问题结构简化为纯子数组最小聚合。 

这些观察结果表明，该问题从根本上讲是关于在受限可达性图下组合局部最小约束。 

## 方法

 如果我们尝试计算`f(l, r)`直接来说，我们首先需要了解允许哪些路径。 青蛙建了一条路`l`到`r`使用边缘`(i → j)`在哪里`1 ≤ j - i ≤ k`。 这形成了一个有向无环图，其中每个节点都连接到下一个节点`k`节点。 

对于固定对`(l, r)`，我们想要一条最大化最小顶点权重的路径。 这是一个经典的“最大瓶颈路径”问题，但每个查询计算它的成本太高。 

关键的转变是观点的转变。 我们不问两个端点之间的最佳路径是什么，而是问：对于给定的阈值`x`，什么时候可以从`l`到`r`仅使用高度至少为`x`？ 

如果我们固定一个阈值`x`，我们可以标记所有位置`a[i] < x`被阻止。 问题变成了检查滑动窗口边缘下 DAG 中的连通性。 对于每个`l`，我们想知道在有效节点内我们能到达多远。 这表明了一种动态规划解释，其中每个位置聚合前一个位置的可达性`k`职位。 

现在是关键的组合洞察。 而不是按每个处理`(l, r)`，我们翻转聚合：每个位置`i`为许多对做出贡献`(l, r)`作为某些最优路径的最小元素。 如果我们按照高度降序对元素进行排序，然后将它们一一激活，就可以维持当前激活集合下可达段的结构。 

我们维护哪些指数是“活跃的”（高度至少是当前阈值）。 当我们激活一个新职位时`i`，它可以桥接一定距离内先前活跃区域之间的连接`k`。 这使我们能够在动态图中维护连接的组件，其中边仅存在于本地。 

每个元素的贡献取决于它何时成为某个区间内的限制因素。 这会导致联合查找或分段合并过程，其中每个激活都会合并附近的可达块，并贡献其高度乘以新块的数量`(l, r)`它成为瓶颈的对。 

这将问题从间隔上的二次问题简化为本质上的排序和使用摊销近线性并集运算的局部合并。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对所有路径进行暴力破解 | O(n3) | O(n²) | 太慢了 |
 | 激活+DSU/段合并| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 按高度递减对索引进行排序，因此我们从最高到最低处理支柱。 这确保了当我们激活一个位置时，它成为涉及它的任何区间的最大可能瓶颈候选者。 
2. 维护数组`active[i]`指示是否位置`i`已被激活。 最初，所有这些都处于非活动状态。 
3. 维护索引的并查找结构，但只允许距离最大为 的位置之间进行合并`k`并且两者都处于活跃状态。 每个组件代表当前阈值下的最大可达块。 
4. 激活位置时`i`，将其标记为活动并尝试将其与范围内的活动邻居合并`[i-k, i-1]`和`[i+1, i+k]`。 每次合并都会扩展可达性。 
5. 对于每个新形成的组件，计算有多少个`(l, r)`它引入了间隔，其中该激活是沿最佳路径的最小高度。 这是从合并段的大小以及任何`l`在左边界和`r`在右边界通过活动节点连接。 
6. 将计数乘以`a[i]`并添加到答案中。 这是可行的，因为我们按照高度递减的顺序进行处理，所以`a[i]`是激活时剩余的最大可能最小值。 
7. 继续，直到处理完所有索引。 

### 为什么它有效

 关键的不变量是当一个位置`i`被激活，所有已经激活的位置至少有高度`a[i]`。 因此此时形成的任何连接仅取决于高度≥的节点`a[i]`。 这意味着任何最佳瓶颈恰好是`a[i]`精确计算时`i`被介绍。 一旦稍后激活较小的高度，它们就不会影响已由较大高度“声明”的区间，因为这些区间已经具有仅使用较高或相等节点的可行路径。 这可以防止重复计算，并确保每个间隔在确定其瓶颈时只贡献一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.sz = [1] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return 0
        if self.sz[a] < self.sz[b]:
            a, b = b, a
        self.p[b] = a
        self.sz[a] += self.sz[b]
        return 1

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    order = sorted(range(n), key=lambda i: -a[i])

    dsu = DSU(n)
    active = [False] * n

    total = 0

    for i in order:
        active[i] = True

        # try to connect within distance k
        for d in range(1, k + 1):
            if i - d >= 0 and active[i - d]:
                dsu.union(i, i - d)
            if i + d < n and active[i + d]:
                dsu.union(i, i + d)

        # after activation, compute contribution
        root = dsu.find(i)

        # compute boundaries of component
        left = i
        j = i
        while left - 1 >= 0 and active[left - 1]:
            if dsu.find(left - 1) == root:
                left -= 1
            else:
                break

        right = i
        while right + 1 < n and active[right + 1]:
            if dsu.find(right + 1) == root:
                right += 1
            else:
                break

        total += a[i] * (i - left + 1) * (right - i + 1)

    print(total)

if __name__ == "__main__":
    solve()
```实施遵循从最高到最低支柱的激活顺序。 每次节点变得活跃时，我们都会将其连接到距离内已经活跃的邻居`k`。 DSU 在只有激活节点参与的约束下跟踪连接的组件。 

联合运算后，我们向左和向右扩展以测量新形成的活性成分的大小，其中包含`i`。 产品`(i - left + 1) * (right - i + 1)`计算在此激活步骤中确定了多少个间隔的最佳瓶颈，因为`i`成为跨越这些端点的所有路径的控制最小值。 

一个微妙的点是，扩展依赖于连续的活动组件，这是有效的，因为激活顺序保证了可达区域的单调增长，而DSU保证了在`k`-步骤规则。

 ## 边缘情况

 当所有高度相等时，每次激活都会同等贡献，并且一旦节点变为活动状态，DSU 就会立即合并所有内容。 该算法对称地对待每个位置，因此每个间隔都以相同的权重精确计数一次。 

什么时候`k = 1`，连通性仅在邻居之间形成。 该算法逐渐构建一条链，每个节点的贡献准确地反映了强制路径上它是最小激活元素的子数组的数量。 扩展步骤正确匹配连续的 DSU 组件。 

什么时候`k ≥ n`，每个新的激活都可以连接到所有先前激活的节点。 DSU 快速折叠成单个组件，并且每个步骤的贡献与端点的完整矩形成正比，其中高度是限制因素，与纯子阵列最小聚合的预期减少相匹配。
