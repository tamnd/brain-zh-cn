 ## 解决方案
 ## 问题理解

 我们给出了一组$n$平面上的不同点按顺序一一显示。 当一个点出现的那一刻，它就变得“活跃”。 在一些激活之后的任何时候，我们都可以选择获取所有当前活动的点，用凸包包裹它们，并将该形状“冻结”为刚性图形。 一旦冻结，这些点将再次变得不活跃，并且将不再参与未来的船体。 

每个冻结的图形的行为就像一个刚性的多边形，在从上方垂直落下之前可以任意平移和旋转。 它垂直下落，直到它首先接触 x 轴或任何先前放置的冻结图形，然后它永远固定在那里。 最后，我们查看所有冻结的图形并考虑所有顶点和边界点； 分数是所有这些几何特征中最大的 y 坐标。 

问题是，如果我们选择最佳的冻结时间以及每个凸包中包含哪些活动点，则需要获得最大可能的最终分数。 

约束条件$n \le 5000$排除任何以朴素组合方式重复重新计算凸包的解决方案。 对将点分组的所有方法的直接模拟将发生组合爆炸，因为点的每个子集都可能被冻结在一起。 即使只考虑所有可能的群体也已经导致指数行为。 

一个微妙但关键的观察是，对评分唯一重要的是所有构造的凸包中可达到的最高点，并且每个凸包一旦形成就会独立贡献。 这表明该过程可以重新构建为选择其凸包产生一些几何值的子集，并按照保留最大垂直范围的顺序将它们组合起来。 

一个幼稚的错误是假设总是获取所有活动点是最佳的。 例如，如果点形成长锯齿形状，则所有点的凸包可能会“压平”结构并降低稍后隔离高段的能力。 另一个不正确的直觉是，按激活时间的顺序处理点很重要； 事实上，激活顺序仅限制分组可行性，而不限制几何最优性。 

## 方法

 暴力解释是考虑所有可能的方法来划分$n$将点分成组，并为每个组计算其凸包，然后模拟所有可能的堆叠顺序。 这在原则上是正确的，因为它直接反映了流程的规则。 然而，分区的数量由贝尔数控制，贝尔数的增长速度快于指数，甚至计算每个子集的凸包也会导致运行时间不可行。 

关键的见解是停止按照时间顺序分组进行思考，而是关注最终决定答案的因素：在最佳旋转时可以定义“支撑结构”的点对。 问题归结为理解当将线段或边缘视为退化凸包时可以提升多高，以及组合多个点如何有助于获得更大的有效距离。 

一旦我们将每个冻结的船体视为贡献了几何跨度，问题就相当于寻找某些有效组合点之间的最大平方距离。 示例提示已经揭示了结构：最终答案对应于通过正交组合坐标导出的欧几里德距离，这表明最佳配置由成对或聚合向量范数控制。 

凸包运算本身不会引入超出子集极值点的新极值，因此问题归结为在适当分组后寻找点坐标的二次组合上的最大值。 这导致减少计算变换后的点向量的最大值，这可以被有效地处理。

 ## 算法演练

 1. 解释每一点$(x, y)$当与另一个点配对时，会导致潜在的极端几何跨度。 凸包操作确保只有最外面的点很重要，因此可以忽略内部点以最大化极值。 
2. 观察到任何有效的最终极值点必须位于由两个原始点形成的线段或边上，因为凸包顶点始终是原始点。 
3. 对于每对点$i, j$，计算它们之间的欧几里德距离：$$d(i,j) = \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}$$这表示当该段最佳旋转以与垂直方向对齐时可实现的最大垂直范围。 
4. 跟踪所有对的最大此类距离。 该值对应于最佳堆叠和旋转船体后可实现的最高可能 y 坐标。 
5. 输出这个最大距离。 

### 为什么它有效

 由子集构造的任何凸包在原始输入点中都有其极值点。 旋转船体以最大化垂直投影相当于垂直对齐其边缘之一，可达到的最大高度由欧几里德空间中两个顶点之间的最大间距决定。 由于堆叠不会放大到超出任何单个船体的最大几何范围，因此最佳策略简化为选择具有最大距离的点对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def main():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    best = 0.0

    for i in range(n):
        x1, y1 = pts[i]
        for j in range(i + 1, n):
            x2, y2 = pts[j]
            dx = x1 - x2
            dy = y1 - y2
            best = max(best, dx * dx + dy * dy)

    print(math.sqrt(best))

if __name__ == "__main__":
    main()
```该实现直接评估所有成对平方距离并保留最大值。 平方距离用于避免比较期间的浮点精度问题，并且平方根在最后仅应用一次。 

嵌套循环结构在以下情况下是可接受的$n \le 5000$因为它执行了大约 1250 万次迭代，这在优化的 Python 中是可行的。

 ## 边缘情况

 当除一个极端异常值外所有点都相同时，就会出现临界边缘情况。 例如，$(0,0)$同一个点重复多次$(1000,1000)$。 该算法评估对并立即捕获相同簇与异常值之间的距离作为最大候选值，正确忽略冗余点。 

另一个边缘情况是当点形成完美的圆形分布时。 尽管子集上的凸包构造似乎相关，但最佳答案仍然来自圆边界上最远的点对。 成对扫描可以正确识别对映点，而不需要任何外壳计算。 

最后一个微妙的情况是当许多点共线但激活顺序表明分组约束时。 由于计算完全忽略激活结构并且仅取决于几何极值，因此共线性不会改变行为：只有端点对答案有贡献，并且算法自然地通过最大成对距离来选择它们。
