 ## 解决方案
 ## 问题理解

 我们得到一个最多 500 个顶点的有向图。 每个顶点都有相同数量的出边和入边，并且该图是强连接的。 在此图上，我们放置一条“蛇”，其配置不仅仅是单个顶点或边，而是固定长度的完整顶点序列。 

蛇的状态由序列描述$a_0, a_1, \dots, a_m$。 解释是蛇的头位于$a_0$，以及每个连续的对$(a_i, a_{i-1})$必须是图中的有向边。 所以如果你颠倒顺序$a_m \to a_{m-1} \to \dots \to a_0$，您将获得有效的有向步行长度$m$。 

一次移动就会使这个窗口沿着下面的路径向前移动：新的头部沿着从$a_0$，并且每个其他关节向前移动一个位置。 因此，蛇的演化就像图中有向行走上的滑动窗口一样。 

任务是计算存在多少个移动序列，从任何初始状态开始，访问每个可能的蛇状态一次。 如果两个这样的完整遍历从不同的状态开始或者访问状态的顺序不同，则它们是不同的。 

制约因素是主要困难。 图尺寸虽小，但蛇的长度$m$可以大到$10^9$，因此我们无法显式构建或迭代蛇状态。 任何解决方案都必须压缩对$m$代数结构或导出量的快速求幂。 

一个微妙的点是，蛇态的数量原则上已经是巨大的。 然而，每个状态完全对应于长度的有向行走$m$在原始图中，所以状态空间有大小$n \cdot k^m$， 在哪里$k$是公出度。 这种指数依赖性$m$意味着我们永远不会直接枚举状态或转换。 

一个天真的误解是将状态视为独立节点并尝试模拟对它们的遍历。 即使存储邻接也是不可能的，因为每个状态都有一个等于其头顶点的出度的分支因子，但状态本身的数量是指数级的$m$。 

## 方法

 蛮力视角是显式构造顶点均为有效长度的状态图——$m$在原始图中行走。 来自一个州$a_0 \dots a_m$，我们可以移动到通过选择出边获得的任何状态$a_0 \to b_0$并移动顺序。 这会产生一个有向图，其中每个节点都有出度$k$，节点数为$n \cdot k^m$。 

然后问题就变成了计算这个巨大图中的哈密顿路径。 这是没有希望的，因为即使表示图也是指数的$m$。 瓶颈在于状态不是独立的对象； 它们严重重叠，因为两个状态仅在步行的后缀上有所不同。 

关键的结构洞察力是这个状态图不是任意的。 它正是原始有向图的迭代线图构造。 每个顶点对应于一次步行，每个转换对应于将步行延长一步并删除最旧的顶点。 该结构的行为类似于基本有向图上的 de Bruijn 图。 

在这种结构中，许多全局组合属性简化为原始图的谱属性。 规律性假设在这里变得至关重要：因为每个顶点都有相同的入度和出度$k$，邻接矩阵具有简单的显性特征结构，并且 walk 将因子干净地计数为$k$与单个全局不变量相结合：跨越树状结构的数量。 

这会减少有效完全遍历的数量仅取决于两个成分。 一个是组合因素，它像力量一样增长$k$决定于$m$和顶点的数量。 另一个是原始图的结构常数，由以任意位置为根的有向生成树的数量给出，可以通过有向矩阵树定理计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 状态图上的暴力破解 | 指数为$k^m$| 指数| 太慢了 |
 | 谱约简+矩阵树定理|$O(n^3 + \log m)$|$O(n^2)$| 已接受 |

 ## 算法演练

 解决方案通过将所有内容简化为原始图的拉普拉斯算子和均匀度来进行$k$。 

1. 计算公共出度$k$每个顶点。 这是明确定义的，因为该图是规则的。 
2. 构建有向图的拉普拉斯矩阵，其中对角线元素为$k$和非对角线条目反映传出边缘。 该矩阵对图的所有跨越树状结构进行编码。 
3. 使用有向矩阵树定理进行计算$\tau(G)$，以固定节点为根的跨越树状结构的数量。 在正则强连通有向图中，该值与根无关。 
4. 计算蛇长度的指数贡献。 每一步都会延伸一段长度——$m$一步一步走，每一步都恰好有$k$新边缘的选择。 在所有状态的哈密顿量覆盖的完整结构上，这产生了一个因子$k^{m(n-1)}$，反映了独立分支选择的积累$n-1$跨越结构选择的自由度。 
5. 将结构和增长成分相乘：最终答案是$\tau(G) \cdot k^{m(n-1)}$，取模$998244353$。 

关键的重要一点是，对详细邻接模式的所有依赖都归结为$\tau(G)$，而所有依赖$m$折叠成一个纯指数$k$。 

### 为什么它有效

 由长度形成的状态图$m$walks 是一个迭代线图$k$-正则欧拉有向图。 线图结构保留了欧拉平衡，同时将步行复杂性提升了一维。 在此类图中，全局遍历计数由 BEST 定理样式分解控制：局部度贡献和全局树状计数的乘积。 

正则性确保每个顶点对度项的贡献相同，因此所有非平凡的组合都集中到原始图的生成树结构中。 蛇的长度仅控制该局部分支结构沿每个蛇复制的次数。$n-1$跨越遍历的独立约束，产生指数$m(n-1)$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def det_mod(mat):
    n = len(mat)
    res = 1
    sign = 1

    for i in range(n):
        pivot = -1
        for r in range(i, n):
            if mat[r][i]:
                pivot = r
                break
        if pivot == -1:
            return 0

        if pivot != i:
            mat[i], mat[pivot] = mat[pivot], mat[i]
            sign = -sign

        inv = pow(mat[i][i], MOD - 2, MOD)
        res = res * mat[i][i] % MOD

        for r in range(i + 1, n):
            factor = mat[r][i] * inv % MOD
            for c in range(i, n):
                mat[r][c] = (mat[r][c] - factor * mat[i][c]) % MOD

    return res * (1 if sign == 1 else MOD - 1) % MOD

n, m = map(int, input().split())
g = [list(map(int, input().split())) for _ in range(n)]

deg = sum(g[0])

k = deg

# build Laplacian minor (remove last row/col)
lap = [[0] * (n - 1) for _ in range(n - 1)]

for i in range(n - 1):
    for j in range(n - 1):
        if i == j:
            lap[i][j] = k
        else:
            lap[i][j] = (-g[i][j]) % MOD

tau = det_mod(lap)

ans = tau * mod_pow(k, m * (n - 1)) % MOD
print(ans)
```该实现首先从邻接矩阵重建均匀度。 然后，它通过放置来构建简化的拉普拉斯矩阵$k$在对角线上和$-1$（模数$MOD$) 只要有有向边。 

行列式以模计算$998244353$使用高斯消去法。 这给出了跨越树状结构的数量。 

最后，快速求幂$k$权力$m(n-1)$，这是唯一受到较大约束的部分$m$出现。 

一个微妙的实现点是行列式必须以素数为模来计算，因此模逆是有效的。 求幂步骤必须使用 64 位整数完成，因为$m(n-1)$可以超过 32 位范围。

 ## 边缘情况

 一种边缘情况是当图是有向循环状规则结构时，其中每个顶点恰好具有一个出边。 在这种情况下$k=1$，因此指数项变为$1^{m(n-1)} = 1$，答案完全简化为跨越树状计数。 该算法自然地处理了这个问题，因为模幂正确返回 1，无论$m$。 

另一种边缘情况是当图形密集但程度对称时，会导致大量跨越树状结构。 行列式计算保持稳定，因为模消除不依赖于稀疏性，仅依赖于域中的可逆性。 

最终的边缘情况很大$m$。 该算法从不构造任何依赖于$m$超越指数，所以即使当$m = 10^9$，计算相对于输入大小保持恒定时间。
