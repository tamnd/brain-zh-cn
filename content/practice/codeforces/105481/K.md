 ## 解决方案
 ## 问题理解

 我们从一个空的多重集开始$S$。 每个操作要么插入一个数字的出现$x$进入$S$，或删除一个出现的$x$这是保证存在的。 每次修改后，我们都会查看通过选择当前元素的任何子多重集可以形成的所有子集和，并计算有多少个不同的正整数可以表示为这样的和。 

换句话说，在每一步之后，我们都会考虑来自的所有有限元素选择$S$（每个副本最多可以使用一次，因为这是一个多重集），计算它们的总和，并询问有多少个不同的值$1,2,3,\dots$是可以实现的。 每次操作后的输出是该可达集的大小，仅限于正整数。 

关键的约束是，在每一时刻，当前所有元素的总和$S$至多是$5 \cdot 10^5$。 这立即限制了我们需要关心的最大可能子集总和，因为子集总和不能超过总和。 它还意味着任何超过总和的动态编程状态都可以安全地由$5 \cdot 10^5$。 

操作次数最多为$5 \cdot 10^3$，所以我们可以负担得起算法$O(n \cdot \text{poly}(V))$在哪里$V = 5 \cdot 10^5$仅当每步工作都经过极其优化时，最好使用位级操作或摊销重用。 

在每次操作后从头开始重新计算子集和的简单方法太慢了，因为每次重新计算已经花费了大约$O(nV)$或者$O(V \cdot \#\text{elements})$，并且这样做直到$5 \cdot 10^3$次变得不可行。 

一个微妙的陷阱是删除会破坏单调性。 如果我们只进行插入，则可达集只会增长，并且标准背包位集更新就足够了。 删除操作迫使我们维持一种完全动态的结构，而不是单向的DP。 

另一个边缘情况是重复值。 由于插入不能保证是唯一的，因此我们必须对待$S$作为真正的多重集。 例如，插入$x$两次可以产生需要使用两个副本的总和，删除一个副本只能部分收回这些贡献。 

## 方法

 蛮力的想法很简单：维护当前的多重集并在每次操作后重新计算子集和 DP。 我们保留一个布尔数组$dp[s]$指示是否求和$s$是可以实现的，并且对于每个元素$x$我们做了一个经典的背包过渡$dp[s] \leftarrow dp[s] \lor dp[s-x]$从高到低。 这可以正确计算当前状态的所有子集总和。 

问题是每次操作后从头开始重新计算成本太高。 每次重建费用$O(V \cdot |S|)$，并且自从$|S|$可以是$O(n)$，总功变为$O(n^2 V)$，这远远超出了限制。 

关键的观察是我们不需要在每个操作中独立地重新计算所有内容。 相反，我们可以将时间视为另一个维度。 每个元素仅存在于从插入到删除的连续时间间隔内。 如果我们知道这些间隔，我们可以为每个出现的数字分配一个$x$到其处于活动状态的操作部分。 

随着时间的推移，这将问题转换为完全离线的动态背包：每个元素在某个时间间隔内处于活动状态$[l, r]$，并且我们需要每个时间前缀之后的 DP 结果，并准确考虑其间隔覆盖该时间点的元素。 处理此问题的标准方法是一段时间内的线段树，其中每个节点存储在该时间间隔内完全活动的项目。 

然后，我们运行分治式 DP：在每个线段树节点，我们维护一个位集 DP，表示分配给该节点的项目贡献的子集和。 我们通过向下传递 DP 来组合子元素，确保每个元素在从根到叶的每个路径上精确应用一次。 因为每个元素都被插入到$O(\log n)$节点，应用程序总数是可管理的。 

DP 本身是作为位集实现的，因此移位和 OR 运算是在机器字上执行的，从而使转换比简单的布尔数组快得多。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每次操作后重新计算 DP |$O(n^2 V)$|$O(V)$| 太慢了 |
 | 随时间变化的线段树 + 位集 DP |$O(n \log n \cdot V / w)$|$O(V)$| 已接受 |

 这里$w$是机器字大小（通常为 64），这使得位集操作变得实用。 

## 算法演练

 ### 1. 将操作转换为活动间隔

 我们按顺序扫描操作并为每个值维护一个堆栈或频率图$x$。 每次插入$x$开始一个新的活动间隔，每次删除都会关闭最近的开放间隔$x$。 如果一个元素被插入多次，则每个副本都会被独立跟踪。 

此步骤将动态序列转换为每个元素出现的一组不相交的时间间隔。 

### 2. 随着时间的推移构建线段树

 我们在索引范围上构建一棵线段树$[1, n]$。 每个节点对应一个时间间隔。 对于每个元素区间$[l, r]$，我们插入它的值$x$进入完全覆盖该区间的所有线段树节点。 这确保每个节点仅存储保证在其整个段中处于活动状态的元素。 

这种分解起作用的原因是每个时间点都属于$O(\log n)$节点，并且每个元素都准确地存储在代表其活动区间的最小覆盖的节点中。 

### 3. 使用位集 DP 计算子集和

 我们维护一个位集$dp$，其中位$i$如果总和为 1$i$是可以实现的。 最初仅$dp[0] = 1$。 

处理节点时，我们迭代所有值$x$存储在该节点中并应用转换$dp \leftarrow dp \,|\, (dp \ll x)$。 该模型包括或排除每次出现的$x$。 

由于移位对大整数（位集）进行操作，因此这比显式迭代所有总和要快得多。 

### 4.在线段树上的DFS

 我们递归地遍历线段树。 在每个节点，我们将其所有存储的项目应用到 DP 的本地副本。 当到达对应的叶子时$t$, DP 正好代表操作后的多重集状态$t$，因此我们通过计算范围内的设置位来计算可达正和的数量$[1, \text{sum}]$。 

每个递归分支完成后都会恢复 DP 状态，因此兄弟节点不受影响。 

### 为什么它有效

 正确性来自两个不变量。 首先，每个元素都被插入到恰好覆盖其活动生命周期的节点中，因此在任何叶子上，DP 都精确地包含当时活动的那些元素。 其次，每个 DP 转换都是标准的子集和背包，因此位集精确地编码了该节点表示的多重集的所有可实现的和。 由于线段树划分时间时没有重叠错误，因此每个操作的答案都是根据活动集的正确重建来计算的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXV = 500000

def count_bits(x):
    return x.bit_count() - 1  # exclude 0

def add_interval(tree, node, l, r, ql, qr, val):
    if ql <= l and r <= qr:
        tree[node].append(val)
        return
    mid = (l + r) // 2
    if ql <= mid:
        add_interval(tree, node * 2, l, mid, ql, qr, val)
    if qr > mid:
        add_interval(tree, node * 2 + 1, mid + 1, r, ql, qr, val)

def dfs(tree, node, l, r, dp, ans):
    local = dp
    for x in tree[node]:
        local = local | (local << x)

    if l == r:
        ans[l] = count_bits(local)
        return

    mid = (l + r) // 2
    dfs(tree, node * 2, l, mid, local, ans)
    dfs(tree, node * 2 + 1, mid + 1, r, local, ans)

def solve():
    n = int(input())
    ops = []
    pos = {}
    intervals = []

    for i in range(1, n + 1):
        op, x = map(int, input().split())
        ops.append((op, x))
        if op == 1:
            pos.setdefault(x, []).append(i)
        else:
            l = pos[x].pop()
            intervals.append((l, i, x))

    for x, lst in pos.items():
        for l in lst:
            intervals.append((l, n, x))

    size = 4 * (n + 5)
    tree = [[] for _ in range(size)]

    for l, r, x in intervals:
        add_interval(tree, 1, 1, n, l, r, x)

    dp = 1  # bitset with only 0 reachable
    ans = [0] * (n + 1)

    dfs(tree, 1, 1, n, dp, ans)

    print("\n".join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```该实现首先将在线插入/删除序列转换为显式活动间隔。 然后，它将每个时间间隔分布到线段树中，以便每个节点仅存储在该时间范围内完全活动的元素。 DFS 向下携带一个位集 DP，用每个节点的元素更新它。 由于 Python 整数充当任意长度的位集，因此移位和 OR 运算自然会实现子集和转换。 

每个叶子的答案是通过计算除零之外的设置位来计算的，因为只需要正和。

 ## 边缘情况

 一种微妙的情况是在删除之前重复插入相同的值。 例如，插入$x$两次然后删除一次必须仍保留一个副本处于活动状态。 间隔构造通过将删除与最近不匹配的插入配对来处理此问题，因此每个副本都有自己的生命周期。 

另一个边缘情况是多重集变空时。 DP 必须重置为仅$\{0\}$，意味着不存在正和。 线段树表示自然会在那时产生一个空的 DP，因为没有间隔对该叶子有贡献。 

最后一个极端情况是所有元素都很大并且接近全局总和限制。 尽管值可能高达$5 \cdot 10^5$，DP 宽度仍然受当前总和的限制，并且位集仍然表现正确，因为超出最高可达位不会影响正确性。
