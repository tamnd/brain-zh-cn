 ## 解决方案
 ## 问题理解

 我们得到了一个记分板，其形式如下`A-B`， 在哪里`A`代表 Alex 的分数，`B`代表对手的得分。 两个值都是 0 到 9 之间的单个数字。 

该系统应用“分数错觉”操作，简单地交换两个值。 变换后，Alex的分数变成了对手的分数，对手的分数也变成了Alex的分数。 输出必须再次以相同的方式打印`A-B`格式，但带有交换的值。 

由于每个值都是直接在输入字符串中编码的单个数字，因此约束非常小。 这意味着除了读取字符或分割字符串之外，不需要解析整数。 任何在每个输入上以恒定时间运行的解决方案都足够了。 

主要的微妙之处纯粹是语法上的：正确提取两个数字并保留格式。 粗心的实现可能会意外地将整个字符串视为数字，或者在出现格式变化时错误地分割。 

具体的边缘情况是`0-0`。 正确的输出仍然是`0-0`。 另一个是`9-0`，这必须成为`0-9`。 任何删除前导零或假设多位算术的解析仍然需要保留精确的数字。 

## 方法

 强力解释会将 A 和 B 视为数字，通过将它们转换为整数来模拟交换，并重建字符串。 这是正确的，因为交换独立于数字结构，但对于如此小的固定大小输入来说这是不必要的开销。 

真正的简化来自于注意到输入格式是严格的：恰好是一个字符，然后是连字符，然后是一个字符。 没有歧义，没有多位解析，也没有空格处理。 “计算”只是一个字符重排问题。 

因此，解决方案简化为读取字符串并交换连字符周围的字符。 根本不需要算术。

 ## 算法演练

 1.读取输入字符串`s`，其形式为`A-B`。 该结构保证恰好三个有意义的字符加上一个换行符。 
2. 识别第一个字符`s[0]`作为亚历克斯的原始乐谱和最后一个角色`s[2]`作为对手的得分。 中间字符始终是分隔符`-`。 
3. 通过放置构建结果`s[2]`， 然后`-`， 然后`s[0]`。 这直接实现了“幻象”，无需转换类型或修改值。 
4. 输出构造好的字符串。 

### 为什么它有效

 该问题将变换定义为嵌入固定位置的两个独立标量值的纯交换。 由于格式不变并且每个分数占据单个字符位置，因此交换位置 0 和 2 处的字符可以保留所有语义。 数字之间没有依赖性，也没有进位或算术效应，因此字符排列与所需的转换完全匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
print(f"{s[2]}-{s[0]}")
```该实现完全依赖于位置索引。 这`.strip()`确保换行符不会干扰索引。 由于格式保证是`digit-digits`, 索引`s[0]`和`s[2]`总是安全的。 

一个常见的错误是尝试分割`-`并忘记正确重建格式。 尽管`split('-')`也可以，直接索引更简单并且避免中间字符串分配。

 ## 边缘情况

 输入`0-0`演示交换相同的值必须保留相同的字符串。 算法读取`s[0]=0`和`s[2]=0`，然后构造`0-0`，符合预期。 

为了`9-0`，算法提取`9`和`0`和输出`0-9`。 不需要特殊处理，因为输出格式纯粹是位置格式，而不是数字格式。 

由于每个有效输入恰好是三个有意义的字符，因此除了数字身份之外不存在结构边缘情况，算法通过索引固有地处理这些情况。
