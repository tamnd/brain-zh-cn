 ## 解决方案
 ## 问题理解

 这个问题要求我们处理一个无向、未加权的图来表示动物园内的路径。 一些顶点包含斑马围栏。 对于每个顶点，我们需要到达包含斑马包围的任何顶点所需的最短边数。 如果一个顶点与每个斑马包围圈分开，那么它的答案是`-1`。 硬版本与简单版本不同，因为可以有许多斑马围栏，而不是只有一个。 [Codeforces Gym 105940C - ASZoo 的大斑马探索（困难）](https://codeforces.com/gym/105940/problem/C)

 输入包含多个测试用例。 每个测试用例都会给出位置数量、位置之间的路径数量以及斑马围栏的数量。 接下来的行描述路径，后面是机柜位置列表。 输出是每个位置的最小距离（按顺序）。 

约束是围绕线性图算法设计的。 在所有测试用例中，顶点和边的总数最多为`2 * 10^5`。 这排除了从每个顶点运行图搜索的解决方案，因为从每个节点执行 BFS 的成本约为`O(n * (n + m))`，可以到达周围`4 * 10^10`运营。 附近的一个解决方案`O(n + m)`是预期的方向。 

有一些情况会破坏粗心的实现。 第一种情况是顶点本身就是斑马围栏。 例如：```
1
3 2 2
1 2
2 3
1 3
```正确的输出是：```
0 1 0
```解决方案的起始距离为`1`对于所有发现的节点并忘记初始化源`0`会产生错误的答案。 

另一种情况是断开连接的图：```
1
4 2 1
1 2
3 4
1
```正确的输出是：```
0 1 -1 -1
```将所有距离初始化为的遍历`0`或者假设每个顶点最终都会被访问，则会错误地将值分配给无法到达的组件。 

最后的边缘情况是当所有顶点都是斑马包围时：```
1
3 3 3
1 2
2 3
1 3
1 2 3
```正确的输出是：```
0 0 0
```如果实现不能正确处理多个起点，则可能仅计算与一个外壳之间的不必要的距离。 

## 方法

 最简单的方法是从每个 Zebra 机箱中单独运行 BFS。 由于 BFS 在未加权图中给出最短距离，因此每次运行都会正确计算来自一个源的距离，并且在所有运行中取最小值即可给出答案。 问题是这会多次重复相同的工作。 

在最坏的情况下，可能会出现`n`斑马围栏。 运行广度优先搜索`k`时间成本`O(k(n + m))`。 和`k`附近`n`，这变成了`O(n(n + m))`，对于给定的限制来说太慢了。 

关键的观察结果是所有斑马围栏都是同样有效的目的地。 我们并不关心我们到达了哪一斑马，只关心最近的斑马。 我们可以扭转观点，而不是分别从每只斑马进行探索。 想象一下所有斑马位置同时在图表中扩展。 第一次到达顶点时，分配给该顶点的距离自动为到最近斑马线的最短距离。 

这就是多源BFS。 我们最初将每个斑马围栏放入队列中并保持距离`0`。 然后继续正常的 BFS。 由于 BFS 通过增加距离来处理节点，因此到达任何顶点的第一个源必须是最近的可能源。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(k(n + m)) | O(k(n + m)) | O(n) | 太慢了|
 | 最佳 | O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 为图创建邻接表。 对于两个位置之间的每条路径，将每个端点添加到另一个端点的邻居列表中，因为该图是无向的。 
2. 创建一个距离数组并将每个值初始化为`-1`。 这表示尚未到达任何位置。 
3. 将每个斑马圈放入一个队列中，并将其距离设置为`0`。 每个围栏与其自身的距离已经为零，并且所有围栏都必须作为起点。 
4. 当队列不为空时，删除下一​​个位置。 对于每个仍有距离的相邻位置`-1`，将其距离指定为当前位置的距离加一并将其添加到队列中。 未访问的检查就足够了，因为 BFS 保证第一次访问是最短的一次。 
5、遍历结束后，输出距离数组。 任何剩余的`-1`值对应于无法到达斑马围栏的位置。 

工作原理：队列始终按照距最近斑马距离的非递减顺序存储顶点。 当第一次发现一个顶点时，会通过尽可能少的边到达它，因为每条较短的路径都已经被处理过。 由于所有斑马线位置都从一起开始，因此计算出的距离是每个可能的封闭范围内的最小值。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, m, k = map(int, input().split())

        graph = [[] for _ in range(n)]
        for _ in range(m):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            graph[u].append(v)
            graph[v].append(u)

        zebras = list(map(int, input().split()))

        dist = [-1] * n
        q = deque()

        for x in zebras:
            x -= 1
            dist[x] = 0
            q.append(x)

        while q:
            u = q.popleft()
            for v in graph[u]:
                if dist[v] == -1:
                    dist[v] = dist[u] + 1
                    q.append(v)

        ans.append(" ".join(map(str, dist)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```邻接列表仅存储现有边，这使图形表示与输入大小成比例。 队列包含 BFS 的边界并保证节点按正确的顺序进行处理。 

初始化循环是与普通 BFS 的主要区别。 不是选择一个源，而是在遍历开始之前插入每个斑马。 在插入之前设置距离可以防止再次访问同一斑马。 

条件`dist[v] == -1`是重要的边界检查。 它确保每个顶点都只分配一次。 由于沿边移动时距离会增加一，因此无需比较和更新已访问过的顶点。

 该循环是从斑马线向外探索的。 旁边的两个顶点接收距离`1`，其余顶点接收其最短值。

| 队列状态 | 当前节点 | 距离 |

 | 1,6 | 1 | 0 1 -1 -1 -1 0 |
 | 6,2| 6 | 0 1 -1 -1 1 0 | 0 1 -1 -1 1 0
 | 2,5 | 2 | 0 1 2 -1 1 0 | 0 1 2 -1 1 0
 | 5,3 | 5 | 0 1 2 -1 1 0 | 0 1 2 -1 1 0

 | 测量| 复杂性 | 说明|

 ## 边缘情况

 对于断开连接的情况：```
1
4 2 1
1 2
3 4
1
```队列以顶点开始`1`。 它访问顶点`2`并停止，因为没有更多可到达的节点。 顶点`3`和`4`不曾离开最初的`-1`状态，所以最终的答案是`0 1 -1 -1`。 

对于所有顶点都是斑马的情况：```
1
3 3 3
1 2
2 3
1 3
1 2 3
```每个顶点进入队列时都有距离`0`。 当检查邻居时，它们已经分配了距离，因此值不会改变。 结果依然`0 0 0`。 

对于竞争同一顶点的多个斑马围栏，BFS 顺序会自动处理平局。 到达顶点的第一个斑马波给出了可能的最小距离，任何后面的波都无法改善它，因为它必须穿过相等或更长的路径。
