 ## 解决方案
 ## 问题理解

 笼子能准确地容纳`k`动物。 有`n`动物家族，一个家族可以贡献任意非负数量的动物，因为每个家族都有无限多个成员。 家庭`i`贡献动物的体重`a[i]`。 任务是找到通过精确选择可以形成的每个总重量`k`动物，允许重复使用同一家族。 输出是按升序排列的所有可达总和的列表。 

家庭数量和动物数量的限制很小，但可能的答案范围是重要的部分。 自从`k`并且每个重量最多`1000`，最大可能的总和最多为`1,000,000`。 这意味着取决于最大重量范围的解决方案是现实的。 另一方面，对每个家庭、每个动物数量和每个金额的直接动态规划方法将花费大约`1000 * 1000 * 1,000,000`运营，这远远超出了我们的承受能力。 

棘手的案例来自于家庭可以被重用。 将每个系列视为只能使用一次的解决方案将会失败。 例如：```
Input
1 3
5

Output
15
```唯一可能的选择就是带同一个家庭三次。 子集样式 DP 会错误地表示只有权重`5`是可能的。 

另一个常见的错误是忘记了`k`需要动物。 例如：```
Input
2 2
1 100

Output
2 101 200
```总和`1`即使单个动物的重量也是无效的`1`存在。 我们必须追踪所选动物的数量，而不仅仅是可达到的数量。 

当所有族具有相同的权重时，会出现最终的边缘情况：```
Input
5 5
7 7 7 7 7

Output
35
```存在许多不同的选择，但它们都会产生相同的总和。 答案必须仅包含唯一的权重。 

## 方法

 简单的想法是构建一个动态规划表，其中`dp[c][s]`告诉我们是否可以准确选择`c`动物总重`s`。 对于每个可到达的状态，我们尝试将每个家庭作为下一个动物。 这是正确的，因为每个有效选择都可以通过重复添加一只动物来描述。 

问题是转换计数。 最多有`k`可能的动物数量，最多`k * max(a[i])`可能的金额，最多`n`下一个动物的选择。 在最坏的情况下，这大约是`1000 * 1,000,000 * 1000`，大约是一万亿次运算。 

关键的观察结果是，对于每个可达到的总和，转换都是相同的。 我们只需要将当前所有可达到的金额按每个家庭的体重进行转移即可。 Bitsets 正是为此而设计的。 位置有点`x`意味着总和`x`是可达的。 将位集左移`a[i]`标记通过添加家庭中的一只动物可以创建的所有总和`i`。 

我们没有将所有总和存储在一张大表中，而是为每种可能数量的动物保留一个位集。 当我们处理新的动物计数时，我们使用位移位更新下一层。 Python 整数的行为已经类似于任意长度的位集，因此单个移位和 OR 运算可以立即更新数千个状态。 

蛮力之所以有效，是因为它探索了每一种可能的最终选择。 更快的方法保持相同的状态定义，但用机器级位操作替换数百万个单独的转换。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(k * k * max(a) * n) | O(k * k * max(a)) | O(k * k * max(a)) | 太慢了|
 | 最佳 | O(k * n * (k * max(a)) / word_size) | O(k * n * (k * max(a)) / word_size) | O(k * k * max(a) / word_size) | O(k * k * max(a) / word_size) | 已接受 |

 ## 算法演练

 1. 创建`k + 1`位集。 这`i`-th 位集表示使用精确方法可实现的所有权重`i`动物。 最初只有零个体重为零的动物是可能的，因此第一个位集仅包含位`0`。 
2. 对于已选择的所有可能数量的动物`0`到`k - 1`，尝试再添加一只动物。 每个家庭的体重`w`，将当前位集左移`w`并将其合并到下一层。 这种转变意味着添加该家族的一种动物。 
3. 构建完所有层后，检查位集是否准确`k`动物。 每个设置位对应一个可实现的总重量，因此按升序收集这些位置。 

更新顺序很重要。 我们只是从更少的动物转移到更多的动物，所以在水平上创造了总和`c + 1`在同一关卡中从未重复使用，并且意外地被算作使用了额外的动物。 

为什么它有效：不变的是在完成层之后`c`，该层中的每个设置位准确地表示可通过以下方式获得的权重`c`动物，并且不存储无效体重。 从任何家族中添加一只动物相当于将整个可达到的权重移动该家族的权重。 将所有这些位移结合起来可以准确地产生有效状态`c + 1`动物。 通过归纳，最后一层恰好包含所有可能的笼子重量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    n, k = data[0], data[1]
    a = data[2:2 + n]

    dp = [0] * (k + 1)
    dp[0] = 1

    for cnt in range(k):
        cur = dp[cnt]
        if cur == 0:
            continue
        nxt = 0
        for w in a:
            nxt |= cur << w
        dp[cnt + 1] = nxt

    ans = []
    bits = dp[k]
    pos = 0
    while bits:
        low = bits & -bits
        pos = low.bit_length() - 1
        ans.append(str(pos))
        bits ^= low

    print(" ".join(ans))

if __name__ == "__main__":
    solve()
```数组`dp`存储每个精确动物计数的位集状态。 初始化`dp[0] = 1`意味着在选择任何动物之前只能达到零和。 

对于每一层，变量`cur`包含当前可达到的所有金额。 每个`cur << w`添加一只动物的重量`w`到之前的每一个可能性。 OR 运算组合了所有可能的族。 

提取循环重复查找最低设置位。 因为整数位是从低到高排序的，所以这自然会按升序产生答案。 删除最低位可以避免扫描每个可能的权重值。 

该实现不需要对整数溢出进行特殊处理，因为 Python 整数会自动增长。 主要边界细节仅迭代直到`k - 1`，因为最后一个转换恰好创建了状态`k`动物。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(k * n * S / 字大小) | 每层移动最大大小的位集`S`， 在哪里`S`是最大可能的总和。 |
 | 空间| O(k * S / 字大小) | 我们为每种可能的动物计数存储一个位集。 |

 这里`S`至多是`1,000,000`。 位集表示将许多布尔状态压缩到每个机器整数中，使该方法能够轻松地满足限制。

import sys
import io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return ""
    n, k = data[0], data[1]
    a = data[2:2+n]

    dp = [0] * (k + 1)
    dp[0] = 1
    for c in range(k):
        for w in a:
            dp[c + 1] |= dp[c] << w

    ans = []
    x = dp[k]
    while x:
        b = x & -x
        ans.append(str(b.bit_length() - 1))
        x -= b

    sys.stdin = old
    return " ".join(ans)

 ## 边缘情况

 对于重复家庭案例：```
Input
1 3
5
```该算法从可达总和开始`{0}`。 经过一次转换后，它有`{5}`，两次之后它有`{10}`，并且在三之后它有`{15}`。 最后一层仅包含`15`，正确地允许一个家庭无限使用。 

对于精确计数的情况：```
Input
2 2
1 100
```一只动物之后可达到的重量是`{1, 100}`。 第二次转换再次组合这些状态并创建`{2, 101, 200}`。 价值`1`永远不会出现在最后一层，因为它只使用一种动物。 

对于重复重量的情况：```
Input
5 5
7 7 7 7 7
```每个转换都会移动相同的量。 可达集增长为`{0}`,`{7}`,`{14}`,`{21}`,`{28}`,`{35}`。 位集会自动消除重复的可能性，因为一个位只能设置一次。
