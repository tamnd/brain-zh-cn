 ## 解决方案
 ## 问题理解

 我们给出了一组$n$必须准确划分为的人$m$非空组。 一旦分组确定，同一组内的每一对人就成为朋友。 一组大小$k$贡献$\frac{k(k-1)}{2}$友谊，因此友谊总数是该表达式在所有组中的总和。 

任务是在所有有效的分割方式中确定此类友谊对的最小和最大可能数量$n$人们进入$m$非空组。 

约束条件$n \le 10^9$立即排除任何枚举分组或模拟分布的解决方案。 任何方法都必须在恒定时间内仅使用封闭式推理来计算答案。 

当出现微妙的边缘情况时$m = n$。 在这种情况下，每个组的大小都是 1，因此不会形成友谊。 另一个是$m = 1$，所有人都在一个组中，并且答案是固定的。 一个天真的贪婪模拟可能会错误地尝试一步步构建组，但是因为$n$很大，即使是线性构造也是不可能和不必要的。 

## 方法

 关键的观察结果是，友谊的数量仅取决于群体规模，而函数$\frac{k(k-1)}{2}$呈二次方增长$k$。 这种凸性驱动最小和最大配置。 

为了最大化，我们希望将人们集中到一个大组中，因为将两个组放在一起总是会增加内部配对的总数，而不是拆分它们减少的总数。 从许多小组开始，合并会增加对的数量，其数量取决于组大小之间的交叉项，这始终是正数。 因此，最佳配置是放置$n - (m-1)$人们分成一组，留下其余的$m-1$组作为单例。 

对于最小值，相反的直觉适用。 由于二次增长会对大型群体造成不利影响，因此我们希望在所有群体中尽可能均匀地分配人员。 如果组大小相差超过 1，则将一个元素从较大的组移动到较小的组会减少平方和，从而减少内部对的数量。 这会导致最平衡的分区，其中组大小可以是$\lfloor n/m \rfloor$或者$\lceil n/m \rceil$，精确计数由余数确定。 

我们可以通过写来精确地导出最小值$n = m \cdot q + r$， 在哪里$0 \le r < m$。 然后$r$团体有规模$q+1$， 和$m-r$团体有规模$q$。

 ## 算法演练

 我们使用从最佳群结构导出的公式直接计算两个极值。 

### 最大友谊

 1. 分配$m-1$大小为 1 的组。这使用$m-1$内部友谊为零的参与者。 
2.将剩余的全部放入$n - (m-1)$参与者分成一组。 
3. 使用以下方法计算这个大群体内的友谊$\frac{k(k-1)}{2}$， 在哪里$k = n - m + 1$。 
4. 返回该值作为最大值。 

原因是，每次我们合并两个组时，我们都会引入新的交叉对，从而成为友谊，因此合并总是会增加总数。 

### 最低好友关系

 1. 计算底座尺寸$q = n // m$和余数$r = n \% m$。 
2. 构建$r$大小组$q+1$和$m-r$大小组$q$。 
3. 计算贡献：$$r \cdot \frac{(q+1)q}{2} + (m-r) \cdot \frac{q(q-1)}{2}$$4. 返回总和作为最小值。 

这样做的原因是，通过将一个元素从较大的组转移到较小的组，可以减少两个组之间的任何不平衡，从而严格减少对计数的总和。 

### 为什么它有效

 功能$f(k) = \frac{k(k-1)}{2}$是凸的$k$。 凸性意味着极端配置发生在边界分布处：要么最大倾斜（一大组），要么最大平衡（相等大小）。 由于我们在固定总和约束下优化凸函数之和，因此这两种结构分别对于最大值和最小值是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    # maximum: one large group, rest singletons
    k = n - (m - 1)
    kmax = k * (k - 1) // 2

    # minimum: balanced partition
    q, r = divmod(n, m)
    kmin = r * (q + 1) * q // 2 + (m - r) * q * (q - 1) // 2

    print(kmin, kmax)

if __name__ == "__main__":
    solve()
```最大计算直接隐式构建单个大组。 减法$n - (m-1)$准确地确保$m-1$单例仍然存在，在配对计数方面是中性的。 

对于最小值，除商和余数可确保组大小最多相差 1。 该公式将配对计数表达式应用于每个组大小并对它们求和，而无需显式构造组。 

主要的实现陷阱是整数除法处理。 使用`divmod`避免不一致并确保余数分布正确。 

## 工作示例

 ### 示例 1：$n = 5, m = 1$这里所有的人都必须在一个群体中。 

| 步骤| 问 | r | 团体人数 | 最小计算 | 最大计算|
 | --- | --- | --- | --- | --- | --- |

 | 最大| - | - | [5]| - |$10$|
 | 最小 | 5 | 0 | [5]|$10$| - |

 对于最大值，我们计算$\frac{5 \cdot 4}{2} = 10$。 最小值是相同的，因为不存在替代分区。 

### 示例 2：$n = 5, m = 2$我们必须将 5 个人分成 2 组。 

| 步骤| 问 | r | 团体人数 | 最小计算 | 最大计算|
 | --- | --- | --- | --- | --- | --- |
 | 初始化| 2 | 1 | - | - | - |
 | 最小 | 2 | 1 | [3, 2] |$3 + 1 = 4$| - |
 | 最大| - | - | [4, 1] | - |$6$|

 对于最小值，一组尺寸为 3，提供 3 对，另一组尺寸为 2，提供 1 对。 最大配置为一组 4 号和一个单例，即 6 对。 

这些痕迹表明，平衡如何减少二次增长，而集中则放大二次增长。

 ## 边缘情况

 对于$m = n$，我们得到$q = 1, r = 0$。 最小公式变为全零组，因为每个组都有贡献$\frac{1 \cdot 0}{2} = 0$，最大值变为$n - (n-1) = 1$，也给出零对。 

为了$m = 1$，我们有$k = n$在最大情况下，产生完整的$\frac{n(n-1)}{2}$。 最小公式崩溃为相同的单组计算，因为$q = n, r = 0$。 

对于大型$n$，这两个公式都是安全的，因为它们只使用整数乘法$10^9$，它很适合 Python 中的 64 位整数范围。
