 ## 解决方案
 ## 问题理解

 我们得到了一个系统的最终状态，该系统有五个参与者，他们在非常严格的规则下开始游戏：每个人都以相同的未知正数硬币开始，称之为$b$。 初始化后，硬币仅在玩家之间移动。 在此过程中不会创建或销毁任何硬币； 每项操作只是将一枚硬币从一个人转移到另一个人。 

最后，我们观察五个玩家每人有多少硬币。 从这个最终的分布中，我们需要确定是否有可能所有玩家最初拥有相同的正数硬币，如果是，则恢复该初始值$b$。 如果无法根据这些规则解释最终状态，我们必须报告这是不可能的。 

关键的结构性限制是硬币总量的保护。 由于转账不会改变币的总数，因此最终值的总和必须等于初始值的总和，即$5b$。 这立即意味着最终数组的总和必须能被 5 整除，商将是以下的候选值$b$。 

约束非常小：每个最终计数最多为 100，并且只有 5 个值。 这消除了对复杂数据结构或优化的任何需要。 直接计算就足够了。 

主要的微妙之处在于区分有效的再分配和无效的再分配。 例如，像这样的状态$1, 1, 1, 1, 1$有效于$b = 1$。 像这样的状态$2, 2, 2, 2, 2$有效于$b = 2$。 但像这样的状态$1, 1, 1, 1, 2$总和为 6，不能被 5 整除，因此无论转移如何，都不能来自相同的起始值。 

一种更具误导性的情况是总和可以被 5 整除，但消极推理可能表明不可能。 例如，$0, 0, 0, 0, 5$总和为 5，所以$b = 1$。 这是有效的：一名玩家最终可以捐赠所有硬币。 任何试图在不使用总体保护的情况下推理个体可行性的方法都有可能使本质上单一的算术条件变得过于复杂。 

## 方法

 一个蛮力的想法是尝试所有可能的初始值$b$从 1 到 100 并模拟我们是否可以从五个相等的堆的初始状态重新分配硬币以达到目标配置。 虽然这在概念上很简单，但它隐藏了一个困难的子问题：确定任意传输下的可达性。 由于硬币可以在任意两个玩家之间自由移动，因此状态空间很大，但我们不受图结构或移动限制的约束。 因此，模拟需要重建传输序列，这是不必要的。 

关键的简化是认识到转账准确地保留了总金额。 这将问题从动态可达性问题转化为静态算术条件。 当且仅当其总和等于时，最终配置才有效$5b$， 在哪里$b$必须是正整数。 

因此，整个问题简化为计算总和并检查整除性。

 ## 算法演练

 1. 读取代表每个玩家最终硬币数量的五个整数。 
2. 计算它们的总和。 这个总和代表系统中的硬币总数，在整个游戏过程中永远不会改变。 
3. 检查总和是否能被 5 整除。如果不能，则不可能进行均等初始分配，因为$5b$必须等于总数。 
4. 如果可整除，计算$b = \frac{\text{sum}}{5}$。 
5. 确保$b > 0$。 如果总和为零，则所有玩家最终都会获得零枚硬币，这与初始赌注严格为正数的要求相矛盾。 
6. 输出$b$如果有效，否则输出-1。 

### 为什么它有效

 不变量是总硬币守恒。 游戏中的每一次操作都是玩家之间的单位转移，保留所有硬币的总和。 因此，最终总和必须等于初始总和。 由于初始配置是五个相同的值$b$，总数必须是$5b$。 这唯一地决定了$b$每当存在解决方案时，任何违反可分性或积极性规则的行为都会立即证明是不可能的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    c = list(map(int, input().split()))
    total = sum(c)

    if total % 5 != 0:
        print(-1)
        return

    b = total // 5

    if b <= 0:
        print(-1)
        return

    print(b)

if __name__ == "__main__":
    solve()
```实现直接遵循基于不变式的推理。 唯一的计算是五个值的总和。 可除性检查确保与等初始分布模型的一致性。 正性检查是必要的，因为该问题明确需要正的初始赌注，而不是零。 

一个常见的错误是跳过积极条件。 没有它，像这样的输入`0 0 0 0 0`会错误地产生$b = 0$，尽管规则禁止初始投注为零。

 ## 边缘情况

 一个微妙的边缘情况是所有玩家都以零硬币结束。 总和为零，可以被 5 整除，但这意味着$b = 0$。 由于该问题需要严格的正初始赌注，因此必须拒绝。 该算法通过显式检查来处理这个问题$b > 0$，确保零不会作为有效解通过。 

另一种情况是高度倾斜的分布，例如`0 0 0 0 5`。 这里总和是 5，给出$b = 1$。 该不变量保证了有效性，因为随着时间的推移，五个初始硬币都可以转移给单个玩家，因此算法正确地接受它。 

最后，任何总和不能被 5 整除的输入都会被立即拒绝，这涵盖了大部分无效状态，无需进一步推理。
