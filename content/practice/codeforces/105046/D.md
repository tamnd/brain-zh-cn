 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 每个测试用例描述一个具有 n 行和 m 列的矩形网格，以及 n·m 整数的多重集。 我们的任务是将所有这些整数放入网格中，每个单元一个，以便共享一条边的任何两个单元始终包含不同奇偶校验的数字。 换句话说，每个水平和垂直邻接都必须连接偶数和奇数。 

输出不仅仅是有效性检查，而且是网格排列的显式构造。 对于每个测试用例，我们必须使用所有提供的值打印一次完整的 n × m 矩阵，或者如果不存在排列则打印 -1。 

所有测试用例的约束 n·m 高达 100000 意味着我们每个测试用例基本上需要线性时间。 任何在对上重复尝试排列或检查邻接条件的解决方案都会太慢。 我们被迫采用仅依赖奇偶校验计数和简单排序的结构。 

需求中已经出现了一个关键的观察结果：邻接迫使网格具有严格的二分结构。 这立即将问题与像棋盘一样的网格着色联系起来。 

当我们忽略奇偶校验的可行性时，就会出现微妙的失败情况。 考虑一个 2 x 2 网格，其值为 1, 1, 1, 2。有 3 个奇数和 1 个偶数。 任何有效的排列都必须像棋盘一样交替奇偶校验，在 2 x 2 网格中，恰好有两个奇数和两个偶数单元。 该实例无法运行，因此答案必须为-1。 只尝试贪婪放置而不检查计数的幼稚方法会错误地输出某些内容。 

另一种边缘情况是单行或单列。 在 1 × m 的网格中，邻接是线性的，因此我们仍然需要严格的奇偶校验交替。 这迫使奇数和偶数沿序列交替变化，可行性取决于平衡线路上的奇偶校验计数。 

## 方法

 暴力方法会尝试将值一一分配给单元格，并在每次放置后检查所有现有邻接是否满足奇偶校验约束。 这很快就变得不可行，因为在每一步我们都会对剩余未使用的值进行分支，导致可能性的阶乘增长。 即使进行剪枝，状态空间本质上也是 n·m 项的排列，这远远超出了 n·m 高达 100000 的可接受限制。 

关键的简化是认识到网格本身强加了固定的二分结构。 如果我们将单元格着色为 (i + j) mod 2，则所有邻接边都将位于相反的颜色之间。 “相邻数字具有不同奇偶性”的条件是指每个黑色单元格必须保存一种奇偶性的数字，而每个白色单元格必须保存另一种奇偶性的数字。 

这将问题从排列单个值减少到分配两组：偶数和奇数。 一旦我们知道哪个奇偶校验属于哪个颜色类，这些类中的任何分配都可以工作，因为着色会自动满足邻接关系。 

因此，问题变成了检查将计数与网格二分区大小匹配的可行性，然后以任何一致的顺序填充单元格。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 通过检查进行暴力放置 | O((纳米)!) | O(纳米) | 太慢了|
 | 通过棋盘着色进行奇偶划分 | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 我们继续使用网格的自然二分结构。

1. 计算有多少单元属于网格着色的每个奇偶校验类别。 对于网格，一种颜色具有 ⌈nm/2⌉ 个单元，另一种颜色具有 ⌊nm/2⌋ 个单元。 这决定了我们需要多少个奇偶校验值。 
2. 计算输入数组中有多少个奇数和偶数。 这是通过一次遍历所有值来完成的。 
3. 检查两种可能的颜色类别奇偶性分配的可行性。 奇数必须与黑色单元匹配，偶数必须与白色单元匹配，或者相反。 如果两者都不匹配，则答案是不可能的。 
4. 选择有效的作业。 这种选择是必要的，因为该问题并未确定哪个颜色类必须对应于奇数值。 
5. 构建两个列表：一个包含所有奇数值，另一个包含所有偶数值。 每个列表内的顺序无关紧要。 
6. 按行优先顺序遍历网格。 对于每个单元格，使用 (i + j) mod 2 确定其棋盘颜色，并从相应列表中分配下一个值。 
7. 输出填充后的网格。 

正确性依赖于邻接约束完全由二分着色捕获的事实，因此一旦一致地分配奇偶校验类，就不需要进一步验证。 

### 为什么它有效

 在标准棋盘着色下，网格图是二分的，这意味着每条边都连接相反的颜色。 该约束要求相邻值的奇偶性不同，因此每条边必须将奇数与偶数连接。 因此，一种颜色的所有单元格必须仅包含奇数值，而另一种颜色的所有单元格必须仅包含偶数值。 这既是必要的，也是充分的。 一旦奇偶校验计数与颜色类大小匹配，值和单元格之间的任何双射都会保留有效性，因为没有边连接相同颜色的两个单元格。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))

        odds = [x for x in a if x % 2]
        evens = [x for x in a if x % 2 == 0]

        total = n * m
        black = (total + 1) // 2
        white = total // 2

        # try odd on black
        ok1 = (len(odds) == black and len(evens) == white)
        # try odd on white
        ok2 = (len(odds) == white and len(evens) == black)

        if not ok1 and not ok2:
            print(-1)
            continue

        if ok1:
            odd_cells = True  # black cells
        else:
            odd_cells = False

        oi = 0
        ei = 0

        res = [[0] * m for _ in range(n)]

        for i in range(n):
            for j in range(m):
                if (i + j) % 2 == 0:
                    if odd_cells:
                        res[i][j] = odds[oi]
                        oi += 1
                    else:
                        res[i][j] = evens[ei]
                        ei += 1
                else:
                    if odd_cells:
                        res[i][j] = evens[ei]
                        ei += 1
                    else:
                        res[i][j] = odds[oi]
                        oi += 1

        for row in res:
            print(*row)

solve()
```该实现首先在线性时间内通过奇偶校验来分隔值。 然后，它检查奇偶性和棋盘颜色类之间仅有的两个可能的全局分配。 使用两个指向奇偶校验列表的指针，按行优先顺序填充网格。 

一个微妙的细节是使用整数除法正确计算黑白计数，因为总单元格可能是奇数。 另一个是确保在提交之前测试两种分配情况，因为任一映射都可能有效，具体取决于输入分布。 

## 工作示例

 考虑一个简单的有效案例：

 输入：

 n = 2，m = 3

 值 = [1, 2, 2, 3, 4, 1]

 我们有赔率 = [1, 3, 1]，偶数 = [2, 2, 4]。 单元格总数 = 6，因此黑色 = 3，白色 = 3。两个奇偶组完美匹配。

 | 2 | (0,1)| 白色| 甚至| 2 | 2 |
 | 3 | (0,2) | 黑色| 奇数| 1 | 2 |
 | 4 | (1,0)| 白色| 甚至| 1 | 1 |
 | 5 | (1,1) | 黑色| 奇数| 0 | 1 |
 | 6 | (1,2) | 白色| 甚至| 0 | 0 |

 这会产生一个完整的有效网格，因为每个邻接都跨越奇偶校验边界。 

现在考虑一个不可能的情况：

 输入：

 n = 2，m = 2

 值 = [1, 1, 1, 2]

 odds = 3，evens = 1，但黑色和白色各有 2 个单元格。 

| 检查 | 价值|
 | --- | --- |
 | 需要黑色| 2 |

 ## 边缘情况

 1 x 米的网格强制沿着一条线严格交替。 例如，n = 1, m = 5，值为 [1, 2, 3, 4, 5]，因为奇数和偶数计数可以匹配交替位置。 该算法将其视为标准棋盘着色，位置 j 处有黑色单元格，其中 j 是偶数，因此分配过程相同。 

3 x 3 网格上的全奇数输入会立即失败。 有 5 个黑色单元格和 4 个白色单元格，因此我们需要同时存在两个奇偶校验。 该算法通过奇数和偶数计数与任一分区的不匹配来检测这一点，并返回 -1，而不尝试放置。 

仅当奇偶分配与更大的类别匹配时，才接受接近平衡但不匹配的情况，例如 3 x 3，有四个偶数和五个奇数。 该算法显式地测试两个方向，即使多数奇偶校验不是很明显，也能确保正确性。
