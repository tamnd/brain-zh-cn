 ## 解决方案
 ## 问题理解

 我们被赋予了漫长的一天`m`分钟和一组不重叠的任务，每个任务占用一个连续的时间间隔。 亚历克斯想要洗澡`s`分钟，我们需要判断是否存在至少一个连续的时间块`s`不与任何计划任务相交。 输入由多个测试用例组成，每个测试用例都有自己的任务和参数列表`n`,`s`， 和`m`。 如果存在这样的块，则输出为简单的“YES”，否则输出为“NO”。 

约束允许最多`2 * 10^5`跨所有测试用例的任务，每天最多可达`10^9`分钟长。 因此，任何在一天中每一分钟迭代的解决方案都会太慢。 我们需要一种在每个测试用例的任务数量上线性工作的方法。 

需要考虑的一个边缘情况是，在第一个任务之前的第一天或最后一个任务之后的最后一天存在空闲块。 例如，如果`s = 3`,`m = 10`，唯一的任务是`(5, 7)`, 区间`(0, 5)`足够长，可以洗澡，也是`(7, 10)`。 仅检查连续任务之间的间隙的粗心实现可能会错过这些开始和结束间隔。 另一个微妙的情况是当`s`正好等于间隙长度； 这里经常出现相差一的错误，因此不等式必须是`>= s`。 

## 方法

 暴力方法会考虑一天中的每一分钟，并检查是否有长度的块`s`是免费的。 每开始一分钟`t`，我们将验证是否`[t, t+s)`与任何任务间隔重叠。 这在逻辑上是正确的，但可能需要最多`10^9`在最坏的情况下进行检查，这远远超出了可行的限度。 

关键的观察结果是任务不重叠并按开始时间排序。 因此，只需检查连续任务之间的间隙以及第一个任务之前一天的开始和最后一个任务之后一天的结束就足够了。 每个间隙由一项任务的结束和下一项任务的开始来定义。 如果任何间隙至少为`s`几分钟后，亚历克斯就可以洗澡了。 这将问题简化为线性扫描`n`间隔，使得复杂度`O(n)`每个测试用例。 这种方法简单、快速，并且可以自然地处理所有边缘情况。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(m * n) | O(n) | 太慢了 |
 | 最佳 | O(n) | 每个测试用例 O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，请阅读`n`,`s`， 和`m`。 
2. 阅读全部`n`任务并将它们成对存储`(l_i, r_i)`。 
3. 检查第一个任务之前的间隔。 如果第一个任务开始于`l_1`， 和`l_1 >= s`，输出“是”。 
4. 迭代连续的任务。 对于任务`i`和`i+1`，计算间隙`l_{i+1} - r_i`。 如果这个间隙是`>= s`，输出“是”。 
5. 检查上次任务之后的时间间隔。 如果最后一个任务结束于`r_n`， 和`m - r_n >= s`，输出“是”。 
6. 如果这些检查均未成功，则输出“NO”。 

为什么它有效：任务是不重叠的并且是排序的。 所有可能的淋浴位置要么在第一个任务之前，要么在两个任务之间，要么在最后一个任务之后。 通过检查每个间隔的长度`>= s`，我们涵盖了所有可能性，不遗漏任何有效窗口。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_shower(n, s, m, tasks):
    if tasks[0][0] >= s:
        return True
    for i in range(n - 1):
        if tasks[i+1][0] - tasks[i][1] >= s:
            return True
    if m - tasks[-1][1] >= s:
        return True
    return False

t = int(input())
for _ in range(t):
    n, s, m = map(int, input().split())
    tasks = [tuple(map(int, input().split())) for _ in range(n)]
    print("YES" if can_shower(n, s, m, tasks) else "NO")
```功能`can_shower`处理核心逻辑。 我们首先检查一天开始的差距，然后检查任务之间的差距，最后检查一天结束的差距。 此顺序确保我们在第一个可能的时间间隔返回“YES”，避免不必要的计算。 使用元组和直接算术使解决方案简单高效。 我们通过仔细使用来避免相差一的错误`>= s`。

 ## 边缘情况

 如果第一个任务恰好开始于`s`，算法将立即返回“YES”，因为间隔`[0, l_1)`有长度`l_1 >= s`。 如果唯一的差距发生在最后一个任务之后，则最终检查`m - r_n >= s`捕获它。 由于输入保证，不会出现负或零长度间隙`l_i > r_{i-1}`，但我们仍然使用`>= s`以避免差一错误。 即使在边界处，这也保证了正确性。
