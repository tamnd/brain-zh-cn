 ## 解决方案
 ## 问题理解

 我们得到一个二进制数组，仅包含`0`和`1`。 对于每个长度的子序列`k`， 在哪里`k`是奇数，我们计算它的中位数并将所有这些中位数加在一起。 

该数组是二进制的，这完全改变了中位数的性质。 奇数长度二进制序列的中位数只能是`0`或者`1`。 对这样的序列进行排序后，中位数为`1`恰好当它的一半以上的元素是`1`。 

让

-`z`是原始数组中零的数量。 
-`o`是原始数组中的个数。 

任务是计算有多少长度-`k`子序列有中位数`1`，因为每个这样的子序列都准确贡献`1`求和，而每个具有中位数的子序列`0`贡献`0`。 

制约因素很大。 总和为`n`所有测试用例最多是`2·10^5`。 枚举所有子序列是不可能的，因为即使`C(200000,100000)`是一个天文数字。 任何涉及显式生成子序列的解决方案都将立即被排除。 

该限制提出了一个解决方案`O(n)`或者`O(n log MOD)`经过一些全局预处理后的每个测试用例。 由于模数是素数并且组合自然出现，因此预先计算阶乘和逆阶乘是一个强烈的暗示。 

一些边缘情况值得关注。 

考虑：```
n = 5, k = 1
array = [1,1,1,1,1]
```每个元素本身都是一个子序列。 答案是`5`。 任何假设从子序列中选择至少两个元素的公式在这里都会失败。 

考虑：```
n = 5, k = 5
array = [0,1,0,1,0]
```只有一个子序列，即整个数组。 它包含两个 1 和三个 0，所以它的中位数是`0`。 答案是`0`。 粗心的实现可能会计算所有方法来选择大多数方法，而不考虑可用的方法数量。 

考虑：```
n = 4, k = 3
array = [1,0,1,1]
```每个长度为 3 的子序列至少有两个，因此每个中位数都等于`1`。 答案是`4`。 本例检查多数阈值是否正确计算为`(k+1)/2`。 

## 方法

 最直接的方法是生成每个长度-`k`子序列，对其进行排序，计算其中值，然后累加结果。 

这是正确的，因为它完全遵循定义。 不幸的是，子序列的数量是$$\binom{n}{k}$$这对于中等值来说已经是巨大的了`n`。 即使是为了`n = 50`和`k = 25`，计数超过$10^{14}$。 蛮力方法是完全行不通的。 

关键的观察是零和一的位置并不重要。 只有选择多少个 0 和 1 才重要。 

由于数组是二进制的，因此长度的中位数`k`子序列是`1`当且仅当子序列至少包含$$\frac{k+1}{2}$$那些。 

让$$m=\frac{k+1}{2}.$$假设一个子序列恰好包含`i`那些。 然后它包含`k-i`零。 这样的子序列存在于$$\binom{o}{i}\binom{z}{k-i}$$方式，因为我们独立选择哪些 1 和哪些 0 参与。 

每个子序列与`i ≥ m`贡献`1`到答案。 每个子序列与`i < m`贡献`0`。 

所以答案就变成了$$\sum_{i=m}^{k} \binom{o}{i} \binom{z}{k-i}.$$现在问题简化为评估组合和。 

自从`n`所有测试用例最多`2·10^5`，我们可以预先计算阶乘和逆阶乘一次，并回答每个组合查询`O(1)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O\left(\binom{n}{k}\cdot k\log k\right)$|$O(k)$| 太慢了 |
 | 最佳 |$O(n + k)$预处理后的每个测试用例|$O(n)$| 已接受 |

 ## 算法演练

 1. 数一下有多少个`o`在数组中。 
2. 计算零的数量：`z = n - o`。 
3.让$$m=\frac{k+1}{2}.$$任意子序列至少有`m`有中位数`1`。 
4. 预计算阶乘和逆阶乘模`10^9+7`最多`2·10^5`。 

这允许在恒定时间内评估每个组合值。 
5. 迭代`i`从`m`到`k`。 
6. 对于每个`i`，将其解释为选择的数量。 
7. 恰好符合的有效子序列的数量`i`个等于$$\binom{o}{i}\binom{z}{k-i}.$$如果任一组合都不可能，则将其视为零。 
8. 将此数量添加到答案模中`10^9+7`。 
9. 输出最终的和。 

### 为什么它有效

 二进制子序列有中位数`1`恰好当严格超过一半的元素是`1`。 自从`k`是奇数，这个条件相当于至少有`(k+1)/2`那些。 

每个有效子序列都可以通过确切的数字进行唯一分类`i`它包含的那些。 对于固定的`i`，选择子序列相当于选择`i`元素来自于`o`可用的和`k-i`元素来自于`z`可用零。 这正好给出了$$\binom{o}{i}\binom{z}{k-i}$$子序列。 

不同值的类别`i`不相交并覆盖中位数为的所有子序列`1`。 总结一切`i ≥ (k+1)/2`将每个贡献子序列精确计数一次，这正是所需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXN = 200000

fact = [1] * (MAXN + 1)
for i in range(1, MAXN + 1):
    fact[i] = fact[i - 1] * i % MOD

inv_fact = [1] * (MAXN + 1)
inv_fact[MAXN] = pow(fact[MAXN], MOD - 2, MOD)

for i in range(MAXN, 0, -1):
    inv_fact[i - 1] = inv_fact[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    ones = sum(a)
    zeros = n - ones

    need = (k + 1) // 2

    ans = 0

    for i in range(need, k + 1):
        ans = (ans + C(ones, i) * C(zeros, k - i)) % MOD

    print(ans)
```预处理计算一次阶乘和逆阶乘。 由于模数是素数，费马小定理给出$$x^{-1}=x^{MOD-2}\pmod{MOD}.$$辅助函数`C(n,r)`当组合不可能时返回零。 这一点至关重要，因为诸如`C(3,5)`不得对总和做出任何贡献。 

对于每个测试用例，只有零和一的计数很重要。 元素的实际排列从未出现在公式中。 

循环结束`i`开始于`(k+1)//2`因为这是可以使中位数等于的最小数量`1`。

 ## 边缘情况

 考虑：```
1
5 1
1 1 1 1 1
```这里`need = 1`。 求和仅包含`i = 1`：$$\binom{5}{1}\binom{0}{0}=5.$$算法返回`5`，匹配每个元素形成有效子序列的事实。 

考虑：```
1
5 5
0 1 0 1 0
```我们有`ones = 2`,`zeros = 3`， 和`need = 3`。 

每个术语都要求至少选择三个，这是不可能的：$$\binom{2}{3}=0.$$所有贡献消失，产生答案`0`。 该算法自然地通过组合函数来处理这个问题。 

考虑：```
1
4 3
1 0 1 1
```我们有`ones = 3`,`zeros = 1`， 和`need = 2`。 

计算公式为$$\binom{3}{2}\binom{1}{1} + \binom{3}{3}\binom{1}{0} = 3+1 = 4.$$所有四个长度为 3 的子序列都有贡献，所以答案是`4`。 这证实了多数阈值已正确实现，并且每个有效组合都被精确计数一次。
