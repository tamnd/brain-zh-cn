 ## 解决方案
 ## 问题理解

 我们得到一排图块，每个图块都有一种颜色和一个整数$k$。 一条路径是通过跳到右边的方块而形成的，如果一条路径的长度能被$k$并且颜色在连续的大小块中是恒定的$k$。 任务是计算最大可能长度的好路径的数量，模$10^9 + 7$。 

输入由多个测试用例组成。 对于每个测试用例，我们都会得到图块的数量$n$，块大小$k$，以及颜色的顺序。 我们需要针对每种情况计算最长的好路径的数量。 

约束条件告诉我们$n \le 100$和$k \le n$，以及总和$n^3$所有测试用例都是有界的。 这意味着一个$O(n^3)$每个测试用例的解决方案都是可行的。 生成所有可能路径的简单解决方案将是指数级的并且显然不可行。 小的$n$表明动态规划或组合计数将很适合。 

边缘情况包括所有图块颜色相同的情况，其中$k = 1$，其中没有两个连续的图块具有相同的颜色，并且其中$k$等于$n$。 例如，如果$n = 3$和$k = 2$有颜色`[1, 2, 3]`，最大良好路径长度为$k = 2$，但只存在单个块，产生的路径很少。 粗心的实现可能无法识别长度路径$k$作为有效的最大长度路径。 

## 方法

 暴力方法会尝试枚举所有图块序列，检查每个序列是否可以整除$k$，并验证每个块具有相同的颜色。 此类序列的数量呈指数增长$n$，即使对于$n = 100$。 

关键的见解是路径的长度$m$可以由每个块的起始瓦片的索引来表示。 最大好的路径长度由最长的子序列决定，其中图块可以分组为大小的块$k$具有相同的颜色。 这将问题简化为组合动态规划问题：对于每个图块$i$，我们计算结束于的最大块数$i$并数一下这种情况有多少种可能发生。 

具体来说，我们可以定义`dp[i]`作为以图块结束的良好路径中的最大块数`i`， 和`cnt[i]`作为结束于该长度的路径数`i`。 我们迭代所有以前的图块`j < i`并检查是否有一个大小的块`k`可以延伸自`j`到`i`。 如果是这样，我们更新`dp[i]`和`cnt[i]`因此。 这种方法是可行的，因为$n \le 100$，导致$O(n^3)$每个测试用例的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 动态规划| O(n^3) | O(n^3) | O(n) | 已接受 |

 ## 算法演练

 1.初始化两个数组，`dp`和`cnt`，每个长度$n$， 和`dp[i] = 0`和`cnt[i] = 1`。`dp[i]`将存储以tile结尾的块的最大数量`i`， 和`cnt[i]`将存储实现该目标的方法数量。 
2. 迭代所有图块`i`从左到右。 对于每个图块，迭代所有先前的图块`j`检查长度是否为一个块`k`可以从以下位置开始形成相同颜色的`j+1`并结束于`i`。 要检查这一点，请验证块中的所有颜色是否相同。 
3. 如果存在有效区块`j+1`到`i`，检查是否扩展结束于的路径`j`产生的区块多于`dp[i]`。 如果是这样，请更新`dp[i] = dp[j] + 1`并设置`cnt[i] = cnt[j]`。 如果产生相同数量的块，则增加`cnt[i] += cnt[j]`。 
4. 灌装后`dp`和`cnt`，找出其中的最大值`dp`。 总和`cnt[i]`为所有人`i`在哪里`dp[i]`等于最大值是最大长度的好路径的数量。 
5. 返回该计数模数$10^9 + 7$。 

为什么它有效：`dp[i]`存储任何结束于的路径的最佳块数`i`。 通过考虑所有先前的扩展块，我们确保所有可能的路径都被计算在内。 计数`cnt[i]`确保达到相同最大块数的多种方式正确累加。 模运算可防止整数溢出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

for _ in range(int(input())):
    n, k = map(int, input().split())
    c = list(map(int, input().split()))
    
    dp = [0] * n
    cnt = [1] * n
    
    for i in range(n):
        for j in range(i):
            # Check if a block of length k ending at i can extend path ending at j
            if i - j >= k:
                block_color = c[i]
                valid = True
                for x in range(i - k + 1, i + 1):
                    if c[x] != block_color:
                        valid = False
                        break
                if valid:
                    if dp[j] + 1 > dp[i]:
                        dp[i] = dp[j] + 1
                        cnt[i] = cnt[j]
                    elif dp[j] + 1 == dp[i]:
                        cnt[i] = (cnt[i] + cnt[j]) % MOD
        # Check if the first block can start at the beginning
        if i + 1 >= k:
            block_color = c[i]
            valid = True
            for x in range(i - k + 1, i + 1):
                if c[x] != block_color:
                    valid = False
                    break
            if valid:
                dp[i] = max(dp[i], 1)
                # cnt[i] remains at least 1
    
    max_blocks = max(dp)
    ans = sum(cnt[i] for i in range(n) if dp[i] == max_blocks) % MOD
    print(ans)
```在代码中，`dp[i]`存储以tile结尾的块的最大数量`i`。 内循环检查大小是否有效的块`k`可以形成结束于`i`通过检查最后一个`k`瓷砖。 初始化确保对从头开始的单个块进行计数。 模运算可防止累加期间溢出。 

## 工作示例

 ### 示例 1

 输入：`5 2`和颜色`[1, 2, 3, 4, 5]`。 

所有瓷砖都不同。 长度为 2 的连续块没有相同的颜色。`dp`停留在`[0, 0, 0, 0, 0]`。 最大块数为 0，仅计算 1 个空路径。 输出是`1`。 

### 示例 2

 输入：`7 2`和颜色`[1, 3, 1, 3, 3, 1, 3]`。 

长度为 4 的好路径对应于 2 个大小为 2 的块：`[1,3,4,5]`,`[2,4,5,7]`,`[1,3,5,7]`,`[1,3,4,7]`。`dp`在多个位置以最大块 2 结束，并且`cnt`累积到`4`。 输出是`4`。

 这证实了算法正确地跟踪块计数和路径组合。
