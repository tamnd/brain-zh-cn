 ## 解决方案
 ## 问题理解

 我们有一排瓷砖，每块瓷砖都涂上了一种颜色。 Vlad 想要沿着这一行创建路径，以便该路径可以分为连续的长度块`k`，并且每个块都由相同的颜色组成。 我们被要求找到所有最大可能长度的“好路径”。 

每个测试用例给出了图块的数量`n`，块大小`k`，以及颜色数组。 输出是最大长度好的路径的数量模`10^9 + 7`。 

约束意味着`n`最多可以达到 5000，并且总和`n^2`所有测试用例的总和是`≤ 25·10^6`。 这告诉我们一个在图块上有嵌套循环的算法（`O(n^2)`）是可行的，但更糟糕的是，比如`O(n^3)`，将超过时间限制。 

当最大长度路径较短时，会出现不明显的边缘情况。 例如，如果`n=5`和`k=2`有颜色`[1,2,3,4,5]`，没有长度为 2 的块具有相同的颜色，因此唯一的最大良好路径实际上长度为 0，并且输出应该是`1`。 另一个棘手的情况是所有瓷砖都具有相同的颜色。 然后可以形成多条路径，我们需要仔细计算图块选择的组合。 

## 方法

 暴力方法很简单：尝试在每个图块处开始一条路径，然后递归或迭代地尝试可以根据块约束继续该路径的每个下一个图块。 检查所有可能的路径长度并保留最长的。 这是正确的，但很快就变得不可行：如果`n`是 5000，我们会大致执行`n^2`每个测试用例的操作仅针对起始位置，并且考虑所有跳跃进一步增加了成本，使得`O(n^3)`在最坏的情况下，这太慢了。 

优化的关键见解是，我们只需要考虑从一个块跳转到颜色匹配的下一个块的路径。 我们可以为每个起始索引预先计算长度连续块的最大数量`k`具有相同颜色。 然后，我们可以使用动态规划来计算在每个位置结束的路径：有效块中的每个位置都可以继承之前相同颜色块的计数。 由于路径是可加的并且块是连续的，因此问题简化为对块上的递增子序列进行计数的变体。 

从朴素的 O(n^3) 方法到动态编程 O(n^2) 解决方案的减少是由以下观察驱动的：好的路径完全由其在每个块中的起始索引决定。 一旦我们知道了块边界和颜色，计数路径就变得组合起来，而不是对所有跳转进行递归。

 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 太慢了 |
 | 最优（DP 块）| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`,`k`，和数组`c`颜色。 
2. 预计算`cnt[i]`对于每个位置`i`。`cnt[i]`是长度连续块的最大数量`k`开始于`i`其中每个块具有相同的颜色。 我们检查每个倍数`k`提前查看块是否均匀。 这使我们能够知道从索引开始的良好路径的最大长度`i`。 
3. 初始化动态编程数组`dp[i]`表示以位置结束的最大长度的好路径的数量`i`。 
4. 反向迭代每个块的起始位置。 对于每个`i`，通过查看未来的位置来计算延长路径的方式总数`j`在哪里`c[j]`匹配下一个块的颜色。 更新`dp[i]`通过求和`dp[j]`值取模`10^9 + 7`。 
5. 填充时跟踪总体最大路径长度`dp`。 仅计算达到此最大长度的路径。 
6. 总和`dp[i]`可以达到最大长度的起始位置以获得测试用例的最终答案。 

**为什么有效：** 每个`dp[i]`累积开始于的所有好路径的计数`i`并仅使用长度相同颜色的块`k`。 不变的是，在每一步中，DP 仅扩展块颜色条件成立的路径。 通过反向迭代，我们确保未来较长路径的计数正确传播到较早的位置，从而保证包含所有最大长度路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        c = list(map(int, input().split()))
        dp = [0] * n
        max_len = 0

        # Compute maximum number of blocks starting at i
        blocks = [0] * n
        i = 0
        while i <= n - k:
            same = True
            for j in range(1, k):
                if c[i+j] != c[i]:
                    same = False
                    break
            if same:
                blocks[i] = 1
            i += 1

        # DP over blocks
        for i in reversed(range(n)):
            if blocks[i]:
                dp[i] = 1
                next_pos = i + k
                while next_pos < n:
                    if c[next_pos] == c[i] and blocks[next_pos]:
                        dp[i] += dp[next_pos]
                        dp[i] %= MOD
                    next_pos += k
                max_len = max(max_len, dp[i])

        # Count paths achieving max length
        ans = 0
        for i in range(n):
            if dp[i] == max_len:
                ans += 1
                ans %= MOD
        print(ans)

if __name__ == "__main__":
    solve()
```**说明：** 我们首先标记有效的长度块`k`所有颜色都相同。 然后，对于每个这样的块，我们期待的步骤为`k`延长路径，同时保持颜色平等。 我们将每个块结束的路径数存储在`dp`。 最后，我们计算有多少块开始了最大长度的路径。 微妙之处包括正确处理索引（`i + k`）和模运算以避免溢出。
