 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$矩阵，其中$n$总是均匀的。 该矩阵被构建为同心层，每层形成一个顺时针移动的循环。 您从给定的单元格开始$(x_1, y_1)$想要到达另一个牢房$(x_2, y_2)$。 沿着传送带的移动是自动发生的并且不消耗能量。 在任何时候，您都可以花费 1 个能量单位移动到相邻的单元格，并且您可以立即执行此操作任意次数。 目标是找到到达目的地所需的最小能量。 

关键输入特征是矩阵大小$n$以及起始和结束坐标。 输出是一个整数：从起点到目的地的最小能源成本。 

约束很严格：$n$可以达到$10^9$并且最多可以有$2 \cdot 10^5$测试用例。 沿着矩阵移动的简单模拟是立即不可行的。 即使只是迭代一层中的所有单元格也需要$O(n^2)$每个测试用例，这太慢了。 这表明我们需要一种纯粹的数学或基于公式的方法。 

不明显的边缘情况包括起始单元和结束单元位于同一周期上的情况。 在这种情况下，如果传送带自然地将您传送到目的地，则可能不需要能量。 另一种边缘情况是，起点位于内层，目的地位于外层（反之亦然），其中最小能量涉及跨层移动而不是沿着传送带移动。 

## 方法

 蛮力方法是显式模拟每一层的循环并尝试所有动作。 您可以将每个单元格映射到其沿传送带的位置，然后计算沿循环的距离。 对于小$n$，这有效，但是对于$n = 10^9$这是不可能的。 计算完整周期长度或生成所有单元坐标将超出内存和时间限制。 

关键的见解是，能源成本只是层数的差异加上沿传送带的任何错位。 每层都是一个方形边框。 您可以通过计算单元到任意边缘的最小距离来确定单元的层。 一旦知道起始层和结束层的层数，最小的能量就是层间的差异，因为沿着传送带移动不需要任何成本，而直接在层之间移动每一步只需要消耗一个能量。 沿同一层的任何移动都可以忽略，因为传送带会自动向一个方向移动您。 

最优解将层数计算为$\text{layer} = \min(x-1, y-1, n-x, n-y)$。 那么到达目的地的能量为$|\text{layer}_1 - \text{layer}_2|$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 太慢了 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n, x_1, y_1, x_2, y_2$。 
2. 计算起始单元的层数为$\text{layer}_1 = \min(x_1 - 1, y_1 - 1, n - x_1, n - y_1)$。 这测量距最近边缘的距离。 
3. 将目标单元的层计算为$\text{layer}_2 = \min(x_2 - 1, y_2 - 1, n - x_2, n - y_2)$。 
4. 所需的最小能量为$|\text{layer}_1 - \text{layer}_2|$。 这会计算您必须穿越多少层，每层消耗一个能量单位。 
5. 输出能源成本。 

这样做的原因是，沿着一层移动不会消耗能量，因为皮带会带着你。 唯一的能量成本来自于层之间的移动，并且移动到相邻层中的任何单元仅花费一个单位。 此属性适用于任何大小$n$和任何偶数$n \ge 2$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x1, y1, x2, y2 = map(int, input().split())
    layer1 = min(x1 - 1, y1 - 1, n - x1, n - y1)
    layer2 = min(x2 - 1, y2 - 1, n - x2, n - y2)
    print(abs(layer1 - layer2))
```该代码通过测量到任何边缘的最小距离来计算每个单元的层。 减去 1 会调整基于 1 的索引。 层之间的绝对差给出最小的能量。 该解决方案避免了循环或内存繁重的结构，处理大型$n$高效。

 ## 边缘情况

 如果起点和终点在同一层，则能量为 0。例如，在$2 \times 2$矩阵起始于$(1,1)$并结束于$(2,2)$，两者都在最外层，因此算法正确计算$|0-0|=0$。 

对于像这样的大矩阵$10^9 \times 10^9$，层计算处理从 1 开始的索引而不会溢出。 公式`min(x-1, y-1, n-x, n-y)`正确缩放到最大约束并直接计算层差异，即使对于极端坐标也保证最小的能量计算。
