[CF 316G2 - 良好的子串](https://codeforces.com/problemset/problem/316/G2)

 **评分：** 2200
 **标签：** 字符串后缀结构
 **求解时间：** 3m 7s
 **已验证：** 否

 ## 解决方案
 ## 问题理解

 我们得到一个源字符串`s`。 我们只对出现在里面的子字符串感兴趣`s`，并且我们对每个不同的子字符串计数一次，无论它出现了多少次。 

如果一个子串满足每条规则，则该子串被认为是好的。 每个规则由一个模式字符串组成`p`和一个范围`[l, r]`。 对于候选子串`t`，我们数数多少次`t`发生在内部`p`作为子串。 当出现次数介于`l`和`r`。 

任务是计算有多少个不同的子串`s`同时满足所有规则。 

首先让这个问题变得困难的是输入大小。 长度为`s`每个规则字符串可能达到50000。长度为50000的字符串如果按位置计算，大约有12.5亿个子串，候选对的数量级大致相同`(start,end)`。 任何显式枚举子字符串的方法都是没有希望的。 

规则数量很少，最多10条。这种不对称是关键。 我们有很长的字符串，但限制很少。 

一个微妙的点是，出现次数是按重数来计算的。 如果子字符串出现在规则字符串内的多个位置，则所有这些位置都会起作用。 

例如：```
s = "aaa"
rule: ("aaa", 2, 2)
```子串`"a"`中出现 3 次`"aaa"`，一次也没有。 仅检查存在性的解决方案会错误地接受它。 

另一个简单的错误是忘记我们计算不同的子串`s`。```
s = "aaaa"
n = 0
```答案是`4`，对应于`"a"`,`"aa"`,`"aaa"`,`"aaaa"`。 

按位置计算出现次数将错误地返回`10`。 

第三个陷阱来自下限为零的规则。```
s = "ab"
1
c 0 0
```的每个子串`s`很好，因为它们都没有出现在`"c"`。 任何仅处理规则字符串中出现的子字符串的实现都会错过有效答案。 

这些约束强烈暗示了后缀结构。 不同的子串自然地对应于后缀自动机的状态或后缀数组内的间隔。 我们需要一种方法来评估所有不同的子字符串，而不需要单独枚举它们。 

## 方法

 蛮力的想法很简单。 生成每个不同的子字符串`s`。 对于每个候选子串`t`，并且对于每个规则字符串`p_i`,数数有多少次`t`发生在内部`p_i`。 如果所有计数都在要求的范围内，则增加答案。 

这是正确的，因为它直接实现了定义。 不幸的是，它的速度极其缓慢。 有`Θ(|s|²)`不同的子串位置和潜在的`Θ(|s|²)`不同的子字符串值。 即使使用高效的字符串匹配，总工作量也远远超出长度 50000 所能完成的工作。 

重要的观察是每个候选子字符串都来自相同的源字符串`s`。 我们可以在后缀自动机中同时表示所有不同的子串，而不是逐个检查子串`s`。 

后缀自动机状态表示子串长度的整个区间。 每个子字符串恰好对应一对：```
(state v, length L)
where
len(link(v)) < L ≤ len(v)
```这种表示将所有不同的子字符串折叠成仅`O(|s|)`州。 

剩下的挑战是评估规则。 对于固定规则字符串`p`，假设我们遍历`p`通过自动机`s`。 每个位置的`p`确定出现在其中的最长后缀`s`。 标准后缀自动机计数技术允许我们为每个状态累积每个表示的子串在内部出现的次数`p`。 

由于最多有10条规则，我们可以独立处理每条规则。 对于每个状态，我们确定规则字符串中该状态表示的任何子字符串的出现次数。 这些计数得出满足规则的长度间隔。 将所有规则的间隔相交给出由该状态表示的良好子串长度集合。 

最后，我们将每个状态中剩余的长度数量相加。 

整个解决方案利用了两个事实：

 首先，后缀自动机压缩所有不同的子串`s`进入`O(|s|)`州。 

其次，规则字符串的数量很少，使得可以在自动机上单独处理每个规则。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O( | s | ² · n · max\|p\|) 或更差 |
 | 基于 SAM 的最佳解决方案 | O((n+1)· | s | + Σ\|p_i\| + n· |

 ## 算法演练

 ### 后缀自动机解释

 对于每个州`v`在后缀自动机中：```
mx = len(v)
mn = len(link(v)) + 1
```状态表示长度属于的所有不同子串`[mn, mx]`。 

每个不同的子串恰好对应于一种状态内的一个长度。 

### 处理一条规则

 对于规则字符串`p`：

 #### 1. 遍历`p`通过自动机

 对于每个位置`p`，保持当前自动机状态和最长匹配后缀长度。 

这是标准的 SAM 匹配程序。 

#### 2. 计算端点贡献

 每当遍历结束于状态`v`，增加该状态的计数器。 

这记录了一个后缀`p`结束于`v`。 

#### 3. 向上传播计数

 进程状态按降序排列`len`。 

将每个州的计数器添加到其后缀链接中。 

经过这次传播后，`cnt[v]`等于出现的次数`p`由状态表示的每个子串`v`。 

这是经典的后缀自动机出现次数计算。 

#### 4. 将计数转换为有效长度间隔

 假设规则要求：```
l ≤ occurrences ≤ r
```对于每个州：

 如果`cnt[v]`满足规则，则该状态表示的所有长度仍然是可能的。 

否则他们都不能满足这个规则。 

我们不存储布尔值，而是为每个状态维护一个在处理所有先前规则后仍然有效的长度区间。 

只要计数满足规则，就将当前有效间隔与状态的全长间隔相交，否则与空间隔相交。 

#### 5. 对所有规则重复

 每条规则都进一步限制了每个州允许的长度。 

在所有交集之后，剩余的长度完全对应于满足每个规则的子串。 

### 最终计数

 对于每个州：```
allowed = max(0, right[v] - left[v] + 1)
```将此数量添加到答案中。 

每个幸存长度恰好对应于一个不同的子字符串。 

### 为什么它有效

 后缀自动机划分所有不同的子串`s`分成不相交的状态长度对。 每个子串恰好属于一种状态以及该状态长度区间内的一个长度值。 

对于固定规则字符串，状态的传播出现计数等于该状态表示的任何子字符串在该规则字符串中出现的次数。 这是后缀自动机的基本属性：由状态表示的所有子串都具有相同的结束位置集，因此具有相同的出现次数。 

因为每个规则仅取决于该出现次数，所以要么整个状态间隔在规则中幸存，要么整个间隔被拒绝。 将所有规则的幸存长度范围相交，恰好留下满足每个约束的子串。 对剩余长度求和，将每个不同的好子串恰好计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SAM:
    def __init__(self):
        self.next = [{}]
        self.link = [-1]
        self.length = [0]

    def extend(self, ch):
        cur = len(self.next)
        self.next.append({})
        self.link.append(0)
        self.length.append(self.length[-1] + 1)

        p = self.last
        while p != -1 and ch not in self.next[p]:
            self.next[p][ch] = cur
            p = self.link[p]

        if p == -1:
            self.link[cur] = 0
        else:
            q = self.next[p][ch]
            if self.length[p] + 1 == self.length[q]:
                self.link[cur] = q
            else:
                clone = len(self.next)
                self.next.append(self.next[q].copy())
                self.link.append(self.link[q])
                self.length.append(self.length[p] + 1)

                while p != -1 and self.next[p].get(ch) == q:
                    self.next[p][ch] = clone
                    p = self.link[p]

                self.link[q] = clone
                self.link[cur] = clone

        self.last = cur

    def build(self, s):
        self.last = 0
        for c in s:
            self.extend(c)

def solve():
    s = input().strip()
    n = int(input())

    sam = SAM()
    sam.build(s)

    sz = len(sam.next)

    maxlen = max(sam.length)
    cnt_len = [0] * (maxlen + 1)

    for x in sam.length:
        cnt_len[x] += 1

    for i in range(1, maxlen + 1):
        cnt_len[i] += cnt_len[i - 1]

    order = [0] * sz
    for v in range(sz - 1, -1, -1):
        l = sam.length[v]
        cnt_len[l] -= 1
        order[cnt_len[l]] = v

    left = [sam.length[sam.link[v]] + 1 if v else 1
            for v in range(sz)]
    right = sam.length[:]

    for _ in range(n):
        p, L, R = input().split()
        L = int(L)
        R = int(R)

        occ = [0] * sz

        v = 0
        cur_len = 0

        for ch in p:
            while v and ch not in sam.next[v]:
                v = sam.link[v]
                cur_len = sam.length[v]

            if ch in sam.next[v]:
                v = sam.next[v][ch]
                cur_len += 1
            else:
                v = 0
                cur_len = 0

            occ[v] += 1

        for state in range(sz - 1, 0, -1):
            x = order[state]
            parent = sam.link[x]
            if parent >= 0:
                occ[parent] += occ[x]

        for state in range(sz):
            if not (L <= occ[state] <= R):
                left[state] = 1
                right[state] = 0

    ans = 0
    for v in range(1, sz):
        if left[v] <= right[v]:
            ans += right[v] - left[v] + 1

    print(ans)

if __name__ == "__main__":
    solve()
```该实现一次性构建源字符串的后缀自动机。 状态按长度排序，以便可以有效地执行后缀链接传播。 

对于每个规则字符串，我们运行标准自动机匹配过程。 每个位置贡献一个端点计数。 按长度递减顺序处理状态通过后缀链接传播这些计数，并将端点频率转换为子串出现频率。 

关键的观察是状态表示的所有子字符串在处理的规则字符串中共享相同的出现计数。 正因为如此，一个国家要么完全在规则中幸存下来，要么被完全消除。 

根状态永远不会计入最终答案，因为它代表空字符串而不是非空子字符串。

 ## 边缘情况

 考虑：```
a
0
```后缀自动机包含一个表示长度区间的非根状态`[1,1]`。 最后的求和恰好贡献了一个子串。 答案是`1`。 

考虑：```
aaaa
0
```有十个位置子字符串，但只有四个不同的值。 SAM 表示存储长度`1,2,3,4`正好一次。 求和间隔大小产生`4`，自动避免重复计数。 

考虑：```
ab
1
c 0 0
```的遍历`"c"`不离根。 每个非空子字符串在规则字符串中的出现次数为零。 由于零位于允许的范围内，因此所有表示的长度都会保留。 答案就变成了`3`。 

考虑：```
aaa
1
aaa 2 2
```出现次数按重数进行计数。`"a"`出现三次，`"aa"`出现两次，`"aaa"`发生一次。 仅有的`"aa"`满足约束条件。 后缀自动机传播通过末端位置聚合计算这些精确的频率，给出正确的答案`1`。
