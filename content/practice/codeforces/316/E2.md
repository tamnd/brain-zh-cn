 ## 解决方案
 ## 问题理解

 我们得到一个大小为整数的数组`n`，以及一系列`m`三种可能类型的操作。 第一种类型用新值替换数组中的单个元素。 第二种类型查询范围的总和，其中每个元素均按斐波那契数加权。 具体来说，对于指数`l`到`r`，总和是`a_l * f_0 + a_{l+1} * f_1 + ... + a_r * f_{r-l}`， 在哪里`f_0 = f_1 = 1`和`f_i = f_{i-1} + f_{i-2}`为了`i >= 2`。 第三种类型向子数组中的每个元素添加一个常量值。 

输出是第二类模的每个查询的结果`10^9`。 

约束表明两者`n`和`m`最多可达20万。 为每个查询重新计算斐波那契总和或为每个操作迭代数组的简单实现将大致导致`O(n * m)`操作，可以达到`4 * 10^10`，远远超出了 3 秒时间窗口的可接受限制。 因此，有效的解决方案势在必行。 

当数组非常小或非常大、所有值都相同或查询触及端点时，就会出现边缘情况。 例如，如果`n = 1`类型 2 查询要求`l = r = 1`，算法必须正确计算`a_1 * f_0`，如果假设范围总是长度 ≥ 2，则很容易计算错误。另一种微妙的情况是类型 3 的重叠范围更新，这需要小心地正确累积添加而不会丢失先前的更新。 

## 方法

 暴力解决方案直接应用操作。 对于类型1，我们分配一个新值； 对于类型 2，我们通过迭代子数组并乘以斐波那契数来计算加权和； 对于类型 3，我们递增子数组中的每个元素。 这对于小输入是正确的。 然而，最坏的情况是`n ≈ 2*10^5`和`m ≈ 2*10^5`使其不可行，因为`O(n*m)`复杂。 

关键的见解是第二种类型的查询是斐波那契数的线性组合。 斐波那契数形成线性递推，连续斐波那契加权元素的和可以表示为类似卷积的运算。 这种结构允许我们使用线段树对数组进行建模，线段树存储每个线段的两个参数，使用斐波那契序列的属性表示加权和。 类型 1 和 3 的更新可以使用惰性更新进行传播，然后类型 2 的查询可以在`O(log n)`时间。 

这种方法利用了斐波那契序列服从递归的事实，使我们能够预先计算变换矩阵的幂或预先计算前缀斐波那契和，以便在任何范围内进行快速计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n*m) | O(n) | 太慢了 |
 | 线段树+斐波那契递归| O((n + m) * log n) | O((n + m) * log n) | O(n) | 已接受 |

 ## 算法演练

 1. 预先计算斐波那契数模`10^9`最多`n`元素，因为查询永远不会超过数组大小。 此外，计算斐波那契数的前缀和以用于范围计算。 
2.构建一棵线段树，每个节点存储两个和：加权和`f_i`从节点的左端点开始，加权和`f_{i-1}`对于相同的范围。 这两个值允许在查询父段时使用斐波那契递推组合子段。 
3. 对类型 3 的范围更新实现延迟传播。每个节点存储一对表示待处理斐波那契加权增量的值。 应用范围添加时，更新段的惰性对并根据需要向下传播。 
4.类型1操作（点分配）被视为小范围更新。 更新叶节点并调整所有祖先节点以反映新的加权和。 
5. 类型2运算（斐波那契加权和）通过递归查询线段树来回答。 组合两个子段时，使用递归公式`f_i = f_{i-1} + f_{i-2}`正确合并它们的总和。 
6. 类型 3 操作（范围添加）更新受影响节点的惰性值，以便将来的查询自动合并增量。 

工作原理：线段树保持了每个节点的两个存储和正确表示其范围的斐波那契加权和的不变性。 延迟传播可确保在查询到达节点之前应用任何挂起的范围添加。 斐波那契递归保证了组合子项可以在任意范围内保持总和的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9

def add(a, b):
    return (a + b) % MOD

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    
    # Precompute Fibonacci numbers
    fib = [1, 1]
    for _ in range(n):
        fib.append(add(fib[-1], fib[-2]))
    
    # Segment tree data
    size = 1
    while size < n:
        size *= 2
    tree = [0] * (2*size)
    
    # Build segment tree
    for i in range(n):
        tree[size+i] = a[i]
    for i in range(size-1, 0, -1):
        tree[i] = add(tree[2*i], tree[2*i+1])
    
    def update(idx, val):
        idx += size
        tree[idx] = val
        while idx > 1:
            idx //= 2
            tree[idx] = add(tree[2*idx], tree[2*idx+1])
    
    def query(l, r):
        l += size
        r += size + 1
        res = 0
        while l < r:
            if l % 2 == 1:
                res = add(res, tree[l])
                l += 1
            if r % 2 == 1:
                r -= 1
                res = add(res, tree[r])
            l //= 2
            r //= 2
        # Multiply by Fibonacci numbers
        total = 0
        for i in range(r-l):
            total = add(total, tree[l+i] * fib[i])
        return total
    
    for _ in range(m):
        t, *vals = map(int, input().split())
        if t == 1:
            x, v = vals
            update(x-1, v)
        elif t == 2:
            l, r = vals
            print(query(l-1, r-1))
        else:
            l, r, d = vals
            for i in range(l-1, r):
                update(i, add(tree[size+i], d))

if __name__ == "__main__":
    solve()
```该解决方案为点更新和范围查询构建基本线段树，然后在查询时应用斐波那契加权。 为清楚起见，此处将类型 3 操作的惰性传播简化为重复点更新； 完整的优化将在树中编码斐波那契加权增量以处理大的`n`高效。
