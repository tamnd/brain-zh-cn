 ## 解决方案
 ## 问题理解

 我们被要求计算字符串中不同子串的数量`s`满足一组基于发生的规则。 每个规则由一个字符串组成`p`和一个范围`[l, r]`，和一个子串`t`的`s`如果它出现的次数被认为是好的`p`落在`[l, r]`对于每条规则。 

输入由主字符串组成`s`, 一些规则`n`，以及规则本身。 输出是一个整数：好的子串的数量`s`。 

约束很严格：`n`最多 10 个，虽然很小，但是长度`s`和辅助弦`p`在最难的子任务中可以达到 50,000。 这立即排除了天真地根据每个规则检查每个子串的暴力方法，因为子串的数量`s`是 O(|s|²)，对于 50,000 来说大约是 25 亿。 即使检查规则字符串中的出现情况`p`花费 O(|p|)，复杂度是不可行的。 

不明显的边缘情况包括零范围、重叠子串和重复模式的规则。 例如，如果`s = "aaa"`一条规则是`("aa", 1, 1)`, 仅子串`"aa"`（从第一个和第二个位置开始）即使它们出现两次，也将一次视为不同的`s`。 粗心的实现在不进行重复数据删除的情况下对子字符串进行计数或忽略范围约束将给出错误的结果。 

## 方法

 暴力法枚举所有子串`s`并且，对于每个，计算它在每个中出现的次数`p`细绳。 这保证了正确性，因为它直接遵循问题定义。 然而，它的时间复杂度为 O(|s|² * n * |p|max)。 对于|s| = 50,000，即使一条长度为 50,000 的规则也会导致大约 10^3 次操作，这是不切实际的。 

关键的见解是我们需要一种方法来有效地检查子字符串的出现并避免重复计数。 子字符串哈希允许对子字符串进行常量时间比较，因此我们可以枚举`s`并存储它们的哈希值以检查唯一性。 对于规则中的出现次数计数，我们可以预处理每个规则字符串`p`使用滚动哈希或 Rabin-Karp 方法，将每个可能的子串长度映射到频率表。 因为`n`很小，我们可以有效地交叉约束。 

因此，问题减少为枚举所有子串`s`，使用散列来保持独特性，并使用每个规则预先计算的频率表来快速验证子字符串是否“好”。 瓶颈变得易于管理：使用预处理表通过 O(1) 哈希检查和 O(n) 规则检查来枚举子字符串的时间复杂度为 O(|s|²)。

 ## 算法演练

 1. 预处理每个规则字符串`p`。 对于每个可能出现的子串长度`s`，计算一个哈希表，将每个子字符串哈希映射到它的频率`p`。 这允许 O(1) 查找给定子字符串哈希出现的次数。 
2. 初始化一个集合来存储不同的好子串的哈希值。 
3. 枚举所有子串`s`。 对于每个子字符串，计算其哈希值。 检查哈希集：如果已经看到，则跳过以避免重复计数。 
4. 对于每个新子字符串，根据所有规则检查它。 在预处理的频率表中查找子字符串哈希并验证频率是否在范围内`[l, r]`每个规则的范围。 
5. 如果子字符串通过所有规则，则将其哈希添加到集合中。 
6.处理完所有子串后，集合的大小就是不同的好子串的数量。 

为什么它有效：哈希保证了每个不同的子字符串`s`只计算一次。 预处理规则可确保出现次数计数准确且高效。 由于我们检查了所有子串和所有规则，因此算法可以正确识别每个好的子串。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def rabin_karp_hash(s, base=257, mod=10**9+7):
    h = [0] * (len(s) + 1)
    p = [1] * (len(s) + 1)
    for i in range(len(s)):
        h[i+1] = (h[i]*base + ord(s[i])) % mod
        p[i+1] = (p[i]*base) % mod
    return h, p

def substring_hash(h, p, l, r, mod=10**9+7):
    return (h[r] - h[l]*p[r-l]) % mod

def solve():
    s = input().strip()
    n = int(input())
    rules = []
    for _ in range(n):
        parts = input().split()
        rules.append((parts[0], int(parts[1]), int(parts[2])))
    
    s_hash, s_pow = rabin_karp_hash(s)
    seen = set()
    
    # Preprocess rules
    rule_hashes = []
    for pstr, l, r in rules:
        ph, pp = rabin_karp_hash(pstr)
        freq = {}
        plen = len(pstr)
        for length in range(1, len(s)+1):
            for i in range(plen - length + 1):
                hval = substring_hash(ph, pp, i, i+length)
                freq[hval] = freq.get(hval, 0) + 1
        rule_hashes.append((freq, l, r))
    
    # Enumerate substrings of s
    slen = len(s)
    for i in range(slen):
        for j in range(i+1, slen+1):
            hval = substring_hash(s_hash, s_pow, i, j)
            if hval in seen:
                continue
            good = True
            for freq, l, r in rule_hashes:
                count = freq.get(hval, 0)
                if not (l <= count <= r):
                    good = False
                    break
            if good:
                seen.add(hval)
    
    print(len(seen))

if __name__ == "__main__":
    solve()
```第一部分计算滚动哈希值`s`和每个规则字符串。 嵌套循环枚举所有子字符串并使用预先计算的幂在 O(1) 中生成哈希值。 这`seen`set 确保我们只计算不同的子字符串。 预处理每个规则字符串允许每个子字符串进行 O(1) 频率查找。
