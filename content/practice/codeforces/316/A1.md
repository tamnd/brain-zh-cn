 ## 解决方案
 ## 问题理解

 该问题要求我们计算有多少数字代码与提示字符串匹配，该提示字符串可以包含固定数字、通配符和表示数字相等约束的字母。 提示字符串中的每个字符代表安全代码中的一个位置。 一个问号`?`可以是0到9之间的任意数字，一个数字`0-9`是固定的，并且字母`A-J`表示组，其中相同的字母必须映射到相同的数字，不同的字母必须映射到不同的数字。 安全代码不能有前导零。 

例如，提示`AJ`用不同的字母表示两个位置。 第一位置`A`可以是 1-9 中的任意数字，因为它是前导，并且是第二个位置`J`可以是 0-9 中的任意数字，除了分配给的数字之外`A`。 因此，总有效代码为`9 * 9 = 81`。 

小子问题的提示长度可达 5，这使我们能够考虑暴力解决方案，而完整问题的长度可达 10^5，排除了指数枚举。 前导零和重复字母是微妙的边缘情况，很容易被错误处理。 例如，`?A?A`需要仔细考虑：如果`A`被赋值为0并且出现在前导位置，即无效。 同样，映射到数字的字母不得与相同位置的固定数字冲突。 

## 方法

 一种简单的方法是尝试对字母和通配符进行所有可能的数字分配，检查与固定数字的冲突。 对于长度为 n 且最多包含 10 个字母的字符串，最坏的情况可能是 10！ （对于字母排列）乘以 10^(n − 字母)，对于 n = 10^5 来说这变得很棘手。 蛮力仅适用于非常小的长度。 

最佳方法将字母视为唯一数字的占位符，并以组合方式计算可能性。 首先，数一下提示中不同的字母。 第一个字符不能为 0，如果是字母或字母，则会减少选择数量`?`。 然后，按顺序为每个不同的字母分配数字。 如果在第一个位置，第一个字母可以取9个选择，下一个字母可以取9个或10个，具体取决于第一个字母是否固定，依此类推。 最后，每一个`?`将计数乘以 10，除非它是第一个字符，这只能占用 9 个字符。固定数字的乘法贡献为 1。这纯粹是算术运算，并且与字符串长度成线性比例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(10^n) | O(10^n) | O(n) | 对于 n > 5 来说太慢 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取提示字符串`s`并确定其长度`n`。 初始化`count = 1`。 
2. 识别所有不同的字母`s`以及它们出现的位置。 维持首次出场顺序。 
3. 对于每个不同的字母，依次分配一个唯一的数字。 字符串中的第一个字母不能为0； 后续字母可以使用剩余的数字。 
4. 对于每个`?`, 乘以`count`如果不是第一个字符，则加 10； 如果是第一个，则乘以 9（因为前导零无效）。 
5. 固定数字的乘法贡献为 1。 
6. 处理完所有字母和通配符后，输出最终计数。 

为什么有效：字母对应于唯一的数字，并且分配的顺序确保不发生冲突。 除前导零外，通配符是独立的。 固定数字充当约束。 顺序乘法对所有组合仅计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)
    count = 1
    used_letters = set()
    first_char = s[0]

    # Count distinct letters and their first positions
    letters_order = []
    for c in s:
        if 'A' <= c <= 'J' and c not in used_letters:
            letters_order.append(c)
            used_letters.add(c)

    # Assign digits to letters
    available_digits = 10
    for idx, c in enumerate(letters_order):
        if idx == 0 and letters_order[0] == first_char:
            count *= 9
            available_digits -= 1
        else:
            count *= available_digits
            available_digits -= 1

    # Count '?'
    for i, c in enumerate(s):
        if c == '?':
            if i == 0:
                count *= 9
            else:
                count *= 10

    print(count)

if __name__ == "__main__":
    solve()
```在这个实现中，`letters_order`确保我们将数字分配给不同的字母而不重复。 乘法处理字母和通配符的组合可能性。 谨慎处理前导位置以防止出现零。 固定数字不需要执行任何操作，因为它们已计为 1。

 ## 边缘情况

 用于输入`?A`，第一个`?`只能是 1-9，并且`A`可以是任何剩余的数字，产生`9*9 = 81`。 为了`AA`，字母重复； 第一个`A`可以是1-9，第二个`A`必须匹配第一个，产生`9`。 该算法将计数顺序相乘并确保字母和`?`正确处理领先位置的值，避免零和重复分配。
