 ## 解决方案
 ## 问题理解

 我们有一个队列`n`海狸，每只编号从 1 到`n`。 每只海狸要么知道谁应该在他们面前，表示为`a[i]`（那只海狸的数量），或者不知道，表示为`0`。 这些依赖关系中没有循环，这意味着“跟随”关系形成了一个链条森林。 目标是找到特定海狸的所有可能位置，`x`，在最终队列中与给定的信息一致。 

关键是有些海狸不知道自己追随的是谁。 这会产生不确定性：这些海狸可能会占据序列中的任何空闲位置，只要它们尊重非零依赖性。 具有已知前任的海狸的位置相对于彼此实际上是固定的，但未知因素引入了组合的可能性。 

约束条件是可以管理的`O(n^2)`算法因为`n ≤ 1000`。 该问题暗示了两个评分子任务：对于最多 20 个未知数，简单的模拟可以工作； 对于任意未知数，需要更系统的方法。 粗心的实现可能会假设输入的线性顺序或忽略未知数的传播。 例如，给定`n=3`,`x=1`和`a=[2,0,0]`，一个简单的解决方案可能会假设海狸 1 只能在第一个位置跟随 2，但也可能位置 1 和 3 对于其他未知数来说是空的，从而导致海狸 1 有多个有效位置。 

## 方法

 蛮力方法是生成尊重非零依赖性的海狸的所有排列，并检查在哪里`x`降落在每一个。 对于每个`n!`排列，验证有效性需要`O(n)`。 这显然太慢了`n=1000`，即使对于未知数上限为 20 的第一个子任务也是如此。蛮力之所以有效，是因为它显式枚举了所有有效订单，但当未知数数量增加时，它会失败，导致组合爆炸。 

关键的见解是海狸基于非零形成链`a[i]`价值观。 每条链都有明确的相对顺序。 海狸与`a[i]=0`可以插入链之间的任何位置。 因此，我们不需要生成完整的排列。 相反，我们可以将每个链建模为位置序列，找到每个链可以占据的最早和最新位置，然后计算所有位置`x`可以根据其所属的链来占据。 通过迭代未知数并考虑每个链之前存在多少个空点，我们可以有效地计算一组位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n! * n) | O(n! * n) | O(n) | 对于 n>20 来说太慢 |
 | 链式传播+位置跟踪| O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1. 创建一个`next_beaver`大小数组`n+1`， 在哪里`next_beaver[i]`海狸紧随其后`i`。 初始化为`0`。 这让我们可以快速遍历链。 
2. 识别所有链头：没有其他人跟随的海狸。 我们还追踪追随已知前辈的海狸。 
3. 对于每个链，计算其长度以及它在队列中可以占据的位置范围。 最小位置由必须位于其之前的链的数量确定，而最大位置由总长度减去剩余链确定。 
4. 如果`x`是一个具有已知前身的海狸，遍历它的链以确定它在该链中的相对位置。 最终可能的位置`x`是队列中尊重其链的最小起点和链的相对位置的所有位置。 
5.如果`x`有`a[x]=0`，那么它的可能位置对应于所有未被非零链占据的空位置`a[i]`。 迭代所有位置，跳过占用的位置，并收集其中的位置`x`可以插入。 
6. 按升序对结果位置进行排序并打印它们。 

**为什么有效**：该算法维护两个不变量。 首先，通过遍历链来保留海狸与已知前辈的相对顺序。 其次，未知的海狸只被插入到不违反现有链条的位置。 这些不变量保证了所有生成的位置`x`是有效的，并且没有遗漏任何有效位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, x = map(int, input().split())
a = list(map(int, input().split()))

next_beaver = [0] * (n + 1)
has_prev = [False] * (n + 1)

for i, val in enumerate(a, 1):
    if val != 0:
        next_beaver[val] = i
        has_prev[i] = True

# Identify chain heads
heads = [i for i in range(1, n + 1) if not has_prev[i]]

# Function to find positions in a chain
def get_chain(head):
    chain = []
    current = head
    while current:
        chain.append(current)
        current = next_beaver[current]
    return chain

occupied = set()
chains = []

for head in heads:
    chain = get_chain(head)
    chains.append(chain)
    occupied.update(chain)

possible_positions = set()

if a[x-1] != 0 or next_beaver[x] != 0:  # x in a chain
    for chain in chains:
        if x in chain:
            idx = chain.index(x)
            for pos in range(idx+1, n+1-len(chain)+idx+1):
                possible_positions.add(pos)
else:  # x is unknown, free to go to any unoccupied
    free_positions = [i for i in range(1, n+1) if i not in occupied]
    possible_positions.update(free_positions)

for pos in sorted(possible_positions):
    print(pos)
```该解决方案首先使用以下方法构建“跟随”链`next_beaver`。 它计算所有链头，然后对于每个链，遍历并收集海狸。 如果`x`是链的一部分，我们计算遵守链顺序的所有可能位置。 如果`x`完全未知，我们只需将其放置在任何未占用的插槽中即可。 微妙之处在于确保计算出的位置正确反映链的偏移量。
