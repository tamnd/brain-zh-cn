 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，表示沿线居民的幸福水平。 对于每个测试用例，我们必须计算有多少个连续子数组具有平均幸福度，其下限等于给定整数$k$。 

对于子数组，以更可操作的方式重写条件$[l, r]$，令其总和为$S = a_l + a_{l+1} + \dots + a_r$其长度为$L = r - l + 1$。 要求是：$$\left\lfloor \frac{S}{L} \right\rfloor = k$$这相当于：$$k \le \frac{S}{L} < k + 1$$乘以通过$L$，我们得到：$$kL \le S < (k+1)L$$因此，每个有效段的总和都位于一个紧密的线性范围内，具体取决于其长度。 

约束条件很大：最多$5 \cdot 10^5$测试用例中的总元素。 这排除了任何$O(n^2)$子数组的枚举。 甚至一个$O(n \log n)$每个测试用例方法必须仔细论证，但在实践中我们应该以线性或近线性行为为目标。 

一个微妙的陷阱是，该条件使用平均值下限，而不是等式。 一个幼稚的错误是只检查$S = kL$，它错过了平均值略高于的有效间隔$k$但仍低于$k+1$。 另一个问题是溢出推理，因为总和可以达到$10^{14}$规模，但 Python 避免了这一点，而 C++ 则需要 64 位。 

一个小例子阐明了结构。 如果数组是$[2, 1, 3]$和$k = 2$，有效的子数组是$[2]$,$[1,3]$， 和$[2,1,3]$。 第二个之所以有效，是因为它的平均值恰好是 2，尽管其总和在长度 2 上是 4。 

## 方法

 直接方法尝试每个子数组并计算其总和，然后检查是否$\lfloor S/L \rfloor = k$。 这需要迭代$O(n^2)$间隔和计算总和，可以简化为$O(1)$每个间隔使用前缀和。 即便如此，总的复杂性仍然存在$O(n^2)$，这远远超出了极限$n$达到$2 \cdot 10^5$。 

病情的结构表明了一种转变。 我们不使用原始值，而是通过减去来移动数组$k$。 定义：$$b_i = a_i - k$$那么对于任意段：$$\sum b_i = S - kL$$条件$kL \le S < (k+1)L$变成：$$0 \le \sum b_i < L$$因此，我们正在计算移位总和非负但严格小于其长度的子数组。 

这仍然涉及到对长度的依赖，这看起来很尴尬。 关键的观察是将两个不等式分开：

 我们需要：$$\sum b_i \ge 0 \quad \text{and} \quad \sum b_i \le L - 1$$第二个不等式可以重写为：$$\sum b_i - L < 0$$如果我们定义另一个转换后的数组：$$c_i = b_i - 1 = a_i - (k+1)$$然后：$$\sum c_i < 0$$现在问题变成了计算满足两个独立的前缀和约束的子数组：$$\sum b_i \ge 0 \quad \text{and} \quad \sum c_i < 0$$令前缀和为：$$P_i = \sum_{j \le i} b_j,\quad Q_i = \sum_{j \le i} c_j$$对于子数组$[l, r]$，条件变为：$$P_r - P_{l-1} \ge 0 \Rightarrow P_r \ge P_{l-1}$$

$$Q_r - Q_{l-1} < 0 \Rightarrow Q_r < Q_{l-1}$$所以我们需要索引对$l-1 < r$这样：$$P_{l-1} \le P_r \quad \text{and} \quad Q_{l-1} > Q_r$$这是 2D 点上的优势计数问题$(P_i, Q_i)$，其中我们对第一个坐标中的一个点不超过但在第二个坐标中严格超过的点进行计数。 这可以使用坐标压缩扫描和芬威克树来解决。 

这个想法是排序$P$，并且对于每个固定的$P_r$, 数一下之前有多少个$P$- 值为$\le P_r$同时过滤$Q$动态排序。

 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了|
 | 最优（Fenwick + 对前缀对排序）|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将数组转换为两个前缀和数组，并将条件简化为前缀点上的成对优势计数问题。 

1. 建立转变的价值观$b_i = a_i - k$和$c_i = a_i - (k+1)$。 这将原始条件中的两个不等式编码为线性前缀约束。 
2. 计算前缀和$P_i$为了$b$和$Q_i$为了$c$， 包括$P_0 = Q_0 = 0$。 各指标$i$变成一个点$(P_i, Q_i)$。 
3. 收集所有前缀点并按以下顺序排序$P_i$。 这确保了在处理一个点时，所有有效的前驱点$P$可以按顺序访问。 
4. 压缩$Q$坐标。 这是必需的，因为我们将查询之前有多少个点$Q$大于阈值，并且 Fenwick 树需要离散索引。 
5. 按升序扫描点$P$。 维护一个 Fenwick 树，存储已处理的点的计数，这些点由压缩键控$Q$。 
6. 对于每个点$i$，我们想要计算有多少个较早的点$j$满足$Q_j > Q_i$。 这是通过查询 Fenwick 树中高于当前值的计数来完成的。$Q_i$。 
7. 处理后将每个点的贡献添加到 Fenwick 树中，确保未来的点将其视为候选前驱。 
8. 将所有点的所有贡献相加以获得最终答案。 

扫描确保$P_j \le P_i$处理顺序自动遵守条件，而芬威克树则强制执行$Q_j > Q_i$约束。 

### 为什么它有效

 每个子数组唯一对应一对前缀索引$(l-1, r)$。 该变换确保有效性仅取决于二维空间中前缀点的相对顺序。 扫描线保证我们只考虑有效的$P$-有序对，Fenwick 结构强制执行严格的$Q$不等式。 由于每个有效对在其右端点都被精确计数一次$r$，不存在多算或漏算的情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, i, v):
        while i <= self.n:
            self.bit[i] += v
            i += i & -i

    def sum(self, i):
        s = 0
        while i > 0:
            s += self.bit[i]
            i -= i & -i
        return s

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        P = 0
        Q = 0
        pts = [(0, 0)]

        for x in a:
            P += x - k
            Q += x - (k + 1)
            pts.append((P, Q))

        qs = sorted(set(q for _, q in pts))
        comp = {q: i + 1 for i, q in enumerate(qs)}

        pts.sort()

        fw = Fenwick(len(qs))
        ans = 0

        for p, q in pts:
            idx = comp[q]
            ans += fw.sum(len(qs)) - fw.sum(idx)
            fw.add(idx, 1)

        print(ans)

if __name__ == "__main__":
    solve()
```实现直接遵循扫描线解释。 每个前缀状态在查询后插入，以便仅考虑较早的前缀。 Fenwick 树通过压缩存储计数$Q$，范围查询计算有多少个较早的前缀总和超过了当前的前缀总和$Q$。 

一个微妙的点是排序依据$P$任意断开关系，这是可以接受的，因为平等$P$值不会影响同一级别计数对正确性的不等式方向。 严格不等式$Q$通过将 Fenwick 查询拆分为后缀和来处理。

 ## 边缘情况

 当所有元素相等时会出现极端情况$k$。 那么每个子数组都有准确的平均值$k$，答案就变成了子数组的总数。 该算法处理此问题是因为所有前缀点都以退化方式对齐，但分域计数仍然正确地计算所有有效的索引对。 

另一种边缘情况是当没有子数组满足条件时，例如当所有值远小于$k$。 在这种情况下，变换后的前缀和在一致的方向上保持严格的负值，并且所有对的主导条件都失败，产生零贡献。 

第三种情况是单元素数组。 前缀结构包括$(0,0)$和一个变形点。 当条件匹配时，Fenwick 查询恰好处理一对有效的对，从而确保正确性，无需特殊的大小写。
