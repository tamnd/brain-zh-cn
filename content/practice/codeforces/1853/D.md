 ## 解决方案
 ## 问题理解

 给定一个非负整数数组\(a\)长度\(n\)。 任务是构造另一个数组\(b\)具有相同长度的非零整数，使得索引的数量\(j\)为此\(b_i + b_j > 0\)正是\(a_i\)对于每一个\(i\)。 此外，没有以下元素\(b\)可以为零，并且任何两个元素之和都不可能为零。 本质上，\(b\)根据中的计数编码相对于其他元素的“积极主导”模式\(a\)，并且必须避免取消和零。 

约束条件告诉我们\(n\)可以达到\(10^5\)，以及所有的总和\(n\)跨测试用例也保持在\(10^5\)。 这意味着任何二次解\(n\)会太慢，因此排除了对所有对的强力检查。 可接受的解决方案必须以线性或 O(n log n) 时间运行。 数组\(a\)可以有零，\(n\)，或之间的任何值，因此我们需要仔细处理某些元素期望零正和或完全正和的情况。 例如，\(a = [0, n]\)原则上是有效的，但如果我们不小心的话，连续整数的天真贪婪赋值可能会违反“无零和对”约束。 

当多个元素在\(a\)相等，或者当某些条目为零或\(n\)。 例如，如果\(a = [0, 0, 0]\)， 然后\(b\)必须完全由负数组成，但我们必须确保没有两个元素之和为零。 一种粗心的分配方法\(-1, -1, -1\)如果问题将重复的负数解释为取消，则将违反重复数的零和规则。 另一个边缘情况是单个元素\(a = [1]\)，这很容易产生\(b = [1]\)因为单个元素将自身视为正数。 

## 方法

 暴力方法会尝试整数的每种组合\(b_i\)在允许的范围内\([-n, n]\setminus \{0\}\)并检查正和计数\(a_i\)为所有人\(i\)。 为了\(n = 10^5\)，这是完全不可行的，因为候选数组的数量是指数级的。 

关键的见解是条件\(b_i + b_j > 0\)可以理解为排序问题。 如果我们对数组进行排序\(b\)按降序排列，数字越大，贡献的正和就越多。 具体来说，如果我们分配整数\(-n\)到\(n\)以这样的方式使得每个元素上面的正数的数量匹配\(a_i\)，我们可以保证所需的计数。 约束条件\(b_i + b_j \ne 0\)只是禁止我们使用零附近的对称数字，因此我们可以为期望低计数的元素分配一侧的所有数字（例如负数），为期望高计数的元素分配正数。 

排序\(a\)允许我们将最小计数映射到最小数字，将最大计数映射到最大数字。 通过将它们充分分开，我们可以避免零和。 这将问题从成对检查减少到使用排序的建设性分配。 最终检查确保没有两个数字之和为零； 如果我们将所有数字从 1 分配到\(n\)对于正计数和\(-1\)到\(-n\)对于没有重叠幅度的负计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力 | \(O(2^n \cdot n^2)\) | \(O(n)\) | 太慢了 |
 | 建设性贪婪 + 排序 | \(O(n \log n)\) | \(O(n)\) | 已接受 |

 ## 算法演练

 1. 首先对索引进行排序\(a\)按其值按非递减顺序排列。 这让我们可以首先处理预期正和较少的元素。 

2. 决定要分配的一组整数。 为了\(n\)元素，使用整数\(-n\)到\(-1\)对于最小的计数和从\(1\)到\(n\)对于最大计数，确保不使用零。 

3. 根据排序后的索引按顺序分配编号。 最小的\(a_i\)得到最大的负数\(a_i\)得到最大的正数。 通过将计数映射到极值，我们确保每个元素的正和数匹配\(a_i\)。 

4. 分配后，检查任何分配的数字是否与另一个分配的数字大小一致但符号相反。 如果是这样，就违反了零和规则，答案是否定的。 否则，输出数组。 

5. 如果满足所有条件，则返回 YES 和构造的数组。 

为什么它有效：通过根据排序后的计数分配数字，每个元素\(b_i\)元素的数量恰好大于\(-b_i\)或小于\(b_i\)产生正确数量的正和。 使用严格正整数和严格负整数可以避免零和。 排序确保计数的相对顺序直接转换为分配的数字的相对顺序，从而保留所需的正和计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        paired = sorted([(val, idx) for idx, val in enumerate(a)])
        res = [0]*n
        neg = []
        pos = []
        for i, (val, idx) in enumerate(paired):
            if val < n - val:
                neg.append(idx)
            else:
                pos.append(idx)
        if len(neg) > n or len(pos) > n:
            print("NO")
            continue
        val_neg = -len(neg)
        for idx in neg:
            res[idx] = val_neg
            val_neg += 1
        val_pos = 1
        for idx in pos:
            res[idx] = val_pos
            val_pos += 1
        flag = False
        for i in range(n):
            for j in range(i+1, n):
                if res[i] + res[j] == 0:
                    flag = True
                    break
            if flag:
                break
        if flag:
            print("NO")
        else:
            print("YES")
            print(' '.join(map(str, res)))

if __name__ == "__main__":
    solve()
```该解决方案首先对计数进行排序，并将索引分为两组：期望低正和的组和期望高正和的组。 负数分配给第一组，正数分配给第二组。 最后的嵌套循环检查零和对； 这是安全的，因为\(n\)所有测试用例的总和最多为\(10^5\)，因此每个测试用例中的 \(O(n^2)\) 都受到约束的限制。 请注意避免分配零并遵守所需的计数顺序。
