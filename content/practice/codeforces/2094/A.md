 ## 解决方案
 ## 问题理解

 每个测试用例都描述一个“国家/地区名称”，该名称以旧格式存储，由三个单独的单词组成。 现代表示是通过将这三个单词压缩成一个缩写来形成的：我们取第一个单词的第一个字符、第二个单词的第一个字符和第三个单词的第一个字符，然后按顺序连接它们。 

所以任务纯粹是关于字符串解析。 对于每一行，我们将其恰好分成三个单词，并从每个单词中提取一个字符。 

限制非常小。 测试用例最多有 100 个，每个单词的长度最多为 10。这意味着总输入大小很小，任何读取并处理每一行一次的方法都已经是最佳的。 即使重复扫描或重建字符串也足够快，但问题的结构强烈建议采用直接提取方法。 

不存在棘手的数值边缘情况，但在不正确的实现中会出现一种微妙的故障模式：将整行视为单个字符串并采取固定位置，例如`s[0], s[1], s[2]`。 这会立即中断，因为空格分隔单词，并且整行的第二个和第三个字母通常是空格而不是字符。 例如，在输入中`oh my god`，字符串开头为`'o'`，然后是一个空格，因此盲目索引会给出错误的结果。 正确的行为始终取决于首先按空格进行分割。 

## 方法

 蛮力视图是获取每一行的每个字符，尝试确定它是否是单词的第一个字符。 人们可以扫描字符串并维护一个布尔标志，该标志指示我们是否位于单词的开头（在索引 0 处或在空格之后）。 每次标志为 true 时，我们都会附加该字符。 这是可行的，但它做了不必要的工作，因为我们正在迭代每一行中的每个字符，即使每个测试用例只需要三个字符。 

关键的观察结果是结构是固定的。 每行始终包含恰好三个单词，并且已经用空格清晰地分隔开。 一旦我们将行分成标记，每个测试用例的答案就会在恒定的时间内确定：只需访问每个标记的第一个字符。 这将问题简化为简单的字符串拆分和索引。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力扫描字符| O(总字符数) | O(1) | O(1) | 已接受但没有必要 |
 | 拆分+直接访问| O(分割的总字符数) | O(1) | O(1) | 已接受 |

 基于分割的方法更加简单，并且避免了手动状态跟踪。 

## 算法演练

 1.读取测试用例数量`t`，它决定了我们将处理多少条独立线。 
2. 对于每个测试用例，读取整行并使用空格分隔将其分成三个单词。 这保证了我们干净地隔离每个单词，无论间距如何。 
3. 提取三个单词中每一个的第一个字符。 由于每个单词都保证非空且由小写字母组成，因此位置 0 处的索引始终有效。 
4. 将这三个字符按顺序连接起来并立即输出结果。 

### 为什么它有效

 每条输入行在结构上都固定为三个标记，而现代名称纯粹被定义为这些标记的确定性投影。 取第一个字符的操作对于每个单词来说是独立的，因此位置之间不存在交互。 只要标记化正确，从输入行到输出字符串的映射就是无损且唯一的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c = input().split()
    print(a[0] + b[0] + c[0])
```解决方案依赖于Python的内置`split()`它会自动处理任意间距并确保我们正确隔离三个单词。 然后，我们直接解构为三个变量，这使得意图明确并避免列表上的索引错误。 

每个单词都保证存在，因此解包为`a, b, c`在问题约束下是安全的。 

最终的连接使用简单的字符串加法，考虑到 3 个字符的固定大小，这是有效的。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        a, b, c = sys.stdin.readline().split()
        out.append(a[0] + b[0] + c[0])
    return "\n".join(out)

 ## 边缘情况

 一个潜在的陷阱是假设原始字符串中的字符位置固定，而不是标记化。 例如，输入`oh my god`不能通过采取处理`s[0]`,`s[1]`,`s[2]`， 因为`s[1]`是一个空间。 正确的处理首先是分割：

 输入：`oh my god`分割后：`["oh", "my", "god"]`然后：

 - 第一个词给出`'o'`- 第二个词给出`'m'`- 第三个词给出`'g'`结果：`omg`另一个边缘情况是单词中重复的字母。 输入`skibidi slay sigma`产生`sss`，这证实我们不需要任何重复数据删除或特殊处理。
