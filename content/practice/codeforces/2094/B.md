 ## 解决方案
 ## 问题理解

 我们被要求追踪感染沿着无限长的房屋的传播情况。 感染从第 0 天从 0 号房屋开始，每天都会传播到与任何当前受感染房屋相邻的另外一栋房屋。 后$n$天，我们得到了连续的房屋部分$[l, r]$那些被感染的人。 任务是确定任何有效的段$[l', r']$可能是在前一天被感染的$m \le n$。 

输入由多个测试用例组成。 对于每个测试用例，关键值为$n$，具有已知片段的那一天，$m$，我们必须找到线段的较早日期，以及坐标$l$和$r$之后的片段$n$天。 该问题保证了$r-l = n$，反映每天被感染的房屋数量正好增长一。 

约束很小（$n \le 2000$）所以即使是强力模拟在技术上也可以运行，但是更简单的构造方法可以在$O(1)$每个测试用例。 

非明显的边缘情况涉及负边界，例如，如果该段包括 0 左边的房屋，或者感染完全在右边。 例如，如果$n=4$该段是$[-2,2]$，则有效段位于$m=1$可能是$[0,0]$,$[-1,0]$， 或者$[0,1]$。 幼稚的方法可能会错误地假设左边界必须保持为 0 或右边界必须保持正值，但只要该段的长度等于天数，就可以自由移动。 

## 方法

 最简单的方法是从第 0 天开始模拟每一天。您可以尝试所有可能的方法，向左或向右扩展一栋房子，直到到达一天$n$。 这是有效的，因为天数$n$很小，但即使有$n=2000$，每天模拟所有测试用例不必要地复杂。 操作计数大致为$O(n \cdot t)$，这里可以接受，但不够优雅。 

关键的见解是，感染段是连续的，并且对称地（每天一栋房子）向左、向右或组合扩展。 知道之后的段长度$n$天 （$r-l = n$），我们可以直接计算一天的有效段$m$通过缩小当前段$n-m$房屋，通过将左边界向右移动、将右边界向左移动或两者都移动。 最简单的选择是将左边界向右移动$n-m$并保持右边界固定。 这保证了一个有效的段并且适用于所有值$l$和$r$因为感染可以向任一方向扩展。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(n * t) | O(1) | O(1) | 已接受但不必要的冗长|
 | 建设性转变| O(t) | O(1) | O(1) | 接受且简单 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，请阅读$n$,$m$,$l$,$r$。 
3. 计算当天以来被感染的额外房屋数量$m$：$extra = n - m$。 
4. 选择当天的有效航段$m$。 一种简单的选择是将左边界向右移动$extra$房屋，保持右边界不变：$$l' = l + extra, \quad r' = r$$这是有效的，因为一天中片段的长度$m$将$r' - l' = n - extra = m$，即每天被感染的房屋数量$m$。 
5. 打印$l'$和$r'$对于每个测试用例。 

**为什么有效：** 每天，感染都会形成一个连续的片段。 段长度等于自开始以来的天数。 通过从两侧对称地缩小片段，我们可以重建任何较早一天的片段，同时保持连续性。 由于存在多个有效选择（例如，从右侧收缩），任何单一的建设性选择都是可以接受的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m, l, r = map(int, input().split())
    extra = n - m
    l_prime = l + extra
    r_prime = r
    print(l_prime, r_prime)
```该解决方案使用有效地读取输入`sys.stdin.readline`并处理多个测试用例。`extra`计算从一天开始要反转的步数$n$今天$m$。 左边界右移`extra`，这确保了段长度等于`m`。 这可以避免差一错误、负索引问题和边界错误。

 ## 边缘情况

 对于`n=m`，段不收缩。 为了`n>m`以及跨越负索引和正索引的段，该算法仅正确移动左边界，保持连续性。 例如，输入`n=4, m=2, l=-2, r=2`产量`l'=-2+2=0`,`r'=2`, 给予`[0,2]`。 即使左边界变为正，该线段仍然有效，因为该问题允许任何有效的连续线段。 

对于完全位于右侧的线段，例如，`n=4, m=2, l=0, r=4`，向左移动边界`extra=2`给出`[2,4]`，再次有效。 

这表明该算法一致地处理负、正和混合片段。
