 ## 解决方案
 ## 问题理解

 我们在笛卡尔平面上得到一组黑点，每个黑点都有整数坐标。 每个命令机器人可以向上、向下、向左或向右移动一个单位。 对于一对黑点，最短路径就是以最小曼哈顿距离到达目的地的任何移动序列。 任务是计算有多少个有序的黑点对$(p_i, p_j)$具有沿任何最短路径的所有整数坐标点也是黑色的属性。 

由于最短路径可以先沿 x 方向移动，然后沿 y 方向移动，反之亦然，因此严格在$p_i$和$p_j$沿着连接它们的轴对齐矩形也必须是黑色才能使该对有效。 换句话说，对于要计数的一对，黑点集必须形成一个轴对齐的矩形，并且沿着连接它们的矩形的边不丢失内部格点。 

约束条件很强：$n$可以达到$5 \cdot 10^5$在单个测试用例中，所有测试用例的总和也是$5 \cdot 10^5$。 这立即排除了对所有内容的任何暴力检查$O(n^2)$对。 我们需要一个大致有效的解决方案$O(n \log n)$或者$O(n)$每个测试用例。 

需要注意的边缘情况是所有点都位于一条线上，无论是水平、垂直还是对角线。 例如，点$(0,0), (1,0), (2,0)$水平形成一条直线。 在这里，所有连续的对都是有效的，但有间隙的对，例如$(0,0)$到$(2,0)$，仅在以下情况下才有效$(1,0)$是黑色的。 仅检查端点而不考虑内部点的简单解决方案会过度计算。 

## 方法

 蛮力方法将迭代所有$O(n^2)$点对并检查连接它们的最短路径上的每个点。 由于沿路径的点数可以是$O(|x_i - x_j| + |y_i - y_j|)$，这种方法很快就会变得棘手； 即使距离很短，也会超过$10^{10}$最大测试用例的操作。 

降低复杂性的关键观察来自于沿 x 轴和 y 轴的分离运动。 任何最短路径都限制在与轴对齐的矩形内。 如果我们按 x 坐标对点进行排序并考虑共享相同 y 坐标的点，则有效路径要求该线上的所有连续 x 值均为黑色。 类似地，按 y 排序并考虑 x 坐标一致性可确保覆盖所有垂直步骤。 

实际上，问题简化为沿着每行和每列黑点进行计数，其中连续点之间不存在间隙。 对于沿直线的坐标排序列表，有效对的数量是组合的：如果有$k$连续点在行或列上，它们贡献$k(k-1)$有序对。 这是因为任何点都可以沿着行或列与其右侧（或上方）的任何其他点配对，从而给出无间隙的有序对的总数。 

在计算水平和垂直对齐对后，存在微妙的重叠：形成轴对齐矩形的点贡献了多次。 该解决方案必须仔细计算不丢失内部点的路径，但是如果维持连续条件，沿行和列的组合方法可以保证所有最短路径点都存在。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 * d) | O(n) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取测试用例的数量并迭代每个用例。 对于每个测试用例，将黑点存储在元组列表中$(x, y)$并且也在一组中用于快速查找。 该集合允许$O(1)$检查坐标是否存在。 
2. 构建字典以按 x 坐标和 y 坐标对点进行分组。 每个字典将坐标映射到相应的其他坐标的排序列表。 例如，`rows[y] = sorted list of x`和`cols[x] = sorted list of y`。 排序可以保证我们能够快速找到连续且没有间隙的点。 
3. 对于每一行（固定 y 坐标），迭代其 x 值的排序列表。 计算相差为1的连续点。每个连续段的长度$k$贡献$k * (k-1)$有序对。 这说明了所有中间点都存在的所有水平路径。 
4. 使用排序后的 y 值对每列（固定 x 坐标）重复相同的计数过程。 这说明了垂直路径。 将这些计数合并到测试用例的总数中。 
5. 由于共享 x 或 y 的两点之间的每条最短路径均由上述计数捕获，因此总数是所有水平和垂直有效对的总和。 
6. 输出每个测试用例的总计。 

通过维持以下不变量来保证正确性：如果一条线段上的所有整数点都是黑色，则我们仅对对进行计数。 通过对坐标进行排序并计算连续序列，我们可以避免间隙并确保只有有效的最短路径才起作用。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import defaultdict

def good_robot_paths():
    t = int(input())
    for _ in range(t):
        n = int(input())
        points = []
        rows = defaultdict(list)
        cols = defaultdict(list)
        for _ in range(n):
            x, y = map(int, input().split())
            points.append((x, y))
            rows[y].append(x)
            cols[x].append(y)
        
        total = 0
        for y, xs in rows.items():
            xs.sort()
            length = 1
            for i in range(1, len(xs)):
                if xs[i] - xs[i-1] == 1:
                    length += 1
                else:
                    total += length * (length - 1)
                    length = 1
            total += length * (length - 1)
        
        for x, ys in cols.items():
            ys.sort()
            length = 1
            for i in range(1, len(ys)):
                if ys[i] - ys[i-1] == 1:
                    length += 1
                else:
                    total += length * (length - 1)
                    length = 1
            total += length * (length - 1)
        
        print(total)

good_robot_paths()
```第一部分读取输入并为行和列分组构建字典。 排序可确保检测到连续的序列。 主计数循环处理由间隙分隔的段并对贡献求和。 注意我们初始化`length = 1`对于至少一个点的线段，我们记得在完成循环后添加最后一段，以避免最后丢失对。 使用`defaultdict(list)`避免重复检查密钥是否存在。
