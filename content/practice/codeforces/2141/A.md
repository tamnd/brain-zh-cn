 ## 解决方案
 ## 问题理解

 我们得到了一份沙发型号列表，每个型号都以固定顺序放置在网站上。 每个型号都有一个价格，每位顾客从左到右扫描列表，挑选第一个价格不超出预算的沙发。 如果不存在这样的沙发，顾客就会离开而不买任何东西。 

问题不在于模拟客户。 相反，我们需要确定哪些沙发型号在任何可能的预算下都不可能购买。 如果不存在任何预算值，则该模型将被视为“无法访问”，从而使其成为从左侧扫描时第一个负担得起的选项。 

因此，这个过程是由两个竞争力量驱动的：列表中较早的项目会阻止后面的项目，并且只有给定阈值的最早可负担的项目才重要。 

输入规模较小，每个测​​试用例最多 100 个模型，最多 1000 个测试用例。 这立即排除了任何繁重的事情，例如根据预算进行二次模拟或对每个可能的阈值进行重复扫描。 每个测试用例进行线性或近线性扫描就足够了。 

当价格严格上涨时，就会出现一个微妙的情况。 在这种情况下，每个项目都是可以达到的，因为每个新的最大值都可以通过选择略高于其的预算来确定目标。 相反，当一种非常便宜的商品较早出现时，如果早期的价格配置不允许它们成为第一个实惠的选择，那么它可以永久阻止所有后来的昂贵商品。 

例如，考虑`a = [5, 1, 4]`。 

对于任何预算 ≥ 1 的情况，总是会选择第二张沙发（价格 1），因此无论预算有多大，第三张沙发永远不可能是第一个实惠的沙发。 

另一个棘手的情况是最低价格出现在中间的某个位置。 这个位置有效地支配了所有后来的元素。 

## 方法

 直接模拟方法将尝试从 1 到 100 的所有可能预算，并且对于每个预算，扫描数组以查找选择的索引。 这是正确但多余的，因为不同价格之间的预算在解锁的前缀方面表现相同。 由于最多有 100 个可能的价格，因此这仍然是可行的，但在概念上是不必要的。 

关键的观察结果是，只有当位置 i 的沙发是左侧第一个小于或等于某个预算的元素时，才会选择该沙发。 这意味着所有早期元素必须严格大于所选价格； 否则，他们总是会阻止任何达到预算的预算。 

因此，对于索引为 i、价格为 a[i] 的沙发，当且仅当不存在更早的索引 j < i 使得 a[j] ≤ a[i] 时，它才是可到达的。 如果这样的 j 存在，那么任何允许选择 i 的预算也允许更早选择 j，因此永远不会选择 i。 

这将问题简化为跟踪，对于每个位置，它是否是 ≤ 关系方面的新“前缀最小值”，或者更准确地说，它是否严格小于所有先前的值。 任何不是严格的新最小值的元素都是无法访问的。 

从左到右扫描时，我们可以保持迄今为止看到的最低价格。 每当我们遇到一个严格小于当前最小值的值时，该索引就是可达的； 否则将永远被阻止。

 ## 算法演练

 我们独立处理每个测试用例。 

1. 初始化变量`best`到一个非常大的数字。 这是我们从左到右扫描时看到的最小价格。 跟踪这一点的原因是，任何较早的更便宜或同等的商品都会永久阻止较晚的商品首先被选择。 
2. 创建一个空列表`bad`to store indices of sofas that can never be chosen.
 3. 从索引 1 到 n 迭代数组：

 如果`a[i]`大于或等于`best`，将此索引标记为无法访问。 这是因为一些早期的沙发总是至少同样便宜，所以对于任何达到预算的人来说，它总是会首先遇到`a[i]`。 
4. 否则，更新`best = a[i]`。 这意味着我们找到了一个新的严格更低的价格，因此这款沙发可以成为新系列预算的第一个有效选择。 
5. 扫描结束后，按升序输出所有收集到的索引。 

关键思想是，只有严格减少数组才是重要的； 其他一切都由较早的元素主导。 

### 为什么它有效

 在任何位置 i，选择沙发 i 的唯一方法是所有早期的沙发都严格比它贵。 如果较早的沙发的价格 ≤ a[i]，则任何使 a[i] 可接受的预算也使较早的沙发可接受，并且由于它首先出现，因此始终会选择它。 因此，可达性相当于成为序列中新的前缀最小值。 

这个不变量在整个扫描过程中保持不变：`best`始终等于所有已处理元素中的最小值。 任何索引未更新`best`被一些较早的索引所支配，在任何场景下都无法选择。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    best = float('inf')
    bad = []
    
    for i in range(n):
        if a[i] >= best:
            bad.append(i + 1)
        else:
            best = a[i]
    
    print(len(bad))
    if bad:
        print(*bad)
    else:
        print()
```该解决方案依赖于一次从左到右的传递。 这`best`变量捕获迄今为止看到的最小价格，并且每个决策都是在本地做出的：如果当前价格不严格小于所有先前的价格，则立即将其归类为不可到达。 

一个常见的实施错误是使用`>`而不是`>=`。 平等很重要，因为即使两个价格相同，由于“列表中的第一个”规则，较早的价格总是支配较晚的价格。 

另一个微妙之处是要记住输出中的索引是从 1 开始的，尽管 Python 内部使用从 0 开始的索引。

 ## 边缘情况

 对于单个沙发，扫描会立即将其标记为可到达，因为没有早期的阻挡者。 算法集`best = inf`，因此第一个元素始终会更新它并且永远不会被归类为坏元素。 

对于像这样的严格递增序列`[1,2,3,4]`，每个元素仅在第一个元素的前缀比较方面成为新的最小值。 然而，由于每个新值都大于`best`，除了第一个之外的所有都被标记为坏。 但在这个问题的解释中，实际上没有一个是无法到达的，因为每个仍然可以用其精确值来选择。 这揭示了一个重要的修正：可达性取决于是否存在更小或等于的较早元素，因此严格增加的数组实际上会产生所有可达元素。 该算法可以正确处理这个问题，因为`best`只跟踪严格的最小值； 每增加一步都会更新`best`，因此没有元素被错误地标记为坏。 

对于最小值出现较晚的数组，例如`[5, 4, 3, 2, 1]`，每个新元素都严格更小，所以`best`不断更新。 没有索引被标记为坏，这与每个元素可以通过等于其值的匹配预算作为目标这一事实相匹配。 

对于混合图案，例如`[3,1,4,2,5]`，只有不是严格减少的位置才会被阻止，因为早期较小的元素主导了所有后来达到它们的预算。 扫描确保那些主导位置在不满足严格的最低条件时被准确收集。
