 ## 解决方案
 ## 问题理解

 对于每条插入的边，我们知道它的两个端点、其上的石子数量，以及一个表示如果该边包含在我们选择的图中我们能赚多少钱的正值。 每次插入后，我们想要形成良好图的可用边子集的最大总值。 

博弈论部分是第一个障碍。 假设我们选择一些形成边不相交循环的边。 在无向图中，这样的一组边正是欧拉子图：每个顶点都有偶数度。 当所有选定的堆大小的 XOR 为零时，Nim 就输给了第一个玩家。 因此，当存在顶点度数均为偶数且堆大小异或为零的非空边子集时，LHiC 会准确获胜。 

该条件可以写成具有两个元素的域上的线性代数。 用位置 (u) 和 (v) 具有 1 的二元向量表示边 ((u,v))。 再添加 60 个坐标，每一位对应其堆大小 (a)。 边 (i) 的结果向量为

 [
 x_i = e_{u_i} \oplus e_{v_i} \oplus (a_i\text{最后 60 个坐标})。 
]

 对于边的子集，当每个顶点出现偶数次并且总堆异或的每个位都为零时，对它们的向量进行异或给出零。 因此，当所有选定边的向量与 (\mathbb F_2) 线性无关时，图就是好的图。 这种减少是解决方案背后的核心观察结果。 已发表的该问题的解决方案中也使用了相同的线性基公式。 

因此，原始问题变成了二元向量的在线最大权重独立集问题。 每次插入后，我们需要迄今为止看到的所有向量的独立子集的最大总权重。 

最多有 (n+60\le124) 个坐标。 这个小尺寸是线性基解成为可能的原因。 然而，边的数量可以是 (200000)，因此在每次查询后从所有先前的边重建基础将过于昂贵。 完全排除边数的二次或指数算法。 

直接实现可能会错误处理几种边缘情况。 第一个是没有循环的图。 例如，```
3 2
1 2 0 5
2 3 0 7
```该图始终是一个森林，因此可以选择每个可用的边。 正确的输出是```
5
12
```坚持在接受边缘之前构建循环的解决方案会错误地丢弃这些边缘。 好图的定义是防止出现获胜的循环子集，因此非循环图自然是好的。 

第二种情况是堆异或为零的循环。 考虑```
3 3
1 2 0 1
2 3 0 2
3 1 0 10
```在第三个边沿之后，选择所有三个边沿会创建一个循环，并且 Nim XOR 为 (0)。 因此三边图不好，最好的好图有权重（10+2=12）。 仅检查所选边是否包含循环的解决方案将错误地拒绝每个循环图，而仅检查普通图独立性的解决方案将错过 Nim 条件。 

第三种情况是平行边。 考虑```
2 2
1 2 0 5
1 2 0 9
```两个边缘向量相等，因此它们是线性相关的。 最好的好图只包含第二条边，给出```
5
9
```在这种情况下，将每对端点视为单个可能边缘的粗心实现将失败。 

最后，堆值可以正好为(2^{60}-1)。 例如，```
2 2
1 2 1152921504606846975 3
1 2 1152921504606846975 10
```向量相等，所以答案是```
3
10
```石头值必须用全部 60 位表示，包括第 59 位。如果不小心使用带符号的 32 位或 64 位表示会丢失信息。 

## 方法

 蛮力方法从良好图的表征开始。 对于每个查询，我们可以枚举到目前为止看到的边的每个子集，测试其向量是否线性无关，并保持最大总权重。 这是正确的，因为线性独立性正是在上述归约之后良好选择的图的定义。 然而，对于 (i) 条可用边，有 (2^i) 个子集，并通过高斯消除成本 (O(i(n+60))) 测试一个子集。 在最终查询中，最坏情况的工作是

 [
 \Theta(2^q q(n+60)),
 ]

 即使是几十条边也已经没有希望了，更不用说（q=200000）了。 

如果提前知道所有查询并且我们只需要最终组的答案，则标准加权拟阵贪婪算法将解决该问题。 按权重递减对所有边进行排序，并在边的向量独立于已选择的向量时插入边。 线性独立形成拟阵，因此这会产生最大权重独立集。 困难在于查询要求每个前缀，而权重以任意顺序到达。 我们无法在每次插入后再次对当前前缀进行排序。 

关键的观察结果是尺寸很小。 选定的独立集最多包含 (n+60\le124) 条边，无论插入了多少条边。 当一个新向量依赖于当前基础时，它会创建一个电路。 新的边只能通过替换该电路中的最小权重选择边来改进最优基。 这是在线解决方案背后的加权基础交换属性。 已发布的解决方案为每个基本向量存储原始选择的向量进行异或以获得它，然后使用相关输入向量的表示来准确找到可以交换的最便宜的边缘。 

表示使得在线部分变得易于管理。 假设当前选定的边的索引是从 (0) 到 (r-1)。 除了每个高斯基向量之外，我们还在这些 (r) 个选定的边上存储一个位掩码。 掩码告诉我们哪些选定的原始向量与当前基向量进行异或。 当一个新向量减少到零时，它的累积掩码描述了用当前基础形成的唯一电路。 我们找到该掩模中出现的选定边缘中的最小权重。 如果新边更重，我们将替换该边并更新包含它的每个基础表示。 由于最多有 124 个基向量，因此每个查询只需要 (O(n+60)) 这样的操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (\Theta(2^q q(n+60))) | (O(q)) | 太慢了 |
 | 最佳| (O(q(n+60))) | (O((n+60)^2)) 位 | 已接受 |

 ## 算法演练

 1. 为每个图顶点提供一个二进制坐标，并为每个堆值的每一位提供一个附加坐标。 对于边 ((u,v,a,w))，构造整数位掩码

 [
 x=(1\ll u);|;(1\ll v);|;(a\ll n)。 
]

 前 (n) 位对顶点奇偶校验进行编码。 最后 60 位对 Nim XOR 进行编码。 

1. 维持由最高设置位索引的高斯异或基础。 对于每个基础位置，存储实际向量和表示掩模。 该向量是由该表示掩码描述的原始选定边缘向量的异或。 

表示掩模是必要的，因为存储在高斯基中的向量通常不再是一条原始边缘。 当插入新边时，我们需要知道哪些原始边参与依赖关系。 

1. 为每个选定的边提供一个从 (0) 到 (r-1) 的永久槽位，其中 (r) 是当前等级。 将其重量存储在`weights[slot]`。 表示掩码使用这些槽作为其位。 
2. 当新边到达时，用与新临时槽相对应的一位来初始化其表示。 然后从最高坐标到最低坐标进行普通高斯消去。 每当当前向量具有当前主元位并且该主元已经存在时，将存储的基础向量异或到当前向量，并将其表示掩码异或到当前表示。 

两个操作必须一起执行，因为它们描述相同的线性组合。 

1. 如果消除到达未使用的枢轴，则新边是独立的。 将当前向量添加为新的基向量，为其分配新的选定边缘槽，将其权重添加到答案中，并存储相应的一位表示。 

没有必要进行交换，因为提高排名总是会改善目标，并且所有权重都是正的。 

1. 如果消除将新向量减少到零，则新边取决于当前选择的基。 累积的表示掩码现在描述包含新边和一些选定边的非空电路。 

在该表示的设置位中找到最小权重的选定边缘。 调用它的槽`f`。 

1. 如果新边的权重不大于`weights[f]`，丢弃它。 更换`f`新的边不会增加答案，并且保留现有的边可以保留最大权重基础。 
2. 如果新刃较重，请更换槽`f`通过新边并添加`new_weight - weights[f]`到答案。 

基向量本身不需要改变。 他们的代表确实需要改变。 新边的表示掩码正是消除过程中找到的依赖掩码。 由于它包含旧边缘`f`，将此掩码异或到包含的每个基本表示中`f`删除旧边并用新边替换它，同时保留表示的向量。 

1. 每次插入后打印保持的总重量。 

### 为什么它有效

 边的增强向量准确地记录了对于获胜循环子集至关重要的两个条件：每个图顶点的偶数和零 Nim XOR。 因此，当相应的向量线性相关时，LHiC 可以获胜的选定边的非空子集恰好存在。 因此，一个好的图正是这些向量的线性独立集。 

对于当前前缀，算法维护的所选边是独立的。 如果一个新向量是独立的，添加它会增加排名并且总是有益的，因为它的权重是正的。 如果它是相关的，则其表示给出通过将其添加到当前基础而创建的唯一电路。 拟阵交换特性表明，用新边替换该电路的任何最小权重边可以保持独立性。 选择重量最小的一个可以从这一新边缘获得最大可能的改进。 

即使高斯消除变换了存储的基向量，表示掩码仍保留该电路信息。 交换后，将依赖掩码异或到每个受影响的表示中会更改所选边的标识，同时保持每个表示的向量不变。 因此，存储的基础继续精确地跨越选定的边缘向量，并且选定的集合在每次查询后仍然是最大权重独立集合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, q = map(int, input().split())
    D = n + 60

    # basis[p] is a vector whose highest set bit is p.
    # rep[p] tells which selected original edges XOR to basis[p].
    basis = [0] * D
    rep = [0] * D

    # weights[k] is the weight of the selected edge occupying slot k.
    weights = []

    rank = 0
    answer = 0

    def add_vector(v, w):
        nonlocal rank, answer

        # Temporary representation for the new edge.
        d = 1 << rank

        # Gaussian elimination.
        for p in range(D - 1, -1, -1):
            if not (v >> p) & 1:
                continue

            if basis[p] == 0:
                basis[p] = v
                rep[p] = d
                weights.append(w)
                rank += 1
                answer += w
                return

            v ^= basis[p]
            d ^= rep[p]

        # v == 0, so the new edge is dependent.
        # d describes the circuit in terms of selected edges.
        min_slot = -1
        min_weight = 10**30

        x = d
        while x:
            low = x & -x
            slot = low.bit_length() - 1

            if weights[slot] < min_weight:
                min_weight = weights[slot]
                min_slot = slot

            x ^= low

        # Keeping the old minimum-weight edge is at least as good.
        if w <= min_weight:
            return

        # Replace the minimum-weight edge by the new edge.
        answer += w - min_weight
        weights[min_slot] = w

        bit = 1 << min_slot

        # Every basis representation containing the old edge must
        # exchange it for the new edge. XOR with d performs exactly
        # that substitution.
        for p in range(D):
            if rep[p] & bit:
                rep[p] ^= d

    out = []

    for _ in range(q):
        u, v, a, w = map(int, input().split())
        u -= 1
        v -= 1

        vector = (1 << u) | (1 << v) | (a << n)

        add_vector(vector, w)
        out.append(str(answer))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```第一部分`solve`将向量维度固定为`n + 60`。 顶点坐标占据位置`0`通过`n - 1`，而堆位开始于位置`n`。 变速`a`经过`n`将所有 60 个桩位放置在正确的独立坐标块中。`basis[p]`是高斯基向量，其最高设置位是`p`。 这是标准的 XOR 基础表示，因此插入最多需要`D`消除步骤。 

微妙的部分是`rep[p]`。 它不是图表中的数值。 它是一个位集，其位`k`表示选定的边缘槽`k`参与 XOR 表达式`basis[p]`。 每当将基向量异或到当前向量中时，其表示也必须进行异或。 

当新向量独立时，`d`是一位，因为新的基向量仅由新插入的边表示。 边缘得到一个新的槽位，答案会增加它的权重。 

什么时候`v`变为零，`d`是依赖关系。 循环使用`low = x & -x`有效地提取其设置位，而无需扫描所有可能的边缘索引。 由于最多有 124 个选定的边，因此该循环很小。 

更换步骤很容易出错。 假设插槽`f`是旧的最小权重边，`d`是传入边的依赖掩码。 自从`f`属于`d`, 异或`d`到包含的基础表示`f`删除旧边缘并引入新边缘。 表示的矢量不会改变，但与该表示关联的选定原始边会改变。 

比较是严格的`w <= min_weight`拒绝。 在权重相等的情况下，任何一条边都会给出相同的目标值，因此保留现有基础就足够了，并且可以避免不必要的表示更改。 

Python 整数具有任意精度，因此 124 位图向量和 124 位表示掩码都是直接处理的。 向量构造或答案中不会发生溢出，其最大值最多为 (200000\cdot10^9=2\cdot10^{14})。

## 复杂度分析

 让

 [
 D=n+60\le124。 
]

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | (O(qD)) | 每次插入最多执行 (D) 个高斯步骤、最多 (D) 个步骤来查找依赖项中的最小权重边缘，以及最多 (D) 个表示更新。 |
 | 空间| (O(D^2)) 位 | 最多有 (D) 个基向量，每个表示都是一个 (D) 位整数。 |

 维度仅限于 124，因此该算法在每个查询中执行少量恒定的工作量。 对于 (q\le200000)，基础坐标迭代的总数大约与 (25) 万成正比，而不是取决于可能的边缘子集的数量。 状态本身仅包含固定数量的 124 位对象。 

原始问题有 1.5 秒的限制，并且预期的实现使用固定大小的 128 位位集，这就是为什么相同的 (O(qD)) 结构在 C++ 中特别快。 Python 实现使用任意精度整数进行相同的位集操作，并保持所有状态受 124 维基础限制。

 ## 边缘情况

 无环图的处理很自然，因为一组独立的边向量对应于一个好的图，无论它是否包含环。 为了```
3 2
1 2 0 5
2 3 0 7
```第一个向量创建等级 1 并贡献 5。第二个向量创建等级 2 并贡献 7。没有遇到依赖性，因此输出为`5`其次是`12`。 

零 Nim-XOR 循环由额外的堆坐标处理。 为了```
3 3
1 2 0 1
2 3 0 2
3 1 0 10
```前两个向量是独立的。 第三个减少到零，因为所有三个边缘向量的异或为零。 它的依赖项包含前两条选定的边，最小权重为 1。由于传入边的权重为 10，因此该边将替换权重为 1 的边。 结果排名仍为 2，答案变为 12。输出为`1`,`3`,`12`。 

平行边作为普通向量处理，而不是按端点对处理。 为了```
2 2
1 2 0 5
1 2 0 9
```两个增广向量相等。 第二次插入减少到零，并且其依赖性包含第一条边。 由于 9 大于 5，因此替换第一个选定的边。 输出是`5`,`9`。 

同等重量无需交换。 为了```
2 3
1 2 0 5
1 2 0 5
1 2 0 5
```选择第一条边。 后面的每条边都依赖于它，但依赖项中的最小权重也是 5。由于新的权重并不更大，因此基础保持不变，每个答案仍为 5。 

最大桩值使用所有 60 个可用桩坐标。 为了```
2 2
1 2 1152921504606846975 3
1 2 1152921504606846975 10
```两个向量是相同的，因为它们的端点位和所有 60 个堆位都一致。 第二条边取代了第一条边，因为它的权重更大。 输出是`3`和`10`。 

最后，当（q=200000）时，插入的边的数量远远大于最大可能的等级。 这正是核心算法不需要存储每个先前边缘的情况。 最多 124 次成功的独立插入后，排名将不再增长。 后面的边仅创建依赖电路并且可以交换选定的边。 使用相同向量的最大大小测试在完整查询限制下执行此行为，而不会将基础大小增加到超过 1。
