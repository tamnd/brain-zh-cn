 ## 解决方案
 ## 问题理解

 我们得到一个三角形面的集合，每个三角形仅由三个整数顶点 ID 描述。 这些 ID 不以除标识之外的任何有意义的方式表示几何图形。 如果两个三角形共享整条边，则它们被视为相邻，这意味着它们恰好有两个共同的顶点 ID。 这个问题中的“3D 模型”只是三角形上这种邻接关系下的连通分量。 

任务是将所有三角形分组为这样的连接组件，其中连接性是通过三角形之间的共享边定义的，然后报告存在多少个组件以及每个组件的大小。 

重要的抽象转变是我们根本不涉及几何。 我们正在处理一个图，其中节点是三角形，并且当两个三角形共享一对顶点时存在边。 

约束很严格：所有测试用例中的三角形总数最多为 100000 个。这立即排除了三角形之间的任何二次比较。 简单的成对检查需要比较每对三角形，在最坏的情况下大约需要 10^10 次操作，远远超出了限制。 任何有效的解决方案都必须确保每个三角形仅被处理少量恒定次数，最好是每次操作的对数或摊销常数。 

一个微妙的陷阱是认为邻接取决于完全顶点重叠或几何重合。 事实并非如此。 只有精确的共享对才重要。 另一个微妙的问题是假设共享顶点意味着连通性。 这是错误的：三角形必须共享一条边，而不仅仅是一个顶点。 例如，三角形 (1,2,3) 和 (1,4,5) 共享一个顶点，但不相连。 

最后，该图不一定是平面的或结构良好的。 一条边可以属于许多三角形，形成密集的局部簇。 任何依赖几何直觉的解决方案都会失败。 

## 方法

 一种直接的方法是比较每对三角形并检查它们是否共享两个顶点。 这是正确的，因为它直接实现了连接的定义。 然而，检查所有对的邻接性会导致 O(n^2) 比较，并且每次比较都需要检查集合交集或排序比较，这使得在实践中速度更慢。 当n达到100000时，这是不可能的。 

关键的洞察力是颠倒视角。 我们不是问两个三角形是否相连，而是问哪些三角形可以通过共享边相连。 每个三角形恰好包含三个边，并且每个边都可以表示为一对无序的顶点 ID。 如果两个三角形共享一条边，则它们共享该边的相同无序对表示。 

因此，我们不是将三角形相互比较，而是将边映射到包含它们的三角形。 每条边都成为一个关键，所有共享该关键的三角形都通过该边连接。 这使我们能够隐式构建连接图。 

一旦我们有了这个映射，我们就可以使用不相交的并集结构来合并共享任何边的三角形。 每个边组连接包含它的所有三角形。 处理完所有边后，每个 DSU 组件都与一个连接的 3D 模型精确对应。 

这将问题从三角形的成对比较减少到三角形边缘的线性处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 边缘哈希+DSU | O(n α(n)) | O(n α(n)) | O(n) | 已接受 |

 ## 算法演练

 我们将每个三角形视为不相交集联合结构中的一个节点。 目标是在节点共享边时合并节点。

1. 初始化一个包含 n 个元素的 DSU 结构，每个三角形一个。 每个三角形都从其自己的组件开始，因为最初没有已知的连接。 
2. 对于每个三角形，枚举它的三个边。 每条边都表示为排序对 (min(u, v), max(u, v))。 排序是必要的，因为边是无向的，并且 (u, v) 必须与 (v, u) 同等对待。 
3.维护从边到与该边见过的第一个三角形索引的散列图。 当我们第一次遇到一条边时，我们存储它的三角形索引。 
4. 当我们在另一个三角形中再次遇到相同的边时，我们将当前三角形与先前存储的三角形合并。 这可确保共享该边的所有三角形最终位于同一 DSU 组件中。 
5. 处理完所有三角形和边后，迭代所有三角形并找到它们的 DSU 根。 计算每个根组件的大小。 
6. 收集所有组件尺寸并按升序对它们进行排序以便输出。 

关键的想法是，每个共享边都会在包含它的所有三角形之间产生传递连接。 通过第一次出现的联合，我们有效地在每个边缘组内构建了一个星形结构，这足以实现连接。 

### 为什么它有效

 每个三角形都属于通过共享边的可达性定义的组件。 每当两个三角形共享一条边时，它们就直接相连，并且必须属于同一个组件。 DSU 保证一旦两个节点联合，它们将保持在同一集合中，从而保留这种连接关系。 

相反，如果两个三角形通过共享边链连接，DSU 将沿着该链逐步合并它们。 因此，每个最终的 DSU 集完全对应于通过边共享连接的最大三角形集，这与问题中 3D 模型的定义相匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        dsu = DSU(n)
        edge_map = {}

        for i in range(n):
            a, b, c = map(int, input().split())

            e1 = (a, b) if a < b else (b, a)
            e2 = (a, c) if a < c else (c, a)
            e3 = (b, c) if b < c else (c, b)

            for e in (e1, e2, e3):
                if e in edge_map:
                    dsu.union(i, edge_map[e])
                else:
                    edge_map[e] = i

        comp = {}
        for i in range(n):
            r = dsu.find(i)
            comp[r] = comp.get(r, 0) + 1

        sizes = sorted(comp.values())
        print(len(sizes))
        print(*sizes)

if __name__ == "__main__":
    solve()
```DSU 用于维护三角形的连通分量。 并集操作仅在我们检测到重复边缘时发生，这确保了正确性而没有冗余合并。 

每个三角形恰好生成三个边，并且通过对其端点进行排序来标准化每个边，以便相同的边映射到相同的键。 哈希图每条边仅存储一个代表性三角形，这已经足够了，因为连接性是可传递的。 

最后的循环压缩 DSU 代表并计算组件大小。 输出规范要求排序。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import defaultdict

    class DSU:
        def __init__(self, n):
            self.p = list(range(n))
            self.s = [1]*n
        def f(self,x):
            while self.p[x]!=x:
                self.p[x]=self.p[self.p[x]]
                x=self.p[x]
            return x
        def u(self,a,b):
            a,b=self.f(a),self.f(b)
            if a==b:return
            if self.s[a]<self.s[b]:a,b=b,a
            self.p[b]=a
            self.s[a]+=self.s[b]

    T = int(input())
    out = []
    for _ in range(T):
        n = int(input())
        dsu = DSU(n)
        mp = {}
        for i in range(n):
            a,b,c = map(int,input().split())
            for e in [(min(a,b),max(a,b)),(min(a,c),max(a,c)),(min(b,c),max(b,c))]:
                if e in mp:
                    dsu.u(i, mp[e])
                else:
                    mp[e]=i
        comp = {}
        for i in range(n):
            r = dsu.f(i)
            comp[r]=comp.get(r,0)+1
        sizes = sorted(comp.values())
        out.append(str(len(sizes)))
        out.append(" ".join(map(str,sizes)))
    return "\n".join(out)

 ## 边缘情况

 一个微妙的情况是，连接是通过共享边缘链形成的，而不是直接共享。 考虑：```
1 2 3
1 2 4
4 2 3
```三角形 0 通过边 (1,2) 连接到 1。 三角形 1 通过边 (2,4) 连接到 2。 尽管三角形 0 和 2 不直接共享边，但它们通过三角形 1 连接。DSU 正确地逐步合并它们，生成单个组件。 

另一种边缘情况是许多三角形共享同一条边。 例如：```
1 2 3
1 2 4
1 2 5
1 2 6
```所有三角形共享边 (1,2)，因此它们必须全部位于一个组件中。 哈希图将第一个三角形以及每个后续三角形并集存储到其中，从而构建单个连接集。 

最后的边缘情况是完全隔离，没有边缘重复。 在这种情况下，每个三角形仍保留其自己的 DSU 集，并且输出为 n 个分量，每个分量的大小为 1。
