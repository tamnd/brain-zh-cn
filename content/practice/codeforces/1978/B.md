 ## 解决方案
 ## 问题理解

 在这个问题中，鲍勃试图通过特别促销来最大化销售面包的利润。 他有`n`包子卖，正常价格`a`每个面包和促销参数`b`。 促销允许他选择一个整数`k`并出售第一个`k`面包价格从`b`下降到`b - k + 1`。 剩下的包子，如果有的话，按平时的价格出售`a`。 任务是确定Bob通过选择最优的能够获得的最大总利润`k`。 

输入由多个测试用例组成。 每个测试用例给出`n`,`a`， 和`b`。 输出是每种情况的最大利润。 自从`n`,`a`， 和`b`可以大到`10^9`最多有`10^4`测试用例中，任何迭代单个面包的解决方案都太慢。 每个测试用例我们需要一个恒定时间公式以保持在时间限制内。 

当出现微妙的边缘情况时`b`相对于非常小或非常大`a`和`n`。 例如，如果`b <= a`，以促销价出售任何包子都不会增加利润。 相反，如果`b`由于规模巨大，因此在促销活动允许的范围内销售尽可能多的面包可能是最佳选择。 尝试所有值的简单解决方案`k`会超时，因此需要直接计算。 

## 方法

 天真的方法迭代`k`从 0 到`min(n, b)`，计算第一个的总和`k`降低价格，补充道`(n - k) * a`，并跟踪最大值。 这是正确的，但需要最多`10^9`在最坏的情况下每个测试用例的操作，这是不可行的。 

最佳方法来自于总利润函数的观察`k`是二次且凹的。 利润为`k`包子以促销价出售`sum_{i=1}^k (b - i + 1) = k * b - k*(k-1)/2`。 剩下的面包给`(n - k) * a`。 结合这些，总利润函数为`profit(k) = k*b - k*(k-1)/2 + (n - k)*a`。 这是一个凹二次函数`k`，因此最大值出现在边界或顶点处。 顶点位于`k = b - a`， 但`k`仅限于`[0, min(n, b)]`。 因此，最优的`k`是`max(0, min(b - a, min(n, b)))`。 

这将问题减少到每个测试用例一次计算，无需循环。 可以在常数时间内直接计算算术公式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（迭代 k）| O(n) | O(1) | O(1) | 太慢了 |
 | 直接计算公式 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`,`a`， 和`b`。 
3. 计算促销包子的候选数`k`作为`b - a`。 这来自于二次利润函数的微分； 这是无约束的最优值。 
4. 夹钳`k`到可行的范围`[0, min(n, b)]`使用`max(0, min(k, min(n, b)))`。 
5. 计算第一个的利润`k`面包作为价格下降的总和：`k * b - k * (k - 1) // 2`。 
6. 计算剩余的利润`n - k`包子的价格`a`:`(n - k) * a`。 
7. 将两个分量相加得到总利润。 
8. 打印利润总额。 

为何有效：利润函数为`k`是凹二次方程，因此最大值出现在顶点或边界处。 夹紧`k`确保我们尊重包子的数量和促销限制。 通过公式计算总和可以避免循环并确保每个测试用例的计算量为 O(1)。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    results = []

    for _ in range(t):
        n, a, b = map(int, input().split())
        k = b - a
        k = max(0, min(k, n, b))
        profit = k * b - k * (k - 1) // 2 + (n - k) * a
        results.append(str(profit))

    sys.stdout.write("\n".join(results) + "\n")

solve()
```### 解释

 该代码使用有效地读取所有测试用例`sys.stdin.readline`。 对于每种情况，它都会使用派生公式计算促销面包的最佳数量。 夹紧确保`k`尊重所有限制。 第一个的总和`k`价格下降是使用算术级数公式计算的。 剩下的包子乘以平时的价格。 最后收集并打印结果以提高效率。

 ## 边缘情况

 当`b <= a`，计算出的`k`变为负数。 钳位到零可确保促销期间不会售出任何面包，这是最佳的。 例如，`n=10, a=10, b=5`结果`k = max(0, min(-5, 10, 5)) = 0`。 利润为`10*10 = 100`，符合预期结果。 同样，当`b`超过`n`，夹紧确保`k <= n`以免包子数量过多。 这保证了所有边界条件的正确性。
