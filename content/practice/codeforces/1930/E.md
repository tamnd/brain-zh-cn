 ## 解决方案
 ## 问题理解

 我们从数组开始$$[1,2,3,\dots,n].$$一个值$k$整个过程都是固定的。 在一次操作中，我们选择一个长度的子序列$2k+1$。 在这些选定的元素中，我们删除第一个$k$和最后一个$k$，只保留中间的一个。 

由于原始数组严格递增并且我们只删除元素，因此每个最终状态只是一个子序列$[1,2,\dots,n]$。 

任务是：对于每一个$k$从$1$到$\lfloor (n-1)/2 \rfloor$，计算执行任意次操作后可以出现多少个不同的子序列。 

答案必须以模数形式报告$998244353$。 

制约因素很大。 一次测试可以有$n=10^6$，以及所有的总和$n$价值观也是$10^6$。 任何检查单个子序列的算法都是不可能的，因为有$2^n$其中。 甚至一个$O(n^2)$算法将执行大约$10^{12}$最坏情况下的操作。 我们需要一些接近的东西$O(n \log n)$全面的$k$。 

棘手的部分是准确描述哪些子序列是可达的。 

考虑$n=5$和$k=2$。 一个操作选择一个长度的子序列$5$，因此唯一可能的删除操作是删除所选中间元素每一侧的两个元素。 唯一重要的结果是$[3]$。 “任何具有奇数个元素的子序列都是可达的”的天真的想法会错误地计算出许多不可能的数组。 

另一个微妙的情况是$k=1$和后续$[1,4]$在$n=4$。 删除了两个元素，这是$2k$，但仅此还不够。 可达性取决于已删除位置的结构，而不仅仅是其数量。 

问题的核心是找到可达子序列的清晰特征。 

## 方法

 强力解决方案会将每个状态视为一个子序列，并对所有可能的操作执行 BFS。 这是正确的，因为最终会发现每个可到达的数组。 

不幸的是，状态空间已经有$2^n$子序列。 为了$n=30$这已经超过十亿个状态，因此在达到实际限制之前，该方法就变得毫无用处。 

关键的观察结果是，操作仅取决于哪些位置能够幸存。 

用长度为二进制的字符串表示最终的子序列$n$:$$1 = \text{element survives}, \qquad 0 = \text{element deleted}.$$每个操作都精确删除$2k$元素。 因此零的总数必须是$2k$。 

令人惊讶的事实是，这个条件几乎是充分的。 

设删除元素的数量为$2ck$。 当且仅当存在一个存活位置使得至少$k$删除的元素位于其左侧并且至少$k$删除的元素位于其右侧。 

这种特征将问题转化为纯粹的计数问题。 

对于固定的$k$， 让$2ck$是被删除元素的数量。 有$$\binom{n}{2ck}$$二进制字符串正好$2ck$零。 

我们现在计算坏字符串，那些不包含任何幸存位置的字符串至少$k$两边都是零。 

糟糕的配置具有非常僵化的形状。 除了最多$k-1$左端附近最多有 0 个零$k-1$右端附近的零，所有剩余的零必须形成一个连续的块。 将块压缩成单个对象后，我们正在选择位置$2k-1$其中的特殊对象$$n-(2ck-(2k-2))+1$$总持仓量。 这产生$$\binom{n-2ck+2k-1}{2k-1}.$$因此对于固定的$k$,$$\text{answer} = 1+ \sum_{c\ge1} \left( \binom{n}{2ck} - \binom{n-2ck+2k-1}{2k-1} \right).$$额外的$1$对原始数组进行计数，对应于零删除。 

剩下的工作是二项式系数的有效评估。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n)$或者更糟|$O(2^n)$| 太慢了 |
 | 最佳 |$O(n \log n)$总体 |$O(n)$| 已接受 |

 ## 算法演练

 ### 预计算

 1. 预计算阶乘和逆阶乘模$998244353$最多$10^6$。 
2. 使用这些数组，计算任何二项式系数$$\binom{a}{b}$$在$O(1)$时间。 

### 对于每个测试用例

 1. 阅读$n$。 
2. 对于每一个$k$从$1$到$\lfloor (n-1)/2 \rfloor$, 初始化$$ans = 1.$$价值$1$对应于不执行任何操作。 

1. 枚举已删除块的数量：$$c = 1,2,\dots,\left\lfloor \frac{n-1}{2k}\right\rfloor.$$那么正是$2ck$元素被删除。 

1. 将二进制字符串的个数与恰好相加$2ck$删除的职位：$$\binom{n}{2ck}.$$1. 减去不良配置：$$\binom{n-2ck+2k-1}{2k-1}.$$1. 减少模数$998244353$。 
2. 输出该测试用例的所有答案。 

### 为什么它有效

 可到达的最终数组可以仅由幸存位置集表示。 

每个操作都精确删除$2k$元素，因此删除位置的数量必须是$2k$。 可达状态的特征表明，当某个幸存位置至少有$k$删除两边的元素。 

对于固定的删除计数$2ck$，每个二进制字符串要么好，要么坏。 计算所有字符串给出$\binom{n}{2ck}$。 坏字符串正是那些所有多余的零都塌陷到一个中央块中的字符串，从而导致计数$\binom{n-2ck+2k-1}{2k-1}$。 

从所有字符串中减去坏字符串即可得出该删除计数的可到达配置的数量。 对所有有效倍数求和$2k$，并添加未触及的数组，对每个可到达的最终数组精确计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAXN = 10 ** 6 + 5

fact = [1] * MAXN
for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

inv_fact = [1] * MAXN
inv_fact[-1] = pow(fact[-1], MOD - 2, MOD)

for i in range(MAXN - 2, -1, -1):
    inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

def C(n, r):
    if r < 0 or r > n or n < 0:
        return 0
    return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

t = int(input())

for _ in range(t):
    n = int(input())

    res = []

    for k in range(1, (n - 1) // 2 + 1):
        ans = 1

        limit = (n - 1) // (2 * k)

        for c in range(1, limit + 1):
            deleted = 2 * k * c

            ans += C(n, deleted)
            ans -= C(n - deleted + 2 * k - 1, 2 * k - 1)

        ans %= MOD
        res.append(str(ans))

    print(" ".join(res))
```阶乘和反阶乘表针对最大可能值构建一次$n$。 由于模数是素数，费马定理给出了最大阶乘的模逆，所有其他逆阶乘都在一次向后传递中获得。 

功能`C(n, r)`显式处理无效参数。 当压缩计数公式产生负的上限索引时，这可以避免细微的错误。 

对于固定的$k$，变量`c`代表有多少组$2k$发生了删除。 最大有效值为$\lfloor (n-1)/(2k) \rfloor$，因为至少有一个元素必须存活。 

表达式```
C(n - deleted + 2 * k - 1, 2 * k - 1)
```是压缩后错误配置的数量。 得到`-1`这里的术语错误是最常见的差一错误的来源。

 ## 边缘情况

 ### 只能发生一个操作

 输入：```
1
5
```为了$k=2$，唯一可能的删除计数是$4$。 该算法精确计算一项：$$1+\binom{5}{4}-\binom{4}{3} = 1+5-4 = 2.$$答案是正确的`2`，对应原始数组和单例数组`[3]`。 

### 删除次数是以下的倍数$2k$但配置无法访问

 采取$n=4$,$k=1$。 幸存者对应的子序列`{1,4}`删除两个满足整除条件的元素。 一个天真的解决方案会自动计数。 

不良配置减法正好消除了此类情况。 该公式减去所有尚存位置两侧至少有一个已删除元素的二进制字符串。 

这就是为什么最终答案变成`4`而不是更大的错误值。 

### 最大可能$k$什么时候$$k=\left\lfloor \frac{n-1}{2} \right\rfloor,$$内部循环只执行一次，因为$2k$已经接近$n$。 

例如，$n=5, k=2$:$$\left\lfloor \frac{n-1}{2k}\right\rfloor = 1.$$该实现自然地处理这个问题，没有任何特殊情况，避免了求和限制中的边界错误。
