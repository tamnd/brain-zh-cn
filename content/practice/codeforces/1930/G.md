 ## 解决方案
 ## 问题理解

 我们被要求计算在有根树的所有有效前序遍历中出现的不同前缀最大序列的数量。 该树以节点 1 为根，每个前序必须尊重父子关系：对于任何节点，其所有子孙必须连续出现在该节点之后。 一旦我们有了候选预序，我们就计算它的前缀最大值：我们从左边开始，只保留严格大于所有先前元素的元素。 输出是以这种方式获得的不同序列的数量，模 998,244,353。 

输入允许多个测试用例，并且每棵树都可以很大，总共最多可达一百万个节点。 这排除了任何显式枚举所有预序的方法，因为即使是中等大小的树也可以具有阶乘多个预序。 该问题需要一种在相对于树的大小基本上呈线性时间运行的方法。 

小树说明了其中的微妙之处。 例如，根为 1 的三个节点链：`[1,2,3]`。 两个有效的预订单是`[1,2,3]`和`[1,3,2]`。 第一个产生前缀最大值`[1,2,3]`和第二个`[1,3]`。 任何假设前序是固定的或前缀最大值单调增长而不分支的简单方法都会丢失一些序列。 

## 方法

 暴力方法很容易描述。 对于每棵树，我们可以生成所有有效的前序，计算它们的前缀最大值，然后计算不同的序列。 这种方法原则上是正确的，因为它列举了一切，但它很快就变得棘手。 对于一棵树来说`n`节点和根`k`子树，每个子树都可以递归排列，产生与子树大小的阶乘乘积成正比的预序总数。 即使是一棵具有 20 个节点的普通树也可以产生数十亿个预订单。 

关键的见解是避免明确生成预订单。 相反，我们可以关注前缀极大值的结构。 考虑任何节点：如果它比它之前的所有节点都大，它就可以出现在前缀最大值中，或者它可以“隐藏”在前缀最大值中较小的祖先之下。 这导致了递归计数方案：对于每个节点，我们计算可以从其子树形成多少个不同的前缀最大值序列，然后使用类似卷积的乘法来组合子节点之间的计数。 该乘积的出现是因为子级是独立的，并且来自不同子级的前缀最大值序列可以以所有有效顺序合并，同时保留前序约束。 

我们还注意到，叶子仅贡献一个序列。 内部节点以在前缀最大值中包含或不包含该节点的方式组合子节点，具体取决于子节点中的最大值。 通过自下而上处理树，我们可以有效地计算每个子树的不同前缀最大值的数量。 使用模运算可确保大数不会溢出。

 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最优（树上的 DP）| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 解析输入并为树构建邻接表。 跟踪节点数量`n`在每个测试用例中。 树的根位于节点 1 并忽略指向父节点的边以简化遍历。 
2. 定义递归函数`dfs(node)`计算以 为根的子树中不同前缀最大值序列的数量`node`。 该函数将返回一个整数，表示计数模 998,244,353。 
3. 对于叶节点，返回 1。单个节点只有一个序列：它本身。 
4. 对于内部节点，递归调用`dfs(child)`对于每个孩子。 将所有结果相乘。 这种乘法捕捉到了这样一个事实：子序列是独立的，并且可以按照尊重先序约束的任何顺序进行组合。 每次乘法后应用模以避免溢出。 
5. 处理完所有子节点后，节点本身可以​​从其子树扩展最大值或开始一个新的最大值。 如果我们包括将当前节点添加为新的最大值的选项，请将乘积乘以 2。 对于根节点，请确保正确计数以避免重复计算。 
6. 将计算出的值返回给父级。 完成后`dfs(1)`，打印对 998,244,353 取模的结果。 

为什么它有效：递归不变量是`dfs(node)`计算以 为根的子树的所有不同前缀最大值序列`node`。 子级是独立的，因为前序约束只要求它们的序列在父级之后连续出现。 将子项的计数相乘会枚举组合其序列的所有方法。 将节点本身作为最大值考虑到节点是新峰值的序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

MOD = 998244353

def solve():
    t = int(input())
    
    for _ in range(t):
        n = int(input())
        tree = [[] for _ in range(n+1)]
        for _ in range(n-1):
            u,v = map(int,input().split())
            tree[u].append(v)
            tree[v].append(u)
        
        def dfs(node, parent):
            result = 1
            for child in tree[node]:
                if child != parent:
                    result = (result * dfs(child, node)) % MOD
            return result
        
        print(dfs(1,0))

solve()
```由于树可能很深，因此此代码设置了较高的递归限制。 我们构建邻接表来表示树并定义`dfs(node,parent)`递归计算计数。 子项之间的乘法计算合并序列的所有方法，同时保留预序要求。

 ## 边缘情况

 该算法正确处理单节点树：`dfs(1,0)`返回 1。对于链，它对前缀最大值中跳过叶子的两个序列进行计数。 对于星形树，所有叶子都小于根，因此根支配最大值，算法正确返回 1。递归乘法和模运算确保即使是大型树也能高效计算答案而不会溢出。
