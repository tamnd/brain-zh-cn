 ## 解决方案
 ## 问题理解

 我们得到一个数组`a`长度`n`。 任务是重复选择一个元素`a`，将其值加上其当前索引添加到集合中`S`，将其从数组中删除，并继续直到`a`是空的。 所有插入完成后，我们对集合进行排序`S`按降序排列形成数组`b`。 目标是从中选择元素`a`以这样的方式，所产生的`b`按字典顺序尽可能大。 

的每个元素`S`计算为`a_i + i`在哪里`i`是选择时基于 1 的位置。 自从`S`是一个集合，重复项将被忽略。 因此，选择稍后产生相同总和的元素不会改善结果，这使得排序至关重要。 约束条件允许`n`最多`3 * 10^5`所有测试用例的总和上限为`3 * 10^5`，这意味着每个测试用例具有 O(n log n) 的任何算法都是可行的，但 O(n^2) 方法太慢。 

当值在`a`严格增加或减少。 例如，`a = [2, 1]`证明删除最大的第一个会产生更多唯一的总和，而删除较小的第一个可能会导致重复。 另一种情况是当所有`a_i`是平等的，说`a = [1, 1, 1]`。 从末尾选取元素可以最大化与当前索引的总和，因为`a_i + i`增加与`i`。 

## 方法

 蛮力方法将尝试移除顺序的每种排列，计算`S`，然后排序形成`b`。 这是正确的，但完全不可行，因为有`n!`排列，甚至对于`n = 10`，这已经是360万种可能性了。 

关键的见解是插入的价值`S`仅取决于元素及其当前索引的总和。 为了按字典顺序最大化，我们希望最大值出现在早期`b`。 对于每个值`a_i`，如果尽可能晚地选择它，则会出现最大的总和，因为后面的位置具有更大的索引。 因此，为了最大化`b`，我们应该首先模拟从数组末尾拾取元素。 我们还必须避免插入重复项`S`，因此我们使用集合来跟踪插入的值。 

具体来说，如果我们迭代`a`以相反的顺序并计算`a_i + i`对于每个`i`相反，将每个总和添加到`S`仅当它以前没有出现过时才排序`S`按降序排列产生所需的字典顺序最大的`b`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最优（反向+设置）| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个空集`S`用于存储唯一的总和。 
2. 迭代`a`从最后一个元素到第一个元素。 
3. 对于每个元素`a[i]`从 0 开始的索引`i`， 计算`a[i] + (i + 1)`考虑从 1 开始的索引。 
4. 如果该金额尚未存入`S`，插入它。 
5.处理完所有元素后，进行转换`S`放入一个列表并按降序排序形成`b`。 
6. 输出`b`。 

为什么有效：从末尾迭代可确保首先考虑索引较高的元素，从而最大化它们`a_i + i`总和。 插入到集合中可以避免重复。 按降序排序可保证最大的总和首先出现，从而生成按字典顺序排列的最大数组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        seen = set()
        result = []
        # process from end to start
        for i in reversed(range(n)):
            val = a[i] + i + 1
            if val not in seen:
                seen.add(val)
                result.append(val)
        # output in decreasing order
        print(*sorted(result, reverse=True))

if __name__ == "__main__":
    solve()
```该代码首先读取测试用例的数量，然后处理每个数组。 使用`reversed(range(n))`从最后正确计算总和。 这`seen`set 可以防止重复插入，这一点至关重要。 最后排序保证了字典顺序。
