[CF 80A - Panoramix 的预测](https://codeforces.com/problemset/problem/80/A)

 **评分：** 800
 **标签：** 暴力破解
 **求解时间：** 1m 18s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 昨天高卢人被击败`n`罗马士兵，以及`n`保证是素数。 今天他们击败了`m`士兵，在哪里`m > n`。 我们需要决定是否`m`正是紧随其后的下一个素数`n`。 

关键细节是“下一个素数”这句话。 两个数都是质数是不够的。 他们之间一定没有其他素数。 

限制很小。 这两个数字最多为 50，因此即使非常慢的强力检查也能在时间限制内轻松完成。 通过试除到数字的平方根进行素性测试在这里只需要几次操作。 甚至检查每个数字`n + 1`向上实际上是即时的。 

主要的危险是误解下一个素数的资格。 

考虑这个输入：```
3 7
```正确答案是：```
NO
```3和7都是素数，但5位于它们之间，也是素数。 一个粗心的实现，只检查是否`m`是素数会错误地打印`YES`。 

另一个容易犯的错误是在寻找下一个素数时停止得太晚。 

例如：```
7 11
```7 后面的下一个素数实际上是 11，因为 8、9 和 10 是合数。 该算法必须正确跳过非素数，而不是假设素数是连续的奇数。 

最终的边缘情况是最小的有效输入：```
2 3
```答案是：```
YES
```由于 2 是第一个素数，所以它后面的下一个素数是 3。 

## 方法

 最直接的方法是生成所有大于的素数`n`直到达到`m`。 我们可以重复测试每个整数的素数并收集素数。 一旦我们找到第一个大于的素数`n`，我们将其与`m`。 

这是可行的，因为约束非常小。 在最坏的情况下，我们检查最多 50 个数字，并且每个素性测试仅检查少数几个除数。 即使是低效的实施也会立即运行。 

一个稍微不同的蛮力想法是使用嵌套循环预先计算最多 50 个素数，然后扫描列表以查看是否`m`紧随其后`n`。 这在限制范围内也能舒适地工作。 

更干净的解决方案使用一个简单的观察：我们不需要所有素数。 我们只需要第一个大于的素数`n`。 

因此，我们不是生成所有内容，而是从`n + 1`向上搜索，直到遇到素数。 根据定义，第一个素数是之后的下一个素数`n`。 如果它等于`m`，答案是`YES`; 否则就是`NO`。 

这将任务减少为两个小部分：

 1. 检查数字是否为质数的函数。 
2. 查找第一个大于的素数的循环`n`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力预计算 50 以内的所有素数 | O(50²) | O(50) | 已接受 |
 | 最优直接搜索下一个素数 | O(50√50) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取整数`n`和`m`。 
2. 编写辅助函数`is_prime(x)`检查是否`x`是素数。 

如果一个数没有 2 到 2 之间的约数，则该数是素数`√x`。 如果存在任何除数，则该数是合数。 
3. 开始检查整数`n + 1`向上。 

我们正在寻找第一个大于`n`。 
4. 对于每个候选人编号，请致电`is_prime(candidate)`。 

如果该数字不是素数，则继续搜索。 
5. 一旦找到第一个素数，就将其与`m`。 

如果相等，则打印`YES`。 否则打印`NO`。 
6. 找到第一个素数后立即停止。 

我们只关心紧随其后的下一个素数`n`。 

### 为什么它有效

 该算法从以下位置开始按升序搜索整数`n + 1`。 遇到的第一个通过素性测试的数字恰好是大于的最小素数`n`，它与下一个素数的数学定义相匹配。 

如果这个数字等于`m`， 然后`m`是之后的下一个素数`n`。 如果它不同于`m`，那么要么`m`不是质数或之间存在另一个质数`n`和`m`。 在这两种情况下，正确答案都是`NO`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_prime(x):
    if x < 2:
        return False

    d = 2
    while d * d <= x:
        if x % d == 0:
            return False
        d += 1

    return True

def solve():
    n, m = map(int, input().split())

    candidate = n + 1

    while True:
        if is_prime(candidate):
            if candidate == m:
                print("YES")
            else:
                print("NO")
            return

        candidate += 1

solve()
```这`is_prime`函数执行试除。 它检查从 2 到数字的平方根的每个除数。 如果任何除数能被整除，则该数是合数。 

主循环开始于`n + 1`因为我们只关心严格大于的数字`n`。 每个候选者都经过素性测试。 遇到的第一个素数自动成为下一个素数`n`。 

一个微妙的实现细节是在找到第一个素数后立即停止。 继续下去是不正确的，因为后面的素数是无关紧要的。 另一个小细节是循环条件`d * d <= x`。 这可以避免丢失完全平方因数，例如 7 除 49。

 ## 边缘情况

 考虑输入：```
3 7
```该算法从 4 开始。它检查 4（合数），然后检查 5（素数）。 由于 5 是第一个大于 3 的素数，因此它是 3 之后的下一个素数。因为 5 不等于 7，所以算法打印`NO`。 这解决了仅检查是否存在的常见错误`m`本身就是素数。 

现在考虑：```
7 11
```搜索检查 8、9 和 10，拒绝所有它们，因为它们是复合的。 找到的第一个素数是 11，所以算法打印`YES`。 这证实了该算法正确地跳过了任意一段合数。 

最后，考虑最小边界情况：```
2 3
```该算法从候选 3 开始。由于 3 是素数并且等于`m`，输出是`YES`。 这证实了约束下限的正确行为。
