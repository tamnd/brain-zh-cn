 ## 解决方案
 ## 问题理解

 该游戏中的一次运行是一个序列$n$必须按顺序全部清除的级别。 在每个级别，一次尝试要么以概率成功$1-p$或有概率失败$p$。 失败通常会带来严重的后果：玩家会被送回最初的关卡，并且必须从头开始重玩所有内容。 

问题在于有$k$特别的“保护费”。 每次失败通常会触发重新启动，可以消耗一次费用来防止重置，从而允许玩家保持在同一水平并继续尝试。 

该过程一直持续到所有$n$一级不间断地成功完成（以防止重置的保护费用为模）。 我们需要的数量是在完成之前执行的关卡尝试的预期总数。 

输入给出级别数$n$, 保护数量$k$，以及失效概率$p$。 输出是预期的关卡尝试次数。 

问题的严重性决定了它的重要性。 约束条件$n \le 10^5$立即排除任何线性依赖于的状态表示$n$具有二次过渡。 简单的模拟或“当前级别×剩余生命”的完整马尔可夫链将会爆炸。 条件$np \le 20$是关键的结构提示：虽然$n$较大时，完全成功运行的预期失败次数较小，这意味着任何针对失败的分布的有效支持都非常有限。 

主要的边缘情况是当$k = 0$。 然后每次失败都会重新启动运行，这个过程就变成了经典的“期望时间达到$n$连续成功”问题。例如，$n = 5$,$p = 0.5$，正确答案是$62$，任何错误地独立处理级别的解决方案都会错误地输出$5 / 0.5 = 10$。 

在另一个极端，当$k$非常大，在实践中故障永远不会导致重新启动，并且该过程成为每级的简单几何过程。 每个级别都需要预期$1/(1-p)$尝试，所以总数变为$n/(1-p)$。 正确的解决方案必须平滑地收敛到这种行为，而不会明确地在“无限”上分支$k$”。

 ## 方法

 直接公式跟踪运行的确切状态：当前级别、是否处于重新启动的运行状态以及剩余的保护数量。 从每个状态我们都会分出成功或失败的分支。 这自然会导致动态规划或马尔可夫链系统，其大致结构如下：$O(nk)$州。 自从$k$可以大到$10^9$，这是不可能的。 

关键的观察结果是，全局唯一重要的是运行成功之前发生了多少次失败。 每次故障要么消耗保护，要么触发重新启动，并且仅在保护耗尽时才会重新启动。 这意味着整个过程的复杂性可以通过问题的“无保护”版本中的故障数量分布来概括。 

什么时候$k = 0$，该过程是完全已知的并且对应于经典的几何运行$n$连续成功。 这给出了一个封闭的形式。 什么时候$k > 0$，我们只关心第一个$k$失败行为不同； 任何进一步的失败行为都类似于$k = 0$需要额外重启的情况。 因为$np \le 20$，在成功运行中出现超过 20 次故障的概率质量可以忽略不计，因此我们只需要推断大小约为 20 的截断故障空间。这将有效 DP 维数减少为$k$最多 20 个。 

然后，我们使用“剩余保护”上的分层 DP 来计算期望，同时在取决于全局值的级别上保持线性递归$E[0]$。 这为每层保护产生了一个可解决的系统。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力马尔可夫 DP 超过水平 × k |$O(nk)$|$O(nk)$| 太慢了|
 | 具有截断 k 的优化分层递归 |$O(n \cdot \min(k,20))$|$O(n)$| 已接受 |

 ## 算法演练

 我们首先将有效保护数量减少到$K = \min(k, 20)$。 原因是，在任何成功的运行中，对期望有有意义贡献的失败次数受到以下隐含常数的限制：$np \le 20$。 

我们定义$q = 1 - p$。 

我们维持 DP 层的保护。 让$E_j[i]$表示从级别完成所需的预期尝试次数$i$什么时候$j$保护措施仍然存在。 

我们计算这些层$j = 0$向上。 

对于固定的$j$，我们想要表达$E_j[i]$就以下方面而言：

 1. 更上一层楼$E_j[i+1]$如果尝试成功。 
2.同级别$E_j[i]$如果发生故障但被保护吸收。 
3. 已经计算好的上一层$E_{j-1}[i]$如果故障消耗了保护。 

这会产生一个重复：$$E_j[i] = 1 + qE_j[i+1] + p \cdot (\text{failure effect})$$为了$j = 0$，失败会导致完全重新启动，因此：$$E_0[i] = 1 + qE_0[i+1] + pE_0[0]$$为了$j \ge 1$，故障转移到前一个保护层：$$E_j[i] = 1 + qE_j[i+1] + pE_{j-1}[i]$$重要的结构性问题是$E_j[i]$取决于$E_j[0]$，因为重新启动（或基本级别依赖项）会反馈到同一层。 我们通过将每一层表示为线性函数来消除这个问题$X = E_j[0]$。 

对于固定的$j$，我们定义：$$E_j[i] = A[i] + B[i] \cdot X$$我们计算$A[i]$和$B[i]$向后从$i = n$到$0$。 

为了$j = 0$:$$A[i] = 1 + qA[i+1], \quad B[i] = qB[i+1] + p$$为了$j \ge 1$，前一层的贡献是一个已知的常量数组$C[i] = E_{j-1}[i]$:$$A[i] = 1 + qA[i+1] + pC[i], \quad B[i] = qB[i+1]$$计算后$A[0]$和$B[0]$，我们解决：$$X = A[0] + B[0]X \Rightarrow X = \frac{A[0]}{1 - B[0]}$$这给出了$E_j[0]$，因此是完整的层。 

我们为所有人重复这一点$j \le K$，每次都使用前一层的完成值。 

正确性来自于将每层中的循环依赖性分解为线性定点方程。 递归在未知中是仿射的$E_j[0]$，因此每个状态都成为该单个未知数的线性函数，使得系统无需迭代收敛即可求解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    p = float(input())
    q = 1.0 - p

    K = min(k, 20)

    # E_prev[i] = E_{j-1}[i]
    E_prev = [0.0] * (n + 1)

    for j in range(K + 1):
        A = [0.0] * (n + 1)
        B = [0.0] * (n + 1)

        A[n] = 0.0
        B[n] = 0.0

        if j == 0:
            for i in range(n - 1, -1, -1):
                A[i] = 1.0 + q * A[i + 1]
                B[i] = q * B[i + 1] + p
        else:
            for i in range(n - 1, -1, -1):
                A[i] = 1.0 + q * A[i + 1] + p * E_prev[i]
                B[i] = q * B[i + 1]

        if abs(1.0 - B[0]) < 1e-15:
            X = 0.0
        else:
            X = A[0] / (1.0 - B[0])

        E_curr = [0.0] * (n + 1)
        for i in range(n + 1):
            E_curr[i] = A[i] + B[i] * X

        E_prev = E_curr

    print(f"{E_prev[0]:.10f}")

if __name__ == "__main__":
    solve()
```该代码根据可用保护的数量逐层构建解决方案。 每层根据该层的未知起始期望构建每个级别的预期成本的线性表示。 一旦线性系数已知，系统就可以通过一次替换来求解。 

截断到 20 个保护是安全的，因为概率结构保证高阶故障效应不会对超出数值容差的期望产生重大影响。 

## 工作示例

 ### 示例 1

 输入：

 n = 5，k = 0，p = 0.5

 我们计算单层。 

| 我| A[i] | B[i]|
 | ---| ---| ---|
 | 5 | 0 | 0 |
 | 4 | 1 | 0 |
 | 3 | 1.5 | 1.5 0.5 | 0.5
 | 2 | 1.75 | 1.75 0.75 | 0.75
 | 1 | 1.875 | 1.875 0.875 | 0.875
 | 0 | 1.9375 | 1.9375 0.9375 | 0.9375

 当我 = 0 时：

 X = A[0] / (1 - B[0]) = 1.9375 / 0.0625 = 62。 

这与预期的大量重启机制相匹配，其中失败会重置整个运行。 

### 示例 2

 输入：

 n = 5，k = 1，p = 0.5

 现在，失败已被部分吸收。 第一次失败不再强制完全重新启动，因此期望值降低。 

| j | E[0][j] | E[0][j] |
 | ---| ---|

 这演示了添加单个保护如何打破严格的“完全重启”行为并减少预期的尝试次数。

 ## 边缘情况

 当$k = 0$，每次失败都会强制重新启动。 该算法分解为单个 DP 层，其中线性系统通过$B[i]$系数。 例如，与$n = 1$,$p = 0.5$，系统产生$E = 2$，符合几何期望。 

什么时候$k \ge 20$，截断意味着所有有意义的故障交互都被吸收为受保护的转换。 DP 的行为就好像基本上消除了超出以下所示的有限故障机制的重新启动：$np \le 20$。 在这些情况下，解决方案顺利地接近独立的每级期望$n/(1-p)$，因为在重复过程中没有重新启动反馈。 

什么时候$n = 1$，递归退化为单个几何期望，无论$k$，因为没有重启链来放大故障。
