 ## 解决方案
 ## 问题理解

 给定一个从 1 到 n 的元素集合，每个元素 i 都带有一个权重 ai。 目标是设计一个随机过程，使用独立的硬币翻转生成固定大小 k 的子集，然后拒绝无效结果。 

该过程的工作原理是为每个索引 i 分配一个概率 pi。 在一次试验中，我们以概率 pi 独立地包含每个 i，产生一个随机子集 T。如果所得子集的大小恰好为 k，我们接受它；否则，我们接受它。 否则我们放弃整个试验并重复直到成功。 在所有成功的结果中，我们希望 k 大小的子集 S 上的分布与 S 中所有元素的 ai 乘积成正比。 

输出不是子集本身，而是包含概率 pi。 这些概率的总和必须为 k，并且在拒绝采样之后，它们必须得出与所需的乘法权重结构相匹配的 k 子集上的分布。 

约束允许 n 最大为 100000，这会立即排除涉及枚举子集或对所有 k 组合进行动态编程的任何内容。 任何正确的方法都必须通过少量的数组遍历将问题减少到线性时间或接近线性时间。 

一个微妙的方面是，分布是在对事件 |T| 进行调节之后定义的。 = k。 该条件耦合了所有坐标，因此即使生成是独立的，最终概率 pi 也不是 ai 的独立函数。 

典型的故障模式是假设 pi 与 ai 成比例，或者单独标准化就足够了。 例如，如果 n = 3、k = 1、a = [1, 100, 100]，则猜测 pi 与 ai 成比例给出的概率不符合条件结构，并且拒绝后的诱导分布在加权单例上并不均匀。 

另一个微妙的陷阱是数值稳定性。 由于 pi 是实数并且必须满足全局约束，因此小误差会通过归一化条件累积并可能违反总和约束或失真比。 

## 方法

 蛮力解释将尝试直接从定义条件求解 pi。 人们可以想象枚举大小为 k 的所有子集 S，将拒绝采样输出 S 的概率写为 pi，并将任意两个子集之间的比率等于它们的权重之比。 这导致了一个由指数级多个方程组成的系统，因为每个子集概率都会扩展为 pi 和 (1 - pi) 的乘积。 即使写出完全似然也需要对所有大小的所有子集求和，即 O(2^n)。 即使对于小n，这也是不可行的。 

关键的结构观察是拒绝步骤以固定基数为条件，这表明与以总和约束为条件的泊松二项式分布有关。 拒绝之前 T 的分布已完全因式分解，但在 |T| 上进行调节之后 = k，我们得到固定大小的产品形式分布。 

k 个子集上所需的目标分布与 ∏ ai 成正比，这正是通过对 k 个项目进行无放回采样而获得的分布，其中每个项目具有权重 ai。 这是经典的加权 k 子集模型，也称为多元 Wallenius 或 Fisher 非中心超几何结构。 在这样的模型中，有一个已知的表示：每个元素 i 都有一个“包含倾向”pi，它取决于单个缩放参数 λ，正确的形式是

 pi = 1 / (1 + λ / ai)

 对于一些 λ > 0 的选择，使得 T 的预期大小等于独立采样下的 k。

这种结构的出现是因为任意两个元素之间的包含概率之比必须与调节后的权重之比相匹配。 在所有 k 子集上强制执行比例性会产生单参数系列的解决方案，并且约束 Σ pi = k 唯一地确定 λ。 

因此，问题简化为找到 λ 使得 pi(λ) 之和等于 k。 由于 pi 在 λ 中单调递减，因此总和也是单调的，因此可以使用二分查找找到 λ。 每个总和的评估都是 O(n)，使得完整的解决方案为 O(n log precision)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对子集的暴力破解 | O(2^n) | O(2^n) | O(2^n) | O(2^n) | 太慢了|
 | 单调参数+二分查找| O(n log(1/ε)) | O(n log(1/ε)) | O(n) | 已接受 |

 ## 算法演练

 我们引入一个正参数 λ 来同时控制所有概率。 对于固定 λ，将每个包含概率定义为 pi(λ) = ai / (ai + λ)。 选择这种形式是因为它是唯一的平滑对称变换，可以在将权重映射到 (0,1) 中的概率的同时保留元素之间的比例几率。 

1. 确定λ的候选值。 对于这个 λ，使用 pi = ai / (ai + λ) 计算每个 pi(λ)。 此步骤以保留排序的方式将权重转换为包含概率：较大的 ai 总是意味着较大的 pi。 
2. 计算总和 S(λ) = Σ pi(λ)。 该总和表示拒绝之前采样集的预期大小。 拒绝步骤不会改变 pi，因此这是要控制的正确量。 
3. 观察到当 λ → 0 时，每个 pi 都趋近于 1，因此 S(λ) 趋近于 n。 当 λ → ∞ 时，每个 pi 都趋近于 0，因此 S(λ) 趋近于 0。这保证了 [1, n − 1] 中的每个目标 k 都是可实现的。 
4. 对 λ 使用二分查找来查找 S(λ) = k 的唯一值。 在每个中点，计算 S(λ) 并将其与 k 进行比较。 如果S(λ)太大，则λ太小，必须增大； 否则减小 λ。 
5. 收敛后，使用最终的 λ 输出每个 i 的 pi。 

当总和足够精确以至于各个 pi 值与其真实值最多相差 1e-6 时，二分查找终止。 

### 为什么它有效

 拒绝后的分布仅取决于元素之间的相对包含几率。 形式 pi = ai / (ai + λ) 准确地保留了这些赔率，因为

 pi / (1 − pi) = ai / λ。 

这意味着包含的对数几率与 log(ai) 成正比，并偏移常数 λ。 以恰好 k 个选定项为条件强制预期基数与 k 匹配，并且 S(λ) 的单调性保证了唯一的解决方案。 因此，该结构是使独立伯努利试验与固定大小加权抽样分布保持一致的唯一一致方法。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    def calc(lam):
        s = 0.0
        for x in a:
            s += x / (x + lam)
        return s

    lo, hi = 0.0, 1.0

    # expand hi until sum <= k
    while calc(hi) > k:
        hi *= 2.0

    for _ in range(80):
        mid = (lo + hi) / 2.0
        if calc(mid) > k:
            lo = mid
        else:
            hi = mid

    lam = hi
    res = [x / (x + lam) for x in a]
    print("\n".join(f"{v:.12f}" for v in res))

if __name__ == "__main__":
    solve()
```该解决方案首先定义函数 S(λ)，该函数计算给定参数的预期子集大小。 初始上限呈指数扩展，直到预期大小降至 k 以下，确保二分搜索间隔有效。 

然后应用二分搜索进行固定次数的迭代。 S(λ)的单调性保证了方向更新的正确性。 收敛后，最终的 λ 用于直接计算每个 pi。 

一个常见的实现陷阱是忘记浮点精度需要足够的迭代而不是天真的 epsilon 停止。 对于双精度来说，使用固定迭代计数（例如 80）就足够了。

 ## 边缘情况

 一种边缘情况是所有 ai 都相等。 在这种情况下，系统必须降低到均匀概率 pi = k / n。 该算法可以处理这个问题，因为 S(λ) 是对称的，并且二分搜索收敛到唯一的 λ，产生相等的概率。 

另一种边缘情况是当 k 非常小时，例如 k = 1。那么 T 中预计只有一个元素，并且解决方案将 λ 推得很大，以便所有概率都很小，且比率与 ai 匹配。 该结构自然地保留了元素之间的比例选择。 

最后一种边缘情况是极端的权重差异，例如一个 ai 为 1e9，其他为 1。单调结构确保二分搜索仍然收敛，并且比率形式 pi = ai / (ai + λ) 可以防止溢出，因为即使对于大 ai，所有操作都以浮点形式保持稳定。
