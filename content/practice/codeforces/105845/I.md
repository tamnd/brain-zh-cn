 ## 解决方案
 ## 问题理解

 我们得到两个长度相等的小写英文字母字符串。 我们可以重复执行一个非常具体的操作，该操作作用于字符串的某个区间。 在一步中，我们选择两个位置，交换这些位置的字符，然后通过将每个字母替换为字母表中的“镜像”来严格独立地在它们之间转换每个字符，其中`a`变成`z`,`b`变成`y`， 等等。 

任务是确定将初始字符串转换为目标字符串所需的此类操作的最少数量，或者决定根本无法完成。 

该操作的重要部分是它将排列效应（交换）与区间上的确定性全局变换（字母表反转）结合起来。 交换是两个头寸的局部，而翻转则以结构化的方式影响所有中间头寸。 这种耦合使得问题变得不平凡，因为交换端点会改变翻转的字符。 

约束允许字符串长度最多约为$10^5$，这排除了任何模拟操作序列或尝试显式搜索状态的解决方案。 任何有效的方法都必须将问题简化为线性或近线性传递，或简化为少量贪婪决策。 

第一个天真的想法是将每个操作视为状态转换，并尝试对一个操作可到达的所有字符串进行 BFS。 这立即爆炸了，因为每个州都有$O(n^2)$可能的操作和状态空间的大小$26^n$。 即使对于非常小的字符串，这也变得很棘手。 

如果我们尝试从左到右贪婪地修复位置，则会出现更微妙的失败模式。 由于每个操作都会以类似奇偶校验的方式修改整个段，因此修复一个位置可能会破坏之前已经正确的位置。 例如，假设我们尝试通过将第一个字符交换到位来匹配它； 根据交换距离，所有中间字符都会被翻转，从而可能使先前匹配的前缀无效。 这种相互依赖意味着局部贪婪修正并不稳定。 

核心困难在于该操作在时间间隔内引入了全局奇偶校验结构，因此正确性取决于跟踪每个位置受影响模 2 的次数，而不是操作的确切顺序。 

## 方法

 暴力视图将每个操作视为对整个字符串配置的转换。 从给定的字符串中，我们可以选择任意一对索引，交换它们，然后翻转整个段。 这给出了巨大的分支因子，即使进行修剪，对齐两个任意字符串所需的深度也可以是线性的$n$，使搜索在实践中呈指数级增长。 

关键的观察结果是交换部分仅排列字符，而翻转部分仅以可逆的方式切换字母。 字母翻转是一种对合，应用两次即可恢复原始字符。 这意味着可以使用奇偶校验对操作的效果进行建模：每个位置都会翻转一定次数，并且只有该计数是奇数还是偶数才重要。 

一旦我们将观点从“操作序列”切换到“间隔上的最终奇偶校验分配加上字母排列”，结构就会简化。 每个操作都贡献一个段翻转加上两个元素的转置。 交换仅重新排列字母的位置，而翻转则确定每个位置是否收到补码。 

关键的见解是分离两层。 首先，我们决定字符之间的匹配$S$和$T$，将互换视为允许任何排列。 其次，我们检查是否可以通过间隔翻转来解决引起的失配模式。 间隔翻转的行为类似于切换差异数组，因此可行性降低为是否可以使用范围异或更新使派生的二进制序列保持一致。 

这个问题相当于检查我们是否可以使用切换子数组的操作将二进制不匹配数组转换为全零，并且每次交换仅有助于重新排列配对的不匹配。 这减少了在间隔操作下维持奇偶校验一致性的问题，这可以通过扫描和维持运行不平衡来贪婪地解决。

 ## 算法演练

 1. 通过比较中的每个位置，将问题转换为不匹配表示$S$和$T$。 不是直接跟踪字母，而是表示每个位置是否已经正确或需要转换，因为交换仅重新排列位置并且不会更改字符的多重集。 
2. 将掉期视为允许任意排列头寸。 这意味着我们可以自由匹配以下字符$S$到职位$T$以任何顺序，所以真正的约束变成是否多重集结构$S$可以转换成$T$在允许的翻转下。 
3. 将每个字母编码为 0 到 25 之间的整数，并将其翻转版本定义为$25 - x$。 这使得量子翻转操作成为固定字母空间上的按位对合，将字母转换变成以固定映射为模的算术。 
4. 对于每个位置，计算当前字符与目标字符之间是否需要翻转的差异。 这会为每个位置生成一个二进制指示符：要么字符已经匹配，要么需要对覆盖该位置的间隔应用奇数次翻转。 
5. 将问题简化为确定是否存在一系列间隔操作，使得每个位置都以所需的奇偶校验结束。 每个操作都会贡献一个范围切换，因此系统成为一个经典的区间奇偶校验构造问题。 
6. 从左向右扫动，同时保持当前累积的翻转奇偶性。 在每个位置，将当前奇偶校验状态与所需状态进行比较。 如果它们不同，我们必须开始一个新的操作，其效果将纠正这种不匹配并一致地向前传播。 
7. 确保仅在必要时才引入操作，并且始终选择修复最早未解决的位置，因为延迟修正只会增加冲突间隔的数量，而不会提高灵活性。 

### 为什么它有效

 关键的不变量是，在字符串的每个前缀处，算法都会保持与所有先前固定位置相匹配的翻转奇偶校验的一致分配。 由于每个操作都会影响一个连续的段，因此在第一个不匹配位置引入的任何校正都可以扩展到右侧，而不会导致先前的决策无效。 这将全局问题转化为一系列强制局部修正，并且由于交换消除了字母放置的位置限制，因此一旦奇偶校验被修复，不相交的段之间就不再存在隐藏的依赖关系。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    S = input().strip()
    T = input().strip()
    n = len(S)

    # mismatch parity: 1 if S[i] needs an odd number of flips to become T[i]
    need = [0] * n

    def f(c):
        return ord(c) - ord('a')

    for i in range(n):
        a = f(S[i])
        b = f(T[i])
        # if we flip once, a becomes 25-a
        # so check if we need an odd number of flips
        need[i] = 1 if a != b else 0

    ops = 0
    i = 0
    cur = 0  # current parity of active interval flips

    while i < n:
        if (cur & 1) != need[i]:
            ops += 1
            cur ^= 1
        i += 1

    print(ops)

if __name__ == "__main__":
    solve()
```该代码将转换简化为对不匹配数组的奇偶校验遍历。 变量`cur`跟踪当前有多少活动间隔翻转影响该位置，模 2。每当当前奇偶校验与某个位置所需的奇偶校验不一致时，就会引入一个新操作，该操作将翻转奇偶校验状态。 

一个微妙的点是我们从不显式构造间隔或执行交换。 互换自由度被吸收到每个头寸可行性的减少中，因此实现只需要确保奇偶校验一致性。

 ## 边缘情况

 关键的边缘情况是每个字符都已经匹配。 在这种情况下，不需要任何操作，因为任何操作都会引入不必要的翻转。 该算法自然会处理这个问题，因为失配数组全为零并且不会触发奇偶校验校正。 

当所有字符都需要翻转时，会出现另一种边缘情况。 在这种情况下，第一个不匹配会触发单个操作，奇偶校验会在整个字符串中一致传播，从而避免额外的更正。 

第三种情况是交替不匹配，例如`abab`到`baba`，其中每个立场在结构化模式中都不一致。 该算法精确地在奇偶校验发散的点引入操作，确保每次校正在下一个不一致出现之前修复最大前缀。
