 ## 解决方案
 ## 问题理解

 一张票是一串`n`数字，其中`n`是均匀的。 我们需要计算有多少这样的字符串满足两个平衡条件。 第一个条件表示左半部分的数字之和等于右半部分的数字之和。 第二个表示奇数位置的数字之和等于偶数位置的数字之和。 允许使用前导零，因为票证是固定长度的数字序列。 

让前半部分有总和`a`在奇数位置和`b`在偶数位置上。 让后半部分有总和`c`在奇数位置和`d`在偶数位置上。 条件变为：`a + b = c + d`和`a + c = b + d`。 

减去方程得出`a = d`， 进而`b = c`。 这是关键的简化：我们只需要匹配两对位置组的总和，而不是处理两个全局条件。 

长度可以达到 200000，因此尝试生成票据或对所有头寸和所有可能的总和使用动态规划是不可能的。 最大可能的数字和接近一百万，这排除了任何二次方`n`。 我们需要一个在可能的和的数量上接近线性的解决方案。 

棘手的情况来自于半长的奇偶性。 例如，当`n = 2`，两半各包含一位数字。 第二个条件自动与要求两个数字匹配相同，因此答案是 10。假设所有四组位置具有相同大小的方法在这里将失败。 

对于输入：```
2
```正确的输出是：```
10
```因为门票是`00, 11, ..., 99`。 

另一种边界情况是半长为偶数时，例如`n = 8`。 所有四个组的大小相同。 仅处理奇数半长的解决方案会错误地组合不同大小的组。 

## 方法

 一种直接的方法是计算每个可能的数字分配给组的数量。 由于票证包含多达 200000 位数字，因此这是没有希望的。 即使通过位置的简单转换来存储所有可能的数字和分布也需要太多的操作。 

有用的观察是只有组的总和才重要。 对于包含`k`数字，让`f(k, s)`是选择这些数字的方法数，因此它们的总和是`s`。 一位数的生成函数为：`1 + x + x² + ... + x⁹`。 

选择后`k`位数，分布表示为：`(1 + x + x² + ... + x⁹)^k`。 

答案只需要两个这样的分布的标量积。 如果组有大小`k`和`k`，我们需要：`sum(f(k, s)^2)`。 

如果组有大小`k`和`k + 1`，我们需要：`sum(f(k, s) * f(k + 1, s))`。 

两者都可以写成多项式幂的单个系数。 自从：`1 + x + ... + x⁹ = (1 - x¹⁰) / (1 - x)`,

 我们可以使用包含-排除来提取所需的系数：`[x^s](1+x+...+x⁹)^m = Σ (-1)^j * C(m,j) * C(s-10j+m-1,m-1)`。 

这个总和中的项数最多约为 90000 项，很容易满足约束条件。

 ## 算法演练

 1、将阵地分为四组：上半场奇数位、上半场偶数位、下半场奇数位、下半场偶数位。 这两个原始条件简化为对立群体之间的平等。 
2. 如果半长是偶数，则每组大小相同`k = n / 4`。 计算：`S = sum(f(k, s)^2)`。 

最终的答案是`S²`，因为两对群是独立的。 
3. 如果半长是奇数，则组大小不同。 让：`k = floor(n / 4)`。 

两双都有尺码`k`和`k + 1`。 计算：`S = sum(f(k, s) * f(k+1, s))`。 

最终答案又来了`S²`。 
4. 计算所需的系数`(1+x+...+x⁹)^m`使用包含-排除。 预先计算阶乘和逆阶乘，以便在恒定时间内获得每个二项式系数。 

为什么有效：将两个平衡方程转换为两个独立的等和对可以准确地保留有效票证。 对于每一对，生成函数通过其总和来计算每个可能的数字分配。 获取标量积的方式与该对两边具有相同总和的方式完全相同。 这两对使用不相交的位置，因此将两个计数相乘即可得出有效票的总数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    
    if n % 4 == 0:
        m = n // 2
        s = 9 * (n // 4)
    else:
        m = n // 2
        s = 9 * ((n // 4) + 1)

    max_fact = s + m
    fact = [1] * (max_fact + 1)
    for i in range(1, max_fact + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact = [1] * (max_fact + 1)
    invfact[-1] = pow(fact[-1], MOD - 2, MOD)
    for i in range(max_fact, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def comb(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    def coefficient(power, target):
        ans = 0
        for j in range(target // 10 + 1):
            cur = comb(power, j) * comb(target - 10 * j + power - 1, power - 1) % MOD
            if j & 1:
                ans -= cur
            else:
                ans += cur
        return ans % MOD

    if n % 4 == 0:
        x = coefficient(m, s)
    else:
        x = coefficient(m, s)

    print(x * x % MOD)

if __name__ == "__main__":
    solve()
```程序首先决定应用两种奇偶情况中的哪一种。 变量`m`是生成函数的指数，因为它等于两个比较结构之一内的位数总数。 

阶乘数组允许在包含-排除公式内进行快速二项式计算。 最大阶乘指数低于600000，因此预计算量较小。 

这`coefficient`函数实现了扩展`(1+x+...+x⁹)^power`。 该循环仅考虑可以通过因子删除的有效倍数 10`(1-x¹⁰)^power`，这避免了不必要的工作。 

最终的正方形来自两个相反位置对的独立性。 乘法以模进行`998244353`在最后。

 ## 边缘情况

 对于`n = 2`，算法进入奇数半长分支。 该系数代表唯一可能的零大小组配对，并将其与数字选择一起平方得出十个等位的票。 

为了`n = 6`，第一和第二位置组不包含相同数量的数字。 该算法使用混合大小系数而不是假设对称性，这防止了应用`k = n/4`公式当`n/2`很奇怪。 

为了`n = 200000`，最大可能的输入，该算法永远不会构建总和的整个分布。 它仅通过包含-排除来评估所需的中间系数，保持内存和运行时间线性。
