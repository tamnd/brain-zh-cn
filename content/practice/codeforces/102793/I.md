 ## 解决方案
 # 问题理解

 我们有一个无向图，其中房间是顶点，隧道是边。 我们需要找到一小群具有两个属性之一的房间。 第一种可能性是一个规模较大的派系`l`，这意味着组中的每对房间之间都有一条隧道。 第二种可能性是反派的规模`k`，这意味着组中没有一对房间之间有隧道。 如果两个结构都不存在，我们打印`-1`。 

输入给出了房间、隧道的数量和两个目标大小。 该图最多可以有 300000 个顶点和 300000 个边，而所请求的组大小最多为 5。`k`和`l`是关键约束。 一般的派系搜索很困难，但是搜索派系或最多五个大小的独立集合允许我们使用拉姆齐理论。 稀疏图表示也很重要，因为存储或检查所有可能的顶点对是不可能的。 

如果有 300000 个顶点，即使检查每对房间也需要大约 90000000000 次操作，这远远超出了极限。 任何直接枚举三元组、四元组或更大的组的解决方案也很快变得不可能。 我们需要一种几乎线性依赖于图大小的方法，并且仅探索由最大答案大小引起的小搜索树。 

第一种边缘情况是请求的大小为 1 时。 任何单个顶点既是一个团，又是一个大小为 1 的反团，因此答案立即是任何顶点。 例如：```
Input:
5 0 1 3

Output:
1
```仅搜索边或非边的解决方案会错误地失败，因为它会忽略单顶点组始终有效的事实。 

另一种边缘情况是图为空时。 如果我们需要一个反派，则每组顶点都可以工作，但如果我们需要一个大小大于 1 的派，则不存在派。 例如：```
Input:
4 0 3 2

Output:
1 2 3
```该算法必须能够正确地穿过非邻居，因为除了所选顶点之外的所有顶点都属于反派一边。 

最后一个棘手的情况是图表何时完成。 那么大于一个的反派是不可能的，但是每组顶点都是一个派。 例如：```
Input:
4 6 3 4

Output:
1 2 3 4
```即使派系的答案是立即的，仅检查缺失边缘的粗心实现也会失败。 

## 方法

 直接方法将枚举所需大小的每个可能的顶点组，并检查它是否形成派系或反派系。 对于目标大小为 5 的情况，这意味着粗略检查`n^5`组。 和`n = 300000`，这是完全不可能的。 

更好的方向来自于问题的结构。 我们并不是在寻找任意的子图。 我们只关心找到一个派系或者它的对立面，一个独立的集合，并且这两种派系的大小都最多为五个。 

选取一个顶点`v`。 每个有效组包含`v`必须从两个位置之一选择剩余的顶点。 如果该组是一个派系，则所有剩余顶点必须是`v`。 如果该群是一个反派，则所有剩余的顶点必须是非邻居的`v`。 

这给出了递归搜索。 寻找一个规模足够大的派系`c`或规模庞大的反派`i`，我们将当前候选集分为一个顶点的邻居和非邻居。 然后我们搜索一个大小的派系`c - 1`邻居之间，或规模较大的反派`i - 1`非邻居之间。 

蛮力方法会失败，因为它平等地对待每个子集。 递归方法仅遵循仍可包含所需结构之一的组合。 由于两个参数最多都是五个，因此递归深度很小。 拉姆齐理论提供了额外的保证，即如果不存在答案，则避免这两种结构的图不会很大。 在困难情况下，递归仅到达少量顶点。 

我们可以利用递归`R(a, b) <= R(a - 1, b) + R(a, b - 1)`与基本情况`R(1, x) = R(x, 1) = 1`。 这给出了一个集合的大小的安全上限，该集合必须包含一个大小为`a`或规模庞大的反派`b`。 如果候选集小于该值，则递归调用可以立即停止。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^5) | O(n^5) | O(1) | O(1) | 太慢了 |
 | 最佳| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 使用完整的顶点集开始递归搜索。 这些参数描述了派系和反派系还需要多少个顶点。 
2. 如果派系要求或反派系要求为一，则返回任意当前顶点。 单个顶点始终满足这两个定义。 
3. 如果当前候选集小于剩余要求的 Ramsey 界限，则停止该分支。 它不能包含有效的答案。 
4. 选择一个顶点`v`从当前集合。 将所有其他候选人分成两组。 第一组包含邻居`v`，第二组包含非邻居`v`。 
5. 搜索邻居组，同时将所需的派系大小减一。 这是正确的，因为团的每个附加顶点都包含`v`必须连接到`v`。 
6. 如果失败，则搜索非邻居组，同时将所需的反派大小减一。 这是正确的，因为反派的每个附加顶点都包含`v`必须避免`v`。 
7. 如果两次递归调用都失败，则该分支中不存在有效的结构。 继续返回失败，直到找到答案或根返回失败。 

为什么它有效：

 不变的是，每个递归调用都准确地接收仍然可以完成两个所需结构之一的顶点。 如果解包含所选顶点`v`，该解决方案的其余部分必须完全位于邻居组或非邻居组中。 递归探索了两种可能性，因此它不能丢弃有效答案。 拉姆齐界仅删除数学上保证不包含所请求大小的解的集合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k, l = map(int, input().split())

    graph = [[] for _ in range(n)]
    for _ in range(m):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        graph[a].append(b)
        graph[b].append(a)

    ramsey = [[0] * 6 for _ in range(6)]
    for i in range(1, 6):
        ramsey[1][i] = 1
        ramsey[i][1] = 1

    for i in range(2, 6):
        for j in range(2, 6):
            ramsey[i][j] = ramsey[i - 1][j] + ramsey[i][j - 1]

    mark = [0] * n
    token = 0

    def dfs(vertices, clique_need, indep_need):
        nonlocal token

        if clique_need == 1 or indep_need == 1:
            return [vertices[0]]

        if len(vertices) < ramsey[clique_need][indep_need]:
            return None

        v = vertices[0]

        token += 1
        cur = token
        for u in graph[v]:
            mark[u] = cur

        neigh = []
        non_neigh = []

        for u in vertices[1:]:
            if mark[u] == cur:
                neigh.append(u)
            else:
                non_neigh.append(u)

        if clique_need > 1:
            res = dfs(neigh, clique_need - 1, indep_need)
            if res is not None:
                return [v] + res

        if indep_need > 1:
            res = dfs(non_neigh, clique_need, indep_need - 1)
            if res is not None:
                return [v] + res

        return None

    ans = dfs(list(range(n)), l, k)

    if ans is None:
        print(-1)
    else:
        print(*[x + 1 for x in ans])

if __name__ == "__main__":
    solve()
```邻接表仅存储现有边，这是必要的，因为图可以有 300000 个顶点。 这`mark`array 避免了重复构建邻接集。 对于每个选定的顶点，其邻居接收当前标记值，从而允许通过候选列表的一次扫描将其分为邻居和非邻居。 

递归函数保留两个计数器。`clique_need`表示一个派系还需要多少个顶点，而`indep_need`对于反派来说也是如此。 当其中之一达到 1 时，当前顶点列表已包含有效的单个顶点答案。 

Ramsey 表使用上限而不是精确值。 这已经足够了，因为唯一的目的是修剪不可能的分支。 这些值很小，因为两个目标大小最多均为 5。 

返回的顶点在打印之前将转换回基于 1 的索引。 该实现自动避免整数溢出，因为 Python 整数具有任意精度。

 考虑：```
Input:

```该图没有边。 我们需要 4 点派系或 2 顶点反派系。 

| 步骤| 候选顶点| 派系需要| 反拉帮结派需要 | 行动|
 | ---| ---| ---| ---| ---|
 | 1 | 1,2,3,4 | 4 | 2 | 选择顶点 1 |
 | 2 | 空邻居| 3 | 2 | 派系分支失败 |
 | 3 | 2,3,4 | 4 | 1 | 返回顶点 2 |

 第二个分支立即成功，因为任何单个顶点都是大小为 1 的有效反派，与顶点 1 一起完成所请求的双顶点反派。 

考虑：```
Input:
4 6 3 4
```图表已完成。 

| 步骤| 候选顶点| 派系需要| 反拉帮结派需要 | 行动|
 | ---| ---| ---| ---| ---|
 | 1 | 1,2,3,4 | 4 | 3 | 选择顶点 1 |

 递归路径继续采用邻居侧，因为每个剩余的顶点都是连接的。 它重建了完整的派系。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n + m) | 每个大型递归分割仅扫描当前候选，并且递归深度以 10 为界，因为两个目标大小最多为 5。 
| 空间| O(n + m) | 邻接列表存储所有边，递归仅存储小的候选列表。 |

 该解决方案符合约束条件，因为递归的昂贵部分仅在候选集足够大且重要时才会发生。 拉姆齐界限保证不成功的搜索迅速缩小为小集合。

 ## 边缘情况

 对于单顶点的情况：```
Input:
1 0 5 1
```递归函数立即发现大小为 1 的团就足够了。 它返回唯一的顶点而不尝试检查边。 

对于空图：```
Input:
5 0 5 3
```选择顶点 1 会创建一个空的邻居组和一个包含顶点 2 到 5 的非邻居组。派分支因没有边而失败，但反派分支保留所有剩余顶点。 递归最终返回所有五个顶点，因为每对顶点都是断开连接的。 

对于完整的图表：```
Input:
5 10 3 5
```选择顶点 1 将每隔一个顶点放入邻居组中。 反派系一侧是空的，但派系一侧会重复删除一个所需的顶点，直到收集到五个顶点。 输出是图中的任意五个顶点。 

对于不存在结构的情况：```
Input:
5 5 3 3
1 2
2 3
3 4
4 5
1 5
```该图是一个长度为 5 的循环。 每个递归分割最终都会达到一个小于剩余要求的拉姆齐界限的候选集，证明没有分支可以包含三角形或大小为 3 的独立集。 算法返回`-1`。
