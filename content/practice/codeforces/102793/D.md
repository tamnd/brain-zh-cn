 ## 解决方案
 ## 问题理解

 此问题中的多米诺骨牌由带有一个垂直分隔符的一排点表示。 分隔符左右两侧的点是图块两半上的点数。 我们有两个这样的瓷砖，需要决定它们是否可以放在一起。 

如果第一张多米诺骨牌的至少一半上以及第二张多米诺骨牌的至少一半上出现了从 0 到 6 的某个数字，则两个多米诺骨牌可以匹配。 输出是`Yes`当存在这样一个共同的半值并且`No`否则。 原始问题陈述准确地描述了两个虚拟多米诺骨牌的兼容性条件。 

每一半最多包含六个点，因此输入字符串非常小。 直接检查所有可能的值已经是常数时间了。 即使我们忽略小边界并想象更大的字符串，我们也只需要检查每个多米诺骨牌的两半一次，这排除了对图算法、动态编程或模拟的任何需要。 

主要的边缘情况来自允许零点的事实。 具有零点的半多米诺骨牌由分隔符的空边表示，因此分隔符本身可能是第一个或最后一个字符。 

例如：```
|
.
```第一个多米诺骨牌的值为 0 和 0，而第二个多米诺骨牌的值为 0 和 1。正确的输出是：```
Yes
```一个粗心的实现，只计算点并忽略空边，会错误地处理第一张多米诺骨牌，并错过值 0 的匹配。 

另一种情况是等值不在同一侧时。```
.|...
....|.
```第一个多米诺骨牌包含值 1 和 3。第二个包含值 4 和 1。正确的输出是：```
Yes
```仅比较左半部分或仅比较右半部分的解决方案将错误地拒绝这一对。 

## 方法

 暴力方法是生成第一个多米诺骨牌的两个值，生成第二个多米诺骨牌的两个值，并将一个多米诺骨牌的每个值与另一个多米诺骨牌的每个值进行比较。 只有四次比较，因此操作次数是恒定的。 这种方法已经足够快了，因为输入仅包含两个多米诺骨牌。 

一个常见的错误是试图模拟连接多米诺骨牌的行为，从而使问题变得过于复杂。 条件要简单得多：两个图块只需要一个匹配的半值。 匹配的两半的位置并不重要。 

关键的观察是每个多米诺骨牌可以减少到一组最多两个数字。 一旦两个集合都建立起来，答案就是它们的交集是否非空。 暴力比较和基于集合的视图是等效的，但集合表示使推理更清晰，并避免丢失涉及零的情况。

 ## 算法演练

 1. 在垂直分隔符处分割每个输入字符串。 分隔符前后的点数给出了写在多米诺骨牌上的两个值。 
2. 存储每个多米诺骨牌的两个值。 该值可以为零，因此字符串的空部分仍必须算作有效的一半。 
3. 检查第一张多米诺骨牌上的任何值是否等于第二张多米诺骨牌上的任何值。 
4. 打印`Yes`如果找到匹配的值。 否则打印`No`。 

这样做的原因是兼容性的整个定义仅取决于两组半值是否共享至少一个元素。 两半的物理位置和多米诺骨牌的方向永远不会影响答案。 

## 为什么它有效

 该算法保留了每张多米诺骨牌所需的准确信息。 多米诺骨牌只有两个相关属性：左半边的点数和右半边的点数。 如果存在兼容的展示位置，则某些值`k`必须出现在两个多米诺骨牌的这两个值之间，并且算法会检查每个可能的对。 如果算法找到共同值，则该值满足所需条件。 如果没有找到，则无效`k`存在。 因此产生的答案总是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a = input().strip()
    b = input().strip()

    def values(s):
        left, right = s.split('|')
        return {left.count('.'), right.count('.')}

    first = values(a)
    second = values(b)

    print("Yes" if first & second else "No")

if __name__ == "__main__":
    solve()
```这`values`函数将多米诺骨牌描述转换为写在其两半上的两个数字。 分割依据`|`比手动扫描更安全，因为它自然会处理空的一半，例如`|`或者`...|`。 

使用集合可以消除重复。 例如，描述的多米诺骨牌`|`变成`{0}`，两半都包含三个点的多米诺骨牌就变成了`{3}`。 交集运算检查是否存在至少一个公共值。 

不使用索引，因此不存在边界问题。 直接计算点数还可以避免整数转换问题，因为所有可能的值都在 0 到 6 之间。

.|...
....|.
```第一张多米诺骨牌变成了`{1, 3}`第二个变成`{4, 1}`。 该算法比较完整的集合而不是仅匹配相应的边，找到共同值`1`，并打印：```
