 ## 解决方案
 ## 问题理解

 我们得到了总学分和两个根据隐藏课程列表计算的汇总统计数据。 每门课程都有一个整数学分值和 60 到 100 之间的整数分数。从这个隐藏列表中，每个学分单位对总计的贡献相等，因此系统的有效行为就好像每门课程都扩展到那么多单位加权分数条目一样。 

提供两个摘要：加权平均分和加权 GPA。 GPA 与分数之间并不是呈线性关系； 它是与 100 的距离的二次函数，这意味着它取决于分数与完美表现的距离，而不是分数本身。 

任务是确定任何多组单位学分分数是否可以准确地再现两个给定的聚合，如果可以，则构建一个有效的作业。 

关键的结构约束是单元贡献的总数最多为 250。这个值足够小，因此问题从根本上讲是在有界范围内的整数上构建离散分布，而不是在大序列上进行优化。 任何试图独立对待每门课程而不扁平化学分的方法都会使问题变得过于复杂，因为将学分分成单元贡献会完全消除层次结构。 

问题的微妙部分是同时固定分布的两个不同矩：平均分数和分数的二次变换。 这立即排除了任意构造，因为一旦均值固定，二阶矩就会严格限制方差。 

当将 GPA 约束视为独立于平均值时，会出现常见的失败情况。 例如，完全集中于平均分数的分布总是与平均分数匹配，但几乎从不与二次 GPA 匹配，除非平均值恰好是平方偏差完全匹配的整数分数。 当尝试将分数贪心舍入到附近的整数时，会发生另一个微妙的失败，这会近似保留平均值，但会破坏二次矩。 

## 方法

 如果我们将每门课程扩展为单位学分，问题就变成了精确构建 [60, 100] 范围内的 c 个整数，其平均值等于给定值 s̄，并且其在二次函数 g(s) 下的平均值与 ḡ 匹配。 

一个蛮力的想法是在 41 个可能的分数上尝试所有可能的大小为 c 的多重集。 这相当于将 c 个相同的球分配到 41 个容器中，这已经提供了一个巨大的状态空间，数量级为$\binom{c+40}{40}$，即使对于 c = 250，也远远超出了任何可处理的范围。 

关键的简化来自于观察到我们只匹配两个矩：线性矩（均值）和二次矩（变换后的类似方差的约束）。 对于此类问题，当域有界并且我们可以自由选择整数重数时，任何可行的分布始终可以使用最多两个不同的值来表示。 这将构造问题简化为查找是否存在两个分数 a 和 b，以及将 c 拆分为 k 和 c − k，从而完全满足两个约束。 

一旦我们确定了两个候选分数，系统就可以完全通过代数来求解：均值决定 k，而二阶矩则充当一致性检查。 由于分数的域很小，我们可以有效地枚举所有对。

 ## 算法演练

 我们首先通过将每个学分视为具有相同分数的独立单元来消除课程的层次结构，因为所有合计的学分都是线性的。 

然后我们将 GPA 公式转换为更简单的二次形式。 将每个分数 s 写为距 100 的距离，即 t = 100 − s，将 GPA 转换为 t² 的函数。 这将问题转化为匹配 t 值的均值和二阶矩。 

接下来我们计算所需的目标数量。 t 的平均值直接根据给定的平均分数确定，而 t² 的平均值是通过代数重新排列 GPA 公式得出的。 

然后，我们尝试仅使用两个不同的 t 值（例如 a 和 b）来表示分布。 我们固定一个顺序并假设 a 的 k 个副本和 b 的 c − k 个副本。 如果 a 和 b 不同，则平均条件唯一确定 k。 我们计算这个 k 并验证它是一个范围内的整数。 

之后，我们使用相同的计数验证二阶矩条件。 如果两个条件在数值容差范围内匹配，我们立即通过将 t 转换回分数来构建答案。 

如果没有对 (a, b) 有效，则不存在有效的两点分布，并且由于具有两个矩约束的有界整数域上的任何可行解都可以压缩为最多两个支持点，因此我们得出结论不存在解。 

### 为什么它有效

 该问题简化为在有限域上两个独立约束下匹配分布。 任何可行的解决方案都会在由这些约束定义的凸集中导出一个点。 在具有有界整数支持的一维中，该集合的极值点对应于最多两个值所支持的分布。 通过枚举所有此类极端配置，我们要么找到有效的分解，要么穷尽所有可能性，从而保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    c = int(input())
    sbar, gbar = map(float, input().split())

    # convert to t = 100 - s
    T = 100.0 - sbar
    Q = (4.0 - gbar) / 3.0

    eps = 1e-9

    # try all pairs of t values in [0, 40]
    for a in range(41):
        for b in range(41):
            if a == b:
                if abs(T - a) < eps and abs(Q - a * a) < eps:
                    print("YES")
                    print(1)
                    print(c, 100 - a)
                    return
                continue

            denom = a - b
            num = c * (T - b)

            if abs(denom) < eps:
                continue

            k = num / denom

            if abs(k - round(k)) > 1e-7:
                continue

            k = int(round(k))
            if k < 0 or k > c:
                continue

            # verify second moment
            lhs = (k * a * a + (c - k) * b * b) / c
            if abs(lhs - Q) > 1e-7:
                continue

            # build answer
            print("YES")
            print(c)
            for _ in range(k):
                print(1, 100 - a)
            for _ in range(c - k):
                print(1, 100 - b)
            return

    print("NO")

if __name__ == "__main__":
    solve()
```该解决方案首先将 GPA 约束转换为变换变量上的二次矩，这消除了原始公式的非线性外观。 对可能支持值的枚举直接在变换后的空间中完成，因为它保持算术稳定且对称于 100 左右。 

对于每个候选对，代码会得出匹配平均值所需的一个值的准确出现次数。 二阶矩检查仅用作一致性过滤器，确保数值错误或代数简并不会产生无效的构造。 

最后，一旦找到有效的配置，每个单元学分就会作为一门大小为 1 的独立课程发出，这满足了课程学分为正整数的原始要求。

 ## 边缘情况

 一个关键的边缘情况是所有课程必须具有相同的分数。 在这种情况下，方差为零，并且两个时刻都崩溃为单个值约束。 该算法在 a == b 分支中处理此问题，直接检查 T 和 Q 之间的一致性并输出均匀分布。 

当所需均值恰好位于整数边界但二次约束对应于非零方差时，会出现另一种边缘情况。 在这种情况下，不存在单值解，并且算法正确地回退到测试不同的对，其中平均方程强制拒绝小数 k。 

另一个微妙的情况是由平均方程重建 k 时的浮点精度引起的。 该解决方案在检查 k 的完整性时明确容忍较小的数值误差，确保从十进制输入导出的值不会由于舍入伪影而错误地失败。
