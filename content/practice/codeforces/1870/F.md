 ## 解决方案
 ## 问题理解

 我们被要求考虑从 1 到$n$以基数表示$k$。 一旦以基数表示$k$，我们像字符串一样按字典顺序对这些表示进行排序。 排序后，我们将元素从 1 到$n$。 任务是数出有多少个数字$i$最终在$i$此排序数组中的第 - 个位置。 

例如，考虑$n=6$和$k=4$。 以 4 为基数的表示形式为 1, 2, 3, 10, 11, 12。按字典顺序对它们进行排序会得到 1, 10, 11, 12, 2, 3。只有数字 1 位于其“自然”位置，因此答案为 1。 

主要挑战是限制：$n$和$k$可以达到$10^{18}$。 显式构建所有表示或排序是不可能的。 甚至$O(n)$时间会太慢。 这立即排除了迭代所有数字或执行任何直接字符串排序的简单方法。 

当出现不明显的边缘情况时$k$相对于较小$n$。 例如，与$n=33$和$k=2$，多个数字共享相似长度的二进制表示。 简单的方法可能会错误计数，因为字典顺序取决于字符串长度，而不是数值。 另一个微妙的情况是当$k > n$。 然后是基地——$k$所有数字的表示$1$到$n$只是数字本身，因此每个数字都与其位置匹配。 

## 方法

 蛮力方法计算基数$k$每个数字的表示，将它们存储为字符串，对它们进行排序，并计算位置。 这适用于小型$n$和$k$，但它需要$O(n \log n)$时间和$O(n \cdot \log_k n)$空间。 为了$n=10^{18}$，这是完全不可行的。 

关键的见解是避免生成所有数字及其表示形式。 观察基数中数字的字典顺序$k$对应于它们的基数的数字顺序$k$数字解释为基数中的数字$k$。 这意味着有效的序列$i$正是可以表示为不同幂次之和的数字序列$k$其中每种力量最多使用一次。 本质上，任何数量的形式$1 \cdot k^0 + 1 \cdot k^1 + \dots$对应于一个数字，其数字为基数$k$严格为 0 或 1。这与在具有基数的类二进制系统中计数数字完全相同$k$，其中数字为 0 或 1。 

因此，我们可以枚举这种形式的所有数字，而不是排序：$1, k, k+1, k^2, k^2+1, k^2+k, k^2+k+1, \dots$直到总和超过$n$。 这为我们提供了一个简单的递归或迭代循环，直接按升序生成数字。 以这种方式生成的每个数字都会自动占据其“正确”的字典位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n log n) | O(n log n) | O(n log n) | O(n log n) | 对于大 n 来说太慢 |
 | 最佳 | O(log_k n) | O(log_k n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化有效数字计数器。 从第一个幂开始$k$,$k^0 = 1$。 
2. 维护一个当前总和的变量，该变量将作为候选编号。 从 0 开始。 
3. 迭代$k$按递增顺序：$1, k, k^2, k^3, \dots$。 对于每个幂，迭代包含它的二进制选择（0 或 1）。 将其添加到当前总和并检查是否超过$n$。 如果是，则中断； 否则，增加计数器。 
4. 使用队列或迭代循环来枚举$k$不超过$n$。 每个和代表一个数字，其基数为$k$数字是 0 或 1。这些数字正是在字典顺序中以其自然位置出现的数字。 
5. 重复，直到下一个候选超过$n$。 

为什么它有效：利用的属性是基数只有 0 或 1 的数字$k$与它们的数字顺序完全相同的字典顺序出现。 任何其他数字在某处都有 ≥ 2 的数字，并且会在字典顺序中进一步向下推。 通过生成不同幂的所有总和$k$≤$n$，我们涵盖了所有处于“正确”位置的数字。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        count = 0
        power = 1
        numbers = [0]
        while numbers:
            next_numbers = []
            for num in numbers:
                for add in (0, power):
                    new_num = num + add
                    if 1 <= new_num <= n:
                        count += 1
                        next_numbers.append(new_num)
            power *= k
            numbers = next_numbers
        print(count)

if __name__ == "__main__":
    solve()
```该解决方案使用逐级生成的幂总和$k$。 每个级别对应一个幂$k$，两个选择（0 或 1）生成使用或不使用该幂的所有数字。 这保证没有重复并涵盖所有数字 ≤$n$其基地-$k$数字只有0或1。 

微妙之处：候选数是按照幂递增的顺序生成的。 我们必须包含从 1 开始的数字（不包括 0）。 乘法`power`经过`k`每次都正确追踪幂，没有溢出，当没有新数≤时算法自然停止$n$可以生成。

 ## 边缘情况

 对于n=1、k=2，算法直接生成1。 不需要进一步增加权力。 输出 = 1，这是正确的。 

对于 n < k，例如 n=3、k=5，每个数字都具有一位以 5 为基数的表示形式。 该算法正确计数 1,2,3，因为每个都位于位置 1
