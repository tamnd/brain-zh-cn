 ## 解决方案
 ## 问题理解

 我们有一个严格递减的横幅值数组 (P_1>P_2>\dots>P_N)。 我们必须在不改变其顺序的情况下将横幅分割成恰好 (K) 个非空连续块。 

对于块（s），假设它包含位置（l，\ ldots，r）。 由于 (P) 严格递减，因此块中的最大值始终为 (P_l)，而最小值为 (P_r)。 因此它的贡献是

 [
 P_r(r-l+1)-L_sP_l。 
]

 分区的值是所有 (K) 个块的这些贡献的总和。 我们需要尽可能大的价值。 

约束 (N\le 50000) 排除每个块编号内 (N) 中的任何二次方。 对于 (K\le100)，(O(KN^2)) 动态程序将以最大值执行大约 (1.25\cdot10^{11}) 转换，远远超出两秒的限制。 目标应该接近 (O(KN)) 或可能 (O(KN\log N))。 

(P) 的严格递减是使优化成为可能的结构特性。 它为我们提供了每个连续块的最小值和最大值的简单表达式，以及凸包技巧的单调查询值。 

第一种边缘情况是(N=1)、(K=1)。 为了```
1 1
5
7
```唯一的块具有值 (5-7\cdot5=-30)，所以答案是 (-30)。 将答案或每个 DP 状态初始化为零的实现将默默地返回错误结果，因为最佳值可能为负。 

另一个边缘情况是（K=1）。 为了```
3 1
8 5 2
3
```根本没有选择。 整个数组为一个块，其值为(2\cdot3-3\cdot8=-18)。 DP 实现不得意外地允许额外的剪切或空块。 

相反的边界是(K=N)。 为了```
3 3
9 4 1
0 0 0
```每个横幅都是一个单例块，所以答案是（9+4+1=14）。 这可以捕获省略第一个或最后一个可能的剪切的索引错误。 

输入保证 (P_i>P_{i+1})，因此所有 (P_i) 相等的数组不是有效的测试用例。 然而，Equal (L_i) 是完全有效的，并且对于测试实现很有用，因为每一层的块惩罚都是相同的。 

## 方法

 直接动态程序考虑最后一次切割的位置。 令 (dp_s[r]) 为前 (r) 个横幅分割成 (s) 个块的最大值。 如果最后一个块从 (l) 开始，则前面的 (s-1) 个块覆盖位置 (1\ldots l-1)，最后一个块贡献

 [
 P_r(r-l+1)-L_sP_l。 
]

 因此

]

 这种递归已经是正确的，但评估每个 (r) 的所有可能 (l) 的成本 (O(KN^2))。 对于 (N=50000) 和 (K=100)，这大约是 (1.25\cdot10^{11}) 个候选转换。 

展开包含 (P_r) 的项后，会出现有用的观察结果：

 ## lP_r

\结束{对齐}
 ]

 对于固定 (l)，最大值内的表达式是在 (x=P_r) 处计算的一条线：

 [
 y=(-l)x+\left(dp_{s-1}[l-1]-L_sP_l\right)。 
]

 因此，每个可能的起始位置 (l) 都会创建一条具有斜率 (-l) 和截距 (dp_{s-1}[l-1]-L_sP_l) 的直线。 

随着 (r) 增加，斜率会按降序插入，因为 (-1,-2,-3,\ldots) 减少。 同时，由于原(P)数组是严格递减的，所以按降序查询(P_r)。 这正是单调的情况，其中双端队列式凸包技巧为每个插入行和每个查询提供摊销 (O(1)) 工作。 

暴力递归仍然是解决方案的基础。 凸包技巧仅改变如何维持所有先前起始位置的最大值。

 ## 算法演练

 1. 将 (dp_s[r]) 定义为将前缀 (P_1,\ldots,P_r) 精确划分为 (s) 个块的最佳值。 我们只需要前一层，所以实现存储`prev[r]`和`cur[r]`。 
2. 对于固定的块号，将转换重写为

 P_r(r+1)
 +
 \max_l
 \左（
 (-l)P_r+
 dp_{s-1}[l-1]-L_sP_l
 \右）。 
]

 取决于 (l) 的部分现在是一条在 (x=P_r) 处评估的线。 

1. 处理(r=s,s+1,\ldots,N)时，插入(l=r)对应的行。 其斜率和截距为

 [
 m=-r,
 \qquad
 b=dp_{s-1}[r-1]-L_sP_r。 
]

 该行有效，因为前面的块恰好占据了第一个 (r-1) 个位置。 

1. 保持插入的线为上凸包。 由于坡度严格递减，新插入的线只能使靠近船体末端的一些线变得无关紧要。 对于三个连续线 (A,B,C)，当 (A) 和 (B) 的交点不在 (B) 和 (C) 交点的右侧时，不需要线 (B)。 

对于斜率递减的线 ((m_1,b_1),(m_2,b_2),(m_3,b_3))，可以在不使用浮点的情况下检查此条件：

 [
 (b_2-b_1)(m_2-m_3)
 \le
 (b_3-b_2)(m_1-m_2)。 
]

 整数交叉乘法可避免精度误差。 

1. 查询 (x=P_r) 处的船体。 由于 (P_r) 随着 (r) 的增加而减少，因此最佳线仅向前穿过船体。 虽然第二行在当前 (x) 处给出的值至少与第一行一样大，但丢弃第一行。 任何被丢弃的行都无法再次变为最佳，因为所有未来的查询值都会更小。 
2. 令(P_r)处的最佳线具有值(mP_r+b)。 套装

 [
 dp_s[r]=P_r(r+1)+mP_r+b。 
]

 处理完所有(r)后，替换`prev`和`cur`并继续下一个块。 

1. 正好 (K) 层之后，`prev[N]`是所有 (N) 个横幅恰好分成 (K) 个块的最大值，因此它是所需的答案。 

不变的是，在每次查询之前，活动外壳恰好包含与当前最后一个块的所有有效可能起始位置相对应的行，并且永远无法成为最佳的每一行都已被删除。 斜率和查询值的单调性保证从任一端删除线是永久性的。 因此，为每个 DP 状态选择的线是所有有效的先前切割中可能的最佳转换。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, k = map(int, input().split())
    p = list(map(int, input().split()))
    L = list(map(int, input().split()))

    neg_inf = -(10 ** 30)

    # prev[r] = best value for the first r elements using the
    # already processed number of blocks.
    prev = [neg_inf] * (n + 1)
    prev[0] = 0

    for s in range(1, k + 1):
        cur = [neg_inf] * (n + 1)
        loss = L[s - 1]

        # Hull is stored in two parallel arrays.
        # Lines are kept in decreasing slope order.
        slopes = []
        intercepts = []
        head = 0

        for r in range(s, n + 1):
            # Add the line corresponding to l = r:
            #
            # y = (-l) * x + prev[l - 1] - loss * P_l
            m = -r
            b = prev[r - 1] - loss * p[r - 1]

            while len(slopes) - head >= 2:
                m1 = slopes[-2]
                b1 = intercepts[-2]
                m2 = slopes[-1]
                b2 = intercepts[-1]

                # Remove the middle line if it is redundant.
                if (b2 - b1) * (m2 - m) <= (b - b2) * (m1 - m2):
                    slopes.pop()
                    intercepts.pop()
                else:
                    break

            slopes.append(m)
            intercepts.append(b)

            x = p[r - 1]

            # Queries arrive with decreasing x, so the optimum
            # moves only from the front toward the back.
            while len(slopes) - head >= 2:
                v1 = slopes[head] * x + intercepts[head]
                v2 = slopes[head + 1] * x + intercepts[head + 1]

                if v1 <= v2:
                    head += 1
                else:
                    break

            best_line = slopes[head] * x + intercepts[head]
            cur[r] = x * (r + 1) + best_line

        prev = cur

    print(prev[n])

if __name__ == "__main__":
    main()
```DP初始化使用`prev[0] = 0`，这意味着在创建任何块之前，空前缀的值为零。 所有其他状态都从负无穷大开始，因为不可能的划分绝不能参与最大值。 

起始位置线`r`用途`prev[r - 1]`和`p[r - 1]`因为 Python 使用从零开始的索引，而数学位置 (r) 是从一开始的。 坡度为`-r`， 不是`-(r - 1)`，因为代数包含项 (-lP_r) 以及基于 1 的位置 (l)。 

船体按降序存储坡度。 冗余测试仅使用整数乘法，因此不需要浮点交点坐标。 这很重要，因为涉及的值可能足够大，以至于浮点比较可能会丢失准确的顺序。 

这`head`索引充当双端队列的前面。 当查询丢弃行时，行不会被物理删除，这避免了 (O(N)) 移位操作。 每行追加一次，最多一次从后面删除，最多一次由查询指针传递。 

Python整数具有任意精度，因此凸包测试和DP使用的乘积不会溢出。 在 Python 中仍然可以轻松管理最大的中间值。

 ## 边缘情况

 对于最小尺寸的情况```
1 1
5
7
```第一个 DP 层创建唯一可能的线 (l=r=1)。 其截距为 (0-7\cdot5=-35)，查询根据转换后的表达式贡献 (5\cdot2-35=-25)。 更直接地说，原始块值为(5-35=-30)，使用(P_r(r+1)-lP_r=5)后变换后的表达式也给出(-30)。 最终的答案是`-30`。 该实现从不将其与人为的零值进行比较。 

对于（K=N），```
3 3
9 4 1
0 0 0
```第一层计算最佳单块前缀，第二层只能在（r=2）或更晚结束，第三层必须在（r=3）时从（l=3）开始。 唯一有效的分区是 (9\mid4\mid1)，产生`14`。 循环边界`range(s, n + 1)`严格执行此限制。 

对于同等损失，```
3 2
6 4 1
3 3
```两个可能的分区是 (6\mid(4,1)) 和 ((6,4)\mid1)。 他们的价值观是

 [
 6+(2-3\cdot4)=0
 ]

 和

 [
 2\cdot4-3\cdot6+1-3=-12。 
]

 最优的是`0`。 相等 (L) 值不会影响凸包参数，因为斜率仍然仅由起始位置 (l) 决定。 

对于边界重的情况```
4 2
8 7 2 1
0 100
```第二个区块的惩罚强烈倾向于使其最大值尽可能小。 最优分区为(8,7,2\mid1)，值为

 [

 船体在 (r=4) 时恰好考虑 (l=4) 的线，因此最终可能的起始位置不会丢失。 这是优化分区 DP 中常见的逐一故障。
