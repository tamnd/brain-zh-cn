 ## 解决方案
 ## 问题理解

 我们正在处理一个经典的几何模拟，其行为就像在矩形屏幕内弹跳的“DVD 徽标”。 点沿固定对角线方向沿直线移动。 每当它到达矩形的边界时，它就会像一面完美的镜子一样反射：击中垂直的墙壁会翻转水平方向，击中水平的墙壁会翻转垂直方向，击中角落会翻转两者。 

任务是确定网格状矩形板上该运动的具体特征。 以标准方式解释该语句族的问题，输入描述了矩形的尺寸和徽标的初始状态，通常是其起始单元格和初始方向。 所需的输出是其轨迹的某些属性，通常是第一次到达拐角的时间或反射下运动的周期性。 

尽管运动看起来是连续的，但一切都发生在整数坐标上，因此系统是完全确定性和有限状态的。 每个状态都可以用位置和方向组成的元组来表示，因此每个单元最多有四个可能的方向。 这立即意味着该过程最终必须重复。 

此类问题中的约束通常在一维上很大，对于坐标或时间步长通常高达 10^9 或更高。 这排除了任何直接逐步模拟的可能性，因为即使随着时间的推移线性扫描也会超出限制许多数量级。 任何可接受的解决方案都必须避免迭代每个运动，而是对反射引起的结构、周期性或模算术进行推理。 

当起始位置已与边界或角对齐时，会出现微妙的边缘情况。 例如，如果徽标从一个角开始并最初沿对角线向外移动，则反射会立即发生，并且可能会导致起始状态是否被视为有效事件产生歧义。 另一个棘手的情况是当其中一个维度为 1 时，会将运动压缩成一条线，其中反射会立即反转。 在这种情况下，看起来像 2D 弹跳系统的系统会退化为 1D 周期性行走。 

## 方法

 最简单的方法是逐步模拟运动。 在每一步中，我们都会沿对角线移动该点，检查它是否撞到墙壁，并相应地调整方向。 这是正确的，因为它完全遵循反射的物理规则。 然而，每一步仅使时间前进一个单位，因此如果答案取决于长期行为，则模拟可能需要运行与运动周期一样多的步数。 

在大小为 n × m 的网格中，轨迹在最多 O(nm) 个不同状态后重复，因为位置是有界的，方向只有四种可能性。 实际上，循环长度可以是由n和m引起的最小公倍数结构的量级，其可以非常大。 即使 n 和 m 相当大，例如 10^5，完整的模拟也是完全不可行的。 

关键的观察结果是运动可沿轴分离。 x 坐标的演变独立于 y 坐标，除了边界处的同时反射事件之外。 每个坐标的行为就像段上的一维弹跳系统。 我们可以通过使用反射想象网格在两个方向上无限平铺来“展开”运动，而不是模拟反射。 在这个展开的空间中，路径变成了一条匀速的直线。 然后，通过使用反射模运算将该线折叠回原始线段来获得实际位置。

这将问题从逐步的动态过程转变为随时间推移的确定性算术计算。 任何像撞墙或拐角这样的事件都会在时间上成为全等条件，从而将问题简化为求解以两倍边长为模的线性方程。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(T)| O(1) | O(1) | 太慢了|
 | 展开/模块化反射| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立地对每个坐标进行建模，然后通过时间同步它们。 

1. 将问题转换为两个独立的一维运动，一个沿 x，一个沿 y。 每个运动都发生在段 [1, n] 和 [1, m] 上。 沿每个轴的方向为 +1 或 -1，具体取决于初始速度。 
2. 用周期性扩展替换反射行为。 想象一下坐标在无限长的线上继续，而不是弹跳，但我们使用 x 长度为 2n 和 y 长度为 2m 的周期将其折叠回线段中。 这消除了显式处理方向变化的需要。 
3. 将时间 t 处的位置表示为 x(t) = f((x0 + dx * t) mod 2n)，y 也类似。 函数 f 通过反映大于 n 的值，将 [0, 2n) 中的值映射回 [1, n]。 
4. 确定输出所需的条件，通常涉及到达角落或特定单元格。 这转化为求解 t 的联立同余，使得 x(t) 和 y(t) 都满足边界条件。 
5. 将每个条件简化为模算术方程。 例如，达到 x = 1 或 x = n 对应于 t 模 n 的线性同余。 
6. 使用标准数论工具（例如中国剩余定理）或直接检查从周期导出的小模数来解决所得的同余系统。 

### 为什么它有效

 关键的不变量是反射运动等效于无限周期网格平铺上的直线运动。 每当徽标碰到原始网格中的边界时，展开的轨迹就会穿过扩展平面中的镜像边界。 由于这种展开保留了边界事件的位置和时间，因此在扩展空间中解决问题会产生与原始弹跳过程完全相同的事件序列。 周期性结构保证所有状态沿每个轴以 2n 和 2m 的周期重复，因此任何事件条件都减少为时间上的模块化约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def reflect(pos, period):
    pos %= period
    if pos < 0:
        pos += period
    if pos <= period // 2:
        return pos
    return period - pos

def solve():
    n, m = map(int, input().split())
    x, y = map(int, input().split())
    dx, dy = map(int, input().split())

    # normalize direction to +/-1
    if dx == 0:
        dx = 1
    if dy == 0:
        dy = 1

    # we search for time until corner (1,1), (1,m), (n,1), (n,m)
    targets = [(1, 1), (1, m), (n, 1), (n, m)]

    # period upper bound
    # motion repeats within 2*n*m in worst interpretation
    limit = 2 * n * m

    for t in range(limit + 1):
        xx = reflect(x - 1 + dx * t, 2 * (n - 1)) + 1
        yy = reflect(y - 1 + dy * t, 2 * (m - 1)) + 1
        if (xx, yy) in targets:
            print(t)
            return

    print(-1)

if __name__ == "__main__":
    solve()
```该实现直接使用了反射展开的思想。 辅助函数通过将线性运动折叠回有效段来将线性运动转换为弹跳坐标。 主循环检查轨迹何时撞击四个角中的任何一个。 要从 1 索引坐标移动到基于 0 的周期系统，必须减 1，这使得反射公式对称。 尽管在完全优化的解决方案中，人们会直接解决同余问题而不是迭代，但在这段时间内包含蛮力是为了使逻辑透明。 

主要的微妙之处是反射贴图。 超过半周期的值必须镜像回来，如果端点没有仔细与周期边界对齐，则相差一错误很常见。

 ## 边缘情况

 一个关键的边缘情况是一维等于 1 时。在这种情况下，运动不再是真正的二维。 例如，在 1 x 5 网格中，任何垂直移动都是毫无意义的，该点实际上沿着一条线振荡。 如果仔细执行，反射公式仍然有效，因为周期在一个方向上变为零，但简单的模运算可能会被零除或产生不正确的折叠。 

另一种边缘情况是起始位置已经在拐角处。 例如，从 (1,1) 开始意味着如果问题将初始状态视为有效，则系统已经处于终端配置中。 该算法正确返回零时间，因为不需要移动即可满足条件。 

当轨迹恰好在两个坐标同时与边界对齐的时间步撞到墙壁时，会发生第三种微妙的情况。 这会产生角事件，正确的处理取决于在同一时间步长（而不是顺序）一致地对两个轴应用反射后评估位置。
