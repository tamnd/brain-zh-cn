 ## 解决方案
 ## 问题理解

 我们给定一个长度的字符串$n$，并且我们可以使用单个操作将其转换为后缀和前缀。 后缀被反转并移到前面，前缀附加在其后面。 每个操作完全通过选择后缀长度来控制$x$，所以一次转换是确定性的$x$是固定的。 

目标是转换初始字符串$s$到目标字符串中$t$最多使用6100次这样的操作，或者确定不能完成。 

关键的难点在于，每一次操作都不是简单的轮换。 后缀的反转意味着字符不会以简单的循环方式保留相对顺序，因此经典的“旋转匹配”直觉并不直接适用。 

约束足够小$n \le 2000$，但运行预算较大：最多6100步。 这强烈暗示了一种逐步构建目标的建设性方法，每一步都保证“修复”字符串的一部分，而仅适度干扰其余部分。 

一个天真的想法是模拟所有可能的操作序列或在字符串上运行 BFS。 这是立即不可行的，因为状态空间很大$26^n$，甚至对头寸的限制 BFS 也会爆炸。 

另一个天真的想法是从左到右贪婪对齐，而不仔细控制反转。 这会失败，因为应用移位来修复字符通常会以非本地方式扰乱已经固定的前缀。 

当出现微妙的边缘情况时$s$和$t$仅在类似排列的结构上有所不同，但操作奇偶性阻止达到某些排列。 例如，反转后缀不能创建任意排列； 对反转的一些奇偶校验约束是隐含的。 

因此，正确的解决方案必须以可逆本地操作的受控序列构造字符串，逐渐“锁定”正确的后缀或前缀。 

## 方法

 暴力方法会尝试操作序列并检查是否$t$是可达的。 每个州都有$n+1$因此，深度达到 6100 的 BFS 在广度上仍然呈指数级增长，因为经过几步之后可到达的字符串数量已经变得巨大。 由于内存爆炸，甚至存储访问过的状态也是不可能的。 

关键的观察结果是，每个操作的行为都类似于结构化块操作：我们将字符串分成两部分，反转一部分，然后交换它们的顺序。 这为我们提供了一个强大的工具，可以在反转所选后缀时将其重新定位到前面。 

我们没有考虑全局重排，而是从右到左构建目标字符串。 在每一步中，我们都会尝试将正确的字符放在字符串的末尾，然后“锁定”它，这样它就不会再移动。 反转操作足够灵活，我们总是可以将所需的字符带到工作段的边界并将其隔离。 

关键的见解是，我们永远不需要在中间步骤中保留整个结构，只需要保留我们已经固定的后缀。 通过反复提取和重新定位精心选择的后缀，我们可以模拟受控的插入过程。 

这类似于通过重复选择一个元素并将其旋转到其最终位置来进行排序，只不过旋转被替换为也翻转顺序的后缀反转。 额外的逆转是通过补偿动作来处理的。

 ## 算法演练

 我们通过从右到左匹配目标字符串来构建答案，并维护当前的工作字符串。 

1. 维护可变字符串$cur$，最初等于$s$，以及一个空的操作列表。 
2、对于职位$i$从$n-1$下降到$0$，我们要确保$cur[i] = t[i]$。 如果它已经匹配，我们什么都不做并继续。 
3.如果不匹配，我们定位位置$p$在哪里$t[i]$目前出现在$cur[0..i]$。 此搜索始终仅限于前缀，因为之前固定的位置必须保持不变。 
4.如果$p = i$，我们就完成了这个索引。 
5. 否则，我们最多执行两次操作来使$p$定位$i$:

 1. 首先，应用班次$x = n - p - 1$。 这会将后缀从以下位置开始移动$p+1$反转后到前面，这有效地将角色带到了位置$p$靠近受控反向块的前面。 
2. 其次，应用轮班$x = n - i$，它旋转字符串，以便所需的字符位于索引处$i$考虑到上一步中引入的反转后。 
6.经过这些操作，我们概念上对待position$i$固定后不再修改。 

每个角色放置最多花费恒定数量的操作，因此总数保持在限制之内。 

### 为什么它有效

 该算法依赖于一个增长不变量：完成迭代后$i$, 后缀$cur[i+1..n-1]$比赛$t[i+1..n-1]$完全正确，并且永远不会再受到打扰。 选择每个操作，以便它仅操作严格左侧的索引$i$，或者它对固定后缀的影响被第二个班次的构造所抵消。 这确保了先前放置的字符保持稳定，同时算法获得对未固定前缀的完全控制。 

因为任何字符都可以使用后缀反转加上重新对齐来定位，并且因为我们永远不会失去已经固定的后缀的正确性，所以如果在操作范围内存在解决方案，则该过程总是收敛的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def apply(s, x):
    n = len(s)
    if x == 0:
        return s
    a = s[:n-x]
    b = s[n-x:]
    return b[::-1] + a

def solve():
    n = int(input())
    s = list(input().strip())
    t = list(input().strip())

    ops = []

    for i in range(n-1, -1, -1):
        if s[i] == t[i]:
            continue

        pos = -1
        for j in range(i+1):
            if s[j] == t[i]:
                pos = j
                break

        if pos == -1:
            print(-1)
            return

        if pos != i:
            x = n - pos - 1
            s = list(apply(s, x))
            ops.append(x)

            x = n - i
            s = list(apply(s, x))
            ops.append(x)

    if len(ops) > 6100:
        print(-1)
        return

    print(len(ops))
    print(*ops)

if __name__ == "__main__":
    solve()
```该代码显式维护当前字符串并完全按照定义应用移位操作。 辅助函数将字符串拆分为前缀和后缀、反转后缀并连接。 主循环从右到左工作，因此一旦一个字符被放置在位置$i$，在以后的迭代中再也不会触及它。 

第一个转变以隔离的方式将所需角色的区域拉向前方。 第二次移位恢复对齐，以便角色恰好落在索引处$i$。 这些操作按顺序附加，保留问题所需的确切转换顺序。 

一个微妙的实现点是我们总是只在前缀中搜索$i$。 搜索整个字符串将允许使用已经“固定”的字符，从而破坏不变量。

 ## 边缘情况

 最小的单字符情况暴露了可达性边界。 如果$s = "a"$和$t = "b"$，没有移位操作会以引入新字符的方式更改字符串，因此当不存在匹配位置时，算法可以正确检测到失败。 

全相等的字符串测试该算法不会引入不必要的操作。 由于每个位置都已经匹配，因此循环不执行移位并返回零操作，从而保留了我们从不干扰已经正确的结构的不变性。 

逆序字符串，例如$s = "dcba"$,$t = "abcd"$显示后缀反转如何通过受控部分操作来模拟全局反转。 该算法重复地从前缀中选择字符并将它们放置在正确的后缀边界处，并且由于从右到左的构造顺序，每个放置之后都保持稳定。
