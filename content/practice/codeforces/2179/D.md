 ## 解决方案
 ## 问题理解

 我们被要求构造一个所有整数的排列$0$到$2^n - 1$。 排列的质量是通过前缀上的运行过程来定义的：我们维护到目前为止看到的前缀的按位与，并且在每一步中，我们将该 AND 值中的设置位数添加到分数中。 

因此，当我们从左到右扫描排列时，该值从第一个元素开始，然后成为前两个元素的 AND，然后是前三个元素的 AND，依此类推。 每个前缀都会贡献一个 popcount，我们希望这些 popcount 的总和尽可能大。 在达到最大可能分数的所有排列中，我们被要求输出字典顺序最小的排列。 

该结构与一整套长度位掩码上的位操作紧密相关$n$。 自从$n \le 16$，宇宙大小最多为$2^{16} = 65536$，所以我们可以负担得起$O(2^n)$或者$O(2^n \log 2^n)$结构，但任何阶乘或涉及明确的排列都是不可能的。 

一个天真的想法是尝试所有排列并计算分数，但即使对于$n = 4$， 那是$16!$，已经远远超出了极限。 即使贪婪的本地交换也会失败，因为分数取决于前缀 AND 链，而不是相邻结构。 

字典编纂的极简性产生了一种微妙的边缘情况。 两个排列可以具有相同的最佳分数，但在排序的早期有所不同。 例如，对于$n=2$， 两个都$[3,1,0,2]$和$[3,2,0,1]$最大化分数，但如果我们坚持字典序最小化，则只有一个有效。 这迫使确定性构造而不是任何任意的最佳解决方案。 

## 方法

 关键的困难是理解什么结构增加了前缀和流行计数的总和。 

蛮力方法将枚举所有排列$2^n$元素，计算前缀 AND，并评估分数。 每次评估费用$O(2^n \cdot n)$，并且有$(2^n)!$排列。 即使对于$n=3$。 

重要的观察是扭转观点。 不要考虑排列，而要考虑前缀 AND 如何演变。 随着我们的进展，AND 运算只会丢失一些位。 一旦某个位在运行 AND 中变为零，它就永远不会返回。 因此，我们的目标是尽可能长时间地保持尽可能多的位。 

这建议按位模式对数字进行分组，以便我们逐渐而不是激进地消除约束。 最佳结构遵循最高有效位的递归分解：我们希望确保较高位在早期前缀中保持活动状态，这意味着我们应该对数字进行排序，以便转换尊重按位分区。 

这自然会导致递归构造：$n$位，根据最高位将数字分成两半，并以尽早保留大 AND 值的方式将它们交错。 在每一半场中，我们都重复相同的策略。 这本质上是类似格雷码的结构，但由最大化前缀和稳定性而不是邻接差异驱动。 

然后，字典顺序最小约束强制对称选择之间的固定排序：当存在多个最佳交错时，我们必须首先选择较小的可用数字。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O((2^n)! \cdot 2^n)$|$O(2^n)$| 太慢了 |
 | 递归位分区构造 |$O(2^n)$|$O(2^n)$| 已接受 |

 ## 算法演练

 该构造在位长度上是递归的。 

1. 考虑以下所有数字$0$到$2^n - 1$。 将它们分为两组：最高位设置为 0 的组和最高位设置为 1 的组。这种分离隔离了数字是否有助于保留早期前缀 AND 中的最高位。 
2. 使用以下方法递归地解决每个组的问题$n-1$位，通过剥离最高位。 此步骤确保我们在每一半内保留最佳结构，而不必担心顶部位。 
3. 合并两个递归结果，但将具有较高位的组放在前面，这样有助于更长时间地保留较大的前缀 AND 值。 由于第二组中的所有数字都设置了最高位，因此将它们放在较早的位置可以使该位在更多前缀 AND 计算中保持活动状态。 
4. 在每个递归调用中，确保在等分构造中，当选择对称时，始终优先选择较小的实际值，从而确保字典顺序最小。 
5. 当从递归返回时，通过将最高位重新附加到第二组元素来恢复实际值。 

该结构的行为类似于位位置上的二叉树。 每个级别控制一位，确保它在与相反组混合而被迫归零之前尽可能长时间地保持活动状态。 

### 为什么它有效

 运行 AND 仅减少设置位。 每个前缀的分数都会有一点贡献，直到我们第一次包含在该位置具有零的元素。 为了最大化总贡献，我们希望高位尽可能晚地消失，这意味着我们必须延迟混合高位不同的数字。 

通过根据最重要的不同位对数字进行分组，并在引入另一组之前耗尽一组，我们最大限度地延长了前缀 AND 中高阶位的寿命。 递归确保相同的逻辑适用于每个较低位，因此该结构在每个尺度上都是最佳的。 字典序的最小性得以保留，因为在每个有效的最佳分区中，我们总是首先扩展较小的标签。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build(n):
    if n == 0:
        return [0]

    prev = build(n - 1)

    # numbers with highest bit = 0
    zero = prev

    # numbers with highest bit = 1
    one = [x | (1 << (n - 1)) for x in prev]

    # key idea: put larger-block first to preserve high bits longer
    return one + zero

t = int(input())
for _ in range(t):
    n = int(input())
    print(*build(n))
```递归构造了所有的排列$2^n$通过构建解决方案来掩盖$n-1$位，然后将其复制为两半：一半最高位为 0，另一半为 1。或运算在递归后恢复正确的数值。 

订购方式`one + zero`是关键的设计选择。 它确保具有最高位设置的所有数字首先出现，以便在引入任何零高位元素之前，该位在前缀 AND 中保持设置，以达到最大可能的步数。

 ## 边缘情况

 一个微妙的案例是$n=1$，其中之间的决定$[0,1]$和$[1,0]$直接决定分数。 该结构将高位元素放在第一位，产生$[1,0]$，这确保了单个位的贡献最大化。 

为了$n=2$， 两个都$[3,2,1,0]$和其他排列，例如$[3,1,0,2]$获得最佳分数，但递归构造修复了单个确定性排序。 第一个元素始终是最大值，因为它属于最高位组。 逐步运行递归表明，在任何较低位元素出现之前，最高位块已完全耗尽，从而保留了较高位尽可能长时间保持活动状态的不变性。 

对于较大的$n$，同样的推理也适用于归纳：在每个位级别，算法确保相应的位不会因过早混合分区而过早地被破坏，这保证了所有前缀的最大累积弹出计数。
