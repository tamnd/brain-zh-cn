 ## 解决方案
 ## 问题理解

 我们被要求根据二元模式将选民划分为选区，同时尊重最小选区规模。 具体来说，我们有 A 和 B 两方，总共有`x`和`y`分别是选民。 有`n`各区以及各区`i`至少需要`p_i`选民总数。 我们还得到了一个二进制字符串`s`长度`n`表示每个区期望的获胜者：如果`s_i = 0`，A方在选区的选民人数必须多于B方`i`; 如果`s_i = 1`，B 方的选民数量必须多于 A 方。 

我们的任务是确定是否可以以这样的方式分配选民，使每个选区都有一个与字符串匹配的获胜者`s`同时满足最低选民人数。 

限制是巨大的。`n`最大可达 2·10^5，并且`n`所有测试用例不超过2·10^5。 每个选民都算数`x`,`y`，以及地区最低值`p_i`最多可达 10^9。 尝试所有分配的简单方法是完全不可行的，因为它需要天文数字的操作。 任何解决方案都必须以线性时间运行`n`对于每个测试用例。 

当最小分区大小时，会出现不明显的边缘情况`p_i`消耗的选民数量超过可用选民数量，或者无法满足获胜者条件的分配。 例如，如果一个地区有`p_i = 5`,`x = 2`,`y = 3`， 和`s_i = 0`，A 不可能拥有比 B 更多的选民，因为仅 A 无法达到最低多数。 同样，如果所有选区都要求 B 获胜，但`y`太小了，解是不可能的。 这些限制表明，问题不仅仅在于总数，还在于仔细分配。 

## 方法

 暴力方法将考虑每个选区选民的所有组合，测试数组的每种可能的分配`a`和`b`。 这种方法是正确的，因为它最终会枚举每个有效的配置，但显然是不可行的。 为了`n = 10^5`当选民计数达到 10^9 时，潜在分布的数量呈指数级增长，远远超过任何实际的计算时间。 

关键的观察是，对于每个地区，要求减少为线性不等式：如果`s_i = 0`，我们必须有`a_i > b_i`和`a_i + b_i >= p_i`; 如果`s_i = 1`，我们要求`b_i > a_i`和`a_i + b_i >= p_i`。 自从`a_i`和`b_i`是非负整数，我们可以分别计算每个选区的最小和最大分配界限，然后检查选民总数是否`x`和`y`可以在全球范围内满足这些限制。 这将问题简化为两个范围：必须前往 A 的选民总数和必须前往 B 的选民总数，这可以在线性时间内检查。 

观察到每个选区的要求定义了来自 A（或 B）的选民人数范围，这使我们能够制定简单的最小值总和和最大值总和检查。 如果各党派的选民总数符合这些范围，则存在解决方案； 否则，它不会。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(sum(p_i))) | O(2^(sum(p_i))) | O(n) | 太慢了 |
 | 基于范围的分配 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 各区`i`，确定必须投向 A 方的最少选民人数（`min_a`）和乙方的最低限度（`min_b`）。 如果`s_i = 0`，A必须获胜，所以A的最小分配是`(p_i + 1) // 2`。 如果`s_i = 1`，B必须获胜，所以A的最小分配是`0`。 
2. 对于同一选区，确定 A 的最大分配额。这受到该选区选民总数的限制：如果`s_i = 0`，A 可以取的最大值为`p_i - 0`（如果 B 没有投票，则为所有选民）。 如果`s_i = 1`，A 可以取的最大值为`p_i - (p_i + 1) // 2`以确保B获胜。 
3. 将所有地区的最低分配额相加，得到`min_total_a`。 将最大分配求和得到`max_total_a`。 这定义了 A 的全局可行范围。 
4. 检查是否`x`（A 的总选民数）位于`[min_total_a, max_total_a]`。 同样，验证`y`符合互补分布。 
5. 如果两个总计都在可行范围内，则打印 YES。 否则，打印NO。 

**为什么有效：** 每个区独立定义 A 和 B 的本地可行范围。 将最小值和最大值相加得出全局可行范围。 如果选民总数超出此范围，则某些选区无法同时满足最低要求和获胜者要求，因此不存在解决方案。 如果它位于内部，则始终可以通过以任何顺序分配剩余选民来贪婪地构建有效的分配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x, y = map(int, input().split())
        s = input().strip()
        p = list(map(int, input().split()))
        
        min_a_total = 0
        max_a_total = 0
        
        for i in range(n):
            if s[i] == '0':
                min_a = (p[i] + 1) // 2
                max_a = p[i]
            else:
                min_a = 0
                max_a = p[i] // 2
            min_a_total += min_a
            max_a_total += max_a
        
        if min_a_total <= x <= max_a_total and (sum(p) - x) <= y:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```该解决方案首先根据获胜者要求计算 A 方在每个选区的最小和最大投票人数。 对所有地区求和给出了 A 的可行总范围。然后我们检查是否`x`是否落在这个范围内以及剩余的投票者是否能够满足 B。操作顺序至关重要：小心地使用整数除法来处理奇数和偶数`p_i`值，确保在需要时存在多数。
