 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，并要求找到最长的连续子数组，其中最频繁的值是相连的，这意味着不存在单个主导元素。 换句话说，如果出现最频繁的元素$f$次在子数组中，必须至少有一个其他不同元素也出现$f$次。 输出只是该子数组的长度。 如果不存在这样的子数组，我们输出零。 

限制是关键。 数组长度$n$最多可达 200,000，这会立即排除 naive$O(n^2)$枚举所有子数组的解决方案，因为这将涉及最多$4 \times 10^{10}$迭代次数，远远超出了 2 秒内所能容纳的范围。 元素值的边界为$\min(n,100)$，因此最多存在 100 个不同的值，这暗示使用固定大小数组或哈希映射的基于频率的方法将是可行的。 

非明显的边缘情况包括所有值都相同的数组，例如，$[5,5,5,5]$，其中任何子数组都不能有平局。 另一个边缘情况是数组，例如$[1,2,1,2,3]$，其中具有平局的最长子阵列可能需要跳过一端的元素以均衡频率。 仅计算全局频率或仅检查立即重复的粗心方法将错过这些场景。 

## 方法

 暴力方法很简单：枚举所有子数组，计算该子数组中每个元素的频率，确定最大频率，并检查是否有多个元素达到该最大值。 对于每个子阵列，计算频率需要$O(n)$时间，所以总体复杂度是$O(n^3)$。 这适用于非常小的数组，但对于以下情况不可行$n$最多200,000。 

更快解决方案的关键观察是我们只需要检查不同值对。 如果我们选择两个值$x$和$y$，我们可以将数组转换为序列$+1$为了$x$,$-1$为了$y$， 和$0$对于其他一切。 那么问题就简化为找到最长的子数组，其中$x$等于$y$，因为在该子数组中的频率$x$和$y$领带。 这是一个经典的前缀和问题：维持一个运行总和$+1$和$-1$，并跟踪每个前缀和的最早出现时间。 当相同的前缀和再次出现时，其间的子数组的个数相等$x$和$y$。 

因为最多有 100 个不同值，所以最多有 4950 对要检查（$100 \choose 2$）。 每对都可以在$O(n)$使用前缀和方法的时间，总体复杂度大致为$5 \times 10^8$运营。 这对 Python 来说是边界，但通过仔细实现是可行的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了|
 | 成对前缀和| O(n * V^2)，V ≤ 100 | O(n) | 已接受 |

 ## 算法演练

 1. 全局计算每个元素的频率。 识别出现频率最高的元素。 如果多个元素已经在此频率上绑定，则整个数组有效，因此输出$n$并退出。 这处理了全局最大值不唯一的数组的简单快捷方式。 
2. 对于每对不同的元素$x$和$y$，初始化一个字典来存储每个前缀和出现的最早索引。 从索引 -1 处的 sum 0 开始，处理从索引 0 处开始的子数组。 
3. 遍历数组。 对于每个元素，如果是，则将前缀和加 1$x$，如果是就减1$y$，否则忽略。 
4. 在每一步中，检查此前缀和以前是否见过。 如果是，则计算从前一次出现加一到当前索引的子数组长度。 如果此长度较大，则更新最大长度。 
5. 处理完所有对后，记录的最大长度就是答案。 如果没有找到有效的子数组，则输出 0。 

这是有效的，因为前缀和确保对于两个相等的前缀和之间的任何子数组，$x$和$y$是相同的。 考虑所有对可以保证我们捕获所有潜在的子数组，其中两个元素与最大频率相关。 其他元素将被忽略，因为在最大频率下只有一对的子数组就足够了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    from collections import Counter
    
    freq = Counter(a)
    max_freq = max(freq.values())
    
    # Shortcut: if any frequency occurs more than once
    if list(freq.values()).count(max_freq) > 1:
        print(n)
        return
    
    vals = list(freq.keys())
    ans = 0
    
    for i in range(len(vals)):
        for j in range(i+1, len(vals)):
            x, y = vals[i], vals[j]
            prefix = {0: -1}
            s = 0
            for idx, val in enumerate(a):
                if val == x:
                    s += 1
                elif val == y:
                    s -= 1
                # ignore other values
                if s in prefix:
                    ans = max(ans, idx - prefix[s])
                else:
                    prefix[s] = idx
    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先计算频率字典并检查数组是否已包含具有相同最大频率的多个元素。 如果是这样，则整个数组都合格。 对于成对前缀和方法，我们仅对两个选定的元素进行递增或递减，忽略其他元素以避免干扰它们的计数。 存储每个前缀和的第一次出现对于快速计算最长子数组至关重要。 初始化前缀字典`{0: -1}`允许正确处理从索引 0 开始的子数组。
