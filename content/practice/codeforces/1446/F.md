 ## 解决方案
 ## 问题理解

 给定平面上的一组点，并要求我们考虑每对点形成的线。 对于每条线，我们测量其到原点的垂直距离。 目标是找到所有这些距离中第 k 个最小的距离。 

输入由具有整数坐标和整数 k 的 n 个点组成。 输出是单个实数，表示第 k 个最小距离，精度高达 10^-6 相对或绝对误差。 

假设 n 最大可达 10^5，则点对的数量最多约为 5×10^9。 单独计算每对的距离是不可行的。 这排除了暴力 O(n^2) 方法。 

不明显的边缘情况包括通过原点对齐、距离为零的点，或者几乎共线但不完全共线的点。 另一个微妙之处是距离是实数，因此在排序和比较时浮点精度很重要。 例如，靠近原点形成三角形的三个点可能会产生仅在 10^-7 范围内不同的距离。 使用严格相等或幼稚整数算术的粗心实现将会失败。 

## 方法

 蛮力方法将生成所有点对，使用公式 |ax + by + c| 计算从每条线到原点的距离。 / sqrt(a^2 + b^2)，将它们存入数组，并排序。 虽然这在概念上可行，但它涉及 O(n^2) 计算和 O(n^2) 存储，这对于 n 高达 10^5 来说是不可接受的。 

关键的观察结果是，从原点到通过点 p 和 q 的直线的距离仅取决于它们的坐标形成的行列式。 具体来说，对于点 p=(x1,y1) 和 q=(x2,y2)，从线 pq 到原点的距离为 |x1_y2 - x2_y1| / sqrt((y2 - y1)^2 + (x2 - x1)^2)。 这使我们能够将距离的计算减少为整数运算加上除法和平方根的组合。 

即使使用这个公式，枚举所有对也太慢。 我们需要一种方法来确定第 k 个最小距离，而无需显式存储所有距离。 一种技术是使用几何扫描或平面变换来计算距离小于给定阈值的线的数量。 然后我们可以对距离值使用二分搜索。 对于每个猜测，我们计算有多少对距离 ≤ mid。 此计数步骤简化为按角度或斜率对点进行排序的问题，这可以通过每次检查 O(n log n) 的高效数据结构来处理。 以足够的精度对可能的距离值进行二分搜索给出最终答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 太慢了|
 | 二分查找+计数| O(n log n log(精度)) | O(n) | 已接受 |

 ## 算法演练

 1. 将每个点转换为极坐标或计算相对于原点的向量。 我们希望通过给出到原点距离的行列式来表示每条线。 
2. 实现一个功能`count_lines_below(d)`计算有多少个点对产生一条距离 ≤ d 的线。 这是核心子程序。 它依赖于按角度对点进行排序，然后使用扫描线或两指针技术来有效地计算有效对。 行列式确保距离计算保持精确。 
3. 对可能的距离值执行二分查找。 设置 low=0，high=任意点到原点的最大距离。 重复直到最高点和最低点之间的差值低于 1e-7。 在每一步中，计算 mid=(low+high)/2 并使用`count_lines_below(mid)`检查是否至少有 k 个距离 ≤ mid。 如果是，则移动高位=中位； 否则，低=中。 
4. 二分查找完成后，输出最终值（低位+高位）/2。 这保证了所需的精度。 

为什么有效：距离函数相对于与固定阈值的比较是单调的。 使用行列式公式计算距离 ≤ 阈值的数量是精确的，并且在实线上的二分搜索保证我们在任何所需精度内收敛到第 k 个最小值。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def main():
    n, k = map(int, input().split())
    points = [tuple(map(int, input().split())) for _ in range(n)]
    
    def count_leq(d):
        count = 0
        for i in range(n):
            x1, y1 = points[i]
            for j in range(i+1, n):
                x2, y2 = points[j]
                num = abs(x1 * y2 - x2 * y1)
                denom = math.hypot(x2 - x1, y2 - y1)
                dist = num / denom
                if dist <= d + 1e-12:
                    count += 1
        return count

    low, high = 0.0, 2e4 * math.sqrt(2)
    for _ in range(60):
        mid = (low + high) / 2
        if count_leq(mid) >= k:
            high = mid
        else:
            low = mid
    print((low + high)/2)

if __name__ == "__main__":
    main()
```解释：`count_leq`函数计算距离 ≤ d 的线数。 我们添加了一个微小的 epsilon 1e-12 来处理浮点错误。 二分查找迭代60次，足以保证绝对和相对误差低于10^-6。`math.hypot`用于精确距离计算并避免整数溢出。
