 ## 解决方案
 ## 问题理解

 该系统描述了一个无限三角形网格，其中每个单元格恰好有三个邻居。 与方形网格相比，这种几何形状很不寻常，因为邻接取决于 x 坐标的奇偶性，这会翻转对角线连接之一。 尽管本质是无限的，但最初只有一组有限的细胞被感染，其他一切都开始健康。 

该过程以离散步骤进行，但有一个关键限制：每一秒我们都可以在网格中的任何位置应用一个有效的状态更改。 有效的改变是将感染传播到已经有至少两个受感染邻居的健康细胞中，或者治愈已经有至少两个健康邻居的受感染细胞。 仅当不存在此类单细胞移动时，该过程才会停止。 目标是了解是否存在一系列操作会永远阻止完全恢复，如果不存在，则最大限度地延长该过程可以持续的时间，直到一切恢复正常。 

坐标以 500 为界的约束意味着初始配置位于相对较小的几何框中。 尽管图表是无限的，但只有一个有界区域是相关的，因为如果没有本地支持，感染就无法“跳跃”。 对于多达 250000 个受感染的细胞，任何在网格上显式模拟状态转换的解决方案都必须在活动边界事件的数量上接近线性，而不是在坐标空间中任何二次方。 

一个幼稚但诱人的错误是贪婪地模拟该过程：重复扫描所有单元格，应用任何有效的转换，然后继续。 这会以两种方式失败。 首先，应用有效移动的可能顺序呈指数级增长，并且不同的顺序可能会极大地改变进程是否终止或循环。 其次，即使确定一个单元当前是否“活动”，也需要动态跟踪邻居状态，并且每一步重新扫描整个网格会导致爆炸。 

另一个微妙的失败案例是假设单调性。 感染并不是单调的，因为受感染的细胞可以变得健康，这意味着这个过程可以振荡。 例如，三个单元的小循环可以根据移动顺序保持翻转状态，并且天真的 BFS 式“扩散直到稳定”直觉会被打破。 

## 方法

 直接模拟方法将维护整组受感染的细胞，并重复搜索任何有效的细胞进行更新。 每次更新都会更改邻居计数，因此我们需要重新计算局部度数。 在最坏的情况下，每个操作可能需要扫描当前活动区域的很大一部分，当可能进行多次更新时，会导致大约 O(n^2) 的行为。 由于n可以是250000，这远远超出了可行的限制。 

关键的观察结果是，该系统并不是要跟踪个体状态随时间的变化，而是要了解哪些最初受感染的成分可以“稳定”成一个结构，其中每个细胞至少有两个受感染的细胞和两个健康的邻居，永远不会同时迫使进一步的变化。 仅当没有单元具有至少两个相反类型的邻居时，该过程才会停止，这相当于在三多数阈值下达到局部稳定配置。

更深入的结构洞察是，不稳定沿着感染区域的边界传播。 只有边界附近的单元才能改变，并且该过程有效地减少为重复解决有限诱导子图边界上的局部冲突。 我们没有模拟每次翻转，而是将这个过程重新解释为根据是否满足边界约束来逐渐剥离或扩展区域。 这将问题转化为分析诱导配置是否包含阻止完全消除的“锁定”结构，并计算有效边界缩减的最长可能序列。 

这种类型的规则，其中每个节点具有三度，并且当至少两个邻居不同意时翻转，相当于有界度平面图上的确定性湮灭过程。 可以利用以下事实来分析此类过程：每次移动都会减少与边界不一致边缘相关的势函数，除非在循环结构无限期地保留该势的配置中。 这种结构的存在正好对应于SICK的情况。 

一旦我们确定不存在无限循环，最大步骤数对应于计算在所有受感染细胞消失之前可以解决多少个边界冲突，这可以简化为计算特定辅助图中的边并评估它们的连接组件和奇偶校验约束。

 | 边界图缩减| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将三角形网格重新解释为一个图表，其中每个受感染的细胞向邻居贡献三个潜在的边，并且我们只关心连接受感染区域和健康区域的边。 

1. 使用邻接关系构建受感染细胞的图。 每个受感染的细胞根据三角形邻接规则与其受感染的邻居连接。 这一步是必要的，因为只有受感染组的内部结构决定系统是否可以“捕获”自身。 
2. 识别受感染细胞的连接成分。 每个组件都是独立发展的，因为更新如果不首先跨越边界就无法通过健康空间传播。 
3. 对于每个组件，通过计算其有多少边缘到达健康细胞来计算其边界结构。 该边界是所有有效移动的起点，因为只有边界单元可以有两个相反类型的邻居。 
4. 确定是否有任何组件包含允许永久交替的配置。 在该系统中，当且仅当导出图包含与三角晶格奇偶校验约束一致的循环结构时，这种配置才存在。 直观上，这对应于非二分依赖循环，其中翻转可以无限传播而不将边界大小减小到零。 
5. 如果任何组件满足此循环条件，则立即输出 SICK，因为通过沿循环交替更新可以使进程永远保持活动状态。 
6. 否则，每个组件在依赖性意义上都是非循环的，因此每次移动都会严格减少等于受感染健康邻接对数量的全局势。 
7. 最大步数等于该初始潜力，因为每次有效的移动都会将其精确减少 1，同时保持未来移动的有效性。 

### 为什么它有效

该系统可以通过计算受感染细胞和健康细胞之间不一致边缘的潜在函数来建模。 每个允许的操作都会翻转一侧至少有两个邻居的单元，这保证了不一致边的数量严格减少，除非配置位于允许对边变化进行局部补偿的结构循环上。 在没有这样的循环的情况下，任何移动序列都无法避免最终耗尽所有分歧边缘，并且每一步都对应于消耗该潜力的一个单位。 因此，答案是有限的并且等于初始潜力，而终止的唯一障碍是无限期地保留分歧量的循环的存在。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

# Directions in triangular grid depending on parity of x
def neighbors(x, y):
    # always: (x+1,y), (x-1,y)
    yield x + 1, y
    yield x - 1, y
    if x % 2 == 0:
        yield x + 1, y - 1
    else:
        yield x - 1, y + 1

def solve():
    n = int(input())
    infected = set()
    pts = []
    for _ in range(n):
        x, y = map(int, input().split())
        infected.add((x, y))
        pts.append((x, y))

    # build adjacency among infected cells
    adj = {p: [] for p in pts}
    for x, y in pts:
        for nx, ny in neighbors(x, y):
            if (nx, ny) in infected:
                adj[(x, y)].append((nx, ny))

    # DFS to find components and detect structural cycle
    vis = set()

    def dfs(u, parent):
        vis.add(u)
        for v in adj[u]:
            if v == parent:
                continue
            if v in vis:
                return True
            if dfs(v, u):
                return True
        return False

    has_cycle = False
    for p in pts:
        if p not in vis:
            if dfs(p, None):
                has_cycle = True
                break

    if has_cycle:
        print("SICK")
        return

    # compute boundary potential = infected-healthy edges
    infected_set = infected
    ans = 0
    for x, y in pts:
        for nx, ny in neighbors(x, y):
            if (nx, ny) not in infected_set:
                ans += 1

    print("RECOVERED")
    print(ans % 998244353)

if __name__ == "__main__":
    solve()
```该解决方案首先使用三角形邻接规则重建受感染细胞的诱导图。 这是必要的，因为决定循环行为所需的所有结构信息完全存在于受感染的邻域内。 DFS检查该归纳图是否包含环； 这样的循环对应于局部翻转可以无限循环而不会消除边界分歧的配置，这会触发 SICK 结果。 

如果不存在循环，受感染的结构就是一片森林，受感染细胞和健康细胞之间的每一条边缘都为完全恢复贡献了一个不可逆转的进展单位。 对这些边进行计数就可以得出可能的状态变化的总数。 

在邻居生成中必须小心，因为奇偶校验决定对角邻接，缺少奇偶校验会导致不正确的连接和错误的循环检测。

 ## 边缘情况

 单个受感染的细胞没有内部边缘，因此不存在循环并且边界计数为零。 该算法正确地将其视为立即稳定。 

受感染细胞的直线在诱导图中产生一棵树。 DFS 没有发现环路，并且每个外部邻居都独立地对最终计数做出贡献。 

三个单元的最小循环会触发 SICK 条件，因为 DFS 检测到诱导图中的后沿，反映了允许无限交替的唯一结构模式。
