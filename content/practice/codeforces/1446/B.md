 ## 解决方案
 ## 问题理解

 我们有两篇用字符串表示的文章，我们希望找到它们之间最可疑的重叠部分。 重叠是使用相似度分数来测量的，该相似度分数定义为两个子串的最长公共子序列的长度的四倍减去它们的长度之和。 换句话说，如果两个子串以相同的顺序共享许多字母，则当共享部分相对于它们的总长度较长时，得分将为正且较大。 

输入提供了两篇论文的长度，后面是论文本身。 输出应该是一个整数，表示第一篇文章的任何子字符串与第二篇文章的任何子字符串之间可实现的最大相似度得分。 

这些限制允许每篇文章的长度最多为 5000 个字符。 检查所有子串对的简单方法将涉及 O(n² * m²) 运算，只是为了枚举子串，在最坏的情况下约为 6.25 × 10^3，并且在 1 秒的时间限制内完全不可行。 这表明我们必须利用问题中的结构来避免迭代所有子串对。 

非明显的边缘情况包括最佳子字符串极短的情况，例如单个匹配字符，或者一篇文章与另一篇文章完全不同。 例如，如果`A = "aaa"`和`B = "bbb"`，所有 LCS 值均为零，因此最大分数为负数。 粗心的方法可能会假设较长的子串总是会产生较高的分数，但这并不能保证，因为分数会惩罚子串的总长度。 

## 方法

 暴力解决方案将迭代所有子串`A`和`B`，计算他们的 LCS，然后评估分数。 这种方法原则上是正确的，因为它直接实现问题陈述，但需要 O(n² * m² * min(n,m)) 次操作。 对于n，m = 5000，这远远不可行，所以我们需要一个更聪明的方法。 

关键的观察是，对于这个问题，我们不需要完整字符串的 LCS，而是需要在任意位置开始和结束的子字符串的 LCS。 如果我们考虑对字符串位置的动态规划，我们可以计算以任何一对位置结束的最大分数`(i,j)`在 O(n*m) 时间内。 具体来说，让`dp[i][j]`表示以结尾的子串的最佳分数`A[i-1]`和`B[j-1]`。 如果`A[i-1]`比赛`B[j-1]`，我们可以将之前的子串分数扩展 2（因为 4×1 − 1 − 1 = 2），否则分数重置为零。 这将问题转换为标准最长公共子串 DP 的变体，但具有修改的评分规则。 

过渡是`dp[i][j] = max(0, dp[i-1][j-1] + 2)`如果字符匹配，否则为零。 迭代所有对`(i,j)`跟踪看到的最高分数。 该DP的时间和空间复杂度为O(n*m)，在给定约束的情况下是可行的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n² * m² * 分钟(n,m)) | O(1) | O(1) | 太慢了|
 | 子串上的 DP | O(n * m) | O(n * m) | 已接受 |

 ## 算法演练

 1.读取输入：长度`n`和`m`和字符串`A`和`B`。 
2. 初始化一个2D数组`dp`尺寸的`(n+1) x (m+1)`带零。 这将存储以每个位置结尾的子字符串的最大相似度得分。 
3. 初始化变量`answer`为零，这将跟踪总体最高分数。 
4. 迭代每个字符位置`i`在`A`和`j`在`B`。 
5. 如果`A[i-1]`比赛`B[j-1]`， 放`dp[i][j] = max(0, dp[i-1][j-1] + 2)`。 否则，设置`dp[i][j] = 0`。 
6. 更新`answer`是其当前值的最大值并且`dp[i][j]`。 
7.处理完所有位置后，打印`answer`。 

该算法之所以有效，是因为`dp[i][j]`始终表示以结尾的子字符串的最大相似度得分`i-1`和`j-1`。 通过在字符匹配时延续之前的分数，我们可以正确地累积共享字符的贡献，同时自动惩罚总长度。 零重置可防止扩展不匹配的序列，与子字符串定义对齐。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
A = input().strip()
B = input().strip()

dp = [[0] * (m + 1) for _ in range(n + 1)]
answer = 0

for i in range(1, n + 1):
    for j in range(1, m + 1):
        if A[i - 1] == B[j - 1]:
            dp[i][j] = max(0, dp[i - 1][j - 1] + 2)
        else:
            dp[i][j] = 0
        answer = max(answer, dp[i][j])

print(answer)
```这`dp`为了简单起见，数组是 1 索引的。 我们添加 2 到`dp[i-1][j-1]`当字符匹配时，因为新的匹配字符起作用`4*1 - 1 - 1 = 2`到分数。 零重置确保只有连续的匹配序列起作用，尊重子串约束。
