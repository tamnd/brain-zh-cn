 ## 解决方案
 ## 问题理解

 每个测试用例都描述一个包含 4 列的小型 osu!mania 节奏图。 每行只包含一个注释，标记为`#`，其余单元格包含`.`。 

行是从上到下给出的，但游戏从下到上处理音符，因为靠近底部的音符首先被击中。 对于处理顺序中的每个注释，我们必须输出其所在的列号`#`出现。 

一行如：```
..#.
```在第 3 栏中包含其注释。 

关键细节是输入顺序和所需的输出顺序是相反的。 输入中的第一行是最上面的行，但是我们打印的第一个答案必须对应于最下面的行。 

限制非常小。 所有测试用例最多有 500 行，每行恰好有 4 个字符。 即使扫描每行每个字符的算法总共也只执行大约 2000 个字符检查。 运行时不是这里的挑战。 这项任务纯粹是认真执行。 

一个容易犯的错误就是忘记反转行。 

考虑：```
1
3
#...
.#..
..#.
```从上到下的行包含列`1, 2, 3`。 

游戏从下到上进行，所以正确的输出是：```
3 2 1
```按输入顺序打印行的粗心解决方案将输出：```
1 2 3
```这是错误的。 

另一个常见错误是使用基于 0 的索引。 

例如：```
1
1
...#
```注释位于第四列。 

正确的输出是：```
4
```直接输出字符串位置的解决方案将打印`3`。 

第三种微妙的情况是多行在同一列中有注释。```
1
2
.#..
.#..
```正确的输出是：```
2 2
```每行必须独立处理。 没有限制列必须不同。 

## 方法

 最直接的方法是检查每一行，找到`#`，存储该列号，最后以相反的行顺序输出存储的答案。 

这种暴力方法已经足够快了，因为每行只包含四个字符。 找到音符位置最多需要检查四个单元格。 总共最多 500 行，最坏情况下的工作也只有大约 2000 个字符检查。 

由于约束很小，因此不需要复杂的优化。 真正的观察只是了解笔记的处理顺序。 

输入给出从上到下的行，但所需的答案是从下到上。 一旦我们认识到这一点，问题就变成了对每一行的直接扫描。 对于每一行，我们确定包含的列`#`，存储它，然后以相反的顺序打印存储的列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 已接受 |
 | 最佳 | O(n) | O(n) | 已接受 |

 由于每行的长度固定为 4，因此扫描一行实际上是恒定时间。 对于这个问题，两种方法都是相同的。 

## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，请阅读`n`，行数。 
3. 创建一个空列表`cols`这将存储每行中注释的列号。 
4. 读取每一行。 
5. 找到位置`#`并将其转换为从 1 开始的列号。 
6. 将该列号附加到`cols`。 
7. 处理完所有行后，通过迭代颠倒顺序`cols`从最后一个元素到第一个元素。 
8. 打印相反的序列，并用空格分隔。 

这种逆转是必要的，因为输入是从上到下给出的，而音符是从下到上处理的。 

### 为什么它有效

 对于每一行，只有一个`#`，因此该注释的列是唯一确定的。 该算法按输入顺序记录每行的该列。 

如果行从上到下编号为`1...n`，则处理顺序为`n...1`。 颠倒记录的列表会产生完全相同的顺序。 每个输出位置都对应于正确处理的音符，因此算法始终返回所需的序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    cols = []

    for _ in range(n):
        row = input().strip()
        cols.append(row.index('#') + 1)

    print(*reversed(cols))
```解决方案直接遵循算法。 

名单`cols`存储每行的列号。 蟒蛇的`index('#')`查找注释的位置，加一会将结果从基于 0 的索引转换为所需的基于 1 的列编号。 

After all rows are read,`reversed(cols)`产生从下到上的处理顺序。 使用`print(*...)`自动在数字之间放置空格。 

最常见的实施错误是忘记`+ 1`。 还有一个就是印刷`cols`直接而不是反转。

 | 测量| 复杂性 | 说明|

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        cols = []

        for _ in range(n):
            row = input().strip()
            cols.append(row.index('#') + 1)

        out.append(" ".join(map(str, reversed(cols))))

    sys.stdout.write("\n".join(out))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    result = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return result

 ## 边缘情况

 ### 从上到下顺序与从下到上顺序

 输入：```
1
3
#...
.#..
..#.
```算法记录：```
[1, 2, 3]
```然后它反转列表：```
[3, 2, 1]
```和输出：```
3 2 1
```这与所需的处理顺序相匹配。 

### 最后一列的注释

 输入：```
1
1
...#
```的位置`#`是索引`3`。 加一给出列`4`。 

输出：```
4
```这证实了该算法正确地从 Python 的基于 0 的索引转换为问题的基于 1 的列编号。 

### 多行使用同一列

 输入：```
1
2
.#..
.#..
```该算法存储：```
[2, 2]
```反转不会改变顺序：```
[2, 2]
```输出：```
2 2
```该解决方案从不假设列是唯一的，因此可以自然地处理重复的列。
