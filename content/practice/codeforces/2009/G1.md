 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，需要回答多个查询。 每个查询都要求创建长度精确的连续递增子数组所需的最小更改次数`k`在数组的指定切片内。 更改包括选择任何元素并将其替换为我们选择的任何整数。 

简单来说，对于每个长度的子数组`k`，我们想知道它离严格连续递增序列有多远。 例如，如果子数组是`[2, 3, 2, 1, 2]`和`k = 5`，我们需要统计不符合连续数字模式的位置数量并替换它们。 

限制表明天真的方法会太慢。 数组长度`n`可以达到`2 * 10^5`，最多可达`2 * 10^5`查询。 独立迭代每个查询的子数组的解决方案将执行最多`2 * 10^5 * k`最坏情况下的操作，可能会超过`10^9`如果`k`很大。 因此，一个`O(n)`每个测试用例的预处理步骤`O(1)`或者`O(log n)`查询处理是必要的。 

当子数组已经形成连续递增序列时，就会出现边缘情况。 例如，`[1, 2, 3, 4]`和`k = 4`要求零改变。 如果简单地检查差异而不在整个子数组中全局验证模式，那么简单的方法可能会误算。 

另一个微妙的边缘情况是由于重复的数字或递减的序列而出现的。 例如，`[3, 3, 3, 3]`和`k = 4`需要更改除一个元素之外的所有元素以实现连续增加的模式。 任何假设元素已排序的解决方案都将在这里失败。 

## 方法

 蛮力方法独立检查每个查询。 对于每个长度的子数组`k`，我们可以尝试连续序列的所有可能的起始值。 对于每个元素，我们将其与预期值进行比较并计算不匹配的情况。 时间复杂度为`O(q * k)`每个测试用例。 虽然这可以正确计算答案，但对于大型数组或许多查询来说，它变得太慢。 

最佳解决方案的关键洞察是注意到对于长度的子数组`k`，使其严格连续所需的更改数量可以计算为与等于 1 的最长连续差异序列不对齐的元素数量。这转化为计算最长游程，其中`a[i+1] - a[i] = 1`。 一旦我们知道在每个位置结束的最大连续递增线段的长度，长度线段的最小变化次数`k`简直就是`k - length_of_run`。 

由于查询总是要求长度的子数组`k`，我们可以预处理连续游程长度的数组。 然后，每个查询简化为一个简单的减法：所需更改的数量等于`k`减去子数组开头的游程长度（上限为`k`）。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(q * k) | O(1) | O(1) | 太慢了|
 | 预处理运行 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读`n`,`k`,`q`，和数组`a`。 
2.初始化一个数组`run`长度`n`存储在每个位置结束的连续递增序列的长度。 
3. 从左到右遍历数组。 对于第一个元素，设置`run[0] = 1`。 对于每个后续元素`i > 0`， 如果`a[i] - a[i-1] == 1`， 放`run[i] = run[i-1] + 1`; 否则，设置`run[i] = 1`。 此步骤捕获在每个索引处结束的最大连续递增游程。 
4. 对于每个查询`(l, r)`，计算最小变化数为`k - min(run[r-1], k)`。 我们取最小值`k`因为run可能比子数组长，而我们只关心length的子数组`k`。 
5. 输出每个查询的结果。 

不变的是`run[i]`始终反映结束于的最长连续递增段的长度`i`。 由于查询子数组的长度正好`k`，减去这次运行`k`给出所需更改的确切数量。 这保证了正确性，因为任何最佳序列总是可以与这个最大运行对齐。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k, q = map(int, input().split())
    a = list(map(int, input().split()))
    
    run = [1] * n
    for i in range(1, n):
        if a[i] - a[i-1] == 1:
            run[i] = run[i-1] + 1
    
    for _ in range(q):
        l, r = map(int, input().split())
        l -= 1
        r -= 1
        length_of_run = min(run[r], k)
        print(k - length_of_run)
```我们计算`run`在一次遍历数组中。 对于每个查询，我们调整从 1 开始的索引并提取以子数组最后一个元素结束的运行长度。 限制运行`k`确保运行超出子数组长度时的正确性。
