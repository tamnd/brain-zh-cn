 ## 解决方案
 ## 问题理解

 我们得到一个数组`a`长度`n`，并且我们被要求处理更大数组上的查询`b`。 这个数组`b`是通过采取所有`n`的循环移位`a`并将它们按顺序连接起来。 每次循环移位都会将第一个元素移动到末尾，因此`i`第-次轮班开始于`a[i]`并环绕到数组的开头。 然后，对于索引定义的每个查询`l`和`r`，我们必须计算子数组的总和`b[l..r]`。 

第一个挑战是规模。 为了`n`最多 2×10^5，数组`b`会有`n^2`元素，最多 4×10^10。 显然，我们无法构建`b`显式地或对其执行朴素的前缀和。 查询数量也高达 2×10^5，因此任何解决方案都必须在常数或对数时间内回答每个查询，否则我们将超出 2 秒的限制。 

一种简单的方法，通过迭代连接所有班次或模拟查询`b`是不可行的。 边缘情况包括非常小的`n`,`n = 1`，以及跨越多个完整副本的查询`a`里面`b`。 另一个微妙的点是查询可以要求内的任何段`b`，可能会覆盖元素的多次重复，因此需要对索引进行模块化算术。 

例如，如果`a = [1,2,3]`， 然后`b`是`[1,2,3,2,3,1,3,1,2]`。 来自的查询`l=3`到`r=5`跨度元素`[3,2,3]`。 一个简单的迭代解决方案会计算`3+2+3=8`，但是我们需要一个方法来对大于的数组执行此操作`b`可以装入内存。 

## 方法

 蛮力方法实际上是构建`b`并计算前缀和。 这适用于小型`n`， 但`b`有`n^2`元素，导致 O(n^2) 内存和 O(q * n) 查询时间。 对于最坏的情况，`n = 2×10^5`，这是完全不可行的，因为它需要数万亿次操作。 

关键的洞察力来自于对结构的认识。 每个元素`a[i]`准确地出现`n`次在`b`，每个班次一次，但位置不同。 如果我们关注串联中每个元素的模式，我们可以通过将其分为三个部分来确定任何范围的总和：第一个部分覆盖的重复的前缀，`a`，以及最后一个部分覆盖的重复的后缀。 

如果我们计算一个前缀和数组`pref`为了`a`本身，以及总和`a`，我们可以映射任意位置`b`到其对应的元素`a`使用模运算。 然后，每个查询可以分解为末端的部分副本和中间的完整副本的贡献。 这使用预先计算的总和将每个查询的查询处理减少到 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 + q * n) | O(n^2 + q * n) | O(n^2) | O(n^2) | 太慢了|
 | 最佳 | O(n + q) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读`n`和`q`，然后是数组`a`。 
2. 计算前缀和数组`pref`为了`a`， 在哪里`pref[i]`是第一个的总和`i`的元素`a`。 这使我们能够快速计算任意连续子数组的总和`a`。 
3. 计算总和`total`的`a`作为`pref[n]`。 
4. 对于每个查询`(l, r)`，转换从 1 开始的位置`l`和`r`在`b`到基于 0 以便更容易进行模运算。 确定哪个重复`a`这些职位分为：

 - 将起始重复计算为`l // n`并在其中偏移`a`作为`l % n`。 
- 将结束重复计算为`r // n`并在其中偏移`a`作为`r % n`。 
5. 如果查询完全在一次重复内`a`，只需取前缀和差：`pref[r_offset + 1] - pref[l_offset]`。 
6. 否则，将第一次重复中的部分前缀、之间的完整重复相加（使用`total`乘以完整重复的次数），以及最后一次重复中的部分后缀。 将这些组合起来就可以得到查询结果。 

不变的是数组`b`可以被认为是一个网格`n`行`a`，并且跨任何段的求和可以分解为行对齐的总和和偏移量。 模运算确保我们始终访问正确的元素`a`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, q = map(int, input().split())
    a = list(map(int, input().split()))
    
    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + a[i]
    total = pref[n]
    
    for _ in range(q):
        l, r = map(int, input().split())
        l -= 1  # 0-based indexing
        r -= 1
        
        l_block, l_offset = divmod(l, n)
        r_block, r_offset = divmod(r, n)
        
        if l_block == r_block:
            ans = pref[r_offset + 1] - pref[l_offset]
        else:
            ans = (pref[n] - pref[l_offset])  # prefix in first block
            ans += (r_block - l_block - 1) * total  # full blocks in between
            ans += pref[r_offset + 1]  # suffix in last block
        print(ans)
```前缀和数组`pref`确保对任意子数组进行 O(1) 求和查询`a`。 在每个查询的开始和结束处处理部分块可以保证正确性。 我们使用`divmod`快速获取块索引和块内的偏移量。 减去 1`l`和`r`转换为基于 0 的索引。
