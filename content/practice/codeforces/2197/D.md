 ## 解决方案
 ## 问题理解

 给定一个整数数组，我们需要计算索引对`(i, j)`在哪里`i < j`相应值的乘积等于索引之间的距离：`a[i] * a[j] = j - i`。 每个测试用例的输出是一个整数，表示此类“美丽”对的总数。 

约束表明数组可以很大，在单个测试用例中最多可以有 2 × 10^5 元素，并且所有元素的总和`n`跨测试用例的范围也以 2 × 10^5 为界。 有了 2 秒的时间限制，这意味着我们可以安全地承受总输入大小中大致线性或线性的东西，但任何二次的东西`n`每个测试用例都会太慢。 这些值本身最大可达 10^9，这排除了任何通过值进行索引的简单频率数组方法。 

可能棘手的边缘情况包括大小为 2 的非常小的数组、所有元素都相同的数组或元素非常大的数组。 例如，如果`a = [10^9, 10^9]`，没有漂亮的对，因为`10^9 * 10^9 = 10^18`远大于`j - i = 1`。 相反，如果`a = [1, 1, 1]`，所有可能的对`(i, j)`和`i < j`可能满足小距离的乘积条件，并且简单的实现可能会错过多个对或对它们进行重复计数。 

## 方法

 最直接的方法是暴力破解：对于每个索引`i`, 迭代所有`j > i`并检查是否`a[i] * a[j] == j - i`。 这是正确的，但每个测试用例的时间复杂度为 O(n^2)。 和`n`高达 2 × 10^5，在最坏的情况下这将导致大约 4 × 10^10 次操作，远远超过 2 秒的限制。 

优化的关键观察是差异`j - i`严格小于`n`，以及产品`a[i] * a[j]`必须恰好等于该差值。 对于较大的值`a[i]`或者`a[j]`，对应的`j - i`太小而无法满足等式。 具体来说，只有两个数字相对于`n`可以做出贡献。 这意味着我们不需要考虑所有对； 相反，我们可以迭代一个索引并计算所有可能的索引`j`通过重新排列公式来满足条件：`j = i + a[i] * a[j]`或等效地检查`a[i]`。 

我们可以通过迭代来有效地实现这一点`i`从 1 到 n，然后对于每个可能的倍数`k * a[i]`（在哪里`k`是一个整数，使得`i + k * a[i] <= n`）检查是否`a[i] * a[j] = j - i`成立。 这大大减少了候选者的数量，因为每个候选者的倍数数量`i`至多是`n / a[i]`，对于大来说小`a[i]`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了 |
 | 倍数支票 | O(n * sqrt(n)) | O(n * sqrt(n)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`和数组`a`长度`n`。 
3. 初始化计数器`ans`为零。 
4. 迭代每个索引`i`从 1 到`n`。 对于每个`i`，计算候选索引`j`作为`i + k * a[i]`在哪里`k = 1, 2, 3...`直到`j > n`。 
5. 对于每个计算的`j`，检查是否`a[i] * a[j] == j - i`。 如果是，则增加`ans`。 
6.处理完所有索引后，打印`ans`。 

这种方法之所以有效，是因为我们只考虑`j`可以满足基于当前的等式的值`a[i]`。 既然有差别`j - i`线性增长，同时`a[i] * a[j]`随着数量的增加，增长速度会更快，大多数对都会被自动跳过，从而将操作总数保持在可接受的范围内。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    ans = 0
    # Use 1-based indexing for easier mapping with formula
    a = [0] + a
    for i in range(1, n + 1):
        # Only consider multiples of a[i] that stay in bounds
        j = i + a[i]
        while j <= n:
            if a[i] * a[j] == j - i:
                ans += 1
            j += a[i]
    print(ans)
```我们在开头添加一个虚拟零`a`使其成为 1 索引，从而简化了公式`a[i] * a[j] == j - i`。 对于每个`i`，我们考虑的倍数`a[i]`直到我们超过`n`。 这保证了我们检查每一位候选人`j`无需迭代所有对。 递增`j`经过`a[i]`确保我们只检查可以满足等式的可行索引。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        ans = 0
        a = [0] + a
        for i in range(1, n + 1):
            j = i + a[i]
            while j <= n:
                if a[i] * a[j] == j - i:
                    ans += 1
                j += a[i]
        output.append(str(ans))
    return "\n".join(output)
