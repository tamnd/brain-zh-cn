 ## 解决方案
 # 问题理解

 该问题模拟了视频通话中的一排人。 所有人都转过头后，每个人都由一个角色代表：`L`如果他们面向左并且`R`如果他们面朝右边。 人群是面向同一方向的最大连续人群。 任务是计算最后一行中有多少个这样的组。 

例如，行`R L L R`包含三个团块：第一个`R`, 中间`LL`，以及最后一个`R`。 

输入包含人数以及按顺序指示的人数。 输出是该序列中连续段的数量，其中段内的每个字符都是相同的。 

该限制允许最多 100,000 人。 这意味着解决方案应该在线性时间内工作。 重复比较多对位置或尝试每个可能的分段的算法可以轻松达到大约 10^10 次操作，这远远超出了典型比赛时间限制中可能实现的操作。 对行进行一次扫描就足够了，因为每个人只需要影响答案一次。 

主要的边缘情况来自簇之间的过渡。 仅包含一个人的一排仍必须形成一丛。 对于输入：```
1
L
```正确的输出是：```
1
```仅计算相邻人群之间变化的解决方案将返回零，因为没有转换，但必须计算第一个簇。 

另一个常见的错误是忘记相等的相邻方向属于同一丛。 为了：```
4
L
L
L
L
```正确的输出是：```
1
```整排都是一团。 计算每个出现的次数`L`或者`R`分开会错误地产生四个。 

最后的边界情况是每个相邻对都不同：```
4
L
R
L
R
```正确的输出是：```
4
```每个人都开始一个新的丛，所以答案是人数。 

## 方法

 蛮力方法是检查每个可能的连续组并确定它是否是一个簇。 由于存在 O(N^2) 个可能的段，并且检查一个段可能需要 O(N)，因此总工作量可以达到 O(N^3)。 即使是稍微改进的仅检查每个段的相邻位置的蛮力仍然考虑 O(N^2) 范围，当 N 达到 100,000 时，它会变得太慢。 

关键的观察结果是团块在方向改变的位置被精确地分离。 我们不需要知道整个段的内容。 我们只需要知道当前的人是继续之前的簇还是开始新的簇。 

该行始终包含至少一个簇。 我们从第一个人的一丛开始，然后当一个人面对与前面的人不同的方向时增加答案。 这将问题简化为一次从左到右的扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N^2) 或更糟 | O(1) | O(1) | 太慢了 |
 | 最佳 | O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 按照原来的顺序阅读所有人的指示。 
2. 将答案初始化为一个，因为第一个人总是属于一个群体。 
3. 从第二个人开始扫描该行。 每当当前方向与先前方向不同时，就增加丛的数量。 方向改变是唯一可以创建新丛的事件。 
4. 输出最终计数。 

为什么它有效：

 在扫描过程中，当前答案准确地代表了迄今为止处理的人员中最大组的数量。 第一个人创建了第一组。 后来的每个人要么在方向匹配时加入前一个组，要么在方向改变时开始一个新组。 由于团块之间的每个可能的边界都被检查一次，因此最终的计数是正确的。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

def solve():
    n = int(input())
    prev = input().strip()
    
    ans = 1

    for _ in range(n - 1):
        cur = input().strip()
        if cur != prev:
            ans += 1
        prev = cur

    print(ans)

if __name__ == "__main__":
    solve()
```该代码仅保留先前的方向，而不是存储整行。 这已经足够了，因为只有通过比较两个相邻的人才能创建新的簇。 

变量`ans`从 1 开始，因为保证输入至少包含一个人。 循环从第二人开始，每次方向改变都会增加答案。 

使用`strip()`从每个输入行中删除换行符。 该代码通过在读取方向时进行处理来避免不必要的内存使用。

import io

def solve():
    import sys
    input = sys.stdin.readline

        cur = input().strip()

 ## 边缘情况

 对于单身人士：```
1
L
```算法初始化`ans`为 1 并且不进行比较。 输出是`1`，这与唯一的人自己形成一个完整的团簇的事实相匹配。 

对于完全相等的行：```
4
L
L
L
L
```每次比较都会发现与之前相同的方向，因此答案永远不会增加。 最终输出是`1`，正确地将整行视为一团。 

对于交替方向：```
4
L
R
L
R
```每次比较都会检测到变化。 答案从 1 开始，然后再增加 3 倍，产生`4`。 每个人都与前一个人分开，因此每个人都形成一个单独的群体。
