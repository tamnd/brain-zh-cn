 ## 解决方案
 # 问题理解

 该问题要求我们将图视为相关随机变量的模型。 每个顶点代表一个零均值随机变量。 变量的方差等于其顶点度，相邻变量具有协方差`-1`，并且非相邻变量具有协方差`0`。 我们必须为这些变量的线性组合选择系数，系数平方和固定为`1`，并最大化该组合的标准差。 

输入给出无向未加权图。 输出是与顶点相关的变量的任何归一化线性组合的最大可能标准偏差。 

该图最多有`100`顶点和`1600`边缘。 这些边界足够小，我们可以负担得起涉及重复遍历所有边或所有顶点的算法。 然而，它们还不够大，无法在竞赛环境中证明重型通用矩阵分解例程的合理性，因此我们需要利用由图创建的矩阵的结构。 

关键的观察结果是协方差矩阵正是图拉普拉斯算子。 对于每个顶点，对角线条目是其度数。 对于每条边，两个相应的非对角线条目是`-1`。 所有其他条目均为零。 归一化线性组合的最大方差是该对称矩阵的最大特征值，答案是其平方根。 

一个常见的错误是仅在单个变量中进行搜索。 例如，具有两个相连顶点的图的每个变量方差等于`1`，但将它们与相反的符号组合会产生方差`4`，产生标准差`2`？ 实际上，对于协方差矩阵`[[1,-1],[-1,1]]`，最大特征值是`2`，所以答案是`sqrt(2)`。 最大化组合同时使用两个变量，这就是独立检查顶点失败的原因。 

另一个边缘情况是断开连接的图。 考虑：```
3 1
0 1
```正确的输出大约是：```
1.4142135623730951
```孤立的顶点贡献零特征值。 假设图必须连接或删除孤立的顶点的粗心实现会改变矩阵并可能丢失正确的频谱。 

最后一个微妙的情况是所有度数都相等的图表。 例如：```
3 3
0 1
1 2
2 0
```协方差矩阵是三角图拉普拉斯算子。 最大特征值是`3`，所以答案大约是`1.7320508075688772`。 仅查看度数会错误地表明每个方向都有方差`2`。 

## 方法

 直接的方法是构建协方差矩阵并运行一般特征值分解。 这在数学上很简单，因为答案是最大特征值的平方根。 然而，实现完整的特征值求解器是不必要的，而且容易出错，特别是当我们只需要一个特征值时。 

一个更简单的蛮力想法是尝试构造候选系数向量并搜索最大方差。 系数向量的方差`a`是`a^T L a`， 在哪里`L`是拉普拉斯算子。 由于系数空间有无限多个可能的方向，因此不可能枚举候选方向。 即使将系数限制在网格内也需要指数数量的可能性。 

重要的结构是`L`是对称的。 对于对称矩阵，重复乘以矩阵会将向量推向最大特征值的方向。 这就是幂迭代法。 图拉普拉斯还允许在不存储完整矩阵的情况下进行乘法。 对于每一个边缘`(u, v)`，拉普拉斯乘法贡献`x[u] - x[v]`到顶点`u`和`x[v] - x[u]`到顶点`v`。 

暴力破解会失败，因为最佳方向是隐藏在系数空间内的连续特征向量。 观察到答案是对称矩阵的极值特征值，我们可以用重复的稀疏矩阵向量乘法来代替搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数或更糟 | 大| 太慢了|
 | 全特征分解 | 取决于实现，通常为 O(n³) | O(n²) | 不必要|
 | 功率迭代 | O(迭代次数 × (n + m)) | O(n + m) | 已接受 |

 ## 算法演练

 1. 构建图形表示。 存储每条边，因为乘以拉普拉斯算子只需要访问边，而不是存储所有边`n × n`矩阵条目。 
2. 从非零系数向量开始，对其进行归一化。 该向量必须在最大特征向量的方向上具有某些分量，否则幂迭代将无法发现它。 
3. 反复将当前向量乘以拉普拉斯算子。 对于边缘连接`u`和`v`， 添加`x[u] - x[v]`到结果`u`并添加`x[v] - x[u]`到结果`v`。 
4. 每次相乘后对结果向量进行归一化。 如果没有标准化，这些值会随着特征值呈指数增长，并最终变得数值不稳定。 
5. 使用瑞利商估计特征值：$$\lambda = \frac{x^T Lx}{x^Tx}$$对于归一化向量，这变得简单`x · (Lx)`。 

1. 输出估计的最大特征值的平方根，因为问题要求的是标准差而不是方差。 

这样做的原因是拉普拉斯算子是一个实数对称矩阵，因此它具有正交特征基。 重复乘法将每个特征向量分量按其特征值缩放。 属于最大特征值的分量增长最快，导致向量向该特征向量收敛。 然后瑞利商收敛到最大特征值本身。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    line = input().split()
    if not line:
        return
    n, m = map(int, line)

    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        edges.append((u, v))

    vec = [i + 1.0 for i in range(n)]
    norm = math.sqrt(sum(x * x for x in vec))
    vec = [x / norm for x in vec]

    for _ in range(10000):
        nxt = [0.0] * n
        for u, v in edges:
            d = vec[u] - vec[v]
            nxt[u] += d
            nxt[v] -= d

        norm = math.sqrt(sum(x * x for x in nxt))
        if norm == 0:
            print("0.0")
            return
        vec = [x / norm for x in nxt]

    lap_vec = [0.0] * n
    for u, v in edges:
        d = vec[u] - vec[v]
        lap_vec[u] += d
        lap_vec[v] -= d

    eigenvalue = sum(vec[i] * lap_vec[i] for i in range(n))
    print(math.sqrt(max(0.0, eigenvalue)))

if __name__ == "__main__":
    solve()
```输入部分读取图形并仅存储边。 该算法永远不会创建完整的协方差矩阵，因为几乎所有条目都为零，并且基于边缘的乘法速度更快并且使用更少的内存。 

初始向量使用不同的值而不是全部值。 全一向量始终是特征值为零的拉普拉斯算子的特征向量，因此从它开始将立即失去有用的方向。 

乘法循环执行幂迭代。 每条边的减法正是拉普拉斯运算：每个顶点接收其度贡献减去其邻居的值。 

收敛后，代码计算瑞利商。 这`max`调用可以在求平方根之前防止微小的负浮点错误。 

## 工作示例

 对于样本：```
2 1
0 1
```拉普拉斯算子是：$$\begin{bmatrix}
1 & -1\\
-1 & 1
\end{bmatrix}$$最大特征值是`2`。 

| 迭代| 矢量方向| 估计特征值|
 | --- | --- | --- |
 | 开始|`(1, 2)`归一化| 未测量|
 | 乘| 方向接近`(1, -1)`| 附近`2`|
 | 决赛| 主特征向量|`2`|

 输出是：```
1.4142135623730951
```因为所需的值是标准差，即方差的平方根。 

三角形图：```
3 3
0 1
1 2
2 0
```有学位`2`在每个顶点。 

| 迭代| 矢量属性| 估计特征值|
 | --- | --- | --- |
 | 开始| 任意非零向量 | 不稳定 |
 | 重复乘法| 删除零特征值分量 | 方法`3`|
 | 决赛| 最大本征方向 |`3`|

 答案是：```
1.7320508075688772
```这表明解决方案取决于整个图结构，而不仅仅是个体方差。

 ## 边缘情况

 对于具有一个孤立顶点的图：```
1 0
```拉普拉斯算子是一对一的零矩阵。 幂迭代检测乘法产生零向量并返回`0`。 标准差正确地为零，因为不存在方差。 

对于断开连接的组件：```
4 2
0 1
2 3
```该算法不需要任何特殊处理。 拉普拉斯乘法在每个分量上独立工作。 幂迭代找到包含最大特征值的分量，这正是全局最大值所需要的。 

对于正则图：```
3 3
0 1
1 2
2 0
```所有顶点都具有相同的方差，但答案不仅仅来自于该共同度。 重复的乘法捕获协方差项之间的相互作用，从而得出正确的最大特征值`3`。 

对于小图，浮点精度是主要风险。 该算法通过检查乘法后的向量范数来避免除数接近于零，并且在应用平方根之前限制微小的负特征值估计。
