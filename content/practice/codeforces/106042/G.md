 ## 解决方案
 ## 问题理解

 我们得到一个值数组，然后根据它构造一个特定的二叉树，称为最大笛卡尔树。 构建树的规则很简单：任何段中最大的元素成为该段的根，其左侧的所有元素形成左子树，而其右侧的所有元素形成右子树，递归应用。 

一旦这棵树建成，我们就不再对其形状感兴趣。 相反，我们从概念上将其放入完美的二叉树布局中：根分配位置 1，左子节点分配位置`2 * p`，右孩子获得位置`2 * p + 1`。 通过这种索引，即使实际的树很稀疏，树的每个级别也可以具有相距较远的节点。 

任务是确定该树的所有级别之间的最大宽度，其中宽度测量为相同深度的最左侧和最右侧分配位置之间的差值加一。 

输入大小足够大，任何显式重复模拟所有段或从头开始重建子树的解决方案都会失败。 扫描每个子数组中最大值的简单递归结构会导致二次行为，如果不小心实现，情况会更糟。 

当树变得高度倾斜时，就会出现微妙的失败情况。 对于已经按降序排序的数组，笛卡尔树退化为链。 在这种情况下，仅跟踪每个级别的节点计数的简单 BFS 会错误地将每个级别的宽度报告为 1，即使位置索引会产生指数级增长的间隙。 例如，对于输入`[5, 4, 3, 2, 1]`，正确的宽度取决于位置分布，而不是节点数量。 

另一个常见的陷阱是忘记树的形状是由值排序决定的，而不是仅由数组索引决定。 如果错误地将数组视为完全二叉树，则计算出的宽度将与实际的笛卡尔结构完全无关。 

## 方法

 蛮力的想法是显式构建笛卡尔树，然后执行层序遍历，同时为每个节点跟踪其分配的位置索引。 树的构建可以通过重复查找每个子数组中的最大值来完成，这确保了正确性，因为每个节点都遵守其线段最大值的定义。 

然而，在最坏的情况下，为每个递归段找到最大值会花费每个节点的线性时间。 对于大小的数组`n`，这退化为`O(n^2)`行为。 即使在遍历之前，构造本身就成为瓶颈。 

关键的改进来自于避免重复扫描段最大值。 我们认识到可以使用单调堆栈在线性时间内构建笛卡尔树，而不是从头开始为每个子问题重新计算结构。 每个元素最多被压入和弹出一次，当较大的元素阻塞较小的元素时，父子关系将在本地确定。 

一旦树以线性形式存在，我们就可以使用 BFS 计算宽度。 在遍历过程中，每个节点都携带其在概念全二叉树中的隐式索引。 对于每个深度，我们跟踪遇到的最小和最大索引。 差值给出了该级别的宽度，答案是所有级别的最大值。 

从蛮力到最优的转变取决于用单调堆栈强制的局部结构约束替换重复的全局搜索，然后将位置索引视为传播问题而不是重新计算问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最优（堆栈+BFS）| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们分两个阶段进行：有效构建笛卡尔树，然后使用索引 BFS 测量宽度。 

1. 我们从左到右扫描数组，保持单调递减的堆栈。 每个元素代表笛卡尔树中的一个候选节点。 当新元素大于堆栈顶部时，它会成为该节点的父元素，因为它是右侧第一个更大的元素。 这确保了无需搜索即可正确分配父级。 
2. 处理完所有元素后，我们将根标识为从未分配父级的元素。 这是数组中的全局最大值，与笛卡尔树定义一致。 
3. 然后我们从根开始执行 BFS。 与每个节点一起，我们在完整的二叉树布局中维护其概念索引，其中左子索引是`2 * i`右子索引是`2 * i + 1`。 这种编码与实际的内存布局无关，而是一种测量结构分布的工具。 
4. 对于每个级别的 BFS，我们记录遇到的最小和最大索引。 该层的宽度是`max_index - min_index + 1`。 
5. 我们在所有级别上保持全局最大值并在最后返回它。 

BFS 在这里很自然的原因是，宽度本质上是基于级别的属性，并且 BFS 按深度干净地分离节点，同时保留索引传播。 

### 为什么它有效

 笛卡尔树保证唯一的父结构仅由最近的较大元素确定。 单调堆栈确保我们在线性时间内准确构建该结构。 一旦结构固定，位置索引的行为就会一致：每个子索引都确定性地从其父索引派生，因此在任何级别内，索引都反映隐式完整树嵌入中的真实水平分布。 由于 BFS 逐层探索节点，因此每个可能的宽度都会被评估一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    parent = [-1] * n
    left = [-1] * n
    right = [-1] * n
    
    stack = []
    
    for i in range(n):
        last = -1
        while stack and a[stack[-1]] < a[i]:
            last = stack.pop()
        if stack:
            parent[i] = stack[-1]
            right[stack[-1]] = i
        if last != -1:
            parent[last] = i
            left[i] = last
        stack.append(i)
    
    root = 0
    while parent[root] != -1:
        root = parent[root]
    
    q = deque([(root, 1)])
    ans = 0
    
    while q:
        level_size = len(q)
        min_idx = float('inf')
        max_idx = 0
        
        for _ in range(level_size):
            node, idx = q.popleft()
            min_idx = min(min_idx, idx)
            max_idx = max(max_idx, idx)
            
            if left[node] != -1:
                q.append((left[node], idx * 2))
            if right[node] != -1:
                q.append((right[node], idx * 2 + 1))
        
        ans = max(ans, max_idx - min_idx + 1)
    
    print(ans)

if __name__ == "__main__":
    solve()
```代码的前半部分使用单调堆栈构建笛卡尔树。 每次弹出元素时，我们都会根据第一个更大的元素规则有效地解析哪个节点成为父节点。 这`last`变量捕获应重新附加为当前节点的左子节点的节点。 

BFS 部分负责宽度计算。 每个队列条目都携带节点及其隐式索引。 使用`2 * idx`和`2 * idx + 1`至关重要，因为它以保留跨级别相对间隙的方式对水平间距进行编码。 

一个微妙的细节是根识别。 由于除了最大值之外的每个节点最终都会收到一个父节点，因此从任何节点向上走直到到达`-1`可靠地找到根。 

## 工作示例

 考虑数组`[3, 1, 2]`。 

我们构建树：`3`是根，`1`是留守儿童，`2`成为的右孩子`3`。 

| 步骤| 队列| 节点| 索引 | 最小指数| 最大索引| 宽度|
 | ---| ---| ---| ---| ---| ---| ---|
 | 1 | [(3,1)] | 3 | 1 | 1 | 1 | 1 |
 | 2 | [(1,2),(2,3)] | 1,2 | 2,3 | 2 | 3 | 2 |

 第二层显示索引为 2 和 3 的节点，产生宽度 2。 

现在考虑`[5, 4, 3, 2, 1]`。 

这形成一棵完全向右倾斜的树。 

| 步骤| 队列| 节点| 索引 | 最小指数| 最大索引| 宽度|
 | ---| ---| ---| ---| ---| ---| ---|
 | 1 | [(5,1)] | 5 | 1 | 1 | 1 | 1 |
 | 2 | [(4,2)] | 4 | 2 | 2 | 2 | 1 |
 | 3 | [(3,4)] | 3 | 4 | 4 | 4 | 1 |
 | 4 | [(2,8)] | 2 | 8 | 8 | 8 | 1 |

 这证实了即使树是一个链，位置索引也会呈指数增长，但每层的宽度仍然为 1。

 ## 边缘情况

 对于像这样的单元素数组`[7]`，堆栈构建一个没有子节点的单个节点。 BFS 立即开始和结束，并且宽度正确计算为 1，因为唯一级别的最小索引和最大索引相等。 

对于严格递减的数组，每个新元素都会成为前一个结构的父元素。 堆栈不断弹出直到空为止，产生右偏链。 BFS分配索引`1, 2, 4, 8, ...`，但每一层只包含一个节点，因此宽度在每个深度都保持为 1。 

对于严格递增的数组，每个新元素都作为前一个根的右子元素附加，从而产生退化的右链。 尽管索引增长，每个 BFS 级别仍然有一个节点，并且计算的宽度正确地保持为 1。
