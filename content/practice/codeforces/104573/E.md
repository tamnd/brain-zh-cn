 ## 解决方案
 ## 问题理解

 我们有一副 52 张牌。 每张卡片都由 1 到 13 之间的整数表示，其中每个值恰好出现四次。 数字 1 代表 A，对于获胜唯一重要的是所有 4 张 A 是否最终都位于这副牌的前 26 个位置中的某个位置。 

我们被允许执行的唯一操作是完美洗牌：将这副牌分成两半，每半张 26 张牌，然后将它们交错排列，以便新牌组从前半部分取出一张牌，然后从后半部分取出一张牌，并重复此模式，直到使用完所有牌。 

我们可以多次应用此随机播放。 问题是是否存在这样的洗牌序列，导致所有四张 A 完全包含在牌堆的前半部分中。 

关键的困难在于这不是随机洗牌。 这是位置的确定性排列。 一旦我们了解了位置在重复洗牌下如何演变，问题就变成了固定排列下位置可达性的问题。 

输入大小固定为 52，因此任何至少达到 O(n²) 甚至 O(n³) 的解决方案都非常快。 这意味着我们可以完全模拟排列结构并分析位置周期。 

幼稚的解释可能会尝试模拟所有可能的洗牌序列，但即使状态空间是有限的，如果将其视为任意排列，它也会是天文数字。 正确的方法必须利用每次洗牌都是固定的排列，因此重复应用只能循环有限的结构。 

随着时间的推移，当考虑“上半年”成员资格时，会出现一个微妙的边缘情况。 一个常见的错误是认为如果一张王牌可以在上半场任何时候到达某个位置，那就足够了。 这忽略了我们需要所有四张 A 在上半场同时处于相同的洗牌状态，而不仅仅是在不同时间单独到达那里。 

## 方法

 暴力方法将重复模拟洗牌操作并跟踪牌组的每个可能状态。 由于每次洗牌都是确定性的，因此这减少了对 52 个元素进行排列的循环。 在重复发生之前，状态空间最多有 52 个不同的配置，因此完整的模拟是可行的。 然而，即使我们模拟所有状态，检查上半场 A 对齐的所有可能状态组合在概念上仍然是混乱且不必要的。 

关键的观察是洗牌定义了位置的排列。 每张卡都确定性地从一个索引移动到另一个索引。 因此，重复洗牌会沿着排列图中的固定循环移动每张牌。 

我们不考虑整个牌组的配置，而是只跟踪四张 A 的位置。 每张王牌都沿着其周期独立移动。 问题是是否存在一个时间步 t，使得所有四个周期同时将其各自的 A 放入索引 1 到 26 中。 

由于该过程是周期性的，周期最多为 52 个，因此我们最多只需要检查 52 个状态。 对于每个状态，我们使用排列取幂思想计算每个 ace 在 t 次洗牌后的位置，或者更简单地重复应用，因为大小是恒定的。 

然后我们检查所有王牌位置是​​否都位于上半场。

 ## 算法演练

 我们将洗牌建模为排列`p`， 在哪里`p[i]`是卡片原来位置的新位置`i`。 

一旦我们计算出这种排列，我们就会重复应用它来跟踪一段时间内的位置。 

1. 构建由一次完美洗牌引发的排列。 我们模拟交错：位置 1 到 26 和 27 到 52。新的顺序是确定性定义的，因此我们可以计算每个原始索引在一次洗牌后的位置。 
2. 提取所有四张 A 的初始位置。 让这些成为`a1, a2, a3, a4`。 
3. 模拟排列的重复应用，最多 52 个步骤。 在每一步中，使用以下命令更新每个 A 的位置`pos = p[pos]`。 
4. 在每一步之后（包括初始状态），检查所有四个 A 位置是否都在 [1, 26] 范围内。 
5. 如果任何步骤满足此条件，则返回“YES”。 
6.如果52次迭代后没有步骤满足，则返回“NO”。 

### 为什么它有效

 洗牌是对 52 个位置的有限集合的排列，因此重复的应用形成循环。 每个位置最多在 52 次申请后恢复到其原始值。 由于我们只跟踪此排列下的 A 位置，因此它们的联合配置是周期性的，周期除以 52。因此，任何可能发生的配置都必须出现在前 52 个步骤内。 检查所有步骤可确保我们不会错过有效的对齐状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_perm():
    # after shuffle: [0..25] interleaved with [26..51]
    p = [0] * 52
    for i in range(26):
        p[i] = 2 * i
        p[i + 26] = 2 * i + 1
    return p

def apply(p, arr):
    return [p[x] for x in arr]

def solve():
    a = list(map(int, input().split()))
    
    aces = [i for i, v in enumerate(a) if v == 1]

    p = build_perm()

    # current positions of aces
    pos = aces[:]

    for _ in range(52):
        if all(x < 26 for x in pos):
            print("YES")
            return
        pos = [p[x] for x in pos]

    print("NO")

if __name__ == "__main__":
    solve()
```该实现首先构造由单个洗牌引起的排列。 映射很简单：前半部分的第 i 个元素转到位置 2i，后半部分的第 i 个元素转到位置 2i+1。 

然后我们找到所有 A 并仅跟踪他们的位置。 这避免了重复模拟整副牌，这是不必要的，因为只有 A 位置对条件很重要。 

在每次迭代中，我们通过应用一次排列来更新 A 的位置。 该循环运行 52 次，因为排列空间以 52 为界，因此任何循环都必须在该范围内重复。 

支票`x < 26`对上半场的成员资格进行编码。 如果所有四个同时满足这一点，我们可以立即终止。

 ## 边缘情况

 一种边缘情况是初始状态已经满足条件。 该算法在任何洗牌之前都会检查这一点，因此当所有四张 A 都已位于位置 1 到 26 时，它会立即返回 YES。 

另一种情况是，即使每个 A 都单独进入上半场，但它们也不会同时进入上半场。 第二个示例捕获了这种情况。 模拟跟踪关节位置，而不是独立可达性，因此它正确返回“否”。 

最后一个微妙的情况是周期性。 由于排列的阶数有限，因此我们不需要超过 52 个步骤。 该算法明确限制迭代，确保我们永远不会依赖无限模拟或意外提前终止。
