 ## 解决方案
 ## 问题理解

 我们得到了一所房子`n`房间。 对于每个房间，我们知道两个数字：`c_i`，我们可以安装的最大散热器数量，以及`sum_i`，充分加热该房间所需的散热器部分的总数。 每个散热器可以有任意数量的部分，并且散热器的成本`k`部分是`k^2`。 我们的目标是将部分分配给散热器，以便房间中的总部分至少`sum_i`，我们不超过`c_i`散热器，并且总成本最小化。 

关键的限制是`n`最多可达 1000 个，每个房间最多需要 10,000 个分区以及最多 10,000 个散热器。 这足够小以允许`O(n)`每个房间的操作，但任何平方`sum_i`或者`c_i`可以达到10^8次操作，这太慢了。 边缘情况发生时`c_i`远小于`sum_i`或者更大。 例如，如果一个房间需要 100 个部分，但我们只能放置 1 个散热器，则必须将所有 100 个部分放在该单个散热器中。 相反，如果一个房间需要 1 个部分，而我们可以放置 10,000 个散热器，那么我们应该将 1 个部分放在单个散热器中。 

粗心的实现可能会尝试迭代跨散热器的所有可能的部分分布。 例如，对于`c_i = 2`和`sum_i = 6`, 枚举`[6,0],[5,1],[4,2]…`适用于小数字，但如果`sum_i`和`c_i`是 10,000，这种方法会非常慢。 

## 方法

 一种天真的暴力方法会尝试所有可能的组合`k`散热器并以所有可能的方式分配部分。 这是正确的，因为它涵盖了每个有效的分配，但组合的数量呈指数增长。 为了`c_i = 10,000`和`sum_i = 10,000`，甚至将 10,000 个分区枚举为 10,000 个部分也是不可能的。 这表明暴力破解是行不通的。 

关键的观察是成本函数`k^2`是凸的。 凸性是指当值尽可能相等时，平方和最小。 换句话说，对于给定数量的散热器，当我们均匀分布这些部分时，会发生最小成本，分配`floor(sum_i/c_i)`到每个散热器并传播剩余部分（`sum_i % c_i`）通过添加一个额外的部分跨越几个散热器。 这是凸函数的经典技巧：为了最小化固定总和的平方和，数字应该尽可能平衡。 

一旦我们知道了要使用的散热器数量，计算成本就很简单了。 我们计算`x = sum_i // c_i`作为每个散热器的基本节数，`r = sum_i % c_i`作为剩余部分，然后将成本计算为`(c_i - r) * x^2 + r * (x + 1)^2`。 该公式平衡散热器并考虑任何剩余部分。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((sum_i 选择 c_i)) | O(c_i) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`，房间数量。 
2. 对于每个房间，请阅读`c_i`和`sum_i`。 
3. 确定我们实际使用的散热器数量。 这是`min(c_i, sum_i)`，因为我们不能使用比允许的最大数量或总节数更多的散热器（具有 0 个节的散热器是没有意义的）。 
4. 计算每个散热器的基数：`x = sum_i // num_radiators`。 
5. 计算余数`r = sum_i % num_radiators`。 这些是无法均匀分布的额外部分。 
6. 计算总成本：`(num_radiators - r) * x^2 + r * (x + 1)^2`。 这个公式分配`x`将其余部分分配给大多数散热器，并将剩余部分分配给每个散热器`r`散热器。 
7. 输出每个房间的成本。 

为什么它有效：不变的是分配的部分的总和等于`sum_i`并且散热器的数量不超过`c_i`。 凸性保证尽可能均匀地分布截面，从而最小化平方和。 某些散热器的截面明显多于其他散热器的任何其他分布都会增加总成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
for _ in range(n):
    c_i, sum_i = map(int, input().split())
    num_radiators = min(c_i, sum_i)
    x = sum_i // num_radiators
    r = sum_i % num_radiators
    cost = (num_radiators - r) * x * x + r * (x + 1) * (x + 1)
    print(cost)
```该解决方案首先读取房间数量。 对于每个房间，它计算要使用的散热器数量并均匀划分所需的部分。 其余部分分配给每个散热器，确保所有散热器都有整数部分。 按此顺序进行乘法和平方可避免浮点错误。 使用`min(c_i, sum_i)`处理散热器数量超过部分数量的边缘情况。
