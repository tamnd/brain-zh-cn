 ## 解决方案
 ## 问题理解

 我们有两个数组，`a`和`b`。 

对于任意子数组`[l, r]`，它的值不仅仅是元素的总和`a`在里面。 我们还添加`b_l`和`b_r`，附加到两个端点的值。 

如果子数组由单个位置组成，则两个端点相同，因此其值变为：$$a_l + 2b_l$$查询更新要么`a[p]`或者`b[p]`。 有趣的查询要求完全包含在一个范围内的**两个非空不相交子数组**的值的最大可能总和`[l,r]`。 

所选的两个子数组可以具有任意长度，但它们不能重叠。 

首先要注意的是，答案并不是简单的“最佳子数组 + 第二最佳子数组”。 端点奖励创建的交互使得通常的最大子数组机制不够。 

限制才是真正的挑战。 两个都`n`查询数量最多为`2·10^5`。 单个查询可能询问几乎与整个数组一样大的间隔。 任何在查询期间扫描间隔的解决方案都会立即变得太慢。 甚至`O(√n)`每次操作都会不舒服。 目标大致是`O(log n)`每次更新和每次查询。 

一些边缘情况会使朴素的状态定义失败。 

考虑：```
a = [0,0]
b = [100,100]
```最佳答案关于`[1,2]`通过取两个单例子数组获得：```
[1] = 200
[2] = 200
answer = 400
```任何仅跟踪普通子数组和的公式都会错过双倍端点贡献。 

另一个微妙的情况是当所有值都是负数时：```
a = [-5,-5]
b = [0,0]
```答案是：```
(-5) + (-5) = -10
```我们被迫选择两个非空子数组。 默默地允许选择任何内容的状态将错误地返回`0`。 

第三个陷阱是当最佳解决方案使用一个长间隔和一个单例时：```
a = [10,-100,10]
b = [0,100,0]
```最好的选择是：```
[1,1] = 10
[2,2] = 100
```而不是任何大型连续结构。 线段树必须保留足够的信息来混合不同形状的区间。 

## 方法

 暴力解决方案将首先计算查询范围内每个子数组的值。 

对于一定长度范围`m`， 有`O(m²)`子数组。 然后我们可以尝试所有不重叠的子数组对，给出`O(m⁴)`的可能性。 即使在预先计算子数组值之后，检查所有对仍然需要花费`O(m⁴)`。 

和`m ≈ 2·10^5`，这是完全不可行的。 

更精细的观察是子数组的值可以重写为$$(a_l+\cdots+a_r)+b_l+b_r$$中间仅贡献普通的前缀和结构。 唯一特殊的部分是两个端点的处理。 

这强烈表明有一个区间 DP 跟踪已选择的端点。 

关键思想是将子数组建模为一条路径，该路径从收集左端点奖励开始，遍历累积的段`a`，并通过收集右端点奖金来结束。 

一旦以这种方式编写，组合间隔就变得非常类似于用于最大子数组和的经典线段树 DP。 不同之处在于，我们需要足够的状态来描述通过构造两个不相交的子数组的部分进度。 

优雅的解决方案是在每个线段树节点中存储一个小的最大加矩阵。 当两个相邻段合并时，矩阵乘法会自动执行 DP 转换。 

该矩阵有五个状态，代表两个子阵列的构建进度。 合并两个段成为 max-plus 矩阵乘法，它是关联的。 这使得它非常适合具有点更新和范围查询的线段树。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个查询 O(n⁴) | O(1) | O(1) | 太慢了|
 | 线段树 + Max-Plus 矩阵 | 每次更新/查询 O(log n) | O(n) | 已接受 |

 ## 算法演练

 整个解决方案基于用转换矩阵表示每个位置。 

我们使用五个 DP 阶段。 

状态`0`意味着什么都还没有开始。 

状态`1`表示第一个子数组的左端点奖金已被选择。 

状态`2`表示第一个子数组已经完成。 

状态`3`表示已选择第二个子数组的左端点奖励。 

状态`4`表示两个子数组都已完成。 

状态数永远不会减少。 每个过渡都会向前移动或保持在同一状态。 

### 矩阵解释

 对于单个位置`i`， 定义：$$A=a_i,\qquad B=b_i$$允许的转换是：$$0\to1 : +B$$开始第一个子数组。$$1\to1 : +A$$通过该位置扩展第一个子数组。$$1\to2 : +A+B$$在这里结束第一个子数组。$$2\to3 : +B$$开始第二个子数组。$$3\to3 : +A$$扩展第二个子数组。$$3\to4 : +A+B$$结束第二个子数组。 

我们还允许每个状态保持价值不变`0`。 

这些转变形成了`5×5`最大加矩阵。 

### 段表示

 对于一个段，它的矩阵表示从左到右扫描整个段时可获得的最佳值。 

入口`(i,j)`存储进入状态段时获得的最大增益`i`并保持状态`j`。 

### 合并段

 假设段`X`有矩阵`M1`和段`Y`有矩阵`M2`。 

扫描`X`其次是`Y`完全对应于 max-plus 乘法：$$M = M_1 \otimes M_2$$在哪里$$M[i][j] = \max_k (M_1[i][k]+M_2[k][j])$$这是有效的，因为在完成状态下的左段之后`k`，我们继续从同一状态穿过右侧路段。 

结合性源自最大加矩阵乘法的结合性。 

### 构建线段树

 每个叶子存储对应于一个数组位置的矩阵。 

内部节点存储其子节点的最大加积。 

### 处理更新

 当`a[p]`或者`b[p]`变化：

 1. 重建叶子矩阵`p`。 
2. 重新计算到根的路径上的矩阵。 

仅有的`O(log n)`节点发生变化。 

### 处理查询

 适用范围`[l,r]`：

 1. 收集覆盖该区间的线段树矩阵。 
2. 按从左到右的顺序将它们相乘。 
3. 设结果矩阵为`M`。 
4.答案是`M[0][4]`。 

状态`0`表示进入间隔之前未选择任何内容。 

状态`4`意味着已经构建了两个完整的不重叠的子数组。 

该转换中存储的最大值正是所需的答案。 

### 为什么它有效

 这五种状态描述了从左到右扫描位置时构建两个不相交子阵列的每个可能阶段。 

从状态的转变`1`陈述`1`表示当前位置属于第一个子数组的内部。 过渡自`1`到`2`表示当前位置是其右端点。 同样的解释也适用于各州`3`和`4`对于第二个子数组。 

由于状态仅向前移动，因此第二个子数组无法在第一个子数组结束之前开始。 这会自动强制执行不重叠。 

每个位置准确地贡献了子数组值定义所需的数量：进入或离开子数组时会添加端点奖励，并且每个包含的位置都贡献其值`a`通过扩展转换的值。 

段的矩阵存储每个可能的进入和退出状态对的最优值。 最大加乘法正确连接相邻段，因此查询区间的矩阵描述了在该区间内构建两个子数组的所有有效方法。 从状态的转变`0`陈述`4`精确地对应于构建两个完整的不重叠的子数组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

NEG = -(10 ** 30)
SZ = 5

class Node:
    __slots__ = ("m",)

    def __init__(self):
        self.m = [[NEG] * SZ for _ in range(SZ)]

def leaf(a, b):
    x = Node()

    for i in range(SZ):
        x.m[i][i] = 0

    x.m[0][1] = max(x.m[0][1], b)

    x.m[1][1] = max(x.m[1][1], a)
    x.m[1][2] = max(x.m[1][2], a + b)

    x.m[2][3] = max(x.m[2][3], b)

    x.m[3][3] = max(x.m[3][3], a)
    x.m[3][4] = max(x.m[3][4], a + b)

    return x

def merge(left, right):
    res = Node()

    A = left.m
    B = right.m
    C = res.m

    for i in range(SZ):
        Ai = A[i]
        Ci = C[i]

        for k in range(SZ):
            if Ai[k] == NEG:
                continue

            v = Ai[k]
            Bk = B[k]

            for j in range(SZ):
                cand = v + Bk[j]
                if cand > Ci[j]:
                    Ci[j] = cand

    return res

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

size = 1
while size < n:
    size <<= 1

seg = [Node() for _ in range(2 * size)]

for i in range(size):
    if i < n:
        seg[size + i] = leaf(a[i], b[i])
    else:
        idm = Node()
        for j in range(SZ):
            idm.m[j][j] = 0
        seg[size + i] = idm

for i in range(size - 1, 0, -1):
    seg[i] = merge(seg[i << 1], seg[i << 1 | 1])

def update(pos):
    p = pos + size
    seg[p] = leaf(a[pos], b[pos])

    p >>= 1
    while p:
        seg[p] = merge(seg[p << 1], seg[p << 1 | 1])
        p >>= 1

def identity():
    x = Node()
    for i in range(SZ):
        x.m[i][i] = 0
    return x

def query(l, r):
    left_res = identity()
    right_res = identity()

    l += size
    r += size

    while l <= r:
        if l & 1:
            left_res = merge(left_res, seg[l])
            l += 1

        if not (r & 1):
            right_res = merge(seg[r], right_res)
            r -= 1

        l >>= 1
        r >>= 1

    res = merge(left_res, right_res)
    return res.m[0][4]

q = int(input())

ans = []

for _ in range(q):
    t, p, x = map(int, input().split())

    if t == 1:
        a[p - 1] = x
        update(p - 1)
    elif t == 2:
        b[p - 1] = x
        update(p - 1)
    else:
        l = p - 1
        r = x - 1
        ans.append(str(query(l, r)))

print("\n".join(ans))
```叶矩阵对单个位置可能发生的每个动作进行编码。 保持相同状态的值为零，这允许跳过位置。 

merge 函数执行 max-plus 矩阵乘法。 由于矩阵大小固定为 5，因此每次合并只需花费`5³ = 125`运营。 

范围查询使用标准迭代线段树技术。 维护两个累加器，因为线段树片段从左侧和右侧以不同的顺序收集。 保留从左到右的乘法顺序至关重要。 反转它会破坏 DP 语义。 

所有值均存储为 64 位整数。 最大答案可以是大约`4·10^14`，所以 Python 整数就足够了。

 ## 边缘情况

 考虑：```
n = 2
a = [-5,-5]
b = [0,0]
```唯一有效的答案是将两个位置选择为单例间隔。 

DP 绝不允许“选择任何内容”作为最终状态，因为查询结果是特定状态`4`。 达到状态`4`需要完成两个子数组。 返回值为`-10`，这是正确的。 

考虑：```
n = 2
a = [0,0]
b = [100,100]
```每个单例区间贡献`200`。 

转换顺序：```
0→1→2→3→4
```添加四个端点奖金，产生`400`。 没有终点被遗漏或重复计算。 

考虑：```
n = 3
a = [10,-100,10]
b = [0,100,0]
```最好的答案是使用单例间隔而不是长间隔。 状态机不假设任何有关间隔长度的信息。 子数组可以在同一位置开始和结束，因为两个转换在单个叶上都可用。 DP 自然会评估这些可能性并返回正确的最大值。
