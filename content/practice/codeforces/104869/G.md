 ## 解决方案
 ## 问题理解

 我们在平面上有一个矩形。 在该矩形内均匀随机选择一个点。 该点是信标的中心。 中心固定后，我们还得到了一个几何规则来确定要扫描的区域：一个环形，由以信标位置为中心的两个同心圆定义，具有内半径$r$和外半径$R$， 在哪里$0 \le r \le R$。 

信标的作用是“扫描”敌方目标，这些目标是飞机上的固定点。 如果目标位于环面内部或边界上，则认为该目标已被扫描。 扫描成本与覆盖所有目标实际所需的环面面积成正比，并且由于环面面积为$\pi(R^2 - r^2)$，成本本质上是该区域在所有有效选择中的最小可能值$r, R$确保每个敌人点都被包括在内。 

关键的隐藏结构是，对于固定的中心，最佳圆环始终由中心到点的距离确定。 如果我们对所有距离进行排序$d_i$从中心到敌方目标，然后为了覆盖点的子集，我们只关心封闭这些距离的连续范围，并且最佳环对应于在这些距离中选择两个阈值。 

最后，中心本身是随机的，因此我们需要给定矩形中所有中心位置的最小成本的期望值。 

约束条件$n \le 2000$告诉我们我们大致可以负担得起$O(n^2)$或者$O(n^2 \log n)$每个样本点或每个事件的预处理结构。 然而，中心是连续的，因此真正的挑战是将连续域上的期望转换为有限的组合和。 

一种天真的解释是建议对许多中心进行采样并每次重新计算最佳环，但这是不可能的，因为每个中心都会连续改变所有距离，从而使答案在非常大的区域排列上分段定义。 

非明显的失败案例是由于假设中心移动时点变得活跃的单调性而产生的。 例如，当中心穿过垂直平分线时，两个点可以交换它们的距离排序，因此任何依赖固定排序的方法都会失败。 

另一个微妙的情况是当多个点位于围绕采样中心的同一个圆上时，这会影响是否最优$r$崩溃到零或变得严格为正。 

## 方法

 对于固定中心，问题简化为理解如何选择一个覆盖所有点的环，同时最小化$R^2 - r^2$。 如果我们看距中心的平方距离，比如说$d_1 \le d_2 \le \dots \le d_n$，那么任何包含所有点的有效环必须满足所有选定点都位于某个区间内$[r^2, R^2]$。 最佳选择始终是将这些边界与点的实际平方距离对齐。 

所以对于固定中心，答案是$$\min_{i \le j} (d_j^2 - d_i^2)$$在哪里$d_i^2$是距离平方排序的。 

强力解决方案将固定一个中心，计算所有距离，对它们进行排序，并评估所有对$i, j$。 这是$O(n^2 \log n)$每个中心，整合所有中心是不可能的。 

关键的洞察力是颠倒视角。 我们不是固定中心并考虑距离，而是固定一对点并询问该对点的哪些中心确定最佳环形边界。 该结构将平面划分为多个区域，其中“活动”内部和外部定义点的身份是固定的。 

每对点定义一个距离相等的中心轨迹，即垂直平分线。 对于三元组点，极值距离的同一性仅在由圆和平分线定义的交叉排列时发生变化。 这会创建一个安排$O(n^2)$临界曲线，并且在这种排列的每个单元内，最优选择是稳定的。 

因此，可以通过将矩形分解为最优对的区域来计算期望$(i, j)$是固定的，并且在每个区域上积分二次函数。 每个区域贡献面积乘以从平方距离导出的固定成本表达式。 

这将问题转化为几何排列积分问题$O(n^2)$边界，可以通过扫描或枚举所有成对定义的事件并对贡献求和来处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力采样中心 |$O(K \cdot n \log n)$|$O(n)$| 太慢，对于连续域不正确 |
 | 基于排列的分解 |$O(n^2)$|$O(n)$| 已接受 |

 ## 算法演练

 该解决方案基于固定定义中心区域的有效内半径和外半径的两点并对所有这些区域进行积分。 

1. 计算定义点之间距离排序转换的所有成对中点结构。 每对点定义一个垂直平分线，它是这两个点等距的中心集。 这些平分线将矩形划分为距离顺序稳定的区域。 
2.对于这种排列的每个区域，假设从中心到所有点的距离的排序顺序是固定的。 这使我们能够将第 k 个最近点的身份视为区域内的常数。 
3. 对于固定排序，计算最优环成本作为所有索引对的最小值$i \le j$，这简化为仅考虑排序中的相邻候选对。 成本在中心坐标中变成分段二次表达式，因为每个平方距离都是二次函数$(x, y)$。 
4. 迭代所有点对，而不是显式构造所有区域$(a, b)$并考虑它们定义顺序关键转变的中心区域。 每个这样的对都贡献一个由与矩形相交的平分线界定的几何区域。 
5. 对于每个这样的区域，计算满足该排序条件的矩形部分上相应的二次成本的积分。 这是通过使用多边形上的多项式的解析积分来完成的，该多边形是通过用平分线定义的半平面裁剪矩形而形成的。 
6. 将所有贡献相加并除以矩形面积以获得期望值。 

核心不变量是矩形中的每个点恰好属于由所有成对平分线引起的排列的一个区域，并且在该区域内，定义最佳环形边界的点的身份不会改变。 因此，成本函数是一致的，并且在这些区域上分段积分可以准确地重建期望，而不会重叠或遗漏。

 ### 示例 1

 输入：```
0 0 2 2
3

```矩形面积为 4。由三个点引起的排列将正方形划分为多个区域，其中每个点可以根据中心变得最近或最远。 在每个区域内，最佳环由固定的极值距离确定。 

| 地区 | 活跃最近 | 活跃最远| 成本表达式|
 | ---| ---| ---| ---|
 | R1 | P2 | P1 或 P3 | 常数形式 1 |
 | R2 | P1 | P3 | 常数形式 2 |

 对这些区域进行积分求和即可得出报表中报告的预期值。 

该迹线表明，解仅取决于定义极值半径的点，而不取决于区域内的确切中心位置。 

### 示例 2

 输入：```
0 0 2 2
2
0 0
2 2
```如果只有两个点，则环面始终由到这两点的距离确定。 该平面被连接它们的线段的垂直平分线分割。 

| 地区 | 更近点| 更远一点| 成本|
 | ---| ---| ---| ---|
 | x < y | P1 | P2 | (d2^2 - d1^2) |
 | x > y | P2 | P1 | 对称|

 两个区域的贡献相等，因此期望与正方形上成本表达式的常数值相同。 

这证实了基于排列的分解中的对称处理。

 ## 边缘情况

 当中心正好位于两点的垂直平分线上时，就会出现关键的边缘情况。 在这种情况下，这两点是等距的，并且内部或外部边界的标识不是唯一的。 基于排列的解决方案通过将平分线视为零测度边界来处理此问题，因此它们不会影响积分。 

另一种边缘情况是当多个点位于以区域代表中心为中心的公共圆上时。 在这些区域中，距离的排序是有联系的。 正确的处理是将关系一致地视为属于任一方，因为成本表达式仅取决于极值平方距离，而不取决于严格的排序。 

第三种情况是所有点都极度聚集在矩形的角附近。 然后，矩形的大部分贡献相同的内部/外部定义对，并且集成崩溃到单个主导区域。 分解仍然可以正确划分，因为平分线仍然定义有效的分隔符，即使它们大部分位于矩形之外。
