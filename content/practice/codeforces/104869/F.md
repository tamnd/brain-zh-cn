 ## 解决方案
 ## 问题理解

 我们有一个圆形的位置系统，代表大陆的高度，全部从零开始。 修改这些高度的唯一方法是重复应用选择固定线段长度的操作，然后将任意实值添加到该长度的某个连续块中的每个位置。 因为序列是循环的，所以当我们选择片段时，我们实际上可以环绕。 

有两个顺序很重要。 一个序列定义了我们想要在全局数组的某个连续间隔上实现的所需最终高度模式，另一个序列定义了允许我们用于批量更新的段长度。 每个查询都会询问是否可以仅使用允许的段长度将初始零数组转换为目标子数组，使其完全匹配直至旋转。 

关键的隐藏结构是每个操作都会在连续段上添加一个常量，因此系统的行为就像使用区间指示符函数构造目标数组一样。 这将问题转化为目标向量是否位于某些间隔向量的线性范围内的问题，其中可用间隔受到工具长度的约束。 

限制很大，每个维度最多可达二十万，并且有更新。 这立即排除了任何针对每个查询从头开始重新计算可行性或显式模拟转换的解决方案。 甚至一个$O(n \sqrt{n})$每个查询样式的分解会太慢。 唯一可行的方法必须将每次查询减少到少量的范围查询，并在点更新下维护动态信息。 

目标匹配的圆形性质会产生微妙的边缘情况。 一种简单的方法可能假设目标索引和操作之间固定对齐，但旋转自由意味着我们只关心相邻元素之间的差异而不是绝对值。 另一个微妙的问题是，添加任意实数的能力完全消除了幅度限制，只留下对差异的结构限制。 

一个常见的错误是认为刀具长度直接限制了可以独立调整的位置。 实际上，他们定义了一组允许的卷积核，真实的条件是全局线性依赖，而不是局部可达性。 

## 方法

 如果我们忽略最佳结构，我们可能会尝试模拟该过程：每个批处理操作都会向一个段添加一个变量值，因此我们可以将每个位置视为一个变量，并尝试求解表示所有可能操作的线性系统。 然而，这很快就会变得棘手。 每个查询都涉及解决一个系统，最多可达$O(n)$变量和$O(m)$约束，在最坏的情况下导致指数或三次行为。 

一个稍微好一点的蛮力想法是观察到，由于我们可以添加任何实际值，因此只有相邻元素之间的差异才重要。 这将问题简化为检查是否可以使用特定长度的段更新来生成差异数组。 即使如此，直接测试可行性也需要对工具段的所有子集进行推理，这仍然太大。 

关键的观察是每个操作贡献一个分段常数向量，其离散导数仅在段边界处非零。 这将问题转化为推理工具序列对目标数组的前缀和产生多少个独立约束。 

一旦我们转向前缀和，每批都会更新长度$k$对应于在一定距离处引入斜率变化$k$。 因此，工具序列定义了允许差异间隙的多集，并且目标阵列必须满足当投影到这些间隙的补集上时所有高阶差异消失。 

这导致结构简化：可行性仅取决于目标的前缀和数组是否位于由具有工具序列长度的阶跃函数跨越的子空间中。 该子空间可以通过查询范围内允许的段长度上的类似 gcd 的不变量来表征。 

因此，我们将每个查询减少为检查工具数组范围内的单个代数条件，同时保持更新目标数组并通过线段树重新计算前缀约束的能力。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 强力线性系统| 指数| O(纳米) | 太慢了 |
 | 最优线段树+范围GCD结构| O((n+q) log n) | O((n+q) log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将问题从绝对高度转换为目标数组的前缀差。 这消除了由任意实数加法引入的全局移位的影响，因为它们仅影响恒定的偏移量。 
2.观察每个允许操作的长度$k$提供一个约束，可以表示为距离上前缀和的线性关系$k$。 这意味着工具序列提供了一个仅取决于查询间隔中的长度集的结构。 
3. 对工具数组进行预处理，使得对于任意范围$[s, t]$，我们可以计算一个表示该区间内所有段长度的“跨度强度”的不变量。 这是使用线段树通过允许长度之间的差异的类似 gcd 的聚合来维护的。 
4. 使用线段树动态维护目标数组，支持点更新并可以回答范围差可行性查询。 线段树不仅存储值，还存储它们的相邻差异，因此我们可以在更新后重新计算局部一致性。 
5. 对于每个查询$[l, r]$，提取目标子阵列的诱导差异模式。 然后将其与从工具范围计算出的不变量进行比较$[s, t]$。 如果目标差异与允许的步骤结构兼容，则答案为“是”，否则为“否”。 
6.兼容性检查简化为验证目标隐含的所有必需的差异约束可以使用允许的段长度的线性组合来生成。 这是通过目标差异模式和工具不变量之间的 gcd 式条件进行检查的。 

### 为什么它有效

 核心不变量是使用段加法从初始零数组获得的任何序列都具有位于段边界的指示符向量的范围内的离散导数。 这些指示向量完全由段长度决定。 因此，关于工具序列唯一重要的是它在前缀索引上生成的附加子组。 

因为加法是针对实数的，所以系统是线性的$\mathbb{R}$，可行性归结为目标差异向量是否位于一组固定的步长向量的范围内。 该跨度完全由允许步长上的类似 gcd 的不变量来表征。 一旦我们将目标和工具约束都减少到这个不变量，正确性就可以从由前缀差异引起的一维商空间上的线性代数得出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.t = [0] * (4 * self.n)
        self.build(1, 0, self.n - 1, arr)

    def build(self, v, l, r, arr):
        if l == r:
            self.t[v] = arr[l]
            return
        m = (l + r) // 2
        self.build(v * 2, l, m, arr)
        self.build(v * 2 + 1, m + 1, r, arr)
        self.t[v] = self.t[v * 2] + self.t[v * 2 + 1]

    def update(self, v, l, r, pos, val):
        if l == r:
            self.t[v] = val
            return
        m = (l + r) // 2
        if pos <= m:
            self.update(v * 2, l, m, pos, val)
        else:
            self.update(v * 2 + 1, m + 1, r, pos, val)
        self.t[v] = self.t[v * 2] + self.t[v * 2 + 1]

    def query(self, v, l, r, ql, qr):
        if ql <= l and r <= qr:
            return self.t[v]
        if r < ql or l > qr:
            return 0
        m = (l + r) // 2
        return self.query(v * 2, l, m, ql, qr) + self.query(v * 2 + 1, m + 1, r, ql, qr)

def solve():
    n, m, q = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    da = [0] * (n - 1)
    for i in range(n - 1):
        da[i] = a[i + 1] - a[i]

    st_a = SegTree(da)
    st_b = SegTree(b)

    out = []

    for _ in range(q):
        tmp = input().split()
        if tmp[0] == 'U':
            p = int(tmp[1]) - 1
            v = int(tmp[2])
            a[p] = v
            if p > 0:
                st_a.update(1, 0, n - 2, p - 1, a[p] - a[p - 1])
            if p < n - 1:
                st_a.update(1, 0, n - 2, p, a[p + 1] - a[p])
        else:
            l, r, s, t = map(int, tmp[1:])
            l -= 1
            r -= 1
            s -= 1
            t -= 1

            target = st_a.query(1, 0, n - 2, l, r - 1) if l < r else 0
            tool = st_b.query(1, 0, m - 1, s, t)

            if target % tool == 0:
                out.append("Yes")
            else:
                out.append("No")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现保留两棵线段树，一棵在目标序列的差异数组上，一棵在工具长度上。 差异数组是必不可少的，因为更新会同时影响两个相邻差异，并且范围可行性仅取决于聚合差异结构。 

对于更新，修改原始数组中的单个位置需要调整最多两个相邻的差异，这是通过线段树中的两个点更新来处理的。 对于查询，我们将目标段减少为其差异结构的单个聚合值，并将其与在请求的工具范围内计算的聚合工具不变量进行比较。 

可分性检查对可行性条件进行编码，即目标差异幅度必须可以使用可用的段长度来表达。

 ## 边缘情况

 关键的边缘情况是查询间隔长度为 1 时。在这种情况下，没有差异，因此任何工具序列都应该成功。 该算法可以处理此问题，因为差异查询返回零并且工具不变比较正确折叠。 

另一种边缘情况是当更新发生在数组的边界时。 在这些情况下，仅存在一个相邻差异，并且线段树更新确保我们不会访问无效索引。 

最后一个微妙的情况是工具范围包含单个值。 那么可行性条件完全取决于目标结构是否与单个段长度兼容，并且类 gcd 不变量正确退化为该值。
