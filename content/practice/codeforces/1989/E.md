 ## 解决方案
 ## 问题理解

 我们得到了一个整数数组，但没有要求我们直接构建或选择该数组。 相反，每个有效数组$a$超值$1$到$k$导出派生数组$b$，其中每个位置$i$存储您必须向左或向右步行多远$i$遇到不同的值$a_i$。 

因此，对于每个位置，我们都会查看值发生变化的最接近的位置。 在等值的恒定段内，靠近边缘的位置看到的距离较小，而中间的位置看到的距离较大。 重要的是，这个距离仅取决于不同值之间的边界在哪里，而不取决于实际使用的标签。 

任务是计算有多少个不同的数组$b$如果我们考虑所有可能的数组，就会出现$a$长度$n$使用来自的值$1$到$k$，约束条件是每个值来自$1$到$k$在某处至少出现一次$a$。 

这些约束迫使我们采取线性或近线性行为。 总计$n$所有测试用例的最大可达$2 \cdot 10^5$， 和$k$至多是$10$。 这强烈表明我们应该避免任何状态爆炸，具体取决于$n \cdot k$或指数依赖$k$。 一个解决方案仅依赖于$n$用简单的组合或小$k$可能是有意进行依赖修正。 

一种简单的方法是尝试枚举所有数组$a$，计算他们的$b$，并对结果进行重复数据删除。 这会立即失败，因为即使是中等程度的$n$，数组的数量是$k^n$，这是一个天文数字。 甚至生成所有可能的$b$间接通过所有细分$a$除非我们发现结构性倒塌，否则它太大了。 

当我们假设段的不同标签产生不同的结果时，会出现更微妙的失败情况$b$。 实际上，许多不同的段值分配都会分解为相同的值$b$， 因为$b$忽略使用哪个值，仅对相邻位置是否相等做出反应。 

## 方法

 关键的观察结果是$b$完全由数组的位置决定$a$改变值，即通过其运行分解。 

如果我们将数组划分为等值的最大段，则每个段都有固定的贡献形状$b$: 在段内$[l, r]$，值$b_i$只是到该线段最近边界的距离。 这仅取决于段长度，而不取决于分配给段的编号。 

所以不要考虑数组$k$价值观，我们可以分两个阶段来思考。 首先选择将阵列分段。 然后为运行分配值，以便相邻运行不同并且所有$k$值在某处至少出现一次。 

关键的简化在于，运行序列的有效着色的存在仅取决于运行次数。 如果有$m$跑步，我们正在为一条长度的路径着色$m$和$k$颜色使得相邻的运行不同并且所有颜色至少出现一次。 对于任何$m \ge k$，这样的着色总是存在的。 原因很简单：我们首先可以保证所有$k$颜色通过将颜色分布在运行中来出现，然后在尊重邻接约束的同时贪婪地扩展。 

因此，对分段的唯一真正限制是运行次数必须至少为$k$。 

现在我们统计一个长度的数组有多少个分段$n$进入$m$存在非空连续运行。 这是标准成分计数：我们选择$m-1$之间削减职位$n-1$差距，给予$\binom{n-1}{m-1}$。 

因此，每个有效的$b$对应于选择运行分解至少$k$段，并且每个这样的分解恰好产生一个不同的$b$。 这将问题简化为对所有有效运行计数的二项式系数求和。 

暴力破解会枚举所有数组$a$，即$O(k^n)$，甚至是所有段标签组合，这仍然是指数级的。 组合洞察力将一切都分解为计数削减。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 数组的暴力枚举 |$O(k^n)$|$O(n)$| 不可能|
 | 运行分区上的组合学 |$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 我们现在将推理转化为直接计算。 

1. 我们解释任何有效的构造$a$作为连续运行的索引分区。 每次运行都是相等值的最大块。 唯一重要的结构$b$是放置这些运行边界的地方。 
2. 我们观察到分区$m$运行对应于选择$m-1$之间切点$n-1$差距。 这正好产生$\binom{n-1}{m-1}$可能的分区。 
3.我们在可以赋值的情况下判断哪些分区是有效的$1..k$运行时至少使用每个值一次。 这正是可能发生的时候$m \ge k$，因为我们至少需要$k$不同的运行来放置所有颜色。 
4. 对于每个有效$m$，我们添加$\binom{n-1}{m-1}$到答案。 这是可以支持完整运行的所有运行计数的总和$k$- 颜色的使用。 
5. 我们计算最终的总和，即所有分区的总数减去无效分区的数量小于$k$运行。 分区总数为$2^{n-1}$，所以我们减去$\binom{n-1}{0}$通过$\binom{n-1}{k-2}$。 

一个有用的简化是我们可以预先计算二项式系数或仅累加小前缀，因为$k \le 10$。 

### 为什么它有效

 每个数组$a$恰好引发一次分解，并且该分解唯一地确定$b$。 相反，任何游程分解都会产生有效的$b$，并且只要它至少有$k$运行时，我们可以分配值，以便满足对颜色的所有约束。 因此有效之间存在一一对应关系$b$数组并运行分解至少$k$段。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, k = map(int, input().split())
    if k == 1:
        return "1"

    # precompute binomial coefficients C(n-1, i)
    m = n - 1
    C = [0] * (k)
    C[0] = 1
    for i in range(1, k):
        C[i] = C[i - 1] * (m - i + 1) // i

    total = 1 << m

    bad = 0
    for i in range(k - 1):
        bad += C[i]

    return str((total - bad) % MOD)

t = int(input())
out = []
for _ in range(t):
    out.append(solve())

print("\n".join(out))
```该代码将问题分解为计算总共$2^{n-1}$，它计算所有可能的运行边界，然后减去至少不允许的配置$k$独特的价值观。 自从$k$很小，二项式前缀是直接计算的，不需要重型组合机器。 

关键的微妙之处在于我们从不显式构造数组$a$或者$b$。 我们只推理平等发生变化的地方，这是唯一能保留下来的信息$b$。 

## 工作示例

 考虑$n = 4, k = 2$。 有$2^{3} = 8$在位置之间设置边界的可能方法。 我们减去少于 2 次运行的配置，这对应于单次运行的情况，留下产生有效的所有分段$b$。 

| 步骤| 价值|
 | --- | --- |
 | 总分区数$2^{n-1}$| 8 |
 | 无效 (m < k) | 1 |
 | 回答 | 7 |

 这符合这样的想法：只要我们允许至少一次剪切，我们就可以在运行结构中的某处实现两种颜色。 

现在考虑$n = 6, k = 3$。 我们再次从一切开始$2^5 = 32$分区。 我们减去运行 1 或 2 次的分区，因为这些分区不能容纳 3 种不同的颜色。 其余分区与有效分区完全对应$b$结构。 

| 跑步$m$| 数数$\binom{5}{m-1}$|
 | --- | --- |
 | 1 | 1 |
 | 2 | 5 |
 | 3 | 10 | 10
 | 4 | 10 | 10
 | 5 | 5 |
 | 6 | 1 |

 仅有的$m \ge 3$是有效的，所以我们取$10 + 10 + 5 + 1 = 26$。 这证实了限制纯粹是在运行次数上，而不是在内部结构上。

## 测试用例```python
import sys, io

MOD = 998244353

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    def solve():
        n, k = map(int, input().split())
        if k == 1:
            return "1"
        m = n - 1

        C = [0] * (k)
        C[0] = 1
        for i in range(1, k):
            C[i] = C[i - 1] * (m - i + 1) // i

        total = pow(2, m, MOD)
        bad = sum(C[i] for i in range(k - 1))
        return str((total - bad) % MOD)

    t = int(input())
    return "\n".join(solve() for _ in range(t))

assert run("1\n2 2\n") == "1"
assert run("1\n5 2\n") == str((2**4 - 1) % MOD)
assert run("1\n6 3\n")  # basic sanity check length

 ## 边缘情况

 对于$k = 2$，条件显着简化，因为至少有两次运行的任何分段都是有效的。 该算法简化为计算所有非平凡分区，这正是$2^{n-1} - 1$。 这符合这样的直觉：只要存在至少一个边界，两种颜色就可以出现。 

对于小$n$附近$k$，减法删除了除最大分段之外的几乎所有分区，这反映出我们几乎没有足够的空间来放置所有所需的不同值。
