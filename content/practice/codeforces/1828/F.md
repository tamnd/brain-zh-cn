 ## 解决方案
 ## 问题理解

 我们得到一棵逐渐增长的树：它从顶点 1 开始，每个后续顶点都附加到树中的某个现有顶点。 对于每次插入，我们都会被问到必须添加多少个额外顶点才能使树**恰好有两个质心**。 质心是一个顶点，其移除后不会留下超过总节点一半的连通分量。 

输入为每个新顶点提供一系列父指针，输出是每次插入后达到二质心属性所需的最小附加顶点数。 

主要限制是节点数可以达到50万个，测试用例最多可以有10000个。 这意味着任何方法都必须大致**总节点数呈线性**，因为二次运算将超出可行的时间限制。 树是动态的，因此每次插入后从头开始重新计算子树大小的简单方法会太慢。 

可能导致幼稚实现失败的边缘情况包括已经居中的树（例如，长度为 2 或 3 的链），以及一侧比另一侧生长得快得多的树。 在这种情况下，如果无法有效跟踪子树大小，所需的附加节点数量并不明显。 

例如，如果前三个节点形成一条链`1 - 2 - 3`，插入节点3后，质心已经是`2`，但如果节点 4 连接到节点 3，则创建`1 - 2 - 3 - 4`，那么为了得到两个质心，我们需要添加一个节点来平衡树。 不跟踪“最重路径”的简单算法会错误计算这一点。 

## 方法

 暴力解决方案将在每次插入后重新计算每个子树的大小并检查质心。 对于一棵树`n`节点，通过 DFS 计算子树大小是`O(n)`每个查询，导致`O(n^2)`最坏情况下的总时间。 和`n = 5e5`，这太慢了。 

关键的见解是**树最多有两个质心**，并且质心结构沿着连接当前质心的路径是稳定的。 对于每个查询，树中唯一可以影响质心位置的部分是从新节点到现有质心的路径。 因此，我们不需要重新计算所有内容：我们只需要跟踪连接极端节点的**类似直径的路径**并维护沿该路径的两个质心。 添加节点有效地扩展了最长的分支，并且操作的数量由树的两半之间的不平衡性决定。 

通过跟踪距候选质心最远的节点及其深度，我们可以计算使树具有恰好两个质心所需的最少添加数量。 这将复杂性降低到`O(1)`维护深度信息后的每个查询。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 用顶点初始化树 1. 维护一个数组`depth`每个节点距顶点 1 的深度，以及`max_depth`用于跟踪当前的“直径末端”。 
2. 对于每个新顶点，从输入记录其父顶点并将其深度设置为`depth[parent] + 1`。 
3.维护两个特殊节点，`a`和`b`，它们是当前候选的质心或直径路径的末端。 最初，`a = b = 1`。 
4. 当添加新节点时：

 - 计算从新节点到`a`和`b`使用深度。 
- 如果新节点增加了距离`a`或者`b`， 更新`a`或者`b`因此。 这维护了树中的“最长路径”。 
5. 达到两个质心的最少加法次数为`max(0, (dist(a, b) - 1) // 2 - 1)`。 该公式来自以下事实：长度为`L`中间有两个质心，任何长度超过2的路径都需要插入额外的节点来平衡。 
6. 将此结果附加到每个查询的输出。 

**为什么有效**：树的质心始终位于两个最远节点之间的最长路径上。 通过跟踪直径末端，我们隐式地跟踪潜在的质心。 更新中`a`和`b`确保我们始终知道树中的最大不平衡性，这决定了引入第二个质心所需的额外节点的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        
        depth = [0] * (n + 1)
        a = b = 1  # current ends of the diameter
        res = []

        for i in range(n - 1):
            u = i + 2
            parent = p[i]
            depth[u] = depth[parent] + 1

            da = depth[u] - depth[a]
            db = depth[u] - depth[b]

            if da > db:
                if da > depth[b] - depth[a]:
                    b = u
            else:
                if db > depth[a] - depth[b]:
                    a = u

            dist = depth[a] + depth[b] - 2 * depth[1]
            ops = max(0, (dist - 1) // 2)
            res.append(ops)

        print(' '.join(map(str, res)))

if __name__ == "__main__":
    solve()
```该代码跟踪每个节点的深度以有效地维护当前直径。 更新至`a`和`b`维持定义不平衡的四肢。 根据直径长度计算操作次数可确保我们始终知道两个质心所需的最小插入次数。 

微妙之处包括从 1 开始索引、仔细的深度计算以及仅在新节点延伸路径时正确更新直径末端。
