 ## 解决方案
 ## 问题理解

 我们被要求计算给定不同整数数组的所有子数组的“美感”累积度量。 子数组的优点被定义为使用在等于范围长度减一的秒数内对连续范围的元素进行排序的操作对其进行排序所需的最短总时间。 具体来说，如果一个子数组已经排序，那么它的美观度为零。 如果它有两个相反顺序的元素，唯一可能的操作在一秒钟内对它们进行排序，因此它的美妙之处在于之一。 

输入由多个测试用例组成。 每个测试用例都提供数组的长度和数组本身。 所有测试用例的长度总和以 5000 为界。这是一个足够小的界限，即使 O(n²) 算法也可能在一秒内运行，但任何 O(n³) 都会太慢。 因为所有元素都是不同的，所以我们不需要处理重复项，这简化了范围排序逻辑。 

对于长度为 1 的子数组，会出现一个重要的边缘情况。 由于单个元素是平凡排序的，因此它的美观度为零。 对于长度为 2 的子数组，如果元素按递增顺序排列，则美感为零；如果元素颠倒，则美感为 1。 尝试模拟完全排序或假设所有范围均等贡献的粗心方法会在这些简单情况下产生错误的结果。 

## 方法

 蛮力方法很简单。 对于每个子数组，可以尝试通过尝试所有可能的范围排序来计算其美丽度。 对于长度为 k 的子数组，有 O(k²) 种可能的范围操作，并且对于 O(k) 个子数组，在最坏情况下总复杂度变为 O(n⁴)。 即使对于 n = 5000，这显然也是不切实际的。 

关键的观察结果是，子数组的美观取决于其最小和最大元素的位置。 由于每个操作都可以对任何连续子数组进行排序，因此排序的最短时间恰好是子数组的长度减去其最长递增连续序列的长度。 换句话说，美度对应于需要合并的“无序”相邻对的数量。 对于这个小版本，我们可以使用更简单的贪心方法：从最大元素开始，向最小元素合并范围，跟踪包括迄今为止看到的所有数字的最大索引范围。 每当当前范围长度与其中不同数字的计数相匹配时，就可以认为子数组可以在最短的时间内完全排序。 

这个故事自然地联系在一起：暴力方法之所以有效，是因为它尝试了所有可能性，但失败是因为子数组和操作的数量增加得太快。 观察到美丽仅取决于元素的跨度而不是它们的精确顺序，这使我们能够通过迭代子数组开始位置并在跟踪最小值和最大值的同时扩展结束位置来以 O(n²) 计算它。 这避免了完整模拟的组合爆炸。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n⁴) | O(1) | O(1) | 太慢了 |
 | 基于贪婪跨度 | O(n²) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化变量`total_beauty`为零。 这将累加所有子数组的总和。 
2. 迭代所有可能的起始索引`i`从 0 到 n-1 的子数组。 每次迭代都考虑从以下位置开始的子数组`i`。 
3.对于每个起始索引`i`,初始化两个变量`min_val`和`max_val`与价值`a[i]`。 它们跟踪当前子数组中的最小和最大元素。 
4. 通过迭代结束索引来扩展子数组`j`从`i`至n-1。 对于每个新元素`a[j]`， 更新`min_val`和`max_val`包括它。 
5. 计算当前子数组长度为`length = j - i + 1`。 将跨度计算为`span = max_val - min_val + 1`。 
6. 如果`span`等于`length`，子数组包含连续的不同整数，其美妙之处在于`length - 1`。 否则，它与之前的美感相同（如果子数组的长度为一，则为零）。 将这个子数组的美丽添加到`total_beauty`。 
7. 处理完所有从`i`，继续下一个起始索引。 
8. 考虑完所有子数组后，输出`total_beauty`。 

为什么它有效：不变的是对于来自`i`到`j`,`min_val`和`max_val`正确跟踪最小和最大的元素。 当且仅当数字连续时，跨度检查保证子数组可以在单个范围操作中排序。 由于元素是不同的，因此这充分表征了每个子数组的最小排序时间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total_beauty = 0
        
        for i in range(n):
            min_val = a[i]
            max_val = a[i]
            for j in range(i, n):
                min_val = min(min_val, a[j])
                max_val = max(max_val, a[j])
                length = j - i + 1
                span = max_val - min_val + 1
                if span == length:
                    total_beauty += length - 1
        print(total_beauty)

if __name__ == "__main__":
    solve()
```外部循环选择子数组的开头，而内部循环将子数组向右扩展。 更新中`min_val`和`max_val`逐渐避免每次从头开始重新计算它们。 美丽计算仅在当前子数组形成连续的整数序列时触发，确保我们计算排序所需的最短时间。
