 ## 解决方案
 ## 问题理解

 我们被要求计算给定不同整数数组的每个子数组的“美观”度量。 该数组可以很大，最多有 300,000 个元素，并且所有测试用例的总数以相同的数字为界。 每个子数组的优点在于使用特定操作对其进行排序所需的最短时间：选择一个连续的范围并对其进行排序，其中该操作所需的时间与范围的长度减一成正比。 单元素子数组已经排序，因此它的美观度为零。 

考虑到这些限制，对每个子数组进行强力排序是不可能的。 有潜在的$O(n^2)$子数组，并且对每个子数组进行排序可能需要线性时间，从而导致$O(n^3)$总共。 和$n$最多 3·10^5，这太慢了。 我们必须利用数组和排序操作的属性来有效地计算美度。 

一个关键的观察结果是，该问题仅取决于元素相对于彼此的位置。 因为数组具有不同的整数，所以我们可以跟踪递增序列或反转。 边缘情况包括严格递增、严格递减或具有单个反转的数组：在严格递增子数组中，美度始终为零； 在长度为 2 的严格递减子数组中，美感是其中之一。 假设对任何子数组进行排序总是将其长度减一的粗心方法会严重计算过多。 

## 方法

 一种简单的方法是生成所有子数组，对每个子数组进行排序，然后直接计算其美丽度。 对于每个长度的子数组$k$，我们需要$O(k)$找到最佳范围排序操作的时间，这相当于对其进行完全排序。 和$O(n^2)$子数组，这大致导致$O(n^3)$最坏情况下的操作。 对于大的情况，这会立即失败$n$。 

突破来自于观察到我们不需要显式地执行范围排序操作。 最小美度由每个子数组中最大和最小元素的位置决定。 具体来说，对于长度大于 1 的子数组，只有当它不是严格递增时，美丽才非零。 通过为每个元素预先计算下一个更大的元素和前一个更大的元素，我们可以确定每个位置的递增序列延伸多远。 使用单调堆栈，我们可以跟踪每个元素所属的连续“未排序”段的长度。 然后，对所有段的贡献进行计数就成为对数组的线性传递。 

实际上，最优方法减少了跟踪局部反演并计算它们在子阵列中的贡献的问题$O(n)$每个测试用例使用单调堆栈和前缀和。 我们避免显式生成子数组。

 ## 算法演练

 1. 如果数组已排序，则将数组的每个元素映射到其排名。 此步骤将任意整数转换为连续范围，从而简化了比较。 
2.初始化两个数组，`next_greater`和`prev_greater`，长度$n$。 对于每个索引$i$,`next_greater[i]`存储右侧最近的具有较大值的索引，并且`prev_greater[i]`存储左侧最近的具有较大值的索引。 对两个数组使用单调堆栈以线性时间填充它们。 这标识了元素可以有效参与范围排序的边界。 
3.对于位置处的每个元素$i$，通过计算确定其为“第一次反转”的子数组的数量$(i - prev_greater[i]) \cdot (next_greater[i] - i)$。 这会计算元素贡献非零美感的所有子数组。 
4. 对所有元素的贡献求和。 每个单位贡献对应于该子数组的最小成本，因为由最近的较大元素标识的段只需要一次范围排序操作。 
5. 返回测试用例的总和。 

为什么有效：通过映射到排名，所有比较都变成整数比较。 单调堆栈确保对于每个元素，我们有效地找到其存在导致子数组需要非零美度的边界。 将到下一个和上一个较大元素的距离相乘，对每个子数组恰好计数一次。 这保证了正确性，因为每个子数组的最小排序时间是由其最大反转精确计算的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # Map values to ranks
        sorted_a = sorted(a)
        rank = {val: i for i, val in enumerate(sorted_a)}
        a = [rank[val] for val in a]
        
        # Compute prev_greater
        prev_greater = [-1] * n
        stack = []
        for i in range(n):
            while stack and a[stack[-1]] < a[i]:
                stack.pop()
            prev_greater[i] = stack[-1] if stack else -1
            stack.append(i)
        
        # Compute next_greater
        next_greater = [n] * n
        stack = []
        for i in range(n-1, -1, -1):
            while stack and a[stack[-1]] < a[i]:
                stack.pop()
            next_greater[i] = stack[-1] if stack else n
            stack.append(i)
        
        # Compute beauty sum
        total = 0
        for i in range(n):
            left = i - prev_greater[i]
            right = next_greater[i] - i
            total += left * right - 1
        print(total)

if __name__ == "__main__":
    solve()
```该解决方案首先将元素转换为其排序等级以简化比较。 单调堆栈标识左侧和右侧最近的较大元素。 这提供了元素构成需要排序操作的子数组的边界。 公式`(i - prev_greater[i]) * (next_greater[i] - i) - 1`计算包含该 beauty 不为零的元素的所有子数组。 减一可确保我们不计算单元素子数组。
