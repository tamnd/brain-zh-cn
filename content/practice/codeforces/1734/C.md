 ## 解决方案
 ## 问题理解

 我们得到了第一个集合$n$正整数，$S = \{1, 2, \dots, n\}$，我们想要删除一些元素，以便只有子集$T$遗迹。 删除不是免费的：我们选择一个数字$k$并删除最小倍数$k$目前在$S$，支付的成本等于$k$。 我们的任务是实现$S = T$以最小的总成本。 

输入提供多个测试用例。 每个测试用例给出$n$和一个长度的二进制字符串$n$，其中“1”表示元素应保留在$T$'0' 表示应删除。 输出是删除所有不在其中的元素的最小成本$T$。 

约束很严格：$n$可以达到$10^6$，测试用例的总和不超过$10^6$。 这意味着任何解决方案都必须大致在线性或接近线性的时间内运行$n$每个测试用例。 尝试每个可能的删除序列的二次或幼稚迭代方法将太慢。 

当保留小数字（它是许多大数字的倍数）时，就会出现微妙的边缘情况。 例如，如果$T = \{3\}$在$S = \{1,2,3,4\}$，首先删除 1 和 2 可能需要仔细选择$k=1$为了成本效率，那么$k=2$删除 4. 粗心的方法可能会尝试按顺序删除数字，而不考虑如果将后面的数字作为较小数字的倍数删除，则后面的数字的删除可能会更便宜$k$。 

## 方法

 蛮力方法精确地模拟了该过程：对于每个不在其中的数字$T$, 迭代可能的$k$值以删除最小倍数。 这是有效的，因为最终每个要删除的数字都可以作为某些数字的倍数到达$k$。 然而，每个数字可能需要迭代多个$k$，考虑最坏情况的操作$O(n^2)$。 为了$n = 10^6$，这是不可行的。 

优化的关键洞察是认识到每个数字$x$只能去除一次，而且是最便宜的去除方法$x$总是选择最小的$k$划分$x$并且还没有被更小的倍数阻止$k$被保存。 这相当于按顺序迭代数字，并且对于每个应该删除的数字，添加其尚未被阻止的最小除数成本。 这将问题转化为类似筛子的过程：我们迭代数字，对于倍数，我们传播成本，除非倍数保留在$T$。 

实际上，我们处理从 1 到$n$。 对于每个数字$i$，如果它不在$T$，我们添加$i$到总成本。 那么对于所有的倍数$j = 2i, 3i, \dots, n$，我们跳过传播如果$j$被保留，否则移除成本为$j$稍后将由较小的除数处理$i$。 这确保我们永远不会过度计数并始终使用最小的可用值$k$。

 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读$n$和表示的二进制字符串$T$。 将字符串转换为布尔数组$keep[1..n]$，其中 True 表示该数字必须保留。 
2. 初始化变量$total\_cost = 0$累积删除的成本。 
3. 迭代$i = 1$到$n$。 对于每个$i$：

- 如果$keep[i]$为真，跳过$i$因为它不应该被删除。 
- 如果$keep[i]$为 False，添加$i$到$total\_cost$。 这是移除的最低成本$i$自从$i$本身是可整除的。 
- 对于倍数$j = 2i, 3i, \dots, n$：

- 如果$keep[j]$是真的，停止通过这个倍数传播，因为保留的数字会阻止通过更小的除数进一步更便宜的去除。 
- 否则，继续； 未来的倍数将在以下情况下处理$i$到达他们。 
4.处理完所有数字后，输出$total\_cost$。 

不变量是每个不在$T$使用尽可能小的值恰好删除一次$k$这将它分开。 中的数字$T$阻止传播，确保我们永远不会无意中删除它们。 该算法保证了最小的成本，因为在每一步我们都选择可用于每次删除的最小除数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        keep = [c == '1' for c in s]
        total_cost = 0
        used = [False] * (n + 1)
        
        for i in range(1, n + 1):
            if keep[i - 1]:
                continue
            j = i
            while j <= n:
                if keep[j - 1]:
                    break
                if not used[j]:
                    total_cost += i
                    used[j] = True
                j += i
        print(total_cost)

if __name__ == "__main__":
    solve()
```这`used`数组确保每个数字仅被删除一次，即使多个除数可以到达它。 迭代倍数`j += i`保证每个号码首先收到最便宜的删除。 保留的号码会停止传播，以防止意外删除。 该算法维持$O(n \log n)$由于倍数的谐波级数行为而产生的复杂性。
