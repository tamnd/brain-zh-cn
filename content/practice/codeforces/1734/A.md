 ## 解决方案
 ## 问题理解

 我们得到了一组木棍，每根木棍的长度都是正整数。 我们的目标是使用最少的操作次数来调整长度，以便其中三个可以形成一个等边三角形。 操作是将棍子的长度增加或减少一个单位，并且操作后棍子的长度不能为零或更小。 

输入由多个测试用例组成。 每个测试用例都提供了木棍的数量及其长度。 输出是确保可以使某些三重木棍相等（相当于形成等边三角形）所需的最少操作次数。 

查看约束条件，我们在所有测试用例中总共有多达 300 个棍子。 这足够小，可以考虑每个测试用例的棒数呈二次方的解决方案。 棍子长度本身可以非常大（最多$10^9$），因此任何尝试显式迭代所有可能长度的解决方案都是不可行的。 挑战不在于迭代棍棒，而在于有效计算差异。 

非明显的边缘情况包括以下情况：棍子已经相等，最少的操作次数需要使中间的棍子与极端相匹配，或者三个最接近的长度是连续的数字。 例如，给定棍子`[1, 2, 3]`，最优等边三角形的边长`2`有两个操作：增加`1`到`2`并减少`3`到`2`。 粗心的解决方案可能会尝试始终选择最小或最大的棍子作为目标，这会产生次优的答案。 

## 方法

 蛮力方法是考虑每一个可能的三元组，计算使它们相等所需的最少操作数，并取所有三元组中的最小值。 每个测试用例最多 300 根棍子，$\binom{300}{3} \approx 4.5 \times 10^6$三胞胎。 对于每个三元组，我们需要一些算术运算，考虑到限制，这在技术上是可行的，但不必要地缓慢和麻烦。 

关键的见解是对木棍进行分类。 一旦排序，最近的三根棍子总是会给出最佳解决方案，因为均衡相距较远的棍子比均衡附近的长度会花费更多的操作。 排序后，我们只需要考虑每组连续的三根木棍即可。 对于任意三元组`(x, y, z)`和`x ≤ y ≤ z`，使三个相等的最小操作是`abs(y-x) + abs(z-y)`。 这个公式的出现是因为移动`y`匹配`x`或者`z`没有比将每根棍子移向中线更好的了。 排序将问题从立方减少到排序后线性扫描，速度快得多。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 对于 n=300 来说太慢 |
 | 排序+滑动三元组| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，请阅读`n`和棍子长度数组。 
3. 按非降序对数组进行排序。 排序可确保在连续的棒中始终找到最小的调整。 
4. 初始化变量`min_ops`到无穷大。 这将跟踪此测试用例的最小操作数。 
5. 从索引迭代数组`0`到`n-3`。 对于每个索引`i`，考虑三元组`(a[i], a[i+1], a[i+2])`。 
6. 计算使三元组相等所需的运算次数：`a[i+2] - a[i]`。 这是因为使三个数字相等的最小移动是通过使它们全部等于中位数来实现的，在排序的三元组中始终是`a[i+1]`。 移动`a[i]`和`a[i+2]`到`a[i+1]`成本`(a[i+1]-a[i]) + (a[i+2]-a[i+1]) = a[i+2]-a[i]`。 
7. 更新`min_ops`如果这个值更小。 
8.扫描完所有三元组后，输出`min_ops`。 

为什么有效：排序保证我们考虑三根棍子之间的最小分布。 使用中位数可以最大限度地减少绝对差异之和。 通过迭代连续的三元组，我们确保不会错过较少数量的操作，因为任何具有较大分布的三元组将需要严格更多的操作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    min_ops = float('inf')
    for i in range(n - 2):
        ops = a[i+2] - a[i]
        if ops < min_ops:
            min_ops = ops
    print(min_ops)
```该解决方案首先读取测试用例的数量并迭代它们。 对每个阵列进行排序，以将木棒排列起来以进行最小程度的调整。 关键的微妙之处在于意识到`a[i+2] - a[i]`就足够了； 试图将所有棍子移至任一极端都不是最佳的。 边界处理（`n-2`) 确保没有超出范围的错误。 

## 工作示例

 **示例1：**

 输入：`[1, 2, 3]`（已经排序）

 | 我| 三胞胎| ops = a[i+2]-a[i] | 最小操作数 |
 | --- | --- | --- | --- |
 | 0 | (1,2,3) | (1,2,3) | 2 | 2 |

 输出：`2`。 这与移动的最少操作相匹配`1 → 2`和`3 → 2`。 

**示例2：**

 输入：`[7, 3, 7, 3]`→ 已排序`[3, 3, 7, 7]`| 我| 三胞胎| 操作| 最小操作数 |
 | --- | --- | --- | --- |
 | 0 | (3,3,7) | 4 | 4 |
 | 1 | (3,7,7) | 4 | 4 |

 输出：`4`。 最小的调整来自均衡`(3,3,7)`通过移动`3 → 7`和`7 → 7`。 

这些示例表明该算法正确地选择了连续棒之间的最小分布。

 ## 边缘情况

 对于`[1, 2, 3]`，算法选择`(1,2,3)`并计算`3-1=2`。 移动`1 → 2`和`3 → 2`实现了等边三角形，表明该方法正确地瞄准了中线，而不是极端。 为了`[1, 1, 10]`, 三元组`(1,1,10)`产量`10-1=9`，正确指示将所有棍子移动到的步数`1`或者`10`。 排序扫描确保不会错过更好的组合。
