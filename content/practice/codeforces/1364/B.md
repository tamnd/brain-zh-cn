 ## 解决方案
 ## 问题理解

 我们得到了一个排列，这意味着从 1 到 n 的每个数字都只出现一次，只是按照某种顺序。 我们可以从这个数组中删除元素并将剩余元素保持相同的相对顺序，形成一个子序列。 在长度至少为 2 的所有子序列中，我们希望有一个能够最大化连续所选元素之间的绝对差之和的子序列。 如果几个子序列达到相同的最大值，我们会选择长度尽可能最小的一个。 

目标函数仅取决于相邻的选定值，而不取决于它们的原始位置。 这很重要，因为这意味着我们关心的结构是由值如何上下移动引起的，而不是它们在数组中的位置。 

在最多 2⋅10^4 个测试用例中，约束 n 高达 10^5 意味着总输入大小约为 10^5，因此每个测试用例在最坏的情况下需要 O(n) 或 O(n log n)，但总体上是有效的线性。 每个测试用例的任何二次方都是不可能的。 

一个天真的想法是尝试所有子序列并计算它们的分数。 即使限制为单个测试用例，也有 2^n 个子序列，这也是完全不可行的。 即使对所有对或三元组进行动态编程仍然太慢。 

一个更微妙的失败案例来自于贪婪地接受局部的巨大差异而不考虑全局结构。 例如，总是在数组顺序中选取相邻的极值会失败，因为最佳子序列与输入中的邻接性无关，而是与值振荡相关。 

## 方法

 暴力方法将枚举每个子序列，计算其总绝对差，并跟踪最佳结果。 这是正确的，因为它直接遵循定义，但它需要指数时间，因为每个元素都可以包含或排除。 当 n = 100000 时，即使 n = 40 也已经变得太大了。 

关键的观察结果是绝对差和仅取决于增加和减少移动之间的转换。 如果我们采用子序列并查看连续元素，则每次方向发生变化时，我们都会“浪费”潜在贡献，因为我们没有在极端之间充分利用。 

为了最大化总和，我们希望子序列捕获排列的所有有意义的“转折点”。 在排列中，可以删除值位于其邻居之间的每个局部中间元素，而不会减少最佳可实现的总差。 这建议将序列压缩为递增和递减片段的交替运行，仅保留这些运行的端点。 

同样，当我们扫描排列时，最优子序列由按值顺序排列的所有局部最小值和局部最大值组成。 从连续保留元素之间的值比较来看，这些正是值序列方向发生变化的点。 

我们可以将其形式化：在扫描排列时，我们维护一个候选子序列，其中每个新保留的元素必须扩展当前的“趋势变化结构”。 如果最后两个选择的元素和新的候选元素在同一方向上是单调的，则中间的元素是不必要的并且可以被替换。 

这导致了线性贪婪构造，其中我们只保留产生斜率变化的元素，确保最大的总变化，同时也最小化点的数量，因为不必要的中间点会立即被丢弃。

 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |

 ## 算法演练

 我们在从左到右扫描排列的同时逐步构建答案。

1. 从代表所选子序列的空列表开始。 我们将维护它，以便它始终保留迄今为止所见的最佳可实现的差异“形状”。 
2. 对于排列中的每个元素，尝试将其附加到子序列中。 
3.追加后，检查最后三个元素是否形成单调趋势。 如果最后三个元素严格递增或严格递减，则中间元素对任何最佳“转弯”没有贡献，可以将其删除。 我们删除它。 

原因是，在单调三元组中，通过跳过中间点可以更有效地实现两条边的总贡献，因为绝对差异会分解为端点之间的单个直接跳跃。 

1. 重复删除步骤，同时最后三个元素保持单调。 这确保了子序列总是尽可能交替方向。 
2.处理完所有元素后，保证得到的子序列具有最大总绝对差。 如果多个子序列达到相同的总和，则该过程自然会产生最短的子序列，因为它会立即删除每个冗余的中间元素。 

### 为什么它有效

 该算法强制要求三个连续选择的元素不得保持相同的方向。 这意味着子序列中的每个内部点都是一个转折点：相对于子序列中的邻居的局部最大值或局部最小值。 

任何具有非旋转中间元素的子序列都可以通过删除该元素来改进，而不减少绝对差的总和。 因此，任何最优解都可以在不损失价值的情况下转化为满足这种交替性质的解，其中贪心构造通过删除每个可移动点一出现就保留了最少的元素。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = list(map(int, input().split()))
    
    res = []
    
    for x in p:
        res.append(x)
        
        while len(res) >= 3:
            a, b, c = res[-3], res[-2], res[-1]
            if (a < b < c) or (a > b > c):
                res.pop(-2)
            else:
                break
    
    print(len(res))
    print(*res)

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```核心结构是类似栈的链表`res`，它存储当前候选子序列。 附加每个新元素，然后我们检查最后三个元素。 如果它们形成严格单调的三元组，则删除中间元素，因为它不会改变方向，只会增加长度。 

while 循环是必不可少的，因为删除一个元素可能会暴露出涉及较早元素的新单调三元组，因此我们反复强制执行不变式。 

操作顺序很重要：我们总是先追加，然后简化。 这保证了每个元素在被丢弃之前都被视为潜在的转折点。

 ## 边缘情况

 严格递增排列如`1 2 3 4 5`是完全单调的。 该算法会追加元素直到出现一个三元组，然后不断删除任何单调三元组的中间元素，最终只留下端点。 对于此输入，序列压缩为`[1, 5]`，因为每个中间元素一旦形成单调链就被消除。 

严格递减排列的行为是对称的。 每个新元素都会扩展递减运行，直到变成三元组，之后删除中间元素，再次只留下端点，例如`[5, 1]`取决于保留方向。
