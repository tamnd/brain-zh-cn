 ## 解决方案
 ## 问题理解

 我们得到了几个候选咖啡馆位置和飞机上的几个地标点。 对于每个固定的咖啡馆位置$C_i$，我们考虑每对不同的地标$L_j, L_k$。 每个这样的对与咖啡馆一起形成一个三角形$C_iL_jL_k$。 

现在想象一下选择任意点$P$在飞机上。 对于固定咖啡馆$C_i$，我们定义分数$P$作为其三角形的地标对的数量$C_i$严格包含$P$。 我们可以选择咖啡馆的位置和点$P$，我们想要尽可能高的分数。 

关键结构是对于固定的$C_i$，我们并不是试图评估单个点$P$，而是询问在平面中的哪个位置许多三角形的重叠变得最大。 

每个测试用例最多提供 400 个咖啡馆和 400 个地标，并且测试用例有很多，但所有测试的总点数是有界的。 这强烈表明每个配置接近二次或三次的解决方案是可以接受的，但是任何尝试处理所有三元组或显式处理每个三角形和每个查询点的几何图形的任何操作都将失败。 

天真的尝试会选择一家咖啡馆$C_i$, 枚举所有$\binom{M}{2}$三角形，然后尝试计算平面上的深度图或测试由三角形边界相交形成的候选点。 这很快就会变得难以管理，因为$O(M^2)$三角形可以产生$O(M^4)$原则上交集复杂度大，甚至迭代候选点也太大。 

更微妙的故障模式来自于尝试修复一个点$P$并通过检查方向条件来计算包含它的三角形。 那需要$O(M^2)$每$P$，但没有明显的相关有限集$P$除非我们了解这些三角形如何重叠的几何形状，否则保证正确性的候选者。 

一个小的说明性陷阱是最优的$P$不一定是地标或咖啡馆点，也不一定是穿过地标的两条线的交点。 它是通过最大化组合重叠来定义的，因此简单的候选缩减是不可靠的。 

## 方法

 确定咖啡馆位置$C_i$。 问题变成：在由 组成的所有三角形中$C_i$和两个地标，找到一个点$P$这就是这些三角形的最大数量。 

一个有用的几何重构是从三角形的推理切换到射线的推理$C_i$。 一点$P$位于三角形内$C_iL_jL_k$当且仅当射线起始于$C_i$方向$C_iP$与线段相交$L_jL_k$。 这将问题转化为计算有多少个地标片段被光线“击中”。 

所以对于固定的$C_i$和方向$\theta$，定义一条射线$C_i$。 每对$(L_j, L_k)$如果该段有贡献$L_jL_k$与该射线相交。 答案为$C_i$是所有射线方向上相交线段的最大数量。 

现在看看一对地标。 从$C_i$，每个地标都有一个极角。 该段$L_jL_k$将与方向上的射线相交$\theta$恰好在什么时候$\theta$位于以下角度之间$L_j$和$L_k$沿着周围较小的圆弧$C_i$。 换句话说，每对在围绕的角圆上定义一个间隔$C_i$，并且我们想要覆盖单个角度的这些间隔的最大数量。 

所以对于每一个$C_i$，问题就变成了循环区间重叠问题$O(M^2)$间隔。 我们通过将角度范围加倍并扫掠将其转换为直线。 

蛮力方法将显式地测试每个方向或离散化角度，但这会失败，因为最佳值可能出现在任何两个界标方向之间，因此需要连续搜索。 间隔扫描捕获所有候选最佳方向。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对点或方向进行暴力破解 |$O(M^3)$每家咖啡馆或更糟|$O(M^2)$| 太慢了|
 | 每个咖啡馆的角度间隔扫描|$O(M^2 \log M)$|$O(M^2)$| 已接受 |

 ## 算法演练

 我们独立处理每家咖啡馆。 

1. 修复咖啡馆点$C_i$。 将所有地标转换为相对于的极坐标$C_i$，计算它们的角度$[0, 2\pi)$。 

这是必要的，因为所有三角形结构仅取决于咖啡馆的方向，而不是绝对坐标。 
2. 按极角对所有地标进行排序$C_i$，并通过添加来复制列表$2\pi$到每个角度来处理圆形环绕。 

这使我们能够将循环间隔视为线性间隔。 
3. 对于每对地标$L_j, L_k$，构造一个代表所有方向的角度区间$\theta$来自哪个段$L_jL_k$通过光线可见$C_i$。 

具体来说，这个区间是沿着它们的角度之间的圆沿着周围较短方向的开弧$C_i$。 
4. 对于每个这样的间隔，在扫描结构中在其起始角度添加+1 事件并在其结束角度添加-1 事件。 

这编码了每个可能的射线方向相交的线段数量。 
5. 按角度对所有事件进行排序并扫描它们，保持连续总和。 

遇到的最大值是这个固定咖啡馆的最佳三角形数量。 
6. 对所有人重复$C_i$并在所有咖啡馆中取最大值。 

### 为什么它有效

 对于固定咖啡馆$C_i$, 每个三角形$C_iL_jL_k$贡献一点$P$恰好当射线$C_iP$位于由下式确定的角区间内$L_j$和$L_k$。 这将每个三角形缩减为方向圆上的一个区间。 任意一点$P$唯一对应于一个方向$C_i$，因此最大化三角形包含相当于找到一个间隔重叠最大的方向。 对角度端点的扫描会检查所有组合不同的方向区域，确保不会错过最佳值。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        N, M = map(int, input().split())

        cafes = [tuple(map(int, input().split())) for _ in range(N)]
        lands = [tuple(map(int, input().split())) for _ in range(M)]

        ans = 0

        for cx, cy in cafes:
            angles = []
            for x, y in lands:
                angles.append(math.atan2(y - cy, x - cx))

            angles.sort()

            a = angles
            n = len(a)

            events = []

            for i in range(n):
                for j in range(i + 1, n):
                    ai, aj = a[i], a[j]
                    # normalize difference to (0, 2pi)
                    d = aj - ai
                    # choose minor arc interval where ray lies between them
                    if d < 0:
                        d += 2 * math.pi

                    # interval is (ai, aj) on circle, but ensure it is minor arc
                    if d > math.pi:
                        # swap to take other arc
                        start = aj
                        end = ai + 2 * math.pi
                    else:
                        start = ai
                        end = aj

                    events.append((start, 1))
                    events.append((end, -1))

            events.sort()

            cur = 0
            best = 0
            for _, v in events:
                cur += v
                best = max(best, cur)

            ans = max(ans, best)

        print(ans)

if __name__ == "__main__":
    solve()
```该实现修复了一家咖啡馆，并将所有地标转换为它周围的角度。 每对地标都成为角圆上的一个间隔，我们使用扫描事件端点来计算有多少个这样的间隔在最佳方向上重叠。 

一个微妙的点是处理角度的圆形性质。 该代码通过允许间隔超出来解决这个问题$2\pi$，有效地展开圆圈，使环绕间隔变为线性。 

另一个重要的细节是，每一对贡献恰好一个与较小弧相对应的间隔。 选择较大的弧会错误地重复计算与有效射线相交不对应的方向。 

## 工作示例

 考虑原点处的一家咖啡馆和以一定角度放置的四个地标$0^\circ, 90^\circ, 180^\circ, 270^\circ$。 每对定义一个小弧间隔。 

| 配对 | 角度间隔（度）|
 | --- | --- |
 | (0, 90) | (0, 90) | (0, 90) | (0, 90) |
 | (0, 180) | (0, 180) | (0, 180) | (0, 180) |
 | (0, 270) | (0, 270) | (270, 360) U (0) 通过 unwrap | 处理
 | (90, 180) | (90, 180) |
 | (90, 270) | (90, 270) |
 | (180, 270) | (180, 270) |

 扫过这些间隔，最大重叠发生在附近$90^\circ$到$180^\circ$，其中多个圆弧相交。 

这表明最佳方向对应于许多地标对同时“看到”来自咖啡馆的光线的区域。 

现在考虑一种倾斜的配置：地标聚集在一个半圆中。 然后，大多数对产生覆盖该密集区域的间隔，并且扫描显示该簇中心附近有明显的峰值重叠，这与最佳观察方向朝向地标的最密集角集中的直觉相匹配。

 ## 边缘情况

 第一个微妙的情况是，所有地标都位于咖啡馆周围的狭窄角区域内。 在这种情况下，大多数对都会生成几乎覆盖同一区域的重叠间隔。 该算法可以正确处理此问题，因为所有间隔都塌陷为密集扫描区域，并且最大重叠反映了该簇中对的组合爆炸。 

另一种情况是地标均匀分布在圆圈周围。 在这里，没有强烈偏爱的方向，并且每个间隔都很短。 扫描正确地显示了相对均匀的低最大值，因为没有角度方向同时位于许多对间隔内。 

最后一种情况是环绕对，其中一个地标处于小角度，另一个地标靠近$2\pi$。 间隔施工必须超出$2\pi$，并且角度的重复确保这些间隔仍然表示为展开线上的连续线段。 对扩展事件列表的扫描可以正确地对这些事件进行计数，而不会错误地分割贡献。
