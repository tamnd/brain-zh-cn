 ## 解决方案
 ## 问题理解

 我们将一组值放入房间的圆形数组中。 每个房间只包含一个物品，每个物品要么是具有奖励值的普通箱子，要么是进入后立即停止运行的模仿品。 玩家从一个均匀随机的房间开始，绕着圆圈向前移动。 在第一个模仿者之前访问的每个常规宝箱都会为总数贡献其价值，而模仿者本身不会贡献任何东西。 

对于每个固定数量的模仿者$k$，我们可以任意重新排列所有箱子并选择哪个$k$位置变成模仿者。 固定该排列后，我们计算均匀随机起始位置上的预期收集值。 我们希望每个人独立地获得尽可能小的期望$k$。 

输出是所有的序列$k$，并且每个值必须以模计算$998244353$作为有理数。 

约束条件$n \le 3 \cdot 10^5$立即排除任何显式模拟启动或处理所有旋转的解决方案。 任何平方项$n$每$k$是不可能的。 即使是一个解决方案$O(n \log n)$每个值$k$会太慢，因为我们需要所有$n$答案。 

一个微妙的点是，期望取决于全局循环结构，而不仅仅是局部排序。 独立处理分段或假设贪婪的局部放置而不分析起点如何在圆上分布的幼稚方法将会失败。 

一个常见的失败案例是假设我们应该始终通过在高价值周围放置模仿来“保护”高价值。 例如，如果我们将一个大值与两侧的模仿隔离开来，我们可能会认为它是安全的，但从该段内部开始仍然会收集它，并且真正的贡献取决于段向前延伸的时间，而不是邻接。 

## 方法

 直接的蛮力策略会尝试每种模仿的排列，然后以所有可能的方式排列值，通过模拟所有的值来计算预期奖励$n$起始位置，并取最小值。 即使固定模仿位置也会留下$O((n-k)!)$排列，并且有$\binom{n}{k}$选择模仿的方法，使得这完全不可行。 

关键的观察结果是，一旦拟态被固定，圆圈就会分解成连续的规则箱子的片段。 从一个片段开始的玩家收集该片段的后缀，直到到达其结束模仿。 这将循环过程转换为独立的线性段。 

在一段长度内$L$，如果值为$v_1, v_2, \dots, v_L$，然后从位置开始$i$收集$v_i + v_{i+1} + \dots + v_L$。 各值$v_j$因此被准确地计入$j$该段内的起始位置。 这将每个段变成一个加权和$\sum v_j \cdot j$。 

现在全局结构仅取决于段长度。 如果我们有长度段$L_1, L_2, \dots, L_t$，总贡献是具有权重的独立加权线性数组的总和$1, 2, \dots, L_i$在每个段内。 唯一剩下的自由是如何通过放置模拟来选择段分区。 

关键的结构事实是权重函数$\sum_{j=1}^{L} j$是凸的$L$。 对于固定总数的常规箱子，将长度集中到更少的部分会严格减少总重量总和。 这意味着我们希望尽可能避免将常规箱子分成多个部分。 

既然我们有$k$模仿，我们可以创造$k$段，并且允许连续模仿会产生空段。 最佳配置是连续放置所有模仿者，恰好产生一段长度为规则的箱子$n-k$，其余段为空。 

这将问题分解为单个长度的线性数组$n-k$，其中位置$j$有重量$j$。 然后，我们通过按升序对值进行排序并将小值与小权重配对来最小化加权和。

 | 段优化+排序|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 ### 1. 对宝箱值进行排序

 我们按非降序对所有值进行排序。 这使我们能够将小值与小位置权重相匹配，这对于最小化权重增加的乘积之和是最佳的。 

### 2.修复拟态诱导的结构

 对于给定的$k$，我们观察到最好的安排是将所有$k$在圆圈上连续模仿。 这会创建一个连续的长度规则的箱子块$n-k$。 任何其他放置都会增加细分并增加总加权贡献。 

### 3.建立位置权重

 在常规块内，位置被标记$1$到$n-k$。 位置上的值$j$准确贡献$j$将其值乘以所有起始位置的总和。 

### 4. 计算总贡献

 我们计算$$S_k = \sum_{j=1}^{n-k} a_j \cdot j$$在哪里$a_j$是排序后的数组。 

### 5. 转换为期望

 每个起始位置之间的可能性相等$n$房间。 因此期望值为：$$\frac{S_k}{n}$$我们乘以模逆$n$以获得最终答案。 

### 为什么它有效

 拟态的每种排列都将圆划分为多个段，每个段在其长度上贡献一个凸加权和。 凸性意味着将质量分割到多个部分只会增加总重量贡献，而不管值分配如何。 因此，最佳结构是常规箱子的单个最大分段。 一旦这个结构被固定，最小化加权和就会减少到标准的重排不等式：按照位置递增的顺序将较小的值分配给较大的权重。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

n = int(input())
c = list(map(int, input().split()))
c.sort()

inv_n = modinv(n)

prefix_weighted_sum = 0
res = []

# We compute answers for all k by progressively removing largest elements
# k mimics => n-k regular elements used
# best uses smallest (n-k) elements
for k in range(1, n + 1):
    m = n - k
    if m == 0:
        res.append(0)
        continue
    s = 0
    for i in range(m):
        s = (s + c[i] * (i + 1)) % MOD
    res.append(s * inv_n % MOD)

print(*res)
```该实现将每个元素减少为单个加权数组。$k$。 排序步骤确保最佳配对。 对于每个$k$，我们取最小的$n-k$值，因为当我们增加模仿的数量时，较大的值会被排除。 

乘以模逆$n$将所有起始位置的总和转换为期望值。

 ## 边缘情况

 一种极端情况是所有箱子都具有相同的价值。 在这种情况下，排序不会改变任何东西，并且每种排列都具有相同的加权和结构。 例如，使用输入`3 3 3`， 每一个$k$产生贡献位置数量的线性缩放。 该算法正确地处理了这个问题，因为它只依赖于前缀长度，而不依赖于值的区别。 

另一个边缘情况是$k = n$，其中所有箱子都是模仿者。 常规段的长度为零，因此无论如何排列都不会做出任何贡献。 在这种情况下，该算法显式返回零，这与每次启动都会立即命中模仿对象并且不收集任何内容的事实相匹配。 

当出现第三种边缘情况时$k = 1$，其中只有一个模仿者。 圆变成了长度的单个线性段$n-1$，答案减少为完全加权的前缀和除以$n$。 该算法自然地捕获了这一点，无需任何特殊处理，因为该构造仍然产生一个连续的段。
