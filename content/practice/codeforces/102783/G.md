 ## 解决方案
 ## 问题理解

 菲利克斯收到巧克力超立方体，其尺寸对应于所选边长的幂`w`。 可用的部件有重量：`1, w, w², w³, ..., w¹⁰⁰`。 

对于每个包裹的重量`x`，我们需要确定 Felix 是否可以将一些超立方体放置在天平的任一侧，以使两侧相等，而包装位于一侧。 

将一块巧克力放在包装的同一侧会从包装的有效重量中减去其价值，而将其放在相反的一侧则会增加其价值。 由于每个可用的超立方体最多只能使用一次，所以问题就变成了是否`x`可以写成以下幂的总和`w`其中每个系数都是以下之一：`-1, 0, 1`。 

输入最多包含 20 个包裹重量，每个包裹重量最多`10^9`。 直接搜索子集是不可能的，因为有 101 种可能的幂`w`，给出的组合远远多于可以探索的组合。 即使将我们限制在有用的幂上，仍然会留下指数搜索空间，因此解决方案必须利用幂的结构。 

重要的属性是`w`形成位置编号系统。 我们可以从最小幂向上决定每个幂的系数，而不是全局选择棋子。 一旦系数为`w^i`是固定的，剩余值必须能被整除`w^(i+1)`，这让我们可以一次将问题减少一位数。 

棘手的情况来自看起来接近可表示但需要无效数字的值。 例如，与`w = 5`，值`2`无法创建：```
1
5
25
```该范围附近可能的有符号组合是`-5, -4, -1, 0, 1, 4, 5`，所以答案是`NO`。 仅检查普通 5 进制数字的简单方法可能会错误地假设每个数字都可以调整。 

另一个边缘情况是余数为`w - 1`。 例如，与`w = 5`和`x = 4`，正确的表示是：`5 - 1 = 4`。 

第一个数字实际上是`-1`， 不是`4`。 任何只允许数字的方法`0`通过`w-1`会在这里失败。 

一个小例子：```
Input
1 5
4

Output
YES
```该包可以通过放置来平衡`5`一侧为立方体，另一侧为单个立方体。 

## 方法

 蛮力方法是尝试可用超立方体的所有可能分配。 每个电源可以具有三种状态：未使用、与包装一起放置或紧靠包装放置。 如果我们考虑所有 101 个幂，这给出`3^101`的可能性，这是一个天文数字。 即使功率仅达到`10^9`从数字上看，搜索空间仍然是指数级的，无法工作。 

有用的观察是，这正是一个平衡位置表示问题。 在正常的基地中——`w`表示，每个数字必须介于`0`和`w-1`。 这里，每个数字都可以是`-1`,`0`， 或者`1`。 我们只需要检查当前的余数模`w`。 

假设当前值为`x`。 的系数`1`-power 确定除以时的余数`w`。 如果`x % w`为零，则当前数字必须为零。 如果余数为一，我们就使用正数。 如果余数是`w-1`，我们使用负数，因为减一会使该值整除`w`。 

删除该数字后，我们除以`w`并为下一个电源解决同样的问题。 如果出现不能用下式表示的余数`-1`,`0`， 或者`1`，答案是不可能。 

暴力破解之所以有效，是因为它会尝试每个有效的位置，但会失败，因为它忽略了位置结构。 贪婪的逐位过程之所以成功，是因为每个决定都是由整除性所迫使的。

 | ---| ---| ---| ---|
 | 蛮力 | O(3^101) | O(3^101) | 奥(101) | 太慢了|
 | 最佳| 每次查询 O(100) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取每个包裹的重量并反复检查其除以的余数`w`。 最低功率`w^0`是影响余数模的唯一幂`w`，所以必须先决定。 
2. 如果余数为零，则分配系数`0`到当前功率。 当前值已经可以整除`w`，所以不需要这个大小的立方体。 
3.如果余数为1，则分配系数`1`。 取当前大小的一个立方体可以消除多余的余数。 
4. 如果余数是`w - 1`，分配系数`-1`。 这与下一位数字加一相同，因为`-1 ≡ w-1 (mod w)`，并且它使剩余值可以除以`w`。 
5. 如果余数为其他值，则当前幂不存在有效系数，因此答案为`NO`。 
6. 将剩余值除以`w`并继续下一个电源。 当值变为零时，该过程停止。 

为什么它有效：

 在每一步中，当前值必须表示为：`current = digit + w * remaining`在哪里`digit`是其中之一`-1`,`0`， 或者`1`。 所选数字是唯一可能的数字`current - digit`可除以`w`。 删除它后，剩下的问题是相同的，但提高了一级。 由于每个数字决策都与原始平衡问题保持等价性，达到零意味着我们找到了有效的排列，而遇到不可能的余数则证明不存在排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def possible(x, w):
    while x > 0:
        r = x % w

        if r == 0:
            digit = 0
        elif r == 1:
            digit = 1
        elif r == w - 1:
            digit = -1
        else:
            return False

        x = (x - digit) // w

    return True

def solve():
    n, w = map(int, input().split())

    ans = []
    for _ in range(n):
        x = int(input())
        ans.append("YES" if possible(x, w) else "NO")

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```这`possible`函数执行平衡基数转换。 变量`x`始终代表尚未被较小功率处理的包装重量部分。 

余数检查是实现的核心。 三种有效情况正好对应于当前功率的三个可能系数。 线路`x = (x - digit) // w`首先删除所选系数，然后移至下一个幂。 

无需显式生成以下权力`w`。 重复的划分自然会经过相同的位置。 由于所有输入最多`10^9`，需要的迭代次数少于 100 次。

 ## 边缘情况

 当余数都不是时`0`,`1`，也不`w-1`，算法立即拒绝该值。 例如：```
Input
1 5
2
```第一个余数是`2`。 当前数字需要是`2`，但单个立方体只能贡献`-1`,`0`， 或者`1`在这个位置。 算法返回`NO`。 

当余数为`w-1`，解必须使用负数。 例如：```
Input
1 5
4
```第一个余数是`4`，所以我们选择数字`-1`：`4 - (-1) = 5`除以之后`5`，剩余值为`1`，通过选择数字来处理`1`。 其表示形式为`5 - 1`，所以答案是`YES`。 

最大值也是安全的。 例如：```
Input
1 2
1000000000
```该算法仅执行二进制归约。 它在大约 30 次迭代后完成，远低于可用的 100 次幂，并正确确定签名表示是否存在。
