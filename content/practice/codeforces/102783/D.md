 ## 解决方案
 ## 问题理解

 我们有一排幽灵，每个幽灵都有一个整数年龄。 一步操作包括选择两个年龄不同的相邻鬼魂。 年轻的鬼魂消失了，而年长的鬼魂仍然存在，并且变老了一岁。 鬼离开后，剩余鬼的顺序保持不变。 

任务不是模拟该过程。 我们只需要决定 Boo 是否可以按某种顺序选择动作，以便只剩下一个幽灵。 

输入给出了鬼魂的数量以及按行顺序排列的年龄。 如果存在一个有效匹配序列，可以删除除一个之外的所有重影，则输出为“是”，否则输出为“否”。 

重要的限制是幽灵的数量可以多达 10000 个。模拟所有可能的选择是不可能的，因为可能的匹配顺序的数量增长得非常快。 即使尝试每对相邻的选择也会导致指数搜索空间。 我们需要一个直接决定答案的时代特征。 

边缘情况很小但很容易被忽略。 如果只有一个鬼魂，答案立即为“是”，因为已经只剩下一个鬼魂了。 

例如：```
Input
1
7

Output
YES
```仅检查所有年龄是否相等的解决方案可能会错误地拒绝这种情况。 

另一个重要的情况是当每个鬼魂的年龄相同并且有多个鬼魂时。```
Input
4
5
5
5
5

Output
NO
```没有两个相邻的鬼魂年龄不同，所以第一步根本无法开始。 

最后一种情况是，相等的年龄并不都是相同的值。```
Input
5
4
4
3
4
4

Output
YES
```粗心的做法可能会认为重复的价值观会阻碍进步，但中年3可以与邻居战斗，让一个幽灵成长并最终消灭其他幽灵。 

## 方法

 暴力方法是尝试每一种可能的战斗序列。 对于每个状态，我们选择具有不同年龄的每对相邻的一对，删除较小的一个，增加较大的一个，并递归地检查是否可以到达单个鬼魂。 这精确地模拟了该过程，因此它是正确的，但状态数量太多了。 拥有 10000 个幽灵，即使是最初的几个选择也已经创造出一棵巨大的分支树。 

关键的观察是，唯一无法开始战斗的情况是每个鬼魂的年龄相同。 如果至少有两个不同的年龄，我们总能进步。 

假设有一个鬼魂，其年龄与其他鬼魂不同。 考虑通过反复与当前与邻居不同的鬼魂战斗来穿过队伍。 每场战斗中年长的鬼魂都会存活下来并增加其年龄。 一旦一个幽灵的年龄严格大于另一个幽灵，它就可以继续击败年轻的邻居。 在更强的幽灵到达之前，可以忽略相同的年龄，因为更强的幽灵将进行有效的战斗。 最终，一个幽灵可以吸收所有其他幽灵。 

整个问题归结为检查所有年龄是否相同，特殊情况是一个鬼已经满足了目标。

 ## 算法演练

 1. 阅读所有幽灵时代。 如果只有一个幽灵，则输出 YES，因为不需要匹配。 
2. 将每个年龄与第一个鬼的年龄进行比较。 如果所有年龄都相等，则输出 NO，因为相邻的一对不可能有不同的年龄。 
3. 如果至少有一个年龄与第一个年龄不同，则输出 YES，因为两个不同年龄的存在保证可以安排进程留下一个幸存者。 

这样做的原因是战斗的确切顺序对于决定并不重要。 非均匀数组始终包含创建幽灵所需的起点，该幽灵在每次成功战斗后都会变老。 成长只会有助于未来的战斗，因为幸存的鬼魂永远不会变得更年轻。 

为什么它有效：

 如果所有鬼魂的年龄相同，并且鬼魂不止一个，则每次相邻的比较都会失败，因此不存在任何移动。 

不然的话，就是两个年龄不同的鬼魂了。 如果年长的人变得相邻，则可以击败年幼的人，并且在获胜后会增加其年龄。 年龄的增长永远不会使未来的战斗变得更加困难，因为年龄越大只会产生更多可能的对手。 重复这个想法可以让一个幽灵在所有比赛中生存下来。 因此，唯一不可能的情况就是存在多个年龄相同的鬼魂。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    ages = [int(input()) for _ in range(n)]

    if n == 1:
        print("YES")
        return

    first = ages[0]
    for age in ages[1:]:
        if age != first:
            print("YES")
            return

    print("NO")

if __name__ == "__main__":
    solve()
```该解决方案仅存储年龄，因为输入每行给出一个值，最简单的实现是将它们读入数组。 实际算法只需要第一个年龄以及是否存在不同的年龄，因此可以通过恒定的额外内存来实现相同的想法。 

这`n == 1`检查出现在相等检查之前，因为任何年龄的单个幽灵都已经是有效的最终状态。 对于更大的输入，找到一个不同的年龄就足以证明存在一系列战斗。 

不存在涉及大值的算术运算，因此 Python 中不存在整数溢出问题。 该实现还避免了模拟战斗，这是不必要的复杂性的主要来源。

 ## 边缘情况

 对于单个幽灵的情况：```
Input
1
7
```算法检查`n == 1`立即并返回 YES。 不需要战斗，因为目标已经满足。 

对于全平等的情况：```
Input
4
5
5
5
5
```扫描将每个值与第一个年龄进行比较。 由于每次比较都相等，因此算法返回“否”。 这与该过程相匹配，因为没有相邻对具有不同的年龄，因此 Boo 甚至无法执行一项操作。 

对于不同年龄组的情况：```
Input
5
4
4
3
4
4
```扫描发现第三个鬼魂的年龄为3，而第一个鬼魂的年龄为4。这证明线路没有冻结。 年长的鬼魂最终可以利用年轻的鬼魂来增加其年龄并继续赢得战斗，所以答案是肯定的。 

对于不同年龄的情况：```
Input
3
10
10
20
```该算法发现最后一个值与第一个值不同并返回 YES。 最后的幽灵不需要在所有其他幽灵旁边开始。 任何差异的存在就足够了，因为可以安排战斗来让成长中的幸存者通过前线。
