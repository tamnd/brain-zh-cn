 ## 解决方案
 ## 问题理解

 我们有一群朋友，人数从 1 到 6 人。一张长凳正好有六个座位，每个小组必须占据一个长凳。 不同团体可以共用一个长凳，但总人数不超过六人。 

对于每个测试用例，六个输入数字给出大小为 1、2、3、4、5 和 6 的组的数量。任务是最小化工作台的数量。 

阳性总数为阳性，一个测试病例最多为 10,000 人。 最多有 1,000 个测试用例。 由于每个组至少有一个人，因此一个测试用例中最多也有 10,000 个组。 这对于对所有组进行线性扫描来说足够小，但问题的结构让我们做得更好：只需使用恒定数量的算术运算即可计算出最佳解决方案。 对可能的分组进行二次或指数搜索是完全没有必要的。 

主要的边缘情况来自几乎占据了一张长凳的组。 例如，与```
1
1 0 0 0 0 0
```答案是1，因为单组需要一张板凳。 

和```
1
0 0 0 1 1 0
```答案也是1，因为四人一组和两人一组正好占满一个长凳。 仅基于总人数的粗心解决方案仍然可以正确处理这种情况，但独立处理每个团体规模的解决方案可以使用两个长凳。 

另一个边界情况是```
1
0 0 1 0 0 1
```需要2张长凳。 六人一组不能与任何人共用一个长凳，而三人一组则需要另一个长凳。 

相反的错误发生在小团体中。 为了```
1
8 0 0 0 0 0
```一个人有八组，所以答案是 2，而不是 8。六组可以共用一张长凳，其余两组共用另一张长凳。 

## 方法

 直接的暴力解决方案会将每个组视为一个项目，并递归地尝试每个可能的工作台分配。 当处理一组时，我们可以将其放入任何兼容的现有工作台中或打开一个新的工作台。 这是正确的，因为每种可能的座位安排都由搜索的某个分支表示。 

问题在于安排的数量。 如果有（n）个组，将它们分配给任意组的长凳与枚举组分区有关，其计数为贝尔数（B_n）。 对于多达 10,000 个组，即使是更小的上限，例如 (n^n = 10000^{10000}) 也已经没有希望了。 对于给定的限制，蛮力方法不仅太慢，而且即使对于相对较小的输入也是不可行的。 

使问题变得容易的结构是六人的固定板凳容量。 大团体几乎没有可能的合作伙伴。 六人一组根本没有伙伴。 五人一组只能与一人一组配对。 四人一组可以使用两人一组，或者两人一组。 三人一组可以与另外三人配对，或者使用较小的小组来填补剩余的座位。 最后，两人一组的每张长凳上最多可容纳三个人，一人一组则可以填满剩余的座位。 

这给出了贪婪策略。 首先处理较大的群体，始终使用最大的有用补充群体。 一旦放置了较大的组，剩下的问题仅由大小为 2 和 1 的组组成，其中最佳包装是立即的。 

关键不是简单地“把大群体放在第一位”。 每个贪婪的选择都可以通过以下事实来证明：较大的组比较小的组具有更少的可能放置位置。 五人小组不能使用二人或三人小组，因此花一个人的小组永远不会比把那个人留给有其他选择的小组更糟糕。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(B_n)) | (O(n)) | (O(n)) | 太慢了 |
 | 最优贪心 | 每个测试用例 (O(1)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 读取大小为 1 到 6 的组的计数。令它们为 (c_1,c_2,\ldots,c_6)。 
2. 将每组 6 号儿童放在各自的长凳上。 这样的一组没有剩余容量可供另一组使用，因此这些板凳是被迫的。 
3. 处理人数为 5 的团体。每个此类团体需要 5 个座位​​，并且只能与人数为 1 的一组共享。将尽可能多的 5 组与 1 组配对，并将剩余的 1 组放在一边。 
4. 处理尺寸为 4 的组。首先将它们与尺寸为 2 的组配对。(4+2) 组合正好填满一张长凳。 如果在所有有用的 2 组都用完后还有更多 4 组，则最多可将两个 1 组与每个剩余的 4 组一起放置。 

即使有两个 1 组也可用，将 4 与 2 配对也是安全的。 无论哪种情况，4 组都已经需要一个长凳，并且替代安排不会减少其他组所需的长凳数量。 
5. 将大小为 3 的组相互配对。 每对 3 组正好填满一个长凳，因此 (\lfloor c_3/2\rfloor) 长凳是强制的。 
6. 如果剩下 1 个 3 组，则再为其腾出一个替补席。 如果有 2 组可用，请将其与 3 组放在一起。 如果还有一个 1 组，它可以加入同一个替补席，产生 (3+2+1=6)。 如果没有 2 组，则用最多 3 个 1 组填补剩余席位。

将剩余的 2 组与不匹配的 3 组一起使用永远不会增加答案。 删除一组 2 组会将所有剩余 2 组所需的长凳数量从 (\lceil b/3\rceil) 更改为 (\lceil(b-1)/3\rceil)，只能保持不变或减少。 
7. 剩下的组现在有 1 号和 2 号。这 2 组每条凳子坐 3 人。 如果 (b) 剩下 2 组，则需要 (\lceil b/3\rceil) 个长凳。 这些长凳有 (6\lceil b/3\rceil-2b) 个未使用的座位，因此请用尽可能多的 1 组来填充这些座位。 
8. 剩下的 1 组需要每 6 组 1 个长凳，向上取整。 将此数字添加到答案中并打印。 

### 为什么它有效

 不变的是，在从最大到最小处理组大小之后，每个已处理组的放置方式不能增加未处理组所需的最小工作台数量。 

6 号组别无选择。 大小为 5 的组只能使用大小为 1 的组，因此只要存在 1 组，就会强制配对。 4 号组可以使用 2 组或两个 1 组，并且首先使用 2 组之后不会花费额外的长凳。 大小为 3 的组彼此最佳配对，最多剩余 1 个不匹配的 3 组。 之后，只剩下尺寸 2 和 1，并且一张长凳上最多可以容纳 3 个 2 组，因此 (\lceil c_2/3\rceil) 个长凳是必要的。 用一组来填补未使用的座位不会有什么坏处，因为否则这些座位就会空着。 剩下的 1 组正好需要 (\lceil c_1/6\rceil) 个长凳。 

因此，每个决定要么是被迫的，要么是用不再使用长凳的另一种包装替换可能的包装。 因此最终的计数是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(c):
    c1, c2, c3, c4, c5, c6 = c

    ans = c6

    # Groups of 5 can only share with groups of 1.
    use = min(c1, c5)
    c1 -= use
    ans += c5

    # Groups of 4 should use groups of 2 first.
    use = min(c2, c4)
    c2 -= use
    remaining4 = c4 - use
    ans += c4

    # Remaining groups of 4 can take two groups of 1 each.
    use = min(c1, 2 * remaining4)
    c1 -= use

    # Pair groups of 3.
    ans += c3 // 2

    # One group of 3 may remain.
    if c3 % 2:
        ans += 1

        if c2 > 0:
            c2 -= 1
            if c1 > 0:
                c1 -= 1
        else:
            c1 -= min(c1, 3)

    # Pack groups of 2, three per bench.
    benches2 = (c2 + 2) // 3
    ans += benches2

    # Use the unused seats on those benches for groups of 1.
    free = 6 * benches2 - 2 * c2
    c1 = max(0, c1 - free)

    # Remaining groups of 1, six per bench.
    ans += (c1 + 5) // 6

    return ans

def main():
    t = int(input())
    out = []

    for _ in range(t):
        c = list(map(int, input().split()))
        out.append(str(solve_case(c)))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```里面的前三行`solve_case`解开六组计数。 答案从所有 6 号组开始，因为每个组都占用一整条板凳。 

对于尺寸 5，`min(c1, c5)`准确给出有多少个 5 组可以接收 1 组。 剩余的 1 组被保存为较小的组。 

对于大小 4，代码首先删除尽可能多的 2 组。`remaining4`是无法获得 2 组的 4 组的数量，因此每个组都有两个 1 组的空间。 表达式`2 * remaining4`是可用座位的总数。 

size-3 处理使用整数除法来配对 3 组。 这`% 2`分支处理单个可能的不匹配组。 该代码更喜欢剩余的 2 组，因为 3 组加上 2 组使用的容量本来会更难放置。 如果还有 1 组可用，那么板凳就完全满了。 

对于其余 2 组，`(c2 + 2) // 3`是 (\lceil c_2/3\rceil) 的整数形式。 这些长椅上的空闲座位数直接计算为`6 * benches2 - 2 * c2`。 然后将剩余的 1 组分成每组 6 人。 

所有值都是非负数，Python 整数不会溢出。 使用`min`和`max`还可以防止剩余计数变为负值。

 ## 边缘情况

 对于单个一组，输入是`1 0 0 0 0 0`。 该算法跳过所有较大的组，达到最终的 size-1 计算，并计算`(1 + 5) // 6 = 1`。 结果就是一张长凳。 

对于六人一组，输入是`0 0 0 0 0 1`。 最初的`ans = c6`立即贡献一张板凳。 没有其他操作可以与该组组合任何内容，因为它的容量已经满了。 

对于精确配合的情况`0 1 0 1 0 0`，大小为 4 的组消耗大小为 2 的组。 该算法为 4 组添加 1 个工作台，并删除 2 组，产生正确答案 1。 

对于不匹配的三人组、两人一组和一人一组，输入`1 1 1 0 0 0`由 size-3 分支处理。 剩下的 3 组消耗了 2 组和 1 组，形成一张完全坐满的长凳，有 6 个座位。 

对于多组一组，输入`10000 0 0 0 0 0`只达到最后阶段。 每个长凳上可容纳六组，因此答案为 (\lceil10000/6\rceil=1667)。 上限实现为`(c1 + 5) // 6`，避免浮点运算。 

最微妙的情况是当 3 组剩余但不存在 1 组时。 例如，`0 1 1 0 0 0`给出 1 个 3 组和一个 2 组。 该算法将它们放在一起，留下一个未使用的座位。 这仍然是最优的，因为将它们分开需要两个长凳，而在现有的 3 组上使用 2 组不能增加剩余 2 组所需的长凳数量。
