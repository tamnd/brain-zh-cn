 ## 解决方案
 ## 问题理解

 给定一个二进制字符串，我们可以从中删除任意数量的字符，可能必须保留除至少一个字符之外的所有字符。 删除后，我们希望剩余的子序列满足基于子序列本身而不是原始字符串内部位置的奇偶校验条件。 

更准确地说，如果我们从 1 开始对保留的字符串进行索引，我们会查看放置在奇数位置的所有字符以及放置在偶数位置的所有字符。 要求是数量`1`出现在奇数位置的字符必须等于`1`字符出现在偶数位置。 我们不需要最大化长度或显式构造任何东西，只需决定是否存在至少一个有效的非空子序列。 

这些约束允许最多 100,000 个测试用例，总组合字符串长度为 200,000。 这立即排除了任何尝试枚举子序列甚至尝试独立模拟每个测试用例的所有删除的方法。 任何超出每个测试用例的线性时间的时间都会太慢，甚至每个测试用例的线性时间也必须仔细处理。 

当考虑贪婪选择时，会出现一个微妙的问题。 人们很容易认为我们必须保留相对结构或平价取决于原始指数。 这是不正确的，因为删除后位置会重新编号。 另一个常见的错误是假设我们需要原始字符串的奇数和偶数索引中的个数相等，但这也不能反映问题。 

最小的边缘情况是单个字符串。 如果是的话`1`，我们可以取它，并且位置只是奇数位置 1，因此奇数为 1，偶数为 0，这不满足条件。 如果是的话`0`，我们也可以取，并且两个计数都为零，所以它是有效的。 这已经表明 0 是无害的，而 1 是唯一有意义的贡献者。 

## 方法

 蛮力的想法是尝试每个子序列并检查它是否满足条件。 对于每个子序列，我们将模拟其构造并计算奇数和偶数位置的子序列。 由于子序列的数量呈指数级增长，这种方法就像$O(2^n)$每个测试用例，即使对于小字符串也是完全不可行的。 

为了简化，我们应该关注真正重要的事情。 该条件仅取决于如何在某些选定子序列中的交替奇偶位置上分布。 零根本不会对条件产生任何影响，它们只是通过填充位置并允许在奇数和偶数槽之间移动来提供帮助。 

关键的观察是我们不需要使用所有字符。 我们只需要知道是否存在至少一种有效的构造。 如果我们能够选择两个，我们总是可以将它们放在子序列中的位置 1 和 2 处，使一个位于奇数位置，一个位于偶数位置，这满足了相等性。 如果我们只选择一个，它总是会处于奇怪的位置并破坏条件。 如果我们不选择任何一个，则子序列必须完全由零组成，这总是满足条件，因为奇数和偶数位置都包含零。 

因此，问题简化为检查字符串是否至少包含两个或根本不包含。 

如果 1 的个数恰好为 1，则答案是不可能的。 如果为零或至少为二，则有可能。

 | 最佳 |$O(n)$总计 |$O(1)$额外 | 已接受 |

 ## 算法演练

 我们独立处理每个测试用例。 

1. 统计字符个数等于`1`在字符串中。 这已经足够了，因为零永远不会影响约束，只有 1 的位置很重要。 
2. 如果个数正好为1，则立即输出`NO`。 对于单个序列，任何包含它的子序列都会将其放置在该子序列的位置 1 或某个奇数位置，并且没有第二个序列可以在偶数位置上平衡它。 
3.否则，输出`YES`。 如果有零个，我们可以保留任何一个零，并且奇数和偶数个数都为零。 如果至少有两个，我们总是可以选择其中两个并将它们排列在子序列中的交替位置，这样一个位于奇数位置，一个位于偶数位置，满足相等性。 

### 为什么它有效

 子序列结构仅通过删除后分配的奇偶校验位置起作用。 零始终可以用作灵活的分隔符，这意味着任何两个选定的零都可以按某些子序列顺序放置到不同的奇偶校验类别中。 唯一的障碍发生在恰好有一个 1 的情况下，因为奇偶平衡需要奇数和偶数位置上的 1 成对贡献，而单个元素不能对两边都有贡献。 所有其他情况要么没有，要么至少有两个，这两者都承认有效的构造。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        s = input().strip()
        ones = s.count('1')
        if ones == 1:
            print("NO")
        else:
            print("YES")

if __name__ == "__main__":
    solve()
```该实现直接对每个测试用例进行计数。 该逻辑完全包含在单个条件中，这避免了显式模拟子序列或跟踪奇偶校验的需要。 关键细节是我们不尝试推理原始字符串中的位置，因为删除完全重新定义了索引。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        s = input().strip()
        ones = s.count('1')
        out.append("NO" if ones == 1 else "YES")
    return "\n".join(out) + "\n"

 ## 边缘情况

 单字符大小写是最敏感的。 用于输入`0`，算法计算零并立即输出`YES`，对应于将整个字符串作为有效子序列。 

用于输入`1`，计数恰好为 1，因此算法输出`NO`。 任何保留此字符的尝试都会将其保留在子序列的位置 1 中，从而产生一个奇数位置 1 和零个偶数位置 1，从而违反了条件。 

另一种边缘情况是所有字符均为零时，例如`000000`。 1 的计数为零，因此算法输出`YES`。 我们可以取任何单个零，并且由于任一奇偶校验类中都没有零，因此满足条件。 

最后，考虑具有多个 1 但以零分隔的字符串，例如`10001`。 个数为 2，因此算法输出`YES`。 我们可以删除零并保留两个一，产生一个子序列`11`，自动平衡奇数和偶数位置。
