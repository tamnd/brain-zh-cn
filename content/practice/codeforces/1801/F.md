 ## 解决方案
 ## 问题理解

 我们有一块 n 维的巧克力棒。 沿着每个维度，条形已被划分为离散单元：对于维度 i，有`a_i`单位。 Vasya 希望沿着这些预先存在的部门进一步切割巧克力，以生产至少`k`件。 他可以选择多少段`b_i`沿着每个维度切割，`1 <= b_i <= a_i`。 切割后，每个所得的块都有许多由地板分割的乘积给出的原始切片`floor(a_1 / b_1) * ... * floor(a_n / b_n)`。 每片都有体积`1 / (a_1 * ... * a_n)`，因此一块的体积是该产品除以切片总数。 Vasya 想要最大化最小块的体积乘以`k`。 

输入给出维度`n`（最多100件），所需的最小件数`k`（最多 10^7），以及数组`a`尺寸的`n`（每个最多 10^7）。 输出是一个浮点数 - 最小件次的最大可能体积`k`。 

约束条件告诉我们`n`中等但是`a_i`和`k`可以非常大。 这排除了尝试各种可能组合的天真的暴力方法`b_i`，因为组合总数是`a_1 * a_2 * ... * a_n`，这可能是一个天文数字。 我们还需要小心处理整数溢出，因为`a_i`可以超过 10^18。 

边缘情况包括无法获得的情况`k`件，例如`n=1, a=[5], k=6`。 在这里，任意选择`b_1`最多生产 5 件，因此正确答案为 0。另一个微妙之处是，最大化体积可能更喜欢沿某些尺寸进行更少的切割，因为地板划分会失去价值。 例如，与`a=[4,7]`和`k=7`，与沿较大维度集中切割相比，均匀分布切割给出不同的最小体积。 

## 方法

 蛮力方法在概念上很简单：尝试所有组合`b_1`通过`b_n`满足`1 <= b_i <= a_i`, 计算`floor(a_1 / b_1) * ... * floor(a_n / b_n)`，并选择至少产生的组合`k`分割并最大化`k * volume`。 这适用于非常小的`a_i`和`n`，但与`n=100`和`a_i=10^7`，组合的数量大得不可思议。 甚至生成所有`b_i`对于像 10^7 这样大的单一维度来说太昂贵了。 

关键的观察是我们实际上正在寻找最大可能的值`x`这样我们就可以将巧克力切成小块，其中一块的最小切片数至少为`x`。 该问题可以重新定义为搜索：寻找候选人`x`，我们能找到整数吗`b_i`这样`floor(a_1 / b_1) * ... * floor(a_n / b_n) >= x`和`b_1 * ... * b_n >= k`？ 因为体积随`floor(a_i / b_i)`，我们可以使用二分查找`x`。 

对于每个`x`，计算最大值`b_i`这确保了`floor(a_i / b_i) >= t`很简单：`b_i <= a_i // t`。 然后，我们需要检查这些产品是否`b_i`界限至少可以达到`k`。 这将问题简化为“中间相遇”或贪婪方法：乘以最大的可行方法`b_i`对于每个维度，直到我们达到`k`或排气选项。 

我们的见解是，问题沿维度分离，并且可以使用整数除法来反转下限函数。 一旦我们设置了候选最小工件尺寸`x`，每个维度独立贡献最大段数`b_i`。 然后就是检查他们的产品是否符合`k`。 二分搜索使我们能够收敛到最大可能的值`x`高效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(产品(a_i)) | O(n) | 太慢了 |
 | 二分搜索 + 维度界限 | O(n log(max(a_i))) | O(n log(max(a_i))) | O(n) | 已接受 |

 ## 算法演练

 1.计算切片总数`total = a_1 * ... * a_n`。 如果`total < k`，立即输出0，因为不可能有`k`件。 
2. 设置最小片数的二分查找范围`x`。 下限为 0，上限为`max(a_i)`，因为最小片段在一个维度上不能包含比`a_i`。 
3. 当二分查找范围不为空时，取`mid = (low + high + 1) // 2`。 这`mid`表示最小片段的候选最小切片计数。 
4. 对于每个维度`i`, 计算`max_bi = a_i // mid`。 这是我们可以沿尺寸进行的最大切割次数`i`不违反候选人的最低件数。 如果`max_bi == 0`, 候选人`mid`太大； 我们无法沿着这个维度得到哪怕一片切片。 
5. 计算乘积`prod_b`的`max_bi`覆盖所有维度。 如果产品在任何时候超过`k`，我们可以提前停下来，因为我们只关心是否能够到达`k`。 
6. 如果`prod_b >= k`, 候选人`mid`是可行的，所以我们设`low = mid`。 否则，设置`high = mid - 1`。 
7. 二分查找完成后，`low`包含每件可实现的最大最小切片数。 将最终体积计算为`volume = (low / a_1) * ... * (low / a_n) * k`，这简化为`volume = low * k / total_slices`。 
8. 以足够的精度输出音量。 

为什么它有效：二分搜索保持了任何不变式`x <= low`是可以实现的并且任何`x > high`不是。 通过独立检查可行性`b_i`边界是正确的，因为楼层划分确保如果我们尊重`b_i <= a_i // x`，没有一块会少于`x`沿该维度切片。 乘以界限确保我们至少达到`k`件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    total_slices = 1
    for ai in a:
        total_slices *= ai
        if total_slices >= 1e18:  # cap to prevent overflow
            break
    if total_slices < k:
        print(0)
        return

    low, high = 0, max(a)
    while low < high:
        mid = (low + high + 1) // 2
        prod = 1
        for ai in a:
            prod *= ai // mid
            if prod >= k:
                break
        if prod >= k:
            low = mid
        else:
            high = mid - 1

    minimal_slices = low
    volume = minimal_slices * k / total_slices
    print(f"{volume:.12f}")

if __name__ == "__main__":
    main()
```该解决方案首先检查是否`k`甚至可以用切片总数来表示。 二分搜索确保我们最大化最小部分。 乘法`ai // mid`对于每个维度，保证满足楼层划分约束，并且提前停止可以防止溢出。 最后，计算`minimal_slices * k / total_slices`给出缩放后的体积`k`。
