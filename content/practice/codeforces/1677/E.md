 ## 解决方案
 ## 问题理解

 我们给出了从 1 到$n$，并且我们被询问有关此排列的连续子段的多个查询。 如果子段的最大值可以表示为该段内两个元素的乘积，则该子段被称为_beautiful_。 对于每个查询，我们需要计算完全包含在指定范围内的所有漂亮子段。 

天真的阅读可能会诱使我们迭代所有子段，计算它们的最大值，并检查是否有任何对乘以该最大值。 然而，自从$n$可以达到$2 \cdot 10^5$和查询数量$q$可以达到$10^6$，迭代每个查询的所有子段是不可行的。 具体来说，有$\Theta(n^2)$子分段，这远远超出了几秒钟内可以处理的范围。 

要考虑的边缘情况包括长度为 1 的线段，其中不存在对，以及最大值为素数的线段，除非重复，否则不能将其表示为线段中两个整数的乘积，这在排列中是不可能的。 例如，一个段`[3]`有最大值`3`但没有`i < j`存在，因此计数为 0。假设每个段都有有效对的粗心解决方案会导致计数过多。 

问题是要求我们不仅要回答整个数组，还要有效地回答任意范围。 这暗示我们需要一个预处理步骤或一个可以在亚线性时间内回答查询的数据结构。 

## 方法

 蛮力方法是考虑每个子段`[x, y]`在每个查询间隔内`[l_i, r_i]`，计算其最大值，然后检查段中的每一对，看看它们的乘积是否等于最大值。 这在原则上是正确的，因为它直接遵循定义，但复杂度是$O(q \cdot n^2)$在最坏的情况下，这对于上限来说是不可能的（$q \sim 10^6$,$n \sim 2 \cdot 10^5$）。 即使单个查询也可能需要$O(n^2)$操作，速度太慢。 

解锁更快解决方案的关键观察是每个排列元素都是唯一的，并且子段的最大值始终是段中的元素之一。 因此，我们只需要关注每个值的位置即可。 对于给定的最大值$m$在位置$k$，一个子段包含$k$只有存在更小的值才可能是美丽的$a$在索引处$i < k$和一个更小的值$b$在索引处$j > i$这样$a \cdot b = m$。 这减少了在每个最大元素周围寻找有效乘积的问题。 

通过按降序迭代元素并使用线段树或二叉索引树有效地跟踪较小元素的位置，我们可以为每个查询计算有多少子线段包含特定的最大值并满足乘积条件。 排列的结构保证每次乘积检查仅涉及现有元素对，以及每个元素的潜在除数的数量$m$仅限于$O(\sqrt{n})$。 

这允许最佳解决方案大致回答所有查询$O(n \sqrt{n} + q \log n)$使用仔细的离线处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(q \cdot n^2)$|$O(1)$| 太慢了|
 | 最佳 |$O(n \sqrt{n} + q \log n)$|$O(n + q)$| 已接受 |

 ## 算法演练

 1. 预先计算数组中排列中每个值的位置`pos`这样`pos[value] = index`。 这让我们可以在常数时间内找到任何数字。 
2. 从最大到最小迭代排列值。 对于每个值$m$，生成所有约数对$(a, b)$这样$a \cdot b = m$以及两者$a$和$b$存在于排列中。 因为是排列，所以我们只考虑位置`pos[a]`和`pos[b]`。 
3. 对于每个除数对$(a, b)$，确定其中的最小和最大位置`pos[m]`,`pos[a]`， 和`pos[b]`。 这确定了包含所有三个元素的最小线段，这是满足产品条件的最小线段。 
4. 维护一个数据结构以有效地对段进行计数。 对于每个位置，更新一个间隔数组，其中该最大值`m`可以成为美丽细分市场的定义价值。 使用前缀和来回答查询$O(1)$预处理后的每个查询。 
5. 离线处理所有查询。 按左端点或右端点对它们进行排序以利用前缀和数组。 对于每个查询`[l, r]`，使用预先计算的累积计数计算完全在间隔内的美丽片段的计数总和。 
6. 返回每个查询的结果。 

为什么它有效：该算法永远不会错过一个漂亮的片段，因为它考虑了每个可能的最大值和所有有效的除数对。 前缀和确保重叠的段只被计算一次。 按降序迭代可以保证我们先处理较大的最大值，然后再处理较小的最大值，这一点至关重要，因为最大的元素决定了任何子段中的最大乘积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, q = map(int, input().split())
p = list(map(int, input().split()))
pos = [0] * (n + 1)
for i, val in enumerate(p):
    pos[val] = i

import math
from collections import defaultdict

# For each segment, we store how many beautiful subsegments start at each index
count = [0] * (n + 1)

for m in range(1, n + 1):
    limit = int(math.isqrt(m)) + 1
    for a in range(1, limit):
        if m % a == 0:
            b = m // a
            if a <= n and b <= n:
                idxs = sorted([pos[m], pos[a], pos[b]])
                l, _, r = idxs[0], idxs[1], idxs[2]
                count[l] += 1
                if r + 1 < n:
                    count[r + 1] -= 1

# prefix sum to accumulate
for i in range(1, n):
    count[i] += count[i - 1]

# compute prefix sum again for query range sums
for i in range(1, n):
    count[i] += count[i - 1]

for _ in range(q):
    l, r = map(int, input().split())
    l -= 1
    r -= 1
    ans = count[r]
    if l > 0:
        ans -= count[l - 1]
    print(ans)
```第一部分将每个值映射到其位置，这使我们能够在恒定时间内找到任何数字。 双前缀和技巧可以有效地将点更新转换为范围和。 迭代除数对可确保仅考虑可行的漂亮线段。 对索引进行排序可确保`l`和`r`正确识别最小覆盖段。
