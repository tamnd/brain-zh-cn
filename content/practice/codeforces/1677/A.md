 ## 解决方案
 ## 问题理解

 我们得到一个从 1 到 n 的整数排列，并要求计算有多少个索引的四元组`[a, b, c, d]`满足两个不等式：第一个元素小于第三个（`p_a < p_c`) 并且第二个元素大于第四个 (`p_b > p_d`）。 指数必须严格增加，这意味着`a < b < c < d`。 输入包含多个测试用例，每个测试用例都有一个排列，我们需要输出每个测试用例的四元数。 

约束条件允许`n`每个测试用例最多 5000 个，总和`n`跨以 5000 为界的所有测试用例。这意味着直接检查所有四元组的 O(n^4) 暴力方法太慢，因为在最坏的情况下可能会导致超过 6×10^13 次操作。 如果仔细实施，O(n^3) 方法几乎不适合，但 O(n^2) 或 O(n^2 log n) 解决方案是理想的。 

当排列严格递增或严格递减时，会出现微妙的边缘情况。 例如，`p = [1,2,3,4]`没有满足的四元组`p_a < p_c`和`p_b > p_d`同时，因此正确的输出为 0。假设某种随机分布的简单算法可能会错误地对元组进行计数。 另一种边缘情况是当四元组依赖于边界处的最小和最大元素时，例如`p = [5,3,6,1,4,2]`，其中只有特定位置满足两个不等式。 该算法必须正确跟踪整个数组的计数，而不是在本地比较值。 

## 方法

 蛮力方法很简单：迭代所有四元组`(a, b, c, d)`有四个嵌套循环，直接检查不等式。 这是正确的，因为它会评估每个组合，但复杂度为 O(n^4)，这对于`n=5000`。 

为了优化，请注意不等式`p_a < p_c`和`p_b > p_d`可以分解为两个独立的计数问题：对于每一对`(b, c)`和`b < c`，我们想要的数量`a`前`b`这样`p_a < p_c`和数量`d`后`c`这样`p_b > p_d`。 一旦知道这些计数，四元组的数量包括`(b, c)`是这些计数的乘积。 这将复杂性从四个嵌套循环减少到三个，因为我们可以迭代`(b, c)`并计算有效的`a`和`d`高效。 

计数有效`a`对于给定的`c`，我们可以维护一个前缀数组来跟踪小于的元素数量`p_c`直到每个位置。 同样，计算有效`d`对于给定的`b`，我们可以为小于的元素维护一个后缀数组`p_b`从每个位置到最后。 这将内部循环减少为简单的前缀/后缀查找，从而给出 O(n^3) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^4) | O(n^4) | O(1) | O(1) | 太慢了|
 | 前缀/后缀计数 | O(n^3) | O(n^3) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，阅读排列`p`长度`n`。 
2. 初始化计数器`ans = 0`为有效四元组的数量。 
3. 迭代`b`从索引 1 到`n-2`。`b`将是四元组中的第二个元素。 
4. 对于每个`b`, 迭代`c`从`b+1`到`n-1`。`c`是第三个元素。 
5. 数一下数量`a`这样`a < b`和`p_a < p_c`。 这可以通过索引的简单循环来完成`0..b-1`。 
6. 数一下数量`d`这样`d > c`和`p_b > p_d`。 循环索引`c+1..n-1`。 
7. 将这两个计数相乘并将结果添加到`ans`。 每个有效组合`a`和`d`与固定的`(b, c)`形成一个有效的四元组。 
8. 迭代完所有之后`(b, c)`成对、打印`ans`对于测试用例。 

为什么有效：对于中间对的每个选择`(b, c)`, 任何有效的`a`和`d`完成满足不等式的四元组。 通过迭代所有`(b, c)`配对并计数有效`a`和`d`，我们将所有四元组恰好枚举一次，而无需重复计算。 不变量`a < b < c < d`前缀/后缀计数确保正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        ans = 0
        for b in range(1, n-2+1):
            for c in range(b+1, n-1+1):
                count_a = 0
                for a in range(b):
                    if p[a] < p[c]:
                        count_a += 1
                count_d = 0
                for d in range(c+1, n):
                    if p[b] > p[d]:
                        count_d += 1
                ans += count_a * count_d
        print(ans)

if __name__ == "__main__":
    solve()
```外层循环固定中间索引`(b, c)`。 两个内循环计数有效`a`和`d`对于这些固定指数。 这明确地实现了组合观察，即每个选择`a`和`d`贡献四倍。 使用`range`边界仔细确保`a < b`和`d > c`抓住。 由于 Python 列表是零索引的，因此可以自然地处理从一开始的索引和从零开始的索引之间的转换。
