 ## 解决方案
 ## 问题理解

 我们被要求模拟动态的座位场景。 有一个大厅有`n`行和`m`列，学生们一一到来，一个个或严肃或调皮。 第一个学生总是坐在第一排的第一列，每个新来的学生都会按行优先顺序推动现有的学生：在一行内，学生向右移动，一行的最后一个座位换到下一行的第一个座位。 每个学生就座后，我们都会被要求计算有多少行和多少列包含至少一名认真的学生。 每个测试用例的输出是每个学生进入后这些累积计数的列表。 

这些限制需要仔细考虑。 每个测试用例的座位数最多可达`10^6`，并且所有测试用例的总和不超过`10^6`。 这排除了幼稚的模拟，即我们维护学生的整个二维网格并在每次到达时轮班条目，因为最坏情况的时间将是二次的，这太慢了。 我们需要一种能够在恒定时间内更新每个学生的计数的方法。 边缘情况包括所有学生都很认真或都很顽皮的情况，或者矩阵只有一行或一列的情况，因为这些会影响行和列更新的传播方式。 

## 方法

 蛮力方法是维护一个代表座位的二维矩阵，将每一行向右移动，并在每次学生到达时将最后一列换到下一行。 每次插入后，我们都会扫描所有行和列，以计算包含至少一名认真学生的行和列。 虽然这会产生正确的答案，但在最坏的情况下，每次插入的成本为 O(n * m)，对于最大大小的单个测试用例来说，成本为 O((n * m)^2)，远远超出了时间限制。 

关键的见解是解耦 2D 网格并仅跟踪所需的最少信息：行或列是否“好”。 每个学生只影响一个座位，这决定了如果学生认真的话，可以成为好的行和列。 因此，我们可以维护两个数组：一个用于好行的累积计数，一个用于好列的累积计数。 为了以行优先顺序处理环绕效果，我们通过以下方式预先计算每个学生的列索引`student_index % m`和行索引`student_index // m`。 对于列，我们不仅需要考虑当前学生，还需要考虑同一列中所有以前的学生； 我们可以为每列认真的学生维护一个前缀总和。 每个新学生只能增加行或列的计数一次，因此可以进行恒定时间更新，从而总体上形成 O(n * m) 算法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((n * m)^2) | O((n * m)^2) | O(n * m) | 太慢了|
 | 最佳 | O(n * m) | O(米) | 已接受 |

 ## 算法演练

 1.初始化两个size的数组`m`：`col_count`跟踪每列有多少认真的学生`col_good`作为一个二进制数组，指示某列是否良好。 初始化集合或数组`row_good`尺寸的`n`跟踪每一行是否包含一个认真的学生。 初始化`good_rows`和`good_cols`计数器归零。 
2. 对于每个学生`i`在字符串中`s`,计算行索引`r = i // m`和列索引`c = i % m`。 这些索引确定哪些行和列受到影响。 
3. 如果学生是认真的（`s[i] == '1'`）和行`r`尚未标记为良好，增量`good_rows`并标记`row_good[r]`是真的。 同样，如果列`c`还没有好，增量`good_cols`并标记`col_good[c]`是真的。 更新`col_count[c]`以反映该栏中新的认真的学生。 
4. 追加`good_rows + good_cols`到输出数组。 这表示当前学生之后的好行和列的总数。 
5. 处理完所有学生后，将输出数组打印为一行。 

为什么有效：每个学生只会影响他们所在的行和列。 通过跟踪哪些行和列已经很好，我们可以避免重复计算并保持以下不变式：`good_rows`和`good_cols`准确反映每一步至少包含一名认真学生的行数和列数。 环绕行为是隐式处理的，因为列索引重复模数`m`和行索引依次增加。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        s = input().strip()
        row_good = [0] * n
        col_good = [0] * m
        good_rows = 0
        good_cols = 0
        col_count = [0] * m
        prefix = [0] * (n * m)
        out = []
        for i in range(n * m):
            r = i // m
            c = i % m
            if s[i] == '1':
                col_count[c] += 1
                if row_good[r] == 0:
                    row_good[r] = 1
                    good_rows += 1
                if col_good[c] == 0:
                    col_good[c] = 1
                    good_cols += 1
            out.append(good_rows + good_cols)
        print(' '.join(map(str, out)))

solve()
```该解决方案维护行和列良好性的数组，并以恒定的时间更新每个学生的计数器。 这`col_count`如果需要跟踪每列多个认真的学生，则数组准备支持潜在的扩展，尽管在这个问题中只有存在才重要。 我们使用整数除法和取模来计算行索引和列索引，以处理展平数组中的 2D 布局。

 ## 边缘情况

 当每列中的第一个学生很认真但其他学生很顽皮时，就会出现一种棘手的边缘情况。 算法正确递增`good_cols`仅当列第一次接收到认真的学生并类似地跟踪行时。 另一种情况是单行或单列，所有学生都位于同一行或同一列。 第一个认真学习的学生将行或列标记为“好”，后续学生不会再次增加计数，从而确保不会重复计算。 即使在这些边缘情况下，模除法和整数除法运算也能自然地处理扁平化的一维到二维映射。
