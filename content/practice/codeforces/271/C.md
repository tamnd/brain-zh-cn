 ## 解决方案
 ## 问题理解

 我们被要求在 _k_ 个 Keeper 之间分配 _n_ 个按顺序编号的单词，以便每个 Keeper 接收一个非空单词子集，这些子集是成对不相交的，它们的并集涵盖所有单词，并且没有子集形成算术级数。 输出应指示每个单词是由 ​​Keeper 保存的，或者`-1`如果不可能的话。 

输入是两个整数_n_和_k_，分别代表单词总数和Keeper数量。 输出是 1 到 _k_ 之间的 _n_ 个整数序列，描述分配，或者`-1`如果不存在有效的分配。 

约束条件很大：_n_ 最多可达$10^6$，因此任何显式检查所有子集或尝试检查所有排列的解决方案都会太慢。 解必须是线性的或至多 O(n log n)。 

当 _n_ 小于 3 或等于 _k_ 时，会出现不明显的边缘情况。 单个守护者获得的单词不能少于三个，因为这样子集将简单地形成算术级数。 如果 _k_ 等于 _n_，则每个 Keeper 只会得到一个单词，这违反了“至少三个元素”的条件。 例如，`n = 3, k = 3`是不可能的，所以输出必须是`-1`。 简单地循环使用 Keepers 的粗心方法会错误地返回不满足算术级数约束的分配。 

## 方法

 暴力解决方案将尝试在 _k_ 个 Keepers 中生成_n_ 个单词的所有可能分区，并检查每个分区的算术级数条件。 这种方法是组合的，大约需要$k^n$操作，这对于 _n_ 来说是不可行的$10^6$。 检查子集是否形成算术级数很简单，但生成所有分区在复杂性上占主导地位。 这种方法适用于小型示例，但在中等大小时立即失败。 

关键的观察是，只有当 Keeper 子集中的所有元素都具有恒定差异时，才会违反算术级数条件。 因此，我们可以通过确保没有固定步长的子集是单调的来避免这种情况。 最简单的方法是以循环、交错的方式将单词分配给 Keeper，确保每个 Keeper 接收到的单词间隔不均匀。 如果我们通过以两个或多个为一组的 Keepers 重复循环来分配单词，则分配给 Keeper 的任何子集都将具有不同长度的间隙，从而打破算术级数模式。 

这导致了一个简单的线性解决方案。 如果 _k = 1_，这是不可能的，因为单个 Keeper 将拥有所有单词，这是一个算术级数。 如果 _k = 2_，则任何大于 2 的单词集都无法满足两个子集的非算术级数条件，因此我们必须小心处理小边缘情况。 对于 _k ≥ 3_，重复分配模式如`[1, 2, 3, 1, 2, 3, ...]`确保大小 ≥ 3 的子集不形成算术级数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k^n) | O(k^n) | O(n) | 太慢了 |
 | 循环赋值| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 检查_k_是否为1，如果是，则输出`-1`因为单个守护者获得所有单词，形成算术级数。 
2. 检查 _n_ 是否小于 3 或者 _k_ 是否大于或等于 _n_。 如果这些条件中的任何一个成立，则输出`-1`。 至少需要三个字，以避免琐碎的算术级数，并且任何 Keeper 都不能留空。 
3. 初始化一个长度为 _n_ 的数组来存储每个字的 Keeper 分配。 
4. 按顺序迭代单词。 以重复的模式将它们分配给守护者`[1, 2, ..., k]`。 到达_k_后绕回。 这确保了分配给每个 Keeper 的字序列不是均匀间隔的，因此不是等差级数。 
5. 将赋值数组输出为整数序列。 至少三个守护者的任何有效重复模式都有效。 

为什么有效：通过在至少三个 Keeper 之间循环分配，没有任何一个 Keeper 会收到具有恒定间距的单词。 成对的不相交和并集属性得到保证，因为每个单词只被分配一次，并且所有单词都被分配。 满足非算术级数，因为每个 Keeper 分配的索引不规则地不同，打破了固定差异条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

if k == 1 or n < 3 or k > n:
    print(-1)
else:
    assignment = []
    for i in range(n):
        # Cycle through 1..k
        assignment.append((i % k) + 1)
    print(' '.join(map(str, assignment)))
```该解决方案首先明确地处理不可能的场景。 模运算确保通过 Keepers 进行重复循环。 使用`(i % k) + 1`保证所有守护者以平衡的方式获得单词，打破算术级数。 用空格连接会产生所需的输出格式。

 当`n = 3`和`k = 3`，每个 Keeper 只收到一个单词。 代码检测到`k > n`和输出`-1`，避免大小为 1 的子集。当`n = 11`和`k = 3`，模循环确保 Keeper 1 在位置 1、4、7、10 处接收单词，这些单词不是算术级数，从而确认算法正确地保持了非均匀间距不变式。
