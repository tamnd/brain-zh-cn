 ## 解决方案
 ## 问题理解

 我们从一组“卡”开始，每张卡都是一对整数$(a, b)$和$a < b$。 从一张初始卡开始$(x, y)$，我们可以重复应用三个转换规则，其行为类似于对该对的操作。 

一次操作将两个数字都加一，因此保留了差异$b - a$。 另一种运算仅在两个数字均为偶数时才适用，并且有效地将它们减半，从而减小了数字对的规模。 第三个操作合并来自两张卡的信息，使我们能够组合$(a, b)$和$(b, c)$进入$(a, c)$，这本质上是可达端点的传递性。 

目标是准确选择一张起始牌$(x, y)$和$1 \le x < y \le m$，并从中使用这些转换生成所有必需的卡片$(1, a_i)$。 只要我们能够获得所有需要的卡片，我们就可以制作额外的卡片。 

所以真正的问题是：有多少个起始间隔$(x, y)$我们最终能否“连接”每个所需的端点$a_i$使用允许的变换回到 1。 

这些限制非常重要。 我们最多有$10^5$所需的值和$m$最多$10^9$。 任何尝试模拟转换或探索状态的解决方案$[1, m]$立即是不可行的。 甚至线性扫描所有可能的起始对$(x, y)$会是$O(m^2)$，这是不可能的。 

一个关键的微妙之处是这些操作永远不会引入任意数字。 它们保留了结构：移动 +1 保留差异，减半减少规模但保持 2 的幂比，合并行为类似于连接。 这强烈暗示了数论结构而不是图搜索。 

一个天真的错误是假设一旦一个值$a_i$从某个区间可达，则包含它的所有区间都是有效的。 这会失败，因为减半操作要求两个端点同时为偶数，因此奇偶校验约束会全局传播，而不是本地传播。 

如果我们忽略所需值之间的排序，则会出现另一种失败情况。 例如，如果$a_i$和$a_j$相差很大的奇数因子，并非每个跨越它们的间隔都是有效的，因为奇偶校验对齐不能仅通过移位来修复。 

## 方法

 如果我们尝试暴力，我们会选择一切可能的方法$(x, y)$并模拟三种操作下的关闭。 即使我们优化每个模拟，可达卡的状态空间也会快速增长，并且有$O(m^2)$可能的开始。 这立即是不可行的，因为$m$取决于$10^9$。 

关键的观察结果是，这些操作在整数区间上定义了一个闭包系统，其中唯一真正重要的不变量是重复除以二和区间覆盖下的结构。 

各值$a_i$可以被认为需要通过一系列减半和移位操作连接到 1。 移动 +1 不会改变可行性； 它只改变绝对位置。 真正的限制是是否所有$a_i$共享兼容的“二元骨干网”。 

如果我们重复划分所有$a_i$2 直到至少有一个是奇数，我们本质上提取了奇数核心结构。 系统减少跟踪这些标准化值的间隔，问题就变成了计算有多少间隔$(x, y)$与覆盖该结构下所有必需的标准化端点一致。 

最终的减少是有效的起始间隔对应于以下选择$x$和$y$这样，在重复应用允许的减少之后，该间隔可以“覆盖”每个奇偶校验层中的最小和最大约束。 这会分解为满足数组转换版本的派生约束集的计数间隔。 

那时，而不是检查所有$(x, y)$，我们确定有效区域$x$和$y$作为线路上间隔的并集，可以使用排序和前缀/后缀约束来计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(m^2)$|$O(1)$| 太慢了 |
 | 最佳 |$O(n \log m)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 通过提取奇数分量来标准化每个所需值，同时跟踪它可以被 2 整除的次数。 

这隔离了偶数减半操作无法改变的不变部分。 
2. 按奇数核心对所有所需值进行分组。 每个组必须独立处理，因为合并操作无法在不违反奇偶校验约束的情况下桥接不同的奇数核心。 

这种分离至关重要，因为转换永远不会任意混合奇偶校验类。 
3. 对于每个组，计算原始值空间中的最小和最大位置。 这些界限定义了任何有效起始段必须覆盖的最小间隔。 
4. 将问题转化为计数区间$(x, y)$这样经过反复归一化后，间隔可以扩大到覆盖每个组所需的范围。 

移位操作确保每个组内只有相对距离重要。 
5. 对于每个可能的右端点$y$，确定最小有效左端点$x$这仍然允许满足所有约束。 这产生了单调结构$y$。 
6. 所有有效的总和$y$，计算有多少个选择$x$每个都存在。 这将问题转换为基于前缀的可行间隔计数。 

### 为什么它有效

 这些操作保留了一个隐藏的不变量：每个可到达的卡对应于一个段，其端点在重复减半的情况下保持一致，直到奇数归一化。 合并操作确保如果每个奇偶校验层中满足相邻约束，则整个链变为连接。 这意味着可行性仅取决于同时覆盖所有所需的标准化范围，并且满足这些范围约束的任何间隔都将通过闭包生成所有所需的卡片。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    # normalize by extracting odd core and exponent of 2
    norm = []
    for x in a:
        t = x
        cnt = 0
        while t % 2 == 0:
            t //= 2
            cnt += 1
        norm.append((t, cnt))

    # group by odd core
    from collections import defaultdict
    groups = defaultdict(list)
    for val, c in norm:
        groups[val].append(c)

    # each group defines constraints on exponent structure
    constraints = []
    for k, arr in groups.items():
        arr.sort()
        constraints.append((arr[0], arr[-1]))

    constraints.sort()

    # merge overlapping constraints
    merged = []
    for l, r in constraints:
        if not merged or merged[-1][1] < l:
            merged.append([l, r])
        else:
            merged[-1][1] = max(merged[-1][1], r)

    # now count valid intervals in exponent space
    ans = 0

    # treat merged segments as forbidden gaps structure
    prev_r = -1
    total_segments = len(merged)

    for i in range(total_segments):
        l, r = merged[i]
        left_bound = prev_r + 1
        right_bound = l

        if right_bound >= left_bound:
            length = right_bound - left_bound
            ans += length * (length + 1) // 2

        prev_r = r

    # tail segment
    if prev_r < m:
        length = m - prev_r
        ans += length * (length + 1) // 2

    print(ans)

if __name__ == "__main__":
    solve()
```代码首先分解每个$a_i$分解为奇数分量和二次幂的指数。 这是至关重要的，因为减半操作是唯一改变幅度结构的操作； 其他一切都保留奇偶校验结构。 

然后，我们按奇数分量对值进行分组。 这与具有不同奇数核心的数字无法通过重复减半和转变为共享结构来协调的事实相匹配。 

对于每个组，我们计算最小和最大指数。 这些定义了指数空间中的约束区间。 重叠间隔被合并，因为它们代表必须同时满足的约束。 

一旦我们有了不相交的约束区间，剩下的问题就变成了计算有效选择$(x, y)$不违反这些禁止的指数区域。 这减少了对合并约束块之间允许间隙中的所有子段进行计数。

 ## 边缘情况

 一个关键的边缘情况是所有数字共享相同的奇数核心但具有递增的 2 次方。 在这种情况下，约束区间变得连续，只留下两个大的无约束区域。 该算法正确地将所有内容合并到单个阻塞段中，仅产生边界间隔。 

当所有的情况发生时，会出现另一种边缘情况$a_i$是相同的。 然后约束区间折叠成指数空间中的单个点。 合并步骤确保它被视为一个完整的块，从而防止无效的内部间隔被计算两次或碎片化。 

第三种边缘情况是当$n = 1$。 这里唯一的约束是单个指数值，答案减少为对避免该单个禁止级别的所有间隔进行计数，这与间隙计数逻辑直接匹配。
