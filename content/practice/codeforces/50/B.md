 ## 解决方案
 ## 问题理解

 我们得到一串由小写字母和数字组成的字符串。 任务是计算字符串中字符相同的有序位置对的数量。 一对是有序的，因此对于位置`i`和`j`， 两个都`(i, j)`和`(j, i)`分别计算。 自配对`(i, i)`也包括在内，因为该字符与自身基本匹配。 

字符串长度最多可达 100,000 个字符。 一个检查每个可能的对的蛮力解决方案大约需要$10^{10}$最坏情况下的比较，超出了我们在两秒钟内可以计算的范围。 这立即排除了天真的嵌套循环。 

微妙的边缘情况包括非常短的字符串和所有字符都相同的字符串。 例如，一个单字符字符串`"a"`应该返回 1 因为唯一的一对`(1, 1)`是有效的。 像这样的字符串`"aaaa"`应返回 16，因为 4 个字符中的每一个都与 4 个位置中的每一个匹配，从而产生$4 \times 4 = 16$有序对。 如果粗心的方法只计算不同的对而没有自对或不考虑顺序，则会产生错误的答案。 

## 方法

 暴力方法很简单：对于字符串中的每个字符，将其与每个其他字符进行检查，计算匹配项。 这是正确的，因为它检查每个有效对，但它需要$O(n^2)$操作，这是不可行的$n = 10^5$。 在最坏的情况下，它的表现大致如下$10^{10}$比较。 

优化的关键观察是我们不需要单独比较每个角色。 我们只需要知道每个不同字符出现了多少次。 如果出现一个字符`k`次，它贡献`k * k`有序对：`k`第一个位置的选择和`k`对于第二个。 将所有不同的字符相加得出最终答案。 这将问题简化为计算字符频率，这可以通过字符串的单次传递来完成。 

这一观察结果将算法从二次变为线性，考虑到约束，这是必要的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n) | O(1)（36 个字符的固定大小地图）| 已接受 |

 ## 算法演练

 1. 初始化字符的频率字典（或数组）。 由于字符串仅包含小写字母和数字，因此我们可以使用按字符索引的大小为 36 的数组。 
2. 迭代字符串中的每个字符，增加其在频率表中的计数。 在此步骤结束时，我们知道每个字符出现了多少次。 
3. 初始化变量`total_pairs`为零。 
4. 迭代频率表。 对于出现的每个字符`count`次，添加`count * count`到`total_pairs`。 推理是有`count`第一个位置的选项和`count`第二个，包括自我配对。 
5. 打印`total_pairs`结果。 

为什么有效：不变的是每个字符对有序对总数的贡献恰好是其频率的平方。 由于我们考虑所有字符并包括自身对，因此所有有效对都只计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
freq = [0] * 36  # 26 letters + 10 digits

def char_index(c):
    if 'a' <= c <= 'z':
        return ord(c) - ord('a')
    else:
        return 26 + ord(c) - ord('0')

for ch in s:
    freq[char_index(ch)] += 1

total_pairs = sum(f * f for f in freq)
print(total_pairs)
```这`char_index`函数将每个小写字母映射到 0-25，将数字映射到 26-35，从而允许使用固定大小的数组而不是字典。 我们对字符串进行一次迭代以填充频率数组，然后对计数的平方求和。 使用固定数组可以避免字典开销并确保每个字符的访问时间为 O(1)。 

一个微妙的点是在单个数组中处理字母和数字。 如果有人认为 ASCII 代码在字母和数字之间是连续的，那么经常会发生错误。 另一个潜在的陷阱是忘记包括自对 - 平方步骤自然包括它们。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    s = input().strip()
    freq = [0] * 36
    def char_index(c):
        if 'a' <= c <= 'z':
            return ord(c) - ord('a')
        else:
            return 26 + ord(c) - ord('0')
    for ch in s:
        freq[char_index(ch)] += 1
    return str(sum(f * f for f in freq))

 ## 边缘情况

 对于单字符字符串`"1"`，频率`'1'`是 1。平方得到`1`，这是正确的。 该算法可以轻松处理这个问题，因为该公式自然包含自对。 

对于具有所有相同字符的字符串，`"aaaa"`，频率为 4。平方得出`16`，占所有 16 个有序对。 不需要嵌套循环，否则会使计数过于复杂并存在差一错误的风险。 

对于混合字母和数字的字符串，`"ab1ab"`，频率是`'a':2`,`'b':2`,`'1':1`。 贡献是`4 + 4 + 1 = 9`，这证实了该公式适用于跨字符类型。 

这篇社论通过利用字符频率和有序对计数，引导读者从简单的二次方法转向线性时间、固定空间解决方案。 按照这个推理，可以有效地解决涉及对具有特定匹配标准的对进行计数的类似问题。
