 ## 解决方案
 ## 问题理解

 我们被要求计算以下形式的二次方程的所有不同实根$x^2 + 2bx + c = 0$， 在哪里$b$范围从 1 到$n$和$c$范围从 1 到$m$。 每对$(b, c)$定义一个二次方程。 输出是所有这些二次方程的不同实根的总数。 

重写二次公式，根由下式给出：$$x = -b \pm \sqrt{b^2 - c}.$$所以实根存在当且仅当$b^2 - c \ge 0$，这相当于$c \le b^2$。 因此，对于每个$b$，只有$c$价值观满足$1 \le c \le \min(m, b^2)$产生真正的根。 每个有效对可以给出一个根（当$b^2 = c$）或两个不同的根（当$b^2 > c$）。 

限制条件很大：$n$和$m$最多可达 5,000,000。 迭代所有的蛮力解决方案$b \times c$对的性能可达$25 \times 10^{12}$操作，这是不可能的。 这意味着任何解决方案都必须避免显式迭代所有对，而是依赖于某些算术属性或数学计数方法。 

当出现不明显的边缘情况时$b^2 - c$是一个完美的正方形。 例如，与$n = 3$和$m = 3$，方程$x^2 + 4x + 3 = 0$有根$-1$和$-3$， 尽管$x^2 + 6x + 3 = 0$有根$-3 \pm \sqrt{6}$，显示不同的重叠根$b$。 单独计算每个方程的简单方法会重复计算根。 

## 方法

 天真的方法很简单：对于每个$b$从 1 到$n$和每个$c$从 1 到$m$, 计算$D = b^2 - c$。 如果$D \ge 0$，计算根$-b \pm \sqrt{D}$并将它们存储在一个集合中以确保唯一性。 虽然正确，但这种方法会迭代至$n \times m$次，当两者都达到 5,000,000 时，这太慢了。 

有效解决方案的关键见解来自于对公式的检查$x = -b \pm \sqrt{b^2 - c}$。 我们可以隔离$\sqrt{b^2 - c}$作为整数$k$，因为只有完美的平方才会产生可以在不同的地方共享的有理根$b$。 也就是说，我们可以设置$\sqrt{b^2 - c} = k \Rightarrow c = b^2 - k^2 = (b-k)(b+k)$。 对于每个$b$, 可能的$k$值是满足以下条件的整数$1 \le c = b^2 - k^2 \le m$，给出区间$\max(0, b^2 - m) \le k < b$。 每个$k$产生一个根$-b \pm k$。 这将问题减少到迭代$b$以及小范围的$k$而不是全部$c$。 

蛮力之所以有效，是因为它显式枚举所有根并通过集合处理唯一性，但在以下情况下会失败$n \times m$超出合理计算。 观察根可以表示为$-b \pm k$减少迭代次数并避免重复工作，同时保持正确性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n*m) | O(n*m) | 太慢了|
 | 最佳 | O(n * sqrt(m)) | O(n * sqrt(m)) | O(不同根的数量) | 已接受 |

 ## 算法演练

 1. 初始化一个空集来存储所有不同的根。 使用集合可以确保我们只计算每个根一次，避免因不同而产生重复$(b, c)$pairs producing the same root.
 2. 迭代$b$从 1 到$n$。 对于每个$b$， 计算$b^2$一次以避免重复计算。 
3. 对于每个$b$, 迭代$k$从 0 到$b-1$。 每个$k$代表的值$\sqrt{b^2 - c}$， 所以$c = b^2 - k^2$。 只考虑$k$在哪里$1 \le c \le m$。 该范围由下式获得：$k_{\min} = \max(0, b^2 - m)$和$k_{\max} = b-1$。 
4. 对于每个有效$k$，计算两个根$-b + k$和$-b - k$。 如果$k = 0$，只有一个根$-b$。 将这些根插入到集合中。 
5. 迭代完所有之后$b$和$k$，集合的大小是不同实根的数量。 

为什么它有效：该算法迭代所有$b$和所有$k$产生有效值$c$。 对于每一个这样的$c$，它正确计算相应二次方的根。 通过将结果存储在一个集合中，重叠根中的重复项将被自动消除。 没有跳过有效的根，因为每个整数$k$满足$1 \le c = b^2 - k^2 \le m$被考虑。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    roots = set()
    
    for b in range(1, n + 1):
        b2 = b * b
        k_min = max(0, b2 - m)
        k_max = b - 1
        for k in range(k_min, k_max + 1):
            roots.add(-b + k)
            if k != 0:
                roots.add(-b - k)
    
    print(len(roots))

if __name__ == "__main__":
    main()
```代码首先计算$b^2$以避免为每个重新计算$k$。 它计算最小值$k$作为$b^2 - m$钳位为零，因为$c$必须至少为 1。它循环到$b-1$以确保$k < b$， 自从$k = b$会给$c = 0$，这是无效的。 将根插入到集合中以仅对不同的值进行计数。 支票为$k \neq 0$防止在以下情况下添加相同的根两次$k = 0$。
