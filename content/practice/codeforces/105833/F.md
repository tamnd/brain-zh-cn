 ## 解决方案
 ## 问题理解

 我们被给予`M`的排名`N`候选人。 每个排名都是一个排列`1..N`，其中较小的位置意味着更好的排名。 

任务是构建`K`新的排名，还有排列`1..N`，满足公平条件。 

对于固定候选人`x`, 前缀长度`l`，和一个阈值`t`， 认为`x`出现在顶部`l`位置至少为$$\left\lceil \frac{tM}{K} \right\rceil$$原来的`M`投票。 

然后`x`必须出现在顶部`l`位置至少为`t`锻造的`K`投票。 

该语句保证有效的构造始终存在。 我们只需要输出一个即可。 

对于施工而言，限制因素出奇地小。 我们有`N, K ≤ 100`， 尽管`M ≤ 10^4`。 这意味着我们可以负担得起周围的算法`O(NMK)`用于预处理和`O(KN^2)`或者`O(KN^3)`以供实际施工使用。 任何涉及粗略大小图匹配的事情`100`是完全安全的。 

微妙的部分是，条件必须同时满足每个候选者、每个前缀长度和每个阈值。 满足一个前缀长度要求的结构很容易破坏另一个前缀长度的要求。 

考虑一个经常出现在前三名但很少出现在第一名的候选人。 如果我们只跟踪精确位置而不是累积前缀，我们可能会错误地将它们放置得太低。 

例如：```
N = 3, M = 2, K = 1

1 2 3
2 1 3
```候选人`1`出现在两票的前两名位置。 任何有效的伪造选票也必须将候选人置于`1`在前两名的位置内。 只看第一名的频率会忽略这个要求。 

另一个陷阱是假设候选人可以独立处理。 前缀要求严重重叠。 一个候选人可能会因为前 2 个统计数据而被迫进入较早的列，而另一个候选人可能会因为前 3 个统计数据而被迫进入较早的列。 施工必须同时尊重所有候选人。 

## 方法

 暴力思维是直接搜索`K`满足所有约束的排列。 

即使是为了`N = 100`，单个排列已经有`100!`的可能性。 搜索结束`K`这样的排列是没有希望的。 

关键的观察是，公平条件仅讨论候选者在长度前缀内出现的次数`l`。 它从不关心该前缀内的确切顺序。 

这建议首先用较弱的对象替换排列。 

想象一下`K`伪造选票安排为`K × N`桌子。 每一行都旨在成为一个投票。 第一个`l`表格的列与顶部完全对应`l`行列。 

对于候选人`i`和前缀长度`l`， 让$$c_{i,l}
=
\left\lfloor
\frac{t_{i,l}K}{M}
\right\rfloor$$在哪里`t_{i,l}`是候选人的原始票数`i`在顶部`l`职位。 

公平条件相当于说候选人`i`必须至少出现`c_{i,l}`第一个内的次数`l`伪造表的列。 这直接来自声明中使用的上限阈值的定义。 

现在忘记行是排列。 我们只尝试构建一个满足这些前缀计数的表。 

让$$d_{i,l}=c_{i,l}-c_{i,l-1}$$和`c_{i,0}=0`。 

我们从左到右填充列。 对于柱`l`，我们放置候选人`i`确切地`d_{i,l}`次。 完成专栏后`l`， 候选人`i`已经准确地出现了`c_{i,l}`次位列第一`l`列。 这会自动满足所有前缀要求。 

此时每个候选人都准确地出现`K`整个表中的次数，但行不一定是排列。 

剩下的挑战是转换表，以便每行只包含每个候选者一次。 

这就成为一个匹配问题。 

固定一排。 我们想要候选人`i`正好占据候选人所在的一列`i`目前出现。 构建二部图：

 左侧：候选人。 

右侧：柱子。 

连接候选人`i`到专栏`j`如果候选人`i`出现在列中的某处`j`。 

完美匹配会为每个候选人选择一个合适的列。 然后，我们对每列内的条目进行排列，以便匹配的候选者占据当前行。 霍尔定理保证这种匹配总是存在。 

修复一行后，删除那些选定的事件。 每个候选在剩余行中仍然出现相同的次数，因此可以对下一行重复相同的参数，然后是下一行，直到所有`K`行变成排列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了|
 | 前缀计数构造+重复匹配| O(NMK + KN³) | O(NK) | 已接受 |

 ## 算法演练

 1. 阅读全部`M`原始排列。 
2. 对于每一位候选人`i`和每个前缀长度`l`, 统计有多少原始选票`i`在第一个内`l`职位。 
3. 计算$$c_{i,l}
=
\left\lfloor
\frac{\text{count}_{i,l}\cdot K}{M}
\right\rfloor$$这是必须安排候选人的最低伪造选票数`i`顶部里面`l`职位。 
4. 计算$$d_{i,l}=c_{i,l}-c_{i,l-1}.$$5. 建立一个`K × N`表格逐列。 对于每一列`l`,插入候选`i`确切地`d_{i,l}`次。 

因为$$\sum_i c_{i,l}\le lK,$$处理后放置的条目总数列`l`永远不会超过第一个的容量`l`列。 
6. 对于从上到下的每一行：

 1. 在候选者和列之间构建二分图。 
2. 候选人`i`连接到列`j`如果候选人`i`仍然存在于列中`j`。 
3. 寻找完美匹配。 
4. 对于每对匹配的`(i,j)`, 地方候选人`i`进入当前行列`j`。 
5. 从列中删除该事件`j`。 
7. 填完的行是伪造的选票。 

### 为什么它有效

 第 5 步后，候选人`i`准确地出现`c_{i,l}`次位列第一`l`列。 通过构造这是正确的，因为列`l`准确贡献`d_{i,l}`新的出现。 

匹配阶段永远不会改变列中存在的候选者的副本数量。 它仅决定哪一行接收每个副本。 因此，所有前缀计数保持不变。 

霍尔的条件成立，因为每个候选出现的次数与剩余行的次数完全相同，而每一列最多只能为一行贡献一次出现。 该社论证明，每个候选子集至少触及相同数量的列，从而保证完美匹​​配。 

由于每一行从每一列接收一个候选，并且每个候选仅接收一次，因此每一行都成为一个排列。 保留的前缀计数意味着所有公平性要求均成立。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def kuhn(v, g, seen, mt):
    if seen[v]:
        return False
    seen[v] = True

    for to in g[v]:
        if mt[to] == -1 or kuhn(mt[to], g, seen, mt):
            mt[to] = v
            return True

    return False

def solve():
    N, M, K = map(int, input().split())

    pref = [[0] * (N + 1) for _ in range(N)]

    for _ in range(M):
        p = list(map(int, input().split()))

        pos = [0] * N
        for idx, x in enumerate(p):
            pos[x - 1] = idx + 1

        for cand in range(N):
            r = pos[cand]
            for l in range(r, N + 1):
                pref[cand][l] += 1

    c = [[0] * (N + 1) for _ in range(N)]
    for cand in range(N):
        for l in range(1, N + 1):
            c[cand][l] = (pref[cand][l] * K) // M

    columns = [[] for _ in range(N)]

    ptr = 0
    for l in range(1, N + 1):
        for cand in range(N):
            d = c[cand][l] - c[cand][l - 1]
            for _ in range(d):
                columns[ptr // K].append(cand + 1)
                ptr += 1

    ans = [[0] * N for _ in range(K)]

    for row in range(K):
        g = [[] for _ in range(N)]

        for col in range(N):
            for cand in columns[col]:
                g[cand - 1].append(col)

        mt = [-1] * N

        for cand in range(N):
            seen = [False] * N
            kuhn(cand, g, seen, mt)

        row_perm = [0] * N

        for col in range(N):
            cand = mt[col] + 1
            row_perm[col] = cand

        ans[row] = row_perm

        for col in range(N):
            cand = row_perm[col]
            columns[col].remove(cand)

    print("\n".join(" ".join(map(str, row)) for row in ans))

solve()
```预处理针对每个候选人和每个前缀长度计算前缀内包含该候选人的原始选票数。 从这些计数中我们得出强制值`c[i][l]`。 

表的构造直接遵循证明。 变量`ptr`线性化`K × N`桌子。 每个新需要的事件都被放入下一个空闲单元中。 社论保证中证明了不平等，我们永远不会溢出当前允许的列。 

在匹配阶段，每列存储该列中仍然可用的候选者。 该图将候选者连接到包含一个剩余副本的每一列。 

完美匹配告诉我们哪个候选者占据当前行中的哪一列。 写入该行后，我们从相应的列中删除使用过的事件。 

最常见的实现错误是忘记在中间阶段列中可能存在同一候选的多个副本。 使用后我们只删除一份。

 ## 边缘情况

 当`N = 1`, 每一次投票都是单一排列`[1]`。 计算值满足`c(1,1)=K`，所以该表恰好包含`K`候选人的副本`1`。 每次匹配都是微不足道的，所有伪造的选票都是有效的。 

当所有原始选票相同时，每个候选人都有确定性的前缀频率。 建设者在每张伪造的选票中强制执行完全相同的顺序。 匹配不会引入任何歧义，因为每一列仅包含一个候选者。 

什么时候`K > M`，某些候选者可能需要在早期前缀中出现比原来更多的次数。 底板缩放公式会自动计算所需的多重性，并且表结构会一致地扩展它们。 

什么时候`K < M`，几张原始投票被有效合并。 前缀计数公式可以保证公平性。 该算法从不对个人投票进行推理，只对聚合前缀频率进行推理，这正是条件所要求的。
