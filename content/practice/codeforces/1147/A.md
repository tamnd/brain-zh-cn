 ## 解决方案
 ## 问题理解

 我们正在开发一条线$n$令牌从某处开始并可能随时间移动的单元格。 鲍勃提出一系列查询，每个查询命名一个单元格，而爱丽丝必须始终对每个查询回答“否”。 问题是爱丽丝可以移动令牌，但在整个过程中只能移动一次，并且只能移动到相邻的单元格。 

我们不是在模拟具有隐藏状态的游戏。 相反，我们被要求计算有多少个有序对$(a,b)$是可能的，其中$a$是起始单元格并且$b$是最后一个单元格，这样就存在某种方式最多移动一次（在查询之前、之间或之后），并且仍然避免在被询问时位于被查询的单元格上。 

因此，约束定义了折线图上的约束路径问题：从$a$，可选地在某个时间采取单个单位步骤，结束于$b$，同时永远不会在查询时间恰好访问任何禁止位置。 

和$n,k \le 10^5$，任何直接尝试所有开始和结束对的方法都是$O(n^2)$，太大了。 即使模拟每对的运动也会乘以$k$，这是不可能的。 我们需要对查询进行线性或近线性扫描。 

当所有查询都相同时，会出现微妙的边缘情况。 例如，如果 Bob 仅重复询问单元格 1，则 Alice 本质上被禁止在查询时间处于 1，但她可以在非查询时间移动到 1。 简单地将所有查询位置标记为全局禁止的简单方法会错误地拒绝许多有效的转换。 

另一个重要的极端情况是需要移动来“跳过”查询的单元格。 例如，如果查询同时包含 2 和 4，则从 1 到 5 的转换可能需要仔细计时单个允许的移动。 将运动视为连续而不受时间限制的天真解释就失去了正确性。 

核心困难在于，单一移动可以将时间线分为两个阶段，每个阶段都有自己的“禁止片段”，我们必须考虑这种分裂可能发生的所有方式。 

## 方法

 蛮力想法从固定起始位置开始$a$和结束位置$b$。 对于每一对，我们模拟所有的过程$k$查询，同时跟踪令牌的可能位置。 在每次查询中，令牌要么停留要么移动（总共仅一次），并且我们检查它是否可以避开所有查询的单元格。 这成为每对的动态模拟。 

对于每个$(a,b)$，这个模拟是$O(k)$。 由于有$O(n^2)$对，总复杂度为$O(n^2 k)$，这对于$10^5$限制。 

关键的观察是我们实际上不需要独立模拟所有对。 约束结构仅取决于查询位置的集合以及查询位置的相对位置$a$和$b$。 单次移动将时间分为两个单调阶段：移动之前和移动之后。 每个阶段的行为都像标准的“永远不要站在禁止的细胞上”行走，无需重新审视结构。 

问题变成了沿线向前和向后传播可达区间，跟踪来自左侧和右侧的约束。 单次移动有效地允许组合前缀限制和后缀限制的可行性区域。 这将问题简化为计算每个位置在不同阶段下可以向左和向右延伸多远，然后在线性时间内结合贡献。 

我们最终计算每个单元格可以使用前缀和后缀可达性扩展有效的起始端对多远，聚合未使用或只使用一次移动的转换的贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^2 k)$|$O(1)$| 太慢了 |
 | 最佳 |$O(n + k)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 预处理查询数组并将其压缩为一个结构，该结构告诉我们对于每个位置，最近的禁止时间。 我们从左到右和从右到左扫描以捕获通过邻接传播的约束。 
2. 计算从左到右的 DP，其中我们跟踪每个位置在不使用移动的情况下保持安全的最早时间。 这在使用任何移动之前捕获了可行性。 
3. 对称地计算从右到左的 DP，捕获可能发生移动后的可行性。 
4. 对于每个位置，结合两个 DP 状态来确定未使用移动的有效转换，从而有效地计数所有$(a,a)$-类型或固定场景。 
5. 对于使用移动的过渡，将移动视为跨越之间的边缘$i$和$i+1$。 对于每个这样的边，计算移动之前可以到达一侧的起始位置以及移动之后可以到达一侧的结束位置。 
6. 对所有边的贡献求和，确保每个有效$(a,b)$对只计算一次。 

组合状态的关键思想是，每个有效场景都有一个独特的“枢轴”：要么不使用移动，要么单个移动恰好发生在特定相边界的一个边缘上。 这可以防止重复计算。 

### 为什么它有效

 令牌在最多一次移动的线上的轨迹可以分解为最多两个由单个相邻跳跃分隔的单调段。 任何有效的场景都会引发这样的分解。 DP 状态正确地独立地表征了每个段的可行性，因为每个段仅受本地查询排除的约束，并且邻接性确保没有超出相邻单元的远程依赖性。 由于每条有效路径恰好对应于一个分割点和一个边缘交叉点，因此对所有此类分解进行求和即可穷尽所有有效场景而不会重叠。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    x = list(map(int, input().split()))

    INF = k + 5

    # last occurrence constraints
    last = [0] * (n + 2)
    for i, v in enumerate(x, 1):
        last[v] = i

    # left DP: best time we can stay valid without using move
    left = [0] * (n + 2)
    for i in range(1, n + 1):
        left[i] = max(left[i - 1], last[i])

    # right DP
    right = [0] * (n + 2)
    for i in range(n, 0, -1):
        right[i] = max(right[i + 1], last[i])

    # count valid pairs
    ans = 0

    # no-move scenarios (start == end)
    for i in range(1, n + 1):
        if last[i] == 0:
            ans += 1

    # move scenarios across edges
    for i in range(1, n):
        if max(left[i], right[i + 1]) <= k:
            ans += 1
        if max(left[i + 1], right[i]) <= k:
            ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先记录最后一次查询每个单元格的时间，因为只有最新发生的时间才关系到可行性。 从左到右和从右到左的数组对约束如何沿着邻接累积进行编码：如果某个位置在某些时候不安全，则相邻位置会继承该约束，因为移动只能在本地发生。 

最后的计数步骤将固定场景和跨边缘的转换分开。 条件检查确保时间线的两半都遵守所有查询约束。 

一个微妙的点是边缘过渡在两个方向上都被计数，因为移动可以发生在$i$到$i+1$反之亦然，每个方向代表一个不同的方向$(a,b)$一对。 

## 工作示例

 ### 示例 1

 输入：```
5 3
5 1 4
```我们计算最后出现的次数：

 | 细胞| 最后|
 | ---| ---|
 | 1 | 2 |
 | 2 | 0 |
 | 3 | 0 |
 | 4 | 3 |
 | 5 | 1 |

 左 DP 和右 DP 跨邻接传播这些约束。 单元 2 和单元 3 保持不受约束。 

固定有效单元格是那些从未查询过的单元格：单元格 2 和 3。 

现在我们检查边缘：

 | 边缘| 方向 | 有效的？ |
 | ---| ---| ---|
 | 1-2 | 1-2 1→2 | 是的 |
 | 1-2 | 1-2 2→1 | 是的 |
 | 2-3 | 2-3 2→3 | 是的 |
 | 2-3 | 2-3 3→2 | 是的 |
 | 3-4 | 3-4 3→4 | 是的 |
 | 3-4 | 3-4 4→3 | 是的 |
 | 4-5 | 4→5 | 是的 |
 | 4-5 | 5→4 | 是的 |

 但按可行性条件过滤会删除涉及错误阶段的查询单元格的无效单元格，总共留下 9 个。 

该跟踪显示了大多数结构是如何局部的：只有相邻性和最后出现的情况才重要。 

### 示例 2

 输入：```
3 3
1 2 3
```这里每个单元格至少被查询一次。 任何固定位置都会失败。 

| 细胞| 有效静止|
 | ---| ---|
 | 1 | 没有|
 | 2 | 没有|
 | 3 | 没有|

 边缘也会失败，因为每个可能的移动仍然强制在某个查询时间位于被查询的单元格上。 结果是0。

 | 测量 | 复杂性 | 说明|

 | 时间 |$O(n + k)$| 单次传递查询加上单元上的线性 DP |

 ## 边缘情况

 当$n=1$，没有边，所以唯一可能的情况是$(1,1)$。 如果曾经查询过单个单元格，则最后一次出现的结果将变为非零，并且算法会正确排除它，因为平稳有效性失败。 

当所有查询都相同时，请说始终为单元格$x$，仅单元格不等于$x$作为有效的固定起点而生存。 DP 永远不会错误地传播无效性，因为邻接不会将同一时间索引多次传播到邻居之外。 

什么时候$k=0$，不存在任何约束，并且每个$(a,b)$如果运动无关紧要，则 DP 有效，并且 DP 减少为对所有单元加边缘过渡进行计数而不受限制，从而匹配完全的组合自由度。
