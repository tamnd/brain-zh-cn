 ## 解决方案
 ## 问题理解

 该问题给出了代表金属板上图案的矩形字符网格，其中每个单元格包含一个`.`（空）或`*`（已填充）。 任务是找到包含所有矩形的最小矩形`*`人物。 该矩形由其最顶行、最底行、最左列和最右列描述，使用从 1 开始的索引。 

输入首先给出行数和列数，然后是网格本身。 输出应该是定义所有恒星的边界矩形的四个整数。 

因为网格可以大到 500x500，所以任何明确检查每个可能的矩形的方法都是不可行的。 考虑每一对上/下和左/右坐标来检查它是否包含所有星星的天真的暴力需要最多`(500^2)^2`操作，大约 6.25×10^10，这对于典型的 2 秒限制来说太慢了。 

需要注意的边缘情况包括带有单个网格的网格`*`，网格，其中所有`*`位于单行或单列中，并且网格其中`*`触摸界限。 例如，像这样的网格：```
3 4
*...
....
....
```应该返回`1 1 1 1`。 假设多行或多列的粗心方法将会失败。 

## 方法

 蛮力方法将扫描每个可能的矩形，计算它是否包含所有星星，并跟踪最小的此类矩形。 这是可行的，因为检查矩形很简单，但当网格很大时就会失败：有 n 行和 m 列，操作计数为 O(n^2 * m^2)，对于 n=m=500 来说太慢了。 

关键的观察是我们不需要检查每个矩形。 每颗星只对矩形的极端有贡献。 矩形的最上面一行是包含以下内容的最小行索引`*`，最底下的行是包含a的最大行索引`*`，最左边的列是最小列索引`*`，最右边的列是最大列索引`*`。 扫描一次网格并记录这些极值就足够了。 

这将问题从四嵌套循环暴力破解减少为一次 O(n*m) 扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 * m^2) | O(n^2 * m^2) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n*m) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化四个变量来跟踪矩形边界。 放`top`为一个大值（大于任何可能的行），`bottom`至-1，`left`为一个大值，并且`right`至-1。 这些代表未初始化的极端情况。 
2. 迭代每一行`i`从 0 到 n-1。 对于每一行，迭代每一列`j`从0到m-1。 如果细胞`(i,j)`包含`*`，更新极值：

 - 设置`top`到`min(top, i)`。 
- 放`bottom`到`max(bottom, i)`。 
- 放`left`到`min(left, j)`。 
- 放`right`到`max(right, j)`。 
3. 扫描网格后，包含所有星星的矩形具有顶行`top+1`，底行`bottom+1`，左栏`left+1`，和右列`right+1`。 这`+1`考虑从 1 开始的索引。 

为什么它有效：变量`top`,`bottom`,`left`,`right`始终保持迄今为止所看到的恒星的极端指数。 因为我们扫描了整个网格，所以不会遗漏任何一颗星星。 通过获取坐标的最小值和最大值，我们保证矩形精确地包围了所有星星。 不存在错过边界的风险，因为每个`*`被单独考虑。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    top, bottom = n, -1
    left, right = m, -1

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '*':
                top = min(top, i)
                bottom = max(bottom, i)
                left = min(left, j)
                right = max(right, j)

    print(top + 1, left + 1, bottom + 1, right + 1)

if __name__ == "__main__":
    main()
```该解决方案的每个部分都直接对应于算法演练。 初始化极值确保我们可以比较每个极值`*`正确。 双循环确保检查每个单元格，防止错过星星。 最后添加的是`+1`从基于 0 的 Python 索引转换为问题所需的基于 1 的输出。

 ## 边缘情况

 对于单个`*`在任何地方，该算法都会将顶部、底部、左侧和右侧设置为相同的值，从而生成大小为 1x1 的矩形。 对于左上角的星星来说，`top`和`left`保持为零，最终`+1`转换为从 1 开始的索引。 对于右下角的星星，`bottom`和`right`正确更新为最大索引。 在所有情况下，该算法都能正确界定所有恒星，而不会出现过冲或下冲的情况。 

该算法可以正确处理所有星星位于单行或单列的网格，因为最小值和最大值收敛到实际位置。 这避免了天真的方法可能假设最小尺寸矩形大于必要的陷阱。
