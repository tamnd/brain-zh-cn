 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 每个测试用例都由一个小的整数数组组成，我们可以在元素之间重复重新分配两个因子。 一个操作选择两个位置，将一个所选值除以二（仅当该值是偶数时），并将另一个值加倍。 此操作保留所有元素的总乘积，但更改总和。 

目标是多次应用此类操作，以便最大化数组的总和。 

这些约束使得该结构与典型的数组优化问题有很大不同。 数组大小最多为 15，并且每个值都小于 16。这立即表明对各个值的状态进行暴力破解是不必要的，而且分解结构也极其有限。 每个数字都可以写成奇数部分乘以 2 的幂，并且由于值很小，所以 2 的幂最多为 3。这强烈暗示系统中唯一有意义的运动是在位置之间移动 2 的幂。 

一个天真的误解是假设总和是不变的或几乎不变的。 它不是。 例如，将因子 2 从较小的奇数移至较大的奇数，会增加大数的贡献，而不是减少小数的贡献。 

第二个微妙的边缘情况是所有数字都是奇数时。 无法进行任何操作，因为没有元素可以被 2 整除。答案是固定的。 

第三种边缘情况是所有数字都是 2 的幂。 在这种情况下，二进制的重新分配不受限制，最终的总和完全取决于我们如何对指数进行分组。 

## 方法

 暴力方法将模拟所有可能的操作序列。 每个状态都是整数的多重集，每次移动都会选择两个索引并修改它们。 即使使用很小的数组，分支因子也很大，并且序列可以任意长，因为值可以通过重复加倍而不断增长。 如果不仔细限制的话，状态空间很快就会变得无限。 

关键的观察是将每个数字分成奇数部分和二次方指数。 将每个值写为$a_i = b_i \cdot 2^{k_i}$， 在哪里$b_i$是奇数并且$k_i$是我们可以除以二的次数。 

该运算有效地将一个指数单位从一个位置移动到另一个位置：减一$k_i$并增加另一个$k_j$，同时保留所有奇数部分不变。 这是核心简化：奇数部分是固定的，仅指数被重新分配。 

现在总和是：$$\sum b_i \cdot 2^{k_i}$$我们可以在指数之间任意重新分配多组指数，但我们不能改变指数的总和。 

所以问题就变成了：在固定权重上分配固定数量的二的幂$b_i$，其中每个指数单位使该位置的贡献加倍。 由于加倍是乘法，因此位置上的每个额外指数都会将其值乘以 2，并且贡献会随着分配的指数数量呈指数增长。 

贪婪结构自然出现：较大的奇数分量应该获得较大的指数。 

我们按奇数部分对值进行排序，将 2 的所有幂提取到一个池中，然后贪婪地将最大指数分配给最大的奇数分量。 这使得加权指数和最大化。

 ## 算法演练

 1. 对于每个数字，分解出 2 的所有幂。 存储奇数部分并计算它被 2 整除的次数。 这隔离了可以移动的内容和固定的内容。 
2. 将所有提取的 2 的幂收集到单个多组指数中。 每个指数代表一个可以分配到其他地方的加倍运算。 
3. 按奇数分量降序对数组进行排序。 原因在于，较高的奇数值从接收额外的 2 次方中获益更多。 
4. 对指数池进行降序排序。 应首先分配较大的指数，因为它们会产生较大的乘法效应。 
5. 贪婪地分配指数：对于按降序排列的每个指数，将其应用于当前最大的奇数分量。 这意味着将该分量乘以$2^{k}$。 
6. 计算所有更新值的最终总和。 

微妙的一点是，我们在模拟中从不单独移动指数。 我们只考虑它们的净效应。 这避免了指数操作序列。 

### 为什么它有效

 每个操作都会保留数组中因数为 2 的总数。 由于奇数分量在除以二的情况下保持不变，因此唯一的自由度是这些因子的分布方式。 单位指数的贡献仅取决于它所应用的奇数底数。 因为函数$b \cdot 2^k$是凸的$k$，最优分配是将较大的指数集中在较大的基数上。 任何违反此顺序的两个位置之间的指数单位交换都会严格减少总和，这保证了贪婪分配是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        odds = []
        exps = []
        
        for x in a:
            k = 0
            while x % 2 == 0:
                x //= 2
                k += 1
            odds.append(x)
            exps.extend([1] * k)
        
        odds.sort(reverse=True)
        exps.sort(reverse=True)
        
        # assign exponents greedily
        i = 0
        for e in exps:
            odds[i] *= (1 << e)
            i += 1
        
        print(sum(odds))

if __name__ == "__main__":
    solve()
```该实现准确地反映了概念分解。 两个循环提取因子从可移动功率单元中分离出不可变的奇数部分。 指数列表代表所有可转移的加倍运算。 对两个列表进行排序可确保最大增益首先配对。 

一个微妙的细节是每个指数单位都是独立的，因此我们不需要跟踪除乘法之外的多个赋值的复合效应。 另一个是，一旦应用排序，移位顺序就不再重要，因为贪婪配对已经强制执行最佳结构。

 ## 边缘情况

 当所有数字都是奇数时，指数列表为空，并且算法永远不会修改任何值。 输入`[1, 3, 5]`立即产生总和`9`，因为任何地方都不可能被二除。 

当所有数字都是 2 的幂时，例如`[8, 8, 8]`，所有奇数部分都变为 1，并且所有指数都汇总在一起。 贪婪分配将所有增长集中在第一个元素上，产生与固定指数预算一致的最大指数放大。 

当有单个元素时，例如`[10]`，无法进行任何操作，因为没有第二个索引可以接收双倍值。 由于不会发生指数重新分布，该算法正确输出原始值。
