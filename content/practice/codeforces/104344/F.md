 ## 解决方案
 ## 问题理解

 我们有一栋大楼，楼层编号为 1 到 N。最初，每个楼层的灯都关闭。 N 个人以结构化的方式走过并切换开关。 第 i 个人切换每个 i 倍数的楼层数。 当所有 N 个人都完成此操作后，一些楼层最终会亮起来，而另一些楼层则保持黑暗。 

切换意味着切换状态，因此关闭变为打开，打开变为关闭。 最终任务不是模拟该过程，而是准确确定最后哪些楼层被点亮，并按升序打印这些楼层号。 

约束 N 可以大到 10^8，这会立即排除所有楼层对所有人进行的任何模拟。 直接方法每人大约需要 N 次操作，在最坏的情况下导致大约 N^2 次操作，这远远超出了可行的限制。 如果我们不小心的话，即使对所有切换进行一次遍历也太大了，因为在优化语言中 10^8 操作已经接近 1 秒，而在 Python 中重复多次时是不可能的。 

关键的困难是认识到该过程是高度结构化的，并且仅取决于每个下限指数的除数数量。 

当 N 很小时，会出现微妙的边缘情况。 例如，如果 N = 1，则唯一的楼层会切换一次并保持打开状态。 对于 N = 2，楼层 1 切换两次并结束，而楼层 2 切换一次并保持开启状态。 这些小案例暗示最终状态是由每个数字固有的奇偶性决定的，而不是由操作序列决定的。 

## 方法

 暴力模拟会迭代每个人 i 从 1 到 N，然后迭代 i 的倍数，切换这些楼层的状态。 这直接反映了问题陈述，并且逻辑上是正确的。 

然而，成本是问题。 内部循环运行 N/i 次，因此切换总数大约为 N/1 + N/2 + ... + N/N，即 N log N。即使这在 C++ 中可能会通过，但在 N 高达 10^8 的情况下，在 Python 中是完全不可行的，甚至从概念上讲，在最坏的情况下我们仍在迭代数十亿次操作。 

关键的观察是倒转视角。 我们不问每个人切换楼层多少次，而是问每个楼层切换多少次。 对于 k 的每个除数，下层 k 都会切换一次，因为当人 i 行动时，每个除数 i 都会贡献一次切换。 因此，下层 k 恰好切换 d(k) 次，其中 d(k) 是 k 的约数数。 

如果地板被切换奇数次，地板就会被点亮。 因此问题简化为找到所有 k 使得 d(k) 为奇数。 一个经典的数论事实是，只有完全平方数的约数是奇数。 发生这种情况是因为除数通常配对为 (a, k/a)，除非 a = k/a 时，这种情况仅发生在完全平方数中。 

因此，答案正是所有小于或等于 N 的完全平方数。 

我们可以通过从 1 迭代 i 直到 i^2 ≤ N 并打印 i^2 来直接生成它们。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(N log N) | O(N log N) | O(N) | 太慢了 |
 | 平方枚举 | O(√N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 观察每层 k 对于 k 的每个除数都会切换一次。 这根据除数计数而不是模拟人来重新构建整个过程。 
2. 认识到最终状态仅取决于 k 的除数计数是否为奇数。 如果很奇怪，地板就会被照亮。 
3. 利用数论事实：只有完全平方数的因数为奇数。 这来自于围绕 √k 对称配对除数。 
4. 结论是我们只需要输出 i² 形式的所有整数，使得 i² ≤ N。 
5. 从 1 开始迭代 i，并在 i² ≤ N 时继续，每次打印 i²。

为什么它起作用：每个非平方整数的除数都以不同的对排列，产生偶数计数，因此它抵消了。 完全平方恰好有一个不成对的除数，即平方根，使得计数为奇数并保留最终状态。 这个不变量对于每层楼都是独立的，因此计算平方完全决定了输出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    i = 1
    while i * i <= n:
        print(i * i)
        i += 1

if __name__ == "__main__":
    solve()
```该解决方案读取 N，然后迭代可能的平方根。 每个值 i 代表在切换过程中幸存下来的下限 i²。 循环条件 i * i <= n 确保我们不会超出有效的下限范围。 不需要额外的数据结构，因为输出是动态生成的。 

关键细节是使用 i * i 而不是浮点平方根，避免精度问题并保持解决方案整数安全。

## 复杂度分析

 | 测量| 复杂性 | 说明|

 ## 边缘情况

 当 N = 1 时，仅存在 1 层。 它被切换一次，所以它保持打开状态。 该算法输出 i = 1，产生 1² = 1，这是正确的。 

对于像 N = 2 这样的非正方形，只有 i = 1 满足 i² ≤ 2，因此只打印第 1 层。 不打印 Floor 2，因为 2 不是完全平方并且有偶数个约数，这意味着它会结束。 

对于较大的 N，例如 10^8，i 最多运行 10^4，并且我们正确输出最多 10000² = 10^8 的所有平方，确保没有溢出或性能问题。 

每个案例都证实该算法仅依赖于整数迭代，完全避免了模拟，从而保持了正确性和效率。
