 ## 解决方案
 ## 问题理解

 我们得到一排孩子，其中每个位置已经包含一个孩子，但每个孩子都有一个他们应该占据的目标位置。 输入数组描述了这个映射：当前坐在索引处的孩子`i`想要最终达到的位置`p[i]`一切都正确排序后。 

目标是将当前的排列转变为完美有序的排列，其中应该处于适当位置的子元素`1`在那里，孩子应该就位`2`在那里，依此类推，直到位置`N`。 唯一允许的操作是交换行中的任意两个子项。 我们希望达到正确配置所需的最少交换次数。 

这是一个经典的“使用交换重新排列排列”问题。 关键的观察是该数组实际上是以下的排列`1..N`，因为每个正确的位置都是唯一分配的。 

约束足够小，使得具有二次行为的解决方案`N`实践中还是会通过的。 和`N ≤ 1000`，甚至是一个按顺序执行的算法`N^2`或者`N^2 log N`操作是可以接受的。 这立即排除了任何指数或涉及每次操作重复深度重新计算的情况。 

一个天真的但常见的错误是在没有一致结构的情况下尝试贪婪地模拟交换。 例如，重复扫描下一个不正确的位置并将其交换到位是可行的，但如果忘记交换可能会在其他地方造成新的错位，则很容易出错。 另一个不正确的想法是总是将错误的元素与当前位于目标位置的元素交换，而不跟踪该元素的实际位置，如果不仔细索引位置，就会中断。 

往往会破坏简单解决方案的边缘情况包括已经排序的数组，例如`[1,2,3,4]`，其中答案为零，纯循环如`[2,3,1]`，其中每个元素都被错位，但在单个循环中构建。 粗心的贪婪掉期可能会多算或少算掉期，具体取决于周期的打破方式。 

这里更深层次的结构是数组定义了一个排列，排列分解为不相交的循环。 所需的最小交换量完全由循环结构决定。 

## 方法

 暴力方法会通过找到属于该位置的元素并将其交换到位来重复修复第一个错误位置。 每次交换都会减少本地错放元素的数量，但需要重复搜索。 在最坏的情况下，每次放置都需要扫描数组以找到正确的元素，从而导致$O(N)$重复扫描$O(N)$次，给予$O(N^2)$时间。 这是可以接受的$N ≤ 1000$，但是该方法在概念上很混乱，并且当交换影响未来的搜索时很容易错误地实现。 

关键的见解是停止考虑单个交换，而是将数组视为排列图。 每个索引都指向其当前值应该去的位置。 这将创建有向边`i → p[i]`。 每个节点恰好属于一个循环。 一个周期的长度`k`准确地要求`k - 1`交换来修复，因为每次交换都可以正确放置一个元素，同时保留循环内的结构。 

将所有周期的总和得出最小交换次数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（重复修复）| O(N²) | O(N) | 已接受但笨拙|
 | 循环分解| O(N) | O(N) | 已接受 |

 ## 算法演练

 1. 将数组解释为排列，其中位置`i`最终必须包含价值`i`。 

这种重构使我们能够根据指数而不是任意互换来推断正确性。 
2. 构建一个访问数组来跟踪哪些索引已分配给循环。 

如果没有这个，我们将重复地重新处理相同的结构并超额计算交换。 
3. 迭代每个索引`1`到`N`。 

如果该索引已经被访问过，则它属于先前处理的循环，因此我们跳过它。 
4. 当我们找到未访问的索引时，开始跟踪链`i → p[i] → p[p[i]] → ...`直到我们返回到访问过的节点。 

该遍历发现了排列的完整循环。 
5. 计算尺寸`k`这个周期的。 

每个循环代表错误放置的元素的闭合依赖循环。 
6. 添加`k - 1`到答案。 

这是将循环分解为正确放置的固定点所需的最小交换次数。 
7. 继续，直到访问完所有索引并对所有贡献求和。 

### 为什么它有效

 每个排列都可以唯一地分解为不相交的循环。 在一个长度周期内`k`，没有一个元素可以在不与同一周期中的其他元素交互的情况下到达其正确位置。 一次交换最多可以正确放置循环中的一个元素，同时在其余元素中保留较小的循环结构。 重复此操作可以得到最佳结果`k - 1`交换，并对独立周期求和可确保它们之间不存在干扰。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = list(map(int, input().split()))
    
    # convert to 0-based target interpretation
    p = [x - 1 for x in p]
    
    visited = [False] * n
    ans = 0
    
    for i in range(n):
        if visited[i]:
            continue
        
        # explore cycle starting at i
        cur = i
        cycle_size = 0
        
        while not visited[cur]:
            visited[cur] = True
            cycle_size += 1
            cur = p[cur]
        
        if cycle_size > 0:
            ans += cycle_size - 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先将排列转换为从零开始的索引，以便位置与数组索引自然对齐。 访问的数组确保每个索引只处理一次，从而防止重复计数循环。 每次循环遍历都遵循排列映射，直到循环回来，循环大小直接决定添加的交换数量。 

减法`cycle_size - 1`是从结构到成本的关键转变。

 ## 边缘情况

 对于已经排序的输入，例如`1 2 3 4`，遍历立即将每个索引标记为大小为 1 的循环。没有累积交换，并且输出保持为零。 

对于像这样的完整周期`2 3 4 1`，算法如下`0 → 1 → 2 → 3 → 0`，产生周期大小 4 并贡献`3`互换。 这与最小序列匹配，其中每次交换逐渐修复一个元素，同时缩小剩余周期。 

对于多个独立循环，例如`2 1 4 3 5`，访问机制确保每个周期都是隔离的。 算法流程`(0,1)`和`(2,3)`分别贡献一份交换，而固定点`4`没有贡献。
