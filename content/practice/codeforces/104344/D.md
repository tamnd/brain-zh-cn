 ## 解决方案
 ## 问题理解

 每个学生的结果都来自一个非常小的固定宇宙：正好有三个独立的问题，分别值 1、2 和 4 分。 任何学生的分数只是他们解决的问题的值的总和，因此 0 到 7 之间的每个分数都对应于这三个问题的唯一子集。 

我们得到了两名学生 Lucca 和 Yvens 的分数。 从这些分数中，我们可以准确推断出他们各自解决了哪些问题子集，因为使用这三个权重表示 0 到 7 之间的数字没有歧义。 

帕西尼奥的行为是以非常具体的方式定义的。 他解决了卢卡或伊文斯至少其中一个解决过的每一个问题，但他没有解决他们俩都没有解决的问题。 这意味着帕西尼奥的解集恰好是两个学生解集的并集。 

因此，任务是计算由分数隐式表示的两个子集的并集，然后将该并集转换回分数。 

两个分数都在 0 到 7 之间的约束意味着每个分数对应于一个 3 位掩码。 这消除了对组合或搜索的任何需要。 整个问题分解为三位以上的按位重建。 

当直接根据分数而不是子集进行推理时，会出现微妙的失败情况。 例如，3 可以是 {1,2}，5 可以是 {1,4}。 天真的尝试可能会尝试以算术方式组合数字，并错误地假设十进制表示中的数字独立。 正确的表示是权重为 1、2 和 4 的二进制，而不是基数 10 的数字。 

## 方法

 蛮力方法是尝试 Lucca 和 Yvens 的三个问题的所有子集，计算哪些子集与它们的分数匹配，然后显式合并每个兼容对并重新计算结果分数。 由于每个人只有 2³ 子集，因此这是一项持续的工作，但该方法在概念上很重并且模糊了结构。 

关键的观察结果是每个分数已经是三个元素子集的直接编码。 以二进制形式写入分数与问题权重完全一致：位 0 代表问题 1，位 1 代表问题 2，位 2 代表问题 4。因此，分数本身就是一个位掩码。 

一旦看到这一点，帕西尼奥的得分只是两个得分的按位或。 OR 运算准确地捕获了已解决问题的并集，因为如果两个学生中至少有一个设置了某个位，则该位就被设置了。 

这将问题减少到单个操作。

 | ---| ---| ---| ---|
 | 子集的暴力枚举 | O(1) | O(1) | O(1) | O(1) | 已接受 |
 | 按位或解释 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 从输入中读取整数 L 和 Y。 它们代表三个位上的两个位掩码。 
2. 将每个数字解释为 {1, 2, 4} 的子集，其中每一位表示问题是否已解决。 
3. 通过在 L 和 Y 之间应用按位 OR 来计算已解决问题的并集。这是有效的，因为 OR 会保留一个位（如果它出现在任一操作数中）。 
4. 输出结果整数，该整数直接对应于帕西尼奥的得分。 

### 为什么它有效

 每个问题对最终分数的贡献都是独立的，并且问题之间不存在交互作用。 这种独立性保证了分数表示在位存在方面是线性的。 由于从 0 到 7 的每个有效分数都是唯一的 3 位向量，因此已解集的并集完全对应于按位 OR。 不存在替代表示，因此结果是唯一确定的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

L, Y = map(int, input().split())
print(L | Y)
```该解决方案依赖于读取两个整数并应用单个按位或运算。 关键的实现细节是不需要转换或解码； 输入值已经代表了伪装的位掩码。 

一个常见的错误是尝试将数字分解为十进制数字或手动重建子集。 这是不必要的，因为编码已经匹配二进制结构。

 ## 边缘情况

 一种边缘情况是两个输入相同，例如 3 和 3。在这种情况下，两个学生解决了完全相同的问题，因此帕西尼奥也应该解决同一组问题。 计算 L OR Y = 3 OR 3 = 3 正确保留原始值。 

另一种边缘情况是当一个输入为 0 时。例如，L = 0 且 Y = 5。并集应该简单地重现 Y。OR 运算给出 0 OR 5 = 5，这与 Passinho 精确求解 Yvens 求解的解释相匹配。 

最后一种情况是两个输入不相交，例如 1 和 2 或 1 和 4 和 2。OR 运算正确地累加所有位而不会产生干扰，当所有位都被覆盖时，会产生最多 7 的完整并集。
