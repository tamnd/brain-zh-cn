 ## 解决方案
 ## 问题理解

 我们有两堆硬币，其中一堆有$A$硬币和另一个$B$硬币。 两名玩家交替轮流，并且在每一轮中，玩家必须从第一堆、第二堆或同时从两堆中取出一枚硬币。 移除硬币的动作是强制性的，因此不允许通过。 从系统中取出最后剩余硬币的玩家赢得游戏。 

我们被要求从第一个玩家布罗的角度来分析这个游戏。 对于给定的起始配置$(A, B)$，我们必须在两个玩家都发挥最佳的情况下决定第一个玩家是否可以强行获胜。 如果存在获胜策略，我们还必须输出保证该结果的有效第一步。 

约束条件允许$A, B \le 10^9$，这立即告诉我们，对所有位置进行任何状态空间探索都是不可能的。 即使对所有状态进行线性扫描也是不可能的，并且任何解决方案都必须将游戏简化为可在每个测试用例的恒定时间内计算的封闭形式条件。 

一个微妙的边缘情况是两个堆都已经空的情况。 在这种情况下，游戏已经结束，第一个玩家没有动作，这应该与失败条件一致地处理。 

另一种微妙的情况是一堆空的时候。 移动集仍然允许从非空堆中获取或从两者中获取，但行为变得不对称，并且如果不仔细从完整的游戏结构而不是关于单堆的直觉中得出，可能会误导幼稚的奇偶推理。 

## 方法

 蛮力方法可以处理每个位置$(a, b)$作为游戏状态并递归地尝试所有可能的移动：从第一堆中删除，从第二堆中删除，或从两者中删除。 如果至少一项操作导致亏损，则该仓位为盈利；如果所有操作均导致盈利，则该仓位为亏损。 

这个递归正确地模拟了游戏，但是状态空间是$(A+1)(B+1)$，在最坏的情况下约为$10^{18}$。 即使有记忆，可到达状态的数量对于任何直接动态编程来说仍然太大。 

关键的观察结果是，移动集总是将硬币总数减少一到两个，并且游戏的行为就像网格上非常结构化的减法游戏。 计算小值揭示了亏损头寸的稳定模式：只要两堆都是偶数，该头寸就会亏损，而所有其他配置都会获胜。 

这将整个游戏崩溃为奇偶条件而不是图遍历问题。 一旦确定了失败的状态，就可以通过迫使对手进入两堆相等的状态来构建获胜的棋步。

 ## 算法演练

 ### 第 1 步：确定亏损头寸

 如果两者都存在，则仓位处于亏损状态$A$和$B$是均匀的。 如果游戏以这样的位置开始，任何举动都必然会打破这一属性并为对手提供获胜的配置。 

### 第 2 步：如果当前状态正在丢失

 如果两者都$A$和$B$是偶数，输出表明第一个玩家不存在获胜策略。 

### 第 3 步：否则构建制胜之举

 我们试图进入失败的位置，即进入两堆都变得相等的状态。 

### 步骤 4：根据奇偶性选择移动

 如果$A$是偶数且$B$是奇数，减少$B$1.

 如果$A$是奇数并且$B$是均匀的，减少$A$1.

 如果两者都是奇数，请同时从每一堆中取出一枚硬币。 

这些动作中的每一个都以达到偶数状态所需的方式精确地翻转奇偶性。 

### 为什么它有效

 关键的不变量是偶数位置正是游戏的 P 位置。 从任何偶数状态开始，每个有效的移动都会改变至少一个桩奇偶性，从而产生非偶数状态。 从任何非偶数状态，总有一种移动可以一步将奇数计数向下翻转以达到偶数，因为我们可以使用三种允许的移动类型独立调整奇偶校验。 这保证了游戏减少到获胜区域和失败区域之间交替强制转换。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

A, B = map(int, input().split())

# losing position for first player
if A % 2 == 0 and B % 2 == 0:
    print("N")
else:
    print("S")
    if A % 2 == 0 and B % 2 == 1:
        print("B")
    elif A % 2 == 1 and B % 2 == 0:
        print("A")
    else:
        print("A B")
```该代码直接对奇偶校验特征进行编码。 第一个条件检查起始状态是否失败，在这种情况下不打印任何动作。 否则，它会选择迫使两个牌堆形成均匀配置的移动。 

决策结构对于奇偶校验情况是详尽的，并且每个分支完全对应于将状态降低到对手的失败类别的移动。

 ## 边缘情况

 ### 情况：两堆都是空的`(0, 0)`该算法将其分类为偶数，因此输出`N`。 这与要移动的玩家没有合法移动并因此立即失败的事实相匹配。 

###案例：大偶偶状态`(10^9, 10^9)`两个值都是偶数，因此输出为`N`在恒定的时间内。 不需要探索状态转换，因为奇偶校验本身就决定了结果。 

### 案例：混合奇偶校验`(even, odd)`该算法总是将奇数堆减一，产生偶数状态。 例如，`(6, 5)`变成`(6, 4)`，迫使对手陷入失败状态。 

### 情况：均为奇数`(odd, odd)`此举`(A-1, B-1)`始终有效并将位置转换为偶数。 例如，`(7, 3)`变成`(6, 2)`，再次将失败的状态交给对手。
