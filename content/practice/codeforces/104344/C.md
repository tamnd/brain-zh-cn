 ## 问题理解

 我们正在研究数轴上的一维运动问题。 艾伦从位置0开始，想要到达目标位置X。一路上，Y处有一堵墙，这堵墙阻挡了通道，直到艾伦在位置Z获得了锤子。一旦收集到锤子，墙壁就不再阻止移动，因此艾伦之后可以自由地穿过Y。 

任务是确定在这些规则下是否有可能到达 X，如果可以，则计算行驶的最小总距离。 

因为运动是在直线上，并且每段成本只是绝对距离，所以任何有效路线完全由 Eren 访问相关点的顺序决定：0、Z、Y 和 X，约束条件是只有在访问 Z 后才能安全地穿过 Y。 

约束很小，所有坐标都在 -1000 到 1000 之间。这立即告诉我们，每个测试用例具有恒定或对数复杂度的任何解决方案就足够了，甚至少量固定数量的路径评估也足够了。 

主要的微妙之处在于，墙并不是几何意义上的单向约束。 这是一个权限约束：只有在访问 Z 之后才允许跨越 Y。忽略此顺序的天真的最短路径直觉将会失败。 

当 Z 相对于起点或目标位于 Y 的“错误一侧”时，就会出现典型的失败情况。 例如，如果Eren需要提前通过Y才能到达Z，但Z超出Y，从而在获得锤子之前强制穿过Y，那么即使所有点都在一条线上，该路线也是不可能的。 

## 方法

 暴力解释是枚举访问相关点的所有可能排列，从 0 开始，到 X 结束，并确保仅在访问 Z 后才交叉 Y。 对于每个排序，我们都会模拟路径并计算行驶的总距离，拒绝无效的距离。 

这是有效的，因为相关点的数量很少，因此只有很少的排列。 然而，即使在这种微小的情况下，强力推理也是不必要的，因为结构完全受到约束：运动是线性的，唯一有意义的决定是在收集 Z 之前 Y 是否位于两个段之间。 

关键的观察结果是，墙唯一重要的方式是它严格位于 0 和 Z 之间，并且也位于 0 和 X 之间，从而在获得锤子之前强制遍历。 如果 Y 位于起点和 Z 之间，则艾伦必须在获得锤子之前穿过 Y，这是被禁止的，因此不存在有效路径。 否则，最佳路径只是从 0 到 Z 到 X 的直线距离，仅当 Y 强制在 Z 之前进行额外遍历时才进行修正。 

更具体地说，我们考虑 Y 是否阻塞了 0 和 Z 之间的路段。如果阻塞，则该旅程是不可能的。 如果没有，那么Eren可以安全地先去Z而不违反约束。 之后，墙就无关紧要了，剩下的只是到X的直线旅行。 

这将问题减少为一行上的几个间隔检查，而不是推理多个排列。

 ## 算法演练

 我们将数轴视为 0、Z 和 X 之间的线段，同时在获得锤子之前检查 Y 是否强制无效交叉。

1. 首先计算 Y 是否位于 0 和 Z 之间。这意味着 Y 在数轴上严格位于它们之间。 如果发生这种情况，艾伦就必须在到达锤子之前穿过墙壁，这是不允许的，所以答案立即不可能。 
2. 如果第一次检查通过，我们接下来考虑有效路线的总距离。 由于锤子在任何约束激活之前就可用，因此 Eren 可以直接从 0 到 Z，然后直接从 Z 到 X。 
3.总成本就是|0 - Z| + |Z - X|，因为到达 Z 后，墙就不再重要了。 
4. 返回该总和作为答案。 

为什么它有效

 该算法强制执行问题中唯一真正的约束：在访问 Z 之前不能越过 Y 处的墙。在一条线上，违反此约束的唯一方法是 Y 严格位于起点和锤子之间。 一旦到达Z，状态就变得不受限制，因此剩余的旅程是一维度量空间中的最短路径，它始终是直接距离。 任何首先绕开 Z 的替代路线只会增加距离，因为直线上的绝对距离严格满足三角不等式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

X, Y, Z = map(int, input().split())

def between(a, b, x):
    return min(a, b) < x < max(a, b)

if between(0, Z, Y):
    print(-1)
else:
    print(abs(Z) + abs(X - Z))
```该实现直接对关键可行性条件和由此产生的最优路径成本进行编码。 辅助函数`between`检查数轴上的严格排序，这是对无效早期交叉重要的唯一几何条件。 

距离公式分为两段：从 0 到 Z 和从 Z 到 X。这是正确的，因为一旦到达 Z，墙约束就会永久删除。 

一个常见的陷阱是试图在距离计算中考虑 Y。 Y 永远不会影响成本，除非它阻止对 Z 的访问，因此它不应出现在最终公式中。 

## 工作示例

 ### 示例 1

 输入：```
10 -10 1
```我们检查 Y = -10 是否位于 0 和 Z = 1 之间。事实并非如此，因为 -10 超出了该区间。 

所以我们继续计算路径 0 → 1 → 10。 

| 步骤| 职位| 行动| 距离 |
 | ---| ---| ---| ---|
 | 1 | 0 → 1 | 去锤子| 1 |
 | 2 | 1 → 10 | 前往目标| 9 |

 总距离为 10。 

这证实了墙壁是无关紧要的，因为它不会妨碍首先到达锤子。 

### 示例 2

 输入：```
20 10 -10
```我们检查 Y = 10 是否位于 0 和 Z = -10 之间。 事实并非如此，因为 10 超出了该区间。 

现在我们计算 0 → -10 → 20。 

| 步骤| 职位| 行动| 距离 |
 | ---| ---| ---| ---|
 | 1 | 0 → -10 | 去锤子| 10 | 10
 | 2 | -10 → 20 | 前往目标| 30 |

 总距离为 40。 

这表明，即使 Y 距离很远，也没关系，除非它位于到 Z 的强制路径上。

 ## 边缘情况

 一个重要的边缘情况是，当 Y 恰好位于 0 和 Z 之间但 0 和 X 之间的线段之外时。例如，如果 0 → Z 是安全的，但 X 位于 Y 的另一侧，则墙仍然无关紧要，因为它在到达 X 之前就已被破坏。在这种情况下，算法正确地忽略 Y 并仍然计算 |Z| + |X - Z|。 

另一种情况是 Z 介于 0 和 X 之间，但 Y 介于 0 和 Z 之间。例如，0、Y = 2、Z = 5、X = 10。检查检测到 Y 位于 (0, Z)，因此输出为 -1。 这与达到 Z 需要提前穿过 Y 的事实相符。 

最后一个微妙的情况是所有点都为负。 由于数轴上的排序是对称的，因此无需修改即可应用相同的区间逻辑。 例如，只要 Y 不在 0 和 Z 之间，0 → Z → X 就保持有效。
