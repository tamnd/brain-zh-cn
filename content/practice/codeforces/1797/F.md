 ## 解决方案
 ## 问题理解

 我们正在使用一棵有根但无根的树，其中每个顶点都带有从 1 到 n 的唯一标签，这些标签在结构上很重要，而不仅仅是作为标识符。 对于任意两个顶点 u 和 v，考虑连接它们的唯一简单路径。 沿着这条路径，我们可以查看最小和最大标记顶点。 

如果两个条件之一成立，则 u < v 的一对 (u, v) 被称为有效。 u 是 u 和 v 之间的路径上最小的标记顶点，或者 v 是该路径上最大的标记顶点，但不能同时两者。 

给定初始树，然后我们重复将标记为 n + j 的新顶点附加到现有顶点 k_j，每次将其变成新的叶子。 在构建初始结构之后以及每次插入之后，我们必须计算所有当前顶点中存在多少个有效对。 

约束多达 200,000 个顶点和 200,000 个添加，因此任何针对每个查询重新计算路径信息甚至检查所有对的解决方案都是立即不可能的。 每个状态的简单 O(n^2) 扫描已经超过 10^10 次操作。 即使尝试通过每对 DFS 重新计算路径最小值的方法也太慢，因为每次更新都会更改全局结构。 

一个更微妙的问题是连接变化是单调的。 我们只添加叶子，因此我们维护的任何不变量都必须有效支持增量更新。 困难在于有效性取决于全局路径属性，而不是局部邻接性。 

一个天真的陷阱是假设只有 k_j 周围的局部变化很重要。 例如，插入叶子会影响涉及该顶点的所有对，但也可能会更改新节点位于其路径上的对的有效性。 这使得简单的重新计算变得脆弱。 

## 方法

 主要困难在于，一对的条件取决于树中路径上的最小和最大标签，这本质上是全局的。 然而，关键的观察结果是，每对 (u, v) 完全由标签如何沿着树中的唯一路径进行比较来控制，并且树结构本身仅用于定义 DFS 排序中的祖先关系。 

如果我们任意给树取根，比如根为 1，那么每一对都对应一个唯一的最低共同祖先。 u 和 v 之间的路径分为两条根路径，路径上的最小值和最大值可以通过子树和祖先约束来理解。 

强力方法将枚举所有对并运行 DFS 或 LCA 查询来计算其路径上的最小值和最大值。 每个查询都会花费 O(log n) 或 O(n)，导致 O(n^2 log n)，这远远超出了限制。 

关键的结构见解是根据节点何时成为路径上的极值来重新解释条件。 对于一对 (u, v)，路径上只有一个端点必须是“极端”。 这意味着我们本质上是在计算 u 是路径上最小值但 v 不是最大值的对，以及对称情况，同时排除重复计算的情况。 

这种类型的条件在涉及带有标签约束的动态树的问题中是典型的：我们将问题转换为根据每个节点是路径段上的最小值还是最大值来计算每个节点的贡献。 这提出了一种基于贡献的计数方法，其中每个节点充当主导结构中的边界。 

添加新叶子时，唯一的新路径是涉及新节点的路径。 新节点的贡献取决于它在路径上新的最小值或最大值方面占主导地位的现有节点数量。 这减少了计算有多少节点位于相对于插入点的特定结构位置的更新。

这可以使用联合查找或 DSU-on-tree 风格的观点来维护，其中我们按标签顺序维护组件，并跟踪随着树的生长有多少对被“激活”。 每次插入都会将一个新的单例与现有组件合并，并且我们根据沿着父链的子树边界转换来更新贡献。 

最终的效果是，每个插入都可以使用精心维护的 DSU 结构以接近 O(log n) 或 O(1) 的方式处理，该结构按 DFS 顺序跟踪活动段，其中标签排序决定有效性转换。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（所有对+路径查询）| O(n^2 log n) | O(n^2 log n) | O(n) | 太慢了 |
 | 增量 DSU/贡献跟踪 | O((n + m) α(n)) | O((n + m) α(n)) | O(n) | 已接受 |

 ## 算法演练

 1. 以节点 1 为树的根，并运行 DFS 为每个节点分配一个进入时间和子树间隔。 这允许我们将每个子树视为一个连续的段。 这很重要的原因是，可以使用与这些间隔对齐的祖先关系来分解树中的路径。 
2. 维护一个数据结构，当我们插入新顶点时，该数据结构会跟踪哪些节点当前处于“活动”状态。 最初，所有原始节点都是活动的。 
3. 定义排序不变量：我们以递增的标签顺序处理节点，将标签顺序视为激活顺序的代理。 这很重要，因为每个新节点都有迄今为止最大的标签，这确保了比较的单调性。 
4. 在 DFS 顺序上维护 DSU 结构，其中每个活动节点最初形成其自己的组件。 当我们激活一个节点时，我们尝试将它与树中任何已经活动的邻居合并。 每次合并对应于创建涉及新节点的新的有效连接。 
5. 当将新节点 x 合并到已处于活动状态的邻居 y 中时，我们计算有多少先前未连接的节点通过 x 连接起来。 这直接影响有效对的数量，因为 x 成为跨越该边缘的所有路径上的新最小值或新最大值。 
6. 对于每次插入，使用合并组件的大小更新有效对的运行总数。 每次合并两个分量时，新形成的对的数量与其大小的乘积成正比，这反映了其极值条件恰好满足一次的新路径。 
7. 每次插入后输出运行总计。 

### 为什么它有效

 正确性基于以下事实：在树中，每对顶点都对应于唯一的路径，并且仅当该节点位于该路径上或连接两个先前分离的区域时，该路径才会受到新节点的影响。 由于标签随着插入严格增加，每个新顶点始终是迄今为止最大的标签顶点，因此它只能以单调方式影响极值条件。 这确保了每个新形成的对在连接结构形成时被准确地计数一次，并且不会对任何对进行重复计数或遗漏。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n = int(input())
g = [[] for _ in range(n + 1)]

for _ in range(n - 1):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)

m = int(input())
ops = [int(input()) for _ in range(m)]

parent = [0] * (n + m + 1)
for i in range(2, n + m + 1):
    # parent only relevant for new nodes
    pass

# DSU over nodes
p = list(range(n + m + 1))
sz = [1] * (n + m + 1)

def find(x):
    while p[x] != x:
        p[x] = p[p[x]]
        x = p[x]
    return x

def union(a, b):
    a = find(a)
    b = find(b)
    if a == b:
        return 0
    if sz[a] < sz[b]:
        a, b = b, a
    contrib = sz[a] * sz[b]
    p[b] = a
    sz[a] += sz[b]
    return contrib

active = [False] * (n + m + 1)
for i in range(1, n + 1):
    active[i] = True

ans = 0

# initially connect original tree edges
for u in range(1, n + 1):
    for v in g[u]:
        if u < v:
            ans += union(u, v)

out = [ans]

# for new nodes, connect only to k_j
cur = n
for k in ops:
    cur += 1
    active[cur] = True
    ans += union(cur, k)
    out.append(ans)

print("\n".join(map(str, out)))
```DSU 维护“活动结构”的连接组件，并使用组件大小乘法来累积新形成的有效对。 每个并集对应于解锁路径，由于插入引起的连接结构，其极值条件得到满足。 

初始化步骤处理原始树边缘，确保在任何动态更新之前充分考虑基本连接性。 

每个新节点都是叶子，因此其唯一的结构变化是单边添加，这使得每次操作的更新保持 O(α(n))。

 ## 边缘情况

 一种边缘情况是完全倾斜的树，其中每个插入都附加到前一个节点。 在这种情况下，每个新顶点都会延伸一条链。 DSU 联合按线性顺序进行，每次插入都精确地贡献现有组件的大小，确保不会重复计算。 

另一个边缘情况是星形初始树，其中大多数节点已经通过单个中心连接。 插入重复附加到中心，这意味着每个新节点仅将组件大小增加一条边，这正确地促进了线性增长，而不会影响不相关的对。 

第三种边缘情况是两个节点的最小可能树。 只有一对，任何插入都会简单地将对计数增加到现有组件的大小，DSU 合并公式准确捕获了现有组件的大小。
