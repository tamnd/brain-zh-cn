 ## 解决方案
 ## 问题理解

 我们需要打印一个由数字组成的对称菱形。 中间行包含的数字从`0`最多`n`，然后减少回到`0`。 上面和下面的每一行都遵循相同的模式，但最大值较小。 

例如，当`n = 3`，中心行是：```
0 1 2 3 2 1 0
```它上面的行停止于`2`:```
0 1 2 1 0
```该模式一直持续到顶行和底行，其中仅包含`0`。 

棘手的部分是格式化。 行必须使用前导空格对齐为菱形​​。 一行内的相邻数字恰好由一个空格分隔，并且行尾绝不能有尾随空格。 

约束很小，因为`n ≤ 9`。 即使是非常低效的解决方案也能在时间限制内轻松完成。 真正的挑战是实现精度，尤其是间距和对称性。 

一个常见的错误是在行尾打印多余的空格。 例如，输入：```
2
```正确的第三行是：```
0 1 2 1 0
```粗心的实施可能会产生：```
0 1 2 1 0
```带有尾随空格。 Codeforces 准确地判断比较输出，因此失败。 

另一个常见错误是错误计算缩进。 当我们向中心移动时，前导空间会减少，然后会增加。 为了`n = 2`，正确的形状是：```
    0
  0 1 0
0 1 2 1 0
  0 1 0
    0
```如果我们在每一层只打印一个前导空格而不是两个，菱形就会倾斜，因为数字本身已经在它们之间包含空格。 

第三个微妙的问题是重复峰值数。 例如，对于`n = 3`，中心行应该是：```
0 1 2 3 2 1 0
```不是：```
0 1 2 3 3 2 1 0
```递减序列必须从`i - 1`，不是来自`i`。 

## 方法

 最直接的方法是将输出视为字符网格并手动填充每个位置。 我们可以分配一个大的二维矩阵，精确计算每个数字所属的位置，然后逐行打印矩阵。 由于最大输出尺寸很小，因此可以在限制范围内轻松工作。 

这种方法的问题不在于性能，而在于不必要的复杂性。 管理字符网格内的坐标、间距和对称性会带来许多出现差一错误的机会。 

菱形的结构使观察更加清晰。 每一行完全由三件事决定：

 1.压痕量。 
2. 递增序列`0`到`i`。 
3. 递减序列`i - 1`回到`0`。 

一旦我们意识到每一行都可以作为字符串独立构建，问题就变得简单的字符串构建。 

对于行`i`:

 - 缩进是`2 * (n - i)`空间。 
- 左半部分是`0 1 2 ... i`。 
- 右半部分是`i-1 ... 1 0`。 

我们首先生成包括中间行的上半部分，然后向下镜像。 

因为输出本身包含`O(n²)`字符，任何正确的解决方案必须至少花费`O(n²)`打印它们的时间。 最优解与该下限完全匹配。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力网格构建 | O(n²) | O(n²) | 已接受 |
 | 直排施工| O(n²) | O(n) | 已接受 |

 ## 算法演练

 1.读取整数`n`。 
2. 迭代所有行索引`0`到`n`。 

每个行索引代表该行中出现的最大数字。 
3. 计算前导空格。 

行距离中心越远，需要的缩进就越多。 每个缺失的数字级别都会贡献两个空格，因为行内的数字由单个空格分隔。 
4. 构建递增序列`0`到`i`。 

这形成了该行的左半部分并包括峰值。 
5. 构建递减序列`i - 1`下降到`0`。 

我们从`i - 1`以避免重复峰值数。 
6. 连接两个序列并用单个空格连接它们。 

使用`" ".join(...)`保证正确的间距并自动避免尾随空格。 
7. 打印带有缩进的行。 
8. 对以下行重复相同的逻辑`n - 1`下降到`0`。 

这将创建菱形的下对称半部分。 

### 为什么它有效

 每行均由其最大值唯一定义`i`。 递增序列保证数字向中心增长，而递减序列随后恢复对称性。 缩进仅取决于距中间行的距离，因此行会自动对齐为菱形​​。 

由于该算法根据模式的精确数学结构构造每一行，因此每条打印行都匹配所需的输出格式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_row(i, n):
    left = [str(x) for x in range(i + 1)]
    right = [str(x) for x in range(i - 1, -1, -1)]

    row = left + right
    spaces = " " * (2 * (n - i))

    return spaces + " ".join(row)

def solve():
    n = int(input())

    for i in range(n + 1):
        print(build_row(i, n))

    for i in range(n - 1, -1, -1):
        print(build_row(i, n))

solve()
```这`build_row`函数封装了单行的结构。 分离此逻辑可以避免重复，因为上半部分和下半部分使用相同的格式规则。 

增加部分使用：```
range(i + 1)
```所以峰值`i`包括在内。 

减少部分使用：```
range(i - 1, -1, -1)
```它从峰值以下一级开始。 这可以防止重复中心值。 

缩进用途：```
2 * (n - i)
```因为每个数字位置实际上占用两个字符槽，一个用于数字，一个用于分隔空间。 

使用`" ".join(row)`比手动添加空格更安全。 它保证相邻数字之间恰好有一个空格，并且行尾没有尾随空格。 

第一个循环打印上半部分，包括中心行。 第二个循环打印镜像的下半部分。

import io

def solve():
    input = sys.stdin.readline

    def build_row(i, n):
        left = [str(x) for x in range(i + 1)]
        right = [str(x) for x in range(i - 1, -1, -1)]

        row = left + right
        spaces = " " * (2 * (n - i))

        return spaces + " ".join(row)

    n = int(input())

    out = []

    for i in range(n + 1):
        out.append(build_row(i, n))

    for i in range(n - 1, -1, -1):
        out.append(build_row(i, n))

    sys.stdout.write("\n".join(out))

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    return sys.stdout.getvalue()

 ## 边缘情况

 考虑最小可能的菱形：```
0
```该算法自然地处理这个问题。 上面的循环运行一次`i = 0`，仅产生数字`0`。 下层循环从`-1`，所以它不会执行。 无需特殊处理。 

另一个微妙的情况是避免重复的中心值。 对于输入：```
2
```中心行必须是：```
0 1 2 1 0
```施工期间：

 - 递增序列变为`0 1 2`- 递减序列变为`1 0`减少的部分从`i - 1`， 所以`2`不重复。 

间距对齐是错误的另一个常见来源。 对于输入：```
1
```顶行正好需要两个前导空格：```
  0
```公式`2 * (n - i)`给出：```
2 * (1 - 0) = 2
```正确对齐菱形。 仅使用`n - i`空格会将行移得太左并破坏菱形。
