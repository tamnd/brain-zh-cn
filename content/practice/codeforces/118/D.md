 ## 解决方案
 ## 问题理解

 我们被要求计算凯撒士兵的排列方式，其中包括给定数量的步兵和骑兵，以便不超过固定数量的同类连续站立。 具体来说，如果超过`k1`男仆出现在一排或以上`k2`骑兵连续出现，该阵容无效。 同一类型的每个士兵都是无法区分的，因此我们只关心类型的顺序，而不关心个体身份。 目标是计算以 100,000,000 为模的有效序列总数。 

输入由四个整数组成：`n1`和`n2`（步兵和骑兵的数量），以及`k1`和`k2`（最多允许连续的步兵和骑兵）。 输出是一个整数，表示所有有效阵容的计数。 

约束足够小以允许动态规划解决方案。 和`n1`和`n2`最多 100，任何具有三次复杂度的算法都有潜在风险，但二次复杂度是安全的。 自从`k1`和`k2`最多 10 个，我们可以有效地跟踪连续计数，而不会爆炸状态空间。 

当以下任一情况发生时，就会出现不明显的边缘情况：`n1`或者`n2`小于其对应的`k`。 例如，如果`n1 = 1`,`n2 = 2`,`k1 = 10`,`k2 = 1`，天真的逻辑总是试图将序列扩展到`k1`可能会产生超出可用步兵数量的序列。 另一个边缘情况是当`k1 = k2 = 1`士兵严格轮换； 缺少这一点会导致差一错误。 

## 方法

 暴力方法将生成所有长度的序列`n1 + n2`恰好与`n1`男仆和`n2`骑士，然后过滤掉违反连续限制的序列。 这是正确的，但不可行。 序列数就是二项式系数`C(n1 + n2, n1)`生长速度极快； 为了`n1 = n2 = 100`，这是一个天文数字，大约是 10^58，远远超出了任何计算能力。 

关键的见解是这个问题具有重叠的子问题和清晰的递归结构。 考虑从左到右构建有效的序列。 如果最后一组是步兵，我们就知道已经放置了多少个连续的步兵。 下一个士兵可以继续这个小组（如果我们还没有达到`k1`）或切换到骑兵。 这自然适合动态规划。 我们定义`dp[f][h][last]`作为有效序列的数量，使用`f`男仆和`h`骑兵，以连续的长度组结束`last`当前类型的。 我们只需要跟踪正在扩展的类型的连续计数，并且我们递归地在步兵和骑兵之间交替。 

通过记住这些子问题，我们将指数暴力复杂度降低到可管理的立方 DP`O(n1 * n2 * max(k1, k2))`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(C(n1+n2, n1)) | O(C(n1+n2, n1)) | O(n1+n2) | O(n1+n2) | 太慢了 |
 | 最佳| O(n1 * n2 * 最大值(k1, k2)) | O(n1 * n2 * 2) | 已接受 |

 ## 算法演练

 1.初始化3D DP数组`dp[f][h][t]`， 在哪里`f`剩下的步兵，`h`剩下的骑兵，以及`t`指示最后添加的士兵是步兵 (0) 还是骑兵 (1)。 每个条目存储该状态的有效序列数。 
2. 基本情况是当`f = 0`或者`h = 0`。 如果`f = 0`，我们最多只能添加长度为的骑兵序列`k2`，类似地对于`h = 0`与男仆。 我们为每种士兵类型初始化长度为 1 的序列。 
3.对于每个DP状态`(f, h, t)`，如果没有超出连续限制，请考虑用相同类型扩展序列，或者切换到其他类型。 累积所有有效扩展的计数。 
4. 迭代所有可能的连续士兵数，直到`k1`对于男仆和`k2`对于骑兵来说，在扩展序列时，要考虑以不同连续长度结尾的序列。 
5. 填充DP后，将恰好对应的所有状态求和`n1`男仆和`n2`骑兵，以步兵或骑兵结束。 
6. 返回对 100,000,000 取模的结果。 

这样做的原因是 DP 状态完全捕获了子问题：剩余士兵和最后一个连续组的类型/长度。 每个有效序列都可以通过根据规则添加步兵或骑兵来构造。 不存在重复计算，也不遗漏任何顺序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 100000000

def solve():
    n1, n2, k1, k2 = map(int, input().split())
    
    # dp[f][h][t] = number of sequences with f footmen, h horsemen, last type t
    dp = [[[0, 0] for _ in range(n2+1)] for _ in range(n1+1)]
    
    dp[1][0][0] = 1  # first soldier is footman
    dp[0][1][1] = 1  # first soldier is horseman
    
    for f in range(n1+1):
        for h in range(n2+1):
            # add footmen
            for l in range(1, k1+1):
                if f >= l:
                    dp[f][h][0] += dp[f-l][h][1]
                    dp[f][h][0] %= MOD
            # add horsemen
            for l in range(1, k2+1):
                if h >= l:
                    dp[f][h][1] += dp[f][h-l][0]
                    dp[f][h][1] %= MOD
    
    result = (dp[n1][n2][0] + dp[n1][n2][1]) % MOD
    print(result)

solve()
```在此实现中，我们预填充了这两种类型的第一个士兵箱。 嵌套循环处理所有可能的连续长度直至极限`k1`和`k2`。 每个 DP 条目都结合了以相反类型结尾的序列的贡献，确保遵守连续约束。 模运算可防止溢出。 通过仔细的索引可以避免差一错误：`dp[f-l][h][1]`确保我们的减法永远不会低于零。

 | 测量 | 复杂性 | 说明|
