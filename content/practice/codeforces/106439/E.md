 ## 解决方案
 ## 问题理解

 任务是建立一个长度为正整数的数组`n`满足每对相邻对之间的本地规则。 对于每个位置`i`，值在`i`必须准确留下余数`1`除以下一个值时。 在所有有效数组中，我们需要字典顺序最小的数组，这意味着两个数组不同的第一个位置应包含所选数组中较小的值。 

输入包含多个测试用例。 每个测试用例仅给出所需的数组长度。 输出是该长度的构造序列。 约束允许最多`10^5`测试用例和所有测试用例的总长度最多为`5 * 10^5`，因此每个元素花费超过线性时间的算法是不必要的。 二次方法，例如为每个位置尝试许多可能的值，将很快超出可用的操作。 

关键的边缘情况来自小除数模的异常行为。 

为了`n = 1`，没有相邻对，因此任何正整数都可以。 最小的选择是：```
Input:
1

Output:
1
```总是尝试构建递减链的粗心解决方案在这里会失败，因为没有第二个元素来约束第一个元素。 

对于较大的数组，最后一个值不能是`1`。 如果第一个位置之后的某个元素是`1`，前一个元素需要满足`x mod 1 = 1`，这是不可能的，因为每个整数模`1`是`0`。 例如：```
Input:
3
```有效答案是：```
1 3 2
```因为`1 mod 3`没有被检查，并且`3 mod 2 = 1`。 

试图独立最小化每个元素的错误方法可能会选择以以下结尾的后缀`1`，但该后缀永远不能扩展到有效的数组中。 

## 方法

 直接的暴力想法是搜索尽可能小的第一个元素，然后搜索尽可能小的第二个元素，并继续检查剩余位置是否仍然可以被填充。 这在逻辑上是正确的，因为字典顺序是从左到右决定的。 然而，候选值的固定范围并不小，探索可能性很快就会变得昂贵。 长度可达`5 * 10^5`，即使是适度的分支搜索也是不可能的。 

有用的观察来自于模条件本身。 对于第一个位置之后的每个位置，下一个值不能是`1`，所以每个元素来自`a2`以后至少是`2`。 如果两个数字都在`x mod y = 1`至少是`2`， 然后`x`必须大于`y`，因为较小的数除以较大的数后不能有非零余数。 

这意味着后缀`a2, a3, ..., an`必须始终严格递减。 最后可能的最小值为`2`， 因为`1`是被禁止的。 一次`an = 2`是固定的，最小的有效先前值是`3`， 然后`4`， 等等。 

第一个元素很特别。 它不必大于第二个元素，因为它只需要满足模数规则`a2`。 最小可能的第一个值是`1`， 和`1 mod anything greater than 1`总是`1`。 因此，最佳施工开始于`1`然后放置递减序列`n`下降到`2`。 

最终的数组是：```
1, n, n-1, ..., 2
```该构造直接给出了尽可能小的前缀和尽可能小的有效后缀。

 ## 算法演练

 1.读取长度`n`所需的数组。 

构造仅取决于大小，因此不需要额外的搜索或预处理。 
2. 放置`1`作为第一个元素。 

这是可能的最小正整数。 由于下一个元素至少是`2`，条件`1 mod a2 = 1`就自动满足了。 
3. 附加来自以下位置的所有数字`n`下降到`2`。 

这将创建一个严格递减的后缀。 该后缀中的每个相邻对都具有以下形式`x`其次是`x - 1`。 自从`x mod (x - 1) = 1`，每个转换都是有效的。 
4. 输出构建的序列。 

为什么它有效：

 从第二个元素开始的后缀必须严格递减，因此它的最小可能值恰好是`n, n-1, ..., 2`。 某个位置的任何较小的值都会强制重复或需要使用`1`，不能出现在后缀中。 第一个值可以独立减少到`1`，并且有效数组不能以较小的正整数开头。 因此，从字典顺序上看，结构是最小的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        cur = [1]
        for x in range(n, 1, -1):
            cur.append(x)
        ans.append(" ".join(map(str, cur)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```代码首先读取所有测试用例并独立构建每个答案。 该列表开头为`1`因为第一个位置与序列的其余部分具有不同的作用。 

循环附加来自的值`n`下降到`2`。 正好有`n - 1`迭代，因此生成的序列具有所需的长度。 降序还可以避免最终元素周围出现任何相差一的错误，因为循环在到达之前恰好停止`1`，不能出现在后缀中。 

Python 整数在这里没有溢出问题，因为最大生成值仅为`5 * 10^5`。

```该迹线证实了第一个元素之后的每个转换都在连续递减的数字之间的不变量。

 ## 边缘情况

 对于单元素情况：```
Input:
1
```该算法输出：```
1
```没有相邻对，因此任何模条件都不会失败。 选择`1`按字典顺序是最小的。 

对于后缀值为`1`可能看起来很有吸引力：```
Input:
3
```该算法创建：```
1 3 2
```第二个元素是`3`， 不是`1`，因为第一个之后的任何元素都不能`1`。 检查内容是：```
1 mod 3 = 1
3 mod 2 = 1
```该构造避免了某些先前值需要满足模数的无效情况`1`。 

对于一个更大的例子：```
Input:
6
```该算法产生：```
1 6 5 4 3 2
```后缀是严格递减的，第一个位置之后的每一对都由连续的数字组成。 对于任意整数`k > 1`,`(k + 1) mod k = 1`，因此所有必需的转换都是有效的。 第一个值保持最小，这保留了词典编排的最优性。
