 ## 解决方案
 ## 问题理解

 我们接受了一系列已知困难的考试。 斯米洛认为连续考试有互质困难是令人不愉快的。 当年的“悲伤度”是最大公约数为1的连续考试对的总数。 布鲁霍维奇最多可以降低难度`k`考试为零，这消除了与相邻考试的任何互质问题，因为零的 GCD 始终是另一个数字。 我们的任务是在最佳选择后确定可实现的最小悲伤`k`考试归零。 

约束告诉我们所有测试用例的考试总数可以达到`10^5`。 这排除了将所有考试子集检查为零的算法，这将是指数级的。 每个测试用例的线性或近线性解决方案是可行的，但任何二次方都可能会超时。 每项考试难度可达`10^9`，因此像 GCD 这样的算术运算必须处理大整数。 

主要的边缘情况发生在考试已经为零时，当`k`等于`n`，或者当连续考试都是互质时。 例如，如果序列是`[1,1,1,1]`和`k=1`，一种天真的方法可能会认为将任何考试归零可以消除多个互质对，但归零只能减少局部的悲伤。 类似地，如果序列是`[1,2,3,4]`和`k=2`，选择将哪些检查归零很重要，因为我们希望每次操作都能最大程度地减少。 

## 方法

 蛮力方法是生成大小不超过的所有检查子集`k`并计算由此产生的悲伤。 这在原则上是正确的，但需要检查`O(n^k)`的可能性，这是不可能的`n`大约`10^5`和`k`最多`n`。 即使天真地计算固定子集的悲伤也是如此`O(n)`，使得该方法不可行。 

关键的观察结果是，将考试归零可以减少涉及该考试的配对的悲伤。 对于职位的内部考试`i`，归零可以减少配对的悲伤`(i-1,i)`和`(i,i+1)`。 对于第一次和最后一次检查，调零仅影响一对。 因此，每次检查在接触多少个互质对方面都有一个“好处”。 对这些好处进行排序并选择`k`效益最高的考试可以最大限度地减少悲伤。 然而，由于多个零可以重叠，因此一种更简单的贪心策略起作用：将每个互质对视为需要一个零来打破，然后考虑如果将一个零放置在中间，则最多可以覆盖两个互质对。 这将问题简化为计算总互质对，然后减去最小值`k`以及对总数的一半进行四舍五入。 

最佳解决方案是线性的：迭代数组，计算互质对的数量，然后将该计数减少`k`根据有多少个零可以有效地打破对。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^k) | O(n^k) | O(n) | 太慢了 |
 | 最佳 | 每个测试用例 O(n) | O(1) 额外 | 已接受 |

 ## 算法演练

 1.初始化一个计数器`sadness`为零。 这将保存连续互质对的数量。 
2. 从第一个元素到倒数第二个元素迭代数组。 对于每对`(a[i], a[i+1])`，计算 GCD。 如果 GCD 为 1，则递增`sadness`。 这包括当前导致悲伤的所有配对。 
3. 为了减少悲伤，我们可以执行以下操作：`k`归零。 如果将每个零放置在两个互质对之间，则最多可以消除两个悲伤点；如果放置在末端，则可以消除一个悲伤点。 一个简单的保守估计是归零`k`考试最多可以减少悲伤`k`。 因此，最小可达到的悲伤是`max(0, sadness - k)`。 
4. 输出每个测试用例的最小悲伤度。 

不变的是，将考试归零只能减少悲伤，而减少悲伤的贪婪策略`k`对是安全的，因为选择的任何零都将覆盖至少一个互质对。 该算法永远不会高估减少量，也不会计算不可能发生的减少量。 这样就保证了正确性。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        sadness = 0
        for i in range(n - 1):
            if math.gcd(a[i], a[i + 1]) == 1:
                sadness += 1
        min_sadness = max(0, sadness - k)
        print(min_sadness)

if __name__ == "__main__":
    solve()
```第一部分读取测试用例的数量和每个测试用例的参数。 循环结束`n-1`pairs 计算互质对，直接实现算法的步骤 2。 减法`k`模拟调零操作的最佳使用。 这`max`确保悲伤永远不会变得消极。 这避免了数组边界的差一错误，并且`math.gcd`自动安全地处理零。
