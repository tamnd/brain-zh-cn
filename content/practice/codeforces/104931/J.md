 ## 解决方案
 ## 问题理解

 我们把虾放在$n \times m$网格，其中每个单元格可以包含虾或为空。 每个配置只是一个二进制矩阵。 

烧烤有一个规则，仅在每个本地激活$2 \times 2$子网格。 如果在任何这样的内部$2 \times 2$方块中虾的数量为奇数，该方块会导致燃烧事件。 问题不是模拟燃烧，而是计算有多少整个网格配置包含至少一个$2 \times 2$具有奇校验的子网格。 

所以任务是纯粹的组合：计算所有大小的二进制网格$n \times m$至少在一个方面违反了奇偶条件$2 \times 2$正方形。 

输入大小可达$2000 \times 2000$，因此网格最多可以包含 400 万个单元。 对所有网格进行强力枚举将涉及$2^{4 \cdot 10^6}$州，这是完全不可能的。 甚至检查单个配置成本$O(nm)$，因此任何迭代所有网格的方法都会立即被排除。 

一个稍微微妙的失败案例来自于尝试对待每一个$2 \times 2$独立。 这些子网格严重重叠，因此在本地选择有效模式并不能保证全局一致性。 

例如，在一个$2 \times 3$网格中，第 1-2 列和第 2-3 列的约束共享中间列。 贪婪或本地计数方法会过度计数，因为它会重复计算共享结构。 

相反，正确的方法必须描述网格的全局结构，其中每个$2 \times 2$子网格具有偶校验，然后从整个空间中减去。 

## 方法

 我们从最直接的想法出发。 有$2^{nm}$填充网格的方法。 对于每一个，我们都可以扫描所有$(n-1)(m-1)$子网格并检查是否有奇数和。 这是正确的，但太慢了：生成所有网格已经花费了指数时间，甚至单个检查也是二次的。 

因此，我们不是直接计算“坏”网格，而是将问题倒置。 我们计算补集：没有的网格$2 \times 2$子网格的总和为奇数。 这些正是每个配置$2 \times 2$块具有偶校验。 

这个条件极其严格。 采取任何$2 \times 2$堵塞：$$a_{i,j} \oplus a_{i,j+1} \oplus a_{i+1,j} \oplus a_{i+1,j+1} = 0$$重新排列给出：$$a_{i+1,j+1} = a_{i,j} \oplus a_{i,j+1} \oplus a_{i+1,j}$$这意味着一旦我们修复了第一行和第一列，整个网格就会被强制。 每个其他单元格都可以逐步计算。 

更结构化的看待它的方式是网格必须满足 XOR 上的线性系统。 解空间正好有$n + m - 1$自由度：选择第一行第一列中的所有值，其中$a_{1,1}$共享。 

所以“安全”网格的数量（没有奇数）$2 \times 2$） 是$2^{n+m-1}$。 其他一切都是有效的答案。 

因此所需的计数为：$$2^{nm} - 2^{n+m-1}$$计算模数$998244353$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举|$O(2^{nm} \cdot nm)$|$O(nm)$| 太慢了|
 | 结构异或计数 |$O(\log(nm))$|$O(1)$| 已接受 |

 ## 算法演练

 1.计算size的二值网格总数$n \times m$，即$2^{nm}$。 这代表了所有可能的虾放置方式，没有限制。 
2. 计算每个网格的数量$2 \times 2$子网格具有偶校验，即$2^{n+m-1}$。 这是因为一旦选择了第一行和第一列，所有其他单元格都由 XOR 约束唯一确定。 
3. 从总计数中减去约束计数，以隔离包含至少一个违规的配置$2 \times 2$子网格。 这给出了$2^{nm} - 2^{n+m-1}$。 
4. 执行所有求模求幂$998244353$，因为数字呈指数增长，并且必须在整个计算过程中减少。 

关键的计算工具是快速求幂，因为两个指数都可以高达 400 万。 

### 为什么它有效

 对每一个的约束$2 \times 2$块通过 XOR 强制执行在整个网格中传播的线性关系。 一旦第一行和第一列被固定，每个剩余的单元格都会受到先前确定的值的强制。 这消除了所有自由，除了$n + m - 1$独立的位，因此有效网格的空间正是该维度的向量空间。 对配置进行计数就变成对这些自由变量的二进制赋值进行计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, e):
    res = 1
    a %= MOD
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    n, m = map(int, input().split())
    
    total = modpow(2, n * m)
    safe = modpow(2, n + m - 1)
    
    ans = (total - safe) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```该实现完全依赖于模幂运算。 第一个调用计算完整的配置空间，而第二个调用计算由 XOR 一致性定义的结构化子空间。 减法取模$998244353$，因此最终调整确保非负性。 

一个常见的错误是尝试迭代网格或在本地模拟约束。 正确的观点是全局线性结构，而不是局部检查。

 ## 边缘情况

 关键的边缘情况是最小的有效网格$2 \times 2$。 在这种情况下，恰好有一个$2 \times 2$子网格，因此问题简化为计算二进制矩阵，其中所有四个单元格的异或都是奇数。 公式给出$16 - 8 = 8$，与直接枚举匹配。 

对于一个$2 \times m$网格，结构简化但仍然遵循相同的规则。 每增加一列，就会在整个空间中增加一个自由度，但在安全空间中只增加一个约束。 该公式一致地处理这个问题，因为它仅依赖于指数算术。 

对于像这样的大网格$2000 \times 2000$, 指数$nm$变得非常大，但模幂可以在对数时间内处理它。 正确性不取决于大小，仅取决于约束空间的代数结构。
