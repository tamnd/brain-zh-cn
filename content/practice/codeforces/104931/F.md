 ## 解决方案
 ## 问题理解

 舞池是一个矩形网格，其中每个单元格包含一个处于正常方向或翻转方向的人。 我们希望通过多次应用特定操作将整个网格转换为全零。 

通过选择位置处的单元格来选择一项操作$(R, C)$。 该操作从左上角切换子矩形中的每个单元格$(1,1)$下降到$(R,C)$。 该矩形中的每个单元格都会翻转状态：0 变为 1，1 变为 0。任务是最小化需要的此类前缀矩形切换次数，以便整个网格变为零。 

关键约束是网格大小最多$3000 \times 3000$，这意味着多达 900 万个细胞。 任何尝试在完整子矩阵上简单地模拟每个操作的解决方案都会太慢。 甚至$O(NM\min(N,M))$是边界，因此解决方案必须在基本上线性的时间内处理网格。 

当网格已经全为零时，会出现微妙的边缘情况。 总是对每个非零单元执行至少一个操作的粗心方法可能会错误地返回肯定答案。 另一个棘手的情况是单行或单列，贪婪选择以链式方式交互，例如：

 输入：```
1 4
1 0 1 0
```正确答案是 2。一个幼稚的局部翻转策略可能会尝试独立地修复每个单元格并过度计算操作，因为每个操作都会影响所有先前的位置。 

主要挑战是每个操作都会影响两个维度的前缀，这会创建每个单元不独立的 2D 依赖结构。 

## 方法

 一个蛮力的想法是直接模拟这个过程。 在每一步中，我们扫描网格并找到当前为 1 的某个单元格，然后在该单元格上应用操作，翻转整个前缀矩形。 这是正确的，因为最终每个 1 都必须通过包含在某些选定的前缀中来删除。 然而，每个操作最多可以触及$O(NM)$细胞，我们最多可以申请$O(NM)$最坏情况下的操作。 这导致$O(N^2 M^2)$，这是完全不可行的。 

关键的观察是扭转视角。 不要考虑操作，而是考虑每个单元如何受到不同位置选择的操作的影响。 一个细胞$(i,j)$由在位置选择的所有操作精确切换$(R,C)$这样$R \ge i$和$C \ge j$。 这是一个经典的2D前缀优势结构。 

如果我们从右下角到左上角处理网格，那么当我们决定单元格的值时，所有影响它的来自下方或右侧的操作都已经确定。 这使我们能够贪婪地决定是否需要一个新的操作$(i,j)$基于已经应用的翻转的奇偶性。 

我们维护 2D 奇偶校验结构，但我们不会将其显式存储为完整网格。 相反，我们使用反向前缀积累的想法来传播影响力。 本质上的简化是，当我们在细胞中时$(i,j)$，确定其最终值的唯一方法是决定是否在$(i,j)$本身，因为这是最小的前缀，仅影响相对于它的左上角的单元格。 

因此，我们以相反的顺序进行处理，累积已经影响每个位置的翻转次数，并在考虑了之前的贡献后，每当当前单元格仍然为 1 时，贪婪地应用新操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟|$O(N^2 M^2)$|$O(NM)$| 太慢了|
 | 反向贪婪+差分传播|$O(NM)$|$O(NM)$或优化 | 已接受 |

 ## 算法演练

 ## 1. 将操作解释为奇偶贡献

 每个选定的操作在$(i,j)$翻转矩形中的所有单元格$[1..i] \times [1..j]$。 这意味着每个单元格的最终状态仅取决于有多少选定的操作在行索引和列索引中占主导地位。 

## 2. 从右下角到左上角处理网格

 我们迭代$i$从$N$下降到$1$， 和$j$从$M$下降到$1$。 此时，所有可能影响的细胞$(i,j)$通过未来的决策（即，位于$(i',j')$和$i' \ge i, j' \ge j$）已经决定了。 

这个方向很重要的原因是操作$(i,j)$是影响的最小矩形$(i,j)$，因此这是唯一仍然可以纠正它而不重新破坏已经固定的较大指数的本地决策。 

## 3. 维护 2D 翻转奇偶校验结构

 我们使用二维差分数组跟踪到目前为止每个单元格已翻转的次数。 我们不是直接更新矩形中的所有单元格，而是应用标准的包含-排除更新，以便前缀和恢复任何单元格的翻转计数。 

当我们“激活”一个操作时$(i,j)$，我们在矩形上加 1$[1..i] \times [1..j]$在差异数组中。 

## 4. 查询当前每个cell的奇偶校验

 在决定之前$(i,j)$，我们计算当前影响它的翻转次数。 如果当前值 XOR 累积翻转为 1，我们必须在以下位置应用新的操作：$(i,j)$。 

这是强制的，因为未来的操作（在字典顺序上较小的坐标中）不会影响该单元而不破坏已处理结构的正确性。 

## 5. 积累答案并更新结构

 如果考虑之前的翻转后单元格仍然为 1，我们将增加答案并更新差异结构以反映新操作。 

## 为什么它有效

 关键的不变量是在处理单元格时$(i,j)$，影响严格位于下方或右侧的任何单元格的所有决策都已固定，并且它们的贡献已在奇偶结构中得到充分考虑。 因此，当前计算的奇偶校验为$(i,j)$对于所有先前决定的操作而言是最终决定。 

任何新操作$(i,j)$仅影响细胞$(1..i, 1..j)$，它们要么已处理，要么包含当前单元格。 由于未来的步骤仅适用于较小的前缀，因此它们无法追溯修复错误$(i,j)$。 这使得贪婪决策局部最优且全局一致。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]

    # 2D difference array for prefix toggles
    diff = [[0] * (m + 2) for _ in range(n + 2)]

    def get(i, j):
        return (diff[i][j]
                + diff[i - 1][j]
                + diff[i][j - 1]
                - diff[i - 1][j - 1])

    ans = 0

    for i in range(n, 0, -1):
        row_acc = 0
        for j in range(m, 0, -1):
            cur = (diff[i][j]
                   + diff[i + 1][j]
                   + diff[i][j + 1]
                   - diff[i + 1][j + 1])

            val = grid[i - 1][j - 1]
            cur %= 2

            if (val + cur) % 2 == 1:
                ans += 1
                diff[i][j] += 1
                diff[i][j + 1] -= 1
                diff[i + 1][j] -= 1
                diff[i + 1][j + 1] += 1

    print(ans)

if __name__ == "__main__":
    solve()
```该实现使用二维差异数组来表示前缀翻转。 每次操作在$(i,j)$使用四个角上的包含-排除将其编码为矩形更新。 

查询当前翻转奇偶校验$(i,j)$是使用差异数组上的标准 2D 前缀重建公式计算的。 网格是从右下角到左上角处理的，因此当我们决定一个单元格时，我们已经知道按所选顺序逻辑上影响它的所有操作的效果。 

一个常见的错误是忘记了差异数组索引超出了网格一步。 实现安全分配$n+2 \times m+2$以避免在应用更新时出现边界问题$i+1$或者$j+1$。

 ## 边缘情况

 一个重要的边缘情况是已经干净的网格。 在这种情况下，算法永远不会触发任何更新，因为每个单元格的奇偶校验为零，因此答案仍然为零。 这避免了由于误解第一个单元格而强制执行至少一个操作的常见错误。 

另一个边缘情况是单行。 由于每个操作都成为前缀段，因此该算法简化为从右到左的一维贪婪扫描。 从右下到左上的遍历自然会退化为这种行为，并且每次翻转都会正确地取消未来的不匹配，而不会影响已经解析的位置。 

最后的边缘情况是完全密集的网格。 该算法在 (1,1) 处仅应用一个操作，因为在处理所有单元之后，累积的奇偶校验表明单个全局前缀翻转一次性解析了整个网格，将所有切换的最佳压缩匹配到单个操作中。
