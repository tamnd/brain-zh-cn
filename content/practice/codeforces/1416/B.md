 ## 解决方案
 ## 问题理解

 我们得到一个正整数数组，并允许使用取决于第一个元素的索引的线性运算在元素对之间重新分配值。 具体来说，我们可以选择索引$i$和$j$和一个非负整数$x$并移动$x \cdot i$单位来自$a_i$到$a_j$。 目标是最多执行$3n$这些操作使所有元素相等。 问题要求要么构造这样的序列，要么报告不可能性。 

关键约束是每个操作都必须保持所有数组元素非负。 另外，数组大小$n$可以达到$10^4$并且可以有$10^4$测试用例，总和$n$跨越所有测试用例$10^4$。 这确保了算法在以下方面必须是线性或近线性的$n$每个测试用例，排除任何二次重新分布模拟。 个人价值观$a_i$可以达到$10^5$，因此整数溢出在 Python 中不是问题，但需要仔细算术以确保操作遵守基于索引的乘法。 

边缘情况包括所有元素已经相等的数组，由于不可分性约束而无法均匀地重新分配元素，以及第一个元素与后面的元素相比较小，如果试图天真地传输任意数量，则无法进行某些重新分配。 

例如，输入数组`[1, 2, 3, 4, 5, 6]`无法平衡，因为总和$21$不能被整除$6$，移动指数倍数的操作无法解决这个问题。 尝试仅传输单位而不检查整除性的简单算法可能会错误地产生负数或无法检测到不可能性。 

## 方法

 暴力方法会尝试在所有对之间以小增量移动值，直到数组变得相等或者我们耗尽了$3n$运营。 这在原则上是正确的，因为每个操作都保留了总和，但对于大的情况来说它变得不可行$n$因为移动的次数可以是所有元素之和的顺序，可以达到$10^9$。 

关键的见解是，我们可以构建操作，将多余的值系统地移向第一个元素，然后将目标值从第一个元素重新分配到每个其他元素。 具体来说，我们可以使每个$a_i$通过移动足够的距离可以被它的索引整除$a_1$，然后将每个的剩余部分转移$a_i$到$a_1$，有效地将数组的总和合并到单个位置。 最后，我们将精确的平均值分散回所有元素。 这个确定性过程最多保证$3n$操作：一项是整除，一项是移动$a_1$，并分配给所有元素。 

这种结构之所以有效，是因为该操作在索引中是线性的，因此我们始终可以求解乘数$x$使余数为零$i$。 通过将问题简化为首先使元素可整除，然后重新分配，我们将潜在的指数搜索转换为线性操作序列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 最大(a_i)) | O(n) | 太慢了|
 | 贪婪再分配 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算总和$S$数组的。 如果$S$不能被整除$n$， 打印$-1$因为均衡是不可能的。 
2. 初始化一个空的操作列表。 
3. 对于每个索引$i$从$2$到$n$，检查剩余的$a_i$模数$i$。 如果不为零，则计算$x = i - (a_i \% i)$并执行操作$1 \to i$与这个$x$, 移动$x$单位来自$a_1$到$a_i$以便$a_i$可以被整除$i$。 记录一下本次操作。 
4. 对于每个$i$从$2$到$n$，现在$a_i$可以整除$i$, 计算$x = a_i // i$并执行操作$i \to 1$与这个$x$，将整个可整除部分转移到$a_1$。 记录一下本次操作。 
5. 此时，$a_1$包含总和以及所有其他$a_i$为零。 计算目标值$t = S // n$。 对于每个$i$从$2$到$n$，执行操作$1 \to i$和$x = t$将最终的相等值分配给每个元素。 记录每次操作。 
6. 打印操作数和操作本身。 

此过程保证所有元素相等$t$并且最多使用$3n$操作：一种用于可分性调整，一种用于合并，一种用于每个元素的分配。 

为什么有效：由于索引乘法传输，操作保留了总和并允许精确控制可除单位。 每个元素都以其索引的整数倍增加或减少，确保合并和重新分配步骤不会产生小数或负值。 模步骤保证在使其可整除时不会有任何元素变为负值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total = sum(a)
        if total % n != 0:
            print(-1)
            continue
        ops = []
        target = total // n
        # Step 1: Make all a[i] divisible by i using a[0]
        for i in range(1, n):
            rem = a[i] % (i + 1)
            if rem != 0:
                x = (i + 1) - rem
                a[0] -= x
                a[i] += x
                ops.append((1, i + 1, x))
            # Now transfer a[i] to a[0]
            x = a[i] // (i + 1)
            a[i] -= x * (i + 1)
            a[0] += x * (i + 1)
            if x > 0:
                ops.append((i + 1, 1, x))
        # Step 2: Distribute target from a[0]
        for i in range(1, n):
            ops.append((1, i + 1, target))
        print(len(ops))
        for op in ops:
            print(*op)

if __name__ == "__main__":
    solve()
```该解决方案首先检查整除性以检测不可能的情况，然后使每个$a_i$使用来自的传输可以除以它的索引$a_1$。 之后，它将所有可整除金额合并为$a_1$，然后将目标值传播到所有元素。 的选择$x$在这两个步骤中确保没有元素变为负值。 最后的循环始终分配平均值，尊重操作约束。 

## 工作示例

 **示例 1**：输入`[2, 16, 4, 18]`。 总和为 40，目标为 10。
