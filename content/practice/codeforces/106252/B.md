 ## 解决方案
 ## 问题理解

 我们得到了一个目标图像$n \times m$网格。 每个单元格包含一个颜色标签或零，其中零表示透明。 最终的可见图像是通过堆叠多个层产生的：在每个位置，最顶层的第一个非透明像素决定了我们看到的内容。 

我们从没有图层开始，可以重复添加新图层。 新图层要么完全填充单一颜色，要么完全透明。 创建图层后，我们可以修改其中的各个像素：我们可以将像素绘制为某种颜色$a$，或者以成本擦除它以使其透明$b$。 目标是构建一些层的堆栈，其生成的可见图像与目标网格完全匹配，同时最小化总成本。 

关键的微妙之处在于各层通过遮挡进行交互。 较高层中的像素会隐藏其下面的所有内容，除非它是透明的。 这意味着较高层中的错误可以完全覆盖下面的正确内容，因此必须仔细擦除或纠正任何使用层中的不正确像素。 

约束条件意味着最多$10^6$所有测试用例的总单元格。 这排除了任何模拟逐层构造或跨颜色或层执行每单元交互推理的解决方案。 每个测试用例的线性扫描是可以接受的。 

一些边缘情况很容易被误判。 

如果所有单元格都为零，则最佳答案为零，因为我们永远不需要引入任何彩色像素。 

如果网格中到处都包含单一颜色，假设所有单元格都是 5，那么我们要么构建一个恒定颜色层而不修复任何内容，要么手动绘制所有内容。 最佳选择仅取决于比较两种成本。 

当颜色稀疏时，会出现更微妙的失败情况。 假设一种颜色在一个巨大的网格中只出现一次。 一种幼稚的方法可能建议构建一个完整的恒定层并擦除大多数单元，但这可能比简单地直接绘制单个像素花费更多。 

关键的挑战是认识到虽然各层在空间上相互作用，但成本结构不会以需要全局排序的方式耦合不同的颜色。 

## 方法

 一个自然的第一个想法是考虑逐像素构建图像。 对于每个目标单元，我们可以想象要么将其绘制在某个层中，要么依赖于恒定层并纠正其周围的所有其他内容。 这很快就会变得昂贵，因为关于像素的每个决定都会影响其上方和下方的所有层。 任何模拟堆叠操作的尝试都会直接导致层选择和排序的组合爆炸。 

真正的简化来自于重新解释“恒定颜色层”的实际含义。 如果我们创建一个完全充满颜色的图层$c$，那么每个位置最初都显示$c$。 为了使该图层与最终图像兼容，每个不应显示的位置$c$必须使用擦除使其透明。 此要求是层本身的局部要求：该层中的像素要么贡献颜色$c$或者必须明确删除。 没有其他层可以修复该层中错误的非透明像素，而不会冒覆盖下面正确内容的风险。 

这导致了关键的分离：每种颜色都可以独立处理。 对于给定的颜色$c$，我们只关心目标网格中包含多少个单元格$c$，还有多少人没有。 我们比较处理所有出现的两种策略$c$。 要么我们从不使用专用层$c$而是单独绘制每个出现的地方，或者我们创建一个完整的恒定层$c$并删除所有不应该的位置$c$。 

由于这些选择不依赖于其他颜色，因此通过单独评估每种颜色并对最佳选择求和来获得最佳解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力分层模拟| 指数| O(纳米) | 太慢了|
 | 每颜色独立优化 | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 ## 步骤 1：计算每种颜色出现的次数

 我们扫描网格一次并计算每种颜色出现的次数。 让$k_c$表示包含颜色的单元格数量$c$。 这准确地告诉我们，如果我们避免使用该颜色的图层，则需要绘制多少像素。 

## 步骤 2：考虑不使用层的成本

 如果我们不创建专用的颜色层$c$，那么每个事件都必须单独绘制。 成本是$a \cdot k_c$。 这是纯粹的逐像素方法，没有结构优化。 

## 步骤 3：考虑使用常量层的成本

 如果我们创建一个充满颜色的完整图层$c$，我们从所有$n \cdot m$单元格设置为$c$。 每一个不该存在的细胞$c$必须擦除，否则它会错误地出现在最终图像中。 有$n \cdot m - k_c$这样的电池，所以成本变成$$a + b \cdot (nm - k_c).$$对于层的创建，第一项为零，因此只有修改才重要。 

## 步骤 4：为每种颜色选择更好的选项

 对于每种颜色，我们采取两种策略中的最小值：$$\min(a \cdot k_c,\; a + b \cdot (nm - k_c)).$$我们将网格中出现的所有颜色的值相加。 

## 步骤5：输出总和

 最终答案是所有颜色的最佳独立成本之和。 

## 为什么它有效

 恒定颜色层一旦创建就完全确定，其中的每个像素独立地贡献有用的信号或噪声。 无论其他层做什么，任何与目标图像不匹配的像素都必须明确删除。 同样，绘制单个像素不会干扰其他颜色，因为每个单元格都属于一个最终值。 

这消除了颜色之间的任何依赖性：任何层的排序都不能减少一种颜色所需的基于另一种颜色的决策的操作数量。 因此，每种颜色的成本都是独立且相加的，使得每种颜色的最小成本达到全局最优。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, m, a, b = map(int, input().split())
        cnt = {}
        nm = n * m

        for _ in range(n):
            row = list(map(int, input().split()))
            for x in row:
                cnt[x] = cnt.get(x, 0) + 1

        ans = 0
        for c, k in cnt.items():
            if c == 0:
                continue
            paint_only = a * k
            layer = a + b * (nm - k)
            ans += min(paint_only, layer)

        print(ans)

if __name__ == "__main__":
    solve()
```该实现依赖于颜色的频率图。 网格大小在概念上被扁平化为计数，避免了模拟层的任何需要。 关键的细节是单独处理零色：它代表透明度，并且不需要建设成本。 

每种颜色只贡献一个决策，根据其频率和总网格大小计算得出。 

## 工作示例

 ### 示例 1

 考虑一个$2 \times 3$网格：```
1 1 0
2 1 2
```我们有$nm = 6$。 计数为$k_1 = 3$,$k_2 = 2$,$k_0 = 1$。 

认为$a = 2$,$b = 1$。 

对于颜色 1：

 | 战略| 公式| 价值|
 | ---| ---| ---|
 | 仅油漆 |$2 \cdot 3$| 6 |
 | 层 |$2 + 1 \cdot (6 - 3)$| 5 |

 最好是5。 

对于颜色 2：

 | 战略| 公式| 价值|
 | ---| ---| ---|
 | 仅油漆 |$2 \cdot 2$| 4 |
 | 层 |$2 + 1 \cdot (6 - 2)$| 6 |

 最好是4。 

总计为$5 + 4 = 9$。 

这显示了图层如何帮助浓密的颜色，但对于稀疏的颜色却是不必要的。 

### 示例 2

 统一的网格：```
3 3
3 3
```这里$k_3 = 4$,$nm = 4$。 

对于颜色 3：

 油漆只给出$4a$，而一层给出$a + 0 = a$。 该层占主导地位，证实密集均匀区域强烈有利于恒定层。

 ## 边缘情况

 完全由零组成的网格被正确处理，因为频率图仅包含颜色 0，这在成本计算中被忽略。 不会触发任何绘画或图层创建，因此输出保持为零。 

对于大网格中的单一极其罕见的颜色，该算法比较$a \cdot k_c$和$a + b \cdot (nm - k_c)$。 自从$k_c$由于面积小，因此选择单独涂漆，从而避免了昂贵的全层施工。 

对于完全均匀的网格，层选项变得更加便宜，因为不需要擦除。 该算法通过相同的比较正确识别这一点，自动选择恒定层策略。
