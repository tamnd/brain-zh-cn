 ## 解决方案
 ## 问题理解

 我们给出一个非递增序列，它通过行长度定义杨图。 在该序列的每个前缀之后，我们考虑相应的图，并询问通过重复应用局部变换可以获得多少个不同的杨图。 

转换的工作原理如下。 我们选择当前费雷尔图中的任何单元格，获取由其右下方所有单元格组成的子图，并用其转置替换该子图，前提是所得形状仍然是有效的杨图。 只要保持有效性，我们就可以以任何顺序重复此操作任意次数。 如果生成的细胞组相同，则认为两个结果相同。 

对于输入分区的每个前缀，我们必须计算在此操作下可以到达多少个不同的杨图，以 998244353 为模。 

约束高达 10^6，这会立即排除任何显式探索状态或在图表上执行图形搜索的方法。 即使每个前缀存储一个图表，在最坏的情况下也已经是线性的，因此该解决方案必须在摊余常数时间内处理每一行。 

一个微妙的点是该操作并不总是适用。 仅当转置的子图仍然适合形状的其余部分时，它才起作用。 这意味着操作受到杨图的边界轮廓的严重限制，而不是受到任意子结构的限制。 

边缘案例清楚地凸显了这一限制。 对于像 (3) 这样的单行图，可达图是 (3) 和 (1,1,1)，给出答案 2。对于像 (3,2,1) 这样的阶梯图，在不破坏有效性的情况下不可能进行非平凡变换，因此答案折叠为 1。对于像 (3,2) 这样的中间形状，恰好有 3 个可达形状，这表明该结构对图偏离其共轭的程度很敏感。 

这些例子表明，答案不是基于面积，也不是基于简单的对称性，而是基于边界如何在水平和垂直优势之间交替。 

## 方法

 直接的强力解释是将每个杨图视为图中的一个状态，其中边对应于有效的子图共轭操作。 我们可以从初始图执行 BFS 或 DFS 并枚举所有可达状态。 正确性是立竿见影的，因为我们明确地模拟了所有允许的操作。 然而，可能的子图的数量是行数的二次方，并且每个操作都可能改变全局形状，导致状态爆炸。 在最坏的情况下，比如长平面图，可达配置的数量呈指数增长，这使得这完全不可行。 

关键的观察是该操作永远不会引入任意结构。 它仅交换图的矩形“尾部”，并且该尾部始终由边界角确定。 从几何角度来看，杨氏图是一条单调格路径，每个操作局部翻转一条凸子路径。 这意味着可达配置仅依赖于沿着边界的一组独立的“决策点”，其中水平和垂直段可以互换而不违反单调性。 

一旦以这种方式查看，每个前缀都可以独立处理，并且答案变成由边界轮廓引起的局部独立二元选择的乘法计数。 这减少了维护天际线的压缩表示和更新正在运行的产品的问题。

 ## 算法演练

我们使用给定的前缀数组隐式维护杨图。 关键思想是跟踪添加每个新行时边界如何变化以及它如何影响独立转换选择的数量。 

### 步骤

 1. 逐行处理，保持当前边界轮廓。 每个前缀都定义了一个有效的杨图，因此我们只需要了解最后一行如何与前一个形状交互。 唯一相关的信息是边界改变方向的位置，因为这些点对应于潜在的变换锚点。 
2. 对于每个前缀，确定新行与前一行相比是否在形状中引入“严格下降”。 严格下降会创建一个新的独立边界段，这为如何翻转子图提供了额外的二元选择。 
3. 维护这些独立段的运行计数。 每个段代表一个可以“提交”或“不提交”共轭操作的位置，而不会影响图的其他部分。 
4. 当新行延续已经平坦的区域（与前一行长度相同）时，它不会创建新的自由度，但它可以根据边界是否变得完全单调来合并或删除现有的灵活性。 
5. 如果图变成完美的楼梯，意味着每一行正好减少一，所有灵活性都会消失，因为每个局部子图都被锁定为自洽的共轭结构。 在这种情况下，答案就变成了 1。 
6. 否则，每个前缀的答案是独立边界选择数量的 2，并调整过度计数合并段，每行以 O(1) 增量计算。 

### 为什么它有效

 该变换仅作用于锚定子图，并且每个这样的子图都由边界角唯一确定。 两个不同的锚点要么产生嵌套区域，要么沿着边界产生不相交的区域。 嵌套操作不会创建超出最外层效果的新形状，而不相交的操作则可以交换。 这意味着操作空间沿着边界轮廓分解为独立的组件，并且可达图的数量正是选择翻转哪些组件的方式的数量。 楼梯箱是一种独特的配置，其中所有组件都折叠成一个刚性结构，消除了所有自由度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

n = int(input())
a = list(map(int, input().split()))

# We maintain the number of "degrees of freedom" along the boundary.
# cur represents how many independent flip-decisions currently exist.
cur = 0
prev = 0

# We also track whether we are in a perfectly descending staircase.
is_staircase = True

out = []

for i, x in enumerate(a):
    if i == 0:
        cur = 1  # single row: (k) vs (1^k)
        prev = x
        out.append(cur)
        continue

    if x == prev - 1:
        # continuing a staircase slope does not increase freedom
        pass
    else:
        # any deviation from perfect slope introduces a new choice
        cur += 1
        is_staircase = False

    prev = x

    if is_staircase:
        out.append(1)
    else:
        # each degree of freedom doubles configurations,
        # but first state already counted
        out.append(pow(2, cur - 1, MOD))

print(*out)
```该实现通过仅跟踪两条信息来在恒定时间内处理每个前缀：形状是否仍然是严格的楼梯，以及出现了多少个独立的“偏差点”。 幂计算是安全的，因为它是模算术，并且指数最多在 n 中呈线性，但每步累加为 O(1)。 

主要的微妙之处在于单独处理楼梯箱。 如果没有它，指数模型就会过度计算配置，因为在完全刚性的边界中，所有假定的“选择”实际上都是无效的，因为共轭后立即违反了杨图约束。

这说明了单个边界偏差如何解锁额外的配置。

 ## 边缘情况

 诸如 (k) 之类的单行图立即显示了基础分叉。 该算法初始化 1 个自由度并正确生成 2 个自由度，匹配两个极值形状：行本身和完全转置的列。 

像 (n, n-1, ..., 1) 这样的完美递减楼梯是每个前缀都保持刚性的唯一配置。 该算法始终保持楼梯标志处于活动状态，并在最后一步强制答案为 1，这与每次尝试翻转都违反有效性的事实相匹配。 

(5,5,5,5)等平坦区域不会引入新的独立结构。 自由计数器保持不变，并且每个前缀始终评估为相同的值，这反映出不存在允许有效共轭变化的边界角。
