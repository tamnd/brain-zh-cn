 ## 解决方案
 ## 问题理解

 每天都会提供一套新的租赁套装。 一个集合由两个值标识：(a_i)，它的两个相等的堆中每一个的大小，以及 (b_i)，Alice 为租用该集合而支付的金额。 爱丽丝可以租用迄今为止出现的任何一套集合，但如果她租用一套，她就会收到该套的两份副本。 

然后，Bob 会看到所有租用的堆，并可以在 Nim 游戏开始之前删除其中的任何集合。 仅当鲍勃无法将剩余头寸转变为失败头寸时，爱丽丝才会获胜。 

每天的输出是爱丽丝可以选择的集合的最大可能总租赁成本，这样，无论鲍勃移除哪堆，爱丽丝仍然获胜。 前一天的答案也是输入解码的一部分：当天的实际对是 (a_i=x_i\mathbin{\mathsf{xor}}last) 和 (b_i=y_i\mathbin{\mathsf{xor}}last)。 

官方实例有(n\le 500000)、(a_i\le10^{18})和(b_i\le10^9)，时间限制为1.5秒，内存为512MB。 重要的后果是我们无法在每次插入后重新访问所有以前的租赁集。 即使 (O(n\sqrt n)) 也太大了，而 (O(n^2)) 方法将需要大约 (2.5\cdot10^{11}) 次操作。 数字 (a_i) 适合 60 位，因此每个堆都可以看作只有 60 个坐标的向量。 这个小的固定维度是线性基础数据结构的开口。 

第一个微妙之处是租赁套装中的两份副本很重要。 具有值 (a) 的集合贡献两个相同的向量，而不是一个。 Bob 可以独立删除任一副本，因此剩余堆的子集中该向量的系数可以是 (0)、(1) 或 (2)。 这正是出现字段 (\mathbb F_3) 而不是普通二进制 XOR 的原因。 

第二个微妙之处是，租用所有有利可图的设备并不一定有效。 例如，考虑实际序列```
3
1 2
3 1
2 7
```解码后的集合是 ((a,b)=(1,2),(1,3),(1,4))，因为之前的答案是 (2,3)。 所有三个向量都是相同的。 正确答案是（2,3,4）。 第三天租用所有这三个副本将获得相同桩值的六份副本，其位数为（6），可被（3）整除，因此鲍勃可以留下亏损头寸。 一个粗心的算法，简单地将每个正租金成本相加，就会输出 (9)。 

另一个微妙的情况是重向量最初依赖于当前基础，但应该替换轻向量。 官方样本已解码值 ((1,4),(2,3),(3,10))，给出答案 (4,7,14)。 第三天，(3) 依赖于 (1) 和 (2)，但其成本 (10) 大于任一现有成本。 最优集合保留（3）和（1），对于（14）。 仅接受独立插入并永久丢弃相关向量的数据结构将错误地保留在 (7)。 

加密是另一个容易产生无声错误的来源。 XOR 必须使用先前的输出，而不是先前的输入值，并且解码后的答案必须分配给`last`在读取下一个加密对之前。 样本输入```
3
1 4
6 7
4 13
```解码为 ((1,4),(2,3),(3,10))，而不是直接显示在输入中的三对。 

## 方法

 直接的方法是保留迄今为止看到的所有租赁套装，并每天搜索爱丽丝可以安全租赁的最昂贵的收藏。 对于 (k) 个集合的集合，Bob 可以通过 (3^k) 种可能的方式选择每个集合的零个、一个或两个副本，因此检查每个可能的删除模式已经是指数级的。 即使在认识了下面的线性代数特征之后，强力实现也可以枚举可用集合的所有子集。 对于 (n=500000)，这意味着最坏情况下有 (2^{500000}) 个候选者，这是完全不可行的。 

游戏可以进一步减少的原因是这个版本的 Nim 中丢失位置的特征。 由于一次移动最多可以影响两堆，因此这是参数为 (2) 的摩尔 Nim。 对于每个二进制位位置，当包含该位的堆的数量为 (0) 模 (3) 时，位置就会丢失。 

用 60 维二进制向量表示每个桩值 (a)。 假设 Alice 租用向量 (v_1,\ldots,v_k) 的集合。 每个向量有两个副本。 如果 Bob 留下了集合 (i) 的 (c_i) 个副本，则 (c_i\in{0,1,2})，并且结果位置恰好在以下时间丢失：

 [
 \sum_{i=1}^{k} c_i v_i=0
 ]

 超过（\mathbb F_3）。 

Alice 必须阻止 Bob 对于每个非空系数选择都获得这样的零和。 该条件准确地表明 (v_1,\ldots,v_k) 与 (\mathbb F_3) 线性无关。 如果它们是相关的，则非平凡相关的系数是 (0,1,) 或 (2)，因此鲍勃可以准确选择这些副本数并获得失败的位置。 相反，如果向量是独立的，则唯一的零线性组合对每个集合都使用系数（0），这对应于删除所有桩，而Bob不允许这样做。 

于是游戏就消失了。 问题变成：

 对于输入的每个前缀，找到 (\mathbb F_3) 上相应向量的线性独立子集的最大总权重。 

这是一个加权线性拟阵问题。 拟阵通常的贪婪性质表明，可以通过考虑从高权重到低权重的元素来获得最大权重独立集。 由于输入是在线到达的，因此我们无法在每次插入后再次对整个前缀进行排序。 相反，我们动态地维护加权高斯基。 

当一个新向量遇到一个被占用的枢轴时，我们消除该枢轴。 如果新向量的权重大于当前占据枢轴的基向量，我们交换它们并继续消除位移向量。 这是最大跨度森林中交换边的线性代数模拟。 

维度最多为 60，因为 (a_i\le10^{18}<2^{60})。 因此每次插入最多执行 60 次主元消除。 三元向量可以存储为两个 60 位掩码，一个掩码用于等于 (1) 的坐标，另一个掩码用于等于 (2) 的坐标。 然后，位运算立即执行整个向量运算，而不是迭代所有坐标。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(2^n)) 或更糟 | (O(n)) | (O(n)) | 太慢了|
 | 最佳 | (O(60n)) | (O(60)) | 已接受 |

 ## 算法演练

1. 将每个堆值 (a) 解释为 (\mathbb F_3) 上的向量。 对于(a)中设置的每个二进制位，相应的坐标是(1)，而所有其他坐标是(0)。 
2. 保持最多 60 个向量的高斯基。 对于每个枢轴位置 (p)，存储一个基向量（其在 (p) 处的系数恰好为 (1)）以及该向量的租赁成本。 
3. 当新的对 ((a,b)) 到达时，首先使用之前的答案对其进行解码。 该向量最初仅包含系数 (0) 和 (1)。 
4. 找到当前向量非零的最高坐标。 这就是高斯消去法接下来要处理的枢轴。 如果没有剩余坐标，则矢量取决于当前基础并且可以被丢弃。 
5. 如果相应的主元为空，则将向量插入其中。 如果其主元系数为 (2)，则将整个向量乘以 (2)，从而交换其 (1)-掩码和 (2)-掩码。 乘以 (2) 是有效的，因为 (2\cdot2=1\pmod3)。 
6. 如果枢轴被占用，则将传入的重量与该枢轴处存储的重量进行比较。 如果传入的权重不较大，则从传入向量中消除主元并继续。 
7. 如果传入的权重较大，则交换两个向量。 较重的向量成为该枢轴处的基向量，而旧的基向量则成为被消除的向量。 答案会因两个权重之间的差异而变化。 
8. 继续，直到输入向量变为零或到达空主元。 每次成功的插入都会增加维护的总数，而每次成功的交换都会用较重的组替换较轻的选定组，而不改变跨度。 
9. 打印维护的总计并将其分配给`last`。 下一个加密输入对必须使用这个确切的值。 

中心不变量是在处理任何前缀之后，存储的基础表示该前缀中所有向量的最大权重独立子集。 高斯消除保留了跨度，而只要新向量可以替换现有的基向量，交换规则就会保留较重的成员。 由于线性独立形成拟阵，因此这些局部交换足以维持全局最大权重独立集。 然后，博弈论约简证明这些独立集合正是爱丽丝可以安全出租的集合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

BITS = 60

# For a ternary vector:
# lo has a 1 where the coefficient is 1.
# hi has a 1 where the coefficient is 2.
#
# The two masks together are a bit-sliced representation of F_3^60.

def add3(al, ah, bl, bh):
    # Coordinate-wise addition modulo 3.
    x = al ^ bl
    y = ah ^ bh

    # Output coefficient 1:
    # (0,1), (1,0), (2,2)
    nl = (x & ~y) | (ah & bh)

    # Output coefficient 2:
    # (0,2), (2,0), (1,1)
    nh = ((~(al | bl)) & y) | (al & bl)

    return nl, nh

def solve(reader=input):
    n = int(reader())

    basis_lo = [0] * BITS
    basis_hi = [0] * BITS
    basis_w = [0] * BITS

    ans = 0
    last = 0
    out = []

    for _ in range(n):
        x, y = map(int, reader().split())

        a = x ^ last
        w = y ^ last

        lo = a
        hi = 0

        while lo or hi:
            p = (lo | hi).bit_length() - 1

            # Since the basis vector at p is normalized,
            # its coefficient at p is exactly 1.
            coeff = ((lo >> p) & 1) | (((hi >> p) & 1) << 1)

            if basis_lo[p] == 0 and basis_hi[p] == 0:
                # Normalize the new pivot to 1.
                if coeff == 2:
                    lo, hi = hi, lo

                basis_lo[p] = lo
                basis_hi[p] = hi
                basis_w[p] = w
                ans += w
                break

            bw = basis_w[p]

            if w > bw:
                # The new vector must become the heavier basis vector.
                if coeff == 2:
                    lo, hi = hi, lo
                    coeff = 1

                # Replace the old basis vector.
                lo, basis_lo[p] = basis_lo[p], lo
                hi, basis_hi[p] = basis_hi[p], hi
                w, basis_w[p] = basis_w[p], w

                ans += basis_w[p] - w

                # The displaced old basis vector has pivot coefficient 1.
                # Eliminate it using the new basis vector.
                blo = basis_lo[p]
                bhi = basis_hi[p]

                # x <- x - basis[p] = x + 2*basis[p].
                lo, hi = add3(lo, hi, bhi, blo)
            else:
                blo = basis_lo[p]
                bhi = basis_hi[p]

                if coeff == 1:
                    # x <- x - b = x + 2b.
                    lo, hi = add3(lo, hi, bhi, blo)
                else:
                    # x <- x - 2b = x + b.
                    lo, hi = add3(lo, hi, blo, bhi)

        last = ans
        out.append(str(ans))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```三个基数组保存每个三元向量的两个位平面及其相关的租赁成本。 仅当两个掩码都为零时，主元才被视为空。 不需要存储原始的(a_i)，因为高斯基只需要当前的约简向量。 

这`add3`核心功能是bitset优化。 对于每个坐标，三进制数字具有编码 (0,1,2) 之一。 低掩码标识等于 (1) 的数字，而高掩码标识等于 (2) 的数字。 里面的布尔表达式`add3`对所有 60 个坐标同时实现九种模 (3) 加法。 

减法也很便宜，因为在 (\mathbb F_3) 中，减去一个向量相当于加上两倍的向量。 乘以 (2) 交换两个掩码，因此`x - basis`被实现为`add3(x, swapped_basis)`， 尽管`x - 2*basis`简直就是`add3(x, basis)`。 

输入向量可以具有主元系数(2)。 在将其安装到基础中之前，交换其两个掩模，使其枢轴系数变为（1）。 这种归一化是必要的，因为假设每个存储的基向量在其自己的主元处具有系数（1）。 

重量交换也很容易出错。 假设输入向量的权重为 (w)，现有的主元向量的权重为 (w_b)。 当 (w>w_b) 时，新向量被选中，旧向量被替换。 答案改变了 (w-w_b)，而位移向量继续以其旧权重进行高斯消去。 该代码在消除主元之前执行该交换。 

所有涉及租金成本和答案的算术都可以轻松地用 Python 整数表示。 最大答案最多是 (60\cdot10^9)，但是使用 Python 的任意精度整数也会使实现对任何中间表示大小不敏感。 

XOR 解码发生在基础运算之前，并且`last`仅在当前答案最终确定后更新。 这种排序是必需的，因为输入是使用先前的输出故意加密的。

 ## 边缘情况

 单个租赁集始终是安全的，因为它的两个相同的堆提供同一向量的零个、一个或两个副本。 非零向量不能通过系数 (1) 或 (2) 变为零，因此鲍勃不能离开失败的位置。 对于准确的输入```
1
1 5
```向量为 (1)，基增益权重为 (5)，输出为`5`。 

重复堆值是所有正租金成本求和失败的主要情况。 和```
3
1 2
4 2
