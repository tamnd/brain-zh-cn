 ## 解决方案
 ## 问题理解

 我们有 (n) 只兔子，初始权重为 (w_1,w_2,\ldots,w_n)。 在每 (k) 个早晨，恰好有一只兔子获得一个额外的重量单位。 当前体重为 (x) 的兔子赢得当天早上的战斗的概率与 (x) 成正比，因此，如果当前总重量为 (S)，则以 (x_i/S) 的概率选择兔子 (i)。 

总重量不是随机的。 它开始于

 [
 W=w_1+w_2+\cdots+w_n
 ]

 并且在每根胡萝卜之后恰好增加 1，因此在第 (t) 个胡萝卜之前，总重量为 (W+t)。 任务是找出所有 (k) 根胡萝卜被吃掉后每只兔子的预期最终重量。 

这些限制使得直接模拟不合适。 单个案例可以有 (k=10^9)，因此即使每天早上执行一次更新也可能需要十亿次操作。 在所有测试用例中，(n) 可以达到 (10^6)，因此具有 (n^2) 等因子的算法也远远超出了实际竞争编程的限制。 我们需要一个能够对每只兔子进行一次处理的公式。 

主要困难在于，每吃一根胡萝卜，选择兔子的概率就会发生变化。 粗心的解决方案可能会对每个胡萝卜使用初始概率 (w_i/W)，但这会忽略强化效果。 例如，对于权重 (1,3) 和 (k=2)，正确的预期最终权重为 (1.5,4.5)。 在这种情况下，简单地添加 (2\cdot(1/4)) 和 (2\cdot(3/4)) 就可以准确地给出这些值，但这种巧合并不能证明使用固定概率是合理的。 在第一个胡萝卜之后，权重发生了变化，因此第二个概率是随机的。 

一个更具启发性的边缘案例是一只兔子。 对于输入 (n=1,k=1,w=[5])，答案正是 (6)。 任何仍执行近似计算的概率处理都是不必要的，因为唯一的兔子必须赢得每场战斗。 更一般地，对于 (n=1)，答案必须始终是 (w_1+k)。 

等权重提供了另一种有用的检查。 对于 (n=3,k=2,w=[1,1,1])，对称性表示每只兔子必须有相同的期望。 最终总权重为(5)，所以答案为(5/3,5/3,5/3)。 仅更新当前最大的兔子或假设同一只兔子反复获胜的解决方案将违反这种对称性。 

较大的初始权重也会暴露数值错误。 假设 (n=2,k=1,w=[10^9,1])。 第一只兔子的预期增加是 (10^9/(10^9+1))，而第二只兔子的预期增加是 (1/(10^9+1))。 分母必须是当前总重量，而不是溢出窄整数类型的值或意外地被单个重量替换的值。 

## 方法

 最直接、准确的方法是考虑每一个可能的获胜者序列。 每天早上都有 (n) 个可能的获胜者，每个分支的概率取决于所有先前的获胜者。 因此，完整的获胜者序列最多具有 (n^k) 种可能性。 即使有 (n=2) 和 (k=10^9)，这也是无望的。 对每只兔子获胜次数的动态规划也不能解决根本问题，因为（n）只兔子中（k）获胜的可能分布数量是（\binom{n+k-1}{n-1}），这也是巨大的。 

一种更简单的蛮力模拟可以在 (O(k)) 运算中生成一个随机的获胜者序列，但这会计算一个样本路径，而不是问题所需的确切期望。 重复模拟只会产生近似值，并且 (k) 本身已经可以是 (10^9)。 

有用的观察是，尽管各个权重是随机的，但它们的总权重是完全确定的。 假设兔子 (i) 在 (t) 胡萝卜之后具有重量 (X_i(t))。 在下一根胡萝卜之前，总重量正好是(W+t)。 在下一场战斗中，兔子 (i) 以条件概率获得胜利

 [
 \frac{X_i(t)}{W+t}。 
]

 我们可以对其下一个权重进行条件期望：

 X_i(t)+\frac{X_i(t)}{W+t}。 
]

分母不包含随机量，因此再次取期望给出

 \left(1+\frac{1}{W+t}\right)\mathbb E[X_i(t)]。 
]

 这是关键的简化。 复杂的随机过程变成了每只兔子期望的确定性递归。 

从 (\mathbb E[X_i(0)]=w_i) 开始，重复应用递推式给出

 w_i
 \prod_{t=0}^{k-1}\frac{W+t+1}{W+t}。 
]

 产品望远镜：

 \frac{W+k}{W}。 
]

 因此最终的预期重量就是

 [
 \boxed{\mathbb E[X_i(k)] = w_i\frac{W+k}{W}}。 
]

 蛮力方法之所以有效，是因为它遵循实际的随机过程，但它会失败，因为可能的历史数量巨大。 总重量是确定性的观察结果让我们一次一步地进行期望，并且由此产生的递归折叠成一个伸缩产品。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(n^k)) 历史 | 每个状态 (O(n)) | 太慢了|
 | 随机模拟| 每次模拟 (O(k)) | (O(n)) | (O(n)) | 没有给出确切的期望|
 | 最佳 | 每个案例 (O(n)) | (O(n)) | (O(n)) | 已接受 |

 ## 算法演练

 1. 读取兔子的数量、胡萝卜的数量 (k) 以及所有初始重量。 计算它们的总和 (W)，因为 (t) 根胡萝卜之后的总重量始终为 (W+t)。 
2. 计算公共乘数

 [
 M=\frac{W+k}{W}.
 ]

 这个乘数对于每只兔子都是相同的。 随机过程会影响哪只兔子收到每根胡萝卜，但不会影响预期的乘法生长因子。 

1. 对于每只兔子 (i)，输出

 [
 w_iM。 
]

 无需模拟任何早晨或维持不断变化的权重，因为循环已经考虑了每个可能的获胜序列。 

1. 打印具有足够小数精度的值，例如小数点后十位数字。 要求的误差是(10^{-4})，所以普通的双精度浮点运算就足够了。 

### 为什么它有效

 令 (X_i(t)) 为兔子 (i) 除去 (t) 胡萝卜后的重量。 此时的总重量是确定的（W+t）。 以 (X_i(t)) 为条件，兔子 (i) 收到下一个胡萝卜的概率为 (X_i(t)/(W+t))。 因此，

 X_i(t)\frac{W+t+1}{W+t}。 
]

 对 (\mathbb E[X_i(t)]) 取期望给出相同的乘法因子。 从(w_i)开始，所有因子收缩，留下(w_i(W+k)/W)。 由于该方程直接从每个单独步骤的条件期望得出，因此它精确地而不是近似地解释了每个可能的获胜者序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    out = []

    for _ in range(t):
        n, k = map(int, input().split())
        w = list(map(int, input().split()))

        total = sum(w)
        factor = (total + k) / total

        out.append(" ".join(f"{x * factor:.10f}" for x in w))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```代码首先计算`total`，这是初始组合权重（W）。 因为每天正好消耗一根重量为 1 的胡萝卜，所以所有 (k) 天后的总重量为 (W+k)。 

表达式`(total + k) / total`直接计算伸缩积。 一次计算一个因子的乘积需要 (k) 次迭代，这违背了推导的目的。 

每个初始权重乘以相同的因子。 乘法作为浮点运算执行，因为所需的输出是实数。 

Python 整数可以安全地处理总重量中可能较大的值。 最大可能的初始总数是 (10^5\cdot10^9=10^{14})，并且相加 (10^9) 也完全在 Python 的精确整数范围内。 最终转换为浮点对于所需的 (10^{-4}) 容错来说是安全的。 

该代码在计算总和后对每个权重只处理一次，从而给出兔子数量的线性功。

 ### 示例 1

 第一个样本箱有一只重量为 (2) 的兔子和一根胡萝卜。 

初始总数为(W=2)。 由于只有一只兔子，它收到胡萝卜的概率为 1。 公式给出

 [
 2\cdot\frac{2+1}{2}=3。 
]

 | 初始| 2 | 1 | (3/2) | 2 |

 结果是`3.00000000`。 此示例证实了 (n=1) 边界情况。 当获胜者是确定性的时，该公式不会引入任何人为随机性。

 第二个示例案例有两只重量为 (1,3) 的兔子和两根胡萝卜。

 ## 边缘情况

 单兔子的情况是完全确定性的。 用于输入```
1
1 1
5
```我们有 (W=5) 和 (k=1)，所以乘数是 (6/5)。 结果是 (5\cdot6/5=6)。 对于 (k=10^9)，同样的推理给出 (5+10^9)。 该算法从不尝试对不存在的概率分布进行建模。 

相同的重量要求期望保持相同，因为兔子是可以互换的。 为了```
1
3 2
1 1 1
```总数从 (3) 开始，最终总数为 (5)，每只兔子都获得乘数 (5/3)。 每只兔子的输出是 (5/3)。 各个执行可能会产生诸如 ((3,1,1)) 或 ((2,2,1)) 之类的权重，但它们的预期值是相同的。 

一根胡萝卜的情况是可以直接检查复发的情况。 为了```
1
2 1
2 3
```总数为 (5)。 兔子一获胜的概率为（2/5），因此它的预期最终重量为（2+2/5=2.4）。 兔子两次获胜的概率为 (3/5)，即 (3+3/5=3.6)。 该公式产生 (2\cdot6/5=2.4) 和 (3\cdot6/5=3.6)，与直接计算完全匹配。 

非常大的 (k) 一定不会导致早上出现循环。 为了```
1
2 1000000000
1 1
```初始总数为 (2)，因此乘数为 (1000000002/2=500000001)。 两只兔子都预期最终重量 (500000001)。 该算法立即获得此结果，而模拟则需要十亿次迭代。 

最后，预期权重必须始终等于确定性的最终总和 (W+k)。 对于任何输入，对公式求和得出

 # \frac{W+k}{W}\sum_i w_i

 W+k。 
]

 此恒等式是一种有用的调试检查，因为意外使用不同分母或错误更新乘数的实现通常会违反它。
