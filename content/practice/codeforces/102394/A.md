 ## 解决方案
 ## 问题理解

 我们有一排 (N) 个立方体，每个立方体要么被涂漆，要么保持原样。 类型 1 规则要求在特定区间 ([L,R]) 内至少有 (K) 个绘制的立方体。 类型 2 规则要求至少 (K) 个在该间隔之外绘制的立方体。 

目标不是明确地构建一幅画。 我们只需要满足每个规则的最小可能数量的着色立方体。 官方问题有(N\le 3000)、(M_1,M_2\le3000)，所有测试用例上这些数量的总和也最多为(3000)。 原问题有 1 秒时间限制和 512 MB 内存限制。 

自然的表示是前缀和。 令 (S_i) 为位置 (1,\ldots,i) 之间绘制的立方体的数量。 然后绘制位置 (i) 对应于将前缀和增加零或一：

 [
 0\le S_i-S_{i-1}\le1。 
]

 对于类型 1 规则，([L,R]) 中绘制的数字为 (S_R-S_{L-1})，因此规则变为

 [
 S_R-S_{L-1}\ge K.
 ]

 对于类型 2 规则，([L,R]) 外部绘制的数字为

 [
 S_N-(S_R-S_{L-1}),
 ]

 所以规则就变成了

 [
 S_N-(S_R-S_{L-1})\ge K.
 ]

 麻烦的部分是（S_N），因为它本身就是我们想要最小化的数量。 一旦（S_N）固定为某个值（X），每个约束就变成只涉及两个前缀和的差异约束。 这是中心观察。 

大小 (N=3000) 排除了 (N) 中的任何指数。 即使枚举所有绘画也需要 (2^{3000}) 个候选。 在另一个极端，(O(N^3)) 方法在最大的单一情况下已经涉及大约 (27) 十亿个基本操作，因此预期的解决方案需要利用稀疏区间结构。 可接受的方法使用 (O(\log N)) 可行性检查，每个检查都基于具有 (O(N+M_1+M_2)) 条边的稀疏图。 

有几种边缘情况很容易被错误处理。 如果根本没有规则，答案就是零，因为任何绘画都是无效的。 例如，```
1
1 0 0
```有答案```
0
```总是绘制至少一个立方体的粗心实现将立即失败。 

一条规则可以有（K=0），这对绘画没有实际要求。 例如，```
1
3 1 0
1 3 0
```有答案```
0
```在这种情况下，前缀和不等式必须允许相等。 

边界 (L=1) 和 (R=N) 也很重要，因为它们涉及 (S_0) 或 (S_N)。 例如，```
1
1 1 0
1 1 1
```要求对立方体 1 进行绘制，因此答案为 (1)。 忘记前缀位置 (S_0) 会使间隔公式变得笨拙，并且经常会引入相差一的错误。 

整个数组的类型 2 规则是另一个有用的边界情况。 它的外部集合是空的，所以它唯一有效的要求是（K=0）。 例如，```
1
3 0 1
1 3 0
```有答案（0）。 将补数视为另一个普通区间是不正确的。 

## 方法

 蛮力方法很简单。 尝试 (N) 个立方体的每个子集，计算它绘制了多少个立方体，并检查每个规则。 由于有 (2^N) 个子集并直接对照所有规则成本检查子集 (O(N+M_1+M_2))，最坏情况的工作是

 [
 O\左(2^N(N+M_1+M_2)\右)。 
]

 对于（N=3000），这大约是大情况下的（6000\cdot2^{3000}）个基本检查，这是完全不可行的。 

蛮力之所以有效，是因为每一种可能的绘画都被明确地表示出来，所以不存在正确性问题。 问题在于，有趣的结构被指数枚举隐藏了。 

第一个有用的观察是用前缀和替换各个绘制立方体的决策。 一旦 (S_i) 已知，任何区间内绘制的立方体的数量只是两个前缀和的差。 每个立方体的二元性质也可以通过简单的不等式来捕获

 [
 S_i-S_{i-1}\ge0
 ]

 和

 [
 S_i-S_{i-1}\le1。 
]

 现在假设绘制的立方体的最终数量固定为 (X=S_N)。 类型 1 规则变为

 [
 S_{L-1}-S_R\le-K。 
]

 类型 2 规则变为

 [
 S_R-S_{L-1}\le X-K。 
]

 总数由下式确定

 [
 S_N-S_0=X,
 ]

 可以用两个不等式来表示

 [
 S_N-S_0\le X
 ]

 和

 [
 S_0-S_N\le-X。 
]

 每个结果约束都有标准形式

 [
 S_v\le S_u+w。 
]

 这样的系统称为差异约束。 它们可以用权重为 (w) 的有向边 (u\to v) 表示。 可行系统没有负环，相反，如果约束图没有负环，则最短路径距离提供可行分配。 

这就留下了一个问题：我们如何找到最小的可行值（X）？ 可行性是单调的。 如果一幅带有 (X) 个已涂色立方体的绘画满足每条规则，则再涂一个未涂色的立方体。 1 类计数只能增加。 对于类型 2 规则，当新立方体位于间隔内时，在其间隔之外绘制的立方体的数量保持不变，或者当新立方体位于间隔外时增加。 因此，每一个较大数量的着色立方体也是可行的。 

因此，我们可以从 (0) 到 (N) 进行二分搜索 (X)。 对于每个候选（X），我们构建相应的差异约束图并使用 SPFA 检查它是否包含负循环。 官方社论准确地给出了这个二分搜索加上 SPFA 公式，当 (M) 表示约束数量时，其复杂度为 (O(NM\log N))。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(2^N(N+M_1+M_2))) | (O(N+M_1+M_2)) | 太慢了|
 | 二分查找+SPFA | (O(N(N+M_1+M_2)\log N)) 最坏情况 | (O(N+M_1+M_2)) | 已接受 |

 SPFA 本身具有与 Bellman-Ford 相同的 (O(VE)) 最坏情况界限，尽管基于队列的实现在此处出现的稀疏图上要快得多。 官方社论明确依赖 SPFA 对已接受的 (O(NM\log N)) 解决方案的实际修剪。 

## 算法演练

1. 将 (S_i) 定义为位置 (1) 到 (i) 之间绘制的立方体的数量。 值 (S_0) 为零，而 (S_N) 正是绘制的立方体的数量。 
2. 修正候选答案（X）。 我们暂时需要（S_N=X）。 这样做的原因是每个包含 (S_N) 的规则都成为具有恒定右侧的普通差分约束。 
3.添加两个约束
 [
 S_{i-1}-S_i\le0
 ]
 和
 [
 S_i-S_{i-1}\le1
 ]
 对于每个位置 (i)。 这些强制每个差异 (S_i-S_{i-1}) 为零或一，与未绘制或绘制的立方体完全匹配。 
4. 将每个类型 1 规则 ((L,R,K)) 转换为
 [
 S_{L-1}-S_R\le-K。 
]
 这只是原始条件 (S_R-S_{L-1}\ge K) 以及重新排列的项。 
5. 将每个类型 2 规则 ((L,R,K)) 转换为
 [
 S_R-S_{L-1}\le X-K。 
]
 从(X-(S_R-S_{L-1})\ge K)开始，这表示区间内绘制的数字不能超过(X-K)。 
6. 通过添加强制总数等于 (X)
 [
 S_N-S_0\le X
 ]
 和
 [
 S_0-S_N\le-X。 
]
 这些一起给出 (S_N-S_0=X) 和 (S_0=0)。 
7. 将每个不等式 (S_v-S_u\le w) 转换为权重为 (w) 的有向边 (u\to v)。 路径松弛的形式与原始不等式完全相同：
 [
 S_v\le S_u+w。 
]
 8. 运行 SPFA 搜索负循环。 该图包含从顶点 (0) 可到达的所有相关顶点，因为前缀和边包括从 (i-1) 到 (i) 的前向边。 如果存在负环，则候选（X）是不可能的。 如果不存在负环，则差分约束系统有解，所以(X)可行。 
9. 二分查找最小可行值（X）。 从范围 ([0,N]) 开始。 上端点始终是可行的，因为绘制每个立方体都满足输入边界允许的每个规则。 当中点可行时，搜索下半部分。 否则搜索上半部分。 

### 为什么它有效

 对于固定 (X)，该图准确地表示具有 (X) 个已绘制立方体的绘画的可能前缀和。 每幅有效的绘画都满足每个图不等式，因此它不会产生负循环。 相反，如果图没有负环，则最短路径距离满足每个差值约束，并且约束 (0\le S_i-S_{i-1}\le1) 使每个前缀差值为 ({0,1}) 中的整数。 因此，这些差异描述了一幅真实的绘画。 涉及 (S_N) 的两个约束强制其绘制的立方体总数恰好为 (X)。 由于可行性在 (X) 中是单调的，因此二分查找返回尽可能小的数字。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    input = sys.stdin.readline
    t = int(input())
    answers = []

    for _ in range(t):
        n, m1, m2 = map(int, input().split())

        type1 = [tuple(map(int, input().split())) for _ in range(m1)]
        type2 = [tuple(map(int, input().split())) for _ in range(m2)]

        def feasible(x):
            g = [[] for _ in range(n + 1)]

            # 0 <= S[i] - S[i-1] <= 1
            for i in range(1, n + 1):
                g[i].append((i - 1, 0))
                g[i - 1].append((i, 1))

            # S[L-1] - S[R] <= -K
            for l, r, k in type1:
                g[r].append((l - 1, -k))

            # S[R] - S[L-1] <= X - K
            for l, r, k in type2:
                g[l - 1].append((r, x - k))

            # S[N] - S[0] <= X
            # S[0] - S[N] <= -X
            g[0].append((n, x))
            g[n].append((0, -x))

            # SPFA, starting from 0.
            # The chain edges make every vertex reachable from 0.
            vcnt = n + 1
            dist = [0] * vcnt
            in_queue = [False] * vcnt
            relax_count = [0] * vcnt

            q = deque([0])
            in_queue[0] = True
            relax_count[0] = 1

            while q:
                u = q.popleft()
                in_queue[u] = False
                du = dist[u]

                for v, w in g[u]:
                    nd = du + w
                    if nd < dist[v]:
                        dist[v] = nd

                        if not in_queue[v]:
                            q.append(v)
                            in_queue[v] = True
                            relax_count[v] += 1

                            if relax_count[v] >= vcnt:
                                return False

            return True

        lo, hi = 0, n

        while lo < hi:
            mid = (lo + hi) // 2
            if feasible(mid):
                hi = mid
            else:
                lo = mid + 1

        answers.append(str(lo))

    return "\n".join(answers)

if __name__ == "__main__":
    sys.stdout.write(solve())
```输入是逐个读取的，并且两种约束被分开存储，因为它们的图边缘对二分搜索值（X）具有不同的依赖性。 

里面`feasible`，该图有 (N+1) 个顶点，编号从 (0) 到 (N)，直接对应于 (S_0,\ldots,S_N)。 对于每个位置，权重为 0 的边 (i\to i-1) 表示 (S_{i-1}\le S_i)，而权重为 1 的 (i-1\to i) 表示 (S_i\le S_{i-1}+1)。 它们一起强制执行二进制增量。 

类型 1 的边是`g[r].append((l - 1, -k))`。 其松弛条件为 (S_{L-1}\le S_R-K)，这正是区间所需的下界。 

类型2的边与类型1相比是相反的，其权重为`x - k`，因为固定 (S_N=X) 会将外部计数条件转换为 (S_R\le S_{L-1}+X-K)。 

最后两条边都是必要的。 仅使用`0 -> n`会给出 (S_N\le X)，同时仅使用`n -> 0`会给出 (S_N\ge X)。 他们的组合精确地确定了总数。 

如果每个顶点都被视为可达，则 SPFA 距离数组可以从全零开始，但此实现仅从顶点零开始。 这是安全的，因为前向前缀边给出了从零到每个顶点的路径。 因此，从任何顶点可到达的负循环也可以从零到达。 

松弛计数器在 SPFA 无限期继续之前检测到负循环。 在具有 (V) 个顶点且没有负环的图中，最短路径不需要包含至少 (V) 条边的重复改进路径。 顶点被松弛多次表示负循环。 

Python 整数消除了任何溢出问题。 尽管累积的最短路径距离可能为负，但涉及的最大值仅约为 (N)。 

二分查找使用`hi = n`因为绘制所有 (N) 个立方体总是满足所有规则。 输入边界保证类型 1 要求永远不会要求超过间隔长度，而类型 2 要求永远不会要求超过其补集的大小。

### 示例 2

 考虑以下情况：```

```第 1 类规则要求在位置 2 到 4 处至少有两个已着色的立方体。第 2 类规则要求在位置 2 到 4 的外部至少有一个已着色的立方体，因此位置 1 和 5 中至少之一也必须被着色。

 |`lo`|`hi`|`mid`| 候选人解读| 可行的？ |
 | ---| ---| ---| ---| ---|

 ## 边缘情况

 当没有规则时，图仅包含前缀差异约束和固定总数约束。 为了```
1
1 0 0
```候选值 (X=0) 产生 (S_0=S_1=0)，因此不存在负循环，二分查找返回零。 该算法从不假设必须至少绘制一个立方体。 

当规则具有 (K=0) 时，其图边的权重为零，并且除了前缀结构已经暗示的限制外，不施加任何附加限制。 为了```
1
3 1 0
1 3 0
```候选 (X=0) 是可行的，正确答案为零。 

对于具有类型 1 要求的单个多维数据集，```
1
1 1 0
1 1 1
```约束变为 (S_0-S_1\le-1)，而二进制前缀约束给出 (S_1-S_0\le1) 和 (S_0-S_1\le0)。 唯一可能的值是 (S_1=1)，所以答案是 1。 这直接运用了(L-1=0)边界。 

对于 2 类边界情况，```
1
