 ## 解决方案
 ## 问题理解

 我们有一个排列 (a)，其中包含从 (1) 到 (n) 的每个整数恰好一次。 对于每个前缀 (a_1,\ldots,a_i)，考虑其最大和最小值。 他们的差别是(h_i)。 任务是确定有多少种不同的排列恰好产生给定的序列 (h)，答案取模 (10^9+7)。 

关键事实是 (h_i) 仅描述当前最小值和最大值之间的间隔宽度。 它没有告诉我们哪个端点是最小值或最大值，也没有告诉我们这些端点之间的值严格出现在哪里。 因此，计数问题是关于在将每个排列元素恰好放置一次的同时，我们可以有多少种方式来增长这个区间。 

官方存档给出了1秒的时间限制和512MB的内存限制。 (n)的值可以达到(10^5)，所有测试用例的总和(n)可以达到(2\cdot10^6)。 (n) 中的二次解已经在最大聚合输入中执行大约 (10^{10}) 次运算，这远远超出了预期的限制。 甚至 (O(n\log n)) 在这里也是不必要的，因为位置 (i) 所需的信息仅取决于先前的宽度和当前未使用的内部值的数量。 目标是线性扫描。 

有几个无效的序列，粗心的实现可能会错误处理。 首先，(h_1) 必须为零，因为第一个前缀仅包含一个值，因此它的最大值和最小值相等。 例如，对于 (n=2) 和 (h=[1,1])，正确答案是 (0)。 仅从 (i=2) 开始处理而不检查 (h_1) 的实现可能会错误地接受它。 

其次，宽度永远不能减小。 一旦看到一个值，前缀最小值只能保持不变或减少，而前缀最大值只能保持不变或增加。 因此 (h_i\ge h_{i-1})。 例如，(n=3) 和 (h=[0,2,1]) 的答案为 (0)。 如果不小心将每个不相等的转换视为扩展，则会将这种不可能的减少视为另一个有效的扩展。 

第三，宽度不能超过(n-1)，因为所有排列值都位于区间([1,n])内。 例如，(n=3) 和 (h=[0,3,3]) 的答案为 (0)。 最大可能的差异是(3-1=2)。 

最后，即使序列是非递减的，平稳期也是不可能的。 考虑 (n=3) 和 (h=[0,1,1])。 第一次扩展后，前缀必须包含宽度为(1)的区间的两个端点，例如(1,2)或(2,3)。 这些端点之间严格没有未使用的值，因此第三个位置没有合法的选择。 正确答案是（0）。 对于每个相等的转换乘以某个固定数字的简单解决方案可能会错过可用内部值的缺乏。 

在另一个极端，(n=1) 和 (h=[0]) 是有效的，并且只有一个排列，即 ([1])。 这种情况很有用，因为没有过程转换，因此初始答案必须已经是 (1)。 

## 方法

 直接的方法是枚举 (1,\ldots,n) 的每个排列。 对于每个排列，从左到右扫描它，保持其前缀最大值和最小值，并将所得差异与给定的 (h) 进行比较。 这是正确的，因为每个可能的排列都被检查一次。 

问题是排列的数量。 它们有 (n!) 个，检查一个排列需要 (\Theta(n)) 时间。 因此，总复杂度为 (\Theta(n\cdot n!))。 即使在 (n=10) 时，这也已经意味着大约 (3.6\times10^7) 次前缀运算，而 (n) 允许为 (10^5)。 蛮力方法不仅速度太慢，而且无法使用。 

有用的观察是我们永远不需要知道确切的最小值和最大值。 我们只需要知道他们的距离如何变化。

假设当前前缀的宽度为(h_{i-1})。 由于前缀间隔无法缩小，因此 (h_i<h_{i-1}) 立即不可能。 

如果 (h_i>h_{i-1})，则新值 (a_i) 必须成为新的最大值或新的最小值。 这是仅有的两种可能性，因此这种转变贡献了因子 (2)。 如果宽度增长 (d=h_i-h_{i-1})，则新端点将恰好 (d-1) 个先前未见过的值严格保留在新区间内。 这些值成为宽度保持不变的位置的未来选择。 

如果(h_i=h_{i-1})，则新值不能是新的最大值或最小值。 它必须是严格在当前端点之间未使用的值。 因此，选择的数量正是未使用的内部值的数量。 

这给出了一个非常小的状态。 让`slots`是当前严格位于前缀最小值和最大值之间的未使用值的数量。 当区间扩大 (d) 时，我们添加 (d-1) 个新的内部值。 当间隔不变时，我们选择其中之一`slots`值并删除它，所以答案乘以`slots`进而`slots`减少一。 

暴力破解之所以有效，是因为每个排列都决定了端点扩展和内部布局的唯一序列。 它失败了，因为它独立地探索了所有排列。 唯一相关信息是当前宽度和未使用内部值的数量这一观察结果让我们可以同时计算共享相同历史记录的所有排列。 

由此产生的方法是：

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(n\cdot n!)) | (O(n)) | (O(n)) | 太慢了|
 | 最佳 | (O(n)) | (O(n)) | (O(n)) 对于输入数组，(O(1)) 额外 | 已接受 |

 ## 算法演练

 1. 读取 (n) 和序列 (h)。 有效的序列必须以 (h_1=0) 开头，因为第一个前缀仅包含一个值。 另外，每个（h_i）最多只能是（n-1），并且最终值必须是（n-1），因为在插入所有（n）个值之后，前缀同时包含（1）和（n）。 如果这些条件中的任何一个不成立，则答案为零。 
2. 扫描从 (i=2) 到 (n) 的序列，保持`ans`，当前状态表示的部分排列的数量，以及`slots`，未使用值的数量严格位于当前最小值和最大值之间。 
3. 如果 (h_i<h_{i-1})，则返回零。 前缀间隔只能保持不变或扩展，而不能收缩。 
4. 如果 (h_i>h_{i-1})，新元素必须扩展两个端点之一。 它可以成为新的最大值或新的最小值，恰好给出两个选择，所以乘以`ans`由（2）。 
5.设(d=h_i-h_{i-1})。 新延伸的边添加了 (d) 个宽度位置，但端点本身立即被 (a_i) 占据。 剩余的 (d-1) 值严格位于新区间内并且之前没有出现过，因此增加`slots`到(d-1)。 
6. 如果(h_i=h_{i-1})，新元素必须严格位于当前区间内。 正好有`slots`未使用的值可用，因此相乘`ans`经过`slots`并减少`slots`一个。 如果`slots`为零，任何排列都无法实现这种转变，答案就为零。 
7. 执行每个模乘法 (10^9+7)，然后打印最终答案。 

### 为什么它有效

 不变量是处理完位置(i)后，`slots`正是尚未出现在排列中且严格位于当前前缀最小值和最大值之间的值的数量。 当宽度增加时，新端点被迫为最小值或最大值，提供两种选择，并且每个新创建的内部整数都不会被使用，因为所有早期值都在旧区间内。 恰好有 (h_i-h_{i-1}-1) 个这样的值。 当宽度保持不变时，下一个值必须是这些未使用的内部值之一，并且每个此类选择都会保留当前间隔和所有先前的 (h) 值。 因此，每个有效排列都被精确地计数一次，而每个计数的转换对应于一​​个有效的位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        h = list(map(int, input().split()))

        if h[0] != 0 or h[-1] != n - 1:
            out.append("0")
            continue

        valid = True
        for i in range(1, n):
            if h[i] < h[i - 1] or h[i] > n - 1:
                valid = False
                break

        if not valid:
            out.append("0")
            continue

        ans = 1
        slots = 0

        for i in range(1, n):
            if h[i] == h[i - 1]:
                if slots == 0:
                    ans = 0
                    break

                ans = ans * slots % MOD
                slots -= 1
            else:
                diff = h[i] - h[i - 1]

                ans = ans * 2 % MOD
                slots += diff - 1

        out.append(str(ans))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```第一个验证检查 (h_1=0) 和 (h_n=n-1)。 第一个条件描述单元素前缀，而第二个条件则源自完整排列包含 (1) 和 (n) 的事实。 

单调性检查立即拒绝减小的宽度。 上限检查在技术上由 (h_n=n-1) 和单调性隐含，但保持其明确可以使有效性条件清晰，并保护转换逻辑免受不可能的输入值的影响。`slots`从零开始。 一开始只有一个排列元素，因此在最小值和最大值之间严格地不存在未使用的值。 

为了扩大过渡，`diff`是积极的。 乘以 2 可以决定新元素是否成为最小值或最大值。 表达式`diff - 1`计算新的内部值。 什么时候`diff`为 1 时，不会创建任何内部值，这就是为什么此更新可以正确加零的原因。 

对于平等的过渡，`slots`是合法选择的确切数量。 检查`slots == 0`在乘法之前避免使状态变为负值。 负槽数没有组合意义，并且可能导致错误的模块化答案。 

Python 整数不会溢出，但仍然需要模运算，因为答案呈指数增长。 总输入大小最多为 (2\cdot10^6)，因此每个测试用例存储一个 (h) 数组并处理一次很容易管理。

### 示例 2

 第二个示例案例是 (n=3) 且 (h=[0,1,2])。 

| 职位| (h_i) | 上一页 (h) | 过渡 |`ans`|`slots`|
 | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | 0 | 初始状态| 1 | 0 |

 每次转换都会将间隔扩大一倍。 每个扩展都有两个选择，但不会创造未使用的内部价值，因为`diff - 1`为零。 因此答案是(2\cdot2=4)。 这四种排列是 ([1,2,3])、([2,1,3])、([2,3,1]) 和 ([3,2,1])。 

这两个例子展示了两种基本的转换类型。 第一个创建一个内部槽并稍后使用它，而第二个仅扩展端点并且从不需要内部放置。

 ## 边缘情况

 对于(n=1)，唯一可能的排列是([1])，因此生成的序列是([0])。 该算法接受 (h_1=0)，确认 (h_n=n-1=0)，不执行转换，并返回初始答案 (1)。 

对于无效的第一个值，请考虑 (n=2) 和 (h=[1,1])。 单元素前缀的最大值始终等于最小值，因此其宽度必须为零。 初始验证拒绝转换扫描之前的序列，给出 (0)。 

对于递减序列，请考虑 (n=3) 和 (h=[0,2,1])。 前两个元素产生宽度（2）后，添加另一个元素不能使前缀范围变窄。 扫描检测到 (1<2) 并返回 (0)。 

对于过大的宽度，请考虑 (n=3) 和 (h=[0,3,3])。 唯一可用的值是 (1,2,3)，因此最大可能的差异是 (2)。 由于 (h_2=3>n-1)，该序列被拒绝，答案为 (0)。 

对于没有可用内部值的平台，请考虑 (n=3) 和 (h=[0,1,1])。 第一个扩展有`diff=1`，所以它创建了`diff-1=0`内部插槽。 在下一个位置，宽度保持相等，但是`slots`为零，因此没有可放置的合法值，答案变为 (0)。 

对于具有可用内部值的平台，请考虑 (n=3) 和 (h=[0,2,2])。 扩展有`diff=2`，创建一个内部插槽。 相等的转换将答案乘以一并消耗该槽。 两个端点方向保持不同，给出答案 (2)。 

对于最大可能的宽度，请考虑 (h=[0,1,2,\ldots,n-1])。 每个转换都会将间隔扩大一，因此总是有两个选择，并且不会创建内部槽。 结果是 (2^{n-1}\bmod(10^9+7))，这也提供了有用的最大尺寸性能测试。
