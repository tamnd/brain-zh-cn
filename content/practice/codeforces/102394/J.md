 ## 解决方案
 ## 问题理解

 对于每个测试用例，我们需要分割整数`n`化为两个正整数`x`和`y`这样`x`是素数，`y`是复合的，并且`x + y = n`。 这两个数字必须都严格小于`n`。 如果不存在这样的分割，我们打印`-1`。 

最多可以有`10^5`测试用例，而每个`n`可以大到`10^9`。 这排除了执行与以下比例成比例的工作的算法：`n`对于每个测试用例。 甚至对所有可能值进行线性扫描`x`最多需要大约`10^14`整个输入的迭代。 我们需要利用所需素数和合数的数学属性，而不是搜索候选数。 

最小的有用合数是`4`。 奇偶性为`n`给我们一个更简单的构造。 如果`n`均匀且足够大，选择`x = 2`使`y = n - 2`，这也是偶数。 每个大于的偶数`2`是复合的，所以只要`n - 2 >= 4`， 意义`n >= 6`。 

如果`n`是奇数且足够大，选择`x = 3`使`y = n - 3`，这是偶数。 对于奇数`n >= 7`，我们有`y >= 4`， 所以`y`是复合的。 因此每一个奇数`n >= 7`也有立即施工。 

小值`1`通过`5`需要单独处理。 为了`n = 1, 2, 3`，没有足够的空间容纳素数加复合数。 为了`n = 4`，使用素数的唯一可能的分割是`2 + 2`， 但`2`是素数而不是合数。 为了`n = 5`，可能的素数优先分解是`2 + 3`和`3 + 2`，并且第二个数字都不是合数。 因此，所有五个值都会产生`-1`。 

例如，输入`1`必须产生`-1`。 粗心的实施会导致`1`因为复合材料可能会错误地接受`1 + 0`或其他无效的分解。 用于输入`5`，只需找到两个数字，其总和为`5`也是不够的，因为`2 + 3`完全由素数组成。 必须正确检查素数和合数之间的区别。 

## 方法

 直接的暴力解决方案可以尝试所有可能的主要候选者`x`从`2`通过`n - 2`， 放`y = n - x`，并测试是否`x`是素数并且`y`是复合的。 该方法是正确的，因为每个有效答案都必须出现在这些候选者中。 如果通过试除法来测试素数，则检查一个数可以花费`O(sqrt(n))`操作，因此扫描所有候选者具有最坏情况的复杂性`O(n sqrt(n))`对于一个测试用例。 和`n`一样大`10^9`，这意味着大约`10^9`候选值和关于`31623`每个候选人的审判除数，顺序为`3 * 10^13`最坏情况下的可分性检查。 重复这样的工作最多`10^5`的情况下是完全不可行的。 

蛮力方法之所以有效，是因为答案（当存在时）必须位于可能的分割中的某个位置，但该问题为我们提供了比任意搜索问题更强的结构。 我们实际上并不需要在附近找到素数`n`，因为固定素数`2`和`3`与奇偶校验完美交互。 

对于一个均匀的`n`，减去素数`2`留下偶数。 一旦余数至少为`4`，它会自动合成。 对于一个奇怪的`n`，减去素数`3`也留下一个偶数，并且对于`n >= 7`余数至少是`4`。 因此，搜索缩减为一次奇偶校验和一次减法。 

生成的算法仅对每个测试用例执行恒定的工作。 不需要素性测试、筛选、因式分解或搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(n sqrt(n))`每个案例都进行初分素性检查|`O(1)`| 太慢了|
 | 最佳 |`O(1)`每箱|`O(1)`| 已接受 |

 ## 算法演练

 1.读取数值`n`。 数值如下`6`不能表示为素数加合数，因此立即打印`-1`为了`n < 6`。 
2.如果`n`是偶数，打印`2`和`n - 2`。 数量`2`是素数，而`n - 2`是偶数并且至少`4`，所以第二个数是合数。 
3.如果`n`为奇数，打印`3`和`n - 3`。 数量`3`是素数，而`n - 3`是偶数并且至少`4`，所以第二个数是合数。 

该结构总是产生小于的正数`n`。 为了`n >= 6`，所选择的素数最多为`3`，复合部分为`n - 2`或者`n - 3`，所以两者都严格介于`0`和`n`。 

### 为什么它有效

 构造背后的不变性是第二个数字始终是大于的偶数`2`。 每个大于的偶数`2`是复合的。 对于甚至`n`, 减去素数`2`给出这样一个数字，因为`n >= 6`意味着`n - 2 >= 4`。 对于奇数`n`, 减去素数`3`给出这样一个数字，因为`n >= 7`意味着`n - 3 >= 4`。 唯一剩下的值是`1`通过`5`，并且没有一个可以同时包含素数和合成正整数，因此返回`-1`对他们来说是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())

        if n < 6:
            print(-1)
        elif n % 2 == 0:
            print(2, n - 2)
        else:
            print(3, n - 3)

if __name__ == "__main__":
    solve()
```第一个分支处理所有不可能的小值。 阈值是`6`而不是`4`因为`n = 4`和`n = 5`仍然不能同时包含素数和合被数。 

对于一个均匀的`n`，代码选择`2`。 由此产生的`n - 2`是偶数并且至少`4`，因此不需要显式测试它是否是复合的。 

对于一个奇怪的`n`，代码选择`3`。 由此产生的`n - 3`又是均匀的并且至少`4`。 使用`3`而不是`2`是必要的，因为奇数减去`2`是奇数，奇数不会自动合成。 

Python 中不存在整数溢出问题。 在具有固定宽度整数的语言中，此处打印的最大值如下`10^9`，因此标准 32 位有符号整数也足够了。 

条件的顺序在概念上很重要。 我们首先删除小的不可能值，然后应用奇偶校验构造。 如果没有`n < 6`检查，值例如`n = 5`会错误地进入奇数分支并产生`3 2`， 在哪里`2`是素数而不是合数。 

## 工作示例

 该示例可以视为三个测试用例，`n = 1`,`n = 6`， 和`n = 7`。 

|`n`|`n < 6`| 平价 | 输出|
 | --- | --- | --- | --- |
 | 1 | 真实 | 未达到|`-1`|
 | 6 | 假 | 甚至|`2 4`|
 | 7 | 假 | 奇数|`3 4`|

 为了`n = 1`，小值条件立即表明不存在有效分解。 为了`n = 6`，这个数是偶数，所以`2 + 4`被构建，与`2`素数和`4`合成的。 为了`n = 7`，这个数字是奇数，所以`3 + 4`被建造。 这些痕迹覆盖了不可能区域、偶数结构和奇数结构。 

一个更大的甚至的例子，`n = 10`，遵循相同的规则。 

|`n`|`n < 6`| 平价 | 主要的`x`| 合成的`y`| 检查 |
 | --- | --- | --- | --- | --- | --- |
 | 10 | 10 假 | 甚至| 2 | 8 |`2 + 8 = 10`|

 剩下的`8`是偶数且大于`2`，所以它是自动合成的。 不需要因式分解。 

一个更大的奇怪的例子，`n = 11`，演示了为什么奇怪的情况使用`3`。 

|`n`|`n < 6`| 平价 | 主要的`x`| 合成的`y`| 检查 |
 | --- | --- | --- | --- | --- | --- |
 | 11 | 11 假 | 奇数| 3 | 8 |`3 + 8 = 11`|

 选择`2`这里会离开`9`，它恰好是复合的，但不能保证每个奇数`n`。 选择`3`总是留下偶数，给出统一的结构。

## 边缘情况

 对于`n = 1`，算法输入`n < 6`分支和打印`-1`。 根本没有可用的正合数，因此这必然是不可能的。 

为了`n = 4`，该算法还打印`-1`。 使用素数作为第一个被加数的唯一方法是`2 + 2`，但是第二个`2`是素数，不是合数。 这种区别很重要，因为仅仅找到两个有效的正被加数是不够的。 

为了`n = 5`，结果又是`-1`。 涉及素数的可能分解是`2 + 3`和`3 + 2`，并且第二个被加数都是素数。 这捕获了忘记这一点的实现`2`和`3`不是复合的。 

为了`n = 6`，算法采用第一个有效的偶数情况并输出`2 4`。 这里`2`是素数并且`4`是合数，其总和恰好是`6`。 这是存在推测分解的第一个整数。 

为了`n = 7`，该算法使用奇数结构并输出`3 4`。 价值`4`是最小的合数，因此这是奇数分支的第一个测试。 

为最大值`n = 10^9`，算法输出`2 999999998`。 第二个值是偶数且大于`2`，所以它是复合的。 尺寸为`n`对操作数量没有影响，这正是恒定时间结构可以轻松处理上限的原因。
