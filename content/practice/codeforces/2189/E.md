 ## 解决方案
 ## 问题理解

 我们得到一个二进制字符串`s`长度`n`。 我们的目标是将这个字符串转换为单个字符`"1"`使用特殊操作：我们可以获取任何连续的子字符串，并将其替换为至少与该子字符串中其他字符出现次数相同的字符。 每个此类操作的成本等于所使用的子字符串的长度。 我们想要最小的总成本，或者`-1`如果不可能的话。 

简单来说，每个操作都会将字符串的一部分减少为该部分中的多数字符。 如果字符串已经仅包含`"1"`s，无需任何操作。 如果字符串只包含`"0"`s，不可能达到`"1"`。 当字符串混合有零和一时，挑战就来了：我们需要以巧妙的方式选择子字符串以最小化总成本。 

约束很严格：`n`可以达到`5⋅10^5`，以及总和`n`所有测试用例都以相同的数字为界。 这排除了任何 O(n^2) 算法，因为尝试所有子字符串的简单方法将大致执行`n^2/2`每个测试用例的操作量太大了。 

非明显的边缘情况包括：

 - 单一`"0"`: 无法转化，所以答案是`-1`。 
- 单一`"1"`：已经是目标，成本是`0`。 
- 具有连续块的字符串`"0"`包围着`"1"`：错误地选择子字符串可能会产生比必要的更高的成本。 
- 长串已经全部了`"1"`：任何算法都必须有效地检测到这一点并返回`0`。 

## 方法

 暴力方法将模拟所有可能的操作序列。 对于每个子字符串，计算多数字符，替换它，然后递归。 这是正确的，但显然是指数级的：分割字符串的方法数量随长度呈超指数增长，因此对于`n`最多`5⋅10^5`。 

关键的见解是任何操作都可以将 1 之间或末尾的连续的 0 序列折叠成单个`"1"`如果至少有一个`"1"`包含在子字符串中。 相反，没有 0 的子串`"1"`无法生产`"1"`。 由此，我们意识到两件事：第一，字符串只能简化为`"1"`如果它至少包含一个`"1"`; 其次，最优策略是贪婪的：重复操作紧邻的最长连续零块。 

最佳方法将每个连续的零块视为一个独立的段。 对于每个段，减少它的最小成本等于将其与相邻段合并的成本之和`"1"`以大多数人成为的方式`"1"`。 由于操作可以包括`"1"`在块的一端，折叠由 1 包围的 0 块的成本是块的长度加一。 开始或结束处的边缘零块的处理方式类似，包括最近的`"1"`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最优（每零块贪婪）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.首先扫描字符串`s`。 如果它不包含`"1"`， 返回`-1`立即地。 
2. 如果字符串已经存在`"1"`， 返回`0`。 
3. 初始化总成本变量为`0`。 
4. 遍历字符串以识别连续的零块。 对于每个零块：

 - 如果在开头或结尾并且没有`"1"`在其左侧或右侧，仍然可以通过包括最近的来减少`"1"`在子串中。 
- 将零块的长度加一添加到总成本中。 这考虑到包括`"1"`在操作中。 
5. 返回累计总成本。 

为什么有效：每个零块必须与至少一个组合`"1"`塌陷成`"1"`。 计算零加一的长度可确保我们包含保证大多数的最小子串`"1"`。 没有任何操作可以在不触及零块的情况下折叠零块`"1"`，所以这种贪婪方法可以证明是最小的。 不变的是，在处理完所有零块之后，每个`"0"`被删除或替换为`"1"`在一次操作中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        if '1' not in s:
            print(-1)
            continue
        if s == '1':
            print(0)
            continue
        total_cost = 0
        i = 0
        while i < n:
            if s[i] == '0':
                j = i
                while j < n and s[j] == '0':
                    j += 1
                # length of zero block
                total_cost += j - i
                # include adjacent '1' for majority
                total_cost += 1
                i = j
            else:
                i += 1
        print(total_cost)

if __name__ == "__main__":
    solve()
```该代码首先处理琐碎的边缘情况：没有的字符串`"1"`和字符串已经`"1"`。 然后它遍历每个零块，计算其对成本的贡献（长度加一以包含`"1"`)，并对它们求和。 使用两个指针（`i`和`j`) 避免嵌套循环并确保 O(n) 时间。
