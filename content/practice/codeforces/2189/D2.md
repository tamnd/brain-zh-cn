 ## 解决方案
 ## 问题理解

 我们没有被要求直接计算排列。 真正的任务是理解哪些二进制字符串$w$有可能，有什么价值$f(w)$他们生成并优化所有问号的替换。 

对于一个排列$0,1,\dots,n-1$,定义一个二进制字符串$w$在哪里$w_i=1$意味着某个子数组的 mex 等于$i$， 和$w_i=0$意味着没有子数组的 mex 等于$i$。 

简单的版本已经隐藏了关键的组合事实：一旦$w$是固定的，有效排列的数量分解为每个位置的独立贡献$i$。 

在硬版本中，某些位置是“？”。 我们可以将它们中的每一个选择为 0 或 1。在所有结果字符串中$w$，我们需要最小值$f(w)$**不能被整除$c$**。 

长度可以达到$2\cdot 10^5$跨所有测试用例。 任何试图枚举问号分配的算法都是没有希望的。 甚至$2^{50}$可能性已经是不可能的，这里问号的数量可以是线性的$n$。 

可除性条件是另一个陷阱。 实际价值$f(w)$增长得天文数字，所以我们无法精确计算它然后测试整除性。 我们必须直接推理素因数。 

一个特别危险的边缘情况是第一个或最后一个位置变为 0 时。没有任何排列可以满足这样的字符串。 例如：```
n = 3
w = 001
```Mex 1 始终存在，因为包含 0 的单元素段具有 mex 1。同样 mex$n$总是存在，因为整个排列有 mex$n$。 这样的字符串有$f(w)=0$。 

另一种微妙的情况发生在$c=1$。 每个整数都可以被 1 整除，包括 0。答案总是：```
-1
```与字符串无关。 

第三个陷阱是当处理固定字符后所有剩余的整除性要求形成 2 的幂时。 然后到处选择最小的因数可能会意外地使整个乘积整除$c$。 最佳分配必须有意消除足够的二的幂。 

## 方法

 蛮力方法很简单。 替换每个“？” 独立地由 0 或 1 构建结果字符串$w$, 计算$f(w)$，并保持不能被整除的最小值$c$。 

如果有$k$问号，这需要$2^k$作业。 自从$k$可以是$\Theta(n)$，最坏的情况大致是$2^{200000}$，这是完全不可能的。 

D1 的观察结果完全改变了问题。 

假设我们插入数字$1,2,\dots,n-1$逐一变成不断增长的排列。 

插入时$k$， 有$k+1$可能的职位。 

如果$k$放置在两端之一，mex$k$将会存在。 这完全是两个选择。 

如果$k$被插入到中间的某个位置，所有值都小于$k$躺在两侧$k$，因此任何包含所有较小值的段也必须包含$k$。 墨西哥$k$变得不可能。 这些正是$k-1$选择。 

这意味着每个职位都独立做出贡献：$$f(w)=\prod_{i=1}^{n-1} \begin{cases} 2,&w_i=1\\ i-1,&w_i=0 \end{cases}$$困难版本现在变成了乘法优化问题。 

固定位置贡献固定产品$b$。 

问号贡献了可变的产品$x$。 

我们需要最小的$bx$不能被整除$c$。 

而不是携带$b$, 移除自$c$已提供的所有素因数$b$。 让$$c'=\frac{c}{\gcd(b,c)}$$使用 gcd 缩减增量执行。 

现在我们只需要最小的$x$不能被整除$c'$。 

此时结构就变得非常简单了。 

对于每个未解决的位置与因素选择$\{2,j\}$， 在哪里$j=i-1\ge2$，较小的因子始终为 2。 

如果$c'$包含一个奇素因数，在任何地方选择 2 都会产生 2 的纯幂，它永远不能被整除$c'$。 该分配已经是最佳的。 

唯一困难的情况是当$c'$本身就是二的幂。 那么整除性仅取决于最终产品中存在的因子 2 的数量。 我们贪婪地替换最大奇数对应的因子$j$值，因为替换$2$通过更大的奇数增加乘积，并在更大的奇数上进行$j$稍后比在较小的地方进行更便宜$j$早些时候。 

这会产生一个$O(n\log n)$解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^k)$|$O(k)$| 太慢了 |
 | 最佳 |$O(n\log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 预先计算阶乘模$10^9+7$最多$2\cdot10^5$。 
2.如果位置1或位置$n$固定为 0，那么每个有效的赋值都有$f(w)=0$。 因为 0 可以被所有正数整除$c$， 输出$-1$。 
3. 仅处理固定位置。 

对于每个固定字符：

 - 如果字符为 1，则因子 = 2，
 - 系数 =$i-1$如果字符为0。 

将这些因素乘以$b$模数$10^9+7$。 
4.同时减少$c$通过 GCD 与这些固定因素。 

处理完所有固定位置后，剩余值为$c'$。 
5. 收集所有未解决的位置$i\in[3,n-1]$。 他们的替代因素是$j=i-1$。 
6. 如果$c'$不是 2 的幂，为每个未解决的位置选择因子 2。 这给出了尽可能小的乘积并且仍然避免了可分性。 
7. 如果$c'=2^k$，计算 all-2 分配贡献了多少 2 的幂。 
8. 贪婪地将因子 2 保留在尽可能多的位置上，同时所得的 2 的指数严格低于$k$。 
9. 每个剩余的未解决的位置都使用其奇怪的替代方案$j$。 
10. 将所有选择的因子乘以模$10^9+7$。 
11. 如果没有赋值可以避免整除，则输出$-1$。 否则输出构建的产品。 

### 为什么它有效

 D1 组合论证证明每个位置独立贡献因子 2 或因子$i-1$。 位置之间不存在任何交互作用。 

除去固定位置已经提供的所有素因数后，整除性仅取决于未解决的部分。 什么时候$c'$包含奇素因数，任何 2 的纯幂都不能被整除$c'$，因此在任何地方选择 2 都是全局最小的。 

什么时候$c'$是二的幂，整除性仅取决于二的总指数。 Every even alternative$j$至少为 2，并且永远不会比选择 2 更好地改进产品，因此只有奇怪的替代方案才重要。 将因子 2 替换为奇数$j$精确消除 2 的一次幂，同时将乘积增加一个乘法因子$j/2$。 选择最大的奇数$j$最后的值最小化了增加，给出了字典顺序上最小的乘法调整，打破了整除性。 

## Python 解决方案```python
import sys
from math import gcd

input = sys.stdin.readline

MOD = 1000000007
MAXN = 200000 + 5

fact = [1] * MAXN
for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

def is_power_of_two(x):
    return x > 0 and (x & (x - 1)) == 0

t = int(input())

for _ in range(t):
    n, c = map(int, input().split())
    s = input().strip()

    if c == 1:
        print(-1)
        continue

    if s[0] == '0' or s[-1] == '0':
        print(-1)
        continue

    ans = 1
    rem = c

    odd_candidates = []

    for i in range(1, n):
        ch = s[i - 1]

        if i == n:
            continue

        if ch == '1':
            ans = ans * 2 % MOD
            rem //= gcd(rem, 2)

        elif ch == '0':
            val = i - 1
            ans = ans * val % MOD
            rem //= gcd(rem, val)

        else:
            if i == 2:
                pass
            elif i >= 3:
                odd_candidates.append(i - 1)

    if rem == 1:
        print(-1)
        continue

    if not is_power_of_two(rem):
        for _ in odd_candidates:
            ans = ans * 2 % MOD
        print(ans)
        continue

    need = rem.bit_length() - 1

    m = len(odd_candidates)

    if m < need:
        for _ in odd_candidates:
            ans = ans * 2 % MOD
        print(ans)
        continue

    use_twos = need - 1

    odd_candidates.sort()

    for idx, j in enumerate(odd_candidates):
        if idx < use_twos:
            ans = ans * 2 % MOD
        else:
            ans = ans * j % MOD

    print(ans)
```第一阶段计算所有固定位置的贡献。 同时它消除了共同因素$c$，产生减少的值$c'$。 

名单`odd_candidates`存储每个未解析的因子对$\{2,j\}$和$j=i-1\ge2$。 

所在分行`rem`不是二的幂是最简单的情况。 到处选择 2 既最小又自动避免整除。 

什么时候`rem`是二的幂，只是二的指数。 变量`need`存储所需的指数。 我们准确地保留`need - 1`因子等于 2，并用奇数替代项替换其余因子，产生其二元估值保持在整除阈值以下的最小产品。

 ## 边缘情况

 考虑```
3 10
0??
```第一个位置固定为 0。Mex 1 始终存在于每个排列中，因此没有有效的排列可以实现该字符串。 有效排列的数量为 0，并且 0 可以被每个正整数整除。 算法立即输出`-1`。 

考虑```
4 100
????
```端点可以选择为1。每个未解决的因子可以取为2。由于约简除数包含奇数因子，所以全2分配已经是最优的。 该算法从不执行不必要的替换。 

考虑```
5 8
100?1
```最小分配产生 8，它可以被 8 整除。算法检测到剩余的除数是 2 的幂，并用 3 替换一个因子 2，产生 12，即最小的有效答案。
