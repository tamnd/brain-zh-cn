 ## 解决方案
 ## 问题理解

 我们需要构造一个数字的排列`1`到`n`。 

对于每个职位`i`和`2 ≤ i ≤ n-1`, 一定存在某个位置`j`满意的`i ≤ j ≤ n`这样$$p_i = p_j \oplus i.$$由于我们可以自由选择整个排列，因此这是一个建设性的问题。 我们没有被要求计算任何东西或优化任何东西，只是为了产生一种有效的安排。 

约束条件`n ≤ 2 · 10^5`以及所有的总和`n`测试用例最多`2 · 10^5`立即建议`O(n)`每个测试用例的构造是完全安全的。 任何搜索排列的方法都是没有希望的。 即使检查所有可能的位置对也已经是`O(n²)`，当`n`是二十万左右。 

问题的微妙部分是 XOR 条件涉及位置和值。 贪婪地放置数字的天真尝试很容易为一个位置创建有效关系，同时破坏另一个位置的有效关系。 

考虑`n = 4`。 如果我们简单地使用恒等排列`[1,2,3,4]`，那么对于`i = 2`我们需要一些等于`2 ⊕ 2 = 0`，它不能出现在排列中`1..n`。 条件立即失效。 

另一个容易犯的错误是在本地构建对而不保留排列属性。 例如，如果我们决定每个所需的位置都应该异或`1`，我们可以尝试分配`p_i = i ⊕ 1`。 为了`n = 3`，这给出了值`[?,3,2]`, 没有留下位置`1`并且不保证所有数字都来自`1`到`n`恰好出现一次。 

该构造必须满足 XOR 要求并保持真正的排列。 

## 方法

 蛮力思维首先会搜索排列并检查每个位置是否满足条件。 给定候选排列，验证需要`O(n²)`如果我们测试所有可能的`j`价值观。 排列数为`n!`，所以即使对于非常小的情况这显然也是不可能的`n`。 

关键的观察是该条件只需要存在一些合适的`j`。 没有什么规定不同的立场必须使用不同的证人。 

这建议尝试使每个位置都指向同一位置。 

最简单的选择是最后一个位置。 如果我们安排$$p_n = 1,$$那么每个需要的位置只需要满足$$p_i = 1 \oplus i.$$现在问题变得简单多了。 对于任意整数`i ≥ 2`，值`i ⊕ 1`只是它的相邻数字：$$2 \leftrightarrow 3,\quad 4 \leftrightarrow 5,\quad 6 \leftrightarrow 7,\ldots$$因为异或与`1`只翻转最低有效位。 

所以我们可以将连续的数字配对：$$2 \leftrightarrow 3,\quad 4 \leftrightarrow 5,\quad 6 \leftrightarrow 7,\ldots$$并放置$$p_i = i \oplus 1$$对于每个位置从`2`到`n-1`。 

唯一剩余的未使用的数字被放置在位置`1`。 这会产生一个完整的排列，并且每个所需的位置都可以选择`j = n`。 这种结构正是简单版本所接受的想法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!·n²) | O(n!·n²) | O(n) | 太慢了 |
 | 最佳施工| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 创建数组`p`长度`n`。 
2. 放置`1`在最后一个位置，所以`p[n] = 1`。 
3. 对于每个位置`i`从`2`到`n-1`：

如果`i`是偶数，设置`p[i] = i + 1`。 

如果`i`是奇数，集合`p[i] = i - 1`。 

这与`p[i] = i ⊕ 1`。 
4. 一个值来自`1..n`仍然未使用。 

如果`n`是奇数，未使用的值是`n - 1`，所以设`p[1] = n - 1`。 

如果`n`是偶数，未使用的值是`n`，所以设`p[1] = n`。 
5. 输出排列。 

### 为什么它有效

 对于每个职位`i`和`2 ≤ i ≤ n-1`，该构造给出$$p_i = i \oplus 1.$$自从`p_n = 1`,$$p_n \oplus i = 1 \oplus i = i \oplus 1 = p_i.$$因而选择`j = n`总是满足所要求的条件。 

分配给位置的值`2..n-1`正是通过交换每个连续对获得的数字`(2,3)`,`(4,5)`,`(6,7)`， 等等。 没有重复的数字。 连同`p_n = 1`，正好有一个数字未被使用，被放置在位置`1`。 因此，每个数字都来自`1`到`n`恰好出现一次，因此该数组是有效的排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    
    for _ in range(t):
        n = int(input())
        
        p = [0] * (n + 1)
        p[n] = 1
        
        for i in range(2, n):
            if i & 1:
                p[i] = i - 1
            else:
                p[i] = i + 1
        
        if n & 1:
            p[1] = n - 1
        else:
            p[1] = n
        
        print(*p[1:])

solve()
```构造直接遵循证明。 

位置循环`2..n-1`执行由 XOR 引起的对交换`1`。 最后的位置固定为`1`，这保证了每个需要的位置都可以使用`j = n`。 

唯一的边界条件是位置`1`。 我们永远不需要满足那里的 XOR 要求，因为简单版本只要求来自`2`到`n-1`。 填充其他位置后，只有一个值保持未使用。 对于奇数`n`这是`n-1`，而对于偶数`n`这是`n`。 

不存在整数溢出问题，因为所有值最多都是`2 · 10^5`。 

## 工作示例

 ### 示例 1：n = 3

 施工：

 | 步骤| 状态|
 | --- | --- |
 | 设置最后位置 |`[0, 0, 1]`|
 | 不存在中间位置 |`[0, 0, 1]`|
 | 设置第一个位置 |`[2, 1, 3]`|

 最终排列：

 | 位置我| p[i] | p[i]
 | --- | --- |
 | 1 | 2 |
 | 2 | 1 |
 | 3 | 3 |

 检查：

 对于`i = 2`,$$p_3 \oplus 2 = 3 \oplus 2 = 1 = p_2.$$条件成立。 

### 示例 2：n = 6

 施工：

 | 步骤| 状态|
 | --- | --- |
 | 设置最后位置 |`[0,0,0,0,0,1]`|
 | 我 = 2 |`[0,3,0,0,0,1]`|
 | 我 = 3 |`[0,3,2,0,0,1]`|
 | 我 = 4 |`[0,3,2,5,0,1]`|
 | 我 = 5 |`[0,3,2,5,4,1]`|
 | 设置第一个位置 |`[6,3,2,5,4,1]`|

 验证：

 | 我| p[i] | p[i] p[6] ⊕ 我 |
 | --- | --- | --- |

 每个需要的位置都使用`j = 6`。 

该迹线说明了中心不变量：所有中间位置相等`i ⊕ 1`，而最后一个位置存储`1`。

import sys
import io

def solve_io():
    input = sys.stdin.readline

        for i in range(2, n):

 ## 边缘情况

 对于`n = 3`，只有一个约束位置，即`i = 2`。 建设产生`[2,1,3]`。 自从`3 ⊕ 2 = 1`，条件立即满足。 这会检查尽可能小的输入。 

为了`n = 4`，该构造给出`[4,3,2,1]`。 所需职位是`2`和`3`。 我们有$$1 \oplus 2 = 3,$$和$$1 \oplus 3 = 2.$$两者都与相应的条目匹配，因此条件成立。 

对于奇数，例如`n = 5`，第一个位置接收`n-1 = 4`。 该值从未在其他地方使用，因为位置`2..4`确切地包含`{3,2,1}`并且最后一个位置已经包含`1`。 排列属性保持不变。 

对于较大的偶数值，同样的论证也适用。 各中间位置存储`i ⊕ 1`，每一个都指向最后一个位置，剩余未使用的值放在前面。 除了奇偶校验之外不需要特殊处理。
