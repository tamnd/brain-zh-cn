 ## 解决方案
 ## 问题理解

 我们被要求帮助青蛙沿着无限数轴从位置 0 移动到目标位置$x$。 青蛙有$n$魔法跳跃的类型。 每种跳跃类型$i$允许青蛙向前移动最多$a_i$单位，但青蛙被诅咒：每$b_i$该类型的第 -th 跳转迫使其回滚$c_i$跳跃前的单位。 目标是确定青蛙必须承受的最小回滚次数才能到达准确位置$x$，或者报告说这是不可能的。 

输入指定多个测试用例。 每个案例都列出了$n$跳跃类型，每种都有$a_i, b_i, c_i$。 限制条件很大：$x$可以达到$10^{18}$和$n$所有测试用例的总和可达$10^5$。 这排除了任何尝试单独模拟每次跳跃的解决方案，因为这样做需要以下顺序：$x$最坏情况下的操作。 我们需要一种数学或贪婪的方法来计算结果，而不需要模拟每次跳跃。 

当最大跳跃距离达到时，会出现不明显的边缘情况$a_i$小于回滚$c_i$用于频繁重复的跳跃。 例如，与$x = 4$和一个跳跃$a = 2, b = 2, c = 3$，青蛙无法到达 4。忽略回滚效应的幼稚方法可能会错误地得出青蛙可以到达目标的结论。 另一种边缘情况是当目标小于任何跳跃距离但一次跳跃即可准确到达时； 在这种情况下，最小回滚次数是零，而不是一。 

## 方法

 暴力方法会逐步模拟每种跳跃类型，尝试所有跳跃组合、跟踪回滚，并在到达时停止$x$。 这是正确的，但太慢了，因为目标$x$可能非常大，每个跳跃序列可能涉及数十亿步。 

关键的见解是独立处理每种跳跃类型，并计算青蛙在给定次数的回滚情况下可以走多远。 跳跃型用$i$，如果我们让$k$是发生的回滚次数，可达到的总距离是$a_i \cdot (k \cdot b_i) - k \cdot c_i + r$， 在哪里$r < b_i$是下一次回滚之前的跳转次数。 优化最小回滚意味着最大化有效跳跃距离$a_i - \frac{c_i}{b_i}$。 我们可以使用整数运算计算每种跳转类型的最小回滚，并选择以最少回滚实现目标的跳转类型。 

暴力方法会失败，因为模拟每次跳跃是不可行的。 我们可以直接根据跳转参数计算回滚，这一观察结果将问题简化为每个跳转类型的恒定时间计算。

 ## 算法演练

 1. 对于每种跳跃类型$i$，检查是否$a_i \ge x$。 如果是的话，青蛙可以到达$x$一跳零回滚。 记录零作为候选答案。 
2. 对于跳转类型，其中$a_i < x$，计算所需的最小回滚次数。 每次回滚发生的时间间隔$b_i$跳跃并减少净距离$c_i$。 让$k$是回滚的次数。 可达的最大距离$k$回滚是$$\text{distance} = a_i \cdot (\text{total jumps}) - k \cdot c_i$$其中总跳转包括导致回滚的跳转和剩余跳转。 求解最小整数$k \ge 0$这样的距离$\ge x$。 

1. 计算$k$使用整数数学：要到达的跳跃次数$x$没有回滚效果的是$\lceil x / a_i \rceil$。 总回滚距离为$\lfloor (\text{jumps} - 1)/b_i \rfloor \cdot c_i$。 调整$k$直到包含回滚的总距离达到或超过$x$。 
2. 跟踪最小值$k$超过所有跳跃类型。 如果没有跳转类型可以到达$x$， 输出$-1$。 否则，输出找到的最小回滚。 

该算法之所以有效，是因为回滚是周期性的且可预测的，允许直接计算其累积效应。 我们可以独立检查每个跳转类型，确保捕获跨类型的最小回滚配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        min_rollbacks = float('inf')
        for _ in range(n):
            a, b, c = map(int, input().split())
            if a >= x:
                min_rollbacks = min(min_rollbacks, 0)
                continue
            if a * b <= c:
                continue
            # compute minimum rollbacks needed
            k = (x - a + (a * b - c) - 1) // (a * b - c)
            if k >= 0:
                min_rollbacks = min(min_rollbacks, k)
        print(-1 if min_rollbacks == float('inf') else min_rollbacks)

if __name__ == "__main__":
    solve()
```该代码首先处理单次跳转即可到达目标的简单情况。 然后，它会过滤掉无用的跳跃类型，因为它们的回滚惩罚超过每个周期的净距离。 对于其余的跳转类型，整数算术计算所需的确切回滚次数。 使用`float('inf')`确保正确标记无法实现的情况。
