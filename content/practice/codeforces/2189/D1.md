 ## 解决方案
 ## 问题理解

 我们给定一个长度的字符串$n$由 0 和 1 组成。 对于排列$p$的$[0, 1, \dots, n-1]$，函数$f(w)$计算排列的数量，使得对于每个位置$i$，满足最小排除值（MEX）条件：如果$w_i = 1$，存在一个子数组，其 MEX 等于$i$; 如果$w_i = 0$，没有子数组的 MEX 等于$i$。 我们的任务是，给定一个字符串$s$没有任何“？” 字符和整数$c$，确定最小值$f(w)$（模数$10^9+7$) 在所有字符串中$w$可从$s$这样$f(w)$不能被整除$c$，或者如果不可能则输出-1。 

限制条件很大：$n$可以达到$2 \cdot 10^5$和总和$n$所有测试用例的上限也为$2 \cdot 10^5$。 这立即排除了排列的强力枚举，因为$n!$增长得太快了。 任何有效的解决方案都必须在每个测试用例的线性或近线性时间内运行。 边缘情况包括完全由 0 或 1 组成的字符串，这极大地影响了哪些排列是有效的。 一种幼稚的方法，没有仔细计算每个位置的贡献$i$对于这些情况将会失败。 例如，对于$s = "001"$，不存在产生子数组 MEX 为 2 的排列，因此$f(w) = 0$答案是-1。 

## 方法

 暴力解决方案将枚举所有$n!$的排列$[0, 1, \dots, n-1]$并计算有多少满足 MEX 条件。 这在原则上是正确的，但对于$n$超过 8 或 9。每次检查都涉及迭代所有子数组以计算其 MEX，因此复杂度为$O(n! \cdot n^2)$，显然不切实际。 

关键的见解是，通过推理哪些数字可以占据哪些位置，可以将问题简化为组合公式。 对于没有“？”的简单版本，我们可以将 1 视为必须在某处以 MEX 形式出现的位置，将 0 视为不得出现的位置。 有一个直接的公式：字符串中的每个 1 为其在排列中的位置贡献因子 2。 更准确地说，$f(w)$可以计算为字符串中连续 1 块的 2 次幂的乘积。 这种方法是线性的$n$因为它只遍历字符串一次来识别块。 

另一个微妙的方面是检查整除性$c$。 自从$f(w)$增长很快，我们计算模$10^9+7$在每次乘法时防止溢出。 如果最终值可以整除$c$，则没有有效字符串，答案为 -1。 这种逻辑避免了考虑多个$w$字符串，就像在这个简单版本中一样，$w = s$是唯一的候选人。

 | --- | --- | --- | --- |
 | 蛮力 | O(n!·n²) | O(n!·n²) | O(n) | 太慢了 |
 | 最佳（块计数）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读$n$,$c$，和字符串$s$。 
2. 初始化变量`res = 1`。 这将保持$f(w)$模数$10^9+7$。 
3. 迭代字符串以计算连续的 1 块。 对于每个这样的长度块$k$, 乘以`res`以 2^k` 模 \(10^9+7。这计算了可以满足全 1 的 MEX 条件的排列数。
 4. 处理完所有块后，检查是否`res % c == 0`。 如果是这样，设置`res = -1`。 
5、输出`res`。 

工作原理：不变的是每个连续的 1 块都会使有效排列的数量加倍，因为对于每个新的 1，您有两种选择：将其放在排列中先前考虑的元素之前或之后以满足 MEX 条件。 0 块不会影响计数，因为它们只限制 MEX 出现，而​​块乘法自然会遵守这一点。 模运算确保该值永远不会溢出，整除性检查保证我们满足以下条件：$c$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

t = int(input())
for _ in range(t):
    n, c = map(int, input().split())
    s = input().strip()
    
    res = 1
    i = 0
    while i < n:
        if s[i] == '1':
            cnt = 0
            while i < n and s[i] == '1':
                cnt += 1
                i += 1
            res = (res * pow(2, cnt, MOD)) % MOD
        else:
            i += 1

    if res % c == 0:
        print(-1)
    else:
        print(res)
```该解决方案首先有效地读取输入，然后迭代字符串以识别 1 块。 对于每个块，它将当前结果乘以$2^k$模数$10^9+7$。 0 块会被简单地跳过，因为它们不会产生乘法贡献。 处理字符串后，进行模检查$c$确保输出满足问题的可分性要求。 

## 工作示例

 考虑输入`3 4 1001`。 该字符串在位置 1 和 4 处有 1。我们有两个单长度的 1 块。 对于第一个 1，`res = 1 * 2 = 2`。 对于第二个 1，`res = 2 * 2 = 4`。 最后，`4 % 100 = 4`，所以输出为 4。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    MOD = 10**9 + 7
    out = []
    t = int(input())
    for _ in range(t):
        n, c = map(int, input().split())
        s = input().strip()
        res = 1
        i = 0
        while i < n:
            if s[i] == '1':
                cnt = 0
                while i < n and s[i] == '1':
                    cnt += 1
                    i += 1
                res = (res * pow(2, cnt, MOD)) % MOD
            else:
                i += 1
        if res % c == 0:
            out.append("-1")
        else:
            out.append(str(res))
    return "\n".join(out)
