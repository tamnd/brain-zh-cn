 ## 解决方案
 ## 问题理解

 子数组乘积可被整除$6$当且仅当产品包含至少一个因素$2$以及至少一个因素$3$。 

对于每个数字，仅能被其整除$2$和$3$很重要。 确切的值无关紧要。 每个元素都属于四组之一：

 -$A$: 可以除以$6$-$B$: 可以除以$2$但不是由$3$-$C$: 可以除以$3$但不是由$2$-$D$: 不能被任何一个整除$2$也不$3$我们可以任意重新排列数组。 目标是最小化其乘积可被整除的子数组的数量$6$。 

所有测试用例的总长度最多为$2 \cdot 10^5$，所以任何解决方案$O(n)$或者$O(n \log n)$很容易足够快。 枚举子数组是不可能的，因为单个测试用例已经可以包含大约$2 \cdot 10^{10}$子数组。 

一个常见的错误是专注于精确的产品。 例如，在$$[2,9]$$该产品是$18$，可除以$6$，即使两个元素都不能被整除$6$单独。 只有因素的存在$2$和$3$很重要。 

另一个简单的陷阱是每个元素已经包含两个因素的情况：$$[6,12,18].$$每个非空子数组都可以整除$6$，无论顺序如何。 任何排列都是最优的。 

第三种边缘情况是数组仅包含$B$和$D$元素。 那么任何子数组都不能包含因子$3$，所以每个排列都是最优的。 

## 方法

 蛮力的想法是尝试每种排列，计算有效子数组的数量，并保持最佳排列。 

这是正确的，因为它直接检查所有可能性。 不幸的是，即使$n=10$已经给出了$$10! = 3{,}628{,}800$$排列，因此该方法几乎立即变得无用。 

关键的观察结果是，只有以下因素$2$和$3$事情。 

让$$X = C \cup D$$是**不**包含因子的元素$2$。 

任何其乘积**不能**整除的子数组$6$因为它缺少一个因素$2$必须完全位于仅包含以下元素的连续块内$X$。 

对于固定数量的元素，当所有子数组形成一个连续的块时，所包含的子数组的数量最大化。 因此，要最大化缺少因子的子数组的数量$2$，所有元素$C$和$D$应该是连续的。 

对因数的论证相同$3$表明所有元素$$Y = B \cup D$$也应该是连续的。 

一次订购即可满足这两个要求：$$A \;|\; B \;|\; D \;|\; C.$$然后$B \cup D$形成一个连续的块，并且$D \cup C$形成一个连续的块。 

组内的任何排列都是可以接受的。 这种布置正是最佳结构所需要的。

 | --- | --- | --- | --- |
 | 蛮力 |$O(n! \cdot n^2)$|$O(n)$| 太慢了 |
 | 最佳施工|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 将数字分成四组。 

团体$A$包含可被整除的数字$6$。 

团体$B$包含可被整除的数字$2$但不是由$3$。 

团体$C$包含可被整除的数字$3$但不是由$2$。 

团体$D$包含所有剩余的数字。 
2.输出所有元素$A$。 
3.输出所有元素$B$。 
4.输出所有元素$D$。 
5.输出所有元素$C$。 

每个组内的顺序并不重要。 

### 为什么它有效

 子数组不能被整除$6$如果它遗漏了因素$2$， 因素$3$，或两者兼而有之。 

不含因子的所有元素$2$正是$C \cup D$。 将它们放置在一个连续的段中可以最大化子数组缺失因子的数量$2$。 

不含因子的所有元素$3$正是$B \cup D$。 将它们放置在一个连续的段中可以最大化子数组缺失因子的数量$3$。 

安排$$A \;|\; B \;|\; D \;|\; C$$同时实现这两个目标，因为$B \cup D$和$C \cup D$都是连续的。 

由于坏子数组的数量最大化，所以好子数组的数量，即$f(a)$，被最小化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        arr = list(map(int, input().split()))

        A = []
        B = []
        C = []
        D = []

        for x in arr:
            by2 = (x % 2 == 0)
            by3 = (x % 3 == 0)

            if by2 and by3:
                A.append(x)
            elif by2:
                B.append(x)
            elif by3:
                C.append(x)
            else:
                D.append(x)

        ans = A + B + D + C
        print(*ans)

solve()
```实施直接跟随构造。 

每个元素都分类一次，因此每个测试用例的工作量与数组长度呈线性关系。 

类别内的顺序是无关紧要的，因此我们只需保留输入顺序即可。 无需排序。 

唯一微妙的一点是整除$6$必须在单独检查整除性之前进行检查$2$和$3$。 否则数字如$12$会被分到错误的组中。

 ## 边缘情况

 考虑$$[6,6,6].$$每个元素已经包含两个必需的素因数。 每个非空子数组都可以整除$6$，无论安排如何。 该算法将所有元素放入组中$A$并输出相同的多重集。 

考虑$$[2,4,8].$$没有元素包含因子$3$。 任何子数组都不能被整除$6$。 该算法将所有内容分组$B$，立即产生最优排列。 

考虑$$[5,7,11,3].$$团体有$$D=\{5,7,11\}, \quad C=\{3\}.$$输出变为$$[5,7,11,3].$$每个避免最终元素的子数组都缺少因子$3$，这正是构造试图最大化的行为。
