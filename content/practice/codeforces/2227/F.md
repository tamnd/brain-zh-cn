 ## 解决方案
 ## 问题理解

 每列包含从高度堆叠的立方体$1$达到高度$a_i$。 当重力转向右侧后，立方体的高度不会改变。 相同高度的立方体独立滑动并占据该水平面上最右边的可用位置。 

逐个考虑高度很有用。 对于固定高度$h$， 定义$$C_h=\#\{i : a_i\ge h\}.$$有$C_h$那个级别的立方体。 重力作用后，那些$C_h$立方体占据最右边$C_h$列，$$n-C_h+1,\dots,n.$$该问题要求所有立方体的移动距离之和。 在重力之前，我们最多可以移除一个立方体，这意味着选择一列$i$并减少$a_i$经过$1$。 

制约因素很大。 在所有测试用例中，$$\sum n \le 2\cdot 10^5.$$任何二次方都是不可能的。 甚至$O(n\sqrt n)$会不舒服。 目标是$O(n)$或者$O(n\log n)$每个测试用例。 

最危险的边缘情况是删除单个多维数据集会改变许多其他多维数据集的行为的情况。 

考虑$$[1,2,3,2,1].$$最初的答案是$5$。 删除最后一列中唯一的立方体会产生$$[1,2,3,2,0],$$答案就变成了$9$。 仅减去已移除立方体的移动的解决方案会忽略全局效果。 

另一个重要的情况是非减数组，例如$$[1,2,3,4,5].$$每个立方体都已经占据了其所在层的最右侧位置。 答案是$0$，并且移除任何立方体都无法改善它。 

第三种情况是多个职位对改进的贡献相同。 例如，$$[5,4,1,1,1].$$正确的选择取决于全局结构，而不是最大的列。 

## 方法

 暴力解决方案会尝试所有可能的删除方法。 对于每个候选索引，重建整个最终配置并重新计算总移动距离。 计算一种配置的结果已经需要处理所有高度或所有立方体，因此总复杂度至少变为$O(n^2)$，而且往往更糟。 和$n=2\cdot 10^5$，这已经远远超出了极限。 

关键的观察结果是最终配置仅取决于计数$C_h$。 

对于身高$h$，立方体占据列$$n-C_h+1,\dots,n.$$柱上有一个立方体$i$和身高$h$动作$$(n-C_h+k)-i,$$在哪里$k$是它在包含高度的列中的排名$h$。 

不要计算移动的立方体，而是计算**不**移动的立方体。 

修复一列$i$。 一个立方体在高处$h\le a_i$当柱准确地保持在原位时$i$属于级别的最后一个最右边的块$h$。 这意味着$$i \ge n-C_h+1.$$等价地，$$C_h \ge n-i+1.$$满足这个条件的最大高度正好是$$s_i=\min(a_i,a_{i+1},\dots,a_n),$$后缀最小值。 

因此列$i$恰好包含$s_i$不移动的立方体。 自列$i$包含$a_i$总共立方体，该列贡献的移动立方体数量为$$a_i-s_i.$$对所有列求和得出初始答案$$\text{base}=\sum_{i=1}^{n}(a_i-s_i).$$现在考虑移除一个立方体。 

如果我们减少$a_i$经过$1$, suffix-minimum 数组中只能改变一个值：列表示的最小值$i$。 总答案增加了$1$正是当我们从高度等于该位置后缀最小值的位置移除立方体时。 

让$$f(x)=\#\{i:s_i=x\}.$$如果我们选择一个值$x$出现在后缀最小数组中，我们可以减少 1 次出现$x$。 这增加了答案$$f(x)-1.$$因此最好的改进是$$\max_x (f(x)-1).$$如果每个后缀最小值仅出现一次，则什么都不做是最佳的。 

因此最终的答案是$$\boxed{ \sum_{i=1}^{n}(a_i-s_i) + \max\!\left(0,\max_x f(x)-1\right) }.$$这一观察结果直接得出线性解。

 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$或者更糟|$O(n)$| 太慢了 |

 ## 算法演练

 1.计算后缀最小数组：$$s_n=a_n,\qquad s_i=\min(a_i,s_{i+1}).$$2. 计算$$\text{base}=\sum_{i=1}^{n}(a_i-s_i).$$这等于任何移除之前的总移动距离。 
3. 计算后缀最小值数组中每个值出现的频率。 
4.让$$m=\max_x f(x).$$5. 最好的改进是$$\max(0,m-1).$$6. 输出$$\text{base}+\max(0,m-1).$$### 为什么它有效

 对于每一列$i$，后缀最小值$s_i$正是该列中在重力作用下保持固定的立方体的数量。 每个其他立方体至少移动一个位置。 所以$a_i-s_i$计算列贡献的移动立方体$i$，求和得出总移动距离。 

删除一个多维数据集只能影响当前用作后缀最小值的值。 如果后缀最小值$x$出现$f(x)$次，减少一次出现会破坏除其中一个位置之外的所有位置的最小值，从而增加$f(x)-1$在答案中。 没有去除可以创造更大的增益。 因此，最优改进是最大$f(x)-1$。 

## Python 解决方案```python
import sys
from collections import defaultdict

input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        s = [0] * n
        s[-1] = a[-1]

        for i in range(n - 2, -1, -1):
            s[i] = min(a[i], s[i + 1])

        base = 0
        freq = defaultdict(int)

        for ai, si in zip(a, s):
            base += ai - si
            freq[si] += 1

        best = 0
        for cnt in freq.values():
            best = max(best, cnt)

        ans.append(str(base + max(0, best - 1)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```后缀最小数组是中心对象。 一旦知道了，对答案的每一个贡献都是本地的。 

变量`base`商店$$\sum(a_i-s_i).$$字典`freq`计算每个后缀最小值出现的次数。 最大频率决定了单次去除可获得的最佳改进。 

所有算术都使用 Python 整数。 最大可能的答案大约是$n^2$，很容易适合。

    out = []

        n = int(input())

assert run("1\n1\n1\n") == "0"

# strictly increasing
assert run("1\n5\n1 2 3 4 5\n") == "0"

# all equal
assert run("1\n4\n3 3 3 3\n") == "3"

# suffix minimum repeated many times
assert run("1\n5\n1 2 3 2 1\n") == "8"

# decreasing array
assert run("1\n5\n5 4 3 2 1\n") == "10"

 ## 边缘情况

 考虑$$[1,2,3,4,5].$$后缀最小数组等于原始数组。 每个频率都是$1$，所以改进项是$0$。 算法输出$0$，与没有立方体移动的事实相匹配。 

考虑$$[3,3,3,3].$$后缀最小数组为$$[3,3,3,3].$$基本答案是$0$，但值$3$出现四次。 改进的是$$4-1=3.$$该算法正确地捕捉到了从共享的最小平台中移除一个立方体的好处。 

考虑$$[5,4,3,2,1].$$后缀最小数组为$$[1,1,1,1,1].$$基本答案是$$(5-1)+(4-1)+(3-1)+(2-1)+(1-1)=10.$$最大频率为$5$，改进了$4$。 该算法完全通过后缀最小频率来处理这个问题，而不模拟重力。
