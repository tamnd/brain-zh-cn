 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$网格，其中每个单元格都是黑色或白色。 单个操作只允许一次：我们选择一个左上角$k \times k$正方形并将该正方形内的每个单元格重新绘制为白色。 执行此操作后，某些行和列可能会变成全白。 

如果行或列在重新绘制后根本不包含黑色单元格，则该行或列被视为“白色”。 目标是选择$k \times k$重新绘制正方形，以使全白行加全白列的总数最大化。 

关键在于，该操作并不添加黑色单元，而只是将其删除在一个固定方格内。 在该正方形之外，网格保持不变。 因此，选择的效果是局部的，但其影响是全局的，因为它可以完成整个行或列。 

约束条件允许$n \le 2000$，所以一个$O(n^3)$或者更糟糕的解决方案将无法生存。 对所有内容进行天真的扫描$O(n^2)$放置，重新计算行和列的有效性$O(n^2)$, 将达到$8 \cdot 10^9$在最坏的情况下，操作速度太慢。 我们需要一种方法来在预处理后在近乎恒定的时间内评估每个位置。 

一些边缘情况很容易被低估。 

如果一行在任何操作之前已经是全白的，那么无论我们将方块放在哪里，它总是贡献 1。 这同样适用于列。 例如，如果网格是全白色的，则答案是$2n$，任何在不分离静态贡献的情况下重新计算所有内容的幼稚方法可能会意外地重复计算或错误地重新计算。 

另一个微妙的情况是当一行中有黑色单元格分布在任何单个单元格之外时$k \times k$窗户。 该行永远不会通过操作变成白色，并且必须全局检测这一事实，而不是每个候选位置。 

最后，一行或一列的所有黑色单元格都位于一个$k \times k$根据放置，区域变得“可修复”。 几何形状和间隔之间的这种依赖性使得问题变得不那么简单。 

## 方法

 直接方法尝试橡皮擦的每个可能的左上角位置。 对于每个位置，我们模拟重新绘制$k \times k$块，然后通过完全扫描来重新计算哪些行和列是全白的。 这是正确的，因为它准确地反映了该过程。 但是，从头开始重新计算每个放置的行和列的有效性$O(n^2)$，并与$O(n^2)$这变成了展示位置$O(n^4)$，远远超出了极限。 

即使我们通过跟踪每行和每列的黑色计数来进行优化，我们仍然面临着核心的低效率问题：我们不断地从重叠的矩形中重新计算相同的局部贡献。 

关键的观察结果是，选择放置的效果仅对与所选位置相交的行和列起作用。$k \times k$正方形。 其他一切都没有改变。 因此，我们应该将答案分为两部分：已经是白色的行和列，以及由于消除了所选正方形内剩余的黑色单元而变成白色的行和列。 

为了使一行在选择一个正方形后变成全白，该行中的每个黑色单元格都必须位于所选的正方形内$k \times k$窗户。 这意味着正方形必须覆盖该行中的最小和最大黑色列位置，并且其垂直位置必须与该行本身相交。 同样的想法对称地适用于柱。 

因此，每一行和每一列都贡献了一组有效位置，正方形可以在其中“固定”它。 问题归结为在所有正方形放​​置中计算有多少个这样的间隔重叠。 

我们将每一行和每一列转换为左上角的一组约束$(i, j)$，然后使用二维差分数组累积所有有效位置的贡献。 这会将每一行或每一列转换为$O(1)$矩形更新，最终答案来自前缀和。

 | --- | --- | --- | --- |
 | 蛮力 |$O(n^4)$|$O(n^2)$| 太慢了 |
 | 最佳 |$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们将解决方案分为静态贡献和动态贡献。 

1. 首先，我们扫描网格并记录每行和每列的所有黑色单元格。 这让我们可以立即识别已经全白的行或列。 无论进行何种操作，每个这样的行或列都会为最终答案贡献 1。 
2. 对于至少包含一个黑色单元格的每一行，我们计算其最左边和最右边的黑色列位置。 如果黑色单元格的范围比$k$，那么没有单个$k \times k$square 可以水平覆盖所有行，因此该行在操作后永远不会变成全白。 
3. 如果该行可能是可修复的，我们确定正方形左上角的所有位置$(i, j)$这将覆盖该行黑色部分的两个极端。 纵坐标$i$必须满足$i \le r \le i+k-1$， 所以$i$在于$[r-k+1, r]$。 水平坐标必须保证$[minCol, maxCol]$位于正方形内部，所以$j \in [maxCol-k+1, minCol]$。 这在可能的放置空间中定义了一个矩形。 
4. 我们使用二维差分数组向该矩形添加 +1。 这确保了使该行完全变白的橡皮擦的每次放置都被精确地计数一次。 
5. 我们对列重复相同的过程，对称地处理每列。 每列还在同一坐标空间中贡献一个有效放置的矩形。 
6. 处理完所有行和列后，我们计算差异数组的 2D 前缀和。 每个单元格的值$(i, j)$表示如果将正方形放置在那里，有多少行和列变成全白色。 
7. 最终答案是所有有效答案中的最大值$(i, j)$，加上已经全白的行数和列数。 

### 为什么它有效

 每行或列根据其黑色单元格是否被所选方块完全覆盖来独立贡献。 2D 差异数组可确保每个有效位置在每个完全覆盖的行上准确累积一个贡献。 因为每一行和每一列都被转换为有效正方形位置的几何区域，并且因为这些区域是线性相加的，所以前缀和正确聚合重叠，而不会在单行贡献内重复计算。 

不变的是，处理完所有线后，每个网格单元$(i, j)$准确存储当橡皮擦放置在位置时变白的行数和列数$(i, j)$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
grid = [input().strip() for _ in range(n)]

base = 0
row_min = [n] * n
row_max = [-1] * n
col_min = [n] * n
col_max = [-1] * n

for i in range(n):
    for j in range(n):
        if grid[i][j] == 'B':
            row_min[i] = min(row_min[i], j)
            row_max[i] = max(row_max[i], j)
            col_min[j] = min(col_min[j], i)
            col_max[j] = max(col_max[j], i)

# count already clean rows and columns
for i in range(n):
    if row_max[i] == -1:
        base += 1
    if col_max[i] == -1:
        base += 1

m = n - k + 1
diff = [[0] * (m + 2) for _ in range(m + 2)]

def add(x1, y1, x2, y2):
    diff[x1][y1] += 1
    diff[x2 + 1][y1] -= 1
    diff[x1][y2 + 1] -= 1
    diff[x2 + 1][y2 + 1] += 1

for i in range(n):
    if row_max[i] == -1:
        continue
    if row_max[i] - row_min[i] + 1 > k:
        continue

    x1 = max(0, i - k + 1)
    x2 = min(i, m - 1)
    y1 = max(0, row_max[i] - k + 1)
    y2 = min(m - 1, row_min[i])

    if x1 <= x2 and y1 <= y2:
        add(x1, y1, x2, y2)

for j in range(n):
    if col_max[j] == -1:
        continue
    if col_max[j] - col_min[j] + 1 > k:
        continue

    x1 = max(0, col_max[j] - k + 1)
    x2 = min(m - 1, col_min[j])
    y1 = max(0, j - k + 1)
    y2 = min(m - 1, j)

    if x1 <= x2 and y1 <= y2:
        add(x1, y1, x2, y2)

ans = 0
for i in range(m):
    cur = 0
    for j in range(m):
        cur += diff[i][j]
        diff[i][j] = cur
        if i > 0:
            diff[i][j] += diff[i - 1][j]
        ans = max(ans, diff[i][j])

print(ans + base)
```该实现首先将每一行和每一列压缩到其极端黑色位置。 差异数组将每条线的所有有效位置编码为可能的左上角空间中的矩形。 在前缀累积期间，每个单元格累积来自基于行和基于列的约束的贡献。 最后，我们添加已经干净的线条，这些线条与橡皮擦位置无关。 

必须小心边界裁剪。 有效的左上角坐标形成一个简化的$(n-k+1) \times (n-k+1)$网格，因此每个计算的间隔必须限制在这个范围内。 这里相差一的错误是错误答案的最常见来源。 

## 工作示例

 ### 示例 1

 输入：```
4 2
BWWW
WBBW
WBBW
WWWB
```我们首先计算哪些行和列已经是全白的。 最初没有任何行或列是全白的，所以`base = 0`。 

我们计算极端黑色位置：

 | 行| 最小颜色 | 最大列数 | 宽度 > k? |
 | --- | --- | --- | --- |
 | 1 | 1 | 1 | 没有|
 | 2 | 1 | 2 | 没有|
 | 3 | 1 | 2 | 没有|
 | 4 | 3 | 3 | 没有|

 每行贡献一个有效位置的矩形。 前缀积累后，最佳放置位置$(2,2)$产生 4 条全白线。 

这证实了行和列的重叠贡献都被捕获在同一放置网格中。 

### 示例 2

 考虑一个更简单的网格：```
3 2
BWB
WWW
BBW
```第 2 行已经是白色，为基数贡献 +1。 

第 1 行仅在第 1 列处有黑色，因此有效方块必须覆盖第 1 列。第 3 行在第 1 列和第 2 列处都有黑色，因此只有当方块覆盖这两列时才可以修复。 

处理约束后，最佳放置最多产生 3 条白线。 

此跟踪显示了如何独立计算已经是白色的行以及其他行如何将有效布局限制到特定矩形。

 ## 边缘情况

 一排黑色单元格分布得比$k$演示了没有放置可以修复它的情况。 该算法通过在生成任何矩形之前检查宽度条件来处理此问题，确保不会添加无效的贡献。 

全白的行或列通过`base`变量，这意味着它不依赖于橡皮擦的位置。 即使差异数组对该行没有贡献，这也可以防止重复计算并确保正确性。 

一行的黑色部分恰好适合$k \times k$窗口在放置空间中生成一个连续的矩形。 前缀总和正确地计算了覆盖该区域的所有展示位置，并且网格上的最大值捕获了与其他行和列的最佳重叠。
