 ## 解决方案
 ## 问题理解

 我们得到了一个数字序列以及一种非常具体的重新排序方法。 在一次操作中，我们选择任何元素，然后将其一直推到数组的前面或一直推到数组的后面。 其他一切都会发生变化以填补空白，但未触及元素的相对顺序被保留。 

目标是使用尽可能少的操作将数组转换为非递减序列。 每个操作只移动一个元素，因此成本就是我们主动重新定位的元素数量。 

驱动一切的关键约束是数组的大小。 高达$2 \cdot 10^5$跨所有测试用例的元素，任何尝试显式模拟操作或探索子集的解决方案都不会通过。 甚至$O(n^2)$每个测试用例的推理已经太慢了，任何涉及重复模拟重新排序的事情都是完全不可行的。 我们被迫陷入$O(n \log n)$或每个测试用例的线性结构。 

当考虑局部修复时，会出现一种微妙的故障模式。 例如，在像这样的数组中$[0, 1, 0]$，人们很容易只修复反转并假设一步就足够了，因为只有一个元素是“错误的”。 但成本与局部反演无关； 这取决于在任意前后移动后，有多少元素可以保持不变，同时仍形成全局排序结构。 

另一个陷阱是假设我们正在构建一个连续的排序块。 这种直觉被打破了，因为操作允许将元素拉到两端，这意味着最终的排序数组不需要与原始数组的连续段相对应。 

## 方法

 最直接的想法就是尝试所有可能的元素子集保持不变。 如果我们决定哪些元素保留在数组中而不被移动，那么所有其他元素将单独移动到前面或后面。 原则上这是正确的，因为我们不保留的每个元素都只贡献一次操作。 

然而，检查子集是否可以保留在原处需要验证这些元素是否可以按照其原始相对顺序以非降序出现，因为未触及的元素会保留其序列。 这与非递减子序列的定义非常相似。 

如果我们进一步推进，问题就变成了：最大化我们可以保持不变的元素数量，以便它们已经在原始数组中形成有效的非递减序列。 该结构之外的每个元素都必须移动一次。 

这正是最长非递减子序列（LNDS）。 这个子序列中的元素正是我们可以“不去管”的元素，而所有其他元素都按某种顺序移动到末尾而不影响可行性。 

蛮力视图将尝试所有子集并检查有效性，其增长为$2^n$。 观察到对未触及元素的唯一约束是子序列顺序，这减少了查找 LNDS 的任务，可以使用带有二分搜索的贪婪结构来有效计算 LNDS。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力子集 |$O(2^n \cdot n)$|$O(n)$| 太慢了 |
 | LNDS（二分搜索）|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 核心思想是跟踪每个长度的非递减子序列的最小可能结束值。 

1. 维护清单`dp`在哪里`dp[k]`是长度非递减子序列的最小可能最后值`k + 1`到目前为止所看到的。 这种结构确保我们始终保持子序列尽可能“可扩展”。 
2. 从左到右迭代数组，一次处理一个值。 每个值都试图扩展现有的子序列或替换更差的尾部。 
3. 对于每个元素`x`, 找到第一个位置`dp`其中该值严格大于`x`。 这个位置告诉我们在哪里`x`可以拟合，同时保持非递减顺序。 
4. 如果存在这样的位置，则将其替换为`x`。 否则，附加`x`到最后`dp`。 这保留了不变量`dp`对于所有子序列长度仍然是最佳的。 
5.处理完所有元素后，得到的长度`dp`是最长非递减子序列的长度。 
6. 测试用例的答案是不在该子序列中的元素数量，计算公式为`n - len(dp)`。 

这样做的原因是 LNDS 中的元素已经以正确的相对顺序出现，不需要移动。 可以提取所有其他元素并将其放置在开头或结尾，而不会干扰子序列结构，因此每个这样的元素只花费一次操作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        dp = []

        for x in a:
            lo, hi = 0, len(dp)
            while lo < hi:
                mid = (lo + hi) // 2
                if dp[mid] <= x:
                    lo = mid + 1
                else:
                    hi = mid
            if lo == len(dp):
                dp.append(x)
            else:
                dp[lo] = x

        print(n - len(dp))

if __name__ == "__main__":
    solve()
```该实现为非递减子序列维护了经典的耐心排序结构。 二分查找找到第一个位置`x`可以扩展或改进子序列。 使用`<= x`确保子序列是非递减的而不是严格递增的，这是给定重复值时正确性的关键细节。 

最后的减法将问题从“最大化保留的结构”转换为“最小化移动的元素”，因为每个删除的元素恰好对应于一个操作。

 ## 边缘情况

 单元素数组已经满足条件，因此不需要任何操作。 LNDS 的长度为 1，减法正确返回 0。 

所有元素都相等的数组会生成长度完整的非递减子序列$n$。 由于没有元素需要重定位，因此答案变为 0，二分查找正确地将每个元素放置在`dp`。 

严格递减数组强制每个新元素替换第一个位置`dp`，将其长度保持为 1。这会产生答案$n - 1$，符合只有一个元素可以按正确顺序保持不变的事实。
