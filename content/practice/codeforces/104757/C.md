 ## 解决方案
 ## 问题理解

 我们得到了一个最终形式的凸多边形，由其顶点按逆时针顺序描述。 不存在简并性：多边形是严格凸的，并且每个顶点都是真正的角。 

我们被要求计算整数格点$p = (x,y)$这样当我们添加$p$对于一组顶点，凸包恰好获得一个新顶点。 除了一个“边替换”之外，所有原始顶点都必须保留为新外壳的顶点，并且生成的多边形必须仍然严格保持非退化，这意味着插入后不会有三个顶点共线。 

从几何角度来看，这意味着我们正在寻找以一种非常受控的方式从多边形中“伸出”的整数点：它们必须位于多边形之外，但不能太远，也不能在这样的方向上，以至于它们会重塑船体的多个边缘。 添加这样一个点的效果是，原始多边形的一条边被穿过新点的两条边所替换。 

约束很小：最多 50 个顶点和坐标限制在 2000 x 2000 的网格内。 这表明，目的是对每个边缘的有效区域进行几何分类，或者对少量区域内的直接网格点进行计数，而不是进行任何全局的繁重计算。 

一个微妙的问题是，“多边形之外”本身就太弱了。 每个凸多边形外部都有无限多个整数点，因此如果这足够了，答案将始终是无限的。 因此，问题实际上是关于保留所有原始顶点（除了精确分割船体的一条边）的点。 

一个天真的错误是假设多边形外部的任何点都会将外壳尺寸增加一。 例如，在正方形中，远高于顶部边缘的点并不简单地添加一个顶点：它通常会替换两个相切点之间的整个顶点链，从而减少幸存的原始顶点数量并使净变化不等于 +1。 

因此，关键的隐藏结构是有效的扩展点必须以非常本地化的方式与船体交互。 

## 方法

 一个蛮力的想法是测试边界框中的每个整数点，并在添加它后重新计算凸包。 这在概念上很简单：我们尝试每个候选者$p$，计算新的外壳，并检查顶点数是否恰好增加 1 并且没有出现简并。 

然而，即使边界框有大约$4 \times 10^6$整数点，为每个候选重新计算大小最大为 51 的凸包仍然大致给出$2 \times 10^8$几何运算，每个船体构造都涉及排序或扫描，这使其远远超出了安全极限。 

关键的观察是我们不需要全局重新计算船体。 原始多边形已经是凸的且有序的，因此外壳改变的唯一方法是通过切线$p$到多边形。 这些切线确定了被替换的顶点的连续间隔。 为了使顶点数恰好增加 1，该间隔必须是单边。 这意味着两个切点必须是原始多边形的相邻顶点。 

此约束将问题折叠为每个边缘周围的局部几何形状。 对于每条边$(v_i, v_{i+1})$，我们可以表征所有点$p$其支撑切线恰好接触这两个顶点。 这些点位于由少量半平面约束定义的区域中，这些半平面约束源自每个端点处的两个相邻边。 

一旦我们固定了一条边，有效区域就变成了凸多边形区域。 由于所有坐标都是有界的，因此这些区域是有限的多边形，因此我们可以使用有界框上的扫描或多边形晶格计数技术直接对它们内部的整数晶格点进行计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解网格+船体重新计算 |$O(R^2 \cdot n \log n)$|$O(n)$| 太慢了 |
 | 基于边缘的区域构建+格子计数|$O(n \cdot R^2)$或更好|$O(n)$| 已接受 |

 这里$R \le 2000$， 所以$R^2$当与严格的几何过滤相结合时是可以接受的。 

## 算法演练

 1.迭代每条边$(v_i, v_{i+1})$的多边形。 每条边都是一个候选位置，新顶点可以“插入”自身。 

我们隔离边的原因是，有效的扩展点必须恰好分割外壳上的一条现有边，否则多个顶点将受到影响。 
2. 对于固定边，构造点的几何区域，使凸包恰好在$v_i$和$v_{i+1}$。 该区域的定义是要求所有其他顶点严格保持在新点引起的支撑线“下方”。 

具体来说，对于多边形的每个其他边，我们强制候选点位于该边的支撑线的内侧。 这可确保没有其他顶点成为切点。 
3. 添加该点必须位于所选边定义的半平面之外的条件$(v_i, v_{i+1})$。 这可以确保该点实际上贡献一个新顶点，而不是留在原始多边形内。 
4.所有这些半平面约束的交集形成凸区域。 由于所有约束都是线性不等式，因此该区域是多边形的，并且可以通过顺序相交的半平面来描述。 
5. 将此区域剪裁成每个边的最终多边形，然后计算其中的所有整数格点。 由于坐标很小，我们可以安全地枚举区域边界框内的整数点，并测试所有半平面的隶属度。 
6. 对所有边上的计数求和。 由于每个有效点恰好对应于成为新“分割”的一个边缘，因此不会出现重复计数。 

### 为什么它有效

 关键的不变量是任何有效的扩展点必须在原始外壳上恰好有两个相切顶点，并且这两个顶点必须相邻。 这是根据船体仅获得一个顶点的要求得出的。 如果相切发生在非相邻顶点上，则整个中间顶点链将被删除，从而使顶点数改变一个以上或减少。 

因此，每个有效点都唯一地属于一个基于边缘的区域，并且该区域内的每个点都会产生有效的凸包扩展。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def orient(a, b, c):
    return (b[0]-a[0])*(c[1]-a[1]) - (b[1]-a[1])*(c[0]-a[0])

def inside_halfplanes(x, y, halfplanes):
    for (a, b, c) in halfplanes:
        if (b[0]-a[0])*(y-a[1]) - (b[1]-a[1])*(x-a[0]) < 0:
            return False
    return True

def solve():
    n = int(input())
    p = [tuple(map(int, input().split())) for _ in range(n)]

    xs = [x for x, y in p]
    ys = [y for x, y in p]

    minx, maxx = min(xs), max(xs)
    miny, maxy = min(ys), max(ys)

    # Build half-planes of polygon (keeping interior on left side)
    poly_hp = []
    for i in range(n):
        a = p[i]
        b = p[(i+1) % n]
        poly_hp.append((a, b, 1))

    ans = 0

    for i in range(n):
        a = p[i]
        b = p[(i+1) % n]

        # candidate region half-planes:
        # must be outside edge (a,b): opposite side of polygon interior
        # so we flip orientation
        halfplanes = []

        # all other edges: must remain inside polygon
        for j in range(n):
            u = p[j]
            v = p[(j+1) % n]

            if j == i:
                continue

            # inside condition: orientation(u,v,point) >= 0
            halfplanes.append((u, v, 1))

        count = 0

        # bounding box search (safe due to constraints)
        for x in range(minx-1, maxx+2):
            for y in range(miny-1, maxy+2):
                # must be outside chosen edge
                if orient(a, b, (x, y)) >= 0:
                    continue

                if inside_halfplanes(x, y, halfplanes):
                    count += 1

        ans += count

    print(ans)

if __name__ == "__main__":
    solve()
```该代码直接遵循逐边区域构造。 对于每条边，它都会构建一个约束系统，使该点保持在多边形的所有其他支撑半平面内，同时迫使其位于所选边之外。 对边界框进行强力扫描是安全的，因为所有候选区域都包含在与输入多边形相同的坐标限制内。 

功能`orient`是用于测试单面性的标准叉积。 帮手`inside_halfplanes`验证一个点是否位于所有未选择的边的正确一侧。 

对边的最终求和反映了这样一个事实：每个有效扩展点都与成为新插入顶点的一条边唯一关联。

 ## 边缘情况

 一种重要的边缘情况是多边形是完美的矩形或正方形。 在这种情况下，每条边都会产生一个无界的可行区域，因为来自非相邻边的约束不会限制一个方向的增长。 这导致无限多个整数点，与样本行为相匹配。 

另一种情况是小三角形。 尽管它只有三个边，但每个边仍然定义一个无界区域，但是来自其他两条边的约束的相互作用将有效整数点限制为顶点扩展附近的有限集。 

当候选点非常靠近多边形边缘但不在其上时，会出现最后一种微妙的情况。 这些必须完全根据交叉乘积检查中的严格不平等来包含或排除。 在错误的地方使用非严格比较会错误地包括共线点，违反“没有三个共线顶点”的要求。
