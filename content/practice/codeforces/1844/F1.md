 ## 解决方案
 ## 问题理解

 我们得到一个正整数数组和一个数字$c$可以是负数、零或正数。 任务是将数组重新排序为一个排列，使连续元素之间的绝对差之和最小化，调整为$c$。 具体来说，对于一个排列$b$的$a$，我们想要最小化$$\sum_{i=1}^{n-1} |b_{i+1} - b_i - c|.$$在达到这个最小总和的所有排列中，我们必须输出字典顺序最小的一个。 字典顺序意味着两个序列不同的第一个元素决定哪个较小。 

输入限制适中。 每个数组最多可以有 5000 个元素，最多可以有 1000 个测试用例，但所有测试用例的元素总数不超过 5000。这告诉我们，任何具有总体复杂度的解决方案大致$O(n \log n)$或者$O(n^2)$是可行的。 

非明显的边缘情况是$c$相对于数组元素非常负或非常正。 例如，如果$a = [1,2,3]$和$c = 10$，那么如果连续差值尽可能接近 10，则总和最小化。 如果我们天真地对数组进行排序，我们可能会错过使$|b_{i+1} - b_i - c|$最小的。 另一个边缘情况是当所有元素都相等时，例如$a = [5,5,5]$和$c$是任意的。 任何排列都会产生相同的总和，因此按字典顺序排列的最小序列就是排序后的数组。 

## 方法

 蛮力方法是生成所有$n!$排列，计算每个排列的总和，然后选择最小值。 即使对于$n=10$， 因为$10! = 3,628,800$运营。 所以我们需要一种更加结构化的方法。 

关键的见解是，当参数的符号固定时，绝对值函数呈线性行为。 对于两个连续的数字$b_i$和$b_{i+1}$， 期限$|b_{i+1} - b_i - c|$最小时$b_{i+1} - b_i$尽可能接近$c$。 这意味着我们希望排列数组元素，以便连续差异近似$c$。 

我们可以将其形式化如下。 我们先对数组进行排序。 然后考虑贪婪放置：我们维护一个已放置元素的双端队列，并选择最大的剩余元素或最小的剩余元素，使当前差异接近$c$。 什么时候$c$是负数，差异应该是负数，所以较大的数字应该先于较小的数字。 什么时候$c$是正数，较小的数字应该先于较大的数字。 这相当于重复从已排序数组的末尾进行拾取，模拟“倾斜”排列。 

一旦我们知道了大致方向（如果$c\ge 0$, 递减如果$c<0$），如果两种选择对总和的贡献相同，我们总是可以通过首先选择较小的元素来打破字典顺序的关系。 这同时确保了最小总和和字典顺序最小的顺序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$,$c$，和数组$a$。 排序$a$是管理词典顺序的第一个自然步骤。 
2. 将数组按升序排序。 这使我们能够从数组的末端做出贪婪的决定，以获得最小的贡献。 
3. 初始化两个指针，一个位于排序数组的开头，一个位于排序数组的末尾。 还初始化一个空结果数组。 
4. 当还有剩余元素时，如果我们将最小剩余元素或最大剩余元素附加到当前序列，则评估绝对差异（取$c$考虑在内）。 选择总和最小的一项。 如果两种选择产生相同的贡献，则选择较小的元素以维持字典顺序。 
5. 重复此操作，直至放置完所有元素。 
6. 输出排列结果。 

为什么它有效：在每一步，我们贪婪地选择最小化对总和的增量贡献的元素。 因为我们只需要考虑连续的差异，并且我们总是在两个极端中选择最好的选择，这确保了全局最小性。 首先排序可以保证在平局的情况下，我们选择字典顺序最小的选项。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, c = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()
        if n == 1:
            print(a[0])
            continue
        res = []
        i, j = 0, n-1
        while i <= j:
            if not res:
                # first element, pick smallest
                res.append(a[i])
                i += 1
            else:
                # decide to pick from left or right
                left = abs(a[i] - res[-1] - c)
                right = abs(a[j] - res[-1] - c)
                if left <= right:
                    res.append(a[i])
                    i += 1
                else:
                    res.append(a[j])
                    j -= 1
        print(" ".join(map(str, res)))

if __name__ == "__main__":
    solve()
```该解决方案首先对数组进行排序以管理字典顺序。 主循环考虑排序数组的两端，计算附加该元素时对总和的增量贡献。 通过选择最小值，总和逐渐最小化。 排序还确保字典顺序的平局打破是正确的。
