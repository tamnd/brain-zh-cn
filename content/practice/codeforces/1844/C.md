 ## 解决方案
 ## 问题理解

 我们得到了排列成一条线的一系列粒子，每个粒子都有一个整数电荷。 我们有一个设备，可以让我们删除任何粒子，然后两个相邻的粒子合并成一个粒子，其电荷是两个邻居的总和。 目标是应用一系列此类操作，直到只剩下一个粒子，并使最后一个粒子的电荷最大化。 

输入由多个测试用例组成。 对于每个测试用例，我们知道粒子的数量及其各自的电荷。 输出是执行最佳操作后剩余粒子的最大可能电荷。 

约束条件很重要：最多可以有$2 \cdot 10^5$所有测试用例中的粒子总数，单个电荷可能非常大或为负。 由于这些限制，任何重复删除粒子并重新计算数组的简单模拟都太慢； 模拟每个操作可能需要$O(n^2)$时间，对于大量输入来说不会在一秒钟内完成。 

当所有粒子均为负值时，会出现微妙的边缘情况。 不加区别地合并粒子的粗心方法可能会不必要地减少最大剩余电荷。 例如，如果该行是`[-1, -2, -3]`，最优策略是以保持最小负和作为最终粒子的方式合并负数。 

## 方法

 蛮力方法很简单：对于每个可能的粒子去除，递归地模拟所有可能的剩余序列，直到剩下一个粒子，然后取最大值。 这保证会产生正确的答案，因为它探索了每个可能的操作序列。 然而，这种方法的时间复杂度是阶乘的：$n$颗粒，大致有$n!$要探索的序列，这对于$n \sim 10^5$。 

关键的观察结果是，除了对连续的正序列或负序列进行分组之外，合并的顺序并不重要。 该操作本质上是合并相邻的数字，因此最后，最终粒子的电荷是原始数组的连续子序列的总和，可能是在跳过负和的零长度合并之后。 这将问题简化为最大子数组和问题的变体。 

具体来说，剩余粒子的最大可能电荷等于非负组合和的最大连续子序列之和。 这可以通过迭代数组、贪婪地合并连续粒子来在线性时间内计算：始终对所有正贡献求和，并在总和因包含负前缀而变小时重置总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取粒子数`n`以及收费清单`c`。 
2.初始化两个变量：`current_sum`跟踪连续子序列的持续总和，以及`max_sum`跟踪找到的最大总和。 
3. 按顺序迭代费用。 对于每个粒子，将其电荷添加到`current_sum`。 如果`current_sum`单独变得小于当前粒子，重置`current_sum`到粒子的电荷。 这是 Kadane 最大子数组和算法的标准修改。 
4. 更新`max_sum`如果`current_sum`超过它。 
5.处理完所有颗粒后，`max_sum`包含最终粒子的最大可实现电荷。 
6. 打印或存储每个测试用例的结果。 

为什么有效：合并操作将序列简化为连续段的总和。 任何最佳的合并序列都不能在不损失潜在总和的情况下跳过积极的贡献。 因此，找到所有连续段的最大总和相当于最佳地执行合并。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        c = list(map(int, input().split()))
        current_sum = max_sum = c[0]
        for charge in c[1:]:
            current_sum = max(charge, current_sum + charge)
            max_sum = max(max_sum, current_sum)
        print(max_sum)

if __name__ == "__main__":
    solve()
```该解决方案对多个测试用例使用快速 I/O。 它只对每个粒子处理一次，并有效地维护运行总和，确保不会出现整数溢出，因为 Python 整数是任意精度的。

 ## 边缘情况

 如果数组仅包含负数，则算法会正确选择最小负粒子，这对应于不执行会减少值的合并。 例如，`[-1, -2, -3]`回报`-1`。 

如果只有一个粒子，则不需要任何操作，算法直接返回该粒子。 

该解决方案还可以处理大的正整数而不会溢出，因为 Python 支持任意精度整数。
