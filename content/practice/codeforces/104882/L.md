 ## 解决方案
 ## 问题理解

 我们正在尝试恢复平面上的一条未知直线，已知其形式为$y = kx + b$，其中两个参数都是介于之间的实数$-100$和$100$。 了解有关该线的任何信息的唯一方法是提出以下形式的问题：“距此点的最短距离是多少？$(x, y)$到线吗？”，然后法官返回该距离。

 交互受到限制：我们最多可以问五个这样的问题，之后我们必须输出一个近似值$k$和$b$最多有相对或绝对误差$10^{-3}$。 

每个查询给出一个几何约束：距一条线固定距离的所有点形成两条平行线。 因此，每个答案并不固定一条线，而是将其限制为围绕查询点的一对对称的可能性。 困难在于将少量的非线性约束组合成一条独特的线。 

界限以一种微妙的方式起作用。 自从$k$和$b$很小，我们可以安全地构造带有坐标的查询，例如$-100, 0, 100$没有数值不稳定。 问题不在于数值精度，而在于解决距离公式中绝对值的歧义。 

一个幼稚的策略会尝试从两三个点猜测这条线，但我们并没有得到线上的点，只有距离。 这意味着我们永远不会直接观察符号信息。 

常见的失败情况是假设距离公式内的符号是固定的。 例如，解释距离$(0,0)$作为$b / \sqrt{k^2+1}$忽略了它实际上是$|b| / \sqrt{k^2+1}$，失去了符号$b$。 任何忽略这种对称性的方法都会产生多个有效的候选线。 

## 方法

 蛮力的想法是采样几个点，将每个查询视为定义一对平行边界线，并尝试以几何方式相交所有可能性。 每个查询都会引入二进制歧义，因此之后$m$我们可能有最多的查询$2^m$候选线。 通过五个查询，这已经达到了 32 种可能性，这仍然是可以管理的，但是如果直接以斜率截距形式完成，交叉点的几何形状会变得混乱且数值不稳定。 

关键的观察是切换表示。 而不是与$y = kx + b$，我们以标准化形式处理该线：$$Ax + By + C = 0$$我们的线路在哪里$A = k$,$B = -1$,$C = b$，直至缩放。 距离公式变为：$$\frac{|Ax + By + C|}{\sqrt{A^2 + B^2}}$$每个查询给出一个二次方程$A, B, C$，但更重要的是，它给出了符号和共享归一化因子的线性约束。 

我们通过选择三个精心挑选的点来减少问题。 每个查询都会产生：$$|kx - y + b| = d \cdot \sqrt{k^2 + 1}$$让$t = \sqrt{k^2 + 1}$。 那么每个查询就变成：$$kx - y + b = \pm d \cdot t$$这将问题转化为解决具有未知数的小系统$k, b, t$和每个方程的未知符号。 通过三个查询，我们得到三个方程和只有八个可能的符号分配，我们可以暴力破解。 每个作业都会产生一个候选解决方案，可以检查其一致性。 

这将几何重建转化为有限枚举问题，每种情况都有一个封闭形式的解决方案。

 ## 算法演练

 我们选择三个固定查询点：$(0,0)$,$(100,0)$， 和$(0,100)$。 

1. 查询$(0,0)$， 收到$d_1$。 这对应于$|b| = d_1 \cdot t$， 在哪里$t = \sqrt{k^2 + 1}$。 
2、查询$(100,0)$， 收到$d_2$。 这给出了$|100k + b| = d_2 \cdot t$。 
3、查询$(0,100)$， 收到$d_3$。 这给出了$|b - 100| = d_3 \cdot t$。 

此时，所有信息都被编码在具有共享比例因子的三个绝对值方程中$t$。 

1. 枚举所有符号三元组$(e_1, e_2, e_3) \in \{\pm 1\}^3$。 将每个绝对值替换为有符号形式：$$b = e_1 d_1 t,\quad 100k + b = e_2 d_2 t,\quad b - 100 = e_3 d_3 t$$2. 从前两个方程中消去$b$并解决$k$按照$t$:$$100k = t(e_2 d_2 - e_1 d_1)$$所以$$k = \frac{t(e_2 d_2 - e_1 d_1)}{100}$$3. 代入$t^2 = k^2 + 1$，它产生一个方程$t$。 明确地解决它。 
4. 恢复$k$和$b$，然后验证与第三个方程的一致性：$$|b - 100| \approx d_3 t$$如果它在容差范围内匹配，则该分配是正确的。 
5、输出$k, b$。 

关键机制是每个符号选择将非线性绝对约束转换为一个剩余标量未知的线性系统，并且归一化条件唯一地解析该标量。 

### 为什么它有效

 该线完全由该表示中的三个实自由度决定：隐式形式的斜率、截距和比例。 每个查询贡献一个二次约束，但是在引入共享尺度之后$t$，每个都变成线性直到一个符号。 符号歧义是离散的且很小，因此详尽的枚举可以保证测试正确的配置。 一旦选择了正确的符号，系统就会有一个唯一的一致解决方案，并且所有其他配置都会违反至少一个约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

def ask(x, y):
    print(f"? {x} {y}")
    sys.stdout.flush()
    d = float(input().strip())
    if d < 0:
        sys.exit(0)
    return d

def solve():
    d1 = ask(0, 0)
    d2 = ask(100, 0)
    d3 = ask(0, 100)

    for e1 in (-1, 1):
        for e2 in (-1, 1):
            for e3 in (-1, 1):

                # We derive t from k^2 + 1 = t^2
                # k = t * C / 100, where C = e2*d2 - e1*d1
                C = e2 * d2 - e1 * d1

                denom = 1 - (C * C) / 10000.0
                if abs(denom) < 1e-12:
                    continue

                t2 = 1.0 / denom
                if t2 <= 0:
                    continue

                t = math.sqrt(t2)

                k = t * C / 100.0
                b = e1 * d1 * t

                # verify third equation
                if abs(abs(b - 100) - d3 * t) < 1e-3:
                    print(f"! {k:.10f} {b:.10f}")
                    sys.stdout.flush()
                    return

solve()
```该实现直接反映了代数。 唯一的微妙之处是当分母$1 - C^2 / 10000$由于符号的近简并配置而变得非常小。 

验证步骤至关重要，因为当浮点舍入与平方根提取相互作用时，多个代数分支可能会产生数值上合理但不正确的解。

 尝试标志配置$e_1 = +1, e_2 = +1, e_3 = -1$一致地对齐所有表达式。 派生系统重构$t$， 然后$k = 2$,$b = 5$，并通过第三个约束。

 ## 边缘情况

 一种微妙的情况是当$1 - C^2 / 10000$变得非常小。 这对应于近乎简并的配置，其中导出的线性关系几乎迫使$k^2 \approx -1$，这是不可能的，表明符号分配无效。 在这种情况下，算法由于分母检查而安全地跳过分支。 

另一个边缘情况是当$b = 0$，使第一个查询返回零距离。 该算法自然地处理这个问题，因为$e_1 d_1 t = 0$力量$b = 0$不管$t$，其余方程仍然确定$k$独一无二。 

第三种情况是当直线在斜截距表示中几乎垂直时，但由于$k$是有界且有限的，表示保持稳定并且通过标准化$t$防止爆炸。
