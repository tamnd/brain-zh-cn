 ## 解决方案
 ## 问题理解

 我们有一棵有根的树$n$节点，标记为$1$到$n$，有节点$1$作为根。 对于每个节点$u$, 一个数字$a_u$已指定。 这个数字代表祖先的计数$v$的$u$（包括$u$如果我们愿意的话）这样分配给的值$v$在排列中$p$数字的$1$通过$n$小于分配给的值$u$。 我们的目标是计算排列的数量$p$每个节点都满足这个条件$u$在树上。 

输入约束限制$n \le 5000$和总和$n$对所有测试用例进行$5000$。 这表明$O(n^2)$算法可能会在时间限制内运行，但任何事情$O(n^3)$或者更糟糕的是速度太慢。 因为这个问题涉及到长度的排列$n$，所有的任意暴力枚举$n!$即使对于中等程度的排列也是不可能的$n$。 必须利用树的组合结构和祖先计数约束。 

非明显的边缘情况包括需要零祖先具有较小值的节点或具有较大值的节点$a_u$靠近根部。 例如，如果树是直链$1 \to 2 \to 3 \to 4$和$a = [0,1,2,3]$，唯一有效的排列是严格递增序列$1,2,3,4$。 不仔细考虑值沿树的位置的简单方法将产生无效的排列。 另一个微妙的例子是一棵有根的星形树$1$和所有$a_i = 0$。 将最小值放在根处的任何排列都是正确的，但粗心的算法可能只假设线性链。 

## 方法

 蛮力方法将生成所有$n!$排列并检查每个节点$u$究竟是否$a_u$它的祖先的值较小。 这在理论上是有效的，因为它直接实现了问题条件，但在计算上是不可能的：$n=10$,$n! = 3,628,800$，并且对于$n=5000$，这是荒谬的。 

关键的见解是条件$a_u$由于树结构，自然是分层的。 如果我们从根向下处理树，我们可以逐步构建有效的排列。 对于任意节点$u$,$a_u$告诉我们之前分配的祖先值中有多少必须小于$p_u$。 这将问题转化为动态规划问题，其中每个子树的有效排列计数取决于在祖先中分配了多少“较小的值”。 

具体来说，定义一个 DP，其中`dp[u][k]`计算将数字分配给以 为根的子树的方法的数量$u$这样正好$k$从根到的路径中的数字$u$小于$p_u$。 因为树的大小最多为 5000，我们只需要祖先计数到深度$u$，这可以实现在$O(n^2)$时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 使用祖先计数的树上的 DP | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读$n$，父数组`fa`，和数组`a`。 
2. 使用父数组将树构建为邻接表。 
3.初始化DP表`dp[u]`对于每个节点`u`。 每个条目最终将存储为以 为根的子树赋值的方法数`u`尊重`a`限制。 
4. 使用 DFS 以自下而上的方式处理树。 对于叶节点，如果它们的有效分配数为 1`a_u`为零，否则为零。 
5. 对于内部节点`u`，结合其子代的 DP 结果。 从概念上讲，每个子子树都可以通过多种方式交错`u`同时尊重祖先计数。 使用组合二项式系数来有效地计算这些交错。 
6. 处理完根节点后，将其中有效赋值的总和`dp[1]`给出有效排列的总数. 输出结果取模$998244353$。 

关键的见解是`a_u`定义位置约束：如果我们按遍历顺序列出祖先，`p_u`必须大于恰好`a_u`这些祖先。 通过从叶到根按递增顺序分配数字并将计数与组合公式相结合，我们尊重所有祖先约束而无需枚举排列。 

工作原理：DP 正确地计算为子树赋值的每种方式，从而满足祖先计数约束。 一旦祖先的位置固定，每个子树的组合都是独立的，并且使用组合交织可确保所有排列都被精确地计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

def solve():
    import sys
    sys.setrecursionlimit(10000)
    
    t = int(input())
    
    fac = [1] * 5001
    for i in range(1, 5001):
        fac[i] = fac[i-1] * i % MOD
    
    inv = [1] * 5001
    inv[5000] = pow(fac[5000], MOD-2, MOD)
    for i in range(5000, 0, -1):
        inv[i-1] = inv[i] * i % MOD
    
    def comb(n, k):
        if k < 0 or k > n:
            return 0
        return fac[n] * inv[k] % MOD * inv[n-k] % MOD
    
    for _ in range(t):
        n = int(input())
        fa = list(map(int, input().split()))
        a = list(map(int, input().split()))
        
        tree = [[] for _ in range(n)]
        for i, p in enumerate(fa):
            tree[p-1].append(i+1)
        
        def dfs(u):
            total = 1
            size = 0
            for v in tree[u]:
                cnt, sz = dfs(v)
                total = total * cnt % MOD * comb(size + sz, sz) % MOD
                size += sz
            if a[u] > size:
                return 0, size + 1
            return total, size + 1
        
        res, _ = dfs(0)
        print(res % MOD)

if __name__ == "__main__":
    solve()
```该解决方案首先预先计算阶乘和模逆以有效地计算组合。 DFS 递归地计算每个子树的有效分配。 关键是将每个子项的计数乘以交织它们的方式的组合数量，同时尊重祖先的约束。 每当`a[u] > size`因为不可能满足该节点的祖先计数要求。
