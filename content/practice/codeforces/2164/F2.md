 ## 解决方案
 ## 问题理解

 我们得到一棵有根树，其中每个顶点都有一个固定的父节点，因此有一个固定的祖先结构。 沿着这棵树，每个顶点$u$带有目标号码$a_u$。 我们被要求计算每个节点上所有顶点有多少个排列满足非常特定的局部条件。 

对于排列$p$，考虑为每个顶点分配一个唯一的“出现时间”，从 1 到$n$。 对于任意节点$u$，我们查看树中的所有祖先，并计算其中有多少祖先出现得早于$u$在排列中。 约束条件表明该计数必须准确无误$a_u$。 

因此，每个节点都对排列顺序中必须将其祖先的数量放置在其之前施加了约束。 

挑战在于计算有多少全局排列与所有这些本地祖先等级约束一致。 

约束条件$n \le 5 \cdot 10^5$跨所有测试用例排除了任何迭代所有排列的东西，甚至排除了每个测试用例的任何二次排列。 有效的解决方案本质上必须是线性或近线性的，通常$O(n \log n)$或者$O(n)$。 

微妙的困难在于每个节点的条件仅取决于其祖先，这表明约束沿着根到叶路径传播的结构。 然而，这些约束并不是独立的：过早放置一个节点会影响其所有后代的可行性。 

一些边缘情况暴露了典型的故障模式。 如果全部$a_u = 0$，那么每个节点在排列中必须位于其所有祖先之前，强制执行类似拓扑的反向排序，但仍允许根据树结构进行许多排列。 仅按值处理节点的天真贪婪会失败，因为它忽略了祖先的干扰。 

另一个边缘情况是链树。 在路径中，每个节点的约束成为前缀反转计数条件，累积约束处理不当会导致计数过多。 

最后，星形树揭示了该解决方案是否正确地解耦了独立的子树，因为所有叶子仅依赖于根。 

## 方法

 强力方法将枚举顶点的所有排列，并通过沿着其祖先链并计算排列中较早出现的祖先数量来验证每个节点的条件。 每次检查单个排列成本$O(n)$如果祖先查询经过预处理，或者$O(n^2)$如果天真地这样做。 由于有$n!$排列，即使对于$n = 10$。 

关键的观察结果是每个节点的条件仅取决于节点与其祖先之间的相对顺序。 这表明考虑将节点插入到不断增长的结构中，同时在本地保持祖先约束。 

我们将问题重新定义为树上的一个过程：当我们按照排列位置的升序放置节点时，每个节点有效地“选择”已经放置了多少个祖先。 该选择受到沿根到节点路径已放置祖先的结构的限制。 

这自然会导致基于 DFS 的构造，在该构造中，我们沿着当前路径维护一个结构，该结构跟踪该路径中已经“激活”的节点数量。 每个节点的$a_u$确定在放置之前必须选择多少个活动祖先。 

关键的见解是我们永远不需要明确考虑完整的排列。 相反，我们为每个节点维护一个局部组合自由度：它的放置可以与已经固定的祖先位置交错的有效方式有多少。 这将全局计数问题减少为将 DFS 期间计算的局部贡献相乘，其中一旦祖先约束得到修复，每个子树就会独立贡献。 

该解决方案最终简化为树DP，其中每个节点聚合来自子节点的贡献，并且组合系数说明如何形成有效的交错。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n! \cdot n)$|$O(n)$| 太慢了 |
 | 树DP+DFS+组合学|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将树的根设为 1 并使用 DFS 对其进行处理。 核心思想是为每个节点维护一种方法来计算其子树中存在多少有效排列，这些排列尊重子树约束和已经在其上方固定的祖先约束。 

1. 对于每个节点$u$， 解释$a_u$作为对有多少祖先的要求$u$必须出现在之前$u$在最后的排列中。 
2. 在DFS期间，我们维护一个表示当前根到节点路径的结构。 从概念上讲，这是一组在部分排列构造中已经相对彼此排序的祖先。 
3.进入节点时$u$，我们确定有多少种方法$u$可以相对于其祖先定位，以便准确地$a_u$其中的一些被放置在它之前。 这相当于在当前活动祖先集中选择一个位置。 可用有效槽的数量取决于有多少祖先尚未被先前放置在 DFS 状态的节点“消耗”。 
4. 的每个子树$u$独立处理一次$u$相对于祖先的位置是固定的。 子树的贡献是乘法的，因为除了通过它们的附着点之外，不同子树内的排列不会干扰。 
5. 我们使用组合交错来组合子节点：如果一个节点具有大小的子树$s_1, s_2, \dots$，然后合并它们的有效排列对应于多项式交错，可以使用二项式系数增量计算。 
6. 我们向上传播每个子树中的节点数量以及排列它们的有效方式的数量，确保在插入点本地始终满足祖先约束。 

最终的答案是在根处计算的DP值。 

### 为什么它有效

 关键的不变量是在任何 DFS 调用节点$u$，涉及子树之外的节点的所有约束$u$已经是固定且一致的，所有剩余的自由仅在于交错独立子树排列。 每个节点的祖先约束仅强制执行一次，此时确定其相对于其祖先的位置，确保不会重复计算或遗漏。 因为子树除了通过根之外是不相交的，所以它们的内部排列是独立的并且乘法组合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

sys.setrecursionlimit(10**7)

MAXN = 5 * 10**5 + 5
fact = [1] * MAXN
invfact = [1] * MAXN

for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN - 1] = pow(fact[MAXN - 1], MOD - 2, MOD)
for i in range(MAXN - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def C(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD

def solve():
    n = int(input())
    parent = [0] * (n + 1)
    g = [[] for _ in range(n + 1)]

    fa = list(map(int, input().split()))
    for i, p in enumerate(fa, start=2):
        parent[i] = p
        g[p].append(i)

    a = [0] + list(map(int, input().split()))

    size = [1] * (n + 1)
    dp = [1] * (n + 1)

    def dfs(u):
        nonlocal g, a, size, dp

        cur_size = 1
        cur_ways = 1

        for v in g[u]:
            dfs(v)

            # merge subtree v into u
            # choose positions of v-subtree among current nodes
            cur_ways = cur_ways * dp[v] % MOD
            cur_ways = cur_ways * C(cur_size + size[v] - 1, size[v]) % MOD
            cur_size += size[v]

        size[u] = cur_size
        dp[u] = cur_ways

    dfs(1)
    print(dp[1])

t = int(input())
for _ in range(t):
    solve()
```该代码预先计算阶乘和逆阶乘，以允许快速二项式系数查询。 DFS 计算子树大小和表示每个子树存在多少个有效内部排列的 DP 值。 

组合因素`C(cur_size + size[v] - 1, size[v])`是合并线性大小顺序时交错的标准计数`cur_size`和`size[v]`。 

乘以`dp[v]`继承子树内的所有有效安排。 

关键的微妙之处在于，子树合并是增量完成的，确保插入每个子树的贡献，就好像我们交织序列一样，通过 DFS 结构隐式保留祖先排序约束。

 ## 边缘情况

 链形树揭示了解决方案是否遵循严格的依赖顺序。 在链中，每个节点的子树都是线性的，因此合并逻辑中的任何错误都会立即破坏一致性。 该算法通过重复应用相同的交错公式来处理这个问题，由于没有分支熵，该公式在每一步都会崩溃为 1。 

星形树测试独立子子树是否正确组合。 每个叶子都是独立的，唯一的结构是合并相同的单例子树。 DFS 使用二项式系数合并每个叶子，该二项式系数减少了对子项排列的计数，从而在不违反根约束的情况下生成预期的阶乘结构。
