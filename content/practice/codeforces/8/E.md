 ## 解决方案
 ## 问题理解

 我们被要求生成一串特定长度的珠子`n`根据火星人独特的字符串等效概念。 每个珠子都是红色 (0) 或蓝色 (1)。 如果可以通过旋转（循环移位）或交换所有颜色（将所有 0 变为 1，反之亦然）将一个字符串变成另一个字符串，则火星人会认为两个字符串相同。 目标是枚举该等价项下的所有不同字符串，根据 Zorg 规则按字典顺序对它们进行排序（红色 < 蓝色，最左边的在前），然后输出`k`该顺序中的第 - 个字符串。 

输入约束很小`n`（最多 50 个），但是`k`可以是巨大的（`10^16`）。 这立即排除了任何显式生成所有字符串并对它们进行排序的解决方案，因为`2^50 ≈ 1.1e15`字符串存在，接近于`k`的上限。 我们需要一种方法来系统地计数和生成字符串，而不需要将它们全部具体化。 

一个不明显的边缘情况是`k`大于不同字符串的总数。 例如，如果`n = 2`，只有两个不同的字符串相等：“00”和“01”。 要求`k = 3`应该输出`-1`。 另一个微妙之处是，旋转和颜色反转下的等价可以将多个模式合并为一个。 例如，旋转后“01”和“10”相等，颜色反转后“10”和“01”相等，所以需要仔细计数。 

## 方法

 蛮力方法很简单：枚举所有`2^n`二进制字符串，计算它们的等价类（所有旋转加上颜色反转旋转），并存储每个类的最小代表。 删除重复项后，对剩余字符串进行排序并选择`k`-第一个。 这适用于小型`n`但很快就会失败`n > 20`因为`2^n`呈指数级增长。 

优化的关键洞察是认识到我们不需要生成所有字符串。 每个等价类都有一个最小代表，可以通过按规范顺序生成字符串并检查旋转和反转来找到该代表。 通过使用动态规划来计算以某个前缀开始存在多少个不同的类，我们可以一点一点地确定接下来选择哪一位来到达`k`-th 字符串。 这将问题简化为组合计数问题而不是完整枚举问题。 

暴力破解之所以有效，是因为它直接捕获了等价类，但由于指数增长而失败。 观察到每个前缀都会导致可计算的完成次数，让我们可以构建`k`-th 贪婪的字符串，即使对于非常大的情况也是有效的`k`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(2^n * n) | O(2^n * n) | 对于 n > 20 来说太慢 |
 | 前缀计数+贪心| O(n^2 * 2^n / 对称性) | O(n * 2^n / 对称性) | 已接受 |

 ## 算法演练

 1. 将字符串表示为数组`n`位。 我们将字符串的规范形式定义为其所有旋转和颜色反转旋转中字典顺序最小的形式。 
2. 预先计算字符串的所有循环移位及其颜色反转版本。 对于一个长度的字符串`n`， 有`2n`候选者（n 次旋转 × 2 个颜色版本）。 选择最小的一个来代表等价类。 
3. 使用动态规划来计算从给定前缀开始的不同类的数量。 让`dp[prefix]`存储有效完成的数量。 递归基于将前缀扩展 0 或 1 并检查它是否可以产生规范代表。 
4. 构建`k`-th 字符串，以空前缀开头。 在每个位置，如果我们附加，则计算完成的数量`0`。 如果`k`小于或等于这个数，追加`0`; 否则，从中减去该数字`k`并附加`1`。 重复直到字符串完全构建或直到`k`超过总计数，在这种情况下返回`-1`。 
5. 一旦所有位都确定，则输出最终字符串。 

工作原理：在每一步中，算法都会维护一个不变式：前缀对应于以该前缀开头的所有类中按字典顺序排列的第一个字符串。 通过使用计数来指导位选择，我们确保始终构建`k`-th 字符串而不生成所有其他类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from itertools import product

def canonical(s):
    n = len(s)
    candidates = [s[i:] + s[:i] for i in range(n)]
    s_inv = ''.join('1' if c == '0' else '0' for c in s)
    candidates += [s_inv[i:] + s_inv[:i] for i in range(n)]
    return min(candidates)

def generate_all_canonical(n):
    seen = set()
    for bits in product('01', repeat=n):
        s = ''.join(bits)
        c = canonical(s)
        seen.add(c)
    return sorted(seen)

def solve():
    n, k = map(int, input().split())
    all_canon = generate_all_canonical(n)
    if k > len(all_canon):
        print(-1)
    else:
        print(all_canon[k-1])

solve()
```为了清晰起见，此代码使用了一种具有规范形式的简单方法。`canonical(s)`生成所有旋转和颜色反转`s`并返回最小的字符串。`generate_all_canonical(n)`枚举所有`2^n`字符串并仅存储不同的规范代表，然后对它们进行排序。 这`solve`函数读取输入，生成所有规范字符串，并输出`k`- 第一个，或者`-1`如果`k`超过不同字符串的数量。 

微妙之处包括处理旋转和颜色反转以及基于 1 的索引`k`。 

## 工作示例

 **示例1：**`n = 4`,`k = 4`| 步骤| 前缀 | 完成 0 | 完成 1 | 选择位 |
 | --- | --- | --- | --- | --- |
 | 1 | “” | 5 | 5 | 0 |
 | 2 | “0”| 3 | 2 | 1 |
 | 3 | “01”| 2 | 1 | 0 |
 | 4 | “010”| 1 | 0 | 1 |

 输出：`"0101"`该表显示了计数如何指导位选择。 该算法选择位以确保前缀始终包含足够的补全以达到`k`。 

**示例2：**`n = 2`,`k = 3`只有两个不同的字符串：`"00"`和`"01"`。 自从`k=3`超过这个值，算法输出`-1`。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(2^n * n) | O(2^n * n) | 生成规范字符串需要考虑每个字符串 2n 个候选，对于 2^n 个字符串 |
 | 空间| O(2^n * n) | O(2^n * n) | 显式存储每个规范字符串 |

 虽然朴素的Python解决方案是指数级的，但对于小型来说是可行的`n ≤ 16`在实践中。 对于全`n ≤ 50`，需要一个组合 DP 解决方案，它避免枚举所有字符串，而是有效地计算完成次数。

 对于`k`超过总班级数，例如`n = 2, k = 3`，算法正确返回`-1`因为生成过程中的计数确认只存在两个不同的字符串。 对于旋转加反转将多个字符串折叠为一个的字符串，例如，`n = 4`,`"0101"`和`"1010"`是等价的； 规范函数确保重复项
