 ## 解决方案
 ## 问题理解

 我们正在计算标记的有根树。 节点`i`带有两条信息：从根开始所需的深度以及允许出现在树的广度优先搜索顺序中的最新位置。 

广度优先排序不仅仅是具有相同深度的节点的任何排序。 节点被逐级处理，节点的子节点显示为连续的块。 如果一个节点出现在另一个节点之前，则它们的父节点必须遵守相同的排序规则。 这正是通过为每个节点的子节点选择顺序而产生的常见 BFS 排序。 

输入仅描述每个标签的限制。 输出是 BFS 排序满足所有限制的不同树的数量，模`10^9 + 7`。 

和`n`达到`100000`在一次测试中总大小达到`510000`，任何尝试构建树、枚举 BFS 顺序或在节点对上使用动态编程的解决方案都将太慢。 我们需要一个接近线性或`O(n log n)`。 排序节点的限制是可以接受的，因为元素总数只有几十万。 

在某些情况下，粗心的实施可能会悄无声息地失败。 如果深度没有节点`1`，没有可能的根。 例如：```
2
2 2
2 2
```正确答案是`0`。 仅检查更深层次的相对顺序的解决方案可能会意外地计算无效树，因为每棵树必须只有一个根。 

如果节点在其深度块开始之前被迫进入某个位置，则答案必须为零。 例如：```
2
1 1
2 1
```第二个节点需要深度`2`，但它唯一能占据的 BFS 位置是根位置。 正确答案是`0`。 

另一个常见错误是忘记节点的子节点按 BFS 顺序形成连续块。 父节点的选择对于每个节点来说并不是独立的。 例如：```
3
1 1
2 3
2 3
```答案是`2`。 两个深度为 2 的节点可以通过两种方式排序，但它们必须都是唯一根的子节点。 将每个孩子视为父母的独立选择就太过分了。 

## 方法

 直接方法首先会生成满足深度约束的所有可能的 BFS 标签排序。 选择这样的顺序后，我们可以决定如何将每个级别拆分为子块并获得树。 这是正确的，因为 BFS 树完全由每个深度级别内的节点顺序以及每个级别在前一个级别的父级之间划分的方式来描述。 

问题是可能的 BFS 订单数量。 即使只有一个深度级别包含许多节点，排列的数量也是阶乘的。 为了`100000`节点，枚举它们将需要超过`100000!`操作，这是不可能的。 

关键的观察是树结构和 BFS 排列可以分开。 构建父关系的方式数量仅取决于每个深度存在多少个节点，而不取决于哪些标签占据这些位置。 

对于固定水平，假设有`a`当前深度的节点和`b`下一个深度的节点。 这`b`下一个 BFS 层中的子节点必须分为`a`连续的组，每个当前节点一组。 允许空组，因为节点可能没有子节点。 这种分裂的数量就是弱组合的数量`b`进入`a`部分：$$\binom{a+b-1}{a-1}$$剩下的任务是计算 BFS 位置的标签的有效分配。 相同深度的节点占据一个连续的位置区间。 如果它们的允许位置已排序，则应首先分配允许位置最小的节点。 当`j`处理此排序顺序中的第 - 个节点，它具有：$$\min(x_i, R)-L+1-(j-1)$$可用职位，其中`[L, R]`是其深度的区间。 将这些选择相乘即可得出该级别的有效排列数。 

两个独立的部分相乘。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算每个深度有多少个节点。 如果深度`1`不包含恰好一个节点，则树不可能存在。 我们还拒绝存在更深层次但不存在所有先前层次的间隙，因为每个非根节点都需要一个父节点。 
2. 对于每个深度，收集`x_i`该深度上的节点值并对它们进行排序。 一个深度的节点只能占据属于该深度的连续BFS位置，因此每个深度都可以独立处理。 
3. 对于有位置间隔的深度`[L, R]`，从最小到最大处理排序的限制。 当前节点必须放置在`L`和`min(R, x_i)`。 减去已经分配给较早节点的位置。 如果选择数为零或负数，则不存在有效的 BFS 排序。 
4. 预先计算阶乘和逆阶乘。 对于每对连续深度，乘以可能的子块分割数：$$\binom{cnt[d]+cnt[d+1]-1}{cnt[d]-1}$$这说明了与 BFS 排序兼容的所有可能的树形状。 

1. 将 BFS 排序计数与树形计数模相乘`10^9+7`。 

为什么它有效：每棵有效的树都会产生一个 BFS 排序。 对于这种排序，在分配标签时可以独立查看每个级别，因为深度的所有节点都占据固定的间隔。 一旦标签按照 BFS 顺序固定，唯一剩下的自由就是每个级别如何在前一个级别的父级之间进行划分。 星形和条形公式精确计算这些分区。 这两个选择是独立的，因此将它们相乘会对每个有效树计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7

def solve_case(n, nodes):
    depths = {}
    xs = {}
    max_depth = 0

    for d, x in nodes:
        depths[d] = depths.get(d, 0) + 1
        xs.setdefault(d, []).append(x)
        max_depth = max(max_depth, d)

    if depths.get(1, 0) != 1:
        return 0

    for d in range(1, max_depth + 1):
        if d not in depths:
            return 0

    cnt = [0] * (max_depth + 2)
    for d, c in depths.items():
        cnt[d] = c

    fact = [1] * (n + 2)
    for i in range(1, n + 2):
        fact[i] = fact[i - 1] * i % MOD

    invfact = [1] * (n + 2)
    invfact[-1] = pow(fact[-1], MOD - 2, MOD)
    for i in range(n + 1, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def comb(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    ans = 1
    start = 1
    for d in range(1, max_depth + 1):
        arr = xs[d]
        arr.sort()
        end = start + len(arr) - 1
        used = 0
        for x in arr:
            choices = min(end, x) - start + 1 - used
            if choices <= 0:
                return 0
            ans = ans * choices % MOD
            used += 1
        start = end + 1

    for d in range(1, max_depth):
        ans = ans * comb(cnt[d] + cnt[d + 1] - 1, cnt[d] - 1) % MOD

    return ans

def main():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        nodes = [tuple(map(int, input().split())) for _ in range(n)]
        out.append(str(solve_case(n, nodes)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```实现的第一部分按深度对节点进行分组并存储它们允许的最大 BFS 位置。 深度计数足以确定稍后可能的树结构的数量。 

每个测试用例构建一次阶乘数组，因为最大的二项式参数如下`n`。 组合函数是使用模逆的常数时间。 

排序计算是最微妙的部分。 变量`start`是当前深度的第一个 BFS 位置，并且`end`是最后一个。 对限制进行排序是必要的，因为首先分配最严格的限制会给出有效排列的标准贪婪计数。 变量`used`表示区间内有多少个位置已经被占据。 

第二个乘法循环计算相邻深度之间可能的父分组。 该公式使用`cnt[d] - 1`因为弱组成`cnt[d+1]`孩子们进入`cnt[d]`团体有`cnt[d+1] + cnt[d] - 1`星形和条形变换中的总位置。

 ## 边缘情况

 对于没有根的树，该算法立即返回零，因为深度 1 必须恰好包含一个节点。 在输入中：```
2
2 2
2 2
```深度计数器检测到`cnt[1]`为零并在任何组合计算之前停止。 

对于允许位置超出其深度区间的节点，贪婪放置会检测到失败。 在：```
2
1 1
2 1
```深度两个区间只是位置`2`，但节点允许的唯一可用位置是位置`1`。 选择的数量变为零，答案被拒绝。 

对于同一级别的多个节点，该算法从不独立选择父节点。 在：```
3
1 1
2 3
2 3
```两个深度两个节点都以两种可能的顺序放置在位置二和位置三。 形状公式给出了一种可能的分组，因为只有一个父级。 最终计数恰好为 2，匹配两个可能的 BFS 序列。
