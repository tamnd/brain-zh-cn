 ## 解决方案
 ## 问题理解

 该游戏是根据数字而不是棋盘或图表进行的。 一步操作将当前数字替换为其除数之一，但除数不能为 1，也不能是数字本身。 没有合法移动的玩家获胜，这使得游戏成为一种 Misère 式的除数游戏：达到素数或 1 就很好，因为下一个玩家被迫失去移动的机会。 

Chino 首先在给定的数字 n 上移动。 她想在第一回合选择一个除数，让大卫处于失败的境地。 在所有这些选择中，她想要尽可能多的数字。 如果n本身没有合法的第一步，那么她已经赢了，答案是0。如果每一个可能的第一步都允许大卫获胜，那么答案是-1。 

n 的值最多为 100000，最多可以有 1000 个测试用例。 这排除了针对每个输入重复探索整个除数树的情况。 对所有除数的递归博弈搜索可能会重复访问相同的状态，并且可能会变得昂贵，因此解决方案需要识别获胜和失败位置的数学结构并预处理有用的信息。 

一些边缘情况很容易被忽略。 当 n = 1 时，没有合法的除数，因此 Chino 立即获胜，答案为 0。粗心的实现会错误地返回 -1 来搜索获胜的除数。 

对于 n = 7，素数也会出现相同的情况。 唯一的除数是 1 和 7，两者都是禁止的，所以正确的输出是 0。 

对于 n = 6，唯一可能的第一选择是 2 和 3。两者都是素数位置，意味着下一个玩家没有动作并获胜。 Chino 无法强行获胜，因此正确的输出是 -1。 仅检查除数是否存在的方法在这里会失败。 

当 n = 12 时，Chino 可以选择 4。数字 4 只有一种可能的走法，即 2，而 2 是最终获胜位置。 因此 4 对于轮到的玩家来说是一个失败的位置，所以在 Chino 选择 4 后 David 就失败了。正确的输出是 4。 

## 方法

 直接的解决方案是将每个数字建模为游戏状态。 对于数字x，我们可以生成所有真因数并递归地确定当前玩家是否可以强行获胜。 这是正确的，因为每次移动都会严格减少数字，因此递归最终会达到素数或 1。 

问题在于，这多次重复相同的推理。 例如，许多不同的合数包含 4、6 或 9 作为除数，简单的搜索会重复重新计算这些位置的结果。 即使有记忆，对许多测试用例独立执行此操作也会浪费工作。 当n达到100000时，为每个状态生成除数并遍历所有可达状态就太大了。 

关键的观察结果是游戏有一个非常简单的失败位置结构。 只有当所有可能的举动都走向获胜位置时，该位置才会失败。 素数和 1 是获胜位置，因为没有可用的移动。 当合数的所有真因数都是质数时，合数就会被输掉。 当数字是两个素数的乘积（计算重数）时，就会发生这种情况。 

如果一个数字包含一个复合真除数，则该除数已经是一个可能的移动。 重要的最小合数因子总是两个素数的乘积，而这些位置正在丢失。 这意味着每个具有两个以上质因数的合数都会向亏损位置移动并获胜。 

然后问题就简化为找到 n 的最大半素因数，其中半素数意味着正好有两个具有重数的素因数。 该除数是最好的第一步，因为它使大卫处于失败状态。 

蛮力方法和优化方法可以进行如下比较。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 可能为 O(每个测试用例可到达除数状态的数量) | O(n) 记忆 | 很多情况下速度太慢|
 | 最佳 | O(N log log N + N log N) 预处理 | O(N) | 已接受 |

 ## 算法演练

 1. 读取所有测试用例并找到出现的最大值N。 所有预处理都可以限制为该值，因为没有查询需要更大的数字。 
2. 使用筛子找出N以内的素数。游戏状态的分类仅取决于其素数因子，因此需要快速的素性信息。 
3. 标记每个半素数。 如果一个数的质因数的重数恰好为二，则该数是半素数。 例如，4 = 2 × 2、6 = 2 × 3 和 9 = 3 × 3 是半素数。 
4. 对于每个半素数 d，更新所有大于 d 的 d 倍数。 值 d 是这些倍数的有效第一步，保留最大候选者会给出最大的获胜第一步。 等于 d 的倍数将被跳过，因为 Chino 无法选择原始数字本身。 
5. 对于每个查询n，首先处理特殊状态。 如果n是1或者素数，奇诺不用移动就获胜，所以输出0。如果n是半素数，所有合法的移动都到素数，所以奇诺不能获胜，答案是-1。 否则，输出预处理期间存储的最大半素除数。 

正确性来自于以下不变量：数字 x 的每个存储答案都是 x 的最大除数，即失败的游戏状态。 失败的游戏状态恰好是半素数，因此任何存储的候选状态都是获胜的第一步。 由于每个非半素合数都至少有一个半素除数，因此只要 Chino 能够通过移动获胜，存储的值就存在。 选择最大的存储除数满足奇诺的偏好而不改变结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    queries = [int(input()) for _ in range(int(input()))]
    if not queries:
        return

    limit = max(queries)

    prime = [True] * (limit + 1)
    if limit >= 0:
        prime[0] = False
    if limit >= 1:
        prime[1] = False

    i = 2
    while i * i <= limit:
        if prime[i]:
            step = i
            start = i * i
            prime[start:limit + 1:step] = [False] * (((limit - start) // step) + 1)
        i += 1

    factor_count = [0] * (limit + 1)
    for p in range(2, limit + 1):
        if prime[p]:
            for x in range(p, limit + 1, p):
                y = x
                while y % p == 0:
                    factor_count[x] += 1
                    y //= p

    semiprime = [False] * (limit + 1)
    for x in range(2, limit + 1):
        if factor_count[x] == 2:
            semiprime[x] = True

    best = [0] * (limit + 1)
    for d in range(2, limit + 1):
        if semiprime[d]:
            for multiple in range(d * 2, limit + 1, d):
                best[multiple] = d

    ans = []
    for n in queries:
        if n <= 1 or prime[n]:
            ans.append("0")
        elif semiprime[n]:
            ans.append("-1")
        else:
            ans.append(str(best[n]))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```筛子以通常的方式通过删除每个发现的素数的倍数来创建素数数组。 0 和 1 的边界情况是明确设置的，因为它们不是素数，并且筛循环从 2 开始。 

因子计数循环重复计算素因子。 这个细节很重要，因为 8 = 2 × 2 × 2 有三个素数因子并且不是半素数，而 4 = 2 × 2 是半素数。 仅计算不同的质因数会错误地对两者进行分类。 

这`best`数组是通过迭代半素数而不是迭代每个查询的除数来填充的。 每个半素数都将自己贡献给所有较大的倍数，并且后来的贡献会覆盖较小的答案，因为迭代向上。 严格的`2 * d`起点防止将原始数字存储为其自己的除数。 

最终的查询处理直接遵循博弈论分类。 质数和 1 是立即获胜，半质数是不可避免的损失，所有剩余的合数都使用预先计算的最佳半质数除数。

 ## 边缘情况

 对于 n = 1，算法检查`n <= 1`首先并立即返回 0。 没有除数可供选择，所以奇诺在行动之前就已经赢了。 

对于素数，例如 n = 7，素数数组将其标记为素数，算法返回 0。搜索半素数约数将是错误的，因为素数根本没有合法的移动。 

对于半素数（例如 n = 6），算法检测到其素因子计数恰好为 2 并返回 -1。 选择任何合适的除数都会得到一个素数，这对大卫来说是一个获胜的位置。 

对于较大的合数，例如 n = 30，半素因数为 6、10 和 15。预处理阶段存储最大的一个，15。由于 15 代表下一个玩家失败，Chino 可以通过选择最大的有效着法来强制获胜。
