 ## 解决方案
 ## 问题理解

 网格通过广度优先搜索从以下位置开始编号`(0, 0)`。 唯一不寻常的部分是 BFS 内部的编号顺序是固定的：扩展单元格时，新单元格按上、右、下、左的顺序考虑。 每个查询要么给出一个数字并询问距当前位置的位移，要么给出一个坐标并询问其 BFS 编号。 每次查询后，当前位置就成为查询点。 

坐标可以非常远，可达曼哈顿距离`10^8`，所以模拟 BFS 是不可能的。 BFS 的单层包含`4d`远处的细胞`d`，并且必须生成的层数太大。 我们需要在坐标和数字之间直接跳转的公式。 

主要的边缘情况是原点和前几层，因为一般模式都有短层例外。 例如第一层是：```
0 1
2 0
0 -1
-1 0
```所以坐标`(1,0)`有号码`2`，不是遵循后面层公式的值。 第二层的结束顺序也略有不同：```
(0,2), (1,1), (-1,1), (2,0), (1,-1), (0,-2), (-1,-1), (-2,0)
```盲目地将大层模式应用于这些情况的解决方案会产生错误的答案。 

## 方法

 直接的方法是构建 BFS 队列并存储每个访问过的坐标。 这是正确的，因为编号完全是 BFS 顺序，但是曼哈顿距离内的单元格数量`10^8`是关于`2 * 10^16`，因此这种方法甚至无法接近完成。 

有用的观察是 BFS 永远不会混合不同的曼哈顿距离。 层中的每个点`d`在层中的所有点小于之后发现`d`，以及层前完成的单元格数量`d`是：```
1 + 2(d - 1)d
```剩下的任务只是了解一层内的固定顺序。 一旦将该顺序写成公式，两个方向都将成为常数时间。 大图层的第一部分是上半部分，它在正 x 值和负 x 值之间交替。 下半部分还有另一个固定序列，也可以直接索引。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(距离²) | O(距离²) | 太慢了 |
 | 基于公式的映射 | 每个查询 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.找到曼哈顿层`d`坐标或包含 id 的图层。 层边界是第一个值，其中`1 + 2d(d + 1)`达到id。 
2. 对于坐标到 id 的转换，计算图层的起始 id。 然后使用位置公式确定图层内的偏移。 
3. 对于 id 到坐标的转换，计算层中第一个 id 的偏移量并反转相同的公式。 
4. 保留`(0,0)`作为特殊情况，因为它是零层中的唯一点。 

为什么它有效：

 每个 BFS 数字都属于曼哈顿层。 累积计数给出了每一层的确切起点，并且层内的发现顺序是确定性的，因为前一层中的每个父代都是按固定顺序处理的。 这些公式完全描述了确定性顺序，因此在任一方向上进行转换都不会选择错误的位置。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def layer_of_id(n):
    if n == 0:
        return 0
    z = math.isqrt(4 * n - 3)
    if z * z < 4 * n - 3:
        z += 1
    return (z - 1 + 1) // 2 if (z - 1) % 2 == 0 else (z + 1) // 2

def id_to_coord(n):
    if n == 0:
        return (0, 0)

    d = layer_of_id(n)
    start = 1 + 2 * (d - 1) * d
    k = n - start

    if d == 1:
        return [(0, 1), (1, 0), (0, -1), (-1, 0)][k]

    if d == 2:
        arr = [(0, 2), (1, 1), (-1, 1), (2, 0),
               (1, -1), (0, -2), (-1, -1), (-2, 0)]
        return arr[k]

    if k < 2 * d - 1:
        if k == 0:
            return (0, d)
        a = (k + 1) // 2
        return (a if k & 1 else -a, d - a)

    r = k - (2 * d - 1)
    if r == 0:
        return (d - 1, -1)
    if r == 1:
        return (d - 2, -2)
    if r == 2:
        return (d, 0)
    if r <= d:
        return (d - r, -r)

    s = r - d - 1
    return (-(s + 1), -(d - 1 - s))

def coord_to_id(x, y):
    d = abs(x) + abs(y)
    if d == 0:
        return 0

    if d == 1:
        return {(0, 1): 1, (1, 0): 2, (0, -1): 3, (-1, 0): 4}[(x, y)]

    start = 1 + 2 * (d - 1) * d

    if d == 2:
        arr = [(0, 2), (1, 1), (-1, 1), (2, 0),
               (1, -1), (0, -2), (-1, -1), (-2, 0)]
        return start + arr.index((x, y))

    if y > 0:
        if x == 0:
            k = 0
        else:
            a = d - y
            k = 2 * a - 1 if x > 0 else 2 * a
        return start + k

    if x > 0 and y == 0:
        r = 2
    elif x >= 0:
        a = -y
        r = 0 if a == 1 else a
    else:
        s = -x - 1
        r = d + 1 + s

    return start + (2 * d - 1) + r

def solve():
    t = int(input())
    curx = cury = 0
    ans = []

    for _ in range(t):
        q = list(map(int, input().split()))
        if q[0] == 1:
            x, y = id_to_coord(q[1])
            ans.append(f"{x - curx} {y - cury}")
        else:
            x, y = q[1], q[2]
            ans.append(str(coord_to_id(x, y)))
        curx, cury = (id_to_coord(q[1]) if q[0] == 1 else (q[1], q[2]))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```该代码将两次转换分开，因为在两个方向上重复使用相同的层算术。 小层被明确处理，避免脆弱的边界条件。 对于较大的层，首先`2d-1`位置是环的上部分，其余位置遵循下环公式。 

层计算使用整数平方根而不是浮点运算。 这可以避免精度问题，因为 id 可能非常大。 当前位置仅在生成答案后更新，与语句的操作顺序相匹配。

 ## 边缘情况

 对于原点，输入`1 0`必须返回位移`0 0`当当前点也是原点时。 该算法在计算图层之前处理它，因为原点不属于任何正距离环。 

对于第一层，坐标`(1,0)`有 ID`2`， 尽管`(0,-1)`有 ID`3`。 通用环公式可能会放错它们的位置，因为第一个环不包含足够的点来形成稍后使用的重复图案。 显式的第一层映射可以防止这种情况发生。 

对于第二层，`(2,0)`有 ID`8`， 和`(1,-1)`有 ID`9`。 这捕获了假设下半部分始终以与较大层相同的模式开始的实现。 

对于非常大的坐标，例如`(100000000,0)`，该算法仅计算图层和偏移量。 它从不分配与距离成比例的内存，因此运行时间保持不变。
