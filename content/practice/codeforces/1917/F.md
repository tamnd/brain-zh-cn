 ## 解决方案
 ## 问题理解

 我们得到了树中必须出现的所有边的长度。 这棵树正好有$n$边缘和$n+1$顶点，因此数组中的每个长度都只用作边权重一次。 

问题是我们是否可以将这些边连接成加权直径恰好为的树$d$。 

思考这个问题的一个有用方法是，每棵树的直径都是一条简单的路径。 如果一棵树有直径$d$，那么树内部的某处一定存在一条总长度恰好为的路径$d$，并且所有其他边都附加到该路径，而不创建更长的路径。 

就重量而言，这些限制令人惊讶地小。 两个都$d$和每一个$l_i$至多是$2000$，以及所有的总和$n$最多也超过输入$2000$。 这立即表明对该值进行某种子集和或背包动态规划$d$。 一个$O(nd)$或者$O(nd^2 / 64)$解是完全合理的，而指数子集枚举是不可能的。 

有几种不明显的情况很容易误导幼稚的构造。 

考虑：```
n = 2
d = 5
lengths = [3, 3]
```正确答案是`No`。 

任何有两条边的树都只是一条路径。 其直径为$3+3=6$，已经大于$d$。 一种简单的方法，仅检查某些子集的总和是否为$d$会想念这个的。 

另一个例子：```
n = 3
d = 10
lengths = [6, 2, 2]
```正确答案是`Yes`。 

使用长度的边缘$6$在直径上。 剩下的两条边形成一条长度的路径$4$，产生长度的直径$10$。 坚持构建没有最大边缘的直径的策略将错误地拒绝这种情况。 

一个更微妙的情况是：```
n = 4
d = 10
lengths = [4, 4, 4, 4]
```正确答案是`No`。 

尽管许多子集之和接近$10$，每条未使用的边都有长度$4$。 直径长度上的任何附着点$10$最多是在距离$5$从一个端点开始，所以附加一个长度-$4$边缘可以轻松创建一条比$10$。 直径的几何形状很重要，而不仅仅是子集和。 

## 方法

 强力解决方案将尝试将每个边缘子集作为直径路径的候选者。 如果子集总和为$d$，然后我们可以检查是否可以在不增加直径的情况下连接剩余的边缘。 

这已经是无望了。 有$2^n$子集，以及$n$可以达到$2000$。 

关键的观察是，在所有不属于直径的边缘中，只有最大的边缘真正重要。 

设最大边长为$M$。 

假设我们已经构建了一条总长度的直径路径$d$。 所有剩余的边都可以附加到该路径上的单个顶点。 如果可以在不产生较长直径的情况下连接最大的未使用边缘，则也可以将每个较小的未使用边缘连接到那里。 

这减少了寻找直径路径和合适的附着顶点的问题。 

另一个重要的观察是，如果两个最大边长满足$$l_n + l_{n-1} > d,$$那么答案就是立即`No`。 

任何树都包含一条穿过这两条边的路径，并且该路径已经超过$d$。 

对长度进行排序后，让$M=l_n$。 

我们将最大的边与其他边分开并执行 DP。 DP 将剩余边分为三组：

 首先，将边放置在所选附着顶点的一侧。 

其次，将边缘放置在另一侧。 

第三，直径上未使用边缘。 

如果两条边都有长度$x$和$y$，则所得直径长度为$x+y$。 

未使用的最大边的长度$M$。 为了安全地连接它，连接顶点的距离必须至少$M$从直径的两端。 这意味着$$x \ge M,\qquad y \ge M.$$唯一的特殊情况发生在最大边缘本身位于直径上时。 那么我们只需要形成剩余的长度$d-M$使用其他边缘。 

DP状态自然地成为二维子集和。 因为$d \le 2000$，位集实现使其足够快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n)$|$O(n)$| 太慢了 |
 | 最佳 Bitset DP |$O(nd^2/64)$|$O(d^2/64)$| 已接受 |

 ## 算法演练

 1. 对所有边长进行排序。 
2.让$M$为最大长度。 
3. 如果两个最大长度之和超过$d$， 输出`No`。 

任何树的直径必然大于$d$。 
4. 忽略$M$暂时处理其他的$n-1$长度与DP。 
5. 定义`dp[a][b]`我们是否可以分布处理过的边，以便未来直径的一侧具有总长度$a$另一边有总长度$b$。 

每条边都有三种选择：

 可以将其添加到第一面。 

它可以添加到第二面。 

它可以保持不使用。 
6. 将第二个维度存储为位集。 

如果一条边有长度$w$，过渡是：

 把它放在第二面：$$dp[a] \gets dp[a] \;|\; (dp[a] \ll w)$$把它放在第一面：$$dp[a] \gets dp[a] \;|\; dp[a-w]$$7. 处理完所有边缘后，除了$M$，检查两种可能性。 
8.第一种可能：$M$属于直径。 

那么剩余的边必须形成长度$d-M$。 

检查是否$$dp[d-M][0]$$是可达的。 
9.第二种可能：$M$不属于直径。 

然后我们需要一个直径和长度$d$围绕一些附件顶点分裂。 

检查是否存在$$x+y=d$$和$$x\ge M,\qquad y\ge M,$$和`dp[x][y]`可达。 
10. 如果任一条件成功，则输出`Yes`; 否则输出`No`。 

### 为什么它有效

 每棵有效的树都可以转换为所有非直径边都附加到直径上的单个顶点的树。 只有最大的非直径边缘才有可能创建新的更长路径，因此验证该边缘是否可以安全连接就足够了。 

如果最大的边本身在直径上，我们只需要补全剩余的直径长度$d-M$。 

如果不在直径上，则附着顶点必须至少位于距离$M$从直径的两端。 将这些距离写为$x$和$y$，我们得到条件$x+y=d$,$x\ge M$， 和$y\ge M$。 

DP 精确地枚举了所有可能的对$(x,y)$可以从剩余的边获得。 因此，当存在必要且充分的结构之一时，该算法准确地接受。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n, d = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()

        if a[-1] + a[-2] > d:
            print("No")
            continue

        dp = [0] * (d + 1)
        dp[0] = 1  # bit 0 set

        for w in a[:-1]:
            ndp = dp[:]

            for x in range(d, -1, -1):
                cur = dp[x]
                if cur == 0:
                    continue

                # put w on second side
                ndp[x] |= cur << w

                # put w on first side
                if x + w <= d:
                    ndp[x + w] |= cur

            mask = (1 << (d + 1)) - 1
            for i in range(d + 1):
                ndp[i] &= mask

            dp = ndp

        m = a[-1]

        ok = False

        if d - m >= 0:
            ok |= ((dp[d - m] >> 0) & 1) != 0

        for x in range(m, d - m + 1):
            if ((dp[x] >> (d - x)) & 1):
                ok = True
                break

        print("Yes" if ok else "No")

if __name__ == "__main__":
    solve()
```首先对数组进行排序，因为最大的边起着特殊的作用。 

早期的拒绝`a[-1] + a[-2] > d`立即消除不可能的情况。 

DP 使用一组位集。 指数`x`存储所有可达值`y`。 每条边都可以忽略、添加到第一条边或添加到第二条边。 “忽略”的选择是自动处理的，因为我们从前一个 DP 的副本开始。 

位移位实现向第二侧添加边缘。 搬家自`x`到`x+w`实现将其添加到第一面。 

最终检查结果与上面证明的两个建设性案例完全一致。

 ## 边缘情况

 考虑：```
1
2 5
3 3
```该算法首先检查两个最大的长度。$$3+3=6>5$$并立即返回`No`。 

这避免了仅基于子集和推理的错误接受。 

考虑：```
1
3 10
6 2 2
```排序后，$M=6$。 剩余边上的 DP 找到一个子集，总和为$d-M=4$。 该算法接受“最大边缘位于直径上”的情况并输出`Yes`。 

考虑：```
1
4 10
4 4 4 4
```DP 可以创建许多直径分解，总和为$10$，但都不满足附着顶点周围的两侧至少为$4$。 最终验证失败，答案为`No`。 

这些示例说明了为什么必须同时检查直径总和条件和附件几何形状。
