 ## 解决方案
 ## 问题理解

 对于每个测试用例，我们给出两个正整数，$u$和$v$。 我们必须找到任意一对整数$x$和$y$，不都是零，这样$$\frac{x}{u}+\frac{y}{v}=\frac{x+y}{u+v}.$$任务不是计算解决方案或找到特定的解决方案。 只要两个值都在允许的范围内，任何有效的对都会被接受。 

从算法的角度来看，约束非常小。 最多有$1000$测试用例，以及$u,v$可以大到$10^9$。 由于数字本身很大，因此搜索可能的值$x$和$y$是不现实的。 预期的解决方案必须导出一个直接公式并在恒定时间内为每个测试用例输出答案。 

一个常见的错误是假设$x=0$或者$y=0$总是有效。 考虑$u=2$,$v=3$。 如果我们选择$x=0$，方程变为$$\frac{y}{3}=\frac{y}{5}.$$对于任何非零$y$，这是假的。 仅有的$y=0$有效，但是$(0,0)$是被禁止的。 

另一个陷阱是除以在代数运算期间可能变为零的表达式，而无需先了解方程的结构。 正确的推导应该产生一个对每个正数都有效的解决方案$u$和$v$。 

案例$u=v$也值得关注。 例如，当$u=v=1$，许多派生公式仍然有效，但一些临时构造可能会意外返回$(0,0)$。 一个有效的答案是$(-1,1)$。 

## 方法

 蛮力方法会尝试不同的值$x$和$y$直到找到有效的一对。 自从$x$和$y$可以是大范围内的任何整数，即使将搜索限制在一个小区间内也不能保证成功。 搜索空间实际上是无限的，使得暴力破解无法使用。 

真正的挑战是从代数角度理解方程。 

开始于$$\frac{x}{u}+\frac{y}{v}=\frac{x+y}{u+v},$$两边乘以$uv(u+v)$:$$xv(u+v)+yu(u+v)=uv(x+y).$$展开给出$$xuv+xv^2+yu^2+yuv=uvx+uvy.$$条款$uvx$和$uvy$双方取消：$$xv^2+yu^2=0.$$现在等式变得简单多了。 我们只需要满足的整数$$xv^2=-yu^2.$$一个明显的选择是$$x=-u^2,\qquad y=v^2.$$替换：$$(-u^2)v^2+(v^2)u^2=0.$$条件立即满足。 

这对从来不是$(0,0)$因为$u$和$v$是积极的。 还，$$u^2,v^2 \le 10^{18}$$自从$u,v\le10^9$，因此输出边界受到尊重。

 | ---| ---| ---| ---|
 | 蛮力 | 无界| O(1) | O(1) | 太慢了 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读$u$和$v$。 
2. 设置$$x=-u^2.$$3. 设置$$y=v^2.$$4. 输出$x$和$y$。 

这样做的原因是原始方程精确地简化为$$xv^2+yu^2=0.$$根据选定的值，$$(-u^2)v^2+(v^2)u^2=0,$$所以条件总是满足的。 

### 为什么它有效

 清除分母并化简后，每个有效解必须满足$$xv^2+yu^2=0.$$施工$$x=-u^2,\qquad y=v^2$$使这两个术语完全相反。 它们的总和为零，这意味着简化的方程成立。 由于简化在代数上等价于原始方程，因此原始方程也成立。 因为$u$和$v$都是积极的，两者都不是$u^2$也不$v^2$为零，所以该对不能是$(0,0)$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    u, v = map(int, input().split())
    print(-u * u, v * v)
```实现直接遵循数学构造。 

对于我们阅读的每个测试用例$u$和$v$, 计算$-u^2$和$v^2$，并打印它们。 

Python 整数自动处理高达$10^{18}$，所以不存在溢出问题。 最大可能的幅度是$$(10^9)^2 = 10^{18},$$与允许的输出范围完全匹配。 

对于相等的值、较大的值或任何其他极端情况，不需要进行特殊处理，因为该公式对于每个正值都有效$u$和$v$。
