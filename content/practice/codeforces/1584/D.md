 ## 解决方案
 ## 问题理解

 我们给定一个长度序列$n$最初包含来自的整数$1$到$n$按递增顺序。 然后评审团选出三个指数$i < j < k$和$j - i > 1$并反转两个子段：第一个来自$i$到$j-1$，第二个来自$j$到$k$。 我们的任务是找出确切的值$i, j, k$。 

我们拥有的唯一工具是查询当前数组的子段中的反转数量。 倒置是一对索引$p < q$这样$a[p] > a[q]$。 每个查询返回子段中的反转数$[l, r]$。 我们最多可以进行 40 个查询，考虑到这一点，这已经很慷慨了$n$可以大到$10^9$。 

这些约束意味着我们无法模拟或存储整个数组，也无法扫描所有可能的三元组。 任何依赖于迭代数组的强力方法都会立即超出时间和内存限制。 边缘情况包括最小的有效数组（$n = 4$），或者当反转段的长度最小时（$j - i = 2$,$k - j = 1$），如果我们假设段长度总是“足够大”，这可能会混淆简单的算术。 

例如，如果$n=5$和$i=1, j=3, k=5$，序列变为$[2,1,5,4,3]$。 如果粗心的方法假设所有段的长度都大于二，则在执行基于反转的算术时可能会错误计算位置。 

## 方法

 蛮力方法将尝试猜测所有三元组$(i,j,k)$并通过查询反转来验证它们。 三元组的数量以立方体增长$n$（$\sim n^3$），使其不可行。 

关键的观察结果是反转计数以简单的数学方式对段长度进行编码。 对于第一个反向段$[i, j-1]$长度$L_1 = j-i$，反转后的反转次数恰好是该段中无序对的数量，即$C(L_1,2) = L_1(L_1-1)/2$。 同样，第二段$[j,k]$长度$L_2 = k-j+1$贡献$C(L_2,2)$倒置。 

如果我们查询整个序列，则反转总数等于$C(L_1,2) + C(L_2,2)$。 查询子段使我们能够隔离$L_1$和$L_2$单独。 这将问题简化为求解简单的二次方程以恢复线段长度。 一旦知道了长度，$i$可以通过二分查找找到：对于具有非零反转的最小前缀，第一个反转段的开始是$i$。 从那里开始，$j$和$k$使用长度来恢复。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 逆算术+二分查找 | O(log n) 次查询 | O(1) | O(1) | 已接受 |

 ## 算法演练

 1、查询全数组倒置总数$[1,n]$。 打电话给这个$total$。 这等于$C(L_1,2) + C(L_2,2)$， 在哪里$L_1 = j-i$和$L_2 = k-j+1$。 
2. 解二次方程$x(x-1)/2 = total$恢复段的潜在长度。 由于总数来自两个段反转计数的总和，因此我们使用额外的查询来分隔它们。 
3. 执行二分查找$i$，第一个反转段的开始。 查询前缀$[1,m]$。 如果反转次数为零，则向右移动。 否则，向左移动。 第一个具有非零反转的前缀包含$i$。 
4.找到后$i$, 查询从$i$隔离第一段的长度$L_1$使用反演公式$C(L_1,2) = inversions\_in\_segment$。 计算$j = i + L_1$。 
5、第二段长度$L_2$现在可以计算为$k-j+1 = L_2$。 询问$[j, n]$或从剩余的反转计数中求解。 计算$k = j + L_2 - 1$。 
6. 输出$(i,j,k)$。 

工作原理：在连续子段上反转的完美递增序列中的反转数量由段长度唯一确定。 通过使用前缀和后缀查询来隔离这些长度，我们可以恢复原始索引，而无需构建数组。 二分查找保证$i$可以有效地找到，并且反转算术将计数转换为精确的段长度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
flush = sys.stdout.flush

def query(l, r):
    print(f"? {l} {r}")
    flush()
    res = int(input())
    if res == -1:
        exit(0)
    return res

def solve_case(n):
    total = query(1, n)

    # binary search for i
    left, right = 1, n
    i = 1
    while left <= right:
        mid = (left + right) // 2
        inv = query(1, mid)
        if inv == 0:
            left = mid + 1
        else:
            i = mid
            right = mid - 1

    # find length of first reversed segment L1
    low, high = 1, n
    L1 = 0
    while low <= high:
        mid = (low + high) // 2
        inv = query(i, i + mid - 1)
        if inv == mid * (mid - 1) // 2:
            L1 = mid
            low = mid + 1
        else:
            high = mid - 1
    j = i + L1

    # remaining inversions to find L2
    inv_second = query(j, n)
    # solve L2*(L2-1)//2 = inv_second
    L2 = 1
    while L2 * (L2 - 1) // 2 < inv_second:
        L2 += 1
    k = j + L2 - 1
    print(f"! {i} {j} {k}")
    flush()

t = int(input())
for _ in range(t):
    n = int(input())
    solve_case(n)
```该代码首先查询总反转，然后执行二分搜索以找到第一个反转段的开始位置。 之后，它使用反演公式找到第一段的长度，然后推导出第二段的长度。 边界处理至关重要，因为对精确子段的查询必须与段的长度匹配，否则反演公式将失败。
