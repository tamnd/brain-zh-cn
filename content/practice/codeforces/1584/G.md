 ## 解决方案
 ## 问题理解

 我们在飞机上有几个点。 我们想要计算连接线段靠近集合中每个点的点对。 更准确地说，对于选定的一对$(p_i,p_j)$，每个点的距离必须最多$R$来自该段。 

重要的是线段，而不是无限的线。 点可以投影到线段之外，在这种情况下，它到线段的距离就是到端点之一的距离。 

点数最多为3000。大约有$4.5\times 10^6$端点对。 根据所有点检查每一对大约需要$$\binom{3000}{2}\cdot 3000 \approx 1.35\times 10^{10}$$距离计算，远远超出了三秒的时间。 任何立方解都被排除。 二次算法是可以接受的，并且$O(n^2\log n)$很容易足够快。 

有几种情况很容易处理不当。 

假设所有点都在一条线上：```
3 1
0 0
2 0
5 0
```正确答案是1，即连接两个极值点的线段。 如果我们只要求每个点都接近无限支撑线，那么所有三对点似乎都是有效的，这是错误的，因为中间的一对在线段之外留下了一个端点。 

当距离支撑线最远的点超出端点时，会出现另一种微妙的情况。```
3 2
0 0
3 0
10 1
```重点$(10,1)$距无限直线仅距离 1$y=0$，但它到线段的距离$(0,0)$到$(3,0)$几乎是 7。仅基于线路的配方就忽略了这一点。 

第三个陷阱是该线段必须覆盖所有点的投影。 为了```
4 2
-3 0
0 1
0 -1
3 0
```只有两个极值点之间的部分有效。 任何较短的线段都会将外部点之一留在外面。 

## 方法

 蛮力的想法很简单。 枚举每对点，将它们视为线段端点，并计算每个点到该线段的距离。 如果所有距离最多为$R$，数一下这对。 

正确性是立即的，因为直接检查定义。 问题是速度。 有$O(n^2)$成对且每对都需要$O(n)$距离测试，给出$O(n^3)$运营。 

为了改善这一点，我们需要了解几何形状。 

指明方向$u$。 将每个点投影到该方向上。 所有预测都有一个最小值和一个最大值。 连接获得这些极端投影的点的线段是其支撑线有方向的唯一候选线段$u$。 具有相同方向的任何其他对都会在线段之外留下一些投影。 

现在看垂直方向$v$。 投影之间的最大差异$v$正是该方向上点集的宽度。 每个点都在距离之内$$\frac{\text{width}}{2}$$从中间线开始。 因此有方向的线段$u$当宽度垂直于$u$至多是$2R$。 

这将问题转化为凸几何问题。 只有凸包顶点很重要，因为内部点永远不会成为极端投影。 对于凸包上的每个边缘方向，我们可以使用旋转卡尺来保持垂直方向上的最远点并在线性时间内获得总体宽度。 

当宽度不超过$2R$，沿当前方向的两个极值点形成一个合格线段。 

关键的观察是，每个方向最多确定一个候选对，将数百万种可能性减少到只有$m$船体顶点，其中$m\le n$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^3)$|$O(1)$| 太慢了 |
 | 最佳 |$O(n\log n)$|$O(n)$| 已接受 |

 ## 算法演练

 ### 1. 计算凸包。 

内点永远不会确定任何方向上的极端投影，因此可以忽略它们。 我们使用单调链算法构造凸包。 

### 2. 处理小船体。 

如果外壳包含一个点，则不存在线段。 

如果船体包含两个点，则它们的线段是唯一可能的答案，并且始终有效。 

### 3. 使用旋转卡尺遍历船体边缘。 

对于每个船体边缘$H_iH_{i+1}$，考虑其方向。 垂直于该方向的宽度等于从通过边缘的支撑线到任何船体顶点的最大距离。 

由于对映点围绕多边形单调移动，因此旋转卡尺技术会更新总线性时间内的最大值。 

### 4. 计算宽度。 

对于边缘向量$e$， 让$$A = |\text{cross}(e, H_k-H_i)|$$在哪里$k$是当前对映点。 

实际宽度是$$\frac{A}{|e|}.$$不使用浮点数，而是比较$$A^2 \le (2R)^2|e|^2.$$这避免了精度问题。 

### 5. 恢复端点对。 

对于当前边缘方向，跨越所有投影的线段由该方向上的两个支撑点形成。 

旋转卡尺同时保持这些极端顶点。 只要宽度条件成立，该对就会贡献一个答案。 

### 6. 计算不同对的数量。 

不同的边缘方向可能会产生相同的端点对，因此我们将端点对存储在一个集合中。 

### 为什么它有效

 对于任何方向，所有点投影都形成一个区间。 具有该方向且投影间隔包含每个点的唯一线段是连接最小和最大投影的线段。 点到该线段的距离等于其到支撑线的距离，因为每个投影都位于该区间内。 

垂直于线段方向的宽度恰好是最大的该距离乘以二。 因此条件“每个点都在距离之内”$R$从线段开始”等价于“垂直于线段的点集的宽度最多为$2R$”。旋转卡尺枚举每个相关方向，因此找到每个有效对，并且不计算无效对。

 ## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def solve():
    n, R = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    hull = convex_hull(pts)
    m = len(hull)

    if m < 2:
        print(0)
        return

    if m == 2:
        print(1)
        return

    hull.extend(hull[:2])

    j = 1
    ans = set()

    for i in range(m):
        ni = i + 1
        ex = hull[ni][0] - hull[i][0]
        ey = hull[ni][1] - hull[i][1]

        while True:
            nj = (j + 1) % m

            cur = abs(ex * (hull[j][1] - hull[i][1]) -
                      ey * (hull[j][0] - hull[i][0]))
            nxt = abs(ex * (hull[nj][1] - hull[i][1]) -
                      ey * (hull[nj][0] - hull[i][0]))

            if nxt > cur:
                j = nj
            else:
                break

        area = abs(ex * (hull[j][1] - hull[i][1]) -
                   ey * (hull[j][0] - hull[i][0]))

        edge_sq = ex * ex + ey * ey

        if area * area <= 4 * R * R * edge_sq:
            a = i
            b = ni % m
            if a > b:
                a, b = b, a
            ans.add((a, b))

    print(len(ans))

solve()
```第一部分构建凸包。 使用`<=0`删除共线的内部点并仅留下极端顶点。 

旋转卡尺保持对点`j`。 自从`j`仅向前移动，指针前进的总数是线性的。 

比较使用平方数量。 这避免了浮点不准确，并符合声明的保证，即微小的扰动$R$不要改变答案。 

将对插入到集合中是因为多个边可能对应于相同的线段方向。

 ## 边缘情况

 考虑```
3 1
0 0
2 0
5 0
```船体仅包含两个极值点。 旋转卡钳永远不需要移动。 该算法输出 1，这是正确的，因为中点位于线段上。 

为了```
3 2
0 0
3 0
10 1
```相对于短线段方向的宽度较小，但投影不跨越第三点。 该方向的支撑对变为$(0,0)$和$(10,1)$， 不是$(0,0)$和$(3,0)$，防止错误计数。 

为了```
4 2
-3 0
0 1
0 -1
3 0
```多个边缘方向满足宽度条件。 它们都产生由两个极值点组成的相同支撑对。 这对集合删除了重复项，留下正确答案 1。
