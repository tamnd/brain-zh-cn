 ## 解决方案
 ## 问题理解

 两辆车从一条长路的两端出发`l`。 左车从位置出发`0`并向右移动。 右车从该位置出发`l`并向左移动。 

两辆车都以速度开始`1`。 沿路有固定坐标处放置的旗帜。 每当一辆汽车经过旗帜时，只有该汽车的速度会增加`1`。 两辆车连续、同时移动。 

我们必须确定两辆车占据相同位置的确切时间。 

首先要注意的是，汽车不会随意改变速度。 它们的速度仅在旗帜位置发生变化。 在两次连续的速度变化之间，每辆车以恒定的速度移动。 这使得该动议具有非常结构化的形式。 

单次测试flag数量可达`10^5`，但所有测试用例的总和也受`10^5`。 这立即排除了任何使用微小时间步长的模拟。 如果每个查询都需要二次工作，那么即使模拟两辆车之间的每一种可能的交互也会变得困难。 

答案是一个实数，所以我们并不是在寻找一个纯粹的组合量。 运动是连续的。 这通常建议直接几何或按时间进行二分搜索。 

一些边缘情况很容易被错误处理。 

考虑：```
1
1 10
5
```车辆在不同时间到达旗帜。 左边的车到达后`5`秒并加速，而右车在会议开始之前从未触及该旗帜。 假设两辆车在同一事件中都获得速度的解决方案将产生错误的答案。 

考虑：```
1
2 10
1 9
```两辆车在一秒钟后就撞上了一面旗帜。 他们的速度变成`2`，并且他们在位置相遇`5`又过了两秒。 答案正是`3`。 如果实现尝试重复模拟微小间隔，浮点累积错误就会变得明显。 

另一个微妙的情况是，会议发生在任何一辆汽车到达下一个旗帜之前。 例如：```
1
2 10
4 6
```两辆车到达各自的第一个旗帜后，就会以更快的速度向对方驶去。 会议可能会在休息时间而不是在旗子上举行。 任何仅检查标志到达时间的解决方案都会错过这一点。 

关键的挑战是在正确处理分段恒定速度的同时计算任意时间后的位置。 

## 方法

 一个自然的暴力想法是模拟事件。 每个事件都是其中一辆车到达下一个旗帜的时刻。 我们可以反复确定哪个事件首先发生，提前该事件的时间，更新位置，增加一个速度，并继续直到汽车相遇。 

这在概念上是有效的，因为速度变化仅发生在标志处。 状态仅在有限的多个时刻发生变化。 

困难在于会议可能发生在两个事件之间。 我们必须不断检查赛车之间的剩余距离是否会在下一次夺旗活动之前关闭。 实施变得相当微妙。 

另一种可能性是使用非常小的时间增量来模拟运动。 这显然太慢了。 即使精度为`10^-7`在一条漫长的路上`10^9`将需要天文数字的步骤。 

关键的观察是，如果我们确定一个时间`T`，我们可以确定每辆车到底在哪里`T`秒。 

对于左边的车，我们知道它经过的路段顺序：```
0 -> a1 -> a2 -> ... -> an -> l
```上段`i`，其速度已知。 我们可以花尽可能多的可用时间`T`尽可能穿过完整的片段。 一旦剩余时间不足以完成下一段，我们就会在该段内的某个位置停下来计算确切的位置。 

同样的想法也适用于合适的汽车。 

现在定义：```
f(T) = position_of_left_car_after_T
g(T) = position_of_right_car_after_T
```左侧位置随时间增加。 正确的位置随着时间的推移而减少。 

车子已经在时间上相遇了`T`确切的时间：```
f(T) >= g(T)
```这个条件是单调的。 如果它在一段时间内是正确的，那么在所有更长的时间里它仍然是正确的。 这使得二分查找成为可能。 

我们二分查找两个位置交叉的最小时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 事件模拟| 每次测试 O(n) | O(1) | O(1) | 已接受，但更复杂 |
 | 二分查找+位置评估| O(n log L) | O(1) | O(1) | 已接受 |

 这里`L`表示时间的搜索范围。 对于双精度来说，大约 60 次二分搜索迭代就足够了。 

## 算法演练

 ### 固定时间内的位置计算

 假设我们想要一段时间后左车的位置`T`。 

汽车在指定位置启动`0`与速度`1`。 

每当它经过一个标志时，速度就会增加`1`。 

我们从左到右处理路段。 

如果当前段长度是`d`当前速度是`v`，那么遍历整个线段需要：```
d / v
```秒。 

如果剩余足够的时间，我们会消耗该时间，移动到该段的末尾，并提高速度。 

否则，汽车将留在路段内。 其地位是：```
current_position + remaining_time * v
```然后我们停下来。 

右车是从右端对称计算的。 

### 二分查找

 1. 设置`low = 0`。 
2. 设置`high = l`。 

会议时间不能超过`l`，因为即使没有任何加速度，汽车也会以组合速度相互接近`2`，会议内`l/2`秒。 
3. 重复大约60次。 
4.让`mid = (low + high) / 2`。 
5. 计算之后的左车位置`mid`秒。 
6. 计算正确的汽车位置`mid`秒。 
7. 如果左边的位置至少是右边的位置，则汽车在时间上已经相遇`mid`，因此将上限移至`mid`。 
8. 否则会议稍后举行，因此将下限移至`mid`。 
9. 迭代结束后，输出`high`。 

### 为什么它有效

 对于任何固定时间`T`，位置计算准确地再现了物理运动，因为每次速度变化仅在遍历完整段时才会发生。 因此，对单辆车的模拟是准确的。 

定义：```
h(T) = left_position(T) - right_position(T)
```最初`h(0) < 0`。 随着时间的增加，左边的位置永远不会减少，右边的位置永远不会增加，所以`h(T)`是单调递增的。 

两辆车恰好在什么时候相遇`h(T) >= 0`。 

由于谓词是单调的，二分查找找到“尚未满足”和“已经满足”之间的唯一过渡点。 重复减半以任意小的误差收敛到真实的会议时间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def left_pos(t, a, l):
    pos = 0.0
    speed = 1.0

    for flag in a:
        dist = flag - pos
        need = dist / speed

        if t >= need:
            t -= need
            pos = flag
            speed += 1.0
        else:
            return pos + speed * t

    dist = l - pos
    need = dist / speed

    if t >= need:
        return float(l)

    return pos + speed * t

def right_pos(t, a, l):
    pos = float(l)
    speed = 1.0

    for flag in reversed(a):
        dist = pos - flag
        need = dist / speed

        if t >= need:
            t -= need
            pos = float(flag)
            speed += 1.0
        else:
            return pos - speed * t

    dist = pos
    need = dist / speed

    if t >= need:
        return 0.0

    return pos - speed * t

def solve():
    t = int(input())

    ans = []

    for _ in range(t):
        n, l = map(int, input().split())
        a = list(map(int, input().split()))

        lo = 0.0
        hi = float(l)

        for _ in range(70):
            mid = (lo + hi) / 2.0

            lp = left_pos(mid, a, l)
            rp = right_pos(mid, a, l)

            if lp >= rp:
                hi = mid
            else:
                lo = mid

        ans.append(f"{hi:.15f}")

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```功能`left_pos`和`right_pos`实现定时位置查询。 每个函数都会遍历段序列，只要完成整个段就会消耗时间。 

一个常见的错误是在到达旗帜之前加快速度。 该实现首先检查是否有足够的时间来完成该段。 只有到达标志后速度才会增加。 

另一个微妙的细节是最后一段。 在最后一个标志之后，汽车以最终速度继续驶向终点。 该代码对该段的处理与其他段完全相同。 

二分查找使用 70 次迭代。 由于每次迭代将搜索间隔减半，这远远足以实现所需的`10^-6`精确。 

## 工作示例

 ### 示例 1

 输入：```
1

1 9
```二分查找最终收敛为`3`。 

在`T = 3`:

 #### 左车

 | 细分 | 速度| 需要时间 | 赛段前剩余时间 | 位置之后 |
 | --- | --- | --- | --- | --- |
 | 0 → 1 | 1 | 1 | 3 | 1 |

1 + 2 × 2 = 5
```#### 右车

 | 细分 | 速度| 需要时间 | 赛段前剩余时间 | 位置之后 |
 | --- | --- | --- | --- | --- |

9 - 2 × 2 = 5
```两辆车均就位`5`，确认答案。

 输入：```

1
```答案是`11/3 ≈ 3.666666666667`。 

#### 左车

 | 细分 | 速度| 需要时间 |

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    def left_pos(t, a, l):
        pos = 0.0
        speed = 1.0

        for flag in a:
            dist = flag - pos
            need = dist / speed

            if t >= need:
                t -= need
                pos = flag
                speed += 1.0
            else:
                return pos + speed * t

        return min(float(l), pos + speed * t)

    def right_pos(t, a, l):
        pos = float(l)
        speed = 1.0

        for flag in reversed(a):
            dist = pos - flag
            need = dist / speed

            if t >= need:
                t -= need
                pos = float(flag)
                speed += 1.0
            else:
                return pos - speed * t

        return max(0.0, pos - speed * t)

    tc = int(input())
    out = []

    for _ in range(tc):
        n, l = map(int, input().split())
        a = list(map(int, input().split()))

        lo, hi = 0.0, float(l)

        for _ in range(70):
            mid = (lo + hi) / 2

            if left_pos(mid, a, l) >= right_pos(mid, a, l):
                hi = mid
            else:
                lo = mid

        out.append(f"{hi:.6f}")

    return "\n".join(out)

 ## 边缘情况

 ### 在下一个旗帜之前集合

 输入：```
1
2 10
4 6
```两辆车到达最近的旗帜后，它们的速度变为`2`。 会议发生在旗帜之间的某个位置，而不是恰好在旗帜位置。 

位置查询函数自然会处理这个问题，因为只要剩余时间不足以到达下一个标志，它们就会在段内停止。 

### 一辆车加速，而另一辆车不加速

 输入：```
1
1 10
1
```左边的车在一秒后到达旗帜并加速`2`。 正确的汽车保持速度`1`。 

该算法独立计算每辆车。 没有对同时加速事件做出任何假设，因此答案仍然是正确的。 

### 跨越旗帜后在同一坐标处相遇

 输入：```
1
2 10
1 9
```一秒钟后，两辆车都撞上了旗帜，并同时加速。 时`3`，两个位置相等`5`。 

二分查找使用条件：```
left_position >= right_position
```因此平等被视为有效的会议状态。 即使汽车完全相遇而不是严格交叉，也能正确找到过渡点。 

### 非常大的坐标

 输入：```
1
2 1000000000
413470354 982876160
```距离和时间可以接近`10^9`。 该算法从不执行整数时间模拟。 它仅使用段长度的算术和对双精度的二分搜索，这在所需的容差范围内保持准确。
