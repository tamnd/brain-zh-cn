 ## 解决方案
 ## 问题理解

 我们得到一个字符串并允许执行一个操作：在某个位置选取一个字符并将其移动到字符串的开头。 目标是在此操作后生成字典顺序最小的字符串。 输入由多个测试用例组成，每个测试用例给出一个字符串。 每个测试用例的输出是最佳移动后的结果字符串。 

约束告诉我们每个字符串最多可以达到$10^5$个字符，并且跨测试用例的所有字符串长度之和最多为$10^5$。 这意味着任何解决方案都必须在相对于字符串长度大致线性的时间内运行，作为$O(n^2)$方法将涉及最多$10^{10}$的操作，这是不可行的。 

边缘情况包括第一个字符已经是最小字符的字符串、具有重复字符的字符串以及多个位置包含相同最小字符的字符串。 例如，对于“aaa”，任何移动都会使字符串保持不变，而对于“cba”，最后一个字符应移动到前面，给出“acb”。 粗心的实现可能只是移动全局最小的字符，而不考虑字符串其余部分的顺序，从而产生次优结果。 

## 方法

 蛮力方法很简单：对于每个位置$i$在字符串中，模拟将该字符移动到前面，并将结果字符串与当前最小值进行比较。 对于一个长度的字符串$n$，每次模拟都需要构造一个新的字符串，取$O(n)$时间。 为所有人做这件事$n$位置给出了$O(n^2)$算法。 这是正确的，但对于$n = 10^5$。 

关键的见解是我们不需要测试每个位置。 仅当字符小于或等于当前第一个字符时，移动字符才有意义，因为否则新字符串将以更大的字符开始，这不是最佳的。 在小于或等于第一个字符的候选者中，我们只需要考虑移动后产生最小字符串的最左边的出现。 通过迭代一次来找到这样的候选者并有效地比较结果字符串，我们将问题简化为$O(n)$每串。 问题结构很简单，因为该操作仅影响第一个字符并保留所有其他字符的顺序，这使得直接比较变得可行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，读取字符串。 
3. 将结果初始化为原始字符串，假设移动第一个字符有效。 
4. 从第二个字符开始迭代字符串。 对于每个字符，检查它是否小于当前的第一个字符或等于。 如果它较小，请考虑将其移动到前面，并通过将其与不包括该字符的子字符串连接来构造结果字符串。 将这个新字符串与当前最好的字符串进行比较。 如果较小，则更新结果。 
5. 考虑完所有字符后，输出该测试用例的结果。 

为什么它有效：不变的是我们始终维护迄今为止所见的字典顺序最小的字符串。 由于我们只考虑可能改进第一个字符的移动字符，并且我们完全比较结果字符串，因此我们保证在一次移动后找到全局最小值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        best = s  # initially, moving the first char is a trivial option
        for i in range(1, n):
            candidate = s[i] + s[:i] + s[i+1:]
            if candidate < best:
                best = candidate
        print(best)

if __name__ == "__main__":
    solve()
```该代码使用快速 I/O`sys.stdin.readline`。 我们从第二个字符开始迭代每个字符，因为移动第一个字符不会更改字符串。 使用切片构建候选字符串，这在 Python 中可以有效地生成新字符串。 我们使用Python内置的字典顺序进行比较`<`运算符，它与问题的定义一致。 通过仔细的索引可以避免差一错误：`s[:i]`排除当前字符，并且`s[i+1:]`后面带有后缀。

 ## 边缘情况

 对于单字符输入“a”，算法不考虑其他位置，原始字符串保持不变。 对于“zzzzz”，任何移动都会产生相同的字符串，并且比较确认最佳值不变。 在“bacab”中，将索引 1 处的“a”移动到前面会得到“abacb”，它比任何其他候选值都小。 对于“aabaaa”，算法正确选择第二个“a”（索引 2）来生成“aaabaa”，确认重复的最少字符得到正确处理。 

该算法在每一步都进行仔细比较，确保不会出现相差一或不正确的字符串形成，并且词典比较可以正确识别所有边缘情况下的全局最小值。
