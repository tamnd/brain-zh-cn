 ## 解决方案
 ## 问题理解

 我们在平面上得到一组点，每个点代表一个不断扩大的圆形“光球”的来源。 每个点都以 1 级灾难开始，其影响随着时间的推移以固定速率均匀向外增长$M$。 时$t$，每个点都有一个半径为的圆盘$M \cdot t$。 

每当两个现有的灾难区域接触或重叠时，它们就会合并成一个组合灾难，其级别是前两个级别的总和。 这种合并是传递的：一旦一组点合并成一个连接的簇，与另一个簇的任何进一步的交集都会合并这两个簇并添加它们的级别。 

任务是找到至少一个连接的簇具有至少总级别的最早时间$K$。 由于每个初始点的级别为 1，因此这相当于找到存在至少包含以下内容的连通分量（在磁盘交叉点下）的最早时间：$K$点。 

两点的几何条件$i$和$j$及时连接$t$是：$$M \cdot t \ge \frac{d_{ij}}{2}$$在哪里$d_{ij}$是点之间的欧几里得距离。 等效地：$$t \ge \frac{d_{ij}}{2M}$$因此，我们正在有效地构建一个图，其边随着时间的推移而“激活”，并且我们希望某些连接的组件达到大小的最早时间$K$。 

约束允许最多$N = 1000$，所以完整的图大约有$5 \times 10^5$边缘。 解决方案与$O(N^2 \log N)$或者$O(N^2)$每个给定的测试用例的结构是可接受的$T \le 200$但我们必须小心常数。 

一个微妙的边缘情况是$K = 1$。 那么答案总是 0，因为每个点在零时刻已经形成了 1 级灾难。 

另一种边缘情况是当点非常接近或相同时。 如果两个点重合，距离为零，因此它们在时间 0 立即合并，这意味着并查找必须正确处理零权重边。 

## 方法

 蛮力的思想是连续模拟时间并重复重新计算在给定时间哪些点是连接的$t$。 对于固定的$t$，我们可以构建一个图，将所有距离最大的对连接起来$2Mt$，然后运行 ​​DFS 或 union-find 来计算组件大小并检查是否有任何组件达到大小$K$。 然后我们可以使用二分搜索随着时间的推移进行搜索。 

这是可行的，因为连接关系在时间上是单调的：一旦两个点连接起来，它们就永远保持连接。 然而，暴力方法变得昂贵，因为每次检查都会花费$O(N^2)$建立边缘和$O(N^2)$或者$O(N \alpha(N))$联合组件。 对于浮动时间（例如 60 次迭代）的二分搜索，对于最坏情况来说总成本变得太大$T = 200$。 

关键的观察是我们实际上不需要模拟时间。 每对点都有固定的激活时间：$$w_{ij} = \frac{d_{ij}}{2M}$$我们只关心边缘何时出现，而不关心时间如何连续进行。 这将问题转化为具有加权边的经典离线连接问题。 我们按激活时间对所有边进行排序，并使用并查找结构按时间递增顺序合并组件。 合并时，我们跟踪组件大小，以及任何组件达到大小的时刻$K$，当前的边缘时间就是答案。 

这将问题简化为对完整图进行克鲁斯卡尔式处理，一旦所需的组件出现就尽早停止。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解 + 二分查找 |$O(T \cdot \log R \cdot N^2)$|$O(N^2)$| 太慢了 |
 | 克鲁斯卡尔 + DSU |$O(T \cdot N^2 \log N)$|$O(N^2)$| 已接受 |

 ## 算法演练

 ### 最优算法

 1. 对于每个测试用例，读取所有点并计算每个成对的欧几里得距离。 这是必要的，因为两个球体之间的每种可能的相互作用仅由它们的几何分离决定。 
2. 对于每对$i, j$，计算它们的球体第一次接触的时间：$$t_{ij} = \frac{\sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}}{2M}$$这将连续增长过程转换为一组离散事件，每对一个。 
3. 存储所有边$(t_{ij}, i, j)$在一个列表中。 每条边代表当时间达到时两个组件之间的未来合并事件$t_{ij}$。 
4. 对所有边进行递增排序$t_{ij}$。 这确保我们按照物理上可能的确切顺序来处理合并。 
5. 初始化一个不相交集并集 (DSU) 结构，其中每个点都从其自己的大小为 1 的分量开始。这反映了最初每个灾难的级别都是 1。 
6. 按排序顺序遍历边。 对于每条边$(t, u, v)$，尝试合并包含的组件$u$和$v$。 如果它们已经在同一个组件中，请跳过它，因为连接是多余的。 
7. 合并两个组件时，更新生成的组件大小。 如果在任何时候组件尺寸至少变为$K$,记录当前时间$t$作为答案并停止处理进一步的边缘。 
8. 输出测试用例的记录时间。 

我们可以提前停止的原因是，一旦组件达到大小$K$，后面的边不能产生更小的有效时间，因为所有剩余的边都出现在相同或更长的时间。 

### 为什么它有效

 随时$t$，由边形成的图$t_{ij} \le t$准确地表示哪些球体相交。 DSU 维护该图的连接组件，因为边按递增顺序添加$t_{ij}$。 由于组件大小恰好是初始单元级别的总和，因此达到大小$K$正好对应有一个级别$K$灾难。 第一次以递增的边顺序发生这种情况必须是最短可能的时间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, M, K = input().split()
        n = int(n)
        M = float(M)
        K = int(K)

        pts = []
        for _ in range(n):
            x, y = map(int, input().split())
            pts.append((x, y))

        if K == 1:
            print("0.0")
            continue

        edges = []
        for i in range(n):
            x1, y1 = pts[i]
            for j in range(i + 1, n):
                x2, y2 = pts[j]
                dx = x1 - x2
                dy = y1 - y2
                dist = (dx * dx + dy * dy) ** 0.5
                edges.append((dist / (2.0 * M), i, j))

        edges.sort()

        parent = list(range(n))
        size = [1] * n

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a, b):
            ra, rb = find(a), find(b)
            if ra == rb:
                return 0
            if size[ra] < size[rb]:
                ra, rb = rb, ra
            parent[rb] = ra
            size[ra] += size[rb]
            return size[ra]

        for t, u, v in edges:
            new_size = union(u, v)
            if new_size >= K:
                print(f"{t:.10f}")
                break
        else:
            print("0.0")

if __name__ == "__main__":
    solve()
```该解决方案是在几何边缘激活时间上直接实现 Kruskal 式合并。 DSU 有效地维护组件成员资格，并且大小数组跟踪灾难级别。 

一个微妙的实现细节是使用浮点平方根计算欧几里德距离。 由于所需的精度公差是$10^{-6}$，标准浮点运算就足够了。 另一个重要的一点是提前终止：一旦出现有效组件，继续只会产生更大的时间，并且是不必要的。

 ## 边缘情况

 当$K = 1$，算法绕过所有几何图形并立即返回 0。 这是正确的，因为每个初始点在没有任何相互作用的情况下就已经形成了 1 级灾难。 

当多个点重合时，它们的两两距离为零，因此它们的合并时间也为零。 DSU 第一步将它们联合起来，立即形成一个更大的组件，并且大小跟踪正确地反映了直接的灾难增长。 

当所有点相距很远时，在很大的时间之前不会出现边缘。 该算法仍然按排序顺序处理所有边，并且仅在第一个必要的合并出现后才返回，即使在稀疏交互场景下也能确保正确性。
