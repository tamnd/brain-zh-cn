 ## 解决方案
 ## 问题理解

 我们得到了一系列硬币堆，每个堆都有一些初始数量的硬币。 两名玩家交替轮流，每个回合中，一名玩家可以选择任意一堆硬币并移除不超过该堆叠中当前硬币数量的任何正数硬币。 在最佳游戏状态下，这种情况无限期地持续下去，游戏最终达到终端配置。 

对结果唯一重要的是堆栈的最终配置。 如果最终数组按非降序排序，则 Ana 获胜。 如果按非递增顺序排序，埃内斯托获胜。 如果两个属性同时成立，则两个玩家都被宣布为获胜者。 

尽管问题被定义为两人最优游戏，但输出仅取决于最终可达到的状态，而不取决于中间得分或移动计数。 这是一个强烈的暗示，表明游戏动态实际上并不影响最终的安排。 

约束条件$N \le 10^6$意味着我们只能对阵列进行一次线性扫描。 任何试图模拟游戏或推理每一步最佳游戏的解决方案都是立即不可行的。 甚至$O(N \log N)$是边界，但这里没有必要，因为每个$A_i \le 100$只允许简单的检查。 

最危险的边缘情况是误解“游戏”的变化。 一个天真的解释会模拟减少或尝试对最佳游戏进行建模，但关键问题是，对于我们关心的最终条件，允许的操作永远不会以任何有意义的方式改变堆栈之间的相对排序约束。 

考虑这些代表性案例：

 如果输入是：```
5
1 2 10 4 5
```该数组既不是非减也不是非增，所以答案不是“两者”。 正确的输出是“Ana”。 

如果输入是：```
5
5 4 3 2 1
```它已经不增加了，所以埃内斯托获胜。 

如果输入是：```
5
5 5 5 5 5
```它同时满足两个单调性，所以两者都赢了。 

一种简单的方法可能会尝试模拟硬币移除和交替回合，但由于每个堆栈始终可以独立地减少并最终减少到 0 与其初始值之间的任何值，因此游戏结构不会引入影响初始序列是否单调的约束。 

## 方法

 暴力解释将尝试模拟游戏。 人们可以将每个状态建模为堆栈的当前向量，并递归地探索所有可能的移动：选择一个堆栈并从中减去任何值。 这很快就变得不可行，因为每个堆栈都可以通过多种方式减少，而且分支因子是巨大的。 即使限制单个单元的移除也最多导致$\sum A_i$移动，但这仍然取决于$10^8$最坏情况下的操作，并且状态空间的堆栈数量呈指数级增长。 

然而，整个模拟是不必要的。 关键的观察是，我们评估的唯一属性是最终配置是否已排序。 由于每个堆栈都可以独立地减少到以下任意值$0$对于其初始值，唯一一致的解释是最终结果不取决于轮次顺序，而仅取决于初始序列是否已经满足在任意独立约简中幸存的单调性约束。 

由于没有任何操作允许在堆栈之间转移硬币，因此最终数组中的相对排序约束已完全由初始配置确定。 游戏不能引入新的反转或以受控方式修复现有的反转； 它仅减少幅度，而不会在位置之间产生耦合。 

因此，整个问题归结为检查初始数组是否不减、不增或两者兼而有之。

 ## 算法演练

 ### 最优策略

 1. 读取堆栈大小数组。 
2. 通过从左到右扫描并验证每个元素至少是前一个元素来检查序列是否为非递减序列。 
3. 通过从左到右扫描并验证每个元素至多是前一个元素来检查序列是否为非递增序列。 
4. 如果两个条件都成立，则输出“Both”。 
5. 如果只有非减成立，则输出“Ana”。 
6. 否则输出“Ernesto”。 

每次扫描都是必要的，因为两个单调性条件是独立的，并且在不跟踪比较的情况下单次扫描无法可靠地确定两者。 

### 为什么它有效

 最终结果仅取决于初始排序是否已经单调。 由于任何移动都不允许改变位置之间的相对顺序约束，因此任何已经非递减或非递增的序列在游戏允许的减少下仍然有效。 相反，如果初始数组违反了两个单调性，则任何独立递减序列都不能以改变分类结果的方式同时强制执行任一全局顺序条件。 因此，分类完全简化为检查初始数组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    nondec = True
    noninc = True

    for i in range(1, n):
        if a[i] < a[i - 1]:
            nondec = False
        if a[i] > a[i - 1]:
            noninc = False

    if nondec and noninc:
        print("Both")
    elif nondec:
        print("Ana")
    else:
        print("Ernesto")

if __name__ == "__main__":
    solve()
```该实现依赖于单个线性扫描，维护两个布尔标志。 第一个标志跟踪是否发生任何下降，这将违反非递减顺序。 第二个跟踪是否发生任何上升，这将违反非递增顺序。 最终决定是在一次通过后做出的，确保了最佳性能$N$最多一百万。 

一个常见的陷阱是使用完整排序重新计算排序，这会引入不必要的$O(N \log N)$开销。 另一种是尝试模拟游戏动作，这与最终分类无关。

 ## 边缘情况

 对于单元素数组，序列同时不减且不增，因为不存在相邻违规。 该算法正确地保持两个标志为真并输出“两者”。 

对于像这样的常量数组`5 5 5 5 5`，每次比较都是相等的，因此不会发生增加或减少违规情况。 两个标志始终保持正确，产生“Both”。 

对于严格单调的数组，只有一个标志幸存下来。 扫描仅根据相邻比较正确识别方向性，确保不依赖于绝对值或游戏解释
