 ## 解决方案
 ## 问题理解

 我们给出一个正整数$X$，并且要求我们构造一个同时满足两个条件的数。 首先，它必须能被整除$X$。 其次，它必须是完全平方，这意味着它的质因数分解的所有指数都是偶数。 

思考这个任务的另一种方式是我们可以乘以$X$由某个正整数$k$，我们想要最小的可能值$X \cdot k$使得结果成为一个完美的平方。 

约束条件$X \le 10^9$意味着我们无法承担任何依赖于迭代倍数或向上搜索平方的算法。 像检查一样简单的扫描$X, 2X, 3X,\dots$在最坏的情况下，测试每个是否是一个正方形会太慢，因为最小的平方倍数可能比$X$，特别是当$X$有许多不同的质因数。 

当出现以下情况时，会出现不太明显的困难：$X$是无平方或接近无平方的。 例如，当$X = 30$，答案是$900$，这已经是 30 倍大了$X$。 如果我们尝试线性搜索，我们很快就会超出任何合理的时间限制。 

关键的边缘情况结构是，答案不是从加法或整除模式得出的，而是从素数分解中指数的奇偶性得出的。 任何忽略因式分解的简单方法在以下情况下都会失败$X = 12$，其中答案是$36$， 不是$12$或者$24$，并且如果没有结构推理，正确的乘数并不明显。 

## 方法

 暴力方法从$X$并检查$X \cdot 1, X \cdot 2, X \cdot 3,\dots$，测试每个值是否是完全平方数。 每次检查都需要计算整数平方根或验证整数的平方是否等于该数字。 在最坏的情况下，正确答案可能很远，因此这会退化为扫描大范围的整数，很容易超过$10^9$运营。 

结构观察来自素因数分解。 一个数是完全平方数当且仅当其因式分解中的每个素数指数都是偶数。 如果我们写$X$作为素数与指数的乘积，我们可以准确地看到哪些素数违反了这个条件。 每个具有奇数指数的素数必须与其自身的另一个副本配对，以使指数为偶数。 这意味着我们只需要乘以$X$通过固定所有指数奇偶性的最小因子。 

这将问题转化为确定性构造：因式分解$X$，收集所有指数为奇数的素数，并将它们相乘一次。 该乘积正是使所有指数变成偶数的最小数字，产生最小的平方倍数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(k \sqrt{X})$或者更糟|$O(1)$| 太慢了|
 | 最佳|$O(\sqrt{X})$|$O(1)$| 已接受 |

 ## 算法演练

 1. 因式分解$X$通过测试除数$\sqrt{X}$。 对于每个除数$p$, 反复除$X$经过$p$来计算它的指数。 这是必要的，因为素数结构决定了方形度。 
2. 维护一个初始化为 1 的运行结果。该变量将存储纠正指数奇偶校验所需的最小乘数。 
3. 对于每个素因数$p$，检查它除以多少次$X$。 如果它的指数是奇数，则将结果乘以$p$。 这修复了奇偶校验，因为添加了一份副本$p$将奇数指数变成偶数。 
4. 处理完所有素数后$\sqrt{X}$，如果剩余的$X$大于 1，它是指数为 1 的质因数。这始终是奇数，因此将结果乘以这个剩余的质数。 
5.归还原件$X$乘以计算出的校正因子，保证是一个完美的平方。 

步骤 4 背后的推理很重要：任何大于的素数$\sqrt{X}$不能出现两次，因此它的指数必须恰好为 1。这会自动使其成为奇数。 

### 为什么它有效

 每个整数都有唯一的质因数分解。 当且仅当分解中的所有指数都是偶数时，一个数才是完全平方数。 该算法通过独立校正每个奇数指数一次来构造最小乘数，使所有指数为偶数。 不同素数之间不存在相互作用，因此最小化乘数就可以简化为局部奇偶校验修复。 由于我们只将每个奇质因子相加一次，因此所得的乘积是可能的最小校正因子。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    x = int(input().strip())
    original = x
    res = 1

    i = 2
    while i * i <= x:
        if x % i == 0:
            cnt = 0
            while x % i == 0:
                x //= i
                cnt += 1
            if cnt % 2 == 1:
                res *= i
        i += 1

    if x > 1:
        res *= x

    print(original * res)

if __name__ == "__main__":
    solve()
```该解决方案依赖于标准试除因式分解循环。 变量`res`精确累加在原始输入分解中出现奇数次的素数。 

一个微妙的点是我们必须保留原始值$X$在因式分解之前将其减少到 1。最终的乘法使用该原始值，因为`x`成为分解过程中减少的余数。

 ### 示例 1：$X = 12$我们因式分解$12 = 2^2 \cdot 3^1$。

这表明只有奇数指数的素数对乘数有贡献。

 最终值为$16 \cdot 1 = 16$。 

这证实了已经完美的正方形保持不变。

 ## 边缘情况

 对于$X = 1$，因式分解循环不执行任何操作，并且`res`仍为 1，因此输出为$1$。 该算法正确地将 1 视为完全平方数。 

对于像这样的素数$X = 2$，因式分解得到指数 1，所以`res`变为 2，结果为$2 \cdot 2 = 4$，这是最小的平方倍数。 

对于像这样的数字$X = 18 = 2 \cdot 3^2$，只有素数 2 有奇数指数。 该算法乘以 2，产生$36$，并且不存在更小的平方倍数，因为任何平方必须至少包含$2^2$。 

对于像这样的完美正方形$X = 49$，所有指数都是偶数，所以`res = 1`并且输出保持不变。
