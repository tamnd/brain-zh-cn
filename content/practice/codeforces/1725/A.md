 ## 解决方案
 ## 问题理解

 这个问题中的网格不是任意的，它完全由它的尺寸决定。 每个单元格都包含一个唯一的整数，并且数字从左到右逐行增加。 第一行填充了前 M 个整数，第二行紧随其后，依此类推。 因此网格的行为就像一个按行优先顺序编写的展平数组。 

我们被要求计算满足特定条件的相邻单元对的数量。 一对由共享一侧的两个单元形成，这意味着我们只考虑水平和垂直的邻居。 如果这两个单元格内的数字之间的绝对差恰好为 1，则这对单元格称为有效单元格对。每个无序单元格对均计数一次。 

关键的结构约束是数字以非常严格的模式连续。 这使得邻接比较具有确定性，因为我们不需要模拟网格，只需推理由行和列位置引起的算术关系。 

约束允许 N 和 M 最大为 10^9，这立即排除了网格的任何构造。 即使是大小为 10^9 的单行也无法在时间限制内显式存储或迭代。 由于线性或二次爆炸，任何单独迭代单元或边缘的解决方案都会失败。 唯一可行的方法是以 O(1) 或 O(log N) 算术项进行推理。 

当 N 或 M 为 1 时，会出现微妙的边缘情况。当 M = 1 时，没有水平邻接，只有垂直邻接。 当 N = 1 时，没有垂直邻接，只有水平邻接。 假设两个方向都存在的幼稚实现将过度计数或尝试无效索引。 另一个极端情况是行之间的转换：值从第 i 行换行到第 i+1 行，并且此边界的行为与行内邻接不同。 

## 方法

 强力解决方案将显式构建网格并检查每对相邻单元格。 每个单元最多有两个前向邻居，因此这将涉及扫描所有 N × M 单元并对每个单元执行持续检查。 这会导致 O(NM) 运算，这是不可能的，因为 NM 可以达到 10^18。 

关键的观察是邻接是局部的并且值分配是线性的。 在行内，连续列的值相差正好 1。 这意味着每个水平边缘都会自动形成有效的紧密多米诺骨牌。 每行恰好有 M - 1 个这样的边，并且有 N 行，因此水平贡献很简单。 

垂直边缘更加微妙。 从同一列的第 i 行移动到第 i+1 行，该值正好增加了 M。因此，垂直邻居相差 M，而不是 1，这意味着除非 M = 1，否则垂直边缘永远不会合格。在这种特殊情况下，每列都是连续整数链，并且每个垂直邻接都有效。 

因此，整个问题简化为计算水平有效边缘，并在 M = 1 时有条件地添加垂直有效边缘。

 | --- | --- | --- | --- |
 | 蛮力 | O(NM) | O(1) | O(1) | 太慢了|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将计数分为水平贡献和垂直贡献。 

1. 通过独立考虑每一行来计算水平紧多米诺骨牌。 

在长度为 M 的行中，每对相邻的列都形成值 x 和 x+1，因此所有 M - 1 条水平边都是有效的。 由于有 N 行，因此贡献了 N × (M - 1)。 
2. 通过检查列结构来单独处理垂直邻接。 

单元格 (i, j) 和 (i+1, j) 之间的值差始终为 M。仅当 M = 1 时才等于 1，因为只有这样编号才会折叠成单个链。 
3. 如果M等于1，则每列成为连续整数的垂直序列。

在这种情况下，每列贡献 N - 1 个有效垂直边缘，并且有 M 个这样的列，因此垂直贡献为 M × (N - 1)。 
4. 将贡献值相加并输出结果。 

为什么它有效

 网格通过线性公式定义坐标和整数之间的双射。 水平邻接保留了连续的整数，因为构造沿行递增 1。 仅当行步长 M 等于 1 时，垂直邻接才保留连续整数。由于邻接结构完全分解为独立的水平和垂直分量，没有重叠，因此单独计算每个方向可以给出所有可能边缘的精确划分。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())

horizontal = N * (M - 1)
vertical = M * (N - 1) if M == 1 else 0

print(horizontal + vertical)
```该实现直接对先前导出的分解进行编码。 水平边缘是根据每行贡献 M - 1 个有效对这一事实来计算的。 仅在 M = 1 的退化情况下添加垂直边缘，因为否则垂直差异始终大于 1。 

一个常见的错误是尝试使用 N × (M - 1) 对称地添加垂直边缘，镜像水平公式。 这是失败的，因为垂直邻接取决于编号的步长，而不是网格形状的对称性。 另一个陷阱是忘记了当 M > 1 时垂直边缘完全消失。

## 测试用例```python
import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline
    N, M = map(int, input().split())
    horizontal = N * (M - 1)
    vertical = M * (N - 1) if M == 1 else 0
    return str(horizontal + vertical)

# provided sample
assert solve("3 4\n") == "9"

# minimum case
assert solve("1 1\n") == "0"

# single row
assert solve("1 5\n") == "4"

# single column
assert solve("5 1\n") == "4"

# rectangular grid
assert solve("2 3\n") == "4"

 ## 边缘情况

 当 N = 1 且 M = 1 时，网格只有一个单元，因此不存在相邻对。 该算法返回水平 = 1 × 0 = 0 并跳过垂直，因为 M ≠ 1 条件失败，正确给出 0。 

当 N = 1 且 M > 1 时，网格为单行。 水平计算产生 M - 1，它与一行中相邻对的数量相匹配。 垂直保持为零，正确避免无效的跨行推理。 

当 M = 1 且 N > 1 时，网格变为连续整数的单列。 水平为零，垂直变为 1 × (N - 1)，正确捕捉每一步相差 1 的链结构。
