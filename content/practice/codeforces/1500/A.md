 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，代表朋友送给 Nastya 的礼物。 她想要在数组中找到四个不同的索引，使得前两个索引处的元素之和等于其他两个索引处的元素之和。 输入由数组的大小及其后的数组本身组成，如果存在此类索引以及索引本身，则输出应为“YES”，否则输出应为“NO”。 

这些约束允许数组大小最多为 200,000 个，每个元素最多为 250 万个。 给定 2 秒的时间限制，任何迭代所有四元组的算法都需要以下顺序：$O(n^4)$的操作，这是完全不可行的。 即使天真地迭代所有对也有可能$O(n^2)$，在最坏的情况下可能达到 4 * 10^10 次操作。 因此，我们需要避免对所有四元组进行天真的枚举。 

非明显的边缘情况包括所有元素都相等的数组，或许多元素重复的数组。 粗心的方法可能会两次选择相同的索引，或者无法考虑共享元素的对。 例如，在数组中`[1, 1, 1, 1]`，如果不强制执行索引唯一性，任何简单的总和比较都可能错误地输出“NO”。 另一个微妙的情况是只有四个元素的小数组； 该算法仍然必须正确处理最小输入大小。 

## 方法

 蛮力方法是迭代四个索引的每个组合$x, y, z, w$，计算两个元素对的总和，并比较它们。 这个方法是正确的，但是需要$O(n^4)$操作，这是不可能的$n = 2 \times 10^5$。 稍微好一点的方法是迭代所有对，计算它们的总和，并将每个总和及其相应的索引存储起来。 一旦我们找到一个在不相交索引中出现两次的和，我们就有了一个解决方案。 将总和存储在哈希图中可以让我们有效地检测重复项。 

关键的见解是我们不需要比较所有四元组。 相反，我们可以迭代所有对，将它们的总和映射到生成它们的索引，并检查该映射中的冲突。 如果总和与不重叠的索引重复，我们立即找到四个不同的索引。 给定约束，迭代所有对是$O(n^2)$，这对于小数组来说是可以接受的，但对于$n = 2 \times 10^5$。 然而，在不失一般性的情况下，该问题可以限制为仅考虑前 200 个元素，因为由于总和范围有限，超过 200 个元素可以通过鸽巢原理保证重复求和。 这将我们的复杂性降低到$O(200^2) = 40,000$，这足够快了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^4) | O(n^4) | O(1) | O(1) | 太慢了 |
 | 对和哈希 | O(分钟(n,200)^2) | O(分钟(n,200)^2) | 已接受 |

 ## 算法演练

 1. 如果数组超过 200 个元素，则截断为前 200 个元素。 这是可行的，因为不同和的数量受到最大元素的限制，因此根据鸽巢原理，前 200 个元素中对之间的任何重复和都足以保证解决方案。 
2. 初始化一个空的哈希映射，它将映射对的总和到生成该总和的索引。 
3. 迭代所有索引对$i$和$j$在截断的数组中。 
4. 计算索引处元素的总和$i$和$j$。 
5. 如果这个和已经在哈希图中，检查存储的索引是否与当前对不重叠。 如果它们不相交，则打印“YES”和四个索引并退出。 
6. 如果总和不在映射中或者索引重叠，则存储该总和的当前对。 
7. 如果在所有迭代之后没有对不相交的索引重复，则打印“NO”。 

工作原理：该算法依赖于将每个可能的对和映射到唯一的索引对。 通过系统地扫描所有对，第一次用不相交索引重复求和可以保证总和相等并且索引全部不同。 将数组截断为 200 个元素是安全的，因为超过 200 个元素可以保证截断数组对之间的重复求和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    limit = min(n, 200)
    a = a[:limit]
    n = len(a)
    
    pair_sum = {}
    
    for i in range(n):
        for j in range(i + 1, n):
            s = a[i] + a[j]
            if s in pair_sum:
                x, y = pair_sum[s]
                if x != i and x != j and y != i and y != j:
                    print("YES")
                    print(x + 1, y + 1, i + 1, j + 1)
                    return
            else:
                pair_sum[s] = (i, j)
    print("NO")

solve()
```该解决方案首先将数组截断为 200 个元素，以使二次方法可行。 嵌套循环可以有效地计算对和，并使用哈希图快速检测重复的和。 在报告解决方案之前，会仔细执行索引唯一性。 在打印之前，索引会转换为从 1 开始的索引。
