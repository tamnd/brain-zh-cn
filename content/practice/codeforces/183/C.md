 ## 解决方案
 ## 问题理解

 我们有一个有向图，其中每条边都强制其端点的颜色之间存在严格的关系。 如果一个顶点有颜色`c`，那么每个出局邻居都必须有颜色`c + 1`，环绕模数`k`。 

条件的另一种写法是：$color(v) \equiv color(u)+1 \pmod{k}$在循环编号系统中，每个有向边都会将颜色精确地增加一步。 

任务是找到最大可能的`k`存在这样的分配。 

该图可能包含自环和多条边。 自循环尤其具有限制性，因为从顶点到自身的边需要：$color(u) \equiv color(u)+1 \pmod{k}$这意味着`k = 1`。 

约束足够大，我们需要一个几乎线性的解决方案。 高达`10^5`顶点和边，任何尝试所有的算法`k`值并独立验证它们会变得太慢。 二次图遍历立即被排除。 我们应该期待周围有什么`O(n + m)`或者`O((n + m) log n)`。 

棘手的部分是理解全局颜色限制的真正含义。 

假设我们沿着一条长度为的有向路径行走`d`。 每条边都会将颜色前进一位，因此在遍历路径后，端点之间的色差被迫为`d mod k`。 

现在考虑长度的有向循环`L`。 从一个顶点出发并返回到该顶点意味着：$L \equiv 0 \pmod{k}$所以每个有向循环长度必须能被整除`k`。 

这一观察完全改变了问题。 我们不需要直接考虑颜色，而只需要了解周期长度。 

一些边缘情况很容易被错误处理。 

考虑一个自循环：```
1 1
1 1
```唯一有效的答案是：```
1
```只考虑普通循环的粗心实现可能会错过长度的循环`1`力量`k = 1`。 

另一个危险的情况是断开连接的图：```
4 2
1 2
3 4
```根本不存在有向循环。 在 DAG 中，我们可以使用任意大的`k`，因为不会出现任何矛盾。 由于问题需要`k ≤ n`，正确答案是`n = 4`。 

仅计算现有周期上的 gcd 的实现可能会意外返回`0`。 

一个更微妙的例子是：```
3 3
1 2
2 3
3 1
```该图有一个长度为环的图`3`，所以答案是`3`。 

但如果我们添加另一条边：```
3 4
1 2
2 3
3 1
1 3
```我们创建一个长度的循环`2`还有：`1 -> 3 -> 1`现在两者`2`和`3`必须能整除`k`，所以只有：```
1
```作品。 

一次仅检查一个 DFS 周期的解决方案可能会错误地返回`3`。 

## 方法

 蛮力的想法很简单。 尝试一切可能`k`从`n`下降到`1`，并检查是否存在有效的着色。 

对于固定的`k`，我们可以使用 DFS 或 BFS 分配颜色。 每条边都强制执行：```
color[v] = (color[u] + 1) mod k
```如果我们为同一个顶点导出两种不同的颜色，那么`k`无效。 

此验证需要`O(n + m)`时间。 为每个人做事`k`给出：```
O(n(n + m))
```和`n = 10^5`，这变得太大了。 

关键的观察结果是边缘约束沿着路径累积。 一条有长度的路`d`强制色差为`d mod k`。 每当两条不同的路径连接同一对顶点时，它们的长度必须模数一致`k`。 

假设 DFS 为每个顶点分配一个深度。 对于每一个边缘`u -> v`，我们知道：```
depth[v] = depth[u] + 1
```沿着树的边缘。 

如果我们遇到非树边，那么：```
depth[u] + 1 - depth[v]
```表示两种到达方式之间的长度差`v`。 

该差值必须能被整除`k`。 

收集整个图中的这些约束可以得出：$k \mid (depth[u]+1-depth[v])$对于每个边缘。 

所以最大有效`k`就是所有这些值的 gcd。 

为什么这有效？ 

每个有向循环都会贡献这些差异之一，并且 gcd 准确捕获所有循环长度共享的公约数。 

如果该图没有有向环，则所有差异为零，这意味着根本没有限制。 在这种情况下，答案是`n`。 

最终算法对图执行一次 DFS 并增量计算 gcd。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n(n + m)) | O(n(n + m)) | O(n) | 太慢了 |
 | 最佳| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 构建有向图的邻接表。 
2. 维护一个初始化为的深度数组`-1`。 值为`-1`表示该顶点尚未被访问过。 
3. 从每个未访问的顶点开始DFS。 将起始深度设置为`0`。 
4. 在DFS过程中，对于每条边`u -> v`：

如果`v`未访问过，则赋值：```
depth[v] = depth[u] + 1
```并继续DFS。 
5. 如果`v`已经被访问过，计算：```
diff = depth[u] + 1 - depth[v]
```该值代表循环约束。 任何有效的`k`必须除以这个数。 
6. 保持所有非零的gcd`diff`DFS 期间遇到的值。 
7. 处理完整个图后：

 如果 gcd 是`0`，该图不包含循环约束，因此任何`k`作品。 允许的最大答案是`n`。 
8. 否则，输出gcd的绝对值。 

### 为什么它有效

 DFS 深度对从 DFS 根开始的路径长度进行编码。 

对于每一个边缘`u -> v`，表达式：```
depth[u] + 1 - depth[v]
```测量两个路径长度之间的差异`v`。 

有效的着色要求相同顶点之间的所有路径长度都符合模数`k`。 这意味着每个这样的差异必须可以被整除`k`。 

所有差异的最大公约数正是同时除以每个循环长度约束的最大数。 任何更大的数字都会违反至少一个周期。 

如果所有差异均为零，则该图对于这些约束的行为类似于 DAG，并且对`k`存在。 

## Python 解决方案```python
import sys
from math import gcd

input = sys.stdin.readline

def solve():
    sys.setrecursionlimit(1 << 25)

    n, m = map(int, input().split())

    graph = [[] for _ in range(n)]

    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        graph[u].append(v)

    depth = [-1] * n
    g = 0

    def dfs(u):
        nonlocal g

        for v in graph[u]:
            if depth[v] == -1:
                depth[v] = depth[u] + 1
                dfs(v)
            else:
                diff = depth[u] + 1 - depth[v]
                g = gcd(g, abs(diff))

    for i in range(n):
        if depth[i] == -1:
            depth[i] = 0
            dfs(i)

    if g == 0:
        print(n)
    else:
        print(g)

solve()
```邻接表存储所有出边。 多个边缘和自环自然地工作，无需任何特殊处理。 

这`depth`数组有两个用途。 它标记访问过的顶点并记录导出循环约束所需的 DFS 深度。 

当 DFS 沿着树边时，子深度将比父深度大 1。 这与每个有向边将颜色增加一这一事实相匹配。 

对于已经访问过的顶点，计算出的`diff`捕获两条路径之间的差异。 增量地获取 gcd 就足够了，因为 gcd 是关联的：```
gcd(a, b, c) = gcd(gcd(a, b), c)
```绝对值很重要。 根据遍历顺序，`diff`可能会变成负值，但可分性约束仅取决于大小。 

特殊情况`g == 0`当每个差异都为零时发生。 这意味着没有发现不平凡的循环约束。 在这种情况下，该图允许任何`k`，所以最大允许值为`n`。

 ## 边缘情况

 自循环立即迫使答案`1`。 

输入：```
1 1
1 1
```DFS 从顶点开始`1`有深度`0`。 

对于边缘`1 -> 1`：```
diff = 0 + 1 - 0 = 1
```gcd 变为`1`，所以最终的答案是`1`。 

这是有效的，因为自循环要求颜色等于它自己的下一个颜色。 

现在考虑一个没有循环的图：```
4 2
1 2
3 4
```DFS 分配不断增加的深度，但每条边都指向未访问的节点。 不会出现非树边，因此 gcd 仍然存在`0`。 

算法输出`n = 4`。 

这正确地反映了非循环图没有施加模块化限制。 

最后，考虑相互冲突的周期长度：```
3 4
1 2
2 3
3 1
1 3
```该图包含 3 循环和 2 循环。 

DFS 使用 gcd 产生约束：```
gcd(3, 2) = 1
```所以只有`k = 1`作品。 

该算法正确地组合了所有周期信息，而不是依赖于单个检测到的周期。
