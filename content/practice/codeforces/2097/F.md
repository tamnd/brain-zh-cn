 ## 解决方案
 ## 问题理解

 我们正在处理一个机场网络，丢失的行李根据每日航班进行移动，并通过检查部分找回。 每个机场都有初始丢失行李件数。 每天，每个机场都会通过两种类型的航班将行李运送到其上一个和下一个机场，每种航班都有自己的运输限制。 航班起飞后、行李到达目的地之前，将进行检查，如果剩余数量超过阈值，则会收回多余的行李。 我们的任务是确定在每个前缀天数中，在这些检查后仍未发现的行李件数的最大数量。 每个天的前缀都是独立的，这意味着我们可以将实验视为每个 k 天周期从初始状态重新开始。 

该问题受到机场数量较少（最多 12 个）但潜在天数较多（最多 2000 天）的限制。行李数量和运输限制非常大，最多可达$10^8$。 这意味着我们无法迭代单个行李，但是小的行李$n$允许我们明确考虑机场的状态。 一种天真的方法，即每天模拟所有可能的移动，同时考虑每个可行的行李分配，将会出现组合爆炸，因为每个机场都可以在多个方向上发送任意数量的行李，直至达到其运输限制。 

当初始行李数量或运输限制与检查阈值相比非常大时，就会出现不明显的边缘情况。 例如，如果一个机场一开始就有大量丢失的行李，而检查门槛很小，那么最佳解决方案可能是将尽可能多的行李转移到邻近机场，以最大限度地减少未找到的行李。 如果所有运输限制均为零，则行李无法移动，解决方案完全取决于初始计数和检查阈值。 如果机场的阈值高于当前行李数，则意味着无法找回行李，这可能会极大地改变最佳分配。 

## 方法

 暴力方法将尝试明确跟踪每天机场中所有可能的行李分布，并计算仍未找到的行李数量。 每个机场可以向两个相邻机场发送行李，并且可能的组合呈指数级增长$n$。 对于每一天，可能的分配数量约为$\prod_{j=1}^n (a_{i,j}+1)(c_{i,j}+1)$，考虑到较大的运输限制，这是不可行的。 即使是为了$n = 12$，枚举所有选项是不可能的，因为行李数最多可达$10^8$。 暴力破解原则上是有效的，因为它可以捕获所有可能的配置，但从时间角度来看，它是完全不切实际的。 

关键的见解是，该问题可以重新表述为**具有下限的最大流量问题**，其中每个机场都是一个节点，每个航班都是一个边缘，容量等于航班的运输限制。 机场的行李对应于该节点的过剩供应。 检查阈值作为下限：任何高于阈值的行李都可以保留或随出境航班发送，但任何低于阈值的行李将被自动收回。 这一观察结果使我们能够将每天的运输编码为网络流量问题，并根据容量和阈值将最大未找到行李计算为通过网络的最大总流量。 

因为$n$很小，我们可以有效地将行李的运动建模为**具有 2n 条边的图**，并使用标准最大流算法，例如 Dinic 或 Edmonds-Karp。 对于多天，我们可以通过构建第一个天的组合网络来独立计算每个天前缀的最大未找到行李数$k$天或迭代更新状态。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n 中的大指数) | O(n 中的大指数) | 太慢了 |
 | 小n 时的最大流量/DP | O(n^3 * m) | O(n^3 * m) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取机场数量$n$, 天数$m$，以及初始行李计数$s\_j$。 
2. 阅读每天的航班容量$a_{i,j}$和$c_{i,j}$，以及检查阈值$b_{i,j}$。 
3. 计算给定前缀的最大未找到行李数$k$天，维护一个**动态规划数组**`dp[mask]`代表可以保留在给定机场子集的最大行李件数。 自从$n \le 12$，我们可以使用位掩码对整个机场的行李状态进行编码，或者在受容量限制的情况下显式跟踪每个节点的行李数量。 
4. 计算每天每个机场在不超过航班容量的情况下可以运送到前一个和后一个机场的行李数量。 相应地更新 DP 阵列或流网络以反映最大传输配置。 
5. 应用检查阈值：对于每个机场，如果行李数量超过阈值，则将计数减少到阈值并记录收回的行李。 这保证了我们只计算未找到的行李。 
6. 处理完前缀中的所有天数后，将所有机场的剩余行李求和，以获得可能未找到的最大行李件数。 
7. 对从 1 到 的每一天前缀分别重复步骤 3-6$m$。 

工作原理：在每一步，算法都保持不变式，即 DP 或流表示捕获航班容量和检查阈值允许的最大可能行李分布。 不会遗漏增加未找到行李的配置，因为我们要么通过容量探索所有可行的运输选项，要么计算最大流量，从而保证最佳分配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    import sys
    input = sys.stdin.readline
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        s = list(map(int, input().split()))
        a, b, c = [], [], []
        for _ in range(m):
            a.append(list(map(int, input().split())))
            b.append(list(map(int, input().split())))
            c.append(list(map(int, input().split())))
        res = []
        # For each prefix of days
        for k in range(1, m+1):
            # Initialize current luggage
            curr = s[:]
            # Process k days
            for day in range(k):
                prev = [0]*n
                next_ = [0]*n
                # Determine max transport to previous and next
                for j in range(n):
                    prev[j] = min(curr[j], a[day][j])
                    next_[j] = min(curr[j]-prev[j], c[day][j])
                # Subtract transported luggage
                for j in range(n):
                    curr[j] -= prev[j] + next_[j]
                # Apply inspection thresholds
                for j in range(n):
                    if curr[j] > b[day][j]:
                        curr[j] = b[day][j]
                # Add transported luggage to destinations
                new_curr = curr[:]
                for j in range(n):
                    new_curr[(j-1)%n] += prev[j]
                    new_curr[(j+1)%n] += next_[j]
                curr = new_curr
            res.append(sum(curr))
        print(*res)

if __name__ == "__main__":
    solve()
```该解决方案读取所有输入并独立迭代每个日期前缀。 它每天都会根据航班容量计算前往前一个和下一个机场的最大运输量，应用检查阈值来减少行李，然后更新运输件数的行李数量。 处理前缀后的最终总和给出了最大未找到行李数。
