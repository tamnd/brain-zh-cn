 ## 解决方案
 ## 问题理解

 任务是在矩形网格上重建一条简单路径，其中仅已知具有奇数索引的单元格。 具体来说，路径在“已知”和“未知”单元之间交替，以已知单元开始和结束。 完整路径中的每对连续单元格必须水平或垂直相邻。 挑战在于计算插入未知单元的所有可能方式，以便路径保持简单并满足邻接约束。 

输入提供多个测试用例。 每个测试用例指定网格尺寸、已知单元之间的步数（由编码$k$），以及坐标$k+1$已知的细胞。 输出是路径模数的有效完成次数$10^9 + 7$。 

约束告诉我们所有测试用例的单元总数最多为$10^6$，这使得解线性化$n \cdot m$每个测试用例。 然而，暴力尝试枚举所有可能的路径将是指数级的$k$，这可能高达单元总数的大约一半，使得朴素的 DFS 或 BFS 不可行。 

当两个连续的已知单元相距太远而无法通过单个中间单元连接时，就会出现边缘情况。 例如，如果 2×4 网格上的已知单元为 (1,1) 和 (1,4)，则不存在与两者相邻的中间单元，因此有效路径的数量为零。 另一个微妙的情况出现在网格边界处，其中唯一可用的邻居可能被先前已知的单元格阻挡，从而限制了未知单元格的选择数量。 

## 方法

 强力方法将尝试在每对已知单元之间生成所有可能的中间单元并检查邻接性。 对于每对已知细胞，未知细胞最多有四个候选邻居，从而导致$4^k$最坏情况下的可能性。 这仅适用于非常小的网格，但完全不切实际$k$所有测试用例最多可达 500,000 个。 

关键的见解是，一旦已知端点固定，路径的未知单元就独立于所有其他未知单元。 两个连续的已知单元格之间$p_{2i-1}$和$p_{2i+1}$, 未知细胞$p_{2i}$必须与两个端点相邻。 这将问题简化为计算每对连续的已知单元之间的共享邻居的数量。 如果一对有零个共享邻居，则不存在路径。 否则，完成次数是所有连续对的共享邻居计数的乘积。 这一观察结果将指数问题转化为线性问题$k$，因为我们只需要计算每个连续对的邻居集的交集。

 | ---| ---| ---| ---|
 | 蛮力 | O(4^k) | O(4^k) | O(k) | 太慢了 |
 | 最佳 | 每个测试用例的 O(k) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读$n$,$m$， 和$k$，然后是坐标$k+1$已知的细胞。 如果方便的话，将它们转换为基于 0 的索引。 
2. 初始化变量`ans = 1`。 这将存储有效完成的数量。 
3. 迭代每对连续的已知单元格，例如$p_{2i-1}$和$p_{2i+1}$。 
4. 计算所有邻居$p_{2i-1}$在网格边界内。 类似地，计算所有邻居$p_{2i+1}$。 
5. 计算这两个邻居集的交集。 该计数表示中间单元格的有效选择数$p_{2i}$。 
6. 如果任何对的计数为零，则立即设置`ans = 0`并打破。 否则，乘以`ans`按此计数模$10^9+7$。 
7. 处理完所有连续对后，打印`ans`对于当前的测试用例。 

为什么它有效：不变的是，对于每对连续的已知单元，我们正确计算所有有效的中间单元。 将计数相乘即可考虑沿路径的所有独立选择。 由于路径必须简单，因此保证每个中间单元不与任何已知单元重合，满足邻接性和简单性约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        known = [tuple(map(int, input().split())) for _ in range(k+1)]
        ans = 1
        for i in range(k):
            x1, y1 = known[i]
            x2, y2 = known[i+1]
            neighbors1 = set()
            neighbors2 = set()
            for dx, dy in [(-1,0),(1,0),(0,-1),(0,1)]:
                nx1, ny1 = x1+dx, y1+dy
                if 1 <= nx1 <= n and 1 <= ny1 <= m:
                    neighbors1.add((nx1, ny1))
                nx2, ny2 = x2+dx, y2+dy
                if 1 <= nx2 <= n and 1 <= ny2 <= m:
                    neighbors2.add((nx2, ny2))
            common = neighbors1 & neighbors2
            cnt = len(common)
            if cnt == 0:
                ans = 0
                break
            ans = (ans * cnt) % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```每个部分都严格遵循算法步骤。 首先读取所有输入允许计算按顺序进行。 集合的使用确保只考虑有效的邻居，并且重复项不会增加计数。 每次乘法后应用模运算以避免溢出。 生成邻居时会显式处理边界条件。
