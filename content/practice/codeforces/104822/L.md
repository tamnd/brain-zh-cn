 ## 解决方案
 ## 问题理解

 我们被要求计算在强结构约束下，从部分已知的数组可以完成多少个从 1 到 n 的数字的完整排列。 

该约束通过前缀规则定义有效排列。 当我们从左到右扫描排列时，每个位置必须是迄今为止看到的所有元素中新的全局最小值，或者是迄今为止看到的所有元素中新的全局最大值。 任何既不严格扩展前缀最小值也不扩展前缀最大值的元素都会使排列无效。 

我们得到一个部分填充的数组。 有些位置是固定的，其余的则未知。 任务是计算有多少种方法可以用剩余的未使用的数字来填充缺失的值，以便最终的排列满足这个前缀最小-最大属性​​。 

关键的限制是已知值保证是不同的，因此我们永远不必解决固定位置之间的冲突。 未知位置形成槽，其中剩余数字必须与前缀结构一致地放置。 

约束很大：测试的总 n 最多为 2⋅10^5。 这立即排除了任何枚举排列或尝试为每个位置独立分配值的方法。 每次测试甚至二次都太慢。 该解决方案必须在线性或近线性时间内有效地处理每个测试。 

一些边缘情况暴露了结构：

 如果所有值均缺失，例如 n = 4 全为零，则答案不是 4！ 但是 2^(n-1)，因为遵守该规则的每个排列都对应于在每个步骤中选择下一个极值是扩展最小边还是最大边。 

如果固定值强制使用不可能的前缀模式，例如在任何有效完成中既不符合前缀 min 也不符合前缀 max 的中间元素，则答案变为零。 例如，如果我们以违反排序约束的方式修复严格位于已强制极端值之间的值，则任何补全都无法修复它。 

如果固定值已经与极值过程形成矛盾，例如强制应出现在较小已知值之后但放置得太早的值，则无论丢失位置如何，配置都会无效。 

## 方法

 强力方法是生成剩余数字的所有排列，并通过从左到右扫描来测试每个候选，检查每个前缀元素是否是其前缀的最小值或最大值。 这在概念上是可行的，因为它直接强制执行定义，但它需要生成阶乘许多排列并在线性时间内检查每个排列，导致在最坏情况下大约为 O(n!·n) 次操作，即使对于 n = 20 也是不可行的。 

关键的观察是，前缀规则强制通过重复扩展允许剩余值的当前区间 [L，R] 来构造排列。 在每一步中，下一个选择的元素必须是 L 或 R。这会将排列变成左或右选择的序列，但仅相对于剩余未使用的数字。 

一旦我们接受了这种区间过程观点，排列就不再是任意的了。 它相当于选择插入顺序，其中每个新元素成为当前前缀的新最小值或新最大值。 这是经典的“通过扩展极值构建排列”结构，其中有效性仅取决于固定元素的相对位置以及有多少未使用的值被强制进入区间的每一侧。

对于部分信息，关键的困难在于某些值已经固定到位置。 这些固定值将排列划分为多个段。 在每个段中，我们有效地选择将多少元素放置在左延伸侧与右延伸侧，但段之间的一致性受到值的全局排序的限制。 

该解决方案简化为跟踪我们可以在尊重固定锚的同时将未知数字分配到这些扩展的极值槽中的有多少种有效方法。 这成为一个间隔内的组合计数问题，可以通过扫描和维护剩余未使用数字的可行范围在每次测试的线性时间内解决。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!·n) | O(n!·n) | O(n) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们根据未使用值的动态区间来解释排列构造。 最初，从 1 到 n 的所有数字都可用，形成范围 [1, n]。 每个放置的元素要么成为前缀的新最小值，要么成为前缀的新最大值，从而相应地缩小可用间隔。 

我们从左到右处理数组，根据我们已经放置的内容，维护仍然与剩余数字的有效分配一致的最小和最大值。 

1. 初始化两个指针 L = 1 和 R = n，分别表示排列中尚未分配的最小和最大数字。 
2. 从左到右扫描位置。 对于每个位置 i，检查是否存在固定值或位置未知。 
3. 如果该值是固定的，我们必须验证与当前间隔的一致性。 该值必须等于 L 或 R，因为在任何有效的构造中，下一个元素都被强制为当前极值之一。 如果是 L，我们消耗 L 并递增它。 如果是 R，我们消耗 R 并递减它。 如果两者都不匹配，则不存在有效的构造。 
4. 如果位置未知，我们可以自由选择区间的任一端点。 然而，选择的数量取决于 L 和 R 是否不同。 如果 L 等于 R，则只有一种选择。 否则，有两个选择，我们将答案乘以 2。考虑到选择后，间隔以与继续构建一致的方式缩小。 
5. 继续，直到处理完所有位置。 累加乘积模 10^9+7 就是有效完成的次数。 

正确性取决于以下事实：在每个前缀处，未使用的数字集形成一个连续的区间。 prefix-min-max 条件强制下一个元素成为此间隔的端点之一，因为任何内部值都会违反该前缀中的最小值或最大值属性。 固定值只是强制在特定步骤中选择哪个端点，而自由位置恰好对应于两个端点之间的二元决策。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        used = [False] * (n + 1)
        for x in a:
            if x != 0:
                used[x] = True

        L, R = 1, n
        ans = 1
        ok = True

        for x in a:
            if x == 0:
                if L == R:
                    ans = ans * 1 % MOD
                else:
                    ans = ans * 2 % MOD
                L += 1
                R -= 1
            else:
                if x == L:
                    L += 1
                elif x == R:
                    R -= 1
                else:
                    ok = False
                    break

        print(ans if ok else 0)

if __name__ == "__main__":
    solve()
```该实现直接模拟可用值的缩小区间。 数组`used`尽管实际的可行性检查是通过端点匹配进行的，但对于核心逻辑来说并不是严格要求的，但反映了预期的排列结构。 

变量`L`和`R`表示剩余未使用的值。 每次我们放置一个数字时，我们都会减少这个间隔。 如果位置是固定的，则它必须与端点之一对齐，否则结构会立即中断。 

对于自由位置，我们假设在左端点和右端点之间进行二元选择。 这就是 2 的乘法因子出现的地方。 L 等于 R 的边缘情况消除了这种分支并贡献了中性因子 1。

 ## 边缘情况

 当固定值不在当前端点时，即使它仍在全局范围内，也会发生微妙的失败情况。 例如，如果 L = 2 且 R = 5，并且我们遇到值 3，则该值在全局排列中有效，但在此前缀过程中无效。 该算法立即正确地拒绝它，因为 3 都不是端点。 

另一种情况是当间隔折叠为单个值时。 如果 L 等于 R，则不存在分支。 任何空闲头寸都必须消耗该单一剩余价值，并且答案不会进一步增加。 该算法自然地处理这个问题，因为当 L == R 时乘法因子为 1。 

最后，如果固定值出现较晚，但强制早期区间收缩与之前的自由选择不一致，则构造会立即失败。 这是因为每个固定值都必须与收缩区间的当前边界相匹配，任何偏差都会中断该过程，而无需回溯。
