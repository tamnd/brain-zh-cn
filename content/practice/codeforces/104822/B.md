 ## 解决方案
 ## 问题理解

 我们有一堆硬币和两个轮流玩的玩家。 在一个回合中，玩家开始时拥有一定数量的硬币，例如$x$。 他们有两种类型的动作。 他们可能总是取出一枚硬币，留下$x-1$。 或者，他们可以一次移除多个硬币，但前提是移除后剩余的硬币数量是当前堆大小的除数$x$。 取出最后一枚硬币的玩家获胜。 

任务是确定每个起始值$n$，第一个玩家是否在最优玩法下强制获胜。 

约束条件$n \le 10^9$排除任何模拟游戏或在所有状态上构建 DP 的方法$n$。 即使是检查每个状态的所有除数的解决方案，如果在许多测试用例中重复，也会太慢，因此最终的解决方案必须将每个查询减少到恒定时间分类或最坏的对数算术，例如检查二的幂或类似素数的结构。 

值非常小时会出现微妙的边缘情况。 什么时候$n = 1$，无法移动，因此第一个玩家立即失败。 什么时候$n = 2$，只需移动到$1$存在，这使得第一个玩家获胜。 对于稍大的值，例如$n = 3$或者$n = 4$，多种移动类型相互作用，并且跳到除数或减一的能力是否总是保证获胜的移动并不是立即显而易见的。 这正是本地分支选项隐藏简单全局模式的游戏。 

## 方法

 暴力策略将对待每个州$x$作为游戏图中的节点。 从$x$，我们枚举所有有效的下一个状态：$x-1$和所有$y < x$这样$y$划分$x$。 然后我们使用标准游戏 DP 来标记获胜和失败状态。 

从概念上讲，这是可行的，因为该图是非循环的，因为每次移动都会严格减少硬币的数量。 然而，成本却很大。 对于每个$x$，检查所有除数成本$O(\sqrt{x})$在最坏的情况下，我们可能需要处理所有状态$n$，大致导致$O(n\sqrt{n})$在最坏的解释中单个测试的行为，当$n$达到$10^9$。 

关键的观察结果是允许的移动结构极其不对称。 此举$x \to x-1$始终可用，并且除数跳转允许跳至结构化位置。 这通常会迫使失败的头寸变得非常稀疏。 在分析小值时，会出现一种模式：二的幂的位置与其他位置的行为不同，因为它们的除数也都是二的幂，并且它们的可达状态崩溃为一个总是有利于对手的严格约束的集合。 

这导致了简单化，即失败的位置恰好是 2 的幂，而所有其他数字都允许以强制获胜的方式移动到 2 的幂。

 | 蛮力 DP 超过状态 |$O(n\sqrt{n})$|$O(n)$| 太慢了 |

 ## 算法演练

 我们将每个查询减少为检查是否$n$是二的幂。 

1. 对于每个测试用例，读取整数$n$。 
2.如果$n = 1$，立即宣布第一个玩家失败，因为不存在任何移动。 
3.为了$n \ge 2$，检查是否$n$是二的幂。 这可以使用位技巧来完成$n \& (n-1) = 0$。 
4. 如果$n$是 2 的幂，第二个玩家获胜的输出。 否则，输出第一个玩家获胜。 

步骤 3 背后的原因是，二的幂在二进制表示中恰好有一个设置位，它表征以下形式的数字$2^k$。 

### 为什么它有效

 游戏总是移动到一个严格较小的数字，因此状态空间形成一个有向无环图。 关键的结构事实是，二的幂在除数条件下形成一个封闭族：二的幂的所有约数也是二的幂。 这限制了对手的反应，防止进入提供额外灵活性的“混合因素”状态。 

对于非二的幂，至少存在一个奇数因子或混合因子，并且玩家可以在一系列移动之后迫使游戏进入二的幂状态。 一旦发生这种情况，对手就会被限制在最终以失败的配置返回控制权的位置。 这种分离恰好创造了两类国家：在二的幂上失去地位，在其他地方赢得地位。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input().strip())
        if n & (n - 1) == 0:
            # power of two
            print("Second")
        else:
            print("First")

if __name__ == "__main__":
    solve()
```有意将实现最小化，因为所有复杂性都被推入数学分类中。 唯一重要的操作是按位检查 2 的幂。 这是可行的，因为 2 的幂恰好有一个设置位，因此减一会翻转所有较低位，并产生一个在任何位位置都不与原始值重叠的数字。 

一个常见的错误是忘记了$n = 1$在此表示中也是二的幂。 逻辑仍然可以正确处理它，因为$1$满足相同的条件并正确输出“Second”。

 ## 边缘情况

 对于$n = 1$，算法立即将其分类为 2 的幂并输出“Second”。 这与起始玩家没有合法动作并根据定义失败的事实相匹配。 

为了$n = 2$，位检查也将其识别为2的幂，结果为“Second”。 从游戏的角度来看，唯一的一步就是$1$，这是下一个玩家的最终失败状态。 

对于像这样的非电源$n = 12$，二进制表示包含多个设置位。 该算法输出“First”，反映出存在一系列动作，总是可以迫使对手进入受约束的位置，最终在最佳游戏下减少到二次方结构。
