 ## 解决方案
 ## 问题理解

 我们有一个大网格$n$行和$m$列，每个单元格必须包含 0 或 1。如果连续块中没有任何行或任何列包含三个相同的值，则网格被视为有效。 换句话说，你被禁止看到水平或垂直的图案$000$或者$111$矩阵中的任意位置。 

任务不是构建网格，而是确定可以放置的最大可能数量，同时保持网格在此约束下有效。 

约束条件非常大，两个维度都达到$10^9$直至$10^5$测试用例。 这立即排除了任何显式构造或模拟网格的方法。 甚至每个测试用例的线性时间$n$或者$m$是不可能的。 解决方案必须是从结构推理中得出的直接公式。 

天真的直觉是独立处理行并尝试最大化每行中的行，同时避免三个连续的行。 然而，当考虑列时，这很快就会变得不一致。 如果不小心跨行重复，在每行中有效的模式仍然可能会在列中中断。 

如果我们尝试贪婪地将每一行构建为类似的内容，则会出现常见的失败情况$110110...$。 虽然每行都有效，但堆叠相同的行会创建填充相同值的列，从而产生较长的垂直运行并立即违反规则。 这表明水平和垂直约束是紧密耦合的。 

另一个微妙的陷阱是假设像棋盘这样的交替图案是最佳的。 虽然有效，但它们只能达到密度$1/2$，并且不充分利用长度 2 游程的余量。 

## 方法

 我们从一维的角度开始。 在单行中，该约束禁止任何三个连续的相等位。 在此规则下最大化的最佳方法是重复该模式$110$。 这实现了每三个块中有两个 1，这是最佳的，因为任何将三个 1 放置在长度为 3 的窗口中的尝试都是被禁止的，并且用 1 替换 0 会立即带来创建禁止三元组的风险。 

同样的逻辑也适用于列。 然而，简单地在所有行中独立地重复最佳行是失败的，因为垂直一致性会创建长的恒定列。 

关键的观察结果是约束完全是局部的：只有长度为 3 的游程才重要。 这表明使用在两个方向上同时有效的周期结构。 尝试的自然周期是 3，因为禁止模式的长度也是 3。 

我们建造一个基地$3 \times 3$同时在每行和每列中实现最佳密度的块：

 第 0 行：110

 第 1 行：101

 第 2 行：011

 每行都是循环移位$110$。 水平扩展此模式可以保留行中的三不相等条件。 垂直方向上，每列变成循环移位$110$,$101$， 或者$011$，因此列也避免运行三个相同的值。 

这种结构在每 9 个单元中恰好实现了 6 个单元，这表明密度为$2/3$。 由于网格是由这种周期性结构平铺的，因此相同的密度扩展到任意$n \times m$网格，而不会在边界处引入无效的三元组。 

最后一步是认识到没有任何建筑可以超过这个密度。 在任何有效的排列中，行或列中三个连续单元格的每个块最多可以包含两个。 这一全球限制限制了可实现的密度$2/3$，并且周期结构与它完全匹配。

 ## 算法演练

 我们直接从最佳周期模式的结构中得出答案。 

1. 观察每个有效的行或列不能包含三个连续的相等值。 这立即意味着在任何长度为 3 的窗口中，如果我们试图最大化单元格，则最多有两个单元格可以为 1。 这给出了硬密度上限$2/3$。 
2. 认识到重复长度为 3 的模式足以满足一维的约束。 图案$110$对于单行是最佳的。 
3. 通过构建 3 周期网格将这个想法扩展到二维。 将三个行模板定义为循环移位$110$:$110$,$101$， 和$011$。 
4. 在这三个模板的重复循环中分配行。 这确保垂直切片也重复这些相同的安全模式，防止任何列形成禁止的三元组。 
5. 计算该结构中有多少个。 每一块$3 \times 3$恰好包含 6 个，因此密度是一致的$2/3$。 因此，对于任何$n \times m$，总数为$\left\lfloor \frac{2nm}{3} \right\rfloor$，在此结构中始终是精确的。 

### 为什么它有效

 正确性来自于任何行或列中长度为 3 的每个连续段都是多重集的旋转这一不变量$\{1,1,0\}$。 这保证了没有任何段可以成为$000$或者$111$。 由于两个维度都是由相同的循环结构构建的，因此该属性在全局范围内有效，而不仅仅是在行或列中局部有效。 

该结构还使各处每三个单元两个 1 的局部上限饱和，因此在不立即违反某个方向上的约束的情况下，无法插入额外的 1。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        print((2 * n * m) // 3)

if __name__ == "__main__":
    solve()
```实现直接应用导出公式。 由于任意精度整数，乘法在 Python 中是安全的，即使对于高达$10^9$。 整数除以 3 会产生在先前建立的结构界限下可实现的精确最大数量。 

关键的简化在于，整个几何和组合结构简化为一个不变量：每组三个对齐的单元最多可以贡献两个，并且这个界限是紧密的。

 ## 边缘情况

 对于一个$3 \times 3$网格，算法返回 6。该构造完全用重复图案填充网格$110 / 101 / 011$，并且每一行和每一列都避免出现三个相同的连续值。 任何放置第七个窗口的尝试都会迫使行或列中出现三元组，因为所有本地窗口都已经饱和。 

对于一个$1 \times m$或者$n \times 1$网格，公式仍然适用。 例如，在一个$1 \times 9$grid，结果是 6。这符合最佳的一维排列$110110110$，其中每三个块恰好包含两个。 即使网格是退化的，相同的局部约束也控制着结构，因此公式在不修改的情况下仍然有效。
