 ## 解决方案
 ## 问题理解

 我们得到了一个整数序列，并且在执行其他操作之前，我们可以多次翻转任何单个元素的符号。 选择最终符号后，我们查看每个子数组并计算其中出现的不同值的数量，然后将所有子数组的数量相加。 

关键的相互作用是改变符号不会改变幅度，但会改变相等关系。 两个相等的绝对值可以相等（符号相同）或不同（符号相反），而零是固定的，因为翻转不执行任何操作。 

目标是为每个元素分配一个符号，以便所有子数组中不同计数的总和变得尽可能大。 

约束条件$n \le 3 \cdot 10^5$排除任何显式检查所有子数组的解决方案。 一个天真的$O(n^2)$子数组的枚举已经太大了，甚至$O(n^2 \log n)$或者任何重复重新计算不同计数的事情都是不可能的。 任何可行的解决方案都必须将问题简化为值或位置贡献的线性或近线性聚合。 

一个微妙的问题是，“让价值观不同”并不纯粹是本地化的。 例如，翻转某个值的一次出现会影响包含该位置的所有子数组，并且它还会与相同绝对值的其他出现交互。 每个元素的贪婪决策而不考虑全局结构很容易错误计算贡献。 

另一种边缘情况是所有值都为零时。 由于零不能分成两个不同的有符号值，因此每个子数组始终只有一个不同的元素。 任何错误地将零视为可拆分值的解决方案都会导致计数过多。 

## 方法

 直接方法将枚举所有子数组，计算每个子数组的不同元素，并尝试所有符号分配。 即使忽略符号选择，维护每个子数组的不同计数也会导致粗略的结果$O(n^2)$州。 添加符号优化使其呈指数增长，因为每个元素都有两种状态。 

关键的结构简化来自于目标的重写。 我们不是首先对子数组求和，而是反转视角并对值求和。 如果每个值在子数组中至少出现一次，则该值将构成子数组。 因此，固定最终值的总贡献$x$是与至少一次出现的相交的子数组的数量$x$。 总答案成为所有不同有符号值的此类覆盖贡献的总和。 

现在标志翻转的作用变得更加清晰。 每个绝对值$v$产生多组位置。 分配符号后，这些位置被分为两个独立的组：$+v$和$-v$，其行为就像两个不同的值。 每个组独立地对不同计数的总和做出贡献。 

因此，对于每个绝对值，我们不是选择它是否存在，而是选择如何将其出现划分为两个标记集。 每个集合都会对子阵列产生覆盖率贡献，我们希望选择能够最大化这些覆盖率总和的分区。 

对于一组固定的位置，其贡献仅取决于连续出现之间的间隙。 如果出现在以下位置$p_1 < p_2 < \dots < p_k$，那么避免所有出现的子数组就是那些完全包含在间隙中的子数组。 这导致成本与间隙长度成二次关系，因此聚类发生紧密地增加了贡献。 

因此，问题简化为将每个出现列表划分为两个子序列，以便两个子序列具有最小的内部扩展。 通过在两组之间按排序顺序交替出现来实现最佳结构，从而平衡它们的间隙分布。 

这减少了计算每个值的两个归纳序列的贡献的问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对子数组和符号分配的暴力破解 | 指数| O(n) | 太慢了 |
 | 通过优化分区进行按值拆分 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 按绝对值对指数进行分组。 每组包含出现给定幅度的所有位置。 
2. 按升序对每组位置进行排序。 这修复了推理间隙所需的结构。 
3. 通过按排序顺序交替位置将每个组拆分为两个子序列，将第一个子序列发送到 A 组，将第二个子序列发送到 B 组，依此类推。 这确保两个子序列尽可能均匀地分布。 
4. 对于每个子序列，计算其对答案的贡献，即包含其中至少一个元素的子数组的数量。 这是使用间隙分解来完成的：如果我们知道连续出现之间的间隙的大小，我们从子数组总数中减去完全包含在间隙中的子数组的数量。 
5. 添加每个值的两个子序列的贡献，并且还单独包含零，因为它们不能拆分并且表现为固定值。 

之所以如此有效，是因为将每个带符号的值视为一种“颜色”。 如果子数组与其至少一个位置相交，则每种颜色都会对子数组产生影响。 将出现的事件拆分为两种颜色是有益的，因为它可以减少聚类，从而减少完全丢失该颜色的子数组的数量。 交替分配可最大限度地减少两种颜色之间最大和总的内部间隙，从而最大限度地提高覆盖范围。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    pos = {}
    zeros = 0
    
    for i, x in enumerate(a):
        if x == 0:
            zeros += 1
            continue
        v = abs(x)
        pos.setdefault(v, []).append(i)
    
    total_subarrays = n * (n + 1) // 2
    ans = 0
    
    def contribution(positions):
        if not positions:
            return 0
        k = len(positions)
        
        # compute complement: subarrays that avoid all positions
        bad = 0
        
        # left boundary
        bad += positions[0] * (positions[0] + 1) // 2
        
        # middle gaps
        for i in range(1, k):
            gap = positions[i] - positions[i - 1] - 1
            bad += gap * (gap + 1) // 2
        
        # right boundary
        bad += (n - positions[-1] - 1) * (n - positions[-1]) // 2
        
        return total_subarrays - bad
    
    for v, ps in pos.items():
        ps.sort()
        
        group1 = []
        group2 = []
        
        for i, p in enumerate(ps):
            if i % 2 == 0:
                group1.append(p)
            else:
                group2.append(p)
        
        ans += contribution(group1)
        ans += contribution(group2)
    
    # zeros contribute 1 per subarray since they are identical and unavoidable
    ans += zeros * (n * (n + 1) // 2)
    
    print(ans)

if __name__ == "__main__":
    solve()
```代码首先按绝对值聚合位置，因为只有大小决定翻转是否可以创建或破坏相等性。 每组被分成两个交替的子序列以模拟最佳符号分配。 

这`contribution`函数实现了标准补码技巧：它不是对至少包含一次出现的子数组进行计数，而是对所有子数组进行计数并减去那些完全避开位置的子数组。 那些“坏”子数组正是完全位于出现次数之间的间隙中或极端之外的子数组，并且每个这样的间隔都贡献一个三角形数。 

零是单独处理的，因为它们表现为无法拆分的固定值，并且包含任何零的每个子数组仍将其视为一个不同的元素。 

## 工作示例

 ### 示例 1

 输入：```
4
1 1 0 -1
```我们将绝对值 1 分组在位置 [0, 1, 3] 处，将 0 分组在位置 [2] 处。 

我们将 [0, 1, 3] 分为两组：

 A 组：[0, 3]

 B组：[1]

 | 步骤| A 组位置 | B 组职位 | 贡献A | 贡献 B |
 | ---| ---| ---| ---| ---|
 | 1 | [0, 3] | []| 通过间隙计算 | 0 |
 | 2 | []| [1] | 0 | 通过间隙计算 |

 A组为间隙结构，中间区域较大，而B组为单组。 它们的综合贡献说明了这两个事件分别对许多子阵列做出了贡献，从而最大化了覆盖范围。 在位置 2 添加零会使包含它的每个子数组增加一个不同的元素。 

该跟踪显示了拆分如何防止两次出现 1 表现为单个聚类值，这会减少许多子数组中的不同覆盖范围。 

### 示例 2

 输入：```

```这里没有非零值。 每个子数组完全由零组成，因此每个子数组只有一个不同的值。 

| 子数组 | 不同计数 |
 | ---| ---|
 | [0]| 1 |
 | [0,0]| 1 |

 对所有 6 个子数组求和得到 6，确认零不会从任何变换中受益并充当恒定基线。

 ## 边缘情况

 关键的边缘情况是所有元素都为零时。 该算法正确地分别处理零，并为每个子数组分配恰好一个不同元素的贡献，这符合任何符号变化都不能改变相等性的事实。 

另一种情况是非零相等绝对值的完全均匀数组。 分割步骤确保事件被分为两组，防止它们崩溃成单个高度聚集的值。 这可以避免子数组覆盖范围的计数不足，特别是对于长数组，否则聚类会显着减少不同的计数。 

最后一个微妙的情况是事件稀疏且不规则。 交替分割仍然有效，因为它避免在单个组内构建大型连续块，保持间隙贡献平衡并防止任何单个组主导子阵列排除。
