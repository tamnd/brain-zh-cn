 ## 解决方案
 ## 问题理解

 该任务描述了一个由 1 到$n$。 你从位置开始$s$，以及以上$m$老板发射攻击的离散时刻禁止站在特定区域内$[l_i, r_i]$。 如果您在攻击时位于该段内，则运行立即结束。 

每次攻击之前，您可以重新调整自己的位置。 你可以免费留在原地，也可以进行一次传送，让你精确移动$k$向左或向右平铺，付费$k$活力。 能量预算绝不能低于零，因此目标是最大限度地减少总能量消耗，同时确保在每个时间步骤都位于该步骤的禁止部分之外。 

重要的结构是你不选择最终目的地; 每次攻击前都必须选择一个有效的位置，每个位置都取决于移动限制和避开当前禁止区间的需要。 

这些限制推动$O(m)$或者$O(m \log n)$每个测试用例的解决方案，总计$m$跨测试范围为$2 \cdot 10^5$。 任何尝试每一步重新计算所有图块的可达性的解决方案都会立即变得太慢。 

一个微妙但关键的建模点是运动仅限于固定大小的跳跃$k$，意味着位置分成独立的算术级数模$k$。 这可以防止在单个步骤中任意重新定位并强制形成结构化转换图。 

一些边缘情况很重要：

 如果禁止区间不影响你当前的位置，那么什么都不做总是有效的。 例如，如果$n = 10$,$s = 5$， 和$[l_1, r_1] = [7, 9]$，那么停留在 5 是非常安全的。 

如果你当前的位置位于禁区之内，你必须在攻击前离开它。 例如，如果您处于 6 级，并且禁止路段是$[4, 8]$，您被迫向 4 的左侧或 8 的右侧移动，但移动限制可能会阻止您一步到达两侧。 

如果运动步数相对于禁止段结构太大，则天真的“总是立即跳开”策略可能会失败，因为它忽略了未来的约束，并且可能不必要地浪费能量。 

## 方法

 蛮力视角将此视为时间扩展图上的最短路径问题。 每个状态都是由时间和位置组成的对，并且转换对应于停留或应用固定长度的传送。 每个时间层禁止里面的所有节点$[l_i, r_i]$。 在该图上运行最短路径是正确的，但图的大小是$O(nm)$，这使得它完全不可行。 

关键的结构观察是，运动不是任意越线，而是以固定的步骤发生。 这将竞技场分成独立的链，其中每个链的行为类似于折线图。 在每条链上，移动基本上是每秒向左或向右一步，问题就变成了保持有效位置，避免随着时间的推移出现禁止的间隔，同时最大限度地减少移动次数。 

优化的见解是，移动的唯一原因是当前位置变得无效。 当发生这种情况时，最好的行动是移动到禁止段之外最近的有效位置，因为任何进一步的移动都会严格增加成本，而不会提高当前步骤的可行性。 这种贪婪修正是足够的，因为成本仅取决于总位移，而不取决于未来状态相互作用，这种相互作用将从“超调”中受益。 

这将问题简化为跟踪单个位置并仅在其落入禁止区间时才修复它。

 | --- | --- | --- | --- |
 | 蛮力（时间扩展最短路径）|$O(nm)$|$O(nm)$| 太慢了 |
 | 贪心位置修复 |$O(m)$|$O(1)$| 已接受 |

 ## 算法演练

 该算法维护一个代表您当前位置的变量，并在需要移动时累积能量成本。 

1. 将您的仓位初始化为$x = s$总能量为0。 
2. 每一秒$i$,读取禁止段$[l_i, r_i]$。 
3. 如果您目前的职位$x$位于区间之外$[l_i, r_i]$，什么也不做，继续下一秒。 因为不需要运动，所以不消耗能量。 
4. 如果$x$位于里面$[l_i, r_i]$，您必须移动到安全位置。 只有两个候选人：$l_i - 1$和$r_i + 1$，假设它们在范围内。 
5. 选择这两个边界位置中较接近的一个$|x - (l_i - 1)|$和$|x - (r_i + 1)|$。 移动到那里并将行驶的距离添加到能量成本中。 
6. 更新$x$到这个新位置并继续。 

这个局部修复步骤正确的原因是，一旦进入禁止区间，每个有效位置都位于该区间之外，并且成本与距离纯粹是线性的。 任何最优解都必须退出该区间，并且最近的退出可以在不影响当时可行性的情况下最小化成本。 

### 为什么它有效

 在每一步中，算法都会确保所选位置对于当前攻击有效。 当需要修复时，它会选择禁止区间之外最接近的可行点。 任何距离较远的替代移动都会严格增加成本，而在当前时间步上没有任何好处，并且延迟退出是不可能的，因为在间隔内会立即致命。 这使得贪婪修正局部最优，并且由于决策仅取决于当前违规，因此它在序列上保持全局最优。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, s = map(int, input().split())
        x = s
        energy = 0

        for _ in range(m):
            l, r = map(int, input().split())

            if l <= x <= r:
                left = l - 1
                right = r + 1

                best = None
                best_cost = 10**18

                if left >= 1:
                    best = left
                    best_cost = abs(x - left)

                if right <= n:
                    cost = abs(x - right)
                    if cost < best_cost:
                        best = right
                        best_cost = cost

                energy += best_cost
                x = best

        print(energy)

if __name__ == "__main__":
    solve()
```该解决方案仅保留当前位置并贪婪地更新它。 唯一的微妙之处是当禁止间隔触及竞技场边缘时正确处理边界。 在这些情况下，仅存在一个有效的逃逸方向，因此算法自然会选择它。 

成本更新是使用绝对距离完成的，如果移动被解释为沿线的单位步转换，则该绝对距离与所需的传送操作数量相匹配。

 ## 边缘情况

 当起始位置已经在所有禁止段之外时，算法根本不执行任何移动。 例如，从 1 开始，所有间隔都远离右侧会导致能量为零，因为不会触发任何修复。 

当禁止区间覆盖除一侧以外的所有区域时，例如$[2, n]$，唯一有效的转义是移动到位置 1。该算法处理此问题是因为仅存在一个边界候选，并且它是自动选择的。 

当当前位置恰好位于禁止区间的边界时，它仍然被认为是不安全的，因为该区间是包含在内的。 在这种情况下，算法会正确触发一步棋，并通过显式检查来避免相差一的错误$l \le x \le r$。
