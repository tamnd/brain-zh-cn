 ## 解决方案
 ## 问题理解

 我们得到了多个独立的查询。 每个查询给出两个整数，我们必须构造固定长度的数组，其条目严格为正且其总和是固定的。 在所有此类数组中，我们只保留那些可以表示具有恰好那么多边的非简并多边形的边长的数组，其中边的顺序很重要。 

因此，对于每个测试用例，我们都在有效地计算整数的有序组合$m$进入$n$正部分，带有附加的几何约束：序列必须能够形成封闭的$n$边多边形。 

几何条件是关键的重要部分。 当且仅当没有单边至少与所有剩余边的总和一样大时，正长度序列才能形成多边形。 这是标准的广义三角不等式。 如果一侧太大，则无法被其他一侧“封闭”。 

以代数形式重写条件，如果总和为$m$，那么每个有效数组必须满足$$\max(a_i) < m - \max(a_i)$$这相当于$$\max(a_i) < \frac{m}{2}$$所以问题就变成了计算长度的正整数数组$n$, 总和$m$，所有条目严格小于$m/2$。 

约束允许最多$10^5$测试用例和值高达$10^6$，因此任何每次测试的组合枚举都是不可能的。 解决方案必须在恒定或对数时间内预先计算或回答每个查询。 

出现微妙的边缘情况时$m$相对于较小$n$。 例如，$n = 3, m = 3$仅有一个有效数组，但是$n = 3, m = 4$有效数组为零，因为即使存在组合，也无法形成三角形，因为一侧相对于其他侧必然太大。 另一种情况是当$m < 2n$，其中多边形约束变得极其严格并且通常消除所有解决方案。 

## 方法

 我们从最直接的解释开始：枚举所有长度的数组$n$正整数总和为$m$，然后检查每个是否满足多边形条件。 这相当于生成$m$进入$n$零件，即$\binom{m-1}{n-1}$的可能性。 为了$m$最多$10^6$，这个数字是一个天文数字，因此无法立即枚举。 

相反，我们使用标准组合变换。 让我们通过定义来转移变量$b_i = a_i - 1$。 然后每个$b_i \ge 0$和$$\sum b_i = m - n$$所以在没有限制的情况下，数组的数量是$$\binom{m-1}{n-1}$$现在我们合并多边形约束。 条件是任何元素都不能至少是总和的一半。 我们通过减去违反此条件的解决方案来计算有效解决方案。 

将最大元素固定为$x$。 如果一个元素是$x$，剩余金额为$m - x$，对于违规，我们要求$x \ge m - x$， IE。$x \ge \lceil m/2 \rceil$。 

因此，我们计算可区分元素太大的配置。 对于固定位置，剩余$n-1$元素总和为$m-x$，给予：$$\binom{m-x-1}{n-2}$$总结所有无效的$x$, 乘以$n$位置的选择，给出了全部无效的配置。 

于是答案就变成了：$$\binom{m-1}{n-1} - n \cdot \sum_{x=\lceil m/2 \rceil}^{m-1} \binom{m-x-1}{n-2}$$我们通过替换使用标准组合恒等式来简化求和$y = m-x$，将其转换为二项式系数的前缀和，其分解为两个组合的封闭形式差：$$\sum_{y=1}^{\lfloor (m-1)/2 \rfloor} \binom{y-1}{n-2}
= \binom{\lfloor (m-1)/2 \rfloor}{n-1}$$这产生了最终的闭合公式：$$\binom{m-1}{n-1} - n \cdot \binom{\lfloor (m-1)/2 \rfloor}{n-1}$$剩下的任务是计算二项式系数模$10^9+7$使用阶乘预计算和模逆来有效地进行许多查询。

 ## 算法演练

 ### 1. 预先计算阶乘和逆阶乘直至最大值$m$我们需要快速计算二项式系数。 我们构建阶乘数组和模逆数组$10^6$。 这确保了任何$\binom{n}{k}$可以在常数时间内得到解答。 

### 2. 对于每个测试用例，计算组合的总数

 我们将数组解释为正整数组合，因此基线计数为：$$\binom{m-1}{n-1}$$这对所有序列进行计数，没有几何限制。 

### 3. 计算禁止范围中点

 有效的多边形要求所有边严格小于周长的一半。 所以阈值是：$$t = \left\lfloor \frac{m-1}{2} \right\rfloor$$这确保我们捕获边太大的所有情况。 

### 4.减去无效配置

 无效的情况对应于选择“太大”的一方，然后将剩余的金额分配给其他一方。 根据对称性，这可以简化为：$$n \cdot \binom{t}{n-1}$$此减法将删除至少一侧违反多边形条件的所有数组。 

### 5. 输出结果取模$10^9+7$### 为什么它有效

 每个无效配置都恰好有一个违反多边形不等式的主边，因为如果两条边都至少是周长的一半，则总和将超过总和。 这确保了减法步骤中不会出现过度计数。 通过将每个无效数组映射到大元素的唯一选择并独立分配余数，我们获得了无效数组与减法公式中计数项之间的双射。 这样就保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXN = 10**6 + 5

fact = [1] * MAXN
invfact = [1] * MAXN

for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN - 1] = pow(fact[MAXN - 1], MOD - 2, MOD)
for i in range(MAXN - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def ncr(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    if n > m:
        print(0)
        continue

    total = ncr(m - 1, n - 1)
    half = (m - 1) // 2
    bad = (n * ncr(half, n - 1)) % MOD

    ans = (total - bad) % MOD
    print(ans)
```阶乘预计算确保所有二项式查询的时间恒定。 关键的实现细节是使用$(m-1)//2$，它正确地编码了多边形闭合的严格不等式要求。 

减法步骤必须以模进行$10^9+7$，所以我们最后对结果进行归一化以避免负输出。

 ## 边缘情况

 对于$m = n$，每个元素都必须为 1，因此唯一可能的数组是全 1。 多边形条件不成立，因为任何边都不能超过周长的一半。 该公式正确减少，因为$\binom{n-1}{n-1} = 1$无效期限因余额不足而消失。 

什么时候$m < 2n$，阈值$\lfloor (m-1)/2 \rfloor$变得小于$n-1$，使第二个二项式系数为零。 这符合直觉，即没有任何配置可以在不违反多边形不等式的情况下容纳足够大的分布，因此所有计数仅来自基本合成公式。 

什么时候$n = 3$，问题简化为计算具有固定周长的三角形，并且该公式与经典三角形计数结果一致，其中最大边严格小于周长的一半。
