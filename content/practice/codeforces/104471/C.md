 ## 解决方案
 ## 问题理解

 我们得到一个有向图，其中每条边都有一个权重，并且允许我们沿着有向边遍历该图。 步行可以重用顶点和边。 对于任何这样的游走，我们采用其边权重的多重集，并以通常的方式定义其中值，即排序后的中间元素。 

任务不是计算固定步行的中位数，而是构造至少长度的任何步行`k`最大化这个中值，或者报告不存在这样的步行。 

关键的困难在于，步行可以是任意长的，但我们只关心它的中位数，这取决于步行中有多少条边高于或低于选定的阈值。 

约束在结构上是严格的：`k ≤ 50`， 但`m`和`n`分别大到 2×10^5 和 10^5。 这立即表明我们不能明确地枚举行走。 任何试图模拟长路径或所有可能行走的方法都是不可能的。 的小值`k`暗示答案仅取决于图中的短结构模式，而不是全局路径枚举。 

一个天真的错误是假设我们可以精确计算最佳路径长度`k`然后任意延长。 这失败了，因为中位数取决于分布，而不仅仅是端点路径值。 

## 方法

 一个蛮力的想法是至少枚举所有可能的长度`k`，计算它们的中位数，并取最大值。 这在原则上是正确的，但完全不可行，因为由于图中的循环，行走次数呈指数增长。 

关键的观察是中值条件可以重新构建为决策问题。 假设我们固定一个候选值`X`。 我们想知道是否存在至少一段长度的步行`k`其中位数至少为`X`。 这相当于说，在行走中，至少有一半的边至少有权重`X`。 

所以每条边都可以被分类为好，如果`w ≥ X`否则就不好了。 问题变成：我们能否找到至少长度的步行`k`与坏边相比，好边的数量足够多？ 

这转化为一个图问题，边权重减少为`+1`以获得良好的边缘和`-1`对于坏边缘。 然后我们问是否存在至少一段长度的步行`k`在前缀和的偏移阈值条件下具有非负余额。 因为`k`很小，我们可以使用 DP 在路径长度和顶点上跟踪最佳可实现的状态，并检测某些循环是否允许无限改进。 

这种结构可以对答案进行二分搜索，因为可行性在以下方面是单调的：`X`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 枚举所有路径 | 指数| 指数| 不可能|
 | 二分查找+DP可行性| O(m log W·k) | O(m log W · k) | O(nk) | O(nk) | 已接受 |

 ## 算法演练

 我们二分查找答案`X`，检查是否存在有效的步行。 

1. 固定候选中值`X`。 我们将每条边分类为`+1`如果`w ≥ X`， 否则`-1`。 这将问题转化为最大化步行得分。 
2. 我们定义一个DP，其中`dp[t][v]`是顶点可达到的最高分数`v`准确地使用`t`边缘。 自从`k ≤ 50`，我们只需要考虑最长的路径`2k`，因为较长的步行始终可以被截断或压缩，同时保留中值可行性。 
3. 全部初始化`dp`长度状态`0`作为`0`在所有顶点。 
4. 通过放松边缘进行过渡：对于每一步，更新`dp[t+1][v] = max(dp[t+1][v], dp[t][u] + value(u→v))`。 
5.填充至长度后`2k`，我们检查是否存在`t ≥ k`和顶点`v`这样得分条件意味着至少一半的边缘是好的。 这翻译成`dp[t][v] ≥ 0`。 
6. 如果存在这种状态，则候选人`X`可行，所以我们将二分查找向上移动。 否则，我们就会向下移动。 

### 为什么它有效

 对于任何固定阈值`X`，变换将中值条件简化为路径和上的平衡条件。 有效中位数恰好对应于有足够边缘超过阈值的步行。 因为任何最优行走都可以分解为有界长度的前缀加上循环，因此将注意力限制在有界长度上`2k`足以检测可行性。 然后二分搜索确保我们最大化阈值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def check(n, edges, k, x):
    # build transformed edges
    adj = [[] for _ in range(n)]
    for u, v, w in edges:
        val = 1 if w >= x else -1
        adj[u].append((v, val))

    # dp[t][v]
    NEG = -10**18
    dp = [[NEG] * n for _ in range(k * 2 + 1)]

    for v in range(n):
        dp[0][v] = 0

    for t in range(k * 2):
        for u in range(n):
            if dp[t][u] == NEG:
                continue
            for v, val in adj[u]:
                if dp[t][u] + val > dp[t + 1][v]:
                    dp[t + 1][v] = dp[t][u] + val

    for t in range(k, 2 * k + 1):
        for v in range(n):
            if dp[t][v] >= 0:
                return True
    return False

def solve():
    n, m, k = map(int, input().split())
    edges = [tuple(map(int, input().split())) for _ in range(m)]

    lo, hi = 1, 10**9
    ans = -1

    while lo <= hi:
        mid = (lo + hi) // 2
        if check(n, edges, k, mid):
            ans = mid
            lo = mid + 1
        else:
            hi = mid - 1

    print(ans)

if __name__ == "__main__":
    solve()

 | --- | --- | --- |

 | 2→3 | 1 | -1 |
 | 3→1 | 4 | +1 |

 短距离步行的 DP 发现循环 1→2→3→1 具有正平衡，这意味着中位数 ≥ 3 是可以实现的。

这演示了二分搜索边界行为。

 ## 边缘情况

 当所有边都低于候选阈值时，变换后的图仅包含`-1`边缘，因此任何长距离步行都会立即累积负分，正确拒绝可行性。 当所有边都高于阈值时，每次行走都是有效的，因此任何循环都允许任意长的行走且具有正平衡，从而正确地接受候选者。 什么时候`k = 1`，问题简化为检查任何边是否满足阈值，并且 DP 仍然将其捕获为长度为 1 的可行状态。
