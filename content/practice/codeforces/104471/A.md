 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 在每个测试用例中，我们都有一组对。 每对都包含一个正权重$a_i$和一个标志$b_i$那就是$+1$或者$-1$。 

我们可以选择索引的任何子集，从一个元素到所有元素的任何大小。 如果我们选择一个子集$S$，它的分数是通过将所有的总和计算出来的$a_i$并将其乘以所有子集的总和$b_i$在子集中。 任务是选择一个子集来最大化该产品。 

关键的困难是子集大小不固定。 每个元素都会对这两个总和做出贡献，因此添加一个元素会同时改变这两个因素。 一个元素与$b_i = -1$减少第二个总和，但仍然增加第一个总和，这会产生不可分离的权衡。 

约束很大：所有测试用例的元素总数最多可达$2 \cdot 10^5$，并且最多可以有$10^5$测试用例。 这立即排除了任何尝试所有子集甚至二次每个测试用例方法的解决方案。 任何有效的解决方案都必须接近每个测试用例的线性或总体线性。 

一些边缘情况值得注意。 

如果我们只选择一个元素$i$，得分变为$a_i \cdot b_i$，这是$a_i$或者$-a_i$。 这意味着单个大的正元素$b_i = 1$在某些情况下已经是最佳的。 

如果全部$b_i = -1$，然后选择更多元素会使第二个总和更负，因此最佳答案通常来自绝对负效应最小的单个元素，但我们仍然需要考虑与大元素的相互作用$a_i$。 

如果全部$b_i = 1$，那么问题就变成了最大化$(\sum a_i)^2$，所以答案就是拿走一切。 

当两个符号都存在时，主要的挑战就出现了，因为添加负元素会增加第一个和，但会减少第二个和，并且乘积表现出非线性。 

## 方法

 暴力方法将枚举所有子集。 对于每个子集，我们计算总和$a_i$和总和$b_i$，然后将它们相乘。 有$2^n$子集，以及每个评估成本$O(n)$如果天真地做或$O(1)$带有前缀簿记，但即使是最好的版本也是指数级的$n$。 和$n$最多$2 \cdot 10^5$，这是不可能的。 

一个稍微不那么天真的想法是对元素进行排序并尝试贪婪的选择策略，但是总和之间的相互作用阻止任何简单的排序参数明显正确。 困难在于，一个元素并不是独立的好或坏，它的价值取决于已经选择的元素。 

关键的观察是重写表达式。 对于选定的子集$S$,$$\left(\sum a_i\right)\left(\sum b_i\right)$$展开为一种形式，其中每个元素在一个部分中线性贡献并且成对相互作用隐式出现。 我们不是直接推理子集，而是尝试理解当我们增量构建集合时值如何变化。 

假设我们维护一个当前子集的总和$A = \sum a_i$和$B = \sum b_i$。 如果我们添加一个新元素$x$，新值变为：$$(A + a_x)(B + b_x) = AB + A b_x + B a_x + a_x b_x$$所以增益为：$$\Delta = A b_x + B a_x + a_x b_x$$这表明决策仅取决于当前的聚合值，而不是完整的子集结构。 这表明，如果我们按照仔细选择的顺序处理元素，我们也许能够有效地维持最佳状态。 

现在我们用符号分隔元素。 如果我们考虑添加一个$+1$元素增加$B$，同时添加一个$-1$元素减少$B$。 由于最终值在很大程度上取决于$B$，我们想要了解如何最大化两个和的乘积，其中一个和只是一个带符号的计数。 

一个关键的简化是观察对于任何固定的子集大小$k$，最好的子集是取$k$的最大值$a_i$在具有选定符号模式的所有元素中。 问题归结为决定有多少$+1$以及有多少$-1$采取的元素。 

让$P$成为以下名单$a_i$和$b_i = 1$， 和$N$成为以下名单$a_i$和$b_i = -1$。 假设我们选择$x$元素来自$P$和$y$元素来自$N$。 然后：$$A = \sum P_x + \sum N_y,\quad B = x - y$$对于固定$x, y$，最好的选择显然是取最大的$x$积极和最大的$y$负面的。 

我们现在需要最大化所有$x, y$。 由于前缀和完全确定最大元素的和，因此我们可以预先计算排序数组和前缀和并有效地评估所有组合。 

这将问题减少到尝试所有有意义的对$(x, y)$，这可以在前缀长度的线性时间内完成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力子集 |$O(2^n)$|$O(1)$| 太慢了|
 | 排序+前缀枚举 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们根据符号将输入分成两个数组：一个包含所有$a_i$在哪里$b_i = 1$，另一个地方$b_i = -1$。 我们按降序对两个数组进行排序，以便我们始终可以考虑最佳的可能前缀。 

我们预先计算两个数组的前缀和，以便我们可以快速计算任何前 k 个选择的总和。 

然后我们迭代我们采取了多少积极元素。 对于每一个这样的选择，我们也会考虑我们采取了多少负面因素。 使用前缀和，我们计算结果$A$和$B$，并评估分数。 

我们记录所有有效组合的最高分。 

## 为什么它有效

 对于任何固定计数$x$和$y$，用相同符号的更大可用元素替换任何选定元素不能减少总和$A$，同时保持$B$不变。 这意味着固定基数的最佳子集始终对应于排序后的前缀。 由于每个可行子集都对应于某个对$(x, y)$，并且我们穷尽了所有这样的对，最优解必须出现在这个枚举中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        pos = []
        neg = []

        for i in range(n):
            if b[i] == 1:
                pos.append(a[i])
            else:
                neg.append(a[i])

        pos.sort(reverse=True)
        neg.sort(reverse=True)

        ps = [0]
        ns = [0]

        for x in pos:
            ps.append(ps[-1] + x)
        for x in neg:
            ns.append(ns[-1] + x)

        best = -10**30

        for x in range(len(pos) + 1):
            A_pos = ps[x]
            for y in range(len(neg) + 1):
                A = A_pos + ns[y]
                B = x - y
                best = max(best, A * B)

        out.append(str(best))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案首先按符号对值进行分区，以便结构$B$变成简单的所选计数的差异。 对每个组进行排序可确保固定大小内的任何最佳选择都必须采用最大值，因为交换可以改善$A$不影响$B$。 

前缀和允许子集和的恒定时间计算。 嵌套循环探索选择了多少个正元素和负元素的所有组合，这已经足够了，因为最佳子集总是对应于某个这样的对。 

一个微妙的点是我们为每个组都包含了空选择。 这允许仅选择正数或仅选择负数，这是必要的，因为最佳子集可能完全忽略一侧。

 ## 边缘情况

 一种边缘情况是当所有$b_i = 1$。 在这种情况下，算法会考虑所有$x$和$y = 0$，所以它有效地计算$x \cdot (\sum \text{top } x)$。 最大值出现在$x = n$，它匹配所有元素。 

另一个边缘情况是当所有$b_i = -1$。 该算法枚举了所有$y$和$x = 0$，所以它计算$(-y) \cdot (\sum \text{top } y)$。 由于总和变为负值并且计数也为负值，因此根据结构，乘积可以变为正值或负值较小，并且枚举仍然捕获最佳的单元素或多元素选择。 

最后一个微妙的情况是将一个大的积极因素与许多小的消极因素混合在一起。 对两个计数的枚举可确保显式地探索交互，因此单个大的配置$a_i$翻转产品标志仍然可以通过$(x,y)$网格。
