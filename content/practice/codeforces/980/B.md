 ## 解决方案
 ## 问题理解

 我们有一个形状像一个非常小的网格的城市：它正好有 4 行和奇数列。 两对位置很重要：第一个旅程从左上角开始并想要到达右下角，而第二个旅程从左下角开始并想要到达右上角。 只允许在四个方向上移动，并且只能通过畅通无阻的单元格。 

我们被要求准确放置$k$网格单元上的酒店，但有一个限制，即网格的外边界上不能放置任何酒店。 边框由第一行和最后一行以及第一列和最后一列组成。 放置这些阻挡单元后，我们考虑两对角之间的最短路径。 目标是确保第一次旅程中的最短路径数量等于第二次旅程中的最短路径数量。 

输入尺寸非常小，$n \le 99$，因此任何网格大小呈线性的构造就足够了。 约束条件$k \le 2(n-2)$不是任意的：它与中间两行的内部单元格数量完全匹配。 

当人们试图贪婪地阻止单元格而不保持对称性时，就会出现一种微妙的失败情况。 例如，放置单个阻塞单元会立即破坏所有对称性。 在 4 x 5 网格上：```
.....
..#..
.....
.....
```第一和第二路径系统不再等效，因为障碍物仅影响一个行进方向。 任何此类不对称放置通常会改变一个路径计数，但不会改变另一个路径计数，这违反了要求。 

另一个边缘情况是当$k$很大。 如果布局结构不仔细，很容易意外地阻塞一个方向上的所有路径，同时保持另一个方向仍然连接。 

## 方法

 蛮力的想法是尝试所有放置的方法$k$并使用动态编程或基于 BFS 的计数计算两对的最短路径数量。 内部细胞的数量为$2(n-2)$，所以配置数量为$\binom{2(n-2)}{k}$。 即使是为了$n = 99$，这变得非常大，并且每个配置都需要重新计算路径计数，这太慢了。 

关键的观察是我们实际上根本不需要计算路径计数。 我们只需要确保两条路径计数保持相等。 网格的结构表明了一种自然的对称性：如果我们垂直反射网格（交换行$i$带行$5-i$），两个旅程的起点和终点也交换了。 这意味着在此反射下对称的任何配置都会强制两个路径计数相同，因为一个方向上的每个有效路径都对应于另一个方向上的镜像路径。 

为了保持这种对称性，每个被阻挡的单元必须与其垂直镜像的对应单元配对。 在 4 行网格中，第 2 行镜像第 3 行，而第 1 行和第 4 行是边界，不能包含块。 因此，每个有效的放置都包括选择列并同时放置块$(2, c)$和$(3, c)$。 

这立即将问题减少到选择$k/2$列出$n-2$可用的内部柱。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(\binom{2(n-2)}{k} \cdot n)$|$O(n^2)$| 太慢了|
 | 对称结构 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1.首先检查是否$k$是均匀的。 如果不是，则不可能进行对称放置，因为每个有效的放置都必须镜像到中间行，这意味着单元格成对出现。 如果$k$为奇数，立即输出NO。 
2. 构建一个最初为空的网格，其中填充有点。 
3. 仅关注中间两行，即第 2 行和第 3 行，因为边界是禁止的，并且对称性迫使所有操作都发生在那里。 
4. 迭代内部列从 2 到$n-1$。 对于每一列，在两列中都放置一家酒店$(2, c)$和$(3, c)$直到恰好$k/2$已使用色谱柱。 这准确地保证了$k$细胞全部被阻塞。 
5. 输出 YES 后跟网格。 

正确性来自于在第 2 行和第 3 行之间保持严格的镜像对称性。这种对称性保证了一个方向上的每条最短路径在相反方向上都有一个唯一的镜像对应项。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

if k % 2 == 1:
    print("NO")
    sys.exit()

grid = [['.'] * n for _ in range(4)]

need = k // 2
for c in range(1, n - 1):
    if need == 0:
        break
    grid[1][c] = '#'
    grid[2][c] = '#'
    need -= 1

print("YES")
for row in grid:
    print("".join(row))
```实施直接遵循构建。 网格从 0 开始索引，因此语句中的第 2 行和第 3 行对应于代码中的索引 1 和 2。 我们只使用从 1 到$n-2$，保留所需的边界约束。 每个选定的列恰好贡献两个被阻止的单元格，确保总计数匹配$k$。 

一个常见的错误是尝试在网格上任意放置块或仅使用中间行之一。 这立即破坏了对称性论证并使正确性失效。

 ## 边缘情况

 一个重要的边缘情况是当$k = 0$。 该算法生成一个空网格，该网格基本对称，因此两条路径计数保持不变且相等。 

另一种情况是当$k = 2(n-2)$。 这里第 2 行和第 3 行中的每个内部单元格都已填充。 该结构仍然有效，因为每根柱子都对称填充，并且网格保持完美镜像。 

第三种情况很奇怪$k$， 例如：```
n = 7, k = 3
```算法立即拒绝。 这是正确的，因为没有对称的单元配对可以产生奇数总数的阻塞单元，因此任何尝试都必然会破坏所需的路径计数相等性。
