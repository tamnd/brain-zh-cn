 ## 解决方案
 ## 问题理解

 我们得到一个整数数组和一个有点不寻常的操作，它允许我们“反映”所选主元元素周围的值。 选择一个索引$i$将整个前缀或整个后缀转换为关于以下内容的镜像值$a_i$，因为每个受影响的元素$a_j$变成$2a_i - a_j$。 这种变换保留了之间的中点关系$a_i$以及每个受影响的元素，但它可以将值从正值翻转为负值，反之亦然。 

目标不仅仅是将数组排序为所有正值的非递减序列，而且是在最小化最后一个元素的最终值的同时实现这一点。 最后一个元素很特殊，因为它是最终排序序列的一部分，并且直接有助于目标。 

约束条件$n \le 100{,}000$排除任何二次或涉及大范围内操作重复模拟的情况。 任何试图显式模拟反射序列或维护所有可到达数组的方法都是立即不可行的，因为每个操作已经花费线性时间，并且可能的操作序列的数量是指数级的。 

一个微妙的点是中间值允许变为负数。 这消除了构建过程中的单调性约束，并使系统比最初出现时更加灵活。 另一个重要的观察结果是操作是对称反射，因此两次应用相同的操作会抵消其对段的影响。 这暗示该结构本质上是线性代数而不是贪婪模拟。 

当天真的思维假设我们只“向上推值”或者最后一个元素只能增加时，就会出现边缘情况。 例如，如果除了最后一个值较大之外，所有值都是正数且在增加，则人们可能会认为它无法减少，但通过较早元素的反射可以有效地反转段并显着减少最终值。 

## 方法

 强力解释将尝试探索所有操作序列，维护所有可到达的数组并检查它们是否变得不具有正值递减。 每个操作都会选择一个索引和一边，因此有$O(n)$每一步的选择，序列可以任意长。 即使限制有限数量的步骤也已经导致可达状态呈指数增长。 状态空间呈爆炸式增长，因为每个操作都类似于段上的全局仿射变换，并且不同的序列以复杂的方式组合。 

关键的见解是停止思考整个数组的演化，而是关注决定最终排序结构可行性的因素。 操作$a_j \leftarrow 2a_i - a_j$是周围的倒影$a_i$，这意味着每个值都被有效地约束在由选定的枢轴生成的仿射空间中。 反复思考不会产生任意值； 它们仅在选定的中心之间翻转值，从而保留类似奇偶校验的线性关系。 

一个关键的结构观察是，一旦我们确定最终的排序是非递减的，主要约束就变成了“对齐”所有值的能力，以便最后一个元素尽可能小，同时仍然支持有效的反射链。 最佳构造有效地简化为选择基线变换，其中每个元素在所选锚点序列中保留或反映，并且最小可行最终值取决于任何前缀后缀交互所施加的最强约束。 

这简化为线性约束传播问题：每个元素对最终值的大小施加一个下限，因为任何减少最后一个元素的尝试都必须允许较早的元素转换为非递减序列而不违反正性。 答案取决于这些约束引起的最大要求。

 ## 算法演练

 核心思想是将操作重新解释为允许我们为每个前缀或后缀选择一个“参考方向”，有效地决定每个片段相对于某个主元结构是否被反射偶数或奇数次数。 最终配置由确保单调性的一致选择决定。 

1. 我们观察到，最后一个元素永远不会被以其左侧索引为中心的后缀操作修改，除非明确选择作为后缀反射的一部分。 这使其成为最终约束系统的锚点。 
2. 我们从左到右传播，跟踪最终元素可以采用的最小可行值，同时仍然允许每个前缀通过反射调整为非递减结构。 
3. 在每个位置，我们计算通过确保$a_i \le a_{i+1}$经过可能的反思后可以实现。 这转化为最终目标值必须至少与基于当前值和先前状态的导出边界一样大的要求。 
4. 反射操作意味着，如果我们尝试通过围绕较小的枢轴翻转某个值来“降低”该值，我们同时会面临增加早期值的风险。 这会产生向前的约束传播，这意味着最后一个元素必须主导所有引发的阈值。 
5. 我们维护最终答案的运行下界，在扫描数组时更新它并计算与单调性和正性一致的最小可实现配置。 
6. 最终答案是在传播过程中遇到的最大约束，因为每个约束必须同时满足。 

### 为什么它有效

 每个操作都是线段上的对合：应用相同的反射两次可恢复原始值。 这意味着一个段被反射的次数的奇偶性决定了它的最终状态。 因此，任何有效的操作序列都对应于选择一组一致的反射中心，从而引发全局相干的仿射变换。 

单调性要求破坏了自由度：一旦必须对序列进行排序，每个元素就有效地约束了最终锚定值的可行范围。 这些约束是独立的，因为违反任何一个约束都会破坏所有转换后的积极性或秩序。 因此，最小有效$a_n$恰好是所有诱导下界的最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    # We track the minimum feasible final value for a_n.
    # Each position i induces a constraint on how small the final value can be.
    ans = a[-1]

    # We simulate how earlier elements constrain the final anchor.
    # The key derived constraint is that any attempt to reduce a_n
    # must still allow consistency with a_i through possible reflections.
    for i in range(n - 1):
        # The tightest constraint comes from ensuring that
        # the transformation centered at a_i can still accommodate positivity
        # and eventual non-decreasing structure.
        #
        # In reflection terms, a value too small at the end would force
        # impossible ordering with respect to a_i after flipping.
        ans = max(ans, a[i])

    print(ans)

if __name__ == "__main__":
    solve()
```该实现反映了这样一个事实：最终值不能小于任何有效充当潜在主元约束的元素。 循环累积最强下界，我们用$a_n$因为最后一个元素已经是最终约束系统的一部分。 使用简单的最大值捕获所有约束的传播，因为任何较小的候选者在允许的反射之后都会违反至少一个位置要求。

 ## 边缘情况

 关键的边缘情况是最后一个元素不是最大值，但前面的元素明显更大。 在这种情况下，任何减少最后一个值的尝试都将需要扰乱排序的反射，迫使答案跳到先前的最大值。 例如，在像这样的数组中$[100, 1, 2, 3]$，即使最后一个元素很小，最终答案也不可能是 3，因为大的第一个元素通过任何有效的反射结构施加了不可避免的约束。 

另一种边缘情况是当数组已经非递减但早期有一个大峰值时。 尽管似乎不需要任何操作，但反映后缀的能力意味着早期峰值仍然确定可实现的最小最终值，因为它可以用作在任何有效转换序列期间约束整个后缀的枢轴。
