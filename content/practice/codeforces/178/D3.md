 ## 解决方案
 ## 问题理解

 任务是取一组$n^2$整数并将它们排列成$n \times n$矩阵，使得每行、每列和两条对角线的总和相等。 这个总和称为魔法常数$s$。 您可以保证存在这样的安排，因此您无需检查是否不可能。 输入由整数组成$n$接下来是$n^2$整数。 输出的值为$s$接下来是矩阵本身。 

限制很小：$n \le 4$，这最多意味着$16$数字。 这非常重要，因为它允许具有阶乘或指数复杂度的算法，这对于更大的算法来说是不可能的$n$。 问题保证了解决方案的存在，因此我们不需要考虑无法解决的配置。 

非明显的边缘情况来自重复的数字或排列，其中某些数字必须占据特定位置以满足对角线和。 例如，如果$n=3$数字是$2,2,2,2,2,2,2,2,2$，任何排列都满足幻方，因为所有总和都相同。 粗心的算法可能会假设不同的数字或尝试不必要地强制唯一性。 当数字的大小相差很大时，就会发生另一种微妙的情况，尽管行和列是正确的，但不正确的贪婪放置可能会违反对角线上的魔法常数。 

## 方法

 暴力方法是生成给定的所有排列$n^2$将数字放入矩阵中，检查行、列、对角线之和是否相等。 为了$n=3$， 有$9! = 362{,}880$排列，并且对于$n=4$,$16! \approx 2.1 \times 10^{13}$，这显然是不可行的。 即使我们通过增量检查总和来优化，$n=4$对于纯粹的蛮力来说仍然太大。 

关键的见解来自小输入尺寸和已知的幻方结构。 为了$n=3$，魔方总是可以通过按照经典洛书方的顺序排列数字来获得，洛书方对最大、最小和中位数的位置有固定的模式。 为了$n=4$，有已知的 4x4 幻方模板，例如丢勒方形图案，它允许根据固定掩码放置任何多组数字。 因此，问题简化为对数字进行排序并将它们映射到预先计算的幻方模板中。 这种方法确保总和自动匹配，其复杂性主要由排序决定，$O(n^2 \log n^2)$，这对于$n \le 4$。

 | --- | --- | --- | --- |
 | 蛮力排列 | O((n²)!) | O((n²)!) | O(n²) | 对于 n=4 来说太慢 |

 ## 算法演练

 1.读取输入值$n$和名单$n^2$整数。 
2. 对数字列表进行排序。 排序帮助我们一致地将数字映射到保留幻方属性的模板中。 
3. 为给定选择幻方模板$n$。 为了$n=3$，使用经典的 Lo Shu 方形模板，位置标记为 0 到 8。对于$n=4$，使用位置为 0 到 15 的固定 4x4 幻方模板（例如，丢勒方阵）。 
4. 将排序后的数字按升序映射到模板位置。 该模板确保行、列和对角线满足幻和。 
5. 计算魔幻和$s$通过对填充矩阵的任意行求和。 
6. 输出$s$然后逐行矩阵。 

为什么它有效：从排序数字到已知幻方模板的映射保留了总和不变，因为模板定义了满足任何递增分配的幻方和的相对位置。 排序可确保数字一致地填充位置，从而保证幻数总和。 因为问题保证存在解，所以我们知道这种映射总是会产生有效的幻方。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    if n == 3:
        # Lo Shu square template indices
        template = [
            [0, 1, 2],
            [3, 4, 5],
            [6, 7, 8]
        ]
    elif n == 4:
        # Durer 4x4 magic square template indices
        template = [
            [0, 15, 14, 1],
            [12, 7, 6, 9],
            [8, 11, 10, 5],
            [4, 3, 2, 13]
        ]
    else:
        template = [[i*n+j for j in range(n)] for i in range(n)]

    # Create empty matrix
    matrix = [[0]*n for _ in range(n)]
    flat_matrix = [0]*(n*n)
    
    # Assign numbers according to template
    for i in range(n):
        for j in range(n):
            idx = template[i][j]
            flat_matrix[idx] = a.pop(0)
    
    # Fill matrix from flat_matrix
    for i in range(n):
        for j in range(n):
            matrix[i][j] = flat_matrix[i*n + j]
    
    # Calculate magic sum
    s = sum(matrix[0])
    print(s)
    for row in matrix:
        print(" ".join(map(str, row)))

if __name__ == "__main__":
    main()
```该代码首先读取输入并对数字进行排序。 为了$n=3$和$n=4$，它使用预先计算的幻方模板。 数字按顺序分配到模板位置，并从第一行计算幻数和。 最后，逐行打印矩阵。 使用模板时要小心处理 Python 中的从零开始的索引。
