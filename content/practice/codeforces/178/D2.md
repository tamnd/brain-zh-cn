 ## 解决方案
 ## 问题理解

 我们被要求建造一个$n \times n$幻方使用给定的多重集$n^2$整数。 幻方具有以下性质：所有行、所有列以及两条对角线的总和都相等。 输入提供$n$和一个简单的列表$n^2$整数，并且输出必须是将这些数字排列成满足幻数和属性的平方。 此外，我们必须输出幻数本身。 

限制很小：$n \le 4$。 为了$n=1$这是微不足道的； 为了$n=2$对于任意整数，幻方可能不存在，但问题保证了解决方案。 为了$n=3$或者$n=4$，可能排列的总数$n^2$最多有整数$16! \approx 2 \times 10^{13}$，对于暴力探索来说太大了。 然而，较小的尺寸允许通过修剪或组合优化进行递归回溯。 

非明显的边缘情况包括许多数字相等的情况。 例如，$n=3$所有数字等于 5 将产生一个所有条目均为 5 且幻数和为 15 的平方。另一种棘手的情况是，当只有一种整数排列满足行、列和对角线和时，因此算法必须正确回溯并且不会过早接受部分和。 

## 方法

 一种简单的方法是尝试数字的所有排列并检查每个排列的幻和属性。 这是正确的，因为任何满足行、列和对角线和的有效排列都是一个解决方案。 然而，排列的阶乘增长使得这种方法对于$n > 2$， 自从$9! = 362{,}880$和$16! \approx 2 \times 10^{13}$2 秒内超出合理计算范围。 

关键的观察是我们不需要盲目地尝试所有排列。 该问题保证存在解决方案，并且$n \le 4$。 因此，递归回溯方法效果很好：我们逐个单元格填充正方形，跟踪行总和、列总和以及对角线总和。 在每一步中，我们都会检查输入数字是否会导致无法达到有效的幻数。 如果是这样，我们跳过该分支。 与探索所有排列相比，这大大减少了搜索空间。 

为了$n=3$和$n=4$，解决方案的小尺寸和保证存在意味着回溯足够快，并且诸如对数字进行排序或首先填充中心/对角线之类的附加优化可以进一步加速它。

 ## 算法演练

 1. 阅读$n$和名单$n^2$整数。 计算所有数字的总和并除以$n$确定魔幻总和$s$。 这是有效的，因为在幻方中每个$n$行总和为$s$，所以总和必须是$n \cdot s$。 
2. 初始化一个$n \times n$网格充满零。 维护每行和列的当前总和的数组，以及主对角线和次对角线总和的两个变量。 
3. 为可用数字创建一个计数器，这样我们就可以在当前单元格中有效地尝试每个未使用的数字一次。 
4. 定义一个递归函数来填充网格。 在每个步骤中，按行优先顺序选择下一个空单元格。 对于每个仍然可用的数字，尝试将其放入单元格中并更新行、列和对角线总和。 如果安置使任何金​​额超过$s$，立刻原路返回。 
5. 如果我们到达最后一个单元格并且所有行、列和对角线的总和都相等$s$，我们找到了一个有效的幻方并且可以停止递归。 
6. 输出$s$和填充的网格。 

工作原理：在每个递归步骤中，算法都会保持不变式，即没有行、列或对角线和超过幻数和。 因为解决方案是有保证的，所以回溯最终将探索正确的位置，而修剪可确保我们不会探索不可能的安排。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import Counter

def solve():
    n = int(input())
    nums = list(map(int, input().split()))
    s = sum(nums) // n
    
    grid = [[0]*n for _ in range(n)]
    row_sum = [0]*n
    col_sum = [0]*n
    diag_main = 0
    diag_anti = 0
    
    count = Counter(nums)
    positions = [(i, j) for i in range(n) for j in range(n)]
    
    def backtrack(pos):
        nonlocal diag_main, diag_anti
        if pos == n*n:
            return True
        i, j = positions[pos]
        for x in list(count.keys()):
            if count[x] == 0:
                continue
            if row_sum[i]+x > s or col_sum[j]+x > s:
                continue
            if i == j and diag_main + x > s:
                continue
            if i + j == n-1 and diag_anti + x > s:
                continue
            # place x
            grid[i][j] = x
            row_sum[i] += x
            col_sum[j] += x
            if i == j:
                diag_main += x
            if i + j == n-1:
                diag_anti += x
            count[x] -= 1
            if backtrack(pos+1):
                return True
            # undo
            grid[i][j] = 0
            row_sum[i] -= x
            col_sum[j] -= x
            if i == j:
                diag_main -= x
            if i + j == n-1:
                diag_anti -= x
            count[x] += 1
        return False
    
    backtrack(0)
    print(s)
    for row in grid:
        print(' '.join(map(str, row)))

if __name__ == "__main__":
    solve()
```解法首先计算幻和$s$从所有数字的总和中。 然后，它使用递归回溯函数来填充网格，在每一步检查行、列和对角线的总和不超过$s$。 计数器确保每个数字的使用次数与给定的次数完全相同。
