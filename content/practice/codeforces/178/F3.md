 ## 解决方案
 ## 问题理解

 我们得到了一组字符串，每个字符串代表一种蛋白质。 从这个集合中，我们必须准确选择$k$字符串并为所选子集分配分数。 分数是在所有无序的所选字符串对上定义的。 对于一对字符串，我们计算它们从一开始到第一次不同之前共有多少个字符； 这是它们最长公共前缀的长度。 总分是所选子集中所有对的该值的总和。 

任务是选择大小的子集$k$最大化总的成对前缀相似度。 

关键的困难在于每个字符串的相似性不是相加的。 单个字符串会影响子集中所有其他字符串的分数，因此我们正在优化子集而不是单个项目的组合结构。 

这些限制将我们推向不同的方向。 字符串数量最大可达 2000 个，每个字符串长度最大为 500。对所有字符串进行直接子集搜索$\binom{2000}{k}$选择是不可能的。 即使对于中等$k$，枚举子集远远超出了可行的限制。 这立即表明必须利用最长公共前缀的结构，而不是将字符串视为不透明对象。 

重复字符串会出现一个微妙的问题。 相同的字符串贡献的最大前缀长度等于每对的完整字符串长度，因此选择重复项可以显着提高分数。 任何将字符串视为唯一对象而不考虑多重性的方法在重复是最佳的情况下都会失败。 

当字符串共享长前缀但较晚发散时，会出现另一种失败情况。 选择与当前集合具有最大成对相似度的字符串的贪婪策略可能会在本地陷入困境，因为早期的选择会严重影响未来的兼容性。 

例如，考虑：```
aba
abb
abc
zzz
```和$k = 3$，贪婪的选择可能会选择`aba`,`abb`,`abc`，但将其替换为`zzz`大大减少贡献。 该结构取决于全局聚类，而不是成对的局部最大值。 

## 方法

 中心观察是最长的公共前缀自然会产生特里结构。 我们不直接考虑字符串，而是按前缀对它们进行分组。 

如果我们将所有字符串插入到 trie 中，则每个节点都对应于某个字符串子集共享的前缀。 如果我们修复一个节点，那么其子树中的所有字符串至少共享该前缀。 该子树内的对的贡献具有清晰的结构：子树中的每一对至少贡献该节点的深度。 

这表明了一种分解：特里树中的每个节点根据通过它的选定字符串的数量对答案做出贡献。 

让$c_v$是节点子树中所选字符串的数量$v$。 最低公共前缀恰好位于节点的每对选定字符串$v$贡献深度(v)。 换句话说，答案可以重写为仅取决于子树中的计数的贡献 trie 节点的总和。 

蛮力方法将枚举大小的所有子集$k$，计算成对的 LCP$O(k^2 \cdot L)$，并取最大值。 这是$O(\binom{n}{k} \cdot k^2 L)$，即使对于$n = 30$。 

关键的简化是目标在 trie 节点上分解，并且不同节点的决策仅通过子树计数进行耦合。 这导致了树DP，我们在其中自下而上地处理trie，并为每个节点计算在其子节点之间分配给定数量的选定字符串的最佳可实现值。 

我们在每个节点维护一个 DP 数组：$dp_v[i]$是通过选择可获得的最大代表性$i$来自以 为根的子树的字符串$v$，不包括上述贡献$v$。 合并子树时，我们对子树大小执行类似背包的卷积。 每条边通过进位计数隐式地贡献其深度。 

复杂性仍然是可控的，因为每个字符串在 trie 中最多贡献 500 个节点，因此总节点数为$O(nL)$，并且每次合并分配$k$跨越儿童的物品。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力子集 |$O(\binom{n}{k} \cdot k^2 L)$|$O(k)$| 太慢了|
 | 子树背包上的 Trie DP |$O(n L k^2)$最坏情况，在实践中有效优化|$O(n k)$| 已接受 |

 ## 算法演练

 1. 从所有字符串构建一个字典树。 每个节点存储其子节点以及它是否对应于某个字符串的末尾。 这将前缀关系转换为深度等于前缀长度的树结构。 
2、在每个节点定义一个DP表$v$， 在哪里$dp_v[i]$是通过精确选择可获得的最大贡献$i$来自以 为根的子树的字符串$v$，还不包括祖先的贡献。 这种分离至关重要，因为前缀贡献自然会在发生分歧的节点处得到考虑。 
3. 初始化每个节点，以便选择以该节点结尾的单个字符串会在子树内贡献 0 个附加对值，因为没有由一个元素形成对。 如果一个节点对应于实际的字符串末端，则它向 DP 贡献一个可用项。 
4. 按后序递归处理子项。 合并孩子时$u$进入$v$，使用背包卷积组合 DP 表：对于每个$i$在$dp_v$和$j$在$dp_u$， 更新$dp_v[i + j]$使用$dp_v[i] + dp_u[j]$。 这样做的原因是，除了选择了多少项之外，不相交子树中的选择是独立的。 
5. 合并子节点后，添加当前节点前缀的贡献。 如果$v$处于深度$d$，那么在其子树中形成的每一对都贡献$d$。 这是通过跟踪通过计数隐式形成多少对来合并的； 同样，我们确保贡献是按最低共同祖先计算的。 
6.最终答案是$dp_{\text{root}}[k]$。 

### 为什么它有效

 每对选定的字符串在特里树中都有一个唯一的最低共同祖先。 该算法通过子树结构在该节点处将该对的贡献恰好分配一次。 由于 DP 强制对每个子树中选定的字符串进行精确计数，因此每个有效选择都恰好对应一个 DP 状态路径，并且不会发生无效的过度计数，因为对永远不会归因于多个节点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

class Node:
    __slots__ = ("ch", "end")
    def __init__(self):
        self.ch = {}
        self.end = 0

def add(root, s):
    v = root
    for c in s:
        if c not in v.ch:
            v.ch[c] = Node()
        v = v.ch[c]
    v.end += 1

def solve():
    n, k = map(int, input().split())
    root = Node()

    for _ in range(n):
        add(root, input().strip())

    # DP: node -> list of best values for selecting i strings
    def dfs(v, depth):
        dp = [-10**18] * (k + 1)
        dp[0] = 0

        # each string ending here contributes as a selectable item
        if v.end:
            ndp = [-10**18] * (k + 1)
            for i in range(k):
                if dp[i] > -10**17:
                    ndp[i + 1] = max(ndp[i + 1], dp[i])
            dp = ndp

        for child in v.ch.values():
            cd = dfs(child, depth + 1)
            ndp = [-10**18] * (k + 1)
            for i in range(k + 1):
                if dp[i] < -10**17:
                    continue
                for j in range(k - i + 1):
                    if cd[j] < -10**17:
                        continue
                    ndp[i + j] = max(ndp[i + j], dp[i] + cd[j] + j * (j - 1) // 2)
            dp = ndp

        return dp

    dp_root = dfs(root, 0)
    print(dp_root[k])

if __name__ == "__main__":
    solve()
```trie 结构是对所有字符串的直接插入，确保共享前缀映射到共享路径。 

DFS 自底向上计算 DP 表。 期限$j(j-1)/2$合并子子树时会出现，因为在子树内，每对贡献一次，并且向上移动时，必须相对于前缀结构考虑完全在该子树内部形成的新对。 

一个微妙的实现问题是内存：每个 DP 数组的大小$k$，每个节点分配一个，因此递归深度和剪枝很重要。 另一个微妙的问题是确保不可能的状态用足够负的哨兵来表示，这样它们就不会被最大程度地选择。

 ## 边缘情况

 关键的边缘情况是所有字符串都相同。 在这种情况下，每一对都贡献全长，因此最佳解决方案是取任意一个$k$其中。 特里树折叠成一条路径，每次合并都会在每个级别累积最大对贡献，从而正确地生成$\binom{k}{2} \cdot L$。 

另一种情况是字符串仅共享短前缀并立即发散。 DP 正确地将所有收益推入浅层 trie 节点，确保没有人为分组会夸大更深层次的贡献。 

最后，当$k = 1$，每个 DP 转换都会崩溃为选择对贡献为零的单个项目，并且算法自然返回 0，与不存在对的定义相匹配。
