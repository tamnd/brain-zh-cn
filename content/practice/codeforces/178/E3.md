 ## 解决方案
 ## 问题理解

 我们得到一个方形的单色图像，表示为$n \times n$矩阵，其中每个元素为 0（白色背景）或 1（黑色前景）。 该图像中有几个不同的几何形状，每个形状都是正方形或圆形。 任务是确定存在多少个圆形和正方形。 形状可以任意旋转，最多 20% 的像素可能有噪点，从而翻转其颜色。 关键限制是形状足够大（直径至少 15 个像素）且间隔至少 10 个像素，并且形状总数不超过 50 个。 

输入尺寸$n$最多为 2000。这会立即排除像素数量为二次或更差的算法（如果它们对每个像素执行大量操作）。 我们必须设计一种能够随像素数量线性或近线性缩放的解决方案，理想情况下$O(n^2)$在最坏的情况下，因为像素总数约为$4 \times 10^6$。 

由于噪音和旋转，仅仅尝试将几何模板适合每个可能位置的简单方法将会失败。 另一个边缘情况是当正方形旋转 45 度时：其边界框变得大于其边长，因此简单的轴对齐检查可能会对其进行错误分类。 如果形状很小或接近噪声阈值，粗心的算法可能会多次对同一形状进行计数或完全错过它。 

例如，旋转 45 度的 20×20 像素正方形可能会占据 28×28 的边界框。 简单的面积周长比检查可能会将其错误地分类为圆形。 正确的操作必须考虑旋转和噪音。 

## 方法

 暴力方法是迭代所有像素，找到黑色像素的连通分量，并尝试将每个分量分类为正方形或圆形。 这是可行的，因为形状分离得很好，因此每个组件对应一个形状。 可以使用 BFS 或 DFS 来实现组件查找。 找到一个组件后，可以计算它的边界框、面积、周长和一个简单的圆度度量，例如$\text{compactness} = \frac{4 \pi \cdot \text{area}}{\text{perimeter}^2}$。 圆形的紧致度接近 1，而正方形（甚至是旋转的正方形）的紧致度稍小，但噪声会引入方差。 

挑战在于对噪声和旋转的鲁棒性。 一种见解是，由于形状很大且分离，因此可以通过腐蚀/膨胀等形态学操作来去除小噪声像素，或者在计算主要连接组件时直接忽略。 另一个原因是旋转的正方形具有尖角，从而降低了紧凑性，而圆形则保持光滑。 使用 BFS 提取主要斑点，然后计算形状的二阶矩（像素坐标的协方差）使我们能够估计偏心率和方向。 圆形在 x 和 y 上的方差几乎相等，而正方形如果旋转则可能略有不同。 

因此，最佳解决方案是标准连通分量标记加上用于对形状类型进行分类的稳健度量的组合。 BFS 或 DFS 运行在$O(n^2)$，并且形状分类与组件的像素数量呈线性关系。 这足够快了$n \le 2000$且组件数量少于 50 个。

 ## 算法演练

 1. 阅读$n \times n$像素矩阵。 将其转换为布尔网格以便于处理。 
2. 初始化相同大小的访问矩阵以跟踪哪些像素已分配给组件。 
3. 迭代每个像素。 如果像素为黑色 (1) 并且未被访问，则启动 BFS 来提取所有连接的黑色像素。 将它们添加到代表当前组件的列表中。 
4. BFS 完成后，将组件面积计算为像素数和边界框尺寸（最小和最大 x 和 y）。 
5. 计算质心$(cx, cy)$和第二个时刻$\text{var}_x, \text{var}_y, \text{cov}_{xy}$。 使用它们来估计形状的偏心率和方向。 接近圆形的组件将具有$\text{var}_x \approx \text{var}_y$和低偏心率。 如果旋转，正方形沿其对角线的变化会稍大一些。 
6. 计算紧凑性指标$C = \frac{4 \pi \cdot \text{area}}{\text{perimeter}^2}$。 圈子里会有$C \approx 1$，方格略少。 结合偏心率和紧凑度阈值对形状进行稳健分类。 
7. 增加相应的圆形或方形计数器。 重复直到访问完所有像素。 
8. 输出两个计数。 

不变的是，由于分离保证，每个连接的组件恰好对应于一种形状。 BFS 确保形状的所有像素都被计算一次，并且由于形状的最小尺寸较大，因此几何度量对于噪声和旋转具有鲁棒性。 

## Python 解决方案```python
import sys
from collections import deque
import math
input = sys.stdin.readline

def main():
    n = int(input())
    grid = [list(map(int, input().split())) for _ in range(n)]
    visited = [[False]*n for _ in range(n)]

    circles = 0
    squares = 0

    dx = [0,0,1,-1,1,1,-1,-1]
    dy = [1,-1,0,0,1,-1,1,-1]

    def bfs(sx, sy):
        q = deque()
        q.append((sx, sy))
        visited[sx][sy] = True
        pixels = []
        while q:
            x, y = q.popleft()
            pixels.append((x, y))
            for d in range(8):
                nx, ny = x + dx[d], y + dy[d]
                if 0 <= nx < n and 0 <= ny < n and grid[nx][ny] and not visited[nx][ny]:
                    visited[nx][ny] = True
                    q.append((nx, ny))
        return pixels

    def classify(pixels):
        area = len(pixels)
        xs = [x for x,_ in pixels]
        ys = [y for _,y in pixels]
        cx, cy = sum(xs)/area, sum(ys)/area
        var_x = sum((x - cx)**2 for x in xs)/area
        var_y = sum((y - cy)**2 for y in ys)/area
        cov_xy = sum((x - cx)*(y - cy) for x,y in pixels)/area
        # Eccentricity estimate
        trace = var_x + var_y
        det = var_x*var_y - cov_xy**2
        if trace == 0:
            e = 0
        else:
            e = math.sqrt(max(trace**2 - 4*det, 0)) / trace
        if e < 0.25:
            return 'circle'
        return 'square'

    for i in range(n):
        for j in range(n):
            if grid[i][j] and not visited[i][j]:
                comp = bfs(i,j)
                shape = classify(comp)
                if shape == 'circle':
                    circles += 1
                else:
                    squares += 1

    print(circles, squares)

if __name__ == "__main__":
    main()
```BFS 函数收集形状的所有像素。 这`classify`函数使用质心和协方差来估计偏心率； 圆在 x 和 y 方向上的分布几乎相等，因此偏心率较低。 该指标可以容忍噪音和旋转。
