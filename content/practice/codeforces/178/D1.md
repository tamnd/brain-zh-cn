 ## 解决方案
 ## 问题理解

 我们被要求安排一组给定的$n^2$整数化为$n \times n$矩阵，使其形成幻方。 幻方被定义为每行、每列和两条主对角线之和为相同值的矩阵$s$。 输入提供尺寸$n$和一个简单的列表$n^2$整数。 输出是总和$s$接下来是矩阵本身，其中输入的每个数字出现的次数与给定的次数完全相同。 

约束限制$n$最多 4 分即可获得满分。 和$n \leq 4$，排列的数量$n^2$数目最多为$16!$，这大约是$2 \times 10^{13}$。 这太大了，无法天真地探索，因此暴力枚举是不可行的。 较小的子案例$n \leq 3$或者最多 9 个不同的数字暗示我们可以利用对称性和组合模式，而不是依赖盲目搜索。 

一个微妙的问题是数字可能会重复，因此假设唯一性的天真放置可能会失败。 例如，如果输入是`2 2 2 2`为了$n = 2$，强力排列生成器可能只考虑一种独特的排列，但所有四个位置都必须包含`2`，和总和$s = 4$。 类似地，主对角线和次对角线可能重叠（奇数在中心）$n$），因此必须谨慎处理共享位置。 

## 方法

 蛮力方法将生成所有排列$n^2$数字，填入正方形，并检查总和条件是否成立。 这是可行的，因为问题保证了解决方案的存在，所以我们最终会找到一个解决方案。 然而，排列的数量呈阶乘增长，这对于$n = 4$甚至$n = 3$如果我们不利用重复项。 

关键的观察是方阵中的位置数量很少，并且魔方结构是刚性的。 为了$n = 3$，经典的洛书方格显示出一种固定的模式，其中中心始终是数字的中位数。 对于较大的$n$，我们可以将位置分类为角点、边缘和中心。 每个类别对行、列和对角线和的贡献相同，并且可以根据这些对称类别放置数字。 为了$n = 4$对于最多 9 个不同的数字，对少量唯一数字进行回溯是有效的，因为大多数排列都会提前违反总和约束，从而修剪搜索。 

我们使用回溯和修剪作为最佳方法。 我们尝试将数字按顺序放置在正方形的位置上，保持行、列和对角线的运行总和。 如果在任何时候部分总和超过目标总和或无法满足所有总和，我们就会回溯。 正方形的对称性使我们能够正确处理共享位置并减少不必要的分支。

 ## 算法演练

 1. 计算每个不同数字的出现次数。 这让我们避免不必要地在多个位置重复尝试相同的数字。 
2. 定义要填补的职位列表，最好按照首先放置最受限职位的顺序。 角线和对角线应该早点走，因为它们参与更多的总和。 
3. 维护每行、每列和两条对角线的运行总计。 这允许早期修剪：如果放置一个数字使得剩余数字无法达到总和，我们会立即回溯。 
4. 实现一个递归函数，尝试将可用池中的数字放入当前位置。 放置后，减少该数字的计数。 递归到下一个位置。 递归结束后，恢复计数（回溯）。 
5. 当所有位置都填满后，检查所有行、列和对角线的总和是否等于候选总和。 如果是，保存溶液并返回。 由于问题保证有解，因此可以输出找到的第一个有效方格。 
6. 在递归之前，尝试猜测目标和$s$来自约束。 对于小$n$，一种选择是对数字进行排序并计算平均行总和，$s = \text{sum(numbers)} / n$。 这是可行的，因为每一行和每一列的总和必须相同$s$，总和正好是$n \cdot s$。 

### 为什么它有效

 不变的是，在每个递归步骤中，所有放置的数字都满足其行、列和对角线的部分和。 通过修剪任何违反此不变量的分支，我们确保找到的任何完整平方都保证满足幻方属性。 详尽的探索仅针对可行的放置，因此保留了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    nums = list(map(int, input().split()))
    target_sum = sum(nums) // n
    from collections import Counter
    counts = Counter(nums)
    
    grid = [[0]*n for _ in range(n)]
    rows = [0]*n
    cols = [0]*n
    diag1 = 0
    diag2 = 0
    positions = [(i, j) for i in range(n) for j in range(n)]
    
    found = False
    
    def backtrack(idx):
        nonlocal found, diag1, diag2
        if found:
            return
        if idx == n*n:
            if all(r == target_sum for r in rows) and all(c == target_sum for c in cols) and diag1 == target_sum and diag2 == target_sum:
                print(target_sum)
                for row in grid:
                    print(' '.join(map(str, row)))
                found = True
            return
        i, j = positions[idx]
        for num in list(counts.keys()):
            if counts[num] == 0:
                continue
            # check feasibility
            rows[i] += num
            cols[j] += num
            if i == j:
                diag1 += num
            if i + j == n - 1:
                diag2 += num
            counts[num] -= 1
            
            if all(rows[k] <= target_sum for k in range(n)) and all(cols[k] <= target_sum for k in range(n)) and diag1 <= target_sum and diag2 <= target_sum:
                grid[i][j] = num
                backtrack(idx+1)
                grid[i][j] = 0
            
            rows[i] -= num
            cols[j] -= num
            if i == j:
                diag1 -= num
            if i + j == n - 1:
                diag2 -= num
            counts[num] += 1
    
    backtrack(0)

solve()
```该解决方案首先计算目标总和，然后递归地填充网格。 计数器可确保有效处理重复项。 早期修剪可以避免探索不可能的部分和。 位置以自然行优先顺序迭代，对角线动态更新以考虑奇数中心的重叠$n$。
