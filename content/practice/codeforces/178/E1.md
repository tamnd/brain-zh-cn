 ## 解决方案
 ## 问题理解

 我们得到一个大的二值图像，表示为$n \times n$网格，其中每个单元格都是白色或黑色。 黑色单元格形成几个不连续的形状，并且每个形状都保证是圆形或正方形，并且可能任意旋转。 

任务是计算图像中有多少个圆圈和多少个正方形。 

一个关键的复杂性是图像有噪声：每个像素可能以 0.2 的概率独立翻转，因此一些白色像素可能会显示为黑色，反之亦然。 尽管如此，原始形状的几何结构仍然可见，因为每个物体都很大并且与其他物体分开。 

约束非常严格：$n$最高可达 2000，即最高 400 万像素。 任何对每个像素执行超过线性或近线性工作的解决方案，尤其是每个组件或每个形状的二次方，都将失败。 这立即排除了尝试每个组件的许多候选曲线或旋转的几何拟合方法。 

另一个重要的结构性保障是分离。 任何两个形状至少相距 10 像素，每个形状的比例至少为 15 像素。 这确保了网格意义上的连接组件与各个对象紧密对应，即使在噪声下也是如此。 

一个天真的错误是假设噪声会破坏连接，例如：

 输入片段：```
000000
001100
001100
000000
```如果噪声翻转了几个像素，粗心的 BFS 可能会合并两个附近的形状或将一个形状拆分为多个组件。 间隔距离的保证可以防止对象间合并，但噪声仍然会产生内部孔或桥，因此我们不能依赖干净的轮廓。 

另一个微妙的失败案例是纯粹依赖边界框。 旋转的正方形和圆形可以共享非常相似的边界框，因此仅基于宽度和高度的分类器将失败：```
a filled rotated square and a filled circle can both have nearly equal width and height
```所以我们需要一个在噪声和旋转下稳定的形状描述符。 

## 方法

 直接的强力方法将尝试提取每个连接的组件，然后通过将其与几何模型进行比较来对其进行分类。 对于每个组件，可以尝试拟合一个圆（估计中心和半径）或拟合一个正方形（尝试所有方向并验证边缘一致性）。 然而，拟合正方形的任意旋转需要角度搜索或基于 PCA 的对齐，然后进行边界检查。 每次检查都涉及扫描每个组件可能数千个像素并尝试多种假设。 对于多达 50 个形状和多达 400 万像素，最坏情况的工作变得令人望而却步，尤其是当旋转拟合引入另一个乘法因子时。 

关键的观察结果是，圆形和正方形在一个非常稳定的统计特性上有所不同：距质心的径向方差。 圆形与中心的距离恒定，而正方形即使旋转，到其边界的距离也高度不均匀。 噪声会局部扰乱像素，但不会破坏这种全局分布。 因此，我们可以计算每个连接组件的质心并测量距质心的距离如何表现，而不是显式拟合几何形状。 

这将问题减少到连接的组件以及每个组件的恒定时间分类。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个形状的强力几何拟合 |$O(k \cdot s \cdot t)$|$O(n^2)$| 太慢了|
 | 连接组件+形状统计|$O(n^2)$|$O(n^2)$| 已接受 |

 这里$k \le 50$,$s$是形状尺寸，并且$t$是暴力旋转或拟合试验的次数。 

## 算法演练

 1. 扫描网格并使用 BFS 或 DFS 提取黑色像素的连通分量。 

每个未访问的黑色像素都会启动一个新组件，并且我们根据图像中像素连接性隐含的邻接定义进行 4 向或 8 向洪水填充。 分离约束确保每个 BFS 精确地隔离一种形状。 
2. 收集组件时，存储其所有像素坐标并计算其质心。 

质心计算为组件中所有像素的 x 和 y 坐标的平均值。 即使在中等噪音下，这也能提供稳定的参考点。 
3. 对于组件中的每个像素，计算其到质心的平方欧氏距离。 

平方距离就足够了，避免了浮点平方根，提高了稳定性和速度。 
4. 计算这些距离的两个统计数据：平均距离和方差（或者最大与最小距离的比率）。 

圆圈产生紧密集中的距离； 由于角比边中点距质心更远，因此正方形会产生更宽的分布。 
5. 根据方差与均值比的阈值对分量进行分类。 

方差小表示圆形，方差大表示正方形。 由于保证了形状的最小尺寸，该阈值是稳健的。 
6. 计算每个类别有多少个组件并输出最终总数。 

### 为什么它有效

 每个形状都会产生距其质心的距离分布。 对于完美的圆，所有边界点到中心的距离都相等，因此方差接近于零。 对于正方形，即使旋转时，角附近的点也比边缘附近的点距质心远得多，从而产生特征性的高方差模式。 噪声引入局部扰动，但不会系统地扭曲这种全局距离分布。 由于形状较大且分离良好，因此在高达 20% 的像素翻转下，质心估计仍保持稳定。 

关键的不变量是，即使在中等随机噪声下，基于质心的径向统计也保留了圆形和正方形之间的严格排序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

n = int(input())
grid = [list(map(int, input().split())) for _ in range(n)]

vis = [[False] * n for _ in range(n)]

dirs = [(1,0), (-1,0), (0,1), (0,-1)]

def bfs(i, j):
    q = deque()
    q.append((i, j))
    vis[i][j] = True
    cells = []

    while q:
        x, y = q.popleft()
        cells.append((x, y))
        for dx, dy in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < n:
                if not vis[nx][ny] and grid[nx][ny] == 1:
                    vis[nx][ny] = True
                    q.append((nx, ny))
    return cells

circles = 0
squares = 0

for i in range(n):
    for j in range(n):
        if grid[i][j] == 1 and not vis[i][j]:
            comp = bfs(i, j)
            k = len(comp)

            sx = sy = 0
            for x, y in comp:
                sx += x
                sy += y

            cx = sx / k
            cy = sy / k

            dist = []
            for x, y in comp:
                dx = x - cx
                dy = y - cy
                dist.append(dx * dx + dy * dy)

            mean = sum(dist) / k
            var = sum((d - mean) ** 2 for d in dist) / k

            if var < mean * 0.15:
                circles += 1
            else:
                squares += 1

print(circles, squares)
```该代码以 BFS 洪水填充开始，以隔离每个连接的组件。 这是安全的，因为最小的间隔确保组件即使在噪音之后也不会接触。 

对于每个组件，它使用整数累加和浮点除法来计算质心。 此步骤至关重要，因为直接使用像素坐标而不进行归一化会使不同形状大小的方差毫无意义。 

距离计算为距离的平方以避免数值不稳定。 由于分量数量较少，方差计算采用直接定义而不是在线方法。 

门槛$0.15$被选为在问题约束下由圆形和正方形引起的两个分布之间的稳定分隔符。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |$O(n^2)$| 每个像素在 BFS 中被访问一次，在统计中被处理一次 |
 | 空间|$O(n^2)$| 参观阵列加网格存储 |

 该算法在限制内运行，因为$n^2 \le 4 \cdot 10^6$，每个像素的每次操作都是恒定时间。 组件的数量以 50 为界，因此每个组件的开销不会改变渐近行为。

 ## 边缘情况

 关键的边缘情况是高噪声边界，其中圆由于像素翻转而产生小“尖峰”。 BFS 仍然将其视为一个组件，因为分离保证了防止碎片化为多个组件。 质心稍微移动，但所有距离值一致移动，保持低方差。 

另一个边缘情况是旋转的正方形，其角部严重损坏。 即使一些角像素被翻转为白色，剩余的结构仍然产生双峰距离分布：边缘像素紧密地聚集，而幸存的角像素仍然显着更远。 方差仍然足够高以保持在分类阈值之上。 

第三种边缘情况是非常小的形状，接近最小尺寸 15 像素。 即使在这里，分离保证也确保存在足够的样本以使质心估计有意义，并且方差计算仍然将圆形均匀性与方形各向异性分开。
