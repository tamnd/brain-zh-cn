 ## 解决方案
 ## 问题理解

 我们被要求计算 Ziota 在一系列游戏关卡中清除所有 Boss 的最短时间。 每个级别包含一定数量的普通怪物，每个怪物有 1 点生命值，并且只有一个 Boss 有 2 点生命值。 齐奥塔拥有三种武器：一把可以杀死单个怪物 1 HP 的手枪，一把可以对所有怪物造成 1 HP 的激光，以及可以立即杀死任何怪物的 AWP。 每种武器都有装弹时间，齐奥塔一次只能装填一把枪。 级别之间的移动需要`d`时间单位，并且我们无法在传送时重新加载或射击。 

输入数组`a`列出每个级别中普通怪物的数量。 我们的目标是从第 1 级开始，用最少的总时间消灭所有 Boss。关键的限制是，在所有普通怪物被杀死之前，我们不能用手枪或 AWP 射击 Boss，如果我们在没有立即杀死 Boss 的情况下伤害了它，我们必须在返回之前将级别保留到相邻的级别。 

主要限制是层数`n`最多可达 10^6 以及每级的怪物数量`a_i`也可以很大。 这排除了任何在嵌套循环中处理每个单独怪物的解决方案。 该解决方案必须在线性或接近线性时间内工作`n`。 不明显的边缘情况包括具有单个怪物和 Boss 的关卡，其中不同的枪支选择会极大地影响是否需要来回移动，以及在多个关卡上使用激光会减少重新加载时间但会强制进行额外移动的情况。 

## 方法

 一种简单的方法是模拟枪支使用和运动的每种可能的组合。 我们会尝试射击普通怪物的每个序列，可能使用激光，然后用手枪或 AWP 杀死 Boss，并根据需要在关卡之间移动。 这在原则上是正确的，因为它探索了所有有效的策略。 然而，由于关卡最多为 10^6 个，并且每个关卡最多有 10^6 个怪物，因此考虑每个怪物或所有武器使用序列的模拟很容易超过 10^12 次操作。 这对于 2 秒的时间限制来说太慢了。 

关键的见解来自于观察，对于每个级别，杀死所有普通怪物加上老板的最短时间可以通过一小组选项独立计算。 一个关卡有两种主要策略：用手枪单独杀死所有怪物，然后用 AWP 消灭 Boss，或者使用激光最佳方式一次性伤害所有怪物，可能让 Boss 活着并稍后处理。 每个级别都可以表示为重新加载时间的成本，加上可选的移动成本（如果我们让 Boss 部分损坏）。 这使我们能够将问题简化为沿关卡的动态编程，其中状态是我们是否来自上一个关卡，且 Boss 完全被杀死或部分损坏。 DP 只需要考虑每个级别的两个状态，使其呈线性`n`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * a_i) | O(n * a_i) | O(n) | 太慢了 |
 | 最佳DP | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个级别，计算两个关键成本。 第一个是简单的“直接杀死所有东西”的成本：对每个普通怪物使用手枪，对头目使用 AWP。 这是`a_i * r1 + r3`。 第二个是“激光或灵活”成本：要么使用激光加可选手枪或AWP来杀死boss，如果boss幸存则利用强制移动。 这是`min(r2 + r1, r1 * a_i + r1 * 2, r3)`对于 Boss 组合，然后添加`a_i * r1`对于普通怪物来说。 
2. 定义DP状态。 让`dp[i][0]`是完成关卡的最短时间`i`老板完全被杀，并且`dp[i][1]`我们结束离开部分损坏的老板的最短时间，这意味着我们需要离开并稍后返回。 对于 1 级，`dp[1][0]`只是直接杀戮成本，并且`dp[1][1]`是灵活成本加变动`d`因为我们会让老板活着。 
3. 按顺序处理级别。 对于每个级别，更新`dp[i][0]`至少要完全完成前一关然后直接完成本关，或者在 Boss 部分损坏的情况下完成前一关然后回来。 更新`dp[i][1]`同样，考虑到该层部分损坏并将移动成本添加到相邻层。 
4.最终答案是`dp[n][0]`，如果将部分损坏的 Boss 留在最后一层有利于早期的减少，则可能会增加最小的额外移动。 

为什么它有效：DP 不变量是`dp[i][0]`始终代表杀死所有 Boss 达到等级的最短时间`i`， 尽管`dp[i][1]`代表杀死所有 Boss 达到等级的最短时间`i-1`加一个等级`i`老板部分损坏。 由于关卡之间唯一的相互作用是由于 Boss 部分损坏而导致的移动，因此每个关卡保持两种状态可以捕获所有最佳策略。 DP 转换仅考虑有效的移动和最少的选择，因此我们不能产生次优的解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, r1, r2, r3, d = map(int, input().split())
a = list(map(int, input().split()))

INF = 1 << 60

# cost to finish level i directly
direct = [0] * n
# cost to leave level i in "flexible" mode
flex = [0] * n

for i in range(n):
    ai = a[i]
    # kill all normal monsters with pistol + boss with AWP
    direct[i] = ai * r1 + r3
    # options: laser r2 + optional finishing, or pistol+r1 etc
    kill_boss_options = min(r3, r1 + r2, r1 * ai + r1 * 2)
    flex[i] = min(r1 * ai + r1 + r3, r2 + r1, r1 * ai + 2 * r1)

dp0 = 0  # previous level fully killed
dp1 = INF  # previous level partially damaged

for i in range(n):
    new_dp0 = min(dp0 + direct[i], dp1 + flex[i] + 2 * d)
    new_dp1 = min(dp0 + flex[i] + d, dp1 + flex[i] + 2 * d)
    dp0, dp1 = new_dp0, new_dp1

ans = dp0
print(ans)
```代码首先为每个级别预先计算两个成本数组：直接杀死成本和灵活杀死成本。 然后它迭代级别，维护两个 DP 状态：`dp0`对于完全清除的水平和`dp1`对于 Boss 部分存活的关卡。 更新公式正确地包含了移动成本。 在 INF 中使用大整数时要特别小心，以避免溢出。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 我们对每个级别处理一次，预先计算每个级别 O(1) 的直接成本和弹性成本。 |
 | 空间| O(n) | direct和flex使用两个长度为n的数组； DP 使用 O(1) 额外空间。 |

 对于 n 最多 10^6 和高常数运算，线性时间复杂度是可以接受的。 内存使用量仍远低于 512 MB 限制。
