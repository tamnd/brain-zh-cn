 ## 解决方案
 ## 问题理解

 矩阵开始时用零填充。 对于每对正数`(i, j)`，我们执行一项操作，翻转行索引可被整除的每个单元格`i`并且其列索引可被整除`j`。 

特定单元不关心未到达它的操作。 对于行中的单元格`r`和列`c`，唯一相关的操作是那些`i`划分`r`和`j`划分`c`。 每对这样的对都会翻转单元一次。 所有操作完成后，单元格包含`1`如果它被翻转了奇数次，否则它仍然存在`0`。 

每个测试用例给出一个矩阵的维度。 任务是计算有多少个单元格结尾为`1`。 

尺寸可以大到`10^18`，所以即使迭代所有行也是不可能的。 任何算法正比于`n`,`m`， 或者`n × m`立即被排除。 该解决方案每个测试用例必须仅使用少量算术运算。 

一个容易犯的错误是认为每个除数都是独立贡献的，而忘记了答案仅取决于奇偶性。 

例如：```
1
2 2
```正确答案是：```
1
```仅细胞`(1, 1)`变成`1`。 虽然其他单元格被翻转了几次，但每个单元格都被翻转了偶数次。 

另一种微妙的情况是只有一个索引是完全平方数时。```
1
3 4
```正确答案是：```
2
```行数`1`是唯一完美的正方形，而柱`1`和`4`是完美的正方形。 仅有的`(1,1)`和`(1,4)`完成为`1`。 只检查一个维度的粗心解决方案会导致计算过多。 

最终的边缘情况是最大可能的输入。```
1
1000000000000000000 1000000000000000000
```该解决方案必须避免模拟并直接从整数平方根计算答案。 

## 方法

 蛮力的想法很简单。 对于每一次操作`(i, j)`，访问每个受影响的单元格并将其翻转。 这是正确的，因为它完全遵循定义。 不幸的是，有`n × m`可能的操作对，并且每个操作可能触及许多单元格。 当维度达到时，即使迭代所有单元格也是不可能的`10^18`。 

关键的观察是独立分析一个细胞。 

假设我们查看单元格`(r, c)`。 每个除数都会翻转一次`i`的`r`和每个除数`j`的`c`。 如果`d(x)`表示除数的个数`x`，那么总翻转次数为`d(r) × d(c)`。 

只有平价才重要。 仅当两个因数均为奇数时，乘积才是奇数。 

现在我们只需要一个经典数论事实。 当整数是完全平方数时，该整数的除数计数正好是奇数。 每个非正方形都有成对出现的约数`(a, x / a)`，而完全平方有一个不成对的除数，即它的平方根。 

于是一个细胞就变成了`1`恰好当它的行索引和列索引都是完全平方数时。 

这个问题简化为计算每个维度的完全平方数。 正好有`⌊√n⌋`之间的完美平方`1`和`n`，并且类似地`⌊√m⌋`之间`1`和`m`。 

最终的答案很简单`⌊√n⌋ × ⌊√m⌋`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n × m × 平均受影响细胞) | O(n × m) | 太慢了|
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`和`m`。 
2. 计算`a = ⌊√n⌋`使用整数平方根函数。 这给出了完美平方行索引的数量。 
3. 计算`b = ⌊√m⌋`使用整数平方根函数。 这给出了完美方柱索引的数量。 
4. 输出`a × b`，因为完美方形行和完美方形列的每个组合都会产生一个翻转奇数次的单元格。 

### 为什么它有效

 对于固定单元`(r, c)`，翻转次数等于除数对的数量`(i, j)`和`i | r`和`j | c`，即`d(r) × d(c)`。 单元格结束为`1`当且仅当该产品是奇数时。 对于完全平方数来说，除数计数恰好是奇数，因此两者`r`和`c`必须是完全平方数。 独立地计算这些行和列可以给出包含以下内容的单元格的确切数量`1`。 

## Python 解决方案```python
import sys
from math import isqrt

input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    print(isqrt(n) * isqrt(m))
```该程序直接实现数学结果。`math.isqrt`返回整数平方根，正好是`⌊√x⌋`没有任何浮点错误。 这一点尤其重要，因为输入可以大到`10^18`，其中浮点平方根可能会失去精度。 

每个测试用例仅执行两次整数平方根计算和一次乘法。 Python 整数可以轻松处理最大可能的答案，因此不存在溢出问题。

## 测试用例```python
import sys
import io
from math import isqrt

def solve():
    input = sys.stdin.readline
    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        out.append(str(isqrt(n) * isqrt(m)))
    sys.stdout.write("\n".join(out))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()
    solve()
    ans = sys.stdout.getvalue()
    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return ans

# provided sample
assert run("1\n2 3\n") == "1"

# minimum size
assert run("1\n1 1\n") == "1"

# rectangular boundary
assert run("1\n3 4\n") == "2"

# no additional perfect square after 15
assert run("1\n15 15\n") == "9"

# maximum values
assert run("1\n1000000000000000000 1000000000000000000\n") == "1000000000000000000"
```| 测试输入| 预期产出 | 它验证了什么 |
 | ---| ---| ---|
 |`1 1`|`1`| 最小可能矩阵 |
 |`3 4`|`2`| 只有一维才能提供多个完全平方|
 |`15 15`|`9`| 正确的地板平方根处理 |
 |`10^18 10^18`|`10^18`| 最大允许值 |

 ## 边缘情况

 考虑最小矩阵。```
1
1 1
```

`isqrt(1) = 1`对于两个维度，所以答案是`1 × 1 = 1`。 唯一的单元格被翻转一次，因为`1`仅有一个除数。 

现在考虑一种情况，其中只有一个维度包含多个完全平方数。```
1
3 4
```该算法计算`isqrt(3) = 1`和`isqrt(4) = 2`，生产`1 × 2 = 2`。 细胞`(1,1)`和`(1,4)`是唯一具有奇数翻转计数的。 

最后，考虑最大的合法值。```
1
1000000000000000000 1000000000000000000
```

`isqrt(10^18) = 10^9`，所以答案是`10^9 × 10^9 = 10^18`。 该算法仅执行恒定时间算术，并且从不依赖于实际矩阵大小。
