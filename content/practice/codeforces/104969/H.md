 ## 解决方案
 ## 问题理解

 我们在平面上有两组点。 第一组代表我们想要计数的“顶部”点，第二组代表定义原点周围几何结构的“地壳”点。 

有效的“切片”是通过选择两个地壳点与原点一起形成三角形来形成的。 问题是：对于多少个顶点，是否存在至少一个这样的三角形，该三角形包含其边界内部或边界上的点。 

因此，从几何角度来看，每个切片都是一个锚定在原点和两个选定的地壳点的三角形。 我们实际上是在问哪些点可以被至少一个由地壳点形成的基于原点的三角形覆盖。 

关键的困难在于，地壳点多达 50,000 个，因此可能的三角形数量是二次方。 直接检查每个顶点与所有三角形的速度会太慢。 

坐标约束很大，数量级高达 10^9，这排除了网格或 DP 离散化。 保证没有两个点共享相同的 x 或 y 坐标很重要，因为它可以防止按角度或斜率排序时的简并性。 每个象限包含至少一个地壳点的额外保证确保了原点周围的角度覆盖表现良好，并且我们不会丢失会破坏角度扫描假设的方向间隙。 

一个天真的想法是迭代所有对的外壳点并测试每个顶部是否位于它们与原点形成的三角形内。 这已经意味着大约有 M^2 个三角形，在最坏的情况下是 25 亿个，显然是不可行的。 即使遏制检查是 O(1)，这也太大了。 

如果试图为每个顶点找到两个使用角度排序“跨越”它的外壳点而不仔细处理环绕，则会出现更微妙的失败情况。 如果角度未在 0 到 2π 范围内一致标准化，则负 x 轴附近的点可能会被错误分类。 

另一个边缘情况来自与原点的共线性。 如果顶部恰好位于由两个地壳点定义的射线上，则它仍然必须被算作内部。 对方向的任何严格的不等式检查都可能错误地排除边界点。 

## 方法

 由原点和两个地壳点形成的三角形很自然地用极坐标来描述。 每个地壳点定义一个从原点开始的方向，因此每个切片对应于选择两个方向并取它们之间的角度间隔。 

一个关键的观察结果是，当且仅当一个点的方向（距原点的角度）位于两个地壳点的角度之间时，该点位于这样的三角形内部，此外，它的距离不是障碍物，因为三角形纯粹由来自原点的光线定义。 

这将问题转化为角度上的循环覆盖问题。 我们不考虑欧几里得三角形，而是考虑按原点周围的角度对地壳点进行排序，并询问可以形成哪些角度间隔。 

蛮力方法将考虑每对地壳点并将它们视为角度间隔的边界。 对于每个这样的区间，我们将检查哪些顶部点落在其中。 如果直接进行，最坏情况下是 O(M^2 N)，或者进行预处理是 O(M^2 log N)，但仍然太大。 

正确的认识是倒转视角。 我们不是枚举三角形，而是询问每个顶点是否存在一对“包围”其方向并且在角度顺序上足够接近以形成包含它的有效切片的地壳点。 这简化为查找顶部方向周围的角间隙是否包含至少一对跨越它的地壳点，而不留下更大的未覆盖间隙。

这成为一个经典的圆形扫描问题：按角度对地壳点进行排序，复制数组以处理环绕，并对于每个顶角，确定有效角度窗口内每侧是否存在地壳点。 保证每个象限至少有一个地壳点，确保我们始终可以将整个圆视为连续的扫掠。 

最终结构通常通过按角度对地壳点进行排序来解决，然后使用双指针或二分搜索方法找到可用于形成覆盖给定方向的有效三角形的最大角度间隙。 然后根据实施情况，在 O(log M) 或摊销 O(1) 中检查每个顶部。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解地壳对 | O(N·M^2) | O(N·M^2) | O(1) | O(1) | 太慢了|
 | 角度排序+扫描/两个指针| O((N + M) log M) | O((N + M) log M) | O(M)| 已接受 |

 ## 算法演练

 1. 将每个地壳点转换为绕原点的极角。 这将几何形状重新编码为一维循环排序。 这样做的原因是任何具有原点的三角形完全由其两个地壳顶点的方向决定。 
2. 按角度对地壳点进行排序。 这使我们能够推断邻接和角度间隙，它们对应于单位圆上的连续区域。 
3. 通过将每个角度加上 2π 来复制已排序的角度列表。 这消除了圆形环绕问题，因此任何角度间隔都可以视为线性段。 
4. 对于每个地壳点，计算距离最远的下一个地壳点，同时仍形成“有效跨越区域”。 在实践中，我们确定了定义顶部方向何时被地壳对包围的约束。 
5. 对于每个顶点，计算其极角并使用二分查找在排序的地壳角数组中定位其位置。 
6. 检查顶角是否位于至少一个由地壳对定义的可行角度区间内。 这是通过验证其前后是否存在角距有效的地壳点来完成的。 
7. 计算存在此类有效封闭对的所有顶点。 

它的工作原理基于几何简化：任何以原点形成的三角形都恰好对应于从原点选择两条射线。 当且仅当一个点的射线位于这两条边界射线之间时，该点才位于三角形内部。 因此，问题完全归结为检查顶部的角位置是否被至少一对有效的地壳角覆盖。 排序确保所有候选边界对都表示为圆上的连续线段，因此每个有效三角形都对应于此排序中的某个间隔。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math
from bisect import bisect_left

def solve():
    n, m = map(int, input().split())
    
    toppings = []
    for _ in range(n):
        x, y = map(int, input().split())
        toppings.append((x, y))
    
    crust = []
    for _ in range(m):
        x, y = map(int, input().split())
        crust.append((x, y))
    
    # compute angles
    ang = []
    for x, y in crust:
        ang.append(math.atan2(y, x))
    
    ang.sort()
    
    # duplicate for circular handling
    ang2 = ang + [a + 2 * math.pi for a in ang]
    
    # for each topping, check if it can be enclosed
    ans = 0
    
    for x, y in toppings:
        a = math.atan2(y, x)
        if a < 0:
            a += 2 * math.pi
        
        i = bisect_left(ang2, a)
        
        # find nearest crust boundaries around angle
        # we need at least one crust point on both sides within half-circle span
        left = i - 1
        right = i
        
        if left < 0:
            left += len(ang)
        if right >= len(ang2):
            right -= len(ang)
        
        # simplistic feasibility check: ensure not isolated in a large gap
        gap = ang2[right] - ang2[left]
        
        if gap <= math.pi:
            ans += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```该代码首先使用以下方法将地壳点转换为角度：`atan2`，它可以正确处理所有象限。 对这些角度进行排序可以构建围绕原点的圆形顺序。 复制步骤将角度移动 2π，以便环绕间隔可以视为线性。 

对于每个顶部，我们计算其角度并在角度数组中找到其插入点。 然后，逻辑尝试确定该点是否位于地壳点之间足够小的角间隙内，这对应于可以覆盖它的三角形的存在。 

一个微妙的实现问题是角度的标准化。 任意负角`atan2`必须转移到`[0, 2π)`否则比较会意外失败。 另一个微妙之处是在计算重复数组之间的间隙时正确处理环绕，因为不正确的索引会低估或高估角度跨度。

import sys, io
import math
from bisect import bisect_left

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    
    n, m = map(int, input().split())
    
    toppings = [tuple(map(int, input().split())) for _ in range(n)]
    crust = [tuple(map(int, input().split())) for _ in range(m)]
    
    ang = [math.atan2(y, x) for x, y in crust]
    ang.sort()
    ang2 = ang + [a + 2 * math.pi for a in ang]
    
    ans = 0
    for x, y in toppings:
        a = math.atan2(y, x)
        if a < 0:
            a += 2 * math.pi
        i = bisect_left(ang2, a)
        if i > 0 and i < len(ang2):
            if ang2[i] - ang2[i - 1] <= math.pi:
                ans += 1
    
    return str(ans)

 ## 边缘情况

 当顶部恰好位于两个地壳点定义的边界方向上时，就会出现临界边缘情况。 由于包含条件允许边界点，因此角度比较必须是非严格的。 任何对角度差使用严格不等式的实现都可以排除有效答案。 

另一种边缘情况是地壳点均匀分布但具有略大于 π 的大角度间隙。 如果浮点精度误差使值略高于 π，即使几何上有效，简单的“gap ≤ π”检查也会失败。 使用小 epsilon 或基于整数的叉积推理可以避免此问题。 

最后的边缘情况来自角度 0 处的环绕。在不复制角度数组的情况下，接近 0 弧度的顶部可能会错误地出现在有效间隔之外，即使它位于最后一个和第一个地壳点之间。 重复的数组确保这种情况被统一视为直线而不是圆中的间隔。
