 ## 解决方案
 ## 问题理解

 睡莲通过直茎附着在湖底。 最初，茎是完全垂直的，因此花位于湖床上根点的正上方。 花漂浮在水面上方已知的高度\(H\)。 

然后我们模拟当花沿着水面水平拉动一段距离时会发生什么\(L\)。 茎保持笔直且刚性，因此它作为锚定在底部点的单个节段旋转。 在问题描述的时刻，花刚刚到达水面。 

任务是确定茎附着点处的湖泊深度。 

从几何角度来看，这变成了一个直角三角形问题。 茎是斜边，长度固定，连接湖底和花。 最初，从底部到花的垂直距离是茎的全长减去水深。 水平拖动花朵后\(L\)，垂直高度恰好等于湖水深度，因为花现在位于水面上。 

限制条件\(1 \le H < L \le 10^6\)表明一切都适合浮点运算，我们可以安全地依赖标准双精度，而不必担心溢出或极端数量级的数值不稳定。 

一个可能混淆天真的推理的微妙问题是混淆了哪个部分对应于茎长度。 茎不简单\(H + \text{depth}\); 仅适用于初始垂直配置。 旋转后，几何形状发生变化，正确的关系来自于茎的长度不变与水平位移和垂直落差形成的直角三角形。 

## 方法

 如果我们纯粹用代数的方式思考，我们可以引入未知数。 设湖水深度为\(D\)。 那么茎的长度就是\(D + H\)，因为最初花是\(H\)高于表面。 拖动后，花躺在水面上，所以茎的垂直投影正好变成\(D\)，而水平位移为\(L\)。 这形成一个直角三角形，其中斜边是\(D + H\), 一条腿是\(D\)，另一个是\(L\)。 

从毕达哥拉斯定理我们得到：$$
(D + H)^2 = D^2 + L^2
$$扩展和简化删除\(D^2\)从双方来看：$$
D^2 + 2DH + H^2 = D^2 + L^2
$$
$$
2DH + H^2 = L^2
$$
$$
D = \frac{L^2 - H^2}{2H}
$$强力方法是每次猜测深度并模拟几何形状，检查所得的茎长度是否符合一致性约束。 这需要迭代所有可能的深度，直到\(10^6\)，这是不必要和浪费的，因为关系是代数和直接的。 

关键的观察结果是系统完全由单个二次方程确定。 一旦几何约束被正确转换，解决方案就立即出现。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 暴力破解（猜测深度）| \(O(L)\) 或更糟 | \(O(1)\) | 太慢了 |
 | 代数推导| \(O(1)\) | \(O(1)\) | 已接受 |

 ## 算法演练

 1. 读取整数\(H\)和\(L\)。 这些定义了水面之上的初始高度和拖动后的水平位移。 

2. 将几何转化为直角三角形关系，其中茎长度恒定并且等于\(D + H\)。 此步骤将物理设置转换为代数。 

3. 应用毕达哥拉斯定理：$$
   (D + H)^2 = D^2 + L^2
   $$这捕获了不变的茎长度和旋转后的正交分解。 

4. 展开并取消两边相同的项，以隔离未知数\(D\)。 由于对称性，这种简化以干净的方式消除了二次项。 

5. 求解所得线性方程\(D\):$$
   D = \frac{L^2 - H^2}{2H}
   $$6. 输出\(D\)作为具有足够精度的浮点数。 

### 为什么它有效

 整个结构依赖于固定长度的刚性部分。 该固定长度在旋转时不会改变，因此茎端点的唯一有效配置位于以湖底点为中心、半径为半径的圆上\(D + H\)。 最终位置形成一个直角三角形，其斜边是该半径，其腿是水平位移\(L\)和垂直深度\(D\)。 因为这个几何约束唯一地确定了三角形，所以计算表达式为\(D\)是唯一与初始配置和最终配置一致的值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

H, L = map(int, input().split())

D = (L * L - H * H) / (2 * H)
print(D)
```该解决方案直接实现了导出的封闭式公式。 使用Python浮点除法就足够了，因为所需的精度仅为\(10^{-6}\)，中间值最多为\(10^{12}\)，在这种情况下，它们在双精度的精确表示范围内。 

减法\(L^2 - H^2\)是安全的，因为这两个值在转换前都适合 64 位整数。 划分由\(2H\)以浮点形式执行，确保最终结果为所需的实数。

 ## 边缘情况

 当\(H\)是最小的，例如\(H = 1\)和\(L = 2\)，计算简化为一个小整数算术表达式，并确认该公式不依赖于缩放。 该算法直接计算\(D = (4 - 1)/2 = 1.5\)，这与预期的几何配置相匹配。 

什么时候\(L\)仅略大于\(H\), 分子\(L^2 - H^2\)仍然为正但很小，产生一个浅湖。 减法步骤是安全的，因为两个平方都适合 64 位整数，并且除法会产生稳定的浮点结果。 

什么时候\(L\)相对于来说非常大\(H\)，深度以二次方增长\(L\)。 该公式仍然可以正确运行，因为 Python 整数在转换为浮点数之前会处理较大的中间值，从而确保整数阶段不会溢出或精度损失。
