 ## 解决方案
 ## 问题理解

 我们被要求对博物馆内两个朋友的随机运动进行建模，该博物馆表示为具有 _n_ 个房间和 _m_ 个走廊的无向连通图。 每个房间都有概率在原地停留一分钟，否则该人统一移动到相邻的房间。 任务是计算每个房间两个朋友在该房间相遇的概率。 Petya 和 Vasya 的初始位置已给出。 仅当双方同时占用同一个房间时才会发生会议； 在走廊里互相擦肩而过不算数。 

_n_ 的小值（最多 22）表明我们可以承受 _n_ 平方指数的运算，因为系统的状态空间（两个朋友的位置对）最多有$n^2 = 484$州。 这使得涉及联合概率的完全枚举或求解线性系统的方法变得可行。 给出的概率最多有四位小数，因此我们必须至少保持双精度浮点精度以满足以下误差要求：$10^{-6}$。 

一个重要的边缘情况是两个朋友在同一个房间开始。 那么该房间的概率应为 1，所有其他房间的概率应为 0，即使停留概率小于 1。另一个微妙的场景是对称图，其中某些房间通过连接性无法区分，这可能导致在这些房间中会面的概率相等。 如果简单的算法无法考虑适当的标准化或同时移动，则输出将关闭。 

## 方法

 暴力方法会尝试每分钟模拟所有可能的轨迹。 我们将维护所有可能的位置对的概率分布，并根据移动规则迭代更新它们。 这在原则上是正确的，但可能需要模拟无限多分钟，因为该过程是随机的，并且可能不会在有限数量的步骤中收敛。 收敛可能很慢，尤其是当停留概率接近 1 时。这使得简单的模拟变得不切实际。 

关键的见解是将问题建模为两个朋友的联合状态空间上的吸收马尔可夫链。 每个状态都是一对房间$(i, j)$。 如果$i = j$，状态很吸引人（他们已经见面了）。 否则，下一个状态的概率由停留概率和图的邻接性确定。 每个房间相遇的概率相当于计算每个吸收状态的吸收概率。 线性代数给出了一个直接的解决方案：建立一个线性方程组，其中每个非吸收状态用邻居表示其吸收概率。 因为$n^2 \le 484$，我们可以使用标准高斯消元法求解该系统。 

这种方法之所以有效，是因为马尔可夫链是有限的，所有状态最终以概率 1 达到吸收状态（图是连通的，停留概率小于 1），并且线性方程准确地捕获了预期吸收概率的递归结构。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 模拟| 潜在无限 | O(n²) | 对于精确的概率来说太慢了 |
 | 吸收马尔可夫链（线性系统）| 朴素高斯最坏情况为 O(n⁶)，实际 << 2s | O(n⁴) | 已接受 |

 ## 算法演练

 1. 根据走廊输入构建图形的邻接表。 另外，记录每个房间的度数，以便于邻居之间的概率分布均匀。 
2. 枚举所有状态$(i, j)$， 在哪里$i$是 Petya 的房间$j$是瓦夏的房间。 有$n^2$州。 确定吸收态$i = j$。 为这些状态分配一个概率向量，在他们自己的房间中为 1，在其他地方为 0。 
3. 对于每个非吸收状态$(i, j)$，写一个线性方程，表达下一分钟转换的会议概率向量。 Petya 可以留在$i$有概率$p_i$或者以概率移动到每个邻居$(1-p_i)/\text{deg}(i)$。 对于瓦夏来说也是如此。 使用乘积规则结合两者的选择，因为运动是独立的。 这给出了接下来的状态的加权和。 
4. 构建线性系统：每一行对应于一个状态的概率向量的一个分量。 对角线条目说明自我贡献（保持在同一状态），非对角线条目说明转换。 对于非吸收态，右侧为零，但吸收贡献除外，吸收贡献是表示吸收态概率向量的常数。 
5. 使用高斯消元法或任何适合小型密集系统的求解器求解线性系统。 从解中提取每个房间对应的每个吸收状态的会议概率。 
6. 按房间顺序输出概率。 

为什么它有效：方程组正确地模拟了马尔可夫链的预期吸收概率。 每个非吸收状态的方程递归地编码最终到达每个吸收状态的概率。 由于链是有限的、连通的，并且所有停留概率都小于1，所以系统严格对角占优，并且有唯一解。 因此，该算法输出精确的满足浮点精度的概率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m, a, b = map(int, input().split())
a -= 1
b -= 1
adj = [[] for _ in range(n)]
deg = [0]*n
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)
    deg[u] += 1
    deg[v] += 1

p = [float(input()) for _ in range(n)]

size = n*n
id_map = {}
inv_map = []
idx = 0
for i in range(n):
    for j in range(n):
        id_map[(i,j)] = idx
        inv_map.append((i,j))
        idx += 1

import numpy as np
A = np.zeros((size, size))
B = np.zeros((size, n))

for i in range(n):
    for j in range(n):
        idx = id_map[(i,j)]
        if i == j:
            A[idx, idx] = 1
            B[idx, i] = 1
        else:
            A[idx, idx] = 1
            petya_moves = [i] + adj[i]
            petya_probs = [p[i]] + [(1-p[i])/deg[i]]*deg[i]
            vasya_moves = [j] + adj[j]
            vasya_probs = [p[j]] + [(1-p[j])/deg[j]]*deg[j]
            for pi, pp in zip(petya_moves, petya_probs):
                for vj, vp in zip(vasya_moves, vasya_probs):
                    if pi == i and vj == j:
                        continue
                    A[idx, id_map[(pi,vj)]] -= pp*vp

X = np.linalg.solve(A, B)
res = X[id_map[(a,b)]]
print(" ".join(f"{x:.10f}" for x in res))
```代码首先读取图表和停留概率。 然后它枚举所有$n^2$联合声明并设置密集线性系统中的转移概率。 该系统是用 NumPy 解决的`linalg.solve`。 使用数组而不是字典作为矩阵索引可确保数值稳定性和性能。
