 ## 解决方案
 ## 问题理解

 我们被要求为每个测试用例构建一个列表`n`总和等于目标值的不同整数`k`，同时将每个选定的数字保持在范围内`[-10^9, 10^9]`。 

输出不是唯一的，只要所有值成对不同并且它们的总和匹配，则接受任何有效序列`k`。 这是一个经典的构造性问题，其中主要困难是同时满足独特性约束和精确和约束。 

约束条件很大，最多可达`2 × 10^5`测试用例和所有用例的总和`n`跨测试范围为`2 × 10^5`。 这立即排除了任何二次构造或基于重复试验的生成。 每个测试用例必须在线性或恒定时间内解决，因为即使`O(n)`每个测试用例已经很紧张，但总体上仍然可以接受。 

关键的非明显边缘情况是`n = 1`。 在这种情况下，我们被迫输出正好等于一个数字`k`。 这始终有效，只要`|k| ≤ 10^9`，这是由约束保证的，因此这里不会出现特殊的故障。 

当出现一个更微妙的问题时`k`很小或为零并且`n`很大。 一个天真的想法，比如挑选`1, 2, ..., n`仅当我们可以自由移动或调整序列时才起作用，但只有当我们同时保留独特性和界限时，单独移动才能以受控方式打破总和约束。 

另一种失败模式是尝试贪婪地选择数字，直到总和接近`k`然后修复剩余部分。 这很容易破坏清晰度，因为最后的更正通常会重复现有值或超出界限。 

## 方法

 一个蛮力的解释是尝试选择`n`范围内的不同整数`[-10^9, 10^9]`，检查它们的总和，并调整直到匹配`k`。 即使我们假设我们可以以某种系统的方式选择候选者，组合的数量也是巨大的，甚至每个测试用例的线性调整也会导致重复扫描和冲突解决。 在最坏的情况下，这至少会变成`O(n^2)`所有调整中的行为。 

结构观察是我们实际上不需要任何复杂的组合。 我们只需要一组基本的`n`其总和很容易计算的不同数字，然后进行受控转换，在保留明确性的同时将总和调整为精确值`k`。 

一个自然的起点是序列`0, 1, 2, ..., n-1`。 这已经很明显并且易于管理。 其总和为`S = n(n-1)/2`。 如果我们可以自由地添加一个恒定的转变`d`对于每个元素，新的总和变为`S + n·d`，这意味着我们可以准确地达到`k`通过选择`d = (k - S) / n`。 问题是这仅在以下情况下有效`(k - S)`可以整除`n`，这是无法保证的。 

因此，我们不是统一移动所有元素，而是修改结构，以便我们仍然可以全局控制总和，但保留足够的调整自由度。 

一个更强大的技巧是构建`n-1`首先选择不同的数字，然后选择最后一个数字来强制求和。 唯一剩下的问题是确保最终数字与之前的数字不同并且在范围内。 

我们可以选择`n-1`例如，从大的负偏移量开始的连续整数`-10^6, -10^6 + 1, ..., -10^6 + (n-2)`。 它们的总和是准确已知的，并且仍然远离上限。 然后我们将最后一个值计算为`k - sum(first n-1 elements)`。 由于范围限制是`10^9`， 和`k`也有界于`10^8`，我们可以安全地选择偏移量，以便计算出的最后一个值不会与范围或构造的序列发生冲突。 

如果发生冲突，我们会稍微调整基本集，例如在构造中使用间隙，例如跳过中间的一个值或使用对称对。 一个更简单和标准的细化是构建`n-1`不同的数字为`1, 2, ..., n-1`然后将最后一个元素设置为`k - (n-1)n/2`。 如果最后一个值与现有值发生冲突，我们会将整个块移动一个大常数（例如`10^6`），这样冲突就消失了，同时保持了清晰度。 

这导致每个测试用例具有恒定时间调整逻辑的直接线性构造。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) 或更糟 | O(n) | 太慢了|
 | 最佳 | 总共 O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将使用基本算术块和最终校正元素独立构造每个序列。 

1. 对于每个测试用例，首先选择`n-1`连续整数：`a[i] = i`为了`1 ≤ i ≤ n-1`。 这可以立即保证清晰性，无需任何额外的记账。 
2. 计算这些的总和`n-1`使用公式的元素`S = (n-1)n/2`。 
3. 将最后一个元素设置为`x = k - S`。 这确保总和恰好变成`k`一次`x`已附加。 
4. 检查是否`x`与任何值发生冲突`[1, n-1]`。 如果不存在，则直接输出序列。 
5.如果`x`在范围内`[1, n-1]`，我们必须修复建筑。 例如，将整个基本序列移动足够大的常数`C = 10^6`，生产`a[i] = i + C`。 相应地重新计算总和并重新定义`x = k - sum(a[1..n-1])`。 
6. 输出移位后的序列加上`x`。 这一转变确保了`x`不能落入构造块内，因为该块现在位于`[C+1, C+n-1]`， 尽管`x`是独立确定的。 

关键思想是我们只调整一个自由度，即最终元素，同时确保结构的其余部分是刚性且无碰撞的。 

### 为什么它有效

 施工保证了第一`n-1`元素在设计上始终是不同的，无论是作为连续整数还是作为移位块。 最终元素纯粹由总和等于的要求来定义`k`。 由于所有先前的元素在计算之前都是固定的，因此通过构造可以完全满足总和约束。 

独特性之所以成立，是因为我们明确避免了计算出的最后一个值与所选块之间的重叠。 可选的移位步骤确保即使是计算出的最后值落在初始范围内的病态情况也可以通过分离值域来消除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    C = 10**6

    for _ in range(t):
        n, k = map(int, input().split())

        if n == 1:
            print(k)
            continue

        # base block: 1..n-1
        s = (n - 1) * n // 2
        x = k - s

        # if collision, shift block
        if 1 <= x <= n - 1:
            base = [i + C for i in range(1, n)]
            s = sum(base)
            x = k - s
            print(*base, x)
        else:
            base = list(range(1, n))
            print(*base, x)

if __name__ == "__main__":
    solve()
```该代码完全遵循所描述的结构。 特殊情况`n == 1`立即处理，因为除了返回之外不需要任何结构`k`。 

碰撞检查确保最终元素不会重复任何基本元素。 当检测到碰撞时，整个基数会平移一个大常数，以便新的范围远离任何合理的值`x`。 

## 工作示例

 考虑`n = 5, k = 15`。 

我们首先构建`1, 2, 3, 4`。 他们的总和是`10`。 最后一个元素是`15 - 10 = 5`。 这会与底座发生碰撞，因此我们使用移位结构。 

| 步骤| 基本数组 | 总和| 最后一个元素 |
 | --- | --- | --- | --- |
 | 初始| [1,2,3,4]| 10 | 10 5 |

 换档后通过`C = 1e6`，基数变为`[1000001, 1000002, 1000003, 1000004]`。 他们的总和是`40000010`。 最后一个元素变成`15 - 40000010 = -39999995`。 

| 步骤| 基本数组 | 总和| 最后一个元素 |
 | --- | --- | --- | --- |
 | 转移| [1000001, 1000002, 1000003, 1000004] | 40000010 | -39999995 | -39999995

 这演示了移位如何在保持正确性的同时干净地避免碰撞。 

现在考虑`n = 2, k = 0`。 

基数是`[1]`，总和是`1`。 最后一个元素是`-1`，不会发生碰撞。 

| 步骤| 基本数组 | 总和| 最后一个元素 |
 | --- | --- | --- | --- |
 | 建筑 | [1] | 1 | -1 |

 输出`[1, -1]`是有效的、独特的并且总和为`0`。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | 所有测试的总计 O(n) | 每个测试输出 n 个元素一次 |
 | 空间| O(1) 额外（除了输出） | 每次测试仅构造一个小型基本数组 |

 该结构的输出大小是线性的，这是最佳的，因为我们必须打印`n`无论如何。 除了输出缓冲之外，内存使用量保持不变。 

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    C = 10**6
    out = []

    for _ in range(t):
        n, k = map(int, input().split())

        if n == 1:
            out.append(str(k))
            continue

        s = (n - 1) * n // 2
        x = k - s

        if 1 <= x <= n - 1:
            base = [i + C for i in range(1, n)]
            s = sum(base)
            x = k - s
            out.append(" ".join(map(str, base + [x])))
        else:
            base = list(range(1, n))
            out.append(" ".join(map(str, base + [x])))

    return "\n".join(out)

# sample-like tests
assert run("2\n5 15\n2 0\n") != "", "basic functionality"

# n = 1 edge
assert run("1\n1 100\n") == "100", "single element case"

# small positive
assert run("1\n3 6\n") != "", "simple construction"

# negative sum target
assert run("1\n4 -10\n") != "", "negative target"

# large n boundary
assert run("1\n5 0\n") != "", "collision case"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 |`1 100`|`100`| 单元素边缘情况 |
 |`3 6`| 有效的类似排列的输出 | 基本结构正确性|
 |`4 -10`| 有效的不同整数 | 负面目标处理|
 |`5 0`| 有效的移位或未移位块 | 碰撞解决 |

 ## 边缘情况

 的`n = 1`case 是最受限制的场景。 算法直接输出`k`，这是安全的，因为不存在独特性冲突。 

对于像这样的碰撞情况`n = 5, k = 15`，未平移的结构产生`x`在基本集合内，但移位步骤将所有基本元素重新定位到不相交的范围，从而保证重新计算的`x`位于该范围之外。 

对于负面目标，例如`k = -10^8`，最终元素变成一个大负数，但仍在范围内，因为基本和最多约为`10^10`对于最大的`n`，并且移位可确保不会溢出或碰撞。
