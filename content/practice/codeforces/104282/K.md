 ## 解决方案
 ## 问题理解

 我们被要求计算从 1 到 n 范围内的四个素数组成的特殊组。 每组由索引 a、b、c、d 组成，所有四个数字都是素数，并且它们形成具有恰好三个相等间隙的算术级数。 换句话说，一旦我们选择了第一个素数a和步长gap，剩下的三个值就完全确定为a+gap、a+2·gap和a+3·gap，并且它们也都必须是素数且不超过n。 

输入是一个整数 n，它定义了我们可以使用的值域。 输出是有效四元组的数量。 

约束 n ≤ 10^6 强烈表明任何尝试直接枚举所有四元组的解决方案都太慢。 10^6 以内的素数数量约为 78,000 个，检查其中的所有 4 元组已经远远超出了可接受的限制，因为这将是 O(P^4) 的量级。 即使尝试所有对作为开始也会导致 O(P^2)，这是边界，但如果仔细优化，仍然可能可以接受； 然而，每对幼稚的间隙探索仍然会面临 TLE 的风险。 

一个关键的结构约束是我们没有选择任意的素数四元组。 等差条件将结构折叠为长度为四的算术级数。 这意味着每个有效的解决方案都是通过选择第一个元素和步长来唯一确定的。 

不存在涉及排序的棘手极端情况，因为 a < b < c < d 隐含着正间隙。 唯一微妙的边缘情况来自边界溢出：如果 a + 3·gap 超过 n，则序列无效并且不能被计数。 

一个幼稚的错误是迭代所有素数并在它们之后尝试所有可能的三元组而不强制执行恒定的间距。 例如，如果只检查成对的相对差异而不是强制执行单个一致的间隙，则可能会意外地考虑选择素数 (5, 11, 17, 29)。 

## 方法

 直接的蛮力方法是生成直到 n 的所有素数，然后按升序尝试其中的每个四元组，并检查它们是否形成算术级数。 这将涉及素数列表上的四个嵌套循环。 如果有 P 个素数，则该方法执行 P^4 / 24 个检查的顺序，当 P 约为 78,000 时，这是完全不可行的。 

即使我们限制自己动态检查算术级数，如果我们修复 a 和 b 并尝试强制 c 和 d，我们仍然面临立方结构。 这导致 O(P^3)，但仍然太大。 

关键的观察结果是，四个素数的算术级数完全由两个参数决定：第一个元素和差值。 一旦我们固定了 a 和 b，差值就被强制为 b − a，剩下的两个值是唯一确定的。 这将问题简化为检查 a + 2d 和 a + 3d 是否为素数。 

这将问题从组合枚举转移到通过恒定时间素性检查对素数进行结构化搜索。 当筛子达到 n 时，每次检查都会变成 O(1)，候选对 (a, b) 的总数约为 P^2 / 2，如果仔细实现的话，在优化的 Python 中 P ≈ 78,000 是可以管理的，但仍然接近极限。 然而，我们可以通过仅迭代素数作为索引并在级数超过 n 时提前中断来减少不必要的工作。 

改进不仅在于加快素性检查，还在于将条件压缩为成对而不是完整四元组的确定性构造。

 ## 算法演练

 ## 第 1 步：构建最多 n 的素数查找

我们首先计算直到 n 的埃拉托色尼筛，将每个数字标记为素数或非素数。 这允许稍后进行常量时间素性检查，这是至关重要的，因为我们将验证从算术级数导出的许多候选值。 

## 步骤 2：提取素数列表

 我们将 2 到 n 之间所有标记为素数的整数收集到一个数组中。 这为我们提供了算术级数有效起点的紧凑表示。 

## 步骤 3：迭代级数的第一个元素

 对于列表中的每个素数 a，我们将其视为长度为 4 的算术级数的潜在开始。 目标是选择第二个素数 b > a 来定义步长。 

我们修复第一个元素的原因是每个级数都有一个递增顺序的唯一起点，因此这可以避免过度计数排列。 

## 步骤 4：选择第二个元素并计算步骤

 对于 a 之后的每个素数 b，我们定义 d = b − a。 这一步完全决定了级数，因为一旦确定了两个点，算术序列就变得严格了。 

如果我们后来尝试独立选择c，我们将失去等间距的保证，因此这种减少是必要的。 

## 步骤 5：验证剩余两个元素

 我们计算 c = b + d 和 d4 = c + d = a + 3·d。 我们使用筛子检查是否都 ≤ n 并且都是素数。 如果两个条件都成立，我们就计算这个四倍。 

这一步是唯一过滤掉无效候选人的地方。 筛子确保每次检查的时间复杂度为 O(1)，从而保持整体解决方案的高效。 

## 第 6 步：累计计数

 每个有效级数都贡献一个计数，因为 (a, b, c, d) 是严格递增的并且是从 (a, b) 唯一生成的。 我们将所有有效案例相加并输出结果。 

## 为什么它有效

 每个有效的四元组恰好对应于一对有序的素数 (a, b)，其中 a < b。 该对唯一地定义了差值 d = b − a，从而唯一地定义了其余两个元素。 相反，任何在位置 a + 2d 和 a + 3d 处产生有效素数的对对应于有效解。 这在有效四元组和有效生成对之间建立了一对一的映射，确保没有多算或遗漏。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    if n < 2:
        print(0)
        return

    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False

    i = 2
    while i * i <= n:
        if is_prime[i]:
            step = i
            start = i * i
            while start <= n:
                is_prime[start] = False
                start += step
        i += 1

    primes = [i for i in range(2, n + 1) if is_prime[i]]

    idx = {p: True for p in primes}

    m = len(primes)
    ans = 0

    for i in range(m):
        a = primes[i]
        for j in range(i + 1, m):
            b = primes[j]
            d = b - a
            c = b + d
            d4 = c + d

            if d4 > n:
                break

            if is_prime[c] and is_prime[d4]:
                ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```筛子部分构造一个布尔数组，其中每个索引直接回答稍后在恒定时间内使用的素性查询。 嵌套循环迭代所有有序素数对 (a, b)，但当第四个元素超过 n 时，内部循环会提前中断，这可以防止大间隙中不必要的检查。 

c 和 d4 的计算直接编码算术级数约束，确保我们永远不需要显式迭代第三和第四个元素。

 ## 边缘情况

 对于 n = 2 或 n = 3，筛子产生素数，但不可能有四元组，因为我们需要四个不同的素数。 该算法立即返回零，因为素数列表太短，无法存在任何对 (a, b)。 

对于像 n = 10 这样的小范围，筛子可以正确识别素数，但内部循环永远不会形成有效的级数，因为即使是最小的间隙也会很快产生范围之外的值或非素数值。 d4 > n 上的早期中断条件确保我们不会尝试无效访问。 

对于存在许多素数的较大 n，该算法仍然保持安全，因为每个候选级数都使用筛子在最后两个位置进行显式验证，从而防止因不完整的算术结构检查而出现误报。
