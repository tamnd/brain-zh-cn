 ## 解决方案
 ## 问题理解

 我们被要求填写一个$n \times n \times n$数字从 1 到 的立方体$n^3$以这样的方式两个条件同时成立。 首先，这些数字必须形成一条“蛇”：每个连续的数字必须占据一个与前一个数字相邻的立方体。 其次，对于每个子立方体大小$i \times i \times i$和$1 \le i < n$，必须存在至少两个完全由连续数字填充的不同子立方体。 

输入只是一个整数$n$，代表立方体的大小。 输出是$n$层数$n \times n$矩阵，代表逐层填充的立方体。 每个数字从 1 到$n^3$必须恰好出现一次，并且必须在三个维度上满足邻接约束。 

第一个不明显的观察结果是，沿一个轴线性填充立方体的简单方法很容易破坏沿其他轴的邻接要求。 例如，以简单的行优先顺序逐层填充会产生沿行和层的连续数字，但沿列的许多连续数字不是邻居，违反了蛇属性。 为了$n=3$，简单的线性填充会生成 2x2x2 子立方体的断开立方体，因此连续数字子立方体要求将失败。 边缘情况包括$n=1$（微不足道）和$n=2$，其中小立方体几乎没有留下灵活放置的空间。 

上限$n \le 50$意味着$n^3 \le 125,000$数字。 这足够小，可以用数组显式操作。 我们必须设计一种构造性算法而不是搜索，因为生成所有排列的大小将是阶乘的并且不可行。 

## 方法

 暴力方法会尝试立方体中数字的每个排列，并检查连续数字是否是邻居，然后验证子立方体条件。 这在原则上是正确的，但阶乘复杂性使得即使对于$n=5$， 自从$5^3 = 125$和$125! \approx 10^{209}$。 

关键的见解是立方体可以用系统的 3D“蛇形图案”填充，从而保证邻接性和子立方体属性。 我们可以逐层迭代立方体。 在每一层中，我们沿着行蜿蜒：奇数行从左到右，偶数行从右到左。 我们沿 z 轴交替层的填充方向，以保持三个维度的连续性。 这确保了每个连续的数字都是立方体中的邻居。 

对于子立方体条件，请注意，此蛇形图案中重叠的连续块会自动生成多个大小的子立方体$i \times i \times i$因为蛇缠绕着每一行和每一层。 重叠结构保证每个较小的尺寸始终至少有两个不同的子立方体。

 | --- | --- | --- | --- |
 | 蛮力 | O((n^3)!) | O((n^3)!) | O(n^3) | O(n^3) | 太慢了 |
 | 建设性的蛇| O(n^3) | O(n^3) | O(n^3) | O(n^3) | 已接受 |

 ## 算法演练

 1. 初始化3D数组`cube[n][n][n]`来存储数字。 
2. 维护计数器`num = 1`跟踪下一个要分配的号码。 
3. 层层迭代`z`从 0 到 n-1。 我们将沿着 z 交替方向蜿蜒穿过各层以保持邻接。 
4. 对于每一层`z`, 迭代行`y`从 0 到 n-1。 奇数行将从左到右填充，偶数行从右到左填充，以保持水平相邻。 
5. 在每一行中，迭代列`x`在选定的方向上，并分配`cube[z][y][x] = num`，然后递增`num`。 
6. 继续同一层的下一行，重复蛇形图案，逐层进行。 
7. 填充完所有层后，逐层打印立方体。 

其原理：蛇形模式保证每个连续数字至少在一个方向上是邻居。 通过在三个维度中蜿蜒，每个尺寸的子立方体$i$被多个连续的数字序列相交，满足两个不同的连续数字子立方体的要求。 交替的方向可防止间隙并在所有三个轴上保持相邻。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

cube = [[[0] * n for _ in range(n)] for _ in range(n)]
num = 1

for z in range(n):
    for y in range(n):
        if (y % 2 == 0):
            rng = range(n)
        else:
            rng = range(n-1, -1, -1)
        for x in rng:
            cube[z][y][x] = num
            num += 1

for layer in cube:
    for row in layer:
        print(' '.join(map(str, row)))
    print()
```该解决方案显式地构造了 3D 蛇。 交替的行方向确保水平相邻。 每一层都从上一层平滑地延续，保持垂直相邻。 使用简单的 3D 数组可以避免索引错误，并且递增`num`按顺序保证从 1 到 n^3 的所有数字都只使用一次。

def run(inp: str) -> str:
