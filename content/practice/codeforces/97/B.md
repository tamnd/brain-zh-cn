 ## 解决方案
 ## 问题理解

 我们从平面上一组不同的格点开始。 我们可以添加更多的点，并且最终的集合必须满足每对点的几何条件。 

取任意两点。 如果它们已经共享相同的 x 坐标或相同的 y 坐标，则它们自动有效。 否则，它们形成轴对齐矩形的对角。 该条件表示该矩形必须至少包含该集合中的一个其他点，无论是在矩形内部还是在其边界上。 

任务不是最小化添加点的数量。 我们只需要构造一些更大的集合来满足条件并且仍然保持在下面`2 * 10^5`点。 

输入大小足够小以允许`O(n^2)`处理，因为`n ≤ 10^4`。 二次算法的执行情况约为`10^8`最坏情况下的原始操作，已经接近 Python 中的实际极限，因此任何速度慢得多的操作都是有风险的。 立方方法是完全不可能的。 输出限制远大于输入大小，这强烈暗示预期的解决方案是建设性的：我们可以添加许多精心选择的辅助点。 

棘手的部分是准确理解矩形内的有效见证点。 额外的点可能位于边界上，不一定严格位于内部。 此外，见证点必须与两个端点不同。 

一个常见的错误想法是独立连接每一对。 例如：```
2
1 1
2 2
```如果我们添加`(2,1)`，形成的矩形`(1,1)`和`(2,2)`包含`(2,1)`在其边界上，因此该对变得有效。 但是，如果我们稍后独立处理另一对并意外地重复使用不再在全局范围内成立的假设，则构造可能会超出点限制。 

当点已经共享坐标时，会出现另一种微妙的情况：```
3
1 5
1 9
4 7
```这对`(1,5)`和`(1,9)`已经有效，因为它们是垂直对齐的。 尝试为每一对添加辅助点的粗心实现可能会生成不必要的点并溢出输出限制。 

最危险的误解是假设每个矩形都需要严格位于其内部的一个点。 考虑：```
2
0 0
5 5
```添加`(0,5)`就足够了，因为它位于矩形边界上。 拒绝边界点会导致结构过于复杂。 

## 方法

 蛮力思维很简单。 对于每一对具有不同 x 和 y 坐标的点，我们可以尝试插入一个缺失的矩形角，或者`(x1, y2)`或者`(x2, y1)`。 这立即使该对有效。 

问题是涉及插入点的新对可能仍然违反条件。 修复一对可能会产生几个新的坏对。 天真地重复这个过程变得难以控制。 在最坏的情况下，生成点的数量可能呈二次方增长甚至更糟，并且终止的推理变得混乱。 

关键的观察结果是，如果每对点与某个中心结构共享 x 坐标或 y 坐标，则该条件变得微不足道。 我们可以将所有点组织成一个递归的网格状层次结构，而不是一个接一个地固定矩形。 

按 x 坐标对点进行排序。 通过 x 选择中点。 添加一条穿过其 x 坐标的垂直线，但仅在当前段中已存在的 y 值处添加。 然后递归求解左半部分和右半部分。 

假设当前递归段中有两个点。 如果它们位于中位数的相对两侧，则它们的 y 值都出现在中位数垂直线上。 由两点形成的矩形在其边界上包含这些中线点之一，因此该对立即有效。 

如果两个点位于同一侧，则递归调用保证有效性。 

这种分而治之的结构提供了清晰的正确性证明，并控制了生成点的数量。 每个递归级别最多为每个原始点贡献一个额外点，并且只有`O(log n)`水平。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 无界/难以控制| 潜力巨大 | 太慢而且不安全|
 | 最优分而治之| O(n log n) | O(n log n) | O(n log n) | O(n log n) | 已接受 |

 ## 算法演练

 1. 读取所有输入点并按x坐标排序。 
2. 定义递归函数`solve(l, r)`对已排序数组的连续段进行操作。 
3. 如果该段包含零个或一个点，则停止递归。 单个点不会产生任何约束。 
4.选择中间索引`mid = (l + r) // 2`。 设中位数 x 坐标为`xm`。 
5. 对于当前线段内的每个点，添加该点`(xm, yi)`到答案集，其中`yi`是该点的 y 坐标。 

这会在以下位置创建一条垂直连接线`x = xm`。 线段中的每个 y 坐标现在都显示在该线上。 
6. 递归处理左半部分`[l, mid]`。 
7. 递归处理右半部分`[mid + 1, r]`。 

其起作用的原因如下。 考虑任意两个原点。 

如果它们在某个递归级别落入不同的一半，那么在该级别我们创建了点`(xm, y1)`和`(xm, y2)`。 自从`xm`位于它们的 x 坐标之间，这些辅助点之一位于其矩形的边界上，使得该对有效。 

如果这两个点始终位于同一递归一半中，则最终递归到达仅包含这些点的段，并且某些更深的递归级别会处理它们。 

为了避免重复，请将所有生成的点存储在一个集合中。 

### 为什么它有效

 递归不变量是：

 对于每个递归段，处理后，该段内的每一对点都满足所需的条件。 

取线段内的任意一对点。 

如果它们沿着中线分开，则构造会在中线垂直线上添加一个点，其中一个端点的 y 坐标。 该辅助点位于矩形的内部或边界上。 

如果它们保持在同一侧，则处理该侧的递归调用保证有效性。 

由于每对要么在某个递归级别分裂，要么保持在一起直到基本情况，因此所有对最终都会得到处理。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    pts.sort()

    ans = set(pts)

    def dfs(l, r):
        if l >= r:
            return

        mid = (l + r) // 2
        xm = pts[mid][0]

        for i in range(l, r + 1):
            ans.add((xm, pts[i][1]))

        dfs(l, mid)
        dfs(mid + 1, r)

    dfs(0, n - 1)

    print(len(ans))
    for x, y in ans:
        print(x, y)

if __name__ == "__main__":
    solve()
```第一步按 x 坐标对点进行排序，因为分而治之的论点依赖于将平面分成左半部分和右半部分。 

递归函数对数组索引进行操作，而不是创建子数组。 这可以避免重复复制并保持较低的内存使用率。 

中位 x 坐标充当当前段的分隔符。 该段中的每个 y 坐标都会投影到分隔线上。 这是解决方案的核心几何技巧。 

答案存储在Python中`set`因为许多递归调用都会生成相同的辅助点。 如果不进行重复数据删除，输出大小可能会变得不必要的大。 

基本情况`l >= r`很重要。 具有一个点的线段已经满足所有约束，并且进一步的递归将永远循环。 

递归深度最多为`log2(n)`，这对于`n ≤ 10^4`，所以 Python 递归在这里是安全的。

 有`O(log n)`递归级别。 在每个级别，每个点最多贡献一个生成的辅助点。 和`n = 10^4`，总点数保持在以下水平`2 * 10^5`。

 ## 边缘情况

 考虑已经共享 x 坐标的两个点：```
2
4 1
4 9
```排序后，递归立即到达大小为 2 的段。 该算法可能会在同一垂直线上添加辅助点，但重复项会被集合删除。 最终的配置仍然满足条件，因为原始对已经位于同一垂直线上。 

现在考虑最小的非平凡对角线情况：```
2
0 0
5 5
```递归选择中值x坐标`0`并添加`(0,5)`。 所形成的矩形由`(0,0)`和`(5,5)`包含`(0,5)`在其边界上。 该算法无需内点即可成功。 

一个更微妙的情况是许多点共享相同的 y 坐标：```
4
1 7
3 7
5 7
9 7
```每对都已经满足条件，因为所有点都水平对齐。 递归仍然执行其正常构造，但重复项占主导地位，并且最终集合的大小仍然很小。 

最后，考虑负坐标点：```
3
-5 -2
0 4
7 -1
```该算法仅使用现有的 x 坐标和 y 坐标，因此所有生成的辅助点都会自动保持在允许的坐标范围内。
