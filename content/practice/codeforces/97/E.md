 ## 解决方案
 ## 问题理解

 我们得到一个无向图，其中顶点代表人，边代表关系。 对于每个查询`(u, v)`，我们必须判断是否存在一条简单路径`u`到`v`其长度为奇数。 

这里的关键词是“简单”。 我们不允许重新访问顶点。 该图不一定是连通的，并且可能包含环。 

来自每个查询顶点的直接 BFS 是行不通的。 顶点数和边数都可以达到`10^5`，并且还有多达`10^5`查询。 任何每次查询花费线性时间的解决方案都需要大约`10^10`最坏情况下的操作，远远超出极限。 

真正的困难在于一对顶点之间可能同时具有偶数和奇数简单路径。 答案不仅仅由最短路径奇偶性决定。 

考虑这个图：```
1 - 2
|   |
3 - 4
```之间`1`和`2`，有一条奇怪的路径`1-2`，也是一条均匀路径`1-3-4-2`。 该问题仅询问是否存在至少一条奇数简单路径。 

一个常见的错误是认为二分着色可以解决所有问题。 在二分图中，两个顶点之间的所有路径都具有相同的奇偶性，因此着色在那里起作用。 但是，一旦图形包含奇数循环，则两个奇偶校验都可能成为可能。 

例如：```
1 - 2
 \ /
  3
```该三角形包含奇数圈。 之间`1`和`2`，我们有：```
1-2        length 1
1-3-2      length 2
```双方都存在。 任何每对仅存储一个奇偶校验的方法都会失败。 

另一个微妙的情况是查询同一顶点。 

输入：```
3 3
1 2
2 3
3 1
2
1 1
2 2
```输出：```
Yes
Yes
```三角形包含奇数圈，所以顶点`1`可以使用长度为简单的奇数循环返回自身`3`。 粗心的实施可能会错误地回答`"No"`因为空路径有长度`0`。 

断开的组件是错误的另一个来源。 

输入：```
4 1
1 2
2
1 3
3 4
```输出：```
No
No
```根本不存在路径，所以答案一定是`"No"`无论奇偶性如何。 

## 方法

 蛮力的想法很简单。 对于每个查询`(u, v)`，运行跟踪奇偶校验的 BFS 或 DFS。 我们可以将每个顶点复制为两种状态：```
(vertex, parity)
```当穿过边缘时，奇偶校验翻转。 

如果我们能达到`(v, 1)`，则存在一条奇数路径。 

这种方法对于步​​行来说是正确的，但对于简单的路径不一定是正确的。 防止重复的顶点会使搜索变得更加困难。 在一般图中，直接跟踪每个查询的简单路径奇偶校验会变得昂贵。 

即使我们忽略简单性问题并为每个查询运行 BFS，复杂性也会变为：```
O(q(n + m))
```所有值都接近`10^5`，这大约是`10^10`运营。 

关键的观察是结构性的。 

在连接的二分组件内，两个顶点之间的每条路径都有固定的奇偶校验。 如果两个顶点属于同一颜色类，则它们之间的所有路径都是偶数。 如果它们处于相反的类别，则所有路径都是奇数。 

在连接的非二分组件内部，情况完全改变。 存在一个奇怪的循环，这个奇怪的循环让我们翻转路径奇偶校验。 事实上：

 如果连通分量是非二分的，则每对顶点之间都有偶数和奇数简单路径。 

这个事实就瓦解了整个问题。 

所以解决方案就变成了：

 1. 查找连接的组件。 
2. 判断每个组件是否是二分组件。 
3. 如果组件是二分的，则使用顶点颜色来确定奇偶性。 
4. 如果组件是非二分组件，则其中的每一对都会回答`"Yes"`。 

这将在一次 DFS/BFS 预处理通过后将所有查询减少为恒定时间检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个查询的暴力破解 | O(q(n + m)) | O(n + m) | 太慢了 |
 | 最优图预处理 | O(n + m + q) | O(n + m + q) | O(n + m) | 已接受 |

 ## 算法演练

 1. 构建图的邻接表。 

该图是稀疏的，因此邻接表是自然的表示。 
2. 使用DFS或BFS遍历每个连接的组件。 

在遍历过程中，为每个顶点分配一个二进制颜色。 
3. 遍历边缘时`(u, v)`，检查着色一致性。 

如果`u`和`v`已经具有相同的颜色，该组件不是二分的。 
4. 存储每个顶点：

 - 其连接的组件 ID
 - 它的二分颜色
 - 其组成部分是否是二分的
 5. 对于每个查询`(u, v)`:

 1.如果`u`和`v`属于不同的连通分量，打印`"No"`。 

根本不存在任何路径。 
2. 否则，如果该组件是非二分组件，则打印`"Yes"`。 

非二分连通分量包含奇数循环，它允许在任何对之间构建奇数简单路径。 
3. 否则，该组件是二分组件。 

在二部图中，两个顶点之间的所有路径都具有相同的奇偶性。 

打印`"Yes"`如果颜色不同，否则`"No"`。 

### 为什么它有效

 连通图是二分图当且仅当它不包含奇环。 

在二分图中，每条边都连接相反的颜色类别。 任何路径在每一步都会交替颜色，因此两个顶点之间路径的奇偶性由它们的颜色唯一确定。 

如果图是非二分图，则存在奇环。 从之间的任意路径开始`u`和`v`，我们可以通过奇数周期来翻转奇偶校验，同时保持路径简单。 由于组件是相连的，所以每对顶点都可以达到奇数周期并用它来改变奇偶校验。 

这意味着：

 - 二分组件 → 奇偶校验固定
 - 非双方组成部分 → 双方均可用

 该算法会精确检查这些条件，因此每个答案都是正确的。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    graph = [[] for _ in range(n + 1)]

    for _ in range(m):
        u, v = map(int, input().split())
        graph[u].append(v)
        graph[v].append(u)

    comp = [-1] * (n + 1)
    color = [-1] * (n + 1)
    bipartite = []

    cid = 0

    for start in range(1, n + 1):
        if comp[start] != -1:
            continue

        queue = deque([start])
        comp[start] = cid
        color[start] = 0

        ok = True

        while queue:
            u = queue.popleft()

            for v in graph[u]:
                if comp[v] == -1:
                    comp[v] = cid
                    color[v] = color[u] ^ 1
                    queue.append(v)
                else:
                    if color[v] == color[u]:
                        ok = False

        bipartite.append(ok)
        cid += 1

    q = int(input())

    out = []

    for _ in range(q):
        u, v = map(int, input().split())

        if comp[u] != comp[v]:
            out.append("No")
        elif not bipartite[comp[u]]:
            out.append("Yes")
        else:
            out.append("Yes" if color[u] != color[v] else "No")

    print("\n".join(out))

solve()
```预处理阶段对每个连接的组件执行 BFS。 在遍历期间，顶点接收交替的颜色。 

这`comp`数组标识每个顶点属于哪个连接组件。 这会立即回答连接查询。 

这`color`数组存储二分分区。 相邻顶点必须始终接收相反的颜色。 如果我们遇到连接相同颜色的边，则该分量包含奇数循环并被标记为非二分的。 

这`bipartite`list 为每个组件存储一个布尔值。 这使得每个查询在恒定时间内运行。 

一个微妙的实现细节是，即使在检测到颜色冲突后我们仍然继续遍历。 提前停止会使组件的某些部分未被访问并中断以后的查询。 

另一个重要的细节是处理查询，例如`(u, u)`。 在二分组件中，答案是`"No"`因为每个周期都是偶数。 在非二分组件中，答案变为`"Yes"`因为存在奇数循环。

 ## 边缘情况

 考虑一个具有非二分组件和自查询的图。 

输入：```
3 3
1 2
2 3
3 1
1
1 1
```在 BFS 期间，顶点接收颜色：```
1 -> 0
2 -> 1
3 -> 1
```边缘`(2, 3)`连接相同的颜色，因此该组件被标记为非二分组件。 

供查询`(1, 1)`，两个顶点属于同一个非二分组件，因此算法打印`"Yes"`。 

这是正确的，因为循环：```
1-2-3-1
```长度为奇数`3`。 

现在考虑断开的顶点。 

输入：```
4 1
1 2
2
1 3
3 4
```组件变成：```
{1,2}
{3}
{4}
```对于这两个查询，组件 ID 不同，因此算法会立即回答`"No"`。 

这可以避免在根本不存在路径时错误地推理奇偶校验。 

最后，考虑存在多条路径的二部图。 

输入：```
4 4
1 3
3 2
1 4
4 2
2
1 2
1 3
```该图是二分图，并带有颜色：```
1,2 -> 0
3,4 -> 1
```尽管有两条不同的道路`1`到`2`，两者的长度都是偶数：```
1-3-2
1-4-2
```算法给出答案`"No"`因为颜色是相等的。 

为了`(1,3)`，颜色不同，所以答案是`"Yes"`。 

这证实了二分图中的所有路径都具有相同奇偶性的不变量。
