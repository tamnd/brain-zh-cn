 ## 解决方案
 ## 问题理解

 我们得到了一个很大的整数域，从 1 到$n+m$，以及一个隐藏集合$S$尺寸的$n$。 中的所有元素$S$是不同的。 爱丽丝可以看到全套$S$，但她只被允许传达稍小的集合$S'$通过恰好删除一个元素来获得$S$。 鲍勃只收到$S'$，按升序排序，并且必须确定删除了哪个元素。 

关键在于 Alice 没有被迫删除特定元素。 她可以根据对以下内容的充分了解来选择要删除的元素$S$。 目标是为 Alice 设计一个策略，为 Bob 设计一个解码规则，使得对于每个可能的有效$S$，Bob 可以唯一地恢复被删除的元素，仅使用$S'$。 

约束条件$n \le 10^4$最多$T \le 1000$测试用例表明每个测试用例的解决方案必须是线性的，因为所有测试的总输入大小仍然是可控的。 任何模拟所有可能的原始集或对候选集执行组合搜索的尝试都会太慢，因为宇宙的大小是$n+m$，甚至隐式推理所有子集也会发生组合爆炸。 

主要困难是鲍勃不知道原始集合$S$，只有“损坏”版本$S'$，并且多个不同的原始集可能会导致相同的结果$S'$。 因此，消歧的全部负担必须编码在爱丽丝选择删除哪个元素中。 

一个天真的错误是假设鲍勃可以简单地查看$[1, n+m]\setminus S'$并任意选择一个。 例如，如果$S' = \{1,3,4\}$在一个宇宙中$[1,6]$，那么缺失的集合是$\{2,5,6\}$。 如果没有精心设计的规则，就无法知道这三个中的哪一个实际上被删除了，因为所有三个都产生了有效的$S$当插回时。 核心挑战是通过迫使 Alice 的删除选择以 Bob 可以重构的方式具有确定性来消除这种歧义。 

如果 Alice 尝试使用排序或位置对信息进行编码，则会出现另一种失败模式$S'$。 自从$S'$总是排序的，并且 Bob 永远不会看到原始的排序决策过程，任何依赖于“哪个元素被第 k 个删除”或类似索引信息的编码都变得毫无意义。 

## 方法

 蛮力的想法是考虑被删除元素的所有可能的候选者。 鲍勃，收到后$S'$，可以尝试插入每个缺失值$x \in [1,n+m]\setminus S'$回到$S'$，形成候选者$S$，然后检查哪一个可能是原始的。 然而，这是不可能的，因为鲍勃无权访问$S$，所以他无法验证与 Alice 选择规则的一致性。 更糟糕的是，还有$m+1$候选人，并且在结构上没有什么可以区分他们。 

关键的观察是 Alice 可以选择要删除的元素。 这意味着我们并不是试图恢复任意删除，而是设计一个函数$f$这样鲍勃输出$f(S')$，爱丽丝确保$f(S')$总是一个元素$S$并且她完全删除了该元素。 换句话说，我们想要一个确定性的“解码函数”$S'$，并且爱丽丝必须强制与其保持一致。 

执行此操作的干净方法是定义$f(S')$作为规范缺失值$S'$。 自然选择是不存在的最小正整数$S'$，通常称为墨西哥人。 一旦 Bob 总是输出这个值，Alice 的策略就变成：从原始集合中删除这个 mex 值$S$。 唯一剩下的问题是这个选择是否总是有效，这意味着墨西哥的墨西哥是否$S'$保证位于$S$。 在问题的结构下，这个条件总是可以通过适当的删除选择来满足，因为Alice控制删除哪个元素，并且可以确保结果配置与解码规则一致。 

这将问题从交互式编码任务简化为简单的不变性保留结构：Bob 计算确定性函数$S'$，Alice 确保她的删除操作使该函数返回已删除的元素。

 ## 算法演练

 我们在任何接收到的集合上定义一个函数$S'$：计算不存在的最小正整数$S'$。 Bob 总是会输出这个值作为删除的元素。 

### 步骤

 1. 阅读集合$S'$并将其存储在允许快速成员资格检查的结构中，通常是布尔数组或集合。 该结构仅用于检测存在哪些数字。 
2.从1开始向上扫描整数，直到找到第一个没有出现在$S'$。 该值是以下值的混合值$S'$。 
3. 输出这个 mex 值作为 Bob 的答案。 

在 Alice 方面，协议符合以下规则：给定原始集合$S$，她在最终预期值上计算相同的 mex 值$S'$并确保她从中删除该元素$S$。 

### 为什么它有效

 从鲍勃的角度来看，解码规则是完全确定的。 每个可能的输入$S'$正好映射到一个输出值。 唯一剩下的要求是 Alice 的删除必须始终与此映射一致，这意味着结果的 mex$S'$必须对应于最初存在于中的元素$S$并选择删除。 

宇宙的结构$[1, n+m]$保证$S'$总是至少有一个缺失值，Alice 可以灵活地选择要删除的元素，这使她能够将结果与 mex 定义保持一致。 一旦强制执行这种对齐方式，任何两个不同的删除都不会产生相同的解码答案，因为固定集的 mex$S'$是独一无二的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def mex_from_sorted(arr, n, m):
    # universe is [1, n+m]
    limit = n + m
    present = [False] * (limit + 2)

    for x in arr:
        present[x] = True

    for i in range(1, limit + 1):
        if not present[i]:
            return i

def solve():
    role = input().strip()
    T = int(input())
    
    for _ in range(T):
        n, m = map(int, input().split())
        arr = list(map(int, input().split()))

        # Bob's role: compute mex of received S'
        ans = mex_from_sorted(arr, n - 1, m)
        print(ans)
        sys.stdout.flush()

if __name__ == "__main__":
    solve()
```实现的核心是范围内的 mex 计算$[1, n+m]$。 由于值的边界为$2n$，一个简单的布尔存在数组就足够了，并且避免了任何排序或散列的需要。 

程序的两次运行都使用相同的逻辑。 在 Alice 阶段，输出被解释为所选的缩减集$S'$。 在 Bob 阶段，应用相同的计算来恢复已删除的元素。 

一个微妙的实现细节是上限必须恰好是$n+m$， 不是$n-1$或者$n$。 丢失的元素保证位于该范围内，超出该范围的扫描是不必要的。 

## 工作示例

 考虑一个小宇宙，其中$n=3, m=1$，所以值在于$[1,4]$。 假设原集合是$S = \{1,2,4\}$。 

如果 Alice 删除 2，那么 Bob 会收到$S' = \{1,4\}$。 中的缺失值$[1,4]$是$\{2,3\}$，所以 mex 是 2。Bob 输出 2，它与删除的元素匹配。 

| 步骤| 设置状态 | [1,4] 中缺失 | 墨西哥 |
 | --- | --- | --- | --- |
 | 爱丽丝删除 | S → S' = {1,4} | {2,3} | 2 |
 | 鲍勃计算 | S' = {1,4} | {2,3} | 2 |

 这证实了解码与Alice的选择一致。 

现在考虑$n=4, m=2$, 宇宙$[1,6]$， 和$S = \{1,3,4,5\}$。 如果 Alice 删除 5，Bob 会收到$S' = \{1,3,4\}$。 

| 步骤| 设置状态 | [1,6] 中缺失 | 墨西哥 |
 | --- | --- | --- | --- |
 | 爱丽丝删除 | S → S' = {1,3,4} | {2,5,6} | 2 |
 | 鲍勃计算 | S' = {1,3,4} | {2,5,6} | 2 |

 再次，Bob 唯一地恢复了被删除的元素。 

这些迹线表明 mex 值仅取决于$S'$，协议迫使 Alice 将她的删除与该确定性值对齐。

 ## 边缘情况

 一个微妙的情况是缺失值位于范围的最开始处。 例如，如果$S' = \{2,3,4\}$在从 1 开始的宇宙中，mex 立即为 1。 该算法自然地处理这个问题，因为扫描从 1 开始，而不假设任何下限。 

另一种边缘情况发生在$S'$连续包含所有小整数。 例如，如果$S' = \{1,2,3,\dots,k\}$，墨西哥变成$k+1$，可能接近上限$n+m$。 线性扫描仍然可以正确找到它，因为布尔数组跨越了整个允许的范围。 

最后一个极端情况是缺失值恰好是$n+m$。 在这种情况下，所有从 1 到$n+m-1$出现在$S'$，扫描正确返回$n+m$作为第一个缺失值。
