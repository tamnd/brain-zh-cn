 ## 解决方案
 ## 问题理解

 我们在平面上得到一组不同的点。 任务是将这些点分成两个非空组，称为 A 和 B，使得 A 形成的凸包和 B 形成的凸包完全不接触，无论是在它们的内部还是在它们的边界上。 

用更简单的几何术语来说，我们正在寻找两组“橡皮筋形状”完全分开的点，以便在两个所得的凸多边形之间存在间隙。 只要两个组都非空且不相交，我们就可以随意忽略任意数量的点。 

约束的关键几何含义是最多有 500 个点，并且没有三个点共线。 最后一个条件消除了简并性，例如位于单个线段上的许多点，这简化了凸包推理，因为每个凸包顶点都是明确定义的并且严格向左或向右旋转。 

对于 500 个点，O(n log n) 甚至 O(n²) 的解决方案是可以接受的。 任何立方或更糟的东西都是不必要的。 

天真的直觉的一个微妙的失败案例是尝试任意分割点，例如将输入的前半部分作为 A，后半部分作为 B。即使两个集合都非空，它们的凸包也可能会严重重叠。 

例如，四个点按顺序形成一个正方形并按索引对角线分割可以产生两个集合，其凸包都是整个正方形，因此即使这些集合不相交，它们也完全相交。 

这表明分区必须尊重几何形状，而不是输入顺序。 

## 方法

 一个蛮力的想法是尝试所有将点分成两个非空子集的方法，并检查它们的凸包是否相交。 对于每个分区，计算两个凸包的成本为 O(n log n)，并且有 2ⁿ 可能的分区，因此即使对于 n = 30，这种方法也是完全不可行的。 

问题的结构表明我们根本不需要搜索。 我们没有被要求优化任何措施； 我们只需要存在一个有效的分离。 

关键的观察是，如果我们可以找到一个保证严格位于所有剩余点的凸包之外的点，那么我们可以将其隔离为一组。 单个点具有仅由其自身组成的退化凸包，因此如果它位于另一个包的外部，则两个包会自动不相交。 

这减少了寻找整个集合的凸包顶点的任何点的任务。 凸包顶点不能写成其他点的凸组合，这意味着它不能位于删除后剩余点的凸包内部。 

因此，整个问题归结为计算全局凸包并选择其顶点之一。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对子集的暴力破解 | O(2ⁿ·n log n) | O(2ⁿ·n log n) | O(n) | 太慢了 |
 | 凸包顶点选择 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们首先使用标准单调链算法计算所有给定点的凸包。 

1. 按 x 坐标对所有点进行排序，按 y 坐标打破平局。 这给出了建造船体的确定性顺序。 
2. 通过从左到右扫描点来构建下部船体。 每次添加新点时，我们都会从船体中删除最后一个点，而形成的最后一个转弯不是严格的逆时针转弯。 这强制了下边界的凸性。 
3. 通过从右向左扫描，应用相同的凸度条件，以类似方式构造上船体。 
4. 合并两个外壳以获得完整的凸多边形。 该结构中保留的每个点都是整个集合的凸包的顶点。 
5. 选择这些外壳顶点中的任意一个，并将其放入 A 组中。 
6. 将所有剩余点放入 B 组中。

我们只选择单个包顶点的原因是，它保证是完整配置的极值点，因此它不能包含在其余点的凸包中。 

### 为什么它有效

 所有点的凸包是包含它们的最小凸集。 该船体的任何顶点都是某个方向上的极值点，这意味着存在一条支撑线，其中所有其他点严格位于该顶点的一侧。 

如果我们删除这样一个顶点，剩下的点都位于不包含该顶点的凸区域中。 由于凸包在凸组合下是封闭的，因此移除的顶点无法从剩余点重建，这意味着它位于凸包之外。 

因此，A 的凸包是一个点，B 的凸包是一个不包含该点的多边形。 两个不相交的凸集无论在内部还是边界都不能相交，因此满足条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

n = int(input())
pts = []
for i in range(n):
    x, y = map(int, input().split())
    pts.append((x, y, i + 1))

pts.sort()

lower = []
for p in pts:
    while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
        lower.pop()
    lower.append(p)

upper = []
for p in reversed(pts):
    while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
        upper.pop()
    upper.append(p)

hull = lower[:-1] + upper[:-1]

# pick any hull vertex
a_idx = hull[0][2]
A = [a_idx]
B = [p[2] for p in pts if p[2] != a_idx]

print(len(A), len(B))
print(*A)
print(*B)
```该代码使用单调链方法构建凸包。 叉积仅用于强制左转，确保结构保持凸形。 

计算完船体后，我们只需取第一个船体顶点即可。 任何船体顶点都同样有效，因为每个这样的点都保证是极端的。 

剩余的点被收集到 B 中。不需要额外的几何检查，因为凸性保证了分离。

 ## 边缘情况

 一种重要的情况是所有点都位于凸包边界上。 在这种情况下，外壳包含每个点，但任何单个顶点对于隔离仍然有效。 该算法选择一个顶点并将其放入 A 中，将其余点留在 B 中，并且分离仍然成立，因为其余点形成排除该顶点的凸多边形。 

另一种情况是当有很多内点时。 即使这些点从未出现在外壳中，它们也会安全地放入 B 中。B 的凸包可能会比完整外壳缩小，但它仍然不能包含删除的极端顶点。 

最后一个微妙的情况是多个点共享极端坐标，例如多个点具有相同的最大 x 值。 单调链仍然选择真正的极端边界顶点，并且选择其中任何一个就足够了，因为所有顶点都保证位于其余顶点的凸包之外。
