 ## 解决方案
 ## 问题理解

 每个立方体都包含一个两位数的数字。 我们必须分裂`2n`将立方体分成两堆`n`每个立方体。 

分割后，Valera 可以从第一个堆中选择任何立方体，从第二个堆中选择任何立方体。 如果第一个立方体包含`ab`第二个包含`cd`，他得到了四位数字`abcd`。 

堆内的顺序并不重要。 重要的是每个堆中出现哪些_值_。 如果一个值`13`在第一个堆中出现五次，它仍然只提供一个可能的前缀。 同样，如果`45`在第二个堆中出现了 3 次，但它仍然只提供一个可能的后缀。 

假设第一个堆包含`x`不同的值，第二个堆包含`y`独特的价值观。 第一个堆中的每个不同值都可以与第二个堆中的每个不同值配对，因此不同的四位数的数量正好是`x · y`。 

任务是最大化该乘积并输出多维数据集到堆的最佳分配。 

就立方体数量而言，约束很小，仅`2n ≤ 200`，但这些值受到更多限制，因为每个立方值都位于`10`和`99`。 只有 90 种可能的不同值。 这强烈表明该解决方案应该推理值的频率而不是单个立方体。 

一个常见的错误是专注于平衡堆中的立方体数量。 目标取决于每个堆中**不同值**的数量，而不是承载这些值的多维数据集的数量。 

考虑：```
n = 2
13 13 13 45
```放两个`13`s 放入不同的堆中会在每个堆中创建一个不同的值。 第三个`13`没有贡献任何新内容。 唯一可以进一步增加非重复计数的值是`45`。 

另一个微妙的情况是每个值都是唯一的：```
n = 2
10 20 30 40
```两个堆中都不能出现任何值。 最好的策略是尽可能均匀地分割四个不同的值，给出不同的计数`(2,2)`和产品`4`。 粗心的贪婪分配可能会产生`(3,1)`和产品`3`。 

另一个极端：```
n = 2
55 55 55 55
```两个堆都可以包含值`55`，但是两个堆都不能包含任何其他值。 答案是`1`， 不是`4`，因为重复项不会创建新的不同值。 

## 方法

 暴力解决方案会尝试各种方法来选择`n`第一个堆的立方体。 有$$\binom{2n}{n}$$这样的选择。 对于最大输入大小来说，这是一个天文数字。 即使是为了`n = 20`，计数已经超过千亿了。 穷举搜索是不可能的。 

关键的观察是，实际的立方体身份仅通过值频率起作用。 

假设一个值只出现一次。 该值最多可以为一个堆贡献一个不同的值。 

假设一个值至少出现两次。 然后我们可以将一个副本放入每个堆中，使该值同时贡献于两个堆的不同计数。 

让：

-`d`是频率至少为 2 的值的数量。 
-`s`是频率恰好为 1 的值的数量。 

每个重复值都会向每个堆贡献一个不同的值。 如果我们想要最大数量的不同值，则必须强制执行此贡献。 

每个单例值都向一个堆贡献一个不同的值。 唯一剩下的决定是哪个堆接收它。 

如果堆最终是`x`和`y`不同的值，那么：$$x+y = 2d+s$$因为每个重复值贡献两次，每个单例贡献一次。 

产品`x·y`最大化时`x`和`y`尽可能接近。 由于重复值已经对两个堆有相同的贡献，因此我们只需在堆之间尽可能均匀地分配单例值。 

在确定哪个堆接收每个值的“独特贡献”之后，所有剩余的重复多维数据集都变得与目标无关。 它们只能用于满足每个堆精确包含的要求`n`立方体。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(\binom{2n}{n})$|$O(1)$| 太慢了 |
 | 最佳 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 计算每个值出现的频率并记住所有立方体的位置。 
2. 对于频率至少为 2 的每个值，将出现一次的值分配给堆 1，将出现一次的值分配给堆 2。 

这保证了该值向每个堆贡献一个不同的值。 
3. 对于频率恰好为 1 的每个值，在堆之间交替。 

第一个单例进入堆 1，第二个进入堆 2，第三个进入堆 1，依此类推。 

交替使不同值的数量尽可能平衡，从而最大化它们的乘积。 
4. 计算$$x = d + \left\lceil \frac{s}{2} \right\rceil, \qquad y = d + \left\lfloor \frac{s}{2} \right\rfloor$$和输出`x · y`。 
5. 一些多维数据集仍未分配。 这些是至少出现两次的值的额外副本。 
6.让`need1`是堆 1 达到大小所需的额外立方体的数量`n`。 
7.分配第一个`need1`未分配的多维数据集到堆 1，所有剩余的未分配的多维数据集到堆 2。 

这些多维数据集不会更改不同值计数，因为它们的值已经存在于相应的堆中。 

### 为什么它有效

 每个频率至少为 2 的值都可以同时对两个堆做出贡献。 拒绝在每个堆中放置一个副本将减少至少一个堆中不同值的数量，并且永远无法改进产品。 

每个频率为 1 的值总体上只贡献一个不同的值。 当所有重复值被分割后，不同值贡献的总数是固定的：$$x+y=2d+s.$$对于固定总和，当两个数字尽可能相等时，乘积最大化。 交替的单例值恰好产生了平衡分布。 

剩余的副本属于已在堆中表示的值，因此移动它们不会改变`x`或者`y`。 它们仅影响堆大小。 任意填充剩余的槽位可以保持最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    pos = {}
    for i, v in enumerate(a):
        pos.setdefault(v, []).append(i)

    ans = [0] * (2 * n)

    d = 0
    s = 0

    single_heap = 1

    for v, idxs in pos.items():
        if len(idxs) >= 2:
            d += 1
            ans[idxs[0]] = 1
            ans[idxs[1]] = 2
        else:
            s += 1
            ans[idxs[0]] = single_heap
            single_heap = 3 - single_heap

    x = d + (s + 1) // 2
    y = d + s // 2
    best = x * y

    cnt1 = sum(1 for xh in ans if xh == 1)
    need1 = n - cnt1

    for v, idxs in pos.items():
        start = 2 if len(idxs) >= 2 else 1
        for idx in idxs[start:]:
            if need1 > 0:
                ans[idx] = 1
                need1 -= 1
            else:
                ans[idx] = 2

    print(best)
    print(*ans)

if __name__ == "__main__":
    solve()
```字典`pos`存储每个值的所有位置。 这让我们可以区分第一次出现、第二次出现以及任何剩余的副本。 

在第一遍期间，我们分配确定不同值计数的出现次数。 对于重复值，每个堆中都会放置一份副本。 对于单例值，我们交替使用堆。 

此时，一些多维数据集仍未分配。 这些立方体都是已经出现在某处的值的冗余副本。 它们无法增加任一堆中不同值的数量。 

变量`need1`告诉我们堆 1 还需要多少个立方体才能达到大小`n`。 我们将那么多未分配的多维数据集分配给堆 1，将其余的多维数据集分配给堆 2。由于多维数据集的总数为`2n`，堆 2 自动以大小结束`n`以及。 

一个常见的实现错误是在分配额外的重复项后对不同的值进行计数。 不同计数完全由第一个分配阶段决定。 额外的重复项的存在只是为了满足堆大小限制。

# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n = int(input())
    a = list(map(int, input().split()))

    pos = {}
    for i, v in enumerate(a):
        pos.setdefault(v, []).append(i)

    ans = [0] * (2 * n)

    d = 0
    s = 0
    cur = 1

    for v, idxs in pos.items():
        if len(idxs) >= 2:
            d += 1
            ans[idxs[0]] = 1
            ans[idxs[1]] = 2
        else:
            s += 1
            ans[idxs[0]] = cur
            cur = 3 - cur

    best = (d + (s + 1) // 2) * (d + s // 2)

    cnt1 = sum(x == 1 for x in ans)
    need1 = n - cnt1

    for v, idxs in pos.items():
        start = 2 if len(idxs) >= 2 else 1
        for idx in idxs[start:]:
            if need1 > 0:
                ans[idx] = 1
                need1 -= 1
            else:
                ans[idx] = 2

    return str(best)

 ## 边缘情况

 考虑：```
2
55 55 55 55
```的频率`55`是四。 该算法立即在每个堆中放置一个副本。 其余两个副本与不同计数无关，仅用于填充堆大小。 两个堆都包含单个不同的值`55`，所以答案是`1`。 

考虑：```
2
10 20 30 40
```每个值都是一个单例。 该算法交替分配，在每个堆中生成两个单例值。 不同的计数变为`(2,2)`答案是`4`。 任何作业产生`(3,1)`只会给`3`。 

考虑：```
3
10 10 20 20 30 40
```价值观`10`和`20`至少出现两次，因此每个都对两个堆都有贡献。 价值观`30`和`40`是单例并且被均匀分割。 不同的计数变成`(3,3)`答案是`9`，这是固定的不同值贡献总数的最大可能乘积。
