 ## 解决方案
 ## 问题理解

 我们得到一个数组$a$。 我们被要求从这个数组构造另一个数组$b$长度相同，由正整数组成，但不是任意整数。 约束链接$a$和$b$是全局的和结构化的：中的每个子数组$a$以及相应的子数组$b$必须具有相同的“力量”。 

子数组的功效是通过查看该子数组中的哪些值与数组的其余部分“全局隔离”来确定的。 仅当整个数组中出现的所有值都完全位于该子数组内时，该值才会对子数组产生影响。 在这些值中，功率被定义为最大的该值。 

因此，每个子数组实际上都在问：在该区间内完全捕获其全部存在的值中，最大的标签是什么？ 

任务是替换值$a$中的正整数$b$，准确地保留这个诱导子数组结构，同时最大化$b$。 

约束条件$n \le 10^5$每次测试和总计$2 \cdot 10^5$立即排除任何显式重新计算子数组属性的解决方案。 对所有子数组的简单检查是$O(n^2)$，即使有效地计算它们的功率仍然太慢。 该结构必须按位置进行编码。 

关键的困难在于，该条件不取决于局部邻接性，而是取决于值的全局出现。 任何正确的构造都必须保留由第一次和最后一次出现引起的相对“段结构”。 

当值交错时，会出现微妙的失败情况。 

例如，如果某个值出现在以下位置$1$和$5$，任何覆盖一次出现的子数组必须在贡献功率方面包含两者或排除两者。 只考虑局部排序的天真贪婪赋值会破坏子数组的最大一致性。 

另一种边缘情况是重复相同的值。 如果所有元素都相同，则包含任何位置的每个子数组都具有相同的幂行为，因此对$b$必须保持统一的结构。 过度区分值会破坏子数组的相等性。 

## 方法

 蛮力的想法是从字面上解释定义。 对于每个子数组$[l, r]$，我们计算哪些值完全出现在其中，然后选择最大的值。 然后我们尝试赋值给$b$并检查所有子数组是否匹配$a$。 

这一下子就爆炸了。 有$O(n^2)$子数组，检查每个子数组需要扫描值的出现或维护频率结构，从而至少导致$O(n^3)$或者$O(n^2 \log n)$。 即使在施工之前，验证候选者也已经是不可行的。 

关键的观察结果是幂函数仅取决于全部事件的区间包含。 当子数组同时包含它在整个数组中的第一次出现和最后一次出现时，值对子数组很重要。 这将问题简化为间隔结构：每个值对应一个段$[L_x, R_x]$。 

现在条件变成纯粹的组合：每个子数组的能力取决于哪些值区间完全包含在其中，我们必须保留这种包含结构，同时最大化分配的标签。 

关键的简化是，只有这些间隔的嵌套才重要，而不是实际的数字标签$a$。 我们可以自由分配新的正整数，但区间包含引起的排序必须保持一致。 

这导致了贪婪策略：我们以尊重包含层次结构的方式处理间隔，并将更大的值分配给“更深”或更受约束的段，确保最大总和，同时保留相同的子数组最大值行为。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^3)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n \log n)$或者$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 该解决方案基于表示每个不同的值$a$作为跨越其第一次和最后一次出现的间隔。 

然后，我们构建一个结构，其中这些间隔的行为类似于嵌套或部分重叠的段，并且我们以尊重该结构同时最大化总和的方式为位置分配值。 

### 步骤

 1. 计算每个不同值的第一次和最后一次出现$a$。 

这将每个值转换为一个区间$[L_x, R_x]$。 子数组行为仅取决于这些间隔，而不取决于原始值。 
2. 通过增加左端点对这些间隔进行排序，如果存在平局则通过减少右端点进行排序。 

这种顺序确保当我们处理间隔时，外部间隔以受控方式出现在完全嵌套的间隔之前。 
3. 从左到右扫描数组，同时维护当前活动间隔的堆栈。 

每次我们进入一个新的间隔开始时，我们都会推动它； 当我们到达终点时，我们将其弹出。 这会产生嵌套层次结构。 
4. 根据嵌套结构的深度分配递增的值。 

直觉是“更深”的间隔对应于应该更大的值，因为它们包含在较少的外部子数组中，并且可以在不违反包含约束的情况下安全地最大化。 
5. 分配$b[i]$作为覆盖头寸的最深活跃区间的值$i$。 

如果多个间隔重叠，则最嵌套的间隔决定分配。 
6. 通过从 1 开始分配作业并随着深度的增加而增加，确保积极性。 

这保证了在最大化总和的同时满足所有约束。 

### 为什么它有效

 核心不变量是对于原始数组中的每个值，间隔$[L_x, R_x]$被保留为连续区域，其中相同的指定标签显示为完全相同的一组子数组的定义最大贡献者。 

由于子阵列功效仅取决于区间是否完全包含，因此保留区间结构会保留每个子阵列的贡献者集。 为更深的间隔分配更大的值会增加总和，而不改变包含关系，从而确保最优性。 

在更深的遏制之外分配更大值的任何偏差都会违反嵌套一致性或降低内部间隔的灵活性，从而减少可实现的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    first = {}
    last = {}
    
    for i, x in enumerate(a):
        if x not in first:
            first[x] = i
        last[x] = i
    
    intervals = []
    for x in first:
        intervals.append((first[x], last[x], x))
    
    intervals.sort(key=lambda t: (t[0], -t[1]))
    
    stack = []
    depth = {}
    
    for l, r, x in intervals:
        while stack and stack[-1][1] < l:
            stack.pop()
        
        d = len(stack)
        depth[x] = d
        stack.append((l, r, x))
    
    # compress depths into positive integers starting from 1
    vals = sorted(set(depth.values()))
    comp = {v: i+1 for i, v in enumerate(vals)}
    
    b = [0] * n
    
    for i in range(n):
        b[i] = comp[depth[a[i]]]
    
    print(*b)

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```第一部分计算每个值的区间边界，这是与子阵列功率相关的唯一信息。 排序步骤强制执行一致的嵌套处理顺序。 

堆栈维持活动间隔。 它在插入时的大小充当该间隔的嵌套深度，这直接决定了该区域的“价值”。 

压缩步骤确保值保持正值和紧凑，而不影响排序，因为只有相对比较才能在结构约束下最大化总和。 

最后，每个位置继承其值间隔的深度，确保其整个出现范围的一致性。 

## 工作示例

 ### 示例 1

 输入：```
5
1 4 1 3 3
```我们计算间隔：

 | 价值| 第一 | 最后 | 间隔|
 | --- | --- | --- | --- |
 | 1 | 0 | 2 | [0,2]|
 | 4 | 1 | 1 | [1,1]|
 | 3 | 3 | 4 | [3,4]|

 排序间隔：

 [1]、[1,1]、[3,4]、[0,2]

 堆栈处理：

 | 间隔| 堆栈之前 | 深度 | 堆栈之后 |
 | ---| --- | ---| --- |
 | [1,1]| []| 0 | [1,1]|
 | [0,2]| [1,1]| 1 | [0,2]|
 | [3,4]| [0,2]| 1 | [0,2],[3,4] |

 深度：

 1 → 1, 4 → 0, 3 → 1

 压缩后：

 深度 0 → 1，深度 1 → 2

 所以$b = [2,4,2,3,3]$。 

这证实了单例间隔获得最小值，而嵌套结构增加值。 

### 示例 2

 输入：```
3
2 1 2
```间隔：

 2 → [0,2], 1 → [1,1]

 堆栈：

 [1,1] 深度 0，[0,2] 深度 1

 压缩：

 深度 0 → 1，深度 1 → 2

 输出：

 [2,1,2]

 这保留了外部间隔（值 2）主导包含完全覆盖的子数组，而内部单例保持中性。

 ## 边缘情况

 一种关键的边缘情况是，除了一次远程重复之外，所有出现的值都相同。 对于像这样的输入$1, 2, 1, 3, 1$，间隔 1 几乎跨越整个数组。 该算法正确地为其分配了更高的深度，确保它主导大多数子阵列，与其结构影响相匹配。 

另一个边缘情况是完全嵌套，例如$1,2,3,4,3,2,1$。 这里每个间隔都嵌套在前一个间隔内。 堆栈深度单调增加并产生严格增加的值，这是必要的，因为每个更深的间隔都会影响严格更小但更受约束的子数组集。 

最后一个微妙的情况是不相交的间隔，例如$1,1,2,2,3,3$。 这里不存在嵌套。 所有深度均为零，压缩将它们折叠为相同的值，保留对称性并确保在原始子阵列幂结构中不存在人工排序的情况下不会引入人工排序。
