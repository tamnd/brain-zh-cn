 ## 解决方案
 ## 问题理解

 我们有四个整数来描述两只外星人手上的手指数量。 金星女孩有`al`手指放在她的左手上`ar`在她的右手上。 火星男孩有`bl`和`br`手指。 

他们想握住一双手。 由于任何一个人都可以站在左边，因此只有两种可能的配对：

 - 女孩的左手和男孩的右手
 - 女孩的右手和男孩的左手

 或相反的方向。 

该布置必须满足两个舒适规则。 

首先，女孩的两根手指不能直接接触。 每对相邻的女孩手指之间，必须至少有一个男孩手指。 

其次，男孩的三个手指不能连续接触。 

任务是确定是否存在至少一对有效的手牌配对。 

限制很小，每个值最多为 100。即使对所有可能性进行强力模拟也会立即运行。 真正的挑战是识别隐藏在措辞中的数学条件。 

棘手的部分是将物理描述正确地转化为不等式。 

假设女孩有`g`手指和男孩有`b`手指在选定的手中。 

为了分开每对相邻的女孩手指，男孩至少需要`g - 1`手指。 例如，如果女孩有 5 个手指，我们需要这样的结构：`B G B G B G B G B G`女孩手指之间有 4 个间隙，因此男孩至少需要 4 个手指。 

同时，男孩不能连续三个手指接触。 这意味着我们最多可以在女孩手指周围的每个插槽中放置两个男孩手指。 

和`g`女孩的手指，有`g + 1`男孩手指可能出现的位置：

 - 在第一个女孩手指之前
 - 每相邻对之间
 - 在最后一个女孩手指之后

 每个插槽最多可以包含 2 个男孩手指，因此男孩手指的最大可能数量为`2 * (g + 1)`。 

一个常见的错误是忘记了边缘槽。 有人可能错误地认为最大值是`2 * (g - 1)`，仅计算内部间隙。 例如：```
girl = 1
boy = 4
```这实际上是有效的：`BBGBB`没有连续的三个男孩手指。 

另一个容易犯的错误是使用严格的不等式。 考虑：```
girl = 5
boy = 4
```这是有效的，因为男孩的一根手指可以分开每对女孩的手指：`GBGBGBGBG`下界是`boy >= girl - 1`， 不是`boy > girl - 1`。 

当女孩的手指很少时，就会出现最后的边缘情况。```
girl = 1
boy = 0
```这是有效的，因为没有相邻的女孩手指可以分开。 

条件仍然有效：```
girl - 1 <= boy <= 2 * (girl + 1)
0 <= 0 <= 4
```## 方法

 最直接的方法就是暴力构建。 对于选定的一双手，我们可以尝试生成所有可能的手指排列并检查是否有任何排列满足规则。 

如果女孩有`g`手指和男孩有`b`，合并序列的总数为：$$\binom{g+b}{g}$$尽管实际的限制很小，但总体而言增长很快。 例如，总共只有 20 个手指，但交错次数已超过 18 万次。 一旦我们了解了有效安排的结构，就没有必要进行全面的搜索。 

关键的观察是约束描述了间距规则。 

女孩的情况对男孩的手指提出了最低要求。 每对相邻的女孩手指都需要至少一个分隔符，因此我们需要：$$b \ge g - 1$$男孩的情况提出了最高要求。 由于男孩的三个手指不能连续接触，所以女孩手指周围的每个槽最多可以包含两个男孩的手指。 

和`g`女孩的手指，有`g + 1`插槽：```
_ G _ G _ G _
```每个插槽最多可容纳两个男孩手指，从而：$$b \le 2(g+1)$$这两个不等式既是必要的也是充分的。 

我们简单地测试两种可能的手牌配对：

 -`(girl left, boy right)`-`(girl right, boy left)`如果其中一个满足不等式，则答案是`"YES"`。

 ## 算法演练

 1. 读取四根手指的计数。 
2. 为选定的双手定义辅助检查函数。 
3. 假设女孩有`g`手指和男孩有`b`。 
4. 验证下限：$$b \ge g - 1$$这保证了每对相邻的女孩手指都可以分开。 

1. 验证上限：$$b \le 2(g+1)$$这保证了男孩的手指可以分布到`g + 1`可用插槽，无需创建三个连续的男孩手指。 

1. 如果两个不等式都成立，则该配对可行。 
2. 测试两个方向：

 1. 左边是女孩，右边是男孩
 2. 女孩在右边，男孩在左边
 3. 如果至少一种方向有效，则打印`"YES"`。 否则打印`"NO"`。 

### 为什么它有效

 下界是不可避免的，因为连续的女孩手指之间的每个间隙必须包含至少一个男孩手指。 一只手与`g`女孩的手指正好有`g - 1`这样的差距。 

上限也是不可避免的，因为男孩可能不会连续贡献三个手指。 大约`g`女孩的手指确实有`g + 1`插入位置，每个位置最多可以包含两个男孩手指。 

这些条件也足够了。 如果男孩手指的数量在区间内：$$g - 1 \le b \le 2(g+1)$$我们可以首先在每个内部间隙中放置一个男孩手指，然后将剩余的男孩手指分配到可用的插槽中，但每个插槽不得超过两个。 这总是构建一个有效的安排。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def possible(g, b):
    return g - 1 <= b <= 2 * (g + 1)

def solve():
    al, ar = map(int, input().split())
    bl, br = map(int, input().split())

    if possible(al, br) or possible(ar, bl):
        print("YES")
    else:
        print("NO")

solve()
```辅助函数直接实现有效排列的数学特征。 

表达式：```
g - 1 <= b
```检查是否有足够的男孩手指来分隔相邻的女孩手指。 

表达式：```
b <= 2 * (g + 1)
```检查是否可以在不创建三个连续手指的情况下分配男孩手指。 

该解决方案测试了两种可能的方向，因为配对会根据谁站在哪一边而交换。 忘记第二个方向是最常见的实施错误。 

所有计算都适合正常整数。 约束很小，但即使对于更大的值，该逻辑仍然会立即运行。

 ## 边缘情况

 考虑男孩有足够的手指来分开女孩手指的情况。 

输入：```
5 1
4 1
```测试第一个方向给出`g = 5`和`b = 1`，立即失败。 第二个方向给出`g = 1`和`b = 4`，满足：```
0 <= 4 <= 4
```算法正确打印`"YES"`因为边缘槽允许两个男孩手指在单个女孩手指之前和之后。 

现在考虑上限失败一的情况。 

输入：```
1 1
5 5
```对于任一方向：```
g = 1
b = 5
```支票变成：```
0 <= 5 <= 4
```上限失败。 由于只有两个可用的边缘槽，放置 5 个男孩手指不可避免地会在某处产生三个连续的男孩手指。 算法正确返回`"NO"`。 

最后，考虑确切的下限场景。 

输入：```
5 2
4 1
```有效配对是`g = 5`,`b = 4`。 

条件变为：```
4 <= 4 <= 12
```安排：```
G B G B G B G B G
```工作完美。 该算法接受下限内的相等性，避免了严格要求更多分隔符的常见差一错误。
