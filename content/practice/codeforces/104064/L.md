 ## 解决方案
 ## 问题理解

 我们正在追踪一堆T恤中的一件独特的T恤$n$衬衫。 总是从顶部访问该堆栈：每天早上您都穿着最上面的衬衫，并在一天结束时将其放入洗衣篮中。 

晚上，你偶尔会洗衣服。 一个洗衣周期包括首先积累一定数量的旧衬衫（包括该周期最后一天穿过的衬衫），然后清洗篮子中的所有衬衫，最后将所有衬衫放入洗衣篮中。$n$衬衫以均匀随机的顺序放回单叠。 

每次洗涤之间的天数是随机的，但这种随机性仅影响洗涤前收集的衬衫数量。 由于每件衬衫最终都会在每个周期中被清洗，因此周期的关键效果是整套衬衫作为均匀随机排列重新插入。 

我们得到了当前堆栈中一件特殊“幸运”衬衫的初始位置，并且我们希望在之后它的预期位置$k$这样的洗涤周期。 

约束允许最多$10^6$衬衫及最多$10^6$循环。 这立即排除了对日常操作或每班次跟踪单件衬衫的任何模拟，因为两者$n$和$k$可以足够大，甚至$O(n)$每个周期会太慢。 解决方案必须将过程简化为封闭式期望或非常小的状态递归。 

朴素推理中的一个微妙问题是假设洗涤后的位置取决于先前的结构。 例如，人们可能会认为幸运衬衫的地位在不同周期中逐渐演变。 然而，由于每个周期都以所有衬衫的完全随机排列结束，因此先前排序的任何记忆都会受到严重破坏，并且只有聚合统计行为仍然有意义。 

主要陷阱是低估了每个周期引入的随机性。 如果错误地假设跨周期部分保留订单，他们将在太大或结构不正确的头寸上建立马尔可夫过程。 

## 方法

 强力解释将尝试显式模拟循环。 在每个周期中，我们将模拟每天移除最上面的衬衫，积累一个篮子，然后对所有衬衫进行完全洗牌。 这已经花费了$O(n)$每个周期只是为了模拟最坏情况下的日子，并且最多$10^6$循环，就变得完全不可行。 

即使我们压缩日常模拟并仅模拟循环，我们仍然需要了解幸运衬衫的位置在随机“删除前缀然后洗牌”操作后如何演变。 关键的观察结果是，每次清洗后堆栈内的确切顺序在所有排列中都是一致的。 这破坏了对前一个位置的任何结构依赖性，因此我们不需要跟踪完整的状态，而只需要每个周期后幸运衬衫位置的分布。 

这将过程分解为简单的随机重置：每次洗涤后，堆栈都是均匀随机排列，因此每件衬衫出现在任何位置的可能性相同。 一旦认识到这一点，该过程在第一个循环后立即变得静止。 

第一个周期是唯一受给定初始位置影响的周期。 此后，系统失去对启动配置的依赖。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 全面模拟日子和洗牌 |$O(kn)$|$O(n)$| 太慢了|
 | 统一排列的循环级推理 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 ### 最优解

 1. 观察洗涤周期结束后，所有$n$衬衫以统一随机顺序放回堆栈中。 这意味着每个排列的可能性都是相同的，与之前的周期无关。 
2. 从概率的角度来看，这意味着在第一次洗涤后，幸运衬衫同样有可能出现在以下任一情况中：$n$位置从上到下。 
3. 计算均匀分布中的预期位置$\{1, 2, \dots, n\}$。 这是该范围的算术平均值，即$(n+1)/2$。 
4. 由于每个后续循环再次以相同的方式完全随机化堆栈，因此在第一个循环之后分布不会改变。 因此，所有$k \ge 1$循环导致相同的期望。 
5、特殊情况处理$k = 0$，尚未发生清洗，因此位置保持给定的初始值$i$。 

### 为什么它有效

 每个循环对所有衬衫应用完全随机排列。 统一的排列消除了对之前排列的任何依赖，这意味着幸运衬衫的位置分布在每次洗涤后都变得相同。 一旦系统在第一个周期后达到此状态，它将在所有未来周期中保持不变。 因此，期望立即稳定并等于头寸均匀分布的平均值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, i, k = map(int, input().split())

if k == 0:
    print(f"{i:.10f}")
else:
    ans = (n + 1) / 2
    print(f"{ans:.10f}")
```该实施反映了关键的结构见解：除了第一个周期之外，该过程没有任何有意义的多步骤演变。 唯一的分歧是是否发生任何洗涤。 

唯一微妙的一点是格式。 由于该问题需要精度高达$10^{-6}$，以固定小数精度打印就足够了。 

## 工作示例

 ### 示例 1

 输入：$n = 3, i = 2, k = 2$第一次清洗后，这堆衬衫变成了三件衬衫的均匀排列，因此幸运衬衫的预期位置变为$2.0$。 后续循环不会改变此分布。 

| 循环| 分布状态| 预期职位 |
 | ---| ---| ---|
 | 0 | 固定为 2 | 2 |
 | 1 | 制服在{1,2,3} | 2 |
 | 2 | 制服在{1,2,3} | 2 |

 该示例说明第二个循环不会改变任何内容，因为第一次洗涤后随机性已经最大。 

### 示例 2

 输入：$n = 5, i = 1, k = 1$一次清洗后，所有排列的可能性均等，因此每个位置的可能性均等。 

| 循环| 分布状态| 预期职位 |
 | ---| ---| ---|
 | 0 | 固定为 1 | 1 |
 | 1 | 制服超过{1..5} | 3 |

 这显示了强烈偏差的初始位置如何在一个周期后立即崩溃为统一的期望。

 ## 边缘情况

 主要的边缘情况是从未发生过洗涤。 在这种情况下，堆栈永远不会是随机的，因此幸运衬衫仍然保持在它开始的位置。 这是通过检查显式处理的$k = 0$并返回$i$。 

另一个极端情况是$n = 1$。 堆栈只有一件衬衫，因此每个循环都会返回相同的位置。 统一期望公式也正确得出$(1+1)/2 = 1$，匹配确定性行为。 

第三个微妙的案例很大$k$。 由于分布在第一次洗涤后立即稳定，因此较大的值$k$不累积数值漂移或需要求幂。 该过程没有超出一步的长期瞬态行为，因此所有大型$k$行为相同。
