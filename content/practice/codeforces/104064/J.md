 ## 解决方案
 ## 问题理解

 我们得到了地球上一系列由纬度和经度描述的点。 旅行者从第一个点开始，按顺序穿过各个点，最后使用相同的规则从最后一个点返回到第一个点：旅程的每一段都遵循球体上两个连续点之间的最短弧线。 

任务是确定球体上的这条闭合多段线是否可以被视为特定定义下的完整环球航行。 有效的环球航行必须在同一位置开始和结束，并且在整个行程期间，必须与每个可能的子午线相交，这意味着由固定经度值定义的每个垂直大圆。 如果这个条件失败，我们必须产生一个路线从未穿过的经度。 所需的经度被限制为整数或半整数。 

从几何角度来看，问题简化为跟踪连接连续航路点的最短球面弧的并集以及最终的闭合弧“扫过”哪些经度。 

约束 n ≤ 1000 足够小，我们可以进行 O(n^2) 推理，或者如果每个段需要的话，甚至可以进行更昂贵的几何处理。 然而，关键的困难不是计算规模，而是球面几何的简并性。 每一段都是大圆弧，而不是经度空间中的直线段，因此当路径穿过极点或环绕 ±180 度时，经度中的朴素区间推理可能会失败。 

当线段穿过反子午线或经过极点附近时，会出现微妙的边缘情况。 例如，从 (0, 170) 到 (0, -170) 的路径穿过 180 和 -180 附近的经度，根据方向可能会穿过几乎所有经线。 经度的天真的间隔联合会错误地将其视为一个小段。 

当路径穿过两极时，会出现另一种故障情况。 穿过极点的任何线段都与每条子午线相交，无论其他线段如何，都会立即得出“是”的答案。 缺少这一点会导致错误的“否”输出。 

## 方法

 蛮力的想法是模拟每个球面并明确确定它相交的所有经度。 人们可以以精细的分辨率离散化经度并标记出哪些子午线相交。 对于每条边，我们计算其大圆弧所接触的所有经度，并将它们标记在布尔数组中。 

这在精神上是正确的，但地球是连续的，经度不容易离散而不失去正确性。 即使我们以 0.5 度分辨率进行离散化（因为输出需要半整数），仍然会给出 720 条可能的经线，并且对于最多 1000 条线段中的每条线段，我们可以通过几何检查来模拟交叉行为。 这仍然是可行的，但真正的问题是正确性：当电弧经过极点附近或环绕不连续性时，离散化会中断。 

关键的观察是，我们可以考虑“禁止哪些经度间隔”，而不是考虑“覆盖了哪些经度”。 如果至少有一个经度从未与任何弧相交，则存在缺失的子午线。 所以问题就变成了找到单位球面上所有弧所覆盖的经度间隔的并集，并检查这个并集是否是整圆。 

每个大圆弧都与子午线圆上的连续经度区间相交，除非它穿过极点，在这种情况下，它会立即覆盖所有经度。 因此，问题简化为计算循环域上的覆盖区间，以及特殊的全覆盖情况。

我们将几何简化为计算每个线段投影到经度圆上时弧所跨越的经度范围。 将它们转换为 [-180, 180) 上的区间后，我们将它们合并在一条圆形线上并检查是否有间隙。 如果存在间隙，则间隙内的任何点都是有效答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力离散化 | O(n·720) | O(720) | 危险/脆弱|
 | 最佳球形区间覆盖 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将所有纬度和经度转换为弧度或保持度数一致，但小心地将经度视为 [-180, 180) 中的圆形变量。 
2. 对于每对连续的航路点，计算它们之间的大圆弧。 第一个关键检查是该段是否穿过任一极。 这可以使用矢量几何来检测：如果大圆平面包含极点方向（z 轴），则圆弧穿过所有经度。 如果任何分段发生这种情况，请立即输出“yes”，因为所有经络都被访问过。 
3. 对于不穿过极点的线段，计算弧所达到的最小和最大经度。 这不仅仅是端点的最小值和最大值，因为经度可以环绕。 相反，我们以 360 为模处理经度差并选择较短的弧方向，有效地映射端点，使其纵向差在 (-180, 180] 范围内。
 4. 对于每个线段，一旦我们有了经度沿弧线变化的连续表示，我们就可以确定它所覆盖的经度间隔。 该区间是 [-180, 180) 上的循环区间。 如果它回绕，我们将其分成两个线性区间。 
5. 收集所有段上的所有此类间隔。 
6. 按起始经度对间隔进行排序，并合并重叠或相邻的间隔。 在合并过程中，将接触端点视为连续覆盖，因为精确接触的经络被视为已访问。 
7. 合并后，扫描连续间隔之间的间隙。 由于域是循环的，因此还要检查回绕后最后一个间隔和第一个间隔之间的间隙。 
8. 如果不存在间隙，则输出“yes”。 否则，选择间隙内的任意经度。 为了满足整数或半整数输出的要求，选择间隙的中点并将其四舍五入到最接近的0.5。 

### 为什么它有效

 每一段都贡献了一组连续的经线，因为投影到经度下的连续大圆弧的图像是连续的，除了极点之外。 一旦排除极点，由于环绕，每个弧最多映射到两个单调经度间隔。 因此，所有访问过的经络的并集是圆形间隔的并集。 如果这个并集没有覆盖整个圆，则补集包含一个开区间，并且该区间中的任何点都不会被访问。 合并可以保留精确的覆盖范围，因为重叠不会删除任何未覆盖的区域。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

EPS = 1e-12

def norm_lon(x):
    while x < -180:
        x += 360
    while x >= 180:
        x -= 360
    return x

def to_vec(lat, lon):
    lat = math.radians(lat)
    lon = math.radians(lon)
    x = math.cos(lat) * math.cos(lon)
    y = math.cos(lat) * math.sin(lon)
    z = math.sin(lat)
    return (x, y, z)

def cross(a, b):
    return (a[1]*b[2]-a[2]*b[1],
            a[2]*b[0]-a[0]*b[2],
            a[0]*b[1]-a[1]*b[0])

def dot(a, b):
    return a[0]*b[0]+a[1]*b[1]+a[2]*b[2]

def has_pole_cross(a, b):
    # great circle plane normal
    n = cross(a, b)
    # pole is (0,0,1), so pole lies on great circle if n.z == 0
    return abs(n[2]) < 1e-12

def lon_from_vec(v):
    x, y, z = v
    return math.degrees(math.atan2(y, x))

def segment_intervals(a, b):
    ax, ay, az = a
    bx, by, bz = b

    la = lon_from_vec(a)
    lb = lon_from_vec(b)

    la = norm_lon(la)
    lb = norm_lon(lb)

    d = lb - la
    if d > 180:
        lb -= 360
    elif d < -180:
        lb += 360

    la0, lb0 = la, lb

    if has_pole_cross(a, b):
        return [(-180.0, 180.0)]

    l1 = la0
    l2 = lb0

    if l1 > l2:
        l1, l2 = l2, l1

    return [(l1, l2)]

def merge(intervals):
    if not intervals:
        return []

    intervals.sort()
    res = []
    cur_l, cur_r = intervals[0]

    for l, r in intervals[1:]:
        if l <= cur_r + 1e-12:
            cur_r = max(cur_r, r)
        else:
            res.append((cur_l, cur_r))
            cur_l, cur_r = l, r

    res.append((cur_l, cur_r))
    return res

def solve():
    n = int(input())
    pts = []
    for _ in range(n):
        lat, lon = map(int, input().split())
        pts.append(to_vec(lat, lon))

    intervals = []

    for i in range(n):
        a = pts[i]
        b = pts[(i+1) % n]
        intervals.extend(segment_intervals(a, b))

    merged = merge(intervals)

    if len(merged) == 1 and merged[0][0] <= -180 + 1e-9 and merged[0][1] >= 180 - 1e-9:
        print("yes")
        return

    if merged[0][0] > -180 + 1e-9 or merged[-1][1] < 180 - 1e-9:
        merged = merge(merged + [(180.0, 180.0)])

    gap_start = None
    gap_end = None

    if merged[0][0] > -180:
        gap_start = -180
        gap_end = merged[0][0]
    else:
        for i in range(len(merged)-1):
            if merged[i][1] < merged[i+1][0] - 1e-12:
                gap_start = merged[i][1]
                gap_end = merged[i+1][0]
                break

        if gap_start is None:
            gap_start = merged[-1][1]
            gap_end = 180

    mid = (gap_start + gap_end) / 2
    mid = round(mid * 2) / 2
    mid = norm_lon(mid)

    print("no", mid)

if __name__ == "__main__":
    solve()
```该解决方案将每个路点转换为 3D 单位矢量，以便大圆弧对应于通过原点的平面的交点。 通过大圆法向量检查每个线段是否有极点交叉。 如果跨越一根极点，弧线立即覆盖所有经度。 

否则，在解决 ±180 度的环绕之后，每个弧都会减少为单调经度间隔。 这些间隔被合并以形成访问经络的联合。 如果联合完整，则该路由有效。 

最后一步找到合并覆盖范围中的间隙并选择其中点，根据需要四舍五入为半整数。

 ## 边缘情况

 一个关键的边缘情况是当一个线段穿过一根杆时。 在这种情况下，经度变得无关紧要，因为每条经线都与极点相交。 该算法通过检测大圆法线中的零 z 分量来处理此问题。 一旦触发，它立即返回“yes”，防止任何错误的区间推理。 

另一种边缘情况是当经度差超过 180 度时，这通常表明是长弧，但实际上对应于穿过反子午线的短路径。 标准化步骤迫使表示进入一致的区间，确保正确的合并。 

第三种边缘情况是完全接触 -180 或 180 的路径。由于经度是圆形的，因此在合并期间必须将这些端点视为相同。 区间并集逻辑明确允许边界邻接，防止出现错误的间隙，从而错误地产生“否”答案。
