 ## 解决方案
 ## 问题理解

 我们在整数网格上得到了一大组点。 每个点代表一颗“星星”，我们需要使用放置在同一网格上的单位方块包围所有这些点。 

我们可以选择一些网格单元并将它们标记为“戴森单元”。 这些选定的单元形成一个单一的连接结构，其中连接性以相当慷慨的方式定义：两个戴森单元即使在角落接触也被认为是连接的。 所以对角线足以保持结构的连接。 

放置这些戴森单元后，所有剩余的网格单元必须恰好分成两个区域：一个包含所有恒星的“内部”区域，以及一个无限延伸的“外部”区域。 这两个区域必须由所选的戴森装置隔开，这意味着如果不穿过戴森装置，您就无法从内部走到外部。 内部区域也必须使用标准边缘邻接进行连接。 

我们的目标是尽量减少我们放置的戴森装置的数量。 

约束允许最多 200,000 个点，坐标的绝对值最多为 100 万个。 这立即排除了 n 中的任何二次方，并且还排除了任何尝试显式模拟网格或在整个平面上执行洪水填充的方法。 任何正确的解决方案都必须将问题简化为排序后大约需要 O(n log n) 或 O(n) 时间计算的几何结构。 

一个常见的失败案例来自于“只取边界框”的思考。 例如，如果点形成像 (0,0)、(100,100)、(200,200) 这样的对角线形状，则边界框很大并且显然不是最佳的。 另一个失败的情况是假设我们需要欧几里得几何中的凸包，当在具有对角连接的网格上定义运动和邻接时，这会产生错误的边界概念。 

关键的难点在于，邻接不是标准的四向或欧几里德邻接，而是障碍物的角连接，这改变了“短边界”的含义。 

## 方法

 蛮力视图将尝试明确地构建网格图，然后搜索所有恒星周围细胞的最小分离周期。 人们可以想象 BFS 从无穷大和恒星扩展，然后尝试在双网格中找到最小的分离结构。 这很快就变得不可行，因为网格是无界的，并且在坐标范围内包含多达 10^12 个潜在单元，使得显式的图构造变得不可能。 

即使我们将自己限制为仅靠近点的单元，网格状态上的朴素 BFS 仍然会爆炸，因为我们试图优化的边界结构不是以简单的方式局部的。 屏障必须在 8 连通性下形成单个连通循环，将形状中相距较远的部分耦合起来。 

关键的观察结果是，尽管有网格公式，但答案仅取决于 8 方向连通性引起的度量下点集的外边界。 在这个几何中，就连通性而言，对角线移动与轴移动具有相同的成本，因此正确的距离概念变成了切比雪夫度量。 

这将问题转化为求 L∞ 度量下点的凸包周长。 一旦我们将边重新解释为长度等于`max(|dx|, |dy|)`，最小闭环正好对应于凸包的边界，其总长度就是所需的戴森单元数。 

因此，任务简化为计算该度量空间中的凸包并对其周长求和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力网格分离 | O（网格大小）| O（网格大小）| 太慢了 |
 | 凸包 + L∞ 周长 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们将每颗恒星视为平面上的一个点。 目标是计算凸包的外边界，但距离以切比雪夫 (L∞) 范数测量。 

1. 按字典顺序对所有点按 x 排序，然后按 y 排序。 

这是有效构建凸包所必需的，并确保我们可以构建单调链。 
2. 使用单调堆栈构建下部船体。 

我们按排序顺序迭代点并维护一堆候选外壳顶点。 当堆栈中的最后两个点与当前点在 L∞ 方向测试下不形成“左转”时，我们删除中间点。 几何直觉是我们只保留对外部边界有贡献的点。 
3. 以相同的方式构建上层船体，以相反的顺序迭代。 

这反映了相同的过程并完成了凸边界。 经过这一步，我们就有了一个描述 L∞ 空间中凸包的闭合多边形。 
4. 连接下壳和上壳，删除重复的端点。 

这给出了正确顺序的完整边界循环。 
5. 使用切比雪夫距离计算该循环的周长。 

对于每对连续的点`(x1, y1)`和`(x2, y2)`，我们添加`max(|x1 - x2|, |y1 - y2|)`。 

这直接对应于沿着允许对角邻接的网格边界遍历的成本。 

### 为什么它有效

 戴森装置形成一个单独的 8 个连接的屏障，将内部与外部分隔开。 任何这样的障碍必须包围所有点，因此它必须包含网格自然度量下的凸包。 在所有封闭循环中，凸包边界是最小的，因为任何向内的缩进都可以是捷径而不破坏分离，并且在 L∞ 几何中，这些捷径在切比雪夫范数下被凸性精确捕获。 因此，最优结构正是凸包边界，其周长是所需的最小单位正方形数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def build_hull(points):
    hull = []
    for p in points:
        while len(hull) >= 2 and cross(hull[-2], hull[-1], p) <= 0:
            hull.pop()
        hull.append(p)
    return hull

n = int(input())
pts = [tuple(map(int, input().split())) for _ in range(n)]
pts.sort()

if n == 1:
    print(0)
    sys.exit()

lower = build_hull(pts)
upper = build_hull(pts[::-1])

hull = lower[:-1] + upper[:-1]

def dist(a, b):
    return max(abs(a[0] - b[0]), abs(a[1] - b[1]))

ans = 0
for i in range(len(hull)):
    ans += dist(hull[i], hull[(i + 1) % len(hull)])

print(ans)
```该代码是标准的单调链凸包构造，但几何解释发生了变化：我们使用切比雪夫距离计算边界长度，而不是欧几里得周长。 叉积测试对于维持平面意义上的凸性仍然有效，并且度量变化仅影响我们测量最终周长的方式。 

一个微妙的实现细节是处理退化情况：当所有点共线或相同时，船体折叠成线段或点。 在这些情况下，循环结构仍然有效，但我们必须确保在连接外壳时不会重复计算端点。

 ## 边缘情况

 一种微妙的情况是所有点都位于一条线上。 在这种情况下，凸包退化为一个线段，并且连接上包和下包可以产生重复点。 该实现通过切掉每个船体的最后一个元素来处理这个问题，但距离计算一致地处理结果循环仍然很重要。 在切比雪夫距离下，周长减小到线段长度的两倍，这与最小包围圈必须仍然封闭在线段周围的事实相匹配。 

另一种情况是当这些点形成高度非凸形状时。 船体结构消除了所有凹面，任何凹痕只会增加 L∞ 度量的周长，同时仍然包围所有点。 这保证了没有内部“凹痕”可以成为最佳屏障的一部分，因为它需要额外的戴森装置而不改善分离。
