 ## 解决方案
 ## 问题理解

 我们得到一排书库，每个书库包含一定数量的书。 目标不是单独移动书籍，而是对两个选定的书堆应用特殊操作。 

一次操作选择两个不同的位置$i$和$j$，从两个堆栈中取出所有书籍，并将它们尽可能均匀地重新分配回相同的两个堆栈中。 如果书的总数是$s$，那么在操作之后一个堆栈得到$\lfloor s/2 \rfloor$书籍和其他得到$\lceil s/2 \rceil$。 赋值实际上并不含糊，因为我们可以认为运算后较小的值移至左侧索引，较大的值移至右侧索引。 

任务是产生最多一个序列$10^5$这样的操作使得执行完这些操作后，堆栈大小的顺序从左到右变为非递减。 

这些约束足够大，以至于任何试图通过一般重新排列或重复全局调整来模拟排序的策略如果每次操作都有一个对数因子，都会有风险。 然而，操作本身非常便宜，因此即使是线性数量也是可以接受的。 

微妙的一点是，本地化操作非常强。 它不仅仅将一本书从一个书堆移到另一个书堆，还迫使所选的两个书堆立即变得几乎相等。 这表明，只需很少的精心选择的局部修复，就可以实现全局排序。 

朴素推理的一个常见失败案例是假设需要重复操作来“平衡”两个堆栈。 实际上，一个操作已经在所选对之间强制执行排序关系，这完全改变了问题的性质。 

## 方法

 强力解释会尝试直接模拟排序：每当反转$A_i > A_{i+1}$发现后，我们将重复对附近的对进行操作，直到反转消失。 虽然这在直观上是合理的，但没有必要，因为每个操作都比典型的类似交换操作具有更强的效果。 

关键的观察是对一对进行一次操作后会发生什么$(i, j)$。 设值为$x$和$y$。 手术后他们变成$\lfloor (x+y)/2 \rfloor$和$\lceil (x+y)/2 \rceil$。 通过构造，如果我们考虑按索引排序，较小的值总是分配给左侧堆栈，因此在操作之后我们总是有一个非递减对：无论初始顺序如何，左侧值都小于或等于右侧值。 

这意味着一个操作完全固定了所选对的顺序。 

一旦理解了这一点，全球战略就变得简单明了。 如果每个相邻对$(i, i+1)$至少一次变为非递减，并且以后的操作再也不会触及之前的指数，那么之前固定的关系仍然有效。 这允许单次从左到右扫描。 

重复局部校正的强力想法被单次确定性传递所取代，该传递逐边强制执行单调性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 重复本地修复直至排序 | O(N²) 或更差 | O(1) | O(1) | 不必要但会过去 |
 | 单次从左到右的操作传递 | O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们依赖于这样一个事实：对一对执行操作$(i, i+1)$使那双立即订购。 

1. 从数组的左端开始向右移动。 
2. 对于每一个相邻的对$(i, i+1)$，对这两个索引执行一项操作。 
3、加工后位置$i$，移至$i+1$并重复直到结束。 

每一步都永久强制执行$A_i \le A_{i+1}$对于该特定对。 由于后续操作仅影响严格位于右侧的对，因此先前固定的关系永远不会受到干扰。 

### 为什么它有效

 处理后指标$i$，关系$A_i \le A_{i+1}$永久保留，因为后续操作不会触及索引$i$。 该数组成为全局排序的，因为每个相邻的对都满足所需的顺序。 A sequence is non-decreasing if and only if all adjacent pairs are non-decreasing, so once all edges are fixed exactly once, the entire array is sorted.

 不变量很简单：完成步骤后$i$, 前缀$1 \dots i+1$已排序。 每个操作都会将此前缀扩展一个元素，而不会破坏先前的约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    a = list(map(int, input().split()))

    ops = []
    for i in range(n - 1):
        ops.append((i + 1, i + 2))

    print(len(ops))
    for i, j in ops:
        print(i, j)

if __name__ == "__main__":
    main()
```该实现不会模拟操作，因为构造独立于值。 它仅发出相邻对的序列。 关键的微妙之处在于输出中索引是从 1 开始的，所以我们输出$(i+1, i+2)$对于从零开始的迭代中的每个相邻对。 

除了琐碎的事情之外，没有任何边界情况需要特殊处理$n=2$情况下，单个操作直接一步对数组进行排序。 

## 工作示例

 ### 示例 1

 输入数组：$[a_1, a_2, a_3, a_4]$我们生成操作：

 | 步骤| 运营| 效果|
 | --- | --- | --- |
 | 1 | (1, 2) | 确保$A_1 \le A_2$|
 | 2 | (2, 3) | 确保$A_2 \le A_3$|
 | 3 | (3, 4) | 确保$A_3 \le A_4$|

 在步骤 1 之后，第一对就被固定了。 步骤2仅修改位置2和3，保持1和2之间的关系不变。 第 3 步仅涉及最后一对。 经过所有步骤后，所有相邻对都已排序，因此整个序列已排序。 

### 示例 2

 输入：$[10, 1]$| 步骤| 运营| 结果 |
 | --- | --- | --- |
 | 1 | (1, 2) | 成为$(5, 6)$|

 操作完成后，即使初始状态发生逆转，该对也会立即排序。 这表明单个操作可以完全解决任何反转。

 ## 边缘情况

 最重要的边缘情况是数组已经排序。 该算法仍然输出$N-1$操作，但每个操作都会保留或重新建立本地顺序，因此不会创建影响正确性的反转。 最终数组保持排序状态，因为每个相邻对都被显式强制为非递减顺序。 

另一种情况是值严格递减。 即使在这里，对每个相邻对的单个操作也可以在本地修复每个反转，并且由于后续操作不会触及较早的索引，因此左侧在纠正后保持稳定。 

最后，当所有值都相等时，每个操作都保持相等，因为分割偶数和会产生相等的两半，而分割奇数和会产生最多相差一但仍处于非递减顺序的两个值。 无需任何特殊处理，该构造仍然有效。
