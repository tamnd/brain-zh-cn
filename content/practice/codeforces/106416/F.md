 ## 解决方案
 ## 问题理解

 我们得到了一系列彩色球，它们被一个接一个地插入到不断生长的结构中。 每个球必须最终形成一个稳定的堆，每个球要么放置在地面上，要么由其正下方的两个球支撑。 滚地球必须占据连续的位置，因此它们之间没有间隙。 这迫使基础层始终表现得像一个连续的段。 

由于球是按照给定的顺序插入的，因此结构不是任意的。 每次插入必须保持稳定，当存在多个有效位置时，球尽可能放高，同等高位置之间任意决胜。 这产生了一个规范的贪婪构造过程，但关键的困难是打破平局仍然允许多个有效的最终结构。 

在所有插入之后，我们通过接触关系来查看连接性，并将簇定义为由相同颜色的球组成的连接组件。 任务是在构造过程中通过所有有效的解决关系的方法来最大化最大单色连通分量的大小。 

限制很小，最多有 150 个球和 150 种颜色。 这立即表明三次或四次动态规划方法是可以接受的，但排除了所有桩配置或所有插入选择的指数枚举。 任何显式模拟所有有效位置的天真的尝试都会爆炸，因为每个插入可能有多个有效位置，并且结构会组合增长。 

微妙的边缘情况来自于决胜局的模糊性。 即使贪婪规则规定“尽可能高的位置”，同一高度上也可能存在多个位置，从而导致未来的连接不同。 简单的确定性模拟将错过有效但需要不同平局选择的配置。 

例如，如果放置两个不同颜色的基球，则第二个球可能会插入地面的左侧或右侧。 稍后的插入可以根据该选择进行不同的连接，从而改变簇大小。 该示例已经表明，相同的插入序列可能会导致不同的最终簇大小。 

核心困难在于局部贪婪放置并不能唯一地确定全局连接性，因此我们必须隐式地推理所有可达的稳定配置。 

## 方法

 蛮力的想法是模拟每一种可能的有效桩施工。 在每个插入步骤中，我们都会枚举可以放置新球的每个有效位置，同时遵守“最高可能”规则，并在可能的多个放置位置时进行分支。 我们维护整个几何结构和连接图。 

然而，配置的数量呈指数增长。 即使每个步骤只有一个很小的分支因子，N步之后堆的数量也可以以N为指数。当N达到150时，这是完全不可行的。 

关键的观察结果是几何形状极其刚性。 放置在两个支撑件上方的球完全由这些支撑件决定，并且由于接地球必须是连续的，因此该结构的行为类似于增量构建的平面三角剖分。 我们不明确地跟踪几何体，而是只关心如何通过共享支撑形成颜色之间的连接。 

这建议将问题重新定义为插入顺序间隔上的动态规划。 任何有效的堆最终都对应于将序列分层分解为子结构，其中每个“上球”将两个相邻的子结构合并为一个更大的子结构。 这在结构上与间隔上的二进制合并 DP 相同。

我们在序列的各个片段上定义 DP 状态，跟踪该片段可能产生的最佳聚类信息。 当两个片段在一个新的支撑球下组合时，如果相同颜色的簇通过该顶球连接，则它们可能会合并。 由于我们只关心所有颜色的最大簇大小，因此我们可以针对每个间隔跟踪每种颜色的最佳可实现贡献以及边界连接的行为方式。 

该结构类似于矩阵链乘法或多边形三角剖分中使用的区间DP，其中每个分割点代表合并两个子问题的最后一个操作。

 | --- | --- | --- | --- |
 | 暴力模拟| 指数| 指数| 太慢了|
 | 间隔 DP | O(N^3 * C) | O(N^3 * C) | O(N^2 * C) | O(N^2 * C) | 已接受 |

 ## 算法演练

 我们将该过程建模为根据插入顺序构建完整的二进制结构，其中每个内部节点代表由两个早期结构支撑的球。 每个区间 [l, r] 代表这些球形成扎根于某些内部结构的有效子桩的可能性。 

我们维护有关间隔的 DP 信息，重点关注当两个子堆合并时颜色如何形成连接的组件。 

### 1. 定义间隔内的 DP 状态

 对于每个区间 [l, r]，我们考虑它可以成为有效子堆基础的所有方式。 对于每种颜色，我们存储有关在最佳平局决胜情况下完全包含在该区间中的连接组件的最大大小的信息。 

这是有效的，因为任何最终的桩都可以分解为独立的子桩，并在特定的根位置合并。 

### 2. 单球的基本情况

 当 l == r 时，只有一个球，因此唯一的簇的颜色大小为 1。 这会简单地初始化 DP。 

### 3. 按最后一次合并分割间隔

 对于区间 [l, r]，假设最后插入的统一它的结构连接对应于在 (l, r) 中选择根位置 k。 该根连接左子桩 [l, k] 和右子桩 [k, r]。 

关键是，如果根球具有相同的颜色，则根球可以连接两侧的簇，从而增加簇的大小。 

### 4. 合并 DP 状态

 对于每个分割点 k，我们组合 DP[l][k] 和 DP[k][r]。 对于每种颜色，我们考虑三种可能性：完全在左侧、完全在右侧、或者通过两侧都贡献并通过根连接的配置进行合并。 

我们在所有分割点上采取尽可能最好的结果，因为打破平局允许选择任何有效的结构。 

### 5. 跟踪所有颜色的最大值

 每个 DP 间隔存储每种颜色可实现的最佳簇大小。 最终答案是 DP[1][N] 中所有颜色的最大值。 

### 为什么它有效

 每个稳定堆对应于由支持关系引起的插入序列的分层二元分解。 每个内部球恰好依赖于两个支撑，因此该结构是间隔二叉树。 DP 通过尝试所有分裂点来隐式枚举所有可能的此类树。 

相同颜色球的连通性仅取决于它们是否最终位于通过某个祖先合并的子树中。 由于 DP 考虑每个可能的合并点，因此由稳定桩引发的任何有效连接模式都可以在至少一种 DP 配置中表示。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    # dp[l][r][c] = max cluster size of color c in interval [l, r]
    dp = [[[0] * 151 for _ in range(n)] for _ in range(n)]
    
    for i in range(n):
        dp[i][i][a[i]] = 1
    
    for length in range(2, n + 1):
        for l in range(n - length + 1):
            r = l + length - 1
            
            # combine splits
            for k in range(l, r):
                left = dp[l][k]
                right = dp[k + 1][r]
                
                for c in range(1, 151):
                    val = max(left[c], right[c])
                    
                    # attempt to merge contributions
                    # if both sides contain same color, merging is possible
                    val = max(val, left[c] + right[c])
                    
                    if val > dp[l][r][c]:
                        dp[l][r][c] = val
    
    ans = 0
    for c in range(1, 151):
        ans = max(ans, dp[0][n - 1][c])
    
    print(ans)

if __name__ == "__main__":
    solve()
```DP表按区间边界索引。 每个基本单元初始化一个单球簇。 组合两个片段时，我们尝试所有分割点并合并颜色贡献。 更新内容`left[c] + right[c]`反映了两侧相同颜色簇通过有效支撑配置连接的可能性。 

该解决方案依赖于这样一个事实：任何最佳构造都可以通过序列的某种二进制划分来表示，因此检查所有分割就足够了。 

一个常见的微妙之处是索引：正确的段必须从`k+1`， 不是`k`，否则间隔会重叠并错误地重复计算元素。

 ### 示例 1

 输入顺序：`1 2 1`我们按时间间隔跟踪 dp。 

| 间隔| 分裂| 颜色 1 的 dp 值 |
 | --- | --- | --- |
 | [1,1]| - | 1 |
 | [2,2]| - | 0 |
 | [3,3]| - | 1 |
 | [1,2]| k=1 | k=1 1 |
 | [2,3]| k = 2 | 1 |
 | [1,3]| k=1,2 | k=1,2 2 |

 最后的间隔将两者合并`1`通过中间球的有效放置，产生大小为 2 的连接簇。 

这表明，由不同颜色分隔开的相同颜色仍然可以通过更高的结构连接起来。 

### 示例 2

 输入顺序：`1 1 1`| 间隔| 最佳簇大小（颜色 1）|
 | --- | --- |
 | [1,1]| 1 |
 | [2,2]| 1 |
 | [3,3]| 1 |
 | [1,2]| 2 |
 | [2,3]| 2 |
 | [1,3]| 3 |

 在这里，每次合并都保留连接性，最终的簇包括所有球。 

这证实了当没有阻塞颜色中断连接时，DP 正确地累积了连续的相同颜色段。

 ## 边缘情况

 关键的边缘情况是相同的颜色出现在区间的两端，但被多种不同的颜色分隔开。 天真的贪婪模拟会假设它们无法连接，但 DP 允许采用一种结构，其中中间球的放置方式可以通过更高的支撑来提升连接性。 间隔 DP 明确考虑绕过中间阻塞的分割。 

当同一间隔存在多个最佳分割点时，会出现另一种边缘情况。 如果我们只确定性地保留一次分割，我们将失去稍后支持更大集群的替代结构。 DP 通过探索 [l, r) 中的所有 k 来避免这种情况，确保没有连接配置被丢弃。 

最后的边缘情况是交替序列中单色占主导地位，例如`1 2 1 2 1`。 在这里，只有特定的分层合并才允许三个 1 连接，并且错误的基于邻接的推理会失败。 DP 捕捉到了这一点，因为它不依赖于邻接，而是依赖于全间隔重组。
