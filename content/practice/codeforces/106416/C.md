 ## 解决方案
 ## 问题理解

 我们在飞机上得到了一组圆形灌溉源。 每个水源都有固定的位置和固定的浇水半径，并且完全覆盖其圈内或圈上的所有内容。 卡米拉想在飞机的任何地方放置另一个圆圈。 这个新圆圈的唯一要求是其边界上的每个点必须位于至少一个灌溉圈内。 卡米拉圆圈的内部根本不重要，只需完全覆盖周边即可。 

任务是最大化这个新圆的半径。 

因此，从几何角度来说，我们正在寻找一个可能的最大圆，使其边界完全被给定圆盘的并集覆盖。 我们构建的圆可以自由放置在任何地方，并且其半径不限于整数。 我们只需要一个高精度的实值最大半径。 

限制很小，最多有 40 个喷头。 这立即表明涉及成对或三重相互作用的解决方案是可以接受的，甚至对子集的三次推理也可能通过。 任何涉及对任意布局进行持续优化的事情都需要减少到一组有限的候选配置。 

对中心和半径的简单连续搜索将会失败，因为两者都是实值并且覆盖条件取决于无限多个边界点。 检查所有圆的直接几何模拟是不可行的。 

当最佳圆不以任何喷水器或交叉点为中心时，就会出现微妙的边缘情况。 许多几何问题隐藏了极值构型发生在边界相互作用处的事实，但在这里我们必须明确地推理圆如何变得“紧”反对圆盘的并集。 

## 方法

 暴力方法会尝试选择一个圆心，然后增加其半径，同时检查整个边界是否被覆盖。 对于固定中心，我们可以对半径进行二分搜索并针对所有磁盘测试许多采样的边界点。 这在概念上是正确的，但从根本上来说是有缺陷的：边界条件是连续的，采样不能保证正确性，甚至密集采样也会太慢。 和$N = 40$，每张支票已经花费$O(N)$，并且对几何图形进行重复的二分搜索很快就会变得不可行。 

关键的观察结果是，圆半径的限制因素始终来自“关键接触事件”。 当圆边界上的某个点恰好位于喷水器圆盘的边缘时，圆停止增长。 这意味着最佳配置是由少量相切约束定义的。 

我们可以翻转视角，而不是思考任意的圆圈。 修复候选半径$R$。 我们问是否存在一个半径为$R$这样其边界上的每个点都被至少一个喷头覆盖。 这就成为一个可行性问题。 如果我们可以测试可行性，我们就可以二分查找答案。 

现在问题减少到检查移动圆边界的覆盖范围。 对于固定中心$C$，边界上有角度的点$\theta$如果存在其磁盘包含该点的喷头，则被覆盖。 每个喷头在半径圆上定义一个覆盖角度间隔$R$以$C$。 所以对于固定的$C$，可行性简化为检查这些角度间隔的并集是否覆盖$[0, 2\pi]$。 

剩下的挑战是选择候选中心。 最佳圆必须是“紧密的”，这意味着它的边界至少以一种关键方式接触到覆盖边界。 这意味着中心必须位于由少量几何约束确定的配置中，通常是偏移圆的交点（喷水器圆扩大或缩小$R$）或单个喷头完全确定覆盖范围的退化情况。 

自从$N \le 40$，我们可以枚举由成对或三组喷头定义的候选中心。 每对定义圆边界以对称方式相切的潜在位置，三元组定义更受约束的交叉点。 对于每个候选中心，我们检查给定的可行性$R$。 

因此完整的解决方案变成了二分搜索$R$，并且对于每个$R$，检查从成对喷头衍生的有限候选中心集，通过角度扫描覆盖范围验证每个中心。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 采样+二分查找| 高，不可靠| 低| 太慢/不正确 |
 | 二分查找+几何候选中心|$O(N^3 \log R)$|$O(N)$| 已接受 |

 ## 算法演练

 我们通过将其转化为半径上的决策问题来解决该问题，然后搜索最佳有效值。 

1.我们定义一个函数`can(R)`检查是否存在半径为圆的圆$R$其边界被至少一个喷水盘完全覆盖。 这将优化问题转化为单调可行性问题。 
2. 我们进行二分查找$R$。 如果一个半径$R$是可行的，那么任何更小的半径也是可行的，因为缩小圆只会使覆盖更容易。 这种单调性证明了二分搜索的合理性。 
3.对于固定的$R$，我们生成候选中心。 关键思想是，如果一个最佳半径的圆$R$存在，那么它的中心必须受到至少一个或两个喷头的约束，这意味着它位于由喷头位置导出的圆的交点处。 我们使用几何构造从成对的喷头中枚举出此类候选中心。 
4. 对于每个候选中心，我们计算角度覆盖区间。 对于每个喷头，我们计算该喷头覆盖边界点的圆上的角度范围。 这是通过使用从中心到喷头的距离和圆相交的几何形状来完成的。 
5. 我们将所有角度间隔标准化为$[0, 2\pi]$，如有必要，分割环绕间隔，并对它们进行排序。 
6. 我们检查这些间隔是否完全覆盖圆。 这相当于在扫描排序间隔时验证不存在未覆盖的间隙。 
7. 如果任何候选中心适用于半径$R$，我们标记$R$尽可能可行。 
8. 继续二分查找，直到达到所需的精度。 

### 为什么它有效

 正确性依赖于这样一个事实：最优解的边界必须由至少一个喷头紧密支持。 这创建了候选中心的有限组合结构。 一旦中心固定，覆盖范围就会减少为角度上的一维区间并集问题。 由于可行性在半径上是单调的，二分搜索保证收敛到最大有效半径。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

EPS = 1e-7

def dist(a, b):
    return math.hypot(a[0] - b[0], a[1] - b[1])

def get_intervals(cx, cy, R, spr):
    intervals = []
    for x, y, r in spr:
        dx = x - cx
        dy = y - cy
        d = math.hypot(dx, dy)

        if d > R + r:
            continue

        if d + R <= r:
            return [(0.0, 2 * math.pi)]

        ang = math.atan2(dy, dx)
        cosv = (d*d + R*R - r*r) / (2*d*R)
        cosv = max(-1.0, min(1.0, cosv))
        delta = math.acos(cosv)

        l = ang - delta
        rgt = ang + delta

        if l < 0:
            l += 2 * math.pi
        if rgt < 0:
            rgt += 2 * math.pi
        if l > 2 * math.pi:
            l -= 2 * math.pi
        if rgt > 2 * math.pi:
            rgt -= 2 * math.pi

        if l > rgt:
            intervals.append((l, 2 * math.pi))
            intervals.append((0.0, rgt))
        else:
            intervals.append((l, rgt))

    intervals.sort()
    cover = 0.0
    for l, r in intervals:
        if l > cover + EPS:
            return False
        cover = max(cover, r)

    return cover >= 2 * math.pi - EPS

def can(R, spr):
    n = len(spr)

    for i in range(n):
        for j in range(i, n):
            x1, y1, r1 = spr[i]
            x2, y2, r2 = spr[j]

            if i == j:
                cx, cy = x1, y1
                if get_intervals(cx, cy, R, spr):
                    return True
                continue

            midx = (x1 + x2) / 2
            midy = (y1 + y2) / 2
            dx = x2 - x1
            dy = y2 - y1
            d = math.hypot(dx, dy)

            if d == 0:
                continue

            h = math.sqrt(max(0.0, 1 - (d / (2 * R)) ** 2)) if R > 0 else 0

            px = -dy / d
            py = dx / d

            cx1 = midx + px * R * h
            cy1 = midy + py * R * h
            cx2 = midx - px * R * h
            cy2 = midy - py * R * h

            if get_intervals(cx1, cy1, R, spr):
                return True
            if get_intervals(cx2, cy2, R, spr):
                return True

    return False

def solve():
    n = int(input())
    spr = []
    for _ in range(n):
        x, y, r = map(int, input().split())
        spr.append((x, y, r))

    lo, hi = 0.0, 3000.0

    for _ in range(60):
        mid = (lo + hi) / 2
        if can(mid, spr):
            lo = mid
        else:
            hi = mid

    print(f"{lo:.10f}")

if __name__ == "__main__":
    solve()
```二分查找驱动解决方案，而`can`函数将几何图形简化为有限的候选中心。 区间构造步骤是从 2D 几何图形到 1D 角度覆盖的核心简化，这使得可行性检查易于管理。 

最微妙的部分是正确处理圆弧环绕，因为角度间隔自然存在于圆而不是直线上。

 ## 边缘情况

 当所有喷头效果相同或严重重叠时，交叉区域内的任何中心都变得有效，并且算法可以正确识别自对生成的任何候选中心的可行性。 

当最佳圆正好位于两个喷头之间的中点时，基于对的候选生成可确保明确测试该中心。 

当覆盖间隔环绕时$0$弧度，分成两段，确保在覆盖检查中不会出现人为间隙。 

当喷头完全覆盖圆形边界时，间隔生成中的早期返回立即标志着可行性，避免了不必要的几何复杂性。
