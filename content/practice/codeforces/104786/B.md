 ## 解决方案
 ## 问题理解

 我们有一棵树\(N\)节点。 John 希望选择不相交的节点对，但限制是仅当沿树的两个节点之间的距离为偶数时，该对才有效。 每个节点最多可以出现在一个选定的对中，目标是在某个对中仅使用每个节点一次。 

问题很简单，就是在这条规则下是否存在完美的配对。 

约束条件\(N \le 5 \cdot 10^5\)排除任何尝试显式测试配对或搜索匹配的行为。 对所有节点对进行二次检查已经需要大约\(10^{11}\)在最坏的情况下进行操作，远远超出了时间限制。 即使是立方体或基于流的方法也是不必要的，并且对于树木的结构观察来说会太慢或过度杀伤力。 

如果试图在本地进行推理，就会出现一个微妙的问题。 例如，人们很容易想到，既然我们可以以偶数距离配对节点，我们可能需要仔细构建路径或按距离贪婪地匹配节点。 这是失败的，因为每对距离并不是独立的。 将一个节点配对会改变其他节点的可用性。 

考虑一个包含三个节点的简单路径：```
1 - 2 - 3
```有效的偶数距离对是 (1,3)。 节点 2 无法与任一端点配对，因此正确答案是否定的。 天真的贪婪尝试可能会配对 (1,2) 或 (2,3)，但这些对是无效的，因为它们的距离为 1。 

另一个例子：```
1 - 2 - 3 - 4
```这里 (1,3) 和 (2,4) 是有效的，因此存在完整的配对。 任何不认识全局奇偶结构的方法都将难以一致地区分这些情况。 

## 方法

 关键的观察是，在一棵树中，距离奇偶性完全由二分着色决定。 如果我们将树植根于任何地方，则每个节点都会获得一个深度，并且两个节点之间的距离奇偶校验等于它们深度奇偶校验的异或。 这意味着两个节点的距离相等当且仅当它们位于二分的同一侧时。 

因此，问题不再是关于路径的几何形状，而是关于按深度奇偶性对节点进行分组。 每个有效对都必须在这两个组中的一个内形成。 

暴力方法将计算所有对的最短路径或检查每个可能的节点配对，验证约束并尝试构建完美匹配。 即使我们假设一个聪明的匹配例程，该结构仍然是矫枉过正，因为唯一的约束是“相同的奇偶校验组”。 瓶颈不是正确性，而是组合爆炸：配对决策呈阶乘增长。 

一旦我们将问题简化为二分着色，剩下的问题是每个颜色类是否可以完全划分为对。 当且仅当集合的大小为偶数时，集合才能被划分为不相交的对。 由于对永远不会在颜色类别之间交叉，因此每一方都必须独立地具有偶数基数。 

这将整个树问题简化为单个 DFS 着色和两个奇偶校验。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 暴力配对搜索 | 指数| O(N) | 太慢了 |
 | BFS/DFS二分着色+奇偶校验 | O(N) | O(N) | 已接受 |

 ## 算法演练

 1. 在任意节点处将树作为根，为了方便节点 1. 运行 DFS 或 BFS 来计算每个节点的深度奇偶校验。 这将每个节点分配到两个组之一，具体取决于它与根的距离是偶数还是奇数。 

2. 维护两个计数器，每个奇偶组一个。 

3. 遍历树时，增加每个节点奇偶校验对应的计数器。 

4. 遍历结束后，检查两个计数器是否为偶数。 如果任一计数器为奇数，则立即返回 NO，因为该组无法完全分成对。 

5. 如果两个计数器都是偶数，则返回 YES，因为我们可以在每个组内任意配对节点。 

重要的隐藏步骤是认识到一旦按奇偶校验对节点进行分区，就不再有进一步的结构约束。 同一奇偶校验类中的任何两个节点在树中的距离都是偶数，因此类内的每个配对都是有效的。 

### 为什么它有效

 树是二分树，因此在有根遍历中每条边都连接相对的奇偶校验节点。 这意味着两个节点之间的路径长度的奇偶性仅取决于它们的深度是否具有相同的奇偶性。 这样，允许的配对关系就变成了“二分着色中的相同颜色”。 

在每个颜色类别中，诱导的限制图是完整的：每对都是有效的。 因此，完美配对的唯一条件是每个类具有偶数个节点，因为配对每次都会将计数减少 2，并且不允许跨类配对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    g = [[] for _ in range(n + 1)]
    
    for _ in range(n - 1):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)
    
    color = [-1] * (n + 1)
    stack = [(1, 0)]
    color[1] = 0
    
    cnt = [0, 0]
    
    while stack:
        u, c = stack.pop()
        color[u] = c
        cnt[c] += 1
        
        for v in g[u]:
            if color[v] == -1:
                stack.append((v, c ^ 1))
    
    if cnt[0] % 2 == 0 and cnt[1] % 2 == 0:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```该解决方案构建树邻接表并执行迭代 DFS 以避免给定的递归深度问题\(N\)最多\(5 \cdot 10^5\)。 着色使用简单的 XOR 翻转来交替父项和子项之间的奇偶性。 

柜台`cnt[0]`和`cnt[1]`累加每个二分边的大小。 最终条件直接实现了每侧必须在内部完美配对的要求。

 ## 边缘情况

 对于\(N=1\)，DFS 将单个节点分配给大小为 1 的一个奇偶校验类。由于配对需要偶数大小的组，因此算法立即返回 NO。 

对于四个节点的路径\(1-2-3-4\)，着色在每个奇偶校验类中生成两个节点。 两个计数都是偶数，算法输出“是”。 这与有效配对 (1,3) 和 (2,4) 匹配，确认不存在超出奇偶校验的结构约束。 

对于星形树，中心具有一个奇偶性，所有叶子具有相反的奇偶性。 如果叶子的数量是奇数，则一个类的大小变为奇数，并且算法正确地拒绝这种情况，因为无论配对策略如何，一个叶子都将保持不匹配。
