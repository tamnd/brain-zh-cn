 ## 解决方案
 ## 问题理解

 我们给定一个整数数组，并且可以重复选取至少长度的子数组`k`并减少该子数组中的每个元素对两个给定值之一的模`p`或者`q`。 目标是在任意数量的此类操作之后最小化数组的总和。 每个测试用例都会给出一个新的数组，并且所有测试用例的元素总数不超过 100,000，因此我们需要一个大致线性的解决方案`n`。 

关键的观察是模运算永远不会增加数字； 它只会将其减少到小于所选模数的余数。 所以，对于任意元素`a[i]`，唯一可能的减少是`a[i] % p`和`a[i] % q`。 但我们不能任意对单个元素应用模； 该操作至少需要一个连续的长度间隔`k`。 如果`k = 1`，我们总是可以独立地减少每个元素，但是当`k > 1`，我们必须尊重这个区间约束。 这就是问题变得非同小可的原因。 

尝试所有间隔和所有模数选择的简单实现会太慢。 为了`n`大约100,000，枚举所有可能的间隔在最坏的情况下是O(n²)，这是不可行的。 此外，粗心的实现可能会错误地处理所有元素都小于的情况`p`和`q`或者只有某些重叠间隔才能减少某些元素。 例如，如果`a = [10, 10, 10]`,`k = 2`， 和`M = {3, 4}`，不能只减少第一个元素； 模数必须应用于大小为 2 或 3 的间隔。 

## 方法

 蛮力方法至少会迭代所有长度间隔`k`，并且对于每个间隔，尝试用两者来减少它`p`和`q`。 每次减少都会更新数组，我们将不断重复，直到不可能进一步减少为止。 原则上这是可行的，但每个测试用例可能需要最多 O(n²) 次操作，并且总共`n`所有测试用例的数量为 10⁵，使得这种方法太慢。 此外，跟踪哪些间隔仍然可以减少元素会增加额外的开销。 

最佳方法利用了这样一个事实：对于每个元素，可实现的最小值就是`min(a[i] % p, a[i] % q)`是否可以将该元素包含在至少长度的区间中`k`。 什么时候`k = 1`，这是微不足道的。 为了`k > 1`，我们需要一种策略来确保每个元素至少被一个区间覆盖。 贪心方法之所以有效，是因为任何连续的长度间隔`k`允许我们减少该区间内的最大元素。 为了全局最小化总和，我们可以扫描数组并将其视为滑动窗口问题：对于每个长度的窗口`k`，将窗口中的所有元素减少到可实现的最佳模数。 重叠窗口确保每个元素最终都减少到它可以实现的最小可能模数。 

关键的见解是，重叠间隔允许我们应用模约简，以便可以尽可能地减少每个元素，而不必担心操作的确切顺序。 这将问题简化为简单地找到每个元素的最小可实现值（假设区间覆盖它）。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳 | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个元素`a[i]`，用两者计算其模`p`和`q`并存储两者中较小的一个。 如果选择包含该元素的区间，则给出该元素可以实现的最小值。 
2. 由于间隔必须至少有长度`k`，检查是否`k = 1`。 如果是，则每个元素都可以独立地实现其最小模数。 
3.如果`k > 1`，使用长度的滑动窗口从左到右处理数组`k`。 在每个窗口中，用预先计算的最小模值替换元素。 由于窗口重叠，每个元素都保证被至少一个窗口覆盖，因此每个元素最终都达到其最小可实现模数。 
4. 对结果数组求和以获得尽可能小的总和。 

为什么它有效：不变的是每个元素都包含在至少一个长度区间中`k`因为滑动窗口重叠。 通过始终将窗口中的元素减少到可实现的最小模数，在任何后续操作中都不能进一步减少任何元素，从而保证全局最小和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k, p, q = map(int, input().split())
        a = list(map(int, input().split()))
        # compute minimal modulo for each element
        min_mod = [min(x % p, x % q) for x in a]
        # if k == 1, each element can be reduced independently
        if k == 1:
            print(sum(min_mod))
            continue
        # if k > 1, every element can be covered by at least one interval
        # so the minimal sum is just sum of min_mod
        print(sum(min_mod))

if __name__ == "__main__":
    solve()
```在此解决方案中，我们首先使用以下方法预先计算每个元素的最小可实现值`min(a[i] % p, a[i] % q)`。 的特殊情况是`k = 1`是明确处理的，但是对于`k > 1`，滑动窗口保证每个元素至少包含在一个区间中，因此最小和就是这些预先计算值的总和。 这避免了必须显式模拟操作。
