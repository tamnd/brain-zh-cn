 ## 解决方案
 ## 问题理解

 我们有一个$n \times m$板和从左下角开始的芯片。 在每一回合中，玩家精确选择一个方向（向上或向右），并将芯片沿该方向移动任意奇数个单元格。 芯片不能离开电路板。 

当筹码到达不存在合法移动的位置时，游戏结束。 由于玩家交替轮流并且都发挥最佳状态，因此我们需要确定起始位置是第一个玩家 Burenka 获胜，还是第一个玩家失败，在这种情况下，Tonya 获胜。 

输入由几个独立的游戏板组成。 对于每块棋盘，我们必须打印假设完美发挥的获胜者。 

约束是数学解存在的主要线索。 两个尺寸都可以大到$10^9$，这使得任何探索董事会状态的方法都是不可能的。 即使单块板也包含多达$10^{18}$细胞，并且可以有$10^4$测试用例。 该解决方案必须可简化为每个测试用例在恒定时间内计算的简单公式。 

一个常见的错误是关注芯片的精确坐标而不是游戏的奇偶校验结构。 

考虑董事会：```
1 1
```上方或右侧没有单元格，因此第一个玩家无法移动。 正确答案是：```
Tonya
```如果粗心地假设第一个玩家总是至少有一个奇怪的动作，那么在这里就会失败。 

另一个棘手的情况是：```
2 2
```唯一合法的举动是向上一级或向右一级。 任何一步都会立即给对手最后一步。 正确答案是：```
Tonya
```许多玩家最初猜测每个棋盘都大于$1 \times 1$是胜利，但事实并非如此。 

最后一个例子是：```
1 4
```第一个玩家可以向右移动三个单元格并立即完成游戏​​。 正确答案是：```
Burenka
```任何仅基于董事会规模而不是奇偶性的方法都很难解释原因$1 \times 4$和$1 \times 3$表现不同。 

## 方法

 最直接的方法是将每个棋盘位置建模为游戏状态并计算它是赢还是输。 让状态代表芯片的当前坐标。 如果存在向失败州移动的情况，则该州获胜；如果每次合法移动都导致获胜州，则该州失败。 

这个递归是正确的，因为它遵循公正博弈的标准定义。 不幸的是，它几乎立即变得不可行。 即使对于一个谦虚的$1000 \times 1000$棋盘上有一百万个状态，每个状态可能有数百个出局动作。 实际约束允许尺寸达到$10^9$，使得状态探索完全不可能。 

要找到模式，请手动计算一些小板。 让$f(n,m)$表示筹码从棋盘左下角开始时的游戏状态$n \times m$木板。 

终端位置是$f(1,1)$，正在丢失。 

现在检查小值：

 | 董事会| 结果 |
 | --- | --- |
 | 1×1 | 左 |
 | 1×2 | 西 |
 | 1×3 | 左 |
 | 1×4 | 1×4 西 |
 | 2×1 | 西 |
 | 2×2 | 左 |
 | 2×3 | 2×3 西 |
 | 3×3 | 3×3 左 |

 出现清晰的图案。 职位所在$n$和$m$拥有相同的奇偶校验都在丢失。 双方实力不同的位置就会获胜。 

为什么奇偶校验很重要？ 

一次移动恰好将一个坐标改变了奇数。 添加奇数总是会翻转奇偶校验。 因此，每一步都会翻转一个维度的奇偶性。 

仅通过奇偶校验对表示状态：$$(n \bmod 2,\; m \bmod 2)$$失败的状态$(1,1)$对应端子板$1 \times 1$。 

如果两个维度具有相同的奇偶校验，则每次合法的移动都会恰好更改一个奇偶校验位，从而产生具有不同奇偶校验的状态。 

如果维度具有不同的奇偶性，则总有一个移动使它们相等。 由于移动奇数会翻转一个奇偶校验，因此我们可以选择合法的奇数移动，适当减少一维并达到相同奇偶校验状态。 

因此：

 - 相同的奇偶校验$\rightarrow$失去。 
- 奇偶校验不同$\rightarrow$获胜。 

整个游戏归结为奇偶校验。

 ## 算法演练

 1. 阅读$n$和$m$。 
2. 使用以下方法计算两个维度的奇偶性$n \bmod 2$和$m \bmod 2$。 
3. 如果奇偶校验相等，则打印`"Tonya"`。 

这些位置正在失败，因为每一步棋都恰好翻转一个奇偶性并将游戏发送到不同奇偶性的位置。 
4. 否则，打印`"Burenka"`。 

从不同平局的位置来看，第一个玩家总是可以做出奇怪的举动，从而创造平等的平局，使对手处于失败状态。 

### 为什么它有效

 关键的不变量是每一个合法的举动都会翻转恰好一个维度的奇偶性。 这意味着可以完全通过奇偶对来分析游戏$(n \bmod 2, m \bmod 2)$。 

平等的国家正在失败，因为每一步都会达到不同的平等状态。 具有不同平等地位的国家正在获胜，因为存在向平等平等国家迈进的趋势。 由于每个位置都属于这两个类别之一，因此分类是完整且正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, m = map(int, input().split())

    if (n & 1) == (m & 1):
        print("Tonya")
    else:
        print("Burenka")
```该解决方案仅需要两个维度的奇偶性。 使用`n & 1`和`m & 1`是计算每个数字是奇数还是偶数的紧凑方法。 

比较检查奇偶校验是否匹配。 平局意味着起始位置失败，所以托尼亚获胜。 不同的平价意味着获胜的起始位置，因此布伦卡获胜。 

不需要模拟，并且不存在溢出问题，因为仅使用奇偶校验。 尺寸可能大到$10^9$，但计算时间保持恒定。

## 测试用例```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n, m = map(int, input().split())
        ans.append("Tonya" if ((n & 1) == (m & 1)) else "Burenka")

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out
