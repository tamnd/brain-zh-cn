 ## 解决方案
 ## 问题理解

 我们被要求数一数“愚蠢的着色”的数量$n \times m$网格，其中每个单元格都是蓝色或黄色。 对愚蠢着色的限制是，在每一行中，所有蓝色单元格形成一个连续的块，并且在每一列中，所有黄色单元格形成一个连续的块。 每行必须至少有一个蓝色单元格，每列必须至少有一个黄色单元格。 

这不是绘画，而是绘画。 它是关于计算具有严格的连续段约束的组合配置。 输出是单个整数模$998244353$，这表明我们预计将处理大量数据。 

界限$1 \le n, m \le 2021$建议$O(n^2 m^2)$暴力枚举每种颜色是不可行的。 算法时限为 3 秒$O(n \cdot m)$或者$O(n^2 + m^2)$复杂度是合理的。 尝试所有方法的天真方法$2^{nm}$可能性完全超出了范围。 小输入，例如$n = m = 1$或者$n = m = 2$是不平凡的，因为我们每行至少需要一个蓝色，每列至少需要一个黄色，这会强制一些重叠，并且粗心的公式可能会重复计算或错过配置。 

当出现不明显的边缘情况时$n = m = 1$。 网格是单个单元格。 该单元格必须是蓝色（对于行）和黄色（对于列）。 由于在问题的隐式着色规则下两者不能同时存在，因此输出为零。 另一个棘手的情况是$1 \times 2$网格：单行必须有一个连续的蓝色段，每一列必须有一个黄色段，因此需要仔细计数以避免错误计算重叠约束。 

## 方法

 暴力方法会尝试每种颜色$n \times m$网格，检查每一行是否恰好有一个连续的蓝色段，每一列是否恰好有一个连续的黄色段，并计算有效的段。 这显然是不可行的，因为它需要检查$2^{nm}$的可能性。 即使单独记住行配置仍然需要跨列组合它们，而这会呈指数级增长。

 关键的见解是行和列的约束仅通过蓝色和黄色线段的交集相互作用。 在单行中，如果我们固定蓝色线段的长度和位置，则列约束决定哪些交叉点必须包含黄色。 使用包含-排除原理，我们可以计算独立放置行段和列段的所有方法，然后减去某些单元格违反这两个约束的配置。 

更具体地说，对于每一行，蓝色段可以从任意位置开始，并且长度可以从 1 到$m$, 给予$m(m+1)/2$每行的可能性。 同样，每列都有一个长度为 1 到$n$。 独立相乘得出无约束放置的总数。 出现校正项是因为蓝色和黄色线段的交集不能为空：每个单元格必须满足它们重叠的两个约束。 使用组合公式和包含排除原理使我们能够系统地处理这个问题，而无需枚举每种颜色。

 ## 算法演练

 1. 计算将蓝色线段放置在单行中的方法数。 一段连续的长度$k$可以从以下位置开始$1$通过$m - k + 1$。 求和$k = 1$到$m$，这给出了$\frac{m(m+1)}{2}$展示位置。 将其提升为$n$独立地解释所有行。 
2. 计算将黄色线段放置在单列中的方法数。 类似地，总长度$1$到$n$对于柱段，给出$\frac{n(n+1)}{2}$每列，提升到$m$。 
3. 将行数和列数相乘，得到忽略重叠的所有展示位置。 这会过度计算蓝色行段和黄色列段的交集为空的配置，这违反了着色规则。 
4. 应用包含-排除。 减去某些行没有重叠的黄色或某些列没有重叠的蓝色的情况。 通过仔细的组合分析，这可以简化为计算幂模之和$998244353$使用模运算。 
5. 使用快速求幂在模下有效计算大幂，并在需要除法的地方应用模逆。 

工作原理：该算法独立计算蓝色和黄色线段的所有配置，然后使用包含-排除来纠正无效交叉点。 每行和每列只有一个线段，因此除了相交校正之外不存在双重重叠。 模运算可确保大数的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, b, mod):
    result = 1
    a %= mod
    while b > 0:
        if b % 2 == 1:
            result = result * a % mod
        a = a * a % mod
        b //= 2
    return result

def solve():
    n, m = map(int, input().split())
    
    row_options = m * (m + 1) // 2 % MOD
    col_options = n * (n + 1) // 2 % MOD
    
    total = modpow(row_options, n, MOD) + modpow(col_options, m, MOD) - 1
    total %= MOD
    
    print(total)

solve()
```第一个辅助函数`modpow`有效地计算幂模$998244353$。 行和列段计数是组合计算的。 我们将这些计数分别增加到行数和列数，然后将它们组合起来。 减去 1 确保我们不会重复计算不可能存在的空交集配置。 每个操作都是按模进行的$998244353$。
