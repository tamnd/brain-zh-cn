 ## 解决方案
 ## 问题理解

 爱丽丝和鲍勃正在填写一个$n \times n$网格。 每次爱丽丝都会首先宣布一种颜色$\{1,2,3\}$。 然后，鲍勃必须选择一个空单元格并放置一个不同颜色的标记。 

如果两个边缘相邻的单元格最终具有相同的颜色，鲍勃将立即失败。 他的目标是填补整个董事会的空缺，同时避免此类冲突。 

在最初的交互版本中，Alice 自适应地选择颜色。 在 Codeforces 上使用的黑客版本中，我们提前获得了 Alice 未来的所有颜色选择。 我们只需要输出鲍勃移动的任何有效序列。 

电路板尺寸最大为$100 \times 100$，所以最多有$10^4$轮流。 任何每次移动执行恒定工作量的解决方案都足够快。 挑战不在于计算复杂性，而在于无论 Alice 的选择如何，构建始终合法的动作。 

第一个微妙之处是鲍勃不能简单地用一种固定颜色贪婪地给单元格着色。 考虑$n=2$和爱丽丝反复选择颜色$1$。 如果鲍勃总是用颜色来回应$2$，相邻单元格最终会获得相同的颜色，并出现冲突。 

另一个容易犯的错误是正确划分了棋盘，但忘记了鲍勃选择的颜色必须与爱丽丝当前的颜色不同。 假设一个单元格属于应该接收颜色的组$1$。 如果爱丽丝也宣布的话$1$, Bob 不能使用该颜色，必须暂时使用颜色$3$反而。 

第三个陷阱在游戏接近尾声时出现。 一个分区可能会先于另一分区变空。 一旦该分区用完单元，始终尝试从首选分区播放的解决方案就会失败。 该策略必须明确处理仅剩下一个分区的情况。 

## 方法

 蛮力思维是独立对待每一个动作。 给定爱丽丝的颜色，搜索所有空单元格和所有允许的颜色，寻找保持棋盘无冲突的移动。 这样的举动总是存在的，但证明它并干净利落地实施它是很困难的。 即使我们每回合扫描整个棋盘，复杂度也大致为$O(n^4)$： 有$n^2$轮流，并且每轮都可以检查$O(n^2)$细胞。 和$n=100$，到达周围$10^8$运营。 

关键的观察来自网格图的结构。 棋盘着色将单元格分成两个独立的组。 每条边连接一个黑色单元和一个白色单元。 

假设我们保留颜色$1$对于所有黑色单元格和颜色$2$对于所有白细胞。 如果我们始终遵循该计划，则相邻单元格将自动具有不同的颜色，因为相邻单元格属于相反的分区。 

Alice 一次只能阻止一种颜色。 如果她说$1$，我们仍然可以放置颜色$2$。 如果她说$2$，我们仍然可以放置颜色$1$。 唯一困难的情况发生在保留颜色可用的分区已经用完时。 

解决方案是维护两个列表：

 - 一个棋盘奇偶性的单元格，与颜色相关$1$。 
- 其他奇偶性的细胞，与颜色相关$2$。 

只要两个列表都不为空，Alice 的选择就决定了我们使用哪个分区。 如果爱丽丝说$1$，我们从颜色中取出一个单元格$2$分区并油漆它$2$。 如果爱丽丝说$2$，我们从颜色中取出一个单元格$1$分区并油漆它$1$。 如果爱丽丝说$3$，任一分区都有效。 

最终一个分区会变空。 此时，所有剩余单元都属于另一个分区。 他们保留的颜色有时可能会被爱丽丝禁止。 当这种情况发生时，我们使用颜色$3$反而。 由于所有剩余的单元格都位于同一个棋盘分区中，因此它们都不相邻，因此引入颜色$3$不能制造冲突。

 | ---| ---| ---| ---|
 | 蛮力 |$O(n^4)$|$O(n^2)$| 太慢/不必要|
 | 最佳|$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 根据棋盘奇偶性将所有棋盘单元分成两组。 

细胞具有$(i+j)\bmod 2=0$进入第一组。 细胞具有$(i+j)\bmod 2=1$进入第二组。 
2. 预留颜色$1$对于第一组和颜色$2$对于第二组。 

如果严格遵循预留，该分配保证相邻小区将接收到不同的颜色。 
3.对于Alice宣布的每种颜色，首先检查两个组是否仍然包含未使用的单元格。 
4.如果两个组都非空并且Alice选择了颜色$1$，从第二组中取出任何未使用的单元格并将其涂上颜色$2$。 

颜色$2$是合法的，因为它与爱丽丝的颜色不同。 
5.如果两个组都非空并且Alice选择了颜色$2$，从第一组中取出任何未使用的单元格并将其涂上颜色$1$。 
6.如果两个组都非空并且Alice选择了颜色$3$，选择任一组。 按照惯例，使用第一组并为其着色$1$。 
7. 如果第一组为空，则所有剩余单元格都属于第二组。 

他们的保留颜色是$2$。 

如果爱丽丝不选择$2$，用以下内容绘制剩余的单元格$2$。 

否则用$3$。 
8. 如果第二组为空，则所有剩余单元格都属于第一组。 

他们的保留颜色是$1$。 

如果爱丽丝不选择$1$，用以下内容绘制剩余的单元格$1$。 

否则用$3$。 

### 为什么它有效

 不变的是第一个棋盘分区中的每个单元格都接收任一颜色$1$或者，当被迫时，颜色$3$。 第二个分区中的每个单元格都接收任一颜色$2$或者，当被迫时，颜色$3$。 

虽然两个分区都可用，但我们从不使用颜色$3$。 每个分区仅接收其保留的颜色，因此相邻的单元格始终具有不同的颜色。 

一旦一个分区变空，所有剩余的单元都属于一个棋盘分区。 同一分区内的两个单元格不相邻。 用颜色替换保留颜色$3$必要时不会产生冲突，因为该分区中没有相邻小区。 

每个动作都使用与爱丽丝选择不同的颜色，并且每个单元格只使用一次。 因此，棋盘被完全填充，而不会创建相同颜色的相邻单元格。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    alice = list(map(int, input().split()))

    p1 = []
    p2 = []

    for i in range(n):
        for j in range(n):
            if (i + j) % 2 == 0:
                p1.append((i + 1, j + 1))
            else:
                p2.append((i + 1, j + 1))

    ans = []

    for a in alice:
        if p1 and p2:
            if a == 1:
                x, y = p2.pop()
                ans.append((2, x, y))
            elif a == 2:
                x, y = p1.pop()
                ans.append((1, x, y))
            else:
                x, y = p1.pop()
                ans.append((1, x, y))

        elif p1:
            x, y = p1.pop()

            if a == 1:
                ans.append((3, x, y))
            else:
                ans.append((1, x, y))

        else:
            x, y = p2.pop()

            if a == 2:
                ans.append((3, x, y))
            else:
                ans.append((2, x, y))

    sys.stdout.write(
        "\n".join(f"{c} {i} {j}" for c, i, j in ans)
    )

solve()
```两个数组`p1`和`p2`存储两个棋盘分区未使用的单元格。 删除一个单元格`pop()`是$O(1)$，所以每一步都需要不断的努力。 

第一个分支处理主阶段，其中两个分区仍然包含单元。 Alice 的选择决定了哪种保留颜色仍然可用。 我们立即使用相应分区中的一个单元。 

第二和第三个分支处理残局。 只剩下一个分区，因此我们尽可能使用其保留的颜色。 如果爱丽丝阻挡了该颜色，我们就会切换到颜色`3`。 

该实现使用基于 1 的索引存储坐标，因为问题输出期望编号为`1`。
