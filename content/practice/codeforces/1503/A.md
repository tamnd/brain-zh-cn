 ## 解决方案
 ## 问题理解

 我们被要求构造两个括号序列，`a`和`b`，与给定的二进制字符串长度相同`s`。 每个位置在`s`规定了之间的关系`a`和`b`： 如果`s[i]`是`1`， 然后`a[i]`和`b[i]`必须相等，并且如果`s[i]`是`0`， 然后`a[i]`和`b[i]`一定是不同的。 两个序列都必须是平衡的括号序列，这意味着当我们从左到右遍历每个字符串时，左括号的数量`(`永远不会低于右括号的数量`)`，以及总数`(`等于总计数`)`。 

输入提供多个测试用例。 每串长度`n`是偶数，这对于平衡括号是必要的。 全部的总和`n`不超过 200,000，因此我们需要一种在每个测试用例的线性时间内工作的方法。 尝试每种括号组合的天真的方法需要`2^n`尝试并且是不可行的。 当数量太多时就会出现边缘情况`0`s，使得不可能同时满足等/差约束和平衡条件。 例如，`s = "1001"`这是不可能的，因为它迫使一种无法维持平衡的配置。 

## 方法

 蛮力方法将尝试所有可能的放置`(`和`)`在两个序列中。 对于每个长度的序列`n`， 有`2^n`选项，我们需要检查每对的相等/差异条件。 这在原则上是正确的，但对于`n`最多200,000。 

最佳解决方案的关键见解来自于观察所施加的约束`s`。 职位与`1`将括号强行插入`a`和`b`是相同的，所以我们可以对称地分配它们。 为了保持平衡，我们必须将一半`1`作为`(`和一半`)`。 职位与`0`力量`a[i]`和`b[i]`不同，这表明了一种“触发器”模式：我们可以交替`(`和`)`之间`a`和`b`跨越这些位置。 然而，要实现这一点，需要有`0`s 必须是偶数； 否则，交替留下一个不匹配的括号。 

观察将问题简化为计算`1`沙`0`并确保它们的奇偶性允许对称和交替分配。 一旦我们有了这个，序列的构建就很简单了。

 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，请阅读`n`和`s`。 初始化空列表`a`和`b`。 
2. 数数`1`沙`0`进入`s`。 如果第一个或最后一个字符是`0`，或数量`0`s 是奇数，立即打印“NO”。 这是因为平衡序列不能以`)`和交替`0`s 必须均匀配对。 
3. 计算`half_ones = count_ones // 2`。 这代表了多少`(`分配给`1`上半场，并且`)`分配给剩余的`1`s。 
4. 初始化计数器`ones_used = 0`和一个翻转标志`0`s，最初`True`。 
5. 迭代中的每个字符`s`。 如果是的话`1`， 分配`(`对双方`a`和`b`如果`ones_used < half_ones`; 否则分配`)`对两者。 增量`ones_used`每个之后`1`。 
6. 如果是`0`， 分配`(`到`a`和`)`到`b`如果翻转标志是`True`; 分配`)`到`a`和`(`到`b`如果翻转标志是`False`。 每次之后切换翻转标志`0`。 
7. 构建序列后，打印“YES”，然后打印`''.join(a)`和`''.join(b)`。 

为什么有效：分配通过放置一半来确保序列平衡`1`作为`(`和一半`)`。 交替`0`s 防止一个序列累积的开局数多于闭局数。 对第一个和最后一个字符以及奇偶校验的边缘约束`0`保证平衡是可能的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    
    ones = s.count('1')
    zeros = s.count('0')
    
    if s[0] == '0' or s[-1] == '0' or zeros % 2 != 0:
        print("NO")
        continue
    
    a = []
    b = []
    half_ones = ones // 2
    ones_used = 0
    flip = True
    
    for ch in s:
        if ch == '1':
            if ones_used < half_ones:
                a.append('(')
                b.append('(')
            else:
                a.append(')')
                b.append(')')
            ones_used += 1
        else:
            if flip:
                a.append('(')
                b.append(')')
            else:
                a.append(')')
                b.append('(')
            flip = not flip
    print("YES")
    print(''.join(a))
    print(''.join(b))
```该解决方案首先过滤不可能的情况，然后通过维护以下不变量来构造序列：`(`永远不会低于`)`以任一顺序。 计数`1`s 确保对称放置，同时交替`0`s 满足不同的约束。
