 ## 解决方案
 ## 问题理解

 我们得到一个连通的无向图，其中每条边代表一条具有独特能源成本的走廊。 戴立克夫妇总是打算构建一棵最小生成树，因此在所有可能的生成树中，他们会选择总成本最小的一棵，这是唯一确定的，因为所有边权重都是不同的。 

对于当前不属于最小生成树的每个走廊，我们都会被问到一个非常具体的敏感性问题。 我们想象增加或减少该走廊的权重，并且我们希望将其设置为最大值，同时仍然有机会使该走廊成为某个最小生成树的一部分。 换句话说，我们要求最大阈值权重，在该阈值权重下，这条边仍然具有足够的竞争力，可以被 MST 结构选择。 

从根本上来说，这是一个关于 MST 稳定性的结构性问题：非树边在保证被排除在每个 MST 之外之前会变得多么“昂贵”。 

约束足够大，任何尝试重新计算每条边的最小生成树的解决方案都立即不可能。 对于多达 10^6 条边，即使重复 m 次 O(m log n) MST 计算也会远远超出可行的限制。 即使每个查询的图遍历也太慢； 我们需要对 MST 进行一次全局预处理，然后对每个边进行快速查询。 

循环产生了一种微妙的边缘情况。 考虑一个三角形，其中 MST 选择两个最小的边并拒绝最大的边。 如果我们增加被拒绝的边的权重，它显然会保持被拒绝的状态。 但如果我们将其减小得足够多，它可能会取代循环中的最大边。 关键的微妙之处在于，重要的不仅仅是邻接性，还有 MST 中端点之间路径上的最大边。 

## 方法

 蛮力的想法很简单。 对于每条非 MST 边，我们临时修改其权重并重新计算 MST。 然后，我们对仍包含边缘的最大权重进行二分搜索。 每个 MST 计算成本为 O(m log n)，并且对最多 m 个边执行此操作会导致 O(m^2 log n)，这在 10^6 条边上完全不可行。 

关键的观察结果来自 MST 的循环特性。 当我们向 MST 添加任何非树边时，它恰好创建一个循环。 MST 条件告诉我们，如果该边不比该边重，则该边只能替换该周期中最重的边。 因此，对于一条边（u，v）来说，重要的是当前MST中u和v之间的唯一路径上的最大边权值。 

如果我们将 u 和 v 之间的 MST 路径上的最大边权重表示为 maxEdge(u, v)，那么我们可以分配给 (u, v) 的最大权重恰好是 maxEdge(u, v)，同时仍允许在某些 MST 中选择它。 如果它更大，它将比该周期上的所有边严格更差，并且永远无法进入 MST。 如果它等于或小于，则存在平局情况，可以替换该最大边。 

这将问题简化为回答树中路径上的最大边缘查询，这是具有二元提升问题的经典 LCA。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 重新计算每条边的 MST | O(m^2 log n) | O(m^2 log n) | O(n) | 太慢了 |
 | MST+LCA路径最大查询次数| O(m log n) | O(n log n) | O(n log n) | 已接受 |

 ## 算法演练

 我们首先使用 Kruskal 算法构建图的最小生成树。 由于所有权重都是不同的，因此该 MST 是唯一的，这简化了推理。 

然后，我们将 MST 视为有根树，并对其进行预处理以进行二元提升。 对于每个节点，我们以两个距离的幂存储祖先，以及到每个祖先的路径上的最大边权重。 这使我们能够在对数时间内计算任何路径上的最大边权重。

接下来，对于原始图中不属于 MST 的每条边，我们计算沿 MST 中其端点之间的路径的最大边权重。 该值就是该边缘的答案。 

1. 按权重对所有边进行排序，并运行 Kruskal 算法来构建 MST，同时记录包含哪些边。 这是有效的，因为 Kruskal 通过始终采用最小的安全边缘来保证最小的总重量。 
2. 构建 MST 的邻接表表示。 
3. 在任意节点处建立 MST 并运行 DFS 来计算父节点、深度以及父节点的边权重。 这建立了用于提升的基础结构。 
4. 构建二元升降台`up[k][v]`是 v 的第 2^k 个祖先，`mx[k][v]`是从 v 到该祖先的最大边权重。 此步骤将路径压缩为对数跳跃。 
5. 对于每个非 MST 边 (u, v)，使用提升表计算 u 和 v 之间沿 MST 路径的最大边权重。 结果是通过在跟踪最大边缘权重的同时向上提升更深的节点，然后向上同步两个节点直到它们相遇而获得的。 
6. 输出每个非树边的最大值。 

正确性取决于在每个提升步骤中的不变量，我们正确地维持了迄今为止在部分路径上看到的最大边缘权重。 由于任何路径都被分解为两个段的幂，因此所有边在分解中只被考虑一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n, m = map(int, input().split())
edges = []
for i in range(m):
    a, b, w = map(int, input().split())
    edges.append((w, a - 1, b - 1, i))

parent_ds = list(range(n))
rank = [0] * n

def find(x):
    while parent_ds[x] != x:
        parent_ds[x] = parent_ds[parent_ds[x]]
        x = parent_ds[x]
    return x

def union(a, b):
    ra, rb = find(a), find(b)
    if ra == rb:
        return False
    if rank[ra] < rank[rb]:
        ra, rb = rb, ra
    parent_ds[rb] = ra
    if rank[ra] == rank[rb]:
        rank[ra] += 1
    return True

edges.sort()

mst = [[] for _ in range(n)]
in_mst = [False] * m

for w, a, b, i in edges:
    if union(a, b):
        in_mst[i] = True
        mst[a].append((b, w))
        mst[b].append((a, w))

LOG = 20
up = [[-1] * n for _ in range(LOG)]
mx = [[0] * n for _ in range(LOG)]
depth = [0] * n

def dfs(v, p):
    for to, w in mst[v]:
        if to == p:
            continue
        up[0][to] = v
        mx[0][to] = w
        depth[to] = depth[v] + 1
        dfs(to, v)

for i in range(n):
    if up[0][i] == -1:
        dfs(i, -1)

for k in range(1, LOG):
    for v in range(n):
        if up[k-1][v] != -1:
            up[k][v] = up[k-1][up[k-1][v]]
            mx[k][v] = max(mx[k-1][v], mx[k-1][up[k-1][v]])

def get_max(u, v):
    if depth[u] < depth[v]:
        u, v = v, u
    ans = 0

    diff = depth[u] - depth[v]
    for k in range(LOG):
        if diff & (1 << k):
            ans = max(ans, mx[k][u])
            u = up[k][u]

    if u == v:
        return ans

    for k in reversed(range(LOG)):
        if up[k][u] != up[k][v]:
            ans = max(ans, mx[k][u], mx[k][v])
            u = up[k][u]
            v = up[k][v]

    ans = max(ans, mx[0][u], mx[0][v])
    return ans

res = []
for w, a, b, i in edges:
    if not in_mst[i]:
        res.append((i, get_max(a, b)))

res.sort()
for _, val in res:
    print(val)
```Kruskal 部分构建 MST 并同时标记哪些边被排除。 这很重要，因为只有排除的边缘才需要答案。 

DFS 初始化直接父值和边到父值。 然后，二进制提升表将其扩展到两次跳转的所有幂，确保每个路径查询都可以在 O(log n) 内得到答复。 

这`get_max`函数首先小心地提升更深的节点，始终更新迄今为止看到的最大边缘。 最后的合并步骤处理 LCA 之前的最后两条边。 

一个常见的陷阱是忘记单独跟踪祖先节点的边权重。 提升结构必须存储边缘信息，而不仅仅是父级信息。

 ### 示例 1

```MST 边是权重为 3 的 (2,3) 和权重为 4 的 (3,1)。

 | --- | --- | --- | --- |
 | (1,2,8) | 没有 | 最大(4,3) = 4 | 4 |

 非MST边连接1和2。它们之间的MST路径是1-3-2，该路径上最大的边是4。这成为限制阈值。 

### 示例 2

 输入：```
4 5
1 2 10
2 3 5
3 4 7
1 4 6
2 4 8
```假设 MST 选择 (2,3,5), (3,4,7), (1,4,6)。 

| 边缘 | 在 MST | MST 中的最大路径 | 输出|
 | --- | --- | --- | --- |
 | (1,2,10) | 没有 | 最大路径 1-4-3-2 = 7 | 7 |
 | (2,4,8) | 没有 | 路径 2-3-4 = 7 | 7 |

 每个答案完全对应于端点之间唯一 MST 路径上最重的边。

 ## 边缘情况

 当两个端点之间的 MST 路径很长但最大边靠近树的顶部时，就会出现一种棘手的情况。 该算法可以处理此问题，因为二进制提升始终首先考虑最高相关段，确保在计算最大值时不会错过路径上的边缘。 

另一种情况是，多条边通过 MST 中的不同路由连接相同的高层区域。 即便如此，答案仅取决于 MST 中的唯一路径，并且提升结构通过构造强制执行唯一性，因此计算的最大值不会出现歧义。
