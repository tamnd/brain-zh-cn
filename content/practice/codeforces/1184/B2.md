 ## 解决方案
 ## 问题理解

 星系是由虫洞连接的行星组成的小图，其中行星之间的距离被测量为该图中的最小边数。 在这个基础设施之上，有两种参与者：帝国船只和叛军基地。 每艘船都位于一个星球上，具有攻击力，并且燃料有限。 每个基地也坐落在一个星球上并具有防御价值。 

只有当一艘船足够强大并且其燃料足以沿着图中的最短路径到达基地时，一艘船才能摧毁一个基地。 每个有效的舰到基地分配每艘舰最多可以使用一次，每个基地最多可以使用一次，因此底层结构是两个集合之间的匹配问题，但具有由图形距离和强度定义的可行性约束。 

每个受到攻击的真实基地都会造成固定的金币损失。 叛军还可以建造任何船只都可以到达的人工基地，并且总是具有足够的吸引力，以至于船只会被分配给他们。 这些虚拟基地不会直接造成金币损失，但每一个虚拟基地的建造都需要金币，并且每个虚拟基地在匹配时会消耗一艘舰船。 

目标是决定引入多少个虚拟基地，以便最终将船只分配给基地，最大限度地增加攻击次数，从而使净黄金损失最小化。 

图表很小，最多有 100 个行星，但最多可以有 1000 艘飞船和 1000 个基地。 这立即表明，可以使用 Floyd-Warshall 有效地预先计算图上的最短路径，时间约为$100^3$操作，主要的计算挑战是具有几千条边的图上的二分匹配问题。 

尝试模拟每个分配或在添加虚拟碱基后重复重新计算匹配的简单方法会太慢，因为如果重新计算多次，最大二分匹配本身在这种规模上已经很昂贵。 

一些微妙的情况很重要。 

第一种边缘情况是由于燃料或强度限制，没有船只能够到达任何基地。 如果没有虚拟基地，答案是零，但引入虚拟基地可能会迫使船只被使用，从而可能增加成本。 

第二个边缘情况是所有船只已经与所有基地匹配。 在这种情况下，虚拟基地只会降低效率，因为它们用无用的攻击代替有利可图的攻击。 

第三种边缘情况是虚拟碱基比每个碱基的黄金损失便宜得多。 那么，即使存在真实基地，故意在虚拟基地上“浪费”船只就变得最优，这极大地改变了最优解的结构。 

## 方法

 核心困难是理解虚拟碱基对匹配结构的实际作用。 如果我们忽略虚拟基地，问题就简化为在船舶和基地之间构建二分图，如果船舶可以攻击基地，则存在一条边。 任务变成寻找最大匹配，因为每个匹配的碱基都会贡献固定的损失。 

让$M_0$是在实际基础上最大匹配的大小。 如果不存在虚拟基地，这是被攻击的真实基地的基线数量。 

暴力策略会尝试所有可能数量的虚拟碱基$D$，每次重建二分图，并重新计算最大匹配。 由于每个匹配计算已经存在$O(E\sqrt{V})$或者更糟，并且$D$可以达到 1000，但这很快就变得不可行。 

关键的结构观察是虚拟基地与真实基地有根本的不同：​​每艘船都可以与每个虚拟基地相匹配。 这意味着虚拟基地充当通用水槽，仅强制额外使用船舶，而不限制可行性。 

一旦认识到这一点，添加的效果$D$虚拟碱基变得可预测。 它们只是增加了始终可以匹配的可用右侧顶点的数量，从而允许消耗超出实际基地已使用的额外船只。 

因此，我们不是重复地重新计算匹配，而是分析最大匹配值如何随着以下函数而变化：$D$。 这将问题从动态匹配简化为单个整数变量的封闭式优化。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 重新计算每个虚拟碱基数量的匹配 |$O(B \cdot \text{matching})$|$O(n^2)$| 太慢了 |
 | 预计算最短路径+一次二分匹配+解析公式 |$O(n^3 + E\sqrt{V})$|$O(n^2 + E)$| 已接受 |

 ## 算法演练

 我们首先将星系转换为最短路径距离。 然后我们构建船舶和真实基地之间的二部图，并计算其最大匹配。 

1. 计算行星图上的所有对最短路径。 这给出了任意两个行星之间的最小旅行成本，这是测试船舶是否可以在燃料限制内到达基地所需要的。 
2. 构建一个二分图，其中每艘船位于左侧，每个基地位于右侧。 如果飞船的攻击足以满足基地的要求并且其燃料至少是行星之间的最短路径距离，则添加一个优势。 此步骤将物理约束转化为纯粹的组合可行性。 
3. 计算最大匹配$M_0$在此图上。 这代表在没有任何虚拟干预的情况下可以攻击的最大真实基地数量。 
4. 观察虚拟基地的行为方式：每个虚拟基地都连接到所有船只，因此它始终可以与任何当前未使用的船只相匹配。 
5.让$s$是船舶的数量。 如果我们添加$D$虚拟底座，匹配尺寸变为$$M(D) = M_0 + \min(D, s - M_0)$$因为每个假人只能贡献一场新的比赛，直到所有船只都被使用为止。 
6. 总成本取决于匹配的真实碱基数量。 真实比赛平等$M(D) - D$，所以损失是$$k \cdot (M(D) - D) + hD$$7. 分裂为两个政权。 为了$D \le s - M_0$，真正的比赛保持不变$M_0$，因此成本随$hD$。 为了$D > s - M_0$，所有船只均已使用，并且不断增加$D$减少真实匹配，给出斜率$h-k$。 
8. 从这个结构中，最优解总是出现在边界值处：$D = 0$或者$D = s$。 这导致了一个封闭的形式：$$\min(k \cdot M_0,\; h \cdot s)$$### 为什么它有效

 与真实基的匹配由可行性约束固定，而虚拟基仅添加通用兼容的顶点。 这些顶点不能改善真实比赛的结构，它们只能重新分配船舶未使用的容量。 因此，唯一有意义的权衡是支付$k$每个真实匹配的基地或付费$h$每艘船完全转向虚拟用途。 一旦建立了这种二分法，中间值$D$不可能是最优的，因为成本函数是分段线性的，没有内部最小值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    INF = 10**9

    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        dist[u][v] = dist[v][u] = 1

    for k in range(n):
        for i in range(n):
            di = dist[i]
            dk = dist[k]
            for j in range(n):
                nd = di[k] + dk[j]
                if nd < di[j]:
                    di[j] = nd

    s, b, k_gold, h = map(int, input().split())

    ships = []
    for _ in range(s):
        x, a, f = map(int, input().split())
        ships.append((x - 1, a, f))

    bases = []
    for _ in range(b):
        x, d = map(int, input().split())
        bases.append((x - 1, d))

    adj = [[] for _ in range(s)]
    for i, (sx, sa, sf) in enumerate(ships):
        for j, (bx, bd) in enumerate(bases):
            if sa >= bd and dist[sx][bx] <= sf:
                adj[i].append(j)

    match = [-1] * b

    def dfs(u, vis):
        for v in adj[u]:
            if not vis[v]:
                vis[v] = True
                if match[v] == -1 or dfs(match[v], vis):
                    match[v] = u
                    return True
        return False

    m0 = 0
    for i in range(s):
        vis = [False] * b
        if dfs(i, vis):
            m0 += 1

    ans = min(k_gold * m0, h * s)
    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先将星系压缩为全距离矩阵，以便船舶和基地之间的每次可行性检查都成为恒定时间。 这避免了重复的 BFS 查询。 

然后，它构建可行攻击的二部图，并运行标准的基于 DFS 的 Kuh 算法来实现最大二部匹配。 这已经足够了，因为$s, b \le 1000$并且该图足够稀疏$O(sb)$最坏情况下的边缘。 

最后，它不是模拟虚拟基，而是应用派生的封闭式表达式。 关键的实现决策是我们从不显式添加虚拟节点； 它们的全部效果都体现在最终的公式中。

 ## 边缘情况

 当没有船只可以到达任何基地时，匹配尺寸为零。 在这种情况下，该公式简化为将零实际增益与可能为正的虚拟成本进行比较，因此最佳解决方案是完全避免虚拟基数，除非$h = 0$，其中任意数量的虚拟碱基变得等效。 

当每艘船都可以到达每个基地时，匹配就变得纯粹是容量限制的。 该决定归结为将舰艇分配到真实基地还是虚拟基地是否更便宜。 导出的公式通过比较直接捕获了这一点$k \cdot M_0$和$h \cdot s$，并且匹配计算确保$M_0 = \min(s, b)$在这个完全连接的情况下。 

当燃料限制很严格时，一些船舶在二分图中被隔离。 这些船只仅在解决方案的第二项中通过虚拟基地做出贡献，并且匹配算法正确地使它们在真实阶段中不匹配，从而保留了$M_0$。
