 ## 解决方案
 ## 问题理解

 我们得到一个连通的无向图，其中每条边代表一个具有相关能源成本的时间走廊。 戴立克一家不一定使用所有走廊。 相反，他们总是选择一组连接所有节点的走廊，同时最小化总能量成本，这正是最小生成树的定义。 

我们对特定的边感兴趣，即输入中的第一个边。 我们想象我们可以将其权重修改为我们想要的任何值。 对于每个可能的修改值，我们询问是否存在仍包含该边的最小生成树。 任务是找到权重的最大值，使得这条边仍然属于至少一个 MST。 

输出是描述第一个边缘的阈值的单个整数。 

约束最多为 100,000 个节点和 1,000,000 个边，这立即排除了任何从头开始为每个候选权重重新计算 MST 的解决方案。 即使单个 MST 构造在 O(m log m) 内也很好，但每个边或每个查询重复它就会太慢。 我们必须从一次 MST 计算中提取结构信息并重用它。 

一个微妙的问题是，一条边可能属于某个 MST，即使它不是 Kruskal 构建的特定 MST 的一部分。 这意味着我们处理的是 MST 灵活性，而不是单个固定树。 另一个重要的边缘情况是多个边缘具有相同的权重，因为平局打破允许多个有效的 MST。 

## 方法

 直接方法会尝试改变第一条边的权重并重新计算它是否出现在 MST 中。 对于固定权重，我们可以运行 Kruskal 并检查包含情况。 然后我们可以在权重范围内二分搜索答案。 每个 MST 计算成本为 O(m log m)，二分搜索增加了大约 30 的因子，导致在最坏的情况下每次测试大约需要 3e7 个对数因子操作，这对于 1e6 条边来说太慢了。 

关键的观察是，边缘是否可以出现在某些 MST 中不是由全局重新计算决定的，而是由 MST 结构中的局部瓶颈决定的。 如果我们构建图的任何 MST，我们可以通过查看树中端点之间的唯一路径来分析每个非树边。 如果我们尝试将该边插入树中，该路径确定必须替换的最大权重边。 

这引出了一个标准的 MST 敏感性思想：当且仅当一条边的权重不严格大于最小生成树中其端点之间的路径上的最大边权重时，一条边才可以成为某个 MST 的一部分。 因此，如果我们知道 MST 并且可以回答路径上的最大边查询，我们就可以计算第一条边的阈值。 

为了支持快速路径最大查询，我们建立 MST 并构建一个二进制提升结构，存储跳跃时的最大边权重。 然后，我们可以计算第一条边 (u, v) 沿路径的最大边权重（O(log n)），并且该值成为该边保持符合某些 MST 资格的最大允许权重。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 重新计算每个值的 MST | O(m log m log W) | O(m log m log W) | O(米) | 太慢了 |
 | MST+LCA路径最大值| O(m log m + n log n) | O(m log m + n log n) | O(n log n) | O(n log n) | 已接受 |

 ## 算法演练

1. 使用 Kruskal 算法构建图的最小生成树。 这给出了一个基线树，它以最小的总成本保留了所有必要的连接。 MST 结构对节点之间的所有关键瓶颈进行编码。 
2. 将MST以任意节点为根，例如节点1，并准备一个二进制提升表。 每个条目不仅存储节点的第 2^k 个祖先，还存储到该祖先的路径上的最大边权重。 这允许快速重建路径信息。 
3. 使用 MST 的 DFS 遍历来预先计算深度和父指针。 在 DFS 期间，记录从其父节点通向每个节点的边权重，因为这成为提升的基本情况。 
4. 自下而上构建二元升降台。 对于每个节点和跳跃长度，通过取存储的边权重的最大值来组合两个较小的跳跃。 这确保每次跳跃都对沿该路径段看到的最重边缘进行编码。 
5. 从输入中取出第一条边 (u, v, w)。 我们使用提升结构计算 MST 内 u 和 v 之间路径的最大边权重。 为此，请将较深的节点提升到相同的深度，然后将两个节点一起提升，同时跟踪遇到的最大边权重。 
6. 令该最大值为 M。答案为 M。这表示可以在不增加 MST 成本的情况下替换沿 MST 路径的边的阈值，这意味着边仍可以属于某些 MST 配置。 

### 为什么它有效

 MST 具有循环属性：对于不在 MST 中的任何边，添加它会创建一个循环，并且该循环上最重的边不能是任何更喜欢较小权重的 MST 的一部分。 相反，如果边权重不严格大于其端点之间的 MST 路径上的最大边，我们可以替换 MST 中的该边，而不会增加总成本。 这准确地表征了权重修改后边缘何时可以出现在某些 MST 中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def find(x, parent):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

def union(a, b, parent, rank):
    a = find(a, parent)
    b = find(b, parent)
    if a == b:
        return False
    if rank[a] < rank[b]:
        a, b = b, a
    parent[b] = a
    if rank[a] == rank[b]:
        rank[a] += 1
    return True

n, m = map(int, input().split())
edges = []

for i in range(m):
    a, b, w = map(int, input().split())
    edges.append((w, a, b, i))

edges.sort()

parent = list(range(n + 1))
rank = [0] * (n + 1)

mst_adj = [[] for _ in range(n + 1)]
used = [False] * m

for w, a, b, i in edges:
    if union(a, b, parent, rank):
        mst_adj[a].append((b, w))
        mst_adj[b].append((a, w))
        used[i] = True

LOG = 20
up = [[0] * (n + 1) for _ in range(LOG)]
mx = [[0] * (n + 1) for _ in range(LOG)]
depth = [0] * (n + 1)

def dfs(v, p):
    for to, w in mst_adj[v]:
        if to == p:
            continue
        depth[to] = depth[v] + 1
        up[0][to] = v
        mx[0][to] = w
        dfs(to, v)

dfs(1, 0)

for k in range(1, LOG):
    for v in range(1, n + 1):
        up[k][v] = up[k-1][up[k-1][v]]
        mx[k][v] = max(mx[k-1][v], mx[k-1][up[k-1][v]])

def query_max(u, v):
    if depth[u] < depth[v]:
        u, v = v, u
    ans = 0

    diff = depth[u] - depth[v]
    for k in range(LOG):
        if diff & (1 << k):
            ans = max(ans, mx[k][u])
            u = up[k][u]

    if u == v:
        return ans

    for k in reversed(range(LOG)):
        if up[k][u] != up[k][v]:
            ans = max(ans, mx[k][u], mx[k][v])
            u = up[k][u]
            v = up[k][v]

    ans = max(ans, mx[0][u], mx[0][v])
    return ans

u, v, w = edges[0][1], edges[0][2], edges[0][0]
print(query_max(u, v))
```该代码首先使用 Kruskal 构建 MST，确保我们拥有一棵保留最小连接结构的树。 DFS 初始化提升所需的父级信息和深度信息。 二进制升降台存储祖先和最大边缘权重，这是至关重要的，因为我们不仅对结构感兴趣，而且对每次跳跃的最重约束感兴趣。 

这`query_max`功能是核心组件。 它仔细地均衡深度，然后爬升两个节点，同时保持不变式，即我们始终知道迄今为止在已处理的路径段上看到的最大边权重。 最终结果是第一条边端点之间唯一 MST 路径上的最大边权重。 

一个常见的陷阱是忘记初始化`up[0][root]`和`mx[0][root]`，这会破坏提升的一致性。 另一个微妙的问题是，DFS 假设图是连通的并且根为 1，由于问题保证，该图成立。

 ## 边缘情况

 关键的边缘情况是多个边缘具有相同的权重。 在这种情况下，MST 不是唯一的，并且第一条边可能会也可能不会出现，具体取决于决胜局。 该算法可以正确处理此问题，因为路径最大值仅捕获严格的瓶颈，而不是 MST 结构的唯一性。 

另一种边缘情况是第一条边缘本身就是 MST 的一部分。 例如，如果第一条边很轻并且在 Kruskal 早期连接两个组件，那么它将被包括在内。 路径最大值仍将返回正确的阈值，因为在任何替代 MST 中不需要用较重的边缘替换该边缘。 

最后一个微妙的情况是当图已经是一棵树时。 那么 MST 就是图本身，第一条边的端点之间的路径就是边本身。 路径上的最大值等于其自身的重量，这正确地表明，将其增加到超过该重量将迫使在其他地方用更重的边缘进行替换，从而将其排除在任何 MST 之外。
