 ## 解决方案
 ## 问题理解

 我们有一排按顺序排列的宇宙，每个宇宙编号从 1 到$n$，医生从位置开始$k$。 多元宇宙可以根据一系列操作随时间变化。 操作可以在两个现有宇宙之间或末端插入一个新宇宙，也可以断开两个宇宙之间的链接，导致**不**包含Doctor的片段消失。 每次操作后，我们必须报告宇宙总数和博士的更新位置。 

输入给出初始长度$n$, 医生的立场$k$，允许的最大宇宙$m$，以及操作次数$t$。 每个操作指定一个插入或一个基于 1 的索引的链接中断。 我们需要按顺序模拟每个步骤，并在每个步骤之后输出当前状态。 

限制很小：$n, m \le 250$和$t \le 1000$。 这立即告诉我们，可以在每个操作的线性时间内直接模拟操作，因为最大多元宇宙尺寸很小并且$t$是适中的。 边缘情况涉及末端操作，特别是当 Doctor 位于位置 1 或最后一个宇宙时，因为断开链接可能会删除整个左侧或右侧部分。 

例如，如果多元宇宙的长度为 3，Doctor 位于位置 1，并且我们断开链接 1，则右侧部分消失，将 Doctor 留在单宇宙多元宇宙中的位置 1。 简单的基于 0 的数组实现可能会错误地计算新的 Doctor 位置，因为索引在插入或删除后会发生变化。 

## 方法

 蛮力方法很简单：维护一个 Universe 数组，并在每次操作发生时显式插入或删除元素。 通过将元素从插入点向右移动来处理插入，并通过对数组进行切片以保留包含 Doctor 的段来断开链接。 每一次操作都需要$O(n)$最坏情况下的时间，但自从$n$最多为 250，这将在 1000 个步骤中产生最多 250,000 次数组操作，这在 1 秒时间限制下是可以接受的。 

稍微更优化的方法的关键见解是我们根本不需要存储宇宙的内容; 只需要多元宇宙的长度和博士索引。 插入会增加长度，如果插入在医生位置之前或位置，可能会移动医生。 链接中断会缩短长度，并且还可能根据幸存的片段改变医生的位置。 通过仔细更新两个整数，我们可以模拟所有操作$O(1)$每一步的时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力阵列模拟 | O(t * n) | O(n) | 由于小的限制而被接受 |
 | 优化长度和位置跟踪 | O(t) | O(1) | O(1) | 接受并清洁|

 ## 算法演练

 1.从初始多重宇宙长度开始$l = n$以及医生的立场$k$。 
2. 对于顺序中的每个操作，读取类型$op$和索引$i$。 
3.如果$op$为 1（插入），增加长度$l$1. 如果$i \le k$, 增量$k$因为所有宇宙都在位置$\ge i$向右移动，如果医生位于插入点或插入点之后，则将其向右移动一步。 如果$i > k$，博士的立场保持不变。 
4.如果$op$为0（链接中断），判断哪个段包含Doctor。 如果$i < k$，Doctor 位于右段； 中断之后，多元宇宙缩减为$l - i$医生的新职位是$k - i$，因为左边的部分消失了。 如果$i \ge k$，医生在左段； 中断之后，多元宇宙缩减为$i$博士的职位仍然存在$k$。 这样处理就自然结束了。 
5. 每次操作后输出当前长度和医生位置。 

这是可行的，因为多元宇宙始终是线性的，并且可以通过简单的算术来跟踪博士的相对位置。 不需要实际宇宙的数组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k, m, t = map(int, input().split())
length = n

for _ in range(t):
    op, i = map(int, input().split())
    if op == 1:
        # insertion
        if i <= k:
            k += 1
        length += 1
    else:
        # link break
        if i < k:
            # Doctor in right segment
            k -= i
            length -= i
        else:
            # Doctor in left segment
            length = i
    print(length, k)
```该解仅维护两个整数：多重宇宙长度和医生的位置。 在插入过程中，如果插入发生在医生当前位置之前或当前位置，则医生会向右移动。 在链接中断期间，我们确定哪一侧包含 Doctor 并相应地调整长度和位置。 边界情况（例如在第一个或最后一个位置插入，或者断开第一个或最后一个链接）会自然处理，无需额外检查。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = []
    n, k, m, t = map(int, input().split())
    length = n
    for _ in range(t):
        op, i = map(int, input().split())
        if op == 1:
            if i <= k:
                k += 1
            length += 1
        else:
            if i < k:
                k -= i
                length -= i
            else:
                length = i
        out.append(f"{length} {k}")
    return "\n".join(out)

# provided sample
assert run("5 2 10 4\n0 1\n1 1\n0 4\n1 2\n") == "4 1\n5 2\n4 2\n5 3"

# minimum-size input
assert run("2 1 2 2\n1 1\n0 1\n") == "3 2\n1 1"

# maximum-size insertion
assert run("250 125 250 1\n1 126\n") == "251 126"

# breaking first link with Doctor at end
assert run("5 5 10 1\n0 1\n") == "4 4"

# consecutive left-breaks
assert run("5 3 10 2\n0 1\n0 1\n") == "4 2\n3 1"
