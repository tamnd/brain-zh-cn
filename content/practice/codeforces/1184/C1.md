 ## 解决方案
 ## 问题理解

 我们在网格上得到一小组点，其中几乎所有点都恰好位于轴对齐正方形的边界上。 只有一个点是例外，并且严格位于正方形内。 任务是识别单个内部点。 

没有明确给出平方。 相反，我们从点的分布来推断：它的四个边上每一边都有很多点，并且恰好有一个点不属于边界。 由于正方形是轴对齐的，因此它的边界由以下形式的四条线组成$x = L$,$x = R$,$y = B$， 和$y = T$。 

输入尺寸非常小。 我们最多有$n = 10$，所以总点数为$4n + 1 \le 41$。 这立即排除了对性能的任何担忧。 甚至一个$O(n^2)$或者$O(n^3)$这种方法在这里很简单，但是一旦确定了方形边界，该结构就可以进行更简单的线性扫描。 

如果我们尝试仅使用点的子集来推断平方，例如采用前几个点或假设第一个不同的 x 和 y 值对应于边界，则会出现微妙的失败情况。 如果输入顺序是对抗性的，这些假设就会被打破。 正确的方法必须依赖于频率或全局结构，而不是顺序。 

## 方法

 暴力策略会尝试通过依次删除每个点并检查剩余点是否可以形成有效的方形边界来猜测哪个点是内部点。 对于每个候选删除，我们将重新计算最小和最大 x 和 y 值，并验证所有剩余点是否位于这四条线上。 这是有效的，因为如果删除内点，则正方形是唯一确定的。 

然而，这种方法反复重新计算边界条件，导致$O(N^2)$最多检查41点。 虽然这仍然很快，但它是不必要的开销并且隐藏了问题的真实结构。 

关键的观察结果是，正方形的边界完全由四个极值定义：最小 x、最大 x、最小 y 和最大 y。 每个有效的边界点必须至少位于这四条线中的一条上。 内部点是唯一违反此条件的点，这意味着它的 x 不等于 minX 或 maxX，并且它的 y 不等于 minY 或 maxY。 

因此，我们首先从完整数据集中恢复方形边界，而不是测试候选者。 一旦我们知道了 minX、maxX、minY 和 maxY，我们就扫描一次以找到唯一不在这些边界线上的点。

 | 蛮力 | O(N^2) | O(N^2) | O(1) | O(1) | 已接受但没有必要 |

 ## 算法演练

 1. 将所有点读入列表，以便我们可以计算全局极值。 这是必要的，因为方形边界取决于所有点，而不是局部结构。 
2. 计算`min_x`,`max_x`,`min_y`， 和`max_y`跨越所有点。 这些定义了候选方的边界。 
3. 迭代每个点并检查它是否位于任何边界线上。 一个点在边界上，如果`x == min_x`或者`x == max_x`或者`y == min_y`或者`y == max_y`。 
4. 不满足此条件的第一个点必须是内点。 立即输出。 

步骤 3 背后的原因是轴对齐正方形的每个边界点必须恰好位于其四个边中的至少一个上。 任何不满足这一点的点都必须严格位于内部。 

### 为什么它有效

 边界点集形成由极值坐标定义的完整矩形。 由于该问题保证除一个点之外的所有点都位于该边界上，因此计算的极值不会以消除有效性的方式受到内部点的影响：如果所有边都充分填充，则内部点不能同时成为两个轴上的极值。 因此，真正的方形边界恰好是全局最小/最大值，并且只有内部点违反了四个边界线的并集中的成员资格。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = []
    m = 4 * n + 1

    min_x = 10**9
    max_x = -10**9
    min_y = 10**9
    max_y = -10**9

    for _ in range(m):
        x, y = map(int, input().split())
        pts.append((x, y))
        if x < min_x:
            min_x = x
        if x > max_x:
            max_x = x
        if y < min_y:
            min_y = y
        if y > max_y:
            max_y = y

    for x, y in pts:
        if x != min_x and x != max_x and y != min_y and y != max_y:
            print(x, y)
            return

if __name__ == "__main__":
    solve()
```实现直接遵循算法。 第一遍在线性时间内计算边界矩形。 第二遍识别不位于任何边界线上的唯一点。 条件写得明确，避免组合逻辑出错； 内部条件是对至少一个边界的否定。 

一个常见的错误是尝试单独对 x 或 y 值使用基于频率的启发式方法。 这是失败的，因为边界点出现在垂直和水平边缘上，因此频率不是唯一标识的。 正确的测试是边界线并集的几何隶属度。

 ## 边缘情况

 一种边缘情况是正方形位于尽可能小的坐标处，例如两个轴上的 0 到 1。 极值计算仍然可以正确识别最小值和最大值，因为所有边界点都存在。 

输入：```
1
0 0
0 1
1 0
1 1
0 2
```此处，min_x = 0、max_x = 1、min_y = 0、max_y = 2。算法根据这些值检查每个点。 只有(1,1)不满足所有边界条件，因此被正确识别。 

另一种边缘情况是当输入顺序将内部点放在第一位时。 由于该算法不依赖顺序并在滤波之前计算全局极值，因此结果保持不变。
