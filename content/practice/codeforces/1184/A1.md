 ## 解决方案
 ## 问题理解

 这个问题给了我们一个函数$H(x, y) = x^2 + 2xy + x + 1$，和一个正整数$r$。 我们需要判断是否存在一对正整数$(x, y)$这样$H(x, y) = r$。 如果存在多对，我们必须返回最小的一对$x$，否则我们返回“NO”。 输入$r$可以大到$10^{12}$，因此任何解决方案都必须有效地处理非常大的整数。 

因为$x$和$y$是正整数，我们立即知道$H(x, y)$至少成倍增长$x$并线性地$y$。 如果$r$很小，很多很大$x$值不可能起作用，所以迭代$x$只有达到某个合理的界限才是可行的。 如果$r$非常大，我们无法迭代所有可能的$x, y$天真的配对，因为$x$大约可以达到$\sqrt{r}$，放弃$10^6$候选人，以及$y$可能会达到类似的幅度，产生不可行的$10^{12}$运营。 

当出现微妙的边缘情况时$x = 1$或者$y = 1$，因为这些是最小的正整数并产生最小的输出$H$。 例如，如果$r = 4$， 然后$H(1,1) = 1 + 2 + 1 + 1 = 5$，它已经大于$r = 4$。 不检查的幼稚算法$x = 1$可能会错误地得出“NO”的结论。 另一个边缘情况是当$r$本身是一个完全平方加上一个小的线性项，例如$r = 19$在样本中，解决方案是$x = 1, y = 8$。 

## 方法

 蛮力方法会迭代所有可能的方法$x$从 1 到$\sqrt{r}$，并且对于每个$x$, 计算$y$通过求解方程$H(x, y) = r$明确地为$y$。 重写，我们得到$x^2 + 2xy + x + 1 = r \implies 2xy = r - x^2 - x - 1 \implies y = \frac{r - x^2 - x - 1}{2x}$。 该公式保证整数$y$如果分子能被$2x$。 蛮力方法之所以有效，是因为$x$大致不能超过$\sqrt{r}$，所以对于$r = 10^{12}$,$x$只会达到$10^6$，这在操作上是可以接受的。 

得出最佳解决方案的关键观察是我们不需要考虑$y$独立。 对于每位候选人$x$，我们可以直接计算$y$从上面的公式可以看出。 如果$y$结果是积极且完整的，我们有一个有效的解决方案。 这将问题减少到一个循环$x$而不是两者上的嵌套循环$x$和$y$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(sqrt(r) * sqrt(r)) | O(1) | O(1) | 对于 r = 10^12 | 来说太慢了
 | 最佳| O(sqrt(r)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 从迭代开始$x$从 1 向上。 最大$x$考虑的是满足的最大整数$x^2 + x + 1 \le r$， 因为$2xy$总是非负的，所以$x^2 + x + 1 > r$将使方程不可能成立。 
2. 对于每个$x$，计算分子$num = r - x^2 - x - 1$。 这代表必须完全正确的剩余部分$2xy$满足方程。 
3. 检查是否$num$可以整除$2x$。 如果不是，则没有整数$y$为此而存在$x$，所以继续下一步$x$。 
4. 如果可整除，计算$y = num // (2x)$。 如果$y$为正，返回该对$(x, y)$立即，因为我们正在扫描$x$按升序排列，并且保证是尽可能最小的$x$。 
5. If no such$x$产生一个有效的正整数$y$，打印“否”。 

为什么它有效：公式$y = \frac{r - x^2 - x - 1}{2x}$封装了正整数解的整个搜索空间。 迭代$x$按升序排列保证第一个有效对具有最小的$x$。 停止条件确保我们永远不会认为不可能$x$价值观。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

r = int(input())

x = 1
found = False
while x * x + x + 1 <= r:
    num = r - x * x - x - 1
    if num % (2 * x) == 0:
        y = num // (2 * x)
        if y > 0:
            print(x, y)
            found = True
            break
    x += 1

if not found:
    print("NO")
```循环停止一次$x^2 + x + 1$超过$r$，因为较大$x$不能产生积极的$y$。 模检查确保$y$是一个整数。 我们明确检查$y > 0$强制执行积极性约束。
