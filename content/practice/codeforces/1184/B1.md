[CF 1184B1 - 医生遇见维达（简单）](https://codeforces.com/problemset/problem/1184/B1)

 **评分：** 1400
 **标签：** 二分查找、排序
 **求解时间：** 5m 28s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 每艘飞船都有一定的攻击力。 每个帝国基地都有防御值和金币数量。 

一艘飞船可以摧毁所有防御力不大于飞船攻击力的基地。 由于摧毁一个基地会给出其所有黄金，因此宇宙飞船的答案就是防御力小于或等于其攻击力的所有基地的黄金总和。 

任务是计算每艘宇宙飞船的这个值，保留原始的宇宙飞船顺序。 

这些约束足够大，足以排除直接模拟的可能性。 最多可以有$10^5$宇宙飞船和$10^5$基地。 检查每艘宇宙飞船的每个基地需要$10^{10}$最坏情况下的比较，远远超出了几秒钟内可以运行的范围。 

问题的结构非常有利于排序。 基地对飞船有没有贡献只看对比$$d \le a$$在哪里$d$是基础防御，$a$是飞船的攻击力。 一旦基地按防御排序，给定宇宙飞船的所有符合条件的基地都会形成该排序顺序的前缀。 前缀查询建议使用前缀和和二分搜索。 

一些边缘情况值得关注。 

考虑具有相同防御的多个基地：```
1 3
5
5 2
5 3
5 4
```正确答案是：```
9
```如果粗心的二分查找只找到一次防御 5，就会错过一些黄金。 我们必须找到最后一个防御值小于或等于攻击力之后的位置。 

考虑一艘无法击败任何基地的宇宙飞船：```
1 2
1
2 5
3 7
```正确答案是：```
0
```二分查找必须正确返回空前缀。 

考虑一艘比每个基地都强大的宇宙飞船：```
1 3
100
1 2
5 3
10 4
```正确答案是：```
9
```搜索应返回整个前缀总和，而不是超出数组范围。 

另一个微妙的情况是防御值为 0：```
2 2
0 1
0 5
1 7
```答案是：```
5 12
```防御力为0的基地即使是攻击力为0的飞船也可以攻击。 

## 方法

 最直接的解决办法就是暴力破解。 对于每艘宇宙飞船，迭代所有基地。 每当一个基地的防御力最多达到飞船的攻击力时，将其金币添加到总数中。 

这是正确的，因为它准确地检查语句中的条件。 不幸的是，与$10^5$宇宙飞船和$10^5$基地，它执行$10^{10}$检查。 即使其中一小部分也已经太慢了。 

关键的观察是，在决定基地是否有贡献时，只有防御价值才重要。 如果我们按防御力对所有基地进行排序，那么对于任何攻击力$a$，每个可攻击的碱基都出现在排序列表的连续前缀中。 

例如，对防御进行排序后：```
Defense: 0 2 4 9
Gold:    1 8 2 4
```攻击力为5的飞船可以恰好击败前三个基地。 问题变成：

 “最后防御值不超过5的前缀含有多少金币？”

 前缀和立即回答第二个问题，而二分搜索回答第一个问题。 

我们按防御力对基地进行排序，构建一个黄金前缀和数组，并对每艘飞船使用二分搜索来找到第一个防御力大于其攻击力的飞船。 该位置之前的所有内容都有助于答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(s·b) | O(1) | O(1) | 太慢了 |
 | 最佳| O(b log b + s log b) | O(b log b + s log b) | O(b) | 已接受 |

 ## 算法演练

 1.读取所有飞船攻击力。 
2. 成对读取所有碱基`(defense, gold)`。 
3. 按防御值对基地进行排序。 

排序后，每艘飞船的有效基地就形成了数组的前缀。 
4. 创建一个仅包含已排序防御的数组。 
5. 构建一个黄金的前缀和数组。 

让`pref[i]`将总金币存储在第一个`i`排序顺序的基础。 使用长度`b + 1`前缀数组使空前缀处理变得简单。 
6.每艘飞船的攻击力`a`，对排序后的防御数组执行二分查找。 

找到第一个防守大于的位置`a`。 在Python中这是`bisect_right`。 
7. 如果返回的位置是`pos`，那么正是第一个`pos`基地是可攻击的。 

答案是`pref[pos]`。 
8. 按照原始飞船顺序输出所有答案。 

### 为什么它有效

 按防御力排序后，每个基地的防御力最多`a`出现在防御力大于的每个基地之前`a`。 二分查找找到这两个组之间的边界。 

返回的位置`pos`正是可攻击基地的数量。 自从`pref[pos]`存储第一个中包含的总黄金`pos`排序后的基地，它等于飞船可以摧毁的每个基地的黄金总和。 这个论点对于每艘宇宙飞船都是独立成立的，因此所有报告的答案都是正确的。 

## Python 解决方案```python
import sys
from bisect import bisect_right

input = sys.stdin.readline

def solve():
    s, b = map(int, input().split())
    attacks = list(map(int, input().split()))

    bases = []
    for _ in range(b):
        d, g = map(int, input().split())
        bases.append((d, g))

    bases.sort()

    defenses = [d for d, _ in bases]

    pref = [0] * (b + 1)
    for i in range(b):
        pref[i + 1] = pref[i] + bases[i][1]

    ans = []
    for a in attacks:
        pos = bisect_right(defenses, a)
        ans.append(str(pref[pos]))

    print(" ".join(ans))

if __name__ == "__main__":
    solve()
```排序后的`bases`array 建立二分搜索所需的顺序。 这`defenses`提取数组是因为`bisect_right`对单个排序列表进行操作。 

前缀和数组有长度`b + 1`。 额外的前导零会删除特殊情况。 如果没有基地可以攻击，`bisect_right`回报`0`和`pref[0]`已经是正确答案了。 

使用`bisect_right`而不是`bisect_left`至关重要。 我们需要所有防御力小于或等于攻击力的基地。`bisect_right`返回最后一个相等元素之后的第一个位置，其中包括每个有效的基数。 

Python 整数自动处理最大可能的黄金总量。 即使在最大的测试中，总和也很合适。

 ## 边缘情况

 考虑一艘无法击败任何基地的宇宙飞船：```
1 2
1
2 5
3 7
```防御排序为`[2, 3]`。`bisect_right([2, 3], 1)`回报`0`。 算法输出`pref[0] = 0`，这是正确的，因为没有基满足`d ≤ 1`。 

考虑几个具有相同防御的基地：```
1 3
5
5 2
5 3
5 4
```排序后，防御是`[5, 5, 5]`。`bisect_right(..., 5)`回报`3`， 不是`1`。 答案就变成了`pref[3] = 9`，正确地包括防御力等于攻击力的每个基地。 

考虑一艘比每个基地都强大的宇宙飞船：```
1 3
100
1 2
5 3
10 4
```

`bisect_right([1, 5, 10], 100)`回报`3`，等于碱基数。 该算法使用`pref[3] = 9`，所有黄金的总和。 

考虑防御值为零：```
2 2
0 1
0 5
1 7
```排序后的防御是`[0, 1]`。 为了攻击力`0`，二分查找返回`1`，所以答案是`pref[1] = 5`。 为了攻击力`1`，它返回`2`，生产`12`。 两个输出完全符合预期行为。
