 ## 解决方案
 ## 问题理解

 给定一个一维整数数组，我们希望将其拆分为连续的子数组，我们将其称为块。 每个块的元素之和必须相同，并且两个块不能重叠。 在满足这一点的所有可能的块选择中，我们想要最大数量的块。 输出应列出块的数量和每个块的索引。 

数组大小限制为1500，每个元素在±10^5以内。 当 n ≤ 1500 时，O(n^3) 算法将执行大约 3.3×10^9 次操作，这对于 3 秒的限制来说太高了，因此我们需要以 O(n^2) 或更好为目标。 内存充足，因此使用 O(n^2) 结构是可以接受的。 

不明显的边缘情况包括带有负数和零的数组。 例如，`[0, 0, 0]`具有多个总和为零的有效块分区。 总是选择第一个最大块的天真的贪婪方法如果阻止以后出现更多块，则可能会失败。 另一个边缘情况是严格递增的数组，例如`[1, 2, 3, 4, 5]`，其中最大的数字可能被视为其自己的块，而不是将较小的总和分组。 该算法必须正确探索子数组中出现的所有可能的和。 

## 方法

 强力解决方案是考虑由连续子数组形成的每个可能的和，然后为该和选择最大的不相交块集。 一种方法是生成所有 O(n^2) 子数组及其和，然后对于每个不同的和，尝试选择最大的不相交块集。 每次检查都可以从左到右贪婪地完成。 这种方法的问题在于，如果我们尝试考虑每对组合，则显式存储所有子数组和可能需要 O(n^3) 操作，这太慢了。 

关键的见解是我们不需要为每个总和独立地枚举每个块。 相反，我们可以使用前缀和来计算 O(1) 中的任何子数组和。 然后，对于每个潜在的目标总和，我们可以从左到右扫描以贪婪地挑选尽可能早结束且不重叠的块。 这是有效的，因为如果我们想要最大数量的不相交块，则左侧较小的块如果具有相同的总和，则无法阻止稍后较大数量的块。 因此，我们考虑出现的所有子数组和，并选择产生最多不重叠块的和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解所有子数组| O(n^3) | O(n^3) | O(n^2) | O(n^2) | 太慢了 |
 | 前缀求和 + 贪心求和 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 计算前缀和数组`pref`在哪里`pref[i] = a[0] + a[1] + ... + a[i-1]`。 这允许计算任何块的总和`[l, r]`在 O(1) 中为`pref[r+1] - pref[l]`。 
2. 创建字典`sum_to_blocks`为每个总和存储实现该总和的块列表。 循环遍历所有对`(l, r)`0 ≤ l ≤ r < n，计算总和`s = pref[r+1] - pref[l]`，并附加`(l, r)`到`sum_to_blocks[s]`。 
3. 初始化变量以跟踪不重叠块的最大数量：`max_blocks = 0`和`best_blocks = []`。 
4. 迭代每个总和`s`在`sum_to_blocks`。 对于对应的块列表`s`，按结束索引对它们进行排序`r`。 这确保了贪婪的从左到右的选择产生最大数量的块。 
5. 执行贪心选择：初始化`last_end = -1`，然后对于每个块`(l, r)`按排序顺序，如果`l > last_end`，将块添加到`current_blocks`并更新`last_end = r`。 
6. 如果为此总和选择的块数超过`max_blocks`， 更新`max_blocks`和`best_blocks`。 
7. 输出`max_blocks`以及中块的从 1 开始的索引`best_blocks`。 

为什么有效：按右端点对块进行排序并从左侧贪婪地选择可确保不重叠块的最大数量。 这是一个经典的间隔调度原则。 通过考虑数组中出现的所有可能的总和，我们保证不会丢失允许最大分区的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

pref = [0] * (n + 1)
for i in range(n):
    pref[i + 1] = pref[i] + a[i]

from collections import defaultdict

sum_to_blocks = defaultdict(list)
for l in range(n):
    for r in range(l, n):
        s = pref[r + 1] - pref[l]
        sum_to_blocks[s].append((l, r))

max_blocks = 0
best_blocks = []

for s, blocks in sum_to_blocks.items():
    blocks.sort(key=lambda x: x[1])
    current_blocks = []
    last_end = -1
    for l, r in blocks:
        if l > last_end:
            current_blocks.append((l + 1, r + 1))  # 1-based
            last_end = r
    if len(current_blocks) > max_blocks:
        max_blocks = len(current_blocks)
        best_blocks = current_blocks

print(max_blocks)
for l, r in best_blocks:
    print(l, r)
```前缀和数组让我们可以有效地计算子数组和。 这`defaultdict`按总和收集块。 按结束索引排序允许贪婪选择。 转换`l + 1, r + 1`调整到问题所需的从 1 开始的索引。 通过使用可以避免相差一错误`pref[r+1]`并迭代`r`从`l`到`n-1`。 

## 工作示例

 **样品1**

 输入：`[4, 1, 2, 2, 1, 5, 3]`| 我| r | 总和| sum_to_blocks[总和] |
 | ---| ---| ---| ---|
 | 0 | 0 | 4 | [(0,0)] |
 | 0 | 1 | 5 | [(0,1)] |
 | 1 | 2 | 3 | [(1,2)] |
 | 2 | 3 | 4 | [(2,3)] |
 | 4 | 5 | 6 | [(4,5)] |
 | 6 | 6 | 3 | [(6,6)] |

 选择 sum=3 并按 r 排序给出块`(1,2)`,`(6,6)`使用last_end跟踪确保没有重叠。 sum 3 的最大块数为 3：`(2,3)`,`(4,5)`,`(7,7)`。 

**自定义示例**

 输入：`[0, 0, 0]`所有总和均为 0。总和为 0 的区块：`(0,0)`,`(0,1)`,`(0,2)`,`(1,1)`,`(1,2)`,`(2,2)`。 r 的贪婪选择产生`(0,0)`,`(1,1)`,`(2,2)`，最多给出 3 个块。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|

 | 空间| O(n^2) | O(n^2) | 存储每个不同总和的块列表； 最坏的情况是所有子数组都有不同的和。 |

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    pref = [0]*(n+1)
    for i in range(n):
        pref[i+1] = pref[i]+a[i]
    from collections import defaultdict
    sum_to_blocks = defaultdict(list)
    for l in range(n):
        for r in range(l,n):
            sum_to_blocks[pref[r+1]-pref[l]].append((l,r))
    max_blocks = 0
    best_blocks = []
    for s, blocks in sum_to_blocks.items():
        blocks.sort(key=lambda x:x[1])
        current_blocks = []
        last_end = -1
        for l,r in blocks:
            if l>last_end:
                current_blocks.append((l+1,r+1))
                last_end = r
        if len(current_blocks) > max_blocks:
            max_blocks = len(current_blocks)
            best_blocks = current_blocks
    out = [str(max_blocks)]
    for l,r in best_blocks:
        out.append(f"{l} {r}")
    return '\n'.join(out)
