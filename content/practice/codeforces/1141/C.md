 ## 解决方案
 ## 问题理解

 我们给出了未知排列的连续元素之间的差异序列。 更准确地说，如果排列是$p_1, p_2, \dots, p_n$，我们得到一个数组$q$长度$n-1$使得每个$q_i = p_{i+1} - p_i$。 任务是重建原始排列或确定不存在这样的排列。 

关键的见解是我们不知道起点$p_1$，但一旦确定，其余的排列就由累积和决定。 那是，$p_2 = p_1 + q_1$,$p_3 = p_2 + q_2 = p_1 + q_1 + q_2$， 等等。 挑战是选择一个$p_1$使得所有由此产生的$p_i$值是 1 到 1 之间的不同整数$n$。 

约束意味着$n$最多可达 200,000，因此任何比线性时间更差的解决方案都会太慢。 这排除了尝试尝试所有排列或强力搜索的方法$p_1$天真地。 非明显的边缘情况包括需要负值或零值的序列$p_i$如果一个人天真地设定$p_1 = 1$。 例如，如果$q = [-2, 1]$，起始点为 1 产生$[1, -1, 0]$，这是无效的，但从 3 开始给出$[3, 1, 2]$，有效。 

## 方法

 蛮力方法会尝试一切可能的方法$p_1$从 1 到$n$，重建序列，并检查所有值是否不同且在范围内。 虽然这是正确的，但它需要$O(n^2)$在最坏的情况下进行操作，这是禁止的$n = 2 \cdot 10^5$。 

最佳方法依赖于这样的观察：差异唯一地定义了直到移位的排列。 让我们定义$r_i$作为从零开始的差值的运行总和：$r_1 = 0$,$r_2 = q_1$,$r_3 = q_1 + q_2$， 等等。 那么实际的排列是$p_i = r_i + x$， 在哪里$x = p_1$是一个不断的转变。 拟合 1 到 1 范围内的所有数字$n$没有重复项，$x$必须选择使得最小$r_i + x = 1$和最大$r_i + x = n$。 这给出了$x = 1 - \min(r_i)$。 移位后，我们只需检查这些值是否形成有效的排列。 这种方法是线性的$n$并且工作高效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算运行和数组$r$， 在哪里$r_0 = 0$和$r_i = r_{i-1} + q_{i-1}$为了$i = 1$到$n-1$。 这表示每个元素从任意起点的相对位置。 
2. 找出最小值$r$。 这将确定将最小元素置于 1 所需的移位。设置$p_1 = 1 - \min(r)$。 
3. 构造排列$p$通过添加$p_1$对每个$r_i$:$p_i = r_i + p_1$。 这会将所有元素转换为候选排列。 
4. 验证$p$包含从 1 到$n$正好一次。 最简单的检查是确保所有值都在 1 之内$n$并且没有重复项。 
5. 如果验证通过，则打印$p$。 否则，打印 -1 表示不存在解。 

关键的不变量是差异$q_i$完全保存在$r$。 唯一的自由度是初始转变$p_1$。 一旦移位使最小值等于 1，如果任何值落在 1 之外$n$或者存在重复项，就不可能形成有效的排列。 这样就保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
q = list(map(int, input().split()))

r = [0] * n
for i in range(1, n):
    r[i] = r[i-1] + q[i-1]

shift = 1 - min(r)
p = [ri + shift for ri in r]

if set(p) == set(range(1, n+1)):
    print(*p)
else:
    print(-1)
```该解决方案首先计算差异的运行总和。 然后，我们计算将最小数字对齐到 1 所需的移位。使用列表理解构建候选排列非常简单。 使用集合检查有效性可确保不存在重复项并且所有数字都在要求的范围内。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    q = list(map(int, input().split()))
    r = [0] * n
    for i in range(1, n):
        r[i] = r[i-1] + q[i-1]
    shift = 1 - min(r)
    p = [ri + shift for ri in r]
    return ' '.join(map(str, p)) if set(p) == set(range(1, n+1)) else '-1'

# Provided sample
assert run("3\n-2 1\n") == "3 1 2", "sample 1"

# Custom cases

assert run("5\n-1 1 -1 1\n") == "2 1 2 1 2", "duplicate check fails"
assert run("5\n-4 1 2 1\n") == "5 1 2 4 5", "edge case max shift"

 ## 边缘情况

 对于具有负差且在不移位的情况下会产生低于 1 的数字的序列，该算法正确地将移位计算为$1 - \min(r)$。 例如，使用输入`3\n-2 1`，运行总和是`[0, -2, -1]`。 移位 3 产生`[3, 1, 2]`，这是有效的。 同样，序列将超过$n$或包含重复项未通过设置检查，确保算法正确返回 -1。 该解决方案处理最小尺寸的输入
