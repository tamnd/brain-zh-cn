 ## 解决方案
 ## 问题理解

 我们给出了一个有向的价值传播规则系统$n$变量。 每条规则都规定一个变量$x$可以使用另一个变量的值来减少$y$，移动一个常数$z$，通过以下形式的操作$a_x \leftarrow \min(a_x, a_y + z)$。 每个规则只应用一次，但顺序是任意的。 

由于运算不可交换，不同的顺序可能会导致不同的最终不动点。 如果所有可能的顺序都导致每个变量的最终结果相同，则初始值的配置称为稳定的。 否则，如果存在某种改变其最终值的应用操作顺序，则该变量是不稳定的。 

在应用操作之前，每个查询允许我们最多减少任意变量$k$总共次数。 每个查询都会询问每个变量$i$，我们是否最多可以花费$k$递减以修改初始向量，以便变量$i$变得不稳定。 

这些限制在某种程度上迫使我们避免模拟操作订单。 高达$4 \cdot 10^5$操作和 1000 个查询，任何反复重新评估所有排列效果的方法都是立即不可能的。 即使每个查询进行一次模拟也太昂贵，因为每个模拟已经依赖于所有边上的排序或 BFS。 

一个关键的结构观察是，不稳定性不是单个操作的局部属性，而是从形成有向链的多个约束之间的相互作用中产生的。 这表明了最短路径或图松弛的观点。 

当人们假设不稳定仅取决于直接邻居时，就会出现一种典型的失败情况。 例如，考虑一条链$1 \to 2 \to 3$并精心挑选重量。 即使没有直接操作连接 1 和 3，顺序相关的传播仍然可以通过 2 发生，这会破坏任何基于邻接的简单检查。 

另一种微妙的情况是当所有值都很大但一个节点仅略高于阈值时。 稍微减小变量可能会突然使替代松弛路径在一个顺序中较早变得活跃，但在另一个顺序中则不然，从而产生如果我们只考虑原始值则看不见的不稳定性。 

## 方法

 第一本能是模拟系统：尝试所有操作排列并比较结果。 这在概念上是正确的，因为稳定性是针对所有订单定义的。 然而，随着$m$最多$4 \cdot 10^5$，即使每个查询有两个排列也已经变得不可行，并且阶乘爆炸使得这完全无法使用。 

更结构化的视图来自于将每个操作重写为有向松弛边$y \to x$有重量$z$， 意义$x$可以根据减少$y$。 如果所有操作都应用在无限循环中，则系统类似于最短路径计算，其中值作为距离传播，除了更新被限制为以任意顺序应用一次。 

关键的见解是，当存在竞争的松弛路径（其激活取决于顺序）时，就会出现不稳定性。 如果一个节点可以通过两个不同的链来松弛，并且一个链需要首先应用另一操作，则不同的排序可以暴露不同的中间最小值。 这将问题转变为检测多个不同的“紧”路径是否可以在有限的初始扰动下竞争同一节点。 

这建议预先计算所有链中变量之间的最小“依赖距离”，从而有效地在有向加权图上构建最短路径结构。 一旦我们知道每个节点对其他节点的依赖程度，我们就可以表征预算是否会小幅减少$k$足以强制给定目标节点严格排序差异。 

我们将每个查询简化为检查是否可以将某个节点推入至少两个不同的松弛源同时变得关键的状态。 这成为预先计算的距离结构上的最短路径比较问题，使我们能够在节点上以接近线性的时间回答每个查询。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力排列 |$O(m! \cdot m)$|$O(n)$| 太慢了 |
 | 图最短路径依赖模型 |$O(m \log n + n q)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 解释每个操作$x \leftarrow \min(x, y + z)$作为有向边$y$到$x$有重量$z$。 这编码了这样一个事实：$y$可以传播影响力$x$。 
2. 构建一个反向图透视图，我们跟踪值如何从所有其他节点流入每个节点。 节点的最终值是来自任何源节点的所有可达加权路径中的最小值。 
3. 在此图上运行多源最短路径计算，以计算每对节点之间的最佳可能传播值，或者等效地为每个节点计算来自每个其他节点的最佳传入影响。 因为$n \le 500$，全对类 Floyd 或重复 Dijkstra 结构在$O(n^2 \log n)$或优化$O(n^3)$。 
4. 对于每个节点$i$，确定候选“关键父母”：节点$j$这样就存在一条紧密的路径$j$到$i$达到最小值。 至少存储每个节点的最佳和第二最佳的不同贡献者。 
5. 系统变得依赖于节点的顺序$i$当且仅当存在至少两个不同的源，其感应路径都可以根据操作顺序变为活动状态。 这转化为检查是否可以通过减小初始值来使两条不同的紧路径同时具有竞争性。 
6. 对于每个查询，我们从概念上减少一些初始值，最多使用$k$递减。 这相当于降低了某些源节点，只能增加其作为最小贡献者的竞争力。 
7. 对于每个节点$i$,检查是否在预算之内$k$，我们可以减少一些贡献节点足以匹配或击败另一条竞争路径$i$。 这成为预先计算的最短路径贡献和可用冗余之间的比较。 

### 为什么它有效

 关键的不变量是每个最终值由操作顺序引起的一组加权路径上的最小值确定。 顺序仅影响哪些中间松弛较早可用，但它不会改变所有可能路径成本的集合。 因此，不稳定性相当于存在至少两条不同的路径，其主导地位取决于首先启用哪个中间松弛。 通过预先计算最短路径结构并识别每个节点的多个紧密贡献者，我们准确地捕获了排序可以改变实现的最小值的情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**18

def solve():
    n, m = map(int, input().split())
    dist = [[INF] * n for _ in range(n)]
    
    for i in range(n):
        dist[i][i] = 0

    edges = []
    for _ in range(m):
        x, y, z = map(int, input().split())
        x -= 1
        y -= 1
        if z < dist[y][x]:
            dist[y][x] = z

    for k in range(n):
        dk = dist[k]
        for i in range(n):
            di = dist[i]
            dik = di[k]
            if dik == INF:
                continue
            for j in range(n):
                nd = dik + dk[j]
                if nd < di[j]:
                    di[j] = nd

    q = int(input())
    for _ in range(q):
        k_budget = int(input())
        a = list(map(int, input().split()))

        ans = []
        for i in range(n):
            base = a[i]
            best1 = INF
            best2 = INF

            for j in range(n):
                if j == i:
                    continue
                cand = a[j] + dist[j][i]
                if cand < best1:
                    best2 = best1
                    best1 = cand
                elif cand < best2:
                    best2 = cand

            if best2 == INF:
                ans.append('0')
                continue

            gap = best2 - best1
            if gap <= k_budget:
                ans.append('1')
            else:
                ans.append('0')

        print("".join(ans))

if __name__ == "__main__":
    solve()
```该代码首先将操作压缩到最短路径矩阵中，其中每个条目代表值影响从一个变量传播到另一个变量的最便宜的方式。 三重循环 Floyd-Warshall 步骤计算所有对的最小传播成本。 

然后，每个查询独立地处理每个节点。 对于固定目标节点$i$，我们计算所有候选输入值$a_j + dist[j][i]$。 其中最小的两个代表两个最强的竞争影响力来源。 如果没有第二个不同的源，则节点无法表现出顺序敏感性，因为只有一种方法可以确定其最终最小值。 

决策条件将最佳贡献者和第二最佳贡献者之间的差距与允许的减少预算进行比较。 降低价值只能帮助竞争对手变得更加相关，因此，如果预算足以消除两条路径之间的差距，我们就可以强制不稳定。 

## 工作示例

 ### 示例 1

 输入：```
n = 3, k = 2
a = [5, 1, 4]
dist =
0 2 5
3 0 1
4 2 0
```对于节点 0，候选值为：

 | j | a[j] + dist[j][0] | a[j] + dist[j][0] |
 | ---| ---|
 | 0 | - |
 | 1 | 1 + 3 = 4 |
 | 2 | 4 + 4 = 8 |

 最佳为 4，次佳为 8，差距为 4，超出预算 2，因此节点 0 是稳定的。 

对于节点 1：

 | j | a[j] + dist[j][1] | a[j] + dist[j][1] |
 | ---| ---|
 | 0 | 5 + 2 = 7 |
 | 2 | 4 + 2 = 6 |

 最好是6，第二是7，差距是1，在预算之内，所以节点1不稳定。 

这表明不稳定性如何取决于竞争的传播路径而不是直接边缘。 

### 示例 2

 输入：```
n = 4, k = 3
a = [10, 0, 8, 6]
```假设节点 3 收到：

 | j | 价值|
 | ---| ---|
 | 0 | 10 + 5 = 15 | 10 + 5 = 15 |
 | 1 | 0 + 2 = 2 |
 | 2 | 8 + 6 = 14 |

 最好的是 2 个，第二个是 14 个，但是将节点 2 减少 3 个，其贡献就会降低到 5 个，缩小差距足以扭转竞争力。 这演示了预算如何改变排序敏感性。

 ## 边缘情况

 一种关键的边缘情况是只有一个节点可以到达目标。 在这种情况下，第二好的贡献者实际上是无限的。 该算法正确输出稳定性，因为不存在其排序可能改变结果的竞争路径。 

另一种情况是，即使在任何减少之前，两个贡献者的成本也相同。 差距为零，所以均匀$k = 0$将节点标记为不稳定。 这符合完美的关系使得排序具有决定性的直觉。 

当一个节点有多个传入路径但其中一个严格受所有其他路径支配时，会出现最后一种微妙的情况。 第二好的计算仍然可以识别出真正的竞争对手，并且差距反映了真实的敏感性而不是原始程度，从而防止了不相关边缘的过度计算。
