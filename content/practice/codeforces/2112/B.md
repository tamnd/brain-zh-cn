 ## 解决方案
 ## 问题理解

 我们得到了一个整数数组，我们想让它变得“漂亮”。 一个漂亮的数组至少有两个元素，并且至少包含一对差值最多为 1 的相邻元素。 我们可以在其范围内重复地将两个相邻元素组合成一个数字，从而有效地将数组一次缩小一个元素。 目标是确定使数组美观所需的此类操作的最少数量，或者报告这是不可能的。 

每个测试用例的输入大小最多可以有 1000 个元素，并且最多可以有 200 个测试用例。 这意味着任何以暴力方式查看每个可能的操作序列的算法都是不切实际的，因为组合的数量呈指数增长。 每个元素的范围最大可达一百万，但实际值本身并没有太多限制； 重要的特征是相邻元素之间的差异。 

一个微妙的问题是数组可能已经很漂亮了。 例如，`[1, 3, 3, 7]`已经包含`3`和`3`，所以不需要任何操作。 另一个棘手的场景是大小为 2 且元素相距较远的数组，例如`[6, 9]`。 这里，将它们组合起来将数组简化为单个元素，这不能满足“至少两个元素”的要求。 幼稚的实现可能会错误地尝试操作并返回答案而不是`-1`。 

## 方法

 暴力方法将尝试模拟每个可能的操作序列。 对于每一对相邻元素，我们可以尝试其范围内的所有可能的整数，并递归地缩小数组，检查是否出现一对漂亮的元素。 这原则上是正确的，但是操作次数与数组长度呈指数关系，大致如下`O(n * (max(a_i) - min(a_i))^n)`，这对于`n = 1000`。 

关键的见解是我们不需要考虑所有可能的操作顺序。 一个漂亮的数组只需要**一个相邻的对，最多相差一个**。 这意味着如果任何相邻对已经满足此条件，则需要零操作。 如果不存在这样的对，并且所有相邻的差值至少为二，那么组合两个相邻元素总是会产生一个在该范围内的数字，该数字与原始数字之一最多相差一，有效地保证我们可以将数组减少到一个新的状态。 由于我们可以选择区间内的整数，因此对于大小大于二的数组来说，**一次操作始终足以创建一对漂亮的数组。 唯一的例外是大小正好为 2 且元素相差超过 1 的数组，因为缩小它只会留下一个元素。 

这一观察结果将解决方案简化为三个简单的检查。 我们扫描阵列中的一对已经很漂亮了。 如果找到的话，答案是`0`。 如果没有，我们检查数组是否恰好有两个元素，并且它们相差超过一个，在这种情况下答案是`-1`。 否则，我们总是可以通过一次操作使数组变得漂亮。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * (最大(a_i)-最小(a_i))^n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 我们将为每个测试用例重复该过程。 
2. 对于每个测试用例，请阅读`n`和数组`a`。 
3. 循环相邻对`a[i]`和`a[i + 1]`为了`i = 0`到`n - 2`。 如果任意一对满足`|a[i] - a[i + 1]| <= 1`，立即返回`0`。 阵法已经很漂亮了。 
4. 如果没有相邻对满足条件，则检查数组的长度。 如果`n == 2`， 返回`-1`，因为执行任何操作都会将数组缩小为单个元素，这并不美观。 
5. 对于所有其他情况`n > 2`没有一双最初是美丽的，回归`1`。 对任何相邻对进行一次操作都会在原始元素之一内创建一个新数字，从而产生一对漂亮的数字。 

为什么它有效：不变的是一个漂亮的数组只需要一对，最多有一个差异。 任何大小大于 2 的数组都允许我们选择两个相邻的数字，并在其间隔内选择一个数字，以与其中一个邻居创建最多 1 的差异。 因此，我们只需要检查初始对或执行一项操作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    found = False
    for i in range(n - 1):
        if abs(a[i] - a[i + 1]) <= 1:
            found = True
            break
    
    if found:
        print(0)
    elif n == 2:
        print(-1)
    else:
        print(1)
```该代码首先读取测试用例的数量。 对于每个数组，它检查所有相邻对的差异最多为 1。 如果找到的话，答案是零。 如果数组恰好有两个元素并且没有漂亮的对，则答案是`-1`。 否则，对于大于 2 且没有初始漂亮对的数组，一次操作足以生成所需的对。 使用`abs()`确保正确处理差异，无论顺序如何。

 ## 边缘情况

 考虑`[1, 1000000]`。 算法循环一次，发现`abs(1-1000000)=999999>1`，看到`n==2`，并正确输出`-1`。 另一个边缘情况是`[1000000, 1000000, 1000000]`。 不需要检查最初的漂亮对，但自从`n>2`，代码输出`1`，这是有效的，因为我们可以将任何相邻的对组合成`1000000`，与其余元素产生美丽的差异。 不变量成立：任何大于二的数组总能在一个数组中变得漂亮
