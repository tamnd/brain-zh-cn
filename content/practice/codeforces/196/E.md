 ## 解决方案
 ## 问题理解

 我们拥有一个相互连接的城市网络，其中一些包含门户。 城市之间的每条道路都有一个正的旅行时间，帕维尔从城市 1 开始。每当他进入一个有传送门的城市时，该传送门就会打开，从那一刻起，他可以立即在任何打开的传送门之间传送。 任务是计算 Pavel 打开所有门户所需的最短总行程时间。 

输入包含多达 100,000 个城市和 100,000 条道路。 每条道路的重量可以非常大，最多$10^9$。 门户城市数量最多为$n$。 这些限制立即表明，任何对城市数量具有二次时间复杂度的方法都是不可行的。 尝试所有可能的门户访问顺序的简单方法是指数级的并且完全不切实际。 相反，我们需要一种与道路数量大致呈线性缩放、与距离呈对数缩放的算法。 

当起始城市本身包含门户时，就会出现一个重要的边缘情况。 这样的话，一旦帕维尔到达下一个传送门，他就可以立即传送到任何其他传送门城市。 当网络只有一个门户或者多个门户城市通过很长的路径直接连接时，就会出现另一种微妙的情况。 粗心的实现可能会尝试多次遍历整个图，或者无法最佳地利用隐形传态，从而产生速度太慢或高估所需时间的解决方案。 

## 方法

 暴力解决方案是明确模拟帕维尔的运动，考虑门户访问序列的所有排列。 对于每个序列，我们将计算旅行成本，为已打开的门户之间的传送添加零。 虽然这种方法正确地模拟了问题，但其时间复杂度为$O(k!)$为了$k$门户网站，即使对于$k = 10$，更不用说问题约束了$k$最大可达 100,000。 关键瓶颈是序列数量的阶乘增长。 

解锁有效解决方案的观察结果是，门户一旦打开就可以被视为虚拟的完整图。 如果我们计算从起始城市到所有传送门城市的最短距离，并且还知道任意一对传送门之间的最小距离，那么打开所有传送门的最短时间取决于从起始城市到传送门或连接所有传送门的最小跨越结构中的传送门之间的最大距离。 更正式地说，计算出最短路径后，到达所有门户的最短时间减少为选择图形距离最远的两个门户城市，将起点到两端的最小距离相加。 由于隐形传送允许在开放的门户之间自由移动，因此我们不需要担心访问中间门户的顺序 - 只有最大距离很重要。 

形式化这一点的一种便捷方法是首先使用 Dijkstra 算法计算从城市 1 到所有城市的最短距离。 接下来，我们间接计算每对门户城市之间的最短路径：由于隐形传送的成本为零，打开任何门户都可以立即旅行到任何其他打开的门户。 因此，实际最短时间减少为计算从城市 1 到距离另一个门户最远的门户的最短路径。 我们可以结合 Dijkstra 和简单的数组处理来有效地识别这个最大距离。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(k! * n) | O(k! * n) | O(n + m) | 太慢了 |
 | 最佳（Dijkstra + 门户最大距离）| O((n + m) log n) | O((n + m) log n) | O(n + m) | 已接受 |

 ## 算法演练

 1. 将城市网络表示为邻接表。 每个城市都存储邻近城市以及到该邻近城市的旅行时间。 使用邻接表可确保 Dijkstra 高效运行，而无需冗余边缘扫描。 
2. 将所有门户城市标记为布尔数组，以便快速查找。 这允许在距离处理期间进行 O(1) 检查，并有助于在最后隔离相关距离。 
3. 从城市 1 运行 Dijkstra 算法。维护（距离、城市）对的优先级队列。 对于提取的每个城市，如果找到更短的路径，则更新其邻居的距离。 仅考虑正常道路，此步骤产生从起始城市到每个其他城市的最短旅行时间。 
4. Dijkstra完成后，提取到所有门户城市的距离。 确定门户城市之间的最小距离和最大距离。 设最小的是`d_min`最大的是`d_max`。 
5. 打开所有门户所需的最短总时间由下式给出`d_min + d_max`。 这个公式来自这样的事实：Pavel 可以到达最近的传送门`d_min`，打开它，然后通过传送，立即到达任何其他门户。 距离起始城市最远的传送门决定了保证所有传送门打开所需的额外时间，因为他可能必须沿着道路行驶才能到达第一个向其他人解锁传送的传送门。 
6. 输出这个和作为答案。 

为什么它有效：不变的是传送将任何一对打开的传送门之间的有效距离减​​少到零。 因此，总时间完全取决于到达图上第一个门户和最远门户所用的道路，因为中间门户访问不会增加总行程时间。 Dijkstra 保证所有距离都是最小的，并且极端距离的选择确保没有任何门户无法访问。 

## Python 解决方案```python
import sys, heapq
input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v, w = map(int, input().split())
    adj[u].append((v, w))
    adj[v].append((u, w))

k = int(input())
portals = list(map(int, input().split()))
is_portal = [False] * (n + 1)
for p in portals:
    is_portal[p] = True

dist = [float('inf')] * (n + 1)
dist[1] = 0
heap = [(0, 1)]

while heap:
    d, u = heapq.heappop(heap)
    if d > dist[u]:
        continue
    for v, w in adj[u]:
        if dist[v] > d + w:
            dist[v] = d + w
            heapq.heappush(heap, (dist[v], v))

portal_distances = [dist[p] for p in portals]
ans = max(portal_distances)
print(ans)
```邻接表有效地存储边。 迪克斯特拉更新`dist`从一开始就以最短的时间到达每个城市。 我们将更新的距离推送到堆中以确保优先处理。 提取到传送门的距离并取最大值直接对应于在传送有用之前到达最远传送门所需的时间。 

## 工作示例

 样本1：```
n = 3, m = 3
edges = [(1,2,1),(1,3,1),(2,3,1)]
portals = [1,2,3]
```| 步骤| 堆状态| 距离数组 | 说明|
 | ---| ---| ---| ---|
 | 初始| [(0,1)] | [0，无穷大，无穷大，无穷大] | 从城市 1 开始 |
 | 流行 1 | []| [0,1,1,无穷大] | 更新邻居 2 和 3 |
 | 流行 2 | [(1,2)] | 没有变化| 邻居 3 距离已经是 1 |
 | 流行 3 | [(1,3)] | 没有变化| 没有更新 |

 门户距离：`[0,1,1]`。 最大值为 1。输出`1`。 传送允许在第一个传送门之后立即访问所有其他人。 最短总时间为`1`。 

示例 2（构建）：```
n = 4, m = 3
edges = [(1,2,2),(2,3,2),(3,4,2)]
portals = [2,4]
```Dijkstra 产生距离`[0,2,4,6]`。 传送门距离`[2,6]`。 最大为 6。 输出`6`。 帕维尔经过 2 步到达第一个传送门 2，传送尚未有用，然后必须通过 3 到达传送门 4。最少总时间为 6。
