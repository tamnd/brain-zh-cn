[CF 1686A - 除了一个之外，无处不在](https://codeforces.com/problemset/problem/1686/A)

 **标签：** 贪婪
 **求解时间：** 1m 35s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 每个测试用例都以整数数组开头。 唯一允许的操作以一种非常具体的方式转换数组：我们精确地选择一个元素保持不变，并用所选组的平均值替换所有其他元素。 

该平均值是根据所选的$n-1$元素，因此每次操作后，所有修改的位置都会收到相同的值。 未触及的元素保留该步骤的旧值。 

问题是，在重复此操作有限次数后，我们是否可以达到数组中的每个条目都相同的状态。 

限制很小，每个测​​试用例最多 50 个元素，最多 200 个测试用例。 这立即消除了对大量优化或组合搜索的需要。 即使三次或二次推理也是可以接受的，但强制执行所有操作序列是不可能的，因为状态空间由于平均引入的分数而不断增长。 

如果我们尝试直接模拟操作，就会出现一个微妙的问题。 经过一次运算后，值可以变成有理数，并且精确的相等变得很难用数字来推理。 另一个陷阱是假设因为我们正在平均，所以我们正在“收敛”到全球平均值。 这种直觉是具有误导性的，因为排除的元素破坏了对称性并阻止了对整个数组的简单平均。 

一个典型的错误假设是重复平均总是将数组平滑为单个值。 例如，在像这样的数组中$[4, 3, 2, 1]$，人们可能期望重复平均最终使值相等，但更新的结构保留了某些阻止完全收敛的线性约束。 

## 方法

 暴力方法将模拟所有可能的操作序列。 每一步都提供$n$排除元素的选择，每次操作后数组都会变成新的连续状态。 即使我们离散化状态（由于分数的原因，我们不能安全地做到这一点），分支因子在操作数量上仍然是指数级的。 由于值可以无限次更改，因此这种方法在计算上没有意义。 

关键的观察结果是该操作保留了很强的不变量：每次操作后所有元素的总和保持不变。 

为了看到这一点，假设我们排除索引$i$。 另一个$n-1$元素被其平均值替换$m$。 这些被替换元素的总贡献变为$(n-1)m$，这正是他们的原始总和。 由于排除的元素未受影响，因此数组的总和不会改变。 

这立即意味着，如果我们达到所有元素都等于某个值的状态$x$，那么总和必须是$n \cdot x$， 所以$x$被强制为数组的初始平均值。 

因此，任何有效的最终状态都必须是等于初始平均值的常量数组。 

剩下的问题是我们是否总能达到那种状态。 关键的结构见解是，只要我们不改变总和，该操作就可以在位置之间自由“移动质量”。 由于我们可以用共享平均值重复覆盖除一个位置之外的所有位置，因此我们可以逐步消除与平均值的偏差。 通过足够的操作，任何配置都可以在尊重不变量的同时趋于一致。 

因此，答案归结为检查除总和不变量之外是否存在任何障碍。 没有，因此任何数组都始终可以满足该条件。 

这得出了一个令人惊讶的简单结论：每个数组都可以被均衡。

 ## 算法演练

 1. 对于每个测试用例，读取数组。 此时，我们只需要值的全局属性，而不需要它们的顺序。 
2. 观察到无论如何应用操作，数组的总和都不会改变。 这意味着任何最终统一值必须等于初始平均值。 
3. 检查是否可以达到均匀数组。 由于该操作允许用所选元素的平均值覆盖除一个位置之外的所有位置，因此我们始终可以在不破坏总和约束的情况下重新分配值。 
4. 得出结论，转变总是可以实现的，所以答案总是“是”。 

### 为什么它有效

 该算法依赖于一个守恒量：所有元素的总和。 每次操作都替换$n-1$元素及其平均值，保留了这些元素的总贡献。 由于最终配置完全由总和决定，并且该操作允许在保留总和的同时进行任意重新分配，因此不存在阻止收敛到常量数组的结构限制。 系统有足够的自由度来消除元素之间的所有差异，同时保持不变量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        arr = list(map(int, input().split()))
        print("YES")

if __name__ == "__main__":
    solve()
```该实现反映了不需要每个元素模拟的关键观察结果。 由于每个数组在派生条件下都有效，因此该解决方案只需为每个测试用例输出“YES”。 

实现中不存在隐藏的极端情况，因为没有分支逻辑依赖于输入值。 唯一需要注意的是正确处理多个测试用例和快速输入读取。

 ## 边缘情况

 完全均匀的数组，例如$[1,1,1]$在任何操作下都保持不变，因为每个平均值都等于相同的值。 该算法无需模拟即可正确输出“YES”。 

高度倾斜的数组，例如$[10,0,0,0,0]$很有趣，因为天真的直觉表明大值可能会被“卡住”。 然而，重复操作总是保留总和并允许在所有位置之间重新分配，因此它在概念上仍然收敛于均值。 输出仍然是“YES”，与基于不变性的推理一致。 

一个小的非均匀数组，例如$[0,1,2]$强调不需要特殊的奇偶性或整除性条件。 即使中间值变成分数，重复覆盖几乎整个数组的能力也确保不保留结构障碍，因此正确的输出仍然是“YES”。
