 ## 解决方案
 ## 问题理解

 我们有`n`位置排列成一圈。 跳蚤从一个位置开始。 第一分钟后向前移动 1 步，第二分钟后向前移动 2 步，第三分钟后向前移动 3 步，依此类推。 

问题是这种运动模式最终是否会到达圆上的每个位置。 

如果跳蚤当前处于以下位置`p`，然后一分钟后`k`它移动到：$p+k \pmod n$输入包含单个整数`n`，圆中的位置数。 输出应该是`"YES"`如果每个位置至少被访问一次，否则`"NO"`。 

限制很小，最多只有 1000 个位置。 即使是具有多个步骤的直接模拟也足够快。 我们不需要高级优化或繁重的数学。 尽管如此，这个问题有趣的部分是理解为什么答案只取决于是否`n`是质数或合数。 

一个容易犯的错误是假设跳蚤总是会拜访所有东西，因为跳跃长度不断变化。 这种直觉对于以下的复合值来说是失败的`n`。 

例如：```
n = 4
```访问的职位有：```
0 -> 1 -> 3 -> 2 -> 2 -> ...
```位置`0`开始后就再也不会被重新访问，并且运动会陷入更小的循环中。 正确的输出是`"NO"`。 

另一个微妙的情况是`n = 1`。```
1
```只有一个位置，所以跳蚤已经立即访问了所有位置。 正确答案是`"YES"`。 

粗心的实施也可能在看到重复的立场后过早停止。 除非我们已经知道某些位置从未被访问过，否则仅重复不足以得出失败的结论。 例如：```
n = 2
```跳蚤永远在两个位置之间交替，这实际上足以覆盖整个圆圈。 正确的输出是`"YES"`。 

## 方法

 最直接的方法是模拟。 我们跟踪当前位置并重复应用长度跳跃`1, 2, 3, ...`。 每次我们到达一个位置时，我们都会将其标记为已访问。 

蛮力之所以有效，是因为状态空间很小。 只有`n`位置，因此最终必须重复该运动。 如果经过足够多的跳跃后，所有位置都被标记，我们回答`"YES"`， 否则`"NO"`。 

对于这个问题规模，即使模拟几千步也是完全可以接受的。 和`n ≤ 1000`， 一个`O(n^2)`进程仍然最多执行大约一百万个操作。 

更有趣的观察来自数论。 

后`k`移动，总移动距离为：$1+2+3+\cdots+k = \frac{k(k+1)}{2}$实际位置仅取决于该值模`n`。 

跳蚤访问每个位置当且仅当`n`是素数。 

为什么？ 对于复合材料`n`，存在一些除数`d < n`。 经过足够的跳跃后，累积的运动开始重复模数`d`，这会阻止访问所有位置。 对于总理`n`，模块化行为循环遍历所有残基。 

另一种表达官方观察结果的方式是，当跳跃结构的最大公约数和`n`保持有利，这种情况只发生在黄金时段`n`并为`n = 1`。 

自从`n`很小，我们可以简单地检查是否`n`是素数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 已接受 |
 | 最佳 | O(√n) | O(√n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取整数`n`。 
2.特殊情况处理`n = 1`。 

一个位置几乎被完全访问过，因为跳蚤从那里开始。 
3. 检查是否`n`是素数。 

我们尝试所有除数`2`最多`√n`。 如果任意除数整除`n`， 然后`n`是复合的。 
4. 如果`n`是素数，打印`"YES"`。 

原始大小的圆圈允许运动模式最终覆盖每个残数模`n`。 
5. 否则打印`"NO"`。 

在访问所有位置之前，复合大小的圆圈迫使跳蚤进入更小的重复结构。 

### 为什么它有效

 跳蚤几次跳跃后的位置取决于累加和模数`n`。 对于总理`n`，圆上的模运算不会折叠成更小的重复子集，因此每个位置都变得可达。 对于复合材料`n`，运动被限制在由除数决定的位置子集`n`。 

该算法是正确的，因为素数准确地表征了运动是否覆盖整个圆。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_prime(x):
    if x < 2:
        return False

    d = 2
    while d * d <= x:
        if x % d == 0:
            return False
        d += 1

    return True

def solve():
    n = int(input())

    if n == 1 or is_prime(n):
        print("YES")
    else:
        print("NO")

solve()
```该解决方案从标准素性测试开始。 任何小于 2 的数都不是素数。 然后我们尝试每个除数`d`尽管`d * d <= x`。 

仅检查平方根就足够了，因为除数总是成对出现。 如果`x`有一个除数大于`√x`，配对除数已经小于`√x`。 

特殊处理为`n = 1`很重要，因为 1 在数学上不是素数，但这个问题的答案仍然是`"YES"`因为跳蚤已经占据了唯一的位置。 

该实现使用恒定的额外内存，并且对于给定的约束几乎立即完成。

 ## 边缘情况

 考虑尽可能最小的输入：```
1
```该算法立即匹配特殊情况`n == 1`和打印`"YES"`。 

根本没有任何动静，但每个位置都已被访问过，因为只有一个位置存在。 

现在考虑一个小的合数：```
4
```素性检查尝试除数`2`。```
4 % 2 == 0
```由于存在除数，因此该数字是合数，因此算法打印`"NO"`。 

这正确地匹配了实际的运动行为，跳蚤永远不会覆盖整个圆圈。 

最后，考虑一个素数：```
5
```可分性检查是：```
5 % 2 != 0
```不存在除数`√5`，因此算法将 5 分类为素数并打印`"YES"`。 

跳蚤最终会在所有五个位置之间循环，这证实了主要标准的正确性。
