 ## 解决方案
 ## 问题理解

 我们有一个$n \times m$网格。 一些单元格包含饼图，并且多个饼图可以共享同一个单元格。 

每个回合有两个阶段。 首先，Volodya 选择一个饼图，并将其向四个方向之一移动一个单元格。 如果馅饼已经在边界上，他可以将其通过一个边界边缘移到棋盘外，并立即赢得整场比赛。 之后，如果游戏尚未结束，弗拉德将恰好阻挡棋盘的一个单位边界边缘。 一旦被阻挡，该边缘就不能再用来将馅饼移到外面。 

这场比赛的重点是，假设两名球员都发挥完美，沃洛迪亚最终能否取得胜利。 

棋盘尺寸最多为 100，饼图最多为 100 个。 这些限制很小，这表明真正的困难不是实现复杂性，而是找到正确的博弈论观察。 对游戏状态进行强力搜索仍然是不可能的，因为状态包括所有饼图的位置以及一组已被阻止的边界边缘。 甚至一个$100 \times 100$棋盘有 400 个边界边，因此可能的阻塞边子集的数量本身就是天文数字。 

这个问题的危险部分在于，它看起来像寻路，但实际的游戏仅取决于边界访问。 诸如“如果某个馅饼可以到达边界，那么沃洛迪亚获胜”之类的天真的想法是完全错误的，因为每个边境出口最终都可能被堵塞。 

一些边缘情况很容易被错误处理。 

考虑一个没有馅饼的董事会：```
2 2 0
```正确答案是`NO`因为沃洛佳没有什么可移动的。 任何仅检查电路板尺寸或边框尺寸而不进行处理的实现$k=0$单独会失败。 

另一个微妙的情况是当饼图已经从边界开始时：```
2 2 1
1 2
```答案是`YES`。 在弗拉德阻挡任何东西之前，沃洛佳在第一步就立即获胜。 忘记移动顺序会导致错误的结果。 

最重要的棘手情况是当有很多馅饼但都在棋盘深处时：```
5 5 20
3 3
3 3
...
```即使有很多馅饼，答案仍然可以是`NO`。 弗拉德每回合仅阻挡一个边界边缘，但沃洛佳也需要时间将馅饼带到边界。 决定性的数量不仅仅是馅饼的数量，而是足够多的馅饼是否能够比弗拉德密封出口更快地威胁出口。 

最后一个微妙之处是不同的边界单元提供不同数量的出口。 角单元有两个通向外部的边界边缘，而非角边界单元有一个。 同等对待每个边界单元会丢失重要信息。 

## 方法

 暴力方法将对整个游戏状态进行建模。 我们将跟踪所有饼图位置和所有被遮挡的边界边缘，然后运行极小极大或逆行分析。 这在理论上是正确的，因为游戏是有限且确定的。 

问题是状态计数立即爆炸。 董事会有$2n + 2m$边界边缘。 每个边缘可能被阻挡或未被阻挡，大致给出$2^{2n+2m}$甚至在考虑馅饼位置之前就有可能。 和$n=m=100$，这完全是没希望了。 

关键的观察是，游戏只关心一件事：Vlad 需要多少回合才能完全封住棋盘。 

弗拉德的每一步动作都恰好阻挡了一个边界边缘。 边界边总数为：$$2n + 2m$$如果沃洛佳能够在所有这些边缘被密封之前迫使一些馅饼到达畅通无阻的出口，那么他就赢了。 

现在从单个饼的角度思考。 假设它到任何边界单元的最小距离是$d$。 那么沃洛佳正是需要$d$移动一步将其放置在边界上，再移动一步离开棋盘。 这样馅饼就可以逃脱$d+1$沃洛佳动了。 

与此同时，在每一次移动之后，弗拉德都会阻挡一条边缘。 后$t$转身，弗拉德正好挡住了$t$边界边缘。 

关键的见解是，蛋糕并不需要所有出口都保持开放。 当它到达边界时，它只需要一条可用的边。 由于整个董事会只有$2n+2m$退出总数，弗拉德最终耗尽了阻塞能力。 

官方的解决方案进一步简化了这一点。 如果存在至少一个饼图，其到最近边界的距离最多为 4，则 Volodya 获胜。 否则弗拉德获胜。 

为什么是4？ 因为任何局部区域周围的不同出口总数都太大，弗拉德无法足够快地封锁。 在弗拉德关闭所有可能性之前，足够接近边界的饼总是可以强制进入某些仍然开放的边缘。 如果所有馅饼的距离都超过 4，弗拉德就有足够的时间准备完整的防御。 

因此，游戏简化为检查某个饼图是否位于距边界 4 的范围内。

 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳|$O(k)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 读取棋盘的尺寸和饼的数量。 
2. For each pie at position$(x,y)$，计算其到任意板边界的最小距离。 

这四个距离是：$$x-1,\ n-x,\ y-1,\ m-y$$它们的最小值告诉我们需要多少次移动才能首先到达边界单元。 
3. 如果任何饼图的最小距离最多为 4，则立即打印`YES`。 

如此靠近边界的馅饼总是可以在弗拉德密封每个相关边界边缘之前迫使逃亡。 
4. 如果所有饼图的距离都大于 4，则打印`NO`。 

弗拉德有足够的时间在任何馅饼变得危险之前组织一次全面封锁。 

### 为什么它有效

 游戏完全由时间控制。 

远处的馅饼$d$从边界需求$d+1$移动逃跑。 弗拉德在每次移动后恰好获得一个格挡边。 如果$d \le 4$，饼图到达边界区域的速度足够快，以至于仍然存在不可避免的开放出口。 弗拉德不可能在这么几个回合内同时封锁所有可能的逃生路线。 

如果每个饼的距离至少为 5，那么 Volodya 需要很多回合才能立即进行逃跑尝试。 弗拉德可以利用这段时间战略性地封锁出口，并最终阻止一切可能的逃跑。 由于只有边界边缘很重要，因此一旦控制了周边，内部移动就不再有帮助。 

这种二分法与算法检查的条件完全匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m, k = map(int, input().split())

for _ in range(k):
    x, y = map(int, input().split())

    dist = min(x - 1, n - x, y - 1, m - y)

    if dist <= 4:
        print("YES")
        sys.exit()

print("NO")
```实现故意很小，因为困难的部分是发现游戏属性。 

对于每个饼图，我们计算到达任何边界单元所需的最少步数。 由于坐标是 1 索引的，因此顶部距离是`x - 1`，底部距离为`n - x`，左边的距离是`y - 1`，正确的距离是`m - y`。 

当我们发现距离最多为4的饼时，我们可以立即停止并打印`YES`。 进一步的馅饼并不重要，因为沃洛佳只需要成功逃脱一次即可。 

早期的`sys.exit()`避免不必要的处理并保持代码简单。 

一个常见的差一错误是将“到边界单元的距离”与“离开电路板的距离”混淆。 该定理已经正确地解释了这一点。 我们只检查边界距离是否最多为 4。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    n, m, k = map(int, input().split())

    for _ in range(k):
        x, y = map(int, input().split())

        dist = min(x - 1, n - x, y - 1, m - y)

        if dist <= 4:
            print("YES")
            return

    print("NO")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdout = io.StringIO()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

 ## 边缘情况

 考虑空板情况：```
2 2 0
```该算法永远不会进入饼图循环，因此它直接打印`NO`。 

这与游戏相符，因为 Volodya 没有合法动作。 

现在考虑一个已经在边界上的饼图：```
3 3 1
1 2
```计算出的距离为：$$0,\ 2,\ 1,\ 1$$最小值为 0，最多为 4，因此算法打印`YES`。 

沃洛佳在弗拉德行动之前将馅饼移到外面，立即获胜。 

接下来，考虑正好处于临界阈值的饼图：```
10 10 1
5 5
```距离为：$$4,\ 5,\ 4,\ 5$$最小距离为 4，所以答案为`YES`。 

这将检查包含边界条件。 使用`< 4`而不是`<= 4`会在这里失败。 

最后，考虑一个刚刚超出阈值的饼图：```
12 12 1
6 6
```距离为：$$5,\ 6,\ 5,\ 6$$最小距离为 5，因此算法打印`NO`。 

这是损失最小的内部配置，并且可以捕获截止点周围的微小误差。
