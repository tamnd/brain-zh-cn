 ## 解决方案
 ## 问题理解

 我们正在填写一个`n × m`带括号的网格​​。 每个细胞都包含`"("`或者`")"`。 

如果从左上角到右下角的每条单调路径都形成正确的括号序列，则该网格被称为有效。 单调路径仅向右或向下移动。 

问题的第二部分定义了网格之间的排序。 每个单元都有一个独特的优先级`1`到`nm`。 为了比较两个网格，我们按优先级递增的顺序检查单元格，并找到网格不同的第一个位置。 网格有`"("`在该位置被认为较小。 

我们必须输出`k`此排序中的第 -th 个有效网格。 

首先要了解有效性条件的真正含义。 一条路径从`(1,1)`到`(n,m)`总是有长度`n + m - 1`。 每个这样的路径本身必须是规则的括号序列。 

常规括号序列有两个属性：

 1. 每个前缀至少包含同样多的前缀`"("`作为`")"`。 
2. 总数`"("`等于总数`")"`。 

由于每条路径的长度相同，因此总长度必须是偶数。 这意味着`n + m - 1`必须是均匀的。 如果是奇数，则不存在有效的网格。 该声明保证了给定的足够的解决方案`k`，所以我们永远不需要显式处理不可能的输入。 

约束足够大，足以排除暴力枚举。 网格最多有`100 × 100 = 10000`细胞。 甚至检查所有`2^(nm)`网格是荒谬的不可能的。 的价值`k`可以大到`10^18`，这强烈表明我们只需要计数到某个上限值，而不是精确的天文计数。 

隐藏的结构特性是每个有效网格完全由反对角索引确定`i + j`。 

考虑任何路径。 在步骤`t`，路径总是在满足条件的单元格上`i + j = t + 2`。 每条路径都访问每个反对角线上的一个单元格。 如果同一对角线上的不同单元格具有不同的括号，则两条路径可以在序列中的同一位置选择不同的括号，这将打破所有路径同时正确的要求。 

这一观察结果将问题从 2D 网格折叠成 1D 括号序列。 

有几种边缘情况打破了天真的推理。 

认为：```
1 3
```唯一的路径长度是`3`，这很奇怪。 不存在奇数长度的正确括号序列。 粗心的实现可能仍然会尝试生成类似的东西`"()("`。 

另一个微妙的情况是：```
2 2
```每条路都有长度`3`，又不可能。 一些简单的 DP 公式会忘记奇偶校验条件并意外地计算无效状态。 

一个更有趣的例子是：```
2 3
```反对角线是：```
(1,1)
(1,2),(2,1)
(1,3),(2,2)
(2,3)
```如果第二个反对角混合括号，则两条路径将产生不同的第二个字符。 其中一个可能比另一个更早失效。 对角线的均匀性不是可选的，而是由条件强制的。 

## 方法

 蛮力方法在概念上很简单。 枚举全部`2^(nm)`网格，检查每个单调路径是否形成规则的括号序列，收集所有有效网格，使用自定义优先级顺序对它们进行排序，然后打印`k`-第一个。 

检查一个网格已经需要检查所有单调路径。 此类路径的数量为：$$\binom{n+m-2}{n-1}$$对于一个`100 × 100`格这个数字是天文数字。 即使在考虑网格数量之前，验证本身也是不可能的。 

关键的观察结果是，每条路径都恰好访问每个反对角线的一个单元格。 让：$$d = i + j$$所有单元格都具有相同的`d`出现在每条路径中的相同位置。 

现在假设同一对角线上的两个单元格包含不同的括号。 那么两条不同的路径可能会在相同的序列位置产生不同的字符。 一个序列可能会违反括号平衡，而另一个序列则不会。 每条路径始终正确的唯一方法是同一对角线上的所有单元格包含相同的括号。 

这彻底改变了问题。 

而不是单独选择括号`nm`对于每个反对角线，我们只选择一个括号。 确切地说有：$$n + m - 1$$对角线，因此整个网格对应于该长度的单个括号序列。 

现在情况变得简单多了。 每条路径读取完全相同的序列。 当且仅当该序列是常规括号序列时，网格才有效。 

自定义订购也变得易于管理。 每个反对角线包含多个具有不同优先级的单元。 对角线的最早比较点只是该对角线内的最低优先级。 因此，我们可以按这些最小优先级对反对角线进行排序，并按该顺序比较括号序列。 

此时问题就简化为：

 1. 建立反对角线的顺序。 
2. 找到`k`- 该自定义位置顺序下的第一个常规括号序列。 
3. 均匀填充每条对角线。 

我们可以贪婪地构建答案。 在比较顺序的每一步中，尝试放置`"("`。 计算存在多少个有效的完成。 如果该计数至少为`k`， 保持`"("`。 否则减去计数`k`并放置`")"`。 

计数DP是具有平衡状态的标准括号序列DP。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(2^{nm} \cdot \binom{n+m-2}{n-1})$| 指数| 太慢了 |
 | 最佳 |$O((n+m)^2)$|$O((n+m)^2)$| 已接受 |

 ## 算法演练

 1. 计算反对角线的数量。 

对角线的索引为：$$s = i + j$$范围从`2`到`n + m`。 
2. 对于每个反对角线，计算其最小优先级。 

同一对角线上的每个单元格必须共享相同的括号，因此对角线之间的比较顺序由每个对角线内出现的最小优先级决定。 
3. 按这些最低优先级对反对角线进行排序。 

这给出了问题使用的确切字典顺序。 
4.让`L = n + m - 1`。 

这是每个路径序列的长度。 由于常规括号序列的长度必须为偶数，`L`必须是均匀的。 
5. 建立DP表。 

让：$$dp[pos][bal]$$是完成位置的有效方法的数量`pos`如果当前余额为`bal`。 

平衡的意思是：$$\#("(") - \#(")")$$已经使用了。 
6. 向后填充DP。 

在最后：$$dp[L][0] = 1$$所有其他期末余额均无效。 

对于每个位置，我们尝试添加`"("`或者`")"`同时绝不允许出现负余额。 
7. 按优先顺序贪婪地构造答案。 

对于按排序顺序的每个对角线：

 1. 临时放置`"("`。 
2. 计算剩余的有效完成次数。 
3. 如果计数至少为`k`， 保持`"("`。 
4. 否则减去计数`k`并放置`")"`。 

这是使用计数的标准词典生成。 
8. 确定每个反对角线的括号后，填充网格。 

每个细胞`(i,j)`接收分配给对角线的括号`i+j`。 

### 为什么它有效

 每条单调路径都按照对角线递增顺序访问每个反对角线上的一个单元格。 如果对角线包含混合括号，则两条路径可能会在同一序列位置产生不同的符号。 那么正确性将取决于路径选择，这与每条路径必须正确的要求相矛盾。 

因此，每个有效网格都唯一对应于对角线上的一个括号序列。 

网格之间的排序也正确减少，因为第一个不同的单元格必须属于最小优先级最早出现的对角线。 

DP 精确计算扩展给定前缀的常规括号序列的数量。 只要剩余足够的补全，贪心构造就会选择字典顺序最小的可能字符，因此生成的序列正是`k`-第一个。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**18

def solve():
    n, m, k = map(int, input().split())

    p = [list(map(int, input().split())) for _ in range(n)]

    L = n + m - 1

    # minimum priority for each anti-diagonal
    diag_min = [10**18] * (L + 2)

    for i in range(n):
        for j in range(m):
            s = i + j
            diag_min[s] = min(diag_min[s], p[i][j])

    # order of diagonals in comparison
    order = sorted(range(L), key=lambda x: diag_min[x])

    # dp[pos][bal]
    dp = [[0] * (L + 2) for _ in range(L + 1)]
    dp[L][0] = 1

    for pos in range(L - 1, -1, -1):
        rem = L - pos

        for bal in range(L + 1):
            val = 0

            # place '('
            if bal + 1 <= L:
                val += dp[pos + 1][bal + 1]

            # place ')'
            if bal > 0:
                val += dp[pos + 1][bal - 1]

            dp[pos][bal] = min(val, INF)

    ans_diag = ['?'] * L

    assigned = [None] * L

    # map diagonal -> sequence position
    pos_of_diag = [0] * L
    for idx, d in enumerate(order):
        pos_of_diag[d] = idx

    seq = ['?'] * L

    balance = 0

    for pos in range(L):
        # try '('
        remain_count = 0

        if balance + 1 <= L:
            remain_count = dp[pos + 1][balance + 1]

        if remain_count >= k:
            seq[pos] = '('
            balance += 1
        else:
            k -= remain_count
            seq[pos] = ')'
            balance -= 1

    # assign brackets to diagonals
    for d in range(L):
        ans_diag[d] = seq[pos_of_diag[d]]

    out = []

    for i in range(n):
        row = []
        for j in range(m):
            row.append(ans_diag[i + j])
        out.append(''.join(row))

    print('\n'.join(out))

solve()
```第一部分计算每个反对角线内的最小优先级。 该值确定对角线何时参与两个网格之间的比较。 

微妙之处在于比较顺序不是自然的对角线顺序。 我们必须按对角线包含的最小优先级对对角线进行排序，因为第一个不同的单元格决定顺序。 

DP是经典的平衡括号序列DP。`dp[pos][bal]`存储处理后可能有多少个后缀`pos`当前余额的角色`bal`。 

计数上限为`10^18`因为这个问题永远无法区分更大的值。 如果没有上限，具有固定宽度整数的语言将会溢出。 Python 整数是任意精度的，但上限仍然保持值的可管理性并反映了预期的逻辑。 

贪心构造是字典式生成。 我们首先测试是否放`"("`至少还剩下`k`有效完成。 如果是，我们保留它。 否则所有这些序列都出现得更早，所以我们减去它们并选择`")"`。 

一个容易犯的错误是忘记序列位置是按对角线优先级排序的，而不是按几何对角线索引排序的。 数组`pos_of_diag`处理这个转换。 

另一个容易出现的错误是在构建过程中允许出现负平衡。 这样的前缀永远不会成为有效的括号序列。
