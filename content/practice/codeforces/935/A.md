 ## 解决方案
 ## 问题理解

 Fafa需要将公司员工进行分组进行项目管理。 他想选出一些团队领导，用 _l_ 表示，并将剩余的员工平均分配给他们。 每个团队领导者必须监督相同数量的员工，没有一个员工没有领导者。 输入是单个整数 _n_，即员工总数。 输出是 _l_ 的可能值的数量，使得这种公平划分成为可能。 

重申一下，我们正在寻找所有严格小于 _n_ 的正整数 _l_，其中非领导者的数量 _n - l_ 可被 _l_ 整除。 这确保了剩余的员工可以在领导者之间平均分配。 例如，如果有 6 名员工，则选择 2 名领导者，剩下 4 名非领导者。 由于 4 能被 2 整除，因此每个领导者可以管理 2 名员工。 

这些限制虽然不大，但也很重要。 _n_ 可以大到 100,000。 尝试对最多 _n_ 的所有值进行所有可能的分组的简单解决方案最多需要 100,000 次操作。 如果每个操作都很简单，那么在 1 秒的时间限制内这是可以接受的，但值得考虑除数以避免不必要的检查。 边缘情况包括 _n = 2_，即员工数量最少，其中唯一有效的领导者数量为 1。另一个微妙的情况是当 _n_ 为素数时； 那么只有 1 位领导者起作用，因为任何其他选择都会留下余数。 

## 方法

 蛮力方法考虑从 1 到 _n - 1_ 的所有可能的领导者数量 _l_。 对于每个 _l_，我们检查剩余员工的数量 _n - l_ 是否能被 _l_ 整除。 这是正确的，但它执行 _n-1_ 除法运算。 在最坏的情况下，_n = 100,000_，大约需要 100,000 次检查，这是可行的，但有点不优雅。 

关键的观察结果是，问题简化为计算小于 _n_ 的 _n - l_ 的除数。 更具体地说，我们正在寻找 _l_ 除 _n - l_ 的所有 _l_。 如果我们重写这个条件，对于某个整数 k ≥ 1，它会变成 _n - l = k * l_。重新排列得到 _n = l * (k + 1)_。 因此，_l_ 必须是 _n_ 的除数，且严格小于 _n_。 这种转换消除了不必要的检查，是一个经典的除数问题。 仅迭代 √n 以内的除数可确保 O(√n) 复杂度。

 ## 算法演练

 1. 读取输入整数_n_。 这代表了Fafa公司的员工总数。 
2. 将计数器初始化为 0。这将跟踪团队领导者的有效选择数量。 
3. 从 1 迭代 _l_ 到 √n（含）。 对于每个_l_，检查它是否整除_n_。 
4. 如果 _l_ 除 _n_，它是一个潜在的候选者，因为它满足 _n = l * (k + 1)_。 如果 _l_ 小于 _n_，则递增计数器。 
5. 同时检查相应的除数_n // l_。 如果它不同于 _l_ 且小于 _n_，则递增计数器。 
6. 处理完所有除数后，打印计数器。 这是选择团队领导者的有效方法的数量。 

为什么它有效：关键的不变量是，当且仅当它除以 _n_ 并且严格小于 _n_ 时，领导者 _l_ 的数量才有效。 通过迭代 _n_ 的所有除数，我们保证所有潜在的有效 _l_ 都被恰好考虑一次。 没有其他值可以满足公平条件，因此计数器是精确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
count = 0
i = 1
while i * i <= n:
    if n % i == 0:
        if i < n:
            count += 1
        if i != n // i and n // i < n:
            count += 1
    i += 1
print(count)
```该解决方案使用整数除法来有效地找到除数。 我们检查 _i_ 和 _n // i_ 以考虑除数对。 边界检查确保领导者数量严格小于_n_，避免所有员工都是领导者的无效情况。 循环在 √n 处停止，以防止冗余检查，从而提高解决方案的效率。

 ## 边缘情况

 对于 _n = 2_，只有一位领导者是可能的。 循环迭代 i = 1。1 < 2，因此计数递增到 1。相应的除数 2 没有被计算，因此输出为 1，正确处理最小输入。 

对于质数 _n = 17_，只有 i = 1 才能整除 17，且 i < 17，因此 count = 1。相应的除数 17 被忽略。 该算法正确地避免了过度计数并处理素数。 

对于像 _n = 36_ 这样的完美平方，除数包括 6，即平方根。 检查 i != n // i 防止重复计算 6，确保每个有效的领导者计数只计算一次。
