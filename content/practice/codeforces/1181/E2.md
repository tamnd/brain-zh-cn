 ## 解决方案
 ## 问题理解

 我们得到一组代表“城堡”的轴对齐矩形。 这些矩形在区域上不重叠，尽管它们可能共享边界或角。 据称，这些城堡来自更早的历史，其中每座城堡都属于自己的国家，随着时间的推移，只要国家的领土仍然是矩形，国家就会合并。 

最后，只剩下一个国家，我们只看到城堡。 问题是是否可以将每个城堡分配给一个初始国家并模拟一系列合并，其中每次合并将两个当前国家合并为一个，只要它们的联合仍然是一个矩形，这样最终所有国家都会合并成一个包含所有城堡的最终矩形。 

关键的隐藏结构是只合并保留矩形，因此每个中间国家必须对应于由整个原始城堡组成的某个轴对齐的矩形。 我们没有被要求重建这个过程，只是要决定这样的过程是否可能存在。 

输入大小达到十万个矩形，每个矩形的坐标高达十亿。 任何检查矩形对或天真地模拟合并的解决方案都会导致二次行为，并且立即不可行。 甚至一个$O(n \log^2 n)$必须仔细论证方法的合理性。 

当矩形形成全局一致但局部不可能以保留矩形的方式合并的配置时，就会出现微妙的失败情况。 例如，想象四个矩形形成一个空心方形边框。 每个矩形都接触两个相邻矩形，但任何成对合并都会生成 L 形而不是矩形，从而阻止任何有效的合并序列。 选择任何相邻矩形的天真贪婪合并策略将错误地接受这种情况。 

另一个棘手的情况是，当全局边界矩形被完全覆盖时，但该结构会强制出现不存在有效合并顺序的依赖关系“循环”。 这通常会破坏仅检查覆盖范围或邻接性而不推理合并可行性的方法。 

## 方法

 直接的暴力解释尝试显式地模拟该过程。 我们将每个矩形视为一个节点，并重复搜索并集形成矩形的两个节点。 检查两个矩形的并集是否是矩形可以在恒定时间内完成，因此暴力步骤是扫描所有对，合并有效对，然后重复直到只剩下一个或无法合并。 

每个合并步骤都需要扫描$O(n^2)$配对，我们最多可以执行$O(n)$合并。 这导致$O(n^3)$最坏情况的行为，远远超出了限制$n = 10^5$。 即使使用空间索引等优化，合并的动态性质也使得维护高效的候选对变得困难。 

关键的观察是我们实际上不需要模拟合并。 仅当两个矩形沿整条边相邻时，矩形并集才有效。 这意味着该过程相当于逐渐将矩形分组为连接的组件，其中通过共享完整的边缘段来定义邻接关系。 

这将问题转化为非常具体的几何邻接规则下的连通性条件。 我们不是模拟合并，而是检查矩形是否可以划分为组，以便每个组可以合并为一个矩形，并且这些组本身可以分层合并而不会产生矛盾。 该结构简化为验证由“可能合并对”引起的邻接图是否支持在不遇到禁止配置的情况下完全简化为一个组件，这可以使用扫描线和间隔事件推理进行测试。 

核心的简化是，当且仅当排列不包含不可避免的“仅限角接触的循环”（该循环会阻止矩形保留合并）时，该过程才有效。 这可以通过跟踪扫描平面时垂直和水平重叠如何相互作用来检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟|$O(n^3)$|$O(n)$| 太慢了 |
 | 扫描线邻接重建 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将矩形解释为几何间隔，并推理它们如何通过有效的矩形并集进行合并。 

1. 首先，按 x 坐标对所有矩形进行排序。 这使我们能够处理平面的垂直切片如何从左到右演变。 这种排序的原因是矩形联合依赖于共享的垂直边界。 
2. 我们在平面上扫描一条垂直线，并保持与扫描位置相交的矩形的活动间隔。 每个活动集代表该 x 坐标处可能合并的“边界”。 
3. 对于每个事件点（矩形的起始或结束 x 坐标），我们更新活动集并跟踪 y 间隔的划分方式。 如果在任何一点，活动矩形形成多个不相交的 y 线段，我们就会在合并图中记录结构边界。 这是必要的，因为如果没有后续交互，不相交的垂直堆栈无法合并为单个矩形。 
4. 我们在共享完全垂直或水平邻接的矩形之间构建隐式连接约束。 仅当两个矩形的投影完全沿着整个边缘段对齐而不是部分重叠时，才认为两个矩形是可连接的。 
5. 然后，我们验证这种连接结构是否允许完全简化为单个组件而不会产生矛盾。 这相当于检查邻接图是否在矩形有效边下连接，并且不包含扫描期间由不一致的 y 分区引起的强制分离。 
6. 最后，我们确认所有矩形是否属于单个一致的合并结构。 如果扫描检测到活动间隔中存在任何不可调和的分裂，我们会拒绝； 否则我们接受。 

### 为什么它有效

 每个有效的合并序列对应于沿完整边缘重复合并相邻矩形，这保留了轴对齐并确保中间对象保持矩形。 这对任何 x 扫描期间 y 间隔的演变施加了严格的层状结构。 如果在任何 x 坐标处，活动集分裂成多个断开的垂直组件，并且永远不会一致地重新连接，则任何保留矩形的并集序列都无法将所有内容合并到一个矩形中。 相反，如果扫描从不强制出现这样的矛盾，则可以按照与扫描结构一致的顺序合并矩形，从而保证存在有效的构造。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_merge(rects):
    # We compress the problem into checking consistency of vertical ordering
    # using sweep events on x-coordinates.
    events = []
    ys = set()

    for x1, y1, x2, y2 in rects:
        events.append((x1, y1, y2, 1))
        events.append((x2, y1, y2, -1))
        ys.add(y1)
        ys.add(y2)

    events.sort()

    # We track active y-interval coverage via coordinate compression + counter.
    ys = sorted(ys)
    idx = {v: i for i, v in enumerate(ys)}

    cnt = [0] * (len(ys) + 1)

    def add(l, r, val):
        for i in range(l, r):
            cnt[i] += val

    def check_gap():
        active = False
        found_block = False
        for i in range(len(ys) - 1):
            if cnt[i] > 0:
                active = True
            else:
                if active:
                    found_block = True
                    break
        return not found_block

    i = 0
    while i < len(events):
        x = events[i][0]

        while i < len(events) and events[i][0] == x:
            _, y1, y2, t = events[i]
            l, r = idx[y1], idx[y2]
            if t == 1:
                add(l, r, 1)
            else:
                add(l, r, -1)
            i += 1

        if not check_gap():
            return False

    return True

def main():
    n = int(input())
    rects = [tuple(map(int, input().split())) for _ in range(n)]
    print("YES" if can_merge(rects) else "NO")

if __name__ == "__main__":
    main()
```该代码对 x 轴上的所有矩形端点执行扫描。 在每个事件中，它都会更新离散 y 间隔的覆盖范围。 关键结构是`cnt`数组，它跟踪当前有多少个矩形覆盖每个垂直段。 这`check_gap`函数强制 y 中的主动覆盖范围必须保持连续； 否则，配置将强制进行无法通过保留矩形的合并来协调的分割。 

一个常见的实现陷阱是忘记邻接必须覆盖整个边缘。 沿 y 的部分重叠是不够的，这就是为什么扫描验证覆盖的连续性而不是简单地跟踪重叠。

 ## 边缘情况

 一个关键的边缘情况是矩形仅在角处接触。 例如，在单个点相交的两个矩形不提供有效的合并边，即使它们在几何上相邻。 该算法正确地将这些视为扫描中不重叠的 y 间隔，因此不会创建连续性并且配置失败。 

另一种情况是形成交替条带的细长矩形。 在本地，它们似乎可以成对合并，但在全球范围内，它们迫使主动覆盖范围持续分裂。 在扫描过程中，这表现为重复创建不相交的 y 分量，且永远不会统一，这会在活动结构不连续的第一个无效 x 事件时触发拒绝。
