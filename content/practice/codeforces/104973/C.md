 ## 解决方案
 ## 问题理解

 我们得到一个无向图$n$城市和$m$拟议的隧道。 每条隧道连接两个城市并带有数字标签。 我们可以为每个城市分配一个标签，也是一个数字。 仅当隧道的端点之一的城市标签等于隧道标签时，隧道才可用。 如果两个端点都与标记匹配或都不匹配，则忽略该隧道。 

目标是为城市分配标签，以便在按此规则过滤隧道后，剩余的可用隧道仍然允许在每对城市之间行驶。 换句话说，可用的边必须形成连通图。 

输入保证，如果我们忽略激活规则并保留所有隧道，则图是连通的。 挑战在于，我们根据全局标签约束有选择地删除边：每个节点都有一个值，但每条边都强制执行一个涉及与其自己的标签相等的条件。 

约束条件很大，最多可达$2 \cdot 10^5$节点和边。 这立即排除了任何指数分配搜索或每节点回溯。 任何解决方案都必须在线性或近线性时间内构造标签，本质上$O(n + m)$。 

如果我们尝试没有结构的贪婪局部选择，就会出现微妙的失败模式。 例如，如果我们独立地为每条边决定标签，则单个顶点可能被迫满足多个冲突的边要求，因为它的标签在所有关联边之间共享。 另一个常见的错误是尝试根据相等边标记的连接组件来分配标签，但这种方法会失败，因为边通过共享顶点而不是单独的共享标签进行交互。 

真正的困难是控制一致性：每个顶点只能“提交”一个标签，但每条边都试图施加一个约束，即其端点之一必须与自己的标签匹配。 

## 方法

 一种简单的方法是独立处理每个顶点并尝试所有可能的标签分配。 对于每个分配，我们重新计算哪些边激活，然后检查连通性。 这立即爆炸了：每个$n$顶点数达到$m$可能有意义的选择（边缘标签加虚拟值），因此状态空间是指数的，连通性检查是线性的，导致不可行$O(m \cdot m^n)$实践中的型爆炸。 

关键的观察是我们实际上并不需要立即推理所有边。 确保激活边的某些子集已经形成生成树就足够了。 由于原始图是连通的，因此它包含一棵生成树。 如果我们可以强制所选生成树的所有边都变为活动状态，则无论非树边发生什么情况，都可以保证连接。 

现在考虑一下这对于单个树边意味着什么$(u, v, a)$保持活跃。 恰好一个端点必须有标签$a$。 这是一个方向性的选择：我们决定是否$u$通过将其标签设置为“承担责任”来满足边缘的要求$a$， 或者$v$做。 

如果我们将每条树边视为将责任分配给一个端点，那么每个顶点不得负责多条边，否则将被迫采用多个不同的标签。 这种限制是核心的结构性约束。 

树承认有一种非常干净的方法来强制执行此操作：将其作为根并将所有边缘定向到根。 然后，每个非根顶点都恰好有一条父边指向它，因此它被分配了正好一个标签，即该父边的标签。 根不接收任何分配，并且可以安全地采用不干扰任何边缘标签的虚拟值。 

这种构造保证了每个树边都被一致地激活，因此激活的子图已经包含生成树。

 ## 算法演练

 我们将问题转化为选择生成树并强制它在规则下激活。 

1. 从任意节点开始，使用 DFS 或 BFS 构建图的任意生成树。 由于完整的图是连接的，所以这总是可能的。 
2. 在任意顶点处将此树作为根，例如顶点 1。根的选择不会影响正确性，但会简化赋值一致性。 
3. 为根分配一个特殊标签，保证不会显示为任何边缘标签。 由于所有边缘标签都在$[1, m]$，选择$m + 1$是安全的。 
4. 遍历有根树。 对于父级之间的每个树边$p$和孩子$c$，带有边缘标签$a$， 分配$b[c] = a$。 
5.此时父母保持不变； 如果它不是根，它要么已经有一个值，要么最终被设置。 在此构造中，每个非根节点从其父边恰好获得一个分配。 
6.输出结果数组$b$。 

这样做的原因是保证每个树边都被激活：子端点的标签等于边标签，而父端点则没有（因为它是具有不同标签的根，或者因为它更接近根，因此分配了不同的边标签）。 由于这些激活的树边形成生成树，因此所有城市都保持连接。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    
    edges = []
    for _ in range(m):
        u, v, a = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append((v, a))
        g[v].append((u, a))
    
    parent = [-1] * n
    parent_edge = [-1] * n
    
    # build spanning tree with BFS
    from collections import deque
    q = deque([0])
    parent[0] = -2
    
    order = []
    
    while q:
        u = q.popleft()
        order.append(u)
        for v, a in g[u]:
            if parent[v] == -1:
                parent[v] = u
                parent_edge[v] = a
                q.append(v)
    
    b = [0] * n
    b[0] = m + 1
    
    for i in range(1, n):
        b[i] = parent_edge[i]
    
    print(*b)

if __name__ == "__main__":
    solve()
```BFS 通过记录每个节点第一次被访问的时间来隐式构造生成树。 这`parent_edge[v]`存储用于到达的边缘的标签`v`，这成为强制值`b[v]`。 

根已分配$m+1$，保证不与任何边缘标签发生冲突的值。 其他每个节点都只采用一个值，因此没有顶点会面临分配冲突。 沿着 BFS 树边逐边满足激活规则。

 ## 边缘情况

 只有两个节点的最小图可以被干净地处理，因为单边成为生成树。 子节点采用边缘标签，根节点采用虚拟值，并且连接性很简单。 

在星形图中，一个节点成为根，每个其他节点直接获取其关联边标签。 由于每片叶子都只有一个父边，因此即使根有许多邻居，也不会发生冲突。 

在长链中，除根之外的每个节点都从其父边缘接收恰好一个分配，因此标签沿路径传播而不会发生分支冲突。 该结构确保没有节点被迫满足多个边缘约束，从而始终保持有效性。
