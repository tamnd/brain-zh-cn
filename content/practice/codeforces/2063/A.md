 **求解时间：** 1m 50s

 ## 解决方案
 ## 问题理解

 给定一个整数段$[l,r]$。 一段$[a,b]$当两个端点$a$和$b$最大公约数等于$1$。 

在所有互质部分中，我们只关心那些最小的部分。 如果不存在完全包含在其中的严格较小的互质段，则互质段是最小的。 

对于每个测试用例，我们必须计算给定范围内包含多少个最小互质段$[l,r]$。 

这些限制非常具有启发性。 端点可以大到$10^9$，这意味着任何迭代所有子段的解决方案都是不可能的。 即使是单个长度区间$10^9$大致包含$10^{18}$子段。 由于测试用例多达 100 个，因此预期的解决方案必须在每个测试用例的恒定时间内运行。 

棘手的部分是理解最小互素段实际上是什么样子。 

考虑细分市场$[2,3]$。 自从$\gcd(2,3)=1$，它是互质的。 它唯一正确包含的段是$[2,2]$和$[3,3]$，两者都不是互质，因为$\gcd(2,2)=2$和$\gcd(3,3)=3$。 因此$[2,3]$是最小的。 

现在考虑$[2,5]$。 它是互质的，因为$\gcd(2,5)=1$，但它包含$[2,3]$，这已经是一个互质段。 因此$[2,5]$不能是最小的。 

数字 1 是一个特别容易错过的情况。$[1,1]$是互质的，因为$\gcd(1,1)=1$。 由于它不包含更小的段，因此它是最小的。 

例如：

 输入：```
1 1
```输出：```
1
```假设每个长度为 1 的段都是非互质的粗心解决方案将错误地返回 0。 

另一个重要案例是：

 输入：```
2 2
```输出：```
0
```这里$\gcd(2,2)=2$，因此该线段不是互质的。 

再举一个例子：

 输入：```
2 4
```最小的互素段仅是$[2,3]$和$[3,4]$，所以答案是2。 

天真的尝试可能会计算所有互质对，包括$[2,4]$，但是该段包含$[2,3]$并且不是最小的。 

## 方法

 蛮力的想法很简单。 枚举每个包含的段$[a,b]$，检查是否$\gcd(a,b)=1$，然后验证它是否包含另一个互质段。 

这是正确的，因为它直接遵循定义。 不幸的是，长度范围$n$包含$O(n^2)$子段。 即使$n$只是$10^5$，这已经意味着$5 \times 10^9$段。 端点高达$10^9$，暴力破解是完全行不通的。 

关键的观察结果是最小互质段具有极其刚性的结构。 

认为$[a,b]$是最小的并且$a<b$。 

如果$b-a\ge 2$，然后包含的段$[a,a+1]$就在里面。 连续整数始终是互质的：$$\gcd(a,a+1)=1$$所以$[a,a+1]$是一个互质段包含在里面$[a,b]$。 这与极简主义相矛盾。 

因此，每个最小互质段的长度必须为 0 或 1。 

长度0表示$[x,x]$。 仅当以下情况时，这样的线段才是互质的：$x=1$， 因为$$\gcd(x,x)=x.$$因此长度为 0 的唯一最小线段是$[1,1]$。 

长度1表示$[x,x+1]$。 连续的整数总是互质的，并且唯一包含的段是$[x,x]$和$[x+1,x+1]$。 为了$x\ge2$，它们都不是互质的，所以$[x,x+1]$是最小的。 

案例$x=1$很特别。 该段$[1,2]$包含$[1,1]$，这是互质的，所以$[1,2]$不是最小的。 

我们已经完全表征了所有最小互质段：

 1.$[1,1]$2.$[x,x+1]$对于每一个$x\ge2$现在计数变得很容易。 

每相邻对$[x,x+1]$里面$[l,r]$贡献一个最小的部分。 这样的对对所有人都存在$$x \in [l,r-1].$$有$r-l$其中。 

唯一的调整是当范围包含特殊段时$[1,1]$。 这恰好发生在$l=1$。 

如果$l=r=1$，答案是1。 

否则，当$l=1$，这对$[1,2]$已包含在计数中$r-l$，但它不是最小的。 我们必须将其替换为$[1,1]$。 总剩余量$r-l$。 

这导致了一个非常简单的公式：

 如果$(l,r)=(1,1)$，回答1。 

否则请回答$r-l$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O((r-l+1)^2)$或者更糟|$O(1)$| 太慢了 |
 | 最佳 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 阅读$l$和$r$。 
2. 检查是否$l=r=1$。 

这是唯一一个其答案未包含在简单差分公式中的范围。 
3.如果$l=r=1$，打印 1。 
4. 否则，打印$r-l$。 

步骤 4 起作用的原因是区间内的每个最小互质段恰好对应于一个相邻对$[x,x+1]$和$x\ge2$，加上特殊的单例$[1,1]$。 计数总是简化为$r-l$对于每个间隔，除了$[1,1]$。 

### 为什么它有效

 任何长度至少为 2 的互质段都包含连续对$[x,x+1]$，它本身是互质的。 这样的部分不能是最小的。 

因此，每个最小互质段的长度都是 0 或 1。 

在长度为0的段中，只有$[1,1]$是互质的。 

在length-1段中，每$[x,x+1]$是互质的。 恰好当$x\ge2$， 因为$[1,2]$包含互质段$[1,1]$。 

这些都是可能的最小互质段，因此将它们算在里面$[l,r]$得出上面的公式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    l, r = map(int, input().split())

    if l == 1 and r == 1:
        print(1)
    else:
        print(r - l)
```实现直接遵循上面证明的特征。 

第一个条件处理仅包含数字 1 的唯一区间。它的答案是 1，因为段$[1,1]$是最小互质。 

每隔一个间隔使用以下公式$r-l$。 自从$l$和$r$至多是$10^9$，普通整数运算就足够了。 Python 整数可以轻松处理这些值。 

最常见的错误是使计数过于复杂并试图推断整个时间间隔内的 gcd 值。 一旦理解了最小段的结构，只有特殊情况$[1,1]$遗迹。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        l, r = map(int, input().split())

        if l == 1 and r == 1:
            ans.append("1")
        else:
            ans.append(str(r - l))

    print("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out
