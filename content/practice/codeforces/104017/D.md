 ## 解决方案
 ## 问题理解

 我们有一条漫长而笔直的海岸线，小屋放置在固定的位置。 小屋$i$正好坐$100$小屋右侧几米处$i-1$，所以小屋形成一条完美均匀的线。 每个小屋都有一定数量的人，每个人只会购买一份冰淇淋。 

除了小屋之外，同一条线上的已知坐标处已经有几家冰淇淋店。 现在我们被允许开设一家新商店，并且我们可以将其放置在这条线上的任何位置，不一定是在小屋或整数位置。 

每个人都会严格按照距离去最近的商店。 如果最接近并列，那么那个人就不会选择我们的商店，因为我们的商店必须严格地比所有现有商店更近。 

目标是选择新店的位置，使我们店所服务的总人数最大化。 

输入包括小屋数量、现有商店数量、每个小屋中的人口以及现有商店的位置。 输出是一个数字：通过最佳放置我们的商店可以捕获的最大总人口。 

这些限制影响到数十万间小屋和商店。 这立即排除了对所有候选位置的任何二次策略或对每个小屋的简单扫描。 任何重复重新计算每个候选位置到所有商店的距离的方法都太慢了。 解决方案必须本质上将问题减少到少量关键候选区域，或者在单次或近乎线性的过程中计算贡献。 

一个微妙的边缘情况是当两个现有商店同样靠近小屋边界区域时。 在这种情况下，可能没有一段时间我们可以“偷”那个小屋，除非我们将新商店严格定位在比两者更近的地方，而这恰好位于中点是不可能的。 例如，如果小屋位于位置 0 和 100，现有商店位于 -100 和 200，则中点结构决定是否可以捕获任何小屋，如果不强制执行严格的不平等，则关于“最近间隔”的天真推理可能会误算。 

当多个商店创建非常小的 Voronoi 单元时，会出现另一种故障模式。 如果一间小屋已经被一家现有商店占据，利润率非常大，那么新商店的放置就无济于事，除非我们跨越由相邻商店之间的中点定义的边界。 试图独立地“选择最好的小屋”的天真贪婪的方法将会失败，因为搬迁新店会改变全球而不是本地的主导地位。 

## 方法

 关键的困难在于，新商店的位置导致线路被划分为每个小屋距离特定商店最近的区域。 对于固定位置，每个小屋仅比较相对于新商店左右两侧最近的现有商店的距离，这意味着该结构由相邻商店之间的中点控制。 

蛮力方法将尝试由所有现有商店和可能的所有小屋位置引起的每一个可能的放置间隔，并为每个候选者计算距离新商店比任何现有商店更近的总人口。 如果有$n$小屋和$m$商店，评估一次安置成本$O(n)$，并且有$O(n+m)$有意义的间隔，给出总复杂度$O(n(n+m))$，这远远超出了可行的范围$2 \cdot 10^5$。 

关键的见解是，每个小屋的优势条件仅取决于左侧和右侧最近的现有商店，并且新商店只有位于这两个相邻商店确定的特定区间内才能“赢得”一个小屋。 具体来说，对于每个小屋，我们可以计算每侧最近的现有商店，并且新商店只有放置得比这两个商店定义的中点边界更近时才能击败这两个商店。 这减少了每个小屋对其“可占领”线上区间的贡献。 

一旦每个小屋被转换成这样一个由其人口加权的区间，问题就变成了选择一条线上的一个点，使覆盖该点的区间的总权重最大化。 这是一个经典的扫描线问题：我们将每个间隔转换为左端点的 +p 事件和右端点的 -p 事件，然后扫描以找到最大有效和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 强力放置检查 |$O(n(n+m))$|$O(1)$| 太慢了 |
 | 扫描捕获间隔 |$O((n+m)\log(n+m))$|$O(n+m)$| 已接受 |

 ## 算法演练

 我们假设所有小屋位置都固定在坐标上$100 \cdot (i-1)$。 我们还对现有的商店位置进行排序。 

1. 对于每个小屋，使用对排序的商店位置进行二分搜索来识别左侧和右侧最近的现有商店。 这给了我们两个候选竞争对手，决定新店能否赢得这个小屋。 如果小屋位于所有现有商店之外，我们会将失踪的邻居视为$-\infty$或者$+\infty$，意味着仅存在一侧约束。 
2. 对于每个小屋，计算与其左右竞争商店的中点边界。 如果小屋位于$x$，离开商店于$L$，右店于$R$，那么新商店必须严格比两者更近，这意味着它必须位于中点之间的有效区间$(L+x)/2$和$(x+R)/2$，与双方的可行性约束相交。 该间隔代表新商店占领该小屋的所有位置。 
3. 将每个这样的间隔转换为两个事件：在左端点添加小屋人口，在右端点减去它。 这编码了这样一个事实：在区间内，小屋有贡献，而在区间外则没有贡献。 
4. 按位置对所有事件进行排序。 从左向右扫描，保持活跃贡献的连续总和。 跟踪看到的最大值。 
5. 返回最大扫描值，该值对应于新商店的最佳可能位置。 

### 为什么它有效

 只有当新商店比每个现有商店都严格更近时，每个小屋才会对答案做出贡献。 由于直线上的距离比较减少到竞争商店之间的中点边界，因此每个小屋都会产生一个连续的有效放置区域。 最终目标是选择这些区域的最大总权重覆盖的点。 扫描保持了所有这些区域的精确重叠结构，因此在每个位置，它都会精确计算将选择那里的新商店的总人口。 由于每个可能的放置都在扫描中的某个位置表示，因此最大值是全局最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    p = list(map(int, input().split()))
    shops = list(map(int, input().split()))
    shops.sort()

    # hut positions: 0, 100, 200, ...
    huts = [100 * i for i in range(n)]

    events = []

    from bisect import bisect_left

    for i in range(n):
        x = huts[i]
        w = p[i]

        idx = bisect_left(shops, x)

        L = shops[idx - 1] if idx > 0 else None
        R = shops[idx] if idx < m else None

        left_bound = -10**30
        right_bound = 10**30

        if L is not None:
            left_bound = max(left_bound, (L + x) / 2)
        if R is not None:
            right_bound = min(right_bound, (R + x) / 2)

        if left_bound <= right_bound:
            events.append((left_bound, w))
            events.append((right_bound, -w))

    events.sort()

    cur = 0
    best = 0
    for x, v in events:
        cur += v
        if cur > best:
            best = cur

    print(best)

if __name__ == "__main__":
    solve()
```该代码首先在数轴上修复小屋的几何形状。 然后，它使用二分搜索来查找每个小屋周围最近的两个现有商店。 这两家商店是新商店可能占据小屋的唯一区域。 

中点计算将距离比较转化为线性不等式，这就是每个小屋成为一个简单区间的原因。 然后，扫描线聚合重叠间隔，并且运行总和始终反映当前通过将商店放置在该坐标处“赢得”的总人口。 

一个微妙的实现点是原始条件下严格的不平等要求。 使用中点边界意味着相等对应于平局，通过事件排序隐式排除边界点可以正确处理平局。 在这里使用浮动除法是安全的，因为只有相对顺序才重要； 如果需要更严格的精度控制，整数双乘表示也可以工作。

 ## 边缘情况

 一个重要的边缘情况是小屋位于所有现有商店之外。 在这种情况下，它只有一个有意义的竞争对手方，因此其有效区间在一侧变得无界。 该算法通过使用哨兵无穷来处理这个问题，因此小屋正确地贡献了半无限间隔。 

另一种边缘情况是小屋与边界中点完全等距。 在这种情况下，严格的不平等意味着小屋不应计入该边界。 在扫描中，我们一致地对待端点，这样平等就不会人为地包括小屋，从而保持正确性。 

最后的边缘情况是多个小屋产生相同的间隔。 扫描线正确地聚合了它们的权重，因此重叠的相同贡献只是简单地求和，这正是目标所要求的。
