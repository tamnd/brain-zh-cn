 ## 解决方案
 ## 问题理解

 我们有许多相同的棍子，任务是使用所有这些棍子形成矩形网格结构。 尺寸网格$n \times m$是一个细分为单位正方形的矩形，其中网格中的每个单位边缘都由一根棍子表示。 这意味着棒用于外边框和所有内部网格线。 

对于固定对$(n, m)$，所需的棒数由两个方向上的单位段数决定。 横向有$n+1$每条水平线由$m$细分市场，贡献$m(n+1)$。 纵向上有$m+1$每条垂直线由$n$细分市场，贡献$n(m+1)$。 所以木棍总数为：$$k = m(n+1) + n(m+1) = 2nm + n + m$$每个测试用例的目标都是双重的。 首先判断是否至少有一对正整数$(n, m)$对于给定的情况满足该方程$k$。 如果不存在，那么答案是不可能的。 否则，在所有有效对中，计算最小和最大可能面积$n \cdot m$。 

约束条件允许$k$最多$10^9$以及最多 10 个测试用例，因此任何解决方案都必须避免迭代所有维度对。 直接搜索所有内容$n, m$会太慢，因为即使是天真的$O(k)$每个测试用例扫描是不可行的。 

一个微妙的边缘情况是较小的值$k$。 例如，$k = 3$无法形成任何有效的网格，因为即使是最小的网格$1 \times 1$网格需要 4 根棍子。 另一种情况是同一个形状存在多个形状时$k$， 例如$k = 22$，其中两者$1 \times 7$和$2 \times 4$配置有效，但产生不同的区域。 

## 方法

 暴力方法会尝试所有可能的方法$n, m$这样$2nm + n + m = k$。 重新排列给出：$$(2n+1)(2m+1) = 2k + 1$$所以我们有效地分解了$2k+1$分成两个奇数因数。 一个简单的解决方案将迭代所有可能的因素对$2k+1$，检查它们是否对应有效$n, m$和计算区域。 

数量$2k+1$可以大到$2 \cdot 10^9 + 1$，因此扫描所有除数直到其平方根已经是临界值，但对于 10 个测试用例来说仍然可以接受。 然而，关键的观察是，一旦我们考虑$2k+1$，每个除数对直接映射到唯一的网格，无需任何嵌套搜索。 

转变$(2n+1)(2m+1) = 2k+1$是关键的简化。 我们不是求解二变量丢番图方程，而是将问题简化为枚举单个数字的因子对并将它们解码回维度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力网格搜索 |$O(k^2)$|$O(1)$| 太慢了 |
 | 因式分解$2k+1$|$O(\sqrt{k})$|$O(1)$| 已接受 |

 ## 算法演练

 我们依赖分解恒等式$(2n+1)(2m+1) = 2k+1$，它将每个有效网格编码为除数对。 

1. 变换输入$k$进入$N = 2k + 1$。 这将几何约束转换为纯因式分解问题。 
2. 迭代所有整数$d$从 1 到$\lfloor \sqrt{N} \rfloor$。 每个$d$是一个候选除数$N$。 
3.如果$d$划分$N$，计算配对除数$N / d$。 
4. 检查两者是否$d$和$N/d$很奇怪。 这确保它们对应于有效值$2n+1$和$2m+1$。 
5. 使用以下方法恢复尺寸：$$n = \frac{d - 1}{2}, \quad m = \frac{N/d - 1}{2}$$6. 计算面积$n \cdot m$并跟踪所有有效对的最小值和最大值。 
7. 如果不存在有效对，则输出-1。 否则输出最小和最大面积。 

### 为什么它有效

 每个有效网格都唯一对应于一对整数$n, m$，唯一对应于奇数$2n+1$和$2m+1$，其产品正是$2k+1$。 反之，每个因子对$2k+1$成奇数整数映射回有效网格。 这在解和奇数因子对之间创建了一对一的对应关系，因此枚举了$2k+1$探索整个解决方案空间，没有冗余或遗漏。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        k = int(input())
        N = 2 * k + 1

        import math
        best_min = float('inf')
        best_max = -1
        found = False

        r = int(math.isqrt(N))
        for d in range(1, r + 1):
            if N % d == 0:
                d2 = N // d

                if d % 2 == 1 and d2 % 2 == 1:
                    n = (d - 1) // 2
                    m = (d2 - 1) // 2

                    if n > 0 and m > 0:
                        area = n * m
                        best_min = min(best_min, area)
                        best_max = max(best_max, area)
                        found = True

        if not found:
            print(-1)
        else:
            print(best_min, best_max)

if __name__ == "__main__":
    solve()
```实现的核心是除数枚举循环$2k+1$。 变换步骤至关重要，因为它消除了双线性结构$2nm + n + m$并用乘法结构代替它。 

我们明确强制执行奇数除数，因为只有奇数可以写为$2n+1$。 我们还强制执行$n, m > 0$，其中排除了退化的 0 维网格，否则这些网格会出现在$d = 1$。 

最小和最大面积跟踪是在所有有效分解上完成的，因为不同的因子对可以为相同的因子产生不同的矩形形状$k$。

 ## 边缘情况

 当$k = 3$，我们得到$N = 7$，这是素数。 唯一的因子对是$1 \cdot 7$和$7 \cdot 1$, 两者都生产$n = 0$或者$m = 0$。 该算法正确地拒绝了两者，因为需要正尺寸，结果为 -1。 

什么时候$k = 4$,$N = 9$，唯一有效的因子对是$3 \cdot 3$。 这产生$n = m = 1$，产生一个单位正方形，因此最小和最大面积都等于 1。 

当$k = 22$,$N = 45$，多个因子对产生有效的网格，并且算法对称地枚举所有这些网格。 最小-最大跟踪正确捕获了之间的差异$1 \times 7$和$2 \times 4$结构，不丢失不对称重复项。
