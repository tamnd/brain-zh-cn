 ## 解决方案
 ## 问题理解

 我们被要求构造长度最小的十进制数$n$仅由数字组成$3$和$6$，这样它就可以被两者整除$33$和$66$。 输入为我们提供了许多测试用例$t$，并且对于每个测试用例一个正整数$n$代表所需的数字长度。 输出必须是满足条件的最小数或$-1$如果不存在这样的号码。 

可整性约束将问题简化为数论性质。 一个数字可以被$66$必须能被两者整除$2$和$3$，因此也由$6$。 整除性$33$需要被整除$3$和$11$。 由于我们的号码只包含$3$沙$6$s，它总是可以被整除$3$，所以真正的约束是整除$11$并由$2$。 整除性$2$要求最后一位数字是$6$， 自从$3$很奇怪。 整除性$11$要求数字交替和是以下的倍数$11$。 

的限制$n$是谦虚的：$1\le n\le 500$和$1\le t\le 500$，所以线性解为$n$每个测试用例是可以接受的。 边缘情况包括非常小的$n$不存在数字的地方，例如$n=1$，以及数字不能满足交替和条件的长度$3$和$6$。 

## 方法

 一个简单的方法是生成所有长度的数字$n$带数字$3$和$6$，对它们进行排序，并检查每个的整除性$66$和$33$。 候选人人数为$2^n$，这对于$n$一样大$500$。 这个方法原则上是正确的，但是指数级的$n$，使其不切实际。 

关键的见解是所有数字都必须以$6$可以被整除$2$，将问题简化为分配数字$3$和$6$在第一个$n-1$满足整除性的位置$11$。 整除性$11$仅取决于数字交替和：奇数位置的数字之和减去偶数位置的数字之和必须是以下的倍数$11$。 鉴于最后一位数字是$6$，我们可以定义一个计数模式$3$沙$6$s 位于奇数和偶数位置以满足此条件。 一旦我们解决了这个问题，就可以通过放置尽可能多的数量来实现最小数量$3$一开始就尽可能的。 

这将问题从指数搜索简化为简单的算术和构造。 对于每个$n$，我们计算有多少$3$s 应放在前面以满足交替求和模$11$，将余数填入$6$s，并附加最后的$6$。

 ## 算法演练

 1.如果$n=1$或者$n=3$，立即返回$-1$，因为没有单位数或三位数的组合$3$沙$6$s 可以整除$33$和$66$。 这些是直接检查得出的小边缘情况。 
2. 对于$n\ge 2$，注意数字必须以$6$满足整除性$2$。 这修复了最后一位数字并简化了交替求和模$11$计算。 
3.让$k$是不超过的最大偶数$n$这样$k$最后的$n-1$数字可以设置为$6$剩下的到$3$满足整除性$11$。 这相当于最大化数量$3$s在前面，同时保证交替求和模$11$为零。 
4. 通过放置来构造数字$n-k-1$ $3$首先是 s，然后是$k$ $6$s，然后附加最后一个$6$。 这保证了最小性，因为$3<6$，所以放置$3$s 尽可能靠左产生最小的十进制数。 
5. 返回构造好的数字。 如果没有合适的$k$存在（例如，$n=1$或者$3$）， 返回$-1$。 

为什么有效：交替求和模$11$条件唯一决定了分区$3$沙$6$位置之间的 s，并将最后一位数字固定为$6$满足整除性$2$。 从左到右构建$3$s 首先保证最小值。 每个测试用例都是独立处理的，并且构建是确定性的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n == 1 or n == 3:
            print(-1)
            continue
        
        # Determine number of 6s in the middle to satisfy divisibility
        six_count = 0
        while six_count <= n and (n - six_count) % 2 != 0:
            six_count += 1
        
        if six_count > n:
            print(-1)
        else:
            threes = n - six_count - 1
            result = '3'*threes + '6'*six_count + '6'
            print(result)

solve()
```第一部分读取输入并处理边缘情况$n=1$和$n=3$。 循环计算有多少个$6$决赛前的名次$6$确保可整除$11$。 其余数字填满$3$s。 该结构通过放置来确保最小化$3$首先。 通过仔细计算最后一位数字可以避免差一的错误。

 ## 边缘情况

 对于$n=1$，算法立即输出$-1$因为一个数字$3$或者$6$不能被整除$33$或者$66$。 为了$n=3$，while循环没有找到合适的$six_count$，算法返回$-1$。 对于甚至$n$喜欢$2$,$6$可以附加到表格中$66$，满足所有条件。 对于奇数$n>3$，交替总和是通过放置适当的组合来管理的$3$沙$6$决赛前$6$，保证可分性和最小性。
