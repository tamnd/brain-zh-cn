 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，并允许执行将 2 的幂从一个元素移动到数组中后面的元素的操作。 具体来说，如果一个元素是偶数，我们可以将它除以二，然后将后面的元素乘以二。 目标是在应用任意数量的此类操作后最大化数组的总和。 不同之处在于，我们不仅需要针对单个数组进行计算，还需要针对给定数组的每个前缀进行计算，即第一个元素，然后是前两个元素，依此类推，直到整个数组。 每个输出应该是模数$10^9+7$。 

关键限制是数组长度，最大可达$2 \cdot 10^5$对于单个测试用例，所有测试用例的长度之和最多为$2 \cdot 10^5$。 这意味着任何最坏情况复杂度为$O(n^2)$会太慢。 线性或线性算术方法是必要的。 数组元素的值可以达到$10^9$，因此如果在没有模运算的情况下简单地实现操作，则必须注意整数溢出。 

一个幼稚的错误是尝试模拟每个前缀上的所有操作，选择任意偶数元素进行除法和乘法。 例如，对于前缀$[2, 3]$，粗心的算法可能会重复将 2 相除，生成多个中间数组，而最优解是将所有可整除的因子合并到最大元素以使总和最大化。 这表明暴力模拟是低效且不必要的。 

## 方法

 暴力方法会尝试每个允许的操作序列。 每次操作都会减少一个元素并增加另一个元素，从而导致组合爆炸。 对于长度前缀$k$，最多可能有$k^2$每一步的潜在操作。 即使是为了$k \sim 10^5$，这是很棘手的，因为操作序列的数量呈指数增长。 

关键的见解是将每个数字分成奇数部分和二次方因子。 任意整数$x$可以写成$x = 2^p \cdot o$， 在哪里$o$很奇怪。 这些操作允许将两个的幂从较早的元素移动到较晚的元素。 因此，最佳策略始终是将 2 的所有幂从较小的元素转移到可以吸收最大乘法效应的单个元素。 最好选择最大的元素（提取奇数部分后）作为所有累加的 2 幂的接收者，因为如果应用于最大数，则乘以 2 的幂对总和影响最大。 

通过这种观察，问题就简化为跟踪奇数部分的总和以及累加 2 的幂。 对于每个前缀，我们可以识别具有最大奇数部分的元素并将其乘以$2^{\text{total accumulated powers}}$。 那么总和就是所有奇数部分加上这个调整后的最大元素的总和。 这将问题从组合模拟转换为每个前缀的线性时间计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$每个前缀 |$O(n)$| 太慢了 |
 | 最佳 |$O(n \log a_{\max})$|$O(1)$每个前缀 | 已接受 |

 ## 算法演练

 1. 初始化两个累加器：一个用于到目前为止所见元素奇数部分的总和，另一个用于从所有元素中提取的 2 的幂的总数。 维护具有最大奇数部分的元素的索引。 
2. 逐个元素地迭代数组。 对于每个元素，将其分解为$x = 2^p \cdot o$， 在哪里$o$是奇数并且$p \ge 0$。 将奇数部分的总和增加$o$，并将幂总数增加$p$。 
3. 记录迄今为止看到的最大的奇怪部分。 这是吸收两个人所有力量的候选者。 如果当前元素的奇数部分超过之前的最大值，则更新候选索引。 
4. 要计算当前前缀的最大和，请从奇数部分的和中删除候选元素的原始奇数部分。 乘以$2^{\text{total powers}}$，然后将剩余奇数部分的总和加回去。 应用模数$10^9+7$。 
5. 将此总和附加到当前前缀的结果中。 
6. 对前缀的每个元素重复此操作。 为每个新的测试用例重置累加器。 

为什么有效：在每一步中，通过将所有可用的 2 的幂合并到具有最大基值（奇数部分）的元素中来最大化总和。 任何对较小元素的重新分配都会对总和产生较小的贡献，因为乘法对于较大的数字更有效。 不变的是，在处理任何前缀之后，以这种方式计算的总和等于通过任何允许的操作序列可获得的最大总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def process_case(a):
    prefix_sums = []
    max_odd = 0
    sum_odds = 0
    powers_total = 0
    candidate_odd = 0
    
    for x in a:
        p = 0
        while x % 2 == 0:
            x //= 2
            p += 1
        o = x
        sum_odds += o
        powers_total += p
        if o > candidate_odd:
            candidate_odd = o
        max_sum = (candidate_odd * pow(2, powers_total, MOD) - candidate_odd + sum_odds) % MOD
        prefix_sums.append(max_sum)
    
    return prefix_sums

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    result = process_case(a)
    print(*result)
```该代码将每个数字分解为其奇数部分和 2 的幂部分。 它累积奇数部分的总和以及 2 的总幂，如果看到更大的奇数部分，则更新候选元素。 当前前缀的最大总和是通过将 2 的所有幂应用于最大奇数部分、将奇数部分的剩余总和加回并应用模算术来计算的。 这保证了正确性并避免溢出。
