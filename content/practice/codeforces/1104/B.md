 ## 解决方案
 ## 问题理解

 我们得到一个由小写字母组成的字符串。 两名玩家轮流轮流，移动包括在当前字符串中挑选一对彼此相邻的相同字符并将它们全部删除。 移除后，琴弦会闭合，因此可能会形成新的相邻对并变得可以演奏。 

当玩家没有有效的相邻相等对可以移除时，游戏结束，该玩家输。 假设两名玩家都处于最佳状态，这意味着他们总是选择能够最大化获胜机会的行动。 

字符串长度最大可达 100,000。 这立即排除了任何以幼稚的方式重复模拟删除的策略，每次移动都重新扫描或复制字符串的大部分。 即使每次移动都是线性的解决方案，在最坏的情况下也会降级为二次，这太慢了。 

当存在多个不相交对时，就会出现一个微妙的问题。 一种简单的方法可能会假设删除任何对与字符串的其余部分无关，但删除可能会跨边界创建新的相邻对，从而改变可用的移动。 例如，在像这样的字符串中`"abba"`，去掉中间的`"bb"`产生`"aa"`，这会创建一个最初不存在的新动作。 任何正确的推理都必须考虑到这些连锁反应，而不是将对视为孤立的。 

另一个不明显的点是，最佳走法不是选择特定的对，而是关于当前配置中是否存在至少一个走法。 一旦我们理解了结构，我们就会发现只有可能删除的数量的奇偶性才重要，而不是它们的确切位置。 

## 方法

 直接的蛮力模拟将维护字符串，并在每一回合扫描任何相邻的相等对，将其删除，然后重复。 每次删除都可能会移动字符串的整个后缀，并且可能需要重新扫描。 在最坏的情况下，比如`"aaaaaa...."`，每次删除都会花费线性时间，并且存在线性删除，从而产生二次复杂度。 这不能超过 100,000 个字符。 

关键的观察结果是，无论策略如何，该游戏都相当于重复折叠相邻的相等对，无论它们出现在何处。 如果我们考虑使用堆栈的过程，那么每当我们看到一个等于堆栈顶部的字符时，它们就会消失。 否则我们就推动它。 这与字符串消除问题中使用的归约过程相同。 

重要的结构见解是，每个有效的移动都会以确定性的方式减少幸存的不匹配字符的数量，并且无论删除的顺序如何，最终的减少形式都是唯一的。 一旦我们计算出最终的堆栈缩减字符串，在此过程中执行的移动次数就固定了。 

由于玩家交替移动，获胜者纯粹取决于此完整减少中的移动总数是奇数还是偶数。 如果删除总数为零，则第一个玩家没有动作并立即失败。 

这将游戏转变为减少字符串长度的单遍计算。

 ## 算法演练

 1. 初始化一个空堆栈来表示字符串当前的缩减状态。 

堆栈仅保留尚未被相邻匹配取消的字符。 
2. 从左到右迭代字符串。 

在每个字符处，将其与当前堆栈顶部进行比较。 
3. 如果堆栈不为空且顶部等于当前字符，则弹出堆栈。 

这完全相当于删除一对相邻的相等字母。 
4. 否则，将当前字符压入堆栈。 

这意味着该角色当前没有立即取消的机会。 
5. 处理完整个字符串后，计算删除次数：$$\text{moves} = \frac{n - |\text{stack}|}{2}$$每次删除恰好删除两个字符。 
6. 如果`moves`奇数，第一个玩家走完最后一步并获胜。 否则，第二个玩家获胜。 

### 为什么它有效

 堆栈过程以确定性顺序模拟所有可能的相邻取消，从而产生与任何有效的合法移动序列相同的最终缩减字符串。 每一次移动都会恰好删除一个相邻的相等对，并且任何移动都不会影响当前在演变的字符串中不相邻的字符。 不变的是，在处理每个前缀之后，堆栈准确地包含该前缀在所有可能的有效删除顺序下的简化形式。 由于这种简化形式是唯一的，因此删除的总数是固定的，游戏就变成了简单的奇偶校验。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    st = []

    for c in s:
        if st and st[-1] == c:
            st.pop()
        else:
            st.append(c)

    moves = (len(s) - len(st)) // 2
    print("Yes" if moves % 2 == 1 else "No")

if __name__ == "__main__":
    solve()
```该实现使用标准堆栈模拟。 唯一的微妙之处在于每次取消恰好删除两个字符，因此移动次数是根据原始长度和最终堆栈大小之间的差值计算的。 

最终的奇偶校验对整个游戏结果进行编码。 不需要进一步模拟转弯。

 ## 边缘情况

 对于像这样的字符串`"abcde"`，堆栈从不执行弹出操作。 堆栈结束等于原始字符串，因此 move = 0 并且第一个玩家立即失败。 

为了`"aaaa"`，每一步交替压入和弹出，留下一个空堆栈。 计算出的移动次数为 2，即偶数，意味着第二个玩家获胜。 堆栈行为直接反映了两次独立的删除。 

为了`"abba"`，前两个字符取消，然后剩下的`"ba"`以相反的顺序变得相邻，导致另一次取消。 堆栈结束时为空并产生 2 步，由于奇数奇偶性正确识别先手获胜。
