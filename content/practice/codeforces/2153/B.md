 ## 解决方案
 ## 问题理解

 我们被要求确定是否可以构造三个非负整数，$a$,$b$， 和$c$，使得它们的成对按位 AND 等于三个给定的整数$x$,$y$， 和$z$。 具体来说，约束条件是$a \& b = x$,$b \& c = y$， 和$a \& c = z$。 每个测试用例都给出这三个整数，如果这些数字存在，则任务是返回“YES”，否则返回“NO”。 

输入整数$x$,$y$， 和$z$可以达到$10^9$，这意味着我们正在处理适合 30 位的数字。 测试用例数量$t$可以达到$10^4$，所以我们的解决方案必须高效地处理每个测试用例，时间大致恒定或最多对数时间是必要的。 

可能破坏简单实现的边缘情况包括位以冲突方式重叠的情况。 例如，考虑$x = 4$,$y = 8$,$z = 12$。 一种幼稚的方法可能会尝试独立构造数字而不检查按位可行性。 中的一些位$x$,$y$， 和$z$可能无法同时满足，因此算法必须一点一点地推理。 

## 方法

 蛮力方法是迭代所有三元组$a, b, c$在最大值规定的范围内$x, y, z$。 对于每个三元组，检查三个 AND 条件是否成立。 这是正确的，但完全不切实际，因为数字可能高达$10^9$，甚至尝试$2^{30}$每个变量的可能性是不可行的。 

关键的见解是 AND 运算在每个位上独立工作。 中的每一位$x, y, z$只约束相应的位$a, b, c$。 例如，如果第 2 位$x$为 1，则两者的第 2 位$a$和$b$必须为 1。如果为 0，则至少其中之一$a$或者$b$该位必须为 0。 通过一点一点的推理，我们将问题简化为检查每一位的约束是否可以同时满足。 

一旦我们将问题视为独立的位约束，我们就可以构造候选位$a, b, c$贪婪地：对于每个位位置，将 1 分配给 AND 需要的任何数字，但确保不违反其他 AND 运算。 如果任何位存在无法解决的冲突，则答案为“否”。

 | 蛮力 | O(2^30*2^30*2^30) | O(2^30*2^30*2^30) | O(1) | O(1) | 太慢了 |

 ## 算法演练

 1.读取三个整数$x, y, z$对于当前的测试用例。 
2. 迭代从 0 到 30 的每个位位置。将第 0 位视为最低有效位。 
3. 对于每个位，检查该位的值$x, y, z$。 根据这三个数字中每一个的位是 0 还是 1，有四种可能的情况。 
4. 如果任何位需要矛盾的分配——例如，$x$该位有 1（强制$a$和$b$到 1) 但是$z$有 0 个（至少需要其中之一$a$或者$c$为 0）并且我们不能同时满足两者 - 立即返回“NO”。 
5. 如果所有位都可以一致分配，则返回“YES”。 

工作原理：每个位位置都可以独立考虑，因为 AND 运算不会混合不同位置的位。 通过检查每一位的可行性并确认不存在冲突，我们保证当且仅当算法返回“YES”时才存在有效的整数分配。 这将原始组合问题简化为每个测试用例的 30 个步骤的简单检查。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x, y, z = map(int, input().split())
        possible = True
        for i in range(31):
            xi = (x >> i) & 1
            yi = (y >> i) & 1
            zi = (z >> i) & 1
            # if xi = 1, a & b = 1 -> a_i = b_i = 1
            # if yi = 1, b & c = 1 -> b_i = c_i = 1
            # if zi = 1, a & c = 1 -> a_i = c_i = 1
            # check if these force conflicts
            a = b = c = 0
            if xi: a = b = 1
            if yi: b = c = 1
            if zi: a = c = 1
            # after combining, check if constraints hold
            if (a & b) != xi or (b & c) != yi or (a & c) != zi:
                possible = False
                break
        print("YES" if possible else "NO")

solve()
```该解决方案读取测试用例的数量并独立处理每个三元组。 对于每一位，它计算所需的位$a, b, c$并验证分配是否满足所有三个 AND 条件。 分配的顺序是灵活的，因为我们可以贪婪地组合它们并检查最终结果。

 ## 边缘情况

 零输入情况 (x=y=z=0) 通过，因为算法将所有位分配为 0，满足所有 AND 运算。 最大 30 位数字案例测试是否正确处理大值的位位置。 当一个位不能同时满足多个 AND 约束时，像 x=1、y=0、z=1 这样的冲突示例会正确触发算法返回 NO。 其中每一个都直接在按位循环中处理，确认解决方案尊重所有约束，而不尝试生成实际数字。
