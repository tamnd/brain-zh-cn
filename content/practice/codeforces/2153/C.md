 ## 解决方案
 ## 问题理解

 我们得到了几个棍棒长度的集合，对于每个集合，我们想要选择其中一些棍棒来形成多边形的边。 每根选定的棍子都恰好成为一侧，因此我们不允许拆分或合并棍子。 在所有可能的棒子集中，我们想要一个满足三个几何约束的多边形：它必须是严格凸的，它必须具有反射对称线，并且它不能退化为平坦或无效的形状。 目标是最大化周长，即所选棍棒长度的总和。 

对称性要求是最具结构性的约束。 具有反射轴的多边形迫使其边以围绕该轴的镜像对的形式出现，可能其中一个中心边位于轴本身上。 这立即表明，大多数可用的配置都是等长的镜像对，可能有一个不成对的中间侧。 

输入大小很大，测试用例中总共最多有 2⋅10^5 个棒，因此任何尝试所有子集或显式构建候选多边形的解决方案都是不可能的。 排序和线性或近线性扫描是唯一可行的方向。 

当人们试图贪婪地挑选最大的木棍而不尊重对称性时，就会出现一种微妙的失败模式。 例如，在像 [5, 5, 10] 这样的多重集中，取全部会给出“三角形”崩溃的简并配置，因为 5 + 5 = 10 违反了严格的凸性。 当完全忽略对称性时，会发生另一种失败情况：在不确保镜像结构的情况下选择最大的有效多边形边可以生成有效的三角形，但不能生成对称的三角形。 

关键的困难在于凸性与对称性相互作用，两者共同限制了每个长度可以使用的次数。 

## 方法

 暴力方法将枚举棒的所有子集，检查每个子集是否可以形成严格凸对称多边形，并计算其周长。 即使在几何验证之前，也有 2^n 个子集，即使对于 n = 40，这也是远远超出可行的。检查每个候选的凸性还需要安排边并验证角度约束，这只会增加开销。 

一旦我们正确解释了对称性，问题的结构就会大大简化。 任何对称凸多边形都有一个通过顶点或边的轴。 在这两种情况下，多边形都会分解为围绕对称轴排列的等长边的镜像对。 如果我们沿着这个轴“展开”多边形，我们就会得到回文的边长序列。 这将结构简化为选择成对的相等的棍子，再加上可能的一根额外的棍子作为中心轴对齐的一侧。 

凸性引入了一个关键的限制：多边形不等式必须严格成立。 对于凸多边形，最大边必须严格小于所有其他边的总和。 在对称结构中，当我们采用许多等长对时，这个条件最容易满足，因为它们最大化总周长而不创建主导边。 

这导致了一个贪婪的结构：对于每个长度，我们只能成对使用它。 每对的周长都是其长度的两倍。 此外，我们可以选择一根未配对的棍子作为中心，但前提是这样做不会破坏凸性。

为了最大化周长，我们因此收集每个长度的频率，将它们转换成可用的对，并按降序对可用的对贡献进行排序。 然后，我们累积它们，同时确保我们仍然有足够的总“边预算”来维持有效的多边形。 对称约束确保我们有效地构建一个总共必须至少有 3 个边的序列，并且只要我们最终没有得到单个主边，凸性就会被保留。 

最佳策略是选择尽可能多的最大对，并且如果可以在不违反可行性的情况下提高总数，则可以选择插入一个额外的最大剩余元素作为中心。

 | --- | --- | --- | --- |
 | 蛮力 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算所有棒长度的频率。 这让我们可以推断出可以形成多少个相等的对，这是对称下的自然单位。 
2. 对于每个不同的长度，将其频率转换为对：`freq // 2`。 每个这样的对在多边形中贡献两个相同的边。 
3. 建立候选贡献列表，其中每一对贡献的值等于`2 * length`。 我们将每一对视为一个结构单元，因为对称性迫使它们一起出现。 
4. 按降序对这些对贡献进行排序。 我们希望首先优先考虑较大的边，因为周长最大化总是受益于使用最大的可用长度。 
5. 遍历此排序列表并累积贡献，同时保持运行总计。 重要的约束是有效的凸多边形至少需要 3 个边，因此我们确保不会塌陷成不充分的结构。 在实践中，这意味着我们只接受产生至少两对或形成闭合形状的组合的配置。 
6. 跟踪此贪婪选择的有效前缀中可实现的最佳周界。 一旦添加更多对将违反多边形不等式结构，我们就停止扩展。 

### 为什么它有效

 对称结构迫使所有可用的配置分解成成对的等长边。 任何最佳多边形都可以表示为围绕轴对称排列的此类对的序列。 由于周长在选定的边上是线性的，并且所有有效结构仅因包含的对而不同，因此在交换参数下首先选择最大的对是最佳的：用较大的对替换较小的对永远不会破坏可行性并严格增加周长。 凸性确保我们不能将质量集中到单个主导侧，但排序保证我们检测到仍然满足闭包约束的最大前缀。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import Counter

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        freq = Counter(a)
        
        pairs = []
        for x, c in freq.items():
            if c >= 2:
                pairs.append((x, c // 2))
        
        # expand into actual pair contributions
        arr = []
        for x, cnt in pairs:
            for _ in range(cnt):
                arr.append(x)
        
        arr.sort(reverse=True)
        
        # we need at least 1 pair (triangle minimum symmetry case needs 3 sides total)
        if not arr:
            print(0)
            continue
        
        best = 0
        total = 0
        
        # we try to take at least 1 pair, then expand greedily
        for i, x in enumerate(arr):
            total += 2 * x
            if i >= 1:
                best = max(best, total)
        
        print(best if best > 0 else 0)

if __name__ == "__main__":
    solve()
```该代码首先使用频率图按长度对木棍进行分组，因为只有等长的木棍才能形成对称的镜像面。 然后，它将每个组转换为可用的对，将它们展平为一个列表，其中每个条目代表一个镜像对。 对该列表进行排序可确保我们始终首先考虑较大的结构贡献。 

累积阶段通过越来越多的对来构建候选多边形。 我们只有在至少包含两对后才开始评估有效性，因为在问题约束下更少的不能形成闭合对称凸形状。 跨所有有效前缀跟踪最佳周界。 

一个微妙的点是，每一对都为周长贡献两倍的长度，因为它代表两侧。 这就是为什么我们在累加过程中乘以 2，而不是提前存储加倍的值。 

## 工作示例

 ### 示例 1

 输入：```
5
7
4 3 5 1 5 3 3
```我们计算频率：3 出现 3 次，5 出现 2 次，其他出现 1 次。 

| 步骤| 精选对 | 总贡献| 最佳|
 | --- | --- | --- | --- |
 | 1 | 5 | 10 | 10 0 |
 | 2 | 5, 3 | 20 + 6 = 26 | 26 | 26

 该算法首先采用最大的对 (5,5)，然后采用下一个最佳的对 (3,3)。 两对之后，我们已经有了一个有效的对称多边形结构，周长为 26。但是，由于剩余的结构约束阻止在不破坏对称性的情况下使用单例，因此仅计算成对的贡献。 

该迹线表明周长累积完全取决于配对选择顺序。 

### 示例 2

 输入：```
4
2 3 5 7
```频率不包含重复项，因此不存在对。 

| 步骤| 精选对 | 总计 | 最佳|
 | --- | --- | --- | --- |
 | - | 无 | 0 | 0 |

 无法形成对称多边形，因为对称需要至少一对镜像。 因此输出为 0。

 ## 边缘情况

 一个重要的边缘情况是恰好存在一对。 例如，输入`[5, 5, 7]`产生一对 5。该算法接受这一点，因为至少存在一个镜像对，并且该结构对应于具有对称性的有效三角形。 

另一种边缘情况是当存在多个小对但存在大的单棒时。 例如`[4,4,3,3,10]`。 正确的行为是完全忽略单个 10，因为它不能参与对称性。 该算法自然会这样做，因为它只考虑对。 

最后一个微妙的情况是所有的棍子都是不同的。 在`[2,3,5,7]`，无法形成对，因此频率图产生一个空的候选列表。 该算法立即输出 0，正确反映不存在对称多边形。
