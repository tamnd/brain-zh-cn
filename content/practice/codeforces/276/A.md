 ## 解决方案
 ## 问题理解

 我们得到了一份餐厅列表，其中每个餐厅都有两个值：基线享受得分和在那里吃饭所需的时间。 教练只允许固定的午餐时间。 如果餐厅能够在允许的时间内完成，团队将获得全部的享受价值。 如果餐厅的用餐时间超过了允许的时间，那么享受的乐趣就会减少，而超出限制的额外时间就会减少。 

任务是在应用此规则后以最大限度地提高享受的方式准确选择一家餐厅。 

输入大小达到一万家餐厅，这意味着独立地重新计算每个餐厅的复杂逻辑的解决方案仍然是可以接受的，但是任何在大型数据结构上进行嵌套处理的二次方都将是不必要的开销。 在这些限制下，单次传递数据很容易足够快，因为我们只评估每个餐厅的一个简单公式。 

有一种微妙的情况经常会导致错误。 当餐厅花费的时间少于或等于允许的时间时，答案就是基本的享受。 当超过时间限制时，我们必须只减去超出的部分，而不是全部时间。 例如，如果限制为 5，则享受时间为 10 且时间为 8 的餐厅将产生 10 − (8 − 5) = 7。一个常见的错误是减去完整时间而不是仅减去溢出时间，这会错误地得出 2。 

当所有餐馆都超过时间限制并且基值较小时，就会出现另一种边缘情况。 修正后的公式可能会产生负结果，正确答案也可能是否定的。 这意味着我们不能默认为零或假设非负结果。 

## 方法

 一种直接的方法是使用给定的规则独立计算每个餐厅的享受并跟踪最大值。 对于每家餐厅，我们都会检查其时间是否在允许的限制内。 如果是，我们取基值； 否则我们减去多余的时间。 这使得每家餐厅的工作量是恒定的。 

这是可行的，因为该问题不会引入餐馆之间的依赖关系。 每个选项都是单独评估的，因此不需要排序、动态编程或前缀处理。 唯一的要求是扫描所有候选人并计算他们的调整值。 

天真的解释可能建议以更复杂的方式分别处理不同的情况，但没有允许重用中间结果的结构。 每个餐厅必须至少评估一次，因此最优解已经是线性的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.初始化一个变量来存储迄今为止看到的最好的享受，从一个很小的数字开始。 这确保了即使是负面结果也能得到正确处理。 
2. 逐一迭代每个餐厅。 
3. 对于每家餐厅，计算其有效享受。 如果其时间小于或等于允许的限制，则直接使用其基本享受。 否则减去溢出`(t_i - k)`从它的基值。 这直接符合问题的规律。 
4. 将此计算值与当前最佳值进行比较，如果新值较大，则更新最佳值。 
5.处理完所有餐厅后，输出找到的最佳值。 

### 为什么它有效

 每家餐厅恰好贡献一个候选值，该值仅取决于其自身的参数和全局常数`k`。 由于选择之间没有相互作用，因此最佳解决方案必须是所有单独计算的调整值的最大值。 该算法保持了这样的不变性：在处理完第i个餐厅之后，存储的最佳值等于前i个餐厅中的最大调整享受。 这个不变量保证了正确性，因为它是通过在每一步将当前候选者与存储的最大值进行比较来保留的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    best = -10**18

    for _ in range(n):
        f, t = map(int, input().split())
        if t <= k:
            val = f
        else:
            val = f - (t - k)
        if val > best:
            best = val

    print(best)

if __name__ == "__main__":
    solve()
```实现直接遵循算法。 关键细节是使用非常小的初始值`best`，因为有效答案可能是否定的，我们不能限制结果。 每次迭代都严格按照定义计算调整后的享受，并根据时间是否超过限制进行条件分割。 

减法的结构被精心设计为`f - (t - k)`而不是`f - t + k`只是为了清楚起见，尽管两者是等效的。 这减少了实施过程中出现符号错误的机会。

 ## 边缘情况

 当所有餐厅都超过时间限制时，该算法仍然有效，因为它会计算每个选项的减少值并直接进行比较。 例如，与`k = 5`和一家餐厅`(f=10, t=10)`，该值变为`10 - 5 = 5`。 此类转换值的最大值仍然是正确选择的。 

当某些调整值变为负数时，初始化`best`由于数量非常少，因此仍会考虑这些问题。 例如，输入：```
2 3
1 10
2 10
```计算值是`1 - 7 = -6`和`2 - 7 = -5`。 算法正确返回`-5`，因为它甚至跟踪负数中的最大值。
