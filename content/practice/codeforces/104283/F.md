 ## 解决方案
 ## 问题理解

 在每个测试用例中，我们给出三个整数，描述一个基数和两个指数参数。 要计算的表达式是两个数字的最大公约数，这两个数字都是同底的幂，其中指数是阶乘。 具体来说，我们比较$n^{a!}$和$n^{b!}$，取其 GCD，并输出结果模$10^9+7$。 

表达式的结构比数字的原始大小更重要。 即使对于中等值$a$和$b$，阶乘爆炸得非常快，因此指数本身非常大。 这立即排除了任何显式计算的尝试$a!$或者$b!$作为整数，因为即使$20!$已经超出了典型的 64 位限制。 

输入约束意味着多个测试用例，其值足够大，以至于朴素的阶乘计算或直接求幂无法及时适应。 任何尝试显式构建的方法$n^{a!}$这是不可能的，因为即使在处理阶乘增长之前，仅求幂就已经太慢了。 

有一些在结构上很重要的边缘情况。 

什么时候$n = 0$，只要指数为正，两个数字都为零。 由于有效输入的阶乘始终至少为 1 ($0! = 1$），这两项都是$0^{\text{positive}}$，其计算结果为零。 零和零的 GCD 为零。 

什么时候$n = 1$，无论指数大小如何，两个数字始终为一。 结果总是一。 

当有人尝试直接计算阶乘模时，会出现微妙的失败情况$10^9+7$。 这会丢失信息，因为指数减少必须以模数完成$10^9+6$， 不是$10^9+7$，根据费马定理。 使用错误的模数会产生完全错误的幂。 

另一种故障模式来自于假设$\gcd(n^x, n^y) = n^{\gcd(x,y)}$。 这是不正确的； 正确的简化使用最小指数，而不是指数的 GCD。 

## 方法

 直接解释计算$a!$和$b!$，然后评估$n^{a!}$和$n^{b!}$，最后计算他们的 GCD。 这在数学上是正确的，但完全不可行。 即使计算阶乘值也会很快溢出，并且在时间限制内不可能用这样的指数求幂。 

关键的观察结果是两个数字具有相同的基数$n$。 对于任何非零$n$，同底的幂满足一个简单的性质：两个幂的 GCD 是较小指数的幂。 这将整个问题简化为了解哪个阶乘更小。 由于阶乘对于非负整数严格递增，因此比较$a!$和$b!$相当于比较$a$和$b$。 因此，最终答案的指数为$\min(a, b)!$。 

剩下的挑战是，即使$(\min(a,b))!$仍然是巨大的。 我们只需要指数模$10^9+6$，因为模数$10^9+7$是素数并且允许通过费马定理进行指数约简$n \not\equiv 0 \pmod{10^9+7}$。 

因此，问题简化为计算指数的模阶乘，然后执行单个模幂。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数/不可能 | O(1) | O(1) | 太慢了 |
 | 最佳| 每个测试用例 O(max(a, b)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将问题重写为计算模幂$n$，其中指数取决于较小的阶乘。 

### 步骤

 1. 阅读$a, b, n$并确定$k = \min(a, b)$。 

这是有效的，因为阶乘严格保留排序，因此较小的基数会产生较小的阶乘。 
2. 立即处理琐碎的事情。 

如果$n = 0$，两个数都为零，因此 GCD 为零。 

如果$n = 1$，任何幂都保持为一，所以答案是一。 
3. 计算$k!$但仅取模$10^9+6$, 不是模数$10^9+7$。 

这是必需的，因为素数模下的求幂允许减少指数模$\varphi(M)$。 
4. 计算$e = k! \bmod (10^9+6)$。 

我们迭代地执行此操作，在每一步中进行乘法和减法。 
5. 计算最终结果为$n^e \bmod (10^9+7)$使用快速求幂。 

### 为什么它有效

 表达式$\gcd(n^{a!}, n^{b!})$简化是因为两个数字都是相同底数的幂。 任何公共幂都必须受到较小指数的限制，因为减小指数是使一种幂除另一种幂的唯一方法。 这给出了$n^{\min(a!, b!)}$。 阶乘函数在整数上严格递增，所以$\min(a!, b!) = (\min(a,b))!$。 指数的模约化是有效的，因为素数模下的求幂仅取决于指数模$10^9+6$，前提是底数不能被模数整除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
PHI = MOD - 1

def modexp(a, e):
    res = 1
    a %= MOD
    while e > 0:
        if e & 1:
            res = (res * a) % MOD
        a = (a * a) % MOD
        e >>= 1
    return res

t = int(input())
for _ in range(t):
    a, b, n = map(int, input().split())
    
    k = min(a, b)
    
    if n == 0:
        print(0)
        continue
    if n == 1:
        print(1)
        continue
    
    fact = 1
    for i in range(1, k + 1):
        fact = (fact * i) % PHI
    
    print(modexp(n, fact))
```该代码首先将问题的结构简化为计算单个指数。 阶乘是根据模计算的$10^9+6$，这很重要，因为使用$10^9+7$会错误地扭曲指数算术。 模幂例程是标准的二进制幂运算，并确保指数的对数时间。 

特殊情况为$n = 0$和$n = 1$防止未定义的行为和不必要的计算。 尤其，$0^e$正数始终为零$e$，阶乘保证正值。

 ## 边缘情况

 当$n = 0$，无论指数大小如何，两个幂都会崩溃为零。 该算法在任何阶乘计算之前显式检查这一点，因此避免了不必要的工作并正确返回零。 

什么时候$n = 1$，指数大小变得无关紧要，因为所有幂都等于一。 提前返回可以防止阶乘计算并确保即使对于大型计算也能保证正确性$a, b$。 

什么时候$a = b$，算法正确地将两个表达式降低到相同的幂，因此 GCD 等于值本身。 阶乘计算仍然运行，但不会影响正确性，因为两条路径都会收敛。 

什么时候$a$或者$b$为零，$0! = 1$，因此指数始终至少为一。 该算法自然地处理这个问题，因为阶乘从 1 开始并且永远不会产生零。
