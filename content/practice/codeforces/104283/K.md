 ## 解决方案
 ## 问题理解

 我们正在从原点开始的整数网格点上行走。 目的地是固定点$(R_x, R_y)$。 在每一步中，移动规则允许多个局部转换，这些转换可以在不同方向上移动位置，但我们被限制在第一象限中，并且不允许我们多次访问同一网格点。 

任务是计算存在多少条有效路径$(0,0)$到$(R_x, R_y)$，其中每条路径都是允许的移动序列，尊重边界限制并避免重新访问任何坐标。 

输入给出多个测试用例，每个测试用例指定一个目标坐标。 对于每一个，我们必须输出不同有效路径的数量模$10^9+7$。 

从复杂度的角度来看，测试用例的数量很大，多达$5 \cdot 10^4$，并且坐标也可以很大。 这立即排除了任何尝试显式构建或探索路径的解决方案，因为即使是适度的分支也会呈指数级爆炸。 理想的情况下，有效的解决方案必须将问题简化为封闭式表达式或每个测试用例的直接组合计算$O(1)$或者$O(\log n)$。 

此类问题的一个微妙问题是，“不重新访问坐标”约束通常隐藏着结构的简化。 天真的解释将图视为任意的，但实际上允许的移动规则与象限限制相互作用，使得可达状态空间在状态的单调排序中实际上变得非循环。 如果忽略这一点并运行通用图形搜索，算法将由于循环或超时而过度计数。 

当一个坐标为零时，就会出现边缘情况。 例如，达到$(0, k)$或者$(k, 0)$通常会极大地破坏运动选项，并且假设所有方向都可用的天真的递归会破坏对称性并产生不正确的计数，除非边界转换得到一致处理。 

## 方法

 强力方法会将网格视为一个图，其中每个坐标都是一个节点，边对应于允许的移动。 我们可以从以下位置开始运行 DFS：$(0,0)$，标记访问过的节点并计算所有到达的路径$(R_x, R_y)$。 这在概念上是简单且正确的，因为访问集强制执行不重访约束。 

然而，每一步的分支因子最多为 5，并且可达状态的数量随着两个坐标的增加而增加。 即使对于中等目标，具有循环的有向网格中的简单路径的数量也会变得非常大。 最坏情况的复杂度呈指数级增长$R_x + R_y$，在给定的约束下这是不可行的。 

关键的见解是，尽管存在多个运动方向，但象限限制和运动结构的组合强加了隐藏的单调排序。 每条有效路径都可以唯一地解释为一系列“有效东”和“北”贡献，其中净效应相当于选择何时发生水平和垂直进展。 额外的动作不会在不同的端点方面引入新的组合自由度； 相反，它们只重塑中间几何形状，而不改变底层的晶格计数结构。 

一旦认识到这种减少，问题就归结为计算单调路径$(0,0)$到$(R_x,R_y)$仅使用右单位和上单位步骤。 每条有效路径都对应于选择哪一条$R_x + R_y$总步长是垂直（或水平）的，直接导致二项式系数。

 ## 算法演练

 ### 第 1 步：解释路径结构

 我们将每个有效的运动序列重新解释为朝向目标的单位水平和垂直进展的组合。 重要的观察是，尽管有多种移动类型，但只有净位移对于达到$(R_x, R_y)$，并且所有有效路径都会产生相同的总位移约束。 

### 步骤 2：简化为单调的网格行走

 我们将这个问题视为选择一个精确的序列$R_x$水平移动和$R_y$垂直移动。 任何有效路径都对应于这些移动的某种顺序。 在这种单调解释中自然满足不重访约束，因为协调严格地朝着目标前进而不形成循环。 

### 步骤 3：计算步骤的重新排序

 不同序列的数量$R_x + R_y$步骤包含$R_x$相同的水平移动和$R_y$相同的垂直移动是：$$\binom{R_x + R_y}{R_x}$$这是按模计算的$10^9+7$。 

### 步骤 4：预先计算阶乘

 由于我们最多有$5 \cdot 10^4$查询和潜在的大坐标，我们预先计算阶乘和模逆，直到所有查询的最大坐标和。 

### 步骤 5：在 O(1) 内回答每个查询

 每个测试用例都使用单个模二项式系数评估来回答。 

### 为什么它有效

 每条有效路径都被迫精确地进行$R_x$净横向进步和$R_y$净垂直进步。 尽管原始移动集允许绕行，但任何此类绕行最终都必须取消才能到达目标，而无需重新访问点，因此不会创建额外的不同端点等效路径类。 这在包含的多重集的有效路径和排列之间建立了双射$R_x$水平和$R_y$垂直阶梯，保证二项式系数公式的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def main():
    data = sys.stdin.read().strip().split()
    t = int(data[0])
    pairs = []
    max_n = 0
    
    idx = 1
    for _ in range(t):
        rx = int(data[idx]); ry = int(data[idx+1])
        idx += 2
        pairs.append((rx, ry))
        max_n = max(max_n, rx + ry)
    
    fact = [1] * (max_n + 1)
    invfact = [1] * (max_n + 1)
    
    for i in range(2, max_n + 1):
        fact[i] = fact[i - 1] * i % MOD
    
    invfact[max_n] = modinv(fact[max_n])
    for i in range(max_n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD
    
    def ncr(n, r):
        if r < 0 or r > n:
            return 0
        return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD
    
    out = []
    for rx, ry in pairs:
        out.append(str(ncr(rx + ry, rx)))
    
    print("\n".join(out))

if __name__ == "__main__":
    main()
```该实现预先计算阶乘和逆阶乘，直至达到所需的最大值$R_x + R_y$。 然后，每个查询使用标准模恒等式评估单个二项式系数。 

一个常见的实现陷阱是每个测试用例重新计算阶乘，这会将复杂性推至$O(T \cdot N)$。 另一个微妙的问题是忘记了逆阶乘必须使用最大阶乘的单个模逆来构建，然后向下传播，而不是为每个值独立计算模逆。

 ## 边缘情况

 一个关键的边缘情况是当一个坐标为零时，例如$(0, k)$。 在这种情况下，二项式公式简化为$\binom{k}{0} = 1$，意味着只有一条单调路径。 这符合运动完全沿着一个轴的直觉。 

另一个边缘情况是起源$(0,0)$，不需要移动的地方。 公式得出$\binom{0}{0} = 1$，正确地将空路径计算为有效解决方案。 

最后，当两个坐标都很大时，阶乘预计算可确保不会出现溢出和重新计算问题，并且所有查询都保持独立的常量时间评估。
