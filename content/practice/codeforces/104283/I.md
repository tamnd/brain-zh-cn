 ## 解决方案
 ## 问题理解

 我们有两个整数，$A$和$B$，以及两个目标余数$m_1$和$m_2$。 任务是找到最小的正整数$X$这样当$A$除以$X$，余数正好是$m_1$，以及当$B$除以$X$，余数正好是$m_2$。 

换句话说，我们想要一个模数$X$同时从两个固定数字产生两个固定残基。 对余数的约束意味着两个整除条件：$A - m_1$必须能整除$X$， 和$B - m_2$也必须能被整除$X$。 此外，余数定义强制$m_1 < X$和$m_2 < X$，否则余数无效。 

输入大小可达$5 \cdot 10^8$对于值，因此任何迭代到的方法$A$或者$B$直接是不可能的。 甚至扫描所有除数$10^9$在最坏的情况下速度太慢。 我们需要一种基于对数或平方根的除数推理方法。 

出现微妙的边缘情况时，$A = m_1$或者$B = m_2$。 在这种情况下，相应的差异变为零。 例如，如果$A = 10$和$m_1 = 10$， 然后$A \bmod X = 10$对于任何有效的$X > 10$，因为余数总是严格小于除数。 这立即使问题变得不可满足。 仅检查差异的整除性的粗心实现会错误地将零视为与所有兼容$X$。 

另一种边缘情况是所需的余数与大小限制发生冲突。 如果$m_1 \ge X$或者$m_2 \ge X$，即使整除条件成立，模数也是无效的。 

## 方法

 蛮力策略考验每一位候选人$X$从 1 到$\max(A, B)$，检查两个余数条件是否成立。 对于每个$X$，我们计算$A \bmod X$和$B \bmod X$在常数时间内，所以总复杂度是$O(\max(A, B))$。 值高达$5 \cdot 10^8$，这种方法每个测试用例执行数亿次操作，这远远超出了时间限制。 

关键的观察是余数条件可以重写为整除形式。 从$A \bmod X = m_1$，我们得到$A - m_1 = kX$对于某个整数$k$。 相似地，$B - m_2 = tX$。 这意味着$X$必须将两者分开$A - m_1$和$B - m_2$。 所以$X$必须是这两个数的公约数。 

此时问题就简化为同时求两个整数的除数，我们立即想到最大公约数。 任何有效的$X$必须划分$g = \gcd(A - m_1, B - m_2)$。 所以候选人$X$正好是$g$，附加约束条件是$X > m_1$和$X > m_2$。 

而不是迭代到$A$，我们只迭代除数$g$，这可以在$O(\sqrt{g})$。 在这些有效除数中，我们选择满足余数界限的最小除数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(\max(A,B))$|$O(1)$| 太慢了 |
 | GCD + 除数 |$O(\sqrt{g})$|$O(1)$| 已接受 |

 ## 算法演练

 1. 计算$x = A - m_1$和$y = B - m_2$。 如果其中之一$x < 0$或者$y < 0$，不存在解。 这是因为余数不能超过原始数。 
2. 计算$g = \gcd(x, y)$。 任何有效的$X$必须将两者分开$x$和$y$，因此必须除以$g$。 
3. 枚举所有的约数$g$。 对于每个除数$d$，我们检查它是否可以作为有效模数。 
4. 对于每个候选除数$d$，验证$d > m_1$和$d > m_2$。 这确保了余数定义对于两个数字都有效。 
5. 在所有有效除数中，选择最小的一个。 如果没有除数满足约束，则返回$-1$。 

### 为什么它有效

 转变$A \bmod X = m_1 \Rightarrow X \mid (A - m_1)$类似地对于$B$完全用可分性来表征问题。 由于除两个差值的任何数字都必须除以它们的 gcd，因此我们不会因为将自己限制为以下的约数而失去任何候选人$g$。 其余约束仅进一步过滤这些候选者。 因为我们枚举了所有的约数$g$，我们保证如果有效$X$存在，它将出现在搜索空间中，选择最小的有效答案给出正确答案。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def solve():
    A, B, m1, m2 = map(int, input().split())

    x = A - m1
    y = B - m2

    if x < 0 or y < 0:
        print(-1)
        return

    g = math.gcd(x, y)

    ans = None

    d = 1
    while d * d <= g:
        if g % d == 0:
            d1 = d
            d2 = g // d

            if d1 > m1 and d1 > m2:
                if ans is None or d1 < ans:
                    ans = d1

            if d2 > m1 and d2 > m2:
                if ans is None or d2 < ans:
                    ans = d2

        d += 1

    print(ans if ans is not None else -1)

if __name__ == "__main__":
    solve()
```解决方案首先将余数条件转换为差分形式。 早期可行性检查确保我们不会继续进行无效的负差异。 

gcd 步骤是结构简化：它将问题从两个约束折叠到单个除数空间中。 除数枚举循环有效地检查所有候选者，直到平方根$g$，将每个除数与其补数配对。 

一个常见的实施陷阱是忘记检查两者$d$和$g/d$。 当最优解是较大因子时，缺少补除数会导致错误答案。 

另一个微妙之处是严格将比较处理为$>$， 不是$\ge$，因为余数必须严格小于除数。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    A, B, m1, m2 = map(int, sys.stdin.readline().split())

 ## 边缘情况

 一种重要的边缘情况发生在以下情况：$A = m_1$或者$B = m_2$。 例如，如果$A = 10$和$m_1 = 10$， 然后$x = 0$。 任何有效的模数都需要$10 \bmod X = 10$，这是不可能的，因为余数必须严格小于$X$。 该算法立即检测到$x < 0$无效，但即使我们放松了检查，$x = 0$会导致$g = y$，我们会错误地考虑除数$y$。 严格不等式条件$X > m_1$防止此类误报。 

另一种边缘情况是 gcd 为 1 时。在这种情况下，唯一的候选者是$X = 1$，但这永远不能满足任何正余数要求，除非两个余数都为零。 除数枚举正确地处理了这个问题，因为它在接受候选之前仍然检查不等式约束。
