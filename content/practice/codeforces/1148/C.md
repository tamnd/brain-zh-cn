 ## 解决方案
 ## 问题理解

 我们得到了从 1 到 1 的数字排列$n$， 在哪里$n$保证是均匀的。 排列意味着每个数字在数组中只出现一次。 任务是按升序对这个排列进行排序。 但是，允许的交换有一个限制：您只能交换位置处的元素$i$和$j$如果它们之间的距离至少为$n/2$， 具体来说$2 \cdot |i-j| \ge n$。 

输入给出$n$和排列$p$，并且输出必须列出您为对数组进行排序而执行的交换序列。 无需最小化交换次数，但不能超过$5n$互换。 

因为$n$可以达到$3 \cdot 10^5$，任何慢于的算法$O(n \log n)$可能会超时。 简单的冒泡排序风格的蛮力需要$O(n^2)$互换，这是不可行的。 粗心的方法可能会尝试贪婪地交换元素而不考虑距离限制。 例如，与$n = 6$和$p = [6, 1, 3, 2, 4, 5]$，如果您尝试将 6 交换到第一个位置而不使用中间交换，您可能会尝试交换索引 1 和 2，这违反了距离约束。 

边缘情况包括已经就位但远离其“合法交换”伙伴的元素，或靠近数组中间但无法与任一端直接交换的元素。 小输入，例如$n = 2$是微不足道的，但仍然必须遵守距离规则。 

## 方法

 暴力方法是重复检查每个位置$i$并交换$p[i]$在允许的情况下使用其正确的值。 这在概念上是有效的，因为最终，所有元素都可以移动，但距离限制使这种方法变得混乱并且可能效率低下，需要最多$O(n^2)$运营。 

关键的观察结果是距离约束允许在阵列的前半部分和后半部分之间自由交换。 左半部分中的任何元素都可以与右半部分中的任何元素交换，因为$|i-j| \ge n/2$。 这一观察结果使我们能够将所有移动减少到每个元素最多三次交换：将元素移动到最近的一端（如果尚未位于正确的一半中），然后在必要时将其与另一半中的正确位置交换。 

需要在同一半内移动的元素需要绕道另一半。 例如，要交换 6 元素数组中位置 2 和 3 的元素，可以将 2 移动到最后一个位置，将 3 移动到第一个位置，然后通过两端交换。 这个技巧保证每个元素最多可以使用固定次数的交换到达其正确位置，保持在$5n$限制。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.首先将每个元素的当前位置存储在数组中`pos`这样`pos[x]`给出当前的价值指数`x`。 这使我们能够知道每个元素在哪里$O(1)$。 
2. 迭代每个位置$i$从 1 到$n$。 如果`p[i]`已经等于$i$， 继续。 否则，我们需要将正确的值移动到位置$i$。 
3. 识别当前索引`j`的价值$i$使用`pos[i]`。 如果$|i-j| \ge n/2$， 交换`p[i]`和`p[j]`直接地。 记录交换。 
4. 如果$i$和`j`都在上半场，移动`j`到数组末尾，然后交换`i`（或者使用中间交换序列，如果`i`也接近尾声了）。 
5. 同样，如果$i$和`j`都在下半场，移动`j`到数组的开头并继续。 
6. 每次交换后，更新`pos`数组来反映新的位置。 重复此操作，直到排列排序完毕。 

这种方法保证每个元素最多使用恒定数量的交换到达其正确位置。 两半之间的交换始终满足距离条件。 同一半内的掉期被分解为两个或三个合法的掉期，使用另一半作为临时占位符。 

**为什么有效：** 不变的是，每次交换后，至少有一个元素移动到其正确的一半或正确的位置，并且没有交换违反距离约束。 绕行另一半可确保卡在一半内的元素始终能够到达另一半。 最终，所有元素都到达正确的位置，但不会超过$5n$互换。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
p = list(map(int, input().split()))
p = [0] + p  # 1-indexed
pos = [0] * (n + 1)
for i in range(1, n + 1):
    pos[p[i]] = i

swaps = []

def do_swap(i, j):
    p[i], p[j] = p[j], p[i]
    pos[p[i]] = i
    pos[p[j]] = j
    swaps.append((i, j))

for i in range(1, n + 1):
    while p[i] != i:
        j = pos[i]
        if abs(i - j) >= n // 2:
            do_swap(i, j)
        else:
            if i <= n // 2 and j <= n // 2:
                do_swap(j, n)
                do_swap(i, n)
            elif i > n // 2 and j > n // 2:
                do_swap(j, 1)
                do_swap(i, 1)
            else:
                if i <= n // 2:
                    do_swap(j, 1)
                    do_swap(1, n)
                    do_swap(i, n)
                else:
                    do_swap(j, n)
                    do_swap(1, n)
                    do_swap(i, 1)

print(len(swaps))
for a, b in swaps:
    print(a, b)
```此代码使用以下方式跟踪元素位置`pos`数组来有效地找到每个数字的位置。 这`do_swap`函数更新排列和位置。 每个条件处理不同的相对位置`i`和`j`确保所有交换都满足距离规则。
