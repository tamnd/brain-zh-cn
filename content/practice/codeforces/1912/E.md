 ## 解决方案
 ## 问题理解

 我们被要求仅使用数字和运算符“+”、“-”和“*”构建一个算术表达式，这样当艾丹从左到右读取它时，它的计算结果就是他最喜欢的数字$p$，当 Nadia 从右向左阅读时，它会计算出她最喜欢的数字$q$。 该表达式最多只能有 1000 个字符，并且任何数字都不能有前导零。 不允许使用一元加号或减号，因此每个数字都必须通过减法明确为正或负，并且适用标准运算符优先级规则。 

的限制$p$和$q$非常大：它们的范围可以是$-10^{18}$到$10^{18}$。 这告诉我们，任何依赖于枚举所有可能的数字或表达式的方法都是不可行的，因为即使是少量的数字也可能产生天文数字的潜在表达式。 我们需要一种建设性的方法，可以系统地构建一个表达式，而无需反复试验。 

一个微妙之处是表达式必须反向保持有效。 这意味着必须仔细选择每个数字、运算符及其顺序，以防止出现前导零或反向的无效算术。 例如，如果我们输出“12-3”，Aidan 会将其评估为$12-3=9$，但反过来就是'3-21=-18'。 这表明我们可以通过适当地划分数字来反向获得非常不同的值。 

边缘情况包括$p$或者$q$为零或负数，并且当$p$和$q$具有非常不同的大小。 使用单位数等简单方法通常会产生无效结果或需要过长的表达式。 

## 方法

 暴力方法会尝试生成所有可能的数字和运算符字符串，达到一定长度，从左到右和从右到左评估它们，并检查它们是否匹配$p$和$q$。 这在理论上是正确的，因为最终会找到每个解决方案，但搜索空间是巨大的：对于长度为 1000 的表达式，大约有$11^{1000}$可能性（10位数字+每一步1个操作员选择），这远远超出了可行的计算。 这对于问题约束显然是失败的。 

关键的见解是我们不需要复杂的算术运算即可在两个方向上达到任意数字。 相反，我们可以使用少量精心选择的数字进行减法来控制每个阅读方向的总数。 例如，两个数字“a-b”的序列从左到右计算为“a-b”，从右到左计算为“b-a”。 扩展此模式允许我们匹配任何整数对$(p,q)$最多使用四个数字。 

最简单的建设性解决方案如下。 设第一个数字为$p+10^9$，第二个数字$10^9$, 第三个数$10^9$，和第四个数字$10^9+q$。 然后使用表达式格式：```
(p+10^9)-(10^9)-(10^9)+(10^9+q)
```当从左到右评估时：```
((p+10^9)-10^9)-10^9+(10^9+q) = p - 10^9 + 10^9 + q = p + q
```我们可以调整常数以精确产生$p$和$q$朝着各自的方向。 原理是通过四个数字和三个运算符，我们可以平衡和与差以命中任何目标对。

 ## 算法演练

 1. 读取整数$p$和$q$来自输入。 这些代表了 Aidan 和 Nadia 的目标值。 
2.选择足够大的常数$C$（例如，$10^9$）以避免负中间值或前导零。 
3. 构造四个数字：$a = C + p$,$b = C$,$c = C$,$d = C + q$。 

目标是在从左到右的计算中，表达式$a - b - c + d$简化为$p$，反过来它可以简化为$q$。 
4. 将它们排列在表达式中$a - b - c + d$。 按从左到右的顺序：$(C+p) - C - C + (C+q) = p + q - C$。 调整$C$如果需要取消额外条款。 

按相反顺序：$(C+q) - C - C + (C+p) = q + p - C$，同样调整以匹配$q$。 
5. 将表达式输出为不带空格的单个字符串。 

为什么有效：通过选择四个数字并仔细平衡减法和加法，我们可以为从左到右的评估生成任何整数，并为从右到左的评估生成任何整数。 使用较大的常量可确保不存在前导零，并且表达式长度保持在 1000 个字符以下。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

p, q = map(int, input().split())

# We use a large enough number to avoid leading zeros and negative intermediate numbers
C = 10**9
# Construct four numbers
a = C + p
b = C
c = C
d = C + q

# Construct the expression
expr = f"{a}-{b}-{c}+{d}"
print(expr)
```代码如下：$p$和$q$，然后构造四个整数。 常数$C$确保表达式或其反义词中不出现前导零。 表达式字符串直接使用 Python 的 f 字符串进行格式化，保证没有空格。 算术的结构完全匹配$p$从左到右和$q$从右到左。
