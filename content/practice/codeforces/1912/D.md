 ## 解决方案
 ## 问题理解

 我们得到一个带有基数的数字系统$b$，我们想检查可被模数整除$n$仅对数字使用本地运算。 一个数字写在基数中$b$，并且我们可以用由其数字构建的结构化表达式替换完整值。 表达式必须始终保留模值$n$，这样检查整除性就简化为检查简化的基于数字的形式。 

我们可以使用三种类型的结构，所有这些都适用于按大小块分组的数字$k$（解释为基数$b$）。 

在第一种类型中，我们忽略除最后一个之外的所有内容$k$数字。 仅当所有高位数字的贡献始终是以下数字的倍数时，此方法才有效$n$，无论其值如何。 

在第二种类型中，我们将数字分成连续的块$k$数字并对这些块求和。 

在第三种类型中，我们在这些块之间交替使用符号。 

每个块都被视为基础$b$整数，因此移位$k$数字对应于乘以$b^k$。 因此，真正的限制是权力是否$b^k$模数表现得很好$n$。 

输入由许多对组成$(b, n)$。 对于每一对，我们必须找到最小的$k$使得这些结构中的至少一个正确地保留了模值$n$。 如果不存在，我们输出零。 

约束条件意味着最多$10^6$所有测试的总计，所以$O(\sqrt{n})$或更好的每个测试方法是必要的。 任何涉及因式分解或模拟数字扩展至$n$每个测试总的来说太慢了。 

一个微妙的失败案例来自于假设所有模数都始终存在块方法。 例如，$b = 10, n = 6$看起来与熟悉的整除规则类似，但允许的线性数字结构都不符合模 6 约束，因此答案为零。 一种幼稚的方法，只检查小的$k$如果不了解结构条件，可能会错误地得出某些分组有效的结论。 

## 方法

 核心观察是，所有三种构造都对应于将数字表示为基数中的多项式$b^k$。 如果我们将数字分组为大小的块$k$，任何数字都变成$$x = x_0 + x_1 b^k + x_2 b^{2k} + \dots$$其中每个$x_i$是一个块值。 

每个整除规则都是一种替换权力的方式$b^k$与简单常数$\mathbb{Z}_n$:

 对于第 1 种，我们实际上需要$b^k \equiv 0 \pmod n$。 这确保了更高的块完全消失。 

对于第 2 类，我们需要$b^k \equiv 1 \pmod n$，因为所有块的贡献相等，并且求和保留原始值模$n$。 

对于第 3 类，我们需要$b^k \equiv -1 \pmod n$，因此交替的符号可以正确取消连续的幂。 

因此任务简化为寻找最小的$k$这样$b^k \equiv 0, 1,$或者$-1 \pmod n$，并选择其中最小的有效值。 

蛮力方法尝试了所有方法$k$从1向上，计算$b^k \bmod n$。 这是正确的，但在最坏的情况下太慢了，因为$k$可能会达到$n$，并且每次计算是$O(1)$, 给予$O(n)$每次测试。 

关键的见解是我们只需要找到类似乘法顺序的行为$b \bmod n$，这可以通过迭代幂直到我们达到 0 或循环来完成，但是因为$n$跨测试可能很大，我们反而跟踪功率直到重复或直到达到所需的残基，这总是发生在$O(n)$由于模块化动力学，所有测试的总计。 

一个更结构化的观点是，我们正在走在乘法幺半群模中$n$，一旦达到三个目标状态之一，我们就会停止。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力力量 |$O(n)$每次测试|$O(1)$| 太慢了 |
 | 增量功率跟踪|$O(n)$总摊销|$O(1)$| 已接受 |

 ## 算法演练

 我们迭代的权力$b$模数$n$，但不是从头开始重新计算$k$，我们维持当前的功率$p = b^k \bmod n$。 

1. 初始化$p = 1$。 这代表$b^0$，空移。 
2. 对于每个$k \ge 1$， 更新$p = (p \cdot b) \bmod n$。 这给出了$b^k \bmod n$。 
3.如果$p = 0$，我们可以立即使用种类 1$k$，因为所有更高的块都消失模$n$。 
4. 如果$p = 1$，我们可以使用种类 2$k$，因为块移位准确地保留了贡献。 
5. 如果$p = n-1$（这代表$-1 \bmod n$），我们可以使用种类 3$k$，因为交替符号正确地取消了幂。 
6. 我们停在最小的地方$k$触发任何这些条件。 
7. 如果我们在没有找到任何条件的情况下达到安全上限，我们就得出结论不存在规则。 

停止条件有效，因为一旦$p$进入一个循环，它永远不会遇到新的残基，因此继续继续不能产生更小的有效值$k$。 

### 为什么它有效

 每个分组规则对应于在权力上强制执行一个简单的身份$b^k$模数$n$。 第一类强制所有更高的力量消失，这正是$b^k \equiv 0$。 类型 2 要求所有移位块做出相同的贡献，即$b^k \equiv 1$。 种类3需要交替取消，即$b^k \equiv -1$。 该算法按升序枚举幂，因此这些代数恒等式第一次成立时，它必须对应于最小的有效组大小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        b, n = map(int, input().split())

        # special quick rejection
        # we search powers of b mod n
        p = 1

        # we will cap iterations at n steps; cycle must appear before that
        ans = 10**18

        for k in range(1, n + 1):
            p = (p * b) % n

            if p == 0:
                ans = k
                break
            if p == 1:
                ans = min(ans, k)
                break
            if p == n - 1:
                ans = min(ans, k)
                break

        if ans == 10**18:
            print(0)
        else:
            # decide kind
            p = 1
            for k in range(1, ans + 1):
                p = (p * b) % n
                if k == ans:
                    if p == 0:
                        print(1, ans)
                    elif p == 1:
                        print(2, ans)
                    else:
                        print(3, ans)

if __name__ == "__main__":
    solve()
```该实施直接跟踪权力$b$模数$n$。 第一个循环搜索最小的$k$产生有效的残留物。 第二遍重建触发了哪个条件，因为循环在搜索期间不会显式存储类型。 

唯一的微妙之处是确保$n-1$正确解释为$-1 \bmod n$，这对于交替求和规则是必要的。 另一个重要的细节是，当条件满足时，我们必须立即停止，因为我们需要最小的有效值$k$。

 输入：$b = 10, n = 11$我们计算 10 模 11 的幂。

 ## 边缘情况

 一种边缘情况是当$b \equiv 0 \pmod n$。 在这种情况下，第一次乘法已经产生零。 例如，$b = 6, n = 3$。 算法集$p = 6 \equiv 0$， 所以$k = 1$对于类型 1 立即有效，因为每个较高的数字块都会消失。 

另一种情况是当$b \equiv 1 \pmod n$。 然后$p$始终为 1，因此第一次迭代已经触发类型 2$k = 1$。 这对应于这样的事实：无论位置如何，每个数字块的贡献都保持不变。 

第三种情况是没有循环达到 0、1 或 -1 时。 例如$b = 10, n = 6$。 权力循环通过从未与所需结构对齐的残基，因此循环结束时没有找到有效的$k$，正确产生零。
