 ## 解决方案
 ## 问题理解

 我们可以把悬崖想象成一条从 1 到 h 高度的垂直线，在高度 h 处有一个特殊的起始平台。 其中一些高度已经包含可用的平台，而其余的则是空的。 您站在顶层平台，想要到达地面 0 层。 

在任何时刻，移动的唯一方法是站在高度为 x 的可用平台上并切换 x 和 x−1 的状态。 这样做会删除当前平台，并可能在下面创建一个新平台，如果该平台可用，您可以立即登陆该平台。 否则，您就会坠落，但仅当间隙最多为 2 时，坠落才是安全的。此约束实际上意味着您必须确保在下降时，永远不会出现三个连续的空关卡。 

我们还可以使用晶体提前“修复”配置，每个晶体都会将单个非顶部平台从空翻转到填充或从填充翻转到空。 我们的目标是通过最少数量的此类修复来实现下降。 

输入给出了多个独立的场景。 每个场景指定高度 h 和平台存在的初始高度集。 我们必须计算所需的最小翻转次数，以便存在从 h 向下到 0 的有效移动序列，而不会被迫下降两个以上的空级别。 

这些约束意味着每次测试都有一个强线性解。 所有查询的平台位置总数最多为 2×10^5，因此任何超过 O(n log n) 的解决方案都已经是安全的，而涉及高达 h 的按高度模拟的任何解决方案都是不可能的，因为 h 可以大到 10^9。 这立即排除了对悬崖的明确模拟。 

一个微妙的问题源于这样一个事实：空的部分而不是单个位置很重要。 一种幼稚的方法可能会尝试从顶部贪婪地模拟运动，每当运动被阻止时翻转，但这会失败，因为局部修复可能会进一步向下创建新的未来块。 另一个常见的错误是只关注连续平台之间的距离，而忽略了最后到 0 的段也是约束的一部分。 

例如，如果平台的高度为 5 和 1，则它们之间的间隙 4 会强制在中间至少进行一项修改，即使两个端点都有效。 类似地，平台位于 3, 2, 1 也可以，但 3, 1, 0 不会直接在输入中表示，仍然必须通过下降约束隐式检查。 

## 方法

 关键的观察结果是，运动约束仅取决于我们是否遇到三个连续的空高度。 这将问题转化为覆盖连续现有平台之间差距的任务。 

如果我们对所有现有平台（包括高度 h 处的隐式平台）进行排序，我们可以检查连续占用位置之间的间隙。 假设两个连续的平台位于高度 x 和 y，且 x > y。 它们之间的段包含 x−y−1 个空位置。 如果该数字最多为 1，则无需执行任何操作。 如果是 2 个或更多，我们需要使用晶体插入额外的平台，以便没有片段有超过两个连续的缺失位置。 

贪婪策略变得自然：从上到下遍历，每当我们检测到大于 2 的间隙时，我们就会在概念上“放置”额外的平台，以便将间隙分成安全块。 每个插入的平台都通过创建新的锚点来减少有效间隙。 

强力方法将尝试模拟晶体在所有空位置的所有可能放置，然后测试可达性，有效地探索指数配置。 这是不可能的，因为即使对于中等的 n，空位置的子集数量也是巨大的。

贪婪归约之所以有效，是因为每个间隙都是独立的：修复一个间隙不会影响之前的间隙，并且最优策略总是通过强制每个下降步骤覆盖最多两个空级别来最小化填充间隙。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 晶体布局的强力模拟 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 贪婪间隙处理| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每个查询。 

1. 将高度为 h 的起始平台添加到现有平台列表中。 这确保了我们从顶部均匀地处理下降。 
2. 按降序遍历平台高度，保持当前“最后看到的平台高度”。 
3. 对于当前 x 以下的每个下一个平台 y，计算间隙 g = x − y − 1。该间隙表示两个可用平台之间有多少个空层。 
4. 如果 g 为 0 或 1，我们什么也不做，因为这样的间隙不能产生三个连续的空电平。 
5. 如果g≥2，我们需要引入使用晶体的人工平台。 每个插入的平台都有效地减少了有问题的段，因此空链不会超过 2 个。间隙所需的晶体数量为 (g − 1) // 2。 
6. 将此贡献添加到答案中并将指针移至 y。 

最终答案是所有差距的总和。 

为什么它有效：只有当我们有三个连续的空高度时，下降约束才会失败。 大小为 g 的间隙恰好创建 g 个连续的空位置。 每个晶体插入都会引入一个新平台，将长的空段分割成更小的段。 最佳策略始终是均匀地放置这些插入，以便每个生成的段的大小最多为 2，并且任何较少的插入都必然会留下长度至少为 3 的段，这违反了约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    for _ in range(q):
        h, n = map(int, input().split())
        p = list(map(int, input().split()))
        
        # include the top
        prev = h
        ans = 0
        
        for x in p:
            gap = prev - x - 1
            if gap > 1:
                ans += (gap - 1) // 2
            prev = x
        
        print(ans)

if __name__ == "__main__":
    solve()
```该实现直接反映了间隙处理逻辑。 我们保留一个指针`prev`从 h 开始，代表最后一个保证可达的平台。 对于它下面的每个平台，我们计算它们之间存在多少个空层。 公式`(gap - 1) // 2`是确保该段中不存在连续三个空位置所需的插入平台的最小数量。 更新中`prev`确保我们只考虑相邻的相关片段。 

一个常见的实现陷阱是忘记将 h 视为初始占用的平台。 如果没有这个，第一个间隙就会被错误计算。 另一个微妙的点是，我们从不明确考虑高度 0，因为该结构保证最终段由相同的间隙逻辑隐式处理到 0。

 ## 边缘情况

 一种边缘情况是所有平台都是连续的，例如 5、4、3、2、1。在这种情况下，每个间隙都为零，因此算法正确地生成零操作。 

另一种情况是高度为 h 的单个平台，没有其他平台。 整个下降是从 h 到 0 的一个大差距，并且该公式正确地将其减少到避免运行三个空级别所需的最小插入次数。 

一个更微妙的情况是当间隙在小值和大值之间交替时。 每个间隙都是独立处理的，因为晶体插入仅影响该间隙内的局部连续性。 该算法对每个段只处理一次，并且不会重复计数，即使在大小间隙交错时也能确保正确性。
