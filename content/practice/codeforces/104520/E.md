 ## 解决方案
 ## 问题理解

 给定一个隐藏的正整数$x$，并且我们可以以线索的形式提出相关问题。 每个线索选择两个整数$a$和$b$，并且我们被告知绝对差异是否$|a-b|$可以整除$x$或不。 换句话说，每个查询仅揭示是否$x$是特定整数的除数$d = |a-b|$。 

目标不是计算$x$通过交互式查询，而是提前设计一套固定的此类线索。 看完所有答案后，一定有一个值$x$在匹配所有答案的有效范围内。 我们还被要求尽量减少所需线索的数量，并明确地构建这样一个集合。 

所以真正的任务是编码一个整数$x \le 10^6$对选定的差异使用一小组可分性或不可分性测试。 

约束条件$t \le 10^3$意味着我们必须独立构建每个测试，但每个构建必须很小，最多$10^3$线索。 由于每条线索只是算术输出，因此我们实际上需要一个$O(1)$或很小$O(\log x)$每个测试用例的构建。 

一个天真的想法是尝试“探测”周围数字的所有可能的约数$x$，但这很快就会成为问题，因为$x$不直接透露； 关于所选整数的整除性，我们只能得到“是”或“否”的答案。 困难在于许多不同的值$x$可以就一小组可分性约束达成一致，除非这些约束经过精心构建。 

当仅使用几个固定数字的整除性信息时，会出现微妙的边缘情况。 例如，如果我们只测试是否$x$除 6、10 和 15，然后得到多个值，例如$x=1$和$x=5$可以表现不同，但仍然有许多合数发生碰撞，除非我们仔细设计一个分离系统。 问题是整除性约束定义了除数集，我们必须将这些集相交为一个整数。 

## 方法

 关键的观察是，每条线索实际上都是“$x$划分$d$“ 或者 ”$x$不分开$d$“。 自从$d$完全由我们控制$|a-b|$，我们实际上是在构建一个关于可分谓词的决策系统。 

蛮力的想法是尝试所有候选值$x$，并针对每组可能的线索检查哪些值保持一致。 这意味着构建一个大小可达$10^6$并反复过滤。 即使每条线索删除了一半的候选人，我们仍然需要大约$\log_2(10^6)\approx 20$仔细选择二进制分割，但在可分性约束上设计此类分割并非易事，因为可分性的行为不像独立位。 

关键的结构见解是，被数字整除相当于除数集合中的成员资格。 如果我们选择的差异是精心选择的素数或结构化整数的乘积，我们可以强制$x$揭示其因子模式。 特别是，我们希望将问题简化为在精心选择的模下使用余数来区分数字。 

一个强大的简化是使用这样一个事实：对于任何整数$d$，我们可以强制执行$x \mid d$或者$x \nmid d$。 如果我们选择编码 2 的幂或增加阶乘式增长的差异，我们可以强制进行二进制编码$x$通过与构造倍数的比较。 

该问题使用的构造策略是隔离$x$通过针对从固定基数派生的精心选择的一组连续整数来测试整除性。 通过查询周围数字的整除性$x$，我们有效地确定是否$x$等于构造系统的 gcd。 最小的构造最终需要恒定数量的精心选择的差异，因为我们可以通过固定来强制唯一性$x$反对两三个精心构建的约束。 

基本思想是两个或三个形式的约束“$x$划分$d_i$“ 和 ”$x$不分开$d_j$” 可以排除除真实候选者之外的所有候选者$x$，假设$d_i$被选择以便他们的 gcd 结构独特地固定$x$。 标准方法是编码$x$作为通过移位结构间接派生的两个已知整数的 gcd。 

因此，而不是搜索$x$，我们构造除数交集恰好是的数字$\{x\}$。

 ## 算法演练

 使用的结构非常小：对于每个测试用例，我们输出两条线索。 

我们利用的身份$x$由该对唯一确定$(x, 2x)$在可分性行为方面。 

1.我们选择$a = x+1$和$b = 1$，所以差异是$d_1 = x$。 

这给了我们一个完美的“阳性测试”：$x \mid d_1$始终为真，但对于所有构造的约束组合，没有更小的整数会以这种方式表现。 
2.我们选择$a = 1$和$b = x+1$, 给予$d_2 = x$再次，但我们通过与整个系统中不匹配的第二个约束配对来翻转解释。 

然而，实际上分离值的更稳健的结构是使用两个差异：

 我们通过以下方式强制可分性$x$对于已知的倍数和不可整除性$x+1$。 

1.我们设定$d_1 = x$，确保$x$划分它。 
2.我们设定$d_2 = x+1$，仅保证$x=1$会将两者分开，与第一个约束结构结合时消除所有情况的歧义。 

在实践中，干净的最小结构是：

 我们输出两条线索：

 - 一个有差异的$d = x$（始终可整除）
 - 一个有差异的$d = x+1$标记为不可分割

 这迫使$x$恰好是与除法一致的整数$d$但不划分$d+1$，它独特地固定$x$。 

为什么它有效：在所有整数中，只有真实的$x$满足它的除法$x$但不划分$x+1$。 任何其他候选人$y \ne x$失败是因为$y \nmid x$或者$y \mid x+1$无法同时消除两个约束下的所有不正确的候选者。 该组合隔离单个固定点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x = int(input())
        
        # Two clues:
        # 1) difference x -> always divisible by x
        # 2) difference x+1 -> not divisible by x
        print(2)
        print(x + 1, 1, 1)
        print(1, x + 1, 0)

if __name__ == "__main__":
    solve()
```该解决方案简单地利用了我们可以直接嵌入的事实$x$进入差异。 第一条线索保证与真实值的一致性。 第二条线索排除了所有会错误划分的候选者$x+1$，这仅适用于平凡除数，并且组合起来留下一个有效的$x$。 

必须注意的是$a, b \le 10^9$，所以使用$x+1$是安全的，因为$x \le 10^6$。 此外，我们将线索数量固定为 2，这远低于限制。

 ## 边缘情况

 当$x = 1$，每个整数都可以被$x$，因此这两条线索有效地简化为关于整除性的琐碎事实。 该构造仍然输出有效的三元组，并且不会出现矛盾，因为$c=0/1$当所有整数都能被 1 整除时，可行性不会改变。 

当$x$最大值为$10^6$，构建的差异$x+1$保持在允许的坐标范围内$10^9$，因此不会发生溢出或无效输入。 第二条线索仍然正确地断言了不可分性，这是因为$10^6$不分开$10^6+1$。 

当测试非常小的复合值时，例如$x=2$或者$x=4$，该结构确保两个可分性约束的唯一一致的解释是预期的$x$，因为没有其他整数同时满足针对所选连续差值对的两个约束。
