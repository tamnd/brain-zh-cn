 ## 解决方案
 ## 问题理解

 我们有两个长度相同的数组。 一个数组，调用它`a`，固定在位置上。 第二个数组，`b`，可以任意排列。 选择订购后`b`，我们评估以稍微间接的方式定义的分数：每个子数组贡献的乘积之和`a[k] * b[k]`对该子数组内的所有索引进行求和，然后对所有子数组求和。 

重新解释这一点的一个有用方法是停止考虑子数组，而是询问每个位置多少次`k`被计算在内。 修复索引`k`。 任意子数组`[i, j]`其中包括`k`贡献`a[k] * b[k]`一次。 这样的子数组的数量就是选择的方式的数量`i ≤ k ≤ j`，等于`(k+1) * (n-k)`。 因此整个表达式折叠成一个加权点积：$$\sum_{k=0}^{n-1} a_k b_k \cdot (k+1)(n-k)$$因此，每个位置都有一个固定的正权重，仅由其索引决定，我们可以自由排列`b`最小化这个加权和。 

约束条件很大，有`n`最多`10^5`。 任何尝试所有排列的解决方案都是不可能的，因为`n!`长得太快了。 即使任何二次分配策略也会太慢。 我们需要更接近的东西`O(n log n)`或者`O(n)`。 

一个微妙的边缘情况来自两个数组中的负值。 自从`a[k]`可以是负数并且`b[k]`也可以是负数，乘积可以是正数或负数，因此，除非我们仔细考虑符号和权重，否则最佳策略并不是简单地“对两者进行排序并将最小的与最小的配对”。 不了解权重结构的天真贪婪可能会失败。 

例如，如果忽略权重，则配对排序数组对于最小化点积是正确的。 这里每个索引的权重各不相同，因此我们必须将它们纳入分配结构中。 

## 方法

 蛮力方法在概念上很简单：尝试每个排列`b`，计算加权和，并取最小值。 这是有效的，因为一旦表达式完全确定`b`是固定的。 然而，排列的数量是`n!`，甚至对于`n = 10`这变得不可行。 每个评价都是`O(n)`，所以总工作量是`O(n! · n)`。 

关键的见解是，重写问题后，我们得到了一个经典的赋值问题：我们从`b`到固定位置`k`，每个都有权重`w_k = (k+1)(n-k)`。 成本是：$$\sum w_k \cdot a_k \cdot b_{\pi(k)}$$我们可以吸收`a_k`通过定义进入权重`c_k = a_k * w_k`。 现在问题变得最小化：$$\sum c_k \cdot b_{\pi(k)}$$这是一种标准的重排不等式情况：为了最小化乘积之和，我们按升序对一个序列进行排序，而另一个序列按降序排序，前提是所有值都得到一致的处理。 

这里`c_k`可以是正数，也可以是负数，所以我们必须通过排序隐式分离符号的影响。 重排不等式仍然适用：两个序列之间的最小点积是通过对两者进行排序并将最大与最小配对来实现的。 

因此我们计算所有`c_k`，排序，排序`b`，并配对`c`按递增顺序`b`按降序排列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!·n) | O(n!·n) | O(n) | 太慢了|
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.计算每个位置的贡献权重`k`作为`(k+1) * (n-k)`。 

这计算有多少个子数组包含索引`k`，因此它用每个索引的单个系数替换了三重和。 
2. 将每个相乘`a[k]`通过其位置权重形成一个新数组`c[k] = a[k] * (k+1) * (n-k)`。 

这将目标转换为之间的点积`c`和一个排列的`b`。 
3. 数组排序`c`按非递减顺序。 

这根据仓位对最终总和的影响程度（包括符号效应）对仓位进行排序。 
4. 数组排序`b`按非递增顺序。 

我们想要大的值`b`与较小的（最负的）值配对`c`，以及较小的值`b`与大号配对`c`。 
5. 按元素相乘并求和`c[i] * b[i]`。 

这给出了重排不等式下的最小可能值。 

### 为什么它有效

 变换后，问题正是选择一种使加权点积最小化的排列。 重排不等式指出，对于任意两个序列，当一个序列升序排列、另一个序列降序排列时，获得两两乘积的最小和。 除了独立缩放每个位置之外，权重不会引入索引之间的耦合，因此排序捕获所有自由度。 任何与相反顺序的偏差都会交换两对并增加或保留总和，这会阻止现有的任何更好的配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    c = [0] * n
    for i in range(n):
        w = (i + 1) * (n - i)
        c[i] = a[i] * w
    
    c.sort()
    b.sort(reverse=True)
    
    ans = 0
    for i in range(n):
        ans += c[i] * b[i]
    
    print(ans)

if __name__ == "__main__":
    solve()
```该代码首先将三重和压缩为每个索引的权重。 实现的关键步骤是正确计算`(i+1)*(n-i)`，表示子数组中每个索引的包含计数。 这里任何相差一的错误都会破坏整个归约。 

之后，两个数组按相反方向排序并相乘。 使用 Python 整数可以避免溢出问题，因为值可以增长到大约`10^10`每个术语，但在 Python 的任意精度下保持安全。

 ## 边缘情况

 一种重要的边缘情况是当所有值都在`a`为零。 在这种情况下每`c[i]`无论排列如何，都会变为零，因此结果必须为零。 该算法自然地处理这个问题，因为排序不会改变任何东西，并且每个产品都是零。 

另一种边缘情况发生在`a`包含较大的正值和负值。 权重会根据位置放大它们的影响，因此不正确的配对会大大增加结果。 排序策略确保负贡献与大的正贡献相匹配`b`值，防止总成本意外放大。 

最后一个边缘情况是`b`相对于最佳配对，已经按“错误”方向排序。 该算法仍然通过重新排序来纠正这个问题，确保输入顺序不会影响正确性。
