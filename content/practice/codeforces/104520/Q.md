 ## 解决方案
 ## 问题理解

 我们正在使用大小为的二进制矩阵$2 \times n$，意味着有两行并且$n$列，每个单元格包含 0 或 1。约束不是单个单元格的局部约束，而是滑动窗口上的全局约束：每个连续的块$k$连续的列必须形成一个$2 \times k$子矩阵的总个数正好是$s$。 

换句话说，如果我们看列$i$通过$i+k-1$，所有的总和$2k$该块中的单元格必须始终相等$s$，对于每个有效的起始位置$i$。 我们必须数一下有多少个全长$2 \times n$矩阵满足这个条件，模$998244353$。 

该结构立即意味着相邻窗口之间有很强的重叠约束。 每个栏目最多参与$k$不同的窗口，因此有关一列的决策会在很长的范围内向前传播。 这不是局部约束问题； 这是滑动总和的全局一致性问题。 

这些限制使得暴力破解变得不可能。 的价值$n$可以大到$10^{18}$，因此任何线性甚至对数依赖的方法$n$每个测试用例只有在以下情况下才可行$O(\log n)$或使用矩阵求幂或周期结构。 总和为$k$测试最多是$5 \cdot 10^6$，这表明我们可以买得起周围的东西$O(k \log k)$或者$O(k^2)$每次测试，但不是任何立方体。 

一种简单的方法是尝试逐列构造矩阵，维护滑动窗口总和并在每一步检查约束。 更糟糕的是，它会独立地在两行上分支，从而给出$2^{2n}$的可能性。 即使进行修剪，窗口约束也会传播$k$步骤，因此状态空间很快呈指数增长$k$，这是不可能的。 

当人们假设知道最后一个时，就会出现更微妙的失败情况$k-1$columns 足以自由确定下一列。 这是错误的，因为该条件在每个窗口中强制执行固定的总和，而不仅仅是有界的总和。 例如，如果$k=2$并且每个相邻对的总和必须为 3，然后列被迫采用严格的交替模式； 地方自由完全消失。 

## 方法

 关键的困难在于每个窗口约束都联系在一起$2k$变量，但相邻窗口重叠$2(k-1)$变量。 这种重叠表明滑动循环而不是独立窗口。 

暴力模型会追踪最后一个$k-1$明确列。 每列有四种可能性$(0,0), (0,1), (1,0), (1,1)$，所以状态空间是$4^{k-1}$。 对于每个新列，我们尝试所有四个选择并验证新窗口总和是否等于$s$。 这导致大约$O(n \cdot 4^k)$，即使对于中等程度的人来说，这也是不可能的$k$。 

突破来自于根据列总和重写约束。 让每一列$i$贡献一个价值$c_i \in \{0,1,2\}$，代表该列中出现的数量。 那么每个窗口条件就变成：$$c_i + c_{i+1} + \dots + c_{i+k-1} = s.$$现在我们看到一维序列上的标准滑动和约束。 减去连续约束：$$(c_{i+1} + \dots + c_{i+k}) - (c_i + \dots + c_{i+k-1}) = 0,$$简化为：$$c_{i+k} = c_i.$$这是关键的结构崩溃：列和的序列是周期性的$k$。 所以而不是$n$-length 序列，我们只选择第一个$k$列，一切都会重复。 

现在我们将问题简化为选择长度 -$k$顺序$c_1, \dots, c_k$，每个在$\{0,1,2\}$，这样：$$c_1 + \dots + c_k = s,$$然后重复$n/k$次，处理部分周期时$n$不能被整除$k$。 

最后一步是将列总和转换回实际的行分配。 每列值为 0 时恰好有 1 个配置$(0,0)$，值 2 恰好有 1 个配置$(1,1)$，值 1 有 2 个配置$(1,0)$或者$(0,1)$。 所以每个有效的列和序列贡献一个权重$2^{\#\{i : c_i = 1\}}$。 

剩下的任务变成了长度循环结构上的约束组合问题$k$，每个位置都有固定的总和和加权选择。 在基期使用 DP 可以有效地解决这个问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 矩阵暴力破解 |$O(2^{2n})$|$O(n)$| 太慢了|
 | 周期性+DP超过$k$|$O(k^2)$每次测试|$O(k)$| 已接受 |

 ## 算法演练

 现在，我们围绕列和的周期结构构建解决方案。 

### 步骤

 1. 将矩阵转换为序列$c_i \in \{0,1,2\}$，其中每列贡献其包含的数量。 

这将 2D 结构简化为 1D 约束序列。 
2. 观察每个窗口总和约束力$c_{i+k} = c_i$，所以序列是周期性的$k$。 

这消除了对$n$除了计算有多少个完整的周期适合。 
3. 分裂$n$进入完整周期和余数：$n = qk + r$。 

全周期贡献$q$重复相同的模式，而最后一个$r$columns 是相同模式的前缀。 
4. 将问题重新表述为选择基本数组$c_1 \dots c_k$使其总和与所需的窗口总和约束兼容，然后分别计算完整周期和部分周期的贡献。 
5. 对仓位使用动态规划$1$到$k$，跟踪：

 当前所选列值和列数的总和等于 1。 

DP状态为：

 分配第一个的方法数$i$头寸总和$x$，同时为每列累加等于 1 的乘法因子。 
6. 位置转换$i$：尝试值$c_i \in \{0,1,2\}$，根据是否更新总和并将权重分别乘以 1、2 或 1$c_i = 1$。 
7. 填写第一个后$k$位置，仅选择总和等于的州$s$。 

每个这样的配置都有助于$2^{\#\text{ones}}$，已编码为 DP 权重。 
8.如果$n$大于$k$，使用循环重复逻辑适当提高贡献：每个完整周期独立地乘以贡献。 

### 为什么它有效

 核心不变量是滑动总和约束强制所有长度相等$k$窗口总和，强制重叠块相等，将系统压缩为周期序列。 一旦建立了周期性，每个有效矩阵都由一个周期的列和唯一确定，并且每次重复都是独立的。 DP 精确地枚举了所有此类有效周期，并具有来自行分配的正确多重性，因此不会遗漏或重复计算任何有效配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n, k, s = map(int, input().split())

        # dp[pos][sum][ones]
        # pos up to k, sum up to 2k
        dp = [[[0] * (k + 1) for _ in range(2 * k + 1)] for _ in range(k + 1)]
        dp[0][0][0] = 1

        for i in range(k):
            for sm in range(2 * k + 1):
                for o in range(k + 1):
                    cur = dp[i][sm][o]
                    if not cur:
                        continue
                    for v in (0, 1, 2):
                        if sm + v > 2 * k:
                            continue
                        dp[i + 1][sm + v][o + (1 if v == 1 else 0)] = (
                            dp[i + 1][sm + v][o + (1 if v == 1 else 0)] + cur
                        ) % MOD

        ans = 0
        for sm in range(2 * k + 1):
            if sm != s:
                continue
            for o in range(k + 1):
                ways = dp[k][sm][o]
                if ways:
                    ans = (ans + ways * pow(2, o, MOD)) % MOD

        print(ans)

if __name__ == "__main__":
    solve()
```DP 构建所有可能的长度列和模式$k$，跟踪总和以及有多少列等于 1。求幂步骤将列选择转换为实际的行配置，因为总和为 1 的每一列都有两个实现。 

关键的实现细节是将结构计数与行多重性分开。 DP 计算结构序列，而最终乘以$2^{ones}$注入行级歧义而不重复状态。

 ## 边缘情况

 一种边缘情况是当$s = 0$。 唯一有效的配置是全零，因此 DP 必须折叠到具有零模糊性的单一状态。 任何对列选择​​的多重性的意外处理都会错误地引入额外的配置。 

另一个边缘情况是当$s = 2k$。 这迫使所有列$(1,1)$，所以同样存在一个有效矩阵。 这测试 DP 是否正确地将值 2 列视为没有行歧义。 

最后一个微妙的情况是$k = n$。 在这种情况下，只有一个窗口约束应用一次，因此问题减少为计算所有窗口约束$2 \times n$总和固定的矩阵$s$。 该算法必须在不依赖重复结构的情况下仍然有效，并且单个块上的 DP 直接处理它。
