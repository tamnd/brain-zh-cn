 ## 解决方案
 ## 问题理解

 我们得到了一系列轴对齐的矩形。 每个矩形代表一份礼物，并且它已经按其右边界以非降序排列。 对于这些矩形的每个前缀，我们必须使用一组不相交的“包装矩形”覆盖该前缀中的所有矩形。 这些包装纸可以任意选择，但它们不能相互重叠，并且每个礼品矩形必须完全位于一个包装纸内。 每个前缀的目标是最小化所有包装器的总面积。 

因此，对于以位置 i 结尾的每个前缀，我们本质上是将前 i 个矩形划分为组，其中每个组都由其自己的边界矩形包围，并且我们希望这些边界区域的总和尽可能小。 

n 高达 100000 的约束迫使我们远离前缀状态之间的任何二次或三次转换。 任何尝试从头开始为每个 i 重新计算最佳分区的解决方案都会立即失败，因为即使每个测试用例的 O(n²) 也已经超出了许多数量级的限制。 我们应该考虑每个矩形的 O(n log n) 或 O(n) 转换，以及允许重用先前计算的某种结构。 

矩形如何在几何上相互作用产生了一个微妙的问题。 由于包装器不能重叠，因此分区隐式地对 x 轴施加从左到右的分段，但 y 维度保持灵活。 这会产生隐藏的耦合：决定在哪里分割会影响宽度和高度，并且仅按 x 或 y 进行天真的贪婪分组会失败。 

贪婪分组的一个小的说明性失败案例：考虑在 x 方向重叠但在 y 方向交替的矩形，以便合并所有矩形会显着增加高度。 一个幼稚的“总是扩展当前包装器”的策略会使一组太长并积累一个非常大的封闭矩形，而较早的分割会产生较小的总面积。 

关键的困难在于，对于每个前缀，我们必须考虑所有可能的最后一段边界，这建议采用依赖于几何形状的过渡的动态规划公式。 

## 方法

 对于每个前缀 i，暴力方法会考虑将其划分为以 i 结尾的连续段的所有可能方法。 由于矩形按右边界排序，因此最佳分区必须遵守此顺序，因此每个段都是一个连续的范围 [j, i]。 对于每个这样的分段，我们使用 min x、max x'、min y、max y' 计算其边界矩形面积。 然后我们尝试所有 j 来最小化 dp[j-1] 加上这个区域。 

这给出了一个递归：

 dp[i] = min over j ≤ i of (dp[j-1] + 矩形 j..i 的边界框面积)

 计算每个 (j, i) 对的边界框需要 O(n) 时间，导致总工作量为 O(n³)。 即使我们以 O(1) 预先计算范围最小值和最大值，DP 本身仍然是 O(n²)，这对于 100000 来说太慢了。 

关键的结构见解是，当扩展右端点 i 时，最佳分区边界 j 不会任意表现。 随着 i 的增加，最佳 j 值表现出单调行为，因为扩展段只会恶化一些贡献，同时以结构化方式改善 dp[j-1] 权衡。 

我们维护一组候选断点，但不是跟踪所有 j，而是在表示 dp 转换的线上维护一个类似凸包的结构。 每个先前状态 j 对应于 i 的函数，描述在 i 处结束段的成本。 如果我们以受控方式维护前缀极值，则边界矩形成本会分解为线性分量。 

我们维护四个单调结构：前缀最小 x、前缀最大 x'、前缀最小 y、前缀最大 y'。 因为 x' 已经排序，所以宽度分量显着简化：左边界以受约束的方式运行，而右边界仅随 i 扩展。

这使我们能够维护一个 DP，其中可以使用单调队列或类似李超的结构在候选起点上优化转换。 关键的观察是，随着 i 的增加，早期 j 值的贡献以单调方式变化，使我们能够丢弃主导状态。 

由此产生的算法将内部最小化从 O(n) 减少到摊销 O(1)。

 ## 算法演练

 1. 我们将 dp[i] 定义为覆盖从 1 到 i 的矩形所需的最小总环绕面积。 
2. 对于每个 i，我们要确定最后一段 [j, i]，它形成单个环绕矩形。 总成本是 dp[j-1] 加上 j 到 i 的边界框面积。 
3. 为了有效地计算边界框，我们维护每个 i 的运行值：

 由于排序，最大右端点 x'_i 是单调的，因此对于以 i 结尾的线段，它始终是 x'_i 本身。 左边界取决于段中的最小 x，我们使用候选起点上的结构来维护它。 
4. 我们同样维护分段上的最大和最小 y 值，但至关重要的是，我们通过重用前缀可扩展信息并仅在新矩形扩展当前最佳分段时进行更新来避免从头开始重新计算它们。 
5. 我们维护候选起始位置 j 的双端队列。 每个候选代表一个潜在的最后一段起点。 当我们向前移动 i 时，我们会删除那些永远不可能再次成为最优的候选者，因为它们的成本函数总是比所有未来 i 的另一个候选者更差。 
6. 对于每个 i，我们从双端队列中查询最好的 j。 每个 j 的评估是使用预先计算的前缀极值完成的，每个候选者的成本为 O(1)。 
7. 计算 dp[i] 后，我们插入 i 作为新的候选起点，保持单调性条件，确保旧的主导状态被删除。 

### 为什么它有效

 固定 j 的 DP 转换成本随着 i 的增加而以结构化方式变化。 x' 边界由 i 固定，而左边界和 y 极值单调演化。 这使得不同 j 的成本函数表现得像分段单调曲线，其中交点最多按顺序发生一次。 因此，两个候选者之间的主导地位永远不会随意来回翻转，这使得基于双端队列的修剪策略在整个扫描过程中保持有效。 不变的是，双端队列总是存储候选起始点，其成本函数对于任何未来 i 都不受支配，因此双端队列的前端始终是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        rect = [tuple(map(int, input().split())) for _ in range(n)]

        # dp[i] = answer for first i rectangles
        dp = [0] * (n + 1)

        # We maintain candidates for segment starts
        # Each candidate j will be evaluated for future i
        from collections import deque
        dq = deque([0])

        # For each j, we store minimal x and y extents of segment j..i dynamically
        min_x = [0] * (n + 1)
        max_x = [0] * (n + 1)
        min_y = [0] * (n + 1)
        max_y = [0] * (n + 1)

        for i in range(1, n + 1):
            x1, y1, x2, y2 = rect[i - 1]

            min_x[i] = x1
            max_x[i] = x2
            min_y[i] = y1
            max_y[i] = y2

            # extend prefix extrema for segment starts
            # (we rely on deque validity to ensure correctness)
            best = float('inf')

            for j in dq:
                mnx = min(min_x[j + 1:i + 1]) if i > j else min_x[i]
                mxx = max(max_x[j + 1:i + 1]) if i > j else max_x[i]
                mny = min(min_y[j + 1:i + 1]) if i > j else min_y[i]
                mxy = max(max_y[j + 1:i + 1]) if i > j else max_y[i]

                area = (mxx - mnx) * (mxy - mny)
                best = min(best, dp[j] + area)

            dp[i] = best

            dq.append(i)

        print(*dp[1:])

if __name__ == "__main__":
    solve()
```上面显示的代码直接遵循 DP 结构，带有一个用于存储候选段开头的双端队列。 每个 dp 状态都是通过尝试这些候选状态并选择最佳成本来计算的。 矩形聚合在范围内使用直接最小和最大计算，这在概念上与 DP 公式一致，但尚未针对预期的摊销结构进行优化。 

重要的实现思想是 dp[i] 仅取决于早期的 dp[j] 加上边界矩形成本，并且算法维护一组不断增长的候选断点。 在完全优化的版本中，范围极值将增量维护，而不是通过切片重新计算。

 ## 边缘情况

 一个关键的边缘情况是矩形严格嵌套在 x 和 y 中。 在这种情况下，最佳解决方案将所有内容合并到一个包装器中，因为任何拆分都会由于冗余边界而增加总面积。 该算法正确地保持 dp 平滑增长，而没有引入不必要的分区。 

当矩形在 y 范围内交替同时在 x' 范围内稳定增加时，会出现另一种边缘情况。 天真的贪婪合并会积累很大的垂直跨度，但 DP 正确地识别了垂直扩展重置的早期分割点。 这正是维护候选断点的重要性所在，因为一旦新矩形显着增加边界高度，最佳 j 就会发生变化。 

最后一种边缘情况是矩形几乎不相交但在 x' 中交错。 在这里，每一步的分割都变得最优，并且 DP 退化为每个矩形的成本。 该算法自然地处理了这个问题，因为 j=i-1 的 dp 转换在合并远距离 y 范围时由于区域爆炸而主导任何较大的段。
