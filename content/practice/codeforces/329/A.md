 ## 解决方案
 ## 问题理解

 我们有一个`n × n`网格。 有些细胞是可用的（`.`），而有些单元格是被禁止的（`E`）。 咒语只能对可用的单元施放。 

当我们对细胞施咒语时`(r, c)`, 行中的每个单元格`r`以及列中的每个单元格`c`变得纯净。 目标是使用尽可能少的法术净化整个网格。 

如果至少一个选定的咒语共享该单元格的行或列，则该单元格被净化。 由于法术只影响一行和一列，因此法术位置的选择决定了哪些行和列被“覆盖”。 

网格大小最多为 100，因此即使是二次或三次算法也很容易负担得起。 挑战不是性能，而是发现解决方案存在时所表征的结构以及如何构建解决方案。 

一个有用的观察是每个咒语最多可以引入一个先前未覆盖的行。 由于有`n`行，至少`n`任何有效的解决方案都需要咒语。 同样的论点也适用于列。 如果我们能找到一个解决方案`n`咒语，它自动是最佳的。 

最常见的错误是假设我们必须同时用选定的单元格覆盖每一行和每一列。 这听起来像是一个二分匹配问题，但它比问题的实际要求更强。 

考虑：```
2
..
.E
```选择`(1,1)`和`(2,1)`仅使用第 1 列，但每一行都被覆盖。 第 1 行中的每个单元格都被第一个咒语净化，第 2 行中的每个单元格都被第二个咒语净化。 即使第 2 列从未包含选定的咒语，整个网格也会变得纯净。 

另一种容易错过的情况是当一行仅包含禁止的单元格时：```
2
EE
..
```第一排不能施展任何咒语。 由于该行中的每个单元格仍然必须被纯化，因此我们需要一些选定的列来到达它们。 不幸的是，该行中的两个单元格都是禁止的，因此没有选定的位置可以位于那里。 正确答案是`-1`。 

列存在对称情况：```
2
E.
E.
```第 1 列仅包含禁止的单元格。 任何基于每列选择一个可用单元格的解决方案都是不可能的，但每行选择一个可用单元格立即有效。 正确的算法必须检查这两种可能性。 

## 方法

 暴力方法将尝试所有可用单元子集，并测试所得的咒语集是否净化整个网格。 如果有多达`10000`可用单元格，搜索空间为`2^10000`，这是完全不可行的。 

关键是要了解净化实际需要什么。 

假设我们从每一行中选择一个可用的单元格。 然后每一行都包含一个咒语。 由于咒语会净化其整行，因此网格的每一行都会被净化。 一旦每一行都被纯化，网格的每个单元格都被纯化，无论选择哪一列。 

只要每一行包含至少一个可用单元格，就会立即给出有效的解决方案。 

同样的推理是对称的。 如果每一列至少包含一个可用单元格，则从每一列中选择一个可用单元格也会净化整个网格。 

现在考虑两个条件都不成立的情况。 存在一行完全由`E`，并且存在一列完全由`E`。 

取该行和列的交集。 该单元格无法从其所在行中净化，因为该行中无法施展法术。 它无法从其柱中净化，因为该柱中无法施展法术。 因此净化是不可能的。 

这给出了完整的表征：

 如果每一行至少有一个可用单元格，则每行选择一个可用单元格。 

否则，如果每一列至少有一个可用单元格，则每列选择一个可用单元格。 

否则，输出`-1`。 

施工完全采用`n`咒语。 因为任何解决方案至少需要`n`咒语，这是最佳的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(n²)) | O(2^(n²)) | O(n²) | 太慢了 |
 | 最佳 | O(n²) | O(n) | 已接受 |

 ## 算法演练

 1. 读取网格。 
2. 检查每一行。 
3. 对于每一行，找到任何可用的单元格`.`。 
4. 如果每一行至少包含一个可用单元格，则存储每一行​​中的一个这样的位置并输出它们。 

该解决方案是有效的，因为每一行都接收一个咒语，因此每个单元格都属于纯化的行。 
5. 如果某些行不包含可用单元格，则放弃基于行的构造并检查列。 
6. 对于每一列，找到任何可用的单元格`.`。 
7. 如果每一列至少包含一个可用单元格，则存储每一列中的一个这样的位置并输出它们。 

每列都会收到一个咒语，因此每个单元格都属于净化列。 
8. 如果某些列也没有可用的单元格，则输出`-1`。 

### 为什么它有效

 如果每一行都有一个可用单元格，则从每一行中选择一个可用单元格将准确创建`n`咒语。 每一行都通过自己的咒语净化，因此网格的每个单元格都被净化。 同样的论点对于列对称地成立。 

如果两种结构都不存在，则至少存在一种全-`E`行和至少一个全`E`柱子。 它们的交叉单元格属于没有拼写的行和没有拼写的列。 任何选定的位置都无法净化它，从而无法净化。 

只要存在解决方案，该算法就会返回有效的解决方案，否则会正确报告不可能的情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    grid = [input().strip() for _ in range(n)]

    row_ans = []

    ok = True
    for i in range(n):
        pos = -1
        for j in range(n):
            if grid[i][j] == '.':
                pos = j
                break
        if pos == -1:
            ok = False
            break
        row_ans.append((i + 1, pos + 1))

    if ok:
        print("\n".join(f"{r} {c}" for r, c in row_ans))
        return

    col_ans = []

    ok = True
    for j in range(n):
        pos = -1
        for i in range(n):
            if grid[i][j] == '.':
                pos = i
                break
        if pos == -1:
            ok = False
            break
        col_ans.append((pos + 1, j + 1))

    if ok:
        print("\n".join(f"{r} {c}" for r, c in col_ans))
    else:
        print(-1)

solve()
```第一个块逐行搜索。 对于每一行，它记录第一个可用的单元格。 如果每一行都提供一个候选，那么这些位置立即形成有效的最佳答案。 

如果一行失败，算法将切换到对称列构造。 对于每一列，它记录第一个可用的单元格。 

该实现在存储答案时使用从 1 开始的坐标，因为输出格式需要它们。 这是差一错误的最常见来源。 

另一个微妙的点是，找到行解后应立即打印。 之后无需检查列，因为行结构已经是最佳的。

 ## 边缘情况

 ### 行完全禁止

 输入：```
2
EE
..
```由于没有可用的单元格，行扫描在第 1 行立即失败。 然后算法检查列。 

第 1 列包含可用单元格`(2,1)`第 2 列包含`(2,2)`，因此列构建成功：```
2 1
2 2
```每根柱子都被纯化，因此每个细胞都被纯化。 

### 列完全禁止

 输入：```
2
E.
E.
```行扫描成功：```
1 2
2 2
```每一行都被净化。 该算法永远不需要列构造。 

这说明了为什么仅检查列是不正确的。 

### 两者都是全-`E`行和全`E`专栏

 输入：```
2
EE
E.
```第 1 行不包含可用单元格，因此行构造失败。 

第 1 列不包含可用单元格，因此列构建也失败。 

该算法输出：```
-1
```细胞`(1,1)`排无符咒，列无符咒，无法净化。 

### 单个可用单元

 输入：```
1
.
```行扫描发现`(1,1)`和输出：```
1 1
```一个法术净化了唯一的一行和唯一的一列，覆盖了整个网格。
