 ## 解决方案
 ## 问题理解

 我们有一个代表森林的矩形网格。 有些单元格被树木挡住，其中一个单元格包含我们的起始位置`S`，一个单元格包含出口`E`，并且某些单元格包含数字。 一个数字单元代表最初站在那里的许多其他饲养员。 

在我们开始移动之前，所有饲养员都知道我们未来的整个路线。 他们可以每回合移动一步，在原地等待，并在可能的情况下完美协调以迫使战斗。 当饲养员到达与我们相同的牢房时，就会发生战斗，并且该饲养员永远消失。 

我们的目标是选择一条在离开之前使战斗总数最少的路线`E`。 

第一个观察是我们并没有试图最小化旅行距离。 如果能以某种方式减少战斗的话，我们可以随意走动。 挑战在于了解哪些育种者可以强制召开会议，无论我们选择什么路径。 

网格最多包含$1000 \times 1000 = 10^6$细胞。 任何从每个育种者或从每个数字单元独立执行图形搜索的算法都将过于昂贵。 甚至$O((rc)^2)$操作是完全不可能的。 我们需要细胞数量接近线性的东西。 

关键的困难在于饲养员要提前知道我们的路线。 一个天真的解释可能会暗示一个复杂的追逐游戏，但最短路径的结构完全将问题分解为一个简单的图形距离问题。 

### 不明显的边缘情况 1

 在我们到达出口之前，饲养员不需要拦截我们。 在出口牢房准确相遇仍然有效。 

例子：```
2 2
1E
S0
```最短距离为`S`到`E`是 1。 

饲养员已经邻近`E`，这样他们就可以站立`E`当我们到达时与我们战斗。 

正确答案：```
1
```一个粗心的解决方案，只在退出前严格考虑细胞，就会错过这个饲养员。 

### 不明显的边缘情况 2

 比我们距离出口更远的饲养员永远无法强行发起战斗。 

例子：```
3 3
E00
0T0
S09
```距离`S`到`E`是 2。价值 9 的饲养员距离 4`E`。 

我们可以简单地沿着最短路径行走并在他们到达该路径上的任何单元之前离开。 答案是：```
0
```计算所有可到达的育种者是不正确的。 

### 不明显的边缘情况 3

 我们可以走更长的路线，但这样做无济于事。 

例子：```
3 4
E111
0000
S000
```最短距离为`S`到`E`是 2。 

所有饲养员的距离最多为 2`E`，这样他们就能在我们之前到达出口。 

尝试四处闲逛只会给他们更多而不是更少的时间。 正确答案是所有此类育种者的总和。 

搜索任意路径的解决方案正在解决比必要的问题困难得多的问题。 

## 方法

 蛮力观点是将问题视为游戏。 我们选择一条完整的路线，每个饲养员选择响应，并且我们计算发生了多少次碰撞。 人们可以想象枚举路径`S`到`E`，模拟饲养员的运动，并选择最佳路线。 

这很快就变得不可能了。 即使在小型开放网格中，有效路线的数量也是指数级的。 对于多达一百万个单元，任何路径枚举方法都是没有希望的。 

突破来自于从出口而不是从一开始就看森林。 

假设我们计算从每个单元格到`E`。 让`dS`是距离`S`到`E`。 

考虑任何站在牢房中的饲养员，其距离`E`至多是`dS`。 

如果我们在旅途中到达某个小区`t`移动，那么该单元格的距离最多`dS - t`从`E`。 饲养员的距离`E`至多是`dS`可以沿着最短路径移动到该单元并且不晚于我们到达。 由于饲养员事先知道我们的路线并且可以随时等待，因此这样的饲养员可以在我们路径上的某个地方强制进行战斗。 

现在考虑一个饲养员，其距离`E`大于`dS`。 

即使我们立即沿着最短路线以最快的速度离开，饲养员也无法到达`E`在我们离开之前。 由于任何最短路径上的每个单元格`E`最多有距离`dS`，饲养员也无法及时到达任何这些细胞。 这样的饲养员永远无法强迫会议。 

这意味着答案仅取决于距离`E`。 

每个数字单元的距离`E`小于或等于的距离`S`将其数字值贡献给答案。 其他人都没有做出任何贡献。 

我们只需要一个 BFS，从`E`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳 | O(rc) | O(rc) | 已接受 |

 ## 算法演练

 1. 读取网格并找到位置`S`和`E`。 
2. 从以下位置开始运行 BFS`E`。 

每个非树单元接收到出口的最短距离。 由于所有移动的成本相同，因此 BFS 可以正确计算最短路径。 
3.记录起始单元格的距离，`dS`。 

这是我们到达出口所需的最少移动次数。 
4. 扫描网格的每个单元格。 

每当单元格包含数字时，检查其 BFS 距离。 
5. 如果可以从以下位置访问数字单元格`E`它的距离最多为`dS`，将其数值添加到答案中。 

这些育种者可以在最短的时间内到达我们最短旅程的某个点。 
6. 输出累加和。 

### 为什么它有效

 让`d(v)`表示距细胞的最短距离`v`到`E`。 

我们的最优策略是遵循最短路径`S`到`E`，正好取`dS = d(S)`移动。 任何更长的路线只会给饲养员额外的时间。 

对于细胞中的任何饲养员`b`和`d(b) ≤ dS`，饲养员可以沿着最短路径向出口移动。 沿着我们最短的路线，经过`t`移动时，我们站在一个单元格上，该单元格的距离为`E`等于`dS - t`。 自从`d(b) ≤ dS`，该路线上存在一个点，饲养员最晚可以到达。 因为饲养员提前知道我们的路线，可能会等待，一场战斗在所难免。 

对于任何饲养员`d(b) > dS`，即使到达出口也比我们整个逃跑要花更长的时间。 由于最短路径上的每个单元格的距离最多`dS`，饲养员无法及时到达任何此类细胞。 一场战斗是不可能的。 

因此，繁殖者恰好位于距离最大的数字单元中`dS`为答案做出贡献。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    r, c = map(int, input().split())
    grid = [list(input().strip()) for _ in range(r)]

    sx = sy = ex = ey = -1

    for i in range(r):
        for j in range(c):
            if grid[i][j] == 'S':
                sx, sy = i, j
            elif grid[i][j] == 'E':
                ex, ey = i, j

    dist = [[-1] * c for _ in range(r)]
    q = deque([(ex, ey)])
    dist[ex][ey] = 0

    dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while q:
        x, y = q.popleft()

        for dx, dy in dirs:
            nx, ny = x + dx, y + dy

            if not (0 <= nx < r and 0 <= ny < c):
                continue
            if grid[nx][ny] == 'T':
                continue
            if dist[nx][ny] != -1:
                continue

            dist[nx][ny] = dist[x][y] + 1
            q.append((nx, ny))

    limit = dist[sx][sy]
    ans = 0

    for i in range(r):
        for j in range(c):
            ch = grid[i][j]

            if ch.isdigit() and dist[i][j] != -1 and dist[i][j] <= limit:
                ans += int(ch)

    print(ans)

solve()
```BFS 计算从出口到每个可到达单元的最短距离。 运行搜索`E`关键的优化不是从每个数字单元开始。 

价值`limit = dist[sx][sy]`正是我们最短的逃亡时间。 距离出口超过此限制的任何饲养员都无法在我们离开之前拦截我们。 

条件`dist[i][j] != -1`这是必要的，因为某些单元可能会被树木与出口断开。 这样的繁殖者永远无法到达我们身边，也不能被计算在内。 

网格包含数字，`S`,`E`， 和`T`。 使用`ch.isdigit()`干净地识别饲养细胞并避免对其他符号进行特殊处理。

 ## 边缘情况

 再考虑一下：```
2 2
1E
S0
```BFS 给出到数字单元的距离 1 和到数字单元的距离 1`S`。 自从`1 ≤ 1`，饲养员被计算在内。 该算法输出 1，正确处理在出口处发生的会议。 

现在考虑：```
3 3
E00
0T0
S09
```起始距离为2。数字`9`距离为 4。因为`4 > 2`，它被排除在总和之外。 该算法输出 0，因为我们可以在这些繁殖者到达任何相关单元格之前逃脱。 

最后考虑一下断开连接的饲养员：```
3 3
ETT
TTT
S99
```BFS 无法到达底行，因此这些单元格保持距离`-1`。 计数步骤明确忽略无法到达的单元格。 答案是 0，因为那些饲养员被困在树后面，永远无法与我们互动。
