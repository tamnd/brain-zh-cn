 ## 解决方案
 ## 问题理解

 对于每个测试用例，我们给出两个整数 (a) 和 (b)，定义

 [
 f(x)=\sqrt{ax}+b。 
]

 我们需要找到每个固定点，即每个满足 (f(x)=x) 的 (x)，并按升序打印这些值。 原问题保证至少存在一个不动点，并且每个不动点都是整数。 官方声明正是使用了这种形式的函数，即 (1\le T\le100) 和 (-1000\le a,b\le1000)。 

当 (a\ne0) 时，平方根还会施加域条件：我们需要 (ax\ge0)。 有趣的是，无需使用浮点运算即可消除平方根。 在某个固定点，

 [
 x=\sqrt{ax}+b。 
]

 将 (b) 移至另一侧并定义

 [
 y=x-b。 
]

 那么(y=\sqrt{ax})，因此(y)必须是非负整数，因为(x)和(b)是整数。 平方给出 (y) 中的二次方程，这意味着最多可以有两个不动点。 

(a) 和 (b) 的界限很小，因此即使是仔细界限的蛮力解决方案也会通过。 例如，从

 [
 y^2=a(y+b)
 ]

 我们有

 [
 y^2\le |a|y+|ab|。 
]

 对于 (y\ge0)，这意味着 (y\le |a|+\sqrt{|ab|}\le2000)。 由于 (x=y+b)，每个固定点都位于 (-1000) 和 (3000) 之间。 扫描整个范围内的所有 100 个案例仅花费大约 (400100) 个候选检查。 更广泛的简单扫描，例如每个案例检查 200 万个可能的 (x) 值，已经需要大约 (2\times10^8) 个检查，并且对于一秒的限制来说是不必要的昂贵。 二次公式完全消除了扫描。 

在许多情况下，粗心的实施可能会失败。 如果 (a=0)，则方程根本不是二次方程。 用于输入```
1
0 -5
```函数为 (f(x)=-5)，因此唯一的不动点为 (-5)。 正确的输出是```
1
-5
```除以 (a) 或盲目应用二次公式的实现在这里将会失败。 

另一个陷阱是二次根表示 (y=\sqrt{ax})，因此只有非负根才有效。 为了```
1
-1 -2
```二次方程为 (y^2+y-2=0)，其根为 (1) 和 (-2)。 只有 (y=1) 可以是平方根。 它给出 (x=y+b=-1)，所以输出是```
1
-1
```保留两个二次根会错误地输出另一个值。 

第三个问题是要求判别式是完全平方数。 为了```
1
1 1
```判别式为 (1+4=5)，因此二次方程没有整数根 (y)。 该输入超出了问题的保证范围，但它说明了为什么使用浮点和舍入平方根是一种糟糕的通用技术。 整数判别测试是精确的。 

## 方法

 一种直接的方法是枚举可能的 (x)，计算是否 (ax\ge0)，并测试是否

 [
 x-b=\sqrt{ax}。 
]

 因为保证答案是整数，所以我们可以通过检查是否 ((x-b)^2=ax) 和 (x-b\ge0) 来避免浮点。 可以从方程中得出安全范围，并且在实际约束下，这种强力方法每个测试用例只需要几千次检查。 该问题已被接受，但没有揭示数学结构。 

更有用的方法是用变量替换平方根本身。 在某一固定点，令

 [
 y=\sqrt{ax}。 
]

 定点方程立即变为 (x=y+b)。 将其代入 (y^2=ax) 给出

 [
 y^2=a(y+b),
 ]

 或

 [
 y^2-ay-ab=0。 
]

 我们将原来的问题简化为求二次方程的非负整数根。 其判别式为

 [
 D=a^2+4ab。 
]

 如果 (D) 不是非负完全平方，则不存在整数根 (y)。 否则两个可能的根是

 [
 y=\frac{a+\sqrt D}{2},
 \qquad
 y=\frac{a-\sqrt D}{2}。 
]

 我们只保留非负整数的根，然后使用 (x=y+b) 将每个根转换回来。 最后，对最多两个答案进行排序即可得到所需的顺序。 

蛮力方法之所以有效，是因为约束恰好使搜索空间变小，但二次观察将工作量减少到恒定数量的整数运算。 它还从解决方案中消除了所有浮点问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| --- |
 | 蛮力 | (O(4000T)) 以及派生的安全范围 | (O(1)) | (O(1)) | 已接受，但没有必要 |
 | 最佳| (O(T)) 除了整数平方根成本 | 每个测试用例 (O(1)) | 已接受 |

 ## 算法演练

 1. 阅读(a)和(b)。 如果 (a=0)，则对于每个 (x)，都有 (\sqrt{ax}=0)，因此函数就是 (f(x)=b)。 唯一的不动点是 (x=b)。 这种特殊情况必须在形成二次方程之前处理，因为一般推导假设 (a\ne0)。 
2. 对于(a\ne0)，引入(y=\sqrt{ax})。 在固定点，我们有 (x=y+b) 和 (y\ge0)，因为它是平方根。 
3. 将 (x=y+b) 代入 (y^2=ax)。 这给出了

 [
 y^2-ay-ab=0。 
]

 因此，每个固定点对应于该二次方程的根，并且每个有效的非负整数根（y）给出一个固定点。 
4. 计算判别式

 [
 D=a^2+4ab。 
]

 如果 (D<0)，则二次方程没有实根。 根据问题的保证，对于有效的测试用例，这种情况不会发生，但处理它可以使实现完成。 
5. 计算精确的整数平方根 (s=\lfloor\sqrt D\rfloor)。 蟒蛇的`math.isqrt`精确返回非负整数的整数平方根，因此避免了浮点可能出现的精度问题`sqrt`。 
6. 如果 (s^2\ne D)，则 (D) 不是完全平方，因此二次方不能有整数根。 否则测试分子 (a+s) 和 (a-s)。 分子必须能被 (2) 整除，相应的根才能成为整数。 
7. 对于每个积分根 (y)，要求 (y\ge0)。 计算 (x=y+b) 并存储它。 非负条件是必要的，因为负数 (y) 不能等于 (\sqrt{ax})。 
8. 如果判别式为零，则删除重复项，对结果值进行排序，并打印其计数，后跟固定点。 

原理：每个不动点都会产生一个满足 (y\ge0)、(x=y+b) 和 (y^2=a(y+b)) 的值 (y=\sqrt{ax})，因此它必须出现在算法考虑的二次根中。 相反，二次方程的每个非负整数根 (y) 都给出 (x=y+b) 和 (y^2=ax)，因此 (\sqrt{ax}=y)，因此 (f(x)=y+b=x)。 该算法精确地过滤满足这些条件的根，因此它会产生每个固定点，而不会产生无效点。 

## Python 解决方案```python
import sys
from math import isqrt

input = sys.stdin.readline

def solve():
    T = int(input())
    out = []

    for _ in range(T):
        a, b = map(int, input().split())

        if a == 0:
            out.append("1")
            out.append(str(b))
            continue

        # y = sqrt(a*x), x = y + b
        # y^2 = a(y + b)
        # y^2 - a*y - a*b = 0

        D = a * a + 4 * a * b

        if D < 0:
            out.append("0")
            out.append("")
            continue

        s = isqrt(D)

        if s * s != D:
            out.append("0")
            out.append("")
            continue

        ans = []

        for num in (a + s, a - s):
            if num % 2 != 0:
                continue

            y = num // 2

            if y < 0:
                continue

            x = y + b
            ans.append(x)

        ans = sorted(set(ans))

        out.append(str(len(ans)))
        out.append(" ".join(map(str, ans)))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```第一个分支直接处理(a=0)。 在这种情况下，即使 (x) 本身为负数，平方根项也始终为零，因为根下的表达式为 (0x=0)。 因此 (x=b) 是唯一不动点。 

对于(a\ne0)，代码直接用整数构成(D=a^2+4ab)。 在给定的约束下，任何中间值的最大幅度都很小，Python 整数也消除了任何溢出问题。 

这`isqrt`call 给出精确平方根的下限。 然后我们检查`s * s == D`，它区分完美正方形和非正方形，而不将任何内容转换为浮点。 

两种表达方式`a + s`和`a - s`是两个二次根的分子。 在除法之前测试能否被二整除是必要的，因为否则 Python 的整数除法会默默地丢弃小数部分。 

支票`y < 0`同样重要。 二次方程来自对平方根方程进行平方，而平方可能会引入符号错误的根。 由于 (y) 代表 (\sqrt{ax})，因此仅允许 (y\ge0)。 

最后，`set`当 (D=0) 时删除重复的根，并且排序给出所需的递增顺序。 最多有两个候选者，因此这两个操作实际上都是恒定时间。 

## 工作示例

 第一个样本包含```
2
1 0
0 1
```对于第一个测试用例，(a=1,b=0)。 关键值是：

 | （一）| （二）| (D) | (s=\sqrt D) | 候选人 (y) | 有效 (x=y+b) |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | 1 | 1 | (1,0)| (1,0)|

 两个根都是非负整数。 它们给出 (x=1) 和 (x=0)，它们被排序为 (0,1)。 这与 (0) 和 (1) 都满足 (x=\sqrt{x}) 的事实相匹配。 

对于第二个测试用例，(a=0,b=1)，因此特殊分支适用：

 | （一）| （二）| 特殊情况| 定点|
 | --- | --- | --- | --- |
 | 0 | 1 | (f(x)=1) | (f(x)=1) | 1 |

 输出是一个固定点 (1)。 官方样本正是这两种情况和输出`2 / 0 1`其次是`1 / 1`。 

一个有用的附加迹是 (a=-1,b=-2)，它说明了为什么必须丢弃负二次根。 

| （一）| （二）| (D) | (s) | 候选人 (y) | 有效（y）| (x=y+b) |
 | --- | --- | --- | --- | --- | --- | --- |
 | -1 | -2 | 9 | 3 | 1, -2 | 1 | -1 |

 根 (y=-2) 满足平方二次但不能表示平方根。 剩下的根 (y=1) 给出 (x=-1)。 确实，

 [
 f(-1)=\sqrt{(-1)(-1)}-2=1-2=-1。 
]

 所以唯一的不动点是(-1)。

 ## 边缘情况

 当 (a=0) 时，对于每个输入 (x)，平方根表达式变为 (\sqrt0=0)。 对于具体输入```
1
0 -5
```函数为 (f(x)=-5)。 该算法立即返回 (x=b=-5)，而不尝试计算判别式。 输出是```
1
-5
```当二次方程有重根时，判别式为零。 为了```
1
2 -1
```我们得到

 [
 D=2^2+4\cdot2\cdot(-1)=0,
 ]

 所以（y=1）。 然后 (x=y+b=0)，但检查原始方程得出 (f(0)=\sqrt0-1=-1)，因此这揭示了一个有用的修正：此输入不满足定点方程。 必须重新检查二次计算：

 [
 y^2-ay-ab=y^2-2y+2,
 ]

 其判别式实际上是 (-4)，而不是 (0)。 因此，这个特定的输入不是有效的有保证的测试用例。 一个正确的重根示例是```
1
2 0
```哪里

 [
 y^2-2y=0,
 ]

 给出 (y=0,2)，因此也不会重复。 要获得真正的双根，请选择(a=2,b=-\frac12)，但要求(b)是整数。 在整数约束下，非零 (a) 不能生成具有非负重根的有效整数 (b)，除了 (b=0) 时 (y=0) 的情况。 因此，实际的整数边界情况是```
1
2 0
```带输出```
2
0 2
```并且只要发生（D=0），实现仍然可以正确处理。 

对于负二次根，考虑```
1
-1 -2
```二次方是

 [
 y^2+y-2=0，
 ]

 有根 (1) 和 (-2)。 该算法检查两者，拒绝 (-2)，因为 (y) 代表平方根，并将 (y=1) 转换为 (x=1-2=-1)。 输出是```
1
-1
```对于最大正系数情况```
1
1000 0
```判别式为 (1000000)，其平方根为 (1000)。 两个根是 (1000) 和 (0)，产生 (x=1000) 和 (x=0)。 排序后输出为```
2
