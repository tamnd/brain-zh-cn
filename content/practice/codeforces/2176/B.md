[CF 2176B - 最佳班次](https://codeforces.com/problemset/problem/2176/B)

 ## 解决方案
 ## 问题理解

 我们得到一个由以下内容组成的二进制字符串`0`沙`1`s，至少有一个`1`。 目标是将这个字符串转换成所有的字符串`1`s。 为了达到这个目的，我们可以反复选择一个shift`d`并执行字符串的循环右移`d`。 对于移位后的字符串中包含的每个位置`1`，原字符串中对应的位置被设置为`1`。 每一次操作的成本都是准确的`d`硬币，我们希望最小化将整个字符串变成硬币所需的总成本。 

输入由多个测试用例组成。 每个测试用例指定字符串的长度和字符串本身。 测试用例中所有字符串长度的总和最多为`2 × 10^5`。 这立即排除了二次算法`n`因为他们大约需要`4 × 10^10`最坏情况下的操作，对于 2 秒的时间限制来说太大了。 我们需要一个在每个测试用例中以大致线性或接近线性时间运行的解决方案。 

一种不明显的边缘情况是字符串已经全部为 1，例如`111`。 在这种情况下，最小成本应该为零。 另一个是一个字符串，其中孤立的零被 1 包围，例如`10101`。 不考虑零之间的间距而天真地选择班次可能会导致比必要的成本更高的成本。 同样，对于像这样的字符串`100001`，我们必须认识到最大的零间隙支配着所需的最小移位。 

## 方法

 蛮力方法考虑尝试每一种可能的转变`d`从`1`到`n`，执行循环移位，更新原始字符串，并累加成本，直到所有元素都变为 1。 这是正确的，因为操作定义保证了移位的重复应用会传播移位。 然而，在最坏的情况下`n`最多`2 × 10^5`，这种方法大约需要`O(n^2)`一个测试用例的操作，速度太慢。 

最佳解决方案的关键观察是将字符串转换为全 1 的成本仅取决于最大的连续零块。 仅当移位将 1 与其中一个 0 对齐时，任何 0 序列才能转换为 1。 因此，我们可以将问题简化为计算从任何一到下一个零的最大距离（考虑循环包装）。 最小成本等于最大零块长度一半的上限。 这是因为尺寸的一项操作`d`可以传播一个`d`位置，因此覆盖了一块`k`零至少需要`ceil(k / 1)`最差对齐的步骤。 

换句话说，最长的连续零段决定了最小`d`我们必须选择。 一旦我们覆盖了这个片段，所有其他的都会自动传播。 这将复杂性降低到`O(n)`每个测试用例，只需扫描最长的零块并考虑循环包装。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取二进制字符串`s`。 
2. 识别所有零的位置。 将字符串视为圆形，因此将末端连接到开头。 
3. 找到最长的连续零块的长度。 这涉及对字符串的单次扫描，计算连续的零并与迄今为止找到的最大值进行比较。 为了处理循环性，如果字符串以零开头和结尾，则将这些计数求和为一个块。 
4. 计算最小成本作为最大零块长度一半的上限。 这是有效的，因为一个班次可以覆盖最多`d`一次操作中的位置。 
5. 输出计算出的最小成本。 

为什么有效：该算法之所以有效，是因为最大的零块决定了 1 必须传播以覆盖所有零的最小距离。 较小的块自然会被相同的班次或更小的班次覆盖。 上限操作确保正确处理奇数长度的零块，因为在单次移位中传播是双向的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        
        # Handle case where string is already all ones
        if '0' not in s:
            print(0)
            continue
        
        # Duplicate string to handle cyclic property easily
        doubled = s + s
        max_zeros = 0
        count = 0
        
        for ch in doubled:
            if ch == '0':
                count += 1
                max_zeros = max(max_zeros, count)
            else:
                count = 0
        
        # Since doubled, max_zeros could be up to 2*n, we clamp to n
        max_zeros = min(max_zeros, n)
        print(math.ceil(max_zeros / 2))

if __name__ == "__main__":
    solve()
```该解决方案首先检查是否已全为 1 的字符串并立即返回零。 为了处理字符串的循环性质，它会复制字符串并扫描连续的零，并获取最大计数。 加倍可确保环绕末尾的零被视为一个连续的块。 最后，它将最小成本计算为该块长度的一半，并在必要时向上舍入。

 ## 边缘情况

 对于长度为 1 且有 0 的字符串，例如`0`，该算法将字符串复制到`00`，将连续零计数为 2，钳位到 n=1，并计算 ceil(1/2)=1。 这会正确返回 1 的成本。对于末尾有零的字符串，例如`1001`, 重复产量`10011001`，并且双倍字符串中的最大连续零为 2，正确地给出了最小成本 2。这表明循环性的处理是正确的。
