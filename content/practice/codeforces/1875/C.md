 ## 解决方案
 ## 问题理解

 我们收到了一组青苹果片，每片的重量正好是 1 公斤。 目标是将这些碎片分配给固定数量的人，以便每个人最终拥有相同的总重量。 水母可以使用一把神奇的刀将任何苹果片切成相等的两半，每次操作都算作一次移动。 我们想要确定实现平均分配所需的最小分割数，或者报告`-1`如果不可能的话。 

输入提供测试用例的数量，对于每个测试用例，两个整数：`n`，苹果片的数量，以及`m`，人数。 输出是所需的最小分割数或`-1`。 

约束条件允许`n`和`m`最多 10^9 和最多 2×10^4 测试用例。 简单地模拟劈开每个苹果的成本将非常昂贵，因为劈开的次数可能非常大。 这需要一种对分布进行数学推理的方法，而不是显式地执行每个操作。 

关键的边缘情况发生在以下情况：`n < m`。 如果苹果碎片比人少，我们就必须通过反复减半来创造碎片。 例如，如果`n = 1`和`m = 5`，使用二次方分割不可能精确地得到每人 1/5 公斤，所以答案是`-1`。 另一个边缘情况是当`n`已经可以被整除`m`; 在这种情况下，不需要拆分。 

## 方法

 蛮力方法会尝试模拟每次分割，递归地将碎片减半，直到每个人都能获得相等的总重量。 这将涉及管理数量可能呈指数级增长的苹果片。 在最坏的情况下，复杂度大约为 O(2^k)，这对于`n, m`最多 10^9。 

关键的观察结果是，唯一允许的分割是一半，因此每个最终碎片的重量必须是 1 / 2^k 形式的分数。 因此，为了平均分配，每个人收到的苹果重量总和必须等于`n / m`。 如果`n / m`不能用1/2的幂和来表示，这是不可能的。 

我们可以将问题简化为计算产生足够“1/2^k”块所需的分割数量，以求和`n / m`对于每个人。 等价地，我们可以乘以`n / m`经过`m`获取“单位权重”的总数并使用位操作来计算分割数：每个操作有效地添加另一个二次方。 

这将问题简化为贪婪方法：重复获取最大的剩余二次方并将其分割，直到各部分的总和匹配`n / m`对于每个人。 因为权重是 2 的幂，所以可以使用商的二进制表示来有效地跟踪权重。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(2^n) | O(2^n) | O(2^n) | O(2^n) | 太慢了 |
 | 贪婪的位计数 | 每个测试用例的 O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和`m`。 检查是否`n < m`。 如果是，立即返回`-1`因为你不能仅使用减半的方式将至少一份分配给每个人。 
2. 计算`k = n // m`。 这是每个人必须承受的最小总重量（以千克为单位）。 
3. 计算`r = n % m`。 如果`r != 0`，我们必须通过分割一些部分来均匀分配剩余部分来进行补偿。 如果`r`不能表示为两个分数的幂之和，返回`-1`。 
4. 计算二进制表示中 1 的数量`m - n % m`（或跟踪所需一半的等效表达式）。 每个 1 对应于生成该大小的一块所需的分割。 
5. 这些计数的总和给出了最小分割数。 

不变的是，在每一步，我们维护一个总重量恰好为的块池`n`。 每次分割都会增加件数，并允许我们仅使用二次幂来匹配每个人的精确重量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_splits(n, m):
    if n < m:
        return -1
    q, r = divmod(n, m)
    if r == 0:
        return 0
    # count minimum splits needed to cover remainder
    count = 0
    while r:
        # subtract largest power of 2
        largest_pow2 = 1 << (r.bit_length() - 1)
        r -= largest_pow2
        count += 1
    return count

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    print(min_splits(n, m))
```功能`min_splits`首先检查每个人是否有足够的苹果。 如果`r == 0`，不需要分裂。 否则，我们重复减去小于或等于余数的最大的两个幂，并计算需要多少次分割。 这相当于创建尺寸为 1/2、1/4 等的较小块，以匹配每人所需的总数。 使用`bit_length`至关重要，因为它有效地给出了 2 的最大幂的指数。 

## 工作示例

 ### 示例 1

 输入：`10 4`- 每个人必须收到`10 // 4 = 2`千克
 - 余数为`2`- 余数的二进制：`10`- 2 ≤ 2 的最大幂是 2 → 减，余数 0，计数 = 1
 - 需要一分为二

 ### 示例 2

 输入：`3 4`- 每个人必须收到`3 // 4 = 0`千克
 - 余数为`3`- 余数的二进制：`11`- 减去最大的二的幂：2 → 余数 1 → 计数 1
 - 减 1 → 余数 0 → 计数 2
 - 需要两次拆分

 变量表：

 | 变量| 步骤 1 | 步骤 2 | 步骤 3 |
 | --- | --- | --- | --- |
 | r | 2 | 0 | - |
 | 最大_pow2 | 2 | - | - |
 | 计数| 1 | 1 | - |

 这表明该算法正确地使用 2 的幂减少余数并计算分割数。

 ## 边缘情况

 如果`n < m`，算法立即返回`-1`。 例如，`n = 1`和`m = 5`仅使用一半无法生产尺寸为 1/5 的碎片。 对于 2 的幂的余数，算法直接执行最小分割。 二进制表示确保每个分割对应于有效的减半操作。 对于大输入，循环最多运行 30 次，因为 2^30 > 10^9，从而保持解决方案的高效。
