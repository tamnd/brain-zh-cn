 **标签：** 暴力、贪婪
 **求解时间：** 1m 20s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们被要求最大限度地延长炸弹爆炸的时间。 炸弹有一个计时器`b`最初，每秒减少 1。 你有`n`工具，每个工具都能够增加计时器`x_i`使用时，但定时器不能超过最大值`a`。 每个工具只能使用一次，并且可以在计时器减少之前的任何一秒使用。 目标是确定在最佳使用工具的情况下炸弹达到零的最长总时间。 

输入由多个测试用例组成。 对于每个测试用例，您都会得到`a`,`b`， 和`n`， 其次是`n`代表工具值的整数。 每个测试用例的输出都是一个整数：炸弹持续的最大秒数。 

限制条件允许`b`和`a`最多$10^9$，但是工具的数量`n`最多 100。因为`n`很小，多次迭代工具的算法是可行的。 然而，大的界限`a`和`b`表明我们不能天真的模拟非常大的计时器的每一秒，因为这可能需要多达$10^9$迭代。 

当工具效果的总和超过最大计时器时，就会出现微妙的边缘情况`a`。 例如，如果`a = 5`,`b = 1`，工具值为`[3, 4]`，总是添加最大工具的天真贪婪方法可能会尝试将计时器增加到超出`a`，这没有效果。 因此，该算法必须遵守上限`a`以避免浪费工具。 

当所有工具值相对于计时器都非常小时，就会出现另一种边缘情况。 例如，`a = 10`,`b = 10`、和工具`[1, 1, 1]`。 开始时使用工具不会增加上面的计时器`a`，因此在同一秒内使用多个工具是多余的。 

## 方法

 暴力方法会每秒模拟一次，在每一步尝试将未使用工具的所有可能子集添加到计时器中，然后减 1。这保证了正确性，但在以下方面呈指数增长：`n`因为有$2^n$工具的子集。 和`n`达到100时，这种方法是不可行的。 

关键的观察是，一旦当前计时器低于，使用工具的顺序并不重要`a`。 在任何时刻，为了最大化延迟，我们希望将计时器增加到接近`a`尽可能。 因此，最好首先使用最大的工具。 这将问题转换为简单的贪心算法：按降序对工具进行排序，然后每秒使用所需数量的工具来填充计时器`a`。 每个工具最多使用一次。 一旦计时器已满或没有剩余工具，炸弹就会每秒倒计时 1 次。 

这将问题转化为对排序工具的线性扫描。 对于每一秒，在计时器低于时添加下一个最大的工具`a`，然后将计时器减 1。继续，直到没有工具剩余并且计时器达到零。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * 最大(a, b)) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取最大计时器`a`,初始定时器`b`, 工具数量`n`，以及一系列工具`x`。 
2. 按降序对工具进行排序。 这确保首先应用最大的可用工具来最大化计时器。 
3.初始化当前定时器`c`作为`b`和一个柜台`seconds`为 0。 
4. 迭代排序的工具，将每个工具添加到`c`不超过`a`。 使用工具后，立即将总秒数加 1，因为计时器每秒会减少 1。 
5. 使用所有工具或计时器到达后`a`这样就没有工具可以进一步增加它，将剩余的计时器值添加到`seconds`。 这说明了在不进一步使用工具的情况下计时器达到零所需的秒数。 
6. 输出`seconds`对于这个测试用例。 

为什么有效：通过始终应用可用的最大工具，我们可以每秒最大化计时器。 由于定时器不能超过`a`，稍后使用较小的工具无助于将最大计时器增加到超出`a`。 因此，贪心选择是全局最优的。 一旦计时器到达`a`或者没有工具剩余，没有更好的配置存在，剩下的倒计时只是`c`秒。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, n = map(int, input().split())
    x = list(map(int, input().split()))
    x.sort(reverse=True)
    c = b
    seconds = 0
    for tool in x:
        if c >= a:
            break
        c = min(c + tool, a)
        seconds += 1
    seconds += c
    print(seconds)
```该解决方案首先按降序对工具进行排序。 对于每个工具，如果当前计时器低于最大值，则它会使用该工具，更新计时器并为计时器递减计数一秒。 一旦没有更多工具可以增加计时器，剩余的倒计时就会添加到总秒数中。 排序可确保首先应用较大的工具，这对于有效填充计时器（由于上限）是必要的`a`。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n log n) | O(n log n) | 对工具进行排序决定了复杂性。 工具的迭代是 O(n)。 |
 | 空间| O(n) | 存储工具数组需要 O(n)。 其他变量使用 O(1)。 |

 该解决方案可有效处理多达 100 个工具。 对 100 个数字进行排序是微不足道的，并且简单的迭代与`n`，所以这个解决方案很容易在 1 秒的时间限制内运行。
