[CF 1145C - 神秘电路](https://codeforces.com/problemset/problem/1145/C)

 **评级：** -
 **标签：** 位掩码，暴力破解
 **求解时间：** 1m 52s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们得到一个整数`a`0 到 15 之间。这个整数表示一个简单 4 位电路的配置，其中每个位可以是 0 或 1。任务是根据电路的神秘内部规则计算输出整数。 从样本来看，当`a = 3`，输出是`13`。 观察这些值，很明显问题本质上是要求我们转换 4 位表示`a`根据固定的按位映射转换为另一个整数。 

限制非常小：`a`范围从 0 到 15，这意味着只有 16 个可能的输入。 这意味着每个输入执行 O(1) 次操作的任何方法都可以，并且所有输入的强力枚举都是可行的。 

非明显的边缘情况是该范围的边界。 最小的输入，`a = 0`，以及最大输入，`a = 15`，如果映射涉及在极端情况下相互作用不同的位位置，则可能会揭示特殊行为。 例如，不小心的位操作可能会翻转错误的位，从而为这些边界情况产生错误的输出。 

## 方法

 最简单的方法是尝试针对所有 16 个输入手动模拟电路的每个可能的输出，并将其存储在查找表中。 这是完全正确的，因为对于小的输入域，暴力枚举是可行的。 仅当输入范围较大时，它才会变得太慢，但这里的操作总数仅为 16 次赋值。 

关键的见解是输入的每一位都映射到输出的特定位。 通过仔细检查样品`a = 3`（二进制`0011`）产生输出`13`（二进制`1101`），我们可以推导出映射：输入位 0 映射到输出位 2，输入位 1 映射到输出位 0，输入位 2 映射到输出位 3，输入位 3 映射到输出位 1。一旦建立了这种映射，就可以使用简单的位移位和按位或运算在恒定时间内计算出任何输入的输出。 

蛮力之所以有效，是因为我们可以枚举所有输入和输出并预先计算它们，但在优雅和通用性方面失败了。 变换是固定位排列的观察结果将问题简化为使用位操作的恒定时间计算。

 | --- | --- | --- | --- |
 | 蛮力 | O(16) | O(16) | 已接受 |
 | 按位映射 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取输入的整数`a`。 
2. 转换`a`转换为 4 位二进制表示形式。 从概念上讲，请考虑从最低有效位（位 0）到最高有效位（位 3）的位。 
3. 初始化`output`为 0。该变量将存储转换后的整数。 
4. 对于每个输入位，根据推导的映射将其放入相应的输出位位置：

 - 输入位 0 → 输出位 2
 - 输入位 1 → 输出位 0
 - 输入位 2 → 输出位 3
 - 输入位 3 → 输出位 1
 5. 使用按位移位和 OR 运算将每个输出位设置到正确的位置。 
6. 打印最终结果`output`。 

工作原理：每个位都独立映射到唯一的位置，因此位之间不存在干扰。 通过系统地应用映射，我们保证输出整数正是神秘电路为任何输入生成的整数`a`范围为 0 到 15。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a = int(input())

# mapping input bits to output bits
output = 0
if a & 1:       # input bit 0 -> output bit 2
    output |= 1 << 2
if a & 2:       # input bit 1 -> output bit 0
    output |= 1 << 0
if a & 4:       # input bit 2 -> output bit 3
    output |= 1 << 3
if a & 8:       # input bit 3 -> output bit 1
    output |= 1 << 1

print(output)
```该解决方案读取整数，然后使用按位 AND 检查 4 个输入位中的每一个。 每个设置位使用左移移动到相应的输出位置，并使用按位或组合。 这可确保所有位都正确映射。 使用 if 语句而不是循环可以使代码保持明确并避免差一错误。 

## 工作示例

 **样品1：**

 输入：`3`（二进制`0011`）

 | 步骤| 输入位| 输出位| 输出值|
 | --- | --- | --- | --- |
 | 0 | 1 | 2 | 4 |
 | 1 | 1 | 0 | 5 |
 | 2 | 0 | 3 | 5 |
 | 3 | 0 | 1 | 5 |

 最终输出：13（二进制`1101`）

 说明： 位按照映射精确放置。 输出与样本匹配。 

**样本2：**

 输入：`8`（二进制`1000`）

 | 步骤| 输入位| 输出位| 输出值|
 | --- | --- | --- | --- |
 | 0 | 0 | 2 | 0 |
 | 1 | 0 | 0 | 0 |
 | 2 | 0 | 3 | 0 |
 | 3 | 1 | 1 | 2 |

 最终输出：2（二进制`0010`）

 解释： 仅设置了最高输入位，并且它移至输出位 1，产生 2。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    a = int(input())
    output = 0
    if a & 1: output |= 1 << 2
    if a & 2: output |= 1 << 0
    if a & 4: output |= 1 << 3
    if a & 8: output |= 1 << 1
    return str(output)

# provided sample
assert run("3\n") == "13", "sample 1"

# custom cases
assert run("0\n") == "0", "all bits zero"
assert run("15\n") == "15", "all bits one"
assert run("8\n") == "2", "highest bit only"
assert run("1\n") == "4", "lowest bit only"
assert run("6\n") == "9", "middle bits set"

 ## 边缘情况

 对于`a = 0`，所有输入位均为零。 该算法检查每一位，发现没有设置，并将输出保留为 0。这符合预期的行为。 

为了`a = 15`，所有输入位均为 1。 每个位移动到其相应的输出位置，产生 13 + 2 = 15。该算法正确处理全位场景，而位之间没有干扰。 

为了`a = 8`，仅设置最高位。 支票`if a & 8`触发，将输出位 1 设置为 1。所有其他位保持为零。 这表明每个位都是独立映射的。 

该方法对于 [0, 15] 中的所有可能输入都是稳健的，因为映射是完整且不重叠的。
