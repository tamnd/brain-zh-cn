 ## 解决方案
 ## 问题理解

 我们接受了一个伪装成编程问题的小型监督学习任务。 有 50 个灰度图像，索引从 1 到 50。对于前 20 个图像，我们给出了二进制标签，指示每个图像是否被视为“傅立叶涂鸦”。 其余 30 张图像没有标签，任务是仅使用从前 20 张学到的信息来推断它们的标签。 

实际上，每个图像都是一个高维数字对象。 如果我们展平大小为 H × W 的图像，我们可以将其视为 ℝ^(H·W) 中的向量。 学习数据集为我们提供了该空间中的 20 个标记点，我们必须预测 30 个未见点的类别。 

就数据集大小而言，约束故意很小，但每个图像仍然包含足够的像素，因此不需要对所有像素进行简单的模式匹配以及所有可能的转换。 期望有完整的图像处理或机器学习方法，但由于训练集很小，只需要一个非常轻量级的模型。 

天真的尝试可能会尝试手动检查图像或根据文件名或索引对启发式进行硬编码。 这会失败，因为图像没有以任何有意义的方式按类别排序。 另一种天真的尝试是使用不进行归一化的强力相似性搜索来比较原始像素阵列，如果图像之间的亮度或对比度不同，则可能会失败。 

当两个图像在结构上视觉上相似但强度缩放不同时，就会出现微妙的边缘情况。 例如，如果一个图像是另一图像的较暗版本，则原始欧几里得距离可能会错误地将它们视为不同的，即使它们代表同一类。 类似地，如果图像稍微移动，没有鲁棒相似性度量的逐像素比较就会变得不稳定。 

## 方法

 暴力策略将处理每个测试图像，并使用原始像素距离将其与每个训练图像进行比较。 对于每张测试图像，我们计算与所有 20 张标记图像的距离，并分配最接近的图像的标签。 这是一个 1 最近邻分类器。 

这种方法原则上是正确的，因为同一类的图像倾向于在像素空间中聚类，但失败点是噪声敏感性。 像素级欧几里德距离很大程度上受到亮度变化或轻微扭曲等微小变化的影响。 此外，如果来自不同类的两个训练图像彼此之间的距离比它们自己的类质心的距离更近，则 kNN 可能会错误分类。 

关键的改进是通过将训练数据压缩成更稳定的表示来降低敏感性。 我们不是与所有样本进行比较，而是为每个类别计算一个原型：类别 0 的平均图像和类别 1 的平均图像。然后分类就变成与两个质心而不是 20 个单独点的比较。 这减少了方差并消除了对单个噪声样本的依赖。 

进一步的细化是每个图像矢量的归一化，确保亮度缩放不会扭曲距离。 这使得余弦相似度或归一化欧几里得距离更加可靠。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力 k-NN（像素距离）| O(30 × 20 × P) | O(20 × P) | 可以工作但不稳定 |
 | 质心 + 归一化距离 | O(50 × P) | O(P)| 已接受 |

 这里 P 是每张图像的像素数。 

## 算法演练

1. 加载所有图像并将每一张图像转换为灰度向量。 这确保了每个图像都在相同的数字空间中表示，从而允许在样本之间进行直接比较。 
2. 通过减去其平均强度并除以其标准差来标准化每个图像向量。 这消除了亮度偏差，以便分类取决于结构而不是照明。 
3. 根据提供的标签将前 20 个向量分成两组。 
4. 通过平均该类中的所有向量来计算该类的质心。 这些质心代表每个类别的“典型”图像。 
5. 对于从 21 到 50 的每个测试图像，使用欧几里得距离或余弦相似度计算其到两个质心的距离。 
6. 将较近质心的标签分配给测试图像。 
7. 按顺序输出所有 30 个预测标签。 

### 为什么它有效

 核心假设是，在每个类别中，图像在归一化后在像素空间中形成一个紧凑的簇。 平均可以减少单个样本中存在的随机噪声，从而产生稳定的原型。 然后根据与这些原型的接近程度对新图像进行分类，这近似于各向同性高斯噪声假设下的贝叶斯决策规则。 这可以防止个别训练异常值主导决策边界。 

## Python 解决方案```python
import sys
import numpy as np
from PIL import Image

input = sys.stdin.readline

def load_image(path):
    img = Image.open(path).convert("L")
    arr = np.asarray(img, dtype=np.float32).flatten()
    return arr

def normalize(x):
    m = x.mean()
    s = x.std() + 1e-8
    return (x - m) / s

# assume images are named "1.png" ... "50.png"
X = []
for i in range(1, 51):
    x = load_image(f"{i}.png")
    x = normalize(x)
    X.append(x)

X = np.array(X)

labels = []
with open("labels.txt", "r") as f:
    for line in f:
        labels.append(int(line.strip()))

labels = np.array(labels)

class0 = X[:20][labels == 0]
class1 = X[:20][labels == 1]

cent0 = class0.mean(axis=0)
cent1 = class1.mean(axis=0)

out = []
for i in range(20, 50):
    v = X[i]
    d0 = np.sum((v - cent0) ** 2)
    d1 = np.sum((v - cent1) ** 2)
    out.append(1 if d1 < d0 else 0)

print("\n".join(map(str, out)))
```加载步骤将每个图像转换为一致的灰度向量，以便所有样本都位于相同的特征空间中。 归一化可确保分类不受全局亮度差异的影响。 质心计算将每个类压缩为单个代表向量，从而稳定了噪声训练数据。 

在预测过程中，每个测试图像仅与两个向量进行比较，这消除了各个训练样本引入的方差。 平方欧几里得距离就足够了，因为我们只比较相对大小。 

一个常见的实现错误是忘记一致地展平图像，这会导致 NumPy 中的形状不匹配或意外广播。 另一个微妙的问题是跳过归一化，这可能导致亮度高的图像主导距离计算。

 ## 边缘情况

 关键的边缘情况是图像中的所有像素具有几乎相同的值。 如果没有归一化，此类图像可能由于大小而不是结构而主导欧几里德距离。 归一化后，这些向量会分解为接近于零的方差向量，从而使它们可以根据相对结构而不是尺度进行比较。 

当训练样本在两个类别之间不平衡时，会出现另一种边缘情况。 如果一类的样本较少，其质心就会变得不太稳定。 平均仍然有效，但方差增加，这会稍微降低分类置信度。 质心方法仍然避免了灾难性的错误分类，因为它聚合而不是记住单个点。 

最后的边缘情况是测试图像类似于两个类别的混合。 在这种情况下，到两个质心的距离可能非常近。 平局决胜规则默认始终为一侧（0 类或 1 类），这确保即使在不明确的情况下也能确保确定性输出。
