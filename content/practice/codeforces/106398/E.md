 ## 解决方案
 ## 问题理解

 我们给出了一个大小为的矩形网格$N \times M$。 在这个网格内，我们构建了一个由同心矩形“环”组成的结构。 每个环占据前一个环内较小矩形的周长，并且在连续的环之间有一个宽度恰好为一个单元格的强制空边框。 每个环的边界几乎都充满了灌木丛，但边界上只有一个单元格留空作为入口。 

第一环是整个网格的外边界。 第二个环向内放置一个单元，第三个环向内放置另一个单元，依此类推。 由于周围空荡荡的走廊，每一个新环相对于前一个环都会消耗两行和两列的收缩。 

如果我们最多建造的话，我们被要求计算使用多少灌木丛$K$环，但我们可能无法将所有$K$如果网格变得太小。 在这种情况下，我们只构建最大数量的有效环，并且每个环内仍保留至少一个内部单元。 

每个有效环贡献其周长减一（因为一个单元格是没有灌木丛的入口）。 

约束条件允许$N, M, K$最多$3 \cdot 10^9$，因此任何解决方案都必须在恒定时间内运行。 任何对环进行迭代的模拟都是不可能的，因为环的数量可能达到数十亿。 该解决方案必须依赖于每个环的直接算术特征。 

当网格变得太小而无法容纳另一个具有内部空闲单元的完整矩形时，就会出现微妙的边缘条件。 例如，如果构建一个环后，剩余的内部矩形是$1 \times M$或者$2 \times 2$，那么即使$K$更大。 

## 方法

 直接的方法是逐环模拟。 对于每个环，我们将矩形在两个维度上缩小 2，计算其周长，为入口减去 1，然后累加。 我们停止时$K$环已构建，或者剩余的矩形不能包含有效的内部区域。 

这是正确的，但成本与环数成线性关系。 在最坏的情况下，每个环只会稍微减小尺寸，因此我们最多可以有大约$1.5 \cdot 10^9$迭代。 即使每次迭代使用恒定时间算术，这也远远超出了时间限制。 

关键的观察是每个环完全由其索引决定。 这$i$第一个环（从 0 开始索引）是矩形的周长，其大小为：$$(N - 2i) \times (M - 2i)$$仅当两个维度都至少为 1 时，环才有效，更重要的是，内部要求意味着环内至少有一个自由单元，因此我们需要：$$N - 2i \ge 3,\quad M - 2i \ge 3$$这给出了环数的硬上限：$$i < \frac{N-1}{2}, \quad i < \frac{M-1}{2}$$所以环数为：$$R = \min\left(K, \left\lfloor \frac{N-1}{2} \right\rfloor, \left\lfloor \frac{M-1}{2} \right\rfloor\right)$$一次$R$已知，我们将每个环的贡献相加。 这$i$-th 环的周长：$$2(N - 2i) + 2(M - 2i) - 4$$我们将入口减去 1，所以：$$4(N + M - 4i) - 4 - 1 = 4(N + M - 4i) - 5$$因此我们计算一个简单的算术级数$i = 0 \ldots R-1$。

 | --- | --- | --- | --- |

 ## 算法演练

 我们计算在网格崩溃之前可以存在多少个完整的环。 

1. 计算几何体允许的最大可能层数为$\left\lfloor\frac{N-1}{2}\right\rfloor$和$\left\lfloor\frac{M-1}{2}\right\rfloor$。 这确保了每个选定的环仍然保留至少一个内部空间。 
2. 设置$R$到最小值$K$以及这两个几何极限。 这会将所需的环数限制为实际适合的环数。 
3. 计算所有环的总贡献。 每个环的周长减去一个入口单元，这与环指数线性相关$i$。 
4. 重写总和：$$\sum_{i=0}^{R-1} (4N + 4M - 16i - 5)$$作为常数之和加上总和$i$。 
5. 使用算术级数公式进行评估：$$R(4N + 4M - 5) - 16 \cdot \frac{R(R-1)}{2}$$### 为什么它有效

 每个环都是独立的，除了其尺寸减小之外，其尺寸减小与环指数呈线性关系。 几何结构保证一旦环无效，所有更深的环也无效，因为这两个维度严格每层减少 2。 这种单调收缩将问题转化为有效环的单个连续前缀。 由于每个环都贡献其索引的线性函数，因此总数成为封闭形式的算术和，从而无需进行模拟。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input())
    M = int(input())
    K = int(input())

    R = min(K, (N - 1) // 2, (M - 1) // 2)

    if R <= 0:
        print(0)
        return

    # sum of (4N + 4M - 16i - 5)
    total = R * (4 * N + 4 * M - 5)
    total -= 16 * (R * (R - 1) // 2)

    print(total)

if __name__ == "__main__":
    solve()
```代码首先确定有多少层是可行的。 表达式`(N - 1) // 2`和`(M - 1) // 2`捕获向内偏移的最大数量，使得环仍然具有至少 1 个单元的内部。 减 1 可确保像这样的退化情况$3 \times 3$网格只允许有一个环。 

求和使用从分割环贡献的常数和线性部分导出的封闭式表达式。 期限`R * (R - 1) // 2`对应于索引的总和$0 + 1 + \dots + (R-1)$，这是唯一的非常数部分。 

必须小心整数运算，因为值可以达到大约$10^{19}$，但 Python 可以安全地处理这个问题。

 ## 边缘情况

 一个关键的边缘情况是网格仅足以容纳一个环而不是两个环。 拿$N = 4$,$M = 4$,$K = 10$。 公式给出：$$R = \min(10, 1, 1) = 1$$仅外环有效。 内部$2 \times 2$区域不能满足另一环至少有一个内部自由单元的要求，因此必须将其排除。 计算自然地通过以下方式强制执行此操作：$(N-1)//2$和$(M-1)//2$界限。 

另一种微妙的情况是当一个维度最小时，例如$N = 3$,$M$大的。 即使$M$允许许多收缩步骤，垂直约束占主导地位，防止出现多个环。 该算法正确地优先考虑了更严格的维度。 

最后，当$K = 0$或极大，表达式为$R$正确夹紧，确保没有负环，也没有超出几何可行性的溢出。
