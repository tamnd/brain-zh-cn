 ## 解决方案
 ## 问题理解

 我们得到一排精神排队，每个都有一个初始高度。 两个观察者从两端观察这个队列，但他们每个人都有一个非常具体的可见性规则。 

从左端开始，尤巴巴从左向右扫描，只有当一个灵魂的高度严格大于她已经见过的每个灵魂时，她才会注意到这个灵魂。 从右端开始，白做了同样的事情，但从右向左扫描，再次只注意到一个灵魂，如果它严格大于他从他身边看到的所有东西。 

一个灵魂可以被任何一个观察者注意到，如果两个观察者都注意到它，它仍然只被计算一次。 我们可以精确地选择一种精神并将其高度任意更改为任何正整数。 目标是在这一单一修改后，最大限度地增加两个观察者中至少​​一个观察者注意到的不同烈酒的数量。 

关键限制是 n 可以大到 200000，因此任何尝试直接重新计算每个可能修改的可见性的解决方案都会太慢。 对所有候选对象进行二次或三次模拟是不可能的，甚至在每次更改后重新计算可见性的 O(n^2) 也会远远超出限制。 

天真的思维的一个微妙的失败案例是假设答案只是前缀最大值加上后缀最大值减去重叠的数量。 这一想法忽略了改变一个元素可以以非局部方式重塑前缀和后缀最大值链。 例如，如果数组严格增加，则最初只有一个精神可见，但增加精心选​​择的元素可能会突然从两侧引入多个新的可见元素。 

另一种边缘情况是最大值位于中间时。 例如，在`[1, 10, 2, 3, 4]`，两个观察者都已经看到了几个元素，但是调整`10`可以销毁或创建多个可见性事件，具体取决于其更改方式。 

挑战在于理解单个值的变化如何同时影响前缀最大值和后缀最大值的结构。 

## 方法

 可见性规则本质上是关于创纪录的高点。 从左边，Yuubaaba 准确地看到了前缀 maxima。 从右边，Haku 准确地看到了后缀最大值。 因此，被注意到的精灵的总数就是前缀最大值位置和后缀最大值位置的并集的大小。 

无需修改，我们可以在线性时间内计算这两个集合。 

蛮力法就是把每一个指标都当作修改后的精神来尝试，尝试所有可能的新高度。 对于每个这样的配置，我们在 O(n) 中重新计算前缀和后缀最大值集，并采用最佳答案。 由于索引有 n 个选择，并且可能有 O(n) 相关高度选择，即使将我们自己限制在有意义的高度，这很快就会变成 O(n^2) 或更糟，这对于 2e5 来说太慢了。 

关键的见解是我们实际上不需要任意的高度选择。 重要的是修改后的元素如何参与前缀和后缀最大值链。 它要么变得无关紧要，要么成为一条新记录，可以桥接两个以前独立的可见性区域。 

如果我们查看数组，前缀最大值在某些位置形成严格递增的值序列，而后缀最大值形成另一个这样的序列。 这两个序列的结合定义了所有当前可见的灵魂。 增加此并集的唯一方法是使所选元素成为前缀段、后缀段或两者中的新最大值，从而可能合并两个可见性边界。 

这将问题简化为了解通过在一个位置插入单个新值可以创建多少个新的前缀最大值和后缀最大值。 

对于每个位置，我们可以考虑使该元素从左侧向上到某个点以及从右侧向下到某个点可见的最佳可能高度。 这导致了一个特征：最佳的新值通常会略高于分段中的某个现有最大阈值，因为超出该阈值的任何额外增加都不会改变可见性结构。 

我们可以预先计算前缀最大值和后缀最大值。 然后，对于每个位置，我们会推断如果强制该位置成为主导某个区间的新最大值，我们将获得多少新的可见元素。 

最后的优化是实现可见点的结构将数组划分为连续的前缀最大值和后缀最大值之间的段，并且修改一个元素最多可以合并或扩展一个这样的段边界。 因此，我们只需要评估从这些边界导出的少量关键配置，而不是所有值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) 或更糟 | O(n) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们首先计算两个数组。 一个存储每个位置是否是前缀最大值，另一个存储是否是后缀最大值。 这些可以分别在单个前向和后向传递中计算。 

然后，我们将基线答案计算为前缀最大值或后缀最大值的位置数。 

接下来，我们考虑如果我们修改单个位置 i 会发生什么。 重要的观察结果是，只有 i 右侧的前缀最大值结构和 i 左侧的后缀最大值结构会受到此更改的影响。 距离已经严格大于我们可以分配的任何值的所有东西都不会受到影响。 

对于固定的 i，我们考虑使 a[i] 足够大以超过所有前缀最大值，直到左侧的某个边界。 这保证了 i 成为新的前缀最大值。 类似地，我们可以使其相对于右侧后缀最大值足够大，使其成为后缀最大值。

我们计算这种影响在两个方向上传播的距离。 在左侧，我们查找 i 之前的最后一个前缀最大值，在右侧，我们查找 i 之后的第一个后缀最大值。 如果我们将 a[i] 升级到两个相关阈值之上，它可能会连接两个之前独立的可见性链。 

我们评估每个 i 变得可见的新位置的数量，因为 i 现在充当桥梁最大值。 我们将其与基线答案进行比较并保留最大值。 

最后，我们输出所有 i 的最佳值，包括不修改任何内容的选项。 

为什么它有效

 每个可见位置都对应于至少一个方向的破纪录值。 一次修改只能从左侧引入一个新记录链，从右侧引入一个新记录链，并且这些链在支配阈值方面是连续的。 由于前缀和后缀最大值是单调结构，因此修改元素创建的任何新可见性都必须锚定在 i 处并扩展，直到被下一个更大的原始值阻止。 此限制确保修改的效果完全由 i 周围的局部最大值边界决定，因此扫描所有 i 并评估其引起的边界扩展足以找到最佳增益。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    pref = [False] * n
    suf = [False] * n
    
    mx = -10**18
    for i in range(n):
        if a[i] > mx:
            pref[i] = True
            mx = a[i]
    
    mx = -10**18
    for i in range(n - 1, -1, -1):
        if a[i] > mx:
            suf[i] = True
            mx = a[i]
    
    base = 0
    for i in range(n):
        if pref[i] or suf[i]:
            base += 1
    
    # precompute next greater prefix/suffix boundaries
    # next prefix max to left, previous suffix max to right
    left_bound = [-1] * n
    last = -1
    for i in range(n):
        if pref[i]:
            last = i
        left_bound[i] = last
    
    right_bound = [n] * n
    last = n
    for i in range(n - 1, -1, -1):
        if suf[i]:
            last = i
        right_bound[i] = last
    
    ans = base
    
    for i in range(n):
        gain = 1
        
        if left_bound[i] != -1:
            gain += (i - left_bound[i] - 1)
        else:
            gain += i
        
        if right_bound[i] != n:
            gain += (right_bound[i] - i - 1)
        else:
            gain += (n - i - 1)
        
        ans = max(ans, gain)
    
    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先使用线性扫描来识别所有前缀和后缀最大值位置。 这些直接对应于最初从每一面可见的灵魂。 

基线计数是通过这两个集合的并集来计算的。 

然后，我们构建辅助数组，将最近的前缀最大值定位到每个位置的左侧，并将最近的后缀最大值定位到每个位置的右侧。 这些边界定义了新增强的元素在被现有更强记录阻挡之前可以扩展可见性的程度。 

对于每个索引，我们模拟使其成为其区域中的主导元素。 增益公式计算如果该元素成为两个方向上的下一个记录打破者，则左侧和右侧有多少不可见的元素将变得新可见。 所有位置的最大值得出最终答案。

 ## 边缘情况

 一个单元素数组，例如`[5]`表明两个观察者看到相同的精神，因此联合大小为 1 并且任何修改都不能增加它。 该算法可以处理此问题，因为前缀和后缀扫描都将唯一位置标记为最大值，并且不会从边界计算增益。 

在严格递增的数组中，例如`[1,2,3,4,5]`，每个元素都是一个前缀最大值，因此基线已经是最大值。 左右边界计算崩溃到完全覆盖，并且每次模拟修改都会产生零个额外的看不见的元素。 

在严格递减的数组中，例如`[5,4,3,2,1]`，每个元素都是后缀最大值，从正确的扫描中产生相同的完整覆盖。 该算法正确地识别出没有内部间隙需要桥接，因此无需修改即可提高联合大小。
