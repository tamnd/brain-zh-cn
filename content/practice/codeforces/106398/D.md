 ## 解决方案
 ## 问题理解

 我们给出了一个大小为的矩形网格$N \times M$。 仓鼠从左上角的单元格开始，以 45 度角沿对角线右下移动，标记每个访问过的单元格。 每当它到达侧壁（左边界或右边界）时，它就会像完美的弹跳一样反射，并继续沿着相反的对角线方向移动。 底部边界缺失，因此一旦仓鼠到达或越过底部边缘，它就会离开网格，并且过程停止。 

任务不是连续模拟物理，而是准确确定在弹跳对角线行走过程中访问了哪些网格单元，并输出 ASCII 绘图。 每个访问过的单元格都标有`*`，并且每个未访问的单元格是`#`。 

约束条件允许$N, M \le 500$，因此网格最多有 250,000 个单元。 逐个单元的直接模拟已经可行，但需要更仔细的观察，以避免不必要的复杂化和潜在的无限弹跳逻辑错误。 

关键的边缘行为是左右边界的反射。 幼稚的心智模型可能会尝试连续的几何运动，但网格性质意味着路径始终保持在整数坐标上，并且仅在遇到垂直边界时才改变方向。 

当发生微妙的边缘情况时$N = 1$或者$M = 1$。 在这些情况下，仓鼠要么立即向下退出，要么以退化的方式反复反映。 例如，如果$N = 1, M = 5$，仓鼠从 (0, 0) 开始并立即退出，因为对角线移动在第一步就从底部出来了。 任何假设至少一次反射的解决方案都会在这里失败。 

另一个极端情况是当$N$或者$M$为 1 并且边界反射逻辑没有得到适当的保护。 粗心的实现可能会尝试多次反转方向或在网格之外进行索引。 

## 方法

 蛮力方法就是逐字逐句模拟仓鼠的运动。 我们保持当前的位置和方向，最初向右下方移动。 在每一步中，我们都会标记当前单元格，然后尝试沿对角线移动。 如果下一个位置超出左边界或右边界，我们翻转水平方向并继续。 当下一个垂直步长超过时我们停止$N - 1$。 

该模拟是正确的，因为运动规则是确定性的并且仅取决于局部边界条件。 然而，每一步只移动一个单元格，在最坏的情况下，仓鼠可能会以之字形模式遍历所有单元格，可能会访问$O(NM)$步骤。 虽然这仍然符合约束条件，但实现在方向翻转和终止条件方面很容易出现相差一的错误。 

关键的观察结果是路径不会不可预测地分支或重新访问； 它是带有反射的单个确定性对角线遍历。 这意味着模拟在复杂性方面已经是最佳的，但通过直接编码方向变化和边界处理而无需任何几何推理，可以使实现变得非常干净。 

因此，我们保留模拟，但将其视为网格行走，其方向向量仅在水平墙上翻转，并且仅在离开底部时终止。

 ## 算法演练

 我们将仓鼠视为在具有方向状态的整数坐标上移动的点。 

1.初始化一个大小为2D的网格$N \times M$充满`#`。 这代表未受影响的细胞。 我们将覆盖访问过的单元格`*`当仓鼠穿过它们时。 
2. 从位置开始$(r, c) = (0, 0)$和方向$(dr, dc) = (1, 1)$，意思是右下。 这与问题中描述的 45 度对角线运动相匹配。 
3. 标记当前单元格$(r, c)$通过将其设置为访问`*`。 这确保了在做出任何移动决定之前记录仓鼠占据的每个位置。 
4.尝试移动到下一个单元格$(r + dr, c + dc)$。 在进行移动之前，请检查水平边界：

 如果$c + dc < 0$或者$c + dc \ge M$，通过设置翻转水平方向$dc = -dc$，并重新计算下一列。 

此步骤模拟垂直墙壁上的反射。 我们在这里不改变行方向，因为弹跳只影响左右运动。 
5、解决水平反射后，检查下一行位置是否$r + dr$超过或等于$N$。 如果是这样，仓鼠就会从底部退出，模拟就会停止。 
6. 如果移动有效，则更新$(r, c)$到下一个位置并从步骤 3 开始重复。 
7. 继续，直到触发终止条件。 

该循环保证每次迭代都会使仓鼠沿着有效的对角线路径向前移动一个单元格，或者在离开网格时立即终止。 

### 为什么它有效

 不变的是，在每一步中，当前单元格恰好是 45 度格子行走所访问的单元格之一，并且在垂直边界上具有完美反射。 方向向量$(dr, dc)$始终对反射之间的路径段的正确局部坡度进行编码。 由于反射仅取决于列边界，并且不会改变行增量符号，因此通过翻转可以完全捕获运动$dc$当需要时。 

由于每次移动都会严格将行索引增加 1，因此该过程必须在最多之后终止$N$步骤，每个访问的位置对应一个唯一的行。 因此，不会错误地跳过或重新访问任何单元格，并且生成的标记是准确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [['#'] * m for _ in range(n)]

    r, c = 0, 0
    dr, dc = 1, 1

    while True:
        grid[r][c] = '*'

        nr = r + dr
        nc = c + dc

        if nc < 0 or nc >= m:
            dc = -dc
            nc = c + dc

        if nr >= n:
            break

        r, c = nr, nc

    for row in grid:
        print(''.join(row))

if __name__ == "__main__":
    solve()
```该实现直接反映了前面描述的模拟。 网格初始化为`#`，并且每个访问过的单元格都会被覆盖`*`。 

方向变量`dr`和`dc`对对角线运动进行编码。 仅有的`dc`在反射期间发生变化，这可以防止向下运动逻辑的意外损坏。 

在计算暂定的下一行之后进行终止检查。 这确保了在退出之前仍然标记了最后一个有效位置，这是必要的，因为仓鼠在接触底部边界后立即离开。

 ## 边缘情况

 对于$1 \times 1$，算法从 (0,0) 开始，对其进行标记，并立即将下一行计算为 1，超过$N$，所以它退出。 不发生反射，输出为单个`*`。 

为了$1 \times M$，同样的逻辑适用。 仓鼠根本无法向下移动，因此它只标记起始单元格并退出。 任何尝试首先计算水平反射的实现仍然是安全的，因为在提交移动之前会检查行终止。 

为了$N \times 1$，水平反射变得无关紧要，因为任何水平移动都会立即翻转方向，但仍然会产生同一列。 该路径实际上变成了一条向下的直线，标记了唯一列中的每个单元格，直到退出。
