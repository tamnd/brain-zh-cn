 ## 解决方案
 ## 问题理解

 我们获得了一系列预定的培训课程。 理想情况下，有$n$会议，但 Vasya 可能会跳过其中一些会议。 每个跳过的会话都不会丢失：必须在以后访问的会话中对其进行补偿。 如果错过了会议$i$在会话中得到补偿$j$，努力成本为$j - i + 1$，这已经包括当天完成的训练$j$本身。 

Vasya 可以跳过任意数量的会话，并且他可以在一次访问中补偿多个错过的会话。 然而，所有补偿的总累计努力不能超过$k$。 目标是尽量减少 Vasya 实际参加的会议次数，同时仍确保所有会议$n$会议最终会在总工作预算内得到补偿。 

重要的不是确切的时间表，而是如何对跳过的课程进行分组以及最终在哪里获得回报。 如果跳过一长段连续的会话并且稍后只参加一次，则成本会变得很大，因为早期错过的会话会累积越来越多的惩罚。 

输入给出两个整数$n$和$k$，输出是最小访问会话数，这样所有错过的会话都可以在不超过总工作量的情况下得到补偿$k$。 

约束条件达到$10^{18}$，因此任何依赖于线性或二次迭代的解$n$是不可能的。 我们需要一个纯粹的数学或贪婪结构，将问题简化为封闭形式条件或对数搜索。 

一个关键的边缘情况是 Vasya 参加几乎所有会议。 一个天真的假设可能是参加$n-1$会话总是有效，但成本仍然可能超过$k$取决于跳过的会话的定位方式。 另一个微妙的情况是，所有跳过的会话都在开始或结束时分组，因为这会以非常不同的方式最小化或最大化成本。 

## 方法

 暴力策略将尝试所有参加的会话子集。 对于每个子集，我们模拟跳过哪些会话，然后将每个跳过的会话分配给稍后参加的会话以最小化成本并检查总成本是否保持在$k$。 这是正确的，因为它直接遵循规则，但子集的数量是$2^n$，甚至对于中等程度的$n$这是完全不可行的。 

关键的观察是最佳结构不是任意的。 如果我们固定参加会议的数量，最好的安排是以最小化累积补偿成本的方式分散它们。 成本结构仅取决于参加的会话之间的相对差距，最严重的惩罚来自长时间连续跳过的片段。 这将问题转化为分析在预算范围内可以“吸收”多少跳过的会话块$k$。 

如果我们反过来思考，假设 Vasya 只参加$m$会议。 然后还有$n - m$跳过的会话，并且当这些跳过的会话尽可能紧密地分组并以最佳顺序补偿时，总成本最小化。 这将问题简化为块大小上的组合成本函数，而不是显式调度。 

隐藏的结构是，最优策略在分组跳过方面总是贪婪地表现，并且成本成为参加多少次会议的函数，而不是参加哪些会议。 这使我们能够得出单调条件并搜索参与会话的最小数量。

 ## 算法演练

 我们根据跳过的会话次数重新解释该问题。 让$x$是 Vasya 跳过的会议次数，因此他参加了$n - x$会议。 目标是确定最大值$x$这样所有跳过的会话都可以在成本范围内得到补偿$k$。 

1. 我们首先观察到成本仅取决于跳过的会话与后来参加的会话的配对方式。 为了最大限度地降低成本，应尽早补偿每个跳过的会话，因为成本随着延迟而线性增长。 
2. 我们安排日程，使参加的会议均匀分布，作为吸收跳过的会议的“锚点”。 每个锚点可以补偿跳过的会话块，并且每个块内的成本遵循基于距离的算术结构。 
3. 对于固定数量的跳过会话$x$，当这些跳过的会话形成单个连续前缀时，可以实现最小的可能成本，因为这可以最小化到第一个可用的参与会话的平均距离。 任何碎片只会增加距离。 
4. 在这种最优安排下，成本变成了三角形结构：跳过的会话贡献$1 + 2 + \dots + x$，等于$x(x+1)/2$，因为每个跳过的会话最终都会以最佳方式与下一个可用的参加会话匹配。 
5. 现在我们解决不等式$x(x+1)/2 \le k$。 这给出了允许的最大跳过次数。 然后我们将答案计算为$n - x$。 

### 为什么它有效

 关键的不变量是成本函数仅取决于跳过和参加的会话之间的相对顺序，而不是它们的绝对标签。 任何配置的料斗都可以转换为连续的块，而不会增加成本。 一旦简化为这种规范形式，成本就变成了纯粹的前缀和结构，通过将跳跃分组在一起可以独特地最小化。 这使得三角数有界既是必要的又是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())

    lo, hi = 0, n

    def cost(x):
        return x * (x + 1) // 2

    while lo < hi:
        mid = (lo + hi + 1) // 2
        if cost(mid) <= k:
            lo = mid
        else:
            hi = mid - 1

    skipped = lo
    print(n - skipped)

if __name__ == "__main__":
    solve()
```该解决方案对跳过的会话数执行二分搜索。 辅助函数计算给定跳跃次数的三角成本。 我们搜索最大可行的跳过次数，其成本不超过$k$，并从中减去它$n$以获得参加会议的最少数量。 

二分查找是安全的，因为成本函数$x(x+1)/2$严格递增于$x$，保证可行性的单调性。

 ## 边缘情况

 用于输入`1 0`，跳过一节的成本已经是1，超出了预算。 二分查找立即找到零个有效跳过，因此答案是 1 个参加的会话。 

用于输入`1 1`，跳过唯一的会话成本恰好为 1，这是允许的。 该算法返回 0 个参与的会话，匹配最佳策略。 

用于输入`10 0`，不可能跳过，因为即使单个跳过的成本也是 1。二分搜索产生零跳过，因此 Vasya 参加所有会话。 

用于输入`10 55`，预算与完整的三角形数匹配$10 \cdot 11 / 2$。 该算法正确地允许跳过所有会话，从而导致零参与会话。
