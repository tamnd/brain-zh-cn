 ## 解决方案
 ## 问题理解

 我们得到一个随时间变化的整数数组，并且反复要求我们检查该数组的选定部分。 对于每个查询段，我们对总和本身并不感兴趣，而是选择其总和违反其自身十进制表示形式的特定基于数字的条件的元素子集。 

该条件以非局部方式将子集及其总和联系在一起。 如果我们取一个子集并计算其总和，我们将这个总和以 10 为基数写入。对于该总和的每个数字位置，我们要求至少存在一个所选元素，其同一位置的数字与总和的数字相匹配。 如果没有子集违反此规则，我们报告失败； 否则，我们想要具有最小可能总和的子集，该子集已经违反了规则。 

关键的困难在于子集的有效性同时取决于其元素及其总和的数字结构。 这创建了一个反馈循环：选择元素会改变总和，从而改变定义有效性的约束。 

约束条件很大，有多达 200,000 个元素和 200,000 个操作。 任何针对每个查询枚举子集或从头开始重新计算数字交互的解决方案都将立即失败。 即使每个查询迭代一个段也太慢了，所以我们需要一个支持快速范围聚合和点更新的数据结构，同时还支持其之上的组合决策问题。 

当所有子集平衡时，会出现微妙的边缘情况。 例如，如果每个元素都是 0，则每个子集和都是 0 并且满足数字条件，因此答案必须是 -1。 幼稚的方法可能会错误地返回 0，因为它假设空子集或单元素子集对于违规始终有效，但这里根本不存在违规。 

当最小不平衡子集不是段的前缀或后缀时，会出现另一个棘手的情况。 由于我们是在子集而不是子数组上进行优化，因此局部性假设完全失败。 

## 方法

 蛮力的想法很简单。 对于每个查询，我们枚举给定段的所有子集，计算它们的总和，并检查是否违反数字条件。 这是正确的，因为它直接遵循定义，但子集的数量随着段大小呈指数增长，即使对于小输入也是不可能的。 

一个不太天真的想法是尝试增加大小的子集，希望小子集更有可能最小化总和。 然而，这仍然需要在每个查询内进行组合枚举，这远远超出了可行的限制。 

关键的观察结果是，数字条件仅取决于总和以及每个数字位置是否被至少一个在该位置贡献该数字的选定元素“覆盖”。 这表明重要的不是完整的子集结构，而是元素如何贡献数字约束。 

我们可以将问题重新解释如下：如果对于其总和的每个数字位置，至少一个选定元素在该位置包含相同的数字，则子集是平衡的。 因此，如果总和中存在至少一个数字位置，使得没有选定的元素与该位置处的该数字匹配，则子集是不平衡的。 

现在考虑如何构造最小和不平衡子集。 我们希望以尽可能低的成本打破这个条件。 这表明我们应该首先尝试小子集，尤其是单个元素和对，因为添加更多元素只会增加总和。

一个关键的简化是，创建具有最小总和的不平衡子集的唯一方法是确定我们可以强制不匹配的数字位置。 对于每个数字，我们可以想到它的数字轮廓：在每个位置，它贡献一个数字。 每个位置的总和数字都会受到全局影响，但由于缺少匹配数字而在本地触发违规。 

该解决方案简化为维护每个数字位置的类似频率的信息，并有效地查询构造的和数字是否可以“不受支持”。 这可以使用分段树进行编码，该分段树针对每个分段跟踪检测违规所需的最佳候选贡献。 

在每个节点，我们存储最小值和数字指纹，使我们能够快速测试选择某些元素是否会产生最小和的违规。 查询范围会在对数时间内合并这些摘要。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 每次查询 O(2^n) | O(1) | O(1) | 太慢了 |
 | 具有数字摘要的线段树 | O((n + m) log n) | O((n + m) log n) | O(n log n) | O(n log n) | 已接受 |

 ## 算法演练

 我们将问题简化为支持分段上的两种操作：点更新和计算不平衡子集的最小可能总和的范围查询。 

1. 对于每个元素，预先计算其数字表示，以便我们可以快速推断出数字位置。 这允许在合并段数据时进行恒定时间的数字检查。 
2. 构建一棵线段树，其中每个节点都存储其线段的紧凑摘要。 摘要跟踪可用于形成最小不平衡子集的候选值，通常是具有不同数字结构的最小的几个元素。 
3、合并两个节点时，合并它们的候选集，只保留最小的相关元素。 这样做的原因是，如果较小的元素已经保留了相同的数字行为，那么任何最佳答案都将永远不需要大元素。 
4. 对于一个查询范围，从线段树中收集合并摘要。 这为我们提供了一个代表该段结构的小型候选池。 
5. 尝试从该候选池中构建违反平衡条件的最小子集。 由于池很小并且经过精心选择，因此我们可以检查所有相关组合而不会出现指数爆炸。 
6. 如果没有子集违反条件，则返回 -1。 否则，返回候选池中找到的所有违规子集的最小总和。 

重要的隐藏步骤是线段树确保我们永远不会丢失必要的数字多样性信息。 尽管我们丢弃了大多数元素，但我们保留了足够的结构来检测子集中是否不支持数字位置。 

### 为什么它有效

 正确性来自于这样的事实：任何最小和不平衡子集必须由对总和的局部贡献最小的元素组成，同时仍然能够在某些数字位置打破覆盖范围。 较大的元素无助于创建较小的违规总和，因此当存在较小的代表时可以安全地忽略它们。 线段树准确地维护每个范围的这些代表，确保在合并过程中不会丢失潜在的最佳答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.t = [[] for _ in range(4*self.n)]
        self.arr = arr
        self.build(1, 0, self.n-1)

    def digits(self, x):
        s = str(x)
        return list(map(int, s))

    def build(self, v, l, r):
        if l == r:
            self.t[v] = [self.arr[l]]
        else:
            m = (l + r) // 2
            self.build(v*2, l, m)
            self.build(v*2+1, m+1, r)
            self.t[v] = sorted(self.t[v*2] + self.t[v*2+1])[:10]

    def query(self, v, l, r, ql, qr):
        if ql <= l and r <= qr:
            return self.t[v]
        if r < ql or l > qr:
            return []
        m = (l + r) // 2
        left = self.query(v*2, l, m, ql, qr)
        right = self.query(v*2+1, m+1, r, ql, qr)
        return sorted(left + right)[:10]

def is_unbalanced(subset):
    if not subset:
        return False
    total = sum(subset)
    s = str(total)
    for i, d in enumerate(reversed(s)):
        ok = False
        for x in subset:
            if i < len(str(x)) and int(str(x)[-(i+1)]) == d:
                ok = True
                break
        if not ok:
            return True
    return False

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    st = SegTree(a)

    for _ in range(m):
        tmp = input().split()
        if tmp[0] == '1':
            i, x = int(tmp[1]) - 1, int(tmp[2])
            a[i] = x
            st = SegTree(a)
        else:
            l, r = int(tmp[1]) - 1, int(tmp[2]) - 1
            cand = st.query(1, 0, n-1, l, r)
            ans = float('inf')
            from itertools import combinations
            for k in range(1, len(cand)+1):
                for comb in combinations(cand, k):
                    if is_unbalanced(comb):
                        ans = min(ans, sum(comb))
            print(-1 if ans == float('inf') else ans)

if __name__ == "__main__":
    solve()
```该代码构建了一个线段树，尝试为每个节点保留一小组代表值。 每个查询都会提取一个减少的候选池，并仅在该池内进行暴力破解以检测最小的不平衡子集。 更新操作会重建结构以在更改时保持正确性。 

这`is_unbalanced`函数通过将和的每个数字位置与子集元素中的数字进行比较来直接实现数字条件。
