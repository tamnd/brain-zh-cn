 ## 解决方案
 ## 问题理解

 我们有一排立方体，每个立方体都涂有 _m_ 种颜色，并且我们最多可以删除 _k_ 个立方体，以最大化所有具有相同颜色的连续立方体段的长度。 输入提供立方体数量_n_、颜色数量_m_、最大删除_k_以及立方体颜色的序列。 输出是一个整数：删除最多 _k_ 个立方体后单一颜色的最长连续段的长度。 

主要挑战是数组可能很大，最多可达 2·10^5 立方体，因此任何解决方案都必须在 _n_ 中大致呈线性或线性对数。 尝试所有子数组或所有删除模式的二次方法是不可行的，因为在最坏的情况下它们将涉及多达 4·10^10 次操作。 颜色的数量也可能很大，最多 10^5，因此使用大量每种颜色操作迭代所有颜色的解决方案必须小心以保持效率。 

容易错误处理的边缘情况包括 _k_ 为零时，在这种情况下无法删除任何立方体，因此算法必须正确找到最长的现有连续段。 另一种情况是所有立方体的颜色相同； 无论 _k_ 是多少，最高分数都是 _n_。 如果 _k_ 很大但不足以删除所有其他颜色，则算法仍必须正确考虑最多 _k_ 的删除。 小序列、具有交替颜色的序列以及仅具有两种颜色的序列也很微妙，因为幼稚的实现可能会错误计数或错位删除。 

## 方法

 暴力方法会考虑序列的每个子数组，并针对每种颜色，计算需要删除多少个立方体才能使该子数组完全具有该颜色。 然后它会跟踪最大的子数组，其中所需的删除最多为_k_。 虽然原则上是正确的，但这种方法在最坏的情况下是 O(n^2·m)：有 O(n^2) 个子数组，对于每个子数组，我们可能会检查所有颜色。 对于 n = 2·10^5 来说这太慢了。 

关键的见解是我们只关心单一颜色的连续片段。 对于任何固定颜色_c_，我们可以将立方体不是颜色_c_的位置视为可能被删除的“间隙”。 然后问题就简化为找到最长的子数组，其中非_c_立方体的数量不超过_k_。 这可以使用两指针或滑动窗口技术有效地解决：维护一个窗口 [l, r] 并计算其中的非_c_ 立方体。 只要非_c_立方体的个数≤k就扩大右端，当个数超过k时就将左端向前移动。 我们对序列中存在的所有颜色重复此操作。 

这种方法之所以有效，是因为两指针窗口始终为给定颜色维护最大连续段，最多删除 _k_ 次。 由于我们只考虑颜色与 _c_ 不同的位置，因此计算与每种颜色的序列长度呈线性关系。 唯一颜色的数量最多为 _m_，因此总复杂度为 O(n·m_unique)，其中 m_unique 是实际存在的不同颜色的数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2·m) | O(n^2·m) | O(1) | O(1) | 太慢了 |
 | 每种颜色的滑动窗口 | O(n·m_unique) | O(n·m_unique) | O(n) | 已接受 |

 ## 算法演练

 1. 计算序列中唯一颜色的数量并迭代每种颜色_c_。 每种颜色将被独立处理，以找到如果我们专注于它的话可实现的最大连续段。 
2.初始化两个指针，`l`和`r`，在序列的开始处。 这些指针定义当前正在考虑的立方体的滑动窗口。 维护一个柜台`bad`对于窗口中不是颜色_c_的立方体。 
3. 展开右侧指针`r`逐个。 如果立方体在位置`r`不是颜色_c_，增量`bad`。 
4. 如果`bad`超过`k`, 增量`l`从左侧缩小窗口直到`bad`再次≤k。 如果离开窗口的立方体不是颜色_c_，则递减`bad`。 
5. 在每一步，更新全局最大值`best`与当前窗口的大小（`r - l + 1`）。 
6. 处理完一种颜色的所有位置后，移至下一种颜色。 所有颜色处理完毕后，`best`包含最多 _k_ 次删除可达到的最大分数。 

工作原理：在任何时刻，窗口都包含颜色 _c_ 的最大连续子数组，可以通过 ≤ k 次删除来形成。 不变的是`bad`始终精确计算当前窗口中非 _c_ 立方体的数量。 扩大或缩小窗口可确保我们永远不会超过允许的删除次数，并且扫描所有颜色可确保我们找到绝对最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m, k = map(int, input().split())
colors = list(map(int, input().split()))

from collections import Counter
unique_colors = set(colors)

best = 0

for c in unique_colors:
    l = 0
    bad = 0
    for r in range(n):
        if colors[r] != c:
            bad += 1
        while bad > k:
            if colors[l] != c:
                bad -= 1
            l += 1
        best = max(best, r - l + 1)

print(best)
```该解决方案迭代所有独特的颜色，使用滑动窗口来跟踪当前段内有多少个非目标颜色立方体。 每当该计数超过 _k_ 时，窗口的左端就会向前移动，直到该段再次有效。 每个窗口大小与全局最大值进行比较`best`，它累积所有颜色中最大的有效段。 使用一组独特的颜色可以避免对数组中不存在的颜色进行不必要的迭代。
