 ## 解决方案
 ## 问题理解

 我们被要求确定适用于给定数字的整除规则的类型`d`在给定的基础上`b`。 这些类型分为 2 类、3 类、11 类、6 类或 7 类，具体取决于是否可以仅使用最后几位数字（2 类）、数字之和（3 类）、数字交替和（11 类）、2 类和 3 类的组合（6 类）或这些都不能检查整除性（7 类）。 输入由两个整数组成：基数`b`和除数`d`。 输出必须说明类型，对于 2 类型，还必须说明验证整除性所需的最后一位数字的最小数量。 

限制条件`2 ≤ b, d ≤ 100`意味着我们可以负担得起复杂度高达`O(d log b)`或者`O(b * d)`不用担心性能，因为即使最坏的情况也将是 10,000 次左右的操作。 检查每个小于的数字的幼稚方法`d`在基地`b`因为整除性是可行的，但没有必要，因为整除性规则具有可预测的结构。 

不明显的边缘情况包括作为基数幂的除数，例如`b`本身，应该是只有 1 位数字的 2 类型，以及类似的数字`11`在某些适用 11 类型规则的碱基中，但 3 类型规则也可能适用，具体取决于碱基。 例如，在基数 2 中，被 3 整除遵循 11 类型规则而不是 3 类型规则，因为基数 2 中的数和方法简化为交替和。 

## 方法

 暴力方法将尝试检查用固定数量的基数最后一位数字表示的所有数字的整除性`b`。 对于 2 类型，我们将迭代`k = 1, 2, 3…`并检查是否`b^k`可以整除`d`或者可以覆盖所有模余数`d`。 对于 3 类型，我们可以尝试检查是否`d`划分`b-1`（或者`b+1`对于 11 类型），因为数字和规则推广到基数`b`使用几何级数公式：任意数`N`表示为基数中的数字`b`满足`N = a_0 + a_1*b + a_2*b^2 + … ≡ a_0 + a_1 + … (mod b-1)`。 同样，11型依赖于`b+1`。 一旦我们按顺序 (2, 3, 11, 6) 测试每种类型，第一个匹配的就是答案。 如果没有匹配，则为 7 类型。 

关键的见解是 2 型整除性对应于仅与 共享因子的除数`b`（或权力`b`), 3-类型对应于除数`b-1`，11型对应于除数`b+1`。 当 2 型和 3 型因素同时存在时，就会出现混合 6 型。 这避免了迭代所有数字并将问题简化为简单的模检查。

 ## 算法演练

 1. 阅读基础`b`和除数`d`。 
2. 通过分解出所有幂来检查 2 类规则`b`从`d`。 计算`k`这样`b^k`涵盖以因子为模的所有留数`d`互质于`b`。 如果在移除所有权力后`b`其余因子为1，为纯2型。 
3. 通过验证是否检查 3 类规则`d`互质于`b`并划分`b-1`。 这是从基数中的数字和属性得出的`b`。 如果是，则返回 3 类型。 
4. 通过验证是否检查 11 类规则`d`划分`b+1`。 这对应于交替数字和属性。 
5. 如果2型和3型条件同时成立，则报告6型。 
6. 如果以上都不成立，则将 7 类型报告为“神秘”规则。 

为什么有效：分类取决于众所周知的数论属性。 被底数的因数整除只需要最后一位数字，被底数的因数整除`b-1`遵循数字之和，以及`b+1`遵循交替数字和。 这保证了无需枚举数字的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

b, d = map(int, input().split())

def check_2_type(b, d):
    k = 1
    while pow(b, k, d) != 0:
        k += 1
    return k

def main():
    x = d
    # check 2-type: divide out gcd with base
    g = 1
    while x % b == 0:
        x //= b
        g *= b
    if x == 1:
        k = check_2_type(b, d)
        print("2-type")
        print(k)
        return
    # check 3-type: divides b-1
    if (b-1) % d == 0:
        print("3-type")
        return
    # check 11-type: divides b+1
    if (b+1) % d == 0:
        print("11-type")
        return
    # check 6-type: combination of 2-type and 3-type
    # already covered 2-type or 3-type separately, only possible if d divisible by both factors
    if (d % b == 0 or b % d == 0) and (b-1) % d == 0:
        print("6-type")
        return
    print("7-type")

main()
```这`check_2_type`函数找到测试整除性所需的最后一位数字的最小数量`d`在基地`b`通过求模求幂`d`。 我们首先减少`d`通过以下因素`b`看看它是否是纯2型的。 对于 3 型和 11 型，可除性测试`b-1`和`b+1`利用数字和和交替数字和规则。 6 类型由混合因素隐式处理。 否则，我们会退回到 7 型。
