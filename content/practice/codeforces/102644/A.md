 ## 解决方案
 ## 问题理解

 该问题描述了一个人的情绪只有两种可能的状态：快乐和悲伤。 每一秒，当前的心情都有概率发生变化`p`，或者概率保持不变`1 - p`。 我们从快乐状态开始，需要找到这个人在恰好之后再次快乐的概率`n`秒。 

输入包含模拟的秒数以及一秒钟内改变情绪的概率。 所需的输出是在这些之后最终感到幸福的概率`n`过渡。 

的价值`n`可以达到`10^9`，这立即排除了每秒的模拟。 直接模拟需要每秒执行一次操作，即使是线性解决方案在最坏的情况下也需要十亿次更新。 该概率具有简单的二态结构，因此解决方案必须使用有效处理重复转换的方法，将操作数量从成比例减少到`n`与位数成正比`n`。 

主要的实施陷阱来自于较大的值`n`以及正确处理概率。 例如，使用输入`1 0.7`，答案是`0.3`因为在一秒钟后仍然快乐的唯一方法就是不改变情绪。 粗心的实施可能会返回`0.7`将切换概率视为最终的快乐概率。 

另一个常见错误出现在以下情况：`n`是均匀的。 用于输入`2 0.1`，答案是`0.82`，因为如果切换两次或者根本不切换，心情就是快乐的。 仅考虑每秒保持不变的概率的解决方案将计算`0.81`错过偶数次转换后回归幸福的路径。 

## 方法

 最直接的方法是记录每一秒之后感到快乐和悲伤的概率。 最初，幸福的概率是`1`悲伤的概率是`0`。 每一秒，我们都会使用转换规则更新这两个值。 如果当前幸福概率为`h`悲伤的概率是`s`，那么下一个快乐的概率是`h * (1 - p) + s * p`，而下一个悲伤的概率是`h * p + s * (1 - p)`。 

该方法是正确的，因为它直接遵循概率转移。 问题在于转换的数量。 什么时候`n`是`10^9`，这需要十亿次更新，这远远超出了可用时间。 

关键的观察是，每一秒都会对这对概率应用相同的变换。 多次重复相同的变换正是矩阵求幂有用的情况。 我们可以将一个转换表示为 2 x 2 矩阵，并计算该矩阵的幂`n`使用二进制求幂。 

暴力破解之所以有效，是因为每一秒都是同一转换规则的独立应用，但当秒数变得太大时，就会失败。 观察到转移本身可以表示为矩阵，让我们可以应用所有`n`对数时间的转变。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 太慢了 |
 | 最佳| O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 构建描述一秒钟情绪变化的转换矩阵。 

如果当前状态表示为列向量`[happy, sad]`，一个转换将其更改为：```
[1-p  p] [happy]
[ p  1-p] [sad]
```该矩阵包含两种状态之间的每种可能的转移概率。 
2. 计算该转移矩阵的幂`n`使用二进制求幂。 

而不是将矩阵乘以状态向量`n`多次，我们重复对矩阵求平方。 当一点点`n`设置后，该平方矩阵就有助于得出最终答案。 
3. 将所得矩阵应用到初始状态。 

初始状态是`[1, 0]`因为这个人开始快乐。 乘以矩阵后得到`n`次方，所得向量的第一个分量是幸福的概率。 

为什么它有效：

 转移矩阵精确地代表了该过程的一秒。 矩阵乘法结合了转换，因此将矩阵与其自身相乘`n`times 代表执行转换`n`次。 二进制求幂使用重复平方计算相同的矩阵幂，这保留了精确的数学含义，同时减少了运算次数。 由于初始状态向量是已知的，因此最终的乘法提取出所有转换后快乐的确切概率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def multiply(a, b):
    return [
        [
            a[0][0] * b[0][0] + a[0][1] * b[1][0],
            a[0][0] * b[0][1] + a[0][1] * b[1][1],
        ],
        [
            a[1][0] * b[0][0] + a[1][1] * b[1][0],
            a[1][0] * b[0][1] + a[1][1] * b[1][1],
        ],
    ]

def power(matrix, n):
    result = [[1.0, 0.0], [0.0, 1.0]]
    while n > 0:
        if n & 1:
            result = multiply(result, matrix)
        matrix = multiply(matrix, matrix)
        n >>= 1
    return result

def solve():
    n, p = input().split()
    n = int(n)
    p = float(p)

    transition = [
        [1.0 - p, p],
        [p, 1.0 - p],
    ]

    result = power(transition, n)

    answer = result[0][0]
    print("{:.10f}".format(answer))

solve()
```这`multiply`函数执行两个 2 x 2 矩阵的乘法。 由于矩阵总是这么小，直接编写四个表达式可以避免不必要的循环。 

这`power`函数从单位矩阵开始，因为它表示应用零转换。 在二进制求幂期间，每个设置位`n`将转换矩阵的相应幂添加到答案中。 在每一位之后对矩阵进行平方可以让我们跳过大范围的转换。 

最终的矩阵代表了所有`n`运动的秒数。 因为初始状态是`[1, 0]`，只有结果矩阵的第一列重要，并且位置处的值`[0][0]`是幸福结局的概率。 

浮点精度就足够了，因为所需的误差仅为`10^-6`。 Python 整数不参与求幂结果，因此不存在溢出问题。

 ## 边缘情况

 对于一秒的情况`1 0.7`，算法创建矩阵：```
[0.3 0.7]
[0.7 0.3]
```指数为 1，因此矩阵不是平方的。 答案是左上角的值，`0.3`，它正确地表示在一次转变后保持快乐。 

对于两秒的情况`2 0.1`，该算法对转移矩阵求平方，因为指数由二进制值表示`10`。 平方矩阵包含所有两步路径的组合概率，包括切换两次和根本不切换。 它的左上角值变为`0.82`。 

对于非常大的值，例如`1000000000 0.5`，每个转变都有相同的改变或停留的概率。 在任意正数秒之后，快乐的概率恰好为`0.5`。 二进制求幂无需一秒一秒地迭代即可得到这个答案。 

对于非常小的概率，例如`10 0.000001`，如果不小心执行，重复乘法可能会失去准确性。 矩阵方法以标准浮点算术进行计算，并避免减去几乎相等的大值，从而产生在所需公差范围内的结果。
