 ## 解决方案
 ## 问题理解

 我们维护一串大写字母和问号。 问号以后可以变成任何大写英文字母。 从左到右读取字符串会改变利马克的情绪，它只有两种可能的状态：快乐和悲伤。 目标是计算在处理整个字符串后有多少次所有问号的替换让 Limak 满意。 每次更新单个字符后，必须再次打印相同的计数。 限制很大：字符串长度和更新次数都可以达到200000，因此每次更新后扫描整个字符串的解决方案在最坏的情况下将执行大约40000000000次操作，这远远超出了正常比赛的限制。 问题陈述和限制来自 Codeforces Gym 102644H。 

重要的是情绪只有两种状态。 我们不需要记住前缀的整个历史，只需要记住一个片段可以通过多少种方式将传入情绪转换为传出情绪。 这个小的状态空间使我们能够动态地维护答案。 

一个常见的错误是独立对待问号，只计算单独好的字母。 这会失败，因为字母会通过当前情绪相互作用。 例如，使用字符串`A?`，正确答案是`6`。 第一个`A`从快乐到悲伤，所以第二个角色必须让心情再次变得快乐。 如果一个粗心的解决方案独立地计算每个位置的有效字母，就会错过这种依赖性。 

另一种边缘情况是某个段根本没有任何影响。 对于输入：```
1 1
B
1 A
```输出是：```
19
18
```

`B`是一封保持心情不变的信，而`A`翻转它。 仅计算翻转次数而忽略中性选择数量的解决方案将给出错误的结果。 

第三种边缘情况是仅由问号组成的字符串。 为了：```
2 0
??
```答案是`403`。 必须考虑每一对可能的字母，包括第一个字母让利马克悲伤而第二个字母修复情绪的组合。 任何仅跟踪当前快乐前缀数量的方法都将失去这些可能性。 

## 方法

 暴力解决方案很简单。 对于每个问号，尝试所有 26 个字母，模拟情绪变化，并计算以快乐状态结束的替换。 这是正确的，因为它准确地检查了可能的字符串集。 但是，如果有 200000 个问号，则可能的字符串数量为`26^200000`，所以即使产生其中的一小部分也是不可能的。 

更好的方向来自于观察每个角色只执行两种状态之间的转换。 字符串的一段可以用 2 x 2 矩阵表示。 行描述起始情绪，列描述最终情绪，每个值存储有多少个替换可以使该转换成为可能。 当两个片段连接时，它们的矩阵会相乘，因为第一个片段选择中间情绪，第二个片段从中继续。 

单个字符有一个小的固定矩阵。 例如，问号会考虑所有 26 个可能的字母，并将每个字母对适当转换的贡献相加。 整个字符串成为这些矩阵的乘积。 由于更新仅影响一个位置，因此线段树可以存储范围的乘积并仅重新计算受更新影响的节点的对数数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(26^x * n) 其中 x 是问号 | O(n) | 太慢了 |
 | 最佳| O(n) 构建后每次更新 O(log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将每个字符表示为 2 x 2 转换矩阵。 第一行和第一列对应于开始的快乐或悲伤状态，第二个维度表示结束状态。 单元格中的值是创建该转换的字符选择数。 
2. 构建一棵线段树，其中每个叶子存储一个字符的矩阵。 内部节点存储其两个子节点的乘积。 使用矩阵乘法是因为左子级描述首先发生的情况，右子级描述随后发生的情况。 
3. 最初的答案是开始快乐和结束快乐的方式数。 这是树根部从 happy 到 happy 的矩阵条目。 
4. 对于每次更新，替换已更改字符的叶矩阵。 重新计算所有祖先，直到到达根。 只有 O(log n) 个节点依赖于一个位置，因此更新很快。 
5. 重建路径后，打印根矩阵中存储的新的 happy to happy 值。 

工作原理：线段树的不变性是每个节点都存储其区间的精确转移矩阵。 一片叶子是正确的，因为它直接描述了一个字符。 如果两个孩子是正确的，则将他们的矩阵相乘会考虑左侧间隔之后的每种可能的情绪以及右侧间隔的每个延续，因此父母也是正确的。 通过归纳，根代表整个字符串，其 happy 到 happy 条目正是所需的计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7

def multiply(a, b):
    return [
        [
            (a[0][0] * b[0][0] + a[0][1] * b[1][0]) % MOD,
            (a[0][0] * b[0][1] + a[0][1] * b[1][1]) % MOD
        ],
        [
            (a[1][0] * b[0][0] + a[1][1] * b[1][0]) % MOD,
            (a[1][0] * b[0][1] + a[1][1] * b[1][1]) % MOD
        ]
    ]

def char_matrix(c):
    res = [[0, 0], [0, 0]]
    for x in range(26):
        ch = chr(ord('A') + x)
        if ch in "AEIOU":
            res[0][1] += 1
            res[1][0] += 1
        elif ch == "H":
            res[0][0] += 1
            res[1][1] += 1
        elif ch in "SD":
            res[0][1] += 1
            res[1][1] += 1
        else:
            res[0][0] += 1
            res[1][1] += 1
    if c != "?":
        res = [[0, 0], [0, 0]]
        if c in "AEIOU":
            res[0][1] = 1
            res[1][0] = 1
        elif c == "H":
            res[0][0] = 1
            res[1][1] = 1
        elif c in "SD":
            res[0][1] = 1
            res[1][1] = 1
        else:
            res[0][0] = 1
            res[1][1] = 1
    return res

def solve():
    n, q = map(int, input().split())
    s = list(input().strip())

    size = 1
    while size < n:
        size *= 2

    tree = [[[1, 0], [0, 1]] for _ in range(2 * size)]

    for i, c in enumerate(s):
        tree[size + i] = char_matrix(c)

    for i in range(size - 1, 0, -1):
        tree[i] = multiply(tree[i * 2], tree[i * 2 + 1])

    ans = [str(tree[1][0][0])]

    for _ in range(q):
        i, c = input().split()
        i = int(i) - 1
        pos = size + i
        tree[pos] = char_matrix(c)
        pos //= 2
        while pos:
            tree[pos] = multiply(tree[pos * 2], tree[pos * 2 + 1])
            pos //= 2
        ans.append(str(tree[1][0][0]))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```矩阵乘法函数组合两个连续的区间。 顺序很重要，因为左侧间隔先于右侧间隔读取。 反转乘法顺序将向后描述字符串。 

这`char_matrix`函数处理固定字母和问号。 对于问号，它以所有可能的大写字母开头并累积它们的转换。 状态索引假设状态`0`意味着快乐和状态`1`意味着悲伤，所以最终答案总是存储在`[0][0]`。 

线段树使用两倍大小的幂来简化索引。 额外的叶子表示空段并使用单位矩阵，因为乘以空段不应改变任何转换计数。 Python 整数不会溢出，但每个乘法结果都会模数减少`10^9+7`保持较小的值。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n + q log n) | O(n + q log n) | 构建树会触及每个角色一次，并且每次更新都会更改一条从根到叶的路径。 |

 ## 边缘情况

 对于字符串`A?`，该算法创建一个矩阵`A`只允许从快乐到悲伤的过渡，然后将其与问号矩阵结合起来。 最后的快乐到快乐条目仅计算第二个角色修复情绪的替换，产生`6`。 

对于单个字符更新情况：```
1 1
B
1 A
```这棵树只包含一片有意义的叶子。 更换叶子会立即改变根部。 答案从`19`到`0`因为`A`总是翻转最初的快乐状态。 

对于全问号字符串，每个叶子包含所有 26 个可能的转换之和。 线段树乘法使两种中间情绪保持活力，因此暂时变得悲伤的路径不会被丢弃。 这就是为什么两个字符的大小写给出`403`而不是只计算立即快乐的选择。
