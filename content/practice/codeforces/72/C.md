 ## 解决方案
 ## 问题理解

 我们被要求确定是否为正整数$x$非常好。 根据问题的定义，如果一个数字的偶数除数与奇数除数的数量完全相同，那么该数就非常好。 输入是单个整数$x$介于 1 和 1000 之间。如果数字非常好，则输出只是“是”，否则输出是“否”。 

看看约束条件，$x \le 1000$很小。 这意味着我们可以考虑直接计算每个数字的除数，而不会遇到性能问题。 每个号码$x$最多有$\sqrt{x}$用于检查因式分解的除数，以及$1000 \times \sqrt{1000}$大约有 32,000 次操作，对于 2 秒的时间限制来说微不足道。 因此，效率并不是这里的主要问题，但聪明的洞察力将极大地简化解决方案。 

1 出现边缘情况。它唯一的除数是它本身，它是奇数。 因此，1 并不是特别好。 另一个微妙的场景是 2 的任何幂：除数都是 1、2、4 等，计算偶数和奇数需要仔细注意。 例如，2 有约数 {1, 2}（一个奇数，一个偶数），因此它符合条件。 任何大于 1 的奇数都会比偶数拥有更多的奇数除数，因为 1 始终是奇数，并且乘以一个奇数会产生另一个奇数除数。 

理解这些模式可以使问题变得简单：只有当一个数是 2 的幂时，它才会非常好，因为只有这样，偶数除数才能“平衡”单个奇数除数 1。 

## 方法

 蛮力方法是迭代从 1 到$x$，检查每个是否是$x$，并计算有多少个偶数和多少个奇数。 这个方法既简单又正确。 为了$x=1000$，最坏情况下的运算计数大致为除数的数量，对于 1000 以下的数字，实际上约为 32。虽然可行，但该方法做了额外的工作：我们不需要除数的精确列表，只需要偶数和奇数的模式。 

关键的洞察力是考虑因素$x$作为$2^k \cdot m$在哪里$m$很奇怪。 奇数除数完全来自$m$（包括 1），偶数因数来自 2 的幂与除数的乘积$m$。 为了使偶数因数的数量等于奇数因数的数量，$m$必须是 1。这将问题简化为检查是否$x$是 2 的幂，使用重复除以 2 的简单运算。 

这一观察结果将暴力计数问题转化为使用除法或按位运算的直接检查。 这里的优雅在于认识到除数的结构特性：仅 2 的幂就可以满足“非常好”的条件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(√x) | O(1) | O(1) | 已接受此问题，但没有必要 |
 | 2 次方检查 | O(log x) | O(1) | O(1) | 最优、优雅、被接受|

 ## 算法演练

 1.读取整数$x$。 这是我们需要测试的数字。 
2.初始化临时变量$y = x$。 这可以避免修改输入。 
3、反复划分$y$偶数时增加 2。 每个除法去掉一个因数 2。 
4. 循环结束后，检查是否$y$等于 1。如果是，$x$是2的纯幂，非常好。 
5. 否则，$y$包含一个大于1的奇因数，即奇数因数的个数超过偶数因数的个数，所以$x$不是特别好。 
6. 如果出现则打印“yes”$x$非常好，否则就是“不”。 

该算法之所以有效，是因为 2 的幂恰好有一个奇数除数 1，并且所有其他除数都是偶数，与幂计数形成一对一匹配。 如果存在任何大于 1 的奇数因数，则奇数因数多于偶数因数，从而破坏条件。 这个不变量保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

x = int(input())
y = x

while y % 2 == 0:
    y //= 2

if y == 1:
    print("yes")
else:
    print("no")
```我们使用`y`作为工作副本以避免修改`x`。 这`while`循环去掉 2 的所有幂`y`。 如果`y`变为 1，不存在奇数因子，确认$x$是 2 的幂。使用整数除法`//`确保我们停留在整数空间，避免微妙的浮点错误。 

## 工作示例

 **示例 1：x = 2**

 | 步骤| y | y%2==0？ | 行动|
 | ---| ---| ---| ---|
 | 1 | 2 | 真实| y //= 2 → y = 1 |
 | 2 | 1 | 假 | 退出循环 |

 查看`y == 1`→ 真 → 输出：“是”。 这表明 2（它的约数为 {1,2}）非常好。 

**示例 2：x = 6**

 | 步骤| y | y%2==0？ | 行动|
 | ---| ---| ---| ---|
 | 1 | 6 | 真实| y //= 2 → y = 3 |
 | 2 | 3 | 假 | 退出循环 |

 查看`y == 1`→ 假 → 输出：“否”。 6 有约数 {1,2,3,6}； 奇数除数 {1,3} = 2，偶数除数 {2,6} = 2。等等，看起来相等。 但除数是：奇数2，偶数2。实际上，这是“是”。 嗯，我们仔细考虑一下：

 6 的约数：{1,2,3,6}。 奇数：{1,3} → 2。偶数：{2,6} → 2。偶数个数 = 奇数个数 = 2。 

啊，这是一个例外：像 6 这样的数字不是 2 的幂，但仍然具有相等的偶数和奇数约数。 所以我之前关于 2 的幂的主张需要改进。 

让我们细化观察：

 - 让$x = 2^a \cdot m$,$m$奇怪的。 
- 奇数除数来自奇数除法$m$。 数数：$\tau(m)$, 的约数个数$m$。 
- 偶数除数来自 2^k (k ≥ 1) 与除数的乘积$m$。 计数：a * τ(m)？ 事实上，它更微妙。 

更好的方法：计算所有除数，按奇偶校验分割。 对于小$x \le 1000$，暴力计数是安全的。 

新的安全最优算法：将 i 从 1 迭代到 sqrt(x)，检查 i 是否整除 x。 准确计算奇数和偶数因数。 如果计数相等，则返回“yes”。 这可以避免错误分类。 

## Python 解决方案（暴力破解，适用于所有情况）```python
import sys
input = sys.stdin.readline

x = int(input())
odd = 0
even = 0

for i in range(1, x + 1):
    if x % i == 0:
        if i % 2 == 0:
            even += 1
        else:
            odd += 1

print("yes" if odd == even else "no")
```我们明确检查所有除数。 这可以避免丢失像 6 这样的数字，其中偶数和奇数除数平衡，但该数字不是 2 的幂。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(x) | 循环遍历 1..x 来查找除数 |
 | 空间| O(1) | O(1) | 只需两个柜台 |

 给定$x \le 1000$，这完全在 2 秒的时间限制内。 

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    odd = 0
    even = 0
    x = int(input())
    for i in range(1, x + 1):
        if x % i == 0:
            if i % 2 == 0:
                even += 1
            else:
                odd += 1
    return "yes" if odd == even else "no"

# provided sample
assert run("2\n") == "yes", "sample 1"

# custom cases
assert run("1\n") == "no", "minimum input, only odd divisor"
assert run("6\n") == "yes", "balanced divisors"
assert run("8\n") == "no", "power of 2 > 2, odd divisors = 1, evens = 3"
assert run("9\n") == "no", "odd number, all divisors odd"
```
