 ## 解决方案
 ## 问题理解

 该问题描述了助教办公时间内学生排队等待的情况。 德雅知道有`n`学生们在排队，但她不记得自己的具体位置。 她只知道，至少`x`学生们最多站在她面前`y`学生们站在她身后。 任务是计算队列中有多少位置可以满足这两个条件。 

队列中的位置是单索引的。 如果 Deja 处于位置`p`，那么有`p - 1`她之前的人和`n - p`追随她的人。 我们需要计算每个值`p`其中两个条件都成立：`p - 1 >= x`和`n - p <= y`约束条件`n <= 1,000,000`告诉我们输入大小足够大，不需要重复检查复杂的条件。 线性扫描已经可以接受，因为一百万次操作很小，但不等式的结构允许更简单的恒定时间解决方案。 任何尝试模拟队列或生成所有可能的排列的方法都在解决比所需大得多的问题。 

主要边缘情况来自队列末端附近的位置。 靠近前面的位置可能会失败，因为领先的学生太少，而靠近后面的位置可能会失败，因为太多的学生落后。 

例如：```
4 2 1
```可能的位置是 3 和 4。位置 2 在 Deja 之前只有一名学生，因此无效。 一个粗心的解决方案，只检查后面的人数，可能会错误地计算出来。 

另一种情况是：```
5 1 4
```从 2 到 5 的每个位置都是有效的，给出输出：```
4
```位置 1 必须被拒绝，因为没有人在 Deja 之前。 仅检查后面学生上限的解决方案将错误地包含第一个位置。 

## 方法

 一个简单的方法是尝试从`1`到`n`。 对于每个位置`p`，我们计算有多少人在 Deja 之前，有多少人在她之后。 如果两个值都满足要求，我们就增加答案。 这是有效的，因为每个有效位置都会被检查一次。 

问题是这是不必要的工作。 队列最多可以包含一百万个位置，因此扫描已经超出了所需的工作量，更复杂的强力解释只会使情况变得更糟。 这两个条件都是简单的不等式，所以我们可以直接求出有效位置的区间。 

第一个条件给出：`p - 1 >= x`这意味着：`p >= x + 1`第二个条件给出：`n - p <= y`这意味着：`p >= n - y`这两个条件都是该位置的下限。 有效位置是从这两个下限中较大者到`n`。 

观察结果是，答案并未分散在队列中。 它形成一个连续的区间，因为将 Deja 向后移动只会增加前面的人数并减少后面的人数。 一旦一个职位生效，以后的每个职位也都有效。

 ## 算法演练

 1. 根据前方学生的情况计算最早可能的位置。 因为必须至少有`x`Deja之前的学生，她的位置必须至少是`x + 1`。 
2. 根据落后学生的情况，计算出最早可能的位置。 因为最多可以有`y`在她之后的学生，她的位置必须至少是`n - y`。 
3. 取这两个值中较大的一个作为第一个有效位置。 该位置满足两个下限。 
4. 计算从第一个有效位置到队列末尾剩余的位置数。 答案是`n - first_valid + 1`。 

为什么它有效：

 有效头寸仅由头寸指数的下限确定。 任何小于计算起点的位置都会违反至少一项要求。 任何等于或大于它的位置在 Deja 之前都有足够的学生且不超过`y`在她之后的学生，所以最后间隔中的每个位置都是有效的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, x, y = map(int, input().split())

    first_valid = max(x + 1, n - y)

    print(n - first_valid + 1)

if __name__ == "__main__":
    solve()
```该程序读取三个值并将两个要求转换为 Deja 位置的界限。 变量`first_valid`存储第一个可以工作的位置。 

使用`max`是核心步骤。 一个位置必须满足这两个限制，因此它必须满足两个下限中更严格的一个。 

最终表达式包含位置计数。 如果第一个有效位置是`first_valid`，位置是：`first_valid, first_valid + 1, ..., n`其中包含`n - first_valid + 1`价值观。 这`+1`是容易发生相差一错误的常见地方。

 ## 边缘情况

 对于输入：```
4 2 1
```第一个条件要求位置至少为`3`。 第二个条件要求位置至少为`3`以及。 该算法从位置 3 开始计数并返回 2，它与有效位置 3 和 4 匹配。 

对于输入：```
5 1 4
```第一个条件要求位置至少为`2`。 第二个条件给出`5 - 4 = 1`，但第一个条件更严格。 该算法选择位置 2 并对位置 2、3、4 和 5 进行计数，产生正确答案 4。 

对于输入：```
2 1 1
```唯一可能的位置是第二个。 该算法计算`max(2, 1)`作为第一个有效位置并返回`2 - 2 + 1 = 1`。 这证实了包含计数公式正确地处理了最小间隔。
