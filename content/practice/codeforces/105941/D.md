 ## 解决方案
 ## 问题理解

 我们得到一个代表年份的整数，我们需要确定它是否满足一个非常具体的数字属性。 如果两个条件同时满足，则该年份有效。 首先，年份本身必须是完全平方数，这意味着存在一个其平方等于年份的整数。 其次，当我们对年份的十进制数字求和时，该和也必须是完全平方数。 

输入的大小非常小，年份范围为 999,999。 这立即排除了诸如繁重的预处理或高级数据结构之类的事情。 任何重复执行平方检查或数字处理的解决方案在限制范围内执行仍然很简单，因为我们只处理一个数字，或者如果扩展的话最多处理几个测试用例。 

唯一微妙的情况来自完美方形检查管理不善。 一个常见的错误是使用浮点平方根而不纠正精度误差。 另一个问题是忘记了数字总和只能在 0 这样的理论情况下为零，这在这里不相关，因为年份至少为 1。第三个问题是假设如果数字看起来像方形图案，那么它一定是 1，对于像 999999 这样的值来说会失败，如果实施不当，可能会出现舍入错误或不正确的整数检查。 

具体的边缘情况是样本 999999。数字总和是 54，这不是一个完美的平方，因此答案是否定的，即使该数字接近一个大平方并且可能会引发错误的启发式。 另一个是 2025，它运行得很好，因为 2025 等于 45 的平方，数字和是 9 等于 3 的平方。 

## 方法

 最直接的方法是计算该数是否是完全平方数，然后分别计算其各位数字之和，并检查该和是否也是完全平方数。 这很简单，因为两个操作都是 O(log y)。 唯一重要的组成部分是方格检查。 

检查数字 n 是否为完全平方数的一种强力方法是尝试从 1 开始的所有整数 i 并测试 i 的平方是否等于 n。 这可以正常工作，但没有必要，因为最大可能的平方根最多为 1000，因为 1000 的平方为 1,000,000，略高于约束限制。 尽管这种蛮力已经很小，但它在概念上是较差的，因为它忽略了平方根的直接数学结构。 

更好的方法是使用内置整数 sqrt 或二分搜索来计算 n 的整数平方根，然后验证对其进行平方是否会重现 n。 这完全避免了浮点问题并提供了确定性检查。 

通过十进制表示一次计算数字和，然后再次应用相同的平方校验逻辑。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力开方扫描 | O(√n) | O(√n) | O(1) | O(1) | 已接受但没有必要 |
 | 整数开方检验 + 数字和 | O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取整数 y 作为输入。 这是我们直接评估的候选年。 
2. 通过重复提取最后一位数字并累加来计算 y 的数字和。 这给出了一个次要数字 s，它捕获了年份的加法结构。 
3. 使用整数算术计算 r = Floor(sqrt(y))。 然后验证 r * r 是否等于 y。 如果不是，则 y 不是完全平方，我们可以立即拒绝它。 此步骤避免了浮点精度问题。 
4. 对 s 重复相同的平方验证。 计算 t = Floor(sqrt(s)) 并检查 t * t 是否等于 s。 这确保了数字和在结构上也是完美的平方。 
5. 如果两项检查都通过则输出 Yes，否则输出 No。 

### 为什么它有效

正确性取决于两个独立的特征。 一个数是完全平方当且仅当它的整数平方根在平方后能够再现原始值。 这完全避免了近似错误，因为所有运算都是基于整数的。 数字和变换与平方性质无关，因此单独验证它不会干扰第一个条件。 由于这两个条件各自都是充分必要的，因此它们的结合完全符合问题要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_square(x: int) -> bool:
    if x < 0:
        return False
    r = int(x ** 0.5)
    return r * r == x or (r + 1) * (r + 1) == x

y = int(input().strip())

digit_sum = 0
tmp = y
while tmp > 0:
    digit_sum += tmp % 10
    tmp //= 10

if is_square(y) and is_square(digit_sum):
    print("Yes")
else:
    print("No")
```功能`is_square`使用浮点平方根，但通过检查两者来纠正可能的舍入错误`r`和`r+1`。 这很重要，因为由于大正方形附近的精度限制，从浮点直接转换有时会被截断。 数字和计算是迭代完成的，以避免字符串转换开销，尽管考虑到限制，任何一种方法都是可以接受的。 

最终条件直接组合这两个检查，满足两个属性必须同时保持的逻辑要求。

 ### 示例 1：2025

这些痕迹表明，排斥反应可以在任何一种情况下独立发生。

 ## 边缘情况

 最小的有意义输入是 1。该算法将数字和计算为 1，并正确地将两个条件识别为 true，因为 1 是完全平方数。 

对于 2，数字和为 2，平方检验立即失败。 平方检查使用整数比较，因此没有浮点错误可以将其错误地分类为平方。 

对于 16，该数字通过了平方测试，因为 4 的平方是 16，但数字和变为 7。第二次检查正确地拒绝了它。 

对于 81，两项检查都顺利通过。 平方根是 9，数字和也是 9，都减少到 3 的平方。 这证实了独立检查不会干扰，并且必须同时满足两者。
