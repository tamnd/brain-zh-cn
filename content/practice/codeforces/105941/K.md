 ## 解决方案
 ## 问题理解

 我们给定一个长度序列$n$，其中每个元素都是范围内的整数$[0, m-1]$。 允许的关键操作是全局循环移位：我们选择一个整数$k$，以及每个元素$a_i$被替换为$(a_i + k) \bmod m$。 这种移位均匀地应用于整个阵列，因此元素之间的相对差异保持不变，只有它们在模环上的绝对位置发生变化。 

每个整数贡献一个独立定义的值：我们将数字转换为其十进制表示形式，并为每个数字分配固定的“孔数”，然后将这些值与数字的所有数字相加。 数组的总分是所有元素的孔数之和。 应用轮班后$k$，我们重新计算这个分数并希望获得最大可能值$k \in [0, m-1]$。 

输入大小限制意味着两者$n$和$m$可以大到$2 \cdot 10^5$。 这立即排除了尝试每个班次并从头开始重新计算完整数组分数的任何解决方案$O(n)$，因为这会导致$O(nm)$，太大了。 即使每个班次稍微优化重新计算仍然太慢。 

第二个重要方面是，价值并不是对头寸的任意权重； 它们仅取决于移位后的数字值。 这使得结构高度规则：每个元素都只在大小的循环环上贡献一个位置$m$，而移位只是将所有贡献轮换在一起。 

一个天真的但微妙的错误是假设移位后元素之间是独立的，例如通过预先计算每个元素的最佳单独移位。 但这会失败，因为必须同时将相同的全局移位应用于所有元素。 另一个常见的陷阱是将问题视为独立地移动重新分配值，而不是全局旋转频率分布。 

为了使这个具体化，假设$m = 5$数组是$[1, 3, 3]$。 错误的方法可能会分别计算每个元素的最佳移位，但是移位$k = 1$一次将所有值更改为$[2, 4, 4]$，并且分数取决于此联合配置，而不是每个元素的优化。 

## 方法

 蛮力的想法很简单：对于每一个可能的转变$k$，计算变换后的数组并对孔数求和。 对于每个$k$，这需要$O(n)$，并且有$m$轮班、给予$O(nm)$。 和$n, m \le 2 \cdot 10^5$，这导致$4 \cdot 10^{10}$在最坏的情况下进行操作，这是不可行的。 

为了改进这一点，我们重新组织计算。 我们不再考虑元素移动的问题，而是翻转视角，考虑围绕大小圆圈流动的贡献$m$。 让$cnt[x]$是价值的多少倍$x$出现，并让$f[x]$是整数的孔数$x$。 换档后通过$k$，每次出现的值$x$移动到$x+k \bmod m$, 贡献$f[x+k]$。 所以班次的总分$k$变为循环相关：$$g[k] = \sum_{x=0}^{m-1} cnt[x] \cdot f[(x+k) \bmod m]$$这是一个类似循环卷积的结构。 关键的见解是$g$可以使用标准卷积技巧有效地计算：通过扩展数组并在双倍域上使用单个卷积，将循环依赖关系转换为线性依赖关系。 一旦我们计算了线性卷积，每个循环移位和就可以通过卷积输出上的滑动窗口和来恢复。 

这将问题简化为计算一个大小约为$2m$，这可以在$O(m \log m)$在实践中使用 FFT 或 NTT 风格的方法（这里 FFT 在概念上就足够了）。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(nm)$|$O(m)$| 太慢了|
 | 卷积（FFT）|$O(m \log m)$|$O(m)$| 已接受 |

 ## 算法演练

 1.统计数组中每个值出现的次数放入数组中$cnt$尺寸的$m$。 这将输入压缩为频率表示，这已经足够了，因为移位仅排列值。 
2. 预先计算孔数函数$f[x]$为所有人$x \in [0, m-1]$。 这是通过独立地对每个数字的数字贡献求和来完成的。 此步骤将数字属性与移位结构隔离。 
3. 构建第二个表示贡献权重的数组$f[x]$。 这充当循环域上的评分函数。 
4. 构建之间的线性卷积$cnt$和$f$，将两者视为整数序列而不是模数$m$。 这会产生一个数组$h$其中每个指数汇总了指数总和达到该位置的所有对的贡献。 
5. 将循环移位解释为该线性卷积的包裹段。 对于每个班次$k$, 所需值$g[k]$通过对连续段求和获得$h$长度$m$，特别是来自索引$k$到$k + m - 1$。 
6. 将其转换为前缀和$h$，所以每个$g[k]$预处理后可以在恒定时间内检索。 
7. 返回所有值中的最大值$g[k]$。 

### 为什么它有效

 核心不变量是每对$(x, i)$， 在哪里$x$是数组中的一个值并且$i$是一个数字贡献指数，在一个移位配置中仅计算一次。 卷积对频率和移动评分位置之间的所有成对相互作用进行编码。 卷积输出上的滑动窗口重建循环环绕，而不会重复计数或遗漏。 因为卷积详尽地枚举了所有索引和，并且加窗精确地将这些和划分为循环等价类，所以每次移位$k$对应于贡献的不相交且完整的聚合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def hole_count(x):
    # standard digital hole mapping assumption:
    # 0->1, 4->1, 6->1, 8->2, 9->1 (others 0)
    mp = {'0':1, '4':1, '6':1, '8':2, '9':1}
    return sum(mp.get(c, 0) for c in str(x))

def fft_convolution(a, b):
    import numpy as np
    n = 1
    while n < len(a) + len(b) - 1:
        n <<= 1
    fa = np.fft.rfft(a, n)
    fb = np.fft.rfft(b, n)
    fc = fa * fb
    c = np.fft.irfft(fc, n)
    return [int(round(x)) for x in c]

def main():
    n, m = map(int, input().split())
    arr = list(map(int, input().split()))

    cnt = [0] * m
    for x in arr:
        cnt[x] += 1

    f = [0] * m
    for i in range(m):
        f[i] = hole_count(i)

    # linear convolution
    h = fft_convolution(cnt, f)

    # prefix sums for cyclic reconstruction
    for i in range(1, len(h)):
        h[i] += h[i - 1]

    best = 0
    for k in range(m):
        total = h[k + m - 1] - (h[k - 1] if k > 0 else 0)
        best = max(best, total)

    print(best)

if __name__ == "__main__":
    main()
```该实现首先将数组压缩为频率表，以便移位不再取决于各个元素，而仅取决于每个值出现的次数。 孔计数功能隔离数字结构，使其独立于模移位逻辑。 

卷积步骤是核心变换，它用单个多项式乘法代替循环移位问题。 生成的数组对原始值和移位目标值之间的所有成对交互进行编码。 前缀求和阶段是必要的，因为每个移位对应于该线性化表示上的包装间隔。 

一个微妙的点是，使用浮点 FFT，因此需要舍入才能可靠地恢复整数卷积结果。 这是安全的，因为所有中间值都是整数，并且在典型约束下数值误差仍然很小。

 ## 边缘情况

 当所有元素都相同时，就会出现极端情况。 在这种情况下，移位不会改变频率分布，但会轮换应用的数字权重。 该算法可以正确处理这一问题，因为即使频率数组只有一个非零条目，卷积仍然会评估所有循环对齐。 

另一个微妙的情况是当$m$相对于较小$n$。 频率数组中发生许多冲突，但卷积仍然有效，因为它仅取决于计数，而不取决于唯一性。 

最后，当数字贡献高度倾斜时（例如，只有少数数字贡献非零孔计数），解决方案仍然表现正确，因为这些值仅充当卷积中的稀疏权重，并且通过线性运算保留稀疏性。
