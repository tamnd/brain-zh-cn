 ## 解决方案
 ## 问题理解

 我们得到一个数字序列，并要求应用由区间定义的单个全局“压缩”操作$[l, r]$，其中间隔长度限制为$r - l \le d$。 序列的每个元素都独立转换：以下值$l$被推至$l$，以上值$r$被拉低到$r$，并且区间内的值保持不变。 

经过此转换后，我们查看数组中的总“相邻张力”，定义为连续元素之间的绝对差之和。 任务是选择区间$[l, r]$以最大化夹紧后的总张力。 

输入尺寸$n \le 5000$允许算法围绕$O(n^2)$是可行的，但任何立方体以上$n$将会失败。 由于区间端点是实数，因此天真的连续搜索$(l, r)$这是不可能的，任何正确的解决方案都必须将搜索空间减少到有限的候选集。 

一个微妙的点是，变换不是线性的$l$和$r$。 间隔的微小变化可能会突然在三种状态之间切换元素：固定到$l$，不变，或固定到$r$。 这会产生分段行为，因此朴素梯度或贪婪推理不适用。 

典型的失败案例来自于假设最佳间隔始终与最小值和最大值一致。 例如，如果序列是$[0, 100, 1, 99]$和$d$量大，采摘$[0, 100]$不执行任何操作，而是更紧密的间隔，例如$[1, 2]$显着改变结构并增加差异。 最佳间隔是由相邻对的分割方式决定的，而不是由全局极值决定的。 

## 方法

 直接的方法是尝试每一个可能的间隔$[l, r]$令人满意$r - l \le d$，然后重新计算钳位数组及其相邻差异。 然而，即使我们将候选端点离散化$O(n)$值，仍然有$O(n^2)$间隔和每次评估成本$O(n)$，导致$O(n^3)$，这对于$n = 5000$。 

关键的结构观察是对于固定的$l$，选择从来没有用$r < l + d$除非增加$r$不会改变任何夹紧结果。 扩展$r$只能将值向上移动或保持不变，这只能增加或保留一些相邻的差异。 这使我们能够修复$r = l + d$而不损失最优性。 

现在问题变成了只选择$l$。 困难在于，作为$l$移动时，每个元素在三种状态之间切换，并且每个相邻对贡献一个值，该值仅在从该对端点导出的有限阈值集上变化。 

而不是重新计算每个的一切$l$，我们翻转观点：每个相邻对贡献一个分段线性函数$l$，在任一端点命中的值处设置断点$l$或者$l + d$。 在所有对中，我们累积了一个全局分段线性函数。 整个函数仅在以下位置改变斜率：$O(n^2)$事件点，因此我们可以按排序顺序扫描这些事件并有效地维护当前值。 

这减少了维持线性函数运行的问题$l$，更新每个事件的斜率和截距，并跟踪扫描期间遇到的最大值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 间隔暴力破解 |$O(n^3)$|$O(1)$| 太慢了|
 | 扫过线$l$与事件处理|$O(n^2 \log n)$或者$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们将搜索空间减少到$r = l + d$，然后将目标视为函数$F(l)$。 

1.修复$r = l + d$，因此每个元素都被限制为三个状态：如下$l$， 里面$[l, r]$，或以上$r$。 这消除了一个自由度并确保单个参数控制转换。 
2. 对于每一个相邻的对$(a_i, a_{i+1})$，确定其对$|b_i - b_{i+1}|$变化为$l$各不相同。 唯一有意义的转换发生在任一端点交叉时$l$或者$l + d$，所以每对贡献事件$a_i$,$a_{i+1}$,$a_i - d$， 和$a_{i+1} - d$。 
3. 将每一对转换为一组间隔$l$- 其贡献呈线性的轴$l$。 在每个这样的区间，我们将贡献表示为$s \cdot l + c$，其中斜率$s$仅在事件边界发生变化。 
4. 收集所有对中的所有事件点并对其进行排序。 这给出了所有区间的全局扫描顺序，其中完整的目标函数具有恒定的斜率行为。 
5. 从左到右浏览这些已排序的事件。 维持两个全局值：当前斜率$F(l)$和当前值$F(l)$在扫描位置。 当穿越一个事件时，根据受影响的对的状态变化来调整斜率和截距。 
6. 在事件之间，函数线性演化，所以如果我们从$l$到下一个活动$l'$，我们更新$F(l') = F(l) + \text{slope} \cdot (l' - l)$，并跟踪遇到的最大值。 

### 为什么它有效

 每个相邻对的贡献仅取决于之间的比较$l$,$l + d$，以及该对的两个值。 这意味着目标中的每一个结构性变化都恰好在这些比较之一发生翻转时发生。 只有$O(n^2)$总共有这样的翻转。 在翻转之间，该函数是完全线性的，因此保持斜率和截距足以准确地描述整个目标。 因为我们按顺序处理每一个变化，没有配置$(l, r)$被跳过，并观察所有可行间隔的最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, d = map(int, input().split())
    a = list(map(int, input().split()))

    events = []

    # Each pair contributes events at critical breakpoints
    for i in range(n - 1):
        x = a[i]
        y = a[i + 1]

        # all relevant breakpoints for l are:
        # x, y, x - d, y - d
        for v in (x, y, x - d, y - d):
            events.append(v)

    events = sorted(set(events))

    # We simulate F(l) = slope * l + const
    # We recompute contributions at each segment endpoint in O(n)
    # (n is small enough for n^2 overall)

    def calc(l):
        r = l + d
        res = 0
        b_prev = 0

        def clamp(x):
            if x < l:
                return l
            if x > r:
                return r
            return x

        b_prev = clamp(a[0])
        total = 0
        for i in range(1, n):
            cur = clamp(a[i])
            total += abs(cur - b_prev)
            b_prev = cur
        return total

    ans = -10**30
    for l in events:
        ans = max(ans, calc(l))

    print(ans)

if __name__ == "__main__":
    solve()
```所示的实现使用了简化但仍然有效的离散化策略。 它不是明确地维持斜率变化，而是评估所有结构上不同的候选值的目标$l$，这是任何元素改变状态的唯一点。 每次评估都会重新计算钳位序列$O(n)$，导致总体$O(n^2)$解决方案。 

关键的实现细节是正确构建候选集。 夹紧结构的每次变化仅发生在$l$跨越一个值$a_i$或当$l + d$十字架$a_i$，这转化为候选人$l$价值观$a_i$和$a_i - d$。 如果不包括两者，一些最佳间隔将永远不会被测试。 

有效地重新计算钳位阵列时需要小心。 由于钳位是每个元素的恒定时间操作，因此每个完整评估保持线性，并且不需要前缀预处理。

 ## 边缘情况

 关键的边缘情况是所有元素都相同。 在这种情况下，任何钳位间隔都保持相等，并且答案必须保持为零。 该算法处理这个问题是因为每个候选人$l$产生一个恒定的钳位序列，并且每次评估都返回零，因此最大值正确为零。 

当出现另一种边缘情况时$d = 0$, 强迫$l = r$。 这会将每个元素折叠为相同的值$l$，使所有相邻差异为零。 对候选人的扫荡仍然包括所有相关的$l$，但每个配置都会产生零，因此最大值被正确处理。 

最后的边缘情况是，最佳行为取决于分割单个相邻对，同时保持所有其他不受影响。 例如，当两个连续值跨越候选边界时，其中一个值会被固定，而另一个值则留在区间内。 基于事件的候选构建保证了这样的边界位置被显式测试，因此不会错过最佳分割点。
