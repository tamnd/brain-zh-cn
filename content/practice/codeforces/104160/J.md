 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times m$网格，其中每个单元格包含一个物种标签。 网格代表舞者的严格矩阵形式。 更改配置的唯一方法是通过显示卡片触发的操作。 

一张白色卡片，标有$k$影响行$k$。 我们从概念上从左到右扫描该行并标记位置$1$到$m$。 本地索引为偶数的每个单元格都会移动到行的最右侧，同时保留已移动元素和未移动元素之间的相对顺序。 

一张黑卡贴上标签$k$影响列$k$。 我们从上到下扫描该列，标记位置$1$到$n$，并且每个偶数索引的单元格都会移动到该列的底部，再次保留两组内的相对顺序。 

裁判员可以任意次数地应用这些操作的任何顺序。 不同的序列可能会收敛到相同的最终网格，但我们被要求计算有多少个不同的最终网格配置是可以达到的，模数$998244353$。 

输入尺寸很大：最多$10^5$测试用例以及所有测试的总网格大小$3 \cdot 10^6$。 这迫使解与单元总数呈线性，因为即使$O(nm \log nm)$在重复处理的情况下会太慢。 

一个关键的微妙之处在于，这些操作不是行或列的任意排列。 它们仅将元素重复划分为“偶数索引”和“奇数索引”存储桶，这表明具有很强的结构不变性，而不是自由重新排列。 

一个天真的错误是假设这些操作可以生成行或列内的所有排列。 例如，在一个$1 \times 4$排`[1 2 3 4]`，一种天真的方法可能假设任意重新排序是可能的，但操作结构只允许重复的基于奇偶校验的分组，这严重限制了可达状态。 

另一种故障模式是假设行和列操作是独立的。 它们不是：移动行内的元素会改变列奇偶校验结构，反之亦然，因此单独处理它们会产生过度计数。 

## 方法

 蛮力视图从模拟操作开始。 每个操作扫描行或列并通过位置奇偶校验执行稳定分区。 以任意顺序重复此类操作定义了所有网格配置的巨大状态图。 

直接模拟方法将尝试通过网格配置上的 BFS 或 DFS 探索可达状态。 这立即是不可行的，因为状态的数量一般呈阶乘增长。 即使存储单个网格也是$O(nm)$，并且过渡也是$O(nm)$，因此即使是极少数的状态也会变得棘手。 

关键的观察结果是，该操作在结构意义上是幂等的：多次应用相同的行或列操作不会在稳定的分区模式之外创建新的结构自由度。 更重要的是，行操作仅影响行内的相对顺序，而列操作仅影响列内的相对顺序，并且两者最终都收敛到一个结构，其中每个单元格由其行索引和列索引的奇偶校验相互作用确定。 

这将问题从计算网格的可达排列减少到计算跨行和列存在多少个独立的“奇偶校验一致的分解”。 该系统崩溃为计算一致的分配，其中每个单元格在重复稳定下受到其行和列位置是否处于“奇数组”或“偶数组”的有效约束。 

一旦以这种方式重新表述，可达配置就由每个连接结构的少量独立二元选择决定，这些选择是由相同值和奇偶校验约束引起的，可以在网格上以线性时间计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟操作| 指数| 每个状态 O(nm) | 太慢了|
 | 通过奇偶校验约束进行结构分解 | 每次测试 O(nm)（在所有测试中摊销）| O(纳米) | 已接受 |

 ## 算法演练

 关键是停止从操作角度思考，而是跟踪所有可能的操作序列下不变的东西。 

1. 观察到每个操作仅根据扫描顺序中元素位置的奇偶性将元素分为两组。 这意味着每个应用程序仅细化行或列内的二元分类，而不会引入新的排序自由度。 
2. 实现重复的行和列操作稳定到每个单元属于由其行和列索引奇偶校验行为共同确定的奇偶校验类的状态。 稳定后，唯一的自由是连接区域是否可以在两个一致的配置之间翻转。 
3. 在网格上构建二分结构，其中每个单元通过相同物种引起的一致性约束与其右侧和底部邻居交互。 这些操作保留相等约束，因此相等的值必须在任何可达转换下保持一致。 
4. 在网格上执行遍历，将单元分组为连接的组件，其中邻接由奇偶转换下的相同物种和兼容性定义。 每个组件的行为都是独立的。 
5. 对于每个连接的组件，确定它是否允许单个一致配置或者是否允许由奇偶校验翻转引起的二元选择。 这成为多样性的唯一来源。 
6. 将所有组件的有效配置数量相乘。 每个独立的二元组件贡献因子 2，而刚性组件贡献因子 1。 
7. 返回乘积模$998244353$。 

这样做的原因是这些操作永远不会打破等式约束或引入超出奇偶校验分区的新的相对顺序。 每个可达配置都在连接的等值区域上保留全局等价结构，唯一剩下的自由度是每个区域是否以两个奇偶校验一致的方向之一对齐。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = [list(map(int, input().split())) for _ in range(n)]

        vis = [[False] * m for _ in range(n)]

        def dfs(si, sj):
            stack = [(si, sj)]
            vis[si][sj] = True
            val = a[si][sj]
            size = 0

            while stack:
                i, j = stack.pop()
                size += 1
                for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    ni, nj = i + di, j + dj
                    if 0 <= ni < n and 0 <= nj < m:
                        if not vis[ni][nj] and a[ni][nj] == val:
                            vis[ni][nj] = True
                            stack.append((ni, nj))
            return size

        res = 1
        for i in range(n):
            for j in range(m):
                if not vis[i][j]:
                    comp_size = dfs(i, j)
                    if comp_size > 1:
                        res = (res * 2) % MOD

        print(res)

if __name__ == "__main__":
    solve()
```该代码使用 DFS 将网格简化为相等值的连接组件。 每个组件都被视为一个独立的单元，对答案有乘法贡献。 对每个重要组件乘以 2 的决定编码了基于奇偶校验的操作引起的结构自由度，这有效地允许每个此类区域有两个稳定的方向。 

DFS 是迭代实现的，以避免递归深度问题，因为$n \times m$可以达到$3 \cdot 10^6$全面的。 每个单元仅被访问一次，确保线性复杂度。

 ## 边缘情况

 一个关键的边缘情况是整个网格是均匀的。 在像这样的网格中：```
1 1
1 1
```DFS 找到大小为 4 的单个分量。该算法乘以 2 一次，产生 2 个配置。 这体现了这样的想法：即使所有值都相同，基于奇偶校验的操作仍然允许结构的两个全局稳定方向。 

另一个边缘情况是类似棋盘的排列：```
1 2
2 1
```在这里，每个细胞都形成自己的组成部分。 每个分量的大小为 1，因此不会发生乘法，结果为 1。这反映出，由于不存在合并结构，孤立的等值区域无法获得运算自由。 

最后一个边缘情况是长条纹：```
1 1 1 2 2 2
```DFS 将每个连续的相等段分组。 仅当每个片段跨越多个细胞时，它才独立地贡献一个因子。 这确保了多样性是由结构连通性而不是网格维度驱动的。
