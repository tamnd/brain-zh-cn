 ## 解决方案
 ## 问题理解

 问题从一棵包含以下内容的树开始：`n`顶点。 该树外部存在一个新的孤立顶点。 对于每个原始顶点`i`，我们想象将这个新顶点连接到`i`多一条边，并询问所得树的直径是多少。 任务是为每个可能的附着点输出该值。 输入仅给出原始树边，输出包含`n`答案，每个可能的连接都有一个答案。 

顶点数可以达到`300000`，因此从每个顶点探索树的方法太慢了。 单次遍历一棵树需要线性时间，在这个规模上是可以接受的，但是重复它`n`时间大约需要`n²`最大的情况下，访问量约为 900 亿次。 该解决方案必须保持接近`O(n)`。 

棘手的情况大多与误解新叶子如何改变直径有关。 如果新叶子附着在已经靠近树中部的顶点上，则原始直径仍然可以作为答案。 例如：```
3
1 2
2 3
```原来的直径是`2`。 将新顶点附加到节点`2`创建一条长度的路径`2`从新叶到任一端，所以答案是`2`。 总是在旧直径上​​加一的粗心解决方案会输出`3`。 

另一个边缘情况是单个顶点：```
1
```输入中没有边缘。 添加新顶点并将其连接到唯一的节点后，树有两个由一条边连接的顶点，所以答案是`1`。 假设总是有两个直径端点的代码在这里可能会失败。 

最后一种情况是附加顶点是原始直径的端点：```
3
1 2
2 3
```将新顶点附加到节点`1`给出路径`new - 1 - 2 - 3`，其长度为`3`。 答案大于旧直径，因此仅打印原始直径的解决方案是不正确的。 

## 方法

 直接的解决方案是尝试每个可能的附着顶点。 对于一个选定的顶点`v`，我们可以从`v`，找到其最远的顶点，并计算新直径作为旧直径的最大值以及从新叶子到该最远顶点的距离。 这是可行的，因为涉及新顶点的每条最长路径都必须从新边开始，然后继续到距离最远的原始顶点`v`。 

问题是这会多次重复几乎相同的工作。 从每一个进行遍历`n`顶点成本`O(n²)`时间。 和`n = 300000`，这远远超出了可能的范围。 

关键的观察结果是，一棵树的直径和最远顶点之间存在非常特殊的关系。 如果`a`和`b`是任意直径的两个端点，那么对于每个顶点`v`，距离最远的顶点`v`始终是其中之一`a`或者`b`。 这意味着我们不需要从每个顶点进行搜索。 我们只需要到这两个端点的距离。 

设原直径长度为`D`。 当新叶子附着在`v`，新树中的任何直径要么是旧直径，要么是从新叶子开始的路径。 从新叶子开始的最长路径有长度`ecc(v) + 1`， 在哪里`ecc(v)`是距的最大距离`v`到任何旧顶点。 因为`ecc(v) = max(dist(v, a), dist(v, b))`，每个答案都变成：```
max(D, max(dist(v, a), dist(v, b)) + 1)
```整个问题简化为找到两个直径端点和两个距离数组。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.从任意顶点开始遍历，例如vertex`1`，并找到距它最远的顶点。 称这个顶点为`a`。 

树中距任意起点最远的顶点始终是直径的端点。 

1. 开始另一次遍历`a`并找到距离最远的顶点`a`。 叫它`b`。 距离`a`到`b`是原始直径长度`D`。 
2. 遍历树一次`a`并存储距离`a`到每个顶点。 

这些距离代表偏心率计算的一个可能的方面。 

1. 遍历树一次`b`并存储距离`b`到每个顶点。 

现在每个顶点都知道它到两个直径端点的距离。 

1. 对于每个顶点`v`，计算：```
max(D, max(dist_a[v], dist_b[v]) + 1)
```第一个值处理不使用新叶子的直径。 第二个值处理从新叶子开始的路径。 

为什么它有效：

 添加额外顶点后引入的唯一新路径是以新边开始的路径。 这样的路径的长度一加上从所选附着顶点到某个原始顶点的距离。 最长的此类路径使用距附着点最远的原始顶点。 在树中，每个顶点的最远顶点是直径的两个端点之一，因此两个存储的距离数组恰好包含计算每个偏心率所需的信息。 取旧直径的最大值涵盖了最长路径的两种可能类型。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def get_dist(start, graph):
    n = len(graph) - 1
    dist = [-1] * (n + 1)
    stack = [start]
    dist[start] = 0

    while stack:
        v = stack.pop()
        for u in graph[v]:
            if dist[u] == -1:
                dist[u] = dist[v] + 1
                stack.append(u)

    return dist

def solve():
    n = int(input())
    graph = [[] for _ in range(n + 1)]

    for _ in range(n - 1):
        a, b = map(int, input().split())
        graph[a].append(b)
        graph[b].append(a)

    dist0 = get_dist(1, graph)
    a = max(range(1, n + 1), key=lambda x: dist0[x])

    dist_a = get_dist(a, graph)
    b = max(range(1, n + 1), key=lambda x: dist_a[x])

    dist_b = get_dist(b, graph)
    diameter = dist_a[b]

    ans = []
    for i in range(1, n + 1):
        ans.append(str(max(diameter, max(dist_a[i], dist_b[i]) + 1)))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```这`get_dist`函数执行迭代 DFS。 使用显式堆栈可以避免 Python 递归深度问题，因为树可以是具有`300000`顶点。 

第一次遍历找到一个直径端点。 第二次遍历既找到另一个端点，又给出距第一个端点的所有距离。 第三次遍历给出了距另一个端点的距离。 这两个数组是所有答案所需的完整信息。 

在计算答案之前存储直径长度。 最后的循环检查每个顶点的两种可能性：保持旧的直径，或通过新附加的顶点创建更长的路径。 

Python 中不存在整数溢出问题，因为整数会自动增长。 要避免的主要实现细节是意外使用递归，这可能会超出路径形树的默认递归限制。 

## 工作示例

 对于输入：```
3
3 2
2 1
```直径端点是节点`1`和`3`。 

| 顶点| 到 1 的距离 | 距离 3 | 原始直径| 回答 |
 | --- | --- | --- | --- | --- |
 | 1 | 0 | 2 | 2 | 3 |
 | 2 | 1 | 1 | 2 | 2 |
 | 3 | 2 | 0 | 2 | 3 |

 这表明新叶子在连接到端点时可以增加直径，但在连接到中心附近时则不会增加直径。

5 4
3 4
```树有中心`4`和叶子之间的直径端点。 

| 顶点| 到端点 A 的距离 | 到端点 B 的距离 | 原始直径| 回答 |
 | --- | --- | --- | --- | --- |

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 三次树遍历和一次最终遍历所有顶点 |
 | 空间| O(n) | 邻接表和距离数组存储线性信息 |

 该算法仅对每个顶点和边执行恒定数量的操作。 这适合`300000`顶点限制，因为总工作量随树大小线性增长。

import io

def solve_io(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.readline

    n = int(data())
    graph = [[] for _ in range(n + 1)]

    for _ in range(n - 1):
        a, b = map(int, data().split())
        graph[a].append(b)
        graph[b].append(a)

    def dist(start):
        d = [-1] * (n + 1)
        d[start] = 0
        stack = [start]
        while stack:
            v = stack.pop()
            for u in graph[v]:
                if d[u] == -1:
                    d[u] = d[v] + 1
                    stack.append(u)
        return d

    d = dist(1)
    a = max(range(1, n + 1), key=lambda x: d[x])
    da = dist(a)
    b = max(range(1, n + 1), key=lambda x: da[x])
    db = dist(b)
    dia = da[b]

    result = "\n".join(
        str(max(dia, max(da[i], db[i]) + 1))
        for i in range(1, n + 1)
    )

    sys.stdin = old_stdin
    return result

 ## 边缘情况

 对于单个顶点：```
1
```遍历找到唯一的顶点作为两个直径端点。 它的偏心率为零，所以公式变为`max(0, 0 + 1)`，生产`1`。 该算法不需要特殊处理，因为直径端点逻辑仍然有效。 

对于中间附着点：```
3
1 2
2 3
```直径为`2`。 对于顶点`2`，两个端点距离为`1`，因此通过添加的叶子的新路径有长度`2`。 最大剩余量`2`，这可以避免错误地增加每个答案。 

对于端点连接点：```
3
1 2
2 3
```对于顶点`1`，最大端点距离为`2`。 添加新边会创建一条长度路径`3`，公式返回`max(2, 2 + 1) = 3`。 同样的推理也适用于相反的端点。
