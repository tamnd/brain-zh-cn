 ## 解决方案
 ## 问题理解

 我们被要求在量子位数组上实现量子操作。 该运算必须对应于唯一的非零项位于反对角线上的酉矩阵。 

对于一个系统$N$量子位，状态空间具有维度$2^N$。 因此，描述操作的矩阵是$2^N \times 2^N$矩阵。 反对角矩阵将每个基本状态精确地映射到另一个基本状态，特别是其索引在反对角线上镜像的基本状态。 

如果基础状态编号为$0$到$2^N-1$，然后反对角矩阵发送基本状态$i$到基础状态$$(2^N-1)-i.$$查看二进制表示形式，该操作会翻转每一位。 例如，对于三个量子位：$$000 \leftrightarrow 111$$

$$001 \leftrightarrow 110$$

$$010 \leftrightarrow 101.$$任务不是显式构造矩阵。 相反，我们必须实现一个量子电路，其酉电路正是具有这种模式。 

限制非常小，仅在两到五个量子位之间，但这在很大程度上是无关紧要的。 挑战在于识别反对角结构所代表的量子变换。 

一个常见的错误是关注矩阵构造而不是基础状态行为。 量子电路在量子位上运行，而不是在显式矩阵上运行。 预期的解决方案来自于理解反对角线执行的基础排列。 

考虑一个双量子位系统：$$|00\rangle \to |11\rangle$$

$$|01\rangle \to |10\rangle$$

$$|10\rangle \to |01\rangle$$

$$|11\rangle \to |00\rangle.$$每一位都独立反转。 任何仅反转量子位顺序的方法都会产生$$|01\rangle \to |10\rangle,$$这对一个州有效，但对其他州无效。 所需的操作是按位补码，而不是寄存器反转。 

另一个微妙之处是小端索引约定。 它影响矩阵行和列的编号方式，但补充每个量子位仍然会改变索引$i$进入$2^N-1-i$。 无论模拟器内部使用的排序约定如何，解决方案都保持不变。 

## 方法

 蛮力观点从矩阵本身开始。 由于所需的矩阵是反对角的，因此可以想象构建一个完整的矩阵$2^N \times 2^N$置换矩阵，然后将其分解为基本门。 

这是正确的，因为反对角矩阵表示计算基础状态的排列。 为了$N$量子位有$2^N$基础状态，因此明确地推理矩阵需要$O(4^N)$条目。 虽然$N \le 5$在这里，这种方法完全忽略了底层结构并且无法扩展。 

关键的观察是反对角排列具有非常简单的二元解释。 带索引的基本状态$$i=b_{N-1}b_{N-2}\dots b_0$$被映射到$$(2^N-1)-i.$$数量$2^N-1$表示为$N$二进制的。 减法$i$从这个值开始翻转每一位：$$b_k \mapsto 1-b_k.$$因此，该操作在每个量子位上都是按位非。 

在量子计算中，按位 NOT 是通过对每个量子位应用 X 门来实现的。 每个 X 门都会翻转一个计算基础位，并将其应用于所有量子位以补充整个基础状态索引。 

因此反对角矩阵就是$$X^{\otimes N}.$$| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力矩阵构造 |$O(4^N)$|$O(4^N)$| 不必要|
 | 将 X 应用于每个量子位 |$O(N)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 迭代输入数组中的所有量子位。 
2. 将量子 X 门应用于当前量子位。 
3. 继续，直到每个量子位都被翻转。 
4.返回。 

为什么这会产生所需的矩阵？ 每个X门变换一个基位$b$进入$1-b$。 将 X 应用于每个量子位后，基础状态$$b_{N-1}b_{N-2}\dots b_0$$变成$$(1-b_{N-1})(1-b_{N-2})\dots(1-b_0).$$得到的二进制数正好是$$(2^N-1)-i.$$每个基本状态都映射到在反对角线上与其配对的唯一状态。 由于 X 门是酉的并且映射是一种排列，因此生成的矩阵在每一行和每一列中恰好有一个非零条目，位于反对角线上。 

## Python 解决方案

 这个问题实际上是一个 Q# 实现任务，而不是传统的竞争性编程问题。 没有标准输入/标准输出接口。 

所需的操作是：```
namespace Solution {
    open Microsoft.Quantum.Intrinsic;

    operation Solve (qs : Qubit[]) : Unit {
        for (q in qs) {
            X(q);
        }
    }
}
```为了完整起见，如果我们在 Python 中将相同的转换建模为基础状态排列，则它将如下所示：```python
import sys
input = sys.stdin.readline

def anti_diagonal_index(i, n):
    return ((1 << n) - 1) ^ i
```由于数学结构是最小的，所以实现是最小的。 每个量子位都是独立翻转的。 量子位之间没有相互作用，没有受控操作，也不依赖于任何其他量子位的值。 

唯一微妙的一点是认识到对所有位求补完全对应于酉矩阵反对角线的反射。

 ## 边缘情况

 考虑最小有效寄存器大小，$N=2$。 国家$|00\rangle$必须成为$|11\rangle$。 将 X 应用于每个量子位会准确地产生该转换。 任何仅交换量子位位置的解决方案都会留下$|00\rangle$不变，这是不正确的。 

考虑最大有效寄存器大小，$N=5$。 索引范围为$0$通过$31$。 翻转所有五个位图$0$到$31$,$1$到$30$， 等等。 反对角结构保持相同，因为变换是为每个位独立定义的。 

考虑这样的状态$|10101\rangle$。 将 X 应用于每个量子位会产生$|01010\rangle$。 相应的指标满足$$21 \mapsto 10 = 31-21.$$这证实了该操作适用于任意基础状态，而不仅适用于对称或极端情况。 

小端索引约定不会创建特殊情况。 对每个量子位求补会翻转二进制索引的每一位，无论哪个量子位被认为是最不重要的。 所得矩阵仍然是反对角的。
