[CF 3A - 国王的最短路径](https://codeforces.com/problemset/problem/3/A)

 **评分：** 1000
 **标签：** 贪心、最短路径
 **求解时间：** 4m 37s
 **已验证：** 是的

 ## 问题理解

 我们被要求以最少的步数将国际象棋王在标准 8×8 棋盘上从一个方格移动到另一个方格。 国王可以沿八个可能的方向移动到任何相邻的方格：垂直、水平或对角线。 输入使用标准国际象棋符号指定起始方格和目标方格​​，其中第一个字符是来自`a`到`h`代表列，第二个字符是来自的数字`1`到`8`代表行。 输出应该是最小的移动次数，然后是实现它的一系列移动。 

主要限制是棋盘尺寸小（8×8）和国王的行动自由度。 因为棋盘很小，所以方格数量为二次甚至三次的算法就足够快了。 每次移动仅在任一轴或两个轴上改变位置 1，因此我们知道任何方向上的最大距离为 7。边缘情况包括起始方格和结束方格相同时、移动严格水平或垂直时以及移动完全对角时。 处理这些情况时不出现相差一的错误非常重要，因为粗心的实现可能会超出范围或产生额外的移动。 

## 方法

 一种强力方法是将棋盘建模为网格，并从起始方格运行最短路径算法，例如 BFS。 BFS会逐层探索所有可能的王走法，直到到达目标，保证走步数最少。 在 8×8 的棋盘上，有 64 个方格，每个方格最多有 8 个邻居，最多有 512 条边。 BFS 需要 O(64 + 512) 次操作，这是可以忽略不计的。 这是正确的，但对于这个问题来说有点过分了。 BFS 还需要跟踪访问的状态并重建路径，这增加了代码的复杂性。 

关键的见解是国王的移动允许对角线捷径。 为了最大限度地减少移动次数，在每一步中，我们都应该尽可能向目标倾斜移动，因为对角移动会同时减少水平和垂直距离。 只有当其中一个轴与目标对齐时，我们才应该严格沿着其余轴移动。 最小移动次数是水平或垂直距离中较大的一个，因为每个对角线移动都会使两者都减少 1。这是一种贪婪方法：在每一步中，进行减少两个坐标的移动，直到其中一个与目标匹配，然后沿着剩余的轴完成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | BFS / 蛮力 | 奥(64) | 奥(64) | 正确但不必要的复杂 |
 | 贪心对角线| O(Δx + Δy) | O(1) | O(1) | 已接受，最简单|

 ## 算法演练

 1. 将起始坐标和目标坐标从国际象棋符号转换为数字坐标。 地图`a`-`h`列为 1-8，`'1'`-`'8'`为行的整数。 这允许算术运算来计算距离。 
2. 计算水平差`dx`作为`target_x - start_x`和垂直差`dy`作为`target_y - start_y`。 这些告诉我们国王必须沿着每个轴移动多远和方向。 
3. 虽然两者`dx`和`dy`非零，沿对角线移动。 如果`dx > 0`和`dy > 0`, 向右移动 (`RU`），同时减少`dx`和`dy`1. 根据 的符号处理所有四个对角线方向`dx`和`dy`。 
4. 一旦一个轴达到零，继续沿另一轴移动。 如果`dx != 0`，向左或向右移动，直到`dx`达到零。 如果`dy != 0`，向上或向下移动，直到`dy`达到零。 
5. 按顺序记录每个动作。 总移动次数等于初始移动绝对值中的最大值`dx`和`dy`。 

为什么有效：每次对角线移动都会使水平和垂直距离减少 1。用完对角线后，可能会剩下一个轴，沿着它一次移动一步可以保证最小移动，因为不可能有对角线捷径。 该算法是贪婪的，但却是最优的，因为在给定国王的移动集的情况下，每次移动都会以尽可能最快的方式减少剩余的曼哈顿距离。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def chess_king_path():
    start = input().strip()
    target = input().strip()
    
    x1 = ord(start[0]) - ord('a') + 1
    y1 = int(start[1])
    
    x2 = ord(target[0]) - ord('a') + 1
    y2 = int(target[1])
    
    dx = x2 - x1
    dy = y2 - y1
    
    moves = []
    
    while dx != 0 or dy != 0:
        move = ""
        if dy > 0:
            move += "U"
            dy -= 1
        elif dy < 0:
            move += "D"
            dy += 1
        
        if dx > 0:
            move += "R"
            dx -= 1
        elif dx < 0:
            move += "L"
            dx += 1
        
        moves.append(move)
    
    print(len(moves))
    for m in moves:
        print(m)

chess_king_path()
```该代码首先将国际象棋符号转换为数字坐标。 然后，它反复选择朝向目标的贪婪对角线或直线移动，将每个移动附加到列表中。 while 循环一直持续到`dx`和`dy`达到零。 开始等于目标的边缘情况会被自然处理，因为循环永远不会执行，并且会打印零移动。

 ## 边缘情况

 如果起始值等于目标值，则 dx 和 dy 为零。 循环永远不会执行，打印 0 次移动。 例如，对于仅单轴移动`a1`到`a8`，对角线移动是不可能的，因此算法严格沿垂直轴移动。 这与国王的合法移动相匹配并产生最少的移动。 同样，如果目标对角对齐，算法永远不会超调，因为它同时减少 dx 和 dy。 每一步都会向目标精确地减少一到两个单位，从而保证所有边缘场景的正确性。
