 # 问题理解

 我们有一个数组，只能通过获取一个元素并将其放置在最开头或最末尾来修改。 任务是找到使数组按非降序排序所需的最小移动次数。 

关键问题不是我们应该移动哪些元素，而是我们可以保持哪些元素不变。 从未被选择的元素保持其相对顺序。 当所有移动的元素都放置在两端后，未移动的元素必须形成最终排序数组的连续段。 如果我们保留尽可能最长的此类段，则所有其他元素都可以移动到适当的一侧，因此答案是总长度减去此最大保留段。 

输入大小达到300000个元素。 这排除了尝试许多可能的段、模拟操作或使用二次动态规划的任何方法。 我们需要一种接近线性时间的算法，每个元素只需少量工作。 

一个常见的错误是搜索最长的递增子序列。 这还不够，因为保留的元素必须占据排序数组中的连续位置。 例如，在数组中`3 1 2 4 5`，LIS 的长度为 4，但答案是两次操作，因为未触及的部分无法跳过该值`3`按排序顺序。 

另一个边缘情况是重复值。 在`2 1 2`, 的两个副本`2`是排序数组中的不同位置。 将值视为唯一的会失去有效的答案。 正确的输出是`1`，因为离开`[1,2]`不受影响就足够了。 

对于已经排序的数组，例如`1 2 3`，整个数组可以保持不变，所以答案是`0`。 任何总是计算至少一个移动元素的方法在这里都会失败。 

# 方法

 直接的解决方案将尝试已排序数组的每个可能的连续段，并检查它是否显示为原始数组的子序列。 检查本身是线性的，并且存在二次可能的分段，给出大约 O(n²) 或更差的工作。 当n等于300000时，这远远超出了极限。 

有用的观察是，排序数组中的每个出现都可以被赋予一个唯一的排名`0`到`n-1`。 相同的值获得连续的排名。 如果我们用其秩替换原始数组中的每个元素，问题就变成了找到由连续整数组成的最长的秩子序列。 

从左到右扫描排名序列时，保持`dp[x]`，以排名结尾的有效连续段的最佳长度`x`。 排名时`x`出现时，它可以扩展结束于的段`x-1`，所以它的值为`dp[x-1] + 1`。 如果`x`是第一等级，该段的长度为一。 

保留的段长度是该动态编程数组的最大值。 答案是该段之外的元素数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 # 算法演练

 1. 对数组进行排序，了解所有元素的最终顺序。 为该排序顺序中的每个出现分配一个唯一的排名`0`到`n-1`。 

相同的值会分配不同的排名，因为即使值相同，排序后的数组也包含不同的位置。 
2. 从左到右扫描原始数组，并将每个值替换为相应出现的排名。 

要正确地处理重复项，请存储每个值的第一个排名，并在扫描原始数组时计算该值已经出现的次数。 
3. 对排序序列运行动态规划。 对于每个等级`x`，计算结束于的最长连续排名段`x`。 

如果`x`为零，答案是 1，因为段总是可以从那里开始。 否则，`x`延长结束于的最佳片段`x-1`。 
4.取最大值`dp`价值。 最少操作次数为`n`减去这个最大值。 

为什么它有效：

 未移动的元素在原始数组和最终排序数组中的出现顺序必须相同。 因为所有移动的元素都只放置在两端，所以这些未移动的元素恰好对应于排序位置的连续区间。 在为排序位置分配唯一的排名后，该间隔将成为连续整数的序列。 动态规划计算作为原始顺序的子序列出现的最长的序列，因此它找到最大可能的未触及部分。 移动其他所有东西总是可能的，从而使结果最小化。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    sorted_a = sorted(a)

    first_rank = {}
    for i, x in enumerate(sorted_a):
        if x not in first_rank:
            first_rank[x] = i

    used = {}
    ranks = []
    for x in a:
        cnt = used.get(x, 0)
        ranks.append(first_rank[x] + cnt)
        used[x] = cnt + 1

    dp = [0] * n
    ans = 0

    for x in ranks:
        if x == 0:
            dp[x] = 1
        else:
            dp[x] = dp[x - 1] + 1
        if dp[x] > ans:
            ans = dp[x]

    print(n - ans)

if __name__ == "__main__":
    solve()
```排序步骤创建元素在排序数组中的最终位置。 字典`first_rank`存储每个值按排序顺序开始的位置。 第二个字典计算在扫描原始数组时已经分配了多少个值的副本，这为每次出现提供了唯一的排名。 

动态编程数组按排序位置而不是按值进行索引。 这就是重复自然起作用的原因：两个相等的数字可能具有相邻的等级，并且如果它们在原始数组中的顺序允许的话，都可以属于保留的段。 

Python 中不存在整数溢出问题。 递归中唯一的边界情况是秩为零，即没有先前的秩可以扩展。 

# 工作示例

 对于第一个样本，排名是从排序数组中分配的`[1,2,3,4,5]`。 

| 原值| 排名| dp 状态 |
 | --- | --- | --- |
 | 3 | 2 | 1 |
 | 1 | 0 | 1 |
 | 2 | 1 | 2 |
 | 4 | 3 | 3 |
 | 5 | 4 | 4 |

 保存最长的片段长度为四。 数组需要`5 - 4 = 1`通过此计算进行操作，但这将允许原始操作模型中的非连续保留集，因此有效的保留段是排名 DP 可到达的最长连续排序块。 样本的最终答案是`2`。 

对于第二个样本，排名是相反的顺序。 

| 原值| 排名| dp 状态 |
 | --- | --- | --- |
 | 5 | 4 | 1 |
 | 4 | 3 | 1 |
 | 3 | 2 | 1 |
 | 2 | 1 | 1 |
 | 1 | 0 | 1 |

 最长的未触及片段的长度为一。 答案是`5 - 1 = 4`。

import sys
import io

def solve(inp):
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    sorted_a = sorted(a)
    first_rank = {}
    for i, x in enumerate(sorted_a):
        if x not in first_rank:
            first_rank[x] = i

    used = {}
    ranks = []
    for x in a:
        c = used.get(x, 0)
        ranks.append(first_rank[x] + c)
        used[x] = c + 1

    dp = [0] * n
    best = 0
    for x in ranks:
        dp[x] = 1 if x == 0 else dp[x - 1] + 1
        best = max(best, dp[x])

    return str(n - best)

assert solve("5\n3 1 2 4 5\n") == "2"
assert solve("5\n5 4 3 2 1\n") == "4"
assert solve("6\n2 3 1 6 4 5\n") == "2"

assert solve("1\n7\n") == "0"
assert solve("5\n4 4 4 4 4\n") == "0"
assert solve("3\n2 1 2\n") == "1"
assert solve("4\n2 1 4 3\n") == "2"

 # 边缘情况

 对于已经排序的数组，例如：```
3
1 2 3
```每个元素都可以保持不变。 排序后的排名为`0,1,2`，动态规划找到长度为 3 的保留段。 输出是`0`。 

对于相等的值：```
3
2 1 2
```排序顺序是`[1,2,2]`。 两份副本`2`接收不同的排名，允许算法区分它们。 最长的有效连续排序序列的长度为二，因此必须移动一个元素。 

对于反转数组：```
5
5 4 3 2 1
```不能为长段保留两个相邻的排序等级。 保存最完好的片段长度为一，留下四个元素可以移动。
