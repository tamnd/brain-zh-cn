 ## 解决方案
 ## 问题理解

 我们需要计算 1 到 1 之间的整数`n`满足两个条件。 该数本身必须是奇数，并且它的正因数的数量也必须是奇素数。 输入仅包含上限`n`，输出是不超过该值的有效整数的个数。 

关键限制隐藏在尺寸中`n`。 该值可以大到`11^13`，对于检查每个整数来说太大了`n`。 即使是线性扫描也需要数万亿次操作。 我们需要利用具有所需除数计数的数字的数学结构。 

一些边缘情况很容易被忽略。 数量`1`有一个除数，但 1 不是质数，因此永远不应该计算它。 对于输入：```
1
```答案是：```
0
```仅检查除数计数是否为奇数的直接方法会错误地包含它。 

另一个陷阱是素数本身有一个素数的约数，但约数必须是奇数。 例如：```
5
```有两个除数，`1`和`5`，所以它是无效的。 答案是：```
0
```仅寻找素值的解决方案在这里会失败。 

最终的边界情况是不符合所需形式的完美正方形。 例如：```
81
```是一个正方形，但它有`5`除数。 自从`5`是质数，它是有效的并且应该被计算。 相比之下：```
45
```不是正方形，因此它的约数不能为奇数。 有用的属性不仅仅是奇数或素数，它是精确的因式分解模式。 

## 方法

 蛮力的想法是迭代每个奇数`1`到`n`，计算其除数计数，并检查该计数是否为素数。 可以通过测试除数到其平方根来找到数字的除数计数。 这是正确的，因为每个数字都有有限多个除数，除数的数量决定了它是否合格。 然而，该范围可以达到大约`1.6 * 10^13`，所以连拜访候选人都是不可能的。 最坏的情况远远超出任何合理的操作极限。 

主要观察来自除数公式。 如果一个数有质因数分解：```
x = p1^a1 * p2^a2 * ... * pk^ak
```那么它的约数个数是：```
(a1 + 1) * (a2 + 1) * ... * (ak + 1)
```仅当每个指数均为偶数时，该乘积才是奇数。 这意味着数字本身必须是完全平方数。 由于数字也必须是奇数，因此平方根也必须是奇数。 

设平方根为：```
m = p1^b1 * p2^b2 * ... * pk^bk
```然后：```
x = m^2
```除数计数变为：```
(2b1 + 1) * (2b2 + 1) * ... * (2bk + 1)
```要使该产品成为优质产品，只能有一个因素。 否则它将是两个大于一的数字的乘积。 所以`m`必须是单个奇素数的幂：```
m = p^a
```和：```
2a + 1
```是首要的。 

现在问题从检查巨大的值减少到生成所有有效的根`m`不超过`sqrt(n)`。 最大可能的根约为`3.3 * 10^6`，所以筛子很容易足够快。 可能的指数也非常小，因为幂增长很快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n sqrt(n)) | O(n sqrt(n)) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(sqrt(n) log log sqrt(n)) | O(sqrt(n) log log sqrt(n)) | O(sqrt(n)) | 已接受 |

 ## 算法演练

 1. 计算`limit = floor(sqrt(n))`。 任何有效数字都是平方，因此其平方根不能超过该值。 
2. 生成直到`limit`使用埃拉托斯特尼筛法。 我们只需要奇数质数，因为原始数必须是奇数。 
3. 生成指数列表`a`在哪里`2a + 1`是素数。 这些是唯一可以出现在有效根中的指数。 
4. 对于每个奇素数`p`和每个有效指数`a`, 计算`p^a`。 如果该值最多为`limit`，那么它的平方就是一个有效的数字，我们将它添加到答案中。 
5. 当当前功率大于`limit`，因为更大的力量永远无法做出贡献。 

这样做的原因是每个有效数字都有唯一的平方根。 因式分解论证证明根必须恰好是一个素数提升到满足素数条件的指数。 生成过程会枚举每个这样的根，因此不会丢失任何有效值。 由于不同的根产生不同的平方，因此不会发生重复计数。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n_line = input().strip()
    if not n_line:
        return
    n = int(n_line)

    limit = math.isqrt(n)

    is_prime = bytearray(b'\x01') * (limit + 1)
    if limit >= 0:
        is_prime[0] = 0
    if limit >= 1:
        is_prime[1] = 0

    i = 2
    while i * i <= limit:
        if is_prime[i]:
            start = i * i
            is_prime[start:limit + 1:i] = b'\x00' * (((limit - start) // i) + 1)
        i += 1

    exponents = []
    for a in range(1, 64):
        if 2 * a + 1 <= limit + 10 and is_prime[2 * a + 1]:
            exponents.append(a)

    ans = 0
    for p in range(3, limit + 1, 2):
        if not is_prime[p]:
            continue
        power = p
        for a in range(1, max(exponents, default=0) + 1):
            if a > 1:
                if power > limit // p:
                    break
                power *= p
            if a in exponents:
                ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先构建一个素数表，直到平方根`n`。 这已经足够了，因为每个候选值都是根据其平方根生成的，而不是根据原始值生成的。 

指数列表仅包含其中的值`2a + 1`是素数。 循环从指数一开始，因为`a = 0`代表数字`1`，这是无效的。 

对于每个素数碱基，代码重复乘以该碱基，同时保持在根限制内。 在可能溢出的语言中，乘法之前的除法检查可以防止值超出 Python 的整数范围，并且还可以避免不必要的工作。 

最终的计数就是有效根的数量。 计算根而不是平方可以避免大量算术运算，因为不需要平方运算。

 对于输入：```
9
```平方根极限是`3`。 

有效指数是`1`因为`2 * 1 + 1 = 3`，这是素数。

```这表明该算法不会搜索所有数字。 它只构建可能起作用的根。

```平方根极限是`10`。 

可能的根是：

 ## 边缘情况

 对于`1`，该算法给出零，因为平方根是 1，并且没有生成素数幂可以产生它。 这可以避免错误地将 1 的单个约数计为素数。 

为了`5`，平方根极限为二，因此不会生成奇数素根。 该算法从不考虑素数本身，这是正确的，因为数字的素数无关紧要。 

为了`81`，算法生成根`9`。 根是`3^2`，指数检查给出`2 * 2 + 1 = 5`，它是素数，所以平方`81`被计算在内。 这说明了为什么仅检查平方条件是不够的。
