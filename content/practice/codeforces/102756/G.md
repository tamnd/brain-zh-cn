 ## 解决方案
 ## 问题理解

 该问题要求我们从多个恢复代码中恢复忘记的密码。 每个代码都有准确的`k`数字，但每个代码都受到相同的未知数字位置重新排列的影响。 我们需要找到使最大结果代码尽可能接近最小结果代码的位置排列，并输出最小可能的差异。 

输入包含`n`代码和位数`k`在每个代码中。 的单一排列`k`位置必须应用于每个代码。 选择该排列后，每个代码都成为一个新的`k`数字，目标是最小化最大和最小变换值之间的差异。 

在最重要的维度上，约束很小。 最多可以有 100 个代码，每个代码最多有 9 位数字。 扫描所有可能的数字重新排列的解决方案是可能的，因为`9! = 362880`，虽然很大但仍然可以管理。 A solution that tries arbitrary assignments of digits independently for every code would explode because it would ignore the fact that all codes share the same permutation.

 主要的边缘情况来自将代码视为普通整数而不是固定长度的数字字符串。 前导零是代码的一部分，可以移动到其他位置。 例如：```
Input
2 2
12
32
```最好的排列使数字保持原来的顺序。 数字变成`12`和`32`，所以答案是`20`。 在其他情况下，将代码存储为整数的粗心实现可能会丢失有关前导零的信息。 

另一个边缘情况是所有代码都相等时：```
Input
3 3
111
111
111
```每个排列产生相同的值，所以正确的输出是`0`。 仅当发现严格较小的值时才更新答案的实现，如果未正确处理第一个排列，可能会意外地保留无限的初始值。 

最后一种情况是最佳排列将零放在最重要的位置：```
Input
2 3
100
200
```将最后一位数字移到前面的排列给出`001`和`002`，因此差值变为`1`。 在应用排列之前删除前导零的代码永远无法找到这个答案。 

## 方法

 最直接的方法是尝试所有可能的排列`k`数字位置。 对于每个排列，我们变换每个代码，跟踪最小变换数和最大变换数，并用它们的差异更新答案。 这是正确的，因为每个合法的重新安排都经过明确检查。 

昂贵的部分是排列的数量。 在最坏的情况下，`k = 9`, 给予`9! = 362880`排列。 对于每个排列，我们必须处理所有`n = 100`代码和所有`k = 9`的数字，大约是`3.2 * 10^8`数字运算。 在 Python 中，这需要仔细实现，但可以通过预先计算一小组代码上的排列效果来改进。 

关键的观察是`k`是小且固定的，而`n`也很小。 我们不需要在排列循环期间重复重建转换后的字符串。 我们可以将所有可能的位置排列存储一次，然后将其有效地应用于每个代码。 由于每个代码都使用相同的排列，因此搜索空间仅为`k!`，而不是依赖于代码数量的指数。 

蛮力之所以有效，是因为可能的数字重新排列的数量是有限的。 优化来自于紧凑地表示每个重新排列并避免最内层循环内的重复工作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k! * n * k) | O(k! * n * k) | O(1) | O(1) | 没有优化太慢|
 | 最佳| O(k! * n * k) 高效实现 | O(k! * k + n * k) | O(k! * k + n * k) | 已接受 |

 ## 算法演练

 1. 将每个恢复代码作为字符串读取并保留前导零。 将每个字符转换为整数，以便可以快速访问位置。 
2. 生成位置的每个排列`0`通过`k - 1`。 每个排列代表平板电脑重新排列数字的一种可能方式。 
3. 对于每个排列，通过按新顺序读取数字来转换每个代码。 通过重复将当前值乘以 10 并添加下一个数字来构建结果数字。 
4. 在处理变换后的代码时，保持最小和最大变换值。 它们之间的区别在于此排列的候选密码。 
5. 保留所有排列中找到的最小差异并打印它。 

为什么它有效：

 每个可能的常见数字位置重新排列在生成的排列中只出现一次。 对于固定排列，该算法会计算该重新排列产生的确切最大值和最小值，因此它会评估该情况的正确密码候选者。 由于最佳排列必须是生成的排列之一，因此对所有候选排列取最小差异即可给出所需的答案。 

## Python 解决方案```python
import sys
from itertools import permutations

input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    nums = [list(map(int, input().strip())) for _ in range(n)]

    perms = list(permutations(range(k)))

    answer = 10 ** k

    for p in perms:
        mn = 10 ** k
        mx = -1

        for num in nums:
            value = 0
            for idx in p:
                value = value * 10 + num[idx]

            if value < mn:
                mn = value
            if value > mx:
                mx = value

        diff = mx - mn
        if diff < answer:
            answer = diff

    print(answer)

if __name__ == "__main__":
    solve()
```输入存储为数字列表而不是整数，因为前导零在排列过程中必须保持可见。 例如，代码`001`与整数不同`1`因为这三个位置以后可以重新排列。 

排列列表在搜索开始之前生成一次。 每个排列都包含原始数字位置，按照重新排列后应出现的顺序排列。 

内循环直接用算术构造变换后的数字。 这避免了重复创建临时字符串，并且自然地处理前导零，因为前导零在构建数字时根本没有任何贡献。 

每次排列都会重置最小值和最大值。 忘记这一点会比较不同重新排列的值并产生无效结果。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(k! * n * k) | O(k! * n * k) | 每个数字排列都会经过测试，每个测试都会检查所有代码及其数字。 |
 | 空间| O(k! * k + n * k) | O(k! * k + n * k) | 存储的排列和输入的数字表示主导内存使用。 |

 和`k <= 9`，排列的数量最多为`362880`。 输入大小足够小，可以检查每个可能的重新排列是否在限制范围内。 

## 测试用例```python
import sys
import io
from itertools import permutations

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    
    def solve():
        input = sys.stdin.readline
        n, k = map(int, input().split())
        nums = [list(map(int, input().strip())) for _ in range(n)]

        ans = 10 ** k
        for p in permutations(range(k)):
            mn = 10 ** k
            mx = -1
            for num in nums:
                value = 0
                for i in p:
                    value = value * 10 + num[i]
                mn = min(mn, value)
                mx = max(mx, value)
            ans = min(ans, mx - mn)

        return str(ans)

    return solve()

""") == "0", "all equal values"

""") == "1", "leading zero permutation"

 ## 边缘情况

 对于相等的值，算法会测试每个排列，但每个转换后的值保持相同。 为了：```
3 3
111
111
111
```每个排列都会产生三个副本`111`，所以最小值和最大值都是`111`答案就变成了`0`。 

对于前导零：```
2 3
100
200
```排列`(2, 0, 1)`将代码更改为`001`和`002`。 该算法将它们构造为整数`1`和`2`，所以它正确地找到了差异`1`。 它不会丢失零位置，因为排列是在构建数字之前应用的。 

对于单个数字：```
2 1
0
9
```只有一种可能的排列。 变换后的值为`0`和`9`，所以算法返回`9`。 这证实了当没有顺序选择时，排列生成也能起作用。
