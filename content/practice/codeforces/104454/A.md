 ## 解决方案
 ## 问题理解

 我们给出了部分指定的$n \times n$网格，但实际上只有第一行是固定的。 该行是从 1 到$n$，意味着每个值都只出现一次。 任务是建造剩余的$n-1$行，以便最终的正方形成为拉丁正方形：每行包含从 1 到$n$恰好一次，并且每列也包含每个数字恰好一次。 

关键限制是第一行不是任意数据，它成为定义整个结构的种子。 每隔一行必须在行方向和列方向上的唯一性方面与其保持一致。 

约束很小，有$n \leq 100$。 这立即消除了对效率的任何担忧。 甚至一个$O(n^3)$施工将顺利进行，因为单元总数仅为$10^4$。 真正的困难不是性能，而是实现有效完成的结构。 

天真的尝试可能会尝试通过贪婪地将未使用的数字放入列中来独立填充每一行。 这很快就会失败，因为列约束将所有行耦合在一起。 例如，如果第一行是$[1,2,3,4]$，并且我们尝试通过在没有全局模式的情况下在本地转移选择来独立构建第二行，我们可能会意外地在列中重复一个数字，从而破坏拉丁属性。 

如果我们尝试对每行进行随机洗牌，则会出现另一种失败情况。 即使每一行都是有效的排列，也无法保证列的唯一性。 例如：

 输入：```
3
1 2 3
```如果我们独立生成如下行：```
1 2 3
2 1 3
3 2 1
```第 2 列变为$[2,1,2]$，它重复 2 并且违反了条件。 问题在于列结构需要跨行确定性对齐。 

因此，问题不在于填充数字，而更多在于将排列扩展到具有一致循环行为的结构化对象。 

## 方法

 强力的视角是逐行构建网格，尝试每行的所有排列，同时逐步验证列约束。 对于每个$n-1$剩余行有$n!$可能性，并且每次检查都需要$O(n)$列验证。 这大约爆炸为$(n!)^n$，即使对于小规模来说，这也是完全不可行的$n$。 

关键的观察结果是第一行已经定义了符号的完整排序，并且我们可以在所有行中一致地重复使用此排序。 如果我们将第一行视为参考序列，则每个后续行都可以通过该序列的循环移位形成。 

更具体地说，如果第一行是$a_0, a_1, \dots, a_{n-1}$，然后行$i$通过将第一行移位获得$i$位置向左。 这保留了行有效性，因为每一行只是第一行的排列。 它还保留了列的有效性，因为每列都成为相同序列的循环排列，从而确保所有值每列只出现一次。 

这将问题从组合搜索简化为线性时间内的确定性构造。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O((n!)^n)$|$O(n^2)$| 太慢了 |
 | 循环移位|$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 阅读$n$和第一行数组$a$。 该行定义了我们必须在整个网格中保留的数字的确切顺序。 
2. 构造每一行$i$将数组左移$i$职位。 从前面移出的元素会环绕到末尾。 这确保每一行仍然是第一行的排列。 
3. 直接打印所有构造的行。 

移位是正确转换的原因是它在旋转位置时保留相对顺序，这正是避免列中重复所需的。 

### 为什么它有效

 每行都是第一行的排列，因此自动满足行约束。 对于列，修复任何列索引$j$。 跨行，该列中的值是$a[(i+j) \bmod n]$。 作为$i$从 0 运行到$n-1$，该表达式循环遍历所有索引模$n$恰好一次，意味着每列只包含每个值一次。 这个不变量同时保证行和列条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())
a = list(map(int, input().split()))

for i in range(n):
    row = []
    for j in range(n):
        row.append(a[(i + j) % n])
    print(*row)
```核心构造发生在双环中。 对于每行索引$i$，我们生成原始数组的循环移位。 表达式`(i + j) % n`是强制环绕行为的机制。 

一个微妙的点是我们永远不会修改原始数组。 每行都直接从固定参考导出，这避免了迭代应用移位时可能出现的累积错误。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()

    a = list(map(int, input().split()))
    for i in range(n):
        row = []
        for j in range(n):
            row.append(a[(i + j) % n])

    sys.stdout = sys.__stdout__
    return output.getvalue().strip()

 ## 边缘情况

 对于$n = 1$, the grid contains a single cell and no shifting occurs. The algorithm produces exactly the input row, which is already valid.

 对于反转的第一行，例如$[4,3,2,1]$，移位操作仍然保持正确性，因为模块化索引不依赖于数字顺序，只依赖于位置旋转。 每列仍然循环遍历所有值一次，因为每个索引移位在行之间只使用一次。
