 ## 解决方案
 ## 问题理解

 我们给出了几个测试用例，每个测试用例都以素数开头$n$。 对于每一个这样的$n$，我们必须选择另一个质数$m$使得总和$n + m$不是素数。 任何有效素数$m$在允许的范围内是可以接受的，并且不同的测试用例是独立的。 

核心任务不是重复计算素数，而是为每个输入素数构造一个有效的伙伴素数。 输出约束是慷慨的：$m$可以是任何素数$10^5$，并且不需要在有效性之外最小化或优化它。 

约束条件$n \le 10^5$和$t \le 10^4$建议在进行一些预处理后，解决方案必须基本上是每个测试用例的恒定时间。 任何涉及每个测试用例重复素性检查的事情仍然可以，只要检查是$O(1)$，但在最坏的情况下，每个查询对素数的重复搜索会太慢。 

当出现微妙的边缘情况时$n$很小。 如果$n = 2$，然后选择小素数，例如$m = 2$或者$m = 3$立即产生总和$4$或者$5$，并且其中只有一个是非素数。 如果假设所有和的行为都相似，那么总是选择列表中第一个素数的天真的方法可能会失败。 另一个极端情况是当$n$又大又近$10^5$，粗心的构建策略可能会超出界限$n + m$，尽管总和的素数是唯一的问题，而不是它的大小。 

## 方法

 暴力方法会尝试每个素数$m$并检查是否$n + m$是素数。 对于每个测试用例，这可以扫描所有素数$10^5$，并为每个候选者计算素数$n + m$。 即使素数是用筛子预先计算的，我们仍然会在每个测试用例中检查大约 9,500 个素数，导致大约$10^8$在所有测试中检查最坏的情况，这是不必要的。 

关键的观察是我们不需要搜索。 我们只需要保证至少一个简单的选择有效。 素数的结构立即给出了一条捷径：如果我们选择一个小的固定素数$m$，我们只需要检查是否$n + m$是复合的。 自从$n$总是素数，我们可以利用奇偶性。 除了$n = 2$，每个素数都是奇数。 两个奇数之和是偶数且大于 2，因此是合数。 这意味着对于所有奇素数$n$，选择$m = 3$总是产生一个复合和。 

唯一有问题的情况是$n = 2$。 这里$n$是偶数，所以$2 + 3 = 5$是素数，失败了。 我们需要另一个固定的小素数。 选择$m = 2$给出$2 + 2 = 4$，这是复合的。 这解决了唯一的例外情况。 

因此，解决方案简化为恒定时间条件选择。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 素数的暴力搜索 |$O(t \cdot \pi(N))$|$O(N)$| 太慢了|
 | 固定结构（2 或 3）|$O(t)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取素数$n$。 我们纯粹将其视为一个整数； 不需要因式分解。 
2. 检查是否$n = 2$。 这是唯一的偶素数，其行为与其他素数不同，因为它打破了奇加奇的结构。 
3.如果$n = 2$， 输出$m = 2$。 这确保了$n + m = 4$，这不是素数。 
4.否则，输出$m = 3$。 由于除了 2 之外的所有素数都是奇数，这保证$n + 3$是偶数且大于 2，因此是合数。 

### 为什么它有效

 正确性取决于素数的结构特性。 每个大于 2 的素数都是奇数。 当我们将两个奇数相加时，结果是偶数。 任何大于 2 的偶数都不能是素数，因为它有 2 作为约数。 因此，对于任意奇素数$n$，选择$m = 3$力量$n + m$成为复合的。 唯一的例外是$n = 2$，其中奇偶校验被破坏，并且我们明确选择另一个素数以避免产生另一个素数和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n == 2:
            print(2)
        else:
            print(3)

if __name__ == "__main__":
    solve()
```代码直接遵循构造。 唯一的决策点是与 2 的相等性检查。其他一切都是恒定输出。 

一个常见的错误是试图“搜索”有效的$m$动态的，这是不必要的并且有超时的风险。 另一个错误是忘记了$2 + 3 = 5$是素数，这使得$m = 3$无效于$n = 2$。 显式分支处理这个问题。

 ## 边缘情况

 唯一有意义的边缘情况是$n = 2$。 如果算法盲目输出$m = 3$，它产生$5$，它是素数，因此无效。 显式分支确保正确处理。 

例如，输入：```
1
2
```该算法选择$m = 2$，生产$4$，这是复合的。 该逻辑避免了对奇偶校验假设的任何依赖，而奇偶校验假设在以下情况下会失败：$n$是均匀的。 

所有其他素数都是奇数，并且构造$m = 3$始终强制大于 2 的偶数总和，保证正确性而无需进一步检查。
