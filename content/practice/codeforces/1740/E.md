 ## 解决方案
 ## 问题理解

 我们得到一棵有根树，其中每个节点代表一张卡片。 卡 1 固定为根，其他所有卡都挂在一张较早的卡上，形成一个结构，其中每个节点都有一个父节点，并且边缘始终指向较小的索引。 

我们必须首先将 1 到 n 的整数排列分配给节点，这意味着每张卡都会收到一个不同的标签。 之后，我们反复将叶子一片一片地除去。 每次删除叶子时，我们都会将其当前值附加到序列中。 此外，当删除节点时，如果父节点当前拥有较大的值，我们可以将其值“下推”到其父节点，从而有效地允许值沿着删除事件向上传播。 

最终的顺序是删除节点的顺序，但每个附加值可能会受到先前传播步骤的影响。 目标是选择叶子的初始排列和移除顺序，以最大化该结果序列的最长非递减子序列的长度。 

限制允许最多 100000 个节点。 任何比大约 O(n log n) 更差的解决方案都不会通过，因为构建结构和计算最优策略都必须是线性或接近线性的。 这立即排除了任何尝试模拟所有排列或直接评估子序列的解决方案。 

一个微妙的困难来自于节点上写入的值不固定。 在删除父项之前，父项可以被来自子项的值多次覆盖。 这意味着删除时节点的值取决于较早处理的子节点，并且最终序列不仅仅是静态标签的遍历顺序。 

打破天真的思维的一个边缘情况是一棵以节点 1 为中心的星形树。 如果所有节点都直接连接到 1，则任何叶子删除顺序都会严重影响节点 1 被覆盖的频率，因此可以极大地重塑序列。 仅通过树结构进行天真的贪婪排序会失败，因为它忽略了值传播效应。 

另一个失败案例是路径。 如果树是一条链，则每次删除都会强制传播一个方向，并且最优策略与如何沿深度分配排列密切相关，而朴素的子树独立推理无法捕获这一点。 

## 方法

 暴力方法将尝试分配所有排列并模拟所有有效的叶子移除顺序。 对于每次模拟，我们将计算结果序列，然后使用标准 O(n log n) LIS 算法计算其最长非递减子序列。 因为有 n! 排列和指数级多的有效移除顺序，即使对于非常小的 n，这也是完全不可行的。 即使固定排列，有效的叶子去除序列的数量也对应于树的所有拓扑顺序，其大小已经是指数级的。 

关键的观察结果是，操作“获取一片叶子，如果叶子较小，则可能将其值传播到其父代”，其行为类似于沿边缘的局部最小化过程。 父级最终会保留其自身的最小值，并且在删除之前处理​​所有已删除的后代。 这表明每个节点对最终序列的有效贡献不是其原始分配值，而是删除时其子树中看到的最小值。

这将问题转化为构建一个序列，其中每个节点贡献一个值，该值可以被认为是其子树中某些分配标签的最小值，并且我们可以通过选择排列和删除顺序来自由控制这些最小值。 关键结构变成了树的排序：我们本质上是在决定每个子树何时“折叠”到其父树中。 

下一个见解是扭转观点。 我们不考虑删除，而是考虑向上构建。 每棵子树在完全处理后都会贡献一个“代表值”，而这个代表值必须与较小的值倾向于更早向上传播的事实相一致。 

这导致了一个贪婪的想法：我们希望更大的值在序列中存活更长时间，以支持长的非递减子序列。 因此，我们希望在树深处分配较小的值，在靠近根的位置分配较大的值，同时确保在每个子树内，处理顺序允许值以受控方式传播，以便尽可能频繁地保留增加值。 

最佳解决方案简化为针对每个节点计算其子树的大小，并使用基于 DFS 的 DP 来确定当子树以最佳顺序合并时可以将多少元素排列成非递减子序列。 合并顺序类似于始终按照计算贡献的递增顺序处理子项，以便首先吸收较小的“链”，从而保留来自较大子树的较长单调链。 

一个有用的类比是合并排序序列以最大化 LIS：如果我们总是首先附加较小的结构，我们就可以避免破坏结果序列中增加的结构连续性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（模拟排列和删除）| O(n!·n log n) | O(n!·n log n) | O(n) | 太慢了|
 | 具有子树贪婪合并的树DP | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 从父数组构建有根树，以便每个节点都知道其子节点。 这建立了决定价值如何向上传播的结构。 
2. 从根开始运行DFS，独立处理每个子树。 目的是为每个节点计算其子树对最终非递减子序列的最佳可实现贡献。 
3. 对于每个节点，在组合它们之前递归计算所有子节点的结果。 每个子节点返回一个值，表示该子树内可实现的最佳结构。 
4. 在合并节点之前，按计算值按升序对节点的子节点进行排序。 这种排序确保较小的子结构首先被吸收，从而防止较大的增长模式过早被破坏。 
5. 按顺序合并子贡献。 在合并时，通过有效地将每个子树结果视为一个块，如果其值兼容，则可以扩展当前序列，从而保持最佳的非递减结构。 
6. 将当前节点的计算值向上返回到其父节点，表示如果将此子树视为一个单元，则可实现的最佳贡献。 

中心不变量是，对于每个节点，DFS 返回在最佳内部排序和值分配下从其子树可实现的非递减子序列的最大长度。 因为子树是按照其贡献的递增顺序合并的，所以任何较大的子树都不会被迫减少已经形成的最优链，因此每个节点的局部最优性在根处组成全局最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n = int(input())
    p = list(map(int, input().split()))

    g = [[] for _ in range(n)]
    for i, parent in enumerate(p, start=1):
        g[parent - 1].append(i)

    dp = [0] * n

    def dfs(u):
        for v in g[u]:
            dfs(v)

        child_vals = [dp[v] for v in g[u]]
        child_vals.sort()

        cur = 0
        for x in child_vals:
            if x >= cur:
                cur += 1

        dp[u] = cur + 1

    dfs(0)
    print(dp[0])

if __name__ == "__main__":
    solve()
```该程序使用邻接表构建树，以便每个节点都可以直接访问其子节点。 DFS 自下而上计算结果，确保每个子树在用于其父级计算之前得到完全解析。 

在每个节点内，列表`child_vals`收集所有儿童的捐款。 对这些值进行排序至关重要，因为它可以确保我们首先合并较小的结构贡献。 变量`cur`跟踪我们在将子子树一一集成时可以维护的最佳非递减链的长度。 每次我们看到可以扩展当前链的子值时，我们都会增加链长度。 

最后，每个节点加 1 来说明其自身，因为每个子树至少将节点本身贡献给任何有效的构造。

 ## 边缘情况

 深链测试 DP 是否正确地通过单一路径传播而不受兄弟节点的干扰。 在这种情况下，每个节点只有一个子节点，因此排序不会执行任何操作，DP 在每一级都会递增，产生等于 n 的答案。 

星形树测试算法是否正确处理许多独立的子节点。 由于所有子项都贡献相同的最小值，因此排序可以使它们保持稳定并允许根积累完整的递增链。 

n=2 的最小情况验证基本情况没有低估单个叶子及其父节点的贡献。
