 ## 解决方案
 ## 问题理解

 我们给出了几个独立的场景。 在每个场景中，Baq 都拥有一组硬币，每个硬币都有一个正整数值。 使用任意数量的这些硬币，他可以通过选择一个子集并将它们的值相加来得出总和。 问题不在于他能组成多少和，而在于不能表示为这样的和的最小正整数。 

因此，对于每个测试用例，我们有效地查看正整数多重集的所有子集和，并询问可实现的和集中的第一个间隙。 

关键的限制是硬币的数量可以很大，在最困难的情况下最多可达 10,000 个，而硬币的价值可以大到 10^9。 这立即排除了任何显式枚举子集和的尝试，因为即使对于中等的 n，子集和的数量也会呈指数增长。 即使对总和进行动态规划也是不可行的，因为总和范围是无界的并且可能非常大。 

天真的思维的一个微妙的失败案例是假设我们需要生成所有可达到的总和，然后扫描第一个缺失的总和。 例如，对于硬币 [1, 3]，可达到的总和为 {1, 3, 4}，因此缺少 2。 但如果我们尝试暴力破解所有组合，对于稍大的输入（例如 30 个任意硬币），我们已经超出了可行的计算范围。 

另一个误导性的直觉是，仅排序就足够了。 排序有助于构建推理，但如果没有正确的贪婪累加逻辑，它并不能直接得出答案。 

## 方法

 暴力破解的想法很简单：生成每个子集和，然后检查缺少哪个正整数。 这在概念上是有效的，因为它直接对可达性的定义进行建模。 然而，每个硬币都会使子集数量加倍，因此对于 n 个硬币，我们得到 2^n 和。 当 n = 40 时，这已经变得天文数字般大，并且约束允许最多 10,000 个硬币，使得这种方法从根本上是不可能的。 

关键的观察来自于转变的视角：我们不是跟踪所有和，而是跟踪我们已经可以从 1 开始连续形成的正整数的最小前缀。假设我们已经确定可以形成从 1 到 x 的每个值。 现在考虑一个新的硬币值 v。如果 v 大于 x + 1，则 x + 1 立即无法达到，因为所有现有总和最多为 x，并且添加 v 会超出间隙而不填充它。 如果 v 至多为 x + 1，那么我们可以将可达区间扩展到 x + v，因为 x 之前的每个值都可以与 v 组合以填充下一段。 

这种贪心区间扩张就是核心思想。 我们不考虑组合，而是维护可表示总和的不断增长的连续部分。 当一枚硬币无法弥补下一个缺失值时，第一个缺口就会出现。 

对硬币进行排序至关重要，因为我们希望首先处理小值，以尽可能有效地构建最小的连续范围。

 ## 算法演练

 1. 按非降序对硬币值进行排序。 这确保我们总是首先尝试扩展最小的可达范围。 
2. 初始化变量`reach = 0`，这意味着我们目前可以计算从 1 到`reach`不断地。 
3. 迭代每个币值`v`按排序顺序。 
4. 如果`v > reach + 1`，立即停止并输出`reach + 1`。 这是第一个无法形成的价值观，因为我们之间存在着无法弥合的鸿沟。 
5. 否则，更新`reach = reach + v`。 这扩大了连续可达范围。 
6.处理完所有硬币后，输出`reach + 1`，因为我们可以形成一切`reach`但除此之外什么也没有。 

步骤 4 中的关键推理是，如果在`reach + 1`，没有后来的硬币可以修复它，因为所有后来的硬币至少和`v`，因此也太大而无法填充缺失值。 

### 为什么它有效

 在处理排序硬币的某些前缀后的任何时刻，我们都保持以下不变式：范围内的每个整数`[1, reach]`可以使用加工硬币的某些子集来表示。 当我们看到一枚硬币时`v`这样`v <= reach + 1`，我们可以将其与所有先前可实现的总和相结合，以扩展可达到的范围，而不会产生间隙。 如果`v > reach + 1`，没有办法构造`reach + 1`，因为所有组合要么留在`[1, reach]`或超越它。 这个不变量保证了第一次违规恰好对应于最小的不可达到的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    arr = list(map(int, input().split()))
    arr.sort()

    reach = 0
    for v in arr:
        if v > reach + 1:
            break
        reach += v

    print(reach + 1)
```该解决方案首先对硬币进行排序，以便我们始终按升序考虑它们，这对于维持连续的可达间隔是必要的。 变量`reach`跟踪我们当前可以形成的最大连续总和。 每个硬币要么延长这个间隔，要么暴露一个缺口。 条件`v > reach + 1`准确捕获第一个无法到达的整数，因为`reach + 1`是任意阶段的最小缺失值。 

一个常见的实施错误是初始化`reach`错误地。 它必须从 0 开始，因为在使用任何硬币之前，只能实现空和，而我们关心的第一个正和是 1。另一个微妙的点是严格的不等式：使用`>=`而不是`>`破坏了正确性，因为一枚硬币等于`reach + 1`仍应扩大可达范围。

 ## 边缘情况

 对于值为 1 的单个硬币，排序后的数组为`[1]`。 算法集`reach = 1`，并且由于没有出现间隙，因此输出`2`。 这与只有 1 可构造且缺少 2 的事实相符。 

对于像这样的硬币`[2, 3]`，排序产生相同的顺序。 最初`reach = 0`，第一个硬币是 2。`2 > 1`，算法立即停止并返回`1`，正确识别不能形成正和。 

对于完全密集的集合，例如`[1, 2, 3, 4]`，每枚硬币满足`v <= reach + 1`，因此可达区间不断增长到 10，答案变为 11。这证实了当每个新硬币足够小以桥接下一个缺失整数时不会出现间隙的不变量。
