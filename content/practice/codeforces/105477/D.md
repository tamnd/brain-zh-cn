 ## 解决方案
 ## 问题理解

 城市可以建模为有向完整图，其中每个位置都是一个节点，并且每个有序的节点对都有一个旅行时间。 每个节点还有一个非负值，代表有多少游客站在那里。 旅行者从节点 0 开始，必须到达节点 1，只要总旅行时间不超过给定的限制 S，就允许节点之间的任何行走。 

在旅行过程中，路径每访问一个节点，就可以收集该节点的所有游客，但每个节点即使被访问多次，也只能贡献一次。 目标是选择从 0 到 1 的步行（可能会重新访问节点），该步行保持在时间限制内，并最大化所有不同访问节点上收集的游客的总和。 

输入给出了多个测试用例。 每个测试用例提供节点数 n、时间限制 S、列表 t（其中 t[i] 是节点 i 处的游客数量）以及 n × n 矩阵 a，其中 a[i][j] 是直接从 i 到 j 的时间。 

关键的困难在于，即使图是完整的，最佳路线也可能会重新访问节点，因为重新访问在奖励方面是免费的，但仍然消耗时间。 约束 S 高达 20000，因此当 n 达到 18 时，对所有节点子集的直接动态编程将不可行，因为 2^18 状态已经需要仔细处理，并且转换将涉及额外的因子 n。 

当多条路径以不同的剩余预算到达同一节点时，就会出现一个微妙的问题。 一个天真的最短路径想法失败了，因为我们不是最小化时间，而是在时间预算下最大化收集的权重，因此帕累托在时间和收集的价值之间进行权衡很重要。 

该陷阱的一个简单示例是较长的路线较早访问高价值节点，而较短的路线快速到达目的地但收集的信息较少。 如果我们只存储每个节点的最短时间，我们就会放弃更长但更有利可图的路径并失去最佳答案。 

## 方法

 该结构表明我们在具有预算约束的完整有向图中选择一条路径，其中每个节点都收集一次奖励。 这立即类似于访问节点子集上的状态空间，但完整子集 DP 将跟踪（掩码，最后一个节点），当 n 为 18 时，该子集太大。 

暴力方法将枚举访问节点子集的所有排列，计算连续选定节点之间的最短路径成本，并对奖励求和。 即使忽略路径计算，这也是 n 的阶乘。 对于 n = 18，排列已经超出了可行的限制。 

关键的观察是 n 足够小，我们可以将子集视为状态，但 S 足够适中，可以预先计算节点之间的最短路径。 一旦知道了所有对的最短路径，问题就简化为节点上的经典位掩码 DP，其中转换对应于使用最短路径距离从一个选定节点移动到另一个节点。 

我们首先在矩阵上运行 Floyd-Warshall，以确保 a[i][j] 代表任意两个节点之间真正的最短旅行时间。 然后我们定义一个 DP，其中 dp[mask][i] 是精确访问设置的 mask 并在节点 i 结束时收集的最大游客量，通过使用最短距离的转换隐式地尊重旅行成本约束。 

然而，直接的 O(2^n * n) DP 仍然忽略 S。我们通过注意到 S 仅限制转换的可行性来进一步细化。 由于 n ≤ 18，我们可以保留 dp[mask][i]，但使用距离和修剪转换。 如果 dp time + dist[i][j] ≤ S，则最终的转换是从 (mask, i) 到 (mask ∪ {j}, j)。我们需要跟踪时间和值，因此每个状态都存储最佳对，并且我们丢弃主导状态。

这导致了帕累托DP，其中对于每个（掩码，i），我们维护一组（时间，奖励）对，仅保留非支配对。 过渡仔细地组合了这些集合。 

更有效的重新表述通过反转视图来避免随着时间的推移出现指数DP：我们预先计算最短距离，然后对状态（掩码，i）执行类似迪杰斯特拉（Dijkstra）的扩展，其中优先级是时间，我们跟踪每个状态（掩码，i，时间边界）的最佳奖励。 因为 S ≤ 20000，我们可以通过修剪超过 S 的状态并通过最佳已知隐式保留每个 (mask, i, t) 的最佳奖励来进行离散化。 

这简化为大小为 O(2^n * n) 的图上的多状态最短路径，但每个边松弛的时间复杂度为 O(1)，并且优先级队列确保每个状态都得到有效处理。 

最终的答案是在时间≤S时以节点1结束的所有状态中的最大奖励。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力排列 | O(n!) | O(n) | 太慢了 |
 | 无需修剪的位掩码 DP | O(2^n n^2) | O(2^n n^2) | O(2^n n) | O(2^n n) | 太慢了 |
 | 状态 Dijkstra (掩码，节点) | O(2^n n log(2^n n)) | O(2^n n log(2^n n)) | O(2^n n) | O(2^n n) | 已接受 |

 ## 算法演练

 我们分两层构建解决方案：最短路径和约束状态探索。 

1. 使用 Floyd-Warshall 计算所有对最短路径，以便在任意两个节点之间移动时具有明确定义的最小行程时间。 这样就无需在 DP 转换期间考虑中间节点。 
2. 定义一个状态为(mask, u)，这意味着我们已经访问了mask中编码的节点集，并且当前位于节点u。 
3. 初始化一个优先级队列，状态为(time=0,reward=t[0],mask=1<<0,u=0)。 这表示从节点 0 开始收集游客。 
4.维护到最小已知时间的最佳字典映射（mask，u）以实现最大已知奖励。 仅当状态改进了该配置的先前知识时，我们才会扩展状态。 
5. 按时间升序从优先级队列中弹出状态。 对于每个状态（mask，u），尝试移动到不在 mask 中的每个节点 v。 转换成本为 current_time + dist[u][v]，新奖励为 current_reward + t[v]。 
6. 如果新时间超过S，则放弃该转换。 否则，如果这个新状态改进了 (mask ∪ {v}, v) 的最佳已知条目，则将其推入优先级队列。 
7. 处理完所有可达状态后，扫描所有 u = 1 且 time ≤ S 的状态并取最大奖励。 

关键的结构是，除非我们以有意义的方式改善时间或奖励，否则我们永远不会重新访问某个状态。 由于时间仅随着转变而增加，而 S 限制了它，因此探索仍然是有限的。 

### 为什么它有效

 每个状态代表一组独特的访问节点和结束位置，并且按时间排序的优先级确保每当我们最终确定一个状态时，我们已经考虑了所有更便宜的方式来达到它。 由于奖励仅在添加新节点时增加，并且节点永远不会在掩码中重复计算，因此每个状态都充分总结了导致该状态的所有有效历史。 剪枝规则避免丢失最优解，因为任何主导状态在不超过 S 或重复访问的情况下都无法导致更好的完成。 

## Python 解决方案```python
import sys
import heapq

input = sys.stdin.readline

def solve():
    n, S = map(int, input().split())
    t = list(map(int, input().split()))
    dist = [list(map(int, input().split())) for _ in range(n)]

    # Floyd-Warshall for all-pairs shortest paths
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][j] > dist[i][k] + dist[k][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    start_mask = 1 << 0
    start_reward = t[0]

    # (time, -reward, mask, node)
    pq = [(0, -start_reward, start_mask, 0)]

    best_time = {}

    best_time[(start_mask, 0)] = 0

    ans = start_reward if 1 == 1 else 0

    while pq:
        time, neg_reward, mask, u = heapq.heappop(pq)
        reward = -neg_reward

        if time > S:
            continue

        if best_time.get((mask, u), float('inf')) < time:
            continue

        if u == 1:
            ans = max(ans, reward)

        for v in range(n):
            if mask & (1 << v):
                continue
            nt = time + dist[u][v]
            if nt > S:
                continue
            nmask = mask | (1 << v)
            nr = reward + t[v]

            state = (nmask, v)
            if nt < best_time.get(state, float('inf')):
                best_time[state] = nt
                heapq.heappush(pq, (nt, -nr, nmask, v))

    print(ans)

if __name__ == "__main__":
    solve()
```Floyd-Warshall 块确保每次转换成本最小，因此 DP 永远不必再次推理中间路径。 堆确保我们始终首先扩展当前最快的已知部分路径，这对于修剪至关重要。 

状态编码使用位掩码来保证每个旅游团最多被计数一次。 best_time 字典可以防止重新访问同一状态的更差版本，否则状态空间将会爆炸。 

一个微妙的细节是奖励不是修剪关键的一部分。 具有相同（掩码、节点）但时间和奖励不同的两个状态仅通过时间来比较主导地位，因为如果在 S 下导致更好的完成，较高时间的较高奖励可能仍然有用。优先级队列排序确保我们首先探索较早的时间，因此我们不会丢失最佳链。

 ## 边缘情况

 当停留在节点 0 并直接跳到节点 1 比任何绕道都便宜，但绕道会收集更多游客时，会出现一个极端情况。 该算法正确地探索了两者，因为它不会通过奖励进行修剪。 

另一种情况是多个中间节点形成一个低成本环路。 DP 允许仅通过掩码重新访问节点，因此循环不会创建无限循环。 

最后一个微妙的情况是两个状态达到相同（掩码、节点）但时间不同。 仅存储最小的时间，但由于我们总是按递增的时间顺序扩展，因此任何后来的更差时间状态都无法在同一掩码内产生更好的延续，从而保持最优性。
