 ## 解决方案
 ## 问题理解

 给我们一些袜子，并要求我们确定可以组成多少双完整的袜子。 一双袜子恰好由两只袜子组成，因此任务简化为将袜子分成尺寸为 2 的不相交的组，并计算可以组成多少个这样的组。 

输入最多包含两个测试用例，对于每个测试用例，我们都会给出一个整数$n$，可用袜子的数量。 每个测试用例的输出是最大配对数，这意味着我们可以在没有颜色或限制等额外约束的情况下以最佳方式配对袜子。 

的约束条件为$n$非常小，在 34 到 35 之间。这立即排除了任何优化问题的需要。 任何$O(1)$甚至$O(n)$方法就足够了。 事实上，问题的结构强烈表明不需要模拟或复杂的处理，因为没有超出计数的附加结构。 

不存在涉及排序或安排的微妙的极端情况。 唯一潜在的边缘情况是$n$是偶数还是奇数。 如果$n$均匀，所有袜子都可以完美搭配。 如果$n$奇怪的是，只有一只袜子仍未配对。 

一个幼稚的错误是尝试通过模拟进行配对而不正确处理剩余部分。 例如，如果$n = 35$，一个天真的循环一次配对两个，直到耗尽，如果使用不正确的边界实现，可能会意外地超出或错误处理最后一个单例。 这种情况下的正确答案很明显$17$， 自从$35 = 2 \cdot 17 + 1$。 

另一种可能的错误方法是由于示例在视觉上串联而假设输入格式中存在某种隐藏结构。 然而，每个测试用例都是独立的，只依赖于它自己的$n$。 

## 方法

 强力解释将显式模拟配对过程。 我们可以反复脱下两只袜子，并计算我们执行了多少次这样的移除，直到剩下的袜子少于两只为止。 这是正确的，因为每个操作完全对应于形成一对有效的操作。 然而，即使这是正确的，但考虑到问题的简单性，这是不必要的开销。 

关键的观察结果是，贪婪地配对袜子是最优的和确定性的。 每双正好消耗两只袜子，因此对的数量完全由整数除法确定$n$2. 不存在选择不同会改变结果的情况，因为对于哪些袜子可以与哪些袜子搭配没有限制。 

这将问题简化为每个测试用例一次算术运算。

 ## 算法演练

 1.读取测试用例数量$t$。 每个测试用例都是独立的，因此我们单独处理它们。 
2. 对于每个测试用例，读取整数$n$，代表袜子的数量。 
3. 通过除法计算完整对的数量$n$使用整数除法除以 2。 这是有效的，因为每双袜子正好消耗两只袜子，并且任何剩余的袜子都不能形成一双。 
4. 输出该测试用例的计算值。 

### 为什么它有效

 每双有效的袜子都需要两只不同的袜子，并且没有任何限制阻止任何两只袜子配对。 因此，问题归结为划分一组大小$n$尽可能分成大小为 2 的组。 这种不相交组的最大数量恰好是$n/2$。 没有其他配对策略可以增加此计数，因为每对消耗两个元素并且没有重用。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input().strip())
for _ in range(t):
    n = int(input().strip())
    print(n // 2)
```该解决方案读取测试用例的数量并独立处理每个测试用例。 对于每个$n$，整数除以 2 直接得出完整对的数量。 

唯一重要的实现细节是确保每行输入都被干净地解析。 因为$t \le 2$，即使是意外的开销也没关系，但为了正确性和一致性，仍然使用标准的快速 I/O 模式。

 ## 边缘情况

 唯一有意义的边缘情况是当$n$很奇怪。 为了$n = 35$，算法计算$35 // 2 = 17$。 在内部，不需要特殊处理，因为整数除法自然会丢弃剩余的 sock。 

追踪$n = 35$:

 步骤 1 读取$n = 35$。 步骤 2 应用整数除法，产生 17。步骤 3 输出 17。剩下的袜子被隐式忽略，因为它无法形成一对。 

这证实了该实现可以正确处理偶数和奇数值，而无需分支或特殊逻辑。
