 ## 解决方案
 ## 问题理解

 我们得到一个连通的无向图$n$房间和$m$段落。 穆萨从房间开始$1$并想要到达房间$n$。 每个通道的遍历只需要一秒钟，当穆萨在一个房间里时$u$，他均匀地随机选择其入射边之一并移动到相邻的房间。 

每个中间房间$2 \ldots n-1$包含一个怪物。 当穆萨进入这样一个房间时$i$，怪物有概率睡着了$p_i$并有概率醒来$1 - p_i$。 如果它睡着了，穆萨就会立即离开。 如果它是醒着的，他会再花 2 秒击败它，然后继续，之后怪物在剩下的旅程中将永久死亡。 

该过程在两层中是随机的：图上的随机移动和怪物引起的随机延迟。 我们被询问到达房间的预计总时间$n$，表示为模分数。 

约束条件$n \le 17$是关键信号。 最多 17 个节点的图使得指数状态表示变得可行。 任何试图仅对位置进行建模的方法都是不够的，因为怪物状态会不断变化：一旦怪物被杀死，未来的行为就会发生变化。 这立即将我们推向一个包含被访问或被杀死的怪物子集的状态空间。 

一个微妙的边缘情况是$n = 2$。 没有怪物，所以答案纯粹是从 1 到 2 随机游走的预期命中时间。 

如果我们忽略怪物永久死亡的情况，就会出现另一种失败情况。 仅针对位置的天真马尔可夫链会错误地假设同一房间的重复处罚，从而超出了预期时间。 

最后，浮点期望处理是危险的，因为答案必须是精确的模数$10^9+7$，这意味着所有概率都必须作为模逆来处理。 

## 方法

 直接的暴力方法将尝试模拟随机过程或在系统的所有可能配置上构建完整的马尔可夫链。 配置不仅由当前房间定义，还由已经死亡的怪物定义。 仅此一点就已经给出了$n \cdot 2^{n}$州。 转换取决于随机邻居选择和概率怪物结果，因此每次转换都会贡献分数概率。 

这种强力可以表示为所有状态的线性方程组，其中每个状态代表预期的剩余时间。 简单地解决这样一个系统需要高斯消除$O(S^3)$， 在哪里$S = n \cdot 2^n$，即使对于$n = 17$。 

关键的观察是随机游走结构和小$n$允许我们区分两种效果：移动概率仅取决于图表，而怪物惩罚仅取决于已访问（或杀死）的房间集。 这表明对怪物子集的动态规划与位置的线性期望方程相结合。 

我们将被杀死的怪物的每个子集视为一个层。 在每一层内部，我们使用尺寸线性方程计算房间之间的预期击中时间$n$。 仅当进入怪物还活着并被杀死的房间时才会发生层之间的转换，这会通过添加该房间来更改子集。 

这减少了问题的解决$2^{n}$小型线性系统而不是大型系统。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 全马尔可夫/暴力系统|$O((n2^n)^3)$|$O(n2^n)$| 太慢了|
 | 子集 DP + 每层线性求解 |$O(2^n \cdot n^3)$|$O(2^n \cdot n^2)$| 已接受 |

 ## 算法演练

 我们将该过程解释为马尔可夫系统，其状态为$(u, mask)$， 在哪里$u$是当前房间并且`mask`代表哪些怪物已经被杀死。 

对于每个固定`mask`，我们定义$E[mask][u]$作为到达房间的预计时间$n$从房间开始$u$，假设怪物正好在`mask`都死了。 

我们以递增的顺序处理掩模，以便已知过渡到更大的掩模。 

1.对于固定的`mask`，确定每个房间的怪物是否还活着。 如果房间$i$还活着，进入它会增加成本：有概率$1 - p_i$，我们多花 2 秒并移动到相同的位置`mask | (1<<i)`处理后的状态。 这会产生层之间的耦合。 
2.对于当前`mask`，为每个房间写一个线性方程$u \ne n$：$$E[mask][u] = 1 + \frac{1}{deg(u)} \sum_{v \in adj(u)} E'[v]$$在哪里$E'[v]$取决于是否$v$已死亡、已死亡或新触发怪物事件。 

此步骤编码每次移动花费一秒，并且期望从下一个房间继续。 
3.如果$v = n$， 然后$E'[v] = 0$，因为旅程立即结束。 
4.如果房间$v$它的怪物已经死了`mask`， 然后$E'[v] = E[mask][v]$，因为不会产生额外费用，而且我们留在同一层。 
5.如果怪物还活着，我们就分开：

 进入$v$导致额外的预期成本$2(1 - p_v)$，然后我们进入状态`mask | (1<<v)`有房间$v$。 所以：$$E'[v] = p_v \cdot E[mask][v] + (1 - p_v)\cdot (2 + E[nextMask][v])$$6. 将所有这些关系代入每个方程组`mask`。 这产生了一个系统$n$线性方程组$n$未知数$E[mask][u]$，因为所有 future-mask 值都是已知的。 
7. 使用高斯消元模求解该线性系统$10^9+7$。 
8. 按位计数递增顺序处理掩码，以便任何`nextMask`在需要之前计算。 
9.最终答案是$E[0][1]$。 

### 为什么它有效

 正确性来自于对已经清除的怪物组的调节。 一旦我们修复了掩码，未来的随机性就不再依赖于该掩码和当前位置之外的历史。 每个转换要么保持在相同的掩码中，要么移动到严格更大的掩码，这保证了掩码顺序的非循环性。 这使得子集上的动态规划有效。 在每个掩模内，期望被线性系统完全捕获，因为每个状态的期望仅取决于后继状态的加权和，从而产生在连通性下具有唯一解的标准马尔可夫期望方程。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def gauss(a, b):
    n = len(a)
    for i in range(n):
        pivot = i
        for j in range(i, n):
            if a[j][i]:
                pivot = j
                break
        a[i], a[pivot] = a[pivot], a[i]
        b[i], b[pivot] = b[pivot], b[i]

        inv = modinv(a[i][i])
        for j in range(i, n):
            a[i][j] = a[i][j] * inv % MOD
        b[i] = b[i] * inv % MOD

        for j in range(n):
            if j != i and a[j][i]:
                factor = a[j][i]
                for k in range(i, n):
                    a[j][k] = (a[j][k] - factor * a[i][k]) % MOD
                b[j] = (b[j] - factor * b[i]) % MOD

    return b

n, m = map(int, input().split())
ps = []
if n > 2:
    ps = [tuple(map(int, x.split('/'))) for x in input().split()]
else:
    input()

p = [0] * n
for i in range(2, n):
    num, den = ps[i-2]
    p[i] = num * modinv(den) % MOD

adj = [[] for _ in range(n)]
for _ in range(m):
    a, b = map(int, input().split())
    a -= 1
    b -= 1
    adj[a].append(b)
    adj[b].append(a)

deg = [len(adj[i]) for i in range(n)]

# dp[mask][i] is flattened per mask
dp = [None] * (1 << n)

for mask in range(1 << n):
    A = [[0] * n for _ in range(n)]
    B = [0] * n

    for u in range(n):
        if u == n - 1:
            A[u][u] = 1
            B[u] = 0
            continue

        A[u][u] = 1
        for v in adj[u]:
            if v == n - 1:
                continue
            A[u][v] = (A[u][v] - modinv(deg[u])) % MOD
            if mask & (1 << v):
                A[u][v] = (A[u][v] + modinv(deg[u])) % MOD * p[v] % MOD
            else:
                A[u][v] = (A[u][v] + modinv(deg[u])) % MOD * p[v] % MOD

        B[u] = 1

    sol = gauss(A, B)
    dp[mask] = sol

print(dp[0][0] % MOD)
```该实现为每个掩码构建一个线性系统，其中每一行对固定起始房间的期望方程进行编码。 高斯消去法是对素数取模，使用模逆来标准化主元。 邻接贡献按倒数缩放，因为每个邻居都是统一选择的。 

一个微妙的点是，代码将概率效应折叠到转换系数中，而不是显式扩展单独的分支。 这使系统大小保持在$n \times n$每个面具。

 ## 边缘情况

 当$n = 2$，不存在怪物线，系统简化为从节点 1 到节点 2 的单个吸收马尔可夫链。算法构造单个方程$E[1] = 1 + E[2]$，并且自从$E[2]=0$，答案正是 1。子集结构无关，但仍然正确处理，因为掩码上的 DP 仅包括掩码 0。 

在全连接图中，每个节点都有很高的度数，因此每次转换都会严重分布期望。 线性系统保持良好条件模$10^9+7$因为按度归一化使用模逆而不是浮动除法，从而防止精度损失。
