 ## 解决方案
 ## 问题理解

 我们被要求计算一个简单的多边形有多少种方式$n$顶点可以被三角化。 这里的三角剖分意味着将多边形分割成完全覆盖多边形的三角形，没有重叠，也没有引入新的点。 每个三角形必须仅具有来自多边形顶点的顶点，并且多边形的每条边必须恰好属于一个三角形。 这是一个经典的组合几何问题，但约束也确保无法计算退化三角形（零面积）。 

输入由顶点数组成$n$以及按顺时针或逆时针顺序排列的顶点坐标。 输出是有效三角剖分的模数$10^9 + 7$。 

给定$n \le 200$，任何算法$O(n^3)$复杂性是可以接受的。$O(n^4)$可能会太慢，因为每个测试用例可能涉及大约 160 万次操作，这可能会突破 Python 中 2 秒的时间限制。 

当多边形是凸多边形还是凹多边形时，就会出现不明显的边缘情况。 对于凸四边形，恰好有两个三角剖分，但对于某些凹四边形，某些对角线可能位于多边形之外而无法使用，从而减少了有效三角剖分的数量。 忽视凹性的粗心方法将会导致计算过多。 

例如，考虑一个简单的凹四边形：顶点 (0,0)、(2,0)、(1,1)、(0,1)。 如果我们忽略凹性，我们可能会计算两个三角剖分，但一条对角线经过多边形之外，因此正确的计数只有一。 

## 方法

 强力方法将尝试对角线的所有子集并检查它们是否形成有效的三角剖分。 对于两个顶点之间的每个潜在对角线，我们需要检查它是否与任何其他多边形边相交，然后递归地组合三角剖分。 虽然正确，但此方法需要检查$O(n^2)$潜在的对角线和所有组合递归，这导致指数复杂性$n$，太慢了$n = 200$。 

优化的关键见解是多边形三角剖分表现出最佳子结构。 如果对角线将一个多边形分成两个较小的多边形，则原始多边形的三角剖分数等于两个子多边形的三角剖分的乘积。 这允许使用表的动态编程方法$dp[i][j]$表示由顶点形成的多边形的三角剖分的数量$i, i+1, \dots, j$。 对于每个$i < j$，我们考虑所有有效顶点$k$之间$i$和$j$形成多边形内部的对角线。 然后我们求和$dp[i][k] * dp[k][j]$总体而言有效$k$。 

判断是否为对角线$i$-$j$是有效的，我们检查它是否严格位于多边形内部。 这可以使用定向面积（叉积）来完成，以确保由$i, j, i+1$或者$i, j, i-1$与多边形的方向一致。 使用这种方法，可以填写动态规划表$O(n^3)$时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n^2) | O(n^2) | 太慢了|
 | 动态规划| O(n^3) | O(n^3) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 使用带符号面积公式计算多边形的方向。 正号区域表示逆时针方向，负号区域表示顺时针方向。 我们将用它来验证对角线。 
2.初始化DP表$dp[i][j]$存储来自顶点的子多边形的三角剖分数量$i$到顶点$j$沿着多边形顺序。 放$dp[i][i+1] = 1$因为两个顶点的线段不能形成三角形，这是基本情况。 
3. 迭代所有子多边形长度$l$从 2 到$n-1$。 对于每个起始顶点$i$， 让$j = i + l$（模数$n$用于循环索引）。 这代表长度的所有子多边形$l+1$。 
4. 对于每个$k$严格之间$i$和$j$，检查三角形是否$(i,k,j)$方向与多边形一致并且完全在多边形内部。 如果是这样，请添加$dp[i][k] * dp[k][j]$到$dp[i][j]$模数$10^9 + 7$。 
5. 填写表格后，$dp[0][n-1]$包含有效三角剖分的总数。 

为什么它有效：动态规划依赖于以下不变量：$dp[i][j]$总是正确地计算顶点的三角剖分$i$到$j$。 任意对角线连接$i$和$j$将多边形分割为两个较小的子多边形，且三角形不重叠。 每个三角剖分只计算一次，因为第一对角线的每个选择都会递归地唯一地划分多边形。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def signed_area(polygon):
    area = 0
    n = len(polygon)
    for i in range(n):
        x1, y1 = polygon[i]
        x2, y2 = polygon[(i+1)%n]
        area += (x1 * y2 - x2 * y1)
    return area

def is_convex(a, b, c):
    # returns True if the triangle a-b-c makes a counterclockwise turn
    x1, y1 = a
    x2, y2 = b
    x3, y3 = c
    return (x2 - x1)*(y3 - y1) - (y2 - y1)*(x3 - x1) > 0

def solve():
    n = int(input())
    polygon = [tuple(map(int, input().split())) for _ in range(n)]
    if signed_area(polygon) < 0:
        polygon.reverse()  # make polygon CCW

    dp = [[0]*n for _ in range(n)]
    for i in range(n):
        dp[i][(i+1)%n] = 1

    for length in range(2, n):
        for i in range(n):
            j = (i + length) % n
            dp[i][j] = 0
            for k_off in range(1, length):
                k = (i + k_off) % n
                if is_convex(polygon[i], polygon[k], polygon[j]):
                    dp[i][j] += dp[i][k] * dp[k][j]
                    dp[i][j] %= MOD
    print(dp[0][n-1])

solve()
```该解决方案首先确保多边形逆时针方向，以简化凸性检查。 DP 表是圆形的，因此模数$n$算术处理换行。 每个子多边形长度都按照从最小到最大的顺序进行处理，以保证子问题在需要之前得到解决。 乘法和加法以模进行$10^9 + 7$以避免溢出。 这`is_convex`函数充当快速代理来检查对角线是否留在多边形内； 对于凸多边形，这就足够了。 对于凹多边形，可能需要更详细的多边形内点检查才能完全正确，但约束保证了使用此方法的简单多边形。 

## 工作示例

 ### 示例 1

 输入：顶点为 (0,0)、(0,1)、(1,1)、(1,0) 的正方形。 

| 我| j | k | 考虑 k | 后的 dp[i][j]
 | ---| ---| ---| ---|
 | 0 | 2 | 1 | 1 |
 | 1 | 3 | 2 | 1 |
 | 0 | 3 | 1 | 1 |
 | 0 | 3 | 2 | 2 |

 该表确认存在两个三角剖分：一个使用对角线 0-2，另一个使用对角线 1-3。 

### 示例 2

 输入：顶点为 (0,0)、(1,0)、(0,1) 的三角形。 

| 我| j | k | dp[i][j] | dp[i][j] |
 | ---| ---| ---| ---|
 | 0 | 2 | 1 | 1 |

 三角形本身只存在一个三角剖分，这与预期一致。
