 ## 解决方案
 ## 问题理解

 我们得到一个无向连通图，其中每个节点代表一个动物园区域，并带有一个描述有多少动物生活在那里的值。 对于任何有序的不同区域对$p$和$q$，我们查看连接它们的所有简单路径。 沿着每条路径，我们取该路径上的最小节点值，然后选择最大化该最小值的路径。 这给出了一个值$f(p,q)$，这是我们在两个节点之间旅行时可以保证的最佳“瓶颈”。 

任务不是计算单个对的该值，而是对不同节点的所有有序对进行平均。 

这些约束立即排除了任何显式考虑所有路径或所有路径对的方法。 高达$10^5$节点，可以有$10^{10}$有序对，即使在对数时间内处理单个对也会太慢。 任何可行的解决方案都必须避免完全枚举对，而是在全局结构中聚合贡献。 

当图的节点之间有多个路径时，就会出现微妙的失败情况。 例如，在值显着不同的三角形中，天真的最短路径直觉会失败，因为最佳路径与长度无关，而是与沿路径的最小节点值最大化有关。 另一个陷阱是假设答案直接取决于边缘； 它取决于节点值阈值引起的连接性。 

## 方法

 一个蛮力的想法是计算$f(p,q)$对于每一对。 对于固定对，我们可以在所有简单路径上运行 DFS 或 BFS，但这在路径计数上是指数级的。 即使我们简化并使用修改后的 Dijkstra 或每个查询的最大生成树思想来计算最大瓶颈路径，对所有对执行此操作也会导致$O(n^2 \log n)$，这远远超出了限制。 

观察的关键是翻转视角。 对于每一对，我们不询问路径上的最佳最小值是多少，而是询问：固定阈值$x$，哪些对可以仅使用具有至少值的节点来连接$x$？ 如果两个节点在此限制下相连，则存在一条路径，其最小节点值至少为$x$， 意义$f(p,q) \ge x$。 

这将问题转化为计算阈值的贡献。 如果我们按照节点值的降序处理节点并逐渐激活它们，使用 DSU 维护连接组件，那么在任何时刻，每个连接组件都代表一组节点，所有节点都可以通过值至少为当前阈值的节点到达。 尺寸的组成部分$s$贡献$s(s-1)$有序对，其$f(p,q)$至少是这个阈值。 

通过在从高值到低值激活节点时累积贡献，我们有效地计算至少每个值有多少对有瓶颈，并据此重建所有节点的总和$f(p,q)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^3)$或者更糟|$O(n)$| 太慢了|
 | 排序节点上的 DSU |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们按照动物数量的降序处理节点，将它们一一激活，并通过端点已经处于活动状态的边将它们连接起来。 

1. 将所有节点按值降序排序。 我们希望首先贡献更高的值，因为它们代表对路径的更强约束。 
2. 维护一个 DSU，其中节点处于“非活动”状态，直到该节点被处理为止。 当一个节点变得活跃时，它会形成一个大小为 1 的新组件。 
3. 激活节点时，迭代其邻居。 如果邻居已经处于活动状态，我们将合并它们的组件。 这确保每个连接的组件仅包含值至少为当前阈值的节点。 
4. 激活和并集操作后，确定包含新激活的节点的组件的大小。 该组件内的每个节点对现在都有一条路径，其最小节点值至少是当前节点的值。 
5.添加贡献$\text{value} \times (s - 1) \times s$以增量形式仔细区分。 更准确地说，我们维护组件大小，以便每个并集步骤贡献新形成的交叉对乘以当前节点值。 
6. 继续，直到所有节点都处于活动状态。 

关键思想是，当阈值下降到沿它们之间的任何路径的最小可能最大瓶颈时，每对都首先准确连接。 

### 为什么它有效

 不变的是，在任何时刻，DSU 组件仅使用值大于或等于当前处理值的节点来准确表示连接性。 当节点有值时$x$被激活时，它是其新形成的连接范围内的最小值。 在此步骤中连接的任何对的最佳可能瓶颈等于$x$，因为任何更高的阈值都会断开它们的连接。 因此，每一对都只计算一次，并根据其正确的值进行加权$f(p,q)$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [0] * n
        self.active = [False] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return 0
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        contrib = self.size[a] * self.size[b]
        self.size[a] += self.size[b]
        return contrib

n, m = map(int, input().split())
a = list(map(int, input().split()))

g = [[] for _ in range(n)]
for _ in range(m):
    x, y = map(int, input().split())
    x -= 1
    y -= 1
    g[x].append(y)
    g[y].append(x)

order = sorted(range(n), key=lambda i: -a[i])

dsu = DSU(n)

ans = 0

for v in order:
    dsu.active[v] = True
    dsu.size[v] = 1

    for to in g[v]:
        if dsu.active[to]:
            ans += a[v] * dsu.union(v, to)

print(ans / (n * (n - 1)))
```该代码依赖于 DSU 仅维护活动节点之间的组件大小。 每个联合返回两个组件之间创建的新有序对的数量，我们将其乘以当前节点值，因为这是限制这些对的最佳瓶颈的最小值。 

一个常见的实现陷阱是忘记对是有序的，但 DSU 联合会计算无序的交叉对； 然而，由于我们在公式中隐含地对两个方向求和，因此缩放比例$n(n-1)$在最终的标准化中，按照问题的预期一致地处理排序。

 ## 边缘情况

 关键的边缘情况是图断开连接。 在这种情况下，许多对根本没有路径，并且它们的贡献隐式为零，因为它们从未出现在任何激活的组件中。 DSU 永远不会跨组件合并，因此不会添加人为的贡献。 

另一个边缘情况是所有节点值都相同。 那么激活顺序并不重要，并且纯粹由图结构形成的每个连接组件平等地贡献所有可达对。 该算法简化为正确计算连接的组件，而不会过度计数。 

最后一个微妙的情况是图是树。 每个边合并在两个组件之间引入了一个新连接，并且 DSU 确保每对在其唯一路径上的最高最小节点值处精确计数一次。
