 ## 解决方案
 ## 问题理解

 密室由大小为 _n_ × _m_ 的网格表示，其中每个单元格要么是空的，要么包含一列。 蛇怪驻扎在右下角并向左看，而试图进入的人则从左上角开始向右看。 规则的柱子可以让蛇怪的目光直接穿过，但如果一根柱子被施了魔法，它就会从四个方向反射目光。 任务是确定必须施魔法的最小柱数，以便任何进入密室的人都不可避免地会遇到反射的凝视并被石化，或者报告说这是不可能的。 

输入是网格的尺寸和每个单元格的描述，其中`.`代表空单元格和`#`代表常规列。 输出是确保完全安全所需的最小魔柱数量或`-1`如果没有安排就足够了。 

_n_ 和 _m_ 最大为 1000 的约束表明复杂度超过 O(n_m_log(n*m)) 的算法可能会太慢。 这排除了模拟魔柱所有可能配置的方法，这些配置在魔柱数量上呈指数级增长。 边缘情况包括左上角或右下角单元格被阻挡的网格、根本没有列的网格、或者列形成断开区域的网格。 

例如，一个包含所有空单元格的 2x2 网格：```
..
..
```应该输出`-1`因为没有魔法柱，所以进入的人可以完全避开蛇怪。 假设至少存在一列的粗心方法在这里会失败。 

## 方法

 蛮力方法会尝试所有列的子集来创造魔法并模拟蛇怪凝视和人的运动的传播。 原则上这是正确的，因为它会检查每种可能的配置，但在计算上是不可行的：对于最多 10^6 个单元，列子集的数量可能是 2^(n*m)，远远超出了任何合理的计算。 

关键的见解来自于将其建模为图表上的最短路径问题。 每个单元都是一个节点，边将四个基本方向上的每个单元连接到下一个单元，但前提是蛇怪的凝视规则允许移动。 制作列魔法对应于启用表示反射的附加边缘。 目标是找到最少数量的魔法柱，使得从入口到出口的每条路径都与魔法柱相交。 这减少了计算网格中的最短路径，其中每个幻列的成本为一。 

通过应用 0-1 BFS，其中穿过空单元格的成本为零，而制作列魔法的成本为 1，我们可以有效地找到所需的魔法列的最小数量。 这种方法利用网格的结构，避免探索不可能的配置，并保证正确性，因为 BFS 按总成本递增的顺序探索路径。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(n_m) * n_m) | O(2^(n_m) * n_m) | O(n*m) | 太慢了|
 | 0-1 BFS /最短路径| O(n*m) | O(n*m) | 已接受 |

 ## 算法演练

 1. 读取网格尺寸和网格本身。 确定所有列的位置。 
2. 初始化成本矩阵`dist`大小为 n x m，无穷大。 这将存储从左上角到达每个单元格所需的最小魔法列数。 
3、使用双端队列实现0-1 BFS。 将起始位置 (0, 0) 推入队列，成本为 0。 
4. 当队列不为空时，弹出一个单元格`(i, j)`。 对于四个方向（上、下、左、右）中的每一个，确定下一个单元格`(ni, nj)`。 
5. 如果`(ni, nj)`在范围内，计算新的成本。 如果下一个单元格包含常规列，则新成本是当前成本加 1（这很神奇）。 否则，成本保持不变。 
6. 如果这个新成本小于`dist[ni][nj]`， 更新`dist[ni][nj]`并推`(ni, nj)`如果成本没有增加，则移至队列的前面；如果成本增加，则移至队列的后面。 
7. BFS完成后，检查`dist[n-1][m-1]`。 如果无穷大，则输出-1。 否则，输出该值作为所需的最小幻列数。 

工作原理：0-1 BFS 确保按照总魔柱成本递增的顺序探索路径。 由于每次移动都会增加零或一的成本，因此我们保证第一次到达具有给定成本的单元格时，它是可能的最小成本。 这个不变量确保了最短路径计算的正确性。 

## Python 解决方案```python
import sys
from collections import deque
input = sys.stdin.readline

def min_magic_columns(n, m, grid):
    dist = [[float('inf')] * m for _ in range(n)]
    dist[0][0] = 0
    dq = deque()
    dq.append((0, 0))
    directions = [(-1,0),(1,0),(0,-1),(0,1)]

    while dq:
        i, j = dq.popleft()
        for di, dj in directions:
            ni, nj = i+di, j+dj
            if 0 <= ni < n and 0 <= nj < m:
                cost = dist[i][j] + (1 if grid[ni][nj] == '#' else 0)
                if cost < dist[ni][nj]:
                    dist[ni][nj] = cost
                    if grid[ni][nj] == '#':
                        dq.append((ni, nj))
                    else:
                        dq.appendleft((ni, nj))
    return dist[n-1][m-1] if dist[n-1][m-1] != float('inf') else -1

def main():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]
    print(min_magic_columns(n, m, grid))

if __name__ == "__main__":
    main()
```该代码读取网格并初始化距离。 0-1 BFS 确保我们始终首先选择成本最低的路径。 推到双端队列的前面或后面的决定至关重要：我们不想延迟不添加魔法列的路径，因为它们可能会在以后启用更便宜的路由。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n*m) | 每个单元最多处理一次，每个边缘四次 |
 | 空间| O(n*m) | 距离矩阵加上大小高达 n*m 的双端队列 |

 给定 n, m ≤ 1000，O(n*m) = 10^6 在 2 秒内是可以接受的。
