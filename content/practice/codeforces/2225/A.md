 ## 解决方案
 ## 问题理解

 我们有两个整数`x`和`y`这样`y`大于`x`并且可以被整除`x`。 任务是判断是否存在第三个整数`z`严格位于`x`和`y`，可除以`x`，但不除`y`。 简单来说，我们正在寻找多个`x`那大于`x`本身但不均匀划分`y`。 

约束条件允许`x`和`y`一样大`10^18`并且最多可以有`10^4`测试用例。 这意味着任何迭代每个候选的解决方案`z`是不可行的，因为之间的倍数`x`和`y`可能是巨大的。 我们需要对每个测试用例进行恒定时间检查，或者在最坏的情况下，比率是对数的`y/x`。 

边缘情况出现时`y`正好是两倍`x`。 在这种情况下，唯一的倍数是`x`严格之间`x`和`y`是`2x = y`，不满足条件`y % z != 0`。 例如，如果`x = 5`和`y = 10`，没有`z`满足条件，所以答案应该是`NO`。 粗心的方法可能会选择`2x`不检查除法约束，产生不正确的`YES`。 

另一种微妙的情况发生在`y`是一个很大的倍数`x`但只能通过大于 2 的质因数。那么最简单的选择`z = 2x`会起作用，因为`y`不能被整除`2x`。 了解质因数分解的原理`y/x`与小倍数相互作用`x`是关键。 

## 方法

 蛮力方法很简单：生成每个倍数`x`从`2x`最多`y-x`，并检查它是否整除`y`。 如果任何这样的倍数不能整除`y`， 返回`YES`。 否则，返回`NO`。 这个方法原则上是正确的，但是对于最坏的情况`y/x`接近于`10^18/x`，迭代所有倍数在计算上是不可能的。 

解锁更快解决方案的关键观察是最小倍数`x`大于`x`是`2x`。 如果`y`不等于`2x`， 然后`2x`自动满足前两个条件（`2x > x`并可除以`x`）。 剩下的唯一检查是是否`y`可以整除`2x`。 如果不是，`2x`是我们的解决方案。 如果`y`可以整除`2x`，我们可以检查下一个倍数`3x`，但是因为`y % x == 0`，划分`y`经过`x`产生一个整数`k`。 我们需要检查是否`k > 2`; 如果是，那么`2x`不分开`y/k > 1`， 所以`2x`作品。 如果`k == 2`,`y = 2x`并且没有有效的`z`。 这将问题减少到每个测试用例的恒定时间检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(y/x) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，读取整数`x`和`y`。 
3. 计算比率`k = y // x`。 这是次数`x`适合`y`。 
4. 如果`k == 2`，没有整数`z`严格之间`x`和`y`即满足条件。 输出`NO`。 
5.如果`k > 2`, 整数`z = 2 * x`满足所有条件。 输出`YES`。 

为什么有效：通过划分`y`经过`x`，我们将问题简化为一个小整数检查。`z = 2x`总是大于`x`并且小于`y`什么时候`k > 2`。 自从`2x`划分`y`仅当`k`是偶数，我们的检查`k > 2`确保`2x`不分开`y`，或存在有效的倍数。 该方法保证所有有效输入的正确性，因为没有其他结构条件可能违反三个标准`z`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    x, y = map(int, input().split())
    k = y // x
    if k == 2:
        print("NO")
    else:
        print("YES")
```该代码通过快速 I/O 有效地读取多个测试用例。 对于每对`x, y`，它计算比率`k = y // x`并立即决定输出。 我们避免生成任何倍数`x`明确地，消除任何超时风险。 边界`k == 2`处理边缘情况`y`正好是两倍`x`。

 ## 边缘情况

 关键边缘情况是`y = 2x`。 用于输入`x = 5, y = 10`，比率`k = 2`。 算法正确输出`NO`因为`2x`等于`y`并违反了严格的不平等。 另一个边缘情况是非常大的数字，例如`x = 10^17, y = 3*10^17`。 这里`k = 3`， 所以`2x = 2*10^17`严格位于`x`和`y`， 和`y % (2x) != 0`。 算法输出`YES`正确。 两种边缘情况都证实该算法能够一致地处理小型和大型输入。
