 ## 解决方案
 ## 问题理解

 我们得到一组从 0 到 n − 1 的整数，任务是将它们排序成一个序列。 该序列必须满足局部约束：对于排列中的每一对连续元素，它们的绝对差必须至少能被给定的小整数列表 k₁、k2、…、kₘ 中的至少一个数字整除。 

用图术语来说，从 0 到 n − 1 的每个数字都是一个顶点。 如果|u − v|，我们在两个顶点u 和v 之间绘制一条无向边。 至少可被给定 k 值之一整除。 任务变成检查该图是否具有哈密顿路径，如果存在，则构造一个。 

约束条件是可行性的关键。 所有测试用例的总 n 最多为 5 · 10³，m 最多为 10。这立即表明每个测试用例具有二次或接近二次行为的解决方案是可以接受的，但如果天真地实现，在大型结构上每个测试用例的任何立方都会太慢。 然而，每个测试用例的全局 O(n²) 构造仍然是安全的。 

一个微妙的点是 kᵢ 值很小，最多为 n/3。 这强烈表明邻接结构不是任意的； 它具有可以利用的周期性或模块化模式。 

一个幼稚的错误是将其视为一般的哈密顿路径问题，并尝试在整个图上进行 DFS 或回溯。 即使 n = 5000，也会发生组合爆炸。 

另一个常见的陷阱是假设贪婪地选择任何有效的下一个节点都有效。 例如，从 0 开始并重复选择最小的未使用的邻居可能会让您陷入困境。 对于 n = 10，k = {3}，边连接相差 3 倍数的数字。该图分成模 3 的残差类。一个组件内的贪婪遍历无法跨组件，因此它可能会提前停止，而未使用的节点仍然存在。 

真正的挑战是理解由可分性约束引起的结构并将其转换为受控遍历。 

## 方法

 蛮力的想法很简单：显式构造图，然后运行 DFS 或回溯搜索尝试构建哈密顿路径。 每一步都会选择一个未使用的邻居并递归地继续。 

这是正确的，因为它探索了符合邻接规则的所有有效排列。 然而，在图的密集部分，分支因子可以大到 n。 在最坏的情况下，这会变成 O(n!) 行为，对于 n 达到 5000 时完全不可行。 

关键的观察结果是，邻接不是任意的；而是任意的。 它仅取决于可被 kᵢ 整除的差异。 这意味着对于每个 k，顶点形成链或算术级数，其中按 k 步进可以保持有效性。 我们可以用结构化的跳跃来思考，而不是用任意的边缘来思考。 

修复 1 k。 如果 |u − v| 能被 k 整除，则 u ≠ v (mod k)。 这意味着边仅连接模 k 相同残基类内的数字。 因此，每个 k 将数组划分为独立的模块化组件。 

由于我们只需要邻接度至少能被 1 k 整除，因此该图就是这些模块团的并集。 重要的结构见解是，运动始终在至少 1 k 的残差类内，并且这些类是大型连续算术结构。 

构建策略变为：选择一个可以将所有数字组织成长链的 k，然后仔细缝合这些链。 因为 m ≤ 10，我们可以尝试将每个 k 作为“驱动结构”并尝试构建有效的排序。 

标准解决方案将问题简化为通过余数模 k 对数字进行分组，并在组内以交替方向连接，以确保邻接差异保持为 k 的倍数。 如果存在多个 k，我们选择一个能够一致地覆盖所有约束的一个，或者我们尝试构建每个 k 并进行验证。

这减少了从图搜索到结构化序列构建的问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力DFS | O(n!) | O(n) | 太慢了 |
 | 每千个模块化结构 | O(n·m) | O(n) | 已接受 |

 ## 算法演练

 我们尝试利用给定的 k 值之一构建有效的排列。 

1. 对于列表中的每个 k，尝试使用 k 作为组织模数构建序列。 这个想法是，如果存在有效路径，则至少有一个 k 将支持干净的模块化遍历。 
2. 根据数字 0 到 n − 1 的余数对 k 进行分组。 每个组包含可以通过可被 k 整除的步骤连接的数字。 这是可行的，因为组内的差异是 k 的倍数。 
3. 在每组中，对数字进行排序。 然后反转每个备用组，以确保组之间的转换不会产生违反可分性结构的大跳跃。 
4. 按照剩余类的升序、交替方向连接组。 这产生了候选排列。 
5. 通过检查每个相邻对来验证构造的排列。 如果所有差异满足至少被 1 kᵢ 整除，则立即返回。 
6. 如果没有 k 产生有效排列，则输出 -1。 

我们单独尝试每个 k 的原因是有效排列的结构与至少一个模类密切相关。 由于 m 很小，因此尝试所有候选者是有效的。 

### 为什么它有效

 关键的不变量是在每个构造的块内，所有连续的差异都是所选 k 的倍数。 通过按余数模 k 对数字进行分组，我们确保组内的任何移动都保持可整除性。 跨组交替方向可以防止大的单调跳跃在一个方向上累积并破坏邻接一致性。 由于每个边要求仅要求能被至少 1 k 整除，因此满足单个仔细选择的 k 的条件足以保证整个序列的有效性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def valid(seq, ks):
    for i in range(len(seq) - 1):
        d = abs(seq[i] - seq[i + 1])
        ok = False
        for k in ks:
            if d % k == 0:
                ok = True
                break
        if not ok:
            return False
    return True

def build(n, k):
    groups = [[] for _ in range(k)]
    for i in range(n):
        groups[i % k].append(i)

    for g in groups:
        g.sort()

    res = []
    for i in range(k):
        if i % 2 == 1:
            groups[i].reverse()
        res.extend(groups[i])

    return res

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        ks = list(map(int, input().split()))

        ans = None
        for k in ks:
            cand = build(n, k)
            if valid(cand, ks):
                ans = cand
                break

        if ans is None:
            print(-1)
        else:
            print(*ans)

if __name__ == "__main__":
    solve()
```这`build`函数使用一个选定的模 k 构造候选排列。 它按残基类别对数字进行分组，然后在组内交替排序。 这是取代任何图搜索需求的核心结构构造。 

这`valid`函数强制正确性。 尽管它添加了 O(n · m) 检查，但 n 足够小，因此仍然有效。 

主循环尝试将每个 k 作为结构主干。 由于 m ≤ 10，这实际上是恒定的开销。 

一个微妙的实现细节是，按 i % k 分组相当于按残差类 mod k 分组，后者直接编码可分性约束。

 ## 边缘情况

 当 k = 1 时，会出现关键的边缘情况。然后每个差值都可以被 1 整除，这意味着任何排列都是有效的。 该算法自然地处理了这个问题：所有数字都进入一个组，构造的序列只是 0 到 n − 1，它会立即通过验证。 

另一种边缘情况是多个 k 值创建不兼容的结构。 例如，n = 6，k = [2, 3]。 该算法首先尝试 k = 2； 如果验证失败，它会尝试 k = 3。k = 2 的构造会产生交替的奇偶校验块，验证可确保正确性。 如果两者都不起作用，则输出为 -1。 重要的一点是，只有在全面验证后才能检测到故障，而不是在施工过程中，从而防止错误的早期验收。 

最后一个微妙的情况是群体高度不平衡，例如 k = n/3。 某些组可能仅包含一个或两个元素。 反转奇数索引组仍然保持正确性，因为当组大小较小时，内部排序无关紧要，并且由于在验证期间全局强制执行可分性检查，因此永远不会违反邻接约束。
