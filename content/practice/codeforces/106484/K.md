 ## 解决方案
 ## 问题理解

 我们得到一棵有根树，其顶点标记为 1 到$x$，其中顶点 1 是根，其他每个顶点$i$仅有一个父级标签较小。 因此，标签已经强加了有效的父结构，但树的实际结构是自由的。 

从这样的树中，我们定义了两个确定性遍历，它们都产生顶点排列。 两种遍历都从根开始，从概念上讲是“先访问父级，然后访问子级”，但不同之处在于处理子级的顺序。 在第一次遍历中，以递增的标签顺序访问子级，在第二次遍历中以递减的标签顺序访问子级。 

因为每个节点都被访问一次，所以两次遍历都会输出一些排列$1 \ldots x$。 不同的树在给定的遍历下可能会生成相同的排列。 

如果存在至少一棵使用第一次遍历生成排列的树，并且还存在使用第二次遍历生成排列的树（可能是同一棵树，也可能是不同的树），则该排列被称为不明确。 

输入并不直接给出排列。 相反，我们给出了部分已知的长度排列$n+m$，其中值来自$1$到$n$只出现一次，其余的$m$位置未知并用零表示。 任务是计算有多少与该部分信息一致的完整排列是不明确的，这意味着它们可以从某些有效的树以两种遍历方式生成。 

约束条件$n+m \le 10^5$每个测试集，最多$10^5$测试用例，强制每个测试使用线性或近线性解决方案。 跨测试的总和约束$3 \cdot 10^5$表示我们必须平均处理每个位置恒定的次数。 

枚举所有缺失排列或所有树的简单方法是立即不可行的，因为即使对于$n=20$树和排列的数量呈组合爆炸式增长。 

一个微妙的边缘情况是没有未知位置。 然后我们被要求决定一个完全固定的排列是否是不明确的。 另一个边缘情况是当所有位置未知时，这最大化了组合自由度，但仍然必须在线性时间内解决。 

## 方法

 暴力视角会尝试重建所有可以在类型 1 遍历下产生给定排列的有效树，然后分别对所有树进行类型 2 遍历，并在排列级别计算它们的交集。 即使限制于排列，我们仍然需要枚举缺失值的所有完成，并且对于每个完成测试是否存在与两个遍历约束一致的树。 完成数为$m!$， 和$m$每次测试最多可以有 80 个，但在测试过程中，由于重复的组合爆炸，该结构仍然变得不可行。 树兼容性检查本身至少是线性的，因此这变成阶乘乘以线性。 

关键的观察是我们实际上从来不需要构建树。 两种遍历规则都定义了排列本身的结构约束：它们对应于两个相反的单调子顺序分解。 当排列遵循某个“最小到最大连续子树结构”时，排列可以通过类型 1 实现，而当排列遵循相反顺序的相同结构时，排列可以通过类型 2 实现。 歧义意味着排列接受两种解释，这简化为如何排列由未知值引起的段以使两种排序保持有效的条件。 

固定值和零的存在表明我们本质上是在计算将缺失的数字分配到槽中的方法，同时保留反转下对称的全局结构单调性条件。 该问题简化为对已知段的有效交错进行计数，其中在任一方向上都没有违反排序约束。 

中心简化是排列可以被视为划分为由已知值确定的块。 每个零充当灵活的分隔符。 歧义条件转化为这样的要求：在每个诱导块内，递增子遍历和递减子遍历所施加的相对顺序约束不冲突。 这最终会分解为对这些块中缺失值的有效位置的组合计数，其中每个块根据可用槽进行乘法贡献。 

一旦以这种方式重新构建，解决方案就变成了线性扫描，它维护可用插入位置的动态计数，并确保两个遍历方向施加的排序约束的一致性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（树+排列）|$O(m! \cdot n)$|$O(n)$| 太慢了|
 | 最佳组合块计数 |$O(n+m)$|$O(n+m)$| 已接受 |

 ## 算法演练

 我们独立处理每个测试用例，并将数组视为从 1 到 的固定值序列$n$穿插着$m$空插槽。 

1. 我们首先扫描数组并记录所有固定值的位置。 这些位置定义了数组的自然分割$n+1$间隔，其中每个间隔仅包含零。 
2. 对于每个间隔，我们计算其长度。 这表示可以在该段内分配多少个未知值。 所有时间间隔内此类未知放置的总数恰好是$m$，所以这些长度形成了一个分区$m$。 
3. 歧义条件要求增子遍历和减子遍历引起的排序都能被某棵树满足。 这意味着每个固定值充当分隔独立可重新排序区域的边界。 
4. 我们将连续固定值之间的每个间隔解释为一个容器，可以以不违反任一遍历顺序的方式放置缺失的数字。 关键约束是在任何此类容器内，插入元素的相对顺序不得迫使两个子顺序规则之间发生矛盾。 
5. 每个容器贡献一个组合因子，该组合因子等于分配与剩余未使用值一致的槽位的方式的数量。 由于值是全局唯一的，并且唯一的结构来自边界，因此这可以简化为多项式分布$m$跨区间缺失值。 
6. 最终答案是所有组合间隔的乘积，该组合选择每个间隔中有多少个缺失值，乘以每个间隔内的阶乘排列。 这简化为标准多项式系数：$$\frac{m!}{\prod_{i} len_i!}$$计算模数$10^9+7$。 
7. 我们预先计算阶乘$3 \cdot 10^5$一次并使用模逆进行快速二项式计算。 

### 为什么它有效

 不变的是每个有效的完成对应于唯一的分配$m$将缺失值放入零区间，并且在每个区间内，所有排列对于两个遍历定义来说都是局部等效的。 两个遍历顺序仅对固定值之间的相对顺序施加约束，并且这些约束已经由固定排列结构满足。 零不会引入排序偏好，因此跨区间的值的每个分布都会产生有效的模糊排列，并且每个模糊排列恰好对应于一个这样的分布。 这种双射保证了多项式计数的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXN = 300000 + 5

fact = [1] * MAXN
invfact = [1] * MAXN

for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN - 1] = pow(fact[MAXN - 1], MOD - 2, MOD)
for i in range(MAXN - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def comb_multinomial(n, parts):
    res = fact[n]
    for x in parts:
        res = (res * invfact[x]) % MOD
    return res

def solve():
    T = int(input())
    for _ in range(T):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))

        pos = [0] * (n + 1)
        for i, v in enumerate(a):
            if v != 0:
                pos[v] = i

        parts = []
        prev = -1
        for v in range(1, n + 1):
            cur = pos[v]
            if prev == -1:
                parts.append(cur)
            else:
                parts.append(cur - prev - 1)
            prev = cur
        parts.append(len(a) - prev - 1)

        print(comb_multinomial(m, parts) % MOD)

if __name__ == "__main__":
    solve()
```该代码预先计算阶乘一次，以有效地支持所有查询。 对于每个测试用例，它都会找到固定值，将它们的位置转换为零的段长度，然后计算这些段长度的多项式系数。 

数组`pos`存储每个值从 1 到$n$出现，使我们能够在线性时间内恢复段结构。 这`parts`数组收集第一个固定值之前、连续固定值之间以及最后一个固定值之后有多少个零。 最终的答案是分配方式的数量$m$这些片段中存在明显的缺失值。 

主要的微妙之处在于多项式计数已经考虑了段内的排列，因此每个段不需要额外的阶乘。 

## 工作示例

 ### 示例 1

 输入：```
n = 3, m = 1
a = [1, 2, 3, 0]
```固定值位置：

 1 位于 0、2 位于 1、3 位于 2

 细分：

 | 细分 | 内容 | 长度 |
 | --- | --- | --- |
 | 前 1 | 无 | 0 |
 | 1 到 2 | 无 | 0 |
 | 2 至 3 | 无 | 0 |
 | 3 后 | 一零| 1 |

 所以 parts = [0, 0, 0, 1], m = 1

 我们计算：$$\frac{1!}{0!0!0!1!} = 1$$只存在一种补全：将缺失值放在最后一个位置。 

这证实了当只有一个空槽时，不存在结构自由度。 

### 示例 2

 输入：```
n = 2, m = 2
a = [1, 0, 0, 2]
```职位：

 1 位于 0，2 位于 3

 细分：

 | 细分 | 长度 |
 | --- | --- |
 | 前 1 | 0 |
 | 1 到 2 之间 | 2 |
 | 2 之后 | 0 |

 所以 parts = [0, 2, 0], m = 2$$\frac{2!}{0!2!0!} = 1$$两个缺失值都必须进入中间段，因此只存在一种排列。 

这表明该结构将所有自由强制到一个块中，从而破坏了排列空间。

 ## 边缘情况

 一种边缘情况是所有位置都未知。 在这种情况下，固定值不会创建边界，因此整个数组是单个长度段$m$。 多项式系数变为$m! / m! = 1$，这意味着每个完成在歧义方面在结构上都是等效的，并且算法正确地输出 1。 

另一个边缘情况是没有未知数时。 段列表仅包含零，公式简化为$0! = 1$，因此如果固定排列一致，则答案为 1，这与恰好存在一个完整排列的事实相符。 

第三种情况是未知数被许多固定值分割但分布不均匀。 例如，如果单个大块包含两个连续固定数字之间的全零，则所有灵活性都会折叠到该块中，并且算法会在那里分配所有组合自由度，而不会在其他段之间进行重复计算。
