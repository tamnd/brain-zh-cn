 ## 解决方案
 ## 问题理解

 我们得到一个代表计算机网络的无向连通图。 任务不是分析任意图结构，而是确定图是否与三种特定拓扑之一完全匹配。 

总线拓扑只是一条路径。 正好有两个顶点是度数为 1 的端点，其他每个顶点的度数为 2。 

环形拓扑是一个环。 每个顶点的度数都是 2。 

星形拓扑有一个中心顶点与所有其他顶点相连。 中心有学位$n-1$，并且每个剩余顶点的度数为 1。 

该图保证是连通的，因此我们不需要自己验证连通性。 我们只需要检查顶点的度数模式并决定哪个拓扑匹配。 

约束允许最多$10^5$顶点和$10^5$边缘。 任何重复遍历图或执行昂贵的成对检查的算法都是不必要的。 由于整个输入仅包含$O(m)$边缘信息，对边缘和顶点的线性扫描是自然目标。 一个$O(n+m)$解决方案很容易符合限制，而任何二次方对于$10^5$顶点。 

如果我们只看边缘的数量，一些边缘情况可能会导致错误的分类。 

考虑：```
4 3
1 2
1 3
1 4
```该图有$n-1$边，就像一条路径，但它的度数顺序是$[3,1,1,1]$。 正确答案是：```
star topology
```一种仅检查是否存在的解决方案$m=n-1$会错误地将其称为公共汽车。 

另一个例子是：```
4 4
1 2
2 3
3 4
4 1
```每个顶点的度数为 2，因此：```
ring topology
```仅关注连接性和边缘数是不够的。 我们必须检查顶点度数。 

最后一个例子：```
5 5
1 2
2 3
3 4
4 5
2 5
```学位是$[1,3,2,2,2]$。 该图已连接，但不匹配所需的结构。 

正确答案是：```
unknown topology
```## 方法

 强力方法将尝试通过显式重建其形状来识别每个拓扑。 例如，我们可以从每个顶点开始，遍历邻居，验证图是否形成单路径、循环或星形。 由于图是相连的，因此这种遍历是正确的，但它们涉及的图逻辑超出了必要的范围。 

在最坏的情况下，重复执行图形遍历或拓扑检查可能会接近$O(n(n+m))$，这远远大于需要时$n$达到$10^5$。 

关键的观察结果是，所有三种拓扑都完全由顶点度数来表征。 

对于环，每个顶点的度数都是 2。 

对于总线，恰好有两个顶点的度数为 1，其余每个顶点的度数为 2。 

对于一颗星来说，只有一个顶点有度数$n-1$剩下的每个顶点的度数都是 1。 

因为保证图是连通的，所以这些度条件就足够了。 我们不需要任何额外的结构验证。 

这将整个问题简化为在读取边缘时计算顶点度数，然后检查一些简单的图案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n(n+m)) | O(n(n+m)) | O(n+m) | 太慢了 |
 | 最佳 | O(n+m) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读$n$和$m$。 
2. 创建数组`deg`尺寸的$n$初始化为零。 
3. 对于每一个边缘$(u,v)$, 增量`deg[u]`和`deg[v]`。 

顶点的度数恰好是入射边的数量，因此在处理所有边之后，数组包含完整的度数序列。 
4. 检查每个顶点的度数是否为 2。 

如果为 true，则该图是环形拓扑。 
5. 计算有多少个顶点的度数为 1，有多少个顶点的度数为 2。 

如果正好有两个 1 度顶点并且正好$n-2$度为 2 的顶点，该图是总线拓扑。 
6. 计算有多少个顶点有度数$n-1$。 

如果恰好有一个这样的顶点，其余的$n-1$顶点的度数为 1，该图是星形拓扑。 
7. 如果以上条件都不成立，则输出`"unknown topology"`。 

### 为什么它有效

 图是连通的，这是至关重要的保证。 

每个顶点的度数为 2 的连通图必定是单环，因此它是环。 

恰好有两个 1 度顶点且所有其余 2 度顶点的连通图必须是一条路径，因此它是一条总线。 

具有一个度顶点的连通图$n-1$而所有其他 1 度只能是以该高度顶点为中心的星形。 

由于这些条件是互斥的并且完全表征了三个所需的拓扑，因此算法始终返回正确的分类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    deg = [0] * n

    for _ in range(m):
        u, v = map(int, input().split())
        deg[u - 1] += 1
        deg[v - 1] += 1

    if all(d == 2 for d in deg):
        print("ring topology")
        return

    cnt1 = sum(d == 1 for d in deg)
    cnt2 = sum(d == 2 for d in deg)

    if cnt1 == 2 and cnt2 == n - 2:
        print("bus topology")
        return

    cnt_center = sum(d == n - 1 for d in deg)

    if cnt_center == 1 and cnt1 == n - 1:
        print("star topology")
        return

    print("unknown topology")

if __name__ == "__main__":
    solve()
```实现直接遵循算法。 

度数组是我们从图中需要的唯一信息。 每条边对每个端点贡献一个度数，因此处理所有边一次就足够了。 

检查的顺序并不是特别重要，因为对于给定的约束，三个有效的拓扑是互斥的。 该代码首先检查环，然后检查总线，然后检查星形。 

一个微妙的点是，我们在检查星形条件时使用已经计算出的 1 度顶点的计数。 一颗有效的星必须恰好有一个度中心$n-1$并且所有其他顶点的度数必须为 1。 

另一个细节是从输入中基于 1 的顶点编号转换为 Python 数组中基于 0 的索引。

 | 测量| 复杂性 | 说明|

 | 时间 | O(n + m) | 一次遍历所有边并对度数数组进行几次扫描 |
 | 空间| O(n) | 存储每个顶点的度数 |

 至多有$10^5$顶点和$10^5$边缘，线性解决方案仅执行数十万次操作，并且完全符合时间限制。 度数数组只需要$O(n)$内存，远低于可用限制。

```每个顶点的度数为 2。第一次检查立即成功并输出：```
