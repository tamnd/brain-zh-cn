 ## 解决方案
 ## 问题理解

 给定一个高度为 ℓ 、宽度为 w 的矩形网格，我们需要将其精确地划分为 n 个不相交的区域。 每个区域必须由整个网格单元组成，必须形成与网格对齐的矩形，并且所有 n 个区域必须具有相等的面积。 每个区域都分配有前 n 个大写字母之一，并且具有相同字母的单元格必须恰好形成一个连续的矩形块。 

因此，任务不仅仅是将网格分割成相等的部分，而是将其分割成 n 个轴对齐的矩形，这些矩形精确地平铺 ℓ by w 板，没有重叠或间隙，并且附加约束是每个标签恰好出现在一个矩形块中。 

关键的限制是每个区域本身必须是一个矩形，这立即排除了任意平铺。 我们本质上是试图将一个大矩形分割成n个面积相等的小矩形。 

根据约束 ℓ、w ≤ 100 和 n ≤ 26，对所有分区进行暴力破解是不可能的，因为将网格分割成矩形的方法数量随着两个维度的组合而增长。 即使检查所有可能的平铺也会远远超出任何可行的界限。 

第一个必要条件是算术：总面积 ℓ·w 必须能被 n 整除。 如果不是，则无法将网格分割为 n 个等面积的整数单元区域，因此答案立即不可能。 

另一个微妙的约束是几何的：即使 ℓ·w 可以被 n 整除，也可能无法用 n 个面积相等的矩形进行平铺，因为每个矩形必须具有整数维度。 例如，n = 2 的 3 x 3 网格的面积为 9，因此每个区域需要面积 4.5，这已经无法整除。 但即使是像 2 x 6 且 n = 4 的情况，每个区域的面积为 3，这原则上是可能的，但可能仍需要仔细排列以确保矩形平铺干净。 

每个字母形成一个矩形的输出要求很重要：我们不允许将一个字母分割成多个不相交的区域。 这大大简化了结构，因为每个标签恰好对应一个矩形。 

## 方法

 一个蛮力的想法是尝试所有方法将 ℓ × w 网格划分为 n 个面积相等的矩形。 我们将选择矩形边界、分配标签并验证平铺。 垂直切割的放置方式数量以w为指数，水平切割以ℓ为指数，然后我们仍然需要将碎片分配到一致的平铺结构中。 即使对于 ℓ = w = 100 这也是完全不可行的。 

关键的观察是我们不需要任意的矩形放置。 我们只需要任何有效的平铺，而不是最佳或规范的平铺。 这使我们能够执行非常结构化的结构。 

我们首先通过区域划分来确保可行性。 令总面积为 A = ℓ · w，并令每个区域的目标面积为 s = A / n。 每个矩形的面积必须正好为 s。 

现在是结构见解：我们不再考虑任意矩形，而是可以逐行构建平铺，贪婪地雕刻水平条带并将每个条带分割成连续的块，从而实现面积 s。 由于行的宽度是固定的 w，我们可以将网格视为按行主序排列的 ℓ·w 个单元的序列，并将它们贪婪地分组为大小为 s 的段。 

但是，这些线段必须对应于矩形。 仅当行主顺序中长度为 s 的段没有错误地跨行“换行”时，它才会形成矩形。 这迫使我们确保每个段边界与行边界对齐或一致的垂直对齐。

一种更简单的构造方法是尝试 s 的所有因子对：我们需要面积 s 的矩形，因此可能的矩形尺寸为 (h, s/h)。 对于除以 s 并除以 ℓ 的每个候选高度 h，我们可以尝试堆叠高度为 h 的水平条带。 在每个条带内，我们需要将宽度 w 划分为宽度 (s/h) 的块。 仅当 (s/h) 除 w 时才有效。 这将问题简化为检查我们是否可以通过 (s/h) 将具有相同矩形形状 h 的网格平铺，然后按行优先顺序放置 n 个这样的矩形。 

由于 n ≤ 26 并且维度很小，我们还可以进一步简化：因为我们只需要存在，我们可以构造一个贪婪填充，以扫描方式逐个分配矩形，确保每当我们开始一个新矩形时，我们将其与第一个可用的未使用单元对齐并贪婪地扩展它以形成区域 s 的完整矩形。 

这是可行的，因为网格最初是完全可用的，并且我们总是雕刻固定区域的完整矩形，所以如果我们总是扩展到完整的矩形形状，我们永远不会得到部分剩余的孔。 

因此，解决方案简化为：验证可分性，然后通过扫描网格并在新标签开始时将每个区域扩展为矩形来贪婪地构建 n 个区域 s 的矩形。

 | 暴力平铺枚举| 指数| 指数| 太慢了 |

 ## 算法演练

 1. 计算总面积 A = ℓ · w 并检查 A 是否能被 n 整除。 如果不是，则立即输出不可能，因为无论几何形状如何，均等面积划分都是不可能的。 
2. 计算目标面积 s = A / n。 每个字母必须恰好覆盖 s 个网格单元。 
3. 维护最初未分配的网格。 我们将从“A”向上按顺序分配字母。 
4. 逐行扫描网格。 每当我们遇到未分配的单元格时，它就会成为新矩形的左上角。 将下一个字母分配给该区域。 
5. 从此起始单元格开始，确定一个向右和向下延伸的矩形，使其面积恰好为 s。 我们尝试通过增加宽度同时保持高度一致来贪婪地选择矩形，以确保我们不会超出网格边界或重叠已分配的单元格。 
6. 一旦形成了区域 s 的有效矩形，用当前字母标记其所有单元格并移至下一个字母。 
7. 继续，直到所有 n 个字母都放置完毕。 如果在任何时候我们都无法从起始单元形成区域 s 的有效矩形，则构造失败并且我们输出不可能。 

### 为什么它有效

 核心不变量是，在每一步中，所有先前分配的单元格形成不相交的矩形，每个精确区域 s 和其余未分配的单元格以行优先顺序形成一个连续区域，该区域仍然可以分区，因为我们总是从最早的可用单元格开始矩形并完全消耗一个矩形块。 由于每个矩形在继续之前都已完全填充，因此不会发生部分重叠或滞留单元格。 可分性条件确保单元格总数恰好匹配 n 个大小为 s 的块，因此如果贪婪扩展成功，它必然会产生有效的完整平铺。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    l, w, n = map(int, input().split())
    A = l * w
    if A % n != 0:
        print("impossible")
        return

    s = A // n
    grid = [[''] * w for _ in range(l)]
    used = [[False] * w for _ in range(l)]

    def find_next():
        for i in range(l):
            for j in range(w):
                if not used[i][j]:
                    return i, j
        return None

    for k in range(n):
        start = find_next()
        if start is None:
            break
        i0, j0 = start

        # try to build a rectangle of area s
        # brute-force width-height pairs
        placed = False
        for h in range(1, l - i0 + 1):
            if s % h != 0:
                continue
            ww = s // h
            if j0 + ww > w:
                continue

            ok = True
            cells = []
            for i in range(i0, i0 + h):
                for j in range(j0, j0 + ww):
                    if used[i][j]:
                        ok = False
                        break
                    cells.append((i, j))
                if not ok:
                    break

            if ok:
                ch = chr(ord('A') + k)
                for i, j in cells:
                    used[i][j] = True
                    grid[i][j] = ch
                placed = True
                break

        if not placed:
            print("impossible")
            return

    for i in range(l):
        print(''.join(grid[i]))

def main():
    solve()

if __name__ == "__main__":
    main()
```实现直接遵循构造逻辑。 我们迭代字母并始终按行优先顺序选择下一个未填充的单元格。 从该锚点开始，我们尝试目标区域的所有因子对以形成一个有效的矩形。 当我们找到一个不与现有分配重叠的有效分配时，我们就会提交它。 

一个微妙的点是排序：始终选择最左上角未使用的单元格可以防止剩余空间碎片化。 另一个重要的细节是检查高度可行性和宽度可行性； 如果不受网格限制的限制，我们将尝试无效的矩形并浪费时间或破坏结构。

 ## 边缘情况

 一种重要的边缘情况是当 ℓ·w 可被 n 整除但没有矩形因式分解对齐时。 例如，ℓ = 3，w = 3，n = 2 给出 s = 4.5，它立即无法整除，因此我们提前拒绝。 

更微妙的情况是当 s 是整数但不能实现为与网格对齐的矩形时。 例如，ℓ = 2，w = 6，n = 4 给出 s = 3。天真的尝试可能会尝试 1×3 矩形，但如果未对齐，则不可能在 2 行网格中将它们不重叠地打包。 贪心构造通过在提交矩形之前始终检查实际可用空间来避免这种情况。 

另一种情况是，如果我们不选择左上角未使用的单元格，网格就会强制碎片化。 如果我们任意开始矩形，我们可能会留下无法到达的洞。 扫描顺序策略通过始终从最早的可用位置扩展来防止这种情况，确保剩余空间在建设性意义上保持连续。
