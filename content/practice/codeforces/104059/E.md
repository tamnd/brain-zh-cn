 ## 解决方案
 ## 问题理解

 食堂以两种“底汤”开始，我们可以将其视为两种纯粹的食材：一种是π-土豆汤，另一种是τ-番茄汤。 日复一日，配方不断演变。 第一天的汤完全是π-土豆，第二天的汤完全是τ-土豆。 从第三天开始，每一种新汤都是由前两种汤等比例混合而成。 

这意味着第n汤始终是前两种汤的混合物，并且每一步都只是混合之前的混合物，而不引入任何新的东西。 任务是确定 n 天后最终混合物中的哪些部分来自原始 π-番茄汤，哪些部分来自 τ-番茄汤。 

输入大小高达 10^18，因此任何逐日模拟的方法都立即不可行。 线性模拟最多需要 10^18 次操作，这远远超出了任何时间限制。 即使对数因子方法也是可以接受的，但任何比 O(log n) 更差的方法都会失败。 

n 值较小时会出现微妙的边缘情况。 当 n 等于 1 或 2 时，答案是普通纯成分。 如果解决方案盲目地应用从 n = 3 开始的递推公式而不处理这些基本情况，则可能会错误地移动序列或产生未定义的值。 

## 方法

 蛮力解释很简单。 我们每天维护一对值，表示 π-tato 和 τ-mato 的存在量。 第 1 天我们从 (1, 0) 开始，第 2 天我们从 (0, 1) 开始。 第二天我们计算前两对的平均值。 这直接遵循问题定义并且通过构造是正确的。 

问题在于规模。 计算直到第 n 天需要迭代之前的所有天，因此复杂度为 O(n)。 当n达到10^18时，这种方法是完全不可行的。 

关键的观察是两个组件在相同的循环下独立进化。 如果我们只跟踪 π-tato 分数，它满足递推 f(n) = (f(n−1) + f(n−2)) / 2，其中 f(1) = 1 且 f(2) = 0。 τ-mato 分数只是 1 − f(n)，但我们也可以对称地计算它。 

这是具有常数系数的线性递推。 这种递归式可以使用矩阵求幂来求解。 我们将从 (f(n−1), f(n−2)) 到 (f(n), f(n−1)) 的转换编码为矩阵乘法。 将此矩阵求 (n−2) 次方即可得到 O(log n) 时间内第 n 天的状态。 

除以 2 会引入分数，但我们可以将其视为浮点乘以 1/2，或者等效地将其合并到转换矩阵中。 由于所需的精度为 10^{-6}，因此浮点矩阵求幂就足够了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 太慢了 |
 | 矩阵求幂| O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将问题简化为通过缩放来计算斐波那契式递归。 

1. 将 f(n) 定义为第 n 天的 π-土豆汤的分数。 从结构上看，f(1) = 1 和 f(2) = 0。这建立了一切事物演化的两个基本状态。 
2. 观察到，对于 n ≥ 3，f(n) = (f(n−1) + f(n−2)) / 2。这直接来自前两个混合的平均。 
3. 将递推重写为线性变换：

 (f(n), f(n−1)) = (1/2 * (f(n−1) + f(n−2)), f(n−1))。 
4. 将其表示为矩阵乘法：

 [f(n), f(n−1)]^T = A * [f(n−1), f(n−2)]^T,

其中 A = [[1/2, 1/2], [1, 0]]。 该表示允许通过求幂重复应用。 
5. 计算 A^(n−2)。 这会将初始向量 [f(2), f(1)] = [0, 1] 转换为 [f(n), f(n−1)]。 
6. 通过平方执行快速求幂。 每个乘法结合了两个过渡状态，保留了递归的正确性。 
7. 从结果向量中提取 f(n)。 τ-mato 分数为 1 − f(n)，因为总混合物总和为 1。 

### 为什么它有效

 关键的不变量是每个状态向量完全编码递归的最后两个值。 转移矩阵精确地再现了递归步骤，因此乘以矩阵会使序列前进一天，而不会产生超出浮点精度的近似误差。 因为矩阵乘法是结合的，所以重复平方可以在对数时间内正确模拟 n−2 个顺序变换。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def mat_mul(a, b):
    return [
        [
            a[0][0]*b[0][0] + a[0][1]*b[1][0],
            a[0][0]*b[0][1] + a[0][1]*b[1][1],
        ],
        [
            a[1][0]*b[0][0] + a[1][1]*b[1][0],
            a[1][0]*b[0][1] + a[1][1]*b[1][1],
        ],
    ]

def mat_pow(m, e):
    res = [[1.0, 0.0], [0.0, 1.0]]
    base = m
    while e > 0:
        if e & 1:
            res = mat_mul(res, base)
        base = mat_mul(base, base)
        e >>= 1
    return res

n = int(input())

if n == 1:
    print("100.0 0.0")
elif n == 2:
    print("0.0 100.0")
else:
    A = [
        [0.5, 0.5],
        [1.0, 0.0],
    ]
    M = mat_pow(A, n - 2)
    f_n = M[0][1]
    print(f"{f_n * 100:.10f} {(1 - f_n) * 100:.10f}")
```该代码直接根据递归构造转移矩阵。 乘法函数无需优化即可实现标准 2×2 矩阵乘法，因为恒定的大小使其保持高效。 

通过平方求幂将乘法次数从 n 减少到 log n。 单位矩阵初始化累加，以便部分结果在合并之前保持中性。 

基本情况 n = 1 和 n = 2 被显式处理，因为矩阵公式假设访问两个先前状态。 

直接使用浮点运算。 由于深度最多为 log2(10^18) ≈ 60 次乘法，因此累积误差保持在可接受的范围内。

 考虑从 n = 1 和 n = 2 开始的递归。

 | 日 | f(n−2) | f(n−2) | f(n−2) f(n−1) | f(n−1) | f(n−1) f(n) 计算 |

 对于 n = 3，结果为 50% π-tato 和 50% τ-mato。 这表明第一个混合步骤直接平均了两种基础汤。 

### 示例 2：n = 4

 | 日 | f(n−2) | f(n−2) | f(n−2) f(n−1) | f(n−1) | f(n−1) f(n) 计算 |
 | --- | --- | --- | --- |
 | 2 | - | - | 0.0 | 0.0

 第 4 天，π-tato 分数下降至 25%，证实重复平均会迅速削弱原始贡献。 

这些例子证实了递归的行为就像平滑的斐波那契序列，每一步缩放 1/2。

 ## 边缘情况

 对于 n = 1，矩阵公式不适用，因为它假设存在两个先前状态。 该算法明确绕过矩阵求幂并返回 (100, 0)，与第 1 天作为纯 π-tato 汤的定义相匹配。 

对于 n = 2，会出现同样的问题，并且输出固定为 (0, 100)。 任何盲目应用递归的尝试都会错误地计算未定义的早期状态的混合。 

对于较大的 n（例如 10^18），直接模拟会溢出时间和内存，但矩阵求幂将计算量减少到大约 60 个平方步骤。 每个步骤仅操作恒定大小的矩阵，因此结果在浮点运算下保持稳定。
