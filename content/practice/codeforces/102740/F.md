 ## 解决方案
 ## 问题理解

 我们的沙拉类型编号为 1 到 10^8。 每种类型的价格都是通过将其数字向上舍入到最接近的幸运数字来确定的。 幸运数字是一个正整数，其十进制表示仅包含数字3和8。例如，3、8、38和883是幸运的，而13和380则不是。 

输入给出沙拉类型的区间 [l, r]。 我们需要找到在这个时间间隔内购买每种类型沙拉的总价格。 挑战在于间隔可能非常大，因此直接检查每种沙拉类型是不切实际的。 原始问题约束允许的值最多为 10^8，这意味着 O(r-l+1) 解决方案对于单个测试用例可能需要最多 1 亿次操作。 这太接近 Python 的极限了，没有留下任何开销空间。 我们需要利用幸运数字的结构，而不是迭代每种类型。 

有用的观察是幸运数字很少。 k位数的幸运数字只有2^k个。 即使所有幸运数字都在我们关心的范围内，总数仍然很小。 这意味着我们可以自己构建幸运数字，并使用连续幸运数字之间的间隔来一次计算大范围。 

一些边界情况可能会破坏仅考虑幸运数字本身的实现。 例如，如果输入是：```
1 2
```答案是：```
6
```两种类型的价格都是 3，尽管这两种类型都不是幸运数字。 

另一种情况是：```
8 8
```答案是：```
8
```值 8 属于以幸运数字 8 结尾的区间。仅处理严格低于下一个幸运数字的数字的粗心实现可能会错过幸运数字本身。 

第三个重要的情况是当区间跨越幸运边界时：```
3 9
```价格为：```
3 8 8 8 8 8 33
```所以答案是：```
76
```值 9 跳转到下一个幸运数字 33。将范围视为在 8 附近连续会错误地将价格 8 分配给 9。 

## 方法

 一个简单的解决方案将生成 l 和 r 之间的每种沙拉类型，找到第一个大于或等于它的幸运数字，然后添加该价格。 这很容易验证，因为它直接遵循定义。 但是，如果区间包含所有 10^8 种可能的类型，则算法将执行大约 1 亿次搜索。 即使每次幸运查找速度很快，迭代次数也太大了。 

关键的洞察力来自于观察价格变化的地方。 沙拉类型的价格不会在每个位置发生变化。 从一个幸运数字边界到下一个幸运数字，它保持不变。 例如，靠近开头的幸运数字是：```
3, 8, 33, 38, 83, 88
```类型 1、2 和 3 的成本都是 3。类型 4 到 8 的成本都是 8。类型 9 到 33 的成本都是 33。 

我们可以对这些常量段求和，而不是对各个类型求和。 唯一需要的信息是幸运数字的有序列表。 

幸运数字的数量足够小，足以生成所有幸运数字。 排序后，我们可以通过遍历幸运区间来计算到任意位置 x 的前缀成本。 对于所请求的答案，我们计算直到 r 的前缀和并减去直到 l-1 的前缀和。

 ## 算法演练

 1. 生成每个可以影响答案的幸运数字。 具有 k 位数字的幸运数字恰好有 2^k 种可能性，因此生成最多 10 的长度只给出几千个值，这很容易管理。 
2. 对生成的幸运数字进行排序。 我们需要按递增顺序排列它们，因为每种沙拉类型都使用不小于它的第一个幸运数字。 
3. 创建一个函数，返回从 1 到 x 的所有沙拉类型的总成本。 该函数按顺序遍历幸运数字，并尽可能消耗完整的间隔。 
4. 对于每个幸运数字 cur，记录上一个幸运数字 prev。 区间 (prev, cur] 中的每种类型都有价格 cur。如果 x 超出此区间，则添加全部贡献：```
(cur - prev) * cur
```然后移动到下一个幸运数字。 

1、当到达第一个大于等于x的幸运数时，可能只需要其区间的一部分。 添加：```
(x - prev) * cur
```并停止。 

1. 计算所需的答案：```
prefix(r) - prefix(l - 1)
```这将原始范围查询转换为两个前缀计算。 

为什么它有效：

 不变的是，在处理幸运数字 cur 之前，直到 prev 之前的每种沙拉类型都已经被准确分配了正确的价格。 prev 之后到 cur 结束的区间仅包含第一个大于或等于它们的幸运数字是 cur 的数字。 由于价格函数仅在幸运数字处发生变化，因此处理这些间隔将每种类型恰好覆盖一次，并将正确的值分配给每个位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def generate_lucky():
    lucky = []

    def dfs(x):
        if x > 10**10:
            return
        if x:
            lucky.append(x)
        dfs(x * 10 + 3)
        dfs(x * 10 + 8)

    dfs(0)
    lucky.sort()
    return lucky

lucky = generate_lucky()

def prefix_cost(x):
    if x <= 0:
        return 0

    ans = 0
    prev = 0

    for cur in lucky:
        if x <= prev:
            break

        if x <= cur:
            ans += (x - prev) * cur
            return ans

        ans += (cur - prev) * cur
        prev = cur

    return ans

def solve():
    l, r = map(int, input().split())
    print(prefix_cost(r) - prefix_cost(l - 1))

solve()
