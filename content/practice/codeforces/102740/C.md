 ## 解决方案
 ## 问题理解

 房间是一个由单位正方形组成的长方形，其尺寸`N`经过`M`。 伊莎贝尔想要使用相同的 L 形瓷砖覆盖每个正方形。 该图块是由四个正方形组成的四格骨牌：三个连续的正方形排成一行，另外一个正方形附加在一端，就像 L 形的俄罗斯方块。 瓷砖可以旋转和反射。 

任务只是判断是否存在完整的平铺。 输出是`YES`如果每个楼层的方块都可以被恰好覆盖一次，并且`NO`否则。 

维度可以大到 1000，因此尝试构建面板或搜索展示位置的解决方案是不必要的，而且是错误的方向。 输入大小表明答案必须来自矩形的数学属性而不是模拟。 

一个常见的错误是仅检查面积是否可以被图块尺寸整除。 每块瓷砖覆盖四个方格，因此面积必须是四的倍数，但这个条件还不够。 例如，一个`2 x 2`房间有面积`4`，但单个 L 形四格骨牌无法填满它，因为瓷砖总是缺角。 

另一种边缘情况是单排或单列的房间。 例如：```
Input:
1 8

Output:
NO
```面积可被四整除，但旋转后每块瓷砖需要两行或两列，因此无法覆盖直条。 

第二个重要的情况是当两个维度都大于一但面积不能被八整除时：```
Input:
3 4

Output:
NO
```面积为`12`，可被四整除，但 L-tetromino 着色参数表明图块的数量必须是偶数，因此总面积实际上必须能被八整除。 

## 方法

 蛮力方法会尝试每个 L 形图块的所有可能放置位置，并使用回溯来确定矩形是否可以完全覆盖。 这是正确的，因为它探索了所有可能的平铺，但放置的数量快速增长。 即使是一个小矩形也有许多可能的图块方向和位置，并且搜索空间呈指数增长。 对于维度高达 1000 的情况，这种方法是不可能的。 

有用的观察是矩形尺寸包含我们需要的所有信息。 每个 L-tetromino 覆盖四个方格，但当棋盘以交替的水平条纹着色时，它也会出现颜色不平衡。 如果我们将每隔一行涂成黑色，其余行涂成白色，则 L-tetromino 总是覆盖三个黑色方块和一个白色方块，或者三个白色方块和一个黑色方块。 为了覆盖整个矩形，每个不平衡的瓦片数量必须相等，这意味着瓦片数量必须是偶数。 由于每个图块覆盖四个正方形，因此矩形面积必须能被八整除。 

这个条件也足够了。 任何边长都大于 1 且面积可被 8 整除的矩形都可以被分割成更小的矩形，这些矩形可以用 L-四联骨牌平铺。 最小的有用构建块是矩形，例如`2 x 4`和`3 x 8`，并且更大的有效矩形可以分解为这些模式。 

蛮力法之所以有效，是因为它直接搜索放置安排，但由于安排的数量巨大而失败。 着色不变量将整个问题简化为检查一些算术条件。

 ## 算法演练

 1. 读取房间的二维尺寸。 
2. 检查任一维度是否为`1`。 单行或单列不能包含 L 形四格骨牌，所以答案是立即`NO`。 
3. 计算面积`N * M`。 如果它不能被整除`8`，矩形不能平铺，因为平铺的数量必须是偶数。 
4. 如果两个条件都通过，则输出`YES`。 

工作原理：该算法依赖于每个有效平铺都使用偶数个 L-四联骨牌的不变量。 由于每个图块贡献四个单元，因此每个有效矩形的面积必须可被八整除。 剩余尺寸条件删除了瓷砖无法实际安装的不可能的薄矩形。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    if n == 1 or m == 1:
        print("NO")
    elif (n * m) % 8 != 0:
        print("NO")
    else:
        print("YES")

if __name__ == "__main__":
    solve()
```该程序首先处理一侧为一条的几何边界情况。 此检查是单独的，因为单独的区域条件会错误地接受诸如`1 x 8`。 

乘法`n * m`在 Python 中是安全的，因为整数具有任意精度。 最终条件检查从着色参数导出的可分性要求。 

没有循环或存储结构，因为答案仅取决于两个输入维度。

 ## 边缘情况

 对于一个`1 x 8`房间，算法首先检查尺寸并返回`NO`。 尽管可以将八个单元分为两组，每组四个，但无法放置该图块，因为在任何旋转后它都需要第二行。 

对于一个`3 x 4`房间，算法计算面积`12`。 按计数计算，该区域足够大，可容纳三块瓷砖，但三块瓷砖将违反偶数块瓷砖不变量。 被八整除的检查捕获并返回`NO`。 

对于一个`2 x 4`房间面积为`8`，并且两个维度都大于一。 算法返回`YES`，与这个矩形可以分成两个 L 形四格骨牌放置的事实相匹配。 

对于一个`1000 x 1000`房间，尺寸有效，但面积为`1,000,000`，不能被八整除。 算法仍然立即完成并正确返回`NO`。
