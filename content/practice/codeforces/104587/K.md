 ## 解决方案
 ## 问题理解

 我们给出的存储场景在数学上与阈值发现实验相同。 有一个未知的极限$x$这样叠加到$x$托盘上的相同盒子是安全的，但堆叠$x+1$盒子会导致失败。 的价值$x$保证位于 0 和$n$，包含在内。 

我们可以选择一个数字来进行实验$k$， 堆$k$将箱子放在托盘上，观察托盘是否完好。 如果它坏了，我们就会了解到$x < k$。 如果它幸存下来，我们就会了解到$x \ge k$。 我们被允许重复实验，并且我们有$m$托盘，这意味着我们可以容忍$m$在资源耗尽之前“中断”。 

每个实验的成本为 1，我们需要一个策略来保证识别$x$在最坏的情况下，使用尽可能少的实验。 在所有最佳策略中，我们还需要报告第一个实验大小的有效值范围。 

约束条件$n \le 5000$表示隐藏阈值位于一个相对较小的离散范围内，但托盘数量$m \le 20$这表明我们必须仔细构建动态规划解决方案，而不是模拟决策。 对所有策略的简单模拟会组合爆炸，因为每个实验都会分支成两个结果，从而形成指数决策树。 

出现微妙的边缘情况时$n = 0$。 在这种情况下，不需要实验，但许多实现仍然尝试计算第一步，并且可能错误地输出非零实验大小。 另一个极端情况出现时$m = 1$，其中唯一可行的策略退化为线性搜索，并且第一个实验范围必须折叠为单个值。 

## 方法

 一种直接的方法是根据决策树来思考。 每个实验选择一个值$k$，并且根据成功或失败，问题会分成一个较小的区间，一个分支中可用的托盘较少。 如果我们尝试枚举所有可能的策略，则每个节点都会分支到所有可能的策略$k$，深度取决于最坏情况下的实验数量。 这很快就变得不可行，因为即使对于中等程度的人来说$n$，可能的自适应策略的数量是指数级的$n$。 

关键的观察是我们实际上并不关心构建完整的决策树。 我们只需要知道，对于给定数量的实验$t$和托盘$m$，有多少个值$x$可以区分。 这导致了与丢蛋问题相同的经典重现。 

让$f[t][e]$是可以区分的阈值的最大数量$t$实验和$e$托盘。 如果我们进行一项实验，我们会选择一些$k$。 如果托盘破裂，我们减少到$t-1$实验和$e-1$托盘，我们最多可以区分$f[t-1][e-1]$下面较小的值$k$。 如果它幸存下来，我们减少到$t-1$实验和仍然$e$托盘，使我们能够区分最多$f[t-1][e]$以上数值$k$。 包括当前的测试点，我们得到递归$f[t][e] = f[t-1][e-1] + 1 + f[t-1][e]$。 

我们增加$t$直到$f[t][m]$至少是$n+1$，因为有$n+1$的可能值$x$从 0 到$n$。 这给出了最坏情况下的最少实验次数。 

一旦达到最佳实验次数$t$众所周知，我们重建所有有效的第一步。 第一次实验选择$k$如果两个分支仍然可解，则有效$t-1$实验。 如果托盘破裂，我们必须能够解决$k-1$价值观与$t-1$实验和$m-1$托盘，所以$k-1 \le f[t-1][m-1]$。 如果它幸存下来，我们必须能够解决$n-k$价值观与$t-1$实验和$m$托盘，所以$n-k \le f[t-1][m]$。 这些约束的交集给出了有效的第一选择的全部范围。

 ## 算法演练

 我们继续构建可达可区分范围的动态规划表。 

1. 初始化一个DP数组，其中$f[0][e] = 0$为所有人$e$，因为零实验我们无法区分任何阈值。 这设定了递归的基础。 
2. 迭代实验次数$t$从 1 向上。 对于每个$t$，计算所有托盘计数的值$e$从 1 到$m$使用递归$f[t][e] = f[t-1][e-1] + 1 + f[t-1][e]$，上限值为$n+1$以避免不必要的增长。 此步骤模拟了每个实验将剩余搜索空间划分为两个独立的子问题的事实。 
3.停在第一个$t$这样$f[t][m] \ge n+1$。 这是区分所有可能的框限制所需的最少实验次数。 
4.让$t$是这个最小值。 考虑第一个实验选择$k$。 对于固定的$k$，失败分支必须处理$k-1$价值观使用$t-1$实验和$m-1$托盘，而成功分支必须处理$n-k$价值观使用$t-1$实验和$m$托盘。 
5. 将这些限制转化为不平等：$k \le f[t-1][m-1] + 1$和$k \ge n - f[t-1][m]$。 有效范围是这两个条件的交集，限制为$[1, n]$。 
6. 输出$t$和计算的范围。 如果下限和上限一致，则输出单个值而不是范围。 

正确性取决于以下不变量$f[t][e]$始终表示精确使用的可区分阈值的最大数量$t$实验和$e$托盘。 每个实验都干净地将剩余空间分割成独立的子问题，因此递归完全捕获了所有可能的策略。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    if n == 0:
        print(0, 1)
        return

    # f[t][e]: max number of distinguishable thresholds
    # we only need up to n+1
    dp_prev = [0] * (m + 1)
    dp_curr = [0] * (m + 1)

    t = 0
    while True:
        t += 1
        for e in range(1, m + 1):
            val = dp_prev[e] + dp_prev[e - 1] + 1
            if val > n + 1:
                val = n + 1
            dp_curr[e] = val

        if dp_curr[m] >= n + 1:
            break

        dp_prev, dp_curr = dp_curr, dp_prev

    # dp_prev is t-1 layer, dp_curr is t layer
    prev = dp_prev

    # compute range for first move
    left = n - prev[m] + 1
    right = prev[m - 1] + 1

    left = max(1, left)
    right = min(n, right)

    if left > right:
        left = right = 1

    if left == right:
        print(t, left)
    else:
        print(t, f"{left}-{right}")

solve()
```DP 以滚动方式实现，因为只需要前一层来计算下一层。 这使内存使用保持线性$m$，这很重要，尽管$m \le 20$很小。 

停止条件检查当前层何时至少可以区分$n+1$价值观。 这直接对应于覆盖从 0 到 的所有可能的框限制$n$。 

重建步骤仅使用最后两个 DP 层。 有效范围的表达式直接来自强制两个递归分支在以下范围内保持可行$t-1$实验。 

## 工作示例

 ### 示例 1：$n = 3, m = 1$对于一个托盘，重复性退化为线性增长。 DP 层的演变如下。 

| t | e=1（容量）|
 | --- | --- |
 | 1 | 1 |
 | 2 | 2 |
 | 3 | 3 |
 | 4 | 4 |

 我们停在$t = 3$因为 3 个实验可以区分 4 个值（0 到 3）。 第一步移动约束给出$f[2][0] = 0$隐含地和$f[2][1] = 2$。 唯一有效的第一步是$k = 1$，因为任何更大的跳跃都会超出单托盘策略在失败后可以恢复的范围。 

输出是$3\ 1$。 

该轨迹表明，使用一个托盘，该策略简化为顺序搜索，并且 DP 正确地编码了线性增长。 

### 示例 2：$n = 4, m = 2$我们计算层：

 | t | e=1 | e=2 |
 | --- | --- | --- |
 | 1 | 1 | 1 |
 | 2 | 2 | 3 |
 | 3 | 3 | 6 |

 我们停在$t = 3$自从$f[3][2] = 6 \ge 5$。 现在$prev = f[2]$， 所以$prev[1]=2$,$prev[2]=3$。 

有效范围：$left = 4 - 3 + 1 = 2$,$right = 2 + 1 = 3$。 

所以第一个实验可以是 2 或 3。 

这证明了当两个分支在相同数量的剩余实验下保持平衡时，多个最佳第一步如何自然出现。

 | 测量 | 复杂性 | 说明|

 界限$n \le 5000$和$m \le 20$使这变得舒适快速。 递归增长得很快，因此迭代次数$t$通常是在$O(\log n)$对于较大的$m$，但即使在最坏的情况下，实施仍然安全地在限制范围内。

 ## 边缘情况

 当$n = 0$，正确的行为是输出零实验和任意第一步，通常标准化为 1。在这种情况下不需要 DP，并且早期返回可以避免访问无效范围。 

什么时候$m = 1$，每次失败都会立即结束该过程，因此 DP 减少为$f[t][1] = t$。 该算法正确地生成了单个有效的第一步 1，因为任何较大的第一次实验都会超出唯一可行的线性搜索结构。 

什么时候$n$很大但是$m$也接近 20，DP 增长得足够快$f[t][m]$达到$n+1$只需相对较少的步骤。 重建公式仍然会产生有效第一步的连续间隔，因为来自两个分支的约束在凸范围内重叠，从而确保最佳决策中没有不相交的间隙。
