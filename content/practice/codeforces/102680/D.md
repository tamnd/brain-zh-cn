 ## 解决方案
 ## 问题理解

 任务是对每个给定的自然数进行分类。 如果一个数的唯一正因数是 1 和它本身，那么它就是素数。 如果它至少有一个附加除数，则它是复合的。 特殊值 1 不属于任何一类，因为它只有一个正因数。 

输入包含几个独立的数字。 对于每个数字，我们只打印一个描述其分类的单词。 

主要困难在于值的大小，而不是输入的量。 数字只能有 100 个，但每个数字最大可以达到 2,000,000,000。 检查从 2 到数字本身的每一个可能的除数，对于一个值需要多达 2000 亿次检查，这远远超出了可用时间。 即使线性地检查许多大型案例也是不现实的。 我们需要利用除数的数学结构。 

最大的有用除数搜索限制是数字的平方根。 如果一个数的除数大于其平方根，则匹配的除数小于平方根。 这将搜索空间减少到大约 44,721 个最大值检查，这对于 100 个测试用例来说很容易管理。 

第一个边缘情况是数字 1。对于输入：```
1
1
```正确的输出是：```
Neither
```只检查是否找到除数的粗心实现可能会错误地将 1 标记为素数，因为它找不到 2 以后的除数。 

另一个边缘情况是完美的正方形。 对于输入：```
1
49
```正确的输出是：```
Composite
```仅当平方严格小于数字的平方根时检查除数的程序可能会意外地错过除数 7 并错误地对 49 进行分类。 

最后的边缘情况是接近极限的大素数：```
1
2000000000
```这不是素数，因为它有很多因素。 仅测试几个小除数或使用不完整的素数表可能会给出不正确的结果。 

## 方法

 直接的方法是尝试从 2 到 (q-1) 的所有可能的除数。 如果任何值整除 (q)，则该数字是合数。 否则它就是素数。 这是正确的，因为除 1 之外的每个非素数都有一个除 1 及其自身以外的约数。 

问题是运行时间。 对于 (q = 2,000,000,000)，暴力法可以对一个数字执行近 20 亿次模运算。 对于最多 100 个输入，最坏的情况会达到大约 (2 \cdot 10^{11}) 次操作。 

关键的观察是约数成对出现。 如果（a \times b = q），则（a）和（b）中至少之一最多为（\sqrt q）。 当搜索除数时，我们只需要测试候选者的平方根。 找到一个就意味着这个数是合数，到达终点就意味着它是质数。 

暴力方法之所以有效，是因为它检查了所有可能的因素，但它重复了许多不必要的检查。 平方根观察删除了所有不能成为除数对中较小成员的候选者。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个数字 O(q) | O(1) | O(1) | 太慢了 |
 | 最佳 | 每个数字 O(sqrt(q)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 独立读取每个数字并处理值为 1 的特殊情况。由于 1 仅有一个正因数，因此必须立即将其归类为“Neither”。 
2. 尝试从 2 到数字的平方根的每个整数除数。 如果任何除数能被整除，则该数有一个不同于 1 和它本身的因数对，因此它是合数。 
3. 如果循环结束后仍未找到除数，则将该数字分类为质数。 每个可能的因子对都包含一个已经测试过的较小因子。 

为什么它有效：

 该算法保持了这样的不变性：在测试当前点之前的每个候选除数之后，没有遗漏该数字的较小因子。 任何合数都有一个因数对。 该对中较小的成员不能超过平方根，因此搜索始终会找到合数的除数。 质数没有这样的约数，因此它们在完整的搜索中幸存下来。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def classify(x):
    if x == 1:
        return "Neither"

    d = 2
    while d * d <= x:
        if x % d == 0:
            return "Composite"
        d += 1

    return "Prime"

def solve():
    n = int(input())
    ans = []

    for _ in range(n):
        x = int(input())
        ans.append(classify(x))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```这`classify`函数隔离了数学决策。 第一个条件删除唯一既不是质数也不是合数的数字。 

循环使用`d * d <= x`而不是计算浮点平方根。 这避免了大整数的精度问题，并且自然也包括完美平方。 

一旦找到除数，函数就会立即返回，因为没有进一步的检查可以改变答案。 如果循环结束，则没有除数达到平方根，这证明了素性。 

Python整数不会溢出，因此循环条件中的乘法是安全的。 最大值只有二十亿，远低于Python的整数限制。

 ## 边缘情况

 在除数循环开始之前处理值 1。 对于输入：```
1
1
```该算法立即返回“Neither”。 它永远不会进入素数检查逻辑，从而防止将没有发现约数的数字视为素数的常见错误。 

对于完全平方数，例如：```
1
49
```循环继续，而`d * d <= x`，允许`d = 7`待测试。 找到除数，答案就变成复合数。 使用严格的不等式会跳过这种情况。 

对于较大的值，例如：```
1
2000000000
```该算法不会尝试扫描每个较小的数字。 它只检查候选值的平方根，快速找到除数并保持运行时间的可预测性。
