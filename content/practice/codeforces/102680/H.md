 ## 解决方案
 ## 问题理解

 该问题定义了联盟颜色的无限序列。 它从一个红队开始。 为了创建序列的下一个版本，我们复制当前序列，交换副本中的每种颜色，并将该副本附加到末尾。 序列的第一个位置足以揭示模式，但序列呈指数增长，因此我们需要回答询问排名非常大的团队颜色的查询。 

输入包含多个团队排名。 每个排名可以大到$10^{18}$，这立即排除了直接构建序列的可能性。 即使存储第一个$10^9$角色已经是不可能的了，实际的构建需要无限多个位置。 由于查询数量很少，因此预期的解决方案必须在大约对数时间内独立回答每个位置。 

困难的情况不在于序列的大小，而在于索引和递归边界。 该序列是一索引的，而大多数实现自然地使用零索引位置。 

例如，输入```
1
1
```有输出```
Red
```错误地转换为零索引的解决方案可能会检查错误的位并返回蓝色。 

另一种情况是：```
3
2
3
4
```该序列开始为：```
Position: 1 2 3 4
Color:    r b b r
```正确的输出是：```
Blue
Blue
Red
```一个常见的错误是假设每个块的后半部分与前半部分完全相反，而不调整该半部分内的位置。 后半部分是相同相对索引处的反向副本。 

最后的边缘情况是非常大的位置，例如：```
1
10000000000000000
```该序列无法生成，甚至部分生成。 任何尝试模拟构造的方法都会耗尽时间或内存。 

## 方法

 最简单的方法是构建序列，直到达到最大的请求等级。 如果当前长度是$L$，下一个构造将其加倍，所以之后$k$迭代长度为$2^k$。 回答附近的询问$10^{18}$，我们需要 60 多个扩展。 扩展的数量不是问题，但最终存储的字符串将包含大约$10^{18}$人物，这是不可能的。 

直接构建包含不必要的工作的原因是我们不需要整个序列，只需要一个位置。 该构造具有递归结构。 一块长度$2^k$由前半部分和前半部分的反转副本组成。 如果某个位置在前半部分，则答案与较小块中的相应位置相同。 如果是在下半场，则答案是与上半场对应位置相反的颜色。 

这将问题简化为重复询问当前位置是否位于 2 的幂块的前半部分或后半部分。 该过程每一步都会删除一位信息，因此操作数只是索引中的位数。 

暴力破解之所以有效，是因为生成的序列完全遵循所需的规则，但当请求的排名变大时，暴力破解就会失败。 观察到每个后半部分都是一个反转副本，这让我们可以用位置的二进制分解来替换序列生成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n)$每个最大排名 |$O(n)$| 太慢了 |
 | 最佳 |$O(\log n)$每个查询|$O(1)$| 已接受 |

 ## 算法演练

 1、将球队排名由一指数转为零指数。 递归构造更容易以这种方式描述，因为第一个字符对应于索引零。 
2. 保留一个标志，表示当前颜色是否已翻转奇数次。 最初该标志为假，因为第一个字符是红色的。 
3. 求包含当前位置的两个块的最大幂。 一块长度$2^k$由较小的长度块组成$2^{k-1}$接下来是它的倒置副本。 
4. 如果该位置在块的前半部分，则保持当前翻转状态并继续在较小块内的相同位置。 
5、如果位置在后半部分，则将位置减去前半部分的大小，切换翻转状态。 进入下半场意味着我们现在正在研究反转的副本。 
6. 继续缩小块，直到只剩下一个位置。 最终的翻转状态决定了答案。 假状态表示红色，真状态表示蓝色。 

为什么它有效：

 在每一步中，当前块都由一个较小的块和该较小块的反转副本精确表示。 该算法会跟踪该位置属于这两种情况中的哪一种。 每当它移动到反转副本时，它都会切换颜色状态，保留当前位置的含义。 当块大小变为1时，原始字符为红色，累积的翻转给出了实际答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_position(n):
    n -= 1
    flipped = False

    while n > 0:
        length = 1
        while (length << 1) <= n:
            length <<= 1

        if n >= length:
            n -= length
            flipped = not flipped

    return "Blue" if flipped else "Red"

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        n = int(input())
        ans.append(solve_position(n))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```该函数首先将排名更改为从零开始的索引。 这避免了将数学序列定义与实现偏移混合。 

变量`flipped`存储我们进入递归块的倒置一半的次数。 只有奇偶性很重要，所以布尔值就足够了。 

循环不断地寻找不超过当前位置的2的最大幂。 如果位置超出该边界，则属于当前块的后半部分。 删除前半部分给出较小块中的相应位置，并切换`flipped`解释了反转。 

用于求两次幂的嵌套循环最多运行 60 次，因为排名受以下限制$10^{18}$。 Python 整数直接处理这个大小，因此不需要溢出处理。

 ## 边缘情况

 第一个位置很特殊，因为原始序列以红色开头。 对于输入：```
1
1
```该算法将索引转换为零，不执行翻转，并返回 Red。 任何将输入等级视为已经从零开始的方法都将在这里失败。 

对于恰好位于新块开头的位置，必须仔细应用后半部分逻辑。 对于输入：```
3
3
4
5
```颜色是：```
Position 3: Blue
Position 4: Red
Position 5: Blue
```位置 4 是长度为 4 的块的倒置一半的第一个字符。 该算法检测到索引位于后半部分，减去一半长度，然后切换颜色。 

对于非常大的排名，例如：```
1
10000000000000000
```该算法从不存储序列。 它反复删除该位置的最高二进制级别，直到达到答案。 工作量与索引中的位数成正比，因此查询处理速度很快。
