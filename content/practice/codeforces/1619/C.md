 ## 解决方案
 ## 问题理解

 该问题给了我们两个整数，`a`和`s`，并要求我们找到一个号码`b`这样如果我们“添加”`a`和`b`以 Tanya 不寻常的方式，我们得到`s`。 Tanya 的加法不是标准的：她从最右边开始添加数字，将每对数字的总和写在当前结果的左侧，而不保留。 

例如，如果`a = 17236`和`b = 3465`，该过程看起来像添加`6+5 = 11`， 然后`3+6 = 9`,`2+4 = 6`,`7+3 = 10`， 和`1+0 = 1`，将结果构建为`1106911`。 我们看到每一位数字`b`从对应的数字可以推断出`s`和`a`，有时需要我们考虑两位数`s`如果单位数减法会产生负数，请立即进行。 

The constraints are large:`a`和`s`可以达到`10^18`最多有`10^4`测试用例。 这立即排除了任何尝试所有可能性的方法`b`或以简单的组合方式模拟加法。 每个测试用例必须仅使用数字的算术运算来有效解决。 

当数字位于`s`小于中的数字`a`。 例如，如果`a = 108`和`s = 112`，最后一位数字`b`需要满足`8 + b_last = 2`。 自从`2`小于`8`，使其发挥作用的唯一方法是借用下一个更高的数字`s`。 如果没有有效的两位数`s`能满足差值，解不存在。 

## 方法

 蛮力方法是反向模拟 Tanya 的加法：尝试所有可能的方法`b`逐位查看总和是否匹配`s`。 对于每个数字，我们可能会尝试从 0 到 9 的所有值`b`。 这是正确的，因为它直接反映了 Tanya 的算法，但对于大输入来说它太慢了：如果`a`最多 18 位数字，可能有`10^18`的可能性`b`。 这是不可能的。 

关键的见解是每个数字`b`可以直接推导出`s`和`a`而不尝试所有可能性。 我们从右到左处理数字。 如果当前数字为`s`大于或等于当前数字`a`，则对应的数字为`b`简直就是`s_digit - a_digit`。 如果`s_digit < a_digit`，我们查看下一个更高的数字`s`形成一个两位数，它必须至少为 10。然后我们减去`a_digit`从这个两位数得到`b`数字。 如果甚至失败（两位数小于`a_digit`），无解。 

这种按数字逆推的工作效率很高，因为它需要处理每个数字`s`正好一次。 逻辑简单且确定性，使得重构成为可能`b`相对于位数的线性时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(10^18) | O(10^18) | O(1) | O(1) | 太慢了 |
 | 按数字扣除| O(log(s)) | O(log(s)) | 已接受 |

 ## 算法演练

 1. 初始化`b`作为一个空列表。 从最低有效数字开始处理`a`和`s`。 
2. 当剩余数字时`a`或者`s`, 提取最后一位数字`a`（`ad`) 和最后一位数字`s`（`sd`）。 
3.如果`sd >= ad`，计算当前数字`b`作为`bd = sd - ad`并附加`bd`到`b`。 从中删除这些数字`a`和`s`。 
4. 如果`sd < ad`，提取下一个数字`s`组成一个两位数`sd_combined = 10 * next_s_digit + sd`。 如果`sd_combined < ad`或者`sd_combined`不在10-18范围内，解不存在，输出-1。 否则，计算`bd = sd_combined - ad`并将其附加到`b`。 去掉两位数`s`和最后一位数字`a`。 
5.一旦所有数字`a`被处理，如果任何数字保留在`s`，将它们附加到`b`直接因为它们对应于高阶数字`b`。 
6. 反转`b`获得最终数字，因为它是从最低有效数字到最高有效数字构建的。 
7. 打印`b`没有前导零。 

为什么它起作用：该算法确保在每个数字位置，总和`a`和`b`数字匹配`s`。 通过从右到左处理并仅在必要时考虑两位数的情况，它保留了以下不变式：`s`总是可以与剩余部分匹配`b`。 如果在任何一步这个不变量被破坏，我们就会正确地检测到不存在解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a_str, s_str = input().split()
        a = list(map(int, a_str[::-1]))
        s = list(map(int, s_str[::-1]))
        b = []
        i = 0
        j = 0
        while i < len(a):
            if j >= len(s):
                b = -1
                break
            ad = a[i]
            sd = s[j]
            if sd >= ad:
                b.append(sd - ad)
                i += 1
                j += 1
            else:
                if j+1 >= len(s):
                    b = -1
                    break
                sd_combined = s[j+1]*10 + sd
                if sd_combined - ad >= 10 or sd_combined - ad < 0:
                    b = -1
                    break
                b.append(sd_combined - ad)
                i += 1
                j += 2
        if b != -1:
            while j < len(s):
                b.append(s[j])
                j += 1
            b = int(''.join(map(str, b[::-1])))
        print(b)

if __name__ == "__main__":
    solve()
```该代码将输入数字转换为反转的数字列表，以便我们可以从最低有效位到最高有效位处理它们。 我们使用两个指针，`i`为了`a`和`j`为了`s`。 当简单的数字减法起作用时，我们将结果附加到`b`。 如果没有，我们将两个数字组合起来`s`形成一个有效的`b`数字。 任何未能形成有效的`b`导致打印-1。 处理完所有数字后，我们附加剩余的数字`s`到`b`，反转它，并将其转换回整数以删除前导零。
