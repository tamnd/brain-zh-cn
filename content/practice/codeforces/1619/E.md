 ## 解决方案
 ## 问题理解

 给定一个非负整数数组，我们可以将任意元素加 1 任意次。 任务是确定从 0 到数组长度的每个整数是否可以转换数组，使其 MEX（最小排除值）等于该整数，如果可以，则计算所需的最小增量数。 数组的 MEX 是数组中不存在的最小非负整数。 

例如，如果数组是`[0, 1, 3]`，墨西哥是`2`因为`0`和`1`存在，但是`2`失踪了。 递增`3`到`2`没有帮助，因为我们无法减少数量。 实现MEX`3`, 所有数字`0, 1, 2`必须存在，在此数组中需要转换现有数字，但仅增量不能创建缺失数字`2`如果它不存在并且所有较小的数字已经存在。 

约束条件是所有的总和`n`测试用例最多是`2*10^5`，测试用例的数量最多可达`10^4`。 这立即排除了模拟每个潜在 MEX 值的每个增量的强力解决方案，因为这可能高达`O(n^2)`每个测试用例的操作。 我们需要一种在每个测试用例的线性或线性时间内工作的方法。 

边缘情况包括所有元素都相同的数组、数组缺少 0、数组已包含所有值`0..n`，以及具有大间隙的阵列。 例如，`[1, 1, 1]`不能有墨西哥`0`不增加，但 MEX`2`可能需要多次增量。 粗心的方法可能会忽略这些差距或我们只能增加数字的事实，从而产生无效的答案。 

## 方法

 一个简单的方法是尝试每个目标 MEX`i`从`0`到`n`。 对于每个目标，我们可以模拟缺失数字的增量，直到形成所有数字`0..i-1`。 这将涉及扫描数组并增加值，这可能需要长达`O(n^2)`最坏情况下的操作，因为每个丢失的数字可能需要扫描或重复增量。 显然，这太慢了。 

关键的观察结果是对于 MEX`i`一切数字皆有可能`0`通过`i-1`经过一些增量后必须存在于数组中。 以下任何缺失的号码`i`必须通过增加较小的数字来“创建”。 相反，任何等于或大于`i`不阻止 MEX`i`。 

我们可以利用频率计数。 如果我们计算每个数字出现的次数，我们可以处理来自`0`向上。 如果某个数字缺失，我们可以尝试“借用”额外出现的较小数字来创建它。 以下数字额外出现`i`可以增加以填补空白，上面的数字`i`可以保持原样。 通过维护剩余元素的运行计数，我们可以在单次传递中有效地计算最小增量数。 

这将问题简化为频率阵列的单个线性扫描，同时跟踪剩余，这比模拟每个增量要快得多。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 频率+剩余跟踪| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.统计数组中每个数字出现的频率，包括最多到的数字`n`。 初始化一个数组`freq`大小的`n+1`。 这样可以立即获取我们拥有的每个数字的数量。 
2. 初始化变量`surplus`为零。 这将跟踪我们可以使用多少元素来填充缺失的数字，即已处理的数字的额外副本。 
3. 迭代`mex`从`0`到`n`。 对于每个`mex`，检查数组中是否存在该数字：

 - 如果`freq[mex] > 0`，我们有可用的号码。 添加`freq[mex] - 1`到`surplus`因为需要出现一次才能满足 MEX 要求，而其余的则可用于填补未来的空白。 
- 如果`freq[mex] == 0`，号码不见了。 我们只能通过增加剩余元素之一来创建它。 如果`surplus > 0`, 递减`surplus`并增加操作计数。 如果`surplus == 0`，然后墨西哥`mex`是不可能的，所有更大的 MEX 值也是不可能的。 
4. 对于每个 MEX，计算操作总数，即用于填充间隙的增量之和加上严格大于的元素数量`mex`如果我们想删除上面的重复项，则需要增加`mex`（以避免阻塞 MEX）。 
5. 按顺序输出结果`0`到`n`。 如果 MEX 不可能，则输出`-1`。 

为什么它有效：我们在处理 MEX 后保持不变式`i`, 所有数字`0..i-1`存在于数组中。 这`surplus`变量保证我们可以使用额外的副本来填充缺失的数字。 如果在任何时候由于不存在盈余而无法创建数字，那么更高的 MEX 值也是不可能的，这在逻辑上是一致的。 这种贪婪的方法确保了最少的操作，因为我们总是在创建新元素之前使用现有的额外元素。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

for _ in range(int(input())):
    n = int(input())
    a = list(map(int, input().split()))
    freq = [0] * (n + 2)
    for x in a:
        freq[x] += 1

    result = []
    ops = 0
    surplus = 0
    for mex in range(n + 1):
        if mex == 0:
            if freq[0] == 0:
                result.append(1)
                surplus = 0
            else:
                result.append(0)
                surplus = freq[0] - 1
        else:
            if freq[mex] == 0:
                if surplus > 0:
                    ops = ops + 1
                    result.append(ops)
                    surplus -= 1
                else:
                    result.extend([-1] * (n + 1 - mex))
                    break
            else:
                ops += freq[mex - 1]
                result.append(ops)
                surplus += freq[mex] - 1
    print(*result)
```我们首先计算频率，这使我们能够立即检查可用性。 这`surplus`变量跟踪可以增加多少个元素来填充缺失的数字。 我们更新`ops`以反映迄今为止所需的增量数量。 MEX 的特殊处理`0`是必要的，因为即使元素丢失，它也可能需要递增。 贪婪方法通过始终首先用剩余来填补缺口来确保最少的操作。
