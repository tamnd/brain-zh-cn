 ## 解决方案
 ## 问题理解

 我们有一系列食物单元，其中每个位置存储一种食物类型。 鲨鱼确实可以吃东西`k`一次馈送中包含多个单元，并且所有这些单元必须具有相同的类型。 如果所选间隔内的所有食物都可以准确地分为几组，则该间隔是成功的`k`相同类型。 

对于固定间隔，其元素的顺序并不重要。 重要的是每种食物类型出现的次数。 当每个这样的计数都可以被整除时，该间隔恰好有效`k`。 

任务是计算满足该条件的所有连续子数组。 和`n`最多`2 * 10^5`, 可以有

 [
 \frac{n(n+1)}2 = 20,000,100,000
 ]

 最大情况下的不同间隔。 二次算法已经必须处理大约 200 亿个间隔，这远远超出了正常竞赛时间限制所允许的范围。 我们需要一种仅处理每个数组位置恒定次数的方法，从而给出大致线性的复杂度。 

有几种边界情况很容易处理不当。 如果`k = 1`，每个间隔都是有效的，因为每个单独的食物单位都可以单独食用。 例如，```
1 1
1
```有答案`1`，而仅查找长度大于 1 的组的实现可能会错误地返回零。 

如果`k > n`，不能包含非空区间`k`任何类型的副本，因此没有有效的间隔。 例如，```
3 4
1 1 1
```有答案`0`。 仅检查总长度是否能被整除的解决方案`k`可能会意外地计算空前缀或错误处理短间隔。 

相同类型的重复出现也必须进行模数计数`k`，而不仅仅是检查所有类型出现的次数是否相同。 例如，```
4 2
1 1 1 1
```有答案`3 + 1 = 4`，因为长度为 2 的三个区间和长度为 4 的整个区间都是有效的。 一种仅识别第一个完整组的方法`k`单位将错过较长的间隔。 

## 方法

 直接解决方案可以枚举每个间隔并保持每种食物类型的频率，同时扩展其正确的端点。 对于固定左端点，添加`a[r]`一次一个位置，并保留一个计数器，告诉当前有多少种食物类型的频率不能被`k`。 当该计数器变为零时，当前间隔有效。 这可以正确检查每个间隔，而无需重复扫描所有间隔`n`类型。 

问题是间隔的数量。 有`n(n+1)/2`其中，达到`20,000,100,000`什么时候`n = 200000`。 尽管在这个优化的暴力版本中每个间隔都是在恒定时间内处理的，但二次时间仍然太慢。 

关键的观察是整除性仅取决于每种类型模的频率`k`。 考虑数组的前缀。 对于每个前缀，将其状态定义为向量

 [
 (c_1 \bmod k,\ c_2 \bmod k,\ \ldots,\ c_n \bmod k),
 ]

 哪里`c_x`是类型出现的次数`x`在该前缀中。 

假设前缀以位置结尾`l - 1`和`r`具有完全相同的状态。 减去它们的频率向量告诉我们，每种类型都会出现多个`k`间隔内的次数`[l, r]`。 因此该区间是有效的。 

反之亦然。 如果`[l, r]`是有效的，每种类型贡献的倍数`k`，所以两个前缀状态模数相等`k`。 

因此，原来的问题变成了一个标准的前缀状态计数问题：扫描数组，计算每个前缀的状态，并计算存在多少对相等的状态。 如果出现了一个状态`f`以前，当前前缀恰好创建`f`新的有效间隔。 

障碍是完整的状态最多有`n`坐标，因此将其存储为元组需要`O(n)`每个职位的工作量。 相反，我们维护状态的随机 128 位指纹。 给予每种食物类型`x`随机 128 位权重`w[x]`。 如果它的当前残差是`c[x]`，其对指纹的贡献为`c[x] * w[x]`。 当类型出现一次时`x`添加，其余数增加一模数`k`，因此总指纹会发生已知量的变化。 我们可以在恒定的时间内更新它。 

指纹是概率性的，而不是数学上无碰撞的，但 128 位随机值使得意外碰撞的可能性微乎其微。 这与大向量的随机散列的想法相同，只是这里向量一次改变一个坐标。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳| O(n) 预期 | O(n) | 已接受 |

 ## 算法演练

 1. 分配每种食物类型`x`随机 128 位权重`w[x]`。 我们将用指纹来表示所有频率残基的向量

 [
 H = \sum_x c_x w_x \pmod {2^{128}}，
 ]

 哪里`c_x`是类型的当前频率`x`模数`k`。 

我们不需要存储整个向量。 指纹足以以压倒性的概率比较前缀状态。 
2.将每个残数初始化为零，这样空前缀就有指纹`0`。 将这个指纹放入带有计数的频率字典中`1`。 

首次出现代表前缀位置`0`。 如果后面的前缀具有相同的状态，则这两个前缀之间的间隔从位置开始`1`。 
3. 从左到右扫描阵列。 对于当前的食物类型`x`，增加其余数模`k`。 

如果其旧残留量小于`k - 1`，余数增加一，所以添加`w[x]`到指纹。 如果旧的残留物是`k - 1`，新的残差变为零，因此贡献从`(k - 1)w[x]`为零。 在这种情况下减去`(k - 1)w[x]`。 
4. 更新指纹后，在字典中查找。 如果已经出现了`f`次，添加`f`到答案。 

具有相同状态的每个先前前缀形成一个以当前位置结束的有效区间。 我们一次计算所有这些间隔。 
5.增加当前指纹在字典中的出现频率。 继续，直到处理完每个位置。 
6. 返回累计答案。 

### 为什么它有效

 对于每个前缀，食物类型所保留的残留量正是其出现次数模数`k`。 考虑两个前缀，一个在间隔之前结束，一个在其右端点结束。 当每种食物类型在两个前缀中具有相同的残基时，它们的状态完全相同。 减去两个前缀计数意味着每种食物类型出现的倍数`k`间隔内的次数。 这样的区间可以精确地分为几组`k`相同的食物单位，所以鲨鱼可以完全吃掉它。 

相反，如果一个区间可以完全吃完，则每种类型出现的倍数`k`次，因此从后面的前缀中删除该间隔不会改变任何残留。 两个前缀状态相等。 因此，有效间隔完全对应于相等的前缀状态。 

字典对每对相等状态计数一次，因此每个有效间隔都会被计数，而不会计数无效间隔。 唯一的近似是随机指纹：理论上两个不同的状态可以接收相同的 128 位值，但概率可以忽略不计。 

## Python 解决方案```python
import sys
import random

input = sys.stdin.readline

MASK = (1 << 128) - 1

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    # A fresh random weight for every food type.
    rng = random.Random()
    weight = [0] + [rng.getrandbits(128) for _ in range(n)]

    # residue[x] = current frequency of type x modulo k.
    residue = [0] * (n + 1)

    # Frequency of every prefix fingerprint.
    seen = {0: 1}

    state = 0
    answer = 0

    for x in a:
        r = residue[x]

        if r == k - 1:
            # (k - 1) * w[x] -> 0
            state = (state - (k - 1) * weight[x]) & MASK
            residue[x] = 0
        else:
            state = (state + weight[x]) & MASK
            residue[x] = r + 1

        answer += seen.get(state, 0)
        seen[state] = seen.get(state, 0) + 1

    print(answer)

if __name__ == "__main__":
    solve()
```这`residue`数组准确地存储了处理新食品单位时发生变化的信息。 对于残基为`r`，添加一个单位将其更改为`r + 1`除非达到`k`，在这种情况下它会回滚到零。 

指纹与残留物保持一致。 对于通常的转换，贡献变化为`+weight[x]`。 关于环绕式过渡，旧的贡献`(k - 1) * weight[x]`完全消失，所以我们减去该值。 

这`& MASK`操作保持指纹模数`2^128`。 Python 整数可以增长任意大，因此如果没有这个掩码，状态将累积不必要的大值。 该掩码还为我们提供了固定的 128 位指纹。 

字典开头是`{0: 1}`因为空前缀是实前缀状态。 忘记它会丢失从位置开始的每个有效间隔`1`。 答案在插入当前状态之前更新，因此仅使用较早的前缀来形成以当前位置结束的间隔。 

Python 整数安全地处理最终答案。 最大间隔数约为`2 * 10^10`，它完全在 Python 的整数范围内。

    old_stdout = sys.stdout

 ## 边缘情况

 当`k = 1`，每个频率自动为零模一。 前缀状态永远不会改变，所以所有`n + 1`前缀具有相同的状态。 因此，字典对每对前缀进行计数，给出`n(n+1)/2`。 为了`n = 6`， 这是`21`，完全按照相应的测试检查。 

什么时候`k > n`，不能包含非空区间`k`任何一种类型的副本。 在输入中`3 4 / 1 1 1`，残差进展自`0`到`1`， 然后`2`， 然后`3`，并且永远不会归零。 初始状态永远不会重复，所以答案仍然存在`0`。 

对于重复的完整组，请考虑`4 2 / 1 1 1 1`。 这些州是`0, 1, 0, 1, 0`。 状态零发生在以下位置`0`,`2`， 和`4`，产生三个间隔，而状态一出现在位置`1`和`3`，再生产一个。 答案是`3 + 1 = 4`。 

环绕式过渡值得特别关注。 如果当前的残差是`k - 1`，添加一次出现使其为零，而不是`k`。 为了`k = 2`，类型从残基变化`1`至残留`0`。 代码减去`(k - 1) * weight[x]`，这正是旧的贡献，因此该类型对新状态没有任何贡献。 

最后，有效间隔可以从第一个数组位置开始。 这就是为什么空前缀被插入到`seen`在处理任何元素之前。 如果没有初始状态，输入如`6 6 / 1 1 1 1 1 1`将无法计算整个数组，即使它的频率可以被`k`。
