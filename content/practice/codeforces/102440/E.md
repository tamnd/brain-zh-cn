 ## 问题理解

 提供的问题陈述与其示例输出之间存在直接矛盾，因此无法完全按照给定的陈述编写正确的社论。 

数组`f`描述一个函数图：每颗星`i`有一个出边`i -> f_i`，以及每一个`-1`是一条边，我们可以选择其目的地。 从一颗星开始，反复沿着这些边，最终进入一个有向循环。 数量`c_i`可以到达的不同恒星`i`因此，它是导致循环的尾部大小加上循环大小，其中包括起始星，因为它可以通过零移动从自身到达，并且在功能图中，在遍历循环后也会再次出现。 

考虑第一个样本：```
n = 5
f = [0, 1, 2, -1, -1]
```星星`0`,`1`， 和`2`已经有了自循环，所以每个人都有贡献`1`。 

两条未知边可以合法地完成为```
f = [0, 1, 2, 4, 3]
```然后星星`3`和`4`形成一个长度的循环`2`。 从任意一颗开始，两颗可到达的恒星是`3`和`4`，所以他们的贡献都是`2`。 

由此产生的吸引力是

 1+1+1+2+2=7，

 这已经大于指定的样本输出`3`。 因此`3`不能是所提供定义下的最大值。 

第二个样本在相反的方向上有同样的问题。 由于所有七个条目均未知，我们可以设置```
f = [1, 2, 3, 4, 5, 6, 0]
```并获得包含所有七颗星的一个周期。 每个起始星都可以达到全部七颗星，所以吸引力是

 7·7=49，

 不是规定的`42`。 

这种差异不是实现细节或边缘情况。 它改变了数学问题本身。 官方 Codeforces 页面当前显示与此处所示完全相同的声明和示例，同时还表明该声明最近已更改。 

## 方法

 对于所写的声明，暴力破解将枚举所有可能的替换`-1`条目。 如果有`k`未知位置，有`n^k`完成情况。 天真地评估一个完整的功能图可能需要`O(n^2)`通过从每个顶点开始遍历，因此直接穷举方法是`O(n^{k+2})`。 由于所有条目未知，这变成了`O(n^{n+2})`，即使对于非常小的情况，这也是远远超出可行的`n`。 

事实上，对于该语句所描述的数学问题，存在一个线性时间图解，该解决方案基于将部分指定的函数图分解为已经包含循环的分量和以未知边缘结束的分量。 然而，该解决方案产生`7`和`49`对于提供的样品，不`3`和`42`。 

由于所需的社论必须包含可接受的实现和准确的工作示例，因此将该算法作为所提供问题的解决方案呈现会产生误导。

 ## 算法演练

 为了完整性，不需要任何复杂的算法就可以建立矛盾。 

1. 保持固定边缘`0 -> 0`,`1 -> 1`， 和`2 -> 2`。 这三颗恒星中的每一颗都恰好有一颗可到达的恒星。 
2. 完成未知边`3 -> 4`和`4 -> 3`。 这是有效的完成，因为两个目的地都是有效的星级索引。 
3.从明星开始`3`，序列是`3, 4, 3, 4, ...`，所以不同的可达恒星是`{3, 4}`和`c_3 = 2`。 
4.从明星开始`4`，同一个循环以相反的方向遍历，所以`c_4 = 2`。 
5. 由此产生的吸引力是`1 + 1 + 1 + 2 + 2 = 7`。 
6. 自从`7 > 3`，第一个样本声称的最大值不能遵循提供的定义。 

第二个例子给出了一个更简单的矛盾。 将七个未知边设置为一个七循环，使每颗星都达到七颗星，从而具有吸引力`49`，而样本声称`42`。 

矛盾背后的不变量很简单，有向循环中的每个顶点都可以到达该循环的每个顶点。 对给定图形规则的任何解释都只能做出七周期的贡献`6`可到达的星星如果`c_i`如声明所述，计算从起始顶点可到达的不同恒星。

 第一个不明显的边缘情况正是第一个样本。 不禁止未知边相互指向。 一次`3 -> 4`和`4 -> 3`被选择时，这些顶点形成一个有效的双循环，因此它们的贡献都是`2`。 任何默默离开的算法`-1`图中的顶点将产生样本的`3`，但它不会解决所述的完成问题。
