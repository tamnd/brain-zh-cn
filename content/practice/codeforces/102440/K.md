 ## 解决方案
 ## 问题理解

 我们有一个二进制数组。 它的绝对值是1的数量和0的数量之间的绝对差。 在更改一个连续的段之后，包括不更改任何内容的可能性，我们希望能够获得最大的绝对值。 然后单个数组元素一次翻转一个，每次更新后我们必须重新计算这个最大值。 

表示数组的一种有用方法是替换每个`1`经过`+1`和每一个`0`经过`-1`。 令结果值为 (b_i)。 那么整个数组的总和就是

 [
 S=\sum b_i=c_1-c_0。 
]

 数组的绝对值就是 (|S|)。 

假设我们翻转一个段，其在变换后的数组中的总和为 (X)。 该段中的每个元素都会改变符号，因此其贡献从 (X) 变为 (-X)。 整个数组的和因此变为

 [
 S-2X。 
]

 因此，对于当前数组，答案是

 [
 \max_{\text{段} I}|S-2\operatorname{sum}(I)|。 
]

 段总和可以是任何子数组总和，因此唯一重要的值是最小和最大子数组总和。 如果 (mn) 是最小子数组和，(mx) 是最大子数组和，则

 [
 c_A=\max\left(|S-2mn|,\ |S-2mx|\right)。 
]

 输入最多包含 (2\cdot10^5) 个元素和最多 (2\cdot10^5) 个更新。 每次更新后扫描整个数组的方法将执行 (O(nq)) 工作，可以达到大约 (4\cdot10^{10}) 元素操作。 即使从头开始重新计算所有子数组的和也远远超出了约束所允许的范围。 我们需要在大致对数时间内更新相关信息。 

有几种边缘情况可能会暴露粗心的实现。 例如，对于单个元素，```
1 1
0
1
```数组变成`[1]`，所以答案是`1`。 线段树实现意外地假设每个内部节点都有两个子节点，可能会错误地处理这种情况。 

全相等数组是另一个有用的检查。 为了```
3 1
0 0 0
1
```更新产生`[1,0,0]`。 翻转最后两个元素给出`[1,1,1]`，所以答案是`3`。 仅考虑翻转单个位置的实现将错误地得到`1`。 

端点也很重要，因为最佳段可以在数组边界处开始或结束。 为了```
4 1
1 0 0 1
1
```更新后的数组是`[0,0,0,1]`。 翻转前三个元素会产生`[1,1,1,1]`，所以答案是`4`。 如果前缀或后缀处理不正确，最大子数组实现可能会丢失此段。 

最后，最佳分段可以是内部分段。 在提供的示例中，第一次更新后，转换后的数组为`[1,1,1,-1,-1,1]`。 包含两个的段`-1`值有总和`-2`，翻转它会改变总和`2`到`6`。 仅查看前缀或后缀会错过最佳结果。 

## 方法

 直接的解决方案是在每个点更新后尝试每个可能的段。 对于固定段，我们可以计算其总和并评估所得的绝对值。 有 (O(n^2)) 个段，因此在每次 (q) 更新之后执行此操作将花费 (O(qn^2)) 时间。 即使我们通过计算带有前缀和的所有子数组和来改进固定数组部分，仍然有 (O(n^2)) 段需要检查。 对于 (n=q=2\cdot10^5)，这是完全不可行的。 

更好的暴力方法是在每次更新后使用 Kadane 算法扫描数组。 Kadane 的算法给出了 (O(n)) 中的最大和最小子数组和，之后答案立即从上面的公式得出。 这将总复杂度降低到 (O(nq))，但最坏的情况仍然包含大约 (4\cdot10^{10}) 个数组元素操作。 

关键的观察结果是答案并不分别取决于每个子数组。 一旦总和 (S) 已知，表达式 (|S-2X|) 将在 (X) 的可能极值处最大化。 因此，我们只需要最小和最大子数组和。 

这正是线段树可以维护的信息。 对于数组的每个段，我们存储其总和、最大前缀和、最大后缀和、最大子数组和以及相应的三个最小值。 当两个相邻段连接时，这些量中的每一个都可以根据两个子段的相应量来计算。 点翻转仅更改一个叶子，因此只需重新计算 (O(\log n)) 线段树节点。 

暴力解决方案之所以有效，是因为 Kadane 的算法正确地找到了两个极端子数组和，但当在 (2\cdot10^5) 更新后必须重新计算这些值时，它就会失败。 观察到所需信息具有可组合的段结构，我们可以动态地保留这些值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解所有细分市场 | (O(qn^2)) | (O(n)) | (O(n)) | 太慢了|
 | 每次更新后的 Kadane | (O(qn)) | (O(n)) | (O(n)) | 太慢了|
 | 线段树 | (O((n+q)\log n)) | (O(n)) | (O(n)) | 已接受 |

 ## 算法演练

 1. 将每个数组值转换为 (+1) 或 (-1)。 一个`1`变成`+1`，和一个`0`变成`-1`。 转换后的数组的总和恰好是 1 和 0 的数量之差。 
2. 对于每个线段树节点，存储七个值：总和、最大前缀和、最大后缀和、最大子数组和、最小前缀和、最小后缀和、最小子数组和。 我们使用非空前缀、后缀和子数组。 
3. 对于两个相邻节点 (L) 和 (R)，计算它们的总和：

 [
 总和=L.总和+R.总和。 
]

 最大前缀要么完全在 (L) 内部，要么由全部 (L) 后跟最大前缀 (R) 组成：

 [
 maxPref=\max(L.maxPref,L.sum+R.maxPref)。 
]

 最大后缀是对称的：

 [
 maxSuff=\max(R.maxSuff,R.sum+L.maxSuff)。 
]

 最大子数组要么完全在左子数组中，要么完全在右子数组中，要么跨越它们的边界。 因此

 [
 maxSub=\max(L.maxSub,R.maxSub,L.maxSuff+R.maxPref)。 
]

 最小值是使用完全相同的公式获得的`min`而不是`max`。 

1. 根据初始变换数组构建线段树。 每个表示值 (x) 的叶子都具有等于 (x) 的所有七个存储量。 
2. 当位置(p)翻转时，将其叶子从(x)更改为(-x)。 重新计算返回根的路径上的每个祖先。 只有 (O(\log n)) 个节点发生变化，因为所有其他段不受影响。 
3. 令根包含总和 (S)、最小子数组和 (mn) 和最大子数组和 (mx)。 用 sum (mn) 翻转一个线段会产生总和 (S-2mn)，而用 sum (mx) 翻转一个线段会产生 (S-2mx)。 
4. 输出

 [
 \max\left(|S-2mn|,\ |S-2mx|\right)。 
]

 这两个候选值足够的原因是 (f(X)=|S-2X|) 是 (X) 的 V 形函数。 在所有可达到的子数组总和中，其最大值在两个极端之一处达到。 

### 为什么它有效

 线段树不变式是每个节点都包含其相应数组段的七个正确聚合值。 合并公式枚举最佳前缀、后缀或子数组的每个可能位置，因此组合两个正确的子项始终会产生正确的父项。 点更新会更改一个叶子，然后沿着到根的唯一路径恢复此不变量。 

在根部，(S) 是整个变换数组的总和，每个合法的翻转段都有一些子数组总和 (X)。 其结果总数为 (S-2X)。 由于该表达式的绝对值在最小或最大可能 (X) 中达到最大值，因此根的最小和最大子数组和给出了准确的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, q = map(int, input().split())
    a = list(map(int, input().split()))

    size = 1
    while size < n:
        size <<= 1

    # Each node is:
    # sum, max_prefix, max_suffix, max_subarray,
    # min_prefix, min_suffix, min_subarray
    tree = [(0, 0, 0, 0, 0, 0, 0) for _ in range(2 * size)]

    for i in range(n):
        x = 1 if a[i] else -1
        tree[size + i] = (x, x, x, x, x, x, x)

    def merge(left, right):
        ls, lp, lsf, lm, lnp, lns, lmin = left
        rs, rp, rsf, rm, rnp, rns, rmin = right

        total = ls + rs

        max_prefix = max(lp, ls + rp)
        max_suffix = max(rsf, rs + lsf)
        max_sub = max(lm, rm, lsf + rp)

        min_prefix = min(lnp, ls + rnp)
        min_suffix = min(rns, rs + lns)
        min_sub = min(lmin, rmin, lns + rnp)

        return (
            total,
            max_prefix,
            max_suffix,
            max_sub,
            min_prefix,
            min_suffix,
            min_sub,
        )

    for i in range(size - 1, 0, -1):
        tree[i] = merge(tree[i << 1], tree[i << 1 | 1])

    out = []

    for _ in range(q):
        p = int(input()) - 1
        pos = size + p

        old = tree[pos][0]
        x = -old
        tree[pos] = (x, x, x, x, x, x, x)

        pos >>= 1
        while pos:
            tree[pos] = merge(tree[pos << 1], tree[pos << 1 | 1])
            pos >>= 1

        total = tree[1][0]
        max_sub = tree[1][3]
        min_sub = tree[1][6]

        answer = max(
            abs(total - 2 * max_sub),
            abs(total - 2 * min_sub)
        )
        out.append(str(answer))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```创建叶子时，首先隐式转换数组。 储存`+1`对于一个和`-1`for a 0 避免了在 0 和 1 计数之间重复转换。 

每个元组中的七个值就足够了，因为每个父聚合都可以仅使用其两个子聚合来表示。 特别是，跨越边界的最大子数组必须是左孩子的最佳后缀，后跟右孩子的最佳前缀。 同样的推理给出了最小子阵公式。 

迭代树使用二的幂基。 之前的职位`n`包含实数数组元素，而其余叶子是中性零段。 这是干净的，因为当使用根聚合时，树仅基于实值构建，并且零叶子不会更改已经从非空实段获得的任何最大值或最小值。 由于每个真实叶子都有一个非零值，因此根的极值仍然是非空子数组极值。 

在更新期间，旧的叶子值被直接求反。 这比查询原始二进制数组更安全，因为原始值可能已经被翻转多次。 然后更新向上进行，直到到达根。 

所有和最多有绝对值 (n)，因此 Python 整数有足够的范围。 在具有固定宽度整数的语言中，有符号的 32 位整数在这里已经足够了，尽管使用 64 位整数是通常的安全选择。

 ## 边缘情况

 对于单元素数组，例如```
1 1
0
1
```唯一的元素变化自`0`到`1`。 转换后的树由一个具有值的真实叶子组成`1`，所以它的总和、最小子数组和最大子数组和都是`1`。 答案是

 [
 |1-2\cdot1|=1。 
]

 对于这种情况，线段树不需要任何特殊情况。 

对于全零数组，```
3 1
0 0 0
1
```更新给出了`[1,0,0]`，表示为`[1,-1,-1]`。 总计为`-1`，最小子数组和为`-2`，最大子数组和为`1`。 翻转最小和段将总数更改为

 [
 -1-2(-2)=3,
 ]

 所以答案是`3`。 该算法自然地找到包含两个零的段，而无需显式推理二进制计数。 

对于接触左边界的最佳线段，```
4 1
1 0 0 1
1
```更新后的变换数组是`[-1,-1,-1,1]`。 其总数为`-2`其最小子数组和为`-3`。 前三个元素形成最小子数组，因此翻转它们给出

 [
 -2-2(-3)=4。 
]

 因此答案是`4`。 树中的最大前缀和最大后缀字段允许正确组合此类跨越边界的段。 

对于内部最优，请考虑所有四次更新后所提供样本的最终状态：```
0 1 1 0 1 0
```这变成```
-1 1 1 -1 1 -1.
```其总数为`0`，而它的最大子数组和是`2`，从位置上相邻的两个得到`2`和`3`。 翻转该部分会将总数更改为

 [
 0-2\cdot2=-4,
 ]

 所以答案是`4`。 这证实了为什么解决方案必须跟踪真正的子数组，而不仅仅是前缀、后缀或单独的运行。 

最后，对同一位置的重复更新需要使用当前叶子值而不是原始输入值。 例如，```
1 3
0
1
1
1
```通过改变转换后的值`-1`,`+1`,`-1`,`+1`。 每次否定当前叶子都会自动处理这个问题。 保留一个单独的布尔数组也可以，但是叶子本身已经包含了下一次更新所需的状态。
