 ## 解决方案
 ## 问题理解

 我们正在计算构建最终单位大小位置序列的方法，其总长度恰好为$N$。 每个位置可以是普通宝石，也可以是魔法宝石分裂的结果。 普通宝石总是只贡献一个单位，并且除了最终序列中的位置之外无法区分。 

当我们构造最终配置时，魔法宝石有两种可能的行为方式。 它可以保持不分割，贡献一个单元，也可以分割成$M$普通宝石，贡献$M$连续的单位位置。 关键的限制是我们从一些魔法宝石的集合开始并选择要分割的宝石，并且所得的扩展序列必须具有精确的总长度$N$。 

如果两种配置在使用原始魔法宝石索引或分割哪些索引方面有所不同，则它们被认为是不同的，这实际上意味着即使最终的扩展序列结构可能看起来相似，选择的顺序和同一性也很重要。 

输入给出$N$，最终总长度，以及$M$，分裂魔法宝石的膨胀尺寸。 输出是获得最终长度序列的不同方法的数量$N$, 取模$10^9 + 7$。 

约束条件$N \le 10^{18}$立即排除任何迭代可能数量的 gem 或使用 DP 的解决方案$N$。 任何线性或二次增长的状态空间$N$是不可能的。 唯一可行的方法是将转换压缩为恒定大小状态或利用线性递归。 

出现微妙的边缘情况时$N < M$。 在这种情况下，不可能进行拆分，并且达到长度的唯一方法$N$就是准确地使用$N$未分裂的魔法宝石，给出了完全相同的一种配置。 假设至少一次分割的简单递归实现可能会错误地返回零或访问无效状态。 

另一种边缘情况发生在$N = M$。 这里我们有两种可能性：要么是一个长度不分割的宝石序列$M$，或者一颗分裂宝石恰好产生$M$普通宝石。 这些是不同的配置，因此答案是 2，尽管最终的序列看起来相同。 

## 方法

 暴力解释首先想象我们决定拿走多少魔法宝石以及分割哪些魔法宝石。 假设我们采取$k$魔法宝石总数和分割数$t$其中。 那么最终的长度就变成了$$(k - t)\cdot 1 + t \cdot M = k + t(M - 1).$$我们需要这个等于$N$。 对于每个$k$，我们可以尝试所有$t$，对于每个有效对，我们计算选择分割宝石的组合。 然而，这很快就会变成组合爆炸，因为$k$本身是无限的并且有效地绑定到$N$，所以枚举所有可能性是不可能的。 

关键的观察结果是该过程是连续的并且对顺序敏感。 我们从左到右构建一个序列，在每一步我们要么放置一个单元（未分割的宝石），要么放置一个大小的块$M$（分裂宝石）。 这正是一条长度线上的平铺问题$N$，其中图块的长度为 1 或 length$M$。 宝石的特性很重要，因为不同的选择对应于按顺序放置这些瓷砖的不同方式，而不仅仅是不同的组合。 

这立即将问题转化为计数组合物$N$使用第 1 部分和$M$，其中顺序很重要。 让$f(n)$是构建长度的方法的数量$n$。 最后一步是放置一个单元，贡献$f(n-1)$，或放置一块大小为$M$, 贡献$f(n-M)$。 这会产生线性递推：$$f(n) = f(n-1) + f(n-M).$$暴力DP结束$n$是不可能的，因为$N \le 10^{18}$，但递归具有固定宽度$M$，因此可以使用大小状态上的矩阵求幂来加速$M$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力DP结束$n$|$O(N)$|$O(N)$| 太慢了 |
 | 矩阵求幂|$O(M^3 \log N)$|$O(M^2)$| 已接受 |

 ## 算法演练

 我们将递归转换为大小向量上的状态转换$M$，跟踪最后一个$M$DP 的值。 

1.定义DP递归$f(n) = f(n-1) + f(n-M)$。 这抓住了这样一个事实：最终配置要么以单个单元结束，要么以完整的单元结束。$M$-堵塞。 
2. 构建一个状态向量来存储$[f(n), f(n-1), \dots, f(n-M+1)]$。 这使我们能够使用固定内存来表示任何步骤的系统。 
3. 构造一个映射步骤步状态的转移矩阵$n$迈出一步$n+1$。 The first row encodes the recurrence: the new value depends on the previous first entry and the entry corresponding to$n+1-M$。 
4. 填充矩阵，以便状态的转变由恒等结构处理：每个$f(n-i)$移动到$f(n+1-(i+1))$。 
5. 转换矩阵的幂$N-M+1$，因为我们可以初始化基值到$M$直接地。 
6. 将矩阵乘以基向量并提取第一个分量作为答案。 

关键思想是矩阵求幂的每一步都模拟一个增量$n$，并且重复平方将过程压缩为对数时间。 

### 为什么它有效

 正确性来自于递归仅取决于最后一个事实$M$状态，因此该系统是具有固定维度的完全马尔可夫系统。 每个有效的长度结构$n$根据其最后一段的长度是 1 还是 length 唯一可分解$M$，并且这种分解是不相交且详尽的。 矩阵表示准确地保留了这种转换，因此对其求幂可以保留长范围内的重现而不会丢失信息。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mul(a, b):
    m = len(a)
    res = [[0] * m for _ in range(m)]
    for i in range(m):
        for k in range(m):
            if a[i][k]:
                aik = a[i][k]
                for j in range(m):
                    res[i][j] = (res[i][j] + aik * b[k][j]) % MOD
    return res

def mat_pow(mat, p):
    m = len(mat)
    res = [[0] * m for _ in range(m)]
    for i in range(m):
        res[i][i] = 1
    while p:
        if p & 1:
            res = mat_mul(res, mat)
        mat = mat_mul(mat, mat)
        p >>= 1
    return res

def solve():
    N, M = map(int, input().split())

    if N < M:
        print(1)
        return

    if M == 1:
        print(1)
        return

    dp = [0] * M
    dp[0] = 1

    T = [[0] * M for _ in range(M)]
    T[0][0] = 1
    T[0][M - 1] = 1

    for i in range(1, M):
        T[i][i - 1] = 1

    power = N - M + 1
    T = mat_pow(T, power)

    base = [0] * M
    base[0] = 1

    ans = 0
    for i in range(M):
        ans = (ans + T[0][i] * base[i]) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该代码直接从转换构造递归矩阵$f(n) = f(n-1) + f(n-M)$。 矩阵的第一行编码两种可能性：继续一个单位步骤或跳回$M$。 次对角线移位处理先前状态的传播。 

一个微妙的点是初始化。 我们对待$f(0) = 1$，并且所有较小的基本情况都通过状态构造隐式处理。 指数$N - M + 1$调整系统，以便我们准确着陆$f(N)$繁殖后。 

边缘处理$N < M$是必要的，因为矩阵转换假设递归处于活动状态，这仅在序列至少为 length 时才有意义$M$。 

## 工作示例

 ### 示例 1

 输入：```
4 2
```我们使用递归$f(n) = f(n-1) + f(n-2)$。 

| n | f(n-1) | f(n-1) | f(n-2) | f(n-2) | f(n) | f(n) |
 | ---| ---| ---| ---|
 | 1 | - | - | 1 |
 | 2 | 1 | 1 | 2 |
 | 3 | 2 | 1 | 3 |
 | 4 | 3 | 2 | 5 |

 最终值为 5，与放置单个宝石或对应于分割的宝石对的方式数量相匹配。 这证实了重复正确地考虑了两种扩展类型。 

### 示例 2

 输入：```
5 3
```我们计算$f(n) = f(n-1) + f(n-3)$。 

| n | f(n-1) | f(n-1) | f(n-3) | f(n-3) | f(n) | f(n) |
 | ---| ---| ---| ---|
 | 1 | - | - | 1 |
 | 2 | 1 | - | 1 |
 | 3 | 1 | 1 | 2 |
 | 4 | 2 | 1 | 3 |
 | 5 | 3 | 2 | 5 |

 这表明较长的跳跃只有在达到长度后才开始起作用$M$，并且递归自然地结合了分裂宝石的延迟结构。

 ## 边缘情况

 当$N < M$，递归不适用，因为任何分割块都无法容纳。 在这种情况下，唯一有效的构造是仅使用单位贡献，因此存在一种配置。 该算法在任何矩阵计算之前显式返回 1，以防止转换中的无效负索引。 

什么时候$N = M$，单个未分割的 gem 和单个分割的 gem 都会产生有效的配置。 递归在过渡边界捕获了这一点，其中$f(n-M)$term 首先变得活跃，确保 2 的值正确，无需特殊情况枚举。 

为了$M = 2$，递归退化为斐波那契数，并且矩阵简化为标准的二维斐波那契转变。 该算法无需修改即可自然地处理此问题，从而确认最小的非平凡分割大小的正确性。
