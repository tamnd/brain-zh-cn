 ## 解决方案
 ## 问题理解

 我们有两行水平的学生，每行包含相同数量的人。 每个学生都有一个身高，我们希望通过严格的排序规则从这两行中选择学生来建立一个团队：一旦我们开始从左到右选择，我们就永远不能在索引上向后移动，并且我们也禁止从同一行中连续选择两个学生。 

这会在两个并行数组上产生约束序列问题。 在每一步中，我们从顶行或底行选择下一个学生，但前提是他们的列索引严格大于最后选择的学生的索引，并且该行与上一个选择交替。 

目标是最大化所选学生的身高总和。 

约束条件$n \le 10^5$立即排除对位置对的任何指数或二次动态规划。 任何尝试显式考虑所有序列或所有索引对之间的所有转换的解决方案都会太慢。 我们需要一种线性或近线性的方法。 

一个微妙的困难是我们不必被迫选择相邻的列。 我们可以完全跳过列，这意味着在每一步中，我们本质上都是在对面行的所有有效位置中选择最佳的未来候选者。 天真的贪婪选择（例如总是选择两个可用的下一个学生中较高的一个）会失败，因为局部最优选择可能会阻止稍后访问更好的交替链。 

典型的失败场景是，稍小的立即选择允许访问另一行中更大的未来序列。 例如，在一行的早期选择一个大值可能会迫使您稍后选择一系列小值，而稍等一下并提前切换行会产生更高的总数。 

这种结构表明，每一行的决策取决于从未来指数开始的最佳延续，这是针对头寸的动态规划的经典信号。 

## 方法

 强力解决方案将尝试从每个可能的第一选择开始模拟所有有效的交替序列。 从每个起始单元格，我们分支到相对行中具有较高索引的每个有效的下一个单元格，累积总和。 这探索了一个指数级大的状态空间，因为从每个位置我们都可以跳转到对面行中的许多未来位置，并且每个位置都会导致进一步的分支。 即使修剪也不能防止最坏情况的爆炸，因为有效序列仍然可能非常多。 

关键的观察是，一旦我们修复了当前的位置$i$在一行中，唯一相关的未来选择位于相反行，索引大于$i$。 在所有这些未来选择中，我们只关心从该索引开始的最佳可能延续。 这建议预先计算最佳后缀值。 

让我们定义两个 DP 数组：$dp_1[i]$是如果最后选择的学生位于第 1 行第 1 列时我们可以获得的最佳总和$i$。 相似地，$dp_2[i]$是为第 2 行定义的。 

如果我们在$dp_1[i]$，下一个选择必须来自某个索引处的第 2 行$j > i$。 最好的延续$j$已经编码在$dp_2[j]$。 所以我们想要：$$dp_1[i] = h_{1,i} + \max_{j > i} dp_2[j]$$类似地：$$dp_2[i] = h_{2,i} + \max_{j > i} dp_1[j]$$这种结构允许我们从右到左计算 DP，同时保持运行后缀最大值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| O(n) | 太慢了 |
 | 具有后缀最大值的最优 DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.创建两个数组$dp_1$和$dp_2$, initially filled with zeros. 这些代表当该位置被选为其行中的最后一个选择时，从每个位置开始可实现的最佳总和。 
2. Also maintain two running variables`best1`和`best2`，代表最大值$dp_1[j]$和$dp_2[j]$对于所有指数$j > i$。 这些编码了转换所需的后缀最大值。 
3. 从右向左遍历索引，从$i = n-1$下降到$0$。 这种排序确保了当我们计算状态时$i$，右边的所有状态都是已知的。 
4. 在每个索引处$i$，计算：$dp_1[i] = h_{1,i} + best2$和$dp_2[i] = h_{2,i} + best1$。 这使用已经计算出的最佳延续直接应用转换规则。 
5. 计算完索引的两个值后$i$， 更新`best1`和`best2`使用$dp_1[i]$和$dp_2[i]$。 这确保了未来（向左）状态可以使用正确的后缀信息。 
6. 处理完所有指标后，答案就是所有指标中的最大值$dp_1[i]$和$dp_2[i]$，因为第一个选择的学生可以从任何地方开始。 

### 为什么它有效

 正确性取决于以下事实：每个有效的交替序列都有一个明确定义的第一选择索引，然后根据 DP 依赖性严格递减“剩余后缀选择”序列。 在任何位置$i$，切换行后的最佳延续仅取决于严格从右侧开始的最佳延续。 通过从右到左处理，我们保证每个后缀选择都已得到最佳解决，因此每个 DP 状态都是在完全了解所有有效延续的情况下计算的。 这确保了未来的改进不会使计算状态无效。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    dp1 = [0] * n
    dp2 = [0] * n

    best1 = 0
    best2 = 0

    for i in range(n - 1, -1, -1):
        dp1[i] = a[i] + best2
        dp2[i] = b[i] + best1

        if dp1[i] > best1:
            best1 = dp1[i]
        if dp2[i] > best2:
            best2 = dp2[i]

    print(max(best1, best2))

if __name__ == "__main__":
    solve()
```代码直接实现了前面介绍的后缀DP。 数组`dp1`和`dp2`存储从每个索引开始的最优值，但实际上我们只需要它们来更新后缀最大值。 变量`best1`和`best2`将 DP 表每行压缩到 O(1) 内存中。 

反向迭代是必不可少的，因为它保证当我们计算位置时$i$, 所有州$j > i$已经被合并到后缀 maxima 中。 最终答案采用两行的最佳起点。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

 ## 边缘情况

 一个关键的边缘情况是最佳解决方案从第二行而不是第一行开始。 该算法自然地处理这个问题，因为它计算了$dp_1[i]$和$dp_2[i]$对称并在最后取全局最大值。 例如，如果第 2 行在位置 0 处具有较大值，而第 1 行较弱，则 DP 仍会捕获它，因为$dp_2[0]$可以直接贡献答案，无需事先选择。 

另一个微妙的情况是，需要跳过许多索引才能达到高值交替。 由于转换仅取决于后缀最大值，因此隐式处理跳过：`best1`和`best2`聚合所有未来位置上可实现的最佳延续，因此 DP 不会强制邻接并正确评估稀疏最优序列。
