 ## 解决方案
 ## 问题理解

 我们得到了一个多重集$3N$整数。 两名玩家在结构化选择过程中与这些数字进行交互，逐渐将每个数字分配给三个角色之一：红色、蓝色或丢弃。 超过$N$一轮中，正好有一个数字变成红色，正好有一个数字变成蓝色，正好有一个数字被删除，所以总共我们以$N$红色元素和$N$蓝色元素，其余元素$N$元素消失而不影响分数。 

红色玩家（Carlinhos）每轮选择一个可用号码。 然后对手立即做出反应，选择另外两个可用的数字，将其中一个分配为蓝色并丢弃另一个。 在所有回合之后，两名玩家都在对抗条件下有效地形成了自己的棋盘：Carlinhos 试图最大化红色总和与蓝色总和之间的差异，而对手则试图迫使这些总和相等。 

结果仅取决于卡利尼奥斯是否可以迫使最终的红色总和与对手在给定最佳发挥下构建的所有可能的蓝色总和不同。 

约束条件$N \le 1000$和$3N \le 3000$表明排序和线性扫描就足够了，任何涉及指数子集或对总和进行动态规划的事情都是不可能的。 

微妙的一点是，对手非常强大：通过每轮选择两个未使用的元素，他可以有效地控制哪些元素仍然可供未来蓝色选择。 这使得该过程在全球意义上具有对抗性，而不仅仅是局部贪婪的决策。 

一个天真的错误是假设游戏是关于每轮独立配对的。 但这失败了，因为早期的选择限制了后来的结构。 

例如，如果所有数字都相等，例如$5,5,5,5,5,5$为了$N=2$，任何划分都会产生相同的总和，因此 Carlinhos 无法获胜。 试图“局部平衡”的贪婪策略可能会错误地暗示获胜的可能性，但全局对称性保证了平等。 

另一个失败的情况是当数字的结构类似于二的幂时，例如$1,2,4,8,16,32$。 在这里，每个子集和都是唯一的，因此对手永远无法匹配不同的红色选择。 任何基于平均值或平衡的推理都可能忽略这种刚性。 

## 方法

 暴力视图会尝试模拟游戏：Carlinhos 选择一个红色元素，而对手尝试所有可能的剩余元素对来决定哪个元素变成蓝色。 后$N$回合中，我们将枚举所有生成的红色和蓝色配置，并检查相等性是否始终是可避免或可执行的。 分支因素是巨大的：每一轮都会引入$O(n^2)$对手的选择，导致远远超出的爆炸$10^{18}$州。 

关键的观察是对手的“选二留一”棋比看起来更强。 由于两个选定元素中只有一个变为蓝色，而另一个则被丢弃，因此对手实际上可以自由决定哪些元素保留在蓝色分配的候选池中。 在整个游戏中，这意味着对手可以确保最终的蓝色集本质上是大小的任何子集$N$取自于$2N$未选择为红色的元素。 

这将游戏简化为干净的组合结构。 卡利尼奥斯选择了红色套装$R$大小的$N$。 剩余的多重集$S$有尺寸$2N$。 然后对手选择任意子集$B \subset S$大小的$N$如果可能的话，匹配红色总和。 

那么问题就变成了：是否存在红色选择$R$这样对于每个子集$B$大小的$N$在补数中，相等$\sum R = \sum B$不可能吗？ 

同样，如果卡利尼奥斯能够将红色总和超出可实现的范围，他就获胜$N$- 剩余元素的子集和。 

排序后结构变得易于处理。 对手在固定集合中可能的最佳和最差蓝色总和是通过采用最小或最大的可用元素来实现的。 这将整个不确定性压缩为极端配置。 

卡利尼奥斯只有两种有意义的策略来最大化分离：采取最大的$N$元素或取最小的$N$元素。 任何混合选择都会削弱他将总和推到对手可实现范围之外的能力。 

如果他拿最大的$N$，对手用最小的$2N$。 对手的最大可能蓝和是通过取最大的来实现的$N$其中，它对应于排序数组的中间块。 

如果卡利尼奥斯取最小的$N$，对手与最大的一起工作$2N$，对手的最小可能蓝色和再次对应于中间的块。 

因此，一切都归结为比较排序数组的前缀、中间和后缀总和。

 ## 算法演练

 我们对数组进行排序，以便对极值的推理变得有意义。 令排序后的数组为$a_1 \le a_2 \le \dots \le a_{3N}$。 

我们预先计算前缀和，以便可以在恒定时间内获得任何连续的块和。 

我们将数组分成三个相等的块：最小的$N$, 中间$N$，以及最大的$N$。 

1. 计算最小的和$N$元素。 这代表卡利尼奥斯选择了尽可能小的红色贡献。 
2. 计算中间的和$N$元素。 这代表了对手在两种极端情况下可实现的蓝和的强制边界。 
3. 计算最大的和$N$元素。 这代表卡利尼奥斯选择了尽可能最大的红色贡献。 
4. 如果最大的和$N$元素严格大于中间元素之和$N$卡利尼奥斯可以选择最大的方块，迫使他的得分高于任何可实现的蓝色配置，从而保证获胜。 
5. 如果最小的和$N$元素之和严格小于中间元素之和$N$元素，卡利尼奥斯可以选择最小的块并迫使他的分数低于任何可实现的蓝色配置，这也保证了胜利。 
6. 如果严格的不等式都不成立，则每个可能的极端红色和都可以与某些有效的蓝色构造相匹配，因此对手可以强制执行相等性。 

这两个极端足够的原因是任何其他红色选择都会产生位于这两个极端之间的和，并且对手的灵活性确保任何内部值都可以在剩余元素的可实现子集和范围内匹配。 

### 为什么它有效

 排序后，对手选择任意尺寸子集的能力$N$从剩余的$2N$元素意味着对于任何固定的红色集合，蓝色总和不是任意的，而是限制在最小和最大可能之间$N$- 补集的子集。 这些极端总是与排序数组的连续段对齐。 

Carlinhos 仅当他选择的总和严格超出此可实现的区间时才能保证匹配失败。 强制这种分离的唯一方法是选择两个极端块之一，因为任何混合选择都会产生一个被中间范围的可能蓝色和“覆盖”的和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input())
    a = list(map(int, input().split()))
    a.sort()

    prefix = [0]
    for x in a:
        prefix.append(prefix[-1] + x)

    def range_sum(l, r):
        return prefix[r] - prefix[l]

    total = 3 * N

    small = range_sum(0, N)
    mid = range_sum(N, 2 * N)
    large = range_sum(2 * N, 3 * N)

    if large > mid or small < mid:
        print("Y")
    else:
        print("N")

if __name__ == "__main__":
    solve()
```该实现依赖于排序来揭示最佳游戏的结构。 使用前缀和，以便排序后可以在恒定时间内计算三个块的和。 

关键细节是我们从不尝试模拟游戏。 所有交互作用都被压缩为从排序数组派生的三个确定性量之间的比较。

这显示了“上分离”情况，其中顶部块主导了对手可以从其余部分构建的所有内容。

这证实了当所有区块都塌陷为相同的总和时，游戏就变得完美平衡，卡利尼奥斯无法创造分离。

 ## 边缘情况

 当所有数字都相同时，排序后的块的总和相等。 在这种情况下，两种极端策略都不会产生严格的优势，因此对手始终可以使用相应的蓝色选择来镜像任何红色和。 算法正确返回`N`因为这两个不等式都失败了。 

当值严格递增但间隔适中时，最大的块通常会主导中间的块。 例如，与$[1,2,3,100,200,300]$，大的块和超过了中间的块和，因此 Carlinhos 可以通过选择最大的元素来强制分离。 条件`large > mid`无需任何游戏模拟即可正确捕获这一点。
