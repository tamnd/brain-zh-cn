 ## 解决方案
 ## 问题理解

 我们得到一个由小写字母组成的字符串以及一种为每个字母分配数字权重的方法。 完整字符串的值是通过对所有位置位置索引（从 1 开始）与该位置字符权重的乘积求和来计算的。 因此，放置在后面的角色贡献更多，因为它们的乘数更大。 

我们也可以精确插入`k`字符串中任意位置的附加小写字母。 每个插入的字符贡献自己的权重乘以它在最终字符串中的位置，插入一个字符会将其后面的所有内容向右移动一个位置，从而增加它们的乘数。 目标是选择插入的字母及其位置，以使最终的加权和最大化。 

限制很小：字符串长度最多为 1000 并且`k`最多为 1000。这立即表明对位置的二次甚至三次推理是可以接受的，但强力强制所有可能的插入配置是不可能的，因为每个插入有 26 个选择和 2000 个位置，导致指数爆炸。 

当贪婪地推理插入时，会出现一个微妙的问题。 一个天真的想法是始终将最高值的字母放在最后，因为后面的位置具有更大的乘数。 这会失败，因为在末尾插入一个字母会增加长度，这也会增加所有先前字符的贡献。 另一个陷阱是认为插入是独立的，而实际上每个插入都会更改所有后续索引。 

## 方法

 蛮力的观点是尝试每一种插入方式`k`将字母插入字符串并直接计算结果分数。 即使我们固定了插入的位置，我们仍然需要选择在每个位置插入哪个字母。 这导致大约$\binom{n+k}{k} \cdot 26^k$即使投入很小，这也远远超出了可行的范围。 评估每种配置的成本与最终长度呈线性关系，因此这种方法立即崩溃。 

关键的观察结果是，价值函数与角色按位置的贡献呈线性关系。 重要的不是我们选择插入的绝对位置，而是我们决定总体使用哪些字母以及插入多少个字母。 

一旦我们修复了插入字母的多重集，最好的策略总是将较高值的字母尽可能地放置在右侧，因为后面的位置会增加它们的权重。 这将问题转化为决定每个字母插入多少个，然后贪婪地将所有插入的字母按重量不递增的顺序放置在字符串的末尾。 原始字符串顺序被保留，因为重新排序原始字符只会造成伤害，因为较早出现的位置乘数较小。 

所以解决方案变成：将原始字符串视为固定，并追加`k`最佳选择的角色。 由于顺序仅通过权重起作用，因此插入的字符应按权重排序并放置在末尾。 

这将问题简化为简单的贪心构造：选择最好的`k`字母（允许重复）并按重量递减顺序附加它们。

 ## 算法演练

 1. 使用公式计算原始字符串的当前贡献，其中每个字符在位置`i`贡献`i * w[c]`。 这是固定的，不能通过重新排序来改变，所以我们只是简单地累积它。 
2. 提取所有字母的权重并确定哪个字母的权重最大。 由于我们可以插入任何字母，因此每次插入都应该使用这个最大权重字符。 

原因是每次插入都会对总和产生线性贡献，因此用较低权重的字符替换任何插入的字符会严格降低结果。 
3. 通过附加构造最终字符串`k`将此最佳字母复制到原始字符串。 我们不需要在原始字符串内交错插入，因为较早放置它们会减少它们的位置乘数，而将它们推到末尾会最大化它们的索引。 
4. 计算插入字符的贡献。 由于他们占据了最后一个`k`头寸，其指数固定为`n+1`到`n+k`，所以他们的总贡献是对这些位置的简单算术评估。 
5. 将原始贡献和插入的贡献相加以获得答案。 

### 为什么它有效

 值函数在位置上是线性的，插入仅影响通过位置移动的排序。 任何较早放置的插入字符都会减少其自身的权重乘数，并将原始字符推到更高的位置，但这些原始贡献已经按相对顺序固定。 由于插入的字符始终可以向右移动，而不会损害任何其他插入字符的贡献，因此最佳排列总是将所有插入推到末尾。 一旦建立，每次插入都是独立的，并且应使用最大可用字母粗细。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    k = int(input())
    w = list(map(int, input().split()))
    
    n = len(s)
    
    # original contribution
    base = 0
    for i, ch in enumerate(s, start=1):
        base += i * w[ord(ch) - ord('a')]
    
    mx = max(w)
    
    # inserted letters occupy positions n+1 ... n+k
    # all are best letter
    for i in range(1, k + 1):
        base += (n + i) * mx
    
    print(base)

if __name__ == "__main__":
    solve()
```该代码将原始字符串贡献与插入的字母分开。 原始循环直接应用评分函数的定义。 然后，我们通过选择最大权重字母并将其放在最后一个来计算最佳可能的插入贡献`k`位置，其指数是准确已知的。 

一个常见的错误是尝试逐步模拟插入字符串，这会导致不必要的复杂性和索引移位中的逐一错误。 该解决方案通过直接推理最终位置来避免所有移动。

 ## 边缘情况

 一个关键的边缘情况是当`k = 0`。 该算法必须跳过所有插入逻辑，只计算原始分数。 该实现自然会处理这个问题，因为插入循环运行零次，只留下基本贡献。 

另一种情况是所有权重都相等。 任何插入选择都变得等效，因此算法仍然通过选择任何最大权重字母来选择有效的最佳策略。 计算仍然正确，因为无论字母选择如何，所有插入的贡献都是相同的。 

当字符串长度为 1 且`k`很大时，插入的贡献占主导地位。 该算法正确地将所有插入放置在位置 2 到`k+1`，确保每个额外的角色贡献的乘数不断增加，这正是线性评分下的最优排列。
