 ## 解决方案
 ## 问题理解

 我们有一个带有半径的大圆桌`R`并想要放置`n`相同的圆板，每个圆板都有半径`r`。 

每块板必须同时满足三个条件。 

首先，整个盘子必须留在桌子内。 

其次，每个盘子必须接触桌子的边界。 

第三，尽管允许接触，但两块板不能重叠。 

任务只是确定这样的安排是否存在。 

限制很小。 所有值最多为 1000，并且只有一个测试用例。 这立即告诉我们挑战不在于优化，而在于推导正确的几何条件。 从恒定时间到二次时间的任何算法都可以轻松地满足限制。 真正的困难是避免不正确的几何推理并干净地处理极端情况。 

最危险的边缘情况来自较小的值`n`。 

考虑这个输入：```
1 5 10
```正确答案是：```
NO
```桌子内必须仍能容纳一块盘子。 由于板半径超过工作台半径，因此无法放置。 仅检查板之间间距的粗心解决方案可能会错误地接受这种情况，因为没有其他板可以碰撞。 

现在看：```
2 4 2
```正确答案是：```
YES
```每块板都有直径`4`，等于工作台半径。 两块板可以彼此相对放置并恰好在一个点接触。 使用严格不等式而不是非严格不等式的实现通常会拒绝这种有效的配置。 

最棘手的情况是：```
2 2 1
```正确答案是：```
YES
```两块板的中心位于半径为1的圆上`R - r = 1`。 该圆上的相对点是距离`2`分开，完全等于`2r`，因此板接触但不重叠。 

另一个微妙的情况是：```
3 2 1
```正确答案是：```
NO
```许多错误的解决方案只检查是否`2r <= R`，这里也是如此。 但是三个单位圆不能全部接触半径为 2 的表的边界而不重叠。 

## 方法

 思考这个问题的强力方法是想象将板中心放置在半径圆上`R - r`，因为接触桌子边界的每个板都会迫使其中心与桌子中心保持同样的距离。 

如果我们尝试所有角度排列`n`围绕这个圆的点并检查板之间的成对距离，当存在一个有效的排列时，我们最终会找到一个有效的排列。 这在概念上是正确的，因为几何形状完全由中心位置决定。 

问题是连续几何有无限多种配置。 即使足够精细地离散角度仍然是尴尬和不必要的。 约束很小，但数值搜索在这里是错误的工具，因为结构是高度对称的。 

关键的观察结果是，最好的排列总是在桌子周围均匀分布。 

各板中心位于同一半径圆上`R - r`。 如果我们均匀分布中心，则相邻中心形成相等的角度`2π / n`。 相邻中心之间的距离成为弦长：$$2(R-r)\sin\left(\frac{\pi}{n}\right)$$为了使板不重叠，该距离必须至少为`2r`。 

所以我们需要：$$2(R-r)\sin\left(\frac{\pi}{n}\right) \ge 2r$$这简化为：$$(R-r)\sin\left(\frac{\pi}{n}\right) \ge r$$有一种更干净的方法可以完全避免三角学。 

什么时候`n >= 2`，板可以适合当且仅当：$$R \ge 2r$$另外圆周布置有足够的空间。 Codeforces 编辑解决方案通常导出等效条件：$$n \cdot r \le R$$仅适用于特殊的几何解释，但这在这里是不正确的。 
正确的标准差是：
 对于`n = 1`，我们只需要`r <= R`。 

为了`n = 2`, 两个板适合 iff`2r <= R`。 

为了`n >= 3`，均匀分布的中心形成正多边形，确切的条件变为：$$\sin\left(\frac{\pi}{n}\right) \ge \frac{r}{R-r}$$使用直接几何是最安全的方法。

 | ---| ---| ---| ---|
 | 蛮力 | 无限/不切实际| O(1) | O(1) | 太慢了 |
 | 最佳几何形状 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`,`R`， 和`r`。 
2、办理案件`n == 1`。 

一块板只需在接触边界时安装在桌子内部即可。 这正是可能发生的时候`r <= R`。 
3、办理案件`n == 2`。 

两个板的中心必须位于半径圆的相对两侧`R-r`。 它们之间的最大距离是直径：$$2(R-r)$$板避免重叠当且仅当这至少是`2r`。 

这简化为：$$R \ge 2r$$4、办理案件`n >= 3`。 

将中心均匀地放置在半径圆周围`R-r`。 

相邻中心之间的夹角为：$$\frac{2\pi}{n}$$邻居之间的弦长为：$$2(R-r)\sin\left(\frac{\pi}{n}\right)$$如果该距离至少为，则板适合`2r`。 
5. 打印`"YES"`如果不等式成立，否则打印`"NO"`。 

### 为什么它有效

 每个有效的板中心必须恰好位于半径圆上`R-r`，因为盘子内部接触到桌子边界。 

在所有的安排当中`n`圆上的点，正多边形使相邻点之间的最小距离最大化。 如果即使是最佳的对称排列也会导致重叠，那么任何不规则的排列都无法做得更好。 

该算法准确地检查此最佳配置。 距离条件保证相邻板不相交，这会自动保证所有对不重叠，因为相邻对是最近的。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n, R, r = map(int, input().split())

    if n == 1:
        print("YES" if r <= R else "NO")
        return

    if R < 2 * r:
        print("NO")
        return

    if n == 2:
        print("YES")
        return

    lhs = (R - r) * math.sin(math.pi / n)

    eps = 1e-12

    if lhs + eps >= r:
        print("YES")
    else:
        print("NO")

solve()
```第一个分支单独处理单例情况，因为当只有一个板时，几何形状会完全改变。 许多错误的提交忘记了这一点并错误地应用了多板公式。 

下一次检查会尽早消除不可能的配置。 如果`R < 2r`，即使是两个相对的板也无法安装。 

为了`n >= 3`，该实现直接评估从正多边形排列导出的几何不等式。 浮点精度很重要，因为有效的情况可能涉及完全相等。 epsilon 避免由于微小的舍入误差而拒绝配置。 

表达式：```
(R - r) * math.sin(math.pi / n)
```来自弦长不等式减半。 这使得算术稍微干净一些，并避免了不必要的乘以 2。

import io
import math

def run(inp: str) -> str:

 ## 边缘情况

 考虑输入：```
1 3 4
```算法立即进入`n == 1`分支。 自从`r > R`，即使在考虑边界接触之前，板也无法放入桌子内。 输出变为：```
NO
```这种情况很重要，因为当只有一个板时，一般的多板几何公式并不完全适用。 

现在检查：```
2 2 1
```该算法跳过单例分支。 自从`R = 2r`，早期的不可能性测试完全平等地通过。 因为`n == 2`，算法打印：```
YES
```两块板彼此相对并在一点接触。 严格的比较会错误地拒绝这种有效的安排。 

最后，考虑：```
3 2 1
```计算变为：$$(R-r)\sin(\pi/3)=1 \times 0.8660$$由于该值小于`r = 1`，相邻的板块会重叠。 该算法正确打印：```
NO
```这个案例证明了为什么只检查`R >= 2r`一旦板片数量超过两块就不够了。
