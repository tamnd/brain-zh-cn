 ## 问题理解

 我们给出了一个起始字符串`s`和一个目标字符串`t`。 唯一允许的操作`s`是删除当前占据奇数位置的所有字符或当前占据偶数位置的所有字符。 该操作可以重复任意多次，问题是是否存在某些改变的操作顺序`s`准确地进入`t`。 

关键的困难在于每次删除后位置都是基于当前字符串的。 最初位于一个位置的角色稍后可能会移动到不同的位置，因此模拟随机删除选择很快就会产生误导。 解决方案来自于理解字符串在重复分割后可以有什么形式。 

所有输入字符串的总长度最多为`2 * 10^5`。 这意味着算法必须接近线性。 比较每个可能的删除序列或每个可能的子序列的二次方法将在`4 * 10^10`最坏情况下的操作，这远远超出了典型的一秒限制所允许的范围。 

重要的边缘情况来自长度变化以及单个删除操作不允许任意子序列的事实。 例如，如果输入是：```
abcdefg
cde
```答案是：```
NO
```粗心的解决方案可能会认为可以生成任何子字符串或子序列，但在一次操作之后，可能的字符串仅是`aceg`或者`bdf`。 人物`cde`永远不会一起出现。 

另一种边缘情况是当目标已经等于原始字符串时：```
baccba
baccba
```正确的输出是：```
YES
```因为允许零操作。 始终执行至少一次删除的实现将错误地拒绝这种情况。 

最后一个棘手的情况是目标比源长：```
nick
james
```输出是：```
NO
```每个操作只保留字符串的一部分，因此长度永远不会增加。 任何只检查角色关系但忘记此限制的解决方案都可能会失败。 

## 方法

 一种简单的方法是生成可到达的每个字符串`s`。 由于每个操作都会选择当前位置的两半之一，因此对状态的广度优先搜索最终会发现是否`t`出现。 这是正确的，因为它准确地探索了可能的转换。 

问题是国家数量增长太快。 长度为一串`n`可以重复地分割成更小的字符串，并在每个级别尝试这两种选择，从而创建一个指数搜索树。 尽管许多分支可能会合并，但存储和比较所有生成的字符串对于接近的长度来说过于昂贵`2 * 10^5`。 

消除模拟需要的观察是查看所有可达字符串的结构。 每个操作都保留具有一个索引奇偶校验的字符。 如果我们查看原始索引，在一次操作之后，我们会保留所有索引具有相同的奇偶校验。 在另一次操作之后，我们再次获取已过滤序列的所有其他字符。 这意味着其余字符始终对应于原始字符串中遵循规则模式的位置。 

更准确地说，每个可达字符串都是通过选择某个起始位置并以固定步长（2 的幂）重复获取字符来获得的。 然而，由于每次操作都会将当前序列减半，因此在目标长度之前存活的唯一可能性是通过重复选择两个奇偶校验组之一来确定的。 

重要的结果是，如果目标长度是`m`，那么唯一可能的第一个操作是产生至少长度的字符串`m`，并且在继续该过程之后，目标必须显示为由这些奇偶校验选择创建的最终子序列。 通过观察分裂的二元性质可以更直接地检查这一点。 

查看过程的一个有用方法是从目标向后看。 If a string`x`可以成为`y`一次操作后，则`y`必须是以下字符之一`x`在职位`0,2,4,...`或位置处的字符`1,3,5,...`。 颠倒这一关系意味着每一个有效的变换链都对应于重复选择一个奇偶校验组，直到剩余长度恰好变成目标长度。 

由于每次分割都会将长度大约减少一半，因此可能的深度数量很小。 最终算法只需要遵循可能的奇偶校验选择，而不是探索所有字符串。

 ## 算法演练

 1.如果目标字符串比原字符串长，则立即回答`NO`。 每个操作都会删除字符，因此增加长度是不可能的。 
2. 检查当前字符串中每隔一个字符重复取出是否可以得到目标。 不要模拟所有可能的分支，而是递归地考虑当前字符串的两个可能的子字符串：偶数索引中的字符和奇数索引中的字符。 
3. 当当前字符串长度等于目标长度时停止递归。 此时，唯一有效的结果是精确的字符串相等性检查。 
4. 记住已经检查过的字符串。 通过不同的操作序列可以达到相同的中间字符串，并且存储失败状态可以防止重复工作。 
5、输出`YES`如果任意奇偶校验选择序列达到目标，否则输出`NO`。 

这样做的原因是，每个合法操作都有两个结果：保持当前头寸的平价。 递归会检查这两个结果，因此它不会错过有效的序列。 记忆仅删除对相同状态的重复检查，并且不会更改正在考虑的可达字符串集。
