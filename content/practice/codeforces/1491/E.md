 ## 解决方案
 ## 问题理解

 我们有一棵树$n$顶点，我们想要确定它是否是斐波那契树。 斐波那契树是一棵大小等于某个斐波那契数的树$F_k$，并且它要么由单个顶点组成，要么可以通过仅删除一条边来分成两个较小的斐波那契树。 换句话说，如果一棵树可以沿着边递归地分解为大小为连续斐波那契数的子树，那么它就是斐波那契树。 

输入给出$n$和名单$n-1$形成树的边。 输出是简单的“是”或“否”，具体取决于树是否满足 Fib 树属性。 第一步是认识到树的大小本身必须是斐波那契数，否则我们可以立即返回“NO”。 

和$n$最多$2 \cdot 10^5$以及1秒的时间限制，我们无法承担时间复杂度的解决方案$O(n^2)$。 这排除了为每个子树天真地考虑所有可能的边缘去除的方法。 我们需要更接近的东西$O(n \log n)$或者$O(n \sqrt n)$最坏的情况是。 

不明显的边缘情况包括已经是 Fib 树的小树，例如单个节点或两个节点。 当有多种方法来分割树时，会出现另一种微妙的情况：我们必须确保至少一条边允许有效的斐波那契分解。 如果算法假设特定的分割顺序而不检查所有可能性，则它可能错误地返回“NO”。 例如，大小树$3$有边缘$1-2$和$2-3$是一棵斐波那契树，但粗心的方法可能只检查一个分裂而错过有效的分解。 

## 方法

 暴力方法会尝试每条边，将其删除，然后检查生成的两个子树是否是斐波那契树。 这是正确的，因为 Fib 树属性是递归的：如果删除任何边所产生的两个子树是 Fib 树，则整个树是 Fib 树。 然而，这种方法太慢了。 有$n-1$边，对于每条边，我们需要计算子树大小并递归检查每个子树。 在最坏的情况下，这会导致$O(n^2)$操作，这是不可接受的$n = 2 \cdot 10^5$。 

关键的观察结果是，在大小为 Fib 的 Fib 树中$F_k$，去掉右边形成的两棵子树必须有大小$F_{k-1}$和$F_{k-2}$（前两个斐波那契数）。 这种见解将问题简化为有效地找到子树大小与连续斐波那契数匹配的边。 使用深度优先搜索（DFS），我们可以计算以任何节点为根的每个子树的大小。 当我们找到一个大小等于的子树时$F_{k-1}$或者$F_{k-2}$，删除相应的边可以适当地分割树。 然后我们递归地将相同的过程应用于每个子树。 

另一个关键的优化是记住斐波那契数及其索引，以便我们可以快速确定每一步两个子树的预期大小。 分而治之的递归确保每条边在其子树的上下文中仅被考虑一次，从而使总运行时间与$O(n \log n)$。

 ## 算法演练

 1. 预先计算所有斐波那契数$2 \cdot 10^5$并存储从每个斐波那契数到其索引的映射$k$。 如果$n$不在此集合中，立即返回“NO”。 
2. 将树构建为邻接表。 初始化一个`used`数组来跟踪在递归分割中已删除的边缘。 
3. 实现 DFS 来计算每个子树的大小并存储每个节点的父边。 
4. 对于一棵大小的树$F_k$，目标是找到一条边，删除该边会将树分成大小不同的子树$F_{k-1}$和$F_{k-2}$。 在DFS中，如果子树的大小恰好$F_{k-1}$或者$F_{k-2}$，将相应的边标记为切割并在两个结果子树上递归。 
5. 当子树的大小为 1 时，递归终止，该子树通常是 Fib 树。 
6. 如果在任何步骤都找不到将树分成两个斐波那契大小的子树的边，则返回“NO”。 

工作原理：该算法保留了每次递归调用时子树大小是斐波那契数的不变量。 通过搜索大小为的子树$F_{k-1}$或者$F_{k-2}$，我们保证生成的两个子树对应于连续的斐波那契数，这正是斐波那契树所需的属性。 DFS 确保有效检查每条边，而递归则确保该属性适用于所有子树。 

## Python 解决方案```python
import sys
sys.setrecursionlimit(1 << 25)
input = sys.stdin.readline

def main():
    n = int(input())
    edges = [[] for _ in range(n)]
    for _ in range(n-1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges[u].append(v)
        edges[v].append(u)
    
    # Precompute Fibonacci numbers up to 2*10^5
    fib = [1, 1]
    fib_idx = {1:1}
    while fib[-1] < 2*10**5:
        fib.append(fib[-1]+fib[-2])
        fib_idx[fib[-1]] = len(fib)-1
    
    if n not in fib_idx:
        print("NO")
        return
    
    used = [False]*n
    
    def solve(u, size):
        if size == 1:
            return True
        k = fib_idx[size]
        target1, target2 = fib[k-1], fib[k-2]
        
        parent = [-1]*n
        sz = [0]*n
        found = [None]
        
        def dfs(v, p):
            sz[v] = 1
            parent[v] = p
            for to in edges[v]:
                if to == p or used[to]:
                    continue
                dfs(to, v)
                sz[v] += sz[to]
            if sz[v] == target1 or sz[v] == target2:
                found[0] = (v, parent[v])
        
        dfs(u, -1)
        
        if found[0] is None:
            return False
        
        x, y = found[0]
        used[x] = True
        used[y] = True
        return solve(x, sz[x]) and solve(y, size - sz[x])
    
    if solve(0, n):
        print("YES")
    else:
        print("NO")

main()
```该代码首先预先计算斐波那契数并将其映射到索引。 这`used`数组标记了先前分割的节点，有效地切割树而无需物理删除边缘。 DFS 计算子树大小并识别要分割的有效边。 递归调用继续，直到到达大小为 1 的子树。 微妙之处包括标记边缘的两端以防止重新访问，处理子树恰好是的情况`target1`或者`target2`，以及递归终止条件。
