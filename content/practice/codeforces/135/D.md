 ## 解决方案
 ## 问题理解

 我们得到了一个二进制网格。 细胞含有`'1'`形成可用的瓷砖，同时`'0'`细胞被阻塞。 

我们希望最长的周期完全由`'1'`细胞。 该循环的行为必须类似于网格上的简单闭合曲线。 循环上的每个单元必须恰好与相邻的其他两个循环单元接触，因此形状不能分支或自相交。 

还有一个条件，这是棘手的部分。 每一个`'1'`不在循环上的单元必须位于封闭区域之外。 换句话说，循环不允许包围任何额外的`'1'`细胞。 

答案是属于该循环的最大细胞数。 

网格可以大到`1000 x 1000`，这意味着最多一百万个细胞。 任何尝试所有子集、所有简单循环、甚至对每个单元执行昂贵的图形操作的算法都将立即失败。 我们需要非常接近线性时间的东西。 

第一个重要的观察结果是，有效的冷却循环实际上是以下连接组件的边界：`'1'`细胞没有孔。 每个边界单元在组件内部的度数正好为 2，并且组件不能包含内部`'1'`细胞与边界条件断开。 

粗心的实现通常会在带有分支或孔的形状上失败。 

考虑这个网格：```
111
111
111
```外圈看起来像一个长度的循环`8`，但中心单元也是`'1'`并且严格位于循环内部。 正确答案是`0`。 

另一个危险的情况是带有尾部的组件：```
1110
1011
1110
```左边`3x3`环是一个有效的循环，但右侧附加的额外单元格破坏了循环顶点之一的度数条件。 简单的周长计算解决方案会错误地报告`8`。 

断开连接的组件也很重要：```
1110111
1010101
1110111
```有两个不同长度的周期`8`。 我们必须返回最大值，而不是总和。 

最后，细长的走廊可以创建自接触结构：```
1111
1001
1111
```这是有效的，因为每个循环单元在循环中仍然恰好有两个邻居，并且没有`'1'`细胞被困在里面。 

## 方法

 蛮力的想法是将网格视为图表并枚举所有简单的循环。 对于每个循环，我们可以验证每个循环顶点是否具有二度以及所有其他顶点是否具有二度`'1'`细胞位于外面。 

这在概念上是有效的，因为定义是局部的加上包含条件。 不幸的是，网格图中简单循环的数量是指数级的。 甚至一个`20 x 20`网格已经包含太多的循环而无法枚举。 

因此，我们需要了解冷循环在结构上到底是什么样的。 

假设我们取一个连通分量`'1'`细胞。 如果该组件中的每个单元在该组件内的度数恰好为 2，则该组件形成一个简单循环。 所有顶点的度数均为 2 的连通图恰好是一个循环。 

现在考虑“没有内部`'1'`cells”条件。如果组件本身就是一个简单的循环，那么就没有额外的`'1'`它里面的细胞，因为每个`'1'`组件的单元已经属于循环。 任何被困的`'1'`单元必然属于同一个连接组件，并且会强制某些顶点度数超过 2。 

这彻底改变了问题。 我们不再需要几何推理或内外测试。 

我们只需要找到以下的连通分量`'1'`每个顶点的度数恰好为 2 的单元格。 

一旦我们看到这种等价性，解决方案就变成了网格上简单的图遍历问题。 

我们扫描网格，对每个未访问的网格运行 DFS 或 BFS`'1'`组件，计算其大小，并验证内部的每个单元恰好有两个相邻的单元`'1'`细胞。 

如果条件适用于整个组件，则该组件是一个简单循环，其大小是候选答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力循环枚举| 指数| 指数| 太慢了|
 | 带度数检查的连接组件 | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1. 读取网格并维护一个访问过的数组。 
2. 迭代网格中的每个单元格。 
3.每当我们遇到未曾拜访过的人时`'1'`单元格，从中启动 DFS 或 BFS 来探索其连接的组件。 
4. 遍历时，统计组件中的单元格数量。 
5. 对于每个访问过的单元格，计算有多少个相邻单元格也包含`'1'`。 只有四个基本方向很重要。 
6. 如果组件中的任何单元格的邻居计数不同于`2`，将组件标记为无效。 
7. 遍历结束后，检查有效性标志。 
8. 如果整个组件有效，则用组件大小更新答案。 
9. 继续，直到处理完所有细胞。 

### 为什么它有效

 在连通分量内部，每个单元的度数正好为 2，这意味着分量图是一个循环。 网格邻接产生一个简单的无向图，并且所有顶点都具有二度的每个连通图都是单个循环。 

组件本身包含所有可达的`'1'`细胞。 由于每个细胞都属于循环，因此不可能存在另一个细胞`'1'`细胞被困在里面。 这符合冷循环的定义。 

相反，每个冷却循环形成一个连接组件，其中每个顶点的度数恰好为 2。 因此，该算法完全接受有效循环并拒绝其他所有循环。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    visited = [[False] * m for _ in range(n)]

    directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

    ans = 0

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '1' and not visited[i][j]:
                q = deque()
                q.append((i, j))
                visited[i][j] = True

                size = 0
                ok = True

                while q:
                    x, y = q.popleft()
                    size += 1

                    deg = 0

                    for dx, dy in directions:
                        nx = x + dx
                        ny = y + dy

                        if 0 <= nx < n and 0 <= ny < m:
                            if grid[nx][ny] == '1':
                                deg += 1

                                if not visited[nx][ny]:
                                    visited[nx][ny] = True
                                    q.append((nx, ny))

                    if deg != 2:
                        ok = False

                if ok:
                    ans = max(ans, size)

    print(ans)

if __name__ == "__main__":
    solve()
```遍历将网格视为无向图。 每个`'1'`单元是一个顶点，边邻接创建边。 

微妙的部分是度数计算。 我们直接从网格中计算邻居，而不是从遍历树中。 DFS 树边计数可能是错误的，因为循环包含后边。 

另一个重要的细节是我们验证整个连接的组件，而不仅仅是检测到的循环片段。 假设一个循环附加了一个额外的分支。 分支上的某些单元可能仍具有局部二级，但附着点将具有三级，因此必须整体拒绝该组件。 

该解决方案使用 BFS 和队列，但 DFS 也同样可以工作。 BFS 避免了非常大的网格上的 Python 递归深度问题。 

访问的数组保证每个单元格只处理一次，从而保持复杂性线性。

 ## 边缘情况

 考虑完全填充的正方形：```
3 3
111
111
111
```中心单元的阶数为四。 在 BFS 期间，算法直接从网格计算邻居计数，因此该组件立即被标记为无效。 最终的答案是`0`。 

现在考虑一个带有尾部的组件：```
3 4
1110
1011
1110
```单独的左环将形成一个有效的循环，但额外的单元附加到一个边界顶点。 该附着顶点的度数为三。 由于整个连接组件被一起处理，因此组件验证失败并且算法输出`0`。 

断开的循环是独立处理的：```
3 7
1110111
1010101
1110111
```BFS 从左侧组件开始，恰好访问了 8 个单元，所有单元的度数均为 2。 正确的组件的行为方式相同。 该算法保持最大组件大小和输出`8`。 

最后，考虑最小可能的非平凡循环：```
2 2
11
11
```每个单元格恰好有两个邻居。 该组件已连接且大小为四，因此算法正确输出`4`。
