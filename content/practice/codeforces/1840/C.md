 ## 解决方案
 ## 问题理解

 该问题要求我们计算在天气限制的情况下迪玛可以选择在滑雪场连续度假的有多少种方式。 我们得到一个表示每日温度的整数数组和两个数字：假期的最短长度$k$和最高温度$q$迪马可以容忍。 有效的假期期间是一个连续的子数组，其中所有温度最多为$q$它的长度至少是$k$。 任务是计算每个测试用例的有效假期总数。 

输入约束表明所有测试用例的总天数不超过$2 \cdot 10^5$。 这排除了任何天真地检查每个可能的子数组的解决方案，因为枚举大数组的所有子数组可能需要$O(n^2)$操作，这对于$n$最多$2 \cdot 10^5$。 

要考虑的边缘情况包括所有温度都高于$q$，所以不可能有假期，或者在哪里$k = 1$所有温度都是有效的，这意味着每天和每个连续的子数组都有贡献。 粗心的方法可能会尝试通过强力对子数组进行计数，并且会超出时间限制或在温度超过时错误处理有效子数组的边界$q$。 

## 方法

 蛮力方法将迭代每个开始日和每个可能的结束日，检查它们之间的温度是否不会超过$q$长度至少为$k$。 这是正确的，但需要$O(n^2)$每个测试用例的操作，这对于最大的输入是不可接受的。 

允许更快的方法的关键观察是，温度最高的任何连续天序列$q$可以被视为一个块。 在这个长度块内$len$，每个连续子数组的长度至少$k$是有效的。 可以使用一个简单的公式直接计算此类子数组的数量：对于长度的块$len \ge k$， 有$(len - k + 1) + (len - k) + \dots + 1 = (len - k + 1)(len - k + 2)/2$有效的子数组。 如果$len < k$，没有有效的子数组。 这将问题减少到扫描一次数组并对每个有效块的计数求和。 

这种方法自然会导致$O(n)$每个测试用例的算法，因为我们只遍历数组一次并为每个有效温度块计算一个简单的算术公式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化一个计数器来跟踪有效假期的数量。 初始化一个变量`length`跟踪温度不超过的连续天的当前块`q`。 
2. 迭代数组中的每个温度。 如果当天的温度最高为`q`, 增量`length`扩展当前块。 
3. 如果当天气温超过`q`，计算当前块中有效子数组的数量。 仅长度至少为的块`k`贡献。 使用公式$(length - k + 1) + (length - k) + \dots + 1 = (length - k + 1) \cdot (length - k + 2) / 2$。 重置`length`为零以开始一个新块。 
4. 循环后，如果数组以有效序列结尾，则处理最后一个块。 
5. 返回有效子数组的总数。 

工作原理：满足最大温度约束的每个连续温度块都可以独立计数。 在每个块内，长度至少为有效的子数组的数量`k`无需枚举即可精确计算。 不变量是在任意点，`length`表示以当前索引结束的连续有效天数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def count_vacations(n, k, q, a):
    count = 0
    length = 0
    for temp in a:
        if temp <= q:
            length += 1
        else:
            if length >= k:
                count += (length - k + 1) * (length - k + 2) // 2
            length = 0
    if length >= k:
        count += (length - k + 1) * (length - k + 2) // 2
    return count

t = int(input())
for _ in range(t):
    n, k, q = map(int, input().split())
    a = list(map(int, input().split()))
    print(count_vacations(n, k, q, a))
```该解决方案使用快速 I/O 读取输入，以处理最多$10^4$有效地测试用例。 功能`count_vacations`跟踪有效天数的块并计算每个块的子数组数量。 关键的实现细节是处理循环结束后的最后一个块，这很容易被忘记。
