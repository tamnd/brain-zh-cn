 ## 解决方案
 ## 问题理解

 我们得到一个由字母和数字组成的字符串，并要求我们为每个前缀计算一个特殊的度量，称为_回文度_。 如果字符串是回文且其前半部分和后半部分长度，则该字符串具有回文度 _k_`len(s) // 2`每个都有度_k-1_。 根据定义，如果我们认为任何字符串为空，则其度数为 0。 我们的目标是对输入字符串的所有前缀的回文度进行求和。 

由于字符串最多可以有 5·10⁶ 个字符，因此独立检查每个前缀并递归检查其一半的简单方法会太慢。 任何在 O(n²) 时间内运行的算法都是不可行的，因为 5·10⁶ 的平方是 25·10^2 运算，远远超出了时间限制。 因此，我们需要一种运行时间接近线性时间的算法，最好是 O(n)。 

当字符串具有重复模式或非常短时，就会出现不明显的边缘情况。 例如，单字符字符串“a”的度数为 1，但像“aa”这样的两字符字符串的度数为 2，因为长度为 1 的前缀和后缀的度数均为 1。如果我们无法从较小的回文中正确传播度数，则可能会漏算。 

当前缀是回文但其半部分不是回文时，会发生另一种微妙的情况，例如“abba”。 它的完整字符串是回文，但前缀“ab”和后缀“ba”不是1次回文，所以“abba”的次数是1，而不是2。 

## 方法

 暴力解决方案将迭代字符串的每个前缀，检查它是否是回文，然后通过检查其左半部分和右半部分递归地计算度数。 这在原则上是可行的，但对于大字符串来说变得不切实际。 对于长度为 n 的字符串，暴力方法可能需要每个前缀进行大约 n²/2 次比较，如果我们包括度传播，则总操作数为 O(n³)。 对于 n = 5·10⁶ 来说，这显然太慢了。 

关键的见解是认识到可以使用_前缀数组_来增量计算回文度数。 如果我们有效地预先计算哪些前缀是回文，我们可以一次性构建度数组。 为此，我们使用 Z 算法或滚动哈希技术，但更简单的方法利用了字符串的回文属性本质上递归的事实：字符串的度数直接取决于其一半的度数。 具体来说，如果长度L的前缀是回文，我们可以检查它的前半部分（长度L//2）的度数并加1。如果我们维护一个数组`deg[i]`对于以索引 i 结尾的前缀的回文度，我们可以计算`deg[i]`作为`deg[i//2] + 1`如果前缀是回文，否则为 0。 

为了有效地检查前缀是否是回文，我们可以使用散列。 我们从左到右计算滚动哈希，从右到左计算反向滚动哈希。 如果这两个哈希值与给定前缀匹配，则它是回文。 这为每个前缀提供了 O(n) 回文检查，并且通过适当的预计算为所有前缀提供了 O(n) 总数。

 ## 算法演练

 1. 计算字符串的前滚哈希数组。 每个前缀的哈希允许使用预先计算的幂数组以恒定时间检索任何子字符串哈希。 这确保我们可以快速将前缀与其镜像后缀进行比较。 
2. 类似地计算反向滚动哈希数组。 这镜像了字符串，让我们可以将前缀与其相应的后缀进行比较，而无需物理反转子字符串。 
3.初始化一个数组`deg`长度为 n 的用于存储每个前缀的回文度。 
4. 迭代以位置 i 结尾的每个前缀。 使用哈希数组检查子字符串是否`s[0..i]`是一个回文。 如果不是，请设置`deg[i] = 0`。 
5. 如果前缀是回文，则使用以下公式计算其度数`deg[i] = deg[i//2] + 1`。 这里，`i//2`对应最大的前缀，其程度决定下一级。 加 1 传播回文度的递归定义。 
6. 总和`deg[i]`值即可得到最终答案。 

工作原理：正向和反向哈希保证每个前缀的回文检测正确。 递归传播自`deg[i//2]`确保每个前缀的度数正确地考虑了其一半的度数。 这保持了不变量`deg[i]`正是最大的 k 使得以 i 结尾的前缀是 k 回文。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
BASE = 31

s = input().strip()
n = len(s)

pow_base = [1] * (n + 1)
for i in range(1, n + 1):
    pow_base[i] = (pow_base[i-1] * BASE) % MOD

hash_forward = [0] * (n + 1)
hash_reverse = [0] * (n + 1)

for i in range(n):
    hash_forward[i+1] = (hash_forward[i] * BASE + ord(s[i])) % MOD
    hash_reverse[i+1] = (hash_reverse[i] * BASE + ord(s[n-1-i])) % MOD

def get_hash(h, l, r):
    return (h[r+1] - h[l] * pow_base[r-l+1]) % MOD

deg = [0] * n
ans = 0

for i in range(n):
    if get_hash(hash_forward, 0, i) == get_hash(hash_reverse, n-i-1, n-1):
        deg[i] = (deg[i//2] + 1) if i > 0 else 1
    else:
        deg[i] = 0
    ans += deg[i]

print(ans)
```该代码首先预先计算哈希基对大素数取模的幂。 存储正向和反向哈希值以启用恒定时间回文检查。 主循环迭代每个前缀，使用哈希比较检查回文属性，然后通过递归计算度数`deg[i//2]`。 将所有度数相加即可得出答案。 通过对子字符串散列一致使用基于 0 的索引，可以小心地避免差一错误。
