 ## 解决方案
 ## 问题理解

 我们在数轴上得到一组线段，每个线段由左端点和右端点定义。 任务是选择具有特定属性的这些线段的最大可能子集：对于子集中的任何两个线段，它们必须完全不相交，这意味着它们根本不共享任何点，或者一个必须完全包含在另一个线段内。 不允许非包容性的部分重叠。 输入包含多个独立的测试用例，每个测试用例都有自己的一组段。 

约束告诉我们，所有测试用例的段总数不超过 3000。这个值足够小，每个测​​试用例的段数具有二次时间的算法是可行的，因为$3000^2$操作完全符合 3 秒的限制。 然而，尝试枚举所有子集的简单方法将是指数级的并且完全不可行。 

当段共享端点但彼此不严格包含时，就会出现一种微妙的边缘情况。 例如，线段 [1,2] 和 [2,3] 在一点处接触，因此它们被视为相交并且不能包含在一起，除非一个严格包含在另一个中。 另一种边缘情况是长度为 1 的嵌套段，例如 [1,3] 内的 [2,2]。 将端点重叠视为非交叉点的粗心解决方案会错误地包括这两个线段。 

## 方法

 暴力方法是尝试线段的所有子集并检查每个子集是否满足非相交或包含条件。 检查一个子集需要比较其中的所有段对，给出一个$O(n^3)$单个测试用例的解决方案$n$段。 这对于$n$最多 3000 个。 

为了优化，我们观察到该问题具有自然结构：段可以排序和嵌套。 按左端点对段进行排序，并通过减少右端点来打破联系，可以保证对于任何段，可以嵌套在其中的潜在段会稍后出现在列表中。 这自然表明了一种动态规划方法，其中`dp[i]`是以第 i 个段结束的最大有效子集的大小。 填补`dp[i]`，我们考虑所有之前的片段`j < i`并检查是否段`i`可以添加到以`j`。 部分`i`如果完全在里面可以添加`j`或完全脱离`j`。 可以有效地检查不相交，因为段是按左端点排序的。 

关键的见解是，排序后，包含段的决定`i`仅取决于之前开始的段`i`。 这让我们可以计算最优解$O(n^2)$一次使用简单的嵌套循环来更新 DP 表。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(n) | 太慢了|
 | 排序后的DP | O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取段数和段本身。 将每个段表示为一个元组`(l, r)`。 
2. 首先按左端点对线段进行排序`l`按升序排列，然后按右端点`r`按降序排列。 以这种方式排序可确保任何可能包含另一个片段的片段都出现在较早的位置。 
3.初始化一个DP数组`dp`尺寸的`n`， 在哪里`dp[i]`将存储以段结尾的最大有效子集的大小`i`。 全部设定`dp[i]`最初为 1，因为每个段都可以自己形成大小为 1 的子集。 
4. 按顺序迭代各个段。 对于细分市场`i`,检查所有之前的段`j < i`。 如果段`i`完全在里面`j`（IE。，`l[j] <= l[i]`和`r[i] <= r[j]`) 或与`j`（IE。，`r[j] < l[i]`）， 然后`i`可以扩展结束于的子集`j`。 更新`dp[i] = max(dp[i], dp[j] + 1)`。 
5. 填充 DP 数组后，该测试用例的最大有效子集是中的最大值`dp`。 

工作原理：按左端点排序可确保所有可以包含另一个段的段都出现在其前面，从而足以仅检查 DP 更新中的先前段。 DP 不变量是`dp[i]`始终表示以段结束的最大子集`i`满足问题的约束条件。 这保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        segments = [tuple(map(int, input().split())) for _ in range(n)]
        # sort by left ascending, then right descending
        segments.sort(key=lambda x: (x[0], -x[1]))
        dp = [1] * n
        for i in range(n):
            li, ri = segments[i]
            for j in range(i):
                lj, rj = segments[j]
                if ri <= rj or rj < li:
                    dp[i] = max(dp[i], dp[j] + 1)
        print(max(dp))

if __name__ == "__main__":
    solve()
```第一部分读取输入并组织段。 按左端点排序可确保包含检查正常工作，而右端点降序则可解决嵌套段的关系。 嵌套循环实现 DP，其中条件`ri <= rj or rj < li`完全符合包含要求：要么`i`在里面`j`或脱节。 取最大值`dp`给出每个测试用例的答案。
