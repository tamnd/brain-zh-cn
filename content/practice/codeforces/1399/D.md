 ## 解决方案
 ## 问题理解

 给定一个二进制字符串，我们希望将其分成几个子序列，以便每个字符仅使用一次，并且每个子序列在`0`和`1`。 换句话说，在任何选定的子序列内，两个相邻的选定字符不能相等。 

我们不允许对子序列中的字符进行重新排序，只能从原始字符串中删除字符来形成子序列。 每个原始位置必须恰好分配给一个子序列，并且我们希望最小化所需的子序列数量。 

输出不仅是子序列的最小数量，而且是将字符串中的每个位置分配给这些子序列之一。 

所有测试用例的总长度最多为 2×10^5 的约束意味着每个测试用例的任何解决方案都应该是线性或接近线性的。 尝试贪婪地重复构建子序列的 O(n²) 构造会立即失败，因为最坏情况下单个测试用例已经达到 2×10^5。 

一种简单但有启发性的方法是逐个模拟构建子序列。 我们可以尝试扫描字符串并将每个字符放入第一个子序列中，使其不违反交替规则。 这是正确的，但维护所有子序列并检查每个字符的兼容性会在最坏的情况下导致二次行为，特别是对于像这样的字符串`000000...111111...`每次放置尝试都会失败许多现有的子序列。 

例如，一个微妙的边缘情况是所有字符都相同`000000`。 一种粗心的贪婪方法可能会尝试扩展一个子序列，然后反复失败并低效地创建新的子序列，但正确的答案很简单，每个字符必须进入一个单独的子序列，因为子序列中没有两个相同的字符可以相邻。 

另一个极端情况是交替字符串，例如`010101`。 这里单个子序列就足够了，但是一种不能正确重用子序列的简单方法可能会过度分割并产生多个子序列。 

## 方法

 关键的观察结果是，每个子序列的行为就像一条链，期望下一个字符与其最后一个字符交替。 因此每个子序列都有一个“最后一个字符状态”，决定是否可以追加新字符。 

如果我们贪婪地思考，我们希望将每个字符放入一个现有的子序列中，该子序列的最后一个字符与其不同。 在所有这些子序列中，选择任何一个都可以保证正确性，但为了最大限度地减少子序列的数量，我们应该尽可能重用现有的兼容子序列。 

蛮力的想法是维护一个子序列列表，并且对于每个字符，扫描所有子序列以找到最后一个元素不同的子序列。 在最坏的情况下，这会花费 O(n²)。 

最佳的见解是，任何时候我们只关心当前有多少个子序列以`0`有多少以`1`。 结尾为的子序列`0`可以接受一个`1`，反之亦然。 因此，我们不是单独跟踪所有子序列，而是跟踪可用的“端点”并贪婪地分配。 

我们维护两个子序列 ID 堆栈（或队列）：一个用于以 结尾的子序列`0`，以及一个以结尾的`1`。 对于每个字符，如果可能的话，我们从相反的堆栈中选择，否则我们必须创建一个新的子序列。 

这是有效的，因为任何子序列都可以与以相同字符结尾的任何其他子序列互换，以便将来扩展； 身份并不重要，只有最后一个字符才重要。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们从左到右处理字符串，将每个字符分配给一个子序列。 

1. 维护两个堆栈：一个用于最后分配的字符为的子序列`0`，以及最后分配的字符为`1`。 我们还维护一个数组来存储每个位置的分配。 
2. 对于每个位置`i`， 检查`s[i]`。 

如果是的话`0`，我们尝试重用当前以`1`。 这样的子序列可以安全地接受这个字符而不破坏交替。 如果不存在这样的子序列，我们创建一个新的子序列。 

同样的逻辑对称地适用于`1`。 
3. 当重用一个子序列时，我们从相反结尾的堆栈中删除它的id，将其分配给当前位置，然后将其推入与新的最后一个字符对应的堆栈中。 
4. 创建新的子序列时，我们增加子序列计数器并将当前位置分配给它。 然后我们将它放入与其字符对应的堆栈中。 
5. 继续，直到处理完所有字符。 

处理后，使用的最大子序列索引就是答案。 

### 为什么它有效

 关键的不变量是每个子序列总是在与其最后一个字符相对应的堆栈中精确地表示一次。 任何可以接受字符的子序列此时都存在于正确的堆栈中。 由于我们总是尽可能重用一个子序列，因此除非所有兼容的子序列都用尽，否则我们永远不会创建新的子序列。 这确保了最小性：每个新子序列都对应于现有子序列无法合法接受该字符的时刻，从而迫使最佳计数增加。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input().strip())
        s = input().strip()

        # stacks of subsequence ids ending in '0' and '1'
        end0 = []
        end1 = []

        ans = [0] * n
        k = 0

        for i, ch in enumerate(s):
            if ch == '0':
                if end1:
                    idx = end1.pop()
                    ans[i] = idx
                    end0.append(idx)
                else:
                    k += 1
                    ans[i] = k
                    end0.append(k)
            else:
                if end0:
                    idx = end0.pop()
                    ans[i] = idx
                    end1.append(idx)
                else:
                    k += 1
                    ans[i] = k
                    end1.append(k)

        print(k)
        print(*ans)

if __name__ == "__main__":
    solve()
```该代码直接反映了基于堆栈的解释。 这两个堆栈存储按最后一个字符分组的子序列 ID，允许 O(1) 选择有效的子序列（如果存在）。 

变量`k`跟踪到目前为止已经创建了多少个子序列，每次两个堆栈都无法提供有效的接收者时，我们就会分配一个新的子序列 ID。 

赋值数组`ans`记录原始字符串中每个字符的子序列索引。

 ## 边缘情况

 对于像这样的单个字符`0`，两个堆栈都是空的，因此创建一个新的子序列并分配 ID 1。该不变量成立，因为长度为 1 的子序列通常满足交替。 

对于完全交替的字符串，例如`010101`，算法总是在相反结尾的堆栈中找到兼容的子序列，因此在第一个子序列之后不会创建新的子序列。 堆栈来回交换单个子序列的所有权，以保持正确性。 

对于像这样的常量字符串`111111`， 这`end0`堆栈始终为空，强制为每个字符创建一个新的子序列。 每个子序列结束于`1`，并且没有人可以接受另一个`1`，满足每个字符必须被隔离的最佳要求。
