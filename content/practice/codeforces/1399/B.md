 ## 解决方案
 ## 问题理解

 我们被给予`n`礼物，其中每份礼物由一定数量的糖果和一定数量的橙子组成。 每份礼物`i`有`a_i`糖果和`b_i`橙子。 我们的目标是使用尽可能少的步骤，使所有礼物在糖果和橙子方面都相同。 我们可以一次性吃掉一份礼物中的一颗糖果、一个橙子，或者两者都吃掉，但我们不能删除超过礼物所包含的内容。 

输入由多个测试用例组成。 对于每个测试用例，我们都会得到礼物的数量和两个数组：一个用于糖果，一个用于橙子。 我们需要输出使所有礼物相等所需的最少步数。 

限制条件适中：`n`最多可达 50 个，每个`a_i`或者`b_i`可以大到`10^9`。 这意味着如果数字很大，我们无法单独模拟每个动作，因为那样会太慢。 相反，我们需要一种直接根据差异计算移动总数的方法。 

可能会导致简单解决方案失败的边缘情况包括：当所有礼物都具有相同数量的糖果或橙子时，或者当一件礼物与其他礼物相比具有大量糖果或橙子时。 例如，如果`a = [1, 1000000000]`和`b = [1, 1]`，一次移除一颗糖果的简单模拟是不可行的。 

## 方法

 暴力方法会尝试重复选择礼物并减少糖果和橙子，直到所有礼物都匹配。 这是正确的，但效率低下，因为每个操作都可以重复`10^9`一些礼物的时间。 和`n=50`，这可能会导致`50 * 10^9`操作，这在 1 秒内是不可能的。 

得出最佳解决方案的关键观察是，所有礼物的目标糖果数量必须至少是所有糖果中的最小值`a_i`，同样，橙子的目标数量必须至少是所有橙子中的最小值`b_i`。 将每件礼物减少到各自的最低限度始终是可行的，并且每件礼物所需的步数最少。 对于单个礼物，我们可以最佳地执行“同时进行”动作。 具体来说，对于礼物`a_i`糖果和`b_i`橙子，如果我们想把它减少到`min_a`和`min_b`，我们可以同时减少两者的次数`min(a_i - min_a, b_i - min_b)`，然后单独完成剩下的部分。 这种贪婪的方法确保了最少的移动。 

蛮力方法和最优方法的比较是：

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 最大值(a_i, b_i)) | O(n) | 太慢了|
 | 最佳| 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和数组`a`和`b`代表糖果和橙子。 
2. 计算`min_a = min(a)`和`min_b = min(b)`。 这些代表了所有礼物的糖果和橙子的目标数量。 
3. 初始化`moves = 0`。 这将累积所需的总移动次数。 
4. 迭代每件礼物`i`从 0 到`n-1`。 
5. 送礼`i`，计算多余的糖果`delta_a = a[i] - min_a`和多余的橙子`delta_b = b[i] - min_b`。 
6. 该礼物的步数为`max(delta_a, delta_b)`。 我们使用最大数量，因为我们可以尽可能同时减少糖果和橙子。 例如，如果`delta_a=3`和`delta_b=1`，一步可以减少两者，仅留下糖果 2 步，总计`max(3,1)=3`。 
7. 添加此礼物的动作`moves`。 
8.处理完所有礼物后，输出总数`moves`。 

为什么有效：不变的是我们总是将每份礼物精确地减少到最少的糖果和橙子。 通过贪婪地执行“同时进行”移动，我们永远不会执行不必​​要的单项减少。 每个礼物所需的动作都是独立的，因此将它们相加即可得出全局最小值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    min_a = min(a)
    min_b = min(b)
    
    moves = 0
    for i in range(n):
        delta_a = a[i] - min_a
        delta_b = b[i] - min_b
        moves += max(delta_a, delta_b)
    
    print(moves)
```代码首先读取测试用例的数量。 对于每个测试用例，它读取数组，计算最少的糖果和橙子，然后迭代每个礼物以使用最大差异计算最小移动。 这种方法直接实现最优算法并有效地处理非常大的数字。 的选择`max(delta_a, delta_b)`确保我们首先以最佳方式应用组合减排。
