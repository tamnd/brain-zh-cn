 ## 解决方案
 ## 问题理解

 我们得到一个仅包含以下内容的数组`1`沙`-1`s。 我们的任务是将这个数组分成连续的段，其中每个段都有一个交替和，定义为第一个元素减去第二个元素加上第三个元素减去第四个元素，依此类推。 所有段上这些交替总和的总和必须为零。 每个元素必须恰好属于一个段，因此这些段共同覆盖了整个数组。 

约束告诉我们数组长度`n`可以达到200,000，所有的总和`n`测试用例的上限为 200,000。 由于时间限制为 2 秒，因此可以排除比每个测试用例的线性复杂度更糟糕的情况。 尝试所有可能的段分区的二次方法会太慢。 

当数组长度为奇数或数组元素全部相同时，会出现不明显的边缘情况。 例如，一个数组`[1, -1, 1]`无法将其交替总和抵消为零的分段进行划分，因为任何分段都会留下无法平衡的剩余总和。 粗心的方法可能会尝试盲目地将相邻元素配对而不检查总数，从而产生不正确的分区。 单元素数组如`[1]`或者`[-1]`也是不可能的，因为没有段总和可以达到零。 长度为偶数且数量相等的数组`1`和`-1`通常很简单，但当连续元素相同时需要小心。 

## 方法

 暴力方法会尝试一切可能的方法将数组划分为段，计算每个段的交替总和，并检查总数是否为零。 原则上这是正确的，但是对于长度的数组`n`，分区的数量呈指数增长，这使得这对于`n`最多200,000。 计算每个候选分区的交替总和会增加额外的开销，因此操作计数将是天文数字。 

关键的见解是长度为 2 的交替和很容易计算：任何一对相同的元素`[x, x]`贡献`x - x = 0`，这是理想的。 不同元素对`[1, -1]`或者`[-1, 1]`贡献`1 - (-1) = 2`或者`-1 - 1 = -2`。 这意味着对于总交替和为零的情况，我们只需要考虑奇数长度数组中的对和可能的单例。 实际上，这会导致贪婪的构造：如果数组长度是偶数，我们总是可以将元素配对为长度为 2 的段。 如果数组长度是奇数并且所有元素都相同，这是不可能的。 否则，我们可以在开始时制作一个长度为 3 的线段来平衡交替和，然后将剩余元素配对。 

此观察允许线性时间解决方案：扫描数组，将元素贪婪地组合成长度为一或二的段，以确保交替和抵消，然后输出段。

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，读取数组长度`n`和数组`a`。 
3.如果`n`是奇数且所有元素都相同 (`[1,1,1,...]`或者`[-1,-1,-1,...]`）， 打印`-1`因为没有分区可以满足条件。 
4. 否则，初始化一个空列表`segments`。 
5. 如果数组总和为零，则创建单个段`[1, n]`并附加到`segments`。 这是有效的，因为具有相同数量的段的交替总和`1`和`-1`会自动取消。 
6. 如果数组长度为偶数，则以 2 为一步迭代数组，创建段`[i, i+1]`。 每个段都有交替和`0`或者`2/-2`，但配对在全球范围内保持平衡。 
7. 如果数组长度为奇数但并非所有元素都相同，则创建长度为 3 的第一个段`[1, 3]`调整交替和，然后成对迭代剩余元素`[4,5],[6,7],...`。 
8. 打印段数，然后打印段列表。 

为什么有效：可以控制小段的交替总和。 通过将元素配对，只要元素相等，我们就创建零和段。 当数组为奇数且不均匀时，单个三元素段会调整和的奇偶校验以使总和为零。 这保证了所有段的交替总和为零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # all identical elements of odd length are impossible
        if n % 2 == 1 and all(x == a[0] for x in a):
            print(-1)
            continue
        
        segments = []
        i = 0
        while i < n:
            if i + 1 < n and a[i] == a[i+1]:
                segments.append((i+1, i+2))
                i += 2
            else:
                segments.append((i+1, i+1))
                i += 1
        
        print(len(segments))
        for l, r in segments:
            print(l, r)

if __name__ == "__main__":
    solve()
```该解决方案使用有效地读取输入`sys.stdin.readline`对于大型阵列。 对相同元素的检查确保我们避免不可能的情况。 贪婪循环构造长度为一或二的段，确保覆盖每个元素。 边界条件通过检查处理`i+1 < n`在创建二元素段之前。 根据需要，段索引从 1 开始。
