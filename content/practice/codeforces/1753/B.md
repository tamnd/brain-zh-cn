 ## 解决方案
 ## 问题理解

 我们被要求确定整数数组的阶乘之和是否可以被另一个阶乘整除。 更具体地说，我们得到一个数组`[a_1, a_2, ..., a_n]`和一个数字`x`。 我们想知道是否`(a_1! + a_2! + ... + a_n!)`可以整除`x!`。 每个`a_i`保证最多是`x`，所以我们永远不必计算大于`x!`。 

关键的限制是`n`和`x`每个最多可达 500,000。 天真地计算每个元素的阶乘并对它们求和将涉及大致大小的数字`x!`，其增长速度远远快于任何数据类型的处理速度。 甚至20个！ 已经大约是 2.4×10^18，所以对于大的情况不可能进行简单的计算`x`。 这告诉我们必须进行数学推理，而不是直接计算阶乘。 

当数组中的某些元素恰好是时，就会出现一个重要的边缘情况`x`。 自从`x!`划分`x!`，任何包含的总和`x!`自动被整除`x!`如果它至少包含一个`x!`。 另一个微妙的情况是当所有`a_i`小于`x-1`。 那么总和严格小于`x!`，所以整除是不可能的。 例如，如果`x = 5`和所有`a_i ≤ 3`，总和最多为`n * 6 = 6n`，小于`5! = 120`除非`n`是巨大的。 但由于总和总是由较小的阶乘组成，因此一个干净的检查是如果有的话`a_i`正是`x`，答案总是“是”。 否则，我们必须确保所有`a_i ≥ x-1`达到可分性。 

## 方法

 蛮力方法是计算每个阶乘，对它们求和，并检查整除性`x!`。 这在原则上是正确的，但立即失败`x > 20`，因为阶乘超出了标准整数限制并且计算时间太长。 为了`n = 500,000`和`x = 500,000`，计算阶乘是完全不可行的。 

关键的观察结果是阶乘增长得非常快。 如果有的话`a_i`正是`x`,`x!`划分它，所以我们可以立即返回“Yes”。 如果所有元素都小于`x`，那么总和中最大的阶乘是`(x-1)!`。 对小于以下任意数量的阶乘求和`x!`无法达到的倍数`x!`， 因为`x!`严格大于所有的总和`(x-1)!`条款。 这将问题简化为一个简单的检查：数组中的最大元素是否等于`x`，返回“是”； 否则，返回“否”。 

这种方法避免了所有实际的阶乘计算，并且在相对于数组大小的线性时间内工作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * x) | O(1) 或 O(x) | 对于大 x 来说太慢/不可行 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取整数`n`和`x`。 
2.读取数组`a`长度`n`。 
3. 计算数组中的最大值。 这确定了总和中最大的阶乘。 
4. 如果最大值等于`x`，总和包含`x!`，所以总和可以除以`x!`。 输出“是”。 
5. 否则，总和严格小于`x!`并且不能被整除`x!`。 输出“否”。 

为什么它有效：`x!`可以被所有较小的阶乘整除，但较小的阶乘之和永远不是以下的倍数`x!`除非至少一项等于`x!`。 通过仅跟踪最大元素，我们可以有效地捕获这个不变量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, x = map(int, input().split())
    a = list(map(int, input().split()))
    
    if max(a) == x:
        print("Yes")
    else:
        print("No")

if __name__ == "__main__":
    main()
```该解决方案可以有效地读取输入并处理大型数组。 我们使用`max(a)`找到最大的元素，而不是手动迭代比较，简洁高效。 阶乘计算没有循环，避免了整数溢出。 我们也不需要存储中间阶乘，从而节省内存。 

## 工作示例

 **示例1**

 输入：```
6 4
3 2 2 2 3 3
```| 步骤| 最大(a) | 状况 | 输出|
 | --- | --- | --- | --- |
 | 读取数组| [3,2,2,2,3,3] | 最大(a)=3 | 3 != 4 → 否 |

 这里最大的元素是3，小于`x=4`。 因此`4!`不除阶乘之和。 

**示例2**

 输入：```
7 3
3 2 2 2 2 2 1
```| 步骤| 最大(a) | 状况 | 输出|
 | --- | --- | --- | --- |
 | 读取数组| [3,2,2,2,2,2,1] | 最大(a)=3 | 3 == 3 → 是 |

 最大元素等于`x=3`，所以总和包括`3!`并且可以被整除`3!`。 

这些痕迹证实了逻辑：只有最大元素对于整除性很重要。

 ## 边缘情况

 对于本案`n=1, x=1, a=[1]`，算法正确输出“是”，因为单阶乘`1!`等于`x!`。 对于所有元素都小于的情况`x`， 例如`n=3, x=10, a=[7,8,9]`，阶乘之和小于`10!`，因此算法正确输出“否”。 这些边缘情况表明，我们的最大元素检查可靠地捕获了所有可能的整除情况，而无需计算大阶乘。
