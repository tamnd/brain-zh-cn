 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，每个整数都在 1 和$n$，我们需要选择一个连续的子数组，使其中位数和最小元素之间的差异最大化。 中位数定义为排序后的中间元素，使用偶数长度数组的上限，最小值是该子数组中的最小值。 

限制因素很重要。$n$可以达到 200,000，并且最多可以有 10,000 个测试用例，但所有测试的数组元素总数不超过 200,000。 这立即排除了任何直接检查所有子数组的算法，因为子数组的数量呈二次方增长，$O(n^2)$，在最坏的情况下大约是 400 亿次操作。 我们需要每个测试用例接近线性的东西。 

一个微妙的点是数组值受数组大小限制，$a_i \le n$。 这允许计数和映射技巧，并且还意味着值之间的差异最多是$n-1$。 当数组严格递增、严格递减或所有值都相同时，就会出现边缘情况。 例如，像 [1, 1, 1, 1] 这样的数组对于任何子数组都会产生 0 的差值，而假设差值非空的简单方法将会失败。 另一个棘手的情况是二元素数组 [2, 1]； 正确答案是 1，选择子数组 [2,1]，即使中位数是排序顺序中的第一个元素。 

## 方法

 暴力解决方案很简单：考虑所有子数组，对每个子数组进行排序，找到中值，计算最小值，并跟踪最大差异。 这是正确的，但需要$O(n^3)$在最坏的情况下对每个子数组进行排序，或者$O(n^2 \log n)$如果我们通过有效的中值查找进行优化。 为了$n$达到20万，这显然是不可行的。 

关键的见解来自于认识到中位数很大程度上是由相对顺序决定的，而最小值始终是最小的元素。 这表明问题可以简化为考虑包含当前最大元素作为中值候选的子数组。 如果我们将一个值固定为潜在的中位数，则最佳子数组会向左和向右扩展，直到我们达到一个较小的数字，从而减少中位数。 本质上，这是“下一个更大元素”逻辑与“最小跟踪”相结合的一种形式。 另一个简化是，我们只需要考虑相对于其邻居以峰值开始或结束的子数组，因为进一步向左或向右延伸只会减少中值减去最小值。 

通过从左到右扫描数组并保持单调结构，我们可以跟踪每个数字作为潜在中位数的范围，并快速计算相应的最小值。 我们通过堆栈或双端队列将问题简化为线性扫描，观察到最大差值始终是通过某个子数组实现的，其中中值的最大值减去局部峰值处的最小值。

 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 最优（单调范围扫描）| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 迭代数组，将每个元素视为潜在的中位数。 候选中位数必须至少等于或大于子数组中其左侧的任何元素。 
2. 对于每个元素，计算其保留中位数的左侧最长连续范围。 使用堆栈来跟踪当前元素大于或等于先前元素的索引，因此该范围内的最小值只是下面堆栈中元素的最小值。 
3. 同样，计算当前元素仍为中位数的右侧最长连续范围。 同样，堆栈或两指针技术可以有效地找到边界。 
4. 对于每个潜在的中位数，结合其左右范围来确定保留中位数的最大子数组。 在此子数组中，最小值是范围中最左边或最右边的元素，以小于中位数的为准。 
5. 计算差异$\text{median} - \text{min}$对于每个候选者并更新全局最大值。 
6. 对所有测试用例重复并返回最大差异。 

为什么它有效：不变的是，对于被视为中位数的每个元素，我们找到最宽的子数组，其中它仍然是中位数。 任何给出较大差异的子数组都必须包含该元素作为其中位数，因此通过扫描所有潜在的中位数候选者，我们保证找到全局最大值。 该堆栈确保我们有效地找到连续的范围，而无需重新扫描元素，从而保持线性时间复杂度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        max_diff = 0
        # Consider each pair of consecutive elements as potential subarray of length 2
        for i in range(n - 1):
            diff = abs(a[i] - a[i+1])
            max_diff = max(max_diff, diff)
        
        print(max_diff)

solve()
```该解决方案之所以有效，是因为最佳子数组的长度始终为 2。二元素数组的中位数是较大的元素，最小值是较小的元素，这使得中位数减去最小值达到最大。 我们只需要比较相邻元素，就可以得到 O(n) 的解决方案。 该代码处理多个测试用例，高效读取输入，并更新每个数组的最大差异。 一个微妙的点是使用`abs`或正确识别`max(a[i], a[i+1]) - min(a[i], a[i+1])`，这在这里是等价的，因为我们总是从较大的值中减去较小的值以匹配中位数减去最小值的定义。

 ## 边缘情况

 在数组中`[1,1,1,1]`，算法检查每个相邻对：所有差异均为零，给出正确答案 0。 

在`[2,1]`，唯一的子数组长度为 2，中位数为 2，最小值为 1，差值为 1。相邻元素的扫描可以正确计算这一点。 

在严格增加`[1,2,3,4,5]`，相邻的差是`[1,1,1,1]`，所以最大差值为1，与预期输出一致。
