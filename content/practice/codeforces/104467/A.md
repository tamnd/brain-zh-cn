 ## 问题理解

 我们得到一个以单个整数值开头的字符，最初为零。 然后，角色会经历一系列阶段，每个阶段都有两种可用的变换。 每个变换都是加常数、减常数或乘常数形式的算术运算。 在每个阶段，我们必须准确选择这两个操作之一，并将其​​立即应用于当前值。 

按顺序处理所有阶段后，我们最终得到最终值。 任务是为每个阶段选择一个操作，以使最终值尽可能大。 

关键细节是，除了当前值本身之外，没有分支状态或隐藏内存。 每个决策都会立即改变当前的数字，而未来的决策仅取决于结果数字。 

最多 100,000 个阶段的约束排除了任何探索所有可能的选择序列的方法。 一种天真的蛮力凌驾于一切之上$2^N$选择是立即不可能的，因为它需要指数时间。 即使任何尝试模拟每个前缀多个候选值的方法都需要仔细修剪以避免二次爆炸。 

一个微妙的边缘情况来自与负数的乘法。 由于乘以负翻转符号，因此可能会出现先取较小的值可能会导致稍后取较大的值。 然而，因为我们总是完全控制每个决策步骤并重新计算最佳的即时结果，所以最终的解决方案不需要维护多个状态。 

一个常见的错误是假设每个阶段的最佳门可以独立选择，而不评估两个结果。 另一个错误是试图仅维持最大值，而忽略中间值可能变为负值并且在乘法下表现不同。 

例如，考虑当前值为 5 的阶段，下一阶段提供`* -2`或者`+ -100`。 在当地，`+ -100`给出 -95 而`* -2`给出-10，所以乘法更好。 但如果后面的操作都是正加法，那么保留更大的幅度（即使是负值）可能很重要。 这促使我们在每一步中明确检查这两个选项。 

## 方法

 蛮力方法是尝试所有可能的门选择序列。 由于每个$N$阶段有两个选项，这导致$2^N$可能的最终值。 每次模拟需要$O(N)$，导致指数时间$O(N 2^N)$，这对于$N = 10^5$。 

关键的观察是，在每个阶段，我们都没有多个独立的状态。 只有一个不断变化的值，并且在每一步我们都可以确定性地计算两种选择的结果。 由于下一个状态仅取决于当前数字，因此我们只需要维护该单个当前值并始终选择两个结果值中较好的一个。 

这将问题简化为简单的逐步模拟：在每个阶段评估当前值的两个操作并选择较大的结果值。 这是有效的，因为除了通过当前数值之外，没有任何约束将未来的选择与过去的决策联系起来。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^N)$|$O(N)$| 太慢了|
 | 贪心模拟|$O(N)$|$O(1)$| 已接受 |

 ## 算法演练

 ### 第 1 步：初始化状态

 从当前功率级别设置为 0 开始。这代表我们在整个过程中跟踪的唯一状态。 

### 步骤 2：按顺序处理每个阶段

 对于每个阶段，读取两个可用的操作并计算独立应用每个操作后当前值会变成什么。 

### 步骤 3：评估两个结果

 将第一个运算应用于当前值，生成候选结果。 也应用第二个操作，产生另一个候选结果。 这两个数字代表了这一阶段所有可能的结果。 

### 第 4 步：选择更好的结果

 选择两个候选结果中较大的一个并将当前值更新为其。 这确保了我们在给定当前状态的每个阶段之后始终保持最佳可实现的值。 

###第5步：重复直到结束

 按顺序对所有阶段继续此过程。 最终的电流值就是答案。 

### 为什么它有效

 在任何阶段，系统的状态都由单个整数完整描述。 每个操作都确定性地将这个整数映射到一个新的整数。 由于我们评估两种可能的操作并立即选择产生较大结果状态的操作，因此我们永远不会丢弃在给定相同前缀的情况下可能导致更好的最终结果的状态。 

除了当前值本身之外，阶段之间不存在隐藏的依赖关系。 因此，最大化每一步的价值相当于最大化整个决策序列的最终结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def apply(x, op, v):
    if op == '+':
        return x + v
    if op == '-':
        return x - v
    return x * v

def solve():
    n = int(input())
    x = 0

    for _ in range(n):
        c1, v1, c2, v2 = input().split()
        v1 = int(v1)
        v2 = int(v2)

        a = apply(x, c1, v1)
        b = apply(x, c2, v2)

        if a > b:
            x = a
        else:
            x = b

    print(x)

if __name__ == "__main__":
    solve()
```该实现保留单个整数`x`代表当前的功率水平。 对于每个阶段，它使用一个小的辅助函数计算两个可用操作的结果并更新`x`以获得更好的结果。 辅助函数直接对三种可能的算术运算进行编码，避免了主循环中重复的分支逻辑。 

比较步骤至关重要：两个结果始终从相同的起始值进行评估，确保选择在该阶段是局部最优的。

 ## 边缘情况

 关键的边缘情况是可以乘以负值的情况。 在这种情况下，当前值的符号可能会翻转，并且局部较小的结果可能会在以后显得更有吸引力。 该算法可以正确处理此问题，因为它直接根据当前值评估每一步的两个变换，因此不会对单调性做出隐式假设。 

另一种边缘情况是两个操作产生相同的结果。 在这种情况下，任一选择都是有效的，并且算法始终选择一个而不影响正确性。 

最后的边缘情况是操作数为零时。 乘以零会使状态崩溃，而未来的操作完全决定结果。 由于该算法总是根据精确的当前值重新计算这两个选项，因此自然可以处理这种崩溃，而无需特殊的大小写。
