 ## 解决方案
 ## 问题理解

 我们被要求构造任何连通的无向图，其结构与两个全局距离测量一致。 

对于图中的每个节点，我们将其不便性定义为从它到任何其他节点的最远最短路径距离。 这是节点的经典偏心率。 在所有节点上，一个值是最小偏心率，另一个值是最大偏心率。 输入为我们提供了这两个值，但不是图表本身。 任务是要么用这些精确的极值偏心率重建任何有效的图，要么报告不存在这样的图。 

因此，我们同时控制两个全局图形参数：半径（最小偏心率）和直径（最大偏心率）。 输入为我们提供了目标直径 X 和目标半径 Y，我们必须实现它们完全匹配的图表。 

约束 X、Y ≤ 100 和 N ≤ 1000 意味着我们不需要对大型结构进行大量优化。 具有多达一千个节点的建设性解决方案是完全足够的，因此 X 和 Y 中的任何多项式都可以。 这强烈表明确定性构造而不是搜索或优化。 

一个天真的尝试是假设任何直径为 X 的树都会自动给出大约 X/2 的半径，然后尝试调整它。 这会以微妙的方式失败。 例如，直径为 10 的简单路径图始终具有半径 5，因此它无法实现半径 2 或半径 7。另一种失败模式是尝试附加叶子来调整偏心率：附加长分支可能会意外增加直径，因为分支的远端点成为新的直径端点。 

关键的困难在于半径和直径是紧密耦合的，因此任意调整其中之一往往会破坏另一个。 

## 方法

 强力方法是生成最多 1000 个节点的所有图，并计算所有对最短路径来评估半径和直径。 即使忽略图的组合爆炸，使用 Floyd-Warshall 计算每个图的距离也是 O(N^3)，而且图的数量是天文数字，所以这立即是不可能的。 

结构洞察是我们根本不需要搜索。 任何图都有一个半径为 Y 的中心节点，这意味着每个节点必须位于某个中心节点的距离 Y 之内。 同时，距离X处必须存在两个节点。这两个要求意味着很强的不等式：直径路径的两个端点都位于距离中心距离Y以内，因此它们的距离最多为2Y。 这给出了必要条件 X ≤ 2Y。 而且半径不能超过直径，因此 Y ≤ X。 

一旦满足这些约束，我们就可以显式地构造一棵树。 这个想法是建立一条实现直径的“脊柱”路径，然后使用受控分支来确保一个选定的中心节点成为偏心率恰好为 Y 的唯一半径见证。 

我们首先构建一条长度为 X 的路径，以强制直径为 X。然后，我们在该路径上选择一个位置作为中心，并附加辅助链，以便在保持所有距离一致的情况下，没有节点的偏心率小于 Y。 路径使我们能够控制直径，而附件使我们能够在不影响端点距离的情况下提升内部节点的偏心率。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举| 指数 + O(N3) | O(N²) | 太慢了|
 | 建设性路径+附件| O(N) | O(N) | 已接受 |

 ## 算法演练

 我们以受控的方式构建图形，以便半径和直径都受到几何形状的强制。

1.首先检查可行性。 如果Y>X或X>2Y，则立即输出-1。 这些不等式来自以下事实：半径不能超过直径，并且任何两个节点都在彼此半径的两倍以内。 
2. 构建 X 条边的路径，创建标记为 0 到 X 的 X+1 个节点。这保证端点 0 和 X 之间的距离恰好为 X，因此直径至少为 X。 
3. 选择该路径的中心节点作为节点 Y。这是关键的定位步骤：我们将未来的半径见证放置在距左端点距离 Y 处。 
4. 验证从节点 Y 到节点 X 的路径右侧的长度是否为 X − Y，由于可行性，长度最多为 Y。 这确保节点 Y 的偏心率恰好为 Y，因为其最远端点是距离 Y 处的左端。 
5. 现在调整图的其余部分，以便没有节点的偏心率小于 Y。对于路径上的每个节点 i，我们附加一条长度为 max(0, Y − dist(i, Y)) 的链。 这确保了靠近中心的节点在距离至少为 Y 处获得额外的最远点，将其偏心率提高到至少 Y，而不影响直径端点。 
6. 输出结果图。 

### 为什么它有效

 构造的图包含长度为 X 的直径路径，因此最大偏心率至少为 X 并且不能超过 X，因为没有新路径超过端点到端点的距离。 

所选中心节点的偏心率恰好为 Y，因为直径路径的两端距中心节点的距离在 Y 以内。 每个其他节点要么位于主干上，要么位于附加链中，保证节点的距离至少为 Y，因此偏心率不会低于 Y。这将最小偏心率精确固定为 Y，最大偏心率精确固定为 X。 

该结构是稳定的，因为所有添加的结构都是植根于脊柱的树木，因此它们无法创建会改变沿主路径的最短路径距离的捷径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    X, Y = map(int, input().split())
    
    if Y > X or X > 2 * Y:
        print(-1)
        return

    n = X + 1
    edges = []

    # build diameter path
    for i in range(X):
        edges.append((i + 1, i + 2))

    center = Y  # node index in 1-based labeling (0-based node Y)

    # attach chains to enforce radius Y
    # we attach one leaf to each node closer to center than Y
    next_id = n

    def dist_on_path(i, j):
        return abs(i - j)

    for i in range(n):
        d = abs(i - center)
        need = Y - d
        last = i + 1
        for _ in range(need):
            next_id += 1
            edges.append((last, next_id))
            last = next_id

    print(next_id, len(edges))
    for u, v in edges:
        print(u, v)

if __name__ == "__main__":
    solve()
```代码首先验证可行性条件，然后构建长度为 X 的主干路径。位置 Y 的节点作为中心候选。 

之后，它通过连接长度取决于到中心的距离的链条来增加偏心率。 每条链条都是纯粹向外的，因此它不能缩短任何现有距离，而只会在需要时增加偏心率。 

节点索引小心地从简单路径开始并单调扩展，这避免了冲突并确保了有效的简单图。 

## 工作示例

 ### 示例 1：X = 4，Y = 2

 我们构建一条路径 1-2-3-4-5。 中心是节点 3。 

| 步骤| 行动| 关键效果|
 | --- | --- | --- |
 | 1 | 构建路径| 直径 = 4 |
 | 2 | 选择中心 = 3 | 候选半径节点|
 | 3 | 连接链条| 如果需要，提高节点 2 和 4 的偏心率 |

 构建后，节点 3 到两个端点的最远距离为 2，因此其偏心率为 2。端点的偏心率为 4，确认直径为 4。 

这表明中心选择正确地固定了半径，而脊柱固定了直径。 

### 示例 2：X = 8，Y = 13

 这立即违反了 X ≤ 2Y，因为 8 ≤ 26 成立，但 Y ≤ X 失败，因为 13 ≤ 8 为假。 

| 步骤| 检查 | 结果 |
 | --- | --- | --- |
 | 1 | Y ≤ X | 假 |
 | 2 | 输出| -1 |

 这表明半径不能超过直径，因此不存在图。

 ## 边缘情况

 一种边缘情况是当 Y = X 时。在这种情况下，结构退化为星形或严重倾斜的树，其中中心是直径路径的一个端点。 该算法将中心放置在位置 X，因此路径的右侧是空的，并且该端点的偏心率恰好变为 X。通过附加链强制所有其他节点具有至少 X 的偏心率，因此半径等于直径。 

另一个边缘情况是 X = 2Y 时。 这里的中心正好位于直径路径的中间。 这是最干净的情况：仅脊柱就已经平衡了两侧，除了确保没有节点意外地具有低于 Y 的偏心率之外，严格不需要额外的链。该结构仍然有效，因为距中心的距离是对称的，并且脊柱上的每个节点自然具有至少 Y 的偏心率。
