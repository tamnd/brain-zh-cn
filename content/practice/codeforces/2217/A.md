 ## 解决方案
 ## 问题理解

 我们得到一个正整数数组。 两名玩家轮流从肖纳克开始。 正常转向包括选择任何值仍为正的位置并将其减一。 当所有条目归零时，游戏结束，谁走完最后一步有效棋子，谁就获胜。 

肖纳克有一种额外的力量，他最多可以使用一次，而不是正常的动作。 当他使用它时，整个数组被覆盖，使得每个位置都等于一个固定值`k`。 

问题是，假设两名球员都发挥最佳，肖纳克是否能取得胜利。 

游戏中唯一重要的真实状态是仍然可以执行的单位递减总数。 每个数组元素`a[i]`准确贡献`a[i]`移动，因此在任何特殊移动之前，游戏长度固定为数组的总和。 

特殊动作是结构变化的唯一来源。 它放弃当前配置并将其替换为`n`大小相同的堆`k`。 从那时起，游戏长度变为`n * k`，但肖纳克也轮流激活它。 

约束足够小，每个测​​试解决方案的 O(n) 或 O(n log n) 就足够了。 最多有 500 个测试用例，每个测试用例最多有 100 个元素，因此即使每个测试的 O(n^2) 仍然可以轻松通过。 这意味着我们可以直接推理奇偶校验和简单的转换，而无需任何高级数据结构。 

一些微妙的情况很重要：

 如果肖纳克从不使用特殊动作，则结果仅取决于总和是奇数还是偶数，因为玩家严格交替每次移动取一个单位。 

如果他立即或在一些动作之后使用特殊动作，则剩余动作的奇偶性会以受控方式改变。 

一个天真的错误是认为特殊动作总是有帮助的`k`很大，或者比较`k`与最大元素。 这是不正确的，因为该操作会重置整个结构，并且不会保留任何局部意义上的进度； 只有奇偶性和总移动数才重要。 

## 方法

 蛮力视图是模拟整个游戏。 在每个状态，我们都会尝试所有可能的减量，并考虑肖纳克是否使用特殊动作。 这导致了一个博弈树，其中每个节点分支为`n + 1`移动，深度可以与所有元素的总和一样大。 即使使用记忆化，状态空间也是巨大的，因为数组值定义状态，并且每个元素最多可以占用 1000 个状态。 

关键的观察结果是，除了通过转弯结构之外，各个位置不会相互作用。 每一步都会删除一个单位的“未来步数”。 所以整个游戏就相当于一堆`S = sum(a[i])`令牌，玩家交替移除一个令牌。 该特殊动作将现有的桩结构替换为新的总固定尺寸结构`n * k`。 

因此，肖纳克唯一的决定是是否将剩余的总步数从`S`进入`n * k`到了某个时候，同时还要消耗一招才能做到这一点。 由于两名棋手都发挥最佳状态，唯一相关的属性是肖纳克能否确保他做出最后一步，这完全取决于最佳可能使用操作后的平价。 

我们比较两种场景：

 如果肖纳克从不使用特殊动作，他就会获胜当且仅当`S % 2 == 1`。 

如果他使用它，他会希望以一种使最终平价有利的方式使用它。 最好的时刻总是立即发生，因为延迟它只会浪费一步，并且不会以有益的方式改变平价结构。 使用后，剩余步数总数变为`n * k`，但一招已经被消耗了。 

因此有效剩余长度变为`n * k`，并进行平价翻转，因为 Shaunak 使用了一步棋。 因此 Shaunak 在这个分支中获胜 iff`(1 + n * k) % 2 == 1`从他的角度来看，这简化为`n * k % 2 == 0`。 

因此，如果满足以下任一条件，肖纳克就可以获胜：

 他不使用特殊动作就获胜，或者立即使用特殊动作后获胜。 

这产生了一个简单的奇偶条件。

 ## 算法演练

 我们计算两个量：数组的和以及奇偶校验`n * k`。 

1. 计算`S = sum(a[i])`。 这表示在不使用特殊操作的情况下游戏中正常移动的次数。 在这种情况下，获胜者取决于是否`S`是奇数还是偶数。 
2. 检查是否`S`很奇怪。 如果是这样，肖纳克无需使用他的特殊动作就可以立即获胜，因为他首先开始，并且每一步都会删除一个单位。 
3. 计算`P = (n * k)`。 这是应用特殊操作后的总移动次数。 
4.考虑立即使用必杀技的效果。 肖纳克花费一步来激活它，因此有效的剩余游戏由奇偶校验决定`P`相对于回合顺序。 这意味着肖纳克在这个分支中获胜，当`P`是均匀的。 
5. 如果任一条件对 Shaunak 有利，则打印“YES”，否则打印“NO”。 

### 为什么它有效

 游戏简化为固定长度的交替消除过程。 除了特殊操作之外，没有任何移动会改变结构，并且该操作仅重置剩余总计数。 由于每一步总是消耗一个进度单位，因此整个游戏取决于剩余的步数以及其回合奇偶性与最终步数一致。 特殊动作仅改变总计数`S`到`n * k`以一回合为代价，因此结果仅取决于奇偶校验比较，而不取决于数组中值的分布。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        s = sum(a)
        
        # option 1: no special move
        if s % 2 == 1:
            print("YES")
            continue
        
        # option 2: use special move immediately
        # after special move, total becomes n*k and parity flips due to move spent
        if (n * k) % 2 == 0:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```该代码首先计算数组的总和以评估无特殊移动场景。 如果这个和是奇数，则肖纳克由于平价优势已经处于获胜位置。 

如果没有，则立即评估使用必杀技的效果。 由于操作将游戏转换为大小统一的结构`n * k`，在考虑到已经花费的回合后，只有该数字的奇偶性才重要。 然后，决定是两个获胜条件之间的简单“或”。 

## 工作示例

 考虑一个输入，其中`n = 3`,`k = 2`，数组是`[3, 3, 3]`。 

我们计算：

 | 步骤| 价值|
 | --- | --- |
 | 总和S | 9 |
 | S 平价 | 奇数|
 | 决定| 无需特殊动作即可获胜|

 自从`S`很奇怪，肖纳克立即获胜，无论`k`。 

现在考虑`n = 2`,`k = 2`， 大批`[2, 2]`。 

| 步骤| 价值|
 | --- | --- |
 | 总和S | 4 |
 | S 平价 | 甚至|
 | n * k | 4 |
 | (n*k) 奇偶校验 | 甚至|

 在这里，肖纳克无法通过等待获胜，但使用必杀技后，总共有 4 步，仍然是均匀的，使得最终的动作与肖纳克的回合顺序一致。 所以答案是肯定的。 

这些示例表明，只有总移动的奇偶性才重要，并且数组内值的分布永远不会影响结果。

 ## 边缘情况

 当数组只有一个元素时，游戏就会缩减为一堆。 如果该堆是奇数，则肖纳克总是获胜，因为他进行了最后的减量。 如果是偶数，则特殊动作决定结果，逻辑简化为检查是否`n * k`是均匀的。 

当所有元素都相等时，基于总和的逻辑仍然完全决定结果，尽管直观上特殊动作看起来很强大。 重置操作不保留奇偶校验之外的优势，因此即使是大型统一数组也不需要特殊处理。 

什么时候`k`非常大，诱惑是假设特殊动作占主导地位。 然而，只有其平价才重要。 幅度永远不会影响最佳游戏，这就是为什么在对数组求和后解决方案保持恒定时间的原因。
