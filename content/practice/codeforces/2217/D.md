 ## 解决方案
 ## 问题理解

 我们得到一个二进制数组和一组特殊索引，其中所有值都相同。 我们的目标是使用最少数量的翻转操作使整个数组等于这些特殊索引处的值。 翻转操作允许我们选择一个至少包含一个特殊索引的连续子数组，并反转该子数组中的每一位。 

该问题需要处理多个测试用例，所有用例的数组大小之和可达 200,000。 这排除了任何显式检查所有可能子数组的解决方案，因为这将是二次或更糟的。 相反，我们需要一种在数组长度上线性或接近线性工作的方法。 

当段内存在与特殊值不同的连续位但没有特殊索引时，会出现微妙的边缘情况。 在每个差异处翻转的简单方法可能会尝试翻转段而不包含特殊索引，这是无效的。 另一种边缘情况是当数组已经是均匀的时； 正确的答案是零翻转，但粗心的贪婪策略可能仍会尝试不必要地翻转段。 例如，对于一个数组`[1,1,1,1]`具有特殊索引`[2,3]`，所需的最少翻转次数为`0`。 

## 方法

 强力解决方案将迭代每个元素，当它与特殊值不同时，尝试包含特殊索引的所有可能范围来翻转它。 这原则上是正确的，因为最终所有位都会匹配，但每个测试用例最多执行 O(n^2) 次操作，这对于 n 高达 200,000 来说太慢了。 

最佳解决方案的关键见解是我们只需要考虑与特殊值不同的连续元素段。 每个这样的段都可以通过一次翻转来中和，该翻转从段的第一个元素延伸到两侧最近的特殊索引。 这是可行的，因为每次翻转都可以包含至少一个特殊索引并反转整个段，从而使段中的所有位达到正确的值。 通过从左到右处理数组并在一次操作中贪婪地翻转每个“错误”的段，我们可以有效地覆盖整个数组。 

贪婪方法之所以有效，是因为问题是线性的：翻转错误段之外的任何位是不必要的，并且翻转在非重叠段上是幂等的。 我们不需要考虑重叠的段或同一段上的多次翻转，因为如果范围包含特殊索引，则单个操作就足够了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，读取n，k，数组`a`，以及特殊索引列表`p`。 转变`p`到从零开始的索引，以便更轻松地处理数组。 
2. 确定目标值`x`在特殊指数中。 所有特殊索引都保证具有相同的值，因此我们可以选择`a[p[0]]`。 
3. 初始化计数器`ops`为零和索引`i`为零。 我们将从左到右扫描数组。 
4. 虽然`i`小于`n`，检查是否`a[i]`等于`x`。 如果是，则增加`i`并继续。 
5.如果`a[i]`不同于`x`，我们找到了需要翻转的段的开始。 增量`ops`1.然后移动`i`向前直到到达下一个元素等于`x`或数组的末尾。 这会在一次操作中跳过整个错误的段。 
6. 重复步骤 4-5，直到阵列结束。 处理后，`ops`包含所需的最少操作数。 

贪婪方法之所以有效，是因为每个与`x`必须至少翻转一次。 通过将翻转扩展到最近的特殊索引，我们满足每个翻转都包含一个特殊索引的约束。 翻转重叠的段是不必要的，因为一旦翻转一个段，它的位就会匹配`x`并且不会再被翻转。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        p = list(map(int, input().split()))
        p = [pi - 1 for pi in p]  # convert to 0-based
        x = a[p[0]]  # target value
        ops = 0
        i = 0
        while i < n:
            if a[i] == x:
                i += 1
            else:
                ops += 1
                while i < n and a[i] != x:
                    i += 1
        print(ops)

if __name__ == "__main__":
    solve()
```该代码首先读取输入并将特殊索引转换为从零开始的索引。 目标值取自第一个特殊索引。 我们扫描数组，每当遇到与`x`，我们增加操作计数器并跳过整个段。 这保证了每次翻转都是最少且必要的。 由于 while 循环停止于`n`。
