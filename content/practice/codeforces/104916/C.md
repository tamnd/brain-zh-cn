 ## 解决方案
 ## 问题理解

 给定一个由大写拉丁字母组成的字符串，我们感兴趣的是计算其中存在多少个“C-A-T”形式的有序子序列。 通过选取索引形成子序列$i < j < k$这样这些位置的字符分别是“C”、“A”和“T”。 字符不需要相邻，只要它们的顺序很重要。 

该任务纯粹是组合性的：对于每个有效的位置选择，我们计算该模式的一次出现。 输出是此类三元组的总数。 

如果字符串长度很大，则约为$10^5$或者更多，任何明确尝试所有三元组索引的解决方案都是不可能的，因为在最坏的情况下这将需要三次或至少二次行为。 当与另一个扫描嵌套时，即使是位置上的双循环也会很快变得太慢。 

一个微妙的边缘情况是当字符串包含许多重复的字母时。 例如，如果字符串是“CATCAT”，天真的贪婪解释可能会错误地假设重叠模式相互干扰，但实际上每个有效的索引三元组都是独立的。 另一种失败模式是将问题视为连续子串匹配而不是子序列计数，这会错过有效的非相邻形式，例如：

 输入：```
CAXAT
```正确输出：```
2
```因为 (C at 1, A at 3, T at 5) 和 (C at 1, A at 4, T at 5) 都形成有效的子序列。 

## 方法

 蛮力的想法很简单：选择“C”的每个位置，然后为“A”选择后面的每个位置，然后为“T”选择后面的每个位置。 这直接遵循问题的定义并且是正确的，因为它枚举了所有有效的三元组$i < j < k$。 然而，这需要检查所有$O(n^3)$最坏的情况下是三倍。 和$n = 10^5$，这远远超出了可行的限度。 

我们可以通过重用部分结构来改进这一点。 我们没有独立搜索每个三元组，而是观察到每个“A”位于其左侧的一组“C”和右侧的一组“T”之间。 如果我们知道，对于每个“A”，有多少个有效的“C-A”前缀以它结尾，以及有多少个“A-T”后缀扩展从它开始，我们就可以有效地将它们组合起来。 

这导致了自然的动态积累策略。 我们从右向左处理字符串，以便我们可以维护右侧存在多少个“T”，右侧存在多少个“AT”对，以及可以形成多少个“CAT”三元组。 

通过维护部分结构的计数器，我们可以避免重新计算重叠的子问题。 每个角色都根据先前积累的信息对更高级别的模式做出贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^3)$|$O(1)$| 太慢了|
 | 从右到左累积 |$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 我们从右向左扫描字符串，同时维护三个计数器：

 1. 柜台`cntT`它存储到目前为止已经看到了多少个“T”字符。 
2. 柜台`cntAT`存储有多少对“A-T”，其中“A”位于后缀中“T”的左侧。 
3. 柜台`cntCAT`它存储处理后的后缀中存在多少个完整的“C-A-T”子序列。 

我们根据当前角色更新这些计数器：

 1. 首先将所有计数器设置为零。 我们从最后一个索引到第一个索引处理字符。 
2. 如果当前字符是“T”，则递增`cntT`因为这个“T”可以作为未来“AT”和“CAT”模式的结尾。 
3. 如果当前字符是“A”，则后缀中当前的每个“T”都可以与该“A”配对，形成新的“AT”。 我们添加`cntT`到`cntAT`。 
4. 如果当前字符是“C”，则后缀中每个现有的“AT”对都可以用前面的这个“C”扩展，形成完整的“CAT”。 我们添加`cntAT`到`cntCAT`。 

处理完所有字符后，`cntCAT`持有答案。 

### 为什么它有效

 在从右到左扫描期间的任何位置，`cntT`正确计算已处理后缀中模式最终字符的所有有效选择。 相似地，`cntAT`计算后缀内所有有效的有序对（A 在 T 之前）。 最后，每次我们看到“C”时，将其与所有现有的“AT”对相结合，以正确的顺序枚举所有三元组（C、A、T）。 每个扩展步骤都会保留顺序，因为贡献仅来自后缀，该后缀严格位于当前位置的右侧。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    
    cntT = 0
    cntAT = 0
    cntCAT = 0
    
    for ch in reversed(s):
        if ch == 'T':
            cntT += 1
        elif ch == 'A':
            cntAT += cntT
        elif ch == 'C':
            cntCAT += cntAT
    
    print(cntCAT)

if __name__ == "__main__":
    solve()
```实现直接遵循反向扫描。 关键细节是严格的更新顺序：`cntT`之前必须更新`cntAT`， 和`cntAT`前`cntCAT`取决于字符类型，因为每一层都取决于之前积累的后缀信息。 

不需要中间存储，因为所有相关结构都被压缩到三个计数器中。

 ## 边缘情况

 关键的边缘情况是字母大量重复并且所有有效组合都存在。 例如：

 输入：```
CCAAATTT
```我们从右向左处理。 每个“T”都会增加`cntT`，每个“A”贡献所有电流`T`到`cntAT`，每个“C”乘以所有电流`AT`配对成`cntCAT`。 由于存在多个相同的字母，因此计数器增长很快，但始终代表精确的组合计数，而不是近似值。 

另一种边缘情况是缺少一个必需的字符，例如字符串中没有“A”。 在那种情况下，`cntAT`永远不会从零开始增加，所以`cntCAT`无论存在多少个“C”和“T”，该值都保持为零。 这与定义相匹配，因为没有中间字符就无法形成有效的三元组。
