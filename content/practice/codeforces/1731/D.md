 ## 解决方案
 ## 问题理解

 我们有几个独立的网格，每个网格代表一个城市地图，其中每个单元格都包含一个建筑物高度。 从每个网格中，我们必须选择一个大小为的正方形子网格$l \times l$使得该正方形内的每个单元格的高度至少$l$。 任务是找到最大可能值$l$对于每个测试用例。 

关键的困难在于约束将几何形状与值耦合在一起：扩大正方形会使要求更加严格，因为边长和最小允许高度都会同时增加。 这使得该问题与阈值固定的标准“最大平方”类型任务根本不同。 

约束条件意味着总共最多$10^6$所有测试用例中的单元格。 这立即排除了每个测试用例超线性的任何方法，例如以简单的方式重新计算每个候选方的答案$O(n^3)$甚至$O(n^2 m)$行为。 一个执行粗略的解决方案$O(nm \log \min(n,m))$或者$O(nm)$每个测试用例的聚合是可以接受的。 

一些边缘行为很容易被忽视。 如果所有值都很小，例如网格中填充了 1，则任何大于的方格$1 \times 1$立即失败，因为该要求已经强制值至少为边长。 相反，如果值很大但很分散，那么孤立的大值没有帮助，除非它形成一个密集区域。 

一个常见的错误是将条件视为仅取决于平方大小或仅取决于值。 例如，假设“所有值至少为 1 的最大平方”始终是最优的，忽略了增加$l$本身就增加了门槛。 

## 方法

 暴力解决方案会尝试每个可能的左上角和每个可能的正方形大小。 对于每个候选方块，它检查所有单元格是否满足高度条件。 这涉及到$O(nm)$每平方格检查，并且有$O(nm)$正方形，导致最坏情况的复杂性$O(n^2 m^2)$，这远远超出了可行的限制$10^6$细胞总数。 

关键的观察是固定的条件$l$成为标准的二元网格问题。 如果我们决定候选边长$l$，我们只关心是否存在$l \times l$所有值至少为的子矩阵$l$。 这会将网格转换为二进制矩阵，其中单元格有效或无效取决于它们是否满足阈值。 

对于固定阈值，我们可以使用动态编程递归来计算最大的全一平方，该动态编程递归跟踪每个单元格结束的最大平方。 如果任何单元格至少实现了价值$l$，则存在一个有效的正方形。 

由于可行性是单调的$l$（如果一个正方形适用于$l$，它也适用于较小的值），我们可以对答案进行二分搜索$l$。 每个检查在网格上以线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^3 m^3)$|$O(1)$| 太慢了|
 | 二分查找 + DP |$O(nm \log \min(n,m))$|$O(m)$| 已接受 |

 ## 算法演练

 我们将问题简化为检查给定边长是否$l$是可行的。 

1.对于固定候选人$l$，将网格转换为二进制网格，其中如果单元格的高度至少为 1，则单元格为 1$l$，否则为 0。此步骤将约束直接编码到结构中，因此剩下的就是几何图形。 
2. 构建动态规划表，其中$dp[i][j]$表示以单元格结尾的最大全一正方形的大小$(i,j)$。 如果当前单元格有效，我们将扩展三个相邻方格中最小的一个。 否则为零。 这是有效的，因为任何以$(i,j)$必须从上方、左侧和左上对角线延伸有效的方块。 
3. 填写DP表时，如果有的话$dp[i][j]$至少达到$l$，我们立即知道一个有效的$l \times l$广场存在，可以提前停车。 
4. 将此可行性检查包含在二分搜索中$l$从 1 到$\min(n,m)$。 如果一个值$l$可行的话，我们尝试更大的值； 否则我们会缩小范围。 
5.最终的答案是最大可行的$l$。 

DP 递推式为：$dp[i][j] = \begin{cases} 1 + \min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) & \text{if } a_{i,j} \ge l \\ 0 & \text{otherwise} \end{cases}$### 为什么它有效

 每个以单元格结尾的有效方块都必须包含在其三个前驱方向中的每一个方向上结尾的较小方块。 如果这些方向中的任何一个违反了条件，则正方形无法延伸。 递归精确地捕获了锚定在每个位置的最大可能的正方形，以及任何有效的正方形。$l \times l$正方形必须显示为 DP 值至少达到$l$。 这使得检查既必要又充分。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can(l, n, m, a):
    dp = [0] * (m + 1)
    prev = [0] * (m + 1)
    
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if a[i-1][j-1] >= l:
                dp[j] = min(prev[j], dp[j-1], prev[j-1]) + 1
                if dp[j] >= l:
                    return True
            else:
                dp[j] = 0
        prev, dp = dp, prev
    return False

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = [list(map(int, input().split())) for _ in range(n)]
        
        lo, hi = 1, min(n, m)
        ans = 1
        
        while lo <= hi:
            mid = (lo + hi) // 2
            if can(mid, n, m, a):
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1
        
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案将可行性检查与优化分开。 这`can`函数在逐行扫描时对 DP 逻辑进行编码，仅使用两个滚动数组来保持内存与列数呈线性关系。 

二分搜索驱动最终答案，因为可行性在以下方面是单调的$l$：一次一个正方形大小$l$存在时，所有较小的尺寸都自动成为可能，因为尺寸要求和高度阈值一起减小。 

一个微妙的实现细节是 DP 循环内的提前退出。 一旦任何细胞达到至少一个正方形的大小$l$，该测试不需要进一步的计算，这显着提高了密集情况下的性能。

 ## 边缘情况

 单单元网格的行为很平常，因为唯一可能的正方形的大小为 1，并且当该值至少为 1 时始终满足阈值要求。 

统一的低网格（例如全网格）可确保任何形成大于 1 的正方形的尝试都会立即失败，因为高度约束随正方形大小缩放，无论几何形状如何，都会强制拒绝。 

统一的高网格（例如全九）使答案纯粹是几何的，并且 DP 将传播最大正方形尺寸，直到受到网格边界而不是值的限制。
