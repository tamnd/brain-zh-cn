 ## 问题理解

 我们给出了一个二进制数组和两种类型的归约操作，这些操作可以缩小数组，同时用最小值或最大值替换段。 该过程一直持续到数组变成单个值为止，目标是确定最终值是否可能是`1`。 

这两种操作对二进制数据的行为非常不同。 对两个相邻元素的最小运算产生`1`仅当两者都`1`，否则会产生`0`。 这意味着这对人来说是一种“破坏性”行动。 长度块上的最大操作`k`产生`1`如果至少有一个`1`在块中，因此它充当传播或保存的一种方式`1`。 

尽管可以通过多种方式转换数组，但限制很小：`n ≤ 50`。 这排除了对数组状态进行复杂动态编程的任何需要。 任何正确的解决方案都应该来自于对保留哪些信息的推理，而不是模拟所有转换。 

关键的边缘情况是当数组不包含`1`根本不。 在这种情况下，每个操作都会保留零，因此结果必须始终是`[0]`。 一个稍微微妙的情况是某些配置是否具有单个`1`可能会被操作“困住”，但实验很快表明，至少存在一个`1`通常足以迫使成功。 

例如，如果`a = [0, 0, 0, 1]`和`k = 4`，单个 max 操作将整个数组变成`[1]`。 如果`k = 2`，我们仍然可以使用 max 操作来移动和保留`1`，而 min 操作仅折叠相邻元素，而不会消除隔离它的可能性。 唯一真正不可能的情况是当没有`1`首先。 

## 方法

 强力解释将尝试模拟所有可能的段上的所有可能的操作。 每个操作都会减少数组大小，但状态数量增长得非常快，因为每个中间数组配置都可以分支到许多其他数组配置。 即使与`n ≤ 50`，这变得不可行，因为操作序列的数量是指数级的。 

关键的观察结果是，这两种操作都不会创建新的`1`从头开始。 唯一的办法是a`1`可以出现在最终数组中的是如果原始数组已经包含至少一个`1`。 一次`1`如果存在，则 max 操作保证它可以保留在包含它的任何选定窗口中。 之后，重复归约可以将数组折叠为单个元素，同时保留至少一个元素`1`活。 

最少的操作无助于创造或传播`1`s，但它也不能阻止`1`如果我们避免将其与`0`以破坏性的方式。 由于我们可以自由选择操作和段，因此我们总是可以安排一个序列，其中`1`被保存到最后。 

这将整个问题简化为一个问题：数组是否至少包含一个`1`？

 ## 算法演练

 我们将问题简化为检查是否存在`1`存在于数组中。 

1.从左到右扫描一次数组，检查是否有元素等于`1`。 此步骤捕获了成功的唯一必要条件，因为没有`1`没有任何操作可以引入这种情况。 
2. 如果至少有一个`1`发现，立即断定可以达到`[1]`。 推理是，一个`1`总是可以通过最大操作来保留，并且数组之后总是可以折叠。 
3.如果没有`1`存在，则得出答案是不可能的结论。 所有对零的操作都将始终产生零，因此最终的数组必须是`[0]`。 

### 为什么它有效

 就存在性而言，这两种操作都是单调的`1`。 最小操作无法创建`1`，并且最大操作仅保留现有的`1`如果已经位于所选段内。 这意味着谓词“数组至少包含一个`1`” 如果它开始为 false，则永远不会变为 true，并且一旦为 true，它就可以保持到数组减小到大小为 1。因此存在`1`既是必要的又是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    if any(x == 1 for x in a):
        print("YES")
    else:
        print("NO")
```该解直接实现导出的条件。 这`any`check 扫描一次数组，给出每个测试用例的线性时间。 不需要模拟操作，因为操作的结构保证没有初始配置就没有配置`1`可以生产出一个。 

一个常见的错误是尝试显式地对操作进行建模，但约束使得这样做没有必要。 整个转换过程分解为单个不变检查。 

## 工作示例

 考虑一个输入，其中`a = [0, 1, 0]`和`k = 2`。 扫描检测到`1`立即，所以答案是`YES`。 在操作上，我们可以合并和缩小，同时保留`1`，但算法不需要模拟这一点。 

现在考虑`a = [0, 0, 0, 0]`与任何`k`。 扫描发现没有`1`，所以答案是`NO`。 每个可能的操作都会产生最小或最大的零，它始终为零，因此数组永远不会变成`[1]`。 

这两条痕迹表明，该算法根本不推理转换，仅推理单个必要资源是否存在。

 ## 边缘情况

 当数组仅包含零时，每个操作都会保留全零结构。 例如，`[0, 0, 0, 0]`在最小和最大操作下都保持全零，因此它总是以以下形式结束`[0]`。 

当恰好有一个时`1`， 例如`[0, 0, 1, 0]`，算法立即接受。 可以安排任何操作序列，使得包含`1`由 max 操作保留，直到数组减少。 即使中间合并涉及零，`1`保证它始终可以保留在某个选定的段内。 

当所有元素都为`1`，任何操作仍然会产生`1`，因此减少为`[1]`很简单，无论`k`。 

什么时候`k = n`，单个 max 操作将整个数组折叠为单个值，该值变为`1`如果有的话`1`存在。 这与一般论证得出的条件相同。
