 ## 解决方案
 ## 问题理解

 计算机的扬声器音量当前设置为`X`，我们想把它改成`Y`。 每一秒我们都可能执行一次操作。 操作可以通过以下方式增加或减少音量`1`或通过`Z`。 音量必须始终保持在有效范围内`0`到`100`，包括每次操作后达到的中间值。 任务是计算达到目标量所需的最短秒数。 

限制非常小。 每个可能的体积都是介于`0`和`100`，所以整个状态空间只包含`101`顶点。 如此小的图使我们能够直接探索每个可到达的状态。 即使每个状态生成四个转换，总工作量也将远低于一千个操作。 任何图算法（例如广度优先搜索）都可以轻松满足限制。 

当尝试推导数学公式而不是搜索状态空间时，很容易错过一些边缘情况。 

如果`Z = 0`，大动作没有任何作用。 例如：```
Input:
5 8 0
```正确答案是`3`，因为只有`+1`改变音量。 基于除以的公式`Z`会失败，因为除以零是未定义的。 

当暂时远离目标是有益的时，会出现另一个微妙的情况。 考虑：```
Input:
1 4 5
```答案是`3`。 一种最佳序列是`1 -> 0 -> 5 -> 4`。 只向目标移动的贪婪策略永远不会发现这条路径。 

边界值也很重要。 例如：```
Input:
100 99 10
```答案是`1`。 从体积来看`100`我们不能增加`10`，因为中间状态必须保持在有效范围内。 任何实现都必须拒绝离开间隔的移动`[0, 100]`。 

## 方法

 最直接的解决方案是将每个可能的卷视为一种状态。 从一卷开始，我们可以尝试四种操作： 添加`1`, 减去`1`， 添加`Z`，并减去`Z`。 每个操作花费一秒，因此每条边的权重相等。 从起始卷运行广度优先搜索按所需时间的递增顺序访问状态。 当我们第一次达到目标时，我们已经找到了最小秒数。 

即使是暴力搜索也已经很快了，因为只有`101`州。 在最坏的情况下，广度优先搜索处理每个状态一次并检查四个传出转换，导致大约`404`转换检查。 

尝试建立一个封闭式公式比乍看起来要困难得多。 双向移动的能力，每个中间体积都留在内部的限制`[0, 100]`，以及特殊情况`Z = 0`创建许多极端情况。 将问题视为最短路径问题可以消除所有这些复杂问题。 广度优先搜索自然地处理弯路、边界和重复操作，而不需要针对每种情况进行单独推理。

 ## 算法演练

 1.创建一个大小为距离的数组`101`并将每个值初始化为`-1`。 该数组记录到达每个卷所需的最短秒数。 
2.设置起始体积的距离`X`到`0`并推`X`进入队列。 广度优先搜索总是按照距离增加的顺序扩展状态。 
3. 重复从队列中删除前面的卷。 
4. 通过应用生成四个可能的下一个卷`+1`,`-1`,`+Z`， 和`-Z`。 
5. 忽略位于间隔之外的每个生成的体积`[0, 100]`，因为这样的举动是不允许的。 
6. 如果之前没有访问过有效卷，则将其距离指定为当前距离加一并将其推入队列。 第一次访问始终是最佳的，因为广度优先搜索会先探索较短的路径，然后再探索较长的路径。 
7. 继续，直到队列变空或达到目标量。 
8.输出记录的距离进行音量`Y`。 

### 为什么它有效

 广度优先搜索保持了一个不变量，即从队列中删除的每个状态都已经具有距起始状态的最小可能距离。 由于每个允许的操作只花费一秒钟，因此所有图边都具有相同的权重。 当发现新状态时，可以通过尽可能短的操作序列达到该状态。 每个合法的按钮按下序列对应于该图中的一条路径，并且每个图路径对应于合法的操作序列。 由于广度优先搜索计算未加权图中的最短路径，因此记录的距离`Y`正是所需的最短时间。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    x, y, z = map(int, input().split())

    dist = [-1] * 101
    dist[x] = 0

    q = deque([x])

    while q:
        cur = q.popleft()
        if cur == y:
            break

        for nxt in (cur + 1, cur - 1, cur + z, cur - z):
            if 0 <= nxt <= 100 and dist[nxt] == -1:
                dist[nxt] = dist[cur] + 1
                q.append(nxt)

    print(dist[y])

if __name__ == "__main__":
    solve()
```距离数组有两个目的。 它存储已知的最短时间，并标记卷是否已被访问。 这避免了多次处理相同的状态。 

每次迭代都会考虑四个候选动作。 边界检查在访问距离数组之前进行，以便无效的体积，例如`-1`或者`101`被安全地忽略。 

提前退出时`cur == y`是可选的，但可以避免在找到最佳答案后进行不必要的工作。 

该实现还处理`Z = 0`自然。 在这种情况下，过渡`cur + z`和`cur - z`两者相等`cur`，已经被访问过，所以不会发生无限循环。

 ## 边缘情况

 当`Z = 0`，该图包含由以下方式产生的自循环`+Z`和`-Z`。 考虑：```
Input:
5 8 0
```搜索开始于`5`。 通过添加或减去零返回生成的移动`5`，已经被访问过，所以它们被忽略。 广度优先搜索继续进行`6`,`7`， 和`8`，产生正确答案`3`。 

当需要绕道时，广度优先搜索仍然会成功，因为它会在移动到更长的路径之前探索当前距离的所有状态。 对于输入```
1 4 5
```搜索达到`0`一步之后，然后`5`经过两步，终于`4`三步之后。 总是减少与目标的绝对差的贪心算法永远不会考虑这个序列。 

当当前交​​易量已经达到最大边界时，非法移动将被立即丢弃。 为了```
100 99 10
```过渡到`110`被忽略，因为它超出了有效范围。 剩余的合法搬迁至`99`一秒达到目标，就是最优答案。
