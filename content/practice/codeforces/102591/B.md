 ## 解决方案
 ## 问题理解

 我们有圆形排列的浆果。 每个浆果都有一个从 1 到 N 的唯一权重，输入中的顺序描述了它们在圆圈中的位置。 只有当两个相邻的浆果具有连续的重量时，才可能进行移动，其中较大的浆果恰好重一个。 较重的浆果会去除较轻的浆果并保持其自身的重量。 任务是确定某些动作序列是否可以移除除重量为 N 的浆果之外的所有浆果。 

主要观察结果来自这样一个事实：每个重量都有一个可能的食用者。 只有当浆果 k+1 仍然活着并且与其相邻时，浆果 k 才能消失。 由于移除k需要k+1，所以移除的顺序实际上是强制的。 浆果 1 必须先于浆果 2 消失，浆果 2 必须先于浆果 3 消失，依此类推，直到浆果 N-1 最后消失。 问题不在于搜索可能的动作，而在于检查这个单一的所需订单是否可以实现。 

约束 N 高达 2 * 10^5 排除尝试不同移动序列的模拟。 状态搜索将有大量的可能性，甚至在每次删除后扫描整个圆的直接模拟也需要 O(N^2) 操作，这对于这个输入大小来说太多了。 我们需要一种线性或近线性的方法。 

在几种边缘情况下，不正确的实现可能会失败。 当N=1时，不需要移动，所以答案一定是YES。```
Input:
1
1
```正确的输出是YES。 始终从检查 1 和 2 之间的邻接性开始的解决方案将访问不存在的值。 

另一个微妙的情况是，当存在连续对时，但过早删除它是错误的。 考虑示例：```
Input:
4
4 1 3 2
```3 和 2 是相邻的对，但是先移走 2 个，剩下 4 和 1 之间没有有用的吃者，所以游戏无法完成。 只检查每时每刻是否存在有效动作的解决方案会给出错误的结果。 

圆形边界也很重要。 例如：```
Input:
3
2 1 3
```值 1 和 2 在圆中相邻，因此 2 吃 1，然后 3 吃 2。正确的输出是 YES。 忘记第一个位置和最后一个位置之间的连接的实现将错误地拒绝这种情况。 

## 方法

 暴力解决方案将尝试每一个可能的有效移动，递归地探索所有可能的删除顺序。 它是正确的，因为它完全遵循规则，并且如果至少有一条路径到达单个浆果，则它会接受。 问题是可能的路径数量增长得非常快。 即使只有很少的浆果，也可以有多种选择，并且对于 N = 2 * 10^5 这种方法是完全不可能的。 

关键的观察是，蛮力探索实际不存在的选择。 驱逐令是强制的。 浆果 k 必须在浆果 k+1 之前被移除，因为 k+1 是唯一可以移除 k 的浆果。 一旦k+1消失，k以后就永远不会消失。 这将整个过程简化为检查是否可以在正确的时刻删除 1、然后 2、然后 3 等等。 

剩下的挑战是当元素从圆圈中消失时保持邻接。 用数组表示的双向链表就足够了。 对于每个权重，我们存储其当前左右邻居的权重。 当权重 k 被移除时，它的两个邻居变得相邻。 每个浆果都会被移除一次，因此总工作量是线性的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| O(N) | 太慢了|
 | 最佳| O(N) | O(N) | 已接受 |

 ## 算法演练

 1. 构建循环链表。 对于每个浆果值，存储紧邻其左侧的值和紧邻其右侧的值。 输入顺序直接给出该信息，包括最后一个位置和第一个位置之间的连接。 
2. 按照从 1 到 N-1 的递增顺序处理浆果。 在步骤k，检查浆果k当前是否紧邻浆果k+1。 这是让 k 消失的唯一可能的方法。 
3. 如果k+1既不是k的左邻居也不是右邻居，则所需的移除顺序不会发生，所以答案为NO。 
4. 如果k可以被移除，则直接连接它的两个邻居，并将k从链表中丢弃。 下一次迭代将在更新后的圆上进行。 
5. 如果从 1 到 N-1 的每个值都可以按此顺序删除，则只剩下浆果 N，所以答案为“是”。 

为什么它有效：

 不变的是，在处理值 k 之前，所有小于 k 的值都已被删除，并且从 k 到 N 的所有值仍然存在。 浆果 k 必须在 k+1 消失之前消失，因为 k+1 是 k 的唯一可能的吃者。 这使得在每个有效游戏中都需要增加移除顺序。 该算法准确地检查每个所需的删除是否可以在需要时发生，并且链表更新在每次删除后保留真正的循环邻接。 如果所有检查都成功，则相同的移除顺序是完成游戏的有效方法。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    if n == 1:
        print("YES")
        return

    left = [0] * (n + 1)
    right = [0] * (n + 1)

    for i, x in enumerate(a):
        left[x] = a[(i - 1) % n]
        right[x] = a[(i + 1) % n]

    for x in range(1, n):
        if left[x] != x + 1 and right[x] != x + 1:
            print("NO")
            return

        l = left[x]
        r = right[x]
        right[l] = r
        left[r] = l

    print("YES")

if __name__ == "__main__":
    solve()
```这`left`和`right`数组按浆果重量而不是位置存储邻居。 这很方便，因为移除顺序基于权重，而不是原始索引。 

从1到N-1的循环遵循强制消失的顺序。 在删除 x 之前，代码会检查两个方向，因为圆没有固定的起点，因此 x+1 可以是任一邻居。 

当 x 被移除时，它的左邻居和右邻居变得相邻。 赋值会更新双向链表的两个方向，这避免了原始数组的任何移位。 这就是 O(N) 解决方案和从列表中间重复删除的解决方案之间的区别。 

Python 整数在这里就足够了，因为只存储索引和最大 2 * 10^5 的值，所以溢出不是问题。 

## 工作示例

 对于第一个样本：```
3
1 3 2
```| 检查当前值| 左邻居| 右邻| 所需邻居| 行动|
 | ---| ---| ---| ---| ---|
 | 1 | 2 | 3 | 2 | 删除 1 |
 | 2 | 3 | 3 | 3 | 删除 2 |

 去掉1后，圆变成3、2。然后3去掉2，只留下最大值。 该迹线表明，连续的对在输入中不需要按升序排列，只需在所需时刻相邻即可。 

对于第二个样本：```
4
4 1 3 2
```| 检查当前值| 左邻居| 右邻| 所需邻居| 行动|
 | ---| ---| ---| ---| ---|
 | 1 | 4 | 3 | 2 | 失败|

 浆果 1 需要浆果 2 相邻，但两个邻居都是 4 和 3。后面的操作无济于事，因为浆果 1 是第一个需要删除的。 答案是否定的。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(N) | 每个 berry 都会初始化一次，最多删除一次 |
 | 空间| O(N) | 存储两个大小为 N + 1 的相邻数组 |

 该解决方案符合限制，因为它只为每个浆果执行恒定量的工作。 内存使用也是线性的，适合N最大为2 * 10^5。

import sys
import io

def solution(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    if n == 1:
        return "YES\n"

    left = [0] * (n + 1)
    right = [0] * (n + 1)

    for i, x in enumerate(a):
        left[x] = a[(i - 1) % n]
        right[x] = a[(i + 1) % n]

    for x in range(1, n):
        if left[x] != x + 1 and right[x] != x + 1:
            return "NO\n"
        l = left[x]
        r = right[x]
        right[l] = r
        left[r] = l

    return "YES\n"

assert solution("3\n1 3 2\n") == "YES\n", "sample 1"
assert solution("4\n4 1 3 2\n") == "NO\n", "sample 2"

assert solution("1\n1\n") == "YES\n", "single berry"
assert solution("5\n5 1 2 3 4\n") == "YES\n", "already removable chain"
assert solution("5\n5 4 1 2 3\n") == "NO\n", "wrong order around maximum"
assert solution("6\n2 3 4 5 6 1\n") == "YES\n", "circular boundary case"
```| 测试输入| 预期产出 | 它验证了什么 |
 | ---| ---| ---|
 |`1 / 1`| 是 | 空的动作序列|
 |`5 / 5 1 2 3 4`| 是 | 直接递增的去除链|
 |`5 / 5 4 1 2 3`| 否 | 诱人的第一步无法解决关卡的案例|

 ## 边缘情况

 对于单个浆果的情况：```
Input:
1
1
```该算法立即返回 YES，因为没有任何内容可以删除。 这可以避免尝试访问不存在的权重 2。 

对于示例失败案例：```
Input:
4
4 1 3 2
```该算法首先检查权重 1，因为移除顺序是强制的。 它的邻居是 4 和 3，因此重量 2 不能作为吃者。 算法立即停止并返回 NO。 

对于循环邻接情况：```
Input:
3
2 1 3
```链表将 1 的邻居存储为 2 和 3。第一次检查成功，因为 2 是左邻居。 删除 1 将连接 2 和 3，下一次检查也会成功。 该算法返回 YES，因为它正确地将数组视为圆而不是直线。
