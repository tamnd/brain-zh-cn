 ## 解决方案
 ## 问题理解

 我们必须构造两个完全不同的数字排列`1...N`。 

对于第一个排列`p`, 每个位置`i`必须接收不同的值，并且该位置及其分配值的按位与必须恰好为零。 

对于第二个排列`q`, 每个位置`i`必须再次接收不同的值，但现在按位 AND 必须严格为正。 

输入仅包含一个整数`N`, 直至`10^5`。 这立即排除了任何对排列的搜索。 甚至一个`O(N^2)`建设成本将不必要地昂贵。 我们需要一个直接的构造模式来在线性时间内填充排列。 

第一个不明显的边缘情况是奇怪的`N`在第一个任务中。 每个奇数索引都以二进制结尾`1`。 获得`i & p[i] = 0`，分配给奇数索引的值必须是偶数。 什么时候`N`是奇数，奇数比偶数多，因此至少有一个奇数索引不能接收不同的偶数值。 例如：```
N = 3
```指数`1`和`3`都是奇数，但只有一个偶数存在，即`2`。 不存在解决方案。 

第二个重要的边缘情况是`N`是第二个任务中的 2 的幂。 考虑`N = 8`。 数字`8`仅设置了最高位。 范围内`1...8`，唯一共享该位的数字是`8`本身。 由于固定点被禁止，位置`8`不能分配任何有效值。 同样的论证适用于二的每一个幂。 

第三个陷阱是较小的值`N`。 即使当`N`不是 2 的幂，第二个排列仍然不存在`N < 6`。 例如，详尽的检查表明`N = 5`到处都没有正 AND 的有效混乱。 

## 方法

 蛮力方法将生成排列并测试每个位置所需的条件。 

对于第一个任务，这意味着检查每对是否`(i, p[i])`满足`i & p[i] = 0`。 对于第二个任务，我们检查`i & q[i] > 0`。 

正确性是立竿见影的，因为我们直接验证了定义。 问题是排列的数量。 即使是为了`N = 15`, 已经有`15! ≈ 1.3 × 10^12`候选人。 实际限制是`10^5`，所以暴力破解是完全不可能的。 

关键的观察是按位 AND 约束自然地按二进制结构对数字进行分组。 

对于第一个排列，由以下形式的掩码界定的区间内的数字`2^k - 1`具有天然的互补性。 如果```
x + y = 2^k - 1
```那么每一点都是`1`在`x`是`0`在`y`，反之亦然。 因此`x & y = 0`。 

对于第二个排列，共享相同最高设置位的数字自动具有正与。 如果我们在这样的块内循环旋转数字，则每个位置都会收到不同的值，并且共同的最高位保证正与。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(N!)`|`O(N)`| 太慢了|
 | 最佳施工|`O(N)`|`O(N)`| 已接受 |

 ## 算法演练

 ### 第一个排列 (`i & p[i] = 0`）

 1.如果`N`为奇数，输出`NO`。 
2. 否则，令`r = N`。 
3. 找到表格中最小的掩码`2^k - 1`这样`mask >= r`。 
4.让`l = mask - r`。 
5. 对于每一个`x`在`[l, r]`， 分配```
p[x] = mask - x
```因为`x`和`mask - x`是掩码内的按位补码。 
6. 对剩余的前缀继续递归`[1, l-1]`。 

每个区间都是独立配对的，并且每个数字都恰好出现一次。 

### 第二个排列 (`i & q[i] > 0`）

 1.如果`N < 6`或者`N`是2的幂，输出`NO`。 
2. 对前七个数字使用固定底座结构：```
q[1..7] = [3, 6, 2, 5, 1, 7, 4]
```3. 对于每个块```
[2^k , min(N, 2^(k+1)-1)]
```和`2^k >= 8`，将块循环移位一位。 
4. 如果块是```
a, a+1, ..., b
```分配```
a -> a+1
a+1 -> a+2
...
b -> a
```同一块中的所有数字共享最高位`2^k`，因此每个分配的对都有正与。 

### 为什么它有效

 对于第一个排列，每个赋值的形式为```
x <-> (mask - x)
```在哪里`mask = 2^k - 1`都是二进制的。 这两个数字是其中的精确按位补码`k`位，因此它们的 AND 为零。 由于两次补码返回原始数字，因此映射是完美的配对，因此是排列。 

对于第二个排列，每个块都由具有相同最高设置位的数字组成。 循环移动永远不会产生固定点。 由于每个指定对中的两个数字都包含最高位，因此它们的 AND 至少包含该位并且严格为正。 基础块为`1...7`处理唯一麻烦的小数字。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_first(n):
    if n % 2:
        return None

    p = [0] * (n + 1)
    r = n

    while r > 0:
        mask = 1
        while mask - 1 < r:
            mask <<= 1
        mask -= 1

        l = mask - r
        for x in range(l, r + 1):
            p[x] = mask - x

        r = l - 1

    return p[1:]

def build_second(n):
    if n < 6 or (n & (n - 1)) == 0:
        return None

    q = [0] * (n + 1)

    base = [3, 6, 2, 5, 1, 7, 4]
    for i in range(1, min(n, 7) + 1):
        q[i] = base[i - 1]

    start = 8
    while start <= n:
        end = min(n, (start << 1) - 1)

        for x in range(start, end):
            q[x] = x + 1
        q[end] = start

        start <<= 1

    return q[1:]

def solve():
    n = int(input())

    p = build_first(n)
    if p is None:
        print("NO")
    else:
        print("YES")
        print(*p)

    q = build_second(n)
    if q is None:
        print("NO")
    else:
        print("YES")
        print(*q)

solve()
```第一个函数重复查找覆盖当前后缀的最小全一掩码。 该后缀中的每个数字都与其掩码内的补码配对。 变量`r`每一步之后缩小到未处理的前缀。 

第二个功能从特别安排开始`1...7`。 之后，每个2的幂块都会循环旋转。 最后一个元素回绕到块的第一个元素，防止固定点。 

一个常见的实施错误是在第一次构造中错误地计算区间边界。 间隔必须是`[mask - r, r]`， 不是`[mask - r + 1, r]`。 缺少一个端点会破坏排列属性。 

另一个常见的错误是尝试旋转方块`[1]`在第二次施工中。 该块的大小为一，不能产生混乱。 特殊的基地建设完全避免了这个问题。

 ## 边缘情况

 对于`N = 3`，第一个构造失败，因为有两个奇数位置且只有一个偶数值。 该算法检测奇数`N`立即并打印`NO`。 

为了`N = 8`，第二次构建失败，因为位置`8`需要不同的号码共享位`8`，但里面不存在这样的数字`1...8`。 二次幂检查在施工开始前捕获了这种情况。 

为了`N = 5`，第二次构建也是不可能的。 该算法拒绝所有`N < 6`，直接覆盖这个小的特殊范围。 

在这些情况下，朴素的构造模式会默默地产生无效的固定点或零 AND 值。
