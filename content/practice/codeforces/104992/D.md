 ## 解决方案
 ## 问题理解

 训练过程会产生一系列练习。 每个练习都有猫头鹰提供的“正确答案”和格里沙写的答案。 同一个练习可能会出现多次，因为如果格里沙的答案不被接受，猫头鹰稍后会重复该练习。 

对于每次出现，我们都会得到两个字符串：首先是 Grisha 的答案，然后是正确答案。 尽管字符串在格式上可能略有不同，但接受规则是宽松的：忽略字母大小写、标点符号和词序的差异，并且根据相同的规范化思想，较小的拼写变化被视为不相关。 实际上，这意味着如果两个答案在删除标点符号和大小写差异后由同一组单词组成，则应被视为等效，并且单词顺序不再重要。 

任务不是对每次尝试的不匹配进行计数。 相反，我们必须计算格里沙第一次出现时失败了多少种不同的练习。 一旦第一次正确回答某个练习，以后重复该练习就与答案无关。 

关键的观察结果是，练习的身份是由标准化后的正确答案决定的，因为相同的任务总是带有相同的正确解决方案字符串。 因此，我们只关心每个标准化正确答案第一次出现的时间以及 Grisha 的标准化响应是否与其匹配。 

这些限制允许最多 40,000 次尝试，总输入大小最多为 200,000 个字符。 这排除了任何以二次方式重复比较字符串的解决方案。 每个字符串的线性或近线性预处理就足够了，但只要我们正确聚合，由于总长度较小，不小心对大型结构进行重复排序仍然会通过。 

当同一个练习多次出现并且首先回答错误，然后又回答正确时，就会出现微妙的边缘情况。 例如，如果练习“A”首先出现错误，然后又出现，我们仍然必须只计算一次。 另一个边缘情况是，表面上看起来不同的两个字符串实际上可能在标准化下代表相同的答案，因此直接字符串比较会错误地计算错误。 

## 方法

 强力解释将独立处理每一对字符串，并根据自定义等效规则直接比较两个字符串。 对于 n 对中的每一对，我们将通过小写、去除标点符号、拆分为单词、对它们进行排序然后进行比较来规范化两个字符串。 就复杂性而言，这已经是可以接受的，因为总输入大小很小，但简单的实现可能会意外地多次重新处理相同的正确答案或尝试以嵌套方式重复标准化，从而导致不必要的开销。 

关键的结构见解是每个练习在标准化后都由其正确答案唯一标识。 由于同一任务的重复出现总是重复使用相同的正确字符串，因此我们可以按该标识符对尝试进行分组。 我们只需要知道每个标识符的第一次出现是否正确。 

这减少了维护以标准化正确答案为键的字典的问题。 对于每个新对，我们计算两个字符串的规范表示并比较它们。 如果之前没有见过该任务，我们会根据正确性决定是否增加答案，然后将其标记为已见过。 稍后发生的事件将被忽略。

 ## 算法演练

 1.读取尝试次数n，然后将2n行处理为n对（Grisha的答案，正确答案）。 每一对对应一次提交尝试。 
2. 对于每个字符串，通过提取单词、将其转换为小写并对结果单词列表进行排序，将其转换为规范形式。 这种转换消除了对标点符号、大写和词序的敏感性。 
3. 使用此规范形式构建正确答案的密钥。 该密钥代表练习的身份。 
4.维护一个字典，存储我们是否已经处理过这个练习以及它的第一次出现是否正确。 
5. 当第一次遇到新的练习题时，比较 Grisha 答案和正确答案的规范形式。 如果它们不同，则增加错误计数器。 
6. 将练习标记为已看到的，以便忽略以后的重复。 

核心思想是，第一个出现的情况是唯一可以对答案做出贡献的。 以后的任何重复都不会影响计数，因为练习已经解决。 

### 为什么它有效

 规范表示将所有等效答案折叠成相同的字符串。 由于同一练习的所有重复都具有相同的正确答案，因此它们共享相同的规范密钥。 字典确保仅评估每个键的第一次出现，因此每个练习最多对最终计数做出一个决定。 这保证了正确性，因为问题询问的是每个不同练习的首次尝试正确性，而不是每次外观。 

## Python 解决方案```python
import sys
import re
input = sys.stdin.readline

def normalize(s: str):
    words = re.findall(r"[a-zA-Z]+", s.lower())
    words.sort()
    return " ".join(words)

n = int(input())
seen = {}
errors = 0

for _ in range(n):
    grisha = input().rstrip("\n")
    correct = input().rstrip("\n")

    key = normalize(correct)
    if key not in seen:
        if normalize(grisha) != key:
            errors += 1
        seen[key] = True

print(errors)
```该解决方案使用相同的标准化例程为学生的答案和正确答案构建规范表示。 正则表达式提取单词，同时忽略标点符号和空格。 排序可确保词序差异不会影响相等性。 字典会跟踪我们是否已经处理过给定的练习，确保只有第一次出现的练习才能得出答案。 

一个常见的错误是比较原始字符串或仅比较小写版本，当词序更改或插入标点符号时，这种错误会失败。 另一个原因是忘记删除重复任务，这会导致错误计数过多。
