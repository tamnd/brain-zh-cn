 ## 解决方案
 ## 问题理解

 我们正在研究一个由相同动物组成的系统，其中每只动物每餐消耗固定整数数量的胡萝卜。 对于特定动物来说，每餐的每餐量是相同的，并且对于所有动物来说也是相同的。 唯一的可变性是不同的动物可能选择不同的整数，但每个这样的整数必须位于固定范围内$[a, b]$。 

我们得知所有动物在两顿饭中消耗的胡萝卜总数是$n$。 由于每只动物在两餐中吃的量相同，因此吃$x$每餐胡萝卜的贡献正好$2x$胡萝卜总数。 如果有$k$动物每餐消耗值$x_1, x_2, \dots, x_k$，则总计为$$2(x_1 + x_2 + \dots + x_k) = n.$$所以问题就变成了问我们是否可以代表$n/2$作为总和$k$整数，每个都在范围内$[a, b]$，我们想要最大化$k$。 

约束条件达到$10^{15}$，因此任何试图枚举候选者或模拟分区的解决方案都是立即不可行的。 甚至迭代所有可能的值$k$或者所有可能的组合都会太慢，因为$k$它本身可能有那么大$10^{15}$。 

第一个重要的观察结果是，如果$n$奇怪的是，情况不可能立即发生。 由于每项贡献都是$2x$，总数必须是偶数。 

另一个微妙的失败案例发生在$n/2$太小或太大而无法表示为值的总和$[a, b]$。 例如，如果$n = 10$,$a = 6$,$b = 7$，那么每只动物在两餐中总共贡献 12 到 14 根胡萝卜。 即使是一只动物也已经超过 10 个，所以正确答案是$-1$。 仅检查能否被 2 整除的简单方法会错误地输出 1 或更多。 

同样，如果$n/2$很大但约束太紧，例如$n = 9$,$a = 2$,$b = 5$， 然后$n/2 = 4.5$不是整数，因此即使局部边界看起来兼容，答案也立即无效。 

关键的困难在于，我们不是单独为每餐分配值，而是为受全局可行性约束的每只动物的固定整数分配值。 

## 方法

 蛮力的观点将尝试确定有多少动物$k$我们可以通过测试是否$n/2$可以分解为$k$之间的整数$a$和$b$。 对于固定的$k$，我们需要检查是否有一个总和$k$值在$[a, b]$可以等于$S = n/2$。 这相当于检查是否$$k \cdot a \le S \le k \cdot b.$$如果这成立，那么通过分配剩余的这种分解就存在$a$均匀地分布在某些元素上，并在范围内进行调整。 

所以对于每一个$k$，检查可行性是常数时间。 蛮力方法会尝试所有$k$从$1$到$S/a$。 在最坏的情况下，当$a = 1$，这意味着迭代到$10^{15}$值，这是完全不可行的。 

关键的观察是可行性仅取决于涉及的不平等$k$，而不是关于分区的内部结构。 一旦我们重写条件$$k \cdot a \le S \le k \cdot b,$$我们可以隔离$k$:$$\frac{S}{b} \le k \le \frac{S}{a}.$$因此问题就简化为寻找最大整数$k$满足这些界限，即：$$k_{\max} = \left\lfloor \frac{S}{a} \right\rfloor,$$前提是这个$k$也满足$k \cdot b \ge S$。 如果不是，则无效$k$存在。 

这将整个组合结构折叠为单个区间检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解结束$k$|$O(S/a)$|$O(1)$| 太慢了 |
 | 减少不平等 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 计算$S = n / 2$。 如果$n$为奇数，立即返回$-1$。 这是必需的，因为每项贡献都会因建设而加倍。 
2. 计算最大可能的动物数量为$k = \left\lfloor S / a \right\rfloor$。 这相当于使用每只动物允许的最小消耗量来最大化计数。 
3. 检查该候选人是否$k$通过验证最大可能总数是有效的$k$动物，即$k \cdot b$，至少是$S$。 如果没有，即使是最慷慨的分配也无法达到所需的总数。 
4. 如果检查通过，则输出$k$。 否则，输出$-1$。 

### 为什么它有效

 每只动物贡献一个独立的整数$[a, b]$，因此可实现的总和的集合$k$动物正是区间$[k a, k b]$。 没有间隙，因为我们可以在保持范围内的同时将一只动物的价值增加 1。 因此，可行性简化为检查是否$S$对于某些人来说位于这个区间内$k$。 选择最大可行的$k$相当于推$k$直到下界约束$k a \le S$是紧的，同时确保上限仍然覆盖$S$。 这保证了正确性和最大化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())
a = int(input().strip())
b = int(input().strip())

if n % 2 == 1:
    print(-1)
    sys.exit()

S = n // 2

k = S // a

if k == 0:
    print(-1)
    sys.exit()

if k * b < S:
    print(-1)
else:
    print(k)
```该代码首先强制执行奇偶校验约束，因为所有有效总数都是偶数。 然后它将问题减少到与$S = n/2$，每餐消耗的总和。 

表达式`S // a`在每只动物允许的最小消耗量下选择最大可能的动物数量。 后续条件`k * b < S`验证即使最大化每只动物的消耗是否仍然无法达到所需的总和，这意味着不存在有效的配置。 

明确的`k == 0`检查处理以下情况$S < a$，这意味着即使是一只动物也不能被分配有效值。

 ## 边缘情况

 当$n$是奇数，比如$n = 1$，算法立即拒绝它，因为$S = n/2$不是整数，因此每个动物的整数分配都不能产生有效的总数。 

什么时候$S < a$， 例如$n = 5$,$a = 3$,$b = 10$，我们得到$S = 2$。 计算给出$k = 0$，算法返回$-1$，正确反映即使是一只动物也不能被分配有效的消耗。 

当每只动物的最低消耗量较大时，例如$n = 100$,$a = 60$,$b = 70$，我们得到$S = 50$，甚至一只动物都已经超过了总数。 条件$k = S // a = 0$触发拒绝，正确处理这个边界。 

什么时候$a = b$， 例如$a = b = 5$，唯一可能的总和结构是刚性的。 该算法简化为检查是否$S$可以整除$5$，并返回$k = S/5$如果有效，否则$-1$。
