 ## 解决方案
 ## 问题理解

 我们被赋予了一个居住着两种生物的世界。 第一种类型的每个生物正好有 1 个头和 19 条腿，而第二种类型的每个生物正好有 7 个头和 4 条腿。 我们被告知在这个世界上观察到的头的总数和腿的总数。 任务是确定每种类型可以存在多少个生物，以便头数和腿数完全匹配。 如果存在多个有效分解，则其中任何一个都是可接受的。 如果不可能分解，我们必须报告不可能。 

输入由两个整数组成。 第一个是头的总数，它限制了两种生物类型的线性组合。 第二个是腿的总数，它提供了第二个线性约束。 输出是一对非负整数，描述存在每种类型的生物数量，如果不存在解，则输出 -1。 

尽管边界允许的值高达 10^8，但该结构本质上不是组合的。 我们正在求解两个变量的两个线性方程组，但具有非负约束并且要求解为整数。 这立即将问题置于常数时间代数求解而不是搜索中。 

一种天真的方法会尝试尝试一种生物的所有可能计数，并从头部方程中推断出另一个生物，检查腿部方程是否匹配。 这可以工作，但没有必要，并且在最坏的情况下概念上最多可以循环 10^8 次迭代，这太慢了。 

边缘情况是由可分性限制以及头部和腿部之间不匹配的奇偶校验结构引起的。 一种常见的故障模式是假设头部方程始终唯一地确定计数而不验证腿部一致性。 另一个问题是忽视了一个物种的头部数量远多于另一物种的腿部数量，这使得看似不可行的系统表面上看起来是可以解决的。 

例如，如果我们有 2 个头和 19 条腿，人们可能会错误地假设存在两个单头生物，但随后腿数立即变得不一致。 仅当两个方程同时执行时才会出现矛盾。 

## 方法

 该问题简化为求解线性方程组。 设 x 为 1 头 19 腿生物的数量，y 为 7 头 4 腿生物的数量。 然后：

 x + 7y = A

 19x + 4y = B

 暴力方法会迭代 y 从 0 到 A // 7 的所有可能值。对于每个 y，计算 x = A - 7y 并检查它是否为非负值并满足腿方程。 这是正确的，因为每个有效的解决方案都必须同时满足这两个约束。 然而，在最坏的情况下，A 可以是 10^8，最多可进行 1.4 × 10^7 次迭代，这对于单一测试问题来说是临界值并且是不必要的。 

关键的观察结果是，这是一个 2×2 线性系统，当它存在时，具有唯一的代数解。 我们可以直接消除变量。 将 x = A - 7y 代入第二个方程：

 19(A - 7y) + 4y = B

 19A - 133y + 4y = B

 19A - 129y = B

 129y = 19A - B

 所以 y 由右边唯一确定。 一旦 y 已知，x 就直接跟随。 剩下的唯一任务是验证 y 是整数并且 x 和 y 都是非负数。 

这将问题转化为具有少量检查的恒定时间算术。

 | --- | --- | --- | --- |
 | 蛮力 | O(A/7) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们采用排除法求解系统，然后验证可行性。

1. 使用头约束以 y 表示 1 头生物 x 的数量：x = A - 7y。 这将系统从两个变量减少到一个。 
2. 将此表达式代入腿方程：19(A - 7y) + 4y = B。此步骤确保同时而不是独立地强制执行两个约束。 
3. 简化方程以分离 y：19A - 129y = B，得出 y = (19A - B) / 129。这是可以同时满足两个方程的 y 的唯一可能值。 
4. 检查(19A - B)是否能被129整除。如果不能整除，则不存在整数解，因此输出-1。 这强制了完整性，这是必需的，因为生物计数必须是整数。 
5. 计算 y，然后计算 x = A - 7y。 一旦 y 得到验证，就会重建完整的解决方案。 
6. 验证 x 和 y 均为非负数。 如果其中一个为负，则该解在计数生物的物理意义上是无效的，因此输出-1。 

### 为什么它有效

 该系统由两个独立的整数线性约束组成。 任何有效解必须同时满足这两个条件，并且消除表明 y 由 A 和 B 中的单个线性表达式唯一确定。由于变换保持等价性，因此导出方程的任何整数解都精确对应于原始系统中的有效对 (x, y)。 因此，检查整除性和非负性足以确定存在性并恢复解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    A, B = map(int, input().split())

    numerator = 19 * A - B
    denom = 129

    if numerator % denom != 0:
        print(-1)
        return

    y = numerator // denom
    x = A - 7 * y

    if x < 0 or y < 0:
        print(-1)
        return

    print(x, y)

if __name__ == "__main__":
    solve()
```该解决方案首先将代数消除步骤直接编码为 y 的单个表达式。 除法检查确保我们永远不会假设生物计数的分数。 计算 y 后，x 从头约束导出，而不是从腿重新计算，这避免了冗余算术，并通过保留整数来完全降低浮点风险。 

最后的验证步骤是必要的，因为单独的代数运算并不能强制非负性； 它仅确保方程的一致性。

 ### 示例 1

 输入：A = 23，B = 50

 | 检查整除性 | 387 / 129 | 3 |

 | 计算 x | A - 7 岁 | 23 - 21 = 2 |

 这证实了存在一致的分解。 所得计数完全满足这两个约束。 

### 示例 2

 | 步骤| 表达 | 价值|
 | --- | --- | --- |
 | 计算分子 | 19A-B| 38 - 19 = 19 | 38 - 19 = 19

 失败的发生是因为生物的任何整数组合都无法满足腿部约束，即使仅从头数就可以得出简单的解释。

 ## 边缘情况

 当系统为 y 生成小数值时，即使 A 和 B 都是有效整数，也会出现微妙的边缘情况。 例如，A = 2，B = 19 生成分子 19·2 - 19 = 19，该分子不能被 129 整除。算法通过整除性检查立即检测到这一点，从而防止任何解释生物计数分数的尝试。 

另一种边缘情况是当代数产生负 y 时。 这对应于任何有效混合物的腿数相对于头数太大的情况。 在这种情况下，计算出的 y 违反非负约束并被明确拒绝，即使线性系统具有可行区域之外的数学解，也能确保正确性。
