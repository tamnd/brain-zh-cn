 ## 解决方案
 ## 问题理解

 我们被要求猜测一个隐藏的数字`x`之间`1`和`c`通过查询所选基数中的数字之和。 每个查询指定一个基数`b`（之间`2`和`c`) 并返回数字之和`x`在那个基地，或者`-1`如果`x`小于`b`。 我们有严格的限制`k = 4`每个数字的查询次数，并且数字本身可能非常大，最多可达`4 × 10^18`。 最多可以有`10^4`连续猜测的数字。 

尝试所有数字的天真方法`1`到`c`是不可能的，因为`c`是巨大的，并且根据数字总和检查每个数字将花费远远超过允许的操作。 此外，交互器是非自适应的，这意味着每个数字都是固定的并且独立于之前的查询，因此我们可以规划查询而不必担心反馈循环。 

一个棘手的方面是查询可能会返回`-1`如果基数大于隐藏数。 这是一种边缘情况，因为它立即识别出该数字小于所选基数。 例如，如果`x = 3`我们查询基地`5`，交互器返回`-1`。 任何不处理的实现`-1`正确地可能会将结果误解为数字之和。 

另一个微妙的点是其庞大的规模`c`。 我们不能依赖暴力枚举，如果我们尝试天真地操作非常大的数字，则可能会发生整数溢出。 这个问题本质上是关于从一些模块化约束中重建一个数字。 

## 方法

 暴力方法会尝试依次查询较小的基数并尝试进行逆向工程`x`通过模拟所有适合响应的数字。 这在原则上是正确的，因为数字之和唯一地标识给定基数中的数字，但这是不可行的。 每个查询都会给出以下形式的一条信息`sum_digits(x, b) ≡ x mod (b-1)`，因为基数中的数字之和`b`与数字模一致`b-1`。 仅使用四个查询，我们需要一种利用这种模块化结构的方法。 

关键的观察是对于任何数字`x`,`x % (b-1)`等于数字之和`x`在基地`b`。 这是数字和数字和的经典属性。 因此，每个查询有效地为我们提供了`x modulo (b-1)`。 如果我们选择两两差互质的四个基，我们可以应用中国剩余定理来唯一地重构`x`对乘积取模`(b-1)`对于那些基地。 如果我们仔细选择这些碱基，产品将超过`c`，因此我们恢复了`x`确切地。 

最佳方法是选择四个大的、不同的二的幂，因为二减一的幂是互质的。 例如，`b1 = 2^1`,`b2 = 2^2`,`b3 = 2^4`,`b4 = 2^8`给出`b1-1 = 1`,`b2-1 = 3`,`b3-1 = 15`,`b4-1 = 255`。 这些模是互质的，它们的乘积远大于`c`。 对于每个查询，我们计算余数模`b_i-1`使用数字和，然后重建`x`使用中国剩余定理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(c) | O(1) | O(1) | 太慢了 |
 | 最佳（CRT + 数字总和）| 每个查询 O(1)，每个数字 O(k) | O(k) | 已接受 |

 ## 算法演练

 1. 预先计算四个基数，使得`(b_i - 1)`互质且其乘积超过`c`。 例如，使用`b = 2, 3, 4, 5`或其他较小的 2 的幂向上移动。 
2. 对于每个要猜测的数字，使用四个碱基中的每一个查询交互器。 阅读答案，即数字之和，或者`-1`如果`x < b`。 如果`-1`发生，我们知道`x`小于该基数，因此我们进行调整。 
3. 将每个数字和转换为模余数：`remainder_i = sum_digits_i mod (b_i - 1)`。 这是有效的，因为`x ≡ sum_digits(x, b_i) (mod b_i - 1)`。 
4.利用中国剩余定理重构`x`对乘积取模`(b_i - 1)`。 因为产品超过`c`，这唯一地决定了`x`。 
5、输出`! x`提交猜测并阅读验证响应。 
6. 对每个数字重复此操作`t`。 

为什么它有效：每个查询都给出一个约束`x ≡ sum_digits(x, b_i) mod (b_i-1)`。 自从`(b_i-1)`是成对互质的，并且它们的乘积超过`c`，CRT 保证了独特的解决方案`[1, c]`。 使用数字和作为模余数是关键的数学属性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def chinese_remainder_theorem(remainders, moduli):
    x = 0
    M = 1
    for m in moduli:
        M *= m
    for r, m in zip(remainders, moduli):
        Mi = M // m
        # compute inverse of Mi mod m
        inv = pow(Mi, -1, m)
        x += r * Mi * inv
    return x % M

t, k, c = map(int, input().split())

# choose bases so that b-1 are coprime
bases = [2, 3, 4, 5]
moduli = [b - 1 for b in bases]

for _ in range(t):
    remainders = []
    for b in bases:
        print("?", b)
        sys.stdout.flush()
        res = int(input())
        if res == -1:
            remainders.append(0)
        else:
            remainders.append(res % (b - 1))
    x = chinese_remainder_theorem(remainders, moduli)
    print("!", x)
    sys.stdout.flush()
    r = int(input())
    if r == 0:
        sys.exit()
```该解决方案首先选择基数使得`b-1`是互质的。 每个查询都会产生一个数字之和，该数字之和将被转换为模余数。 这`chinese_remainder_theorem`函数重构`x`唯一，并提交猜测。 边缘情况，例如`-1`通过将余数设置为来处理响应`0`，这是有效的，因为任何小于基数的数字都与其自身模一致`b-1`。
