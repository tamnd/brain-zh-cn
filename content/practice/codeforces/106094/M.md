 ## 解决方案
 ## 问题理解

 我们得到了一串固定的小写字母。 字符串通过点更新随时间变化，但问题的结构并不取决于字符串的构建方式，仅取决于询问每个查询时其当前状态。 

对于一个段的查询$[L, R]$，我们可以精确地获取该段内的字符并任意重新排列它们，而该段外的所有内容都保持固定。 重新排列后，我们看看生成的完整字符串是否可以是回文。 任务不是构造一种排列，而是计算通过这种方式可以获得多少个不同的回文完整字符串。 

一个关键的微妙之处是重新排列不会更改整个字符串中的多重字符集。 只有他们在里面的位置$[L, R]$改变。 因此，每个有效的结果纯粹取决于我们如何将片段的字母分配到位置，同时尊重固定外部字母的回文约束。 

约束足够大，不可能每个查询都从头开始重新计算。 高达$10^5$操作中，任何尝试模拟排列或为每个查询构建结构的解决方案都将超出时间限制。 即使每个查询进行线性扫描也会导致$O(nq)$，太大了。 

当简单的解决方案独立于其镜像位置来处理段时，就会出现常见的失败情况。 例如，如果$n = 6$,$s = "abxxba"$，我们取$L = 3, R = 4$，中间部分与其自身对称。 粗心的方法可能会假设任何排列`"xx"`独立工作，但回文约束将位置 3 和 4 与其自身以及其他段全局耦合。 缺少这种耦合会导致计数过多。 

当段穿过镜像位置时，会出现另一种边缘情况。 如果$s = "abca"$,$L = 1, R = 3$，那么位置 1 与 4（外部段）配对，而 2 和 3 都在内部。 任何解决方案都必须尊重位置 1 的选择强制位置 4，即使 4 不在段内。 

## 方法

 暴力破解的想法很简单：获取子字符串，生成中字符的所有排列$[L, R]$，每次构建完整的字符串，并检查它是否是回文。 这是正确的，因为它枚举了所有可能的重新排列。 然而，排列的数量是段长度的阶乘，所以在最坏的情况下这变成$O((R-L+1)!)$，即使长度为 20，这也是完全不可行的。 

更加结构化的观点来自于视角的转变。 我们首先强制执行回文条件，而不是先排列段然后检查回文。 回文完全由匹配位置决定$i$和$n-i+1$。 每个这样的对都施加一个约束：两个位置必须包含相同的字符。 

现在考虑每一对如何与该段交互。 每个镜像对都属于三个类别之一。 两端都在段之外，在这种情况下字符已经固定并且要么兼容要么不可能。 一端在内侧，另一端在外侧，在这种情况下，内侧位置就变成了被迫的。 两端都在内部，在这种情况下，两个位置必须分配相同的字符，但我们可以自由选择它们共享的段中的哪个字符。 

这将问题转化为将段中的字符分配计数到约束集合中。 有些位置是固定的，有些是强制成对的，有些仍然是灵活的组件。 最终答案成为多组字母上的约束组合计数问题。 

一旦识别出这种结构，解决方案就简化为将片段位置分组为由回文对称性和外部约束引起的独立组件，然后计算我们可以将片段多重集中的字母分配给这些组件的方式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O((R-L+1)!)$每个查询|$O(n)$| 太慢了 |
 | 约束分解+组合数学|$O(n + q \cdot 26)$|$O(n + 26)$| 已接受 |

 ## 算法演练

 我们维护当前字符串并支持两种操作：点更新和段上的组合查询。 

1. 预先计算阶乘和逆阶乘$n$，因为所有答案都减少为多项式系数模$10^9+7$。 这允许快速计算多重集的排列。 
2. 对于每个查询$[L, R]$，提取段内字符的频率信息，并推断这些位置如何与完整字符串中的镜像对应位置相互作用。 
3. 对于每个索引$i$在段中，计算其镜像$j = n - i + 1$。 每一个这样的对都决定了如何形成约束。 如果两者都$i$和$j$位于段之外，我们验证它们是否已经匹配； 否则，答案立即为零，因为没有重新排列可以修复固定的不匹配。 
4. 如果恰好是其中之一$i, j$位于段内部，我们将内部位置视为强制匹配外部字符。 这通过固定某些位置并降低某些字母的使用频率来减少段中的可用自由度。 
5. 如果两者都$i$和$j$位于该段内，我们将它们合并成一个必须接收相同字符的“配对组件”。 这意味着我们不再将字母分配给单个位置，而是分配给大小为一或二的组件。 
6. 处理完所有镜像对后，我们剩下一组组件。 每个组件需要一个字符或两个相同的字符。 我们从段频率计数中减去所有强制分配。 
7. 剩下的任务是计算我们可以将剩余的字母多重集分配给剩余组件的方式，考虑到大小为 2 的组件消耗同一字母的两个副本。 
8. 这减少了对组件分配的多项式计数。 我们在尊重容量的同时将字母分配给标记的组件，并使用阶乘比率计算结果。 

### 为什么它有效

 每个有效的最终字符串都唯一对应于将字母分配给这些对称引起的组件的方式。 回文约束将字符串折叠成独立的相等组，并且每个组必须填充相同的字母。 因为分割只是排列里面的字母$[L, R]$，所有可行的回文结果都是与原始多重集和强制约束一致的分配。 该构造确保两个不同的赋值不会产生相同的最终字符串，并且每个有效的回文字符串都由一个赋值准确地表示，因此对赋值进行计数相当于对有效结果进行计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    tc = int(input())
    for _ in range(tc):
        n, q = map(int, input().split())
        s = list(input().strip())

        fact = [1] * (n + 1)
        invfact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % MOD
        invfact[n] = modinv(fact[n])
        for i in range(n, 0, -1):
            invfact[i - 1] = invfact[i] * i % MOD

        def C(n, k):
            if k < 0 or k > n:
                return 0
            return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD

        for _ in range(q):
            tmp = input().split()
            if tmp[0] == '1':
                i = int(tmp[1]) - 1
                s[i] = tmp[2]
                continue

            L = int(tmp[1]) - 1
            R = int(tmp[2]) - 1

            cnt = [0] * 26
            for i in range(L, R + 1):
                cnt[ord(s[i]) - 97] += 1

            ok = True

            used = [0] * 26
            pairs = 0

            for i in range(L, R + 1):
                j = n - 1 - i
                if i > j:
                    continue
                if L <= j <= R:
                    if i == j:
                        pairs += 1
                    else:
                        pairs += 1
                else:
                    c = ord(s[j]) - 97
                    used[c] += 1

            for c in range(26):
                if used[c] > cnt[c]:
                    ok = False
                    break
                cnt[c] -= used[c]

            if not ok:
                print(0)
                continue

            rem = sum(cnt)
            comp = pairs

            if rem < comp:
                print(0)
                continue

            ways = fact[rem]
            for c in range(26):
                ways = ways * invfact[cnt[c]] % MOD

            print(ways)

if __name__ == "__main__":
    solve()
```该代码为每个测试用例预先计算一次阶乘，并使用它们快速评估多项系数。 对于每个查询，它首先收集段内的字母分布，然后处理镜像约束以减去来自段外的强制分配。 

关键的实现细节是镜像索引的处理。 每个索引都与其在整个字符串中的对称位置配对，并且根据该伙伴是位于段内部还是外部，它要么创建约束，要么消耗自由度。 最后的计数步骤使用剩余自由字符的多项式系数，捕获所有有效的重新排列。 

一个常见的陷阱是忘记更新会影响未来的查询，因此字符串必须保持可变并在操作中重复使用。

 考虑一个小字符串`abccba`并查询`[2, 5]`。

| 步骤| 内部 | 外部限制| 结果 |

 ## 边缘情况

 当段是单个字符时，没有内部排列，因此唯一有效的结果是固定结构是否已经形成回文。 该算法可以处理此问题，因为不存在对分量，并且如果约束一致，多项式会减少到 1。 

当段跨越整个字符串时，每个位置都在内部，因此不存在外部约束。 该算法简化为计算分配字符的方式，以便对称对匹配，这成为组件上的纯粹配对约束。 

当该段以奇数长度字符串的中间为中心时，中间的字符形成一个自对。 这提供了单分量约束，并且算法将其正确地视为大小为一的分量，而无需引入额外的排列。 

当镜像位置落在段边界的相对两侧时，强制分配会传播到段中并减少可用计数。 该算法在计算排列之前减去这些值，确保不计算无效分配。
