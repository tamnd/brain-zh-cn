 ## 解决方案
 ## 问题理解

 我们得到一个从 1 到 1 的数字排列的前缀和派生的数组$n$。 这些前缀和之一缺失。 我们的任务是确定不完整的数组是否来自有效的排列。 

这里的排列只是一个包含从 1 到$n$正好一次。 前缀和数组是通过对元素进行累加求和而形成的：$b_i = a_1 + a_2 + ... + a_i$。 例如，排列$[1, 3, 2]$有前缀和$[1, 4, 6]$。 如果我们删除一个前缀和，比如 4，数组就变成$[1, 6]$。 问题是确定是否存在在删除单个前缀和后导致给定数组的排列。 

这些限制条件使我们能够$2 \cdot 10^5$所有测试用例的数字总和，因此任何解决方案都必须大致运行$O(n)$每个测试用例。 所有排列的暴力重建是完全不可行的，因为$n!$增长速度极快。 

当缺失元素是排列中最大的数字时，就会出现微妙的边缘情况。 例如，如果$n = 4$输入前缀和是$[1, 3, 6]$，缺失的和对应于最后一个元素 4，我们必须认识到这种情况。 另一个棘手的情况是删除前缀和隐藏了一个可能重复的数字，例如，$[1, 3, 3]$看起来不可能，但可能对应于缺失的 2$[1, 3, 5, 6]$。 仅检查连续前缀和之间的差异的粗心方法可能会在这里失败。 

## 方法

 暴力方法将尝试通过尝试在所有可能的位置插入一个数字并检查结果数组是否形成有效的排列，从给定的前缀和重建所有可能的原始数组。 这原则上是正确的，因为每个前缀和唯一地定义累积和，但可能性的数量是$O(n)$每个测试用例的插入和$O(n)$每次插入都进行工作以验证排列，从而导致$O(n^2)$。 这对于$n \approx 2 \cdot 10^5$。 

关键的见解是缺失的元素对应于从 1 到$n$或最后一个前缀和本身。 这将问题简化为分析连续前缀和之间的差异，这些前缀和代表排列中的原始数字（除了缺失的数字）。 具体来说，如果差异形成一个多重集，其中几乎所有数字都是从 1 到$n$，那么缺失的数字要么是差值之和太大，要么是数字$n$本身。 

因此，更快的方法是：计算连续前缀和之间的差异以获得候选数字，计算每个数字出现的次数，并以可以解释丢失前缀的方式验证一个数字是否丢失或一个数字重复。 这将解决方案简化为$O(n)$每个测试用例，在约束下是可行的。

 ## 算法演练

 1. 对于每个测试用例，计算连续前缀和之间的差异。 包括前缀和数组的第一个元素作为差异，因为它等于原始排列的第一个元素。 将这些差异存储在一个名为的列表中`nums`。 
2. 计算从 1 到 的数字之和$n$使用公式$n(n+1)/2$。 
3.比较总和`nums`到这个总和。 如果它们匹配，则所有数字都存在，并且缺少的前缀和对应于最后一个元素。 在这种情况下，数组形成有效的排列。 
4. 如果总和`nums`小于总和，计算缺失数作为差值。 计算每个数字出现的次数`nums`。 如果这个缺失的数字正好出现零次并且所有其他数字都在 1 到$n$，那么通过在正确的位置插入缺失的数字就可以进行排列。 
5. 如果任何数字出现两次或数字在 1 之外$n$，答案是“否”。 否则，答案是“是”。 
6. 返回每个测试用例的结果。 

**为什么有效**：连续前缀和之间的差异正是原始排列的元素，除了缺失的元素。 通过检查这些差异的总和和频率，我们可以推断是否存在单个数字可以恢复从 1 到 1 的完整排列$n$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        b = list(map(int, input().split()))
        total = n * (n + 1) // 2
        nums = [b[0]] + [b[i] - b[i - 1] for i in range(1, n - 1)]
        current_sum = sum(nums)
        
        if current_sum == total:
            print("YES")
            continue
        
        diff = total - current_sum
        count = {}
        valid = True
        for x in nums:
            if x < 1 or x > n:
                valid = False
                break
            count[x] = count.get(x, 0) + 1
            if count[x] > 1:
                valid = False
                break
        if not valid:
            print("NO")
        elif diff >= 1 and diff <= n and count.get(diff, 0) == 0:
            print("YES")
        else:
            print("NO")

solve()
```此实现可以有效地读取多个测试用例的输入，计算差异，并检查总和和频率以验证是否可以进行有效排列。 单独处理第一个元素可确保第一个元素的正确重建，这是差一错误的常见来源。
