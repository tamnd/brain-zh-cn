 ## 解决方案
 ## 问题理解

 我们有一个固定的自动扶梯结构和一组已知身高的人。 弗拉德也有身高。 自动扶梯具有等距的梯级，每个梯级的高度增加一个恒定值。 问题不在于身体运动，而在于是否可以将两个人放在两个不同的台阶上，以便他们之间的垂直距离与他们的身高差完全匹配。 

对于输入中的每个人，我们需要独立决定 Vlad 和该人是否存在一对步数，使得步数差约束和身高差约束完美对齐。 如果存在这样的位置，我们就会计算该人。 

关键的观察结果是步长差始终是固定值的倍数，因为每一步都会增加高度`k`。 这立即将问题转变为检查给定的高度差是否可以表示为`d * k`对于某个整数`d`适合自动扶梯的范围。 

限制很小：最多 1000 个测试用例，每个测试用例最多 50 人。 这保证了每个测试用例解决方案的 O(n) 就足够了，甚至每个人进行简单的算术检查就足够了。 

当高度差为零或不能被整除时，就会出现常见的边缘情况`k`。 另一个微妙的情况是当所需的步长差超过可用步数时，即使整除性成立。 这两个条件必须同时执行。 

一个幼稚的错误是尝试模拟每个人的所有步对，这是不必要的，并且有可能忽视这样一个事实：只有差异才是重要的，而不是绝对位置。 

## 方法

 暴力解决方案将尝试 Vlad 和每个人的每一对台阶，检查是否存在有效的步差和高度差对齐。 对于每个人，这都需要迭代所有`m * m`步骤对，导致每个测试用例的复杂度为 O(n m^2)。 虽然在技术上受到限制仍然很小，但它在概念上效率低下并且模糊了问题的结构。 

关键的简化是认识到唯一重要的是弗拉德和另一个人之间的绝对身高差。 一旦解决了这种差异，唯一的问题是我们是否可以使用自动扶梯几何结构来实现它。 因为每一步都准确贡献`k`高度差，我们正在检查该差是否可以被整除`k`以及隐含的步距是否在范围内`[1, m-1]`。 

这将问题简化为每个人的直接算术条件，消除了所有组合推理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·m^2) | O(n·m^2) | O(1) | O(1) | 太慢了 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算 Vlad 与每个人之间的绝对身高差。 这代表必须使用自动扶梯台阶来解释的总垂直间隙。 
2. 检查这个差值是否能被整除`k`。 如果不是，那么任何脚步运动序列都无法完全匹配高度间隙，因为每一步都精确地贡献`k`单位。 
3. 如果可整除，则将所需的步距计算为`diff // k`。 
4. 验证该步距严格介于 1 和`m - 1`。 我们需要两个不同的步骤，因此零是无效的，并且我们不能超出自动扶梯的范围。 
5. 统计所有满足这两个条件的人。 

### 为什么它有效

 自动扶梯产生离散线性度量，其中有效高度差恰好是`k`。 任何有效的对话都对应于选择两个不同的步骤，其索引差与高度差除以的商相匹配`k`。 由于步长介于 1 和`m`，最大可达到的指数差为`m - 1`。 这充分描述了所有有效配置的特征，因此检查整除性和界限既是必要的也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m, k, H = map(int, input().split())
    h = list(map(int, input().split()))
    
    ans = 0
    
    for x in h:
        diff = abs(x - H)
        
        if diff == 0:
            continue
        
        if diff % k != 0:
            continue
        
        d = diff // k
        
        if 1 <= d <= m - 1:
            ans += 1
    
    print(ans)
```读取输入后，我们迭代每个人并计算他们与 Vlad 的绝对身高差。 我们立即丢弃差异为零的情况，因为需要两个不同的步骤。 然后我们通过以下方式强制整除条件`k`，保证自动扶梯的步长能够代表高度差距。 最后，我们检查隐含的步距是否在自动扶梯范围内。 每个有效的人都会增加答案。 

有意将实现最小化，因为所有结构都由这些算术约束捕获。

 ## 边缘情况

 当所有身高都等于弗拉德的身高时，每个差异都为零，并且没有一个被计算在内，因为该问题需要两个不同的步骤，使得自匹配无效。 

什么时候`k`相对于所有高度差异而言，大多数差异都无法通过整除性检查，从而导致有效对话为零，即使原始差异看起来很接近。 

什么时候`m = 1`，不存在一对不同的台阶，因此无论高度值如何，答案始终为零，因为无法满足步距约束。
