 ## 解决方案
 ## 问题理解

 我们有一个聚会`n`人，每人持有一定数量的糖果`a_i`。 每个人都会向另外一个人提供正数的糖果，并且每个人都会从另外一个人那里收到糖果。 所给予的糖果必须是2的幂，并且任何人都不能给予比目前拥有的更多的糖果。 

目标是双重的：首先，每个人给予恰好一个并从恰好一个接收（糖果转移的完美一对一映射），其次，在所有转移之后，每个人最终都会得到相同数量的糖果。 输入由多个测试用例组成，每个测试用例指定`n`和清单`a`。 如果存在有效的传输配置，则输出为“Yes”，否则输出为“No”。 

约束很严格：`n`每个测试用例可以达到 2×10^5，所有测试用例的总和也上限为 2×10^5。 这排除了任何尝试所有传输排列的解决方案，这将成为阶乘`n`。 

边缘情况包括所有糖果已经相等的情况（这很简单“是”），以及糖果之和不能被除以的情况`n`，这立即使解决方案变得不可能。 小的`n = 2`也是一种边缘情况，因为它是一对一交换的最小大小。 

## 方法

 蛮力方法是尝试将糖果从一个人给另一个人的每一种排列（以 2 的幂次方表示），然后模拟结果状态并检查每个人的结果是否相等。 这将涉及迭代所有大小排列`n`，每个都最多有 log(max(a_i)) 二次方分割，导致复杂度为 O(n! × log(max(a_i)))。 对于 n 达到 2×10^5 的情况，这是不可行的。 

关键的观察是每个人的净收益或净损失必须恰好是`target - a_i`， 在哪里`target`是每个人最终应该拥有的糖果数量。 为了使所有人的平均数相等，`target`必须是糖果总数除以`n`。 如果这不是一个整数，则不可能有解决方案。 

考虑到二次方转移限制，我们需要每个人的净收益/损失可以表示为二次方之和。 具体来说，之间的差异`a_i`和`target`可以分解为两个不同幂的和。 因为每个人都向一个人给予并从一个人接收，所以一组传出和传入的二次幂转移必须完美平衡。 

出现的方法是检查每个差异是否`target - a_i`可以表示为 2 的幂之和。 通过计算所有正差和负差中需要多少个 2 的幂，我们可以验证 2 的幂的总和是否完全匹配。 如果这样做，则存在有效的分配。 这避免了模拟每个排列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!× log(max(a_i))) | O(n!× log(max(a_i))) | O(n) | 太慢了 |
 | 最佳| O(n × log(max(a_i))) | O(n × log(max(a_i))) | O(log(max(a_i))) | O(log(max(a_i))) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和清单`a`。 计算糖果总数`S`并确定`target = S // n`。 如果`S % n != 0`，打印“No”并继续，因为不可能每个人最终都平等。 
2. 初始化两个计数器：`give`和`receive`，每个都是从二次方值到其计数的映射。 
3. 对于每个人`i`， 计算`diff = a[i] - target`。 如果`diff > 0`，这个人必须赠送糖果。 如果`diff < 0`，他们必须收到`-diff`糖果。 
4. 对于每个非零`diff`，将其分解为 2 的幂。 这是通过迭代从 0 到 30 的位来完成的（因为`a_i ≤ 10^9`），增加相应的功率`give`如果`diff > 0`或在`receive`如果`diff < 0`。 
5. 在处理完所有人之后，为了存在解决方案，需要给出的二的幂的多重集必须与需要接收的多重集完全匹配。 如果匹配，则打印“Yes”。 否则，打印“否”。 

原理：分解为 2 的幂可确保每个人的净差异可以通过给予或接受 2 的幂糖果来满足。 因为每个人都必须给予恰好一个人并从恰好一个人那里接收，所以每种力量的总计数必须平衡。 这个不变量保证了正确性，而无需显式模拟所有传输序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total = sum(a)
        if total % n != 0:
            print("No")
            continue
        target = total // n
        
        give = {}
        receive = {}
        
        for x in a:
            diff = x - target
            if diff == 0:
                continue
            power = 0
            if diff > 0:
                while diff:
                    if diff & 1:
                        give[power] = give.get(power, 0) + 1
                    diff >>= 1
                    power += 1
            else:
                diff = -diff
                while diff:
                    if diff & 1:
                        receive[power] = receive.get(power, 0) + 1
                    diff >>= 1
                    power += 1
        
        if give == receive:
            print("Yes")
        else:
            print("No")

solve()
```代码首先计算每人的目标糖果数。 然后它会计算每个人必须给予或接受的两次权力。 比较这些计数可确保在不违反一对一映射约束的情况下执行每个所需的传输。 注意正确处理负差和按位分解。 使用字典可以避免创建不必要的大型数组。
