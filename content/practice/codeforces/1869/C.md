 ## 解决方案
 ## 问题理解

 我们被要求建造一个$n \times m$矩阵，其中每一行都是以下数字的排列$0$到$m-1$。 这意味着每行只包含一次所有值，但行之间可以不同。 

一旦建立了矩阵，每一列都会产生一个多重集$n$价值观。 对于每一列$i$，我们计算$v_i$，该列的 MEX。 最后，我们把所有这些$v_i$值并计算该序列的 MEX。 目标是最大化这个最终值。 

因此，问题不在于单个单元格，而在于控制每列中出现哪些值，特别是控制每列可以避免包含给定数字的时间。 

关键约束是所有测试用例的总大小最多为$2 \cdot 10^5$，因此每个测试用例的任何构造都必须是线性或接近线性的。 任何平方项$n \cdot m$会立即失败。 

天真的思维的一个微妙的失败案例来自于试图独立地最大化每一列。 例如，如果试图在不协调列的情况下任意或贪婪地填充每一行，很容易意外地使许多列具有 MEX 0，这会立即将最终答案折叠为 0。另一个误导性的想法是尝试通过平衡每列值的出现次数来独立地最大化每列的 MEX，但排列约束将所有列强烈耦合在一起，因此独立推理会中断。 

## 方法

 蛮力视角将尝试构造所有可能的行排列并评估结果矩阵。 即使限制于有效排列，也有$(m!)^n$可能的矩阵，这是完全不可行的。 

更结构化的蛮力可能会尝试为每个值做出决定$x$，在每行都是排列的约束下，它应该出现在哪些列中。 这已经成为跨行和列的复杂匹配问题，并且检查有效性将需要维护每行约束，使其至少是二次或更糟。 

关键的简化是停止考虑行，而是考虑循环移位结构。 由于每一行必须包含所有值，因此我们可以将第一行修复为$[0,1,2,\dots,m-1]$，并通过移动该序列生成其他行。 这保证了每一行都是一个排列，并对列分布提供了强有力的控制。 

如果我们移动行$i$经过$i \bmod m$，然后每一列都成为一个循环模式$0..m-1$。 这种结构使得在重复导致 MEX 下降之前控制每列中出现的不同值的数量成为可能。 

主要的见解是在专栏中$j$，我们可以确保值$0,1,\dots,k-1$如果我们至少使用的话都会出现$k$明显的循环移位，但我们不能超过$n$行。 这立即意味着最好的全球 MEX 受到两个方面的限制：我们不能支持超过$n$每列都有不同的出现次数，我们不能引入超过$m$整体上具有独特的价值观。 最优值变为$\min(n, m)$。 

一旦确定了这个界限，结构就会简化为确保第一个$k = \min(n,m)$值，每列包含所有值$0..k-1$，所以每列 MEX 至少$k$，同时确保至少一列中缺少每个值，以便全局 MEX 准确地变为$k$。 

这是通过循环拉丁方式结构实现的：$M_{i,j} = (i + j) \bmod m$。 这保证了每一行都是一个排列，并且每列也包含每个值一次$n=m$，或结构化前缀$n < m$，足以实现最佳 MEX 模式。

 ## 算法演练

 1. 将答案计算为$s = \min(n, m)$。 这是因为我们不能强制 MEX 大于可用的不同行或列交互的数量。 
2. 使用循环移位规则构造矩阵：对于每个单元格$(i, j)$， 分配$(i + j) \bmod m$。 这保证了每一行都是一个排列，因为移位保留了所有残基模的排序$m$。 
3. 输出构建的矩阵。 

不明显的部分是为什么这个简单的循环模式足以控制列 MEX。 每列包含均匀分布在各行中的值，因此第一列$s$值以结构化方式跨列显示，确保下面的 MEX 不会提前崩溃$s$。 

### 为什么它有效

 该结构形成拉丁矩形结构。 根据模加法的定义，每一行都是一个排列。 每列包含可预测的残基分布。 对于任何值$x < s$，有足够多的行，该值出现在足够多的列中，从而防止它同时普遍存在于所有列中。 这确保了列值的 MEX 可以精确地驱动$s$，并且由于约束而无法获得更大的值$s \le \min(n,m)$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())

        k = min(n, m)
        print(k)

        for i in range(n):
            row = [(i + j) % m for j in range(m)]
            print(*row)

if __name__ == "__main__":
    solve()
```代码首先读取所有测试用例。 对于每种情况，它计算限制参数$k = \min(n,m)$，这决定了可实现的最佳美感。 然后，它通过按行索引移动基本排列来构造每一行。 这保证了每一行的有效性，而不需要任何额外的簿记。 

一个常见的实现陷阱是忘记必须对每个列索引而不是每个行值应用模数，或者混淆$i+j$相对$i \cdot j$，这会破坏行的排列属性。

 | 1 | 1 2 0 | 1 2 0
 | 2 | 2 0 1 | 2 0 1

 现在每列包含一个排列$\{0,1,2\}$，因此每列都有 MEX 3。列上的最终 MEX 是 3。 

这证实了全循环覆盖在以下情况下提供最大分集：$n \ge m$。

这证实了行数少于列数时的限制因素。

import sys, io

def run(inp: str) -> str:

 ## 边缘情况

 对于$n=1, m=5$，该构造生成单个排列行，并且每一列只包含一个值，因此所有列 MEX 值均为 0。最终答案为 1，与$\min(n,m)$。 

为了$n=5, m=1$，每一行都是$[0]$，所以单列有MEX 1，最终结果又是$\min(n,m)$。 

为了$n=m=3$，矩阵变成完整的拉丁方，每列包含所有值$0,1,2$，产生最大对称性并实现答案 3。
