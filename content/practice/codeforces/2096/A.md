 ## 解决方案
 ## 问题理解

 我们接受了从 1 到 n 的数字的排列任务。 每个数字代表一根棒的长度，并且每个长度必须恰好使用一次。 目标是将这些棒按顺序排列，以满足连续位置之间的相对约束。 

约束来自长度为 n − 1 的字符串 s。每个字符描述序列中的下一个元素与所有先前元素的比较情况。 如果字符是“<”，则下一个选择的数字必须严格小于已放置的每个数字。 如果是“>”，则下一个选择的数字必须严格大于已放置的每个数字。 

因此，每个步骤不是仅比较相邻元素，而是将新元素与迄今为止构建的前缀的全局最小值或最大值进行比较。 “<”强制新的全局最小值，而“>”强制新的全局最大值。 

关键的结构含义是，每一步要么向下或向上扩展当前范围，而不是在其内部。 这使得该过程类似于通过重复扩展间隔来构建序列。 

约束 n ≤ 100 和 t ≤ 500 意味着即使每个测试用例的 O(n²) 也很容易足够快。 然而，该结构足够简单，可以进行线性构造。 主要困难是确保我们始终有一个符合未来限制的有效数字。 

一种常见的错误方法是尝试仅根据当前字符贪婪地选择最小或最大的未使用数字。 但这会失败，因为选择必须预见到未来的扩展。 例如，如果我们提前看到“>”，立即选择最大的可能会阻止满足稍后的“<”，因为“<”需要一个比所有先前选择都小的新的全局最小值。 

另一个失败案例是在简单的堆栈式结构中对称地处理“<”和“>”，而没有正确分离未使用的低值和高值。 正确性取决于约束序列与我们向上和向下扩展的次数之间保持一致的映射。 

## 方法

 暴力解决方案将尝试 1 到 n 的所有排列，并检查每个排列是否满足约束定义。 对于每个候选排列，我们将从左到右扫描，维护前缀的最小值和最大值，并验证每个步骤是否满足严格小于所有先前元素或严格大于所有先前元素，具体取决于字符。 有n个！ 排列，并且每次检查都需要 O(n)，导致 O(n · n!) 次操作，即使对于 n = 100 也是不可行的。 

关键的观察是我们实际上不需要搜索排列。 这些约束仅描述我们何时必须创建新的最小值或新的最大值。 这表明要从极端的角度进行思考。 

在构建过程中的任何时候，我们都会从未使用的数字中进行选择。 如果我们维护一个可用值的排序列表，每个“<”都会迫使我们选择剩余的最小数字，因为它必须比它之前的所有数字都小。 类似地，每个“>”都迫使我们选择剩余的最大数字，因为它必须比它之前的所有数字都大。 

然而，有一个微妙的问题：第一个元素不受约束，并且未来的最小和最大操作顺序必须与剩余计数一致。 解决这个问题的正确方法是反向解释序列：我们使用简单的计数参数提前决定从低端和高端取多少次，然后一次构建排列。

一个更清晰的建设性观点是：假设我们修复第一个元素。 然后，每个后续步骤都会插入新的全局最小值或最大值。 这相当于通过重复取最小或最大未使用值来构建序列。 约束字符串直接告诉我们从哪一边取。 

因此，我们在可用数字的排序集合上维护两个指针，并从左到右贪婪地构建答案。

 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们通过维护从 1 到 n 的可用数字池以及代表最小和最大未使用值的两个指针来构造排列。 

1. 将可用数字的列表隐式初始化为范围 [1, n]，并将低指针设置为 1，将高指针设置为 n。 我们还准备了一个空的答案数组。 
2. 任意选择第一个元素作为当前值。 一个方便的选择是最小的剩余值，因为它不限制后续步骤。 我们将 1 放入序列中，并将低位指针移至 2。 
3. 从左到右迭代字符串 s。 对于每个角色，决定是否必须创建新的全局最小值或新的全局最大值。 
4. 如果 s[i] 为“<”，我们必须选择一个小于之前选择的值。 在维持排列的同时保证这一点的唯一方法是从低指针中获取当前最小的未使用值。 我们附加它并增加低值。 
5. 如果 s[i] 是“>”，我们必须选择一个比之前选择的所有值都大的值。 我们从高位指针中取出当前最大的未使用值。 我们将其附加并递减高位。 
6. 继续，直到所有位置都被填满。 由于每一步只消耗一个数字，因此两个指针恰好相遇一次。 

正确性依赖于以下不变量：在每个步骤之后，所有先前选择的元素按照使用值的排序顺序形成一个连续的段。 当我们从低端取时，我们将使用过的段向下延伸； 当我们从高端开始时，我们将其向上延伸。 这保证了每个新选择的值要么小于所有先前的值，要么大于所有先前的值，完全符合相应字符的要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()

        low, high = 1, n
        ans = []

        ans.append(low)
        low += 1

        for ch in s:
            if ch == '<':
                ans.append(low)
                low += 1
            else:
                ans.append(high)
                high -= 1

        print(*ans)

if __name__ == "__main__":
    solve()
```该代码在未使用的范围内保留两个指针。 第一个元素固定为最小值，这确保了稳定的起点。 每当我们看到“<”时，我们就会通过消耗下一个最小的数字来向下扩展序列。 每当我们看到“>”时，我们就会通过消耗下一个最大的数字来向上扩展。 由于每个数字只使用一次，因此指针自然会收敛。 

一个微妙的点是，最初选择 1 是任意的，但很方便。 只要剩余结构持续消耗极端值，任何固定的起始值都可以工作。

 ## 边缘情况

 一个微妙的边缘情况是字符串在“<”和“>”之间交替。 例如，n = 5 且 s =“<>><”。 该算法仍然有效，因为每一步仅取决于剩余的极值，而不是先前的模式形状。 低位和高位指针始终向内移动，保证可用性。 

另一个边缘情况是所有“<”的前缀。 在这种情况下，我们不断选择增加的最小值，有效地以相反的顺序产生完全递减的前缀。 该算法仍然有效，因为每个新值都保证小于所有以前的值。 

最后，当字符串以“<”结尾时，最后一步强制使用最小的剩余值。 由于低和高精确收敛，因此最终元素是唯一确定的，并且排列保持有效而没有歧义。
