 ## 解决方案
 ## 问题理解

 我们得到了无限整数网格上发光单元的最终配置。 最初，除了一开始打开的一个隐藏的“原始”单元之外，所有单元都关闭。 然后，我们重复应用一个操作，恰好切换四个单元格，形成倾斜的 2×2 形状：对于选定的对$(x, y)$，我们翻转$(x, y)$,$(x, y+1)$,$(x+1, y)$， 和$(x+1, y-1)$。 

经过一些未知的此类操作序列后，我们观察当前打开的所有单元的集合。 任务是恢复单个点亮单元的任何可能的初始位置。 

关键的观点是该操作不会创建或破坏任意模式； 它在网格上保留了某些线性不变量。 最终的配置相当于采用一个起点并添加由运算形状生成的几个类似 XOR 的“奇偶校验移位”。 

约束的总规模很大，最多可达$2 \cdot 10^5$所有测试用例的点。 这立即排除了任何二次方，例如针对所有点尝试候选原点或向后模拟操作。 我们必须根据所有点的聚合信息计算原点。 

一种微妙但重要的边缘情况是只有一个点亮的单元格时。 在这种情况下，不需要进行任何操作，因此答案必须正是该坐标。 任何尝试“平均”或组合点的方法都必须准确保留这种情况。 

当点形成结构化形状时，会出现另一种边缘情况，其中在操作下发生局部取消。 例如，除非仔细选择不变量，否则看起来对称或彼此移位副本的配置可能会误导基于质心的朴素推理。 

## 方法

 操作翻转四点：$(x, y)$,$(x, y+1)$,$(x+1, y)$,$(x+1, y-1)$。 

暴力方法会尝试猜测最初的宝藏位置$(s, t)$，模拟操作如何产生最终集合，并验证一致性。 然而，可能的操作序列的空间是无界和组合的，使得重建不可行。 

正确的方法来自于认识到该操作保留了坐标的线性不变量。 我们不是跟踪整个网格，而是跟踪精心选择的坐标线性组合，该组合在每次操作下都保持稳定。 

让我们检查一项操作对坐标和的影响。 假设我们维持这样的值：$$S = \sum x_i \quad \text{or} \quad \sum y_i$$或组合，例如$\sum (ax_i + by_i)$。 目标是找到系数$a, b$使得应用该操作不会改变总贡献。 

对于四个翻转点，x 坐标的变化为：$x, x, x+1, x+1$，所以总共$2x + 2(x+1) = 4x + 2$。 

对于 y 坐标：$y, y+1, y, y-1$， 全部的$4y$。 

这表明简单的总和不是不变的，但精心选择的加权总和之间的差异可以是不变的。 关键技巧是移动到变换后的坐标系中：$$u = x + y, \quad v = x - y$$在这些坐标中，操作变得足够对称，以至于奇偶校验结构之一崩溃。 每个操作都会切换一组点，其组合效果保留所有点的异或$u$值和所有值的异或$v$价值观。 由于具有成对取消的多重集上的异或反映了原点加上平衡操作，因此所有点的最终异或编码了初始位置。 

因此，如果我们计算：$$U = \bigoplus (x_i + y_i), \quad V = \bigoplus (x_i - y_i)$$然后我们恢复：$$x = \frac{U + V}{2}, \quad y = \frac{U - V}{2}$$这是有效的，因为每个操作在不变空间中对每个受影响点贡献偶数次，这意味着它在 XOR 空间中的净效应为零。

 ## 算法演练

 1. 对于每个测试用例，阅读所有要点$(x_i, y_i)$。 目标是提取配置的稳定签名。 
2. 计算两个累加器：一个是变换后的坐标$u_i = x_i + y_i$，还有一$v_i = x_i - y_i$。 累加是使用 XOR 而不是 sum 完成的，因为操作结构被设计为在奇偶校验空间中取消。 
3. 异或全部$u_i$值以获得单个值$U$。 这表示沿对角轴的配置的净不平衡。 
4. 异或全部$v_i$获得的值$V$，代表沿反对角轴的不平衡。 
5. 通过求解线性系统恢复原点：$x = (U + V) / 2$,$y = (U - V) / 2$。 
6. 输出$(x, y)$。 

除以 2 始终有效，因为该操作生成的有效配置保证了$U$和$V$具有匹配的奇偶性。 

### 为什么它有效

 该操作会切换以独立保留两个对角奇偶性的方式排列的四个点。 在改造后的$(u, v)$空间中，每个操作都会翻转一组 XOR 为零的值。 这意味着所有的异或$u_i$和所有$v_i$最终配置必须等于单个初始点的异或。 由于 XOR 取消了操作引入的所有配对贡献，因此只有原始宝藏位置仍然编码在两个不变量中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        U = 0
        V = 0
        for _ in range(n):
            x, y = map(int, input().split())
            U ^= (x + y)
            V ^= (x - y)
        x = (U + V) // 2
        y = (U - V) // 2
        print(x, y)

if __name__ == "__main__":
    solve()
```该解决方案独立处理每个测试用例，在转换后的坐标上累积异或。 关键的实现细节是通过 XOR 安全地使用 Python 的整数算术，因为所有值都保持在有符号整数的范围内并且不会发生溢出。 

重建步骤依赖于整数除以 2，这是安全的，因为奇偶校验结构保证了偶数和。

 ## 边缘情况

 单点输入是最直接的情况：两个异或累加器都减少到该点的变换坐标，并且重建立即返回它。 任何尝试标准化或排序点的错误实现仍然可以在这里工作，但没有必要。 

对称配置例如$(0,0)$,$(1,1)$迫使 XOR 在一个方向上取消，同时在另一个方向上增强。 该转换可确保系统仍然解析为有效来源之一，而不是错误地崩溃。 

大数量级坐标测试没有中间步骤超过整数限制。 由于所有运算都是异或和加法，Python 可以安全地处理这个问题，并且无论大小如何，奇偶校验都保持正确。
