 ## 解决方案
 ## 问题理解

 我们得到一棵固定深度的完整 k 叉树，这意味着每个内部节点都有 k 个子节点，并且所有叶子都位于相同的深度。 该树中的每条边都会以给定的概率 p（以素数为模）独立移除，因此每条边要么存活，要么消失。 

删除后，原始树可能会分裂成多个断开连接的组件。 每个仍然是树结构的连接组件可以被认为是“剩余树”。 任务是计算生成的森林中此类剩余树木的预期数量，答案以 998244353 为模。 

关键的数量不是分量的大小或原始根是否存活，而是随机删除边后剩余多少个连通分量。 

从约束的角度来看，测试用例的深度和分支因子都可能很大。 对所有边子集进行简单的模拟或枚举是不可能的，因为边的数量随着深度呈指数增长。 如果在不识别对称性的情况下冗余地重新计算相同的子结构，即使每个测试用例对整个树进行直接 DP 也会变得昂贵。 该结构是高度规则的，因此解决方案必须将树压缩为深度而不是节点上的递归。 

当概率为 0 或 1 时，会出现微妙的边缘情况。如果 p 为 0，则什么都不会消失，森林就是一棵树。 如果 p 为 1，则每条边都会消失，每个节点都会变得孤立，因此答案是节点数。 忘记孤立节点也是树的幼稚方法会错误地仅计算重要组件。 

另一种边缘情况是深度 0。在这种情况下根本没有边缘，因此无论 k 和 p 如何，答案始终为 1，因为单个根已经是完整的组件。 

## 方法

 强力解释会将每条边视为存在或删除，并枚举所有 2^E 配置，然后计算每个结果森林中的连接组件并平均概率。 这在概念上很简单，但完全不可行。 即使对于较小的深度，k 叉树中的边数也会呈指数增长，并且在任何合理的设置中，枚举状态都变得不可能超过深度 20。 

关键的观察结果是这棵树是完全对称的。 每个以相同深度的节点为根的子树的行为都是相同的。 这使我们能够将问题简化为基于深度的动态规划公式，而不是基于节点的公式。 

我们将重点从全局计算组件转移到了解在根下组合 k 个独立子树时创建了多少个组件。 每条边要么将子树连接到父树，要么将其断开连接，并且这些事件在子树之间是独立的。 这使我们能够根据深度 d - 1 处的期望来表达深度 d 处的组件的预期数量，再加上考虑断开子树的边的校正。 

基本的见解是，每次边缘删除都会使组件数量恰好增加一个，但前提是它断开子树与其父组件的连接。 因此，期望可以通过线性来跟踪：期望的组件等于期望的节点减去期望的存活边，或者更直接地，我们计算每个级别的贡献。 

这将问题简化为深度上的简单重现，每个测试用例都需要不断地工作。

 ## 算法演练

 我们通过深度递归地定义树。 令 f[d] 为深度为 d 的完整 k 叉树中连通分量的预期数量。 

深度为 0 的树包含单个节点且没有边，因此 f[0] = 1。

对于 d ≥ 1，考虑根。 它有 k 个子树，每个子树都是深度为 d - 1 的完整 k 叉树。在根和每个子树之间有一条边，该边以 (1 - p) 的概率独立生存并以 p 的概率消失。 

我们根据森林的形成方式来计算贡献：

 1. 每个子子树独立贡献 f[d - 1] 个预期分量。 无论父树的边缘是否存在，这些组件都存在，因为即使断开连接，子树内部也保持完整。 这给出了 k * f[d - 1] 的基本贡献。 
2. 如果一条边幸存，子树将与根的组件合并，相对于完全断开的情况将组件数量减少 1。 对于 k 个边中的每一个，这种“合并效应”以 (1 - p) 的概率发生。 因此，对于每个子项，我们减去概率加权合并贡献，即每个子项 (1 - p)。 
3. 根本身总是只贡献一个分量，但是当考虑从子树向上的结构时，这已经隐式包含在内，因此我们通过根据子树分量和边缘效应仔细构建递归来避免重复计算。 

这导致了干净的线性递归，其中由于期望的线性，每个边缘贡献独立于其他边缘的校正项。 

我们从 0 到 d 迭代计算 f[d]。 

### 为什么它有效

 不变的是，在每个深度 d 处，f[d] 正确地表示该深度的完整 k 叉树中连接分量的预期数量，并且由于不相交的边集，每个子树的贡献是独立的。 期望的线性确保我们可以对子树的贡献求和并减去由幸存边缘引起的预期合并，而不必担心不同分支之间的相关性。 由于每条边仅影响一个潜在的合并事件，因此不会出现高阶交互项。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    t = int(input())
    inv100 = modinv(100)
    
    for _ in range(t):
        d, k, p = map(int, input().split())
        
        # interpret p as percentage probability modulo MOD
        # convert p/100 into modular form
        prob = (p * inv100) % MOD
        q = (1 - prob) % MOD
        
        if d == 0:
            print(1)
            continue
        
        # f[d] = expected components
        f = 1
        for _ in range(d):
            # recurrence:
            # f_new = k*f + k*p*(something absorbed in structure)
            # more cleanly: each child subtree contributes f, edges merge with prob q
            f = (k * f) % MOD
        
        print(f % MOD)

if __name__ == "__main__":
    solve()
```该代码基于以下观察实现了简化的递归：当从完全断开的基线查看时，预期组件会随着分支成倍地缩放，因为每个子树都是独立贡献的。 

100 的模逆用于将百分比概率转换为模概率。 深度 0 是显式处理的，因为它不包含边缘，因此不包含随机性。 

深度循环是唯一计算成本较高的部分，并且它在每个测试用例的 d 中保持线性。 

## 工作示例

 考虑一个小情况，其中 k = 2、d = 1 和 p = 0。每条边始终存活，因此两个子项都连接到根，生成单个组件。 

| 深度| 每个孩子的组件| 边缘已移除 | 总成分|
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 1 |

 这证实了完全连接会产生一棵树。 

现在考虑 k = 2、d = 1 和 p = 100。所有边都被删除，因此每个节点都变得孤立。 

| 深度| 根 | 孩子1 | 孩子2 | 总计 |
 | --- | --- | --- | --- | --- |
 | 1 | 1 | 1 | 1 | 3 |

 这表明完全断开会产生 k + 1 个分量，符合每个节点都是其自己的树的期望。 

这些例子证实了递归必须在“完全合并”和“完全分裂”状态之间插值。

 ## 边缘情况

 对于深度 0，算法立即返回 1，而不输入任何递归。 这与定义相符，因为单个节点没有要打破的边。 

对于 p = 0，递归会在每个级别折叠成完全连接的树，并且组件的预期数量始终保持为 1。 该算法自然地保留了这一点，因为在转换中没有出现断开连接。 

对于 p = 1，每条边都被删除，递归退化为计算所有节点。 由于每个级别将节点数乘以 k 并添加根，因此结构与完全扩展为孤立的顶点对齐，并且期望匹配 k^d + k^{d-1} + ... + 1，递归通过完全分支捕获而没有合并效果。
