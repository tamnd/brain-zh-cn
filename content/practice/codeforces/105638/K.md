 ## 解决方案
 ## 问题理解

 棋盘是一个包含三种类型单元格的网格：黑色棋子、白色棋子和空交叉点。 正交接触的相同颜色的石头形成一个连接的组。 对于每个这样的组，我们需要确定有多少个不同的空单元在四个基本方向上与该组中的任何石头直接相邻。 这些相邻的空单元格代表自由度，它们是按组计算的，而不是按石头计算的。 

任务是分别计算黑人和白人有多少个相连的群体恰好有一个不同的自由细胞。 

网格尺寸足够小，可以轻松地进行二次遍历。 即使电路板的每个维度多达数千个，每个单元执行恒定工作量并使用洪水填充的解决方案也将保持在限制范围内。 这排除了任何对每块石头重复重新计算可达性或邻接性的想法，因为这会在密集情况下转向立方体行为。 

一个天真的但重要的失败模式来自于计算每块石头而不是每组的自由度。 考虑一排两块黑色石头，两块石头旁边都有一个空单元格。 如果我们计算每块石头，我们会认为每块石头都有一个自由度，并错误地得出两者都是独立的 atari 的结论。 正确的解释是，两颗宝石都属于一组，其自由集的大小为一。 

当同一个空单元接触一组宝石中的多个宝石时，就会出现另一个微妙的问题。 它必须计算一次，而不是每个邻接计算一次。 例如，围绕一个空中心的加号组将有一个自由度，而不是四个。 

## 方法

 暴力方法将检查每块棋子并向外执行局部搜索以确定其组中所有连接的棋子，然后通过再次扫描邻居来重新计算其自由度。 这很快就会多次重复相同的工作，因为组中的每个石头都会触发同一组件的完整遍历。 在最坏的情况下，棋盘完全填满，这会退化为重复探索大区域，产生立方或接近立方数量的操作。 

关键的观察结果是，组是网格图中不相交的连接组件。 一旦我们识别了一个组件，有关它的所有必需信息（包括其自由集）都可以一次性计算出来。 这表明对相同颜色的单元格进行标准洪水填充，在此期间我们将所有相邻的空单元格累积到一组中。 每个单元只处理一次，并且每个边缘最多检查恒定次数。 

这将问题转化为具有辅助聚合的连接组件遍历。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 最坏情况 | O(n²·k) O(n²) | 太慢了|
 | 最佳洪水填充 | O(n²) | O(n²) | 已接受 |

 ## 算法演练

 1. 遍历网格中的每个单元格。 当一个单元格包含一块石头并且尚未被访问时，将其视为新连接组件的起点。 
2. 运行仅限于相同颜色的单元格的广度优先搜索或深度优先搜索。 标记每一个访问过的石头，这样它就不会被再次处理。 这确保了每一块石头都属于一个组件遍历。 
3. 在探索组件时，每当相邻单元格为空时，将其坐标记录在与该组件关联的集合中。 需要设置该集合，以便从多个棋子到达的相同空交点仅计算一次。 
4. 遍历结束后，检查收集到的自由集的大小。 如果正好是 1，则增加该石材颜色的计数器。 
5. 继续，直到处理完所有单元格，并输出两个计数器。

我们明确区分遍历和自由度收集的原因是自由度是整个连接结构的属性，而不是单个石头的属性。 混合每个石头的逻辑会重新引入重复的工作。 

### 为什么它有效

 每次洪水填充都会准确地发现一个相连的石头组成部分。 由于邻接是四向的并且仅限于同色扩展，因此在遍历过程中不会错误地拆分或合并组件。 与该组件相邻的每个空单元格至少可以通过其相邻的一块石头被发现一次，并且使用一组可以保证唯一性。 因此，最终的自由集正是该群体的真实自由集，使得“恰好一个自由”条件对于分类来说是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n = int(input().strip())
    grid = [list(input().strip()) for _ in range(n)]

    visited = [[False] * n for _ in range(n)]

    dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]

    black_atari = 0
    white_atari = 0

    def bfs(sr, sc):
        stack = [(sr, sc)]
        visited[sr][sc] = True
        color = grid[sr][sc]
        liberties = set()

        while stack:
            r, c = stack.pop()
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if nr < 0 or nr >= n or nc < 0 or nc >= n:
                    continue
                if grid[nr][nc] == 'E':
                    liberties.add((nr, nc))
                elif not visited[nr][nc] and grid[nr][nc] == color:
                    visited[nr][nc] = True
                    stack.append((nr, nc))

        return color, len(liberties)

    for i in range(n):
        for j in range(n):
            if grid[i][j] != 'E' and not visited[i][j]:
                color, lib_count = bfs(i, j)
                if lib_count == 1:
                    if color == 'B':
                        black_atari += 1
                    else:
                        white_atari += 1

    print(black_atari, white_atari)

if __name__ == "__main__":
    solve()
```该实现保留了一个全局访问数组，以便每个石头都被处理一次。 使用基于堆栈的 DFS 代替递归，以避免大连接区域中的堆栈溢出。 

套装`liberties`是防止对多个宝石共享的空单元进行重复计数的关键结构。 每次遇到空单元格的边界时，都会将其插入到集合中，并自动忽略重复项。

 ## 边缘情况

 一个关键的边缘情况是多个宝石共享同一个自由单元。 在这种情况下，每块石头的方法会错误地乘以该自由度的计数，但基于集合的聚合确保它被计数一次。 例如，具有单个相邻空单元的 2x2 石头块应该为整个组件生成大小为 1 的自由集。 

另一种情况是棋盘边缘有一颗棋子。 出界位置不得被视为自由，因为只有板内的空单元才算在内。 DFS 中的边界检查显式地跳过无效坐标，从而防止出现虚假自由。 

最后一种情况是孤立的石头，没有相邻的空单元。 这些群体的自由度为零，不能算作 atari。 该算法自然会处理这个问题，因为自由集仍然为空，并且只接受完全等于 1 的大小。
