 ## 解决方案
 ## 问题理解

 我们正在一组固定的端口和电缆上模拟一个非常小的随机过程，其中每根电缆最终都恰好插入一个端口。 有 n 个端口标记为 1 到 n，n 根电缆也标记为从 1 到 n。 电缆按照递增顺序一根接一根地插入。 

前 m 条电缆的行为不可预测：每条电缆都被均匀随机地放置在当前空的端口中。 在这 m 个步骤之后，剩余的电缆遵循大部分确定性规则。 当插入电缆 i 时，如果端口 i 仍然空闲，则电缆将插入那里。 否则，如果端口 i 已被占用，则电缆被迫在剩余的空端口中统一随机选择。 

任务是计算所有插入完成后电缆 n 最终到达端口 n 的概率。 

重要的结构约束是 n 至多为 10。这立即表明任何在 n 中呈指数增长的状态空间或概率模型都是可行的，但任何依赖于大组合 DP 的东西都是不必要的。 相反，这是一个小的概率过程，其中完整枚举或直接递归推理是现实的。 

当 m 等于 n 时，会出现最微妙的边缘情况，这意味着每根电缆都是随机放置的，并且确定性规则永远不会激活。 在这种情况下，该过程变成均匀随机排列，并且电缆 n 到达端口 n 的概率恰好为 1/n。 假设稍后的确定性行为的幼稚实现会错误地偏向这种情况。 

另一个极端情况是 m 等于 0，除非发生碰撞，否则一切都是确定性的。 由于强制重新分配，这仍然会产生随机性，并且“只有前 m 步骤重要”的天真假设会立即失效。 

## 方法

 暴力方法将模拟前 m 条电缆的所有可能分配，然后递归地探索剩余插入的所有碰撞结果。 每个随机放置分支最多为 O(n) 个选择，每次碰撞也分支为最多 O(n) 个选择。 即使 n ≤ 10，这也会导致一棵具有重复状态的可能性树，并且在没有记忆的情况下，它的增长大致与 n 一样！ 在最坏的情况下。 虽然正确性很简单，但这种方法变得多余，因为许多分支达到相同的配置。 

关键的观察是，在任何步骤之后，唯一重要的信息是哪些端口被占用以及当前正在处理哪些电缆。 如何达到配置的身份是无关紧要的。 这将问题简化为占用端口子集上的小概率 DP，其中转换仅由处理电缆 i 时目标端口 i 是否空闲来确定。 

由于 n 非常小，因此进一步简化。 我们可以将系统视为由占用端口集定义的状态上的马尔可夫过程，并确定性地向前传播概率。 每个状态最多转换到 n 个下一个状态，具体取决于是否发生强制放置或随机放置。 我们最终对端口 n 被电缆 n 占用的状态概率求和。

 ## 算法演练

 我们通过位掩码来表示每个状态，该位掩码描述在处理某些电缆前缀后哪些端口已经被占用。 我们维持这些状态的概率分布。

1. 将 DP 初始化为没有端口被占用且概率为 1 的单一状态。这代表插入任何电缆之前的系统。 
2. 依次处理从 1 到 n 的电缆。 在步骤 i，我们根据每个状态下端口 i 是否被占用来更新分布。 
3. 对于固定状态，如果端口 i 空闲，则电缆 i 确定性地到达那里。 我们将概率质量移动到一个新状态，并将该端口标记为已占用。 
4. 如果端口 i 已被占用，我们将概率均匀分布在所有当前空闲端口上。 这会创建多个后继状态，每个后继状态对应于选择一个空端口。 
5. 对于前 m 条电缆，我们完全跳过确定性检查，并始终均匀分布在所有空闲端口上，因为它们被迫是随机的。 
6.处理完所有n条电缆后，我们将端口n被电缆n占用的所有状态的概率求和，这相当于在最后一步检查端口n是否被填充。 

它起作用的原因是，在每一步中，DP 状态都会准确地编码确定未来转换所需的相关信息：占用集完全确定是否发生强制放置以及有效的随机选择是什么。 由于转换仅取决于当前掩码和当前索引 i，因此导致相同掩码的所有历史在未来都会表现相同，因此合并它们可以保持正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    # dp[mask] = probability of this occupancy state
    dp = [0.0] * (1 << n)
    dp[0] = 1.0

    for i in range(1, n + 1):
        ndp = [0.0] * (1 << n)

        for mask in range(1 << n):
            p = dp[mask]
            if p == 0:
                continue

            # if i-th port is free
            if not (mask >> (i - 1)) & 1:
                new_mask = mask | (1 << (i - 1))
                ndp[new_mask] += p
            else:
                # choose uniformly among free ports
                free = []
                for j in range(n):
                    if not (mask >> j) & 1:
                        free.append(j)

                k = len(free)
                if k == 0:
                    continue

                for j in free:
                    new_mask = mask | (1 << j)
                    ndp[new_mask] += p / k

        dp = ndp

    ans = 0.0
    for mask in range(1 << n):
        if mask & (1 << (n - 1)):
            ans += dp[mask]

    print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```DP 数组存储占用端口的每个子集的概率。 每次迭代对应于插入新电缆并根据规则重新分配概率质量。 关键的实现细节是仔细处理强制放置与随机重新分配； 两者都直接根据目标端口是否已在掩码中设置而得出。 

浮点除法在这里是安全的，因为 n 很小并且深度最多为 10，因此累积误差仍然在容差范围内。 

## 工作示例

 ### 示例 1：n = 3，m = 1

 我们跟踪每条电缆后的 DP 状态。 

| 步骤| 掩码状态（二进制）| 概率 |
 | ---| ---| ---|
 | 开始| 000 | 000 1.0 |
 | 电缆1后（随机）| 100、010、001 | 各 1/3 |
 | 电缆 2 之后 | 多个合并状态 | 通过转换计算|
 | 电缆 3 之后 | 最终分配| 有效掩码总和|

 关键行为是早期随机性将概率分布在所有配置中，而后期的确定性插入会根据目标端口是否已被占用而导致结果偏差。 

最终结果匹配 0.5，这意味着一半的概率质量导致电缆 3 占用端口 3。 

### 示例 2：n = 2，m = 2

 | 步骤| 口罩状态| 概率 |
 | ---| ---| ---|
 | 开始| 00 | 00 1.0 |
 | 电缆1随机| 10, 01 | 0.5 个 |
 | 电缆2随机| 11 永远 | 1.0 |

 这里两条电缆都是随机的，因此最终的配置始终是完整的排列，并且每个排列的可能性相同。 电缆 2 位于位置 2 的概率为 1/2。 

这证实了当 m = n 时，该过程退化为均匀排列。

 ## 边缘情况

 ### 情况：m = n（全部随机）

 输入：```
3 3
```这里，每根电缆都均匀地插入剩余的空闲端口，产生均匀的随机排列。 DP 转换始终均匀地分配概率，并且最终状态空间为所有 3 个分配相同的概率！ 配置。 事件“电缆 n 位于端口 n”恰好在 2 内发生！ 共 3 个！ 例，产量为 1/3。 

### 情况：m = 0（除了碰撞之外完全确定）

 输入：```
3 0
```在电缆 1 处，确定性地采用端口 1。 在电缆 2 处，如果端口 2 空闲，则使用该端口，否则会出现随机性。 DP 正确捕获两个分支，因为即使是单个冲突也会在剩余端口之间引入均匀的重新分配。 电缆 3 在端口 3 着陆的最终概率完全来自早期的强制结构，并且 DP 确保对称地考虑碰撞和非碰撞路径。 

### 情况：n = 1

 输入：```
1 0
```仅存在一根电缆。 无论随机性规则如何，它始终以端口 1 结束。 DP 从掩码 0 开始，立即将概率 1 分配给掩码 1。最终答案恰好是 1，并且不会发生分支。
