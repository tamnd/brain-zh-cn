 ## 解决方案
 ## 问题理解

 我们有 n 个俱乐部的集合，我们必须为每个俱乐部分配 m 种徽章类型中的一种。 多个俱乐部可以共享相同的徽章类型，但每个徽章类型必须至少出现一次。 

任务确定后，参与者会反复访问俱乐部。 每次访问都会从所有 n 个俱乐部中统一随机选择一个俱乐部，与之前的访问无关，并且参与者会收到该俱乐部的徽章。 该过程将持续进行，直到参与者至少收集了每种徽章类型中的一个。 我们被要求选择将徽章类型分配给俱乐部，以便收集所有 m 种类型所需的预期访问次数最小化，并输出该最小预期值。 

随机性完全在于俱乐部的重复统一选择。 唯一的控制是我们如何在 n 个俱乐部中分配 m 种类型，这决定了每种类型在单次访问中出现的可能性。 

约束意味着 n 最多 100000，m 最多 5000，其中 m 不超过 n。 这立即排除了任何显式模拟流程或枚举所有分配的解决方案。 即使是 O(nm) 的构造也是边界性的，任何涉及所有 m 类型子集的东西只有在高度优化或可避免的情况下才可行。 关键的困难在于，答案不仅取决于计数，还取决于分配引起的完整概率分布。 

当用天真的直觉进行推理时，就会出现一个微妙的问题。 人们可能会认为均匀分布徽章总是最佳的，然后直接代入标准优惠券收集公式以获得统一概率。 当 n 不能被 m 整除时，这种情况就会中断。 

例如，如果 n = 3 且 m = 2，我们将被迫分割计数 (2, 1)，导致概率为 2/3 和 1/3。 天真的“类型统一”估计会错误地给出 3，而正确的期望是 3.5，这表明概率的不平衡以非线性方式直接影响运行时间。 

另一种故障模式是假设每种徽章类型在预期时间内呈线性，例如求和 1/p_i。 这超出了计数，因为收集是并行的，而不是顺序的。 

## 方法

 该分配定义了 m 个徽章类型的概率分布。 如果类型 i 出现在 a_i 俱乐部中，则单次访问产生类型 i 的概率为 p_i = a_i / n。 该过程成为一个典型的具有非均匀概率的优惠券收集问题。 

对于固定分布，看到所有类型之前的预期时间由速率为 p_i 的独立指数时钟的到达时间分布确定。 这导致了指数变量最大值期望的已知包含-排除形式：

 E = (-1)^{|S|+1} 的非空子集 S 的总和 /（S 中 p_i 的总和）

 这个公式是正确的，但取决于类型的所有子集，其以 m 为指数。 

然后，优化问题是选择整数 p_i = a_i / n，其中 a_i ≥ 1 且求和 a_i = n 来最小化此对称凸表达式。 函数的结构意味着平衡概率是最优的：如果两个概率不同，则将质量从较大的移动到较小的会降低期望。 这是比率对称凸函数的标准多数化论证。 

因此，最佳结构是在徽章类型之间尽可能均匀地分配俱乐部。 设底数 = n / m，余数 = n % m。 然后剩余类型得到基数 + 1 球杆，其余类型得到基数球杆。 

修复此分布后，问题减少为评估仅包含两个值的概率多重集的预期覆盖时间。 剩下的挑战是有效计算 m 至 5000 的包含-排除表达式。

直接子集枚举是不可能的。 但是，由于概率仅采用两个值，因此可以根据每组中有多少元素对子集进行分组，从而将问题从子集简化为计数问题。 这将指数结构折叠成包含多少“大概率”和“小概率”类型的二维求和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 枚举所有分配+模拟| 指数| O(1) | O(1) | 太慢了 |
 | 修复分布+完整子集包含-排除| O(2^m) | O(2^m) | O(米) | 太慢了 |
 | 修复分布+按概率类别分组 | O(m^2) | O(米) | 已接受 |

 ## 算法演练

 我们分两个概念阶段进行：构建最佳概率分布，然后评估该分布的预期覆盖时间。 

### 1. 平衡徽章频率

 我们首先决定每种徽章类型应占据多少个俱乐部。 由于每种类型必须至少出现一次，因此我们首先为每种类型提供一个俱乐部。 剩余的 n − m 个俱乐部尽可能均匀地分布。 这会产生两个最多相差一的频率值。 

这一步不仅仅是启发式的。 任何偏离平衡分布的情况都会产生一对类型，其中一种类型比另一种类型严格地更频繁，并且由于比率中的覆盖时间函数的凸性，将俱乐部从更频繁的类型转移到不太频繁的类型会严格减少预期时间。 

### 2. 将频率转换为概率

 每种类型 i 的概率为 p_i = a_i / n。 平衡后，有 k 种概率为 p_high = (base + 1) / n 的类型和 m − k 种类型，概率为 p_low = base / n。 

### 3. 通过子集分组评估预期覆盖时间

 我们使用指数时钟解释：每种类型 i 都有一个独立的指数到达时间，速率为 p_i，答案是期望的最大到达时间。 

最大指数的期望可以使用子集上的包含-排除来编写。 我们不是直接迭代所有子集，而是根据子集包含的高概率和低概率元素的数量对子集进行分组。 

对于包含 i 个高概率类型和 j 个低概率类型的子集，总速率为 i·p_high + j·p_low，子集的数量为 C(k, i) · C(m − k, j)。 我们对所有有效对 (i, j) 求和，排除空子集，并根据子集大小使用交替符号。 

这将计算从子集的指数计算减少到计数的双重求和。 

### 为什么它有效

 关键的不变量是，在包含-排除扩展中的任何一点，相同组成的子集的贡献相同，因为只有概率之和重要，而不是类型的同一性。 分组保留了子集的精确多重性，同时用组合计数替换基于身份的枚举。 由于所有有效子集均由 (i, j) 唯一划分，因此不会丢失或重复任何项，因此所得总和等于原始期望公式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    base = n // m
    rem = n % m

    k = rem  # number of high-frequency types

    p_high = (base + 1) / n
    p_low = base / n

    # Precompute binomial coefficients up to m
    C = [[0.0] * (m + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        C[i][0] = 1.0
        for j in range(1, i + 1):
            if j == i:
                C[i][j] = 1.0
            else:
                C[i][j] = C[i - 1][j - 1] + C[i - 1][j]

    ans = 0.0

    for i in range(0, k + 1):
        for j in range(0, m - k + 1):
            if i == 0 and j == 0:
                continue
            sign = 1.0 if (i + j) % 2 == 1 else -1.0
            rate = i * p_high + j * p_low
            ans += sign * C[k][i] * C[m - k][j] / rate

    print(ans)

if __name__ == "__main__":
    solve()
```该代码首先构建跨徽章类型的俱乐部的最佳划分。 然后，它使用标准帕斯卡三角形计算二项式系数，因为 m 对于 O(m^2) 预处理来说足够小。 

双循环实现分组包含-排除。 每个项对应于具有固定数量的高频和低频类型的所有子集。 交替符号仅取决于子集大小，分母是该子集的组合比率。 

浮点运算就足够了，因为所需的精度为 1e-6，并且所有中间值都保持在 m 至 5000 的稳定范围内。 

## 工作示例

 ### 示例 1

 输入：

 n = 3，m = 2

 我们有 base = 1，rem = 1，所以 k = 1。 

一种类型的概率为 2/3，另一种类型的概率为 1/3。 

我们计算：

 | 我（高）| j（低）| 子集大小 | 标志| 率 | 贡献 |
 | ---| ---| ---| ---| ---| ---|
 | 1 | 0 | 1 | + | 2/3 | +1.5 |
 | 0 | 1 | 1 | + | 1/3 | 1/3 +3 |
 | 1 | 1 | 2 | - | 1 | −1 |

 求和得出 3.5。 

这符合稀有类型主导等待时间的直觉，并且这种不平衡增加了超出统一情况的期望。 

### 示例 2

 输入：

 n = 111，m = 7

 这里，base = 15，rem = 6，因此六种类型的概率为 16/111，一种类型的概率为 15/111。 

计算遵循相同的结构，但分割更大。 包含稀有类型的子集在包含时会产生稍长的等待时间，与完全一致的情况相比，这增加了总体期望。 

分组枚举确保我们将所有 2^7 子集仅计算一次，而无需明确列出它们。

 ## 边缘情况

 当 n 等于 m 时，每种类型恰好出现一次，因此每次访问都会显示均匀随机的类型。 该算法产生 k = 0 余数，从而产生相同的概率和稳定的包含-排除和，可评估经典的 m 次谐波行为。 

当m=1时，进程在第一次访问后立即终止。 该算法产生单一概率 1，并且除基本情况外的所有子集项都消失，产生期望 1。 

当 n 仅略大于 m 时，大多数类型的概率为 1/n，少数类型为 2/n。 这会造成强烈的不平衡，并且包含-排除表达式会严重加权包含稀有类型的子集。 分组计算准确地捕捉到了这一点，因为它通过组成而不是身份来区分贡献。
