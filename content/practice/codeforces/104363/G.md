 ## 解决方案
 ## 问题理解

 我们在平面上得到一组点，每个点代表一颗质量相等的小行星。 我们必须将这些点分成两个非空组。 每个组都被压缩到其质心，这只是其点坐标的算术平均值，因为所有质量都是相同的。 这会产生两个点 A 和 B。在原点处还有一个固定参考点 O。 

目标是选择将点划分为两个非空组，以使三角形 ABO 的面积最大化。 由于 O 是固定的，因此面积仅取决于 A 和 B 的位置，具体取决于线段 AB 相对于原点“展开”的距离。 

输入大小达到十万点，这排除了尝试所有分区甚至所有子集对的任何解决方案。 任何与 n 成二次方的方法都已经太大，甚至 O(n log n) 方法也需要仔细论证。 

当所有点都位于通过原点的直线上时，就会出现一个微妙的问题。 在这种情况下，每种可能的分组都会产生共线的 A、B 和 O，因此面积为零。 假设非零面积并除以矢量幅度的简单实现可能仍然可以正确地进行数值计算，但几何推理必须考虑简并性。 

如果试图贪婪地选择两个极值点并根据它们分配组而不考虑 A 和 B 是平均值而不是选定点，则会出现另一种失败情况。 例如，极值点不一定使质心分离最大化。 

## 方法

 一个蛮力的想法是将 n 个点的每个可能的划分枚举为两个非空集合。 对于每个分区，我们在 O(n) 时间内计算两个质心，然后在 O(1) 时间内计算三角形面积。 这导致O(2^n·n)，这是完全不可行的。 

我们可以通过观察重要的不是每个组的确切组成，而是两个组的坐标之和之间的差异来减少搜索空间。 令 S 为所有点的总和。 如果我们将组 1 的和定义为 S1，则组 2 的和为 S − S1。 质心为 S1 / k 和 (S − S1) / (n − k)，因此几何形状取决于 S1 如何随所选子集变化。 

关键的见解是面积表达式成为子集和的线性函数的最大化。 具体来说，三角形面积与 A 和 B 叉积的绝对值成正比。在代数简化之后，这简化为在所有非平凡子集上最大化线性表达式，这相当于选择“投影”点并按符号分割的方向。 

这将问题转化为寻找通过原点的直线引起的最佳划分：一侧的所有点都进入 A 组，其余的进入 B 组。任何最优解都可以转换为这样的半平面划分，因为跨划分边界移动点会以线性和单调的方式改变目标。 

一旦减少到方向分离，我们只需要按原点周围的角度对点进行排序，并考虑代表一组的滑动窗口。 质心差异可以增量地维持，允许由于排序而实现 O(n log n) 解，然后进行 O(n) 扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了 |
 | 角度扫描优化 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

1. 计算所有点坐标的总和。 这使我们能够使用互补和来表达任何组的质心，而不是从头开始重新计算。 
2. 将每个点转换为其绕原点的极角。 按角度排序可确保任何连续的线段对应于一组可以由穿过原点的旋转线分隔开的点。 
3. 通过再次添加角度增加 2π 来复制已排序的列表。 这允许将圆形间隔视为线性窗口。 
4. 在代表一个候选组的双倍数组上维护一个滑动窗口。 跟踪窗口内 x 和 y 坐标的运行总和。 
5. 对于每个窗口，确保它不包含所有点，因为两组都必须非空。 这意味着窗口大小必须严格介于 1 和 n − 1 之间。 
6. 使用前缀和和总和计算窗口组及其补集的质心。 
7. 对于每个有效窗口，使用 A 和 B 之间的叉积计算三角形面积，并更新最大值。 

### 为什么它有效

 任何使面积最大化的点划分都可以由穿过原点的分隔线表示。 当点按角度排序时，这样的线对应于圆上的连续间隔。 由于质心仅取决于总和，并且有效地维护了区间内的总和，因此最佳分区必须显示为这些区间之一。 循环复制确保我们不会错过围绕角度边界的间隔。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def area(ax, ay, bx, by):
    return abs(cross(ax, ay, bx, by)) / 2.0

n = int(input())
pts = []
sx = sy = 0

for _ in range(n):
    x, y = map(int, input().split())
    pts.append((x, y))
    sx += x
    sy += y

# sort by angle
import math
pts.sort(key=lambda p: math.atan2(p[1], p[0]))

# duplicate for circular window
ext = pts + pts

px = [0] * (2 * n + 1)
py = [0] * (2 * n + 1)

for i in range(2 * n):
    px[i + 1] = px[i] + ext[i][0]
    py[i + 1] = py[i] + ext[i][1]

ans = 0.0

l = 0
for r in range(1, 2 * n):
    while r - l + 1 > n:
        l += 1

    if r - l + 1 < n and r - l + 1 > 0:
        sx1 = px[r + 1] - px[l]
        sy1 = py[r + 1] - py[l]

        k = r - l + 1
        k2 = n - k

        if k2 == 0:
            continue

        ax = sx1 / k
        ay = sy1 / k

        bx = (sx - sx1) / k2
        by = (sy - sy1) / k2

        ans = max(ans, abs(ax * by - ay * bx) / 2.0)

print(f"{ans:.10f}")
```该解决方案首先读取所有点并计算全局总和，随后使用该总和来导出第二组的质心，而无需直接重新计算其总和。 

排序依据`atan2`按原点周围的角度顺序组织点，确保任何有效的几何切割对应于连续的线段。 复制步骤允许统一处理环绕间隔。 

前缀和`px`和`py`启用 O(1) 检索任何段总和，这是至关重要的，因为滑动窗口检查 O(n) 候选分区。 

对于每个右端点，我们缩小左指针以确保该段不超过大小 n。 这可以保持分区的有效性并确保两个组都非空。 

质心直接根据总和计算，三角形面积通过叉积计算。

 ## 边缘情况

 沿通过原点的任何直线的完全共线的点集迫使每个质心对位于同一条线上。 A 和 B 之间的叉积始终为零，并且该算法永远不会正确找到非零区域，因为所有候选窗口都保持共线性。 

对称配置（例如围绕原点形成正方形的点）会产生多个等效的最佳分区。 滑动窗口会遇到几个质心差相同的区间，无论选择哪个区间，最大值都保持稳定。 

非常小的输入，尤其是 n = 2，会减少为单个有效分区。 窗口逻辑自然地选择唯一可能的分割，并且质心计算保持明确定义，因为两组都只包含一个点。
