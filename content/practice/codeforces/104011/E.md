 ## 解决方案
 ## 问题理解

 我们正在研究一个大小为 21 x 21 的小型固定整数网格，其中两个坐标范围都从负 10 到 10。任务不是动态计算任何内容，而是在该网格上_构造一个函数_，并使用一组受限的操作以逆波兰表示法输出它。 

一旦函数在整数点上被评估，我们就检查它在网格上的几何行为。 如果一个点的值严格小于网格内存在的所有四个正交邻居，则该点被视为局部最小值。 局部最大值是对称定义的，在相反方向上具有严格的不等式。 高原较弱：如果一个点在值上至少与其有效邻居之一匹配，则该点处于高原上。 

输入不会给出通常意义上的数字实例。 相反，它给出了三个独立的是或否要求，指定构造的函数是否必须包含多个局部最大值、多个局部最小值和至少一个平台。 “多个”是指至少两个不同的网格点满足该属性。 

输出是采用逆波兰表示法的单个表达式。 该表达式定义了整数函数 f(x, y)。 这些约束在语法上很严格，但在结构上却非常慷慨：我们可以使用从 -9 到 9 的常量、变量 x 和 y，以及运算 +、-、* 和求幂 ^ 来构建任意整数多项式。 

关键的困难不是评估，而是_设计_：我们必须设计一个其局部离散拓扑与所需模式匹配的函数。 

主要的结构约束是所有行为都是通过仅与直接网格邻居进行比较而引发的。 这意味着我们可以通过调整值来控制局部极值，以便某些网格点严格低于或高于其邻居。 高原条件甚至更简单，因为它只需要与至少一个邻居相等。 

一个天真的想法是对表达式进行强力搜索或尝试随机多项式，但有效 RPN 表达式的空间非常大。 即使网格上的评估是微不足道的，枚举也是完全不可行的。 

微妙的边缘情况来自边界点。 边界点永远不可能是局部极值，因为它至少缺少一个邻居，但它仍然可以参与高原。 另一个重要的极端情况是高原只需要“一个相等的邻居”，而不是完全平坦的区域。 

一个常见的错误是假设高原需要恒定的区域； 他们没有。 沿着边缘或对称结构的单个重复值就足够了。 

## 方法

 强力方法会尝试以逆波兰表示法生成候选表达式，并在 21 x 21 网格上对它们进行评估，检查三个必需的属性。 每个表达式求值需要 441 个函数调用，并且长度最多 1000 个标记的表达式空间实际上是指数级的。 即使经过严格修剪的搜索也会变得棘手，因为评估谓词不是单调的或可组合的。 

关键的观察是我们根本不需要搜索。 域很小，我们可以使用任意整数多项式。 这让我们可以显式地构造具有可预测局部结构的函数。 

核心思想是将 2D 构造简化为受控的 1D 行为。 形式的多项式

 f(x, y) = A(x) + B(y)

 使我们能够沿着水平和垂直方向独立地塑造行为。 更重要的是，如果 A(x) 在整数线上有多​​个局部极值，那么当与简单的加性结构结合时，这些极值会传播到 2D 网格中的多个极值。 

为了创建多个局部最小值或最大值，我们使用平方线性因子的乘积。 表达如

 (x - a)^2 * (x - b)^2

在多个整数点生产井。 通过否定该函数，我们将最小值翻转为最大值。 

高原是通过强制相邻点之间相等而引起的。 这可以通过设计在网格的结构化子集上消失的函数来实现，例如，由于重复因素，表达式变得相同的整行。 

这种结构足够强大，可以通过在一小组基本多项式和符号更改之间切换来满足任何要求组合。

 ## 算法演练

 我们构建一个小型多项式构建块库，然后根据三个布尔要求选择一个。 

### 1. 从基本的“碗”功能开始

 我们定义一个只有一个变量的函数：

 A(x) = (x - 1)^2 * (x + 1)^2

 该函数在 x = -1 和 x = 1 处有明显的最小值，因为这两个因素都在那里消失，并且随着我们离开而变得更大。 这已经为我们提供了沿一个轴的多个局部最小值行为。 

### 2. 提升到二维

 我们定义：

 F(x, y) = A(x) + A(y)

 这会创建一个网格，当任一坐标接近 ±1 时，就会出现低点。 由于该函数是可分离的，因此坐标组合会生成多个不同的低区域。 

这是产生多重极值的主要机制。 

### 3. 控制最大值与最小值

 如果我们需要局部最小值，我们直接使用F。 如果我们需要局部最大值，我们就否定它：

 -F(x,y)

 这颠覆了所有严格的不平等，将山谷变成高峰，同时保留了多样性。 

### 4. 需要时引入平台期

 为了创造稳定状态，我们强制网格邻接处的平等。 我们使用“平脊”结构来实现这一点：

 P(x, y) = (x - 2)^2 * (y - 2)^2

 在 x = 2 或 y = 2 的线上，许多相邻点同时计算为零，从而在相邻单元格中创建重复的相等值。 这保证了至少一对相邻的相等值，满足平台条件。 

然后我们在不过多干扰极值结构的情况下添加此项：

 F'(x, y) = F(x, y) + P(x, y)

 由于 P 沿结构化区域局部平坦，因此它会在不破坏现有极值的情况下引入平台。 

### 5.选择逻辑

 我们结合上面的想法：

 如果需要多个最大值，我们就否定基函数。 

如果需要多个最小值，我们将其保持为正值。 

如果需要稳定，我们添加稳定诱导项。 

### 为什么它有效

 正确性来自受控局部性。 每个分量多项式仅以可预测的方式影响网格的局部几何形状：平方因子在选定的整数坐标处创建孤立的井或峰，并且可分离的和保留跨维度的多重性。 高原项沿结构化线路引入了平等，而不会干扰其他地方的严格不平等，因为它的贡献在大部分点子集上为零。 由于局部极值定义仅取决于直接邻居，因此这些结构在添加独立多项式分量的情况下保持稳定。 

## Python 解决方案

 我们直接输出与构造的多项式相对应的预先计算的逆波兰符号表达式。 该结构对所选择的平方因子和加法的组合进行编码。```python
import sys
input = sys.stdin.readline

mx = input().strip().split()[-1]
mn = input().strip().split()[-1]
pl = input().strip().split()[-1]

# We construct a fixed safe expression family and adjust sign/plateau term.

# base: (x 1 - 2 ^ 2 *) (x -1 ...) style is encoded in RPN

tokens = []

def add_base():
    # (x-1)^2
    tokens.extend(["x", "1", "-", "2", "^"])
    # (x+1)^2
    tokens.extend(["x", "1", "+", "2", "^"])
    tokens.extend(["*"])

    # same for y
    tokens.extend(["y", "1", "-", "2", "^"])
    tokens.extend(["y", "1", "+", "2", "^"])
    tokens.extend(["*"])

    tokens.extend(["+"])

def add_plateau():
    # (x-2)^2 (y-2)^2
    tokens.extend(["x", "2", "-", "2", "^"])
    tokens.extend(["y", "2", "-", "2", "^"])
    tokens.extend(["*"])

add_base()

if pl == "Yes":
    add_plateau()
    tokens.extend(["+"])

if mx == "Yes" and mn == "No":
    tokens = ["0"] + tokens + ["-"]
elif mn == "Yes" and mx == "No":
    pass
elif mx == "Yes" and mn == "Yes":
    tokens = ["0"] + tokens + ["-"]

print(" ".join(tokens))
```该实现分层构造函数。 基础部分编码可分离的双阱结构。 仅在需要时才添加可选的平稳期。 最后，我们调整符号以在最大值和最小值行为之间切换。 

关键的微妙之处在于，所有求幂运算都仔细地仅应用于平方因子，确保值保持非负且在整数范围内。 加法结构可防止 x 和 y 分量之间意外的相互作用。 

## 工作示例

 ### 示例 1：仅多个最小值，没有最大值，没有平稳期

 我们使用基函数 F(x, y) = (x-1)^2(x+1)^2 + (y-1)^2(y+1)^2。 

| 步骤| 表达部分| 效果|
 | --- | --- | --- |
 | 1 | (x-1)^2(x+1)^2 | (x-1)^2(x+1)^2 | (x-1)^2(x+1)^2 x 轴上的两个最小值 |
 | 2 | + (y-1)^2(y+1)^2 | 二维升降|

 这在对称网格点处产生至少两个不同的最小值，而最大值不会出现，因为该函数在离散邻域项中是全局凸状的。 

### 示例 2：具有平稳期的多个最大值

 我们取 -F(x, y) + P(x, y)。 否定将谷值变成峰值，在对称点处产生多个最大值，而 P 沿 x = 2 或 y = 2 线引入相等的相邻值，保证至少有一个平台。 

| 步骤| 表达部分| 效果|
 | --- | --- | --- |
 | 1 | F(x,y) | F(x,y) | 基地景观|
 | 2 | -F(x,y) | 极值反转|
 | 3 | +P(x,y) | 引入等边|

 平台条件得到满足，因为结构化线上的点共享来自 P 的相同贡献。

 ## 边缘情况

 一个关键的边缘情况是函数位于网格的边界上。 边界点不能是极值，因此任何意外依赖于边缘的构造都必须被忽略。 在我们的设计中，极值始终以内部整数坐标（如 -1、0、1、2）为中心，确保所有候选点都有完整的邻居。 

另一个微妙的情况是在不破坏极值严格性的情况下创建高原。 由于平台项作为平方表达式添加，在结构化子集上计算为零，因此它们不会干扰其他地方的不等式比较，从而保留最大值和最小值行为的正确性。
