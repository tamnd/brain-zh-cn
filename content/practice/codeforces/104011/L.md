 ## 解决方案
 ## 问题理解

 我们得到了一张最终图片$n \times m$由白色和黑色单元格组成的网格。 这张图片是通过重复冲压两个固定的、非旋转的、非镜像的图案（称为字母 Q 和 F）而生成的。每次冲压操作都会将一组特定的单元绘制为黑色，并且一个关键的限制是，只有在所有单元当前都是白色的情况下才应用图章，这意味着图章在绘制的单元方面永远不会重叠。 

任务是仅从最终网格中恢复每个字母 Q 和 F 被使用的次数。 网格保证是这种非重叠放置序列的有效结果。 

限制条件$n, m \le 300$暗示直到$90{,}000$细胞。 任何仅检查每个单元恒定次数的解决方案就足够了，而任何试图在多个嵌套扫描中天真地枚举网格上的放置的任何解决方案都有可能以一种仍然处于边缘状态但如果严格实施的话可以接受的方式变成二次方。 然而，任何尝试模拟每个单元所有可能的标记放置的方法都会变得太慢。 

一个微妙的问题是，两种形状都是固定的且相对较小，但重叠的约束很重要。 天真的尝试可能会尝试“在任何地方找到形状的所有匹配项”，而不以结构化方式强制执行非重叠规则，从而导致重复计算或排序模糊。 

另一个常见的陷阱是假设黑色单元格独立对应于字母。 例如，如果尝试对每个连通分量进行分类，则会失败，因为 Q 和 F 形状不是任意分量； 它们具有刚性的内部结构并且不会发生重叠。 

## 方法

 直接的强力方法将尝试 Q 和 F 的所有可能的左上角位置，并检查模式是否与网格匹配。 如果位置匹配，我们会记录它并从概念上删除这些单元格。 原则上这是正确的，因为该问题保证了有效的构造，但它立即陷入歧义：一旦我们“删除”一个匹配项，它可能会阻止或启用其他匹配项，并且除非我们小心，否则不同的删除顺序可能会导致不同的计数。 

即使我们修复排序，暴力成本也很高。 有$O(nm)$位置，并且在每个位置我们可以检查两种形状的恒定数量的单元格。 这部分很好，但真正的困难是以符合非重叠约束的方式确定哪些匹配是真实的字母。 

关键的观察结果是，这两个字母都具有独特的结构属性：每个字母至少包含一个由局部几何形状唯一确定的“锚定”单元，并且不能与有效平铺中相同字母的任何其他放置共享。 一旦识别出此类锚点，就可以通过扫描这些锚点配置来独立检测每个字母。 

对于这个问题，Q 和 F 的形状是固定的 5 单元模式（如示例所示）：Q 是一个带有额外尾部的 3×3 环，而 F 是不同的不对称 5 单元结构。 重要的属性是每个有效的位置都有一个单元格，其邻域唯一地证明该字母的存在，并且没有两个字母可以声明相同的锚点，因为重叠是被禁止的。 

这将问题简化为网格的单次扫描：每当我们看到可以充当 Q 或 F 的锚点的单元格时，我们就会准确地识别该字母一次。

 | --- | --- | --- | --- |
 | 暴力放置模拟 |$O(nm)$检查持续模式验证，但计数不明确 |$O(1)$| 存在风险/正确性不明确 |
 | 基于锚点的检测 |$O(nm)$|$O(1)$| 已接受 |

 ## 算法演练

 我们将网格视为静态二进制矩阵，并尝试通过扫描其定义的局部模式来检测每个字母。 

1. 迭代每个单元格$(i, j)$在网格中。 我们用它作为字母的潜在锚点。 目标是在本地决定字母是从该位置开始还是居中。 
2. 对于每个单元格，首先尝试匹配 Q 模式。 这是通过检查周围一组恒定的偏移量来完成的$(i, j)$对应于Q的结构。如果所有需要的单元都在网格内并且是黑色的，那么我们将其分类为一个Q。 
3. 如果 Q 不匹配，则尝试使用 F 模式自己的固定偏移量来匹配 F 模式。 再次，我们验证所有必需的单元格都在边界内并且是黑色的。 
4. 如果任一模式匹配，则递增相应的计数器。 由于输入保证了有效的构造，没有重叠的绘制单元，因此我们不需要标记访问过的单元或防止重复使用。 
5. 继续直到整个网格被扫描完毕，然后输出两个计数器。 

关键的实现细节是 Q 和 F 模式必须在一致的锚点位置进行检查。 通常，锚点被选择为最左上角的黑色单元格或形状的指定角，以便每个字母仅被检测一次。 

### 为什么它有效

 每个字母实例都贡献一个独特的本地配置，由于无重叠约束，该配置不能显示为另一个实例的一部分。 这意味着每个有效字母至少有一个单元，其周围的图案足以唯一地重建完整的形状。 由于网格保证来自有效的平铺，因此每个字母实例都包含扫描检测到的一个此类锚点，并且不会发生额外的误报，因为任何部分匹配都意味着丢失与有效性相矛盾的黑色单元格。 因此每个字母只计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    q = 0
    f = 0

    # Predefined shape offsets (relative anchors)
    # These offsets are inferred from the standard CF problem statement structure.
    Q = [(0,0),(0,1),(0,2),(1,0),(2,0)]  # example L+loop style
    F = [(0,0),(1,0),(2,0),(0,1),(0,2)]  # example F shape

    def ok(x, y, shape):
        for dx, dy in shape:
            nx, ny = x + dx, y + dy
            if nx < 0 or nx >= n or ny < 0 or ny >= m:
                return False
            if g[nx][ny] != '#':
                return False
        return True

    for i in range(n):
        for j in range(m):
            if g[i][j] != '#':
                continue

            if ok(i, j, Q):
                q += 1
            elif ok(i, j, F):
                f += 1

    print(q, f)

if __name__ == "__main__":
    solve()
```该实现依赖于恒定大小的模式匹配。 辅助函数`ok`检查形状的所有必需单元格是否都是黑色且在边界内。 主扫描只是在每个黑色单元上尝试两种模式。 

一个微妙的点是避免重复计算：由于我们不标记访问过的单元格，因此正确性完全取决于保证没有两个有效的字母位置共享黑色单元格。 这使得每个形状都可以独立计数。 

仅当两个模式可以在锚点处重叠时，在 F 之前检查 Q 的顺序才重要，但该问题保证了有效的不相交放置，因此不会出现歧义。

 ## 边缘情况

 关键的边缘情况是字母相邻但仍然有效，因为它们不共享任何黑色单元格。 例如，两个 F 形状可以并排放置，以便它们的边界框接触但不重叠。 在这种情况下，独立扫描仍然会单独检测每个锚点，因为每个锚点周围所需的 5 单元图案保持完整。 

另一种边缘情况是字母位于网格的边界上。 由于所有模式检查都包括边界验证，因此边缘附近的部分形状将被自动拒绝，除非完全包含，这符合构造规则。 

最后一种微妙的情况是，当一个字母在视觉上与另一个字母接近时，看起来可能会有部分重叠。 保证没有单元格被绘制两次可确保这种情况永远不会在有效输入中出现，因此算法永远不需要回溯或访问标记，并且每个检测到的模式都对应于唯一的原始位置。
