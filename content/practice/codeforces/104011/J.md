 ## 解决方案
 ## 问题理解

 我们正在研究一条固定长度的一维街道$L$。 一个端点是 Julia 的家所在位置$0$，另一个端点是 Jane 在位置的家$L$。 在零时刻，Jane 开始以恒定但未知的速度从她的一端走向 Julia，该速度是从给定列表中随机选择的$v_1, v_2, \dots, v_n$。 朱莉娅从位置开始$0$，知道所有可能的速度列表，但不知道选择了哪一个。 

Julia 可以沿着路段的任何位置移动，随时改变方向，并使用最大速度$V$。 只有当他们在同一点重合时，她才会看到简。 一旦朱莉娅遇见简，她必须以最快的速度回到家$V$。 总时间为集合时间加上返回时间。 

任务是计算最小可能的预期总时间，假设 Julia 针对 Jane 速度的均匀随机性选择了最佳策略。 

这些约束清楚地表明，任何解决方案都必须本质上是线性的$n$。 和$n$最多$10^5$、二次或偶数$n \log n$对每个速度的模拟进行推理是不必要的，而且可能是多余的。 问题的核心必须简化为评估每个速度的简单函数。 

一个微妙的困难是 Julia 不知道 Jane 的速度，因此任何策略都必须在流程开始之前选择，而不能依赖于实际情况$v_i$。 这排除了每个实例的自适应优化，并将解决方案推向在所有速度下表现最佳的阈值或结构策略。 

一个常见的失败案例是假设朱莉娅应该总是向简靠拢。 例如，如果$L=1000$,$V=10$， 和$v=50$与等待相比，积极前进实际上可能会导致结果更糟，因为简到达朱莉娅家的速度比朱莉娅接近她的速度要快得多。 

另一个失败案例是忽略回程成本。 在简家附近开会会减少会议时间，但会增加返回距离，这种权衡至关重要。 

## 方法

 自然的第一次尝试是模拟每种可能速度的策略$v_i$，计算会议时间，然后求平均值。 即使我们制定了一个简单的策略，比如“朱莉娅总是以正确的速度运行”$V$”，我们可以将会议时间计算为线性运动方程的解。

 如果朱莉娅快速移动$V$，简快速向左移动$v$，那么它们的距离以速率缩小$V+v$。 他们在某个时间相遇$t = \frac{L}{V+v}$，此时朱莉娅处于位置$x = Vt$。 总时间变为$t + \frac{x}{V} = \frac{2L}{V+v}$。 这为该策略提供了一个干净的封闭形式。 

然而，这种策略并不总是最佳的。 如果简比朱莉娅快得多，那么在家等待会更好，因为无论如何简都会很快到达。 等待换取见面时间$L/v$，并且由于会议在朱莉娅的家中举行，因此无需额外的移动费用。 

关键的观察结果是，朱莉娅只有两种有意义的行为：要么立即走向简，要么在家里等待。 搬家前的任何中间等待时间都可能陷入这些极端情况之一，而不会改善结果。 这会导致每个速度的最佳决策仅取决于 Jane 比 Julia 快还是慢。 

如果$v < V$，立即移动更好，因为 Julia 可以比 Jane 更快地缩短会议时间。 如果$v \ge V$，等待是最佳选择，因为 Jane 缩短距离的速度快于 Julia 通过移动获得优势的速度。 

因此，问题简化为评估每个的简单表达式$v_i$并求平均值。

 ## 算法演练

 ### 最优策略推导

 1.考虑固定速度$v$。 比较两种极端策略：在家等待，或者立即全速向简移动$V$。 
2. 如果 Julia 等待，Jane 会在一段时间后到达 Julia$\frac{L}{v}$，所以总时间是$\frac{L}{v}$。 
3. 如果 Julia 立即移动，则使用相对速度求解相遇方程$V+v$, 给予会议时间$\frac{L}{V+v}$。 
4. 开会时，朱莉娅在远处$x = V \cdot \frac{L}{V+v}$，所以返回时间为$\frac{x}{V} = \frac{L}{V+v}$。 
5. 因此立即移动给出了总时间$\frac{2L}{V+v}$。 
6. 为此选择两种策略中较好的一个$v$：$$\min\left(\frac{L}{v}, \frac{2L}{V+v}\right)$$7. 确定它们相等的阈值：$$\frac{L}{v} = \frac{2L}{V+v} \Rightarrow V = v$$8. 总结最优决策规则：

 如果$v \le V$，立即移动； 否则等待。 
9. 通过对所有最优成本求和来计算期望值$v_i$并除以$n$。 

### 为什么它有效

 对于固定的$v$，任何策略都可以分解为初始等待时间，然后是最大速度运动。 由此产生的成本成为等待时间的仿射函数，其斜率仅取决于$V-v$。 这会产生一种单调的行为：如果 Julia 更快，等待只会带来伤害；如果 Julia 更快，等待只会带来伤害。 如果简跑得更快，移动只会带来伤害。 结果，最优策略崩溃到零等待或完全等待的边界选择，因此没有中间策略可以改善期望。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, L, V = map(int, input().split())
    v = list(map(int, input().split()))

    ans = 0.0
    for x in v:
        if x <= V:
            ans += 2.0 * L / (V + x)
        else:
            ans += 1.0 * L / x

    print(ans / n)

if __name__ == "__main__":
    solve()
```该代码直接实现了导出的每速度公式。 关键的实现细节是始终使用浮点运算，因为最终答案需要高精度，并且表达式涉及除法。 

条件`x <= V`与导出的阈值完全匹配，包括相等，其中两个公式一致。 这避免了边缘情况分支不一致。

 ## 边缘情况

 平等案例$v = V$是主要的微妙点。 例如：```
1 100 10
10
```如果我们应用“立即移动”公式，我们会得到$\frac{2L}{V+v} = \frac{200}{20} = 10$。 如果我们等待，我们会得到$\frac{L}{v} = 10$。 该算法正确地分配任一行为，并且统一的公式确保没有不连续性。 

另一个边缘情况是当$v \gg V$， 例如：```
1 1000 1
100
```在这里，朱莉娅实际上太慢了，无法从移动中受益。 算法选择等待，产生$\frac{L}{v} = 10$。 任何搬家的尝试都会产生更大的价值，因为集合点远离朱莉娅的家，从而显着增加返回成本。 

这些案例证实，基于阈值的分解正确地将状态空间划分为两个状态，而不需要任何更细粒度的策略。
