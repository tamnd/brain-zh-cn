 ## 解决方案
 ## 问题理解

 我们在简化的时间轴上给出了两个点，其中每年都在 AD 系统或 BC 系统中标记。 每条输入行描述一个年份，如“AD 2022”或“5508 BC”。 任务是计算第一个给定年份的第一天和第二个给定年份的第一天之间有多少个整年。 

关键的微妙之处在于历史惯例，没有 0 年。围绕过渡的年份顺序是……公元前 2 年、公元前 1 年、公元 1 年、公元 2 年……。 如果我们不仔细编码映射，这会使有符号整数的直接减法变得有点棘手。 

约束很小，年份范围为 1 到 9999。这立即告诉我们，每个测试用例在恒定时间内运行的任何解决方案都是足够的，甚至重复的解析或简单的算术都可以忽略不计。 

主要的边缘情况是跨越 BC 到 AD 边界。 例如，在“公元前1年”和“公元1年”之间，答案不是2，而是1，因为它们之间正好有一年的边界步长。 将公元前年份视为包括零的负数的简单映射在这里将失败。 

另一个边缘情况是订购。 不保证较早的日期首先出现，因此任何解决方案都必须通过在一致的数字映射中采用绝对差来标准化。 

## 方法

 思考这个问题的一种强力方法是从较早的日期开始逐年模拟，然后递增或递减，直到到达较晚的日期，计算步数。 这在概念上很简单并且总是正确的，但这是不必要的工作。 尽管范围很小，但在最糟糕的公元前到公元转换中，端点之间的差异可能高达大约 20000 年，这仍然很小，但并不优雅，如果扩展，就会变得很尴尬。 

真正的见解是，这只是一个不连续性为零的线性排序问题。 如果我们可以将每年映射到一条整数线，其中邻接性与时间邻接性完全对应，那么答案就变成了简单的绝对差。 

自然的构造是将公元年指定为正整数，将公元前年指定为负整数，但需要进行修正：由于没有0年，我们必须确保公元前1年映射到-1，公元1年映射到+1，使得转换间隙在原始整数中恰好是2个单位，但实际上只有1年。 为了解决这个问题，我们在转换时将公元前年移一位，从而有效地跳过数轴中的零。 

一旦将这两个年份映射到这个校正后的整数轴上，它们之间的年数就是绝对差。

 ## 算法演练

 我们将每个输入年份转换为统一时间线上的整数，其中连续整数对应于历史上的连续年份。 

1. 将每一行解析为由数字年份值和方向标记（AD 或 BC）组成的对。 
2. 将年份转换为有符号整数表示形式。 如果年份是公元，我们直接将其映射到+year。 如果年份是 BC，我们将其映射到 -year。 在此阶段，BC 1 变为-1，AD 1 变为+1。 
3. 计算这两个整数之间的原始差。 然而，这种原始差异双重计算了缺失的零年过渡。 
4. 通过将 BC 侧视为向前移动 1 个单位来调整映射。 这可以通过将 BC 年 y 映射到 -(y - 1) 来等效地实现，这确保 -1 对应于 1 BC，0 对应于 AD 1 的前一个时隙，从而有效地消除了不存在的年份间隙。 
5. 转换后，取两个映射值之间的绝对差。 这给出了两个 1 月 1 日边界之间逐年转换的确切数量。

### 为什么它有效

 整数映射构建了真实历史年份和单位间距整数之间的双射。 映射值每增加 1 就对应向前移动一个日历年，包括跨越公元前到公元边界。 由于映射保留了邻接性并消除了人为的零点，因此整数空间中的距离与实时经过的年数相同。 因此，绝对差异准确地计算了年份转换的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def parse(line: str) -> int:
    parts = line.strip().split()
    if parts[0] == "AD":
        return int(parts[1])
    else:
        y = int(parts[0])
        return -(y - 1)

a = parse(input())
b = parse(input())

print(abs(a - b))
```该解决方案读取两行并将每行转换为统一的整数时间线值。 辅助函数通过移动 BC 年份来处理 BC 和 AD 之间的不对称性，从而不存在人为的零点。 

最终答案被计算为绝对差，这是有效的，因为映射保证了线性邻接。 

一个常见的错误是将公元前年份直接映射到负整数而不进行移位。 这会导致“1 BC”为 -1，“AD 1”为 +1，这错误地暗示距离为 2。纠正后的移位正好解决了这个问题。

 ## 边缘情况

 对于 BC 到 AD 的转换，请考虑输入“1 BC”和“AD 1”。 解析器将 BC 移位 1 后分别将它们映射为 0 和 1。 差值为 1，与跨越边界的单年过渡相匹配。 

对于纯 BC 输入（如“2 BC”和“1 BC”），映射给出 -1 和 0。差异为 1，正确反映了按时间倒序排列的连续年份。 

对于相同的年份，例如“AD 2022”和“AD 2022”，都映射到 2022 年，按预期生成 0。 

移位逻辑确保所有不连续性都被吸收到连续的整数线中，因此每个可能的排序都简化为单个绝对差计算。
