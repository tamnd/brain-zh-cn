 ## 解决方案
 ## 问题理解

 网格是无限的，除了单元格`(0,0)`包含一堵墙。 遥控器包含一个固定的动作序列。 放置在某个非墙壁单元的汽车遵循该顺序，但每当移动进入墙壁时，该单个移动将被忽略，汽车将继续执行其余命令。 

对于每个起始坐标，我们需要在按下按钮一次后找到最终坐标。 

命令序列的长度可达`300000`，并且还可以有多达`300000`查询。 对每个查询的整个路径进行模拟最多需要`9 * 10^10`最坏情况下的操作，远远超出了2秒的限制。 我们需要对命令序列进行一次预处理，并在恒定时间内回答每个查询。 

关键的困难在于，墙只影响可以与其碰撞的起始位置。 大多数起始位置只是遵循命令序列，就好像墙不存在一样。 

粗心的实现可能会在命令路径中的重复位置上失败。 例如，如果路径多次访问相同的位移，则第一次访问是重要的，因为汽车撞到了那里的墙壁并改变了模拟的其余部分。 

对于命令：```
2
RL
```前缀位移是`(0,0)`,`(1,0)`,`(0,0)`。 开始于`(0,-0)`无效，因为它是墙，但在附近的情况下也会出现相同的重复位置问题。 如果我们存储最后一次出现的前缀位置而不是第一次出现的前缀位置，则计算出的碰撞点将是错误的。 

另一个边缘情况是命令路径永远不会返回相同的位移。 为了：```
1
R
```查询开始于`(5,5)`应该输出`(6,5)`。 尝试处理路径附近的每个点而不是使用位移观测的解决方案会浪费时间。 

## 方法

 直接的方法是模拟每个查询的命令。 对于查询`(x,y)`，我们保留当前位置并应用命令的每个字符。 每当下一个单元格是`(0,0)`，我们跳过该动作。 这显然是正确的，因为它完全遵循汽车的规则，但需要`O(N)`每次查询的时间。 两者都有`N`和`Q`等于`300000`，这变成了`O(NQ)`，这是不可能的。 

重要的观察是，只有翻译的命令路径到达原点时，墙才有意义。 让`P[i]`是第一个之后汽车的位移`i`开始时的命令`(0,0)`。 没有墙，汽车从`(x,y)`结束于：```
(x + P[N].x, y + P[N].y)
```仅在以下情况下才会遇到墙壁：```
(x,y) + P[i] = (0,0)
```这意味着：```
(x,y) = -P[i]
```因此，只有作为前缀位置的负数的起始位置才需要特殊处理。 

对于这些位置，路径第一次到达墙壁时就是该前缀位移的第一次出现。 在该被阻止的移动之后，路径的剩余后缀将正常执行。 我们可以在扫描一次命令的同时，对每个危险起始位置的答案进行预处理。 

暴力破解之所以有效，是因为它遵循精确的模拟，但会失败，因为它对许多查询重复相同的工作。 观察到只有前缀位移才会导致冲突，从而减少了预处理一组异常状态的问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(NQ) | O(1) | O(1) | 太慢了|
 | 最佳 | O(N + Q) | O(N) | 已接受 |

 ## 算法演练

 1. 计算整个命令序列的总位移。 任何起始位置永远不会到达墙壁的查询都可以通过添加此位移来回答。 
2. 扫描命令序列并存储每个前缀位移。 对于每个位移，仅保留其第一次出现的索引。 第一次发生是汽车第一次可能撞到相应起始位置的墙壁的时间。 
3. 对于前缀位置的每个第一次出现`P[i]`，为危险起点创建一个条目`-P[i]`。 
4. 要计算危险起点的最终位置，令`i`是路径第一次到达该前缀位移的时间。 碰撞前，汽车到达由 表示的位置`P[i-1] - P[i]`。 当时的命令`i`被阻止，其余命令贡献位移`P[N] - P[i]`。 

因此最终的立场是：```
P[i-1] - P[i] + P[N] - P[i]
```或者：```
P[N] + P[i-1] - 2 * P[i]
```1. 对于每个查询，检查其坐标是否存在于预先计算的危险位置地图中。 如果是，则输出存储的答案。 否则，输出正常的平移位置。 

为什么它起作用：与墙的每个可能的交互都与命令路径的前缀位移精确对应。 如果起始位置不是任何前缀位移的负值，则永远不会到达墙壁，并且最终位置只是总位移。 如果这是一个危险的位置，则该前缀位移的第一次出现决定了第一个被阻止的移动。 在那之后，汽车的行为完全由剩余的后缀决定，这正是公式计算的结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    s = input().strip()

    dx = [0] * (n + 1)
    dy = [0] * (n + 1)

    x = y = 0
    for i, c in enumerate(s, 1):
        if c == 'L':
            x -= 1
        elif c == 'R':
            x += 1
        elif c == 'U':
            y += 1
        else:
            y -= 1
        dx[i] = x
        dy[i] = y

    total_x, total_y = x, y

    first = {}
    for i in range(n + 1):
        pos = (dx[i], dy[i])
        if pos not in first:
            first[pos] = i

    special = {}
    for (px, py), i in first.items():
        if px == 0 and py == 0:
            continue
        prev_x = dx[i - 1]
        prev_y = dy[i - 1]
        ans_x = total_x + prev_x - 2 * px
        ans_y = total_y + prev_y - 2 * py
        special[(-px, -py)] = (ans_x, ans_y)

    q = int(input())
    out = []
    for _ in range(q):
        x, y = map(int, input().split())
        if (x, y) in special:
            ax, ay = special[(x, y)]
            out.append(f"{ax} {ay}")
        else:
            out.append(f"{x + total_x} {y + total_y}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```数组`dx`和`dy`存储从原点开始的命令路径。 保留所有前缀可以避免在回答查询时重新计算坐标。 

这`first`字典是预处理的重要部分。 当相同的位移出现多次时，只存储最早的索引，因为那是第一次碰撞发生的地方。 使用最后一个事件会模拟一辆已经穿过墙壁的汽车，这是不可能的。 

这`special`字典仅存储非墙起始坐标。 原点被排除，因为汽车永远无法从那里启动。 每个正常的查询都会避免这种字典查找并直接使用总位移。 

所有计算都使用Python整数，因此不存在溢出问题。 索引与`i - 1`是安全的，因为第一次存储的出现`(0,0)`是索引`0`，并且该情况被跳过。

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(N + Q) | 命令路径被扫描一次，每个查询都通过字典查找来回答。 |
 | 空间| O(N) | 我们存储前缀位移和危险的起始位置。 |

 ## 边缘情况

 重复的前缀位置必须使用其第一次出现的位置。 假设命令路径多次达到相同的位移。 以负排量出发的汽车在第一次访问时会发生碰撞，因此以后的访问无关紧要。 预处理保留最早的索引并产生正确的后缀模拟。 

永远不会到达墙的查询一定不能进入特殊情况逻辑。 例如，与：```
1
R
1
5 5
```总位移为`(1,0)`。 自从`(-5,-5)`不是前缀位置，答案很简单`(6,5)`。 

立即返回或重复位置的路径由相同的规则处理。 字典仅包含每个位移第一次出现的时间，因此模拟始终使用第一个被阻止的移动，并且从不假设汽车可以穿过墙壁。
