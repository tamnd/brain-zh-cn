 ## 解决方案
 ## 问题理解

 该安装是一个完整的图：每对节点之间都有一根电线。 唯一缺少的信息是哪个标签值属于哪条电线。 我们收到所有标签值，并且必须决定这些值的两种不同分配。 

第一个分配应该使最​​小生成树尽可能便宜。 第二个分配应该使最​​小生成树尽可能昂贵。 两种情况下的输出都是 MST 成本。 

节点数量最多为100个，因此电线数量可以达到$$\frac{100 \cdot 99}{2}=4950$$它足够小，我们可以对所有标签进行排序并进行线性扫描。 尝试所有可能的标签到电线分配的解决方案是不可能的，因为即使是 4950！ 作业存在。 预期的方法必须使用完整图的结构，而不是探索单独的线。 

主要棘手的情况是由相等的值和非常小的图形引起的。 相同的标签不能被视为不同的选择，因为交换它们不会改变任何内容。 小值`N`也很重要，因为当仅存在一条或两条 MST 边时，基于顶点组的公式必须仍然有效。 

例如，对于两个节点，只有一根电线。```
Input
2
10

Output
10 10
```假设存在多个 MST 边缘的粗心实现可能会访问不存在的位置。 

另一种情况是所有标签都相同。```
Input
4
7 7 7 7 7 7

Output
21 21
```每个可能的分配都会产生相同的 MST 成本。 试图强迫不同的最小和最大选择的方法会产生错误的答案。 

第三种边缘情况是一个小的完整图，其中最大分配不是通过取最大的来获得的`N - 1`标签。```
Input
4
3 5 5 8 8 9

Output
13 16
```最大的三个标签之和为 25，但不能强制进入 MST。 较小的标签可以隐藏在已连接的组内，并且最大可能的 MST 使用排序顺序中特定位置的标签。 

## 方法

 直接的解决方案将尝试将每个标签放置在每个可能的电线上并计算生成的 MST。 使用 Kruskal 算法，MST 计算本身很容易，但分配数量是连线数量的阶乘。 即使是为了`N = 10`，已经有 45 根电线，使得这种方法完全无法使用。 

第一个观察结果是该图是完整的。 由于每对节点都有一条线路，因此最便宜的 MST 分配很简单。 我们可以放置最小的`N - 1`任何树边缘的标签。 Kruskal 将准确选择这些边，因为它们已经连接了所有顶点。 每个剩余的边都可以接收更大的值，而不影响 MST。 最小答案是第一个答案的总和`N - 1`排序后的值。 

最大的情况需要不同的视图。 Kruskal 从最小到最大处理边缘。 第一条边始终进入 MST，因为最初每个节点都是孤立的。 在该边连接两个节点之后，可以通过为其分配一个较小的值来使这两个节点之间的边变得无用，因为两个端点已经在同一个组件中。 

为了延迟以后的 MST 选择，我们希望创建一个不断增长的连接组件。 选择后`i - 1`MST 边，该组件有`i`顶点。 里面有$$\frac{i(i-1)}{2}$$边，并且所有边都可以出现在下一个有用边之前而不被选择。 这意味着`i`第 MST 边可以放置在位置$$\frac{i(i-1)}{2}+1$$在标签的排序列表中，使用基于一的索引。 

例如，对于四个顶点，最大 MST 使用位置：```
i = 1: position 1
i = 2: position 2
i = 3: position 4
```对于样本值`3 5 5 8 8 9`，这给出了`3 + 5 + 8 = 16`。 

这两种策略可以总结如下。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(M! * M log M) | O(M! * M log M) | O(M)| 太慢了|
 | 最佳 | O(M log M) | O(M log M) | O(M)| 已接受 |

 ## 算法演练

 1. 按非降序对所有标签值进行排序。 标签的顺序是唯一需要的信息，因为 MST 取决于相对边权重。 
2. 通过添加第一个来计算最小 MST 成本`N - 1`排序值。 这些值总是可以放置在生成树上，迫使 Kruskal 选择它们。 
3. 通过迭代第一个来计算最大 MST 成本`N - 1`MST 边缘。 对于`i`选定的边，在索引处添加值`i * (i - 1) / 2`在从零开始的索引中。 
4. 打印两个累加值。 

最大施工量是因为之后`i - 1`选定的边，最好的排列有一个组件包含`i`顶点。 该组件内的所有边都可以用较小的标签填充，并被 Kruskal 忽略。 连接该组件到新顶点的下一条边恰好在处理所有这些内部边后出现。 

为什么它有效：

 对于最小答案，任何 MST 都不能包含少于`N - 1`边，并且通过使用最小的标签来实现这么多标签的最小可能总和`N - 1`标签。 

为了获得最大答案，每个 MST 边必须在 Kruskal 选择它时连接两个不同的组件。 第一个有用的边缘只能出现在零个内部边缘之后，第二个有用的边缘只能出现在一个内部边缘之后，第三个有用的边缘只能出现在三个内部边缘之后，依此类推。 增长单个组件可以最大化每个 MST 边之前可隐藏的边数。 公式生成的头寸恰好是最新的可能头寸，因此所得总和是可实现的最大 MST 成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    c = list(map(int, input().split()))
    c.sort()

    mn = sum(c[:n - 1])

    mx = 0
    for i in range(1, n):
        idx = i * (i - 1) // 2
        mx += c[idx]

    print(mn, mx)

if __name__ == "__main__":
    solve()
```输入恰好包含一个测试用例，因此解决方案只需要一个执行路径。 

排序后计算最小的取第一个`n - 1`条目。 切片是安全的，因为树上`n`顶点总是有精确的`n - 1`边缘。 

对于最大值计算，循环变量`i`表示在添加下一条 MST 边之前已在增长组件内的顶点数。 从零开始的索引`i * (i - 1) // 2`与一基位置相同`i * (i - 1) / 2 + 1`。 

Python 整数不会溢出，这很重要，因为标签值最多可达`2 * 10^9`MST 可以包含 99 条边。

 ## 边缘情况

 对于两个节点来说，只有一根线路，因此最便宜和最昂贵的 MST 成本是相同的。```
Input
2
10
```排序后的数组是`[10]`。 最小值使用唯一的值。 最大循环也运行一次并选择索引零。 输出是：```
10 10
```当每个标签都相等时，每个可能的分配都会给出相同的 MST。```
Input
4
7 7 7 7 7 7
```最少使用三个七。 最多也选择三个位置，但每个位置包含七个。 两个结果都是：```
21 21
```对于最大的情况`N - 1`标签不能形成最大MST：```
Input
4
3 5 5 8 8 9
```排序后，最大位置就是索引`0`,`1`， 和`3`。 该算法选择`3`,`5`， 和`8`。 价值观`8`和`9`不能将两者都强制放入 MST，因为太多较大的边已经使较小的边无法隐藏。 结果是：```
13 16
```这正是组件增长论点重要的情况。 该算法并不是简单地选取较大的值；而是选取较大的值。 它选择实际上可以作为克鲁斯卡尔选择的边出现的值。
