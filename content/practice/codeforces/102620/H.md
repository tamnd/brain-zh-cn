 ## 解决方案
 # 问题理解

 该问题描述了冰山的集合，其中每个冰山通过其边界点的坐标被指定为一个简单的多边形。 任务是计算所有冰山覆盖的总面积并仅输出该面积的整数部分。 多边形不重叠，因此它们各自的面积可以简单地添加在一起。 输入包含多个独立的多边形描述，输出是它们的面积向下舍入的总和。 

多边形的数量可以达到1000个，每个多边形最多有50个顶点。 这意味着顶点总数最多为 50000 个，因此处理每个顶点恒定次数的算法很容易足够快。 在某些情况下，比较每个多边形的每对边的方法仍然适用于这些限制，但这是不必要的。 预期的方法应该与顶点数量成线性，因为几何有一个直接的公式。 

主要的边缘情况来自多边形方向和分数区域。 多边形可以顺时针或逆时针列出，因此直接应用带符号面积公式而不考虑符号可能会产生负结果。 例如：```
1
4
0 0
0 1
1 1
1 0
```正确的输出是：```
1
```粗心的实现可能会计算出一个有符号区域`-1`并错误地打印负值。 

另一种情况是实面积不是整数。 例如：```
1
3
0 0
1 0
0 1
```实际面积为`0.5`，所以所需的输出是：```
0
```答案不会四舍五入到最接近的整数。 小数部分必须始终被丢弃。 

最后一个常见错误是忘记最后一个顶点连接回第一个顶点。 对于此输入：```
1
4
0 0
2 0
2 2
0 2
```输出是：```
4
```忽略闭合边缘会留下不完整的多边形并给出错误的面积。 

## 方法

 强力方法是将每个多边形分成许多小块或尝试在网格上模拟形状的内部。 这是不必要的，因为坐标是精确的并且多边形边界已经包含足够的信息。 基于网格的解决方案将取决于坐标范围，该范围可以达到一百万，使得可能的单元格数量太大。 

关键的观察是，可以使用鞋带公式直接从其边界获得多边形区域。 每对连续的顶点都会贡献一个带符号的值，该值表示以原点形成的三角形的面积。 当所有贡献相加时，重叠的有符号区域会正确取消，从而准确地留下多边形的面积。 

蛮力方法之所以有效，是因为它试图重建冰山的内部，但它忽略了边界已经完全描述了形状的事实。 通过观察面积仅取决于有序边，我们可以将问题简化为对所有顶点进行一次遍历。 

对于有顶点的多边形`(x1, y1), (x2, y2), ... , (xp, yp)`，有符号双精度面积为：$$S = \sum_{i=1}^{p}(x_i y_{i+1} - x_{i+1} y_i)$$其中最后一个顶点之后的下一个顶点是第一个顶点。 实际面积为`abs(S) / 2`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(坐标范围面积) | O(1) | O(1) | 太慢了|
 | 鞋带配方| O(顶点总数) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取多边形的数量。 对于每个多边形，存储第一个顶点，因为最终的边必须连接回它。 
2. 遍历每个顶点，并添加当前顶点和下一个顶点之间的叉积贡献。 贡献是`x1*y2 - x2*y1`。 
3. 处理完所有边后，取累加值的绝对值，因为输入顺序可能在任一方向上描述多边形。 
4. 将加倍的面积添加到全局总和中。 将所有内容保持加倍可以避免处理几何图形时的浮点错误。 
5. 处理完所有多边形后，使用整数除法将总面积加倍的面积除以二。 这会根据需要自动删除小数部分。 

为什么它有效：

 鞋带公式基于将多边形分解为带符号的三角形。 如果顶点逆时针排列，则所有三角形都有正向贡献。 如果按顺时针顺序排列，则所有贡献均为负。 取绝对值即可恢复真实的两倍面积。 由于多边形不重叠，因此将所有多边形的双倍面积相加即可得到总覆盖面积的两倍。 整数除以二即可得出所需的下限值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    total2 = 0

    for _ in range(n):
        p = int(input())
        points = []

        for _ in range(p):
            x, y = map(int, input().split())
            points.append((x, y))

        area2 = 0
        for i in range(p):
            x1, y1 = points[i]
            x2, y2 = points[(i + 1) % p]
            area2 += x1 * y2 - x2 * y1

        total2 += abs(area2)

    print(total2 // 2)

if __name__ == "__main__":
    solve()
```输入是逐个多边形处理的，因为只需要当前边界。 点列表被临时存储，以便最后一个顶点可以连接回第一个顶点。 

表达式`(i + 1) % p`处理闭合边缘。 如果没有模运算，每个多边形的最后一条边都会丢失。 

计算使用双倍面积而不是浮点值。 坐标可以大到一百万，因此叉积可能很大，但 Python 整数会自动扩展以容纳所需的值。 在添加到最终答案之前，会对每个多边形应用绝对值，因为每个多边形可能都有自己的方向。

 ## 边缘情况

 顺时针多边形通过取有符号面积的绝对值来处理。 为了：```
1
4
0 0
0 1
1 1
1 0
```累计面积翻倍为`-2`。 该算法将其转换为`2`，然后除以二得到`1`。 

具有分数面积的多边形将保持双倍的值，直到最终操作。 为了：```
1
3
0 0
1 0
0 1
```加倍的面积是`1`。 该算法计算`1 // 2`，生产`0`，这符合所需的地板行为。 

通过使用最后一个顶点之后的第一个顶点来包含闭合边。 为了：```
1
4
0 0
2 0
2 2
0 2
```最终贡献来自`(0,2)`回到`(0,0)`包括在内，面积增加一倍`8`和最终答案`4`。
