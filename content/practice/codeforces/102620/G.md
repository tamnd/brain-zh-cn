 ## 解决方案
 ## 问题理解

 乐曲由一系列音符表示。 每个音符可能已经有一个所需的弓方向，或者向下弓（`D`) 或向上鞠躬 (`U`），或者可能没有标记（`B`）。 我们必须决定所有未标记音符的方向。 最终序列不能包含任何`B`，并且不能更改原始标记。 

当两个相邻的音符使用相同的方向时，就会发生钩弓。 我们的目标不是避免所有钩弓，因为当某些固定音符迫使它们时，这可能是不可能的。 相反，我们需要为未标记的音符选择方向，以使相等的相邻对的总数尽可能小。 

输入大小最多允许 1000 个音符。 尝试空白音符的所有可能分配的解决方案需要考虑最多$2^{1000}$可能性，这远远超出了可以运行的范围。 我们需要一种直接处理序列的方法，利用下一个音符的决策仅取决于前一个音符选择的方向这一事实。 

棘手的情况是最优选择在局部不明显的地方。 例如，如果输入是：```
3
B D B
```正确的答案可能是：```
U D U
```有两个方向变化和零钩弓。 总是选择与前一个音符不同的方向的贪婪策略可能会在以后失败，因为前面几个位置的固定音符可能会迫使人们做出更好的早期选择。 

另一种边缘情况是每个音符都已固定：```
4
D D U U
```唯一有效的输出是：```
D D U U
```有两个钩状的弓。 在搜索最小值时尝试修改固定注释的实现将产生无效答案。 

最终的边界情况是一个注释：```
1
B
```答案可以是`U`或者`D`。 没有相邻的音符，因此钩弓的最小数量为零。 假设每个音符都有一个左邻居的代码在这里可能会失败。 

## 方法

 直接的暴力方法是替换每一个`B`与任一`U`或者`D`，评估结果序列，并保留具有最少钩状鞠躬的分配。 这是正确的，因为它会检查乐谱的所有可能的有效完成。 但是，如果 1000 个笔记全部为空，则作业数量为$2^{1000}$，并且每个作业都需要扫描整个序列。 操作次数大致为$1000 \times 2^{1000}$，这是不可能的。 

问题的结构给了我们一个更小的状态空间。 选择当前音符的方向时，前一个音符中唯一重要的信息是前一个音符的方向。 在我们知道以结尾的最佳成本后，前十个音符是否包含许多钩弓或少量钩弓并不重要`U`最佳成本以`D`。 

这自然会导致动态规划。 对于每个位置，我们存储截至该点的所有有效分配中的最小钩弓数量，并以最后一个音符的方向分隔。 当处理下一个音符时，如果它是空白的，我们会尝试两个可能的方向，如果它是固定的，我们会尝试单个允许的方向。 每当新方向等于前一个方向时，过渡就会加一。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N × 2^N) | O(N × 2^N) | O(N) | 太慢了|
 | 最佳| O(N) | O(N) | 已接受 |

 ## 算法演练

 1. 为每个位置创建两个动态规划状态。 一种状态存储以结尾的作业中钩弓的最小数量`U`，另一个为以结尾的赋值存储相同的值`D`。 

我们只保留最后一个方向的原因是下一个音符只能与其直接前一个音符创建新的钩弓。 
2. 初始化第一个音符。 如果固定为`U`，只有`U`状态是可能的。 如果固定为`D`，只有`D`状态是可能的。 如果为空，则两种状态都可能且成本为零。 
3. 从左到右处理剩余的音符。 对于当前音符的每个可能的方向，查看前一个音符的两个可能的方向。 当两个方向相等时，将成本加一，因为这会产生钩状弯曲。 
4. 存储较小的值并记住之前的方向产生该值。 存储的父信息允许我们在找到最小成本后重建实际序列。 
5. 整块加工完成后，选择最终成品中较小的一个`U`和`D`州。 按照保存的家长指示向后恢复完整的答案。 

为什么它有效：

 动态规划不变量是处理后的位置`i`，每个状态都包含第一个状态的所有有效分配中的最小可能数量的钩弓`i + 1`带有指定最后方向的注释。 过渡考虑当前音符的每个可能的方向以及前一个前缀的每个可能的最佳结束方向。 由于每个完整的作业必须以以下任一结束`U`或者`D`，采用更好的最终状态给出全局最优解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(s):
    n = len(s)

    inf = 10**9
    dp = [[inf, inf] for _ in range(n)]
    parent = [[-1, -1] for _ in range(n)]

    choices = []
    for c in s:
        if c == 'U':
            choices.append([0])
        elif c == 'D':
            choices.append([1])
        else:
            choices.append([0, 1])

    for c in choices[0]:
        dp[0][c] = 0

    for i in range(1, n):
        for cur in choices[i]:
            for prev in (0, 1):
                cost = dp[i - 1][prev] + (1 if cur == prev else 0)
                if cost < dp[i][cur]:
                    dp[i][cur] = cost
                    parent[i][cur] = prev

    last = 0 if dp[-1][0] <= dp[-1][1] else 1

    ans = [0] * n
    ans[-1] = last
    for i in range(n - 1, 0, -1):
        ans[i - 1] = parent[i][ans[i]]

    return ' '.join('U' if x == 0 else 'D' for x in ans)

def main():
    n = int(input())
    s = input().split()
    print(solve_case(s))

if __name__ == "__main__":
    main()
```这`choices`array 将每个音符转换为其允许的方向集。 固定音符只有一个可能的方向，而空白音符则有两种可能的方向。 

这`dp`表存储每个位置的最佳钩弓数量。 指数`0`代表`U`和索引`1`代表`D`。 在转换过程中，表达式`(1 if cur == prev else 0)`完全符合钩弓的定义。 

这`parent`需要表格是因为仅靠最低成本是不够的。 到达末尾后，我们需要输出一个实际的序列。 通过存储产生每个最佳状态的先前方向，我们可以重建答案，而无需存储每个候选序列。 

不存在大的算术问题，因为钩弓的最大数量仅为`N - 1`，所以普通的 Python 整数就足够了。 第一个音符单独初始化，因为它没有前一个音符，无法创建钩弓。 

## 工作示例

 考虑示例：```
7
B D B B B U U
```一个可能的动态规划轨迹是：

 | 位置 | 注意| 最好的结局你| 最佳结局D | 最终选择的方向 |
 | --- | --- | --- | --- | --- |
 | 0 | 乙| 0 | 0 | |
 | 1 | d | 信息 | 0 | |
 | 2 | 乙| 1 | 1 | |
 | 3 | 乙| 1 | 2 | |
 | 4 | 乙| 2 | 2 | |
 | 5 | 你| 2 | 信息 | |
 | 6 | 你| 2 | 信息 | |

 从存储的父项重建的最终答案是一个最佳分配，例如：```
U D D U D U U
```该轨迹表明该算法并未独立地最小化每个本地对。 它保留了两种可能的结局，因为未来更好的决定取决于之前的方向。 

第二个例子：```
4
D D U U
```跟踪变为：

 | 位置 | 注意| 最好的结局你| 最佳结局D | 最终选择的方向 |
 | --- | --- | --- | --- | --- |
 | 0 | d | 信息 | 0 | |
 | 1 | d | 信息 | 1 | |
 | 2 | 你| 1 | 信息 | |
 | 3 | 你| 1 | 信息 | |

 唯一有效的输出是：```
D D U U
```两个相等的相邻对是不可避免的。 动态编程状态正确地保留固定标记，而不是尝试删除这些钩子。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N) | 每个注释仅考虑两个先前状态和两个当前状态。 |
 | 空间| O(N) | 父表存储重建期间每个状态的一个先前方向。 |

 1000 个音符的约束很容易满足这个线性解决方案。 即使使用父重建数据，内存使用量也只有几千个整数。

 ## 边缘情况

 对于单个空白注释：```
1
B
```该算法以零成本初始化这两个状态。 由于没有过渡，因此任一方向都是最佳的，并且重建会返回一个有效答案。 

对于固定连续音符：```
4
D D U U
```该算法从不插入替代方向，因为每个位置的选择列表仅包含固定值。 转换对两个不可避免的相等对进行计数，产生唯一有效的完成。 

对于固定音符周围的空白：```
3
B D B
```可以指定第一个空白`U`最后一个空格也可以指定`U`，生产：```
U D U
```两个过渡都在不同方向之间，因此答案的钩状弯曲为零。 动态编程状态在每一步都保留两种可能性，从而允许找到全局选择。
