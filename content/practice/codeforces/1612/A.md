 ## 解决方案
 ## 问题理解

 我们正在开发一个网格，其中使用曼哈顿距离来测量运动，这意味着两点之间的成本是水平和垂直间隔的总和。 其中一个点固定在原点，第二个点位于坐标$(x, y)$。 任务是判断是否存在中间网格点$C$，具有非负整数坐标，恰好位于原点和$B$。 如果存在这样的点，我们必须输出任何有效的点； 否则我们报告不可能。 

需求的结构是对称的：从原点到$C$必须等于从原点到$B$，并且同样必须成立$B$到$C$。 这立即意味着$C$不仅仅是欧几里得术语中的任何中点，而是 L1 度量下的中点，其行为非常不同，因为距离跨轴分割而不是形成一条直线。 

约束很小，坐标以 50 为界，最多有 3000 个测试用例。 这意味着$O(1)$或者在最坏的情况下需要每个测试用例的恒定因子构造； 即使是对网格进行强力扫描，理论上也是可能的，但没有必要。 然而，正确性不是由性能决定的，而是由对曼哈顿中点何时存在的理解决定的。 

当出现微妙的边缘情况时$x + y$很奇怪。 在这种情况下，曼哈顿距离$A$到$B$是奇数，将其减半会产生一个非整数。 由于整数点之间的曼哈顿距离始终是整数，因此不存在有效的中点。 例如，当两个坐标都很小但混合奇偶校验时，会发生另一种失败情况$(2, 1)$，其中诸如独立分割坐标之类的天真的尝试无法同时满足两个距离约束。 

## 方法

 天真的方法会尝试每个候选点$C = (i, j)$和$0 \le i, j \le x + y$，计算两个距离，并检查两者是否相等$(x + y)/2$。 这在概念上是有效的，因为网格很小，但在最坏的情况下，它会粗略地检查$O((x+y)^2)$每个测试用例的候选人。 在 3000 个测试用例中，这在理论上仍然是可以管理的，但不必要地昂贵并且模糊了底层结构。 

关键的观察结果是曼哈顿距离沿轴分解。 我们想要：$$|x| + |y| = d$$我们需要一个点$C = (c_x, c_y)$这样：$$c_x + c_y = d/2$$还有：$$|x - c_x| + |y - c_y| = d/2$$一旦我们将其解释为将所需的总距离划分为水平和垂直贡献，几何形状就变得简单。 由于所有点都位于第一象限，绝对值消失，问题简化为分布$d/2$x 轴和 y 轴之间的距离单位，其方式与到达两个端点一致。 

让$d = x + y$。 如果$d$为奇数，不存在整数中点。 如果是偶数，我们需要构造$c_x, c_y \ge 0$这样：$$c_x + c_y = d/2$$和$c_x$不超过$x$以一种打破与距离的一致性的方式$B$。 

一个干净的建设性技巧是尝试首先放置所有水平进度：我们尝试沿 x 轴移动，直到消耗一半的距离或击中$x$，然后在 y 方向使用余数。 对称的替代方案也有效； 一种有效的构造是：$$c_x = \min(x, d/2), \quad c_y = d/2 - c_x$$这确保了非负性，保留了所需的总和，并自动对齐两个距离，因为每个移动单位都在曼哈顿度量中得到了准确的说明。

 ## 算法演练

 我们独立处理每个测试用例并直接构建中点。 

1. 计算$d = x + y$。 这是从原点到$B$，并且它确定中点在数值上是否可能。 
2.如果$d$为奇数，输出$-1 -1$。 原因是任何中点必须恰好位于该距离的一半处，这在整数中是不可能的$d$很奇怪。 
3.让$half = d / 2$。 
4. 设置$c_x = \min(x, half)$。 这优先考虑保持在可用水平距离内$B$，确保我们不会超出路径的轴对齐结构。 
5. 设置$c_y = half - c_x$。 这迫使剩余的所需距离垂直分配。 
6. 输出$(c_x, c_y)$。 

不明显的部分是为什么这种贪婪分配是有效的。 曼哈顿度量允许沿轴独立移动，因此将总距离分解为水平和垂直分量都对应于有效路径。 该结构确保总距离的两半是平衡的。 

### 为什么它有效

 关键的不变量是，在每一步我们都构建一个点，其到原点的 L1 距离恰好是$x + y$，同时确保剩余距离$B$匹配相同的值。 由于曼哈顿距离是跨轴相加的，因此分配$c_x$水平移动单位和$c_y$垂直运动的单位完全决定了两个距离，无需交互项。 基于最小值的分割在不违反非负性或超出坐标的情况下保证了可行性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x, y = map(int, input().split())
        d = x + y

        if d % 2:
            print(-1, -1)
            continue

        half = d // 2
        cx = min(x, half)
        cy = half - cx

        print(cx, cy)

if __name__ == "__main__":
    solve()
```该解决方案是围绕完全避免任何搜索而构建的。 奇偶校验是唯一可以使存在无效的条件。 一旦通过，分割使用`min(x, half)`确保我们永远不会分配负坐标并且永远不会超过所需的总距离。 

一个微妙的实现细节是计算`cy`因为其余部分保证了一致性。 如果`cx`已经消耗掉了所有的`half`， 然后`cy`变为零； 否则它恰好填补了空白。 这避免了条件分支并保持结构稳定。

 ## 边缘情况

 当$x + y = 0$，算法立即返回$(0, 0)$，因为两个距离都为零并且中点条件正确退化。 该构造不会尝试奇偶校验之外的任何除法，因此不需要特殊处理。 

例如，当一个坐标为零时$(42, 0)$，算法集$half = 21$，然后赋值$cx = 21$,$cy = 0$，准确地保留两个距离约束。 这避免了尝试独立分割坐标而不考虑所有距离必须来自单个轴的常见错误。 

什么时候$x + y$是奇数，比如$(13, 37)$，该函数立即拒绝。 任何构建中点的尝试都需要分数曼哈顿距离，这在整数网格中是不可能的，因此输出$-1 -1$是被迫的。 

该构造始终能够处理这些情况，因为它从不假设欧几里得对称性，而仅假设曼哈顿距离的加法分解。
