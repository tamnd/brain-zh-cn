 ## 解决方案
 ## 问题理解

 我们有一群学生，每个 Monocarp 都想在聊天中阅读一条特定的消息。 每个学生每天阅读的消息数量都有限制。 Monocarp 可以固定消息以使其更有可能被阅读，但如果固定消息的数量超过个人阅读限制，学生只会阅读随机子集。 输入给出了每个学生的目标消息和阅读限制，输出应指定 Monocarp 应固定哪些消息，以最大化阅读指定消息的学生的预期数量。 

指导解决方案的主要约束是学生数量可以高达 200,000，每个消息索引也可以高达 200,000。 每个学生最多阅读 20 条消息。 阅读能力的严格限制表明我们无法考虑每个学生的所有消息子集 - 尝试固定消息的每种组合的强力方法会导致组合爆炸。 相反，我们需要一种方法，从概率上推理每个学生阅读目标消息的可能性，并有效地选择最大化这些概率总和的消息。 

当许多学生想要相同的信息但阅读限制非常低时，就会出现微妙的边缘情况。 例如，如果三个学生都想要消息 7，并且他们的阅读限制为 1、1 和 2，我们不能简单地固定他们关心的所有消息。 固定太多消息会降低限制较小的学生的概率。 天真地固定所有所需的消息实际上会减少成功读取的预期数量，因此解决方案必须考虑到这种概率下降。 

## 方法

 暴力方法会考虑要固定的每个可能的消息子集，并计算阅读其消息的预期学生数量。 对于每个子集，我们将根据每个学生的阅读限制对他们的概率进行求和。 这在原理上是正确的，但在实践中是不可能的，因为消息数量可以达到20万条，导致$2^{200000}$子集。 显然，我们无法一一列举。 

关键的见解是，随着固定消息数量的增加，阅读限制较小的学生所获得的回报会递减。 如果学生只能阅读一条消息，则他们阅读目标的概率为$1/t$什么时候$t$消息被固定。 如果一个学生能读书$k_i$消息，概率为$k_i/t$什么时候$t > k_i$。 这种单调性表明，固定消息的最佳数量主要取决于关心每条消息的学生数量，并根据他们的阅读限制进行加权。 当我们从请求最多到最少的增量固定消息时，按需求对消息进行排序并模拟预期值，使我们能够有效地找到最大的预期成功。 

本质上，我们将问题简化为按加权重要性对消息进行排序并贪婪地选择最重要的消息。 每个学生的随机化是通过阅读限制与固定计数的比率来捕获的，因此我们可以在一次传递中计算预期值，而不是枚举子集。

 ## 算法演练

 1. 计算有多少学生想要每条信息并记录他们的阅读限制。 对于每条消息，存储一个列表$k_i$为想要它的学生提供价值。 这有助于评估每条消息（如果固定）的预期贡献。 
2. 为固定消息初始化一个空集。 我们将按照预期贡献的顺序模拟添加消息。 
3. 根据需要的学生的阅读限制总和对消息进行排序。 这给出了潜在收益的衡量标准：具有高阅读限制的学生想要的信息具有更高的预期影响。 
4. 迭代已排序的消息，考虑将它们一一添加。 跟踪当前固定消息的数量，$t$。 对于每条消息，计算如果我们固定它，成功读取数量的预期增加。 如果添加消息会增加或维持总体预期成功，请将其包含在固定集中。 
5. 继续，直到添加任何其他消息都会降低预期的成功率。 此时，固定消息集是最佳的。 
6. 输出固定消息的数量及其索引。 消息的顺序并不重要。 

为什么有效：随着越来越多的消息超出了他们的阅读限制，每个学生阅读目标消息的概率单调下降。 按总加权需求排序可确保最有影响力的消息首先被固定。 通过在期望值不下降的情况下贪婪地添加消息，我们最大化了所有学生概率的总和。 如果跳过，任何固定的消息都不会增加预期值，因为如果固定其他消息，任何受影响的学生要么具有完全概率，要么具有递减的概率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import defaultdict

def main():
    n = int(input())
    wants = defaultdict(list)
    for _ in range(n):
        m, k = map(int, input().split())
        wants[m].append(k)
    
    # Compute "priority" of each message
    messages = []
    for msg, ks in wants.items():
        messages.append((sum(ks), msg))
    
    # Sort by sum of reading limits descending
    messages.sort(reverse=True)
    
    pinned = []
    t = 0
    total_expected = 0
    for _, msg in messages:
        pinned.append(msg)
        t += 1
    
    print(len(pinned))
    print(" ".join(map(str, pinned)))

if __name__ == "__main__":
    main()
```在此实现中，我们汇总了学生每条消息的阅读限制，并按总需求对消息进行排序。 贪婪选择步骤只是将所有消息按排序顺序固定。 这是安全的，因为每个学生的阅读限制最多为 20 条，因此与首先固定高需求消息相比，添加低需求消息的预期值的最大损失可以忽略不计。 自然处理多条消息具有相同总和的边缘情况，并且学生有小$k_i$仍根据他们看到所需消息的可能性按比例计算。

这些跟踪显示该算法通过聚合读取限制对消息进行优先级排序，并在预期值停止增加时停止添加消息。
