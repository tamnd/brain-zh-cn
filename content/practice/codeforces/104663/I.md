 ## 解决方案
 ## 问题理解

 给定一棵无向树，我们必须为每个节点分配一个小写字母。 标记后，树中的每个简单路径都对应于通过读取沿该路径的节点标签形成的字符串。 

两个全局约束必须同时成立。 首先，如果我们采用任何端点都是叶子的路径，则结果字符串必须是回文。 其次，如果我们采用任何端点为叶节点和非叶节点的路径，则该字符串绝不能是回文。 

因此，树标记不是关于单个路径，而是关于在所有叶到叶路径上强制执行回文结构，同时明确地破坏每个叶到内部路径上的回文结构。 

输入大小高达二十万个节点，因此任何解决方案在顶点数量上都必须是线性的或接近线性的。 任何试图单独推理所有节点对或所有路径的方法都是不可行的，因为树具有二次方的多条路径。 

一个微妙的点是，约束谈论_所有叶子对_，而不仅仅是选定的一对。 这迫使树上有一个全局结构，而不是局部分配技巧。 

当树枝出现时，往往会打破天真的推理的边缘情况就会出现。 

如果我们尝试一颗有中心和许多叶子的星，任何两个叶子都会形成长度为三的路径。 该字符串必须是回文，这迫使两个叶子具有相同的字符。 将其扩展到所有叶对上很快就会迫使许多相等性，然后叶到非叶约束变得不可能满足。 

例如，考虑一颗四号星：```
    2
    |
3 - 1 - 4
```所有叶对都是 (2,3)、(2,4)、(3,4)。 使所有这些路径成为回文会强制实现强对称性，但如果标签统一，则 2 到 1 或 3 到 1 等路径也将成为回文，这违反了第二个条件。 

这种冲突表明分支结构是危险的，只有非常受限的树才能发挥作用。 

## 方法

 一种暴力的想法是任意分配字母，并通过枚举所有叶到叶和叶到非叶路径来验证这两个条件。 即使使用固定标签，检查所有路径的成本也很高，因为树中有 θ(n²) 条路径。 每次路径检查都会花费路径长度的线性时间，因此在最坏的情况下会爆炸到 θ(n3)，这远远超出了限制。 

关键的结构观察是条件迫使树本身表现得像一条单链。 

如果存在任何度数至少为三的节点，则它连接多个子树，每个子树都包含叶子。 从不同的树枝上采摘叶子会创建多个经过分支点的不同的叶到叶路径。 这些路径需要不兼容的对称约束，因为每个分支都需要通过分支中心同时镜像所有其他分支。 如果不折叠成恒定的标签，固定的小字母表就无法满足这一点，从而违反了叶到非叶的限制。 

此限制将树折叠成单个简单路径。 一旦树成为路径，问题就变成一维的：我们只需要沿着一条线分配字母，这样两个端点之间的每个子路径都是回文，而从端点到内部节点的任何前缀都不是回文。 

在一条路径上，恰好有两个叶子，即端点。 唯一的叶到叶路径是完整路径。 该字符串必须是回文，因此标签必须沿路径对称。 

同时，考虑叶到非叶路径：从端点开始并在路径内的某个位置停止。 如果这个前缀是回文，它会在中点周围镜像自身，这会强制出现与全路径对称性冲突的强烈重复，除非我们在端点之后立即引入至少一个字符更改。 

最简单的构造是使用两个字符。 在两个端点放置一个字符，并在所有内部节点放置不同的字符。 这使完整路径保持回文，同时确保从端点开始的任何前缀立即破坏回文性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 所有路径上的暴力验证 | O(n3) | O(n) | 太慢了|
 | 度数检查+线性构造| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取树并计算每个节点的度。 如果树有两个以上度数为 1 的节点，或者任何度数大于 2 的节点，则拒绝它。 这强制树必须是简单路径。 
2. 对n=1的情况单独处理。 单个节点通常满足这两个条件，因为不存在叶到非叶路径。 给它分配任何字符，按字典顺序最小的选择是`'a'`。 
3. 对于有效路径，将其两个端点标识为度数为 1 的节点。 
4. 从一个端点开始遍历路径，以产生沿链的节点排序。 这可以通过使用邻接性的简单步行来完成，并避免重新访问前一个节点。 
5. 分配字符：give`'a'`到两个端点，并分配`'b'`到每个内部节点。 
6. 按照原始节点索引顺序输出结果字符串。 

### 为什么它有效

 唯一的叶到叶路径是整个链。 它的标签是`'a' + many 'b' + 'a'`，这是一个回文。 从端点到内部节点的任何路径都以`'a'`紧随其后的是`'b'`，这已经打破了回文对称性，因为第一个和最后一个字符不同。 因此这样的前缀不能是回文。 路径结构确保不存在其他叶对，因此不会引入额外的约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
adj = [[] for _ in range(n)]

for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

if n == 1:
    print("a")
    sys.exit()

deg = [len(adj[i]) for i in range(n)]

# Tree must be a path
bad = False
leaves = 0
for i in range(n):
    if deg[i] > 2:
        bad = True
    if deg[i] == 1:
        leaves += 1

if bad or leaves != 2:
    print(-1)
    sys.exit()

# find one endpoint
start = 0
for i in range(n):
    if deg[i] == 1:
        start = i
        break

order = []
prev = -1
cur = start

while cur != -1:
    order.append(cur)
    nxt = -1
    for nei in adj[cur]:
        if nei != prev:
            nxt = nei
            break
    prev, cur = cur, nxt

res = [''] * n
for i, node in enumerate(order):
    if i == 0 or i == n - 1:
        res[node] = 'a'
    else:
        res[node] = 'b'

print("".join(res))
```该代码首先通过检查度数来验证树结构是否为单链。 这是唯一能够满足全局回文约束的结构情况。 

验证后，它通过使用前一个指针技术从一个叶子走到另一个叶子来重建路径，这避免了需要完整的 DFS。 

分配步骤有意最小化：只有端点与内部节点不同。 这已经足够了，因为约束仅区分端点和内部节点，而不区分路径内部超出对称性要求的位置。

 ## 边缘情况

 具有高度节点的树会立即触发拒绝，因为它违反了所需的路径结构。 例如，连接到三个叶子的节点强制多个独立的叶子到叶子约束，这些约束不能一致满足，并且算法通过度检查正确地检测到这一点。 

单节点树绕过所有结构推理并直接处理，因为不存在矛盾的路径约束。 

双节点树是最简单的有效路径，并且构造为两个端点分配相同的字符，产生有效的回文，同时完全避免任何内部节点约束。 

在所有情况下，该算法都会将问题简化为经过验证的路径或立即不可能的问题，从而防止任何模糊的部分配置。
