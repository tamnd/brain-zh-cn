 ## 解决方案
 ## 问题理解

 我们正在处理一个长度的数组$N$，但数组值本身是不相关的。 重要的只是从 1 到$N$。 在这条线上，我们给出$M$特殊细分市场$[l_i, r_i]$。 这些段代表了对子数组“坏”的限制。 

一个子数组$[a, b]$如果它完全包含至少一个给定的段，则被认为是坏的，这意味着存在一定的间隔$[l_i, r_i]$这样$a \le l_i$和$r_i \le b$。 一个好的子数组就是能够避免所有给定段出现这种情况的子数组。 

所以任务是数出有多少对$(a, b)$和$1 \le a \le b \le N$不要完全覆盖任何禁止的部分。 

约束条件$N \le 10^9$立即排除任何直接迭代所有子数组甚至所有端点的方法。 子数组的数量为$\Theta(N^2)$，这是一个天文数字，所以我们必须完全依赖于结构$M$间隔。 关键的观察是复杂性必须取决于$M$，不在$N$，除了哪里$N$出现在最终的算术公式中。 

一种简单的方法是检查每个子数组并测试它是否包含禁止的段。 即使检查单个子数组是$O(M)$，总计为$O(N^2 M)$，这是完全不可行的。 

一个稍微聪明一点的方法是修复子数组$[a, b]$并维护一个数据结构来测试内部是否有任何区间。 这仍然需要迭代所有$\Theta(N^2)$对，所以它也会立即失败。 

如果我们尝试仅检查端点，则会出现更微妙的故障模式$l_i, r_i$并在当地进行推理。 例如，人们可能会错误地假设只有边界与某些值匹配的子数组$l_i$或者$r_i$很重要，但这忽略了子数组可以在任何地方开始和结束，并且仍然完全覆盖一个段。 

一个具体的陷阱：如果$N = 6$我们有一个片段$[2, 3]$，子数组$[1, 4]$即使两个端点都不完全匹配 2 或 3，它已经很糟糕了。 任何只直接跟踪端点而不考虑覆盖结构的方法都会错过这种情况。 

问题本质上是关于对数的计数$(a, b)$完全避免包含任何禁止区间，这是二维的几何条件。 

## 方法

 一个有用的重新表述来自于翻转条件。 一个子数组$[a, b]$如果它至少包含一个区间则不好$[l_i, r_i]$，这相当于$a \le l_i$和$b \ge r_i$。 因此每个间隔都会生成一组坏对$(a, b)$平面：矩形内的所有点$[1, l_i] \times [r_i, N]$，仅限于$a \le b$。 

所以问题就变成了计算三角形网格中这些矩形的并集。 这个并集的补集给出了答案。 

蛮力方法将显式枚举所有对$(a, b)$并测试它们是否位于任意矩形内。 那是$O(N^2 M)$，这是不可能的。 

关键的结构观察是我们可以扫过左端点$a$。 对于固定的$a$，我们想知道有多少个正确的端点$b$被至少一个矩形覆盖。 每个区间$[l_i, r_i]$贡献报道$b \ge r_i$每当$a \le l_i$。 这意味着作为$a$减少，更多间隔变得活跃，并且每个间隔都贡献一个范围$b$-轴。 

这样我们就可以处理$a$按降序排列，维持间隔的动态联合$b$-轴。 对于每个固定段$a$- 活动集不改变的值，贡献只是宽度$a$次覆盖长度$b$。 这减少了在插入时维护间隔并集的问题，这可以通过压缩坐标上的线段树来处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(N^2 M)$|$O(1)$| 太慢了|
 | 扫描+线段树 |$O(M \log M)$|$O(M)$| 已接受 |

 ## 算法演练

 我们现在逐步构建解决方案，重点关注活动区间的几何形状。 

### 1. 将每个禁止段平移为一个矩形

 每个区间$[l, r]$代表所有坏子数组$[a, b]$这样$a \le l$和$b \ge r$。 我们将其解释为一个矩形$(a, b)$空间。 

这种转换至关重要，因为它将组合条件转化为几何并集问题。 

### 2. 压缩正确的端点

 我们只需要跟踪显示为某些值的值$r_i$加上边界$N$。 我们压缩这些值，以便可以将它们维护在线段树中。 

此步骤是必要的，因为正确的端点维度是我们聚合的对象。 

### 3. 按左端点对区间进行排序

 我们按降序处理间隔$l_i$。 这与当我们向左移动时的想法是一致的$a$，更多间隔变得活跃。 

### 4. 扫过左端点$N$降至 1

 我们维护一个指针$a$。 在每个不同的$l_i$，我们用该左端点激活所有间隔。 

两个连续激活点之间$L_{k}$和$L_{k+1}$，活动集不会改变，所以覆盖范围$b$是恒定的。 

### 5. 保持右轴覆盖

 我们维护一个经过压缩的线段树$b$-价值观。 每个间隔都会贡献一个范围更新$[r_i, N]$。 线段树存储总覆盖长度。 

添加间隔后，我们会增加其范围内的覆盖计数。 当覆盖计数为正时，该段会影响联合长度。 

### 6. 累积各部分的贡献$a$对于每个段$a$- 宽度值$w$，我们添加：$$w \times (\text{covered length on } b)$$这给出了所有矩形贡献的坏子数组的总数。 

### 7. 从总子数组中减去

 总子数组是$N(N+1)/2$。 减去计算出的错误计数以获得良好的子数组。 

### 为什么它有效

 在任意固定的$a$，活动间隔正是那些$l_i \ge a$。 每个这样的间隔都会贡献一个连续的无效范围$b$-价值观。 线段树准确地维护了这些范围的并集。 因为活动集仅在值为$l_i$，在这些点处分割扫描可确保正确性，而不会丢失中间状态。 每对坏人$(a, b)$作为一个扫描段的一部分仅被计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, vals):
        self.n = len(vals) - 1
        self.coords = vals
        self.tree = [0] * (4 * self.n)
        self.cnt = [0] * (4 * self.n)

    def _push_up(self, idx, l, r):
        if self.cnt[idx] > 0:
            self.tree[idx] = self.coords[r + 1] - self.coords[l]
        else:
            if l == r:
                self.tree[idx] = 0
            else:
                self.tree[idx] = self.tree[idx * 2] + self.tree[idx * 2 + 1]

    def update(self, idx, l, r, ql, qr, val):
        if ql <= l and r <= qr:
            self.cnt[idx] += val
            self._push_up(idx, l, r)
            return
        mid = (l + r) // 2
        if ql <= mid:
            self.update(idx * 2, l, mid, ql, qr, val)
        if qr > mid:
            self.update(idx * 2 + 1, mid + 1, r, ql, qr, val)
        self._push_up(idx, l, r)

def solve():
    N, M = map(int, input().split())
    segs = []
    ys = {1, N + 1}

    for _ in range(M):
        l, r = map(int, input().split())
        segs.append((l, r))
        ys.add(r)

    ys = sorted(ys)
    idx = {v: i for i, v in enumerate(ys)}

    segs.sort(reverse=True)
    st = SegTree(ys)

    active = 0
    ans_bad = 0
    i = 0

    while i < M:
        cur_l = segs[i][0]
        j = i
        while j < M and segs[j][0] == cur_l:
            l, r = segs[j]
            st.update(1, 0, len(ys) - 2, idx[r], len(ys) - 2, 1)
            j += 1

        next_l = segs[j][0] if j < M else 0
        width = cur_l - next_l
        ans_bad += width * st.tree[1]

        i = j

    total = N * (N + 1) // 2
    print(total - ans_bad)

if __name__ == "__main__":
    solve()
```该实现将扫描分开$l$维持覆盖范围的价值$r$-轴。 线段树存储了覆盖的并集长度$b$-值，每次更新对应于激活一个与所有较小值相关的间隔$a$。 

关键的微妙之处在于范围$[r_i, N]$，这需要添加一个哨兵$N+1$在压缩期间，长度计算可以在线段树中干净地进行。

 ## 边缘情况

 一种重要的边缘情况是根本没有间隔。 在这种情况下，算法永远不会激活任何段，扫描贡献零坏子数组，并且最终答案正确地变为$N(N+1)/2$。 

另一种情况是当一个区间覆盖整个数组时，比如$[1, N]$。 这会产生一个覆盖所有可能的矩形$(a, b)$与$a \le b$，所以每个子数组都是坏的。 线段树最终会覆盖整个线段树$b$- 轴，并且扫描累积整个区域，与预期的零良好子阵列匹配。 

一个更微妙的情况是重叠间隔，例如$[1, 3]$和$[2, 3]$。 简单的求和会重复计数，但线段树保持并集覆盖，因此重叠仅贡献一次。 即使在严重重叠的情况下，这也能保持正确性。
