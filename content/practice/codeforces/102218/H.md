 ## 解决方案
 ## 问题理解

 我们有 (n) 个正弦信号。 每个信号都以相同的角频率 (\omega) 振荡，但每个信号都有自己的幅度 (A_i) 和相位 (\phi_i)。 它们的总和保证仍然是具有相同频率的正弦曲线，因此任务是恢复单个等效信号的幅度 (A) 和相位 (\phi)。 

输入包含 (n)、公共频率，然后包含 (n) 对 ((A_i,\phi_i))。 频率本身不需要出现在输出中，因为添加信号后它不会改变。 输出只需要所得波的幅度和相位，相位归一化为区间 ([0,2\pi))。 

关键约束是 (n\le 10^5)。 在 2 秒的限制下，(O(n)) 解决方案是自然的目标。 (O(n^2)) 方法将以最大输入大小执行大约 (5\cdot10^9) 对操作，这远远超出了时间限制。 幅度和相位都是实数，因此需要浮点运算，并且要求的（10^{-6}）容差意味着我们应该避免不必要的不​​稳定计算。 

有几种边缘情况可能会导致粗心的实施失败。 

第一个是相位缠绕。 考虑```
2 1
1 6.2
1 0.1
```这两个相位接近 (2\pi) 和 (0)，因此它们的合成相位接近 (0)，而不接近 (2\pi)。 一个原始的`atan2`结果可能为负，直接打印它违反了所需的相位间隔。 相位必须用模 (2\pi) 进行归一化。 

二是取消。 考虑```
2 1
1 0
1 3.141592653589793
```这两个波完全相反，因此它们的和是零函数。 正确的幅度是 (0)。 相位在数学上是无关的，因为对于每个 (\phi) 都有 (0\sin(x+\phi)=0)。 当计算的幅度为零时，稳健的实现可以返回相位 (0)。 

第三种是仅在一个坐标中取消。 例如，```
2 1
1 0
1 1.5707963267948966
```总和为 (\sin x+\cos x=\sqrt2\sin(x+\pi/4))，因此答案大约为```
1.4142135623730951 0.7853981633974483
```一个公式仅使用`atan(y/x)`可能会丢失象限并产生错误的相位。`atan2`是必需的，因为它确定两个坐标的角度。 

## 方法

 思考这个问题的一个直接方法是一次组合两个波。 假设我们已经知道两个频率相同的波可以用一个等效波来表示。 我们可以将前两个结果结合起来，然后将结果与第三个结果结合起来，然后与第四个结果结合起来，依此类推。 该顺序版本已经是线性的，但字面上的强力实现可能会在选择下一个组合之前重复重新计算所有剩余波对的结果。 这样的过程对每对波执行一对组合，给出

 [
 \frac{n(n-1)}2
 ]

 组合。 对于 (n=10^5)，即 (4,999,950,000) 个组合，因此即使每个单独的组合都是恒定时间，该方法也太慢了。 它的正确性来自加法的结合性，但重复表示相同的部分和会浪费工作量。 

消除这种浪费工作的观察方法是完全停止存储中间幅度和相位。 使用角加恒等式展开一波：

 A_i\sin x\cos\phi_i
 +
 A_i\cos x\sin\phi_i,
 ]

 其中 (x=\omega t)。 

因此，每个波只是相同的两个基函数 (\sin x) 和 (\cos x) 的线性组合。 我们可以独立地添加所有系数：

 [
 S=\sum_i A_i\cos\phi_i,
 \qquad
 C=\sum_i A_i\sin\phi_i。 
]

 完整的总和变为

 [
 f(t)=S\sin(\omega t)+C\cos(\omega t)。 
]

 现在展开所需的单波：

 A\cos\phi\sin x+A\sin\phi\cos x。 
]

 匹配系数给出

 [
 A\cos\phi=S,
 \qquad
 A\sin\phi=C。 
]

 因此，振幅就是矢量 ((S,C)) 的长度：

 [
 A=\sqrt{S^2+C^2}。 
]

 相位是该矢量的方向：

 [
 \phi=\operatorname{atan2}(C,S)。 
]

 这是中心思想。 每个原始波贡献一个二维向量 ((A_i\cos\phi_i,A_i\sin\phi_i))。 添加波与添加这些向量完全相同。 最终的幅度是矢量的长度，最终的相位是其方向。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 重复暴力配对组合 | (O(n^2)) | (O(1)) | (O(1)) | 太慢了 |
 | 系数累积| (O(n)) | (O(n)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 读取 (n) 和共同频率 (Ω)。 之后不需要 (Ω) 的值，因为每个波具有完全相同的频率，因此它在最终信号中保持不变。 
2. 初始化两个累加器（S=0）和（C=0）。 对于每个波，将 (A_i\cos\phi_i) 添加到 (S)，将 (A_i\sin\phi_i) 添加到 (C)。 

这两个值正是 (\sin(\omega t)) 和 (\cos(\omega t)) 的完整总和系数，因此不需要存储单个波。 
3. 将最终振幅计算为

 [
 A=\sqrt{S^2+C^2}。 
]

 这是从方程 (S=A\cos\phi) 和 (C=A\sin\phi) 得出的，因为对它们进行平方和相加得到 (S^2+C^2=A^2)。 
4. 计算相位

 [
 \phi=\operatorname{atan2}(C,S)。 
]

 这些论点是故意按这个顺序排列的。`atan2(y, x)`返回向量 ((x,y)) 的方向，我们的向量是 ((S,C))。 
5. 如果相位返回`atan2`为负数，加(2\pi)。 这会将角度转换为所需的间隔 ([0,2\pi))。 
6. 以足够的精度打印幅度和归一化相位。 Python 的双精度浮点运算足以满足所需的 (10^{-6}) 误差。 

### 为什么它有效

 处理每个输入波后，累加器满足

 [
 S=\sum_i A_i\cos\phi_i
 ]

 和

 [
 C=\sum_i A_i\sin\phi_i。 
]

 使用角度加法恒等式，原始和正好是

 [
 S\sin(\omega t)+C\cos(\omega t)。 
]

 该算法选择 (A=\sqrt{S^2+C^2}) 和 (\phi=\operatorname{atan2}(C,S))，满足 (A\cos\phi=S) 和 (A\sin\phi=C)。 将这两个等式代入 (A\sin(\omega t+\phi)) 会产生与所有输入波之和完全相同的表达式。 因此，返回的幅度和相位描述了所需的等效信号。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n, omega = input().split()
    n = int(n)
    omega = float(omega)

    s = 0.0
    c = 0.0

    for _ in range(n):
        a, phi = map(float, input().split())
        s += a * math.cos(phi)
        c += a * math.sin(phi)

    amplitude = math.hypot(s, c)
    phase = math.atan2(c, s)

    if phase < 0.0:
        phase += 2.0 * math.pi

    print(f"{amplitude:.12f} {phase:.12f}")

if __name__ == "__main__":
    solve()
```第一行读取波数和公共频率。 虽然`omega`被解析是因为它属于输入格式，所以永远不会进入计算。 这是所有波共享相同频率的直接结果。 

该循环实现算法的系数累加。`math.cos(phi)`贡献于 (\sin(\omega t)) 的系数，而`math.sin(phi)`贡献于 (\cos(\omega t)) 的系数。 变量被命名为`s`和`c`根据这些累积的系数。`math.hypot(s, c)`以数值稳健的方式计算 (\sqrt{s^2+c^2})。 它还避免了手动编写平方根表达式，并且在处理浮点大小时更可取。 

相位计算使用`atan2(c, s)`而不是`atan(c / s)`。 每当后者失去象限`s`是负数并且也有被零除的问题`s`为零。`atan2`直接处理这两种情况。 

标准化仅检查结果是否为负。`atan2`返回 ([-\pi,\pi]) 中的角度，因此添加 (2\pi) 一次就足以将其放入 ([0,2\pi)) 中。 浮点舍入可能会使理论上的零幅度变得非常小，但这不会产生正确性问题，因为零幅度波的相位是任意的。 

不涉及整数乘法或大整数数组，因此整数溢出无关紧要。 最大的和约为 (10^7)，可以用 Python 的双精度浮点类型轻松表示。

 下面的测试工具将浮点结果与容差进行比较，而不是精确比较十进制字符串。 这是测试此问题的适当方法，因为多个数值等效答案的最终打印数字可能有所不同，但仍满足所需的误差范围。```python

import io
import math

def solve():
    input = sys.stdin.readline

    n, omega = input().split()
    n = int(n)
    omega = float(omega)

    s = 0.0
    c = 0.0

    for _ in range(n):
        a, phi = map(float, input().split())
        s += a * math.cos(phi)
        c += a * math.sin(phi)

    amplitude = math.hypot(s, c)
    phase = math.atan2(c, s)

    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    try:
        old_stdout = sys.stdout
        sys.stdout = io.StringIO()
        solve()
        return sys.stdout.getvalue().strip()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

    a, p = map(float, out.split())
    return a, p

def assert_close(actual: str, expected_a: float, expected_p: float,
                 message: str):
    a, p = parse_output(actual)

    assert math.isclose(a, expected_a, rel_tol=1e-9, abs_tol=1e-9), message
    assert math.isclose(p, expected_p, rel_tol=1e-9, abs_tol=1e-9), message

 ## 边缘情况

 对于相位缠绕，请使用```
2 1
1 6.283185307079586
1 0.0000000001
```第一阶段是 (2\pi-10^{-10})，第二阶段是 (10^{-10})。 它们的矢量几乎指向相同的方向，因此它们的和的幅度非常接近 (2)，相位非常接近 (0)。 累积的正弦分量近似为零，余弦分量近似为(2)。`atan2`由于浮点舍入，可能会产生微小的正值或负值。 如果为负，算法会添加 (2\pi)，从而在所需范围内产生等效相位。 

要准确取消，请使用```
2 1
1 0
1 3.141592653589793
```第一个波贡献 ((1,0))，第二个波贡献 ((-1,0))。 累加向量为 ((0,0))，因此`math.hypot`返回零。`atan2(0,0)`在 Python 中返回零，给出有效的输出```
0.000000000000 0.000000000000
```当幅度为零时，相位没有物理意义，因此允许间隔内的任何相位都将代表相同的波。 返回零是一个方便的规范选择。 

对于象限问题，使用```
2 1
1 0
1 1.5707963267948966
```累加向量为((1,1))，因此相位为(\pi/4)。 一个公式基于`atan(C/S)`碰巧在这里工作，但请考虑一下```
2 1
1 3.141592653589793
1 1.5707963267948966
```累积向量约为((-1,1))。 正确的相位是(3\pi/4)。 一个天真的`atan(C/S)`计算看到的比率约为 (-1)，并返回约为 (-\pi/4)，这是错误的方向。`atan2(C,S)`看到两个符号并正确返回 (3\pi/4)。 

最后，最大尺寸的情况可以变得特别简单：```
100000 50
1 0
1 0
...
1 0
```有（100000）个相同的波。 每个贡献都是 ((1,0))，因此最终向量是 ((100000,0))。 结果是幅度 (100000) 和相位 (0)。 该算法对每个输入只处理一次，这证明了为什么 (O(n)) 界限在允许的最大输入大小下仍然实用。
