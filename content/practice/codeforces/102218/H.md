 ## 解决方案
 ## 问题理解

 我们有 (n) 个正弦波。 每个波都以相同的角频率 (\omega) 振荡，但每个波都有自己的振幅 (A_i) 和相位 (\phi_i)。 它们的总和保证可以表示为另一个具有相同频率的正弦曲线，并且我们需要恢复其幅度 (A) 和相位 (\phi)。 

输入给出 (n)，公共频率，然后给出 (n) 对 ((A_i,\phi_i))。 输出是一对 ((A,\phi)) 使得

 A\sin(\omega t+\phi)
 ]

 对于每个 (t)，其中 (A\ge 0) 和 (0\le\phi<2\pi)。 

频率本身不影响计算。 由于每项都具有完全相同的 (Ω)，因此我们只需组合它们的幅度和相位即可。 

(n)的值可以达到(10^5)。 将每个波与其他每个波进行比较的解决方案在最坏的情况下将执行大约 (10^{10}) 成对操作，这远远超出了两秒的时间限制。 我们需要一个线性或近线性算法。 幅度最多为 (100)，因此累积系数最多约为 (10^7)，完全在普通浮点范围内。 相位值已经以弧度给出，并且位于一整圈内。 

有几种数值边缘情况可能会使看似合理的实现变得错误。 考虑单个波：```
1 1
5 0
```结果正好是 (5)，相位 (0)。 当该分量为零时，不必要地修改相位或使用涉及除以一个三角分量的公式的解决方案可能会失败。 

第二种情况是波指向相反方向：```
1 1
5 3.141592653589793
```结果具有幅度 (5) 和相位 (\pi)。 计算相位`atan(y / x)`是不安全的，因为 (x) 可能为零，更重要的是，(x) 和 (y) 的符号决定了象限。`atan2`正是针对这种情况而设计的。 

最后，完全取消是可能的：```
2 1
1 0
1 3.141592653589793
```两个波互为负数，因此结果是零函数。 它的幅度是 (0)，并且它的相位在数学上是无关的，因为对于每个 (\phi) 都有 (0\sin(\omega t+\phi)=0)。 浮点实现可能会留下微小的残差而不是精确的零，这在所需的容错范围内是无害的。 

(2\pi) 周围还有一个边界情况。 例如，```
2 1
1 0
1 6.283185307079586
```所得相位非常接近 (2\pi)，而不是负角。 自从`atan2`返回 ([-\pi,\pi]) 中的角度，负结果必须平移 (2\pi)。 

## 方法

 直接方法会尝试将总和评估为 (t) 的函数（可能在几个点上），然后从这些值中恢复幅度和相位。 这是不必要的，并且为每一波评估许多点只会增加工作量。 更代数的强力方法可以使用三角恒等式重复组合两个正弦曲线。 尽管每个单独的组合都是正确的，但重复操作表达式仍然会带来不必要的工作和数字复杂性。 如果考虑每对波，最坏的情况约为 (n^2=10^{10}) 次操作。 

有用的观察是，在进行任何求和之前可以扩展相移。 对于一波，

 A_i\sin(\omega t)\cos\phi_i
 +
 A_i\cos(\omega t)\sin\phi_i。 
]

 因此，每个波只是相同两个函数 (\sin(\omega t)) 和 (\cos(\omega t)) 的线性组合。 我们可以独立地添加它们的系数。 

定义

 [
 X=\sum_{i=1}^{n} A_i\cos\phi_i
 ]

 和

 [
 Y=\sum_{i=1}^{n} A_i\sin\phi_i。 
]

 那么完整的总和就变成了

 [
 f(t)=X\sin(\omega t)+Y\cos(\omega t)。 
]

 现在展开所需的单波：

 A\cos\phi\sin(\omega t)
 +
 A\sin\phi\cos(\omega t)。 
]

 匹配系数给出

 [
 A\cos\phi=X,
 \qquad
 A\sin\phi=Y。 
]

 ((X,Y)) 对可以视为二维向量。 它的长度是所得的振幅，

 [
 A=\sqrt{X^2+Y^2},
 ]

 它的方向是结果相，

 [
 \phi=\operatorname{atan2}(Y,X)。 
]

 这将整个问题简化为一次通过输入。 蛮力之所以有效，是因为正弦波可以通过代数方式组合，但它无法利用每个波都使用相同的两个基函数这一事实。 所有项都减少为 (\sin(\omega t)) 和 (\cos(\omega t)) 的系数这一观察结果让我们可以用一个累积的二维向量替换整个波集合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(n^2)) | (O(1)) | (O(1)) | 太慢了 |
 | 最佳| (O(n)) | (O(n)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 读取 (n) 和 (\omega)。 之后不需要 (Ω) 的值，因为它对于每个波都是相同的，因此所有工作都可以使用幅度和相位来完成。 
2. 初始化两个累加器，(X=0) 和(Y=0)。 他们将 (\sin(\omega t)) 和 (\cos(\omega t)) 的系数存储在完整的和中。 
3. 对于每个波 ((A_i,\phi_i))，将 (A_i\cos\phi_i) 添加到 (X)，并将 (A_i\sin\phi_i) 添加到 (Y)。 这直接由展开 (\sin(\omega t+\phi_i)) 得出。 
4. 计算所得振幅

 [
 A=\operatorname{hypot}(X,Y)。 
]

 这是系数向量的欧几里德长度，在数值上优于手动写入 (\sqrt{X^2+Y^2})。 
5. 计算相位

 [
 \phi=\operatorname{atan2}(Y,X)。 
]`atan2`使用两个坐标，因此它选择正确的象限。 蟒蛇的`math.atan2`返回 (-\pi) 到 (\pi) 范围内的角度。 
6. 如果相位为负，则添加 (2\pi)。 所需的输出间隔为 ([0,2\pi))，因此这将转换为`atan2`约定到问题所需的约定。 
7. 打印 (A) 和 (\phi)，并包含足够的小数位。 在小数点后打印十二位数字比所需的精度 (10^{-6}) 高得多。 

### 为什么它有效

 处理任意波前缀后，(X) 正是该前缀对 (\sin(\omega t)) 贡献的系数，而 (Y) 正是其对 (\cos(\omega t)) 的系数。 添加另一个波将精确地更新这些系数 (A_i\cos\phi_i) 和 (A_i\sin\phi_i)，因此对于每个输入线，不变式仍然成立。 

当所有的波都处理完之后，完整的函数是

 [
 X\sin(\omega t)+Y\cos(\omega t)。 
]

 选择 (A=\sqrt{X^2+Y^2}) 和 (\phi=\operatorname{atan2}(Y,X)) 给出 (A\cos\phi=X) 和 (A\sin\phi=Y)。 将这些恒等式代入 (A\sin(\omega t+\phi)) 可以精确地再现累积函数，除了浮点舍入之外。 相位归一化仅增加一整圈，不会改变正弦曲线。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n, omega = input().split()
    n = int(n)

    x = 0.0
    y = 0.0

    for _ in range(n):
        a, phi = map(float, input().split())
        x += a * math.cos(phi)
        y += a * math.sin(phi)

    amplitude = math.hypot(x, y)
    phase = math.atan2(y, x)

    if phase < 0.0:
        phase += 2.0 * math.pi

    print(f"{amplitude:.12f} {phase:.12f}")

if __name__ == "__main__":
    solve()
```第一行写着`omega`，但实现故意不使用它。 公共频率已经存在于每一项中，并且在系数匹配期间永远不会改变。 

变量`x`和`y`直接对应于算法中导出的两个系数。 每个输入波在角度 (\phi_i) 处贡献一个长度 (A_i) 的向量，因此累加这两个分量相当于向量加法。`math.hypot(x, y)`计算该累积向量的长度。 Python文档`hypot`作为其参数的欧几里得范数，这正是这里所需的幅度计算。`math.atan2(y, x)`被用来代替`math.atan(y / x)`。 除了避免被零除之外，它还保留两个坐标的符号，从而选择正确的象限。 

负相位调整是在`atan2`。 仅当结果为负时添加 (2\pi) 将返回的角度映射到所需的区间，而不改变其正弦或余弦。 

三角计算不涉及整数运算，因此不存在整数溢出问题。 最大可能的累积坐标约为 (10^7)，这很容易用双精度浮点数表示。

 ## 边缘情况

 相位为零的单波，```
1 0.1
5 0
```产生 (X=5) 和 (Y=0)。 振幅为 (5)，并且`atan2(0,5)`给出零相。 没有除以 (X) 或 (Y)，因此可以自然地处理轴情况。 

(\pi) 的一个阶段，```
1 1
5 3.141592653589793
```产生 (X=-5) 和 (Y) 非常接近于零。`atan2`看到负 (X) 坐标并返回 (\pi) 附近的角度，而普通`atan(Y/X)`方法可能会丢失象限信息。 

如需完全取消，```
2 1
1 0
1 3.141592653589793
```数学向量和为 ((0,0))。 Python 对 (\sin(\pi)) 的浮点计算可能会留下一个很小的值而不是精确的零，但是`hypot`仍然产生机器精度数量级的幅度。 这远远低于所需的 (10^{-6}) 绝对误差，因此计算结果正确地表示了零函数。 

对于接近 (2\pi) 的相位，```
2 1
1 0
1 6.283185207179586
```第二个向量几乎与第一个向量相同，但无限小地指向正 (X) 轴下方。`atan2`因此返回一个微小的负相位。 (2\pi) 的显式加法会将其转换为略低于 (2\pi) 的值，从而满足所需的输出范围。 

最大尺寸的情况由 (100000) 个相同的波组成，振幅为 (100)，相位为零。 每个向量贡献 ((100,0))，因此最终向量是 ((10^7,0))，给出幅度 (10^7) 和相位零。 该算法仍然为每个波执行一个恒定的工作量，因此输入大小线性地而不是二次地改变运行时间。
