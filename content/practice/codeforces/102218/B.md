 ## 解决方案
 ## 问题理解

 Alice 购买 (M) 堆。 每堆独立地接收 (K) 个允许的正大小之一，每个大小的概率为 (1/K)。 一旦尺寸已知，游戏就是普通的 Nim 位置。 

对于 Nim 来说，当所有堆大小的按位异或非零时，第一个玩家获胜。 因此，该问题相当于求 (M) 的 XOR 从集合中独立选择值的概率

 [
 C={c_1,c_2,\ldots,c_K}
 ]

 不为零。 所需的答案是该概率模 (998244353)，因此除法是通过模逆进行的。 

困难的部分是（M）的大小。 它可以大到(10^9)，所以我们无法将这些堆一一处理。 可能值的数量受 (2^{17}) 限制，这是关键的结构约束。 这意味着整个问题存在于仅包含 (131072) 个元素的有限 XOR 组中。 该大小对于 (O(2^{17}\cdot17)) 变换来说足够小，而巨大的 (M) 可以通过二进制求幂来处理。 

所有可能的有序序列的暴力枚举将有 (K^M) 种情况。 即使有（K=2）和（M=10^9），这也已经是无望的了。 在每堆之后枚举所有 XOR 状态也需要 (O(M2^{17}))，这太大了，因为 (M) 非常大。 

有几种边缘情况可能会使原本合理的实现变得错误。 对于一堆，XOR 只是其正大小，因此 Alice 总是获胜。 例如，```
1 1
5
```有答案（1）。 将零异或视为获胜位置的实现将错误地返回零。 

由于只有一种可能的堆大小，因此每一堆都是相同的。 如果(K=1)，则当(M)为偶数时异或为零，当(M)为奇数时异或非零。 例如，```
2 1
5
```答案为 (0)，而```
11 1
5
```有答案（1）。 假设存在多个不同值的解决方案可能会错误地处理这种情况。 

另一种边界情况是可用大小包含接近 (2^{17}) 的值。 低于 (2^{17}) 的两个值的异或仍然低于 (2^{17})，因此恰好包含 (2^{17}) 个状态的数组就足够了。 例如，与```
2 2
65536 131071
```唯一的零异或结果是两个相等的选择，因此爱丽丝以概率 (1/2) 获胜。 使用大小为 (2^{17}-1) 的数组将访问无效状态。 

## 方法

 直接解决方案立即遵循 Nim 规则。 生成 (M) 堆大小的每个可能序列，对序列中的所有值进行异或，并对异或非零的序列进行计数。 由于每个有序序列都有概率 (1/K^M)，因此获胜概率是获胜序列的数量除以 (K^M)。 

这是正确的，因为完整的序列决定了 Nim 的确切位置，并且当其 XOR 非零时，Nim 就具有获胜的第一步。 问题在于序列的数量。 在最坏的情况下，它们有 (K^M) 个，它是 (M) 的指数。 对于 (K=131071) 甚至很小的 (M)，这都变得不可行。 

更结构化的蛮力可以维持获得每个 XOR 值的方法数量。 如果(dp[x])是异或为(x)的序列数，则再添加一堆意味着

 [
 newdp[x]=\sum_{c\in C}dp[x\oplus c].
 ]

 有 (2^{17}) 个可能的 XOR 值，因此一次转换成本为 (O(K2^{17}))。 重复 (M) 次给出 (O(MK2^{17}))，但仍然失败，因为 (M) 可以是 (10^9)。 

关键的观察是 XOR 不是普通的加法，而是形成一个群，其中 Walsh-Hadamard 变换对角化卷积。 上面的转换是与可用堆大小的频率函数的异或卷积。 应用 Walsh-Hadamard 变换后，每个异或卷积都变成逐点乘法。 

当 (x) 是可用大小时，令 (f[x]) 为 (1)，否则为 (0)。 (f) 的变换记为 (F)，描述了每个 XOR 频率的贡献。 选择 (M) 个独立堆对应于 (f) 的第 (M) 次异或卷积幂，因此变换后每个分量就变成 (F[i]^M)。 

然后，逆 Walsh-Hadamard 变换恢复每个所得 XOR 值的序列数。 我们只需要 XOR (0) 处的值。 对于标准非归一化变换，逆变换贡献一个因子 (1/2^{17})。 由于原始选择是等概率的，我们还除以 (K^M)。 

因此，整个计算被简化为一次 Walsh-Hadamard 变换、(2^{17}) 模幂和一次最终归一化。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(K^MM)) | (O(M)) | 太慢了 |
 | XOR 状态上的 DP | (O(MK2^{17})) | (O(2^{17})) | 太慢了 |
 | 沃尔什-阿达玛变换 | (O(2^{17}\cdot17 + 2^{17}\log M)) | (O(2^{17})) | 已接受 |

 ## 算法演练

 1. 创建数组`a`长度 (N=2^{17})。 将 (1) 放置在每个允许的堆大小 (c_i) 处，将 (0) 放置在其他位置。 这表示产生每个异或值的可用选择的数量。 
2. 应用 Walsh-Hadamard 变换`a`。 对于 XOR 卷积，变换通过逐点乘法代替卷积。 经过这次操作后，`a[x]`是与频率 (x) 相关的变换值。 
3. 将每个变换后的值提高到 (998244353) 的 (M) 次方模数。 这代表选择（M）堆，因为（M）倍异或卷积在变换后变成普通乘法。 
4. 对所有 (N) 个乘方变换值求和。 零位置处的 Walsh-Hadamard 逆变换正是该总和除以 (N)，因为零频率逆系数中的每个符号都是 (+1)。 
5. 将获胜序列的数量除以 (K^M)。 我们可以使用模逆来执行模 (998244353) 的两个除法。 等效地，乘以 (N^{-1}) 和 ((K^M)^{-1})。 
6. 结果值是异或为零的概率。 由于当 XOR 非零时 Alice 获胜，因此从 (1) 中减去它。 

其原理：设 (g_M[x]) 表示 (M) 个允许堆大小的有序序列的数量，其 XOR 为 (x)。 基函数是(g_1=f)，加上一堆就得到XOR卷积(g_{m+1}=g_m*f)。 Walsh-Hadamard 变换将此递推式转换为 (\widehat g_{m+1}[x]=\widehat g_m[x]\widehat f[x])，因此归纳给出 (\widehat g_M[x]=\widehat f[x]^M)。 因此，逆变换可恢复精确的计数 (g_M[0])。 除以总数 (K^M) 得出失败位置的概率，并取其补数得出 Alice 获胜的概率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353
N = 1 << 17

def fwht(a):
    n = len(a)
    length = 1

    while length < n:
        step = length << 1
        for start in range(0, n, step):
            end = start + length
            for i in range(start, end):
                x = a[i]
                y = a[i + length]
                a[i] = (x + y) % MOD
                a[i + length] = (x - y) % MOD
        length <<= 1

def solve():
    M, K = map(int, input().split())
    c = list(map(int, input().split()))

    a = [0] * N
    for x in c:
        a[x] = 1

    fwht(a)

    total_zero_xor = 0
    for x in a:
        total_zero_xor = (total_zero_xor + pow(x, M, MOD)) % MOD

    inv_n = pow(N, MOD - 2, MOD)
    inv_k_power = pow(pow(K, M, MOD), MOD - 2, MOD)

    zero_probability = total_zero_xor * inv_n % MOD
    zero_probability = zero_probability * inv_k_power % MOD

    answer = (1 - zero_probability) % MOD
    print(answer)

if __name__ == "__main__":
    solve()
```该数组的大小为 (N=2^{17})，因为每个堆大小都低于 (2^{17})，并且 XOR 永远不会将其设置为高于其操作数中出现的最高位。 对于每个允许的大小，该数组的初始化频率为 1。`fwht`就地执行 XOR Walsh-Hadamard 变换。 在每一层，值对都被它们的和与差所取代。 有 (17) 层，每层处理所有 (N) 个条目，需要 (O(N\log N)) 时间。 

变换后的值提升为`M`与Python的模块化`pow`，它使用二进制求幂。 这一点至关重要，因为 (M) 可以是 (10^9)； 明确地乘以 (M) 次是不可能的。 

所有幂变换值的总和是 XOR 零处的非标准化逆变换。 除以 (N) 给出零异或序列的数量。 原始数组包含计数而不是概率，因此该数字还必须除以 (K^M)（有序堆配置的总数）。 

模逆是用费马定理计算的，因为 (998244353) 是素数。 Python中不存在整数溢出问题，每次中间模乘都会减少`% MOD`。 

该变换不需要显式地反转。 我们只需要系数零，并且对于该系数，每个逆变换符号都是正的。 计算完整的逆变换会增加不必要的工作。 

## 工作示例

 ### 示例 1

 输入是```
2 2
1 3
```有(N=8)种可能的XOR状态，并且初始频率阵列在位置(1)和(3)处具有XOR状态。 

对于这两个值，Walsh-Hadamard 变换仅包含值 (2) 或 (0)，具体取决于相应的掩码是否为这两个值提供相同的符号。 

| 数量 | 价值|
 | ---| ---|
 | (男)| 2 |
 | (K) | 2 |
 | XOR 状态数量 | 8 |
 | 非零初始位置 | 1, 3 |
 | 总配置| (2^2=4) | (2^2=4) |
 | 零异或配置 | 2 |
 | 零异或概率 | (2/4=1/2) |
 | 爱丽丝的概率 | (1/2) |

 对 (998244353) 取模，(1/2) 为 (499122177)，与样本匹配。 

两个失败的配置是`(1,1)`和`(3,3)`。 另外两个配置进行异或 (1\oplus3=2)，因此 Alice 获胜。 

### 示例 2

 输入是```
11 1
5
```只有一种可能的堆大小。 因此，十一堆中的每一堆都包含 (5)。 

| 数量 | 价值|
 | ---| ---|
 | (男)| 11 | 11
 | (K) | 1 |
 | 唯桩价值| 5 |
 | 异或结果 | (5) |
 | 零异或概率 | 0 |
 | 爱丽丝的概率 | 1 |

 因为十一是奇数，

 [
 5\oplus5\oplus\cdots\oplus5=5。 
]

 位置获胜，所以答案是（1）。 

这个例子也证实了算法在没有任何特殊情况的情况下处理（K=1）。 在变换中，每个变换后的值要么是 (1) 要么是 (-1)，将它们提高到奇数次方可以保留所需的零异或计数。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | (O(2^{17}\cdot17 + 2^{17}\log M)) | 每个变换系数的一个 FWHT 加一个模幂 |
 | 空间| (O(2^{17})) | 变换数组包含 (131072) 个模值 |

 最大的变换只有 (131072) 个条目和 17 个层，因此变换本身需要大约 (2.2) 万对操作。 求幂阶段针对 (M\le10^9) 的每个条目执行大约 (17) 个模乘法步骤。 这很容易与 (256) MB 内存限制兼容，并且对于 (M) 可以是 (10^9) 的问题来说是适当的复杂度。

## 边缘情况

 当(M=1)时，唯一可能的堆大小为正，因此其异或不能为零。 例如，```
1 1
5
```有答案（1）。 在算法中，变换后的值用于重建原始频率数组，并且零异或系数为零，因为输入数组在零位置没有值。 因此最终的补集是(1)。 

当（K=1）时，所有桩的大小相同。 为了```
2 1
5
```XOR 为 (5\oplus5=0)，所以答案为 (0)。 对于奇数 (M)，XOR 为 (5)，因此 Alice 获胜。 样品```
11 1
5
```有十一个 (5) 的副本，给出 XOR (5) 和答案 (1)。 该变换自然地处理两个奇偶校验，因为每个变换后的分量都被提升到相应的幂。 

当堆大小接近最大允许值时，变换仍然只需要 (2^{17}) 个状态。 考虑```
1 2
65536 131071
```单堆要么是（65536），要么是（131071），两者都非零，所以答案是（1）。 数组索引有效，因为最大可能值恰好是 (2^{17}-1=131071)。 因此，该数组必须具有从 (0) 到 (131071) 的索引，正好需要 (2^{17}) 个条目。 

对于具有不同可用值的两堆，唯一的零异或结果是相等的值。 和```
2 2
1 2
```四个有序结果是`(1,1)`,`(1,2)`,`(2,1)`， 和`(2,2)`。 两个具有零 XOR，两个具有非零 XOR，给出 Alice 的概率 (1/2)。 这会发现一个简单的错误，即计算无序对而不是有序独立选择。 

最后，实现不得使用大小等于最大堆值的数组。 该变换表示整个 XOR 组，包括状态 0，因此其大小为 (2^{17})，而不是 (131071)。 这种区别对于 (131071) 等值至关重要，其索引是变换数组的最终有效位置。
