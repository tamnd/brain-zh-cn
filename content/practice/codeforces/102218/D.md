 ## 解决方案
 ## 问题理解

 网络是一棵树，一次长出一台计算机。 计算机 1 最初存在。 每台新计算机都会收到下一个未使用的 ID，因此当当前有`curr`计算机，新计算机获得 id`curr + 1`。 它通过一个边缘连接到一台现有的计算机上。 

类型 1 的查询间接指定新计算机的父级。 类型 2 的查询要求两台现有计算机之间的最短路径。 答案计算的是计算机而不是边缘，因此包含的路径`k`边缘有答案`k + 1`。 

使用之前的答案故意对输入进行编码。 如果`last`是最新的答案，有`curr`现有计算机，类型 1 值`p'`代表父母

 [
 p=(p'+最后)\bmod curr+1。 
]

 对于类型 2，两个端点的解码方式完全相同。 这意味着查询必须严格在线处理。 我们不能先解码所有查询，然后预处理最终的树，因为解码下一个查询所需的值是由当前查询生成的。 

最多可以有 (2\cdot10^5) 次操作，因此最终的树也最多有 (2\cdot10^5+1) 台计算机。 为每个查询遍历整个根到节点路径的解决方案可能需要 (O(Q^2)) 时间。 使用 (Q=2\cdot10^5)，可以达到大约 (4\cdot10^{10}) 次父遍历，远远超出了两秒限制所允许的范围。 我们需要每次操作的对数工作。 

树结构给了我们一个特别有用的属性：每个新创建的顶点都是一个叶子，并且它的父节点已经存在。 因此，有关新顶点的所有信息都可以立即从其父顶点计算出来。 插入后我们永远不需要重建或遍历现有的树。 

有几种边缘情况可能会悄无声息地破坏实现。 第一个是查询同一台计算机两次。 例如，```
1
2 0 0
```只有计算机 1，因此解码的两个端点都是 1，正确的输出是`1`。 边的距离为零，但问题要求计算机的数量，所以答案是 1。 忘记最终结果的实现`+1`会打印零。 

第二个边缘情况是新添加的计算机，其父级是当前最大的有效 id。 考虑```
4
1 0
1 1
2 0 0
2 0 1
```第一次插入在计算机 1 下创建计算机 2 并输出`2`。 第二个插入有`last=2`，所以它的父级是`(1+2)%2+1=2`，在计算机2下创建计算机3并输出`3`。 第三个查询解码为`(1,1)`和输出`1`。 最终查询解码为`(2,3)`，其路径是`2-3`，所以输出是`2`。 正确的输出是```
2
3
1
2
```一个常见的差一错误是使用`curr`在解码父级时递增它之后。 在插入新顶点之前，必须使用计算机数量对父顶点进行解码。 

第三个边缘情况是`last`每次查询后都会发生变化，包括类型 2 查询。 例如，```
3
1 0
2 0 0
2 0 0
```插入后，`last=2`。 下一个查询将两个端点解码为 1 并输出`1`， 所以`last`变为 1。因此，仅当当前计算机数量和编码值产生该结果时，最终查询的两个端点仍等于 2。 重用旧的`last`value 会错误地解码后续查询。 编码是算法状态的一部分，而不仅仅是输入预处理。 

## 方法

 直接的解决方案是存储每台计算机的父级，并在之间进行查询`u`和`v`，从两个顶点向上行走，直到它们的路径相交。 这是正确的，因为网络始终是一棵树，因此两台计算机之间只有一条路径。 如果我们能找到它们的最低共同祖先，则路径上的边数为

 [
 深度[u]+深度[v]-2\c点深度[lca]。 
]

 添加一台即可得到所需的计算机数量。 

问题是运行时间。 考虑一棵只有一条长链的树。 涉及最深计算机的查询可能需要 (O(n)) 父步骤。 如果树有 (2\cdot10^5) 个顶点，并且我们进行 (2\cdot10^5) 个这样的查询，则总数约为 (4\cdot10^{10}) 次操作。 蛮力法是正确的，但从根本上来说太慢了。 

改变问题的观察是插入仅添加叶子。 当新电脑`x`附加到现有的父级`p`，它的整个祖先链可以立即概括出来。 店铺`up[k][x]`, 的祖先`x`通过向上移动 (2^k) 条边获得。 自从`p`已知，则递推式为

 [
 上[0][x]=p
 ]

 和

 [
 上[k][x]=上[k-1][上[k-1][x]]。 
]

 当以下情况时，现有顶点不会发生变化`x`被插入，因此所有先前计算的二进制提升信息将永远有效。 

这正是二进制提升效果很好的设置。 它让我们在 (O(\log n)) 时间内找到 LCA，方法是首先向上移动较深的顶点，直到两个顶点具有相等的深度，然后将两个顶点一起从大跳跃提升到小跳跃。 插入本身也需要 (O(\log n))，因为我们为 2 的所有幂计算新顶点的祖先。 

编码输入不会改变数据结构。 它只需要我们在处理查询之前对其进行解码，计算其答案，并立即将该答案存储在`last`以便进行下一次查询。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(Q^2)) 最坏情况 | (O(Q)) | 太慢了 |
 | 最佳| (O(Q\log Q)) | (O(Q\log Q)) | 已接受 |

 ## 算法演练

 1. 将计算机 1 初始化为 root。 将其深度设置为零并将每个二进制提升祖先初始化为零。 根没有真正的父节点，因此零是一个方便的哨兵。 
2. 保留`curr`等于当前存在的计算机数量并且`last`与之前的答案相同。 最初两者都有所需的值，`curr=1`和`last=0`。 
3. 对于类型 1 查询，使用以下命令解码父查询`(p_prime + last) % curr + 1`改变之前`curr`。 新电脑有id`curr + 1`，因为 id 是连续分配的。 
4. 将新计算机的深度设置为`depth[parent] + 1`及其直接父级`parent`。 然后计算每个更高的祖先`up[k][new] = up[k-1][up[k-1][new]]`。 这是可行的，因为右侧引用的每个顶点在插入之前就已经存在。 
5. 新计算机到计算机1的路径包含`depth[new] + 1`电脑。 将此值设置为`last`并输出它。 由于根的深度为零，因此深度处的顶点`d`正好有`d+1`到根的路径上的顶点。 
6. 对于类型 2 查询，使用当前的解码两个端点`last`和`curr`。 两个端点都保证引用现有计算机，因为模数是按当前顶点数取的。 
7. 找到解码端点的LCA。 首先提升更深的端点，直到深度匹配。 然后从最大到最小检查二元提升级别，并在对应的祖先不同时提升两个端点。 在此过程之后，它们的直接父级是 LCA。 
8. 计算端点之间的边数：`depth[u] + depth[v] - 2 * depth[lca]`。 加一，因为两个端点都被计数，将结果存储在`last`，并输出它。 

### 为什么它有效

 关键的不变量是对于每台现有的计算机`v`,`depth[v]`是其与计算机 1 之间的精确边缘距离，并且`up[k][v]`是其精确的第 (2^k) 个祖先。 当插入新叶子时，其父叶子已经有效，因此递归可以正确计算所有新的祖先值，而无需修改任何旧值。 然后，二元提升会找到真正的 LCA，因为均衡深度将两个顶点置于同一水平，并且随后的最大到最小跳跃将它们向上移动，而不跨越其 LCA。 因此，标准树距离公式给出了精确的边数，加一则给出了路径上计算机的精确数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAX_Q = 200000
MAX_N = MAX_Q + 1
LOG = MAX_N.bit_length()

def solve():
    q = int(input())

    depth = [0] * (MAX_N + 1)
    up = [[0] * (MAX_N + 1) for _ in range(LOG)]

    curr = 1
    last = 0

    out = []

    for _ in range(q):
        parts = input().split()
        t = int(parts[0])

        if t == 1:
            p_prime = int(parts[1])

            # Decode using the number of computers before insertion.
            parent = (p_prime + last) % curr + 1

            new_node = curr + 1
            depth[new_node] = depth[parent] + 1
            up[0][new_node] = parent

            for k in range(1, LOG):
                mid = up[k - 1][new_node]
                up[k][new_node] = up[k - 1][mid]

            curr += 1

            last = depth[new_node] + 1
            out.append(str(last))

        else:
            u_prime = int(parts[1])
            v_prime = int(parts[2])

            u = (u_prime + last) % curr + 1
            v = (v_prime + last) % curr + 1

            if depth[u] < depth[v]:
                u, v = v, u

            # Bring u to the same depth as v.
            diff = depth[u] - depth[v]
            bit = 0
            while diff:
                if diff & 1:
                    u = up[bit][u]
                diff >>= 1
                bit += 1

            if u == v:
                lca = u
            else:
                for k in range(LOG - 1, -1, -1):
                    if up[k][u] != up[k][v]:
                        u = up[k][u]
                        v = up[k][v]

                lca = up[0][u]

            last = depth[u] + depth[v] - 2 * depth[lca] + 1
            out.append(str(last))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```这`depth`array 使用从零开始的树深度，因此计算机 1 的深度为零。 这使得标准距离公式特别清晰。 所请求的答案就是边缘距离加一。`up[0][v]`存储直接父级，同时`up[k][v]`存储上面的祖先 (2^k) 条边`v`。 级别数为`MAX_N.bit_length()`。 至多有`200001`计算机，这提供了足够的级别来表示每个可能的深度差异和每个可能的 LCA 跳跃。 

对于插入，`curr`仍然代表旧的计算机数量，同时对父级进行解码。 只有在计算出新计算机的所有信息后，我们才会递增`curr`。 编码公式需要这种排序。 

对于类型 2 查询，端点在任何 LCA 工作之前被解码。 然后根据设置的深度差位来提升较深的端点。 如果顶点相等，则该顶点已经是 LCA。 否则，循环考虑从最大到最小的跳转。 什么时候`up[k][u]`和`up[k][v]`不同的是，两个顶点都可以安全地向上移动 (2^k)，因为它们的 LCA 仍然高于这两个不同的祖先。 最终他们成为 LCA 的孩子。 

对于此处使用的值，Python 整数不会溢出。 解码公式中的中间值最大也只有几十万，距离最多也就是计算机的数量。

 ## 边缘情况

 处理单计算机情况是因为根的深度为零，并且其上的每个查询的边缘距离为零。 该实现将距离转换为计算机数量时加一。 为了```
1
2 0 0
```两个端点都解码为 1，`lca=1`，答案是`0+0-2*0+1=1`。 

自查询情况不需要特殊的数据结构操作。 什么时候`u == v`，深度均衡使它们立即相等，因此 LCA 是同一个顶点。 距离公式变为`depth[u] + depth[u] - 2*depth[u] + 1`，这是一个。 因此```
4
2 0 0
2 0 0
2 0 0
2 0 0
```产生四行包含`1`， 虽然`last`每次查询后都会发生变化。 

父边界情况由模公式控制。 在```
4
1 0
1 1
2 0 0
2 0 1
```第一个插入使用父级 1。它的答案是 2，因此第二个插入将其父级解码为`(1+2)%2+1=2`。 因此，新计算机的深度为 2，答案为 3。在下一个查询之后，`last`变为1，最终编码端点变为2和3。它们的路径恰好包含两台计算机。 该算法无需走完整条路径即可获得这些结果。 

的排序`curr`是另一个微妙的边界条件。 假设插入之前有两台计算机。 父级必须用模 2 进行解码，因为当前仅存在 id 1 和 2。 递增`curr`首先会错误地允许公式选择尚未创建的计算机 3. 实现计算`parent`首先，构建`new_node`，然后才递增`curr`。 

最后，编码后的输入必须进行在线处理。 查询可以改变`last`，并且该值会改变每个后续编码数字的含义。 例如，在示例 1 中，第一次插入产生`last=2`; 第二个插入的原始父值是`2`，但它的实际父级是`(2+2)%2+1=1`。 任何解码所有操作的实现`last=0`，或者使用最终答案而不是先前的答案，构建不同的树并因此给出不同的结果。
