 ## 解决方案
 ## 问题理解

 Monocarp 的密码问题是一个受数字多重性和排除性约束的计数问题。 密码是四位数字的序列。 每个序列必须恰好包含两个不同的数字，并且每个数字恰好出现两次。 我们还得到了密码中不能出现的数字列表。 任务是确定存在多少符合这些约束的有效 4 位序列。 

输入提供多个测试用例。 对于每个测试用例，我们首先读取禁止数字的数量，然后读取禁止数字本身。 输出必须是满足两个不同数字、每个数字两个要求的序列计数，同时避免禁止数字。 

限制很小：总共最多 10 个数字，最多 8 个禁止数字。 这意味着任何对剩余允许数字执行简单组合计算的解决方案都是高效的。 边缘情况包括禁止的数字仅留下 1 个或 0 个可用数字的情况，其中不可能有有效的密码。 例如，如果10位数字中有9位被禁止，只留下一位数字，则不可能用两个不同的数字组成密码。 

## 方法

 最简单的方法是生成从 0 到 9 的所有可能的 4 位数字序列，检查是否正好出现两个不同的数字，并且每个数字出现两次，然后丢弃包含禁止数字的序列。 这种强力解决方案是可行的，因为只有 10,000 个序列，但它是不必要且乏味的。 

更好的方法依赖于组合学。 一旦我们删除了禁止的数字，我们就剩下了`k`允许的数字。 为了形成有效的密码，我们需要从中选择两个不同的数字`k`允许的数字。 这只是“k 选择 2”。 对于每个这样的对，恰好有六个不同的序列满足每个数字中两个的条件：这些序列都是以下的所有可能排列`[d1, d1, d2, d2]`，即`4! / (2! * 2!) = 6`。 因此，有效序列的总数为`6 * (k choose 2)`。 如果`k`小于 2，则不存在有效密码。

 ## 算法演练

 1.读取测试用例数量`t`。 

2. 对于每个测试用例，读取禁止数字的数量`n`以及禁用数字列表。 

3. 计算允许的位数：`k = 10 - n`。 

4.如果`k < 2`，输出 0，因为不可能选择两个不同的数字。 

5. 否则，计算从允许的数字中选择两位数字的方法数，即`k * (k - 1) / 2`。 

6. 将对的数量乘以 6 以考虑排列`[d1, d1, d2, d2]`。 

7. 输出结果。 

该方法保证了正确性，因为它直接枚举所有组合可能性，不会过度计数或遗漏任何情况。 保持的不变性是我们只计算具有两个不同数字的序列，每个数字恰好出现两次，并且不包含禁止的数字。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    forbidden = list(map(int, input().split()))
    k = 10 - n  # number of allowed digits
    
    if k < 2:
        print(0)
        continue
    
    # number of pairs of distinct allowed digits
    pairs = k * (k - 1) // 2
    
    # each pair has 6 permutations of type [d1, d1, d2, d2]
    result = pairs * 6
    print(result)
```该代码使用快速输入读取并有效处理多个测试用例。 我们用 10 减去禁止的数字，得到可用的数字数量。 当剩下的数字少于两位时，我们检查简单的情况。 对于有效计数，我们计算“k 选择 2”并乘以六以获得每个数字对的六种可能排列。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())

        n = int(input())
        forbidden = list(map(int, input().split()))
        k = 10 - n
        if k < 2:
            output.append("0")

        pairs = k * (k - 1) // 2

 ## 边缘情况

 如果除一位数字外所有数字均被禁止，`k = 1`，算法正确返回 0，因为无法形成密码。 如果没有禁止数字，`k = 10`，对数为 10 选择 2 = 45，给出 45 * 6 = 270 个序列。 如果仅允许保留两位数字，则算法会正确生成 6 个序列。 所有边缘情况都可以通过简单的算术正确处理。
