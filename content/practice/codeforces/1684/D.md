 ## 解决方案
 ## 问题理解

 我们得到了一系列陷阱，每个陷阱都有一个基本伤害值。 我们按顺序穿过陷阱，对于每个陷阱，我们要么承受其伤害，要么通过跳过它来跳过它。 每次跳过陷阱都会防止其造成伤害，但每次跳跃都会使所有后续陷阱的伤害增加 1 点。 我们最多可以做$k$跳跃。 目标是尽量减少受到的总损害。 

输入由多个测试用例组成。 每个测试用例给出$n$, 陷阱数量,$k$，允许的最大跳跃，以及列表$n$代表每个陷阱的基础伤害的整数。 每个测试用例的输出是一个整数：可实现的最小总损坏。 

约束条件允许$n$达到$2 \cdot 10^5$和总和$n$跨测试用例最多$2 \cdot 10^5$。 这表明任何解决方案都必须大致呈线性$n$每个测试用例。 尝试每种跳跃组合的简单方法是不可能的，因为陷阱子集的数量是$2^n$，远远超过合理的计算时间。 基础伤害值高达$10^9$建议我们必须避免任何低效累积损害的解决方案。 

非明显的边缘情况包括以下情况$k \ge n$，我们可以跳过所有陷阱并受到零伤害，以及由于额外伤害的级联效应，最佳跳跃不是最大基础伤害陷阱的情况。 例如，在`[5,10,11,5]`和$k=1$，跳过第三个陷阱比跳过最大的陷阱更好，因为它在考虑了后续陷阱的+1加值后最小化了总和。 

## 方法

 暴力解决方案将枚举要跳过的陷阱的所有子集，计算每个子集的总损害，并选择最小值。 这是正确的，因为它尝试了所有可能性，但它需要$O(2^n)$每个测试用例的操作，这对于$n$最多$2 \cdot 10^5$。 

关键的见解是考虑以相反顺序跳过陷阱的效果。 每个陷阱的有效成本是其基础伤害减去跳过后续陷阱所带来的潜在“避免奖励”。 如果我们跳过最后一个$k$陷阱，这些跳跃不会影响之前的陷阱。 通过反转伤害列表并首先考虑最大的有效伤害，我们可以贪婪地选择$k$跳过陷阱可以最大限度地减少总伤害。 通过减少基础伤害对陷阱进行排序是有效的，因为奖励效果随着跳跃次数线性增加，因此最好跳过最近位置的基础伤害最大的陷阱。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和$k$，以及陷阱伤害数组$a$。 
2. 按照基础伤害的降序对陷阱进行排序。 这可以识别出其伤害对总伤害贡献最大的陷阱。 
3. 选择第一个$k$陷阱从排序列表中跳过。 每次跳跃都会避免陷阱的基础伤害，从而减少总伤害。 跟踪到目前为止已应用的跳跃次数。 
4. 按顺序遍历数组。 对于每个陷阱，如果它被标记为跳跃，则跳过添加其伤害。 否则，将其伤害加上之前已应用的跳跃次数。 
5. 步骤4中累加的总和就是最小总损坏。 

该算法之所以有效，是因为跳跃对于基础伤害最大的陷阱最为有效。 通过排序并选择顶部$k$陷阱，我们确保每次跳跃都能最大限度地减少总伤害。 额外伤害自然是通过按顺序穿过陷阱时累积跳跃计数来处理的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        # sort traps by base damage in descending order
        sorted_indices = sorted(range(n), key=lambda i: a[i], reverse=True)
        jump_set = set(sorted_indices[:k])
        damage = 0
        jumps_done = 0
        for i in range(n):
            if i in jump_set:
                jumps_done += 1
            else:
                damage += a[i] + jumps_done
        print(damage)

if __name__ == "__main__":
    solve()
```我们首先按伤害降序对陷阱索引进行排序，然后选择顶部$k$指数跳跃。 穿越时，每个跳过的陷阱都会增加跳跃计数器，从而增加后续陷阱的有效伤害。 总和`a[i] + jumps_done`对于非跳跃陷阱，总伤害最小。

 ## 边缘情况

 当$k \ge n$， 例如`n=4, k=4, a=[8,7,1,4]`，算法正确地跳过所有陷阱。 每个陷阱的跳跃计数器都会增加，但由于所有陷阱都会被跳过，因此没有陷阱会造成伤害。 损坏保持为零，这符合预期的最小损坏。 

当多个陷阱的伤害相同时，例如`a=[5,5,5,5]`和`k=2`，算法选择排序后的前两个索引（索引0和1）进行跳转。 其余陷阱造成的伤害为 5 + 2 跳跃 = 7 和 5 + 2 = 7，总和为 14，对于任何其他组合而言，这是最小的。 该方法通过选择排序顺序中最早出现的值来优雅地处理相等的值。
