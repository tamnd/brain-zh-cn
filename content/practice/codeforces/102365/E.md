 ## 解决方案
 ## 问题理解

 我们有一个数组`a[1..N]`按时间顺序描述激动人心的场景。 我们必须将这个数组精确地切割成`K`非空连续部分。 某个部分贡献的值是该部分内的最大数组值，目标是最大化这些值的总和`K`最大值。 官方的限制是`1 <= K <= N <= 2000`和`1 <= a[i] <= 1000`。 

第一个界限，`N <= 2000`，足够大，以至于在每个 DP 状态内尝试每对切入位置的成本太高。 标准分区 DP 有`K * N`状态，每个状态最多可以有`N`可能的先前切割位置，给出`O(KN^2)`，达到约`8 * 10^9`转变时`N = K = 2000`。 这远远超出了一秒的限制所能支持的范围。 我们需要利用当线段的右端点移动时其最大变化的特殊方式。 

有几种边界情况可以悄悄地破坏粗心的实现。 如果`K = 1`，只有一个段，所以答案就是整个数组的最大值。 例如，`N = 2, K = 1, a = [3, 1]`给出`3`， 不是`4`，因为两个场景属于同一幕。 

如果`K = N`，每个段必须恰好包含一个元素。 例如，`N = 3, K = 3, a = [2, 7, 4]`给出`13`。 意外允许空段的 DP 可能会产生无效转换和溢出。 

同等价值也需要小心处理。 为了`N = 4, K = 2, a = [5, 5, 1, 5]`，答案是`10`。 当新值等于当前段最大值时，相应的候选值可以被视为一个单调堆栈组，因为它们的最大值不会改变。 在堆栈条件中使用错误的严格性可能会将相等的最大值分成不必要的组，尽管只有在相关候选状态得到一致处理的情况下，最终值才保持正确。 

## 方法

 直接动态规划公式很简单。 让`dp[k][i]`是通过划分第一个可以获得的最大兴奋`i`元素精确地`k`非空行为。 如果最后一幕在位置之后立即开始`j`，那么它的贡献就是`max(a[j+1..i])`， 所以`dp[k][i] = max(dp[k-1][j] + max(a[j+1..i]))`总体而言有效`j`。 

这种递归是正确的，因为每个有效分区在其最后一个行为之前都有一个唯一的位置。 一旦这个位置固定下来，第一个`j`元素形成最优解`k-1`作用，而最后的间隔贡献其最大。 

暴力实现可以在移动时保持最大值`j`向后，所以每个 DP 状态需要`O(N)`时间，而不是从头开始重新计算每个间隔最大值。 有`O(KN)`状态，给予`O(KN^2)`总工作量。 和`N = K = 2000`，这是关于`8 * 10^9`候选人转换太慢了。 

关键的观察是，过渡过程中昂贵的部分并不`dp[k-1][j]`。 这是变化的值`max(a[j+1..i])`作为`i`向右移动。 

修复一层DP层`k`假设我们正在处理正确的端点`i`。 对于每一个可能的开始`j`，考虑候选人`dp[k-1][j] + max(a[j+1..i])`。 

作为`i`加一，所有这些区间最大值要么保持不变，要么成为新值`a[i]`。 更具体地说，如果当前多个起点的分段最大值不大于`a[i]`，所有这些开始现在都具有相同的新最大值`a[i]`。 它们可以合并为一组。 

单调堆栈自然地代表这些组。 堆栈存储递减的段最大值。 除了每个最大值之外，我们还存储最大的`dp[k-1][j]`在属于该组的所有开始中。 该组代表的最佳候选者就是`group_maximum + largest_previous_dp`。 

当一个新的`a[i]`到达，其最大值最多为`a[i]`被弹出并合并。 自从`a[i]`至少与它们之前的最大值一样大，它们的候选值在合并后不会减少。 这给出了另一个重要的简化：我们不需要线段树或堆来维护全局最大值。 如果旧的全局最优值属于弹出组，则合并组包含相同的候选者并可能对其进行改进。 如果它属于未弹出的组，则它保持不变。 因此，我们可以用单个标量维持当前 DP 状态的答案。 

堆栈是单调的，每个组在一个 DP 层期间被压入一次并最多弹出一次。 因此一个 DP 层需要`O(N)`，给出一个`O(KN)`算法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力DP |`O(KN^2)`|`O(N)`带滚动 DP | 太慢了 |
 | 单调堆栈 DP |`O(KN)`|`O(N)`| 已接受 |

 ## 算法演练

 1. 定义`prev[i]`作为划分第一个的最佳分数`i`元素转化为前几行为。 最初，对于零行为，仅`prev[0] = 0`是有效的。 其他任何状态都是不可能的。 
2. 处理来自的行为数`1`通过`K`。 对于当前图层，创建`cur`， 在哪里`cur[i]`最终将代表划分第一个的最佳分数`i`元素变成当前的行为数。 
3. 对于固定的右端点`i`，考虑每一个可能的开始`j`最后一幕。 其候选值为`prev[j] + max(a[j+1..i])`。 组不是单独存储每个候选者，而是从当前间隔最大值相等的组开始。 
4. 将这些组存储在堆栈中，其最大值严格从下到上递减。 每个堆栈条目包含一个最大值`mx`和最大的`prev[j]`在该组代表的所有开始中。 该组中最好的候选人是`mx + best_prev`。 
5、加工时`a[i]`，从新的可能的最后一幕开始`j = i-1`。 其区间仅由`a[i]`，所以它的段最大值是`a[i]`其基值为`prev[i-1]`。 
6. 弹出最大值最多为的每个堆栈组`a[i]`。 这些组中的所有起始现在都有`a[i]`作为新的间隔最大值。 合并他们的`best_prev`价值观与`prev[i-1]`，然后创建一组具有最大`a[i]`。 

条件使用`<=`而不是`<`因为相等的最大值对每个候选者都有相同的影响。 将它们组合起来可以保持堆栈紧凑，而不会失去任何可能的最佳效果。 
7. 新创建组的最佳候选者是`a[i] + best_prev`。 更新全球最佳`cur[i]`与这个值。 未被弹出的组保留完全相同的候选值，因此之前的全局最佳值仍然有效。 
8. 仅处理具有足够元素来满足请求的操作数量的端点。 为了`k`行为，第一个可能的端点是`i = k`，因为每一个行为都必须至少包含一个元素。 完成图层后，替换`prev`经过`cur`。 
9.全部处理完毕后`K`层，`prev[N]`是整个数组的最大可能兴奋度，准确地划分为`K`行为。 

不变量是在计算之前`cur[i]`,每一个可能的开始`j`因为最后一幕恰好由一个堆栈组表示。 在该组中，所有此类起始值都具有相同的值`max(a[j+1..i])`，因此只保留最大的`prev[j]`就足够了。 什么时候`a[i]`被添加，正是最多具有最大值的组`a[i]`变化，并且全部变化到相同的最大值`a[i]`，这正是弹出并合并操作执行的操作。 由于未受影响的组保留了它们的候选者，而合并后的组保留或改进了它吸收的每个候选者，因此维护的全局最大值恰好是`cur[i]`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    neg = -10**18

    # prev[i] = best value for first i elements using the previous
    # number of acts.
    prev = [neg] * (n + 1)
    prev[0] = 0

    for acts in range(1, k + 1):
        cur = [neg] * (n + 1)

        # Each entry is [current maximum, best prev[j]]
        # for all starts j represented by this group.
        stack = []

        best = neg

        for i in range(acts, n + 1):
            x = a[i - 1]

            best_prev = prev[i - 1]

            while stack and stack[-1][0] <= x:
                _, group_best = stack.pop()
                if group_best > best_prev:
                    best_prev = group_best

            stack.append((x, best_prev))

            candidate = x + best_prev
            if candidate > best:
                best = candidate

            cur[i] = best

        prev = cur

    print(prev[n])

if __name__ == "__main__":
    solve()
```外循环为每个可能的动作数量构建一个 DP 层。`prev`包含以下问题的答案`acts - 1`行为，同时`cur`已满`acts`行为。 仅保留两层就足够了，因为重复仅指先前的行为数。 

在一层内，`stack`存储对`(maximum, best_previous_value)`。 第二个分量是最大值`prev[j]`当前共享第一个分量作为其分段最大值的所有起始位置。 有关这些启动的其他信息不会影响过渡。 

线路`while stack and stack[-1][0] <= x`是优化的核心。 每个弹出组的先前最大值不大于`x`，所以将右端点延伸到当前位置后，其最大值变为`x`。 最好的`prev[j]`因此可以合并到新组中。 

变量`best`存储当前端点看到的所有组中的最大候选者。 弹出组后不需要重新计算。 如果旧的最优值位于未弹出的组中，则它不会改变。 如果它位于弹出组中，则该组的候选者将被合并组中至少同样大的候选者替换。 

下界`i = acts`防止不可能的状态，其中少于`acts`元素被分为`acts`非空段。 Python整数不会溢出，理论答案最多是`K * 1000 <= 2,000,000`。 

## 工作示例

 对于样品 1，```
2 1
3 1
```只有一个行为，因此DP层需要找到整个前缀的最大值。 

|`i`|`a[i]`| 更新后的堆栈 |`best`|`cur[i]`|
 | --- | --- | --- | --- | --- |
 | 1 | 3 |`(3, 0)`| 3 | 3 |
 | 2 | 1 |`(3, 0), (1, -inf)`| 3 | 3 |

 在`i = 2`，新值`1`不取代现有的最大值`3`，所以最好的一步划分仍然存在`3`。 输出是`3`。 

对于样品 2，```
2 2
3 100
```第一 DP 层代表一个动作。 在该层的末尾，前缀答案是`3`和`100`。 然后第二层只考虑`i = 2`，因为两个行为至少需要两个元素。 

|`i`|`a[i]`| 更新后的堆栈 |`best`|`cur[i]`|
 | --- | --- | --- | --- | --- |
 | 2 | 100 | 100`(100, 3)`| 103 | 103 103 | 103

 唯一可能的分区是`[3] | [100]`，其得分为`3 + 100 = 103`。 该跟踪还说明了原因`prev[i-1]`是新开始的最后一幕的正确基值。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |`O(KN)`| 每个DP层处理每个端点一次，并且每个堆栈条目最多被压入和弹出一次。 |
 | 空间|`O(N)`| 两个 DP 数组和一个单调堆栈各最多包含`N + 1`条目。 |

 和`N <= 2000`和`K <= 2000`，该算法执行大约 400 万次主 DP 迭代，加上每层线性数量的堆栈操作。 这完全符合预期的渐近要求，而先前切割位置的二次过渡将达到数十亿次操作。

 ## 边缘情况

 当`K = 1`，该算法仅运行一层 DP 层。 对于输入```
2 1
3 1
```第一个位置创建组`(3, 0)`。 在第二个位置上，`1`小于`3`，所以它创建了另一个组，但全局最好的仍然存在`3`。 最终的答案是`3`，恰好是整个数组的最大值。 

什么时候`K = N`，每一幕必须恰好包含一个元素。 考虑```
3 3
2 7 4
```第一层产生最佳的一次性前缀值`2, 7, 7`。 第二层开始于`i = 2`, 给予`2 + 7 = 9`，并最终达到两个行为的正确前缀值。 第三层只能结束于`i = 3`，其中最终的单元素行为贡献`4`，生产`2 + 7 + 4 = 13`。 

相等的值执行堆栈合并规则。 为了```
4 2
5 5 1 5
```当第二个`5`到达时，现有的最大组`5`被弹出，因为它的最大值等于新值。 现在，两个起点都具有相同的段最大值，因此合并它们不会丢失任何信息。 后来，决赛`5`类似地合并当前最大值最多为的所有组`5`。 最优分数是`10`。 

一个案例如```
4 2
1 10 2 9
```显示了为什么 DP 必须保留多个可能的起始位置。 在第一个元素之后切割给出`1 + 10 = 11`，在第三个元素之后切割给出`10 + 9 = 19`。 单调堆栈保留两种可能性的候选者，直到右端点确定哪一个更好，因此算法返回`19`。 

最大尺寸输入包含`2000`元素并可能需要`2000`行为。 所有值都等于`1000`，每个行为都贡献准确`1000`，所以答案是`2,000,000`。 即使在这种高度重复的情况下，每个 DP 层的堆栈操作仍保持线性，从而提供所需的`O(KN)`运行时间。
