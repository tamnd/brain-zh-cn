 ## 解决方案
 ## 问题理解

 我们需要使用凯撒密码来转换小写单词。 输入首先告诉我们是编码还是解码。 编码将每个字母向前移动固定移位`s`，而解码时将每个字母向后移动相同的量。 字母表是循环的，所以移动过去`z`继续从`a`，并在之前移动`a`继续从`z`。 

例如，通过平移`4`，这封信`x`变成`b`在编码期间，因为四个前向位置是`y`,`z`,`a`,`b`。 在解码过程中，`b`变成`x`出于同样的原因反过来。 

第一个输入行是`E`或者`D`，第二个包含转变`s`，第三个包含单词。 该单词包含 1 到 100 个小写字母。 由于单词很短，即使是简单的逐字符模拟也很容易足够快。 移位最多 25，因此即使一次移动一个字母位置的实现最多也能执行`100 * 25 = 2500`人物动作。 

有趣的部分不是性能，而是正确处理循环字母表。 直接的字符比较，例如`ord(c) + s`当结果通过时，可以产生超出小写字母范围的值`z`。 将字母转换为 0 到 25 之间的数字并使用模 26 可以完全避免该边界问题。 

单字母单词是一种有用的最小尺寸情况。 用于输入`E`， 转移`1`，和词`a`，答案是`b`。 意外地仅处理长度大于 1 的单词的实现将在此处失败。 

两端缠绕是主要的边界情况。 例如，编码`z`经过`1`给出`a`，不是后面的字符`z`在统一码中。 同样，解码`a`经过`1`给出`z`。 粗心的实现只是简单地对字符代码进行加法或减法而不对 26 进行模运算，将会产生无效字符。 

该移位也可以大于到字母表边界的距离。 和`E`， 转移`25`，和词`b`，结果是`a`。 将移位视为没有循环算术的普通整数加法使得这些情况很容易被错误处理。 

## 方法

 直接的强力实现可以通过在字母表中重复移动一个位置来处理每个字符。 对于每个角色，我们一次一步地执行转换，从`z`到`a`或来自`a`到`z`根据需要。 这是正确的，因为重复应用一个有效的字母转换会准确地产生所请求的凯撒移位。 

最多 100 个字符，最多 25 个班次，最多执行 2500 次单位置移动。 这远未达到一秒程序的极限，因此对于给定的约束，这种方法实际上是可以接受的。 它的弱点是它做了不必要的工作并且模糊了操作的简单数学结构。 

关键的观察结果是字母表正好有 26 个位置，这些位置形成一个循环。 代表`a`为 0，`b`作为1，通过`z`如 25. 编码则变为`(value + s) % 26`，而解码变为`(value - s) % 26`。 Python的模运算可以正确处理负值，因此解码`a`有班次`1`自然产生位置 25，即`z`。 

蛮力方法之所以有效，是因为重复的单步移动最终会到达相同的目的地。 字母表是一个固定循环的观察结果让我们可以用一个模算术运算来替换所有这些单独的移动。 生成的算法只需要每个字符进行一次转换。

 ## 算法演练

 1.读取操作类型、班次`s`，和这个词。 操作类型决定是否应该对每个字符添加或减去移位。 
2. 使用以下命令将每个字符转换为其从零开始的字母位置`ord(c) - ord('a')`。 这将字母表映射到方便的数字范围`0`通过`25`。 
3.如果操作是编码，则添加`s`到该位置。 如果是解码操作，则减去`s`。 方向直接匹配两个操作的定义。 
4. 申请`% 26`到结果位置。 这使得字母表循环，因此超过 25 的值会回绕到开头，负值会回绕到末尾。 
5. 将结果位置转换回小写字符：`chr(position + ord('a'))`，并将其附加到答案中。 
6. 打印转换后的单词。 每个输入字符都经过独立转换，因此处理所有字符会产生完整的加密或解密单词。 

### 为什么它有效

 在每次迭代中，当前答案字符准确地表示相应输入字符的凯撒变换。 它的从零开始的字母位置增加了`s`用于编码或减少`s`用于解码，模 26 标识该移动之后循环字母表上的唯一位置。 由于每个字符的转换都是独立正确的，因此连接所有转换后的字符即可准确给出所需的单词。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

operation = input().strip()
s = int(input())
word = input().strip()

result = []

for c in word:
    pos = ord(c) - ord('a')

    if operation == 'E':
        pos = (pos + s) % 26
    else:
        pos = (pos - s) % 26

    result.append(chr(pos + ord('a')))

print(''.join(result))
```前三行按照与输入格式相同的顺序读取操作、移位和字。`strip()`从每行中删除换行符，同时保留实际的小写单词。 

对于每个角色，`ord(c) - ord('a')`生成 0 到 25 之间的值。这比直接操作 ASCII 值更可取，因为模运算现在与字母表中的位置完全对应。 

编码分支在取模 26 之前添加移位。对于解码，则使用减法。 蟒蛇的`%`运算符将负结果映射回 0 到 25 的范围，因此`(0 - 1) % 26`是`25`。 这处理解码`a`进入`z`没有任何特殊的边界条件。 

结果会累积在列表中，因为字符串在 Python 中是不可变的。 附加每个字符并连接一次很简单并且以线性时间运行。 

不存在整数溢出问题，因为涉及的最大位置很小。 重要的主要实现细节是在加法或减法之后取模 26，而不是忘记字母表边界处的环绕。

## 测试用例```python
import sys
import io

def solve():
    input = sys.stdin.readline

    operation = input().strip()
    s = int(input())
    word = input().strip()

    result = []

    for c in word:
        pos = ord(c) - ord('a')

        if operation == 'E':
            pos = (pos + s) % 26
        else:
            pos = (pos - s) % 26

        result.append(chr(pos + ord('a')))

    print(''.join(result))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()
    output = sys.stdout.getvalue().strip()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return output

assert run("E\n3\nhello\n") == "khoor", "sample 1"
assert run("D\n3\njreeohghbjrrn\n") == "gobbledeygook", "sample 2"

assert run("E\n1\na\n") == "b", "minimum-size encoding"
assert run("D\n1\na\n") == "z", "minimum-size decoding with wraparound"
assert run("E\n1\nzzzzzzzzzzzzzzzzzzzz\n") == "aaaaaaaaaaaaaaaaaaaa", "all-equal boundary case"
assert run("D\n25\nabcdefghijklmnopqrstuvwxyz\n") == "bcdefghijklmnopqrstuvwxyza", "maximum shift and full alphabet"
assert run("E\n25\nb\n") == "a", "large shift crossing the alphabet boundary"

 ## 边缘情况

 最小尺寸输入`E`， 转移`1`， 单词`a`产生`b`。 该算法转换`a`到位置 0，加 1，得到位置 1，再转换回`b`。 不假设该单词包含多个字符。 

对于前向环绕，请考虑`E`， 转移`1`， 单词`z`。 人物`z`位置为 25。添加移位后得到 26，并且`26 % 26`是0，所以结果是`a`。 直接添加字符代码不会有这种行为。 

对于向后环绕，请考虑`D`， 转移`1`， 单词`a`。 位置为 0，减去位移得出`-1`。 Python 评估`-1 % 26`为 25，所以结果变为`z`。 这是区分正确的模算术与仅处理非负位置的实现的主要情况。 

对于较大的转变，请考虑`E`， 转移`25`， 单词`b`。 的位置`b`为1，所以变换后的位置为`(1 + 25) % 26 = 0`。 输出是`a`。 这会捕获意外使用仅针对接近字母表边界的移位的特殊规则的实现。 

最后，考虑一个仅包含`z`字符，例如`E`， 转移`1`， 单词`zzzz`。 每个字符独立地从位置 25 映射到位置 0，产生`aaaa`。 即使每个字符都执行相同的边界条件，每个字符的不变量仍然有效。
