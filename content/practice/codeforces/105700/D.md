 ## 解决方案
 ## 问题理解

 我们得到一组 n 张稀疏“卡片”，每张长度为 m。 每张卡片只在某些位置写有字母，而所有其他位置都是空白的。 我们还有一个长度为 m 的目标字符串 s。 

我们可以将所有卡片按照从上到下的顺序堆叠。 对于每个位置 i，我们查看第 i 列中具有字母的最上面的卡片，并且该字母成为结果字符串中的可见字符。 如果没有卡片在位置 i 处有字母，则该位置无法填充，并且排序无效。 

任务是确定是否存在恰好产生 s 的卡片排序，如果存在，则输出任何有效的排列。 

约束允许 n 和 m 最多为 100000，写入单元总数最多为 200000。这立即排除了直接比较每对卡片或模拟每个排列的堆叠的任何内容。 任何解决方案都必须在写入条目数量大致线性或接近线性的时间内工作。 

一个微妙的点是，每个位置在可见性方面都是独立的，但顺序将它们耦合在一起：选择一张卡来满足一个位置可能会阻止或覆盖它下面的其他卡。 另一个重要的细节是多张牌可能包含相同的位置，并且只有最上面的一张牌重要。 

一个幼稚的错误是尝试将每个位置贪婪地独立分配给某些卡。 例如，在位置 i 处选择任何与 s[i] 匹配的卡很容易导致以后出现矛盾，因为可能需要同一张卡才能一致地满足多个位置。 另一种失败模式是尝试构建卡之间的依赖关系图，而不考虑每个位置的约束以及在许多卡之间共享的约束。 

## 方法

 一个直接的暴力想法是尝试卡片的所有排列并模拟每个排序是否产生目标字符串。 这是正确的，因为它完全遵循定义，但它是 n 的阶乘，即使 n = 100 也是不可能的。 

关键的观察结果是，最终字符串的每个位置 i 由包含 i 处字母的第一张卡片（按顺序）确定。 因此，对于每个位置 i，只有一张“负责”牌：包含该位置的牌中最大的牌。 该卡必须在位置 i 处包含 s[i]。 

这将问题转化为对卡片相对顺序的约束系统。 对于每个位置 i，我们查看包含 i 处字母的所有卡片。 其中，最终排序中最上面的卡片必须是 i 处字母等于 s[i] 的卡片。 任何在 i 处具有不同字母的卡片必须严格放置在所选卡片的下方，否则它将覆盖可见字母并破坏 s。 

因此，对于每个位置，我们有效地选择一张与 s[i] 匹配的“证人卡”，并且该位置上的所有冲突卡必须按顺序排列在后面。 这导致了卡之间的定向约束。 最后的问题变成：我们能否找到满足所有这些排序约束的排列，如果是，则输出任何拓扑排序。 

我们构造一个有向图，其中边 a → b 意味着卡 a 必须出现在卡 b 之上。 然后我们进行拓扑排序。 如果存在循环，则不存在排序。 

关键的效率技巧是，我们不会以 O(n^2) 的方式为所有冲突显式添加每对边。 相反，我们按位置进行处理：对于每个位置 i，我们按卡片在 i 处包含的字符对卡片进行分组。 所有在 i 处具有不匹配字符的卡片必须位于所有在 i 处具有匹配字符的卡片下方，因此我们将匹配组中的边添加到该位置的所有其他卡片。 由于总出现次数限制为 200000，因此这仍然有效。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力排列 | O(n!) | O(n) | 太慢了 |
 | 约束图+拓扑排序| O(n + 总单元数) | O(n + 总单元数) | 已接受 |

 ## 算法演练

 我们将问题转换为从每列独立导出的排序约束。 

1. 对于每张卡片，将其字母存储在将位置映射到字符的结构中。 这允许快速查找卡片在给定列中的贡献。 这是必要的，因为约束取决于特定位置的比较。 
2. 对于从 1 到 m 的每个位置 i，我们收集所有在 i 处有字母的卡片。 其中，我们将卡片分为匹配 s[i] 的卡片和不匹配 s[i] 的卡片。 
3. 如果至少有一张卡片的 i 字母等于 s[i]，我们将其视为位置 i 的潜在“顶级提供商”。 非匹配集中的任何卡必须位于每个匹配卡的下方，否则它将覆盖 i 处的可见字符并破坏目标字符串。 
4. 我们将位置 i 处的每张匹配卡的有向边添加到位置 i 处的每张不匹配卡上。 这强制要求有效的排序必须将所有正确的贡献者置于该职位的所有错误贡献者之上。 
5. 处理完所有位置后，我们对图进行拓扑排序。 如果我们可以对所有节点进行排序，那么该排序就是有效的堆叠顺序。 如果不是，约束就会相互矛盾，并且不存在解决方案。 

其工作原理取决于可见性的定义方式。 在每个位置，可见字符仅由最高的带有字母的卡片决定。 如果错误的字符出现在正确的字符之上，它将永久覆盖该列，因此必须通过订购来禁止此类配置。 我们的约束精确地编码了这些禁止的反转，并且任何满足它们的排序都独立地保证了每个位置的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import defaultdict, deque

n, m = map(int, input().split())
s = input().strip()

# store: for each position, list of (card_id, char)
pos_cards = [[] for _ in range(m)]

cards = []
for idx in range(n):
    parts = input().split()
    k = int(parts[0])
    card = {}
    j = 1
    for _ in range(k):
        a = int(parts[j]) - 1
        c = parts[j + 1]
        j += 2
        card[a] = c
        pos_cards[a].append((idx, c))
    cards.append(card)

graph = [[] for _ in range(n)]
indeg = [0] * n

# build constraints
for i in range(m):
    if not pos_cards[i]:
        continue

    good = []
    bad = []

    for idx, c in pos_cards[i]:
        if c == s[i]:
            good.append(idx)
        else:
            bad.append(idx)

    if not good:
        print(-1)
        sys.exit()

    # every good card must be above every bad card
    for u in good:
        for v in bad:
            graph[u].append(v)
            indeg[v] += 1

# topological sort
q = deque(i for i in range(n) if indeg[i] == 0)
order = []

while q:
    u = q.popleft()
    order.append(u)
    for v in graph[u]:
        indeg[v] -= 1
        if indeg[v] == 0:
            q.append(v)

if len(order) != n:
    print(-1)
else:
    print(*[x + 1 for x in order])
```该解决方案逐个位置构建约束。 每张卡都存储其稀疏表示，但关键结构是`pos_cards`，这使我们能够快速找到影响某一列的所有卡片。 

对于每一列，我们将卡片分为匹配组和不匹配组。 如果没有匹配的卡，则答案是不可能的，因为最上面的选择不能产生 s[i]。 否则，我们强制所有匹配的卡片必须出现在所有不匹配的卡片之上。 

在最坏的情况下，对于单列，该图可能会很密集，但总边缘受到总输入出现次数的限制，因为每个（卡，位置）对贡献一次。 

最后，我们计算拓扑排序。 如果失败，则存在循环，这意味着各个职位之间存在矛盾的约束。

 2, 1, 0。 

这显示了单张卡如何被强制到达顶部，因为它唯一地满足多个位置。 

### 示例 2

 输入：```
2 2
aa
2 1 a 2 b
2 1 b 2 a
```在位置 1，卡 0 有 a，卡 1 有 b。 由于 s[0] = a，卡 0 是好的，卡 1 是坏的，所以我们添加边 0→1。 

在位置2处，s[1] = a，所以卡1是好的，卡0是坏的，所以我们添加边1→0。 

我们得到一个循环：0→1 和 1→0。 拓扑排序失败，我们输出-1。 

这抓住了矛盾：每张卡都阻止另一张卡在不同的列中位于顶部。

 ## 边缘情况

 一种边缘情况是某个位置没有包含任何字母的卡片。 例如，如果 s[i] 是“a”，但没有卡在位置 i 写入任何内容，则任何排序都无法生成目标字符串。 该算法会立即检测到这一点，因为“好”集为空并返回 -1。 

另一种边缘情况是当多张卡在某个位置匹配 s[i] 时。 在这种情况下，它们中的任何一个都可能是最顶层的提供者，并且该算法不会强制进行单一选择。 相反，它仅强制所有不匹配的卡牌必须低于所有匹配的卡牌，这保留了灵活性并避免过度约束解决方案。 

最后的边缘情况是不同位置之间的矛盾约束，如 2 周期。 每个位置独立地强制执行一个方向，但组合位置可能会产生循环。 拓扑排序会在全局范围内检测到这一点，即使局部约束看起来一致，也能确保正确性。
