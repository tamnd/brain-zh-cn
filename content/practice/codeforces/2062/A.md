 ## 问题理解

 我们给定一个由字符组成的二进制字符串`0`和`1`。 目标是将字符串中的每个字符转换为`0`。 我们可以执行以下操作：选择字符串的子序列，使得子序列中没有两个连续字符相同，然后翻转该子序列中的每个字符（`0`变成`1`和`1`变成`0`）。 每个操作可以同时翻转多个字符，但前提是所选子序列中的相邻元素交替。 

输入由多个测试用例组成。 每个测试用例都是一个长度最多为 50 的字符串。测试用例的数量最多可达 10,000 个。 由于每个字符串都很短，最多 50 个字符，因此我们可以考虑至少运行在$O(n^2)$每个测试用例不超过时间限制。 但是，我们应该避免不必要的嵌套循环，因为测试用例的数量很大。 

不明显的边缘情况包括已经全为零的字符串、全为 1 的字符串以及仅出现在交替位置的字符串。 粗心的方法可能会试图翻转每个`1`单独或贪婪地翻转每个最大交替段而不考虑重叠，这可能会产生超出必要数量的操作。 例如，对于`10101`, 每个单张的天真翻转`1`将产生五个操作，但我们可以通过仔细选择交替子序列在三个操作中完成相同的操作。 

## 方法

 暴力方法将尝试字符串的每个可能的有效子序列，翻转它，并递归地求解剩余的字符串。 这是正确的，但速度非常慢。 即使是为了$n = 50$，子序列的数量呈指数增长，使得这种方法不可行。 

关键的观察是每个操作都会翻转具有交替字符的子序列。 因此，最小操作数由相同字符的连续块的数量决定，因为连续的块`1`s 至少需要与其长度一样多的翻转，或者可以与相邻位置的翻转相结合以减少总计数。 更具体地说，每个`1`可能会与相邻的一起翻转`0`s 处于交替模式，但最小操作数对应于计算其中的位置数`1`s 连续出现，或者 的运行次数`1`s。 

将这个问题简化为简单的计数任务的见解是，操作数等于所有操作的总和，但考虑到交替翻转会进一步减少这一点。 事实上，最少的操作次数等于连续相同字符的段数。`1`。 每次运行`1`可以在一个精心选择的交替翻转序列中删除，并且可以在同一操作中同时处理不相邻的。

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个字符串，初始化一个计数器`ops`为零。 
3. 从左到右遍历字符串。 
4. 每当`1`遇到时，增加`ops`计数器，并继续向右移动，直到本次运行结束`1`已达到 s。 
5. 跳过`0`直到下一个`1`找到并重复上一步。 
6. 遍历完整个字符串后，`ops`代表所需的最少操作数。 
7. 输出每个测试用例的结果。 

为什么它有效：每次连续运行`1`s 必须至少翻转一次。 通过翻转从以下位置开始的最大交替子序列`1`并包含尽可能多的字符，我们删除所有`1`s在运行中，无需不必要的额外操作。 任何将不同运行之间的翻转组合起来的尝试都无法减少操作数量，因为翻转无法连接非相邻的运行`1`s 不违反交替子序列规则。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_operations(s: str) -> int:
    ops = 0
    i = 0
    n = len(s)
    while i < n:
        if s[i] == '1':
            ops += 1
            while i < n and s[i] == '1':
                i += 1
        else:
            i += 1
    return ops

t = int(input())
for _ in range(t):
    s = input().strip()
    print(min_operations(s))
```功能`min_operations`迭代字符串，计算每个连续的运行`1`作为单个操作。 内部循环确保我们跳过当前运行以避免重复计数。 使用`input().strip()`避免尾随换行符引起的错误。 该解决方案工作效率很高，因为每个字符都只处理一次。

 ## 边缘情况

 对于完全由零组成的字符串，例如`00000`，算法正确地识别出没有运行`1`和回报`0`运营。 对于完全由 1 组成的字符串，例如`11111`，该算法识别单个连续运行并返回`1`操作，这是最小的。 交替图案如`10101`正确地数出每一个`1`在其自身运行中，提供最少的操作次数。 该算法不会重复计数，因为内部循环会跳过连续的计数，从而防止出现差一错误。
