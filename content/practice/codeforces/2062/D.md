 ## 解决方案
 ## 问题理解

 我们得到一棵有根树，其中每个节点都有一个允许值范围`[l_i, r_i]`。 最初，每个节点可以被分配其范围内的任何值。 目标是使树平衡，这意味着所有节点具有相同的最终值。 唯一允许的操作是选择根`u`和一个子树根`v`并增加子树中的所有值`v`一个。 我们被要求确定树可以等于的最小可能最终值，而不用担心操作的数量。 

输入提供多个测试用例。 每个测试用例最多可以有 200,000 个节点，但总和`n`所有测试用例的上限为 200,000。 每个节点的初始值可以大到10^9。 这意味着我们无法显式模拟操作 - 任何 O(n^2) 或逐个操作的方法都是不可行的。 每个测试用例的解决方案必须以大约 O(n) 或 O(n log n) 的速度运行。 

一个微妙的点来自于操作定义。 节点的价值只会增加。 因此，任何算法都必须处理节点的值范围的可能性`[l_i, r_i]`可能需要增加以匹配子树的值。 粗心的实现可能只是尝试独立地分配每个范围内的最小可能值而不向上传播，从而导致错误的答案。 例如，具有两个具有范围的节点的树`[0,0]`和`[1,1]`对于第一个节点必须增加到 1 - 只需选择以下边界`[0,0]`会失败的。 

边缘情况包括单节点树，节点其中`l_i == r_i`，以及所有节点都具有不重叠范围的树 - 在这些情况下，必须仔细计算增量的传播。 

## 方法

 暴力方法会尝试为每个节点分配初始值`[l_i, r_i]`范围，然后模拟操作，直到所有节点都相等。 这在理论上是正确的，但完全不可行：模拟每个操作可能需要每个增量 O(n) 个步骤，导致最坏情况下的复杂度为 O(n^2) 或更多。 

实现有效解决方案的关键观察是认识到操作总是会增加子树值。 因此，可以使用动态规划方法沿着树找到最优解。 在每个节点，我们跟踪平衡子树所需的最少操作以及该子树最终值的可能范围。 对于叶节点，范围很简单`[l_i, r_i]`。 对于内部节点，在调整操作后，最终值必须至少是其子级范围的最大下限。 这允许后序遍历在单个 DFS 中计算树的最小最终值。 

最终值是子级所需“提升”的总和，这一观察结果导致每个测试用例的解决方案为 O(n)。 暴力方法会失败，因为它无法有效地传播增量，而DP方法则利用树结构来最佳地组合子树。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 树上的 DP (DFS) | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 解析输入并构建树的邻接表。 初始化元组列表`[(l_i, r_i)]`代表每个节点的范围。 
2. 定义一个 DFS 函数，对于给定节点和父节点，计算两个值：`min_val`- 该子树的最小最终值，以及`needed_ops`- 确保所有子节点都能达到节点的最终值所需的总操作。 
3. 对于叶子节点，返回`(l_i, 0)`因为不需要超出节点自身范围的额外增量。 
4.对于内部节点，递归计算`min_val`和`needed_ops`对于每个孩子。 
5. 访问完所有子节点后，计算将子节点提升到节点级别所需的总操作数。 如果子节点的最大可实现值低于节点的下限，则按差值增加操作。 
6. 设置节点的最终值`min_val`作为其下限和最高限的最大值`min_val`需要从孩子们那里得到。 积累`needed_ops`从所有子节点中，添加匹配当前节点所需的任何调整。 
7. 返回`(min_val, needed_ops)`为根。 第一个元素是树的最小最终值。 

**为什么有效：** 每个节点计算其子树平衡所需的最小值，同时尊重其范围。 从叶子向上传播可确保我们永远不会低估所需的增量。 由于操作总是可以增加子树值，因此选择子树中的最大下界可以保证可行性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        lr = [tuple(map(int, input().split())) for _ in range(n)]
        adj = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            adj[u-1].append(v-1)
            adj[v-1].append(u-1)
        
        def dfs(u, parent):
            total_ops = 0
            lower, upper = lr[u]
            for v in adj[u]:
                if v == parent:
                    continue
                child_ops, child_val = dfs(v, u)
                total_ops += child_ops
                # if child_val < lower, we need to increment it to reach lower
                if child_val < lower:
                    total_ops += lower - child_val
                    child_val = lower
                upper = max(upper, child_val)
            return total_ops, upper
        
        result, _ = dfs(0, -1)
        print(result)

if __name__ == "__main__":
    solve()
```DFS 返回两个值：平衡子树所需的总操作和最小最终值。 在每个节点，我们确保子节点的值至少达到当前节点的下限，累积操作。 递归有效地向上传播这些约束。
