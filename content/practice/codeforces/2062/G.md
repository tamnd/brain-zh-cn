 ## 解决方案
 ## 问题理解

 我们有两种长度排列$n$,$p$和$q$，我们的目标是转变$p$进入$q$使用一系列交换操作。 每个操作交换两个元素$p$并且成本等于位置之间的距离和值之间的距离的最小值。 我们必须最小化总成本并产生一系列交换来实现这一目标。 

输入约束告诉我们$n$最多可以为 100，并且$n^3$所有测试用例不超过$10^6$。 这意味着我们可以负担得起一个大致为$O(n^3)$每个测试用例，但任何更糟糕的情况都会超出时间限制。 测试用例数量$t$可以达到$10^4$，因此我们必须小心地保持每个测试用例的操作适度。 

一种幼稚的方法可能会在元素不合适时尝试贪婪地交换元素，而不考虑成本优化。 对于小周期，这会失败。 例如，如果$p=[1,3,2]$和$q=[2,1,3]$，粗心的从左到右交换可能会首先将 3 移动到正确的位置，从而增加总成本，而最佳序列会直接交换 1 和 2。 

当最小交换距离来自位置而不是值时，会出现另一种不明显的边缘情况。 例如，$p=[2,1,4,3]$和$q=[4,2,3,1]$说明最佳交换可能并不总是相邻位置，并且成本函数$\min(|i-j|, |p_i-p_j|)$是指导互换选择的关键。 交换“值相距较远但位置接近”的元素可能会比相反情况产生更小的成本。 

## 方法

 蛮力方法将尝试在每一步考虑所有可能的交换，并选择成本最小的交换，更新$p$直到匹配为止$q$。 这在原则上是正确的，因为任何交换序列最终都可以排序$p$匹配$q$，但在计算上是不可行的。 和$O(n^2)$每一步的潜在交换和$O(n)$步骤，总操作爆炸超出了可接受的限度$n=100$。 

关键的见解是将问题视为解决映射排列中的循环$p$到$q$。 任何排列都可以分解为不相交的循环。 在每个周期内，元素必须旋转才能到达目标位置。 在一个循环内交换两个元素可以将问题减少到一个更小的循环，如果我们总是选择涉及循环中最小和最大索引的交换，我们可以最小化$\min(|i-j|, |p_i-p_j|)$因为价值观或立场的巨大差异使成本最大化，而较小的差异则使成本最小化。 

这将问题转化为沿周期的结构化交换序列。 按位置对每个周期进行排序可确保每次交换都很便宜，并有效地将排列移向目标。 因为$n\le 100$，迭代循环并按顺序执行交换在计算上是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^4) | O(n^4) | O(n) | 太慢了 |
 | 基于周期的最优 | O(n^3) | O(n^3) | O(n) | 已接受 |

 ## 算法演练

 1. 根据中的值构建映射$q$到他们的目标指数。 这使我们能够快速知道每个元素在哪里$p$应该去。 
2. 将所有元素标记为未访问。 我们将迭代$p$并找到通过将当前位置映射到目标位置定义的排列中的循环。 
3. 对于每个未访问的元素，按照映射构建其循环。 该循环包含闭环中涉及的必须旋转的所有索引。 
4. 在长度大于 1 的每个循环内，对索引进行排序。 这确保了在周期中相距较远但在价值或位置上尽可能接近的指数之间执行交换，从而最大限度地减少$\min(|i-j|,|p_i-p_j|)$成本。 
5. 一个周期$[i_1,i_2,...,i_k]$，按顺序在第一个元素和其余每个元素之间执行交换。 每次交换后，第一个元素都会更接近其最终位置，循环逐渐解决。 记录每个交换以产生输出序列。 
6. 重复此操作，直至处理完所有循环。 在最后，$p$比赛$q$。 

为什么有效：每个周期都是不相交的，因此解决一个周期不会干扰另一个周期。 将循环的第一个元素与其他元素交换可确保每个元素达到其目标，而无需重新访问位置。 对指数进行排序可以保证每个周期内的掉期成本最小化。 不变的是，处理完一个循环后，它的所有元素都处于正确的位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        q = list(map(int, input().split()))
        pos = [0]*(n+1)
        for idx, val in enumerate(q):
            pos[val] = idx
        visited = [False]*n
        ops = []
        for i in range(n):
            if visited[i] or p[i] == q[i]:
                continue
            cycle = []
            x = i
            while not visited[x]:
                visited[x] = True
                cycle.append(x)
                x = pos[p[x]]
            if len(cycle) <= 1:
                continue
            cycle.sort()
            for j in range(len(cycle)-1, 0, -1):
                ops.append((cycle[0]+1, cycle[j]+1))
                p[cycle[0]], p[cycle[j]] = p[cycle[j]], p[cycle[0]]
        print(len(ops))
        for a,b in ops:
            print(a,b)

if __name__ == "__main__":
    solve()
```第一部分将目标值映射到位置以促进周期检测。 主循环迭代$p$，识别错位元素的循环。 在执行交换之前对周期索引进行排序可以根据$\min(|i-j|,|p_i-p_j|)$功能。 交换循环有效地旋转循环，确保正确性。 对输出使用从 1 开始的索引至关重要，因为问题需要这样做。
