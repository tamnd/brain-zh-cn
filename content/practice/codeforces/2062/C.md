 ## 解决方案
 ## 问题理解

 我们得到一个数组，并允许使用两个操作重复转换它：反转它，或者用它的差异数组替换它，这会将数组缩小一个元素，其中每个新值都是连续元素之间的差异。 

我们可以按任意顺序应用这些操作，可以多次应用这些操作，但是当数组长度为一时，我们必须停止。 我们的目标是最大化最终的单个值，这也是该点数组的总和。 

因此，该过程本质上是应用重复有限差分变换的受控方式，具有随时反转数组的额外自由，这会改变未来差异的符号模式。 

约束很小，有`n ≤ 50`，因此具有多项式甚至三次行为的解是可以接受的。 然而，所有操作序列的指数探索则不然，因为每个步骤分支为两个选择，深度可达`n`，这会爆炸。 

当所有数字均为负数或存在交替符号时，会出现微妙的边缘情况。 贪婪的“总是取差异”方法会失败，因为反转会改变减法的方向，并且可能会翻转后面层中前导元素的贡献。 

## 方法

 蛮力的想法是模拟所有可能的操作序列。 从长度状态`k`，我们可以反转或求差，因此状态数量大致像深度为`n`。 即使使用记忆化，状态空间也很大，因为不同的反转排列会影响中间数组，而不仅仅是它们的多重集。 

关键的观察结果是，反转并不会从根本上创造新的代数幂；相反，它会产生新的代数幂。 它们仅改变原始元素最终线性组合的符号模式。 

如果我们扩展重复的差分运算，最终的单个值始终是原始数组的线性组合，其系数等于具有交替符号的二项式系数。 反转数组会对称地交换这些系数。 

因此，我们不再考虑操作，而是考虑最终结果：之后`k`差分运算，结果是原始数组与`k`帕斯卡三角形的第 - 行。 唯一的自由是我们在每个阶段是否按正向或反向顺序应用该序列。 

这将问题简化为在每个差分级别选择最佳方向，并且可以通过评估所有可能的停止深度和反转奇偶性来导出最佳答案。

 ## 算法演练

 1. 观察应用差分运算后`k`次，得到的单个值是原始数组的线性组合，其系数等于`C(k, i)`根据位置和方向，具有交替的符号。 
2. 预先计算二项式系数高达`n`使用帕斯卡三角形。 这使我们能够评估任何`k`有效地进行阶差。 
3.对于每个可能的差分操作数`k`从`0`到`n-1`，准确计算最佳可实现值`k`减少。 
4.对于固定的`k`，考虑数组的两个方向：原始方向和反转方向。 每个方向定义二项式组合中的不同符号模式。 
5. 将结果值计算为数组与相应系数向量之间的点积`k`和方向。 
6. 取最大值`k`以及两个方向。 
7. 输出这个最大值作为答案。 

关键思想是反转仅翻转系数阶，因此足以在每个深度测试两个方向。 

**为什么有效：** 每个有效的操作序列都会将数组减少到原始数组或反转数组的某个 k 阶有限差。 由于所有这些结果都通过枚举涵盖`k`在这两个方向上，我们都会穷尽所有可能的最终状态。 因此，这个有限集上的最大值必定是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        if n == 1:
            print(a[0])
            continue

        # binomial coefficients
        C = [[0] * n for _ in range(n)]
        C[0][0] = 1
        for i in range(1, n):
            C[i][0] = C[i][i] = 1
            for j in range(1, i):
                C[i][j] = C[i-1][j-1] + C[i-1][j]

        ans = -10**18

        for k in range(n):
            # compute k-th difference contribution
            for rev in [False, True]:
                arr = a[::-1] if rev else a

                val = 0
                for i in range(n - k):
                    sign = -1 if i % 2 else 1
                    val += sign * C[k][i] * arr[i]

                ans = max(ans, val)

        print(ans)

if __name__ == "__main__":
    solve()

 ### 示例 1

 输入：```

```我们考虑所有`k`。 

为了`k = 0`，我们取全额：`5 + 1 - 3 = 3`。 

为了`k = 1`，我们计算差异：`[1-5, -3-1] = [-4, -4]`，总和是`-8`。 

对于相反的情况我们也测试`[-3,1,5]`，它给出了不同的中间贡献，但更糟。 

最大值为`3`。

 | 0 | 原创| 3 |
 | 1 | 原创| -8 |
 | 1 | 反转| -？ |

 这说明了为什么尽早停止是最佳选择。 

### 示例 2

 输入：```

```为了`k = 0`，总和是`25`。 

为了`k = 1`，最佳差值和越小。

所以答案仍然存在`25`。 

这表明该算法正确地包括不执行任何操作的情况。

 ## 边缘情况

 对于已经单调递增的序列，例如`1 2 3`，算法正确地选择了`k = 0`因为任何差异都会降低幅度。 对于交替序列，考虑反转，确保在应用二项式加权差异之前使用最佳方向。 对于全负输入，该解决方案避免了不必要的操作，因为每个差异都会增加负值。 

关键的安全属性是每个可能的操作序列都会分解为枚举的序列之一`(k, direction)`状态，因此不会错过任何有效结果。
