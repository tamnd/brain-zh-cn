 ## 解决方案
 ## 问题理解

 我们有一棵树`n`以节点为根的节点`1`，每个节点都有一个关联的整数权重。 琪露诺和大妖精在这棵树上进行连续游戏。 在轮到她时，玩家选择一个权重严格大于对手选择的最后一个节点的节点，并删除以该节点为根的整个子树。 琪露诺首先开始，目标是找到她在第一步中可以选择的所有节点，这样，如果两个玩家都发挥最佳，她最终会赢得比赛。 如果没有必胜棋，我们必须输出`0`。 

输入由多个测试用例组成，每个测试用例定义一棵带有权重的树。 约束条件很强：`n`可以达到`4 * 10^5`所有测试用例的总计。 这排除了任何简单地模拟所有可能的游戏序列的解决方案，因为即使来自每个节点的单个 DFS 也很容易超过`10^8`操作，对于 6 秒的限制来说太慢了。 权重本身介于`1`和`n`，这使我们能够推理相对顺序而不是绝对大小。 

非明显的边缘情况包括所有权重相等、根具有最大权重或第一个玩家没有有效动作的树（所有节点的权重都小于所需的权重）。 例如，如果所有权重都沿着单一路径增加，选择根可能会立即允许第二个玩家选择下一个最大的节点，从而翻转胜利。 忽略树路径上权重排序相互作用的简单方法将会失败。 

## 方法

 暴力方法将尝试从每个节点开始模拟每个可能的游戏序列。 对于每个初始节点，您将删除其子树并递归地探索第二个玩家的所有选择。 这在原则上是正确的，但不可行，因为序列的数量随着节点的数量呈指数增长。 和`n`最多`10^5`，这种方法可能涉及多个`2^n`状态，这在计算上是不可能的。 

关键的见解来自于将树视为博弈图并将其视为经典公正博弈的变体。 我们可以根据每个节点的子树和权重的相对顺序为每个节点分配一个“获胜值”，而不是模拟移动。 具体来说，我们注意到游戏结果主要取决于**树中严格增加路径的高度**。 如果我们按权重对节点进行排序并执行 DFS，我们可以使用以下规则将获胜/失败状态从叶向上传播到根：如果节点允许对手移动到失败节点，则该节点获胜。 这将问题简化为每个测试用例一个 DFS，再加上对按权重排序的节点进行拓扑扫描，这在约束下是可行的。 

最佳方法是结合使用 DFS 捕获树结构和对节点排序进行动态编程以有效计算获胜位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 解析输入并构建树的邻接表表示。 
2. 将所有节点按权重升序排序。 这确保了在考虑节点时，所有较小权重的节点都已被分析。 
3.初始化一个数组`win[i]`跟踪子树是否以节点为根`i`如果轮到对手，则为获胜位置。 最初，所有叶子都失去位置。 
4. 按权重升序遍历节点。 对于每个节点，检查其在树中的邻居（按 DFS 顺序的子节点）。 如果存在权重较小的邻居导致失败，则将当前节点标记为获胜。 这实现了最佳游戏规则：如果玩家能够迫使对手进入失败的子树，那么他们就可以获胜。 
5. 处理完所有节点后，第一个玩家获胜位置的任何节点都是 Cirno 第一步的候选节点。 收集这些节点。 
6. 对获胜节点进行排序并输出，或者`0`如果不存在获胜节点。 

工作原理：不变性在于，通过按权重顺序处理节点并从叶子向上传播赢/输状态，每个节点准确地反映在该节点移动的玩家是否可以在最佳游戏中强制获胜。 根据树上公平博弈的特性，任何能够迫使对手陷入失败状态的节点本身就是胜利的。 这保证了第一步选择的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import defaultdict, deque

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        w = list(map(int, input().split()))
        adj = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            adj[u-1].append(v-1)
            adj[v-1].append(u-1)
        
        # Track parent and children using BFS
        parent = [-1]*n
        order = []
        dq = deque([0])
        while dq:
            node = dq.popleft()
            order.append(node)
            for nei in adj[node]:
                if nei != parent[node]:
                    parent[nei] = node
                    dq.append(nei)

        # Nodes sorted by weight
        nodes_by_weight = sorted(range(n), key=lambda x: w[x])
        win = [False]*n

        # Traverse from smallest weight to largest
        for u in nodes_by_weight:
            for v in adj[u]:
                if parent[u] == v:
                    continue
                if w[v] < w[u] and not win[v]:
                    win[u] = True
                    break

        result = [i+1 for i in range(n) if win[i]]
        if result:
            print(len(result), *sorted(result))
        else:
            print(0)

if __name__ == "__main__":
    solve()
```BFS 确保我们能够一致地定义父子关系。 按权重对节点进行排序可以保证当我们检查一个节点时，所有较低权重的邻居都已被处理，从而允许正确的动态编程传播。 使用一个简单的`win`array 避免了递归堆栈限制并保持算法高效。
