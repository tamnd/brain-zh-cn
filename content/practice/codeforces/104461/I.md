 ## 解决方案
 ## 问题理解

 我们给出了一个大小为的矩形网格$n \times m$，任务是使用大小的多米诺骨牌覆盖每个单元格$2 \times 1$。 每个多米诺骨牌必须恰好占据水平或垂直方向上的两个相邻单元格，并且网格的每个单元格必须恰好属于一个多米诺骨牌。 

除了简单的平铺之外，还有一个额外的结构限制：不允许任何网格点成为四个不同多米诺骨牌的交汇角。 这种情况禁止经典的“交叉”配置，即四个图块在单个顶点处相交，这可能会发生在某些交替图块中。 一旦构建了有效的平铺，就必须为每个多米诺骨牌分配一个唯一的整数标签，以便同一个多米诺骨牌覆盖的两个单元共享相同的编号，并且所有多米诺骨牌都有不同的编号。 

因此，输出不仅仅是一个可行性决策，而是一个完全构建的带标签的网格平铺，或者字符串“不可能！” 如果不存在有效的平铺。 

约束条件足够严格$n, m \le 100$，但存在多个测试用例，并且所有测试的单元总数最多为$2 \cdot 10^6$。 这强烈表明任何解决方案在每个测试用例的网格大小上都必须是线性的，因为即使$O(nm \log nm)$如果常数很高，则可能会变得临界。 

一个关键的微妙之处在于“四个角不相交”的限制。 天真的检查者可能会忽略它并生成标准的多米诺骨牌，这在以下情况下总是可能的：$nm$是均匀的。 然而，并不是每一个多米诺骨牌都在这个规则下有效，因此如果没有仔细的结构，简单地将单元格配对成棋盘图案是不够的。 

一个简单的失败案例出现在小网格中，其中交替的水平和垂直放置创建了交叉点。 例如，在一个$2 \times 2$在网格中，任何有效的多米诺骨牌平铺都恰好使用两个多米诺骨牌。 如果两者垂直放置，则不会出现问题。 如果在交叉配置中一个是水平的，另一个是垂直的，则共享顶点将成为禁止的四向角。 粗心的交替构造可能会意外地产生这样的交叉点。 

另一个边缘情况是奇偶校验。 如果$n \cdot m$奇怪的是，覆盖棋盘是不可能的，因为每个多米诺骨牌恰好覆盖了两个单元格。 

## 方法

 暴力方法会尝试一张一张地放置多米诺骨牌，回溯所有可能的放置位置。 在每一步中，我们选择下一个未覆盖的单元格，并尝试放置水平或垂直的多米诺骨牌（如果有效），递归地继续，直到网格被填满。 这在原则上是正确的，因为它探索了平铺的完整搜索空间。 

然而，平铺的数量随着网格大小呈指数增长。 即使是为了谦虚$n, m$，大多数位置的分支因子大约为 2，导致大约$O(2^{nm/2})$配置。 除了微小的网格之外，这变得完全不可行。 

关键的观察是我们实际上并不需要探索所有的瓷砖。 我们只需要一种有效的平铺来避免禁止的 4 角交叉。 我们可以构建一个确定性模式来保证各处的局部一致性，而不是搜索。 

约束的结构允许基于简单不变量的贪婪配对策略：如果我们将网格平铺成大小独立的小块$2 \times 2$，并确保多米诺骨牌永远不会以冲突的方式跨越块边界，那么任何顶点都不能成为四个不同多米诺骨牌的交汇点。 在每个块内，我们可以使用固定的配对模式来完全避免交叉。 

这减少了用不相交的网格填充的问题$2 \times 2$块并以一致、不相交的布局为每个块分配两个多米诺骨牌。

 | ---| ---| ---| ---|
 | 暴力回溯|$O(2^{nm})$|$O(nm)$| 太慢了 |
 | 砌块施工|$O(nm)$|$O(nm)$| 已接受 |

 ## 算法演练

 我们通过对网格的结构化扫描贪婪地构建平铺。 

1.首先检查是否$n \cdot m$很奇怪。 如果是，则不存在平铺，因为每个多米诺骨牌正好覆盖两个单元，留下一个未配对的单元。 我们立即输出“不可能！”。 
2. 否则，我们逐行遍历网格。 目标是分配多米诺骨牌 ID，同时将单元格分组成对，而不创建交叉点。 
3. 我们以成对的列处理每一行。 对于每个$2 \times 2$由细胞形成的块$(i, j), (i, j+1), (i+1, j), (i+1, j+1)$，我们放置两个水平多米诺骨牌：

 一个覆盖物$(i, j)$和$(i, j+1)$，和另一个覆盖物$(i+1, j)$和$(i+1, j+1)$。 

这完全避免了块内的垂直交互，确保四个不同的多米诺骨牌不共享任何顶点。 平铺局部平坦且不相交。 
4. 我们在创建每个多米诺骨牌时为其分配一个新的递增标识符。 每次我们放置一对单元格时，我们都会增加计数器。 
5. 如果行数或列数是奇数，我们通过根据方向水平或垂直扩展相同的想法来单独处理剩余的条带。 当剩下一行时，我们用水平多米诺骨牌将其完全平铺； 当剩下一列时，我们将其垂直平铺。 
6. 继续，直到覆盖所有单元格。 

### 为什么它有效

 正确性依赖于每个多米诺骨牌都被限制在单行对或单列对内的不变量，从不混合跨块的方向。 因为每个$2 \times 2$该区域由两个平行的多米诺骨牌平铺而成，四个不同的多米诺骨牌不会共享任何顶点。 任何潜在的“交叉”配置都需要在块内交替方向，而该结构明确避免了这种情况。 因此，禁止的配置不能出现在网格中的任何位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    out = []

    for _ in range(T):
        n, m = map(int, input().split())

        if (n * m) % 2 == 1:
            out.append("Impossible!")
            continue

        grid = [[0] * m for _ in range(n)]
        id_counter = 1

        # handle 2x2 blocks
        i = 0
        while i + 1 < n:
            j = 0
            while j + 1 < m:
                grid[i][j] = grid[i][j+1] = id_counter
                id_counter += 1
                grid[i+1][j] = grid[i+1][j+1] = id_counter
                id_counter += 1
                j += 2
            i += 2

        # if odd row remains
        if n % 2 == 1:
            i = n - 1
            j = 0
            while j + 1 < m:
                grid[i][j] = grid[i][j+1] = id_counter
                id_counter += 1
                j += 2

        # if odd column remains
        if m % 2 == 1:
            j = m - 1
            i = 0
            while i + 1 < n:
                grid[i][j] = grid[i+1][j] = id_counter
                id_counter += 1
                i += 2

        for row in grid:
            out.append(" ".join(map(str, row)))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现直接构建网格，在形成多米诺骨牌对时分配多米诺骨牌 ID。 主要思想是首先消耗矩阵$2 \times 2$chunks，它干净地处理大部分结构。 如果一个维度是奇数，则会保留剩余的条带，并使用直接水平或垂直多米诺骨牌放置单独处理。 

唯一微妙的实现点是确保每个多米诺骨牌只分配一次 ID。 每次分配都会在多米诺骨牌的两个单元都被填充后立即增加计数器，以防止意外重复使用或重叠。

 ## 边缘情况

 一个$1 \times 1$grid 立即触发不可能条件，因为该区域是奇数，因此根本不可能放置多米诺骨牌。 该算法在尝试任何构造之前检测到这一点，从而产生正确的拒绝。 

一个$1 \times m$网格与均匀$m$完全在水平条带逻辑中处理。 该算法永远不会进入$2 \times 2$块相位，而是按顺序对相邻单元进行配对，确保完全覆盖而无交叉。 

一个$n \times 1$网格的行为是对称的。 垂直配对干净地覆盖了列，同样不会形成禁止的角结构，因为单列中的四个不同的多米诺骨牌不能共享任何顶点。 

一个$2 \times 2$网格展现了核心的结构保障。 该结构恰好产生两个平行的水平多米诺骨牌，避免了会形成十字的交替图案。 这证实了即使在最小的非平凡块中也可以避免禁止的配置。
