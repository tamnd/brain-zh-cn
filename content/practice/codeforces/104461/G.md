 ## 解决方案
 ## 问题理解

 我们得到了几堆独立的石头。 玩家从爱丽丝开始轮流轮流，每轮主动玩家选择一堆石子并从中移走正数的石子。 当玩家无法做出任何合法动作时，游戏结束。 

关键的问题是爱丽丝在玩耍时没有完全的自由。 对于每一堆，一个约束决定了她可以进行的清除量。 如果一堆被标记为约束为零，则爱丽丝的行为就像鲍勃一样，可以移除任意正数的石子。 如果约束为一，她只能从该堆中取出奇数块石头。 如果是两颗，她只能取出偶数正数的石头。 鲍勃从来没有任何限制，并且总是可以从任何堆中移除任意正数的石子。 

目标是在最佳发挥下确定获胜者。 

约束很大，每个测试用例最多 10^5 个桩，总输入大小最多 10^6。 这排除了每堆游戏玩法或状态探索的任何模拟。 任何有效的解决方案都必须将每个桩减少到恒定时间评估，然后在每个测试用例的线性时间内聚合结果。 

一种简单的方法是尝试模拟游戏状态或计算每个桩位置的完整格伦迪数。 这会立即失败，因为每堆最多有 10^9 颗石头，并且转换取决于奇偶校验约束的移动，这将需要每堆 O(a_i) 状态。 另一个微妙的陷阱是假设这是标准 Nim。 这是因为只有 Alice 有限制； 鲍勃总是可以完全灵活地做出反应，这完全改变了结构。 

第二个常见的错误想法是使用标准的公正博弈论独立地处理桩。 这也会失败，因为游戏在玩家之间不对称，因此经典的 Nim 堆等效性并不直接适用。 

## 方法

 蛮力观点会尝试将每一堆石子建模为一种游戏状态，其中的位置由剩余的石子以及轮到谁来定义。 从每个状态，我们根据玩家枚举所有合法的移除，并递归地确定获胜或失败状态。 这在原则上是正确的，但是每个堆有 O(a_i) 个状态，每个状态有 O(a_i) 个转换，因此总复杂度远远超出了可行的极限。 

关键的简化来自于注意到鲍勃主导了游戏动态。 由于鲍勃总是可以移除任意数量的石头，因此他可以立即删除爱丽丝试图建造的任何结构，除非爱丽丝可以在鲍勃做出响应之前完全解决一堆石头。 这迫使每一堆的结果仅取决于爱丽丝是否可以在鲍勃中和它之前强制采取决定性的移动模式，而这反过来又将所有大值折叠为奇偶行为。 

一旦我们认识到在最佳响应播放下只有奇偶校验转换很重要，每个桩就会根据其约束类型和 a_i 的奇偶校验变成一个恒定大小的状态机。 然后，堆之间的交互简化为这些简化状态上的简单的类似异或的聚合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每堆完整的游戏树 | O(Σa_i) | O(最大 a_i) | 太慢了 |
 | 每堆奇偶减少| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每一堆，并将其简化为一个二进制贡献，表示它是否是全局游戏中当前玩家的“获胜压力”。

1. 对于每一堆，我们查看约束类型 b_i 和 a_i 的奇偶校验。 超出奇偶校验的 a_i 的确切大小不会影响最终的减少结果，因为任何长的删除序列都会立即被 Bob 不受限制的响应能力折叠。 
2. 如果 b_i = 0，Alice 没有限制，因此两个玩家在这一堆上的行为是对称的。 该堆的行为类似于标准的单堆，其中只有奇偶校验对简化的游戏状态很重要，因此我们分配等于 a_i mod 2 的贡献。 
3. 如果 b_i = 1，Alice 只能删除奇数。 这意味着她的动作总是会翻转牌堆大小的奇偶性。 鲍勃总是可以通过选择任意删除来消除结构优势。 唯一稳定的属性是堆以奇数还是偶数配置开始，因此如果 a_i 为奇数，我们将堆编码为 1，否则为 0。 
4. 如果 b_i = 2，Alice 只能删除偶数，因此她的动作保持奇偶性。 鲍勃再次可以自由地破坏任何结构，唯一有意义的区别是堆是否以偶数或奇数状态开始，但实际上是相反的。 当 a_i 为偶数时，这会产生 1 的贡献，否则为 0。 
5. 我们对所有桩贡献进行异或。 如果结果非零，则爱丽丝有获胜策略； 否则鲍勃获胜。 

异或聚合的出现是因为在减少之后，每个堆的行为就像一个独立的二进制游戏组件，在最佳游戏下，并且当所有组件抵消时，全局位置正在丢失。 

### 为什么它有效

 不变的是，每一堆，无论大小，都完全由最佳游戏下的单个二元状态表征，因为任何多步结构都可能被鲍勃的不受限制的移动所破坏。 Alice 的约束只会影响她是否可以切换奇偶校验或保留奇偶校验，而 Bob 总是可以在轮到他时重置更深层次的结构。 这将每一堆折叠成一位贡献，并且对这些贡献的异或完全捕获第一个玩家是否强制移动到获胜状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        x = 0
        for ai, bi in zip(a, b):
            if bi == 0:
                x ^= (ai & 1)
            elif bi == 1:
                x ^= (ai & 1)
            else:
                x ^= (1 if ai % 2 == 0 else 0)

        out.append("Alice" if x else "Bob")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该代码独立处理每个测试用例并累加单个 XOR 累加器。 每堆仅贡献一位源自其约束和奇偶校验的比特。 最终的决定取决于该累加值是否为零。 

该实现将所有内容保留在整数算术中，并避免任何每桩模拟，考虑到输入大小，这一点至关重要。

 ## 边缘情况

 当一堆石子数量非常多但仅约束 b=1 或 b=2 时，算法完全忽略大小并仅读取奇偶校验。 例如，像 a_i = 10^9 和 b_i = 1 这样的堆的贡献恰好为 1，因为它是奇数。 计算保持恒定时间并且不会随着值大小而降低。 

当所有贡献异或为零时，算法正确地宣布鲍勃为获胜者，即使每一堆单独看起来“不平凡”，因为取消反映了爱丽丝在组合的减少的游戏状态中没有强制先走优势。
