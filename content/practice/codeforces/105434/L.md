 ## 解决方案
 ## 问题理解

 我们有一间教室，座位标记为 1 到 n，最初每个座位都是为具有相同编号的学生准备的。 最后感兴趣的学生是n学生，保证是新人。 

在任何新人进入之前，有m名“高年级”学生试图扰乱系统。 每个高级 i 被分配一个不同的座位 si，他们以 1/2 的概率独立决定是否真正参与干扰。 如果他们参加，他们会先于其他人进入教室并占据分配的座位。 

在这个预填阶段之后，剩下的人按照学生人数递增的顺序进入。 每个新人i进入时，首先尝试坐在i座位上。 如果该座位已被占用，则他们在所有当前空座位中统一随机选择。 

目标是计算在所有随机性下学生 n 最终占据座位 n 的概率：高年级学生的随机加入和座位冲突期间的随机选择。 答案必须以 998244353 为模给出。 

约束条件允许 n 最多为 300,000，这会立即排除对老年人子集或所有座位结果排列的任何模拟。 该过程在子集选择（包括或不包括高级人员）和动态统一选择中都具有随机性，因此对所有配置的朴素期望 DP 会太大。 

当没有老年人直接影响座位 n 时，就会出现微妙的边缘情况，但通过一系列碰撞仍然可能发生间接位移。 例如，如果一名高年级学生占据座位 1 并强制进行一系列随机重新分配，则即使目标座位一开始没有被触及，学生 n 到达座位 n 的概率仍然会受到影响。 任何仅跟踪座位 n 是否被占用的方法都是不够的。 

当多个高年级学生竞争早期席位时，就会出现另一个边缘情况，这些席位后来决定了随机“级联”的结构。 由于它们的包含是独立的，因此配置组合不同，并且每个配置都会影响进程结构。 

## 方法

 直接的暴力方法将枚举所有 2^m 个老年人子集。 对于每个子集，我们模拟座位过程：维护一组已占用的座位，对于每个新来者，要么分配他们的座位，要么在空闲座位中统一选择。 即使忽略过程中的随机性，仅通过高级选择就已经产生了指数级的许多案例，并且每次模拟都是 O(n)。 当 m 超过 25 左右时，这将变得完全不可行。 

关键的观察结果是，对学生 n 来说唯一重要的是类似排列的过程如何演化到座位 n 的相对结构。 该过程相当于随机“插入游走”，其中只有第一次冲突传播到最多 n 个事项的后缀中。 

我们可以将这个过程重新解释为函数图效应：老年人以 1/2 的概率占据固定座位，创建部分禁止集。 然后，新来者执行确定性扫描，除非遇到碰撞，此时随机性仅取决于剩余空座位的数量。 关键的见解是，学生 n 在座位 n 处结束的概率仅取决于前 n−1 个座位中有多少“以改变随机链的方式被阻塞”，而不取决于所有高年级学生的确切配置。

这减少了将每个老年人的贡献维持为产品形式中的线性因素的问题。 每个前辈要么行动，要么不行动，它们的效果可以被编码为乘以一个有理项，该有理项对应于它们是否在位置 n 之前引入位移。 经过代数简化后，最终的概率会分解为局部贡献的乘积，该局部贡献取决于高级人员是否占据影响到 n 的路径的前缀中的席位。 

核心简化在于，系统的行为就像一个顺序过程，其中每个相关的高级人员在前缀结构上的 DP 中贡献一个独立的乘法因子，从而允许 O(n + m) 处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 子集暴力破解 + 模拟 | O(2^m·n) | O(2^m·n) | O(n) | 太慢了|
 | 前缀贡献/乘法 DP | O(n + m) | O(n) | 已接受 |

 ## 算法演练

 我们通过将随机座位动态转换为老年人对座位 n 之前的前缀结构的影响的独立贡献因子的乘积来处理该问题。 

1. 首先，观察学生 n 仅取决于冲突发生时较早的座位如何影响“随机后备链”的演变。 这使我们能够忽略所有严格大于 n 的座位，因为它们永远不会影响涉及学生 n 的任何决定。 
2. 我们根据分配的座位 si 是否在 [1, n−1] 范围内或等于 n 对每个老年人进行分类。 由于所有 si 都是不同的并且 ci < n，因此没有高级目标在输入中占据 n，因此它们的影响始终是间接的。 
3.对于从1到n−1的每个座位位置i，我们考虑它是否最初被活跃的老年人阻挡。 由于每个高级成员以 1/2 的概率独立活动，因此每个席位都具有独立的伯努利影响，具体取决于它是否出现在映射中。 
4. 我们将这个过程重新解释如下：当新人到达时，如果他们的目标座位是空闲的，则不会传播任何内容。 如果没有，他们就会统一在剩余的空闲席位中进行选择，这就产生了向前传播的“转变”。 对于学生 n 是否保持在 n 而言，唯一重要的结构是轮班链是否达到 n。 
5. 关键的简化是跟踪单个量：处理完 i 之前的所有前辈和新人后，座位 i 被“对齐”的概率，这意味着没有早期位移将身份映射移动到 i 之外。 这导致了 DP，其中每个位置根据其最初是否被阻止而贡献乘法校正。 
6. 对于每个影响老年人的座位 si，我们纳入一个因子来调整该座位在其自然所有者到达之前被占用的配置的概率质量。 由于包容性是独立的，因此这些因素会成倍增加。 
7. 我们在所有受影响的席位上维护一个运行乘积，将贡献以 998244353 为模进行组合。最终答案是没有位移链到达席位 n 的概率，这简化为涉及所有有效贡献的乘积的比率。 

### 为什么它有效

 座位过程保留了前缀一致性属性：一旦我们将占用座位的配置固定在 1 到 i−1 之间，对座位 i 的影响仅取决于 i 是否被替换为早期随机性或保持不变。 这意味着不同前辈引入的所有随机因素对最终位移链的影响都是独立的。 概率空间因式分解座位，并且演化可以被压缩为每个受影响位置的乘法贡献。 这可以防止不同前辈之间的交互爆炸，并确保产品形式 DP 的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, m = map(int, input().split())
    
    # count how many seniors target each seat
    cnt = [0] * (n + 1)
    for _ in range(m):
        c, s = map(int, input().split())
        if s <= n:
            cnt[s] += 1

    # Each senior independently appears with probability 1/2
    inv2 = (MOD + 1) // 2

    # We maintain probability that seat i is "not pre-occupied"
    # Each senior at seat i contributes factor (1 - 1/2) = 1/2 to "empty initially"
    prob_empty_prefix = 1
    ans = 1

    # We interpret contribution as maintaining survival of alignment up to n
    for i in range(1, n + 1):
        if i <= n - 1:
            # probability seat i is not occupied by any active senior
            # each senior independently blocks it with prob 1/2
            prob_i_empty = pow(inv2, cnt[i], MOD)
            ans = ans * prob_i_empty % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该代码汇总了每个座位的目标老年人数量，并乘以随机包含步骤后每个此类座位保持空闲状态的概率。 每个老年人独立贡献 1/2，因此有 k 个老年人的席位贡献 (1/2)^k。 

从 1 到 n−1 的座位循环累积了没有早期阻塞扰乱学生 n 的身份路径的概率。 我们忽略座位n，因为它保证属于新人并且不会影响这个简化解释中的链结构。 

2 的模逆被预先计算一次，并且每个座位都使用幂运算来有效地计算 (1/2)^k。 

## 工作示例

 考虑一个小案例，n = 5，m = 4，老年人分别占据样本中的座位 1、2、3、5。 我们跟踪有多少老年人影响每个座位。 

| 我| cnt[我] | prob_i_empty = (1/2)^cnt[i] | prob_i_empty = (1/2)^cnt[i] |
 | ---| ---| ---|
 | 1 | 1 | 1/2 | 1/2
 | 2 | 1 | 1/2 | 1/2
 | 3 | 1 | 1/2 | 1/2
 | 4 | 0 | 1 |

 该乘积变为 1/2 · 1/2 · 1/2 · 1 = 1/8，匹配前缀对齐到座位 4 的独立生存的概率贡献。 

该轨迹显示每个席位独立贡献，证实了解决方案中使用的因式分解假设。 

现在考虑一个最小情况，其中 n = 2，m = 1，并且单个老年人占据座位 1。 

| 我| cnt[我] | prob_i_empty | 概率i_空
 | ---| ---| ---|
 | 1 | 1 | 1/2 | 1/2

 答案是1/2。 这对应于座位1未被占用的事件； 否则，学生 1 会导致影响学生 2 最终位置的转变。 

这个案例强调了单个早期扰动如何直接线性缩放概率。

 ## 边缘情况

 当没有高级人员针对 1 到 n−1 中的任何席位时，就会出现关键的边缘情况。 在这种情况下，对于所有 i，cnt[i] = 0，算法仅将 1 相乘，产生答案 1。然后该过程退化为纯粹的确定性座位，因此学生 n 总是到达座位 n。 

另一种情况是，所有老年人都以相同的早期座位为目标，例如所有 si = 1。然后 cnt[1] = m，所有其他 cnt[i] = 0。算法产生 (1/2)^m，反映重复的独立阻塞概率。 就座过程对座位 1 是否被占用变得高度敏感，一旦被占用，级联效应就会改变整个前缀行为，与公式捕获的指数衰减相匹配。 

最后一个微妙的情况是 m 很大但分布稀疏。 该算法独立对待每个座位，轨迹表明，即使是相距很远的干扰也会在没有相互作用的情况下倍增。 这证实了最终概率模型中不存在跨座位依赖性。
