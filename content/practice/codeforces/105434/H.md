 ## 解决方案
 ## 问题理解

 每个测试用例给出一个整数$n$。 任务是把这个数字分成两个不同的正整数$x$和$y$使得它们的总和等于$n$。 如果这样的一对不存在，则输出必须是两个负数。 

输入大小达到$10^5$测试用例，以及每个$n$至多是$10^5$。 这已经表明任何解决方案都必须是每个测试用例的恒定时间，因为即使$O(\sqrt{n})$每次测试都会开始感觉没有必要，并且$O(n)$每次测试显然会太慢。 

一个微妙的点是，两者$x$和$y$必须是积极的和不同的。 这立即产生了最小值的边界问题$n$。 如果$n = 1$，不存在分解为两个正整数的情况。 如果$n = 2$，唯一的办法是$1 + 1$，但值没有不同，因此无效。 为了$n \ge 3$，有效的构造突然变得微不足道。 

一个天真的方法可能会尝试所有对$(x, y)$和$x + y = n$，但即使这样也太过分了，因为该结构强制任何可行的解决方案都采用单一候选形式。 唯一的危险是忘记最小值的独特性约束，这会错误地输出$1, 1$为了$n = 2$。 

## 方法

 最直接的解释是尝试构造两个数字，其总和为$n$。 蛮力方法会迭代所有可能的值$x$从$1$到$n-1$， 放$y = n - x$，并检查是否$x \ne y$。 这总是正确的，因为它详尽地检查了每个分解，但这是浪费的。 对于每个测试用例，它执行$O(n)$工作，导致$O(Tn)$在最坏的情况下，这将是大约$10^{10}$操作，是完全不可行的。 

关键的观察是我们实际上不需要搜索。 一旦我们选择$x = 1$，唯一的约束变为是否$y = n - 1$不同于$1$。 仅当以下情况时此操作才会失败$n = 2$。 对于所有较大的值，$1$和$n - 1$保证是不同的正整数，其总和正确为$n$。 整个问题分解为一个恒定时间的条件构造。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n)$每次测试 |$O(1)$| 太慢了|
 | 最佳|$O(1)$每次测试 |$O(1)$| 已接受 |

 ## 算法演练

 我们直接从有效分解的结构构建答案。 

1. 阅读$n$。 目标是将其表示为两个不同正整数的和。 
2. 检查是否$n \le 2$。 在此范围内，不存在有效对，因为最小的不同正对是$(1,2)$，这已经等于$3$。 任何较小的总和要么强制重复，要么包含零，两者都无效。 
3.如果$n \ge 3$， 放$x = 1$。 选择最小的正整数可以最大限度地减少对第二个值的约束并保证正数。 
4. 计算$y = n - 1$。 这是由总和条件强制的。 
5、输出$x$和$y$。 它们自动不同，因为$n - 1 \ne 1$为了$n \ge 3$。 

### 为什么它有效

 对于任何有效的解决方案，我们需要$x + y = n$和$x \ne y$并且都是积极的。 为了$n \ge 3$，这对$(1, n-1)$满足所有约束条件。 由于构建不依赖于任何特殊属性$n$除了至少$3$，只要存在分解，它总是会产生有效的分解。 为了$n \le 2$，对积极性和独特性的不平等约束消除了所有可能性，因此否定答案是被迫的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        if n <= 2:
            out.append("-1 -1")
        else:
            out.append(f"1 {n-1}")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```实现准确地反映了推理。 每个测试用例在恒定时间内独立处理。 唯一的条件分支检查是否存在有效的分解。 对于有效的情况，选择$1$是经过深思熟虑的，因为它自动保证独特性，避免任何额外检查的需要。 

一定要注意不要意外输出$n$和$0$，因为零不是正整数。 施工$1$和$n-1$完全避免了这种情况。

这些示例证实，相同的构造在所有有效输入上统一工作，无需任何调整。

 ## 边缘情况

 对于$n = 1$，算法直接输出$-1 -1$因为没有办法将1分成两个正整数。 任何尝试都需要零或负值，这是不允许的。 

为了$n = 2$，唯一的代数分解是$1 + 1$，但独特性要求使其无效。 该算法在尝试构建之前正确地拒绝它。 

对于所有人$n \ge 3$，构造总是产生$(1, n-1)$。 即使在边界$n = 3$，这产生$(1, 2)$，无一例外地满足正性和明确性。
