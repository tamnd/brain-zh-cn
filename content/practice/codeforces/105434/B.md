 ## 解决方案
 ## 问题理解

 我们获得了几个独立的数据源，每个数据源代表一个可能有助于混合数据集的平台。 每个平台都贡献了总数据的已知部分，每个平台也有自己被“人工智能污染”的可能性。 

更具体地说，想象一下您从一个巨大的组合池中随机选择一条数据。 首先，根据其在混合物中的重量选择平台。 然后，在该平台内，数据要么是干净的，要么是人工智能根据已知概率生成的噪声。 任务是计算随机选择的数据被污染的总体概率。 

输入提供两个对齐的概率分布。 第一个描述了每个平台被选择的可能性。 这些概率之和已经为一，因此它们形成了有效的混合分布。 第二个描述了每个平台的数据被污染的条件概率。 

输出是整个混合物污染的边际概率。 

限制很小：最多 100 个平台，因此即使是 O(n) 或 O(n log n) 解决方案也是微不足道的。 唯一的微妙之处是数值稳定性，因为答案是浮点加权和，并且所需的误差容限是相对的，而不是绝对的。 这意味着接近零的值需要小心，但标准双精度就足够了。 

一个常见的错误是将概率视为独立的并将所有值相乘，或者在不加权的情况下对条件概率进行平均。 例如，如果一个平台贡献了 99% 的数据，另一个平台贡献了 1%，那么简单地平均它们的污染率就会严重扭曲结果。 权重是必不可少的。 

第二个错误是忘记平台概率已经形成完整的分布。 添加标准化步骤或重新标准化可能会引入不必要的浮点错误。 

## 方法

 强力解释将模拟两阶段过程。 可以根据平台的概率分布对平台进行重复采样，然后采样是否被污染，并通过蒙特卡罗估计结果。 虽然在概念上是正确的，但这种方法是不必要的且不精确，即使进行大量模拟，它也只能近似得到答案。 方差还取决于概率的偏斜程度，并且不能保证满足严格的相对误差要求。 

关键的观察结果是污染概率是总概率定律的直接应用。 每个平台都独立地对最终期望做出贡献，并根据选择的频率进行加权。 我们可以通过对“选择平台 i 的概率乘以给定平台 i 的污染概率”形式的贡献进行求和，一次性计算出准确的期望，而不是进行模拟。 

这将整个问题分解为单个线性聚合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蒙特卡罗模拟| 对于大 k 个样本 | O(k) O(1) | O(1) | 太慢/不精确|
 | 加权和（最优）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 读取平台数量n。 每个平台都代表一个互斥的数据源，因此在概率模型中将恰好选择一个平台。 
2. 读取数组f，其中f[i]是随机选择的数据项源自平台i的概率。 这些值的总和已经为 1，因此它们形成了有效的混合分布。 
3. 读取数组a，其中a[i]是来自平台i的数据项被AI污染的条件概率。 
4. 初始化累加器 ans = 0。这将存储所有平台上的总污染概率。 
5. 对于从 1 到 n 的每个平台 i，将 f[i] * a[i] 添加到 ans 中。 该项表示平台 i 对总概率的贡献：首先选择平台，然后观察其中的污染。 
6. 将 ans 输出为浮点数。 

和中的乘法是关键的建模步骤。 每个平台的贡献与其被选择的频率成比例，因此在聚合之前其污染率必须根据其选择概率进行缩放。 

### 为什么它有效

 设 A 为随机选择的数据项被污染的事件，Fi 为该数据项来自平台 i 的事件。 Fi 事件形成样本空间的一个分区。 根据全概率定律，P(A) 等于 P(Fi) 中所有 i 的总和乘以 P(A | Fi)。 该算法精确地计算这种分解，没有近似或隐藏的假设。 由于所有 Fi 都是不相交且详尽的，因此不会重复计算或省略概率质量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input().strip())
    f = list(map(float, input().split()))
    a = list(map(float, input().split()))

    ans = 0.0
    for i in range(n):
        ans += f[i] * a[i]

    print(ans)

if __name__ == "__main__":
    main()
```解决方案是直接实现加权和。 唯一值得关注的细节是自始至终都使用浮点运算。 由于 n 很小，因此除了简单循环之外不需要进行优化。 

乘法在累加之前执行，这是该输入大小的数值稳定排序。 不需要标准化或缩放，因为输入已经定义了有效的概率分布。

 ## 边缘情况

 一个关键的边缘情况是当一个平台的概率为 1 而所有其他平台的概率为 0 时。在这种情况下，答案应该与该平台的污染概率完全匹配。 该算法自然地处理了这个问题，因为所有零权重项都消失了，只留下一个贡献。 

另一种情况是污染概率全部为零。 无论平台重量如何，计算都会变成零之和，按预期产生零。 

第三种情况是所有污染概率均为一。 结果折叠为 f[i] 的总和，由于输入分布已归一化，因此保证为 1。 因此，该算法无需特殊处理即可准确生成 1。 

最后，当概率极其接近零或一时，浮点舍入可能会引入微小的误差，但所需的相对误差容限允许标准双精度累加安全通过。
