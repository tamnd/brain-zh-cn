 ## 问题理解

 我们得到了一系列每日股票价格。 您最多可以选择一对日期，在较早的一天买入并在较晚的一天卖出，您赚取的利润等于价格的涨幅除以持有天数。 正式来说，如果您当天购买$x$并当天出售$y$，得分为$(a_y - a_x) / (y - x)$。 如果没有选择有利可图的交易，则分数定义为 0。 

任务是计算所有有效对中该比率的最大可能值$x < y$。 

输入大小达到$10^5$，这会立即排除任何检查所有日期对的解决方案。 对所有的二次扫描$(x, y)$对需要大约$5 \cdot 10^9$最坏情况下的评估，远远超出了3秒的限制。 甚至稍微次优$O(n \log n)$或者大量的预处理是不必要的，因为比率的结构表明可以利用更强的单调性。 

一个关键的边缘情况是价格单调递减。 例如，输入$5, 4, 3, 2, 1$不会产生正利润，因此答案必须为 0。任何未明确允许空选择的算法都会错误地从某些对中输出负比率，即使问题定义禁止这样做。 

另一个微妙的情况是，最佳利润来自短时间间隔而不是大幅跳跃。 例如，$1, 100, 2, 3$可能会引发选择极端的贪婪策略，但最佳部分取决于同时平衡分子和分母。 

## 方法

 蛮力方法枚举所有日期对$x < y$，计算值$(a_y - a_x)/(y - x)$，并跟踪最大值。 这是正确的，因为每笔有效交易都会被检查。 然而，对于每个右端点$y$，它检查所有之前的$x$，大致导致$n(n-1)/2$评价。 和$n = 10^5$，这变得不可行。 

表达式的结构暗示了几何解释。 每一天$x$可以看作一个点$(x, a_x)$，一对的值是连接两点的直线的斜率。 该问题简化为随着 x 坐标的增加找到任意两点之间的最大斜率。 

这变成了一个经典的凸包优化场景：对于每个点，我们希望维护一个结构，该结构允许我们查询给出与当前点的最大斜率的最小截距。 关键的见解是，随着时间的推移，只有先前点的子集可以成为最佳候选点，并且这些点可以保留在凸包中，其中连续点之间的斜率是单调的。 

这使我们能够维护点的较低凸包，并使用单调指针或双端队列在摊销常数时间内查询每个新日的最佳先前点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|
 | 凸包/单调包 | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们重新诠释每一天$i$作为一个点$(i, a_i)$。 两点之间的分数是连接它们的线的斜率。 我们希望所有指数对的斜率最大。 

我们维护候选点的凸包，其中每个点代表前一天，可以作为最佳购买时间。 

1. 从一个空双端队列开始存储候选索引。 双端队列将维护结构中的点，使得连续点之间的斜率是单调的。 
2. 迭代每一天$i$从左到右。 
3、插入当前点之前，查询双端队列中斜率最大的最佳前一个点$(a_i - a_j) / (i - j)$。 
4.找到最好的$j$，我们比较双端队列中的候选者。 斜率函数在船体上是单峰的，因此我们可以在下一个候选者改善斜率时前进指针。 
5. 使用当天找到的最佳坡度更新全局答案$i$。 
6.插入当前点$i$进入双端队列，同时保持凸性。 如果最后两个点和新点违反凸性，则删除中间点。 
7. 继续，直到处理完所有日期。 

插入和查询的关键思想是支配点永远不会再次成为最优，因此可以安全地删除它们。 

### 为什么它有效

 表达式$(a_y - a_x)/(y - x)$是平面上两点之间的斜率。 凸包属性保证对于任何一组点，到新点的最大斜率是在包的极值点实现的，而不是在其内部。 通过按照索引的递增顺序仅维护极端候选点，我们确保每个被删除的点在所有未来查询中都比其邻居的某些组合更差。 这保留了正确性，同时将搜索空间总体减少到线性大小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def slope(i, j, a):
    return (a[i] - a[j]) / (i - j)

def bad(a, i, j, k):
    return (a[j] - a[i]) * (k - j) >= (a[k] - a[j]) * (j - i)

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    from collections import deque
    dq = deque()

    ans = 0.0

    for i in range(n):
        while len(dq) >= 2:
            j = dq[0]
            k = dq[1]
            if slope(i, j, a) <= slope(i, k, a):
                dq.popleft()
            else:
                break

        if dq:
            ans = max(ans, slope(i, dq[0], a))

        while len(dq) >= 2 and bad(a, dq[-2], dq[-1], i):
            dq.pop()

        dq.append(i)

    print(f"{ans:.3f}")

if __name__ == "__main__":
    solve()
```该解决方案维护候选购买日的双端队列。 这`slope`函数评估候选对的每日利润。 查询步骤从双端队列的前面移动，而更前面存在更好的斜率，利用凸包上斜率的单调结构。 

这`bad`如果不需要维持凸性，函数会删除中间点。 它比较交叉相乘的斜率，以避免船体维护步骤中的浮点精度问题，即使最终答案是以浮点形式计算的。 

答案从 0.0 开始，以尊重“无交易”选项。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个索引最多进入和离开双端队列一次，并且每个索引都在摊余常数时间内处理 |
 | 空间| O(n) | 在修剪之前，双端队列最多存储最坏情况下的所有索引 |

 线性复杂度是必要的，因为$n = 10^5$，任何二次探索都会超出时间限制。 内存使用量在 512 MB 以下仍然安全，因为仅存储整数索引。

 ## 边缘情况

 对于像这样的单日输入`10`，双端队列仅包含一个点并且不存在有效交易。 该算法从不计算斜率，因此答案仍然是 0.0。 

对于严格递减的序列，例如`5 4 3 2 1`，每个计算出的斜率都是负数，但算法仍然更新双端队列并检查候选者。 由于答案从 0.0 开始，并且只有积极的改进才重要，因此不会发生任何更新。 

对于最优对相邻的情况，例如`1 100`，第一次比较直接评估斜率 99，它立即成为最佳答案。 双端队列逻辑不会延迟或跳过这种情况，因为每个新索引在插入之前都会针对当前外壳进行测试。 

对于振荡输入，在船体维护期间移除主导点，确保仅保留结构相关的候选点，并且当正确端点到达时仍评估每个潜在的最佳斜率。
