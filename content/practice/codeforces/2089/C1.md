 ## 解决方案
 ## 问题理解

 在这个问题中，我们被要求模拟一个顺序游戏，其中一组`n`参与者尝试解锁`l`锁定使用精确`l`有效的密钥。 每个参与者以固定的循环顺序一次轮流进行一次。 在每一轮中，参与者选择一把钥匙和一把锁，以最大化打开锁的概率。 一旦锁被打开或钥匙被成功使用，都不能再次使用。 我们被要求计算每个参与者成功匹配的预期次数，取模$10^9 + 7$。 

输入给出了多个测试用例。 对于每个测试用例，我们知道参与者的数量、锁的数量和假钥匙的数量。 对于这个简单版本，假钥匙的数量为零，因此每把钥匙只能打开一把锁。 

约束条件适中：最多 100 个测试用例，所有测试用例的锁总数以 5000 为界。这意味着算法的时间复杂度大致为$O(n \cdot l)$每个测试用例都是可行的，因为所有测试用例的总和将保持在$5 \cdot 10^5$运营。 边缘情况包括非常小的游戏（例如，1 个锁，1 个参与者）和高度不对称的分布，其中$n > l$或者$n < l$，这会影响谁获得轮次以及预期值的分配方式。 

随着钥匙和锁的排列数量呈阶乘增长，尝试在每个回合模拟每种可能的随机选择的简单方法将会出现组合爆炸。 粗心的实现可能会尝试在没有模运算的情况下将概率跟踪为分数，这可能会导致溢出。 另一个微妙的问题是正确处理模逆，因为期望值是有理数。 

## 方法

 暴力方法将枚举所有参与者的每一个可能的关键尝试序列。 对于每个序列，它将计算每个玩家的成功次数，并对所有序列进行平均以找到期望。 虽然原则上是正确的，但这种方法是因式分解的`l`并且完全不可行`l`小到20个，更不用说5000个了。 

有效解决方案的关键是期望的线性度。 无论尝试的顺序如何，参与者打开锁的预期数量只是参与者轮流打开该锁的概率的总和。 由于参与者的行为最佳，并且每个钥匙恰好对应一把锁，因此玩家轮流打开特定锁的概率可以表示为一个简单的分数：剩余的锁数量除以循环顺序中的剩余参与者。 这使我们能够迭代计算期望值，而无需枚举所有随机结果。 

因此，我们可以计算出期望值`O(n * l)`通过迭代每个锁并将成功概率依次分配给参与者。 使用模运算，我们在除分数时乘以模逆，以避免精度问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(l!) | O(l!) | O(l) | 太慢了|
 | 期望值模拟| O(n * l) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`ans`长度`n`带零。 这将保存每个参与者的预期成功比赛次数。 
2. 迭代从1到所有的锁`l`。 上`i`-th 锁，计算参与者索引为`(i-1) % n`。 这给出了轮流的循环顺序。 
3.添加`1/l`到所选参与者的期望值。 这里`1/l`表示如果所有锁在任何回合都有相同的可能性被解决，则每个锁的预期成功率。 使用模算术除以`l`通过乘以模逆`l`模数$10^9 + 7$。 
4.处理完所有锁后，输出`ans`测试用例的数组。 
5. 对所有测试用例重复此操作。 

为什么它有效：通过期望的线性，我们可以独立地考虑每个锁。 每个参与者的贡献是他们轮流的所有锁的预期成功的总和。 循环轮分配确保公平性，并使用模逆保留精确的理性期望模$10^9 + 7$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD-2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n, l, k = map(int, input().split())
        inv_l = modinv(l)
        ans = [0] * n
        for i in range(l):
            ans[i % n] = (ans[i % n] + inv_l) % MOD
        print(" ".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```每个部分直接对应于算法步骤。 我们预先计算模逆`l`处理模下的除法。 然后我们迭代`l`次并增加轮到参与者的期望值。 使用`(i % n)`自动循环参与者。 模运算确保最终答案在正确的范围内。

 ## 边缘情况

 对于`n=1`和`l=1`，唯一的参与者获得锁定，因此预期数量为 1。算法计算`1 * inv(1) = 1`。 

为了`n=3`和`l=2`，第一个参与者收到`1/2`对于第一个锁，第二个参与者收到`1/2`对于第二把锁。 模算术转换`1/2`进入`500000004`。 该算法正确地循环参与者并分配分数。 

所有案例均带有`l < n`或者`l > n`通过使用自动处理`(i % n)`索引。
