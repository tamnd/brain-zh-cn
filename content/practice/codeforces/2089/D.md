 ## 解决方案
 ## 问题理解

 我们给定一个长度为的二进制字符串`2n+1`。 目标是准确插入`n`条件运算符`?:`在字符之间形成有效的 C++ 样式表达式，可以选择添加括号，并确定最终表达式是否可以计算为`1`。 换句话说，我们想要决定是否可以使用条件来“路由”评估，以便顶级结果为真。 

字符串中的每个字符代表一个文字：`0`是假的，`1`是真的。 条件运算符的工作原理如下：`a?b:c`，值为`b`如果`a`是真的并且`c`如果`a`是假的。 由于运算符是右关联的，`a?b:c?d:e`被解析为`a?b:(c?d:e)`。 

约束条件告诉我们`n`可以大到`1.5 * 10^5`每个测试用例和所有测试用例的总和`n`跨测试的界限是相同的。 这排除了每个测试用例的 O(n) 更差的任何算法。 尝试所有方法放置的蛮力方法`?`括号将涉及枚举类似加泰罗尼亚数字的结构，单个案例的运算量很容易超过 10^5。 我们需要一个线性检查字符串的解决方案。 

当字符串全为零时，就会出现幼稚的边缘情况，例如，`"00000"`。 这里，没有放置`?`和`:`可以做出结果`1`，因为条件语句从来没有`1`来选择。 另一个微妙的边缘情况是当第一个字符是`0`和所有的`1`s 位于字符串的后面。 由于右结合性，第一个字符是`0`将强制评估到正确的分支，该分支必须至少包含一个`1`成功。 

## 方法

 蛮力方法是生成所有有效的括号`n` `?`跨界运营商`2n+1`操作数，评估每个表达式，并检查是否有给出`1`。 有效括号的数量对应于加泰罗尼亚数字，其增长大致如下`4^n / (n^(3/2))`。 为了`n=10^5`，这是一个天文数字，显然是不可能的。 

优化的关键观察是：条件运算符允许我们“选择”一个`1`如果它存在于字符串中。 更准确地说，表达式可以计算为`1`当且仅当存在至少一个`1`在字符串中。 如果没有`1`，任何条件序列都不能产生`1`。 如果至少有一个`1`，我们可以使用简单的线性贪心方法构造一个有效的表达式。 将第一个字符作为初始条件，然后递归地构建右关联的条件链，使得第一个字符`1`遇到的被选中。 可以插入括号来满足优先级要求，但是像这样的简单模式`(a?b:c)?d:e`确保正确性。 

这一观察结果将问题从组合爆炸简化为简单的线性扫描和受控表达构建。

 | --- | --- | --- | --- |
 | 蛮力 | O(4^n) | O(4^n) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 从左到右扫描字符串，检查是否至少包含一个`1`。 如果字符串只有`0`s，立即输出`No`。 
2. 如果至少有一个`1`，我们知道答案是`Yes`。 我们现在的目标是构造一个有效的表达式，其计算结果为`1`。 
3. 开始贪婪地构建表达式。 将前三个字符视为迷你表达式：如果第一个字符是`1`， 然后`first?second:third`评估为`second`如果第一个是`1`和`third`如果第一个是`0`。 因为我们已经拥有至少一个`1`在字符串中，像这样的链接确保顶级表达式可以选择一个`1`。 
4.继续插入`?`和`:`以右关联方式使用运算符，同时将子表达式括在括号中。 始终对待最左边的人`1`作为要选择的主要分支。 
5. 输出构造好的字符串。 

为什么它有效：不变的是到目前为止构建的部分表达式可以计算为`1`因为至少有一个`1`保留在字符串的未处理部分。 右关联性保证每个添加`?:`操作员可以“推迟”对后面的字符的选择，使我们始终能够达到`1`。 我们永远不会选择错误，因为我们总是知道`1`存在于剩余部分中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        if '1' not in s:
            print("No")
            continue
        print("Yes")
        # Build a simple right-associated expression
        expr = s[-1]
        for i in range(len(s)-2, -1, -1):
            expr = f"({s[i]}?{expr}:{s[i+1]})"
        print(expr)

if __name__ == "__main__":
    solve()
```该解决方案首先检查字符串是否有任何`1`。 如果没有，则打印`No`。 否则，它会构造一个右关联的条件链，将每个步骤括在括号中。 这确保了正确的优先级。 字符串构造是从右到左完成的，以自然地以右关联形式构建表达式。 

微妙之处：输入长度为`2n+1`， 所以`s[-1]`始终是最后一个字符。 通过反向迭代并使用可以避免差一错误`i+1`表达式中正确。 每个周围都添加了括号`?:`以防止歧义。
