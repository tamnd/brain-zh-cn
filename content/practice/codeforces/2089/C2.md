 ## 解决方案
 ## 问题理解

 我们有一个游戏，其中`n`成员们轮流尝试打开`l`使用一组锁`l + k`键。 在这些键中，正是`l`都是正品，每把锁只能打开一把锁，而其余的`k`钥匙是假的。 每个成员选择一把钥匙，并在轮流中尝试一把锁，所有成员都是理性的：考虑到之前尝试的历史，他们选择的钥匙和锁能够最大化打开锁的可能性。 一旦锁被打开，它和它的钥匙就不再被考虑。 

任务是计算每个成员在此最佳策略下成功匹配（他们打开的锁）的预期数量。 预期数字是有理数，但我们必须以模数形式报告它们$10^9 + 7$作为$p \cdot q^{-1} \mod 10^9+7$， 在哪里$\frac{p}{q}$是代表期望值的分数。 

约束允许最多 100 个测试用例，`n`最多 100 个，`l`最多 5000 个，并且`k`最多 25 个。所有的总和`l`所有测试用例不超过5000个。因为`l`可以是 5000，任何超过的算法$O(l^2)$每个测试用例的步骤可能会太慢。 的小值`k`表明它可以被视为一个微小的调整，这暗示了动态规划或组合概率方法。 边缘情况包括`k = 0`（所有钥匙都是正品），`n = 1`（只有一名成员），以及`k \ge l`（许多假钥匙）。 

对所有转弯的简单模拟都会失败，因为可能的钥匙锁历史数量是以下因素的阶乘：`l`并组合在`k`，太大了。 

## 方法

 暴力方法会模拟每一次转弯，尝试每把钥匙打开每把锁，并跟踪所有可能的成功和失败历史。 在每一步中，我们都会计算用每把钥匙打开每把锁的概率，并向前传播所有可能性。 这是正确的，但不可行，因为有$(l+k)!$密钥选择序列，并且每个锁都可以尝试多次，从而导致指数级的复杂性`l`。 

解锁有效解决方案的洞察力来自期望的对称性和线性。 每回合，会员开锁的机会就是剩余的真钥匙数量除以剩余钥匙数量。 我们不需要模拟所有序列。 通过跟踪剩余的正版密钥的数量（`l_remaining`）和剩余的总密钥（`total_remaining = l_remaining + k`），我们可以使用旋转序列模来计算每个成员在每一轮的预期成功作为分数`n`。 

这将问题简化为动态规划`l`锁和`n`成员。 具体来说，定义`dp[locks_left][turn]`作为每个成员将获得的预期成功比赛数`locks_left`下一回合剩余的锁属于成员`turn`。 递归基于在剩余密钥中随机选择一个密钥并添加`1`如果是正品的话就成功了。 这是可以管理的，因为`l`最多为 5000，`n`最多 100 个，并且`k`最多 25 个。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((l+k)!) | O((l+k)!) | O((l+k)!) | O((l+k)!) | 太慢了|
 | 带期望的动态规划 | O(l * n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读`n`,`l`， 和`k`。 
2.初始化一个数组`expected`尺寸的`n`存储每个成员的预期成功，全部从 0 开始。 
3.让`l_remaining = l`和`total_remaining = l + k`。 
4. 虽然`l_remaining > 0`，按模顺序迭代成员`n`。 
5. 对于当前成员，计算成功概率为`p = l_remaining / total_remaining`。 添加`p`到`expected[member]`。 
6. 减量`l_remaining`经过`p`（分数）和`total_remaining`1. 该模型根据期望而不是整数模拟来移除锁和钥匙。 
7. 重复此操作，直到分配完所有锁。 完成后，所有期望值都是分数，将每个转换为模$10^9 + 7$使用模逆。 
8. 打印`expected`测试用例的数组。 

为什么它有效：我们依赖于期望的线性，这使我们能够独立地处理每个锁。 只要我们总是计算当时成功的概率，谁选择哪个键的确切顺序就无关紧要，因为期望是线性增加的。 这很重要：它避免了模拟序列的组合爆炸。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

t = int(input())
for _ in range(t):
    n, l, k = map(int, input().split())
    expected = [0] * n
    l_remaining = l
    total_remaining = l + k
    member = 0
    while l_remaining > 0:
        p_num = l_remaining
        p_den = total_remaining
        expected[member] = (expected[member] + p_num * modinv(p_den)) % MOD
        l_remaining -= 1
        total_remaining -= 1
        member = (member + 1) % n
    print(" ".join(map(str, expected)))
```此代码使用模逆来计算模分数$10^9 + 7$。 这`while`循环精确迭代`l`次，每个锁一次，并在成员之间分配预期的成功。 使用期望的线性可以避免组合枚举。 通过递减可以避免差一错误`l_remaining`和`total_remaining`在概率计算中使用它们之后。

import sys, io

    MOD = 10**9 + 7
    def modinv(x):
        return pow(x, MOD - 2, MOD)
    t = int(input())
    res = []
    for _ in range(t):
        n, l, k = map(int, input().split())
        expected = [0]*n
        l_rem = l
        total = l + k
        member = 0
        while l_rem > 0:

            p_den = total

            l_rem -= 1
            total -= 1
            member = (member + 1) % n
        res.append(" ".join(map(str, expected)))
    return "\n".join(res)
