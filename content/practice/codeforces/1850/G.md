 ## 解决方案
 ## 问题理解

 我们在二维整数网格上得到一组不同的点。 对于每对有序的点，我们想象在第一个点放置一个指南针并将其指向第二个点。 仅当从第一个点到第二个点的方向是八个标准罗盘方向之一（北、南、东、西或四个对角线之一）时，罗盘才被视为有效。 

任务是计算有多少有序点对产生这样的允许方向。 

表达该条件的等效方法是对于一对点$(x_1, y_1)$和$(x_2, y_2)$，它们之间的向量必须具有相等的 x 坐标（垂直线）、相等的 y 坐标（水平线），或者满足$|x_2 - x_1| = |y_2 - y_1|$（完美对角线斜率为 1 或 -1）。 

这些限制迫使我们远离二次比较。 高达$2 \cdot 10^5$总的来说，对所有对的简单检查将需要大约$O(n^2)$操作，其顺序为$4 \cdot 10^{10}$最坏情况下的比较，远远超出了2秒的运行时间。 

主要的微妙之处在于多个点可能位于同一条水平线、垂直线或对角线上，并且沿着这些线的每一对点都有贡献。 如果方向没有正确分组，粗心的方法经常会重复计算或漏掉对。 另一个常见的陷阱是通过混合斜率来错误地处理对角线，而没有通过 gcd 或绝对相等进行标准化。 

边缘情况包括：

 所有点共享相同 x 坐标的配置。 那么每一对都是垂直有效的，答案很简单$n(n-1)$。 简单的定向检查可以工作，但速度太慢。 另一个边缘情况是对角链，例如$(0,0), (1,1), (2,2)$，其中每一对都是有效的，并且必须全部计算在内，而不仅仅是相邻的。 最后，像随机点这样的混合分布需要按线族分离贡献，而不是成对检查。 

## 方法

 暴力解决方案很简单。 对于每对有序点，计算它们之间的向量并检查它是否位于八个允许的方向之一。 这意味着检查 x 差值是否为零、y 差值是否为零或者它们的绝对值是否匹配。 这是有效的，因为它直接编码有效罗盘运动的定义。 

问题在于规模。 和$n$最多$2 \cdot 10^5$，对的数量约为$n^2$，这使得这种方法不可行。 

关键的观察结果是，有效性仅取决于三个独立的几何类：相同的 x 坐标、相同的 y 坐标和相同的斜率对角线$+1$或者$-1$。 如果我们通过这些签名对点进行分组，则每个有效对都会成为其中一个组内的一对。 我们不是检查对，而是计算组内的组合。 

对于垂直线，我们按 x 坐标分组。 如果一个团体有规模$k$，它贡献$k(k-1)$有序对。 对于水平线，我们类似地按 y 坐标分组。 对于对角线，我们使用变换后的坐标：$x - y$对于一个对角家庭和$x + y$对于另一个。 各组再次贡献$k(k-1)$。 总结所有贡献即可得出答案。 

这将问题从对枚举减少到对四个可散列键进行频率计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了 |
 | 团体计数|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取所有点并为四个不同的线签名准备频率图。 目标是将可以在有效罗盘方向上相互看到的点分组。 
2. 对于每一点$(x, y)$，四个键的增量计数器：$x$,$y$,$x - y$， 和$x + y$。 每个键对应一组有效方向。 此步骤构建沿有效罗盘轴对齐的点的等价类。 
3. 处理完所有点后，迭代每个频率图。 对于每个值$k$， 添加$k \cdot (k - 1)$到答案。 这会计算该组内的所有有序对。 
4. 将所有四张地图的贡献相加。 这包括垂直、水平和两个对角方向。 
5. 输出测试用例的最终总和。 

### 为什么它有效

 每个有效的有序对必须恰好满足四个结构条件之一：相同的 x、相同的 y、相同的 x 减 y 或相同的 x 加 y。 这些条件充分表征了所有八个罗盘方向，因为对角线分为两个斜率族，并且每个轴分为两个方向。 每个有效对恰好出现在一个对应的组内，并且组内的每个对都是有效的。 这创建了有效对的完美划分，确保计数准确，没有重叠或遗漏。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import defaultdict

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        cx = defaultdict(int)
        cy = defaultdict(int)
        cd1 = defaultdict(int)
        cd2 = defaultdict(int)

        pts = []
        for _ in range(n):
            x, y = map(int, input().split())
            cx[x] += 1
            cy[y] += 1
            cd1[x - y] += 1
            cd2[x + y] += 1

        ans = 0

        for d in (cx, cy, cd1, cd2):
            for k in d.values():
                ans += k * (k - 1)

        print(ans)

if __name__ == "__main__":
    solve()
```该代码维护四个独立的哈希映射。 每张地图对应一个几何约束类。 对角线变换$x - y$和$x + y$确保捕获所有 45 度线，没有斜率算术或浮点错误。 最后的循环直接累加有序对计数，避免除以二，因为方向很重要。 

一个微妙的点是需要有序对，所以我们使用$k(k-1)$而不是$k(k-1)/2$。 当考虑指南针在两个方向上的放置时，每对贡献两次，这与问题的定义相符。 

## 工作示例

 ### 示例 1

 要点：$(0,0), (-1,-1), (1,1)$| 步骤| CX | CY | cd1 | cd2 | 部分答案 |
 | --- | --- | --- | --- | --- | --- |
 | 插入后| 3 组 | 3 组 | 3 组 | 3 组 | 0 |
 | 计算| 所有 k=1 | 所有 k=1 | 所有 k=1 | 所有 k=1 | 0 |

 每个结构都没有重复的键，因此没有组贡献额外的对。 但是，该语句中的此示例将所有有序对视为有效，因为每对都匹配四个结构之一，但由于每个组在结构之间重叠，因此对每个结构进行计数可确保累积覆盖所有方向。 

### 示例 2

 要点：$(6,9), (10,13), (0,0)$| 步骤| CX 尺寸 | CY 尺寸 | cd1 尺寸 | cd2 尺寸 | 回答 |
 | --- | --- | --- | --- | --- | --- |
 | 插入后| {6,10,0} | {9,13,0} | { -3, -3, 0 } | {15,23,0} | 0 |
 | 计算| 全 1 | 全 1 | 全 1 | 全 1 | 0 |

 只有对角对齐的对才有贡献，并且只有当两个点共享相同的变换密钥时。 (6,9) 和 (10,13) 共用$x-y = -3$，形成一个大小为 2 的有效组，贡献 2 个有序对。

 ## 边缘情况

 垂直对齐，例如$(0,0), (0,1), (0,2), (0,3)$在 x-map 中生成大小为 4 的单个键。该算法添加$4 \cdot 3 = 12$，正确计算指南针指向北方或南方的所有有序对。 

像对角链一样$(0,0), (1,1), (2,2), (3,3)$共享相同的$x-y$键，产生另一个尺寸 4 组。 这又贡献了 12，覆盖了所有对角罗盘方向。 

混合配置如$(0,0), (1,2), (2,1)$跨不同的键进行分割，确保只有有效的几何对齐才起作用，并防止在不兼容的方向上意外配对。
