 ## 解决方案
 ## 问题理解

 我们得到了几个独立的 8 × 8 字符网格。 每个网格都包含点和小写字母，但每个网格内只存在一个有意义的结构：单个列包含一个没有间隙的垂直书写的单词。 其他所有细胞都是不相关的噪音。 

每个网格的任务是通过读取不完全是点的唯一列中的字母来提取隐藏的单词。 因为单词是从上到下连续的，所以我们只需按顺序扫描该列并收集所有字母即可。 

限制非常小：最多 1000 个测试用例，每个测试用例只有 64 个字符。 这意味着在时间限制下，即使对每个网格中的每个单元进行完全强力扫描也是微不足道的。 任何直接检查所有字符的解决方案都已经是最佳的。 

常见的失败模式是假设该单词可能出现在多列中或跨行拆分。 这会导致更复杂的解析逻辑或过早停止。 另一个微妙的问题是停在一行中找到的第一个字母而不是识别整个列，这会打破单词在网格中较晚开始的情况。 

## 方法

 一种简单的方法是尝试通过逐行扫描并按阅读顺序收集字母来检测单词。 这会失败，因为单词不是水平的； 它是垂直对齐的，因此按行串联会混合不相关的列。 

另一种错误的尝试是查找第一个非点单元格并假设单词从那里开始，然后仅在该行索引中继续向下。 这会破坏，因为该单词跨越单个固定列中的多行，而不是单个行中的多个列。 

正确的观察是结构性的。 每行最多贡献答案的一个字符，并且该字符始终位于同一列中。 因此，问题简化为找到包含任何字母的列的索引，然后从上到下读取该列。 

这是有效的，因为保证单词是连续的并且仅限于一列，因此通过扫描第一个非点条目可以唯一地识别该列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力扫描行并猜测结构 | 每次测试 O(8²) | O(1) | O(1) | 不必要但有效 |
 | 扫描列并提取 | 每次测试 O(8²) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每个测试用例。 

1. 将 8 x 8 网格作为 8 个字符串读入内存。 这保留了对任何单元的直接访问而无需重新计算。 
2. 识别包含该单词的列索引。 我们从左到右扫描所有列，并在每列中扫描所有行。 包含除点之外的任何字符的第一列是目标列。 这是有效的，因为只有一列包含字母，因此检测是明确的。 
3. 找到正确的列后，从第 0 行迭代到第 7 行，并收集该列中不是点的每个字符。 由于单词是连续的，因此该列中作为单词一部分的每个位置都按顺序贡献了一个字母。 
4. 将收集到的字符作为重构词输出。 

关键思想是我们将结构检测与提取分开：首先找到活动列，然后线性读取它。 

### 为什么它有效

 网格结构保证恰好一列包含形成连续垂直字符串的非点字符。 任何其他列仅包含点。 因此，逐列扫描将隔离唯一的候选者，而从上到下阅读则保留单词的原始顺序。 不会出现歧义，因为没有其他结构与其重叠。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    grid = [input().strip() for _ in range(8)]
    
    col = -1
    for j in range(8):
        for i in range(8):
            if grid[i][j] != '.':
                col = j
                break
        if col != -1:
            break
    
    res = []
    for i in range(8):
        if grid[i][col] != '.':
            res.append(grid[i][col])
    
    print("".join(res))
```该解决方案首先存储所有行，以便列访问成为恒定时间索引。 嵌套循环的存在只是为了识别正确的列； 一旦找到有效列，它就会立即停止。 

一个微妙的细节是，一旦检测到列，我们就必须打破两个循环。 如果实施不小心，不这样做可能会覆盖正确的列索引。 另一个重要的一点是，我们在读取列时仅附加非点字符，因为即使在正确的列中，填充点也可能出现在词段之外。

 ## 边缘情况

 一种边缘情况是单词从网格的最后一行开始。 该算法仍然有效，因为我们扫描列中的所有行，而不仅仅是直到第一个或最后一个匹配。 

另一种边缘情况是单词开始之前多行为空。 由于我们只附加非点字符，因此这些空行没有任何贡献，无需特殊处理即可保持正确性。 

第三种情况是单词是单个字符时。 该算法仍然找到正确的列并返回一个单字母字符串，因为该列中只有一个单元格是非点的。
