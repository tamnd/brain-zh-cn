 ## 解决方案
 ## 问题理解

 我们给出了三个曼哈顿距离。 一名玩家处于未知整数坐标`(x1, y1)`，另一个位于`(x2, y2)`，原点是第三个参考点。 第一个距离告诉我们第一个玩家离我们有多远`(0,0)`，第二个告诉我们第二个玩家的情况相同，第三个告诉我们两个玩家之间的距离。 任务是计算有多少个有序的整数位置对满足所有三个测量值。 交换两名球员会造成不同的情况。 

输入最多包含`100000`独立的测试用例，每个距离可以大到`10^9`。 直接枚举可能的坐标是不可能的，因为即使是一个曼哈顿圆也可以包含数十亿个整数点。 该解决方案必须在恒定时间内处理每个测试用例。 

主要的陷阱情况是由奇偶校验引起的。 坐标变换后，并非变换平面中的每个点都对应于原始平面中的整数点。 另一个常见的错误是忘记两名球员是有顺序的。 

例如，如果输入是：```
1
1 1 1
```答案是`0`。 曼哈顿距离两点`1`从原点出发也不可能在曼哈顿距离`1`以这种方式彼此区分，同时尊重变换坐标所需的奇偶性。 一种对所有变换后的方形边界点进行计数而不检查奇偶校验溢出的解决方案。 

另一个边缘情况是两个玩家都在原点：```
1
0 0 0
```答案是`1`，因为两个坐标必须是`(0,0)`。 仅基于正方形大小的公式可能会意外地计算出不存在的方向。 

第三个重要的情况是当两个测量到的距离原点的距离不同但玩家交换时。 为了：```
1
2 4 2
```答案将第一个玩家在距离2层和第二个玩家在距离4层的情况与相反的排列分开计算。 将这对视为无序会失去有效答案。 

## 方法

 强力解决方案将生成具有曼哈顿距离的每个整数点`d01`从原点开始，用曼哈顿距离生成每个点`d02`，并测试每一对。 曼哈顿半径圆上的点数`r`正比于`r`，所以最坏的情况大约是`10^9`每层点数。 将它们配对远远超出了可行的极限。 

关键的观察是，旋转坐标系后曼哈顿距离变得更加简单。 定义：```
u = x + y
v = x - y
```对于两点，曼哈顿距离变为：```
max(|u1-u2|, |v1-v2|)
```到原点的距离变为：```
max(|u|, |v|)
```所以问题就从原来平面上的菱形变成了平面上轴对齐的正方形。`(u,v)`飞机。 

一点`(u,v)`代表整数`(x,y)`仅当`u`和`v`具有相同的奇偶性。 我们不是枚举正方形边界，而是计算正方形内的对并使用包含-排除来恢复边界。 

让`G(a,b,r)`是第一个点位于半径平方内的变换点对的数量`a`，第二个在半径的平方内`b`，他们的切比雪夫距离最多为`r`。 那么恰好在两个所需层上的对的数量是：```
G(a,b,r) - G(a-1,b,r) - G(a,b-1,r) + G(a-1,b-1,r)
```最后给出准确距离的答案`c`是距离最大的数字`c`减去距离最大的数`c-1`。 

计算`G`，我们通过奇偶校验来分割变换点。 一个点可以有`(u,v)`均为偶数或均为奇数。 对于第一点和第二点奇偶校验的每次选择，两个坐标都成为独立的一维计数问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(d01 * d02) | O(1) | O(1) | 太慢了|
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将曼哈顿问题转换为切比雪夫问题：`u=x+y`和`v=x-y`。 

该转换将菱形变为正方形，这让我们可以推断出轴对齐的范围。 

1. 实现一个函数，计算两个正方形内距离最大的变换点对`r`。 

半径的平方`a`包含两个变换坐标之间的所有点`-a`和`a`。 我们首先计算这些正方形区域，因为边界很难直接处理。 

1. 按奇偶校验拆分计数。 

对于第一个点和第二个点的每个可能的奇偶性，计数有效`u`坐标和有效`v`独立协调。 这两个计数的乘积给出了该奇偶校验组合的二维对的数量。 

1. 使用一维前缀计数。 

对于一个坐标，除以二后，我们需要统计差值在一个区间内的索引对。 这可以通过计算差值最多为一个值的对的前缀计数来完成。 

1. 使用包含-排除将平方数转换为层数。 

从外部正方形中减去内部正方形，以便仅保留恰好位于所需曼哈顿距离的点。 

1. 计算精确的距离答案。 

所需的距离正好是`d12`，所以计算距离最大的数`d12`减去距离最大的数`d12-1`。 

为什么它有效：

 坐标变换保留了问题所需的距离。 每个有效的原始点恰好映射到一个具有匹配坐标奇偶性的变换点，并且每个具有相等坐标奇偶性的变换点恰好映射回一个整数点。 方形包含-排除将不在所请求的距离层上的每个点恰好删除一次。 最后的减法移除距离小于所需第三距离的所有对，仅留下具有所需距离的对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ceil_div(a, b):
    return -((-a) // b)

def sum_range(l, r):
    if l > r:
        return 0
    return (l + r) * (r - l + 1) // 2

def prefix_diff(n1, n2, s):
    # number of pairs (i, j), 0 <= i < n1, 0 <= j < n2, i-j <= s
    ans = 0

    l = 0
    r = min(n1 - 1, s)
    if l <= r:
        ans += (r - l + 1) * n2

    l = max(0, s + 1)
    r = min(n1 - 1, s + n2 - 1)
    if l <= r:
        ans += (r - l + 1) * (n2 + s) - sum_range(l, r)

    return ans

def count_difference(l1, r1, l2, r2, lo, hi):
    if l1 > r1 or l2 > r2:
        return 0
    n1 = r1 - l1 + 1
    n2 = r2 - l2 + 1
    shift = l1 - l2
    return prefix_diff(n1, n2, hi - shift) - prefix_diff(n1, n2, lo - 1 - shift)

def coordinate_count(a, b, r, p, q):
    if a < 0 or b < 0:
        return 0

    l1 = ceil_div(-a - p, 2)
    r1 = (a - p) // 2
    l2 = ceil_div(-b - q, 2)
    r2 = (b - q) // 2

    if l1 > r1 or l2 > r2:
        return 0

    diff = p - q
    lo = ceil_div(-r - diff, 2)
    hi = (r - diff) // 2

    return count_difference(l1, r1, l2, r2, lo, hi)

def square_count(a, b, r):
    if a < 0 or b < 0:
        return 0

    ans = 0
    for p in (0, 1):
        for q in (0, 1):
            c = coordinate_count(a, b, r, p, q)
            ans += c * c
    return ans

def inside_layers(a, b, r):
    return (
        square_count(a, b, r)
        - square_count(a - 1, b, r)
        - square_count(a, b - 1, r)
        + square_count(a - 1, b - 1, r)
    )

def solve_case(a, b, c):
    if c < 0:
        return 0
    return inside_layers(a, b, c) - inside_layers(a, b, c - 1)

t = int(input())
out = []
for case in range(1, t + 1):
    a, b, c = map(int, input().split())
    out.append(f"Case #{case}: {solve_case(a, b, c)}")

print("\n".join(out))
```这`ceil_div`需要 helper 是因为 Python 的整数除法向下舍入，而转换坐标范围时需要数学上限除法。 

这`prefix_diff`函数是核心的一维计数例程。 它将可能的第一个索引分为三个区域：每个第二个坐标都起作用的索引、仅部分间隔起作用的索引以及没有第二个坐标起作用的索引。`coordinate_count`通过固定奇偶校验将变换后的坐标范围转换为索引范围。 距离条件成为两个指数之差的范围。`square_count`结合了四种奇偶校验组合。 乘法本身是有效的，因为`u`和`v`变换后维度是独立的。`inside_layers`应用包含-排除来删除内部方形层。 最后，`solve_case`将“最多距离”计数更改为精确距离计数。

 ## 边缘情况

 对于：```
1
0 0 0
```两个变换后的正方形的半径都为零。 包含-排除仅留下单个变换点`(0,0)`，对应于原点`(0,0)`。 

为了：```
1
1 1 1
```变换后的正方形有几个点，但只有其中的点`u`和`v`股票平价有效。 奇偶校验分为`square_count`在计数之前丢弃无效的变换点。 

为了：```
1
2 4 2
```这两名球员属于曼哈顿的不同层。 包含-排除仅保留每个正方形的边界，而最终的距离减法仅保留切比雪夫距离恰好为二的对。 

对于距离非常远的情况，例如：```
1
1000000000 1000000000 1000000000
```该算法从不迭代坐标范围。 所有计算都是通过整数算术完成的，因此大范围仅影响中间值的大小。 Python 整数安全地处理这些值。
