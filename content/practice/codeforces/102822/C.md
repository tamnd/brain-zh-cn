 ## 解决方案
 ## 问题理解

 我们得到了对未知特里树执行多次搜索的结果。 每次搜索都从根开始，并尽可能遵循字符串的字符。 如果下一条边不存在，则搜索立即停止并返回当前节点存储的值。 原始 trie 中的每个节点都有一个唯一的值，因此返回的数字恰好标识一个节点。 

任务是在可能产生所有给定查询结果的任何字典树中重建尽可能少的节点数。 根也算作节点。 如果没有 trie 可以满足所有观察结果，我们必须报告这一点。 

输入给出了几个测试用例。 对于每个测试用例，每个查询都包含一个小写字符串以及该字符串的搜索操作返回的值。 

一个测试用例中所有字符串的总长度最多为 (10^5)，所有测试用例的总长度最多为 (5 \times 10^5)。 这排除了比较每对字符串或重复重建结构的解决方案。 该算法的总输入大小必须接近线性。 

关键的边缘情况与长字符串无关，而是与前缀和冲突值有关。 如果两个相同的查询有不同的答案，则特里树不能存在，因为遵循相同的路径必须始终以相同的节点结束。 

例如：```
2
a 1
a 2
```正确的输出是`-1`。 粗心的实现可能只保留其中一个值并错误地接受这种情况。 

另一种棘手的情况是当一个字符串是另一个字符串的前缀并且答案不一致时。```
2
a 1
aa 2
```正确的输出是`-1`。 如果该节点代表`a`有价值`1`，查询`aa`如果边只能返回另一个节点`a -> a`存在。 但随后查询`a`读完后也会停在该节点`a`，所以这两个要求不能同时满足。 

第三个重要的情况是许多不同的字符串具有相同的答案。```
3
aa 1
ab 1
ac 1
```正确的输出是`1`。 空的根节点可以存储值`1`，并且所有三个查询都会立即停止，因为第一个边都不需要存在。 

## 方法

 一种直接的方法是将每个查询的字符串插入到 trie 中，然后尝试为节点赋值。 这会构建所有前缀，即使其中许多前缀是不必要的。 在最坏的情况下，如果有（10^5）个长度为（10^5）的字符串，则可能的前缀关系的数量对于重复检查来说变得太大。 

重要的观察是，仅当需要在该节点下方分隔不同的答案时，该节点才需要存在。 如果通过前缀的每个查询都有相同的返回值，我们可以在该前缀处停止并在那里分配值。 我们不需要知道原始插入的字符串在哪里，因为查询结果只关心第一个缺失的边。 

这自然会导致递归构造。 构建所有查询字符串的普通 trie。 在每个节点，查看其子树中出现的值集。 如果该集合仅包含一个值，则整个子树可以由该单个节点替换。 如果出现多个值，则必须保留该节点，并且必须独立求解其子节点。 

蛮力方法和最佳方法的区别仅在于是否保留不必要的前缀。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(L^2)) | (O(L)) | 太慢了|
 | 最佳| (O(L)) | (O(L)) | 已接受 |

 这里（L）是测试用例中所有查询字符串的总长度。 

## 算法演练

 1. 将每个查询字符串插入到一个字典树中。 将值存储在每个字符串的终端节点处。 如果相同的字符串出现不同的值，则答案是不可能的，因为相同的搜索不能产生不同的节点。 
2. 用深度优先搜索遍历 trie。 对于每个节点，收集其子树中所有终端字符串中出现的不同值。 
3. 如果节点的子树恰好包含一个值，则返回子树大小为 1。 节点本身可以​​代表所有这些查询，因此所有后代都是不必要的。 
4. 如果一个节点包含多个值，则保留该节点并递归处理至少包含一个查询的每个子节点。 添加这些子解决方案的大小。 
5. 返回的根的大小是 trie 节点的最小可能数量。 

为什么它有效：

 考虑代表前缀的任何节点。 该节点下面的每个查询最终都必须返回该子树中的一个节点。 如果所有这些查询都需要相同的值，则将它们合并到当前节点始终有效并保存节点。 如果需要不同的值，它们不能共享当前节点，因为每个 trie 节点只有一个值，因此子节点必须将不同的情况分开。 递归过程在每个前缀处精确地进行这两个选择，因此每个不必要的节点都被删除，并且每个必需的区别都被保留。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class Node:
    __slots__ = ("children", "value")
    def __init__(self):
        self.children = {}
        self.value = None

def solve_case(data):
    root = Node()

    for s, v in data:
        cur = root
        for c in s:
            if c not in cur.children:
                cur.children[c] = Node()
            cur = cur.children[c]
        if cur.value is not None and cur.value != v:
            return -1
        cur.value = v

    def dfs(node):
        vals = set()
        if node.value is not None:
            vals.add(node.value)

        child_info = []
        for child in node.children.values():
            ok, size, child_vals = dfs(child)
            if not ok:
                return False, 0, set()
            child_info.append((size, child_vals))
            vals.update(child_vals)

        if len(vals) == 1:
            return True, 1, vals

        size = 1
        for child_size, _ in child_info:
            size += child_size

        return True, size, vals

    ok, ans, _ = dfs(root)
    return ans if ok else -1

def main():
    t = int(input())
    out = []

    for case in range(1, t + 1):
        n = int(input())
        queries = []
        for _ in range(n):
            s, v = input().split()
            queries.append((s, int(v)))

        out.append(f"Case #{case}: {solve_case(queries)}")

    print("\n".join(out))

if __name__ == "__main__":
    main()
```插入阶段创建了我们唯一需要的结构。 它不会尝试模拟被遗忘的插入操作，因为许多不同的插入字符串集可能会导致相同的查询结果。 

DFS是该解决方案的核心。 返回的集合包含仍需要在当前前缀下方表示的所有值。 当设置的大小变为 1 时，整个子树会折叠到当前节点。 

插入期间的冲突检查尽早处理最简单的不可能的情况。 如果没有它，具有不同答案的相同字符串可能会被错误地合并。 

递归不会两次探索前缀，因此总工作量与创建的 trie 节点的数量成正比。

 ## 边缘情况

 当相同的字符串具有不同的值时，算法会在插入时检测到矛盾。 终端节点无法存储两个不同的值，因此立即返回`-1`。 

为了：```
2
a 1
a 2
```插入到达同一个终端节点两次。 第一个查询存储值`1`，第二个查询尝试存储值`2`。 由于一个 trie 节点不能同时具有两个值，因此这种情况是不可能的。 

当短字符串和较长字符串需要不同的答案时，DFS 会保留足够的节点来分隔它们。 

为了：```
2
a 1
aa 2
```根包含两个值，因此它必须保留子项`a`。 该节点仍然包含两个值，因此它必须保留子节点`aa`。 结果大小是`3`，代表根，`a`， 和`aa`。 

当许多字符串共享相同的答案时，DFS 会删除所有不必要的后代。 

为了：```
3
aa 1
ab 1
ac 1
```根只看到价值`1`在它下面，所以它成为答案节点并且所有子节点都消失。 最小节点数正好是`1`。
