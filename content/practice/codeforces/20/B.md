 ## 解决方案
 ## 问题理解

 我们被要求求解以下形式的二次方程$Ax^2 + Bx + C = 0$， 在哪里$A$,$B$， 和$C$是范围内的整数$[-10^5, 10^5]$。 目标是找到方程的所有实根，对它们进行计数，并以高精度按升序打印它们。 如果方程有无穷多个解，我们应该输出$-1$。 如果没有解决方案，我们打印$0$。 

输入系数可以包括零，这会带来微妙之处。 例如，如果$A = 0$，方程简化为线性（$Bx + C = 0$），如果两者都$A = 0$和$B = 0$，方程要么无解（如果$C \neq 0$）或无穷多个解（如果$C = 0$）。 

约束足够小，我们不需要担心简单算术之外的算法效率。 计算平方根并执行条件检查完全在允许的时间内。 挑战完全在于正确处理所有情况并保持数值精度。 

非明显的边缘情况包括以下场景。 如果$A = 0$和$B = 0$，那么解完全取决于$C$。 例如，$0x^2 + 0x + 5 = 0$没有根，而$0x^2 + 0x + 0 = 0$有无限多个根。 当判别式为零时，会出现另一个微妙之处，即恰好产生一个根，并且该根不得在输出中重复。 负判别式不产生实根。 正确处理浮点精度对于确保打印的根在小数点后至少有五位数字也是必要的。 

## 方法

 一个天真的方法是尝试所有可能的值$x$在一个范围内，检查是否满足$Ax^2 + Bx + C = 0$达到一定的精度。 这种强力方法是不必要的，因为只要我们正确处理退化情况，二次公式就可以为任何二次方程提供精确的解析解。 枚举$x$在很大的间隔内需要无限数量的操作，并且永远无法以高精度可靠地识别根。 

最佳方法依赖于标准代数。 为了$A \neq 0$，我们计算判别式$D = B^2 - 4AC$。 如果$D > 0$，有两个不同的根由下式给出$(-B - \sqrt{D}) / (2A)$和$(-B + \sqrt{D}) / (2A)$。 如果$D = 0$, 有一个根$-B / (2A)$。 如果$D < 0$，没有真正的根。 对于线性情况（$A = 0$和$B \neq 0$), 恰好有一个根$-C / B$。 如果两者都$A$和$B$为零，则解要么为零根，要么有无穷多个根，具体取决于是否$C$为零。 

关键的见解是分别处理线性和二次情况，并使用二次方程的判别式。 仔细排序条件可确保我们不会尝试除以零或取负数的平方根。 一旦找到根，对它们进行排序可以保证升序。

 ## 算法演练

 1. 读取整数$A$,$B$， 和$C$。 这些系数定义了方程$Ax^2 + Bx + C = 0$。 
2. 检查是否$A = 0$。 如果是，则该方程不是二次方程而是线性方程。 
3.如果$A = 0$和$B = 0$， 查看$C$。 如果$C = 0$， 打印$-1$为无限多个解决方案。 否则，打印$0$没有解决方案。 
4. 如果$A = 0$但$B \neq 0$，计算单根$-C / B$， 打印$1$，然后是小数点后至少五位数字的根。 
5. 如果$A \neq 0$，计算判别式$D = B^2 - 4AC$。 
6. 如果$D < 0$，没有实根，所以打印$0$。 
7. 如果$D = 0$，计算单根$-B / (2A)$并打印$1$其次是根。 
8.如果$D > 0$，计算两个根$(-B - \sqrt{D}) / (2A)$和$(-B + \sqrt{D}) / (2A)$。 打印$2$接下来是按升序排列的根。 

为什么有效：每种情况都是相互排斥且详尽的。 线性情况单独处理以避免被零除。 带有判别分析的二次公式保证了根的正确计数和计算，并且对两个根进行排序确保了升序。 不存在丢失的边缘情况，因为考虑了零/非零系数的每种组合。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

A, B, C = map(int, input().split())

if A == 0:
    if B == 0:
        if C == 0:
            print(-1)
        else:
            print(0)
    else:
        x = -C / B
        print(1)
        print(f"{x:.10f}")
else:
    D = B * B - 4 * A * C
    if D < 0:
        print(0)
    elif D == 0:
        x = -B / (2 * A)
        print(1)
        print(f"{x:.10f}")
    else:
        sqrt_D = math.sqrt(D)
        x1 = (-B - sqrt_D) / (2 * A)
        x2 = (-B + sqrt_D) / (2 * A)
        x1, x2 = sorted([x1, x2])
        print(2)
        print(f"{x1:.10f}")
        print(f"{x2:.10f}")
```该代码将线性和二次情况分开以避免零除并正确处理无限根。 我们使用`math.sqrt`仅适用于正判别式，并在存在两个时对根进行排序以确保升序。 打印用`.10f`为问题的要求提供足够的精度。
