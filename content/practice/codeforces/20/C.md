 ## 解决方案
 ## 问题理解

 我们得到一个无向加权图。 每条边都连接两个顶点并具有正成本。 任务是从顶点开始`1`，到达顶点`n`，并打印一条最短路径。 如果不存在路线，我们打印`-1`。 

该图足够大，我们无法探索所有可能的路径。 高达`10^5`顶点和`10^5`边缘，任何接近的算法`O(n^2)`在 Python 中已经存在风险，任何指数级的事情都是不可能的。 该图是稀疏的，因为边的数量与顶点的数量相同，这强烈建议使用邻接列表而不是邻接矩阵。 

边权重均为正。 这个细节完全改变了问题。 正权重允许 Dijkstra 算法发挥作用，因为一旦我们最终确定了到节点的最短距离，未来的路径就无法改进它。 

该问题还要求实际路径，而不仅仅是最小距离。 这意味着我们必须记住在放松过程中我们是如何到达每个顶点的。 

一些边缘情况很容易被错误处理。 

图表可能会断开连接。 

输入：```
3 1
1 2 5
```没有路径从`1`到`3`，所以正确的输出是：```
-1
```粗心的实现可能仍会尝试重建路径并崩溃，因为节点不存在父节点`3`。 

该图可以在同一对顶点之间包含多条边。 

输入：```
3 3
1 2 10
1 2 1
2 3 2
```最短路径是：```
1 2 3
```与总成本`3`。 如果我们覆盖边缘或假设唯一性，我们可能会意外地保留较重的边缘。 

该图可能包含自环。 

输入：```
2 2
1 1 5
1 2 3
```节点上的循环`1`应该简单地被松弛过程自然地忽略。 如果不正确处理过时状态，有缺陷的实现可能会意外地永远放松同一个节点。 

最短路径可能涉及非常长的距离。 边权重可达`10^6`，并且路径可能包含许多边，因此总距离可能超过 32 位整数范围。 Python 整数会自动处理这个问题，但在像 C++ 这样的语言中，我们需要`long long`。 

## 方法

 蛮力的想法是枚举所有可能的路径`1`到`n`，计算其成本，并保持最小值。 这是合乎逻辑的，因为每条有效路线都会被检查，因此不会错过最佳路线。 

问题在于图中简单路径的数量可能呈指数增长。 即使是中等连接的图也可能包含数百万或数十亿条路径。 和`10^5`顶点，暴力破解是完全行不通的。 

稍微好一点的简单方法是反复使用 BFS 式松弛，类似于 Bellman-Ford。 即使权重为负，贝尔曼-福特法也能正常工作，因为它会不断地改善距离，直到不存在更短的路径为止。 其复杂度为`O(n * m)`。 这里大致变成`10^10`最坏的情况下操作，远远超出了时限。 

关键的观察结果是每个边权重都是正的。 正权重赋予最短路径单调结构：一旦我们提取当前最小的暂定距离，未来的路径就无法改进它。 这个属性正是 Dijkstra 算法所依赖的。 

Dijkstra 保持与每个节点的最佳已知距离，并且始终首先扩展最近的未处理节点。 使用优先级队列可以保持提取效率。 由于图是稀疏的，邻接表加上堆会带来复杂性`O((n + m) log n)`，很容易满足约束条件。 

我们还存储了一个`parent`大批。 每当我们改进到节点的最短距离时，我们都会记录哪个先前的节点产生了该改进。 Dijkstra 完成后，我们通过从`n`到`1`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力路径枚举| 指数| O(n) | 太慢了 |
 | 贝尔曼-福特 | O(纳米) | O(n) | 太慢了 |
 | Dijkstra 与堆 | O((n + m) log n) | O((n + m) log n) | O(n + m) | 已接受 |

 ## 算法演练

 1. 为图构建邻接表。 

由于图是无向的，所以每条边`(u, v, w)`必须在两个方向上添加。 
2. 创建一个初始化为无穷大的距离数组。`dist[x]`存储当前已知的距节点的最短距离`1`到节点`x`。 最初仅`dist[1] = 0`。 
3. 创建一个父数组，初始化为`-1`。`parent[x]`记住最短路径上的前一个节点`x`。 这允许稍后重建路径。 
4. 推`(0, 1)`进入最小堆。 

堆总是为我们提供具有最小暂定距离的节点。 
5. 反复从堆中弹出最小的状态。 

假设我们弹出`(d, u)`。 如果`d`不等于`dist[u]`，此状态已过时，应跳过。 

堆中可以存在同一节点的多个副本，因为稍后可能会发现更短的路由。 
6.放松每一个离开的边缘`u`。 

对于每个邻居`(v, w)`，检查是否：```
dist[u] + w < dist[v]
```如果属实，我们找到了一条更短的路线`v`。 
7. 更新距离和父数组。 

放：```
dist[v] = dist[u] + w
parent[v] = u
```然后将更新后的状态推入堆中。 
8.堆变空后，检查`dist[n]`。 

如果仍然无穷大，则节点`n`无法访问，我们打印`-1`。 
9. 重建路径。 

从节点开始`n`并反复移动到`parent[cur]`直到达到`1`。 打印前反转收集的顺序。 

### 为什么它有效

 Dijkstra 算法依赖于所有边权重均为正的事实。 当堆中提取一个节点时`u`具有最小的暂定距离，其他所有未处理的路径都必须至少具有同样的成本。 任何替代路线到达`u`后面就需要经过另一个距离不小于的节点，然后加上正边权重，所以无法提高`dist[u]`。 

由于该属性，一旦使用当前最佳距离处理节点，该值就是最终值。 

父数组始终记录产生最佳已知距离的边。 由于距离只会向真正的最短值改进，因此最终的父链会重建有效的最短路径。 

## Python 解决方案```python
import sys
import heapq

input = sys.stdin.readline

INF = 10**30

n, m = map(int, input().split())

graph = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v, w = map(int, input().split())
    graph[u].append((v, w))
    graph[v].append((u, w))

dist = [INF] * (n + 1)
parent = [-1] * (n + 1)

dist[1] = 0

pq = [(0, 1)]

while pq:
    d, u = heapq.heappop(pq)

    if d != dist[u]:
        continue

    for v, w in graph[u]:
        nd = d + w

        if nd < dist[v]:
            dist[v] = nd
            parent[v] = u
            heapq.heappush(pq, (nd, v))

if dist[n] == INF:
    print(-1)
else:
    path = []

    cur = n

    while cur != -1:
        path.append(cur)
        cur = parent[cur]

    path.reverse()

    print(*path)
```邻接列表使内存使用量与边数成线性关系。 高达`10^5`边，这比矩阵更有效，矩阵需要`10^10`细胞。 

堆存储对`(distance, node)`。 蟒蛇的`heapq`实现了最小堆，因此总是首先处理最小距离。 

陈旧状态检查：```
if d != dist[u]:
    continue
```是必不可少的。 假设节点`u`之前被推了距离`10`，后来我们找到了一条有距离的更好的路径`5`。 两种状态都保留在堆内。 当过时的`(10, u)`最终出现的时候，我们必须忽略它。 如果没有这种检查，算法仍然保持正确，但会执行不必​​要的松弛，并且可能会变得太慢。 

当发现更短的路径时，父更新就会发生。 这保证了重建的链对应于最终的最短距离。 

路径重建从`n`朝向`1`。 由于父母指向相反的顺序，我们在打印之前反转收集的数组。 

使用像这样的大整数`10**30`无穷远是安全的，因为最大可能的最短距离远小于该距离。

 ## 边缘情况

 考虑断开连接的图：```
3 1
1 2 5
```算法从节点开始`1`, 放松节点`2`，然后堆变空。 节点`3`永远不会达到，所以：```
dist[3] = INF
```最终检查检测到这一点并打印：```
-1
```没有尝试重建路径，因此不存在无效的父访问。 

现在考虑多条边：```
3 3
1 2 10
1 2 1
2 3 2
```处理节点时`1`，两条边到节点`2`被检查。 第一个给出距离`10`，但第二个将其改进为`1`。 

最终距离变为：```
dist[2] = 1
dist[3] = 3
```母链重构：```
1 → 2 → 3
```该算法自然地处理平行边，因为每条边都是独立松弛的。 

最后，考虑一个自循环：```
2 2
1 1 5
1 2 3
```当节点`1`处理后，循环边提出：```
0 + 5 = 5
```对于节点`1`本身。 自从`dist[1]`已经是`0`，没有更新发生。 

正常的边到节点`2`给出：```
dist[2] = 3
```输出变为：```
1 2
```自循环没有任何效果，正如预期的那样。
