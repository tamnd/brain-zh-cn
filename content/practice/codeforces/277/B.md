 ## 解决方案
 ## 问题理解

 我们被要求构建一组`n`二维平面上的点，使得由这些点可以形成的最大凸多边形恰好具有`m`顶点。 任何三点都不可能位于一条直线上。 输入由两个整数组成`n`和`m`有界限`3 ≤ m ≤ 100`和`m ≤ n ≤ 2*m`。 输出应该是`-1`如果不存在构造或列表`n`整数坐标点的边界为`10^8`。 

的限制`n`和`m`告诉我们该集合必须包含凸面的所有顶点`m`-gon 并可能达到`m`里面有额外的点。 自从`n`不能超过`2*m`，我们保证每个额外的点都可以放置在凸多边形内部，而无需创建更大的凸子集。 任何三个点都不位于一条线上的限制阻止了沿着单条线的简单构造。 

边缘情况包括最小场景`n = m = 3`，其中凸多边形是整个点集，并且情况`n = 2*m`，迫使我们在内部放置最大数量的点而不形成新的凸包。 将所有点放置在单个凸层上的简单方法将失败`n > m`因为凸度会超过`m`。 

## 方法

 暴力方法将尝试生成点的所有子集并检查凸包的大小。 对于每个候选点集，我们将使用格雷厄姆扫描或安德鲁单调链算法计算凸包，然后检查其大小是否等于`m`。 子集的数量组合增长，最多`2^n`，即使对于`n = 100`。 

关键的见解是几何的：我们总是可以从凸面开始`m`-gon 并在其内部放置额外的点而不增加凸包。 如果我们放置额外的`n - m`严格位于多边形内部且不与任何边共线的点，最大的凸子集完全保持原始状态`m`顶点。 该结构给出了简单的线性时间结构。 

为了满足“一条线上不能有三个点”的约束，我们可以稍微错开内部点，例如沿着多边形内部的浅对角线添加点。 坐标可以选择小，整数，并且限制在`10^8`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n log n) | O(2^n * n log n) | O(n) | 太慢了 |
 | 构造凸多边形| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.构造一个凸`m`- 贡。 最简单的选择是沿线放置点`y = x`以整数增量，确保它们处于严格的凸位置。 标记这些点`P0, P1, ..., P_{m-1}`。 这些点的凸包的大小精确`m`。 
2. 确定需要多少个内部点：`k = n - m`。 这些点必须严格位于多边形内部。 
3. 地点`k`沿着稍微偏离多边形底部的一条线的内部点，例如在`y = 0`和`x`两个顶点之间的坐标交错。 这保证了它们位于凸包内部并避免共线性。 
4.输出所有的坐标`n`点。 

为什么它起作用：点集的凸包由最外面的点定义。 通过放置额外的`k`严格位于内部的点，它们不能成为新的凸多边形的顶点，因此最大的凸子集仍然是原始的`m`点。 交错的内部点确保没有三个点共线。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

if m < 3 or m > n or n > 2 * m:
    print(-1)
    sys.exit()

points = []

# Step 1: Construct convex m-gon along y = x
for i in range(m):
    points.append((i * 2, i * 2))

# Step 2: Place interior points, staggered along y = 0
for i in range(n - m):
    points.append((i * 2 + 1, 0))

for x, y in points:
    print(x, y)
```每个部分对应算法步骤。 外凸多边形使用坐标`(0,0), (2,2), ..., (2*(m-1), 2*(m-1))`，这保证了严格增加的斜率。 内点使用`y = 0`并交错着`x`坐标`(1,3,5,...)`，因此它们不能与多边形边共线。 将坐标乘以 2 可以留出空间来放置内部点而不会重叠。

 ## 边缘情况

 对于`n = m`，该算法仅构造凸多边形。 例如，`n = 5, m = 5`产生积分`(0,0),(2,2),(4,4),(6,6),(8,8)`。 没有内点，所以凸性恰好是`m`。 

为了`n = 2*m`，算法将`m`沿着多边形内部的一条线的内部点。 不会创建新的凸顶点，因为内部点严格位于内部、交错且不与任何多边形边共线。 为了`n = 6, m = 3`, 点`(0,0),(2,2),(4,4)`形成三角形并且`(1,0),(3,0),(5,0)`位于内部，凸度保持为 3。 

所有其他情况`m ≤ n ≤ 2*m`均进行类似处理。 没有三点共线，内部点严格位于多边形内部，并且凸包尺寸保持精确`m`。
