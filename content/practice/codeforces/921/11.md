 ## 解决方案
 ## 问题理解

 我们有一个二维迷宫，表示为`n × m`网格，其中每个单元格要么是空的，要么包含一堵墙。 我们从左上角开始，想要到达右下角。 允许的移动是向上、向下、向左或向右移动一步，进入空单元格。 挑战不仅在于找到一条路径，还在于计算以大素数为模的最短路径的数量。 

输入提供`n`和`m`（每个最多 1000 个），然后是网格。 输出应该是一个整数：从`(1,1)`到`(n,m)`模数`10^9+7`。 

这些约束意味着对所有路径进行强力探索是不可行的，因为路径总数可能是网格大小的指数。 即使显式存储所有路径也会超出内存限制。 我们必须有效地计算计数，同时确保有障碍物的网格的正确性。 

不明显的边缘情况包括起点或终点被阻挡的网格，或者由于走廊狭窄而最短路径是唯一的。 例如，在一个`2×2`网格中，除了开头之外，只有右下角的单元格是空的，正确答案是`0`。 粗心的 BFS 在不考虑路径长度的情况下计算所有可到达的节点可能会错误地返回`1`。 

## 方法

 一种简单的方法是递归地探索从开始到结束的所有路径，并以最少的步骤计算到达目标的路径。 这可以通过跟踪路径长度的 DFS 来实现。 正确性来自于探索所有的可能性，但复杂性在于`O(4^(n*m))`在最坏的情况下，显然不可行`n, m ≤ 1000`。 

高效解决方案的关键在于我们只需要最短路径的数量，而不是它们的显式路由。 这一观察结果使我们能够使用修改后的广度优先搜索（BFS）。 BFS 自然地计算到每个单元的最短距离，因为它逐层探索节点。 通过增强 BFS 来维护以最短距离到达每个单元格的方式计数，我们可以有效地计算结果。 

每个单元维护两条信息：距起点的距离和到达起点的最短路径的数量。 当BFS到达邻居时，如果邻居尚未被访问过，我们设置其距离和路径计数。 如果之前已经以相同的距离到达邻居，我们就会增加其路径计数。 这确保只有最短路径起作用。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(4^(n*m)) | O(4^(n*m)) | O(n*m) | 太慢了 |
 | 带有路径计数的 BFS | O(n*m) | O(n*m) | 已接受 |

 ## 算法演练

 1. 初始化一个2D数组`dist`尺寸的`n × m`无穷大，表示到每个单元格的最短距离。 初始化一个二维数组`count`带零，表示到每个单元格的最短路径的数量。 放`dist[0][0] = 0`和`count[0][0] = 1`。 
2. 初始化一个队列并压入起始单元`(0,0)`。 
3. 当队列不为空时，弹出一个单元格`(x,y)`。 对于四个邻居中的每一个`(nx,ny)`，检查它是否在网格内而不是墙内。 
4.如果`dist[nx][ny] > dist[x][y] + 1`， 更新`dist[nx][ny] = dist[x][y] + 1`并设置`count[nx][ny] = count[x][y]`。 推`(nx,ny)`进入队列。 
5. 如果`dist[nx][ny] == dist[x][y] + 1`, 增量`count[nx][ny] += count[x][y]`模数`10^9+7`。 
6. BFS完成后，`count[n-1][m-1]`保存最短路径的数量。 如果`dist[n-1][m-1]`为无穷大，输出`0`。 

**为什么有效：** BFS 确保每个单元格在距起始点尽可能短的距离处首先被访问。 路径计数更新规则保证只有最短路径起作用。 更新中`count`当遇到相同的最短距离时，确保正确聚合所有可能的最短路径，而不计算较长的路径。 

## Python 解决方案```python
import sys
from collections import deque
input = sys.stdin.readline

MOD = 10**9 + 7

n, m = map(int, input().split())
grid = [input().strip() for _ in range(n)]

dist = [[float('inf')] * m for _ in range(n)]
count = [[0] * m for _ in range(n)]

dist[0][0] = 0
count[0][0] = 1

q = deque([(0, 0)])
dx = [1, -1, 0, 0]
dy = [0, 0, 1, -1]

while q:
    x, y = q.popleft()
    for dir in range(4):
        nx, ny = x + dx[dir], y + dy[dir]
        if 0 <= nx < n and 0 <= ny < m and grid[nx][ny] == '.':
            if dist[nx][ny] > dist[x][y] + 1:
                dist[nx][ny] = dist[x][y] + 1
                count[nx][ny] = count[x][y]
                q.append((nx, ny))
            elif dist[nx][ny] == dist[x][y] + 1:
                count[nx][ny] = (count[nx][ny] + count[x][y]) % MOD

print(count[n-1][m-1] if dist[n-1][m-1] != float('inf') else 0)
```这`dist`数组跟踪每个单元格的最小步数，而`count`累积最短路径的数量。 模运算确保值永远不会超过`10^9+7`。 BFS 确保按照距离递增的顺序访问单元格，因此路径计数是正确的。
