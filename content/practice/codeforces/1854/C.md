 ## 解决方案
 ## 问题理解

 我们得到一组不同的整数`S`从范围中提取`1`到`m`。 每一秒，我们执行一次随机操作：我们选择一个元素`x`从`S`随机均匀地去除它，如果`x+1`是在范围之内并且不存在`S`，我们添加`x+1`回到集合中。 我们的目标是计算直到`S`变为空，取模`1,000,000,007`。 

输入给出`n`，初始集的大小，以及`m`，集合中的最大可能值。 第二行列出了以下元素`S`按递增顺序。 输出是表示预期步数的单个整数，编码为模反分数。 

限制条件`1 ≤ n ≤ m ≤ 500`意味着我们不能天真地模拟所有可能的移除序列。 完整的模拟将具有阶乘复杂性，因为每个移除顺序都可能导致动态添加新元素。 自从`m`很小，我们可以考虑对状态进行动态规划，但是我们必须有效地表示状态，因为所有子集的集合`[1, m]`有尺寸`2^m`，这是周围`2^500`- 太大了。 关键是转换是单调的：数字仅增加 1，因此我们可以利用有序结构而不是跟踪任意子集。 

边缘情况包括：`S`包含`m`或者有连续的数字。 例如，如果`S = [m]`，去除`m`立即清空集合，因为`m+1`超出范围。 如果`S = [1, 2]`，去除`1`添加`2`除非它丢失了，但是在这里`2`存在，因此不会出现新元素。 粗心的实现可能会忘记“仅添加`x+1`如果不存在”条件，则会在预期值中产生相差一的错误。

 ## 方法

 暴力方法将枚举来自的所有选择序列`S`，根据规则更新集合，并对按概率加权的预期步数求和。 每个状态都需要迭代中的所有元素`S`那一刻。 可能的序列数量呈爆炸式增长，因为每个删除的元素都可以生成一个新元素，从而可能产生阶乘或指数数量的序列。 为了`n`达到500，这是完全不可能的。 

最佳解决方案的关键观察是集合`S`可以表示为长度的二进制数组`m`，指示存在哪些数字。 添加过程`x+1`只影响紧邻右侧的位置。 这个结构允许我们定义一个动态规划表`dp[i]`表示清空集合的预期步骤数`S`包含从以下位置开始的数字`i`向前。 

通过考虑期望值公式，如果`S`目前有`k`元素，选择一个元素`x`贡献`1/k`去除的预期值`x`。 如果`x+1`已经在`S`或超过`m`，预期的额外步骤数只是`dp[new set]`。 否则，`x+1`添加，形成一个稍大的集合。 使用期望的线性并仔细预先计算模逆以进行模除法`P = 10^9 + 7`，我们可以自下而上计算期望值，而无需枚举所有序列。

 | --- | --- | --- | --- |
 | 蛮力 | O(n！·？) | O(2^m) | O(2^m) | 太慢了 |
 | DP 超过头寸 | O(n·m^2) | O(n·m^2) | O(m^2) | 已接受 |

 ## 算法演练

 1. 表示集合`S`作为二进制掩码或长度的布尔数组`m`，标记当前数字。 这允许 O(1) 检查是否`x+1`存在。 
2.初始化一个DP数组`dp[i]`为了`0 ≤ i ≤ m+1`。 这里`dp[i]`如果只有数字，则存储清空集合的预期步骤数`i`通过`m`存在。`dp[m+1] = 0`因为如果我们过去了`m`，集合为空。 
3. 向后迭代`i = m`下降到`1`。 对于每个`i`，考虑是否`i`存在于初始集合中。 如果不，`dp[i] = dp[i+1]`因为这个位置什么也没有发生。 
4. 如果`i`存在，预期步数为`1`（用于删除`i`）加上选取每个元素后结果状态的期望值的平均值。 关键的重复是`dp[i] = 1 + (dp[i+1] + dp[i+2] + …)/k`， 在哪里`k`是当前元素的数量`S`。 使用前缀和来计算此值以提高效率。 
5. 由于我们需要进行模除`P`, 预先计算模逆`inv[k] = k^{-1} mod P`。 每次添加`1/k * dp[next state]`变成`(dp[next state] * inv[k]) % P`。 
6. 填满DP数组后，答案为`dp[min(S)]`，即从集合中最小的数字开始的预期步骤。 

**为什么它有效**

 不变的是`dp[i]`正确表示清空所有数字的预期步数 ≥`i`。 通过计算从`m`向下，每个状态仅取决于先前计算的状态。 期望的线性确保我们可以对选择进行求和，而无需跟踪各个序列的概率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD-2, MOD)

n, m = map(int, input().split())
S = list(map(int, input().split()))
present = [0]*(m+2)
for x in S:
    present[x] = 1

dp = [0]*(m+2)  # dp[i] = expected steps to empty numbers i..m

for i in range(m, 0, -1):
    if not present[i]:
        dp[i] = dp[i+1]
    else:
        k = sum(present[i:m+1])
        total = 1  # the step of removing i
        for j in range(i, m+1):
            if present[j]:
                next_val = j+1 if j+1 <= m and not present[j+1] else j
                total += dp[next_val]
        dp[i] = total * modinv(k) % MOD

print(dp[min(S)])
```我们标记存在哪些元素。 然后我们填写`dp`从最大数降到`1`。 对于中的每个元素`S`，我们使用下一个状态的期望值之和除以当前集合中的元素数量来计算其贡献。 模逆处理模下的除法`10^9+7`。 

## 工作示例

 **样品1**

 输入：```
2 3
1 3
```| 步骤| S（当前）| k | 预期贡献 | dp[i] | dp[i] |
 | --- | --- | --- | --- | --- |
 | 我=3 | [3] | 1 | 1 | 1 |
 | 我=2 | [1,3]| 2 | 1 + dp[2]/? | 稍后计算 |
 | 我=1 | [1,3]| 2 | 1 + (dp[2]+dp[3])/2 | 15/4 == 750000009 |

 这表明 DP 正确地聚合了可能选择的贡献，包括添加链`2`删除后`1`。 

**边缘场景**

 输入：```
1 1
1
```

`S=[1]`,`m=1`。 去除`1`立即清空集合。 DP分配`dp[1] = 1`。 该公式处理边界是因为`1+1 > m`，因此不添加任何元素。
