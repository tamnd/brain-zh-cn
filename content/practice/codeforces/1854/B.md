 ## 解决方案
 ## 问题理解

 我们面临这样一个场景：玩家希望在解锁游戏技能的同时最大化自己的收入。 有`n`技能，每个技能都需要某些先前解锁的技能，如果解锁则提供硬币奖励。 有些技能可以在没有先决条件的情况下立即解锁，而另一些则需要先前技能的组合。 目标是通过选择符合这些先决条件的解锁技能顺序来计算玩家可以获得的最大总硬币数。 

输入描述了每项技能的奖励及其先决条件。 输出是在限制下可实现的最大硬币。 

约束足够小`n`最多为 20。这立即表明任何迭代所有技能子集的解决方案都是可行的，因为`2^20`约为一百万，完全符合典型的计算限制。 然而，尝试解锁订单的所有排列的天真的方法将需要`n!`操作规模对于`n=20`。 因此，我们需要考虑子集动态编程或位掩码等技术。 

边缘情况很微妙。 一种是最初可以解锁但奖励为零的技能； 另一个是需要所有其他技能才能解锁的技能。 例如，对于三个技能，其中技能 3 需要技能 1 和 2，最佳顺序必须考虑在 3 之前解锁 1 和 2。仅首先选择最高奖励的粗心贪婪方法可能会失败。 

## 方法

 暴力方法是考虑解锁技能的每一个顺序。 对于每个排列`n`技能，我们检查每一步是否满足先决条件，总结解锁技能的奖励。 虽然这保证了正确性，但它需要`n!`最坏情况下的操作，这是不可行的`n=20`。 

最佳方法利用位掩码动态编程。 每个技能子集都可以表示为长度的位掩码`n`，如果相应的技能被解锁，则设置一个位。 DP状态`dp[mask]`表示解锁子集后可获得的最大金币`mask`。 关键的观察是，我们可以迭代所有子集，并且对于每个子集，如果当前掩码满足其先决条件，则考虑添加一项新技能。 这减少了解决方案空间`n!`排列为`n * 2^n`过渡，这是可以接受的`n ≤ 20`。 

蛮力之所以有效，是因为它考虑了所有可能性，但在以下情况下会失败：`n`很大。 观察到问题可以表示为子集之间的转换，这使我们能够将其简化为位掩码上的 DP，这是有效的并且避免了不必要的检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 位掩码 DP | O(n * 2^n) | O(n * 2^n) | O(2^n) | O(2^n) | 已接受 |

 ## 算法演练

 1. 读取测试用例的数量，然后迭代每个测试用例。 
2. 对于每项技能，存储其硬币奖励和先决条件的位掩码。 
3.初始化一个大小为DP的数组`2^n`负无穷大，除了`dp[0] = 0`因为没有解锁技能会产生零硬币。 
4. 迭代所有蒙版`0`到`2^n - 1`。 对于每个面具，考虑解锁一项新技能`i`还没有戴上面具。 
5.如果当前面具包含技能的所有先决条件`i`，通过设置位计算新的掩码`i`。 更新`dp[new_mask]`作为其当前值的最大值并且`dp[mask] + coins[i]`。 
6. 处理完所有掩码后，答案是 DP 数组中的最大值，对应于解锁技能的任意子集。 

不变的是`dp[mask]`始终持有该组解锁技能可获得的最大金币。 我们从不跳过任何有效的过渡，因为我们系统地探索每个子集和每个技能添加。 不会遗漏任何有效序列，因此最后计算的最大值保证是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        coins = []
        prereq_masks = []
        for _ in range(n):
            parts = list(map(int, input().split()))
            c = parts[0]
            k = parts[1]
            prereqs = parts[2:] if k > 0 else []
            mask = 0
            for p in prereqs:
                mask |= 1 << (p - 1)
            coins.append(c)
            prereq_masks.append(mask)
        
        dp = [-1] * (1 << n)
        dp[0] = 0
        for mask in range(1 << n):
            if dp[mask] == -1:
                continue
            for i in range(n):
                if not (mask & (1 << i)) and (mask & prereq_masks[i]) == prereq_masks[i]:
                    new_mask = mask | (1 << i)
                    dp[new_mask] = max(dp[new_mask], dp[mask] + coins[i])
        
        print(max(dp))

if __name__ == "__main__":
    solve()
```该解决方案有效地读取输入并构建先决条件的掩码。 DP 数组跟踪每个子集的最大硬币数，并且仅在满足先决条件时才会发生转换。 仔细的按位运算可确保我们永远不会过早地解锁技能。 使用`-1`对于未初始化的状态可以避免意外地与无效子集求和。

 当一项技能没有奖励但其他人需要时，DP 仅在必要时正确包含它。 例如：

 输入：```

 尽管奖励为零，算法仍选择技能 1，因为它启用了技能 2。这证实了即使某些奖励为零，DP 也能正确执行先决条件。
