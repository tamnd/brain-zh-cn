 ## 解决方案
 ## 问题理解

 我们正在四维整数网格中工作。 从原点开始，宇宙飞船执行一系列移动，其中每次移动选择四个坐标轴之一，并在任一方向上步进一个单位。 

不同的是，指令列表中的第 i 个动作不是执行一次，而是执行 i 次。 因此，如果我们决定 k 个移动的序列，则实际位移是加权和，其中第一个移动贡献一次，第二个移动贡献两次，依此类推，最多 k 次。 

对于这个 4D 网格中的任何目标点，我们将 f(a, b, c, d) 定义为在此加权执行规则下产生精确位移所需的最小移动次数。 任务是计算以原点为中心、边长由 A、B、C、D 确定的框内所有整数点的最小长度之和。 

关键的困难在于每个动作的重量都在增加，因此后面的动作主导了位移。 这意味着我们处理的不是统一成本图中的简单最短路径，而是处理系数为三角形数的结构化数字系统。 

约束允许每个维度的绝对值最多为 1000。 在最坏的情况下，点的总数最多可达 10^12 左右，因此枚举点甚至每个点独立计算 f 是不可能的。 任何解决方案都必须将所有点压缩到共享计数结构中，并跨维度重用工作。 

一种简单的解释是尝试使用加权序列上的 DP 或 BFS 独立计算 f(a, b, c, d)。 即使是单个评估也是昂贵的，并且对所有点进行评估是不可行的。 

一个微妙的边缘情况是原点和小坐标。 例如，(0, 0, 0, 0) 的值为 0，而像 (1, 0, 0, 0) 或 (2, 0, 0, 0) 这样的点可以通过很少的移动来实现，但是一旦多个维度交互，贪婪的直觉就会失败，因为大的加权步骤可以用来“纠正”早期的超调。 

## 方法

 第一个想法是直接解释该过程。 每次移动都会选择一个维度和一个符号，并在第 i 步为该坐标贡献 i 个单位。 如果我们固定 k 个移动，那么每个坐标都是 {1, 2, ..., k} 的某个子集的总和，并且每次出现都会分配符号。 

因此，对于固定的 k，每个坐标都可以表示为三角形结构的有符号子集和。 关键的观察是，除了共享相同的步长索引之外，坐标是独立的。 这种耦合就是暴力破解的爆发点。 

蛮力方法会迭代所有的移动序列，直到达到某个最大 k，模拟它们的加权效果，并记录可以用最小 k 到达哪些点。 即使对于中等的 k，每步有 4 个选择，即 8^k 种可能性，这也是指数级的，甚至通过对称修剪也没有足够的帮助。 

结构洞察力就是扭转观点。 我们不是从移动中构造点，而是问固定的 k 对可实现的坐标施加了哪些约束。 对于每个维度，在 k 个步骤之后，我们可以为每个索引 i 分配一个符号，或者为该维度跳过它，但由于每个索引在全局范围内仅使用一次，因此每个维度都会收到同一组权重的带符号选择。 这创建了一个耦合约束，可以将其重新解释为三角形权重上的 4D 背包。 

该问题系列中的标准技巧是将问题转换为计算有多少个点的 f(a, b, c, d) 恰好等于 k，然后将 k 乘以该层的大小求和。 因此，我们需要了解 k 步内可到达的点集以及它如何随 k 扩展。

对于 k 次移动，每个坐标都以可实现的最大有符号和 1.​​.k 为界，即 k(k+1)/2。 这给出了分层结构：所有点都位于不断增长的 4D 盒子中，并且每个层 k 都添加了新的可到达点的外壳。 核心简化是 f(a, b, c, d) 等于最小 k，这样每个坐标都可表示为 1..k 的有符号子集和，并且这些约束在每个维度上解耦。 

这将问题转化为最小 k 阈值上的经典多维前缀和。 对于每个坐标 x，我们计算最小 k 使得 |x| ≤ k(k+1)/2，因为我们总是可以贪婪地分配符号以达到该区间内的任何值。 因此，f(a, b, c, d) 是其各自最小 k 要求的四个坐标上的最大值。 

因此，我们将问题简化为计算每个坐标范围每个 k 需要多少个整数，然后使用独立分布的卷积在 4D 产品空间上进行聚合。 

我们预先计算 gA[k]，即 [-A, A] 中的整数计数，其最小 k 恰好为 k，B、C、D 也类似。然后最终答案是 4 路卷积，其中每个点贡献 max(k1, k2, k3, k4)。 这可以通过转换为“至多 k”的累积计数然后使用前缀包含来计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 序列的暴力枚举| O(8^k) | O(8^k) | O(k) | 太慢了 |
 | 分层阈值+1D预处理+4D聚合| O(A + B + C + D + K) | O(A + B + C + D + K) | O(K) | 已接受 |

 ## 算法演练

 1. 对于每个坐标范围 [-A, A]，计算表示每个整数 x 所需的最小 k。 这是通过找到最小的 k 来完成的，使得 |x| ≤ k(k+1)/2，因为 k 次移动可以生成该区间内的任何有符号和。 
2. 将其转换为频率数组 cntA[k]，其中 cntA[k] 计算 [-A, A] 中有多少个整数恰好需要 k。 对 B、C 和 D 重复此操作。这会将几何约束转换为“难度级别”上的离散分布。 
3. 将每个cnt数组转换为前缀形式prefA[k]，它统计最多需要k次移动的值有多少个。 这很有用，因为“最大坐标”更容易通过补码处理。 
4. 对于固定的 k，f(a, b, c, d) ≤ k 的 4D 点的数量是 prefA[k] × prefB[k] × prefC[k] × prefD[k] 的乘积，因为一旦 k 固定，坐标是独立的。 
5. 通过对连续值进行差分，将“最多 k”个计数转换为“恰好 k”个层。 
6. 通过将 k 乘以最小可行 k 等于该值的点数来累加最终答案。 

正确性背后的关键思想是每个坐标约束仅取决于其大小，并且加权移动系统精确地减少到三角形数容量。 一旦 k 固定，坐标就变得独立，因为所有耦合仅通过共享边界 k，而不是通过单独的步骤分配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def calc(x):
    x = abs(x)
    k = 0
    # find smallest k with k(k+1)/2 >= x
    # binary search up to 2000 is enough
    lo, hi = 0, 2000
    while lo < hi:
        mid = (lo + hi) // 2
        if mid * (mid + 1) // 2 >= x:
            hi = mid
        else:
            lo = mid + 1
    return lo

def build(limit):
    cnt = {}
    for x in range(-limit, limit + 1):
        k = calc(x)
        cnt[k] = cnt.get(k, 0) + 1
    maxk = max(cnt)
    arr = [0] * (maxk + 1)
    for k, v in cnt.items():
        arr[k] = v
    return arr

def prefix(arr):
    res = [0] * len(arr)
    s = 0
    for i in range(len(arr)):
        s += arr[i]
        res[i] = s
    return res

def solve():
    A, B, C, D = map(int, input().split())

    a = build(A)
    b = build(B)
    c = build(C)
    d = build(D)

    K = max(len(a), len(b), len(c), len(d))
    a += [0] * (K - len(a))
    b += [0] * (K - len(b))
    c += [0] * (K - len(c))
    d += [0] * (K - len(d))

    pa = prefix(a)
    pb = prefix(b)
    pc = prefix(c)
    pd = prefix(d)

    ans = 0
    total = (2*A+1)*(2*B+1)*(2*C+1)*(2*D+1)

    prev = 0
    for k in range(K):
        ca = pa[k]
        cb = pb[k]
        cc = pc[k]
        cd = pd[k]
        cur = ca * cb * cc * cd
        exact = cur - prev
        ans += k * exact
        prev = cur

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案构建每个坐标的“难度层”，然后通过前缀产品将它们合并。 重要的实现细节是将所有数组填充到相同的长度，以便前缀产品正确对齐。 第二个微妙之处是使用累积差异来恢复精确的层，因为自然计算给出的是 f ≤ k 而不是 f = k 的点的计数。

 ## 边缘情况

 原始情况是最简单的边界。 当所有坐标都为零时，每个坐标都需要k=0，所以总和为零。 前缀结构确保了这一点，因为第一层已经包含一个点。 

当只有一个维度非零时，产品结构会完全崩溃为单个坐标分布。 该算法处理此问题是因为其他维度贡献常数 pref[0]=1，因此它们不会扭曲计数。 

当A、B、C、D相等且较大时，k层的增长由三角形数阈值主导。 前缀积仍然可以正确运行，因为所有坐标共享相同的分布，并且最大聚合是通过前缀差异隐式处理的。 

转变点其中 |x| 交叉 k(k+1)/2 是由 calc 中的二分搜索精确处理的，因此即使在完美的三角数中也不存在差一歧义。
