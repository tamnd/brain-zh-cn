 ## 问题理解

 我们得到一个数字`n`以及允许值的范围`[l, r]`。 我们需要找到最小的整数`x`在此范围内，使得最大公约数`n`和`x`也在同一范围内。 如果没有这样的`x`存在，我们打印`-1`。 

重要的观察来自 gcd 的定义。 无论价值如何`gcd(n, x)`是，它必须除`n`。 而且，它永远不能大于`x`。 这意味着每个有效答案都与一个除数有关`n`。 

输入最多包含`1000`测试用例。 的价值观`n`,`l`， 和`r`可以大到`10^9`，因此迭代中的每个值`[l, r]`是不可能的。 该范围本身可能包含十亿个数字。 我们需要一种取决于规模的方法`n`的因式分解来代替。 检查至`sqrt(n)`是可以接受的，因为`sqrt(10^9)`只是关于`31623`, 给予周围`3.2 * 10^7`对所有测试用例的操作。 

棘手的情况来自于将有效的 gcd 与有效的 gcd 混淆。`x`。 一个数字可以有一个有效的最大公约数，但它本身并不是最小的可能答案。 例如，如果输入是：```
6 5 6
```范围内的值为`5`和`6`。 第一个值给出`gcd(6,5)=1`，这是无效的。 第二个给出`gcd(6,6)=6`，所以答案是`6`。 仅检查范围是否包含具有非平凡 gcd 的某个值的解决方案可能会错误地接受`5`。 

另一种边缘情况是当除数存在但位于下面时`l`。 为了：```
12 7 11
```的约数为`12`是`1, 2, 3, 4, 6, 12`。 范围内或之上的唯一除数是`12`，但它超出了范围，因为`12 > 11`。 无效`x`存在，所以答案是`-1`。 一个粗心的实现，找到了之后的下一个除数`l`没有检查`r`会失败的。 

最终的边界情况是单元素范围：```
10 1 1
```唯一可能的答案是`1`。 自从`gcd(10,1)=1`，输出是`1`。 这测试算法是否处理`l = r`正确。 

## 方法

 一个简单的方法会尝试一切可能的方法`x`从`l`到`r`, 计算`gcd(n, x)`，并返回第一个有效的值。 这是正确的，因为我们按升序检查候选项，因此第一个有效的候选项自动是最小的。 

问题在于范围的大小。 如果`l = 1`和`r = 10^9`，对于单个测试用例，这需要多达十亿次 gcd 计算。 高达`1000`测试中，最坏的情况远远超出了时间限制。 

关键的观察是有效的 gcd 必须是以下的除数`n`。 认为`x`是一个有效的答案并且`d = gcd(n, x)`。 自从`d`划分`n`和`d`在里面`[l, r]`, 数量`d`本身也是一个有效的选择，因为`gcd(n, d) = d`。 还，`d <= x`，所以替换`x`和`d`永远不会让答案变得更糟。 

这彻底改变了问题。 我们只需要找到最小的除数`n`属于`[l, r]`。 自从`n`至多是`10^9`，我们可以通过检查周围的对来枚举除数`sqrt(n)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 每个测试用例 O(r - l + 1) | O(1) | O(1) | 太慢了 |
 | 最佳 | 每个测试用例 O(sqrt(n)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 迭代所有可能的除数候选`i`从`1`到`sqrt(n)`。 如果`i`划分`n`，那么两者`i`和`n / i`是除数。 
2. 对于每个找到的除数，检查它是否属于`[l, r]`。 保留迄今为止看到的最小有效除数。 
3. 处理完所有除数后，输出最小的存储值。 如果除数不在范围内，则输出`-1`。 

原因查到`sqrt(n)`就足够了，每个除数都大于`sqrt(n)`有一个小于的匹配除数`sqrt(n)`。 这对`(i, n / i)`让我们发现因式分解的两边。 

为什么有效：每个可能的有效答案都可以简化为除数`n`。 该算法检查每个除数`n`，所以它不会错过有效的候选人。 由于它始终保持所需区间内的最小除数，因此最终值恰好是可能的最小值`x`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(n, l, r):
    ans = 10**18
    i = 1
    while i * i <= n:
        if n % i == 0:
            if l <= i <= r and i < ans:
                ans = i
            other = n // i
            if l <= other <= r and other < ans:
                ans = other
        i += 1

    return -1 if ans == 10**18 else ans

def main():
    t = int(input())
    out = []
    for _ in range(t):
        n, l, r = map(int, input().split())
        out.append(str(solve_case(n, l, r)))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```功能`solve_case`执行除数搜索。 循环条件`i * i <= n`就足够了，因为每个因子对最多有一个成员是平方根。 

当除数`i`找到后，代码还会检查`n // i`，这是配对除数。 这可以避免丢失可能在区间内的大除数。 答案以一个非常大的值开始，而不是`None`，这使得最小比较变得简单。 

主函数读取所有测试用例并在打印之前收集答案。 该实现仅使用整数运算，因此 Python 中不存在溢出问题。

 ## 边缘情况

 对于输入：```
6 5 6
```该算法检查除数`6`。 它发现`1`,`2`,`3`， 和`6`。 仅有的`6`位于所需的区间内，因此答案变为`6`。 这可以处理范围内的值不会自动有效的情况。 

为了：```
12 7 11
```除数搜索发现`1`,`2`,`3`,`4`,`6`， 和`12`。 两者之间没有一个`7`和`11`，因此存储的答案保持不变并且算法打印`-1`。 范围检查可防止接受超出允许间隔的除数。 

为了：```
10 1 1
```找到的第一个除数是`1`，这立即成为答案。 该算法仍然完成除数扫描，但没有其他值可以更小。 这涵盖了恰好包含一个可能值的范围。
