 ## 解决方案
 ## 问题理解

 我们有一个正多边形，其顶点编号为`1`到`n`按顺时针顺序。 可以在顶点之间绘制线段`i`和`j`仅当顶点在多边形边界上不相邻且`gcd(i, j) = 1`。 目标是绘制尽可能多的此类线段，同时保持绘图不交叉。 允许线段在端点处相交，但两个线段在其内部不得相交。 

输入包含多个测试用例，每个测试用例由一个值组成`n`。 对于每个测试用例，我们必须输出可以添加的最大段数。 

的最大值`n`是`10^5`，并且最多可以有`10^4`测试用例。 任何执行每个顶点几何或图形构造的解决方案都是不必要的。 我们需要每个测试用例接近恒定的时间。 

一个微妙的一点是，互质条件看起来很重要，这可能会诱使我们寻找复杂的图结构。 关键的观察是顶点`1`与所有其他顶点互质。 

考虑`n = 3`。```
3
```三角形中没有对角线，所以答案是`0`。 

仅检查互质条件的粗心解决方案可能会错误地计算涉及顶点的线段`1`，忘记相邻顶点不能连接。 

考虑`n = 4`。 

唯一的对角线是`(1,3)`，并且它是有效的，因为`gcd(1,3)=1`。 答案是`1`。 

尝试对所有互质对进行计数的解决方案会过度计数，因为许多有效对在没有交叉的情况下无法共存。 

## 方法

 蛮力方法是生成每个有效段，然后搜索最大的非交叉子集。 即使构建所有候选片段也大约需要`O(n²)`对，找到最大兼容子集要困难得多。 和`n = 10^5`，这是完全不可行的。 

多边形的结构给出了更强有力的事实。 在任何`n`-gon，不交叉对角线的最大可能数量为`n - 3`。 这在每个三角剖分中都会发生。 

所以问题就变成了：我们真的能实现吗？`n - 3`仅使用允许的段？ 

是的。 

从顶点取每条对角线`1`到顶点`3, 4, ..., n-1`。 

这些线段形成扇形三角剖分。 它们永远不会交叉，因为它们共享相同的端点。 每个这样的段都是有效的：`|1 - j| > 1`为了`j = 3 ... n-1`，因此顶点不相邻。`gcd(1, j) = 1`对于每个整数`j`。 

这些对角线的数量正好是：$$(n-1) - 3 + 1 = n-3$$由于非交叉配置不能包含超过`n-3`对角线，我们已经准确地构建了`n-3`，这是最优的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) 或更糟 | O(n²) | 太慢了 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`。 
2. 回想一下，任意一组不相交的对角线`n`-gon 最多包含`n - 3`对角线。 
3.观察从顶点开始的每条对角线`1`到一个顶点`j`和`3 ≤ j ≤ n-1`是允许的，因为`gcd(1, j) = 1`。 
4. 这些对角线形成一个扇形，因此它们不会相互交叉。 
5. 这样的对角线的数量正好是`n - 3`。 
6. 输出`n - 3`。 

### 为什么它有效

 上限来自多边形三角剖分理论：非交叉对角线集不能包含超过`n - 3`对角线。 我们的施工完全使用`n - 3`对角线，所有这些都满足问题的有效性规则。 由于我们同时达到全局上限并满足所有约束，因此答案一定是`n - 3`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    print(n - 3)
```实现非常小，因为所有工作都是通过数学观察完成的。 

对于我们输出的每个测试用例`n - 3`。 不需要几何、图形构造或 gcd 计算。 证明已经保证扇形以顶点为中心`1`总是存在并且是最优的。 

唯一的边界条件是`n = 3`。 在这种情况下，公式给出`0`，这是正确的，因为三角形没有对角线。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        ans.append(str(n - 3))

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out
