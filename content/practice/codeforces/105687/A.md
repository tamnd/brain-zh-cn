 ## 解决方案
 ## 问题理解

 我们有两支足球队，每支球队`n`玩家。 A 队向 B 队守门员射门，守门员身高为`k`。 B 队向 A 队守门员射门，守门员身高为`m`。 

如果一名球员的射门力量至少是对方守门员身高的一半，则该球员得分。 直接进行比较`height / 2`，所以一个有权力的玩家`x`得分时`2 * x >= height`。 

获胜者分两个阶段决出。 首先，比较各队的总进球数。 如果一支球队进球较多，则该队获胜。 如果两队进球数相同，则比较两队所有球员的最大射门力量。 最大功率较大的团队获胜。 

爱丽丝预测 A 队会获胜。 鲍勃预测 B 队会获胜。 我们必须输出`"Alice"`根据上述规则如果A队获胜，否则输出`"Bob"`。 

限制非常小。 测试用例最多 500 个，每个团队最多 100 名玩家。 即使是直接扫描所有玩家也不过几万次操作。 不需要高级算法。 

一个微妙的点是评分条件。 声明称，当球员的力量大于或等于守门员身高的一半时，即可得分。 如果守门员身高是奇数，则一半不是整数。 

考虑：```
1
1 5 3
2
1
```A队逆高射门`3`。 自从`2 >= 1.5`，A队得分。 

使用整数除法的粗心实现会测试`2 >= 3 // 2 = 1`，这恰好在这里有效，但在其他情况下失败。 

例如：```
1
1 5 5
2
1
```正确的阈值是`2.5`，所以功率`2`应该错过。 使用`5 // 2 = 2`会错误地将其视为目标。 

当进球数打成平手时，就会出现另一种边缘情况。```
1
2 4 4
2 10
3 9
```两队进球数相同。 A队的最大力量为`10`, B队的是`9`，所以 A 队获胜。 仅比较目标计数的解决方案会产生错误的答案。 

该声明保证所有射门功率都是不同的，因此如果进球数相同，则最大功率不能相等。 抢七局总是会产生一个独特的获胜者。 

## 方法

 最直接的方法是准确模拟规则所描述的内容。 

对于 A 队，计算有多少玩家满意`2 * a[i] >= k`，因为他们的射门是针对B队身高较高的门将`k`。 

对于 B 队，计算有多少玩家满意`2 * b[i] >= m`，因为他们的射门对象是A队身高较高的门将`m`。 

获得两个进球数后，对它们进行比较。 如果 A 队有更多目标，那么爱丽丝是正确的。 如果 B 队有更多目标，那么鲍勃是正确的。 当计数相等时，比较两队的最大射击能力，并宣布最大射击能力较大的球队获胜。 

由于每个玩家都会被检查一次，因此运行时间与`n`。 考虑到限制，这已经足够快了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 在这个问题中，暴力模拟已经是最优的，因为规则本身要求对每个玩家至少检查一次。 

## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，请阅读`n`,`m`， 和`k`。 
3. 读取 A 队的投篮能力和 B 队的投篮能力。 
4. 通过检查每个值来计算 A 队的目标`a[i]`。 进球得分时`2 * a[i] >= k`。 
5. 通过检查每个值来计算 B 队的目标`b[i]`。 进球得分时`2 * b[i] >= m`。 
6. 如果 A 队的进球数较多，则打印`"Alice"`。 
7. 如果 B 队的进球数较多，则打印`"Bob"`。 
8. 如果进球数相等，则计算`max(a)`和`max(b)`。 如果 A 队的最大值更大，则打印`"Alice"`，否则打印`"Bob"`。 

### 为什么它有效

 该算法严格遵循匹配规则。 

步骤 4 和 5 中计算的计数正是每支球队成功罚球的次数，因为每个球员都会根据所需的得分条件进行检查。 如果计数不同，则根据定义，进球数较多的球队必定获胜。 

规则规定，当计数相等时，个人射击能力最高者决定获胜者。 比较`max(a)`和`max(b)`准确地再现了这场抢七局。 由于每个决策都符合规范，因此算法始终返回正确的获胜者。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, m, k = map(int, input().split())

    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    goals_a = sum(1 for x in a if 2 * x >= k)
    goals_b = sum(1 for x in b if 2 * x >= m)

    if goals_a > goals_b:
        print("Alice")
    elif goals_b > goals_a:
        print("Bob")
    else:
        if max(a) > max(b):
            print("Alice")
        else:
            print("Bob")
```第一个循环独立处理每个测试用例。 

进球数计算使用`2 * x >= height`而不是比较`height / 2`。 这避免了浮点运算并正确处理奇数守门员高度。 

仅当进球数相同时才会评估抢七。 因为所有的射门能力都不同，最大值不可能相等，所以在比较中总是有一支球队获胜。 

除了存储输入值之外，不需要额外的数组或数据结构。

 ## 边缘情况

 考虑奇数高度阈值情况：```
1
1 5 5
2
1
```A队逆守门员高度射门`5`。 评分阈值为`2.5`。 力量`2`不得分。 

该算法评估：```
2 * 2 >= 5
4 >= 5
false
```所以A队进球数为0。 

B队逆高投篮`5`还有：```
2 * 1 >= 5
2 >= 5
false
```B队也进0球。 

抢七比较最大值，`2`相对`1`，所以 A 队获胜。 该算法避免了整数除法错误，从而错误地计算幂`2`作为目标。 

现在考虑平局比分：```
1
2 4 4
2 10
3 9
```两支球队都得分两次，因为每个球员的力量至少`2`。 

算法进入抢七阶段：```
max(A) = 10
max(B) = 9
```自从`10 > 9`，它打印`"Alice"`。 

仅比较目标计数的解决方案会错误地将这种情况视为未解决。 

最后，考虑最小的可能输入：```
1
1 1 1
1
2
```两名球员都得分是因为一半`1`是`0.5`。 

进球数均为 1。最大值为`1`和`2`，所以 B 队获胜并且算法打印`"Bob"`。 

这证实了该实现正确地处理了所有约束的下限。
