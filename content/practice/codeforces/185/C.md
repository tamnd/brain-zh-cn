 ## 解决方案
 ## 问题理解

 我们得到了一个按行排列的“称重板”的三角形结构。 最上面一行有$n$盘子，下一个有$n-1$，依此类推，直到最后一行有一个盘子。 每个板块都有一个重量阈值。 如果施加在板上的负载达到或超过其阈值，该板会立即破裂，并将其所承载的所有东西重新分配到下面的行，无论是左下还是右下，具体取决于板的位置。 

最初，每个顶排盘子都会收到固定数量的谷物。 一旦该过程开始，板可能会以某种顺序破裂，并且当板破裂时，其内容物通过分支结构向下传播，直到最终一些质量可能到达底部单板。 问题是是否存在任何中断决策序列（每个内部盘子的左侧或右侧）使得正数量的谷物到达底部。 

因此，问题不在于模拟一个确定性过程。 这是关于是否存在至少一条从顶行到底部的有效级联路径，其中质量永远不会以阻止到达最后一个节点的方式被阻止。 

输入尺寸$n \le 50$足够小$O(n^3)$甚至$O(n^4)$风格的动态规划是可以接受的。 然而，对所有断裂序列的任何简单模拟都是指数级的：每个内板分为两个选择，大致给出$2^{n^2}$的可能性，这是完全不可行的。 

当顶行中的多个板以可能通过共享下游节点相互作用的质量开始时，就会出现微妙的边缘情况。 仅跟踪单个“当前路径”的简单模拟会错过多个独立源可以在较低级别组合、增加质量并实现其他方式不会发生的进一步中断。 

另一个特殊情况是所有顶部重量都太小而无法打破任何板。 在这种情况下，根本不会发生传播，答案一定是“Cerealguy”，因为没有任何东西到达底部。 

## 方法

 关键的困难在于，质量传播沿着单一路径不是线性的：多个传入源可以在一个节点处合并，并且板块是否破裂取决于从所有可能的上游路线到达的总累积质量。 这表明我们应该考虑质量的可达性而不是个体的轨迹。 

暴力方法将模拟每次中断事件时所有可能的左/右选择。 每个内部节点最多有两条出边，该结构具有$O(n^2)$节点，因此可能的全局配置的数量是指数级的。 即使每次模拟都是$O(n^2)$，总数变得棘手。 

关键的见解是扭转观点。 我们不问质量如何向下流动，而是问：如果允许我们以对抗性或最佳方式选择断裂方向，则可以强制通过每个节点的最大质量是多少？ 由于我们只关心是否有任何正质量到达底部，因此我们可以将其视为极小极大型传播问题，在该问题中我们尝试最大化幸存到底部的质量。 

每个板的作用就像一个分裂流动的节点，但我们可以自由选择哪个传出边缘在破裂时接收全部质量。 因此，在每个节点，我们可以假设我们将所有传入的质量引导到更“有前途”的子节点，以到达底部。 

这导致了三角形上的动态规划公式。 对于每个节点，我们计算从该节点开始可以传递到底部的最大可能质量，假设从该点开始进行最佳路由决策。 如果在某个节点累积的质量达到其阈值，它就会“激活”并将其整个质量向下传递； 否则它就没有任何进一步的贡献。 

这将问题转变为自下而上的DP，其中每个节点聚合来自上方的贡献，并选择方向向下转发它们。

 ## 算法演练

 我们将三角形建模为网格，其中每个单元格$(i, k)$通过级联分裂从顶行接收质量。 

1.首先初始化一个DP表`dp[i][k]`代表到达板的总质量$(i,k)$在最佳可能的传播策略下。 
2、直接设置顶行：`dp[1][k] = a_k`。 这是麦片的初始放置。 
3. 从上到下处理行。 在每个盘子上$(i,k)$，检查传入的质量是否足以打破它。 如果`dp[i][k] < w[i][k]`，那么该节点无法进一步传播任何内容，因此它不会向下做出任何贡献。 
4. 如果板破裂，则该节点上的所有质量必须精确地转发到其两个子节点之一：$(i+1, k-1)$或者$(i+1, k)$，取决于哪个有效。 
5. 我们计算哪个孩子“更好”，因为它最终有更高的能力到达底部。 为了正确地做到这一点，我们自下而上地传播贡献，以便每个节点知道它最终可以向最终接收器传递多少质量。 
6.处理完所有节点后，我们检查底部节点$(n,1)$。 如果`dp[n][1] > 0`，那么存在一系列的中断和方向，允许一些谷物到达老鼠的手中。 

### 为什么它有效

 该过程可以被视为有向无环图上的流网络，其中每个节点要么阻止流，要么将其完全转发给一个子节点。 由于结构是 DAG 并且决策是局部的，因此任何全局策略都会分解为每个节点的局部选择。 DP 为每个节点计算可实现的最大下游贡献，假设所有后代都有最佳路由。 这确保了如果任何正流可以到达底部，它将被根部的 DP 值捕获。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    w = [None]
    for i in range(n):
        w.append(list(map(int, input().split())))
    
    # dp[i][k] = maximum mass that can reach (i,k)
    dp = [[0] * (n + 2) for _ in range(n + 2)]
    
    for k in range(1, n + 1):
        dp[1][k] = a[k - 1]
    
    for i in range(1, n + 1):
        for k in range(1, n - i + 2):
            if dp[i][k] < w[i][k - 1]:
                continue
            
            # if it breaks, we can send all mass down either way
            if i == n:
                continue
            
            left = (i + 1, k - 1)
            right = (i + 1, k)
            
            li, lk = left
            ri, rk = right
            
            # propagate to both possibilities as achievable states
            if lk >= 1:
                dp[li][lk] += dp[i][k]
            if rk <= n - i:
                dp[ri][rk] += dp[i][k]
    
    print("Fat Rat" if dp[n][1] > 0 else "Cerealguy")

if __name__ == "__main__":
    solve()
```DP 表存储每个板可以累积的质量。 转换检查板是否会破裂； 只有这样它的质量才会被转发。 实现的关键思想是，我们将传播视为子节点的累积，因为多个父节点可以为同一个节点做出贡献。 

边界处理至关重要：左孩子仅在以下情况下存在$k-1 \ge 1$，并且右孩子仅存在于$k \le n-i$。 这里的差一错误很常见，因为每一行都会缩小一个元素。 

最终答案仅取决于是否有任何质量到达左下角的单元格，这是最后一行中唯一的节点。

 ## 边缘情况

 一个重要的边缘情况是顶排中没有板破裂。 例如，如果所有$a_i < w_{1,i}$， 然后`dp`永远不会传播到第一行之外。 该算法自然会处理这个问题，因为不会触发任何转换，使底部值保持为零。 

另一种情况是，只有一块顶板破裂，但其质量分散在随后均失效的路径上。 DP仍然在中间节点累积贡献，但如果不满足阈值，则传播在本地停止，防止在底部错误累积。 

最后一个微妙的情况是多个顶部节点贡献于同一个中间板。 该算法在检查阈值之前正确地计算这些贡献的总和，确保只有当总传入质量足够时，板才会破裂。
