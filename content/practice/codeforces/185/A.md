 ## 解决方案
 ## 问题理解

 我们被要求对三角形植物多年来的生长进行建模。 每个植物三角形都有一个方向：“向上”或“向下”。 增长规则是确定性的：每年，每个三角形都会产生四个新三角形。 三个新三角形继承父级的方向，而第四个则指向相反的方向。 任务是计算之后有多少个三角形指向上方`n`年，从单个向上的三角形开始，并返回该数字模 10^9+7。 

输入是单个整数`n`代表年数，输出是一个整数，向上三角形的数量模 10^9+7。 上限为`n`非常大，10^18，这排除了任何模拟逐年增长的解决方案。 简单的模拟会在 n 年后产生 4^n 个三角形，其增长远远超出了可行的计算。 这表明需要数学或组合方法而不是显式枚举。 

边缘情况包括`n = 0`，没有任何一年过去，所以植物仍然是一个向上的三角形，并且`n = 1`，它产生四个三角形，其中三个向上。 任何方法都必须正确处理模数，以避免在具有固定大小整数的语言中出现整数溢出。 

## 方法

 暴力方法每年都会迭代并更新向上和向下三角形的计数。 对于第 0 年，我们有 1 个向上三角形和 0 个向下三角形。 在随后的每一年，每个向上三角形都会产生三个向上三角形和一个向下三角形，而每个向下三角形都会产生一个向上三角形和三个向下三角形。 此过程需要迭代更新 n 年的计数。 然而，由于 n 可以大到 10^18，这种方法需要 10^18 次迭代，这在 2 秒内是不可能的。 

关键的观察是该问题是线性递推关系。 让`U_n`是向上三角形的数量并且`D_n`年 和 时向下三角形的数量。 增长规则给出：```
U_{n+1} = 3 * U_n + 1 * D_n
D_{n+1} = 1 * U_n + 3 * D_n
```这可以表示为矩阵乘法：```
|U_{n+1}|   |3 1|   |U_n|
|D_{n+1}| = |1 3| * |D_n|
```这使我们能够计算`U_n`在 O(log n) 时间内有效地使用矩阵求幂。 这是有效的，因为重复的矩阵乘法恰好对应于迭代线性递归，并且通过平方求幂避免了迭代所有 n 年。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 对于 n 达到 10^18 来说太慢 |
 | 矩阵求幂| O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 定义矩阵`M = [[3,1],[1,3]]`代表向上和向下三角形的重复出现。 
2.定义初始向量`V_0 = [[1],[0]]`对于第 0 年。 
3. 使用快速矩阵求幂来计算`M^n`模 10^9+7。 这避免了每年单独计算。 
4. 乘法`M^n`和`V_0`获得`V_n = [[U_n],[D_n]]`。 该向量的第一个元素是向上三角形的计数。 
5、输出`U_n % 10^9+7`。 

为什么有效：递推是线性的并且完全被 2x2 矩阵捕获。 矩阵求幂正确地累积了应用递归 n 次的效果。 模运算将值保持在整数限制内。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mult(A, B):
    return [
        [(A[0][0]*B[0][0] + A[0][1]*B[1][0]) % MOD,
         (A[0][0]*B[0][1] + A[0][1]*B[1][1]) % MOD],
        [(A[1][0]*B[0][0] + A[1][1]*B[1][0]) % MOD,
         (A[1][0]*B[0][1] + A[1][1]*B[1][1]) % MOD]
    ]

def mat_pow(M, power):
    result = [[1,0],[0,1]]  # Identity matrix
    while power > 0:
        if power % 2 == 1:
            result = mat_mult(result, M)
        M = mat_mult(M, M)
        power //= 2
    return result

def solve():
    n = int(input())
    M = [[3,1],[1,3]]
    if n == 0:
        print(1)
        return
    Mn = mat_pow(M, n)
    U_n = (Mn[0][0]*1 + Mn[0][1]*0) % MOD
    print(U_n)

solve()
```这`mat_mult`函数处理模数下的矩阵乘法，以及`mat_pow`使用平方求幂来有效地计算幂。 将最终矩阵与初始向量相乘得出向上三角形的数量。 我们处理`n=0`分开，以避免不必要的计算。 

## 工作示例

 对于`n = 0`:

 | 步骤| M^n | V_n | U_n |
 | --- | --- | --- | --- |
 | 0 | 我| [[1],[0]] | 1 |

 正如预期的那样，输出为 1。 

为了`n = 1`:

 | 步骤| M^n | V_n | U_n |
 | --- | --- | --- | --- |
 | 1 | [[3,1],[1,3]] | [[3],[1]] | 3 |

 第一年产生三个向上和一个向下的三角形。 

为了`n = 2`:

 | 步骤| M^n | V_n | U_n |
 | --- | --- | --- | --- |
 | 2 | [[10,6],[6,10]] | [[10],[6]] | 10 | 10

 我们看到复发率如预期增长。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(log n) | 每个矩阵乘法都是常数时间，平方求幂使用 log n 乘法 |
 | 空间| O(1) | O(1) | 任何时候都只存储几个2x2矩阵 |

 这可确保解决方案在时间和内存限制内轻松处理高达 10^18 的 n。

 ## 边缘情况

 对于`n = 0`，算法立即输出 1，不执行任何矩阵运算，正确返回初始植物计数。 

对于非常大的`n`例如 10^18，矩阵求幂按对数缩放。 每次乘法仅涉及 2x2 矩阵，因此由于模运算，结果永远不会超过整数限制。 乘以初始向量可确保第一个分量，`U_n`，始终正确地表示模 10^9+7 的向上三角形。
