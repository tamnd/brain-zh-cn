 ## 解决方案
 ## 问题理解

 我们被要求最大化在三个非负实数变量 _x_、_y_ 和 _z_ 上定义的函数，并受到总和约束。 该函数的形式为 _f(x, y, z) = x^a · y^b · z^c_，其中 _a_、_b_、_c_ 是非负整数。 变量必须满足 _x + y + z ≤ S_ 且 _x, y, z ≥ 0_。 输入提供总和限制 _S_ 和指数 _a、b、c_。 输出必须是在对数精度容差范围内最大化函数的三元组 (_x_, _y_, _z_)。 

主要限制是 _S_ 最大为 1000，指数最大为 1000。该函数在每个提升到其指数的变量中以乘法方式增长，因此不可能对所有可能的实数进行简单枚举。 我们需要一种能够有效收敛到最大值的持续优化方法。 问题提出了对数标度，这暗示将乘积转换为对数之和以简化微分。 

不明显的边缘情况包括指数为零，因为在此问题中 0^0 被定义为 1。 例如，如果输入是`S=5`和`a=0, b=0, c=0`，任何 (_x_, _y_, _z_) 的选择总和为 5 都是可接受的，因为该函数的计算结果为 1。另一种边缘情况是某些指数为零而其他指数为正； 例如`S=3`和`a=1, b=0, c=2`需要将所有可能的总和分配给 _x_ 和 _z_，而 _y_ 可以为零。 

## 方法

 强力解决方案将迭代满足总和约束的 _x_、_y_、_z_ 的所有实值并评估 _x^a · y^b · z^c_。 这显然是不可行的，因为域是连续的，甚至离散网格也太细而无法保证所需的精度。 即使步长为 0.001，组合数量也将是天文数字，大约为 (S/0.001)^3，远远超过任何合理的时间限制。 

关键的见解来自使用对数转换函数。 令 _L(x, y, z) = ln(x^a · y^b · z^c) = a ln x + b ln y + c ln z_。 现在我们需要最大化满足 _x + y + z = S_ 的对数线性组合。 这是一个凸优化问题，因为对数的负数是凸的，正权重保持凹性。 使用拉格朗日乘子的方法，我们可以证明，在最大值时，偏导数成比例：a/x = b/y = c/z，这意味着最佳解决方案是将_S_按比例分配给变量的指数。 

如果指数和为零，则所有变量都可以是任意非负数，其总和为 S，因为该函数恒定为 1。否则，解很简单：

 _x = S * a / (a + b + c)_

 _y = S * b / (a + b + c)_

 _z = S * c / (a + b + c)_

 这给出了直接的封闭式解，无需迭代搜索，使得算法的时间和空间为 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((S/ε)^3) | O(1) | O(1) | 太慢了 |
 | 拉格朗日乘子/比例分配| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取总和极限 _S_ 和指数 _a、b、c_。 
2. 计算指数总和，_total = a + b + c_。 这表示在坐标之间分配的总“权重”。 
3. 如果 _total == 0_，则所有指数均为零。 在这种情况下，该函数等于 1，因此任何非负数的三元组之和为 _S_ 都是有效的。 为了方便起见，我们可以输出_(0, 0, S)_。 
4. 否则，按比例分配每个坐标：_x = S * a /total_、_y = S * b /total_、_z = S *c /total_。 这满足了总和约束以及当坐标与其指数成正比时函数最大化的性质。 
5. 以足够的精度打印坐标，以确保满足对数差要求 (10^-6)。 

原理：在线性约束下最大化乘积 x^a · y^b · z^c 可简化为最大化 a ln x + b ln y + c ln z。 该函数在正象限中是严格凹的，因此由导数相等得出的比例分配保证了全局最大值。 如果任何指数为零，则其相应的坐标可以安全地为零，而不影响乘积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

S = int(input())
a, b, c = map(int, input().split())

total = a + b + c

if total == 0:
    # All exponents zero: any allocation works
    x, y, z = 0.0, 0.0, float(S)
else:
    x = S * a / total
    y = S * b / total
    z = S * c / total

print(f"{x:.10f} {y:.10f} {z:.10f}")
```第一个块有效地读取输入。 我们计算指数总和来检测所有指数都为零的简并情况。 在这种情况下，我们返回满足总和约束的任意分配。 否则，我们将每个坐标与其指数成比例地缩放。 打印格式确保浮点精度足以满足问题的容差。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    S = int(input())
    a, b, c = map(int, input().split())
    total = a + b + c
    if total == 0:
        x, y, z = 0.0, 0.0, float(S)
    else:
        x = S * a / total
        y = S * b / total
        z = S * c / total
