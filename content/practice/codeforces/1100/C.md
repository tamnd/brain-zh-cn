 ## 解决方案
 ## 问题理解

 我们正在构建一个非常具体的圆圈配置。 有一个半径为中心的圆$r$。 在它周围，$n$放置相同的圆圈，使其形成一个环。 这些外圆中的每一个都与中心圆相接触，并且每个外圆也都与它的两个相邻的外圆相接触。 

任务是确定半径$R$每个外圆的几何排列都是完全可能的。 

关键约束是外圆的中心位于围绕内圆中心的正多边形上。 一旦我们修好$n$，几何形状是刚性的，所以$R$唯一确定的是$r$。 

限制条件$3 \le n \le 100$和$1 \le r \le 100$足够小，任何常数时间几何公式就足够了。 即使是数值求解的方程也是可以接受的，但问题的结构允许直接三角推导，因此不需要搜索。 

一个常见的错误是假设之间的线性缩放$r$和$R$，或将外圆视为围绕点的独立切圆。 这忽略了一个事实，即外圆同时受到中心切线和邻接的约束，这会强制形成刚性的角间距。 

唯一真正的边缘情况发生在$n$很小，特别是$n = 3$，如果不小心实现，几何形状会变得紧密，并且三角函数中的数值不稳定可能会出现。 

## 方法

 暴力方法会尝试候选半径$R$， 地方$n$均匀地围绕半径圆的点$r + R$，并检查半径是否相邻的圆$R$是相切的。 这可以通过计算相邻中心之间的距离并检查它们是否相等来验证$2R$。 

问题是这变成了一个寻根问题。 对于每一个猜测$R$，我们必须评估几何条件，并且收敛需要迭代搜索，例如二分搜索或牛顿法。 每张支票都是$O(n)$，并且在足够的精度要求下，我们可能需要数十次迭代。 虽然仍然可行，但对于具有封闭形式结构的问题来说，它是不必要的间接。 

关键的观察结果是外圆中心位于半径为$r + R$，等角间隔$\frac{2\pi}{n}$。 相邻圆心之间的距离是这个大圆的弦。 该和弦必须等于$2R$，因为相邻的外圆相切。 

这样我们就得到了一个直接的几何方程：$$2R = 2 (r + R)\sin\left(\frac{\pi}{n}\right)$$这来自弦长公式：弦对角$\theta$在一个半径的圆内$S$有长度$2S\sin(\theta/2)$。 这里$S = r + R$和$\theta = \frac{2\pi}{n}$。 

以代数方式求解方程消除了所有搜索：$$R = (r + R)\sin\left(\frac{\pi}{n}\right)$$

$$R - R\sin\left(\frac{\pi}{n}\right) = r\sin\left(\frac{\pi}{n}\right)$$

$$R(1 - \sin(\frac{\pi}{n})) = r\sin\left(\frac{\pi}{n}\right)$$

$$R = \frac{r\sin(\frac{\pi}{n})}{1 - \sin(\frac{\pi}{n})}$$这种封闭形式是稳定的并且在恒定时间内求值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（二分查找）$R$) |$O(n \log \epsilon^{-1})$|$O(1)$| 已接受但没有必要 |
 | 最优（封闭几何形状）|$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 计算相邻外圆圆心之间的角度步长，即$\frac{\pi}{n}$。 这来自于将全角度减半$\frac{2\pi}{n}$因为弦长使用半角正弦。 
2. 评估$s = \sin\left(\frac{\pi}{n}\right)$。 该值捕获相邻中心相对于其排列的外接圆半径的距离。 
3. 将几何转化为线性方程$R$：相邻中心之间的距离都是$2R$（相切条件）和$2(r+R)s$（弦长条件）。 
4. 解方程$R = (r+R)s$代数上，隔离$R$。 这会产生一个无需迭代的直接公式。 
5. 使用浮点运算计算最终值并以足够的精度输出。 

### 为什么它有效

 整个结构简化为常规$n$由外圆的中心形成的边形。 由于所有外圆都是相同的并且在一个周期中相互相切，因此它们的中心必须位于角间距相等的圆上。 这种刚性对称性迫使单个弦长约束，并且该约束唯一地确定了之间的比率$R$和$r$。 一次不存在替代配置$n$和$r$是固定的。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

n, r = map(int, input().split())

s = math.sin(math.pi / n)
R = (r * s) / (1 - s)

print(R)
```代码直接对推导公式进行编码。 唯一的微妙之处是使用`math.pi / n`而不是`2*pi/n`，因为弦公式取决于半角。 一个常见的实施错误是忘记这种减半并使用完整的中心角，这会导致结果出现系统缩放误差。 

所有计算均以双精度完成，这已经足够了，因为所需的容差为$10^{-6}$，远高于浮点 epsilon。

这些例子展示了该公式如何顺利地适应小型和中等规模的情况$n$，保持几何一致性。

 ## 边缘情况

 对于$n = 3$，该配置成为围绕中心的外圆的最紧密的三角形。 这里$\sin(\pi/3)$很大，所以分母$1 - s$变小，放大浮点灵敏度。 该公式仍然正确运行，因为分子和分母都在稳定的浮点范围内。 

对于大型$n$,$\sin(\pi/n) \approx \pi/n$， 所以$R \approx \frac{r \cdot \pi/n}{1 - \pi/n}$，接近 0 作为$n$成长。 计算保持稳定，因为分子和分母都平滑收缩而没有取消。 

对于中间值，例如$n = 6$，对称性导致精确的简化，例如$\sin(\pi/6) = 1/2$，产生干净的整数结果。 该公式无需特殊的外壳即可处理这些情况，从而确认它均匀地捕获了完整的几何形状。
