 ## 解决方案
 ## 问题理解

 我们有一个池塘`N`一排排的睡莲叶。 每行包含两个可能的着陆位置：左侧和右侧。 在任何时候，一排的恰好一侧都在水面之上并且可以使用。 两只青蛙在第一排之前出发，都需要穿过池塘。 

青蛙永远向前。 它通过降落在当前可用的睡莲叶上来进入一行，当它离开该行时，使用过的睡莲叶下沉，而同一行中的另一个睡莲叶上升。 由于一次只能有一只青蛙占据一个垫子，因此青蛙必须轮流穿过各行。 每当青蛙落在右侧垫上时，总分就会增加一分。 

输入给出行数和每行的初始状态。 输出要求两只青蛙可以获得的最大总分。 

主要限制是`N`足够小，许多解决方案都可以通过，但真正的目标是注意结构。 即使`N`更大，我们应该寻找接近线性时间的解决方案，因为输入本身包含`N`信息片段。 模拟两只青蛙的所有可能的顺序会创建不必要的状态并呈指数增长。 

棘手的部分是青蛙可以选择不同的顺序。 粗心的解决方案可能会尝试根据当前行贪婪地选择哪只青蛙先走，但是为一行选择的顺序会影响第二只青蛙该行的状态。 重要的观察是，每一行对最终分数的贡献都是独立的。 

例如，对于一行：```
1
L
```第一只青蛙落在左边的垫子上，没有得分。 垫翻转，第二只青蛙落在右侧垫上并获得一分。 答案是：```
1
```只计算最初右面焊盘的解决方案将输出`0`，这是错误的。 

另一种边缘情况是每行都以可用的右侧焊盘开始：```
3
RRR
```每行第一只青蛙都得一分。 每次跳跃后，第二只青蛙得到左垫并且不得分。 答案依然是：```
3
```假设两只青蛙应该以某种方式避免连续占据第一位置的解决方案可能会错误地认为分数可以提高。 

## 方法

 一种自然的暴力方法是尝试两只青蛙交错移动的所有可能方式。 有许多可能的顺序，因为在每一行中，任何一只青蛙都可能是第一个到达它的青蛙。 对于每个排序，我们可以模拟行并计算点。 这是正确的，因为唯一重要的决定是哪只青蛙首先到达每一行。 

问题在于，这探索的内容远远超出了必要的范围。 每行谁先走有两种选择，因此可能的订单数最多为`2^N`。 为了`N`大约`100`，这已经是`10^30`无法处理的可能性。 

关键的观察是每一行总是给出一个点。 假设一行当前有可用的左焊盘。 第一个进入的青蛙获得左垫并得分为零。 当它离开时，左边的垫子进入水下，右边的垫子变得可用，所以第二只青蛙得到一分。 如果右侧垫开始可用，则第一只青蛙得一分，第二只青蛙得零分。 在这两种情况下，该行的总贡献恰好是 1。 

由于两只青蛙必须穿过每一行，因此无论初始配置如何，也无论选择的顺序如何，每一行都会贡献一分。 整个问题简化为计算行数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^N * N) | O(2^N * N) | O(N) | 太慢了|
 | 最佳| O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取行数。 答案所需的唯一信息是存在多少行，因为每一行只贡献一个点。 
2. 忽略每行的左侧或右侧配置。 第一个访问一行的青蛙和第二个访问同一行的青蛙总是将它们之间的两个垫分开，因此该行的总得分是固定的。 
3、输出`N`，行数。 

为什么它有效：

 对于每一行，恰好发生两次着陆，每只青蛙一次。 第一次着陆使用当前的浮动垫，第二次着陆使用第一只青蛙离开后变得浮动的垫。 两只青蛙一起访问该行中的两个垫一次，并且这些垫中恰好有一个垫是正确的垫。 因此，每行恰好添加一个点。 将这个固定贡献添加到所有`N`rows 给出了可能的最大分数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    input().strip()
    print(n)

if __name__ == "__main__":
    solve()
```该解决方案只需要行数。 读取描述初始睡莲叶位置的字符串，因为它是输入格式的一部分，但其值不会影响答案。 

不存在边界问题，因为该算法从不索引到字符串。 该实现还避免存储字符串，从而保持内存使用量恒定。 与 Python 的功能相比，输入大小很小，因此快速 I/O 就足够了。

 ## 边缘情况

 对于以以下开头的单行`L`，第一只青蛙到达左侧垫并没有获得任何结果。 离开后，左垫下沉，右垫可用，因此第二只青蛙获得一分。 算法输出`1`，匹配实际最大值。 

对于所有以以下开头的行`R`，第一只青蛙在每一行中获得分数。 第二只青蛙从这些行中没有得到任何分数，因为右边的垫已经下沉了。 该算法输出与总分相匹配的行数。 

对于交替行，例如`LRL`，青蛙可能会根据谁先到达而在不同的行中获得分数。 总数保持不变，因为每一行总是给出一分，所以答案仍然是行数。
