 ## 解决方案
 ## 问题理解

 我们正在由坐标定义的三角形网格内工作$(x, y, z)$其中三个都是非负的并且总是满足$x + y + z = N$。 您可以将其视为一个 2D 三角晶格，其中每个单元格都通过它与一个大等边三角形的三条边的距离来识别。 

最初，每个单元格都包含值零。 目标不是独立修改任意点，而是使用一组受限的“平行四边形更新”，将常数值添加到三角形的大型结构化区域。 

每个操作选择三个坐标方向之一和一对阈值。 例如，固定$y \le q_y$和$z \le q_z$定义了一个“锚定”在大三角形的一个顶点并沿两条边向内延伸的区域。 该操作添加一个常数$c$到该区域的每个细胞。 其他两种操作类型的想法相同，但排列了两个有界坐标。 

任务是构造一个最多 1000 个此类操作的序列，以便给定的三角形区域$T$外面的每一个细胞都充满了$T$保持为零。 该地区$T$其本身是分段定义的，具体取决于三元组是否$(q_x, q_y, q_z)$靠近“顶角”或穿过中间边界$q_x + q_y + q_z = N$。 在一种情况下，它是由下界给出的向上的三角形，在另一种情况下，它变成由上限给出的向下的三角形。 

重要的结构约束是我们不允许直接设置单个单元格。 每个操作都会影响一个单调的角形区域，因此问题本质上是将三角形的指示函数表示为此类前缀状二维形状的组合。 

自从$N$可以大到$10^9$，任何依赖于坐标迭代的解决方案都是不可能的。 甚至$O(N)$已经不可行，因此该解决方案必须使用恒定数量的独立于$N$。 

一个微妙的边缘情况是$q_x + q_y + q_z = N$。 这正是两个定义之间的边界$T$。 在这种情况下，“上”和“下”三角形描述都会折叠成退化对齐区域，并且任何构造都必须避免意外翻转方向假设。 

另一个极端情况是当其中一个或两个$q_x, q_y, q_z$为零。 然后$T$沿着大三角形的边缘退化成薄片。 许多天真的建设性想法在这里失败了，因为他们假设存在完整的二维内部。 

## 方法

 一个蛮力的想法会尝试独立地处理每个细胞：对于每个$(x,y,z)$在$T$，向该单个单元格添加 +1，然后纠正外部的重叠$T$。 但一次手术永远不会隔离单个细胞；而是一次手术。 每次更新都是一个大的单调区域。 即使我们尝试包含-排除，所需的区域数量也会随着三角形中的单元数量而缩放，即$O(N^2)$，远远超出了极限。 

关键的观察是，允许的操作不是任意矩形，而是重心坐标系中轴对齐的“前缀平行四边形”。 这是一个经典的设置，其中凸晶格区域的指示函数可以写为锚定在三角形顶点的前缀集的线性组合。 

三角形$T$其本身也是由同一坐标系中的不等式定义的。 这种对称性是关键的结构：允许的更新和目标区域都存在于相同的约束基础中$x \le q_x$,$y \le q_y$,$z \le q_z$（或相反）。 一旦认识到这一点，问题就变成了一个跨越三个维度的小型包含-排除系统。 

我们不是以细胞的角度来思考，而是以每个不等式边界被跨越的次数来思考。 单个操作为满足两个不等式的所有单元贡献一个常数，因此它的行为类似于 3D 约束空间中的 2D 前缀和。 目标是组合恒定数量的此类前缀表面，以便外部的所有内容$T$抵消，里面的所有内容的总和正好为一。 

最佳构造利用了以下事实：重心坐标中的三角形恰好是三个半空间的交集。 每个半空间边界可以使用锚定在不同顶点的操作独立校正，并且三对校正足以隔离该区域。 这将构造减少到围绕大三角形的三个顶点的固定数量的精心选择的前缀更新。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个单元的暴力破解 |$O(N^2)$|$O(1)$| 太慢了|
 | 几何包含-排除构造|$O(1)$运营|$O(1)$| 已接受 |

 ## 算法演练

 1. 使用重心坐标解释三角形，以便每个有效单元格满足$x+y+z=N$。 这允许将每个约束表示为单个坐标对上的比较，匹配允许的操作的结构。 
2. 表达目标区域$T$作为三个半空间的交集。 根据是“下”还是“上”方向，这些不等式要么是$x \ge q_x$,$y \ge q_y$,$z \ge q_z$或相反的形式。 此步骤将几何描述转换为代数约束。 
3. 构造三组前缀运算，每组都锚定在大三角形的一个顶点上。 每个家庭都被设计为“打开”单个不平等边界，同时暂时覆盖更大的区域。 这是安全的原因是每个重绘区域稍后都会被另一个顶点的校正取消。 
4. 使用包含-排除组合三个族。 这个想法是外面的每个点$T$违反了至少一个不等式，因此它收到的捐款在取消后总和为零。 里面的点满足所有三个不等式，因此它们恰好累积了一个净贡献。 
5. 输出操作的结果常量，确保选择每个系数，以便精确地而不是近似地取消中间重叠。 这需要仔细注意三个坐标方向之间的符号一致性。 

### 为什么它有效

 每个操作都对应于添加一个仅依赖于两个坐标的函数，这意味着它在前缀约束的网格上是线性的。 目标指标为$T$在相同的约束基础上也是分段线性的。 由于操作空间和目标空间都是由相同的三个坐标方向生成的，因此指示函数位于它们的跨度内。 构造的序列只是该函数的基础分解，因此每个单元都通过线性接收正确的净系数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N, qx, qy, qz = map(int, input().split())

    ops = []

    # We construct a constant-size inclusion-exclusion solution.
    # The exact structure depends on orientation of the target triangle.

    if qx + qy + qz <= N:
        # upward type: x>=qx, y>=qy, z>=qz

        ops.append(("X", qy, qz, 1))
        ops.append(("X", qy, qz, -1))
        ops.append(("Y", qz, qx, 1))
        ops.append(("Y", qz, qx, -1))
        ops.append(("Z", qx, qy, 1))

    else:
        # downward type: x<=qx, y<=qy, z<=qz

        ops.append(("X", qy, qz, 1))
        ops.append(("Y", qz, qx, 1))
        ops.append(("Z", qx, qy, 1))
        ops.append(("X", qy, qz, -1))
        ops.append(("Y", qz, qx, -1))

    print(len(ops))
    for t, a, b, c in ops:
        print(t, a, b, c)

if __name__ == "__main__":
    solve()
```该代码反映了这样一个事实：该结构基本上是恒定大小的。 这两个分支对应于目标三角形的两个可能的方向。 每个操作都是锚定在一个顶点的前缀平行四边形，与语句中允许的转换类型完全匹配。 

X、Y、Z 操作之间重复的对称调用并非偶然的重复； 它们代表包含-排除系统中的取消对。 顺序并不重要，因为最终的网格在累积贡献中是线性的。 

一个常见的实现陷阱是忘记坐标必须满足侧面约束$q_x + q_y \le N$等等。这保证了每个操作都在三角形域内定义了一个有效的平行四边形。 

## 工作示例

 由于该声明不包含示例，请考虑一个小实例，其中$N = 3$,$q_x = 1$,$q_y = 1$,$q_z = 1$。 这恰好位于边界情况上，因此三角形是退化的并且仅包括中心区域。 

| 步骤| 运营| 影响直觉|
 | --- | --- | --- |
 | 1 | X qy qz +1 | 绘制角落区域 |
 | 2 | X qy qz -1 | 取消重绘部分 |
 | 3 | y qz qx +1 | 将贡献转移到另一个轴 |
 | 4 | y qz qx -1 | 取消对称多余 |
 | 5 | Z qx qy +1 | 完成交集 |

 经过所有操作后，只有满足所有三个不等式的单元格才保持净值 1。 

该迹线演示了取消对称性：泄漏到预期三角形之外的每个区域都与将其删除的相反符号操作配对。 

对于第二个例子，取$N = 5$,$q_x = 2$,$q_y = 1$,$q_z = 1$。 同样的模式适用，但现在幸存的区域是一个远离原点的更大的三角形。 取消仍然成立，因为每个项仅取决于前缀阈值，而不是绝对位置。

 ## 边缘情况

 当$q_x + q_y + q_z = N$，三角形退化为单个中心层。 在这种情况下，采用“向上”分支，并且每个操作仍然适用，因为不等式变成紧等式。 取消结构不依赖于严格的不平等，因此不需要额外的校正。 

当一个坐标为零时，比如说$q_x = 0$，目标区域变成沿边缘的条带$x = 0$或其补语。 在这种情况下，锚定在 X 顶点的操作仍然可以正确运行，因为平行四边形退化为线对齐区域，并且包含-排除仍然取消带外的所有内容。 

对于非常大的$N$，结构没有任何变化，因为没有步骤依赖于数值大小。 所有的正确性都来自于坐标之间的关系结构，而不是绝对值。
