 ## 解决方案
 ## 问题理解

 每栋房子都位于网格位置$(r,c)$。 

一座塔放置在$(R,C)$覆盖每一个满意的房子$$C \le c$$和$$r+c \le R+C.$$这座塔的成本很简单$R$，其行。 

对于每一个$k$从$1$到$n$，我们必须计算覆盖每间房屋所需的最小总成本，最多使用$k$塔。 

第一个挑战是了解塔覆盖范围的几何形状。 该条件仅取决于两个量：$$x=c,\qquad y=r+c.$$在这些坐标中，一座带有参数的塔$$X=C,\qquad Y=R+C$$完全覆盖了房屋$$x \ge X,\qquad y \le Y.$$因此，塔对应于轴对齐的优势区域$(x,y)$飞机。 

输入大小达到$2\cdot10^5$，因此任何涉及房屋之间的成对比较或所有区间内的动态规划的解决方案都是立即不可能的。 我们周围需要一些东西$O(n\log n)$。 

一个微妙的点是，每当另一栋房子被覆盖时，一些房子就会自动被覆盖。 

考虑：```
(1,1)
(2,2)
```它们变换后的坐标为：```
(1,2)
(2,4)
```覆盖第二栋房子并不意味着覆盖第一栋房子。 但如果我们有```
(1,2)
(1,1)
```从而成为```
(2,3)
(1,2)
```然后覆盖$(1,2)$自动覆盖$(2,3)$。 如果一个解决方案保留所有房屋而不删除这些控制点，就会错过问题的关键结构。 

当添加额外的塔没有帮助时，会出现另一种边缘情况。 

例子：```
3
3 5
1 3
2 3
```答案是```
5 5 5
```使用更多塔并不会降低成本，因为所有有用的削减位置已经具有非负贡献。 始终使用精确的解决方案$k$塔会错误地产生较小的值。 

## 方法

 从最直接的想法开始。 

假设我们按列对房屋进行排序$c$。 我们可以尝试将每个分区分组，计算覆盖每个组的最便宜的塔，然后按时间间隔运行动态规划解决方案。 

对于一组房屋来说，最便宜的覆盖塔必须满足$$C \le \min c,
\qquad
R+C \ge \max(r+c).$$选择较大的值只会增加成本，因此一组的最优成本为$$\max(r+c)-\min(c).$$这一观察使得间隔成本易于计算。 

问题是分区 DP 超过$n\le 2\cdot10^5$是无望的。 甚至$O(n^2)$间隔处理远远超出了极限。 

关键的观察来自于主导地位。 

让$$x_i=c_i,\qquad y_i=r_i+c_i.$$排序方式$x$。 

如果一个点稍后出现并且有$$y_{\text{later}}\le y_{\text{earlier}},$$然后覆盖前一点会自动覆盖后一点。 后面一点永远不会影响答案，可以丢弃。 

去除所有支配点后，剩余点满足$$x_1<x_2<\cdots<x_m,$$

$$y_1<y_2<\cdots<y_m.$$现在每个幸存的点都位于严格增加的楼梯上。 

对于任何连续的块$[l,r]$，其成本变为$$y_r-x_l,$$因为$y_r$是最大值$y$和$x_l$是最小值$x$。 

假设我们用一座塔覆盖所有剩余的点。 成本是$$y_m-x_1.$$如果我们在位置之间切换$i$和$i+1$，总成本变化$$(y_i-x_{i+1}).$$这是关键的简化。 

每一次切割都是独立贡献的。 

如果我们选择多个切割位置，则总成本为$$(y_m-x_1)
+
\sum (y_i-x_{i+1}).$$那么问题就变成了：

 最多选择$k-1$从中截取值$$d_i=y_i-x_{i+1}$$以最小化总和。 

最好的选择就是最小的切割值。 

一旦全部$d_i$已知，对它们进行排序，构建前缀和，并回答每个$k$从这些前缀和中。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 强力间隔 DP |$O(n^2)$或者更糟|$O(n^2)$| 太慢了|
 | 优势减少+排序削减|$O(n\log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1.将每栋房子都变成点$$(x,y)=(c,r+c).$$1. 对所有点进行排序$x$上升。 
2. 删除支配点。 

从左到右扫描，同时保持最大$y$到目前为止所看到的。 仅保留一个点$y$严格大于之前的每一个$y$。 

这一步之后，两个坐标都严格递增。 
3. 设剩余点为$(x_1,y_1),\dots,(x_m,y_m)$。 

用一座塔覆盖所有东西的成本是$$base=y_m-x_1.$$1. 对于每个相邻对，计算$$d_i=y_i-x_{i+1}.$$每个$d_i$表示因在那里进行切割而产生的额外成本。 

1.全部排序$d_i$。 
2. 构建前缀和$$pref[0]=0,
\qquad
pref[i]=d_1+\cdots+d_i.$$1.让$$best[i]=\min(best[i-1],pref[i]).$$这存储了最多使用的最小可实现总和$i$削减。 

1. 对于每一个$k$从$1$到$n$:

 可用切割数量不能超过$m-1$，所以让$$t=\min(k-1,m-1).$$答案是$$base+best[t].$$### 为什么它有效

 除去支配点后，剩下的每一点都是必不可少的。 任何有效的解决方案都会将该递增序列划分为连续的块。 

一个区块的成本$[l,r]$正是$y_r-x_l$。 对所有块求和会导致每个内部边界独立贡献为$y_i-x_{i+1}$。 不同剪切之间不存在交互作用。 

因为每次切割都是独立贡献的，所以最优解的极限为$k-1$通过选择最小的切割值来获得切割。 如果某个切割值为正，我们就不会采用它，因为问题允许使用少于$k$塔。 

这与算法产生的值完全匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

pts = []
for _ in range(n):
    r, c = map(int, input().split())
    pts.append((c, r + c))

pts.sort()

x = []
y = []

mx = -1
for cx, cy in pts:
    if cy > mx:
        x.append(cx)
        y.append(cy)
        mx = cy

m = len(x)

base = y[-1] - x[0]

cuts = []
for i in range(m - 1):
    cuts.append(y[i] - x[i + 1])

cuts.sort()

pref = [0]
for v in cuts:
    pref.append(pref[-1] + v)

best = [0] * len(pref)
best[0] = 0
for i in range(1, len(pref)):
    best[i] = min(best[i - 1], pref[i])

ans = []
for k in range(1, n + 1):
    t = min(k - 1, m - 1)
    ans.append(str(base + best[t]))

print(" ".join(ans))
```第一部分将每个房屋转换为变换后的坐标$(c,r+c)$。 

优势移除扫描是最重要的实现细节。 仅当一个点被保留时$y$价值超过之前的每一个$y$。 每当主点被覆盖时，任何被丢弃的点都保证被覆盖。 

压缩后，楼梯属性自动保持。 切割的成本仅取决于相邻的幸存点，因此我们计算所有值$y_i-x_{i+1}$，对它们进行排序，并构建前缀和。 

数组`best`是必要的，因为问题要求**至多**$k$塔。 如果下一个截断值为正，则采用它会增加答案。`best[i]`存储最多长度的所有前缀中的最小前缀和`i`，它精确地模拟了使用更少塔的自由度。 

所有算术都适合 64 位有符号整数，但 Python 整数会自动处理它。

 ## 边缘情况

 考虑：```
3
5 5
4 4
3 3
```变换后的点为：```
(3,6)
(4,8)
(5,10)
```排序后，每个点都不支配后面的点，因此所有点都保留下来。 截断值为正：```
2
3
```任何削减都会增加成本。 这`best`数组在任何地方都保持为零，因此每个答案都等于一塔答案。 这正是“最多$k$塔”的要求。

 现在考虑：```
3
3 5
1 3
2 3
```变换后的点为：```
(3,4)
(3,5)
(5,8)
```重点$(3,4)$是由$(3,5)$，所以它消失了。 剩余的楼梯仅包含两个点，产生零的单个切割值。 添加更多塔不会改变成本，从而产生：```
5 5 5
```与示例输出匹配。
