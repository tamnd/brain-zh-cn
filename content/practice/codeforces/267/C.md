 ## 解决方案
 ## 问题理解

 我们有一个连接少量交叉路口的有向道路系统。 每条道路都有容量，这意味着无论方向如何，都可以分配给它的总交通量最大。 关键的自由度是道路上的交通可以在任一方向上分割，由有符号值表示：如果遵循输入方向则为正，否则为负。 

该系统不是任意的。 它的行为类似于保守流场：每个中间连接点都保留流量，因此除入口节点 1 和出口节点 n 外，总流入量等于总流出量。 除此之外，还有更强的结构约束：在任意两个节点之间，沿任意路径的流量“积分”都是路径无关的。 这相当于说流量可以表示为节点上势函数的差异，这立即意味着每个可行的解决方案完全由节点势而不是逐边独立流决定。 

任务是最大化离开节点 1 的总流量（这将等于进入节点 n 的流量），同时为每个边分配有效的签名流，同时考虑容量约束和潜在的一致性结构。 

约束足够严格，任何二次或三次边数都是可接受的，但任何图结构上的指数则不可接受。 由于有多达 100 个节点和 5000 个边，我们被迫采用线性代数或最短路径式推理，而不是组合枚举。 

如果我们尝试通过贪婪或局部流量调整独立处理边缘，则会出现微妙的失败情况。 例如，如果两个节点之间存在多条平行道路，则独立分配它们可能会违反全局潜在一致性条件，即使每条边都尊重其容量。 另一种故障模式是假设任意可行流：不允许势循环，除非它们对应于零净差，而朴素的最大流公式并不强制执行。 

## 方法

 暴力视图会尝试为每条边分配一个流变量，并直接强制执行所有约束：节点处的流守恒、边上的容量约束以及路径和的一致性。 这导致了一个具有不等式的线性方程组，本质上是一个包含多达 5000 个变量的大型线性程序。 直接通过通用 LP 方法解决它在理论上是正确的，但鉴于结构太慢且不必要。 

关键的观察是，路径独立条件迫使节点电势的存在，使得每个边流都是其端点之间的电势差。 也就是说，每个有效的配置都可以写成图上的梯度场。 这将整个问题简化为在从每个边容量导出的间隔约束下查找节点值。 

u 和 v 之间的每条边都限制 |pot[u] − pot[v]| 的差值 ≤c。 目标变成最大化从源到汇的净流量，这对应于最大化 pot[1] − pot[n] 直至缩放。 因为约束是同构且对称的，所以我们可以固定 pot[1] = 0 并计算受不同约束的最大可行 pot[n]。 这相当于找到最长的可行潜在间隙，这减少了变换图中的最短路径计算，其中每条边都施加两个方向的不等式。 

因此，问题变成了一个差异约束系统，可以使用最多 100 个节点的图中的最短路径来解决。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 线性规划公式| 指数/超多项式 | O(米) | 太慢了 |
 | 通过最短路径的差异约束| O(纳米) | O(n + m) | 已接受 |

 ## 算法演练

我们将每条边重新解释为节点电位的两个约束。 对于一条边 (u, v, c)，我们有 v − u ≤ c 和 u − v ≤ c，它们成为约束图中的两条有向边。 

1. 为每个节点v引入一个势值dist[v]，表示其在一致势场中的位置。 我们修复 dist[1] = 0 以消除翻译歧义。 
2. 对于每条道路 (u, v, c)，添加两个有向约束：dist[v] ≤ dist[u] + c 和 dist[u] ≤ dist[v] + c。 这些强制限制了两个方向的容量。 
3. 为了计算最大可行配置，我们求解该约束图中从节点 1 开始的最短路径。 每个松弛步骤都确保我们尊重潜在差异的所有上限。 
4. 我们从节点 1 运行 Bellman-Ford，因为该图可能包含任意权重，但有效实例中不应存在负循环。 
5. 收敛后，dist[n]表示在所有约束条件下与节点1的最大可能一致电位差，等于最大流量值。 
6. 对于每条边，实际流量可以重构为 dist[u] − dist[v]（或其负值，具体取决于方向），因为流量等于潜在下降。 

为什么它有效：由所有边约束定义的可行性区域正是形成类似度量空间的节点势的集合。 Bellman-Ford 计算这些约束的最严格的上包络线。 因为每个有效的解决方案必须满足由边引起的所有成对边界，所以计算出的势是最大化源和汇之间的分离的极值一致分配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    m = int(input().strip())

    edges = []
    adj = [[] for _ in range(n + 1)]

    for _ in range(m):
        u, v, c = map(int, input().split())
        edges.append((u, v, c))
        adj[u].append((v, c))
        adj[v].append((u, c))

    INF = 10**18

    dist = [0] * (n + 1)

    # Bellman-Ford-like relaxation (difference constraints)
    # We want the maximum feasible distances, so we relax using min constraints on negated system.
    for _ in range(n):
        updated = False
        for u, v, c in edges:
            if dist[v] > dist[u] + c:
                dist[v] = dist[u] + c
                updated = True
            if dist[u] > dist[v] + c:
                dist[u] = dist[v] + c
                updated = True
        if not updated:
            break

    # Now compute answer as maximum possible separation
    ans = 0
    for i in range(1, n + 1):
        ans = max(ans, dist[i] - dist[1])

    # reconstruct flows
    flows = []
    for u, v, c in edges:
        flows.append(dist[u] - dist[v])

    print(f"{ans:.5f}")
    print("\n".join(f"{x:.5f}" for x in flows))

if __name__ == "__main__":
    solve()
```该实现维护单个节点电位数组并重复强制边缘一致性。 每次松弛都确保没有边在任一方向违反其容量引起的界限。 流重构利用电势差，自动满足反对称性：反转边会翻转流的符号。 

一个常见的微妙之处是我们没有显式存储与方向相关的流变量； 这样做会过度参数化系统并破坏结构。 一切都源自节点电位。

 ## 边缘情况

 一种边缘情况是多个平行边连接具有不同容量的相同节点。 在这种情况下，最严格的约束占主导地位，但重复松弛可确保达到最小界限，无论输入顺序如何。 该算法自然收敛，因为每次更新只会减少距离。 

另一个边缘情况是具有一致容量的节点循环。 由于所有约束都是对称边界，因此不会出现负循环，并且 Bellman-Ford 在最多 n 次迭代后稳定。 由此产生的电势在所有循环路径上保持一致，自动保持路径独立性。
