 ## 解决方案
 ## 问题理解

 我们得到一棵树，意味着一个没有循环的连通图，我们想决定它是否可以被视为“曼哈顿树”。 定义属性不是关于显式提供的距离或坐标，而是关于树的结构是否与使用曼哈顿式邻接在 2D 整数网格上绘制兼容，其中边的行为类似于网格连接。 

在网格上，每个点最多有四个自然方向来连接到邻居，上、下、左、右。 该几何约束直接转化为对可以嵌入其中的任何树的结构约束：任何顶点都不能具有超过四个关联边。 然而，仅仅这个条件是不够的，因为分支在平面网格嵌入中相互作用的方式对有多少高度顶点可以共存以及分支链如何在不冲突的情况下传播施加了更严格的限制。 

任务是读取树并确定其结构是否属于允许的配置的小系列。 约束足够大，输入树最多可以有大约 200,000 个节点，因此任何解决方案都必须在线性时间内运行。 这立即排除了任何涉及尝试所有嵌入、几何模拟或布局组合枚举的情况。 

天真的尝试可能会尝试为节点分配坐标，同时尊重沿边缘的曼哈顿距离。 这样的模拟很快就会变得模糊不清。 例如，在一棵形状像五片叶子的星形树中，人们可能会尝试将中心放置在四个方向上并展开分支，但任何额外的分支都会打破网格容量限制。 类似地，具有多个分支顶点的树很容易在方向分配中产生矛盾，即使每个节点在本地看起来都是可行的。 

当度数很小但分支结构仍然与网格嵌入不兼容时，就会出现微妙的边缘情况。 例如，考虑一棵树，其中两个顶点的度数均为 3，并且它们的分支子树以总共需要四个以上方向的方式交错。 如果不考虑全局分类结构，仅单纯的程度检查可能会错误地接受或拒绝此类情况。 

该问题的关键在于有效的曼哈顿树不是任意有界度树。 它们属于极少数的全局结构模式，识别这些模式可以将问题简化为简单的计数和分类。 

## 方法

 暴力方法会尝试在网格上构建树的实际嵌入。 从任意根开始，我们可以递归地为边分配方向，尝试将每个子项放置在四个曼哈顿方向之一，同时确保不会发生冲突。 每个放置决策都会将约束传播到子树，并且每当出现冲突时就需要回溯。 

这种方法原则上是正确的，因为它直接模拟了有效嵌入的定义。 然而，每个分支顶点都会引入多种选择，并且在最坏的情况下，具有许多分支点的树会导致指数数量的方向分配。 即使进行修剪，搜索空间也会增长得非常快，这对于大树来说是不可行的。 

关键的观察是我们实际上并不需要坐标。 问题陈述已经将有效树限制为一小组结构签名。 这些特征源于这样一个事实：在网格中，分支受到严重限制：大多数节点只能位于链上，并且只有少数顶点可以充当分支连接点。 一旦我们分析了存在多少个 3 或 4 度的顶点，以及它们如何连接，我们发现所有有效的树都分为四类。

一棵有效的曼哈顿树必须是以下其中一种：每个节点的度数最多为 2 的纯链、仅具有一个 3 或 4 度的分支节点的树、或者恰好具有两个以链状结构连接的 3 度的分支节点的树。 任何额外的分支都会立即迫使网格中出现不可能的布局。 

因此，问题简化为计算度数并检查有多少顶点超过度数 2，以及是否有任何顶点超过度数 4。

 | --- | --- | --- | --- |
 | 强力嵌入搜索 | O(4^n) | O(4^n) | O(n) | 太慢了|
 | 基于学位的分类| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取树并通过扫描所有边来计算每个顶点的度数。 这给出了每个节点有多少个连接的本地度量，这直接对应于我们尝试嵌入它时需要多少个网格方向。 
2. 检查是否有任何顶点的度数大于4。如果存在这样的顶点，则该树无法嵌入到网格中，因为任何点上只有四个可用的曼哈顿方向。 在这种情况下，我们立即拒绝。 
3. 计算有多少个顶点的度数至少为 3。这些是分支点，因为 2 度顶点的行为类似于直线，而 1 度顶点是端点。 
4. 如果没有 3 度或以上的顶点，则该树是简单路径。 通过将节点放置在网格上的直线上，这始终是可嵌入的。 
5. 如果恰好有一个 3 级或以上的顶点，我们接受。 该顶点可以作为中心结点，所有的链都可以在不同的网格方向上向外延伸而不会发生冲突，只要其度数不超过4即可。 
6. 如果正好有两个度数为 3 或更高的顶点，我们检查该结构是否仍然与两个分支点的链一致。 在树中，这一点自动成立，因为任何两个节点之间都只有一条路径，因此该结构被迫成为连接两个分支节点的线性主干。 
7. 如果有两个以上的分支顶点，则拒绝，因为网格嵌入在不强制重叠或方向重用的情况下无法容纳两个以上的真实分支结点。 

### 为什么它有效

 关键的不变量是，将树有效嵌入到曼哈顿网格中必须为与分支顶点相关的每条边分配不同的网格方向，并且每个节点全局上只有四个可用的此类方向。 一旦两个以上的顶点需要同时分支，该结构就会在沿着共享路径的方向分配中产生矛盾。 由于树在任何两个节点之间都有唯一的路径，因此只能以线性排列支持分支点，这将一致嵌入中的分支点数量限制为最多两个。 上面使用的程度分类准确地体现了这种结构限制。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    if n == 1:
        print("YES")
        return

    deg = [0] * (n + 1)

    for _ in range(n - 1):
        u, v = map(int, input().split())
        deg[u] += 1
        deg[v] += 1

    for d in deg:
        if d > 4:
            print("NO")
            return

    big = sum(1 for d in deg if d >= 3)

    if big > 2:
        print("NO")
    else:
        print("YES")

if __name__ == "__main__":
    solve()
```实现首先从边列表计算度数。 这是唯一需要的结构信息，它完全确定树是否适合允许的曼哈顿配置之一。 

对大于 4 的度数的检查会提前应用，因为它立即违反了网格约束。 之后，计算度数至少为 3 的顶点即可识别所有分支点。 最终的决定纯粹基于存在多少个这样的顶点，与算法中得出的分类相匹配。 

该逻辑不需要对树进行生根或执行超出度数累积的任何遍历，这使解决方案保持线性和鲁棒性。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input())
    deg = [0] * (n + 1)

    for _ in range(n - 1):
        u, v = map(int, input().split())
        deg[u] += 1
        deg[v] += 1

    if n == 1:
        return "YES"

    for d in deg:
        if d > 4:
            return "NO"

    big = sum(1 for d in deg if d >= 3)
    return "YES" if big <= 2 else "NO"

# minimum size
assert run("1\n") == "YES"

# simple chain
assert run("5\n1 2\n2 3\n3 4\n4 5\n") == "YES"

# star with 5 leaves (invalid)
assert run("6\n1 2\n1 3\n1 4\n1 5\n1 6\n") == "NO"

# two branching nodes
assert run("5\n1 2\n1 3\n2 4\n2 5\n") == "YES"
```| 测试输入| 预期产出 | 它验证了什么 |

 ## 边缘情况

 单节点树是有效的，因为它简单地满足所有度数约束，并且算法正确地返回 YES，因为没有顶点违反度数限制并且没有分支点可供计数。 

有五片叶子的星星暴露了 4 度边界条件。 中心节点的度数为 5，在任何进一步推理之前立即触发拒绝。 该算法通过显式度检查尽早发现了这一点。 

恰好具有两个分支顶点的树演示了预期的非平凡接受情况。 即使两个节点的度数为 3 或更高，该结构仍然是具有两个连接点的有效线性主干，并且计数条件允许它无需进一步的结构模拟。
