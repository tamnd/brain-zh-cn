 ## 解决方案
 ## 问题理解

 我们得到了一行由大整数索引的房屋，以及沿着这条线的多组柱形位置。 多个酒吧可以占据同一栋房子，但每个酒吧都被视为一个单独的点。 

对于任何候选房屋$x$，我们将成本函数定义为从$x$到所有剩余的酒吧。 选择之前$x$，我们最多允许删除$k$酒吧。 删除后，我们计算最佳成本函数并考虑所有位置$x$最小化绝对距离的总和。 任务是计算有多少个不同的整数位置$x$在某些有效的删除策略下可以变得最优。 

关键的隐藏结构是最小化绝对偏差之和仅取决于剩余多重集的中位数。 一旦我们删除一些条形，最优的$x$始终是剩余点的中值间隔。 因此问题是：最多可以将多少个整数作为删除后得到的某个子集的中值$k$元素。 

约束意味着$n$总和为$10^5$，所以每次测试我们大约需要$O(n \log n)$或排序后呈线性。 任何二次或枚举所有删除都是不可能的，因为子集的数量是指数级的$n$。 即使尝试所有选择$k$要删除的条已经是组合的。 

一个天真的陷阱是假设我们必须选择一个“最佳子集”并计算其中值。 那错过了不同的$x$在不同的删除策略下，值可能是最优的，因此解决方案必须聚合所有可实现的中位位置，而不是一种配置。 

当所有条形都相同时，边缘情况直觉很重要。 例如，如果所有$a_i = 5$，那么每次删除仍然使所有点都为 5，所以只有$x = 5$作品。 另一个微妙的情况是当$k$足够大，可以完全移除一侧，使极端位置变得可行； 这就是区间扩展发生的地方。 

## 方法

 暴力法会尝试所有方法来删除最多$k$条形图，然后计算剩余多重集的中值间隔。 对于每个子集，我们将添加所有有效的中位位置。 这立即失败，因为子集的数量是$\sum_{i=0}^k \binom{n}{i}$，这是指数关系$n$。 即使是为了$n = 10^5$，这是不可行的。 

结构洞察力来自于按排序顺序重写问题。 对条形位置进行排序后，任何中位数都由索引的中间部分确定。 删除条对应于以最佳配置从该排序数组的末端删除元素，因为删除内部点不能比删除极值更有效地扩展可能的中值区间。 

于是，问题就变成了：我们要选择一个剩余大小的窗口$m = n - t$在哪里$0 \le t \le k$，并考虑此类窗口的所有可能的中值区间。 当大小为偶数时，多重集的中位数不是单个点； 它成为两个中间元素之间的间隔。 当我们改变哪些$t$元素被删除，我们有效地滑动了一个窗口，同时还允许通过删除来扩展端点。 

这简化为计算我们可以将中心区域周围的中值范围扩大多远。 最终答案成为所有允许删除的所有可行中值间隔的并集，这可以通过分析可以从排序数组的左侧和右侧丢弃多少个元素来计算，同时仍保留至少一半的元素。 

我们将问题简化为寻找一个区间$[L, R]$在已排序的数组中，存在一个有效的子集，其中中位数位于$a_L$和$a_R$。 端点取决于我们分配给每一侧的删除数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(\sum \binom{n}{k})$|$O(n)$| 太慢了 |
 | 最佳 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 对柱位置数组进行排序。 排序是必要的，因为中位数仅取决于顺序，而不取决于原始位置。 
2.让$n$是条形的数量。 对于固定的最终子集大小$m = n - t$，中值区域由指数确定$\left\lfloor \frac{m-1}{2} \right\rfloor$和$\left\lceil \frac{m-1}{2} \right\rceil$在已排序的子集中。 这表明每个有效中位数对应于删除后排序的原始数组的某个连续段。 
3.观察到删除有效地允许我们忽略最多$k$任何位置的元素，但为了最大化可能的中位数范围，最好在排序数组的极端处使用删除。 删除内部元素不会比删除边界元素更多地扩展可达中值。 
4.让$m = n - k$。 这是可能的最小剩余尺寸。 在这种情况下，中值间隔最大化，因为较小的子集在其中值位置上具有更大的不确定性。 
5. 有效中位位置对应于所有大小的窗口$m$在已排序的数组中。 每个窗口根据奇偶性贡献一个或两个中值候选者$m$。 这些间隔的并集给出了值空间中的连续段。 
6. 答案归结为计算所有有效窗口的最小可能中位数和最大可能中位数之间的间隔中有多少个整数值。 这些极端情况是通过采用最左边窗口和最右边窗口的大小来实现的$m$。 
7. 计算：

 -$L = a[\lfloor (n-k-1)/2 \rfloor]$-$R = a[n - 1 - \lfloor (n-k-1)/2 \rfloor]$那么答案就是$R - L + 1$。 

### 为什么它有效

 任何多重集的中位数仅取决于排序顺序中的中间元素。 Since we are allowed to remove at most$k$元素，我们可以通过从任一侧删除来移动占据中间位置的元素。 通过将尽可能多的小元素推出中值窗口的右边界和将尽可能多的大元素推出左边界来获得极端中值。 任何内部删除策略都不能超过这些极端，因为它会消耗删除预算，而不会比边界删除更有效地移动中值索引。 因此，可达中位数恰好形成按排序顺序的连续段。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()

        m = n - k
        mid = (m - 1) // 2

        L = a[mid]
        R = a[n - 1 - mid]

        print(R - L + 1)

if __name__ == "__main__":
    solve()
```排序步骤建立了用于推理中位数的固定顺序。 变量$m = n - k$表示我们必须考虑的最小子集大小，因为删除更多元素只会降低灵活性。 

关键的实现细节是使用相同的中点偏移$mid = (m-1)//2$从阵列的两端。 这种对称性捕获了可实现的最小和最大中间位置。 最后的减法$R - L + 1$计算可行区间内的整数房屋位置。

 ## 边缘情况

 关键的边缘情况是所有值都相同。 用于输入`[5,5,5,5]`与任何$k$，删除元素不会改变中值。 该算法对数组进行排序并计算$mid$，但两者都$a[mid]$和$a[n-1-mid]$等于 5，产生答案 1，匹配唯一可行的房子。 

另一个边缘情况是当$k = n-1$。 删除除一根柱线以外的所有柱线后，任何剩余元素都是中位数。 该公式简化为$mid = 0$， 所以$L = a[0]$和$R = a[n-1]$，这意味着每个原始值都可以作为单个中位数来实现，从而正确地产生可能结果的全部分布。 

第三种情况是高度倾斜的分布，例如`[1,1,1,100,100,100]`有适度的$k$。 该算法正确地认识到，删除一些极值点无法将中值移动到两个簇的中心重叠之外，因为中点索引边界仍然由排序位置而不是绝对值锚定。
