 ## 解决方案
 ## 问题理解

 我们得到一串恰好有 10 位数字的字符串，表示满足“美观”条件的电话号码：第一个数字至少为 9，第二个数字至少为 8，依此类推，直到最后一个数字，至少为 0。Vadim 希望重新排列这些数字，以形成仍满足相同美观条件的数字最小的数字。 每个测试用例都提供一个漂亮的电话号码，我们需要为每个测试用例进行最小的重新排列。 

约束告诉我们最多可以有 10,000 个测试用例，并且每个字符串的长度固定为 10。这意味着任何算法对于每个测试用例都必须运行得非常快。 一种生成全部 10 个的暴力方法！ 数字排列是完全不可行的，因为 10! 是3,628,800，乘以10,000例，就变成了数十亿次运算。 由于字符串很短并且操作是简单的比较和重新排列，因此每个字符串的 O(n²) 或更好的方法是可以接受的。 

一个重要的边缘情况是多个数字满足相同的最小要求值。 例如，如果输入是`9988776655`，天真的从左到右的贪婪选择可以选择第一个“9”，而不检查稍后移动它是否会允许较小的数字。 正确的做法必须全局考虑数字计数，确保数字最小。 

另一个微妙的边缘情况是数字完全符合最低要求。 例如，`9899999999`已经有数字不能向左移动而不违反美观条件。 任何算法都必须处理此类情况，而不尝试不必要的交换。 

## 方法

 强力解决方案将生成数字的所有排列，过滤出那些漂亮的排列，并选择最小的排列。 虽然原则上是正确的，但这需要 10 个！ 检查每个测试用例，这对于 10,000 个测试用例来说太慢了。 每次检查都需要扫描所有 10 位数字来验证美观状况，每个测试用例大约需要 3600 万次操作。 这很快就超出了实际限制。 

有效解决方案的关键见解是美丽条件为每个位置施加了明确的最小值。 因此，我们不需要所有的排列，只需要确保每个位置得到满足其要求的最小可用数字即可。 这将问题简化为贪婪计数方法：计算每个数字有多少个，对于从左到右的每个位置，选择至少是所需的最小值且仍然可用的最小数字。 计数使我们能够有效地处理多个相同的数字，并保证最小的数字，因为每个位置都填充了尽可能少的有效数字。

 ## 算法演练

 1.初始化一个数组`count`大小为 10 来记录输入字符串中每个数字的频率。 这使我们能够快速检查哪些数字仍可用于放置。 
2.定义一个数组`min_required`含有`[9, 8, 7, 6, 5, 4, 3, 2, 1, 0]`，表示每个位置的最小允许值。 
3.初始化一个空字符串`result`这将保存最终重新排列的电话号码。 
4. 对于每个位置`i`从 0 到 9，迭代所有数字`min_required[i]`最多 9 个，按升序排列。 选择剩余计数为正的第一个数字。 
5. 将所选数字附加到`result`并减少其计数`count`。 
6. 处理完所有位置后，`result`字符串代表最小的漂亮电话号码。 

为什么有效：贪心选择满足仓位最小值的最小可用数字可确保仅在没有更小的选项可用时才使用任何较大的数字。 由于每个选择只考虑可行的数字并使用计数来避免重复，因此最终的数字既尊重美观条件又尊重数字最小化。 任何重新排列都不会产生更小的数字，因为每个最左边的数字都按顺序最小化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def smallest_beautiful_number(s):
    count = [0]*10
    for ch in s:
        count[int(ch)] += 1

    min_required = [9,8,7,6,5,4,3,2,1,0]
    result = []
    for i in range(10):
        for d in range(min_required[i], 10):
            if count[d] > 0:
                result.append(str(d))
                count[d] -= 1
                break
    return ''.join(result)

t = int(input())
for _ in range(t):
    s = input().strip()
    print(smallest_beautiful_number(s))
```功能`smallest_beautiful_number`首先计算数字，然后从左到右迭代，用最小的有效数字填充每个位置。 内部循环确保我们为每个位置选择最小选项，这就是输出全局最小化的原因。 使用计数数组可以防止选择已放置的数字。 这`min_required`为了清晰和正确，数组显式地编码了美丽条件。
