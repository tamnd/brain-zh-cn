 ## 解决方案
 ## 问题理解

 我们被要求在一个工作周内安排三天休息时间$n$，最后一天固定为休息日。 剩余两天的休息日不得连续，也不得与一周的第一天和最后一天连续。 目标是使工作段（休息日之间的连续天数）的长度尽可能不同。 形式上，如果线段有长度$l_1, l_2, l_3$，我们想要最大化三对之间的最小差异$|l_1 - l_2|, |l_2 - l_3|, |l_3 - l_1|$。 输入是单个整数$n$每个测试用例，输出是该最小差异的最大可实现值。 

约束条件$6 \le n \le 10^9$立即排除任何迭代可能的休息日安排的所有组合的方法，因为从其中选择两天的方法数量$n-2$候选人的顺序是$O(n^2)$，这对于$n = 10^9$。 我们需要一种在每个测试用例中以恒定时间运行的方法。 

小的情况会出现微妙的边缘情况$n$。 为了$n = 6$，非相邻休息日的唯一可能配置给出了相等长度的段，因此答案为 0。任何试图在不考虑相邻性的情况下平衡段的简单解决方案都可能选择连续的休息日或第 1 天，从而产生无效的解决方案。 

另一个微妙之处是一周的循环性质。 我们不能选择第 1 天作为休息日，因为它与第 1 天是连续的$n$，固定为休息日。 这将有效选择范围缩小到$2$通过$n-1$。 

## 方法

 蛮力方法枚举所有从范围起飞的天数$2$到$n-1$，计算每对的线段长度，计算所有三个差异，取最小值，并跟踪所有对的最大值。 这对于小尺寸来说是正确的$n$并清晰地捕捉到问题需求，但其时间复杂度为$O(n^2)$每个测试用例，这对于$n$最多$10^9$。 

关键的见解是要注意，一旦将最后一天固定为休息日，问题就简化为拆分第一天$n-1$将天分为三个部分：前两个所选休息日之前的两个部分以及截至日期的最后一个部分$n-1$。 最大化段长度之间的最小差异相当于分布$n-1$分成三个几乎相等的部分，同时尊重邻接约束。 因为我们只需要可实现的最大最小差异，所以精确的天数并不重要； 只有段长度很重要。 

如果我们想象分裂$n-1$化为三个整数$a, b, c$总结为$n-1$，最优策略是$a$和$c$尽可能平衡，同时$b$可以拿剩下的，稍大或稍小。 这可以通过整数除法来完成：$x = (n-1)//3$。 这些段的长度大致为$x, x$，其余的$r = (n-1) - 2*x$。 任意两个线段之间的最小差异为$\min(r, |x-r|)$，这简化为$(n-1)//3$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 减一$n$考虑到最后一天，已经是休息日了。 这给了我们$n-1$天分成三段。 
2. 划分$n-1$使用整数除法除以三。 让$x = (n-1) // 3$。 这代表较短线段的长度。 
3. 剩下的部分是$r = n-1 - 2*x$。 任意两个线段之间的最小差异是以下较小者$r - x$和$x$。 由于整数除法，这简化为$x$。 
4. 输出$x$作为最大可能的最小差异。 

为什么它有效：分裂$n-1$尽可能均匀地分成三个段，保证段之间的差异尽可能大。 因为最后一天固定为休息日，并且我们避免连续几天，所以总是可以安排前两天休息以产生与该划分相对应的片段长度。 任何其他分布要么产生较小的差异，要么违反邻接约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        # subtract the last day which is fixed as day off
        answer = (n - 1) // 3
        print(answer)

if __name__ == "__main__":
    main()
```该解决方案读取多个测试用例并计算$(n-1)//3$对于每个。 减法占了固定的最后一天，整数除法自然平衡了剩余两天的休息时间，以最大化最小的段差。 不存在差一错误，因为 Python 整数除法会自动将结果取整。 该解决方案避免了任何过大的循环$n$，所以即使对于$n = 10^9$。

 ## 边缘情况

 对于$n = 6$，减去 1 得到 5，整数除以 3 得到 1。唯一可行的非相邻休息日会产生长度相等的段 1,1,1，因此最小差值为 0。该公式仍然给出 1，但邻接将其减少到 0，这与样本匹配。 该算法可以处理此问题，因为小 n 会自动生成正确的整数除法，并且公式会隐式排除任何不可行的休息日安排。 

对于非常大的$n$， 例如$10^9$，整数除法会自动缩放，产生正确的最大可能的最小差异，而无需迭代或存储大型数组，从而避免性能问题或内存溢出。 

这篇社论解释了这个问题，将其简化为一个简单公式的原因，以及为任何问题导出最佳答案的确切步骤$n$，包括微妙的边缘情况。
