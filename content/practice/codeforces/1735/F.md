 ## 解决方案
 ## 问题理解

 我们有两种可以被认为是可以相互转化的资源的数量：卵石和珠子。 我们从最初的鹅卵石和珠子库存开始，然后考虑一系列的日子。 每天都有一个转换规则，允许我们以小数形式在两种资源之间进行交易，但只能按照当天确定的固定比例进行交易。 

正式来说，日$i$给我们一个转换对$(p_i, q_i)$。 我们可以选择一个实数$x$和$|x| \le p_i$，将其解释为改变鹅卵石$x$，并同时更换珠子$y$这样$x \cdot q_i = -y \cdot p_i$。 这意味着任何操作都相当于沿着直线移动$(\text{pebbles}, \text{beads})$坡度由下式确定的平面$p_i / q_i$，我们可以向前或向后移动，但只能在该线的有界线段内移动。 

每天我们最多可以应用一次这样的分段移动，或者什么也不做。 每天之后我们都会被问到：如果我们当时试图最大化鹅卵石的数量，我们能实现的最佳价值是多少？ 

重要的是，我们没有被要求整天保持单一的轨迹。 每一天都是一个从初始状态开始的独立优化问题，但我们可能使用的操作仅限于当天可用的操作。 

约束意味着$n$可以大到$3 \cdot 10^5$在所有测试中。 任何每天重新计算全局搜索或模拟细粒度分数转换的解决方案都是不可能的。 我们必须保持最佳可达状态的紧凑表示。 

一个天真的解释会尝试模拟所有可能的中间转换，甚至离散化可能的状态$(a, b)$，但转变的连续性立即打破了这种方法。 

当单个操作可以增加卵石但只能首先减少它们并使用珠子作为中间存储时，就会出现微妙的边缘情况。 例如，如果$a=0, b=10$，并且我们有一个转换，允许以有利的比例将珠子变成卵石，最佳策略可能会暂时将卵石方向减少到零变化，然后带着增益回来。 任何只考虑立即增加卵石的贪婪方法在这里都会失败，因为它忽略了通过珠子获得的间接收益。 

当什么都不做是最佳的时候，就会出现另一种边缘情况。 如果无论方向如何，每次允许的转换都会减少卵石的数量，那么正确的答案就是当前状态，必须在模型中明确保留该状态。 

## 方法

 蛮力观点是将每一天视为二维状态空间中的受约束运动。 从给定点$(a, b)$， 天$i$允许沿着由线性约束定义的线段移动。 人们可以想象通过探索段的两个端点和潜在的中间点来枚举每天之后的所有可能的最终状态。 由于操作是连续的，因此这成为状态的连续体而不是离散图。 

即使我们只离散化端点，我们也会很快在几天内遇到状态的指数增长。 每天候选极端状态的数量可能会增加一倍，从而导致$O(2^n)$行为。 即使修剪也很重要，因为不同的序列可能导致平面不同区域的非支配状态。 

关键的结构观察是我们只关心最大化一个线性目标：卵石的数量。 在所有变换都是线性约束的 2D 系统中，任何步骤的最优解都必须位于可达凸区域的边界上。 每天之后的可达集仍然是凸的，因为我们正在应用从凸集开始的线性变换和线段的并集。 

这将问题简化为仅跟踪可到达凸体的极值点。 然而，跟踪全凸包仍然太昂贵。 

更深入的见解是，每个操作有效地允许我们以受控的方式旋转或倾斜坐标系，并且最佳答案仅取决于单个标量状态：在动态演化的基础下，卵石和珠子的最佳可实现线性组合。 这将问题转变为维持状态在变化方向上的最佳投影。 

该预测可以增量地维持。 每一天都会带来潜在的改进，该改进仅取决于当前的最佳线性表示，并且我们可以按顺序处理几天，同时更新一小组编码最佳权衡前沿的参数。

 ## 算法演练

 我们将状态重新解释为一个点$(P, B)$每天都给出鹅卵石和珠子之间的线性贸易方向。 约束条件$$x \cdot q_i = -y \cdot p_i$$意味着可行的移动保持线性不变量：每个允许的移动都会沿着与$(p_i, -q_i)$。 

关键的简化是跟踪以下形式的线性函数的最佳可能值：$$\text{value} = P + k \cdot B$$为适当的演化系数$k$。 系数$k$代表在未来的最佳转换下，我们可以有效地为每颗珠子获得多少颗卵石。 

1. 初始化当前状态为$P = a$,$B = b$，并初始化边际价值系数$k = 0$。 该系数从零开始，因为最初珠子没有隐式转换值。 
2. 处理日$i$按顺序，治疗$(p_i, q_i)$作为新的允许转换方向。 
3. 通过考虑我们可以通过比率从珠子转换中提取多少卵石增益，计算当天可实现的最佳改进$p_i/q_i$与当前边际价值相结合$k$。 决策归结为是否使用此交换可以改善当前的预测。 
4.更新有效斜率$k$反映珠子现在可以通过这个新的比率转换成卵石，但前提是它提高了总预计价值。 从只保留更好的转换效率的意义上来说，此更新是单调的。 
5. 一天后更新答案$i$作为维持系数下状态的当前有效投影。 

关键机制是每天都会完善两种货币之间最著名的转换效率，并且始终通过将这种最佳转换解释应用于初始资源来获得答案。 

### 为什么它有效

 在任何时刻，可达状态集在平面上形成一个凸区域，并且我们正在优化线性函数（卵石）。 该区域的边界完全由迄今为止看到的最佳转换率确定，因为每天都会贡献一个新的线性约束方向。 

因为所有操作都是线性的并且在边界内可逆，所以可到达的区域永远不需要记住内部结构，只需要定义珠子如何转化为卵石的最佳斜率。 这减少了维持每天兑换率引起的线性函数上限的问题。 该算法以增量方式准确地维护此包络，确保不会丢弃先前的最佳变换，除非它严格受到更好的比率支配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, a, b = map(int, input().split())
        p = list(map(int, input().split()))
        q = list(map(int, input().split()))

        # We maintain best achievable slope of converting beads into pebbles.
        # dp represents best "pebbles + k * beads" coefficient interpretation.
        best = 0.0
        ans = []

        for i in range(n):
            pi = p[i]
            qi = q[i]

            # effective conversion ratio from this day
            ratio = pi / qi

            # update best conversion efficiency
            if ratio > best:
                best = ratio

            # apply best known conversion to initial resources
            # pebbles + best * beads
            ans.append(a + best * b)

        print("\n".join(f"{x:.10f}" for x in ans))

if __name__ == "__main__":
    solve()
```该代码维护一个标量，`best`，这代表迄今为止观察到的从珠子到卵石的最强转换效率。 每天都会介绍一个候选人比例$p_i / q_i$，并且我们保留这些值中的最大值。 这反映了这样的想法：只有最佳的线性交换方向对于最大化卵石很重要。 

每天之后的最终答案是通过使用这个最佳比例将珠子解释为部分转化为卵石来计算的。 这避免了任何显式状态模拟，并将问题简化为流式最大计算。

 ## 边缘情况

 当以下任一情况发生时，就会出现极端情况：$a = 0$或者$b = 0$。 如果$b = 0$，那么再多的转换比例也无法增加卵石，因为没有什么可以转换的。 算法自然返回$a$自学期以来的所有日子$best \cdot b$始终为零。 

如果$a = 0$和$b > 0$，整个答案取决于迄今为止看到的最大比率。 该算法正确地积累了最佳比率并将其应用于$b$，产生非递减的答案序列。 

另一种边缘情况是比率波动时：先是小比率，然后是大比率。 该算法正确地忽略了较大比率出现后的小比率，因为只有最大值对线性投影很重要。 

最后，当所有$p_i/q_i$正在减少，第一天之后答案保持不变，这与没有发现更好的转化方向的事实相符。
