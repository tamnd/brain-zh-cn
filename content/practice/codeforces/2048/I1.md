 ## 解决方案
 ## 问题理解

 我们被要求构造一个与方向字符串相对应的非负整数数组，其中字符串中的每个字符指定有关数组前缀或后缀中不同数字计数的条件。 如果一个字符是`L`在位置`i`，数组元素位于`i`应等于其之前的子数组中不同整数的数量。 如果角色是`R`，数组元素位于`i`应等于其后不同整数的数量。 如果没有数组满足所有这些约束，我们必须报告`-1`。 

字符串长度`n`最多可以达到 200,000 个，并且最多可以有 10,000 个测试用例，所有测试用例的总和`n`跨 200,000 个测试用例。 这意味着解决方案的复杂性比线性更差`n`每个测试用例都会太慢。 对每个位置的不同元素进行计数的蛮力方法将是二次的，因此是不可行的。 

例如，当所有字符都相同时，就会出现微妙的边缘情况`RRR`或者`LLL`。 为了`RRR`，我们希望每个元素计算其后面的后缀中的不同数字，这意味着严格的递增或递减模式可以工作。 为了`LLL`，数组必须以前缀方式增长。 另一个边缘情况是交替字符，例如`LRLR`，其中需要仔细分配以满足左右不同计数。 

## 方法

 暴力方法将尝试所有可能的数组并检查每个位置的不同计数条件。 对于每个位置，我们将扫描前缀或后缀以计算唯一元素。 这将涉及$O(n^2)$每个测试用例的操作，这对于`n`最多 2×10^5。 

关键的观察是数组中的值对应于某些严格递增或递减序列中的索引。 由于前缀或后缀中不同数字的计数从零开始，并且每一步最多可增加 1，因此我们可以通过沿着滑动序列仔细选择递增的整数来构造一个有效的数组。 我们可以从`0`在任一端并增加`1`或根据模式保持不变`L`和`R`。 具体来说，如果我们对待`L`由于希望前缀非重复计数与数组元素相匹配，我们可以将该元素指定为其在从左侧开始的增量序列中的位置。 同样，对于`R`，我们可以从右边开始赋值。 

本质上，有两个候选序列：一个以`0`并从左到右递增，并且以`0`并从右到左递增。 如果这些序列中的任何一个满足所有约束，我们就可以输出它。

 ## 算法演练

 1. 对于每个测试用例，读取长度`n`和字符串`s`。 
2. 构造数组`a`长度`n+1`存储候选解决方案。 
3. 考虑元素递增分配的顺序`0`到`n`从左到右。 该序列对应于治疗`L`从一开始就计算唯一元素。 对于每个位置`i`， 分配`a[i] = i-1`。 检查这是否满足`R`通过比较定位`a[i]`到`n-i`。 
4. 如果从左到右的序列失败，则构造一个从右到左的序列，其中`a[i] = n-i`。 检查是否满足`L`通过比较定位`a[i]`到`i-1`。 
5. 如果两个序列之一有效，则输出它。 否则，打印`-1`。 

该算法利用了这样一个事实：对于一串`L`s，前缀不同计数从零开始并且只能递增，因此分配增量值满足所有`L`s。 同样，对于`R`s，以递减的方式分配值`n-1`到`0`确保后缀不同计数匹配。 

工作原理：每个数组元素反映其之前或之后的不同整数的数量。 通过考虑每一步数字恰好增加 1 的序列，可以保证不同计数不变量成立。 由于只允许非负整数，因此从`0`确保有效性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        
        # try left-to-right assignment
        left = list(range(n+1))
        right = list(range(n, -1, -1))
        
        candidate = None
        for start in range(n+1):
            # build array with start point
            a = list(range(start, start+n+1))
            valid = True
            for i in range(n):
                if s[i] == 'L' and a[i] != i:
                    valid = False
                    break
                if s[i] == 'R' and a[i] != n-i-1:
                    valid = False
                    break
            if valid:
                candidate = [a[i] for i in range(n)]
                break
        
        if candidate:
            print(' '.join(map(str, candidate)))
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```该解决方案首先读取测试用例的数量。 对于每种情况，它都会尝试对应于从左到右和从右到左增量分配的两个简单序列。 对于每个位置，代码检查元素是否满足前缀或后缀不同计数要求。 如果找到有效序列，则打印它； 否则，它会打印`-1`。 一个微妙的实现选择是仔细处理索引以避免差一错误，尤其是在从零开始的 Python 列表中。
