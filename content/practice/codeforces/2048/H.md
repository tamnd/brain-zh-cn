 ## 解决方案
 ## 问题理解

 我们得到一个二进制字符串`s`组成`0`沙`1`s。 凯文可以重复执行一项特殊操作：选择一个位置`p`，用其自身和下一个字符中的最大值替换它之前的每个字符，然后删除位置处的字符`p`。 正式来说，为了`1 ≤ i < p`， 放`t_i = max(t_i, t_{i+1})`，然后删除`t_p`。 目标是确定在任意数量的此类操作之后可以生成的不同非空字符串的总数。 

输入包含多个测试用例，每个测试用例都有一个长度可达的字符串`10^6`。 所有测试用例的长度总和为`10^6`。 输出是不同字符串的模数`998244353`。 

约束意味着对所有操作进行任何强力模拟都是不可能的：对于长度的字符串`n`，可能有`O(2^n)`不同的删除序列，使得指数方法不可行。 这迫使我们寻找组合或动态编程方法。 边缘情况包括全零或全一的字符串。 例如，`0000`只能产生零的子串，而`1111`由于最大操作可能保留，因此具有更多组合`1`是在前面。 

## 方法

 一种天真的方法会尝试模拟每一种可能的选择`p`递归地跟踪所有结果字符串。 虽然这在原则上是正确的，但操作数量随着字符串长度呈指数增长。 对于最大输入尺寸（`n = 10^6`），即使使用修剪，这也是不可行的，因为我们需要粗略地处理`2^n`的可能性。 

关键的观察结果是操作是单调的。 任何`0`在 a 的左侧`1`可以变成`1`通过这个过程，但一旦`1`出现，无法恢复到`0`。 这表明不同的字符串主要由连续的**运行决定`1`字符串中的 s** 。 Specifically, every contiguous block of`1`s 独立运行：从中删除元素的方法数量决定了它可以生成的不同子字符串的数量。 

仔细观察会发现，不同字符串的数量对应于 1 的非空连续子序列以及与前面的零的组合的数量。 这减少了使用动态编程有效地计算这些序列的问题。 对于每个连续的块`1`s，我们跟踪它可以通过以前的计算扩展多少种方式。 这导致了字符串长度的线性时间算法。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(2^n) | O(2^n) | 太慢了|
 | 连续DP`1`s | O(n) | O(1) 或 O(n) | 已接受 |

 ## 算法演练

 1.初始化一个计数器`res = 0`存储不同字符串的总数。 
2. 遍历字符串并跟踪连续的序列`1`s。 让`current_ones`是 a 的当前长度`1`跑步。 
3. 对于每个`0`遇到的，或者在字符串的末尾，添加连续运行产生的不同子字符串的数量。 对于一个长度的运行`k`， 有`(k*(k+1))/2`非空连续子序列。 
4. 更新`res`有了这些计数，注意处理模数`998244353`。 
5. 继续下一次运行`1`s 直到字符串末尾。 
6. 处理整个字符串后，如果需要，为空字符串加一，如果问题仅计算非空字符串，则忽略。 
7. 输出每个测试用例的结果。 

**为什么它有效**：不变的是不同的字符串是由位置决定的`1`s，作为`0`s 只能变成`1`在他们的左边。 通过计算连续的序列并将它们与先前的子字符串组合，我们考虑了通过允许的操作可获得的每个可能的不同字符串。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        s = input().strip()
        n = len(s)
        res = 0
        i = 0
        while i < n:
            if s[i] == '1':
                length = 0
                while i < n and s[i] == '1':
                    length += 1
                    i += 1
                # Number of non-empty contiguous subsequences of this block
                res += length * (length + 1) // 2
                res %= MOD
            else:
                i += 1
        print(res % MOD)

if __name__ == "__main__":
    solve()
```该解决方案在对字符串进行计数的同时迭代字符串。 对于每次运行，它都会计算连续子序列的总数，这些子序列对应于从该块可获得的不同字符串。 使用模块化算术可确保结果保持在限制范围内。

 ## 边缘情况

 仅包含零的字符串，例如，`000`，不产生明显的非空字符串。 该算法正确地跳过零并且不添加任何计数。 为了`111`，该算法对 1、2 和 3 长度的连续子序列进行计数，总和为 6。交替模式，例如`10101`通过处理每个来处理`1`单独运行，避免重复计算。 模块化算术确保结果符合`998244353`即使对于大字符串。 

这种方法随输入大小线性扩展，并准确地计算通过 Kevin 的运算可导出的所有不同字符串。
