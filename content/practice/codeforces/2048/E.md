 ## 解决方案
 ## 问题理解

 我们被要求为海报图案设计一个二分图。 左边的部分有$2n$顶点，并且右侧部分有$m$顶点，每个左顶点都连接到每个右顶点。 每条边必须用介于两者之间的整数着色$1$和$n$。 一个好的设计要求图中没有一个简单的循环是单色的，这意味着没有一个循环的所有边都应该是相同颜色的。 我们要么生产一种满足这个约束的颜色，要么报告说这是不可能的。 

输入由多个测试用例组成。 每个测试用例给出整数$n$和$m$。 如果不存在有效的着色，则输出为“NO”，或者后跟一个“YES”$2n \times m$颜色矩阵。 

约束表明$n$和$m$每个可以达到$10^3$，并且所有测试用例的总和不超过$10^3$。 这意味着我们可以负担得起$O(nm)$每个测试用例的解决方案，但是任何显式迭代周期的解决方案都会太慢，因为周期数呈指数增长。 

当出现不明显的边缘情况时，$n = m = 2$。 在这个小型配置中，如果处理不当，长度为四的每个周期很容易成为单色。 简单地以每行重复图案分配颜色的简单解决方案可能会无意中形成一个$2 \times 2$单色正方形。 另一个棘手的情况是当$m > n$或者$n > m$; 我们必须避免以允许形成单色循环的方式多次重复单一颜色。 例如，与$n = 2$和$m = 3$，仅指定颜色${1,2}$沿行需要小心交错以防止循环。 

## 方法

 蛮力方法试图枚举所有可能的颜色$2nm$边缘，然后检查每个简单循环的单色。 这是正确的，但完全不切实际，因为边缘着色的数量是$n^{2nm}$，循环数与$n$和$m$。 即使是为了$n=m=5$，这种方法不可行。 

关键的见解是，完整二分图中的所有简单循环的偶数长度至少为 4。因此，为了避免单色循环，我们只需要确保在每个$2 \times 2$连接两个左顶点和两个右顶点的边的子矩阵，颜色不相同。 如果我们分配颜色使得每行（左顶点）都有不同的排列$1..n$跨列（右顶点），否$2 \times 2$子矩阵可以具有相同的所有边。 这将问题简化为构造一个简单的交错颜色图案，围绕模数进行环绕$n$如果需要的话。 仅当以下情况时，该模式是不可能的：$n = 1$和$m > 1$因为我们无法阻止任何事情的重复$2 \times 2$堵塞。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^(2nm)) | O(n^(2nm)) | O(2nm) | 太慢了 |
 | 交错着色| O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读$n$和$m$。 
2.如果$n = 1$和$m > 1$，输出“NO”，因为我们只有一种颜色，这将为$m \ge 2$。 
3. 否则，输出“YES”。 构造一个$2n \times m$矩阵，其中行$i$颜色为$(i + j - 2) \bmod n + 1$对于列$j$。 此公式交错颜色，以便没有两行形成一个$2 \times 2$单色正方形。 
4. 逐行打印结果矩阵。 

为什么有效：通过对每行的颜色进行模数转换$n$， 每一个$2 \times 2$由两个左顶点和两个右顶点形成的块总是至少有两种不同的颜色。 这消除了任何单色 4 循环的可能性。 由于二部图中的所有循环都是偶数长度，并且最短的循环是 4 循环，因此防止单色 4 循环可确保不存在任何长度的单色循环。 该算法绝不会在同一对列的两行中重复相同的颜色。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        if n == 1 and m > 1:
            print("NO")
            continue
        print("YES")
        for i in range(2 * n):
            row = [((i + j) % n) + 1 for j in range(m)]
            print(' '.join(map(str, row)))

if __name__ == "__main__":
    main()
```该解决方案使用有效读取所有输入`sys.stdin.readline`。 对于每个测试用例，它立即处理不可能的情况，其中$n = 1$和$m > 1$。 行结构使用模算术确保交错颜色，这保证了没有$2 \times 2$单色块。 一个微妙之处是我们使用`i + j`在模数里面而不是`i + j - 2`因为Python的迭代是0索引的，所以这个调整使颜色保持在范围内`[1, n]`。
