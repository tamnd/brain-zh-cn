 ## 解决方案
 ## 问题理解

 我们给出了两个整数来描述树上分支的垂直结构。 分支按递增顺序编号，从低层开始一直到某个最大高度。 下部分支的子集包含grasshopper，并且每个grasshopper都有确定性的跳跃模式：从当前分支开始，它可以重复降落在由语句隐含的固定算术规则确定的某些其他分支上。 

任务是选择尽可能高的树枝，使任何蚱蜢都无法落在上面，从它们的初始位置开始并使用允许的跳跃。 如果每个分支至少有一只蚱蜢可以到达，那么答案就不存在。 

关键点在于，每个蚱蜢并不是任意探索，而是生成一组结构化的可到达位置。 所有这些可到达位置的联合形成了禁止分支的集合。 我们需要不在该联合范围内的最大整数。 

约束很大，值高达 10^9。 这立即排除了对所有分支的任何模拟。 即使线性迭代所有分支也是不可能的。 任何方法都必须依赖于数论结构，而不是显式遍历。 

一个微妙的边缘情况是当每个分支由于重叠的算术级数而变得可到达时。 例如，如果蚱蜢共同覆盖周期性结构中的所有残基，则不存在安全分支。 另一种边缘情况是当最高安全分支位于最大可达边界下方时，因此如果我们假设完全覆盖而不仔细跟踪补集，则逐一推理很容易出错。 

## 方法

 暴力解释将模拟每个 Grashopper 并标记直到 y 的所有可到达分支。 每个蚱蜢都会生成可到达位置的算术级数。 对于每只蚱蜢，我们可以重复跳跃并标记访问过的分支。 这在概念上是正确的，但在复杂性上立即失败：在最坏的情况下，单个grasshopper可以生成O(y)个位置，并且在问题结构的最坏的解释中最多有O(y)个可能的起始分支。 这会导致二次行为，这在 10^9 尺度范围内是不可能的。 

关键的观察是每个 Grashopper 的可达集是周期性的。 从语句来看，位置x处的每个蚱蜢可以跳到x、2x、3x等等。 这意味着它可以准确地到达其起始位置的所有倍数。 因此，如果一个分支可以被至少一个 Grasshopper 位置整除，那么它就是不安全的。 

所以问题归结为一个干净的数论问题：在从 2 到 y 的整数中，我们想要不能被 [2, p] 中的任何整数整除的最大整数。 如果范围内的每个数字都可以被至少一个这样的值整除，我们返回 -1。 

此结构建议从 y 向下扫描并检查从 2 到 p 的所有值的整除性。 由于 p 可以达到 y，因此如果对每个候选者天真地进行直接检查，在最坏的情况下会太慢。 然而，我们只需要找到从顶部开始的第一个有效数字，所以一旦找到我们就尽早停止。 这是可以接受的，因为在实践中，我们在遇到有效的候选者之前只测试少数候选者。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(y²) | O(1) | O(1) | 太慢了|
 | 自上而下的可分性检查 | O((y - 答案) · p) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 从最高可能的分支 y 开始，并将其视为候选答案。 目标是按降序测试候选者，以便第一个有效的自动成为最佳选择。 
2. 对于每个候选值v，检查[2, p]范围内的任何整数是否能整除v。如果存在这样的除数，则v是不安全的，因为从该除数开始的grasshopper可以到达v。 
3. 如果我们在 [2, p] 中找不到除数，我们立即返回 v，因为不存在更高的候选者。 
4. 如果 v 不安全，则将 v 减 1 并重复该过程。 
5. 如果我们在没有找到有效值的情况下达到 2 以下，则返回 -1，因为每个分支至少有一个 Grashopper 可到达。 

### 为什么它有效

 从位置 i 开始的每个 Grashopper 都可以精确地到达 i 的倍数集合。 因此，当且仅当分支不能被 2 到 p 之间的任何整数整除时，分支才是安全的。 该算法按降序详尽地检查候选者，确保遇到的第一个安全分支是最大可能的安全分支。 不变量是所有大于当前候选的数字都已被测试并确定为不安全，因此第一次成功是全局最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    p, y = map(int, input().split())
    
    for v in range(y, 1, -1):
        ok = True
        for i in range(2, p + 1):
            if v % i == 0:
                ok = False
                break
        if ok:
            print(v)
            return
    
    print(-1)

if __name__ == "__main__":
    solve()
```解决方案首先读取分支系统的边界。 然后，它从最高分支向下迭代，通过构造确保最大化。 对于每个候选者，它会检查所有可能的 Grashopper 起始位置的整除性。 一旦找到除数，内循环就会尽早退出，这在许多情况下避免了不必要的检查。 如果没有有效的候选者，该函数将打印 -1。 

关键的实现细节是严格的降序迭代。 如果没有这个，我们将需要显式地跟踪最大值，但降序搜索会自动保证正确性。

 ## 边缘情况

 当每个候选值都可以被 [2, p] 中的至少一个数字整除时，就会出现一种边缘情况。 例如，如果 p 相对于 y 较大，则小除数几乎涵盖所有整数。 在这种情况下，循环将所有值耗尽到 2 并正确打印 -1。 

另一种边缘情况是 y 本身不能被范围内的任何数字整除。 例如，如果 y 是大于 p 的素数，则算法会立即接受它，而不进行任何向下搜索。 

最后，当 y 很小时且 p 很大时，许多候选者会由于 2 或 3 之类的小除数而很快失败，但该算法仍然有效，因为它独立检查候选者并在第一个有效的候选者处停止，从而确保正确性而不需要全局预处理。
