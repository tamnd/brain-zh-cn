 ## 解决方案
 ## 问题理解

 我们有一块大小为的方板`n × n`其中每个单元格包含一个数字`0`和`9`。 对于每个数字`d`，我们想要找到一个三角形，其顶点是包含以下单元格的中心`d`，至少一侧平行于板边缘，使得该三角形的面积最大化。 在构建三角形之前，我们可以将板上的一个单元格更改为`d`。 输出是每个数字的最大面积乘以 2。 

输入由多个测试用例组成。 第一行给出测试用例的数量`t`。 每个测试用例都以`n`， 其次是`n`代表棋盘的字符串行。 总和`n²`所有测试用例的数量不超过 4 × 10⁶。 这个界限表明我们每个测试用例最多必须使用大约 O(n²) 的算法； 任何慢的都会超过时间限制。 

当数字在棋盘上只出现一次或根本不出现时，就会出现不明显的边缘情况。 在这种情况下，三角形可能会退化或完全依赖于最佳放置额外的单元。 另一个微妙之处是，最大面积三角形通常使用沿一个轴的最大可能距离，这很简单`n - 1`，对应于板的角。 

例如，如果`n = 3`棋盘上只包含零，即数字的最大三角形面积`0`当顶点占据位置时发生`(0,0)`,`(0,2)`,`(2,0)`，面积为 2（乘以 2 → 4）。 迭代所有三元组单元的粗心方法会太慢，并且忽略轴对齐条件会产生无效的三角形。 

## 方法

 一种朴素的暴力方法会枚举每个数字的所有位置三元组，并计算三角形的面积（如果至少一侧是轴对齐的）。 每个测试用例每个数字的时间复杂度为 O(n⁴)，因为每个数字有 O(n²) 个位置，以及 O((n²)³) 个三元组。 这是不可行的`n`最多 2000。 

关键的观察结果是，具有最大面积且至少一侧平行于轴的三角形由包含数字的极端行和列确定。 具体来说，对于一个数字`d`，我们可以预先计算：

 - 包含的最小和最大行索引`d`。 
- 包含的最小和最大列索引`d`。 

将顶点放置在这些极端位置即可获得最大的可能面积。 通过迭代所有位置并计算相对于最远可能的行或列的面积，我们可以在每位数字的 O(n²) 中有效地找到最大值。 这是可行的，因为可以通过考虑沿板边缘的位置来合并添加额外允许的单元以延长最大距离。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n⁴) | O(n²) | 太慢了|
 | 最佳 | O(n²) | O(n²) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和`n × n`木板。 
2. 初始化 10 个数组来跟踪每个数字的最小和最大行索引和列索引。 
3. 迭代每个单元格`(i, j)`董事会的。 对于数字`d`在该单元格中，更新：

 -`min_row[d]`和`max_row[d]`和`i`。 
-`min_col[d]`和`max_col[d]`和`j`。 
4. 对于每个数字`d`从 0 到 9，计算最大面积如下：

 - 对于每次出现`d`在`(i, j)`：

 - 考虑形成一个边沿行的三角形：`height = max(i, n - 1 - i)`,`base = max_col[d] - min_col[d]`。 
- 考虑形成一个边沿柱的三角形：`height = max(j, n - 1 - j)`,`base = max_row[d] - min_row[d]`。 
- 保留任何获得的最大面积`(i, j)`。 
5. 打印所有数字的面积乘以 2。 

**为什么起作用：** 极端的行和列位置保证三角形的至少一侧平行于轴并且距离最大化。 考虑每次发生的情况可确保我们以最佳方式放置额外的单元格。 该算法仅检查每个数字的 O(n²) 个位置，并使用简单的算术来查找最大面积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        board = [input().strip() for _ in range(n)]
        
        min_row = [n] * 10
        max_row = [-1] * 10
        min_col = [n] * 10
        max_col = [-1] * 10
        
        for i in range(n):
            for j in range(n):
                d = int(board[i][j])
                min_row[d] = min(min_row[d], i)
                max_row[d] = max(max_row[d], i)
                min_col[d] = min(min_col[d], j)
                max_col[d] = max(max_col[d], j)
        
        res = [0] * 10
        for d in range(10):
            for i in range(n):
                for j in range(n):
                    if int(board[i][j]) != d:
                        continue
                    # side along row
                    height = max(i, n - 1 - i)
                    width = max_col[d] - min_col[d]
                    res[d] = max(res[d], height * width)
                    # side along column
                    width = max(j, n - 1 - j)
                    height = max_row[d] - min_row[d]
                    res[d] = max(res[d], height * width)
        print(*res)

if __name__ == "__main__":
    solve()
```该代码预先计算每个数字的极端行索引和列索引。 对于数字的每次出现，它都会使用沿行和列到边缘的最大距离来计算潜在的三角形面积。 这种方法有效地找到满足轴对齐约束的最大三角形。
