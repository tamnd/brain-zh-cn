 ## 解决方案
 ## 问题理解

 我们有一个（N × M）矩形网格。 X先生占据一个单元格，并且有一个或两个HAHA特工占据另外两个单元格。 在每一轮中，每个智能体必须以任何顺序精确地移动一步到相邻的空闲单元。 当所有特工移动完毕后，X 先生也准确地向相邻的空闲单元迈出了一步。 如果 X 先生的每个相邻单元格都被特工占领，则他没有合法的移动并失败。 

输入给出了网格尺寸、X 先生的起始单元格以及 (K) 个代理的起始单元格。 输出询问代理是否可以在双方完美发挥的情况下迫使损失。`Y`意味着代理人有制胜策略，而`N`意味着X先生可以永远继续前进。 

这些约束看起来足够大，足以阻止任何游戏模拟。 对于 (N,M\le300)，可以有 (90{,}000) 个单元格。 具有两个代理的状态包含三个占用的单元，因此显式游戏图已经具有大约 (90{,}000^3)、大约 (7.3\times10^{14}) 的有序配置。 即使存储这样的图表也是不可能的。 最多有两种试剂这一事实是关键的结构限制，使得表征变得更加简单。 

第一个有用的观察是网格单元至少有两个邻居，内部单元有四个。 由于最多有两名特工，X先生只有当他站在一个角落并且该角落的两个邻居都被占领时才能投降。 因此，代理永远不需要包围内部细胞。 他们只需要把X先生逼到墙角就可以了。 

第二个观察结果是网格是二分的。 根据 (r+c) 的奇偶性对单元格 ((r,c)) 进行着色。 每一个法律举措都会改变这种平衡。 由于每个参与者在每个完整回合中只移动一次，因此在一轮开始时三个参与者之间的奇偶关系永远不会改变。 

考虑小输入```
1
3 3 1
1 1
2 2
```只有一个代理，因此正确的输出是`N`。 粗心的模拟可能会看到智能体向角落移动，并假设它最终可以困住 X 先生，但最终位置需要两个被占领的邻居。 

现在考虑```
1
3 3 2
1 1
1 3
3 1
```所有三个位置都有偶数 (r+c)。 正确的输出是`Y`。 当智能体移动到 ((1,2)) 和 ((2,1)) 后，((1,1)) 处的 X 先生没有空闲邻居。 

一个更微妙的情况是```
1
4 4 2
1 2
1 3
1 4
```奇偶校验为 (1,0,1)，因此它们并不全部相等。 正确的输出是`N`。 仅检查代理是否可以接近同一个角的模拟可能会错误地预测陷阱。 当必须占用最后两个相邻单元时，奇偶关系会阻止其中一个代理处于正确的颜色类别。 

奇偶特征也与竞赛讨论一致，其中问题 A 的公认观察被总结为，当 (K=2) 时，要求所有三个点具有相同的 ((x+y)\bmod2) 值，而 (K=1) 总是对代理失败。 

## 方法

 直接方法将 X 先生和代理人的每一种可能的安排建模为博弈状态。 从每个状态，我们将枚举代理可能的动作，解释它们可能的顺序，然后枚举 X 先生的响应。 因为这是一个有限可达性博弈，逆行博弈分析理论上可以将每个状态分类为赢或输。 

问题在于该状态空间的大小。 让(V=NM)。 对于两个智能体，大约有 (V(V-1)(V-2)) 个有序放置，因此在最大网格大小下，在考虑任何移动之前大约有 (90{,}000^3=7.29\times10^{14}) 个状态。 即使每个州的工作量恒定也远远超出了限制。 

破坏这个巨大状态空间的结构是棋盘着色。 每一个动作都会翻转颜色。 在每个完整回合开始时，所有三个参与者自开始以来都进行了相同数量的移动，因此他们的配对平价关系永远固定。 

假设（K = 2），并且一个代理从与 X 先生相反的颜色开始。在每个代理阶段开始时，该代理仍然处于与 X 先生相反的颜色。然后代理必须移动，因此它切换到 X 先生的颜色。 X先生的邻居具有与X先生相反的颜色，因此代理在强制移动后不能占据X先生的相邻单元格。 由于角点的两个邻居都需要困住 X 先生，因此特工永远不可能获胜。 

这给出了所有三个初始位置必须具有相同奇偶性的必要条件。 

条件相同就足够了。 当所有三个参与者都从相同的棋盘颜色开始时，两个智能体可以使用标准的二智能体网格挤压策略。 两个代理足以迫使移动的玩家向有限矩形网格的边界移动，并最终进入角落。 经典的网格追踪策略正是通过维持两个收缩区域或阴影锥体来实现这一点，并防止跑步者穿过受控边界返回。 Two agents suffice for rectangular grids because the agents can progressively reduce the runner's available rectangle until only a corner remains.

 每个代理必须移动的特殊规则由相同的奇偶条件处理。 每轮开始时，特工和 X 先生的实力相等。 当 X 先生的下一步行动将翻转他的平价时，所需的代理行动恰好翻转其平价。 因此，代理可以执行挤压策略，而无需等待未使用的回合。 当奔跑者到达角落时，两个特工可以在移动中占领其两个邻居，迫使其投降。 

蛮力之所以有效，是因为它明确地表示了每种可能的游戏状态，但会失败，因为状态空间的单元数量是立方的。 奇偶性观察将整个游戏分解为一个恒定时间测试。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O((NM)^{K+1})) | (O((NM)^{K+1})) | 太慢了 |
 | 最佳| 每个测试用例 (O(K)) | (O(K)) | 已接受 |

 ## 算法演练

 1.读取(N,M,K)，X先生的位置，以及所有代理位置。 网格的实际尺寸不会影响最终的测试，因为 (N,M\ge3) 保证每个角都恰好有两个邻居。 
2. 如果(K=1)，回答`N`。 一个智能体最多可以占领一个角的两个邻居之一，而投降则要求两个邻居都被占领。 
3. 如果(K=2)，计算每个参与者的棋盘颜色为((r+c)\bmod2)。 移动会更改此值，因为恰好有一个坐标会更改 (1)。 
4. 检查两个代理和X先生是否具有相同的奇偶性。 如果有任何不同，请回答`N`。 不同的智能体在强制移动以参与角陷阱之后将始终具有错误的奇偶校验，因此它永远无法占据所需的相邻单元之一。 
5. 如果三个奇偶性都相等，则回答`Y`。 两个智能体可以在矩形网格上应用标准的二智能体挤压策略。 他们平等的回合开始奇偶性让每一个所需的动作都适合交替颜色的结构，并且该策略最终将 X 先生限制在角落里。 一旦他到达那里，特工就可以占领两个相邻的牢房，让他无法合法移动。 

不变量是每轮开始时的奇偶关系。 每个参与者每轮只移动一次，因此每个参与者都会翻转颜色一次。 因此，如果两个参与者最初具有相同的颜色，则他们在每个回合边界处具有相同的颜色，如果他们最初具有不同的颜色，则他们保持不同。 获胜的角落陷阱要求两名特工在特工阶段开始时与 X 先生具有相同的颜色，因为他们的移动必须将他们放置到相反颜色的单元格上。 因此，不等的初始奇偶性是绝对的障碍，而相等的初始奇偶性正是双代理网格挤压策略可以完成陷阱的情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for tc in range(1, t + 1):
        n, m, k = map(int, input().split())

        x_r, x_c = map(int, input().split())
        agents = [tuple(map(int, input().split())) for _ in range(k)]

        if k == 1:
            ans = "N"
        else:
            target_parity = (x_r + x_c) & 1
            ans = "Y"

            for r, c in agents:
                if ((r + c) & 1) != target_parity:
                    ans = "N"
                    break

        out.append(f"Case #{tc}: {ans}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```一次读取一个测试用例的输入。 对于每种情况，X 先生的奇偶校验均使用以下公式计算一次`(x_r + x_c) & 1`。 

当有一个代理时，程序立即返回`N`，因为网格至少有三行和三列，所以每个角都有两个不同的邻居。 一名代理人不能同时占据两者。 

当有两个代理时，程序开始于`Y`并将其更改为`N`一旦代理与 X 先生具有不同的奇偶性，就无需存储网格、生成移动或跟踪未来位置。 奇偶关系已经决定了游戏的胜负。 

坐标是从一开始的，与问题所提供的完全一样。 在采用奇偶校验之前添加它们不受基于 1 与基于 0 的索引的选择的影响，因为将两个坐标移动 1 会将它们的总和更改为 2。 

Python 整数具有任意精度，尽管这里不涉及大型算术。 除了最多两个代理位置的小列表之外，内存使用量是恒定的。

## 边缘情况

 单代理人案件在任何平等推理之前处理。 为了```
1
3 3 1
1 1
2 2
```X 先生从一个角开始，但唯一的代理无法同时填充 ((1,2)) 和 ((2,1))。 即使特工转移到其中一个，另一个仍然是自由的。 算法立即返回`N`。 

对于混合奇偶校验，请考虑```
1
4 4 2
1 2
1 3
1 4
```X 先生具有奇偶性 (3\bmod2=1)。 第一个代理具有奇偶校验 (4\bmod2=0)，而第二个代理具有奇偶校验 (5\bmod2=1)。 在每一轮边界处，第一个特工的颜色与 X 先生相反。第一个特工被迫移动后，它会切换到 X 先生的颜色，而不是陷阱所需的邻居颜色。 因此，在代理阶段之后，两个所需的角邻居永远不会被占用。 算法返回`N`。 

对于获胜的奇偶校验配置，```
1
3 3 2
1 1
1 3
3 1
```所有三个总和都是偶数。 特工们从牢房开始，从角落开始沿着两个方向走两步。 它们移动到 ((1,2)) 和 ((2,1))，这正是 X 先生的两个邻居。下一步移动是不可能的，因此算法返回`Y`。 

最后，最大的网格尺寸不会产生特殊情况。 为了```
1
300 300 2
2 3
100 100
299 299
```X 先生具有奇校验，而两个代理具有偶校验。 一旦发现奇偶校验障碍，网格大小就无关紧要了，所以答案是立即的`N`。 该算法从不分配（300×300）网格，也从不模拟追逐。
