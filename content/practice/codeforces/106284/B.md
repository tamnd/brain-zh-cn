 ## 解决方案
 ## 问题理解

 我们有几种无符号整数类型。 类型与`a`位可以存储来自的值`0`到`2^a - 1`。 我们需要判断是否存在某个整数`x`适合较小的类型，但其正方形不适合较大的类型。 

换句话说，在给定的位大小中，我们需要知道是否有两种类型的大小`a < b`这样一些值可以表示为`a`位的平方需要超过`b`位。 

输入给出了可用类型的数量及其位容量。 输出是`YES`如果存在这样一对类型并且`NO`否则。 

这些限制很重要，因为类型的数量可以多达`100000`，而每个位的大小可以大到`10^9`。 比较每对类型的解决方案将执行大约`10^10`检查最坏的情况，这远远超出了典型的比赛时间限制所允许的。 我们需要一个接近的解决方案`O(n log n)`或更好。 

大值也意味着我们无法迭代可能的数字`x`或计算巨大的力量。 答案必须来自位长度本身之间的关系。 

棘手的部分是，相同的位大小不会创建有效的对，因为我们需要一个严格较小的类型`x`和一个严格更大的类型`x^2`。 例如，输入：```
2
5 5
```答案是：```
NO
```仅检查两个值是否不同的粗心解决方案可能会错误地接受它。 

当最小类型比最大类型小得多时，就会出现另一种边缘情况。 例如：```
3
1 2 3
```答案是：```
YES
```因为 1 位类型仅存储`0`和`1`，最大有用值为`1`，其平方仍然适合 2 位。 但是，size 2的类型可以存储`3`， 和`3^2 = 9`需要 4 位，这不适合 3 位类型。 仅在排序后检查相邻值的解决方案可能会丢失非相邻对。 

## 方法

 直接的方法是尝试每种较小的类型和每种较大的类型。 对于一对钻头尺寸`a`和`b`，适合较小类型的最大值是`2^a - 1`。 我们需要检查是否`(2^a - 1)^2 >= 2^b`。 如果为 true，则较小类型包含的值的平方会溢出较大类型。 

这种方法是正确的，因为检查最大值就足够了。 平方随着数字的增加而增加，因此如果最大可能值无法溢出，则更小的值也不会溢出。 

然而，检查所有对的速度太慢。 和`n = 100000`，对的数量大致为`n^2 / 2`，大约有 50 亿次比较。 

关键的观察是我们只关心位长度。 对于一个值`a`位，最大可能值的平方略小于`2^(2a)`。 这意味着类型`b`位可以保存从`a`-bit 类型仅当`b`至少是`2a`。 如果存在一个较大的类型且少于`2a`位，答案是立即`YES`。 

所以问题就变成了寻找是否存在一个bit size`a`其中另一个现有位大小大于`a`但小于`2a`。 我们可以对大小进行排序并保留迄今为止看到的最大值。 加工尺寸时`a`，我们需要知道是否存在至少为`a`？ 一种更简单的方法是降序排序并保留已处理的最大较小尺寸。 

可以使用排序数组检查条件。 对于每种尺寸，唯一危险的较大尺寸是低于其两倍的尺寸。 因为所有尺寸都是排序的，所以我们可以使用二分查找来查找是否存在这样的值。

 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 按升序对所有位大小进行排序。 排序后，给定类型的每个可能的较大类型都会出现在其右侧的某个位置。 
2. 对于每个位置`i`, 处理当前尺寸`a[i]`作为存储的类型`x`。 我们需要查找是否有一些后来的尺寸小于`2 * a[i]`。 这样的尺寸足以成为较大的类型，但又太小而无法存储每个可能的正方形。 
3. 使用二分查找查找后面的第一个索引`i`其值至少为`2 * a[i]`。 如果该索引不是数组的下一个边界，则之间存在一个值`a[i]`和`2 * a[i]`，所以答案是`YES`。 
4. 如果每种类型都通过了这次检查，则打印`NO`。 

为什么它有效：对于一种类型`a`位，它存储的最大值是`2^a - 1`。 对它进行平方得到一个小于`2^(2a)`并且非常接近这个极限。 小于的类型`2a`位不能代表所有这样的正方形。 由于我们只需要证明一个溢出值的存在，因此在下面找到一个更大的类型`2a`正是所要求的条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    for i in range(n):
        target = 2 * a[i]
        lo, hi = i + 1, n
        while lo < hi:
            mid = (lo + hi) // 2
            if a[mid] >= target:
                hi = mid
            else:
                lo = mid + 1
        if lo < n and lo > i + 1:
            print("YES")
            return

    print("NO")

solve()
```首先对数组进行排序，以便将所有较大的类型分组在一起。 对于每种类型，二分查找查找第一个不小于的大小`2 * a[i]`。 如果该位置不是下一个元素，则在它之前至少有一个较大的类型，并且该类型太小而无法安全地包含所有方块。 

乘以 2 是安全的，因为输入值适合`10^9`，因此中间值很容易适合 Python 整数。 二分查找从`i + 1`因为类型不能与其自身配对。

 ## 边缘情况

 对于相同大小的情况：```
2
5 5
```排序后的数组是`[5, 5]`。 对于第一个元素，后面的元素不小于`10`，但后面的元素无论如何也不会更大。 该算法从不接受相同的大小并返回`NO`。 

对于大间隙情况：```
3
1 2 3
```排序后，第一个值为`1`。 第一个尺寸至少为`2`是第二个元素，所以那里没有候选者。 对于尺寸`2`，我们至少需要一个值`4`，但值`3`在该边界之前找到，这意味着它大于`2`并且小于`4`。 算法返回`YES`，与 2 位数字在平方时可能溢出 3 位类型的事实相匹配。 

对于重复的情况：```
5
1 1 1 1 1
```每次搜索都在当前索引之后开始，但所有候选都具有相同的值。 没有值大于当前类型，因此不存在有效的对，答案是`NO`。 

对于非常大的输入：```
2
1000000000 1999999999
```第二个值大于第一个值，但仍小于第一个值的两倍。 算法正确检测间隔并返回`YES`无需尝试计算任何巨大的力量。
