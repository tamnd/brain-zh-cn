 ## 解决方案
 ## 问题理解

 我们有两个算术级数，$B$和$C$。 进展情况$C$包含某些未知级数共有的所有数字$A$和$B$。 我们的目标是计算有多少个有限算术级数$A$可能存在满足这个性质的。 一个进展$A$由其第一项、其公差及其项数唯一定义。 如果这三个值中的任何一个不同，则两个级数被视为不同。 

输入提供$B$和$C$标准算术级数格式：第一项、公差和项数。 由此，我们可以重建所有元素$B$和$C$如果需要的话。 输出必须是可能的级数$A$模数$10^9 + 7$， 或者$-1$如果存在无穷多个。 

约束很严格：$B$和$C$最多可以有$10^9$条款。 这使得完整序列的任何暴力生成都是不可能的。 相反，解决方案必须依赖算术推理和数论。 边缘情况发生时$C$不符合$B$，或者当$A$可以无限延伸超出$C$同时仍然匹配$C \cap B = C$。 例如，如果$B = [2, 7, 12, 17, 22]$和$C = [7, 12, 17, 22]$, 无穷多个$A$可以通过向后或向前扩展的算术步骤来实现$r$划分项之间的差异$C$。 

## 方法

 一个简单的方法是迭代所有可能的第一项$a$和差异$d$为了$A$并检查序列是否相交$B$准确地生产$C$。 这在原则上是正确的，但不可行，因为即使迭代差异达到$10^9$长度可达$10^9$产生天文数字的操作。 

关键的观察结果是第一项$A$必须与$C$，意味着第一项$A$是这样的形式$c - k \cdot r$对于某个整数$k \ge 0$。 同样，共同的区别是$A$必须除以公差$C$因为$C$是一个子序列$A$。 如果$d$的区别是$A$和$r$的区别是$C$， 然后$r \% d = 0$。 

此外，$A$不能引入任何属于以下范围的新术语$B$但不在$C$。 如果会的话$A \cap B$将包含超出的额外元素$C$，这是无效的。 这就是我们如何检测无限多个解决方案的情况：如果$A$可以延伸到外面$C$在不违反交集的情况下，解决方案的数量将变得无限。 

经过此推理，解决方案简化为迭代所有除数$r$，这是共同差异的潜在候选者$d$的$A$。 对于每个$d$，我们计算允许有多少个起点$A$覆盖$C$不包括额外的元素$B$外部$C$。

 ## 算法演练

 1. 检查是否$C$完全位于$B$通过验证第一项和最后一项$C$反对$B$还有那个$r$可以整除$q$。 如果任何条款$C$位于外面$B$，返回0。 
2.如果共同差异$q$的$B$是 0，那么$B$包含重复的相同元素。$C$必须全部相同$B$，否则返回0。如果$C$是相同的，有无穷多个$A$（返回-1）。 
3. 计算所有正因数$r$，因为这是唯一可能的差异$d$为了$A$与$C$。 
4. 对于每个除数$d$,检查是否扩展$A$之前或之后一步$C$会添加数字$B$外部$C$。 如果是，请跳过此步骤$d$。 否则，计算序列数$A$使用$d$完全覆盖$C$仅此而已$B$。 计数与第一项可以在其之前开始的方式数成正比$C$的倍数$d$。 
5. 所有有效的总和$d$并取模$10^9+7$。 

为什么有效：该算法利用了序列的算术特性。 通过限制为除数$r$，我们保证$A$可以包含$C$作为子序列。 前向/后向扩展检查保证没有无关项进入交集，从而正确处理无限解。 每个除数恰好占一个结构$A$，确保我们计算所有有效序列而不重复。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline
MOD = 10**9 + 7

def divisors(n):
    res = set()
    for i in range(1, int(n**0.5)+1):
        if n % i == 0:
            res.add(i)
            res.add(n//i)
    return res

def solve():
    t = int(input())
    for _ in range(t):
        b, q, y = map(int, input().split())
        c, r, z = map(int, input().split())
        
        last_b = b + (y-1)*q
        last_c = c + (z-1)*r

        # Check C inside B
        if (c < b) or (last_c > last_b) or ((c-b)%q != 0) or ((last_c - b)%q != 0):
            print(0)
            continue

        # Infinite solutions check
        inf = False
        if q == 0:
            if r != 0 or y != z or b != c:
                print(0)
                continue
            else:
                print(-1)
                continue

        ans = 0
        for d in divisors(r):
            # Check for extraneous B elements
            ok = True
            if (c - d >= b) and ((c - d - b) % q == 0):
                ok = False
            if (last_c + d <= last_b) and ((last_c + d - b) % q == 0):
                ok = False
            if ok:
                ans = (ans + pow(r//d, 2, MOD)) % MOD
        print(ans)

solve()
```该解决方案可高效读取输入，首先检查边界条件，计算除数，并对有效序列进行模数计数$10^9+7$。 扩展检查可防止序列中包含不需要的元素$B$。 中的平方`pow(r//d, 2)`计算第一项和最后一项沿除数间距的所有位置。
