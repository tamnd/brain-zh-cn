 ## 解决方案
 ## 问题理解

 我们的房屋均匀地分布在圆形湖周围。 有`N`房屋和相邻房屋之间有一定距离`D`。 一栋房子是起点。 米哈伊尔必须每隔一所房子就访问一次，并亲自选择顺序。 两个连续房屋之间的每次移动都使用绕圆圈的较短路线。 目标是最大化步行的总距离。 

输入包含`N`，房屋数量，以及`D`，相邻房屋之间的距离。 输出是最大可能的步行距离。 

主要困难在于可能的访问订单数量巨大。 和`N`达到一百万，即使是检查所有排列的算法也是不可能的。 阶乘搜索立即被排除，甚至二次解也太大了，因为在最大的情况下它们将执行大约一万亿次运算。 预期的解决方案必须导出数学模式并在恒定时间内运行。 

一些边缘情况可能会破坏仅猜测模式的实现。 当有三栋房子，邻居之间的距离是五时，答案是`10`。 该路径必须进行两次移动，并且两次移动的长度都可以为 5，因为每对房屋都在三角形上相邻。 假设最大跳跃总是的解决方案`floor(N/2)`并乘以移动次数在这里给出了正确的结果，但是这个想法甚至失败了`N`。 

例如，输入：```
6 10
```最大可能的单跳是`3 * 10`，但不能进行五次这样的跳跃，因为在反复占据相反的房屋后，剩余的位置会迫使移动更短。 正确答案是`130`， 不是`150`。 缺少的洞察力是`N`改变最优路径的结构。 

另一个边界情况是当`N`很奇怪。 对于输入：```
5 1
```答案是`8`。 粗心的实现可能会尝试使用偶数情况公式并获得较小的值。 在一个奇数大小的圆圈上，可以重复跳跃最大可能的距离并访问每一个房屋。 

## 方法

 直接的方法是尝试每一种可能的访问顺序。 对于每个排列`N - 1`在朋友的房子里，我们模拟步行并添加连续房屋之间的最短圆形距离。 这是正确的，因为每条可能的路线都会被检查。 然而，排列的数量是`(N - 1)!`，即使对于很小的值，这也是不可能的`N`。 对于一百万栋房屋来说，这种方法根本不可行。 

圆圈的结构提供了更强的观察力。 唯一重要的是每次跳跃可以多远。 对于奇数个房屋，令`N = 2k + 1`。 准确地跳跃`k`周围的房子总是搬到新房子，并反复添加`k`模数`N`走访每户人家，因为`k`和`2k + 1`是互质的。 因此每一位`N - 1`动作可以有长度`k`。 

对于偶数个房屋，令`N = 2k`。 最大可能的跳跃是`k`，到达对面的房子。 使用这样的跳转后，下一个有用的跳转模式将在长度之间交替`k`和长度`k - 1`。 有订单的路线```
0, k, 1, k+1, 2, k+2, ...
```走访每户人家。 它包含`k`长度跳跃`k`和`k - 1`长度跳跃`k - 1`，给出最大可能的总数。 

这是最佳的原因是每次移动都受到圆上最大可能距离的限制。 在奇怪的情况下，每次移动都会达到上限。 在偶数情况下，尝试使用太多相反的跳跃将迫使重新访问房屋，因此剩余的跳跃必须至少失去一个单位的距离。 交替结构恰恰丢失了那些不可避免的单元。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((N-1)!) | O(N) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`N`和`D`。 我们首先计算以相邻间隙为单位的最大距离，然后乘以`D`在最后。 
2. 检查是否`N`很奇怪。 如果`N = 2k + 1`，每个动作都可以有长度`k`，并且有`2k`移动。 答案的单位为`D`是`2k * k`。 
3.如果`N`是偶数，写成`N = 2k`。 最优路径有`k`长度移动`k`和`k - 1`长度移动`k - 1`。 答案的单位为`D`是`k * k + (k - 1) * (k - 1)`。 
4. 将结果乘以`D`并打印它。 Python 整数是任意精度的，因此最大可能值不需要特殊处理。 

原理：两栋房子之间的每次移动都受到半个圆的限制。 对于奇数`N`，最大跳跃长度为`k`，以及添加的模块化序列`k`每次都到达每个顶点，因此所有移动都达到上限。 对于甚至`N`，最大跳跃长度为`k`，但相反的顶点形成对。 在进行反向跳跃之后，下一次跳跃不能再次到达另一个未使用的反向顶点而不产生冲突。 交替结构达到了最大可能的长跳数量，并用最大的可用短跳填充了所有剩余的动作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, d = map(int, input().split())

    if n % 2 == 1:
        k = n // 2
        ans = 2 * k * k
    else:
        k = n // 2
        ans = k * k + (k - 1) * (k - 1)

    print(ans * d)

if __name__ == "__main__":
    solve()
```变量`k`表示在相邻房屋之间的间隙中测量的最大可能跳跃长度。 对于奇数`N`，正好有`2k`移动并且每一步都到达那个距离。 对于甚至`N`，公式分别统计了圆形排列所强制的长跳和稍短的跳。 

乘以`D`被延迟到最后，因为问题的组合部分仅取决于跨越的间隙的数量。 这也使得公式更容易验证。 没有数组索引或模拟，因此构建实际路线时不会出现边界错误。 

## 工作示例

 对于第一个样本，`N = 3`和`D = 5`。 圈子里有`k = 1`。 

| 步骤| N型| k | 间隙距离|
 | --- | --- | --- | --- |
 | 1 | 奇数| 1 |`2 * 1 * 1 = 2`|
 | 2 | 乘以 D | 1 |`2 * 5 = 10`|

 该路线可以使用长度为一个间隙的两种可能的移动，给出答案`10`。 

对于第二个样本，`N = 6`和`D = 10`。 这里`N = 2k`， 所以`k = 3`。 

| 步骤| N型| k | 间隙距离|
 | --- | --- | --- | --- |
 | 1 | 甚至| 3 |`3 * 3 = 9`|
 | 2 | 剩余短期走势 | 3 |`2 * 2 = 4`|
 | 3 | 总差距| 3 |`9 + 4 = 13`|
 | 4 | 乘以 D | 3 |`13 * 10 = 130`|

 施工对应顺序`0, 3, 1, 4, 2, 5`，产生跳跃长度`3, 2, 3, 2, 3`。
