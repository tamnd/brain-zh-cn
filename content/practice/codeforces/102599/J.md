 ## 解决方案
 ## 问题理解

 我们有一系列的柱子高度。 目标是选择一个最终高度`x`并变换每根柱子，使其高度恰好变为`x`。 增加支柱成本`A`每添加一块砖，移除一块砖的成本`R`每移除一块砖块，并将一块砖块从一根柱子移动到另一根柱子上会产生成本`M`。 

输出是最终高度的所有选择中可能的最小总成本。 

柱子数量可达`100000`，因此尝试每个可能的高度直至最大砖块数量是不现实的。 高度可以大到`10^9`，这会根据高度的数字范围排除任何方法。 我们需要一个接近的算法`O(N log N)`或者`O(N)`排序后，因为迭代太多候选高度将超出可用操作。 

一个常见的错误是假设最佳最终高度必须是平均值或中位数。 运营成本改变了答案。 例如，如果添加砖块非常便宜，则最佳高度可以高于平均高度，因为移除砖块的成本很高。 

当移动砖块比单独移除和添加砖块更便宜时，就会出现另一种边缘情况。 考虑：```
3 100 100 1
1 3 8
```正确答案是`4`。 砖块总数为`12`，所以使每个柱子的高度`4`只需要从高度的柱子上搬砖`8`到高度的柱子`1`。 仅比较独立添加和删除的解决方案将错过这种更便宜的传输。 

第二种边缘情况是当一个操作方向是自由的时。 例如：```
2 0 100 100
0 5
```正确答案是`0`。 将空柱升高到一定高度`5`不花钱，所以目标高度`5`是免费的。 总是假设必须移动或移除一些砖块的粗心实施会产生积极的成本。 

第三种边缘情况是所有柱子都具有相同高度时：```
3 10 20 5
7 7 7
```正确答案是`0`。 该算法必须考虑当前高度作为候选，并避免执行不必要的操作。 

## 方法

 一个简单的解决方案是尝试所有可能的最终高度。 对于每个候选人身高`x`，我们计算必须添加多少块砖以及必须移除多少块。 然后我们计算修复差异的成本。 这是正确的，因为每个可能的答案都会被检查。 

然而，最大高度可以是`10^9`，所以扫描所有可能的`x`值最多需要`10^9`评价。 即使一次评估也需要`O(N)`，导致大约`10^14`最坏情况下的操作，远远超出了极限。 

关键的观察结果是成本函数是凸的。 如果我们将目标高度增加一，需要添加或移除的砖块数量会逐渐变化。 总成本逐渐下降，直到达到最佳值，然后增加。 整数范围内的凸函数可以通过斜率上的二分搜索来最小化。 

对于固定目标高度`x`，每根高度低于的柱子`x`有助于所需的补充，以及上面的每个支柱`x`有助于清除。 如果我们能够有效地计算这两个数量，我们就可以评估任何成本`x`迅速地。 

对高度进行排序可以让我们使用二分搜索找到有多少根柱子低于候选高度。 前缀总和让我们可以计算缺失或额外砖块的总数，而无需每次都遍历所有支柱。 然后我们对答案高度进行二分搜索。 

暴力方法之所以有效，是因为它检查了每个可能的目标，但由于范围太大而失败。 观察到成本曲线是凸的，将搜索从数十亿个候选减少到大约 31 个检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(NH)，其中 H 是最大高度 | O(1) | O(1) | 太慢了 |
 | 最佳 | O(N log N + log(H) log N) | O(N log N + log(H) log N) | O(N) | 已接受 |

 ## 算法演练

 1. 对柱子高度进行排序并构建前缀和数组。 前缀总和使我们能够立即找到任何柱子前缀的总高度，这使得成本计算与柱子的数量无关。 
2. 定义一个函数来计算所选目标高度的成本`x`。 对已排序的数组使用二分查找来找到高度至少为第一个的柱子`x`。 该位置之前的柱子需要添加砖块，其余柱子有多余的砖块需要拆除或移走。 
3. 计算下侧缺失的砖块和上侧多余的砖块数量。 这两个值代表达到高度所需的工作量`x`。 
4. 尽可能使用移动的砖块。 从一根柱子上取下一块砖并添加到另一根柱子上可以同时满足这两种操作。 此类移动的次数是缺少的砖块数和多余的砖块数中的最小值。 
5. 将搬迁成本限制在`min(M, A + R)`。 如果移动一块砖的成本比移除它并添加新砖的成本更高，那么就没有理由移动它。 
6. 二分查找目标高度。 比较成本`mid`和`mid + 1`。 如果成本下降，则向上移动搜索范围。 否则，将其向下移动。 最小成本出现在斜率变化点附近。 

为什么有效：选择目标高度的成本具有凸形状。 从左到右移动目标高度会以可预测的方向改变成本：在最佳值之前，增加目标会比增加添加物更快地减少昂贵的移除，而在最佳值之后会发生相反的情况。 二分查找找到转变点。 对于任何固定目标，成本计算都是准确的，因为所有可能的砖块转移都会在有利时首先使用，而剩余的差额则通过添加或移除来处理。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, A, R, M = map(int, input().split())
    h = list(map(int, input().split()))

    h.sort()
    pref = [0]
    for x in h:
        pref.append(pref[-1] + x)

    M = min(M, A + R)

    def cost(x):
        import bisect

        idx = bisect.bisect_left(h, x)

        need = x * idx - pref[idx]
        extra = (pref[n] - pref[idx]) - x * (n - idx)

        move = min(need, extra)
        need -= move
        extra -= move

        return move * M + need * A + extra * R

    left = h[0]
    right = h[-1]

    while left < right:
        mid = (left + right) // 2
        if cost(mid) <= cost(mid + 1):
            right = mid
        else:
            left = mid + 1

    print(cost(left))

if __name__ == "__main__":
    solve()
```排序后的数组和前缀和数组对应于算法的第一步。 排序后，每个候选高度将柱子分为下组和上组，这就是为什么可以对排序位置进行二分搜索。 

这`cost`函数首先找到分割点`bisect_left`。 表达式`x * idx - pref[idx]`计算低于目标的砖块数量。 表达式`(pref[n] - pref[idx]) - x * (n - idx)`计算高于目标的多余砖块。 

转移计算是在添加和删除之前处理​​的。 这个顺序很重要，因为移动一块多余的砖块可以同时修复一块缺失的砖块。 有用的移动次数受到较小一侧的限制，因此`min(need, extra)`是正确的金额。 

移动成本替换为`min(M, A + R)`因为比单独创建和删除砖块花费更多的移动永远不会有用。 

Python 整数不会溢出，这是必要的，因为总成本可以达到大约`10^18`。 二分查找使用`h[0]`和`h[-1]`作为边界，因为此间隔之外的目标永远不会比最近的边界更好。

 对于第一个样本：```

 最佳高度是`4`。 可以从最高的柱子上移走四块砖，然后添加一块额外的砖，给出答案`12`。 

对于第二个样本：```

1 3 8
```有效移动成本为`100`，同时添加和删除成本`101`。 

| 目标| 失踪| 额外 | 移动| 总成本|

import io
import bisect

def solution(inp: str) -> str:

    input = sys.stdin.readline

    n, A, R, M = map(int, input().split())
    h = list(map(int, input().split()))

    h.sort()
    pref = [0]
    for x in h:
        pref.append(pref[-1] + x)

    M = min(M, A + R)

    def cost(x):
        idx = bisect.bisect_left(h, x)
        need = x * idx - pref[idx]
        extra = pref[n] - pref[idx] - x * (n - idx)

        if cost(m) <= cost(m + 1):

 ## 边缘情况

 对于廉价机芯情况：```
3 100 100 1
1 3 8
```该算法评估最佳值附近的候选高度。 在高处`4`，有三块缺失的砖块和四块多余的砖块。 三个动作将砖块从最高的柱子转移到最短的柱子，留下一块额外的砖块需要移除。 成本是`3 * 1 + 1 * 100 = 103`对于那个高度，但是高度`3`更好：两步固定第一根柱子，剩下五块砖需要拆除，给出`2 + 5 = 7`。 二分查找达到正确的最小值`4`通过凸成本函数。 

对于免费添加的情况：```
2 0 100 100
0 5
```目标高度`5`给出一根空柱子需要五块砖并且没有多余的砖。 添加成本为零，因此总成本为零。 成本函数可以处理这种情况，因为允许缺失和额外计数不平衡。 

对于等柱：```
3 10 20 5
7 7 7
```每个可能的修正都在高度上进行计算`7`为零。 该函数返回零，二分查找将答案保持在有效范围内，直到达到现有高度。 该解决方案不会强制执行不必要的操作。
