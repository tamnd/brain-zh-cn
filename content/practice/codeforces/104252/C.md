 ## 解决方案
 ## 问题理解

 我们从一张纸条开始，它在概念上分为$2^N$相等的段。 阿米莉亚的家位于已知的段指数$P$。 条带反复折叠$N$次。 每次折叠都会将当前的条带从中间分开，然后将一半放在另一半的上面。 每次折叠的方向都在我们的控制之下：要么左半部分位于右半部分之上，要么右半部分位于左半部分之上。 

全部折叠后，条带就变成了一堆$2^N$层。 每个原始片段最终都从下到上到达某个最终层位置。 任务是选择折叠方向的顺序，以便包含 Amelia 家的线段最初位于位置$P$，最终精确到高度$H$在最后的堆栈中。 

重要的是，每次折叠不会随机排列所有片段。 相反，它确定性地重新排列两半，这会产生递归结构：每次折叠都会细化间隔的反转和堆叠方式。 问题本质上是要求我们构建一个二元决策路径，将一个索引映射到一个大小$2^N$在一系列受控逆转之后达到目标排名的间隔。 

约束条件$N \le 60$是关键信号。 大小的配置空间$2^N$是一个天文数字，因此对所有段进行任何模拟或对带的显式构造都是不可能的。 即使明确地表示该带也是不可能的。 该解决方案必须适用于$O(N)$，可能使用位级推理或区间变换的递归映射。 

折叠方向如何翻转会产生一个微妙的问题。 逐层跟踪所有片段位置的简单模拟很容易失败，因为它忽略了每次折叠都会反转两半内部的相对顺序，并且这种效应会随着级别的增加而复合。 另一个常见的陷阱是将过程视为层的独立插入，而不是反转的结构化二叉树。 

例如，用小$N = 2$，人们可能会假设仓位根据弃牌选择单调向上移动。 实际上，一个段可能会向上或向下移动，具体取决于它在每个阶段是位于左半部分还是右半部分，以及该半部分在堆叠之前是否翻转。 天真的贪婪模拟会错误预测最终层位置，因为它失去了方向反转的跟踪。 

## 方法

 强力解释将明确模拟该条带。 在每一步中，我们将当前的段列表分成两半，然后将反向左附加到右上或将右反向附加到左上。 每一步都会使结构尺寸加倍，所以之后$N$我们有的步骤$2^N$元素。 即使代表这种结构成本$O(2^N)$，并表演$N$转变导致$O(N \cdot 2^N)$，这对于$N = 60$。 

关键的观察是我们永远不需要完整的结构。 我们只需要跟踪一个片段，$P$，并确定其最终位置$H$。 每次折叠只告诉我们区间如何包含$P$被分割和翻转。 我们不是构建整个排列，而是通过递归二进制分区跟踪单个索引。 

每一步的间隔大小$2^k$被分成两半大小$2^{k-1}$。 折叠选择决定左半部分是成为新堆栈的上半部分还是下半部分。 这会导致目标段的索引及其对最终堆栈位置的最终贡献发生确定性转换。 

我们可以逆转这个过程：我们不模拟向前折叠，而是解释最终位置$H$以二进制形式并重建需要哪些折叠决策，以便$P$映射到该位置。 每个步骤有效地决定目标高度的当前位是否对应于来自上半部或下半部，以及是否需要反转。 

这将问题简化为在匹配时对区间进行二元分解$P$到一片叶子，同时强制其最终深度等于$H$。 唯一性保证意味着每一步都有一个有效的方向来保持一致性。

 | --- | --- | --- | --- |
 | 暴力模拟|$O(N \cdot 2^N)$|$O(2^N)$| 太慢了 |

 ## 算法演练

 我们将该过程视为重复分割当前间隔并确定目标位置相对于该分割的位置。 最终的堆栈位置以二进制编码，每次折叠对应于解析一位结构。 

### 步骤

 1. 将问题解释为追踪位置$P$移动通过$N$二进制分裂。 每个分割将当前段范围分为左半部分和右半部分。 折叠方向决定左端是否在右端上方，反之亦然。 
2. 维持当前间隔$[l, r]$代表我们正在跟踪的细分范围。 最初，$l = 1$,$r = 2^N$， 和$P$位于里面的某个地方。 
3. 在每一步中，计算中点$m = (l + r) / 2$。 决定是否$P$位于左半部分$[l, m]$或右半边$[m+1, r]$。 这个选择决定了我们在递归中遵循哪一边。 
4. 同时考虑所需的最终高度$H$。 在每个级别，$H$也在于与堆叠顺序相对应的结构化区间。 我们判断是否$H$对应于当前折叠形成的顶部或底部块。 
5. 折叠选择是由一致性强制的：如果将左放在右对齐包含的一侧，我们选择“L”$P$与需要到达的一侧$H$，否则我们选择“R”。 
6. 将间隔更新为包含的一半$P$，并继续直到所有$N$折叠决定了。 

### 为什么它有效

 每次折叠都会导致段间隔的二进制划分，同时导致最终堆栈位置的二进制划分。 该系统是一个完整的二叉树，其中叶子对应于原始段，根到叶子路径对应于折叠决策。 因为每次折叠只交换两半而不会在它们内部混合，所以每半内部的相对结构保持完整。 这保证了在每个级别，位置之间都有唯一一致的映射$P$和目标高度$H$，因此贪婪的局部决策在全球范围内仍然有效。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N, P, H = map(int, input().split())
    
    # We simulate intervals of size 2^k.
    l, r = 1, 1 << N
    p = P
    h = H
    
    ans = []
    
    for _ in range(N):
        mid = (l + r) // 2
        
        # determine which half P is in
        if p <= mid:
            p_side = 0  # left
        else:
            p_side = 1  # right
        
        # determine which half H is in
        if h <= mid:
            h_side = 0  # bottom half in current view
        else:
            h_side = 1  # top half in current view
        
        # If we fold left over right (L):
        # left becomes top, right becomes bottom
        # so left -> top, right -> bottom
        #
        # If we fold right over left (R):
        # right becomes top, left becomes bottom
        
        # We choose fold so that p_side ends up consistent with h_side
        # under stacking transformation.
        
        if p_side == h_side:
            ans.append('L')
        else:
            ans.append('R')
        
        # update interval to the side containing P
        if p_side == 0:
            r = mid
        else:
            l = mid + 1
    
    print("".join(ans))

if __name__ == "__main__":
    solve()
```该实现保持了不变式$[l, r]$始终包含原始位置$P$，每一步将间隔缩小一半。 决策规则比较双方的哪一方$P$和目标高度$H$位于当前水平，并选择对齐其相对方向的折叠。 折叠特征是本地决定的，而间隔更新确保我们始终与递归分解保持一致。 

主要的微妙之处在于中点分区同时代表空间分割和堆叠结构。 将它们视为相同的二进制分割可以让算法避免显式模拟堆栈。

 ## 边缘情况

 一个关键的边缘情况是当$P$和$H$从不同的半部分开始，但仅在几次分裂后才收敛到最终分区的同一部分。 例如，与$N = 3$,$P = 6$,$H = 3$，第一次分割立即将它们分开，迫使选择提前翻转方向的折叠选择。 该算法处理此问题是因为它始终比较当前间隔大小的侧成员资格，而不是假设全局对齐。 

另一种情况是当$P = H$，其中目标细分市场应在所有级别上保持一致。 在这种情况下，算法始终会看到$p\_side = h\_side$每一步都会产生统一的折叠序列。 这对应于二元分解树的单调路径，并且不会出现矛盾，因为间隔更新始终保留以下不变式：$P$保持在跟踪段范围内。 

最后，边界情况如$P = 1$或者$P = 2^N$强调更新间隔。 由于中点是按整数除法计算的，因此左半部分始终包含较低的索引，右半部分始终包含较高的索引，从而确保在缩小间隔时不会出现差一的歧义。
