 ## 解决方案
 ## 问题理解

 我们给定了一个目标字符串`T`必须由简单的印刷机生产。 本机不直接打印任意文本。 相反，每条指令都由一个字符串组成`s`和重复次数`n`。 机器输出字符串`s`循环重复，直到产生`n`人物。 

所以如果`s = "abcd"`和`n = 10`，输出是`"abcdabcdab"`。 输出中的每个位置仅取决于`i mod |s|`。 

我们的任务是构造给定的字符串`T`通过连接多个此类指令的输出。 每条指令都有一个限制：字符串`s`该指令中使用的长度最多必须为`D`。 我们希望最大限度地减少指令数量。 

关键的困难在于指令不仅仅附加字符，它们还生成周期性模式。 所以一条指令可以覆盖多个字符`T`仅当周期性结构符合我们的需要时。 

约束条件允许`|T|`最多 200000。这立即排除了任何直接尝试所有子串和所有指令分组的解决方案，因为对所有间隔的简单划分至少是二次或更差。 

当字符串具有较大的重复结构但稍微未对齐时，就会出现微妙的边缘情况。 

例如，如果`T = "abababxababab"`和`D = 2`，一种贪婪的方法，在字符匹配时总是扩展当前指令，可能会尝试将所有内容吸收到`"ab"`重复，然后单次失败`x`，并且重新启动效率低下。 正确的解决方案认识到，只有当周期段稳定时，周期段才是最大的。 

另一个边缘情况是当`D = 1`。 每个指令字符串都是一个字符，因此每个指令都会生成一个统一的块，例如`"aaaaaa"`。 那么答案就是运行的字符数`T`，而不是不同字符的数量。 

## 方法

 蛮力观点是从分割字符串的角度来思考`T`分成段，其中每个段对应一条指令。 对于从位置开始的段`i`，我们尝试每一个可能的长度`L`，以及每个可能的字符串`s`长度可达`D`，并检查是否重复`s`准确生成该段。 这将需要检查每个候选段的周期性约束的一致性，这已经花费了`O(L)`每张支票有`O(n^2)`段和呈指数级增长的候选模式。 即使我们修复`s`通过观察第一个`D`对于字符，扩展段仍然会导致二次扫描，因此这种方法远远超出了可行的限制。 

重要的观察是每条指令定义了一个周期模式，我们只关心前缀有多长`T`可以用周期最多的单个周期函数来解释`D`。 如果我们知道从位置开始的最长前缀`i`可以由一条指令生成，我们可以直接跳过它。 这将问题转化为使用最大有效周期覆盖沿着字符串重复跳跃。 

核心理念是计算，适用于每个职位`i`，最大`j ≥ i`这样子串`T[i:j]`可以由一些周期串产生`s`最多有长度`D`。 然后我们贪婪地获取这些最大的段，因为任何有效的解决方案都必须在最早的未覆盖位置开始每条指令，并且尽可能地扩展它永远不会有坏处，因为指令是独立的。 

技术挑战是如何有效地检查这一点。 而不是尝试所有`s`，我们使用这样一个事实：对于固定段，有效指令意味着对于每个偏移量`k`, 位置处的字符`i + k`和`i + k mod |s|`必须同意。 这意味着在一个窗口内，所有以某个周期为模的全等位置必须是一致的。 

我们可以维护，对于每个候选期，最多`D`，扩展段是否仍然有效。 一个更有效的观点是认识到一个段是否在一段时间内有效`p`，那么所有位置`i`和`i + p`段内必须匹配。 因此，我们可以维护当前的活动段并尝试扩展它，同时保持所有时期的一致性`D`。 

这会导致贪婪扫描：我们维护当前段的开头，并尝试扩展其结尾，同时确保任何偏移模数都不会出现冲突`1..D`。 一旦出现冲突，我们就关闭该段并开始新的指令。

 | ---| ---| ---| ---|
 | 暴力破解段枚举 | O(n²D) 或更差 | O(1) | O(1) | 太慢了 |
 | 带检查的贪婪周期性分段| O(nD) | O(n) | 已接受 |

 ## 算法演练

 我们从左到右处理字符串，贪婪地构建指令。 

1. 从位置开始`i = 0`。 这是第一条指令的开始。 我们将尝试扩展该细分市场`[i, r)`尽可能。 
2. 对于固定的起始位置`i`，我们尝试维护一个有效性结构，确保当前段最多可以由某个长度的周期字符串生成`D`。 具体来说，我们跟踪在任何有效期限内需要匹配的位置之间的一致性约束。 
3.我们扩展一个指针`r`从`i`向右。 当我们考虑添加角色时`T[r]`，我们检查它是否违反由位置引起的任何周期性约束`r - p`为了`1 ≤ p ≤ D`。 如果有的话`T[r] != T[r - p]`对于相关的强制对齐，则进一步扩展当前指令将破坏周期性一致性。 
4. 如果没有检测到冲突，我们将包括`r`在当前指令中并继续。 
5. 当我们遇到冲突或字符串末尾时，我们最终确定一条指令，涵盖`[i, r)`，增加答案，并设置`i = r`开始新的指令。 

这样做的原因是任何指令都必须对应于单个周期结构。 一旦出现与所有可能的周期不匹配的情况，`D`，没有有效的指令可以在不违反周期性的情况下包含该位置。 所以贪婪切割是被迫的，而不仅仅是方便。 

不变的是当前段`[i, r)`总是可以用至少一个长度最多的周期串来表示`D`。 我们只是在保留这个不变量的同时进行扩展，并且对于每个可能的周期选择，我们都会在它被违反的时候精确地进行削减。 这确保了每个段在可行性下是最大的，并且最大可行段最小化了序列的分区中的段的数量，其中每个段必须独立地满足结构约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    line = input().strip().split()
    T = line[0]
    D = int(line[1])
    n = len(T)

    # last occurrence tracking per offset pattern is not needed explicitly,
    # we maintain compatibility checks with a sliding window idea.
    # We use a simple greedy check with an array storing last D characters
    # for periodic validation.

    ans = 0
    i = 0

    while i < n:
        ans += 1
        # start new segment
        seen = [{} for _ in range(D + 1)]
        # seen[p][k] = character at position congruent k mod p in current segment

        r = i
        ok = True

        while r < n and ok:
            c = T[r]
            # try to place r into any period structure up to D
            ok = False

            for p in range(1, D + 1):
                k = r % p
                if k in seen[p]:
                    if seen[p][k] != c:
                        continue
                seen[p][k] = c
                ok = True
                break

            if ok:
                r += 1

        i = r

    print(ans)

if __name__ == "__main__":
    solve()
```该代码实现了贪婪分割。 外循环启动每条指令。 对于每个片段，我们为每个可能的周期长度维护一系列候选周期解释`D`。 对于每个新角色，我们尝试将其一致地分配到至少一个时期桶中。 如果没有句点分配可以容纳该字符，则当前段必须结束。 

一个微妙的点是我们重新启动`seen`每个段的结构，因为每条指令都是独立的。 内部逻辑确保我们仅在至少一个时期假设保持一致的情况下进行扩展。 

正确性取决于这样一个事实：任何有效的指令必须承认至少一种一致的周期解释，一旦所有解释失败，就不可能进行扩展。

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys

 ## 边缘情况

 一个关键的边缘情况是字符串是完全周期性的，但最佳分段取决于尽早识别有效周期。 为了`T = "abababab", D = 2`，该算法使周期 1 和 2 都保持可行，但周期 2 对于整个字符串保持一致，因此该段永远不会中断，答案为 1。 

另一个边缘情况是当`D`很大但是字符串没有重复。 为了`T = "abcdef", D = 6`，每个新角色最终都会打破除琐碎假设之外的所有时代假设，迫使每个角色成为自己的指令。 一旦没有有效的周期分配，算法就会检测到这一点，确保立即剪切而不是不必要的扫描。 

最后的边缘情况是具有中断的交替结构，例如`"ababaxababa"`。 The moment the mismatch`x`看来，所有依赖于一致性的周期解释都会同时崩溃，迫使恰好在中断点处进行削减，这对于最优性至关重要。
