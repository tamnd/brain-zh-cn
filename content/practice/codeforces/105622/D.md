 ## 解决方案
 ## 问题理解

 我们有一棵树，其中每条边都带有非零权重，无论是正数还是负数。 不同的是，我们可以重复选择任意两条边并交换它们的权重，因此最终我们可以在边上任意排列多组权重。 

重新排列后，我们查看树中至少使用一条边的所有简单路径。 仅当我们遍历路径时，连续边的符号严格在正负之间交替时，路径才被视为有效。 此类路径的值是其边权重之和。 在所有有效路径中，我们感兴趣的是最大可能的总和，并且我们希望首先选择边缘重新排序以使这个最佳可能值尽可能大。 

重要的一点是我们没有优化固定的树标签。 我们正在优化如何将权重分配给边缘，然后才考虑最佳的交替符号路径。 

约束多达二十万个节点，这立即排除了任何显式尝试所有路径或模拟分配的解决方案。 在最坏的情况下，即使枚举树中的所有路径也是二次的，因为链已经具有 O(n²) 条子路径。 

当局部思考时，会出现一个微妙的问题。 如果我们忽略全局结构，只是尝试贪婪地为某些“重要”边分配较大的权重，我们可能会错过交换使图完全对称的情况：只有权重的多重集很重要，而不是哪条边最初具有哪条权重。 

另一个常见的陷阱是假设树结构严重限制了答案。 交换后，树只在最大可能的路径长度上起作用，因为我们可以沿着任何选定的路径放置任何权重序列。 

一个简单但危险的例子是，除了一个负值之外，所有权重均为正值。 一个幼稚的策略可能会尝试隔离负面因素，但由于我们可以任意重新排列，因此可以将负面因素放置在任何选定路径上的任何位置，从而改变哪条路径变得最佳。 

## 方法

 蛮力视角是固定对边的权重分配，然后通常通过考虑所有简单路径并检查交替条件来计算树中的最佳交替路径。 即使我们可以有效地评估一个分配，分配的数量也是边数量的阶乘，这是立即不可行的。 

关键的观察是交换使分配问题完全独立于树结构。 我们只关心我们在一条路径中采用了多少条边以及我们在这些边上放置了哪些权重。 一旦长度为 k 的路径固定，树只提供这样的路径必须存在的约束，这意味着 k 不能超过树的直径。 

所以问题分为两个独立的部分。 首先，确定树中最长的简单路径，因为这是任何候选路径可以使用的最大边数。 其次，假设我们可以选择沿路径的任意 k 个边，我们从多重集中分配权重以最大化交替和。 

对于固定长度 k，在考虑排序时，最佳构造是直观的。 我们希望大的正值能够做出积极的贡献，而大的负值则被放置在交替要求迫使它们发挥作用的位置。 最好的策略是按绝对值降序对正权重和负权重进行降序排序（相当于首先是最负的），然后沿着路径从这些池中交替挑选。 

如果我们将排序后的正数表示为 pos，将负数表示为 neg，那么对于长度为 k 条边的路径，最佳值来自于从更好的选择开始，以交替顺序取大约一半正数和一半负数。 这导致了基于前缀和的直接公式。

最后，我们评估直到树直径的所有可行路径长度 k 并选择最佳值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解分配和路径 | 指数 / O(n³) 或更差 | O(n) | 太慢了|
 | 排序权重+直径+前缀评估 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算树的直径。 这给出了任何简单路径中的最大可能边数。 我们可以通过两次 DFS 运行来完成此操作：首先找到最远的节点，然后从该节点找到最远的距离。 
2. 将所有边权重分成两个数组，正数和负数。 正数按降序排列。 负数按升序排序（最负数排在第一位），因为它们是负数绝对值的最大贡献者。 
3. 为两个数组构建前缀和，以便我们可以快速计算顶部元素的和。 
4. 对于固定路径长度 k（边数），计算理想情况下我们将填充交替图案的正负位置数。 如果我们从正边缘开始，我们使用 ceil(k/2) 正值和 Floor(k/2) 负值。 如果我们从负优势开始，角色就会互换。 我们对两者进行评估并取最大值。 
5. 将 k 从 1 迭代到 min（直径、边总数），使用前缀和计算每个 k 的最佳可实现值，并跟踪最大值。 
6. 输出所有 k 中的最佳值。 

评估所有 k 是安全的原因是，较长的路径并不总是更好：添加一条边可能会导致更差的符号放置模式，因此即使存在较长的路径，也可能会在较小的长度处出现最佳结果。 

### 为什么它有效

 一旦边权重可以任意排列，树结构就只限制我们可以在简单路径中连续使用多少条边。 交替符号条件强制在任何选定的路径上采用严格的模式，这意味着只有选定权重的顺序很重要，而不是它们的原始放置。 排序确保我们始终将最大的可用正贡献与可用槽相匹配，并且直径约束确保我们永远不会假设一条路径比树可以实现的路径长。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def diameter(n, adj):
    from collections import deque

    def bfs(start):
        dist = [-1] * (n + 1)
        q = deque([start])
        dist[start] = 0
        far = start

        while q:
            u = q.popleft()
            for v in adj[u]:
                if dist[v] == -1:
                    dist[v] = dist[u] + 1
                    q.append(v)
                    if dist[v] > dist[far]:
                        far = v
        return far, dist[far]

    far, _ = bfs(1)
    _, d = bfs(far)
    return d

def solve():
    n = int(input())
    adj = [[] for _ in range(n + 1)]

    pos = []
    neg = []

    for _ in range(n - 1):
        u, v, w = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)
        if w > 0:
            pos.append(w)
        else:
            neg.append(w)

    if n == 2:
        print(w)
        return

    d = diameter(n, adj)

    pos.sort(reverse=True)
    neg.sort()

    P = [0]
    for x in pos:
        P.append(P[-1] + x)

    N = [0]
    for x in neg:
        N.append(N[-1] + x)

    p = len(pos)
    q = len(neg)

    ans = -10**18

    maxk = min(d, p + q)

    for k in range(1, maxk + 1):
        a = (k + 1) // 2
        b = k // 2

        best = -10**18

        if a <= p and b <= q:
            best = max(best, P[a] + N[b])

        a2 = k // 2
        b2 = (k + 1) // 2
        if a2 <= p and b2 <= q:
            best = max(best, P[a2] + N[b2])

        ans = max(ans, best)

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案将树处理与权重优化分开。 基于 DFS 的直径计算是孤立的，因为它是唯一重要的结构属性。 

一个微妙的实现细节是正确处理负前缀和。 由于负数按递增顺序存储（负数较大的在前），因此随着我们的扩展，它们的前缀和变得负数更大，这符合首先选择危害最小的负数的目标。 

另一个重要的点是从 1 开始的 k 的处理，因为路径必须包含至少一条边。 计算仔细评估交替序列的两个可能的起始奇偶校验。 

## 工作示例

 考虑第一个样本：

 输入：```
6
1 2 3
2 -1
3 4
4 -1
4 -130
```分割权重后，正数为 [3, 2]，负数为 [-1, -1, -130]。 直径为4，因此我们从1到4评估k。 

对于 k = 1，我们可以取 3 或 -1，最好是 3。 

对于 k = 2，最佳交替和为 3 + (-1) = 2。 

对于 k = 3，最好是 3 + 2 + (-1) = 4。 

对于 k = 4，强制更多的负值会降低增益。 

| k | 使用的POS | 否定使用| 价值|
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 3 |
 | 2 | 1 | 1 | 2 |
 | 3 | 2 | 1 | 4 |
 | 4 | 2 | 2 | 1 |

 最大值为 4。 

这表明最优解不一定是最长的可能路径，而是可用的正负权重之间的最佳平衡。

 ## 边缘情况

 一个关键的边缘情况是所有权重均为负数。 在这种情况下，交替仍然会强制包含额外的负数，因此最好的答案就是负数最少的单边。 该算法处理此问题是因为始终考虑 k = 1 并且 pos 贡献变为零，只留下最佳负前缀。 

另一种情况是，存在正值，但数量少于长交替模式所需的值。 例如，如果有很多负值而只有一个正值，即使直径很大，最佳 k 也会很小，因为延长路径会迫使越来越有害的负前缀和累积。 

最终的结构边缘情况是星形树，其直径为 2。该算法正确地将评估限制为 k ≤ 2，确保不会尝试构建比树可以支持的更长的路径。
