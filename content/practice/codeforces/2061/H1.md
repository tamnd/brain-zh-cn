 ## 解决方案
 ## 问题理解

 凯文有一个图，其中每个顶点最初可能包含一块石头或为空。 他还有一个目标配置，指示石头需要最终到达的位置。 在每次移动中，凯文可以同时将每个石子从当前顶点移动到相邻顶点，但没有两个石子可以同时占据同一顶点。 任务是确定是否可以使用零个或多个这些操作从初始配置达到目标配置。 

输入提供多个测试用例，每个测试用例指定顶点和边的数量、初始和目标二进制字符串以及图的边。 保证初始状态和目标状态的棋子数量相等。 约束条件适中：所有测试用例最多 2000 个顶点，总共最多 10^4 条边。 这意味着如果仔细实施的话，我们可以负担每个测试用例 O(n^2) 的算法。 

一个简单的解决方案会尝试模拟每一个可能的动作序列。 例如，考虑一个三角形图，其顶点为 1-2-3，棋子位于顶点 1 和 2 上，目标在 2 和 3 上放置棋子。尝试每种移动组合都会很快爆炸，因为可能的序列数量呈指数增长。 类似地，孤立的顶点、断开连接的组件或奇数长度的循环可能会产生直接贪婪移动方法失败的场景，除非我们推理图中的可达性而不是模拟移动。 

一个微妙的边缘情况是一个断开的组件。 假设一个组件有一颗处于初始状态的棋子，但该组件的目标棋子位于另一个断开连接的组件中。 一个幼稚的算法可能会尝试全局交换棋子，但不存在合法的移动序列，因为棋子无法跨越断开连接的组件。 类似地，其中一个组件具有奇数个顶点但需要以奇偶敏感方式移动石头的图可以产生有效/无效配置区别。 

## 方法

 暴力方法是枚举所有可能的同时移动并检查是否达到目标配置。 每次移动都需要为每个石头选择一个要移动到的相邻顶点。 如果有 k 个棋子，每个棋子有 d 个邻居，则每次移动有 d^k 个选择。 即使n=2000很小，石头的数量也可能是O(n)，所以d^k很快就变得不可行。 这种做法原则上是正确的，但无法在合理的时间内完成。 

关键的见解来自于观察到每次移动都是沿边缘的全局排列：石头仅沿边缘交换，因此问题简化为底层图中的可达性。 更具体地说，石头只能在连接的组件内移动。 因此，对于每个连接的组件，初始配置和目标配置中的多组石子计数必须匹配。 如果某个组件最初的石子数量与目标中的石子数量不同，则无法将石子移动到该组件中。 否则，可以使用沿边缘同时移动的序列在组件内任意排列棋子。 这将问题转换为图形连通性检查和多重集比较，这在每个测试用例的 O(n + m) 中是可行的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(d^k) | O(d^k) | O(n) | 太慢了 |
 | 组件可达性| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

1.读取测试用例的数量。 对于每个测试用例，读取 n、m、初始字符串 s 和目标字符串 t。 
2. 从 m 条边构建图的邻接表。 这允许有效地遍历邻居。 
3. 初始化一个数组来标记访问过的顶点。 
4. 迭代所有顶点。 当找到未访问的顶点时，执行深度优先搜索（DFS）或广度优先搜索（BFS）以识别同一连通分量中的所有顶点。 
5. 对于每个连接的组件，计算初始配置中的石子数量和目标配置中的石子数量。 
6. 如果组件的这些计数相等，则将该组件标记为有效。 如果任何组件的宝石数量不匹配，则测试用例的答案为“否”。 
7. 如果所有组件都有匹配的宝石数，则答案为“是”。 

为什么有效：石头无法离开其连接的组件。 在一个组件内，同时移动允许石头沿着路径进行任意排列。 因此，只要初始棋子和目标棋子的多组每个组件匹配，就存在将棋子重新排列到目标的一系列移动。 正确性依赖于图是无向的并且连通分量是最大的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10000)

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        s = input().strip()
        t_str = input().strip()
        adj = [[] for _ in range(n)]
        for _ in range(m):
            u, v = map(int, input().split())
            adj[u-1].append(v-1)
            adj[v-1].append(u-1)
        visited = [False]*n
        possible = True

        def dfs(u, component):
            visited[u] = True
            component.append(u)
            for v in adj[u]:
                if not visited[v]:
                    dfs(v, component)

        for i in range(n):
            if not visited[i]:
                component = []
                dfs(i, component)
                init_count = sum(int(s[x]) for x in component)
                target_count = sum(int(t_str[x]) for x in component)
                if init_count != target_count:
                    possible = False
                    break
        print("Yes" if possible else "No")
```该代码有效地读取输入并构造邻接表。 它使用 DFS 来查找连接的组件。 对于每个组件，它会比较初始配置和目标配置中的棋子数量。 如果任何组件未通过此检查，则会立即输出“否”。 如果图形成长链，则增加递归限制以处理深度 DFS。

 ## 边缘情况

 对于组件大小为 1 的断开图，该算法将每个顶点识别为其自己的组件。 如果该顶点的初始石子和目标石子不同，则输出“否”。 对于长链，DFS 可以正确找到组件并对石子求和。 在全连接图中，单分量和确保任何排列都是可行的，证明了多集比较不变量的充分性。
