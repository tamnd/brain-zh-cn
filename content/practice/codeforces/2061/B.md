 ## 解决方案
 ## 问题理解

 给定了多组棍子长度，我们必须恰好选择四根可以形成面积非零的等腰梯形的棍子。 这些木棍变成了凸四边形的四个边长，只要满足几何条件，我们就可以将它们重新排列成任何有效的梯形配置。 

等腰梯形有一对对边平行，且两条不平行的边相等。 包括矩形和正方形是因为它们作为两对相对边平行的退化对称情况满足此定义。 

从组合的角度来看，我们选择四个数字，并询问是否可以将它们排列起来，使其中两个形成相等的“腿”，其余两个形成两个底。 唯一的结构约束是腿必须相等，而底座是任意正长度，另外要求形状是非退化的，因此两个底座不能折叠成零面积配置。 

输入量很大，所有测试用例的输入量高达 200,000 个。 这立即排除了任何尝试所有四元组甚至所有对的方法，因为每个测试用例这些都会呈二次方增长或更糟。 有效的解决方案必须在总输入大小方面有效地呈线性或接近线性。 

一个微妙的问题是，可能存在多个有效配置，而我们只需要输出一个。 这表明我们并没有优化几何形状超出可行性； 我们只检测多重集中的结构。 

值得隔离的一种边缘情况是所有棍子都是不同的。 在这种情况下，无法形成一对相等的腿，因此答案立即不可能。 另一种情况是，有很多重复项，但全部集中在一个值中，例如`1 1 1 1`，我们可以在其中形成一个类似矩形的配置。 仅检查“至少两个相等对”而不正确跟踪多重性的简单方法可能无法构建有效的排列。 

## 方法

 蛮力策略会尝试每一个四边形，并测试它是否可以形成有效的等腰梯形。 对于四个索引的每个选择，我们将检查所有排列或直接推理是否可以将两个相等的边指定为边，并将其余边指定为底。 这成本约为$O(n^4)$在最坏的情况下，即使对于$n = 10^5$，因为这意味着$10^{20}$运营。 

稍微改进的蛮力可能会首先修复这对腿，然后在剩余元素中搜索另外两个边。 这将搜索减少到$O(n^3)$或者$O(n^2)$，但在约束下仍然失败。 

关键的结构观察是任何有效的梯形都需要一对相等的边作为腿。 一旦我们识别出这样的一对，剩下的两条边就会自动形成底面，并且不需要检查进一步的几何约束，因为在此问题设置中任何正长度都适用于底面（因为明确允许使用矩形并且没有施加额外的度量约束）。 

这将问题简化为查找至少出现两次的任何值。 如果我们能找到这样的值，我们就用它作为腿。 然后我们只需要另外两根棍子作为底座。 唯一的微妙之处是确保我们不会错误地重复使用相同的事件，如果我们跟踪频率或位置，这自然会得到处理。 

为了使构造可靠，对数组进行排序简化了重复项的检测，并允许我们有效地选取任意两个剩余元素。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解四倍 |$O(n^4)$|$O(1)$| 太慢了 |
 | 频率+贪婪构造|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将问题转化为检测重复值，然后选择两个额外的不同元素。 

1. 对棒长度数组进行排序。 

排序将相等的值分组在一起，如果我们更喜欢确定性，这使得检测重复项成为单个线性扫描而不是基于散列的结构。 
2. 扫描已排序的数组，找到第一个至少出现两次的值。 

当我们遇到连续的相等元素时，我们将该值标记为相等边的候选值。 
3. 删除两次出现的该重复值作为潜在基础。 

这两根棍子成为梯形的腿。 
4. 从剩余的棒中选择任意两个值。 

由于我们只从大小至少为 4 的多重集中删除了两个元素，因此如果找到有效的重复项，则始终至少有两个剩余元素。 
5. 输出四个选定的值。 

如果没有值出现至少两次，则立即输出`-1`。 

### 为什么它有效

 任何等腰梯形都需要一对等长的边作为腿。 因此，任何解的必要条件是重复长度的存在。 一旦选择了这样的一对，剩余的两条边在此问题设置中不受约束，因为任何正长度都可以用作底，同时仍然形成有效的梯形（包括作为特殊情况的矩形）。 这将问题完全简化为频率检测。 由于我们总是从数组中选择实际出现的情况，因此我们保证有效性而不需要几何重建。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        a.sort()
        
        pair_val = -1
        i = 0
        while i < n - 1:
            if a[i] == a[i + 1]:
                pair_val = a[i]
                break
            i += 1
        
        if pair_val == -1:
            print(-1)
            continue
        
        used = 0
        res = []
        
        # take two equal legs
        cnt = 0
        for x in a:
            if x == pair_val and cnt < 2:
                cnt += 1
                continue
            res.append(x)
        
        # pick any two remaining as bases
        if len(res) < 2:
            print(-1)
            continue
        
        print(pair_val, pair_val, res[0], res[1])

if __name__ == "__main__":
    solve()
```该实现首先进行排序以确保重复项是相邻的，从而使有效支路对的检测变得简单。 一旦找到，我们在构建剩余池时明确跳过该值的两次出现。 这样可以避免意外地重复使用同一根棍子。 

一个微妙的点是确保我们不会从几何中假设出超出必要的结构。 我们从不尝试强制执行三角形不等式或角度约束，因为一旦满足对称条件，问题定义就隐式允许任何配置。

 ## 边缘情况

 关键的边缘情况是恰好有两个重复项但没有足够的剩余元素来形成基础。 例如`2 2 2 2`仍然有效，因为选择两条腿作为腿后，剩下两条作为底座。 该算法自然会处理这个问题，因为删除是精确的，并且在多个值上不会贪婪，从而确保不会意外耗尽。
