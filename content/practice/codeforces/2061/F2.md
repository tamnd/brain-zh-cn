 ## 解决方案
 ## 问题理解

 我们得到一个二进制字符串`s`由 0 和 1 以及目标字符串组成`t`长度相同，可以包含 0、1 或通配符`?`。 允许的操作是选择两个**相邻的块**相同的字符`s`并交换它们。 块是相同字符的最大连续序列。 我们的目标是转型`s`到匹配的字符串中`t`在所有位置`t`不是一个`?`使用最少的交换次数。 如果不可能，我们应该返回-1。 

约束允许最多 10^4 个测试用例，并且所有字符串的总长度最多为 4×10^5。 这意味着任何解决方案都必须大约处理每个字符一次或两次，排除尝试块的所有排列或显式模拟每个交换的方法。 

非明显的边缘情况来自`?`中的字符`t`以及其中存在多个同一个角色的情况`s`比要求的`t`。 例如，如果`s = "0101"`和`t = "1010"`，这是不可能的，因为我们无法在不违反块邻接规则的情况下将 0 移过两个连续的 1。 同样，如果`t`仅包含通配符，任何`s`对于零操作来说是非常有效的。 不考虑这些不平衡或互换的不可逆转性的粗心实施将产生错误的答案。 

## 方法

 暴力方法是重复识别中的所有块`s`，尝试每个有效的相邻块交换，并检查结果字符串是否更接近`t`。 每个交换可以被视为搜索树中的一个节点，我们可以尝试 BFS 或 DFS 来找到交换的最小数量。 虽然这在原则上是正确的，但块的数量最多可达`n`在最坏的情况下，交换序列的数量呈指数级增长。 和`n`多达 10^5 和多个测试用例，这种方法是不可行的。 

最佳解决方案的关键见解是将精确的字符抽象为需要移动的 0 和 1 的计数。 由于交换相邻块保留了相同类型块的相对顺序，因此问题减少为计算有多少个“0”字符需要移过“1”字符，反之亦然。 换句话说，我们可以计算之间的**不平衡**`s`和`t`当我们从左到右扫描时：每次出现一个字符`s`与相应的固定字符不同`t`，我们为该类型的“额外”增加一个计数器。 最小交换次数就是需要相互交叉的错位 0 和 1 的计数之间的绝对差之和。 中的通配符`t`可以忽略，因为它们不会将角色限制在该位置。 这将问题简化为单个线性扫描，每个测试用例为 O(n)。

 ## 算法演练

 1. 解析输入字符串`s`和`t`。 初始化两个计数器`excess0`和`excess1`到 0。这些将跟踪有多少个 0 和 1`s`相对于`t`。 
2. 从左到右迭代字符串。 对于每个位置`i`， 如果`t[i]`是一个`?`，跳过它，因为任何字符都可以接受。 如果`s[i]`比赛`t[i]`， 继续。 否则，如果`s[i]`是`0`但`t[i]`是`1`, 增量`excess0`。 如果`s[i]`是`1`但`t[i]`是`0`, 增量`excess1`。 这表示一个放错位置的字符，最终必须跨越其他一些字符才能到达正确的位置。 
3. 扫描完字符串后，检查错位的0和1的总数是否兼容。 如果 0 的总数`s`小于 0 的数量`t`（忽略通配符），无法匹配`t`，返回-1。 
4. The minimum number of swaps required is the maximum of`excess0`和`excess1`。 这是有效的，因为每次交换都可以修复 0 和 1 之间的一个交叉点，并且某些角色可能需要移动多个步骤，但计算最大值涵盖了所有必要的移动。 
5. 输出结果。 

保持的不变量是每次扫描后，`excess0`表示所有 0 必须通过一些 1 才能到达目标位置，反之亦然。 交换相邻块可以一次有效地解决一个交叉问题，从而保证这些计数的最大值是所需交换的最小数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_swaps(s, t):
    excess0 = 0
    excess1 = 0
    for i in range(len(s)):
        if t[i] == '?':
            continue
        if s[i] == t[i]:
            continue
        if s[i] == '0' and t[i] == '1':
            excess0 += 1
        elif s[i] == '1' and t[i] == '0':
            excess1 += 1
    # Check if total counts allow a valid transformation
    if s.count('0') < t.count('0'):
        return -1
    return max(excess0, excess1)

def main():
    t = int(input())
    results = []
    for _ in range(t):
        s = input().strip()
        tstr = input().strip()
        results.append(str(min_swaps(s, tstr)))
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```功能`min_swaps`首先计算有多少个字符被放错位置。 然后我们检查 0 的数量是否`s`足以满足`t`, 忽略`?`。 如果不是，转型是不可能的。 否则，错位的 0 和 1 的最大数量给出了所需的最小交换量。 主函数使用快速 I/O 有效地处理多个测试用例。
