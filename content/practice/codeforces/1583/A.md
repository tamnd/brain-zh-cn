 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 在每个测试用例中，都有一个不同正整数的数组，任务是选择尽可能多的元素，使得所选元素的总和不是质数。 在所有有效选择中，我们必须输出具有最大可能大小的任何子集。 

输出不是总和本身，而是所选元素的索引。 因此，真正的目标是决定我们是否可以包含所有元素，如果不能，则哪些最小的删除可以修复总和的素数。 

关键的限制是每个数组最多有 100 个元素，每个值最多 200 个。这使得不可能暴力破解所有子集，因为子集的数量呈指数增长 2ⁿ。 完整的枚举每个测试用例最多需要大约 21⁰⁰ 子集，即使在优化的 Python 中，这也远远超出了任何可行的限制。 

重要的结构观察是我们不是在子集上优化任意函数。 唯一重要的是所选元素的总和，以及该总和是质数还是合数。 

尝试以任意顺序贪婪地删除元素或测试子集的幼稚方法在微妙的情况下可能会失败。 例如，首先删除最小的元素不一定会固定素数和，并且删除最大的元素可能会不必要地缩小子集，即使不同的删除可以保留大小。 

另一个失败案例来自于假设整个数组始终有效。 如果总和是质数，则整个集合无效，即使仅删除一个仔细选择的元素可能会修复它。 

## 方法

 蛮力的想法很简单。 我们生成每个子集，计算其总和，检查它是否是复合的，并跟踪满足条件的最大子集大小。 这是正确的，因为它直接评估所有可能性。 然而，它需要评估 2ⁿ 子集，并且计算每个子集的总和会添加另一个因子，使其实际上为 O(n·2ⁿ)。 对于 n = 100，这是不可能的。 

关键的观察是我们根本不需要搜索子集空间。 我们只关心所选元素的总和。 由于所有数字都是正数，因此添加元素总是会增加总和，并且最大的子集只是整个数组，除非其总和是质数。 

如果总和已经是合数，那么答案就是所有元素。 唯一有问题的情况是当总和为素数时。 在这种情况下，删除任何单个元素都会改变总和，我们只需要检查删除一个元素是否可以使总和复合。 由于所有数字均为正数，删除多个元素只会进一步减小子集大小，因此最佳解决方案必须是完整数组或数组减去一个元素。 

因此，问题简化为检查总和的素数，如果它是素数，则找到任何单个元素，通过删除该元素使剩余的总和成为复合元素。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n·2ⁿ) | O(n) | 太慢了 |
 | 最佳 | O(n·√S) | O(n·√S) | O(1) | O(1) | 已接受 |

 ## 算法演练

 令 S 为所有元素的总和。 

1. 通过对所有数组元素求和来计算 S。 这给出了与选择整个数组相对应的总和。 
2. 通过尝试直到 √S 的约数来检查 S 是否为素数。 如果 S 是复合的，我们就完成了并且可以选择所有索引。 
3. 如果S是素数，我们需要恰好删除一个元素。 尝试每个索引 i 并计算 S - a[i]。 如果这个值是复合值，我们可以选择除 i 之外的所有元素并停止。 
4. 输出结果子集。 

我们只考虑删除一个元素的原因是，删除多个元素会严格减少子集大小，并且我们正在最大化基数。 

### 为什么它有效

正确性依赖于一个简单的极值论证。 任何有效答案都是完整数组的子集。 如果总和是合数，则它在大小上支配所有较小的子集，因此它一定是最优的。 如果总和是素数，则任何有效的解决方案都必须避免该精确总和。 保留最大大小的最接近的方法是删除尽可能少的元素，删除一个元素就足够了，因为按任何正数更改总和都会破坏素数的精确值。 由于我们测试了所有单个删除，因此我们保证只要存在一个有效的最大子集即可找到。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_prime(x):
    if x < 2:
        return False
    if x % 2 == 0:
        return x == 2
    i = 3
    while i * i <= x:
        if x % i == 0:
            return False
        i += 2
    return True

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    total = sum(a)

    if not is_prime(total):
        print(n)
        print(*[i + 1 for i in range(n)])
        continue

    # try removing one element
    found = False
    for i in range(n):
        if not is_prime(total - a[i]):
            print(n - 1)
            print(*[j + 1 for j in range(n) if j != i])
            found = True
            break

    # guaranteed to exist per problem statement
    if not found:
        # fallback (should never happen)
        print(1)
        print(1)
```该实现首先使用标准 √n 试除法计算总和并检查素数。 如果总和不是质数，则直接输出所有索引。 否则，它会迭代每个元素并检查删除它是否会产生复合和。 使用第一个成功的候选者。 

包含后备分支只是为了安全起见，尽管该问题保证在所有情况下都存在有效子集。

 ## 边缘情况

 关键的边缘情况是总和恰好是素数。 在这种情况下，即使删除单个元素可以修复问题，获取所有元素也会失败。 例如，像这样的数组`[8, 1, 2]`和为 11，这是素数。 该算法正确地检测到这一点，并尝试逐一删除元素，直到总和变为合数。 

另一个边缘情况是删除任何单个元素仍然留下素数和。 该问题保证这种情况不会在有效输入中发生，因此对单个删除的搜索就足够了并且总是成功。 

最后的边缘情况是大小为 3 的小数组。即使在这里，逻辑也成立，因为要么全和是复合的，要么至少一次删除产生复合和，确保存在有效答案，而无需考虑空子集或多次删除子集。
