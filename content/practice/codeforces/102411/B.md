 ## 解决方案
 ## 问题理解

 Treap 同时是其键 (x) 的二叉搜索树和其优先级 (y) 的最小堆。 在这个问题中，优先级不是随机的：对于每个整数键（x），它被固定为

 [
 y=\sin(x)。 
]

 我们必须打印 (n) 个不同的整数，每个整数都适合一个带符号的 32 位整数，以便生成的陷阱的高度恰好为 (n)。 由于包含 (n) 个顶点的二叉树的高度不能大于 (n)，这意味着我们需要强制每个节点都位于一条长的根到叶路径上。 

关键是使两个坐标按同一方向排序。 如果

 [
 x_1<x_2<\cdots<x_n
 ]

 并且同时

 [
 \sin(x_1)<\sin(x_2)<\cdots<\sin(x_n),
 ]

 那么笛卡尔树就没有分支。 最小的 (y) 属于 (x_1)，因此 (x_1) 成为根。 其他每个键都较大，因此每个剩余节点都属于其右子树。 递归地重复相同的参数，给出一串 (n) 顶点。 

约束 (n\le 50000) 足够小，打印 (O(n)) 整数是微不足道的。 真正的困难不是计算复杂性，而是构造正弦整数参数，并将其保留在正弦曲线的一个严格递增的部分内。 32 位限制排除了简单地将极其精确的近似值乘以任意大的因子的可能性，因此该结构必须能够轻松地适应大约 40 亿个可能的整数值。 

有几种边缘情况值得记住。 对于 (n=1)，任何有效整数都有效，因为单节点树的高度已经为 1。 例如，```
1
```可以生产```
0
```树的高度为 (1)。 

另一个边界是（n=50000）。 使用 (-25000d) 到 (24999d) 范围内的值的构造必须将其最大绝对值保持在 (2^{31}) 以下。 对于 (d=710)，最大幅度仅为 (17750000)，因此带符号的 32 位条件远非严格。 

更微妙的边缘情况发生在零附近。 取小的连续整数，例如```
4
```并且尝试 (x=-1,0,1,2) 不起作用，因为正弦值是

 [
 -\sin(1),0,\sin(1),\sin(2),
 ]

 这在这里不是问题，但序列很快就到达了转折点。 一旦其参数离开该区间，仅基于正弦增加接近零的局部事实的粗心构造可能会悄然失败。 样本的正确输出是一组可能的输出，例如```
-2
0
-1
-4
```即使打印的键没有排序，它也会产生一个链。 陷阱取决于点的集合，而不是答案打印的顺序。 

最危险的问题是将打印整数的顺序与树的结构混淆。 例如，打印```
-17750000
-17749290
-17748580
```很有用，因为这些值是 (710) 的连续倍数，但基本属性是它们的 (x) 值和正弦值都严格递增。 输出顺序本身不需要描述树。 

## 方法

 直接的暴力策略是搜索整数集合，构建相应的笛卡尔树，并检查其高度是否为 (n)。 检查一个提议的集合可以有效地完成，但搜索可能的集合的空间是没有希望的。 有 (2^{32}) 个可能的带符号 32 位值，因此即使搜索超序 (n) 元组也会给出

 [
 \binom{2^{32}}{n}
 ]

 的可能性。 对于 (n=50000)，这远远超出了任何计算限制。 即使是对起始值和正步长进行更窄的强力搜索，在检查 (n) 个生成值之前也会有大约 (2^{32}\cdot 2^{32}) 个候选对，然后对每个候选进行 (O(n)) 工作。 这个问题显然需要数学构造而不是搜索。 

有用的观察是我们不需要显式地构造树。 我们只需要 (x) 坐标及其优先级保持一致。 所以问题就变成了找到许多 (\sin(x)) 严格递增的整数 (x)。 

正弦在区间上严格递增

 [
 \left[-\frac{\pi}{2},\frac{\pi}{2}\right]。 
]

 如果我们可以选择任意实数，我们只需将所有 (x) 值放入该区间即可。 整数值无法为我们提供足够多的不同点，因为间隔比 (50000) 短得多。 

解决这个问题的方法是利用周期 (2\pi)。 我们想要一个非常接近 (2\pi) 倍数的整数 (d)。 然后

 [
 d = 2\pi k+\delta
 ]

 对于一个非常小的正数 (\delta)。 由于正弦有周期 (2\pi)，

 [
 \sin(id)=\sin(i\delta)。 
]

 因此，就正弦而言，大整数 (d) 的倍数的行为就像 (δ) 的小倍数。 

特别方便的选择是(d=710)。 自从

 [
 113\cdot 2\pi\约709.9999397，
 ]

 我们有

 [
 710=113\cdot 2\pi+\delta
 ]

 与

 [
 \delta\大约 0.0000603。 
]

 对于 (-25000) 和 (24999) 之间的每个整数 (i)，

 [
 i\delta
 ]

 大约保持在 (-1.5075) 和 (1.5074) 之间。 两个端点都严格位于 ([-\pi/2,\pi/2]) 内部，其边界约为 (1.5708)。 因此，在我们使用的每个值中，正弦都严格递增。 

我们现在可以采取

 [
 x_i=710i,\qquad -25000\le i\le24999。 
]

 (x_i) 值严格递增，并且

 [
 \sin(x_i)=\sin(i\delta)
 ]

 也是严格增加的。 我们正好有 (50000) 个这样的整数，因此该序列的任何前缀都可以解决所需 (n) 的问题。 

该结构也安全地保持在有符号的 32 位范围内，因为它的绝对值最多为 (25000\cdot710=17,750,000)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (n) | 中的指数 O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) 用于输出缓冲，O(1) 额外 | 已接受 |

 ## 算法演练

 1. 读取(n)，所需的节点数。 
2. 使用固定台阶(710)。 将第 (i) 个答案写为

 [
 x_i=(i-25000)\cdot710
 ]

 对于 (i=0,1,\ldots,n-1)。 

这给出了不同的整数，因为连续的值正好相差 (710)。 
3. 观察 (710=113\cdot2\pi+\delta) 是否有一个微小的正数 (\delta)。 因此

 [
 \sin(710k)=\sin(k\delta)。 
]

 我们使用的 (k) 的最大绝对值为 (25000)，因此 (|k\delta|<\pi/2)。 正弦在整个区间内严格递增。 
4. 由于 (x_i) 和 (\sin(x_i)) 都随 (i) 增加，因此具有最小键的点也具有最小优先级。 它成为根，并且所有其他点都位于二叉搜索树中的右侧。 递归地应用相同的参数给出包含所有 (n) 个节点的单个路径。 
5. 打印 (n) 个构造的整数。 该构造使用 (-17750000) 和 (17749290) 之间的值，因此每个答案都适合在所需的 32 位有符号范围内。

不变的是，在选择构造的任何前缀后，键严格递增，它们的正弦值也严格递增。 因此，最小优先级点始终是最左边的键，并且所有其他点都属于其右子树。 删除该根为剩余后缀留下完全相同的属性，因此归纳给出了一条 (n) 个节点的链。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    base = -25000 * 710
    ans = []
    for i in range(n):
        ans.append(str(base + i * 710))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```表达式`base + i * 710`正是构造公式。 从 (-25000\cdot710) 开始并将乘数加一给出序列

 [
 -25000\cdot710,,-24999\cdot710,\ldots
 ]

 这是完整 (50000) 元素构造所需的前缀。 

该代码使用 Python 整数，因此即使问题本身需要打印值适合有符号的 32 位整数，溢出也不是问题。 实际值只有(1.8\times10^7)左右，远低于(2^{31}-1)。 

无需计算`sin`在提交的程序中。 计算浮点正弦值会增加不必要的工作，并可能引入与证明无关的数值比较。 选择（710）的全部目的是数学论证已经保证了排序。 

输出顺序不断增加。 这很方便，但不是问题所必需的。 陷阱由点集 ((x,\sin x)) 定义，因此相同有效键的任何排列都将描述相同的笛卡尔树。

## 测试用例

 由于该问题接受许多不同的输出，因此测试应该验证生成序列的数学属性，而不是将其与一个固定字符串进行比较。 下面的帮助程序检查每个值是否不同，所有值是否都在有符号的 32 位范围内，并且正弦值严格递增。 它还使用足够高精度的浮点算术直接验证这些特定参数的构造。```python
import sys
import io
import math

def solve_data(inp: str) -> str:
    data = inp.strip().split()
    n = int(data[0])

    base = -25000 * 710
    return "\n".join(str(base + i * 710) for i in range(n))

def run(inp: str) -> str:
    return solve_data(inp)

def validate(inp: str) -> bool:
    out = run(inp)
    values = list(map(int, out.split()))
    n = int(inp.strip())

    assert len(values) == n
    assert len(set(values)) == n
    assert all(-2**31 <= x <= 2**31 - 1 for x in values)

    ys = [math.sin(x) for x in values]

    for i in range(1, n):
        assert values[i - 1] < values[i]
        assert ys[i - 1] < ys[i]

    return True

# Minimum-size input
assert run("1") == "-17750000", "minimum n"

# Small boundary case around the centre of the construction

# All-equal-values adversarial idea: the output itself must never contain duplicates.

bad = "0\n0\n"
bad_values = list(map(int, bad.split()))
assert len(set(bad_values)) != len(bad_values), "duplicate-value check"

# Maximum-size input
assert validate("50000"), "maximum n"

# A case large enough to cross zero in the generated sequence

 ## 边缘情况

 对于 (n=1)，算法仅打印 (-17750000)。 没有与另一个节点进行比较的排序条件，因此生成的陷阱由一个顶点组成，高度为 1。 

对于最大值 (n=50000)，乘数范围为 (-25000) 到 (24999)。 相应的键范围从 (-17750000) 到 (17749290)。 删除完整周期后的正弦参数范围大致为 (-1.5075) 到 (1.5074)，仍然严格位于正弦增加的区间内。 生成的陷阱是所有（50000）个节点的路径。 

当 (n) 足够大时，该结构也会通过乘数零。 在 (k=0) 处，密钥为 (0)，优先级为 (\sin(0)=0)。 它的邻居对应较小的负和正缩小角，因此它们的正弦值分别较小和较大。 零时不存在重复优先级。 

最后，打印的键是 (710) 的倍数这一事实不会导致正弦值相等。 全周期关系

 [
 \sin(710k)=\sin(k\delta)
 ]

 将问题简化为严格递增区间 ((-\pi/2,\pi/2)) 内的不同 (k\delta) 值。 由于乘数(k)是不同的，因此它们的约角是不同且有序的，因此它们的正弦值也是不同且有序的。 这个属性将最初看起来像困难的陷阱构造问题变成了恒定步长算术构造。
