 ## 解决方案
 ## 问题理解

 我们有一个长度的盒子`n`包含平行导轨上的两根杆。 短杆有长度`a`，长条的长度`b`， 和`a < b`。 长杆的两端各有一个塞子，短杆必须完全保持在这两个塞子之间。 

最初，两个条形都与框的左侧齐平。 目标是移动两个条，直到它们与右侧齐平，使用尽可能少的移动。 在一次移动过程中，只有一根杆可以重新定位，而另一根杆保持固定。 唯一的限制是，每次移动后，短杆必须仍然位于长杆的两个止动件之间。 

输入包含`a`,`b`， 和`n`， 在哪里`1 ≤ a < b ≤ n ≤ 10^7`。 的上限`10^7`告诉我们，执行恒定工作量的算法是理想的，而即使是与`n^2`是完全不可行的。 在最坏的情况下，线性模拟可以达到大约一千万次迭代，这可能接近 Python 中两秒限制的边界。 直接公式更可取，因为它可以将计算减少到一些算术运算。 官方限制是两秒，内存限制是512MB。 

第一个边缘情况是当长条已经填满整个框时。 例如，使用输入`1 3 3`，长条的长度`3`盒子也有长度`3`。 它根本不能移动，而短杆可以直接从左挡块移动到右挡块，所以答案是`1`。 总是假设两个条都必须移动的粗心解决方案至少会返回`2`。 

第二种边缘情况发生在`b - a = 1`。 例如，`2 3 5`长条内部围绕短条只有一个单位的可用空间。 长杆必须移动`5 - 3 = 2`个单位，每对移动只能使其前进一个单位，所以答案是`2 * 2 + 1 = 5`。 使用整数除法而不是上限的公式只会错误地计算`3`移动。 

第三种边缘情况是长杆所需的运动不能被除以`b - a`。 例如，`2 5 8`需要长杆才能移动`3`单位，而短条最多可以产生一个间隙`3`单位。 这里，一整对动作将长杠推进了`3`, 给予`3`总共移动。 和`2 4 9`但是，长杆必须移动`5`单位和每对最多可以推进`2`，所以需要三对，答案是`7`。 吊顶操作必不可少。 

## 方法

 强力方法可以明确地对两个条的位置进行建模。 让`x`是长条的左端点并且`y`短条的左端点。 合法国家满足`0 ≤ x ≤ n - b`和`x ≤ y ≤ x + b - a`。 

开始于`(0, 0)`，我们可以对所有可能的整数状态执行最短路径搜索。 有`O(n^2)`可能的配对`(x, y)`，并且从一种状态我们可以为所选柱尝试许多可能的新位置。 这放弃了`O(n^3)`工作最直接的落实。 和`n = 10^7`，这的顺序是`10^21`操作，因此它远程不可行。 

蛮力之所以有效，是因为它明确地代表了条形图的每个合法相对位置。 关键的观察是我们实际上不需要考虑所有这些立场。 让`d = b - a`。 

假设长条从位置开始`x`。 由于短杆必须保持在两个止动件之间，因此它的左端点最多可以是`x + d`。 因此，当长杆固定时，短杆最多可以向右移动`d`。 
现在互换角色。 短条的位置是`y`，长条可以向右移动，直到其左端点到达`y`。 如果我们首先将短条放在`x + d`，然后长条可以从`x`到`x + d`。 因此，一根短棒移动后跟一根长棒移动可以使长棒精确前进`d`。 

在达到最大可能位置之前停止任何一个动作都没有任何好处。 进一步向右移动不会使未来的状态变得更糟，因为后来的每一个法律位置也都更向右。 这让我们可以贪婪地交替这些条形，除了最后的短条形移动之外的每一步移动都完全贡献`d`长条的进度单位。 官方教程给出了相同的观察结果和结果公式。 

长杆必须从位置移动`0`定位`n - b`，因此所需的短/长移动对的数量为`ceil((n - b) / (b - a))`。 

每对使用两次移动，在长杆到达其最终位置后，最后一次移动将短杆放在盒子的右侧。 因此答案是`2 * ceil((n - b) / (b - a)) + 1`。 

我们可以计算正整数的上限`ceil(x / d) = (x + d - 1) // d`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(n²) | 太慢了|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`a`,`b`， 和`n`。 对运动计数重要的唯一量是长杆必须移动的距离，`n - b`，以及条之间可用的最大相对位移，`b - a`。 
2. 计算`distance = n - b`。 这是在长条到达框的右侧之前，长条的左端点必须移动的总距离。 
3. 计算`gap = b - a`。 这是短杆可以放置在长杆前面同时仍保持在长杆的两个止动件之间的最大距离。 
4. 计算`pairs = (distance + gap - 1) // gap`。 每对都包括将短杆尽可能向右移动，然后将长杆尽可能向右移动。 这样的一对将长杠推进了`gap`，除了可能的最后一对，这可能会使其前进较少，因为长条已到达边界。 
5. 乘法`pairs`两，因为每一对都包含一个短柱移动和一个长柱移动。 
6. 为短杠添加最后一步。 当长杆到达其目标位置后，短杆可以直接移动至其目标位置，同时停留在最终止动件之间。 

### 为什么它有效

 不变的是，在每次长棒移动之前，最多可以放置短棒`b - a`长条前面的单位。 因此，单个长杆移动最多可以将其左端点推进`b - a`。 每当需要更多进展时，贪婪策略就恰好达到最大值，因此就移动次数而言，没有任何策略可以更快地移动长条。 

长杆需要移动`n - b`单位，所以至少`ceil((n - b) / (b - a))`长杆动作是必要的。 在每次此类长杆移动之前，除了初始配置外，都需要进行短杆移动以创建所需的间隙。 一旦长棒到达其目标，就只剩下一次短棒移动。 构造的序列达到了这个下界，给出`2 * ceil((n - b) / (b - a)) + 1`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b, n = map(int, input().split())

    distance = n - b
    gap = b - a

    pairs = (distance + gap - 1) // gap
    answer = 2 * pairs + 1

    print(answer)

if __name__ == "__main__":
    solve()
```第一行直接从标准输入读取三个维度。 该问题只有一个测试用例，因此不需要测试用例循环。`distance = n - b`是长条左端点必须移动的量。 如果`n == b`，这变成零，这正确地导致零对和答案`1`。`gap = b - a`总是积极的，因为该声明保证`a < b`。 这意味着上限除法是安全的并且永远不会被零除。 

表达式`(distance + gap - 1) // gap`执行上限除法而不进行浮点运算。 浮点在这里是不必要的，并且可能会引入可避免的精度问题，而整数运算对于整个输入范围都是精确的。 

最后，`2 * pairs + 1`计算每个空头/多头对中的两次移动以及最后一个短柱移动。 Python 整数具有任意精度，尽管这里的答案很容易在普通 64 位整数范围内。

 ## 边缘情况

 当`n = b`，长条已经跨越了整个盒子。 用于输入`1 3 3`，我们有`distance = 3 - 3 = 0`和`gap = 3 - 1 = 2`。 天花板划分给出`pairs = 0`，所以答案是`2 * 0 + 1 = 1`。 唯一需要的移动是将短杆从左侧移动到右侧。 

什么时候`b - a = 1`，短条与长条的长度几乎相同，因此只能产生一个单位的间隙。 用于输入`1 2 5`，长杆必须移动`3`单位。 由于每次长杆移动只能将其推进一个单位，因此需要三对，然后是最后的短杆移动。 公式给出`2 * ceil(3 / 1) + 1 = 7`。 

当距离恰好能被间隙整除时，不需要部分完成的对。 用于输入`2 5 8`，长杆移动`3`单位和可用间隙也是`3`。 因此，一次短棒移动和一次长棒移动使长棒完全对准其目标，然后是最后一次短棒移动。 答案是`3`。 

当距离不能被间隙整除时，最终的长杆移动仅使用可用间隙的一部分。 用于输入`2 4 8`，长杆必须移动`4`单位，而每对只能提供`2`单位。 需要两对，给出`2 * 2 + 1 = 5`。 用普通整数除法替换上限恰好适用于这种精确整除的情况，但在输入上会失败，例如`2 4 9`， 在哪里`5 / 2`需要三对而不是两对。
