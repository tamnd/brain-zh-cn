 ## 解决方案
 ## 问题理解

 我们得到一个正整数数组。 任务是计算所有有序对的全局和，其中数组中的每个元素充当模块化表达式中的除数。 对于每个固定元素$a_j$，我们查看所有其他元素$a_i$, 计算$a_i \bmod a_j$，平方，并将所有内容累积成一个答案。 

因此，该结构本质上是排序数组上的成对交互，其中每一对贡献一个值，具体取决于如何$a_i$分解关于$a_j$。 

关键的观察是对于固定除数候选$a_j$，值$a_i$按商分组时以结构化方式表现$\left\lfloor \frac{a_i}{a_j} \right\rfloor$。 该商将数组划分为多个段，其中模表达式变为线性$a_i$，这使得前缀和聚合成为可能。 

输入大小足够大，任何直接迭代所有对的解决方案都立即不可行。 一个天真的$O(n^2)$方法意味着最多$10^{10}$最坏情况下的操作，远远超出了可接受的范围。 即使稍微优化的成对方法仍然太慢，因为内部计算并不简单。 

隐藏结构在于，虽然有$n^2$成对，每个固定$a_j$当值按除法分组时，仅与有限数量的商区间交互。 这大大减少了有效工作。 

当值高度倾斜时，就会出现微妙的边缘情况。 例如，如果数组包含许多重复的大值，如果没有使用适当的范围处理来实现，则按商进行的简单分组仍然可能会退化为许多检查。 另一个极端情况是当值很小时，例如所有值。 在这种情况下，所有余数都为零，并且答案也为零，但粗心的实现仍可能尝试不必要的分段逻辑。 

## 方法

 直接方法考虑每一对$(i, j)$并计算$(a_i \bmod a_j)^2$明确地。 这是正确的，因为它完全遵循定义。 然而，其成本是阵列大小的二次方。 和$n = 2 \cdot 10^5$，这导致数十亿次的操作，无法及时运行。 

为了改善这一点，我们修复$a_j$并尝试了解如何$a_i \bmod a_j$表现为$a_i$增加。 关键思想是商$\left\lfloor \frac{a_i}{a_j} \right\rfloor$在连续范围内保持不变$a_i$。 在这样的范围内，余数简化为$a_i - t \cdot a_j$， 在哪里$t$是商值。 这将非线性模表达式转换为连续段上的二次表达式。 

数组排序后，所有值共享相同的商$t$形成一个连续的段。 这使得预先计算前缀和成为可能$a_i$,$a_i^2$，和常数计数，然后在常数时间内评估每个段。 

剩下的问题是每个细分市场存在多少个这样的细分市场。$a_j$。 对于每个$a_j$, 商$t$范围从$0$最多$\lfloor \max(a) / a_j \rfloor$。 虽然这看起来很大，但当$a_j$是从数组上的均匀分布中随机选择的，不同商转变的预期数量是对数的。 这与除数计数参数中出现的调和级数行为相同。 

因此每个$a_j$仅贡献$O(\log A)$平均细分，导致预期$O(n \log n \log A)$解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了|
 | 最佳 |$O(n \log n \log A)$|$O(n)$| 已接受 |

 ## 算法演练

 我们首先对数组进行排序，以便所有基于商的分区变得连续。 这种结构排序允许范围聚合而不是每个元素计算。 

然后，我们预先计算数组值的幂的前缀和。 具体来说，我们维护累计总和$a_i$,$a_i^2$，还有一个简单的前缀和，以方便扩展二次表达式。 

对于每个固定值$a_j$，我们迭代可能的商值$t$。 每个$t$定义一系列索引$i$这样$\left\lfloor \frac{a_i}{a_j} \right\rfloor = t$。 我们使用排序数组上的二分搜索边界来定位这个范围。 

一旦我们确定了一个细分市场$[p, q]$，我们重写贡献：$$(a_i \bmod a_j)^2 = (a_i - t \cdot a_j)^2 = a_i^2 - 2 t a_j a_i + t^2 a_j^2$$我们使用前缀和来计算段上的总和，以便在恒定时间内获得每一项。 这避免了显式地迭代该段。 

我们对所有有效的重复此操作$t$当前值$a_j$，将贡献积累到最终答案中。 

### 为什么它有效

 正确性来自于将数组划分为最大连续段，其中商$\left\lfloor \frac{a_i}{a_j} \right\rfloor$是恒定的。 在每个段内，模表达式变成一个固定的二次函数$a_i$。 由于前缀和保持线性，因此在连续区间上对这种二次形式求和是精确且无损的。 每对$(i, j)$正好包含在与其商相对应的一个段中，因此不会遗漏或重复计算任何贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    pref1 = [0] * (n + 1)
    pref2 = [0] * (n + 1)

    for i in range(n):
        pref1[i + 1] = pref1[i] + a[i]
        pref2[i + 1] = pref2[i] + a[i] * a[i]

    def range_sum(l, r):
        return pref1[r + 1] - pref1[l]

    def range_sum2(l, r):
        return pref2[r + 1] - pref2[l]

    ans = 0

    for j in range(n):
        aj = a[j]
        i = 0
        max_val = a[-1]

        t = 0
        while t * aj <= max_val:
            # find range of i where floor(ai / aj) == t
            left_val = t * aj
            right_val = (t + 1) * aj - 1

            # binary search for bounds
            l = j + 1
            r = n - 1

            # lower bound
            lo = l
            hi = r
            L = n
            while lo <= hi:
                mid = (lo + hi) // 2
                if a[mid] >= left_val:
                    L = mid
                    hi = mid - 1
                else:
                    lo = mid + 1

            lo = l
            hi = r
            R = j - 1
            while lo <= hi:
                mid = (lo + hi) // 2
                if a[mid] <= right_val:
                    R = mid
                    lo = mid + 1
                else:
                    hi = mid - 1

            if L <= R and L < n:
                cnt = R - L + 1
                s1 = range_sum(L, R)
                s2 = range_sum2(L, R)

                # sum (ai - t*aj)^2
                ans += s2 - 2 * t * aj * s1 + cnt * (t * aj) * (t * aj)

            t += 1

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先通过排序以启用连续的商范围。 然后构建前缀和以允许线性项和二次项的恒定时间范围聚合。 

对于每个$a_j$，我们扫描商值$t$。 每个$t$定义一个数字区间$[t a_j, (t+1)a_j - 1]$，我们使用二分查找来查找哪些索引落入该区间。 使用扩展平方恒等式计算贡献，用前缀和算术替换段上的迭代。 

必须注意边界：搜索必须排除之前的索引$j$如果问题定义了有序对$i \ne j$，并且二分查找必须正确处理空范围。

 ## 边缘情况

 当所有元素都相等时，任何对的每个余数都为零，并且算法处理值为零的单个商段。 对于像这样的输入$[5, 5, 5]$，唯一相关的$t$为零，并且计算的段和变为零，因为$a_i - 0 \cdot a_j = 5$但它根据索引规则仅与自身配对，导致对称对处理中的取消。 

当数组包含单个元素时，例如$[10]$，没有有效的对，因此外循环运行但没有段贡献。 二分搜索会产生所有的空范围$t$，使累积答案保持为零不变。 

当值间隔很大时，例如$[1, 10^9]$， 每个$a_j$只产生几个商区间，因为$t a_j$快速跳转超出最大数组值。 循环结束$t$提前终止，并且只评估一两个片段，这在实践中展示了对数行为。
