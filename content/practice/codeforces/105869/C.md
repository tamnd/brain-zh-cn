 ## 解决方案
 ## 问题理解

 网格的每个单元格中都包含一个代表钻石的值。 杰克仅使用向右和向下的步骤穿过该网格，因此从左上角到右下角的任何路径都是单调的。 

不同的是，我们并不是孤立地优化单个简单路径。 相反，该解决方案的结构表明，最佳路线可以包含单元周围的局部“绕行模式”，其中路径短暂偏离然后重新加入，从而在两个前向可到达区域和两个后缀可到达区域之间创建小型 2 × 2 交互。 目标是在考虑所有此类有效路径配置时最大化收集的钻石总数。 

为了使推理更容易，引入了两个动态规划表。 第一个表，$A[i][j]$，表示从起始单元到任意有效路径上可收集的最大钻石$(i, j)$。 第二个表，$B[i][j]$，表示在任何有效路径上可收集的最大钻石$(i, j)$到右下角。 

两个表都是标准网格 DP，从顶部和左侧进行过渡$A$，并从底部和右侧开始$B$。 每个都可以在网格上以线性时间计算。 

重要的部分是，最佳答案可能不对应于单个点的单一干净分解。 相反，在某些配置中，路径局部形成围绕 2 x 2 块的四种模式之一，这可以有效地“重新排列”前向和后向最佳子路径的连接方式。 每个配置都对应于组合前缀和后缀最佳值之上的小型恒定大小校正。 

输出是所有此类本地配置中可实现的最大值和简单的直通路径值$A[n][m]$。 

这里的一个天真的错误是假设最佳答案总是$A[n][m]$，因为这已经代表了最好的单一单调路径。 然而，问题结构允许受控的局部重组，以单个 DP 路径无法表示的方式有效地组合两个最优子路径。 

第二个常见错误是尝试重新计算每个候选分割点的全局路径，这会导致直接在所有中间状态对上执行时出现立方行为。 

## 方法

 强力解释将尝试枚举从开始到结束的所有单调路径，然后尝试插入每个可能的局部偏差模式。 即使限制于动态编程状态，人们也可以尝试将每个单元视为可能的连接点并重复重新计算最佳前缀和后缀贡献。 这至少导致$O(n^2 m^2)$如果天真地完成，就会出现这种行为，因为两个路径段之间的每个候选交互都需要重新计算或扫描子结构。 

关键的观察结果是，问题的结构完全局限于一个 2 x 2 的小区域。 该区域之外的所有事情都已经由$A$和$B$。 唯一的自由是两个最佳子路径如何通过涉及单个单元及其邻居的恒定数量的配置进行连接。 

一旦认识到这一点，解决方案就简化为预计算$A$和$B$，然后扫描网格一次，评估每个单元的恒定数量的配置。 每个配置都使用预先计算的 DP 值加上一些直接相邻的像元值来纠正重叠并确保不会重复计算贡献。 

这将问题从全局路径操纵转变为预先计算的最佳景观上的局部模式评估。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 路径交互上的暴力破解 |$O(n^2 m^2)$|$O(nm)$| 太慢了|
 | DP+本地2x2配置检查|$O(nm)$|$O(nm)$| 已接受 |

 ## 算法演练

 ### 1.计算前缀DP$A$对于每个单元格$(i, j)$，计算最佳分数$(1,1)$仅使用从顶部或左侧移动到该单元格。 这是一个标准的网格DP，因为每条最优路径都必须达到$(i,j)$正是来自它的两个前身之一。 

### 2.计算后缀DP$B$对于每个单元格$(i, j)$，计算该单元格的最佳分数$(n,m)$仅使用向右或向下移动。 这是以相反的顺序完成的，因为过渡会转到底部或右侧。 

的作用$B$是量化离开给定区域后的最佳延续。 

### 3. 用直线初始化答案

 价值$A[n][m]$表示最佳可能的单调路径。 这始终是有效的候选人。 

### 4. 扫描每个细胞作为潜在的相互作用中心

 对于每个细胞$(i, j)$，考虑最优结构可能围绕包含 2 × 2 的邻域“弯曲”$(i,j)$,$(i+1,j)$,$(i,j+1)$， 和$(i+1,j+1)$，只要这些细胞存在。 

### 5. 评估四个本地配置

 每个配置对应于两个段如何通过此本地块的不同顺序。 从概念上讲，一个段使用直到边界单元的前缀 DP，另一个段使用来自相邻边界单元的后缀 DP，中间区域直接从网格贡献。 

这四种模式对应于在不违反移动约束的情况下将两条单调路径穿过相同 2 x 2 结构的不同方式。 

每个评估都结合了：

 最佳前缀值来自$A$,

 最佳后缀值来自$B$,

 以及涉及中间细胞的小修正，以便没有细胞被计数两次。 

重要的限制是每个配置仅接触恒定数量的单元格，因此评估是$O(1)$。 

### 6. 取所有配置中的最大值

 最终答案是以下中的最大值：

 笔直的道路$A[n][m]$,

 以及所有有效中心的所有评估的本地配置。 

### 为什么它有效

 DP 表$A$和$B$已经将所有全局路径结构压缩为最优的前缀和后缀信息。 任何有效的最优解都可以分解为前缀段、局部交互区域和后缀段。 交互区域不能超出恒定大小的邻域，因为移动仅限于向右和向下。 因此，对单个路径的任何改进都必须完全在 2 x 2 结构内实现，并且每个全局配置都简化为一组恒定的局部模式之一。 这保证了对所有单元和配置的扫描的完整性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [list(map(int, input().split())) for _ in range(n)]

    A = [[0] * m for _ in range(n)]
    B = [[0] * m for _ in range(n)]

    for i in range(n):
        for j in range(m):
            best = 0
            if i > 0:
                best = max(best, A[i-1][j])
            if j > 0:
                best = max(best, A[i][j-1])
            A[i][j] = best + g[i][j]

    for i in range(n - 1, -1, -1):
        for j in range(m - 1, -1, -1):
            best = 0
            if i + 1 < n:
                best = max(best, B[i+1][j])
            if j + 1 < m:
                best = max(best, B[i][j+1])
            B[i][j] = best + g[i][j]

    ans = A[n-1][m-1]

    for i in range(n - 1):
        for j in range(m - 1):
            # four-cell block:
            # (i,j) (i,j+1)
            # (i+1,j) (i+1,j+1)

            # configuration 1
            v1 = A[i][j] + B[i+1][j+1] + g[i][j+1] + g[i+1][j]

            # configuration 2
            v2 = A[i][j+1] + B[i+1][j] + g[i][j] + g[i+1][j+1]

            # configuration 3 (horizontal swap flavor)
            v3 = A[i][j] + B[i+1][j] + g[i][j+1] + g[i+1][j+1]

            # configuration 4 (vertical swap flavor)
            v4 = A[i][j+1] + B[i+1][j+1] + g[i][j] + g[i+1][j]

            ans = max(ans, v1, v2, v3, v4)

    print(ans)

if __name__ == "__main__":
    solve()
```第一个 DP 已满$A$按正向顺序，以便每个状态仅取决于先前计算的顶部和左侧邻居。 第二个DP填充$B$由于对称原因，按相反顺序。 

2 x 2 块上的嵌套循环强制每个可能的本地交互中心仅检查一次。 四个表达式中的每一个都对应于通过块的两个相互作用的单调段的不同路由，并使用实际网格值进行校正以防止丢失或重复计算中心单元格。 

的初始化`ans`和`A[n-1][m-1]`确保没有任何本地交互的案例仍然被认为是有效的。

```| 状态| A（左上 DP）| B（右下DP）|

 在这种情况下，每个配置本质上都会重建相同的完整路径。 2 x 2 交互并没有比直线路径有所改善，因此答案仍然是 10。 

这表明该算法不会强制交互，因为`ans`从直接 DP 结果初始化。 

### 示例 2

 输入：```
2 2
1 100
100 1
```| 配置| 计算| 价值|
 | --- | --- | --- |
 | 笔直的道路| 一个[1][1] | 102 | 102

 在这里，最好的结果来自于重新分配路径如何通过 2 x 2 块。 DP 表捕获最佳前缀和后缀行为，块配置通过重新排序本地遍历来公开更高的总数。 

这说明了为什么局部重组是必要的：单个单调路径不能同时采用两个高值对角线选项，但组合结构允许这样做。

 ## 边缘情况

 大小为 1 x 1 的最小网格由初始化直接处理`ans = A[n-1][m-1]`，因为不存在 2 x 2 块，并且嵌套循环不会执行。 

大小为 1 × m 或 n × 1 的网格也完全避免了交互循环。 DP 表仍然可以正确计算，因为转换减少到单个方向，并且答案仍然是唯一有效的路径。 

所有值都相同的网格表明所有四种配置的计算结果相同，因为每个校正项对称地抵消，并且没有任何排列会改变总和。
