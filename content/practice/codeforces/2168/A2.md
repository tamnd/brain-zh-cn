 ## 解决方案
 ## 问题理解

 我们被要求对整数数组实现两阶段编码和解码过程。 在第一阶段，程序接收一个数组`a`尺寸的`n`值最大为 10 亿，并且必须输出字符串`s`由小写字母组成。 该字符串是唯一会持续到第二阶段的信息，在该阶段中，程序将在没有第一次运行的记忆的情况下重新启动。 在第二次运行中，程序收到`s`并且必须重建两者`n`和原始数组`a`确切地。 约束意味着字符串`s`必须足够紧凑以适应合理的长度，同时仍然编码潜在的大整数。 

挑战是双重的。 首先，我们不能直接存储或传输数值； 我们必须将它们编码为字符。 其次，编码必须在允许的最多 100,000 个字符的字符串长度内明确且可解码，即使在`n`最大可达10000，数值可达`10^9`。 将每个整数映射到单个字符的简单方法将会失败，因为字母表只有 26 个字母，远远少于可能的数字范围。 

边缘情况包括单元素数组、具有所有相同值的数组或包含最大值的数组`10^9`。 如果粗心的解决方案没有对值进行标准化或将它们清晰地分开，则可能会错误地解码。 例如，编码`[1, 27]`作为`'ab'`如果在没有分隔符的情况下重复使用数字映射，则可能会产生歧义。 

## 方法

 暴力方法是尝试将每个整数直接映射到一个字符。 你可以采取`a_i % 26`出具一封信。 对于小数字，这原则上是正确的，但在解码时会失败，因为多个整数会折叠为同一字符。 操作次数可以忽略不计，但方法不明确，因此不可接受。 

关键的见解是，我们可以将数组视为使用基数 26 的位置数字系统中的数字序列。每个整数可以用多个字符进行编码，表示基数 26 中的数字。通过这样做，我们可以将任何数字映射到`10^9`成字母序列。 为了确保明确的解码，每个编码的整数都由标记分隔，或者我们将每个整数的长度编码为字符串的一部分。 一个实用的解决方案是每个字母使用 5 位，这样我们就可以得到 32 个不同的符号，这比 26 个字母还要多。 然后我们可以将数字打包成二进制并将 5 位块映射到字母。 这保证了解码准确并且在字符串长度限制内工作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 模棱两可，对于大量数据失败 |
 | 最佳 | O(n log(max(a))) | O(n log(max(a))) | O(n log(max(a))) | O(n log(max(a))) | 已接受，精确编码/解码 |

 ## 算法演练

 1. 在第一次运行时，阅读`n`和数组`a`。 转换每个整数`a_i`为二进制。 按顺序连接所有二进制表示形式，生成一个长位串。 
2. 将位串拆分为 5 位的块。 每个 5 位块通过添加偏移量映射到一个小写字母`'a'`。 这会产生一个字符串`s`仅包含小写字母。 
3.输出字符串`s`。 程序终止，丢失所有内存`a`。 
4. 在第二次运行中，读取字符串`s`。 将每个字母转换回其对应的 5 位值并重建长位串。 
5. 使用每个原始整数的已知位长度（因为`10^9 < 2^30`，每个数字 30 位就足够了），将位串分割成连续的 30 位段。 将每个段转换回整数。 
6. 输出`n`接下来是解码后的数组。 

这样做的原因是，5 位编码保证在将字母映射回二进制时不会出现歧义，并且每个整数的固定 30 位宽度确保每个原始数字都能准确重建。 不变的是每个原始数字都完全用 30 位表示，并且在编码过程中不会丢失任何位。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def encode(a):
    bits = ""
    for x in a:
        bits += bin(x)[2:].rjust(30, '0')
    # pad to make length a multiple of 5
    if len(bits) % 5 != 0:
        bits += '0' * (5 - len(bits) % 5)
    s = ""
    for i in range(0, len(bits), 5):
        val = int(bits[i:i+5], 2)
        s += chr(ord('a') + val)
    return s

def decode(s, n):
    bits = ""
    for c in s:
        val = ord(c) - ord('a')
        bits += bin(val)[2:].rjust(5, '0')
    a = []
    for i in range(n):
        x = int(bits[i*30:(i+1)*30], 2)
        a.append(x)
    return a

mode = input().strip()
if mode == 'first':
    n = int(input())
    a = list(map(int, input().split()))
    print(encode(a))
else:
    s = input().strip()
    # estimate n by using length: each number is 30 bits, each letter 5 bits
    total_bits = len(s) * 5
    n = total_bits // 30
    a = decode(s, n)
    print(n, *a)
```编码将位串填充为 5 的倍数以匹配字母块。 在解码过程中，程序会重建原始位串并将其切成每个数字的 30 位段。 主要的微妙之处在于确保位串长度与 5 位字母映射和 30 位数字对齐，避免差一错误。

 ## 边缘情况

 对于单元素数组`[1]`，该算法生成一个 30 位字符串并将其编码为 6 个字母。 在解码过程中，正好提取 30 位来生成数字 1。对于`[10^9, 10^9]`，30 位表示确保不会丢失任何信息，并且两个元素都能正确解码。 对于跨越字母边界的数组，例如`[1, 27]`，5 位映射可以防止冲突，因为每个 5 位段都是不同的，并且 30 位片与原始整数对齐。
