 ## 解决方案
 ## 问题理解

 我们给出了一系列月销售值和固定的窗口大小$K$。 对于每个连续的长度段$K$，我们计算其平均销售额。 由于所有窗口的长度相同，因此比较平均值相当于比较总和。 

任务是识别两个位置：具有最小总和的窗口的最早起始索引，以及具有最大总和的窗口的最早起始索引。 

这里的关键结构是，我们不仅仅根据值选择单个最佳窗口，而且还根据最早出现的情况执行平局打破规则。 这改变了我们对待相等总和的方式：当我们再次看到相同的值时，我们不能覆盖之前的索引。 

约束条件达到$10^5$元素，这排除了从头开始重新计算每个窗口的总和。 独立地对每个窗口求和的简单方法将采用$O(NK)$，当两者都变得太大时$N$和$K$很大。 

当多个窗口共享相同的最小或最大总和时，就会出现边缘情况。 更新索引的粗心实现`<=`或者`>=`而不是严格`<`或者`>`将错误地选择后面的位置而不是第一次出现的位置。 

另一个微妙的情况是当$K = 1$。 那么每个元素都是它自己的窗口，答案就简化为第一次出现的最小和最大数组值。 

## 方法

 蛮力方法通过迭代每个窗口来计算每个窗口的总和$K$元素。 这是正确的，但重复工作很重：每个$N-K+1$窗户费用$O(K)$，导致$O(NK)$。 在$10^5$，这太慢了。 

改进来自于观察重叠。 相邻窗口共享$K-1$元素，因此我们可以通过减去传出元素并添加传入元素来在恒定时间内更新总和。 这种滑动窗口技术将复杂性降低到线性时间。 

一旦我们输入了每个窗口的总和$O(1)$，跟踪最小值和最大值成为一次通过仔细的平局决胜。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(NK)$|$O(1)$| 太慢了 |
 | 滑动窗|$O(N)$|$O(1)$| 已接受 |

 ## 算法演练

 我们维护第一个窗口的总和，然后将其滑过数组，同时更新最小值和最大值。 

1. 计算第一个的总和$K$元素。 这会初始化当前窗口和比较基线。 
2. 将最佳最小值和最佳最大值设置为该第一个总和，并记录两者的索引 1。 
3. 从左向右将窗口移动一步。 
4. 对于每一步，通过减去离开窗口的元素并添加新进入的元素来更新当前总和。 
5. 如果新的总和严格小于最佳最小值，则更新最小值并存储当前索引。 
6. 如果新的总和严格大于最佳最大值，则更新最大值并存储当前索引。 

严格的比较是必要的。 如果我们使用非严格比较，我们将覆盖之前的有效答案并违反返回第一次出现的要求。 

### 为什么它有效

 每个可能的窗口都按顺序检查一次。 滑动总和确保每个窗口值的正确性，单调更新确保只有严格更好的候选者才能替换当前的最佳值。 由于我们从不覆盖联系，因此第一个出现的位置通过构造得以保留。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    v = list(map(int, input().split()))

    window_sum = sum(v[:k])

    min_sum = window_sum
    max_sum = window_sum
    min_idx = 1
    max_idx = 1

    for i in range(k, n):
        window_sum += v[i] - v[i - k]
        start_idx = i - k + 2

        if window_sum < min_sum:
            min_sum = window_sum
            min_idx = start_idx

        if window_sum > max_sum:
            max_sum = window_sum
            max_idx = start_idx

    print(min_idx, max_idx)

if __name__ == "__main__":
    solve()
```实现首先读取输入并显式计算第一个窗口总和。 然后循环保持滑动窗口不变。 指数计算`i - k + 2`将从零开始的右端点转换为从一开始的窗口起点。 

比较使用严格的不平等来保留最早出现的要求。 这是此问题中最常见的错误来源：使用`<=`或者`>=`默默地打破关系的正确性。

 ## 边缘情况

 当所有窗口具有相同的总和时，算法必须保留最小值和最大值的第一个索引。 这是有保证的，因为更新仅发生在严格改进时，因此初始索引保持不变。 

什么时候$K = 1$，每个元素都是它自己的窗口。 滑动机制仍然有效：每次更新都会用新元素替换先前的总和，并且比较可以正确识别最小值和最大值的第一次出现。 

当所有值都相等时，每个窗口总和都相同，因此不会触发任何更新。 输出保持不变`(1, 1)`，符合首次出现选择的要求。
