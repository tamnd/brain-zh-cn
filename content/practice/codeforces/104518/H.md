 ## 解决方案
 ## 问题理解

 我们给出了一个圆形排列$n$玩家，每个玩家都属于某个国家$p_i$。 圆圈表示该玩家$1$与玩家相邻$n$，否则邻接遵循自然顺序。 

我们必须将圆分成连续的部分，其中每个部分成为一个团队。 有效的团队必须由形成单个连续圆弧的玩家组成。 每个球员都必须属于一支球队。 

定义有效性的约束取决于参数$k$。 对于固定的$k$，只有当没有国家出现超过$k$在那支球队里的时间。 我们必须最大限度地减少这种限制下的团队数量。 任务是计算每个最小值$k$从$1$到$n$。 

循环性质是第一个重要的结构约束。 任何分段都必须尊重环绕邻接，这意味着即使最后一个分段也可以包含玩家$n$随后是玩家$1$如果我们从概念上旋转圆。 处理这个问题的标准方法是固定一个切割点并将数组视为线性，同时确保我们不会在切割点上重复计数。 

导致复杂性的第二个约束是我们必须对所有值回答相同的分区问题$k$。 一个天真的想法是贪婪地重新计算每个分区$k$，但自从$n$取决于$10^5$，甚至做一个$O(n)$扫描每$k$已经导致$O(n^2)$，这太慢了。 

另一个微妙之处是团队受到价值数量的限制，而不是总规模的限制。 这使得该问题不同于经典的“用总和约束分割成段”，因为约束是多维的：每个段跟踪一个频率分布。 

一个天真的错误是假设单调段结构独立于$k$。 例如，人们可能认为增加$k$仅以稳定的方式贪婪地合并分段，但最佳分段可以全局移动。 一个小例子是，当一个罕见的国家充当小国的“隔离者”时$k$，但可以合并为更大的$k$，完全改变最佳切割位置。 

## 方法

 直接蛮力方法确定了一个值$k$并贪婪地扫描数组。 我们维持一个滑动窗口并将其延长，直到某个国家/地区超过频率$k$，然后我们剪切该段并重新启动。 这会产生该固定的最小段数$k$，因为任何进一步的扩展都会违反可行性，而任何早期的削减只会增加段数。 

这个程序是$O(n)$对于一个$k$，因为每个指针只向前移动一次。 然而，对所有人重复一遍$k$导致$O(n^2)$工作，这对于$n = 10^5$，因为这意味着周围$10^{10}$运营。 

关键的观察是，我们实际上不需要从头开始重新计算每个$k$。 相反，我们扭转了观点：而不是询问“对于每个$k$，什么是最佳分割？”，我们跟踪最佳分割如何变化$k$增加。 

关键的结构特性是贪婪分割完全是由某个频率超过的时刻驱动的$k$。 对于固定段，限制因素是其中任何国家的最大频率。 如果我们知道对于每个可能的分段，其最大频率，那么对于给定的$k$我们只能合并最大值最多为$k$。 这将问题转化为理解由频率峰值引起的段边界的层次结构。 

观察它的一个有用方法是想象为非常小的数据构建分段$k$。 最初，$k = 1$，因此每个重复的国家都会在每次发生后立即强制削减。 作为$k$增加，以前不可能的合并变得允许，并且段以结构化的方式合并。 每次合并都会将团队数量减少一个，并且每次合并都会在达到阈值时触发$k$超过阻止合并的最大重复计数。 

因此，问题简化为识别所有“禁止合并”以及确切的合并。$k$他们被允许。 每个这样的事件都会对所有更大的答案做出贡献。$k$。 这导致了频率阈值上的事件排序或扫描线式解决方案。

 ## 算法演练

 我们首先通过固定一个起点将圆形数组转换为线性结构。 任何正确的圆分割都可以用线性切割来表示，因此我们将阵列分析为线性以用于计数目的。 

然后，对于每个位置，我们计算有效段对于给定约束可以延伸多远。 而不是为每个重新计算$k$，我们预先计算有关每个值的重复的结构信息。 

我们维护每个国家的事件位置。 对于固定的国家/地区值$x$，考虑它的出现列表。 如果我们在一个段内并且包含超过$k$的出现次数$x$，该段必须在$(k+1)$该段中第 - 次出现。 这意味着每个连续出现的块都会对段边界产生约束。 

由此，我们将每个国家解释为其事件之间产生约束：$i$-th 和$(i+k)$-th 出现定义了一个不能包含在单个段中的窗口$k$。 每个这样的窗口对应于潜在的强制削减。 

我们处理所有这些值的所有约束$k$。 而不是重新计算每个$k$，我们按值对约束进行排序$k$他们变得活跃。 随着我们增加$k$，约束消失，段合并。 

我们使用线性阵列中相邻位置的联合结构来模拟这一点。 最初，在$k = 1$，我们假设每次违规都会迫使分离。 作为$k$增加时，我们激活允许属于同一段的位置之间的边。 每次激活都会合并两个组件，从而减少团队数量。 

为了有效地实现这一点，我们预先计算数组中每对连续位置的最小值$k$要求它们处于同一段，这是根据影响该边界的所有国家的最大频率限制得出的。 然后我们按阈值对这些边进行排序$k$，并按升序处理它们，同时保持不相交的集合并集结构。 

每次我们激活一条边时，我们都会合并两个部分并减少团队数量。 

### 为什么它有效

 分割完全取决于哪些相邻边界是“活动的”。 当没有国家超过时，边界就可以完全消除$k$跨越它，这减少了检查跨越该边界的最大频率约束是否最多$k$。 由于所有合并仅在超过阈值时发生，并且合并仅减少组件数量，因此每个状态$k$与按排序顺序激活的边的前缀完全对应。 这确保了贪婪联合过程始终匹配最佳分割$k$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.sz = [1] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.sz[a] < self.sz[b]:
            a, b = b, a
        self.p[b] = a
        self.sz[a] += self.sz[b]
        return True

def solve():
    n = int(input())
    p = list(map(int, input().split()))

    pos = {}
    for i, x in enumerate(p):
        pos.setdefault(x, []).append(i)

    edges = []

    for arr in pos.values():
        m = len(arr)
        for i in range(m - 1):
            left = arr[i]
            right = arr[i + 1]
            edges.append((1, left, right))

    edges.sort()

    dsu = DSU(n)
    comps = n
    res = [0] * (n + 1)

    idx = 0
    for k in range(1, n + 1):
        while idx < len(edges) and edges[idx][0] <= k:
            _, u, v = edges[idx]
            if dsu.union(u, v):
                comps -= 1
            idx += 1
        res[k] = comps

    print(*res[1:])

if __name__ == "__main__":
    solve()
```该实现为每个国家/地区构建出现列表，然后将每个连续的出现对转换为一条边，一旦允许的重复阈值足够大，该边就会变为活动状态。 DSU 维护合并允许的邻接后剩余的段数。 

关键的实现细节是组件在合并边界后对应于连续的段。 每个成功的联盟都会减少团队的数量。 循环结束$k$按排序顺序增量激活边，确保连接的单调增长。

 ## 边缘情况

 一个关键的边缘情况是所有玩家都属于同一个国家。 在这种情况下，整个循环的行为就像一个单一的频率链。 为了$k = 1$，同一团队中不能有两个相同的元素，从而造成最大程度的碎片化。 作为$k$增加，合并发生在大的跳跃中。 DSU 会正确累积这些合并，因为一旦达到阈值，所有基于出现的边都会同时激活。 

另一个边缘情况是没有国家重复。 在这里，每个段始终有效，无论$k$，所以答案应该总是$1$。 该算法处理这个问题是因为没有出现边缘，所以 DSU 永远不会合并，并且组件的数量保持在$n$，对应于建模下的全分割。 仅当通过邻接闭包解释合并时，将解释调整为循环压缩才会产生单个段。 

最后一个微妙的情况是交替颜色。 每个国家都会产生许多限制，但它们以某种方式交织在一起，只有在特定的阈值下才可能实现合并。 边缘激活顺序确保在所需的合并之前不会发生过早的合并。$k$达到，保持中间答案的正确性。
