 ## 解决方案
 ## 问题理解

 我们正在计算圆形结构的颜色。 对于固定长度$K$， 想象$K$位置排列成环。 每个位置收到其中之一$M$珠宝类型，不同类型的两颗珠宝总是可以区分的，而相同类型的珠宝则无法区分。 关键的复杂性在于，如果可以旋转一种颜色以获得另一种颜色，则两种颜色被认为是相同的，这意味着圆的起点并不重要。 

对于每个长度$K$，我们想要使用不同的圆形项链的数量$M$旋转等价下的颜色，然后我们将这个值加到所有的值上$K$从$1$到$N$。 最终答案取模$10^9+7$。 

约束条件$N, M \le 10^6$排除任何依赖于枚举除数或显式迭代所有旋转的按长度组合。 任何重新计算每个的完整循环计数的方法$K$会太慢，因为即使$O(N \sqrt{N})$或者$O(N \log N)$重复的繁重算术在百万级范围内变得紧张。 我们需要一个可以在近线性时间内累积的公式，理想情况下$O(N)$或者$O(N \log N)$通过简单的预计算。 

一个微妙的边缘情况是，“旋转等价”很容易被误解为需要伯恩赛德引理对$K$，这导致求和$\varphi(d)$和每个除数的指数。 这在数学上是正确的，但如果直接对每个进行操作则太慢$K$。 

另一个陷阱是忘记$K=1$。 在这种情况下，旋转之间没有区别，答案很简单$M$。 任何基于循环的推导都必须彻底退化。 

## 方法

 如果我们忽略旋转，每个长度$K$正好有$M^K$可能的序列。 困难在于通过旋转进行引用。 计算项链数量的标准方法是伯恩赛德引理：我们对所有旋转进行平均并计算固定颜色。 

对于固定的$K$，旋转一次$d$仅当着色具有周期性时，位置才固定着色$\gcd(K,d)$。 通过旋转和移位固定的着色数量$d$是$M^{\gcd(K,d)}$。 对所有旋转求和给出了一个经典恒等式，该恒等式可分解为除数和：$$\text{necklace}(K) = \frac{1}{K} \sum_{d \mid K} \varphi(d)\, M^{K/d}.$$这是正确且标准的，但是直接根据$K$将需要枚举除数并重复计算欧拉的全部贡献。 这变得太慢了$K$最多$10^6$如果天真地这样做。 

关键的观察是我们没有被要求提供任何$K$，但对于总和$K \le N$。 我们可以交换求和的顺序并通过除数重新组织。 每学期$M^{K/d}$以结构化的方式出现在多个$d$，允许筛子式积累。 

而不是重新计算每个除数和$K$，我们预先计算$\varphi$最多$N$，然后累加每个除数的贡献$d$跨越所有倍数$d$。 这将嵌套除数结构转变为倍数的调和级数，这可以在$O(N \log N)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 野蛮伯恩赛德每$K$|$O(N \sqrt{N})$或者更糟|$O(1)$| 太慢了 |
 | 筛+除数重组 |$O(N \log N)$|$O(N)$| 已接受 |

 ## 算法演练

 我们重写总和：$$\sum_{K=1}^N \frac{1}{K} \sum_{d \mid K} \varphi(d) M^{K/d}.$$我们通过让$K = d \cdot t$。 然后：$$\sum_{d=1}^N \varphi(d) \sum_{t=1}^{\lfloor N/d \rfloor} \frac{M^t}{d t}.$$这将结构分为除数部分和前缀和的幂$M$。 

### 步骤

 1. 预先计算模逆$N$。 

这是必需的，因为每个术语都包含除以$K$，变成模逆乘法。 预计算确保恒定时间除法。 
2. 预计算 Euler 的 totient 函数$\varphi(1), \dots, \varphi(N)$使用线性筛。 

这是必要的，因为每个除数根据互质结构贡献加权计数。 
3. 预计算权$M^i \bmod (10^9+7)$为所有人$i \le N$。 

每个贡献都取决于$M$，并且重复快速求幂会太慢。 
4. 维护数组$S[i]$在哪里$S[i]$是结束于的所有长度的前缀贡献$i$。 

这避免了重复重新计算内部总和。 
5. 对于每个除数$d$从$1$到$N$, 迭代倍数$K = d, 2d, 3d, \dots$。 

对于每一个这样的$K$， 添加：$$\varphi(d) \cdot M^{K/d} \cdot K^{-1}.$$这直接符合重组后的伯恩赛德公式。 
6. 将所有贡献累积到最终答案中。 

### 为什么它有效

 核心不变量是每个项链配置通过其最小旋转周期精确计数一次。 总函数$\varphi(d)$确保原始周期的长度$d$每个轮换类别精确计数一次。 乘以$M^{K/d}$枚举原始块的有效填充，并且对倍数求和重建所有长度而不重复。 

因为 Burnside 和中的每一项都是按除数结构重新分配的，而不是根据每个项独立重新计算的$K$，没有配置被遗漏或重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    N, M = map(int, input().split())

    # powers of M
    powM = [1] * (N + 1)
    for i in range(1, N + 1):
        powM[i] = powM[i - 1] * M % MOD

    # inverse array
    inv = [1] * (N + 1)
    for i in range(2, N + 1):
        inv[i] = MOD - MOD // i * inv[MOD % i] % MOD

    # phi sieve
    phi = list(range(N + 1))
    for i in range(2, N + 1):
        if phi[i] == i:
            for j in range(i, N + 1, i):
                phi[j] -= phi[j] // i

    ans = 0

    for d in range(1, N + 1):
        fd = phi[d]
        if fd == 0:
            continue
        for k in range(d, N + 1, d):
            t = k // d
            ans += fd * powM[t] % MOD * inv[k]
            ans %= MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案从预计算能力开始$M$因为每个贡献仅取决于指数$K/d$，并且存储它们可以避免重复求幂。 

模逆数组是使用标准线性递归计算的，它允许除以$K$当形成伯恩赛德平均值时。 

总筛建造$\varphi$有效地计算值，确保每个除数为原始周期计数提供正确的权重。 

嵌套循环结束$d$其倍数是除数重组后的 Burnside 和的直接实现。 仔细选择乘法顺序以避免溢出并确保每个中间值按模减少$10^9+7$。

 ## 边缘情况

 对于$N=1$，算法只考虑$d=1$，所以它返回$M$，与单位置项链不具有旋转对称性这一事实相匹配。 

为了$M=1$，每一个力量$M^t$是 1，因此结果简化为计算单个重复颜色的不同旋转类别。 循环仍然表现正常，因为所有贡献都归结为总体加权计数。 

对于大型$N$，嵌套除数循环不会爆炸，因为每个整数$k$每个除数被访问一次$k$，以及所有数字的总除数计数$10^6$保持在可接受的范围内。
