 ## 解决方案
 ## 问题理解

 两名玩家每人开始种植固定数量的土豆，然后以固定的每日速度种植更多的土豆。 技术刀片始于$X_1$土豆和收益$Y_1$每天土豆。 他的对手开始于$X_2$土豆和收益$Y_2$每天土豆。 时间一整天都在流逝，两个成长过程都以同样的速度发生。 

任务是确定 Technoblade 的总数严格超过对手总数的最早日期。 如果这样的时刻永远不会到来，答案就是-1。 

后$d$天，总计是线性表达式：$$T(d) = X_1 + d \cdot Y_1, \quad S(d) = X_2 + d \cdot Y_2$$我们被要求找到最小的非负整数$d$这样$T(d) > S(d)$，或者决定不存在这样的$d$存在。 

约束很小，所有值都达到 1000，这意味着甚至随着时间的推移进行直接模拟也是可行的。 然而，线性增长问题往往隐藏着一个微妙的问题：当竞争对手增长更快或开始领先时，不平等可能永远不会翻转，或者可能只翻转一次。 这使得推理单调性而不是盲目迭代变得很重要。 

当 Technoblade 起步落后但增长更快时，就会出现一种常见的失败案例。 幼稚的解决方案可能会过早停止或无法考虑$d = 0$。 另一种边缘情况是，两者以相同的速率增长，但其中一个开始提前，在这种情况下，答案要么是 0，要么永远不可能，具体取决于初始值。 

## 方法

 暴力方法日复一日地进行模拟。 开始于$d = 0$，我们计算这两个值并检查 Technoblade 是否有更多的土豆。 如果没有，我们增加日期并重复。 由于值线性增长，因此该过程保证最终找到交叉点或检测到它永远不会在合理的范围内发生。 

这是有效的，因为两个玩家之间的差异也是线性变化的。 然而，如果我们无限期地模拟，最坏的情况就会发生，即 Technoblade 永远追不上。 在这种情况下，天真的循环将永远运行或依赖于任意中断，这是不安全的。 

关键的观察是我们可以直接比较增长率。 定义差异：$$D(d) = (X_1 - X_2) + d (Y_1 - Y_2)$$这是一个线性函数。 如果$Y_1 \le Y_2$，该函数是非增函数或常数。 在这种情况下，如果 Technoblade 尚未领先$d = 0$，以后他就永远不会领先了。 如果$Y_1 > Y_2$，差异随着时间严格增加，因此最多会有一个交叉点。 我们可以解决一个简单的不等式，而不是进行模拟。 

从：$$X_1 + dY_1 > X_2 + dY_2$$我们得到：$$X_1 - X_2 > d (Y_2 - Y_1)$$如果$Y_1 = Y_2$，比较在第 0 天之后就不会改变。否则我们可以直接使用整数算术来计算阈值。

 | --- | --- | --- | --- |
 | 暴力模拟| O(D) | O(1) | O(1) | 太慢/不安全|
 | 直接配方| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算初始差值$diff = X_1 - X_2$。 这可以在任何增长发生之前捕捉到谁处于领先地位。 
2.如果$diff > 0$，Technoblade 在第 0 天就已经严格领先，所以答案是 0。不需要未来的模拟，因为要求已经满足。 
3.如果$Y_1 = Y_2$，两名球员的成长速度相同，因此差异永远不会改变。 如果 Technoblade 尚未领先，他就不可能领先，因此返回 -1。 
4. 如果$Y_1 < Y_2$，Technoblade 的增长速度更加缓慢，这意味着随着时间的推移，差距只会越来越大。 即使他一开始很接近，他也永远无法超越，所以返回 -1。 
5.如果$Y_1 > Y_2$，差异每天增加固定的正数。 我们需要最小的$d$这样：$$X_1 + dY_1 > X_2 + dY_2$$重新排列：$$diff + d (Y_1 - Y_2) > 0$$求解$d$:$$d > \frac{X_2 - X_1}{Y_1 - Y_2}$$最小整数$d$满足这个的是：$$d = \left\lfloor \frac{X_2 - X_1}{Y_1 - Y_2} \right\rfloor + 1$$6. 输出计算结果$d$。 

### 为什么它有效

 关键的不变量是两个玩家之间的差异是斜率恒定的时间线性函数$Y_1 - Y_2$。 整数上的线性函数最多可以过零一次，除非斜率为零。 这意味着两个玩家的顺序最多可以改变一次，并且可以通过代数计算而不是搜索确切的交叉点。 该算法通过将动态过程转换为单个不等式求解来利用这一点，无需迭代即可保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    x1, y1, x2, y2 = map(int, input().split())
    
    diff = x1 - x2
    
    if diff > 0:
        print(0)
        return
    
    if y1 == y2:
        print(-1)
        return
    
    if y1 < y2:
        print(-1)
        return
    
    # y1 > y2
    gap = x2 - x1
    gain = y1 - y2
    
    d = gap // gain
    if gap % gain != 0:
        d += 1
    
    print(d)

if __name__ == "__main__":
    solve()
```代码首先检查 Technoblade 是否已经在第 0 天领先，这会立即确定答案。 然后，它会处理相对增长率不利的情况，因为在同等增长和较小增长的情况下，不平等永远不会对他有利。 

只有在严格递增的情况下，它才会计算精确的交叉点。 使用上限逻辑仔细处理除法，因为我们需要严格不等式成立的第一个整数日。 使用整数运算可以避免浮点精度问题并保持解决方案的确定性。

 ## 边缘情况

 当两个玩家以相同的速度增长时，系统的排序就变得静态。 用于输入`10 3 5 3`，差值始终为 5，因此答案为 0。算法通过增长率的相等检查立即处理此问题。 

当 Technoblade 开始落后但增长更快时，答案完全取决于线性函数是否在整数点过零。 为了`0 2 5 1`，差异从 -5 开始每天增加 1，因此当累积收益抵消初始赤字时恰好发生交叉。 计算值$d = 5$匹配直接模拟。 

当 Technoblade 增长缓慢时，例如`10 1 100 5`，差距每天都在扩大。 该算法通过以下方式检测到这一点$Y_1 < Y_2$并返回 -1，而不尝试不必要的计算，这与线性差值具有负斜率并且永远不会在正方向上过零这一事实相匹配。
