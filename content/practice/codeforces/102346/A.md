 ## 解决方案
 ## 问题理解

 房间是有角的长方形`(0, 0)`和`(M, N)`。 窃贼需要从左下角到右上角的连续路径，同时严格留在每个传感器的检测盘之外。 

每个传感器`(x, y, s)`可以在几何上视为半径为封闭的圆`s`以`(x, y)`。 问题不在于找到一条实际的路径。 有用的问题是，禁止盘的集合是否可以形成连续的墙，将两个所需的角分开。 

和`K <= 1000`，检查每对传感器是可行的，因为只有`K(K-1)/2`, 最多大约`500,000`, 对。 因此，二次算法是实用的。 立方方法已经存在`10^9`操作处于上限，对于一秒的比赛限制来说太慢了。 房间尺寸可达`10^4`传感器半径也可以达到`10^4`，因此坐标值本身并不能使网格模拟有吸引力。 事实上，房间上方的网格可以包含周围`10^8`位置，这既是不必要的，又比传感器的数量多得多。 

有两个边界细节很容易处理不当。 首先，触摸被视为阻挡，因为窃贼必须保持严格大于传感器灵敏度的距离。 例如，两个完全相切的传感器必须被视为已连接：```
10 10 2
3 5 2
7 5 2
```两个圆盘接触于`(5, 5)`并从左侧到右侧形成一堵墙。 正确答案是`N`。 使用严格的`<`比较会错误地报告`S`。 

其次，即使传感器的中心严格位于房​​间内，传感器也可以到达房间边界。 例如：```
10 10 1
5 5 5
```圆盘接触所有四个边，因此它完全分开左下角和右上角。 正确答案是`N`。 如果粗心地只检查传感器中心是否位于边界上，就会错过障碍物。 

四个相关的边界对也很容易混淆。 接触顶部和左侧的连接障碍物将左下角与房间的其他部分隔开。 接触底部和右侧的组件会阻挡右上角。 接触顶部和底部的组件将两个垂直边分开，而接触左侧和右侧的组件则将两个水平边分开。 因此，阻塞条件恰好是一个连接的传感器组件接触到传感器的至少一侧。`{top, left}`和至少一侧`{bottom, right}`。 

## 方法

 直接的几何方法将尝试构建自由空间区域并搜索通过它的路径。 一种可能性是将房间离散成精细网格并运行 BFS，标记传感器覆盖的每个网格点。 这在概念上很简单，并且适用于小房间，但房间可能是`10^4`经过`10^4`。 即使每米一个细胞也会给出`10^8`单元格，而输入仅包含`1000`传感器。 离散化还带来了尴尬的精度问题，因为实际的障碍物是圆形而不是单位正方形。 

有用的观察是，只有当禁圈形成连续的障碍时，路径才变得不可能。 当两个传感器的圆盘相交或接触时，它们恰好属于同一屏障。 用于传感器`i`和`j`，这发生在`(xi - xj)^2 + (yi - yj)^2 <= (si + sj)^2`。 

因此，在建立连接后，我们可能会忘记重叠区域的确切形状。 让每个传感器成为一个图形顶点，并在两个顶点的圆盘相交或接触时连接两个顶点。 该图的每个连通分量代表一个连通的禁区。 

暴力图结构检查每对传感器，这只是`O(K^2)`。 图构建完成后，DFS 会访问每个顶点和边一次。 对于每个组件，我们记录其圆圈接触的房间边界。 如果该组件连接一个边界`{top, left}`到一从`{bottom, right}`，它在之间形成分隔符`(0, 0)`和`(M, N)`，所以答案是`N`。 如果没有组件执行此操作，则自由空间包含两个角之间的路线，因此答案是`S`。 

可以使用不相交集联合结构而不是 DFS 来实现相同的想法。 对于这个问题，DFS 足够简单并且使连通分量解释变得明确。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 网格模拟| 潜在地`O(MN)`或者更糟|`O(MN)`| 太大|
 | 暴力路径几何 | 可能比二次差得多 | 大| 太慢了|
 | 传感器交集图+DFS |`O(K^2)`|`O(K^2)`带有明确的图表| 已接受 |

 ## 算法演练

 1. 将每个传感器存储为`(x, y, s)`。 将其检测区域视为一个封闭的圆盘，因为距离恰好等于`s`也被检测到。 
2. 对于每对传感器，计算其中心之间的平方距离，并将其与半径的平方和进行比较。 如果`dx² + dy² <= (si + sj)²`,

 连接图中的两个传感器。 平方距离完全避免了浮点运算，并且最大的中间值很容易由 Python 整数处理。 
3. 从每个未访问的传感器运行 DFS。 在 DFS 期间，收集该连接组件中每个传感器触及的房间边界。 当传感器触及左边界时`x - s <= 0`，右边界时`x + s >= M`，下边界时`y - s <= 0`，以及上边界时`y + s >= N`。 
4. 完成一个连通分量后，测试它是否接触到至少一个边界`{top, left}`并且至少有一个边界`{bottom, right}`。 如果是这样，该组件是一个连续的墙，将入口角与绘画角分开，因此立即输出`N`。 
5. 如果每个连接的组件都未通过该测试，则输出`S`。 没有禁止的组件将两个角分开，因此存在一条穿过房间其余部分的连续路径。 

其工作原理：不变的是每个 DFS 组件都准确地代表传感器磁盘的一个连接联合。 每当两个磁盘接触时，小偷就无法通过它们的接触点，因为相等是被禁止的，因此合并接触的磁盘可以保留与路径存在相关的拓扑。 连接上到下或从左到右的连接禁止集将矩形的两个相对边分开，而连接上到左或下到右则切断两个目标角之一。 相反，如果没有元件连接一侧`{top, left}`与一侧`{bottom, right}`，不存在能够分隔两个对角的连接障碍墙。 该算法准确地检查这些可能的分隔符。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    M, N, K = map(int, input().split())
    sensors = [tuple(map(int, input().split())) for _ in range(K)]

    graph = [[] for _ in range(K)]

    for i in range(K):
        x1, y1, r1 = sensors[i]
        for j in range(i + 1, K):
            x2, y2, r2 = sensors[j]

            dx = x1 - x2
            dy = y1 - y2
            sr = r1 + r2

            if dx * dx + dy * dy <= sr * sr:
                graph[i].append(j)
                graph[j].append(i)

    visited = [False] * K

    for start in range(K):
        if visited[start]:
            continue

        stack = [start]
        visited[start] = True

        top = False
        right = False
        bottom = False
        left = False

        while stack:
            u = stack.pop()
            x, y, r = sensors[u]

            if y + r >= N:
                top = True
            if x + r >= M:
                right = True
            if y - r <= 0:
                bottom = True
            if x - r <= 0:
                left = True

            for v in graph[u]:
                if not visited[v]:
                    visited[v] = True
                    stack.append(v)

        if (top or left) and (bottom or right):
            print("N")
            return

    print("S")

if __name__ == "__main__":
    solve()
```第一个嵌套循环构造交集图。 没有平方根，因为比较平方距离会给出完全相同的结果，并避免浮点边界错误。 这`<=`比较是经过深思熟虑的：相切的两个检测盘没有通过其接触点留下合法路径。 

DFS 使用显式堆栈而不是递归 DFS。 和`K = 1000`，在增加递归限制后，Python 递归可能就足够了，但迭代遍历避免了依赖于递归深度，并使实现更加健壮。 

每个传感器提供四个独立的边界测试。 不等式也是包容性的，因为仅接触房间边界的圆盘参与了阻挡墙。 例如，`x - r == 0`表示传感器到达左边界，必须进行计数。 

组件在以下情况下被拒绝：`(top or left) and (bottom or right)`是真的。 在考虑坐标系使用的角方向后，这个紧凑的表达式表示四个分隔对：上下、右上角、左右下和左右。 和`top`与`left`作为一个团体并且`bottom`与`right`另一个则相当于检查分隔两个对角的四个可能的障碍。 

输入只有一个测试用例，因此`solve()`被调用一次。 Python 的任意精度整数还消除了平方坐标和半径计算中的任何溢出问题。

 ## 边缘情况

 切线对是最常见的数值边界错误。 考虑：```
10 10 2
3 5 2
7 5 2
```中心相距四米，半径之和为四，所以比较是`16 <= 16`。 磁盘在一点上精确连接。 这种接触足以阻塞通过该点的路径，因为窃贼必须保持严格超出传感器灵敏度的距离。 该图将两个传感器放在一个组件中，并且该组件接触左右边界。 算法输出`N`。 

即使每个传感器中心都严格位于房​​间内，大型传感器也可以到达角落。 为了：```
10 10 1
3 3 5
```到传感器中心的距离`(0,0)`是`sqrt(18)`，小于`5`。 入口本身位于检测盘内，因此入口处没有合法的起点。 边界检查还显示磁盘到达左侧和底部。 该算法的分隔符逻辑处理连接的边界障碍，而几何解释则清楚地说明了为什么这是一个阻塞入口情况。 

必须对精确接触边界的传感器进行计数。 例如：```
10 10 1
5 5 5
```给出`x-r = 0`,`x+r = 10`,`y-r = 0`， 和`y+r = 10`。 该组件接触每一面，所以条件`(top or left) and (bottom or right)`是真的，答案是`N`。 用严格的不等式替换任何边界比较都会错误地错过这种情况。 

最后，多个传感器可能不会单独形成一堵墙，但可以在传递合并后形成一堵墙。 假设传感器 A 接触 B，B 接触 C，C 接触房间边界。 A 与该边界相连，即使 A 本身距离该边界很远。 DFS 捕获了这一点，因为所有三个传感器都属于同一个连接的组件。 该组件记录其任何成员到达的每个边界，这正是决定整个链是否阻塞房间所需的信息。
