 ## 解决方案
 ## 问题理解

 我们有（N）辆坦克。 水箱 (i) 包含 (M_i) 条雄性小丑鱼和 (F_i) 条雌性小丑鱼。 条件（M_i=0）或（F_i>0）意味着当前有雄性的每个坦克也至少有一只雌性。 

在一个晚上，恰好有一条鱼可以从一个鱼缸转移到另一个鱼缸。 当晚结束时，每个含有至少一只雄性且没有雌性的水箱会导致该水箱中的一只雄性在第二天变成雌性。 目标是用尽可能少的动作让每条雄性鱼变成雌性。 答案是鱼需要移动的最少次数。 

鱼缸数量最多为3000条，而每条鱼的数量最多可达（10^5）。 因此，鱼的总数约为 (3\cdot10^8)，因此算法无法迭代单个鱼。 相关工作必须取决于坦克的数量，而不是鱼的总数。 对于 (N=3000)，(O(N^2)) 已经是大约 900 万次操作并且是合理的，而坦克子集的指数枚举是完全不可行的。 

有几种边缘情况很容易被错误处理。 如果根本没有雄性，答案就是零。 例如，```
2
0 3
0 5
```即使水箱里有鱼，也不需要移动。 

水箱可能完全是空的。 例如，```
2
1 1
0 0
```需要一个动作。 将雌性从第一个水箱移至空水箱中。 第一个坦克变成了仅限雄性，所以第二天它的雄性就变成了雌性。 将空水箱视为普通的女性专用水箱会错过这种可能性。 

包含雄性的水箱不一定必须保留为那些雄性被转化的水箱。 例如，```
2
2 5
1 3
```有三名男性。 独立处理两个坦克需要第一个坦克的 (5+2-1=6) 次移动，第二个坦克的 (3+1-1=3) 次移动，共 9 次移动。 更好的解决方案是将一只雄性从第二个水箱移到第一个水箱中，并在那里处理所有三只雄性，需要七次移动。 官方样本输出是7。 

第三个样本，```
4
2 3
0 0
3 1
0 0
```有五只公鱼和两个空鱼缸。 它的答案是5。空水箱很有用，因为它们本身可以成为雄性转化的水箱。 

## 方法

 直接的暴力方法是决定最终使用哪些鱼缸作为雄性鱼转化的鱼缸。 对于每个坦克子集，我们可以计算将所有雄性分配到这些选定坦克的成本并保留最佳结果。 这是正确的，因为当触发转换时，每个雄性最终都必须属于某个没有雌性的坦克。 

问题是子集的数量。 有 (2^N) 个可能的选择，通过扫描所有 (N) 个储罐来评估子集会给出 (\Theta(N2^N)) 操作。 在 (N=3000) 时，即使 (2^{3000}) 也远远超出任何实际计算。 

关键的观察结果是，选择一个坦克的贡献可以独立于其他选定的坦克来表达。 从一个简单的参考策略开始，其中每个男性需要两次动作。 一个动作将雄性放入水箱中进行处理，另一个动作则将当该水箱重新用于另一只雄性时产生的雌性移走。 这给出了参考成本

 [
 2\sum_i M_i。 
]

 现在考虑选择坦克（i）作为实际处理雄性的坦克之一。 如果它原来的（M_i）雄性留在那里，我们不需要为它们每个人支付两次移动费用。 相反，所有 (M_i) 个雄性都可以通过 (F_i+M_i-1) 个动作来处理。 与参考成本（2M_i）的差异为

 F_i-M_i-1。 
]

 因此，将罐 (i) 指定为处理罐将完全改变答案

 [
 c_i=F_i-M_i-1。 
]

 同样的公式也适用于空水箱和女性专用水箱。 如果（M_i=0），这样的坦克可以接收来自其他坦克的雄性。 它的值仍然是(F_i-1)。 特别是，空罐具有 (c_i=-1)，它正确地代表了将其用作处理罐所获得的单次移动节省。 

每个选定的处理池必须至少接收一个雄性，因此最多可以选择 (M=\sum_i M_i) 个池。 由于负数 (c_i) 总是可以改善答案，因此我们需要最大的负值，最多有 (M) 个。 如果没有负值，我们仍然需要一个处理池，因为有雄性，所以我们选择最小的（c_i）。 

这将指数子集搜索转变为对 (N) 个值进行排序并取有用的负值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (\Theta(N2^N)) | (O(N)) | 太慢了|
 | 最佳| (O(N\log N)) | (O(N)) | 已接受 |

 ## 算法演练

 1. 读取每个水箱并计算雄性总数 (M)。 如果（M=0），没有鱼必须改变性别，所以答案立即为零。 
2. 对于每个储罐，计算其价值
 [
 c_i=F_i-M_i-1。 
]
 这是当选择该坦克作为加工坦克而不是使用每个原始男性两次移动的参考成本时的成本变化。 
3. 按升序对所有 (c_i) 进行排序。 最大的负值代表最大的节省，因此应首先考虑它们。 
4. 开始于`answer = 2 * M`。 这是选择任何处理罐之前的参考成本。 
5. 从已排序的数组中取出至多（M）个负值并将它们添加到`answer`。 每个选定的值对应于一个接收至少一名雄性并保存（-c_i）次移动的坦克。 
6. 如果没有负值且（M>0），则添加最小值。 处理罐是必要的，当每一种可能的选择都有非负的成本变化时，最便宜的就是最佳的。 
7. 打印结果值。 

### 为什么它有效

 考虑任何最终策略，如果至少有一只雄性最终在那里转化，则将一个坦克称为加工坦克。 每只雄性都属于这样的一个坦克。 如果一个水箱不是加工水箱，则其所有原来的雄性都必须转移到其他地方。 如果坦克是加工坦克，则将其原始雄性保留在那里，用（F_i+M_i-1）代替每个雄性两次移动的参考成本，从而给出独立调整（F_i-M_i-1）。 唯一的全局限制是每个处理槽至少需要一个雄性，因此最多可以有（M）个处理槽。 因此，在所有可能的策略中，最好的策略恰好选择最有利的负面调整，最多为 (M) 个坦克。 如果没有任何好处，则需要选择最小的调整，因为必须存在至少一个处理槽。 该算法准确地考虑了这些选择，因此它获得了尽可能少的移动次数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    total_males = 0
    costs = []

    for _ in range(n):
        m, f = map(int, input().split())
        total_males += m
        costs.append(f - m - 1)

    if total_males == 0:
        print(0)
        return

    costs.sort()

    answer = 2 * total_males
    used = 0

    for c in costs:
        if c >= 0 or used == total_males:
            break
        answer += c
        used += 1

    if used == 0:
        answer += costs[0]

    print(answer)

if __name__ == "__main__":
    solve()
```第一个循环只需要雄性总数和每个坦克的值（F_i-M_i-1）。 之后就不需要存储原始的(M_i,F_i)对了。 

参考成本存储在`answer`作为`2 * total_males`。 Python 整数具有任意精度，因此最大可能的鱼总数不会导致溢出问题。 

排序后，负值按照从小到大的顺序进行处理。 选择后我们停下来`total_males`因为每个选定的加工池必须至少包含一只雄性。 在实践中（N\le3000），因此这个限制主要与公式的正确性相关，而不是与性能相关。 

条件`used == 0`处理每个 (c_i) 都是非负的情况。 只要有至少一只雄性，我们仍然必须选择一个处理池，因此添加最小的值。 

空罐自然会产生 (c_i=-1)。 它不需要特殊情况，这是该公式的有用特征之一。

 ## 边缘情况

 当没有男性时，算法在排序之前返回零。 为了```
2
0 0
0 100000
```男性总数为零，因此不需要移动。 

当水箱为空时，其值为 (-1)。 为了```
2
1 1
0 0
```值为 (-1,-1)，并且有一名男性，因此算法选择其中之一。 初始参考成本为 2，所选坦克贡献 (-1)，给出答案 1。 

当一个水箱中有雌性但没有雄性时，它仍然可以是一个有用的加工池，因为可以将另一个水箱中的雄性移入其中。 例如，```
2
2 1
0 5
```具有值 (-2) 和 (4)。 第一个坦克是更好的目标，因此第二个坦克的雌性可以留在原地，而如果需要的话，其雄性可以在其他地方处理。 该公式将第二个水箱视为可能的目标，但没有错误地要求它包含原始雄性。 

当有利的目标坦克比男性多时，我们不能选择所有目标坦克，因为每个选定的坦克都需要至少一名男性。 假设有一只公鱼和许多空鱼缸。 只有一个目标可以真正接收该雄性。 因此该算法最多需要`total_males`负值。 

当每个槽都具有非负值（F_i-M_i-1）时，选择处理槽永远不会提高参考成本。 如果至少有一名男性，则目标仍然是必要的，因此算法会选择最小值。 这正是示例 2 中的情况，其中值为 2 和 1，答案变为 (2\cdot3+1=7)。 

当多个坦克的数值为负值时，只要有足够的雄性来占领它们，就应该选择所有有用的坦克。 在样本3中，值为(0,-1,-3,-1)，并且有五个男性，因此可以选择所有三个负值。 从 (2\cdot5=10) 开始，调整将答案减少为 (10-3-1-1=5)。
