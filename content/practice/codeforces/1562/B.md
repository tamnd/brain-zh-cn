 ## 解决方案
 ## 问题理解

 我们得到一个数字`n`十进制表示中没有零，任务是删除一些数字以获得一个**非质数**的数字，可以是合数或`1`。 目标是删除尽可能多的数字，同时仍然确保结果不是质数。 输入包括多个测试用例，每个测试用例指定位数`k`和号码`n`本身。 每个测试用例的输出是剩余数字的长度和删除后的数字本身。 

限制条件适中：`k`最多为 50，并且`k`所有测试用例最多为 10,000 个。 这意味着我们无法负担枚举所有数字子序列的算法，因为子序列的数量呈指数增长`k`。 我们需要一种主要是线性的方法`k`每个测试用例。 

可能破坏简单解决方案的边缘情况是小数字，其中个位数或数字对是素数。 例如，如果`n = 53`，没有一个数字是非质数，但是数字对`53`本身是素数，因此解决方案必须考虑对或其他短子序列。 另一个微妙的情况是完全由相同数字组成的数字，例如`4444`，其中删除除一位数字之外的所有数字仍然会产生复合值。 

## 方法

 暴力方法是生成长度为 1 到 1 的所有数字子序列`k-1`并检查每个数字是否不是素数。 原则上这是可行的，但是子序列的数量是`2^k - 1`，对于`k = 50`。 即使对每个数字进行线性素性测试也太慢了。 

简化问题的关键观察是我们只需要找到一个**小的非素数**，理想情况下长度为 1 或 2。这是有效的，因为总是存在一个个位数的合数 (`4, 6, 8, 9`) 或形成两位非素数的一对数字。 自从`n`没有零，任何数字`1, 4, 6, 8, 9`立即给出长度为 1 的有效答案。如果没有一个数字有效，则检查所有数字对是可行的：最多有`k*(k-1)/2`对，最多 1,225 个`k = 50`，验证两位数是否为非素数的时间为常数。 

因此，最佳解决方案是：首先扫描一位数字组合。 如果不存在，则扫描所有两位数。 该问题保证至少存在一个解决方案，因此我们总会找到一个。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^k * k) | O(2^k * k) | O(k) | 太慢了|
 | 最佳| O(k^2) | O(k^2) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`k`和`n`。 转变`n`到数字列表中以便于操作。 
2. 从左到右扫描数字，检查集合中是否有数字`{1, 4, 6, 8, 9}`。 这些是非素数的个位数。 如果找到则输出`1`和该数字，然后继续下一个测试用例。 
3. 如果没有找到个位数合数，则通过取每对数字来生成所有两位数`(i, j)`和`i < j`。 
4. 对于每个两位数，检查它是否**不是素数**。 由于最大的两位数是 99，因此在预先计算的小素数集中进行简单查找或恒定时间检查就足够了。 
5.输出长度`2`以及发现的第一个非质数的两位数。 继续下一个测试用例。 

**为什么有效**：通过构造，该算法首先优先考虑单位数字组合，这是我们可以进行的最大删除以减少数字。 如果不存在，则根据问题约束保证任何两位数非素数都存在。 这确保了正确性和最少的计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

# Helper: check if 2-digit number is prime
def is_prime_2digit(x):
    if x < 2: return False
    for p in [2, 3, 5, 7]:
        if x == p: return True
        if x % p == 0: return False
    return True

t = int(input())
for _ in range(t):
    k = int(input())
    n = input().strip()
    
    # Step 1: check single-digit non-prime
    for d in n:
        if d in '14689':
            print(1)
            print(d)
            break
    else:
        # Step 2: check two-digit non-prime
        found = False
        for i in range(k):
            for j in range(i+1, k):
                num = int(n[i] + n[j])
                if not is_prime_2digit(num):
                    print(2)
                    print(n[i] + n[j])
                    found = True
                    break
            if found:
                break
```该代码首先检查立即非素数的数字。 这`else`之后`for`循环确保如果不存在单位数解，我们只输入两位数搜索。 对于两位数，我们用一个小的常量时间素性检查来检查每个组合，这是安全的，因为这些数字最多都是 99。 

## 工作示例

 ### 输入示例 1

 | n | 发现个位数合成 | 找到两位数对 | 输出|
 | --- | --- | --- | --- |
 | 237 | 237 2,3,7 → 无 | 23, 27 → 27 是合数 | 2 / 27 | 2
 | 44444 | 4 存在 | - | 1 / 4 |

 迹线显示，对于 237，不存在个位数解，因此第一个非素数对`27`被选中。 对于 44444，个位数 4 就足够了。 

### 输入示例 2

 | --- | --- | --- | --- |
 | 773 | 773 无 | 77 → 77 是合成 | 2 / 77 |
 | 35 | 35 无 | 35 → 35 是合成 | 2 / 35 | 2 / 35

 此处，扫描单位数字组合失败。 生成对会产生第一个非素数。
