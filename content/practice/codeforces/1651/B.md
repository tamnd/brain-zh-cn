 ## 解决方案
 ## 问题理解

 我们需要构造一个长度的数组`n`这样，将给定的操作应用于任何位置对都不会减少数组的总和。 

假设我们选择两个值`x`和`y`。 该操作将两个数字替换为`|x-y|`。 

手术前，这两个位置贡献$$x+y$$至总和。 

手术后，他们贡献$$2|x-y|.$$为了使总和永远不会减少，我们需要$$2|x-y| \ge x+y$$对于数组中的每对元素。 

输入包含多个测试用例。 对于每个测试用例，我们仅给出所需的数组长度`n`。 我们必须构造一个有效的数组，其元素位于`1`和`10^9`，或者证明不存在这样的数组。 

限制很小。 最多有 100 个测试用例`n`最多 1000。每个测试用例以线性时间运行的任何构造都绰绰有余。 真正的挑战是发现数学模式，使每一对满足所需的不等式，同时将所有值保持在允许的范围内。 

一些边缘情况值得关注。 

考虑`n = 2`。 数组`[1, 2]`是有效的，因为$$2|2-1| = 2,\qquad 1+2 = 3.$$实际上这减少了总和，所以它是无效的。 粗心的解决方案可能会假设任何递增序列都有效。 我们需要连续值之间有更大的差距。 

考虑`n = 3`和数组`[1, 2, 4]`。 一对`(2,4)`,$$2|4-2| = 4 < 6.$$总和减小，因此 2 的幂不够。 

考虑大`n`。 即使我们找到一个快速增长的序列，所有值也最多只能保留`10^9`。 增长太快的结构可能会在达到长度之前超出限制`n`，使某些值非法。 

## 方法

 蛮力观点是直接考虑每对的条件。 给定一个数组，我们可以检查所有对`(i,j)`并验证是否$$2|a_i-a_j| \ge a_i+a_j.$$对于长度的数组`n`，这需要检查`O(n^2)`对。 

真正的问题不是验证而是构建。 我们需要一个数组族来自动满足每一对的不等式。 

假设两个元素满足`x < y`。 然后$$|x-y| = y-x.$$代入不等式可得$$2(y-x)\ge x+y.$$重新排列，$$y \ge 3x.$$这是关键的观察结果。 每对都必须满足条件，对于排序数组来说，每个较大元素至少是较小元素的三倍就足够了。 

一个自然的构造是$$1,\ 3,\ 9,\ 27,\dots$$其中每个元素是前一个元素的三倍。 

对于任何有索引的对`i < j`,$$a_j = 3^{j-i}a_i \ge 3a_i,$$因此导出的条件自动成立。 

现在我们只需要检查有多少个这样的值适合`10^9`。$$3^{19}=1162261467>10^9,$$尽管$$3^{18}=387420489<10^9.$$开始于`1`，我们最多可以使用 19 个数字：$$3^0,3^1,\dots,3^{18}.$$因此，只有当`n \le 19`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 候选者的暴力验证 | O(n²) | O(1) | O(1) | 不是一个建筑 |
 | 3 的幂 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`。 
2.如果`n > 19`， 打印`NO`。 

没有有效的三幂构造符合限制`10^9`，官方解决方案依赖于这样一个事实：在允许的范围内不可能有更大的有效构造。 
3. 否则打印`YES`。 
4. 生成序列$$1,3,9,27,\dots$$通过将当前值重复乘以`3`。 
5.输出第一个`n`价值观。 

这种构造起作用的原因是每个后面的元素至少是每个前面的元素的三倍。 这正是从控制总和是否减少的不等式中获得的条件。 

### 为什么它有效

 取构造数组的任意两个元素并假设`x < y`。 

因为数组是三的幂，所以每个较大的元素至少是较小元素的三倍：$$y \ge 3x.$$重新排列给出$$y-x \ge \frac{x+y}{2}.$$乘以二，$$2(y-x)\ge x+y.$$自从`y>x`，我们有`|x-y|=y-x`， 所以$$2|x-y|\ge x+y.$$这两个位置术后的贡献至少是术前的贡献。 由于所有其他头寸保持不变，因此总和永远不会减少。 

最大生成值为`3^{18}=387420489`，满足界限`10^9`。 下一个幂超出了限制，因此长度 19 是最大可能的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())

    if n > 19:
        print("NO")
        continue

    print("YES")

    cur = 1
    ans = []

    for _ in range(n):
        ans.append(cur)
        cur *= 3

    print(*ans)
```该程序直接遵循构造。 

第一个决定是是否`n`超过 19。如果超过，我们立即打印`NO`。 

对于可行的长度，我们迭代地构建序列。 开始于`1`，每个新值都是通过将前一个值乘以得到的`3`。 这避免了对浮点运算或求幂错误的任何担忧。 

所有算术都可以轻松地用 Python 整数表示。 即使最大的生成值也低于`10^9`，因此不存在溢出问题。

 ## 边缘情况

 考虑：```
1
2
```该算法输出：```
YES
1 3
```对于唯一的一对来说，$$2|3-1| = 4,$$而原始贡献是$$1+3 = 4.$$总和保持不变，这是允许的。 

考虑：```
1
19
```生成的数组结尾为$$3^{18}=387420489.$$每个元素都在允许的范围内。 对于任何一对，较大的值至少是较小的值的三倍，因此所需的不等式成立。 

考虑：```
1
20
```下一个力量将是$$3^{19}=1162261467,$$这超过了`10^9`。 算法正确打印`NO`而不是产生无效的数组。 

考虑序列深处的一对，例如`81`和`2187`。 

自从$$2187 = 27 \cdot 81,$$我们有$$2187 \ge 3 \cdot 81.$$因此$$2(2187-81)=4212,$$和$$2187+81=2268.$$新的贡献比旧的贡献更大，证实了证明中使用的不变量。
