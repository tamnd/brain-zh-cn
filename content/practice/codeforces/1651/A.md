 ## 解决方案
 ## 问题理解

 我们正在模拟一场淘汰赛，参赛人数为 2 的幂。 玩家被标记为从 1 到$2^n$，他们反复对峙，直到只剩下一个。 

配对规则是固定的，不依赖于技能或之前的成绩：在每一轮中，玩家按顺序分组。 首先，1 玩 2，3 玩 4，依此类推。 相邻对的获胜者随后以相同的结构方式在下一轮中相遇，因此分组是完全确定的。 

这个问题的有趣之处在于决定每场比赛的不寻常规则。 如果有两个玩家$x$和$y$竞争，平等控制一切。 什么时候$x+y$为奇数，较小的索引获胜。 什么时候$x+y$为偶数时，指数较大者获胜。 这意味着结果在索引顺序上不是单调的，并且锦标赛不是标准的“较高的总是获胜”或“较低的总是获胜”的分组。 

任务是确定哪个初始索引在所有$n$回合。 

从计算角度来看，约束非常小。 和$n \le 30$，赛事规模可达$2^{30}$，大约有十亿玩家。 这立即排除了对所有参与者的任何模拟，甚至明确地构建中间回合。 任何解决方案的运行时间都必须与$n$，而不是玩家数量。 

一个微妙的陷阱是假设局部一致性意味着全局单调性。 例如，人们可能错误地认为低指数或高指数始终占主导地位。 但一个小检查已经打破了这种直觉：$n=1$，玩家 1 击败 2，而对于更高的回合，交互会根据奇偶传播而翻转，因此简单的“总是左边获胜”或“总是右边获胜”规则在本地不成立。 

## 方法

 暴力模拟将明确构建所有$2^n$玩家并反复模拟回合。 在每一轮中，我们都会比较相邻的对，计算获胜者，并形成下一个列表。 每轮玩家人数减半，因此总工作量为$2^n + 2^{n-1} + \dots + 1$，即$O(2^n)$。 为了$n=30$，这是完全不可行的。 

关键的观察是我们不需要跟踪所有玩家，只需要跟踪最终获胜者的身份。 配对的结构和确定性规则意味着锦标赛有一个固定的全局获胜者，与模拟中间状态无关。 

如果我们仔细检查小案例，就会发现一种模式。 为了$n=1$，获胜者是 1。对于$n=2$，最终获胜者是 3。对于$n=3$，为 7。这表明获胜者始终是最大可能的索引，$2^n - 1$，除了$n=1$其中它是 1，因为只有两名玩家，并且规则强制较小的索引赢得那场比赛。 

更深层次的原因是，在前几轮的两个幸存者之间的任何比赛中，其中一个必须是其细分市场中最大的可用代表，并且奇偶规则确保在后面的几轮中与结构上可比的对手配对时，较大的指数占主导地位。 这会导致级联效应，其中最高可达索引在每个合并步骤中幸存下来。 

因此，我们不进行模拟，而是直接根据模式计算答案。

 ## 算法演练

 1. 阅读$n$。 这定义了锦标赛的规模$2^n$，但我们不会建造它。 
2.如果$n = 1$，直接返回 1，因为只有一场比赛，并且规则强制玩家 1 获胜。 
3. 否则计算$2^n - 1$作为获胜者。 
4. 输出结果。 

我们减去 1 而不是使用的原因$2^n$来自消除结构。 尽管有$2^n$对于参与者，交互规则确保最终的幸存者永远不是完整的最大索引，而是第二高的结构代表索引。 

### 为什么它有效

 锦标赛结构重复合并相同大小的相邻段。 在每次合并中，段的有效代表在奇偶校验规则下成为其最大索引幸存者。 当细分市场结合起来时，这些代表本身就会相互竞争，并且相同的统治模式会在各个层面上重复出现。 系统中的最高索引在后续轮次中始终没有结构性弱点，因为它始终是其本地配对上下文中最大的元素。 这种归纳稳定性确保它能够在所有合并中幸存下来，并且所有其他候选者都在某些早期合并阶段被淘汰。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    if n == 1:
        print(1)
    else:
        print((1 << n) - 1)
```该实现直接对派生结构进行编码，而不是模拟锦标赛。 左移运算计算$2^n$在恒定时间内有效。 除基本情况外，我们对所有情况减去 1$n=1$，这可以避免错误地返回 1$2^1 - 1 = 1$巧合地匹配但不代表一般模式。 

的分支为$n=1$包含在内是为了使逻辑明确并防止将公式误解为普遍有效而无需异常处理。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        if n == 1:
            out.append("1")
        else:
            out.append(str((1 << n) - 1))
    return "\n".join(out)

# provided samples
assert run("2\n3\n1\n") == "7\n1"

 ## 边缘情况

 对于$n=1$，算法直接返回1，而不应用公式。 这避免了依赖表达式$2^n - 1$作为一个普遍规则，尽管它在这里巧合地给出了相同的结果。 显式分支确保正确性源自问题的单匹配定义，而不是模式外推。 

为了$n=2$，计算得出$2^2 - 1 = 3$。 跟踪锦标赛：1 胜 2、3 胜 4、然后 1 面对 3。$1+3=4$是偶数，较大的索引获胜，所以 3 获胜。 这与公式输出完全一致。 

对于较大的$n$，重复的配对结构保证了在每个合并级别中始终保留最高可达索引，因此没有中间配对可以消除它。
