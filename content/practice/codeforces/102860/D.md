 ## 解决方案
 # 问题理解

 房子是一个正交多边形：它的墙壁是水平或垂直的，它的角有整数坐标。 我们需要建造最短的包含整个房子的封闭栅栏，并且栅栏上的每个点至少保持在曼哈顿距离`l`从房子的每一个角落。 输入按顺序给出房屋的边界顶点，输出是此类栅栏的最小可能周长。 

约束足够大，处理点的数量必须保持线性或接近线性。 房子最多可以有`100000`顶点，因此比较每对顶点或通过许多几何操作显式模拟整个扩展形状的算法将不适合。 解决方案围绕`O(n log n)`是合适的，因为对线性数量的生成点进行排序是主要操作。 

关键的几何观察是，所需的栅栏是房屋的闵可夫斯基扩展曼哈顿半径的边界`l`形状。 我们不需要构建该边界的每个点，而只需要一小组候选极值点。 对于每个原始顶点`(x, y)`, 四点`(x+l, y)`,`(x-l, y)`,`(x, y+l)`， 和`(x, y-l)`就足够了。 所有这些生成点的凸包给出了最短的封闭栅栏。 

一些边缘情况很容易被忽略。 如果`l = 0`，答案只是原始多边形的周长，生成的点包含许多重复项。 例如：```
Input:
4 0
0 0
0 2
2 2
2 0

Output:
8
```粗心的实现可能会创建具有重复点的外壳，并错误地计算零长度边，或者在对相同点进行排序时失败。 

另一个棘手的情况是凹形房屋。 最佳围栏不是在每个边缘独立移动的原始形状，因为最短的封闭曲线可能会穿过凹角。 例如：```
Input:
9 0
0 0
4 0
4 1
2 1
2 3
1 3
1 1
0 1
0 0
```正确的栅栏遵循外边界，但在应用正距离后，凹口消失。 仅将每面墙独立向外移动的方法可能会留下不必要的内角并产生更长的周长。 

## 方法

 直接的方法是尝试通过处理房屋的每一面墙来构建偏移多边形。 每个水平墙都可以垂直移动，每个垂直墙都可以水平移动，然后可以计算所有交点。 这看起来很自然，因为房子本身仅由轴对齐的部分组成。 

困难在于曼哈顿距离不仅仅创建水平和垂直边界。 在拐角处，最近的点形成对角线段。 手动处理每个角落的情况需要跟踪相邻墙壁如何相互作用，尤其是在凹角周围。 简单的几何构造也可能会创建太多分段，需要仔细合并。 

更好的观点是考虑距离的定义。 与某个点的曼哈顿距离的所有点的集合`(x, y)`至多是`l`是一颗钻石。 用这些钻石扩大整个房子就形成了禁区边界。 最小的有效栅栏是此扩展的外边界。 

对于正交多边形，该展开的极值点是通过在四个基本方向上移动每个原始顶点来生成的`l`。 一旦收集了这些点，剩下的所有工作就是标准的凸包问题。 船体会自动去除不必要的凹入部分，只保留最短围栅上出现的点。 

暴力构造需要花费精力来推理每个片段的交互。 外壳方法用单个几何不变量替换所有这些情况：生成点的凸包恰好是扩展形状的边界。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取房子的所有顶点并为每个顶点生成四个移位点。 这些点代表曼哈顿扩张可能的极端位置。 我们不需要沿着边缘生成点，因为扩展形状的每条边缘都是由其端点极值决定的。 
2. 删除重复的生成点，并将剩余点按字典顺序排序。 排序允许单调链壳算法按顺序处理点。 
3. 构建凸包的下部和上部。 添加新点时，只要不是逆时针转动，就删除前一个点。 这仅保留外部边界点。 
4. 按顺序遍历最终的外壳，并将每对连续顶点之间的欧氏距离相加，包括最后一个顶点到第一个顶点的距离。 这给出了栅栏的长度。 

为什么它有效：

 集合的曼哈顿展开式是该集合与半径为菱形的闵可夫斯基和`l`。 对于正交多边形，该扩展形状的每个极值点必须来自将原始角移动四个基本方向之一。 生成的点集包含所有此类极值。 采用凸包可以精确保留最小封闭栅栏所需的外边界，同时删除对周长无贡献的点。 由于栅栏必须包含扩展区域并且无法进入它，因此不能存在更短的有效栅栏。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def cross(a, b, c):
    return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

def convex_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def solve():
    n, l = map(int, input().split())
    points = []

    for _ in range(n):
        x, y = map(int, input().split())
        points.append((x + l, y))
        points.append((x - l, y))
        points.append((x, y + l))
        points.append((x, y - l))

    hull = convex_hull(points)

    ans = 0.0
    m = len(hull)
    for i in range(m):
        x1, y1 = hull[i]
        x2, y2 = hull[(i + 1) % m]
        ans += math.hypot(x1 - x2, y1 - y2)

    print("{:.10f}".format(ans))

if __name__ == "__main__":
    solve()
```输入处理直接读取多边形顶点并立即创建四个可能的移位点，与算法的步骤 1 匹配。 坐标可以变得和周围一样大`2 * 10^8`，它仍然可以由 Python 整数安全地处理。 

外壳实现采用单调链方法。 这`cross`函数确定三点的方向。 删除非左转点是必要的，因为这些点位于当前边界内并且不能出现在最短栅栏上。 

重复删除通过`set`当`l = 0`或者当多个生成点重合时。 如果没有它，外壳循环可能包含重复的顶点并创建不正确的周长计算。 

周长计算使用`math.hypot`，避免手动计算平方根并直接使用浮点输出。 Python 整数避免叉积计算期间溢出。

 ## 边缘情况

 当`l = 0`，每个生成的点与原始顶点有四次相同。 该算法首先删除这些重复项，然后计算正常的凸包。 对于前面示例中的正方形，船体是原始正方形，答案是`8`。 

对于凹多边形，该算法从不尝试保留原始缩进。 考虑第二个样本。 生成的点包括向内凹口周围的候选点，但凸包丢弃那些不能出现在外部边界上的点。 由此产生的船体正是最短的栅栏形状。 

对于非常大的坐标，移动点可能会接近`2 * 10^8`在幅度上。 Python 的整数算术使所有叉积计算保持精确，并且只有最终的周长转换使用浮点值。 这可以防止船体建造过程中出现精度问题。
