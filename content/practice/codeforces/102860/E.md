 ## 解决方案
 # 问题理解

 国旗是由`n`星星排列成水平行。 这些行不必包含完全相同的星数，但每个行的大小必须与其他行的大小最多相差 1 个。 如果使用两种不同的行大小，则相同大小的行不能相互接触，因此两种大小必须交替。 在所有可能的排列中，我们需要找到行数与任意行中的最大星星数之间可能的最小差异。 

输入包含单个整数`n`，可用星星的数量。 输出是此类标志的高度和宽度之间的最小可能绝对差。 

的价值`n`可以大到`10^12`，因此迭代所有可能的行数是不可能的。 线性解决方案最多需要`10^12`检查，远远超出可用时间。 我们需要利用可能的行计数的数学结构。 不同值的个数`floor(n / x)`只是关于`2 * sqrt(n)`，对于这个限制来说足够小。 

当星星的数量不能分成相等的行时，就会出现棘手的情况。 例如，与`n = 5`，使用两行给出大小`3`和`2`，但这些行是允许的，因为只有两行。 粗心的实现可能会拒绝它，因为两个行大小不同。 正确答案是`1`。```
5
```输出：```
1
```另一种边缘情况是所有行都具有相同的长度。 为了`n = 16`，四行四星有效。 答案是`0`。```
16
```输出：```
0
```仅检查交替行的解决方案可能会错过这种情况，因为没有两种不同的行大小可供交替。 

## 方法

 直接的方法是尝试所有可能的行数`r`。 对于每个选择，最大行长度为`ceil(n / r)`。 我们可以检查剩余的星星是否可以分布在大小的行中`ceil(n / r)`和`floor(n / r)`。 这是正确的，因为每个有效标志都必须恰好具有这两个可能的行大小。 然而，尝试一切`r`从`1`到`n`执行`O(n)`检查。 和`n`最多`10^12`，这是不可能的。 

关键的观察是有效的行计数可以使用商来描述`q = floor(n / r)`。 什么时候`q`是固定的，一切皆有可能`r`值形成一个区间。 大约只有`2 * sqrt(n)`不同的商。 

假设一个标志有`r`行和`q = floor(n / r)`。 让`rem = n mod r`。 

如果`rem = 0`, 每行都有大小`q`， 所以`r`必须是`n / q`。 

否则，有`rem`行大小`q + 1`和`r - rem`行大小`q`。 这两个行大小必须交替，因此它们的计数最多可以相差一：```
abs(rem - (r - rem)) <= 1
```这给出了三个可能的方程：```
rem = r / 2
rem = (r - 1) / 2
rem = (r + 1) / 2
```替代`n = q * r + rem`给出了三个直接候选人`r`:```
r = 2n / (2q + 1)
r = (2n + 1) / (2q + 1)
r = (2n - 1) / (2q + 1)
```对于每个商区间，我们只需要测试这几个候选者。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 太慢了 |
 | 最佳| O(sqrt(n)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 迭代所有具有相等值的区间`floor(n / r)`。 对于起始行数`l`, 计算`q = n // l`和最大行数`r`具有相同的商。 这会立即跳过许多不可能的行计数。 
2. 对于当前商`q`,测试候选人`n / q`。 这是所有行具有相同大小的唯一可能的行计数。 
3. 测试由交替行计数得出的三个公式：```
2n / (2q + 1)
(2n + 1) / (2q + 1)
(2n - 1) / (2q + 1)
```只有当前商区间内的候选者实际上可以具有该值`q`。 
4. 对于每个候选行计数，验证行分布是否有效并更新`abs(rows - maximum_row_size)`。 

为什么它有效：每个可能的标志都有一些行数`r`。 该算法访问包含此的唯一商区间`r`。 在该区间内，上面的方程涵盖了两种行大小交替的所有可能方式。 大小相同的行单独处理。 由于检查了每一种有效排列，因此记录的最小差异就是最佳排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(n):
    ans = n
    def check(r):
        nonlocal ans
        if r <= 0:
            return
        q = n // r
        rem = n % r
        if rem != 0 and abs(rem - (r - rem)) > 1:
            return
        ans = min(ans, abs(r - ((n + r - 1) // r)))

    l = 1
    while l <= n:
        q = n // l
        r = n // q

        if n % q == 0:
            check(n // q)

        d = 2 * q + 1
        for x in (2 * n, 2 * n + 1, 2 * n - 1):
            if x > 0 and x % d == 0:
                cand = x // d
                if l <= cand <= r:
                    check(cand)

        l = r + 1

    return ans

def main():
    n = int(input())
    print(solve_case(n))

if __name__ == "__main__":
    main()
```主循环在商区间之间跳转，而不是逐一增加行数。 间隔`[l, r]`包含产生相同结果的所有行数`floor(n / rows)`价值。 

由于所有行可以具有相同的大小，因此可单独检查可整性情况。 对于其余情况，生成的三个候选正是较大和较小行计数可以交替的情况。 

验证函数重新计算余数并检查交替条件。 这避免了单独依赖代数，并防止整数除法导致无效候选。 Python 整数可以安全地处理大值，因此不需要溢出处理。

 ## 边缘情况

 对于`n = 5`，算法达到商区间`q = 2`。 候选人`r = 2`由交替公式生成。 余数为`1`，所以行的大小`3`和`2`。 它们的计数相差 1，这意味着该标志有效，答案变为`1`。 

为了`n = 16`, 候选人`r = 4`来自等行情况，因为`16`可以整除`4`。 余数为零，因此每行包含四颗星。 高度和宽度都是四，产生答案`0`。 

对于较大的值，例如`n = 10^12`，该算法从不尝试一万亿行计数。 它只访问商区间，并且相同的算术适用于大整数。 这就是可行解和暴力搜索之间的区别。
