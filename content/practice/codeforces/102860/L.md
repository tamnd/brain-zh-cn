 ## 解决方案
 ## 问题理解

 我们有一个矩形板，其中每个单元格都是黑色或白色。 我们需要决定是否可以放置南磁体和最少数量的北磁体，以便通过移动北磁体可以准确地到达黑色单元格，而永远无法到达白色单元格。 

当两个细胞位于同一行或同一列时，北极磁体会将一个细胞移向南极磁体。 南磁体永远不会移动。 由于每一行和每一列都必须有一个南极磁体，因此北极磁体的可到达区域取决于哪些行和列包含南极磁体。 

关键的观察结果是，棋盘本身已经描述了最终可到达的区域。 黑色单元必须是可到达的，因此一些北极磁体最终必须到达那里。 白细胞必须永远无法到达，这意味着运动规则在从起始北磁体扩展时不能穿过白细胞。 

这些限制允许电路板的尺寸达到 1000 x 1000，从而提供最多 100 万个单元。 任何尝试每种可能的放置或重复模拟许多单元之间的移动的解决方案都会太慢。 我们需要一种单元数量接近线性的方法，因为百万单元扫描是可行的，但网格上的二次工作则不可行。 

棘手的情况来自断开的黑色区域和空行或空列。 例如：```
2 2
##
##
```答案是`1`。 单个北极磁体可以覆盖整个矩形，因为每一行和每一列都必须包含南极磁体，从而允许在两个方向上移动。 

一个常见的错误是只计算黑色单元格的连通分量。 考虑：```
2 2
#.
##
```答案是`1`， 不是`2`。 尽管不允许对角相邻，但左上单元格和下行通过列方向上的移动连接。 

另一个危险的情况是完全白板：```
1 3
...
```答案是`0`。 不需要北极磁体，因为没有必须到达的黑色单元格。 总是用 1 初始化答案的解决方案在这里会失败。 

## 方法

 直接的方法是尝试放置北磁体并模拟所有可能的运动。 由于北极磁体可以穿过行和列，因此可以想象从每个可能的单元格开始并检查它是否恰好到达黑色单元格。 这是正确的，因为模拟遵循实际规则，但成本太高。 在具有一百万个单元的板上，从每个单元重复探索可能需要大约一万亿次操作。 

有用的结构来自于以不同的方式看待运动规则。 北极磁体不需要一系列复杂的移动来到达细胞。 如果一行包含南极磁铁，则北极磁铁可以在该行内水平移动，直到被可到达的黑色区域的限制阻挡。 垂直方向上的列也是如此。 

最终可到达的单元格必须形成一个形状，其中每个连接的黑色组件在其边界矩形内不包含空行或空列。 如果组件在其极端之间缺少行或列，则移动将穿过白色单元格，从而导致无法放置。 

对于黑色单元格的每个有效连接组件，一个北磁体就足够了。 北极磁体的最小数量正是此类组件的数量。 我们可以通过洪水填充找到这些组件，并通过检查其边界矩形来验证每个组件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((纳米)^2) | O(纳米) | 太慢了|
 | 最佳 | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1. 扫描网格并找到每个未被访问过的黑色单元格。 从它开始洪水填充以收集整个连接的黑色组件。 
2. 在洪水填充期间，记录组件大小以及最小和最大行索引和列索引。 这四个边界描述了包含组件的最小矩形。 
3. 洪水填充完成后，检查该矩形内的每个单元格。 如果任何单元格是白色的，则该组件不能作为有效的磁体区域存在，因为北磁体将被迫穿过白色单元格。 在这种情况下，答案是不可能的。 
4. 如果矩形仅包含黑色单元，则该组件恰好需要一个北磁体。 增加答案数。 
5. 继续，直到处理完所有黑色单元格。 

为什么它有效：

 有效组件必须完全填充在其边界矩形内。 如果白色单元格出现在该矩形内部，则相对两侧的两个黑色单元格之间的移动将不可避免地使该白色单元格可达。 相反，当组件是实心矩形时，在其内部放置一个北极磁铁，并在每一行和每一列中放置南极磁铁，可以使磁铁到达矩形中的每个单元格，并且永远不会离开它。 由于单独的组件无法在不访问额外单元的情况下共享北极磁体，因此每个有效组件恰好贡献一个所需的北极磁体。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    visited = [[False] * m for _ in range(n)]
    ans = 0
    dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '#' and not visited[i][j]:
                ans += 1
                stack = [(i, j)]
                visited[i][j] = True

                min_r = max_r = i
                min_c = max_c = j

                while stack:
                    r, c = stack.pop()
                    min_r = min(min_r, r)
                    max_r = max(max_r, r)
                    min_c = min(min_c, c)
                    max_c = max(max_c, c)

                    for dr, dc in dirs:
                        nr, nc = r + dr, c + dc
                        if 0 <= nr < n and 0 <= nc < m:
                            if grid[nr][nc] == '#' and not visited[nr][nc]:
                                visited[nr][nc] = True
                                stack.append((nr, nc))

                for r in range(min_r, max_r + 1):
                    for c in range(min_c, max_c + 1):
                        if grid[r][c] == '.':
                            print(-1)
                            return

    print(ans)

if __name__ == "__main__":
    solve()
```外部循环定位每个未探索的黑色分量的起点。 基于堆栈的洪水填充避免了 1000 x 1000 板上的递归深度问题。 

在探索组件时，代码只需要四个矩形边界，而不是存储所有组件单元格。 经过探索后，矩形扫描会验证组件是否是完整的矩形。 

在验证之前答案会增加，因为每个发现的组件都代表一个可能的北极磁体。 如果验证失败，该函数立即打印`-1`因为任何安排都不能满足规则。 

洪水填充中的边界检查是必要的，因为组件可能会接触电路板的任何一侧。 Python 整数在这里不会溢出，最大内存使用量来自访问的数组，大约有一百万个布尔条目。

 ## 边缘情况

 对于有孔的组件：```
3 3
###
#.#
###
```洪水填充会访问所有八个黑色单元格。 边界矩形是整个板，但中心单元格是白色的。 验证步骤立即检测到并返回`-1`。 

对于空板：```
2 4
....
....
```因为没有黑色单元，所以不会开始洪水填充。 答案仍然为零，这与不需要北极磁体的事实相符。 

对于单个细胞：```
1 1
#
```组件矩形的宽度为一个单元格，高度为一个单元格。 它不包含白细胞，因此它是有效的并且只需要一块北磁体。 

对于完全填充的板：```
2 3
###
###
```整个板是一个组件。 它的边界矩形等于棋盘本身，所以答案是 1。
