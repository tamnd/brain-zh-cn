 ## 解决方案
 ## 问题理解

 我们有两种类型的棋子：白子和黑子。 我们需要将它们全部排列成一个垂直的塔。 黑色条纹是一个最大的连续黑色棋子块，这意味着该块中的每个黑色棋子都接触上方或下方的另一个黑色棋子，并且该块通过白色棋子或塔的末端与其他黑色棋子分开。 

任务是在选择所有碎片的最佳顺序后，找到尽可能多的独立黑色条纹。 

输入包含白色棋子的数量和黑色棋子的数量。 输出是可以创建的黑色组的最大数量。 

这些约束允许计数非常大，最多可达 10^18 左右。 这立即排除了任何模拟、塔的建造或对部件数量的动态编程。 该解决方案必须仅依赖于两个量之间的数学关系，并且在恒定时间内运行。 

关键的边缘情况来自于白色碎片是分隔符的事实。 例如，如果没有黑色棋子，则不可能有任何黑色条纹。 

输入示例：```
5 0
```正确的输出是：```
0
```总是返回至少一个条纹的解决方案是错误的。 

另一个重要的情况是有黑色碎片但没有白色分隔符。 

输入示例：```
0 3
```唯一可能的塔是三个黑色棋子组合在一起，所以答案是：```
1
```如果不小心返回黑色棋子的数量，就会错误地输出 3。 

最后的边界情况是当有足够的白色棋子来分隔每个黑色棋子时。 

输入示例：```
10 3
```三个黑色棋子可以放置为`BWBWB`，其他地方还有剩余的白色碎片。 答案是：```
3
```仅考虑白色块数作为答案的解决方案将失败，因为条纹数不能超过黑色块数。 

## 方法

 蛮力方法是尝试不同的碎片顺序并计算所得的条纹。 这是正确的，因为考虑了每种可能的排列，但可能的塔的数量是巨大的。 对于 10^18 块，甚至代表塔都是不可能的，因此任何基于枚举或模拟的方法都行不通。 

有用的观察是，一个白色棋子最多可以在两组黑色棋子之间产生一个分隔。 如果我们有`a`白色的碎片，他们最多可以创造`a + 1`黑色条纹可能出现的地方：第一个白色棋子之前、白色棋子之间以及最后一个白色棋子之后。 

同时，每条条纹必须包含至少一个黑色棋子。 和`b`黑色的碎片，我们不能创造更多`b`条纹。 

最大条带数是这两个限制中较小的一个：`min(number of black pieces, number of possible gaps created by whites)`最佳的排列方式只是将黑色棋子放入尽可能多的可用间隙中，并使用白色棋子作为分隔符。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(排列数) | O(件数) | 太慢了|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取白棋子和黑棋子的数量。 
2. 如果没有黑子，则输出`0`，因为一条条纹必须至少包含一个黑色块。 
3. 计算黑色条纹的可用位置数。 和`a`白色的碎片，有`a + 1`塔内可能存在分离的区域。 
4. 答案是黑块数量与可用区域数量之间较小的值。 

这样做的原因是每个条纹至少消耗一个黑色块，而条纹之间的每个分隔都需要一个白色块。 通过在每个选定区域中放置一个黑色块，该结构始终可以实现此限制。 

为什么它有效：

 假设一个安排有`x`黑色条纹。 由于每条条纹至少包含一个黑色块，`x`不能大于黑色棋子的总数。 另外，每对连续条纹之间必须至少有一个白色块，所以`x`条纹至少需要`x - 1`白色分隔符。 这意味着条纹数量不能超过`a + 1`。 由于这两个限制都是必要的，因此答案不能超过`min(b, a + 1)`。 通过将一个黑色棋子放入每个可用区域，直到黑色棋子或区域用完，我们总是可以准确地获得那么多条纹。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b = map(int, input().split())

    if b == 0:
        print(0)
    else:
        print(min(b, a + 1))

if __name__ == "__main__":
    solve()
```该解决方案直接读取两个计数，并且从不尝试建造塔。 这是必要的，因为这些值对于迭代来说可能太大。 

的特殊处理`b == 0`在 Python 中并不严格要求，因为`min(0, a + 1)`也会产生零，但保留条件会使推理变得明确。 表达式`a + 1`是安全的，因为 Python 整数具有任意精度。

 ## 边缘情况

 对于没有黑色棋子的情况：```
0 0
```该算法看到`b == 0`并立即返回零。 不可能有黑色条纹，因为塔中没有黑色棋子。 

对于没有白色碎片的情况：```
0 3
```可用区域的数量为`0 + 1 = 1`。 公式变为`min(3, 1)`, 给予`1`。 所有黑色棋子必须保持连接，因为没有白色分隔符。 

对于白块较多的情况：```
10 3
```有`10 + 1 = 11`可能的区域，但只有三个黑色棋子。 答案是`min(3, 11) = 3`。 每个黑色块可以占据不同的区域，形成三个独立的条纹。 

对于黑块较多但分隔符有限的情况：```
2 10
```只有`2 + 1 = 3`可能的区域。 即使存在十个黑色棋子，它们最多只能形成三个条纹，因此输出为：```
3
```该算法通过应用两个限制而不是仅考虑一侧来处理此问题。
