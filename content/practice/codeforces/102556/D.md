 ## 解决方案
 ## 问题理解

 让选定的百分比`i`- 第一个人是`P_i`，写成之间的分数`0`和`1`。 

当人`i`转弯时，会发生两件事。 他们采取`P_i`未动过的馅饼，然后他们也采取`P_i`以前的人已经拥有的每一片。 每个人都玩完后，饼中未触及的部分必须为零，并且我们希望最终的切片大小尽可能相等。 

输入仅包含人数。 输出是每个人按顺序选择的百分比。 

唯一的限制是`N ≤ 1000`，所以即使是`O(N^2)`模拟很容易适合。 挑战不在于效率，而在于发现过程的数学结构。 

第一个不明显的边缘情况是`N = 1`。 唯一有效的答案是`100%`，因为否则有些馅饼还没吃完。 

第二个微妙的情况是让最后一个人选择`100%`不是必需的。 例如，与`N = 2`，选择`100%, 50%`没有留下未触及的馅饼，因为第一个玩家已经吃掉了所有馅饼。 总是迫使最后一个玩家拿走一切的贪婪策略会错过最佳分配。 

最后一个陷阱是混淆了玩家选择的百分比和他们最终拥有的百分比。 后来的玩家不断地从前面的玩家那里偷东西，所以选择的百分比和最终的份额是不同的数量。 

## 方法

 直接模拟会保留每个玩家当前的份额。 每当新玩家到来时，之前的每个切片都会乘以`(1 - P_i)`，新玩家收到从这些切片中删除的所有内容加上`P_i`未触及的饼图，并且未触及的饼图也乘以`(1 - P_i)`。 这忠实地模拟了游戏，但它没有告诉我们如何选择百分比。 

关键的观察结果是，玩家从未触及的馅饼和偷窃中获得的收益总和是相同的值。 

假设 person 之前未触及的分数`i`是`R`。 之前玩家已拥有的总金额为`1 - R`。 新玩家收到`P_i · R + P_i · (1 - R) = P_i`。 

因此，在自己的回合结束后，玩家立即`i`总是完全拥有`P_i`原来的馅饼。 

之后，每个后来的玩家只需按比例缩放该切片`(1 - P_j)`。 因此最终的份额是$$F_i=P_i\prod_{j=i+1}^{N}(1-P_j).$$现在定义$$S_i=\prod_{j=i}^{N}(1-P_j),$$person 之前未触及的部分`i`。 

然后$$F_i=S_{i+1}-S_i.$$剩下的馅饼是`S_1`，并且要求没有剩菜意味着`S_1=0`。 还`S_{N+1}=1`。 

由于最终股份总数为`1`，当每个最终份额恰好是时，就实现了最大份额和最小份额之间的最小可能差异`1/N`。 

设置每个`F_i=1/N`给出$$S_i=\frac{i-1}{N}.$$恢复百分比，$$P_i=\frac{S_{i+1}-S_i}{S_{i+1}}.$$为了`i=1`,$$P_1=1.$$对于每一个`i≥2`,$$P_i=\frac{1/N}{i/N}=\frac1i.$$所以答案非常简单。

 ## 算法演练

 1. 阅读`N`。 
2. 打印`100.0`对于第一人称。 这保证了未触及的馅饼立即变为零，满足无剩菜条件。 
3. 对于每个人`i`从`2`到`N`， 打印`100 / i`。 这正是根据推导公式得到的值`P_i = 1/i`。 

推导保证了每个玩家的最终份额恰好变成`1/N`，这是最好的，因为所有股份的总和为一。 

### 为什么它有效

 The invariant is that player`i`完全拥有`P_i`完成自己的回合后立即。 之后的每个回合都会将每个现有切片简单地乘以相同的因子。 这给出了公式$$F_i=P_i\prod_{j>i}(1-P_j).$$将后缀积写为`S_i`将表达式转换为$$F_i=S_{i+1}-S_i.$$平等的最终份额唯一地决定了每个`S_i`，而这些后缀产品唯一地确定了每个百分比。 由于相等的份额使最大值和最小值相同，因此不存在更好的分配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    print(f"{100.0:.10f}")
    for i in range(2, n + 1):
        print(f"{100.0 / i:.10f}")

if __name__ == "__main__":
    solve()
```程序直接打印封闭式答案。 第一个值始终是`100%`。 每个后来的值都是简单的`100/i`。 不需要模拟，因为数学推导已经表征了唯一的最佳解决方案。 

浮点精度在这里就足够了。 所需的误差为`1e-4`，同时打印十位小数使累积误差小许多数量级。

## 测试用例```python
import io
import sys

def solve():
    input = sys.stdin.readline
    n = int(input())
    print(f"{100.0:.10f}")
    for i in range(2, n + 1):
        print(f"{100.0 / i:.10f}")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    solve()
    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return out.getvalue()

assert run("1\n") == "100.0000000000\n"

assert run("2\n") == (
    "100.0000000000\n"
    "50.0000000000\n"
)

assert run("3\n") == (
    "100.0000000000\n"
    "50.0000000000\n"
    "33.3333333333\n"
)

out = run("1000\n").splitlines()
assert len(out) == 1000
assert abs(float(out[-1]) - 0.1) < 1e-9

 ## 边缘情况

 当`N = 1`，该算法仅打印`100`。 未触及的馅饼立即变为零，唯一的玩家拥有整个馅饼。 两个要求都满足。 

什么时候`N = 2`，算法打印`100`和`50`。 第一个玩家最初拥有整个馅饼。 第二个玩家偷走了一半，让两个玩家都得到了`50%`。 这表明第一个玩家，而不是最后一个玩家，是必须选择的人`100%`。 

对于较大的值，例如`N = 3`，算法打印`100`,`50`， 和`33.333...`。 最终得出的份额完全正确`1/3`，确认该结构使每个玩家的最终所有权均等，同时仍然不留下任何未触及的馅饼。
