[CF 102556F - Riana 和 Fiber 聊天室](https://codeforces.com/problemset/problem/102556/F)

 **标签：** -
 **求解时间：** 1m 3s

 ## 解决方案
 ## 问题理解

 每个用户都可以用他们的出生年份来表示，因为所有同一年份出生的用户自动具有相同的年龄。 唯一的额外连接来自于“快年”生日，即 1 月 1 日到 2 月 28 日之间的日期。快年用户出生年份`y`连接年`y`与年份`y-1`。 

这些连接的传递闭包定义了最终的年龄组。 Riana 希望在添加尽可能少的新用户后，每个现有用户和她自己都属于一个年龄段。 

输入包含现有用户和 Riana 的注册生日。 输出询问创建连接的年龄组的额外生日的最小数量，后跟要添加的任何有效生日。 

高达`100000`用户，检查每一对人是不可能的。 二次解的性能约为`10^10`比较，远远超出了极限。 有用的结构是岁月形成一条线，因此问题就变成了连接路径上缺失的边缘。 

一个常见的错误是比较确切的生日。 规则仅取决于年级和快年级​​联系。 另一个错误是忘记了瑞安娜本人。 即使她不属于现有的聊天成员，也必须包括她的年份。 

## 方法

 直接方法是在所有用户之间构建一个图，每当两个用户被认为是相同年龄时添加一条边，然后重复添加用户直到图连接起来。 这是正确的，因为年龄的定义正是这些规则下的连通性。 然而，比较所有对的成本太高，并且图表可以包含`100001`顶点。 

关键的观察结果是每个用户年份都是数轴上的一个节点。 一年中的快年生日`y`仅创建之间的边缘`y`和`y-1`。 我们只需要知道哪些相邻年份的边已经存在。 

如果最小和最大相关年份是`L`和`R`，之间的每个缺失边`y-1`和`y`必须在这个区间内创建。 在年份中添加快年用户`y`正是创建该边缘的操作。 由于每个添加的用户只能创建一个相邻年份的连接，因此每个缺失的边都是不可避免的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N²) | O(N²) | 太慢了|
 | 最佳| O(N + 年份范围) | O(N) | 已接受 |

 ## 算法演练

 1. 解析 Riana 的生日和每个现有的生日。 存储出现的年份并标记每年至少包含一个快年生日。 
2. 将 Riana 的出生年份纳入相关年份。 最后的年龄组也必须包含她。 
3. 找出最小和最大相关年份。 所需的每一次联系都存在于这两年之间。 
4. 每年`y`从`min_year + 1`到`max_year`,检查是否已经存在某年出生的快年用户`y`。 如果没有，则添加当年 1 月 1 日出生的新用户`y`。 
5.输出所有添加的生日。 

为什么有效：年龄图是多年来的路径。 唯一可能的边缘是连续年份之间。 现有的快年用户提供了其中一些优势。 任何缺失的边都会将路径分成两个不相连的部分，因此必须由至少一个新用户添加它。 该算法为每个缺失的边缘添加一个用户，这既是充分的也是必要的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def parse_date(s):
    y, m, d = map(int, s.split("-"))
    return y, m, d

def format_date(y, m=1, d=1):
    if y < 10000:
        return f"{y:04d}-{m:02d}-{d:02d}"
    return f"{y:05d}-{m:02d}-{d:02d}"

def solve():
    n = int(input())
    ry, rm, rd = parse_date(input().strip())

    years = {ry}
    fast = set()

    for _ in range(n):
        y, m, d = parse_date(input().strip())
        years.add(y)
        if m == 1 or (m == 2 and d <= 28):
            fast.add(y)

    lo = min(years)
    hi = max(years)

    ans = []
    for y in range(lo + 1, hi + 1):
        if y not in fast:
            ans.append(format_date(y))

    print(len(ans))
    for x in ans:
        print(x)

if __name__ == "__main__":
    solve()
```解析器忽略年份的确切格式宽度，因为按`-`直接给出数字年份。 仅检查 1 月和 2 月 28 日或更早时间的快速年条件。 

循环开始于`lo + 1`因为当年的快年用户`y`连接`y`到`y - 1`。 开始于`lo`会在所需的时间间隔之外创建不必要的连接。 使用 1 月 1 日很方便，因为它始终是有效的快速年份日期。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N + Y) |`N`生日被读取并且`Y`是最小年份和最大年份之间的距离 |
 | 空间| O(N) | 这些集合存储相关年份和现有的快速年份连接 |

 年份范围最多为`99999 - 1000`，所以线性扫描很小。 该解决方案很容易满足约束条件。
