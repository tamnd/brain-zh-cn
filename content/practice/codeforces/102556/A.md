 ## 解决方案
 ## 问题理解

 输入是城市周围的一排圆形位置。 当一个位置被标记为 时，该位置包含一个敌人`X`当它被标记为空时`.`。 一拳可以击败属于同一连续敌人链的每一个敌人。 空位置会破坏该链，因此目标是将尽可能少的空位置变成敌人，直到所有敌人都属于一个循环链。 

输出是最小数量`.`必须成为的职位`X`职位。 圆形连接很重要，因为最后一个位置与第一个位置相邻。 一群敌人可以继续穿过此边界，因此将字符串视为正常线会给出错误的结果。 

长度最多为 100 个字符。 它足够小，可以轻松运行许多线性或二次解，但它也足够大，无需尝试所有可能的填充位置集。 对所有空位置进行暴力破解需要最多$2^{100}$最坏情况下的可能性，远远超出一秒的极限所能处理的范围。 有用的结构是位置形成一个圆圈，因此问题可以简化为寻找现有敌人之间间隙的属性。 

一些边缘情况可能会破坏直接实现。 如果所有位置都已经是敌人，则答案为零，因为链条已经完整。 

对于输入：```
XXXXX
```正确的输出是：```
0
```仅搜索点间隙的方法可能会错误地假设始终存在需要填充的间隙。 

如果只有一个敌人，它本身就已经形成了一个相连的群体。 

对于输入：```
.....
```正确的输出是：```
0
```没有需要连接的敌人。 假设至少存在一个敌人的粗心解决方案可能会在搜索第一个敌人时失败`X`。 

另一个重要的情况是当连接穿过字符串的末尾时。 

对于输入：```
XX..XX
```正确的输出是：```
0
```首尾两组实际上在圆上是相邻的，所以它们已经是一条相连的链条了。 忽略圆形边缘的线性扫描会错误地将中间间隙视为必须填充的东西。 

## 方法

 一种直接的方法是考虑填充空位置的某个子集，并检查生成的圆圈是否只有一个敌人组成部分。 对于每个可能的点子集，我们可以模拟圆圈并计算相连的敌人群体的数量。 这是正确的，因为它探索了每种可能的最终排列，但子集的数量呈指数增长。 有 100 个头寸，最坏的情况包含 100 个空头寸，给出$2^{100}$可能性，这是不可能处理的。 

关键的观察来自于观察空旷的空间而不是敌人。 现有的敌人被圆形的点状间隙隔开。 如果我们完全填满一个点间隙，双方的敌人就会通过这个间隙连接起来。 为了使整个圆圈成为一个相连的敌人群，必须消除除可能的一个点之外的所有点间隙。 

为什么还能留一分差距呢？ 想象一下留下一个连续的空段。 所有其他间隙都被填满，因此绕圈穿过填充的间隙会到达每个敌人。 剩余的空段只是成为同一连接的敌人链的末尾和开头之间未使用的中断。 

由于保留间隙可以避免我们填充其点，因此我们应该保留最大的点间隙并填充所有其他点。 答案是总点数减去敌方群体之间最大圆形间隙的长度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n \times n)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 统计圈内敌人的数量。 如果没有敌人，答案为零，因为没有任何东西可以连接。 
2. 找到每个连续的空位置序列。 因为字符串是循环的，所以第一个和最后一个位置可能属于同一个空序列，所以扫描时必须小心处理边界。 
3. 记录最大空序列的长度。 这是唯一可以保持空的间隙，因为它代表最终循环链的断裂。 
4. 统计空位置的总数。 最大缺口之外的每一个空位都必须变成敌人。 
5. 返回空位置总数减去最大间隙长度。 

最大的缺口是最好保持不变的原因是，所有其他缺口都必须消失才能连接敌方群体。 保持较小的差距将迫使我们填补不必要的职位。 

为什么它有效：

 考虑一下圆圈周围现有的敌人群体。 每个空间隙将两个相邻组分开。 如果两个或多个间隙仍为空，则该圆圈包含多个不相连的敌方部分。 因此最多可以保留一个间隙。 选择最大间隙可以最大限度地减少填充位置的数量，因为它可以避免填充最大数量的点。 该算法检查所有间隙并准确选择最佳间隙，因此返回值最小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)

    if 'X' not in s:
        print(0)
        return

    total_dots = s.count('.')

    doubled = s + s
    first_x = doubled.find('X')

    max_gap = 0
    current = 0

    for i in range(first_x, first_x + n):
        if doubled[i] == '.':
            current += 1
            max_gap = max(max_gap, current)
        else:
            current = 0

    if max_gap > total_dots:
        max_gap = total_dots

    print(total_dots - max_gap)

solve()
```该解决方案首先处理空圈情况，因为没有敌人组可以连接。 之后，至少有一个`X`存在，因此我们通过在敌人位置开始扫描来旋转圆的视图。 这消除了点序列穿过输入字符串末尾的歧义。 

双倍字符串无需使用模块化索引即可访问循环邻居。 我们只精确扫描`n`位置在第一个敌人之后，因此从末尾到开头的点序列被视为一个连续间隙。 

变量`current`存储当前空段的长度。 每当敌人出现时，该片段就结束并`max_gap`已经包含了迄今为止所见的最佳差距。 由于最大可能的间隙不能超过点数的总数，因此最终的答案只是不包含在该保存的间隙中的点数。 

Python 中不存在整数溢出问题，因为输入长度只有 100。主要边界条件是正确选择起点。 从任意位置开始，可以将圆形点间隙分割成两个较小的部分。

## 测试用例```python
import sys
import io

def solution(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    s = sys.stdin.readline().strip()
    n = len(s)

    if 'X' not in s:
        ans = 0
    else:
        total_dots = s.count('.')
        doubled = s + s
        start = doubled.find('X')

        best = 0
        cur = 0
        for i in range(start, start + n):
            if doubled[i] == '.':
                cur += 1
                best = max(best, cur)
            else:
                cur = 0

        ans = total_dots - min(best, total_dots)

    sys.stdin = old_stdin
    return str(ans)

assert solution("XX..XX.X....") == "4", "sample 1"
assert solution("X..XX.X..X") == "3", "sample 2"

assert solution("X") == "0", "single enemy"
assert solution(".....") == "0", "no enemies"
assert solution("XXXXX") == "0", "already connected"
assert solution("XX..XX") == "0", "circular connection"
assert solution("X.X.X") == "2", "alternating enemies"

 ## 边缘情况

 对于`XXXXX`，算法发现点的总数为零。 最大差距也为零，因此答案仍然为零。 敌方之间没有空位。 

为了`.....`，第一个条件触发，因为不存在敌人。 该算法立即返回零，而不是搜索起始敌人位置。 这避免了无效的索引，并且符合不需要连接敌人的想法。 

为了`XX..XX`，线性方法可能会看到两组被两个点分开。 相反，该算法从敌人开始扫描整个圆圈，正确地将结束和开始视为相邻。 唯一的间隙长度为 2，但保持该间隙仍然会使所有敌人通过圆的另一侧连接起来，因此答案为零。 

对于这样的情况`X.X.X`，间隙的长度均为一。 该算法只能保存这些间隙之一，因此必须填充三个点中的两个。 计算值是`3 - 1 = 2`，它与所需的最小更改数量相匹配。
