 ## 解决方案
 ## 问题理解

 我们得到一个与坐标轴对齐的矩形屋顶，宽度$w$和身高$h$。 屋顶位于从$(0,0)$。 我们还有固定尺寸的相同矩形瓷砖$a \times b$。 这些瓷砖不允许旋转，因此它们的方向是固定的。 

任务不是从头开始找到任何瓷砖。 相反，两块瓷砖已经放置在平面上的某处。 它们可以延伸到屋顶之外，但是它们中的每一个都与屋顶的至少一部分重叠，并且它们彼此不重叠。 这两块瓷砖必须保持在原来的位置。 

我们必须决定是否仍然可以使用相同的副本覆盖整个屋顶区域$a \times b$瓷砖，无需移动现有的两个瓷砖，也不重叠任何瓷砖，同时允许瓷砖延伸到屋顶边界之外。 

关键的困难在于平铺在结构上是全局刚性的：由于平铺不能旋转并且全部相同，因此任何有效的平铺都必须与宽度网格对齐$a$和身高$b$。 两个预先放置的图块限制了仍然可能的网格对齐（如果有）。 

输入大小最多允许$10^4$测试用例，坐标和尺寸可达$10^9$。 这排除了任何模拟或暴力放置。 每个测试都必须依靠模算术和结构观察在恒定时间内解决。 

一个天真的错误是假设我们可以通过稍微移动瓷砖来局部“修复”放置。 这是不可能的，因为一旦存在平铺，它就会迫使所有平铺位置遵循严格的周期晶格。 另一个微妙的问题是认为只有一个坐标方向很重要。 实际上，x 和 y 对齐必须同时一致。 

朴素推理的一个具体失败场景是两个放置的图块具有不同的 x 坐标模数$a$。 例如，如果一个图块开始于$x=0$另一个在$x=1$和$a=2$，人们可能会认为我们仍然可以填补空白，但这是不可能的，因为没有一个全球网格可以同时通过两者。 

## 方法

 如果我们忽略瓷砖的结构，我们可能会尝试模拟放置：选择一个起始瓷砖位置并尝试水平和垂直延伸网格，同时确保两个固定瓷砖都位于其上。 这很快就变得不可行，因为网格在放置选择上是不受限制的，并且通过强力移动来检查一致性将需要迭代两个轴上的所有可能的偏移，这在约束下是不可能的。 

关键的观察是，通过固定的平面的任何有效平铺$a \times b$矩形对应于选择单个偏移量$(x_0, y_0)$，然后在所有位置放置瓷砖$(x_0 + ka, y_0 + lb)$。 这意味着每个图块的左下角必须满足：$$x \equiv x_0 \pmod a, \quad y \equiv y_0 \pmod b$$现在考虑两个预先放置的图块。 它们中的每一个都对这种全球抵消施加了限制。 如果两个图块属于同一个图块，则它们的 x 坐标必须模一致$a$，并且它们的 y 坐标必须模全等$b$。 

然而，还有一个额外的微妙之处：即使它们是全等的模$a$和$b$，它们不得与如何将矩形的完全覆盖扩展到屋顶边界产生矛盾。 屋顶本身并不限制瓦片，但两个固定瓦片仍然是同一无限网格的一部分的要求却会限制瓦片的使用。 

因此问题简化为检查两个图块是否可以属于一个公共图块$a \times b$晶格排列。 如果不是，答案立即是否定的。 如果是，那么我们还必须确保垂直或水平网格线划分屋顶的方式不会出现强制不匹配。 这导致沿着至少一个维度检查对齐一致性，其中瓦片可能“阻挡”屋顶的不同条带分解。 

更可操作的方式是：将平面划分为宽度垂直的条带$a$。 每个条带在 y 方向上独立平铺。 如果两个固定图块位于不同的垂直相位（即，它们的 x 坐标模$a$不同），然后它们强制不兼容的条带对齐。 同样的逻辑也适用于水平方向和高度$b$。 

因此，决策简化为检查 x 对齐或 y 对齐是否可以全局一致，而不会因第二个图块引起矛盾。

 |---|---|---|

 | 暴力网格搜索偏移量 |$O(ab)$每次测试 |$O(1)$| 太慢了 |

 | 最佳模块对准检查 |$O(1)$每次测试 |$O(1)$| 已接受 |

 ## 算法演练

 1. 通过检查是否计算 x 偏移兼容性$x_1 \equiv x_2 \pmod a$。 这决定了两个图块是否可以位于同一垂直图块网格上。 
2. 通过检查是否计算 y 偏移兼容性$y_1 \equiv y_2 \pmod b$。 这决定了两个图块是否可以位于同一水平图块网格上。 
3. 如果两个同余成立，则得出结论，存在一致的全局平铺对齐，因此输出“Yes”。 
4.否则，得出结论，没有单个周期性平铺可以同时包括两个固定平铺，因此输出“否”。 

我们只需要模块化比较的原因是任何完全平铺都相当于选择晶格原点。 两个图块要么在该格子上一致，要么强制形成两个不兼容的格子。 

### 为什么它有效

 相同的非旋转平面的有效平铺$a \times b$矩形在平面上产生唯一的等价关系，其中点相差整数倍$a$在 x 和$b$在 y。 每个图块左下角恰好属于一个由下式确定的等价类：$(x \bmod a, y \bmod b)$。 如果两个预先放置的图块位于不同的类中，则任何补全都无法协调它们，因为任何扩展都会在全局范围内保留相同的类结构。 如果它们属于同一类，则可以一致地扩展平铺，因为可以在每个对齐的条带中独立填充平面，而不会产生矛盾。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        w, h, a, b = map(int, input().split())
        x1, y1, x2, y2 = map(int, input().split())

        if (x1 - x2) % a == 0 and (y1 - y2) % b == 0:
            out.append("Yes")
        else:
            out.append("No")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```实现直接遵循模块化对齐思想。 唯一微妙的一点是正确处理负坐标，但 Python 的模运算符已经确保了在用作同余检查时获得一致的结果`(x1 - x2) % a == 0`。 

该解决方案在恒定时间内独立处理每个测试用例，读取输入并检查两个模块化条件。

 | 计算| (-1 - 5) % 2 = 0 | (-2 - 4) % 3 = 0 | 是的 |

 两个图块都在相同的晶格偏移上对齐，因此存在一致的图块。 

这证实了即使瓦片延伸到屋顶之外，它们的相对对齐仍然匹配有效的周期性网格。 

### 示例 2

 输入：```

```| 步骤| x 条件 | y 条件 | 结果 |
 | ---| ---| ---| ---|

这表明屋顶的局部覆盖是无关紧要的：矛盾纯粹来自于格子结构。

 ## 边缘情况

 一种边缘情况是坐标为负但仍代表有效的图块放置。 例如，一个图块位于$(-1,-1)$仍然必须在模运算下进行一致的处理。 支票`(x1 - x2) % a == 0`正确处理这个问题，因为它比较相对比对而不是绝对残基。 

当瓷砖远离屋顶边界时，会出现另一种边缘情况。 即使两个图块完全位于外部，它们仍然会限制全局图块。 例如，如果两个瓷砖都放置在$(10^9, 10^9)$和$(10^9 + a, 10^9)$，x 条件通过，但 y 条件可能失败或独立通过，并且决策仍然是纯模块化的。 

最后一种边缘情况是，一个图块与网格边界完全对齐，而另一个图块靠近边界但不在边界上。 即使坐标相差 1 也会破坏可行性，因为它会强制两个不兼容的晶格原点，并且任何部分调整都无法使它们协调一致。
