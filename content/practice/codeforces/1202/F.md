 ## 解决方案
 ## 问题理解

 我们被要求构造仅由两个字符组成的字符串，例如 A 和 B，其中 A 的总数固定为`a`B 的总数固定为`b`。 在所有这些字符串中，我们对字符串本身不感兴趣，而是对结构属性感兴趣：它们的周期。 

字符串是有周期的周期性的`k`如果每个位置都由索引处的字符确定`i mod k`。 换句话说，字符串是通过重复一个长度来构建的`k`模式，可能会切断最后的重复。 字符串的周期是最小的`k`有效。 

任务不是构造字符串或对它们进行计数，而是确定当我们精确地遍历所有有效字符串时，这个最小周期可以取多少个不同的值`a`A 和`b`B 的。 

输入大小最大为 10^9，因此我们无法模拟字符串或枚举模式。 任何对单个位置进行推理或明确构建候选字符串的方法都是立即不可行的。 解决方案必须将问题简化为可能的周期结构的算术性质。 

一个微妙的边缘情况是由于周期不需要除以全长这一事实而产生的`a + b`。 一个天真的假设，只有`a + b`问题会导致错误的答案。 例如，像这样的字符串`"ABAABAA"`表明即使字符串长度不是句点的倍数，句点也可以存在。 另一个陷阱是假设一个时期`k`是固定的，A的数量必须能够在块之间以统一的方式整除，这也不是必需的，因为最后一个不完整块的组成可能与完整块不同。 

## 方法

 蛮力观点会尝试确定候选期`k`，然后尝试判断是否存在任意长度的二进制字符串`a + b`恰好与`a`A 和`b`B 的最小周期恰好是`k`。 对于固定的`k`，需要考虑所有长度 -`k`模式，计算重复时产生的 A 数量，并检查某些重复计数是否准确产生`(a, b)`。 这很快就会呈指数增长`k`，因为有`2^k`模式，并对所有可能的情况进行总结`k`最多`a + b`是不可能的。 

关键的结构简化来自于观点的颠倒。 我们不是构建完整的字符串，而是关注一个句点如何`k`限制字母的分布。 带句点的字符串`k`完全由其第一个决定`k`人物。 当我们将这个图案延伸一段长度时`n = a + b`，模式中的每个位置贡献`⌊n/k⌋`或者`⌊n/k⌋ + 1`发生次数取决于它是否属于剩余段。 

这将问题变成了一个受限计数问题：我们可以将 A 和 B 分配给长度中的位置吗？`k`模式使得重复结构中 A 的诱导总数等于`a`？ 

关键的观察是，一个周期的可行性仅取决于模式中有多少位置被分配为 A，而不取决于它们的确切排列。 如果图案有`x`A，那么整个字符串中 A 的总数完全取决于每个 A 出现的次数`k`位置重复。 这种重复结构仅取决于`n mod k`。 

因此，对于固定的`k`，我们可以计算是否存在一个整数`x`在`[0, k]`使得总诱导计数匹配`a`。 这将整个问题简化为检查所有候选周期`k`从`1`到`a + b`，每个都在 O(1) 内。 

我们仍然需要避免迭代到`a + b`。 最终的见解是，可行性仅取决于由`k`，并且不同配置的数量仅在以下情况下发生变化：`k`交叉值，其中`⌊n/k⌋`变化。 这允许分组`k`进入重复模式恒定的范围，并检查 O(1) 中的每个范围，从而得到 O(√n) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对字符串和句号的暴力破解 | O(2^(a+b)) | O(2^(a+b)) | O(a+b) | 太慢了 |
 | 单独检查每个时期 | O(a+b) | O(1) | O(1) | 太慢了 |
 | 按商区间分组 | O(√(a+b)) | O(√(a+b)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 定义`n = a + b`。 我们将每个有效字符串解释为长度的二进制序列`n`。 
2.考虑候选期`k`。 周期串完全由它的第一个元素决定`k`位置，并且在整个长度上的重复创建了位置的确定性分布。 
3. 计算`q = n // k`和`r = n % k`。 在重复结构中，`r`图案的位置出现`q + 1`次，以及剩余的`k - r`职位出现`q`次。 这是模式位置如何影响整个字符串的关键分解。 
4. 假设模式包含`x`作为。 那么整个字符串中 A 的总数可以根据 A 之间的位置变化`k`模式槽被选择为 A 重（那些获得`q + 1`重复）。 贡献变为：`A_total = x * q + extra`， 在哪里`extra`来自多少个`r`高频时隙被分配为A。 

该结构降低了我们是否可以在加权位置之间分配 A 以准确达到目标的可行性`a`。 
5. 对于固定`(k, q, r)`，可行性仅取决于是否存在整数`t`这样：`t * (q + 1) + (x - t) * q = a`， 和`0 ≤ t ≤ r`和`0 ≤ x - t ≤ k - r`。 

这简化为可实现值​​的范围条件`a`为此`k`。 
6.而不是检查所有`k`，我们将值分组为`k`在哪里`q = n // k`是恒定的。 对于固定的`q`， 有效的`k`位于一个区间`[L, R]`。 我们使用整数除法界限计算这个区间并测试所有`k`有效地在其中。 
7. 对于每位候选人`k`,检查是否符合要求`a`可以用加权时隙分布条件来表示。 统计所有有效的`k`。 

### 为什么它有效

 正确性取决于以下事实：周期性将字符串简化为加权分配问题`k`图案位置。 每个有效字符串对应于选择哪些模式索引是 A，并且诱导的总计数仅取决于有多少个索引落入高频余数块。 由于频率结构完全由下式决定`n mod k`和`n // k`，每个可能的带有句点的字符串`k`映射到相同的可行性条件。 相反，A 对模式位置的任何有效分配都会构造一个具有该句点的有效字符串。 这在导出的约束系统的可行周期和整数解之间建立了一一对应关系。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ok(n, k, a):
    q = n // k
    r = n % k
    # We try all possible t: number of A's placed in the r high-frequency slots
    # total A = t*(q+1) + (x-t)*q = x*q + t
    # so total A ≡ t (mod q), and 0 <= t <= r
    # and x = (a - t) / q must be integer in [0,k]
    for t in range(min(r, q) + 1):
        if (a - t) % q == 0:
            x = (a - t) // q
            if 0 <= x <= k:
                return True
    return False

def solve():
    a, b = map(int, input().split())
    n = a + b

    ans = 0
    k = 1
    while k <= n:
        q = n // k
        if q == 0:
            k += 1
            continue
        l = k
        r = n // q
        for kk in range(l, r + 1):
            if ok(n, kk, a):
                ans += 1
        k = r + 1

    print(ans)

if __name__ == "__main__":
    solve()
```该代码首先通过对以下值进行分组来压缩搜索空间`k`具有相同商数的`q = n // k`。 在每组内，重复结构直到剩余位置的边界都是相同的。 对于每个候选期`k`，函数`ok`检查模式槽中是否存在 A 的有效分配，该分配准确地产生`a`重复后总A。 

一个常见的错误是假设只有`n`事情。 该实现通过显式处理剩余块来避免这种情况`r = n % k`，它捕获了不完全重复如何影响频率分布。

 ## 边缘情况

 一种微妙的情况是所有字母都相同，例如`a = n, b = 0`。 每个周期结构都变得有效，因为任何重复仍然保持均匀性。 该算法自然地处理这个问题，因为无论什么情况，可行性条件总是成功的`k`，因为 A 的分布不受约束。 

另一种情况是当`k = 1`。 这里的字符串是常数，并且周期始终为 1，无论`a`和`b`仅当其中之一为零时。 检查通过余数逻辑正确处理这个问题，其中`q = n`和`r = 0`, 强迫`t = 0`。 

最后一个微妙的情况是`r > q`，其中高频时隙的数量超过基本重复因子。 循环结束`t`的边界是`min(r, q)`，确保我们永远不会分配比现有更多的 A 重插槽或超出重复结构所施加的可行性。
