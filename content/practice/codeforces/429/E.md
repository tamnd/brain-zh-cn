 ## 解决方案
 ## 问题理解

 我们得到了数轴上的线段集合。 每个线段从左端点跨越到右端点，我们必须为每个线段分配两种颜色之一。 

选择颜色后，想象一下选择线上的任何点并查看覆盖该点的所有线段。 在这些活动片段中，有些是红色的，有些是蓝色的。 要求是，在每一点上，覆盖该点的红色和蓝色线段数量之差的绝对值不得超过 1。 

该条件是局部的，因为它必须适用于每个实际坐标，但线段本身仅更改其端点处的活动集。 所以问题的真正结构是关于间隔如何重叠以及我们如何在重叠处一致地分配颜色。 

输入大小达到十万个段，因此任何比较所有段对或重新计算每个点的重叠信息的方法都太慢了。 任何与段数成二次方的操作都将进行 10^10 次运算，并且不会在时限内通过。 仅当每个操作都是轻量级时，即使 O(n log n) 也是可接受的，因为我们必须在所有段上维护动态结构。 

微妙的边缘情况来自密集的重叠。 如果许多线段共享一个大的公共交叉点，则所有线段都会在某个时刻同时处于活动状态。 在这样的区域中，着色约束变得最强，因为活动颜色的多重集必须在每个时刻保持平衡。 

举个例子，如果我们有段 [0, 10]、[1, 9]、[2, 8]，全部都严重重叠，那么只查看端点而不跟踪全局重叠结构的天真贪婪很容易产生五个红色和一个蓝色重叠的时刻，即使早期的决策看起来局部良好，也会违反约束。 

另一个特殊情况是嵌套，例如 [0, 10]、[1, 9]、[2, 8]、...，其中严格包含间隔。 这里重叠集逐渐变化，但在很长一段时间内仍然很大，这对任何假设仅成对相互作用很重要的算法产生了压力。 

## 方法

 思考这个问题的一个直接方法是尝试所有可能的颜色分配。 有 2ⁿ 的可能性，对于每个分配，我们都会扫描数轴，跟踪活动段并验证所有关键点的平衡条件。 每次检查都需要对端点进行排序或扫描线路，成本为 O(n log n)，因此完整的暴力破解变为 O(2ⁿ·n log n)，这远远超出了可行的范围。 

即使我们修复了颜色，仅检查有效性也可以通过扫描线进行管理：我们对所有线段端点进行排序，模拟进入和离开线段，并维护红色和蓝色的当前计数。 失败点不是验证，而是对作业的搜索。 

关键的结构观察是约束仅与任何时刻的活动段集有关。 在任何固定的 x 处，所有包含 x 的线段在区间重叠图中形成一个团。 要求规定，在每个此类集团内，色差必须保持在 1 以内。 这表明我们不是在处理任意的图形着色，而是在处理一种结构，其中间隔通过其端点强加全序。 

利用此功能的一种有用方法是按左端点升序处理段，同时维护所有当前活动的段按其右端点排序。 这个顺序不是任意的：在同时活动的间隔中，按右端点排序给出了一致的结构，当我们从左向右扫描时，该结构会平滑地演变。

关键的想法是在这个有序的活动集中保持交替的着色。 当新的区间进入时，我们根据其右端点将其放置在结构中，并根据此顺序中的邻居为其分配颜色。 由于区间图中的重叠行为类似于此排序结构中的连续块，因此在本地保留交替足以确保全局平衡条件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2ⁿ·n log n) | O(2ⁿ·n log n) | O(n) | 太慢了|
 | 扫一扫+有序活动集| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 按左端点对所有线段进行排序。 我们按照它们激活的顺序对其进行处理，因此我们永远不会错过某个片段开始与其他片段重叠的时刻。 
2. 维护当前活动段的平衡有序结构，按其右端点排序。 该结构表示当前扫描位置的“实时”间隔。 
3. 按左端点升序扫描线段。 当段变为活动状态时，将其按其右端点位置插入到有序结构中。 
4. 插入后，根据有序结构中的前任分配其颜色。 如果顺序中紧接其前面有一个段，则指定相反的颜色。 如果没有前任，则指定任意颜色，例如红色。 
5. 有序结构隐含地形成了颜色必须交替的间隔序列。 插入规则在本地保留这种交替，因为每个新间隔仅取决于其直接邻居。 
6.全部插入后，着色就完全确定了。 

### 为什么它有效

 不变的是，在任何时候，如果我们查看按右端点排序的活动段，它们的颜色就会沿着该顺序交替。 任何点 x 都位于一组活动区间中，这些区间在此排序中形成一个连续的块，因为在覆盖 x 的区间中，没有一个点可以在不违反区间排序属性的情况下“跳过”另一个区间。 在交替序列的任何连续块内，两种颜色的计数之差最多为 1。 这直接意味着对于每个 x，所需的平衡条件成立。 

按右端点排序使结构在插入时保持稳定。 新的间隔仅影响该顺序中的直接邻居，因此可以维持交替而无需全局重新计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    segs = []
    for i in range(n):
        l, r = map(int, input().split())
        segs.append((l, r, i))
    
    segs.sort(key=lambda x: x[0])

    import bisect

    # active list sorted by r: store (r, id)
    active = []
    color = [-1] * n

    for l, r, i in segs:
        pos = bisect.bisect_left(active, (r, i))
        
        # predecessor determines color
        if pos == 0:
            c = 0
        else:
            prev_id = active[pos - 1][1]
            c = 1 - color[prev_id]
        
        color[i] = c
        active.insert(pos, (r, i))

    print(" ".join(map(str, color)))

if __name__ == "__main__":
    solve()
```代码首先按段的左端点对段进行排序，以便我们仅在它们变为活动状态时插入间隔。 这`active`列表始终按右端点排序，这模拟了算法中描述的排序结构。 

对于每个新间隔，我们使用二分搜索来定位其在此排序中的位置。 颜色由紧邻其左侧的间隔决定：我们翻转其颜色以保持交替。 如果不存在前驱，则该间隔将开始一个新的交替序列。 

关键的微妙之处在于我们从不重新计算早期片段的颜色。 该结构保证颜色一旦分配就保持有效，因为后来的插入仅在本地扩展交替序列。 

## 工作示例

 ### 示例 1

 输入：```
2
0 2
2 3
```我们按照左端点的顺序处理段。 两个间隔均按顺序插入。 

| 步骤| 活跃（由 r）| 当前的着色决定|
 | --- | --- | --- |
 | 插入 [0,2] | [0,2]| 无前任，颜色 0 |
 | 插入 [2,3] | [0,2], [2,3] | 前任为红色，分配为蓝色|

 输出变为：```
0 1
```这显示了一个简单的情况，其中间隔接触但不产生深度重叠。 交替规则直接产生有效的分配。 

### 示例 2

 输入：```
3
1 5
2 6
3 7
```| 步骤| 活跃（由 r）| 着色|
 | --- | --- | --- |
 | [1,5]| [1,5]| 0 |
 | [2,6]| [1,5],[2,6] | 1 |
 | [3,7]| [1,5],[2,6],[3,7] | 0 |

 活动集形成一条不断增长的链，其中颜色交替。 在 [3,5] 内的任何点，所有三个段都处于活动状态，并且计数为 2 个红色和 1 个蓝色，满足约束。 

这表明即使有最大的重叠，交替结构也能保证平衡。

 ## 边缘情况

 由于活动结构中没有前身，因此通过为其分配默认颜色来处理最小单个段。 该算法初始化一个新的交替序列，因此结果是非常有效的。 

对于像 [0, 10]、[1, 9]、[2, 8] 这样的嵌套区间，每个插入都位于按右端点排序的前一个插入区间内。 每个新片段都会选择与其前一个片段相反的颜色，从而产生稳定的交替链。 在最深的重叠点，颜色最多相差一，因为结构是完美交替的。 

对于不相交的线段，例如 [0,1]、[2,3]、[4,5]，每次插入都会看到一个空的前导线段，因此所有线段都会收到相同的颜色。 由于没有一点被多个线段覆盖，因此该条件立即成立。 

对于严格增加的右端点，活动排序变成一个简单的增长链，每个新段相对于前一个段翻转颜色，在扫描的每个前缀处保持平衡。
