 ## 解决方案
 ## 问题理解

 我们被要求分析在一排编号从 1 到 1 的睡莲叶上进行的两人游戏。$n$。 爱丽丝从睡莲开始$a$和鲍勃在睡莲叶上$b$，他们轮流向左或向右跳一步。 如果青蛙不能跳到有效的、未被占据的睡莲叶上，那么它就输了。 爱丽丝先行动，问题是如果双方都发挥最佳，她能否保证获胜。 

输入由多个测试用例组成。 每个测试用例给出$n$、睡莲叶的数量以及起始位置$a$和$b$。 如果 Alice 总是能赢，则输出为“YES”，否则输出为“NO”。 

因为$n$最多 100，任何每个位置执行少量操作的算法都是可行的。 下限表明，即使按顺序考虑位置也是可以接受的。 当青蛙开始靠近边缘（位置 1 或$n$）或者当青蛙相邻时。 例如，如果爱丽丝在 1 处而鲍勃在 2 处，则爱丽丝无法向左移动，并且向右移动会落在鲍勃旁边，从而可能会造成亏损。 如果爱丽丝无法跳到任何地方，她就会立即失败。 

一种简单的方法可能会尝试递归地模拟所有可能的跳转序列。 这可能适用于小型$n$，但这是不必要的，因为游戏是对称的，并且可以从到边缘的距离导出最佳移动。 

## 方法

 蛮力方法是递归地模拟游戏：对于每个青蛙的回合，尝试每个有效的动作，然后递归到下一个回合。 对于由 Alice 和 Bob 的位置定义的每个游戏状态，我们检查当前玩家是否有导致获胜的动作。 这是正确的，因为它探索了每个法律序列，但状态的数量是$O(n^2)$（每对位置）并且每个递归最多分支为 2 个移动。 这可能会导致每个测试用例有数百次递归调用，对于 500 个测试用例来说就显得有些过分了。 

关键的见解是，游戏归结为爱丽丝是否可以首先将鲍勃推到边缘。 如果距 Alice 最近的边缘的睡莲数量小于距 Bob 的数量，则她可以更快地到达边缘并迫使 Bob 进入不需移动的位置。 正式来说，如果 Alice 的位置到该行最近端的最小距离严格小于 Bob 到最近端的最小距离，则 Alice 可以获胜。 如果两个距离相等，鲍勃就可以模仿爱丽丝的动作并获胜。

 | --- | --- | --- | --- |
 | 蛮力 | O(2^(n^2)) | O(2^(n^2)) | O(n^2) | O(n^2) | 太慢了|
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算 Alice 到最近边缘的距离：$\text{dA} = \min(a-1, n-a)$。 这代表爱丽丝能够以多快的速度到达鲍勃无法阻挡她的睡莲叶。 
2. 计算 Bob 到最近边缘的距离：$\text{dB} = \min(b-1, n-b)$。 这是鲍勃的类比距离。 
3. 比较两个距离。 如果$\text{dA} < \text{dB}$，爱丽丝可以先到达边缘并保证获胜。 打印“是”。 
4. 否则，Alice 不能保证获胜，因为 Bob 可以先到达边缘，也可以模仿她的动作来阻挡她。 打印“否”。 

不变量是靠近边缘的玩家拥有游戏的控制权。 通过始终向边缘移动，爱丽丝可以减少鲍勃的选择，直到他被困住。 如果她不比鲍勃更接近边缘，则没有其他移动序列可以改善她的位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, a, b = map(int, input().split())
    # compute distance to nearest edge
    dA = min(a - 1, n - a)
    dB = min(b - 1, n - b)
    if dA < dB:
        print("YES")
    else:
        print("NO")
```我们首先读取测试用例的数量。 对于每个测试用例，我们读取睡莲数量和青蛙位置。 直接计算并比较到边缘的距离。 边界条件得到正确处理，因为`min(a-1, n-a)`始终产生一个非负整数，表示到最近端的步数。 自从$a \neq b$并且两者都在范围内，不需要额外的检查。

 ## 边缘情况

 如果在 2-lilypad 游戏中，爱丽丝从位置 1 开始，鲍勃从位置 2 开始，则爱丽丝不能向左跳跃并向右移动到与鲍勃相邻的土地。 该算法计算`dA = min(1-1, 2-1) = 0`和`dB = min(2-1, 2-2) = 0`。 自从`dA < dB`为 false，则输出为 NO，这正确地识别出 Alice 立即输了。 类似地，如果 Alice 和 Bob 从中间开始，到各自边缘的距离相等，则算法输出“否”，捕获对称镜像场景。 距离比较完全处理边缘邻接、中间位置和最小板尺寸，无需额外的分支逻辑。
