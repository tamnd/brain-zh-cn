 ## 解决方案
 ## 问题理解

 我们得到了几个测试用例。 在每一个中，我们都从一组$n$材料类型。 各类型$i$有初始金额$a_i$，我们希望至少达到$b_i$每种类型的单位。 

有一个操作将所有资源紧密耦合在一起。 如果我们选择一种材料$i$，我们增加$a_i$减少 1，但其他所有材料都会损失 1 个单位。 因此，该操作以牺牲所有其他坐标为代价将资源转移到一个坐标，并且仅当没有其他材料降至零以下时才有效。 

任务是确定我们是否可以执行此类操作的任何序列（可能为零），以便所有最终值达到或超过所需的目标。 

关键限制是每个操作同时消耗一个单位$n-1$材料。 这使得系统高度相互依赖：改进一个坐标会主动损害所有其他坐标。 

从约束条件来看，总和$n$跨测试用例最多$2 \cdot 10^5$，因此每个测试用例的任何解决方案都必须是线性或近线性的。 任何平方项$n$会立即失败。 

一种幼稚的方法可能会模拟操作或尝试独立地贪婪地调整每个坐标，但这两种方法都会失败，因为每个操作都会全局更改所有值。 

一些微妙的失败情况值得强调。 

考虑一种情况，其中一种材料远远低于其目标，但其他材料勉强够用。 天真的贪婪者可能会尝试重复“修复”有缺陷的坐标，但每次操作都会耗尽所有其他坐标，从而导致级联故障。 

另一个棘手的情况是，当所有值都接近目标但全局总和不足以重新分配质量时。 例如：```
n = 3
a = [0, 0, 10]
b = [5, 5, 5]
```在局部看来，将材料 3 转换为其他资源似乎是可能的，但每次转换也会破坏其他资源，并且可行性取决于全局平衡条件而不是局部移动。 

问题的根本在于系统是否有足够的总“松弛”来支持对称成本结构下的重复再分配。 

## 方法

 暴力解释将每个操作视为一个状态转换$n$维空间。 来自一个州$a$，我们尝试所有的选择$i$，应用变换，并继续，直到满足所有约束或无法移动。 

这在原则上是正确的，因为它探索了完整的状态空间。 然而，每个州都分为$n$新的状态和值可以增长到$O(10^9)$，使得状态空间变得巨大。 即使是很小的实例也会发生组合爆炸。 

关键的观察结果是该操作具有非常严格的全局效应。 如果我们对所有元素求和，一项操作会将总和更改为：$$(+1) + (-(n-1)) = 2 - n$$所以每次操作都会减少总和$n \ge 3$，并且仅当$n = 2$。 这立即表明可行性是由全局不变量而不是一系列选择控制的。 

为了$n \ge 3$，每个操作有效地重新分配质量，但会稳步降低总可用性，因此我们必须仔细检查初始配置是否已包含足够的“可用容量”以达到$b$。 

更准确的理解方法是定义赤字：$$d_i = b_i - a_i$$我们需要通过反复转移资源来消除所有正赤字，但每一次转移都需要$n-1$其他指数的支持单位。 这就导致了这样一种情况：可行性取决于最大赤字是否可以通过系统内分配的总盈余来补偿。 

这将问题简化为简单的线性检查，该检查是通过在操作约束下平衡总盈余与所需增量而得出的。 

最终简化为：

 我们计算总盈余$S = \sum (a_i - b_i)$。 如果$S < 0$，我们立即失败，因为我们已经缺乏总质量。 否则，我们检查是否可以支持最大赤字，因为每个操作都会消耗$n-2$整个系统的灵活性净单位。 这导致的检查相当于确保没有单个坐标需要比系统可以重新分配的补偿更多的补偿。 

更清晰的推导得出最终条件：

 我们排序$b_i - a_i$通过跟踪最大赤字隐式地进行，并验证总盈余至少是该赤字所需的结构性补偿。 

这会产生一个$O(n)$每个测试用例的解决方案。

 | --- | --- | --- | --- |
 | 暴力破解（状态搜索）| 指数| 指数| 太慢了|

 ## 算法演练

 我们根据赤字和盈余重新表述问题，然后验证单一的全球可行性条件。 

1. 计算差异$d_i = b_i - a_i$对于每种材料。 正值代表需求增加，负值代表供给过剩。 
2. 计算总盈余$S = \sum (a_i - b_i)$。 这反映了我们是否有足够的总资源来满足重新分配后的需求。 如果$S < 0$，无论采取什么行动，我们都无法达到目标。 
3.确定最大赤字$D = \max(d_i)$。 这是最难满足的坐标，因为每一项有助于它的操作都会同时伤害所有其他操作。 
4. 检查系统是否有足够的灵活性来弥补最严重的赤字。 一个坐标中每增加一个单位都需要牺牲$n-1$单位，因此全球盈余必须足以“资助”这种再分配结构。 这导致了可行性条件比较$D$针对可用盈余。 
5. 如果条件成立则返回“YES”，否则返回“NO”。 

### 为什么它有效

 不变量是在保持坐标之间固定线性关系的操作下总质量的分布。 每个操作都将向量向一个方向移动，即增加一个分量，同时同等地减少所有其他分量。 这意味着可达状态形成一个受总和演化和坐标对称性约束的晶格。 

任何有效的最终配置必须位于这些操作可到达的凸区域内，并且该区域完全由总和和极限坐标约束来表征。 该检查确保没有坐标需要比全局系统在中间步骤期间不违反非负约束的情况下可以重新分配的补偿更多的补偿。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        sa = sum(a)
        sb = sum(b)
        
        if sa < sb:
            print("NO")
            continue
        
        # compute maximum deficit
        max_def = 0
        for i in range(n):
            if b[i] > a[i]:
                max_def = max(max_def, b[i] - a[i])
        
        # key condition derived from redistribution constraint
        if max_def <= sa - sb:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```### 代码解释

 我们首先计算初始资源和所需资源的总和。 如果所需的总量超过了我们所拥有的总量，则任何操作序列都无法解决该问题，因为操作仅在以下情况下重新分配或减少总质量：$n \ge 3$。 

接下来，我们计算最大的个体短缺。 这捕获了最难修复的坐标，因为改进它的每个操作都会同时耗尽所有其他坐标。 

最后，我们将这一最大赤字与可用的全球盈余进行比较。 如果盈余大到足以“支付”纠正最差坐标的费用，则由于操作的统一性质，可以同时处理所有其他坐标。

 ## 边缘情况

 一种边缘情况是所有数组都相等。 该算法计算$sa = sb$和最大赤字$0$，因此它立即返回 YES，而不尝试任何重新分配。 

另一种边缘情况是总数完全匹配但分布不均匀。 在那种情况下，$sa - sb = 0$，所以任何正赤字都会迫使NO。 这符合这样的事实：任何操作都会由于缺乏松弛而破坏另一个坐标。 

最后一种边缘情况是当一个坐标存在极大赤字但总体存在盈余时。 检查确保即使总盈余为正，也必须足以覆盖最差坐标； 否则，任何操作序列都无法避免中间违规。
