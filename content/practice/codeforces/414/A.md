 ## 解决方案
 ## 问题理解

 Mashmokh 想要选择一个序列`n`不同的整数，这样他的老板 Bimokh 就可以准确地获得收益`k`一场比赛中的分数。 游戏成对进行：Bimokh 反复从当前序列中删除前两个整数，将这两个数字的最大公约数作为分数，直到剩下的数字少于两个。 任务是构造这样的序列或确定它是不可能的。 

输入是两个整数，`n`和`k`。 输出是`-1`如果不存在序列，或者`n`不同的整数`a1`到`an`每个不超过 10^9 将准确给出`k`应用所描述的过程时的点。 

界限很关键。 和`n`最多 10^5 和`k`直到 10^8，任何具有二次时间的算法都会太慢。 我们需要一个基本上以线性时间运行的解决方案。 每个整数必须符合标准 32 位有符号整数范围，因此我们不能依赖无界数字来对解决方案进行编码。 

当出现不明显的边缘情况时`k = 0`。 这要求所有对都是互质的。 如果`n = 1`，没有对，所以任何数字都可以。 为了`n = 2`，该序列必须包含 gcd 恰好为零的数字，这是不可能的，因为 gcd 始终至少为 1。这说明了`n`和`k`对可行性施加了限制。 

另一个边缘情况是当`k`相对于来说非常大`n`。 每对贡献最多`gcd(x, y)`点，所以第一个的总和`floor(n/2)`数字的 gcd 必须相等`k`。 这给出了我们必须遵守的序列的上限。 

## 方法

 暴力方法会尝试所有可能的序列`n`不同的整数，计算每个连续对的 gcd，并将它们相加以检查它是否等于`k`。 这在原则上是正确的，但不可行，因为序列的数量随阶乘增长`n`。 即使按升序生成序列并计算 gcd 也需要 O(n!) 次操作，这远远超出了 1 秒的限制。 

关键的见解是我们只关心每个删除对的第一个元素，因为我们通过选择数字来控制 gcd。 确保一对具有 gcd 1 的最简单方法是选择连续的整数。 达到总分`k`，我们可以构造前两个数字，使其 gcd 等于`k`并使序列的其余部分成为对 gcd 和没有贡献的连续数字，即它们的 gcd 为 1。这种方法将问题简化为选择两个产生所需 gcd 的数字，然后用与第一个元素互质的连续数字填充剩余序列。 

这种见解将问题转化为建设性的序列生成，而不是暴力搜索。 通过仔细挑选前两个数字作为`k + 1`和`2 * k + 1`，我们保证这对的 gcd 恰好是`k`。 其余数字可以是从 1 开始的连续整数，以避免与前两个数字冲突，确保所有数字不同且 ≤ 10^9。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 检查是否`n = 1`和`k > 0`。 如果是，则返回`-1`因为单个数字不能产生正的 gcd 点。 如果`n = 1`和`k = 0`， 返回`[1]`。 
2. 将序列中的前两个数字初始化为`k + 1`和`2 * k + 1`。 这两个数的 gcd 正好是`k`因为`2*k + 1 - (k + 1) = k`。 此选择满足目标分数。 
3.填写剩余部分`n - 2`从 1 开始的连续整数的数字，跳过已经选择的数字 (`k + 1`和`2*k + 1`）以保持独特性。 确保这些附加数字都不超过 10^9。 
4、按照构造好的顺序输出序列：`[k + 1, 2*k + 1, 1, 2, ..., skipping collisions]`。 

为什么它有效：不变的是只有第一对有贡献`k`到分数。 所有剩余的连续数字对要么从 1 开始，要么避免第一对的倍数，保证它们的 gcd 为 1。这种结构确保总和恰好是`k`同时保持所有数字不同且≤ 10^9。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

if n == 1:
    if k == 0:
        print(1)
    else:
        print(-1)
else:
    first = k + 1
    second = 2 * k + 1
    sequence = [first, second]
    current = 1
    while len(sequence) < n:
        if current != first and current != second:
            sequence.append(current)
        current += 1
    print(" ".join(map(str, sequence)))
```代码处理`n = 1`分开，因为它是不存在对的退化情况。 它构造前两个数字来匹配 gcd 要求，然后用小整数填充剩余序列以避免冲突。 使用`current`避免前两个数字意外重复。

 ## 边缘情况

 对于`n = 1`和`k = 0`，序列`[1]`正确地产生零分，因为不存在对。 为了`n = 1`和`k > 0`，算法返回`-1`因为单个数字无法产生正的 gcd。 对于大型`k`接近 10^8，前两个数字`k + 1`和`2*k + 1`不要超过 2 * 10^8 + 1，安全地低于 10^9，确保遵守约束。 

该算法通过跳过重复项来优雅地处理填充小数字可能与前两个数字重叠的序列，从而保留独特性。 这保证了对于任何有效的`n`和`k`，输出顺序正确。
