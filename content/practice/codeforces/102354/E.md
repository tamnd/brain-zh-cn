 ## 解决方案
 ## 问题理解

 该常数可以重写为

 [
 \varphi=\prod_{k=1}^{\infty}(1-10^{-k}),
 ]

 因为第 (k) 个因子恰好是 ((10^k-1)/10^k)。 我们需要小数点后占据位置（n）的数字，其中（n）可能大到（10^{18}）。 

最多有 (10^5) 个独立查询。 每个查询花费 (O(n)) 甚至 (O(\sqrt n)) 工作量的方法太慢了。 在最大 (n) 时，一次查询将需要 (O(n)) 大约 (10^{18}) 次操作，而 (O(\sqrt n)) 每个查询仍需要大约 (10^9) 次操作。 该解决方案必须利用无限乘积的精确结构，并在基本恒定的时间内回答每个位置。 

第一个陷阱是产品本身不直接暴露小数位。 例如，前两位数字是 (8) 和 (9)，尽管其有用展开式的第一项具有系数 (-1)。 如果我们简单地看一下 (10^{-n}) 的系数，我们会得到一个负值，而忘记了需要小数借位。 用于输入```
1
1
```答案是```
8
```不是 (-1)，因为展开从 (0.89\ldots) 开始。 

当 (n) 恰好是展开式中出现的特殊指数之一时，会出现第二种边界情况。 例如，```
1
5
```有答案（1）。 指数（5）贡献（+10^{-5}），但它后面的项仍然影响是否需要借位。 在这里，将系数单独视为最终数字恰好可行，但相同的快捷方式在 (n=7) 处失败，其中系数为 (+1)，而正确数字为 (0)。 

第三个边界立即出现在特殊指数之后。 为了```
1
6
```答案是（0），因为当小数点位置达到（6）时，（10^{-5}）贡献已经成为整数前缀的一部分。 仅查看下一个特殊指数的粗心实现可能会错误地返回 (1)。 

## 方法

 直接方法会使因素成倍增加

 [
 (1-10^{-1})(1-10^{-2})(1-10^{-3})\cdots
 ]

 足够高的精度并检查所需的小数位置。 这适用于较小的 (n)，因为索引大于 (n) 的因子无法对小数点前 (n) 位产生明显的影响。 然而，对于 (n=10^{18})，甚至构造前 (n) 个十进制数字也是不可能的。 对于一个查询来说，暴力工作是 (\Theta(n))，在最大允许位置已经是 (10^{18}) 位数字级操作。 

关键的观察是欧拉五边形数定理。 它给出了精确的扩展

 1+\sum_{k=1}^{\infty}(-1)^k
 \左（
 x^{k(3k-1)/2}+x^{k(3k+1)/2}
 \右）。 
]

 代入 (x=1/10)，我们得到

 1+\sum_{k=1}^{\infty}(-1)^k
 \左（
 10^{-k(3k-1)/2}
 +
 10^{-k(3k+1)/2}
 \右）。 
]

 因此，几乎每个小数位的系数都为零。 唯一的非零系数出现在广义五边形数处

 [
 P_k^-=\frac{k(3k-1)}2,
 \qquad
 P_k^+=\frac{k(3k+1)}2,
 ]

 并且两个位置都有系数 ((-1)^k)。 

这种稀疏性将问题简化为在 (n) 周围定位两个连续的广义五边形数。 我们不需要构造任何十进制前缀。 展开式乘以(10^n)后，每一项指数小于(n)的项都成为(10)的整数倍，因此不会影响最终模(10)的十进制数字。 唯一重要的局部信息是指数 (n) 处的系数，以及 (n) 之后开始的无限尾部是正数还是负数。 

尾部的星等小于 (1/9)。 它的第一项的大小严格大于所有后面项的总和，因此尾部的符号恰好是其第一项的符号。 因此，如果下一个广义五边形指数的系数为 (+1)，则不会发生借用。 如果系数为(-1)，则必须从位置(n)处的系数借用1个单位。 

相关的 (k) 大约在 (\sqrt{n}) 附近，但我们不会迭代到它。 解决

 [
 \frac{k(3k-1)}2\le n
 ]

 给出

 [
 k\le \frac{1+\sqrt{24n+1}}6.
 ]

 整数平方根让我们可以直接获得 (k)，因此每个查询都需要 (O(1)) 算术运算。

 | --- | --- | --- | --- |

 | 最佳 | 每个查询 (O(1)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 对于查询 (n)，计算

 [
 k=\left\lfloor\frac{1+\sqrt{24n+1}}6\right\rfloor。 
]

 这是 (P_k^-\le n) 的最大 (k)，其中 (P_k^-=k(3k-1)/2)。 

1.计算属于这个(k)的两个广义五边形位置，

 [
 a=P_k^-,
 \qquad
 b=P_k^+。 
]

 它们在展开中连续出现，除了(b)之后的下一个位置是(P_{k+1}^-)。 

1. 确定位置(n)处的系数。 如果(n=a)，则系数为((-1)^k)。 如果(n=b)，则系数也是((-1)^k)。 否则系数为零。 
2. 确定第一个严格大于(n)的指数。 如果(n<b)，则为(b)。 如果(n\ge b)，则为(P_{k+1}^-)。 在第一种情况下，其系数具有符号 ((-1)^k)，在第二种情况下，其系数具有符号 ((-1)^{k+1})。 
3. 从位置 (n) 处的系数开始。 如果第一个省略的项是负数，则减一。 最后对结果取模 (10)，将 (-1) 等值转换为十进制数字 (9)。 
4. 将结果数字附加到输出。 独立处理所有查询给出所需的数字序列。 

乘以 (10^n) 后最容易看出借用规则的原因。 写

 [
 10^n\varphi=S+R,
 ]

其中 (S) 包含指数最多为 (n) 的所有项，(R) 包含其余项。 数字(S)是整数。 余数满足(|R|<1/9)，其符号等于其第一项的符号。 因此，当 (R>0) 时 (\lfloor10^n\varphi\rfloor) 为 (S)，当 (R<0) 时 (S-1)。 以 (10) 为模，只有指数 (n) 处的系数保留在 (S) 中，准确地给出了上述算法。 

### 为什么它有效

 不变量是，在位置 (n) 之后，为了确定 (10^n\varphi) 的整数部分，整个无限尾部的行为与小正分数或小负分数完全相同。 第一个省略的五边形项决定出现哪种情况，因为它的绝对值支配所有后面省略的项。 同时，前面的每一项在乘以 (10^n) 后都会贡献 (10) 的倍数，因此只有指数 (n) 处的系数决定整数前缀的最后一位。 因此，该算法考虑了两种可能的影响、局部系数和单个可能的借位，并且不能产生不同的数字。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def digit(n):
    # k is the largest integer with k(3k-1)/2 <= n.
    k = (1 + (24 * n + 1) ** 0.5) // 6

    # Floating point is not safe for n up to 10^18.
    # Recompute using integer square root.
    s = math.isqrt(24 * n + 1)
    k = (1 + s) // 6

    while (k + 1) * (3 * (k + 1) - 1) // 2 <= n:
        k += 1
    while k * (3 * k - 1) // 2 > n:
        k -= 1

    a = k * (3 * k - 1) // 2
    b = k * (3 * k + 1) // 2

    if n == a or n == b:
        cur = 1 if k % 2 == 0 else -1
    else:
        cur = 0

    if n < b:
        next_sign = 1 if k % 2 == 0 else -1
    else:
        next_sign = -1 if k % 2 == 0 else 1

    if next_sign < 0:
        cur -= 1

    return cur % 10

def solve():
    t = int(input())
    ns = list(map(int, input().split()))

    ans = []
    for n in ns:
        ans.append(str(digit(n)))

    print(" ".join(ans))

if __name__ == "__main__":
    import math
    solve()
```第一个计算找到包含 (n) 的广义五边形块。 使用整数平方根是因为 (n) 可以达到 (10^{18})，而浮点平方根可能会在完美平方附近失去足够的精度以将 (k) 移动 1。 实际上，校正循环是恒定时间的，即使整数平方根公式落在相邻候选上，也可以使边界精确。 

变量`a`和`b`是属于 (k) 的两个指数。 将 (n) 与它们进行比较，确定当前系数是 (0) 还是 ((-1)^k)，并告诉我们接下来是哪个五边形数。 

表达式`next_sign`捕获无限后缀可以创建的唯一进位或借位。 负后缀会将楼层改变一层，因此`cur -= 1`是完整的小数进位调整。 

Python 整数具有任意精度，因此诸如 (24n+1) 之类的值以及涉及 (k) 的乘积是安全的，无需特殊的溢出处理。 该代码还使用缓冲输入并在一次输出操作中生成所有答案，这对于 (10^5) 测试用例很重要。

 ## 边缘情况

 对于 (n=1)，输入```
1
1
```有 (k=1)、(P_1^-=1) 和 (P_1^+=2)。 当前系数为(-1)，下一个系数也为负。 该算法再减一，得到 (-2) 和 (-2\bmod10=8)。 因此正确的输出是`8`。 

对于 (n=7)，输入```
1
7
```正好落在 (P_2^+=7) 上。 它的系数是(+1)，但下一个指数是(P_3^-=12)，其系数为负。 因此，缩放 (10^7) 后的下限比局部系数建议的整数前缀小 1。 该算法计算 (1-1=0)，给出正确的输出`0`。 

对于 (n=8)，输入```
1
8
```紧接在指数 (7) 之后。 指数(8)处没有系数，因此当前值为零。 第一个省略的项是指数 (12) 处的负项，强制借位。 结果是 (-1\bmod10=9)，与十进制扩展相匹配。

1
1000000000000000000
```有（k=816496580）。 其下广义五边形指数为

 999999997319296310,
 ]

 而上面的一个是

 [
 1000000813815876890。
