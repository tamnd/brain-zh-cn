 ## 解决方案
 ## 问题理解

 对于每个测试用例，法官秘密选择一个正有理数（x=p/q），其中（p）和（q）都最多为（10^9）。 我们无法直接看到（p）和（q）。 相反，我们可以选择一个大素数（m），询问（p q^{-1}\pmod m）的值，并使用返回的余数来恢复有理数。 答案最多可以使用任何正分子和分母 (10^9) 来表示相同的有理值，因此始终允许减少分数。 该问题是交互式的，这意味着程序必须打印查询、刷新它们、读取法官的答复，最后打印恢复的分数。 

分子和分母的上限 (10^9) 是关键的数值约束。 它告诉我们满足界限的两个不同的约简分数最多可以有 (10^{18}) 的叉积。 仅略大于 (10^9) 的模数不足以区分它们，因此一次查询通常无法提供足够的信息。 查询限制 10 足以组合两个乘积远大于 (10^{18}) 的模。 测试用例的数量可以达到（10^5），因此每次查询后的本地计算必须是模数的对数而不是与（10^9）成正比。 每个测试用例的两个查询和一个扩展欧几里得计算很容易就足够小。 

由于不需要减少输入分数，因此还存在另一个微妙之处。 假设隐藏值为(2/4)。 正确的数学值为 (1/2)，并且返回`! 1 2`是有效的。 仅搜索精确的隐藏对 (2,4) 的重建算法将解决比必要的问题更严重的问题，并且当它坚持恢复原始表示时可能会产生错误的答案。 

第二个边缘情况是 (p=q=10^9)。 分数正好是 (1)，因此正确的响应可以是`! 1 1`，不一定`! 1000000000 1000000000`。 将给定界限视为需要原始分子和分母的粗心算法将不必要地区分相同有理数的表示。 

当模块余数非常大时，就会出现第三种边缘情况。 例如，对于 (x=1/2) 和奇素数 (m)，返回的余数为 ((m+1)/2)，接近 (m/2)，远高于 (10^9)。 因此，尝试将返回值本身解释为分子会失败。 分子和分母必须根据同余 (p\equiv rq\pmod M) 重建，而不是直接从余数读取。 

## 方法

 一种直接的方法是查询一个模数并尝试从 (1) 到 (10^9) 的每个可能的分母 (q)。 对于每个 (q)，同余将候选分子确定为 (p=rq\bmod m)。 如果该值介于 (1) 和 (10^9) 之间，我们就找到了有效的表示。 这是可行的，因为隐藏对保证位于这些候选对象中，但最坏的情况需要对一个测试用例进行 (10^9) 模乘法。 跨 (10^5) 个测试用例变成 (10^{14}) 次迭代，这是完全不切实际的。 

关键的观察是可以组合几个模块化答案。 问两个不同的素数 (m_1,m_2)，然后使用中国余数定理将两个答案转化为单个余数 (r) 模

 [
 M=m_1m_2。 
]

 我们可以选择两个素数使得 (M>2\cdot 10^{18})。 价值观

 [
 m_1=999999999989,\qquad m_2=1000000000039
 ]

 都是素数并且满足要求的查询范围。 他们的乘积约为 (10^{24})，远远高于所需的界限。 

现在这个问题变成了一个标准的理性重构问题。 我们知道

 [
 r\equiv pq^{-1}\pmod M,
 ]

 或同等地，

 [
 rq\equiv p\pmod M.
 ]

 减少的隐藏分数有 (1\le p,q\le10^9)。 如果两个不同的约简分数 (p_1/q_1) 和 (p_2/q_2) 产生相同的残差，则

 [
 p_1q_2-p_2q_1\equiv0\pmod M。 
]

 左边的绝对值至多为(2\cdot10^{18})，而(M)大于此。 因此，差值实际上必须为零，因此分数是相同的。 这正是理性重建背后的唯一性条件，可以使用扩展欧几里得算法来执行。 

欧几里得算法给出了一系列恒等式

 [
 R_i=A_iM+B_ir。 
]

 当余数 (R_i) 首先变为至多 (10^9) 时，相应的系数 (B_i) 是重构分数的分母，直到一个公共符号。 模数故意远大于 (2N^2)，其中 (N=10^9)，因此所需的分子和分母必须出现在欧几里德序列中的这一点。 

蛮力方法和最优方法可总结如下。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个测试用例 (O(10^9)) | (O(1)) | (O(1)) | 太慢了 |
 | CRT+理性重建| 每个测试用例 (O(\log M)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 求隐藏余数模（m_1=999999999989）。 该数字是质数并且严格位于 (10^9) 和 (10^{12}) 之间，因此它是合法的查询。 
2. 求余数模（m_2=1000000000039）。 使用两个不同的素数给出描述相同有理数的两个同余。 
3. 将两个答案与中国剩余定理结合起来。 如果答复是 (r_1) 和 (r_2)，则写

 [
 r=r_1+m_1k。 
]

 我们选择 (k) 使得 (r\equiv r_2\pmod {m_2})。 因此

 [
 k\equiv(r_2-r_1)m_1^{-1}\pmod {m_2}。 
]

 结果 (r) 是满足两个查询的唯一余数模 (M=m_1m_2)。 

1. 对 (M) 和 (r) 运行扩展欧几里得算法，同时跟踪 (r) 的系数。 最初，两个相关对是

 [
 (M,0),\qquad(r,1)。 
]

 每个欧几里得过渡都保留了形式的同一性

 [
 R=AM+Br。 
]

1. 用 (R\le10^9) 停在第一个欧几里得余数 (R) 处。 有理重构定理指出，因为 (M>2\cdot10^{18})，该余数及其 (r) 系数给出了所需范围内唯一的简化分子和分母。 
2. 如有必要，通过更改两个符号使系数为正。 在这个问题的有效正重构中，最后一对是正的，但对符号进行归一化可以使实现变得稳健。 
3. 打印重建的分子和分母作为最终答案。 即使法官最初选择非简化表示，重建分数与隐藏分数具有相同的有理值。 

整个欧几里德阶段的不变量是每个当前余数 (R) 都有一个已知的表示 (R=AM+Br)。 由于 (r\equiv pq^{-1}\pmod M)，将后者同余乘以 (q) 得到 (rq\equiv p\pmod M)。 因此，隐藏对本身就是该欧几里得格中表示的小解之一。 界限 (M>2N^2) 使该小简化解唯一，因此当欧几里得达到第一个足够小的余数时，它不能是不同的有效分数。 

## Python 解决方案

 原来的任务是交互式的，所以下面的程序是实际的交互式解决方案。 语句中显示的示例是交互记录而不是普通输入，因此它不能作为传统的 stdin-to-stdout 批处理测试来执行。```python
import sys
input = sys.stdin.readline

P1 = 999999999989
P2 = 1000000000039
N = 10**9

def extended_gcd(a, b):
    old_r, r = a, b
    old_s, s = 1, 0
    old_t, t = 0, 1

    while r:
        q = old_r // r
        old_r, r = r, old_r - q * r
        old_s, s = s, old_s - q * s
        old_t, t = t, old_t - q * t

    return old_r, old_s, old_t

def crt(r1, r2):
    # r = r1 + P1 * k
    # P1 * k == r2 - r1 (mod P2)
    _, inv, _ = extended_gcd(P1, P2)
    inv %= P2

    k = ((r2 - r1) % P2) * inv % P2
    return r1 + P1 * k

def rational_reconstruct(r, mod):
    # Euclidean sequence:
    # remainder = A * mod + B * r
    old_r, cur_r = mod, r
    old_b, cur_b = 0, 1

    while cur_r > N:
        q = old_r // cur_r

        old_r, cur_r = cur_r, old_r - q * cur_r
        old_b, cur_b = cur_b, old_b - q * cur_b

    numerator = cur_r
    denominator = cur_b

    if denominator < 0:
        numerator = -numerator
        denominator = -denominator

    return numerator, denominator

def ask(m):
    print("?", m, flush=True)
    ans = int(input())

    if ans == -1:
        sys.exit(0)

    return ans

def main():
    t = int(input())

    for _ in range(t):
        r1 = ask(P1)
        r2 = ask(P2)

        r = crt(r1, r2)
        mod = P1 * P2

        p, q = rational_reconstruct(r, mod)

        print("!", p, q, flush=True)

if __name__ == "__main__":
    main()
```在处理任何测试用例之前，这些常量是固定的。 两者都是允许区间内的有效素数，因此无需花费查询或计算来搜索素数。 它们的乘积大于 (2\cdot10^{18})，这是理性重建所需的唯一尺寸条件。 

这`ask`函数打印查询并立即刷新标准输出。 在交互式问题中，刷新是强制性的，因为法官无法回答尚未收到的查询。 的回复`-1`通常意味着交互失败，因此程序立即终止而不是发送更多输出。 

这`crt`函数遵循直接二模 CRT 公式。 扩展欧几里得算法给出 (P_1) 模 (P_2) 的倒数，并且在构造最终残数之前将乘法减少模 (P_2)。 Python 整数具有任意精度，这很有用，因为 (P_1P_2) 约为 (10^{24})，远远超出有符号 64 位范围。 

这`rational_reconstruct`函数仅跟踪查询的残差的系数。 无需保留模数系数。 什么时候`cur_r`首先变为至多(10^9)，相应的系数给出分母，余数给出分子。 停止条件使用`>`而不是`>=`，因为等于 (10^9) 的余数已经是有效的分子，必须接受。 

该算法永远不会除以原始分母对组合模数取模。 分母最多为 (10^9)，而查询的两个素数都大于 (10^9)，因此它会自动对每个素数取模可逆。 这就是有理数的模表示得到明确定义的原因。

 ## 边缘情况

 对于非约简情况，考虑确切的输入`2 4`在离线线束中。 两个素数的模值与 (1/2) 相同，因为

 [
 2\cdot4^{-1}\equiv1\cdot2^{-1}\pmod m.
 ]

 CRT将两个观测值组合成(1/2)的残差，有理重建返回`1 2`。 这是正确的，因为所需的输出是有理值，而不是原始编码。 

对于最大相等的情况，考虑`1000000000 1000000000`。 两个模块化回复都是 (1)，因此 CRT 给出 (r=1)。 第一个欧几里得余数已经满足 (10^9) 界限，系数为 (1)，给出`1 1`。 尝试保留隐藏表示的解决方案将不必要地返回未简化的对，但判断器接受该值的任何有效表示。 

对于 (x=1/2)，模数回复约为 (5\cdot10^{11})，即使分子和分母最多为 (10^9)。 欧几里得序列最终达到系数 (2) 的余数 (1)。 这捕获了假设返回的模值本身必须是分子的常见错误。 

对于上限分数`1000000000 999999999`，分子正好在允许的限度内。 组合模数仍然比每个相关叉积大得多，因此有理重构定理适用，无需对边界相等性进行任何特殊处理。 该算法返回相同的约简对，确认停止条件必须接受等于 (10^9) 的余数，而不仅仅是严格小于它的一个。 

基本思想是使用十个可用查询中的两个来生成 (10^{24}) 附近的模数，然后停止考虑交互并解决纯算术问题。 CRT 给出一个同余取足够大的模，扩展的欧几里德算法将该同余转换回唯一的小有理数。
