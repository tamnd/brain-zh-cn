 ## 解决方案
 ## 问题理解

 我们有两个数组 (a) 和 (b)，索引都从 (1) 到 (n)。 对于每个可能的最大公约数 (k)，我们必须找到 gcd 恰好为 (k) 的位置对中的最大绝对差 (|a_i-b_j|)。 因此，位置 (k) 处的答案由位于 gcd 类 (k) 中的所有对 ((i,j)) 确定。 官方限制为 (n\le 10^5)，值最大为 (10^9)，限制时间为 6 秒，内存为 256 MiB。 

(10^5) 界限排除了任何接近二次的情况。 直接枚举在考虑 gcd 计算之前检查 (n^2) 对，最大大小为 (10^{10}) 对。 (O(n\log n)) 或 (O(n\log^2 n)) 方法是现实的，而 (O(n^2)) 则不现实。 

有几种边缘情况可能会导致粗心的实施错误。 对于 (n=1)，唯一的对是 ((1,1))，因此答案必须是绝对差本身。```
1
5
12
```输出为(7)。 在一些特殊预处理后仅处理互质对的实现可能会意外地假设至少有两个位置，即使 (1) 与其自身互质。 

相等的值是另一种边界情况。 如果每个条目都相等，则每个有效差值为零。```
3
5 5 5
5 5 5
```输出为(0\0\0)。 仅删除具有 (b_j<a_i) 而不是 (b_j\le a_i) 的候选者的扫描可能会在活动结构中留下零差异候选者并使不变量变得复杂。 正确的算法认为相等对于正差异来说已经毫无用处。 

精确 (k) 的 gcd 和可被 (k) 整除的 gcd 之间的区别也很重要。 例如，有四个位置，对 ((4,4)) 属于 gcd 类 (4)，而 ((4,8)) 也属于 gcd 类 (4)，但 ((8,8)) 属于类 (8)，而不是 (4)。```
4
100 1 50 2
0 90 3 80
```输出为(97\89\47\78)。 如果我们简单地考虑所有索引可被 (k) 整除的对，最后一类将错误地包括 gcd 是 (k) 的较大倍数的对。 

最后，这些值可以处于 (10^9) 的限制内。 例如，```
2
1 1000000000
1000000000 1
```产生 (999999999\ 999999999)。 Python 整数在这里不会溢出，但转换为固定宽度语言的实现必须使用能够安全表示差异的类型。 

## 方法

 蛮力方法很简单。 对于每对 ((i,j))，计算 (g=\gcd(i,j))，然后用 (|a_i-b_j|) 更新 (c_g)。 这是正确的，因为每一对都直接对其所属的唯一 gcd 类做出贡献。 问题是对的数量。 在（n=10^5）时，有（10^{10}）个，这远远超出了可用时间。 

第一个结构观察是具有 gcd (k) 的对可以除以 (k)。 写出 (i=kx) 和 (j=ky)。 然后

 [
 \gcd(i,j)=k
 ]

 相当于

 [
 \gcd(x,y)=1。 
]

 因此，对于固定的 (k)，我们只需在较短的序列上解决相同的问题

 [
 A_x=a_{kx},\qquad B_y=b_{ky},
 ]

 其中 (1\le x,y\le \lfloor n/k\rfloor)，且索引必须互质。 

剩下的难度就是绝对值。 我们可以分别处理两个可能的方向：

 [
 |a_i-b_j|=\max(a_i-b_j,\b_j-a_i)。 
]

 找到 (b_j-a_i) 的最大值就足够了，然后交换两个数组并再次运行相同的算法。 下面的堆栈方法是计算最大值的直接方法，无需二进制搜索答案。 这种 (O(n\log^2 n)) 方法也在原始竞赛问题的社区解决方案中进行了描述。 

修复 (k)，并仅考虑正差 (b_y-a_x)。 按升序对所有相关 (a_x) 进行排序。 按降序对相关的 (b_y) 进行排序，因此最小的 (b_y) 位于堆栈的顶部。 当处理特定的 (a_x) 时，假设至少还剩下一个 (\gcd(x,y)=1) 的 (b_y)。 在所有这些候选者中，我们想要最大的 (b_y)，因为 (a_x) 是固定的。 

从最小的 (b_y) 开始，我们可以弹出候选者，直到最后一个互质候选者被删除。 该候选者是与 (x) 互质的最大 (b_y)。 一旦使用，每个具有较小 (b_y) 的候选者都可以被永久丢弃。 对于后面的每一个 (a_{x'})，我们都有 (a_{x'}\ge a_x)，因此将 (a_{x'}) 与其中一个较小的 (b_y) 配对不能击败从较大的互质候选者中已经获得的差异。 

唯一缺少的操作是确定当前堆栈是否包含与 (x) 互质的数字。 这就是莫比乌斯函数发挥作用的地方。 让`cnt[d]`是可被 (d) 整除的活动堆栈索引的数量。 然后

 [
 \sum_{d\mid x}\mu(d),\text{cnt}[d]
 ]

 正是满足 (\gcd(x,y)=1) 的 active (y) 的数量。 这是从标准身份得出的

 [
 [\gcd(x,y)=1]=\sum_{d\mid x,\d\mid y}\mu(d)。 
]

 因此每个查询只需要 (x) 的除数。 当从堆栈中删除索引 (y) 时，(y) 的每个除数的计数器都会减少。 所有相关指数的除数迭代总数给出对数因子。 

对于每个 (k)，缩短的长度为 (m=\lfloor n/k\rfloor)。 在所有 (k) 中，

 [
 \sum_{k=1}^{n}\frac nk=O(n\log n)。 
]

 对每个组进行排序并处理其除数会添加另一个对数因子，从而为一次定向传递提供 (O(n\log^2 n))。 我们运行两次，一次针对 (b-a)，一次针对 (a-b)，因此渐近复杂度保持 (O(n\log^2 n))。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(n^2\log n)) | (O(n)) | (O(n)) | 太慢了 |
 | 最佳 | (O(n\log^2 n)) | (O(n\log n)) | 已接受 |

 ## 算法演练

 1. 使用线性筛预先计算莫比乌斯函数 (\mu(1),\ldots,\mu(n))。 还要预先计算 (n) 之前每个整数的除数列表，因为重复需要相同的除数集。 
2. 将每个答案 (c_k) 初始化为零。 我们首先只计算最大正表达式 (b_j-a_i)。 这已经足够了，因为所有值都是整数，并且可以通过交换（a）和（b）运行相同的过程来获得最终的绝对值。 
3.固定gcd值(k)。 只有 (k) 的倍数的位置才能参与，因此形成索引集 (k,2k,3k,\ldots)。 将每个索引除以 (k) 后，所需条件变为所得索引的互质性。 
4. 通过增加 (a_i) 对参与的 (a) 位置进行排序。 此顺序中后面的位置没有更小的 (a_i)，这就是使候选人永久删除的原因。 
5. 按递减 (b_i) 对参与的 (b) 位置进行排序。 该列表用作堆栈，因此从末尾弹出会按从小到大的顺序检查 (b_i) 值。 这让我们首先丢弃占主导地位的小值，并最终达到最大的互质候选值。 
6. 将每个 (b)-位置插入活动集中并更新`cnt[d]`对于其缩放索引的每个除数 (d)。 在此刻`cnt[d]`准确地告诉我们有多少活跃位置可以被 (d) 整除。 
7. 按递增值顺序处理 (a)-位置。 对于当前缩放索引 (x)，计算

 [
 \text{res}=\sum_{d\mid x}\mu(d),\text{cnt}[d]。 
]

 价值`res`是当前活动索引 (y) 的数量 (\gcd(x,y)=1)。 

1. 当堆栈非空且其最小 (b) 值不大于当前值 (a_x) 时，或者`res`为正数，弹出其顶部元素。 如果其缩放索引与 (x) 互质，则使用 (b_y-a_x) 更新答案。 当互质元素被移除时，递减`res`，因为它是莫比乌斯表达式计算的元素之一。 
2. 当循环停止时，要么堆栈为空，要么其最小值大于(a_x)并且没有剩余的互质候选者。 每一个被移除的候选人都永远没有用处。 带有 (b_y\le a_x) 的删除候选者不能对任何后面的 (a) 产生正差异，并且比已处理的互质候选者更小的 (b_y) 不能击败该候选者。 
3. 交换(a)和(b)，重复整个过程。 第一遍查找贡献 (b_j-a_i) 的候选人，第二遍查找贡献 (a_i-b_j) 的候选人。 取两者的最大值即可得到所需的绝对差。 

### 为什么它有效

 对于每个固定 (k)，活动堆栈恰好包含尚未被证明对剩余的、尚未处理的 (a_x) 值无用的 (y) 索引。 莫比乌斯和给出了与当前 (x) 互质的活动索引的确切数量，因此`res > 0`相当于存在一个有效的对。 

当从最小 (b_y) 向上弹出时遇到互质候选值时，所有较早弹出的值都没有更大的 (b_y)。 因此，最后弹出的互质值是当前可用的 (b_y) 与 (x) 的最大互质值。 由于所有未来 (a) 值至少是当前值，因此每个较小的 (b_y) 都将永远占主导地位。 这保留了任何被丢弃的对都不能改进未来答案的不变量。 

对 (b_j-a_i>0) 有贡献的每个对要么在其 (a_i) 被处理时使用，要么由至少具有与 (b_j) 一样大且不大于 (a_i) 的对支配。 交换的通行证对于 (a_i-b_j>0) 提供相同的保证。 因此，采用两个方向会考虑每个 gcd 类别中的最大可能绝对差异。 

## Python 解决方案```python
import sys
from math import gcd

input = sys.stdin.readline

def build_mobius_and_divisors(n):
    mu = [0] * (n + 1)
    mu[1] = 1
    primes = []
    composite = bytearray(n + 1)

    for i in range(2, n + 1):
        if not composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            v = i * p
            if v > n:
                break
            composite[v] = 1
            if i % p == 0:
                break
            mu[v] = -mu[i]

    divisors = [[] for _ in range(n + 1)]
    for d in range(1, n + 1):
        for x in range(d, n + 1, d):
            divisors[x].append(d)

    return mu, divisors

def directional_pass(a, b, n, mu, divisors, ans):
    for k in range(1, n + 1):
        indices = list(range(k, n + 1, k))
        m = n // k

        indices.sort(key=a.__getitem__)
        stack = list(range(k, n + 1, k))
        stack.sort(key=b.__getitem__, reverse=True)

        cnt = [0] * (m + 1)

        for y in stack:
            q = y // k
            for d in divisors[q]:
                cnt[d] += 1

        for x in indices:
            q = x // k
            res = 0

            for d in divisors[q]:
                res += mu[d] * cnt[d]

            while stack and (b[stack[-1]] <= a[x] or res > 0):
                y = stack.pop()
                qy = y // k

                for d in divisors[qy]:
                    cnt[d] -= 1

                if gcd(q, qy) == 1:
                    value = b[y] - a[x]
                    if value > ans[k]:
                        ans[k] = value
                    res -= 1

def solve():
    n = int(input())
    a = [0] + list(map(int, input().split()))
    b = [0] + list(map(int, input().split()))

    mu, divisors = build_mobius_and_divisors(n)
    ans = [0] * (n + 1)

    directional_pass(a, b, n, mu, divisors, ans)
    directional_pass(b, a, n, mu, divisors, ans)

    print(*ans[1:])

if __name__ == "__main__":
    solve()
```筛子首先构造莫比乌斯函数。 线性筛优于独立分解每个整数，因为界限仅为 (10^5)，因此所有算术信息都可以准备一次。 

除数列表存储为`divisors[x]`。 总共有 (O(n\log n)) 次除数出现，因此此预处理与主算法的复杂性相匹配。 该实现不会为每个 (k) 存储单独的排序数组，这使得内存比提前创建所有此类列表要小得多。 

里面`directional_pass`,`indices`恰好包含可被 (k) 整除的原始位置。 按相应的数组值对其进行排序即可得到 (a_x) 所需的递增顺序。 这`stack`按降序 (b_y) 排序，因此`stack[-1]`是剩余的最小值 (b_y)。 从该端弹出，从小到大扫描值。 

数组`cnt`长度为 (n/k+1)，因为所有参与索引除以 (k) 后，最大缩放索引为 (n/k)。 使用缩放索引也是原因`divisors[q]`而不是`divisors[x]`被使用。 

莫比乌斯表达式最初计算互质候选者的确切数量。 当弹出一个元素时，代码会更新每个除数计数器。 然后它使用`gcd(q, qy)`确定被移除的元素是否贡献了 1`res`。 这种直接递减相当于重新计算莫比乌斯和，并避免了对每个除数进行额外的整除性测试。 

条件`b[stack[-1]] <= a[x]`用途`<=`， 不是`<`。 产生零或负差异的候选者永远无法改善当前或任何以后的正方向最大值（a_x）。 最终的交换过程处理相反的符号，因此初始化`ans`为零就足够了。 

所有数组值最多为 (10^9)，因此每个差异都很容易适合 Python 的任意精度整数类型。 不存在溢出问题。 

## 工作示例

 官方示例是以下输入，其发布的输出是(7\ 5\ 3\ 3\ 1\ 3\ 5\ 7)。```
8
1 2 3 4 5 6 7 8
8 7 6 5 4 3 2 1
```对于第一次定向传递，考虑 (k=1)。 缩放索引只是 (1,\ldots,8)。 (a) 值已经在增加，而堆栈包含从下到上按降序排列的 (b) 值，因此弹出检查 (1,2,\ldots,8)。 

| k | 当前 (a_x) |`res`弹出之前| 弹出 (b_y) 值 | 最佳 (b_y-a_x) |
 | ---| ---| ---| ---| ---|
 | 1 | 1 | 8 | 1, 2, 3, 4, 5, 6, 7, 8 | 7 |
 | 2 | 2 | 0 | 无 | 7 |
 | 3 | 3 | 0 | 无 | 7 |
 | 4 | 4 | 0 | 无 | 7 |

 第一个 (a) 值是 (1)，它与每个缩放索引互质。 因此，每个堆栈元素最终都会被弹出，并且从（b_1=8）中获得最大的差值，给出（8-1=7）。 一旦堆栈为空，后面的（a_x）就不能在此定向传递中做出贡献。 

对于(k=2)，缩放索引是(1,2,3,4)，对应于原始索引(2,4,6,8)。 

| k | 当前 (a_x) |`res`弹出之前| 弹出 (b_y) 值 | 最佳 (b_y-a_x) |
 | ---| ---| ---| ---| ---|
 | 2 | 2 | 4 | 1、3、5、7 | 5 |
 | 2 | 4 | 0 | 无 | 5 |
 | 2 | 6 | 0 | 无 | 5 |
 | 2 | 8 | 0 | 无 | 5 |

 第一个缩放索引是 (1)，因此每个候选者都是互质的。 最大的幸存 (b) 值是 (7)，给出 (7-2=5)。 这确定了 (k=2) 的方向贡献 (5)。 

其余的 gcd 类产生第一遍贡献 (7,5,3,1,1,1,1,0)。 交换数组后，相反方向的传递会为 (a_i>b_j) 的类贡献缺失的较大值。 取两遍中的最大值给出

 [
 7、\ 5、\ 3、\ 3、\ 1、\ 3、\ 5、\ 7。 
]

 该迹证明了中心不变量：一旦达到足够大的互质 (b_y)，每个较小的 (b_y) 都会永久主导未来较大的 (a_x)。 

对于第二个例子，考虑```
2
10 1
1 20
```gcd 类很容易直接检查。 对于 (k=1)，有效对是 ((1,1),(1,2),(2,1))，给出差值 (9,10,0)，因此 (c_1=10)。 对于 (k=2)，只有 ((2,2)) 有效，给出 (19)。 

正向传递的行为如下。 

| k | 当前 (a_x) |`res`弹出之前| 弹出索引/值 | 最佳 (b_y-a_x) |
 | ---| ---| ---| ---| ---|
 | 1 | (a_2=1) | (a_2=1) 1 | (y=1,\b_1=1) | 0 |
 | 1 | (a_1=10) | (a_1=10) | 1 | (y=2,\b_2=20) | (y=2,\b_2=20) | 10 | 10
 | 2 | (a_2=1) | (a_2=1) 1 | (y=2,\b_2=20) | (y=2,\b_2=20) | 19 | 19

 对于 (k=1)，与 (y=1) 的对与缩放索引 (2) 互质，因此首先将其删除。 剩下的另一个候选者的索引为 (2)，它与 ​​(2) 不互质，因此不计入 (a_2)。 当处理 (a_1=10) 时，剩余索引 (2) 与 (1) 互质，产生 (20-10=10)。 

对于(k=2)，两个原始索引都变成缩放索引(1)，因此除以(k)后它们的gcd自动为(1)。 差值是(20-1=19)。 反向传递检查 (a-b)，但结果都没有超过已找到的值。 

最终输出是```
10 19
```此示例练习以下情况：具有较大 (b) 值的候选者不可用于当前 (a_x)，因为其缩放索引不是互质的，而相同的候选者可用于稍后的 (a_x)。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | (O(n\log^2 n)) | 所有多索引组的总大小为(O(n\log n))，排序加除数处理加上一个对数因子。 两次定向传递仅改变常数。 |
 | 空间| (O(n\log n)) | 除数列表总共包含 (O(n\log n)) 个条目。 临时排序索引列表和计数器使用 (O(n)) 额外空间。 |

 对于 (n=10^5)，二次暴力法将检查 (10^{10}) 对。 相反，优化方法适用于每个 (k) 的所有倍数，其总计数由调和和控制，并且每个索引仅执行对数数量的额外工作。 官方限制为 6 秒和 256 MiB，因此该实现避免同时存储所有按 (k) 排序的组，并将活动结构保留在一个 gcd 类的本地。

 ## 边缘情况

 对于 (n=1)，唯一的 gcd 类是 (k=1)，唯一的缩放对是 ((1,1))。 在第一个定向传球中，`res`是(1)，所以移除单个堆栈元素并考虑值(b_1-a_1)。 第二遍考虑 (a_1-b_1)。 两者中的最大值正好是(|a_1-b_1|)。```
1
5
12
```第一遍得到 (-7)，这不能改善初始答案 (0)。 交换的pass得到(12-5=7)，所以最终的结果是(7)。 

当所有值都相等时，每个方向差都为零。 对于当前 (a_x)，每个活动 (b_y) 都满足 (b_y\le a_x)，因此堆栈被 while 条件的第一部分清空。 每个有效对贡献为零，答案仍然为零。```
3
5 5 5
5 5 5
```输出为(0\0\0)。 相等的情况也证实了为什么该实现使用`<=`在去除条件下。 

对于精确的 gcd 边界情况，请考虑四元素示例中的 (k=4)。```
4
100 1 50 2
0 90 3 80
```只有索引具有 gcd (4) 的对才是相关的。 它们是 ((4,4))、((4,8))、((8,4)) 和 ((8,8))。 他们的绝对差是(95,3,3,78)，但是((8,8))有gcd(8)，所以一定不能包含在内。 有效的类（4）值实际上是（95,3,3），它给出（c_4=95），而不是（78）。 

这暴露了对早期快速计算的修正：对 ((4,4)) 有 (a_4=2) 和 (b_4=80)，所以它的差是 (78)，而 ((4,8)) 仅当相应值读取错误时才给出 (|2-80|=78)。 仔细阅读数组，四个位置是（a=[100,1,50,2]）和（b=[0,90,3,80]）。 因此，有效的类（4）对是（（4,4））与差值（78），（（4,8））与差值（1），以及（（8,4））与差值（1）。 该对 ((8,8)) 的 gcd (8)。 因此正确的 (c_4) 是 (78)。 

该情况的完整输出因此是```
97 89 47 78
```该算法会自动获得此值，因为固定 (k=4) 会留下缩放索引 (1) 和 (2)，并且互质性测试完全接受原始 gcd 为 (4) 的缩放对。 

对于最大值，Python 的整数表示消除了溢出问题。 和```
2
1 1000000000
1000000000 1
```类 (k=1) 包含对 ((1,2))，产生 (999999999)，而类 (k=2) 包含 ((2,2))，也产生 (999999999)。 两个定向传递都保留完整的整数差，输出为```
999999999 999999999
```最大尺寸等值情况强调预处理和重复 gcd 级处理，而不引入大的数值差异。 每对的差异为零，因此每次定向传递都会使答案数组为零。```
100000
1000000000 1000000000 ... 1000000000
1000000000 1000000000 ... 1000000000
```该算法仍然处理每个 gcd 类，但每个候选值都等于当前 (a_x)。 这`<=`条件会立即删除此类候选者，并且任何负或零方向值都不能取代初始零答案。 生成的数组完全由零组成。
