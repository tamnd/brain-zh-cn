 ## 解决方案
 ## 问题理解

 我们有一系列围绕原点的点卫星。 每颗卫星都有一个角位置、距原点的距离和质量。 Elphaba 选择一条从原点开始的射线，并希望沿着该射线的总重力在她访问的任何点上都没有垂直于该射线的分量。 

中心观察是有效的飞行路线必须是整个加权卫星配置的反射轴。 跨越线路的反射必须保留每颗卫星的位置及其质量。 这也是问题的几何简化：有效线正是加权配置的对称轴，之后问题就变成了回文问题。 

角度以整数弧秒给出，一整圈恰好包含 129600 个位置。 这种有限的角分辨率非常有用。 我们可以创建一个长度为129600的数组，将这对`(rho, mass)`在每个占据的角度，并在其他地方使用空标记。 

的价值`n`可以大到 200000，但角坐标是从 0 到 129599 的不同整数，因此有效输入最多可以包含 129600 个卫星。 两秒的时间限制排除了任何二次方`n`。 即使是 129600 平方也大约需要 168 亿次比较，远远超出了 Python 的及时执行能力。 固定角度宇宙上的线性或近线性算法是正确的目标。 官方的问题有256 MiB的内存限制，对于一些大小约为260000的数组来说已经足够了。 

直接几何实现可能会错误处理几种边缘情况。 首先，对称轴可以穿过卫星，但如果卫星位于行进方向，则相应的飞行射线将被禁止。 例如，```
2
1 0 1
1 64800 1
```对称轴位于 0 和 32400 角秒模 64800。方向 0 和 64800 被卫星阻挡，而 32400 和 97200 是清晰的，因此正确的输出是```
2
32400.0000000
97200.0000000
```在不检查实际光线的情况下报告对称轴的粗心实现会错误地输出四个方向。 

其次，轴不必处于整数角度。 角度为 0 和 1 的两颗相等的卫星的对称轴为 0.5 度（以问题的角秒为单位，更准确地说是 0.5 角秒）：```
2
1 0 1
1 1 1
```正确的输出是```
2
0.5000000000
64800.5000000000
```仅默默地检查整数中心的实现会错过这两个答案。 

第三，如果质量不同，几何对称是不够的。 考虑```
4
1 0 1
1 64800 2
1 32400 3
1 97200 3
```几何位置绕水平轴对称，但该轴上的两颗卫星具有不同的质量。 该配置不是加权反射对称性，并且水平方向也被阻挡。 正确的输出是```
0
```仅检查坐标并忽略质量会错误地接受方向。 

最后，空的角度位置很重要。 如果两颗卫星之间存在较大的角度间隙，则反射必须保留该间隙以及卫星本身。 使用显式空符号填充完整的 129600 位置角度数组可以自动处理此问题。 仅将输入压缩到占用的位置会丢失有关角距离的信息，并可能产生错误的对称性。 

## 方法

 强力方法是选择一条可能的线，反射穿过该线的每颗卫星，并检查反射的配置是否相同，包括质量。 由于每个有效轴都由其在角坐标上的作用确定，因此只有 O(129600) 个可能的轴，因为轴是以 180 度为模确定的，并且可能位于整数或半整数弧秒处。 对照所有轴检查一个轴`n`卫星需要 O(n)，给出 O(129600n)，或者在最大可行输入下进行大约 1.7 × 10^10 比较。 即使在考虑 Python 的开销之前，这也太慢了。 

有更好的方法，因为角坐标是离散的。 Put the satellite label`(rho, mass)`并在每隔一个整数角度处放置一个空值。 绕双角轴反射`k`发送角度`x`到`k-x`模129600。因此，当在适当的点切割圆形阵列时，轴两侧的标签必须形成回文。 

圆形边界是唯一的复杂因素。 我们通过复制角度数组来解决它。 原始圆的对称性变成以加倍数组中某处为中心、长度为 129600 的回文。 整数中心和半整数中心都会出现，因此我们使用 Manacher 算法中的奇数和偶数回文半径。 Manacher 在线性时间内计算所有最大回文半径。 

物理参数根本不需要浮点计算。 当两个反射位置精确相等时，它们`(rho, mass)`对是相等的。 这意味着元组比较就足够了，并且完全避免了哈希冲突。 

一旦找到每个反射轴，每个轴代表两个相反的飞行方向。 仅当没有卫星正好位于该射线上时，方向才有效。 由于所有卫星角度都是整数，因此半整数方向永远不可能包含卫星，而整数方向可以直接在角度数组中检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(129600n) | O(n) | 太慢了 |
 | 最佳 | O(129600 + n + A) | O(129600 + n + A) | O(129600 + n) | 已接受 |

 这里`A`是输出方向的数量。 最终的扫描实际上是 O(259200)，因此整个解决方案在固定角度宇宙中实际上是线性的。 

## 算法演练

 1. 创建角度数组`a`长度`C = 129600`。 在位置`phi`， 店铺`(rho, mass)`对于具有该角度的卫星。 每隔一个位置存储`None`。 元组是反射必须保留的完整信息。 
2.复制该数组得到`s = a + a`。 反射轴可以跨越角度 129599 和角度 0 之间的人为边界，因此单独处理一个副本将丢失有效的回文。 第二个副本提供了足够的空间来将每个圆形回文表示为普通回文。 
3. 运行 Manacher 的算法`s`并计算奇数回文半径`d1`甚至回文半径`d2`。 奇数半径`d1[i]`是匹配层的数量，包括位置`i`， 尽管`d2[i]`是之前间隙周围的匹配层数`i`。 
4. 表示一个可能的轴`k = 2alpha`， 在哪里`alpha`是它的角度。 因为一个轴和旋转180度的同一轴是相同的，`k`只需要 0 到 0 之间的值`C-1`。 甚至`k`给出整数轴角度，而奇数`k`给出半整数轴角度。 
5.对于甚至`k`，轴以位置为中心`C + k/2`在双倍数组中。 完整的圆形反射要求距离相等`C/2 - 1`从这个中心。 在 Manacher 的符号中，这正是条件`d1[C + k/2] >= C/2`。 
6.对于奇数`k`，轴位于两个数组位置之间。 它的中心由偶回文索引表示`C + (k+1)/2`。 我们需要`C/2`匹配对，所以条件是`d2[C + (k+1)/2] >= C/2`。 
7. 标记每个`k`满足相应的回文条件作为有效的反射轴。 回文包含整个角圆，因此该测试不仅仅是检查配置的局部部分。 它对照其反射的对应物检查每颗卫星和每一个空角位置。 
8. 扫描双方向角`x`从 0 到`2C-1`。 实际飞行方向为`x/2`弧秒，其反射轴为`k = x mod C`。 如果该轴不对称，则该方向将被拒绝。 如果`x`is odd, the direction is a half-integer angle and cannot contain a satellite. 如果`x`是否为偶数，检查是否`a[x/2]`is empty. 仅发出空方向。 
9. 按升序打印双倍方向角，格式化时除以二。 扫描`x`按升序排列已经给出了所需的排序输出，因此不需要单独排序。 

### 为什么它有效

 对于固定的飞行路线，将每个卫星的位置分解为与该路线平行和垂直的坐标。 其重力的垂直分量与

 [
 \frac{m_i b_i}
 {(t^2-2a_i t+\rho_i^2)^{3/2}},
 ]

 哪里`t`是 Elphaba 沿射线距原点的距离，`a_i`是卫星的平行坐标，并且`b_i`是它的垂直坐标。 每个总和必须消失`t > 0`。 

离轴卫星具有由其平行坐标、距原点的距离和质量决定的奇异贡献。 唯一可能的抵消是来自其穿过线的镜像，因为镜子具有相同的`a_i`和`rho_i`但恰恰相反`b_i`。 取消也要求群众平等。 轴上的卫星有`b_i = 0`并且不贡献垂直力。 因此，加权卫星配置在飞行路线上的反射下必须保持不变。 

角度数组准确地记录了这个配置。 绕双角轴反射`k`地图位置`i`到`k-i`模数`C`，这正是定义循环回文的等式关系。 加倍数组将该循环回文转换为普通回文，Manacher 查找所需的全长回文是否存在。 因此，每个标记的轴都是真正的对称轴，并且每个真正的对称轴都被标记。 

最后的射线检查精确地删除了那些包含卫星的半线。 因此，发射的方向正是物理允许的飞行方向。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

C = 129600
HALF = C // 2

def manacher_odd_even(s):
    n = len(s)

    d1 = [0] * n
    l = 0
    r = -1

    for i in range(n):
        if i > r:
            k = 1
        else:
            k = min(d1[l + r - i], r - i + 1)

        while i - k >= 0 and i + k < n and s[i - k] == s[i + k]:
            k += 1

        d1[i] = k

        k -= 1
        if i + k > r:
            l = i - k
            r = i + k

    d2 = [0] * n
    l = 0
    r = -1

    for i in range(n):
        if i > r:
            k = 0
        else:
            k = min(d2[l + r - i + 1], r - i + 1)

        while i - k - 1 >= 0 and i + k < n and s[i - k - 1] == s[i + k]:
            k += 1

        d2[i] = k

        k -= 1
        if i + k > r:
            l = i - k - 1
            r = i + k

    return d1, d2

def solve():
    n = int(input())

    a = [None] * C

    for _ in range(n):
        rho, phi, mass = map(int, input().split())
        a[phi] = (rho, mass)

    s = a + a
    d1, d2 = manacher_odd_even(s)

    good = [False] * C

    for k in range(C):
        if k & 1:
            center = C + (k + 1) // 2
            if d2[center] >= HALF:
                good[k] = True
        else:
            center = C + k // 2
            if d1[center] >= HALF:
                good[k] = True

    out = []

    for x in range(2 * C):
        k = x % C

        if not good[k]:
            continue

        if x & 1:
            out.append(f"{x / 2:.10f}")
        else:
            phi = x // 2
            if a[phi] is None:
                out.append(f"{phi:.10f}")

    sys.stdout.write(str(len(out)) + "\n")
    sys.stdout.write("\n".join(out))
    if out:
        sys.stdout.write("\n")

if __name__ == "__main__":
    solve()
```第一部分`solve`构造完整的循环序列。 使用`None`是故意的。 这意味着反射的空位置必须与另一个空位置匹配，因此回文检查还会验证所有角度间隙。 

这`manacher_odd_even`函数是标准线性时间奇偶回文计算。 需要它的两个数组，因为轴可以直接穿过整数角位置或两个整数位置之间。 该算法仅使用相等比较，因此可以直接比较卫星元组，而无需将其大坐标转换为浮点数。 

偶轴情况使用`d1`。 为了`k = 2alpha`，重复数组的中心是`C + alpha`，所需半径为`C/2`。 确切的阈值是`HALF`， 因为`d1`将中心本身算作一层，因此半径为`HALF`涵盖从 0 到`HALF-1`。 距离正好的一对`HALF`表示一整圈后的相同角位置，并且不施加任何附加条件。 

奇数轴情况使用`d2`。 这里轴位于两个整数角位置之间，并且正好有`HALF`围绕一个完整的圆有明显的反射对。 因此，所需的偶数回文半径恰好是`HALF`。 

最终扫描使用双倍角度。 这可以避免累积浮点错误，并且还可以免费提供排序输出。 对于奇数倍角，方向是半整数弧秒并且不能与输入卫星重合。 对于偶数倍的角度，相应的整数位置被签入`a`。 

Python 中不存在整数溢出问题。 最大的存储整数大约只有`10^18`，Python 整数无论如何都能准确地处理它。 更重要的是，该算法从不执行三角计算，因此也不执行`rho`也不`phi`需要转换为浮点数。

 ### 示例 1

 两颗卫星占据角度0和64800，具有相同的`(rho, mass)`一对。 除了这两个相反的位置之外，角序列到处都是空的。

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|

## 边缘情况

 第一个边缘情况是包含卫星的对称轴。 为了```

1 0 1
1 64800 1
```检测到 0 处的轴是因为反射向自身发送角度 0，向自身发送角度 64800。 对应的双轴索引为`k = 0`。 在输出扫描期间，方向`x = 0`映射到角度 0，其中`a[0]`已被占用，因此被拒绝。 方向`x = 129600`映射到角度 64800，其中`a[64800]`也被占用，所以被拒绝。 垂直轴幸存并产生 32400 和 97200。 

第二个边缘情况是半整数轴。 为了```
2
1 0 1
1 1 1
```0.5左右的反射交换了两颗卫星。 其双倍轴值为`k = 1`，因此该算法使用偶回文半径。 因为两条射线都有双角 1 和 129601，所以它们是半整数方向。 输入角度不能等于任一方向，因此两个方向都是安全的。 输出为0.5和64800.5。 

第三种边缘情况是质量不等。 为了```
4
1 0 1
1 64800 2
1 32400 3
1 97200 3
```32400 和 97200 处的位置具有相同的标签，但 0 和 64800 处的标签不同。 任何交换这两个位置的反射都会改变质量，因此它不是引力场的对称性。 使两颗不等质量卫星保持固定的唯一几何轴是水平轴，但该轴的两条射线都包含卫星。 最终的答案是空的。 

第四种边缘情况是跨越圆形边界的对称性。 为了```
2
1 129599 7
1 0 7
```两颗卫星在 0 度边界上相邻。 它们的对称轴位于 129599.5，以 64799.5 模 180 度表示。 双数组结构使这个普通的回文结构变得可见。 如果不复制角度序列，该对似乎位于数据结构的两端，并且本地回文实现可能会错过它。 

第五个边缘情况是完全被占据的角圆。 如果从 0 到 129599 的每个整数角度都包含相同的`(rho, mass)`，每个反射轴作为几何对称性都是有效的。 每条整数射线都被阻挡，而每条半整数射线都是清晰的。 正好有 129600 个有效方向，每个半整数角度一个。 该算法在没有任何特殊情况的情况下处理此问题，因为回文测试看到完全一致的序列，并且最终的射线测试恰好删除了占用的整数位置。
