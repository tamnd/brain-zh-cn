 ## 解决方案
 ## 问题理解

 场地是一个网格，其中一些单元格是可用的草单元格，其余的是阻塞的岩石单元格。 莎莉可以垂直跳跃固定距离，`kv`，或水平方向，`kh`，但只有当跳跃穿过的每个单元格都是草时才允许跳跃。 一个完整的动作总是由两次这样的跳跃组成。 

任务是对不同草细胞的有序对进行计数`(a, b)`从哪里开始`a`，莎莉最终可以到达`b`完成一个或多个完整动作后。 答案就是领域的开放性。 

输入包含网格尺寸、两个跳跃长度以及网格本身。 简单版本没有落石，所以我们只需要计算初始开放度。 

网格最多可包含`n * m = 200000`细胞。 虽然`n`和`m`单个单元可能很大，但单元总数对于线性或近线性算法来说足够小。 尝试每对草细胞的解决方案需要`O((nm)^2)`工作，远远超出了极限。 我们只需要处理每个单元和每个可能的跳跃恒定的次数。 

棘手的部分是莎莉的动作是由两次跳跃组成，而不是一次。 通过单个有效跳转连接的单元格在完成移动后不会自动到达。 简单的图形解释可能会错过跳跃次数的奇偶性。 

考虑单行：```
1 3 5
```和`kh = 2`所有的细胞都是草。 一次跳跃可以从一端移动到另一端，但完整的移动需要两次跳跃。 如果一个粗心的解决方案将一次跳跃的同一连接组件中的所有单元都计算为可达，则将包括需要奇数次跳跃的对。 对于这对来说，正确答案是零`(1,3)`如果不存在两个跳转序列。 

Another edge case appears when a component is bipartite. 对于每个有效跳跃都会在两个分区之间改变颜色的网格，只能使用奇数次跳跃才能到达相对侧的单元格。 

例子：```
Input
2 2 1 1
**
**
0

Output
4
```一跳图是一个正方形。 对角需要两次跳跃，但相邻的单元格需要一次跳跃。 有效的有序对只是棋盘颜色相同的单元格之间的四对。 计算整个组件将错误地输出`12`。 

最后一种情况是包含奇数循环的组件。 一旦存在奇数循环，就可以在任意两个顶点之间创建偶数和奇数长度的路径，因此该组件内的所有不同对都变得有效。 

## 方法

 一种直接的方法是构建有效单跳的图表。 每个草细胞都是一个顶点，当莎莉可以一次跳跃在两个细胞之间移动时，一条边连接两个细胞。 然后我们可以从每个顶点运行图遍历，并计算在偶数条边之后哪些顶点是可到达的。 这是正确的，因为完整的运动恰好是该图中的两条边。 

然而，从每个单元格进行遍历太慢了。 对于 200000 个电池，最坏的情况需要大约`200000 * 200000`运营。 

关键的观察是我们不需要单独的可达性查询。 我们只需要连接组件的结构以及每个组件内的路径是否可以具有两个奇偶校验。 

对于一跳图的连通分量，有两种情况。 如果组件是二分的，则每条边都会改变颜色，因此每个偶数长度的路径都保持在相同的颜色类内。 一个细胞可以准确地到达与它自己颜色相同的其他细胞。 如果组件不是二分的，则存在奇数循环，这允许更改路径的奇偶校验。 每个顶点都可以到达其他每个顶点。 

剩下的工作是找到连通分量、检查二分性并计算两个颜色类的数量。 当我们扫描有效跳转时，具有奇偶校验跟踪的不相交集并集可以处理所有三个任务。 

有效的跳跃图本身可以使用岩石上的前缀和在线性时间内生成。 如果起点和目的地之间的单元格中的岩石数量为零，则跳跃有效。

 ## 算法演练

 1. 构建一个前缀和数组，存储网格每个矩形中岩石单元的数量。 这让我们可以在恒定时间内检查跳跃路径是否包含任何岩石。 
2. 创建奇偶不相交集并集结构。 每个草细胞最初都是它自己的组成部分。 存储的奇偶校验表示节点是否与其组件根具有相同或相反的颜色。 
3. 扫描每个草细胞。 尝试长度的向下跳跃`kv`和长度的向右跳跃`kh`。 仅检查这两个方向就足够了，因为每个有效的跳转都是可逆的。 如果目的地存在并且路径畅通，则在奇偶校验 DSU 中的两个单元之间添加一条边。 
4. 处理完所有边后，再次扫描每个草单元并找到其 DSU 根以及相对于该根的奇偶校验。 对于每个组件，计算属于每个奇偶校验类别的单元数量。 
5. 对于每个组件，添加其对答案的贡献。 如果组件不是二分的，则每个有序的不同单元对都可以工作，给出`size * (size - 1)`。 如果是二分的，则只有具有相同奇偶性的单元才能相互到达，给出`cnt0 * (cnt0 - 1) + cnt1 * (cnt1 - 1)`。 

为什么它有效：

 DSU 准确存储单跳图的连通分量。 奇偶校验信息模拟两次着色尝试。 如果一条边曾经连接两个已经具有相同颜色的顶点，则该分量包含奇数循环并且不是二分的。 在二分组件中，每次跳跃都会翻转颜色，因此偶数次跳跃会返回到相同颜色的一侧。 由于莎莉的完整运动包含两次跳跃，因此只能到达相同的奇偶顶点。 在非二分组件中，奇数循环消除了奇偶校验限制，允许顶点之间的路径长度为偶数和奇数。 该公式精确计算所有有效的有序对，同时排除两个单元格相同的对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
        self.par = [0] * n
        self.bad = [False] * n

    def find(self, x):
        if self.parent[x] != x:
            p = self.parent[x]
            self.parent[x] = self.find(p)
            self.par[x] ^= self.par[p]
        return self.parent[x]

    def union(self, a, b):
        ra = self.find(a)
        rb = self.find(b)
        xa = self.par[a]
        xb = self.par[b]

        if ra == rb:
            if xa == xb:
                self.bad[ra] = True
            return

        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
            xa, xb = xb, xa

        self.parent[rb] = ra
        self.par[rb] = xa ^ xb ^ 1
        self.size[ra] += self.size[rb]
        self.bad[ra] |= self.bad[rb]

def solve():
    n, m, kv, kh = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    pref = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n):
        row = 0
        for j in range(m):
            row += 1 if grid[i][j] == '@' else 0
            pref[i + 1][j + 1] = pref[i][j + 1] + row

    def has_rock(r1, c1, r2, c2):
        return (
            pref[r2 + 1][c2 + 1]
            - pref[r1][c2 + 1]
            - pref[r2 + 1][c1]
            + pref[r1][c1]
        ) > 0

    total = n * m
    dsu = DSU(total)

    def idx(r, c):
        return r * m + c

    for i in range(n):
        for j in range(m):
            if grid[i][j] != '*':
                continue

            if i + kv < n and not has_rock(i + 1, j, i + kv, j):
                dsu.union(idx(i, j), idx(i + kv, j))

            if j + kh < m and not has_rock(i, j + 1, i, j + kh):
                dsu.union(idx(i, j), idx(i, j + kh))

    cnt = {}
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '*':
                x = idx(i, j)
                r = dsu.find(x)
                c = dsu.par[x]
                if r not in cnt:
                    cnt[r] = [0, 0]
                cnt[r][c] += 1

    ans = 0
    for r, colors in cnt.items():
        a, b = colors
        if dsu.bad[r]:
            ans += (a + b) * (a + b - 1)
        else:
            ans += a * (a - 1) + b * (b - 1)

    print(ans)

if __name__ == "__main__":
    solve()
```前缀和构造将每个跳转验证转换为恒定时间矩形查询。 向下跳跃查询的矩形从 Sally 下面的一个单元格开始，到目的地结束，与必须保持草地的单元格相匹配。 

DSU 存储连接和颜色信息。 当两个组件合并时，会选择它们的根之间的奇偶性，以便新的边缘连接相反的颜色。 如果一条边与当前颜色相矛盾，则该组件将被标记为非二分组件。 

最终计数阶段不执行任何图搜索。 奇偶校验计数已经包含计算可到达的有序对的数量所需的所有信息。 乘法使用 Python 整数，因此即使结果可能大于 32 位值，也不存在溢出问题。

 ## 边缘情况

 在一次跳跃图中看起来连接的组件仍然可能具有受限的可达性，因为完整的移动需要偶数次跳跃。 完整的 2 x 2 草地示例演示了这一点。 DSU 创建一个组件，但着色将其分成大小为 2 的两组，给出`2 * 1 + 2 * 1 = 4`有效的有序对，而不是计算所有十二个可能的对。 

具有奇数周期的组件消除了奇偶校验限制。 在 2 x 3 全草网格中`kv = 1`和`kh = 1`，单跳图包含奇数长度的循环。 DSU 检测到着色矛盾，将组件标记为非二分组件，并对所有组件进行计数`6 * 5 = 30`如果所有单元都连接，则为有序对。 实现会自动应用此规则。 

单个孤立的草细胞的分量大小为 1。 由于没有不同的目标单元格，因此公式产生零，因此正确排除了自可达情况。 DSU 不需要对这种情况进行任何特殊处理。 

矩形检查还可以正确处理边界附近的跳转。 仅当目标单元位于网格内部时才考虑跳跃，并且前缀和查询仅包含每个交叉单元一次，从而防止岩石周围出现一个错误。
