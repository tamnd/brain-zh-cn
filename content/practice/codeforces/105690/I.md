 ## 解决方案
 ## 问题理解

 游戏包含`n`信封。 信封`i`开始于`a[i]`硬币。 移动选择当前包含相同正数硬币的任何非空信封组，然后从每个选定的信封中恰好取出一枚硬币。 做出最后可能移动的玩家获胜。 

任务是确定第一个玩家 Ai 或第二个玩家 Bo 在双方都处于最佳状态时是否有获胜策略。 

约束是主要线索。 最多可以有`2 * 10^5`信封，每个信封最多可包含`10^9`硬币。 任何对每个硬币执行一次操作的模拟都是不可能的，因为硬币总数可以达到`2 * 10^14`。 我们需要一个解决方案，其工作取决于信封的数量而不是硬币的价值。 

直接实现也无法存储所有可能的硬币数量，因为最大值很大。 解决方案必须压缩高度的结构。 

有些情况很容易打破不正确的方法。 考虑一个装有两枚硬币的信封。```
1
2
```正确答案是`Bo`。 Ai 只能将信封减少到一枚硬币，之后 Bo 拿走最后一枚硬币。 任何将每个信封视为普通 Nim 堆的解决方案都会错误地认为第一个玩家获胜。 

另一个重要的情况是具有相同价值的多个信封。```
2
1 1
```正确答案是`Ai`。 艾可以选择两个信封并一次性取出他们仅有的硬币。 一次只考虑一个信封的策略会错过这种交互。 

最后的边界情况是所有值都相等。```
4
5 5 5 5
```正确的结果是`Bo`。 四个信封一起运行，而不是四个独立的游戏。 选择等高信封的任何子集的能力会改变 Grundy 值。 

## 方法

 暴力方法会尝试对每种可能的游戏状态进行建模。 状态由每个信封中当前硬币的数量确定。 对于每个状态，我们可以生成所有合法的移动，递归地求解结果状态，并使用斯普拉格-格伦迪定理。 这是正确的，因为每次移动都会减少硬币总数，因此游戏图没有循环。 

问题是国家数量巨大。 即使是一个信封`10^9`硬币创造了十亿个国家的链条。 对于许多信封，组合的数量变得无法枚举。 

关键的观察是信封的确切身份并不重要。 重要的是有多少个信封到达了每个高度。 

让`c[h]`是至少有的信封数量`h`硬币。 例如，如果信封包含`1, 3, 3`， 然后：```
h = 1: c[1] = 3
h = 2: c[2] = 2
h = 3: c[3] = 2
```移动会降低某些信封的价值`h`到`h-1`。 按照`c`，它正好减少一个值`c[h]`根据所选信封的数量。 该游戏的 Grundy 值等于：```
c[1] xor c[2] xor c[3] xor ...
```原因是每个级别的行为都类似于 Nim 组件。 一次移动只会改变一个级别的计数，并且该计数的合法范围与 Nim 堆的标准 Grundy 结构相匹配。 

剩下的挑战是`h`可以大到`10^9`。 我们无法遍历每个级别。 相反，按降序对信封高度进行排序。 两个连续高度之间的值`c[h]`保持不变。 

假设排序后的值是：```
a1 >= a2 >= ... >= an
```适合所有级别`h`在范围内：```
a[i+1] < h <= a[i]
```确切地`i`信封至少有`h`硬币。 出现该值`a[i] - a[i+1]`次异或。 如果该长度是奇数，则贡献为`i`，否则会抵消。 

暴力破解之所以有效，是因为它直接遵循游戏规则，但会失败，因为状态空间随着硬币数量的增加而增长。 级别计数观察将所有相同的行为压缩为`n`间隔。

 ## 算法演练

 1. 按降序对所有包络值进行排序。 附加最终值`0`这样每个高度区间都有一个正确的边界。 
2. 对于每个位置`i`从`0`到`n-1`，考虑之间的高度`a[i+1] + 1`和`a[i]`。 在这个整个范围内，恰好`i + 1`信封至少装有那么多硬币。 
3. 计算该范围的大小为`a[i] - a[i+1]`。 如果这个数字是奇数，则将答案与`i + 1`。 如果它是偶数，则这种贡献消失，因为相同的数字被异或偶数次。 
4、处理完每个区间后，得到的异或值就是起始位置的Grundy数。 非零值意味着第一个玩家有获胜的动作，而零则意味着每次动作都会导致失败状态。 

为什么它有效：

 不变量是到达每个可能高度的信封数量的异或。 合法的移动仅更改一个高度层，因此 Grundy 值的行为与 Nim 位置完全相同。 如果异或为零，则每一步可能的操作都会将其更改为非零值，从而使对手处于获胜位置。 如果异或非零，则存在使异或为零的移动，从而为当前玩家提供获胜策略。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    a.sort(reverse=True)
    a.append(0)

    grundy = 0

    for i in range(n):
        if (a[i] - a[i + 1]) & 1:
            grundy ^= i + 1

    print("Ai" if grundy else "Bo")

if __name__ == "__main__":
    solve()
```输入被读取一次，因为整个问题仅取决于包络值的初始多重集。 

排序将相等且接近的高度放在一起，这允许将级别计数表示作为间隔而不是单个硬币级别进行处理。 

附加的零是边界值。 如果没有它，最后一组高度将不会有下限端点，并且将错过最终的间隔贡献。 

索引是`i + 1`而不是`i`因为第一个`i + 1`信封恰好是至少与当前间隔内的每个高度一样高的信封。 

Python 整数是任意精度的，因此值可达`10^9`不需要特殊处理。

 ## 边缘情况

 对于装有两枚硬币的一个信封：```
1
2
```排序后的数组是`[2, 0]`。 唯一的区间有长度`2`，它是偶数，因此它对异或没有任何贡献。 Grundy 值为零，算法输出`Bo`，与第二个玩家拿走最后一枚硬币的事实相匹配。 

对于两个信封和一枚硬币：```
2
1 1
```排序后的数组是`[1, 1, 0]`。 唯一的非空区间有长度`1`，达到该高度的信封数量为`2`。 异或变为`2`，所以算法输出`Ai`。 获胜的举动是立即选择两个信封。 

对于具有相同值的所有信封：```
4
5 5 5 5
```只有最后一个间隔有贡献，因为早期间隙的长度为零。 贡献是`4`，这意味着只有当异或变为零时，仓位才会亏损。 这里的异或非零，因此算法正确地识别了获胜玩家。 这种情况证实了相等的高度是通过组计数而不是独立的包络计算来处理的。
