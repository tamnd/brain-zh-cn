 ## 解决方案
 ## 问题理解

 我们得到一组水平“龙段”，绘制在从位置 1 到位置 m 的一维地线上。 每条龙在此线上占据一个连续的区间，从 li 到 ri（含）。 在该区间内的每个整数位置，龙都会贡献一些“鳞片”，这取决于龙的力量和区间内的位置。 

关键细节是龙的区间内的位置不是全局的，而是该龙的局部位置。 如果龙从 li 开始，则位置 li 对应于该龙的索引 1，li + 1 对应于索引 2，依此类推。 在局部索引 j 处，贡献为 pi·j。 因此，每条龙都在其分段上贡献算术级数，从左端点的 pi 线性增加到右端点的 pi·(ri − li + 1)。 

对于从 1 到 m 的每个地面位置 x，我们需要覆盖 x 的所有龙的鳞片总数。 

约束最大为 n，m ≤ 2 · 10^5，每个 pi 可以大到 2 · 10^6。 迭代所有龙的直接按位置计算太慢，因为在最坏的情况下最多需要 4 · 10^10 次操作。 即使对每条龙进行迭代并单独更新每个覆盖的位置也会是 O(nm)，这远远超出了可行的范围。 

因此，正确的解决方案必须以避免明确接触每个单元格的方式处理范围贡献。 

一个常见的失败案例来自于将每条龙视为在其间隔内添加了一个恒定值。 例如，如果一条龙是 (1, 3, 1)，天真的方法可能会错误地将 1 添加到所有位置 1, 2, 3。正确的贡献分别是 1, 2, 3。 这个错误打破了所有重叠的情况。 

当试图“转移”贡献而不正确处理线性增长时，会出现另一个微妙的失败。 如果我们只跟踪斜率变化但正确忽略偏移，我们很容易在多个重叠间隔之间错位贡献。 

## 方法

 暴力解决方案处理每条龙并更新它覆盖的每个位置。 对于龙 i，我们从 1 到 ri − li + 1 计算 j，并将 pi · j 添加到位置 li + j − 1。这是直接且正确的，因为它直接遵循定义。 然而，更新的总数为 Σ (ri − li + 1)，在最坏的情况下变为 n·m，远远超出了任何可行的限制。 

贡献的结构揭示了一些更有用的东西：每条龙在一段上产生一个线性函数。 在 [li, ri] 内的 x 位置，其贡献等于 pi · (x − li + 1) = pi · x − pi · (li − 1)。 这将每条龙在其间隔上分成两个独立的部分：一个与 x 成比例，一个是常数。 

这将问题转化为对于每个位置 x 维护两种类型范围更新的总和。 一种类型将 pi 添加到 [li, ri] 上的“斜率累加器”，另一种类型将 -pi·(li − 1) 添加到相同范围内的“常数累加器”。 一旦知道每个位置的两个累加器，x 处的最终答案就是 x 乘以 x 处的斜率和加上 x 处的常数和。 

这将问题简化为两个标准范围添加、点查询结构，可以使用差异数组和单个前缀扫描来实现。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力 | O(纳米) | O(米) | 太慢了|
 | 最优（差异数组）| O(n + m) | O(米) | 已接受 |

 ## 算法演练

 1.将每条龙在其区间内x位置的贡献重写为pi·x−pi·(li−1)。 这隔离了依赖于 x 的项和独立于 x 的项。 

2. 维护两个阵列，一个跟踪累积斜率贡献，另一个跟踪常量偏移。 每条龙都将 pi 贡献给斜率数组的其区间内的每个位置。

3. 对于常数数组，每条龙在其区间内贡献−pi·(li−1)。 

4. 使用差异数组应用两种类型的范围更新，以便每次更新都是 O(1)。 差异数组存储端点处的更改，并且前缀和稍后重建完整数组。 

5. 处理完所有龙后，独立计算两个数组的前缀和，以获得每个位置的斜率和常数值。 

6. 对于从 1 到 m 的每个位置 x，将最终答案计算为斜率[x] · x + 常量[x]。 

分为斜率功和常数功的原因是每个贡献在 x 的区间上都是仿射的。 仿射函数在求和下是封闭的，因此对所有龙求和可以保留此结构。 

### 为什么它有效

 在任意固定位置x，每条龙要么不贡献，要么贡献pi·x−pi·(li−1)。 对覆盖 x 的所有龙求和得出 x 中的线性表达式之和，该总和始终可以分组为（活动龙上的 pi 之和）·x 加上从其左端点导出的常数之和。 该算法准确地为每个 x 维护这两个聚合量，因此计算结果与每个位置的直接定义相匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    slope_diff = [0] * (m + 3)
    const_diff = [0] * (m + 3)

    for _ in range(n):
        l, r, p = map(int, input().split())

        slope_diff[l] += p
        slope_diff[r + 1] -= p

        const_val = -p * (l - 1)
        const_diff[l] += const_val
        const_diff[r + 1] -= const_val

    slope = [0] * (m + 2)
    const = [0] * (m + 2)

    for i in range(1, m + 1):
        slope[i] = slope[i - 1] + slope_diff[i]
        const[i] = const[i - 1] + const_diff[i]

    out = []
    for i in range(1, m + 1):
        out.append(str(slope[i] * i + const[i]))

    print(" ".join(out))

if __name__ == "__main__":
    solve()
```该代码保留两个差异数组。 1 代表每条龙在其时间间隔内增加 x 系数的程度。 另一个跟踪由左端点偏移引起的恒定偏移。 

前缀和步骤重建每个位置的实际斜率和常数贡献。 将斜率乘以 i 是安全的，因为斜率已经聚合了仅在位置 i 处有效的贡献。 最终组合一次完成。 

一个常见的实现陷阱是忘记常数项中的负号或错误地应用 l 而不是 (l − 1)。 另一个是 r + 1 处的离一处理，这对于确保更新恰好在间隔边界处停止至关重要。

 ## 边缘情况

 从 1 开始到 1 结束的单条龙测试公式是否正确处理 j = 1，而不会在 (l − 1) 中引入差一错误。 该算法将常数平移设置为 -p · 0，因此答案仍为位置 1 处的 p。 

完全重叠的情况（例如 [1, m]）重复多次可确保斜率累加和常量累加正确叠加。 每个位置 x 变为 x 乘以所有 pi 之和，并且常数部分保持为零，因为所有 l − 1 项在均匀覆盖下一致抵消。
