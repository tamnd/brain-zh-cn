 ## 解决方案
 ## 问题理解

 我们得到了排列成固定行的一系列舞者，每个舞者都有一个高度。 从这条线开始，我们想要形成一个子序列（保持原始顺序），它将在“舞龙”中表演。 

限制是局部的：当最终阵容中两个相邻的选定舞者并排站立时，他们的身高差异不得超过给定阈值\(k\)。 如果差值超过\(k\)，在最终选择中不允许出现这种邻接。 

任务是选择最大可能长度的子序列，使得该子序列中的每个连续对都满足此高度差约束。 

输入提供\(n\)，舞者的数量，以及\(k\)，最大允许高度差。 第二行按原始顺序给出高度。 输出是一个整数：最长的有效子序列长度。 

约束条件\(n \le 2 \cdot 10^5\)排除任何二次或三次方法。 任何尝试使用动态编程转换来测试所有子序列甚至所有位置对的解决方案都将超出时间限制。 我们正在寻找线性或接近线性的结构，通常是在我们扫描阵列时可以增量维护的结构。 

一种经常失败的天真的解释是将其视为全局范围问题，例如按高度排序或贪婪选择。 这打破了排序约束，因为不允许重新排序。 

另一个微妙的问题是假设一旦本地形成有效的链，它总是可以贪婪地扩展。 如果局部最优步骤由于不兼容的间隙而阻塞更长的未来链，则这是错误的。 

例如，如果\(k = 2\)和高度是\([1, 10, 2, 3, 4]\), 采摘\(1 \to 2 \to 3 \to 4\)是最优的，但是天真贪婪的选择\(1 \to 10\)立即提前打破序列并阻止进一步的有效扩展。 

## 方法

 蛮力的想法是计算在每个位置结束的最长有效子序列。 对于每个位置\(i\)，我们检查所有之前的位置\(j < i\)，如果\(|h_i - h_j| \le k\)，我们可以扩展一个结束于的有效链\(j\)。 这导致了标准的动态规划公式：\[
dp[i] = 1 + \max(dp[j]) \quad \text{over all } j < i \text{ with } |h_i - h_j| \le k.
\]这是正确的，因为它明确地探索了所有有效的前身。 问题在于性能：每个状态可能会扫描 \(O(n)\) 先前的状态，从而导致 \(O(n^2)\) 转换，这大约是\(4 \cdot 10^{10}\)在最坏的情况下运作，远远超出极限。 

关键的观察结果是，转换条件仅取决于高度值，而不取决于位置结构。 对于固定高度\(h_i\)，我们只关心高度位于区间内的较早元素\([h_i - k, h_i + k]\)。 这会将 DP 转换转换为对值的范围查询。 

我们没有扫描所有先前的索引，而是维护一个支持两种操作的高度数据结构：在处理元素时插入 dp 值，以及查询高度范围内的最佳 dp 值。 这正是高度坐标压缩后的 Fenwick 树或线段树的情况。 

我们从左到右处理舞者。 对于每个高度，我们查询以兼容高度范围结尾的最佳子序列，然后将其扩展 1。在计算当前位置的 dp 后，我们将其插入结构中，以便将来的位置可以使用它。 

这减少了从线性扫描到对数查询的每次转换。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 对所有对进行暴力 DP | \(O(n^2)\) | \(O(n)\) | 太慢了|
 | DP + 线段树超高度 | \(O(n \log n)\) | \(O(n)\) | 已接受 |

 ## 算法演练

 1. 将所有高度压缩到更小的坐标系中。 这是必要的，因为高度可达\(10^9\)，我们需要将它们映射到一个紧凑的索引范围，同时保留顺序。 

2. 构建一个线段树（或 Fenwick 树变体），为每个高度索引存储迄今为止该高度实现的最大 dp 值。 

3. 初始化一个大小为n的数组dp。 每个 dp[i] 代表结束于位置 i 的最佳有效子序列。 

4. 从左到右扫描舞者。 对于每个舞者 i，确定与高度对应的压缩指数范围\([h_i - k, h_i + k]\)。 该范围代表可以连接到 i 的所有有效前驱。 

5. 在此范围内查询线段树，以获取先前有效高度中迄今为止看到的最大 dp 值。 如果不存在有效的前任，则结果为 0。 

6. 将 dp[i] 设置为该值加 1，因为我们扩展了在允许范围内结束的最佳有效子序列。 

7. 更新压缩索引处的线段树\(h_i\)与 dp[i] 一起，确保未来的职位可以在此基础上发展。 

最终的答案是 dp 的最大值。 

### 为什么它有效

 在扫描中的任何点，线段树都会存储所有先前处理的舞者中以每个高度结束的最佳子序列。 DP 转换仅考虑那些可以合法先于当前高度的先前状态，而不考虑其他状态。 由于我们从左到右处理，树中的所有候选者按位置顺序都是有效的，并且高度约束是通过范围查询强制执行的。 这确保每个 dp[i] 代表以 i 结尾的最佳子序列，并且不会跳过任何有效的转换。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, n):
        self.n = n
        self.t = [0] * (4 * n)

    def update(self, v, l, r, i, val):
        if l == r:
            if val > self.t[v]:
                self.t[v] = val
            return
        mid = (l + r) // 2
        if i <= mid:
            self.update(v * 2, l, mid, i, val)
        else:
            self.update(v * 2 + 1, mid + 1, r, i, val)
        self.t[v] = max(self.t[v * 2], self.t[v * 2 + 1])

    def query(self, v, l, r, ql, qr):
        if qr < l or r < ql:
            return 0
        if ql <= l and r <= qr:
            return self.t[v]
        mid = (l + r) // 2
        return max(
            self.query(v * 2, l, mid, ql, qr),
            self.query(v * 2 + 1, mid + 1, r, ql, qr)
        )

n, k = map(int, input().split())
h = list(map(int, input().split()))

vals = sorted(set(h))
idx = {v: i for i, v in enumerate(vals)}

seg = SegTree(len(vals))
ans = 0

for i in range(n):
    hi = h[i]
    left_val = hi - k
    right_val = hi + k

    l = 0
    r = len(vals) - 1

    while l <= r:
        mid = (l + r) // 2
        if vals[mid] < left_val:
            l = mid + 1
        else:
            r = mid - 1
    L = l

    l = 0
    r = len(vals) - 1
    while l <= r:
        mid = (l + r) // 2
        if vals[mid] <= right_val:
            l = mid + 1
        else:
            r = mid - 1
    R = r

    best = 0
    if L <= R:
        best = seg.query(1, 0, len(vals) - 1, L, R)

    dp = best + 1
    seg.update(1, 0, len(vals) - 1, idx[hi], dp)
    ans = max(ans, dp)

print(ans)
```线段树用作压缩高度值的最大范围结构。 二分搜索将数字约束转换为压缩数组中的索引范围。 每次更新都会插入以给定高度结束的最佳链，每个查询都会检索最佳的可扩展链。 

一个常见的错误是在查询之前更新，这会错误地允许当前元素扩展自身。 正确的顺序是先查询，再更新。 

另一个微妙之处是处理空查询范围，它必须返回 0 来表示从当前位置开始的新子序列。

 ## 边缘情况

 一种边缘情况是当所有高度都落在相对于\(k\)。 用于输入`5 100`和`1 2 3 4 5`，每一对都是兼容的，并且该算法有效地简化为简单的递增 DP，其中每个位置扩展了先前的最大值，产生 5。 

另一个边缘情况是当\(k = 0\)。 只有相等的高度才能连接，因此最佳子序列由相同值的出现频率决定。 线段树自然会处理这个问题，因为查询范围会折叠为单个压缩索引。 

第三种情况是孤立的尖峰，例如`1 100 2 3 4`与小\(k\)。 100 处的峰值会重置链，但后面的值仍然可以形成独立于它的长子序列。 DP 正确重新启动，因为其查询范围内没有有效的前驱。
