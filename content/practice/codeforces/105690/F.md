 ## 解决方案
 ## 问题理解

 我们有一排灯笼。 灯笼`i`有高度`a[i]`，龙在选定的灯笼上出发。 只有当两个灯笼在跳跃时高度相同时，他才能跳到相邻的灯笼。 

龙可以改变他当前站立的灯笼的高度。 高度增加一会消耗一份能量，而高度减少一会返还一份能量。 任务是找到每个查询起始位置所需的最小初始能量，以便龙最终能够访问每个灯笼。 灯笼高度也可以在查询之间更新。 问题在每次更新或起始位置查询后要求答案。 

约束允许最多`2 * 10^5`灯笼和`2 * 10^5`事件。 扫描所有灯笼以查找每个查询的解决方案需要大约`4 * 10^10`在最坏的情况下进行操作，这远远超出了典型的比赛时间限制。 我们需要更新和查询都在对数时间左右，这意味着维护数组上的数据结构。 

主要的边缘情况来自于将当前灯笼高度与其原始高度混淆，以及忘记启动灯笼本身可以通过降低来提供能量。 

例如，与：```
2 1
5 10
1 1
```答案是`5`。 龙从第一盏灯开始，从`5`到`10`没有能量是不可能的，所以他需要`5`能量来举起它并跳跃。 仅检查相邻灯笼之间差异的解决方案可能会忽略第一次移动具有直接成本。 

另一个例子是：```
3 1
10 5 10
1 2
```答案是`5`。 中间的灯笼比两侧的灯笼低，所以龙在跳跃之前需要足够的能量来升起它。 仅检查一侧的粗心解决方案可能会返回`0`错误地。 

最终的边界情况是单个灯笼：```
1 1
100
1 1
```答案是`0`，因为没有要执行的跳跃。 任何查询空左范围或右范围而不对其进行处理的实现都可能会失败。 

## 方法

 暴力法是模拟龙的运动。 从选定的灯笼开始，我们可以尝试不同的顺序访问左侧和右侧，跟踪每次跳跃需要多少能量。 这是正确的，因为可以直接检查每个有效的运动序列。 然而，它太慢了。 和`n = 2 * 10^5`，单个查询可以检查所有灯笼，并重复此操作`q = 2 * 10^5`查询给出二次行为。 

关键的观察结果是，穿过阵列一侧的运动具有简单的能量需求。 

假设龙从位置开始`p`并且只向右走。 到达灯笼前`i + 1`，之前的每一次跳跃都会将当前灯笼更改为下一个灯笼的高度。 到达灯笼后的总能量变化`i`正是`a[p] - a[i]`。 为了进行下一次跳跃，龙必须有足够的能量来举起当前的灯笼，如果`a[i + 1]`更高。 结合这些值表明，唯一重要的是该侧遇到的最高灯笼高度。 

到达右侧每个灯笼所需的能量为：`max(0, maximum height on positions p+1 through n - a[p])`左侧是对称的：`max(0, maximum height on positions 1 through p-1 - a[p])`龙必须处理两边，所以答案是这两个值中较大的一个。 这将问题减少到具有点更新的最大查询范围。 线段树存储每个区间的最大高度，为这两个操作提供对数时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个查询 O(n) | O(1) | O(1) | 太慢了|
 | 最佳| 每次操作 O(log n) | O(n) | 已接受 |

 ## 算法演练

 1. 构建一棵线段树，其中每个节点存储其区间内的最大灯笼高度。 靶场所需的唯一信息是其最高的灯笼。 
2. 对于更新查询，替换线段树中所选灯笼的值，并重新计算到根的路径上的最大值。 
3. 对于起始位置查询`p`，获取左侧所有灯笼的最大高度`p`。 
4. 获取右边所有灯笼的最大高度`p`。 
5. 计算每一面所需的能量。 如果一侧的最大高度为`mx`，龙需要`max(0, mx - a[p])`能量到达那一边。 
6. 返回两侧要求中较大的一个，因为最终必须访问两侧。 

为什么它有效：

 在朝一个方向行走时，每次跳跃都会有效地将高度差转化为龙的能量平衡。 到达任何灯笼后可用的总能量仅取决于起始高度和当前灯笼的高度。 最大的障碍总是必须到达的最高的灯笼，因为到达更高的灯笼是唯一需要消耗能量的情况。 线段树准确返回两个方向的最高障碍物，因此计算值是可能的最小初始能量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SegmentTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.tree = [0] * (4 * self.n)
        self.build(1, 0, self.n - 1, arr)

    def build(self, node, left, right, arr):
        if left == right:
            self.tree[node] = arr[left]
            return
        mid = (left + right) // 2
        self.build(node * 2, left, mid, arr)
        self.build(node * 2 + 1, mid + 1, right, arr)
        self.tree[node] = max(self.tree[node * 2], self.tree[node * 2 + 1])

    def update(self, node, left, right, pos, value):
        if left == right:
            self.tree[node] = value
            return
        mid = (left + right) // 2
        if pos <= mid:
            self.update(node * 2, left, mid, pos, value)
        else:
            self.update(node * 2 + 1, mid + 1, right, pos, value)
        self.tree[node] = max(self.tree[node * 2], self.tree[node * 2 + 1])

    def query(self, node, left, right, ql, qr):
        if ql > right or qr < left:
            return -1
        if ql <= left and right <= qr:
            return self.tree[node]
        mid = (left + right) // 2
        return max(
            self.query(node * 2, left, mid, ql, qr),
            self.query(node * 2 + 1, mid + 1, right, ql, qr)
        )

def solve(data):
    it = iter(data.split())
    n = int(next(it))
    q = int(next(it))
    a = [int(next(it)) for _ in range(n)]

    seg = SegmentTree(a)
    ans = []

    for _ in range(q):
        t = int(next(it))
        if t == 1:
            p = int(next(it)) - 1
            left_max = seg.query(1, 0, n - 1, 0, p - 1)
            right_max = seg.query(1, 0, n - 1, p + 1, n - 1)

            need = 0
            if left_max != -1:
                need = max(need, left_max - a[p])
            if right_max != -1:
                need = max(need, right_max - a[p])

            ans.append(str(max(0, need)))
        else:
            p = int(next(it)) - 1
            x = int(next(it))
            a[p] = x
            seg.update(1, 0, n - 1, p, x)

    return "\n".join(ans)

def main():
    data = sys.stdin.read()
    print(solve(data))

if __name__ == "__main__":
    main()
```线段树只存储最大值，因为每个查询都要求阻止移动的最大高度。 更新操作会更改一个灯笼并刷新受影响的间隔。 

查询使用`-1`作为空范围标记。 由于所有灯笼高度都是非负的，因此该值不能与真实的灯笼高度混淆。 决赛`max(0, need)`处理相关侧的每个灯笼都低于起始灯笼的情况，这意味着龙可以通过降低起始灯笼来获得足够的能量。 

所有索引都会立即转换为从零开始的索引。 范围`0`到`p - 1`和`p + 1`到`n - 1`代表起始灯笼的两侧，避免意外包含起始位置。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(log n) | 每次更新和每个范围最大查询都遵循线段树的一条路径。 |
 | 空间| O(n) | 树中每个灯笼包含固定数量的节点。 |

 这些限制需要处理数十万次操作。 对数运算使总工作保持不变`n log n + q log n`，它完全符合预期的限制。

 ## 边缘情况

 对于这个案例：```
2 1
5 10
1 1
```线段树返回`10`作为右侧的最大高度。 起始高度为`5`，所以所需能量为`10 - 5 = 5`。 该算法正确捕获了第一次跳跃成本。 

对于这个案例：```
3 1
10 5 10
1 2
```左右最大值都是`10`。 起始灯笼有高度`5`，所以双方都需要`5`活力。 结果是`5`，这是移动前中间灯笼升起所需的量。 

对于这个案例：```
1 1
100
1 1
```两个范围查询都返回空标记，因为没有相邻的灯笼。 该算法将答案保留在`0`，这与不需要移动的事实相匹配。
