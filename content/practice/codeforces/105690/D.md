 ## 解决方案
 ## 问题理解

 走廊是一系列的柱子。 柱子`i`包含`k_i`垂直堆叠的平台，以及所有`n`舞者必须站在该列的不同平台上。 舞者是按身高排序的，所以舞者`1`必须始终是占用最低的平台和舞者`n`必须始终是最高的占用平台。 任务是计算有多少次完整的表演是可能的，其中一次表演是每列中舞者位置的选择。 

对于单列`k_i`平台，唯一真正的决定是哪个`n`平台位置已被占用。 一旦选择了这些位置，排序规则就会自动将最低选择的位置分配给舞者`1`，下一位舞者`2`， 等等。 该列的可能性数就是选择的方式数`n`职位来自`k_i`，这是二项式系数`C(k_i, n)`。 

列之间不会互相影响。 舞者只需保持每一列中的顺序，并且没有限制将一列中所选的平台连接到下一列中所选的平台。 表演总数是每列选择数的乘积。 

约束是围绕这一观察而设计的。 列数可达`100000`， 尽管`n`至多是`100`。 试图枚举舞者位置或模拟所有可能的排列的解决方案是不可能的，因为即使是单个列也可能具有大量的有效状态。 我们需要一种在恒定或非常短的时间内处理每一列的方法。 自从`n`很小，用短循环计算组合就足够了。 

一些边缘情况可能会破坏粗心的实现。 什么时候`n = 1`，每一列都准确贡献`k_i`可能性，因为单个舞者可以站在任何地方。 例如：```
Input:
1 3
2 5 4

Output:
40
```将排序规则视为需要特殊排列的解决方案可能会错误地输出较小的值，但答案很简单`2 * 5 * 4`。 

当一列恰好有`n`平台，必须使用每个平台，并且该列仅提供一个选择。 例如：```
Input:
3 2
3 5

Output:
10
```第一栏贡献`C(3,3) = 1`，而第二个贡献`C(5,3) = 10`。 忘记这种情况可能会导致不必要的减法或错误地假设总是有多种选择。 

大值也需要小心。 一个列可以有`100000`平台，因此阶乘高达`100000`可以使用，但前提是正确处理模逆计算。 自从`n`只是`100`，用最多的乘积计算每个组合`100`术语避免了不必要的复杂性。 

## 方法

 直接蛮力方法是生成每一个可能的集合`n`每列占用的平台，然后跨列组合这些选择。 这是正确的，因为每个有效性能都是每列平台的一个选择。 然而，一栏中的选择数量已经是`C(k_i, n)`。 和`k_i = 100000`和`n = 50`，这个数字远远超出了任何可以枚举的范围。 暴力方法需要处理天文数字的状态。 

关键的观察是舞者的身份并没有增加额外的选择。 一旦选择了一组平台，排序规则就会强制进行分配。 一个列与`k_i`平台仅提供组合值，而不提供排列值。 

这将整个问题变成了独立贡献的倍增。 因为`n`很小，我们可以计算`C(k_i, n)`直接作为：`k_i * (k_i - 1) * ... * (k_i - n + 1) / n!`除法必须以模进行`1e9 + 7`，所以我们预先计算模逆`n!`并将每个列的贡献乘以它。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(C(k_i, n) 的乘积) | O(C(k_i, n) 的乘积) | 太慢了|
 | 最佳| O(m * n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读`n`,`m`，以及所有列的高度。 答案是通过一次考虑一列来构建的，因为每个列的选择都是独立的。 
2. 计算`n!`模数`1e9 + 7`并使用快速求幂求其模逆。 每个组合计算都需要除以`n!`，模逆提供了模算术下的等效运算。 
3. 对于每个柱高`k_i`，计算选择占用平台的方式数量。 开始于`1`并乘以`n`连续值来自`k_i - n + 1`通过`k_i`。 然后乘以`n!`。 
4. 将此列贡献乘以全局答案模`1e9 + 7`。 乘法是有效的，因为在一列中选择平台永远不会限制另一列中的选择。 
5. 打印最终产品。 

工作原理：对于每一列，该算法都会精确计算可能被占用的平台集。 排序条件不会产生额外的可能性，因为每个选定的组都具有从最低平台到最高平台的舞者分配。 由于完整的性能包括为每一列独立选择一个有效状态，因此乘法规则给出了准确的性能数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7

def mod_pow(a, b):
    res = 1
    while b:
        if b & 1:
            res = res * a % MOD
        a = a * a % MOD
        b >>= 1
    return res

def solve():
    n, m = map(int, input().split())
    k = list(map(int, input().split()))

    fact = 1
    for i in range(1, n + 1):
        fact = fact * i % MOD

    inv_fact = mod_pow(fact, MOD - 2)

    ans = 1
    for height in k:
        cur = 1
        for x in range(n):
            cur = cur * (height - x) % MOD
        cur = cur * inv_fact % MOD
        ans = ans * cur % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```阶乘计算仅达到`n`，而不是最大柱高。 这是故意的，因为`n`为选择的平台数量，公式只需分母`n!`。 

模逆是用费马小定理计算的，因为`1e9 + 7`是素数。 指数`MOD - 2`给出的倒数`n!`在模运算下。 

对于每一列，循环精确相乘`n`价值观。 第一个值是`height`，下一个是`height - 1`， 等等。 这直接构造了组合公式的分子。 范围在之后停止`n`值，因此不存在相差一的错误。 

Python 整数不会溢出，但每次乘法都会减少模数`MOD`立即保持值较小并匹配所需的算术。

 ## 边缘情况

 当只有一名舞者时，组合公式变为`C(k_i, 1) = k_i`。 对于输入：```
1 3
2 5 4
```该算法计算列贡献`2`,`5`， 和`4`。 该产品是`40`，与舞者在每一列中独立选择一个平台的事实相匹配。 

当一个柱子的平台与舞者的数量完全相同时，每个平台都必须被占用。 为了：```
3 2
3 5
```第一列给出`C(3, 3) = 1`。 第二个给出`C(5, 3) = 10`。 该算法将这些值相乘并返回`10`。 

当每列的高度等于`n`，每一个动作都是被迫的。 为了：```
2 4
2 2 2 2
```每列贡献`C(2, 2) = 1`，所以最终答案仍然是`1`。 这证实了该算法不会意外地将不同的舞者分配计为单独的表演。
