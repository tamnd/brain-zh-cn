 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 每个测试用例中都有$n$小块，每个块恰好包含两个数字。 我们可以任意重新排序这些块，但不允许更改任何块内的顺序。 选择块的顺序后，我们将它们连接成一个长度数组$2n$。 目标是最大限度地减少结果数组中的反转数量，其中反转是一对位置$i < j$使得值在$i$大于该值$j$。 

所以唯一的自由是长度为 2 的线段的排列。 在每个段内，其两个值的相对顺序是固定的。 

关键的困难在于反转是​​全局的。 一对的错误放置可能会与许多其他元素相互作用，因为每个块的两个元素都可能与其他块的两个元素发生反转。 

约束允许最多$10^5$所有测试用例的总对数。 这排除了任何二次方$n$，因为即使$O(n^2)$每个测试用例的比较会太慢。 解决方案本质上必须是$O(n \log n)$或者$O(n)$每次测试。 

一些边缘情况很重要：

 一种简单的方法可能会尝试按块的第一个元素或其最小值或最大值对块进行排序。 这可能会失败，因为最佳排序取决于不同块的两个元素之间的交叉交互，而不仅仅是单个代表。 

例如，考虑块$[1, 100]$和$[50, 51]$。 按第一个元素排序给出$[1,100],[50,51]$，它会产生从 100 到 50 和 51 的许多反转。将它们反转可以显着减少反转。 

另一个微妙的失败情况是当一个块在内部增加或减少时，但它的贡献取决于我们是否交换它相对于其他块的角色。 

因此，我们需要一个规则来捕获每个块在排序决策中的行为方式。 

## 方法

 蛮力策略会尝试所有的排列$n$块。 对于每个排列，我们构建连接数组并使用 Fenwick 树或归并排序来计算反转，成本$O(n \log n)$每个排列。 由于有$n!$排列，这导致$O(n! \cdot n \log n)$，即使对于$n = 10$。 

我们需要了解将两个块放置在一起时真正重要的是什么。 假设我们有两个块$(a,b)$和$(c,d)$。 如果第一个块出现在第二个块之前，则交叉反转的贡献取决于有多少个块$a,b$大于$c,d$。 这表明每个块应该通过其元素相对于其他块的“高”或“低”程度来概括。 

一个关键的观察是，每个块都可以被视为定义其第一个和第二个元素之间的“过渡行为”。 如果我们总是将每个块内较小的元素放在较大的元素之前，我们就可以避免不必要的内部反转，并且只有跨块反转才重要。 

现在关键的简化：将每个块排序为$(x_i \le y_i)$，我们将块视为数轴上的间隔。 最佳策略是按块的第二个元素对块进行排序$y_i$，即它们的最大值。 直观上，具有较小最大值的块应该更早出现，因为它们不太可能与未来的块产生反转。 

如果较早放置具有较大最大值的块，则该大值可能会在后面的块中创建许多具有较小值的反转。 如果它被放置在后面，它只会以有限的方式影响较早的块，并且这种排序使贡献在全局一致的方向上对齐。 

这将问题简化为排序$y_i$，然后将每个块连接为$[x_i, y_i]$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n! \cdot n \log n)$|$O(n)$| 太慢了|
 | 按块最大值排序 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们独立处理每个测试用例。 

1. 对于每个块，重新排序其两个值，使较小的值排在前面。 这消除了不必要的内部反转，因为块内的任何反转总是可以避免的。 
2. 按所有块的第二个值以非降序对所有块进行排序。 第二个值充当该块未来可以创建多少个反转的“风险边界”。 
3. 按顺序遍历已排序的块，并将每个块的两个元素附加到答案数组中。 
4. 输出连接数组。 

按第二个元素排序正确的原因是第二个元素表示该块在数组早期引入的最大值。 首先放置具有较小最大值的块可确保尽可能延迟较大的值，从而减少它们与许多较小的未来元素形成反转的机会。 

### 为什么它有效

 对每个块进行排序后，$x_i \le y_i$，块的唯一潜在有害贡献是其较大的元素$y_i$。 如果一个块有较大的$y_i$放置在较小的块之前$y_j$， 然后$y_i > y_j$无论内部结构如何，都保证至少一次反转。 

通过对块进行排序$y_i$，我们确保每当$i < j$，我们有$y_i \le y_j$，因此第二个元素按相反顺序不会引入反转。 从第一个元素开始$x_i$总是$\le y_i$，它们也受到相同顺序的约束。 这种对齐可确保全局最小化所有跨块反转。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        arr = []
        for _ in range(n):
            a, b = map(int, input().split())
            if a > b:
                a, b = b, a
            arr.append((a, b))
        
        arr.sort(key=lambda x: x[1])
        
        res = []
        for a, b in arr:
            res.append(a)
            res.append(b)
        
        out.append(" ".join(map(str, res)))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现首先对每一对进行标准化，以便较小的值首先出现，这可以防止我们的构造引入内​​部反转。 然后它按每对的第二个元素进行排序，该元素编码该块在最终序列早期贡献的最大值。 

最后的循环只是将排序对展平。 不需要额外的反转跟踪，因为排序已经确保了最小的交叉交互。 

一个微妙的细节是排序必须仅使用第二个元素。 使用第一个元素或元素之和可能会产生不正确的排序，因为反转结构取决于每个块中较大的暴露值。

 ## 边缘情况

 对于像这样的单个块$(b, a)$在哪里$b > a$，算法首先将其交换为$(a, b)$，确保不存在内部反转。 由于没有其他块，因此最终输出基本上是正确的。 

对于重复的相同对，排序不起作用，任何排列都会产生零反转。 该算法以任何顺序保留所有值，并且结果保持最佳。 

对于严格递减的最大值序列，例如$(10,1), (9,2), (8,3)$，归一化产量$(1,10), (2,9), (3,8)$。 按第二个元素排序会反转顺序，产生$(3,8), (2,9), (1,10)$，它通过将大的第二个元素推入数组的后面来最小化交叉反转。
