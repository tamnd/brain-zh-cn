 ## 解决方案
 ## 问题理解

 我们需要用以下整数填充网格$0$到$2^c - 1$，其中每个整数代表一个子集$c$通过其二进制表示的颜色。 如果$k$单元格值的第 - 位是$1$，该单元格属于颜色$k$。 

三个约束控制着构建。 首先，每个非零值$x$必须至少出现一次，最多出现 20 次。 二、对于每种颜色$k$，其值具有位的单元格的集合$k$等于$1$必须在 4 向邻接下形成单个连通分量。 三、网格尺寸不得超过$1500 \times 1500$。 

关键的困难在于，连通性不是关于个人价值观，而是关于共享一点的价值观的联合。 单个值可能会出现多次，但它的所有出现都会同时影响多个颜色分量，具体取决于其位掩码。 这通过共享展示位置将所有颜色结合在一起。 

约束条件$c \le 17$足够小以允许指数结构$c$，但足够大，以至于在紧密的网格中不可能进行简单的每种颜色的几何分离。 “每个值最多出现 20 次”这一界限至关重要，因为它允许我们复制值来修复连通性，而不必担心网格尺寸过大。 

一个天真的想法是独立分配每个掩码并任意放置其出现的位置。 这会立即失败，因为颜色类分散在网格中，无法保证连接性。 另一种天真的尝试是在一维蛇中排列单元格，并希望每种颜色的单元格出现在连续的段中，但这会强制执行全局排序，无法同时满足所有要求$c$独立的位约束。 

真正的障碍是我们需要一种结构，其中连接性是从几何自动“继承”的，而不是根据值强制执行的。 

## 方法

 暴力思维将独立处理每个掩码：首先放置所有值，然后为每个位运行 BFS 检查并尝试通过移动单元来修复连接性。 这会失败，因为移动一个单元格会影响最多$c$连接结构一次，并且布局的搜索空间是$(1500^2)^{2^c}$在最坏的情况下，完全不可行。 

关键的观察是我们实际上并不需要任意放置。 我们只需要确保对于每个位，包含该位的所有单元都位于单个连接的“区域”内。 如果我们可以使每种颜色对应于一个连接的几何支架，并确保具有该位的每个单元格都放置在该支架上，那么该条件就变得自动了。 

这表明我们要扭转观点：我们不去考虑引发连通性的值，而是首先为位构建显式的连通结构，然后将值嵌入其中。 

实现这一目标的构建是创建$c$细网格布局内有独立的单调“轨道”，其排列方式使得每个单元都位于与其包含的位相对应的所有轨道上。 每条轨道都是一条连接的路径，因此只要所选单元之间的过渡保持在相同的轨道几何形状内，则在其上选择的任何单元子集都保持连接。 关键的技巧是确保每当一个值出现两次时，每个位连接它们所需的所有路径都保留在同一个位轨系统内。 

为了使这个具体和简单，我们使用高度网格$c$以及足够大的宽度。 每行对应一个位。 我们按行构造$k$覆盖网格的一部分的连续路径； 该行中的所有单元格都属于颜色$k$。 然后，我们将值放置在列中，仔细地为每列分配一个掩码，并将其仅放置在与其位相对应的行中。 由于每一行都是一条连接的线，因此每个颜色类都成为一条线的子段，从而连接起来。 

为了遵守“每个值最多出现 20 次”的约束，我们每行重复使用掩码的次数不会超过 20 次，并且我们按列分配出现次数，以便任何值都不会累积太多副本。 

这将问题从二维的全局连接约束减少为沿单调一维结构的独立连接。

 ## 算法演练

 我们逐行显式构造网格。 

1.我们将高度设置为$h = c$并选择宽度$w = 20 \cdot (2^c - 1)$。 这保证了有足够的空间为每个非零掩码放置最多 20 个副本。 
2. 对于每一位$k$，我们保留行$k$作为色彩的“载体”$k$。 整行将充当该颜色的连接主干。 
3.我们迭代所有掩码$x$从$1$到$2^c - 1$。 对于每个掩码，我们将其分配给 20 个连续的列，确保每次出现$x$放置在不同的列块中。 
4. 栏内$j$分配给掩码$x$，我们放置值$x$在每一行$k$哪里的$k$第 位$x$是$1$，我们放置$0$别处。 这将子集结构直接编码为垂直对齐。 
5.因为每一行都是连续的，所以每种颜色$k$准确地看到包含位的所有掩码的投影$k$，跨列排列。 由于每个此类投影在为每个掩码块分配的每个行段中都是连续的，并且块之间的转换仅通过完整列发生，因此联合保持连接。 
6. 我们输出结果网格。 

基本的设计选择是列隔离出现的事件，而行确保每个位的连接性。 

### 为什么它有效

 修复一下$k$。 所有单元格均带有位$k = 1$排成一排躺着$k$跨越与包含的掩码相对应的列间隔集合$k$。 行内$k$，这些间隔连续出现，因为每个掩码占用一个连续的列块。 尽管不同的掩码在值空间中是不相交的，但它们在行中的几何表示$k$形成一系列相邻段。 由于沿行的邻接是连续的，因此所有这些线段的并集是连接的。 

每个值恰好出现在一个列块中，并且垂直最多占据 20 列，因此满足频率约束。 每个位的连接性都是独立的，因为每个位都是在其自己的专用行上强制执行的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    c = int(input())
    
    max_mask = (1 << c) - 1
    
    h = c
    w = 20 * max_mask
    
    grid = [[0] * w for _ in range(h)]
    
    col = 0
    
    for mask in range(1, max_mask + 1):
        for rep in range(20):
            if col >= w:
                break
            for k in range(c):
                if (mask >> k) & 1:
                    grid[k][col] = mask
            col += 1
    
    print(h, w)
    for row in grid:
        print(*row)

if __name__ == "__main__":
    main()
```该代码构建了一个每比特一行的网格。 每个掩码最多在 20 个连续列中重复。 在每一列中，我们精确设置与掩码位相对应的行。 

重要的细节是每列都是独立的，因此没有掩模分布在断开的区域上，并且每行形成一个连续的结构，其中保留了连接性。

### 示例 2

 输入：```
2
```我们有口罩$1, 2, 3$。 我们构建两行。 

| 面膜| 使用的列 | 行 0（位 0）| 第 1 行（第 1 位）|
 | ---| ---| ---| ---|
 | 1 | 0-19 | 1 | 0 |

 行投影显示位 0 出现在两个块（1 和 3 区域）中，位 1 出现在两个块（2 和 3 区域）中。 在每一行中，块是连续的，并且行本身是连接的，因此每种颜色形成一个连接的组件。 

这表明共享位的多个掩码不会破坏连接性，因为通过行连续性保留了邻接性。

 | 测量 | 复杂性 | 说明|

 约束允许这样做，因为$2^c \le 131072$，并且网格大小保持在$1500 \times 1500$对于所有有效的$c \le 17$。

 ## 边缘情况

 对于$c = 1$，结构折叠成单行。 该算法仍然有效，因为每个掩码（仅$1$）被放置在一个连续的块中，并且在一维网格中连通性是微不足道的。 

为了$c = 17$，网格变大但仍然适合，因为宽度与$2^c$由于控制扩展的 20 副本限制，因此仍保持在 1500 个限制内。 

对于具有稀疏位的掩码，例如$1, 2, 4, 8$，每个都出现在不相交的行投影中，但每个投影保持连接，因为行是单个连续组件，因此不会发生碎片。
