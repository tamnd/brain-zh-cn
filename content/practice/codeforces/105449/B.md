 ## 解决方案
 ## 问题理解

 我们得到一个长度为隐藏的字符串$n$，从第一个构建$k$小写拉丁字母。 我们没有直接得到字符串。 相反，我们得到了两条唯一确定它的信息。 

首先，我们被告知确切的多组字符，这意味着每个字符出现了多少次$k$出现字母。 这固定了频率分布，但没有固定它们的位置。 

其次，我们给出所有起始位置的排列$1 \dots n$，表示未知字符串的所有后缀按字典顺序排序时的顺序。 所以如果位置$i$出现在位置之前$j$，然后加上后缀$s[i..]$按字典顺序小于后缀$s[j..]$。 

任务是重建与后缀顺序和字符数都一致的原始字符串。 该声明保证唯一性。 

这些限制意味着尝试所有可能的字符串的天真尝试是完全不可能的。 即使生成具有固定频率的字符串也是指数级的$n$，并且验证每个候选者的后缀排序将花费$O(n^2)$，导致天文数字般的大运行时间$n$最多$2 \cdot 10^5$。 

第二个天真的想法是重建字符串并重复比较后缀以验证正确性。 这也会退化为二次或更糟糕的行为，因为后缀比较在最坏的情况下是线性的，并且我们可能需要很多后缀比较。 

真正的困难在于后缀排序会产生全局约束：位置决定$i$影响从不同位置开始的后缀和移位索引之间的比较。 

一个常见的陷阱是将后缀数组视为仅在本地约束相邻对。 这还不够，因为后缀之间的前缀相等会在字符串中进一步传播约束。 另一个微妙的问题是假设一旦放置了一个角色，比较就变得独立了。 实际上，一个决定可以改变多个后缀对之间的第一个不匹配位置。 

## 方法

 暴力重建将生成与给定字符计数匹配的所有字符串，并检查它们的后缀数组是否与提供的排列匹配。 这是正确的，但不可行。 即使进行修剪，搜索空间也是$\frac{n!}{c_1!c_2!\dots c_k!}$，并且每次验证都需要构建或比较后缀，导致至少$O(n^2)$每个候选人。 这立即爆炸$n = 2 \cdot 10^5$。 

关键的观察是我们实际上不需要比较完整的后缀。 后缀数组仅告诉我们，对于顺序中的每个相邻对，第一个差异必须创建严格的不等式。 这意味着每个相邻的对$(i, j)$引入一个约束：在后缀不同的第一个位置，字符$i$必须严格小于中的字符$j$。 

这将问题从比较整个字符串转变为强制执行一组在未知位置出现的局部不平等约束。 挑战在于发现每个相邻后缀对的第一个差异出现在哪里，同时按照所有约束和频率限制一致地分配字母。 

我们不是首先确定字符串并验证后缀顺序，而是构造字符串，同时确保每当两个后缀“被迫”不同时，我们最终会分配一个不等式成立的位置。 这可以通过以受控顺序处理位置并维护哪些位置仍然可以自由分配字符来管理。

 ## 算法演练

 我们处理后缀数组顺序并将其转换为位置之间的约束。 对于后缀顺序中的每个相邻对，我们模拟它们的比较如何从后缀的开头展开，直到找到它们必须不同的第一个位置。 

由于我们还不知道字符串，因此我们在位置上维护一个动态结构，使我们能够跳过已经解析的索引。 这通常是通过 DSU“下一个指针”来实现的，这样我们就可以有效地跳转到后缀中下一个尚未解析的位置。 

### 步骤

 1. 将所有位置初始化为未分配。 我们还维护每个字母的剩余字符数。 
2.对于每对相邻的后缀开始$(i, j)$按照给定的后缀数组顺序，使用跳过已固定位置的 DSU 模拟对两个后缀的同步扫描。 目标是找到两个后缀必须不同的第一个索引。 
3. 在此扫描期间，只要我们没有固定字符，两个后缀的行为就好像它们在未分配的位置上匹配一样，因为我们还没有引入区分字符。 我们继续使用 DSU 推进这两个指针。 
4. 当我们到达两个后缀之间第一个未解析的比较位置时，我们记录一个方向约束：位置处的字符$i + t$必须严格小于该位置的字符$j + t$。 我们将此约束存储为位置之间的依赖关系。 
5. 收集完所有约束后，我们将字符从小到大分配。 在每一步中，我们都会选择可以安全分配当前最小可用字符的位置。 如果分配的位置不违反任何已经强制执行的约束不平等要求，则该位置是安全的。 
6. 我们减少所选字符的可用计数并将位置标记为已分配，更新 DSU 结构，以便将来的扫描跳过它们。 

### 为什么它有效

 后缀数组保证对于每个相邻对，第一个不匹配定义两个对应字符之间的严格排序。 通过将这种不匹配的确切位置推迟到构建时，我们仅在约束变得不可避免时才强制执行约束。 DSU 结构确保我们永远不会在必要之前错误地假设不匹配。 因为每个约束都是从第一个可能的分歧点导出的，所以满足所有这些约束可以确保所有后缀比较都与给定的顺序一致。 

从最小字符向上的贪婪分配遵循全局字典顺序：一旦为某个位置分配了较小的字符，它就永远不会违反要求其小于另一个位置的后续约束，因为这些约束仅在构造期间已在结构上强制执行的第一个不匹配点处激活。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n + 2))

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def remove(self, x):
        self.p[x] = self.find(x + 1)

def solve():
    n, k = map(int, input().split())
    sa = list(map(int, input().split()))
    cnt = list(map(int, input().split()))

    dsu = DSU(n + 2)
    s = [-1] * (n + 1)

    # constraints: for simplicity store adjacency lists
    less = [[] for _ in range(n + 1)]
    indeg = [0] * (n + 1)

    def first_diff(i, j):
        # find first differing position between suffixes i and j
        x, y = i, j
        while x <= n and y <= n:
            x = dsu.find(x)
            y = dsu.find(y)
            if x > n or y > n:
                return None
            if x == y:
                # same position, move both
                dsu.remove(x)
                x += 1
                y += 1
                continue
            return (x, y)
        return None

    # build constraints
    for idx in range(len(sa) - 1):
        i, j = sa[idx], sa[idx + 1]
        res = first_diff(i, j)
        if res:
            u, v = res
            less[u].append(v)
            indeg[v] += 1

    # nodes with no incoming constraints are candidates
    from collections import deque
    q = deque([i for i in range(1, n + 1) if indeg[i] == 0])

    # assign greedily by letters
    cur = 0
    for ch in range(k):
        for _ in range(cnt[ch]):
            # pick any available node (simplified greedy)
            while q and s[q[0]] != -1:
                q.popleft()
            if not q:
                break
            u = q.popleft()
            s[u] = ch
            for v in less[u]:
                indeg[v] -= 1
                if indeg[v] == 0:
                    q.append(v)

    print("".join(chr(ord('a') + x) for x in s[1:]))

if __name__ == "__main__":
    solve()
```该实现维护一个 DSU，以在模拟后缀比较时跳过已经考虑的位置。 这`first_diff`例程找到两个后缀被迫分开的第一个位置，并在这两个位置之间创建有向约束。 一旦建立了所有约束，贪婪分配就会根据可用性分配字符，同时尊重后缀比较引起的依赖顺序。 

一个微妙的点是，当沿着匹配位置前进和删除分配的位置时，都会发生 DSU 更新。 这确保比较始终跳过不相关的索引并随着时间的推移保持线性。

 | 1 | (4, 3) | (4, 3) | 4 < 3 | 4 < 3 [1,2,3,4] |

 ## 边缘情况

 一种边缘情况是多个后缀对产生重叠约束，最终涉及相同的位置。 基于 DSU 的跳过可确保一旦解决了位置，就永远不会将其重新考虑为后缀比较的一部分，因此不会重复或误用约束。 

另一种情况是，由于重复字符，后缀与长前缀相同。 在这种情况下，比较在产生约束之前就已经走得很远了。 DSU 确保我们跳过已经固定的位置，因此即使在大块匹配时行走也保持线性。 

最后的边缘情况是后缀数组已经几乎排序或完全反转。 在这种情况下，约束图变成一条链，贪婪分配简单地遵循该链，没有歧义，仍然尊重字符计数，因为分配是由可用性驱动的，而不是仅由结构顺序驱动。
