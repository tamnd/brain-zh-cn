 ## 解决方案
 ## 问题理解

 我们得到三个整数。 数组长度不能超过`n`，每个值必须介于`1`和`m`，并且满足特殊邻接规则的不同循环排列的数量必须介于`1`和`k`。 

邻接规则定义了一个“好”数组。 在一个好的数组中，每个相邻的对都完全不同`1`，包括由最后一个和第一个元素形成的对。 这样数组就形成了一个循环，每一步要么向上，要么向下一位。 

我们没有被要求直接计算好的数组。 相反，我们考虑一个非减数组`b`。 我们可以任意排列它的元素。 如果在所有排列之间存在`1`和`k`不同的好循环数组，那么`b`被称为伟大。 我们必须计算有多少不同的非递减数组是伟大的。 

关键的困难在于输入数组已排序，但属性取决于所有可能的重新排列。 我们需要准确了解哪些多组数字可以形成有效循环，以及它们生成多少个不同的循环。 

约束足够小以允许多项式动态编程，但对于强力排列来说太大了。 自从`n`,`m`， 和`k`最多都是`100`，围绕解决方案`O(n^3)`或者`O(n^4)`是可以接受的。 任何指数级的东西`n`是不可能的。 

这个问题最危险的部分是了解好的数组实际上是什么样子。 简单的实现可能会尝试生成多重集的所有排列并检查循环条件。 即使是长度`10`，这已经变得太大了。 

有几种边缘情况完全改变了结构。 

考虑：```
1 1 1
```单元素循环需要`|a1 - a1| = 1`，这是不可能的。 所以答案是`0`。 

另一个微妙的情况是多重集包含的值相差超过`1`。 

例如：```
n = 3, m = 3
multiset = {1, 3}
```没有排列有效，因为每个相邻对必须完全不同`1`。 仅检查计数的粗心实现可能会错误地接受它。 

最重要的结构边缘情况是奇偶校验。 

取多重集：```
{1, 1, 2, 2}
```我们可以这样安排：```
1 2 1 2
```这很好。 

但：```
{1,1,1,2,2}
```不能形成循环交替序列，因为最终两个相等的值必须变得相邻。 

这导致了中心观察：每个良好循环在两个连续值之间交替，并且两个值必须出现相同的次数。 

理解这个属性就可以彻底改变问题。 

## 方法

 蛮力方法在概念上很简单。 我们生成每个非减数组`b`，生成其多重集的所有不同排列，检查哪些排列满足循环邻接条件，并计算存在多少个有效循环。 

检查一种排列很容易。 我们只验证：```
|a[i] - a[(i+1)%r]| = 1
```对于每个职位。 

问题是排列的数量。 即使是长度`100`，不同重排的数量是天文数字。 没有机会一一列举。 

下一步是研究好的循环数组的结构。 

假设一个值`x`出现在一个良好的循环中的某个地方。 每个邻居`x`那么必须是`x-1`或者`x+1`。 由于循环是封闭的，因此所有值都必须属于连续整数的连接链。 

现在假设出现三个不同的值：```
x, x+1, x+2
```价值`x`只能连接到`x+1`， 和`x+2`只能连接到`x+1`。 最终，某些两个相等的值必须变得相邻，这违反了规则。 

唯一可能的结构恰好是两个连续的值。 

因此，每个良好的周期仅包含：```
x and x+1
```此外，循环必须交替：```
x, x+1, x, x+1, ...
```这立即意味着这两个值出现的次数相同。 

如果每个值都出现`t`次，周期长度为`2t`。 

这样的多重集会生成多少个不同的良好循环数组？ 

一旦起始位置固定，整个循环就被迫交替。 确切地说有两种可能性：```
x, x+1, x, x+1, ...
x+1, x, x+1, x, ...
```除非长度为零，否则这两者是不同的。 

所以每个有效的多重集都会准确产生`2`好的阵列。 

这意味着“1 到 k 个好数组之间”的条件变得极其简单：

 如果`k = 1`，答案总是`0`。 

如果`k >= 2`，每个有效的多重集都有贡献。 

现在，问题简化为计算非减数组，其多重集恰好包含两个具有相同正频率的连续值。 

假设值`x`出现`t`时间和价值`x+1`出现`t`次。 

排序后的数组是唯一的：```
x x x ... x (t times)
x+1 x+1 ... x+1 (t times)
```所以每一对`(x, t)`恰好定义了一个大数组。 

结构缩减后，约束变得微不足道。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳 | O(纳米) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`,`m`， 和`k`。 
2.如果`k < 2`， 打印`0`。 

一个有效的良好循环总是产生准确的结果`2`不同的数组，对应于两个交替的起点。 因此，没有多重集可以精确地产生一个好的数组。 

1. 迭代每个可能的较小值`x`。 

较大的值必须是`x+1`， 所以`x`范围从`1`到`m-1`。 

1. 迭代每个可能的频率`t`。 

总长度变为`2t`，所以我们需要：```
2t <= n
```1. 数一数每对`(x, t)`一次。 

排序后的数组是唯一确定的：```
[x repeated t times, x+1 repeated t times]
```没有两个不同的对会产生相同的数组。 

1. 输出计数模数`1e9+7`。 

这里的数字很小，但我们仍然遵循声明。 

### 为什么它有效

 循环良好数组必须满足每个相邻差值都等于`1`。 这迫使每个元素仅连接到相邻的值。 如果出现三个或更多不同的值，最终两个相等的值会在循环中的某个位置相邻。 因此只能存在两个连续的值。 

对于使用值的循环`x`和`x+1`，每个位置都必须在它们之间交替。 只有当它们的频率相等时才有可能。 

一旦多重集固定，就存在两个循环数组，具体取决于哪个值开始交替。 因此，每个有效的多重集都会贡献 iff`k >= 2`。 

该算法精确地枚举了所有此类多重集，既不遗漏也不重复计算任何一个。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, m, k = map(int, input().split())

    if k < 2:
        print(0)
        return

    ans = 0

    for x in range(1, m):
        t = 1
        while 2 * t <= n:
            ans += 1
            t += 1

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```处理的第一个条件是`k < 2`。 每个有效的多重集总是恰好生成两个好的循环数组，而不是一个，因此答案立即变为零。 

外循环选择较小的值`x`。 由于第二个值必须是`x+1`， 有`m-1`选择。 

The inner loop chooses the common frequency`t`。 总长度等于`2t`，所以我们只允许满足的值`2t <= n`。 

每对`(x, t)`精确定义一个排序数组。 因为数组是非递减的，所以没有歧义：```
x x ... x x+1 x+1 ... x+1
```这里没有出现模块化算术复杂性，因为答案最多是`5000`，但仍应用模数来匹配语句。

 ## 边缘情况

 考虑：```
1 5 100
```长度为 1 的循环数组需要：```
|a1 - a1| = 1
```这是不可能的。 

该算法自然地处理这个问题，因为没有积极的`t`满意：```
2t <= 1
```所以计数仍然为零。 

现在考虑：```
4 3 1
```多重集`{1,1,2,2}`形成有效周期：```
1 2 1 2
2 1 2 1
```正好有两个。 

自从`k = 1`，这个多重集不符合条件。 该算法立即通过条件拒绝所有配置：```python
if k < 2:
    print(0)
```最后考虑：```
6 4 100
```可能的对是：```
(1,1), (1,2), (1,3)
(2,1), (2,2), (2,3)
(3,1), (3,2), (3,3)
```该算法准确地计算了这九种情况。 

例如：```
(2,3)
```对应于：```
[2,2,2,3,3,3]
```它可以恰好形成两个循环好的数组：```
2 3 2 3 2 3
3 2 3 2 3 2
```没有其他排列满足该条件。
