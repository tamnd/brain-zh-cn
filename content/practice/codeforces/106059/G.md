 ## 解决方案
 ## 问题理解

 我们得到一个最多有 100 个顶点的连通二分图，其中每个顶点都有一个正权重。 任务不仅仅是为边缘任意分配方向，而是对每条边缘进行定向，以使特定的成本函数变得尽可能小。 

一旦我们确定了图的方向，一些顶点将没有出边。 这些顶点形成一个特殊的集合，并且从每个顶点我们测量到它们中的任何一个的最短有向距离。 如果一个顶点无法到达任何这样的汇点顶点，则其距离被视为极大。 最终成本是这些距离的加权和，其中较重的顶点如果远离汇集则贡献更大。 

因此，真正的决定是如何定向边，以便高权重顶点最终靠近（以有向术语来说）至少一个出射度为零的顶点。 

约束足够小$n \le 100$，但边数可以是二次方。 这立即排除了任何依赖于枚举方向的东西，因为每条边都会使状态空间加倍。 即使对顶点或边的子集进行动态规划也是指数级的。 

一个微妙的点是距离的定义取决于下沉顶点的有向可达性，而不是无向距离。 首先选择一组汇点然后尝试将边向内“推”的简单方法很容易失败，因为错误地选择汇点可能会导致某些顶点无法到达并造成巨大的损失。 

例如，在路径 1-2-3-4 中，如果我们错误地定向边 1→2→3→4，则顶点 1 是一个汇点，但顶点 4 无法到达它，因此其距离变得无限，这决定了成本。 正确的方向通常会平衡可达性，以便每个顶点都有一条通往某个汇点的定向路径。 

另一个失败案例出现在带有循环的二部图中。 在 4 循环 1-2-3-4-1 中，选择一个方向上的所有边根本不会产生任何汇点，从而使每个距离都是无限的。 任何有效的解决方案都必须确保至少一个顶点的出度为零。 

这些观察结果表明，最优解的结构受到高度约束，任意方向几乎总是不好的。 

## 方法

 暴力方法会尝试所有边的每种可能的方向，计算生成的汇集，为每个顶点运行 BFS 或有向图中的最短路径，并评估成本。 这在原则上是正确的，因为它直接遵循定义。 然而，每条边都有两个方向，因此有$2^m$方向，甚至对于$m = 100$，这是完全不可行的。 

关键的见解来自于重新解释顶点到汇点距离较小的含义。 如果顶点具有到汇点的定向路径，则沿着该路径的边必须始终向汇点层移动。 这表明该图应该分层，以便边缘主要从较高“级别”顶点指向较低“级别”顶点。 

由于该图是二分图，因此我们可以利用非常强大的结构约束：我们可以将一个分区视为“流源”，将另一个分区视为“流汇”，并在整个二分区上一致地定位边。 一旦我们修复了二分，任何边都必须从一侧到另一侧，因此每个边方向对应于选择哪一侧在有向意义上“更高”。 

现在考虑成本函数的作用。 一个顶点贡献$w_i$乘以到最近水槽的距离。 这正是朝向一组出度为零的终端顶点的加权最短路径目标。 最佳结构的行为就像相反的最短路径树：我们希望每个顶点都有一条通往所选根状结构的有向路径，并且重顶点应该更接近它。 

这导致了减少：我们不考虑任意方向，而是构建一个有向结构，其中每个顶点都被分配一个等于其到最近接收器的距离的级别，并且每条边必须从较高级别到较低级别。 这确保了非循环性并保证汇点恰好是 0 级顶点。 

剩下的问题变成选择哪些顶点是汇点以及如何定向边缘，以便每条边缘降低水平，同时最小化水平的加权和。 这可以通过将其视为二分结构上的最短路径样式传播来解决，其中最佳配置对应于选择最小化加权距离的一致方向分配，这减少了从最佳接收器候选中计算类似 BFS 的分层并相应地定向边缘。 

因为$n$很小，我们可以显式地尝试由二分奇偶性引起的两个可能的全局方向并计算结果成本，保持最佳。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(2^m \cdot n)$|$O(n+m)$| 太慢了 |
 | 双方定向+评价|$O(n+m)$|$O(n+m)$| 已接受 |

 ## 算法演练

 该解决方案依赖于修复二分区并将一侧视为“偶数级别”，另一侧视为“奇数级别”，然后评估一致的方向。 

1. 首先使用 BFS 计算图的二分。 每个顶点都被分配两种颜色之一，以便每条边连接相反的颜色。 这个结构是由问题保证的。 
2. 考虑方向的两种可能的全局解释：要么边缘主要从颜色 0 到颜色 1，要么从颜色 1 到颜色 0。我们对两者进行评估。 
3. 对于固定的方向选择，我们通过将所选“源侧”的每条边定向到另一侧来构造有向图。 这确保每个顶点都有一组与选择一致的明确定义的传出边。 
4. 将汇点顶点识别为在此方向下没有出边的顶点。 这些正是“目标侧”上的顶点，没有受入射结构强制的传出边缘。 
5. 从所有接收器开始，沿边缘的相反方向运行多源 BFS。 该 BFS 计算从每个顶点到任何接收器的最小有向距离。 
6. 将成本计算为所有顶点权重乘以计算距离的总和。 
7. 重复相反的方向选择并采用最低成本配置。 
8. 输出最小成本以及实现该最小成本的相应边缘方向。 

### 为什么它有效

 在二分图中，每条边都必须在两个分区之间交叉，这意味着任何避免无限距离的有效方向策略都必须一致地选择穿过分区边界的方向。 任何混合的局部方向都会产生定向循环或孤立的组件，使汇点变得无法到达。 

一旦固定了一致的方向，到接收器的最短路径就成为由二分引起的有向非循环结构中的标准最短路径。 来自接收器的 BFS 可以正确计算所有距离，因为所有边都会根据所选方向严格降低或增加隐式级别，从而防止出现替代的较短定向路线。 

成本完全由这些距离决定，因此评估两个全局方向可以保证在所有结构上有效的配置中找到最佳分配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

n, m = map(int, input().split())
w = list(map(int, input().split()))

adj = [[] for _ in range(n)]
edges = []

for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append((v, len(edges)))
    adj[v].append((u, len(edges)))
    edges.append((u, v))

# bipartite coloring
color = [-1] * n
q = deque([0])
color[0] = 0
while q:
    u = q.popleft()
    for v, _ in adj[u]:
        if color[v] == -1:
            color[v] = color[u] ^ 1
            q.append(v)

def solve(forward_color):
    # orient edges from forward_color -> other
    outdeg = [0] * n
    orient = []

    for i, (u, v) in enumerate(edges):
        if color[u] == forward_color and color[v] != forward_color:
            orient.append((u, v))
            outdeg[u] += 1
        else:
            orient.append((v, u))
            outdeg[v] += 1

    sinks = [i for i in range(n) if outdeg[i] == 0]

    # reverse graph BFS for distances
    radj = [[] for _ in range(n)]
    for u, v in orient:
        radj[v].append(u)

    dist = [10**9] * n
    dq = deque()

    for s in sinks:
        dist[s] = 0
        dq.append(s)

    while dq:
        u = dq.popleft()
        for v in radj[u]:
            if dist[v] > dist[u] + 1:
                dist[v] = dist[u] + 1
                dq.append(v)

    cost = sum(dist[i] * w[i] for i in range(n))
    return cost, orient

c1, o1 = solve(0)
c2, o2 = solve(1)

if c1 <= c2:
    print(c1)
    for u, v in o1:
        print(u + 1, v + 1)
else:
    print(c2)
    for u, v in o2:
        print(u + 1, v + 1)
```代码首先读取图形并显式存储边，以便稍后可以明确地定位它们。 二分着色是使用 BFS 计算的，这是安全的，因为连接性保证到达每个顶点。 

这`solve`函数将二分的一侧固定为主要方向源。 它根据该选择一致地确定每条边的方向，并计算出度以确定汇。 然后使用反向邻接列表从所有接收器运行多源 BFS，计算最短有向距离。 

最后，评估两个全局方向，并将最好的方向与相应的有向边缘一起打印。

 ## 边缘情况

 关键的边缘情况是当一个二分区边包含单个顶点时。 在星形结构中，该顶点根据方向要么成为通用汇点，要么成为通用源点。 该算法自然地处理这个问题，因为 BFS 着色仍然分配有效的分区，并且反向方向一致地翻转接收器选择。 

另一种情况是一条长路径，其中所有权重都集中在一个端点。 如果该端点在一个方向上不靠近汇点，则其贡献会变大，并且替代方向将变得最佳。 基于 BFS 的距离计算正确地反映了这种不对称性，因为距离沿着路径线性传播。 

最后一种情况是密集二分图，其中许多顶点具有相同的结构。 这里存在多个具有相同成本的接收器组，并且两个方向可能相同。 该算法保留了正确性，因为它显式评估全局方向并选择任何最佳方向而不依赖唯一性。
