 ## 解决方案
 ## 问题理解

 我们得到了一份数值评估列表，每个学生一个，代表每个学生对宿舍位置的重视程度。 仅顶部`m`按申报价值的学生将获得宿舍权利。 该机制定义了一个“市场价格”，该价格源自两者之间的边界`m`-th 和`(m+1)`- 最高估值。 该价格用于计算获胜者支付的金额和非获胜者收到的金额，从而平衡所有学生的总资金流。 

在计算出这个理想的分数支付系统后，问题引入了一个实际约束：只允许整数交易。 因此，系统是四舍五入的，大学吸收了四舍五入造成的任何不平衡。 

所需的输出由三个值组成：每个获胜者支付的整数金额、每个非获胜者收到的整数金额以及大学必须弥补的绝对不平衡。 

该限制允许最多 200,000 名学生，因此任何解决方案必须至少`O(n log n)`或更好。 完整排序是可以接受的，但任何二次排序都是不可行的，因为在最坏的情况下它需要大约 400 亿次运算。 

一个幼稚的错误是重复重新计算排名或显式模拟转移。 例如，如果我们尝试重复选择顶部`m`元素不排序，每次选择都可能花费线性时间，导致`O(nm)`行为，当两者都很大时，这太慢了。 

另一个微妙的问题是精度。 核心公式涉及平均值，例如`m * v / n`，一般都是小数。 如果使用浮点运算进行处理，小的精度误差可能会翻转下限和上限结果，从而产生不正确的整数输出。 

最后，当出现以下情况时，会出现一个简单的边缘情况：`m`非常接近`n - 1`。 这样就只有一个非获胜者，并且舍入差异变得极其敏感，因为不平衡取决于许多小舍入误差的总和。 

## 方法

 暴力视图首先明确识别每个可能的候选估值阈值的赢家和非赢家，每次都重新计算价格定义。 人们可以想象重复对子集进行排序，或者通过为每个学生分配确切的部分付款然后将所有内容相加来直接模拟转学系统。 

从概念上讲，这是可行的，因为系统纯粹是根据排序顺序统计定义的，因此一旦我们知道排序数组，我们就可以准确地计算所有内容。 然而，重新计算部分排名或重新计算每个学生的贡献会导致重复扫描整个数组。 和`n`最多可达 200,000 个，即使是单个`O(n^2)`方法将涉及数十亿次操作。 

关键的观察是整个机制仅依赖于排序数组中的两个值：`m`第最大和`(m+1)`-th 最大元素。 一旦数组排序完毕，其他所有事情都会简化为这两个边界值的算术运算。 关于其余元素的进一步结构信息并不重要。 

因此，问题分为三个步骤：排序、提取两个边界值、计算一些算术表达式，最后应用整数舍入和一致性校正。 

排序控制了复杂性，使解决方案变得高效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |

 | 暴力模拟| O(n²) | O(n) | 太慢了 |
 | 排序+直接公式 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 ### 1.将所有值按降序排序

 我们首先对数组进行排序，以便顺序统计数据成为直接索引。 这使我们能够访问`m`-th 和`(m+1)`- 恒定时间内的第一个最大值。 

### 2.提取边界值

 让`a[m-1]`成为`m`第一个最大值和`a[m]`成为`(m+1)`-第一个最大值。 这些定义了关键价格中点。 

我们计算一个分数价格：$$v = \frac{a_{m-1} + a_m}{2}$$### 3. 计算系统总价值

 系统将总价值定义为：$$m \cdot v$$我们在概念上将其存储为有理表达式，但在实现中我们避免浮动。 

### 4. 计算每人的公平份额

 每个学生有效地获得：$$\frac{m \cdot v}{n}$$该值也是小数，必须小心处理。 

### 5. 计算原始付款

 获奖者支付：$$v - \frac{m \cdot v}{n}$$非获奖者将获得：$$\frac{m \cdot v}{n}$$然后我们将它们转换为整数：

 -`P = floor(winner payment)`-`Q = ceil(non-winner payment)`此舍入步骤至关重要，因为它强制执行仅允许整数传输的约束。 

### 6. 计算不平衡

 从获奖者那里收集到的总奖金是`m * P`。 分配给非获奖者的总金额为`(n - m) * Q`。 学校吸收绝对差异：$$R = |mP - (n - m)Q|$$### 为什么它有效

 该系统完全由围绕获胜者和非获胜者之间的划分的订单统计数据决定。 一旦阈值固定，每个导出的量都是这两个数字的线性变换。 排序确保了这些顺序统计的正确性，并且所有后续步骤都是确定性算术。 舍入不会影响分类的正确性，只会引入受控的全局不平衡，该不平衡在`R`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    v = list(map(int, input().split()))
    
    v.sort(reverse=True)
    
    # boundary values
    vm = v[m - 1]
    vmp1 = v[m]
    
    # work in rational form using integers
    # v = (vm + vmp1) / 2
    # m*v = m*(vm + vmp1)/2
    mv_num = m * (vm + vmp1)
    mv_den = 2
    
    # fair share = (m*v)/n
    # = mv_num / (mv_den * n)
    # winner payment = v - share
    # = (vm+vmp1)/2 - mv_num/(2n)
    # we compute directly as fraction:
    
    # convert everything to common denominator 2n
    winner_num = n * (vm + vmp1) - m * (vm + vmp1)
    winner_den = 2 * n
    
    # non-winner share
    nonwinner_num = m * (vm + vmp1)
    nonwinner_den = 2 * n
    
    # convert to integers
    P = winner_num // winner_den
    Q = (nonwinner_num + nonwinner_den - 1) // nonwinner_den
    
    # imbalance
    R = abs(m * P - (n - m) * Q)
    
    print(P, Q, R)

if __name__ == "__main__":
    solve()
```实现遵循推导的结构。 排序可确保正确识别分割点。 直接提取边界值。 通过延迟除法直到显式应用下限和上限的最后一步，所有计算都保持在整数算术中。 

一个微妙的点是获胜者和非获胜者公式共享相同的分子结构，因此我们完全避免浮点运算。 天花板为`Q`由处理`(x + d - 1) // d`，即使除法准确与否，也能保证正确性。

 ## 边缘情况

 当所有值都相等时，就会出现一种重要的边缘情况。 在这种情况下，边界值是相同的，因此计算出的价格会缩减为单个数字，并且所有小数差异都会消失。 该算法仍然表现正确，因为排序保留了邻接性并且两者`vm`和`vmp1`相等，产生一致的零方差转移。 

另一种情况是当`m = 1`。 只有最优秀的学生才是赢家，因此整个不平衡取决于单个楼层的操作。 该算法仍然有效，因为即使获胜者集的大小为一，所有公式仍然有效，并且非获胜者的上限操作均匀分布。 

什么时候`m = n - 1`，只有一名学生未获奖。 在这种情况下，`(n - m) * Q`折叠为单个项，因此任何舍入误差`Q`直接决定学校的补偿。 该算法可以正确处理这个问题，因为不平衡是全局计算的，而不是每个学生计算的，从而确保四舍五入后精确的保护计算。
