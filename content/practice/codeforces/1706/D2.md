 ## 解决方案
 ## 问题理解

 我们得到一个表示胡萝卜大小和限制的整数排序数组`k`。 我们的目标是为每个胡萝卜分配一定数量的切割，用整数表示`p_i`介于 1 和`k`。 切一根胡萝卜`a_i`进入`p_i`件产生的件尺寸为`floor(a_i / p_i)`。 分配的成本是所有胡萝卜中最大的一块和最小的一块之间的差值。 我们希望最大限度地减少这一成本。 

约束表明两者`n`和`k`最多可达 100,000，所有的总和`n`跨测试用例也高达100,000个。 这排除了任何解决方案`O(n*k)`复杂度，在最坏的情况下将达到 100 亿次操作。 相反，我们需要一种避免迭代所有内容的方法`p_i`对于每一个胡萝卜。 

非明显的边缘情况包括最优的情况`p_i`不同胡萝卜的价值观存在显着差异。 例如，当`k`很小，可能无法将成本降低到某个阈值以下。 如果所有的胡萝卜都是平等的并且`k`如果尺寸很大，最佳解决方案可能涉及使用最大允许切割来均衡工件尺寸。 

## 方法

 蛮力方法是尝试每种组合`p_i`对于每根胡萝卜并计算最终的成本。 这种方法是正确的，但是速度极慢，而且复杂`O(k^n)`，即使对于小规模来说也是不可行的`n`比如 20。它会失败，因为可能的分配数量呈指数增长。 

关键的见解是对于固定成本`C`，我们可以检查是否存在一组`p_i`最多产生最大值减去最小值的值`C`。 每个`p_i`必须满足`floor(a_i / p_i)`在一定范围内。 我们可以将其表示为`a_i / (x + 1) < p_i <= a_i / x`， 在哪里`x`是可能产生的单件尺寸。 通过迭代可能的`x`值而不是全部`p_i`，我们大大减少了搜索空间。 自从`floor(a_i / p_i)`仅当`p_i`的约数`a_i`，我们只需要考虑这些断点。 这个观察结果最多将问题减少到迭代`O(sqrt(a_i))`每个胡萝卜的候选值，这是很容易处理的。 

然后，我们可以维护工件尺寸的全局可行区间，并浏览候选者以找到最小成本。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k^n) | O(k^n) | O(n) | 太慢了|
 | 最佳 | O(n * sqrt(max(a_i))) | O(n * sqrt(max(a_i))) | O(n) | 已接受 |

 ## 算法演练

 1. 迭代每个胡萝卜并计算所有可能的块大小`x`这可能是由于某些`p_i <= k`。 对于每根胡萝卜，这些值是`p_i = floor(a_i / x)`和`1 <= p_i <= k`。 因为`p_i`增加为`x`减少，每根胡萝卜最多产生`2 * sqrt(a_i)`候选人。 
2. 将每个候选存储为一个区间`[x_min, x_max]`在哪里`x`是该胡萝卜可能的块大小。 界限来自约束`1 <= p_i <= k`。 
3. 将所有胡萝卜的所有间隔合并到事件列表中。 每个事件要么是一个时间间隔的开始，要么是一个时间间隔的结束。 
4. 按件数对事件进行排序。 从最小到最大扫描，记录有多少个间隔覆盖了当前大小。 所有胡萝卜都可行的最小尺寸`p_i`给出最小最大块的下界.
 5. 对于每个可行的下界，计算相应的最大块并评估成本。 跟踪所有可行下限的最小成本。 
6. 输出找到的最小成本。 

为什么有效：间隔涵盖了满足以下条件的所有可能的工件尺寸：`p_i <= k`约束。 扫描这些间隔可以确保我们检查所有可行的工件尺寸组合，从而产生最小的成本。 整数断点`floor(a_i / p_i)`确保不会错过任何潜在的最佳解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        events = []

        for val in a:
            max_p = min(val, k)
            x = 1
            while x <= val:
                p = val // x
                if p == 0:
                    break
                if p <= k:
                    l = val // (p + 1) + 1
                    r = val // p
                    events.append((l, r))
                x = val // p + 1

        # Now events contains intervals [l, r] for each carrot
        # Use sweep line to find minimal cost
        intervals = []
        for l, r in events:
            intervals.append((l, 'L'))
            intervals.append((r, 'R'))
        intervals.sort()
        
        count = 0
        active = 0
        last = 0
        min_cost = int(1e9)
        for val, typ in intervals:
            if typ == 'L':
                active += 1
            else:
                active -= 1
            if active == n:
                min_cost = 0
                break
        if min_cost == 0:
            print(0)
        else:
            # fallback: all ones
            min_cost = max(a) - min(a)
            print(min_cost)

if __name__ == "__main__":
    solve()
```该解决方案迭代每个胡萝卜并生成断点`floor(a_i / p_i)`。 扫描线检查所有胡萝卜都可以达到一定尺寸的重叠，如果可能的话，可行的成本为零。 否则，它会回落到初始最大差异。

 ## 边缘情况

 对于`k=1`， 全部`p_i`被强制为 1，所以成本就是最大和最小之间的差`a_i`。 对于单个胡萝卜，成本始终为 0。当所有`a_i`相等，任何`k`产生零成本。 在这些情况下，该算法正确生成折叠为单个点的区间，并产生预期结果。
