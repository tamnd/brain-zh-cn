 ## 解决方案
 ## 问题理解

 我们有一排建筑物，每栋建筑物都有一定的楼层数。 如果一栋建筑严格高于其紧邻的建筑，则该建筑被认为是“酷”的。 第一个和最后一个建筑物不可能很酷，因为它们没有两个邻居。 我们可以通过增加楼层来增加任何建筑物的高度，目标是最大化酷建筑的数量，同时最小化添加的额外楼层的总数。 

输入由多个测试用例组成。 每个测试用例都提供建筑物的数量及其当前高度。 每个测试用例的输出是最大化凉爽建筑物数量所需的最小楼层数。 

约束表明所有测试用例的建筑物数量总和不超过 200,000。 这排除了每个测试用例的建筑物数量呈二次方的解决方案。 我们需要一个针对每个测试用例大致以线性时间运行的算法。 

非明显的边缘情况包括建筑物高度已经交替的序列或多个相邻建筑物高度相等的序列。 例如，一个序列`[1, 2, 1, 2, 1]`already has maximal cool buildings at positions 2 and 4, so no additional floors are needed. 另一个棘手的情况是`[3, 1, 4, 4, 2]`其中两个连续建筑物相等； 选择增加哪座建筑物可能会影响增加的楼层总数。 

## 方法

 一种强力方法是尝试使每个内部建筑物单独冷却并计算所需的楼层数。 然后，我们可以尝试所有建筑物的组合，以找到最酷的建筑物的最大数量和最少的附加楼层。 然而，对于`n`最多`10^5`，尝试所有组合显然是不可行的，因为可能性的数量呈指数级增长。 

关键的见解是我们不需要考虑所有组合。 很酷的建筑物不能相邻，因为如果我们试图让两座连续的建筑物比它们的邻居高，它们的高度就会发生冲突。 这一观察结果将问题简化为独立选择所有奇数索引内部建筑物或所有偶数索引内部建筑物。 我们可以计算这两种模式所需的楼层，并选择总和较小的一种。 对于奇数长度的序列，我们可能需要通过检查重叠对来考虑混合方法，但对于大多数情况，比较奇数和偶数位置就足够了。

 ## 算法演练

 1. 对于每个测试用例，读取建筑物的数量`n`和高度数组`h`。 
2.如果`n`是奇数，初始化两个总和：一个用于使所有奇数索引的内部建筑物冷却所需的额外楼层，另一个用于所有偶数索引的内部建筑物。 
3. 对于索引处的每个内部建筑物`i`（基于 1，所以`2 ≤ i ≤ n-1`），计算使其比两个邻居都高所需的最小楼层数：`max(h[i-1], h[i+1]) + 1 - h[i]`。 如果结果为负，则使用零。 
4. 将计算出的楼层添加到奇数或偶数位置的总和中，具体取决于`i`。 
5. 处理完所有内部建筑后，如果`n`是奇数，取两个和中的最小值。 如果`n`是偶数，则模式更复杂，因此使用滑动窗口方法来计算不相邻的冷建筑物的总和并选择最小总数。 
6. 输出测试用例的最小总楼层数。 

为什么它有效：不变的是没有两座相邻的建筑物可以同时很酷，因此任何最佳解决方案都必须选择不相邻建筑物的子集。 该算法考虑两个最大的不相邻子集（奇数和偶数），保证我们找到最大化酷建筑数量的最小总数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        h = list(map(int, input().split()))
        if n % 2 == 1:
            total = 0
            for i in range(1, n-1, 2):
                total += max(0, max(h[i-1], h[i+1]) + 1 - h[i])
            print(total)
        else:
            # Sliding window for even length
            add = [0] * (n-2)
            for i in range(1, n-1):
                add[i-1] = max(0, max(h[i-1], h[i+1]) + 1 - h[i])
            prefix = [0] * (n-1)
            prefix[0] = add[0]
            for i in range(1, n-2):
                prefix[i] = prefix[i-1] + add[i]
            res = float('inf')
            for i in range((n-2)//2 + 1):
                left = prefix[i-1] if i > 0 else 0
                right = prefix[-1] - prefix[i + (n-2)//2 - 1] if i + (n-2)//2 - 1 < n-3 else 0
                middle = prefix[i + (n-2)//2 - 1] - prefix[i-1] if i > 0 else prefix[i + (n-2)//2 - 1]
                res = min(res, left + right + middle)
            print(res)

solve()
```该代码首先通过对所有其他建筑物所需的最小楼层求和来处理奇数长度序列。 对于偶数长度序列，它预先计算所有内部建筑物所需的楼层，然后使用前缀和和滑动窗口来考虑不相邻建筑物的组合。 索引时要特别小心，以避免差一错误。 负值被限制为零，因为如果建筑物已经比两个邻居都高，则不需要楼层。
