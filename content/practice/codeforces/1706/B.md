 ## 解决方案
 ## 问题理解

 我们得到一个序列`n`块，每个块都有一个颜色`1`到`n`。 我们需要将它们一一放置在二维网格上。 第一个块始终开始于`(0, 0)`。 每个后续块都可以相对于前一个块向左、向右或向上移动，但不能向下移动或占据已包含块的位置。 一旦放置了块，我们就会被要求，对于每种颜色，找到该颜色块的最大连续垂直堆叠，即仅使用该颜色块的最高塔。 

输入最多为`10^5`每个测试用例的块数，所有测试用例的总数是`2 * 10^5`。 由于时间限制为一秒，我们无法承受比每个测试用例的线性或线性对数更糟糕的事情。 块上的二次运算太慢。 

当某种颜色仅出现一次或出现在不违反放置规则的情况下无法垂直对齐的位置时，就会出现边缘情况。 例如，如果块是`[1, 2, 1, 2, 1]`，对出现次数的天真计数`1`建议建一座大小的塔`3`，但放置限制可能会阻止垂直堆栈大于`2`。 同样，根本不出现的颜色应该正确返回`0`。 

微妙之处在于相同颜色的连续块之间的“垂直分离”很重要。 我们不能在不考虑中间的方块的情况下自由地垂直堆叠它们，这可能会迫使它们水平移动。 

## 方法

 暴力方法将尝试模拟将每个块放置在网格上，跟踪所有可能的坐标并检查每种颜色的垂直塔高度。 这是正确的，但速度非常慢。 对于每个块，我们可能会探索多个可能的位置，并且最多有`10^5`块。 在最坏的情况下，这会导致指数行为并且无法在时间限制内运行。 

关键的见解是绝对坐标并不重要。 影响特定颜色的塔高度的唯一因素是我们需要水平“跳跃”以放置下一个相同颜色的块的频率。 如果两个相同颜色的块在序列中是连续的，我们可以通过水平放置中间的块来垂直堆叠它们。 因此，我们可以将问题简化为计算相同颜色的连续块之间“间隙”的最小数量以及这些间隙如何强制水平移动。 

我们可以通过考虑特定颜色出现的一系列位置来形式化这一点。 在两次出现之间，如果还有其他不同颜色的块，我们需要至少进行一次水平移动。 所以颜色的最大垂直堆叠本质上是`1 + the number of times that color appears with other blocks in between`。 

有效实现此目的的一个简单方法是迭代块，跟踪每种颜色最后看到的索引，并对它们之间的“段”进行计数。 这将问题转换为每个测试用例对数组的线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`max_tower`尺寸的`n`带零。 这将存储每种颜色的结果。 
2. 对于每种颜色，维护最后一次出现的索引。 开始于`-1`来表明它还没有被看到。 
3. 按顺序迭代块。 对于每个颜色块`c`:

 a. 如果这是第一次出现`c`，开始一个新的塔段，从`1`。 

b. 如果以前出现过，请检查与上次出现的间隔。 如果中间还有其他块，我们就增加所需的垂直段数`c`。 这有效地计算了我们可以对这种颜色进行多少次“垂直移动”。 

c. 更新颜色的最后出现索引`c`。 
4. 扫描完色块后，每种颜色的最大垂直线段就是答案。 
5.输出数组`max_tower`。 

这样做的原因是每个街区必须要么继续垂直塔，要么在另一个街区介入时被迫水平移动。 通过计算相同颜色连续出现之间的块数，我们捕获所需的最小垂直线段数。 这保证了放置规则下的最大塔高度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    c = list(map(int, input().split()))
    
    last_pos = [-1] * (n + 1)
    max_tower = [0] * (n + 1)
    
    for idx, color in enumerate(c):
        if last_pos[color] == -1:
            max_tower[color] += 1
        else:
            if idx - last_pos[color] > 1:
                max_tower[color] += 1
        last_pos[color] = idx
    
    print(" ".join(str(max_tower[i]) for i in range(1, n + 1)))
```该代码会跟踪每种颜色出现的最后一个索引，并在遇到带有插入块的新出现时增加塔数。 使用尺寸列表`n+1`避免差一错误。 这`if idx - last_pos[color] > 1`检查确保我们仅在中间至少有一个其他块时才递增，反映了放置时所需的水平移动。
