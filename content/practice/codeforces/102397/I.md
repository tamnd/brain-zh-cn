 ## 解决方案
 ## 问题理解

 有`n`多项选择题，阿尤布用一封信回答了每个问题`a`通过`e`。 关键的额外信息是每个问题的正确答案都是相同的字母。 我们不知道它是五个字母中的哪一个。 

对于正确字母的任何固定选择，当阿尤布在该位置的答案等于所选字母时，他就正确地回答了一个问题。 因此，如果正确的字母是`c`，他的分数就是`c`他的答案字符串中的字符。 

我们需要考虑所有五个可能的正确字母。 最低可能分数是其中最小的频率`a`,`b`,`c`,`d`， 和`e`，而最大可能得分是最大频率。 

问题数量满足`1 <= n <= 1000`。 这是一个非常小的输入大小，因此即使针对每个问题检查所有五个可能的正确字母也只需要`5 * 1000 = 5000`人物比较。 线性扫描速度足够快，即使是简单的五遍解决方案也能在时间限制内轻松完成。 不需要排序、动态编程或任何更复杂的数据结构。 

在某些情况下，实施可能会默默地出错。 随着输入`3`和`aaa`，答案是`0 3`。 如果正确的字母是`a`，所有三个答案都是正确的，但如果是任何其他字母，则没有一个是正确的。 假设字符串中必须出现正确的字母的粗心实现可能会错误地生成至少`1`。 

另一个边缘情况是每个可能的字母出现的频率相同。 例如，与`5`问题和字符串`abcde`，每个可能的正确字母都会给出一个正确答案，因此输出为`1 1`。 在这种情况下，从错误频率初始化最小值或最大值的实现可能会失败。 

最小的有效输入也很有用。 为了`n = 1`和`s = a`，可能的分数是`1, 0, 0, 0, 0`，所以答案是`0 1`。 仍必须考虑字符串中未出现的四个字母。 

## 方法

 直接的暴力解决方案可以尝试五个可能的正确字母中的每一个。 对于选定的字母，它会扫描整个答案字符串并计算包含该字母的位置。 这样做之后`a`,`b`,`c`,`d`， 和`e`，取五个分数中的最小值和最大值。 这是正确的，因为该声明保证实际考试中恰好有一个共同的正确字母，并且只有五种可能的选择。 

最坏的情况执行`5n`人物比较。 和`n <= 1000`，也就是至多`5000`比较，因此在给定的约束下，这种蛮力方法实际上并不会变得太慢。 其渐进复杂度仍为`O(n)`，因为五的因数是常数。 

我们可以通过观察候选字母的分数恰好是其在字符串中的频率来使相同的推理更清晰。 我们可以扫描一次字符串并维护五个计数器，而不是为每个候选者扫描一次整个字符串。 每个字符只增加一个计数器。 一旦知道频率，最小和最大频率立即给出所需的答案。 

暴力破解之所以有效，是因为只有五个可能的正确答案，但它会重复检查相同的字符。 通过观察候选人的分数只是其频率，我们可以在一次扫描期间收集所有五个分数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(5n) = O(n) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 最佳版本更可取，因为它与问题的关系是直接的：对每个字母计数一次，然后检查五次计数。 

## 算法演练

 1. 创建五个计数器，代表频率`a`,`b`,`c`,`d`， 和`e`。 每个可能的正确答案都需要自己的计数，因为每个计数代表如果该字母是通用正确答案，Ayoub 将获得的分数。 
2. 扫描答案字符串中的每个字符并递增与该字符对应的计数器。 处理字符串的任何前缀后，每个计数器等于其字母在该前缀中出现的次数。 
3. 处理完整个字符串后，找到五个计数器中最小和最大的。 这些值恰好是最小和最大分数，因为选择特定字母作为正确答案可以使 Ayoub 在包含该字母的位置精确地得到正确答案。 
4. 打印最小频率，然后打印最大频率。 

### 为什么它有效

 让`count[x]`是 Ayoub 通过信件回答的问题数量`x`。 如果`x`是实际常见的正确答案，Ayoub 在他的答案是的那些问题上是正确的`x`，所以他的分数是`count[x]`。 由于常见的正确答案可以是五个字母中的任何一个，因此所有可能分数的集合恰好是五个频率。 取最小值给出可能的最小分数，取最大值给出可能的最大分数。 计数过程精确地计算了这些频率中的每一个，因此最后一对是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
s = input().strip()

count = [0] * 5

for ch in s:
    count[ord(ch) - ord('a')] += 1

print(min(count), max(count))
```第一行写着`n`，尽管算法在读取字符串后不需要它。 该字符串本身包含计算五个可能分数所需的所有信息。 

这`count`数组有五个位置。 由于输入仅包含来自的字母`a`通过`e`，表达式`ord(ch) - ord('a')`将这些字符映射到索引`0`通过`4`。 因此`a`更新`count[0]`,`b`更新`count[1]`， 等等。 

该循环对每个字符只处理一次。 无需将每个字符与所有五个字母进行比较，因为它自己的字符准确地确定了哪个计数器必须增加。 

零初始化很重要，因为字母可能永远不会出现。 例如，与`aaa`，计数器变为`[3, 0, 0, 0, 0]`。 这些零值代表 Ayoub 的答案中缺少正确字母的有效可能性。 

Python整数在这里不存在溢出问题，并且每个计数器最多`1000`。 输入字符串被剥离，以便标准输入中的换行符不被视为答案字符。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    s = input().strip()

    count = [0] * 5

    for ch in s:
        count[ord(ch) - ord('a')] += 1

    print(min(count), max(count))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()
    result = sys.stdout.getvalue().strip()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return result

# Provided samples
assert run("10\naaaaaabcde\n") == "1 6", "sample 1"
assert run("3\naaa\n") == "0 3", "sample 2"

# Minimum-size input
assert run("1\na\n") == "0 1", "single question"

# All five letters occur equally often
assert run("5\nabcde\n") == "1 1", "all letters equally frequent"

# All answers are the same
assert run("7\nbbbbbbb\n") == "0 7", "all equal values"

# Maximum-size input
assert run("1000\n" + "a" * 1000 + "\n") == "0 1000", "maximum n"

# Boundary distribution that catches incorrect min/max initialization
assert run("5\naaaab\n") == "0 4", "zero-frequency letters and maximum frequency"

 ## 边缘情况

 对于单一问题的情况，考虑`n = 1`和`s = a`。 计数器变成`[1, 0, 0, 0, 0]`。 如果`a`是正确答案，阿尤布得一分。 如果任何其他字母正确，他将得到零分。 算法打印`0 1`，正确考虑所有五个可能的正确答案。 

对于仅包含一个不同字母的答案字符串，请考虑`n = 3`和`s = aaa`。 计数器变成`[3, 0, 0, 0, 0]`。 最高分是`3`，当获得`a`是正确的，而最小值是`0`，为其他四个可能的正确字母中的任何一个获得。 结果是`0 3`。 

对于每个字母都只出现一次的情况，请考虑`n = 5`和`s = abcde`。 计数器是`[1, 1, 1, 1, 1]`。 无论哪一个字母是通用的正确答案，阿尤布都正确地答对了一个问题。 因此两个极值都是`1`, 给予`1 1`。 

对于最大输入大小，请考虑`n = 1000`和一个包含 1000 的字符串`a`人物。 计数器是`[1000, 0, 0, 0, 0]`，所以结果是`0 1000`。 该循环仍然只对每个字符执行一次操作，这表明该解决方案直接随输入大小而缩放。
