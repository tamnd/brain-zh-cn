 ## 解决方案
 ## 问题理解

 我们有一个序列`n`石板，每块石板都有一种颜色`a[i]`。 我们需要计算其石板颜色完全相同的位置的每个非空子集。 位置是不同的，因此选择不同的石板会产生不同的子集，即使它们的颜色相同。 

假设出现一种特定的颜色`c`次。 使用此颜色的每个有效子集只是这些颜色的非空子集`c`石板。 有`2^c`总共子集，包括空子集，所以这个颜色有贡献`2^c - 1`有效的选择。 最终的答案是出现的每种颜色的数量之和。 

该序列最多可以包含`10^5`石板，而每种颜色最多`10^5`。 对于这个输入大小，检查所有子集的算法是不可能的，因为可能有`2^100000 - 1`非空子集。 甚至一个`O(n^2)`解决方案将执行大约`10^10`在最坏情况下的操作，远远超出了大约两秒的竞争性编程限制所能支持的。 我们需要一种算法，其工作本质上与石板数量呈线性关系。 

有几种边缘情况可能会导致粗心的实施失败。 用一块石板，例如`1`其次是`5`，只有一个有效的子集，即石板本身。 忘记删除空子集的公式将返回`2`而不是`1`。 

例如，所有颜色都不同`3`其次是`1 2 3`，每个有效子集恰好包含一块石板，所以答案是`3`。 计算所有子集而不按颜色分组的解决方案将错误地包括混合颜色子集，例如`{1, 2}`。 

具有重复的颜色，例如`5`其次是`5 5 1 2 3`，两块彩色石板`5`产生三个有效的子集：其中之一，或两者一起。 总计为`3 + 1 + 1 + 1 = 6`。 仅计算每种颜色的一个子集会错过通过选择该颜色的多个石板形成的组合。 

最后，颜色可以出现在最大允许值。 例如，`2`其次是`1 100000`有答案`2`，因为两种颜色都出现一次。 分配频率数组小于的实现`100001`将访问其预期范围之外。 

## 方法

 直接的方法是考虑每个非空子集`n`职位。 正好有`2^n - 1`这样的子集。 对于每个子集，我们可以检查其选定的石板并检查它们的所有颜色是否相同。 这是正确的，因为每个可能的子集在满足条件时都会被精确地检查和接受。 

问题是子集的数量。 什么时候`n = 100000`， 有`2^100000 - 1`非空子集，这已经远远超出了任何可行的工作量。 如果检查子集需要查看最多`n`位置，最坏情况下的总工作是`Θ(n 2^n)`。 即使使用更聪明的子集表示来降低检查成本，`2^n`枚举本身已经是不可能的了。 

有用的观察是，一旦我们知道每种颜色出现了多少次，石板的实际位置就不再重要了。 如果颜色`x`出现`c`次，每个有效子集的颜色为`x`必须从这些集合中选择一些非空集合`c`职位。 选择这样一个集合的方法有多种`2^c - 1`。 

这将原来的子集问题变成了频率计数问题。 我们首先数一下每种颜色有多少块石板，然后计算`2^c - 1`对于每个频率并将这些贡献模数相加`10^9 + 7`。 

例如，在`3 5 5 1 2`， 颜色`3`发生一次并贡献`1`， 颜色`5`发生两次并做出贡献`3`， 颜色`1`发生一次并贡献`1`和颜色`2`发生一次并贡献`1`。 总计为`1 + 3 + 1 + 1 = 6`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |`O(n 2^n)`|`O(n)`| 太慢了|
 | 最佳 |`O(n)`|`O(n)`| 已接受 |

 ## 算法演练

 1. 创建一个频率结构，记录每种颜色有多少块石板。 因为每种颜色都介于`1`和`100000`，一个大小的数组`100001`就足够了。 计算频率只需遍历输入一次。 
2. 预先计算 2 的幂`2^0`通过`2^n`，总是对结果取模`10^9 + 7`。 我们需要`2^c`对于每个可能的频率`c`，并且颜色的出现不能超过`n`次。 
3. 迭代颜色并查看它们的频率。 如果出现颜色`c`次，有`2^c`选择这些石板子集的方法，因为每个`c`独立的职位有两种选择，选择或不选择。 
4. 减一`2^c`排除空子集。 因此这种颜色的贡献是`2^c - 1`。 
5. 将每种颜色对答案的贡献取模`10^9 + 7`。 频率为零的颜色没有任何贡献，因此可以简单地跳过它们。 

### 为什么它有效

 对于每种颜色`x`，设其频率为`c`。 石板都有颜色的子集`x`只能包含`c`头寸携带`x`。 每个位置都有两个独立的选择，所以有确切的`2^c`这些位置的子集。 正好其中一个是空的，剩下`2^c - 1`非空有效子集。 

每个有效子集都恰好有一种颜色，因此它属于恰好一种颜色的贡献。 相反，每个子集都按颜色计算`2^c - 1`该术语仅包含该颜色的石板，因此有效。 因此，这些贡献是不相交的，并且总共包含每个有效子集一次，这证明它们的总和是所需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAX_COLOR = 100000

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    freq = [0] * (MAX_COLOR + 1)

    for color in a:
        freq[color] += 1

    pow2 = [1] * (n + 1)
    for i in range(1, n + 1):
        pow2[i] = (pow2[i - 1] * 2) % MOD

    ans = 0

    for color in range(1, MAX_COLOR + 1):
        c = freq[color]
        if c:
            ans = (ans + pow2[c] - 1) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```第一部分`solve`读取石板的数量及其颜色。 频率阵列使用以下事实：`a[i]`至多是`100000`， 所以`freq[color]`直接存储该颜色出现的次数。 

这`pow2`数组包含可能需要的所有 2 的幂。`pow2[0]`是`1`，并且后面的每个值都是通过将前一个值取模一倍而获得的`MOD`。 这避免了重复重新计算能力并使每个存储的整数保持较小。 

答案循环使用`pow2[c] - 1`，完全匹配组合参数。 减法是在表达式中的最终模运算之前执行的，但累加结果使用以下公式进行归一化`% MOD`在每次迭代中。 Python 整数不会溢出，尽管仍然需要模算术，因为请求的答案是显式模数的`10^9 + 7`。 

频率条件`if c:`防止为未出现的颜色添加任何内容。 循环开始于`1`并结束于`100000`，因此允许的颜色范围的两个极端都被处理。 

该问题只有一个测试用例，因此不存在测试用例循环。 提供的语句显示的示例格式不一致，但预期的示例是`n = 5`有颜色`3 5 5 1 2`。

def solve():

def run(inp: str) -> str:

    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        solve()
        return sys.stdout.getvalue().strip()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

# Single flagstone

# Every flagstone has a different color

## 边缘情况

 一块石板是尽可能小的输入。 为了`n = 1`和数组`1`, 颜色频率`1`是`1`，所以它的贡献是`2^1 - 1 = 1`。 算法打印`1`。 这里减一是必要的，因为二元选择生成的第二个子集是空子集，这是不允许的。 

例如，当所有颜色都不同时`4`其次是`1 2 3 4`，每个频率是`1`。 每种颜色都有贡献`2^1 - 1 = 1`，总共给出`4`。 基于频率的计数会自动拒绝包含两个不同位置的子集，因为没有单一颜色接收这样的子集。 

例如，当每块石板都有相同的颜色时`5`其次是`7 7 7 7 7`，整个问题简化为选择五个位置的任何非空子集。 有`2^5 - 1 = 31`这样的子集，并且算法从单个频率中准确地获得该值`c = 5`。 

对于边界颜色，请考虑`6`其次是`1 100000 100000 1 100000 1`。 颜色`1`出现3次并贡献`7`，同时颜色`100000`也出现了三次并贡献了另一个`7`。 答案是`14`。 频率数组的索引为`100000`，因此两个边界值都正确表示。 

对于最大输入大小，如果全部`100000`石板具有相同的颜色，该算法不枚举任何子集。 它存储频率`100000`，计算`2^100000`模数`10^9 + 7`，减一，然后返回`607723519`。 即使有效子集的数学数量大约有三万位十进制数字，执行仍然保持线性。
