 ## 解决方案
 ## 问题理解

 我们需要根据一块矩形土地的面积重建其尺寸。 输入包含单个整数`n`，表示矩形的面积。 我们需要打印两个正整数`height`和`width`谁的产品正是`n`。 

例如，如果`n = 20`， 两个都`4 5`和`2 10`描述有效的矩形，因为它们的乘积是 20。该问题明确允许任何有效的对，因此不需要找到唯一的矩形或优化尺寸。 

约束条件`1 <= n <= 200`使问题变得非常小。 甚至是检查从 1 到 1 的每个整数的算法`n`最多执行 200 次迭代，这对于 1.5 秒的限制来说已经足够快了。 尽管如此，数学结构给了我们一个更清晰的`O(sqrt(n))`方法。 这在概念上很重要，因为因子对问题通常有更大的限制，其中检查每个值最多`n`会变得太贵了。 

主要的边缘情况来自完美的正方形和尽可能小的面积。 为了`n = 1`，唯一可能的尺寸是`1 1`。 一个从 2 开始检查的粗心实现永远不会找到一个因子，并且可能无法打印任何内容。 

对于完美的正方形，例如`n = 16`，尺寸`4 4`有效，因为相同的因子可以使用两次。 即使相同的维度完全有效，错误地仅搜索两个不同因素的实现也可能会拒绝这种情况。 

对于黄金地段，例如`n = 7`, 2 和 之间没有因数`sqrt(7)`。 有效的矩形很简单`1 7`。 假设每个数字都有一个重要因素的实现可能会在这里失败。 

所提供语句中的示例格式省略了相应的输入行，但显示的输出对清楚地对应于区域`20`,`16`， 和`6`:`4 * 5 = 20`,`4 * 4 = 16`， 和`2 * 3 = 6`。 

## 方法

 最直接的方法就是暴力破解。 尝试从 1 到 1 的所有可能的高度`n`，并且每当`n`可以被高度整除，使用`n / height`作为宽度。 第一个成功的除数立即给出一个有效的对，因为`height * (n / height) = n`。 在最坏的情况下，这会执行`n`可分性检查。 结合实际情况约束`n <= 200`，这意味着最多 200 次检查，因此这里完全接受暴力破解。 仅当约束大幅增加时，例如增加到周围的值，它才会变得太慢`10^9`或更大，其中性能高达`n`迭代不再现实。 

有用的观察是因素是成对出现的。 如果`a * b = n`和`a <= b`， 然后`a <= sqrt(n)`。 因此，如果我们从`floor(sqrt(n))`，第一个相除的值`n`立即给出一个因子对. 没有理由检查任何大于`sqrt(n)`，因为它的匹配因子已经小于或等于`sqrt(n)`。 

这最多减少了搜索`n`最多检查到`sqrt(n)`检查。 对于这个问题，两种方法都足够快，但平方根方法捕获了因子对问题背后的标准推理，并且扩展性更好。

 ## 算法演练

 1. 阅读区域`n`。 我们需要找到任何正因数`n`并用其互补因子作为另一个维度。 
2. 计算`floor(sqrt(n))`。 总是可以排列一个因子对，使得较小的因子至多`sqrt(n)`，因此超出此边界的搜索是不必要的。 
3. 开始于`floor(sqrt(n))`向下移动到 1。向下搜索很方便，因为它找到具有最大可能的较小维度的因子对，尽管问题并不需要这个特定的对。 
4. 对于每位候选人`h`，检查是否`n % h == 0`。 如果余数为零，`h`精确地划分区域，所以`n // h`是一个整数并且对`h, n // h`形成一个有效的矩形。 
5. 打印`h`和`n // h`并停止。 保证能找到除数，因为 1 能整除每个正整数。 

### 为什么它有效

 不变的是循环考虑的每个候选者最多是`sqrt(n)`。 对于每个有效的因式分解`n = a * b`，至少其中之一`a`和`b`至多是`sqrt(n)`。 由于循环检查每个整数`floor(sqrt(n))`降到1，最终必然会遇到这样的因素。 当它发生时，互补值`n // a`满足`a * (n // a) = n`，因此打印尺寸始终具有精确的所需区域。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

h = int(n ** 0.5)

while h >= 1:
    if n % h == 0:
        print(h, n // h)
        break
    h -= 1
```第一行读取单个区域值。 只有一个测试用例，因此不需要外部测试用例循环。 

表达式`int(n ** 0.5)`给出这些非常小的约束的平方根的整数部分. 然后我们检查从该值到 1 的可能更小的尺寸。 

可分性测试是核心操作。 如果`n % h`为零，整数除法给出精确的互补维数。 我们立即打印，因为任何有效的对都会被接受。 

循环条件使用`h >= 1`而不是`h > 1`因为 1 是每个正数的后备因子`n`。 这可以处理素数和`n = 1`无特殊情况。 

Python 中不存在整数溢出问题，并且仅在确认整除性后才执行除法。

### 示例 2

 对于第二个显示的样本，面积为`16`，预期尺寸为`4 4`。 

|`n`|`h`|`n % h`| 行动|

 这里`sqrt(16) = 4`，因此循环恰好从平方根开始。 平方根因子除以数字，产生两个相等的维度。 这说明了为什么完全平方不需要特殊处理。

## 测试用例

 由于该问题接受任何有效的因子对，因此下面的测试助手会验证输出的数学属性，而不是需要一对特定的因子。 示例的断言接受语句中显示的确切尺寸，同时还检查返回的尺寸是否乘以请求的面积。```python
import sys
import io

def solve():
    input = sys.stdin.readline
    n = int(input())

    h = int(n ** 0.5)

    while h >= 1:
        if n % h == 0:
            print(h, n // h)
            break
        h -= 1

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()
    result = sys.stdout.getvalue().strip()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return result

def check(inp: str, expected_area: int):
    out = run(inp)
    a, b = map(int, out.split())
    assert a * b == expected_area, (
        f"Invalid rectangle for area {expected_area}: {a} {b}"
    )
    assert a >= 1 and b >= 1

# Provided samples, whose input lines are omitted in the supplied statement.
assert run("20\n") == "4 5", "sample 1"
assert run("16\n") == "4 4", "sample 2"
assert run("6\n") == "2 3", "sample 3"

# Minimum-size input.
assert run("1\n") == "1 1", "minimum area"

# Maximum-size input.
check("200\n", 200)

# Another perfect square.
assert run("25\n") == "5 5", "perfect square"

# Prime number, where only 1 and n are factors.
check("197\n", 197)
```| 测试输入| 预期产出 | 它验证了什么 |
 | ---| ---| ---|
 |`1`|`1 1`| 1 | 处的最小面积和环边界
 |`200`|`10 20`| 最大约束和非方形复合 |
 |`25`|`5 5`| 完美的方形处理|
 |`197`|`1 197`| 初始输入和回退到因子 1 |

 ## 边缘情况

 对于`n = 1`,`floor(sqrt(1))`是 1。第一个整除性检查是`1 % 1 == 0`，所以算法打印`1 1`。 不需要单独的特殊情况，并且下循环边界已正确处理。 

为了完美的正方形`n = 16`，循环从 4 开始。`16 % 4 == 0`，它打印`4 4`。 允许相同的尺寸，因为矩形不要求其高度和宽度不同。 

对于素数输入`n = 7`,`floor(sqrt(7))`是 2. 算法检查`7 % 2`，非零，则达到 1。因为`7 % 1 == 0`，它打印`1 7`。 这是可行的，因为每个正整数都有 1 作为除数。 

对于最大输入`n = 200`，循环从 14 开始向下检查。 遇到的第一个除数是 10，因为`200 % 10 == 0`。 互补维度是`200 // 10 = 20`，所以输出是`10 20`。 他们的乘积正好是 200，满足所需的矩形面积。
