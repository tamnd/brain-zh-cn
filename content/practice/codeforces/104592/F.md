 ## 解决方案
 ## 问题理解

 我们在 3D 空间中有一个起点、一个目标点以及最多约 150 个称为传送点的特殊点。 移动不是自由的：移动的唯一方法是选择传送器并执行受限跳跃。 

每个传送器都根据曼哈顿距离施加规则。 如果你站在某个点并看着传送器，你到它的 L1 距离在跳跃过程中是固定的。 您可以传送到空间中与同一传送器具有完全相同的 L1 距离的任何其他点。 跳跃后，你降落在太空的其他地方，但你永远不会失去未来的移动必须再次通过传送器完成的限制。 

任务是确定是否可以仅使用这些受限跳跃到达目的地，如果可以，则最小化隐形传送操作的数量。 

一个关键的微妙之处是目的地不一定是传送器，中间位置可以是任意真实坐标。 因此状态空间是连续的，但唯一重要的结构是由传送器引起的。 

约束 N ≤ 150 是真实信号。 试图直接在连续空间上探索几何的解决方案是不可行的。 如果简单地将其视为连续的，那么即使存储所有可到达几何区域对之间的关​​系也会太大。 

自然故障模式试图将每个传送器解释为距离相等的点之间的简单图形边缘。 这是不正确的，因为一个传送器将一个点连接到整个无限的点表面，而不是单个目的地。 

另一个常见的陷阱是假设如果两个点都靠近传送器，那么它们是可以互换的。 这是错误的：只有距离相等才重要，而不是相对顺序或阈值。 

一个小的说明性失败：假设传送器位于 (0,0,0)。 从(1,0,0)开始，可以跳到距原点曼哈顿距离为1的任意点。 这包括 (0,1,0)、(0,0,1)、(1,0,0)、(-1,0,0) 和无数其他。 将其视为有限邻接列表会错过大多数可到达的状态。 

## 方法

 强力解释会将每个可到达的点视为图中的一个节点，并尝试以几何方式模拟跳跃。 从当前点 p 和传送器 i，我们将生成所有点 q，使得它们到 i 的曼哈顿距离等于 p 的曼哈顿距离。 这立即爆炸了，因为每个这样的集合都是 3D 空间中的无限连续表面。 即使离散空间也是不可能的，因为坐标是无界的实值。 

结构的简化来自于视角的转变：我们实际上从不关心你在几何上着陆的位置，只关心你满足每个传送器的等式约束。 

修复传送器 i. 定义函数 di(p) 作为从 p 到 i 的曼哈顿距离。 使用 i 进行传送会保留该值。 因此，使用传送器 i 的每个有效移动都保留在 di 的水平集中。 

这将每个传送器变成空间中所有点的划分，划分为由单个实数标记的等价类。 两个点可以通过 i 直接连接当且仅当它们位于 di 下的同一类中。 

因此，我们不考虑几何，而是构建一个图，其顶点是给定的特殊点加上起点和终点。 对于每个传送器 i，我们计算每个顶点的 di。 所有共享相同值的顶点在一次移动中通过 i 完全连接，因为从其中任何一个我们可以以相等的距离跳到任何其他顶点。 

这给出了一个干净的图结构：边是每个传送器的隐式派系，但我们从未明确构建它们。 相反，我们在最短路径搜索期间按需处理等价类。

如果我们将“使用一次传送器”视为一个步骤，并且我们动态地为每个传送器值对共享传送器的相同值的所有节点恰好扩展一次，那么节点上的标准 BFS 就会起作用。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 强力几何模拟 | 无限/指数 | 无限| 不可能|
 | 隐式平等群上的 BFS | O(N² log N) | O(N² log N) | O(N²) | 已接受 |

 ## 算法演练

 ### ## 算法演练

 1. 将起点、目的地和所有传送器视为一组离散节点。 我们完全忽略连续空间，只对这 N+2 个点进行操作。 
2. 对于每个传送器 i，计算每个节点 j 的键值 di(j)，定义为节点 j 和传送器 i 之间的曼哈顿距离。 该值决定了哪些节点在 teleporter i 下是等效的。 
3. 对于每个传送器 i，根据计算出的 di 值对所有节点进行分组。 每组代表在一次使用传送器 i 时可以相互到达的节点。 
4. 从起始节点运行 BFS。 每个节点代表当前可到达的位置。 
5. 当处理节点u时，迭代所有传送器i。 对于每个传送器，计算 di(u)。 满足 di(v) = di(u) 的所有节点 v 都可以使用 i 在一次隐形传态中从 u 到达。 
6. 一旦传送器 i 处理了特定的距离值，就将该 (i, value) 对标记为已使用，这样它就不会再次扩展。 这可确保每个等价类被处理一次，从而防止重复的 O(N) 扫描。 
7. 继续BFS，直到到达目的地或队列为空。 BFS 深度是隐形传态的最小数量。 

关键的实现细节是我们从不显式地在组中的所有对之间构建边。 我们只会在第一次从任何节点遇到一个组时扩展它，然后丢弃它。 

### 为什么它有效

 每个传送器在所有节点上定义一个函数 di 。 使用 i 进行一次隐形传送可以将您移动到该函数的水平集中的任何位置，因此共享相同值的所有节点都可以在一步中相互访问。 对这些隐式集团的 BFS 探索状态空间，就像所有有效的跳转都明确存在一样。 访问的状态实际上是一个节点加上一个传送器值对，确保我们永远不会两次重新处理相同的等价类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque, defaultdict

def solve():
    T = int(input())
    for tc in range(1, T + 1):
        n = int(input())
        pts = []
        for _ in range(n + 2):
            x, y, z = map(int, input().split())
            pts.append((x, y, z))

        s = 0
        t = 1
        tele = list(range(2, n + 2))

        # dist[i][j] = Manhattan distance from node j to teleporter i
        dist = [[0] * (n + 2) for _ in range(n)]

        for i in range(n):
            tx, ty, tz = pts[i + 2]
            for j in range(n + 2):
                x, y, z = pts[j]
                dist[i][j] = abs(x - tx) + abs(y - ty) + abs(z - tz)

        # visited state: (node, teleporter, distance-value) compressed via used set per teleporter
        used = [set() for _ in range(n)]

        q = deque()
        q.append((s, 0))
        visited_node = [False] * (n + 2)
        visited_node[s] = True

        while q:
            u, d = q.popleft()
            if u == t:
                print(f"Case #{tc}: {d}")
                break

            for i in range(n):
                val = dist[i][u]
                if val in used[i]:
                    continue
                used[i].add(val)

                # expand all nodes v with dist[i][v] == val
                for v in range(n + 2):
                    if dist[i][v] == val and not visited_node[v]:
                        visited_node[v] = True
                        q.append((v, d + 1))
        else:
            print(f"Case #{tc}: IMPOSSIBLE")

if __name__ == "__main__":
    solve()
```该解决方案首先预先计算从每个节点到每个传送器的曼哈顿距离。 这就把几何条件变成了查表问题。 

BFS 状态就是我们当前所在的节点，而成本则跟踪隐形传输的数量。 关键的优化是`used[i]`设置，防止多次重新扩展传送器的相同距离等级。 如果没有这个，每个节点扩展将重复地重新扫描相同的等价类，将复杂性推向立方行为。 

内部循环检查所有节点是否匹配距离值。 由于 N 最多为 150，因此在与剪枝相结合的约束下，这种 O(N3) 最差结构是可以接受的，但实际上仍然在限制范围内。 

## 工作示例

 ### 示例 1

 输入：```
N = 1
S = (0,0,0)
T = (0,4,0)
teleporter = (0,3,0)
```我们计算到传送器的距离。 

| 节点| 点| 距离到远程 |
 | ---| ---| ---|
 | S | (0,0,0) | (0,0,0) | 3 |
 | T | (0,4,0) | 1 |

 从 S 开始，我们只能跳到距传送器距离 3 的点。 T 的距离为 1，因此无法到达。 BFS 永远不会将 T 入队，所以答案是不可能的。 

这证实了可达性是由平等而非邻近性决定的。 

### 示例 2

 输入：```
S = (0,0,1)
T = (0,0,11)
teleporters: (0,0,3), (0,0,0), (0,0,3)
```我们跟踪 BFS 状态：

 | 步骤| 节点| 行动| 新到达|
 | ---| ---| ---| ---|
 | 0 | S | 开始 | (0,0,5) | (0,0,5) |
 | 1 | (0,0,5) | (0,0,5) | 通过电话A | (0,0,-5) | (0,0,-5) |
 | 2 | (0,0,-5) | (0,0,-5) | 通过电话 B | (0,0,11) | (0,0,11) |

 每一步对应于输入一个新的距离等价类。 该算法捕获了这一点，因为每个传送器根据当前位置重复地对节点进行不同的分区。

 ## 边缘情况

 一种重要的边缘情况是起点或目的地与传送器重合。 该算法自然地处理这个问题，因为这些点包含在同一节点集中，并且距离分组仍然适用，无需特殊的大小写。 

另一种情况是重复使用相同的传送器产生不同的可达区域。 这`used[i]`结构确保每个距离类别仅处理一次，即使通过不同的节点重新访问也是如此，防止指数爆炸，同时在距离值变化时仍然允许同一传送器的多次不同使用。 

最后一个微妙的情况是所有节点到传送器的距离相同。 在这种情况下，整个集合在单个 BFS 扩展步骤中变得可访问，分组机制通过在第一次遇到该值时立即将所有节点入队来正确捕获这一点。
