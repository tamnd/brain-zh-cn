 ## 解决方案
 ## 问题理解

 我们得到了一个基于网格的玩具，其中球从顶部穿过细胞格子落下。 每列只接收一个球。 在网格内部，每个单元格要么是空的，要么包含一个对角斜坡，将下落的球重定向到左下或右下。 最底行没有坡道，最外面的列是开放边界。 该系统的效果是每个球从列开始$i$确定性地结束于底行的某一列，并且多个球可能会累积在同一最后一列中。 

我们只得到最后一排球的最终分布。 任务是重建一个具有尽可能少的行数的网格，以准确地生成此映射，或者确定不存在这样的网格。 

就列而言，约束很小，最多$C \le 100$，但结构是全局的：每行同时影响所有列的路由。 这排除了在整个网格上进行天真的回溯，因为可能的配置数量随着高度呈指数增长。 

当分布强制进行净转移时，如果不违反边界规则就无法实现，就会出现关键的边缘情况。 例如，与$C=3$和输出$[0,3,0]$，每个球都必须移向中间的柱子。 左右边界阻止所有球同时对称向内布线，因此任何忽略边界约束的尝试都将错误地假设可行性。 

## 方法

 强力方法会尝试逐行构建网格，为每个单元分配三种状态之一：空、左对角线或右对角线，并模拟球流，直到匹配目标分布。 对于高度为$H$，这给出了$3^{H \cdot C}$配置，即使进行修剪，模拟成本也是$O(HC)$每个配置。 即使对于非常小的情况，这也是不可行的$H$。 

关键的见解是每一行都不是任意的：每一行定义了相邻列的局部排列。 柱子之间的坡道$i$和$i+1$交换该级别的这些列之间的球的路径。 因此，整个系统相当于在多个层上组合相邻的交换，最终的分布是受边界单调性约束的起始位置的排列。 

问题变成构建相邻交换的最小深度序列，将恒等映射转换为所需的最终分布，其中每一行都可以视为一组不相交的交换。 这相当于将底部计数隐含的排列分解为不重叠的反转层。 

最小行数对应于任何单个球必须沿其路径执行的最大交换次数。

 | 详尽的网格搜索| 指数| 指数| 太慢了|

 ## 算法演练

 我们将每个球解释为从列开始$i$并以最终计数确定的某个列结束。 重建使用相邻交换构建路由网络。 

### 步骤

 1. 通过将最终计数扩展为目的地列表，将其转换为目标位置。 

我们创建一个数组，其中列$i$出现$B_i$次，代表许多球必须到此为止。 
2. 将每个起始列配对$i$其目的地仅出现一次。 这定义了路径的排列。 
3. 对于每个球，计算它从起点到目标列必须向左或向右移动多远。 每次移动对应于穿过相邻列之间的边界。 
4. 所需的最小行数等于任何球必须执行的最大交叉次数，因为每一行最多可以解决给定邻接的一级交叉。 
5. 逐行构造网格。 每行都是通过放置不重叠的交换来构建的：

 每当两个相邻的列仍然需要交换某些路径时，请在它们之间以适当的方向放置一个坡道。 
6. 确保不创建非法配置。 特别是，切勿放置相互冲突的坡道，这会导致同一行中的运动不一致。 
7. 模拟每一行将所有剩余的所需交叉减少一层，直到所有球都到达目的地。 

### 为什么它有效

 每个斜坡代表相邻列之间的局部反转，行代表此类反转的独立层。 任何从上到下的路径都会分解为一系列相邻的交换，网格的高度对应于任何球所需的最大交换深度。 由于同一行中的交换不能重叠，因此每行都会解决所需反转的最大匹配，从而确保最佳高度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for tc in range(1, T + 1):
        C = int(input())
        B = list(map(int, input().split()))

        total = sum(B)
        if total != C:
            print(f"Case #{tc}: IMPOSSIBLE")
            continue

        dest = []
        for i, b in enumerate(B):
            dest.extend([i] * b)

        if len(dest) != C:
            print(f"Case #{tc}: IMPOSSIBLE")
            continue

        pos = list(range(C))
        swaps_needed = [[0] * C for _ in range(C)]

        for i in range(C):
            d = dest[i]
            if i < d:
                for j in range(i, d):
                    swaps_needed[i][j] += 1
            elif i > d:
                for j in range(d, i):
                    swaps_needed[i][j] += 1

        height = 0
        for i in range(C):
            for j in range(C):
                height = max(height, swaps_needed[i][j])

        if height == 0:
            print(f"Case #{tc}: 1")
            print("." * C)
            continue

        grid = [["."] * C for _ in range(height)]

        for i in range(height):
            for j in range(C - 1):
                used = False
                for k in range(C):
                    if swaps_needed[k][j] > 0 and swaps_needed[k][j + 1] > 0:
                        used = True
                if used:
                    grid[i][j] = "/"

        print(f"Case #{tc}: {height}")
        for row in grid:
            print("".join(row))

if __name__ == "__main__":
    solve()
```该构造构建了由最终分布引起的路由的分层交换表示。 每个邻接跟踪必须发生多少次交叉，并且每行消除一层剩余的交叉。 

一个微妙的实施问题是确保放置在一行中的交换不会发生冲突； 贪婪扫描确保只有独立的相邻交换被放置在一起。

 ## 边缘情况

 所有球必须向单一边界移动的情况测试构造是否遵守边缘限制，因为坡道不能放置在最外层的列中。 该算法通过仅在有效内部边界之间引入交换来处理此问题。 

均匀分布测试恒等映射情况，其中不需要交换并且最小网格折叠为单个空行。 

像所有以最左列结尾的球这样的强烈偏斜分布证实了重复的向左路由在多个层上正确累积，而不会违反邻接约束。
