 ## 解决方案
 ## 问题理解

 我们给出四个数字，代表未知正整数的三对和$a$,$b$,$c$以及所有三个数字的总和。 这四个数字没有特定的顺序。 我们的任务是重建原来的三个整数$a$,$b$,$c$从这些金额中。 

输入保证了解决方案的存在，这简化了我们的任务，因为我们不需要验证可行性。 棋盘上的每个数字至少为 2，最多为$10^9$，这意味着我们正在处理较小的输入大小（只有四个数字），但可能是非常大的整数。 因为只有四个数字，所以任何具有恒定或线性时间复杂度的算法都是可以接受的。 

要考虑的边缘情况包括以下情况：部分或全部$a$,$b$， 和$c$是平等的。 例如，如果$a = b = c = 1$，棋盘上的四个数字将是$2, 2, 2, 3$。 假设所有和都是不同的天真的方法在这里可能会失败。 另一种情况是两个数相等，例如$a = b = 2, c = 3$，产生总和$4, 5, 5, 7$。 识别所有三个数字的总和并将其与成对的总和分开至关重要。 

## 方法

 暴力方法将尝试检查四个数字对角色的所有可能分配$a+b$,$a+c$,$b+c$， 和$a+b+c$。 只有$4! = 24$排列，它很小，所以纯粹的蛮力就可以了。 对于每个排列，我们可以求解一个小的线性方程组并检查所有结果是否都是正整数。 这种方法之所以有效，是因为只有四个数字，但它不必要地复杂且不直观。 

关键的观察结果是所有三个数字的总和$a+b+c$始终是四个数字中最大的数字，因为它包含所有三个正整数。 一旦我们确定最大的数字为$a+b+c$，其余三个数必须是两两相加。 将最大数表示为$S = a+b+c$和其他数字$x, y, z$。 那么我们可以直接求解原始数：

 -$a = S - (b+c) = S - x$-$b = S - (a+c) = S - y$-$c = S - (a+b) = S - z$无论顺序如何，这都有效，因为$x, y, z$代表所有成对的和。 该算法简化为排序、识别最大数和简单的减法。 它简单、直接，避免了不必要的枚举。

 ## 算法演练

 1. 将四个整数读入列表中。 这捕获以任意顺序提供的总和。 
2. 按升序对列表进行排序。 排序可以很容易地找出最大的数字，保证是$a+b+c$因为所有三个整数都是正数。 
3. 令排序列表中的最后一个数字为$S = a+b+c$。 令排序列表中的前三个数字为$x, y, z$。 这些对应于成对的和，但我们不需要知道哪个是哪个。 
4. 通过减去每个成对的和来计算原始数字$S$：

 -$a = S - x$-$b = S - y$-$c = S - z$这些计算之所以有效，是因为$S - x$删除包含除 1 之外的所有整数的总和，留下剩余的整数。 
5. 打印$a$,$b$， 和$c$以任何顺序。 

为什么有效：排序保证我们识别$a+b+c$作为最大的数。 从所有三个数字的总和中减去每个剩余数字就可以分离出各个整数。 因为我们保证得到正整数的解，所以没有歧义，并且操作可以正确地重建原始数字。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

nums = list(map(int, input().split()))
nums.sort()
S = nums[3]
a = S - nums[0]
b = S - nums[1]
c = S - nums[2]
print(a, b, c)
```该解决方案有效地读取输入，对四个数字进行排序，将最大的数字确定为总和，并使用减法重建每个单独的数字。 排序可确保我们始终如一地识别$a+b+c$无需手动检查哪个总和包含所有三个数字。 减法顺序是灵活的，因为该问题允许输出中的任何顺序。

 ## 边缘情况

 例如，如果所有数字都相等`2 2 2 3`, 排序标识`3`作为所有三个数字的总和。 减法`2`从`3`产生`1`对于每个单独的数字，正确重建`a = b = c = 1`。 

例如，如果两个数字相等`4 5 5 7`，排序给出`4,5,5,7`。 最大`7`是$a+b+c$。 减法`4,5,5`产生`3,2,2`，它正确识别了原始整数
