 ## 解决方案

 ## 问题理解

 我们有一个矩形屏幕，宽度为`a`和身高`b`，被视为具有整数坐标的像素网格。 某个位置有一个像素损坏`(x, y)`。 目标是选择一个轴对齐的矩形子窗口，该子窗口内部不包含此损坏的像素，并且具有尽可能大的面积。 

关键的约束是几何的：我们不删除像素或修改网格，我们选择一个边与屏幕边缘平行的矩形，并且该矩形必须避免包含禁止点。 

每个测试用例都是独立的，我们必须计算该配置的最大可实现面积。 

就测试数量而言，输入大小很大，最多可达`10^4`，而每种情况都很小并且可以在常数时间内计算。 这立即排除了任何尝试枚举候选矩形或模拟放置的解决方案。 任何方法都必须将每个测试用例的算术减少到 O(1)。 

一个天真的心理模型是尝试所有可能的矩形并检查它们是否避免了坏点。 这失败了，因为一个矩形的数量`a × b`网格的顺序是`a^2 b^2`，这远远超出了可行的限制`a, b`达到`10^4`。 

一个更微妙的失败案例来自于假设最好的矩形只是整个屏幕减去一个单位单元。 这是不正确的，因为删除死像素并不意味着切出一个单元格，我们必须排除在其内部任何位置包含该坐标的任何矩形，包括矩形跨越其的边界相邻情况。 

例如，考虑一个`5 × 1`屏幕中间行有坏点。 一个天真的想法可能表明最好的矩形是`5 × 1 = 5`，但如果像素阻止水平分割，则最佳解决方案可能来自仅采用侧段，具体取决于包容性规则的解释。 正确的推理取决于围绕点的划分，而不是删除单个单元格。 

主要困难是认识到任何有效的矩形必须完全位于通过分割网格形成的四个区域之一`(x, y)`。 

## 方法

 蛮力方法尝试每一个可能的矩形`(x1, y1)`到`(x2, y2)`并检查是否`(x, y)`就在里面。 这是正确的，因为它直接强制执行约束，但速度太慢。 矩形的数量大致为`(a(a+1)/2) × (b(b+1)/2)`，达到约`10^16`最坏的情况下操作，完全不可行。 

关键的观察是，任何避免坏像素的矩形必须完全位于通过绘制垂直和水平线形成的四个轴对齐象限之一中`(x, y)`:

 - 左侧：列`[0, x]`- 右侧：列`[x, a-1]`- 顶部：行`[0, y]`- 底部：行`[y, b-1]`然而，由于矩形必须避免包含点本身，因此我们仔细对待分割并考虑在一侧进行完全包含。 

最佳矩形必须完全位于以下四个区域之一：

 - 左上角块：`(x+1) × (y+1)`- 右上角的块：`(a-x) × (y+1)`- 左下块：`(x+1) × (b-y)`- 右下块：`(a-x) × (b-y)`每个都对应于选择一个完全位于垂直和水平切割一侧的矩形，确保坏点不在内部。 

由于我们只需要四个常量表达式中的最大值，因此每个测试用例的复杂度为 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(a²b²) | O(1) | O(1) | 太慢了|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取数值`a, b, x, y`对于每个测试用例。 这些定义了完整的网格和禁止的坐标。 
2.计算四周分割形成的四个候选矩形区域`(x, y)`。 每个候选对应于选择一个完全位于四个方向区域之一的矩形。 

这四个领域是：

 -`(x + 1) * (y + 1)`-`(a - x) * (y + 1)`-`(x + 1) * (b - y)`-`(a - x) * (b - y)`每个表达式都来自计算剪切两侧剩余可用的列和行数。 
3. 取这四个值中的最大值。 这表示在保持轴对齐的同时避免坏像素的最大矩形。 
4. 输出测试用例的结果。 

### 为什么它有效

 任何有效的矩形，避免`(x, y)`必须避免在其内部包含该精确坐标。 由于矩形是轴对齐的，任何跨越矩形左侧和右侧的矩形`x`，以及上方和下方`y`，必须包含该点。 这迫使每个有效矩形完全位于由垂直和水平切割定义的四个区域之一`x`和`y`。 每个区域恰好对应于四个面积公式之一，因此最优解必须是其中的最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, x, y = map(int, input().split())

    ans = max(
        (x + 1) * (y + 1),
        (a - x) * (y + 1),
        (x + 1) * (b - y),
        (a - x) * (b - y)
    )

    print(ans)
```该实现是四区域分解的直接转换。 每一项对应于相对于坏点固定矩形的一侧并最大化剩余尺寸。 

唯一微妙的一点是正确处理逐一推理：`x + 1`表示有多少列可用`0`通过`x`， 和`a - x`表示有多少列可用`x`通过`a - 1`。 同样的对称性也适用于`y`。

 ## 边缘情况

 角落位置，例如`(0, 0)`迫使四个候选区域中的三个折叠，只留下远离原点延伸的矩形。 计算`(x + 1)`和`(y + 1)`变成`1`，因此最大值来自沿相反轴的完全延伸，并且公式仍然正确捕获它。 

像这样的边界情况`a = 1`将问题简化为单列，其中只有垂直分割很重要。 表达式`(a - x)`和`(x + 1)`两者都成为`1`，确保最大减少为选择最长的连续段，避免坏点行。 

完全位于中心的坏点可以最大限度地提高所有四个象限之间的对称性。 在这种情况下，答案始终是大约半维的四个乘积之一，并且 max 表达式可以正确选择最佳分区，而无需特殊的大小写。
