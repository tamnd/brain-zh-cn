 ## 解决方案
 ## 问题理解

 对于每个候选人，我们知道五个整数统计数据：身高、臂展、场均得分、场均篮板和场均助攻。 每个统计数据都有其自己的预期区间，并且根据每个值相对于该区间的位置来判断候选者。 

对于预期区间内的值，中点属于上半部分。 因此，进入上半区的五个门槛是：身高205、臂展225、得分15、篮板4、助攻5。 严格大于上端点的值被视为高于预期范围。 例如，高度 205 已经在上半部分，而高度 221 则高于预期范围。 

任务是将每个候选者分为类别 0、1、2 或 3。类别 0 的条件最强，必须首先检查。 它需要至少三项高于预期范围的统计数据，其中身高或臂展在这三项之中。 接下来是类别 1，然后是类别 2。如果它们的条件都不成立，则答案是类别 3。 

输入最多包含 32 个候选值，并且每个候选值始终恰好有 5 个值。 即使算法对每个候选者执行数百次操作，速度也会相当快。 不需要排序、动态编程、图形算法或任何数据结构。 有用的目标是每个候选人持续工作，总时间为 O(N)。 

一个微妙的边界是中点属于上半部分。 对于高度，预期区间为 190 到 220，因此 205 算作上半部分。 身高为 204 的候选人不满足该条件。 例如：```

205
225
15
4
5
```所有五个统计数据至少都在上半部分，所以答案是`2`， 不是`3`。 使用严格的实现`>`与中点进行比较将错误地拒绝所有五个上半部分条件。 

上端点本身不高于预期范围。 对于高度，220 仍在预期范围内，而 221 则高于预期范围。 例如：```

```所有五个值都在预期范围内，并且都在上半部分，所以答案是`2`。 将上端点视为“高于”会错误地创建三个或更多高于范围的统计数据。 

另一个容易犯的错误是忘记了 0 类的特殊身高或翼展要求。请考虑：```

```得分、篮板和助攻都超出了他们的预期范围，但身高和臂展都没有超出预期范围。 正确答案是`1`，因为候选人满足首轮条件，但不满足独角兽条件。 仅检查超出范围的统计数量会错误输出`0`。 

最后，类别是分层的。 满足类别 0 的候选也可以满足类别 1 或 2 中较弱的条件，因此必须首先测试类别 0。 例如：```

## 方法

 字面上的强力解决方案可以将五个统计数据中的每一个分类为四种状态之一：低于预期区间、处于其下半部分、处于其上半部分或高于预期区间。 一个候选者只有 (4^5=1024) 种可能的状态组合。 我们可以枚举所有组合，确定每个组合所属的类别，并将候选者与这些案例进行比较。 对于 32 个候选者的最大输入，这只是 (32\cdot1024=32768) 个状态检查，因此即使是这种刻意朴素的方法对于实际约束来说也足够快。 

当候选人数量增加时，它就变得没有吸引力了，因为统计工作的数量呈指数级增长。 对于 5 个固定统计量，这种区别主要是理论上的，但如果将相同的想法推广到 20 个统计量，则枚举将需要 (4^{20})，这大约是 (1.1\cdot10^{12}) 组合。 即使对于当前的五统计问题，当类别规则仅依赖于少数计数时，也没有理由枚举状态。 

关键的观察是，在我们确定每个统计量的两个属性后，确切的值并不重要。 我们只需要知道它是否至少在上半部分，以及是否严格高于预期范围。 我们可以直接计算这些属性。 

对于每个候选人，让`high`是至少位于上半部分的统计数据的数量，并让`above`是严格高于预期范围的数字。 我们还分别记住身高或翼展是否超出预期范围。 然后可以使用这些计数来表达每个类别条件。 

第一轮规则还包含“所有参数至少在预期范围内”这一短语。 这相当于说这五个统计数据没有一个低于下端点。 我们可以使用布尔变量来跟踪它。 一旦这几个计数器可用，就可以直接测试每个类别。 

蛮力方法之所以有效，是因为状态空间很小，但它在实际候选者从未达到的状态上执行工作。 观察到每条规则仅依赖于少数聚合属性，从而将问题简化为每个候选者的恒定比较次数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |

 | 最佳| (O(N)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 阅读一位候选人的五项统计数据。 我们独立处理候选者，因为一个候选者的类别从不依赖于另一候选者。 
2. 对于每个统计量，确定其是否至少为上半阈值以及是否严格高于预期上端点。 阈值分别为 205、225、15、4 和 5。 之间的区别`>=`和`>`至关重要，因为中点属于上半部分，而上端点仍在预期区间内。 
3. 统计有多少个统计数据在上半部分或上面。 打电话给这个`high`。 还要计算有多少统计数据严格高于预期范围。 打电话给这个`above`。 
4. 记录身高或翼展是否超出其预期范围。 这是必需的，因为类别 0 要求这两个物理测量之一位于上述范围的统计数据中。 
5. 首先检查类别 0。当`above >= 3`并且身高或翼展超出了预期范围。 我们首先测试它，因为独角兽也满足较弱的质量条件，但类别 0 优先。 
6. 如果类别 0 不适用，请检查类别 1。其第一个条件是`above >= 2`与...一起`high >= 3`。 它的第二个条件要求每个统计数据至少在预期范围内，并且至少有三个统计数据在上半部分。 第一个条件足以表达“两个以上，另一个至少上半部分”，因为每个超出范围的值本身都在上半部分或更好的组中。 
7. 如果类别 1 不适用，请检查类别 2。其第一个条件是`above >= 1`和`high >= 2`。 它的第二个条件很简单`high >= 3`。 同样，高于预期范围的值将自动计算为`high`。 
8. 如果前面的条件都不满足，则输出类别 3。由于按所需的优先级顺序检查类别，因此这正是剩余的情况。 

### 为什么它有效

 对于每一位候选人来说，`above`正是严格高于预期上限的统计数据数量，而`high`至少是他们上半区的统计数字。 单独的物理标志准确地捕获了类别 0 的附加高度或翼展要求。因此，每个书面条件相当于分类系统中的相应规则。 由于类别 0 在类别 1 之前检查，类别 1 在类别 2 之前检查，并且仅当它们都不成立时才使用类别 3，因此生成的类别对于每个候选者来说是最强的适用类别。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def classify(values):
    lower = [190, 200, 10, 2, 3]
    upper = [220, 250, 20, 6, 7]
    middle = [205, 225, 15, 4, 5]

    high = 0
    above = 0
    all_expected = True

    for i, x in enumerate(values):
        if x < lower[i]:
            all_expected = False

        if x >= middle[i]:
            high += 1

        if x > upper[i]:
            above += 1

    physical_above = values[0] > upper[0] or values[1] > upper[1]

    if above >= 3 and physical_above:
        return 0

    if (above >= 2 and high >= 3) or (all_expected and high >= 3):
        return 1

    if (above >= 1 and high >= 2) or high >= 3:
        return 2

    return 3

def solve():
    n = int(input())
    answer = []

    for _ in range(n):
        values = [int(input()) for _ in range(5)]
        answer.append(str(classify(values)))

    sys.stdout.write("\n".join(answer))

if __name__ == "__main__":
    solve()
```数组`lower`,`upper`， 和`middle`按照与输入值相同的顺序存储五个边界。 保持阈值与五个统计数据明确一致可以使分类逻辑统一，而不需要五个单独的比较代码。`all_expected`开始时为 true，一旦值低于其预期间隔，就会变为 false。 这直接代表了第二类 1 条件，该条件要求每个统计量至少是其预期范围的下端点。 

表达式`x >= middle[i]`计算上半部分，包括中点。 表达式`x > upper[i]`仅计算其上方预期范围之外的值。 这些比较不得被交换或在错误的方向上严格进行。 

这`physical_above`条件仅检查身高和翼展，因为独角兽规则特别要求这两个统计数据之一高于其范围。 如果至少有一个满足条件，我们不需要知道是哪一个。 

Python 中不存在整数溢出问题，即使在具有固定宽度整数的语言中，此处的所有计数器也最多为 5。 输入包含每个候选者恰好五行，因此列表理解精确读取属于当前候选者的值。

 ## 边缘情况

205
225
15
4
5
