 ## 解决方案
 ## 问题理解

 我们有 (N) 个标记的城市，并且必须使用 (N-1) 个不同的航空公司连接来构建一个连接的无向图。 由于 (N) 个顶点上具有 (N-1) 条边的连通图是一棵树，因此问题实际上是关于标记树的。 

城市的可达性就是它的度，因此我们要考虑最大顶点度尽可能大的树。 任务是计算有多少不同标记的树达到了最大可能的程度。 

输入包含一个整数 (N)，其中 (2 \le N \le 10^9)。 上限是主要线索：构建图、枚举顶点，甚至运行与 (N) 成比例的循环都是不必要的，也是不合适的。 答案必须来自结构观察并在恒定时间内计算。 

最小的情况值得特别关注。 对于 (N=2)，只有一棵可能的树，由两个城市之间的单边组成。 它的两个顶点的度数均为(1)，因此最大度数为(1)，答案为(1)。 仅返回 (N) 的公式将错误地给出 (2)。 

对于 (N=3)，最大可能次数为 (2)。 三个标记顶点上的每棵树都是一条路径，并且每棵这样的树都有一个度数为 (2) 的顶点。 该中心顶点有 3 个选择，因此答案为 (3)，与样本匹配。 

## 方法

 直接的暴力解决方案可以从 (\binom N2) 个可能的城市对中枚举每个可能的 (N-1) 条边集，检查结果图是否连通，计算所有度数，并保留具有最大最大度数的树。 候选边集的数量正好是

 [
 \binom{\binom N2}{N-1},
 ]

 因此，即使对于相当小的（N），这也变得毫无希望。 另一种基于凯莱公式的强力方法可以枚举所有 (N^{N-2}) 个标记树，但这仍然是指数级的大。 当 (N) 达到 (10^9) 时，任何一种解释都完全无法使用。 

关键的观察结果是，一个顶点最多可以直接连接到所有其他 (N-1) 个城市。 因此，没有一棵树的最大度数可以大于 (N-1)。 这个上限是可以实现的：选择一个城市并将其与其他所有城市连接起来。 生成的图是一个星形图，它是连通的并且恰好包含 (N-1) 条边。 

对于 (N\ge3)，每棵达到最大度数 (N-1) 的树必定是这样的一颗星。 如果某个顶点的度数为 (N-1)，则它与所有其他顶点相邻，并且已使用所有 (N-1) 条可用边。 不能存在额外的边，因为树恰好有 (N-1) 条边。 因此唯一的选择是以哪个城市为中心，给出 (N) 种不同的树。 

情况（N=2）是唯一的例外。 两个顶点都与唯一边相关，因此选择任一顶点作为假设的中心不会生成不同的树。 只有一种独特的结构。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O\left(\binom{\binom N2}{N-1}\cdot N\right)) | (O(N^2)) | 太慢了 |
 | 最佳| (O(1)) | (O(1)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 阅读（N）。 由于答案仅取决于 (N=2) 还是 (N\ge3)，因此无需构造任何图。 
2.如果(N=2)，则输出(1)。 只有一条可能的边，因此只有一棵可能的树。 
3. 如果(N\ge3)，则输出(N)。 最大可能的度数是 (N-1)，当一个选定的城市与所有其他城市相连时，一棵树恰好到达该度数。 (N) 个城市中的每一个都可以独立地成为该独特的中心。

关键的不变量是，顶点度数为 (N-1) 的树已经使用了树所需的所有 (N-1) 条边。 因此，这样的树一定是一颗星，并且当(N\ge3)时，每棵最优树都由它的中心唯一确定。 特殊情况（N=2）没有唯一的中心，这就是为什么必须单独处理。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

if n == 2:
    print(1)
else:
    print(n)
```第一行读取城市的数量。 条件`n == 2`处理唯一可能的中心数量不等于不同最优树数量的情况。 

对于每个 (n\ge3)，程序打印`n`，因为对于其中心的每一个选择，都恰好有一颗最优星。 城市上没有循环，也没有图形数据结构，因此即使在 (N=10^9) 时，实现也保持恒定时间。 

Python 整数很容易表示答案，因为答案最多是 (10^9)，因此不存在溢出问题。 比较必须使用`n == 2`， 不是`n <= 2`，尽管输入保证 (N\ge2)。

## 边缘情况

 对于 (N=2)，确切的输入是`2`。 唯一可能的树包含边 ((1,2))，因此最大度为 (1)。 算法进入特殊分支并输出`1`。 粗心的实施`print(n)`会输出`2`，通过将同一棵树的两个端点视为不同的中心，有效地对同一棵树进行两次计数。 

对于 (N=3)，输入为`3`。 最大可能的度数是(2=N-1)。 任何最优树都必须包含与其他两个顶点相邻的顶点，并且该顶点恰好有三种选择。 该算法采用一般分支并输出`3`。 这证实了从特殊情况到公式（N）的转变恰好发生在（N=3）处。 

对于最大输入，`1000000000`，即使构建所有城市的列表也已经需要不必要的内存，并且枚举边缘是不可能的。 该算法仅执行一次比较并打印`1000000000`。 结果直接源自以下事实：每个 (10^9) 个城市都可以作为一颗不同的最佳恒星的中心。 

结构论证还排除了隐藏图的情况。 如果 (N\ge3) 的最优树具有最大度 (N-1)，则其中心与所有其他城市相邻。 这些（N-1）个关联边已经占了树的整个边集，因此两个非中心城市之间不可能有另一条边。 因此，不会错过最佳构造，也不会计算非星级构造。
