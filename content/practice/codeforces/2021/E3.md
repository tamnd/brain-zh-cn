 ## 解决方案
 ## 问题理解

 我们得到了一个用图表表示的相连村庄。 每个节点都是一座房子，边缘是具有延迟权重的互联网电缆。 某些房屋特别需要互联网。 我们最多可以安装服务器$k$房屋，每个需要互联网的房屋都会沿着某条路径连接到最近的服务器。 房屋经历的延迟是沿着到其指定服务器的路径的边缘的最大权重。 任务是，对于每个$k = 1$到$n$，在选择最佳可能的放置位置时确定所有需要互联网的房屋的最小总延迟$k$服务器。 

输入约束很大。$n$和$m$每个都能达到$2 \cdot 10^5$，并且所有测试用例的总和不超过$2 \cdot 10^5$。 这排除了比粗略更糟糕的情况$O(n \log n)$每个测试用例，当然排除了朴素的组合方法。 需要互联网的房屋数量$p$可以达到$n$，所以解决方案不能依赖于$p$很小。 

一个天真的方法可能会尝试所有子集$k$服务器的房屋并计算每个子集的总延迟。 为了$k=1$到$n$，这将呈指数级缓慢且不可行。 另一个微妙的边缘情况是当多个需要互联网的房屋相邻时或者当一些房屋需要互联网但具有零延迟边缘时。 粗心的实现可能不会考虑正确的“沿路径的最大边缘”度量，或者可能假设单个最短路径度量而不是问题所需的最大边缘度量。 

例如，考虑一个节点三角形$1,2,3$有边缘$1-2=1$,$2-3=10$,$1-3=2$， 和$p=2$有房子$2$和$3$需要互联网。 如果$k=1$我们选择节点 1 处的服务器，简单的距离总和方法可能会选择对边权重求和的路径，给出 1+2=3，但正确的度量是沿路径的最大边，因此延迟为 1 和 10，总和为 11。错误的度量将产生无声的错误答案。 

## 方法

 暴力方法的地方$k$所有组合中的服务器$n$节点并计算每个对互联网有需求的房屋到服务器的最小最大边缘路径。 沿路径计算最大边需要全对处理或重复树遍历。 即使计算所有对的最大边也需要$O(n^3)$在邻接矩阵方法中或$O(nm)$每个服务器都使用 BFS，这对于我们的边界来说是不可行的。 

关键的见解是将问题转化为最小生成树（MST）问题。 延迟度量（沿路径的最大边缘）相当于 MST 术语中的“瓶颈”边缘。 在树中，两个节点之间唯一路径的最大边是固定的。 因此，问题简化为找到一个连接所有需要互联网的房屋的子图，从而最小化沿着到服务器的路径的最大边缘。 这可以通过构建图的 MST 并以“切割”最大边来减少总延迟的方式选择服务器位置来准确捕获。 

我们可以按权重对边进行排序，并使用 Union-Find（不相交集并集）来构建类似 Kruskal 的 MST，但进行了增强以跟踪每个组件中需要互联网的房屋数量。 当我们合并组件时，连接两个组件的最大边会增加总延迟乘以该边（如果我们要“切割”它）将被该边分隔开的互联网房屋的数量。 当考虑$k$服务器，这相当于删除$k-1$该 MST 的最大边。 因此，问题简化为计算这些排序的边贡献的累积和。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 蛮力 | O(n 选择 k * n) | O(n+m) | 太慢了|
 | MST + 并查 + 边排序 | O(m log m + n log n) | O(m log m + n log n) | O(n+m) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，阅读图表和需要互联网的房屋组。 跟踪哪些节点需要互联网。 
2. 构建边及其权重的列表。 
3. 通过增加权重对边进行排序。 
4. 初始化并查数据结构以跟踪连接的组件。 每个组件都会维护其包含的需要互联网连接的房屋的数量。 
5. 初始化一个空的“贡献”值列表，它将存储两个组件合并时添加的额外延迟。 
6. 迭代边缘以增加权重。 对于每条边连接$u$和$v$，找到它们的组件的根。 让$cnt_u$和$cnt_v$是每个组件中互联网公司的数量。 如果根不同，则将较小的组件合并到较大的组件中。 边权重贡献$w * cnt_u * cnt_v$总延迟，因为一个组件中的每个互联网房屋在连接到另一个组件中的房屋时都会经历这一边缘。 将此贡献添加到贡献列表中。 
7. 处理完所有边后，我们得到了“单服务器”情况下的总延迟。 按贡献值降序排列。 这个想法是，添加更多服务器可以让我们“削减”最大的贡献，因为将服务器放置在端点可以避免这种优势。 
8. 计算移除贡献的前缀总和$k = 1$到$n$。 对于每个$k$，最小总延迟是所有贡献的总和减去最大的总延迟$k-1$贡献，固定为零。 
9. 输出每个的总延迟$k$。 

为什么这样工作：该算法利用了树中任何路径上的最大边都是瓶颈，而 MST 最小化了组件之间所有此类瓶颈的总和。 使用 Union-Find 可确保我们在每个步骤中正确跟踪每个组件中需要互联网的房屋数量。 切割最大的边缘模拟将服务器放置在最佳位置以隔离高延迟路径。

import sys

class DSU:
    def __init__(self, n, internet):
        self.parent = list(range(n))
        self.size = [1]*n
        self.internet_count = [1 if i in internet else 0 for i in range(n)]
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:

            x_root, y_root = y_root, x_root
        self.parent[y_root] = x_root
