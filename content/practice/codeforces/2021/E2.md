 ## 解决方案
 ## 问题理解

 我们得到一个代表村庄的无向连通图，其中节点是房屋，边缘是有延迟的互联网电缆。 部分房屋需要互联网，我们可以将服务器放置在最多`k`房屋。 每个需要互联网的房屋都会根据路径上的最大延迟连接到最近的服务器 - 也就是说，对于一个房屋`h`连接到服务器`s`，延迟时间`L(h)`是路径上最大的边权重`h`到`s`。 目标是最大限度地减少所有需要互联网的家庭的延迟总和。 任务是计算所有的最小总和`k = 1..n`。 

主要限制是：`n`最多可达 5000 个，`m`最多 5000 个，并且总和`n`和`m`跨测试用例≤ 5000。每个边的权重可以非常大，最多`10^9`。 这些数字排除了迭代所有子集的蛮力方法`k`服务器位置，因为对于`k`附近`n`组合的数量是天文数字。 边权重也很大，因此依赖整数计数而不是实际权重的算法将不起作用。 

一个重要的边缘情况出现时`k`大于或等于需要互联网的房屋数量`p`。 在这种情况下，每个这样的房子都可以自行托管服务器，使其延迟为零，从而产生最小的总延迟为零。 另一个微妙的情况是当图形稀疏或高延迟边缘占主导地位时，因为使用总和而不是沿路径的最大值的朴素最短路径方法将产生不正确的结果。 

## 方法

 蛮力方法是尝试每种组合`k`房屋作为服务器位置。 对于每种组合，我们将计算从每个需要互联网的房屋到最近的服务器的最大延迟路径。 这可以通过修改后的 BFS 或类似 Dijkstra 的程序来完成，该程序沿路径传播最大边权重。 虽然正确，但这种方法的速度呈指数级缓慢：即使`n = 5000`，选择`k = 5`放弃`2.5*10^16`组合，使得这种方法变得不可能。 

解锁最佳解决方案的观察结果是，问题可以简化为**需要互联网的房屋的最小生成树（MST）**。 如果我们只关心路径上的最大延迟，则 MST 保证对于任何两个连接的节点，它们之间的路径上的最大权重最小化。 一旦我们有了连接所有的 MST`p`需要网络的房子，我们可以“剪掉”`k-1`最大的边缘。 每次剪切都会有效地将连接的组件分配给单独的服务器。 这是可行的，因为在 MST 中，两个节点之间的任何路径都已经是具有最小可能最大边权重的路径。 因此，沿最大边缘分割 MST 可确保到服务器的最大延迟路径最小。 

关键的见解是将问题视为**树上的瓶颈分配**，而不是一般图，然后使用 **Kruskal 的 MST 算法**。 步骤是：为所有需要的节点构建 MST，按权重递减对边进行排序，并重复删除最大的边以增加服务器数量。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 暴力破解（所有服务器组合）| O(n^k * (n+m)) | O(n^k * (n+m)) | O(n+m) | 太慢了|
 | MST+最大边缘去除| O((n+m) log n) | O((n+m) log n) | O(n+m) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，阅读图表和需要互联网的房屋列表。 将它们标记在布尔数组中以进行快速成员资格检查。 
2. 使用 Kruskal 算法构建整个图的最小生成树。 添加边时，仅考虑最终连接所需节点的边。 将 MST 边保留在列表中。 
3. 提取 MST 中沿着连接所需房屋的路径的所有边。 这些边缘代表最大延迟瓶颈。 
4. 按权重降序对这些边进行排序。 此排序顺序中的每条边都对应于一个潜在点，在该点上添加新服务器将减少延迟：切割最大的边会分割组件。 
5. 初始化数组`latency_sums`尺寸的`n`。 开始于`k=1`，总延迟是所有 MST 边权重的总和。 对于接下来的每一个`k`，从 MST 和中删除下一个最大的边并将其分配给新服务器。 重复直到`k=n`。 为了`k > p`，剩余的延迟为零，因为每个所需的房子都可以拥有自己的服务器。 
6. 输出`latency_sums`为所有人`k`从 1 到 n。 

**为什么有效**：MST 确保两个所需房屋之间的任何路径在所有可能的子图中具有最小的最大延迟。 通过移除最大的边缘，我们有效地将所需的房屋划分为可由独立服务器提供服务的单独组件。 每次删除都会严格减少总延迟或保持不变，因此我们获得每个删除的最小总延迟`k`。 在不违反 MST 属性的情况下，不可能更好地分配服务器。

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0]*n
    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x
    def union(self, x, y):
        xr, yr = self.find(x), self.find(y)
        if xr == yr:
            return False
        if self.rank[xr] < self.rank[yr]:
            self.parent[xr] = yr
        else:
            self.parent[yr] = xr
            if self.rank[xr] == self.rank[yr]:
                self.rank[xr] += 1
        return True
