 ## 解决方案
 ## 问题理解

 我们有一个游戏，柯南和阿笠轮流从一堆牌中取出牌。 每张卡片上都写有一个正整数。 当玩家选择一张牌时，不仅该牌会被移除，而且所有数字严格较小的牌也会被移除。 当玩家因没有牌而无法移动时，游戏结束，该玩家输了。 柯南总是先行动。 任务是确定如果双方发挥最佳，谁将获胜。 

输入给出卡的数量`n`以及这些卡片上的整数列表。 如果第一个玩家可以强制获胜，则输出为“Conan”；如果第二个玩家可以，则输出为“Agasa”。 约束条件允许`n`最高 100,000，卡值最高 100,000。 这意味着任何在纸牌上以二次方时间迭代或模拟所有可能的移动的解决方案都可能太慢。 我们需要一个线性或线性算术解。 

当许多卡具有相同的号码时，就会出现边缘情况。 例如，如果所有卡牌都相同且数量为偶数，则柯南无法在一个回合中移除所有卡牌。 选择任何卡牌只会移除该值的卡牌。 然后阿笠可以镜像移动，直到所有牌都消失。 像这样的小输入`2\n5 5`应该输出“Agasa”，但是假设最大的牌总是获胜的粗心方法会错误地返回“Conan”。 同样，如果一张牌是独特的并且比所有其他牌都大，柯南可以拿走它并立即获胜，就像`3\n4 5 7`选择 7 会移除所有牌。 

## 方法

 蛮力方法将模拟每一个可能的动作序列。 在柯南的回合中，尝试每张牌，删除所选牌和所有较小的牌，然后递归计算对手的最佳动作。 这是正确的，但呈指数级增长`n`，因为每个卡的选择都可以导致多个递归分支。 即使有记忆，状态空间也很大，因为剩余卡的每个子集都是一个单独的状态，这使得它不可行`n = 10^5`。 

关键的观察结果是，唯一重要的因素是**每个卡号的频率奇偶性**。 每一步都会消除所有较小的数字，因此游戏有效地减少了计算每个唯一值存在多少张牌。 如果存在**奇数**的数字，柯南总是可以从其中一个开始，留下偶数或迫使阿笠陷入失败的境地。 相反，如果所有计数都是偶数，阿笠可以模仿柯南的动作，最终让柯南在他的回合中没有牌。 这将问题简化为简单的频率检查。

 ## 算法演练

 1.读取输入的卡片数量`n`以及卡值列表。 
2. 使用字典或字典计算每张牌值出现的频率`Counter`。 
3. 迭代频率值。 
4. 如果任何频率是奇数，则打印“Conan”并停止。 理由是，奇数计数可以让柯南强行取得第一优势； 无论阿笠采取什么行动，柯南都可以做出反应以保持对等。 
5. 如果所有频率都是偶数，则打印“Agasa”。 在这种情况下，柯南所做的每一个动作都可以被阿笠镜像，直到阿笠轮到拿完最后一张牌为止。 
6. 结束。 

为什么有效：不变的是，在任何回合中，如果最小剩余数字的出现频率是偶数，则当前玩家无法获得决定性优势。 势均力敌决定了谁能取得胜利。 通过检查奇数，我们可以立即确定哪个玩家可以控制流量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import Counter

n = int(input())
cards = list(map(int, input().split()))
freq = Counter(cards)

for count in freq.values():
    if count % 2 == 1:
        print("Conan")
        break
else:
    print("Agasa")
```该代码可有效读取卡片数量和卡片面值。 这`Counter`计算每张独特卡出现的次数。 该循环检查是否有奇数计数，这保证了柯南的获胜举动。 这`else`仅当没有发生中断时循环才会触发，这意味着所有计数都是偶数。

## 测试用例```python
import sys, io
from collections import Counter

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    cards = list(map(int, input().split()))
    freq = Counter(cards)
    for count in freq.values():
        if count % 2 == 1:
            return "Conan"
    return "Agasa"

# Provided samples

 ## 边缘情况

 对于单张卡`1\n5`，频率为`{5:1}`，这很奇怪。 该算法按预期打印“Conan”。 对于两张相同的卡`2\n5 5`，频率为`{5:2}`， 甚至。 循环找不到奇数，因此打印“Agasa”。 对于像这样的混合计数`5\n1 1 2 2 2`，频率是`{1:2, 2:3}`。 第一个奇数（2:3）触发“Conan”，表明算法正确检测到获胜策略。 该实现始终能够正确处理大输入和奇偶校验逻辑。
