 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，需要找到**不是完美平方**的最大元素。 完美平方是可以表示为整数的平方的数字。 输入由数字 _n_（数组的大小）和后跟数组元素组成。 输出是一个整数：数组中不是完美平方的最大元素。 

约束条件很适中：_n_ 最多可达 1000，元素的范围为 -10^6 到 10^6。 负数永远不可能是完全平方数，因此我们立即知道它们是候选数。 _n_ 的上限意味着我们可以在线性时间内单独检查每个数字，而不会出现性能问题。 数字范围还允许我们使用整数算术安全地计算平方根。 

当数组包含大的完全平方数和较小的非平方数的混合时，就会出现边缘情况。 例如，输入`5\n1 4 9 16 2`最大的非正方形只有 2 个。 简单地选择最大数字而不检查平方的简单方法将返回 16，这是不正确的。 负数和零需要小心：零是完全平方数，而负数永远不是完全平方数。 

## 方法

 蛮力方法很简单。 我们迭代数组的每个元素并检查它是否是一个完美的正方形。 如果不是，我们会跟踪迄今为止看到的最大值。 检查一个数字是否是完全平方数可以通过取整数平方根并将其平方以查看它是否等于原始数字来完成。 由于最多有 1000 个元素，每个元素都需要恒定时间的平方根检查，因此总操作次数约为 1000 次，可以忽略不计。 因此，在实践中，蛮力是可以接受的，但对于较大的阵列来说，它可能会变得低效。 

关键的见解是我们不需要对数组进行排序或存储额外的数据结构。 一次线性传递就足够了。 对于每个元素，我们使用以下公式计算整数平方根`math.isqrt`函数，将其平方，并与原始数字进行比较。 如果它们不相等，则该数字不是完全平方数，我们将其与当前最大值进行比较。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 已接受 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 由于此问题中的最佳方法和强力方法实际上是相同的，因此重点是正确识别非正方形。 

## 算法演练

 1. 初始化变量`best`到负无穷大。 这将存储迄今为止发现的最大的非正方形。 
2. 迭代每个元素`x`数组的。 
3.如果`x`为负数，不可能是完全平方数。 将其与`best`并更新`best`如果`x`更大。 
4.如果`x`是非负数，计算`y = int(sqrt(x))`使用`math.isqrt(x)`。 检查是否`y * y == x`。 如果不，`x`不是一个完美的正方形。 
5. 如果`x`不是完全平方，比较一下`best`并更新`best`如果`x`更大。 
6.处理完所有元素后，输出`best`。 

**为什么有效：** 在每一步中，我们都保持不变式`best`是迄今为止看到的最大的非完全平方数。 因为我们检查每个元素并正确识别完全平方数，所以最终值`best`保证是最大的非正方形。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

best = -float('inf')
for x in a:
    if x < 0:
        best = max(best, x)
    else:
        y = math.isqrt(x)
        if y * y != x:
            best = max(best, x)

print(best)
```该解决方案首先使用有效地读取输入`sys.stdin.readline`。 我们初始化`best`为负无穷以正确处理负数。 对于每个元素，负数自动成为候选元素。 使用整数平方根测试非负数是否为完美平方，以避免浮点不准确。 最后，`best`包含最大的非正方形。

## 测试用例```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    best = -float('inf')
    for x in a:
        if x < 0:
            best = max(best, x)
        else:
            y = math.isqrt(x)
            if y * y != x:
                best = max(best, x)
    return str(best)

# provided samples
assert run("2\n4 2\n") == "2", "sample 1"

# custom cases
assert run("5\n1 4 9 16 2\n") == "2", "all squares except one"
assert run("3\n-1 0 1\n") == "-1", "negative numbers handled"
assert run("4\n2 3 5 7\n") == "7", "all non-squares"
assert run("1\n0\n") == "-inf", "single element, square zero"  # would never happen due to guarantee
assert run("6\n-100 -36 0 1 2 3\n") == "3", "mixed negative and positive"
```| 测试输入| 预期产出 | 它验证了什么 |

 |`3\n-1 0 1`| -1 | 正确处理负数 |
 |`4\n2 3 5 7`| 7 | 在所有非正方形中选择最大的非正方形 |

 ## 边缘情况

 对于输入`-1 0 1`,`best`从负无穷开始。`-1`是负数，所以`best`变为-1。`0`是一个完全平方数，被跳过。`1`是一个完全平方数，被跳过。 输出为-1，这是正确的。 该算法绝不会错误分类负数或零。 

对于输入`2 3 5 7`，所有数字都是非正方形。 算法更新`best`每一步都以 7 结尾。这证实了没有正方形的序列是自然处理的。 

这证实了该解决方案正确识别了所有边缘场景中最大的非正方形。
