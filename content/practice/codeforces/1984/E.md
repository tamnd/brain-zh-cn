 ## 问题理解

 我们有一棵树`n`节点，我们可以对其执行单个“shuffle”操作。 洗牌包括选择任何节点作为新根，将其从树中删除，递归地洗牌每个生成的子树，然后将所有洗牌后的子树根附加回该新根。 在执行完一次洗牌后，目标是最大化生成的树中的叶子数量。 叶子是度数为 1 的节点，因此如果根只有一个子节点，则可以算作叶子。 

输入由多个测试用例组成。 每个测试用例通过其边缘定义一棵树。 约束允许最多`2 × 10^5`每棵树的节点，以及`n`所有测试用例不超过`3 × 10^5`。 这立即意味着任何解决方案都必须在每棵树上以大致线性的时间运行。 尝试所有可能的方法来洗牌每个子树的幼稚方法将是指数级的且不可行。 

边缘情况包括具有 2 个节点的非常小的树、星形树或线性链。 例如，一条由三个节点组成的线`1-2-3`通过改组节点最多可以产生 2 个叶子`2`到根，而天真地选择端点作为根只会给出 1 个叶子。 一颗具有一个中心和多个叶子的恒星不能产生比现有叶子更多的叶子。 正确处理这些需要推理每个节点的子节点以及子树选择如何传播。 

## 方法

 暴力解决方案将递归地尝试每个子树的每个可能的根。 在每个节点，我们将通过尝试将每个子节点作为其子树的新根并组合结果来计算可实现的叶子数量。 虽然这在逻辑上可行，但它需要评估每个子树的根的所有排列。 对于大小为 2 × 10^5 的树来说，这太慢了——本质上是阶乘复杂度。 

关键的观察是我们不需要考虑所有排列。 每个子树根据其大小和结构贡献一定数量的叶子，并且我们可以通过在最大化其贡献的节点处生根子树来贪婪地最大化叶子。 更具体地说，子树中的叶子只有在被选为下一个洗牌级别的根时才能成为内部叶子。 相反，如果我们巧妙地将其子树作为根，任何非叶节点都可以变成叶节点。 因此，问题简化为树上的动态规划方法。 

我们定义`dp[u]`如果我们以节点为子树的根，则可获得的最大叶子数`u`。 如果`u`是原始树中的一片叶子，`dp[u] = 1`。 否则，`dp[u] = sum(dp[v] for all children v)`。 原因是每个子子树都可以贡献至少一个叶子。 在最后一步中，如果根只有一个子节点，那么它也可以成为叶子。 这可以通过计算合并`max(1, dp[u])`如果根有一个孩子，否则只是将所有孩子的贡献相加。

 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 树上的最优 DP | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，请阅读`n`和边列表。 为树构建邻接表。 
2. 选择任意根（例如节点 1）。 我们将执行 DFS 来计算`dp[u]`对于所有节点。`dp[u]`表示如果节点可获得的最大叶子数`u`是其当前子树的根。 
3.在DFS中，对于每个节点`u`,遍历所有孩子`v`不等于父级。 递归计算`dp[v]`。 
4.如果`u`在 DFS 中没有子节点（即它是叶子），设置`dp[u] = 1`。 否则，总结所有`dp[v]`其孩子的价值观。 这代表让每个子子树贡献尽可能多的叶子。 
5. DFS之后，考虑到原始根可能只有一个孩子。 那么，根本身也可以变成叶子，所以`dp[root]`如果根在 DFS 树中只有一个子节点，则可以加 1。 
6. 打印`dp[root]`作为测试用例的答案。 

**为什么有效**：每个`dp[u]`表示在最佳洗牌下该子树中可实现的最大叶数。 通过从叶子到根的计算，我们保证所有子树都贡献其最大可能的叶子数量。 由于洗牌仅应用一次，因此计算中会考虑每个节点，并且不会重复计算任何节点。 不变量是处理完一个节点后，`dp[u]`正确表示以最佳洗牌子树为根的叶子计数`u`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n + 1)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            adj[u].append(v)
            adj[v].append(u)

        def dfs(u, parent):
            leaves = 0
            child_count = 0
            for v in adj[u]:
                if v != parent:
                    child_count += 1
                    leaves += dfs(v, u)
            if child_count == 0:
                return 1
            return leaves

        print(dfs(1, 0))

if __name__ == "__main__":
    solve()
```DFS 自下而上计算叶子。 对于每个节点，如果它没有子节点，则它是叶子。 否则，它会累积所有子节点的叶子。 我们不需要专门处理根，因为在任何最佳洗牌中，根都会通过聚合所有子树叶子自动做出最大贡献。
