 ## 解决方案
 ## 问题理解

 我们正在处理一系列数字，同时维护从零开始的运行值。 在每个位置，我们必须在两个操作之间做出决定：要么直接将当前数字相加，要么将其相加然后取结果的绝对值。 第二个操作可以看作是“重置符号”操作，可以防止运行总和变为负数，但它也可能会破坏有用的负积累，而这些积累可能在以后变得有益。 

目标是在数组中选择这些操作，以在处理所有元素后最大化运行总和的最终值。 

关键的难点在于绝对值运算不是局部的。 采取绝对提前可以翻转整个累积和的符号，这会改变未来添加的行为方式。 这在决策之间创建了一种依赖关系，看起来就像连续状态空间上的动态编程。 

约束很大：测试用例中所有数组的总长度最多为 300,000。 这立即排除了所有前缀和状态上的任何二次 DP。 如果使用重型结构实现，即使每个测试用例的 O(n log n) 解决方案也将是边缘的，因此每个测试用例的预期解决方案必须是线性的。 

当运行总和在几个大的负值之后变为负值时，就会出现微妙的边缘情况。 例如，如果我们有一个像 [-5, -4] 这样的早期前缀，我们可能希望避免过早应用绝对值，因为后来的正数可以从在正确的时间翻转符号中受益。 相反，太晚应用绝对值可能会“锁定”负前缀，从而拖累所有未来的添加。 

另一个重要的边缘情况是所有数字均为非负数或全部为非正数。 如果全部都是非负数，则绝对运算毫无帮助，答案就是简单的求和。 如果所有值都为非正数，则重复取绝对值会有效地将过程转变为累加量值，但时机仍然很重要。 

## 方法

 蛮力策略将尝试在每个索引处应用或不应用绝对值的所有可能选择。 由于每个位置有两个选择，这导致每个测试用例有 2^n 种可能性。 对于 n 高达 2⋅10^5 的情况，这是完全不可行的。 即使 n = 40，它也变得临界。 

为了超越暴力，我们检查绝对操作实际上做了什么。 假设在某个步骤我们有当前值 c 并添加 a_i。 没有绝对值，我们得到 c + a_i。 对于绝对值，我们得到|c + a_i|，这相当于如果它是非负的则保持它不变，或者如果它是负的则翻转它的符号。 

这意味着仅当前缀和变为负数时该操作才有意义。 如果我们决定使用绝对值“修复”负前缀，那么我们实际上会丢弃到该点为止的符号历史记录，并将结果视为非负。 

关键的观察结果是，最优策略永远不会从复杂模式中多次应用绝对值中受益。 重要的是我们是否允许运行总和变为负值，以及在我们“恢复”它之前它变为负值的深度。 一旦我们决定恢复，最好的恢复就是取迄今为止看到的最小前缀和的绝对值。 

这导致了简化：答案取决于前缀和的最大可能绝对偏差。 直观上，我们希望最大化最终值，而绝对值唯一有帮助的时候是将负前缀转换为正前缀，从而有效地将大量负积累转化为大量正增益。 

因此我们跟踪前缀和及其最小值。 最好的策略对应于求总和或翻转一个足够负的前缀，以便其大小产生积极的贡献。

更精确的观点是，最佳答案是所有可能的最终状态中的最大值，其中我们选择一个断点 i，使得 i 之前的所有内容都允许变为负数，然后如果有利的话，我们翻转该前缀的符号。 这减少了跟踪前缀和并选择最佳可能的改进。 

我们可以维护当前的前缀和和最小前缀和。 答案是最终和与最终和的最大值减去最小前缀和的两倍，相当于翻转最差的前缀段。

 ## 算法演练

 我们处理数组的同时维护两个值：运行的前缀和和迄今为止观察到的最小前缀和。 

1. 将当前和初始化为 0，将最小前缀和初始化为 0。 

这表示处理任何元素之前的空前缀。 
2. 从左到右迭代数组，将每个元素添加到运行总和中。 

处理每个元素后，运行和反映了一致选择加法运算的效果。 
3. 更新运行和后，用迄今为止看到的最小值更新最小前缀和。 

这跟踪在任何前缀处达到的低于零的最深下降。 
4. 遍历完成后，计算两个候选值：最终总和以及“翻转”最差前缀得到的值，即final_sum - 2 * min_prefix_sum。 

减法相当于将负贡献转换为正贡献。 
5. Output the maximum of these two values.

 仅考虑最小前缀背后的逻辑是，绝对运算的任何最佳使用都可以解释为恰好纠正前缀结构中的一个连续负偏差段。 最差的下降决定了这种修正的最大可能增益。 

### 为什么它有效

 运行总和对所有决策进行编码，就好像我们从未使用过绝对值一样。 任何绝对值的应用只能将某些前缀和的符号从负变为正。 唯一重要的前缀是最负的前缀，因为翻转较小的负前缀并不能比翻转最小值更好地改善结果。 因此，相对于朴素总和的最佳可实现改进完全由最小前缀和确定，从而使解决方案完整。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        cur = 0
        min_pref = 0
        
        for x in a:
            cur += x
            if cur < min_pref:
                min_pref = cur
        
        ans = max(cur, cur - 2 * min_pref)
        out.append(str(ans))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案一次性计算前缀和。 变量`cur`如果我们从未应用绝对值，则为运行总计。 变量`min_pref`记录该轨迹到达的最低点，代表负段累积的最大“伤害”。 最终表达式将未修改的结果与通过反映零附近最差前缀获得的最佳可能校正进行比较。 

表达式`cur - 2 * min_pref`至关重要：当`min_pref`为负数，这会增加结果，有效地将负数下降转化为正数增益。

 ## 边缘情况

 完全正数组，例如`[2, 3, 1]`永远不会从绝对操作中受益。 运行总和永远不会低于零，因此最小前缀保持为零，并且算法返回普通总和。 这证实了当不存在负结构时，“翻转校正”术语不会人为地夸大结果。 

一个完全负的数组，例如`[-1, -2, -3]`产生稳定递减的前缀和。 最小前缀等于最终总和，公式翻转整个累加，将其转换为等于总和绝对值的正总和。 

混合序列如`[3, -10, 4]`演示了部分校正。 第二个元素之后前缀下降到-7，成为决定增益的关键值。 翻转该下降可以恢复丢失的幅度，并产生比任何未校正的累积更高的最终结果。
