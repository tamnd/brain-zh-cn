 ## 解决方案
 ## 问题理解

 该过程描述了一个雪球从起始高度向下滑动直到到达地面。 在每个整数高度级别，雪球在三个有序阶段中重复改变其重量：它首先获得等于其当前高度的额外重量，然后如果该高度有一块石头，则可能会减轻重量，最后向下移动一步。 

输入描述了该系统的初始状态。 我们给出了雪球的起始重量和起始高度，以及放置在特定高度的两块石头，每当雪球经过它们的高度时，每块石头都会去除固定量的重量。 

任务是模拟这种运动，直到雪球到达零高度并报告其最终重量。 关键的难点在于权重随着特定位置的累加和减法而不断演变。 

约束很小：高度最多为 100，权重最多为 100。这立即意味着对每个高度级别的直接模拟足够有效，因为最多执行 100 个步骤，并且每个步骤执行 O(1) 工作。 任何最多大约 10^7 次操作的解决方案在时间限制下都是安全的，因此除了直接迭代之外不需要进行优化。 

如果不严格遵循操作顺序，一些边缘情况很容易被错误处理。 一是忘记了在石头碰撞之前重量会增加。 例如，如果雪球从高度 1 开始，石头的高度为 1，则高度的增量首先发生，因此雪球在失去重量之前会增加重量。 另一个是在石头撞击后错误地处理负重量。 该问题明确地将权重限制为零，但继续模拟，因此天真的提前停止是不正确的。 

第三种微妙的情况是石头的重量为零。 即使这样，碰撞仍然必须被处理，尽管它没有改变任何东西。 有条件地跳过这些石头是安全的，但在那个高度完全跳过碰撞步骤则不安全，因为顺序对于一致性很重要。 

## 方法

 暴力解决方案直接逐秒模拟该过程。 在每个高度，我们将雪球重量增加当前高度，如果适用，则施加石头伤害，如果为负，则将结果钳位为零，然后减少高度。 由于每次迭代高度正好减少 1，因此该模拟正好运行 h 个步骤。 每个步骤都是恒定的时间，因此在给定的约束下，暴力方法已经是最佳的。 

没有隐藏的数学结构来进一步压缩，因为状态转换仅取决于当前身高和当前体重，并且身高严格减小。 任何跳过步骤的尝试仍然需要考虑石头在各个高度的相互作用，因此没有聚合技巧以有意义的方式进一步降低复杂性。 

正确和错误解决方案之间的主要区别不在于效率，而在于严格遵守事件顺序。

 ## 算法演练

 我们模拟雪球一次下降一层，始终跟踪其当前的高度和重量。

1. 根据输入初始化雪球的重量和高度，并将两块石头存储在允许按高度快速查找的结构中。 这很重要，因为我们需要在每一步进行恒定时间的检查。 
2. 当当前高度大于零时，执行一个完整的更新周期。 
3. 首先将雪球重量增加当前高度。 这一步至关重要，因为这个问题定义了与石头发生任何相互作用之前的体重增加。 顺序决定正确性。 
4. 检查当前高度是否有石头。 如果是这样，请从雪球中减去它的重量。 如果多个石头存在于同一高度，则两种效果将按顺序应用，尽管此处的输入保证了不同的高度。 
5. 如果所得重量变为负值，则将其钳位至零。 雪球不会停止或改变行为； 仅调整存储的重量。 
6. 将高度减一以模拟向下运动。 
7. 重复直到高度为零，然后输出最终的重量。 

### 为什么它有效

 在每次迭代中，算法都会保留问题定义中描述的确切状态：权重反映了所有先前的增量和石头在更高或相等级别上的相互作用，并且高度严格跟踪剩余的未处理级别。 由于每个高度仅按正确的顺序处理一次，因此不会跳过或重复计算任何贡献。 因此，高度为零之后的最终状态是所有确定性转变的累积结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    w, h = map(int, input().split())
    u1, d1 = map(int, input().split())
    u2, d2 = map(int, input().split())

    stone = {}
    stone[d1] = u1
    stone[d2] = u2

    weight = w
    height = h

    while height > 0:
        weight += height

        if height in stone:
            weight -= stone[height]
            if weight < 0:
                weight = 0

        height -= 1

    print(weight)

if __name__ == "__main__":
    solve()
```该解决方案将石头效果存储在按高度键入的字典中，以便在给定级别检查石头的时间复杂度为 O(1)。 该循环处理从 h 到 1 的高度，与雪球的物理运动相匹配。 增量步骤发生在查找之前，保留所需的顺序。 

减法后的钳位步骤是必要的，因为即使过程继续不变，负权重也不允许持续存在。

 ## 边缘情况

 一种微妙的情况是，当石头在一定高度时消除的重量比当前存在的重量更多。 例如，在雪球刚刚获得少量高度的高度，一块大石头可能会将其推向负值。 该算法在减法后显式钳位为零，确保状态保持有效而不中断循环。 

另一种情况是当石头位于高度 1 时。即使这是最后的活动步骤，雪球仍然执行完整的序列：增益 1，应用石头，然后移动到零。 循环结构自然地处理这个问题，无需特殊分支，因为高度仅在处理后才变为零。 

第三种情况是两颗宝石的重量都为零。 模拟仍然执行字典查找和减法尝试，但最终效果是中性的。 正确性取决于仍在执行碰撞步骤，即使它不改变状态。
