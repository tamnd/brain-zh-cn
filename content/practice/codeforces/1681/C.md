 ## 解决方案
 ## 问题理解

 我们有两个长度相同的数组，`a`和`b`。 我们可以执行一个特殊的交换操作：选择任意两个位置`i`和`j`，同时交换`a[i]`和`a[j]`和`b[i]`和`b[j]`。 目标是使用最多 10,000 次移动将两个数组排序为非降序。 我们必须要么制定一系列行动来实现这一目标，要么报告说这是不可能的。 

输入指定多个测试用例。 每个测试用例都给出数组长度和数组元素。 输出必须打印`-1`如果不存在序列，或者首先是移动数，然后是移动对本身。 

鉴于限制条件，`n`最多可以是 100，我们允许移动 10,000 次。 这很慷慨：对每个无序元素执行类似冒泡排序的交换的朴素算法最多可以执行 O(n²) 次交换，由于当 n = 100 时 n² = 10,000，因此最多为 10,000 次。因此，二次时间算法是可行的。 每个元素都在`[1, n]`，它允许进行简单的比较，而不必担心大整数溢出。 

关键的边缘情况是无法同时排序的数组，即使每个数组都可以单独排序。 例如，`a = [2, 1]`和`b = [1, 2]`不能用任意数量的同时交换进行排序，因为任何修复的交换`a`会打破`b`。 另一个边缘情况是已经排序的数组； 该解决方案应该输出零步。 具有重复值的数组是有效的，因为可以出现多个相同的数字并且不会妨碍排序。 

## 方法

 暴力方法是重复扫描数组并交换任意对`(i, j)`其中任一数组都是无序的。 这是有效的，因为每次交换都会减少至少一次反转。 对于两个长度的数组`n`，每个数组中最多有 O(n²) 次反转，因此在最坏情况下交换次数为 O(n²)。 自从`n ≤ 100`，这最多会产生 10,000 次交换，这是允许的。 但是，如果数组的顺序发生冲突，其中一个数组想要向左交换，而另一个数组想要向右交换，则暴力方法可能会失败。 在这种情况下，不可能同时对两个数组进行排序。 

关键的观察是我们可以使用简单的成对冒泡排序方法进行排序，但我们必须保持第一个数组的不变性`a`和第二个数组`b`每次移动后都不会减少。 为了确保这一点，我们仅在以下情况下交换`a[i] > a[j]`或者`b[i] > b[j]`同时地。 如果在任何时候一个数组中的反转无法与另一个数组对齐，我们就会检测到不可能性。 通过系统地将最小的剩余元素推入正确的位置（如选择排序），同时交换`b`，我们可以对两个数组进行排序或检测冲突。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解泡沫 | 每个测试用例的 O(n²) | O(n) | 已接受（10⁴ 步以内）|
 | 最优选择排序变体 | 每个测试用例的 O(n²) | O(n² 移动) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`，数组`a`和`b`。 
3. 初始化一个空的移动列表。 
4. 对于每个位置`i`从`0`到`n-1`，找到最小的`j ≥ i`使得两者`a[j]`和`b[j]`可以放置在适当的位置`i`不违反相对于先前元素的非递减顺序。 如果没有这样的`j`存在，输出`-1`因为这是不可能的。 
5. 如果`j ≠ i`， 交换`a[i]`和`a[j]`和`b[i]`和`b[j]`，并记录移动`(i+1, j+1)`使用从 1 开始的索引。 
6. 继续此过程直到数组末尾。 经过所有迭代后，`a`和`b`应该排序。 
7. 打印移动次数和移动顺序。 

为什么它有效：该算法保持了位置之前元素的不变性`i`在两个数组中都已排序。 每次交换都会将一个元素移动到两个数组中的正确位置，而不会违反先前的顺序。 如果在任何时候都没有合适的元素可以移动到位`i`，数组处于冲突状态，无法同时排序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        moves = []
        possible = True
        for i in range(n):
            for j in range(i+1, n):
                if a[i] > a[j] or b[i] > b[j]:
                    a[i], a[j] = a[j], a[i]
                    b[i], b[j] = b[j], b[i]
                    moves.append((i+1, j+1))
        if a != sorted(a) or b != sorted(b):
            print(-1)
        else:
            print(len(moves))
            for x, y in moves:
                print(x, y)

if __name__ == "__main__":
    solve()
```外循环迭代每个位置以确保最小的剩余元素被正确放置。 内部循环仅在必要时执行交换。 我们根据问题陈述的要求附加从 1 开始的索引移动。 在所有交换之后，将根据其排序版本检查数组以检测不可能性。

 ## 边缘情况

 具有重复值的数组，例如`a = [2,2]`和`b = [1,1]`，不需要交换。 算法正确输出`0`。 如果数组的顺序有冲突，例如`a=[2,1]`和`b=[1,2]`，该算法执行交换`i=0,j=1`，检查数组并确定不可能性。 对于已经排序的数组，不会记录任何移动。 该算法保持了最小尺寸数组的正确性`n=2`和最大`n=100`。
