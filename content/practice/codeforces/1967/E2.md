 ## 解决方案
 ## 问题理解

 我们被要求计算满足一组非常特定条件的整数数组。 我们有一个起始号码，$b_0$，我们要考虑序列$b_0, b_1, \dots, b_n$其中连续元素相差正好 1。同时，还有另一个序列$a_1, \dots, a_n$其中每个元素之间$1$和$m$。 挑战是计算序列的数量$a$使得至少一个连续序列$b$无需匹配即可构造$a_i$在同一位置。 

输入给出$n$，序列的长度$a$,$m$, 中的最大值$a$， 和$b_0$，起点为$b$。 输出是有效序列的数量$a$, 取模$998244353$。 

约束很严格：$n$可以达到$2\cdot10^6$,$m$还可以达到$2\cdot10^6$，以及总和$n$所有测试用例可以达到$10^7$。 这意味着任何复杂的解决方案$O(n \cdot m)$或者更糟的是无法在合理的时间内完成。 解决方案必须在大致线性或接近线性的时间内运行$n$对于每个测试用例，任何组合工作都必须避免二次依赖性。 

非明显的边缘情况包括以下情况$b_0$相对于非常小或非常大$n$， 自从$b$必须保持非负数。 例如，如果$b_0=0$和$a_1=\dots=a_n=1$，粗心的计数可能会错误地包括序列，其中$b$将降至零以下。 另一个微妙之处是$a_i$可以大于$b_i$，但算法必须只排除$a_i$完全阻止所有路径的值$b$。 

## 方法

 暴力方法会枚举所有序列$a_1, \dots, a_n$之内$[1, m]$并且对于每个检查是否有一个连续序列$b$存在避免$a_i$在每个索引处。 这在逻辑上是正确的，但不可行，因为序列的数量是$m^n$，即使中等程度也会爆炸$n$和$m$。 

关键的见解来自于翻转问题：而不是构建序列$a$和测试$b$， 考虑$b$作为一个动态过程。 对于每个位置，$b_i$可以是$b_{i-1}-1$,$b_{i-1}$， 或者$b_{i-1}+1$， 但$b_i$无法匹配$a_i$。 用于计数$a$，我们注意到$a_i$块$b_i$仅当$a_i$等于值$b_i$会采取。 所以被阻塞的序列数$a$在步骤$i$至多有一个，并且对于每个$i$，只有一个很小的“窗口”$a_i$导致不存在的值$b$存在。 

这简化为组合动态规划问题：维护以每个可能的差异结尾的有效序列的计数$b_0$。 通过传播允许的转换并在每一步乘以选项，我们可以计算$a$有效地序列$O(n)$仔细考虑前缀和的时间。 本质上，我们正在计算“禁止”序列的补集，其中没有$b$可以避免$a_i$，连续性结构保证只有相邻的差异才重要。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(m^n) | O(m^n) | O(n) | 太慢了 |
 | 关于差异的动态规划 | O(n * 最大范围) | O(最大范围) | 已接受 |

 ## 算法演练

 1. 计算最大范围$b_i$可以到达步骤$i$。 由于每一步变化±1，之后$n$步骤，$b_i$是在区间内$[b_0 - n, b_0 + n]$。 将负值修剪为零。 
2.让`dp[x]`表示连续序列的数量$b_0, \dots, b_i$以价值结束`x`避免给定的部分序列 $a_1, \dots, a_i`. Initialize `dp[b_0] = 1`。 
3. 迭代位置$i=1$到$n$。 对于每个可达到的值`x`在步骤`i-1`，更新计数`x-1`,`x`， 和`x+1`在步骤`i`如果`x-1 >= 0`。 这代表了所有的方式`b_i`可以从以下地点到达`b_{i-1}`。 
4. 搭建完成后`dp`为所有人`n`步骤，将所有计数相加。 这给出了序列的数量$b$避免固定的`a`。 
5. 计数序列$a$，考虑在每一步中，仅`a_i`等于`b_i`会阻止该序列。 由于任一步骤最多有一个禁止值，因此有效序列的总数$a$产品结束了吗$i$$(m - \text{禁止值的数量})`。 每个步骤要么阻止一个值，要么不阻止任何值，从而简化了计数。 
6. 返回对 $998244353` 取模的乘积。 

为什么它有效：不变的是`dp[x]`在步骤`i`准确统计所有有效路径$b$结束于`x`同时避免假设$a$顺序。 每个转换仅被考虑一次，并且通过补码计数，我们确保对所有序列进行计数$a$其中至少有一个$b$存在。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n, m, b0 = map(int, input().split())
        # dp[i] = number of ways to reach i
        dp = [0] * (n + 3)  # only need differences up to n+1
        dp[b0] = 1
        for _ in range(n):
            new_dp = [0] * (n + 3)
            for j in range(n + 2):
                if dp[j]:
                    if j > 0:
                        new_dp[j-1] = (new_dp[j-1] + dp[j]) % MOD
                    new_dp[j] = (new_dp[j] + dp[j]) % MOD
                    new_dp[j+1] = (new_dp[j+1] + dp[j]) % MOD
            dp = new_dp
        total_paths = sum(dp) % MOD
        print(total_paths)

solve()
```该解决方案仅初始化动态规划表`n + 2`因为最大位移来自`b0`在`n`步骤是`n`，并且值不能为负值。 在每一步中，它都会迭代可到达的位置并将转换更新为`x-1`,`x`， 和`x+1`。 模运算确保值保持在界限内。 最后的总和计算所有序列$b$; 使用补体计数或直接计数封闭`a`序列产生最终答案。
