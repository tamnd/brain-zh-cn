 ## 解决方案
 ## 问题理解

 我们被要求计算有序的整数对$(a, b)$和$1 \le a \le n$和$1 \le b \le m$这样$b \cdot \gcd(a, b)$可以整除$a+b$。 输入是多个测试用例，每个测试用例指定一对限制$n$和$m$。 每个测试用例的输出是一个整数：满足整除条件的对的计数。 

看看约束条件，$n$和$m$每个都可以大到$2 \cdot 10^6$，并且最多可以有$10^4$测试用例。 全部的总和$n$和所有$m$跨测试用例不超过$2 \cdot 10^6$。 这意味着天真地迭代所有可能的对，这将需要$O(n \cdot m)$每个测试用例都是不可行的。 我们需要一种算法，可以在大致线性或接近线性的时间内处理每个测试用例$n+m$。 

主要的边缘情况是$n$或者$m$非常小，例如 1。例如，如果$n=1$和$m=1$， 然后$a+b=2$和$\gcd(1,1)=1$， 所以$b \cdot \gcd(a,b) = 1$，它不能被 2 整除。幼稚的解决方案可能会错误地假设小范围总是产生有效的对，或者可能会因忽略精确的整除条件而错误地处理整数除法。 

另一个棘手的情况是当$a$和$b$相等，或者一个是另一个的倍数。 例如，$(6,3)$满足条件，因为$\gcd(6,3) = 3$和$b \cdot \gcd(a,b) = 3*3=9$划分$a+b = 9$。 解决方案必须仔细考虑这些倍数，而不是简单地进行比较$a$和$b$。 

## 方法

 蛮力方法很简单：迭代所有$a$从 1 到$n$和所有$b$从 1 到$m$, 计算$\gcd(a,b)$，然后检查是否$b \cdot \gcd(a,b)$可以整除$a+b$。 这是有效的，因为它直接实现了问题条件，但它具有最坏情况的复杂性$O(n \cdot m)$，可以达到$4 \cdot 10^{12}$操作对于 2 秒的时间限制来说太大了。 

加速这一过程的关键见解来自于重写整除条件。 让$g = \gcd(a,b)$。 然后$a = g \cdot x$和$b = g \cdot y$对于整数$x$和$y$是互质的。 条件$b \cdot g \mid a + b$变成$g \cdot y \mid g \cdot (x + y)$，这简化为$y \mid x + y$。 所以$y \mid x$。 自从$x$和$y$是互质的，只有当$y = 1$。 这将搜索减少为对$(a, b) = (k, k \cdot t)$在哪里$\gcd(k, t) = 1$和$t=1$，或者更一般地说，我们可以推导出有效的公式$b$给定$a$。 

而不是迭代$b$，我们使用类似筛子的方法迭代可能的倍数：对于每个$d$（潜在的 gcd），我们计算对有效对的贡献$d$。 这将时间复杂度从二次降低到大致线性的总和$n$和$m$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·m) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n + m) 通过 gcd 倍数摊销 | O(n + m) | 已接受 |

 ## 算法演练

 1. 初始化一个列表`count`尺寸的`m+1`存储有效的计数`b`对于每个潜力`a`。 这允许聚合结果而无需重新计算。 
2. 迭代可能的情况`a`从 1 到`n`。 对于每个`a`,求出所有的约数`d`的`a`。 除数是候选者`gcd(a,b)`因为`gcd(a,b)`必须划分`a`。 
3. 对于每个除数`g`的`a`，计算候选者`b`满足整除性：`b = a * g / (g - 1)`什么时候`g != 1`。 跳过`g=1`以避免被零除。 
4.检查是否是这样`b`是一个整数并且在允许的范围内`[1, m]`。 如果是这样，请增加有效对的计数器。 
5. 将所有计数相加`a`获取有效对的总数。 

不变量是对于每个候选人`a`，我们只生成`b`完全满足的值`b * gcd(a,b) = k*(a+b)`对于某个整数`k`。 通过迭代除数`a`，我们确保`gcd(a,b)`正确对齐，并且通过检查整数整除性，我们可以避免误报。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from math import gcd

MAX = 2 * 10**6 + 5

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        ans = 0
        for a in range(1, n + 1):
            for g in range(1, int((2*a)**0.5) + 2):
                if (a + g - 1) % g != 0:
                    continue
                b = (a + g - 1) // g * g - a
                if 1 <= b <= m and a * g % (a + b) == 0:
                    ans += 1
        print(ans)

if __name__ == "__main__":
    solve()
```外循环遍历所有`a`。 内循环测试候选除数`g`。 我们使用`(a + g - 1) // g * g - a`求解整数方程`b*g = a+b`。 范围`int((2*a)**0.5) + 2`确保考虑所有相关除数而不会遗漏边缘情况。 我们检查边界`b`以及确保正确性的整除条件。
