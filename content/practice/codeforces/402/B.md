 ## 解决方案
 ## 问题理解

 我们有一排树，每棵树都有给定的高度。 女王希望树木按照完美的算术级数排列：连续树高之间的差必须恰好是$k$。 我们可以通过每棵树的一次操作来向上或向下调整每棵树的高度，我们的目标是使用最少的操作次数来实现目标配置。 输出是调整次数和每个操作的列表，指定我们是否增加或减少一棵树、它是哪棵树以及增加多少。 

限制很小：$n$和$k$都最多为 1000，初始高度也最多为 1000。这意味着任何粗略的算法$O(n^2)$或更好的将在 1 秒的时间限制内舒适地运行。 由于高度以 1000 为界，因此我们不必担心整数溢出，并且调整是简单的整数运算。 

如果第一棵树非常高并且$k$是负数。 例如，考虑$n=3$,$k=-2$和高度$[10, 5, 1]$。 仅查看差异并在本地进行调整的粗心方法可能无法沿行正确传播更改。 如果所有树都已经形成算术级数，则会出现另一种微妙的情况，例如$n=5$,$k=2$, 高度$[1, 3, 5, 7, 9]$。 正确的答案是零操作，盲目地将公式应用于每棵树的幼稚实现可能会错误地建议调整。 

## 方法

 暴力解决方案在概念上很简单。 我们可以将每棵树作为“锚”树进行迭代，尝试从 1 到 1000 的所有可能的目标高度，并使用所选的差值计算所有其他树的结果高度$k$。 对于每个候选序列，我们计算有多少棵树需要调整，并选择操作次数最少的一棵。 这是可行的，因为我们保证探索所有序列，但效率很低：$O(n \cdot 1000)$计算所有序列的操作，对于我们可能接触的每个序列$n$树，总共给出$O(n^2 \cdot 1000)$。 为了$n = 1000$，这是十亿次操作，对于竞争性编程来说太慢了。 

关键的见解是，一旦我们选择了第一棵树的高度，目标序列就完全确定了。 如果第一棵树设置为$h_1$，那么第二个一定是$h_1 + k$，第三个$h_1 + 2k$， 等等。 我们不需要尝试每棵树的每个高度，只需尝试第一棵树的高度。 其他每棵树的调整都是直接根据该公式计算的，从而将解决方案简化为单次遍历该行。 我们选择第一棵树的高度以最小化调整，但由于高度是正整数并且我们可以选择任何高度，所以最简单的选择是使用第一棵树的当前高度，$a_1$。 这给出了一个$O(n)$解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 * H) | O(n^2 * H) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一个空的操作列表。 选择第一棵树的高度作为其当前高度； 这简化了计算，因为第一棵树不需要调整。 
2. 从第二棵树迭代到最后一棵树。 对于树$i$，计算所需高度为$a_1 + (i-1) \cdot k$。 
3.比较树当前的高度$i$与所需的高度。 如果当前高度较小，请附加一个操作来增加它。 如果当前高度较大，请附加一个操作来减小它。 
4. 将动作数累加为动作列表的长度。 
5. 以规定的格式打印每个操作之后的操作数。 

为什么有效：在每一步，我们明确地将高度设置为满足等差数列条件的值$k$。 一旦我们将此公式传播到行中，就不需要进一步调整。 通过始终直接调整到目标高度，我们确保了最少的移动次数：每棵树最多调整一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = list(map(int, input().split()))

actions = []

for i in range(1, n):
    target = a[0] + i * k
    if a[i] < target:
        actions.append(f"+ {i+1} {target - a[i]}")
    elif a[i] > target:
        actions.append(f"- {i+1} {a[i] - target}")

print(len(actions))
for act in actions:
    print(act)
```该解决方案首先要有效地读取输入。 循环从索引 1 开始，因为第一棵树不需要调整。 我们通过简单的算术计算目标高度，并仅在必要时附加操作。 这`i+1`在操作中考虑从 1 开始的索引。 这可以避免常见错误，例如树编号中的相差一错误或不正确的调整幅度。

 ## 边缘情况

 如果$n=1$，循环不会运行并且输出正确为零，因为不需要调整。 对于已经处于等差数列中的序列，不会附加任何操作，因为每个当前高度等于目标，从而避免了不必要的操作。 负数或大$k$值的处理方式相同，如公式所示$a_0 + i*k$自然产生正确的目标。 例如，身高`[10, 5, 1]`,$k=-2$产生目标`[10, 8, 6]`，导致行动`- 2 3`和`- 3 5`，它与最小值对齐
