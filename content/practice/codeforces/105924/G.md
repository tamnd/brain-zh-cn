 ## 解决方案
 ## 问题理解

 给定一个有 n 个顶点和 m 个边的无向图。 该图已经可以包含自环和同一对顶点之间的多条边。 每条边都以通常的方式对其端点的度数做出贡献，目标是通过添加尽可能少的额外边来修改图，以便每个顶点最终具有偶数的度数。 

一个重要的自由是我们可以在任意一对顶点之间添加边，包括添加自循环，并且我们还可以在同一对顶点之间添加多条边。 每条添加的边都会以与标准无向图中相同的方式改变度数：自循环为其顶点的度数贡献 2，而 u 和 v 之间的边将两个度数都增加 1。 

输出必须描述添加边的最小数量以及添加边的一种有效方法。 

约束 n, m ≤ 10^5 意味着我们必须在线性时间内处理该图。 任何尝试显式考虑顶点对或构建辅助密集结构的方法都会太慢。 唯一可行的方法是将问题简化为顶点奇偶性的简单结构不变量。 

一个关键的微妙之处是自循环的存在。 自循环不会改变顶点度数的奇偶性，因为它增加了 2。这意味着自循环对于直接修复奇偶性是无用的，但在构造中仍然允许它们，并且在某些边缘情况（例如单个奇数顶点）中可能需要。 

第二个微妙之处是图可能已经包含多个边，因此度计算必须纯粹依赖于计数出现次数，而不是假设简单的图结构。 

一种幼稚的方法会尝试在没有全局结构的情况下以任意方式贪婪地连接奇数度顶点。 如果局部配对决策最终导致奇数顶点未配对，例如当奇数顶点的数量未一致跟踪时，这可能会失败。 

## 方法

 第一个自然的尝试是观察只有每个顶点的奇偶性才重要。 人们可以计算所有具有奇数度的顶点，然后尝试贪婪地修复它们：重复选择两个奇数顶点并将它们连接起来。 这似乎是正确的，因为每个添加的边都会翻转两个端点的奇偶校验。 

这种贪婪的配对已经接近最优，但真正的问题是我们是否需要做一些比任意配对顶点更复杂的事情。 暴力思维是搜索所有可能的添加边的方式并验证条件，但这很快就会变成指数级的，因为每个边的选择都会改变两个奇偶校验，并且搜索空间随着奇数顶点的数量组合增长。 

关键的观察结果是奇偶校验是唯一重要的约束。 每条边相加都会翻转两个端点的奇偶校验，因此奇数顶点的总数始终为偶数。 因此，问题简化为任意配对奇数顶点，通过在它们之间添加一条边来固定每对顶点。 每条这样的边同时解析两个奇数顶点，并且对之间不需要交互。 

仍然存在一个微妙的情况：如果恰好有一个奇数顶点，我们就不能将它与另一个不同的顶点配对。 在这种情况下，唯一有效的操作是使用自循环将其与其自身连接，这会将其次数加 2 并修复奇偶校验。 

因此，解决方案完全是通过收集所有奇数度顶点并以任意顺序将它们配对来确定的，如果计数是奇数，则使用自循环。

 ## 算法演练

 我们处理图表并仅使用度奇偶性。

1. 通过迭代所有边并递增两个端点来计算每个顶点的度数。 自循环对同一个顶点贡献 2，这不会影响奇偶性，但我们仍然将它们计入度数计算中。 
2. 将所有度数为奇数的顶点收集到一个列表中。 该列表准确地代表了图中的不平衡情况。 
3. 如果列表为空，则图已满足条件，无需添加边。 
4. 如果列表长度为奇数，则从中取出一个顶点并使用自循环将其连接到自身。 从概念上讲，这会从奇数列表中删除该顶点，因为在加 2 后，其奇偶校验在度数计数中翻转 0 mod 2。 
5. 现在列表中所有剩余的顶点的数量都是偶数。 按顺序将它们配对：一次按两个顺序获取顶点，并将每对与新边连接。 
6.输出所有构造的边。 

顺序配对背后的原因是任何配对都是有效的，因为每条边独立地恰好固定两个奇数顶点并且不影响其他顶点。 

### 为什么它有效

 不变的是，在每个阶段，具有奇数度的顶点集合正是我们在列表中跟踪的集合。 每个操作都会删除两个顶点（当 u 和 v 配对时）或通过自循环有效地解析最后一个单例。 由于每个操作仅在本地翻转奇偶校验，并且永远不会在所选端点之外引入新的奇数顶点，因此该过程严格减少奇数顶点的数量，直到没有剩余。 奇数顶点的总数始终是偶数，除了可能通过自循环对单个顶点进行瞬态处理之外，这保留了正确性，因为自循环不会更改奇偶校验。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    deg = [0] * (n + 1)

    for _ in range(m):
        u, v = map(int, input().split())
        deg[u] += 1
        deg[v] += 1

    odd = []
    for i in range(1, n + 1):
        if deg[i] % 2 == 1:
            odd.append(i)

    res = []

    # If odd count is odd, fix one vertex with a self-loop
    if len(odd) % 2 == 1:
        x = odd.pop()
        res.append((x, x))

    # Pair remaining vertices
    for i in range(0, len(odd), 2):
        u = odd[i]
        v = odd[i + 1]
        res.append((u, v))

    print(len(res))
    for u, v in res:
        print(u, v)

if __name__ == "__main__":
    solve()
```该解决方案首先构建一个度数组，这是捕获奇偶校验信息所需的唯一结构。 邻接结构本身是无关紧要的，因为我们可以自由添加边，因此不存在连通性约束。 

奇数列表正好存储那些需要校正的顶点。 通过自循环处理单个剩余顶点是唯一不明显的实现细节。 如果没有此步骤，奇数个奇数顶点将导致一个顶点无法解析。 

为简单起见，配对按线性顺序完成。 由于任何配对都是有效的，因此不需要匹配算法或优化。

 ## 边缘情况

 一张只有一个顶点且没有边的图暴露了自循环的必要性。 次数为零，已经是偶数，因此无需采取任何操作。 该算法正确地生成一个空列表，因为奇数列表是空的。 

处理后只有一个顶点具有奇数度的图需要特殊处理。 例如，如果度为 [1, 0, 0]，则奇数列表为 [1]。 如果没有自循环步骤，算法就会失败，因为没有伙伴顶点。 自循环通过添加 (1, 1) 来解决此问题，这会将度数增加 2 并保留奇偶校验正确性，同时消除单例。 

具有许多奇数顶点的大图证实了线性配对。 由于每条边恰好在两个顶点处翻转奇偶校验，因此对奇数集的任何分区进行配对都是有效的。 该算法不依赖于结构，仅依赖于奇偶校验计数，因此即使奇数顶点在图中任意分布，它也保持正确。
