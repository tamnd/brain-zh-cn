 ## 解决方案
 ## 问题理解

 我们被要求对一个过程进行逆向工程，该过程通过在现有元素之后立即重复插入该元素的增量副本来生成序列。 正式地，我们从长度的初始序列开始`m`并重复插入`x_i + 1`在某个元素之后`x_i`直到序列的长度达到`n = m + k`。 任务是，给定最终序列`a`，找到最小起始长度`m`。 换句话说，我们想要可以产生的最小原始序列`a`通过有效的插入。 

输入由多个测试用例组成，每个测试用例都有一个序列`a`长度`n`高达 300,000。 总和为`n`所有测试用例不超过300,000。 由于时间限制为 2 秒，因此每个测试用例的任何超过大约 O(n) 次操作的解决方案都可能太慢。 二次解被排除，我们应该瞄准线性或近线性算法。 

非明显的边缘情况包括具有重复元素的序列、减少的序列或出现多个不相交的递增值“链”的序列。 例如，`a = [1, 2, 5, 6, 5]`有跳跃和重复。 始终从第一个元素开始或假设严格递增模式的幼稚方法将会失败。 这里正确的最小启动顺序是`[1, 5, 5]`，长度为 3，不是整个序列。 

## 方法

 暴力方法会尝试向后模拟所有可能的插入序列，检查哪些元素可以从原始序列中插入。 这将涉及尝试每一个分割`a`进入起始序列并插入元素。 在最坏的情况下，这具有指数复杂性并且对于`n`高达 300,000。 

关键的观察是任何元素`a[i]`不继续前一个元素的递增序列的元素必须源自原始序列。 换句话说，如果`a[i] != a[i-1] + 1`，我们知道`a[i]`无法通过插入后生成`a[i-1]`因此一定是起始序列的一部分。 这将问题简化为计算序列从连续增量中“中断”的次数。 每个中断都标志着最小起始序列中的一个新元素。 我们可以一次性处理该序列，每当看到这样的中断时就增加计数器。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 贪婪连续扫描| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.初始化一个计数器`m`为 1，因为序列的第一个元素必须始终是原始序列的一部分。 任何插入都不能生成第一个元素。 
2. 从第二个元素到最后一个元素迭代序列。 对于每个元素`a[i]`，将其与前一个元素进行比较`a[i-1]`。 
3.如果`a[i]`不等于`a[i-1] + 1`, 增量`m`。 这表示起始序列中有一个新元素，因为它不能通过插入到前一个元素之后来生成。 
4. 迭代完序列后，`m`表示起始序列的最小长度。 输出`m`。 

为什么它有效：保持的不变性是序列中延续模式的任何元素`prev + 1`可以被认为是从前一个元素生成的，而任何偏差都标志着一个新的原始元素。 由于该算法按顺序扫描并计算所有此类偏差，因此可以确保以最小长度考虑所有原始元素。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        m = 1  # first element is always part of the original sequence
        for i in range(1, n):
            if a[i] != a[i-1] + 1:
                m += 1
        print(m)

if __name__ == "__main__":
    solve()
```解决方案初始化`m`为 1，因为任何序列的第一个元素都必须源自初始序列。 然后，我们从第二个元素迭代到末尾，检查每个元素是否从前一个元素继续连续增量。 任何打破这种模式的行为都会增加`m`因为该元素不能通过在前一个元素之后插入来生成。 这种直接的一次性方法可确保每个测试用例的时间为 O(n)，并具有 O(1) 的额外空间。 

## 工作示例

 考虑顺序`a = [1, 2, 3, 4, 5]`。 第一个元素 1 开始序列，`m = 1`。 接下来的每个元素都延续递增模式（`2=1+1`,`3=2+1`， ...）， 所以`m`永远不会增加。 最小起始序列长度为 1。 

| 我| 一个[我] | a[i-1]+1 | 米 |
 | ---| ---| ---| ---|
 | 0 | 1 | - | 1 |
 | 1 | 2 | 2 | 1 |
 | 2 | 3 | 3 | 1 |
 | 3 | 4 | 4 | 1 |
 | 4 | 5 | 5 | 1 |

 现在`a = [1, 2, 5, 6, 5]`。 开始于`m = 1`。 在索引 2 处，`5 != 3`, 增量`m = 2`。 在索引 3 处，`6 = 5+1`，模式继续，`m`不变。 在索引 4 处，`5 != 6+1`, 增量`m = 3`。 最小起始序列长度为 3。 

| 我| 一个[我] | a[i-1]+1 | 米 |
 | ---| ---| ---| ---|
 | 0 | 1 | - | 1 |
 | 1 | 2 | 2 | 1 |
 | 2 | 5 | 3 | 2 |
 | 3 | 6 | 6 | 2 |
 | 4 | 5 | 7 | 3 |

 该跟踪确认连续增量中的每次中断都正确地发出新原始元素的信号。
