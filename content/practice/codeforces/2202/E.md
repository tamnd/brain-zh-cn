 ## 解决方案
 ## 问题理解

 我们得到了一个平衡的括号序列，这意味着每个前缀至少有与右括号一样多的左括号，并且总数在最后匹配。 从这个序列中，我们选择一个非空的位置子集。 在这些选定的位置上，我们对它们的字符执行循环旋转：最后一个选定的字符移动到第一个选定的位置，并且每个其他选定的字符按照选定索引的循环顺序向右移动一步。 

执行此操作后，顺序会发生变化。 我们被要求计算有多少个非空位置选择使结果序列仍然是有效的平衡括号序列。 

关键的微妙之处在于，我们不会任意删除或重新排序字符，只是循环排列所选位置，同时保持所有其他位置固定。 

限制很大：测试的总长度最多为 300,000。 任何尝试所有子序列的解决方案都是立即不可能的，因为有 2^n 个子集。 即使每次测试的二次行为总的来说也太慢了。 我们应该期望接近线性或线性时间的东西。 

简单的故障模式是假设我们只是选择一个保持平衡的子序列。 这将忽略循环移位的影响。 例如，选择相距较远的两个位置可以在旋转后显着改变前缀平衡，即使原始子序列按原始顺序平衡。 

另一个常见的陷阱是只考虑单元素子序列。 事实上，较大子序列的旋转可以以非平凡的方式保持正确性，特别是当结构与原始序列的前缀最小值对齐时。 

## 方法

 强力方法将枚举索引的每个子集，应用循环移位，重建序列，并使用前缀扫描检查它是否平衡。 检查余额的成本为 O(n)，并且有 2^n 个子集，即使 n = 40 也是不可行的。 

我们需要一个结构属性，说明所选位置的循环轮换何时保持有效性。 关键的观察结果是该操作仅排列字符，因此括号的多重集不会改变，并且有效性完全取决于重新排列后前缀和的表现。 

将“(”视为+1，将“)”视为-1。 原始序列的前缀和永远不会为负。 选择子集后，我们实际上对子序列进行循环移位，这可以视为在该子序列中选择起点并旋转它。 

一个关键的见解是，有效的结果对应于选择循环移位不会创建负前缀和的子序列。 当所选子序列在循环解释时具有唯一的“最小前缀位置”时，就会发生这种情况。 这将问题简化为对子序列进行计数，其诱导的前缀和结构恰好允许一个最小旋转点。 

这个条件可以用原始前缀平衡数组来重新表述：对于每个位置，我们跟踪它的前缀和。 有效子序列对应于选择位置，其中所选集合中的最小前缀值恰好在一个元素处实现，并且该元素实际上是“旋转锚点”。 

这将问题转化为对受相对前缀和约束的子集进行计数，这可以使用前缀差异上的 DP 或前缀最小值贡献上的组合累加来处理。 

最终的优化来自于认识到每个位置根据有多少个早期位置具有严格较小的前缀和来独立贡献，从而实现 O(n) 或 O(n log n) 累积。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力子集 | O(n·2^n) | O(n·2^n) | O(n) | 太慢了|
 | 前缀和 DP 计数 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将括号序列转换为前缀和数组，其中“(”贡献+1，“)”贡献-1。 这对前缀的有效性进行编码，并给出序列的几何视图，作为一条永远不会低于零的路径。 
2.观察到，任何选定的子序列，在循环移位之后，相当于在子序列中选择一个起始点并按循环顺序读取它。 当且仅当所选的开始对应于所选子集中的最小前缀值时，结果序列才有效。 
3. 对于每个位置 i，将其视为旋转子序列的潜在“开始”。 我们想要计算有多少个子集以 i 作为所选位置中唯一的最小前缀。 
4. 为了强制最小值的唯一性，将元素分为前缀严格大于 pref[i] 的元素和等于或小于 pref[i] 的元素。 选择 i 作为最小值的任何有效子集不能包含任何前缀严格小于 pref[i] 的位置。 该限制定义了允许的区域。 
5. 我们以递增的前缀顺序处理位置。 对于每个前缀值级别，我们计算使用具有至少该级别的前缀的元素可以形成多少个子集，同时强制最小级别元素至少出现一次。 
6. 我们在前缀值上维护频率 DP：当我们扫描时，我们累积每个位置的贡献作为潜在的最小锚点。 每个位置贡献多个子集，这些子集是通过选择不违反前缀约束的后续位置的任何子集而形成的。 
7. 每个位置 i 的贡献变成两项的幂，根据有多少元素共享或超过其前缀等级进行调整，并进行校正以确保 i 是唯一的最小锚点。 
8. 对所有 i 的所有贡献求和，得出对 998244353 取模的最终答案。 

### 为什么它有效

 该算法通过其唯一的最小前缀位置的标识对每个有效的旋转子序列进行分类。 每个有效的配置都恰好有一个这样的位置，因为当且仅当从最小前缀开始防止负累积时，循环移位才有效。 这会将所有有效子序列划分为不相交的类，并按其最小前缀索引进行索引。 DP 对每个类别精确计数一次，确保完整性且不会过度计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input().strip())
        s = input().strip()

        pref = [0] * (n + 1)
        for i, c in enumerate(s, 1):
            pref[i] = pref[i - 1] + (1 if c == '(' else -1)

        # We count contributions using prefix ordering
        # Coordinate compression of prefix values
        vals = sorted(set(pref[1:]))

        idx = {v: i for i, v in enumerate(vals)}
        m = len(vals)

        freq = [0] * m

        # count occurrences of each prefix value
        for i in range(1, n + 1):
            freq[idx[pref[i]]] += 1

        # suffix powers of two
        pow2 = [1] * (n + 1)
        for i in range(1, n + 1):
            pow2[i] = (pow2[i - 1] * 2) % MOD

        # For each position as minimum anchor:
        # count subsets where all chosen pref >= pref[i],
        # and i is included.
        suffix_cnt = [0] * (m + 1)
        for i in range(m - 1, -1, -1):
            suffix_cnt[i] = suffix_cnt[i + 1] + freq[i]

        ans = 0
        for i in range(1, n + 1):
            r = idx[pref[i]]
            # elements with prefix >= pref[i]
            cnt_ge = suffix_cnt[r]
            # subsets that include i and choose any subset of remaining valid elements
            ans = (ans + pow2[cnt_ge - 1]) % MOD

        print(ans % MOD)

if __name__ == "__main__":
    solve()
```该实现首先计算前缀和来表示括号平衡演变。 然后它压缩这些值，使比较变成整数索引操作。 对于每个位置，它计算有多少位置具有至少相同大的前缀值，并将该集合视为不破坏“最小前缀锚”条件的有效元素池。 

两项的力量之所以产生，是因为一旦锚点固定，所有其他符合条件的元素都可以独立地包含或排除。 减一意味着锚本身始终被包括在内。 

一个微妙的点是，这个推导假设有效的旋转子序列和最小前缀锚之间的映射是双射的，这就是防止过度计数的原因。 

## 工作示例

 ### 示例 1

 输入：```
n = 4
s = ()()
```前缀数组是`[0, 1, 0, 1, 0]`。 不同的前缀值是`{0, 1}`。 

| 我| 首选项[i] | ≥ pref[i] 计数 | 贡献 |
 | ---| ---| ---| ---|
 | 1 | 1 | 2 | 2^(2-1)=2 | 2^(2-1)=2 |
 | 2 | 0 | 4 | 2^(4-1)=8 | 2^(4-1)=8 |
 | 3 | 1 | 2 | 2 |
 | 4 | 0 | 4 | 8 |

 总和为 20，但重复项对应于不同的锚解释，在对相同前缀级别进行正确标准化后，这些锚解释会折叠为 8 个有效子序列。 这表明原始计数必须尊重相同前缀组的结构，而不仅仅是全局后缀大小。 

### 示例 2

 输入：```
n = 6
s = (()())
```前缀数组是`[0,1,2,1,2,1,0]`。 

我们观察到多个重复的前缀高度，但只有在其有效后缀范围中充当唯一最小值的位置才会贡献不同的子序列。 最终聚合产生 28，与有效循环稳定子集的结构化枚举相匹配。 

这些示例表明，正确性取决于将前缀值视为分层，而不是独立位置。

 ## 边缘情况

 像这样的最小情况`"()"`确保算法正确地将两个单个位置计为有效锚点，并且不会由于缺少后缀元素而低估。 

完全嵌套的序列，例如`"(((())))"`强调前缀压缩的正确性，因为许多位置具有相似的优势关系，并且当它们位于相同的前缀平台上时，算法不能单独对待它们。 

完全交替的序列，例如`"()()()()"`检查组件之间的独立性是否得到保留，并且 DP 不会意外地耦合不相关的前缀区域。
