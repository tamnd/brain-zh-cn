 ## 解决方案
 ## 问题理解

 问题是关于从原点开始在 2D 整数网格上构建一系列移动`(0,0)`并在目标点结束`(x,y)`。 每次移动必须是以下三种特定类型之一：向右移动 2 个单位、向上移动 1 个单位、向右移动 3 个单位且不发生垂直变化、或者向右移动 4 个单位、向下移动 1 个单位。 任务是确定仅使用这些动作是否可以达到目标。 

输入由多个测试用例组成，每个测试用例都有一个目标`(x,y)`。 约束条件允许`x`一样大`10^9`和`y`之间`-10^8`和`10^8`。 这意味着任何暴力尝试枚举所有可能的移动序列都是不可行的，因为移动的数量可能约为`10^9 / 2`在最坏的情况下，这对于 1 秒的时间限制来说太大了。 

不明显的边缘情况包括远离 x 轴或需要精确垂直调整的点。 例如，达到`(4,1)`是不可能的，因为唯一增加的动作`x`也减少了 4`y`1，并且允许的移动组合不能产生网络`(4,1)`从`(0,0)`。 同样，较大的 x 值和极端的 y 值需要仔细检查，以确保垂直增量和减量能够正确平衡。 

## 方法

 一种简单的方法会尝试递归地或使用 BFS 来模拟每个移动序列，从`(0,0)`并尝试三种移动类型中的每一种，直到达到`(x,y)`。 这在原则上是正确的，因为它详尽地探索了所有可能性，但状态的数量大致为`x/2`每个维度的最小值，并且可以呈指数增长`x`，使其完全不切实际`x`一样大`10^9`。 

关键的见解来自于对移动代数的考虑。 让`a`,`b`， 和`c`表示类型的移动次数`(2,1)`,`(3,0)`， 和`(4,-1)`分别。 那么总的x坐标是`2a + 3b + 4c = x`总 y 坐标为`a - c = y`。 这将问题简化为求解两个非负整数线性丢番图方程的简单系统。 观察结果是`b`是由`b = x - 2a - 4c`和`y = a - c`给出`a = y + c`。 将其代入 x 方程得出`b = x - 2(y + c) - 4c = x - 2y - 6c`。 为了满足非负性，我们需要`b >= 0`和`c >= 0`和`a = y + c >= 0`。 如果这些不等式对于某个整数成立`c >= max(0, -y)`，则存在解。 

这将问题简化为检查是否`x - 2y`考虑后可以表示为6的倍数`c`。 我们可以进一步简化：`c`必须满足`0 <= c <= (x - 2y)/6`（整数除法）和`c >= max(0, -y)`。 如果有这样一个`c`存在，则该点可达。

 ## 算法演练

 1. 对于给定的`(x,y)`，首先检查简单边界。 目标无法到达，如果`y`小于`-x//4`或大于`x//2`。 这是因为观察到，向下移动每 4 个 x 单位将 y 减少 1，向上移动每 2 个 x 单位将 y 增加 1，给出了给定 x 的 y 的最大范围。 
2. 计算`c_min = max(0, -y)`。 这是向下的最小数量`(4,-1)`避免出现负数的向上移动所需的移动，因为`a = y + c`必须是非负数。 
3. 计算`c_max = (x - 2*y)//6`。 这来自于替换`a = y + c`代入 x 方程并求解最大可能值`c`这仍然允许`b`为非负数。 
4. 如果`c_min <= c_max`, 一个有效的`c`存在，这意味着对应的非负整数`a = y + c`和`b = x - 2a - 4c`可以构建。 否则，该点无法到达。 
5、输出`YES`如果可以到达并且`NO`否则。 

为什么有效：该算法将问题简化为检查具有非负整数约束的线性丢番图方程组的可行性。 通过仔细地约束`c`并推导`a`和`b`由此，我们保证任何报告的“YES”对应于实际可达的序列，任何“NO”对应于不可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_reach(x, y):
    c_min = max(0, -y)
    c_max = (x - 2 * y) // 6
    if c_min <= c_max:
        return "YES"
    return "NO"

t = int(input())
for _ in range(t):
    x, y = map(int, input().split())
    print(can_reach(x, y))
```该解决方案直接实现了所描述的可行性检查。 它使用整数运算来避免浮点问题并有效处理多个测试用例。 这`max(0, -y)`确保我们永远不会选择负数的移动，并且整数除法会自动降低上限`c`。
