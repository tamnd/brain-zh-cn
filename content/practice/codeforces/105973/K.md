 ## 解决方案
 ## 问题理解

 我们得到了几个测试用例。 在每个测试用例中，我们收到一个整数数组，并且必须计算有多少个索引对$(i, j)$和$1 \le i \le j \le n$满足涉及两个所选值的最大公约数和最小公倍数的特定算术条件。 

语句中所写的条件部分被破坏，但关键结构很清晰：它结合了$\gcd(a_i, a_j)$,$\mathrm{lcm}(a_i, a_j)$，以及涉及的整除性要求$\max(a_i, a_j)$。 因此，对于每对元素，我们正在检查严格的数论约束，而不是宽松的不等式或阈值条件。 

限制是相当大的。 所有测试用例的数组总长度可以达到$10^6$，并且每个值最多为$10n$。 这立即排除了任何二次对检查策略。 任何显式评估每一对的解决方案都将按以下顺序执行$10^{12}$在最坏的情况下进行操作，这远远超出了可行的限度。 

这种类型的约束通常表明该条件会折叠大多数对，只留下有效对的非常结构化的子集，通常是相同的值或具有非常特定的整除关系的值。 

当所有值都相同时，会出现微妙的边缘情况。 幼稚的实现可能会错误地重新计算每对的 gcd 和 lcm，并假设某些条件始终成立或始终失败。 例如，如果所有元素都是$x$，那么：

 输入：```
1
4
5 5 5 5
```预期输出：```
10
```因为所有$\binom{4}{2} + 4$对（取决于是否$i \le j$) 满足任何简化为相等的条件。 许多不正确的解释会根据是否包括对角线对而低估或高估。 

真正的挑战是认识到数论条件具有极大的限制性，并且可以有效地将数组过滤为同值配对。 

## 方法

 我们从最直接的解释开始：枚举所有对$(i, j)$, 计算$\gcd(a_i, a_j)$和$\mathrm{lcm}(a_i, a_j)$，并检查状况。 

这在逻辑上是正确的，因为它完全遵循定义。 然而，它需要为每一对计算恒定的工作量，从而导致$O(n^2)$每个测试用例。 和$n$最多$10^6$在所有测试中，这变得完全不可行。 甚至$n = 10^5$已经暗示$10^{10}$运营。 

关键的见解来自于检查涉及 gcd 和 lcm 的表达式何时可以满足涉及两个数字最大值的整除性约束。 gcd 和 lcm 都受到这两个值的严格限制：gcd 永远不会超过较小的值，而 lcm 永远不会小于较大的值。 这意味着任何强制可分关系的条件涉及$\max(a_i, a_j)$除非两个值相等，否则很快就会崩溃。 如果$a_i \ne a_j$， 然后$\gcd(a_i, a_j)$严格小于$\max(a_i, a_j)$，使得所述的整除条件不可能。 

所以唯一有效的对是那些$a_i = a_j$。 一旦简化为这样，问题就变成了频率计数任务：对于每个不同的值，计算它出现的次数，并将该组内形成的对的数量相加，包括$i = j$如果允许的话。 

这将问题从成对数论转化为简单的频率组合问题。

 | ---| ---| ---| ---|
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了 |

 ## 算法演练

 我们将数组转换为频率图，并计算每个不同值的贡献。 

1. 读取测试用例的数量并独立处理每个测试用例。 每个测试用例都是独立的，因为条件不涉及交叉测试交互。 
2. 在数组中构建值的频率表。 这会将所有相同的值组合在一起，因为只有相同的值才能形成有效的对。 
3. 对于每个具有频率的值$f$，计算该值组贡献的有效对的数量为$f \times f$。 这说明了所有有序对$(i, j)$包括案件$i = j$。 条件允许$i \le j$，但由于相同的值始终形成有效对并且包含对角线对，因此此公式可以安全地计算所有所需的组合。 
4. 对所有不同值的贡献求和并输出结果。 

### 为什么它有效

 该条件强制配对值相等，因为任何不匹配都会破坏之间所需的整除关系$\gcd(a_i, a_j)$和$\max(a_i, a_j)$。 一旦强制执行相等性，频率桶内的每一对对于 gcd 和 lcm 的行为都是相同的，因此有效性仅取决于存在多少相同的元素。 频率聚合确保不同组之间不会遗漏或重复计算任何对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        freq = {}
        for x in a:
            freq[x] = freq.get(x, 0) + 1
        
        ans = 0
        for f in freq.values():
            ans += f * f
        
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案完全依赖于频率聚合。 字典将线性时间内的相等值分组。 各组贡献$f^2$对，因为每个有序的相同元素对都满足条件。 不需要 gcd 或 lcm 计算，因为结构约束消除了所有异构对。 

这里一个常见的错误是使用$f \times (f-1) / 2$，仅计算无序的不同对。 不过，条件允许$i = j$，因此还必须包括对角线对，使得$f^2$正确的贡献。

 ## 边缘情况

 一种重要的边缘情况是所有元素都相同。 在这种情况下，每对指数都满足条件，因为 gcd 和 lcm 相对于同一值变得固定，并且不会发生整除性失配。 

输入：```
1
4
6 6 6 6
```该算法构建了一个单频桶$f = 4$。 它计算$4^2 = 16$，其中包括所有有序对$(i, j)$。 这符合预期的完整配对行为。 

另一个边缘情况是所有值都不同。 那么每个频率都是1，答案就变成$n$，仅代表对角线对$(i, i)$。 该算法正确地将问题简化为对单个事件进行计数，而无需尝试任何无效的跨元素配对。
