 ## 解决方案
 ## 问题理解

 我们得到一个无向图，其中每条边都带有正整数权重。 任务是为每个顶点分配一个值，以便对于每条边，两个端点值中较大的一个恰好等于边的权重。 

换句话说，每条边都施加了严格的约束：如果一条边以权重 w 连接 u 和 v，则两个顶点之一必须带有 w 值，另一个必须带有不超过 w 的值，并且实际上两者中的最大值必须恰好是 w。 因此，至少一个端点必须“实现”边权重，而另一端点不能超过它。 

输出是满足所有约束的 1 到 10^9 范围内的整数对顶点的任何赋值，或者是不存在此类赋值的声明。 

约束很大，所有测试用例最多有 3·10^5 个顶点和边。 这排除了每个测试用例中任何二次甚至接近二次的情况。 预计每个测试用例都有线性或接近线性的结构。 

当多条边对同一顶点施加相互矛盾的要求时，就会出现一个微妙的问题。 例如，如果一个顶点的一条边被迫等于 5，另一条边等于 7，则不存在解。 另一个问题出现在循环中，其中“最大值等于边权重”条件迫使传播不一致，特别是当图形包含围绕循环权重递减的边时。 没有全局一致性的每条边的天真贪婪分配很容易崩溃。 

## 方法

 每条边上的条件可以理解为较高端点值必须等于边权重的约束。 这立即表明边缘权重的行为类似于必须在本地某处实现的上限。 

一个蛮力的想法是将每个顶点值视为未知，并尝试迭代地分配值。 人们可以尝试回溯或约束传播：选择一个顶点，分配与一个入射边一致的值，然后沿邻居传播约束。 从概念上讲，这是可行的，因为每条边都约束两个变量，但在最坏的情况下，图的约束是密集的。 每个分配可以通过许多边级联，回溯可以重新访问分配的指数组合。 对于多达 3·10^5 的边，这变得完全不可行。 

关键的观察是，每条边都强制执行一个涉及最大值的非常局部的条件。 如果一条边的权重为w，则至少一个端点必须恰好为w，并且两个端点都不能超过w。 这建议按权重降序处理边缘，以便首先固定较大的约束，然后围绕它们调整较小的约束。 

这导致了一个建设性的观点：我们尝试贪婪地从大权重分配值到小权重，确保当我们决定为顶点分配值时，我们以后永远不需要增加它。 问题之一是确保跨相同或递减权重的连接约束的分配的一致性。 

主要的结构见解是，仅当顶点需要采用由同一最大相关权重区域的边引起的两个不同值时，才会出现冲突。 如果我们处理按权重分组的边，并确保在每个组内我们一致地分配值，则构造可以简化为在相同权重阈值的边下维护连接的组件。 

我们按权重降序有效地处理边，每当我们看到权重为 w 的边时，我们必须确保其端点与值 w 兼容。 如果两个端点都没有固定为 w，我们可以自由选择一个端点并将其设置为 w，同时保持另一个端点最多为 w。 为了避免未来的矛盾，我们使用不相交的集合结构来合并约束，该结构跟踪哪些顶点被迫共享相同的最终值。

这将问题转化为跨权重层的并查一致性检查。

 | 蛮力 | 指数| O(n + m) | 太慢了 |
 | 最佳 | O(m α(n)) | O(m α(n)) | O(n + m) | 已接受 |

 ## 算法演练

 我们按权重降序处理边，以便较高的约束支配较低的约束。 

1. 按权重递减对所有边进行排序。 这确保了当我们处理边缘时，后面的步骤不会引入更严格的要求，涉及可能与先前决策相矛盾的更大权重。 
2. 维护顶点上的不相交集合并集结构，表示最终必须具有相同指定值的顶点组。 直觉是，如果两个顶点通过重叠约束被迫承担相同的“最大实现角色”，那么它们就属于同一个组件。 
3. 将所有顶点值初始化为未分配。 
4. 迭代按相等权重 w 分组的边。 对于每条边 (u, v, w)，我们检查 DSU 中 u 和 v 的代表。 
5. 如果两个代表都已经分配了值，并且这些值与 w 不同，使得 max(au, av) 不可能为 w，我们会检测到不一致并返回不可能。 实际上，唯一安全的矛盾是当两个分量都已固定为严格大于 w 的值时，因为这将迫使边缘最大值大于允许的值。 
6. 如果一个或两个组件都未分配，我们确保至少一个端点的组件被分配值 w。 我们选择一名代表，如果尚未分配，则将其分配给 w。 如果两者均未分配，我们将任意分配，通常分配给一名代表。 
7. 分配后，我们合并两个顶点，因为边意味着它们现在受到相同权重层的约束。 
8. 继续，直到处理完所有边缘。 任何剩余的未分配组件可以分配 [1, 10^9] 中的任何值，例如 1。 

合并背后的原因是，一旦处理了权重 w 的边，两个端点现在都受到 w 或更小的边的约束，因此必须将它们视为向前移动的同一约束区域的一部分。 

### 为什么它有效

 不变的是，在处理完权重严格大于 w 的所有边后，DSU 中的每个连通分量对应的顶点的最终值已经与所有更高权重约束一致。 在处理权重 w 时，我们确保权重 w 的每条边都至少有一个恰好分配了 w 的端点组件，并且不会为任何组件分配大于当前正在处理的边权重的值。 由于我们向下移动，一旦一个组件获得一个值，它就永远不需要增加，并且任何未来的边缘只能强制执行相等或更小的值。 这可以防止矛盾并确保每个边缘准确地达到其所需的最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        edges = []
        for _ in range(m):
            u, v, w = map(int, input().split())
            u -= 1
            v -= 1
            edges.append((w, u, v))

        edges.sort(reverse=True)

        parent = list(range(n))
        size = [1] * n
        val = [0] * n

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a, b):
            ra, rb = find(a), find(b)
            if ra == rb:
                return
            if size[ra] < size[rb]:
                ra, rb = rb, ra
            parent[rb] = ra
            size[ra] += size[rb]
            if val[ra] == 0:
                val[ra] = val[rb]
            rb_val = val[rb]
            if rb_val != 0:
                if val[ra] == 0:
                    val[ra] = rb_val

        ok = True

        for w, u, v in edges:
            ru, rv = find(u), find(v)

            vu, vv = val[ru], val[rv]

            if vu > w or vv > w:
                ok = False
                break

            if vu == 0 and vv == 0:
                val[ru] = w
            elif vu == 0:
                val[ru] = w
            elif vv == 0:
                val[rv] = w

            union(ru, rv)

        if not ok:
            print(-1)
            continue

        ans = []
        for i in range(n):
            r = find(i)
            if val[r] == 0:
                val[r] = 1
            ans.append(str(val[r]))

        print(" ".join(ans))

if __name__ == "__main__":
    solve()
```该解决方案首先对边进行排序，以便更早地强制执行更高的权重，这是防止以后出现矛盾的核心机制。 DSU 对通过处理的边连接的顶点进行分组，每个组件都带有一个代表值，该代表值表示该组件内的最终顶点分配。 

联合操作经过精心设计，可以在合并的组件之间传播任何已经固定的值。 如果一侧已经有一个值，它将被保留，确保一旦组件被强制指定权重，该决定就会通过合并而持续存在。 

在边缘处理过程中，如果两个分量都超过了当前的边缘权重，则该配置无效，因为该边缘的最大值无法再降低到 w。 否则，至少一侧被迫取值 w，确保满足边缘约束。 

最后，任何不受任何边强制的分量都会被分配最小的可能值 1，这是安全的，因为它不会影响任何需要更大值的最大约束。

 ## 边缘情况

 当高权重边缘提前强制某个分量值时，会发生一种重要的边缘情况，然后该组件值与后来的较小权重边缘发生冲突。 在像权重为 5 和 2 的链 1-2-3 这样的图中，尽早为第一条边分配 5 是正确的，但如果传播错误地将 5 强制到整个组件上，则第二条边将变得不可能。 降序处理确保首先解析 5 边，然后仅引入兼容的较低分配，从而防止以后需要增加或矛盾分配。 

另一种边缘情况是多个边缘共享相同的权重并形成连接的组件。 在这种情况下，必须为每个连接组件至少一个顶点分配该权重，但并非必须立即显式分配所有顶点。 DSU 合并可确保一旦组件中的一个顶点设置为 w，其余顶点就会继承一致性，而不会强制执行可能意外覆盖有效配置的多个冗余分配。
