 ## 解决方案
 ## 问题理解

 我们给定两个正整数，`a`和`b`，它们是直角三角形的边的长度。 任务不是检查这样的三角形是否存在，它显然存在。 相反，我们必须将该三角形放置在整数晶格上，以便所有三个顶点都具有整数坐标，并且其任何一条边都不平行于任一坐标轴。 

思考该问题的一个有用方法是构造两个垂直向量，其长度恰好为`a`和`b`。 如果我们把一个顶点放在原点，那么沿着这些向量移动就可以得到另外两个顶点。 生成的三角形将自动变为直角。 

限制非常小。 两个都`a`和`b`最多 1000。这意味着我们可以枚举所有平方和为的整数坐标对`a²`或者`b²`。 甚至一个`O(1000²)`搜索是完全安全的。 

主要困难不是性能而是几何。 我们需要整数坐标、直角、规定的边长，并且没有边可以是水平或垂直的。 

一个容易犯的错误是构造明显的三角形```
(0,0), (a,0), (0,b)
```例如，使用输入```
3 4
```它具有正确的边长，但两条边平行于坐标轴，因此无效。 

另一个陷阱是找到正确长度的整数向量，但允许它们位于同一行。 例如，如果两个向量指向同一方向，则这三个点将共线并且不会形成三角形。 

更微妙的情况是不存在整数分解。 用于输入```
1 1
```唯一长度为 1 的整数向量是`(±1,0)`和`(0,±1)`。 任何使用它们的构造都必然会创建一条平行于轴的边。 正确答案是```
NO
```仅检查长度而不强制执行“无轴平行边”条件的解决方案将错误地输出三角形。 

## 方法

 一个蛮力的想法是搜索某个大盒子内三个顶点的所有整数坐标并测试每种可能性。 这种方法显然是正确的，因为每个有效的三角形最终都会被检查。 问题是，即使一个边长为 2000 的盒子也包含数百万个格点，使得三元组的数量成为天文数字。 

问题的结构为我们提供了更好的表示。 由于三角形是直角，我们可以将直角放在原点。 让一条腿用向量表示```
(x1, y1)
```与长度`a`，另一个是向量```
(x2, y2)
```与长度`b`。 

向量必须满足```
x1² + y1² = a²
x2² + y2² = b²
```并且它们必须是垂直的：```
x1*x2 + y1*y2 = 0
```一个关键的观察结果是，如果`(x1, y1)`已知，则垂直向量为```
(-y1, x1)
```或者```
(y1, -x1)
```它们的长度与`(x1, y1)`。 

假设我们找到整数`(x, y)`这样```
x² + y² = a².
```然后向量```
(-y, x)
```有长度`a`。 获得长度的垂直向量`b`，我们可以通过以下方式缩放它`b / a`：```
(-y*b/a, x*b/a)
```为了使该向量具有整数坐标，两者`y*b`和`x*b`必须能整除`a`。 

我们可以直接枚举所有整数对，而不是用分数推理`(x, y)`满意的```
x² + y² = a²
```和所有整数对`(u, v)`满意的```
u² + v² = b².
```那么我们只需要找到一对```
x*u + y*v = 0.
```边界很小，因此搜索很容易。 

大多数公认的解决方案中都使用了一种更简单的观察方法。 枚举所有非零整数对`(x, y)`和```
x² + y² = a².
```然后采取```
(u, v) = (-y, x).
```这是自动垂直的并且有长度`a`。 

如果我们想要长度`b`，我们可以寻找一个比例因子```
k = b / a
```保持坐标完整。 同样，我们寻找另一种分解`b²`并检查是否与垂直方向一致。 

标准接受的实现枚举了所有分解`a²`直接测试对应的缩放后的垂直坐标是否为整数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解顶点位置 | 巨大| 巨大 | 太慢了 |
 | 枚举圆上的格向量 | O(a + b) 到 O(1000²) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将直角顶点固定在`(0,0)`。 
2. 枚举所有正整数`x`从`1`到`a-1`。 
3. 计算```
y² = a² - x².
```如果`y²`不是一个完美的正方形，这`x`不能属于长度为整数的向量`a`。 
4.让`y = sqrt(y²)`。 跳过案例`y = 0`因为这会创建一个与轴平行的边。 
5.考虑垂直方向`(-y, x)`。 它的长度也是`a`。 
6. 缩放该垂直向量`b / a`。 候选坐标变为```
X = -y*b/a
Y = x*b/a.
```7. 检查两者是否`X`和`Y`是整数。 这相当于检查```
(y*b) % a == 0
(x*b) % a == 0.
```8. 如果两个整除条件都成立且坐标均不为零，则输出```
(0,0)
(x,y)
(X,Y)
```并终止。 
9. 如果穷尽所有分解都没有成功，则输出`"NO"`。 

### 为什么它有效

 第一条腿是向量`(x,y)`，其长度恰好是`a`因为它满足`x²+y²=a²`。 

第二条腿是从垂直向量获得的`(-y,x)`并按比例缩放`b/a`。 缩放改变其长度`a`到`b`，同时保持垂直度。 因此，两条腿向量的点积保持为零，因此原点处的角度是直角。 

可整除性检查保证整数坐标。 排除零坐标可防止任何边变为水平或垂直。 每个在原点具有直角的有效构造都对应于某个长度的晶格向量`a`，因此枚举不会错过解。 

## Python 解决方案```python
import sys
from math import isqrt

input = sys.stdin.readline

a, b = map(int, input().split())

for x in range(1, a):
    y2 = a * a - x * x
    y = isqrt(y2)

    if y * y != y2 or y == 0:
        continue

    if (y * b) % a != 0:
        continue
    if (x * b) % a != 0:
        continue

    X = -(y * b) // a
    Y = (x * b) // a

    if X == 0 or Y == 0:
        continue

    print("YES")
    print(0, 0)
    print(x, y)
    print(X, Y)
    sys.exit()

print("NO")
```该代码直接遵循几何构造。 

该循环枚举长度的所有整数格向量`a`具有正坐标。 对于每个候选者，表达式```
y2 = a * a - x * x
```计算剩余的平方。 使用`isqrt`测试是否时避免浮点精度问题`y2`是一个完美的正方形。 

可分性检查是解决方案的核心。 他们验证了缩放垂直向量`b/a`保持两个坐标完整。 如果没有这些检查，整数除法会默默地截断值并产生不正确的三角形。 

最后的守卫```
if X == 0 or Y == 0:
```删除会引入轴平行边的结构。 

一旦找到有效的配置，程序就会立即打印它并退出。 由于任何有效的三角形都是可接受的，因此无需继续搜索。

import sys
import io
from math import isqrt

def solve():
    a, b = map(int, input().split())

    for x in range(1, a):
        y2 = a * a - x * x
        y = isqrt(y2)

        if y * y != y2 or y == 0:
            continue

        if (y * b) % a != 0:
            continue
        if (x * b) % a != 0:
            continue

        X = -(y * b) // a
        Y = (x * b) // a

        if X == 0 or Y == 0:
            continue

        print("YES")
        print(0, 0)
        print(x, y)
        print(X, Y)
        return

    print("NO")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return out

# provided sample
assert run("1 1\n") == "NO\n"

# custom cases
assert run("5 10\n").startswith("YES")
assert run("2 2\n") == "NO\n"

 ## 边缘情况

 用于输入```
1 1
```循环范围为空，因为没有正数`x < 1`。 该算法立即打印`"NO"`。 这符合每个长度为 1 的晶格向量都是轴对齐的事实。 

用于输入```
2 2
```唯一的候选人是`x = 1`, 给予```
y² = 3
```这不是一个完美的正方形。 不存在长度为 2 且两个坐标均非零的晶格向量，因此答案为`"NO"`。 

用于输入```
3 4
```候选向量是`(x,y)=(?,?)`。 唯一的分解`3²`是有效地`(0,3)`和`(3,0)`，都包含零坐标。 该算法会自动拒绝它们并打印`"NO"`。 

用于输入```
5 5
```该算法发现`(3,4)`自从```
3² + 4² = 25.
```垂直向量是```
(-4,3),
```其长度已经为 5。所有坐标均非零，因此输出```
YES
0 0
3 4
-4 3
```每条边都避免水平或垂直，并且所有坐标都保持整数。
