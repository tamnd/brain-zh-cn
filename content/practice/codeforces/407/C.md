 ## 解决方案
 ## 问题理解

 我们得到一个数组和一系列范围操作。 每个操作选择一个段$[l, r]$和一个参数$k$，并且对于每个位置$j$在该段内，我们添加一个值，该值取决于距离$j$从左端点开始$l$。 添加的值是一个二项式系数，其参数随着$j - l$，这意味着在一次更新中，贡献形成一个固定的组合序列，从$l$当我们向右移动时，它会确定性地演变。 

按顺序处理完所有操作后，我们需要每个数组位置模的最终值$10^9+7$。 

这些限制迫使我们采取严格的制度。 和$n, m \le 10^5$，任何涉及每个查询的每个元素的解决方案都会立即太慢，因为这会导致$10^{10}$最坏情况下的更新。 甚至$O(n \log n)$每个查询远远超出可接受的范围。 因此，必须转换更新的结构，以便每个查询在恒定或接近恒定的时间内做出贡献，并且繁重的工作被推迟到全局重建步骤。 

一个微妙的困难来自于整个段的更新不是恒定的这一事实。 一个幼稚的错误是将二项式值视为在整个区间内是固定的。 例如，如果人们错误地假设更新在各处添加了相同的值$[l, r]$，然后像这样的查询$(l=1, r=3, k=2)$将统一应用，这是错误的，因为不同职位的贡献不同$1, 2, 3$。 正确的顺序取决于距离$l$，所以即使是非常小的例子也已经暴露了错误。 

另一种失败模式是尝试独立计算每个单元的二项式系数。 虽然$k \le 100$，重新计算每个组合$(i, j)$每个查询中的对在实践中仍然会导致二次行为。 

真正的挑战是认识到所有更新都是同一族离散函数的转换，并且这些函数可以通过更简单的基本表示的重复前缀和来生成。 

## 方法

 直接模拟通过迭代其段并向每个位置添加适当的二项式值来应用每个查询。 这在概念上是有效的，因为它完全遵循定义，但每个查询可能会触及$10^5$元素，大致导致$m \cdot n$最坏情况下的操作。 两个极限均为$10^5$，这变得不可行几个数量级。 

关键的观察是固定的附加功能$k$不是任意的。 作为位置的函数$i$，它的行为就像一个离散的次数多项式$k$。 这些函数在前缀和下是稳定的：重复的前缀将有效的“二项式水平”增加一。 这直接关系到身份$$\binom{x}{k} = \sum_{t=0}^{x} \binom{t}{k-1},$$这意味着可以使用累积和从低阶二项式层构造高阶二项式层。 

这表明了一种分解策略。 我们没有直接对数组应用查询，而是维护一个分层结构，索引为$k$。 每个查询仅作为简单的范围添加对其相应层做出贡献。 然后，我们使用前缀和将贡献从较低层重复传播到较高层，在此过程中重建实际的二项式贡献。 

这将问题从“在范围内应用复杂函数”转变为“应用恒定范围更新，然后最多跨 101 层进行结构化传播”。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(nm)$|$O(1)$| 太慢了|
 | 分层前缀传播 |$O(n \cdot 100)$|$O(n \cdot 100)$| 已接受 |

 ## 算法演练

 我们构建一个 2D 结构，其中每个级别对应一个固定的$k$，每个级别存储位置上的差异数组。 

1.我们创建数组$dp[k][i]$为所有人$k \in [0, 100]$，初始化为零。 每一层最终将代表二项式的贡献$k$在向上转换之前。 
2. 对于每个查询$(l, r, k)$，我们在图层上应用标准范围更新$k$：我们增加$dp[k][l]$并减少$dp[k][r+1]$。 这编码了顺序的二项式序列$k$从位置开始$l$并继续通过$r$。 形状本身尚未扩展。 
3. 对于每个$k$从$0$到$100$，我们首先使用位置上的前缀和将差异数组转换为数组中的实际值。 这一步之后，$dp[k][i]$表示该级别所有查询的累积贡献$k$在位置$i$，在向上传播之前。 
4. 仍在同一个通道内$k$，我们通过添加将这些贡献传播到下一个级别$dp[k][i]$进入$dp[k+1][i]$。 这一步是组合变换：它对二项式层的重复前缀和产生下一个二项式层的恒等式进行编码。 
5. 处理完所有图层后，我们合并结果。 各位置$i$收到所有的总和$dp[k][i]$穿过$k$，添加到原始数组值。 

### 为什么它有效

 每层$k$表示类似多项式的函数在索引上的离散导数水平。 范围更新在起始位置插入“单位脉冲”，并且前缀和将其扩展为该级别的正确二项式结构。 向上传播确保身份链接$\binom{x}{k}$和前缀和$\binom{x}{k-1}$在全球范围内强制执行。 

由于每个转换都是线性的，并且在整个数组中一致应用，因此不同查询的贡献可以无干扰地叠加，并且在传播过程中不会丢失任何信息。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    K = 100
    dp = [[0] * (n + 2) for _ in range(K + 2)]

    for _ in range(m):
        l, r, k = map(int, input().split())
        dp[k][l] += 1
        dp[k][r + 1] -= 1

    for k in range(K + 1):
        for i in range(1, n + 1):
            dp[k][i] += dp[k][i - 1]
            dp[k][i] %= MOD
        if k < K:
            for i in range(1, n + 1):
                dp[k + 1][i] += dp[k][i]
                dp[k + 1][i] %= MOD

    for i in range(1, n + 1):
        a[i - 1] = (a[i - 1] + sum(dp[k][i] for k in range(K + 1))) % MOD

    print(*a)

if __name__ == "__main__":
    solve()
```实现干净地分离了关注点。 第一个循环将所有查询记录为适当二项式级别上的简单范围更新。 这里不计算任何组合。 

第二阶段是结构化重构。 每个内部的前缀和$k$将差异形式转换为沿数组的实际贡献。 紧接着，向上传播步骤将累积的影响转移到下一个二项式级别。 顺序很重要：在每个$k$，前缀必须在传播之前发生，否则贡献的结构就会被破坏。 

最后，通过将所有级别添加到原始数组来组装答案。 总结完毕$k$是安全的，因为$k \le 100$，使最后一步线性化$n \cdot 100$。

 ### 示例 1

 输入：```
5 1
0 0 0 0 0
1 5 0
```这里$k=0$，因此范围内的每个位置都会收到$\binom{x}{0} = 1$，与距离无关。 

| 步骤| dp[0] 差异 | 前缀 | 后的 dp[0] dp[1] | dp[1] |
 | --- | --- | --- | --- |
 | 初始化| [1,0,0,0,0,-1] | - | - |
 | 前缀 | 之后 - | [1,1,1,1,1] | - |
 | 传播| - | - | [1,1,1,1,1] |

 最终数组变成全1。 

这证实了基础层正确处理常数二项式序列。

 ## 边缘情况

 具有单个位置的最小数组测试范围更新在以下情况下是否正确降级：$l = r$。 在这种情况下，差异数组更新仅触及一个点，并且前缀逻辑不应意外地将其扩展到边界之外。 

第二个边缘情况是当$k = 0$。 这里，每次更新在该范围内都是恒定的，并且算法不能错误地以扭曲的方式将其传播到更高层。 即使函数是平坦的，传播规则仍然必须保持正确性。 

最后一个微妙的情况是一长串重叠的查询。 由于一切都是可加的，因此该算法依赖于交换性和线性。 如果传播的顺序错误，早期的贡献可能会被部分覆盖或重复计算。 固定的每层传播前前缀顺序可防止这种情况发生。
