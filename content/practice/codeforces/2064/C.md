 ## 解决方案
 ## 问题理解

 我们得到一个非零整数数组。 在每一步中，我们都可以选择任何元素，获得等于其绝对值的硬币，然后如果它是负数，则删除其右侧的所有内容，如果它是正数，则删除其左侧的所有内容。 目标是在阵列变空时最大化收集的硬币总数。 

输入由多个测试用例组成。 每个测试用例的数组长度可达$2 \cdot 10^5$，并且所有测试用例的所有数组长度之和不超过$2 \cdot 10^5$。 每个元素可以大到$10^9$以绝对值表示。 这意味着任何解决方案都必须在每个测试用例的线性或近线性时间内运行。 模拟每种可能选择的简单暴力方法将导致数组的长度呈指数级增长，并且显然是不可行的。 

边缘情况包括长度为 1 的数组、全部为正数或全部为负数的数组以及开头或结尾出现较大绝对值的数组。 例如，如果数组是$[-10, -5, -1]$，最好的选择是选择最后一个负数，$-1$，留下前缀$[-10, -5]$，然后重复取第一个元素以使硬币最大化。 总是取最大绝对值而不考虑它是在开头还是结尾的粗心贪婪方法可能会失败。 

## 方法

 暴力解决方案在每一步都会考虑所有可能的元素。 对于长度的数组$n$，第一步有$n$选择，然后直至$n-1$在下一步中，依此类推，大致给出$n!$序列。 每个序列必须计算收集到的硬币的总和。 清楚地，$n!$是禁止的$n \sim 10^5$。 

关键的观察是，每一步的选择都会自然地将数组拆分为前缀或后缀。 因为我们总是在选择后完全删除一侧，所以可以通过查看**相同符号的连续段**来找到最佳移动序列。 在一段正数中，除了该段中的最大数字之外，我们永远不会选择任何其他数字，因为选择任何较小的正数都会删除其右侧可能更大的数字。 类似地，在负数段中，我们应该选择该段中的最后一个（最右边的）数字，它是绝对值的最大值，因为选择较早的负数会丢弃该段的其余部分。 

这将问题简化为扫描一次数组，将相同符号的连续数字分组，并取每组中的最大值。 这些最大值的总和给出了最佳硬币总数。 这种贪婪策略之所以有效，是因为一旦我们提交了一个段中的某个数字，我们就被迫删除它之前或之后的所有内容。 通过始终在每个连续分段中取局部最大值，我们可以在移动到下一个分段之前最大化从该分段收集的数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 贪心段最大 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化变量`total_coins`到 0 和`i`至 0。`i`跟踪数组中的当前索引。 
2. 虽然`i`小于`n`，开始一个新的段。 记录当前数字的符号（正数或负数）。 初始化一个变量`segment_max`到当前元素。 
3. 移动相同符号的连续数字，更新`segment_max`到段内的最大绝对值。 继续直到符号改变或数组结束。 
4.添加`segment_max`到`total_coins`。 这对应于最优地选择使该连续段中的硬币最大化的数量。 
5. 设置`i`到下一段的开头并重复步骤 2-4，直到数组完全处理完毕。 
6. 输出`total_coins`。 

这是有效的，因为相同符号的每个部分在选择方面都是独立的。 在正段中选取最大值可确保以最佳方式丢弃左前缀，在负段中选取最大值可确保以最佳方式丢弃右后缀。 任何其他选择都会严格减少收集的硬币总数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total_coins = 0
        i = 0
        while i < n:
            current_sign = a[i] > 0
            segment_max = a[i]
            j = i
            while j < n and (a[j] > 0) == current_sign:
                segment_max = max(segment_max, a[j])
                j += 1
            total_coins += segment_max
            i = j
        print(total_coins)

if __name__ == "__main__":
    solve()
```该代码读取每个测试用例，迭代数组，并识别相同符号的段。 对于每个段，它找到最大元素并将其添加到运行总计中。 变量`j`扫描直到下一个标志发生变化。 自然会处理边界条件，例如单元素段或以负段结尾的数组，因为`while`循环在数组末尾停止。 该解决方案从不修改数组本身，从而避免了昂贵的切片操作。
