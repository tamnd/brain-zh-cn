 ## 解决方案
 ## 问题理解

 我们得到的单词已经是一种非常受限的玩具语言中的单数形式。 每个单词都是由根字符串构成的，并且单数形式始终是通过将后缀“us”附加到该根字符串来创建的。 我们的任务是逆转这个过程：删除单数后缀，并通过附加“i”将剩余的根转换为其复数形式。 

输入的大小非常小，每个单词的长度最多为10个，并且只有小写英文字母。 这立即排除了对复杂数据结构或优化的任何需要。 任何处理每个字符恒定次数的解决方案都足够了。 

微妙的边缘情况是最小根。 “us”这个词对应于一个空词根。 删除“us”会产生一个空字符串，正确的复数变为“i”。 另一个特殊情况是根本身以内部类似于后缀模式的字母结尾，例如“sussus”。 只有最后两个字符很重要； 前面出现的“我们”必须被忽略。 

## 方法

 暴力解释是尝试显式解析所有可能的根分裂，但这是不必要的，因为语言的结构是严格的。 每个有效输入都保证以“us”结尾，因此转换规则是确定性的。 

关键的观察是我们不需要搜索或验证任何东西。 后缀是固定的，所以根总是通过删除最后两个字符来获得。 一旦提取出根，构建复数就是与“i”直接连接。 

这将问题从任何类型的解析或模式匹配减少到简单的字符串切片操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力解析 | O(2^n) 或不必要的匹配 | O(n) | 太慢/不必要|
 | 直接去除后缀 | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取表示单数名词的输入字符串。 
2. 删除字符串的最后两个字符。 这是安全的，因为该问题保证了后缀“us”始终存在。 
3. 将剩余的前缀视为词根。 
4. 将字符“i”附加到词根以形成复数形式。 
5. 输出结果字符串。 

这里唯一的推理步骤是后缀删除始终有效并且不依赖于任何额外的检查。 

### 为什么它有效

 每个有效单词都由词根+“us”构成。 删除最后两个字符总是可以准确地重建原始根。 由于复数形式被独立定义为根+“i”，因此变换是完全确定的和单射的，这意味着不存在歧义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    w = input().strip()
    root = w[:-2]
    print(root + "i")
```读完每个单词后，我们只需切掉最后两个字符即可。 这是安全的，因为保证“以我们结束”确保切片永远不会损坏根。 然后我们将“i”连接起来形成复数。 该实现避免了任何条件或特殊情况，因为即使是空根情况也能正确运行：“us”变成“”，然后变成“i”。

 ## 边缘情况

 对于输入“us”，删除最后两个字符会产生一个空字符串。 该算法无需特殊逻辑即可正确处理此问题并输出“i”，匹配所需的复数形式。 

对于任何包含内部“us”序列（例如“sussus”）的单词，仅删除最后两个字符。 根变成“suss”，附加“i”给出“sussi”，表明内部模式不影响正确性。
