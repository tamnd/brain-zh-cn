 ## 解决方案
 ## 问题理解

 我们从一个二进制字符串开始`s`和一个空字符串`t`。 

移动允许我们采用一个字符串的任何后缀并将其附加到另一个字符串。 由于只能移动后缀，因此字符的相对顺序永远不会改变。 角色只能跨越之间的界限`s`和`t`。 

目标是结束每一个`0`里面`s`和每一个`1`里面`t`。 我们需要达到该状态所需的最少后缀传输次数。 

每个字符串的长度最多为 1000，所有测试用例的总长度也最多为 1000。尽管约束很小，但预期的解决方案比任何基于搜索的方法要简单得多。 可以通过扫描一次字符串来计算答案。 

棘手的部分是理解一个举动实际上会改变什么。 由于只能转移后缀，因此我们不能任意重新排列字符。 每一步只会移动两根弦之间的边界。 相同字符的连续块的结构成为关键观察。 

考虑一些简单的边缘情况。 

如果字符串已仅包含零，例如：```
s = "00000"
```然后`t`可以保持为空。 答案是`0`。 

一个不经意的解决方案总是让所有人感动`1`进入`t`可能会错误地执行不必要的操作。 

现在考虑：```
s = "1111"
```唯一有效的最终状态是：```
s = ""
t = "1111"
```一次移动即可传输整个字符串。 答案是`1`。 

另一个微妙的情况是：```
s = "001"
```最后一个块已经是一个块了。 我们可以直接将该后缀移动到`t`一步到位，所以答案是`1`。 

一个常见的错误是计算块的数量并返回该值。 这里有两个块（`00`和`1`），但只需要一步。 

最后，考虑：```
s = "101"
```答案是`3`。 

交替的结构迫使我们来回移动多个后缀。 在此示例中，任何仅计算 1 或 0 数量的方法都会失败。 

## 方法

 暴力的观点是将每个状态视为一对字符串`(s, t)`并运行 BFS。 每个可能的后缀传输都会创建一个新状态。 BFS 最终会找到最小移动次数，因为所有移动的成本相同。 

问题在于国家数量呈爆炸性增长。 即使对于中等长度的字符串，也有太多可能的字符串对需要探索。 这种方法几乎立即变得不切实际。 

为了找到更好的解决方案，我们需要了解移动会实现什么效果。 

将字符串视为由相同字符组成的连续块。 例如：```
001110011
```包含块：```
00 | 111 | 00 | 11
```每次角色在相邻位置之间发生变化时，都会开始一个新的块。 

假设我们从左到右扫描字符串。 每当一个块`1`s 出现，那些最终必须以`t`。 由于移动是根据后缀进行的，因此不同角色之间的每次转换都会产生额外的障碍，需要再次进行转换。 

在研究了几个例子之后，一个简单的模式出现了。 

让`changes`是位置的数量`i`这样：```
s[i] != s[i - 1]
```然后：

 如果字符串开头为`0`，答案正是`changes`。 

如果字符串开头为`1`，答案是`changes + 1`。 

为什么起始角色很重要？ 

如果字符串开头为`1`，第一块最终必须移出`s`。 这需要一项额外的操作。 如果字符串开头为`0`，第一个块已经位于正确的一侧，不需要初始移动。 

这立即给出了`O(n)`解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取二进制字符串`s`。 
2. 计算相邻字符不同的次数。 

对于每个索引`i > 0`， 如果`s[i] != s[i-1]`，增加一个计数器`changes`。 

每个这样的位置都标记一个新块的开始。 
3. 如果第一个字符是`1`，在答案中再添加一个。 

前导块必须被转出`s`，创建一个额外的必需动作。 
4. 否则，如果第一个字符是`0`，答案很简单`changes`。 
5. 输出结果。 

### 为什么它有效

 该字符串可以被视为零和一的交替块。 

两个相邻块之间的每个边界必须在某个点被移动后缀边界穿过。 每个角色变化都恰好贡献一次所需的转移。 这说明了字符串中的所有转换。 

如果字符串以一个 1 块开头，则该块最初位于错误的位置，因为所有 1 都必须在内部完成`t`。 移出第一个块需要在已经计算的转换之外进行额外的操作。 

因此，最小移动次数等于角色变化的次数，当第一个角色出现时加一。`1`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        s = input().strip()

        changes = 0
        for i in range(1, n):
            if s[i] != s[i - 1]:
                changes += 1

        answer = changes + (1 if s[0] == '1' else 0)
        print(answer)

solve()
```实现直接遵循对块的观察。 

该循环对当前字符与前一个字符不同的每个位置进行计数。 这正是连续块之间的转换数量。 

之后，我们检查第一个字符。 如果是的话`1`, we add one extra move. Otherwise nothing additional is needed.

 唯一的边界条件是长度为一的字符串。 In that case the loop never executes,`changes`仍然为零，并且公式仍然正确有效。`"0"`产生`0`， 尽管`"1"`产生`1`。
