 ## 解决方案
 ## 问题理解

 经过重力排序后，沙子的形状完全由排列决定。 自从$p$是一个排列$1 \ldots n$，最终的形状始终是相同的楼梯：第一列包含$n$块，第二个包含$n-1$， 等等。 

有趣的部分是颜色。 

对于每一行$i$，该行中的所有块最初都有颜色$c_i$。 施加重力后，块仅垂直移动。 块永远不会改变它的列。 因此，整个第一列不受重力影响。 从上到下读取第一列的颜色给出了数组$c$。 

亚历克斯得到最终的彩色布局并询问有多少对$(p',c')$本来可以生产它的。 

第一次观察立即修复$c'$。 由于第一列被保留，任何有效的源配置都必须满足$c' = c$。 问题变成：

 有多少种排列$p'$当颜色数组固定时产生相同的最终颜色布局？ 

所有测试用例的总长度最多为$2 \cdot 10^5$。 任何比较所有位置对的解决方案都太昂贵。 我们周围需要一些东西$O(n \log n)$或者$O(n \alpha(n))$。 

当所有颜色都相同时，会出现微妙的边缘情况。 

例如：```
p = [5,3,4,1,2]
c = [1,1,1,1,1]
```每个沙块都有相同的颜色。 最终图片不包含有关排列值顺序的信息。 任何排列都有效，所以答案是$5!$。 

另一个重要的情况是每种颜色都不同。```
p = [4,2,3,1,5]
c = [2,1,4,1,5]
```现在每种颜色都像一个标签。 最终的布局唯一地确定了每个值的来源，给出了答案$1$。 

天真的“在等色组内排列值”的论点在这里失败了，因为一些等色位置可以交换值，而其他位置则不能。 确切的可互换性条件是问题的核心。 

## 方法

 强力方法将枚举通过在相同颜色位置之间重新排列值而获得的每个排列，并检查所得的重力排序图片是否相同。 

这是正确的，因为$c$是固定的，但是速度慢得令人绝望。 即使是单一颜色等级的尺码$20$已经创建了$20!$的可能性。 

关键的观察是，最终图片仅取决于相同颜色位置之间的某些相对约束。 

占据两个位置$i$和$j$具有相同的颜色。 

当且仅当它们之间不同颜色的每个位置包含严格小于两个端点的值时，它们可以交换排列值而不改变最终图片。 这种描述是问题的核心，出现在官方社论中。 

一旦这个条件被写成排列值，基于 DSU 的值扫描就变得自然了。 

从小到大处理排列值。 

当值$v$被激活，所有值小于$v$已经活跃了。 这些活动头寸恰好是可能位于两个较大的同色值之间而不阻止交换的头寸。 

使用 DSU，我们可以维护由已激活位置形成的连接区域。 对于每个位置，我们获得其值可能移动的最大间隔。 

这些区间具有层状结构：任何两个区间要么不相交，要么一个包含另一个。 

层状家族的行为就像一棵有根的树。 对这种结构内的有效分配进行计数可以简化为在组件内重复选择一个空闲位置。 我们可以在 DSU 合并期间进行计数，而不是显式构建树。 每次合并组件时，我们都会将答案乘以当前组件大小，然后将可用计数减一。 这是社论中描述的优化。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 阶乘 | 指数| 太慢了|
 | 最优 DSU + 组合计数 |$O(n \alpha(n))$|$O(n)$| 已接受 |

 ## 算法演练

 1. 观察第一根柱子在重力作用下永远不会移动。 
2. 得出任何有效的源配置必须具有完全相同的颜色数组的结论$c$。 
3. 按升序处理排列值。 
4. 在值已激活的位置上维护 DSU。 每个 DSU 组件都存储其最左边和最右边的位置。 
5. 对于包含价值的位置$v$，使用相邻的激活组件来确定该值在保留最终图片的同时可以移动的最大间隔。 
6. 由此产生的区间形成层流族。 任何两个区间要么不相交，要么嵌套。 
7. 处理间隔从小到大。 按间隔顺序合并 DSU 组件，而不是显式构建间隔树。 
8. 每当合并创建一个包含以下内容的组件时$k$当前可用的选择，将答案乘以$k$。 
9. 将该组件内的可用计数减一，表示刚刚修复的选择。 
10. 继续，直到处理完所有间隔。 
11. 输出累加乘积模$998244353$。 

### 为什么它有效

 交换特征完整地描述了两个相同颜色的值何时可以交换位置。 每一个有效的排列都是通过重复应用这样的交换而产生的，并且每一次这样的交换都保留了最终的沙画。 递增值 DSU 扫描准确找到每个值可到达的最大区域。 

因为可达区间是层流的，所以不同分支内的选择不会相互干扰。 计数与计算有根区间树中的有效分配相同。 DSU 合并过程执行与显式树 DP 执行的乘法完全相同的操作，但不构造树。 

因此，每个有效的源排列都会被计算一次，并且不会计算无效的排列。

        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]

 ## 边缘情况

 考虑：```
n = 1
p = [1]
c = [5]
```第一列包含单色 5。不存在替代颜色数组。 唯一的排列是`[1]`，所以答案是1。 

考虑：```
p = [3,2,1]
c = [1,1,1]
```每个块都有相同的颜色。 最终的图片无法区分任何排列顺序。 全部$3! = 6$排列是有效的。 

考虑：```
p = [3,1,2]
c = [1,2,3]
```每种颜色都是独一无二的。 第一列立即标识每一行，没有留下任何自由。 答案是1。 

这些例子说明了 DSU 区间框架统一的两个极端：完全自由和完全刚性。
