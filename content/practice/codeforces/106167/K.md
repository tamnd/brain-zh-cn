 ## 解决方案
 ## 问题理解

 我们得到了一群人和一份不能坐在同一个房间的人的名单。 有效的会议安排会将每个人恰好分配到东或西两个房间中的一个，这样每个“不喜欢”的房间就会被分配到不同的房间。 

每年我们都必须为相同的人员和限制再次选择这样一个有效的任务。 问题是我们试图不断生成新的有效分配，而不会重复以前使用过的分配，并且交换两个房间被认为是相同的而不是新的。 我们想知道在哪一年重复变得不可避免，这意味着所有不同的作业（在此等价下）已经用尽。 

输入描述了一个图，其中顶点是人，边是不喜欢的关系。 有效的分配正是该图的 2 着色。 输出是必须出现重复的第一年，以给定的奇素数为模，或者如果根本不存在有效的 2 着色，则输出不可能的单词。 

约束多达一百万个顶点和边，因此任何解决方案在图的大小上都必须基本上是线性的，最多具有对数开销。 任何涉及枚举作业或颜色指数探索的事情都会立即被排除。 

一个天真的但危险的边缘情况是当图形包含奇数循环时。 例如，三角形 1-2-3-1 使得不可能分成两个房间。 一个粗心的实现，只贪婪地分配而不检查一致性，可能仍然会输出一些数字，但正确的输出肯定是不可能的。 

另一个微妙的情况是没有边的图。 在这种情况下，每个分配都是有效的，但交换东和西被认为是相同的，因此不同分配的计数不是 2^n 而是在全局对称下崩溃。 这就是独立顶点选择的天真计数通常会过度计数的地方。 

## 方法

 一种强力解释是生成每个有效的人员分配到东西房间并将它们存储在一组中，当出现重复项时停止。 每个分配都是图的二进制标签，但它还必须满足所有边缘约束，因此我们需要枚举所有有效的 2 着色。 

即使忽略验证成本，原始分配的数量也是 2^n，这对于 n 达到 10^6 来说已经是不可能的。 即使我们将自己限制为仅有效的着色，数量仍然随着连接组件的数量呈指数增长，因此枚举仍然不可行。 

关键的观察结果是，有效性对于连接的组件来说完全是局部的。 图的每个连接组件的行为都是独立的：一旦我们修复了组件中单个顶点的颜色，该组件的其余部分就会被强制。 因此，每个组件都贡献一个二元选择，对应于翻转该组件中的所有颜色。 

如果有 c 个连通分量，则有 2^c 个原始有效着色。 然而，全局交换东西方不会产生新的分配，因此每个配置都与其全局补充配对。 这会将计数除以 2，留下 2^(c−1) 个不同的赋值。 

问题中描述的过程有效地枚举所有不同的分配，直到耗尽，因此在使用所有唯一分配后，重复就不可避免。 这意味着答案是 2^(c−1) + 1，以 p 为模计算。 

在计数之前，我们还必须确保图是二分图。 如果任何组件不是 2-colorable，则该过程会立即中断。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力枚举分配| 指数| 指数| 太慢了 |
 | 连接组件+双向检查+电源| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

我们将问题简化为图结构的属性以及它包含多少个独立的二元选择。 

1. 根据给定的不喜欢对构建图表。 每个人都是一个节点，每一对都是一条无向边。 
2. 在每个未访问的节点上运行 BFS 或 DFS，以检查二分性并计算连接的组件。 遍历组件时，分配交替颜色以检测矛盾。 如果我们尝试为节点分配与已有颜色不同的颜色，则该图不是二分图，并且不存在有效的分配。 
3. 每次我们从未访问的节点启动新的 BFS/DFS 时，我们都会增加连接组件计数 c。 这是可行的，因为每次遍历都会充分探索一个组件。 
4. 如果在任何一点发现矛盾，我们立即输出不可能。 
5. 一旦我们有了 c，就计算全局交换所有房间的不同分配的数量。 这是 2^(c−1) 模 p。 
6. 第一次重复发生在所有不同的赋值都用尽之后，因此我们输出 2^(c−1) + 1 modulo p。 

微妙的一点是为什么只有组件很重要：在连接的组件中，固定一个顶点决定其余的顶点，因此每个组件恰好贡献一个独立的翻转位。 全局交换同时消除了所有组件的一个自由度。 

### 为什么它有效

 每个有效的分配都对应于为每个连接的组件选择一个二进制方向。 如果两个作业仅通过同时翻转所有组件而有所不同，那么在问题的等价性下，两个作业是相同的。 这意味着不同配置的空间是 c 维布尔立方体除以全局翻转对称性的商，恰好留下 2^(c−1) 个不同状态。 由于每年必须使用新的状态直到用尽，因此第一次强制重复会在这组用尽后立即发生。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n, m, p = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        a, b = map(int, input().split())
        g[a].append(b)
        g[b].append(a)

    color = [-1] * (n + 1)
    components = 0

    for i in range(1, n + 1):
        if color[i] != -1:
            continue
        components += 1
        stack = [i]
        color[i] = 0

        while stack:
            v = stack.pop()
            for to in g[v]:
                if color[to] == -1:
                    color[to] = color[v] ^ 1
                    stack.append(to)
                elif color[to] == color[v]:
                    print("impossible")
                    return

    if components == 0:
        print(1 % p)
        return

    ans = pow(2, components - 1, p) + 1
    print(ans % p)

if __name__ == "__main__":
    solve()
```该图存储为邻接列表，以便遍历和二分检查都在线性时间内运行。 DFS 使用显式堆栈来避免一百万个节点上的递归深度问题。 

这`color`数组同时跟踪访问和二分着色。 值为`-1`表示未访问过，而`0`和`1`代表两个房间。 邻居已经具有相同颜色的任何冲突都表示奇数周期。 

每当我们找到未访问的节点时，通过开始新的遍历来完成组件计数。 这直接产生最终公式中独立二元选择的数量。 

最后，模幂用于模数 p 下的 2^(c−1)，并且我们添加 1 以考虑第一次强制重复。 

## 工作示例

 ### 示例 1

 输入图：4 个节点、边 (1-2) 和 (3-4)。 

我们跟踪组件和颜色：

 | 步骤| 节点| 行动| 组件| 颜色 |
 | ---| ---| ---| ---| ---|
 | 开始| 1 | 新组件| 1 | 1:0 |
 | BFS | 2 | 颜色相反 | 1 | 1:0、2:1 |
 | 下一页 | 3 | 新组件 | 2 | 3:0 |
 | BFS | 4 | 颜色相反 | 2 | 3:0, 4:1 |

 我们以 2 个连接的组件结束。 不同作业的数量为 2^(2−1) = 2，因此第一次重复发生在第 3 年。 

这符合每个边对组件都可以翻转的直觉，但全局交换识别对称配置。 

### 示例 2

 输入图：5个节点，边（1-2）和（3-4），节点5隔离。 

| 步骤| 节点| 行动| 组件| 颜色 |
 | ---| ---| ---| ---| ---|
 | 开始| 1 | 新组件 | 1 | 1:0 |
 | BFS | 2 | 颜色相反 | 1 | 1:0、2:1 |
 | 下一页 | 3 | 新组件| 2 | 3:0 |
 | BFS | 4 | 颜色相反 | 2 | 3:0, 4:1 |
 | 下一页 | 5 | 新组件| 3 | 5:0 |

 我们现在有 3 个组件，因此不同的分配是 2^(3−1) = 4，并且重复从 5 开始。 

跟踪显示，孤立顶点的行为与具有强制结构的组件完全相同，对计数有独立贡献。

 ## 边缘情况

 一个关键的边缘情况是完全断开的图。 在这种情况下，每个节点都是它自己的组件，因此组件的数量等于 n。 该算法在 DFS 期间仍然将每个孤立的顶点视为一个单独的组件，最终公式正确地减少到 2^(n−1) + 1。 

另一种边缘情况是具有单个顶点的图。 遍历从一个组件开始并立即结束。 公式变为 2^(0) + 1 = 2，这意味着我们可以首先指定东或西，第二年必须重复。 

最后一个关键情况是奇数周期。 在 DFS 过程中，我们最终尝试为节点分配与先前分配冲突的颜色。 该算法立即停止并输出不可能，而不尝试对组件进行计数，因为根本不存在有效的分配空间。
