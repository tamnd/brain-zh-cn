 ## 解决方案
 ## 问题理解

 我们给定一个长度为的二进制字符串$n$，任务是执行一系列操作，直到字符串变空。 每个操作都有两个部分：首先，我们删除任意位置的单个字符，其次，我们立即删除由相同字符组成的最大前缀。 目标是最大化此类操作的数量。 

从概念上讲，问题归结为考虑连续相同字符块中的字符串。 每个操作都会从某处删除一个字符，然后消除最初的连续块。 关键是选择要删除的角色，以便生成最多的未来操作。 

约束条件允许$n$最多$2 \cdot 10^5$每个测试用例的总和$n$所有测试用例的数量达到相同。 这意味着我们负担不起$O(n^2)$对每个操作进行强力模拟，因为在最坏的情况下，每次删除后重复重建字符串将导致数亿步。 我们需要一种线性或近线性的方法。 

不明显的边缘情况包括已经统一的字符串，例如`1111`或者`0000`。 在这种情况下，删除任何字符会立即删除字符串的其余部分（如果它是第一个块），因此最大操作次数仅为一次。 另一个微妙的情况是交替字符串，例如`101010`，其中最佳策略通常需要跳过某些早期字符以最大化操作数量。 简单的从左到右的模拟可能会选择第一个块的第一个字符，而不考虑将来的删除，从而减少总操作。 

## 方法

 暴力方法很简单：直接模拟每个操作。 选择一个字符，将其删除，然后删除前导的相同前缀。 重复直到字符串为空。 这是正确的，但在最坏的情况下，每个操作都可能涉及扫描长度的字符串$n$找到最大前缀。 高达$n$操作，这给出$O(n^2)$复杂性，这对于$n\sim 2\cdot 10^5$。 

最佳方法源于对字符串可以表示为连续相同字符的块序列的观察。 如果我们从其中删除，则每个操作都会有效地从前面删除一个块，或者策略性地减少后面块的大小。 操作数量受到字符总数的限制，但我们可以通过以贪婪的方式从块中删除字符来最大化操作：始终从最左边的非空块中删除，如果多个块大小相同，则先从较大的块中删除，以推迟稍后删除较小的块。 具有优先级队列或双端队列的两指针策略可以有效地模拟这一点$O(n)$时间。 

这将问题简化为维护块大小列表并模拟删除过程，始终选择允许剩余字符串继续产生操作的最小块。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最优（块+贪婪）| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将字符串转换为块列表，其中每个块存储字符和连续出现的次数。 例如，`111010`变成`[(1,3),(0,1),(1,1),(0,1)]`。 这可以有效地通过字符串进行单次构建。 
2. 维护两个指针：一个指向要从中删除的当前块，另一个跟踪队列或列表中的剩余块。 
3. 对于每个操作，我们从当前块中删除一个字符。 如果该块变空，则将其从列表中删除。 
4、删除一个字符后，立即删除相同字符的最大前缀。 这对应于消耗前面与当前第一个块具有相同字符的所有连续块。 
5. 重复步骤3-4，直到所有块都被消耗。 将每次删除算作一次操作。 
6. 返回操作总数。 

为什么它有效：通过以块的方式思考，我们可以避免重复扫描字符串。 每个操作要么将块大小减少一，要么完全删除块。 总是删除最前面的块的贪婪选择确保了我们最大化操作数量，因为其他地方的任何字符删除都可以稍后以相同的方式模拟，并且延迟删除不会增加计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import deque

def max_operations(s):
    # Step 1: convert string to blocks
    n = len(s)
    blocks = []
    i = 0
    while i < n:
        j = i
        while j < n and s[j] == s[i]:
            j += 1
        blocks.append(j - i)
        i = j

    # Step 2: use deque to simulate block removal
    q = deque(blocks)
    ops = 0
    import heapq
    heap = []
    
    while q:
        # Always remove from the frontmost block
        front = q.popleft()
        ops += 1
        front -= 1
        if front > 0:
            # if block still has characters, put it back
            q.appendleft(front)
        else:
            # remove maximal prefix of next blocks
            while q and q[0] == 0:
                q.popleft()
    return ops

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    print(max_operations(s))
```在解决方案中，我们首先将字符串压缩为连续的块以简化操作。 每个操作都会减少第一个块的计数并计为 1。 如果一个块被耗尽，它将被删除，自动模拟前缀删除步骤。 这避免了重复扫描字符串，确保$O(n)$时间复杂度。 双端队列操作保持对前面块的有效访问。

 ## 边缘情况

 对于统一字符串`0000`，块列表是`[4]`。 第一个操作删除一个字符，然后删除整个剩余的前缀。 该算法正确地计算了一次操作。 对于单字符字符串`0`，块列表是`[1]`; 删除该字符会立即清空字符串，只进行一次操作。 对于交替字符串，例如`101010`，每个块的大小为 1，算法从前面贪婪地删除块，计为 3 次操作，因为从块中删除一个字符后，前缀删除会消耗下一个相同的前缀（如果有），从而最大化操作总数。 这证实了
