 ## 解决方案
 ## 问题理解

 每个输入值都可以视为一个标有整数的框，对于每个框，我们必须选择该数字的两个非平凡除数。 所选择的除数必须都大于一，必须精确地除以该数字，并且它们的总和必须与原始数字“不兼容”，即不允许原始数字的素因数被该总和除。 

输出要么为每个数字提供这样一对除数，要么以 -1 -1 声明失败。 关键的困难在于，约束不是关于所选除数本身的整除性，而是关于它们的总和与数字的完整素数结构之间的关系。 

约束很大：最多 5×10^5 个数字，每个数字最大为 10^7。 这排除了通过试除法对每个数字进行因式分解。 即使是 O(n√a_i) 方法，在最坏的情况下也意味着大约 10^10 次操作，这远远超出了时间限制。 该结构强烈建议在整个值范围内进行预处理步骤，最自然的是像筛子一样，允许对每个数字进行恒定或接近恒定的因子查询。 

当数字是素数幂时，会出现微妙的边缘情况。 例如，对于 8，每个大于 1 的除数仍然仅由相同的素数组成，因此两个这样的除数的任何和仍然可以被该素数整除，这立即违反了 gcd 条件。 在这种情况下，不存在有效的对。 

另一种边缘情况是当数字具有多个不同的素数但其中一个在特定因式分解选择中仅出现一次时。 粗心地选择任意除数的方法可能会失败，因为即使两个除数单独有效，总和也可能意外地继承与原始数字共享的质因数。 

## 方法

 暴力策略将检查每个数字的所有除数对。 对于单个值 a_i，我们可以枚举所有除数并测试所有对，检查 gcd(d1 + d2, a_i) 是否等于 1。 在最坏的情况下，像 10^7 这样的数字可能有数千个除数，并且在 5×10^5 查询中这在计算上变得不可行。 甚至枚举除数本身也需要因式分解，这已经在复杂性中占据主导地位。 

关键的观察是我们不需要任意除数。 构造一对具有从数字的质因数分解得出的非常具体的结构就足够了。 将 a_i 写为 p^k · b，其中 p 是 a_i 的最小质因数，并且 p 不能整除 b。 如果 b 等于 1，则该数是纯素数幂并且不存在解。 否则，选择 d1 = p^k 和 d2 = b 保证两者都是大于 1 的有效除数，并且由于共享素数因子上的结构性矛盾论证，gcd 条件成立。 

这将问题简化为快速分解查询，可以使用预先计算的最小素因子筛来回答。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n·d^2 + 因式分解成本) | O(1) 额外 | 太慢了 |
 | 最佳 | O(N log log N + n log a_i) | O(N log log N + n log a_i) | O(N) | 已接受 |

 ## 算法演练

 ### 预处理和构建逻辑

1. 为 10^7 以内的每个整数构建一个最小质因数数组。 这使我们能够通过重复除以任何数字的最小素数来快速分解任何数字。 
2. 对于每个数字a_i，检索其最小素因数p。 这保证了 p 是其因式分解中的第一个素数并且可以干净地分离。 
3. 通过在可整除的情况下重复除法，从 a_i 中提取 p 的全部幂。 这会产生 p^k 和不能被 p 整除的剩余值 b。 
4. 如果b等于1，则该数是素数幂并且不存在有效分解，因此输出-1 -1。 
5. 否则，设置 d1 = p^k 且 d2 = b。 两者都保证大于 1 并且都整除 a_i。 
6. 输出构建的对。 

### 为什么它有效

 设a_i = p^k · b，其中p 不能整除b。 假设某个素数 q 既能整除 d1 + d2 又能整除 a_i。 然后 q 必须整除 p 或 b，因为它们是因式分解中素数的唯一来源。 如果 q = p，则 p 除 p^k + b，这意味着 p 除 b，与结构相矛盾。 如果 q 整除 b，则 q 整除 b 和 p^k + b，这意味着 q 整除 p^k，这是不可能的，因为 p 不能被 q 整除。 这消除了所有可能的共享素数，因此 gcd 必须是 1。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXA = 10**7

spf = list(range(MAXA + 1))
for i in range(2, int(MAXA ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, MAXA + 1, step):
            if spf[j] == j:
                spf[j] = i

def solve():
    n = int(input())
    arr = list(map(int, input().split()))

    out1 = []
    out2 = []

    for x in arr:
        p = spf[x]

        d1 = 1
        while x % p == 0:
            x //= p
            d1 *= p

        d2 = x

        if d2 == 1:
            out1.append("-1")
            out2.append("-1")
        else:
            out1.append(str(d1))
            out2.append(str(d2))

    print(" ".join(out1))
    print(" ".join(out2))

if __name__ == "__main__":
    solve()
```筛子预先计算最小的质因数，因此每个数字都可以在其大小的对数时间内分解。 内部循环提取最小素数的全部幂，确保 d1 是干净的素数幂除数，并且 d2 包含剩余结构。 

关键的实现细节是在构建 d1 时 x 被破坏性地减少。 这保证了 d2 恰好是互补因子，而不需要额外的乘法或因子跟踪。 

## 工作示例

 考虑示例输入：```

```我们追踪一些有代表性的值。 

| a_i | p = 防晒指数 | d1 施工 | 剩余 d2 | 结果 |
 | ---| ---| ---| ---| ---|
 | 4 | 2 | 2^2 = 4 | 2^2 = 4 1 | -1 -1 | -1 -1
 | 6 | 2 | 2 | 3 | (2, 3) |
 | 8 | 2 | 2^3 = 8 | 2^3 = 8 1 | -1 -1 | -1 -1
 | 24 | 2 | 2^3 = 8 | 2^3 = 8 3 | (8, 3) |

 对于 6，分成 2 和 3 是有效的，因为它们是从不同的质因数导出的。 对于 24，隔离 2 的全部幂留下 3，并且它们的和避免了与 24 的任何公共质因数。 

这表明该结构始终将最小素数的贡献与分解的其余部分完全分开。

 ## 边缘情况

 对于像 16 这样的素数幂，算法会重复提取 p = 2，直到 d1 变为 16，d2 变为 1。这会立即触发故障条件，正确拒绝输入，因为所有除数都仅限于单个素数。 

对于像 10 这样的数字，分解得到 p = 2、d1 = 2、d2 = 5。总和为 7，它与 10 没有素因数，即使两个除数各自也是素数，也确认了正确性。 

对于具有多个因子的数字（例如 12），提取 2 的全部幂会产生 d1 = 4 和 d2 = 3。即使存在其他有效的分解，这种构造也通过将最小素数分量与分解的其余部分分开来始终避免和中共享素数。
