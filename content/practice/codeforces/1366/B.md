 ## 解决方案
 ## 问题理解

 我们得到一个大小的数组$n$除了位置上有一个 1 之外，均使用全零进行初始化$x$。 该数组是 1 索引的。 然后我们有$m$操作，每个操作都由一个范围定义$[l_i, r_i]$。 在每个操作中，我们可以交换该范围内的任意两个元素。 任务是确定在按照我们选择的任意顺序应用这些操作后，数组中有多少个位置可能包含 1。 

虽然数组大小$n$可以非常大，最多$10^9$, 操作次数$m$很小，最多 100。这表明我们无法显式地表示该数组。 相反，我们必须推理范围以及 1 在这些范围内的运动。 

一个重要的微妙之处是，重叠范围中的多次交换可以有效地将 1 传播到由范围并集连接的任何位置。 例如，如果初始的1在位置4，并且第一次操作覆盖了[1, 6]，那么1可以立即到达从1到6的所有位置。 如果后面的操作覆盖 [2, 3]，则不会进一步扩展范围，但如果另一个操作覆盖 [5, 7]，则可到达位置扩展到 [1, 7]。 

非明显的边缘情况包括：从边界开始的 1（位置 1 或$n$）、单例操作 ([3,3]) 以及不与任何当前可到达位置重叠的操作。 尝试模拟所有可能的交换的简单解决方案将会失败，因为$n$太大了。 例如，与$n = 10^9$，存储数组或迭代它是不可行的。 

## 方法

 暴力方法将通过维护数组来直接模拟交换。 对于每个操作，我们将尝试范围内的所有交换对，检查 1 是否移动。 即使我们只跟踪 1 的位置，尝试每个范围内的每次交换很快就会变得棘手。 为了$m = 100$范围达 size 的操作$n$，由于数组规模巨大，这种方法是不可能的。 

关键的见解是跟踪**可以出现 1 的位置的连续范围**而不是数组本身。 最初，范围只是 [x, x]。 对于每个操作，如果其范围与 1 的当前范围重叠，我们可以将它们合并：1 现在可以出现在当前范围和操作范围的并集中的任何位置。 否则，该操作不会影响 1 的可能位置。 处理完所有操作后，答案就是最终范围的长度。 

这一观察结果将问题简化为简单的区间并集跟踪，这是有效的，因为$m$很小并且$n$不需要明确表示。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(m * n) | O(n) | 太慢了 |
 | 最佳（间隔跟踪）| O(米) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化`left`和`right`到`x`。 这些变量表示 1 可以出现的当前包含范围。 
2. 迭代由以下定义的每个操作`[l_i, r_i]`。 
3.如果操作的范围`[l_i, r_i]`与当前范围重叠`[left, right]`（IE。，`l_i <= right`和`r_i >= left`)，更新范围以包含操作：`left = min(left, l_i)`和`right = max(right, r_i)`。 
4. 处理完所有操作后，1 能结束的索引个数为`right - left + 1`。 
5. 对所有测试用例重复此操作。 

为什么它有效：不变的是`left`和`right`始终包含 1 通过迄今为止所考虑的操作可到达的所有位置。 每当操作与此范围重叠时，可达范围就会扩展以包含该范围。 当前范围之外的任何操作都不会影响 1，因此忽略非重叠操作是正确的。 最终的范围长度正是可能位置的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x, m = map(int, input().split())
    left = right = x
    for _ in range(m):
        l, r = map(int, input().split())
        if l <= right and r >= left:
            left = min(left, l)
            right = max(right, r)
    print(right - left + 1)
```该解决方案读取测试用例的数量并对其进行迭代。 对于每个测试用例，它将可达范围初始化为`[x, x]`。 检查每个操作是否有重叠，并相应更新范围。 最后，打印范围的长度。 该代码使用包含索引并正确处理单元素范围，因为范围计算`right - left + 1`为`left = right`。

 ## 边缘情况

 如果 1 从第一个或最后一个索引开始，并且操作涵盖包括边界在内的范围，则算法会正确合并范围。 例如，与`n = 5, x = 5, m = 1`和操作`[4,5]`，初始范围`[5,5]`合并于`[4,5]`到`[4,5]`。 输出是`2`，这是正确的。 单元素运算`[3,3]`与当前范围不重叠的部分保持范围不变，正确生成输出 1。
