 ## 解决方案
 ## 问题理解

 该任务描述了基于重复求和整数幂的简单数值构造$k$。 对于每个查询，我们都会得到一个基值$k$和一个长度$n$，我们必须计算将第一个相加得到的值$n$的权力$k$，从$k^1$。 

换句话说，我们正在评估几何级数，其中第一项是$k$，第二个是$k^2$，依此类推，直到$k^n$。 输出是这些值的总和。 

从计算的角度来看，每个查询的输入大小在结构上很小，但潜在的价值很大，因为$k$增长速度极快。 这立即排除了对大指数序列进行朴素整数模拟的可能性$n$，除非我们有效地处理求幂。 

如果$n$可以达到很大的值（通常高达$10^5$或更多这种风格的问题），由于重复乘法，独立计算每个幂的线性循环变得不可行。 即使每次乘法都是$O(1)$，由于大整数运算，中间值的指数增长也成为Python的瓶颈。 

主要的约束含义是我们必须避免从头开始重新计算幂，而是重用以前的计算或应用封闭式公式。 

边缘情况出现时$k = 1$，因为一般几何级数公式涉及除以$k-1$，它变为零。 另一个微妙的情况是当$n = 1$，其中总和退化为单项$k$。 一个幼稚的公式实现很容易在这里崩溃。 

盲目使用封闭形式时会发生一个具体的失败例子：

 输入：```
k = 1, n = 5
```正确的输出是：```
5
```但申请$\frac{k(k^n - 1)}{k - 1}$导致除以零。 

另一个案例：```
k = 2, n = 1
```正确的输出是：```
2
```粗心的循环可能会在以下位置开始求幂$k^0$而不是$k^1$，产生总和的偏移一位。 

## 方法

 蛮力的想法很简单。 我们从指数 1 迭代到$n$, 计算$k^i$每次，并累加总和。 这是正确的，因为它直接遵循问题的定义。 然而，计算$k^i$每一步独立地导致重复的求幂工作。 即使我们使用快速幂来优化取幂，$n$次导致$O(n \log n)$，对于大的情况来说变得太慢$n$。 

更好的观察来自于认识到连续幂是乘法相关的。 而不是重新计算$k^i$从头开始，我们可以维持当前功率的运行值。 开始于$k^1 = k$，下一项是通过将前一项乘以$k$。 这将每学期的成本降低到$O(1)$，使总和线性于$n$。 

对于以下情况$n$非常大并且存在多个测试用例，我们也可以依靠几何级数封闭形式：$$k + k^2 + \dots + k^n = \frac{k^{n+1} - k}{k - 1}$$为了$k \neq 1$。 这将问题简化为单个快速求幂。 

因此，问题的结构给出了两种可行的最优策略：增量乘法或快速求幂的直接公式计算。 当以下情况时，通常首选基于公式的方法：$n$很大。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n)$或者$O(n \log n)$|$O(1)$| 太慢了|
 | 公式+快速动力|$O(\log n)$|$O(1)$| 已接受 |

 ## 算法演练

 当以下情况时，我们使用封闭式几何级数表达式：$k \neq 1$，以及其他特殊情况。 

1. 读取整数$k$和$n$。 这些定义了幂和中的基数和项数。 
2.如果$k = 1$， 返回$n$。 这是因为总和中的每一项都是 1，所以总计只是项数。 
3. 否则计算$k^{n+1}$使用快速求幂。 我们计算$n+1$而不是$n$因为该公式涉及的项高达$k^{n+1}$。 
4. 计算$k$单独并从中减去它$k^{n+1}$，形成几何和公式的分子。 
5. 将结果除以$k - 1$。 这产生了几何级数的总和。 

关键的推理步骤是保持索引的正确性。 该系列开始于$k^1$，因此以封闭形式移动指数至关重要。 错过这种转变是最常见的错误来源。 

### 为什么它有效

 表达式$k + k^2 + \dots + k^n$是一个带有比率的标准几何级数$k$。 将总和乘以$k$将所有项平移一次幂，产生$k^2 + k^3 + \dots + k^{n+1}$。 减去原始总和就取消了所有中间项，只留下$k^{n+1} - k$。 这个恒等式确保闭合形式始终等于所有的原始总和$k \neq 1$。 特殊情况$k = 1$是单独处理的，因为代数变换在那里除以零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def mod_pow(a, e):
    res = 1
    base = a
    while e > 0:
        if e & 1:
            res *= base
        base *= base
        e >>= 1
    return res

def solve():
    data = input().strip().split()
    if not data:
        return
    k = int(data[0])
    n = int(data[1])

    if k == 1:
        print(n)
        return

    # sum = k + k^2 + ... + k^n = (k^(n+1) - k) / (k - 1)
    kn1 = mod_pow(k, n + 1)
    kn1_minus_k = kn1 - k
    print(kn1_minus_k // (k - 1))

if __name__ == "__main__":
    solve()
```解决方案如下$k$和$n$，然后分离退化情况$k = 1$。 对于所有其他情况，它计算$k^{n+1}$使用二进制求幂。 减法步骤仔细构造几何和恒等式的分子。 整数除法是安全的，因为保证表达式可以被整除$k - 1$。 

一个微妙的实现细节是我们计算$k^{n+1}$， 不是$k^n$。 这种转变使代数推导与总和开始于$k^1$， 不是$k^0$。 另一个重要的点是处理大整数，因为 Python 自然支持大整数，但中间值仍然可以显着增长。

 ## 边缘情况

 对于$k = 1$，算法立即返回$n$。 如果我们模拟该公式，就会被零除，所以这个分支是必不可少的。 例如输入$1, 5$，否则循环将计算$1 + 1 + 1 + 1 + 1 = 5$，而公式未定义。 

为了$n = 1$，公式变为$(k^2 - k)/(k-1)$，这简化为$k$。 算法正确计算$k^2$, 减去$k$，并除以，产生$k$确切地。 例如$k = 7, n = 1$产量$(49 - 7)/6 = 7$，确认边界处的一致性。 

对于大型$k$和$n$，中间值如$k^{n+1}$变得非常大，但 Python 的大整数可以安全地处理这个问题。 计算保持正确，因为没有应用模数约简，从而在整个过程中保持精确的算术。
