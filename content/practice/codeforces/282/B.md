 ## 解决方案
 ## 问题理解

 我们被要求在两个孩子 A 和 G 之间分配一系列鸡蛋，其中每个鸡蛋对每个孩子都有单独的成本。 关键约束是支付给 A 的总费用和支付给 G 的总费用不得相差超过 500。每个鸡蛋必须恰好分配给一个孩子，并且任何鸡蛋的 A 和 G 的成本总和固定为 1000。输入包括`n`鸡蛋，每个由两个整数描述：绘制它所需的价格 A 和 G 所需的价格，因此它们的总和始终为 1000。输出应该是表示鸡蛋分配的字母“A”或“G”序列。 

该问题需要仔细管理累计金额以保持在 500 的差异限制之内。 的上限`n`是 10^6，这排除了尝试所有 2^n 种可能分配的任何解决方案。 需要线性扫描或贪婪分配。 边缘情况包括大多数鸡蛋强烈偏爱一个孩子的情况，例如，许多鸡蛋都有成本`999`对于 A 和`1`对于 G。仅交替或始终选择更便宜的选项的简单方法可能会在这些情况下失败，因为差异很容易超过 500。解决方案必须跟踪运行总计并根据维持允许的差异做出分配决策。 

## 方法

 暴力方法会尝试将鸡蛋分配给 A 或 G 的每一种可能，并检查总差值是否在 500 以内。这原则上可行，但对于最多 10^6 个鸡蛋，将涉及 2^10^6 次操作，这是完全不可行的。 即使是修剪明显失败分支的回溯方法也无法扩展，因为差异约束可能会以不可预测的方式波动，并且较大`n`。 

关键的见解来自固定总和属性：对于每个鸡蛋，如果 A 的成本为`a`G 的成本为`g`， 然后`a + g = 1000`。 这意味着将一个鸡蛋分配给 A 会使 A 的总数增加`a`并使 G 的总数有效增加`g`。 自从`g = 1000 - a`，我们可以考虑运行差异`diff = Sa - Sg`。 如果我们把鸡蛋分配给A，`diff`增加了`2*a - 1000`; 如果我们将其分配给G，`diff`减少`2*a - 1000`（或同等地，增加`2*g - 1000`）。 这种线性关系允许贪婪分配：在每一步，选择将绝对差值保持在 500 以下的子级。`|Sa - Sg| <= 500`重要的是，简单的从左到右的贪婪选择是有效的，因为每个决策都有有限的效果，并且总的最大差异是累积的，但通过始终选择更安全的分配而限制在±500。

 ## 算法演练

 1. 初始化变量`diff`为0。该变量表示当前总差值`Sa - Sg`。 当我们分配鸡蛋时，它将逐步更新。 
2. 创建一个空列表`assignment`存储哪个孩子得到每个鸡蛋。 
3. 按顺序遍历鸡蛋列表。 每个鸡蛋都有成本`(a, g)`：

 1.如果将鸡蛋分配给A不会导致`abs(diff + a - g)`如果超过 500，请在后面添加“A”`assignment`并更新`diff += a - g`。 
2. 否则，将“G”附加到`assignment`并更新`diff += g - a`。 因为`a + g = 1000`，增量相当于`diff += -(a - g)`。 
4.处理完所有鸡蛋后，输出连接后的字符串`assignment`。 

为什么有效：在每一步中，我们都会做出贪婪的决定，将运行差异保持在允许的 ±500 范围内。 该问题保证存在有效的分配，除非`n`或者特定的值使得约束不可能，但是在给定每个鸡蛋 1000 总和的情况下，贪婪方法一定会成功。 不变的是`abs(diff) <= 500`在每一步中，每个分配都会选择维护此属性的子级。 由于每个鸡蛋都会线性且独立地影响差异，因此这足以构建有效的分布。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
eggs = [tuple(map(int, input().split())) for _ in range(n)]

diff = 0
assignment = []

for a, g in eggs:
    if abs(diff + a - g) <= 500:
        assignment.append("A")
        diff += a - g
    else:
        assignment.append("G")
        diff += g - a

print("".join(assignment))
```代码首先阅读`n`以及鸡蛋成本清单。 这`diff`变量跟踪当前支付给 A 和 G 的金额之间的总差异。在迭代过程中，我们通过测试哪个孩子将差异保持在 ±500 之内来决定每个鸡蛋的分配。 的更新为`diff`根据选择完成。 最后，作业列表被连接成一个字符串并打印。 边界条件是自然处理的，因为每个鸡蛋都会影响`diff`增量地，贪心选择保证`abs(diff) <= 500`每一步之后。
