 ## 解决方案
 ## 问题理解

 我们有两个二进制字符串。 操作选择任何相邻的位对。 如果该对是`(x, y)`，我们计算：

 -`p = x xor y`-`q = x or y`然后我们写`p`进入一个位置并且`q`以任一顺序进入另一个位置。 

字符串的长度永远不会改变。 从字符串开始`a`，我们必须确定某些此类操作序列是否可以将其转换为字符串`b`。 

字符串最长可达一百万个字符。 这立即排除了任何尝试模拟转换或搜索可达状态的方法。 即使线性扫描也已经处理了一百万个字符，所以目标复杂度应该是`O(n)`。 

棘手的部分是了解操作保留哪些信息以及可以更改哪些信息。 

第一个不明显的边缘情况是长度不同。 

输入：```
1
11
```输出：```
NO
```每个操作都作用于两个现有位置，并且从不插入或删除字符。 长度是不变的，因此不同长度的字符串永远不能相互转换。 

另一种重要的情况是一个字符串仅包含零。 

输入：```
000
001
```输出：```
NO
```从全零开始，每个相邻对都是`(0,0)`。 该操作产生`(0 xor 0, 0 or 0) = (0,0)`，所以字符串永远不会改变。 仅检查长度的粗心解决方案会错误地回答“是”。 

一个更微妙的情况是：

 输入：```
10
01
```输出：```
YES
```操作于`(1,0)`给出`(1,1)`和`(0,1)`尽可能的输出。 选择第二种排列方式直接产生`01`。 追踪个体精确位置的解决方案将会失败，因为个体可以四处移动。 

另一个边缘情况是：

 输入：```
111
000
```输出：```
NO
```运算虽然可以减少个数，但永远无法消除最后剩下的一个。 至少有一个人的存在`1`事实证明这是关键的不变量。 

## 方法

 暴力方法会将每个固定长度的二进制字符串视为一个状态，并对所有可达状态执行图搜索。 对于一个长度`n`， 有`2^n`可能的字符串。 即使是为了`n = 50`，这个数字已经是天文数字了，实际的极限是`10^6`。 状态空间探索是完全不可能的。 

为了找到更好的解决方案，我们需要了解该操作实际上做了什么。 

考虑所有可能的相邻对：

 | 原创| 异或 | 或 |
 | --- | --- | --- |
 | 00 | 00 0 | 0 |
 | 01 | 1 | 1 |
 | 10 | 10 1 | 1 |
 | 11 | 11 0 | 1 |

 关键的观察是操作后的对包含`1`当且仅当原始对包含`1`。 

为了`00`，结果仍然是`00`。 

为了`01`和`10`，结果变成两位，其值为`{1,1}`。 

为了`11`，结果变为`{0,1}`。 

在每种情况下，一对至少包含一个`1`继续包含至少一个`1`。 一对没有`1`永远不会得到一个。 

这意味着整个字符串永远不会失去其最后的剩余部分`1`，并且全零字符串永远不能创建`1`。 

下一个问题是这是否是唯一的限制。 

假设字符串至少包含一个`1`。 然后我们可以重复使用操作来移动它`1`周围并创建任何所需的零和一排列。 事实上，任何两个长度相同的字符串都至少包含一个`1`是互相可达的。 这是问题背后的关键定理。 

因此，转换问题只剩下两个检查：

 1. 长度必须相等。 
2. 要么两个字符串都至少包含一个`1`，或者两个字符串都不包含`1`。 

这给出了一个简单的线性时间解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(2^n) | O(2^n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取字符串`a`和`b`。 
2. 如果它们的长度不同，则打印`"NO"`。 

该操作永远不会改变位置的数量，因此不可能有不同的长度。 
3. 检查是否`a`至少包含一个`'1'`。 
4. 检查是否`b`至少包含一个`'1'`。 
5. If both checks have the same result, print`"YES"`。 

This covers two situations:

- Both strings are all zeros.
 - Both strings contain at least one`1`。 
6. 否则打印`"NO"`。 

### 为什么它有效

 该操作保留属性“该字符串是否至少包含一个`1`?"。全零字符串永远保持全零，因为对的每个操作`00`产生`00`。 相反，如果一个字符串包含`1`，每个操作都保留至少一个的存在`1`，所以最后的`1`永远不会消失。 

更深层的事实是，一旦一个字符串包含至少一个`1`， 那`1`可以通过字符串传播和移动。 通过重复操作，我们可以将任何非零二进制字符串转换为任何其他相同长度的非零二进制字符串。 因此，在固定长度的字符串中，恰好存在两个连通分量：全零字符串和包含至少一个的所有字符串`1`。 

该算法精确地检查了这些不变量，因此它既是必要的也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a = input().strip()
b = input().strip()

if len(a) != len(b):
    print("NO")
elif ('1' in a) == ('1' in b):
    print("YES")
else:
    print("NO")
```第一个条件处理长度不变的不变量。 

第二个条件检查两个字符串是否属于同一可达性类别。 表达式`('1' in a)`评估为`True`如果字符串包含至少一个一位并且`False`否则。 可达性要求这些值匹配。 

不需要模拟。 整个解决方案基于操作的结构属性。 

一个常见的错误是试图比较数量。 不保留 1 的计数。 例如，`11`可以成为`01`，将计数从 2 减少到 1。 唯一保留的属性是计数是零还是正数。

# helper: run solution on input string, return output string
import sys, io

def solve():
    import sys
    input = sys.stdin.readline

    a = input().strip()
    b = input().strip()

    if len(a) != len(b):
        print("NO")
    elif ('1' in a) == ('1' in b):
        print("YES")
    else:
        print("NO")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out

    solve()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.getvalue().strip()

# provided sample
assert run("11\n10\n") == "YES", "sample 1"

# minimum size
assert run("0\n0\n") == "YES", "single zero"

# minimum size, different classes
assert run("0\n1\n") == "NO", "cannot create a one"

# all-zero strings
assert run("00000\n00000\n") == "YES", "all-zero component"

# same length, both non-zero
assert run("1000\n0001\n") == "YES", "all non-zero strings are connected"

# different lengths
assert run("1\n11\n") == "NO", "length is invariant"

# large-style boundary case
assert run(("1" + "0" * 20) + "\n" + ("0" * 20 + "1") + "\n") == "YES", "non-zero strings"

 ## 边缘情况

 考虑：```
0
0
```该算法首先检查匹配的长度。 两个字符串都没有`'1'`，因此布尔值相等，答案为 YES。 这是正确的，因为零操作已经达到了目标。 

考虑：```
0
1
```长度匹配，但是`'1' in a`是`False`尽管`'1' in b`是`True`。 该算法输出NO。 自从`00 -> 00`是全零字符串中唯一可用的行为，创建一位是不可能的。 

考虑：```
111
000
```两个字符串的长度相等。 第一个包含一个`1`，第二个没有。 该算法输出NO。 每个操作都会保留至少一个的存在`1`，所以最后剩下的一个永远不会消失。 

考虑：```
10
01
```长度匹配并且两个字符串都包含`1`，因此算法输出 YES。 事实上，将该操作应用于该对`(1,0)`并选择安排`(0,1)`直接到达目标。 

这些情况涵盖了唯一重要的属性：长度相等以及是否至少有一个一致`1`存在。
