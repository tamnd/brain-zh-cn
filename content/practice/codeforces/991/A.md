 ## 解决方案
 ## 问题理解

 我们获得有关一组学生在考试后表现如何的汇总统计数据。 每个学生都属于四类中的一类：他们要么只去了 BugDonalds，只去了 BeaverKing，两家餐馆，要么因为考试不及格而呆在家里。 

从输入中，我们得知总共有多少学生访问了 BugDonalds，总共有多少学生访问了 BeaverKing，有多少学生访问了两个地方，以及该组中的学生总数。 任务是检查这些统计数据是否可以来自学生的某些有效分布，如果可以，则计算有多少学生未通过考试并留在家里。 

关键的隐藏结构是餐厅数量不是不相交的。 代表“两家餐厅”的值都计入两个总数中，因此必须仔细重建不同访客的实际数量。 一旦我们知道有多少学生至少去了一家餐馆，其他人一定都是呆在家里的人。 

约束很小，所有值最多为 100，这立即告诉我们，每个测试用例在恒定时间内运行的任何解决方案就足够了。 即使对以 100 为界的四个类别的所有分布进行强力枚举也是可行的，但没有必要。 

微妙的失败案例来自重叠和总数之间的不一致。 一个常见的错误是忘记重叠部分包含在 A 和 B 中，从而导致不可能的负计数或过量计数。 

一些具体的无效场景有助于澄清：

 如果 A = 1、B = 1、C = 1、N = 1，则 A 和 B 都意味着每个餐厅中至少存在一名学生，但重叠会产生矛盾，因为除非仔细对齐，否则单个学生无法同时满足所有计数。 

如果C大于A或B，例如A = 2，B = 2，C = 3，那么这立即是不可能的，因为“两者”不能超过“任一总数”。 

如果 A + B − C 超过 N，那么即使在考虑重叠之前，我们已经需要比小组中现有的学生更多的学生。 

这些不一致是算法必须检测到的。 

## 方法

 强力解释会尝试将 N 个学生中的每一个分配到四个州之一，并检查我们是否可以准确匹配所需的计数 A、B 和 C。 这将涉及将 N 的所有可能的分割迭代为四组并验证约束。 将 N 划分为四个非负整数的方法数量约为 N3，因为固定三个会自动确定第四个。 尽管 N ≤ 100 使得这几乎可以接受，但对于本质上是直接算术重建问题来说，它是不必要的复杂性。 

关键的观察是重叠结构完全决定了分区。 设 x 仅是 BugDonalds，y 仅是 BeaverKing，z 是两家餐厅，w 则呆在家里。 那么 A = x + z，B = y + z，C = z。 这立即给出 x = A − C 和 y = B − C。一旦这些被固定，至少访问过一家餐厅的学生总数为 x + y + z = A + B − C。其余学生为 w = N − (A + B − C)。 

整个问题简化为检查这些导出值是否都是非负整数以及它们的总和是否一致为 N。任何违规都表明不可能输入。

 ## 算法演练

 我们使用代数根据给定的总数重建四个类别，然后验证可行性。

1. 计算去过两家餐厅的学生人数，记为 z = C。这是直接给出的，因此不需要推断。 
2. 计算 x = A − C，即仅访问 BugDonalds 的学生人数。 这将从 BugDonalds 访客总数中删除了两者中的人数。 
3. 计算 y = B − C，即仅访问过 BeaverKing 的学生人数。 这是应用于第二家餐厅的对称推理。 
4. 将至少访问过一家餐厅的学生人数计算为 x + y + z。 这简化为 A + B − C，因为 z 正确抵消。 
5. 计算待在家里的学生人数 w = N − (A + B − C)。 这代表那些考试不及格的人。 
6. 检查有效性条件：x、y、z 和 w 必须均为非负数。 如果有任何一个为负数，则计数与实际情况相矛盾，我们输出 -1。 
7. 如果有效，输出 w 作为不及格的学生人数。 

为什么有效：通过包含-排除强制分解为四个不相交的组。 每个学生都是唯一的分类，并且公式是同时满足两个餐厅总数的唯一方法。 任何对非负性的违反都对应于不可能的重叠结构或总群体规模与重建参与之间的不匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    A, B, C, N = map(int, input().split())

    x = A - C
    y = B - C
    z = C

    if x < 0 or y < 0:
        print(-1)
        return

    total_attended = x + y + z  # equals A + B - C
    w = N - total_attended

    if w < 0:
        print(-1)
        return

    print(w)

if __name__ == "__main__":
    solve()
```实现直接遵循重构的变量。 唯一微妙的一点是确保减法不会默默地产生无效的负计数。 在继续之前，我们明确保护 x 和 y，因为它们代表物理学生计数并且不能为负数。 最终检查确保重建的参加学生不超过小组规模。

 ## 边缘情况

 当 A、B 和 C 均为零且 N 为正数时，算法计算 x = 0、y = 0、z = 0 且total_attended = 0，因此 w = N。这对应于所有学生呆在家里，这是有效的并正确处理，因为没有负检查触发。 

当 C 超过 A 或 B 时，例如 A = 2、B = 1、C = 3，计算结果为 x = -1 或 y = -2。 该算法在计算总数之前立即拒绝这种情况，正确识别重叠不能超过总类别。 

当A + B − C超过N时，例如A = 10，B = 10，C = 0，N = 15，我们得到total_attended = 20，w = -5。 这个负面结果直接表明不可能，反映出重建的出席人数超过了小组规模。
