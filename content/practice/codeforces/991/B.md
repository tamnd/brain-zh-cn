 ## 解决方案

 ## 问题理解

 我们得到一份实验室成绩列表，每个成绩在 2 到 5 之间。课程成绩计算为所有实验室成绩的算术平均值，然后四舍五入到最接近的整数。 舍入规则是标准的“向上舍入”，这意味着 4.5 等值变为 5，而 4.49 变为 4。 

瓦夏可以通过选择一些实验室作品并重做来提高他的期末成绩。 重做会强制实验室成绩变为 5。每次重做都会增加成绩总和，同时保持实验室数量不变，从而提高平均值。 

目标是确定 Vasya 必须重做的最小实验室工作数量，以便舍入平均值变为 5。由于获得最终 5 的舍入阈值达到平均值至少 4.5，因此问题减少为确保升级后平均值至少为 4.5。 

限制很小，最多 100 个等级。 这允许本质上是二次甚至三次的解决方案，但也使贪婪排序策略成为非常自然的候选者。 

当平均值已经接近 4.5 时，就会出现微妙的边缘情况。 例如，如果除了一个 5 之外所有成绩均为 4，则平均值可能已超过 4.5，这意味着无需执行任何操作。 总是试图修改成绩的幼稚方法会错误地增加答案。 

另一个边缘情况是由舍入行为引起的。 由于规则是“向上舍入”，因此条件不是严格大于 4.5，而是大于或等于 4.5。 缺少此阈值会导致在确定当前配置是否足够时出现相差一的错误。 

## 方法

 一种直接的方法是尝试增加成绩的子集。 对于每个可能的重做次数 k，我们可以选择任意 k 个位置，将它们设置为 5，计算新的平均值，并检查它是否达到所需的阈值。 这是正确的，因为它详尽地探索了所有改进的组合。 然而，它太慢了，因为子集的数量随着 n 的增加而组合增长，对于每个 k 大约为 C(n, k) 的数量级，导致指数行为。 

关键的观察结果是，改进较低等级比改进较高等级产生更多效益。 用 5 替换 2 会使总和增加 3，而用 5 替换 4 只会使总和增加 1。由于我们希望以最少的操作达到阈值，因此我们应该始终优先考虑首先升级最小值。 这样排序后问题就变成了贪心选择问题。 

一旦成绩按升序排序，我们就模拟将最小值一一转换为 5。 每次转换后，我们更新总和并检查是否满足平均条件。 满足条件的第一时刻给出最少的操作次数。

 ## 算法演练

 我们将问题转化为检查必须用 5 替换多少个最小元素才能使平均值至少为 4.5。 

1. 计算所有成绩的总和。 这给出了当前的基线平均值。 
2. 按升序对成绩进行排序，以便首先考虑最弱的成绩进行改进。 这是最佳的，因为每次升级在应用于最小值时都会增加最大可能的增益。 
3. 迭代我们决定升级的元素数量，从 0 到 n。 
4. 对于每个 k，通过为 k 个最小元素添加 (5 - a[i]) 来计算新的总和。 
5. 检查new_sum ≥ 4.5 * n 的条件是否成立。 
6.满足条件的最小k即为答案。

关键的决策点是步骤 2。如果不进行排序，我们可能会浪费升级已经很高等级的操作，这会减少每个操作的改进，并且会增加所需重做的次数。 

### 为什么它有效

 该过程取决于单调属性：与替换较大的值相比，替换较小的值总是会产生更大或相同的总和增加。 这意味着任何最佳策略都可以重新排列，以便所有选择的重做都适用于最小的元素，而不会导致结果恶化。 一旦排序，每个升级前缀都代表通过该数量的操作可实现的最佳改进，因此跨过阈值的第一个前缀必须对应于全局最优值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    a = list(map(int, input().split()))
    
    total = sum(a)
    a.sort()
    
    need = 4.5 * n
    
    if total >= need:
        print(0)
        return
    
    for i in range(n):
        total += (5 - a[i])
        if total >= need:
            print(i + 1)
            return

if __name__ == "__main__":
    main()
```解决方案首先读取等级数及其值。 总和计算一次，代表任何修改之前的当前状态。 

对数组进行排序至关重要，因为它可以确保当我们模拟升级时，我们始终首先选择最小的等级，从而最大化每次操作的增益。 

然后我们将阈值计算为 n 的 4.5 倍。 这避免了重复重新计算平均值，并将条件转变为对总和的简单比较。 

该循环逐步应用改进。 每次迭代都会通过将总和增加（5 - 当前等级）来模拟重做一个实验。 一旦达到阈值，我们立即返回所使用的操作数。

 ## 边缘情况

 关键的边缘情况是初始平均值已经超过或等于 4.5。 例如，输入`3, 5 4 5`得出的总和为 14，阈值为 13.5。 该算法会在任何升级之前立即处理此问题，返回 0 而不进入循环。 

另一种情况是所有值都相同且较低，例如`4, 4, 4`。 该算法按顺序处理升级，并且仅在积累了足够的累积增益时才停止。 每一步都会不断改进，循环保证最终的成功。 

最后，最小输入尺寸`n = 1`行为一致。 如果单个等级为 5，则答案为 0。如果低于 5，则恰好升级一次就足够了，因为该值立即变为 5，保证了阈值。
