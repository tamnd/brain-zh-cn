 ## 解决方案
 ## 问题理解

 我们在二维网格上有两个轴对齐的正方形。 每个正方形由其左下角的坐标和边长来描述。 根据该信息，每个正方形占据平面的一个封闭区域：x 坐标位于左边缘和右边缘之间、y 坐标位于下边缘和上边缘之间的所有点。 

任务是确定两个正方形周长是否以任何方式重叠。 重叠的定义是严格的：即使是单点接触也被认为是重叠，包括角落接触。 因此，我们不仅检查内部的交集，还检查边界集的交集，规则是禁止任何共享点。 

每个正方形都可以表示为 x 轴上的一个区间和 y 轴上的一个区间。 第一个正方形的范围是从 x1 到 x1 + s1 以及从 y1 到 y1 + s1。 第二个跨度从 x2 到 x2 + s2 以及从 y2 到 y2 + s2。 因此，几何形状被简化为关于两个轴对齐的矩形（实际上是正方形）的推理。 

约束非常小，坐标以 10^3 为边界，边长最大为 10^3。 这保证了恒定时间计算就足够了。 即使每个点进行简单的几何检查也是可以接受的，但这是不必要的，因为该结构纯粹是基于区间的。 

当正方形仅在一个点或沿着边界线接触时，就会出现一种微妙的情况。 例如，如果一个方块在 x 轴上恰好在另一个方块开始的地方结束，即使它们的 y 范围在单个坐标处重叠，仍然算作重叠。 同样，诸如一个方块的右上角与另一个方块的左下角重合之类的角接触也是无效的。 

## 方法

 强力方法会尝试将每个正方形的周长建模为一组点或线段，然后检查是否有任何线段相交或任何点是共享的。 这需要枚举所有边，然后检查所有线段对之间的交集，或者离散网格并标记所有边界点。 尽管坐标很小，但如果使用浮点几何，这会带来不必要的复杂性和丢失边缘触摸情况的风险。 

关键的观察结果是内部结构是无关紧要的。 当且仅当两个轴对齐的正方形在两个轴上的投影重叠时，它们才会以任何禁止的方式重叠。 如果 x 区间以任何非空方式相交并且 y 区间以任何非空方式相交，则矩形在某处相交。 由于接触算作重叠，因此即使单个共享边界点也足够了，因此我们将间隔视为闭合的。 

这将问题从形状的几何推理减少到一维的区间相交检查。

 ## 算法演练

 1. 将两个正方形的 x 区间计算为 [x1, x1 + s1] 和 [x2, x2 + s2]。 这完全捕获了每个正方形的水平覆盖范围。 
2. 类似于 [y1, y1 + s1] 和 [y2, y2 + s2] 计算 y 区间。 这捕获了垂直覆盖范围。 
3. 检查x 区间是否相交。 对于闭区间，如果 max(左端点) ≤ min(右端点)，则存在交集。 这一条件确保至少共享一个 x 坐标。 
4. 使用相同的逻辑检查 y 区间是否相交。 
5. 如果两个轴投影相交，则正方形至少有一个共同点，因此输出 YES。 否则输出NO。

两个维度必须重叠的原因是，只有当一个点同时满足两个约束时，它才属于两个正方形。 没有共享 y 范围的共享 x 范围对应于垂直分隔的矩形，反之亦然。 

### 为什么它有效

 每个正方形恰好是其 x 区间和 y 区间的笛卡尔积。 当且仅当两个相应区间相交时，两个此类乘积的交集才非空。 此属性确保在区间推理之外不存在几何极端情况。 因为我们将区间视为闭区间，所以边界接触被正确分类为交集。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def intersect(a1, a2, b1, b2):
    return max(a1, b1) <= min(a2, b2)

def solve():
    x1, y1, s1 = map(int, input().split())
    x2, y2, s2 = map(int, input().split())

    x1r, x2r = x1 + s1, x2 + s2
    y1r, y2r = y1 + s1, y2 + s2

    if intersect(x1, x1r, x2, x2r) and intersect(y1, y1r, y2, y2r):
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```该解决方案读取两个正方形，将每个正方形转换为每个轴的两个闭区间，并使用辅助函数来检查区间重叠。 辅助函数对关键几何条件进行紧凑编码，并避免 x 和 y 维度的重复逻辑。 

一个常见的错误是将间隔视为半开，这会错误地拒绝端点接触的情况。 另一个是忘记在重叠条件下应该允许相等，因为这里的接触算作重叠。

 ## 边缘情况

 一个关键的边缘情况是正方形恰好与角接触。 例如，[0,0,1] 和 [1,1,2]。 x 区间为 [0,1] 和 [1,3]，它们恰好相交于 1，y 也类似。 该算法返回 YES，因为 max(0,1) ≤ min(1,3) 成立。 这正确地将单个共享点视为重叠。 

另一种情况是纯边缘接触，例如[0,0,2]和[2,1,3]。 这里 x 间隔在 2 处相交，但 y 间隔不相交，因为 [0,2] 和 [1,3] 重叠； 实际上它们确实重叠，因此这成为从 [1,2] 中的 x=2 和 y 开始的角区域，这是有效的重叠。 区间逻辑自然地捕获了这一点，无需特殊的外壳。 

完全分离的配置（如 [0,0,1] 和 [2,2,1]）会产生不相交的 x 和 y 间隔，因此条件立即失败。 这表明任一轴上的分离足以保证不相交。
