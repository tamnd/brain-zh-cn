 ## 解决方案
 ## 问题理解

 我们得到一个整数长度的集合，每个长度代表一根酸稻草。 从这些中，我们想要选择一个子集，这样当我们以非递减顺序对所选长度进行排序时，每个较小的元素都会除掉它后面的每个较大的元素。 

换句话说，在选定的子集中，如果我们取任意两个元素，较小的元素必须是较大元素的约数。 任务是找到这样一个子集的最大可能大小。 

输入大小最多为 1000 个元素，每个值最大可为 2 × 10^9。 这立即表明，任何具有三次行为的解决方案或任何涉及每对重复因式分解的解决方案都可能是边界性的，但仍然可能是可接受的，而子集上的任何指数形式都是不可能的。 

微妙的边缘情况来自重复的值。 相等的值在一起总是有效，因为任何数字都可以整除。 另一种边缘情况是没有两个数字可以相除，在这种情况下答案就是 1。 

一个天真的错误是认为这是一个经典的最长递增子序列问题，并尝试仅强制执行排序，忽略整除性。 这对于像[2,3,6]这样的情况会失败，在这种情况下，仅排序是不够的，可分结构很重要。 

## 方法

 暴力解释是尝试每个子集并检查它是否满足整除条件。 对于大小为 k 的子集，检查有效性需要检查排序后的所有对或至少所有连续对，即 O(k^2)。 由于有 2^n 个子集，这种方法完全不可行，以 2^1000 的数量级增长。 

一种更结构化的方法是认识到在对数组进行排序后，整除条件变得更加容易。 一旦排序，约束就减少为构建最长的链，其中每个元素都划分下一个元素。 这将问题转化为有向无环图中最长路径的变体，其中如果 i < j 并且 l[j] 可被 l[i] 整除，则边从 i 到 j。 

从这里开始，动态规划就变得自然了。 对于每个元素，我们计算以该元素结束的最长有效链。 为了计算转换，我们只需要考虑按排序顺序划分它的较早元素。 

关键的观察结果是整除性以支持链接的方式传递：如果 a 整除 b 并且 b 整除 c，则 a 整除 c。 排序确保我们只从较小或相等的值扩展到较大的值，这可以防止无效的向后转换。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力子集 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了|
 | 排序数组上的 DP | O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1. 按非降序对长度列表进行排序。 这确保了任何有效的子集都可以被排列，以便仅需要向前检查可分性。 
2. 创建一个 DP 数组，其中 dp[i] 表示有效子集的最大大小，该子集的最大元素位于已排序数组中的位置 i。 
3. 将每个 dp[i] 初始化为 1，因为每个元素单独形成一个有效子集。 
4. 对于从左到右的每个索引 i，考虑所有较早的索引 j < i。 如果 l[i] 可被 l[j] 整除，那么我们可以通过添加 l[i] 来扩展以 j 结尾的任何有效子集。 更新 dp[i] = max(dp[i], dp[j] + 1)。 此步骤构建以 i 结尾的所有有效链。 
5. 答案是所有 dp[i] 的最大值，因为最佳子集可以在任何位置结束。 

它之所以有效，是因为排序不需要考虑子集的排列。 每个有效子集都有一个按排序顺序排列的规范形式，并且 DP 确保考虑每个可能的最后一个元素，同时保留沿转换的可分性约束。 DP 状态完全捕获以每个索引结尾的所有有效链，因此不会错过任何最佳解决方案。

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

a.sort()

dp = [1] * n

for i in range(n):
    for j in range(i):
        if a[i] % a[j] == 0:
            dp[i] = max(dp[i], dp[j] + 1)

print(max(dp))
```该解决方案首先对数组进行排序，以便任何潜在的子集都可以解释为仅需要前向整除检查的递增序列。 dp 数组存储以每个索引结尾的最佳链。 每个转换都会检查当前值是否可以扩展先前的有效链，所有 dp 值的最大值给出最终答案。 

一个常见的微妙之处是处理重复项。 条件`a[i] % a[j] == 0`自然地允许相等的值，因为数字会自行划分，因此重复的数字可以正确地链接在一起。

```排序后的数组变为`[2, 4, 5, 7, 8]`。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    dp = [1] * n
    for i in range(n):
        for j in range(i):
            if a[i] % a[j] == 0:
                dp[i] = max(dp[i], dp[j] + 1)

    return str(max(dp))

 ## 边缘情况

 对于单个元素输入，例如`[42]`，DP数组为`[1]`，结果为 1，因为不存在任何转换。 

为了`[2, 3, 5, 7]`，排序不会创建任何整除关系。 每个 dp[i] 保持 1，因为没有一对满足`a[i] % a[j] == 0`。 输出正确地保持为 1。 

对于像这样的完全可链接的情况`[1, 2, 4, 8]`，排序保持顺序，并且每个元素都会扩展所有先前的元素，因为每个元素都除下一个元素。 DP 构建`[1, 2, 3, 4]`，给出最终答案4。
