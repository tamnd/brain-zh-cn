 ## 解决方案
 ## 问题理解

 我们得到一棵树，每个节点上都有一个值，代表该容器中有多少糖果。 魔术师可以删除边，这会将树分成相连的部分。 每个结果分量被给予一个风扇，并且每个风扇必须接收节点值总和为偶数的分量。 没有任何东西可以被丢弃，因此每个节点在删除后都必须恰好位于一个组件中。 

任务是最大化我们最终可以得到的组件数量，同时尊重每个组件总和的奇偶校验约束。 如果不可能以这种方式划分树，则答案为-1。 

最多 200,000 个节点的约束立即表明任何解决方案都必须接近线性。 对节点或边对的二次方法会太慢，因为即使$O(n \log n)$或者$O(n)$具有多个 DFS 通道是可以接受的，但任何涉及每次切割重新计算或每次边缘移除的全局重新计算的情况都是不可接受的。 

一个微妙的点是我们没有选择任意的节点分区。 我们只能沿着树的边缘进行分割，因此每个组件在某种隐式有根意义上都是一棵子树。 这种结构使得问题可以简化为单个 DFS 计算。 

如果一个人在没有全局平等的情况下贪婪地思考，那么一些边缘情况很容易出错：

 如果所有节点值之和为奇数，例如一行包含三个节点的值$1, 1, 1$，无论如何删除边，每个分量的总和仍将等于所有分量的总和，这是奇数，因此至少有一个分量必须是奇数。 这使得答案为-1。 

当贪婪策略试图在本地子树看起来甚至没有从根角度确保一致性的情况下进行切割时，就会出现另一种失败情况。 像链条一样挂在树上$1 - 2 - 3$有价值观$1, 2, 1$，总和为 4，这是偶数，但如果计算顺序错误，在计算完整子树和之前在节点 2 处不小心进行切割可能会错误地分离无效组件。 

关键的难点在于，一条边是否可以被切断取决于它下面的整个子树的奇偶性，而不仅仅是局部节点值。 

## 方法

 暴力方法会考虑删除所有边缘子集。 每个子集定义一个森林，我们可以计算每个组件的总和并验证所有组件是否都是偶数。 和$n-1$边缘，这给出$2^{n-1}$的可能性，甚至检查每个分区都会花费线性时间，导致$O(n 2^n)$，这是完全不可行的。 

即使是尝试逐步构建组件的稍微更精细的蛮力也会失败，因为切割边缘的决定会影响全局连接性，并且在不重复重新计算子树总和的情况下无法独立评估。 

关键的见解是停止以任意切割的方式思考，而是对树求根并分析子树和。 一旦我们修复了根，每次删除边缘都对应于将子树与其父树分离。 唯一的问题是：子树何时可以有效分离？ 

如果子树的总和为偶数，则它可以单独形成有效分量。 这意味着将其连接到其父级的边缘可以被切割。 如果其总和为奇数，则它必须保持向上附着，否则该组件将违反奇偶校验约束。 

这将问题转化为单个 DFS，其中我们计算子树和模 2 并计算可以分离的子树数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解边缘子集 |$O(n 2^n)$|$O(n)$| 太慢了|
 | DFS子树奇偶分析|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们任意将树作为根，例如在节点 1 处，并使用 DFS 计算子树和。 

1. 从根运行 DFS，并为每个节点计算其子树中的值的总和。 计算是后序完成的，因此子级在父级之前处理。 
2. 在DFS期间，对于每个节点，我们维护其子树的和。 处理完所有子节点后，我们添加节点自己的值。 
3.如果一个节点的子树和是偶数，我们将其标记为“组件的可割根”，这意味着它的整个子树可以与其父边分离。 
4. 我们计算有多少个节点的子树和为偶数。 这些节点与可以与其父节点完全分离的子树完全对应。 
5.我们单独检查根。 如果所有节点的总和（根的子树和）为奇数，则不存在有效分区，我们返回 -1。 
6. 否则，答案是子树和为偶数的节点的数量。 

微妙之处在于，每次我们在子树和为偶数的节点上方切割一条边时，我们都会创建一个新组件，并且这些切割是独立的，因为它们对应于不相交的子树。 

### 为什么它有效

 DFS 强制每个子树总和都在一致的层次结构上计算。 任何有效的最终组件必须对应于其边界是切边的子树。 当子树和为偶数时，这种切割是有效的，因为这保证了树的剩余部分也保持全局奇偶校验一致性。 由于切割仅在子树边界处进行，因此不会有两个选定的切割发生干扰，并且每个偶数子树都恰好产生一个附加组件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n = int(input())
a = list(map(int, input().split()))

g = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

even_subtree = 0
total = 0

def dfs(v, p):
    global even_subtree
    s = a[v]
    for to in g[v]:
        if to == p:
            continue
        s += dfs(to, v)
    if s % 2 == 0:
        even_subtree += 1
    return s

total = dfs(0, -1)

if total % 2 == 1:
    print(-1)
else:
    print(even_subtree)
```DFS 以后序方式计算子树总和，确保每个节点在做出奇偶校验决策之前聚合所有后代的值。 全球柜台`even_subtree`跟踪有多少节点可以充当可拆卸组件的根。 

如果根的子树和是偶数，则根自然包括在该计数中，但它不对应于切边。 这是一致的，因为它在最终计数中只贡献了一个组成部分，而不是削减。 

增加递归限制以避免链形树的堆栈溢出。

 ## 边缘情况

 完全奇数配置（例如三个节点，每个节点的值为 1）演示了总和必须为偶数的全局约束。 DFS 仍然正确计算子树和，但根处的最终奇偶校验会触发 -1 输出。 

单节点树测试实现是否正确地将根视为有效组件而不需要任何边。 如果该值为偶数，则子树之和为偶数，答案为 1，这符合整棵树是一个有效组件的事实。 

深链测试递归稳定性并确认子树积累与树分支结构无关。 每个节点的子树总和都是通过从叶子向上的线性传播来计算的，确保中间切割决策不会干扰正确性。
