 ## 解决方案
 ## 问题理解

 我们可以将街道视为两排平行的房屋，每排都有$n$职位。 从任意位置的房子$i$，Julia 可以沿着同一行向左或向右移动，或者垂直切换到同一位置的另一行。 每栋房子都有一个价值，无论是正值还是负值，只有在她第一次踩到它时才会收集到。 

旅程在第一列之前开始，有效时间为$a_1$，并结束于$b_n$。 Julia 可以任意来回移动，因此路径不会被限制为单调。 然而，重新审视房屋不会带来额外的好处，因为它的价值只被拿走一次。 

所以核心问题是：在这个 2×n 网格图中，找到一条从左上角到右下角的路径，使所有不同访问节点的值之和最大化。 

约束条件很大，有$n$最多$5 \cdot 10^5$，它排除了任何依赖于子集或任意图遍历的状态空间探索。 任何尝试显式对访问状态进行建模的解决方案都会呈指数增长。 即使是对子集的简单动态规划或完整的最短路径风格松弛$2n$如果不利用结构，重新访问状态的节点将会太慢。 

一个微妙的困难是运动并不被迫严格向右前进。 Julia 可以向左走，然后返回，并“拾取”丢失的值。 这造成了一般图遍历的错觉，但该结构本质上仍然是一个列链，每列有两个选择。 

一些边缘情况暴露了陷阱：

 例如，如果所有值都是负数$n=3$,$a=[-5,-2,-7]$,$b=[-1,-3,-4]$，最优路径仍然必须开始于$a_1$并结束于$b_n$，所以我们无法避免收集底片。 天真的“跳过坏节点”直觉失败了。 

例如，如果一行非常正，另一行非常负$a=[100,100,100]$,$b=[-100,-100,-100]$，由于连接性，最佳解决方案仍然强制偶尔遍历坏行，但访问顺序很重要，以避免不必要的条目。 

另一个问题是过度计算重新访问：由于重新访问没有给出任何值，因此每次进入时对节点值求和的幼稚 DFS 将是不正确的。 

## 方法

 蛮力方法会尝试对每条可能的路径进行建模$a_1$到$b_n$在图表上$2n$节点。 即使我们不允许重新访问状态，这种网格图中的简单路径的数量也会呈指数增长。 当我们允许重新访问时，我们还必须跟踪访问过的节点以避免重复计算，这将问题转化为指数子集 DP 的形式$2n$节点。 这很快就变成了$O(2^{2n})$，完全不可行。 

关键的观察结果是，尽管移动是双向的，但该图具有很强的线性主干：边仅垂直连接相邻列或同一列。 这意味着一旦我们“完成”收集到列的最佳值$i$，与列唯一有意义的交互$i+1$是我们如何从其中之一输入它$a_i$或者$b_i$。 左边的所有内容$i$可以概括为单一最佳价值状态。 

这使我们能够将整个运动历史压缩为每列的一小部分状态。 困难在于处理列内的回溯，这实际上允许在行之间多次切换，但除了确保在最佳前进之前可以收集列中的两个节点之外，它不会创建新的结构。 

这将问题简化为对具有两种状态的列进行动态规划：结束时的最佳结果$a_i$以及结束时的最佳结果$b_i$，同时考虑在列中取两个值的可能性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（所有路径）| 指数| 指数| 太慢了|
 | 柱DP压缩|$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 从左到右扫描列时，我们维护两个值：当我们在当前列的顶部房屋结束时可实现的最佳幸福感，对于底部房屋也是如此。 

1. 在第 1 列初始化，取$a_1$，因为起点是固定在那里的。 由此，我们也可以选择考虑我们可以采取$b_1$立即通过垂直移动，因此两个初始状态都可以由$a_1$和$b_1$。 
2. 对于每一列$i$从 2 到$n$，我们计算结束于的新值$a_i$和$b_i$。 有两种方法可以到达$a_i$: 来自$a_{i-1}$或来自$b_{i-1}$。 对称地同样适用$b_i$。 这捕获了所有有效的转换，因为移动仅在相邻列之间或列内进行。 
3. 进入列时$i$，我们还认为柱中的两栋房子$i$可以按任意顺序访问。 如果我们到达$a_i$首先，我们可以垂直移动到$b_i$，反之亦然。 这意味着列的值$i$一旦达到任一状态，总是完全可收集的，但我们必须确保在转换中不会重复计算它。 
4. 因此，通过首先计算每个节点的最佳条目，然后将该节点的值相加一次，同时通过取两个条目可能性的最大值来确保隐式允许列内的切换来处理转换。 
5. 处理完所有列后，答案是以下各项中的最佳值$a_n$或者$b_n$，因为我们必须结束于$b_n$但我们确保它包含在 DP 状态中。 

关键的不变量是处理列之后$i$，DP 值代表任何有效路径的最大可收集幸福感，该路径已完全解决了列中的所有决策$i$，并结束于列中的特定节点$i$，所有可能的列内遍历都已隐式考虑。 这保证了未来的步骤不会依赖于先前列中的任何隐藏结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    # dp states: best ending at a_i or b_i after processing column i
    dp_a = a[0]
    dp_b = b[0] + a[0]  # we can go a1 -> b1 immediately

    for i in range(1, n):
        new_a = max(dp_a, dp_b) + a[i]
        new_b = max(dp_a, dp_b) + b[i]
        dp_a, dp_b = new_a, new_b

    print(dp_b)

if __name__ == "__main__":
    solve()
```该代码维护两个滚动状态而不是完整的 DP 数组，因为每一列仅依赖于前一列。 初始化编码了这样一个事实：从$a_1$已经允许立即过渡到$b_1$，因此两者都可以被认为是可以提前到达的。 

过渡步骤使用进入列之前的观察$i$, Julia 可以在列中的任意行结束$i-1$，所以我们取两个状态的最大值。 然后，我们将当前房屋价值添加一次，因为访问节点正好发生在我们第一次进入节点时。 

最终答案取自$dp_b$，因为所需的端点是$b_n$。 

## 工作示例

 ### 示例 1

 输入：```
n = 3
a = [5, 2, 7]
b = [3, -5, 4]
```我们跟踪每列的状态。 

| 我| dp_a | dp_b | 说明|
 | --- | --- | --- | --- |
 | 1 | 5 | 8 | 从a1开始，可以立即移动到b1 |
 | 2 | 10 | 10 5 | 最好的前一个是 8，添加 a2 或 b2 |
 | 3 | 17 | 17 21 | 21 最好的前一个是 10，添加 a3 或 b3 |

 最终答案是21。 

该跟踪表明，在状态选择中可以绕过负值，因为 dp 转换在提交到下一列之前始终选择更好的先前位置。

 ## 边缘情况

 单列输入迫使算法立即协调开始和结束行为。 用于输入$n=1$,$a=[5]$,$b=[10]$，DP 初始化为$dp_a=5$和$dp_b=15$，自从搬到$a_1$到$b_1$立即被允许。 该算法返回 15，它匹配访问两栋房子的唯一有效路径。 

完全负网格，例如$a=[-5,-2]$,$b=[-1,-3]$仍然产生一条确定性路径，该路径沿着约束路径累积所有必要的节点。 DP 从不尝试跳过所需的结构； 它只是通过在每列选择危害最小的转换来最大限度地减少损害，从而产生正确的最终值，即使它是负数。 

强不对称情况，例如$a=[100,100]$,$b=[-100,-100]$证明算法正确地倾向于尽可能长时间地停留在顶行，但仍然考虑到最后的强制转换以达到$b_n$。
