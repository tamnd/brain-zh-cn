 ## 解决方案
 ## 问题理解

 我们有一个管孔系统，每个孔都有固定的尺寸，决定了当水倒入系统时可以排出多少水。 阿尔卡季倒了固定数量的水，但只有一个洞，即第一个洞，被认为对他有用。 他的目标是确保至少有所需量的水最终通过第一个孔流出。 

他的关键控制能力是他可以在倒水之前堵住任何一个洞。 堵塞后，剩余的开孔按其大小按比例分享水。 如果开孔的总尺寸为$S$，那么第一个孔收到一个分数$s_1 / S$占总水量的$A$，所以它的输出是$A \cdot s_1 / S$。 

任务是最小化有多少个孔被阻塞，以便第一个孔至少接收到$B$水的单位。 

这些限制迫使我们采用贪婪或基于排序的解决方案。 和$n$最多$10^5$，任何尝试所有孔子集的方法都是不可能的。 甚至迭代所有$2^n$可能性是不可能的，如果天真地这样做，即使通过重新计算检查每个可能的删除数量也会太慢。 

一个微妙的点是，去除孔只会影响分母$S$，不是分子$s_1$。 这会产生单调效应：移除孔总是会增加第一个孔的份额。 

一些边缘情况很容易被忽略。 

如果没有堵住任何洞，可能已经足够了。 例如，如果$s_1$与所有大小的总和相比较大，则条件立即成立且答案为零。 

如果所有其他孔与$s_1$，那么满足条件的唯一方法就是删除除第一个孔之外的几乎所有内容。 在极端情况下，答案变成$n-1$。 

第三种微妙的情况是多个孔具有相同的尺寸。 由于只有总和才重要，而不是同一性，因此该决策仅取决于消除分母的最大贡献者。 

## 方法

 一个蛮力的想法是尝试阻止所有漏洞子集。 对于每个子集，计算剩余总和$S$，并检查是否$A \cdot s_1 / S \ge B$。 这将需要迭代所有子集并对剩余元素求和，这会导致$O(n \cdot 2^n)$行为。 和$n = 10^5$，这是完全不可行的。 

重写条件可以得到更结构化的视图：$$\frac{A \cdot s_1}{S} \ge B \quad \Rightarrow \quad S \le \frac{A \cdot s_1}{B}$$因此，我们不考虑直接最大化第一个洞的份额，而是考虑减少总剩余金额$S$。 第一个孔的大小是固定的，因此我们希望使剩余孔的总和尽可能小，同时堵塞尽可能少的孔。 

这给出了一个贪心方向：为了最快地减少总和，我们应该首先删除最大的洞。 每个移除的孔都会减少$S$每次移除尽可能多。 因此，按降序对孔（不包括第一个）进行排序并逐步删除它们给出了最佳策略。 

我们模拟将最大的尺寸一一移除，直到满足条件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（所有子集）|$O(2^n \cdot n)$|$O(n)$| 太慢了 |
 | 排序+贪心去除|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 计算所有孔尺寸的总和。 这代表任何删除之前的分母。 
2. 单独提取第一个孔的尺寸，因为它永远不会被删除。 
3. 在不删除任何内容的情况下检查条件是否已满足。 如果$A \cdot s_1 \ge B \cdot S$，立即返回0。 
4. 将所有其他孔尺寸收集到列表中，因为只有它们才是要移除的候选对象。 
5. 按降序排列此列表，以便首先考虑对分母的最大贡献。 
6. 迭代排序列表，一次删除一个洞：

 1. 从总和中减去其大小。 
2. 增加移除次数。 
3. 检查是否不等式$A \cdot s_1 \ge B \cdot S$现在成立。 

如果成立，则停止并返回移除的孔的数量。 

排序背后的原因是，每次删除都会减少分母，并且当我们只关心达到阈值时，减少较大的量总是至少与减少较小的量一样好。 

### 为什么它有效

 关键的不变量是，在任何时刻，在所有相同大小的孔组中（相同的移除次数），移除最大的可用孔可以最小化剩余的总和$S$。 由于条件仅取决于是否$S$低于固定阈值，以最少的移除达到该阈值相当于始终最大化减少$S$在每一步。 Any deviation from removing the largest remaining element can only leave a larger sum after the same number of removals, which cannot help satisfy the inequality earlier.

 ## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, A, B = map(int, input().split())
    s = list(map(int, input().split()))
    
    s1 = s[0]
    total = sum(s)
    
    if A * s1 >= B * total:
        print(0)
        return
    
    rest = s[1:]
    rest.sort(reverse=True)
    
    removed = 0
    for x in rest:
        total -= x
        removed += 1
        if A * s1 >= B * total:
            print(removed)
            return

if __name__ == "__main__":
    solve()
```该代码直接遵循导出的不等式，通过条件交叉相乘来避免浮点除法。 这可以防止精度问题。 

排序步骤确保每次迭代产生每个删除元素的总和的最大可能减少。 一旦条件满足，循环就会立即停止，因此我们永远不会删除不必要的洞。 

一个常见的陷阱是意外地将第一个洞包含在已排序的删除列表中。 这将错误地允许删除我们所依赖的分子元素。

 ## 边缘情况

 当只有一个洞时，分母永远不会改变，答案始终为零。 该算法会处理此问题，因为删除列表为空，并且早期条件检查会立即决定结果。 

当除第一个之外的所有孔都非常大时，算法会按降序删除它们，从而快速缩小分母。 每次删除都是必不可少的，循环自然会准确计算需要多少个孔，直到只剩下第一个孔或达到阈值。 

当初始配置已经满足不等式时，不会有效地使用排序或删除，因为早期检查立即终止。
