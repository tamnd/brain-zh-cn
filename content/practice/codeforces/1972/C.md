 ## 解决方案
 ## 问题理解

 我们有一组多张卡片，每张卡片都标有从 1 到$n$，并且对于每种类型$i$我们知道有多少张牌$a_i$我们已经拥有了。 我们还有$k$金币可以购买额外的卡，并且商店每种类型的供应量都是无限的。 购买卡片后，我们可以将所有卡片排成一行。 目标是最大化长度连续子数组的数量$n$这是一个排列$[1, 2, \ldots, n]$。 每个测试用例的输出就是这个最大可能计数。 

关键的挑战是$n$可以达到$2 \cdot 10^5$和$a_i$和$k$可以大到$10^{12}$。 任何尝试生成所有子数组或显式模拟排列的解决方案都会太慢。 这些限制促使我们采用不需要构建完整数组的数学或贪婪方法。 我们还需要有效地处理多个测试用例，其中总计$n$所有测试最多是$5 \cdot 10^5$。 

当出现不明显的边缘情况时$k$足够大以平衡所有牌张数或当某些牌张数极度不平衡时。 例如，如果$n = 3$,$k = 5$，初始计数为$[1, 1, 1]$，那么我们可以再添加五张牌。 最佳策略是平衡计数，使每个数字出现的频率相同，因为每个完整的集合$n$卡贡献一种排列。 仅查看现有计数或将所有硬币添加到当前最小卡类型的简单解决方案可能会低估最大分数。 

## 方法

 暴力法是模拟所有可能的卡片添加和重新排列，然后计算长度-$n$结果数组中的排列。 这在原则上是正确的，但变得不切实际，因为数组大小可能超过$10^{12}$，并且生成所有子数组是不可行的。 即使是单个测试用例的操作次数也会非常巨大。 

关键的见解是，排列的数量受到分配硬币后副本最少的卡类型的限制。 每个排列都需要每种卡片类型中的一张，因此分数由所有卡片类型的最小计数决定。 因此，最佳策略是使用硬币尽可能均衡卡牌数量，优先考虑卡牌较少的类型。 这将问题转化为“最大化最小”问题：我们想要最大的整数$x$这样，在添加硬币后，每种卡类型至少有$x$副本。 我们可以使用贪心方法或二分搜索有效地解决这个问题，因为函数“是否可以实现$x$所有类型的副本？”是单调的$x$。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 蛮力 | O(卡片总数 × n) | O(卡片总数) | 太慢了|
 | 最佳 | O(n log(max_a + k)) | O(n log(max_a + k)) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$,$k$，以及初始计数$a_1, a_2, \ldots, a_n$。 这些代表我们最初拥有的每种类型的卡片数量。 
2. 对计数数组进行排序。 这使我们能够有效地计算需要多少硬币才能使所有较小的计数达到目标水平。 
3. 对目标最小副本数使用二分查找，$x$，跨越所有类型。 初始化搜索，下限为 0，上限为$\max(a) + k + 1$，这是如果我们将所有硬币都花在一种类型上可实现的最大计数。 
4. 对于候选人$x$，计算需要多少硬币才能使所有计数小于$x$最多$x$。 这只是所有的总和$i$的$\max(0, x - a_i)$。 
5. 如果所需金币数量超过$k$， 然后$x$太高了，我们调整二分查找上限。 否则，$x$是可以实现的，我们调整下限。 
6. 继续二分查找直至收敛。 最大可实现$x$是最终的下界。 
7.一次$x$确定后，最高分是所有计数之和减去$x \cdot (n-1)$越过卡片线。 更简单地说，因为每种排列使用每种类型一张牌，所以完整排列的总数恰好是加硬币后所有类型中的最小数量。 

为什么有效：最小计数卡类型总是限制我们可以形成的完整排列的数量。 通过确保所有类型至少有$x$副本，我们保证准确无误$x$可以形成完整的排列。 任何重新排列都不能产生比我们拥有所有可用卡类型的次数更多的排列，因此这种贪婪/二分搜索方法是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_permutations(n, k, a):
    a.sort()
    left, right = 0, max(a) + k + 1
    while left < right:
        mid = (left + right) // 2
        required = sum(max(0, mid - count) for count in a)
        if required <= k:
            left = mid + 1
        else:
            right = mid
    # left overshoots by 1
    return left - 1

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    print(max_permutations(n, k, a))
```代码首先对卡片计数进行排序，这确保了在计算达到候选最小值所需的硬币时，我们只需要一次通过。 二分搜索有效地缩小了可实现的最大最小计数以及候选者的赤字总和$x$决定可行性。 边缘情况，例如非常大的情况$k$或统一的初始计数，都是自然处理的，因为二分搜索将探索正确的可实现范围。

 输入：`1 10 1`（1种，10枚金币，初始1张卡）

**样本2：**

 输入：`2 4 8 4`（2 种，4 个硬币，计数 [8,4]）

 二分搜索的目标是提高较小的计数以匹配较大的计数，需要 4 个硬币，从而实现计数 [8,8]。 最小值为 8，但长度序列中完整排列的总数$n=2$是 8。这表明算法以最佳方式平衡计数。
