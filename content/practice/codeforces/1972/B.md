 ## 解决方案
 ## 问题理解

 我们得到了圆形排列的硬币。 每枚硬币要么面朝上，要么面朝下。 两名玩家轮流轮流，每轮一名玩家必须挑选一枚当前朝上的硬币，将其取出，然后翻转它的两个相邻硬币。 随着硬币的移除，圆圈会缩小，邻接结构会动态变化。 

如果玩家要移动并且没有可用的面朝上的硬币，那么他们会立即失败。 游戏总是会结束，因为每一步都会减少硬币的数量。 

任务是决定，对于每个初始配置，假设双方都表现完美，第一个玩家是否可以强行获胜。 

限制很小，每个测​​试用例最多 100 个硬币。 这使我们能够考虑对游戏的结构属性进行推理的策略，而不是需要对大状态进行大量计算或搜索。 完整的博弈树模拟在理论上是可能的，但很快就变得不可行，因为每次移动都会在所有当前有效的“向上”位置上分支，并且状态空间呈指数增长。 

当硬币很少时，就会出现微妙的边缘情况，尤其是$n \le 3$。 在这种情况下，翻转规则会退化，因为移除一枚硬币可以将同一枚硬币翻转两次或消除所有邻接效应。 假设稳定的三邻居结构的简单模拟会为这些小情况产生不正确的转换。 

## 方法

 暴力解决方案会将整个游戏模拟为所有可达配置上的递归极小极大过程。 每个状态由当前循环二进制字符串和要移动的玩家定义。 从每个状态，我们尝试所有可能的向上硬币移除并递归计算结果配置的结果。 这种方法是正确的，因为它直接对游戏定义进行编码，但它太慢了，因为状态数量呈指数增长$n$，甚至对于$n = 100$，可达到的配置数量是天文数字。 

关键的观察结果是，除了简单的结构性平价效应之外，游戏对上硬币的确切位置并不敏感。 每一步都会移除一枚面朝上的硬币并翻转两个邻居，这有效地切换了局部奇偶校验并在圆圈周围转移“活动”。 这种类型的操作是公正游戏的特征，其中只有活动元素数量的奇偶性很重要，而不是它们的确切排列。 

决定性的简化是，获胜者仅取决于向上硬币的数量是奇数还是偶数，对于最初不可能移动的情况进行小修正。 如果开始时没有硬币，则第一个玩家立即失败。 否则，当且仅当向上的硬币数为奇数时，第一个玩家总是可以强行获胜。 

这是有效的，因为每次移动都会恰好移除一枚硬币，并在翻转后保留剩余活动集的奇偶校验结构。 翻转不会以对手可以控制的方式改变向上硬币总数的平价，因此游戏简化为平价游戏。

 ## 算法演练

 1.读取测试用例的数量并独立处理每个配置。 每个配置都是独立的，因为测试用例之间没有交互。 
2. 数一下当前有多少枚正面朝上的硬币。 这是对确定结果唯一重要的状态变量。 
3. 如果硬币数为零，则第一个玩家无法采取行动并立即失败。 这是一个被迫失败的位置。 
4、否则，检查上币数量的奇偶性。 如果是奇数，则第一个玩家获胜； 如果是偶数，则第二个玩家获胜。 
5. 输出每个测试用例的结果。 

这种方法有效的原因是，每次移动都会删除一枚向上的硬币，并且翻转操作不允许玩家以打破此不变量的方式改变“有效活动集”的奇偶性。 游戏简化为交替移除有效的活跃单位，并且当第一个玩家在这个交替过程以对他们有利的位置开始时就获胜。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input().strip())
    s = input().strip()

    ups = s.count('U')

    if ups == 0:
        print("NO")
    elif ups % 2 == 1:
        print("YES")
    else:
        print("NO")
```实现直接遵循导出的不变量。 我们只计算向上硬币的数量并应用奇偶校验。 每个测试用例都会读取该字符串一次，并且计数与其长度呈线性关系。 

一个常见的实现陷阱是在读取字符串时忘记去除换行符或意外错误地读取多行。 另一个微妙的问题是假设圆形结构需要显式建模，但一旦确定了不变量，这些都不再是必要的。

 ## 边缘情况

 对于单个代币来说，行为完全取决于它是上涨还是下跌。 如果下降，则第一个玩家无法移动并立即失败。 如果它出现了，他们就会将其移除，游戏立即以对他们有利的方式结束。 奇偶校验规则正确匹配这两种情况。 

对于所有硬币上涨，每一步都会移除一枚活跃硬币，同时翻转邻居，但奇偶性仍然是决定因素。 如果计数为奇数，则先行者始终保留最后一步的优势。 

对于像 UUDD 这样的交替配置，存在有效的移动，但翻转的结构不会改变平价结果，因此第二个玩家在最佳游戏下获胜。
