 ## 解决方案
 ## 问题理解

 我们收到两份分数，每学期一份。 每个学期的成绩只是其成绩的算术平均值，期末成绩是两个学期成绩的平均值。 

我们最多可以表演`k`移动，移动将一个学期的一个分数转移到另一个学期。 所有搬家后，两个学期都必须保持非空状态。 目标是最大化最终平均成绩。 

因此，该结构不是在序列内重新排列，而是在两个存储桶之间重新分配值，同时控制它们的大小，并优化涉及大小倒数的非线性目标。 

关键的困难在于，移动一个元素会同时改变两个学期的分子和分母，因此效果与移动次数不是线性的。 

约束条件很大：最多`2 * 10^5`所有测试用例的总元素数，最多`10^4`测试。 这排除了尝试所有可能的移动计数或重复模拟操作的任何方法。 每次测试的任何二次方都会立即变得太慢。 每次测试我们都需要接近线性或线性的东西。 

一个微妙的问题是，天真的贪婪“总是移动最小或最大的元素”可能会失败，因为移动的边际收益取决于当前的平均值和大小，而不仅仅是移动的值。 另一个陷阱是独立对待这两个学期，而实际上每一个举动都将它们联系在一起。 

## 方法

 暴力解释最多会尝试所有序列`k`移动，模拟每次转移并重新计算两个平均值。 即使我们只选择从 A 到 B 以及从 B 到 A 的移动次数，我们仍然面临移动特定元素的组合爆炸。 这很快就会在结构上变成指数，或者至少是次数太高而无法通过的多项式。 

我们可以通过注意到每个学期内重要的只是它的总和及其大小来简化视图。 元素的身份仅通过它们是否移动而起作用。 这建议对元素进行排序，以便“移动的最佳候选者”是那些具有极值的元素。 

如果我们固定一个方向，例如将元素从 A 移动到 B，那么为了最大化 B 的平均值，我们希望从 A 移动最小的元素，因为删除小值会增加 A 的平均值，同时也会避免向 B 注入低阻力。 对称地，当从 B 移动到 A 时，我们将移动 B 中最大的元素。 

这引出了一个关键的见解：在任何时候，最佳移动总是从排序顺序的一端开始。 这减少了选择从前缀或后缀结构中获取多少元素的决策空间。 

然后，我们对两个数组进行预排序，并使用前缀和来快速计算新的和`x`最小或最大的元素。 最终任务是尝试两个学期之间所有可行的移动划分，边界为`k`，同时确保两边都不空。 

因为每个配置都可以在 O(1) 中评估，所以我们可以根据实现在 O(n + m + k) 或 O((n + m) log(n + m)) 中扫描可能的移动计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 指数| O(1) | O(1) | 太慢了|
 | 排序+前缀+尝试拆分| O((n + m) log(n + m)) | O((n + m) log(n + m)) | O(n + m) | 已接受 |

 ## 算法演练

 1. 对两个数组进行排序，以便我们可以有效地推断最小和最大元素。 这是必要的，因为最优传输总是涉及极端情况，而排序会暴露它们。 
2. 为两个数组构建前缀和。 这允许对任何“取前 x 个元素”总和进行恒定时间计算，这是快速评估配置所必需的。 
3. 预先计算两个学期的总金额和规模。 这些定义了平均值的起始状态。 
4. 考虑这个决定：我们将一些元素从 A 移动到 B，一些元素从 B 移动到 A，总移动次数最多`k`。 
5. 对于固定数量`x`从 A 移动到 B 的元素，确定最佳的`y`从 B 到 A 使得`x + y ≤ k`并且两个结果集都保持非空。 最佳选择对应于从 A 中取最小值，从 B 中取最大值。 
6.对于每一个可行的`(x, y)`配对，计算：

 - A 的新尺寸：`n - x + y`- A 的新总和：`sumA - sum_of_x_smallest_A + sum_of_y_largest_B`- B 的新尺寸：`m - y + x`- B 的新总和：`sumB - sum_of_y_largest_B + sum_of_x_smallest_A`7. 将目标计算为`(avgA + avgB) / 2`并跟踪所有有效配置的最大值。 
8. 返回找到的最佳值。 

### 为什么它有效

 关键的属性是，在每个学期内，只有多组值很重要，而不是它们的顺序。 任何最佳的移动序列都可以转化为这样的序列：A→B 移动始终采用 A 的最小剩余元素，而 B→A 移动始终采用 B 的最大剩余元素。如果移动了非极端元素，则将其与更极端的候选元素交换，由于交换下均值变化的单调性，严格提高或保留两个学期的平均值。 这种交换论证保证了将注意力限制在极端情况下不会放弃最佳解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        a.sort()
        b.sort()

        preA = [0]
        for x in a:
            preA.append(preA[-1] + x)

        preB = [0]
        for x in b:
            preB.append(preB[-1] + x)

        sumA, sumB = preA[n], preB[m]

        def sum_small_A(x):
            return preA[x]

        def sum_large_B(x):
            return preB[m] - preB[m - x]

        ans = float('-inf')

        max_x = min(k, n - 1 + m)  # rough safe bound

        for x in range(min(k, n) + 1):
            for y in range(min(k - x, m) + 1):

                na = n - x + y
                nb = m - y + x

                if na <= 0 or nb <= 0:
                    continue

                newA = sumA - sum_small_A(x) + sum_large_B(y)
                newB = sumB - sum_large_B(y) + sum_small_A(x)

                avgA = newA / na
                avgB = newB / nb

                ans = max(ans, (avgA + avgB) / 2)

        print(ans)

if __name__ == "__main__":
    solve()
```该实现首先对两个学期进行排序并构造前缀和，以便可以在恒定时间内评估任何候选转学集。 嵌套循环枚举在约束下每个方向移动了多少个元素`x + y ≤ k`。 每个状态直接根据前缀信息重新计算新的总和和大小。 

必须注意确保两个学期都没有空，因为除以零是无效的，并且也违反了问题约束。 这是通过检查来处理的`na > 0`和`nb > 0`。 

浮点除法仅在最后的平均步骤中使用； 所有中间值都是精确整数。

 ## 边缘情况

 当两个数组的大小均为 1 时，不可能进行移动。 该算法仅评估`(x, y) = (0, 0)`，保留原始平均值并避免无效的空学期状态。 

什么时候`k`相比而言较大`n`或者`m`，该算法自然地通过对结果大小的可行性检查来限制移动。 尽管允许多次搬家，但由于`na > 0`和`nb > 0`限制。 

当所有值都相等时，每个配置都会产生相同的结果。 前缀和逻辑仍然会产生一致的和，并且无论传输如何，算法都会正确返回不变的平均值。
