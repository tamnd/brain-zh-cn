 ## 解决方案
 ## 问题理解

 我们正在追踪一个人检查时钟的一系列时刻。 每次检查发生的时间由重复确定，从初始延迟开始，然后根据先前的检查时间和步数的小周期函数进行演变。 

在每次检查时，我们不关心完整的时间戳。 我们只关心时钟显示的内容，即当前时间模数$m$。 如果显示的值最多为$x$，我们将其视为“休息”。 恰好之后$n$进行此类检查后，进程就会停止，并且我们必须报告发生了多少次中断。 

关键的难点在于，下一次检查时间取决于之前的完整时间，但决策仅取决于时间模$m$。 这立即表明我们应该尝试跟踪模算术中的所有内容而不是绝对值，因为原始时间无限增长并且可以达到极大的值。 

这些约束使得所有的暴力模拟$n$步骤不可能时$n$很大，因此递归的结构必须包含强重复或周期性。 另一个微妙的点是更新规则取决于$i \bmod c$，它引入了一个与模相互作用的小重复模式$m$状态。 

简单的模拟将直接根据前一次计算下一次。 这在逻辑上是正确的，但是当$n$很大，因为它需要最多$10^9$过渡。 

粗心优化的一个常见失败案例是尝试仅减少模数重复率$m$不了解全职时间如何与模数相互作用。 递归混合乘法$m-1$具有小的加性扰动，并且缺少符号翻转效果会导致不正确的转换。 

例如，如果人们错误地假设只有$z_i \bmod m$需要并尝试将其更新为$(m-1)z_i \bmod m = z_i \bmod m$，他们失去了本质的否定行为模$m$，这完全改变了顺序。 

## 方法

 直接模拟保持全时间$z_i$。 每个步骤都适用$$z_{i+1} = (m-1)z_i + a(i \bmod c)^2.$$这显然适用于小型$n$，但值$z_i$生长速度极快，甚至存储它们也变得不必要，因为只有$z_i \bmod m$计算休息时间很重要。 

关键的观察结果是，在模数下，转换大大简化了$m$。 自从$m-1 \equiv -1 \pmod m$，我们得到：$$z_{i+1} \bmod m = (-z_i + a(i \bmod c)^2) \bmod m.$$所以如果我们定义$t_i = z_i \bmod m$，该过程变成纯粹基于残差的递归：$$t_{i+1} = (a(i \bmod c)^2 - t_i) \bmod m.$$这是具有交替符号的线性递推，由周期的周期性外项驱动$c$。 符号翻转是关键结构：它意味着状态在“翻转和添加一个小值”之间交替。 

为了消除交替符号，我们将序列分为偶数索引和奇数索引。 如果我们应用递归两次，符号就会取消：$$t_{i+2} = t_i + (f_{i+1} - f_i) \bmod m,$$在哪里$f_i = a(i \bmod c)^2$。 

现在，每个奇偶校验类别都成为一个纯加法过程。 增量仅取决于$i \bmod c$，所以它会重复每个$c$步骤。 这使得序列具有周期性，周期最多$2c$。 自从$c \le 1000$，我们可以显式计算一个完整周期的长度$2c$，然后重复此操作以覆盖所有$n$步骤。 

一旦我们知道一个时期内的值，计算间隔就减少为计算这些值中有多少个$\le x$，乘以适合的完整周期数$n$，加上余数。

 | --- | --- | --- | --- |
 | 暴力模拟|$O(n)$|$O(1)$| 太慢了|
 | 定期减量|$O(c)$|$O(c)$| 已接受 |

 ## 算法演练

 我们完全处理残留物$t_i = z_i \bmod m$。 

1. 开始于$t_1 = b \bmod m$。 这是第一次时钟观察。 
2. 计算$t_{i+1} = (a(i \bmod c)^2 - t_i) \bmod m$为了$i = 1$最多$2c$。 

我们停在$2c$因为这个长度足以捕获系统的完整重复行为。 
3. 存储所有值$t_1, t_2, \dots, t_{2c}$并数一下有多少个$\le x$。 调用这个值`cnt_period`。 
4. 计算有多少个完整周期的长度$2c$适合$n$。 让`full = n // (2c)`。 
5. 乘法：每个完整周期贡献相同数量的休息时间，因此相加`full * cnt_period`。 
6. 模拟剩余的$n \bmod (2c)$步骤并分别添加他们的贡献。 

为什么它有效有两个事实。 首先，残差的递归仅取决于当前残差和步长索引的确定性周期函数。 其次，经过两步后，符号效应消失，将演化转变为具有有界周期性增量序列的纯加性系统。 这迫使整个系统重复每一个$2c$步骤，因此状态序列是周期性的，并且中断的计数也是周期性的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, a, b, x, c = map(int, input().split())

        def f(i):
            r = i % c
            return (a * r * r) % m

        max_len = min(n, 2 * c)

        tvals = [0] * (max_len + 1)
        tvals[1] = b % m

        for i in range(1, max_len):
            tvals[i + 1] = (f(i) - tvals[i]) % m

        cnt = 0
        for i in range(1, max_len + 1):
            if tvals[i] <= x:
                cnt += 1

        if n <= max_len:
            print(cnt)
            continue

        full = n // max_len
        rem = n % max_len

        ans = full * cnt
        for i in range(1, rem + 1):
            if tvals[i] <= x:
                ans += 1

        print(ans)

if __name__ == "__main__":
    solve()
```该实现仅存储最多一个完整周期长度的残差序列$2c$。 转换直接使用模块化形式，避免了处理大整数。 

索引保持从 1 开始，以完全匹配重复定义。 功能$f(i)$计算周期性贡献$a(i \bmod c)^2$，总是模数减少$m$。 

最终的答案是通过将过程分成完整的循环和剩余的前缀来组装的，确保没有任何步骤超出$O(c)$需要模拟。

 ## 边缘情况

 当$c = 1$， 期限$i \bmod c$始终为零，因此递归简化为$t_{i+1} = -t_i$。 该序列在两个值之间确定性地交替，并且算法在计算的内部正确地捕获了这一点$2c = 2$时期。 

什么时候$b \ge m$，初始值减少模数$m$。 实施明确适用$b \bmod m$，即使启动时间超过模数，也确保状态有效。 

什么时候$x = m-1$，每个残基都算作一​​个中断。 定期计数方法仍然会产生正确的总数，因为它无一例外地对每个周期中的所有位置进行计数。
