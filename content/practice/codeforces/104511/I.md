 ## 解决方案
 ## 问题理解

 我们正在开发一个咖啡类型系统，其中每种类型的行为都像可转换资源。 我们的目标是最终获得尽可能多的 1 类咖啡。 

最初，加奈子从纯香那里收到了一定数量的咖啡。 Sumika 仅提供某些类型，由二进制字符串表示。 如果某种类型可用，我们可以采用任何非负实际数量，只要所有选定的起始类型的总数量不超过固定预算$v$。 这意味着我们可以自由地将初始预算按任何比例分配给允许的类型。 

设置完成后，我们就可以重复应用交易规则。 每笔交易涉及两种输入类型并产生一种输出类型。 交易不是离散的，而是连续的：我们选择一个比例因子$k$，并且贸易消耗按比例数量的两种咖啡类型并生产按比例数量的第三种类型。 这使得每笔交易都是资源数量之间的线性转换。 

最终目标是在任意多次交易后最大化我们最终可以获得的 1 类咖啡的数量。 

种类数量限制较少，咖啡种类最多20种，贸易规则最多100条。 初始体积$v$可以非常大，最多$10^{18}$，这表明该解决方案无法直接模拟数量，而必须使用比率或归一化值。 实值系数的存在也强烈表明连续优化或线性不等式公式而不是组合搜索。 

当交易可以链接成一个无限增加总产出的循环时，就会出现一个关键的边缘情况。 例如，如果一系列交换允许将一种类型的 1 个单位变成其自身的 1 个以上单位，则重复应用会产生无界增长，答案必须是$-1$。 这是很微妙的，因为它可以通过多种中间类型间接发生。 

另一个微妙的情况是系统有界但有多个初始源。 由于我们可以在可用的起始类型之间任意分配初始预算，因此最佳策略不是固定的，而是取决于哪种类型产生到类型 1 的最佳最终转换。 

对交易的简单模拟或对数量的重复应用会立即失败，因为数量是实际价值的，并且该过程可能需要无数次改进才能收敛或完全发散。 

## 方法

 直接模拟将尝试维持当前的咖啡量向量，并重复应用所有可能的交易以寻求改进。 每笔交易都会不断扩展，因此即使一个应用程序也可以生成无限多个中间状态，具体取决于$k$。 因此，离散模拟没有明确定义，即使离散化，有意义的状态数量也会爆炸，因为每次交易都会创建新的资源分配组合。 

一种更加结构化的方法是将视角从数量转向价值传播。 我们没有跟踪我们有多少咖啡，而是为每种咖啡类型分配一个值：我们最终可以从该类型的一个单元中获得多少类型 1 咖啡。 如果我们知道这些值，最终的答案就变成了初始供应量的简单线性表达式。 

这将问题转化为寻找一致的值分配$R[i]$，其中每项交易都会施加一个约束：输出的价值必须至少与适当缩放的输入的加权总和一样大。 如果交易转化$a$类型单位$x$和$b$类型单位$y$进入$c$类型单位$z$，那么我们必须有$$c \cdot R[z] \ge a \cdot R[x] + b \cdot R[y].$$重新排列给出了可以改进估计的松弛规则$R[z]$。 

这形成了类似于最长路径问题的单调最大化系统，只不过边依赖于节点对而不是单个前驱。 重复松弛会收敛到最佳可实现的值，除非存在正循环，在这种情况下，值可以无限制地增长，答案是无限的。 

一旦全部$R[i]$计算出来后，初始条件变得简单：我们可以分配总体积$v$在可用的源类型中，因此我们采用最佳源类型并将其单位值乘以$v$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 指数/非终止| O(n) | 太慢了|
 | 价值放松（贝尔曼式）| O(n·m·迭代) | O(n) | 已接受 |

 ## 算法演练

 我们将系统重新表述为计算从每种类型到类型 1 的最佳转换率。 

### 1. 初始化值估计

 我们定义一个数组$R$在哪里$R[i]$代表我们可以从一单位类型中获得多少类型 1 咖啡$i$。 我们从$R[1] = 1$，因为类型 1 的一个单位已经是目标的一个单位，并且所有其他值都从零开始。 

此初始化仅对已知信息进行编码，并允许通过交易进行改进。 

### 2. 多次放宽所有贸易规则

 对于每笔交易转换$x, y \to z$，我们计算通过生成获得的类型 1 值的最佳可能增益$z$从$x$和$y$。 交易意味着：$$R[z] \leftarrow \max\left(R[z], \frac{a \cdot R[x] + b \cdot R[y]}{c}\right).$$我们对所有交易多次重复此过程，因为提高一个值可以解锁下游的进一步改进。 这种传播是必要的，因为依赖关系形成循环。 

### 3. 检测无限增长

 如果在松弛期间我们观察到在对所有交易进行多次完整传递后某些价值仍然可以增加，则系统包含一个盈利周期。 这意味着我们可以继续应用交易来无限期地放大资源，所以答案是$-1$。 

实用的办法最多就是跑步$n$完整的迭代并检查之后是否仍然出现任何改进。 

### 4. 计算最佳初始分配

 一旦价值稳定，我们就会检查 Sumika 提供的所有类型。 由于我们可以任意分配总体积，因此我们取：$$\max_{i \in S} R[i] \cdot v,$$在哪里$S$是可用起始类型的集合。 

这相当于将整个初始预算投资到最有效的起始资源中。 

### 为什么它有效

 关键的不变量是$R[i]$始终表示可实现的最佳类型转换率的下限$i$输入 1。每个松弛步骤都保留了正确性，因为每个交易都编码了一个有效的线性变换，该变换不能高估真实的转换效率。 当不可能进一步放松时，所有约束都以最严格的可能值得到满足。 如果经过多次传播后仍然有可能改善，则意味着存在严格增加价值的循环，意味着无限增长。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, v = input().split()
        n = int(n)
        m = int(m)
        v = float(v)

        s = input().strip()

        edges = []
        for _ in range(m):
            a, x, b, y, c, z = input().split()
            a = float(a)
            b = float(b)
            c = float(c)
            x = int(x) - 1
            y = int(y) - 1
            z = int(z) - 1
            edges.append((a, x, b, y, c, z))

        INF = 1e100
        R = [0.0] * n
        R[0] = 1.0

        def relax():
            changed = False
            for a, x, b, y, c, z in edges:
                val = (a * R[x] + b * R[y]) / c
                if val > R[z] + 1e-15:
                    R[z] = val
                    changed = True
            return changed

        # propagate values
        for _ in range(n * 5):
            if not relax():
                break

        # check unbounded growth
        if relax():
            print(-1)
            continue

        best = 0.0
        for i in range(n):
            if s[i] == '1':
                best = max(best, R[i])

        print(best * v)

if __name__ == "__main__":
    solve()
```实现直接遵循问题的松弛视图。 数组`R`将转换效率存储为类型 1，锚定于`R[0] = 1`。 每次迭代都将所有贸易规则作为线性改进应用。 稳定后的额外放松检查可以检测无限增长：如果任何值仍然增加，则存在盈利周期。 

浮点运算在这里是稳定的，因为约束很小，并且所需的精度允许具有较小 epsilon 阈值的标准双精度。 

最终乘以`v`反映出初始预算可以完全集中在最有效的起始咖啡类型上。 

## 工作示例

 ### 示例 1

 输入：```
n=3, m=1, v=10
s=101
trade: 1 unit of type2 + 1 unit of type3 -> 2 units of type1
```我们初始化：

 | 类型 | 右 |
 | --- | --- |
 | 1 | 1 |
 | 2 | 0 |
 | 3 | 0 |

 放松后：

 | 贸易应用 | 更新值 |
 | --- | --- |
 | 2+3 → 1 | R[1] 保持 1 |

 不存在进一步的改进。 可用源有类型 1 和 3，因此最好是类型 1。 

最终答案是$10 \cdot 1 = 10$。 

这表明交易并不能提高初始知识，而答案纯粹来自于初始供应。 

### 示例 2

 输入：```
n=2, m=2, v=1
s=11
1 1 + 1 2 -> 2 1.5
1 2 + 1 1 -> 2 1.5
```初始：

 | 类型 | 右 |
 | --- | --- |
 | 1 | 1 |
 | 2 | 0 |

 第一次放松：

 | 步骤| R[2] |
 | --- | --- |
 | 申请交易 1 | 0.5 | 0.5
 | 申请交易 2 | 仍然是 0.5 |

 下一次迭代不会进一步改进。 

最终答案：$$1 \cdot \max(1, 0.5) = 1.$$这表明当相互强化平衡但不增加时趋同。

 ## 边缘情况

 一个关键的情况是，即使没有任何一笔交易看起来有利可图，一个周期也允许严格改进。 在这种情况下，反复放松最终会增加一些$R[i]$全通后，触发无界检测逻辑。 例如，像这样的链$1 \to 2 \to 3 \to 1$如果组合比率超过 1，则不会在单个步骤中检测到，但在传播后变得可见。 

另一个微妙的情况是，即使最佳初始选择可用，也不是类型 1。 由于我们正在最大化输出，因此该算法会正确比较所有源类型，而不是假设类型 1 始终是最佳。 

最后的边缘情况是当改进非常小时的数值稳定性。 epsilon 阈值可确保无穷小的浮点噪声不会触发错误循环检测或无限循环。
