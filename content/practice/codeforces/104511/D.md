 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$网格，其中一些单元格已经具有固定的整数值，其余单元格未知。 我们想要想象完成的最终网格必须满足一个非常严格的几何规则：每对边缘相邻单元格的值必须精确地相差 1。这意味着在四个基本方向中的任何一个方向上移动一步总是将高度改变 +1 或 -1，幅度永远不会是 0，也永远不会超过 1。 

我们没有被要求构建一个有效的完成。 相反，我们被要求了解尊重给定固定单元格和邻接规则的所有可能的完成。 如果无论我们如何一致地完成网格，该单元格总是以相同的值结束，则该单元格被称为唯一确定的。 输出是一个网格，如果该强制值存在，我们将在其中打印该强制值，否则将打印 0。 

约束的关键结构含义是每个步骤都强制执行类似奇偶校验的传播。 一旦单个单元格的值固定，所有其他可到达的单元格都被限制在由路径确定的一致“高度表面”上，但不同的路径可能会不一致，除非它们由多个固定点锚定。 

自从$n$最多可以达到 500 个，并且所有测试用例中的单元总数最多为 250,000 个，我们需要每个单元基本上是线性或接近线性的时间。 任何独立地重新计算每个单元的约束或尝试枚举可能性的方法都将无法扩展。 

当网格只有一个已知单元格时，就会出现一种微妙的边缘情况。 在这种情况下，每个其他单元都可以通过多种方式进行全局移动，同时保留邻接约束，因此除了已知单元本身之外，没有任何东西可以被修复。 在不考虑全局偏移的情况下分配距离的朴素 BFS 会错误地得出确定了更多单元格的结论。 

当来自不同已知单元的约束仅通过奇偶校验发生冲突时，会出现另一种边缘情况。 例如，两个已知的单元格可能在所有奇偶校验约束上达成一致，但仍然允许网格部分中的自由加性常数移位，从而使大面积区域处于不确定状态，即使它们看起来“连接”。 

## 方法

 思考该问题的一种强力方法是尝试为所有未知单元格分配值，然后检查与约束的一致性。 对于每个未知的分配，我们将通过网格传播约束并验证所有相邻差异是否恰好为 1 并且所有已知单元格都匹配。 然后，我们将所有有效完成的结果相交，以查看哪些单元格保持固定。 

这种方法在概念上是正确的，但立即不可行。 赋值方式的数量随着未知单元格的数量呈指数增长，甚至单个完成检查也是如此$O(n^2)$，使得完整的枚举变得巨大。 

关键的观察结果是，“相邻差值恰好为 1”这一约束将网格转变为具有绝对值约束的整数线性方程组，但更重要的是，它的行为类似于最短路径一致性系统。 如果我们为边指定一个方向，则每条边都会强制执行 +1 或 -1 的差异，因此网格变成一个图，其中每个有效的完成都对应于选择满足所有固定节点的一致方向。 

关键思想是将问题转化为关于相对于未知的全球“潜在变化”的距离的推理。 如果我们为一个已知单元选择一个起始解释，我们可以使用 BFS 传播约束两次：一次计算最小可行值，一次计算约束下的最大可行值。 当这两个值一致时，单元格被唯一确定。 

这将问题从指数可能性简化为网格图上的两个多源最短/最长传播过程，这两个过程都与单元数量呈线性关系。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| O(n²) | 太慢了|
 | 双 BFS / 约束传播 | 每次测试 O(n²) | O(n²) | 已接受 |

 ## 算法演练

 我们将问题重新表述为计算每个单元格在所有有效完成中可以采用的可能值的范围。 

我们使用两个约束传播过程：一个计算最小可行高度，另一个计算最大可行高度。 

### 步骤

 1. 识别所有具有已知值的单元格并将它们初始化为传播的起点。 

这些充当锚点，因为每个有效的完成都必须与它们完全匹配。 如果没有它们，整个网格将是平移不变的，并且任何值都不会被固定。 
2. 运行最短路径式 BFS 来计算每个单元格的最小可能值。 

我们将每个像元值视为约束，并使用邻居必须相差 1 的规则传播到邻居。当放松边缘时，我们会尝试将值向下推（只要一致）。 这会产生每个单元格在遵守所有固定约束的情况下可以获得的最小值。 
3. 运行第二个 BFS 来计算每个单元格的最大可能值。 

这次我们向相反的方向传播，在约束允许的范围内将值向上推。 从概念上讲，这探索了约束系统的对偶可行区域。 
4. 对于每个单元格，比较获得的最小值和最大值。 

如果两者相等，则单元格不能在任何有效完成中进行调整，因此它是唯一确定的。 否则，至少存在一种可以改变它的自由度。 
5. 输出唯一确定的单元格的公共值，否则输出0。 

### 为什么它有效

 网格约束定义了一个连接系统，其中任何有效的完成都对应于图上整数势的一致分配。 单元格的可行值形成一个区间，因为任何增加单元格值的调整都可以沿着路径一致传播，直到被固定约束阻止，对于减小的值也类似。 

两次 BFS 遍同时计算由所有约束引起的最紧下限和上限。 任何有效的分配都必须位于两个边界之内，并且区间内的每个值都可以通过沿周期局部调整传播选择来实现。 因此，如果间隔折叠为单个点，则在每个有效完成中都会强制使用该值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import deque

def solve():
    n = int(input())
    g = [list(map(int, input().split())) for _ in range(n)]

    INF = 10**18

    def bfs_min():
        dist = [[INF] * n for _ in range(n)]
        q = deque()

        for i in range(n):
            for j in range(n):
                if g[i][j] != 0:
                    dist[i][j] = g[i][j]
                    q.append((i, j))

        dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        while q:
            x, y = q.popleft()
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < n:
                    cand = dist[x][y] - 1
                    if cand < dist[nx][ny]:
                        dist[nx][ny] = cand
                        q.append((nx, ny))
        return dist

    def bfs_max():
        dist = [[-INF] * n for _ in range(n)]
        q = deque()

        for i in range(n):
            for j in range(n):
                if g[i][j] != 0:
                    dist[i][j] = g[i][j]
                    q.append((i, j))

        dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        while q:
            x, y = q.popleft()
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n:
                    cand = dist[x][y] + 1
                    if cand > dist[nx][ny]:
                        dist[nx][ny] = cand
                        q.append((nx, ny))
        return dist

    mn = bfs_min()
    mx = bfs_max()

    out = []
    for i in range(n):
        row = []
        for j in range(n):
            if mn[i][j] == mx[i][j]:
                row.append(str(mn[i][j]))
            else:
                row.append("0")
        out.append(" ".join(row))

    print("\n".join(out))

t = int(input())
for _ in range(t):
    solve()
```该解决方案执行两个多源 BFS 式松弛。 在第一遍中，每个已知单元都会传播最小可行值，并且始终沿边缘减少 1。 在第二遍中，使用相同的结构，但相反以最大化值。 

最后的比较步骤至关重要，因为它将唯一性编码为区间崩溃。 如果下限和上限匹配，则该单元格的值没有自由度。 

一个微妙的实现细节是两个 BFS 队列同时从所有已知单元开始。 这是必要的，因为约束会同时传播到所有锚点； 单独处理它们将无法正确合并交互区域。 

## 工作示例

 考虑一个小网格，其中两个已知单元放置在网格的不同部分。 传播将约束向外传播并在中间重叠。 

### 示例 1

 输入：```
3
1 0 0
0 0 0
0 0 5
```我们从概念上跟踪传播。 

| 步骤| 处理过的细胞| 最小更新 | 最大更新 |
 | --- | --- | --- | --- |
 | 1 | (0,0)=1 | 邻居 ≥ 0 | 邻居 ≤ 2 |
 | 2 | (2,2)=5 | 邻居 ≥ 4 | 邻居 ≤ 6 |
 | 3 | 重叠中心| 受两者约束| 受两者约束|

 中心单元格受到相互冲突的方向约束，导致出现一个范围而不是单个值。 

这显示了多个锚点如何限制可行的间隔，但不一定会折叠它们。 

### 示例 2

 输入：```
2
1 0
0 0
```| 步骤| 处理过的细胞| 最小更新 | 最大更新 |
 | --- | --- | --- | --- |
 | 1 | (0,0)=1 | 向下传播| 向上传播|
 | 2 | 传播| 宽间隔| 宽间隔|

 这里只有一个锚点存在，所以整个网格均匀地移动。 没有额外的约束来固定超出相对距离的绝对值。 

这说明了为什么唯一性需要多个相互作用的约束，而不仅仅是连接性。

 ## 边缘情况

 一种关键的边缘情况是只有一个已知单元格的情况。 在这种情况下，两个 BFS 都会向外传播值，但不会遇到另一个固定锚点来折叠间隔。 每个单元格最终都会有一系列可行值，因此如果仔细处理的话，输出完全为零，除了锚点本身之外。 该算法可以正确处理此问题，因为除了源之外，最小值和最大值在任何地方都保持不同。 

另一种边缘情况是两个已知单元相距较远但一致。 来自两个源的传播在中间相遇，但除非它们的约束沿着所有路径紧密同步，否则间隔仍然是非单一的。 基于 BFS 的边界计算正确地捕获了这一点，因为它同时合并所有约束前沿，而不是独立处理源。 

当网格完全确定时，会出现最后一个微妙的情况。 在这里，来自已知单元的传播完全锁定每条路径，导致最小值和最大值在各处收敛。 该算法自然会检测到这种崩溃，因为一旦实现一致性，任何松弛都无法改善任何一个界限。
