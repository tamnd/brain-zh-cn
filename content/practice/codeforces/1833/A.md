 ## 解决方案
 ## 问题理解

 我们得到了一个目标旋律，它只是字母表上的一个字符串`{a, b, c, d, e, f, g}`。 Vlad 无法直接以任意块的形式构建该字符串。 相反，他只能记录长度恰好为两个字符的片段，例如`"ab"`或者`"gg"`。 

在录制几个这样的双字符片段后，他可以将它们连接成一个更长的序列，但前提是相邻片段在边界处“匹配”。 具体来说，一个片段的最后一个字符必须等于下一个片段的第一个字符，这样连接就不会产生非法跳转。 

目标是使用尽可能少的两个字符记录来重建整个给定字符串。 

重新解释该问题的一个有用方法是将每个双字符记录视为其第一个字符和第二个字符之间的定向连接。 当我们连接录音时，我们本质上是沿着这些连接行走，重用端点连续性条件作为行走约束。 任务变成：需要多少个这样的有向边，以便它们的重叠可以产生整个序列。 

字符串长度最多为50，测试用例最多为10⁴。 这意味着任何每次测试的 O(n²) 或更好的解决方案都足够快，但任何指数或涉及边缘子集的大量搜索都是不必要且有风险的。 

当字符串中的所有字符都相同时，就会出现一种微妙的情况，例如`"aaaaaa"`。 这里是单曲录音`"aa"`可以在概念上重用以扩展整个链，因此答案变为 1。另一个边缘情况是当转换在锯齿形图案中全部不同时，例如`"abacaba"`，其中重用是有限的，我们必须考虑重叠对之间的重复转换。 

一个天真的错误是假设我们需要字符串中每个相邻对的一个记录。 这会失败，因为如果端点匹配得当，单个记录对可以在链中重复使用多次，从而减少所需的记录数量。 

## 方法

 暴力解释尝试明确选择要记录的两个字符段以及如何将它们缝合在一起以形成字符串。 人们可以想象枚举所有可能的边的多集选择，例如`"ab"`,`"ba"`,`"ac"`，依此类推，然后检查是否可以通过按顺序链接它们来形成字符串。 这很快就会变得棘手，因为即使字母表很小，可能的边多重集的数量也会随着字符串中不同转换的数量呈指数增长。 每次检查都需要模拟路径构造，即使对于 n = 50，这种方法也太慢。 

关键的见解是停止考虑正在构建的完整字符串，而是查看目标字符串中连续字符之间的局部转换。 每相邻对`(s[i], s[i+1])`要求某些记录的片段可以覆盖它，这意味着我们需要确保每个有向过渡类型至少可用一次。 然而，重叠很重要：如果我们已经有一个片段`"ab"`以及以后需要`"ab"`同样，我们不需要第二次记录，只要它可以在构建路径中重复使用即可。 

关键的简化是，字符串的结构只迫使我们关心字符之间的不同转换，但有一个例外：当字符出现在必须充当分支点的模式中时，它可能会强制进行额外的记录，因为单独一个边缘无法服务于单个链中的多个不兼容的方向。 在实践中，最佳解决方案减少为在贪婪扫描中计算不同字符之间有多少个转换是“新的”，同时尽可能重用以前看到的转换。 

正确的表述是：我们贪婪地模拟构建字符串并计算我们必须“开始新记录”的次数，因为当前的转换无法通过继续先前的链来满足。

 ## 算法演练

 我们独立处理每个字符串。 

1. 从一组空的已用定向转换开始。 每个转换都是一对`(s[i], s[i+1])`。 
2. 从左到右扫描字符串并考虑每个相邻的对。 对于每一对，检查我们是否已经在记录集中“覆盖”了这个转换。 如果没有，我们必须为这一对引入新的双字符录音。 
3. 当我们为一对介绍新录音时`(a, b)`，我们将其标记为已使用。 这代表记录该段`"ab"`。 
4. 继续扫描。 如果以后我们遇到同一对`(a, b)`，我们不需要另一条记录，因为它可以重用链中现有的记录。 
5. 最终答案是字符串中出现的不同定向转换的数量。 

一个关键细节是我们将转换视为有指导的，这意味着`"ab"`和`"ba"`是不同的录音。 这是至关重要的，因为串联约束取决于方向。 

### 为什么它有效

 每个记录的两字符字符串精确对应一个有向边。 最终字符串的任何有效构造都必须能够通过某些边实现原始字符串中的每个相邻对。 如果出现两个相同的转换，则单个记录的边就足够了，因为只要保留连接性，就可以在链中的多个位置重复使用它。 因此，最小记录数等于字符串所需的不同相邻字符对的数量。 

不变的是，在扫描的每一步中，记录的转换集足以再现所有处理过的邻接对而不会产生矛盾，并且只有当出现新类型的邻接时我们才对其进行扩展。 这保证了最小性，因为引入更少的边将导致至少一个邻接不受支持。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()

    used = set()
    ans = 0

    for i in range(n - 1):
        pair = (s[i], s[i + 1])
        if pair not in used:
            used.add(pair)
            ans += 1

    print(ans)
```该实现直接反映了跟踪不同相邻对的想法。 套装`used`指导过渡的商店已经被计算在内。 每次我们看到一对新的时，我们都会增加答案。 除了迭代最多之外，不存在边界问题`n-2`，因为我们总是访问`i+1`。

 ## 边缘情况

 对于像这样的字符串`"aaaaaa"`，每个相邻对都是相同的。 该算法看到`(a,a)`一次并且不再增加计数器，产生输出 1。这与单个记录的事实相匹配`"aa"`可以在整个建筑过程中重复使用。 

对于完全交替的模式，例如`"ababab"`，扫描仅产生两个不同的转换：`(a,b)`和`(b,a)`。 尽管字符串长度相对于转换数量很大，但基于集合的方法正确地将重复折叠为重用，从而确认答案仅取决于不同的邻接类型，而不取决于频率。
