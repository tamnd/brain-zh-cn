 ## 解决方案
 ## 问题理解

 在一个节日里，我们有一群人，每个人都准确地记得一个正在跳圆舞的邻居。 每场舞蹈都是一个封闭的循环，每个参与者都有两个邻居，但我们每个人只知道一个邻居。 任务是根据这些部分观察确定可能存在的圆形舞蹈的最小和最大数量。 

输入列出了每个人记住的邻居，索引从 1 到 n。 每个人的记忆都指向群体中的其他人，所以没有人指向自己。 例如，如果人 1 记住了 2，而人 2 记住了 1，他们可以形成大小为 2 的圆形舞蹈。输出应该为每个测试用例给出两个整数：可能存在的最少舞蹈数量（最小值）和最大可能的单独舞蹈数量（最大值）。 

约束允许最多$2 \cdot 10^5$所有测试用例的总人数，最多$10^4$测试用例。 检查所有人员组合以形成循环的简单解决方案将需要阶乘时间，并且完全不可行。 因此，我们必须寻求一个大致运行的解决方案$O(n)$每个测试用例。 

边缘情况包括大小为 2 的非常小的循环的情况，其中一个人的邻居间接指向自己。 另一个微妙的例子是，人们记住邻居的链条最终会循环，形成一个更大的循环。 例如，对于`n=4`和邻居数组`[2,1,4,3]`，舞蹈的最小数量为 1，因为所有四个舞蹈都可以连接在一个循环中，但最大数量为 2，因为每一对都可以形成自己的两人舞蹈。 

## 方法

 暴力方法将尝试通过尝试邻居的每种可能的排列来重建所有循环。 对于每个人，我们都会追踪他们的邻居，将他们标记为已访问，并继续，直到形成一个循环。 计算周期就能得出答案。 虽然这在原则上是有效的，但它是$O(n^2)$在最坏的情况下，因为后续循环可能会重复扫描许多元素，并且 n 的总和可以是$2 \cdot 10^5$，太大了。 

关键的见解是将其建模为一个有向图，其中每个人都指向一个邻居。 该图中的每个连接组件形成一个循环，可能还有其他链通向该循环。 在这个问题中，每个节点的出度都是 1，因此保证每个连通分量恰好包含一个环。 最少舞蹈次数为以下总和$\lceil \text{cycle length}/2 \rceil$对于大小至少为 2 的所有循环，因为我们可以对循环中的节点进行配对，以将舞蹈数量减少到最少。 最大舞蹈数就是循环总数，将大小为 2 的循环的每个节点计为自己的舞蹈。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 图+周期检测| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，读取 n 和邻居数组。 将每个邻居减 1 以转换为基于 0 的索引。 
2. 初始化一个大小为 n 的已访问数组，以跟踪已处理周期的人员。 
3. 对于每个人`i`从 0 到 n-1，如果它们未被访问，则开始循环跟踪邻居，直到返回到访问过的节点。 该遍历标识了一个循环。 将每个节点标记为沿途已访问。 
4. 计算找到的循环的长度。 对于最少的舞蹈次数，如果循环长度为`l`， 添加`(l + 1) // 2`至总数。 这说明长度为 2 的循环只能是一个舞蹈，长度为 3 或 4 的循环有时可以分为更少的舞蹈。 
5. 对于最大数量的舞蹈，每个循环，无论长度如何，都算作一支舞蹈。 将最大计数器加 1。 
6. 处理完所有人员后，输出该测试用例的累计最小和最大数量。 

为什么它有效：每个人都指向一个邻居，因此有向图由可能带有通向它们的链的循环组成。 因为每个人都准确地记住一个邻居，并且所有节点的出度均为 1，所以每个连通分量实际上都是一个循环。 跟踪邻居可以保证我们找到所有循环而不会丢失或重复计算节点。 计算`(length + 1) // 2`对于最少的舞蹈来说，用最少的舞蹈捕捉尽可能最佳的人群分组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a = [x - 1 for x in a]  # convert to 0-based
        visited = [False] * n
        min_dances = 0
        max_dances = 0
        
        for i in range(n):
            if not visited[i]:
                length = 0
                x = i
                while not visited[x]:
                    visited[x] = True
                    x = a[x]
                    length += 1
                min_dances += (length + 1) // 2
                max_dances += 1
        
        print(min_dances, max_dances)

if __name__ == "__main__":
    solve()
```该解决方案首先将输入转换为基于 0 的索引以简化数组访问。 这`visited`数组可以防止重复计数。 对于每个未访问的节点，while 循环遵循邻居链来识别一个循环，递增`length`在每一步。 最小舞蹈计算`(length + 1) // 2`确保我们以最佳方式组合配对，而最大化则很简单，因为每个循环都算作一场舞蹈。
