 ## 问题理解

 给定一个正整数数组，任务是构造一个相同长度的新数组，其中所有元素都是正数并且具有相同的奇偶性，要么全是奇数，要么全是偶数。 对于新数组中的每个元素，我们可以从原始数组中复制相应的元素，或者获取该元素与原始数组中任何其他元素之间的差异。 我们需要确定是否可以为每个测试用例构建这样的数组。 

数组长度最多可达 200,000，所有测试用例的长度总和也不超过 200,000。 这意味着任何简单地处理每对元素的解决方案（例如尝试每个元素的每个可能的差异）都需要以下顺序：$O(n^2)$操作，显然太慢了。 相反，我们需要一个在每个测试用例的线性或线性时间内工作的解决方案，理想情况下$O(n)$。 

可能棘手的边缘情况是数组包含奇数和偶数的混合，但每种类型仅包含一个。 例如，数组`[2, 3]`无法形成一个漂亮的数组，因为元素的差异不会产生可以对齐奇偶校验的数字。 另一种微妙的情况是所有元素都具有相同的奇偶性。 在这种情况下，答案立即是“是”，但是总是尝试计算差异的粗心方法可能会浪费时间或错误分类。 

## 方法

 暴力方法将尝试每对可能的元素来计算所有可能的差异，然后检查是否可以从这些数字构造一个漂亮的数组。 对于长度的数组$n$， 有$n^2$需要考虑的可能差异。 我们可以将所有差异存储在一个集合中，并检查可能的统一奇偶校验数组。 这在原则上是正确的，因为它涵盖了所有允许的操作，但是$n$如果达到 200,000，最坏的情况将导致 400 亿次操作，这太慢了。 

实现有效解决方案的关键见解是差异的奇偶性完全由原始数字的奇偶性决定。 如果所有数字都具有相同的奇偶性，我们就完成了。 如果存在奇数和偶数的混合，则从偶数中减去奇数（反之亦然）始终会得到奇数结果，而将两个具有相同奇偶性的数相减得到偶数结果。 这意味着唯一的障碍是混合在一起，阻止所有差异的统一。 真正的检查简化为查看数组是否包含相差正好一的奇数和偶数。 

这一观察结果使我们能够通过简单地计算奇数和偶数的数量来在线性时间内解决每个测试用例。 如果至少有一个奇数和一个偶数，我们检查它们的最小差异，看看美丽的数组是否可行。 不然的话，数组就已经很漂亮了。

 ## 算法演练

 1. 对于每个测试用例，读取数组长度$n$和数组$a$。 这设置了要处理的数据。 
2. 统计数组中奇数和偶数的个数。 这立即告诉我们该数组的奇偶校验是否已经一致或混合。 
3. 如果所有数字都是奇数或所有数字都是偶数，则打印“YES”。 无需进行任何更改，因为数组已经很漂亮了。 
4. 如果同时有奇数和偶数，则对数组进行排序。 排序使我们能够有效地检查是否存在任何两个奇偶性相反且差值恰好为 1 的数字。这样的数字不能在一个漂亮的数组中共存。 
5. 遍历已排序的数组。 对于每个连续的对，如果一个是奇数，另一个是偶数，并且它们的差为 1，则打印“NO”并中断。 这是唯一不可能构建漂亮数组的情况。 
6. 如果没有找到这样的相邻对，则打印“YES”。 超过 1 个或相同奇偶校验对的差异并不妨碍构造一个漂亮的数组，因为我们总是可以选择差异来对齐奇偶校验。 

工作原理：该算法依赖于这样一个事实：两个奇偶校验相同的数字相减得到一个偶数，两个奇偶校验不同的数字相减得到一个奇数。 因此，无法构建漂亮数组的唯一方法是当奇数和偶数相差正好 1 时，因为没有任何差异组合可以将它们转换为相同的奇偶校验而不产生零或负数。 所有其他配置都允许选择原始数字或差异来生成统一的奇偶校验阵列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        odd_count = sum(1 for x in a if x % 2 == 1)
        even_count = n - odd_count
        if odd_count == 0 or even_count == 0:
            print("YES")
            continue
        a.sort()
        possible = True
        for i in range(1, n):
            if a[i] - a[i-1] == 1:
                possible = False
                break
        print("YES" if possible else "NO")
```该代码首先计算奇数和偶数，以立即处理简单的情况。 排序可确保检查 1 的差异是高效且线性的。 连续对上的循环捕获了唯一无法构建漂亮数组的情况。
