 ## 解决方案
 ## 问题理解

 我们给出了从 1 到$n$。 我们的目标是仅执行一次由两部分组成的操作，以产生字典顺序上可能的最大排列。 该操作包括首先反转数组的连续段，然后交换该段之外的剩余前缀和后缀。 输出是结果排列。 

每个测试用例提供$n$和排列。 限制是适度的：总和$n$所有测试用例最多 2000 个，这表明$O(n^2)$算法将在 1 秒内轻松运行。 关键的挑战是理解反转段和交换前缀/后缀的组合如何产生最大排列。 

边缘情况包括非常小的数组（长度为 1 或 2），其中反转段可能很简单，以及最大数量位于末尾或已位于开头的情况，因此“交换前缀和后缀”步骤需要仔细处理。 幼稚的方法可能会选择要反转的段，而不考虑前缀和后缀交换如何影响字典顺序，从而产生次优结果。 

## 方法

 蛮力方法是尝试所有可能的段$[l, r]$，反转它们，交换前缀和后缀，并比较结果排列。 有$O(n^2)$段，并且每个操作都需要$O(n)$是时候构建新数组了。 这产生$O(n^3)$总时间，这仅对于很小的情况是可行的$n$，但与$n \le 2000$在所有测试用例中，如果天真地应用的话，这会太慢。 

关键的见解来自于反转段后的观察$[l, r]$，交换前缀和后缀的操作有效地移动了之后的元素$r$到前面和前面的元素$l$到后面。 因此，为了最大化第一个元素，我们需要将最大的元素放置在结果排列的开头。 一旦第一个元素被固定，我们就可以通过选择适当的段来贪婪地为第二个位置选择下一个最大的可用元素。 

这将问题简化为迭代第一个元素的可能位置，将其放置在前面，然后根据相对顺序贪婪地选择剩余的序列。 通过仔细观察，我们发现我们只需要考虑将前缀反转到最大的剩余元素，或者反转该元素的后缀。 我们不需要探索所有$O(n^2)$因为最大元素必须在前面结束。 这种见解降低了时间复杂度$O(n^3)$到$O(n^2)$，在约束条件下是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（所有部分）| O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 优化贪心（最大元素优先）| O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1. 确定排列中最大元素的位置。 为了最大化字典顺序，该元素必须在执行操作后占据第一个位置。 
2. 选择细分市场$[l, r]$这样反转后，最大的元素位于位置$l$如果它当前位于数组的中间。 这保证了交换前缀和后缀后，它会落在开头。 
3. 首先放置最大的元素后，考虑排列的剩余部分。 对下一个位置递归或贪婪地应用相同的逻辑：选择剩余数组中最大的元素，并在操作后反转将其定位在剩余序列开头的段。 
4. 通过将反转的段与交换的前缀和后缀组合起来构造结果排列。 始终检查边界：如果段包含开始或结束，则交换可能涉及空数组。 
5. 输出每个测试用例的最终排列。 

工作原理：该操作实际上是线性的：它将所选的反向段移动到中间，其余元素在其周围交换。 通过始终将最大的剩余元素放在结果的前面，我们确保序列在字典顺序上是最大的。 较小的元素不会影响它们之前元素的字典顺序，因此这种贪心策略是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        if n == 1:
            print(1)
            continue
        
        # Find the index of the largest element
        max_val = max(p)
        max_idx = p.index(max_val)

        # Strategy: make the largest element first
        if max_idx == 0:
            # Already at the front, just reverse the rest if needed
            rest = p[1:]
            rest.reverse()
            result = [p[0]] + rest
        else:
            # Reverse prefix including max element to move it to front
            result = p[:max_idx+1][::-1] + p[max_idx+1:]

        print(' '.join(map(str, result)))

if __name__ == "__main__":
    solve()
```该解决方案首先读取测试用例的数量并迭代每个测试用例。 它标识最大的元素及其位置。 如果最大的元素已经在前面，算法将反转其余元素以最大化字典顺序。 否则，它将前缀反转到最大元素以将其置于前面。 最后，它打印结果排列。

 | --- | --- | --- | --- | --- |

 该算法将前缀反转最多 5 个以将其置于前面，然后交换前缀/后缀（这里很简单，因为前缀位于开头）。 最终结果是`[5, 4, 1, 3, 2]`。 

**示例输入 2：**`9 4 1 6 7 2 8 5 3 9`| 步骤| 最大元素 | 要反转的段 | 反转后的排列 | 交换后的结果 |

 前缀反转将 9 带到开头。 前缀/后缀的交换适当地定位剩余元素以最大化字典顺序。
