 ## 解决方案
 ## 问题理解

 我们在平面上得到一组点，我们可以选择其中的三个或四个。 所选点必须形成一个简单的多边形，这意味着边缘不能交叉，并且我们希望形状能够最大化封闭区域。 输出不是面积本身，而是按循环顺序形成此类最佳三角形或四边形的点的索引。 

约束最多允许 4000 个点，坐标范围较大。 这立即排除了任何尝试大小为三或四的所有子集的方法。 对所有三元组的简单枚举已经大约是$O(n^3)$，这大约是$6.4 \times 10^{10}$上限操作，远远超出 1-2 秒内任何可行的限制。 即使经过仔细优化的四边形枚举也会更糟。 

几何条件“没有三个点共线”简化了简并性：每个三元组形成一个面积非零的有效三角形，并且凸包边缘被明确定义，没有歧义。 然而，它并不能保证最优多边形必须以简单的方式来自像凸包这样的固定子集； 四边形使结构变得复杂。 

如果不小心，一些边缘情况很容易被忽略。 

如果所有点形成凸多边形，则答案将始终位于凸包上，但这不足以证明正确性，除非我们正确证明它的合理性。 例如，由四个点组成一个凸四边形，在其中选取任何三角形都无法击败四边形区域。 

如果点集最小，比如说$n = 3$，答案被迫为那个三角形。 任何假设存在四边形的解决方案都会失败。 

如果点的排列使得凸包正好有三个点，则在不引入内点的情况下不可能有四边形，因此即使存在内点也必须选择三角形。 

## 方法

 蛮力的想法很简单：计算每个三元组和每个四元组的面积，检查四元组是否形成一个简单的多边形，并保留最好的。 通过叉积计算面积是$O(1)$，但枚举所有四元组是$O(n^4)$， 关于$2.5 \times 10^{14}$最多的情况下。 即使仅限制于三角形也给出$O(n^3)$，仍然不可能。 

结构见解是面积最大化下的最佳多边形必须位于凸包上。 严格位于船体内部的任何点如果替换船体顶点，则无法增加面积，因为它会“向内拉动”至少一条边。 这将问题减少到点集的凸包上。 

一旦我们限制在凸包上，我们就会处理一个凸多边形$h \le 4000$顶点。 任务变成：找到凸多边形内接的最大面积三角形或四边形。 

对于凸多边形中的三角形，一个经典属性是固定一个顶点并沿外壳移动另外两个顶点会产生单峰区域行为，可以使用旋转卡尺来利用。 对于四边形，最佳形状可以分解为共享对角线的两个三角形，并且凸性再次确保我们只需要将外壳顶点对视为对角线。 

这将搜索从指数组合减少到使用两指针技术对船体顶点进行线性或近线性扫描。 关键的结构限制是凸性：一旦顶点被循环排序，面积函数在端点的单调移动下的行为就可以预测。 

因此，解决方案变为：计算凸包，然后使用旋转卡尺式扫描系统地评估候选三角形和四边形，保持最佳面积。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^4)$|$O(1)$| 太慢了|
 | 凸壳 + 卡尺 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 使用单调链算法计算给定点的凸包。 这是必要的，因为任何最佳多边形必须仅使用外壳顶点； 包含内点时只能减少面积。 
2. 按逆时针顺序存储外壳顶点。 这种排序至关重要，因为所有后续关于面积单调性的推理都取决于循环结构。 
3. 初始化一个变量来跟踪迄今为止看到的最佳三角形和四边形，以及使用叉积计算出的面积。 
4. 对于三角形，固定起始顶点$i$在船体上并使用两指针扫描来选择顶点$j$和$k$最大化三角形面积$(i, j, k)$。 指针移动之所以有效是因为$k$沿着船体向前移动，该区域对于固定的情况表现为单峰$i, j$。 
5. 对于四边形，固定两个顶点$i$和$j$作为潜在的对角线。 然后通过选择对角线每条边上的最佳顶点对来独立优化四边形的两个“边”，使对角线形成的三角形面积之和最大化$(i, j)$。 这是可行的，因为凸四边形分裂成共享对角线的两个不重叠的三角形。 
6. 比较所有候选三角形和四边形区域并存储索引的最佳配置。 
7. 以循环顺序输出存储的索引，确保以一致的方向（顺时针或逆时针）报告多边形，这可以从外壳排序重建。 

### 为什么它有效

 正确性取决于这样一个事实：任何具有从集合中选择的顶点的最大面积多边形都必须位于凸包上。 一旦限制为凸多边形，任何非凸选择都可以通过沿着外壳向外“推动”顶点而不减少面积来改进。 第二个结构属性是，在凸多边形内，由三元组或对角线定义的面积函数沿着外壳顺序是单峰的，允许双指针优化在不检查所有组合的情况下定位最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def tri_area(a, b, c):
    return abs(cross(a, b, c))

def main():
    n = int(input())
    pts = [tuple(map(int, input().split())) + (i,) for i in range(n)]

    hull = convex_hull([(x, y, i) for x, y, i in pts])
    m = len(hull)

    best_area = -1
    best = None

    # triangles
    for i in range(m):
        for j in range(i + 1, m):
            k = j + 1
            while k + 1 < m:
                a1 = tri_area(hull[i], hull[j], hull[k])
                a2 = tri_area(hull[i], hull[j], hull[k + 1])
                if a2 >= a1:
                    k += 1
                else:
                    break
            if k < m:
                area = tri_area(hull[i], hull[j], hull[k])
                if area > best_area:
                    best_area = area
                    best = (3, hull[i][2], hull[j][2], hull[k][2])

    # quadrilaterals via diagonal split
    for i in range(m):
        for j in range(i + 1, m):
            best1 = (0, -1)
            best2 = (0, -1)

            # pick best k on one side
            for k in range(j + 1, m):
                val = tri_area(hull[i], hull[j], hull[k])
                if val > best1[0]:
                    best1 = (val, k)

            # pick best l on other side
            for l in range(0, i):
                val = tri_area(hull[i], hull[j], hull[l])
                if val > best2[0]:
                    best2 = (val, l)

            if best1[1] != -1 and best2[1] != -1:
                area = best1[0] + best2[0]
                if area > best_area:
                    best_area = area
                    best = (4, hull[i][2], hull[j][2], hull[best1[1]][2], hull[best2[1]][2])

    print(best[0])
    print(*best[1:])

if __name__ == "__main__":
    main()
```凸包构造是基础； 没有它，算法的其余部分就没有可利用的结构。 三角形搜索使用受控指针，该指针仅在扩大面积时才前进，从而避免了完全枚举。 四边形搜索依赖于沿固定对角线的分割，这将 4 点选择减少为沿船体顺序的两个独立的一维优化。 

一个微妙的实现细节是外壳顶点必须保留原始索引，因为输出需要引用输入顺序，而不是几何坐标。 另一个是在对四边形的三角形面积求和时对方向的一致处理，因为必须仔细解释叉积的符号。

 ## 边缘情况

 如果所有点都位于三角形上（凸包大小等于 3），则算法永远找不到有效的四边形候选者，并且三角形扫描成为唯一的贡献者。 这符合几何约束，即如果不复制顶点或引入减少面积的内部点，则不存在简单四边形。 

如果外壳尺寸恰好为 4，则同时评估三角形和四边形，并考虑沿任一对角线分割的四边形。 该算法正确地比较三角形与四边形的面积并选择较大的一个，这是必要的，因为凸四边形并不总是击败由其三个顶点形成的最佳三角形。
