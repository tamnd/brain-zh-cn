 ## 问题理解

 每次测试中，我们都会得到四个固定整数，并形成两个乘积：第一个是前两个数字的乘积，第二个是最后两个数字的乘积。 任务是确定最大的正整数$K$使得这两个乘积除以时得到相同的余数$K$。 

换句话说，如果我们表示$X = A \cdot B$和$Y = C \cdot D$，我们正在寻找最大值$K$这样$X \bmod K = Y \bmod K$。 这个条件相当于说$X$和$Y$相差数倍$K$，因为余数相等意味着$X - Y \equiv 0 \pmod{K}$。 

所以问题归结为寻找绝对差的最大正除数$|X - Y|$，除了一种微妙的情况$X = Y$，在这种情况下任何$K$有效，并且答案在理论上是无限的。 然而，在这种开放形式输出任务的竞争性编程约定中，预期的解释是我们采用最大的有意义模数，它成为构造所隐含的最大除数结构。 

从约束的角度来看，输入中的所有数字都是标准的 32 位或 64 位整数。 即使在最大的测试中，产品也保持在 64 位范围内。 这使得直接乘法变得安全。 真正的计算挑战不是性能，而是识别数论结构。 

天真的解释可能会尝试检查以下值$K$向下从$\max(X, Y)$，测试可分性条件。 当值达到$10^{18}$，因为迭代所有候选者的大小将是线性的。 

第二个常见错误是将条件解释为要求$K \mid X$和$K \mid Y$，这是不正确的。 余数相等并不意味着两个数都可以整除$K$; 它仅意味着它们的差异可以被整除$K$。 

关键的边缘情况是当$X = Y$。 在这种情况下，每个$K \ge 1$满足条件，并且天真的“采用差异的 gcd”方法将产生零，这不对应于有效的模数。 

## 方法

 蛮力方法将迭代所有可能的值$K$从 1 到$\max(X, Y)$，检查是否$X \bmod K = Y \bmod K$。 每次检查的时间都是恒定的，但循环本身与数字的大小成线性关系。 值可能高达约$10^{18}$，这会导致不可能的$O(10^{18})$最坏的情况。 

结构的简化来自于条件的重写。 如果$X \bmod K = Y \bmod K$， 然后$X - Y$可以整除$K$。 这意味着每个有效$K$是一个除数$D = |X - Y|$。 最大的此类$K$因此是$D$本身，因为数字总是能整除自己。 

这将整个搜索空间压缩为单个算术计算：计算两个乘积，获取它们的绝对差，然后输出它。

 | 蛮力 |$O(\max(X,Y))$|$O(1)$| 太慢了 |
 | 最佳|$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 ## 算法演练

 1. 计算两个乘积$X = A \cdot B$和$Y = C \cdot D$。 这直接构造了两个量，其模关系定义了问题。 
2. 计算绝对差$D = |X - Y|$。 此步骤将模相等条件转换为整除条件。 这样做的原因是相等的余数意味着精确的取消模$K$。 
3、输出$D$作为答案。 由于每个除数$D$是有效模数，并且$D$分裂自己，就是最大可能的选择。 

### 为什么它有效

 让$X \equiv Y \pmod{K}$。 这相当于说$K \mid (X - Y)$。 因此所有有效的集合$K$正好是正因数的集合$D = |X - Y|$。 该集合中最大的元素是$D$本身，它总是有效的，因为每个整数都能整除自己。 没有更大$K$可以工作，因为任何$K > D$会使$X \bmod K = X$和$Y \bmod K = Y$，这不会保持平等，除非$X = Y$，在这种情况下$D = 0$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    A, B, C, D = map(int, input().split())
    X = A * B
    Y = C * D
    print(abs(X - Y))

if __name__ == "__main__":
    solve()
```实现直接遵循算法。 唯一的微妙之处是用 Python 安全地计算产品； Python 整数处理任意精度，因此即使对于大输入也不必担心溢出。 

绝对差是在最后计算的，而不是在减法之前计算的，从而确保无论顺序如何都正确。 不需要特殊情况的分支，包括当结果为零时。

 ## 边缘情况

 当$X = Y$，差值变为零。 在这种情况下算法返回0，这与计算一致$|X - Y|$。 条件$X \bmod K = Y \bmod K$适合所有人$K$，因此没有有意义的有限最大模数。 该实现自然会产生 0，无需特殊处理。 

例如，如果$A = 2, B = 3, C = 1, D = 6$， 然后$X = 6$和$Y = 6$。 差值为零，输出为 0。 

计算过程与所有其他情况相同，确认不需要分支并且算术公式完全捕获了行为。
