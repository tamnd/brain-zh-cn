 ## 解决方案
 ## 问题理解

 我们得到一个四位数的年份作为字符串，可能包含前导零，并且要求我们确定这个数字是否可以表示为两个非负整数之和的平方。 形式上，对于给定的字符串`s`代表一个数字`Y`，我们想要整数`a, b ≥ 0`这样`(a + b)^2 = Y`。 如果存在这样的整数，我们输出任何有效的对`(a, b)`。 如果没有，我们输出`-1`。 

这个问题有几个微妙之处。 首先，输入是一个由四个字符组成的字符串，因此“0001”或“0185”等数字是有效的。 任何解决方案都必须正确处理这些前导零。 其次，约束允许最多 10,000 个测试用例，因此我们必须确保算法足够高效，能够处理这个数量而不会超时。 由于每年最多为四位数，因此我们可能遇到的最大数字是 9999，因此任何考虑到 9999 的数字的解决方案都是可行的。 

边缘情况包括最小可能的年份“0000”，可以表示为`0 + 0 = 0`，以及根本不是完美平方的年份，例如“1001”，它没有整数平方分解。 无法正确处理零或错误解释前导零的简单方法可能会产生不正确的输出。 

## 方法

 蛮力方法很简单：迭代所有可能的对`(a, b)`和`a, b ≥ 0`这样`(a + b)^2`等于目标年份。 鉴于最大可能值`Y`是9999，`a + b`最多可以是 99，因为`99^2 = 9801`和`100^2 = 10000`。 我们可以遍历所有`a`从 0 到 99 并检查是否`b = sqrt(Y) - a`是一个整数。 这种方法是正确的，因为它详尽地检查了每个组合，但在最坏的情况下，我们将为每个测试用例执行大约 10,000 次迭代，这对于 10,000 个测试用例来说是过多的。 

实现有效解决方案的关键观察是任何 4 位数字`Y`可以分为两部分：前两位数字和最后两位数字。 假设我们将年份解释为`Y = XY`， 在哪里`X`和`Y`是两位数的数字。 那么我们可以尝试表示`Y`作为`(X + Y)^2`。 只有 100 对可能`(a, b)`在哪里`a, b`范围从0到99，我们可以预先计算有效的组合`(a, b)`其平方和等于小于 10,000 的年份。 这将问题简化为对每个测试用例的简单查找。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(10^4 * 10^4) | O(10^4 * 10^4) | O(1) | O(1) | 太慢了 |
 | 预计算/直接检查 | O(10^4) | O(10^4) | O(100) | 已接受 |

 ## 算法演练

 1. 解析整数`t`代表测试用例的数量。 我们需要独立处理每个测试用例。 
2. 预先计算所有有效总和`(a + b)`在哪里`0 ≤ a, b ≤ 99`这样`(a + b)^2 ≤ 9999`。 将这些总和存储在字典中，将平方值映射到有效的`(a, b)`一对。 这避免了为每个测试用例重复重新计算平方。 
3. 对于每个测试用例，读取字符串`s`并将其转换为整数`Y`。 
4. 检查是否`Y`存在于预先计算的字典中。 如果存在，则输出存储的`(a, b)`一对。 如果没有，则输出`-1`。 
5. 对所有测试用例重复此操作。 

不变的是预先计算的字典包含所有可能的正方形，可以写成`(a + b)^2`和`a, b ≥ 0`和`a + b ≤ 99`。 通过构建，如果可以以所需的形式表示，则每个小于 10,000 的有效年份都将完全匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

# Precompute all (a+b)^2 <= 9999
squares = {}
for a in range(100):
    for b in range(100):
        val = (a + b) ** 2
        if val <= 9999:
            squares[val] = (a, b)

t = int(input())
for _ in range(t):
    s = input().strip()
    year = int(s)
    if year in squares:
        a, b = squares[year]
        print(a, b)
    else:
        print(-1)
```第一个块预先计算所有可能的`(a + b)^2`有效地价值观。 测试用例的循环读取每个字符串，将其转换为整数，然后在中查找值`squares`。 前导零`s`不影响整数转换，它可以正确处理“0001”等情况。 这种方法避免了重复计算并确保每个测试用例在恒定的时间内运行。 

## 工作示例

 对于输入`"0001"`，整数转换给出`1`。 预先计算的字典包含`(0 + 1)^2 = 1`，所以我们输出`0 1`。 

| 步骤| 变量| 价值|
 | ---| ---| ---|
 | 将“0001”转换为整数 | 年 | 1 |
 | 字典中查找年份 | 方块[1] | (0, 1) | (0, 1) |
 | 输出| 一个，b | 0 1 |

 对于输入`"4900"`，整数转换给出`4900`。 我们发现`(70 + 0)^2 = 4900`在字典中是`(70, 0)`，即输出。 

| 步骤| 变量| 价值|
 | ---| ---| ---|
 | 将“4900”转换为整数 | 年 | 4900 |
 | 字典中查找年份 | 正方形[4900] | (70, 0) | (70, 0) |
 | 输出| 一个，b | 70 0 | 70

 这些痕迹表明算法正确地找到了对`(a, b)`或返回`-1`如果不存在对。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(t) | 预计算运行一次 O(100*100) = O(10^4) 次，然后每个测试用例都是字典查找，O(1)。 t=10^4 的总计为 O(10^4)。 |
 | 空间| O(10^4) | O(10^4) | 预先计算的字典最多包含 10,000 个总和 (a+b)^2 ≤ 9999 的条目。 

考虑到这些限制，该解决方案可以在 1 秒时间限制和 256 MB 内存限制内轻松运行。

 ## 边缘情况

 对于年份“0000”，整数转换为 0。字典包含`(0 + 0)^2 = 0`，所以算法输出`0 0`。 

对于年份“1001”，整数转换得到 1001。没有对`(a + b)`这样`(a + b)^2 = 1001`，因此字典查找失败并且算法输出`-1`。 

对于“4900”，整数转换得到4900。字典查找发现`(70 + 0)^2 = 4900`，算法输出`70 0`。 这些示例证实了最小年、最大年和非平方年的边缘情况得到了正确处理。
