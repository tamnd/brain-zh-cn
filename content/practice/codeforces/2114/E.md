 ## 解决方案
 ## 问题理解

 我们得到一棵有根树，其中顶点 1 是根，每个顶点都有一个数值。 对于每个顶点$v$，我们考虑从$v$到根。 沿着这条路径，我们形成了几个交替和表达式：我们可以在任何祖先处停止，并且我们计算以加号开头的符号交替的值的总和$v$，然后在其父级处减去，然后在祖父母处加上，依此类推。 

任务是为每个顶点计算所有此类向上线段中可获得的最大值。 

重新表述这一点的一个有用方法是，每个顶点沿着其祖先链定义一个序列，并且我们希望在交替符号下该链的最佳前缀。 

这些约束清楚地表明，任何解决方案对于每个测试用例都必须基本上是线性的。 所有测试用例的顶点总数为$2 \cdot 10^5$，因此任何使用向上遍历独立地为每个顶点重新计算答案的解决方案都将在路径的共享前缀上重复工作并立即超出限制。 一个天真的$O(n^2)$每个测试用例的方法已经是不可能的。 

每个顶点的答案取决于其所有祖先，但祖先在子树之间共享，这一事实引起了一个微妙的问题。 在每个节点从头开始重新计算总和的朴素 DFS 将重复访问相同的边并大量重复计算。 

另一个陷阱是假设只有完整的根路径才重要。 最佳交替和可能会在任何祖先处提前停止，不一定在根处，因此限制完整的根到节点计算会丢失有效的候选者。 

## 方法

 一种直接的方法是独立处理每个顶点。 对于一个顶点$v$，我们遍历它的父指针，维护交替总和并跟踪最大值。 这是正确的，因为它明确评估每个允许的段。 然而，在每个节点只有一个子节点的倾斜树中，每个查询都需要$O(n)$，并且在所有顶点上这变成$O(n^2)$，这太慢了。 

关键的观察结果是，交替结构可以标准化，以便问题变成沿根到节点路径对变换序列进行最大后缀查询。 我们不是从头开始重新计算所有内容，而是在从根开始执行 DFS 时维护动态信息。 

让$dp[v]$表示交替和$v$直到根部都有固定的符号模式。 我们可以递归地定义它，以便每个节点都是在恒定时间内从其父节点构建的。 一旦这些值可用，任何交替和$v$给祖先$u$通过符号调整成为两个类似前缀的值之间的差异。 

主要困难在于，我们不仅对每个节点的单个前缀和感兴趣，而且对该前缀结构的所有后缀的最大值感兴趣。 这可以在 DFS 期间使用第二状态来维护：在遍历方向上结束于当前节点的最佳交替后缀。 当我们从父级移动到子级时，我们可以更新交替总和以及迄今为止在该路径上看到的最佳值。 

这将问题转化为树DP，其中每个节点从其父节点继承两个值：一个代表当前交替总和，一个代表在其之上可实现的最佳答案。 每个转变都是$O(1)$，所以整棵树都是在线性时间内处理的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^2)$|$O(1)$额外 | 太慢了 |
 | DFS DP |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们以 1 为树根，并执行 DFS，同时沿当前路径携带两个值：交替前缀值和当前节点的最佳答案。 

1. 我们为根分配一个初始交替值，等于$a_1$，因为长度为 1 的路径没有交替。 
2. 我们还将根的最佳值初始化为$a_1$，因为这是从根开始的唯一可能的段。 
3. 在 DFS 期间，从父母处搬走时$v$给一个孩子$u$，我们计算交替值$u$通过翻转父贡献的符号并添加$a_u$。 这可以沿路径保持正确的交替结构。 
4. 对于每个节点$u$，我们还通过考虑扩展来自父级的最知名前缀信息并将其与从新开始进行比较来计算候选答案$u$。 
5. 答案为$u$是这些可能性中的最大值，并且在继续深入之前将其存储。 
6. 我们将交替前缀值和最佳答案传播给子树，以便每个子树都建立在正确的历史基础上。 

重要的设计选择是我们从不向上重新计算任何内容。 节点所需的每个值都已编码在从其父节点传递的状态中。 

### 为什么它有效

 沿着任何根到节点的路径，以节点结束的每个有效交替线段完全对应于在其祖先中选择切割位置。 DFS 状态将所有这些前缀计算压缩为两个运行值：一个跟踪在当前节点结束的交替总和，另一个跟踪迄今为止在该路径上看到的最佳段。 因为每个节点都被访问一次，并且其状态仅取决于其父节点的状态，所以不会错过任何候选段，也不会重复计算任何段。 

## Python 解决方案```python
import sys
sys.setrecursionlimit(10**7)
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = [0] + list(map(int, input().split()))
        
        g = [[] for _ in range(n + 1)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            g[u].append(v)
            g[v].append(u)
        
        ans = [0] * (n + 1)
        
        def dfs(v, p, cur_alt, best_up):
            ans[v] = best_up
            
            for u in g[v]:
                if u == p:
                    continue
                # child alternation: flip sign relative to parent path
                next_alt = a[u] - cur_alt
                
                # best value either starts new at u or extends path
                next_best = max(a[u], a[u] - cur_alt, best_up)
                
                dfs(u, v, next_alt, next_best)
        
        dfs(1, -1, a[1], a[1])
        print(*ans[1:])

if __name__ == "__main__":
    solve()
```DFS 有两个状态。 第一个，`cur_alt`，表示以当前节点结束的完整路径的交替和。 第二个，`best_up`，表示从根到当前节点的路径上某处结束的最佳交替段。 

当移动到一个孩子时，我们通过计算翻转符号结构`a[u] - cur_alt`。 这是有效的，因为交替和定义在每个深度都会改变奇偶校验。 该转换保持了符号的一致性，而无需明确跟踪深度奇偶性。 

表达式为`next_best`考虑三种可能性：在子级开始一个新的段，扩展包含父级贡献的段，或者继承上面已经看到的最佳答案。

 ## 边缘情况

 线性链是最敏感的情况，因为每个节点都依赖于一长串交替翻转。 DFS 状态确保了正确性，因为每个节点只从其父节点接收一次更新，从而保留完整的历史记录而无需重新计算。 

根号为 1 的星号完全孤立了孩子们。 每个孩子的答案仅取决于根状态以及`best_up`确保分支机构之间不交叉污染。 

均匀数组强调该算法不依赖于幅度差异，而是依赖于交替结构，因为相同的值仍然会根据深度奇偶性产生不平凡的交替和。
