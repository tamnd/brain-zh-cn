 ## 解决方案
 ## 问题理解

 我们正在一个非常大的矩形网格上行走，从左上角的单元格开始，尝试到达右下角的单元格。 在每一步中，我们可以沿四个基本方向之一移动一个单元格，但有一个限制：我们不允许在两个连续移动中重复相同的方向。 因此，如果我们向右移动，下一步不可能也是正确的，但只要我们留在网格内，其他三个方向中的任何一个都是允许的。 

任务是计算从起点到目的地所需的最少移动次数，或者确定这是不可能的。 

网格大小的约束是极端的，两个维度都高达 10^9，并且最多有 1000 个测试用例。 任何直接模拟运动或探索网格上状态的方法都是不可能的。 即使每个单元格存储任何内容也是不可能的，因此解决方案必须将问题简化为每个测试用例的恒定时间公式。 

在一些微妙的边缘情况下，天真的推理会失败。 当网格是1乘1时，不需要移动。 当一维为 1 时，强制沿直线移动，但禁止在同一方向上连续移动的限制在某些情况下可能会导致遍历变得不可能。 例如，在 1 x 3 网格中，需要连续向右移动两次，但这是不允许的，因此答案为 -1。 另一个微妙的情况是，当两个维度都很小时，例如 2 x 2 或 2 x 3，需要来回移动才能在不重复方向的情况下进行，如果我们假设单调移动，天真的最短路径直觉就会被打破。 

## 方法

 强力解释将网格视为一个图表，其中每个状态都是一个单元格以及最后采取的方向。 从给定的状态，我们尝试所有有效的下一步动作并运行 BFS 来找到最短路径。 这是正确的，因为每次移动都有相同的成本，并且在状态定义中强制执行方向约束。 然而，状态的数量与 n × m × 4 成正比，并且当 n、m 达到 10^9 时，该图太大而无法构建或探索。 

关键的观察结果是，最佳运动模式是高度结构化的。 因为我们不能重复方向，所以除非我们改变方向，否则长时间的单调直线跑步是不可能的。 这迫使形成锯齿形图案。 最佳路径有效地在水平和垂直移动之间交替，同时偶尔插入回溯步骤以满足方向约束。 唯一重要的是我们是否处于单行或单列（退化情况），否则需要多少步才能模拟一条类似于强制转弯的受约束曼哈顿步行的路径。 

在两个维度至少为 2 的一般情况下，我们总是可以构建一条以可预测的移动次数到达目标的路径，并且该数字仅取决于奇偶效应和总位移 (n-1, m-1)。 该限制不会增加超出恒定附加开销的复杂性，因为一旦我们不在单个行或列上，我们总是可以改变方向。 

该问题简化为一小组情况：大小为 1 × 1、1 × m、n × 1 的网格以及所有其他网格。 每个行为都不同，因为交替方向的能力取决于至少具有两个维度的自由度。

 ## 算法演练

 我们根据网格的结构减少答案。

1. 如果n和m都为1，则我们已经到达目的地，因此不需要移动。 这是唯一答案为零的情况。 
2. 如果 n 或 m 等于 1，我们就被迫只向一个方向移动。 在这种情况下，任何有效路径都需要多次重复相同的移动方向。 由于连续重复同一个方向是被禁止的，所以我们只能迈出一步，如果需要多走一步，任务就变得不可能了。 
3. 如果n和m都大于1，我们总是能够在水平和垂直移动之间交替。 最佳策略是以之字形移动，每一步始终切换方向，同时稳步减小两个坐标以达到目标。 这保证了我们可以实现曼哈顿距离 (n-1) + (m-1)，而仅需要很小的强制交替造成的开销。 由此产生的最佳长度简化为 n + m - 2 加上不需要的额外调整，因为一旦两个维度都超过 1，交替总是可行的。 

因此，答案就变成了一个直接公式，取决于我们是在退化的行或列中，还是在完整的网格中。 

### 为什么它有效

 关键的不变量是，一旦两个维度都可用，我们总是可以选择与先前方向不同的下一步行动，同时仍然朝着目标取得进展。 这意味着我们永远不会陷入需要重复禁止方向才能进步的状态。 网格不再表现得像一条线，而是表现得像一个二维系统，其中方向始终可以交替，从而使最短路径等于不受约束的曼哈顿结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    
    if n == 1 and m == 1:
        print(0)
    elif n == 1 or m == 1:
        print(-1)
    else:
        print(n + m - 2)
```实现直接反映了案例分析。 第一个分支处理琐碎的起始目标情况。 

第二个分支捕获所有单行或单列网格。 在这些情况下，任何长于一步的路径都会强制重复相同的方向，这违反了规则，因此只能到达长度为 1 的网格。 

最后的情况涵盖了至少有两行和两列的所有网格。 在这种情况下，交替水平和垂直移动总是可能的，并且最短路径与角点之间的曼哈顿距离匹配，即 n + m - 2。 

必须注意不要过度考虑一般情况下的运动约束，因为两个维度的存在保证了交替方向的自由而不会被迫重复。

## 测试用例```python
import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline
    
    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        if n == 1 and m == 1:
            out.append("0")
        elif n == 1 or m == 1:
            out.append("-1")
        else:
            out.append(str(n + m - 2))
    return "\n".join(out)

 ## 边缘情况

 对于 1 × m 的情况，考虑输入 n = 1，m = 5。算法将其分类为不可能。 从 (1,1) 开始，唯一可能的方向是正确的。 向右移动一次后，禁止再向右移动，所有其他移动均离开网格。 BFS 式的推理立即陷入死胡同，并且输出正确地变为 -1。 

对于 1 by 1 的情况，算法返回 0。状态已经到达目的地，因此不需要转换，也不会触发约束。 

对于 2 x 2 网格，算法返回 2。有效序列是向右然后向下，到达 (2,2)。 尽管方向不能重复，但交替自然就满足了约束。 

对于 4 x 6 等较大的网格，算法返回 8，并且交替构造确保每一步都是可行的，因为总是有一个未使用的可用方向，可以继续朝着目标前进，同时尊重最后的移动约束。
