 ## 解决方案
 ## 问题理解

 我们有一个运行时间恰好为$X$分钟。 一开始，灯泡亮着。 每分钟，乔必须切换灯泡或进入持续时间正好的睡眠阶段$L$分钟。 在睡眠期间，灯泡没有任何反应，时钟仍然正常前进。 还有一个额外的结构约束：每一分钟都必须被“使用”，这意味着每一步都会消耗一个切换动作或一个睡眠动作，而睡眠会消耗一整块时间。$L$连续分钟。 

睡眠是原子的，因为选择它会提交下一个睡眠$L$分钟完全到灯泡不活动，并且即使跨越多分钟，它也算作输出中的单个决策。 目标是确定是否存在精确持续的有效切换和睡眠序列$X$分钟并以灯泡处于开启状态结束。 如果存在这样的序列，我们必须输出切换次数和睡眠段数。 

关键的困难在于，睡眠会消耗大量时间，而切换会消耗一分钟的时间，并且每次都会翻转状态。 这在切换奇偶性和睡眠块占用时间线的多少之间创建了组合约束。 

约束条件很大，最多$10^5$测试用例和值高达$10^9$，所以任何解都必须是$O(1)$或每个测试用例的摊销常数。 任何模拟每分钟的方法都是不可能的。 

奇偶校验和可行性相互作用产生了微妙的边缘情况。 例如，如果$L = 5$和$X = 5$，我们可以睡眠一次或尝试切换。 睡眠一次会产生零切换并以相同的状态结束，因此有效。 但如果$X = 5$我们尝试切换5次，灯泡熄灭，因此无效。 许多错误的解决方案仅通过检查是否$X$可以表示为以下的线性组合$1$和$L$，忽略切换奇偶校验。 

当在不考虑奇偶校验的情况下尝试贪婪地减去睡眠时，会发生另一种失败情况：进行过多的睡眠可能会强制切换不可能的剩余奇偶校验。 

## 方法

 蛮力观点是考虑每一个可能的行动序列$X$分钟，其中每分钟要么是一个切换，要么是一个长度睡眠块的开始$L$。 这相当于将时间线的所有分区探索为大小为 1（切换）和大小的片段$L$（睡觉）。 这很快就会变成指数级的，因为在每个位置我们都会分为两个选择，并且睡眠会跳跃多个步骤。 

这种简化来自于将过程压缩为计数。 假设我们使用$N$睡眠片段。 他们消费$N \cdot L$分钟。 剩余时间充满了切换，因此切换次数为$M = X - N \cdot L$。 这立即迫使$M \ge 0$。 

唯一剩下的条件是灯泡的最终状态。 每个开关都会翻转灯泡，我们从 ON 开始，所以之后$M$切换灯泡打开当且仅当$M$是均匀的。 因此，整个问题简化为寻找一个非负整数$N$这样$X - N L \ge 0$和$X - N L$是均匀的。 

这是一个简单的模块化约束。 我们搜索任何$N$满意的$X \equiv NL \pmod{2}$。 由于只有奇偶校验很重要，因此我们将所有内容都以 2 为模进行减少。如果$L$是偶数，那么$NL$总是偶数，所以$X - NL$具有相同的奇偶性$X$。 这意味着我们需要$X$甚至。 如果$X$很奇怪，不可能。 如果$X$是偶数，我们可以取$N = 0$和$M = X$。 

如果$L$是奇数，那么$NL \equiv N \pmod{2}$。 所以我们需要$X - N \equiv 0 \pmod{2}$，这意味着$N \equiv X \pmod{2}$。 我们可以选择任何可行的$N$在范围内$0 \le N \le X / L$具有匹配的奇偶校验。 如果$X / L$足够大，这样$N$始终存在，除非范围太小而无法适应奇偶校验调整。 

我们选择最大的$N = \lfloor X/L \rfloor$并最多向下调整 1 以修复奇偶校验。 然后计算$M = X - NL$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力模拟 |$O(X)$每次测试 |$O(1)$| 太慢了 |
 | 奇偶校验减少 |$O(1)$每次测试 |$O(1)$| 已接受 |

 ## 算法演练

 我们独立处理每个测试用例并构造任何有效的对$(M, N)$。 

1. 计算可以容纳多少个完整睡眠块$X$， 环境$N = \lfloor X / L \rfloor$。 这在不超过时间的情况下提供了最大可能的睡眠次数。 
2. 检查是否使用$N$sleeps 产生有效的切换计数$M = X - N \cdot L$。 如果$M \ge 0$，我们只需要验证是否$M$是均匀的。 
3.如果$M$是偶数，我们输出$(M, N)$直接地。 这是有效的，因为该过程恰好在时间结束$X$，并且奇偶校验条件确保灯泡打开。 
4. 如果$M$很奇怪，我们尝试减少$N$由 1 提供$N > 0$。 这翻转了奇偶校验$M$什么时候$L$很奇怪，并且保留了可行性，因为我们仍然停留在总时间内。 
5. 如果递减后$N$我们仍然得到$M < 0$，则不存在解。 这对应于即使单个有效睡眠调整也不能同时满足时间和奇偶校验约束的情况。 
6. 如果调整不起作用，则输出$-1 -1$。 

该结构总是首先尝试最大化睡眠使用，因为睡眠是唯一不翻转灯泡状态的机制。 然后强制切换来填充剩余时间，因此奇偶校验是唯一真正的约束。 

### 为什么它有效

 整个系统崩溃为两个不变量：总消耗时间必须等于$X$，灯泡状态仅取决于切换次数的奇偶校验。 睡眠不会影响状态，但会以固定的时间块贡献时间。 任何有效的时间表都唯一对应于一对$(M, N)$，并且任何这样的对都通过将所有睡眠放在第一位或以任何顺序放置来确定有效的调度，因为它们是状态中立的段。 该算法搜索唯一重要的自由度，即之间的奇偶兼容性$X - NL$和零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        L, X = map(int, input().split())

        n = X // L
        m = X - n * L

        if m % 2 == 0:
            out.append(f"{m} {n}")
            continue

        if n > 0:
            n -= 1
            m = X - n * L
            if m >= 0 and m % 2 == 0:
                out.append(f"{m} {n}")
                continue

        out.append("-1 -1")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该代码直接实现了贪婪选择，即获取尽可能多的睡眠块，然后在需要时通过减少一次睡眠来纠正奇偶校验。 关键细节是调整后重新计算剩余的切换计数$N$，因为更改睡眠计数会更改剩余时间，从而更改切换的奇偶校验。 

每个测试用例的所有算术都是恒定时间，考虑到较大的约束，这是必要的。

 ## 边缘情况

 当$X < L$，不可能有睡眠，解决方案必须完全依赖于切换。 算法正确设置$N = 0$， 制作$M = X$，并直接检查奇偶性。 如果$X$很奇怪，它正确地拒绝了这种情况，因为灯泡会熄灭。 

什么时候$L = 1$，从时间粒度上来说，每次睡眠都相当于一次空操作，问题就简化为选择多少个睡眠$X$分钟被视为睡眠与切换。 奇偶条件仍然决定着可行性，贪婪调整$N$自然地处理它。 

什么时候$X$非常大并且可以被整除$L$，算法最初最大化$N$，那么最多只调整一步，确保正确性，而不需要对多个候选进行迭代。
