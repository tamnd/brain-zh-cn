 ## 解决方案
 ## 问题理解

 对于每个测试用例，我们有三个正整数 (A)、(B) 和 (C)。 我们首先将 (A) 和 (B) 相加，然后将该总和除以 (C)。 所需的输出是结果的十进制表示形式，小数点后正好 50 位。 如果精确的十进制扩展继续超出这 50 位数字，则第 50 位数字之后的所有内容都将被丢弃而不是四舍五入。 

这些数字最多可以包含 50 个十进制数字，因此普通机器大小的整数类型在具有固定宽度整数的语言中是不够的。 输入最多可以包含 (10^4) 个测试用例，这也排除了运行时间取决于 (A)、(B) 或 (C) 数值的算法。 在 Python 中，任意精度整数使数字的大小易于管理，但我们仍然希望每个测试用例的工作量不变。 由于输出本身始终包含 50 个小数位，因此每个情况执行 (O(50)) 长除法步骤的算法是一个自然目标。 

在某些情况下，看似合理的实施可能会失败。 第一个是精确的整数结果。 例如，使用输入```
1
1 3 2
```答案是```
2.00000000000000000000000000000000000000000000000000
```简单打印整数商的程序忘记了输出必须始终包含小数点后的 50 位数字。 

第二个问题是截断而不是四舍五入。 例如，```
1
1 1 6
```代表 (1/3)，因此所需答案以 50 个数字 3 的副本开始：```
0.33333333333333333333333333333333333333333333333333
```浮点转换后进行格式化可能会引入舍入，更重要的是，浮点数无法准确表示任意 50 位整数输入或 50 位小数。 

第三个问题是小数部分可能包含前导零。 为了```
1
1 1 100
```该值为 (0.02)，因此输出必须为```
0.02000000000000000000000000000000000000000000000000
```这些零是 50 位小数字段的一部分，无法删除。 

最后，第 50 位数字本身必须保留。 和```
1
1 1 99999999999999999999999999999999999999999999999999
```分子是 2，分母恰好有 50 个 9。 第一个非零小数位出现在位置 50，因此小数部分以`2`。 仅生成 49 位数字的实现存在差一错误。 

## 方法

 小数除法的直接强力解释将重复减去分母以确定每个商位。 对于整数部分，找到一位商数可能需要最多 (C) 次减法。 每个小数位都会出现同样的问题。 对于 50 个小数位置，这可能需要对一个测试用例进行 (O(50C)) 减法。 由于 (C) 几乎可以是 (10^{50})，最坏的情况是在一种情况下进行 (5 × 10^{51}) 次减法，对于 (10^4) 种情况，理论总数达到约 (5 × 10^{55})。 该方法在数学上是有效的，但输入的数值大小使其完全不切实际。 

有用的观察是十进制除法不需要通过减法来搜索每个数字。 普通的长除法已经准确地告诉我们要做什么。 首先使用整数除法计算整数商。 除法之后的余数包含小数部分所需的所有信息。 

假设当前余数为(r)。 要获得下一个十进制数字，请将 (r) 乘以 10 再除以 (C)。 商正好是下一个数字，新的余数就是剩下的数。 重复此过程 50 次即可精确生成小数点后的前 50 位数字。 

其工作原理与手动长除法工作的原因相同。 如果当前余数代表数字的未解析部分，则将其乘以 10，将该未解析部分向左移动一位小数。 除以 (C) 即可提取下一个数字，而无需使用浮点运算。 

这两种方法可以进行如下比较。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(50C)) | (O(1)) | (O(1)) | 太慢了|
 | 长除法 | 每个测试用例的 (O(50)) 大整数运算 | (O(1)) 除了输出 | 已接受 |

 ## 算法演练

 1. 读取(A)、(B)和(C)，并计算(N=A+B)。 Python 的整数类型可以准确地处理结果值，即使它最多可以包含 51 位数字。 
2. 计算整数部分`N // C`。 这给出了小数点之前的所有内容。 
3. 计算初始余数`N % C`。 部门身份
 [
 N = (\lfloor N/C\rfloor)C + (N\bmod C)
 ]
 告诉我们这个余数正是构造小数位所需的部分。 
4. 重复以下操作 50 次。 将当前余数乘以 10，然后除以 (C)。 商是下一个小数位。 存储该数字，然后用除法余数替换余数。 

如果余数为零，则后面的每个数字也为零。 我们仍然可以执行所有 50 次迭代，这使实现变得简单并保证了所需的输出长度。 
5. 将生成的 50 个数字转换为字符串，并将整数部分、小数点和小数字符串连接起来。 由于恰好生成了 50 位数字，因此输出始终具有所需的格式。 

### 为什么它有效

 整数除法后，我们有 (N=qC+r)，其中 (q) 是整数部分，并且 (0\le r<C)。 小数部分为(r/C)。 在任何小数步中，假设当前余数为 (r)。 然后

 \压裂{\lfloor 10r/C\rfloor}{10}
 +
 \frac{(10r\bmod C)}{10C}。 
]

 第一项给出了下一个小数位，而第二项的形式与我们开始的分数问题完全相同，只是有一个新的余数。 因此，每次迭代都保留相同的不变量：生成的数字恰好是原始分数的前导十进制数字，而存储的余数代表尚未生成的所有内容。 50次迭代后，存储的数字正是前50位小数位，这正是所请求的截断结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        a, b, c = map(int, input().split())
        n = a + b

        integer_part = n // c
        remainder = n % c

        digits = []

        for _ in range(50):
            remainder *= 10
            digit = remainder // c
            remainder %= c
            digits.append(str(digit))

        out.append(f"{integer_part}." + "".join(digits))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```前两个算术运算实现步骤 2 和 3 中的整数部分和初始余数。它们必须在生成小数位之前执行，因为 (A+B) 除以 (C) 后的余数是长除法的精确起始状态。 

在 50 次迭代循环中，`remainder *= 10`执行小数点移位。 整数除以`c`提取下一个数字，并且`% c`为下一次迭代保留新的余数。 顺序很重要：在将余数替换为之前，必须从相乘的余数中获得数字`% c`。 

解决方案中的任何地方都没有出现浮点运算。 这可以避免精度损失和意外舍入。 Python 在这里也没有固定的 32 位或 64 位溢出问题，因此接近 (10^{50}) 的值会被准确处理。 

即使余数为零，循环也会运行 50 次。 那是故意的。 提前停止需要单独用零填充结果，而固定迭代计数直接给出所需的 50 位小数部分。 

决赛`sys.stdout.write`收集所有答案并将它们写在一起。 对于最多 (10^4) 个测试用例，这比单独重复打印每个结果更好。

 ## 边缘情况

 对于精确除法，例如```
1
1 3 2
```我们得到（N=4），`integer_part = 2`， 和`remainder = 0`。 每次小数迭代都会将零乘以 10 并提取数字零。 结果正是`2.00000000000000000000000000000000000000000000000000`。 不需要特殊情况，因为余数不变量自然可以处理它。 

对于带有前导小数零的分数，```
1
1 1 100
```我们有 (N=2)，因此整数部分为零，初始余数为 2。第一次迭代计算 (20//100=0)，产生第一个小数位`0`。 第二个计算 (200//100=2)，产生`2`。 然后余数变为零，因此剩余 48 位数字为零。 最终的答案是`0.02000000000000000000000000000000000000000000000000`。 

对于涉及第 50 位数字的边界，```
1
1 1 99999999999999999999999999999999999999999999999999
```分子为 2，分母为 (10^{50}-1)。 对于前 49 次迭代，将余数乘以 10 仍然会得到小于分母的值，因此每个提取的数字都为零。 在第 50 次迭代中，余数变为 (2\cdot10^{49})，将其乘以 10 得到 (2\cdot10^{50})。 除以 (10^{50}-1) 会产生数字 2，新的余数为 2。该算法恰好执行 50 次迭代，因此最终`2`被保留，并且它之后的所有内容都被正确截断。 

对于循环小数，例如```
1
1 1 6
```初始余数为 2。每次迭代都会将其乘以 10，提取 (20//6=3)，并再次留下余数 2。 状态返回完全相同的余数，因此生成的 50 个数字中每一位都是 3。结果是`0.33333333333333333333333333333333333333333333333333`，不进行舍入。 

对于最大尺寸值，Python 的任意精度整数允许相同的操作而不会溢出。 如果(A)和(B)都是49位数字，它们的和可以有50位，商和余数运算仍然准确。 该算法取决于位数，而不是重复迭代到 (C) 的数值，这使得它适合给定的边界。
