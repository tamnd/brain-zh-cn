 ## 解决方案
 ## 问题理解

 我们收到了一系列敌人的攻击波。 每个波都有两个参数：每秒的伤害率和持续时间。 如果玩家选择级别ℓ，则每波都会通过从其伤害率中减去ℓ来削弱，但永远不会低于零。 因此，第 i 波每秒仅造成 max(0, dᵢ − ℓ) 伤害，持续 tᵢ 秒。 

所有波浪受到的总伤害是这些贡献的总和。 目标是找到最小等级 ℓ ，使总累积伤害严格小于给定的健康阈值 h，这意味着玩家能够生存。 

关键的计算对象是函数 D(ℓ) = Σ max(0, dᵢ − ℓ) · tᵢ。 我们不是在每个波的独立决策中进行选择，而是选择一个统一减少所有波的全局参数ℓ。 

输入大小允许最大的 n 以及较大的 dᵢ 和 tᵢ 值。 任何以简单方式重复重新计算完整损伤表达式的解决方案都需要处理每个查询的所有波。 如果我们尝试对可能的 ℓ 值进行线性扫描，直到 max(dᵢ)，这会变得太大，因为 dᵢ 可能很大，使得 O(max(dᵢ) · n) 方法不可行。 

主要的结构观察是单调性：增加 ℓ 只能减少每一项 max(0, dᵢ − ℓ)，因此 D(ℓ) 永远不会随着 ℓ 的增长而增加。 这意味着一个干净的阈值行为，一旦在某个 ℓ 下生存成为可能，所有更大的 ℓ 也都可以工作。 

一个微妙的边缘情况是当 ℓ 超过所有 dᵢ 时。 在这种情况下，每一项都变为零，因此 D(ℓ) = 0 并且生存得到了微不足道的保证。 这保证了搜索空间是有界的并且答案总是存在。 

另一个极端情况是，即使 ℓ = 0 也已经给出 D(0) < h。 那么答案是 0，二分查找必须正确地允许下界有效，而不会由于差一错误而跳过它。 

## 方法

 最直接的想法是从零开始尝试每个可能的级别 ℓ 并计算每个选择的总伤害。 对于固定的 ℓ，我们扫描所有波并计算 max(0, dᵢ − ℓ) · tᵢ，求和为总数。 这是正确的，因为它直接遵循损坏的定义。 然而，每次评估都是 O(n)，如果 ℓ 的范围达到 max(dᵢ)，则总成本变为 O(n · max(dᵢ))，当 dᵢ 很大时，这个成本就太大了。 

改进来自于认识到我们不是在优化任意函数，而是在搜索单调谓词。 条件“D(ℓ) < h”的行为是一致的：如果它对于某些 ℓ 成立，那么它对于所有更大的 ℓ 都成立。 这将问题转化为在单调递减函数中寻找阈值点。 

一旦这种结构可见，二分查找就成为自然的工具。 我们定义从 0 到 max(dᵢ) 的搜索范围。 上限就足够了，因为一旦 ℓ 达到 max(dᵢ)，所有项都消失并且损坏为零。 每次检查都会在线性时间内评估 D(ℓ)，给出评估的对数总数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n·max(dᵢ)) | O(n·max(dᵢ)) | O(1) | O(1) | 太慢了|
 | 最优（二分搜索）| O(n log max(dᵢ)) | O(n log max(dᵢ)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们想要找到最小的 ℓ，使总损坏降至 h 以下。

1. 计算所有 dᵢ 中的最大值以定义搜索空间的上限。 这是有效的，因为任何超过此点的 ℓ 都会使所有伤害贡献无效。 
2. 设置二分搜索边界，low = 0 且 high = max(dᵢ)。 我们正在一个离散的单调域上搜索。 
3. 当 low ≤ high 时，计算 mid = (low + high) // 2. 这代表候选级别。 
4. 通过迭代所有波并对 max(0, dᵢ − mid) · tᵢ 求和来评估中级的总伤害。 这直接模拟了问题定义。 
5. 如果计算出的伤害至少为 h，则 mid 不够，因此我们将其降低到 mid + 1。这是因为增加 ℓ 是减少伤害的唯一方法。 
6. 否则，mid 就足够了，因此我们将其存储为候选答案，并将高值移动到 mid − 1 以尝试找到更小的有效级别。 
7. 循环结束后，存储的候选者是最小有效ℓ。 

为什么它有效

 函数 D(ℓ) 的 ℓ 是不递增的，因为每个单独的项 max(0, dᵢ − ℓ) 都是不递增的。 这会在整数行上创建一个连续的无效值区域，后跟一个连续的有效值区域。 二分搜索通过重复丢弃一半的搜索空间，同时保留无效区域和有效区域之间的边界来利用这种结构。 该算法保持以下不变量：所有低于低值的值均无效，所有高于高值的值均有效，因此答案必须保持在区间内。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, h = map(int, input().split())
    d = []
    t = []
    mx = 0

    for _ in range(n):
        di, ti = map(int, input().split())
        d.append(di)
        t.append(ti)
        if di > mx:
            mx = di

    def damage(l):
        total = 0
        for i in range(n):
            if d[i] > l:
                total += (d[i] - l) * t[i]
                if total >= h:
                    return total
        return total

    low, high = 0, mx
    ans = mx

    while low <= high:
        mid = (low + high) // 2
        if damage(mid) >= h:
            low = mid + 1
        else:
            ans = mid
            high = mid - 1

    print(ans)

if __name__ == "__main__":
    solve()
```实现直接遵循二分查找结构。 损害函数包括一旦累积和达到 h 就提前退出，这可以防止在大情况下进行不必要的计算。 这并不影响正确性，因为我们只需要区分 D(ℓ) 是否至少为 h 即可。 

二分搜索会跟踪 ans 中的最佳有效答案。 当中间值通过条件时，我们仍然继续向左搜索以确保最小值。 

一个常见的实现陷阱是忘记提前停止条件或为所有 i 计算 (dᵢ − ℓ)，即使 dᵢ ≤ ℓ 时也是如此，这会增加不必要的操作，并且如果包含负值，则可能会出现错误累积的风险。 

## 工作示例

 考虑一个具有三波的小实例：

 n = 3，h = 10

 波： (d, t) = (5, 2), (8, 1), (3, 4)

 我们计算候选 ℓ 值。 

| ℓ | 第 1 波 | 第 2 波 | 第 3 波 | 总 D(ℓ) |
 | ---| ---| ---| ---| ---|
 | 0 | 10 | 10 8 | 12 | 12 30|
 | 2 | 6 | 6 | 4 | 16 | 16
 | 4 | 2 | 4 | 0 | 6 |
 | 5 | 0 | 3 | 0 | 3 |

 对于ℓ=2，伤害仍然在10以上，所以无效。 当 ℓ = 4 时，伤害降至 10 以下，因此它是有效的。 最小有效 ℓ 为 4。 

该迹线显示了 D(ℓ) 的单调递减，这正是二分搜索所依赖的。 

现在考虑一个生存已经很容易的情况：

 n = 2，h = 5

 (2, 10), (1, 10)

 | ℓ | 总 D(ℓ) |
 | ---| ---|
 | 0 | 30|
 | 1 | 10 | 10
 | 2 | 0 |

 这里的答案是 ℓ = 1。二分搜索将正确地收敛到伤害低于 h 的第一级附近。

 ## 边缘情况

 当 ℓ = 0 已经满足条件时，就会出现一种边缘情况。 例如，如果所有波都非常弱或者 h 很大：

 n = 2，h = 100

 (1, 1), (2, 1)

 当 ℓ = 0 时，总伤害为 3，已经低于 h。 二分查找正确地识别出中间值始终有效，因此高值缩小到零。 一旦找到有效的 mid，算法就会保持 ans = 0。 

另一种边缘情况是最优 ℓ 等于 max(dᵢ) 时。 例如：

 n = 2，h = 1

 (3, 1), (3, 1)

 当 ℓ = 2 时，损伤仍为正； 当 ℓ = 3 时，所有贡献都消失了。 二分查找必须包含 high = max(dᵢ)，否则正确的边界点将被排除。
