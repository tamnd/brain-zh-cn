 ## 解决方案
 ## 问题理解

 任务是在已经给出三边的情况下确定四边形第四边的可能长度。 每个输入案例提供三个整数，表示三个现有栅栏段的长度。 我们需要输出第四段的单个整数长度，以便可以形成一个简单的非退化四边形。 

简单四边形不能有三个共线点，也不能与自身相交。 实际上，这意味着任何三边之和必须严格大于第四边，这是推广到四边形的广义三角形不等式。 由于问题保证解始终存在，因此我们可以自由选择满足此不等式的第四边的任何值。 

输入限制适中。 测试用例数量最多为 1000 个，边长最多为 10^9。 尝试第四边的所有可能值的简单解决方案效率极低，但直接的数学计算是每个测试用例的恒定时间，这已经足够了。 

当三个给定边相对于彼此极小或极大时，就会出现边缘情况。 例如，如果边是`1, 1, 1`，第四边不能大于 3，但 1 到 3 之间的任何值都可以。 粗心的方法可能会选择零或负数，这是无效的。 另一种情况是当边很大时，例如`10^9, 10^9, 10^9`。 第四边最多必须是`3*10^9 - 1`保持非退化四边形。 

## 方法

 蛮力方法是迭代所有整数并检查每个整数是否可能是四边形。 这是可行的，因为我们可以测试所有四个边的三角形不等式。 然而，这是不必要的，并且对于大边长来说速度太慢； 对每个测试用例从 1 迭代到 10^9 是不可行的。 操作次数可能达到10^12，这超出了1秒时间限制的实际限制。 

关键的见解是对于任何三边`a, b, c`，有一个简单的第四边选择可以保证非退化四边形。 一个简单的选择是`d = a + b - c`（假设`a + b > c`），满足所有循环排列中的三角形不等式。 我们还可以选择`d = max(a, b, c)`为了简单起见； 严格介于 1 和其他三边之和之间的任何值都有效。 这将问题简化为每个测试用例的恒定时间计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(最大(a,b,c)) | O(1) | O(1) | 太慢了 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 每个测试用例由三个代表栅栏长度的整数组成。 
2. 对于每个测试用例，读取三个整数`a`,`b`,`c`。 
3.为第四边选择一个简单的值`d`。 一个安全的选择是`d = a + b - 1`。 这确保了`d`严格为正且严格小于`a + b + c`，它保持一个非退化的四边形。 
4. 打印`d`对于当前的测试用例。 
5. 对所有测试用例重复此操作。 

这样做的原因是任何小于其他三边之和的正整数都会形成一个有效的四边形。 的选择`d = a + b - 1`保证积极性和非堕落性。 我们正在利用只要最大边小于其他三边之和就存在四边形的性质，并且通过选择稍小于现有任意两条边之和的第四边，我们可以轻松地满足该性质。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c = map(int, input().split())
    d = a + b - 1
    print(d)
```该解决方案使用有效地读取所有输入`sys.stdin.readline`。 对于每个测试用例，它使用直接算术表达式计算第四边。 我们避免边界问题，因为`a, b >= 1`， 所以`a + b - 1`总是积极的。 使用此公式可以保证任何满足约束的输入都是有效的四边形。 不需要明确检查不等式，因为问题确保存在解，并且我们的选择满足一般四边形条件。

 ## 边缘情况

 用于输入`1 1 1`，算法计算`d = 1 + 1 - 1 = 1`。 得到的四边形有边`1, 1, 1, 1`，这是有效且非退化的。 

用于输入`10^9 10^9 10^9`，算法计算`d = 10^9 + 10^9 - 1 = 1999999999`。 该值小于其他三边之和，因此所有不等式成立。 

用于输入`10 1 1`，算法计算`d = 10 + 1 - 1 = 10`。 侧面`10, 1, 1, 10`满足四边形条件，确认即使是极端的边长比也能正确处理。
