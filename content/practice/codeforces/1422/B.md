 ## 解决方案
 ## 问题理解

 给定一个由整数大小组成的矩形网格$n \times m$，我们想将它转换成一个“好的”矩阵。 如果矩阵的每一行和每一列向前和向后读取相同，这意味着它们是回文，那么矩阵就很好。 例如，一行`[1, 2, 3, 2, 1]`是回文，列也是回文`[4, 7, 7, 4]`。 

唯一允许的操作是将单个元素递增或递减 1。目标是找到使矩阵良好的此类操作的最小数量。 输入给出多个测试用例，每个测试用例指定矩阵维度和矩阵本身。 输出是每个测试用例的最小操作数。 

限制因素$1 \le n, m \le 100$意味着矩阵足够小$O(n \cdot m)$解决方案，但对于类似的东西来说太大了$O((n \cdot m)^2)$如果它涉及迭代所有可能的转换。 每个矩阵元素可以大到$10^9$，因此我们必须避免随元素值缩放的操作。 

边缘情况是具有单行或单列的矩阵。 在这些情况下，使行或列成为回文可能需要调整多个元素以匹配其镜像对应项。 例如，一个`1x5`矩阵`[1, 3, 5, 3, 2]`应该成为`[1, 3, 5, 3, 1]`对最后一个元素使用 1 次操作。 幼稚的方法可能会忽略行和列之间的对称性以及错误地重复计数更改。 

另一个微妙的情况是两个维度均为奇数的矩阵，例如`3x3`。 中心元素是所有回文约束共享的，但它只需要匹配自身，因此可以不需要对其进行任何操作。 

## 方法

 暴力方法将尝试递增或递减每个元素，直到所有行和列都是回文。 这在原则上是正确的，但太慢了，因为它可能需要最多$10^9$每个元素的操作，这是不可行的。 

更好的方法利用对称性。 每个元素在矩阵中最多有四个对称对应项：水平镜像、垂直镜像或两者。 例如，在一个`4x4`矩阵、元素`(0,0)`必须匹配`(0,3)`,`(3,0)`， 和`(3,3)`。 关键的见解是这四个数字必须在最少的步骤数中相等。 执行此操作的最佳方法是将所有四个数字更改为其中位数，因为与中位数的绝对差之和最小化。 

通过仅迭代矩阵的左上象限并收集每组四个镜像元素，我们可以计算每组的最小操作数并对它们求和。 如果$n$或者$m$是奇数，某些组只有两个对称元素（在中间行或列）或单个元素（矩阵中心），我们使用较小组的中位数进行类似处理。 

这减少了处理问题$\lceil n/2 \rceil \cdot \lceil m/2 \rceil$每个组最多包含四个数字，这样速度很快并且可以确保最优性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m * 最大元素) | O(n * m) | 太慢了 |
 | 最优（对称性 + 中值）| O(n * m) | O(1) 额外 | 已接受 |

 ## 算法演练

 1. 使用索引迭代矩阵`i`从`0`到`(n-1)//2`和`j`从`0`到`(m-1)//2`。 这确保我们只访问左上象限并处理每个对称组一次。 
2. 对于每个位置`(i, j)`，识别对称元素：`(i,j)`,`(i, m-j-1)`,`(n-i-1, j)`,`(n-i-1, m-j-1)`。 将它们的值收集到一个列表中。 
3. 对列表进行排序并计算中值。 对于四个元素，中位数是排序后的第二个或第三个元素，这可以最小化绝对差之和。 
4. 将组中每个元素与中位数之间的绝对差值相加。 这给出了该组所需的最少操作数。 
5. 累加所有组的总和。 如果`n`或者`m`是奇数，类似地处理中心行和列，但某些组将只有两个元素或单个元素。 
6. 打印总和作为测试用例的答案。 

原理：矩阵中的每个元素都属于一个对称组，该对称组决定其最终值。 通过始终选择每组的中位数，我们可以保证操作总数最少，因为将所有值更改为中位数可以最小化绝对差值之和。 这保留了行和列的回文性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_operations_to_nice(matrix, n, m):
    ops = 0
    for i in range((n + 1) // 2):
        for j in range((m + 1) // 2):
            group = [
                matrix[i][j],
                matrix[i][m - j - 1],
                matrix[n - i - 1][j],
                matrix[n - i - 1][m - j - 1]
            ]
            group = list(set(group)) if i == n - i - 1 or j == m - j - 1 else group
            group.sort()
            median = group[len(group) // 2]
            ops += sum(abs(x - median) for x in group)
    return ops

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    matrix = [list(map(int, input().split())) for _ in range(n)]
    print(min_operations_to_nice(matrix, n, m))
```该代码读取所有测试用例，仅迭代矩阵的左上象限，计算对称组，并使用中值来最小化运算。 有条件的`list(set(group))`当维度为奇数时处理中心行/列重复，避免重复计数。 累积并打印绝对差值之和。
