 ## 解决方案
 ## 问题理解

 问题给出了一个数字$n$不是十进制形式，而是某种任意基数$b$。 的数字为$n$从最重要到最不重要的顺序列出，任务是决定是否$n$小数为偶数或奇数。 例如，如果基数为 13，位数为 [3, 2, 7]，则$n$是$3\cdot13^2 + 2\cdot13 + 7 = 540$，这是偶数。 

约束允许最多$10^5$数字，每个数字可以大到 99（因为$b \le 100$）。 计算完整的十进制数是不可能的，因为$n$可能是天文数字般大，远远超出标准整数限制。 这排除了任何尝试直接计算的方法$n$然后检查其奇偶性。 

当只有一位数字或基数为偶数时，就会出现边缘情况。 对于单位数，奇偶校验仅由该数字确定。 对于较大的数字，基数和数字之间的奇偶性之间的相互作用很重要，因为奇数或偶数乘以基数的幂可以以可预测的方式影响最终的奇偶性。 

粗心的方法会尝试计算$n$直接或在错误的点减少模 2。 例如，对乘积求和$a_i \cdot b^{k-i}$不考虑模运算会溢出。 另一个微妙的情况是当基数为偶数时：那么除最后一项之外的所有项都保证为偶数，因此只有最后一位数字很重要。 这一观察至关重要。 

## 方法

 暴力方法将构建$n$通过求和$a_1 \cdot b^{k-1} + a_2 \cdot b^{k-2} + \dots + a_k$。 这适用于小型$k$和$b$，但与$k$最多$10^5$，这种方法需要重复乘以非常大的数字。 即使使用模运算来减少模 2，它仍然需要迭代所有数字和计算能力$b$，这是不必要的。 

最佳方法利用模运算和奇偶校验属性。 一个数是偶数，如果它能被 2 整除，可以通过模 2 来确定。观察偶数底的任何幂都是偶数，所以当$b$是偶数，除最后一位之外的所有数字都乘以偶数，贡献 0 模 2。仅最后一位数字$a_k$影响奇偶性。 什么时候$b$是奇怪的，每一个力量$b$很奇怪。 因此，每一项贡献$a_i \cdot 1 \mod 2 = a_i \mod 2$，所以奇偶性为$n$是所有数字的模 2 之和。 

这种见解将问题简化为检查最后一位数字（偶数基数）或对所有数字求和模 2（奇数基数）。 无论如何，强力方法都会迭代数字，但最佳方法只对每个数字执行一次简单的模运算，完全避免大整数运算。

 | --- | --- | --- | --- |
 | 蛮力 | O(k log n) | O(k log n) | O(1) | O(1) | 由于数量巨大，速度太慢 |
 | 最佳| O(k) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读基础`b`和位数`k`。 这些定义了给定基数中数字的结构。 
2. 阅读`k`将数字放入列表中`a`。 它们按从最重要到最不重要的顺序排列。 
3. 检查是否`b`是均匀的。 如果是的话，那么每一个力量`b`大于零是偶数。 因此，除了最后一位数字之外的所有贡献都与奇偶校验无关。 
4. 如果`b`是偶数，如果最后一位数字则打印“偶数”`a[-1]`是偶数，否则打印“奇数”。 
5.如果`b`是奇数，迭代所有数字并计算模 2 的总和。如果总和可被 2 整除，则打印“even”； 否则打印“奇数”。 

工作原理：当对模 2 进行约减时，乘以偶数会得到 0，因此只有乘以奇数底的奇次方的数字才会起作用。 该算法保持了当前模 2 和准确反映每一步整个数的奇偶性的不变性。 这可以确保正确性，而无需计算完整值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

b, k = map(int, input().split())
a = list(map(int, input().split()))

if b % 2 == 0:
    print("even" if a[-1] % 2 == 0 else "odd")
else:
    total = sum(a) % 2
    print("even" if total == 0 else "odd")
```该解决方案首先使用有效地读取输入`sys.stdin.readline`。 它立即检查基本奇偶校验。 对于偶数碱基，仅检查最后一位数字，这避免了不必要的计算。 对于奇数基数，它将所有数字以 2 为模求和，确保结果与数字的奇偶性匹配，而无需构造完整的整数。 通过正确索引最后一位数字可以避免差一错误`a[-1]`。 

## 工作示例

 样本1：`13 3`带数字`[3, 2, 7]`。 

| 步骤| 描述 | 价值|
 | --- | --- | --- |
 | 读 b、k | 基数 13，3 位数字 | b=13，k=3 |
 | 读取数字 | 数字列表 | a=[3,2,7] | a=[3,2,7] |
 | 检查 b 奇偶校验 | 13 是奇数 | 求和(a) % 2 = (3+2+7)%2 = 12%2 = 0 |
 | 输出| 甚至| “偶数”|

 这表明，当基数为奇数时，对所有数字求和模 2 可以正确确定奇偶校验。 

样本2：`2 5`带数字`[1, 0, 0, 1, 1]`。 

| 步骤| 描述 | 价值|
 | --- | --- | --- |
 | 读 b、k | 以 2 为基数的 5 位数字 | b=2，k=5 |
 | 读取数字 | 数字列表 | a=[1,0,0,1,1] | a=[1,0,0,1,1] |
 | 检查 b 奇偶校验 | 2 是偶数 | 最后一位数字 a[-1] = 1 -> 奇数 |
 | 输出| 奇数| “奇怪”|

 这表明对于偶数碱基，只有最后一位数字很重要。
