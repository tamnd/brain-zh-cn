 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，表示一行石子上的电荷。 单个操作选择任何内部位置并使用其两个邻居替换其值：新值变为左右邻居之和减去其旧值。 端点永远不会被直接修改。 

任务是确定是否可以使用任意数量的此类操作将初始数组转换为相同长度的目标数组。 

关键是操作不会引入外部值，它们只是通过固定的线性规则混合现有的值。 这立即表明系统的行为就像整数数组空间上的线性变换，问题就变成两个向量是否位于相同的可达等价类中。 

n 最大为 10^5 的约束意味着我们无法模拟操作。 每个操作都会涉及 O(1) 个元素，因此即使是 10^9 次操作也是不可能的。 我们需要一个仅依赖于不变量的表征。 

当局部变换看起来很强大但不能影响某些全局结构时，就会出现微妙的边缘情况。 例如，如果数组是常量，则任何操作都会使其保持常量，因此不可能达到非常量目标。 另一个隐藏的情况是，小的局部变化似乎可以自由地修改值，但实际上保留了朴素模拟可能会错过的更深层次的不变量。 

例如，当 n = 3 时，从 [1, 2, 3] 开始，索引 2 处的一次操作给出 [1, 4, 3]，再次应用给出 [1, 2, 3]。 中间值振荡，但端点从未改变，显示出很强的结构性约束。 

## 方法

 暴力方法将尝试模拟所有可能的操作序列，本质上是探索一个状态图，其中每个节点都是一个数组，边是有效的操作。 每个状态都有 n 个可能的动作，从而导致指数增长。 甚至存储状态也变得不可行，因为值是无界整数。 

关键的观察结果是每个操作都是线性的：它将 c[i] 替换为 c[i-1] + c[i+1] - c[i]。 这可以重写为保留某些线性不变量的向量更新。 特别是，该操作保留了元素之和以及从二阶差分导出的加权交替结构。 

一个更有用的视角是看待差异。 如果我们定义 d[i] = c[i+1] - c[i]，则该操作仅修改局部结构，但保留直到符号为止的多重差异集。 更准确地说，它保留了二阶差分模式传播的绝对值，这导致了更强的不变量：一阶差分的序列直到反转在操作下是不变的。 

这意味着一个简单的表征：当且仅当差异数组与全局反转对齐匹配时，或者等效地，如果一个数组可以通过重复“重新分布曲率”而不改变边界行为而将一个数组转换为另一个数组，则该转换是可能的。 实际上，这减少了检查对齐后差异数组是否相同。 

我们可以通过比较差异序列并确保它们完全匹配，将其形式化为确定性检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 指数| 每个状态 O(n) | 太慢了 |
 | 差异不变检查 | O(n) | O(n) | 已接受 |

 ## 算法演练

1. 计算初始配置的差异数组，其中 diff_c[i] = c[i+1] - c[i]。 这捕获了阵列的所有局部斜率。 
2. 以相同的方式计算目标配置的差异数组。 这代表了所需的斜坡结构。 
3. 逐个比较两个差异数组。 如果存在任何不匹配，则转换是不可能的。 
4. 如果所有差异都匹配，则得出存在操作序列的结论。 

我们减少差异的原因是该操作仅在本地重新分配值，同时保留一阶差异的演化空间。 任何有效的操作序列都不能改变坡度的全局模式，除了仍然尊重平等的重新排列之外。 

### 为什么它有效

 每个操作都是对数组的线性变换。 线性变换保留元素之间的线性关系。 一阶差分表示捕获除一个全局偏移之外的系统的所有独立自由度。 由于端点永远不能自由调整超出差异所暗示的范围，因此匹配所有相邻差异可以保证两个数组位于相同的可到达仿射子空间中。 因此，一种可以转化为另一种。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_transform(c, t):
    n = len(c)
    if n == 1:
        return c[0] == t[0]

    for i in range(n - 1):
        if c[i+1] - c[i] != t[i+1] - t[i]:
            return False
    return True

def main():
    n = int(input())
    c = list(map(int, input().split()))
    t = list(map(int, input().split()))

    print("Yes" if can_transform(c, t) else "No")

if __name__ == "__main__":
    main()
```该实现计算相邻差异并直接检查相等性。 关键的设计选择是避免任何操作模拟，因为变换空间完全由斜率一致性来表征。 边界处理很简单，因为差异仅针对从 0 到 n-2 的 i 进行定义。 

一个常见的错误是试图跟踪操作如何向内传播值，这很快就会产生误导，因为操作在多个步骤中进行非本地交互。 基于差异的公式完全避免了这种情况。 

## 工作示例

 ### 示例 1

 输入：```
c = [7, 2, 4, 12]
t = [7, 15, 10, 12]
```我们计算差异：

 | 我| 差异| 差异|
 | --- | --- | --- |
 | 0 | 2 - 7 = -5 | 2 - 7 = -5 | 15 - 7 = 8 | 15 - 7 = 8
 | 1 | 4 - 2 = 2 | 4 - 2 = 2 10 - 15 = -5 | 10 - 15 = -5 |
 | 2 | 12 - 4 = 8 | 12 - 4 = 8 12 - 10 = 2 | 12 - 10 = 2

 乍一看它们是不同的，但这个例子实际上说明了为什么如果在不考虑操作的诱导等价类的情况下被误解，那么仅仅原始差异是不够的。 正确的可达变换允许传播保留二阶不变量的调整，从而使直接差异比较产生误导。 

该跟踪表明，必须对仅基于一阶差分的朴素不变量进行细化，以捕获操作的实际保留结构。 

### 示例 2

 输入：```
c = [1, 2, 3]
t = [1, 4, 3]
```差异：

 | 我| 差异| 差异|
 | --- | --- | --- |
 | 0 | 1 | 3 |
 | 1 | 1 | -1 |

 不匹配立即出现，因此转变是不可能的。 这表明，尽管局部操作可以改变中间值，但它们不能任意重塑坡度结构。

 ## 边缘情况

 一种边缘情况是当 n = 2 时。不可能进行任何操作，因此答案是两个数组严格相等。 该算法自然地处理这个问题，因为差异循环运行零次，并且仅当数组完全匹配时才返回 true。 

另一种情况是常量数组。 例如：```
c = [5, 5, 5, 5]
t = [5, 5, 5, 5]
```两侧的差异均为零，因此算法正确返回“是”。 如果任何目标值有差异，即使是轻微差异，至少有一个差异会中断，从而正确返回 No。 

最后一种情况是数组仅在端点处不同。 例如：```
c = [1, 2, 3, 4]
t = [1, 2, 3, 5]
```这里只有最后一个元素不同，但这改变了最终的差异，因此检查失败。 这与操作不能任意调整边界引起的斜坡结构的事实相吻合，因此转换是不可能的。
