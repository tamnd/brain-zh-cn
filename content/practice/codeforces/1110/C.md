 ## 解决方案
 ## 问题理解

 我们得到一个数字$a$。 对于这个数字，我们可以选择任何$b$这样$1 \le b < a$。 对于每一个选择$b$，我们计算由按位运算得出的两个值：一个是$a \oplus b$，另一个是$a \& b$。 然后我们取这两个结果的 gcd。 任务是最大化所有有效的 gcd$b$，并对多个查询重复此操作。 

关键的难点在于$b$相互作用$a$以两种不同的二进制方式。 XOR 的行为类似于“无进位的位差异”，而 AND 的行为类似于“仅公共位”。 然后gcd从这两个导出的整数中提取一个共享除数结构，该结构与原始数字没有明显的相关性。 

约束的查询数量很少，但值大小很大，最多约为$2^{25}$。 这立即排除了尝试所有$b$每个查询的值。 暴力循环$b < a$最多需要$10^7$最坏情况下每次测试的迭代次数，远远超出了限制。 

一个天真的但诱人的简化是尝试特殊值$b$， 例如$b = a-1$或二的幂，但这忽略了最佳结构取决于包含在其中的二的最高幂的情况$a$。 

出现微妙的边缘情况时$a$是这样的形式$2^k - 1$。 例如，如果$a = 7$，然后选择$b = 2$产量$a \oplus b = 5$和$a \& b = 2$, 给出 gcd$1$，但其他选择如$b = 3$给$a \oplus b = 4$,$a \& b = 3$，仍然是gcd$1$。 最优结果实际上是$a$在许多这样的情况下，这与 gcd 必须始终小于的直觉相矛盾$a$。 

另一个棘手的情况是当$a$是二的幂。 然后$a \& b = 0$对于所有有效的$b$，gcd 减少为$a \oplus b$，这在很大程度上取决于我们如何翻转该单个位。 

## 方法

 暴力法很简单。 对于每个$a$，迭代每一个$b$从$1$到$a-1$, 计算$x = a \oplus b$,$y = a \& b$，并评估$\gcd(x, y)$。 这是正确的，因为它直接遵循定义。 然而，它执行$O(a)$每个查询的 gcd 计算，对于接近的值是不可能的$2^{25}$。 

为了改善这一点，我们检查了两个内部都存在哪些结构$a \oplus b$和$a \& b$。 关键的观察是 XOR 和 AND 分割了$a$和$b$以互补的方式：每一点$a$要么与$b$（有助于 AND）或不同（有助于 XOR）。 该划分表明两个结果均受以下限制$a$并且它们的 gcd 必须与除数密切相关$a$。 

更深入的见解是考虑按位结构$a$。 让$p$是两个不超过的最高幂$a$。 我们可以写$a = p + r$， 在哪里$r < p$。 最佳结构源于选择$b$以最大化 XOR 和 AND 结果之间共享因子的方式隔离此最高位结构。 事实证明，最佳可能值仅取决于$a$的两个块的最高幂，答案简化为：$$f(a) = 2^{\lfloor \log_2(a) \rfloor + 1} - 1$$这对应于严格大于的最小全一数$a$的最高位，有效地填充所有位直到最高有效位$a$。 

这是可行的，因为我们总是可以构造一个$b$这迫使$a \oplus b$成为那个万能的面具，同时制作$a \& b$折叠成一个值，其 gcd 变得最大，达到完整掩码。 

所以而不是搜索$b$，我们只需要计算上面的下一个二的幂掩码$a$。

 ## 算法演练

 1.对于每个查询值$a$，计算严格大于的两个的最高幂$a$。 这可以使用位长度来获得$a$。 
2. 将答案形成为小于 2 的幂的 1，从而有效地创建一个由直到最高有效位位置的所有 1 组成的二进制数$a$。 
3. 输出该值进行查询。 

此步骤起作用的原因是位长度直接编码最高有效位的位置，并且所有有效结构仅取决于该位置而不是较低位。 

### 为什么它有效

 XOR 和 AND 的结构确保所有候选值仅取决于$a$可以分为共享位置和不同位置$b$。 当两个结果数字在最大可能的统一位模式上对齐时，即可实现最大 gcd。 该模式恰好是直到最重要位的完整块$a$，由位长度唯一确定。 任何偏差都会导致高位缺失，从而严格降低可实现的 gcd。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    for _ in range(q):
        a = int(input())
        msb = a.bit_length()
        ans = (1 << msb) - 1
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案独立处理每个查询。 关键操作是`bit_length()`，它找到最高设置位的位置$a$。 将 1 左移该量可创建下一个 2 的幂，减去 1 会生成一个二进制数，所有位都设置在该位置下方。 

必须小心，不要从错误的 2 次方中减去 1。 使用`bit_length()`直接避免了手动扫描位时可能出现的差一错误。

 ## 边缘情况

 对于二的幂$a = 8$，算法计算$msb = 4$，所以答案是$2^4 - 1 = 15$。 虽然$a$它本身只有一位设置，结果扩展为完整掩码。 这正确地捕捉到了以下事实：$b$可以完全重塑 XOR 和 AND 结果，同时保留最大 gcd 结构。 

对于已经是全一形式的数字，例如$a = 7$，我们得到$msb = 3$并回答$7$。 任何其他$b$无法产生更大的公约数，因为界限内不存在更大的统一位结构。 

对于像这样的混合数$a = 6$, 二进制`110`，我们得到答案`111`。 选择不同$b$值仅影响较低位的交互，但最高位位置主导可实现的 gcd 结构，因此该算法在所有此类配置中保持稳定。
