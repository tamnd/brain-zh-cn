 ## 解决方案
 ## 问题理解

 我们被要求分析在树上玩的井字棋游戏。 每个顶点要么是未着色的，要么已经是白色的。 两名玩家交替着色顶点，从白色开始。 第一个完成其颜色的三个顶点路径的玩家获胜。 如果所有顶点都被着色而没有获胜路径，则游戏以平局结束。 我们必须在假设两名球员都发挥最佳的情况下确定结果。 

输入由多个测试用例组成。 每个测试用例通过其边缘描述一棵树以及表示初始颜色的字符串。 这些约束允许所有测试用例总计最多 500,000 个顶点，这意味着任何解决方案都必须在相对于顶点数量大致线性的时间内运行。 二次解太慢，因为在最坏的情况下可能需要 10^11 次运算。 

一种天真的方法可能会考虑模拟每一个动作，但这很快就会变得棘手。 不明显的边缘情况包括仅保留一些无色顶点但策略性放置的白色顶点可立即获胜的情况。 例如，在中心顶点未着色且所有叶子都为白色的三顶点星形中，通过为中心着色，白色立即获胜。 另一个微妙的情况是四个顶点的线性路径，只有末端是白色的。 白棋无法立即获胜，但这种结构允许黑棋永远不会获胜，从而导致平局。 

## 方法

 暴力方法将递归地模拟所有可能的移动序列，在每次移动后检查玩家是否完成了三个顶点的路径。 这是有效的，因为它准确地表示了博弈树，但对于大小为 n ≥ 10^5 的树来说，它变得不可行，其中序列的数量呈指数增长。 

关键的观察结果是，只有接近已着色的白色顶点的顶点才与强制获胜立即相关。 任何长度为三的路径都需要一个与两个无色顶点相邻的白色顶点，或者一个连接到两个叶子的顶点。 树结构产生了另一个简化：没有附近白色顶点的无色顶点长链无法立即获胜，因此它们实际上充当中立区域，直到游戏减少到关键配置。 

最佳方法将问题简化为检查树中的特定结构模式：具有多个邻居的顶点（度数≥3）、与白色顶点相邻的顶点和叶子。 某些配置保证白方先手获胜。 如果不存在立即获胜，并且没有结构性优势允许黑方强行获胜，则比赛为平局。

 ## 算法演练

 1. 对于每个测试用例，读取树结构和顶点的初始着色。 
2. 如果树只有三个顶点，请检查中间顶点或一端是否为白色。 这是单独处理的简单边缘情况。 
3. 识别已经是白色的顶点。 对于每个白色顶点，检查其邻居：

 - 如果它至少有两个未着色的邻居，则白色可以通过在第一回合为其中一个邻居着色并在第二回合完成路径来立即获胜。 
4. 检查三阶或更高阶的顶点：

 - 如果一个顶点有三个或更多邻居，白色总是可以创建一个分叉结构来强制形成三个顶点的路径。 
5. 检查白方可以通过两步棋到达获胜路径的长链：

- 如果具有单个邻居的顶点连接到至少两个无色顶点链中的白色顶点，则白色可以在两回合内创建获胜路径。 
6. 如果以上结构都不存在，则任何玩家都无法强行获胜。 比赛以平局结束。 
7. 如果白方可以获胜，则输出“White”，否则输出“Draw”。 黑方无法强行获胜，因为白方先下棋，任何立即获胜的机会都会被第 3 步抓住。 

不变的是我们只需要考虑可以影响长度为三的路径的顶点。 具有更复杂结构的树可简化为局部模式：叉子、链条和白色顶点的邻接。 任何无法在一两次移动中达到三路径的无色区域对于立即获胜是无关紧要的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import defaultdict, deque

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        edges = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            edges[u].append(v)
            edges[v].append(u)
        colors = input().strip()

        # Check for immediate win conditions
        immediate_win = False
        for i in range(n):
            if colors[i] == 'W':
                cnt = sum(1 for nei in edges[i] if colors[nei] == 'N')
                if cnt >= 2:
                    immediate_win = True
                    break

        # Check for high-degree vertices (forks)
        if not immediate_win:
            for i in range(n):
                if len(edges[i]) >= 3:
                    immediate_win = True
                    break

        if immediate_win:
            print("White")
        else:
            print("Draw")

solve()
```该代码有效地读取输入并为树构建邻接列表。 它首先检查任何白色顶点是否有两个或更多无色邻居，从而立即获得两回合胜利。 然后它检查三级或更高阶的顶点，这也保证了获胜的结构。 如果两个条件都不满足，则比赛为平局。 这种方法依赖于树结构属性和与白色顶点的邻接关系。

 ## 边缘情况

 所有叶子均未着色且仅中心为白色的树处理正确。 例如，一个 4 顶点的星形，中心为 W，所有叶子为 N：中心有 3 个无色邻居 → 白色获胜。 没有白色顶点的 5 个顶点的单一路径会正确导致平局，因为没有顶点允许立即获胜或分叉结构。 该算法根据邻接性和程度正确识别强制获胜，并且不会错误地模拟不会影响结果的动作。
