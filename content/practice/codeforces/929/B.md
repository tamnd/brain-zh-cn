 ## 解决方案

 ## 问题理解

 我们得到了一个分成几行的飞机座位布局，其中每行都是一个包含座位和分隔符的字符串。 每排座位以固定模式排列，但重要的细节更简单：只有排内水平相邻的座位才能有助于“邻居”关系，而破折号字符会打破邻接关系。 

一些座位已经被两种类型的乘客占据。 乘客状态，已标记`S`，是唯一“邻居数”对目标有贡献的人。 普通旅客`P`已经占用了一些座位，并且在计算邻居时表现得与任何其他占用的座位一样。 我们最多可以放置`k`额外的普通乘客进入空座位标记`.`; 这些将被标记为`x`在输出中。 

我们想要最小化的数量是所有状态乘客的相邻已占用座位的总数。 对于每一个`S`，我们在其行内向左和向右看，以及被其中任何一个占据的每个相邻座位`S`,`P`，或新放置的`x`为答案贡献一分。 如果两个状态乘客坐在一起，则该邻接贡献两次，每个端点一次。 

约束条件`n ≤ 100`并且至多`10·n`新乘客意味着座位总数较少，因此`O(total seats log total seats)`策略已经足够了。 带有排序步骤的线性扫描是完全安全的。 

一个微妙的点是，放置新乘客不会改变座位之间的相邻规则，它只会改变座位是否被占用。 所以网格的结构是固定的； 我们只决定哪些空位置被占据。 

主要的边缘情况是，一个座位可能与零个、一个或两个状态乘客相邻，具体取决于其在本地集群中的位置。 例如，在像这样的片段中`S.S`，放置一个`x`中间创建了两个新的贡献，而在`S..P`如果中间的座位是一个，则其左边只有一个相关的相邻座位`S`。 

在不评估全局最佳选择的情况下贪婪地模拟所有布局的幼稚方法可能会失败，因为在以下情况下放置成本为 1 的席位可能比保留成本为 2 的席位更糟糕`k`是有限的。 

## 方法

 暴力方法会尝试所有方法来选择`k`空座位并安置乘客，然后重新计算状态乘客的总邻接成本。 如果有`m`空位子，这本质上是选择`k`出于`m`，导致`O(m choose k)`配置以及每次评估成本`O(total seats)`。 即使输入很小，一旦有超过几十个空座位，这在组合上就变得不可能。 

关键的观察是每个空座位对最终答案的贡献独立于其他选择。 当我们将乘客放在空座位上时，影响目标的唯一方法是增加相邻座位的邻居数量`S`座位。 它永远不会改变其他席位之间的相邻关系。 

这减少了为每个空座位分配成本的任务：有多少状态乘客紧邻其左侧或右侧。 每个选择的座位都会按该成本增加总分。 因此，为了最小化最终价值，我们应该将乘客安排在`k`以最小的成本腾出座位。 

一旦选择了这些座位，我们将它们标记为已占用，并通过扫描所有座位的相邻性重新计算最终分数`S`座位。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力组合 | O(C(m,k) · n) | O(C(m,k) · n) | O(n) | 太慢了 |
 | 按成本对空座位进行排序 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.扫描每一行并收集所有空位置`.`到一个列表中。 对于每个这样的位置，通过检查同一行中其左邻和右邻来计算其成本。 每个相邻的`S`贡献一单位成本。 
2. 根据计算出的成本以升序对所有空仓进行排序。 这确保我们优先考虑对目标造成最小损害的席位。 
3.选择第一个`k`在此排序顺序中的位置并将其标记为已填充`x`。 这些是最佳放置，因为每个放置都对最终总和贡献最小可能的增量增量。 
4.全部放置完毕后`x`，通过迭代所有单元格来计算最终答案。 对于每一个`S`，检查其左、右邻居在同一行； 如果邻居是任何占用的座位（`S`,`P`， 或者`x`)，总数加一。 
5. 输出计算出的总和，然后输出修改后的网格。 

我们只考虑直接邻居的原因是邻接在一行中是严格局部的，并且破折号字符防止任何跨行交互。 

### 为什么它有效

 每个空座位仅影响该排中两个相邻状态的乘客。 任何放置都不能影响不相邻的对或改变现有的`S-S`关系。 这使得总成本超过所选座位。 由于每个决策都会产生独立的成本，因此选择最小的`k`贡献通过直接交换论点使总和最小化：将选定的成本较高的席位与未选定的成本较低的席位交换总是可以改善或保持结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    rows = [list(input().strip()) for _ in range(n)]

    empties = []

    # compute cost of placing x in each empty seat
    for i in range(n):
        row = rows[i]
        m = len(row)
        for j in range(m):
            if row[j] == '.':
                cost = 0
                if j - 1 >= 0 and row[j - 1] == 'S':
                    cost += 1
                if j + 1 < m and row[j + 1] == 'S':
                    cost += 1
                empties.append((cost, i, j))

    # choose best k positions
    empties.sort()
    for t in range(k):
        _, i, j = empties[t]
        rows[i][j] = 'x'

    # compute answer
    ans = 0
    for i in range(n):
        row = rows[i]
        m = len(row)
        for j in range(m):
            if row[j] == 'S':
                if j - 1 >= 0 and row[j - 1] != '-':
                    if row[j - 1] in 'SPx':
                        ans += 1
                if j + 1 < m and row[j + 1] != '-':
                    if row[j + 1] in 'SPx':
                        ans += 1

    print(ans)
    for r in rows:
        print(''.join(r))

if __name__ == "__main__":
    solve()
```第一阶段建立一份具有当地影响力的候选人席位名单。 第二阶段贪婪分配`x`到危害最小的位置。 最终扫描通过忽略相邻行来仔细尊重行边界`-`，确保我们只计算有效的相邻座位。 

一个常见的错误是在每次展示位置后动态重新计算成本。 这是不必要的，因为成本与之前的安置无关。

 输入：```

```我们计算空座位的成本：

 | 职位| 左| 对| 成本|

 | 第三个座位 | 普 | - | 0 |
 | 第七席| S | S | 2 |

 排序后，我们选择两个成本最小的位置并放置`x`那里。 

| 步骤| 行动| 网格状态|
 | --- | --- | --- |
 | 1 | 初始| SP.-SS.S-S.S |
 | 2 | 将 x 置于成本 0 | SPx-SS.S-S.S |
 | 3 | 将 x 置于次佳位置 | SPx-SSxS-S.S |

 现在重新计算邻接关系`S`。 每个`S`计算相邻的占用座位数，给出最终答案`5`。 

这证实了尽早避开高影响力的座位可以正确减少总的相邻性。 

### 示例 2

 输入：```
2 1
S.S-..S
..S-S..
```我们计算空座位的成本。 部分座位触及`S`有的在一侧，有的在两侧，有的则没有。 该算法选择一个最便宜的座位，这是一个有成本的座位`0`。 配售`x`没有增加任何`S`邻接，所以最终的答案仍然是最小的。 

这表明零成本展示位置始终是完全安全的，应该优先考虑。

 ## 边缘情况

 一个重要的边缘情况是两个状态乘客之间有一个空座位，例如`S.S`。 成本变为 2，除非强制，否则算法会正确避免它。 如果所有座位的成本都是 2，算法仍然会在其中任意选择，因为所有选择都是等价的。 

另一种情况是座位靠近仪表板边界。 例如`S.-.`确保邻接不交叉`-`，并且实现在计算邻居之前显式检查边界。 

最后一个边缘情况是`k`等于零成本席位的数量。 该算法首先填充所有无害的座位，并且从不触及有害的座位，从而对目标产生最小的增加或不增加。
