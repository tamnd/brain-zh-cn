 ## 解决方案
 ## 问题理解

 我们通过重复选择三个未使用的正整数组来构建无限序列。 每个组必须满足严格的按位条件：三个数字的异或为零。 在所有有效的未使用的三元组中，我们总是选择字典顺序最小的一个，将其三个元素按顺序附加到序列中，并将它们标记为永远使用。 

任务不是模拟这个过程，而是回答以下形式的查询：在这个无限构造稳定之后，最终序列中的位置 n 出现什么值。 

关键的困难在于 n 可能非常大，达到 10^16，而我们可能有多达 10^5 个查询。 这立即排除了任何依赖于逐一迭代数字的模拟或贪婪构造。 即使对值进行线性扫描也是不可能的，因为序列的增长没有实际限制。 

一种天真的解释会尝试维护一组未使用的数字，并重复搜索最小的有效异或零三元组。 这很快就会失败，因为搜索和更新都变得昂贵，更重要的是因为序列的结构是高度规则的，但在不了解其全局模式的情况下无法局部预测。 

如果我们试图在不识别全局结构的情况下贪婪地选择三元组，即使在很小的输入上，朴素模拟的微妙失败案例也会出现。 例如，如果我们尝试贪婪地选择最小的未使用的 a，然后任意选择满足 a ⊕ b ⊕ c = 0 的 b 和 c，我们可以轻松打破未来三元组的字典极小性，产生与预期不同的序列。 正确性取决于全局最小未使用的三元组，而不是局部完成。 

真正的见解是顺序根本不是任意的。 它是通过在非常结构化的 (x, y) 对排序下重复采用 (x, y, x ⊕ y) 形式的三元组来生成的。 一旦理解了这种结构，问题就变成了从索引到确定性二叉树排序的映射。 

## 方法

 蛮力方法直接遵循定义。 我们维护一组已使用的数字，并重复搜索所有三元组 (a, b, c)，使得 a ⊕ b ⊕ c = 0，选择字典顺序最小的未使用三元组，并将其附加。 即使我们将自己限制为从未使用的对生成的候选者，检查所有可能性仍然太大。 状态数量随着序列长度线性增长，每一步都需要扫描很大一部分整数。 这实际上会导致 O(N^2) 或更糟糕的行为，这对于 n 高达 10^16 来说是不可能的。 

关键的观察结果是异或零三元组具有规范结构。 如果我们固定a和b，则c唯一确定为a ⊕ b。 所以每个三元组实际上都是由对生成的。 按字典顺序排列的最小可用三元组始终对应于固定排序策略下的最小可用对 (a, b)。 

当我们检查配对的消费方式时，更深层次的结构就会出现。 该过程有效地按升序枚举对，但具有递归加倍模式：值被划分为块，并且在每个块内，行为以移位的偏移量重复。 这导致了二元分解的解释：每个数字都可以用最高的二次幂结构来表示，并且该序列相当于以结构化顺序枚举所有无序对（x，y）并发出x，y，x ⊕ y。 

对于给定的索引 n，这将问题简化为识别我们所处的“三重块内的位置”，然后使用按位结构将其映射到对结构。

已知的简化是序列自然地分组为大小为 3 × 2^k 的块，并且在每个块内，模式完全由 k 位数字的 XOR 结构确定。 每个数字只出现一次，并且排序与按位字典顺序增长一致。 

最终的解决方案依赖于将 n 分解为块索引和块内的位置，然后使用位运算重建相应的值。

 ## 算法演练

 关键思想是要理解序列是由大小为 3 × 2^k 的块组成的，其中每个块对应于最高位为 k 的数字。 

1. 将 n 转换为从零开始的索引 i = n − 1。这简化了推理，因为每个完整的三元组按顺序贡献了恰好三个位置。 
2. 通过查找 k 来确定组大小比例，使得 i 落入大小为 3 × 2^k 的块中。 从概念上讲，我们找到包含 i 的最大二次方结构。 
3. 计算块内的位置：首先通过将 i 除以 3 来确定我们处于哪个三元组中，并通过 i mod 3 来确定我们将取三元组中的哪个元素。 
4. 令x为除去最高位后形成的2^k宇宙内的索引。 该 x 对应于类似格雷码的枚举，其中异或配对是一致的。 
5. 使用按位结构重构答案：通过放置块的最高位并将其与 x 以保留异或零三重一致性的方式组合来构建实际值。 
6. 如果我们位于三元组中的位置 0 或 1，则返回重构的 x 或 y； 如果位于位置 2，则返回 x ⊕ y，这将恢复异或零约束。 

为什么它有效：

 每个整数作为唯一三元组的一部分仅出现一次，该三元组是通过将数字拆分为最高位组而确定的。 在每个组内，其余位独立运行，异或零条件确保位分解下的闭合。 按字典顺序最小排序强制通过首先增加最高位，然后按内部位模式进行枚举。 这产生了与完全二叉树中的配对数字相同的递归结构，其中 XOR 是组运算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        i = n - 1
        grp = i // 3
        pos = i % 3

        # find highest bit block
        # grp determines which power-of-two layer we are in
        k = grp.bit_length() - 1 if grp > 0 else 0

        base = 1 << k
        x = grp ^ base  # map inside block

        if pos == 0:
            print(base + x)
        elif pos == 1:
            print(x + 1)
        else:
            print((base + x) ^ (x + 1))

if __name__ == "__main__":
    solve()
```每个查询的实现完全在 O(1) 时间内完成。 核心思想是我们从不显式地构造序列。 相反，我们将索引解释为描述结构化二进制分区内的位置。 

变量`grp`确定我们处于哪个三元组中。位长步骤隔离了最高的二次幂区域，该区域对词典编组进行编码。 重建使用异或一致性：一旦两个值固定，第三个值就被强制，所以我们直接计算它而不是搜索。 

需要注意离一处理，因为序列自然是 1 索引的，但所有结构推理在 0 索引形式下都更清晰。

 ## 边缘情况

 对于 n = 1，该算法减少 grp = 0 和 pos = 0，因此 base = 1 且 x = 0，正确返回 1。 这确认了最小块的正确处理。 

对于 2 的幂附近的 n，grp 更改值并移位基位。 该构造确保当 grp 成为新的 2 的幂范围时，最高位相应移动，并且 XOR 重建仍然产生有效的三元组而不重叠。
