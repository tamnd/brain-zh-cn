 ## 解决方案
 ## 问题理解

 给定一棵树，问题要求我们思考可以在其上执行的几何构造。 每个顶点都成为平面上一条闭合的非自相交曲线。 这些曲线需要以非常严格的方式交互：当且仅当两条曲线相应的顶点由树中的一条边连接时，两条曲线才会相交。 除此之外，与不相邻顶点相对应的曲线必须保持完全分离。 

在此几何模型之上，我们定义了包含的概念：如果一条曲线严格位于其封闭区域内并且不与其相交，则该曲线被视为在另一条曲线内部。 使用它，我们寻找一系列顶点，使得每条曲线严格包含下一条曲线。 

假设我们可以自由设计树的任何有效几何实现，则输出是此类嵌套序列的最大可能长度。 

关键的困难在于几何形状不是任意的。 交叉规则强制形成全局结构：每条边都是强制交叉，而非边则禁止任何交互。 这使得绘图受到高度约束，因此嵌套行为不能自由地针对每个顶点独立选择。 

约束 n 高达 100000 意味着任何解都必须是线性或接近线性的。 每节点二次甚至 n log n 的方法将不会通过。 这立即排除了任何尝试显式模拟嵌入或检查所有顶点对嵌套可行性的构造。 

一些边缘案例阐明了这里的微妙之处。 在一个中心与所有其他中心相连的星形树中，不可能有超过 2 个中心的长嵌套，因为叶子不能在不违反邻接约束的情况下相互嵌套。 然而，在简单的路径中，每个顶点都可以排列在完美嵌套的链中，这表明答案随着路径长度线性增长。 这两个极端已经暗示答案取决于“线性结构”在树内存在的时间。 

一个天真的误解是假设嵌套与子树深度有关。 对于最深的根不是最长链的一部分的树来说，这种方法会失败。 另一个错误的想法是贪婪地挑选最深的叶子，这可能会错过经过分支点的长交替路径。 

## 方法

 暴力方法将尝试构建树的有效几何嵌入，然后在所有可能的配置中搜索最长的嵌套链。 即使我们抽象出几何形状，这实际上也会成为树嵌入的全局组合优化，从而导致复杂性爆炸。 在最坏的情况下，任何枚举顶点之间可能的包含关系的尝试都会很快变得指数级，因为每个分支都会引入曲线的多个相对排序可能性。 

关键的观察结果是，几何约束消除了几乎所有自由度：保持一致的相交规则的唯一方法是将顶点排列在结构中，其行为在包含方面类似于路径。 一旦一个顶点被放置在另一个顶点内而不相交，它的所有邻居必须保持在一致的区域内，并且这沿着单个链传播。 分支不允许独立嵌套，因为兄弟姐妹必须保持分离，防止它们以不同的顺序位于彼此的区域内。 

这会强制任何有效的嵌套序列对应于树中的简单路径。 相反，任何简单的路径都可以通过逐步将每个下一个顶点放置在前一个顶点内，同时尊重路径上的邻接约束来实现为嵌套链。 

因此，问题简化为找到树中最长的简单路径，这正是以顶点数衡量的树直径。

 ## 算法演练

 我们现在将观察转化为具体的计算。 

1. 从输入边构建树的邻接表。 
2. 从任意节点（例如节点 1）运行 DFS 或 BFS，并找到距离它最远的节点。 这是有效的，因为在一棵树中，直径的一个端点始终是距任何起始节点最远的点。 
3. 从最远的节点开始运行第二个 DFS 或 BFS。 跟踪到所有节点的距离。 
4. 第二次遍历中获得的最大距离是在边缘中测量的直径。 
5. 通过加 1 将此基于边的直径转换为顶点数，因为具有 k 个边的路径包含 k + 1 个顶点。 

两次遍历起作用的原因是第一次扫描保证我们降落在最长路径的一个极端。 然后，第二次扫描从该极端向外扩展，并且必然到达直径的相反端点。 

### 为什么它有效

 任何最长的嵌套链都对应于树中的一条简单路径。 树的每对顶点之间都有一条唯一的简单路径，因此最大化嵌套长度相当于最大化该路径上的顶点数量。 最远点属性确保从直径的任意端点开始的第二个 BFS 将发现相反的端点，因为在不与第一个末端的最大值相矛盾的情况下不再存在路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def bfs(start, adj):
    n = len(adj) - 1
    dist = [-1] * (n + 1)
    q = deque([start])
    dist[start] = 0
    far = start

    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
                if dist[v] > dist[far]:
                    far = v
    return far, dist[far]

def solve():
    n = int(input())
    adj = [[] for _ in range(n + 1)]

    for _ in range(n - 1):
        a, b = map(int, input().split())
        adj[a].append(b)
        adj[b].append(a)

    if n == 1:
        print(1)
        return

    any_node = 1
    far, _ = bfs(any_node, adj)
    far2, dist = bfs(far, adj)

    print(dist[far2] + 1)

if __name__ == "__main__":
    solve()
```第一个 BFS 只负责定位直径端点，它还没有产生答案。 第二个 BFS 是测量实际直径长度的地方。 决赛`+1`是必要的，因为 BFS 距离计算边，而嵌套序列计算顶点。 

一个微妙的实现细节是在 BFS 期间维护“迄今为止最远的节点”。 这避免了对距离数组的第二次传递，并使代码保持线性，而无需额外的开销。

 ### 示例 1

 输入：```
6
1 3
2 3

```来自节点 1 的第一个 BFS：

 | 步骤| 节点| 距离 | 最远|
 | ---| ---| ---| ---|
 | 开始| 1 | 0 | 1 |
 | 访问 | 3 | 1 | 3 |
 | 访问 | 2 | 2 | 2 |
 | 访问 | 4 | 2 | 2 |
 | 访问 | 5 | 3 | 5 |
 | 访问 | 6 | 3 | 5 |

 最远的节点是5。第二个BFS从5开始。 

| 步骤| 节点| 距离 | 迄今为止最大|
 | ---| ---| ---| ---|
 | 开始| 5 | 0 | 0 |
 | 访问 | 4 | 1 | 1 |
 | 访问 | 3 | 2 | 2 |
 | 访问 | 2 | 3 | 3 |
 | 访问 | 6 | 2 | 3 |
 | 访问 | 1 | 3 | 3 |

 最大距离是 3 条边，因此答案是 4 个顶点。 

这证实了最长的链遵循路径 2 到 5 或 2 到 6 通过中心。

```这已经是一条线了。 第一个 BFS 到达一个端点，第二个 BFS 到达距离 4 个边的相反端点，给出答案 5。这表明纯路径实现了最大可能的嵌套。

 该树最多有 100000 个顶点，因此线性遍历是最佳的。 两个 BFS 遍历完全符合时间和内存限制。

    def bfs(start, adj):

        q = deque([start])
        dist[start] = 0
        far = start

                if dist[v] == -1:
                    dist[v] = dist[u] + 1

        return "1\n"

    far, _ = bfs(1, adj)

 ## 边缘情况

 星形树测试该解决方案是否避免高估嵌套深度。 直径始终为 2，因为任何两个叶子都通过中心连接，并且不再存在路径。 

线性链测试每个顶点都可以参与单个嵌套序列的上限行为。 BFS 必须正确传播距离，而不会因平局处理而丢失端点。 

平衡二叉树确保局部深度不会误导算法认为更深的子树总是产生更长的链，因为实际最长的路径穿过根部穿过两个最深的叶子。
