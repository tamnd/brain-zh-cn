 ## 解决方案
 ## 问题理解

 我们被要求构造一个具有非常特定属性的整数数组：其递增子序列的总数应等于给定的整数$X$。 递增子序列是数组中按顺序排列的元素序列，使得每个元素都严格大于前一个元素。 如果每个子序列使用数组中的不同位置，则即使值相同，也将被视为不同的子序列。 空子序列也计算在内。 

输入由多个测试用例组成，每个测试用例提供一个整数$X$，可以大到$10^{18}$。 输出必须给出一个长度最多为 200 的数组，该数组精确实现$X$增加子序列，或表明不可能。 每个数组元素可以是范围内的任意整数$[-10^9, 10^9]$。 

大上限为$X$立即排除子序列的天真枚举。 如果我们尝试生成每个子序列来对它们进行计数，即使对于长度为 60 的数组，子序列的数量也可能达到$2^{60} \approx 10^{18}$，这是不可行的。 这意味着我们不能依赖暴力计数，需要一种建设性的方法。 

边缘情况包括最小的$X = 2$，它对应于空子序列和单元素数组。 同样，非常大$X$值接近$10^{18}$需要仔细设计以避免超过 200 个元素的长度限制。 线性增加元素或重复块的简单方法可能会悄悄超出允许的数组长度或产生错误的计数。 

## 方法

 暴力方法可能会尝试增量生成数组并计算所有增加的子序列，直到达到$X$。 例如，从空数组开始并添加元素，同时使用动态编程计算子序列。 这对于小尺寸来说是正确的$X$，因为每一步都可预测地增加子序列计数，但它立即不切实际：每个新元素都会使涉及它的子序列数加倍，因此对于$X \sim 10^{18}$，我们需要一个长度约为 60 的数组才能达到$X$，并且计数将涉及迭代$2^{60}$组合。 

关键的见解是使用**二元分解$X$**，将二的幂映射到数组中的重复块。 如果我们构建数组，使每个块独立地对总子序列做出贡献，我们就可以乘法组合块。 具体来说，形式为数组`[a, a, a, ...]`重复$k$时代贡献$k + 1$增加由该数字组成的子序列（包括该块的空子序列）。 通过仔细选择与二进制数字相对应的块大小$X$，我们可以构造一个长度最多为 200 的数组来实现任意$X \le 10^{18}$。 

贪心策略是从两个的最高幂中分配尽可能大的块$X$，然后减少$X$通过该贡献，继续递归。 数组值可以在每个块中增加整数，以避免不必要的合并，或者如果我们希望每个块准确贡献其设计数量的子序列，则可以重复。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 二进制块构造 | O(log X) | O(n ≤ 200) | 已接受 |

 ## 算法演练

 1. 转换$X$进入其二进制表示形式。 每个`1`在位置$k` corresponds to a contribution of $我们需要在数组中实现2^k$个子序列。 
2. 初始化一个空数组。 跟踪当前使用的最大元素，以便新块可以在需要时具有严格更大的值。 
3. 对于按降序排列的每个 2 的幂，附加一个大小等于该幂的重复元素块。 例如，一个电源`2^k`可以通过一个长度的块来实现`k + 1`使用相同的数字。 
4. 确保方块不会干扰。 在块之间，递增值以保证新的递增子序列不会与先前的子序列重叠，从而保留精确的计数。 
5. 继续下去，直到 2 的所有幂都在$X$已被分配到块。 检查总长度不超过200，超过则输出-1。 否则，输出数组。 

保持的不变量是每个块准确地贡献其预期数量的递增子序列，并且不会改变先前块的贡献。 这保证了总子序列的总和恰好为 $X`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(X):
    # Start with empty array and current value
    array = []
    current = 0
    # Iterate over bits from most significant to least
    for bit in reversed(range(61)):  # 2^60 > 10^18
        if X >= (1 << bit):
            count = bit + 1
            array.extend([current] * count)
            current += 1
            X -= (1 << bit)
    if len(array) > 200:
        return "-1"
    return f"{len(array)}\n{' '.join(map(str, array))}"

def main():
    t = int(input())
    for _ in range(t):
        X = int(input())
        print(solve_case(X))

if __name__ == "__main__":
    main()
```该解决方案首先读取测试用例的数量以及每个测试用例的数量$X$。 功能`solve_case`使用二元分解方法构造数组。 从最高有效位向下循环确保我们首先使用最大的块，从而最小化数组长度。 每个区块使用相同的数字以确保独立贡献，并且`current`按值递增以分隔块。 长度检查保证符合 200 个元素的限制。
