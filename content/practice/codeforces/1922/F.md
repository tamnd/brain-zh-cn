 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，每个整数都在 1 和某个最大值之间$x$。 我们希望使用特殊操作使每个元素相等：选择数组的连续子段和一个值$k$当前不存在于该子段中，然后将该子段中的每个元素替换为$k$。 目标是计算使整个数组统一所需的此类操作的最少数量。 

输入尺寸$n$最多为 100，并且$x \le n$，与所有的总和$n$测试用例不超过 500 个。这允许$O(n^2 x)$或每个测试用例的操作稍高而不会超时。 小界限还意味着我们可以迭代所有可能的目标值（我们希望数组变为的值）并有效计算每个目标的最小操作数。 

要考虑的边缘情况包括已经统一的数组、每个元素都不同的数组（需要多次操作）以及最佳策略跳过某些元素以最小化操作的数组。 例如，像这样的数组`[1, 2, 1]`和$x = 2$可以通过选择在一次操作中转换为全 1$k = 1$以及仅包含中间元素的子段。 总是从左到右替换连续不匹配的简单方法可能会执行不必​​要的额外操作。 

## 方法

 暴力方法是模拟每个可能的操作序列。 对于每个子段以及该子段中不存在的每个值，我们可以尝试替换并递归地继续。 虽然原则上是正确的，但这是不可行的，因为子段的数量是$O(n^2)$，候选值的数量是$x$，并且操作顺序是组合的。 即使这样也会爆炸$n = 100$。 

关键的见解来自于观察，即数组只需要转换为统一值，并且该操作允许用当前不在该子段中的新值替换任何连续的子段。 这让我们可以将最小操作数计算为**尚未等于目标值**的连续块的数量。 如果两个与目标不同的元素块被目标值分隔开，则它们需要单独的操作。 如果它们是连续的，则单个操作可以覆盖整个段。 因此，对于每个候选目标值，我们可以扫描数组，对这些块进行计数，并在所有可能的目标值中取最小值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳（每个目标的块计数）| O(n x) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化变量`res`到无穷大。 这将保持所有可能目标值的最小操作数。 
2. 迭代每个潜在的目标值`k`从 1 到`x`。 
3. 初始化计数器`ops`将此目标设置为 0，并设置一个指针`i`来遍历数组。 
4. 虽然`i < n`，检查是否`a[i]`等于`k`。 如果是，则增加`i`并继续。 
5. 如果`a[i]`不等于`k`，我们找到了连续的不匹配块的开始。 增量`ops`1.
 6. 前进`i`直到该块的末尾（直到`a[i] == k`或者`i == n`）。 这捕获了可以在单个操作中替换的完整连续段。 
7. 扫描阵列寻找目标后`k`， 更新`res`作为`min(res, ops)`。 
8. 检查完所有目标后，`res`包含使数组统一所需的最少操作数。 打印或存储该值。 

工作原理：与所选目标不同的每个连续元素块都可以用单个操作替换，因为该操作允许更改不包含目标的任何段。 不重叠的块必须单独处理，而计数块可以确保我们准确地做到这一点。 通过检查所有可能的目标值，我们保证全局最小值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        a = list(map(int, input().split()))
        res = float('inf')
        for k in range(1, x + 1):
            ops = 0
            i = 0
            while i < n:
                if a[i] == k:
                    i += 1
                    continue
                ops += 1
                while i < n and a[i] != k:
                    i += 1
            res = min(res, ops)
        print(res)

if __name__ == "__main__":
    solve()
```该代码首先读取测试用例的数量。 对于每个测试用例，它读取数组及其参数。 对于每个潜在的目标值，它会计算与目标不同的连续块的数量，并跟踪所有目标的最小计数。 内部 while 循环确保我们正确识别完整块而无需重复计数，处理块到达数组末尾的边缘条件。

 ## 边缘情况

 对于单元素数组`[1]`和`x=1`，算法扫描数组，没有发现不匹配，并输出 0。对于数组`[1,2,1]`和`x=2`和目标`1`，单个中间元素被识别为需要一次操作的块。 由于内部 while 循环不断前进，该算法可以正确处理数组开头、中间和末尾的块`i`直到区块结束
