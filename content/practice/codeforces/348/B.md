 ## 解决方案
 ## 问题理解

 我们得到一棵有根树，其中最初只有叶子包含苹果，而内部节点为空。 每片叶子贡献固定数量的苹果，任何子树的“权重”定义为该子树内所有叶子中的苹果总数。 

如果一个顶点的所有直接子子树都具有完全相同的权重，则该顶点被认为是平衡的。 如果每个顶点同时满足这个条件，则树是平衡的。 

我们只能从叶子上摘下苹果。 目标是使整棵树保持平衡，同时移除尽可能少的苹果。 

关键的困难在于，移除一片叶子上的苹果会影响每个祖先的子树总和，因此变化会以一种受限的方式向上传播。 

约束 n ≤ 10^5 迫使我们远离每个节点的任何二次重新计算。 任何解决方案都必须对每个节点处理恒定次数或使用线性树遍历。 

当节点的子节点的子树权重已经接近但不相等时，就会出现微妙的边缘情况。 例如，如果一个节点具有子子树总和 [10, 10, 9]，则天真的贪婪调整可能会尝试“本地修复”，而没有意识到减少较大的子树可能会向上级联并强制在其他地方进一步减少，从而可能不必要地增加总删除量。 另一个陷阱是假设我们可以独立地将每个子树调整到目标，而不考虑所有调整最终必须在叶子上实现。 

## 方法

 思考这个问题的一个直接方法是为每片叶子分配最终允许的苹果数量，以满足所有内部约束。 如果我们自下而上固定目标子树权重，则每个内部节点必须强制其所有子子树匹配相同的值。 这提出了一个递归定义：每个节点确定其子树权重必须变为多少，并且必须删除任何多余的苹果。 

暴力方法将通过重复选择一个节点、计算所有子子树总和、选择目标值并通过向下传播到叶子来强制所有子树匹配它来模拟这个想法。 然而，在每次调整后重新计算子树总和使得这种方法在最坏的情况下呈二次方，因为每次调整都可能触发大型子树的完全重新计算。 

关键的见解是子树权重不是独立的自由度。 在任何节点，唯一可行的最终权重由其子节点决定：所有子节点必须以相同的权重结束，因此父节点的子树权重实际上是“一个共享值”。 我们不是任意选择，而是选择唯一允许与最小删除保持一致的值：处理子节点后的最小子子树权重。 任何更大的目标都需要增加更小的子树，这是不可能的，因为我们只能删除苹果。 

这将问题转化为后序 DFS，其中每个节点在平衡其子节点后计算其子树权重。 每当子树大于所选目标时，必须从该子树的叶子中删除多余的部分。 成本按照差额精确累积。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 后序 DFS 传播 | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将树的根设为 1，并使用 DFS 自下而上处理节点。

1. 执行后序遍历，以便每个节点先处理其所有子节点。 这确保了子子树权重在需要时已经最终确定。 
2. 对于每个节点，计算每个子子树的最终权重。 这些表示使每个子子树内部平衡后剩余的苹果数量。 
3. 如果一个节点没有子节点，那么它的子树权重就是它自己的叶子值。 这是基本情况，因为它下面不存在平衡约束。 
4. 如果节点有子节点，则收集所有子子树权重。 节点必须强制它们之间相等，但由于我们只能删除苹果，因此唯一可实现的公共值是这些权重中的最小值。 
5. 对于子树权重超过此最小值的每个子节点，我们必须从其叶子中删除差异。 这直接有助于答案。 
6. 调整后，节点自身的子树权重变为所选的最小值，返回给其父节点。 

遍历确保每个子树在向上合并之前独立地保持一致。 

### 为什么它有效

 在每个节点，所有子节点必须以相同的子树权重结束。 由于我们无法增加值，因此任何有效的最终配置都必须以最小子子树权重为界。 选择更大的东西就需要在某个地方添加苹果，这是不可能的。 因此，最低儿童体重被迫作为唯一一致的目标。 所有去除量恰好是高于此强制目标的多余质量，并且后续操作无法恢复或补偿这些减少量，从而确保最优性。 

## Python 解决方案```python
import sys
sys.setrecursionlimit(10**7)
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    g = [[] for _ in range(n)]
    
    for _ in range(n - 1):
        x, y = map(int, input().split())
        x -= 1
        y -= 1
        g[x].append(y)
        g[y].append(x)

    visited = [False] * n
    visited[0] = True
    ans = 0

    def dfs(v):
        nonlocal ans
        visited[v] = True

        child_weights = []

        for to in g[v]:
            if not visited[to]:
                child_w = dfs(to)
                child_weights.append(child_w)

        if not child_weights:
            return a[v]

        mn = min(child_weights)

        for w in child_weights:
            ans += w - mn

        return mn

    dfs(0)
    print(ans)

if __name__ == "__main__":
    solve()
```DFS 的结构使得每个节点在平衡后返回其最终的子树权重。 这`child_weights`list 存储以孩子为根的每个子树的有效权重。 选取其中最小的作为强制目标，所有超出的都累加到`ans`。 

一个微妙的实现细节是我们将节点标记为已访问，而不是传递父参数。 这避免了在不需要父跟踪逻辑的情况下重新访问无向树中的边。 另一个关键点是向上返回最小化的子树权重，它编码了所有下游删除的全部效果。

 | 测量 | 复杂性 | 说明|

 ## 边缘情况

 一个关键的边缘情况是当一个节点的子节点具有非常不同的子树权重时，例如 [1, 100000000, 100000000]。 该算法正确地选择 1 作为目标，并从其他两个子树中删除所有多余的部分。 因为这个决定是自下而上做出的，所以后面的节点都不能使其无效，并且每个移除的苹果都会正确地累积成本一次。 

另一种情况是深链，其中不平衡仅出现在叶子附近。 由于DFS是自下而上解析的，所以链中的每个节点都会返回一个正确的值，并且不会发生冗余的重新计算。 例如，叶子值为 [0, 10, 10, 10] 的链逐渐向上传播减少，直到所有节点都同意最小值，从而保持所有级别的正确性。
