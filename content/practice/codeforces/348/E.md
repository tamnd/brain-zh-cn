 ## 解决方案
 ## 问题理解

 我们有一棵包含 n 个城镇的加权树。 其中一些城镇设有修道院，每个修道院只接待一名朝圣者。 国家的结构保证每个城镇都可以相互到达，距离由沿唯一树路径的边权重之和决定。 

每个朝圣者都会查看所有的寺院，并根据树的距离来确定距离自己的寺院最远的寺院。 如果几座修道院的最大距离并列，它们都会出现在个人名单上。 

后来，发生了一场灾难，恰好有一个非寺院城镇被摧毁。 如果在这次破坏之后，朝圣者列出的最远的寺院都无法从自己的寺院到达，那么该朝圣者就会被认为是不快乐的。 

任务是选择一个非修道院节点进行删除，以使不满意的朝圣者的数量最大化，并计算有多少个节点达到了这个最大的效果。 

关键的微妙之处在于，每个朝圣者的名单仅取决于所有修道院之间的全局树木几何形状，而不取决于破坏情况。 破坏仅影响特定最远节点的可达性。 

约束 n 高达 100000 意味着我们无法重新计算所有节点对之间的距离，也无法通过最短路径重新计算来模拟每个节点的移除。 任何尝试 O(nm) 或 O(n^2) 策略的解决方案都会失败。 我们基本上需要线性或近线性预处理，然后对每个节点进行 O(1) 或 O(log n) 评估。 

一个常见的失败案例是假设每个朝圣者都有一个最远的修道院。 事实上，可能存在多个截然相反的修道院，只有当所有修道院同时无法到达时，朝圣者才会感到不高兴。 

另一种故障模式是忽略删除节点后连通性决定的“不可达”，这相当于询问删除的节点是否位于从朝圣者修道院到所有最远修道院的每条路径上。 

## 方法

 暴力策略将尝试摧毁每个候选城镇，并为每个朝圣者重新计算是否所有最远的修道院都已断开连接。 这需要重复的 BFS 或重复的树距离检查。 即使距离是预先计算的，删除后检查连接性也很昂贵，因为删除节点会将树分成多个组件，并且验证一组节点的分离将需要重新运行图遍历。 这会导致大约 O(n^2) 或更糟糕的行为。 

关键的观察结果是，“摧毁节点 v 会断开所有距离朝圣者源头最远的修道院”这一条件可以转化为对树路径的结构约束。 对于修道院 s 的固定朝圣者，考虑距离 s 最远的修道院的集合 F(s)。 当 F(s) 中从 s 到任意 t 的每条路径都经过 v 时，节点 v 就会让这个朝圣者不高兴。在树中，这相当于 v 位于 F(s) 中从 s 到每个 t 的所有路径的交集，这简化为支配者式结构：节点 v 必须将 s 与目标的并集分开，这意味着 v 是所有这些路径上的接合点。 

树路径的交集有一个清晰的解释：如果我们任意地对树进行根，那么对于每个 s，我们可以计算由 {s} ∪ F(s) 导出的虚拟树。 F(s) 中从 s 到每个 t 的所有根到目标路径的交集是从 s 到 F(s) 中所有节点的最低公共祖先的路径，以根项测量。 更准确地说，位于每条 s 到 t 路径上的节点正是从 s 到 LCA 的路径上最小化覆盖范围的最远集合端点的节点； 这简化为识别每个朝圣者独特的“核心部分”。

因此，每个朝圣者贡献一个路径段（可能是单个节点），我们需要在所有树节点 v 上计算有多少个这样的路径段包含 v。最后，我们必须将 v 限制为非修道院节点。 

为了有效地计算这些段，我们首先通过对树进行生根并使用 DFS + 重新生根或通过使用多源技术计算与所有修道院的距离来隐式计算所有对最远修道院结构，然后对于每个修道院 s 确定其最大距离 D 并收集实现 D 的所有节点。具有多个源的加权树的标准树直径技术为我们提供了每个节点的极限集。 

然后，对于每个 s，我们计算虚拟交集节点集作为其最远节点上的路径交集。 每个这样的交叉点都会减少到单个路径的贡献，我们可以使用树上差异技术（tree imos）对其进行标记：沿路径添加+1并在外部减去，从而允许聚合覆盖每个节点的朝圣者路径的数量。 

最后，我们评估所有非寺院节点，选择最大覆盖范围，并计算有多少个达到它。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²m) | O(n) | 太慢了 |
 | 最佳 | O(n log n) 或 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 在任意节点处将树作为根，并使用 DFS 预处理父数组和深度数组，存储二进制提升祖先。 这允许快速 LCA 查询来推理路径交叉点。 
2. 计算距离的方式使我们能够识别每个修道院中哪些其他修道院最远。 这可以通过来自所有修道院的多源 BFS/DFS 或通过使用虚拟结构上的两个 DFS 传递来计算所有修道院之间的距离来完成。 目标是了解每个修道院的最大距离 D 以及实现该距离的节点集。 
3. 对于每个修道院 s，识别所有最远的修道院 F(s)。 这是通过检查哪些节点与 s 的距离恰好为 D(s) 来完成的。 在树中，这些极值节点形成可以通过 LCA 分组处理的结构化子集。 
4.使用LCA将F(s)压缩为最小代表结构：重复取F(s)中节点的LCA来找到它们的交集结构。 关键思想是，从 s 到 F(s) 中每个节点的所有路径上的节点正是从 s 到由重复 LCA 聚合确定的特定“交汇点”的路径上的节点。 
5. 使用树上的差异数组标记此路径贡献。 对于路径 (u, v)，在 u 和 v 处递增，并在 LCA(u, v) 及其父路径处递减。 这确保了累积后，每个节点存储有多少条朝圣者路径经过它。 
6. 处理完所有修道院后，运行最终的 DFS 来累积从子节点到父节点的值，从而生成每个节点的覆盖计数。 
7. 迭代所有非修道院节点，找到最大覆盖值，并统计有多少节点达到该值。 

### 为什么它有效

 每个朝圣者恰好贡献一棵由节点组成的最小子树，如果要断开所有最远的目标与源的连接，这些节点是不可避免的。 该子树折叠为根到目标路径的并集，其交集是树中的单个路径段。 树差异传播确保每个节点准确地计算有多少个这样的不可避免的段包含它。 由于删除节点会破坏穿过该节点的所有路径，因此位于这些线段数量最多的节点会最大化其整个最远集合断开连接的朝圣者的数量。 聚合是精确的，因为每个朝圣者都在树路径上独立且累加地做出贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n, m = map(int, input().split())
mon = set(map(int, input().split()))

g = [[] for _ in range(n + 1)]
for _ in range(n - 1):
    a, b, c = map(int, input().split())
    g[a].append((b, c))
    g[b].append((a, c))

LOG = 18
parent = [[-1] * (n + 1) for _ in range(LOG)]
depth = [0] * (n + 1)
dist = [0] * (n + 1)

def dfs(u, p):
    for v, w in g[u]:
        if v == p:
            continue
        parent[0][v] = u
        depth[v] = depth[u] + 1
        dist[v] = dist[u] + w
        dfs(v, u)

dfs(1, -1)

for k in range(1, LOG):
    for v in range(1, n + 1):
        if parent[k - 1][v] != -1:
            parent[k][v] = parent[k - 1][parent[k - 1][v]]

def lca(a, b):
    if depth[a] < depth[b]:
        a, b = b, a
    diff = depth[a] - depth[b]
    for k in range(LOG):
        if diff & (1 << k):
            a = parent[k][a]
    if a == b:
        return a
    for k in reversed(range(LOG)):
        if parent[k][a] != parent[k][b]:
            a = parent[k][a]
            b = parent[k][b]
    return parent[0][a]

def add_path(u, v, diff):
    w = lca(u, v)
    diff[u] += 1
    diff[v] += 1
    diff[w] -= 1
    if parent[0][w] != -1:
        diff[parent[0][w]] -= 1

# find farthest monastery for each monastery
mon = list(mon)
m = len(mon)

def get_farthest(src):
    best = -1
    far = []
    for t in mon:
        d = dist[src] + dist[t] - 2 * dist[lca(src, t)]
        if d > best:
            best = d
            far = [t]
        elif d == best:
            far.append(t)
    return far

diff = [0] * (n + 1)

for s in mon:
    far = get_farthest(s)
    if not far:
        continue
    base = far[0]
    for t in far[1:]:
        add_path(base, t, diff)

# accumulate
def dfs2(u, p):
    for v, _ in g[u]:
        if v == p:
            continue
        dfs2(v, u)
        diff[u] += diff[v]

dfs2(1, -1)

best = -1
cnt = 0

for i in range(1, n + 1):
    if i in mon:
        continue
    if diff[i] > best:
        best = diff[i]
        cnt = 1
    elif diff[i] == best:
        cnt += 1

print(best, cnt)
```该解决方案首先在加权树上构建 LCA 机制，从而实现对数时间内的距离查询。 这`get_farthest`函数为每个修道院确定所有达到最大距离的修道院。 每个这样的集合都使用基于 LCA 的成对分解转换为路径贡献。 树上的差异数组将这些路径转换为节点覆盖计数。 最终的 DFS 聚合了贡献，因此每个节点都知道它影响了多少个朝圣者约束。 然后我们忽略修道院节点并选择最佳的非修道院节点。 

一个微妙的实现细节是，DFS 中的根选择不会影响正确性，因为所有路径分解仅依赖于 LCA 结构。 另一个是减去`parent[w]`需要小心时`w`是根。

 ## 边缘情况

 一个重要的情况是修道院最远的集合包含多个节点。 在简单的对称树中，修道院距两个端点的距离可以相等。 该算法可以处理此问题，因为它将整个最远集合转换为成对路径约束，确保保留交叉行为而不是假设单个目标。 

另一种情况是所有修道院都位于同一条道路上。 在这种情况下，每个最远的关系都会崩溃到该路径的端点，并且累积正确地集中在中间区域。 差分阵列传播确保即使多个路径严重重叠，也能正确计数堆栈，而不会重复计算超出预期贡献的结构交叉点。
