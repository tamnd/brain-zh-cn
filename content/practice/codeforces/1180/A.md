 ## 解决方案
 ## 问题理解

 我们被赋予了一个从单个细胞开始在网格上生长的形状。 在第一阶段只有一个细胞。 在接下来的每个阶段，形状都会通过附加与形状中已有的任何单元共享边缘的每个网格单元来扩展。 换句话说，每个步骤都会在四个基本方向上围绕当前图形添加完整的“单单元粗边框”。 

这会产生以初始单元为中心的菱形图案。 任务是确定形状完全扩展后存在多少个单位网格单元$n$按此规则次数。 

输入是单个整数$n$， 在哪里$1 \le n \le 100$，输出是最终形状中占用的单元总数。 

约束非常小。 和$n \le 100$，任何方法粗略地达到$10^8$简单的操作就可以轻松通过，但实际上这个问题具有封闭形式的结构，使得模拟变得不必要。 

简单的模拟将显式地维护单元集并逐层扩展它。 这在概念上可行，但随着形状呈二次方增长而变得低效。 然而，即使这里最坏的情况也很小，所以模拟不会超时，但对于理解结构来说没有必要。 

输入有效性方面不存在棘手的边缘情况。 唯一的边界条件是$n = 1$，其中答案必须恰好是 1 个单元格。 

## 方法

 蛮力解释很简单。 从原点的单个单元格开始。 对于每个步骤，扫描所有当前单元格并添加它们的四个邻居（如果它们尚不存在）。 如果我们维护一个集合，我们就确保没有重复。 后$n-1$扩展后，我们计算细胞总数。 

这是正确的，因为它直接遵循定义：每一步都包含与当前形状至少共享一条边的所有单元格。 

问题是这种方法隐藏了结构。 每层都会在前一个形状周围添加一个对称环。 如果我们观察几步后的形状，我们会观察到：

 在$n = 1$，我们有 1 个单元格。 

在$n = 2$，我们得到 5 个细胞的杂交。 

在$n = 3$，形状扩展到 13 个单元。 

在$n = 4$，它变成25个细胞。 

增量为 4、8、12 等。 每个新层都会添加$4(n-1)$细胞。 发生这种情况是因为形状的边界形成菱形，其周长与$n$。 

因此，我们不是模拟几何，而是将问题简化为对算术级数求和：$$1 + 4(1 + 2 + \cdots + (n-1))$$内部总和是$\frac{(n-1)n}{2}$，给予：$$1 + 2n(n-1)$$这种封闭形式消除了所有模拟，并将任务简化为常数时间算术。

 ## 算法演练

 1.读取整数$n$。 这代表我们从单个单元开始应用多少层扩展。 
2.如果$n = 1$，立即返回 1，因为没有发生膨胀并且形状仍然是单个晶胞。 
3. 计算扩展后添加的单元格数量：$2n(n-1)$。 这是通过对连续边界层的尺寸求和得出的。 
4. 为原始中心单元加 1。 
5. 输出最终结果。 

### 为什么它有效

 第一步之后，形状始终保持与网格轴对齐的完美对称菱形。 每个新层都贡献一个完整的边界，其长度随着层索引线性增加。 由于每一层均已完全形成且不与先前添加的单元重叠，因此单元总数恰好是独立边界贡献的总和。 这保证了算术级数正确地模拟生长，而不会遗漏或重复计算任何单元格。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())

if n == 1:
    print(1)
else:
    print(1 + 2 * n * (n - 1))
```该解决方案完全依赖于封闭式表达式。 特殊情况$n = 1$已明确处理，尽管该公式已正确计算$n = 1$以及。 

表达式$2n(n-1)$使用 Python 整数计算，它可以安全地处理远远超出约束的值。 不存在中间溢出问题。 

代码的结构直接反映了数学推导，没有模拟或辅助存储。
