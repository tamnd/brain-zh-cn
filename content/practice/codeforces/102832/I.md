 ## 解决方案
 ## 问题理解

 我们有一棵社区树。 一个社区`k`是配送中心。 对于其他每个社区，快递员从那里出发，重复随机均匀地选择其中一条相邻道路，直到到达`k`。 随机行进距离不仅仅是树的距离，因为快递员可以从中心走开然后回来。 

对于一个起步社区`i`，令随机距离为`D`。 预期的疲劳程度为：`i * E[D * x^D]`在哪里`x = px / qx`。 我们需要计算这个值的模`10^9 + 7`对于每个社区并对所有结果进行异或。 

该树可以包含`100000`社区。 任何为每个节点单独探索随机游走的解决方案都是不可能的，因为即使是单个随机游走也没有固定的长度。 树上的二次解已经可以执行`10^10`最坏情况下的操作，远远超出了一秒的限制。 我们需要一个线性或接近线性的树动态规划解决方案。 

棘手的情况是由随机游走而不是树结构引起的。 中心节点的距离为零，概率为 1，因此其贡献始终为零。 例如：```
2 1 1 2
1 2
```节点的答案贡献`1`是`0`，因为它已经在中心了。 将非根递归应用于根的解决方案可能会错误地创建非零值。 

另一个边缘情况是`x = 1`。 例如：```
3 1 1 1
1 2
1 3
```预期距离仍然是有限的，但生成函数公式必须以素数为模进行计算。 用普通整数距离替换幂或假设行走长度是树深度会给出错误的结果。 

## 方法

 直接方法将开始随机游走模拟或导出每个节点的每个可能距离的概率。 这是正确的，因为期望正是所有可能步行长度的加权和。 然而，可能的行走次数是无限的，因为信使可以重复地进入子树并返回。 即使将概率存储到合理的距离也是行不通的，并且对所有节点执行此操作会太慢。 

有用的观察是树上的随机游走具有简单的递归结构。 树根位于`k`。 对于一个节点`v`，第一个移动要么直接进入其父树，要么进入其子子树之一。 一旦步行进入子子树，它必须首先返回到`v`在最终走向父母之前。 这种独立性让我们可以使用生成函数来表达整个分布。 

定义：`Fv = E[x^D]`对于距离`v`到有根树的父侧。 如果`Sv`是`Fu`超过所有儿童`u`的`v`， 然后：`Fv = x / (deg(v) - x * Sv)`答案需要`E[D*x^D]`，通过对生成函数求导得到：`E[D*x^D] = x * Fv'(x)`导数也可以自下而上计算，因为它仅取决于子值和子导数。 树结构准确地给出了我们需要的顺序：首先处理子级，然后计算父级。

 | --- | --- | --- | --- |
 | 蛮力 | 最坏情况下呈指数 | 大| 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 树根位于`k`并存储每个节点的父节点和子节点。 DFS 订单提供后序序列，因此每个子订单都会在其父订单之前处理。 
2. 对于逆向 DFS 顺序中的每个非根节点，计算`Fv = E[x^D]`。 让`S`是已计算的子值的总和。 其递归式为：`Fv = x / (deg(v) - x*S)`分母是由可能进入子子树的行程引起的概率生成函数校正。 
3. 连同`Fv`, 计算`Hv = x*Fv'(x)`。 如果`T`是孩子的总和`H`值，微分递归给出：`Hv = x * (deg(v) + x^2*T) / (deg(v) - x*S)^2`这直接给出了所需的期望值，而不需要重建整个概率分布。 
4. 对于每个节点`i`, 乘以`Hi`经过`i`并对结果进行异或。 根的贡献为零，因为它的距离始终为零。 

为什么它有效：不变的是在处理一个节点之后，`Fv`表示从该节点到父节点的所有可能游走的完整生成函数，包括到后代的任意游览。 递归枚举步行所采用的第一条边，并通过乘法组合独立的子游览。 对这个精确生成函数进行微分可以得到问题所需的加权期望，因此每个计算值都符合数学定义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7

def solve():
    n, k, px, qx = map(int, input().split())
    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    x = px * pow(qx, MOD - 2, MOD) % MOD

    parent = [-1] * n
    order = [k - 1]
    parent[k - 1] = -2

    for v in order:
        for u in g[v]:
            if parent[u] == -1:
                parent[u] = v
                order.append(u)

    f = [0] * n
    h = [0] * n

    for v in reversed(order):
        if v == k - 1:
            continue

        s = 0
        t = 0
        for u in g[v]:
            if parent[u] == v:
                s += f[u]
                if s >= MOD:
                    s -= MOD
                t += h[u]
                if t >= MOD:
                    t -= MOD

        den = (len(g[v]) - x * s) % MOD
        inv = pow(den, MOD - 2, MOD)

        f[v] = x * inv % MOD
        h[v] = x * ((len(g[v]) + x * x % MOD * t) % MOD) % MOD
        h[v] = h[v] * inv % MOD * inv % MOD

    ans = 0
    for i in range(n):
        ans ^= (i + 1) * h[i] % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```第一个 DFS 构建了树的有根表示，无需递归，避免了链形树上的 Python 递归深度问题。 这`order`数组是从根向外的拓扑顺序，因此反转它可以保证每个孩子的生成函数都已被计算。 

数组`f`和`h`存储递归所需的两个数量。 总和`s`和`t`仅针对子树，而不是父树，因为父树方向代表子树的最终出口。 模逆是有效的，因为该语句保证最终分母不能被整除`10^9+7`。 

乘法为`h[v]`是模数完成的`MOD`每次操作后。 Python 整数不会溢出，但保持值减少可以避免不必要的增长，并直接遵循模块化公式。 

## 工作示例

 对于第一个样本：```

1 2
3 1
```根是节点`1`。

 | 1 | 根 | 被忽略 | 0 | 0 |

 贡献的异或为：`2 xor 3 = 1`该迹线表明，即使树深度为 1，叶子仍然可以具有非零的预期距离，因为步行可以通过相同的边返回。

 ## 边缘情况

 当起始节点是中心时，算法会跳过递归并将其答案贡献保留为零。 为了：```
2 1 1 2
1 2
```节点`1`是根，所以它的距离始终为零。 该算法从不对其应用子公式。 

什么时候`x = 1`, 的权力`x`不再减少长途步行的影响。 该公式仍然有效，因为它是从生成函数本身导出的，而不是从有限概率和导出的。 为了：```
4 2 1 1
1 2
2 3
3 4
```同样适用自下而上的计算，其中`x`成为`1`模数`MOD`。 

当一个节点有多个子节点时，总和必须排除父节点。 对于扎根于中心的星形来说，每片叶子在扎根的树中都没有子节点。 实施检查`parent[u] == v`，因此它不会意外地将边缘包含回中心并创建圆形循环。
