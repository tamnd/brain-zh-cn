 ## 解决方案
 ## 问题理解

 我们给出了一个圆形排列$N$房屋。 每栋房子要么已经有一个固定类别（大写字母）的所有者，要么是空的，以后可以分配任何类别。 每个类别都有货币价值。 

除此之外，还有称为收藏家的特殊代理人。 每个收集器选择一个固定的步长，然后使用该步长重复绕圈行走，直到返回到起始位置。 此步长受到限制，以便明确定义步行并均匀划分圆圈。 在步行过程中，只有当收集者访问的所有房屋都属于同一类别时，收集者才能成功。 如果发生这种情况，他会从每所拜访的房子中收取一次钱。 

重要的结构结果是具有步骤的收集器$s$（在哪里$s = d+1$) 访问所有指数同余模$s$。 因此，每个收集器都与一个残差类相关联，该残差类以某个除数为模$N$，并且仅当我们为空房子分配颜色后整个残基类别是单色的时它们才有效。 

目标是以最大化所有有效收集者同时收集的总资金的方式为所有空房子分配类别。 

约束条件是$N$素数的幂是至关重要的。 这意味着每个除数$N$是这样的形式$p^k$，因此除数结构是链而不是分支晶格。 这消除了多个独立素因数带来的复杂性，并使步长之间的子集关系更加清晰。 

从复杂性的角度来看，$N \le 10^5$排除任何关于位置或所有除数对的二次方。 任何显式模拟收集器或检查所有分配的解决方案都是立即不可行的。 即使迭代除数的所有子集也是不可能的，因此解决方案必须通过利用残差类和除数结构的对称性来压缩贡献。 

一个幼稚的错误是独立处理每个步骤：计算每个除数的每个残基类别的最佳颜色并对所有内容求和。 这严重夸大了，因为相同的房屋分配可以使许多不同的收藏家同时有效。 

另一个微妙的边缘情况是当房屋已经固定在多个剩余类别中时。 例如，与$N=8$，同一位置参与步长的类别$2$,$4$， 和$8$。 任何每步独立分配颜色的方法都会违反重叠类之间的一致性约束。 

## 方法

 直接的暴力方法是考虑将字母分配给$?$位置，并为每个分配计算所有有效的收集器。 对于每个除数$s$，我们会检查每个残基类模$s$并验证所有值是否匹配，然后添加其贡献。 这已经花费了$26^{\#?}$，甚至评估单个作业也需要对所有除数和所有残差类求和，这是$O(N \log N)$。 这远远超出了可行的限度。 

关键的观察是收集器仅依赖于残差类对除数取模$N$。 因此，我们不应该考虑单个房屋，而应该考虑这些剩余类别以及作业如何在它们之间相互作用。 

自从$N$是素数幂，因数形成链：$$1, p, p^2, \dots, p^k$$这意味着残基类以嵌套方式相互完善。 A类模$p^i$是一个联盟$p$模类$p^{i+1}$。 这种层次结构使我们能够推断最终着色的“周期性水平”。 

关键的重新表述是根据着色的确切时期来思考。 着色可能会意外地对类进行取模$p^i$单色，但发生这种情况是因为它已经在更精细的水平上是单色的。 因此，我们不是独立地计算每个级别，而是通过使用除数链上的包含-排除来分离“精确的周期性级别”来计算贡献。 

对于每个除数$s$，我们计算一个值，假设我们只关心在残差类模内强制执行一致性$s$。 这个值很简单：对于每个残基类别，我们根据固定字母和分配的值贪婪地选择最好的字母。 然而，这会多次计算不同的贡献$s$，因为在更精细的尺度上是单色的类自动意味着它在所有更粗略的尺度上都是单色的。 

为了纠正这个问题，我们从最小到最大处理除数（反之亦然），并沿着除数链应用莫比乌斯式减法。 这隔离了配置的贡献，其最小强制周期恰好是$s$。 最终的答案是所有确切级别的贡献之和。 

## 算法演练

 1. 列出 的所有约数$N$。 自从$N$是一个主要力量，这是一个简单的链条$p^0, p^1, \dots, p^k$。 
2. 对于每个除数$s$，计算一个初步值$f[s]$。 

计算$f[s]$，将数组划分为余数类模$s$。 对于每个类别，如果我们强制该类别中的所有位置共享一个字母，则计算最佳可实现值。 这是通过将固定字母的贡献相加来完成的$?$，然后选择使总价值最大化的字母。 
3. 计算完毕后$f[s]$，将它们转换为精确的贡献$g[s]$使用除数链上的包含。 我们按大小递增的顺序处理除数。 对于每个$s$，减去$f[s]$所有贡献都已归因于更精细的除数（即除以较小的除数）$s$）。 这确保了$g[s]$表示其最小均匀度尺度恰好为的配置$s$。 
4. 最终答案是所有答案的总和$g[s]$。 

### 为什么它有效

 每个有效的字母分配都会产生一个唯一的最小除数$s$这样所有收集器有效的残基类别都来自大规模的周期性结构$s$。 在较粗的级别上计算的任何贡献也可以通过较精细的周期结构来充分解释，因为在质数模数晶格中，周期性是嵌套的而不是独立的。 沿除数链的包含-排除确保每个结构配置以其最小定义比例精确计数一次，从而防止重叠收集器定义之间的重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input().strip())
    S = input().strip()
    k = int(input().strip())

    val = {chr(i): 0 for i in range(65, 91)}
    for _ in range(k):
        c, v = input().split()
        val[c] = int(v)

    # all divisors of N (prime power => chain)
    divisors = []
    x = N
    p = None

    tmp = N
    for i in range(2, int(tmp ** 0.5) + 1):
        if tmp % i == 0:
            p = i
            break
    if p is None:
        p = tmp

    while x > 1:
        divisors.append(x)
        x //= p
    divisors.append(1)
    divisors.sort()

    idx = {d: i for i, d in enumerate(divisors)}
    m = len(divisors)

    f = [0] * m
    g = [0] * m

    # precompute positions grouped by modulo each divisor
    for i, d in enumerate(divisors):
        groups = [[] for _ in range(d)]
        for j in range(N):
            groups[j % d].append(j)

        total = 0
        for grp in groups:
            best = 0
            for c in val:
                cur = 0
                for j in grp:
                    if S[j] == '?' or S[j] == c:
                        cur += val[c]
                    else:
                        cur = -10**18
                        break
                best = max(best, cur)
            total += best

        f[i] = total

    # inclusion-exclusion on chain
    for i in range(m):
        g[i] = f[i]
        for j in range(i):
            if divisors[i] % divisors[j] == 0:
                g[i] -= g[j]

    print(sum(g))

if __name__ == "__main__":
    solve()
```该实现首先计算所有除数，由于质数幂约束，这些除数形成一个简单的链。 对于每个除数，它按残基类别明确对索引进行分组，并通过尝试所有 26 个字母来评估每组的最佳统一分配。 此步骤捕获了强制执行该周期性结构的原始潜在贡献。 

第二阶段沿着除数链执行包含-排除。 由于每个较粗的除数聚合了更精细的周期结构，因此我们减去先前计算的贡献以避免重复计算。 最终总和仅汇总不可约定期贡献。 

## 工作示例

 考虑一个小例子$S = \text{"A?A?"}$,$N = 4$，有值$A=10$,$B=25$。 

我们首先考虑除数$1,2,4$。 

为了$s=1$，有一个包含所有位置的类。 我们能做的最好的事情就是选择一个字母。 如果我们选择$A$，只有位置 0 和 2 匹配固定约束，而其他位置必须一致分配，因此最佳值是在整个字符串上计算的。 

| s | 团体 | 每组最佳 | f[s] | f[s] |
 | --- | --- | --- | --- |
 | 1 | {0,1,2,3} | 一个选择| 40|
 | 2 | {0,2}, {1,3} | 两者都可以是 A | 40|
 | 4 | {0}、{1}、{2}、{3} | 个人选择| 40|

 在包含-排除之后，更精细的周期性解释了所有更粗糙的周期性，因此只保留了最具体的结构。 

| s | f[s] | f[s] | 克[s] |
 | --- | --- | --- |
 | 1 | 40| 0 |
 | 2 | 40| 0 |
 | 4 | 40| 40|

 结果是 40，对应于每个位置都是独立的最精细结构。 

现在考虑$S = \text{"A??A"}$。 这里，约束在步骤 2 中推向强周期性结构。$\{0,2\}$强烈喜欢$A$， 和$\{1,3\}$可以最佳地统一。 包含-排除将第 2 期的贡献隔离为主要贡献。

 ## 边缘情况

 一个关键的边缘情况是当固定字母出现在不同除数的冲突残基类中时。 例如，固定到一个字母的位置可能会迫使残基类别在一个除数处不是最佳的，但在另一个除数处是最佳的。 该算法处理这个问题是因为每个除数评估在计算局部最佳分配时严格遵守固定约束。 

另一个微妙的情况是所有字符都是“？”。 在这种情况下，每个类都可以独立分配，并且包含-排除将所有内容简化为最精细的周期性分解。 这确保了嵌套除数之间不会出现过度计数。 

第三种情况是固定字母稀疏出现但仍然强制执行全局周期结构。 分组步骤确保即使是稀疏约束也能在每个残差类中正确传播，而包含-排除可防止在多个除数级别对同一结构进行计数。
