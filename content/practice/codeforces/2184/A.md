 ## 解决方案
 ## 问题理解

 我们有$n$人们。 他们必须分成小组，每个小组有 2 或 3 名成员。 队伍组建后，每队独立选择两个文明之一。 

分配给某个文明的人数是选择该文明的所有团队规模的总和。 我们希望对团队规模和文明选择进行安排，使两个文明人口之间的差异尽可能小。 

对于每个测试用例，我们仅给出值$n$，并且我们必须输出可实现的最小差异。 

限制非常小。 最多有$10^4$测试用例和每个$n$至多是$10^4$。 即使是一个简单的$O(n)$每个测试用例的解决方案都会顺利通过。 尽管如此，问题的结构仍然允许$O(1)$解决方案。 

棘手的部分是认识到选择文明的是团队，而不是个人。 我们不能在两个文明之间随意分配人员。 每个团队同时贡献 2 或 3 人。 

考虑$n=2$。 只有一支队伍的规模为 2。一个文明有 2 人，另一个文明有 0 人，所以答案是 2。粗心的方法可能会假设我们可以单独分割人员，并错误地返回 0。 

考虑$n=5$。 我们可以组建 2 号和 3 号队伍。将 2 号队分配给一个文明，将 3 号队分配给另一个文明。 区别在于 1. 任何仅检查是否$n$是偶数还是奇数都会错过这个。 

考虑$n=7$。 一个有效分区是$2+2+3$。 文明总数可以变成$5$和$2$, 给予差异$3$， 或者$4$和$3$, 给予差异$1$。 组队后选择文明任务的能力至关重要。 

## 方法

 暴力方法将枚举所有表示方法$n$作为 2s 和 3s 的总和。 对于每个代表，它将尝试所有可能的团队分配给两个文明并记录最小差异。 

这是有效的，因为每个有效的解决方案都对应于一些团队分解和一些团队分配。 问题在于分解和赋值的数量呈指数增长。 即使对于中等值$n$，探索所有可能性变得不切实际。 

关键的观察结果是团队规模只有 2 人和 3 人。$$3 - 2 = 1,$$我们可以非常灵活地构建总计。 唯一重要的是剩下的$n$模 2。 

如果$n$是均匀的，我们总能将两个文明的人平分。 一种简单的构造是只组建规模为 2 的团队。然后每个文明都可以接收恰好一半的团队。 差值变为0。 

如果$n$是奇数，相等的分裂是不可能的，因为文明人口的总和必须是奇数。 最好的差异至少为 1。 

下一个问题是对于奇数是否总是可以实现差 1$n$。 

对于每一个奇数$n \ge 5$，我们可以写$$n = 3 + 2k.$$创建一支规模为 3 的团队并$k$团队规模为 2。由于剩余$2k$人们组成了一个均匀的总数，我们可以平均分配它们。 额外的 3 号团队为一个文明贡献的人数比另一个文明多出 1 人，产生的差异正好为 1。 

唯一不适合这种结构的奇数是$n=3$。 对于一支规模为 3 的队伍，一个文明获得全部 3 人，另一个文明获得 0 人，因此差异为 3。 

这完全决定了答案：

 -$n=3$给出 3.
 - 任何其他奇怪的情况$n$给出 1。 
- 任何偶数$n$给出 0，除了$n=2$，给出 2。 

这些情况可以更紧凑地写为$n \bmod 2$，特殊值除外$2$和$3$。

 ## 算法演练

 1. 阅读$n$。 
2.如果$n=2$，输出2。 

只有一支规模为 2 的队伍，因此一个文明接待所有人。 
3. 否则，如果$n=3$，输出3。 

只有一支3号队，所以一个文明接待所有人。 
4.否则，输出$n \bmod 2$。 

如果$n$是偶数，存在完美分裂，答案为 0。 

如果$n$是奇数且至少为 5，则存在差异为 1 的分裂，并且不可能有更小的差异，因为总人口是奇数。 

### 为什么它有效

 对于甚至$n$，仅组成规模为 2 的团队可以让总人口在两个文明之间平均分配，因此最小差异为 0。 

对于奇数$n \ge 5$， 写$n=3+2k$。 将 3 号队分配到一侧，将 2 号队平均分配。 文明人口相差正好 1。由于总人口是奇数，因此不可能存在 0 的差异。 

案例$n=2$和$n=3$非常特殊，因为只能组建一支团队。 一种文明接纳所有人，而另一种文明则不接纳任何人。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

ans = []
for _ in range(t):
    n = int(input())

    if n == 2:
        ans.append("2")
    elif n == 3:
        ans.append("3")
    else:
        ans.append(str(n % 2))

sys.stdout.write("\n".join(ans))
```前两个条件仅处理异常值。 为了$n=2$和$n=3$，只有一个团队，因此差值等于团队规模本身。 

对于每个较大的值，奇偶性完全决定了答案。 即使值也返回 0，因为可以进行均等分割。 奇数值返回 1，因为总人口为奇数，排除了差异 0，并且使用一支 3 号团队的构建实现了差异 1。 

不存在算术溢出问题，因为所有值都很小。 该实现对于每个测试用例仅执行一些恒定时间操作。

## 测试用例```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())

        if n == 2:
            ans.append("2")
        elif n == 3:
            ans.append("3")
        else:
            ans.append(str(n % 2))

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out

# provided sample
assert run("3\n2\n5\n12\n") == "2\n1\n0"

# minimum valid values
assert run("2\n2\n3\n") == "2\n3"

# smallest odd value with answer 1
assert run("1\n5\n") == "1"

# even value
assert run("1\n8\n") == "0"

# maximum constraint
assert run("1\n10000\n") == "0"

# large odd value
assert run("1\n9999\n") == "1"

 ## 边缘情况

 对于输入```
1
2
```该算法进入第一个特殊情况分支并返回 2。只有一个规模为 2 的团队，因此文明人口为$2$和$0$。 差值正好是 2。 

对于输入```
1
3
```该算法进入第二个特殊情况分支并返回 3。只有一支规模为 3 的团队，因此文明人口为$3$和$0$。 

对于输入```
1
5
```算法达到一般规则并返回$5 \bmod 2 = 1$。 一个有效的构造是将规模为 2 和 3 的团队分配给不同的文明，产生人口$2$和$3$。 

对于输入```
1
12
```算法返回$12 \bmod 2 = 0$。 我们可以组建六支规模为 2 的队伍，向每个文明派出三支队伍。 两个文明各接收6人，差额为0。
