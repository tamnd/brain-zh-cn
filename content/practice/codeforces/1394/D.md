 ## 解决方案
 ## 问题理解

 我们有一棵树`n`山脉，由`n-1`道路，以便从其他任何一座山都可以到达。 每座山都有一个高度`h_i`和一种疲倦`t_i`。 博博尼乌希望将道路组织成“挑战”，其中挑战是一条山高不下降的路径。 每条路都必须属于一个挑战，但山脉可以出现在多个挑战中。 挑战的疲劳度是其中所有山脉的疲劳值的总和，我们的目标是将道路划分为挑战，以最小化总的疲劳度。 

挑战来自于不降低的高度要求，这限制了如何将道路分组为单一路径。 因为`n`可以达到`2 * 10^5`，任何迭代所有可能路径的解决方案都是不可行的； 我们需要一个大致线性的算法`n`。 

一种简单的方法可能会尝试列出满足非递减属性的所有路径，然后选择覆盖所有边的分区。 这失败有两个原因。 首先，树中的路径数量是指数级的。 其次，即使我们忽略枚举，所有子集上的朴素 DP 也会花费`O(2^n)`时间。 边缘情况包括等高的山脉、叶节点和路径，其中一座山必须被多次计数，因为它充当连接多个递增序列的交汇处。 例如，如果根的高度较低，而所有子项的高度较高，则它必须包含在从其子项开始的每个挑战中。 

## 方法

 暴力方法将尝试将树分解为非递减路径的所有可能的分解，计算每个路径的疲劳度，并取最小值。 因为考虑了每个分区，所以保证了正确性，但分区数量的增长速度比`O(2^n)`。 即使有小`n`，这是不可行的。 

关键的见解是利用树结构和单调性约束。 考虑每座山及其孩子。 如果孩子的身高比父母高，则可以从父母开始参加同一挑战。 如果较低，我们必须对孩子开始新的挑战。 这一观察结果提出了树上的动态编程解决方案：对于每个节点，跟踪在两种情况下覆盖其子树中的所有边所需的最小疲劳度。 情况一是该节点是其父挑战的起点； 情况二是它开始自己的挑战。 使用后序遍历，我们结合子节点的结果来计算当前节点的最小疲劳度，添加`t_i`当一个节点参与多个挑战时。 该问题简化为一个 DP，它处理每个节点一次并合并其子节点的结果，给出`O(n)`时间。

 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 树上的最优 DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 任意为树求根，例如在节点 1 处。这简化了父子关系并确保单一遍历顺序。 
2.为每个节点定义一个DP`u`。 我们维持`dp[u]`作为覆盖以 为根的子树中所有边的最小疲劳总和`u`。 为了方便起见，跟踪两个值：`dp[u].up`如果路径从`u`继续到其父级并且`dp[u].alone`如果`u`为孩子们开启新的挑战。 
3. 按后序遍历树。 对于每个节点，处理所有子节点`v`。 如果`h[v] > h[u]`，孩子可以扩展挑战`u`。 那么贡献给`dp[u].up`是`dp[v].up`。 否则，我们必须开始新的挑战`v`，添加`dp[v].alone`加`t[u]`到`dp[u].alone`。 
4.处理完所有孩子后，确定最小疲劳度`u`通过选择以最少的重复计数覆盖所有边缘的值组合。 包括`t[u]`由于孩子无法延长路径，因此每次必须计入多次挑战。 
5. 返回`dp[root].up`，代表所有道路的最小总疲劳度。 

这是有效的，因为对于任何节点来说，不变式是：`dp[u]`考虑到它是继续其父挑战还是重新开始，正确捕获其子树所需的最小疲劳度。 后序遍历可确保所有子子树在父子树之前得到处理，因此组合是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

n = int(input())
t = list(map(int, input().split()))
h = list(map(int, input().split()))
edges = [[] for _ in range(n)]

for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    edges[u].append(v)
    edges[v].append(u)

def dfs(u, parent):
    max_gain = []
    total = 0
    for v in edges[u]:
        if v == parent:
            continue
        child = dfs(v, u)
        if h[v] > h[u]:
            total += child
        else:
            total += child
            max_gain.append(t[v])
    if not max_gain:
        return total + t[u]
    max_gain.sort(reverse=True)
    return total + t[u] + max_gain[0]

ans = dfs(0, -1)
print(ans)
```我们使用递归来实现后序遍历。 每个孩子都会根据其父母的身高进行检查，以决定是否可以继续挑战。`max_gain`捕获无法合并的可选添加的子山。 排序可确保我们在需要时首先添加最大的贡献。 递归与`sys.setrecursionlimit`确保我们可以处理很深的树木。
