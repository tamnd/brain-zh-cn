 ## 解决方案
 ## 问题理解

 我们有一个线性花园，有_n_个连续的床，这些床的一个子集包含水龙头。 每个水龙头一旦打开，就会立即给它所占据的床浇水，并且在接下来的每一秒，它都会向两个方向扩展一张床的覆盖范围。 我们的目标是确定在所有水龙头同时打开的情况下为所有床浇水所需的最短秒数。 

输入指定多个测试用例，每个测试用例给出床位数量_n_、抽头数量_k_以及抽头位置。 每个测试用例的输出都是一个整数：每张床浇水的最早秒数。 

约束很小：_n_ 最多为 200，并且所有测试用例的 _n_ 总和不超过 200。这意味着每个测试用例大约为 O(n²) 的任何解决方案都可以轻松运行，因此如果需要，我们可以单独模拟或处理每个床。 

不明显的边缘情况包括水龙头聚集在一端或多个水龙头严重重叠的花园。 例如，如果 _n = 5_ 并且水龙头位于位置 1 和 2，则最左边的苗床会立即浇水，但最右边的苗床距离较远，仅查看最近的水龙头的天真的方法可能会低估所需的时间。 当花园的一端只有一个水龙头时，就会发生另一种微妙的情况； 该算法必须考虑从任何水龙头到床的最远距离，而不仅仅是最近的距离。 

## 方法

 蛮力方法是逐秒模拟浇水过程。 我们可以维护一个代表花园床的数组，并且每一秒都扩大每个水龙头的浇水范围。 每一秒，我们都会检查所有床是否都浇过水。 这是正确的，但效率低下：对于拥有 200 个床和一个水龙头的最坏情况花园，此模拟可能每秒执行多达 200 次操作，持续 200 秒，导致大约 40,000 次操作。 虽然考虑到问题的限制是可以接受的，但它过于冗长。 

最佳方法源于观察，对于任何床，浇水的最短时间由最近的水龙头决定。 如果我们对水龙头进行排序并检查从每个床到最近的水龙头的距离，所有床的这些最小距离的最大值就会给出答案。 这是有效的，因为水以每秒一个床的速度从每个水龙头对称地扩散，因此距离所有水龙头最远的床决定了所需的总时间。 

蛮力之所以有效，是因为它确实模拟了该过程，但它在优雅和清晰度方面失败了。 观察到所需的时间只是从床到最近的水龙头的最大距离，这让我们可以在排序后将问题简化为简单的线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 已接受但冗长 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 干净，接受|

 ## 算法演练

 1. 对于每个测试用例，读取床位数量 _n_、抽头数量 _k_ 以及抽头位置列表。 对抽头位置进行排序可简化距离计算。 
2. 初始化一个变量来跟踪床浇水所需的最长时间。 这代表了答案。 
3. 从 1 到 _n_ 迭代每张床。 对于每个床，计算到每个水龙头的绝对距离，然后选择最小距离。 这给出了浇灌该特定床所需的时间。 
4. 如果当前床的最小距离大于之前的最大距离，则更新最大时间。 扫描所有床位后，最大时间代表整个花园浇水的最早秒数。 
5. 打印当前测试用例的最长时间。

工作原理：该算法可确保每张床位均得到统计。 来自多个水龙头的水不会减少距最近水龙头距离以下的床的时间，最远的床控制总浇水时间。 对于这种小输入大小，排序是可选的，但它使最近抽头计算在概念上更简单。 不变量是在每次迭代中，`max_time`保持迄今为止遇到的最长的最小距离。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    taps = list(map(int, input().split()))
    max_time = 0
    for bed in range(1, n + 1):
        min_dist = min(abs(bed - tap) for tap in taps)
        max_time = max(max_time, min_dist)
    print(max_time + 1)
```该解决方案首先读取测试用例的数量。 对于每个测试用例，它都会读取花园大小和水龙头位置。 床上的循环计算到每个水龙头的距离，选择最近的，并跟踪最大距离。 我们添加一个是因为第一秒给水龙头自己的床浇水。 仔细处理索引可确保我们不会超出范围并尊重从 1 开始的床位编号。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(nk) | O(nk) | 对于每个床，我们计算到所有 k 个水龙头的距离。 当 n ≤ 200 且 k ≤ n 时，这是可以接受的。 |
 | 空间| O(n + k) | 用于点击的数组和最大时间的简单标量跟踪。 |

 鉴于 n 和 k 都很小，并且所有测试用例的总和≤ 200，该解决方案在 1 秒限制内运行良好，并且使用最少的内存。

 ## 边缘情况

 对于在该床上有水龙头的单床花园，输入`1 1\n1`，算法计算床 1 的最小距离 0，加 1，得到总秒数 1。对于水龙头仅占据末端的花园，`5 2\n1 5`，床 2 和 4 到最近水龙头的最小距离为 1，床 3 的距离为 2。最大最小距离为 2，总秒数为 3。这些示例确认该方法正确处理边界和单击覆盖。
