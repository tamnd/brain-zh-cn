 ## 解决方案
 ## 问题理解

 这个问题中的图表不是以通常的方式给出的。 输入不是列出存在的边，而是列出显式断开连接的顶点对。 未出现在此列表中的每一对顶点都应被视为在它们之间具有边。 

因此，该结构实际​​上是一个密集的图，除了一组禁止的连接之外，几乎所有东西都是连接的。 任务是确定这个隐式图如何分裂成连接的组件，并报告存在多少个这样的组件以及每个组件的大小。 

一种有用的思考方式是，每个顶点一开始都可能与所有其他顶点相连，并且每个禁止对都从这个完整的图中删除了一条边。 因此，连通性取决于这些缺失的边是否足以将顶点分成组。 

约束足够大，任何尝试显式构建完整图的解决方案都是不可能的。 一个完整的图有多达 200000 个顶点，其边数约为 n2，这远远超出了内存和时间的限制。 即使迭代所有对也将需要大约 4 × 10^10 次操作，这在 2 秒限制内是不可行的。 这立即排除了显式构造图上的邻接矩阵和朴素 BFS/DFS。 

微妙的困难在于，与隐式完整图相比，缺失的边是稀疏的。 该结构比标准图遍历问题更接近补图问题。 

一些边缘情况很容易出错。 

如果不存在禁止对，则该图是完全图，因此恰好具有大小为 n 的一个分量。 假设输入边是实际边的简单方法会错误地将其视为空图并生成大小为 1 的 n 个分量。 

如果每个可能的对都被禁止（由于约束这是不可能的，但在概念上有用），则该图将有 n 个孤立的顶点。 仅跟踪缺失边缘而不正确处理隔离的解决方案可能会失败。 

另一个微妙的情况是禁止边缘形成星形图案。 例如，如果涉及顶点 1 的所有对都丢失，则顶点 1 会变得孤立，而其余的则保持完全连接。 不考虑补体结构的简单遍历可能会错误地合并或拆分这些组。 

## 方法

 蛮力的想法是显式地构造补图的邻接表。 对于每一对顶点，我们检查它是否是禁止的。 如果没有，我们添加一条边。 这立即变得不可能，因为迭代所有对的时间复杂度为 O(n²)，并且在最坏的情况下存储邻接关系也是 O(n²)。 

关键的观察是我们永远不需要显式枚举边。 每个顶点最初都与所有其他顶点连接，因此两个顶点未连接的唯一原因是我们从禁止列表中有证据表明它们已断开连接。 这建议为每个顶点维护未连接到的顶点集。 

当我们从顶点 v 执行 BFS 或 DFS 时，我们希望移动到仍然“可用”的所有顶点，这意味着除了那些明确禁止的顶点和已经访问过的顶点之外的所有顶点。 面临的挑战是在不扫描所有 n 个候选点的情况下有效地找到这些可用顶点。 

这是基于集合或有序结构变得至关重要的地方。 我们维护一组未访问的顶点。 在处理顶点 v 时，我们迭代未访问的集合，但跳过 v 禁止的顶点。v 的禁止邻居存储在哈希集中，因此我们可以有效地测试成员资格。 每次我们确认一个有效的邻居时，我们都会将其从未访问集中删除并继续。

重要的效率技巧是每个顶点从未访问的集中删除一次。 尽管我们可能会多次检查它，但所有 BFS 步骤的总工作量在 n 加 m 中保持线性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（显式图）| O(n²) | O(n²) | 太慢了|
 | 最优（集合 + BFS 超过补集）| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 我们构建禁止边的表示，然后在隐式补图上运行 BFS。 

1. 将所有禁止对存储在基于哈希的结构中，并按顶点对它们进行分组。 这允许恒定时间检查两个顶点之间是否缺少边。 目标是快速测试补图中的邻接性。 
2. 维护一组所有未访问过的顶点。 该集合表示尚未分配给组件的顶点的边界。 
3. 当未访问集不为空时，从中选取任意顶点 v 并为新组件启动 BFS。 该 BFS 的大小将决定一个连接组件的大小。 
4. 用 v 初始化一个队列，并将 v 从未访问集中删除。 这确保我们永远不会处理同一个顶点两次。 
5. 当队列不为空时，弹出一个顶点x。 我们想要找到补图中与 x 连接的所有尚未访问的顶点。 这意味着除了 x 本身以及 x 明确禁止的顶点之外的所有顶点。 
6. 迭代未访问集并识别不在 x 的禁止列表中的顶点。 每个这样的顶点在补图中都是相邻的，因此我们将其添加到队列中并将其从未访问的集合中删除。 
7. 继续，直到队列耗尽。 至此，我们已经发现了v的全连通分量。 
8. 记录该组件的大小，并对另一个未访问的顶点重复该过程。 

其高效工作的关键原因在于，每个顶点都从​​未访问的集合中删除一次，并且每次删除都对应于补图中确认的边遍历。 

### 为什么它有效

 在任何时刻，未访问的集合都包含尚未分配给任何组件的顶点。 当处理顶点 x 时，仍在未访问集中的每个顶点都是补图中的潜在邻居。 唯一的例外是 x 明确禁止的情况。 

当我们将未访问的顶点 y 移至队列时，我们断言不存在禁止边 (x, y)，这意味着隐式图中存在边。 由于 BFS 会探索此邻接定义下的所有可到达顶点，因此最终将发现通过允许的边可到达的每个顶点。 因为我们从不重新访问顶点，所以组件保持不相交，并且每个顶点只分配一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import defaultdict, deque

def solve():
    n, m = map(int, input().split())
    
    forbidden = defaultdict(set)
    for _ in range(m):
        x, y = map(int, input().split())
        forbidden[x].add(y)
        forbidden[y].add(x)
    
    unvisited = set(range(1, n + 1))
    components = []
    
    while unvisited:
        start = next(iter(unvisited))
        unvisited.remove(start)
        
        q = deque([start])
        size = 0
        
        while q:
            v = q.popleft()
            size += 1
            
            to_remove = []
            for u in unvisited:
                if u not in forbidden[v]:
                    q.append(u)
                    to_remove.append(u)
            
            for u in to_remove:
                unvisited.remove(u)
        
        components.append(size)
    
    components.sort()
    print(len(components))
    print(*components)

if __name__ == "__main__":
    solve()
```禁止的邻接被存储为集合的字典，因此成员资格检查的复杂度为 O(1)。 未访问的集合允许我们避免重新访问顶点，并且在迭代后延迟删除顶点可以避免在迭代期间修改集合。 

BFS 循环通过扫描当前未访问的池并仅选择有效的邻居来扩展组件。 虽然这看起来像一个嵌套循环，但每个顶点都被从`unvisited`恰好一次，因此成功插入组件的总数与 n 成线性关系。 

最后需要进行排序，因为组件必须按非降序打印。 

## 工作示例

 ### 示例 1

 输入：```
5 5
1 2
3 4
3 2
4 2
2 5
```我们从未访问的 = {1,2,3,4,5} 开始。 

我们选择 1 作为第一个开始。 

| 步骤| 当前| 之前未访问过 | 禁止检查 | 新增 | 元件尺寸|
 | ---| ---| ---| ---| ---| ---|
 | 1 | 1 | {1,2,3,4,5} | 2 不允许？ 是的，禁止吗？ 没有| 2,3,4,5 禁止除外 | 4 |

 顶点 1 连接到除明确禁止的之外的所有顶点。 经过 BFS 之后，我们得到一个大小为 4 的分量。 

剩余未访问 = {2}。 

现在从 2 开始。 

| 步骤| 当前| 之前未访问过 | 禁止检查 | 新增 | 元件尺寸|
 | ---| ---| ---| ---| ---| ---|
 | 1 | 2 | {2} | 无 | 无 | 1 |

 我们以组件 [4,1] 结尾，排序为 [1,4]。 

这证实了禁止边将单个顶点与密集核心隔离开来。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n + m) 摊销 | 每个顶点被删除一次，每个禁止边被存储一次 |
 | 空间| O(n + m) | 未访问集和禁止邻接的存储|

 该结构通过从不显式构建边来避免二次枚举。 即使内部循环扫描集合，从未访问到访问的每个顶点转换都会发生一次，这在实践中使总工作保持线性。

 ## 边缘情况

 当没有禁止边时，算法应立即生成包含所有顶点的单个组件。 未访问集从所有节点开始，从任何节点开始的第一个 BFS 将接受所有其他节点，因为没有一个节点被禁止列表排除。 

当单个顶点与所有其他顶点被禁止时，该顶点将变得孤立，而其余图保持完全连接。 从任何非隔离节点开始的 BFS 永远不会包含隔离顶点，因为它在邻接检查期间始终被排除。 

当禁止边在顶点对之间形成不相交约束时，补图就变为完全连接。 BFS 会将所有内容合并到一个组件中，因为每个顶点仍然可以通过允许的边到达。
