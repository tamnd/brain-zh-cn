 ## 解决方案
 ## 问题理解

 该问题要求我们处理放置在平面上的一组房屋上的许多拟议电缆线路。 对于每条线，我们需要从任何房屋到该线的最大垂直距离。 官方声明将房屋描述为点，将电缆计划描述为线`Ax + By + C = 0`。 

到一点的距离`(x, y)`这样的一行是：$$\frac{|Ax + By + C|}{\sqrt{A^2+B^2}}$$一次查询中每栋房屋的分母都是相同的，因此真正的任务是找到最大值`|Ax + By + C|`所有点之中。 

输入尺寸很大。 高达`2 * 10^5`房屋和`2 * 10^5`查询，一种检查每所房子的每个查询执行的解决方案`4 * 10^10`的操作，远远超出了比赛时间限制。 我们需要对房屋进行预处理，以便每个查询都接近对数时间。 

关键的几何观察是一组点上的线性函数的最大值总是在凸包上达到。 船体内的所有点都是无关的，因为它们是其他点的凸组合，并且线性函数在那里不能有严格的最大值。 问题变成凸包支持查询问题。 

有一些边缘情况会破坏粗心的解决方案。 如果所有房屋都位于一条线上，则凸包只有两个顶点。 例如：```
2 1
0 0
5 5
1 -1 0
```线路`x - y = 0`包含两栋房子，所以答案是：```
0.0000000000
```假设至少三个船体点的解决方案可能会失败。 

另一个问题是答案使用绝对值。 考虑：```
2 1
0 0
1 1
1 0 -10
```表达式值为`-10`和`-9`，所以最大绝对值为`10`。 仅搜索最大有符号值将错误返回`9`。 

第三种微妙的情况是最佳点不是原始输入点。 距某个方向最远的点始终位于船体上，但不一定是输入顺序中的第一个或最后一个点。 任何依赖输入排序的解决方案都会默默地失败。 

## 方法

 直接解决方案很简单。 对于每个查询，计算每个房屋的线表达式的值，保留最大的绝对值，然后除以归一化因子。 这是正确的，因为它检查答案的确切定义。 然而，随着`n`房屋和`q`查询，复杂度为`O(nq)`，大致变成`4 * 10^10`以最大输入大小进行评估。 

改进来自于对表达式结构的认识。 对于查询法线向量`(A, B)`，我们需要：$$\max |A x + B y + C|$$这`C`部分仅平等地移动所有值，因此我们需要以下值的最大值和最小值：$$A x + B y$$覆盖所有房屋。 凸包恰好包含每个方向的极值点。 这将问题转化为寻找凸多边形的支撑点。 

构建凸包后，每个查询都成为凸包上的二分搜索。 固定方向的点积围绕凸多边形以单峰方式变化，因此我们可以在对数时间内定位极值顶点。 基于凸包的极端查询是凸多边形有序结构的标准使用。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(nq) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n log n + q log n) | O(n log n + q log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取所有房屋坐标并使用单调链算法构建凸包。 删除内部点，因为它们永远无法最大化线性表达式。 
2. 按逆时针顺序存储外壳顶点。 排序很重要，因为凸多边形周围的点积值形成了可以进行二分搜索的形状。 
3. 对于每个查询行，提取`A`,`B`， 和`C`。 方向`(A, B)`告诉我们船体的哪一侧最远。 
4. 求最大值`A*x + B*y`在船体上。 这是通过对循环凸多边形进行二分搜索来完成的。 
5、用方向搜索同样的方法求最小值`(-A, -B)`。 否定方向会将最小查询变成最大查询。 
6. 将两个极端结合起来。 最大绝对表达值是：$$\max(\text{maxValue}+C,\;-(\text{minValue}+C))$$然后除以`sqrt(A^2+B^2)`。 

为什么它起作用：凸包包含原始点集的所有可能的极值点。 对于任何方向向量，线性函数在船体上达到最大值和最小值。 由于距离公式只是一个绝对线性表达式除以一个常数，因此两个支持查询准确地给出了答案所需的两个候选值。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def cross(a, b, c):
    return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

def build_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def dot(p, a, b):
    return p[0] * a + p[1] * b

def support(poly, a, b):
    n = len(poly)
    if n == 1:
        return dot(poly[0], a, b)

    l, r = 0, n - 1
    while l < r:
        m = (l + r) // 2
        cur = dot(poly[m], a, b)
        nxt = dot(poly[(m + 1) % n], a, b)
        if cur <= nxt:
            l = m + 1
        else:
            r = m
    ans = dot(poly[l], a, b)
    ans = max(ans, dot(poly[(l - 1) % n], a, b))
    ans = max(ans, dot(poly[(l + 1) % n], a, b))
    return ans

def solve():
    n, q = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    hull = build_hull(pts)

    out = []
    for _ in range(q):
        A, B, C = map(int, input().split())

        mx = support(hull, A, B)
        mn = -support(hull, -A, -B)

        value = max(abs(mx + C), abs(mn + C))
        ans = value / math.sqrt(A * A + B * B)
        out.append(f"{ans:.12f}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```外壳结构删除了隐藏在多边形内的点。 这`cross`函数检查最后两个船体边缘是否会创建非左转，这意味着中间点不能属于凸边界。 

这`support`功能是核心优化。 它搜索投影到的顶点`(A, B)`是最大的。 围绕找到的索引进行的最终检查处理平坦边缘并避免相等投影值带来的问题。 

查询处理执行两个支持查询。 一种是找到最大投影，另一种是通过反转方向向量来找到最小值。 仅在知道两个极值后才应用绝对值，这避免了忘记负数的常见错误。

 ## 边缘情况

 对于共线房屋：```
2 1
0 0
5 5
1 -1 0
```外壳仅包含两个端点。 支持查询检查两个可能的顶点，并且线表达式对于两个顶点都为零，给出正确的答案。 

对于绝对值问题：```
2 1
0 0
1 1
1 0 -10
```两个表达式的值为`-10`和`-9`。 该算法计算最大和最小投影，然后应用绝对值，产生`10`。 

对于输入顺序有误导性的情况：```
4 1
100 100
0 0
100 0
0 100
1 1 0
```根据任何有用的排序，最远的点不是第一个输入点。 外壳消除了排序假设，并且支持搜索找到了正确的极端顶点。
