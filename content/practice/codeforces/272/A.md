 ## 问题理解

 迪马和他的朋友们正在通过计数游戏来决定谁来打扫公寓。 每个人，包括迪玛，都会伸出一到五根手指。 然后，他们从迪马开始绕圈数数，总数等于显示的所有手指的总和。 计数结束的人必须清洁。 

输入给出 Dima 的好友数量`n`以及表示每个朋友将展示多少根手指的整数列表。 迪马想要选择几个手指，以避免成为计数停止的人。 输出是 Dima 保证他安全的选择数量。 

限制很小：`n`最多 100 个，每个朋友展示 1 到 5 个手指。 这意味着任何循环 Dima 可能的手指计数（1 到 5）并对总手指求和的算法都足够快。 除了基本算术之外，不需要复杂的数据结构或优化。 当朋友的手指加上 Dima 的选择之和恰好可以整除时，就会出现边缘情况`n + 1`，这决定了迪马是否被选中。 例如，如果迪马有 1 个朋友露出 1 个手指，那么总计数可以是 2 到 6，具体取决于迪马的手指，并且只有总数能被 2（圆圈大小）整除的总数才会落在迪马身上，而其他人则避开他。 粗心的解决方案可能会错误计算模数或忘记包含从 1 到 5 的所有可能选择。 

## 方法

 由于可能性范围较小，蛮力方法本质上已经是最佳的。 我们可以枚举 Dima 的每个选择（1 到 5），计算所有朋友的手指加上 Dima 的选择的总和，然后检查总模数是否等于 Dima 的位置。 由于 Dima 总是开始计数，因此他的位置是索引 1。如果模数为零，则计数在 Dima 结束，因此他输； 否则，他就安全了。 

这种方法之所以有效，是因为 Dima 的选择数只有 5 个，所以运算总数极少（即使对于`n = 100`）。 这里不存在渐近瓶颈。 关键的见解是认识到绕圆计数相当于计算对圆大小取模的总和。 一旦你明白了这一点，解决方案就变成了简单的算术检查，并且不需要巧妙的组合或动态编程。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个候选人 O(n)，总共 O(5n) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`，迪玛的好友数量，并读取数组`friends`包含每个朋友展示的手指数量。 
2. 计算`total_friends`，朋友展示的所有手指的总和。 这是了解 Dima 每个选择的总数所必需的。 
3. 初始化计数器`safe_choices`为零。 这将存储有多少手指选择可以保证 Dima 的安全。 
4. 循环遍历 Dima 所有可能的手指计数，从 1 到 5。对于每个选择`d`:

 - 计算总计数为`total_friends + d`。 
- 如果`(total_friends + d) % (n + 1) != 1`, 增量`safe_choices`。 模数`(n + 1)`表示圆的大小，计数从 Dima（位置 1）开始。 如果余数等于 1，则迪马的计数结束，因此他不安全。 
5. 测试完所有五个选项后，打印`safe_choices`。 

为什么它有效：不变的是模算术正确地模拟了循环计数。 圈子里有`n + 1`人，并在计数`k`从位置 1 开始的步骤结束于`(1 + k - 1) % (n + 1) + 1`。 这个公式确保每个可能的总计数都映射到正确的人，并且我们正确地识别哪些选择避免了 Dima。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
friends = list(map(int, input().split()))
total_friends = sum(friends)

safe_choices = 0
for d in range(1, 6):
    if (total_friends + d) % (n + 1) != 1:
        safe_choices += 1

print(safe_choices)
```该代码使用有效地读取输入`sys.stdin.readline`。 我们计算一次朋友的手指总和，然后循环遍历 Dima 的可能选择。 模检查`(total_friends + d) % (n + 1) != 1`确保迪玛不是计数停止的人。 使用`range(1, 6)`准确地涵盖了五个有效的手指计数。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    friends = list(map(int, input().split()))
    total_friends = sum(friends)
    safe_choices = 0
    for d in range(1, 6):
        if (total_friends + d) % (n + 1) != 1:
            safe_choices += 1
    return str(safe_choices)

# Provided samples
assert run("1\n1\n") == "3", "sample 1"
assert run("2\n2 1\n") == "3", "sample 2"

# Custom cases

assert run("3\n1 1 1\n") == "3", "all friends show minimum fingers"

assert run("2\n3 5\n") == "2", "sum of friends is 8, testing modulo wrap"

 -`d = 3`→ 总计 8 → 8 % 2 = 0 → 安全
