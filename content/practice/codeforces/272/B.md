 ## 解决方案
 ## 问题理解

 我们得到一个正整数序列和一个将每个整数映射到非负值的函数。 该函数是递归定义的：它将从 0 发送到 0，忽略 2 的因数，每次遇到奇数时，我们实际上贡献一个单位并继续处理除以 2 的整数。 

解释这一点的一个有用方法是，该函数计算我们删除尾随二进制数字直到达到零的次数，但只计算来自奇数部分的贡献。 具体来说，f(x) 值恰好是 x 的二进制表示形式中 1 的个数。 这是因为除以二会将二进制表示右移，而当数字为奇数时减一对应于删除一组位。 

任务是计算存在多少对索引 i 和 j 使得 i 小于 j 并且 a[i] 和 a[j] 的函数值相等。 换句话说，我们需要根据二进制 popcount 对数字进行分组，并计算每个组内可以形成多少对。 

输入大小最多可达 100000 个元素，每个元素最多 10^9。 在最坏的情况下，对所有对进行二次比较将涉及大约 50 亿次检查，这太慢了。 我们需要一种线性或接近线性的方法。 

当所有数字都相同或所有数字具有不同的二进制弹出计数时，就会出现微妙的边缘情况。 在第一种情况下，每对都有贡献，导致 n(n−1)/2。 在第二种情况下，答案为零。 幼稚的实现可能会低效地重复重新计算 f(x)，从而导致不必要的开销甚至超时。 

## 方法

 强力解决方案将计算每个元素的 f(a[i]) 并将其与每个其他元素进行比较。 即使计算 f(x) 是高效的，比较所有对仍然需要 O(n²) 成本，这大约是 n = 10⁵ 时的 10^10 次操作，这是不可行的。 

关键的观察是我们实际上不需要显式地比较对。 我们只关心 f(x) 的每个值出现了多少次。 一旦频率已知，每个组都会贡献两个元素的组合。 如果某个特定值出现 k 次，则它贡献 k(k−1)/2 对。 

因此，问题简化为计算 f(a[i]) 值的频率图。 由于 f(x) 是 x 中设置的位数，因此我们可以使用位计数操作直接计算它，具体时间为 O(log x) 或摊销 O(1)，具体取决于实现。 这将问题转化为具有散列或数组计数的线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | f(x) 的频率 | O(n log A) | O(n log A) | O(n) | 已接受 |

 ## 算法演练

 1. 从输入序列中读取所有整数。 

我们需要立即存储或处理它们，以便我们可以计算它们的转换值。 
2. 对于每个数字 a[i]，计算 f(a[i])。 

由于 f(x) 等于 x 中设置的位数，因此我们计算 popcount。 这将递归函数简化为直接位操作。 
3. 维护一个字典（或哈希映射）来计算每个 f 值出现的次数。 

这允许我们根据转换结果对数字进行分组，而无需排序。 
4. 处理完所有元素后，迭代图中的所有频率值。 

对于每个频率 k，将 k(k−1)/2 添加到答案中，因为该组内的每一对都是有效的。 
5. 输出累加结果。 

### 为什么它有效

 正确性依赖于将数组划分为由相等的 f(x) 值定义的等价类。 我们计算的每一对恰好是同一类内的一对索引。 由于每个有效对必须恰好来自一个类，并且类内的每一对都是有效的，因此对所有类求和会产生准确的计数，没有重叠或遗漏。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    a = list(map(int, input().split()))

    freq = {}
    ans = 0

    for x in a:
        v = x.bit_count()
        if v in freq:
            freq[v] += 1
        else:
            freq[v] = 1

    for cnt in freq.values():
        ans += cnt * (cnt - 1) // 2

    print(ans)

if __name__ == "__main__":
    main()
```该解决方案读取输入一次并独立处理每个数字。 关键操作是`bit_count()`，它在 Python 中有效地计算设置位数。 我们将这些值的频率存储在字典中。 最后，我们使用组合公式计算对贡献，以从每组中选择两个元素。 整数算术是安全的，因为最大答案适合 n 最大为 10^5 的 64 位有符号整数范围。 

一个常见的实现陷阱是在嵌套循环内重复重新计算 f(x)，这会导致二次行为。 另一个微妙的问题是忘记了 Python 字典在累积组合时必须迭代值而不是键。

```所有数字都只有一个设置位，因此所有数字都映射到值 1。 

| 步骤| x| f(x) | f(x) | 频率图|

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    freq = {}
    ans = 0

    for x in a:
        v = x.bit_count()
        freq[v] = freq.get(v, 0) + 1

    for cnt in freq.values():
        ans += cnt * (cnt - 1) // 2

    return str(ans)

# provided sample

# all distinct popcounts

# all equal values
assert run("5\n3 3 3 3 3\n") == "10"

# mixed case
assert run("6\n1 2 3 4 5 6\n") == run("6\n1 2 3 4 5 6\n")

# single element
assert run("1\n100\n") == "0"

 ## 边缘情况

 大小为一的最小输入，例如`1 / 100`，产生零对。 该算法处理此问题是因为频率图包含计数为 1 的单个条目，并且 1·0/2 的计算结果为零。 

所有元素都是 2 的幂的情况，例如`1 2 4 8 16`，也会产生零，因为每个数字都只有一个设置位，因此所有 f(x) 值都是相同的。 该算法将所有内容分组到一个桶中并计算 5·4/2 = 10，这是正确的，因为每一对都匹配。 

所有数字都相同的情况，例如`3 3 3 3`，产生一组中的四个元素。 该算法计算 4·3/2 = 6，匹配无序对的数量。
