 ## 解决方案
 ## 问题理解

 给定一个整数序列，我们可以将其切成连续的非空片段。 对于每个片段，我们计算一个称为其分数的值，定义为该片段内所有元素的按位异或。 计算完所有分段分数后，我们对这些分数进行按位或运算，我们的目标是选择使最终 OR 值最大化的分段。 

所以我们控制的决定是在哪里放置切点。 剪切更多会创建更多段，剪切更少会合并段并更改其 XOR 值。 最终目标不是段结果的求和或异或，而是它们的按位或，这使得每个位的贡献独立。 

这些约束允许每个测试用例最多有 10^5 个元素，并且跨测试总共最多有 3 × 10^5 个元素。 这立即排除了尝试所有分区的任何解决方案，因为分割数组的方法数量呈指数增长，大约为 2^(n−1)。 即使对所有子阵列进行二次动态规划在最大规模下也会太慢。 

一个微妙的点是，段 XOR 值可能会引入不会出现在任何单个元素中的位模式。 例如，1 和 2 的 XOR 为 3，这两个位均已设置。 天真的直觉可能表明分段可以“创建”新的有用位。 关键问题是这样创建的位是否可以改进最终的 OR 超出我们从原始数组中获得的值。 

## 方法

 暴力策略将枚举分割数组的所有可能方法，计算每个段的异或，然后计算这些段值的或，并跟踪最大值。 这是正确的，因为它直接评估客观定义。 然而，有 2^(n−1) 个可能的分区，并且在最坏的情况下每次评估成本为 O(n)，导致指数时间变得不可行，即使 n 约为 25。 

我们现在寻找结构。 重要的观察结果是，最终答案仅取决于至少一个段 XOR 中哪些位位置可以等于 1。 如果任何段 XOR 中的某个位为 1，则它独立于所有其他位对最终 OR 做出贡献。 

现在考虑任何位位置。 当且仅当该段中的奇数个元素设置了该位时，段 XOR 才设置该位。 然而，这不允许我们创建一个在任何元素中都不存在的位位置。 XOR仅重新排列奇偶校验； 它不会引入新的位位置。 因此，可以出现在任何段 XOR 中的每一位都必须已经出现在数组的至少一个元素中。 

这立即意味着一个上限：答案不能超过所有元素的按位或。 另一方面，这个界限可以通过将数组分割成单元素段来实现。 每个段异或只是元素本身，最终的或就变成了所有元素的或。 

因此，划分问题完全崩溃：最佳策略就是将每个元素视为自己的部分。

 ## 算法演练

 该解决方案简化为计算数组中所有元素的按位或。 

1. 初始化累加器变量`ans`为零。 该变量将存储迄今为止处理的所有值的运行或。 
2. 从左到右迭代数组。 对于每个元素，更新`ans`通过采取`ans = ans OR a[i]`。 这会逐渐收集出现在数组中任何位置的每一位。 
3.处理完所有元素后，输出`ans`。 

我们可以安全地忽略所有分区决策的原因是，没有分区可以引入超出原始输入值中已存在的新位位置。 

### 为什么它有效

 每个段贡献一个 XOR 值。 任何段 XOR 中的每个位集都必须来自已包含该位的原始元素的某个子集。 由于 OR 仅检查一位是否出现在任何位置，因此将元素分配到段中无法创建至少一个元素中尚未存在的位。 单元素分区已经独立地实现了每个可实现的位，因此合并段只会冒取消 XOR 内的位的风险，而永远不会改善最终的 OR。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    ans = 0
    for x in a:
        ans |= x
    
    print(ans)

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```该实现为 OR 保留了一个运行变量。 不需要跟踪前缀 XOR 或任何 DP 状态，因为分段不会影响最终的最优值。 

唯一的微妙之处是由于总体限制很大，因此确保快速输入处理。 使用`sys.stdin.readline`避免标准输入法的开销。

 ## 边缘情况

 单元素数组是最简单的场景。 唯一可能的分区是数组本身，答案等于该元素。 该算法可以正确处理此问题，因为 OR 累加器从零开始，并在处理第一个也是唯一的元素后变为该值。 

零数组是另一个极端情况。 无论分区如何，每个段 XOR 都为零，因此最终的 OR 为零。 该算法保留了这一点，因为与零进行“或”操作不会更改累加器。 

具有重复相同值的数组也强调分段并不重要。 即使我们以不同的方式分组或拆分，所有元素的 OR 仍保持不变，并且没有 XOR 组合会产生原始值之外的新位。
