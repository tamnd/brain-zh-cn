 # 问题理解

 输入是描述物理尺寸的数学表达式。 每个拉丁字母代表一个基本维度，而乘法、除法和括号则以通常的方式组合维度。 重复一个字母意味着乘以该尺寸几次，所以`AAA`代表的三次方`A`。 

任务是通过组合相等的维度来简化整个表达式。 分子中出现的维度与分母中出现的相同维度相抵消。 全部取消后，必须分别打印剩余的分子和分母因子，并按照所需的顺序对每一边进行排序：`A, a, B, b, ... , Z, z`。 

表达式长度最多为 1000 个字符。 这个值足够小，适合线性解析器，但它排除了重复扩展或简化大型中间字符串的方法。 尝试每对可能的因素的解决方案可能会接近二次行为，并且重复的字符串替换可能会变得更糟，因为每次替换可能会再次扫描大部分表达式。 

棘手的部分是由嵌套以及尺寸位置与其最终符号之间的差异引起的。 例如，在`kg/(kg/(m/s))`，内部除法在知道最终结果之前改变符号两次。 仅处理从左到右的乘法和除法而不考虑括号的解析器将错误地保留`kg`在答案中。 

另一个边缘情况是完全取消。 用于输入`A/A`，正确的输出是：```
1
1
```粗心的实现可能会在一侧打印一个空行，而不是用`1`。 

区分大小写也很重要。 用于输入`aA`，这两个符号的尺寸不同。 正确的输出是：```
Aa
1
```仅按小写形式处理字母会错误地取消它们。 

必须对重复的维度进行计数，而不是将其视为单次出现。 用于输入`AAA/A`，正确的输出是：```
AA
1
```使用集合而不是计数的解决方案将丢失剩余的指数。 

## 方法

 一种直接的方法是在计算运算时将表达式转换为单个因素的列表。 每次乘法都会保留当前上下文的符号，而每次除法都会将其反转。 然后，强力简化器可以将每个分子因子与每个分母因子进行比较并删除匹配对。 这是正确的，因为取消仅取决于每个维度在每一侧出现的次数。 然而，在最坏的情况下，包含大约 1000 个因子的表达式将需要大约一百万次比较，并且从列表中重复删除会增加更多开销。 

关键的观察是每个维度只需要它的最终指数。 解析后，因子出现的确切位置不再重要。 将每个字母映射到整数计数的字典可以直接存储它。 正数表示维度保留在分子中，而负数表示维度保留在分母中。 

表达式的结构使递归解析变得自然。 括号创建独立的子表达式，除法只是更改后一项内每个因子的符号。 在解析时，我们维护一个乘数，表示当前部分是正面贡献还是负面贡献。 一封信将这个乘数添加到它的计数中。 这将整个简化变成了表达式的一次遍历。

 ## 算法演练

 1. 递归地解析表达式并为当前上下文维护一个符号乘数。 初始乘数为正，因为整个表达式从分子开始。 带括号的表达式从其周围的运算符接收乘数。 
2. 找到字母后，将当前乘数添加到该字母的计数器中。 计数器存储净指数，因此稍后的取消会自动发生，无需单独的分子和分母列表。 
3. 当找到乘法时，继续解析具有相同乘数的下一项。 乘法不会改变因子是属于分子还是分母。 
4. 找到除法后，用相反的乘数解析下列项。 除法翻转以下表达式中每个维度的一侧，包括括号内的所有内容。 
5. 解析完成后，将带有正计数器的字母与带有负计数器的字母分开。 打印分子中的正计数和分母中的负计数的绝对值。 
6. 使用自定义字母顺序对每一侧进行排序，其中同一字母的大写和小写版本相邻。 如果一方没有因子，则打印`1`。 

符号乘法器起作用的原因是每个除法运算都会更改其后面的整个表达式的指数符号。 嵌套除法是自然处理的，因为每个递归调用都会收到所有周围除法产生的符号。 

为什么它有效：在解析过程中，每个维度的计数器正是该维度每次出现所贡献的指数。 乘法使指数符号保持不变，而除法则否定除法表达式的贡献。 括号仅控制哪个子表达式接收符号更改。 遍历后，正指数代表剩余的分子因子，负指数代表剩余的分母因子，因此产生的输出是完全降维的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)
    cnt = {}

    def parse(pos, sign):
        while pos < n:
            c = s[pos]

            if c.isalpha():
                cnt[c] = cnt.get(c, 0) + sign
                pos += 1
            elif c == '(':
                pos = parse(pos + 1, sign)
            elif c == ')':
                return pos + 1
            elif c == '*':
                pos += 1
            elif c == '/':
                pos = parse(pos + 1, -sign)
            else:
                pos += 1

        return pos

    parse(0, 1)

    def sort_key(c):
        return (c.lower(), 0 if c.isupper() else 1)

    numerator = []
    denominator = []

    for c in sorted(cnt.keys(), key=sort_key):
        if cnt[c] > 0:
            numerator.extend([c] * cnt[c])
        elif cnt[c] < 0:
            denominator.extend([c] * (-cnt[c]))

    print('*'.join(numerator) if numerator else "1")
    print('*'.join(denominator) if denominator else "1")

if __name__ == "__main__":
    solve()
```字典`cnt`是中心数据结构。 该代码不是单独存储每个事件，而是立即将相等的维度合并到它们的最终指数中。 这可以保持较小的内存使用量并自动取消。 

递归函数`parse`遍历表达式。 它的第二个参数是当前符号。 字母使用该符号修改计数器。 部门操作员致电`parse`带有相反的符号，这与将以下子表达式乘以相同`-1`。 

右括号将控制返回给调用者，因为调用者已经知道整个括号部分是相乘还是相除。 这避免了需要构建单独的表达式树。 

排序键不能使用正常的 ASCII 顺序，因为 ASCII 将所有大写字母放在小写字母之前。 所需的顺序将两种情况分组在一起，因此键首先比较小写形式，然后将大写放在小写之前。 

输出结构根据其指数重复每个字母。 这可以处理诸如以下的尺寸`AAA/A`正确，因为存储的计数是取消后的剩余电量。 

## 工作示例

 对于第一个样本，表达式为`kg/(kg/(m/s))`。 

| 步骤| 当前表达部分 | 标志 | 专柜|
 | ---| ---| ---| ---|
 | 1 |`kg`第一师之前| +1 | k：1，g：1 |
 | 2 | 内`kg`| -1 | k：0，g：0 |
 | 3 | 内`m`| +1 | 米：1 |
 | 4 | 内`s`| -1 | s：-1 |

 两人`kg`由于嵌套除法改变了符号两次，所以事件被取消。 最后的积极因素是`m`最终的负面因素是`s`。 

对于第二个样本，表达式为`kg*a/(Fs*B)*A*Kt`。 

| 步骤| 当前表达部分 | 标志 | 专柜|
 | ---| ---| ---| ---|
 | 1 |`k`,`g`,`a`| +1 | k：1，g：1，a：1 |
 | 2 |`F`,`s`,`B`| -1 | F:-1, s:-1, B:-1 |
 | 3 |`A`,`K`,`t`| +1 | A：1，K：1，t：1 |

 按照自定义顺序排序后，分子变为`A*a*Kt*kg`分母变为`B*Fs`。 此示例演示区分大小写的符号保持独立，并且仅在所有算术完成后才进行排序。

 ## 边缘情况

 对于`kg/(kg/(m/s))`，解析器首先记录`kg`带正号，然后输入带负号的除括号表达式。 在该表达式中，第二部分再次翻转符号`m/s`。 两人`kg`因素抵消，留下`m`在分子和`s`在分母中。 

为了`A/A`，第一个`A`将计数器增加到一和第二`A`将其减回到零。 由于双方都没有任何剩余因子，因此两条输出线都变为`1`。 

为了`aA`，该算法保留两个单独的字典键，因为字符大小写是维度名称的一部分。 排序使用两个键的小写形式和大小写进行比较，产生`Aa`而不是合并它们。 

为了`AAA/A`，计数器`A`变为三，然后减一。 最终指数为 2，因此输出包含`A`两次。 这证实了该算法存储多重性而不仅仅是存在。
