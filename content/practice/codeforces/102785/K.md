 ## 解决方案
 ## 问题理解

 我们有四个火花室放置在半径为圆的圆周上`R`。 输入给出了它们之间的四个连续的角度间隙，因此我们可以重建圆上的四个点。 我们必须建立一个最短的电缆网络，在圆圈内使用两台计算机。 每台计算机可以连接到任意数量的房间，并且两台计算机相互连接。 两台计算机的位置不固定，因此任务是找到该网络的最小可能总长度。 

终端的数量始终是四个。 这是关键的约束。 一般的欧几里得斯坦纳树问题很困难，但对于四个点，最优网络只有几种可能的形状。 这两台计算机正是这棵树的斯坦纳点，因此我们只需要检查可能的完整斯坦纳树拓扑以及其中一台计算机与另一点合并的退化情况。 

半径可以大到 100，因此答案可以有几百个单位长。 所需精度为`1e-6`，这意味着需要进行浮点计算。 由于只有四个点，具有恒定数量几何运算的算法很容易足够快。 任何依赖于搜索网格或迭代许多可能的计算机位置的方法都是不必要的，并且会使达到所需的精度变得更加困难。 

一个常见的错误是忘记简并配置。 如果三个腔室的放置使得三角形的一个角至少为 120 度，则费马点不存在于三角形内部，并且最佳连接就是在该角处相交的两条边。 第二个错误是在梅尔扎克的构造中构造等边三角形时仅考虑一个方向。 相反的方向可以对应于实际的最短拓扑。 

例如，具有三个重合的角度间隙和一个大间隙：```
10 120 120 60 60
```假设每个拓扑都是完整的 Steiner 树的解决方案可能会产生无效值。 正确的方法还必须与普通的最小生成树长度进行比较。 

## 方法

 直接暴力的想法是选择两个计算机位置并优化它们的坐标。 成本函数是计算机之间的距离加上每个房间到其指定计算机的距离。 即使只有四个腔室，也会留下四个连续变量，并且尝试以数字方式搜索该空间并不能保证可靠的精度。 

更好的观点是将结构识别为具有四个终端的欧几里得施泰纳树。 具有四个终端的最优树最多有两个斯坦纳点。 当两台计算机都是真正的分支点时，每台计算机都有以 120 度相交的三个边。 将四个端子分成两对只有三种可能的方法。 对于固定分割，梅尔扎克的构造用等边三角形的第三个顶点代替一对端点。 应用此替换两次后，两个虚拟点之间的最终距离等于该斯坦纳树拓扑的长度。 

蛮力之所以有效，是因为它搜索了可能网络的整个空间，但它失败了，因为该空间是连续的。 通过观察可能的斯坦纳树形状的数量是恒定的，我们可以用一些几何构造来代替优化。 

我们还计算最小生成树作为后备。 这处理了斯坦纳点消失的情况，因为 120 度条件是不可能的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力坐标搜索 | 没有可靠的界限 | O(1) | O(1) | 太慢且不准确 |
 | 用 Melzak 构造枚举 Steiner 拓扑 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将四个角间隙转换为圆上的四个笛卡尔点。 从角度零开始，累积间隙并使用余弦和正弦来获得每个室的位置。 
2. 计算四个点的最小生成树的长度。 这是最优施泰纳结构退化的所有情况的答案。 
3. 列举四个室的三种可能的配对。 对于每个配对，应用梅尔扎克的构造。 将第一对替换为两个可能的等边三角形第三个顶点，然后以相同的方式替换第二对。 两个所得虚拟点之间的最小距离是候选答案。 
4. 取所有 Steiner 候选值中的最小值和最小生成树长度。 

这样做的原因是每个完整的四点 Steiner 树都恰好具有三对终端对中的一对。 梅尔扎克变换保留了该固定拓扑的总长度，因此测量最终的虚拟段可以给出该候选树的准确长度。 如果完整拓扑无效，生成树比较将覆盖折叠版本。 

## 为什么它有效

 不变的是，算法产生的每个候选代表了最佳电缆网络的完整可能形状。 完整的斯坦纳树被梅尔扎克候选树覆盖，并且每棵退化树不再短于相应的最小生成树。 由于检查了所有可能的拓扑，找到的最小值就是全局最优值。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def dist(a, b):
    return math.hypot(a[0] - b[0], a[1] - b[1])

def rotate60(v, sign):
    c = 0.5
    s = math.sqrt(3) / 2 * sign
    return (v[0] * c - v[1] * s, v[0] * s + v[1] * c)

def equilateral(a, b):
    v = (b[0] - a[0], b[1] - a[1])
    r1 = rotate60(v, 1)
    r2 = rotate60(v, -1)
    return ((a[0] + r1[0], a[1] + r1[1]),
            (a[0] + r2[0], a[1] + r2[1]))

def mst(points):
    edges = []
    for i in range(4):
        for j in range(i + 1, 4):
            edges.append(dist(points[i], points[j]))
    edges.sort()
    return edges[0] + edges[1] + edges[2]

def solve():
    data = list(map(float, input().split()))
    if not data:
        return
    r = data[0]
    gaps = data[1:]

    pts = []
    cur = 0.0
    for g in gaps:
        ang = math.radians(cur)
        pts.append((r * math.cos(ang), r * math.sin(ang)))
        cur += g

    ans = mst(pts)

    pairs = [
        ((0, 1), (2, 3)),
        ((0, 2), (1, 3)),
        ((0, 3), (1, 2))
    ]

    for p1, p2 in pairs:
        for a, b in equilateral(pts[p1[0]], pts[p1[1]]):
            for c, d in equilateral(pts[p2[0]], pts[p2[1]]):
                ans = min(ans, dist(a, c), dist(a, d),
                          dist(b, c), dist(b, d))

    print("{:.10f}".format(ans))

if __name__ == "__main__":
    solve()
```点重建使用腔室的累积角度。 以圆心为原点，因此直接由三角法得到坐标。 

这`equilateral`函数返回两个可能的第三个顶点，因为正确的方向取决于拓扑。 忽略其中之一可能会错过最佳树。 

生成树计算有意保留为单独的候选者。 它避免了必须手动检测斯坦纳点崩溃的每种情况。 

所有计算均使用`float`，这已经足够了，因为输入尺寸很小并且所需的误差容限是`1e-6`。

 ## 边缘情况

 当由室形成的三角形的角度至少为 120 度时，完整的施泰纳点不在三角形内部。 该算法可以处理此问题，因为最小生成树始终作为候选对象包含在内。 最终的最小值不能大于折叠的解决方案。 

当正确的等边构造使用线段的另一侧时，仅考虑一个方向会错过答案。 例如，平方输入```
1 90 90 90 90
```有几种对称的可能性。 该算法会尝试每对的第三个顶点，因此始终存在有效方向。 

当腔室几乎遍布整个圆时，如果坐标生成不正确，可能会出现角度累积带来的数值误差。 该实现仅在创建每个点时累积间隙并将度数转换为弧度，从而使所有计算保持双精度。
