 ## 解决方案
 ## 问题理解

 每次称量记录两个整数。 第一个是秤上放置的相同零件的数量，第二个是测得的这些零件的总重量。 

如果批次中的每个零件具有相同的整数重量`x`，那么每条记录都必须满足`wi = ai × x`。 

控制器事先并不知道正确的重量。 他只检查是否存在某个整数权重来解释每个记录的测量结果。 如果至少存在一个这样的整数，则没有证据表明存在缺陷，并且该批次被接受。 如果没有整数重量与所有测量值一致，则该批次肯定有缺陷。 

测量次数最多为 1000。涉及的每个值也足够小，简单的整数运算就足够了。 不需要任何高级优化，因为即使是处理每条记录一次的算法也很容易满足限制。 

唯一真正的困难是正确解释“缺陷”的含义。 我们并不是试图确定零件的真实重量。 我们只需要确定某个整数权重是否可以同时解释每个测量结果。 

一个常见的错误是仅检查每个单独的测量值是否具有整数权重。 考虑```
2
2 6
3 12
```第一次称重建议重量为`3`，而第二个建议的权重为`4`。 两者都是整数，但它们不一致，所以正确的输出是```
DEFECT
```另一个容易犯的错误是从第一次测量中选择重量并忽略它是否是整数。```
2
2 5
4 10
```第一条记录意味着权重为`2.5`，这是不可能的，因为权重必须是整数。 尽管两次测量都与相同的小数值一致，但正确答案是```
DEFECT
```最后一种边缘情况是只有一个测量值。```
1
7 35
```唯一的隐含重量是`5`，它是一个整数，所以正确的输出是```
QUALITY
```一次一致的测量就足够了，因为只有当记录与所有可能的整数重量相矛盾时，控制器才会拒绝该批次。 

## 方法

 最直接的方法是尝试每一个可能的整数权重并检查所有测量值是否满足`wi = ai × weight`。 这是正确的，因为当至少一个候选权重与每条记录匹配时，该批次是可接受的。 

弱点在于决定必须测试多少候选权重。 该声明没有提供真实重量的明确上限。 即使我们通过考虑最大观测权重的每个可能值来从输入中得出一个，该算法也会对一千个测量中的每一个执行近一百万次检查，在最坏的情况下导致大约十亿次比较。 

关键的观察结果是，每次测量都直接决定了它可以代表的唯一可能的重量。 重新整理方程给出`weight = wi / ai`。 

为了使测量有效，除法必须精确，因为重量是整数。 每个有效的测量还必须产生完全相同的值。 我们不是搜索可能的权重，而是简单地计算第一个记录的隐含权重，并验证每个剩余记录是否隐含相同的整数。 

这将问题简化为通过测量进行的单个线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(k × W)，其中W是搜索到的权重范围| O(1) | O(1) | 太慢了|
 | 最佳 | O(k) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取测量次数。 
2. 读取第一个测量值。 如果总重量不能除以零件数，则立即打印`DEFECT`，因为即使是这个单一的记录也没有整数权重可以解释。 
3. 否则，将候选权重计算为`w1 // a1`。 每个有效的测量都必须准确地产生该值。 
4. 逐一处理剩余的每个测量值。 
5. 每次测量时，首先检查是否`wi`可以整除`ai`。 如果不是，则打印`DEFECT`并终止，因为隐含的权重不是整数。 
6. 计算隐含重量`wi // ai`。 如果与候选体重不同，则打印`DEFECT`并终止，因为不同的测量需要不同的零件重量。 
7. 如果每次测量都通过了两项检查，则打印`QUALITY`。 

### 为什么它有效

 该算法在整个扫描过程中保持一个不变量。 候选权重是与每个处理的测量一致的唯一整数权重。 

第一个有效测量唯一地确定候选者。 后来的每一次测量要么与其一致，要么证明不存在共同的整数权重。 由于每个可能的有效解决方案必须满足每个测量，因此仅当所有隐含权重相同时才接受既是必要的也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

k = int(input())

a, w = map(int, input().split())

if w % a != 0:
    print("DEFECT")
    sys.exit()

weight = w // a

for _ in range(k - 1):
    a, w = map(int, input().split())
    if w % a != 0 or w // a != weight:
        print("DEFECT")
        sys.exit()

print("QUALITY")
```第一次测量确定了唯一可能的整数权重。 在存储之前，代码会验证除法是否准确。 这会阻止分数权重被接受。 

后面的每个测量在将隐含权重与存储的候选权重进行比较之前都会执行相同的整除性检查。 仅在确认整除后才使用整数除法以避免错误截断。 

程序在检测到任何矛盾后立即退出。 由于一次不一致的测量足以拒绝该批次，因此没有理由处理剩余的输入。

import sys
import io

def solve():
    input = sys.stdin.readline

    k = int(input())
    a, w = map(int, input().split())

    if w % a != 0:
        print("DEFECT")
        return

    weight = w // a

    for _ in range(k - 1):
        a, w = map(int, input().split())
        if w % a != 0 or w // a != weight:
            print("DEFECT")
            return

    print("QUALITY")

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return out

# provided samples

 ## 边缘情况

 考虑这样的情况：每个测量单独给出一个整数权重，但权重不同。```
2
2 6
3 12
```该算法存储候选权重`3`从第一次测量开始。 第二次测量意味着`4`，与候选者不匹配，所以它打印`DEFECT`。 这捕获了简单的整除性检查可能会错过的矛盾。 

现在考虑分数隐含权重。```
2
2 5
4 10
```第一次测量未通过整除性检查，因为`5 % 2 != 0`。 该算法立即打印`DEFECT`没有检查后来的记录。 这正确地拒绝了只能用非整数重量解释的批次。 

最后，考虑最小的有效输入。```
1
7 35
```测量值隐含整数权重`5`。 不存在其他记录与之相矛盾，因此算法完成扫描并打印`QUALITY`。 这符合控制器仅在收集的证据与每个可能的整数权重不一致时拒绝该批次的要求。
