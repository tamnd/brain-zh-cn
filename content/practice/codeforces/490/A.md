 ## 解决方案
 ## 问题理解

 我们得到了一份孩子名单，每个孩子都用一个数字来表示他们的技能：编程（1）、数学（2）或体育（3）。 任务是组建尽可能多的三人团队，每个团队只有一个来自每种技能的孩子。 输出应首先说明团队的数量，然后列出组成每个团队的孩子的指数。 每个孩子只能出现在一个团队中。 

关键的限制是$n \le 5000$。 它足够小，可以对数据进行线性或近线性扫描，甚至可以对所有子项进行多次简单操作。 索引必须根据原始输入保留以用于输出目的，但我们可以根据内部需要自由地重新排列或存储它们。 

当一项技能代表性不足时，就会出现不明显的边缘情况。 例如，使用输入`1 1 2 2 2 3`，我们有三名程序员、三名数学家和一名运动员。 团队的最大数量显然是 1，因为我们不能组建多个团队，并且每种技能只有一个子项。 尝试按顺序匹配孩子的幼稚方法可能会错误地尝试创建两个团队，这将无法满足技能要求。 

## 方法

 暴力方法会尝试尝试三个孩子的所有可能组合，并检查他们是否组成一个有效的团队。 最多有 5000 个孩子，可能的三胞胎数量为$\binom{5000}{3}$，大约200亿，这显然是不可行的。 这在理论上是有效的，因为它会检查每个组合，但是当$n$增长到几十个以上。 

关键的见解是通过技能来区分孩子。 一旦我们有了三个列表 - 一个用于程序员，一个用于数学家，一个用于运动员 - 团队的最大数量受到最小列表的限制，因为如果每种技能都至少有一个子项，我们就无法组建团队。 然后我们可以从每个列表的前面挑选孩子并按顺序组成小组。 这保证了每个团队都有独特的技能，我们自然尊重每个孩子一个团队的限制。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(n) | 太慢了 |
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化三个空列表：`prog`对于程序员来说，`maths`对于数学家来说，以及`pe`对于运动员来说。 这些将存储孩子每种技能的指数。 
2. 遍历子级列表。 对于每个孩子，根据技能将其从 1 开始的索引附加到适当的列表中。 
3. 计算三个列表中的最小长度。 这个数字，`w`，是可以组建的最大团队数量。 
4. 对于每个整数`i`从 0 到`w-1`，输出一个由以下组成的团队`i`第一个元素来自`prog`,`maths`， 和`pe`。 这可确保每个团队的每种技能都只有一个子项，并且不会出现重复的子项。 
5. 打印`w`首先，然后在单独的行上打印每个团队。 

为什么有效：在每一步中，我们从每项技能中选取一个子项。 通过迭代到三个技能组中的最小数量，我们保证永远不会超过任何技能的可用儿童数量。 这会产生最大数量的有效团队，并且由于我们直接跟踪索引，因此保留了输出的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
skills = list(map(int, input().split()))

prog = []
maths = []
pe = []

for idx, s in enumerate(skills, 1):
    if s == 1:
        prog.append(idx)
    elif s == 2:
        maths.append(idx)
    else:
        pe.append(idx)

w = min(len(prog), len(maths), len(pe))
print(w)

for i in range(w):
    print(prog[i], maths[i], pe[i])
```该解决方案读取儿童的数量及其技能。 它根据技能将索引分为三个列表。 然后，它计算最大团队数量作为三个列表长度的最小值。 最后，它打印`w`并通过按顺序从每个技能列表中取出一个索引来输出每个团队。 使用从 1 开始的索引至关重要，因为问题需要它。

 我们分两队，因为最小的技能组（`maths`和`pe`）各有 2 个孩子。 该表显示了如何从每个列表中按顺序选取索引。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 我们遍历子列表一次以分离索引，然后迭代到`w`(≤ n) 组成团队。 |
 | 空间| O(n) | 我们将索引存储在三个单独的列表中，每个列表总共最多 n 个元素。 |

 该解决方案很容易满足 n ≤ 5000 的 1 秒时间限制和 256 MB 的内存限制。

 ## 边缘情况

 例如，如果一项技能没有子项`3\n1 1 2`，那么列表就变成了`prog=[1,2]`,`maths=[3]`,`pe=[]`。 长度的最小值为 0，因此无法组队。 该算法正确地打印 0。这无需任何额外的检查即可处理边缘情况，因为 min 操作自然会强制执行它。
