 ## 解决方案
 ## 问题理解

 我们得到一个一维的单元格条，编号从 0 到$10^{18}$。 最初所有细胞都是白色的。 我们需要将某些单元格涂成黑色，并且允许我们选择距离最多为 的成对的白色单元格$k$同时将它们涂成黑色。 我们还可以最多绘制一个不在所需列表中的附加单元格。 任务是找到最小的$k$这使得在尊重配对约束的同时绘制所有所需的单元格成为可能。 

输入列出了必须绘制的单元格，并按升序排序。 输出是一个整数$k$每个测试用例。 约束条件意味着细胞数量$n$每个测试用例最多 2000 个，所有测试用例的总和不超过 2000。这允许算法运行在$O(n \log n)$甚至$O(n^2)$，因为操作的绝对数量将保持在可控范围内。 单元位置的大值，最多$10^{18}$，排除条带的直接阵列表示或模拟； 我们必须处理数字本身，而不是使用与单元格索引成比例的内存。 

边缘情况包括所需单元连续、稀疏且间隙较大、$n=1$并且我们只有一个必需的单元格，并且当单元格均匀分布时，如果我们不考虑额外的可选单元格，从左到右的简单配对可能会失败。 例如，如果$a=[1,3]$，最小的$k$为 2，因为两个单元相距 2； 总是将连续单元格配对的粗心方法可能会错误地返回 1。 

## 方法

 暴力方法将尝试模拟绘画过程以增加$k$，检查所有可能的配对并确保最多使用一个额外的电池。 这在原则上是正确的，但$n$最多 2000 个，模拟所有配对需要$O(n^2)$每$k$，以及最大$k$如果单元格相距较远，则可能会非常大，从而导致计算不可行。 

关键的见解是，问题可以简化为贪婪和建设性的策略。 对于给定的$k$，我们可以尝试从左到右顺序配对单元格。 如果下一个未配对的单元格在$k$下面的单元格，我们将它们配对。 如果没有，我们可能必须使用可选的额外单元来弥补差距。 这允许检查候选人$k$在线性时间内$O(n)$。 一旦定义了这个决策函数，我们就可以使用二分搜索$k$从 0 到所需单元格之间的最大距离，以找到最小可行值$k$。 从左到右贪婪配对就足够的观察结果依赖于这样一个事实：只有连续的间隙才重要，并且可选的额外单元最多可以使用一次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 * 最大间隙) | O(n) | 对于稀疏大索引来说太慢 |
 | 贪心+二分查找| O(n log max_gap) | O(n log max_gap) | O(n) | 已接受 |

 ## 算法演练

 1. 对所需单元格列表进行排序。 这是由输入保证的，但确保了正确性。 
2. 定义辅助函数`check(k)`如果可以用给定的值绘制所有必需的单元格，则返回 True$k$。 初始化第一个单元格处的指针和指示是否已使用可选额外单元格的标志。 
3. 按顺序迭代单元格。 对于每个未配对的单元格，尝试将其与下一个单元格配对。 如果距离最多为$k$，将它们配对并将指针前进 2。 
4. 如果下一个单元格距离太远，请考虑使用可选的额外单元格。 如果尚未使用，则“消耗”它以弥补差距，然后前进 1 并将可选标记标记为已使用。 
5. 如果配对失败并且可选的额外电池已被使用，则返回 False。 
6. 如果所有单元都配对成功，则返回 True。 
7. 执行二分查找$k$从 0 到所需单元格之间的最大可能距离。 对于每个中点，调用`check(k)`来决定是搜索更低还是更高。 
8. 输出最小值$k$为此`check(k)`返回 True。 

不变量是对于给定的$k$，贪婪配对会消耗最左边的未配对单元，如果间隙太大，则单个额外单元仅使用一次。 没有配置可以减少$k$进一步不违反距离约束，因为任何更小的$k$将留下至少一个可选单元无法跨越的间隙。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        def check(k):
            used_extra = False
            i = 0
            while i < n:
                if i + 1 < n and a[i + 1] - a[i] <= k:
                    i += 2
                elif not used_extra:
                    used_extra = True
                    i += 1
                else:
                    return False
            return True
        
        lo, hi = 0, a[-1] - a[0]
        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1
        print(lo)

if __name__ == "__main__":
    solve()
```每个部分直接对应于算法步骤。 排序是隐含在输入中的。 这`check`函数贪婪地配对单元，在第一个不可桥接的间隙处消耗可选的额外单元。 二分查找确保最小性。 使用`a[-1] - a[0]`作为上限`k`是安全的，因为任何间隙都不能超过该值。 处理`i+1 < n`防止索引错误。 这`used_extra`flag 保证可选单元最多使用一次。

 单个单元格的最小输入，例如，`a = [7]`，返回 0，因为不需要配对。 第一个和最后一个所需单元之间的最大间隙使用可选的额外单元来覆盖一个未配对的单元。 在所有情况下，该算法都能成功地将连续单元配对`k`并正确消耗
