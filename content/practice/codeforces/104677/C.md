 ## 解决方案
 ## 问题理解

 我们有一群人，每个人都拿着一定数量的蛋糕片。 如果蛋糕被完美地分割，那么每个人都会收到完全相同数量的切片，因为切片总数保证能被人数整除。 

任务是确定有多少人不符合这个理想的平等份额。 换句话说，我们计算每个人的平均切片数，并计算有多少人与该值不同。 

输入是一个小整数数组，输出是一个整数：值不等于平均值​​的位置数。 

由于人数和切片数都最多为 10，因此输入大小非常小。 除了单次遍历数组之外，这消除了对高级数据结构或优化的任何需要。 

当所有值都相等时，就会出现微妙的边缘情况。 在这种情况下，答案应该是零。 另一个极端情况是只有一个人存在时，因为“平均值”只是他们的价值，所以答案再次为零。 

一个幼稚的错误是重新计算或模拟重新分配操作，而不是直接与计算的平均值进行比较。 这是不必要的，如果处理不当，可能会引入舍入或整数除法错误。 

## 方法

 暴力解释是尝试重新分配切片，直到每个人变得平等，然后计算在此过程中有多少人发生了变化。 人们可以模拟货币对之间的转移，直到达到平衡。 然而，尽管这里的约束很小，但这种方法基本上是不必要的，并且模糊了问题的结构。 

关键的观察是，每个人的最终正确值是固定且唯一确定的：它只是总和除以 N。不需要模拟任何分配过程。 一旦知道了这个目标值，问题就简化为与数组的每个元素进行直接比较。 

这将问题从过程模拟转变为简单的聚合和计数任务。 蛮力思想在概念上是有效的，因为重新分配最终会导致一致性，但它作为一种方法是失败的，因为它引入了与最终问题无关的额外状态变化。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(k·N²) 或更差 | O(N) | 太慢/不必要|
 | 直接比较| O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 ### 步骤

 1.读取人数N和切片计数列表。 
2. 计算所有切片的总和。 这代表了分配给所有参与者的完整蛋糕。 
3. 将总和除以 N 来计算每人的目标切片数。由于问题条件，这保证是一个整数。 
4. 将计数器初始化为零。 
5. 迭代每个人的切片计数。 
6. 对于每个人，将他们的价值与目标价值进行比较。 
7. 如果值不同，则递增计数器。 
8. 输出最终计数器值。 

每次比较都直接回答那个人是否偏离公平分配，因此不需要中间转换。 

### 为什么它有效

 总和约束确保存在代表公平份额的唯一整数值。 由于公平性纯粹是通过等于该派生常量来定义的，因此每种不正确的情况都恰好是一个不等于该常量的元素。 该算法依赖于目标值全局正确并且独立于元素之间的排序或局部关系的不变量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))
    
    target = sum(a) // n
    ans = 0
    
    for x in a:
        if x != target:
            ans += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```该实现是算法的直接翻译。 最重要的细节是在对所有元素求和后使用整数除法计算目标。 由于该问题保证了整除性，因此不需要浮点处理或舍入。 

该循环只是计算不匹配的数量。 无需排序或额外存储。

def run(inp: str) -> str:

 ## 边缘情况

 对于单人输入，例如`1\n5`，算法计算总和 5、目标 5，并且没有发现任何不匹配，从而产生 0。这证实了当 N = 1 时公平性的定义正确退化。 

对于已经统一的数组，例如`3\n2 2 2`，计算出的目标为 2，并且每次比较都成功，因此计数器始终保持为零。 这验证了算法不会由于冗余检查或整数除法问题而错误地标记相等的配置。
