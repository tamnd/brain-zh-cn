 ## 解决方案
 ## 问题理解

 该任务描述了一个简单的划分场景。 一个人有固定数量的披萨片和一群朋友。 切片尽可能均匀地分配给所有朋友，任何不能均匀分配的东西都不会被使用。 

输入由两个整数组成，其中第一个表示有多少个披萨片可用，第二个表示有多少朋友将分享它们。 输出必须描述两个数量。 第一个是平均分割后每个朋友收到的切片数量，第二个是还有多少切片未分配。 

这两个值的约束都达到 10^9，这立即表明任何逐片模拟分布的方法都会太慢。 在 1 秒限制下，最多 10^9 次迭代的循环将无法及时完成。 该解决方案必须使用算术运算在恒定时间内计算结果。 

当切片数量小于好友数量时，会出现微妙的边缘情况。 例如，如果有 2 个切片和 5 个朋友，则每个朋友获得零个切片，并且所有切片都保持未使用状态。 另一个特殊情况是当切片均匀分配时，例如 3 个朋友分 9 个切片，没有留下任何东西。 这两种情况都必须正确处理，无需超出整数算术的特殊分支。 

## 方法

 直接模拟方法会在朋友之间以循环方式一次分配一个切片。 这将继续分布，直到没有切片剩余。 虽然概念上很简单，但最坏的情况需要每个切片迭代一次，导致多达 10^9 次操作，这远远超出了可行的限制。 

关键的观察结果是分布是完全均匀的。 每个朋友都会收到总切片除以朋友数量的整数部分。 任何余数都是无法均匀分配的。 这将过程从重复模拟转变为单个算术除法。 

暴力破解之所以有效，是因为它明确地模拟了分发过程，但当切片数量变大时，它会失败。 观察到只有商和余数问题将问题简化为整数除法和模运算，两者都可以在常数时间内计算。

 ## 算法演练

 1.读取两个整数，切片数和好友数。 这些代表了总资源和我们想要形成的相等分区的数量。 
2. 使用整数除法计算每个朋友收到的切片数量。 这在不超过可用切片的情况下捕获了可能的最大平等分配。 
3. 使用模运算计算剩余切片。 这直接代表了均分后的余数。 
4. 输出商和余数作为最终结果。 

每个步骤背后的推理都与除法的数学结构相关。 整数除法自然地编码了相等的分割，而模捕获了不能均匀分割的内容。 

### 为什么它有效

 不变量是分布后`x`之间均匀切片`N`朋友们，总分配的切片必须是最大的倍数`N`不超过`x`。 整数除法乘以时正好产生这个倍数`N`。 余数是减去这个最大可整除部分后剩下的部分，这正是模计算的结果。 由于这两个操作都是原始数字的精确分解，因此结果不会偏离正确的分布。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

x, n = map(int, input().split())

each = x // n
leftover = x % n

print(each, leftover)
```该解决方案读取输入一次并立即执行两个算术运算。 整数除法运算符`//`确保丢弃小数部分，这与仅分布整个切片的想法相匹配。 模运算符`%`计算此分配后剩余的内容。 

不需要循环或条件分支，因为算术完全编码了分布逻辑。 运算顺序很简单，除了确保整数运算之外不存在任何边界问题，Python 可以自然地处理大值。

## 测试用例```python
import sys, io

def solve():
    x, n = map(int, sys.stdin.readline().split())
    print(x // n, x % n)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    import io as _io
    out = _io.StringIO()
    with redirect_stdout(out):
        solve()
    return out.getvalue().strip()

# provided samples
assert run("5 2\n") == "2 1", "sample 1"
assert run("9 3\n") == "3 0", "sample 2"

# custom cases
assert run("1 2\n") == "0 1", "fewer slices than friends"
assert run("10 1\n") == "10 0", "single friend gets everything"
assert run("1000000000 2\n") == "500000000 0", "large equal split"
assert run("7 3\n") == "2 1", "general remainder case"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 | 1 2 | 0 1 | 比朋友少切片|
 | 10 1 | 10 10 0 | 10 单一收件人边缘情况 |
 | 1000000000 2 | 500000000 0 | 最大输入大小 |

 ## 边缘情况

 当切片数量小于好友数量时，比如输入`1 5`，整数除法产生零，这意味着没有朋友收到任何切片。 模运算返回原始数字，这正确地反映了没有分配任何内容。 

当好友数量为1时，比如`10 1`，除法产生该单个朋友的所有切片，余数为零。 这证实整个资源已正确分配，无需特殊处理。 

当切片均匀分割时，例如`8 4`，整数除法产生精确的每个好友份额，模数返回零。 这表明除了算术分解本身之外不需要剩余处理。 

当值很大时，例如`10^9 2`，由于 Python 可以处理任意大小的整数，因此操作仍然可以正确运行。 计算保持恒定时间并且不会随着输入幅度而降低。
