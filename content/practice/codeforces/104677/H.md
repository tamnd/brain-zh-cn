 ## 解决方案
 ## 问题理解

 我们有一个巨大的网格，除了少量称为杂质的特殊细胞外，大部分是空的。 每种杂质都位于固定的坐标处，并贡献可能的正或负强度值。 

我们可以在网格内选择任何固定大小 R 乘 C 的轴对齐子矩形。 这种矩形的每个有效位置都有​​一个“值”，定义为落在其中的所有杂质的强度之和。 没有杂质的细胞没有任何贡献，因此只有 K 标记点才重要。 

任务是将 R x C 窗口滑动到 N x M 网格内的任意位置，并计算窗口捕获的杂质强度的最大可能总和。 

尽管 N 和 M 可以大到 10^9，但只有 K 最多 10^5 个单元格是非零的。 这立即告诉我们，任何迭代整个网格的方法都是不可能的。 唯一有意义的对象是杂质点本身。 

主要的困难是几何上的：我们正在最大化固定矩形的所有平移的加权和。 

一种简单的方法是尝试 R x C 矩形的所有可能的左上角。 由于位置多达N·M个，这是完全不可行的。 

负值会出现一个更微妙的问题。 如果所有杂质都是负的，那么最好的矩形可能不包含杂质贡献，因为我们更愿意完全避免它们，但我们仍然被迫选择一个矩形； 在这种情况下，根据解释，答案可能为负或为零，并且从样本中我们看到，空贡献实际上会产生零，因此最佳答案至少为 0。 

当多个杂质聚集在矩形边界附近时，就会出现边缘情况。 几乎不包含或不包含点的矩形可能会突然改变答案，因此正确的解决方案必须处理精确的包含条件，而不会出现重复计算或相差一错误。 

## 方法

 蛮力的想法很简单：对于 R × C 矩形的每种可能的放置，计算其中所有杂质的总和。 对于每个位置，我们都会扫描所有 K 个杂质并测试它们是否位于矩形内。 这导致最坏情况下的 O(N·M·K)，这远远超出了给定 N 和 M 最多 10^9 的任何限制。 

即使我们将自己限制在矩形有意义不同的位置，放置的数量仍然是天文数字。 

关键的观察结果是网格大小无关紧要； 只有杂质坐标才重要。 每个矩形对应于选择坐标落入平移的 R by C 窗口内的所有杂质。 我们可以认为每个杂质都将其值贡献给有效矩形原点的区域。 每个杂质定义了包含该杂质的左上角位置的矩形。 

因此，我们不是移动矩形，而是反转视角：每个杂质“将其权重添加到”变换后的坐标空间中的一组位置。 问题就变成了在变换后的空间中找到所有这些重叠的轴对齐矩形的最大总和。 这减少为稀疏加权矩形集上的二维最大子矩阵和，可以使用坐标压缩和扫描来解决。 

我们对所有重要的 x 坐标进行排序，并将条件“x in [x_i - R + 1, x_i]”转换为矩形原点的区间约束。 对于 y 来说也是如此。 每个杂质都成为原始空间中的一个加权矩形，我们需要最大的重叠和。 

我们将其简化为扫描一个维度并在另一个维度上使用线段树，维护范围更新并查询最大前缀和。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N·M·K) | O(1) | O(1) | 太慢了|
 | 最优扫描+线段树| O(K log K) 或 O(K log K + K^2 压缩扫描) | O(K) | 已接受 |

 ## 算法演练

 我们根据矩形原点重新构建问题。 当且仅当 x ≤ a ≤ x + R − 1 且 y ≤ b ≤ y + C − 1 且 y ≤ b ≤ y + C − 1 时，左上角位于 (x, y) 的矩形包含 (a, b) 处的杂质。这相当于 x ∈ [a − R + 1, a] 且 y ∈ [b − C + 1, b]。 

因此，每个杂质 (a, b, t) 都将 t 贡献给由这些边界定义的原始空间中的矩形内的每个原点。 

现在我们解决二维轴对齐矩形的最大加权重叠问题。 

1. 对于每种杂质，计算其有效的 x 区间 [a − R + 1, a] 和 y 区间 [b − C + 1, b]。 这些间隔描述了矩形原点必须位于何处才能包含该杂质。 这种变换将原始的滑动窗口问题转换为原点上的几何覆盖问题。 
2. 从区间端点收集所有唯一的 x 坐标并对它们进行排序。 我们将使用这些压缩边界来扫描 x。 坐标压缩是必要的，因为坐标可以大到 10^9。 
3. 对于每种杂质，我们创建两个事件：一个事件的 y 间隔以 x = a − R + 1 开始，另一个事件以 x = a + 1 结束。这些事件将在 y 轴范围内添加和删除杂质的权重。 这将 2D 问题转化为 x 上的扫描线。 
4. 在压缩的 y 坐标上维护线段树。 每个节点存储惰性范围更新和 y 上的最大前缀和。 当处理给定 x 处的事件时，我们将所有更新应用于与进入或离开活动 x 板的杂质相对应的 y 间隔。 
5. 当我们从左到右扫描 x 时，在连续的 x 值之间，我们保持一组一致的活跃 y 贡献。 在处理给定 x 的更新后，我们查询线段树中的最大值，该最大值对应于该 x-slab 的最佳 y 位置。 我们跟踪所有 x 的全局最大值。 
6. 返回找到的最大值。 

关键的设计选择是我们从不显式枚举矩形。 相反，我们将每个杂质分解为变换空间中连续区域的贡献，并有效地计算最大重叠。 

### 为什么它有效

 每个可能的矩形原点恰好对应于压缩的 2D 原点空间中的一个点。 每个杂质将其重量精确地贡献给它位于矩形内的原点集。 因此，任何原点的总和恰好是覆盖该点的所有活性杂质矩形的权重之和。 扫描线确保我们在每个 x 坐标切片上正确维护活动集，而线段树确保我们找到该 x 的最佳 y。 由于通过这些扫描隐式地考虑了每个原点，因此找到的最大值是全局正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, n):
        self.n = n
        self.mx = [0] * (4 * n)
        self.lz = [0] * (4 * n)

    def push(self, v):
        if self.lz[v]:
            for c in (v * 2, v * 2 + 1):
                self.mx[c] += self.lz[v]
                self.lz[c] += self.lz[v]
            self.lz[v] = 0

    def add(self, v, l, r, ql, qr, val):
        if ql > r or qr < l:
            return
        if ql <= l and r <= qr:
            self.mx[v] += val
            self.lz[v] += val
            return
        self.push(v)
        m = (l + r) // 2
        self.add(v * 2, l, m, ql, qr, val)
        self.add(v * 2 + 1, m + 1, r, ql, qr, val)
        self.mx[v] = max(self.mx[v * 2], self.mx[v * 2 + 1])

    def query(self):
        return self.mx[1]

def solve():
    R, C = map(int, input().split())
    N, M = map(int, input().split())
    K = int(input())

    xs = set()
    ys = set()
    events = []

    for _ in range(K):
        x, y, t = map(int, input().split())

        x1 = x - R + 1
        x2 = x
        y1 = y - C + 1
        y2 = y

        events.append((x1, y1, y2, t))
        events.append((x2 + 1, y1, y2, -t))

        xs.add(x1)
        xs.add(x2 + 1)
        ys.add(y1)
        ys.add(y2)

    xs = sorted(xs)
    ys = sorted(ys)
    y_id = {v: i for i, v in enumerate(ys)}

    events.sort()
    st = SegTree(len(ys))

    ans = 0
    i = 0

    for x in xs:
        while i < len(events) and events[i][0] == x:
            _, y1, y2, val = events[i]
            l = y_id[y1]
            r = y_id[y2]
            st.add(1, 0, len(ys) - 1, l, r, val)
            i += 1
        ans = max(ans, st.query())

    return ans

if __name__ == "__main__":
    print(solve())
```该解决方案在发生变化的 x 坐标上构建扫描，并使用 y 坐标上的线段树来维持任何垂直位置的最佳累积杂质和。 每个事件对应于当矩形原点越过其有效边界时变得活跃或不活跃的杂质。 

一个微妙的实现细节是间隔端点的处理。 移除事件放置在 x2 + 1 处，以便区间 [x1, x2] 被视为包含在内。 y 间隔压缩也需要类似的注意，以确保更新和段索引之间的一致性。 

最终答案保持为所有扫描位置的最大值，包括没有新事件发生但线段树已经反映了正确的活动集的中间板。

 ## 边缘情况

 一个关键的边缘情况是所有杂质值均为负值。 在这种情况下，每个包含任何杂质的矩形都会降低分数，但最佳矩形有效地避免了所有贡献，因为在问题的解释下，最佳可实现的总和为零。 该算法可以正确处理此问题，因为线段树到处都用零初始化，因此任何负更新都会使局部值降低到零以下，但全局最大值仍为零。 

当多个杂质位于矩形间隔的同一边界上时，会出现另一种边缘情况。 例如，如果一种杂质位于 (x, y)，且 R = 1、C = 1，而另一种杂质位于 (x+1, y+1)，则两者都会导致重叠的起始区间，必须在包含和排除之间正确划分。 通过 x2 + 1 使用半开区间可确保每个贡献在正确的原点范围内仅应用一次。 

最后一个微妙的情况是，所有杂质都紧密聚集在一起，以便每个大小为 R 乘 C 的矩形同时覆盖所有杂质。 扫描将在进行任何查询之前激活所有事件，并且线段树将正确累积全部总和，从而在正确的 x-slab 处产生全局最大值。
