 ## 解决方案
 ## 问题理解

 我们正在模拟矩形 DVD 徽标在较大的矩形屏幕内移动。 徽标本身具有宽度和高度，因此其运动相当于跟踪较小矩形的左下角，该矩形被限制在尺寸缩小的矩形内移动$(W-A) \times (H-B)$。 

徽标从给定位置开始并以固定方向向量移动$(x, y)$以单位速度。 每当它撞到墙壁时，它都会像台球一样反射，这意味着入射角等于反射角。 我们没有被要求一步步模拟这个运动。 相反，我们必须确定位置和速度方向再次与初始状态完全匹配的第一个正时间。 

关键的困难在于反射会改变方向，因此矩形内的轨迹并不是简单的线性。 然而，运动在几何意义上是周期性的。 问题归结为寻找最小时间$T > 0$使系统返回到完全相同的状态。 

的限制$W, H, A, B$很小，这表明几何或数论推理是有意的而不是模拟。 方向向量分量$x, y$可以很大，但它们只定义方向，而不定义速度大小，因为速度固定为每秒 1 个单位。 

一个微妙的问题是徽标占用区域，因此当其左下角到达缩小边界而不是全屏边界时，会发生碰撞。 这是错误的常见来源：与$W, H$直接代替$W-A, H-B$。 

另一个棘手的问题是我们必须匹配位置和速度方向。 仅仅回到同样的位置是不够的； 一个循环后，运动方向可能会发生镜像，这种状态是无效的。 

当方向分量之一为零时，就会出现边缘情况。 如果$x = 0$，运动纯粹是垂直的，水平约束变得无关紧要。 这同样适用于对称的情况$y = 0$。 在这些退化情况下，简单的模拟或简单的周期计算经常会失败。 

最后，输出格式很不寻常：我们不打印完整的实数，而是打印前六位有效数字$T$。 这意味着我们必须小心地保持数值精度并避免影响前导数字的浮动错误。 

## 方法

 蛮力的想法会逐秒（或以较小的时间步长）模拟运动，更新位置并在边界处反映。 每个步骤都会计算墙壁碰撞和方向变化。 虽然这在概念上很简单，但它失败了，因为周期可能非常大，更重要的是，碰撞的实值时间通常是不合理的。 即使很小的精度误差也会累积，导致精确的相等检测变得不可靠。 

关键的观察结果是可以通过展开平面来消除反射。 我们不反映路径，而是反映整个坐标系。 这会将运动变成无限镜像矩形网格中的直线。 在这个展开的空间中，标志沿着直线移动，速度与$(x, y)$。 

当两个条件同时成立时，系统返回到相同的状态：x 坐标和 y 坐标返回到缩小矩形中的原始位置，并且每个方向上的反射次数导致相同的方向。 在展开的表示中，这转化为沿两个轴的位移是它们各自周期的公倍数的条件。 

这将问题简化为寻找共同时间$T$使得线性运动满足两个独立的模块化约束，每个轴一个。 这些约束成为一对线性丢番图条件，我们使用从方向向量和矩形尺寸导出的比率来同步 x 和 y 的周期。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 步进模拟 | O(T) 具有实数算术不稳定性 | O(1) | O(1) | 太慢/不准确|
 | 展开+数论 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1、将工作矩形替换为有效区域$(L_x, L_y) = (W-A, H-B)$。 这代表徽标左下角的所有有效位置。 
2. 计算速度大小$s = \sqrt{x^2 + y^2}$。 实际速度分量是$\left(\frac{x}{s}, \frac{y}{s}\right)$。 我们保留$s$目前具有象征意义，因为它取消了比率比较。 
3.观察到，在展开的网格中，返回到相同状态需要x和y的位移均为整数倍$2L_x$和$2L_y$， 分别。 因此我们要求：$$\frac{x}{s}T = 2L_x k, \quad \frac{y}{s}T = 2L_y m$$对于某些整数$k, m > 0$。 
4.消除$T$和$s$通过使两个表达式相等：$$\frac{2L_x k}{x} = \frac{2L_y m}{y}$$这将问题简化为寻找比例约束的整数解。 
5. 将其重写为丢番图等式：$$k \cdot (2L_x y) = m \cdot (2L_y x)$$计算两个系数的最大公约数以找到最小正整数解$k$和$m$。 
6.处理退化案件。 如果$x = 0$，运动是纯垂直的，只有 y 维度决定周期。 同样，如果$y = 0$，只有 x 重要。 
7.一次$k$（或者$m$) 确定，计算：$$T = \frac{2L_x k}{x/s} = \frac{2L_x k s}{|x|}$$使用绝对值来确保时间的正性。 
8. 转换$T$转换为具有足够精度的字符串，并从第一个非零数字开始提取前六位有效数字。 

### 为什么它有效

 展开变换将反射转换为跨矩形镜像副本的平移。 在这个空间中，轨迹是一条直线，返回到原始状态正好对应于落在一个格点上，该格点映射回具有相同方向的原始配置。 gcd 结构找到独立的 x 和 y 周期之间的最小同步，确保位置和速度同时对齐。 由于所有反射在展开网格中都被编码为奇偶校验，因此匹配两个坐标可保证完全状态等效。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def first_six_digits(x):
    s = f"{x:.15f}"
    if '.' in s:
        s = s.rstrip('0').rstrip('.')
    s = s.replace('.', '')
    i = 0
    while i < len(s) and s[i] == '0':
        i += 1
    if i == len(s):
        return "0"
    return s[i:i+6]

def solve():
    W, H = map(int, input().split())
    A, B = map(int, input().split())
    x0, y0 = map(int, input().split())
    x, y = map(int, input().split())

    Lx = W - A
    Ly = H - B

    if x == 0:
        s = abs(y)
        T = (2 * Ly * math.sqrt(x*x + y*y)) / abs(y)
        print(first_six_digits(T))
        return

    if y == 0:
        s = abs(x)
        T = (2 * Lx * math.sqrt(x*x + y*y)) / abs(x)
        print(first_six_digits(T))
        return

    a = 2 * Lx * y
    b = 2 * Ly * x

    g = math.gcd(abs(a), abs(b))
    k = abs(b) // g

    s = math.sqrt(x*x + y*y)
    T = (2 * Lx * k * s) / abs(x)

    print(first_six_digits(T))

if __name__ == "__main__":
    solve()
```该实现直接遵循展开平面缩减。 格式化帮助器确保我们不会丢失前导有效数字，因为当整数部分很小或出现尾随零时，单独的浮点格式化可能会降低早期精度。 gcd 步骤同步两个轴周期，最终公式根据所选整数解重建时间。 

在方向的一个坐标为零的退化情况下需要小心。 在这些情况下，运动简化为单轴周期系统，并且丢番图同步步骤是不必要的。

 ## 边缘情况

 当运动轴对齐时，会出现关键的边缘情况。 如果方向向量有$x = 0$，整个基于 gcd 的同步中断，因为在展开的公式中 x 循环是无限的。 在这种情况下，正确的行为是完全忽略 x 维度并直接根据 y 运动计算垂直周期。 该算法通过在任何 gcd 计算之前进行分支来处理此问题，确保不会发生被零除的情况。 

当出现另一种边缘情况时$W-A$或者$H-B$非常小，特别是等于 1。在这种情况下，反射发生得极其频繁，但展开的表示仍然有效，因为周期变为速度投影的小整数倍。 gcd 步骤仍然有效，因为它仅取决于整数几何，而不取决于大小。 

最后一个微妙的情况是方向向量很大但未标准化。 由于速度固定为 1，因此缩放$(x,y)$不会改变方向，但如果处理不仔细，它确实会影响中间算术。 仅使用比率和 gcd 计算可确保缩放不变性，因此无论大小如何，最终时间都保持正确$(x,y)$。
