 ## 解决方案
 ## 问题理解

 我们得到一个带权无向图，最多有 15 个顶点和最多 2000 条边。 每条边都具有正权重，并且可能存在连接同一对顶点的多条边或环回同一顶点的边。 任务是找到从顶点 1 开始并至少遍历每条边一次的最短循环。 如果这样的循环不存在，我们返回-1。 

关键的观察是，如果有必要，必须允许循环重用顶点和边，因为精确地访问每个边一次可能是不可能的。 本质上，我们被要求计算从给定顶点开始的**边缘覆盖循环。 当 n ≤ 15 时，我们可以利用在 n 中呈指数但在 m 中不呈指数的算法，因为 m 可达 2000。 

试图生成所有可能的边序列的简单方法是不切实际的，因为序列的数量以 m 为单位呈阶乘增长。 即使只有 15 个顶点，拥有 2000 条边也使得暴力边序列变得不可能。 循环和多个边使情况变得复杂，因为最小循环可能多次重复使用某些边。 例如，权重为 5 的循环的单个顶点应返回 5，而不是 0。 

边缘情况包括具有单个顶点且没有边的图（其中不存在环）、存在多个平行边的图或某些顶点与顶点 1 断开连接的图。粗心的解决方案可能会尝试遍历每个顶点而不是每个边一次，从而在具有多个边的图中产生错误的结果。 

## 方法

 暴力方法将尝试枚举所有边的排列或从顶点 1 开始的所有游走。对于每个候选游走，我们将检查它是否访问每条边并对其总权重求和。 行走次数与 m 组合爆炸。 即使我们修剪明显无效的路径，这种方法在最坏的情况下也是 O((2^m) × m)，并且很快超过 m ≈ 2000 的任何可行时间限制。 

关键的见解来自**将问题转化为中国邮递员问题的变体**（也称为路线检查问题）。 在图中，如果我们想以最小的成本遍历每条边至少一次，我们只需要添加额外的边来使所有顶点具有偶数度，因为欧拉循环已经覆盖了所有边一次。 如果一个顶点的度数为奇数，我们必须将其与另一个奇数度的顶点配对，并在它们之间添加最短路径。 生成的增强图可以从顶点 1 开始遍历，并且它将以最小的额外成本覆盖所有边至少一次。 

由于 n ≤ 15，我们可以使用 Floyd-Warshall 在 O(n^3) 中计算所有对最短路径。 然后我们找到所有具有奇数度数的顶点。 因为最多可以有 n 个奇数度顶点，所以我们可以使用**位掩码动态编程**方法来计算最小配对，其中每个状态表示哪些奇数顶点不匹配。 该 DP 的运行时间复杂度为 O(2^k × k^2)，其中 k 是奇数顶点的数量，这对于 k ≤ 15 是可行的。添加现有边的权重和最小配对即可得出答案。 

与蛮力的关键转变是观察到我们不需要显式地构建每个循环。 相反，我们可以推断哪些边必须重复才能允许欧拉遍历。 一旦我们将问题简化为奇数度顶点的最佳配对，问题就变成了子集上易于处理的DP。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((2^m) × m) | O((2^m) × m) | O(米) | 太慢了|
 | 最优（欧拉+DP）| O(n^3 + 2^k × k^2) | O(n^3 + 2^k × k^2) | O(n^2 + 2^k) | O(n^2 + 2^k) | 已接受 |

 ## 算法演练

1. 读取输入并构建大小为 n × n 的邻接矩阵，将非边初始化为无穷大。 对于两个顶点之间的多条边，仅保留最小权重。 
2. 使用 Floyd-Warshall 计算所有对最短路径。 这确保了当我们需要添加边来配对奇数度顶点时，我们知道连接任意两个顶点的最小成本。 
3. 使用原始边计算每个顶点的度数。 识别所有具有奇数度数的顶点。 令 k 为奇数度顶点的数量。 
4. 如果 k = 0，则该图已经是欧拉图。 最小循环长度就是所有边权重的总和。 返回这笔金额。 
5. 如果 k > 0，我们必须对奇数度顶点进行配对。 使用位掩码来表示哪些奇数顶点仍然不匹配。 初始化 dp[mask] = 无穷大，但 dp[0] = 0 除外。 
6. 对于每个掩码，找到第一个不匹配的顶点 i。 然后迭代所有不匹配的顶点 j > i 并计算 dp[mask | (1 << i) | (1 << j)] = min(dp[mask | ...], dp[mask] + dist[i][j])，其中 dist[i][j] 是从 i 到 j 的最短路径长度。 
7. 填充 DP 后，dp[(1 << k) - 1] 包含配对所有奇数顶点的最小总权重。 
8. 最终答案是 sum_of_edge_weights + dp[(1 << k) - 1]。 如果图是断开的，检查顶点1是否与所有边相连； 否则，返回-1。 

**为什么有效**：欧拉定理保证所有偶数度的图都具有欧拉循环。 如果顶点具有奇数度数，则沿着它们之间的最短路径添加边可确保所有顶点具有偶数度数，并且额外成本最小。 子集上的 DP 确保我们找到奇数顶点的最小配对，这直接对应于完全遍历图所需的最小重复边数。 由于所有最短路径都是预先计算的，因此通过 DP 添加边总是使用最小的成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**18

def solve():
    n, m = map(int, input().split())
    dist = [[INF]*n for _ in range(n)]
    deg = [0]*n
    sum_edges = 0
    
    for _ in range(m):
        x, y, w = map(int, input().split())
        x -= 1
        y -= 1
        sum_edges += w
        deg[x] += 1
        deg[y] += 1
        if dist[x][y] > w:
            dist[x][y] = dist[y][x] = w

    for i in range(n):
        dist[i][i] = 0

    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][j] > dist[i][k] + dist[k][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    # check connectivity
    for i in range(n):
        for j in range(n):
            if dist[i][j] == INF:
                # If there are edges in disconnected components, no solution
                if deg[i] > 0 and deg[j] > 0:
                    print(-1)
                    return

    odd = [i for i in range(n) if deg[i] % 2 == 1]
    k = len(odd)

    if k == 0:
        print(sum_edges)
        return

    dp = [INF]*(1<<k)
    dp[0] = 0

    for mask in range(1<<k):
        i = 0
        while i < k and (mask & (1 << i)):
            i += 1
        if i == k:
            continue
        for j in range(i+1, k):
            if not (mask & (1 << j)):
                new_mask = mask | (1 << i) | (1 << j)
                dp[new_mask] = min(dp[new_mask], dp[mask] + dist[odd[i]][odd[j]])

    print(sum_edges + dp[(1<<k)-1])

if __name__ == "__main__":
    solve()
```邻接矩阵允许快速的最短路径计算。 Floyd-Warshall 确保我们在配对奇数顶点时始终选择最小路径。 位掩码 DP 仔细处理所有配对，没有冗余。 连接性检查确保我们对于断开连接的图返回 -1。 通过在内部一致使用基于 0 的索引可以避免索引中的差一错误。
