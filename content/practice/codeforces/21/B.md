 ## 解决方案
 ## 问题理解

 每条输入线描述平面中的一个几何对象。 等式$$Ax + By + C = 0$$代表一条线。 任务是确定有多少个点同时属于两条线。 

两条不同的非平行线正好相交于一点。 两条平行但不同的线永远不会相交。 两条相同的直线完全重叠，因此它们共享无限多个点。 输出格式直接如下：

 - 打印`1`如果两条线相交一次，
 - 打印`0`如果它们从不相交，
 - 打印`-1`如果它们实际上是同一条线。 

约束很小，系数仅在`-100`和`100`。 性能并不是这里的挑战。 整个问题是关于正确处理所有几何情况并避免比例系数的错误。 

危险的部分是区分“平行”和“相同”。 一个幼稚的实现可能只比较斜率。 这适用于检测并行性，但它无法判断方程是否描述了完全相同的线。 

考虑这个输入：```
1 1 0
2 2 0
```第二个方程只是第一个方程乘以`2`，所以两者都描述同一条线。 正确答案是：```
-1
```仅检查行列式是否为零的粗心实现会错误地打印`0`。 

另一个棘手的情况是一对系数按比例匹配但常数项不匹配。```
1 1 1
2 2 3
```方向矢量成比例，因此直线是平行的。 但这些常数的缩放比例不同，因此它们是不同的平行线。 正确的输出是：```
0
```有缺陷的相等性检查可能会错误地将它们分类为相同。 

还有一个涉及零系数的微妙边缘情况：```
0 1 0
0 2 0
```这些方程变为：$$y = 0$$和$$2y = 0$$它们又是同一条线，尽管`A = 0`。 任何基于除法的解决方案都可能会崩溃或失去精度。 整数交叉乘法完全避免了这种情况。 

## 方法

 蛮力的想法是显式求解线性系统并检查结果。 对于两个方程：$$A_1x + B_1y + C_1 = 0$$

$$A_2x + B_2y + C_2 = 0$$我们可以计算行列式：$$D = A_1B_2 - A_2B_1$$如果`D ≠ 0`，系统有唯一解，所以答案是`1`。 

如果`D = 0`，线是平行的。 这时我们还需要区分“同线”和“异线”。 一种方法是使用浮点运算求解比率。 这在理论上是可行的，但它是不必要的脆弱，因为除以零和精度问题会立即出现。 

关键的观察是相同的线必须具有成比例的所有系数：$$\frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2}$$我们不进行划分，而是比较产品：$$A_1B_2 = A_2B_1$$

$$A_1C_2 = A_2C_1$$

$$B_1C_2 = B_2C_1$$这完全避免了浮点错误并自然地处理零。 

问题变成了基于决定因素和比例的小案例分析。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 具有浮点比率的暴力破解 | O(1) | O(1) | O(1) | O(1) | 实施有风险|
 | 最优整数行列式检查 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取描述两条线的六个系数。 
2. 计算行列式：$$D = A_1B_2 - A_2B_1$$如果`D ≠ 0`，这些线不平行，因此它们正好相交于一点。 打印`1`。 

1.如果`D = 0`，直线平行或相同。 我们现在检查所有系数是否成比例。 
2、比较：$$A_1C_2 = A_2C_1$$和$$B_1C_2 = B_2C_1$$行列式检查已经保证：$$A_1B_2 = A_2B_1$$因此这些额外的比较足以验证完全的比例性。 

1. 如果两个比例检验都成立，则方程描述同一条直线。 打印`-1`。 
2. 否则，这些线是平行但不同的。 打印`0`。 

### 为什么它有效

 行列式告诉我们两条线的方向向量是否线性无关。 非零行列式意味着两条线必须相交一次。 

当行列式为零时，两条线具有相同的方向，因此它们要么从不相交，要么完全重合。 当一个方程可以通过将另一个方程乘以常数得到时，两个线性方程精确地描述同一条几何直线。 交叉乘法无需除法即可检查此比例，因此可以安全地处理零和非零系数的每种可能组合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a1, b1, c1 = map(int, input().split())
a2, b2, c2 = map(int, input().split())

det = a1 * b2 - a2 * b1

if det != 0:
    print(1)
else:
    same = (
        a1 * c2 == a2 * c1 and
        b1 * c2 == b2 * c1
    )

    if same:
        print(-1)
    else:
        print(0)
```第一部分计算系数矩阵的行列式。 这是判断一个人是否合格的标准`2 × 2`线性系统有独特的解决方案。 

如果行列式非零，则答案立即`1`，因为两条线相交一次。 

第二个分支处理并行情况。 该实现不使用除系数来比较比率，而是使用整数乘法。 这很重要，因为系数可以为零。 例如，比较`a1 / a2`当`a2 = 0`。 

比例检查被写为精确的整数相等，因此不存在浮点精度问题。 由于所有值都很小，因此在 Python 中根本不可能发生溢出，尽管对于这些限制，相同的方法在 C++ 中也是安全的。

```| 变量| 价值|

 行列式为零，因此两条线平行或相同。 两个比例检查都成功，这意味着第二个方程恰好是第一个方程的两倍。 该算法打印：```
-1
```此示例说明了为什么仅检查行列式是不够的。 

### 示例 2

 输入：```
1 -1 0
1 1 -4
```| 变量| 价值|
 | --- | --- |

 |`det`|`1*1 - 1*(-1) = 2`|

 由于行列式不为零，因此两条线正好相交于一点。 该算法立即打印：```

```该迹线证实非平行线总是产生唯一的交点。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    a1, b1, c1 = map(int, input().split())
    a2, b2, c2 = map(int, input().split())

    det = a1 * b2 - a2 * b1

    if det != 0:
        print(1)
    else:
        same = (
            a1 * c2 == a2 * c1 and
            b1 * c2 == b2 * c1
        )

        if same:
            print(-1)
        else:
            print(0)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert run("1 1 0\n2 2 0\n") == "-1\n", "sample 1"

# intersecting lines
assert run("1 -1 0\n1 1 -4\n") == "1\n", "unique intersection"

# parallel but distinct
assert run("1 1 1\n2 2 3\n") == "0\n", "parallel lines"

# zero coefficients, same line
assert run("0 1 0\n0 2 0\n") == "-1\n", "horizontal line scaling"

# maximum magnitude coefficients
assert run("100 -100 50\n-100 -100 0\n") == "1\n", "boundary coefficients"

# vertical parallel lines
assert run("1 0 -1\n2 0 -3\n") == "0\n", "distinct vertical lines"

 ## 边缘情况

 考虑两个方程代表同一水平线的情况：```
0 1 0
0 2 0
```行列式变为：$$0 \cdot 2 - 0 \cdot 1 = 0$$所以这些线是平行的或相同的。 比例性检查给出：$$0 \cdot 0 = 0 \cdot 0$$和$$1 \cdot 0 = 2 \cdot 0$$两者都是真的，所以算法打印`-1`。 基于划分的方法在这里很容易失败，因为`A_1 = A_2 = 0`。 

现在检查不同的平行线：```
1 1 1
2 2 3
```行列式再次为零：$$1 \cdot 2 - 2 \cdot 1 = 0$$但比例检查失败：$$1 \cdot 3 \neq 2 \cdot 1$$算法正确打印`0`。 这区分了“同方向”和“同一条线”。 

最后，考虑垂直线和水平线的相交：```
1 0 -2
0 1 -3
```行列式是：$$1 \cdot 1 - 0 \cdot 0 = 1$$由于它不为零，算法立即打印`1`。 不需要对垂直线进行特殊处理，因为行列式方法对每个方向都适用。
