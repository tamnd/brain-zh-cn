 ## 解决方案
 ## 问题理解

 我们得到一个二进制字符串，并且允许我们使用另一个相同长度的二进制字符串“修改”它。 第二个字符串的效果不是任意的，因为它仅受包含的字符串数量的限制。 选择这样的辅助字符串后，我们将其与原始字符串进行异或，生成转换后的字符串。 问题是我们是否可以选择辅助字符串，以便转换后的字符串成为回文，并且我们不仅会被问到一个选择，还会被问到辅助字符串中每一个可能的数量。 

所以输出是长度的二进制指示符数组`n+1`。 位置`i`如果存在某种方法可以精确地选择辅助字符串，则为一`i`这样在异或之后，结果字符串就变成了回文。 

约束很大，测试用例的总长度可达`10^5`，它排除了任何尝试所有位置子集或显式构造候选字符串的方法。 任何解决方案都必须接近每个测试用例的线性，理想情况下依赖于回文约束的计数和结构特性而不是模拟。 

当字符串已经是回文时，会出现微妙的边缘情况。 在这种情况下，选择空辅助字符串是可行的，所以`i = 0`始终有效。 然而，附加值`i`取决于对称性，也可能变得有效，并且关于“独立修复不匹配”的天真的贪婪假设会失败，因为异或耦合了对称位置。 

## 方法

 暴力视图是迭代所有可能的辅助字符串`l`，按个数分组，与原始字符串进行异或，检查结果是否为回文。 这一下子就炸了：有`2^n`选择`l`，甚至按权重分组仍然留下指数数量的配置。 即使检查每个配置的回文，其复杂性也远远超出了可行性。 

关键的结构观察是 XOR 仅翻转位，回文条件是镜像位置之间的成对约束。 每对`(i, n-1-i)`要求翻转后，两个位置变得相等。 这将问题转换为约束系统，其中每个对称对要么已经匹配，要么必须通过精确翻转两个位置之一来修复。 这立即将问题转化为计算存在多少“不匹配的货币对”以及这些货币对之间翻转预算的灵活性。 

曾经被视为匹配约束问题的“数量”的作用`l`“成为我们翻转多少头寸的预算，每个对称对都贡献一个固定成本模式。这减少了确定在这些对引起的奇偶性和范围限制下可实现哪些总翻转计数的问题。

 | ---| ---| ---| ---|
 | 蛮力胜过一切`l`| O(2^n·n) | O(2^n·n) | O(n) | 太慢了 |
 | 对约束计数 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每个测试用例。 

1.我们配对对称索引`(i, n-1-i)`并根据位是否相等进行分类。 这是因为只有这些对才能在异或后实现回文。 
2.让`diff`是位置的数量，其中`s[i] != s[n-1-i]`。 每个这样的对都强制在其两个位置之一中至少进行一次翻转，以使它们在异或后相等。 这给出了所需的最少翻转次数。 
3.任何有效的解决方案必须至少有`diff`辅助字符串中的那些，因为每个不匹配的对都需要一次更正。 然而，我们还必须尊重奇偶校验约束：翻转会改变分布，但对的行为仅取决于奇偶校验效应。 
4. 我们观察到，在满足最小修正后，每对在如何自由分配翻转方面贡献了 0 或 2。 这将创建一个可到达的所有整数集，从`diff`并以 2 为步长扩展至`n`。 
5. 因此，一些`k`如果满足以下条件则有效：

 -`k >= diff`-`(k - diff) % 2 == 0`-`k <= n`6.我们构造答案字符串`t`通过设置`t[k] = 1`每当这些条件成立时。 

一个关键的微妙之处是无与伦比的中间字符（当`n`是奇数）不施加配对约束并提供充分的灵活性，但仅影响可达性边界，而不影响从对派生的奇偶校验结构。 

### 为什么它有效

 每个对称对在变换后独立地强制相等。 修复不匹配的对总是需要在该对中恰好进行一次翻转，并且任何超出最小值的额外翻转都可以成对添加，而不会破坏可行性。 这创建了一个结构，其中所有有效解决方案完全由强制修正的数量加上任何偶数剩余决定，这保证了可达的算术级数`k`价值观。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()

        diff = 0
        for i in range(n // 2):
            if s[i] != s[n - 1 - i]:
                diff += 1

        res = ['0'] * (n + 1)

        for k in range(diff, n + 1):
            if (k - diff) % 2 == 0:
                res[k] = '1'

        print(''.join(res))

if __name__ == "__main__":
    solve()
```该解决方案首先计算不匹配的对称对，这确定了所需的最小翻转次数。 然后，它通过成对添加多余的翻转来检查可以达到哪些总数，从而填充输出。 奇偶校验确保我们不会违反配对引起的对称约束。 

一个常见的错误是独立对待每个职位。 正确性完全取决于这样一个事实：操作总是影响耦合对中的对称约束，而不是孤立的索引。

 ## 边缘情况

 当字符串已经是回文时，`diff = 0`，所以每一个偶数`k`是有效的。 这会在输出中产生从零开始的完整交替模式。 这与任何偶数次翻转都可以对称分布而不会破坏相等性这一事实相一致。 

当所有对称对不同时，`diff = n/2`，强制设定较高的最小值。 只有从该阈值开始并遵守奇偶校验的值才保持有效，这表明配对约束对可行性的控制有多严格。
