 ## 解决方案
 ## 问题理解

 我们从一个数组开始`a`长度`n`填充零，我们想将其转换为目标数组`b`相同长度的。 唯一允许的操作是“循环覆盖”：我们选择一组`k`不同的位置，并将这些位置上的每个元素替换为同一集合中下一个元素的索引，并在末尾环绕。 更具体地说，如果`l`是我们选择的索引集，`a[l[i]]`变成`l[(i+1) % k]`。 

输入由多个测试用例组成，每个测试用例提供数组长度`n`, 操作大小`k`，以及目标数组`b`。 如果可以达到，则每种情况的输出都是简单的“是”`b`使用零个或多个操作，否则为“NO”。 

关键的限制是`n`可以达到`10^5`每个测试用例，所有测试用例的总和不超过`2·10^5`。 这禁止对每个操作序列进行任何强力模拟，因为可能的序列数量会组合增长。 我们需要一个线性或近线性扩展的解决方案`n`。 

边缘情况出现时`k = 1`或者`k = n`。 为了`k = 1`，该操作将单个元素替换为自身，这仅在以下情况下有用：`b[i] = i`。 幼稚的实现可能会忽略这一点，当某些值超出范围时会产生错误的“YES”。 另一个微妙之处是重复值`b`：如果连续元素需要不同的源进行循环操作，则粗心的贪婪赋值可能无法遵守循环依赖性。 

## 方法

 强力解决方案将模拟索引集的每种可能选择`l`并重复应用循环操作，直到`a`等于`b`或者所有的选择都用尽了。 虽然原则上是正确的，但其复杂性却是天文数字。 每一个选择`k`职位来自`n`有`C(n, k)`的可能性，这对于`n = 10^5`和`k = n/2`是完全不可行的。 

最佳解决方案的洞察来自于逆向操作。 而不是试图“构建”`b`我们一步步来看`b`并推断哪些位置可以是同一循环操作的一部分。 观察到一个操作只是排列一组大小内的元素`k`，我们意识到任何序列`k`中的连续值`b`如果它们形成连续的循环，则可以被“覆盖”。 这导致了贪婪分解：我们扫描`b`从左到右，并且对于可以通过长度的单个循环操作分配的每个连续的值`k`，我们将它们标记为已处理。 如果任何元素不能包含在有效循环中，则答案为“否”。 

这减少了扫描的问题`b`同时保持周期长度达`k`，这是线性的`n`。 唯一的附加要求是`k = 1`，每个元素必须等于自己的索引，可以直接检查。

 ## 算法演练

 1. 在数组开头初始化一个指针`b`。 该指针将从左向右扫描，尝试将元素分组为循环。 
2.趁指针未到末尾，查看当前元素`b[i]`。 这是潜在循环的“头”。 
3. 尝试形成最长长度的循环`k`开始于`b[i]`。 检查下一个元素是否对应于预期的循环排列。 具体来说，循环中的下一个元素必须是将映射回以循环长度为模的下一个索引的值。 
4. 如果有效循环长度≤`k`找到后，将指针移过循环。 否则，配置是不可能的，我们输出“NO”。 
5. 重复此操作，直至覆盖所有元素。 如果每个元素都参与有效循环，则输出“YES”。 

为什么它有效：该操作是一个仅限于的排列`k`职位。 通过确保每个连续的子序列`b`对应于这样的排列，我们保证存在一个构造的操作序列`b`。 每个元素必须恰好属于一个循环，这与每个操作仅在其所选集合内覆盖的不变量一致。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_form_array(n, k, b):
    if k == 1:
        # Each element must be equal to its own index
        for i in range(n):
            if b[i] != i + 1:
                return False
        return True

    # Track groups of repeated numbers
    i = 0
    while i < n:
        start = i
        while i < n and b[i] == b[start]:
            i += 1
        group_len = i - start
        if group_len > k:
            return False
    return True

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    b = list(map(int, input().split()))
    print("YES" if can_form_array(n, k, b) else "NO")
```我们处理`k = 1`作为一种特殊情况，因为长度为 1 的循环不能更改值。 对于较大的`k`，我们将相同的值分组并检查每个连续组的长度； 如果任何组超过`k`，它不能放入循环中，所以答案是“NO”。 这种方法避免了构建实际的周期并且在时间上是线性的。
