 ## 解决方案
 ## 问题理解

 我们得到一个数组`a`长度`n`。 我们必须构造一个排列`b`的数字来自`1`到`n`这样当我们逐个元素相减时，形成`c_i = a_i - b_i`，出现在不同值的数量`c`尽可能大。 

简单来说，我们将每个位置配对`i`有一个唯一的号码`b_i`之间`1`和`n`，每对都会产生一个差异。 目标是使所有职位的这些差异尽可能多样化。 

关键的限制是`b`必须是一个排列，因此每个整数`1`到`n`仅使用一次。 我们没有优化以下值`c`本身，只有多少个不同的值出现在`c`。 

测试用例的总输入大小最多为`4 * 10^4`，因此任何解决方案都必须在每个测试用例的线性时间内运行。 任何涉及排序和大量模拟的事情都可以，但任何二次以上的事情都可以`n`如果重复多次，就已经是临界点了。 

一个微妙的边缘情况是`n = 1`。 那么只有一种可能的排列，而且答案是微不足道的。 另一种需要注意的情况是，当许多`a_i`是平等的。 一个幼稚的想法可能会尝试以特殊的方式匹配相同的值，但问题并不奖励控制差异的大小，而只是奖励它们的独特性。 

最常见的错误直觉是试图最大化数字分布`c_i`。 这是无关紧要的：之间只有平等关系`c_i`事情。 

## 方法

 蛮力策略会尝试每一种排列`b`的`[1, 2, ..., n]`，计算所有差异`c`，并计算出现了多少个不同的值。 这是正确的，但立即不可行。 有`n!`排列，并且对于每个我们计算`n`差异，导致大致`O(n! * n)`即使对于`n = 10`。 

为了改进，我们需要了解真正决定两个差异是否相等的因素。 我们有：`c_i = a_i - b_i`两个位置`i`和`j`在以下情况下产生相同的值：`a_i - b_i = a_j - b_j`，重新排列为：`a_i - a_j = b_i - b_j`这告诉我们，碰撞`c`完全对应于等差`a`被镜像在`b`。 自从`b`是一个排列，我们有完全的自由来分配不同的值，所以我们可以尝试“打破结构”`a`。 

关键的观察是我们可以最大限度地提高多样性`c`通过确保尽可能多的对`(a_i, b_i)`尽可能避免产生重复的差异。 要做到这一点，最简单和最有效的方法是最大化之间的反对齐`a`和`b`。 

如果我们排序`a`，然后将最小的元素配对`a`的最大值为`b`，反之亦然，尽可能地分散差异。 这是标准的重排原则：相反的顺序使线性组合的变化最大化。 

所以我们对索引进行排序`a_i`，然后赋值`b`沿着该顺序降序排列。 

具体来说：

 最小的`a_i`得到`n`，第二小的得到`n-1`， 等等。 

这产生了单调结构`c`从而避免不必要的重复。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!·n) | O(n!·n) | O(n) | 太慢了 |
 | 最优（排序+反向赋值） | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取数组`a`并将每个值与其索引相关联。 我们需要索引，以便我们可以将值放入正确的位置`b`。 
2. 按增加值对索引进行排序`a`。 这将创建从小到大的排序`a_i`。 排序的原因是强加结构`a`这样我们就可以控制差异的行为方式。 
3. 创建一个空数组`b`长度`n`。 
4. 赋值给`b`按照可用性的相反顺序：最小的`a_i`得到`n`，下一个得到`n-1`， 等等。 这确保了更大的`b_i`值与较小的值配对`a_i`。 
5、输出`b`按原始索引顺序。 

第 4 步背后的推理是，配对极端可以最大化对应的之间的分离`a_i`和`b_i`，减少两个差异重合的机会。 

### 为什么它有效

 排序后，假设`a_i < a_j`。 然后我们分配`b_i > b_j`。 所以对于任意一对`i, j`，我们有相反的顺序`a`和`b`。 这种反单调配对确保了表达式`a_i - b_i`尽可能地传播价值，因为增加`a`被减少所抵消`b`。 

这会破坏如果两个数组的顺序相似时会出现的结构化重复。 虽然我们没有明确保证所有差异都是不同的，但这种结构最大限度地提高了分离度并避免了系统性冲突，这正是问题所奖励的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    idx = list(range(n))
    idx.sort(key=lambda i: a[i])

    b = [0] * n
    val = n

    for i in idx:
        b[i] = val
        val -= 1

    print(*b)
```该解决方案首先构建一个索引数组，这样我们就不会丢失元素的原始位置`a`。 排序依据`a[i]`允许我们在不修改原始数组的情况下强加结构。 

变量`val`开始于`n`并减少，确保严格排列。 每个索引接收一个唯一的值，所以`b`是有效的。 

一个微妙的点是我们从不排序`a`本身，只有指数。 这是必要的，因为输出必须尊重位置的原始顺序。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out_lines = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        idx = list(range(n))
        idx.sort(key=lambda i: a[i])

        b = [0] * n
        val = n
        for i in idx:
            b[i] = val
            val -= 1

        out_lines.append(" ".join(map(str, b)))
    return "\n".join(out_lines)

 ## 边缘情况

 对于`n = 1`，排序后的索引列表包含单个元素，我们分配`b[0] = 1`。 该算法产生唯一有效的排列，并且差异数组只有一个元素，因此不同计数几乎被最大化。 

对于所有相等的值`a`，排序索引是任意的。 该算法仍然将完整排列分配给`b`。 自从`a_i`是相同的，差异纯粹由`-b_i`，它们都是不同的，因为`b`是一个排列。 这确保了最大可能的不同计数`n`。 

对于严格增加`a`，算法对最小`a_i`与最大的`b_i`，产生严格结构化的差异序列。 虽然`a`是有序的，反向赋值通过避免增量对齐来防止重复差异`a`和`b`。
