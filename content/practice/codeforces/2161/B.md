 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$标有黑色单元格的网格`#`和标记的白细胞`.`。 我们的目标是将一些白细胞涂成黑色，以便同时满足三个条件。 首先，必须至少有一个黑色单元格。 其次，所有黑色单元格必须在正交邻接下形成单个连通分量：您可以通过仅踩在黑色单元格上、向上、向下、向左或向右移动，从任何黑色单元格移动到任何其他黑色单元格。 第三，任何行或列都不能有三个连续的黑色单元格。 

输入包括多个测试用例，每个测试用例都有自己的网格。 单个网格的最大尺寸为 100 x 100，并且$n$所有测试用例的数量不超过 2000。这意味着在每个单元上迭代几次的解决方案是可以接受的，但任何二次方$n^2$如果重复 1000 个测试用例，每个测试用例可能会变慢。 

有一些微妙的边缘情况可能会阻碍简单的方法。 例如，完全充满黑色单元格的 3x3 网格显然违反了“不能连续三个”规则。 另一个棘手的情况是黑白单元格的棋盘图案。 虽然连通性可以通过绘画来实现，但添加黑色单元可能会意外地创建三个连续的单元。 大小为 1 或 2 的小网格也需要特殊处理，因为它们的行数或列数限制了相邻的可能性。 

## 方法

 暴力方法将尝试绘制白细胞的每个可能的子集，每次检查连通性和“不连续三个”规则。 这在原则上是正确的，但不可行，因为子集的数量是指数级的。 对于一个$n \times n$网格与$k$白细胞，有$2^k$的可能性。 即使是为了$n=10$，这太大了，无法穷尽探索。 

关键的见解是关注 2x2 的正方形。 如果网格在任何地方违反了三连规则，则不可能在不破坏连接或创建新违规的情况下进行本地修复。 通过考虑每个 2x2 正方形，我们注意到绘制该正方形内的所有单元格要么保留非三连续属性，要么破坏它。 因此，检查每个 2x2 正方形中是否有“一行中的三个黑色单元格”就足以检测无法解决的模式。 由于任何行或列中都不能出现三个连续的黑色单元格，因此 2x2 正方形内唯一禁止的模式是排列黑色单元格，以便再添加一个黑色单元格将在一行中创建一个三元组。 如果所有 2x2 正方形都满足这个属性，我们总是可以通过沿对角线绘制来构建一条连通路径，保证连通性并避免三连违规。 

这导致了一个简单的 O(n^2) 解决方案：迭代网格中的所有 2x2 正方形并检查禁止的模式。 如果不存在，则打印“YES”； 否则，打印“NO”。 这是有效的，因为$n^2$每个测试用例的迭代次数乘以最大总和$n^2$所有测试用例大约是2,000,000个，在2秒内是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^{n^2}) | O(2^{n^2}) | O(n^2) | O(n^2) | 太慢了 |
 | 2x2 方格格子| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，请阅读$n$然后网格作为字符串列表。 
2. 迭代所有位置$(i,j)$在哪里$0 \le i < n-1$和$0 \le j < n-1$。 这些是 2x2 正方形的左上角。 
3. 对于由以下定义的每个 2x2 正方形$(i,j)$，数出四个位置黑色单元格的数量$(i,j)$,$(i,j+1)$,$(i+1,j)$,$(i+1,j+1)$。 
4. 如果 2x2 正方形恰好包含三个黑色单元格，则不可能在不创建三个连续单元格的情况下添加黑色单元格以使所有黑色单元格连接起来。 立即对此测试用例返回“NO”。 
5. 如果没有 2x2 正方形恰好包含三个黑色单元格，则返回“YES”。 

工作原理：任何局部违反三排约束的解决方案都将显示为三个黑色单元格 2x2 正方形。 通过验证每个方块的这个属性，我们捕获了所有无法解决的配置。 一旦我们确认不存在禁止模式，我们就可以沿着对角线或 L 形路径构建一个连接的黑色组件，而无需创建三个连续的黑色单元。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        grid = [input().strip() for _ in range(n)]
        possible = True
        for i in range(n - 1):
            for j in range(n - 1):
                black_count = sum(
                    grid[i][j] == '#' +
                    grid[i][j+1] == '#' +
                    grid[i+1][j] == '#' +
                    grid[i+1][j+1] == '#'
                )
                if black_count == 3:
                    possible = False
                    break
            if not possible:
                break
        print("YES" if possible else "NO")

if __name__ == "__main__":
    solve()
```第一部分使用有效读取输入`sys.stdin.readline`。 我们迭代网格中的所有 2x2 正方形。`black_count`对四个布尔表达式求和； 在Python中，`True`是 1，`False`为 0，给出黑色单元格的数量。 如果正好有三个单元格是黑色的，我们立即将测试用例标记为不可能。 然后我们打印结果。 嵌套循环仅通过迭代来自动处理边界条件`n-1`。
