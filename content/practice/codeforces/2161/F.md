 ## 解决方案
 ## 问题理解

 我们被要求计算树中所有顶点子集的全局总和。 输入是一个未加权的树`n`顶点。 从这棵树中，我们想象一个完整的图，其中任意两个顶点之间的权重等于原始树中它们之间的距离。 对于每个顶点子集，我们找到导出子图的最小生成树 (MST)，并且我们需要所有子集中这些 MST 权重的总和。 最终答案取模$10^9 + 7$。 

约束条件告诉我们$n$最多可以有5000个，测试用例可以有很多，但是总和$n^2$所有测试用例最多为 2500 万个。 这排除了任何显式枚举所有顶点子集的算法，因为有$2^n$子集，即使对于中等程度的子集也会变得天文数字般大$n$。 它还建议任何$O(n^3)$每个测试用例的解决方案都是临界的，所以我们应该瞄准$O(n^2)$或每个测试用例更好。 

当树只有一个顶点时，就会出现边缘情况，在这种情况下，任何 MST 中都没有边可包含，因此总和为零。 类似地，一棵直线树将创建强制 MST 边的子集，如果独立于子集如何包含边来处理边，则可能会导致微妙的计数错误。 

## 方法

 强力方法会考虑每个顶点子集，构造完整图的导出子图（其中权重是距离），然后计算其 MST，对权重求和。 这是可行的，因为计算 MST 是很好理解的，但它的速度却慢得无可救药，因为有$2^n$子集。 即使有记忆，我们也无法承受指数增长。 

更快解决方案的关键见解是使用树结构本身而不是完整的图。 子集的每个 MST 对应于连接所有包含的顶点的原始树的边的子集。 如果我们关注原始树中的单个边，则其权重（距离）为 1。如果我们暂时删除该边，则该边将有助于端点位于不同连接组件中的那些子集的 MST 总和。 对于连接节点的边`u`和`v`， 让`a`是子树中的顶点数`u`如果我们移除边缘，并且`b = n - a`是另一个组件中的顶点数。 该边出现在两侧至少包含一个顶点的任何子集的 MST 中。 计算这些子集给出$(2^a - 1) * (2^b - 1)$对于每条边，乘以边权重。 这将问题从指数枚举转换为使用简单组合计数对树边进行单次遍历。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(n^2) | O(n^2) | 太慢了|
 | 最佳| O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取顶点数`n`和树的边缘。 构建代表树的邻接表。 
2. 初始化一个`mod`变量为$10^9 + 7$并预先计算两个模的幂`mod`最多`n`，因为我们需要`2^k`经常用于子树大小。 这避免了重新计算每个边缘的功率。 
3. 对于树中的每条边，将其视为已删除。 从一个端点执行深度优先搜索 (DFS) 以计算大小`a`从该端点可到达的子树而不跨越边缘。 尺寸`b`另一个组件是`n - a`。 
4.这条边对最终总和的贡献就是乘积`(2^a - 1) * (2^b - 1)`。 将其乘以边权重，在我们的例子中为 1。 将其添加到运行总和模`mod`。 
5. 对所有边缘重复此操作。 输出总和模`mod`。 

为什么它有效：通过删除一条边，树就分裂成两个部分。 当子集至少包含每个组件的一个顶点时，边就会出现在子集的 MST 中。 对每条边满足此条件的子集进行计数可确保每个子集 MST 权重仅计数一次，因为每个子集的 MST 是由原始树中连接其顶点的边唯一确定的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10000)

mod = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n)]
        edges = []
        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            adj[u].append(v)
            adj[v].append(u)
            edges.append((u, v))
        
        pow2 = [1] * (n + 1)
        for i in range(1, n + 1):
            pow2[i] = (pow2[i-1] * 2) % mod
        
        def dfs(u, parent):
            size = 1
            for v in adj[u]:
                if v != parent:
                    size += dfs(v, u)
            return size
        
        ans = 0
        for u, v in edges:
            # size of subtree if we remove edge u-v
            size_u = dfs(u, v)
            size_v = n - size_u
            contrib = ((pow2[size_u] - 1) * (pow2[size_v] - 1)) % mod
            ans = (ans + contrib) % mod
        print(ans)

solve()
```该代码首先为每个测试用例构建邻接表。 我们预先计算两个模的幂`mod`以避免DFS中的重复计算。 对于每条边，我们从概念上删除它，并使用 DFS 从一个端点计算子树大小。 那么边的贡献为`(2^size_u - 1) * (2^size_v - 1)`，然后我们将其与模数相加`10^9 + 7`。 使用`sys.setrecursionlimit`确保 DFS 不会达到 Python 对深树的递归限制。 

## 工作示例

 考虑第一个样本，其中 3 个顶点连接为 1-2-3。 

| 边缘| 子树大小 (a,b) | 贡献 |
 | --- | --- | --- |
 | 1-2 | 1-2 1,2 | (2^1-1)_(2^2-1)=1_3=3 | (2^1-1)_(2^2-1)=1_3=3 |
 | 2-3 | 2-3 1,2 | (2^1-1)_(2^2-1)=1_3=3 | (2^1-1)_(2^2-1)=1_3=3 |

 总和为 6，与预期输出相符。 这表明对于小线树，该算法可以正确计算所有子集。 

对于单边 2-1 (n=2) 的树：

 | 边缘| 子树大小 | 贡献 |
 | --- | --- | --- |
 | 2-1 | 2-1 1,1 | (2^1-1)_(2^1-1)=1_1=1 | (2^1-1)_(2^1-1)=1_1=1 |

 总和为 1，这是正确的，因为唯一具有至少两个顶点的非空子集包括两个端点，形成权重为 1 的 MST。
