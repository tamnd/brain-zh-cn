 ## 解决方案
 ## 问题理解

 我们正在模拟一系列比赛轮次，参与者有时可以在每个评分轮次之前调整他们的评分。 关键的复杂性在于，是否对参与者进行一轮评级取决于他们当前的评级与固定阈值的比较，并且在评级轮次中，他们可以在有限的范围内改变其评级。 

每个测试用例都会给出一个初始评级、分隔两种轮次的阈值、在评级轮次之前可以调整评级的最大步长，以及标记为类型 1 或类型 2 的轮次序列。始终对类型 1 轮次进行评级。 仅当当前评级严格低于阈值时，才会对类型 2 回合进行评级； 否则，它将变为未评级并且评级不会改变。 

当对一轮进行评分时，玩家可以选择当前评分周围对称区间内的任何最终评分。 这使得这个过程感觉就像在数轴上受控行走，只不过当评级太高时，某些步骤会被“冻结”。 

任务是最大化最终评级的回合数。 

约束告诉我们，每个测试用例的轮数最多为 1000，所有测试的总轮数最多为 30000。这立即表明，所有状态和所有轮次的二次或接近二次动态规划是可以接受的，但每步超过 1000 个状态的三次方就已经是边界了。 需要一种解决方案，即每步仅维护一小部分可达到的评级。 

主要困难在于评级原则上是无限制的，但对于第 2 类轮次而言，只有评级与阈值的关系才重要。 这表明我们永远不需要精确跟踪所有评级，只需要影响我们是否保持低于或高于阈值的范围或极值可能性。 

当本地做出贪婪决策时，就会出现微妙的失败情况。 例如，立即将评级降低到尽可能低可能有助于启用未来的第 2 类轮次，但它可能会降低第 1 类轮次的灵活性，我们可能希望保持在阈值以上以避免不必要的状态更改。 这种相互作用是长期的，因此局部决策是不可靠的。 

## 方法

 强力解释是将每一轮视为在每个评级轮之后可达到的所有可能评级值的分支。 在一轮评级之后，评级可以变成当前评级周围长度为 2D 的段中的任何整数。 如果我们准确地跟踪所有可达的评级，我们很快就会得到状态爆炸：每个状态都会扩展到 O(D) 个新状态，并且在最坏的情况下，经过 n 个步骤，这会变成 n 的指数。 

然而，问题的结构使得这种杀伤力过大。 评级之间唯一有意义的区别是它们是否低于 X，因为这决定了 2 类轮次是否活跃。 在低于 X 的区域和高于 X 的区域内，我们只关心我们的可达性以及在需要时是否可以跨越阈值。 

关键的见解是，我们不是跟踪所有可达到的评级，而是跟踪最大化未来评级回合的最佳可能“有效位置”。 我们观察到，当我们处于评级回合中时，我们总是可以将评级移动到 2D 大小的区间内的任何位置。 这意味着在每个评级轮次之后，可能的评级集始终是连续的区间。 此属性将状态空间从潜在的多个点折叠为单个区间。

因此，在每一步中，我们都保持在迄今为止最大化评级轮数后可达到的最小和最大可能评级。 对于每一轮，我们根据该轮是否被评级以及类型 2 是否处于活动状态或被跳过来更新此间隔。 当对回合进行评分时，我们将间隔在两个方向上扩大 D。 当它被跳过时，间隔保持不变。 我们还需要考虑这样一个事实，即只有当当前间隔低于 X 时，类型 2 轮才会被评级，这决定了我们是否获得分数以及是否应用转换。 

这将问题简化为具有恒定时间间隔更新的轮次线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（所有评级状态）| 指数| 指数| 太慢了 |
 | 间隔 DP | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们从左到右处理回合，同时在达到迄今为止的最大评级轮数后保持可能的评级范围。 

1. 将当前可达到的额定值区间初始化为初始额定值 R₀ 处的一个点。 同时将答案初始化为 0。 
2. 按顺序扫描每一轮。 对于每一轮，确定是类型 1 还是类型 2。 
3. 如果回合类型为 1，则始终评级。 我们将答案增加 1。然后，我们通过将其扩展为 [L - D, R + D] 来更新区间，因为在一轮评级之后，我们可以选择任何先前可达到的值的 D 内的任何评级，并且组合所有可能性产生完整扩展的区间。 这一步确保我们保留所有未来的可能性。 
4. 如果该轮次为类型 2，我们首先检查该轮次是否可以被评级，即当前区间内至少存在一个严格小于 X 的评级。这相当于检查该区间的最小值是否小于 X。 
5. 如果类型 2 回合的评级低于当前区间，我们将答案增加 1。然后，我们以与类型 1 相同的方式更新区间，在两侧将其扩展 D。 
6. 如果类型 2 回合未评级，我们不会更改间隔，因为评级在未评级回合期间保持冻结。 
7. 继续此过程，直到处理完所有回合，并输出累积的评分回合数。 

关键思想是，在最大化决策后，我们始终保留可实现的全部评级。 我们永远不需要选择单一轨迹，因为区间已经代表了所有最佳可能性。 

### 为什么它有效

 正确性取决于处理每个回合前缀后的不变量，区间 [L, R] 准确地表示在最大化到该点的评分回合数后可以实现的所有评分的集合。 

当对一轮进行评分时，前一个间隔中的每个点都可以在±D内独立移动，并且所有所得间隔的并集再次成为单个连续间隔。 当一轮未评级时，不会发生任何转换，因此可达集保持不变。 由于类型 2 轮次仅由是否有任何可行评级低于 X 来决定，因此检查间隔最小值足以决定该轮次是否可以在某些最佳执行中进行评级。 

因为我们从不丢弃任何可能导致以后进行更多评级的可达到的评级，所以最终计数是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        R0, X, D, n = map(int, input().split())
        s = input().strip()

        L = R0
        R = R0
        ans = 0

        for c in s:
            if c == '1':
                ans += 1
                L -= D
                R += D
            else:
                if L < X:
                    ans += 1
                    L -= D
                    R += D
                else:
                    pass

        print(ans)

if __name__ == "__main__":
    solve()
```实现直接遵循区间解释。 变量 L 和 R 代表最大化评级轮数后可能的评级的全部范围。 对于每一轮第 1 类，我们总是扩大间隔并增加答案。 

对于类型 2 回合，条件`L < X`是足够的，因为如果最小可能评级已经高于或等于 X，则假设该区间包含所有可达状态，则没有任何执行路径可以使评级低到足以符合资格。 一旦一轮被认为评级，我们再次应用相同的扩展规则。 

一个微妙的细节是，我们从不试图将评级“强行”到特定区域； 间隔自动对所有有效选择进行编码。 这可以避免任何回溯或案例分割。

 ## 边缘情况

 一种边缘情况是初始评级已低于阈值。 在这种情况下，第一个类型 2 轮次立即符合资格，并且间隔从一开始就开始扩大。 该算法自然地处理这个问题，因为条件`L < X`is true at initialization, so no special casing is needed.

 Another edge case is when the rating starts far above X and D is small. 在这种情况下，可能需要进行几轮评级才能使区间降至 X 以下。区间表示确保隐式捕获这种转变，因为只有当可以在整个区间内自由选择评级时，重复扩展最终才会使下限向下移动。 

A final edge case is when X is extremely large compared to all reachable ratings. 那么类型 2 的回合就不会被计算在内。 The algorithm correctly leaves the answer unchanged because the interval never intersects below X.
