 ## 解决方案
 ## 问题理解

 我们得到了几个数据包，每个数据包都包含已知数量的气球。 任务是将这些数据包分给两个人，以便每个数据包完全准确地发送给其中一个人。 任何一个数据包都不能被破坏，并且两个人都必须至少收到一个数据包。 

分割后，我们计算每个人收到的气球总数。 目标是确保这两个总数不同。 如果存在这样的分割，我们必须向第一个人输出一个有效的数据包分配； 否则我们会报告不存在有效的分割。 

输入大小非常小，最多 10 个数据包。 这立即表明对子集的指数搜索是可行的。 即使使用简单的计算，检查所有可能分配（最多 2^10 = 1024 种情况）的解决方案也完全在限制范围内。 

当只有一个数据包时，就会出现主要的边缘情况。 在这种情况下，不可能同时给两个人至少一包，所以答案一定是不可能的。 另一个微妙的情况是，每个分区的总数相等，但由于所有数据包大小均为正数，因此这种情况只能发生在简单的单个数据包情况下。 

## 方法

 最直接的想法是尝试一切可能的方式将数据包分配给Grigory或Andrew。 每个数据包有两个选择，因此总共有 2^n 次分配。 对于每个作业，我们计算每组中气球的总和，并检查两组是否非空以及它们的总和是否不同。 

这种蛮力方法是正确的，因为它无遗漏地探索了完整的解决方案空间。 问题在于 n 可能很大的一般问题的性能。 当 n 达到 10 时，这种方法仍然非常快，因为最多检查 1024 个子集，每个总和计算成本为 O(n)，大约需要 10,240 次操作。 

关键的观察结果是我们不需要进一步优化。 约束条件故意设置得很小，以便穷举搜索成为预期的解决方案。 我们只需要确保跳过无效分区，其中一组为空或总和完全匹配。

 ## 算法演练

 1. 计算所有数据包中气球的总数。 这个值可以帮助我们快速评估每个分割，因为一旦我们知道一侧，另一侧就确定了。 
2. 如果只有一个数据包，则立即输出-1。 无法将单个数据包拆分为两个非空组。 
3. 迭代数据包的所有子集，表示每个数据包是否分配给 Grigory。 
4. 对于每个子集，确保它既不是空集也不是完整集。 这保证了双方至少收到一个数据包。 
5. 计算所选子集中气球的总和。 
6. 将该金额与剩余金额进行比较。 如果它们不同，那么这是一个有效的解决方案，我们可以立即输出它。 
7. 如果没有子集有效，则输出-1。 

### 为什么它有效

 每个有效的分配恰好对应于数据包索引的一个子集。 该算法检查除一侧为空的无效子集之外的所有子集。 对于每个有效子集，它验证唯一剩余的约束，即两个总和不同。 由于检查了每个可能的分区，因此将找到任何有效的解决方案，如果不存在，则搜索将穷尽所有可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    if n == 1:
        print(-1)
        return

    total = sum(a)
    m = 1 << n

    for mask in range(1, m - 1):
        s = 0
        for i in range(n):
            if mask & (1 << i):
                s += a[i]

        if s != 0 and s != total and 2 * s != total:
            print(bin(mask).count("1"))
            res = []
            for i in range(n):
                if mask & (1 << i):
                    res.append(i + 1)
            print(*res)
            return

    print(-1)

if __name__ == "__main__":
    solve()
```该解决方案使用位掩码枚举所有子集。 每个掩码对发送给 Grigory 的数据包进行编码。 条件`mask range 1 to (1<<n)-2`确保两边都不为空。 

对于每个掩码，我们计算子集和并检查它是否与互补和不同。 支票`2 * s != total`直接编码两个总数不相等的要求。 

一旦找到有效的子集，我们就输出它的大小和索引。

 ## 边缘情况

 单数据包情况是唯一结构上不可能的情况。 输入类似`1\n7`，无法为每个人分配至少一个数据包，因此算法在进行任何枚举之前立即返回 -1。 

对称情况例如`2\n1 1`在枚举下也失败。 唯一可能的分裂是`{1}`和`{2}`，并且两者产生相同的总数。 该算法检查两个掩码并正确找到没有有效的子集，最终打印 -1。 

稍微大一点的类似对称的情况仍然可以正确运行，因为子集检查显式比较`2 * sum != total`。 任何完美平衡的分区都会被拒绝，而任何不平衡的分区一旦发现就会立即接受。
