[CF 175C - 几何马](https://codeforces.com/problemset/problem/175/C)

 **评分：** 1600
 **标签：** 贪婪、实现、排序、两个指针
 **求解时间：** 1m 1s
 **已验证：** 否

 ## 解决方案
 ## 问题理解

 我们有几种类型的几何图形。 类型`i`包含`k_i`相同的数字，并且该类型的每个数字都有基值`c_i`。 

当人物被摧毁时，获得的分数等于：`base value × current factor`该因素随着时间的推移而变化。 最初是`1`。 恰好之后`p1`数字已被破坏，因子变为`2`。 恰好之后`p2`人物被毁掉了，变成了`3`， 等等。 后`pt`数字已被破坏，因子变为`t + 1`。 

所有人物最终都必须被摧毁，但我们可以自由选择它们的摧毁顺序。 任务是最大化总分。 

关键的观察结果是，该因素仅取决于有多少人物已经被摧毁，而不取决于具体是哪些人物。 这意味着游戏会创建多个具有不同乘数的连续“槽”。 我们必须决定哪些人物占据哪些位置。 

这些限制是不寻常的。 最多有 100 种图形类型，但每种类型最多可包含`10^9`数字，并且因子变化位置可以大到`10^12`。 任何试图表示单个数字的算法都是不可能的。 数字总数可能超过`10^11`，因此我们必须批量处理计数。 

另一个重要的细节是成本可能为零。 只要有可能，这些数字自然应该分配给最差的乘数，因为将它们转移到更好的乘数会浪费宝贵的位置。 

一个常见的错误是按时间顺序思考过程并贪婪地逐个选择下一个数字。 考虑：```
2
1000000000 1
1 1000
1
1
```第一个被摧毁的人物使用因子`1`，所有其他使用因子`2`。 

最优策略首先销毁廉价的图形，并保存昂贵的图形作为因子`2`。 

分数：```
1*1 + 1000*2 = 2001
```首先摧毁昂贵的人物给出：```
1000*1 + 1*2 = 1002
```当因子边界超出数字总数时，会出现另一种微妙的情况。```
1
5 10
2
100 200
```只有五个人物存在，所以每个人物都会被因子破坏`1`。 

答案是：```
50
```一个粗心的实现，盲目地处理来自`p`可能会错误地假设因素`2`和`3`曾经达到过。 

另一种边缘情况是多种图形类型具有相同的成本。```
2
3 5
4 5
1
3
```由于每个数字都具有相同的值，因此任何排序都会产生相同的答案。 该算法仍然必须正确工作，而不依赖于严格的不等式。 

## 方法

 蛮力视图有助于理解结构。 

想象一下将每个图形扩展为一个单独的项目。 我们会确切地知道有多少个槽位属于因子`1`, 有多少属于因子`2`， 等等。 每个插槽都附有一个乘数。 

例如：```
Factors by destruction position:
1 1 1 2 2 3 3 3 ...
```每个数字都贡献：```
cost × assigned multiplier
```如果我们明确列出所有数字和所有槽位，那么问题将变成分配问题。 最佳解决方案很简单：按成本对数字进行排序，并将最大的成本分配给最大的乘数。 

这直接来自重排不等式。 每当较大的成本与较小的乘数配对，而较小的成本与较大的乘数配对时，交换它们会增加或保留分数。 

暴力方法会失败，因为数字的数量可能非常巨大。 单个类型可能包含`10^9`数字，因此扩大所有数字是不可能的。 

关键的观察结果是，只有 100 种图形类型，最多有 101 个不同的乘数级别。 我们永远不需要追踪个人数字。 

假设我们按成本升序对图形类型进行排序。 然后，在最优分配中，低成本人物占据乘数较小的最早的槽位，而高成本人物占据乘数较大的最晚的槽位。 

我们不是一次分配一个数字，而是按升序处理乘数间隔，并消耗已排序数字类型的计数。 每个区间包含一些具有相同因子的破坏位置。 我们使用目前最便宜的剩余数字来填补这些职位。 

这模拟了最佳排序分配，而无需扩展计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(F log F) | O(F log F) | O(F) | 太慢了|
 | 最佳 | O(n log n + n + t) | O(n log n + n + t) | O(n) | 已接受 |

 这里`F = Σ k_i`，可能超过`10^11`。 

## 算法演练

 ### 1. 按成本升序对所有图形类型进行排序

 每种类型都表示为`(cost, count)`。 

最佳安排将便宜的人物放入低因子槽中，将昂贵的人物放入高因子槽中。 

### 2. 将因子变化转换为间隔长度

 让：```
prev = 0
```对于每个边界`p_i`，创建一个区间：```
length = p_i - prev
factor = i
```然后更新：```
prev = p_i
```这些间隔描述了有多少破坏位置使用每个因素。 

### 3.从最小因子到最大因子处理区间

 维护一个指向当前最便宜的仍然有剩余图形的图形类型的指针。 

对于长度的区间`L`和因素`f`，重复从当前类型中获取数字，直到：```
L = 0
```或者那种类型已经用尽了。 

如果我们采取`x`成本数字`c`，我们添加：```
x * c * f
```到答案。 

然后减少该图形类型的间隔长度和剩余计数。 

### 4. 处理所有剩余的数字

 处理完每个边界间隔后，任何剩余的图形都会被破坏：```
t + 1
```消耗所有剩余计数并添加：```
count * cost * (t + 1)
```到答案。
