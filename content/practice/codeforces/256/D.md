 ## 解决方案
 ## 问题理解

 我们有 _n_ 个人坐在一张桌子旁，每个人要么总是诚实，要么总是撒谎。 诚实的人总是如实回答餐桌上有多少诚实的人。 说谎者可以选择 1 到 _n_ 之间的任何数字，除了真实数字。 小塞尔吉按顺序写下所有答案，发现其中有_k_个与总数不一致，因此这_k_个被认为是“明显撒谎”。 

输入给出数字 _n_ 和 _k_，我们被要求计算有多少种可能的长度为 _n_ 的答案序列可能导致恰好 _k_ 个人明显在撒谎。 答案必须对 777777777 取模。 

约束很小：_n_ 最多为 28，并且它是 2 的幂。这意味着我们可以使用 _n_ 内的指数算法，但不比 O(2^n * n) 更差，因为 2^28 ≈ 2.7×10^8，这对于 1 秒的时间限制来说是可行的。 所有序列的任何 O(n!) 或强力枚举都是遥不可及的。 该问题具有组合结构，因此动态规划可能是正确的工具。 

当 _k = n_ 时会出现微妙的边缘情况，这意味着所有人似乎都在撒谎。 如果只有一个人 (_n = 1_)，这是不可能的，因为孤独的人必须诚实才能得到真实计数 1。因此，输出应该为 0。任何忽略诚实计数和说谎计数的某些分布的不可能性的幼稚解决方案都会失败。 

## 方法

 暴力方法会尝试枚举所有 2^n 种将人标记为诚实或说谎的方法，然后分配所有有效的答案序列，对那些恰好有 _k_ 个人似乎撒谎的序列进行计数。 这是正确的，但效率低下：每个说谎者最多有 n-1 个答案选择，导致复杂度为 O(2^n * (n-1)^n)。 对于 n = 28，这是完全不可行的。 

关键的见解是将问题分为两部分：选择诚实人的数量 _h_，然后计算与 _k_ 个明显说谎者完全匹配的序列。 一旦 _h_ 固定下来，正好 _h_ 人必须回答正确的数字 _h_，剩下的 _n - h_ 人可能会回答错误。 对于每个说谎者，有 _n - 1_ 个选项可供选择（除 _h_ 之外的所有数字）。 该序列必须恰好包含 _k_ 个明显的说谎者，即 n - h = k 或 h = n - k。 因此，诚实人的数量由_k_决定，序列的计数减少为选择哪些人是诚实的，并为说谎者分配错误的数字。 

我们可以使用组合数学来计算计数。 选择哪 n - k 个人是诚实的：C(n, n - k)。 对于 k 个说谎者中的每一个，他们可以选择除正确计数 h 之外的任何数字，给出 (n-1)^k 个选项。 相乘得到总序列模 777777777。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * (n-1)^n) | O(2^n * (n-1)^n) | O(n) | 太慢了 |
 | 组合DP | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1.确定诚实人的数量。 由于恰好 _k_ 个人似乎在撒谎，因此有 n - k 个诚实的人。 称此为 _h = n - k_。 
2. 如果 h 为负数或零，而 k = n，则作为返回 0 的特殊情况处理。当所有人似乎都在撒谎但没有有效的诚实计数可以匹配时，就会发生这种情况。 
3. 计算选择诚实人的方法数量：C(n, h)。 这是二项式系数，代表大小为 h 的所有子集。 
4. 对于 k 个说谎者中的每一个，指定一个与真实计数 h 不同的答案。 每个说谎者都有 (n-1) 个选项，给出 (n-1)^k 个序列。 
5. 将选择诚实者的方法数量乘以分配给说谎者的任务数量。 对 777777777 取模以避免溢出。 
6. 输出结果。

为什么有效：不变的是诚实的人必须准确回答 h，而说谎者不能选择 h。 一旦通过 k 个明显说谎者的要求确定了 h，所有满足约束的序列都将通过组合计数捕获。 没有序列被遗漏或重复计算，因为诚实者的选择和骗子答案的独立选择完全参数化了解决方案空间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 777777777

def mod_pow(a, b, mod):
    result = 1
    a %= mod
    while b > 0:
        if b % 2:
            result = (result * a) % mod
        a = (a * a) % mod
        b //= 2
    return result

def comb(n, k):
    if k < 0 or k > n:
        return 0
    res = 1
    for i in range(1, k+1):
        res = res * (n - i + 1) // i
    return res

def main():
    n, k = map(int, input().split())
    h = n - k
    if h < 0 or h > n:
        print(0)
        return
    ways_honest = comb(n, h)
    ways_liars = mod_pow(n - 1, k, MOD)
    print((ways_honest * ways_liars) % MOD)

if __name__ == "__main__":
    main()
```该解决方案首先使用整数算术计算二项式系数以避免浮点错误。 模幂可以有效地处理 n-1 的大幂。 特殊情况 h < 0 或 h > n 对于防止不可能的计数是必要的。 相乘并取模得到最终结果。

 ## 边缘情况

 如果 n = 1、k = 1、h = 0、ways_liars = 0，则输出为 0。算法正确地识别出不存在有效的答案序列。 如果k = 0，h = n，则只有一种诚实配置，说谎者没有影响力。 如果 k = n，h = 0，则所有都必须是骗子，并且ways_liars = (n-1)^n，给出有效的序列计数。 每个边缘情况都由二项式和模幂逻辑处理。
