 ## 解决方案
 ## 问题理解

 我们被要求处理一个整数数组，其中每个整数都适合`k`位。 对于数组中的每个位置，我们必须找到包含该位置的所有子数组中“按位或非”的最大值。 两个数字的按位或非是它们的按位或的按位补。 对于子数组，我们从左到右累加地计算或数。 

输入给出了多个测试用例，每个测试用例都有`n`整数和位数`k`。 输出是一个长度的数组`n`其中每个元素是包含该索引的所有子数组中的最大元素。 

限制因素很大。`n`可以达到`10^5`并且可能最多有`10^4`测试用例，尽管所有测试用例的元素总数仅限于`10^5`。 考虑所有子数组的简单方法将大致执行`O(n^2)`每个测试用例的操作，这对于`n=10^5`。 我们需要一个接近线性的解决方案`n`。 

长度为 1 的数组会出现边缘情况。这里，唯一元素的最大值 或 是元素本身。 当所有数字都为`2^k - 1`，即所有位均为 1。在这种情况下，两个或多个数字中的任何一个“或”都变为 0，因此包含给定索引的最大值“或”可能来自该元素本身，而不是任何更大的子数组。 粗心的实现可能会假设较大的子数组总是会增加nor，这是不正确的。 

## 方法

 暴力解决方案迭代包含索引的所有子数组`i`。 对于每个子数组，它计算累积或并更新最大值。 这是可行的，因为 Nor 在问题定义的从左到右的意义上是关联的。 然而，包含单个索引的子数组的数量大致为`O(n)`并天真地计算他们的也不是`O(n)`以及，导致`O(n^2)`每个测试用例。 为了`n=10^5`，这是不可行的。 

关键的观察是按位或非是按位或的补集。 如果我们表示`nor(x, y) = ~(x | y)`为了`k`位，当我们扩展子数组时，我们可以考虑“哪些位可以保持为 1”。 对于包含的子数组`a[i]`，我们要尽可能向左和向右扩展，直到其中任何一位为 1`a[i]`被另一个元素中的 1 覆盖。 换句话说，当且仅当子数组中的所有元素的该位均为 0 时，结果中的每一位都可以保持为 1。 

这将问题简化为一种“该位中带有 1 的最近元素”问题。 对于每个元素，我们可以为每个位预先计算距离该位设置的左侧和右侧最近的索引。 使用这些，我们可以确定包含的最大子数组`i`其中每个位都保持未设置状态。 将所有位的这些结果组合起来给出该索引的最大或非。 

这个想法导致了线性扫描`O(n*k)`复杂度，其中`k`最多为 17，使其可行。 该解决方案维护每个位的最后看到的位置的数组，并使用位掩码操作更新最大值或。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 * k) | O(n^2 * k) | O(1) | O(1) | 太慢了|
 | 最佳| O(n * k) | O(k) | 已接受 |

 ## 算法演练

 1.初始化一个数组`ans`尺寸的`n`存储每个索引的最大值 或 。 初始化两个辅助数组`last_left`和`last_right`尺寸的`k`，分别从左和右扫描时，将最后看到的索引存储为每个位 1。 
2. 从左到右扫描。 对于每个索引`i`，对于每个位位置`b`从 0 到`k-1`， 如果`a[i]`有位`b`设置、更新`last_left[b] = i`。 将重置位的最靠近左侧的索引`b`对于结束于的子数组`i`是`last_left[b]`。 
3. 同样，从右向左扫描。 对于每个索引`i`和位`b`， 如果`a[i]`有位`b`设置、更新`last_right[b] = i`。 右边最近的索引将重置位`b`对于从以下位置开始的子数组`i`是`last_right[b]`。 
4. 对于每个索引`i`, 初始化`res = 0`。 对于每一位`b`，检查距离`i`到最近的左或右索引，其中位`b`已设置。 如果`i`是在位的边界内`b`可以保留 0，包括该位`res`通过设置位`b`至 1。 
5、输出`res`对于每个索引作为最大也不包含该索引。 

这样做的原因是，当累积运算中任何位从 0 翻转到 1 时，按位或非严格递减。 通过跟踪位为 1 的最近位置，我们可以确定每个位可以保持为 1 的最大子数组长度，并将它们组合起来以有效地计算最大 Nor 值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        last_left = [-1] * k
        last_right = [n] * k
        left_bound = [0] * n
        right_bound = [n-1] * n
        
        for i in range(n):
            left_bound[i] = 0
            for b in range(k):
                if a[i] & (1 << b):
                    last_left[b] = i
                left_bound[i] = max(left_bound[i], last_left[b]+1)
        
        last_right = [n] * k
        for i in range(n-1, -1, -1):
            right_bound[i] = n-1
            for b in range(k):
                if a[i] & (1 << b):
                    last_right[b] = i
                right_bound[i] = min(right_bound[i], last_right[b]-1)
        
        ans = []
        for i in range(n):
            res = 0
            for b in range(k):
                if left_bound[i] <= i <= right_bound[i]:
                    res |= (1 << b)
            ans.append(res)
        
        print(*ans)

solve()
```该解决方案首先计算每个索引的边界，其中每个位可以保持未设置状态，然后将它们组合起来以确定哪些位可以在最大nor中为1。 使用`last_left`和`last_right`数组确保我们不会重复重新计算距离。 最后的循环通过检查每个位的子数组边界来组装每个索引的结果。
