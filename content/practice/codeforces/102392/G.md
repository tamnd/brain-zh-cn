 ## 解决方案
 ## 问题理解

 对于固定深度坐标 x，第一个投影告诉我们哪些 y 位置必须包含至少一个立方体，而第二个投影告诉我们哪些 z 位置必须包含至少一个立方体。 (x,y,z) 处的立方体同时创建投影单元 (x,y) 和 (x,z)。 

设 Y x 为 y 坐标集，其中第一个投影包含`1`在 x 行中，并令 Z x ​为第二个投影的相应 z 坐标集。 当 y ∈ Y x ​且 z ∈ Z x ​时，深度为 x 的立方体是有用的。 因此，一旦两个集合都已知，Y x ​ ×Z x ​中的每一对都是一个合法的立方体。 

这就将三维问题完全分离成n个独立的二维问题。 对于每个 x，我们只需要将 Y x ​的每个顶点与 Z x ​的至少一个顶点连接起来。 

第一个可行性条件立即出现。 如果 Y x ​非空但 Z x ​为空，则永远无法生成所需的第一投影单元。 两边颠倒也是同样的道理。 如果两个集合都是空的，则该切片不包含任何立方体并且是有效的。 

维度最多为 100，因此最多有 100⋅100⋅100=10 6 个可能的立方体。 这足够小，足以一次枚举所有立方体，但对于子集上的任何指数搜索来说太大了。 所需的解决方案在可能的立方体数量上应该基本上是线性的，在优化实现中这完全在 1 秒限制内。 

一个微妙的情况是一个完全空的切片。 例如，```
1 2 2
00
00
```根本没有必要的阴影。 正确的输出是```
0
0
```假设每个切片至少需要一个多维数据集的粗心实现可能会错误地拒绝它。 

另一个重要的情况是切片不一致：```
1 2 1
10
0
```第一个投影需要 y=0 的立方体，但第二个投影根本不需要立方体，因为它的唯一条目为零。 正确的输出是```
-1
```尝试用每一个元素构建一个立方体`1`在第一个投影中会默默地创建一个不需要的`1`在第二个投影中。 

字典顺序的要求也很重要。 考虑```
1 3 2
111
11
```存在三个必需的 y 位置和两个必需的 z 位置。 三个立方体是必要且充分的。 按字典顺序最小的最小解是```
3
0 0 0
0 1 0
0 2 1
```在不考虑字典顺序的情况下对坐标进行对角配对的构造可以产生具有相同数量的立方体但具有更大的坐标序列的有效解决方案。 

## 方法

 蛮力方法是考虑 nmh 可能立方体的每个子集，将该子集投影到两个矩阵上，并保留具有最大大小的有效子集和具有最小大小的有效子集。 这是正确的，因为每种可能的物理排列都由立方体的一个子集表示。 然而，有 2 nmh 子集。 在最大维度下，这将成为 2 1,000,000 个候选者，甚至检查一个候选者也需要多达 10 6 次立方体操作。 这是完全不可行的。 

有用的观察结果是具有不同 x 坐标的立方体永远不会相互作用。 对于一个固定的 x，允许的立方体在 Y x ​和 Z x ​之间形成完整的二分图。 每个所需的 y 坐标和每个所需的 z 坐标之间都有一条边。 

为了获得最大的解决方案，每个允许的边缘都可以存在。 添加任何已经需要两个投影单元的立方体不会使投影无效，因此最大解在切片 x 中恰好包含 ∣Y x ​ ∣∣Z x ​ ∣ 立方体。 

对于最小解决方案，我们需要接触这个完整二分图的每个顶点的边最少。 如果两侧包含 a 和 b 顶点，则每个立方体每侧最多接触一个顶点，因此至少需要 max(a,b) 个立方体。 许多也足够了：将一条边分配给较大一侧的每个顶点，并根据需要重用较小一侧的顶点。 因此，切片 x 的最小值为 max(∣Y x ​ ∣,∣Z x ​ ∣)。 

剩下的问题是按字典顺序选择这些边。 假设a≥b。 每个 y 必须恰好有一条边，因为需要一条边并且必须出现所有不同的 y 坐标。 由于输出按 (x,y,z) 排序，因此 y 坐标被迫显示为 y 0 ​ ,y 1 ​ ,…,y a−1 ​。 为了使 z 坐标序列按字典顺序最小，同时仍然使用每个 z，我们尽可能多次使用最小的 z，然后移至下一个。 因此，序列是 z 0 ​ 重复 a−b+1 次，然后是 z 1 ​ ,z 2 ​ ,…,z b−1 ​。 b>a 的情况是对称的。 

蛮力方法之所以有效，是因为它明确地考虑了每种排列，但会失败，因为排列的数量是指数级的。 观察到每个切片都是一个完整的二部图，从而将问题简化为简单的计数和直接的词典结构。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2 nmh ⋅ nmh) | O(2 nmh ⋅ nmh) | O(nmh) | 太慢了 |
 | 最佳| O(nmh) | O(n(m+h)) | O(n(m+h)) | 已接受 |

 ## 算法演练

 1. 读取两个投影矩阵，对于每个 x，存储包含以下内容的 y 坐标和 z 坐标：`1`。 

这两个列表完整地描述了该切片中可能发生的所有情况。 不需要存储三维体积本身。 
2. 对于每个 x，检查 Y x ​和 Z x ​中是否正好有一个为空。 

如果发生这种情况，预测就会相互矛盾。 产生所需 y 位置的立方体必然会产生一些 z 位置，反之亦然。 如果任何 x 检查失败，则打印`-1`。 
3. 对于最大解，迭代每个 y∈Y x ​和每个 z∈Z x ​，并输出立方体 (x,y,z)。 

每个这样的对都是允许的，并且将它们全部相加仍然会产生完全相同的投影，因为两个端点已经被标记为`1`。 由于包含了所有可能的合法立方体，因此立方体的数量是最大的。 
4. 对于最小解，令 a=∣Y x ​ ∣，b=∣Z x ​ ∣，且 k=max(a,b)。 

至少需要 k 个立方体，因为每个立方体最多可以引入一个新的 y 坐标和最多一个新的 z 坐标。 存在具有 k 个立方体的结构，因此 k 是最优的。 
5. 通过将 i 从 k 迭代到 1 来生成最小解。使用

 y[max(0,a−i)]

 和

 z[max(0,b−i)]。 

当一侧较大时，其坐标会在整个列表中前进，而较小一侧会重复其最小坐标，直到覆盖较大一侧上的每个顶点。 由于列表按升序存储，因此生成的三元组已经按字典顺序排序。 
6.按升序处理x，并按升序处理每个存储的投影坐标。 

这使得完整的输出按字典顺序排序，这是语句所要求的。 由于不同的 x 切片是独立的，因此使每个切片按字典顺序最小也会使串联解决方案按字典顺序最小。 

### 为什么它有效

 对于每个固定的 x，所需的投影单元定义了 Y x ​和 Z x ​之间的完整二部图。 有效的立方体集正是接触每个顶点的边集。 如果一侧为空而另一侧不是，则不能存在这样的边集。 否则，所有 ab 边都是合法的，给出最大解。 

对于最小解决方案，至少需要 max(a,b) 条边，因为一条边最多可以覆盖每一侧的一个顶点。 该结构恰好使用了那么多边并覆盖了每个顶点，因此它是最佳的。 在所有此类解中，如果 a≥b，则每个 y 必须恰好出现一次。 因此，它们的顺序是固定的。 在每个位置选择尽可能小的 z，这样做仍然留下足够的位置来引入所有剩余的 z 坐标。 这给出了尽可能小的 z 序列，证明了词典编排最优性。 当 b>a 时，对称论证适用。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, h = map(int, input().split())

    ys = [[] for _ in range(n)]
    zs = [[] for _ in range(n)]

    for x in range(n):
        row = input().strip()
        for y, ch in enumerate(row):
            if ch == '1':
                ys[x].append(y)

    for x in range(n):
        row = input().strip()
        for z, ch in enumerate(row):
            if ch == '1':
                zs[x].append(z)

    for x in range(n):
        if bool(ys[x]) != bool(zs[x]):
            print(-1)
            return

    out = []

    # Maximum solution.
    kmax = 0
    for x in range(n):
        kmax += len(ys[x]) * len(zs[x])

    out.append(str(kmax))

    for x in range(n):
        for y in ys[x]:
            for z in zs[x]:
                out.append(f"{x} {y} {z}")

    # Minimum solution.
    kmin = 0
    for x in range(n):
        kmin += max(len(ys[x]), len(zs[x]))

    out.append(str(kmin))

    for x in range(n):
        a = len(ys[x])
        b = len(zs[x])
        k = max(a, b)

        for i in range(k, 0, -1):
            y = ys[x][max(0, a - i)]
            z = zs[x][max(0, b - i)]
            out.append(f"{x} {y} {z}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```输入存储为每个 x 两个列表。 一个`1`在第一个投影中成为一个条目`ys[x]`，同时一个`1`在第二个成为一个条目`zs[x]`。 构造这些列表后，原始矩阵不需要保留在内存中。 

可行性检查使用比较两个列表是否为空`bool`。 这两个布尔值的相等恰好是两个投影集都为空或都非空的条件。 

最大计数使用两个列表大小的乘积。 然后，嵌套循环以增加 y 的方式枚举每一对，然后增加 z。 这会产生按字典顺序排列的三元组，因为 x 已经从小到大进行了处理。 

对于最小构造，表达式`max(0, a - i)`是关键的边界操作。 当a小于b时，前几次迭代中索引保持为零，因此重复最小的y。 一旦较大的索引到达较小列表的末尾，所有较小侧的坐标都已被使用。 相同的表达式无需单独的分支即可处理相反的不平衡。 

Python 整数具有任意精度，因此最大计数（最多 10 6）不需要特殊的整数处理。 输出累积在一个列表中并写入一次，避免了一百万个单独的开销`print`来电。

 ## 边缘情况

 ### 一个完全空的切片

 对于```
1 2 2
00
00
```我们有 Y 0 ​ =∅ 和 Z 0 ​ =∅。 可行性检查接受该切片，因为两侧都是空的。 它对最大值的贡献是 0⋅0=0，对最小值的贡献是 max(0,0)=0。 输出是```
0
0
```没有引入人造立方体，这是必要的，因为任何立方体都会产生不需要的投影单元。

 对于```

10
0
```我们有 Y 0 ​ ={0} 和 Z 0 ​ =∅。 布尔空值不同，因此算法打印`-1`在建造任何东西之前。 这可以防止发明会改变第二个投影的 z 坐标的常见错误。

 对于```

11
```我们有 Y 0 ​ =(0,1,2) 和 Z 0 ​ =(0,1)。 下限表示至少需要三个立方体，因为存在三个不同的 y 坐标。 建设用途```

 对于```

11

0 0 1
0 1 2
```这里重复 y=0，因为 y 边较小。 z 坐标按递增顺序引入，给出字典顺序上最小的可能序列。 

### 最大输出大小

 当n=m=h=100且每个投影单元为`1`，10 6 个可能的立方体中的每一个都属于最大解。 该算法不会尝试存储三维布尔结构或搜索配置。 它只是枚举了数百万个合法对。 最小解仅包含 100⋅100=10 4 个立方体，因为 100 个切片中的每一片都需要 max(100,100)=100 个立方体。
