 ## 解决方案
 ## 问题理解

 我们有一个奇数 (n) 个顶点的完整无向图。 它的每一条 (\frac{n(n-1)}2) 边都有一个正权重。 

我们必须将所有边划分为循环数组。 一个数组中的连续边必须共享一个顶点，并且每条边周围的两个过渡必须使用不同的端点，因此该数组描述了穿过图形的闭合路径。 循环数组允许重新访问顶点。 重要的是它的边是循环排列的，并且每条边通过其每个端点与一条边相邻。 

对于两个连续的边 (e_i,e_{i+1})，贡献是它们的权重中较大的一个。 一个循环阵列的价格是整个阵列周围这些贡献的总和。 所需的输出是将每个图边划分为此类数组的最小可能总价格。 

(n) 的奇怪之处是问题变得简单的结构原因。 每个顶点的度数 (n-1) 是偶数。 由于进入循环数组中的顶点的边必须与离开该顶点的一条边恰好配对，因此与顶点相关的所有边都可以分成对。 

最多有 (999) 个顶点，但图很稠密。 对于 (n=999)，它包含

 [
 \frac{999\cdot998}{2}=498501
 ]

 边缘。 这立即排除了枚举循环、循环分解或任意配对的算法。 即使所有边的单个循环排序也有大约 (498500!/2) 的可能性。 预期的解决方案需要利用目标可以由顶点分隔的事实。 

权重可以大到 (10^9)，因此答案不适合 32 位有符号整数。 在最大的全平等实例中，答案是（498501），并且对于较大的个体权重，答案可以是（10^{15}）的量级。 Python 整数会自动处理这个问题，而 C++ 实现则需要`long long`。 

一种小边缘情况是 (n=3)。 每个顶点恰好有两个入射边，因此每个顶点处只有一对可能的边。 例如，```
3
1 2 1
2 3 1
1 3 1
```有答案（3）。 假设每个顶点至少有四个关联边或执行不正确的配对循环的解决方案可能会错过这种情况。 

另一个重要的情况是等权。 为了```
3
1 2 5
2 3 5
1 3 5
```答案是（15）。 每个邻接的成本为 (5)，并且三角形有 3 个邻接。 尝试按权重区分边缘的粗心实现可能会意外丢弃等权重边缘或仅计算其中之一。 

第三种情况涉及大重量。 为了```
3
1 2 1000000000
2 3 1000000000
1 3 1000000000
```答案是（3000000000）。 使用 32 位整数会溢出。 该算法本身只执行加法，因此实现应该简单地使用能够保存最终总和的整数类型。 

## 方法

 一种直接的方法是尝试枚举可能的周期分割，计算每个周期的价格，并保持最小值。 这是正确的，因为每个有效的分割最终都会被考虑。 问题在于可能性的数量。 如果 (m=\frac{n(n-1)}2)，那么即使只考虑包含所有 (m) 条边的一个循环，也会在无向设置中给出 ((m-1)!/2) 个不同的循环排序。 对于（n=999），（m=498501），所以这远远超出了任何可执行的范围。 枚举多个循环或尝试顶点处的所有配对甚至更糟糕。 

有用的观察是价格可以局部分配给顶点。 

考虑一条边 (e=(u,v))。 在其循环数组内，它与通过 (u) 的正好一个相邻边进行比较，并且与通过 (v) 的正好一个相邻边进行比较。 因此，在顶点 (u) 处，入射边被分成对，每对贡献其两个权重中的最大值。 整个周期分割中的每个价格贡献都恰好属于一个这样的顶点。 

因此，全局问题变成了独立局部问题的集合：在每个顶点，尽可能便宜地对其 (n-1) 个关联边进行配对。 

假设一个顶点的事件权重从大到小排序为

 [
 w_1\ge w_2\ge w_3\ge w_4\ge\cdots\ge w_{n-2}\ge w_{n-1}。 
]

 有 (\frac{n-1}{2}) 对。 为了最小化成对最大值的总和，应该将两个最大值配对，然后是下两个最大的值，依此类推：

 [
 (w_1,w_2),(w_3,w_4),\l点
 ]

 因此贡献是

 [
 w_1+w_3+w_5+\cdots+w_{n-2}。 
]

 为什么这种配对是最佳的？ 最大元素必须是某个对中的最大值，因此每个配对至少支付 (w_1)。 将其与第二大值配对后，剩余问题在其余值上具有相同的形式。 同样，将大值与小值配对会浪费该小值，因为大值已经决定了配对的成本。 从最大到最小连续对值进行配对可以最大限度地减少成为对最大值的大值的数量。 

剩下的问题是在每个顶点独立选择这些最优对是否真的可以产生有效的循环数组。 可以。 将每个选定的对视为一个过渡，告诉我们在该顶点哪一条边跟随哪一条边。 从任何未使用的边开始，沿着配对边的当前端点进行操作。 每次我们到达一个顶点时，恰好有一对被部分使用，因此有一条唯一的边来完成该对。 继续这个过程最终会回到起点，因为边的数量是有限的，并且每条边都有两个配对的端点。 生成的闭合轨迹是一个有效的循环数组。 完成后，从另一个未使用的边缘重新开始。 

由此产生的结构实现了每个局部最优对，因此局部最小值之和不仅仅是下界。 这是可以实现的，并且正是全局最优值。 这是官方社论使用的中心缩减。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 至少 (O(m!))，其中 (m=\frac{n(n-1)}2) | 指数/阶乘搜索状态 | 太慢了|
 | 最佳 | (O(n^2\log n)) | (O(n^2)) | 已接受 |

 ## 算法演练

1. 读取所有 (m=\frac{n(n-1)}2) 条边并将每条边存储为其两个端点及其权重。 该图是完整的，因此每个顶点最终将准确接收 (n-1) 个入射边。 
2. 对于每个顶点，收集所有关联边的权重。 由于(n)是奇数，(n-1)是偶数，因此这些权重可以分成对。 
3. 按降序对事件权重进行排序。 对位置 (0) 和 (1)、位置 (2) 和 (3)、位置 (4) 和 (5) 等。 每对的最大值就是该对的第一个元素。 
4. 将位置 (0,2,4,\ldots) 处的权重添加到答案中。 这会独立于所有其他顶点计算该顶点的最小可能贡献。 
5. 对每个顶点重复此操作。 每个循环数组中两个连续边的每个邻接都恰好出现在一个顶点上，因此对这些局部贡献求和就将全局价格的每一项都计算一次。 

关键的不变量是每个有效的循环分割都会在每个顶点处产生入射边的配对，而我们的排序配对给出了该顶点的最小可能成本。 独立选择的配对可以作为闭合轨迹进行跟踪，因此它们对应于有效的循环分割。 因此，没有任何解决方案的成本可以低于我们的总和，并且存在精确实现该总和的解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    edges = n * (n - 1) // 2

    incident = [[] for _ in range(n)]

    for _ in range(edges):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        incident[u].append(w)
        incident[v].append(w)

    ans = 0

    for v in range(n):
        incident[v].sort(reverse=True)
        ans += sum(incident[v][i] for i in range(0, n - 1, 2))

    print(ans)

if __name__ == "__main__":
    solve()
```第一个循环准确读取 (\frac{n(n-1)}2) 条边，这是完整图中的边数。 每个权重都附加到两个端点的列表中，因为该边参与两个顶点的本地配对。 

对于每个顶点，列表恰好有 (n-1) 个元素。 范围`range(0, n - 1, 2)`访问索引 (0,2,4,\ldots,n-3)。 每个访问过的元素都是一对最佳元素中较大的元素，因此将这些值相加即可得出该顶点的最小贡献。 

每个顶点的排序都是独立完成的。 由于每个顶点最多有 (998) 个入射边，因此这很容易足够快。 输入本身已经包含 (\Theta(n^2)) 条边，因此二次尺度处理是不可避免的。 

不需要显式的循环构造。 证明表明，最佳局部配对可以同时实现为循环数组，而答案只要求它们的总价格。 避免构造可以节省时间和实现复杂性。 

当答案大于 (2^{31}-1) 时，Python 的整数类型还可以避免溢出。

 ### 示例 1

 该图是一个三角形，每条边都有权重 (1)。 

| 顶点| 排序事件权重 | 最佳配对 | 贡献|
 | ---| ---| ---| ---|
 | 1 | (1,1) | ((1,1)) | ((1,1)) | 1 |

该迹线演示了 (n=3) 边界情况。 每个顶点恰好有一对，并且三个局部贡献的总和正是三角形的价格。 

### 示例 2

 对于十条边，入射权重变为：

 | 顶点| 排序事件权重 | 最大对 | 贡献|

 | 1 | (4,4,4,3) | (4,4) | 8 |

 | 4 | (4,3,2,2) | (4,2) | 6 |
 | 5 | (4,4,4,2) | (4,4) | 8 |

 最终的答案是

 [

]

 样本的最佳分割具有价格 (12) 和 (23)，给出相同的总数 (35)。 本地计算无需显式发现这两个周期即可达到该值。 

该迹线展示了中心不变量：两个连续边之间的每个转换都被计入它们的共享顶点，因此在所有五个顶点处添加最优对最大值就可以算出整个循环分割价格。

 ## 边缘情况

 对于 (n=3)，每个顶点的度数为 (2)。 考虑```
3
1 2 1
2 3 2
1 3 3
```在顶点 (1) 处，权重为 (3,1)，贡献 (3)。 在顶点 (2) 处，它们是 (2,1)，贡献 (2)。 在顶点 (3) 处，它们是 (3,2)，贡献 (3)。 答案是（8）。 该算法自然地处理这个问题，因为每个顶点唯一处理的索引是 (0)。 

对于相等的权重，请考虑五个顶点的完整图，每条边都等于 (7)。 每个顶点有四个入射边，因此它形成两对，每对都有贡献（7）。 每个顶点贡献 (14)，给出 (5\cdot14=70)。 每对内部的边的身份并不重要，因为所有权重都是相等的。 

对于最大权重边界，```
3
1 2 1000000000
2 3 1000000000
1 3 1000000000
```三个顶点中的每一个贡献 (10^9)，所以答案是 (3\cdot10^9=3000000000)。 Python中不存在溢出，并且除了最终的整数和之外，计算不依赖于权重的大小。 

对于最大的图 (n=999)，每个顶点都有 (998) 个入射边。 如果每个权重均为 (1)，则 (499) 个局部对中的每一对都贡献 (1)，因此一个顶点贡献 (499)。 在 (999) 个顶点上，答案是 (999\cdot499=498501)，这也正是图边的数量。 该实现处理所有（498501）个输入边并执行所需的局部排序，而不尝试构造或枚举大量可能的循环分裂。
