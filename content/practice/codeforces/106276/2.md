 ## 解决方案
 ## 问题理解

 该问题描述了一个带有两个秤盘和三个已知重量的天平。 重物有质量`a`,`b`， 和`c`， 和`a < b < c`。 质量梨`p`已经被成功测量，所以我们知道这三个重量的某种排列可以平衡它。 

你的任务就是输出一种这样的安排。 梨必须放在左盘上。 有些权重也可能放在左侧，有些可能放在右侧，有些可能未使用。 两个盘上的总质量必须相等。 

如果与左边的梨放在一起的重物有总质量`x`，右边的权重有总质量`y`，条件是：`p + x = y`输入值可以大到`10^9`，因此任何依赖于较小数值的方法都是不合适的。 然而，权重的数量固定为三个。 这完全改变了问题：可能的放置数量很小，并且不会随着输入大小的增加而增加。 时间复杂度恒定的解决方案就足够了。 

主要的边缘情况来自于忘记了重量可以不使用并且可以放置在秤的两侧。 

例如，与：```
1
3
10
9
```一个有效的答案是将梨和重量`1`左边和重量`10`在右侧。 等式是`9 + 1 = 10`。 一个粗心的解决方案，只搜索`p`因为一个重量减去另一个重量会错过这一点，因为梨的一侧也需要较小的重量。 

另一种情况是：```
2
5
8
1
```可以通过将梨放在左侧并称重来测量梨的大小`2`和`5`在右侧。 等式是`1 + 2 + 5 = 8`。 只考虑在每一侧使用一个重量的解决方案将会失败。 

固定数量的对象是关键的观察结果。 大的质量限制不会使搜索空间变大。 

## 方法

 直接的强力方法是尝试每种重量的每种可能的放置方式。 每个砝码都有三种选择：左盘、右盘或未使用。 三个权重只有`3^3 = 27`可能的安排。 对于每种排列，我们可以计算两侧的总质量并检查天平是否平衡。 

此方法是正确的，因为所有可能的合法位置都包含在搜索中。 只有当权重数量增加时，它才变得不切实际，因为状态数量会变得`3^n`。 对于当前的问题，最坏的情况只有 27 次检查。 

重要的观察是，问题不在于在巨大的数字中找到巧妙的算术分解。 值很大，但选择的数量却非常少。 对选择的详尽搜索实际上是恒定时间。 

蛮力之所以有效，是因为可能的配置集是完整且微小的。 同样的想法不适用于数百个重量，但仅使用三个重量，这是最简单、最安全的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(27) = O(1) | O(27) = O(1) | O(1) | O(1) | 已接受 |
 | 最佳| O(27) = O(1) | O(27) = O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取三个重量和梨的质量。 我们将权重存储在数组中，因为算法会对称地处理它们。 
2. 枚举三个权重的每个分配。 对于每个重量，选择三种状态之一：左平移、右平移或未使用。 这涵盖了比例规则允许的所有可能的安排。 
3. 对于当前作业，计算没有梨的左盘的质量和右盘的质量。 平衡条件是右侧必须等于梨加上左侧。 
4. 当分配满足方程时，输出梨以及分配给左侧的权重，并输出分配给右侧的权重。 该问题保证至少存在一个这样的分配，因此第一个有效的分配就足够了。 

为什么有效：检查每个重量的每个可能的放置位置。 梨的原始称重所使用的有效排列是这 27 种状态之一，因此枚举必须达到至少一种等式成立的状态。 一旦找到这样的状态，所产生的放置就直接满足正确称重的定义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a = int(input())
    b = int(input())
    c = int(input())
    p = int(input())

    weights = [a, b, c]

    for mask in range(27):
        x = mask
        left = []
        right = []

        for w in weights:
            state = x % 3
            x //= 3

            if state == 0:
                left.append(w)
            elif state == 1:
                right.append(w)

        if p + sum(left) == sum(right):
            print(*([p] + left))
            print(*right)
            return

solve()
```该代码使用的数字来自`0`到`26`作为展示位置的紧凑表示。 以三为基数的每个数字都描述了一个重量的状态。 一个数字`0`表示重量放在梨上，数字为`1`表示它被放置在对面的平底锅上，并且数字`2`意味着它没有被使用。 

转换循环重复进行`x % 3`提取当前权重的选择，然后除以三以移动到下一个权重。 由于正好有三个权重，因此涵盖了所有可能的三元组合。 

条件`p + sum(left) == sum(right)`直接符合平衡方程。 该程序首先在左侧打印梨，因为输出格式需要它。 该语句允许使用空列表，因此对于平底锅仅包含梨或仅包含重量的情况，不需要进行特殊处理。 

Python 中不存在溢出问题，因为整数具有任意精度。 较小的枚举大小也使得输入速度无关紧要，但所需的`sys.stdin.readline`接口被使用。

 ## 边缘情况

 对于这个案例：```
1
3
10
9
```枚举达到权重的状态`1`是在梨的一边和重量`10`是在另一边。 支票变成`9 + 1 == 10`，因此算法会打印该排列。 一种只寻找的方法`p = y - x`和`x = 0`会失败，因为左侧需要额外的重量。 

对于这个案例：```
2
5
8
1
```有效的排列需要两个重物一起对抗一个较大的重物。 搜索最终分配权重`2`和`5`到左侧和重量`8`到右侧。 等式变为`1 + 2 + 5 = 8`，所以结果被接受。 

对于非常大的值，例如：```
999999999
1000000000
1000000001
1
```该算法执行与小数完全相同的 27 次检查。 算术值不会影响搜索大小，这就是解决方案保持恒定时间的原因。
