 ## 解决方案
 ## 问题理解

 我们有一棵无向树$n$顶点。 对于每一个根的选择$r$，树就生根了。 对于每一个$k$- 元素顶点集$S$，我们查看包含所有顶点的最小有根子树$S$。 

有根子树不仅仅是任何连接的子图。 如果一个顶点属于它，那么该顶点的每个后代也必须属于它。 由于该定义，一旦根固定，最小有根子树包含$S$是唯一确定的。 

对于每对$(r,S)$， 让$f(r,S)$是该最小有根子树中的顶点数。 我们必须将这个值加到所有的根和所有的值上$k$-元素子集。 

该树最多包含$2 \cdot 10^5$顶点。 仅子集的数量就已经是天文数字了，因此任何迭代子集的方法都是不可能的。 甚至$O(n^2)$对于这个限制来说太大了。 目标基本上是线性的或$O(n \log n)$。 

棘手的部分是根的变化。 直接尝试单独计算每个根的答案已经需要$O(n^2)$甚至在处理子集之前就开始工作。 

### 不明显的边缘情况

 考虑$k=1$。```
3 1
1 2
1 3
```对于单个选定的顶点$v$，最小有根子树就是$v$在选择的生根中。 仅考虑 Steiner 树或 LCA 的解决方案将错过有根子树条件并产生错误的计数。 

考虑$k=n$。```
3 3
1 2
1 3
```唯一的子集是整个顶点集。 对于每个根，最小有根子树是整棵树，所以答案是$n^2$。 任何涉及二项式系数的公式必须正确处理诸如$\binom{x}{k}$什么时候$x<k$，其贡献应为零。 

考虑一条链条。```
4 2
1 2
2 3
3 4
```许多派生公式取决于子树大小和子树的补集。 由于边的一侧可能仅包含单个顶点，因此补码大小中的相差一错误经常出现在这里。 

## 方法

 暴力解决方案将枚举每个根$r$， 每一个$k$-子集$S$，构造最小有根子树，并添加其大小。 即使我们有一个$O(1)$一对的公式$(r,S)$， 有$$n \cdot \binom{n}{k}$$成双成对，这是完全不可能的。 

关键的观察是我们应该停止单独思考根。 

修复一个子集$S$。 而不是计算$f(r,S)$分别对于每个根，令$$F(S)=\sum_{r=1}^{n} f(r,S).$$如果我们能够表达$F(S)$利用树的结构特性，我们只需要计算有多少个子集产生每个结构配置。 

对于固定的$S$，定义一个顶点为**关键**，如果它属于$S$，或者如果它的至少两个子子树包含来自$S$。 这些正是连接所有选定顶点所需的分支点。 

每个非关键顶点都属于附加到关键骨架的连接组件。 如果这样的组件有尺寸$sz$，然后对于该组件内的每个根，$$f(r,S)=n-sz.$$对所有根求和得出一个非常简单的公式：$$F(S)=n^2-\sum sz_i^2,$$哪里的$sz_i$是所有非关键组件的尺寸。 这一观察结果将问题转化为计算组件贡献。 

下一个见解是，每个可能的组件只是某些树边缘的一侧。 只有$2(n-1)$这样的连接区域。 我们不是迭代子集，而是计算有多少子集使边的特定一侧成为这些组件之一。 

该计数可以完全通过子树大小和二项式系数来表达。 

生成的算法执行单个 DFS 并评估每个顶点的恒定数量的组合公式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O\!\left(n\binom{n}{k}\right)$或者更糟| 巨大| 太慢了|
 | 最佳|$O(n)$阶乘预计算后 |$O(n)$| 已接受 |

 ## 算法演练

 我们在顶点给树生根一次$1$。 

1. 预计算阶乘和逆阶乘模$10^9+7$这样每个二项式系数都可以计算为$O(1)$。 
2.运行DFS来计算：$$SZ[u]$$这是子树的大小$u$， 和$$p[u]=\sum_{v \text{ child of }u}\binom{SZ[v]}{k}.$$价值$p[u]$让我们快速计算完全包含在一个子子树中的子集。 
3. 对于每个非根顶点$u$，考虑该分量等于$u$。 它的大小是$SZ[u]$。 

我们数数有多少$k$-子集使该组件显示为非关键块。 结果计数为$$\binom{n-SZ[u]-1}{k-1} + \binom{n-SZ[u]-1}{k} - \Bigl(p[fa[u]]-\binom{SZ[u]}{k}\Bigr) - \binom{n-SZ[fa[u]]}{k}.$$乘以$SZ[u]^2$给出该组件的贡献$$\sum sz_i^2.$$4. 还要考虑通过去除之间的边缘获得的互补分量$u$及其父级。 它的大小是$$n-SZ[u].$$使该区域成为非关键组件的子集数量为$$\binom{SZ[u]-1}{k-1} + \binom{SZ[u]-1}{k} - p[u].$$乘以$(n-SZ[u])^2$添加其贡献。 
5. 将每个非根顶点的所有此类贡献相加得出$$X=\sum_{S}\sum_i sz_i^2.$$6. 自从$$F(S)=n^2-\sum_i sz_i^2,$$对所有子集求和得出$$\text{Answer} = n^2 \binom{n}{k} - X.$$对所有内容取模$10^9+7$。 

### 为什么它有效

 对于固定子集$S$，每个非关键顶点恰好属于一个最大非关键连通分量。 同一组件内的所有根产生相同的值$f(r,S)$，即$n-sz$， 在哪里$sz$是该组件的大小。 

对根求和将问题从计算有根子树转变为计算组件大小的平方。 每个这样的组件恰好是某个边缘的一侧。 组合公式精确地计算该边形成最大非关键分量的子集。 由于每个分量都被计数一次且仅一次，因此累加值等于$$\sum_S \sum_i sz_i^2.$$代入$$F(S)=n^2-\sum_i sz_i^2$$产生所需的总数。 

计数公式和实现遵循官方编辑解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

n, k = map(int, input().split())

g = [[] for _ in range(n + 1)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)

fac = [1] * (n + 1)
for i in range(1, n + 1):
    fac[i] = fac[i - 1] * i % MOD

invfac = [1] * (n + 1)
invfac[n] = pow(fac[n], MOD - 2, MOD)
for i in range(n, 0, -1):
    invfac[i - 1] = invfac[i] * i % MOD

def C(a, b):
    if b < 0 or b > a:
        return 0
    return fac[a] * invfac[b] % MOD * invfac[a - b] % MOD

parent = [0] * (n + 1)
sz = [0] * (n + 1)
p = [0] * (n + 1)

order = [1]
parent[1] = -1

for u in order:
    for v in g[u]:
        if v == parent[u]:
            continue
        parent[v] = u
        order.append(v)

for u in reversed(order):
    sz[u] = 1
    cur = 0
    for v in g[u]:
        if v == parent[u]:
            continue
        sz[u] += sz[v]
        cur += C(sz[v], k)
    p[u] = cur % MOD

ans_sub = 0

for u in range(2, n + 1):
    par = parent[u]

    cnt1 = (
        C(n - sz[u] - 1, k - 1)
        + C(n - sz[u] - 1, k)
        - (p[par] - C(sz[u], k))
        - C(n - sz[par], k)
    ) % MOD

    ans_sub = (ans_sub + sz[u] * sz[u] % MOD * cnt1) % MOD

    cnt2 = (
        C(sz[u] - 1, k - 1)
        + C(sz[u] - 1, k)
        - p[u]
    ) % MOD

    comp = n - sz[u]
    ans_sub = (ans_sub + comp * comp % MOD * cnt2) % MOD

total = n * n % MOD * C(n, k) % MOD
answer = (total - ans_sub) % MOD

print(answer)
```阶乘和反阶乘数组提供恒定时间二项式系数。 自从$n$达到$2 \cdot 10^5$，这个预处理是必不可少的。 

DFS 是迭代实现的。 Python的默认递归限制对于长度链来说不够大$2 \cdot 10^5$。 

数组`p[u]`是一个性能关键的优化。 如果没有它，计算计数公式将重复迭代父级的子级，并且可能退化为星形树上的二次时间。 为此，社论明确引入了这种预计算。 

每个组合表达式都被模约化$MOD$。 允许负中间值，并取`% MOD`最后正确地标准化它们。

 ## 边缘情况

 当$k=1$，每个子集恰好包含一个顶点。 计数公式仍然有效，因为诸如$\binom{x}{k-1}$变得$\binom{x}{0}=1$。 该算法自然地计算其最小有根子树是所选顶点的普通有根子树的所有根。 

什么时候$k=n$，上参数小于的每个二项式系数$n$变为零。 所有组件的贡献都消失了，只剩下$$n^2 \binom{n}{n}=n^2.$$这符合必须始终包含整棵树的事实。 

对于链条，许多边缘切口的一侧具有尺寸$1$。 公式明确使用$SZ[u]-1$和$n-SZ[u]-1$。 只要上面的参数为负或小于下面的参数，组合函数就会返回零，从而防止链末端出现差一错误。
