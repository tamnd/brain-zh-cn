 ## 解决方案
 ## 问题理解

 我们得到了一组学生的鞋码排序列表。 每个学生最初都拥有一双鞋，我们希望在学生之间重新分配这些鞋，以便每个人都收到一双鞋。 

再分配必须同时满足两个约束。 首先，不允许学生保留自己的鞋子。 其次，学生只能收到至少与自己鞋码一样大的鞋子。 由于尺寸按非递减顺序排序，较小的索引对应于较小或相同的尺寸，这强烈限制了谁可以安全地接收谁的鞋子。 

任务是构建描述谁给谁鞋子的索引排列，或者确定不存在这样的排列。 

关键的结构性限制是，这不仅仅是一个混乱问题。 即使我们可以避免固定点，我们也必须尊重基于大小排序的单调可行性条件。 这个额外的约束使得许多自然排列无效。 

约束允许最多 1000 个测试用例，总 n 最多为 100000。任何每个测试用例都是二次的解决方案都会立即变得太慢，因为即使每个测试用例有 10^5 次操作，在跨测试求和时也已经超出了限制。 这促使我们对每个测试用例采用线性或近线性构造。 

当所有大小都严格增加时，会出现微妙的边缘情况。 在这种情况下，最大元素没有严格更大的候选元素可供接收，并且如果最小元素违反相反方向的排序约束，则无法安全地从某个较大索引接收。 另一种边缘情况是当 n 等于 1 时，根本不存在没有固定点的排列。 

当贪婪分配尊重本地尺寸限制但意外地为学生分配了自己的鞋子时，会发生更有趣的失败情况，即使所有尺寸条件都成立，这也会使排列无效。 

## 方法

 一个蛮力的想法是尝试所有排列并检查有效性。 对于每个排列，我们验证没有索引映射到自身，并且每个分配都满足大小约束。 有n个！ 排列，即使对于 n = 10 这也已经是不可行的。 检查本身是 O(n)，因此总成本变为 O(n · n!)，这远远超出了任何限制。 

关键的观察结果是数组是排序的，因此我们可以在大小相等或相似的块中进行推理。 如果我们将具有相同体型的学生分组，则组内任何有效的重新分配在体型限制方面总是安全的，因为相同体型可以自由交换，而不会违反“大于或等于”。 

这将问题减少到避免固定点，同时尊重交换不应破坏单调可行性。 出现的自然结构是在等值段内进行排列。 在每个相同值的块中，我们可以旋转元素，这样就没有人呆在原地。 

唯一有问题的情况是当相等值的段的大小为 1 时。段中的单个元素不能在其组内移动，并且它也不能在不违反排序可行性的情况下与更小或更大的值交换，因为任何相邻的交换要么是非法的，要么仍然在全局结构中创建固定点情况。 因此，任何单例块都会导致失败。 

这导致我们识别连续的等值段并独立旋转每个段的结构。 如果所有段的大小至少为 2，我们可以安全地在每个段内旋转并连接结果。

 ## 算法演练

 我们独立处理每个测试用例。

1. 将数组分割为值相等的连续段。 这是很自然的，因为数组已经排序，因此相等的值形成连续的块。 
2. 对于每个段，检查其长度。 如果任何段的长度为 1，则立即断定不存在有效排列。 如果不违反无定点条件或排序隐含的可行性约束，则无法移动单个元素。 
3. 对于长度 k ≥ 2 的每个段，构造一个循环移位。 具体来说，如果段包含索引 [i, i+1, ..., j]，则分配 i → i+1, i+1 → i+2, ..., j → i。 这可以确保没有人在细分市场中保持自己的位置。 
4. 将所有段排列组合成全局排列。 

这种构造安全的原因是，在相等值的段内进行交换永远不会违反大小约束，因为所有元素都具有相同的大小。 同时，循环移位保证每个索引都远离自身。 

### 为什么它有效

 该算法保持了一个不变量，即每个学生仅从自己的等值块中分配一只鞋子。 由于块中的所有值都是相同的，因此每个分配都会自动满足大小要求。 唯一剩下的条件是避免固定点，并且循环移位确保每个块中的每个元素移动到不同的位置。 如果任何块的大小为 1，则无法维持该不变式，因为该元素在其允许的集合内没有替代位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = list(map(int, input().split()))

    p = [0] * n

    i = 0
    ok = True

    while i < n:
        j = i
        while j < n and s[j] == s[i]:
            j += 1

        length = j - i
        if length == 1:
            ok = False
            break

        # cyclic shift within [i, j)
        for k in range(i, j):
            p[k] = k + 1 if k + 1 < j else i

        i = j

    if not ok:
        print(-1)
    else:
        print(*p)
```该解决方案的工作原理是扫描一次排序数组并识别连续的相等段。 在每个段内，它通过将每个索引映射到下一个索引来构建旋转，最后一个回绕到第一个。 这保证了局部有效的排列结构，并且由于段是不相交的，所以全局映射也是一种排列。 

唯一关键的实现细节是正确处理段边界。 该循环确保`j`完全停止在第一个不同的值处，并且循环赋值使用`k + 1 < j`以避免进入下一段。

## 测试用例```python
import sys, io

def solve():
    import sys
    input = sys.stdin.readline
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        s = list(map(int, input().split()))
        p = [0] * n

        i = 0
        ok = True
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            if j - i == 1:
                ok = False
                break
            for k in range(i, j):
                p[k] = k + 1 if k + 1 < j else i
            i = j

        out.append("-1" if not ok else " ".join(map(str, p)))
    return "\n".join(out)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    return solve()

# provided samples

""") == """5 1 2 3 4
-1"""

# all equal minimal
assert run("""1

""") == "-1"

# small valid pair
assert run("""1

""") in ["2 1"]

# mixed blocks
assert run("""1

""") != "-1"

 ## 边缘情况

 单元件段是最重要的失效模式。 在这样的情况下`[5]`，没有其他位置可以将鞋子分配到，因此任何尝试都会强制固定点。 该算法在分段构建时正确检测到这一点并立即拒绝。 

严格增加数组形成另一个关键情况，例如`[1,2,3,4]`。 每个段的长度都是 1，因此任何地方都不可能进行交换。 分割步骤直接公开该结构，防止任何不正确的贪婪配对尝试。 

大型均匀阵列，例如`[7,7,7,7]`展现出建设性的一面。 循环移位会旋转所有索引，从而保持有效性，因为所有比较都相等，因此始终满足不等式约束。
