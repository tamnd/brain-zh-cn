 ## 解决方案
 ## 问题理解

 该问题要求我们计算一个数组中有多少个子序列是有效的。 通过选择一些索引并保持其原始顺序来创建子序列。 选定的长度序列`k`如果第一个选择的值可以被整除，则有效`1`，第二个选择的值可以被整除`2`，第三个由`3`， 等等。 我们只关心选择了哪些索引，因此两个具有相同值但位置不同的子序列将被单独计数。 答案必须以模数形式打印`1e9 + 7`。 

输入是一个长度的数组`n`， 在哪里`n`可以达到`100000`值可以大到`10^6`。 二次动态规划解决方案已经需要大约`10^10`在最坏的情况下，操作速度太慢。 值限制表明数字的整除结构是关键，因为一个值的可能约数数量最多为`10^6`足够小，可以有效处理。 

一个常见的错误是通过子序列的值而不是索引来跟踪子序列。 例如，使用输入`3`和数组`1 1 1`，每个元素形成一个不同的子序列，所以答案是`3`， 不是`1`。 另一个棘手的情况是当一个值由于其所需的位置而无法扩展子序列时。 用于输入`2`和数组`2 1`，子序列`[2,1]`无效，因为第二个元素必须能被整除`2`， 和`1`不是。 正确答案是`2`，来自`[2]`和`[1]`。 只检查值而不考虑当前长度的粗心解决方案会导致计数过多。 

另一个边界情况是`1`。 自从`1`可以被所有正整数整除，它可以放置在有效子序列中的任何位置。 有输入`3`和数组`1 1 1`，答案是每个非空子序列，即`7`。 

## 方法

 直接的方法是构建所有子序列。 对于每个子序列，我们可以检查它的第一个选择的元素是否可以被整除`1`，其第二个由`2`， 等等。 这是正确的，因为它完全遵循定义。 然而，长度的数组`100000`有`2^100000 - 1`可能的非空子序列，因此枚举是不可能的。 

更好的方向是从左到右处理数组，并维护每个当前长度存在多少个有效子序列。 假设我们已经处理了数组的某些前缀。 如果我们看到一个新值`x`，它可以成为任何现有有效子序列的下一个元素，其下一个所需位置除以`x`。 

重要的观察是我们永远不需要完整的长度分布`n`。 一个值`x`只能帮助创建新的子序列长度`i`什么时候`i`划分`x`。 自从`x <= 10^6`，除数的数量很少。 我们只能更新这些长度。 

让`dp[i]`表示长度有效子序列的数量`i`由迄今为止处理过的元素形成。 当我们处理一个值时`x`, 每个除数`d`的`x`表示长度的子序列`d - 1`可以延长至长度`d`通过添加`x`。 我们更新`dp[d] += dp[d-1]`。 长度`1`情况总是可能的，因为每个数字都可以被整除`1`， 所以`dp[1]`每个元素加一。 

更新顺序很重要。 我们必须按降序处理除数，以便当前值不会在同一子序列中多次重复使用。 如果我们从小长度更新为大长度，则新创建的子序列可以立即使用相同的数组元素再次扩展，这是无效的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了|
 | 最佳| O(n * sqrt(max(a))) | O(n * sqrt(max(a))) | O(最大(a)) | 已接受 |

 ## 算法演练

 1. 创建一个动态规划数组，其中`dp[i]`存储长度有效子序列的数量`i`处理完数组的当前前缀后。 最初所有值都为零，因为没有使用任何元素。 
2. 迭代每个数组值`x`从左到右。 当前值可以开始一个新的长度子序列`1`，所以增加`dp[1]`一个。 
3. 找出 的所有约数`x`。 对于每个除数`d`大于`1`， 更新`dp[d]`通过添加`dp[d-1]`。 原因是每个长度有效的子序列`d-1`可以追加`x`并成为长度有效`d`。 
4. 按降序处理除数。 这使得转换仅基于早期数组元素的子序列，从而防止当前元素被多次计数。 
5. 处理完整个数组后，将所有的求和`dp[i]`价值观。 每个有效的非空子序列都有一定的长度，所以这个和就是答案。 

为什么它有效：

 不变量是在处理完第一个之后`j`元素，`dp[i]`正好等于长度的有效子序列的数量`i`仅使用那些`j`元素。 当一个新元素`x`考虑到，唯一可能的新子序列是以`x`。 它们的前一部分必须已经是有效的长度子序列`d-1`， 在哪里`d`划分`x`，因为新元素将占据位置`d`。 更新仅计算这些扩展，仅计算其他扩展。 降序更新保证前一部分永远不包含当前元素，因此每个计数的子序列对应于一组唯一的索引。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10 ** 9 + 7

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    dp = [0] * (n + 2)

    for x in a:
        divs = []
        i = 1
        while i * i <= x:
            if x % i == 0:
                divs.append(i)
                if i * i != x:
                    divs.append(x // i)
            i += 1

        divs.sort(reverse=True)

        for d in divs:
            if d == 1:
                dp[1] = (dp[1] + 1) % MOD
            elif d <= n:
                dp[d] = (dp[d] + dp[d - 1]) % MOD

    print(sum(dp) % MOD)

if __name__ == "__main__":
    solve()
```数组`dp`大小为`n`因为子序列的长度不能大于元素的数量。 过渡只需要实际可以出现的位置。 

对于每个值，代码首先通过检查所有数字直至其平方根来收集其除数。 最大值为`10^6`，所以这足够快了。 按降序对除数进行排序是防止当前元素无效重用的细节。 

什么时候`d == 1`，该值自行创建一个新的子序列。 对于较大的除数，`dp[d-1]`已经表示在当前索引之前结束的子序列，因此添加当前值会创建新的有效长度子序列`d`。 

Python 整数不会溢出，但在更新期间应用模运算以保持存储的值有界。

 ## 边缘情况

 对于输入`2`带数组`2 1`，算法处理`2`首先并创建一个长度子序列`1`。 价值`1`也可以创建一个长度`1`子序列，但不能扩展现有长度`1`后续因为`2`不分开`1`。 最终的答案是`2`。 

对于输入`3`带数组`1 1 1`，每个处理后的值都会增加一个新的长度`1`子序列。 第一个`1`创建一个子序列，第二个子序列创建新长度`1`并且可以将前一个延伸到长度`2`，第三个创造了所有剩余的可能性。 计数变为`3`,`3`， 和`1`对于长度`1`,`2`， 和`3`，给出答案`7`。 

对于重复值，例如`3`带数组`2 2 2`，降序除数更新可防止单个`2`以免被使用两次。 有效子序列的长度为 3`1`和三个长度`2`, 给予`6`，而长度`3`是不可能的，因为`2`不能被整除`3`。
