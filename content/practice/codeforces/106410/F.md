 ## 解决方案
 ## 问题理解

 我们有两个字符串，`a`和`b`，长度相同。 允许的操作是不寻常的：我们选择一个索引，而不是交换两个字符或更改一个位置`i`并反转一切`i`到当前字符串的末尾。 任务是找到这样的后缀反转序列，将其转换为`a`进入`b`，或者证明这是不可能的。 该序列最多必须包含 2000 个操作。 官方声明描述了长度最大为 1000 的字符串的转换问题。 

输入大小足够小，我们不需要近线性算法，但它仍然足够大，盲目尝试所有可能的操作是不可能的。 对于长度为 1000 的字符串，每个时刻都有 1000 种可能的后缀反转。 探索所有选择的搜索树就像$1000^k$，所以即使深度 10 也已经远远超出了可以处理的范围。 

重要的观察是后缀反转具有很强的结构。 它们影响从某个点到右侧的每个位置，这意味着所选索引之前的前缀被冻结。 正确的解决方案应该利用这样一个事实：我们可以从左到右决定字符并且不再打扰它们。 

一个常见的错误是假设每个操作都可以通过稍后简单地反转相同的后缀来撤消。 虽然这是事实，但这并不意味着可以进行任意转换。 例如：```
Input:
3
deb
fyf

Output:
-1
```第一个字符串包含字符`d`,`e`,`b`，而目标有`f`,`y`,`f`。 由于后缀反转仅重新排列现有字符，因此无法创建新字母。 仅模拟位置而不检查角色可用性的粗心实现可能会尝试构建序列并稍后失败。 

另一个边缘情况是字符串已经相等。```
Input:
1
m
m

Output:
0
```无需任何操作。 始终对每个位置执行反转的实现可能会错误地输出不必要的操作，甚至超出操作限制。 

最后一个棘手的情况是所需的反转仅影响后缀的转换。```
Input:
4
emog
egom

Output:
1
2
```从位置 2 开始反转后缀变化`emog`进入`egom`。 只允许全字符串反转的解决方案会忽略这些情况。 

## 方法

 蛮力的想法是模拟后缀反转的每个可能的序列。 该操作很容易应用，如果序列到达目标字符串，那么它显然是正确的。 对状态的广度优先搜索甚至会找到最短的序列。 问题在于州的数量。 最多有$26^n$可能的字符串，甚至只存储可达状态也不够$n=1000$。 2000 次操作限制并没有帮助，因为探索选择的分支仍然太多。 

关键的观察来自于最终位置。 目标字符串的最后一个字符必须来自原始字符串中的某个字符。 长度至少为 2 的后缀反转会更改反转后缀的第一个字符和最后一个字符。 这意味着我们可以通过选择将所需字符带到那里的反转来控制当前的最后位置。 

一旦一个字符被放置在末尾，我们就不需要再次触摸它。 这建议从右到左处理字符串。 在每一步中，我们都会查看应该出现在当前最后一个未固定位置的字符。 如果它已经存在，我们可以忽略它。 否则，我们会找到该角色当前所在的位置。 单个后缀反转可以使其结束，但其余部分的方向可能会变得不方便。 第二次逆转可以恢复方向。 

这将问题简化为贪婪构造。 每个位置最多需要两次操作，因此对于$n=1000$操作总数最多为2000。

 ## 算法演练

 1. 从琴弦的最后一个位置开始，向第一个位置移动。 当前位置后面的后缀已经是正确的，永远不会再修改。 
2. 如果当前的最后一个字符`a`已经等于对应的字符`b`，移动到下一个位置。 不需要任何操作，因为正确的字符已经固定。 
3. 否则，在剩余前缀中找到所需字符的位置。 该字符必须移动到字符串活动部分的末尾。 
4. 从找到的位置开始反转后缀。 所需的字符移动到活动端。 
5. 如果找到的位置不是活动部件的第一个位置，则反转整个活动部件。 这将恢复方向，以便剩余的未固定字符保持其可用顺序。 
6. 处理完所有位置后，输出记录的操作。 如果在任何时候剩余部分中不存在所需的字符，则转换是不可能的。 

为什么它有效：每次迭代后，当前后缀为`a`匹配后缀`b`。 这些操作仅触及尚未固定的位置，因此已经正确的后缀保持不变。 当放置一个字符时，第一次反转保证所需的字符到达其目的地，并且可选的第二次反转将剩余的前缀更改为与放置之前相同的状态，只是删除了一个字符。 由于每一步都会将未解决的位置数量减少一个，因此该过程最终会完成或检测到不可能的字符要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(input().strip())
    b = input().strip()

    ans = []

    for end in range(n - 1, -1, -1):
        if a[end] == b[end]:
            continue

        pos = -1
        for i in range(end + 1):
            if a[i] == b[end]:
                pos = i
                break

        if pos == -1:
            print(-1)
            return

        if pos != 0:
            ans.append(pos + 1)
            a[pos:] = reversed(a[pos:])

            ans.append(1)
            a[:end + 1] = reversed(a[:end + 1])
        else:
            ans.append(1)
            a[:end + 1] = reversed(a[:end + 1])

    print(len(ans))
    for x in ans:
        print(x)

if __name__ == "__main__":
    solve()
```该实现将当前字符串保留为可变列表，因为后缀反转会更改许多字符。 Python 切片和赋值让我们可以精确反转所需的部分，而无需创建完全独立的字符串。 

循环过程`end`从右到左。 指数`end`表示仍允许更改的最后一个位置。 之后的一切都已经等于目标。 

当找到所需的字符时，存储操作将使用基于 1 的索引，因为问题语句使用从 1 开始的位置。 实际的 Python 索引是从零开始的，所以`pos + 1`被打印。 

操作次数自然是有界的。 每个`n`位置最多使用两个操作，最多给出`2n`，这符合所需的限制`n ≤ 1000`。
