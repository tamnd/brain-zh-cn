 ## 解决方案
 ## 问题理解

 我们在一条线上放置了一组信标。 每个信标都有一个位置和当前功率。 充满力量的灯塔`p`覆盖包含区间`[x - p, x + p]`。 在每一轮中，每对具有不同功率的重叠间隔都会导致较弱的信标获得一个功率。 所有收益同时发生。 任务是确定进程达到稳定状态后覆盖的整数位置总数。 

信标数量可达`2 * 10^5`，所以模拟回合是不可能的。 一轮可以改变很多力量，而且轮数也可以很大，因为力量可以一次增加一种。 对于这个输入大小，我们需要一个接近的解决方案`O(n log n)`，这排除了涉及多对信标之间重复比较的任何情况。 

主要的陷阱是由功率变化引起的，而不仅仅是间隔变化。 最初与另一个信标分离的信标可以在增加一些后变得连接。 仅合并最初重叠间隔的解决方案是不正确的。 

例如：```
2
0 1
5 3
```间隔是`[-1,1]`和`[2,8]`，所以它们已经重叠，因为第二个在第一个结束后立即开始。 权力变得平等`3`，最终的并集是`[-3,8]`，长度`12`。 只保留初始并集的粗心实现会输出`10`。 

另一个例子是：```
3
0 1
4 1
8 5
```前两个信标不重叠，但第三个信标到达第二个信标。 第二个信标增加并最终可以将前两个信标连接到相同的最终组件中。 忽略新产生的重叠将会错过这种连锁反应。 

最后一个边缘情况是组件中具有最大功率的信标。 它永远不会增长，而每一个较弱的灯塔最终都会达到相同的功率。 将所有信标视为对称生长会给出错误的最终功率。 

## 方法

 直接的方法是模拟该过程。 对于每一轮，我们可以检查每对信标，找到所有重叠的对，并增加较弱的功率。 这是正确的，因为它完全遵循规则。 然而，检查所有对的成本`O(n^2)`每轮。 和`n = 2 * 10^5`，即使是一次完整扫描也已经太昂贵了，而且轮数不受一个小常数的限制。 

关键的观察结果是该过程仅取决于连接的组。 在任何连接的重叠间隔组内，最大功率永远不会改变，因为没有更强的信标来增加它。 每个其他信标都有一条导致最大功率信标的重叠路径，因此增量沿着该路径传播，直到每个信标达到相同的最大功率。 

这意味着动态过程可以被静态合并过程取代。 我们从左到右处理信标。 每个处理组由其最左位置、最右位置以及内部的最大功率表示。 如果在两者都扩展到其最终幂后，新组与前一组重叠，则它们实际上必须属于同一个最终组件。 我们将它们合并并保留较大的最大功率。 

堆栈就足够了，因为只有最后处理的组件才能受到新信标的影响。 合并两个组件后，新组件也可以到达它们之前的组件，因此我们在最后两个堆栈条目重叠时重复合并。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(r * n^2)`|`O(n)`| 太慢了|
 | 最佳|`O(n log n)`|`O(n)`| 已接受 |

 ## 算法演练

 1. 按位置对所有信标进行排序。 我们按此顺序处理它们，因为未来每种可能的交互只能与已经看到的组件或右侧的组件发生。 
2. 从当前信标创建一个新组件。 它的左右边界均为信标位置，其功率为信标原始功率。 
3. 将新组件与堆栈中的前一个组件进行比较。 如果它们的最终间隔重叠，它们就不能保持分离。 通过从左组件中获取左边界、从右组件中获取右边界以及从两者中获取最大功率来合并它们。 
4. 继续向后合并，同时新合并的组件仍与前一个堆栈元素重叠。 这处理了一个强大的组件，该组件扩展得足够远以吸收多个旧组件。 
5.处理完所有信标后，每个堆栈条目都是一个最终的稳定组件。 将它们的间隔长度相加。 

为什么它有效：不变的是在处理第一个之后`i`信标，该堆栈恰好包含仅使用这些信标即可形成的最终组件。 组件存储其最终的最大功率，因为​​其内部的每个较弱的信标最终都会达到该值。 当两个相邻的存储组件重叠时，它们的信标在稳定后会相互影响，因此将它们分开会违反最终组件的定义。 重复合并会在每次插入后恢复不变性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = []
    for _ in range(n):
        x, p = map(int, input().split())
        a.append((x, p))

    a.sort()

    stack = []

    for x, p in a:
        stack.append([x, x, p])

        while len(stack) >= 2:
            l1, r1, p1 = stack[-2]
            l2, r2, p2 = stack[-1]

            if l2 - p2 <= r1 + p1:
                nl = l1
                nr = max(r1, r2)
                np = max(p1, p2)

                stack.pop()
                stack.pop()
                stack.append([nl, nr, np])
            else:
                break

    ans = 0
    for l, r, p in stack:
        ans += r - l + 1

    print(ans)

if __name__ == "__main__":
    solve()
```首先对输入进行排序，因为堆栈方法依赖于从左到右的处理。 每个堆栈条目仅存储稳定后重要的信息：极端位置和最大功率。 

重叠检查使用最终的扩展间隔。 两个组件`[l1, r1]`和`[l2, r2]`有权力`p1`和`p2`互动如果`l2 - p2 <= r1 + p1`。 合并操作保留最大功率，因为​​这是整个连接组件共享的最终功率。 

最后的循环计算包含长度，因此贡献`[l, r]`是`r - l + 1`。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |`O(n log n)`| 排序占主导地位，每个组件最多被压入和弹出一次 |

 ## 边缘情况

 对于本案```
2
0 1
5 3
```堆栈首先创建两个组件。 第二个组件扩展为`[2,8]`，重叠`[ -1,1 ]`，所以它们合并。 最后一个组件有电`3`和间隔`[-3,8]`，给出长度`12`。 

为了```
3
0 1
4 1
8 5
```前两个信标合并成一个带电源的组件`1`。 当插入第三个信标时，其间隔`[3,13]`与该组件的最后一个间隔重叠，因此整个结构成为一个组件。 存储的最大功率变为`5`，生产`[-5,13]`与长度`19`。 

stack 方法还可以安全地处理大幂，因为所有算术都是使用 Python 整数完成的，因此位置最多为`10^9`超出此范围的扩展范围不会溢出。
