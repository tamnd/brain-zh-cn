 ## 解决方案
 ## 问题理解

 我们得到一个起始整数，并且可以使用一组固定的整除运算重复缩小它。 每个操作都会用较小的值替换当前值，但前提是当前值可被特定数字整除：2、3 或 5。目标是使用尽可能少的操作将数字转换为正好 1。 如果使用这些规则无法达到 1，我们必须报告不可能。 

每个查询都是独立的，因此我们针对不同的起始值多次解决此转换问题，可能高达$10^{18}$。 关键思想是每个操作都严格减少数字，因此任何有效过程都是有限的，但并不是每个整数都可以减少到 1，因为允许的操作仅删除结构化比率中的某些素因数。 

约束条件$n \le 10^{18}$立即排除任何模拟所有可能的转换路径的方法。 超过值的 BFS 或 DP 是不可能的，因为状态空间是无界的，即使适度的分支也会爆炸。 剩下的是一种直接推理数字结构而不是探索序列的方法。 

当数字包含除 2、3 或 5 以外的质因数时，就会出现微妙的边缘情况。例如，$n = 14$包含因子 7。任何操作都不会删除因子 7，因此任何尝试都会立即失败。 正确的输出是-1。 如果不明确验证最终可达性，仅在可能时尝试操作的粗心贪婪归约可能仍会循环或错误地得出成功结论。 

当数字已经为 1 时，会出现另一种边缘情况。在这种情况下，不需要任何操作，答案为 0。这很重要，因为总是尝试除法的简单循环会错误地尝试不必要的操作。 

## 方法

 强力解释是将每个数字视为图中的一个状态，其中边代表有效操作。 从任意号码$n$，我们可以去$n/2$,$2n/3$， 或者$4n/5$当满足可除条件时。 BFS 将保证最少步数达到 1。 

这种方法是正确的，因为每个操作都有相同的成本，并且 BFS 按距离递增的顺序探索状态。 然而，关键的缺陷是可达状态的数量没有以有用的方式受到限制。 尽管值总体下降，但跨不同因子去除顺序的分支会创建许多中间状态，并且对于大量而言，这变得不可行。 

关键的观察是操作的结构不是任意的。 每个操作仅删除质因数 2、3 或 5，并且以固定的比例进行。 这意味着操作顺序并不重要； 重要的是我们删除每个素因子多少次。 该问题简化为计算 2、3 和 5 的重数$n$，同时确保不存在其他素因数。 

一旦我们认识到这一点，最佳解决方案就变成了一个简单的因式分解循环：重复除以 2，然后除以 3，然后除以 5，并跟踪每次除法执行的次数。 除去所有可能的 2、3、5 后，如果剩下除 1 以外的任何值，则答案是不可能的。

 | --- | --- | --- | --- |
 | 蛮力（状态上的 BFS）| 指数| O（状态）| 太慢了 |
 | 最优（质因子剥离）| 每个查询 O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每个查询并逐步减少数量。 

1. 读取号码$n$。 如果$n = 1$，因为不需要任何操作，所以立即输出0。 这可以干净地处理退化情况，而不会进入任何循环。 
2. 初始化计数器`moves = 0`。 这将存储执行的操作总数。 
3.同时$n$能被 2 整除，除以 2 并递增`moves`。 每一个这样的除法都精确对应一个有效的运算，所以我们贪婪地提取 2 的所有因子。 
4. 对 3 重复相同的过程： while$n$能被3整除，除法和增量`moves`。 这确保了来自第二操作类型的所有贡献。 
5. 再次重复 5: while$n$能被 5 整除，除法和增量`moves`。 这提取了与第三操作类型相对应的所有因素。 
6. 去除2、3、5的所有因数后，检查剩余值是否为1。如果不是，则输出-1，因为这意味着$n$至少包含一个 {2, 3, 5} 之外的质因数，且永远无法通过允许的操作删除该质因数。 
7、如果剩余值为1，则输出`moves`。 

### 为什么它有效

 每个操作仅以受控方式从数字中删除一种类型的质因数。 没有任何操作会引入新的素数或更改 {2, 3, 5} 之外的素数。 因此，任何有效的操作序列都准确地对应于从因式分解中删除所有出现的 2、3 和 5$n$。 删除的顺序并不重要，因为乘法在素因数分解中是可交换的。 如果删除这些素数后还剩下任何东西，那么根据规则，剩下的因子是不可变的，所以达到 1 是不可能的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve(n: int) -> int:
    moves = 0

    for p in (2, 3, 5):
        while n % p == 0:
            n //= p
            moves += 1

    return moves if n == 1 else -1

q = int(input())
for _ in range(q):
    n = int(input())
    print(solve(n))
```该解决方案使用素数 2、3 和 5 上的小循环独立处理每个数字。每个除法完全对应于一个允许的操作，因此对除法进行计数可以直接给出答案。 最终检查确保不存在无效的质因数。 

处理素数的顺序并不重要，因为每个循环都是独立的，并且仅删除该素数的贡献。

 ## 边缘情况

 对于$n = 1$，算法在检查任何因素之前立即返回 0。 这可以避免错误地计算不必要的除法。 

对于像这样的数字$n = 1000000000000000000$，该算法重复除以 2，然后除以 3，然后除以 5。尽管数字很大，但它很快就会崩溃为 1，因为它只包含允许的质因数。 循环结构保证了正确性，因为每次删除都是精确且不可逆的。 

为了$n = 14$，该数字在所有允许的除法中幸存下来，剩余因子为 7。算法通过最终检查正确检测到这一点$n \neq 1$，确保即使部分减少提前发生也不会发生误报。
