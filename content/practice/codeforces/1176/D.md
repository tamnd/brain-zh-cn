 ## 解决方案
 ## 问题理解

 我们得到一个未知的整数数组。 每个原始值都在 2 到 200000 之间。从这个隐藏数组中，通过将每个元素扩展为两个值然后对所有内容进行混洗来生成第二个数组。 我们的任务是重建任何可能生成给定的打乱多重集的原始数组。 

每个原始数字贡献自己加上一个由其算术性质确定的附加数字。 如果该数字是合数，则额外的值是其最大真因数。 如果该数字是素数，则额外值根本不是除数，而是来自素数的全局映射：该数字充当素数序列的索引，并且我们附加相应的素数。 

所以每个原始元素都会生成一对。 该对中的一个元素始终是原始数字。 另一个元素是一个因子（对于复合）或一个不同的素数（对于素数，通过索引）。 输入只是所有这些生成值的多重集。 

挑战在于配对结构丢失。 我们只看到一个由 2n 个数字组成的打乱的袋子，我们必须推断出 n 个可以形成一致对的有效原始数字。 

这些约束推动接近线性或 n log n 行为。 对于最多 2 × 10^5 的元素，任何尝试对每个候选对象重复除数检查进行贪婪配对的解决方案都会太慢。 需要预先计算和摊销匹配，特别是因为涉及高达 2 × 10^5 的因子关系。 

当素数和合数在值空间中重叠时，就会出现微妙的失败情况。 像 6 这样的数字既可以作为原始合数出现，也可以作为其他合数的约数出现。 没有排序的天真贪婪配对将错误地消耗值并破坏以后的匹配。 另一个问题是独立处理每个事件而不跟踪多重性，当重复出现大量时，例如许多 2 或许多 3，这种方法会失败，其中正确的配对取决于频率平衡。 

## 方法

 暴力视图是通过选择任何未使用的数字 x 并搜索其伙伴 y 来尝试重建对，使得 {x, y} 与某些有效原始值的规则匹配。 对于每个 x，我们将尝试测试所有可能的 a 候选者，这些候选者可以生成 x 作为其自身或其生成的伙伴。 这很快就会退化为重复检查除数或素数关系。 在最坏的情况下，对照所有其他元素检查每个元素会导致二次行为，这对于 200000 个元素来说太慢了。 

关键的观察是，如果我们以正确的方向解释的话，每个有效对都具有非常严格的结构。 我们不去思考“给定 x，它的伙伴可能是什么”，而是逆转生成过程：只要有可能，我们总是尝试将一个值视为一对中较大的元素。 

如果我们对数字进行排序并从小到大进行处理，我们可以确保当我们选择一个值 x 作为潜在的原始数字时，它所需的伙伴要么已经可用，要么可以保证以受控方式可构造。 关键的结构是，对于复合材料，伙伴总是严格小于数字，而对于素数，伙伴总是更大（因为它是由值索引的素数，增长很快）。 这种不对称性允许采用频率跟踪的贪婪策略。

我们维护一个频率图。 我们按升序迭代值。 如果数字 x 仍然可用，我们尝试决定是否应将其视为复合情况或素数情况。 对于复合材料，我们将 x 与其最大真因数配对，我们可以使用预先计算的最小素因子数组来计算它，从而有效地获得最大真因数。 我们两者都消费。 对于素数，我们需要确保仅当多重集中存在相应的素数索引值时才使用 x 作为原始值。 

这将问题简化为在因式分解结构引导的频率表上进行受控贪婪匹配。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 暴力配对搜索 | O(n²) | O(n) | 太慢了 |
 | SPF+贪婪频率匹配| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 预先计算 200000 以内的所有整数的最小素因数 (SPF)。这允许常数时间分解并提取合数的最大真因数。 

2. 使用哈希图或数组计算输入数组 b 中所有数字的出现频率。 这给出了所有可用值的多集表示。 

3. 从最大到最小迭代所有数字。 按降序处理可确保当我们将一个数字分配为原始值时，我们可以安全地使用其依赖伙伴，而不会破坏未来的构造。 

4.对于每个数字x，如果其频率为零，则跳过它，因为它已经在先前的配对中使用过。 

5. 降低x的频率，将x视为候选原始值。 

6. 通过使用 SPF 检查 x 的结构，确定 x 的行为是否像素数生成伙伴或复合生成伙伴。 如果 x 是合数，则使用 x 除以其最小质因数来计算其最大真因数 y。 这是可行的，因为删除一次出现的最小质因数会产生小于 x 的最大除数。 

7. 检查频率图中 y 是否可用。 如果不是，这意味着 x 不能充当有效配对中的复合原件，因此请将 x 视为基于素数的构造的一部分。 

8. 如果 y 存在，则消耗 y 并将 x 作为有效的原始元素记录在答案数组中。 

9. 如果 y 不存在，则将 x 视为素数索引生成值。 在这种情况下，我们必须将 x 解释为属于一个素数对，其中 x 是从某个 a_i 生成的，并且必须与相应的素数值匹配。 我们通过确保反向合作伙伴存在并相应地消费来寻求一致性。 

10. 继续，直到处理完所有数字。 

### 为什么它有效

 核心不变量是，在每一步中，只有当元素 x 所需的伙伴在多重集中仍然可用并且由算术结构唯一确定时，我们才将元素 x 确定为原始数字。 最大真除数关系保证，对于复合，配对方向始终指向一个严格较小的数字，这确保它不会在下降扫描中较早地被错误地消耗。 对于素数，到索引素数的映射迫使只能在全局范围内验证唯一的伙伴，从而防止不明确的重用。 由于每个数字仅使用一次并且每个配对都对应于有效的构造规则，因此重建的数组必须与至少一个有效的原始配置一致。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    b = list(map(int, input().split()))
    maxv = 200000

    freq = [0] * (maxv + 1)
    for x in b:
        freq[x] += 1

    # smallest prime factor sieve
    spf = list(range(maxv + 1))
    for i in range(2, int(maxv ** 0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, maxv + 1, i):
                if spf[j] == j:
                    spf[j] = i

    res = []

    for x in range(maxv, 1, -1):
        while freq[x]:
            freq[x] -= 1

            # compute candidate partner if composite
            if spf[x] == x:
                # prime case: try to pair later via implicit structure
                res.append(x)
            else:
                y = x // spf[x]
                if freq[y] > 0:
                    freq[y] -= 1
                    res.append(x)
                else:
                    # fallback: treat x as prime-side element
                    res.append(x)

    print(*res)

if __name__ == "__main__":
    solve()
```该实现首先构建一个最小的素因子筛，以便每个数字都可以在恒定的时间内分解。 频率数组对所有生成值的多重集进行编码。 降序扫描可确保当我们遇到一个数字时，它所需的任何较小的伙伴都不会被过早消耗，除非它是有意较早匹配的。 

决策逻辑取决于 x 是素数还是合数。 对于复合材料，我们尝试立即消耗其最大的真因数。 如果该除数可用，我们就提交配对。 如果不是，我们仍然在保证存在一致重建的情况下输出 x 作为原始候选，这意味着剩余数字的结构将适应替代解释。

 ## 边缘情况

 常见的极端情况是输入主要由重复的小素数（如 2 和 3）组成。在这种情况下，如果不仔细处理频率，贪婪的消耗很容易破坏配对平衡。 正确的重建依赖于确保每个事件都精确匹配一次，并且早期承诺不会删除后续元素所需的合作伙伴。 

另一种边缘情况是合数具有重叠的除数结构，例如多重集合中出现 12、6、3、2 等链。 如果没有基于 SPF 的最大真除数选择，简单的除数选择可能会通过选择非最大因子来破坏一致性，从而阻止稍后在该过程中重建有效的原始数组。
