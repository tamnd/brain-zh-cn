[CF 1176E - 覆盖它！](https://codeforces.com/problemset/problem/1176/E)

 **评分：** 1700
 **标签：** dfs 和类似、dsu、图、最短路径、树
 **求解时间：** 10m 33s
 **已验证：** 否

 ## 解决方案
 ## 问题理解

 对于每个查询，我们都会得到一个无向连通图，并且我们必须选择一个顶点子集，使得我们未选择的每个顶点都至少有一个选定的邻居。 换句话说，每个未选择的顶点必须被相邻的选定顶点“覆盖”。 额外的限制是所选顶点的数量不得超过所有顶点的一半。 

因此，任务本质上是构造一个在图上占主导地位的顶点集，但保证大小上限最多为楼层（n/2）。 我们不需要最小化任何内容，只需生成满足覆盖条件和大小约束的任何有效集合即可。 

约束很大：所有 n 和 m 次查询的总和最多为 2⋅10^5，并且最多可以有 2⋅10^5 个查询。 这迫使每个查询都有一个线性或近线性的解决方案，总体复杂度约为 O(n + m)。 任何涉及成对检查、子集枚举或每个顶点重复图遍历的操作都会太慢。 

稀疏图中会出现微妙的边缘情况，例如路径。 如果我们尝试贪婪地选取没有结构的任意顶点，我们可能会意外地选取太多顶点或无法保证覆盖范围。 例如，在路径 1-2-3-4-5 中，选择 {2,4} 是可行的，但幼稚的策略（例如总是错误地选取每隔一个顶点开始的策略）可能会超出或错过边界的覆盖范围，具体取决于遍历顺序。 

另一个边缘情况是像派系这样的密集图。 在完整图中，任何单个顶点都会覆盖所有其他顶点，因此选择 1 个顶点就足够了。 幼稚的交替策略可能仍然会不必要地选择太多顶点，但仍然有效。 

关键的困难是确保结构始终保持在 n/2 以内，同时保证统治。 

## 方法

 一个蛮力的想法是尝试所有顶点子集，检查它们是否在图上占主导地位，并跟踪那些大小最多为 n/2 的顶点。 对于每个候选集，验证覆盖范围需要扫描所有边或邻接列表，这已经花费了 O(n + m)。 由于有 2^n 个子集，这是完全不可行的。 

我们需要一种在确保覆盖范围的同时从本质上限制答案大小的结构。 关键的观察结果是，如果我们使用 BFS 或 DFS 奇偶校验着色对图进行 2 着色，则每条边都连接相同奇偶校验或不同奇偶校验节点，但我们仍然可以根据 BFS 树深度将顶点划分为两组。 由于图是连通的，即使图不是二分图，BFS 级别也为我们提供了一种自然的二分结构。 

现在考虑按 BFS 级别奇偶性对顶点进行分组：偶数深度和奇数深度。 在 BFS 树术语中，每条边都连接深度最多相差 1 的节点，但通常图边可以连接任意级别。 然而，我们利用的重要属性更简单：每条边都有端点，并且至少一个端点属于偶数或奇数水平集。 因此，未从一个奇偶校验集中选择的每个顶点都与另一奇偶校验集中的某个顶点相邻（通过 BFS 树边或图边），从而在选择较小的集合时保证覆盖范围。 

一种更可靠的查看方法是在任意节点处将图作为根，并按距离奇偶性着色。 每条边都连接相同或相反的奇偶校验。 如果一条边连接相同的奇偶校验，它并没有直接帮助，但可以保证全局覆盖，因为每个顶点在连接相反奇偶校验的 BFS 树中都有父子关系。 因此，选择两个奇偶校验集合中较小的一个可确保每个未选择的顶点在所选集合中至少有一个邻居。 

由于这两个集合对顶点进行了划分，因此其中一个集合的大小最多为 n/2，这立即满足约束。 

这将问题简化为单个 BFS 和奇偶校验计数。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n · (n + m)) | O(2^n · (n + m)) | O(n) | 太慢了 |
 | BFS 奇偶校验分区 | O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 我们以任意顶点（通常为 1）为图求根，并计算 BFS 距离。 

1. 从节点 1 运行 BFS 并记录每个节点的距离奇偶校验。 

我们根据每个节点到根的距离是偶数还是奇数来为每个节点分配 0 或 1。 这将创建两个候选组。 
2. 根据奇偶校验将节点收集到两个列表中。 

一个列表包含所有偶数距离节点，另一个列表包含所有奇数距离节点。 
3. 比较两个列表的大小。 

由于它们一起包含所有节点，因此至少一个列表的大小最多为楼层（n/2）。 我们选择该列表。 
4. 输出选择的列表作为答案。 

为什么这已经足够了，因为 BFS 分层如何保证从根开始的可达性结构，并确保每个节点都有一条交替奇偶校验步骤的路径，这意味着删除一个奇偶校验类仍然会使每个节点与至少一个选定的顶点相邻。 

### 为什么它有效

 每个顶点都属于两个奇偶校验类别之一。 所选集合是这两个类中较小的一个，因此任何未选择的顶点都属于另一个类。 在 BFS 树中，除根之外的每个节点都有一个具有相反奇偶校验的父节点，这意味着每个未选中的节点至少有一个处于相反奇偶校验类别的相邻节点。 由于我们选择了整个类，因此保证每个未选择的节点在所选集合中都有一个邻居。 大小界限保持不变，因为我们总是选择较小的分区。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    dist = [-1] * (n + 1)
    q = deque([1])
    dist[1] = 0

    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)

    even = []
    odd = []

    for i in range(1, n + 1):
        if dist[i] % 2 == 0:
            even.append(i)
        else:
            odd.append(i)

    if len(even) <= len(odd):
        ans = even
    else:
        ans = odd

    print(len(ans))
    print(*ans)
```BFS 计算距节点 1 的最短距离，这已经足够了，因为连接性保证每个节点均可到达。 奇偶校验分割存储在两个列表中。 最后，我们选择较小的列表以确保大小限制。 

一个常见的错误是假设任意着色都有效； BFS 确保整个图中奇偶校验分配的一致性。 另一个微妙的点是，我们不需要显式验证覆盖范围，因为奇偶校验结构在结构上保证了它。

 ## 边缘情况

 在单顶点中心星中，BFS 深度在距离 0 处产生一个中心，在距离 1 处产生所有其他中心。该算法选择较小的奇偶校验类，即中心，正确覆盖所有叶子。 

在长路径中，BFS 沿着链精确地交替距离，因此奇偶校验类均匀或几乎均匀地划分。 选择较小的类仍然通过其邻居覆盖每个内部节点。 

在完整图中，BFS 为除根之外的所有节点分配距离 1。 偶数集成为单个节点，它已经支配所有其他节点，因为每个顶点都与其相邻。
