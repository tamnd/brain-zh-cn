 ## 解决方案
 ## 问题理解

 我们有两个数组，每个数组都按非降序排序，并且每个数组都有奇数个元素。 任务是确定是否可以使用一系列操作使两个数组相同。 操作允许我们选择一个数组，标记其任意奇数个元素，用其中位数替换标记的段，然后将该中位数重新插入到同一数组中的任何位置。 

关键的观察结果是该操作保留了标记段之外的元素的相对顺序。 更重要的是，重复应用这些操作使我们能够将任何奇数长度的段折叠到其中位数。 由于两个数组的长度均为奇数，因此如果需要，每个数组最终都可以缩减为单个值。 

限制因素很大。 测试用例中所有数组长度的总和最多为 300,000。 重复标记段并移动中线的强力模拟可能需要对数组长度进行二次工作，这会太慢。 这意味着我们需要一个避免直接模拟操作的解决方案。 

需要注意的边缘情况包括长度为 1 的数组、所有元素都相等的数组或分布差异很大的数组。 例如，给定数组`[1, 3, 5]`和`[3]`，可以将第一个减少到`[3]`，但是对于`[1, 2, 3]`和`[4, 5, 6]`，没有任何操作序列可以使数组相等。 

## 方法

 强力方法是模拟每个有效操作，尝试每个数组的所有奇数长度子集，计算它们的中值，然后重新插入。 这种方法原则上是正确的，因为问题定义允许任何奇数长度的子集，但它的成本却高得令人望而却步。 对于长度为 301 的数组，有数百个潜在的奇数长度子集，而对于跨测试用例的完整数组长度 300,000，这很快就变得不可行。 

最佳方法取决于这样的见解：操作保留所有可能的奇数长度段的中位数的多重集。 换句话说，因为两个数组都是已排序的，并且操作可以选择整个数组或任何子数组，所以唯一重要的信息是第一个数组的最大元素和第二个数组的最小元素。 通过中位数反复折叠数组后，当且仅当第一个数组的最大值不超过第二个数组的最小值时，数组才能相等，反之亦然，具体取决于我们选择先折叠哪个数组。 

这一观察使我们能够有效地将每个数组减少为单个数字：选取整个数组的中位数。 然后，检查一个数组的最大中位数是否可以匹配另一个数组的最小中位数就足够了。 已经提供了排序，因此每个测试用例获取数组的最后一个元素和第一个元素的时间复杂度为 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个测试用例 O(n^2 + m^2) | O(n + m) | 太慢了 |
 | 最佳 | 输入后每个测试用例的 O(1) | 每个测试用例 O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，读取两个排序数组的长度和元素。 
3. 确定每个数组的中位数，即中间元素，因为两个数组的长度均为奇数。 在排序数组中，这很简单`a[n//2]`和`b[m//2]`。 
4. 比较中位数。 如果第一个数组的中位数等于第二个数组的中位数，则打印 YES； 否则，打印NO。 

正确性取决于任何奇数长度数组都可以通过重复操作折叠到其中值的不变量。 一旦我们将两个数组减少到各自的中位数，相等就很简单了。 中间元素并不重要，因为操作允许通过中值选择完全减少。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        median_a = a[n // 2]
        median_b = b[m // 2]
        print("YES" if median_a == median_b else "NO")

if __name__ == "__main__":
    main()
```该解决方案使用整数除法`n // 2`和`m // 2`直接访问中间元素。 这利用排序属性和奇数长度约束来查找 O(1) 中的中值。 不存在差一错误，因为 Python 列表是零索引的，并且整数除法自然指向中间元素。 输入读取经过优化`sys.stdin.readline`有效地处理大型测试用例。 

## 工作示例

 **示例1：**

 输入数组：`a = [1, 2, 3, 4, 5]`,`b = [1, 3, 7]`

`median_a = 3`,`median_b = 3`输出：是

 | 步骤| 一个 | 乙| 中位数_a | 中位数_b | 比较|
 | --- | --- | --- | --- | --- | --- |
 | 初始| [1,2,3,4,5] | [1,3,7]| 3 | 3 | 3 == 3 → 是 |

 该跟踪表明，将每个数组折叠到其中位数足以确定相等性。 

**示例2：**

 输入数组：`a = [11, 17, 19]`,`b = [19, 20, 26, 29, 37]`

`median_a = 17`,`median_b = 26`输出：否

 | 步骤| 一个 | 乙| 中位数_a | 中位数_b | 比较|
 | --- | --- | --- | --- | --- | --- |
 | 初始| [11,17,19] | [19,20,26,29,37] | 17 | 17 26 | 26 17 != 26 → 否 |

 这证实了算法可以正确识别数组何时不能相等。

 ## 边缘情况

 考虑长度为1的数组，例如`[5]`和`[5]`。 中位数是唯一的元素，算法正确返回 YES。 对于数组`[5]`和`[6]`，中位数不同，因此返回 NO。 当所有元素都相同时，`[7, 7, 7]`和`[7, 7, 7]`，两者的中位数都是 7，因此返回 YES。 排列但具有相同中位数的数组，`[1, 2, 3]`和`[3, 2, 1]`，也返回 YES，确认算法正确捕获中值崩溃的关键不变量。
