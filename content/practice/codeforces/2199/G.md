 ## 解决方案
 ## 问题理解

 我们被要求在矩形网格上找到可以放置干扰器的位置，以便它始终拦截从左下角移动的机器人$(0,0)$到右上角$(n,m)$，同时在起点和终点保持不可见。 机器人只能向右或向上移动，这意味着任何路径都由一系列水平和垂直步骤组成，最终到达$(n,m)$。 干扰器具有半径为圆形的范围$r$，并且我们需要保证机器人在**每条可能的路径**上进入该半径内的点，不包括太靠近的点$(0,0)$或者$(n,m)$。 

输入给出$n$,$m$， 和$r$， 和$1 \le n,m$和$n \cdot m \le 10^9$。 因此，网格尺寸很大，使得对所有点进行任何强力检查都是不可行的。$r$可以大到$n + m$，这意味着干扰器可能会覆盖整个对角线$(0,0)$到$(n,m)$。 输出是整数坐标点的数量$(x,y)$满足约束条件。 

出现了一个微妙的问题，因为干扰器必须覆盖机器人**所有路径**。 这相当于覆盖了“曼哈顿路径走廊”中的每一个点$(0,0)$到$(n,m)$。 机器人的路径形成一个网格对齐的对角走廊，因此任何距离该对角线太远的点都可以通过某些路径来避开。 这一观察立即表明我们需要考虑沿线的距离$x+y$sum，它唯一地确定机器人旅程中某个点的距离。 

边缘情况包括非常窄的网格（例如$1 \times 1$）或极长的细网格（如$1 \times 10^9$），只有很少或非常有限的职位可以工作。 另一个陷阱是当$r$足够大以覆盖明确禁止的开始或结束。 

## 方法

 蛮力方法很简单：迭代每个整数网格点$(x,y)$，检查其欧几里德距离$(0,0)$和$(n,m)$超过$r$，并验证其到**所有可能路径**的距离最多为$r$。 要检查每条路径，需要枚举所有路径$\binom{n+m}{n}$路径，对于$n,m$最多$10^9$。 即使忽略这一点，迭代所有网格点至少是$O(n \cdot m)$，这是不可行的。 这种做法原则上是正确的，但完全不切实际。 

关键观察是几何的：任何点$(x,y)$必须满足其与连接线段的**曼哈顿距离$(0,0)$到$(n,m)$** 最多是$r$在两个方向上。 由于机器人仅向右或向上移动，因此机器人的位置满足$0 \le x \le n$和$0 \le y \le m$，并且对于拦截**所有路径**的点，它必须位于由定义的“对角线带”中$x + y$距离。 具体来说，欧氏距离约束在 45 度旋转坐标中得到简化$u = x + y$,$v = x - y$因为所有的路都沿着$u$从 0 到$n+m$。 干扰器必须位于满足以下条件的方格内$r < x^2+y^2$以避免开始和$r < (n-x)^2 + (m-y)^2$以避免结束。 然后可以使用范围的简单算术直接计算此类整数点数的数量$x$和$y$。

 | --- | --- | --- | --- |
 | 蛮力 | O(n_m_2^(n+m)) | O(n_m_2^(n+m)) | O(1) | O(1) | 太慢了 |

 ## 算法演练

 1. 通过观察约束是对称的，交换到沿机器人对角线旋转的坐标系$x$和$y$。 路径总和$x+y$必须与对角走廊中的任何干扰器相交。 
2. 计算最小值和最大值$x$坐标，使得干扰机到起点和终点的欧几里德距离严格大于$r$。 这定义了$x$- 界限为$x_{\min} = r$和$x_{\max} = n - r$。 相似地，$y_{\min} = r$,$y_{\max} = m - r$。 
3. 这些边界之外的任何干扰都会违反开始或结束约束，因此丢弃这些边界定义的矩形之外的点。 
4. 计算剩余矩形内的所有整数点：$\max(0, x_{\max} - x_{\min} + 1) \cdot \max(0, y_{\max} - y_{\min} + 1)$。 如果任一维度为负，则没有点满足条件。 
5. 输出每个测试用例的乘积。 

该算法之所以有效，是因为关键的不变量是中心对角线带内的每个点都在距离内$r$每个机器人路径的起点或终点附近的矩形之外的点违反禁区规则。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, r = map(int, input().split())
        x_min = r + 1
        x_max = n - r - 1
        y_min = r + 1
        y_max = m - r - 1
        width = max(0, x_max - x_min + 1)
        height = max(0, y_max - y_min + 1)
        print(width * height)

if __name__ == "__main__":
    solve()
```代码首先读取测试用例的数量。 对于每个测试用例，它计算与起点和终点之间的距离有关的最小和最大坐标。 这`+1`和`-1`调整强化了严格的不平等。 最终产品对允许的矩形内的所有整数坐标点进行计数，如果矩形是退化的或维度为负的，则返回零。 

## 工作示例

 输入示例：```
n=10, m=5, r=3
```| 变量| 价值| 说明|
 | --- | --- | --- |
 | x_最小值| 4 | 从开始起严格超过 3 |
 | x_最大| 6 | 距离结束严格超过 3 (10-3-1) |
 | y_分钟 | 4 | 从开始起严格超过 3 |
 | y_最大| 1 | 5-3-1=1，负->钳位|
 | 宽度| 3 | x_max - x_min + 1 = 6-4+1=3 |
 | 高度| 0 | y_max - y_min +1=0，钳制为 0 |
 | 结果 | 3*0=0 | 3*0=0 没有积分 |

 这符合一维网格太窄的推理。
