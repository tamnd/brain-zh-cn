 ## 解决方案
 ## 问题理解

 我们从一个非常受限的系统开始：一个数组以全 1 开始，另一个数组全为零，第三个数组`c`提供 1 到 50 之间的一系列目标值。该过程运行于`m`阶段，并且在每个阶段，只要尊重整除性，我们就可以通过以任意方式将其元素乘以或除以素数来“重塑”第一个数组，每个位置独立。 

在此重塑步骤之后，我们可以选择分配一个位置`k`如果该位置的值匹配，则从第一个数组到当前阶段`c[i]`。 如果我们这样做，我们将该索引记录到`b[i]`。 否则我们就离开`b[i] = 0`。 

关键的抽象是第一个数组并不是真正的固定结构。 因为每个元素都可以在每个阶段独立地乘以或除以任何素数，所以`a`基本上不受约束，除了它们始终保持为使用任意质数指数调整从 1 可达的正整数这一事实。 这意味着任何元素总是可以达到任何正整数值，并且不同的元素可以在任何阶段自由地相等或不同。 

因此，真正的约束不是关于算术可达性，而是关于随着时间的推移我们可以通过多少种方式分配索引来匹配序列`c`，其中每个阶段要么分配一个匹配索引，要么跳过。 

我们必须计算有多少个数组`b`可以产生，其中每个`b[i]`是 0 或索引`[1, n]`，唯一的限制是每当我们分配`b[i] = k`，我们必须能够确保在阶段`i`，某些元素已转换为值`c[i]`。 

由于我们可以在任何阶段自由地强制任何元素采用任何所需的值，因此唯一有意义的约束变成了组合：分配如何跨阶段交互，特别是当多个位置可以重复使用或新“激活”以匹配所需值时。 

微妙之处在于，从朴素的意义上来说，每个阶段的分配并不是独立的，因为如果我们将过程解释为消耗结构，那么使用索引一次会影响后续阶段中剩余可用的不同索引的数量。 该解决方案最终简化为最多计算分配方式`n`难以区分的“主动身份”`m`时间步长，尊重相同的多重性`c[i]`。 

约束条件`n, m ≤ 10^4`立即排除长度为指数的子集或序列上的任何 DP`m`。 任何解决方案都必须将过程压缩为基于频率的值推理`1..50`。 

一种天真的解释会尝试逐步模拟该过程，跟踪所有可能的索引分配，但这会组合爆炸。 关键的边缘情况是当所有`c[i]`是相同的：每个阶段看起来都可以互换，但有效数组不同，因为重复的赋值通过重用索引进行交互。 

另一个边缘情况是当`n = 1`。 那么至多可以存在一个非零赋值，因此答案就变成了选择单阶段或无的方法数量，这与较大的阶段有很大不同`n`。 

## 方法

 暴力方法尝试显式地模拟该过程。 在每个阶段，我们都会考虑所有可能的索引子集`a`可以转化为等于`c[i]`，然后选择其中之一来分配给`b[i]`。 这导致分支因子大致为`O(n)`每个阶段及以上`m`阶段产生`O(n^m)`的可能性。 即使进行了修剪，状态空间实际上也是将索引分配给时间位置的方法的数量，并且呈指数增长。 

蛮力的失败来自于独立对待每个阶段。 关键的观察是因为我们可以任意重塑`a`在每个阶段，元素的特性都不是限制因素。 重要的是在分配中使用了多少个不同的索引，以及如何重用或引入这些分配。 

我们可以将这个过程重新解释如下：每次我们分配一个非零值时，我们都会选择其中一个的“新用法”`n`可用插槽，但值在`c`施加分组约束，因为相同的值表现对称。 这将问题简化为计算在可用索引上分配相等值的出现次数的方法，这成为由频率控制的组合分配问题。 

让`freq[x]`是价值的多少倍`x`出现在`c`。 对于每个值`x`，我们决定将使用多少个不同的索引来服务出现的情况`x`。 每个此类索引都会提供一系列使用它的位置，全局限制是所有值中使用的总不同索引不能超过`n`。 

该结构成为按值分组的所有事件的分区问题，二项式选择控制如何跨事件引入索引。 

这导致 DP 超过值`1..50`，跟踪到目前为止已消耗了多少个索引，并针对每个值将其出现次数分布在现有索引中或引入新索引。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（模拟所有作业）| 指数| 指数| 太慢了 |
 | 最佳 DP 值频率 | O(50·n²) | O(50·n²) | O(n) | 已接受 |

 ## 算法演练

 我们将数组分组`c`按价值。 对于每个值`x`，假设出现`k`次。 

我们维护一个DP数组`dp[i]`， 在哪里`i`是已使用的不同索引的数量，并且`dp[i]`是处理所有先前值的方法数量，从而准确地得出结果`i`使用的指数。 

我们一一处理价值观。 

1. 初始化`dp[0] = 1`。 在处理任何内容之前不使用任何索引。 
2. 对于每个值`x`随频率`k`，我们计算一个转换表`ndp`。 
3. 对于固定当前状态`i`使用索引，我们考虑值的出现方式`x`被分配：

 每个`k`事件要么使用现有的之一`i`索引或引入新索引。 
4. 假设我们准确地决定`j`引入新的价值指数`x`。 然后，我们必须选择哪些事件启动新索引，并将剩余事件分配给现有或新创建的索引。 组合结构简化了选择分区`k`出现在`i + j`可用标签，其中`j ≥ 0`和`i + j ≤ n`。 
5. 数量分配方式`k`标记的事件进入`i + j`标记索引使得所有`i + j`所使用的是由类似斯特林数的行为给出的，但这里对称性将其简化为满射上的标准组合数学，可以通过小数上的 DP 预先计算或计算`k`。 
6. 我们将转换累积为`ndp[i + j]`对于所有有效的`j`。 
7. 处理完所有值后，答案就是总和`dp[i]`为了`i ≤ n`。 

### 为什么它有效

 不变量是在处理值的子集之后，每个 DP 状态`i`主动索引代表所有有效的部分结构，其中`i`不同的索引已用于满足所有处理的值，并且所有分配只能通过索引的重用或新引入方式来区分。 由于未来值是独立的，除了共享最多`n`索引，仅通过使用索引的计数合并状态保留所有必要的信息。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, m = map(int, input().split())
    c = list(map(int, input().split()))

    from collections import Counter
    freq = Counter(c)

    # DP: dp[i] = number of ways using i distinct indices so far
    dp = [0] * (n + 1)
    dp[0] = 1

    # Precompute factorials up to max frequency
    max_k = max(freq.values(), default=0)
    fact = [1] * (max_k + 1)
    for i in range(1, max_k + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact = [1] * (max_k + 1)
    invfact[max_k] = modinv(fact[max_k])
    for i in range(max_k, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def ways(k, t):
        # number of ways to assign k items onto t labeled non-empty groups
        if t > k:
            return 0
        # Stirling numbers of second kind via DP
        stir = [[0] * (t + 1) for _ in range(k + 1)]
        stir[0][0] = 1
        for i in range(1, k + 1):
            for j in range(1, min(i, t) + 1):
                stir[i][j] = (stir[i - 1][j - 1] + j * stir[i - 1][j]) % MOD
        return stir[k][t] * fact[t] % MOD

    for val, k in freq.items():
        ndp = [0] * (n + 1)
        for used in range(n + 1):
            if dp[used] == 0:
                continue
            for add in range(0, n - used + 1):
                t = used + add
                if t == 0:
                    continue
                w = ways(k, t)
                if w:
                    ndp[t] = (ndp[t] + dp[used] * w) % MOD
        dp = ndp

    print(sum(dp) % MOD)

if __name__ == "__main__":
    solve()
```DP 围绕处理每个值后有多少个不同的索引处于活动状态进行组织`c`。 对于每个值频率`k`，我们计算如何将其出现分配到`t`指数，其中`t`范围从已使用的索引到`n`。 这`ways(k, t)`函数计算满射`k`出现在`t`标记指数，通过第二类斯特林数乘以`t!`考虑标签。 

嵌套循环反映了从`used`索引到`used + add`指数，其中`add`对应于为当前价值组引入新指数。 

阶乘预计算支持高效的模块化组合学，而斯特林 DP 仍然可行，因为`k ≤ 10^4`但总的重新计算受值频率的限制。

```频率都是 1。我们从`dp[0] = 1`。

 ## 边缘情况

 当`n = 1`，DP 只允许单个活动索引。 每个值组都必须将所有出现的情况映射到该索引，因此斯特林转换会崩溃为单个配置。 该算法自然会强制执行此操作，因为`t`永远不会超过 1，因此不会发生分支到其他索引的情况。 

当所有`c[i]`是相同的，整个过程简化为将所有出现的情况分配到单个组结构中。 民主党永远不会从增加`used`超过 1，因为当所有项目的值都相同时，引入新指数不会产生额外的有效满射，因此模型正确地稳定在单状态演化。
