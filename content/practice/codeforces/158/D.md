 ## 解决方案
 ## 问题理解

 我们有`n`冰雕均匀地放置在一个圆圈上。 每个雕塑都有其价值，可能是正面的，也可能是负面的。 我们可以移除一些雕塑，但剩下的仍然必须形成正多边形。 

由于雕塑无法移动，因此剩余的顶点必须沿着原始圆等距分布。 这意味着如果我们保持`k`雕塑，那么`k`必须划分`n`，保留的雕塑是通过固定步长反复跳跃得到的。 

例如，如果`n = 12`我们保留 4 个雕塑，那么连续保留的雕塑之间的间距必须是`12 / 4 = 3`。 从任意位置开始重复添加 3 模 12 会生成一个有效的多边形。 

任务是最大化保留的雕塑价值的总和，同时保留至少 3 个雕塑。 

约束足够小，可以尝试许多除数`n`，但对于任何二次方来说太大了`n`。 自从`n ≤ 20000`， 一个`O(n^2)`在最坏的情况下，解决方案将执行大约 4 亿次操作，这在 Python 中太慢了。 解决方案围绕`O(n * d(n))`， 在哪里`d(n)`是除数的个数，很容易拟合。 

这个问题有几个容易犯的错误。 

一种常见的错误是仅检查连续的段。 其余的雕塑不需要在圆圈上保持相邻。 

考虑：```
8
1 2 -3 4 -5 5 2 3
```最好的答案是保留每一个雕塑：```
2 + 4 + 5 + 3 = 14
```连续子数组方法将完全忽略这种结构。 

另一个错误是忘记剩余的多边形必须至少有 3 个顶点。 

例子：```
6
100 -1 100 -1 100 -1
```只保留三个`100`s 有效并给出`300`。 保留两个顶点将给出`200`，但不允许使用 2 边形。 

处理循环步进时会出现一个更微妙的错误。 认为：```
5
1 2 3 4 5
```由于 5 是素数，因此唯一有效的多边形使用所有雕塑。 任何使用步长大小 2 或 3 的尝试仍然会访问每个顶点，因为这些步长与 5 互质。正确答案是`15`。 

粗心的实现有时会多次计算此类循环，或者错误地假设每个步骤都会创建一个较小的多边形。 

## 方法

 蛮力的想法很简单。 我们可以尝试雕塑的每个子集，并检查所选位置是否形成正多边形。 如果连续选定的顶点之间的间隙围绕圆相等，则子集有效。 

这在概念上是有效的，因为正多边形的定义非常严格。 不幸的是，有`2^n`子集，即使对于`n = 30`，更不用说`20000`。 

更结构化的蛮力观察到每个有效的多边形都对应于围绕圆重复进行固定大小的跳跃。 

假设跳跃大小为`d`。 从位置开始`s`，我们访问：```
s, s+d, s+2d, ...
```模数`n`。 

这样就形成了一个循环。 访问的不同顶点的数量等于：```
n / gcd(n, d)
```为了使多边形有效，我们至少需要 3 个顶点。 

现在搜索空间变得易于管理。 对于每个可能的步长，我们可以模拟每个起始位置并计算其周期的总和。 

关键的观察结果是，由相同步长产生的循环将圆划分为不相交的组。 如果`g = gcd(n, d)`，那么正好有`g`不同的周期，每个周期的长度`n / g`。 

我们不需要考虑任意多边形，而只需要考虑`n`。 

让`k`是保留的顶点数。 然后`k`必须划分`n`。 步长变为：```
step = n / k
```对于每个除数`k ≥ 3`，我们计算所有算术级数模的总和`n`使用该步长并保持最大值。 

一个数的约数个数可达`20000`很小，因此总功保持接近线性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力子集 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 除数循环枚举 | O(n × d(n)) | O(n × d(n)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取雕塑值数组。 
2. 将答案初始化为所有雕塑的总和。 

这已经对应于保留整个多边形，这始终是允许的。 

1. 枚举所有除数`k`的`n`这样`k ≥ 3`。 

这里，`k`表示剩余多边形的顶点数。 

1. 对于每个有效`k`，计算：```
step = n / k
```如果我们反复经过`step`，我们正好访问`k`返回起点之前的顶点。 

1. 对于每个起始位置`0`到`step - 1`，计算重复相加形成的循环之和`step`。 

每个起始位置都会为此除数生成一个不同的多边形配置。 

1. 用周期和更新全局最大值。 
2. 打印找到的最佳值。 

### 为什么它有效

 有效的剩余多边形必须由原始圆上等距的顶点组成。 如果多边形有`k`顶点，那么连续保留的顶点之间的间距必须恰好是`n / k`。 

从任何顶点开始并重复添加此间距模数`n`精确生成该多边形的顶点。 

相反，以这种方式生成的每个循环都会形成一个有效的正多边形，因为所有间隙都相等。 

该算法枚举每个可能的除数`k`以及该间距的每个可能的起始位置，因此每个有效的多边形都会被检查一次。 由于我们计算每个候选者的精确总和并保留最大值，因此最终答案是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    ans = sum(a)

    for k in range(3, n + 1):
        if n % k != 0:
            continue

        step = n // k

        for start in range(step):
            cur = 0
            pos = start

            for _ in range(k):
                cur += a[pos]
                pos += step

            ans = max(ans, cur)

    print(ans)

solve()
```该解决方案直接遵循有效多边形的数学结构。 

外循环迭代所有可能的多边形大小`k`。 仅有约数`n`是有效的，因为等间距的顶点必须完美地环绕圆。 

对于固定的`k`，跳跃大小为`step = n // k`。 从任意索引开始，重复添加`step`精确访问一个候选多边形的顶点。 

范围`0 .. step-1`对于起始位置来说足够了，因为较大的起始位置会重复相同的循环。 这是一种微妙的优化，可以避免重复工作。 

在最里面的循环中，我们准确地收集`k`元素。 自从`k * step = n`，我们在恰好之后返回到起始位置`k`跳跃。 

另一个细节是这里不需要模运算。 因为`pos`增加了`step`确切地`k`次，最大访问索引为：```
start + (k - 1) * step < n
```所以每次访问都在界限之内。

 ## 边缘情况

 考虑所有值为负数的情况：```
4
-1 -2 -3 -4
```一个粗心的解决方案可能会试图只保留一件有价值的雕塑`-1`，但少于 3 个顶点的多边形无效。 

该算法仅检查除数`k ≥ 3`。 

为了`k = 4`:```
sum = -10
```不存在其他有效的多边形，所以答案是`-10`。 

现在考虑素数个雕塑：```
5
1 2 3 4 5
```5 的唯一约数是 1 和 5。由于我们需要至少 3 个顶点，因此`k = 5`被考虑。 

该算法计算：```
1 + 2 + 3 + 4 + 5 = 15
```这正确地处理了以下事实：每个非零步长以素数为模遍历整个圆。 

最后，考虑重复循环：```
8
1 2 -3 4 -5 5 2 3
```为了`k = 4`，步长为2。 

大于 1 的起始位置将重复现有循环：```
0 -> 2 -> 4 -> 6
1 -> 3 -> 5 -> 7
```该算法仅迭代开始于`[0, step-1]`，因此每个不同的多边形都会被处理一次。
