 ## 解决方案
 ## 问题理解

 我们被要求安排一天给杰克逊先生打电话，以最大限度地延长最长的不间断睡眠时间。 每个呼叫都有特定的开始时间和持续时间。 如果他正忙时有呼叫到达，则该呼叫会排队并在完成当前呼叫后立即处理。 Jackson 先生最多可以忽略 _k_ 个电话。 我们的目标是找到一天中他既不说话也不排队说话的最大连续时间段。 

输入保证调用次数最多为 4000 次，每次调用时间和持续时间在一天 86400 秒内。 这个界限足够小，以至于具有大约 O(n²) 运算的算法是可以接受的。 然而，尝试被忽略的调用的每种组合的天真的方法（这将是 O(2ⁿ)）是不可能的。 每个呼叫都有唯一的开始时间，但持续时间可能会重叠，因此我们必须小心处理排队问题。 

当忽略呼叫是最佳选择时，即使对于不重叠的呼叫，也会出现不明显的边缘情况。 例如，如果在时间 100、200、300 处有 3 个调用，每个调用的持续时间为 100，并且 _k_ = 2，则通过忽略前两个调用来实现最大睡眠，从而产生从 1 到 99 的长时间睡眠。仅忽略重叠调用的粗心算法将产生更小的睡眠周期。 

另一个边缘情况是忽略呼叫必须与排队呼叫进行平衡。 例如，较晚的调用可能会不必要地延长队列，如果我们忽略较早的错误调用，则会减少潜在的睡眠时间。 

## 方法

 强力方法将尝试忽略所有呼叫子集、模拟呼叫处理并测量最长的空闲段。 这是正确的，但当 n ≤ 4000 时，子集 2ⁿ 的数量是天文数字，完全不可行。 

一个关键的观察是处理排队呼叫的顺序是确定的。 一旦我们决定忽略哪些调用，剩余的调用就会按时间递增的顺序处理，并且排队的调用总是在完成当前调用后立即处理。 这表明动态编程：我们可以维护一个 DP 状态，表示处理前 i 个调用和 j 个被忽略的调用后的最早时间。 令 dp[i][j] 表示 Jackson 先生在处理前 i 个呼叫（同时忽略 j 个呼叫）后最早空闲的时刻。 如果我们正常处理下一个调用，则转换到 dp[i+1][j] 会发生，由于排队，下一个调用可能会稍后开始，如果我们忽略该调用，则会发生 dp[i+1][j+1] 。 那么最大睡眠就是根据该 DP 计算出的连续繁忙间隔之间的最大间隙。 

这将问题从指数时间减少到 O(n * k) 时间，这是可以接受的，因为 n 和 k ≤ 4000。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2ⁿ) | O(n) | 太慢了 |
 | 动态规划| O(n * k) | O(n * k) | 已接受 |

 ## 算法演练

1. 按开始时间对通话进行排序。 这已经由输入保证，但为了清楚起见，我们将其包括在内。 
2.初始化DP表dp[i][j]，其中i的范围从0到n，代表考虑的前i个呼叫，j的范围从0到k，代表被忽略的呼叫的数量。 将除 dp[0][0] = 0 之外的所有条目设置为无穷大，这意味着在当天开始时没有处理任何呼叫，并且 Jackson 先生在时间 0 空闲。 
3. 对于每个呼叫 i（从 0 到 n-1）和每个可能被忽略的呼叫数 j（从 0 到 k），更新下一次呼叫的 DP 表。 如果我们进行呼叫 i，则下一个空闲时间是当前 dp[i][j]（当我们完成之前的呼叫时）和 t[i]（当前呼叫的预定开始时间）的最大值加上其持续时间。 将 dp[i+1][j] 设置为其当前值和下一个空闲时间的最小值。 如果我们忽略调用 i 且 j < k，则将 dp[i+1][j+1] 更新为其当前值和 dp[i][j] 的最小值。 
4. 处理完所有调用后，收集 0 ≤ j ≤ k 的所有结束时间 dp[n][j]。 这些时间代表处理所有忽略 j 的呼叫后的最早空闲时间。 
5. 要计算最大睡眠时间，请注意睡眠可以从 1（第一秒）开始，也可以在任何调用结束后开始。 考虑连续繁忙时段之间的间隙：dp[i-1][j] 与下一次呼叫开始之间，以及最后一个繁忙时间与 86400 当天结束之间。返回此类间隔的最大值。 

工作原理：DP 维护一个不变量，即 dp[i][j] 是处理第一个 i 调用且正好 j 个被忽略的调用后的最早时间。 在每一步中，我们都会探索接听电话或在可能的情况下忽略它，因此涵盖了尊重忽略限制的所有可行场景。 由于转换总是占用尽可能早的空闲时间，因此根据这些时间之间的间隙计算出的最大睡眠时间保证是最佳的连续睡眠周期。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
calls = [tuple(map(int, input().split())) for _ in range(n)]

INF = 10**9
dp = [[INF] * (k + 1) for _ in range(n + 1)]
dp[0][0] = 0

for i in range(n):
    t_i, d_i = calls[i]
    for j in range(k + 1):
        if dp[i][j] < INF:
            # take the call
            dp[i+1][j] = min(dp[i+1][j], max(dp[i][j], t_i) + d_i)
            # ignore the call
            if j + 1 <= k:
                dp[i+1][j+1] = min(dp[i+1][j+1], dp[i][j])

max_sleep = 0
for j in range(k + 1):
    end_time = dp[n][j]
    max_sleep = max(max_sleep, 86400 - end_time)

# also consider sleep before the first call
first_times = [calls[0][0]] + [0]
for j in range(k + 1):
    if dp[0][j] == 0:
        max_sleep = max(max_sleep, calls[0][0] - 1)

print(max_sleep)
```此代码将 DP 表初始化为无穷大，并将起始状态设置为 0。对于每个呼叫和忽略计数，它模拟接听或忽略呼叫。 睡眠时间计算为最后一次忙碌时间与当天结束之间的最大间隔，同时还考虑了第一次呼叫之前的睡眠时间。 边界条件经过仔细处理：采用 max(dp[i][j], t[i]) 确保遵守排队，并且忽略调用仅在限制 k 内递增 j。
