 ## 解决方案
 ## 问题理解

 我们有一群学生分成小组，每个小组都想一起乘坐出租车。 每个团体可容纳 1 至 4 名儿童，每辆出租车最多可搭载 4 名儿童。 目标是确定运送所有团体所需的出租车的最低数量，同时尊重团体不能分散在出租车上，但如果多个团体的总人数不超过四人，则可以共享一辆出租车。 

输入由组数组成，后跟每个组的大小。 输出是一个整数，表示所需出租车的最小数量。 

关键限制是最多可以有 100,000 个组，并且时间限制为 3 秒。 这意味着我们不能承受比组数量的线性时间更糟糕的事情。 尝试所有分组组合的二次或简单方法会太慢，因为可能的组合数量随着组数呈指数增长。 

要考虑的边缘情况包括所有组的规模均为四的场景，这将迫使每个组一辆出租车，以及所有组的规模为一的场景，这允许完美地挤进四辆出租车。 另一个微妙的情况是组大小的混合，使得贪婪打包变得不平凡 - 例如，三个一组和两个一组不能组合在一起，因此组合顺序很重要。 

## 方法

 暴力方法将尝试尝试组的所有排列，并尝试以所有可能的顺序将它们打包到出租车中。 这是正确的，因为它探索了每种配置，但对于 n 高达 100,000 的情况在计算上是不可行的。 即使每个排列检查都是线性的，排列的阶乘增长也使其变得不可能。 

关键的见解是这些组只有四种可能的大小。 这个有限的范围允许基于频率的方法。 我们可以计算每种大小有多少个组，并以最佳方式组合它们。 四人团体总是自己乘坐出租车。 如果有的话，三号组可以与一号组配对。 尺寸为 2 的组可以与另一组尺寸为 2 的组配对，或者最多与两组尺寸为 1 的组配对。 最后，剩余的大小为 1 的组可以合并为 4 个。 问题的结构允许采用贪婪策略：首先处理最大的组，然后用较小的组填充剩余空间。 这保证了最少的出租车，因为较大的团体是限制因素，而较小的团体可以在不违反限制的情况下填补空白。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最优（频率+贪婪）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 计算从 1 到 4 的每个大小的组有多少个。这为我们提供了一个小的频率表，可用于贪婪决策。 
2. 每四人一组需要单独的出租车。 将出租车柜台增加四号组的数量。 
3. 如果可能，将每组尺寸为 3 的组与一组尺寸为 1 的组配对。 对于每一对，增加出租车计数器并相应地减少 1 号组的计数。 如果一号组不够，三号组仍单独乘坐出租车。 
4. 将两人组配对。 每对两个尺寸的组正好适合出租车。 如果剩下一组奇数尺寸为 2 的组，则最多可以将其与两组尺寸为 1 的组配对。 相应地增加出租车计数器并减少一号组。 如果没有留下一号组，则由二号组单独占用一辆出租车。 
5. 最后，处理剩余的第一组。 每辆出租车可以共享四辆出租车。 将剩余出租车数量的上限除以四来计算出租车数量。 
6. 在这些步骤中计算出的所有出租车的总和给出了所需出租车的最少数量。 

为什么它有效：不变的是，在每一步中，我们都会最大限度地用最大的剩余组来填充出租车，然后才使用较小的组来填补空白。 由于组大小限制为 1 到 4，因此不存在以不同方式组合会减少出租车总数的配置，从而使这种贪婪方法成为最佳选择。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
sizes = list(map(int, input().split()))

count = [0] * 5  # index 0 unused
for s in sizes:
    count[s] += 1

taxis = 0

# size 4 groups
taxis += count[4]

# size 3 groups + size 1 groups
pair_3_1 = min(count[3], count[1])
taxis += pair_3_1
count[3] -= pair_3_1
count[1] -= pair_3_1

# remaining size 3 groups
taxis += count[3]

# size 2 groups
taxis += count[2] // 2
if count[2] % 2:
    taxis += 1
    count[1] -= min(2, count[1])

# size 1 groups
if count[1] > 0:
    taxis += (count[1] + 3) // 4  # ceil division

print(taxis)
```该代码为每个大小的组初始化一个频率数组。 它直接计算四人一组所需的出租车数量，然后将三人组与三人组配对以优化空间利用率。 剩下的三三两两的人会被仔细处理，剩下的最后装满出租车。 天花板除法可以有效地处理剩余的，并且除了初始计数之外的所有操作都是恒定时间的，从而提供线性时间复杂度。
