 ## 解决方案
 ## 问题理解

 我们得到了编程竞赛的最终排名。 分数已按非递增顺序排序，这意味着每个参与者的分数大于或等于下一个参与者。 

如果满足两个条件，参与者将进入下一轮。 他们的分数必须至少与当前排名第 k 的参与者的分数一样大，并且他们的分数必须为正。 

任务是计算有多少参与者满足这两个条件。 

限制非常小。 最多有 50 名参与者，因此即使是简单的线性扫描也绰绰有余。 任何时间复杂度高达 O(n²) 的算法都可以轻松满足该限制。 这个问题主要是仔细执行而不是优化。 

棘手的部分是正确处理第 k 个位置周围的零分和平局。 

考虑这个例子：```
5 3
10 5 0 0 0
```第三个参与者的得分为 0。粗心的解决方案可能会计算得分大于或等于 0 的每个人，结果为 5。这是错误的，因为参与者也必须有正分。 正确答案是2。 

当许多参与者与第 k 个参与者得分相同时，就会出现另一个微妙的情况。```
8 5
10 9 8 7 7 7 5 5
```第五名的参赛者得分为 7。得分为 7 或更高的所有人晋级，包括第六名参赛者。 正确答案是 6。错误的实现可能只是输出 k，这会错过绑定的参与者。 

另一种边缘情况是可能的最小输入：```
1 1
0
```唯一的参与者得分为 0，因此没有人晋级。 答案是 0，而不是 1。 

## 方法

 最直接的做法就是对每一位参赛者进行检查，检查他们是否符合比赛规则。 我们首先找到第 k 个参与者的分数，然后计算有多少分数既为正值又至少达到该阈值。 

这种蛮力方法已经完全可以接受，因为 n 最多为 50。在最坏的情况下，我们执行大约 50 次比较，这实际上是瞬时的。 

不需要更复杂的方法，因为输入已经排序。 我们需要的唯一观察是第 k 个参与者定义最低资格分数。 一旦我们知道了这个值，就可以独立检查每个参与者。 

暴力破解之所以有效，是因为资格规则仅取决于一个固定阈值。 不需要搜索、排序或额外的数据结构。 一次线性扫描就足够了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取整数`n`和`k`。 
2. 读取分数数组。 
3. 求第 k 位参与者的得分。 由于 Python 使用基于 0 的索引，因此该值为`scores[k - 1]`。 
4. 将计数器初始化为 0。 
5. 迭代数组中的每个分数。 
6. 对于每个分数，检查两个条件：

 1. 分数大于或等于第k个分数。 
2. 分数严格大于0。 
7. 如果两个条件都成立，则递增计数器。 
8. 打印最终计数器。 

第二个条件是必要的，因为得分为 0 的参与者永远不会晋级，即使第 k 个参与者也得分为 0。 

### 为什么它有效

 第 k 位参与者确定获得资格所需的最低分数。 任何分数较小的参赛者都无法晋级。 任何得分相同或更高的参与者都符合资格，只要他们的得分为正。 

该算法为每个参与者准确检查这两条规则。 由于每个符合资格的参与者都会被计算一次，而每个不符合资格的参与者都会被忽略，因此最终的计数是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
scores = list(map(int, input().split()))

threshold = scores[k - 1]

answer = 0

for score in scores:
    if score >= threshold and score > 0:
        answer += 1

print(answer)
```该计划首先读取参与者人数和资格位置。 分数存储在列表中。 

变量`threshold`存储第 k 个参与者的分数。 这是晋升所需的最低分数。 

该循环独立地处理每个参与者。 条件：```
score >= threshold and score > 0
```完全符合比赛规则。 

第一部分正确处理关系。 如果多个参与者与第 k 个参与者得分相同，则所有参与者都被计算在内。 

第二部分阻止零分参与者晋级。 这是最容易出错的细节。 

实现使用`k - 1`因为Python列表是从0开始索引的，而竞赛位置是从1开始的。

import sys, io

def solve():
    input = sys.stdin.readline

    n, k = map(int, input().split())

    threshold = scores[k - 1]

    ans = 0

    for score in scores:
        if score >= threshold and score > 0:
            ans += 1

    print(ans)

    backup_stdout = sys.stdout

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output

 ## 边缘情况

 考虑第 k 个参与者得分为 0 的情况。 

输入：```
5 3
10 5 0 0 0
```阈值变为 0，因为第三名的参与者得分为 0。 

该算法检查每个参与者：```
10 >= 0 and 10 > 0  -> counted
5 >= 0 and 5 > 0    -> counted
0 >= 0 and 0 > 0    -> not counted
```最终答案是2。额外的`score > 0`条件可防止错误计数。 

现在考虑截止点周围的关系。 

输入：```
8 5
10 9 8 7 7 7 5 5
```阈值是 7。算法会计算分数至少为 7 的每个参与者。 

其中包括排名第六的参与者，因为：```
7 >= 7 and 7 > 0
```是真的。 

最终答案变为 6，这可以正确处理平局分数。 

最后，检查尽可能小的输入。 

输入：```
1 1
0
```阈值为 0。唯一的参与者不符合正分条件，因此计数器永远不会增加。 输出为0，完全符合规则。
