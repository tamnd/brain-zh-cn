 ## 解决方案
 ## 问题理解

 我们被赋予了一个物品系统，其中每个物品如果在开始时直接选择或可以通过配方生产，最终都会变得“充满活力”。 每个配方采用多个输入项并产生一个输出项，其规则是仅当所有输入都已通电时输出才会通电。 

最初，没有任何物品通电。 我们可以手动为某些项目供电。 完成后，我们重复应用所有输入完全通电的配方，并且这些输出也通电。 该过程持续进行，直到没有更多的项目可以被激活。 

问题在于我们实际上并不知道食谱的结构。 我们只知道有 n 个物品和 m 个食谱，并且我们必须假设食谱的最佳排列方式，以尽量减少我们最初激活的物品数量。 目标是计算这个最小可能数字。 

约束 n 最大为 2×10^5，m 最大为 n 意味着我们需要线性或近线性解决方案。 n 中的任何二次方都会立即失败，因为即使是 10^10 次操作也远远超出了时间限制。 

当 m 为零时，会出现微妙的边缘情况。 如果没有配方，就无法生产任何东西，因此每个项目都必须手动通电，给出答案 n。 另一个边缘情况是，配方足够丰富，有可能将所有内容连接到单个派生链中，在这种情况下，答案应降至 1。 

关键的困难在于了解配方在优化设计下可以提供多少“合并能力”。 

## 方法

 我们从最悲观的观点开始：如果没有食谱，每件物品都是孤立的。 激活一切的唯一方法是手动选择所有 n 项，所以答案是 n。 

现在考虑一下菜谱在最佳情况下的实际作用。 如果我们自由设计配方，我们总是希望它们在先决条件方面尽可能简单。 具有多个输入的配方实际上更难满足，因为它要求所有输入都已处于活动状态。 相比之下，具有单个输入的配方的行为就像从一个项目到另一个项目的有向边：一旦第一个项目处于活动状态，第二个项目就会立即变为活动状态。 

这一观察是关键的简化。 在最佳结构中，每个配方都可以被视为从一个项目到另一个项目的有向边。 该问题简化为在 n 个节点上选择 m 个有向边，以最小化所需的起始节点数量，以便所有节点在沿着有向边的可达性下变得可达。 

现在结构变得熟悉了。 我们试图最大限度地减少覆盖有向森林结构中所有节点所需的源数量。 每条有向边最多可以减少一个独立起始组件的数量，因为它可以将以前独立的节点连接到现有的可达链中。 

因此，如果我们从 n 个孤立的节点开始，在最好的情况下，每个配方都可以将所需的起始点数量减少 1 个。 使用 m 个这样的归约后，所需的起始点数量变为 n - m。 如果 m 足够大到低于 1，我们仍然需要至少一个起始节点，因为某些节点必须首先通电。 

这直接导出公式 max(1, n - m)。

 ## 算法演练

1. 从输入中读取 n 和 m。 这些描述了存在多少项目以及我们可以优化设计多少食谱。 
2. 如果没有菜谱，则返回n。 由于没有可用的转换，每个项目都必须首先通电。 
3. 否则，将每个配方以其最有效的形式解释为两个项目之间的单个定向依赖关系。 这是使传播效率最大化的配置。 
4. 从想法开始，每个项目最初形成自己独立的需求，因此有n个所需的起点。 
5. 每个配方都可以将一个先前独立的项目合并到一个可达的结构中，从而将所需的起始点数量减少一个。 最佳使用所有 m 个配方后，计数变为 n - m。 
6. 如果该值低于 1，则将其限制为 1，因为至少需要一个初始通电项目才能触发任何传播。 

### 为什么它有效

 该过程可以被视为逐渐减少覆盖该图所需的独立“激活源”的数量。 每个配方在优化设计为单个先决条件规则时，都可以将一个以前无法访问的组件附加到现有的可访问结构中。 由于配方无法从无到有地创造激活，因此它们只能传播现有的能量，而不能完全消除对起点的需要。 这意味着每个配方的独立启动组件的总数最多减少一个，并且这个限制可以通过构造链状依赖结构来实现。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    ans = n - m
    if ans < 1:
        ans = 1
    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案依赖于这样一个事实：我们永远不需要显式构造配方图。 答案仅取决于 m 相对于初始 n 个孤立项目可以实现多少个独立缩减。 减法捕获了有多少项可以被吸收到依赖链中，并且最终的限制确保我们不会完全消除对起始种子的需要。 

一个常见的错误是尝试模拟配方或构建实际的图表，这是不必要的，并且会在不改变最终组合结构的情况下引入开销。

 ## 边缘情况

 当n为1时，只有一项，无论m如何，都必须通电。 该公式给出 max(1, 1 - m)，其计算结果始终为 1，符合要求。 

当 m 为零时，不可能进行传播，并且必须首先选择每个项目。 该公式给出 max(1, n)，对于任何 n ≥ 1，它都会正确返回 n。 

当 m 相对于 n 非常大时，减法 n - m 变为负值，但钳位确保答案永远不会低于 1，这反映了这样一个事实：启动任何推导链始终需要至少一个起始项。
