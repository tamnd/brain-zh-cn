 ## 解决方案
 ## 问题理解

 我们给出了一个高度完美的满二叉树$n$。 这意味着这棵树有$n$水平，根位于水平$n$，每个内部节点恰好有两个子节点，并且所有叶子都处于水平状态$1$。 每片叶子都被分配$0$或者$1$。 每个内部节点都对其两个子节点进行异或运算。 

一旦值在叶子上固定，树中的每个节点就变得确定性$0$或者$1$。 任务是选择叶子值，以使树中所有节点的值之和尽可能大。 

输入由许多独立的查询组成，每个查询给出一个高度$n$。 对于每个查询，我们必须输出所有节点上的最大可能总和，取模$998244353$。 

关键的结构性限制是$n$可以大到$10^{18}$，因此任何显式模拟树甚至迭代级别的解决方案都是不可能的。 答案必须可以用封闭的形式表达，或者可以用每个查询的对数时间来计算。 

一个微妙的点是，虽然节点数量呈指数级增长，但结构却极其规则：每个内部节点都代表大小为 2 的幂的连续叶子块的异或。 这意味着每个节点的值仅取决于其子树中 1 数量的奇偶校验。 

经常出现的一个天真的误解是认为内部节点可以独立优化。 例如，人们可能会尝试将每个子树的根设置为$1$贪婪地，但这忽略了重叠约束之间的一致性：叶子选择同时影响许多节点。 

边缘情况来自较低的高度。 为了$n=1$，只有一个节点，答案很明显$1$。 为了$n=2$，我们有三个节点，最佳可实现的总和是$2$。 为了$n=3$，该结构变得不平凡，并且已经需要跨多个级别协调叶分配。 

## 方法

 暴力方法会枚举所有$2^{2^{n-1}}$叶值的分配，计算每个分配的结果异或树，并取最大总和。 即使计算单个配置成本$O(2^n)$，所以即使对于$n=5$。 

一个更现实的天真的想法是对子树进行动态编程，尝试跟踪每个子树高度的可能配置。 然而，状态空间仍然会爆炸，因为子树是由其整个叶子分配决定的，而不仅仅是单个位。 

关键的见解是停止考虑单个节点，而是考虑树的级别。 每个级别都由不相交的叶段组成，该级别的每个节点只是其段的异或。 那么问题就变成了：选择一个长度的二进制数组$2^{n-1}$，并最大化其 XOR 为的二进区间（对应于树节点的区间）总数$1$。 

这将问题转化为所有二次幂部分的结构化组合优化。 关键的观察结果是，最优解决方案具有递归模式：高度树的贡献$n$可以用树的高度来表示$n-2$，因为级别以允许每隔一层进行独立优化的方式交替。 

这导致简单的递归并最终形成封闭的形式。

 ## 算法演练

 ### 最佳想法

 我们观察到每个节点对应一段长度$2^k$，其值是该段的异或。 所以每个节点贡献要么$0$或者$1$取决于该段是否包含奇数个。 

目标是选择叶数组以最大化其 XOR 为的段数（在所有级别上）$1$。 

### 关键结构观察

 1. 底层（叶子）直接贡献数组中的个数。 
2. 下一级小组成对离开。 每对贡献$1$如果这两个位不同。 
3. 较高级别在较大块上重复此模式。 

重要的约束是叶级别的选择同时影响其之上的所有级别。 

### 递归结构

 我们定义$f(n)$作为高度的最大可能总和$n$。 

我们将树分成大小的块$2^{n-2}$比较水平交互时。 最优构造交替影响每两个级别，从而导致递归：$$f(n) = f(n-2) + 2^{n-1}$$直觉是，级别中可实现的最佳贡献$n-1$占主导地位，其余结构的行为就像一个独立的较小高度的树$n-2$。 

### 基本情况

 我们直接计算：$f(1) = 1$

$f(2) = 2$由此，递归完全决定了所有值。 

### 封闭形式

 展开递归：$$f(n) = 2^{n-1} + 2^{n-3} + 2^{n-5} + \cdots$$所以我们用步骤 2 将 2 的幂相加。 

如果$n = 2m$：$$f(n) = 2^{2m-1} + 2^{2m-3} + \cdots + 2^1 = \frac{2^{n+1} - 2}{3}$$如果$n = 2m+1$：$$f(n) = 2^{2m} + 2^{2m-2} + \cdots + 2^0 = \frac{2^{n+1} - 1}{3}$$### 为什么它有效

 递归之所以成立，是因为一旦前一层得到最佳固定，每个第二层的贡献就可以彼此独立地进行优化。 该树每两层分裂成相同的子结构，并且最佳配置以一致的模式重复。 这可以防止超出两级边界的任何跨级干扰，这就是解压缩为几何级数的原因。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())

        p = modpow(2, n + 1)

        if n % 2 == 0:
            ans = (p - 2) * pow(3, MOD - 2, MOD)
        else:
            ans = (p - 1) * pow(3, MOD - 2, MOD)

        print(ans % MOD)

if __name__ == "__main__":
    solve()
```实现直接应用封闭形式。 唯一的微妙之处是处理模块化划分$3$，这是使用模逆来完成的$998244353$。 

求幂计算$2^{n+1}$甚至有效地$n$最多$10^{18}$。 奇偶性为$n$在两个封闭形式之间进行选择。 

这里的一个常见错误是忘记减法必须以模进行$MOD$，特别是在偶数情况下$2^{n+1} - 2$在正常化之前可能会变为负值。

 ## 边缘情况

 对于$n=1$，树折叠成单个节点。 公式给出：$$\frac{2^2 - 1}{3} = 1$$它匹配唯一可能的分配。 

为了$n=2$，该结构具有三个节点。 公式给出：$$\frac{2^3 - 2}{3} = 2$$这与可实现的最佳配置相匹配，其中可以制作两个节点$1$。 

对于大型$n$，直接求幂是唯一可行的计算方法。 递归确保没有溢出或结构模糊，并且基于奇偶校验的分割可以正确处理所有交替层，而无需特殊情况的更深树行为。
