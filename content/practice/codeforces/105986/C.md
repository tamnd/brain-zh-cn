 ## 解决方案
 ## 问题理解

 我们给出了一个具有尺寸的矩形网格$n \times m$。 在这个网格上，有$k$矿田。 每个矿区由一个中心单元定义$(x_i, y_i)$和切比雪夫半径$dis_i$，这意味着它占据行和列都在其中的每个网格单元$dis_i$的中心。 从几何角度来看，每个字段都是一个以实心轴对齐的正方形，中心位于$(x_i, y_i)$。 

我们想要放置一个发射平台，也以一些网格单元为中心$(x, y)$，但这一次它的影响是由曼哈顿距离定义的：它占据了曼哈顿距离的所有单元格$(x, y)$至多是$D$。 关键的限制是这些平台单元都不允许与任何矿场单元重叠。 平台中心必须位于网格内部，但占用区域允许延伸到外部。 

任务是选择任何有效的中心$(x, y)$并最大化$D$。 如果没有中心允许零半径平台，我们输出 -1。 

限制因素$n, m, k \le 500$暗示直到$2.5 \times 10^5$网格单元和 500 平方的障碍物。 对所有可能的中心和半径的直接模拟已经很严格，但如果每次检查都很有效，则可以管理。 真正的困难是避免重复计算大型几何区域之间的重叠检查。 

当矿区覆盖整个网格时，就会出现微妙的边缘情况。 在这种情况下，即使是零半径平台也会与各处的占用单元相交，因此不存在有效的中心，答案必须为 -1。 另一种边缘情况是存在至少一个完全空闲的单元； 那么答案至少为 0，但最佳半径以一种不明显的方式取决于到最近的阻塞单元的距离，因为形状不同：切比雪夫正方形与曼哈顿菱形。 

## 方法

 一个天真的想法是修复一个候选中心$(x, y)$，然后增加$D$直到曼哈顿钻石与任何矿物方块相交。 每次检查都需要扫描所有矿场并验证其占用的方块是否与当前钻石相交，这已经很昂贵了。 自从$D$可以长大到$n+m$，并且有$O(nm)$中心，这变得太慢了。 

观察的关键是倒转观点。 我们不是扩展菱形并检查固定方块，而是询问每个网格单元与曼哈顿度量中最近的禁区的距离有多近。 如果我们可以标记所有被矿田占据的单元格，那么问题就变成：对于每个空闲单元格，计算到任何被占用单元格的最小曼哈顿距离。 该值正是最大有效值$D$一个以那里为中心的平台。 

因此，整个问题简化为构建一个禁止单元的二进制网格，然后在曼哈顿距离上运行一个多源 BFS。 所有矿物方块都是源，BFS 在网格上扩展，计算到任何禁止单元的最小距离。 矿田内的单元距离为零，自由单元继承到曼哈顿度量中最近的禁止单元边界的距离。 答案是所有空闲单元中的最大值。 

唯一的复杂之处是如何有效地构建禁止网格。 每个矿田都是一个切比雪夫正方形，因此我们可以使用二维差分数组来标记其矩形$O(1)$每个字段，然后进行前缀求和以获得最终的覆盖范围。 之后，BFS 就很简单了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每个中心和半径的强力 |$O(nm \cdot k \cdot (n+m))$|$O(1)$| 太慢了 |
 | 网格标记+多源BFS |$O(nm + k)$|$O(nm)$| 已接受 |

 ## 算法演练

 我们首先构建一个网格，告诉我们哪些单元格被至少一个矿田占据。 每个矿场都是一个轴对齐的正方形，因此我们使用二维差分数组在其矩形上添加 +1，然后通过前缀和恢复覆盖范围。 

一旦我们知道了所有被占用的单元，我们就用每个被占用的单元初始化一个 BFS 队列，每个单元的距离为 0。这将所有矿物覆盖的单元视为污染源。 

然后，我们在四邻居网格上运行标准的多源 BFS。 每次我们从一个单元格扩展到相邻的空闲单元格时，我们都会为其分配一个等于父距离加一的距离（如果尚未访问过该单元格）。 该距离表示到最近的占用单元格的曼哈顿距离。 

BFS 完成后，每个单元与任何矿场单元都有其最小曼哈顿距离。 

最后，我们扫描所有未被占用的单元格并取最大距离值。 该值是最大可能的半径$D$一个以那里为中心的平台。 

如果没有未被占用的单元格，我们输出-1。 

其工作原理是，网格边缘上的 BFS 计算曼哈顿图中的最短路径距离，并且由于每个矿物单元都是源，因此每个自由单元都标记有到其最近的禁止单元的距离。 半径平台$D$当曼哈顿距离内没有禁止单元格时，以某个单元格为中心是有效的$D$，这相当于说最近的禁止单元的距离严格大于$D$。 因此最好的可能$D$正是所有有效中心之间的最大最短路径距离。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    
    diff = [[0] * (m + 2) for _ in range(n + 2)]

    for _ in range(k):
        x, y, d = map(int, input().split())
        x0, x1 = max(1, x - d), min(n, x + d)
        y0, y1 = max(1, y - d), min(m, y + d)
        diff[x0][y0] += 1
        diff[x1 + 1][y0] -= 1
        diff[x0][y1 + 1] -= 1
        diff[x1 + 1][y1 + 1] += 1

    grid = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            grid[i][j] = (diff[i][j]
                          + grid[i - 1][j]
                          + grid[i][j - 1]
                          - grid[i - 1][j - 1])

    from collections import deque
    dist = [[-1] * (m + 1) for _ in range(n + 1)]
    q = deque()

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if grid[i][j] > 0:
                dist[i][j] = 0
                q.append((i, j))

    if len(q) == n * m:
        print(-1)
        return

    directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

    while q:
        x, y = q.popleft()
        for dx, dy in directions:
            nx, ny = x + dx, y + dy
            if 1 <= nx <= n and 1 <= ny <= m and dist[nx][ny] == -1:
                dist[nx][ny] = dist[x][y] + 1
                q.append((nx, ny))

    ans = 0
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if grid[i][j] == 0:
                ans = max(ans, dist[i][j])

    print(ans if ans > 0 else 0)

if __name__ == "__main__":
    solve()
```该解决方案首先将每个矿场转换为矩形更新。 前缀和重构确保每个单元知道它是否属于至少一个方格。 之后，BFS 用所有占用的单元进行播种，这至关重要，因为它将多源距离问题转化为单次遍历。 

距离数组存储网格图中的曼哈顿距离。 最终扫描仅考虑未占用的单元，因为根据定义，在已占用的单元上启动是无效的。 答案是有效中心之间的最大距离。 

早期检查完全覆盖的网格可以防止不必要的 BFS 并处理“-1”情况。

 ## 边缘情况

 完全覆盖的网格是最微妙的情况，因为 BFS 仍然运行但不会产生有效的中心。 该算法通过在初始化期间对源进行计数来显式处理它； 当每个单元格都是源时，它立即返回-1，而不扫描距离。 

没有矿田的网格是相反的极端。 在这种情况下，BFS 从一个空队列开始，但实现通过将所有单元视为空闲并将距离保留为 -1 来避免这种情况。 正确的解释是每个单元格都是有效的，并且答案为 0，因为不存在禁止区域，并且实现通过在最终扫描后默认为 0 来解决此问题。 

1×1等小网格测试边界条件是否处理正确。 如果唯一的单元被占用，提前退出会正确触发； 否则它产生距离 0。
