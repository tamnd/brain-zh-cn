 ## 解决方案
 ## 问题理解

 我们得到了以下数字的排列$1$到$n$排列成一行。 在每一轮中，都会根据当地规则删除一些人：只有当一个人的标签不严格小于至少一个当前邻居时，一个人才能生存。 否则，他们将在该轮中被移除。 移除后，队伍会压缩，并再次应用相同的规则，直到只剩下一个人。 

一旦初始顺序固定，该过程就是确定性的，任务是计算需要多少轮，直到系统崩溃为单个元素。 

约束条件$n \le 10^5$迫使$O(n \log n)$或者$O(n)$解决方案。 任何每轮重新计算邻居关系或重新扫描数组的模拟都太慢，因为在最坏的情况下，我们每轮只能删除几个元素，但仍然具有线性轮次，从而产生二次行为。 

当排列严格递增或严格递减时，会出现微妙的边缘情况。 在像这样的完全递增数组中$[1,2,3,4]$，除了最后一个元素之外的所有元素都在第一轮中被删除，所以答案是$1$。 在严格递减的数组中，例如$[4,3,2,1]$，只有第一个元素在第一轮中幸存下来，但随后结构发生了变化，并且该过程继续进行，因此，如果没有精确的不变量，关于“逐层剥离极端”的天真的直觉是不够的。 

另一个极端情况很小$n$。 为了$n=1$，超出最终状态不需要进行任何回合，答案是$0$或者$1$取决于解释； 在此过程立即结束，无需任何淘汰赛。 

## 方法

 直接模拟很容易想象：重复扫描数组，标记所有小于至少一个邻居的元素，删除它们，然后压缩数组。 每轮费用$O(n)$，在最坏的情况下，每轮只有一个元素可能存活，给出$O(n^2)$总时间。 这失败了$n=10^5$。 

关键的观察是，该过程仅取决于每个元素与其最近的幸存更强邻居相比的相对“强度”。 每个元素都会有效地生存，直到它被不大于它的元素从两侧“控制”为止。 我们可以考虑每个值在暴露之前需要“传播”多远，而不是模拟删除。 

一种更具结构性的看待它的方式是将排列解释为引发定向影响：较大的值保护其后面较小的值。 轮数等于每个要消除的元素所需的最大层数，这变成了从局部最大值计算单调传播深度。 

这导致基于堆栈的分解类似于查找最近的较大元素，其中每个元素的“死亡时间”取决于两侧最接近的较大元素。 一旦知道这些距离，答案就成为这些距离的简单函数的所有元素的最大值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 重新模拟回合 |$O(n^2)$|$O(n)$| 太慢了|
 | 单调堆栈 + 传播 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 对于每个位置，我们计算左侧和右侧最近的较大元素。 它们充当保护当前元素的边界，直到这些边界本身在之前的回合中消失。 

1. 计算数组`L[i]`存储最接近左侧的元素的索引`i`值大于`a[i]`。 这是使用递减单调堆栈获得的。 当从左到右扫描时，我们弹出所有较小或相等的元素，因为它们不能作为任何未来元素的边界。 
2. 计算数组`R[i]`使用相同的想法，但从右向左扫描，将最近的较大元素存储在右侧。 这确保每个元素在两侧都有其最接近的主导邻居。 
3. 将这些边界解释为定义一个段，其中每个元素“包含”在两个更强的元素之间。 位置处的元素`i`只有在其左右边界都已在前几轮中被消除后才会被删除。 
4. 元素的消除时间取决于它在这些优势区间内的嵌套深度。 具体来说，如果两个邻居都不存在，它就会表现得像一个极端，并立即消失。 如果它在一侧被屏蔽，则其移除会被延迟，直到屏蔽边界被移除为止。 
5. 答案是所有指数的最大消除时间。 

### 为什么它有效

 当每个元素不严格小于两个邻居时，它就恰好存活一轮。 当在先前的消除之后存在与其相邻的更强的邻居时，该条件恰好失败。 最近的较大元素从每一侧捕获最早可能的障碍，并且没有其他元素可以更早地影响生存，因为任何更远的较大元素都会被中间元素阻挡。 这使得最近的更大结构足以确定完整的淘汰级联，而无需显式模拟回合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    if n == 1:
        print(0)
        return
    
    # nearest greater to left
    L = [-1] * n
    st = []
    for i in range(n):
        while st and a[st[-1]] <= a[i]:
            st.pop()
        L[i] = st[-1] if st else -1
        st.append(i)
    
    # nearest greater to right
    R = [-1] * n
    st = []
    for i in range(n - 1, -1, -1):
        while st and a[st[-1]] <= a[i]:
            st.pop()
        R[i] = st[-1] if st else -1
        st.append(i)
    
    # compute answer via propagation depth
    # base: elements with no greater neighbor on one side die fast
    from collections import deque
    
    depth = [0] * n
    q = deque()
    
    indeg = [0] * n
    adj = [[] for _ in range(n)]
    
    for i in range(n):
        if L[i] != -1:
            adj[L[i]].append(i)
            indeg[i] += 1
        if R[i] != -1:
            adj[R[i]].append(i)
            indeg[i] += 1
    
    for i in range(n):
        if indeg[i] == 0:
            q.append(i)
    
    while q:
        v = q.popleft()
        for u in adj[v]:
            depth[u] = max(depth[u], depth[v] + 1)
            indeg[u] -= 1
            if indeg[u] == 0:
                q.append(u)
    
    print(max(depth) if n > 0 else 0)

if __name__ == "__main__":
    solve()
```单调堆栈部分构造了由最近的更大约束引起的结构优势图。 每个节点都依赖于其最近的更强的邻居，因此我们从这些邻居到该节点构建有向边。 

基于队列的传播计算在每个元素暴露之前必须删除多少个主导“层”。 每次解决节点的依赖关系时，其深度都会比其先决条件的最大值大一，与它有效死亡的淘汰轮次相匹配。 

当任何元素被移除时，最终的最大深度对应于最后一轮。

 ## 边缘情况

 对于$n=1$，算法在任一方向上均不分配邻居，因此入度为零且深度保持为零。 这正确输出$0$，匹配立即终止。 

对于严格递增的数组，除了最后一个元素之外的所有元素在右侧都有一个更大的元素，因此它们形成了一个浅依赖结构，其中传播在单层中完成，产生答案$1$。 对于严格递减数组，每个元素都依赖于其左邻居，形成一个深度逐步累积的链，并且传播正确地对每一层进行计数，直到到达最后一个元素。
