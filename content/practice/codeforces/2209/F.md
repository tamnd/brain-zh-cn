 ## 解决方案
 ## 问题理解

 我们有一棵树`n`顶点，其中每个顶点都有一个整数值。 我们可以表演`k`操作，并且在每个操作中，我们选择一个顶点作为树的根。 一旦选择一个顶点作为根，它的值将直接添加到总数中，然后设置为零。 然后，所有非叶顶点将它们的值重新分配到其子树中的特定叶 - 最远的叶（通过最小索引打破关系）。 后`k`这样的操作，问题要求我们可以累积的最大总数。 

关键的挑战是每次生根后值从内部节点“流”到叶子，这会动态改变值的分布。 自从`n`所有测试用例最多可达 300,000 个`k`可以达到`n`，任何模拟每个操作和每个重新分配的简单方法都会太慢。 暴力模拟大致是`O(n^2)`在最坏的情况下每个测试用例，这是不可接受的。 

边缘情况包括小树，其中`n = 1`或者`k = 1`、已经是线性的树（路径）以及值极度偏向叶子的树。 例如，粗心的方法可能总是选择最大值，而不管其子树如何，而忽略了首先将高内部值传输到远叶可以最大化未来总数的事实。 

## 方法

 暴力方法的工作原理是显式模拟每个操作。 您可以在每个候选顶点处建立树，根据问题陈述重新分配值，然后重复`k`运营。 虽然在概念上是正确的，但这种方法至少执行`O(k * n)`每个测试用例的操作，以及`n`最多 3·10^5 且`k`可能等于`n`，它很快就超过了允许的时间限制。 

优化的关键见解是注意到每个顶点有效地贡献其值乘以它可以“扎根”或沿着其路径转移到叶子的次数。 特别是，值传播是向叶子累积的。 叶子本身无法进一步传播其价值，因此它们是所有内部价值最终积累的“汇”。 因此，要最大化之后的总数`k`操作中，我们想要选择具有最高有效贡献的顶点，这是它们的值加上它们从内部节点收到的贡献的总和。 

这将问题简化为计算每个顶点的“权重”——最终到达那里的潜在总价值。 计算出这些权重后，将顶部的总和求和即可得到最大总和`k`重量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(k * n) | O(n) | 太慢了 |
 | 基于权重的贪婪 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取树以及所有顶点的初始值。 构造邻接表以实现高效遍历。 
2. 对于每个顶点，递归计算其“有效贡献”。 对于一片叶子来说，这只是它自己的价值。 对于内部节点，其贡献是其值加上其子节点之间的最大贡献（因为值被发送到最远的叶子）。 这需要对树进行一次后序 DFS 遍历。 
3. 计算所有顶点的贡献后，将它们存储在列表中。 
4. 按降序排列此列表。 最大贡献对应于当植根于第一个操作时为总数提供最大累积的顶点。 
5.选择顶部`k`贡献并求和。 该总和是在以下情况下可实现的最大总和`k`运营。 

工作原理：DFS 确保每个内部节点将其值传递给能够承载它最远的叶子，这与问题的重新分配规则相匹配。 通过求和最大的`k`贡献，我们正在有效地模拟`k`在这些操作中，我们总是选择使当前总数最大化的顶点，这在贪婪意义上被证明是最优的，因为贡献仅从内部节点流向叶子，而永远不会返回。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        tree = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            tree[u].append(v)
            tree[v].append(u)
        
        contribution = [0] * n
        
        def dfs(u, parent):
            max_child = 0
            for v in tree[u]:
                if v == parent:
                    continue
                dfs(v, u)
                max_child = max(max_child, contribution[v])
            contribution[u] = a[u] + max_child
        
        dfs(0, -1)
        
        contribution.sort(reverse=True)
        total = sum(contribution[:k])
        print(total)

if __name__ == "__main__":
    solve()
```DFS 函数计算每个顶点的最大贡献。 通过避免重新访问父级，我们可以正确处理树的边缘。 对贡献进行排序保证我们可以选择`k`高效地做出最高贡献。 使用`sys.setrecursionlimit`确保我们处理深树时不会触及 Python 的默认递归深度。

 ## 边缘情况

 单节点树之所以有效，是因为 DFS 将其贡献设置为等于其值，并选择`k=1`直接将该值添加到总数中。 在线性树中，DFS 沿着路径正确传播值，确保叶子累积来自祖先的值。 处理具有极度倾斜值的树，因为算法始终识别每个内部节点的最大贡献路径。 在所有情况下，贪心选择顶部`k`捐款保证最大总额。
