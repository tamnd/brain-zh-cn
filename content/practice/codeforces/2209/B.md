 ## 解决方案
 ## 问题理解

 给定一个整数数组，对于每个元素，我们需要确定在特定意义上，其右侧有多少元素可以被它“支配”。 对于一个元素`a[i]`，我们要计算索引的最大数量`j > i`使得存在某个整数`k`其中绝对差`|a[i] - k|`严格大于`|a[j] - k|`。 关键是`k`可以为每个独立选择`i`，并且我们希望计数最大。 

这相当于询问：对于每个元素`a[i]`,后面有多少个元素`a[j]`严格介于`a[i]`和一些选择的`k`？ 凭直觉选择`k`非常大或非常小都允许`a[i]`支配所有小于或大于自身的元素。 最优的`k`始终位于两个元素的范围之外以最大化计数。 

这些约束表明数组在所有测试用例中总共最多可以有 5000 个元素。 检查每一对的幼稚方法`(i, j)`为所有潜力`k`需要 O(n²) 次操作，这是可以接受的，因为 n ≤ 5000，但可能有一种更简单的方法，使用数字的属性，而不是暴力迭代`k`。 

边缘情况包括大小为 1 的数组、具有重复元素的数组以及最大或最小元素出现在开头或结尾的数组。 例如，一个数组`[5, 5, 5]`必须产生`[0, 0, 0]`，因为无论选择`k`，没有元素严格“接近”`k`当值相等时优于另一个。 

## 方法

 蛮力方法将迭代每个元素`a[i]`，那么对于每个`i`,检查每个元素`a[j]`为了`j > i`。 对于每对`(i, j)`，我们会尝试找到一个整数`k`这样`|a[i] - k| > |a[j] - k|`。 这种不等式简化为一个简单的检查：`k`应该在之间的间隔之外`a[i]`和`a[j]`。 具体来说，要么`k < min(a[i], a[j])`或者`k > max(a[i], a[j])`。 既然这样一个`k`总是存在于任何`i ≠ j`，条件简化为检查`a[i] ≠ a[j]`。 每个测试用例的简单复杂度是 O(n²)，考虑到约束条件，这是可以容忍的。 

最佳方法利用了以下观察结果：对于任何`a[i]`，支配元素的最大数量是通过选择来实现的`k`向左很远或向右很远，这样`a[i]`距离更远`k`比`a[j]`如果`a[j]`位于之间`a[i]`和`k`。 这将问题简化为计算右侧元素的数量`i`要么严格小于或严格大于`a[i]`，并取这两个计数的最大值。 我们不再需要计算或迭代`k`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | n ≤ 5000 可接受 |
 | 优化贪心| O(n²) | O(1) | O(1) | 已接受的、更简单的逻辑 |

 ## 算法演练

 1. 对于每个测试用例，读取数组`a`长度`n`。 
2. 初始化结果数组`res`长度`n`带零。 
3. 迭代每个索引`i`从`0`到`n-1`。 
4. 对于`i`,初始化两个计数器`count_less`和`count_greater`为零。 
5. 迭代每个索引`j`从`i+1`到`n-1`。 如果`a[j] < a[i]`, 增量`count_less`。 如果`a[j] > a[i]`, 增量`count_greater`。 
6. 设置`res[i]`至最大`count_less`和`count_greater`。 
7. 处理完所有索引后，输出测试用例的结果数组。 

为什么有效：对于每个`i`，可以支配的元素数量仅取决于相对值`a[i]`和`a[j]`。 选择`k`左边最远的元素将主导所有较小的元素，并选择`k`远到右边将主导所有较大的元素。 由于我们想要最大值，因此取这两个计数中较大的一个即可得出正确答案。 没有任何元素会被重复计算，因为每个元素的统治都是独立的`i`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        res = [0] * n
        for i in range(n):
            count_less = 0
            count_greater = 0
            for j in range(i + 1, n):
                if a[j] < a[i]:
                    count_less += 1
                elif a[j] > a[i]:
                    count_greater += 1
            res[i] = max(count_less, count_greater)
        print(" ".join(map(str, res)))
```代码直接实现了算法步骤。 每个`i`仅与其后面的索引进行比较。 使用`max(count_less, count_greater)`确保我们选择最优的`k`隐含地。 该方法避免了不必要的实际计算`k`值，仅依赖于相对顺序。
