 ## 解决方案
 ## 问题理解

 我们被要求使用“美丽”的整数集合，这意味着集合中的任何两个数字在可整除性下都是可比较的。 给定两个整数`l`和`r`，任务是找到仅由区间内的数字组成的最大可能的美丽集合`[l, r]`并计算存在多少这样的最大集合。 每个测试用例需要两个输出：最大集合的大小和该大小的集合的模数`998244353`。 

关键是要认识到美丽的集合本质上是可分关系下的一条链条。 这允许我们将集合构造为序列，其中每个元素都是前一个元素的倍数。 约束条件，与`r`最多`10^6`直至`2 * 10^4`测试用例意味着任何迭代所有子集的算法都是不可能的，因为子集的数量呈指数增长。 相反，我们需要一种在间隔长度或最大数的对数方面以线性或近线性时间工作的方法。 

需要注意的边缘情况包括间隔，其中`l`非常接近`r`，可能只允许大小为 1 的集合。例如，`l = 5, r = 5`应该输出`1 1`。 另一个微妙的情况是当`l`是 1，可以被任何数字整除。 忘记将 1 作为最小链起点的幼稚方法可能会计算错误。 此外，2 的幂占主导地位的区间，例如`l = 1, r = 16`，要求算法正确识别沿倍数的最大链长度。 

## 方法

 蛮力方法将尝试生成所有子集`[l, r]`并检查每对的可分性条件。 虽然这在概念上是简单且正确的，但它很快就变得不可行，因为大小范围`10^6`有`2^10^6`子集。 

解锁更快解决方案的观察是将美丽的集合视为乘法链。 任何所有元素相互划分的集合都可以表示为序列`x, 2x, 4x, ...`从一些最小元素开始`x`。 最大集合长度通过重复乘以 2 来确定，直到超过`r`。 这将问题简化为计算最长序列`x * 2^k ≤ r`和`x ≥ l`。 最大组数对应于计算所有起始数`x`允许如此最大的链长度。 

我们可以有效地计算它，因为最大链长度仅取决于间隔长度和加倍，并且有效起始点的计数可以通过简单的 2 的幂算术来计算。 我们避免循环遍历每个可能的子集，而是利用二的幂结构来产生相对于间隔大小的对数时间的结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(r-l+1) * (r-l+1)^2) | O(2^(r-l+1) * (r-l+1)^2) | O(r-l+1) | 太慢了 |
 | 最优（乘法链）| 每个测试用例 O(log(r)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算美丽集合的最大长度作为最大`k`这样`l * 2^(k-1) ≤ r`。 这找到了我们可以在从某个数字开始的链中形成的最大元素数`x`不超过`r`。 我们采取`l`作为最小起点，因为较小的数字不能出现在区间中。 
2. 初始化最大组数计数器。 链条长度`k`定义加倍过程的指数。 对于每个起始数字`x`从`l`最多`r // 2^(k-1)`，一条链的长度`k`存在。 数一下所有这样的`x`值来计算最大集的总数。 
3. 应用模数`998244353`计数，因为它可能超出标准整数限制。 
4. 对所有测试用例重复步骤 1 至 3。 

为什么它有效：每个最大的美丽集合必须是一个数字链，其中每个数字除下一个数字。 最大化集合大小的唯一方法是从最小的数字开始`x`并重复乘以 2。这保证了所有整除条件都得到满足，并确保其中没有其他数字`[l, r]`可以延伸链条。 计算允许完整链捕获所有不同最大集的起始数字，因为任何开始超出此范围的链要么太短，要么超过`r`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

t = int(input())
for _ in range(t):
    l, r = map(int, input().split())
    length = 0
    x = l
    while x <= r:
        x *= 2
        length += 1
    max_size = length
    
    # Count starting numbers x for which x*2^(length-1) <= r
    count = r - (l * (2 ** (length - 1))) + 1
    print(max_size, count % MOD)
```该解决方案首先通过重复乘以最小起始数来计算最大链长度`l`2 直到超过`r`。 然后它计算该长度的链适合的所有起始数字`[l, r]`。 使用算术可以确保我们永远不会显式地构建链或检查每个子集的可分性。

 ## 边缘情况

 对于`l = r`，算法计算`x = l`并乘以一次超过`r`，链长度为 1。计数计算变为`r - l + 1 = 1`，它正确处理单例间隔。
