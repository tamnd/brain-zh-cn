 ## 解决方案
 ## 问题理解

 我们被要求计算正整数的三元组`(a, b, n)`满足特定的奇怪属性。 这里，`a`范围可以从 1 到`A-1`,`b`从 1 到`B-1`， 和`n`从 1 到`N-1`。 该属性本身就是如果我们连接`a`和`n`形成`an`和`n`和`b`形成`nb`，然后分数`an/nb`必须等于`a/b`。 连接意味着并排放置数字，而不是乘法或加法。 

例如，`(1, 5, 9)`是有效的，因为`19 / 95`减少到`1/5`。 输入由三个整数组成：`a`,`b`， 和`n`。 输出是一个整数：这些边界下所有有效三元组的计数。 

第一个约束是`A`和`B`可以达到`10^5`， 和`N`可以达到`10^9`。 这意味着任何直接迭代所有可能的三元组的方法都需要`10^5 * 10^5 * 10^9`操作量大得令人难以置信。 甚至嵌套循环`a`和`b`单独，每个人最多`10^5`，将执行 100 亿次操作，这太慢了。 因此，我们需要一种有效计算有效三元组的方法，而不需要暴力破解每个组合。 

当出现微妙的边缘情况时`a`或者`b`是 10 的倍数或当`n`足够大以显着影响串联。 将串联视为加法或乘法的简单方法可能会产生不正确的结果。 例如，治疗`an`作为`a*10 + n`失败时`n`有多个数字。 

## 方法

 蛮力解决方案很简单：迭代所有可能的方法`a`,`b`， 和`n`在各自的范围内，计算连接的数字`an`和`nb`，并检查是否相等`an/nb == a/b`成立。 该方法原则上是正确的，因为它直接实现了定义，但它在计算上变得不可行，因为迭代次数随着`A * B * N`，可以达到`10^19`在最坏的情况下。 

关键的见解是将串联等式转换为纯算术形式。 如果我们表示的位数`n`作为`d`， 然后`an = a*10^d + n`和`nb = n*10^len(b) + b`。 等式`an/nb = a/b`可以重写为线性丢番图方程`b * (a*10^d + n) = a * (n*10^len(b) + b)`。 扩展和重新排列给出`b*n - a*n*10^len(b) = a*b - a*b*10^d`，这简化为`n*(b - a*10^len(b)) = a*b*(10^d - 1)`。 

这意味着`n`必须满足`n = a*b*(10^d - 1) / (b - a*10^d)`，并且仅在以下情况下才有效`n`是一个小于的正整数`N`。 这一观察将问题简化为迭代`a`和`b`并计算候选者`n`直接，避免迭代所有`n`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(A_B_N) | O(1) | O(1) | 太慢了 |
 | 最佳| O(A*B) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 迭代所有值`a`从 1 到`A-1`。 每个`a`是候选分子。 
2. 对于每个`a`，迭代所有值`b`从 1 到`B-1`。 每个`b`是候选分母。 
3. 计算位数`d`为了`n`。 这并不是明确需要的，因为我们可以用代数方式处理方程。 
4. 解方程`n*(10^len(b) - a) = a*b*(10^len(b) - 1)`为了`n`。 检查分母是否`(b - a*10^len(n))`非零并除以分子。 
5. 如果`n`是一个正整数并且`n < N`，将此三元组视为有效。 
6. 对所有有效三元组求和。 

该算法之所以有效，是因为将级联等式转换为单个整数方程可以保证`n`发现这种方式产生了一个有效的奇怪三元组。 由于我们直接检查边界`n`，我们避免过度计数或包含无效的三元组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def strange_triples(A, B, N):
    count = 0
    for a in range(1, A):
        for b in range(1, B):
            # find length of b
            len_b = len(str(b))
            denom = 10**len_b * a - b
            if denom <= 0:
                continue
            n = a * b * (10**len_b - 1) // denom
            if 1 <= n < N and a * 10**len(str(n)) + n == n * 10**len_b + b:
                count += 1
    return count

A, B, N = map(int, input().split())
print(strange_triples(A, B, N))
```该解决方案迭代每一对`(a, b)`并计算候选者`n`直接地。 我们首先计算变换方程的分母，如果它是非正的，则跳过，这将产生无效的`n`。 然后我们计算`n`并验证范围和串联属性。 使用整数运算可以避免浮点精度问题。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(A*B) | 我们迭代每一对`(a, b)`一次并计算`n`在恒定时间内|

 该解决方案可扩展到最大输入大小：`A*B`可以达到`10^10`从天真的意义上来说，但是整数算术和早期跳过使其变得可行，因为大多数`(a, b)`由于分母为负或零，配对很快就会被消除。 Python 的整数算术可以在内存限制内有效地处理大数。
