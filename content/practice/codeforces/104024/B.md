 ## 解决方案
 ## 问题理解

 我们得到两个来自两个隐藏数字的整数，称它们为$a$和$b$。 而不是透露$a$和$b$直接，我们只被告知他们的总和$a + b$以及它们的按位与$a \land b$。 任务是恢复按位异或$a \oplus b$。 

关键的困难在于加法将位与进位混合在一起，而 AND 捕获两个数字都有 1 位的位置。 XOR 准确捕获它们不同的位，因此目标是在不显式重建的情况下重建它$a$和$b$。 

约束条件允许$a, b \le 10^9$，这意味着值适合 31 位。 这足够小，使得按位推理是完全安全的并且恒定时间操作就足够了。 任何能在比特线性时间甚至 O(1) 算术中工作的解决方案就足够了。 对所有对的暴力破解是无关紧要的，因为我们不是在搜索，而是在重建。 

这里的一个天真的错误是假设$a + b = a \oplus b$。 当有进位时，这会立即失败。 例如，如果$a = 1$和$b = 1$， 然后$a + b = 2$但$a \oplus b = 0$。 另一种失败情况是假设 AND 直接参与 XOR，但 AND 代表实际上“创建进位”的共享位。 

一个更微妙的边缘情况是当 AND 相对于总和较大时。 例如，如果$a = 3$和$b = 2$， 然后$a + b = 5$,$a \land b = 2$，异或是$1$。 任何忽略进位因子 2 的错误重排都会在这里失败。 

## 方法

 暴力方法会尝试枚举所有对$(a, b)$与给定的和与AND一致，则直接计算异或。 自从$a$和$b$可以达到$10^9$，这会导致搜索空间大小不可行$10^{18}$。 即使进行剪枝，也没有允许枚举的结构，因为多个位配置可以匹配相同的和和 AND。 

关键的见解是使用连接加法、XOR 和 AND 的标准恒等式：$$a + b = (a \oplus b) + 2 \cdot (a \land b)$$这是通过独立检查每一位得出的。 在每个位位置，如果两个位都为 1，则它们为下一级的总和贡献 2，这正是 AND 编码的内容。 XOR 捕获剩余的未配对 1 位。 由于这些贡献不会跨位干扰，因此该身份在全球范围内保持不变。 

重新排列给出：$$a \oplus b = (a + b) - 2 \cdot (a \land b)$$因此整个问题简化为一个算术表达式。

 ## 算法演练

 1.读取两个整数$s = a + b$和$c = a \land b$。 这些是有关隐藏数字的唯一提供的信息。 
2. 使用恒等式计算异或$x = s - 2c$。 这是有效的，因为由于二进制进位传播，AND 中计数的每个共享位在总和中贡献了两倍。 
3. 直接输出计算出的异或值。 

### 为什么它有效

 每个位位置对算术结构都有独立的贡献。 如果两者都设置了一个位$a$和$b$，它在总和中的该位级别贡献 2，并且该贡献被精确地编码为$2 \cdot (a \land b)$。 去除这些进位后的剩余贡献恰好对应于异或位。 由于除了已考虑的进位之外不存在交叉位干扰，因此减去两倍的 AND 可以唯一地隔离 XOR。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s, c = map(int, input().split())
    print(s - 2 * c)

if __name__ == "__main__":
    solve()
```该实现直接应用派生身份。 无需重建$a$或者$b$，并且不需要逐位模拟。 唯一的微妙之处是确保在减法之前将乘以 2 应用于 AND 值； 由于更复杂的表达式中的运算符优先级，反转顺序将是不正确的，尽管在 Python 中此特定行按照书面形式是安全的。 

## 工作示例

 我们使用提供的示例输入。 

输入：```
5 2
```我们将其解释为$a + b = 5$和$a \land b = 2$。 

让我们一步步计算：

 | 步骤| 价值|
 | ---| ---|
 | 和$s$| 5 |
 | 和$c$| 2 |
 | 异或$s - 2c$| 5 - 4 = 1 | 5 - 4 = 1

 所以输出是1。 

这与有效的重建相匹配，例如$a = 3$,$b = 2$。 以二进制表示：3 = 011 且 2 = 010，因此 AND 为 010 (2)，sum 为 5，XOR 为 001 (1)。 

第二个构造的例子：

 输入：```
10 2
```尝试$a = 8$,$b = 2$。 那么 sum 是 10，AND 是 0，所以 XOR 应该是 10。应用公式：

 | 步骤| 价值|
 | ---| ---|
 | 和$s$| 10 | 10
 | 和$c$| 0 |
 | 异或$s - 2c$| 10 | 10

 当不存在重叠位时，这确认了正确性。

 ## 边缘情况

 用于输入$0\ 0$，两个数字都为零，因此 AND 为零，总和为零。 公式给出$0 - 0 = 0$，这是正确的。 没有隐藏的进位结构，因此 XOR 也必须为零。 

用于输入$7\ 7$，我们将两个数字解释为相同。 那么总和为 14，AND 为 7。应用该算法可得出$14 - 14 = 0$。 按位计算，相同的数字总是异或为零，并且该公式正确地取消所有共享贡献两次，不留下任何东西。
