 ## 解决方案
 ## 问题理解

 我们有一个圆形奖轮`l`编号部分来自`0`到`l-1`。 滚轮指针从某个部分开始`a`。 每次旋转都会使指针向前移动精确的距离`b`位置模数`l`。 目标是确定通过旋转轮子任意次数（包括零旋转）可以达到的最大部分数。 

限制条件适中：`l`和`b`每个最多可以有 5000 个，并且最多可以有 500 个测试用例。 这意味着任何模拟每次旋转的方法`l`每个测试用例的步骤是可行的，因为 5000 个步骤乘以 500 个测试用例大约是 250 万次操作，这在 1 秒的时间限制内是可以接受的。 重复旋转直到位置重复的蛮力方法是可行的，但值得研究是否存在更简单的公式以避免不必要的迭代。 

当出现不明显的边缘情况时`b`大于`l`， 什么时候`b`和`l`不互质，或者当`b`划分`l`确切地。 例如，与`l=2`,`a=0`， 和`b=6`，指针永远不会离开节`0`因为`(0 + k*6) mod 2`总是`0`。 一种粗心的方法假设`b`总是生成新的位置可能会错误地建议更高的最大值。 另一个边缘情况是`b=1`，最终将访问所有位置，因此最大值始终为`l-1`。 

## 方法

 蛮力方法很简单。 开始于`a`，我们不断添加`b`模数`l`并跟踪达到的最大值。 这是正确的，因为重复加法模`l`循环通过由最大公约数确定的部分子集`b`和`l`。 在最坏的情况下，指针可以击中所有`l`位置，因此最大迭代次数为`l`。 在 500 个测试用例中，结果是`500 * 5000 = 2.5 * 10^6`操作，在可接受的范围内。 

最佳解决方案的关键见解是认识到指针可以到达的位置形成算术级数模`l`。 具体来说，可达部分的顺序是`a, (a+b) mod l, (a+2b) mod l, ...`。 循环将在之后关闭`l / gcd(b, l)`旋转，因为经过多次旋转后，`(a + k*b) mod l`返回到`a`。 最大可达路段可以直接计算，无需使用公式进行迭代`l - gcd(l, b) + ((a - 1) % gcd(l, b))`或更简单的逻辑：循环重复之前算术级数中的最后一部分。 

这一观察结果将问题简化为计算最大公约数 (GCD)`l`和`b`然后确定可达子集中的最大值。 这避免了模拟每次旋转，同时保证正确性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个测试用例 O(l) | O(1) | O(1) | 对于给定的限制是可接受的 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 完全接受|

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读`l`,`a`， 和`b`。 
2. 计算`g = gcd(l, b)`。 这告诉我们连续可达位置模之间的步长大小`l`。 
3. 确定循环中最后可到达的位置。 最大位置为`l - g + a % g`。 这是有效的，因为位置是有间隔的`g`分开，从`a % g`，以及下面的最大值`l`在这个算术级数中是`l - g + (a % g)`。 
4. 打印每个测试用例的最大值。 

这样做的原因是指针只能到达与以下内容一致的部分`a modulo g`。 下面同余类中最大的部分`l`是`l - g + (a % g)`。 每个可到达的位置都包含在算术级数中，因此我们不会错过任何最大值的候选位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from math import gcd

t = int(input())
for _ in range(t):
    l, a, b = map(int, input().split())
    g = gcd(l, b)
    max_prize = l - g + a % g
    print(max_prize)
```解决方案首先读取测试用例的数量。 对于每个测试用例，它计算 GCD`l`和`b`，它定义位置模的步长`l`。 然后它使用以下公式计算循环中的最大可到达部分`l - g + (a % g)`。 该公式仔细处理余数以说明起始位置`a`并确保该值严格小于`l`。 结果立即打印。

 | 0 | 0 |
 | 1 | 0 |

 GCD(2,6)=2。 最大可达：`2 - 2 + 0%2 = 0`。 

这些痕迹证实该公式正确处理循环和固定点。

def run(inp: str) -> str:

 ## 边缘情况

 对于`l=2, a=0, b=6`，指针保持在 0。公式计算`gcd(2,6)=2`， 和`max_prize = 2 - 2 + 0%2 = 0`，这与观察到的行为相匹配。 为了`l=5, a=3, b=2`，指针循环经过所有位置。 GCD 为 1，所以`max_prize = 5-1 + 3%1 = 4`，正确捕获最高部分。 该公式正确处理静止位置和完整循环。
