 ## 解决方案
 ## 问题理解

 我们需要两个居中形状的公共面积：有边长的正方形`s`和一个有半径的圆`r`。 由于它们的中心重合，因此答案仅取决于圆如何到达正方形的四个边和角。 输出是重叠面积，四舍五入到小数点后两位`3.14159265358979`对于 π。 

让`a = s / 2`。 在第一象限中，正方形占据长方形`0 <= x <= a`,`0 <= y <= a`，而圆有上边界`y = sqrt(r^2 - x^2)`。 

几何形状具有三种不同的状态。 如果`r <= a`，圆完全位于正方形内，所以答案就是圆的面积。 如果`r >= a * sqrt(2)`，圆到达正方形的角，因此覆盖了整个正方形。 在这两种情况之间，圆穿过正方形的每条边，但没有到达其角点，这需要计算圆弧段。 

的限制`s`和`r`都很小，都最多 100，所以算术本身从来都不是问题。 更重要的是，该声明没有对场景数量施加很大的上限，因此理想的解决方案应该只为每个场景执行恒定的工作。 任何在网格上迭代、对许多样本执行数值积分或重复细化近似的方法都会浪费工作，而简单的几何结构可以让我们避免这些工作。 

第一种边缘情况是圆完全包含正方形。 例如，```
1
1 1
```面积为 平方`1`，并且圆有半径`1`，因此圆远远超出所有四个角。 正确答案是`1.00`。 总是打印的粗心实现`πr²`将输出大约`3.14`，这是锅的面积而不是覆盖天窗的部分。 

当圆完全位于正方形内部时，会出现相反的边缘情况。 例如，```
1
10 5
```有半边`5`，正好等于半径。 圆与所有四个边都相切，因此它的整个面积被覆盖，答案是`78.54`。 假设圆总是与正方形的角相交的实现将错误地应用部分重叠公式。 

真正偏颇的情况也容易处理不当。 为了```
1
8 5
```半边是`4`。 半径大于`4`，所以圆穿过正方形的边，但是`5 < 4sqrt(2)`，所以它不会覆盖角落。 正确答案是`62.19`。 使用完整的圆形区域或完整的正方形区域都是错误的。 

## 方法

 直接的暴力方法可以通过将正方形细分为非常精细的网格并检查每个小单元或代表点是否位于圆内来近似交集。 从概念上讲，这是可行的，因为交集正是满足方形和圆形不等式的点的集合。 问题在于，获得可靠的两位小数精度需要足够精细的细分，并且工作量随着采样位置的数量而不是输入的实际几何复杂性而增长。 

例如，扫描`10000 x 10000`网格已经意味着`100,000,000`一种场景的点评估。 在许多情况下，这很快就变得不切实际，并且点采样方法仍然存在必须仔细控制的边界误差。 数值积分也有同样的弱点：增加切片数量可以提高准确性，但不能提供明确的保证，除非误差被明确限制。 

蛮力方法之所以有效，是因为它试图近似一个几何上明确定义的区域，但它失败了，因为几何给我们提供的信息比采样算法使用的信息多得多。 关键的观察结果是正方形和圆形共享一个中心，因此重叠在两个轴上是对称的。 我们可以计算一个象限内的面积并乘以四。 

在一个象限内，唯一有趣的过渡发生在圆到达水平边的地方`y = a`。 解决`sqrt(r² - x²) = a`给出`x = sqrt(r² - a²)`。 

调用这个值`x0`。 从`x = 0`通过`x = x0`，圆延伸到正方形的顶边上方，所以覆盖的高度就是`a`。 从`x0`通过`x = a`，覆盖的高度就是圆的高度`sqrt(r² - x²)`。 这将整个问题转化为一个基本积分。 

圆上边界的反导数是`F(x) = 1/2 * (x * sqrt(r² - x²) + r² * asin(x / r))`。 

因此，部分情况下的第一象限重叠为`a * x0 + F(a) - F(x0)`,

 最终答案是该值的四倍。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个场景的 O(K)，其中 K 是几何样本的数量 | O(1) | O(1) | 太慢且依赖于近似 |
 | 最佳| 每个场景 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读出正方形的边长`s`和圆半径`r`，然后设置`a = s / 2`。 使用半边使坐标系以原点为中心，让我们仅分析第一象限。 
2. 检查是否`r <= a`。 在这种情况下，圆完全位于正方形内部，包括相切的情况，因此返回`πr²`。 
3. 检查是否`r >= a * sqrt(2)`。 正方形距中心最远的点是其角点，其距离为`a * sqrt(2)`。 如果圆到达该距离，则正方形的每个点都位于圆内，因此返回`s²`。 
4. 对于剩余的部分重叠情况，计算`x0 = sqrt(r² - a²)`。 这是圆在第一象限中与正方形顶边相交的 x 坐标。 由于我们处于两种边界情况之间，`x0`严格位于`0`和`a`。 
5. 定义反导数`F(x) = 0.5 * (x * sqrt(r² - x²) + r² * asin(x / r))`。 

积分为`sqrt(r² - x²)`从`x0`到`a`是`F(a) - F(x0)`，给出第一象限重叠的弯曲部分。 
6. 添加矩形部分`0`到`x0`。 其宽度为`x0`它的高度是`a`，所以它的面积是`a * x0`。 因此第一象限面积为`a * x0 + F(a) - F(x0)`。 
7. 将第一象限面积乘以四并打印出小数点后恰好两位数。 这四个象限具有相同的重叠，因为两个形状都居中且关于坐标轴对称。 

### 为什么它有效

 该算法恰好在圆与正方形顶边相交的点处划分第一象限重叠。 在那一点之前，整个垂直段从`y = 0`到`y = a`位于圆的内部，因此它的贡献是一个矩形。 在该点之后，圆边界位于正方形顶部下方，因此贡献正好是下面的面积`sqrt(r² - x²)`。 反导数计算的弯曲面积精确到浮点精度。 由于相同的区域出现在所有四个象限中，因此乘以四可以精确地得出完整的方圆交点。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

PI = 3.14159265358979

def covered_area(s, r):
    a = s / 2.0

    # The circle is completely inside the square.
    if r <= a:
        return PI * r * r

    # The circle contains the entire square.
    if r >= a * math.sqrt(2.0):
        return s * s

    # Partial overlap.
    x0 = math.sqrt(r * r - a * a)

    def F(x):
        y = math.sqrt(max(0.0, r * r - x * x))
        return 0.5 * (x * y + r * r * math.asin(x / r))

    quadrant = a * x0 + F(a) - F(x0)
    return 4.0 * quadrant

def main():
    t = int(input())

    out = []
    for _ in range(t):
        s, r = map(int, input().split())
        area = covered_area(s, r)
        out.append(f"{area:.2f}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```常数`PI`是显式编写的而不是使用`math.pi`因为该问题指定了用于计算的 π 的精确值。 差异很小，但使用规定的常数可以消除舍入的任何歧义。 

第一个条件使用`r <= a`，不仅仅是`r < a`，因为与正方形边相切不会从圆中删除任何区域。 同样，第二个条件使用`r >= a * sqrt(2)`，因为触及角意味着整个正方形已经在圆内。 

在部分情况下，`x0`保证在数学上是有效的，所以`r² - a²`是非负的。 这`max(0.0, ...)`里面`F`是在计算理论上应为零的表达式时针对浮点舍入引起的微小负值的防御措施。 

论点为`asin`数学上也介于`-1`和`1`。 这里它是非负的，因为所有坐标都是在第一象限中获取的。 该公式仅计算`x <= a < r`在部分情况下，所以`x / r`是有效的。 

Python 的浮点运算对于所要求的两位小数（最多为 100）来说绰绰有余。Python 中也不存在整数溢出问题，尽管由于交集区域通常不是整数而故意将计算转换为浮点。

 ## 边缘情况

 对于`s = 1`和`r = 1`，半边是`0.5`角距离约为`0.7071`。 该算法首先检查圆是否适合正方形，这是错误的，然后检查圆是否到达角落，这是正确的。 它返回平方面积，`1.00`。 这可以防止返回圆面积的常见错误。 

为了`s = 10`和`r = 5`，半边和半径都是`5`。 第一个条件`r <= a`成功，因此算法返回`π * 25`，即`78.54`与所需的 π 值。 圆仅接触正方形的边，因此圆的任何部分都不位于天窗之外。 

为了`s = 2`和`r = 1`，半边是`1`中心到每个角的距离也是`1`。 第二个条件成功是因为`r >= a * sqrt(2)`这里实际上是错误的，所以这种情况需要仔细检查：角距离是`sqrt(2)`， 不是`1`。 正确的分类是`r <= a`，表示圆与四个边相切并且有面积`π`，生产`3.14`， 不是`4.00`。 这捕捉到了对角距离边界的诱人但不正确的解释。 

相应的具有积分值的碰角情况可以通过以下方式获得`s = 2`和非整数半径`sqrt(2)`，但输入限制`r`为一个整数。 因此，没有整数半径输入恰好落在该正方形的角边界上。 该实现仍然通过以下方式正确处理该数学边界`r >= a * sqrt(2)`比较。 

对于部分情况`s = 8`和`r = 5`，半边是`4`，因此这两个包含条件都不适用。 与顶边的交点是`x0 = sqrt(25 - 16) = 3`。 该算法分配完整高度`4`在间隔内`[0, 3]`，将圆积分为`3`到`4`，并将第一象限结果乘以四。 最终值为`62.19`，匹配样本。 

最后一个值得检查的边界是当圆比正方形小得多时。 例如，```
1
100 1
```有半边`50`和半径`1`。 圆完全在正方形内，因此算法立即返回`π`，格式为`3.14`。 假设圆的某些部分必须与方形边界相交的数值或几何实现会引入不必要的复杂性，并且可以轻松减去不存在的区域。
