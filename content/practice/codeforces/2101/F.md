 ## 解决方案
 ## 问题理解

 我们有一棵树`n`顶点。 每个顶点都可以是红色、蓝色或白色。 颜色的“冷度”是红色和蓝色顶点之间的最大距离。 如果没有红色或蓝色顶点，则冷度为零。 我们的任务是总结所有的酷`3^n`树的可能颜色，模`998244353`。 

输入由多个测试用例组成。 每个测试用例提供顶点数`n`和`n-1`形成树的边。 我们要输出每棵树所有颜色的凉爽度值的总和。 

限制条件适中：`n`最多可以达到 3000，但所有测试用例的总数也最多为 3000。枚举所有颜色的简单暴力方法是不可行的，因为`3^3000`是一个天文数字。 这意味着我们需要一种组合或动态编程方法来避免显式迭代每种颜色。 

边缘情况包括非常小的树（`n=2`），其中所有颜色都是微不足道的，并且具有许多顶点的树，其中大多数颜色不包含红色或蓝色顶点。 粗心的实现可能会尝试单独计算每种颜色的距离，这在时间和内存上都会失败。 

## 方法

 一个天真的方法是生成所有`3^n`着色。 对于每种颜色，识别所有红色和蓝色顶点，计算成对距离，并记录最大距离。 即使计算树中一种颜色的距离也需要`O(n^2)`使用 BFS 并结合`3^n`着色，这是没有希望的。 显然，暴力破解只是概念上正确的。 

关键的观察结果是，冷度完全取决于红色和蓝色顶点之间的距离。 我们可以用顶点对来思考：对于每个无序对`(u, v)`我们可以问：有多少种颜色`u`红色和`v`蓝色（或反之亦然）？ 每一种颜色都有助于`d(u, v)`到总和。 

让我们表示`d(u, v)`作为顶点之间的距离`u`和`v`。 那么，其中的着色数量`u`是红色的，`v`是蓝色的，所有其他顶点都可以是任何颜色`2 * 3^(n-2)`（因子 2 用于交换红色和蓝色）。 这看起来很简单，但它计算过多了，因为如果在相同颜色中存在另一对距离较大的红蓝对，则仅计算最大距离。 所以我们需要一种方法来计算每一对`(u, v)`有多少种颜色是**最远的红蓝对**。 

树结构给出了一个关键的简化：着色中最长的红蓝距离总是出现在作为某些红蓝子集的树直径端点的顶点之间。 因此，如果我们关注**每条边**，我们可以计算红色和蓝色顶点之间的路径上该边的最大着色数。 

我们通过删除每条边将树分解为子树`(u, v)`。 让生成的连接组件具有大小`s1`和`s2`。 如果一个组件中的所有顶点都是红色或白色，而另一个组件中的所有顶点都是蓝色或白色，则最长的红蓝路径将使用该边`(u, v)`并贡献距离`d(u, v)`。 使用组合计数，我们可以计算满足此属性的着色数量：```
(count of colorings in component 1 with no blue) *
(count of colorings in component 2 with no red)
```这利用了组件上的包含-排除原则。 将所有边缘的总和得出总的冷却度总和。 这降低了复杂性`3^n * n^2`粗略地`O(n^2)`每个测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(3^n * n^2) | O(3^n * n^2) | O(n^2) | O(n^2) | 太慢了|
 | 最优（边缘分解）| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 预先计算 3 模的幂`998244353`适用于所有尺寸，最大可达`n`有效地处理计数。 
2. 对于每条边`(u, v)`，执行 DFS 以确定以`u`当边缘`(u, v)`被删除。 设这个尺寸为`s1`; 另一个组件有尺寸`s2 = n - s1`。 
3. 计算最远的红蓝对使用这条边的颜色。 一个组件不得包含蓝色，另一组件不得包含红色。 使用组合学，此类着色的数量为：```
(3^s1 - 2^s1) * (3^s2 - 2^s2) * 2
```这里`3^s1`计算第一个组件中的所有颜色，`2^s1`减去没有红色的部分（全蓝色或白色），留下至少有一种红色的部分。 对于第二个组件也是如此。 乘以 2 即可交换红色和蓝色分量。 

1. 将颜色数量乘以`d(u, v)`得到这条边的总贡献。 
2. 对所有边上的贡献求和并取模`998244353`。 
3. 对所有测试用例重复此操作。 

**为什么起作用**：该算法利用了这样一个事实：在树中，红色和蓝色顶点之间的最长路径穿过分隔红色和蓝色分量的单个边。 计算最大化该边缘贡献的颜色可确保我们准确地考虑该边缘是最大红蓝距离的一部分的颜色。 对所有边求和涵盖所有最大距离，无需重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(5000)
MOD = 998244353

def solve():
    t = int(input())
    pow3 = [1] * 3001
    pow2 = [1] * 3001
    for i in range(1, 3001):
        pow3[i] = pow3[i-1] * 3 % MOD
        pow2[i] = pow2[i-1] * 2 % MOD

    for _ in range(t):
        n = int(input())
        edges = [[] for _ in range(n)]
        edge_list = []
        for _ in range(n-1):
            u,v = map(int,input().split())
            u -= 1; v -= 1
            edges[u].append(v)
            edges[v].append(u)
            edge_list.append((u,v))

        size = [0] * n
        def dfs(u, parent):
            size[u] = 1
            for v in edges[u]:
                if v != parent:
                    dfs(v, u)
                    size[u] += size[v]

        total = 0
        for u,v in edge_list:
            # compute component sizes after removing edge u-v
            dfs(u, v)
            s1 = size[u]
            s2 = n - s1
            contrib = ( (pow3[s1]-pow2[s1]) * (pow3[s2]-pow2[s2]) * 2 ) % MOD
            total = (total + contrib) % MOD
        print(total)

if __name__ == "__main__":
    solve()
```这`dfs`计算“删除”边后的子树大小。 组合公式计算一侧至少有一种红色、另一侧至少有一种蓝色、并且所有其他顶点都空闲的所有着色。 乘以 2 即可交换红蓝边。 模运算避免溢出。
