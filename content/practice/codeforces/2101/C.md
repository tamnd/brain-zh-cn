 ## 解决方案
 ## 问题理解

 我们被要求最大化从给定数组派生的数组的“美感”`a`。 对于每个位置`a`，新数组`b`必须满足`1 ≤ b_i ≤ a_i`。 之美`b`是每个值重复出现之间最大差距的总和`b`。 具体来说，对于一个值`x`,`d_x(b)`是第一次出现和最后一次出现之间的距离`x`在`b`。 如果`x`发生一次或根本不发生，`d_x(b) = 0`。 总的美丽是所有美丽的总和`d_x(b)`对于存在于`b`。 

输入尺寸`n`每个测试用例可以达到 200,000 个，所有测试用例的总数也以 200,000 个为界。 迭代所有可能数组的简单方法`b`显然这是不可能的，因为组合的数量呈指数级增长。 该算法必须接近线性`n`，否则会超时。 的限制`a_i`(`1 ≤ a_i ≤ n`）意味着潜在的价值`b`的边界是`n`以及。 

非明显边缘情况包括所有值都相同的数组、值严格递增或递减的数组以及边缘有重复值的数组。 例如，如果`a = [1, 1, 1, 1]`，任意选择`b`也将是`[1, 1, 1, 1]`美丽的是`3`， 不是`0`。 如果`a = [1, 2, 1, 2]`，选择`b = [1, 2, 1, 2]`最大化距离。 天真的尝试简单地选择最大值或贪婪的顺序分配通常会在边缘放置上失败，特别是当相同的数字可以多次出现但距离不同时。 

## 方法

 暴力方法将枚举所有可能的数组`b`满足`1 ≤ b_i ≤ a_i`并计算每个的美丽度。 对于每个数组，我们将跟踪每个数字的位置并计算`d_x(b)`作为最大距离。 这是正确的但不可行：如果每个`a_i`的数量很大，`b`数组呈指数增长。 即使与`n = 20`，如果元素为，则数组数量超过一百万`a`是无限的，使得暴力无法使用。 

关键的见解是最大化`d_x(b)`对于一个值`x`，我们只需要放置`x`在最左边和最右边的位置`x`是允许的。 中间位置不会增加距离。 因此，对于每个可能的值`x`，我们跟踪位置`a`在哪里`x`可能会出现（`x ≤ a_i`）。 那么最大距离为`x`是`last - first`， 在哪里`first`和`last`是该列表中的第一个和最后一个索引。 美是一切的总和`x`。 这将问题简化为线性扫描`a`以及每个值的候选位置，每个测试用例的时间复杂度为 O(n)。

 ## 算法演练

 1.读取测试用例的数量。 循环每个测试用例。 
2. 对于每个测试用例，请阅读`n`和数组`a`。 
3.初始化字典`positions`映射每个潜在值`x`到一个空列表。 
4. 遍历数组`a`按索引。 对于每个`i`, 附加`i`到`positions[x]`为所有人`1 ≤ x ≤ a[i]`。 
5. 对于每个值`x`出现在`positions`，计算距离为`positions[x][-1] - positions[x][0]`。 
6. 将所有这些距离相加`x`为测试用例获得最大的美感。 
7. 输出结果。 

第 4 步的推理很微妙。 我们不需要跟踪每个数字`a_i`; 相反，我们只跟踪实际出现的数字`a`至少一次。 计算距离时，我们只考虑数字`x`这样`x ≤ a_i`在某个位置。 这确保了正确性，同时避免了不必要的存储。 

为什么有效：通过放置每个数字`x`在其最早和最晚允许的位置，我们最大限度地发挥其对美丽的贡献。 任何中间放置都不会增加最大间隙。 由于贡献是独立的，因此将它们相加会产生全局最大的美感。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        from collections import defaultdict
        positions = defaultdict(list)
        
        for i, val in enumerate(a):
            positions[val].append(i)
        
        beauty = 0
        for val, pos_list in positions.items():
            if len(pos_list) > 1:
                beauty += pos_list[-1] - pos_list[0]
        
        print(beauty)

if __name__ == "__main__":
    main()
```该解决方案使用快速读取输入`sys.stdin.readline`。 字典`positions`收集每个值出现的索引。 通过计算每个值的最后一个索引和第一个索引之间的差异，我们可以有效地计算最大距离。 单次出现自动贡献零，并且数组外部的值永远不会出现在`positions`。
