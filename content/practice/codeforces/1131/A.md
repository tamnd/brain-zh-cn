 ## 解决方案
 ## 问题理解

 船是由两个轴对齐的矩形堆叠而成。 下面的矩形有宽度`w1`和身高`h1`。 上面的矩形有宽度`w2`和身高`h2`，它从第一个矩形的正上方开始，左边缘对齐。 

飞船被摧毁后，每一个与飞船侧面或角落接触的单元都必须被标记。 属于船舶本身的单元不计算在内。 场是无限的，所以我们只需要计算形状周围的单元格即可。 

输入给出两个矩形的尺寸。 输出是组合形状周围标记单元的数量。 

约束允许尺寸达到`10^8`。 该大小的矩形包含太多单元格，无法单独枚举。 甚至储存船只也是不可能的。 任何依赖于单元格迭代的解决方案都被排除。 我们需要一个在恒定时间内运行的直接数学公式。 

一个常见的错误是将船视为单个宽度的矩形`w1`和身高`h1 + h2`。 这仅在以下情况下有效`w1 = w2`。 考虑：```
w1 = 4, h1 = 1
w2 = 2, h2 = 1
```上方的矩形较窄，在右侧创建了一个垂直台阶。 该台阶周围的单元格提供了简单的周长公式会忽略的额外标记单元格。 

当宽度相等时，会出现另一种微妙的情况：```
w1 = 2, h1 = 1
w2 = 2, h2 = 1
```形状实际上是一个`2 × 2`长方形。 任何盲目增加宽度差贡献的公式都会过量计算，因为没有步骤。 

最小情况```
w1 = 1, h1 = 1
w2 = 1, h2 = 1
```对于检查差一错误很有用。 该船占据两个堆叠的单元格，必须标记周围的十个单元格。 

## 方法

 强力解决方案将明确地在网格上构建船舶，然后检查每个船舶单元周围的每个相邻位置。 如果一个单元接触至少一个船舶单元并且其本身不是船舶的一部分，则该单元被标记。 

这种方法是正确的，因为它直接遵循定义。 问题在于规模。 一个矩形最多可以包含`10^8 × 10^8`细胞，所以船可能包含周围`10^16`细胞。 枚举它们是完全不可能的。 

关键的观察结果是，我们只需要形状周围一单元格边框中的单元格数量。 

想象一下绘制一艘船，然后将其向各个方向扩展一个单元格。 除船舶单元本身外，每个标记的单元都属于此扩展轮廓。 

我们可以计算形状边界的贡献，而不是推理单个细胞。 

从外边框开始：

 左侧有贡献`h1 + h2`细胞。 

右侧也有贡献`h1 + h2`细胞。 

底层贡献`w1`细胞。 

顶层贡献`w2`细胞。 

四个外角又贡献了四个单元。 

到目前为止我们有：```
2(h1 + h2) + w1 + w2 + 4
```现在考虑上部矩形较窄的水平边缘。 宽度差`w1 - w2`创建一个垂直的台阶。 围绕该步骤，我们需要在其上方和下方添加额外的标记单元，以贡献`2(w1 - w2)`细胞。 

最后，两个矩形之间的连接在过渡附近贡献了两个角单元。 

结合一切：```
answer =
2(h1 + h2)
+ 2(w1 + w2)
+ 4
+ (w1 - w2)
+ (w1 - w2)
```简化为：```
answer = 2*(h1+h2) + 2*(w1+w2) + 4 + 2*(w1-w2)
```这正是公认的解决方案所使用的公式。

 ## 算法演练

 1. 阅读`w1`,`h1`,`w2`， 和`h2`。 
2. 计算形状垂直边的贡献：```
2 * (h1 + h2)
```每侧都跨越船的整个高度。 
3. 计算水平边界的贡献：```
2 * (w1 + w2)
```底边有宽度`w1`顶边有宽度`w2`。 
4. 添加四个外角单元：```
+4
```5. 考虑创建的步骤`w1 > w2`。 

暴露的水平差异有助于：```
2 * (w1 - w2)
```6. 打印结果值。 

### 为什么它有效

 每个标记的单元恰好位于船舶边界之外的一个单元。 该公式计算所有此类边界位置。 

涉及高度的术语计算与左侧和右侧相邻的单元格。 涉及宽度的术语计数与顶部和底部相邻的单元格。 常数`4`占四个外角。 当上部矩形较窄时，会出现额外的暴露台阶，并且其相邻单元格的贡献正好`2(w1 - w2)`更多职位。 

每个标记的单元格都会被计数一次，并且每个所需的标记单元格都属于这些边界块之一。 由于该形状仅由两个对齐的矩形组成，因此这些贡献完全描述了边界。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

w1 = int(input())
h1 = int(input())
w2 = int(input())
h2 = int(input())

ans = 2 * (h1 + h2)
ans += 2 * (w1 + w2)
ans += 4
ans += 2 * (w1 - w2)

print(ans)
```该实现是派生公式的直接转换。 

第一项对与两个垂直边相邻的单元格进行计数。 第二项对顶部和底部边界附近的单元格进行计数。 常数`4`占外角。 最后一项处理当上部矩形较窄时出现的步骤。 

所有算术都适合 Python 整数。 即使在最大尺寸下，答案也仅约为`10^9`。

# helper: run solution on input string, return output string
import sys, io

def solve():
    w1 = int(input())
    h1 = int(input())
    w2 = int(input())
    h2 = int(input())

    ans = 2 * (h1 + h2)
    ans += 2 * (w1 + w2)
    ans += 4
    ans += 2 * (w1 - w2)

    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out
