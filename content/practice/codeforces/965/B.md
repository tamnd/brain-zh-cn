 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$网格中的每个单元格要么被禁止，要么被允许。 禁止单元格标有`#`并且永远不能成为船舶的一部分。 允许的单元格标记为`.`并且可能是船的一部分。 

船是一条直线$k$连续的单元格，水平或垂直放置。 我们考虑这样一艘完全位于网格内并且仅使用允许的单元格的船舶的每个有效放置。 每个有效的放置都是一个具体的段，由其方向和起始位置定义。 

任务不是选择船舶放置位置。 相反，我们会同时想象所有有效的展示位置，并且对于每个单元格，我们都会计算其中有多少个展示位置包含它。 我们必须返回计数最大的任何单元格。 

限制条件$n \le 100$和$k \le n$至多暗示$10^4$细胞，最多$O(n^2)$候选片段水平和垂直。 任何明确枚举所有布局并更新每个单元贡献的解决方案在几百万次操作内都是可行的。 

一个微妙的问题是有效段必须完全包含在`.`细胞。 仅检查端点或假设连续性而不验证所有中间单元的简单方法将会过多计算无效布局。 另一个陷阱是在聚合每个单元格的贡献时完全忘记垂直段或错误地重复计算重叠段。 

## 方法

 暴力方法将枚举两个方向的每个可能的起始位置，验证长度段是否$k$是完全有效的，如果是这样，则为所有的计数器增加一个计数器$k$该段中的细胞。 这是正确的，因为它直接反映了有效船舶放置的定义。 成本来自重新计算有效性和更新$k$每个候选片段的单元格。 有$O(n^2)$起始位置和每次更新成本$O(k)$, 给予$O(n^2 k)$，在最坏的情况下达到约$10^6 \cdot 100 = 10^8$运营。 这是边界，但考虑到更简单的观察是不必要的。 

关键的观察是我们实际上不需要独立模拟每个部分。 对于每个单元格，我们只需要知道有多少个水平段和垂直段的长度$k$盖住它。 当且仅当该段有效并且完全位于连续的块中时，该段才会对单元做出贡献。`.`单元格至少跨越$k$长度。 

这使我们能够有效地预先计算所有有效的水平段和垂直段，然后对于每个有效段，我们直接更新其贡献$k$细胞。 因为每个部分仍然需要花费$O(k)$，我们可能会担心我们没有改进渐近，但是$n \le 100$使得这仍然很快。 更重要的是，我们避免了重复检查并简化了正确性：每个有效段仅处理一次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举|$O(n^2 k)$|$O(n^2)$| 已接受但紧张 |
 | 段枚举+标记|$O(n^2 k)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 预先计算所有水平有效长度段$k$。 对于每一行，从左到右扫描并识别最大连续块`.`。 每个长度块内$L$, 每个子段的长度$k$是有效的，所以有$L-k+1$从不同列开始的段。 
2. 对于每个有效的水平线段，起始于$(i, j)$，为每个单元格增加一个贡献计数器$(i, j), (i, j+1), \dots, (i, j+k-1)$。 这直接计算每个单元格包含多少个有效展示位置。 
3. 对垂直线段重复相同的过程。 对于每一列，找到连续的`.`块并枚举长度的所有垂直段$k$。 
4. 保持全局$n \times n$大批`cnt`初始化为零。 每次找到有效段时，都会增加它覆盖的所有单元格。 
5. 处理完两个方向后，扫描整个网格并选择具有最大值的单元格`cnt`。 如果多个单元共享最大值，则可以返回任何一个。 

### 为什么它有效

 每个有效的船舶放置恰好对应于完全位于连续区域内的一个水平或垂直段。`.`堵塞。 该算法将每个这样的段精确地枚举一次。 每次我们遇到一个片段时，我们都会将一个贡献单位分配给它占据的每个单元格。 因此，存储在单元格中的值正是包含该单元格的有效船舶放置的数量。 在所有单元格上最大化该值可以直接解决问题。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def add_segment(cnt, i, j, di, dj, k):
    for _ in range(k):
        cnt[i][j] += 1
        i += di
        j += dj

n, k = map(int, input().split())
grid = [input().strip() for _ in range(n)]

cnt = [[0] * n for _ in range(n)]

# horizontal segments
for i in range(n):
    j = 0
    while j < n:
        if grid[i][j] == '#':
            j += 1
            continue
        start = j
        while j < n and grid[i][j] == '.':
            j += 1
        length = j - start
        if length >= k:
            for s in range(start, j - k + 1):
                add_segment(cnt, i, s, 0, 1, k)

# vertical segments
for j in range(n):
    i = 0
    while i < n:
        if grid[i][j] == '#':
            i += 1
            continue
        start = i
        while i < n and grid[i][j] == '.':
            i += 1
        length = i - start
        if length >= k:
            for s in range(start, i - k + 1):
                add_segment(cnt, s, j, 1, 0, k)

best_i, best_j = 0, 0
best_val = -1

for i in range(n):
    for j in range(n):
        if cnt[i][j] > best_val:
            best_val = cnt[i][j]
            best_i, best_j = i, j

print(best_i + 1, best_j + 1)
```功能`add_segment`概括了将一个有效的船舶放置的贡献分配到其所有单元的想法。 这避免了水平和垂直处理的重复代码，并使更新逻辑明确。 

行和列扫描逻辑依赖于对连续的分组`.`将细胞分成最大块。 这很重要，因为线段不能交叉`#`细胞。 在每个块中，我们只开始全长的片段$k$仍然适合。 

最终扫描只是选择最大条目`cnt`，+1 移位处理问题的 1 索引输出要求。

def run(inp: str) -> str:

    import sys as _sys
    input = _sys.stdin.readline

    cnt = [[0] * n for _ in range(n)]

    def add(i, j, di, dj):
        for _ in range(k):
            cnt[i][j] += 1
            i += di
            j += dj

        j = 0
        while j < n:
            if grid[i][j] == '#':
                j += 1
                continue
            s = j
            while j < n and grid[i][j] == '.':
                j += 1
            for st in range(s, j - k + 1):
                add(i, st, 0, 1)

    for j in range(n):
        i = 0
        while i < n:
            if grid[i][j] == '#':
                i += 1
                continue
            s = i
            while i < n and grid[i][j] == '.':
                i += 1
            for st in range(s, i - k + 1):

    bestv = -1

 ## 边缘情况

 当网格不包含有效长度段时$k$，贡献矩阵保持全零。 在这种情况下，算法仍然返回 (1,1)，因为不存在更好的候选者。 这符合问题的要求，即任何单元格都是可接受的。 

什么时候$k = 1$， 每一个`.`单元格本身形成一个有效的段。 该算法将每个单元格视为长度为 1 的片段，因此每个允许的单元格对自身的贡献恰好为 1，而禁止的单元格则不贡献任何内容。 因此最大值是任意的`.`单元格，扫描自然会选择一个。 

当长块`.`细胞存在，重叠部分的贡献主要集中在中央细胞。 该算法正确地累积多个重叠窗口，确保内部单元接收到的计数高于边界单元，这与覆盖片段的真实数量相匹配。
