 ## 解决方案

 ## 问题理解

 一群人想要生产相同的纸飞机，但制造飞机的唯一方法是通过纸张间接制造。 每张纸可以折叠成固定数量的飞机，并且纸张仅以包装形式出售，每包包含固定数量的纸张。 

需求结构简单，但约束条件分层。 每个人必须能够独立建造固定数量的飞机。 由于多架飞机来自一张单张，我们首先将飞机需求转换为每人的单张需求，然后按人数进行缩放，最后将单张转换为包，因为不可能购买碎片包。 

关键数量是总共需要多少张。 如果每张纸产生`s`飞机，那么每个人都需要`ceil(n / s)`工作表，因为不存在部分工作表。 穿过`k`人，总纸张需求变为`k * ceil(n / s)`。 一旦我们知道了张数，我们就将其转换成包装尺寸`p`使用另一个天花板分区。 

约束足够小，任何恒定时间算术解决方案都足够。 所有变量最多为 10^4，因此即使直接乘法也只能达到 10^8，这对于 Python 来说完全在整数范围内，并且不需要超出 O(1) 计算的优化。 

发生错误的主要地方是正确处理舍入。 例如，如果一个人需要 5 架飞机，而每张纸可以生产 2 架飞机，那么 2 张纸只能生产 4 架飞机，这是不够的。 单纯的整数除法会错误地分配 2 张而不是 3 张。将纸张转换为包时，同样的问题会再次出现。 

另一个微妙的错误是应用上限划分太晚或太早。 例如，乘以后舍入`k`由于线性，而不是每个人仍然可以在这里工作，但是当不小心实施时，在错误的阶段进行舍入通常会导致相差一的错误。 

## 方法

 思考这个问题的一种暴力方式是模拟一个一个地购买包裹，分发单子，并检查是否所有人都能生产足够的飞机。 每增加一个包后，我们都会重新计算可以生产多少架飞机并验证需求。 虽然概念上很简单，但这种方法效率低下，因为包的数量可能会变大，并且每次检查都需要重新计算所有纸张的总产量，从而导致对每个候选包数进行重复的 O(k) 评估。 

然而，问题的结构消除了任何模拟的需要。 每包贡献固定数量的纸张，每张贡献固定数量的飞机，每个人都有相同的需求。 这将问题转化为确定性转换流程：每人的飞机数到每人的床单数，然后到总床单数，然后到包装数。 

关键的观察结果是，除了在划分边界处向上取整之外，所有变换都是线性的。 一旦我们意识到我们只需要满足全局最小张数，问题就减少到计算单个上限除法两次。

 ## 算法演练

 1. 计算一个人需要制作多少张纸`n`飞机。 由于每张纸都使`s`飞机，我们计算`need_per_person = ceil(n / s)`。 这可以确保即使飞机没有均匀地分配每张飞机，也不会出现人员供应不足的情况。 
2. 将每人需求乘以人数转换为总需求：`total_sheets = k * need_per_person`。 这种聚合之所以有效，是因为每个人的需求都是独立且相同的。 
3. 将纸张转换为包装。 每包包含`p`张数，所以包数为`packs = ceil(total_sheets / p)`。 这确保我们永远不会购买部分包。 
4. 打印计算出的包数。 

主要的微妙之处是确保两个分区都是天花板分区，而不是楼层分区。 单个错过的舍入步骤会低估需求并产生无效的解决方案。 

### 为什么它有效

 该算法之所以有效，是因为每个约束都是单调和线性的：更多的纸张永远不会降低生产飞机的能力，并且每次转换都保留了可行性。 唯一的不连续性来自于每架飞机的纸张和每张纸张的包装的不可分割性，并且两者都是通过天花板划分来精确处理的。 一旦考虑了两个舍入点，计算出的数字就是满足所有约束的最小值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

k, n, s, p = map(int, input().split())

need_per_person = (n + s - 1) // s
total_sheets = k * need_per_person
packs = (total_sheets + p - 1) // p

print(packs)
```第一行计算每张飞机的上限划分。 第二个是所有人的总和。 最后一条生产线使用相同的天花板图案将板材转换成包装。 表达式`(x + d - 1) // d`是 Python 中天花板除法的标准整数技巧，避免浮点运算并保留约束中所有整数范围的正确性。

 ## 边缘情况

 一种极端情况是一张纸已经足够一个人使用。 对于输入：```
k=4, n=1, s=10, p=3
```每个人都需要`ceil(1/10)=1`床单。 总张数为 4 张，每包为`ceil(4/3)=2`。 该算法正确地避免了由于分数表而导致的低估。 

另一种极端情况是包装尺寸大于总张数要求。 对于输入：```
k=1, n=5, s=2, p=100
```我们得到`ceil(5/2)=3`张，所以总共是 3 张。 即使只需要3张，也必须购买一整包。 该算法产生`ceil(3/100)=1`，正确处理Pack粒度造成的供过于求。
