 ## 解决方案
 ## 问题理解

 我们在平面上有一组点，代表布料上的点。 缝纫序列描述了穿过这些点的过程。 序列中的每一对连续的点都会创建一个边缘，但这些边缘在布料的正面和背面之间交替。 目标是使用尽可能短的序列使两边包含一个连通的、不交叉的图。 

长度序列`k`准确地创造`k - 1`总计边数。 正面在以下位置接收边缘`(1,2), (3,4), ...`，而背面接收剩余的交替边缘。 每一侧都必须连接所有`N`点，所以每一方至少需要`N - 1`边，因为连通图`N`顶点的边数不能少于树的边数。 

这立即给出了下限。 两侧合计至少需要`2(N - 1)`边，所以序列至少需要`2(N - 1) + 1 = 2N - 1`点。 自从`N`至多是`1000`，即使是二次算法在许多设置中也是可以接受的，但实际结构允许更简单的线性构造。 我们不需要诸如凸包或相交检查之类的几何算法。 

主要的边缘情况来自于对“最短”含义的误解。 目标是序列中的位置数，而不是绘制线段的总长度。 

例如，有两个点：```
Input
2
10 10
20 20
```正确的输出长度是`3`，序列如下：```
3
1 2 1
```粗心的解决方案可能会尝试创建两个不同的边或两个不同的生成树，但允许两侧使用相同的几何边。 正面和背面是单独的层。 

另一种边缘情况是所有点排列成复杂形状时：```
Input
4
1 1
100 1
50 50
20 80
```正确的输出仍然有长度`7`。 一个幼稚的实现可能会尝试找到所有点的特殊非交叉排序，但这是不必要的，因为以任何点为中心的星形始终是非交叉的。 

## 方法

 许多人的第一个想法是显式地构造两个不同的平面生成树。 由于每棵生成树都有`N - 1`边，答案就是这两棵树之间交替的序列。 这是正确的，但它会产生不必要的工作。 找到合适的平面树，然后将它们的边缘排列成有效的交替序列，比实际问题所需的要困难得多。 

蛮力观点是我们需要`2N - 2`边总数，我们可能会在可能的树中搜索。 完整图中可能的生成树数量是巨大的。 为了`N`点，完整的图包含`N(N-1)/2`可能的边，并且可能的树的数量是指数级的，因此这种方法立即变得不可能。 

关键的观察是同一棵树可以出现在布料的两面。 双方是独立的。 如果我们选择一个点作为中心，将所有其他点连接到它，并在另一侧重复这些相同的边，则两侧都已连接且平坦。 

星形图始终是平面的，因为每条边共享相同的端点。 顺序```
center, vertex1, center, vertex2, center, vertex3, ..., center
```在两侧交替创建星形边缘。 每隔一条边属于前面，其余的边属于后面。 双方均收到准确的`N - 1`边缘。 

下界证明长度序列`2N - 1`是最好的，并且构建达到了这个界限。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| O(N²) | 太慢了|
 | 最佳 | O(N) | O(N) | 已接受 |

 ## 算法演练

 1. 选择任意一点作为星星的中心。 第一个点之所以有效，是因为该问题没有对哪个点成为中心施加任何限制。 
2. 输出中心点，然后输出另一个点，然后再次输出中心点，重复此模式，直到每个非中心点都出现一次。 

这使得每对连续的点都形成星形边缘。 缝纫顺序的交替性质自动将这些边缘分布在两侧之间。 
3. 计算生成的序列长度并打印。 长度始终是`2N - 1`，这是可能的最小长度。 

工作原理：正面接收序列的所有其他边缘。 这些边都是所选中心和另一个点之间的连接，因此正面是包含每个点的星形。 背面接收剩余的边缘，这些边缘与布料另一侧的星形边缘相同。 一颗星是相连的，除了公共中心外，它的任何两条边都不能交叉。 由于任何有效的解决方案至少需要`2N - 1`序列位置，这种结构是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    for _ in range(n):
        input()

    ans = [1]
    for i in range(2, n + 1):
        ans.append(i)
        ans.append(1)

    print(len(ans))
    print(*ans)

if __name__ == "__main__":
    solve()
```该实现在读取坐标后忽略它们，因为构造不依赖于点的几何排列。 任何选定的中心都有效。 

序列以点开头`1`。 对于每隔一个点`i`，我们追加`i`然后返回中心。 返回的中心是必要的，因为下一条边必须继续在边之间交替，同时仍然属于同一颗星。 

最终序列包含`1 + 2(N - 1)`值，这正是`2N - 1`。 不存在边界问题，因为循环仅在非中心点上运行。

 ## 边缘情况

 对于两个点，该算法产生：```
1 2 1
```第一个边缘位于正面，第二个边缘位于背面。 双方都包含唯一可能的连接，因此两者都是连接的。 

对于已经处于困难几何排列的点，例如形成凸多边形或随机云的许多点，该算法仍然选择一个中心并仅从该中心绘制线段。 由于所有线段共享一个端点，因此任何一对边都不能在其内部相交。 

对于最大输入尺寸，算法不执行任何几何计算。 它仅存储和打印`1999`整数，因为最短序列有长度`2 * 1000 - 1`。 这使运行时间保持线性并避免不必要的复杂性。
