 ## 解决方案
 ## 问题理解

 我们拥有最多18个城市的无向公路网。 每条现有道路都必须分配其两个可能方向之一，并且所选择的方向必须使整个有向图强连通。 成本取决于每条道路所选择的方向，因此任务是找到最便宜的有效方向或报告不存在有效方向。 

的小值`N`是主要线索。 共有18个城市`2^18`可能的子集，大约有262,000个。 这排除了尝试每条边的每个方向的任何情况，因为即使稀疏图也可以有许多边，并且方向的数量随着道路的数量呈指数增长。 该解决方案必须直接使用顶点限制，这指向位掩码动态编程。 

有几个案例很容易被忽视。 如果图根本不连通，则任何方向都无法使每个城市都可达。```
3
-1 5 -1
5 -1 -1
-1 -1 -1
```答案是`-1`因为城市 3 是孤立的。 仅检查局部边缘选择的方法可能会错误地假设每条道路都可以独立定向。 

第二个陷阱是一个连通但有桥的图。```
3
-1 1 -1
1 -1 2
-1 2 -1
```答案是`-1`。 为一侧和另一侧之间的唯一道路选择的任何方向都会导致一个端点无法返回。 强大的连接需要的不仅仅是普通的连接。 

当每条边都已包含在所选结构中时，就会出现最终的实施问题。 例如：```
2
-1 7
3 -1
```唯一可能的定向成本`7`如果道路从城市 1 定向到城市 2 并且`3`在另一个方向。 答案是`3`。 假设必须选择两个方向或者始终只能使用更便宜的方向的解决方案将会失败。 

## 方法

 直接方法将尝试所有道路的每一种可能的方向，并保留产生强连通有向图的最便宜的方向。 这是正确的，因为每个可能的答案都会被检查。 然而，如果有`m`道路，搜索空间有大小`2^m`。 如果有 18 个城市，则该图可以有 153 条道路，这完全不可能。 

有用的观察来自于强连通有向图的表征。 强连通图可以通过从一个顶点开始并重复添加一个“耳朵”来构建，“耳朵”是一条有向路径，其端点已经在当前强连通部分内部，而所有内部顶点都是新的。 第一个顶点已经是一个有效的起始强连通图，并且每个添加的耳朵都保持强连通性。 

这将问题转化为子集 DP。 我们不是一次性决定所有边缘，而是采用最便宜的方式来构建一组紧密连接的城市。 从这个状态开始，我们寻找下一个引入新城市的耳朵。 

还有一种成本技巧。 每条路最终都必须有方向，因此首先支付每条路更便宜的方向。 如果我们后来选择更贵的方向，我们只需支付额外的差价。 这使得 DP 只将额外成本降至最低，从而避免了施工期间担心未使用的道路。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^m) | O(2^m) | O(米) | 太慢了|
 | 耳朵分解DP | O(2^N N^3) | O(2^N N^3) | O(2^N N^2) | O(2^N N^2) | 已接受 |

 ## 算法演练

 1. 对于每条道路，从两个方向中减去其两个方向成本中更便宜的一个。 将所有这些更便宜的成本添加到基本答案中。 剩余的值代表选择非廉价方向的额外费用。 
2.让`f[mask]`是使城市处于`mask`紧密相连。 我们修复城市`0`作为初始城市，因此唯一有效的起始状态是`mask = 1`。 
3. 维持另一个DP状态`g[mask][x][y][b]`。 这意味着我们当前正在构建一个耳朵，其当前端点是`x`，其在现有组件内的最终端点是`y`， 和`b`指示是否使用直接边缘`x -> y`是允许的。 
4. 每当耳朵到达其最终端点时，用最后一个边缘将其关闭并更新`f[mask]`。 额外标志的原因是仅包含闭合边缘的路径在构造期间并不总是有效。 
5. 从每个强连接状态开始新的耳朵。 选择组件中已有的两个城市作为端点，并将一个传出边缘带到组件外部的城市。 
6. 通过从当前端点移动到当前集合之外的新城市来扩展未完成的耳朵。 每一次这样的转变都会增加该边缘的剩余成本。 
7. 处理完所有子集后，`f[(1 << N) - 1]`包含强连接方向的最小额外成本。 将基本成本加回来。 如果状态不存在，则图不能是定向强连通的。 

为什么它有效：不变的是每个可达的`f[mask]`代表了其中城市的有效强连接方向`mask`。 添加耳朵可以保持强大的连接性，因为新顶点具有进出现有组件的定向路径。 相反，每个强连通有向图都有耳分解，因此可以通过这些转换的一个序列生成最佳方向。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    cost = [list(map(int, input().split())) for _ in range(n)]

    base = 0
    for i in range(n):
        for j in range(i + 1, n):
            if cost[i][j] != -1:
                mn = min(cost[i][j], cost[j][i])
                base += mn
                cost[i][j] -= mn
                cost[j][i] -= mn

    total = 1 << n
    inf = 10**18

    f = [inf] * total
    g = [dict() for _ in range(total)]

    f[1] = 0

    for mask in range(1, total):
        if (mask & 1) == 0:
            continue

        cur = g[mask]

        for (u, v, can_close), val in list(cur.items()):
            if can_close and cost[u][v] != -1:
                nv = val + cost[u][v]
                if nv < f[mask]:
                    f[mask] = nv

        if f[mask] != inf:
            vertices = [i for i in range(n) if mask >> i & 1]
            for u in vertices:
                for v in vertices:
                    key = (u, v, 0)
                    if f[mask] < cur.get(key, inf):
                        cur[key] = f[mask]

        for (u, v, can_close), val in list(cur.items()):
            for w in range(n):
                if mask >> w & 1:
                    continue
                if cost[u][w] == -1:
                    continue
                nmask = mask | (1 << w)
                ncan = 1 if (can_close or u != v) else 0
                key = (w, v, ncan)
                nv = val + cost[u][w]
                if nv < g[nmask].get(key, inf):
                    g[nmask][key] = nv

    ans = f[-1]
    if ans == inf:
        print(-1)
    else:
        print(base + ans)

if __name__ == "__main__":
    solve()
```预处理部分将原始成本转化为“额外成本”。 每条边都会立即贡献其最便宜的可能方向，并且 DP 仅在需要另一个方向时才付费。 

这`f`数组存储完整的耳朵，而里面的字典`g`存放部分建成的耳朵。 使用字典而不是完整的四维数组，因为许多理论状态从未发生。 

每个掩码的操作顺序都很重要。 首先使用完整的耳朵来更新强连接状态。 然后从改善的状态开始新的耳朵，最后这些耳朵扩展到更大的面具。 因为转换仅添加顶点，所以每个未来状态都有一个更大的位掩码，并将在稍后处理。

## 复杂度分析

 | 测量| 复杂性 | 说明|

 | 时间 | O(2^N N^3) | O(2^N N^3) | 每个子集都可以包含耳朵状态，并且转换会尝试可能的端点和下一个顶点 |

 ## 边缘情况

 对于断开连接的图：```
3
-1 5 -1
5 -1 -1
-1 -1 -1
```DP 从城市 0 开始。任何耳朵序列都无法引入城市 2，因为没有边缘进入或离开城市。 最终的完整掩码仍然无法到达，因此算法打印`-1`。 

对于桥的情况：```
3
-1 1 -1
1 -1 2
-1 2 -1
```民主党可以修建一条穿过所有三个城市的道路，但它不能堵住为每个城市提供返回路线的耳朵。 该不变量无法产生完整的强连通状态，因此结果是正确的`-1`。 

对于两个城市的情况：```
2
-1 8
3 -1
```基础预处理消除了更便宜的成本`3`。 The remaining DP cost is zero because choosing the cheaper orientation already makes the graph strongly connected. 打印出来的答案是`3`。
