 ## 解决方案
 ## 问题理解

 我们有一套教科书。 每本教科书都有一个主题标识符和一个代表老虎喜欢它的程度的值。 这些查询不会询问原始集合中的位置。 相反，每个查询都会给出一系列可能的主题频率，我们必须通过考虑该范围内的每个有序频率对来计算产生的分数。 

对于一个频率`k`， 定义`cnt[k]`作为准确出现的主题数量`k`次。 在所有出现频率的主题中`k`， 定义`best[k]`作为最大的享受价值。 对于两个频率`i`和`j`，他们的贡献为零，除非`cnt[i]`和`cnt[j]`是平等的。 如果它们相等并且两个频率都存在，那么最好的一对书就有价值`best[i] * best[j]`。 查询答案是所有有序对的这些贡献的总和`(i, j)`在查询区间内。 

输入规模大：课本数量和查询数量都可以达到`5 * 10^5`。 扫描每个查询的每个可能频率的解决方案需要大约`2.5 * 10^11`最坏情况下的操作，远远超出了两秒的限制。 我们需要避免依赖于整个频率范围。 

隐藏在频率表示中的关键约束是实际出现的不同频率的数量很少。 如果有`s`不同的正频率，最小可能的教材总数为：`1 + 2 + 3 + ... + s`。 

由于这笔金额不能超过`n`,`s`最多是关于`1000`什么时候`n = 500000`。 这彻底改变了问题。 我们只需要存储和处理存在的频率。 

一些边缘情况很容易被忽略。 没有主题的频率无法做出贡献，即使两个缺失的频率在技术上具有相同的零主题数。 例如：```
n = 1
topics = [5]
values = [10]
query = [2, 3]
```没有题目出现两三次，所以答案是`0`。 一个粗心的实现，所有人都是平等的`cnt[k]`值而不检查是否`cnt[k] > 0`可能会错误地添加零频率组。 

另一种特殊情况是查询仅包含一个现有频率。 例如：```
n = 3
topics = [1, 1, 1]
values = [5, 7, 9]
query = [3, 3]
```仅频率`3`存在。 答案是`9 * 9 = 81`，因为三本书中的最大值是`9`。 使用所有值的总和而不是最大值会给出错误的结果。 

最后的边界情况是当查询范围超出最大可能频率时。 例如：```
query = [100, 1000000000]
```仅频率高达`n`可以存在。 额外的范围必须被忽略。 

## 方法

 直接的解决方案首先构建频率信息，然后通过迭代之间的每个可能的频率来回答每个查询`L`和`R`。 这是正确的，因为每个频率对都可以独立评估。 然而，频率范围可以大到`10^9`在查询中，甚至将其限制为`n = 500000`会使每个查询都太慢。 最坏的情况大约是`5 * 10^5 * 5 * 10^5`频率检查。 

重要的观察结果是频率计数数组极其稀疏。 价值`cnt[k]`仅对于主题中出现的频率才非零。 主题可以有很多，但不能有很多不同的正频率，因为每一个新频率都会比前一个频率消耗更多的教科书。 

对于每个现有频率`k`，我们保留这对`(k, best[k])`。 频率相同`cnt[k]`属于同一组。 如果一个组包含频率`k1, k2, ...`，那么在查询中，该组中所有有序对的贡献为：`(best[k1] + best[k2] + ...)^2`因为组中的每个频率都可以与同一组中的每个其他频率配对，包括其自身。 

现有频率数量最多约为`1000`，因此每个组可以简单地存储其排序的频率。 对于查询，我们对每个组内的第一个和最后一个频率进行二分搜索，并获得`best`落在区间内的值。 将该总和的平方相加即可得到答案。 

暴力破解之所以有效，是因为它精确地检查了语句中描述的对，但会失败，因为它在许多查询中重复相同频率的比较。 稀疏频率观察使我们能够用一些二分搜索代替巨大的频率范围扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n + qn) | O(n) | 太慢了|
 | 使用二分搜索的稀疏频率组| O(n + q * s log s) | O(n + q * s log s) | O(s) | 已接受 |

 这里`s`是实际发生的不同频率的数量，并且`s <= 1000`。 

## 算法演练

 1. 统计每个主题出现的次数。 这样做的同时，还要记住每个主题的所有书籍中最大的享受价值。 
2. 对于每个主题，使用其最终更新频率`cnt[frequency]`和`best[frequency]`。 存储的值`best[k]`恰好出现的话题中观赏价值最大`k`次。 
3. 收集所有频率`k`在哪里`cnt[k] > 0`。 频率与`cnt[k] = 0`被忽略，因为无法为他们选择有效的教科书。 
4. 按频率对这些频率进行分组`cnt[k]`价值。 每个组代表可以在查询中相互交互的频率。 
5. 对每组内的频率进行排序。 还存储它们的前缀和`best`价值观。 这允许总和`best`通过二分查找可以找到任意查询区间内的值。 
6. 查询`[L, R]`，处理每个组。 找出该组中介于两者之间的频率`L`和`R`。 如果他们的`best`值总和为`x`， 添加`x * x`到答案。 

这种分组起作用的原因是来自不同组的频率具有不同数量的主题，因此这些组之间的每一对贡献为零。 在一组内，每一对贡献相应最佳值的乘积，并且所有有序乘积的总和恰好是总和的平方。 

不变量是每一对有效频率都属于一个频率计数组。 在该组内，前缀和计算准确地包括查询允许的频率，而不包括其他频率。 由于每种可能的贡献都包含一次，因此最终的总和是正确的。 

## Python 解决方案```python
import sys
from collections import defaultdict
from bisect import bisect_left, bisect_right

input = sys.stdin.readline

def solve():
    n, q = map(int, input().split())
    a = list(map(int, input().split()))
    v = list(map(int, input().split()))

    freq = defaultdict(int)
    best_topic = defaultdict(int)

    for x, val in zip(a, v):
        freq[x] += 1
        if val > best_topic[x]:
            best_topic[x] = val

    cnt = defaultdict(int)
    best = defaultdict(int)

    for topic, f in freq.items():
        cnt[f] += 1
        if best_topic[topic] > best[f]:
            best[f] = best_topic[topic]

    groups = defaultdict(list)
    for f in cnt:
        if cnt[f] > 0:
            groups[cnt[f]].append((f, best[f]))

    data = []
    for items in groups.values():
        items.sort()
        freqs = []
        pref = [0]
        for f, val in items:
            freqs.append(f)
            pref.append(pref[-1] + val)
        data.append((freqs, pref))

    ans = []
    for _ in range(q):
        l, r = map(int, input().split())
        cur = 0

        for freqs, pref in data:
            left = bisect_left(freqs, l)
            right = bisect_right(freqs, r)
            if left < right:
                s = pref[right] - pref[left]
                cur += s * s

        ans.append(str(cur))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```代码第一部分将原始教材压缩为主题信息。 此后我们不需要单独的书籍，因为频率只关心具有该频率的主题中的最大值。 

这`groups`字典代表主要观察结果。 其关键在于具有一定频率的主题数量。 共享相同密钥的频率可以一起贡献，而具有不同密钥的频率则不会相互作用。 

对于每个组，排序的频率列表和前缀和数组允许在不扫描每个频率的情况下回答查询。`bisect_left`找到第一个有效频率并`bisect_right`找到最后一个有效频率之后的位置，因此前缀和的差给出了所需的总和`best`价值观。 

Python 整数自动处理较大的答案值。 最大可能分数可以超过 32 位整数限制，因此没有自动大整数的语言将需要 64 位类型。

 ## 边缘情况

 对于频率缺失的情况：```
1 1
5
10
2 3
```唯一存在的频率是`1`。 查询不包含它，因此每个组都有一个空交集。 该算法执行二分搜索，找不到任何值，然后返回`0`。 

对于单频情况：```
3 1
1 1 1
5 7 9
3 3
```主题`1`有频率`3`，最佳值为`9`。 该组仅包含频率`3`，所以选择的总和是`9`贡献是`9 * 9 = 81`。 

对于超出可能范围的查询：```
3 1
1 2 2
4 8 9
10 1000000000
```该间隔内没有存储的频率。 二分搜索为每个组返回空范围，结果为`0`。 

这些情况可以自然地处理，因为该算法永远不会为不可能的频率创建人工条目，并且仅适用于与实际主题相对应的频率。
