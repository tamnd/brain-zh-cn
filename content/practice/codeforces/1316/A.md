 ## 解决方案

 ## 问题理解

 我们有一个教室，每个学生都有一个介于零和某个最大值之间的整数考试分数。 学校允许我们自由改写所有分数，但我们必须保留分数总和，因为保持平均分不变就等于保持总和不变。 

我们的目标仅关注学生 1。我们希望在重新分配后为该学生分配尽可能大的分数，同时仍然能够为其他所有人分配有效的整数分数，每个分数都保持在 0 到 m 的范围内，并保持总和固定。 

因此，问题简化为重新分配任务：我们取固定数量的“分数质量”，等于原始总和，并且我们希望将尽可能多的“分数质量”集中到第一个位置，而不超过每个学生的上限 m。 

约束足够小，即使每个测试用例进行二次或贪婪线性扫描也能轻松通过。 每个测试用例最多有 1000 名学生，最多有 200 个测试用例，即使 O(n^2) 也可以接受，而 O(n) 或 O(n log n) 则微不足道。 这已经表明该解决方案不应涉及复杂的优化结构或搜索。 

当第一个学生已经接近 m 但数组的其余部分太小以至于重新分配理论上可以将其推高时，就会出现微妙的边缘情况。 然而，硬上限阻止了任何此类尝试。 另一个边缘情况是所有学生的分数都相等； 在这种情况下，重新分配不会改变任何事情，只有当总和允许将所有内容集中到一个学生身上时，答案才简单。 

一个常见的错误直觉是认为我们总是可以将学生 1 设置为 m。 当总和太小时，此操作会失败。 例如，如果 n = 4，m = 10，总和为 6，我们不能将 10 分配给任何单个学生，因为我们至少需要 10 个总分数质量单位。 

## 方法

 思考这个问题的强力方法是模拟重新分配。 我们尝试逐步增加学生 1 的分数，并检查剩余的总和是否可以在不超过 m 或低于零的情况下分配给其他学生。 对于学生 1 的每个候选值 x，我们通过验证剩余总和 S - x 是否可以分为 n - 1 个值（每个值在 0 到 m 之间）来检查可行性。 这是正确的，但如果简单地实现的话效率会很低，因为对于每个候选 x，我们可能会重复扫描或重新计算可行性条件。 

关键的观察是，唯一真正的约束是全局的：总和是固定的，并且每个单独的值都是独立有界的。 学生之间不存在超出总和约束的耦合。 这意味着可行性完全取决于剩余金额是否适合其他 n-1 名学生的能力。 

每个学生最多可以容纳 m 个，因此他们的总容量为 (n - 1) * m。 这就给出了一个简单的可行性条件。 如果我们将 x 分配给学生 1，则剩余总和 S - x 必须满足 0 ≤ S - x ≤ (n - 1) * m。 这将问题转化为 x 上的直接不等式约束。 

因此，我们在两个约束下最大化 x：它不能超过 m，并且它不能超过 S 减去其他人所需的最小空间。 由于其他项最多可以采用 (n - 1) * m，因此最大可行 x 只是 S - 0，但受到限制，以便其余项仍然适合。 

最终结果变成直接计算而不是搜索。

 | ---| ---| ---| ---|
 | 暴力重新分配| O(n * m) 或更糟 | O(n) | 太慢/不必要|
 | 最优和为基础的界限| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 计算所有学生成绩的总和S。 该总和是固定的，因为重新分配保留了平均值。 
2. 认识到将值 x 分配给学生 1 后，剩余的总和变为 S - x。 
3. 剩下的n - 1个学生每人最多可以容纳m个，因此他们的总存储容量为(n - 1) * m。 
4. 为了使 x 的选择有效，剩余的总和必须满足 S - x ≤ (n - 1) * m。 重新排列得到 x ≥ S - (n - 1) * m。 
5. 还要强制 x 不能超过 m，因为每个单独的分数都有上限。 
6. 由于我们想要最大可能的 x，因此我们取 x = min(m, S)，但确保已经满足其他可行性，因为当 x 在上限下选择尽可能大的值时，S - x 自动适合剩余容量。 

### 为什么它有效

 关键的不变量是可行性仅取决于总剩余容量，而不取决于单个学生之间的分配。 一旦学生 1 被固定为 x，剩下的问题就简化为检查容量为 m 的 (n - 1) 个槽是否可以恰好吸收 S - x 单位。 由于这些插槽是独立的且容量相同，因此范围内的任何剩余空间始终可以在不违反边界的情况下贪婪地分配。 这消除了任何结构化分配的需要。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    
    s = sum(a)
    
    # maximum possible for student 1 is bounded by:
    # 1) cannot exceed m
    # 2) cannot exceed total sum (we must leave non-negative for others)
    print(min(m, s))
```读取输入后，我们计算所有分数的总和。 然后，答案受到两个独立限制的约束：学生 1 不能超过 m，也不能超过可用总和 S。任何剩余总和始终可分配给其他 n - 1 名学生，因为当 x 被最佳选择时，他们的总容量至少为 S - m，并且边界确保不会发生违规。 

该实现避免了任何模拟或重新分配逻辑。 正确性完全来自于将问题简化为全球容量论证。

 ## 边缘情况

 当 n = 1 时，没有其他学生可以分配，因此唯一的约束是允许的最大分数 m。 该算法计算 min(m, S)，由于 S 等于 a1，因此结果正确地变为 a1，这是唯一可行的分配。 

当所有学生的值都等于 m 时，总和为 n * m。 该公式返回 min(m, n * m) = m，这与学生 1 不能超过每个学生的上限这一事实相符，即使总质量足够大。 

当总和小于 m 时，答案恰好是和。 这对应于将所有可用分数质量集中到学生 1，同时将所有其他分数设置为零，这仍然有效，因为零在范围内。 

这些案例中的每一个都表明，解决方案仅取决于全局容量，而不取决于个体重新排列，从而确认没有隐藏结构影响结果。
