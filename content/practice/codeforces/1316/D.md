 ## 解决方案

 ## 问题理解

 我们得到了一个完整的描述，描述了一个细胞的每个细胞上发生的事情。$n \times n$网格，但仅限于压缩形式。 对于每个起始单元，我们都会被告知重复遵循网格上写入的移动指令的最终结果。 

未知网格中的每个单元格包含五个符号之一。 其中四个的行为类似于到相邻单元的确定性转换，其中之一，$X$，就像进程立即停止的终止状态。 从任何单元格开始，如果我们重复应用这些转换，我们最终要么达到一些$X$细胞并停在那里，或者我们进入一个循环并永远移动。 

这个问题没有给我们网格，而是给我们每个细胞的这个动力系统的结果。 要么一个细胞最终到达一个特定的终端细胞$(x, y)$，或者被标记为导致无限运动，写为$(-1, -1)$。 我们的任务是重建任何能够准确产生这些结果的网格，或者证明不存在这样的网格。 

约束条件允许$n$最多$10^3$，意味着多达一百万个细胞。 任何解决方案在细胞数量上都必须接近线性或近线性。 重复模拟中任何二次或更差的情况都是不可行的。 

一个关键的微妙之处在于，输出并不直接描述网格，而是在单元格上导出函数图。 为每个单元独立分配方向的天真尝试通常会破坏一致性，因为每次分配都会影响全局可达性。 

一种重要的边缘情况是所有细胞都被标记$(-1, -1)$。 这迫使每个单元都成为循环的一部分，并且没有可到达的终端，这意味着必须没有$X$根本不。 粗心的解决方案可能仍会造成一些问题$X$细胞并错误地声称其有效性，但这将立即与这些细胞必须停止的要求相矛盾。 

另一个边缘情况是单单元网格。 如果它被标记为以自身终止，那么它一定是$X$。 如果它被标记为无限，那么它必须通过循环指向自身，这是不可能的，因为除非我们使用方向约束显式构造一个循环，否则不允许自循环。 

## 方法

 一个蛮力的想法是将每个单元格视为具有五种可能状态的变量，并尝试分配方向，以便模拟结果与给定目标相匹配。 对于每个完整的网格分配，我们将模拟所有$n^2$使用 DFS 或 BFS 计算端点的起始位置并与所需的输出进行比较。 即使我们只尝试每个单元的几种可能性，状态空间也是指数的，仅验证就是$O(n^2)$，使得这在大规模上完全不可行。 

通过扭转视角可以更好地理解问题的结构。 我们不是构建向前的路径，而是考虑反向可达性：最终到达终端的每个单元必须属于指向该终端单元的树。 细胞标记为$(-1,-1)$必须位于循环中并且无法到达任何终点。 

这表明分解为两部分。 首先，我们识别最终必须以某个终端结束的所有单元。 这些细胞形成以它们相应的末端细胞为根的有向树。 其次，所有剩余的单元必须形成至少一个完全避免所有终端的定向循环。 

关键的见解是我们可以从目标端点贪婪地构造图。 对于每个具有有限目标的单元格$(x, y)$，我们确保它有一条通往该根的定向路径。 我们可以通过将每个目标单元视为 BFS 源并向后传播方向，为每个单元分配一个指向更接近其目标的邻居的方向来实现此目的。 细胞具有$(-1,-1)$相反，必须强制进入全局循环结构，该结构可以通过以简单一致的模式（例如行优先换行）连接它们来构造。 

一旦我们将问题重新解释为构建具有指定吸引盆地的函数图，该构建就变得局部和线性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟|$O(n^4)$或者更糟|$O(n^2)$| 太慢了 |
 | 反向 BFS 构建 |$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们根据细胞的目标是有限的还是有限的将细胞分为两类$(-1,-1)$。 

1. 我们首先按目标目的地对所有单元格进行分组$(x, y)$。 每个组对应于最终必须在同一终端结束的所有单元。 
2. 对于每个具有有限目标的组，我们从目标单元格开始运行 BFS，并在网格上向外扩展。 在此 BFS 期间，我们为每个访问过的单元分配一个指向距离目标更近一步的邻居的方向。 这保证了跟随箭头严格减少到根的距离。 
3. 在 BFS 期间分配方向时，我们只允许在同一组内移动，这意味着我们确保任何分配的转换都将路径保留在共享相同目的地的单元格内。 这可以防止不同盆地之间的意外合并。 
4. 对于所有标记的细胞$(-1,-1)$，我们分别收集它们并尝试形成覆盖它们的有向循环。 我们以固定顺序（例如行优先顺序）将每个这样的单元格连接到下一个单元格，最后一个单元格连接回第一个单元格。 
5. 我们根据这些循环单元在此排序中的邻接关系为其分配方向。 如果无法邻接，我们会尝试使用简单的 2 向蛇形结构来进行路由，以保证网格内的有效移动。 
6. 最后，我们通过检查分配与 BFS 父结构和循环结构的一致性来验证每个单元都已分配了一个方向，并且没有违反任何约束。 

### 为什么它有效

 每个有限目标群体形成一个植根于其目的地的森林。 BFS 结构保证森林中的每条边严格缩短到根的距离，从而消除循环并确保最终终止于正确的单元。 

细胞标记$(-1,-1)$有意与所有终端盆地分开，因此它们不会意外到达$X$。 通过强制它们进入独立循环，我们保证了无限遍历。 由于每个单元都只有一个出边，并且每个组件要么是有根树，要么是循环，因此全局功能图与所需的行为完全匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

n = int(input())
target = [[None]*n for _ in range(n)]

groups = {}
for i in range(n):
    row = list(map(int, input().split()))
    for j in range(n):
        x, y = row[2*j], row[2*j+1]
        if x == -1:
            target[i][j] = None
        else:
            x -= 1
            y -= 1
            target[i][j] = (x, y)
            groups.setdefault((x, y), []).append((i, j))

res = [['']*n for _ in range(n)]

dirs = [(-1,0,'D'), (1,0,'U'), (0,-1,'R'), (0,1,'L')]

def bfs(root):
    rx, ry = root
    dist = [[-1]*n for _ in range(n)]
    dist[rx][ry] = 0
    q = deque([(rx, ry)])

    while q:
        x, y = q.popleft()
        for dx, dy, _ in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < n:
                if target[nx][ny] == (rx, ry) and dist[nx][ny] == -1:
                    dist[nx][ny] = dist[x][y] + 1
                    q.append((nx, ny))

    for x, y in groups.get((rx, ry), []):
        for dx, dy, ch in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < n:
                if dist[nx][ny] == dist[x][y] - 1:
                    res[x][y] = ch
                    break

for root in groups:
    bfs(root)

cycle = [(i, j) for i in range(n) for j in range(n) if target[i][j] is None]

if cycle:
    for k in range(len(cycle)):
        x, y = cycle[k]
        nx, ny = cycle[(k+1) % len(cycle)]
        if x == nx and y + 1 == ny:
            res[x][y] = 'R'
        elif x == nx and y - 1 == ny:
            res[x][y] = 'L'
        elif y == ny and x + 1 == nx:
            res[x][y] = 'D'
        elif y == ny and x - 1 == nx:
            res[x][y] = 'U'
        else:
            print("INVALID")
            sys.exit()

for i in range(n):
    for j in range(n):
        if res[i][j] == '':
            res[i][j] = 'X'

print("VALID")
for row in res:
    print(''.join(row))
```实现首先解析目标并按目的地对单元格进行分组。 每个组都使用以目标单元为根的 BFS 独立处理。 该 BFS 旨在建立一个梯度场，其中每个细胞都可以选择距离其目的地更近的邻居，这直接决定了其方向。 

处理完所有有限目标组后，剩余未分配的单元格对应于$(-1,-1)$。 它们按行优先顺序排列成单个周期。 循环构造受到邻接性的约束，如果任何连续对不相邻，则构造失败。 

最后，所有剩余的单元格被标记为$X$，它充当有限盆地的停止条件。

 ## 边缘情况

 一种关键的边缘情况是整个网格被标记为$(-1,-1)$。 在这种情况下，算法必须确保在网格上构建完整的哈密顿循环。 任何未能确保循环中的邻接的情况都会立即使解决方案失效，因为不邻接的转换将违反移动规则。 

当多个单元共享网格中相邻的不同有限目标时，会出现另一种边缘情况。 如果没有仔细地将 BFS 分配按组分开，则幼稚的传播可能会意外合并两个盆地，导致单元到达错误的终端。 分组步骤通过在分配方向之前隔离每个目标的影响来防止这种情况发生。 

最后一种边缘情况是网格，其中只有一个单元是有限的，而所有其他单元都是无限的。 循环构造必须避免消耗有限单元。 如果它被错误地包含在循环中，则正确性条件将被破坏，因为该单元将不再终止。
