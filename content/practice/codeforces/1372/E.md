 ## 解决方案
 ## 问题理解

 我们被要求设计 Omkar 房子的最后一层，表示为$n \times m$网格最初用零填充。 每行被细分为连续的间隔。 在每个区间中，我们都可以将一个零精确地更改为一个一。 处理完所有行后，我们计算每列的总和，对其进行平方，然后对所有列求和以获得地板的质量。 任务是最大限度地提高总体质量。 

限制因素$1 \le n,m \le 100$足够小，允许复杂度高达$O(n \cdot m^2)$without risking a timeout. 每行的间隔数量可以变化，并且间隔可以小至单列或跨越多列。 

如果不考虑行之间的重叠选择，一种简单的方法可能会默默地失败。 例如，如果我们总是在每个间隔中选择最左边的列，我们可能最终会在一个列中不必要地堆叠许多列，同时将其他列留空，从而导致总体质量较低。 考虑一行，其间隔覆盖所有列； 将一个与另一行放在同一列中可能不是最佳选择。 一个小例子：两行，每行有一个间隔覆盖第 1 列和第 2 列。为两行选择第 1 列会产生质量$2^2 + 0^2 = 4$，但将它们分成第 1 列和第 2 列给出了质量$1^2 + 1^2 = 2$。 在这里，最左边的方法实际上更好，但在更复杂的布局中，不正确的分布会降低总体平方和。 

## 方法

 蛮力方法是尝试每行中每个间隔的所有可能的放置位置。 每个区间有多个候选位置，因此组合总数可以达到$\prod_{i=1}^{n} \prod_{j=1}^{k_i} (r_{i,j}-l_{i,j}+1)$。 即使对于小$n$和$m$，这个产品呈指数级增长，完全不可行。 

关键的见解是，使用动态规划可以很好地按行分解问题。 列总和跨行线性累加，质量函数每列可分离。 因此，对于每一行，我们可以计算它对给定当前列总和的最佳贡献。 这表明状态跟踪每列中放置的 DP 的数量，或者更有效地，DP 将行视为间隔序列并贪婪地分配间隔以最大化局部平方和，同时携带累积和。 

另一种见解是，在单个间隔内，将其放置在具有当前最小总和的列中始终是最佳的。 由于平方函数随着数字的增加而增长得更快，因此将数字集中在已经有更多数字的列中会增加总数。 这将问题简化为每行的两指针或贪婪策略，其中我们顺序处理间隔并选择具有最大当前总和的列来放置 1。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| O(n*m) | 太慢了 |
 | 贪心+DP/区间处理| O(n*m^2) | O(n*m^2) | O(米) | 已接受 |

 ## 算法演练

 1.初始化一个数组`cols`长度$m$带零。 该数组将存储每列的当前总和。 
2. 对于每一行，按顺序迭代其间隔。 
3. 对于每个间隔，确定该间隔内当前具有最大总和的列`cols`。 通过增加相应的条目来放置一个`cols`。 
4. 处理完所有行和间隔后，将总质量计算为$\sum_{i=1}^{m} cols[i]^2$。 

原因是，向当前总和最大的列添加 1 使总平方和增加最多。 因为每个间隔必须恰好放置一个，所以这种贪婪的选择在尊重间隔约束的同时最大化了该行的增量增益。 

### 为什么它有效

 不变量是，处理每个区间后，在已放置区间的约束下，总质量最大化。 平方函数是凸函数，因此与现有的最大和相加总是比与较小的和相加产生更大的增量。 通过按顺序处理间隔，我们在每一步都保持最佳的增量选择。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
cols = [0] * m

for _ in range(n):
    k = int(input())
    intervals = [tuple(map(int, input().split())) for _ in range(k)]
    for l, r in intervals:
        # convert to 0-indexed
        l -= 1
        r -= 1
        # find column with max current sum
        best_col = max(range(l, r + 1), key=lambda x: cols[x])
        cols[best_col] += 1

print(sum(c * c for c in cols))
```该代码使用有效地读取输入`sys.stdin.readline`。 对于每一行，它读取间隔，然后为每个间隔选择具有当前最大总和的列来放置一个。 边界处理是通过转换为 0 索引位置来完成的。 最终的平方和计算很简单。
