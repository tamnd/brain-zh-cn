 ## 解决方案
 ## 问题理解

 我们得到一组相同的直角等腰三角形拼图。 每个三角形都有两条相等的边和一个直角。 凤凰想要使用准确$n$将这些三角形组合起来形成一个完美的正方形，没有重叠或孔洞。 他可以自由旋转和移动棋子。 任务是针对每个测试用例确定是否可以形成这样的正方形。 

输入提供多个测试用例，每个测试用例由一个整数组成$n$，可以大到$10^9$。 如果可以形成正方形，则输出简单地为“YES”，否则输出为“NO”。 

约束条件$n \le 10^9$立即告诉我们，任何迭代所有部分或尝试每种几何排列的解决方案都是不切实际的。 我们需要一种方法，在每个测试用例的恒定时间内使用公式或算术检查来计算答案。 

一个重要的微妙之处是并非所有整数$n$可以组成一个正方形。 例如，$n = 2$之所以有效，是因为两个三角形可以通过连接它们的斜边形成一个正方形。$n = 4$也有效，因为四个三角形可以形成一个更大的正方形。 然而，$n = 6$失败：六个相同的直角等腰三角形的任何排列都不能完美地形成一个正方形。 粗心的解决方案可能会假设任何偶数都有效，但棋子的排列要么需要 2 的倍数形成边长为 1 的正方形，要么需要 4 的倍数形成更大尺寸的正方形。 

## 方法

 蛮力方法将尝试将三角形逐一放置并检查是否形成正方形。 从概念上讲，人们可以尝试模拟所有旋转和位置。 这在原理上是正确的，但在计算上是不可能的$n \sim 10^9$，因为排列的数量呈阶乘增长。 

关键的见解是根据三角形的总面积进行推理。 每个三角形的面积为$0.5$（假设单位腿）。 如果$n$三角形组成一个正方形，正方形的面积必须是$n \times 0.5 = n/2$。 因此，正方形的边一定是$\sqrt{n/2}$。 对于具有整数坐标的正方形，$\sqrt{n/2}$应该是一个有理数，可以表示为由三角形构造的整数长度边的总和。 

根据几何推理，我们发现可以构造一个正方形当且仅当$n$可以表示为$2k^2$或者$4k^2$， 在哪里$k$是一个整数。 第一种形式对应于由两个三角形沿斜边构成的正方形，第二种对应于由四个三角形沿斜边构成的正方形。$k \times k$正方形网格。 

这一观察将问题简化为使用整数算术检查两个条件：是否$n$能被 2 整除并且$n/2$是一个完全平方数，或者是否$n$能被 4 整除并且$n/4$是一个完美的正方形。 两项检查都是$O(1)$每个测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取整数$n$代表三角形的数量。 
2.如果$n$能被2整除，计算$n/2$。 检查是否$n/2$是一个完美的平方，通过取其整数平方根并将其平方回来。 
3.如果$n/2$是一个完美的正方形，打印“YES”并跳到下一个测试用例。 这对应于由 2 个三角形沿斜边形成的正方形。 
4. 否则，检查是否$n$能被 4 整除。 计算$n/4$并验证它是否是一个完美的正方形。 
5.如果$n/4$是一个完全正方形，打印“YES”。 这对应于由排列在方格中的 4 个三角形构建的正方形。 
6. 如果两项检查均未通过，则打印“NO”。 

工作原理：不变的是，由直角等腰三角形形成的正方形需要 2 或 4 个三角形才能形成基本单位正方形，而较大的正方形是这些基本单位的整数倍。 因此，面积参数保证了正确性，整数平方检查确保了各个部分完美对齐，没有间隙或重叠。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    ans = "NO"
    if n % 2 == 0:
        half = n // 2
        if int(math.isqrt(half)) ** 2 == half:
            ans = "YES"
    if ans == "NO" and n % 4 == 0:
        quarter = n // 4
        if int(math.isqrt(quarter)) ** 2 == quarter:
            ans = "YES"
    print(ans)
```该解决方案使用有效地读取输入`sys.stdin.readline`处理最多$10^4$测试用例。 这`math.isqrt`函数精确计算整数平方根，没有浮点错误，并将其平方可确保精确的完美平方检测。 检查两者`n/2`和`n/4`涵盖了两种几何排列。 检查顺序确保我们在尝试 4 三角形情况之前检测到 2 三角形情况。 

## 工作示例

 | ---| ---| ---| ---| ---|

 该算法正确地识别出 2 个三角形可以形成一个正方形。 

**示例 2：n = 6**

 | n | n % 2 | n/2 | 开方(n/2)^2 | n % 4 | n/4 | sqrt(n/4)^2 | 开方 结果 |
 | ---| ---| ---| ---| ---| ---| ---| ---|
 | 6 | 0 | 3 | 1 | 2 | - | - | 否 |

 两者都不`n/2`也不`n/4`是完全平方数，所以答案是否定的。 

这些痕迹证实该算法区分了 n = 6 等不可能的情况并检测了最小的可能平方。

 ## 边缘情况

 对于 n = 1，算法检查能否被 2 和 4 整除。两者都失败，因此打印 NO。 这符合直觉：单个三角形不能形成正方形。 对于 n = 8，算法首先检查 n/2 = 4，这是一个完全平方数，因此打印 YES。 这证明了检查 2 三角形和 4 三角形排列的重要性。 对于像 2 × 10^9 这样的大 n，该算法仍然可以在每个测试用例的 O(1) 时间内工作而不会溢出，因为 Python 整数是无界的并且`math.isqrt`有效地处理大整数。
