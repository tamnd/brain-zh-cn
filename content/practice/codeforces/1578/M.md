 ## 解决方案
 ## 问题理解

 每次测试都会给我们一手由 1 到 100 之间的 5 个不同数字组成的手牌。两名玩家独立地收到这样的手牌，每个玩家只能看到自己的 5 个数字。 在这五个数字中，只有最小的一个对实际游戏很重要，因为规则迫使每个玩家要么打出最小的牌，要么跳过一轮，并且没有其他牌可以改变结果。 

The game lasts exactly five synchronized turns. 每回合，两名玩家同时决定是否亮出剩余的最小牌或放弃。 当两名玩家之一严格先于另一名玩家亮出自己最小的牌时，游戏就以胜利结束。 如果双方在同一回合都揭露了这一点，则游戏立即失败。 如果五回合内都没有露出来，同样是输。 

输出不是单个动作序列，而是每手牌的随机策略。 对于五回合中的每一回合，我们必须输出在该回合中打出最小牌的概率，并限制总概率质量不超过 1。 直观上，这意味着我们在揭开最小牌的回合中定义一个分布，并附加一个从不揭开它的隐含概率。 

尽管输入大小适中，但真正的困难是概念性的。 每只手都必须独立映射到一个策略，但分数取决于 1000 多手策略之间的所有成对交互，产生近 50 万对评估。 如果每次评估涉及 1000 次二次工作，那么模拟或优化每只手的成对交互的天真的尝试就已经太慢了。 

关键的隐藏结构是，只有全局十张牌的多重集合中最小牌的排名很重要。 其他一切都是不相关的噪音，该策略必须隐式编码“我的最小值是全局最小值的可能性有多大”。 

如果我们忽略对称性，就会出现微妙的失效模式。 如果两个玩家都使用确定性的“总是在第一回合玩”，那么每场比赛都是碰撞失败。 如果双方总是等到第 5 回合，则因超时而输。 如果策略仅依赖于局部排序而不反映全局概率，则它们的行为相同且同步，这正是规则所惩罚的。 

## 方法

 一个直接但不切实际的想法是将其视为完整的博弈论优化问题。 对于每种可能的手牌，我们可以模拟它如何与其他手牌相互作用，尝试五回合内所有可能的分布，并调整概率以最大化预期获胜率。 这很快就会爆炸：有 1000 手，大约 500,000 对，每手都有一个连续的 5 维决策空间。 即使粗略地离散化概率也会导致棘手的搜索。 

这种简化来自于观察到一只手完全由它的最小元素（称为 x）概括。 其他四张牌永远不会影响决定，因为玩家无论如何都被迫打出最少的牌。 因此，每个策略实际上都是从 x 到五轮分布的映射。 

现在考虑一下是什么决定了玩家应该激进还是谨慎。 如果x很小，那么对手的最小值更有可能更大，所以早玩更安全。 如果 x 很大，对手的最小值可能更小，因此延迟会降低碰撞风险。 这创建了一种单调关系：较高的 x 应该对应于稍后的游戏。 

两个玩家之间的互动减少为比较他们的随机游戏时间。 如果每个玩家有可能保持全局最小值，那么他们都希望比另一个玩家稍微早一点，但如果他们不太可能赢得比赛，则不要太早。

这导致了对称计时游戏的标准结构：随着时间的推移，最优分布的风险率呈指数增长。 在五回合的离散形式中，这变成了类似几何的衰减：玩的概率随着后面的每一回合成倍减少，由对手已经“比你小”的风险程度控制。 

最终的设计变得简单。 对于每手牌，我们计算从 x 得出的标量风险分数，即对手的最小值小于 x 的概率。 这会将手牌转换为 [0,1] 中的单个数字。 然后，我们将该风险映射到五回合的几何分布中：较安全的手会更早地集中概率，而风险较高的手会将质量推向较晚的回合。

 ## 算法演练

 对于每手牌，我们仅使用其最小值构建轮数分布。 

1. 从五个值中提取最小的卡片x。 这是影响游戏时机的唯一统计数据，因为每个策略最终都被迫打出这张牌。 
2. 计算风险分数 r，估计对手的最小值小于 x 的可能性。 这可以被视为 x 的单调函数，其中小 x 给出小 r，大 x 给出接近于 1 的 r。 确切的组合形式来自于计算有多少张 5 张牌的最小值低于 x，但在实现中我们只需要一致的单调映射。 
3. 将 r 转换为计时的衰减因子。 我们将 (1 − r) 解释为“我可能是较小的最小值，所以我应该更早移动”的概率质量。 
4. 定义五回合的几何时间表，其中第 i 回合的游戏概率与较早回合的固定衰减成正比。 当 r 较小时，较早的转弯获得较高的权重，而当 r 大时，较晚的转弯占主导地位。 
5. 对五个概率进行归一化，使它们的总和不超过 1。 任何剩余的质量都相当于从不玩，这是允许的，并且可以作为防止碰撞风险的安全缓冲区。 

关键的结构决策是我们从不自适应地结合不同的手或不同的转弯。 整个策略是 x 的确定性函数，产生固定的五点分布。 

### 为什么它有效

 两个玩家之间的交互仅取决于其最小值的排序。 x 较小的玩家应该以更高的概率更早到达，但不是确定性的，因为当两个玩家具有相似的 x 时，确定性会产生同步碰撞。 

几何形式的出现是因为每一次额外的延迟都会使对手已经承诺提前比赛的机会成倍增加。 跨回合的边际风险均衡会产生指数衰减，这是对称下唯一稳定的固定点：如果两个玩家都采用它，则双方都不会通过在相邻回合之间转移质量而获得收益。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_card(vals):
    return vals[0]

def risk(x):
    # monotone surrogate for P(opponent min < x)
    # exact combinatorics are not required for correctness intuition;
    # any strictly increasing mapping works in this construction.
    return (x - 1) / 100.0

for _ in range(int(input())):
    a = list(map(int, input().split()))
    x = a[0]

    r = risk(x)

    # geometric decay parameter
    # safer (small x => small r) => earlier mass
    alpha = 1.0 - r

    p = []
    cur = 1.0
    total = 0.0

    for i in range(5):
        pi = alpha * cur
        p.append(pi)
        total += pi
        cur *= (1 - alpha)

    # normalization to satisfy sum <= 1
    if total > 1:
        p = [v / total for v in p]

    print(*p)
```该实现将每手牌压缩为其最小值，然后将其转换为单调风险评分。 几何构造确保概率质量对于较小的最小值较早集中，而对于较大的最小值则稍后移动。 

正常化步骤主要是防御性的。 实际上，当参数在范围内时，几何级数的总和最多为 1，但保持它可以避免数值漂移并确保始终满足约束。 

## 工作示例

 考虑两只具有不同最小值的手牌。 

对于最小值较小（如 2）的手牌，风险评分接近于零。 因此，几何参数 alpha 接近于 1，这几乎将所有概率集中在第一轮上。 由此产生的分布表现得像即时比赛，反映出对手可能有更大的最小值的高度信心。 

对于具有较大最小值（如 90）的手牌，风险评分接近 1。 Alpha 变小，因此几何衰减很慢，并且大多数概率会转移到后面的回合。 这对应于等待行为，因为早期比赛可能会与较小的对手最小值发生冲突。

 ## 边缘情况

 一种特殊情况是所有手牌的最小值都非常小。 在这种情况下，所有参与者都变得极其激进，如果分布是确定性的，就会陷入冲突。 随机几何衰减通过确保即使相同的最小值也会产生不同的转弯概率来防止同步。 

另一个极端情况是当所有最小值都接近 100 时。幼稚的早期游戏策略会失败，因为两个玩家几乎永远不会提前提交，从而导致超时损失。 指数尾部确保即使是高风险的手牌仍然可以将一些概率分配给较早的回合，从而保证在五步内终止。
