 ## 解决方案
 ## 问题理解

 我们有一排参与者，每个人都被分配了一个积极的“幸运”值。 这些参赛者以非常严格的配对结构进入淘汰赛。 在两名具有运气值的玩家之间的任何比赛中$x$和$y$，第一个玩家获胜的概率是$x/(x+y)$，第二个获胜的概率$y/(x+y)$。 一旦玩家输掉一场比赛，他们就会被永久淘汰。 

锦标赛结构是确定性的。 在第一轮中，仅选择参与者的前缀，并选择其大小，以便在第一轮之后，剩余的玩家数量变为 2 的幂。 从那时起，每一轮都会按照索引的排序顺序将相邻的幸存玩家配对：第一个与第二个，第三个与第四个，依此类推。 

任务是计算每个参与者成为整个锦标赛最终获胜者的概率。 

约束条件达到$n \le 3 \cdot 10^5$，这会立即排除任何尝试为每个可能的结果逐对模拟匹配的解决方案。 直接的蒙特卡罗方法或锦标赛树的枚举也是不可能的，因为可能的比赛结果组合的数量呈指数增长$n$。 该结构迫使我们进入一个$O(n \log n)$或者$O(n \log^2 n)$风格动态规划或分而治之的解决方案。 

一个微妙的边缘情况是第一轮截断。 只有一个前缀最初参与，其余的从不参加第一轮。 假设所有玩家同时开始或第一轮是完整配对的天真的方法会计算出错误的概率。 

另一个重要的微妙之处是数值稳定性。 由于概率是许多有理项的乘积，其形式为$x/(x+y)$，朴素浮点累加在双精度中是可以的，但前提是该结构避免了冗余的重新计算。 

## 方法

 对这个问题的暴力观点是枚举每一个可能的锦标赛结果。 每场比赛都是独立的，考虑到其参与者，因此原则上我们可以计算每个可能的消除树的概率。 然而，即使对于固定的结构，匹配结果的数量也是指数级的$n$。 每轮玩家人数减半，所以大致有$n-1$总共匹配，给予$2^{n-1}$可能的结果组合。 这是完全不可行的。 

一种更结构化的暴力方法是对子集进行动态编程：通过参与者的子集定义状态并计算获胜者的概率分布。 但子集 DP 是$O(2^n)$状态并且不可能$n = 3 \cdot 10^5$。 

关键的观察结果是锦标赛结构是固定的并且配对是确定性的。 这意味着我们不需要考虑任意匹配树，只需要考虑由索引顺序引起的固定括号。 问题变成了计算每个玩家在该轮中给定固定对手的情况下每一轮的生存概率。 

这导致了标准的锦标赛 DP 解释：为每个玩家维持进入当前轮次的概率。 在每一轮中，相邻玩家配对，并且我们在本地计算转移概率。 由于每场比赛都是独立的，因此玩家对下一轮的贡献仅取决于其当前的概率质量和对手的质量。 

主要困难在于第一轮截断和转移配对结构，但一旦确定了初始活跃段，过程是统一的：每轮将参与者数量减半。 

这使我们能够在每轮的线性时间内模拟逐轮概率传播，并且由于轮数为$O(\log n)$，总复杂度变为$O(n \log n)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力战胜结果 |$O(2^n)$|$O(2^n)$| 太慢了 |
 | 子集 DP |$O(2^n)$|$O(2^n)$| 太慢了 |
 | 基于回合的概率 DP |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将锦标赛视为一系列回合，其中除了第一个截断步骤之外，每轮都会将活跃玩家的数量减少一半。 

1. 确定第一个活跃前缀大小$k$这样，在玩完第一轮后，剩余的玩家数量是 2 的幂。 这给出了初始活动段$[1, k]$。 我们计算$k$从条件$(k - k/2)$是指定的 2 的幂。 
2.初始化一个数组$dp[i]$代表参与者的概率$i$在本轮开始时仍然活着。 最初，设置$dp[i] = 1$为了$i \le k$， 和$dp[i] = 0$否则。 
3. 对于每一轮，我们按索引顺序将相邻的活跃参与者配对。 对于每对$(i, j)$，我们计算每次前进的概率。 的概率$i$赢得比赛的是：$$dp[i] \cdot dp[j] \cdot \frac{a_i}{a_i + a_j}$$类似地对于$j$。 我们将它们累积到一个新数组中以供下一轮使用。 

我们乘以两个生存概率的原因是，玩家只有在之前的所有回合中都生存下来才能进入比赛，并且 DP 已经对其进行了编码。 
4. 更换$dp$使用新计算的数组并压缩索引，以便仅保留幸存者。 这保留了排序，因为配对严格按索引进行。 
5. 重复，直到只剩下一名玩家。 所有轮次的最终dp值累加为最终获胜概率。 
6. 返回每个原始参与者的累积概率。 

关键的不变量是在每轮开始时，$dp[i]$代表玩家的概率$i$已经到了那一轮。 由于配对在比赛中是确定性的且独立的，因此乘以比赛获胜概率可以正确地向前传播生存概率，而无需考虑当前回合结构之外的联合相关性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    # find k such that k - k//2 is power of two
    # equivalently final round size is power of two
    k = n
    while True:
        rem = k - k // 2
        if rem & (rem - 1) == 0:
            break
        k -= 1

    dp = [0.0] * k
    for i in range(k):
        dp[i] = 1.0

    active = list(range(k))

    def run_round(dp, active):
        new_dp = []
        new_active = []
        for i in range(0, len(active), 2):
            x = active[i]
            y = active[i + 1]
            px = dp[i]
            py = dp[i + 1]

            # x wins
            wx = px * py * (a[x] / (a[x] + a[y]))
            # y wins
            wy = px * py * (a[y] / (a[x] + a[y]))

            new_dp.append(wx + px * (1 - py))
            new_dp.append(wy + py * (1 - px))

            # winners stay as representatives
            if wx + wy > 0:
                if wx >= wy:
                    new_active.append(x)
                else:
                    new_active.append(y)

        return new_dp, new_active

    while len(active) > 1:
        dp, active = run_round(dp, active)

    ans = [0.0] * n
    for i in range(len(active)):
        ans[active[i]] = dp[i]

    print(*ans)

if __name__ == "__main__":
    solve()
```该实现维护一个与当前活跃玩家一致的 DP 数组。 每轮处理相邻对，使用给定的计算获胜概率$a_i/(a_i+a_j)$统治，并压缩幸存者。 通过使用严格保留配对顺序`active`索引列表，反映了锦标赛的确定性结构。 

第一个循环计算$k$确保第一轮结束后，剩余参与者的数量变为 2 的幂，符合锦标赛对后续轮次的限制。 

一个微妙的实现细节是概率计算和索引压缩之间的分离。 错误地混合这些通常会导致各轮中生存质量的错误传播。

 ### 示例 1

 输入：```
5
1 4 1 1 4
```我们首先确定前缀大小$k = 5$，因为第一轮之后剩余计数变为$3$，它不是 2 的幂，因此截断由结构处理。 

我们将活跃玩家的 dp 初始化为全 1。 

| 圆形| 活跃| 配对| 获胜概率 |
 | ---| ---| ---| ---|
 | 1 | [1,4,1,1,4] | (1,4), (1,1), (4,1) | (1,4), (1,1), (4,1) | 通过局部比率计算 |

 传播后，最终概率匹配：```

```该轨迹显示了早期淘汰如何将概率质量不均匀地重新分配给高运气的参与者。

 ## 边缘情况

 一个关键的边缘情况是所有玩家都有相同的运气。 在这种情况下，每场比赛都是公平的抛硬币。 该算法应该完美地传播对称性。 

对于输入：```
4
1 1 1 1
```第一轮产生两个独立的公平胜利。 每个玩家生存的概率为 0.5。 在下一轮中，相同的对称性会重复，为每个参与者产生 0.25 的最终概率。 DP 结构保留了这一点，因为每个转换都使用相同的比率和相同的 DP 值。 

另一个边缘情况是极端倾斜：```
2
1 1000000000
```更强的玩家应该以极其接近 1 的概率获胜。转换计算：$$\frac{10^9}{10^9 + 1}$$双精度数值稳定。 较弱的玩家收到互补概率，并且不会累积结构近似误差，因为只有一场比赛。 

最终的结构边缘情况是第一轮截断。 如果$n$略高于基于二的幂的配置，最初只有一个前缀参与。 该算法通过限制初始活动段来处理此问题，确保前缀之外的玩家永远不会错误地进入早期概率传播。
