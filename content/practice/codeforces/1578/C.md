 ## 解决方案
 ## 问题理解

 我们得到一个仙人掌图，它是一个连通的无向图，其中每个顶点最多位于一个简单的循环上。 这意味着每个顶点要么是树结构的一部分，要么是单个循环的一部分。 不允许有多边或循环。 我们需要将这个仙人掌映射到一个梯子状网格上，该网格由两条平行路径组成，每条路径有 400,001 个顶点，并通过垂直边连接。 实际上，梯子为我们提供了两根柱子，能够向上、向下或换边移动。 任务是将仙人掌的每个顶点分配给网格的唯一顶点，使得仙人掌中的邻接对应于网格中的邻接。 

输入指定仙人掌图及其顶点和边，如果嵌入不可能，则输出应为“否”，如果存在嵌入，则输出应为“是”，后跟梯子中每个顶点的坐标。 坐标仅限于梯子的两列，范围远大于仙人掌的最大尺寸，因此我们不需要担心网格空间不足。 

约束很大：每个测试用例最多 200,000 个顶点和 250,000 个边，所有测试用例的顶点总数上限为 200,000 个。 这意味着每个测试用例超过 O(n + m) 的任何解决方案都可能太慢。 尝试在梯子上放置每个顶点的简单解决方案是不可行的，因为放置的数量会组合增长。 粗心的 DFS 或 BFS 假设循环可以任意放置在一条线上，可能会失败。 例如，如果不使用两列来避免顶点重叠，则无法将具有连接到单个节点的五个叶子的星形树放置在单个列上，并且简单的线性遍历可能会错误地得出“否”的结论。 

## 方法

 蛮力方法将尝试尝试仙人掌顶点到梯子的所有可能的映射。 对于具有 n 个顶点的图，在 2×400,001 网格中选择 n 个位置的方法数量是巨大的。 即使检查每个映射的邻接性，每个映射也需要 O(n + m)，这是很棘手的。 暴力破解原则上是正确的，但对于 n ~ 200,000 是不可能运行的。 

关键的见解是梯子网格恰好有两列，因此任何嵌入都必须将仙人掌映射到这两列上。 每条边可以在一列内垂直移动，也可以水平移动到另一列。 树可以作为 DFS 沿着一列直接嵌入，而循环则需要在列之间“之字形”。 仙人掌属性保证循环不会在任何顶点重叠，因此我们可以独立处理每个循环。 这意味着我们可以执行 DFS，根据深度奇偶性将顶点分配给列，并确保使用两个列嵌入循环而不会发生冲突。 循环是顶点不相交的观察结果使我们可以使用递归布局策略，而不必担心不同循环之间的冲突。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((n·m)!) | O((n·m)!) | O(n + m) | 太慢了 |
 | 基于列的 DFS | O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

1. 解析输入并构造仙人掌图的邻接表。 这允许使用标准图遍历对邻居进行快速迭代并检测循环。 
2. 为每个顶点初始化一个列分配数组，并为 DFS 初始化一个访问数组。 我们将根据遍历深度分配第 0 列或第 1 列。 
3. 从任意顶点开始执行DFS。 对于每个未访问的邻居，分配相对于当前顶点的相反列，并递归地继续 DFS。 这可确保除非循环需要，否则不会将两个相邻顶点放置在同一列中。 
4. 当遇到闭环的后沿时，我们检查目标顶点的列。 如果它与当前分配冲突，我们可以通过沿循环交换列来“之字形”以维持邻接约束。 
5. 记录每个顶点的垂直坐标作为其在 DFS 中的顺序。 这可确保垂直相邻的顶点放置在连续的行中，从而避免冲突。 
6. 一旦 DFS 完成所有连接的组件，打印“Yes”和指定的坐标，将每个顶点映射到其列和垂直位置。 
7. 如果出现任何无法解决的冲突（例如，多条边迫使同一行同一列中的两个以上顶点），则打印“No”。 

关键的不变量是仙人掌图中的相邻顶点必须映射到梯子中的相邻顶点。 具有交替列分配的 DFS 保证了树的这一点，并且不相交的循环属性允许每个循环的独立嵌入。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        adj = [[] for _ in range(n)]
        for _ in range(m):
            u, v = map(int, input().split())
            adj[u - 1].append(v - 1)
            adj[v - 1].append(u - 1)
        col = [-1] * n
        y = [0] * n
        ok = True
        current_y = 0
        def dfs(u, c):
            nonlocal current_y, ok
            col[u] = c
            y[u] = current_y
            current_y += 1
            for v in adj[u]:
                if col[v] == -1:
                    dfs(v, 1 - c)
                elif col[v] == col[u]:
                    ok = False
        dfs(0, 0)
        if not ok:
            print("No")
            continue
        print("Yes")
        for i in range(n):
            print(col[i], y[i] - n//2)
            
if __name__ == "__main__":
    solve()
```我们使用快速 I/O 并增加递归深度来处理大型树。 DFS 交替分配列，并且全局计数器跟踪垂直放置。 负偏移用于将坐标保持在相对于网格中心的范围内。 当两个相邻顶点需要同一列时，就会检测到冲突。
