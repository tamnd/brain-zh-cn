 ## 解决方案
 ## 问题理解

 我们被要求安排任务，这些任务被安排为高度的完整二叉树$h$。 高度满二叉树$h$有$2^h - 1$节点。 最初，只有根任务准备就绪。 在每个离散时刻，最多$p$进程可以同时执行就绪任务。 一旦任务执行完毕，它的子任务就会在下一刻做好准备。 目标是确定执行树中所有任务所需的最小时刻数。 

输入提供多个测试用例。 每个测试用例给出$h$和$p$，表示树的高度和进程数。 每个测试用例的输出是一个整数，即完成所有任务所需的最小时刻数。 

限制是至关重要的。 最多可以有$5 \cdot 10^5$测试用例。 高地$h$最多 50 个，这意味着最大的树有$2^{50} - 1$节点。 工序数$p$取决于$10^4$。 这些限制表明我们无法单独模拟大型任务$h$- 显式遍历所有节点是不可行的。 相反，我们需要一种利用树的结构和每个深度的可预测节点数量的策略。 

不明显的边缘情况包括只有一个进程具有中等大小的树。 例如，$h = 3$,$p = 1$导致任务按顺序执行：时刻为 7，因为任务必须一项一项地执行。 假设并行性始终可以充分利用所有进程的粗心贪婪方法可能会低估这种情况下所需的时间。 

## 方法

 蛮力方法很简单：模拟该过程。 保留一个就绪任务队列，每个时刻分配最多$p$进程，将任务标记为已完成，并将其子任务推入就绪队列。 这工作正常，但对于$h = 50$， 有$2^{50} - 1$任务。 模拟每项任务需要$10^{15}$操作 - 远远超出任何合理的时间限制。 

最佳方法利用二叉树结构。 在深度$d$， 有$2^{d-1}$任务。 只有在前一级别完成后，深度的任务才会准备就绪。 由于同一级别的所有任务同时准备就绪，因此我们可以计算就绪任务的数量并分批处理它们，最大尺寸为$p$。 这将问题简化为各级求和，按流程限制执行任务的上限划分$p$。 计算取决于每个深度的任务计数，而不是单独迭代每个节点。 

关键的见解是认识到问题可以简化为计算完成最后一个级别需要多少时间，并考虑到先前级别的未完成任务的累积积压。 通过维护剩余任务的排序列表并始终首先处理最大的可用批次，我们可以最大限度地减少总时间。

 ## 算法演练

 1. 计算树每个深度的任务数量。 对于深度$d$从 1 到$h$， 有$2^{d-1}$任务。 将这些存储在列表中`tasks`。 
2. 反转列表，以便我们从最深层开始处理。 这允许优先考虑最大的批次，这对于最小化总时间至关重要。 
3. 初始化`ready`为1，代表根任务在时刻1准备就绪。初始化`time`为 0。 
4. 虽然还有任务需要执行：

 4.1. 将当前深度的任务数添加到`ready`。 

4.2. 确定此时可以执行多少任务：`done = min(ready, p)`。 

4.3. 减去`done`从`ready`。 

4.4. 增量`time`1.
 5. 重复直到所有级别都用完并且`ready`达到 0. 返回`time`作为最小数量的时刻。 

为什么它有效：不变的是`ready`始终正确地表示当前可以执行的任务数量。 通过始终执行最多`p`每个时刻的任务并首先处理较大的批次，我们确保在进程可用的情况下不会出现空闲时间。 该策略保证了总时间最少。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def minimal_time(h, p):
    tasks = [(1 << i) for i in range(h)]
    tasks.reverse()
    ready = 0
    time = 0
    for t in tasks:
        ready += t
        done = min(ready, p)
        ready -= done
        time += 1
    while ready > 0:
        done = min(ready, p)
        ready -= done
        time += 1
    return time

t = int(input())
for _ in range(t):
    h, p = map(int, input().split())
    print(minimal_time(h, p))
```第一个循环构造每个深度的任务数量，相反，因此我们首先处理最大的批次。 变量`ready`跟踪可供执行的任务。 我们重复执行直到`p`每时刻的任务。 最后的 while 循环处理先前深度的剩余任务。 这可确保没有未处理的任务。

 ## 边缘情况

 对于`h = 1`,`p = 1`: 树只有根。 算法正确计数`ready = 1`，瞬间执行，然后终止。
