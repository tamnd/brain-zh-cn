 ## 解决方案
 ## 问题理解

 该问题要求我们选择一个点 (p=(p_t,p_i)) 来表示我们想要使用的参数，以及 (t) 的最小可能值。 对于每个给定点 (c=(c_t,c_i))，该问题定义一个量 (T(c,p))、一个内积项 (I(c,p))，并要求

 [
 T(c,p)-I(c,p)\le t。 
]

 目标是输出合适的 (p_t,p_i) 和最小可能的 (t)。 

相关定义可写为

 [
 T(c,p)=\frac{s(c)+d(p)}{2},
 ]

 哪里

 [
 s(c)=c_t^2+c_i^2,\qquad d(p)=p_t^2+p_i^2,
 ]

 和

 [
 I(c,p)=c_t p_t+c_i p_i。 
]

 乍一看，这看起来像是一个涉及多个代数表达式的优化问题。 有用的步骤是在考虑算法之前扩展它们。 

代入定义可得

 \frac{c_t^2+c_i^2+p_t^2+p_i^2}{2}
 -c_t p_t-c_i p_i。 
]

 乘以 2 并对各项进行分组产生

 [
 (c_t-p_t)^2+(c_i-p_i)^2\le 2t。 
]

 因此，对于 (p) 的固定选择，重要的数量只是从 (p) 到每个输入点的欧几里德距离的平方。 

因此，原始优化相当于选择一个中心 (p)，以最小化到所有给定点的最大距离。 如果最小外接圆的半径为（R），则其圆心恰好是最优圆心（p），并且

 [
 t=\frac{R^2}{2}。 
]

 竞赛版本有三秒的时间限制，并允许大量的积分。 可接受的实现使用随机最小外接圆算法，其预期运行时间是线性的。 对三元组进行三次搜索是不可行的，当 (n) 很大时，即使是通用的 (O(n^2)) 几何算法也会出现问题。 该实现还需要浮点运算，因为最佳中心和半径通常不是整数。 

第一个边缘情况是单点。 例如，```
1
3 7
```具有最佳中心 ((3,7))、半径 (0)，因此 (t=0)。 在这种情况下，假设圆由两个或三个点确定的实现将不必要地失败。 

第二个边缘情况是两点。 为了```
2
0 0
4 0
```最佳中心是((2,0))，半径是(2)，(t)的答案是(2)。 一个粗心的实现只考虑三个点的外接圆，没有三角形可以用来构造答案。 

第三种边缘情况是三个共线点。 为了```
3
0 0
2 0
5 0
```最小外接圆的圆心为 ((2.5,0))，半径为 (2.5)，因此 (t=3.125)。 当三点共线时，三点的外接圆公式未定义。 正确的圆是由两个极值点确定的，因此实现时必须单独处理共线性。 

第四个边缘情况是正好位于当前圆边界上的点。 如果一个点的平方距离恰好等于当前的平方半径，则该点已被覆盖，并且不应导致重建圆。 使用不必要的大或选择不当的浮点容差可能会使此类边界情况不稳定。 

## 方法

 直接方法将尝试由输入几何形状确定的可能中心。 对于一组点，最小外接圆由以中点为圆心的两个边界点或以外心为圆心的三个边界点确定。 我们可以枚举每一对和每一个三元组，构造相应的圆，检查所有点与它的关系，并保留最小的有效点。 

这是正确的，因为最佳包围圆的边界上最多有三个点。 如果恰好需要两个边界点，则它们的中点确定这两个点的最小圆。 如果需要三个，则它们的外接圆决定唯一的圆。 检查每一位候选人最终会选出最佳候选人。 

问题在于操作计数。 有 (O(n^3)) 个三元组，检查每个候选点的所有 (n) 个点就可以得到简单的版本 (O(n^4))。 即使我们避免额外的检查并利用几何结构来获得 (O(n^3)) 实现，对于大 (n) 来说，这仍然是太多的工作。 对于 (n=10^5)，即使 (n^2) 也已经意味着大约 (10^{10}) 对运算，因此三次或四次算法完全超出范围。 

改变问题的观察是我们不需要枚举所有可能的边界集。 经过代数变换后，任务就是最小外接圆问题。 随机增量算法可以保持迄今为止处理的点的最小圆。 

假设当前圆已经包含所有先前处理的点，并且一个新点位于其中。 没有任何改变。 如果新点位于外部，则它必须位于已处理前缀的新最佳圆的边界上。 我们可以将该点固定在边界上重新开始构建。 如果另一个较早的点位于生成的圆之外，则该第二个点也必须位于边界上。 在该阶段，候选圆由一对边界点确定。 如果第三个较早的点仍在外部，则所有三个点都必须是边界点，因此它们的外接圆决定了答案。 

随机打乱点使得此类重建的预期数量变小。 生成的算法预计有 (O(n)) 运行时间和 (O(n)) 存储点的空间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 枚举候选圈 | (O(n^3)) 或更糟 | (O(n)) | (O(n)) | 太慢了|
 | 随机增量最小外接圆| 预期 (O(n)) | (O(n)) | (O(n)) | 已接受 |

 ## 算法演练

1. 读取所有输入点并随机打乱它们的顺序。 随机化是获得预期线性运行时间的关键，因为对抗性输入顺序可以使增量算法执行更多的重建。 
2. 从以第一个点为中心、半径为零的圆开始。 单个点始终可以被这样的圆包围，因此这是初始前缀的有效最小圆。 
3. 按照随机顺序从左到右处理点。 如果当前点已经在当前圆内，则保持圆不变。 现有的圆已经包含了迄今为止处理的每个点，包括新点。 
4. 如果当前点 (p_i) 在外部，则重建圆并将 (p_i) 强制到其边界上。 从以 (p_i) 为中心的零半径圆开始。 旧圆无法保持最佳状态，因为它不包含 (p_i)。 
5. 回顾之前的所有要点。 如果较早的点位于新圆内，则保持该圆不变。 如果它在外部，则新的最佳圆必须在其边界上同时具有 (p_i) 和这个较早的点 (p_j)。 
6. 以 (p_i) 和 (p_j) 作为相对边界点构造圆。 它的中心是它们的中点，半径是它们距离的一半。 这是包含这两个边界点的最小圆。 
7. 重新访问 (p_j) 之前的所有点。 如果每一个都被覆盖，两点圆就足够了。 如果点 (p_k) 在外部，则此前缀的最佳圆的边界上必须有 (p_i,p_j,p_k)。 
8. 构造三点的外接圆。 如果三点不共线，则这个圆是唯一确定的。 如果它们共线，则外接圆不存在，正确的圆是由最远的两个点确定的包含这三个点的最小圆。 
9. 处理完所有点后，所维护的圆是整个输入集的最小外接圆。 输出其中心坐标和 (R^2/2)，因为原始参数 (t) 等于外接圆半径平方的一半。 

不变的是，在处理前 (i) 个随机点之后，维持的圆是那些 (i) 点的最小外接圆。 当下一个点已经被覆盖时，不变量将保持不变。 当它在外部时，放大前缀的任何有效圆都必须包含该点，因此将其固定在边界上不会失去最佳解决方案。 当在外面找到第二个和第三个点时，同样的论点也适用。 三个不共线的边界点唯一确定所需的圆，而三个共线的边界点则简化为由两个极值点确定的圆。 因此，每次重建都保留了最小圆不变量。 

## Python 解决方案```python
import sys
import math
import random

input = sys.stdin.readline

EPS = 1e-12

def dist2(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return dx * dx + dy * dy

def inside(circle, p):
    cx, cy, r2 = circle
    dx = p[0] - cx
    dy = p[1] - cy
    return dx * dx + dy * dy <= r2 + EPS * max(1.0, r2)

def circle_two(a, b):
    cx = (a[0] + b[0]) * 0.5
    cy = (a[1] + b[1]) * 0.5
    r2 = dist2(a, b) * 0.25
    return cx, cy, r2

def circle_three(a, b, c):
    ax, ay = a
    bx, by = b
    cx, cy = c

    abx = bx - ax
    aby = by - ay
    acx = cx - ax
    acy = cy - ay

    cross = abx * acy - aby * acx

    scale = max(
        1.0,
        abs(abx * acy),
        abs(aby * acx)
    )

    if abs(cross) <= EPS * scale:
        ab = dist2(a, b)
        ac = dist2(a, c)
        bc = dist2(b, c)

        if ab >= ac and ab >= bc:
            return circle_two(a, b)
        if ac >= ab and ac >= bc:
            return circle_two(a, c)
        return circle_two(b, c)

    # Circumcenter formula.
    d = 2.0 * (ax * (by - cy) +
               bx * (cy - ay) +
               cx * (ay - by))

    a2 = ax * ax + ay * ay
    b2 = bx * bx + by * by
    c2 = cx * cx + cy * cy

    ux = (
        a2 * (by - cy) +
        b2 * (cy - ay) +
        c2 * (ay - by)
    ) / d

    uy = (
        a2 * (cx - bx) +
        b2 * (ax - cx) +
        c2 * (bx - ax)
    ) / d

    r2 = (ux - ax) * (ux - ax) + (uy - ay) * (uy - ay)

    return ux, uy, r2

def minimum_enclosing_circle(points):
    random.shuffle(points)

    n = len(points)

    if n == 0:
        return 0.0, 0.0, 0.0

    circle = (points[0][0], points[0][1], 0.0)

    for i in range(1, n):
        p = points[i]

        if inside(circle, p):
            continue

        circle = (p[0], p[1], 0.0)

        for j in range(i):
            q = points[j]

            if inside(circle, q):
                continue

            circle = circle_two(p, q)

            for k in range(j):
                r = points[k]

                if inside(circle, r):
                    continue

                circle = circle_three(p, q, r)

    return circle

def solve():
    n = int(input())
    points = [tuple(map(float, input().split())) for _ in range(n)]

    cx, cy, r2 = minimum_enclosing_circle(points)

    # The original inequality becomes distance^2 <= 2t.
    t = r2 * 0.5

    print(f"{cx:.10f} {cy:.10f} {t:.10f}")

if __name__ == "__main__":
    solve()
```这`dist2`函数故意计算平方距离。 该算法只需比较距离和半径，因此取平方根会增加不必要的浮点运算。 

这`inside`函数将距离平方与半径平方进行比较。 小公差与半径的比例相关，这有助于处理数学上恰好位于边界上但以微小浮点误差表示的点。`circle_two`直接实现两边界点情况。 中点是圆心，点之间距离的平方的四分之一是半径的平方。`circle_three`处理三边界点情况。 行列式表示为`cross`检测共线性。 对于共线点，外接圆是未定义的，但最小外接圆只是直径连接两个最远点的圆。 

嵌套循环在`minimum_enclosing_circle`直接对应于边界参数。 外循环识别违反当前圆的点。 下一个循环修复该点并搜索第二个边界点。 最里面的循环搜索第三个边界点。 顺序很重要，因为一旦一个点违反了当前圆，它就必须属于该前缀的新最佳圆的边界。 

该算法使用`random.shuffle`加工前。 如果没有随机化，预期的线性时间保证就会消失。 几何本身不依赖于顺序，因此洗牌是安全的。 

Python 的浮点类型是 C double，这对于这里使用的几何计算来说足够了。 最终值在小数点后打印十位数字，为通常的绝对或相对浮点检查器提供足够的精度。

## 边缘情况

 对于单点情况```
1
3 7
```外循环在 ((3,7)) 处初始化半径为零的圆，并且没有遇到违规点。 最终半径平方为零，因此算法打印 (t=0)。 这里重要的性质是允许最小外接圆的半径为零。 

对于两点```
2
0 0
4 0
```第一个点创建一个零半径圆。 第二个点位于它的外部，因此它成为强制边界点。 第一个点也在零半径圆之外，导致构建两点圆。 其中心为 ((2,0))，半径平方为 (4)，报告值为 (4/2=2)。 不尝试进行三点计算。 

对于共线点```
3
0 0
2 0
5 0
```当所有三个点都成为边界候选点时，叉积为零。 无法从共线点计算外心，因为不存在经过三个不同共线点的有限圆。 相反，该实现比较三个成对的平方距离，选择对 ((0,0),(5,0))，并构造它们的中点圆。 中心为 ((2.5,0))，半径平方为 (6.25)，答案为 (3.125)。 

对于已经在边界上的点，`inside`测试采用小公差。 考虑```
2
0 0
4 0
```在第二个点创建以 ((2,0)) 为圆心、半径为平方 (4) 的圆之后，两个原始点的平方距离正好为 (4)。 浮点计算可以产生比 (4) 无限大的值，因此与严格的比较`<`可能会错误地重建圆圈。 容差在数学上将边界点视为已覆盖。 

对于重复点，```
5
7 7
7 7
7 7
7 7
7 7
```每个点与第一个点的距离为零。 圆永远不需要改变，答案仍然是 ((7,7,0))。 重复点不会改变最小外接圆。 

对于对称配置，例如```
4
0 0
2 0
2 2
0 2
```最优中心是((1,1))。 所有四个角的距离均平方为 (2)，因此半径平方为 (2)，所需的 (t) 为 (1)。 这种情况很有用，因为每个点都可以位于边界上，并且它检查算法是否不依赖于某个特定点作为唯一极值点。
