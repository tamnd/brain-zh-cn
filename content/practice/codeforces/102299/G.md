 ## 解决方案
 ## 问题理解

 我们有`n`莱西，每个都有固定的力量。 一开始，每个莱西都是其自身层次结构的根，因此有`n`单独的树。 

一次会议操作`+ i j`莱希说`j`成为莱希的下属`i`。 由于保证层次结构永远不会包含循环，因此此操作将连接两个先前独立的层次结构树。 确切的父子方向对于报告很重要，但为了回答查询，我们只需要知道哪些莱西属于同一棵树。 

威胁行动`? i`从莱希开始`i`并向上移动，直到到达该层次结构的领导者。 一旦整个层次结构知道了威胁，整个树中最弱的莱西就会被分配来处理它。 因此，查询要求包含以下内容的连接组件中所有莱西之间的最小功率：`i`。 

这些约束使预期的表示相当清晰。 最多可以有`10^5`莱西斯和多达`5 * 10^5`操作，时间限制为一秒。 扫描整个层次结构以查找每个查询的算法可以执行以下操作：`10^5 * 5 * 10^5 = 5 * 10^10`在最坏的情况下进行操作，远远超出了时间限制。 每次操作我们都需要几乎恒定的摊销工作。 

权力可以大到`10^9`，但它们只是进行比较和存储，因此 Python 整数就足够了。 事实上，层次结构保证是非循环的，这意味着每次成功的会议都会合并两个不同的树，这正是应用不相交集联合结构的设置。 

第一个边缘情况是单个莱西。```
1 1
7
? 1
```答案是`7`。 假设每个查询都有一个要跟随的父查询的解决方案在这里可能会失败，因为查询的 leshy 已经是领导者。 

另一个边缘情况是相等的功率值。```
2 2
5 5
+ 1 2
? 2
```答案是`5`。 等级制度决定谁是领导者，但权力决定谁处理威胁。 如果实现尝试根据权力选择领导者，混淆这两个概念可能会产生错误的结果。 

第三个有用的情况是当一个新的下属被附加到非根 leshy 之下时。```
3 3
10 4 7
+ 1 2
+ 2 3
? 3
```由此产生的层次结构是`1 -> 2 -> 3`，答案是`4`。 该组件是`{1, 2, 3}`，所以答案是整个组件的最小功率，而不仅仅是从`3`到根。 仅遵循父链并尝试检查访问的顶点的解决方案在这里可能会起作用，但它仍然会做不必要的工作，因为答案取决于整个树。 

## 方法

 直接的方法是显式维护每个 leshy 的父级。 对于查询`? i`，我们可以从`i`通过其父母，直到达到领导者，收集该层次结构的成员，然后找到他们的最低权力。 这是正确的，因为同一层次结构中的每个莱西最终都会向同一个领导者报告，而分配的莱西只是该层次结构中权力最小的成员。 

问题是工作量。 一个层次结构可以包含所有`n`leshys，查询可能需要检查所有这些。 和`m`操作，最坏情况的序列可能需要`O(nm)`工作，这取决于`5 * 10^10`给定范围内的基本访问。 即使我们优化父级遍历，重复扫描层次结构以获取其最小值仍然过于昂贵。 

有用的观察是查询的答案不依赖于层次结构的形状或方向。 它仅取决于属于同一层次结构的 leshys 集合。 会议合并两个这样的集合，而查询则要求一组中存储的最小功率。 

这正是由不相交集联合 (DSU) 处理的抽象。 每个层次结构由一个 DSU 组件表示。 对于每个组件，我们都存储其最小功率。 什么时候`+ i j`发生时，我们合并包含的组件`i`和`j`，新分量的最小值只是两个旧最小值中的最小值。 什么时候`? i`发生时，我们找到代表`i`并返回该代表存储的最小值。 

暴力方法之所以有效，是因为它会为每个查询重建层次结构，但当重复查询相同的大层次结构时会失败。 观察到只有组件成员资格和组件最小问题让我们完全放弃层次结构并准确维护查询所需的信息。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(nm)`最坏的情况|`O(n)`| 太慢了 |
 | 最佳|`O((n + m) α(n))`|`O(n)`| 已接受 |

 这里`α(n)`是阿克曼反函数，它的增长速度非常缓慢，以至于对于所有实际的竞争性编程约束，它的表现就像一个小常数。 

## 算法演练

 1. 读取每个 leshy 的功率并初始化仅包含该 leshy 的 DSU 组件。 它的最小组成部分是它自己的力量，因为还没有其他莱西属于它。 
2.对于一个`+ i j`操作，找到DSU代表`i`和`j`。 该会议连接了它们的两个层次结构，因此它们的组件必须合并。 

方向说`j`成为从属于`i`与未来的答案无关。 无论哪一个莱西是正式的父代，这两个集合现在都属于一个层次结构。 
3. 合并两个组件时，请按大小或等级使用并集，以使 DSU 树保持浅层。 将两个分量最小值中较小的一个存储为合并分量的最小值。 
4.对于一个`? i`运算，找到代表`i`并输出为该代表存储的最小值。 该组件中的每个莱西都属于同一层次结构，因此该值正是处理威胁的莱西的力量。 
5.使用路径压缩`find`。 每当发现代表时，就压缩从查询的 leshy 直接到该代表的路径。 未来的操作可以更快地找到该组件。 

### 为什么它有效

 不变量是每个 DSU 组件恰好代表一个当前层次结构，并且其代表处存储的最小值是该层次结构中所有莱西之间的最小功率。 

最初，每个层次结构都由一个莱西组成，因此不变量成立。 会议将两个不同的层次结构合二为一。 DSU 完全执行该合并，并取两个存储的最小值中的最小值给出组合层次结构中的最小值。 查询不会修改层次结构，因此查找的组件`i`返回其存储的最小值会在意识到威胁的人中提供最弱的莱西。 由于每个操作都保留这个不变量，因此每个查询都会返回所需的幂。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    power = list(map(int, input().split()))

    parent = list(range(n))
    size = [1] * n
    minimum = power[:]

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    out = []

    for _ in range(m):
        op = input().split()

        if op[0] == '+':
            a = int(op[1]) - 1
            b = int(op[2]) - 1

            a = find(a)
            b = find(b)

            if a == b:
                continue

            if size[a] < size[b]:
                a, b = b, a

            parent[b] = a
            size[a] += size[b]
            minimum[a] = min(minimum[a], minimum[b])

        else:
            x = int(op[1]) - 1
            root = find(x)
            out.append(str(minimum[root]))

    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```这`parent`array 是 DSU 林。 最初`parent[i] = i`，因为每个莱西一开始都是其自身等级制度的代表。 这`size`array 支持按大小并集，防止 DSU 结构退化为长链。 

这`minimum`数组存储每个组件代表的最小功率。 属于非代表的值不需要更新，因为每个查询都会首先调用`find`然后从当前代表处读取值。 

这`find`实现使用迭代路径减半。 作业`parent[x] = parent[parent[x]]`向上行走时缩短路径，提供与普通路径压缩相同的渐近行为，无需递归。 这也避免了 Python 递归深度的问题。 

输入中的索引是从 1 开始的，而 Python 数组是从 0 开始的，因此每个输入索引都会立即减 1。 并集操作检查两个代表是否已经相等。 该问题保证层次结构永远不会成为循环，因此此类合并不应发生在有效输入中，但保持检查可以使 DSU 稳健并避免破坏组件大小或最小值。 

Python 中不存在整数溢出问题，而且最大的幂无论如何都适合 Python 整数。 输出累积在列表中并在最后写入一次，这避免了为每个查询执行单独的输出操作的开销。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |`O((n + m) α(n))`| 每个联合和查询执行恒定数量的 DSU 操作，每个操作均按逆阿克曼复杂度进行摊销。 |
 | 空间|`O(n)`| DSU 存储每个莱西的父级、大小和最小值。 |

 和`n <= 10^5`和`m <= 5 * 10^5`，该解决方案每次操作执行基本上恒定的摊销工作。 这非常适合一秒的时间限制，而重复遍历大型层次结构可能需要数百亿次操作。

 ## 边缘情况

 单例层次结构情况由初始 DSU 状态处理。 为了```
1 1
7
? 1
```

`find(1)`立即返回唯一的代表，并且`minimum[0]`是`7`，所以输出是`7`。 不需要特殊情况的代码，因为单元素层次结构已经是有效的 DSU 组件。 

权力平等也是理所当然的。 为了```
2 2
5 5
+ 1 2
? 2
```合并计算`min(5, 5)`，即`5`。 该算法从不使用莱西索引或层次领导者作为权力的替代品，因此相等的值不会引入歧义。 

合并可以在不是其自身代表的 leshy 之下附加一个层次结构。 例如，```
3 3
10 4 7
+ 1 2
+ 2 3
? 3
```第一次合并后，`{1,2}`有最小值`4`。 第二次合并加入leshy`3`与该组件，给出最小`4`再次。 查询找到代表`3`并返回`4`。 DSU 不需要知道正式的层次结构是`1 -> 2 -> 3`，因为整个集合决定了答案。 

最大功率值是另一个值得检查的边界。 诸如以下的值`1000000000`直接存储在`minimum`， 和`min()`比较正常。 Python 具有任意精度的整数，因此即使稍后将实现调整为存储其他派生的整数值，也不存在溢出风险。 

最后，查询可能在涉及所查询的 leshy 的任何合并之前立即到达。 例如，```
3 2
8 3 5
? 3
? 1
```两个查询都对单例组件进行操作，产生`5`和`8`。 DSU 表示从第一个操作开始就有效，因此查询不需要任何预先的构建阶段。
