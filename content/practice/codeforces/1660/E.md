 ## 解决方案
 ## 问题理解

 给定一个二进制方阵，我们可以使用行和列的循环移位来重新排列它。 这些移位不会改变值，它们只会旋转位置，因此最终重要的是我们在开始支付翻转位之前如何对齐矩阵。 

选择任意行和列旋转顺序后，我们可以翻转单个单元格（从 0 切换到 1 或从 1 切换到 0），每次翻转花费一个单位。 目标是将矩阵转换为单位矩阵，这意味着每个对角单元必须为 1，每个非对角单元必须为 0。 

关键的困难在于我们没有被迫将对角线固定在原始位置。 通过循环移位行和列，我们有效地选择行索引的循环移位和列索引的循环移位。 这意味着我们的目标对角线不是固定的，而是可以相对于原始矩阵“移动”。 

每个测试用例都是独立的。 矩阵大小最多可达 2000，测试中的单元总数最多可达 400 万个，因此任何解决方案都必须避免每次对齐时进行三次或重复的大量重新计算。 

一种简单的方法会尝试所有行移位和所有列移位，从而给出 O(n^2) 对齐。 对于每次对齐，我们将计算需要多少次翻转才能使对角线对齐且其他所有值为零。 这将花费 O(n^3)，这太慢了。 

当矩阵在某些移位下已经具有接近对角线的结构而不是在其他移位下时，就会出现微妙的边缘情况。 例如，在类似排列的矩阵中，只有一种特定的循环对齐会产生完美的对角线。 假设只有行移位或列移位很重要的粗心方法将会失败，因为两个维度都会相互作用。 

## 方法

 如果我们忽略移位操作，问题很简单：我们必须将每个不匹配的单元格与恒等进行比较，这只是计算与恒等矩阵的差异。 复杂的是我们可以先循环旋转行和列。 

强力策略是尝试每对可能的循环移位，一个用于行，一个用于列。 应用移位对后，我们检查每个单元格并计算需要翻转多少次才能使矩阵统一。 由于行移位有 n 个选择，列移位有 n 个选择，并且每次评估成本为 O(n^2)，因此总复杂度变为 O(n^4) 或 O(n^3)，具体取决于我们重用计算的仔细程度。 不管怎样，这远远超出了 n 最多 2000 的限制。 

关键的见解是仅循环移动重新索引行和列。 我们可以考虑选择目标对角线，而不是考虑移动矩阵。 循环移位矩阵中的对角线对应于索引对 (i, j)，其中 j - i 是模 n 的常数。 因此，每个移位配置对应于选择对角线偏移。 

一旦我们固定了对角线偏移 d，如果 j - i == d (mod n)，则每个单元格 (i, j) 都被分类为对角线上，否则分类为非对角线。 对于固定的 d，我们可以直接计算成本：对角线单元必须变为 1，非对角线单元必须变为 0。成本只是计算不匹配。 

因此，我们不需要尝试 n^2 个移位对，而只需尝试 n 个可能的对角线偏移。 每次评估的成本为 O(n^2)，即 O(n^3)。 在最坏的情况下，这仍然太大。 

我们通过观察每个单元格对每个对角线选择的独立贡献来进一步减少。 如果 A[i][j] 为 1，则它恰好有助于一个对角线偏移（当 j - i 与该偏移匹配时）。 对于所有其他偏移量，它是一个非对角单元格，应该为 0，因此如果它在那里为 1，则会产生惩罚。 类似地，如果 0 位于所选对角线上，则会产生惩罚。

我们可以在 O(n^2) 中预先计算每个偏移量的贡献：对于每个单元，我们更新两个聚合结构，一个计算每个对角线上有多少个 1，并隐式导出非对角线成本。 这允许计算每个测试用例总共 O(n^2) 的最佳偏移量。 

这减少了从搜索布局到聚合每个模块化对角线类的贡献的问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力转变 | O(n^4) | O(n^4) | O(n^2) | O(n^2) | 太慢了|
 | 直接检查所有对角线 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 太慢了|
 | 对角线贡献聚合| O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 我们将问题重新定义为选择对角线偏移以最小化失配成本。 

1. 对于每个可能的对角线偏移 d，计算有多少个落在该对角线上。 我们通过 (j - i mod n) 定义对角线类。 此步骤是必要的，因为只有所选对角线上的单元格才需要为 1。 
2. 对于每个偏移量 d，我们计算对角单元的数量，即 n。 所以非对角单元格是 n^2 - n。 
3. 对于固定的 d，cost 计算如下：所有包含 0 的对角线位置必须翻转为 1，所有包含 1 的非对角线位置必须翻转为 0。这将 cost 分成两个独立的部分。 
4. 对于每个 d，使用预先计算的计数计算成本：

 对角线不匹配为 (n - Ones_on_diagonal[d])，

 非对角线不匹配为 (total_ones - Ones_on_diagonal[d])。 
5. 总成本变为：

 成本[d] = (n - 个对角线[d]) + (总个数 - 个对角线[d])。 
6. 迭代所有 d 并取最小成本。 

这样做的原因是循环移位不会改变哪些单元共享相同的 (j - i mod n) 值。 他们只旋转被认为是主要对角线的对角线。 因此，每个有效的移位配置完全对应于选择这些对角线类别之一。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t_line = input().strip()
    while t_line == "":
        t_line = input().strip()
    t = int(t_line)

    for _ in range(t):
        line = input().strip()
        while line == "":
            line = input().strip()
        n = int(line)

        grid = []
        total_ones = 0

        for _ in range(n):
            row = input().strip()
            grid.append(row)
            total_ones += row.count('1')

        diag_ones = [0] * n

        for i in range(n):
            row = grid[i]
            for j, ch in enumerate(row):
                if ch == '1':
                    diag_ones[(j - i) % n] += 1

        ans = 10**18

        for d in range(n):
            ones_on_diag = diag_ones[d]
            cost = (n - ones_on_diag) + (total_ones - ones_on_diag)
            ans = min(ans, cost)

        print(ans)

if __name__ == "__main__":
    solve()
```该代码首先使用模差 (j - i) 聚合每个对角线类的所有值。 这编码了所有可能的循环行和列移位的效果。 然后，它通过计算对角线内部和外部需要多少校正来评估每个对角线选择。 

一个微妙的点是我们从不明确地模拟转变。 模索引已经捕获了所有可能的循环对齐。 

## 工作示例

 ### 示例 1

 输入：```
n = 3
010
011
100
```我们计算总贡献和对角线贡献。 

| 我| j | A[i][j] | A[i][j] (j - i 模 3) |
 | ---| ---| ---| ---|
 | 0 | 1 | 1 | 1 |
 | 1 | 1 | 1 | 0 |
 | 1 | 2 | 1 | 1 |
 | 2 | 0 | 1 | 1 |

 所以 diag_ones = [1, 3, 0]，total_ones = 4。 

现在评估成本：

 对于 d = 1，对角线有 3 个 1，因此对角线翻转 = 3 - 3 = 0，非对角线翻转 = 4 - 3 = 1，总计 = 1。 

对于其他 d 值，成本更大。 

这证实了最佳对齐对应于移位，使得对角线类别 1 成为主对角线。 

### 示例 2

 输入：```
n = 2
10
10
```所有的都在第 0 列中。 

| 我| j | A[i][j] | A[i][j] (j - i 模 2) |
 | ---| ---| ---| ---|
 | 0 | 0 | 1 | 0 |
 | 1 | 0 | 1 | 1 |

 所以 diag_ones = [1, 1]，total_ones = 2。 

对于两个 d 值，成本 = (2 - 1) + (2 - 1) = 2。 

这显示了对称性：没有移位可以改善对齐，并且两条对角线同样有效，但仍然需要两次翻转。

 ## 边缘情况

 最小 1x1 矩阵不包含结构自由度。 唯一的要求是使单个单元格等于 1，因此如果它从 0 开始，则需要翻转一次。 该算法可以处理这一问题，因为只有一个对角线类，并且计算减少为直接不匹配计数。 

完全用零填充的矩阵没有对角对齐优势。 每个对角线选择都会产生相同的成本，因为所有对角线位置都是零并且必须翻转。 该算法反映了这一点，因为所有 d 的 diag_ones[d] 均为零，并且成本变为常数。 

充满 1 的矩阵强调非对角线惩罚。 即使选择对角线来最大化对齐，所有非对角线也必须被翻转。 该公式直接通过total_ones - diag_ones[d] 捕获这一点，确保非对角线校正的正确累积。
