 ## 解决方案
 ## 问题理解

 我们得到一个仅由加号和减号组成的字符串。 如果通过用一个加号重复替换两个连续的减号，可以将该子串转换为平衡字符串（这意味着它具有相同数量的加号和减号），则该字符串的子串被认为是有希望的。 我们被要求计算每个输入字符串的所有有希望的非空子字符串，每当相同的子字符串出现在不同位置时就计算重复项。 

限制因素很大。 每个字符串最多可以有 200,000 个字符，并且最多可以有 10,000 个测试用例。 所有测试用例的字符串长度总和也限制为 200,000，这意味着我们的解决方案在字符串长度上必须接近线性，理想情况下每个测试用例的 O(n) 或 O(n log n)。 独立检查每个子串的简单解决方案是每个测试用例的 O(n²) 时间复杂度，或者最多 4×10^10 次操作，这对于 2 秒的时间限制来说远远超出了可行的范围。 这意味着我们无法显式生成或检查所有子字符串。 

微妙的边缘情况包括完全由减号组成的字符串、具有交替的加号和减号的字符串以及非常短的字符串。 例如，字符串“----”有希望的子字符串“--”和“----”，但我们必须正确考虑替换操作可以生成平衡序列的次数。 不考虑替换操作的影响而天真地计算子串将会低估一些有希望的子串。 类似地，字符串“+-+-”在每个两个字符的子字符串中已经是平衡的，因此粗心的方法可能会根据索引而过度计数或不足计数。 

## 方法

 暴力法很简单。 迭代所有可能的子串，对于每个子串，模拟重复用“+”替换“--”，然后检查结果字符串是否平衡。 这原则上可行，但需要 O(n²) 个子字符串，并且模拟替换可以为每个子字符串添加另一个 O(n) 因子，在最坏的情况下给出 O(n³)。 显然这是不切实际的。 

关键的见解来自于用数字余额表示子字符串。 将加号视为+1，将负号视为-1。 平衡子串的净和为零。 替换操作可以解释为将“-2”（两个连续的负数）转换为“+1”，有效地将余额增加 3。这导致观察到，如果在从左到右遍历子串并保持累积和（或余额）时，最小余额永远不会低于后续替换无法补偿的水平，则子串是有希望的。 我们可以跟踪平衡前缀和，并使用哈希映射来计算 O(n) 时间内每个调整后的前缀的出现次数，类似于计算经典问题中的零和子数组。 

该转换将问题简化为扫描一次字符串，维护运行平衡，并使用映射来跟踪每个有效平衡发生的频率，仔细调整替换操作的效果。 这消除了显式生成所有子字符串的需要。

 ## 算法演练

 1. 将字符串转换为数值：+1 表示“+”，-1 表示“-”。 这允许我们使用整数和而不是字符串操作。 
2. 初始化变量`balance`归零和字典`count`跟踪调整余额的发生情况。 我们从`count[0] = 1`考虑空前缀。 
3.逐个字符遍历字符串，更新`balance`根据每个字符的数值。 
4. 每当我们在奇怪的位置遇到减号（或者等效地，可能需要更换才能达到平衡的状态）时，请调整`balance`减去 2。这有效地提前模拟了替换操作。 
5.查字典`count`对于当前调整后的`balance`。 之前发生这种平衡的次数表示以当前字符结尾的有希望的子字符串的数量。 按此计数增加答案。 
6. 增加字典中当前调整余额的计数。 
7. 继续到字符串的末尾，对所有贡献求和以计算有希望的子字符串的总数。 

为什么它有效：保持不变的是`count[balance]`表示可以扩展以形成以当前位置结尾的有希望子串的前缀子串的数量。 调整平衡以考虑替换操作可确保最终可以转换为平衡字符串的所有子字符串都被正确计数。 不会错过任何有希望的子字符串，因为以每个字符结尾的每个前缀都有助于所有以该字符结尾的有效子字符串。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

for _ in range(int(input())):
    n = int(input())
    s = input().strip()
    
    balance = 0
    count = {0: 1}
    result = 0
    
    for ch in s:
        if ch == '+':
            balance += 1
        else:
            balance -= 1
        
        # Adjust balance to account for replacement of -- with +
        adj_balance = balance
        while adj_balance % 2 != 0:
            adj_balance -= 3
        
        result += count.get(adj_balance, 0)
        count[adj_balance] = count.get(adj_balance, 0) + 1
    
    print(result)
```代码保持运行平衡，并对其进行调整以捕获潜在替换的影响。 使用字典可确保 O(1) 访问先前的计数。 字符串上的循环保证了相对于字符串长度的线性时间，而调整 3 以累积方式捕获替换操作。
