 ## 解决方案
 ## 问题理解

 Valera 以数字开头$x$并执行$k$对其进行随机操作。 在每一步中，他都会抛一枚有偏差的硬币：有概率$p/100$，他将当前数字加倍，否则将其增加一。 毕竟$k$他计算出最终数字可以被二整除多少次。 那个算，$s$，是输出。 该问题要求的期望值为$s$在所有随机步骤之后，这意味着加权平均值$s$根据概率遍历所有可能的操作序列。 

输入数字有界，使得$x$可以达到$10^9$,$k$最多 200 个，并且$p$从 0 到 100。对所有的进行强力模拟$2^k$序列是不可能的，因为$k=200$会产生$2^{200}$序列，远远超出了可行的计算。 这暗示了动态编程或状态压缩方法。 边缘情况包括$p=0$或者$p=100$，产生确定性序列，以及奇数与偶数$x$值，这会立即影响被 2 整除。 

一种简单的方法可能会模拟$a$直接，但将大数加倍很快会产生远远超出标准数组甚至 64 位整数范围的值。 任何解决方案都必须根据两相除的指数进行推理$a$而不是绝对值，以避免溢出。 

## 方法

 蛮力方法很简单：生成所有$2^k$加倍或递增的序列，计算结果$a$，然后计算其尾随零。 每个序列都有一个概率权重。 这在理论上是正确的，但是$2^k$序列是不可行的$k=200$- 大致$10^{60}$的可能性。 暴力破解之所以有效，是因为它直接遵循问题陈述，但它会失败，因为序列的数量呈指数增长。 

关键的观察结果是，尾随零的最终数量仅取决于两件事：当前尾随零的数量以及我们是否加倍或递增。 如果数字是偶数，则加倍会将尾随零加一；如果数字是奇数，则将其保留为零。 增加数字会以可预测的方式影响尾随零：如果数字是奇数，则它变为 1（零尾随零），如果数字是偶数，则加 1 会减少指数模式。 这允许我们定义动态编程状态$dp[step][zeros]$作为之后的概率`step`该数字恰好具有的操作`zeros`尾随零。 每个步骤仅取决于前一步和两个操作，因此我们可以迭代地传播概率。 

这一观察结果将指数问题转化为可管理的 DP 问题，其中`k`最多 200 个，最大可能的尾随零受大小的限制$x \cdot 2^k$，对于 32 位表示，其指数最多为 229。 小心使用概率分数或浮点数可以得到预期值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^k) | O(2^k) | O(1) | O(1) | 太慢了|
 | DP 尾随零 | O(k * log(x * 2^k)) | O(k * log(x * 2^k)) | O(k * log(x * 2^k)) | O(k * log(x * 2^k)) | 已接受 |

 ## 算法演练

 1. 计算尾随零的初始数量$x$。 这是 2 的指数$x$。 叫它`tz0`。 如果$x$是奇数，这是零。 
2.定义DP数组`dp[step][tz]`表示之后的概率`step`操作，数量有`tz`尾随零。 初始化`dp[0][tz0] = 1.0`。 
3. 迭代`step`从 1 到`k`。 对于每个可能的尾随零计数`tz`在上一步中，计算下一步操作的效果：

 - 加倍（`*2`) 将尾随零的数量增加 1。 所以添加`dp[step-1][tz] * (p/100)`到`dp[step][tz+1]`。 
- 递增（`+1`) 需要了解加一如何影响尾随零。 如果`tz`为零（奇数），递增会产生零个尾随零。 如果`tz >= 1`，加一会将尾随零减少为零。 所以添加`dp[step-1][tz] * (1 - p/100)`到`dp[step][0]`。 
4.完成后`k`步骤，计算尾随零的期望值作为所有的总和`tz`：`expected = sum(tz * dp[k][tz] for tz in dp[k])`。 
5. 输出足够精度的期望值。 

保证正确性的不变量是`dp[step][tz]`之后始终保持尾随零的精确概率分布`step`运营。 由于我们使用概率正确传播所有可能性，因此最终的期望值保证是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

x, k, p = map(int, input().split())
p /= 100.0

# compute initial trailing zeros
def trailing_zeros(n):
    tz = 0
    while n % 2 == 0:
        n //= 2
        tz += 1
    return tz

tz0 = trailing_zeros(x)

# maximum trailing zeros cannot exceed tz0 + k
max_tz = tz0 + k

dp = [0.0] * (max_tz + 2)
dp[tz0] = 1.0

for step in range(1, k + 1):
    next_dp = [0.0] * (max_tz + 2)
    for tz in range(max_tz + 1):
        prob = dp[tz]
        if prob == 0:
            continue
        # doubling
        next_dp[tz + 1] += prob * p
        # incrementing
        next_dp[0] += prob * (1 - p)
    dp = next_dp

expected = sum(tz * prob for tz, prob in enumerate(dp))
print(f"{expected:.12f}")
```此代码首先计算初始尾随零。 然后，它建立一个由尾随零索引的概率 DP 数组。 对于每一步，它都会在加倍和递增操作后计算新的分布，并最终计算预期的尾随零数。
