 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times m$网格中的每个单元都必须精确地划分为$k$简单的路径。 每条路径（称为管）必须至少包含两个单元，并且只能穿过边缘相邻的单元，而不能重新访问单元。 换句话说，每个管都是网格图中的一条路径，没有重复的顶点，并且每个网格单元必须恰好属于一个这样的路径。 

关键要求不仅仅是划分网格，而是输出每条路径的显式顶点序列。 所以任务是将整个网格建设性地分解为$k$不相交的简单路径，每条路径的长度至少为二。 

约束允许最多$n, m \le 300$，因此网格最多可以包含 90,000 个单元格。 这立即排除了任何尝试搜索路径或通过回溯将其解决为一般图分解问题的行为。 任何对每根管子进行线性时间 DFS 或尝试动态重新路由路径的方法都有可能在最坏的情况下变成二次方。 

一个微妙的限制是每个管必须至少有两个细胞。 这可以防止微不足道的分解为单例，并迫使我们确保单元的配对或链接。 另一个限制是$k$管子一定存在，所以我们不能随意决定覆盖网格后形成多少条路径； 施工必须精确控制段尺寸。 

打破朴素方法的主要边缘情况是当人们试图贪婪地创建长蛇然后任意分割它们时。 如果在不保留邻接性的情况下进行分裂，则管可能会断开连接或重新访问细胞。 例如，在一个$2 \times 3$网格，一条天真的蛇$(1,1)\to(1,2)\to(1,3)\to(2,3)\to(2,2)\to(2,1)$作为完整路径有效，但将其分割成任意块，例如$(1,1),(1,3)$会破坏邻接关系。 因此，分段必须尊重底层的遍历顺序。 

另一个问题是确保准确地$k$生成路径的同时仍然保证每个路径的大小至少为 2。这意味着我们至少需要$2k$单元格，这是由输入约束保证的$2k \le nm$，但我们仍然必须仔细分配长度。 

## 方法

 暴力方法会尝试构建所有可能的简单路径，然后选择$k$它们覆盖网格而不重叠。 这变成了对网格图路径分解的指数搜索。 即使试图贪婪地增长路径并在单元变得不可用时回溯也会导致组合爆炸，因为每个单元最多有四个邻居，并且决策会在全球范围内传播。 在最坏的情况下，我们将按以下顺序进行探索$O(4^{nm})$的可能性，这是完全不可行的。 

关键的观察是网格可以线性化为单个类似哈密顿量的遍历：我们可以按蛇形顺序逐行遍历所有单元格。 这会产生一条长而简单的路径，该路径恰好访问每个单元一次。 一旦我们有了一条路径，问题就简化为将该序列分割成$k$连续的段，因为蛇顺序中的邻接保证了网格中的邻接。 

关键的想法是蛇的任何连续部分都对应于有效的管子。 由于蛇中的连续元素是网格相邻的，因此每一段都形成一条有效的简单路径。 因此，我们不是解决图分解问题，而是将其简化为具有段长度约束的序列划分。 

然后我们确保每个段的长度至少为 2。因为我们正好需要$k$段，我们最初将 2 个细胞分配给每个管（消耗$2k$细胞），然后将剩余的细胞任意分布在最后一个管中或逐渐跨管分布。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解路径 | 指数| 指数| 太慢了|
 | 蛇穿越+分裂|$O(nm)$|$O(nm)$| 已接受 |

 ## 算法演练

 1. 使用蛇形遍历构造所有网格单元的单一排序：一行中从左到右，下一行中从右到左。 这确保了序列中每对连续的单元共享网格中的一条边。 
2. 存储全部$n \cdot m$数组中的单元格`cells`按照访问的顺序。 
3. We now need to split this array into$k$非空段，每个段的大小至少为 2。要强制执行此操作，请分配第一个$k-1$每个段大小为 2。 这正好消耗$2(k-1)$细胞。 
4. 剩余的单元格形成最后一段。 自从$2k \le nm$，最后一个段的大小至少为 2，满足约束条件。 
5. 对于每个段，依次输出其长度和单元格的坐标。 

正确性取决于每个段在蛇序中是连续的，并且该顺序中的邻接对应于网格中的邻接。 

### 为什么它有效

 该结构将网格简化为哈密顿路径。 沿着这条道路，邻接性通过建设得以保留。 简单路径的任何连续子路径本身就是简单路径，因此每个段都是有效的管。 由于分区恰好覆盖了所有索引一次，因此每个网格单元都属于一个管，并且没有管与另一个管共享单元。 在形成最后一段之前，通过在每个管中保留两个单元来强制执行最小长度约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m, k = map(int, input().split())

cells = []

for i in range(n):
    if i % 2 == 0:
        for j in range(m):
            cells.append((i + 1, j + 1))
    else:
        for j in range(m - 1, -1, -1):
            cells.append((i + 1, j + 1))

idx = 0

for i in range(k - 1):
    segment = cells[idx:idx + 2]
    idx += 2
    print(2, segment[0][0], segment[0][1], segment[1][0], segment[1][1])

remaining = cells[idx:]
print(len(remaining), end=" ")
for x, y in remaining:
    print(x, y, end=" ")
print()
```实现首先构建蛇形遍历。 每行的交替方向确保水平相邻，而连续的行在行边界处垂直连接。 

分裂逻辑有意最小化。 每个第一个$k-1$Tubes 恰好需要两个连续的单元格，保证有效性而无需推理结构。 最后一个管吸收所有剩余的细胞，并且约束$2k \le nm$保证它仍然至少有两个单元格。 

一个常见的陷阱是试图将额外的细胞分配到早期的管中。 这是不必要的，并且会增加破坏邻接关系的风险； 保持最后一段的所有灵活性完全避免了这种复杂性。 

## 工作示例

 ### 示例 1

 输入：```
3 3 3
```蛇令：

 (1,1) (1,2) (1,3) (2,3) (2,2) (2,1) (3,1) (3,2) (3,3)

 我们形成3个管子。 

| 步骤| 行动| 剩余细胞|
 | ---| ---| ---|
 | 1 | 取 (1,1)-(1,2) | 还剩 7 格 |
 | 2 | 取 (1,3)-(2,3) | 还剩 5 格 |
 | 3 | 剩余形式最后一管 | 5 格 |

 输出管：

 第一：(1,1)-(1,2)

 第二：(1,3)-(2,3)

 第三：按顺序剩余 5 个单元格

 这证实了所有管都遵循邻接关系，因为每一对都直接来自连续的蛇位置。 

### 示例 2

 输入：```
2 4 2
```蛇令：

 (1,1)(1,2)(1,3)(1,4)(2,4)(2,3)(2,2)(2,1)

 | 步骤| 行动| 剩余|
 | ---| ---| ---|
 | 1 | 取前 2 个单元 | 6 |
 | 2 | 剩余形式最后一管 | 6 |

 第一个管是有效边缘，第二个管是覆盖网格其余部分的完整蛇段。 

这表明即使当$k$由于体积小，施工时自然产生一根大管和一根小管，无需任何特殊套管。

 ## 边缘情况

 单行网格的行为与线性阵列相同。 蛇结构退化为从左到右的直线序列，并且分成对仍然产生有效的相邻片段。 

单列网格也会退化为笔直的垂直路径。 蛇形交替没有水平效果，但邻接仍然有效，因为连续单元格仅行索引不同。 

边界情况$2k = nm$迫使每个管子恰好有两个细胞。 该算法干净地处理了这个问题，因为最后一个段的大小也为 2，并且没有单元格未分配或重复。
