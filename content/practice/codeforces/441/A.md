 ## 解决方案
 ## 问题理解

 瓦莱拉想从一组卖家那里购买一件古董物品。 每个卖家都以当前拍卖价格提供多件商品。 瓦莱拉（Valera）只有在报价严格高于商品当前价格并且有固定预算的情况下才能达成交易`v`。 目标是找到他可以成功购买至少一件商品的所有卖家。 

输入提供卖家数量`n`和瓦莱拉的预算`v`。 对于每个卖家，我们都会收到他们拥有的商品数量以及当前价格列表。 输出必须说明 Valera 可以处理的卖家数量，然后是按升序排列的从 1 开始的指数。 

限制很小：`n`以及每个卖家的商品数量`k_i`最多 50 个。价格和 Valera 的预算最多为 10^6。 这意味着对每个卖家的所有商品进行直接搜索是可行的，因为最坏情况下的价格检查总数为 50 × 50 = 2500，这对于现代 CPU 来说在一秒钟内是微不足道的。 

一个微妙的边缘情况是，卖家的所有商品的价格都高于瓦莱拉的预算。 假设任何拥有商品的卖家都可以被选择的天真的方法会错误地包括它们。 另一个极端情况是当多种商品的价格比`v`; 每个卖家只需成功出价一次就足够了，但粗心的实施可能会导致多次出价。 

## 方法

 由于输入量较小，暴力方法本质上也是最佳方法。 我们可以遍历每个卖家，然后遍历他们的每件商品，检查价格是否低于 Valera 的预算。 第一个满足此条件的商品确认 Valera 可以与该卖家进行交易，我们可以继续与下一个卖家进行交易。 这是正确的，因为问题只要求每个卖家至少有一件商品是可以负担得起的，而选择的具体商品并不重要。 在最坏的情况下，我们执行`n * k_i`比较，最大输入最多为 2500。 

使这个问题能够有效解决的观察结果是我们不需要跟踪下面的所有项目`v`对于每个卖家； 我们只需要检测一个的存在。 这避免了不必要的计算，并使解决方案简单高效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力/最优| O(n * 最大 k_i) = O(2500) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读`n`和`v`来自输入。 
2.初始化一个空列表`deal_sellers`存储 Valera 可以与之进行交易的卖家的索引。 
3. 对于每个卖家`i`从 1 到`n`：

 1.读取物品数量`k_i`以及他们的价格。 
2. 按顺序查看每件商品的价格。 
3. 如果某件商品的价格严格低于`v`, 追加`i`到`deal_sellers`并为该卖家打破循环。 
4. 打印卖家数量`deal_sellers`。 
5. 按升序打印这些卖家的指数。 

为什么它有效：不变的是，每当卖家添加到`deal_sellers`, Valera 至少可以从该卖家那里购买一件商品。 迭代每个项目可以保证不会错过任何卖家，并且尽早中断可以避免多余的检查。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, v = map(int, input().split())
deal_sellers = []

for i in range(1, n + 1):
    data = list(map(int, input().split()))
    k_i, prices = data[0], data[1:]
    for price in prices:
        if price < v:
            deal_sellers.append(i)
            break

print(len(deal_sellers))
print(' '.join(map(str, deal_sellers)))
```该代码读取卖家数量和 Valera 的预算。 对于每个卖家，它会读取他们的商品并检查是否至少有一件商品价格实惠。 一旦找到价格实惠的商品，它就会记录卖家的索引并继续前进。 输出打印卖家总数及其指数，符合所需的格式。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n * 最大 k_i) | 我们会检查每个卖家的每件商品，直到找到价格实惠的商品。 |
 | 空间| O(n) | 我们存储瓦莱拉可以处理的卖家的索引。 |

 假设 n ≤ 50 且 k_i ≤ 50，总操作次数低于 2500，很容易在 1 秒内完成。 与 256 MB 限制相比，内存使用量可以忽略不计。 

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, v = map(int, input().split())
    deal_sellers = []
    for i in range(1, n + 1):
        data = list(map(int, input().split()))
        k_i, prices = data[0], data[1:]
        for price in prices:
            if price < v:
                deal_sellers.append(i)
                break
    out = f"{len(deal_sellers)}\n{' '.join(map(str, deal_sellers))}"

 ## 边缘情况

 如果某个卖家的所有商品都比 Valera 的预算贵，则算法永远不会追加该卖家。 例如，输入：```
2 10000
1 15000
2 12000 13000
```踪迹：

 | 卖家 | 价格 | 项目 < v? | 交易卖家 |
 | ---| ---| ---| ---|
 | 1 | 15000 | 15000 没有| []|
 | 2 | 12000、13000 | 没有| []|

 输出：```
0
```这证实了拥有买不起商品的卖家被正确排除。 该算法会检查每个项目，仅在找到有效项目时才会中断，从而防止误报。
