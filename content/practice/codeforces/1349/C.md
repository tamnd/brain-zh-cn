 ## 解决方案
 ## 问题理解

 网格在离散时间内演化。 每个单元格都有两种颜色之一，并且仅根据其四个邻居同时更新每个步骤。 

单元格查看当前状态。 如果它的邻居都不共享它的颜色，它就保持不变。 如果至少有一个邻居与它的颜色相匹配，它就会翻转。 

该规则是本地的，但是查询数量很大，时间参数可能会很大，最多$10^{18}$。 这立即排除了直接模拟步骤的可能性。 即使一个查询也可能需要迭代许多转换，因此任何随时间演变网格的方法都是不可能的。 

关键的困难是网格每个单元并不是独立的。 细胞的行为取决于附近的结构，并且变化会传播。 

过早假设周期性行为时会出现常见的失败情况。 例如，在交替的棋盘图案中，没有细胞发生翻转，但在聚集区域​​中，翻转以波的形式向外传播。 一种简单的方法可能会尝试模拟直到稳定，但稳定时间可以是线性的$n+m$每个单元格，这在全局范围内太大了。 

另一个微妙的问题是假设查询的独立性。 每个查询都依赖于相同的演化系统，因此预计算必须同时处理所有单元。 

## 方法

 直接模拟通过扫描所有单元格并应用规则来计算每个步骤。 每次迭代成本$O(nm)$。 由于值$p$上升到$10^{18}$，即使检测周期也不可靠，因为不同区域在不同时间稳定，并且全局周期性不完全保持。 

关键的观察结果是，该过程相当于图上的多源 BFS，其中已经具有至少一个相同颜色邻居的单元格立即“活跃”。 被相反颜色包围的细胞的行为与同质区域中的细胞不同。 

我们不是在时间上向前模拟，而是颠倒视点。 每个细胞都取决于它受到冲突邻居“影响”的速度。 已经有相同颜色邻居的细胞会较早开始翻转，而孤立的细胞则保持稳定的时间更长。 

这导致计算每个细胞变得不稳定的最早时间。 在那一刻之后，行为会变成周期 2 的周期性行为，因为具有至少一个相同颜色邻居的单元格会确定性地交替。 

因此，问题简化为使用 BFS 预先计算每个单元格的稳定距离，然后回答以下查询：$O(1)$。 

蛮力之所以有效，是因为它直接遵循规则，但在以下情况下会失败：$p$很大，因为传播是全局的并且每个查询都会重复。 BFS 减少之所以有效，是因为不稳定时间仅取决于本地结构并且与查询计数无关。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟|$O(tnm p)$|$O(nm)$| 太慢了 |
 | BFS 预计算 |$O(nm)$|$O(nm)$| 已接受 |

 ## 算法演练

 1. 对于每个单元格，检查其是否至少有一个具有相同初始颜色的相邻单元格。 将此类细胞标记为最初“不稳定”。 这些细胞会很早就开始翻转行为。 
2. 在时间 0 处初始化所有不稳定单元的 BFS 队列。这是有效的，因为不稳定会向外传播：一旦单元格的邻居已经不稳定或具有相同颜色的影响力到达它，它就会变得不稳定。 
3. 在网格上运行 BFS。 对于每个单元，计算它变得不稳定的最短时间。 这是分层传播的，因为每次迭代不稳定都会传播一步。 
4.将这个时间存储在一个数组中`dist[i][j]`。 如果一个细胞从未被到达，它就会永远保持稳定。 
5. 对于每个查询$(i, j, p)$， 比较$p$和`dist[i][j]`。 
6. 如果$p < dist[i][j]$，单元格从未开始翻转，因此其颜色与初始状态相同。 
7. 如果$p \ge dist[i][j]$，细胞处于交替状态，因此它在某个时间的颜色$p$仅取决于奇偶性$p - dist[i][j]$。 

不变的是 BFS 计算每个细胞受到相同颜色邻居影响的最早确切时间。 在那一刻之后，更新是确定性的，并且是周期性的，周期为 2。因为影响力每个时间步传播一层，所以 BFS 距离与时间演化完全匹配。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m, t = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    INF = 10**18
    dist = [[INF] * m for _ in range(n)]
    q = deque()

    # Step 1: find initially unstable cells
    for i in range(n):
        for j in range(m):
            for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
                ni, nj = i + di, j + dj
                if 0 <= ni < n and 0 <= nj < m:
                    if g[ni][nj] == g[i][j]:
                        dist[i][j] = 0
                        q.append((i, j))
                        break

    # Step 2: BFS propagation
    while q:
        i, j = q.popleft()
        for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
            ni, nj = i + di, j + dj
            if 0 <= ni < n and 0 <= nj < m:
                if dist[ni][nj] == INF:
                    dist[ni][nj] = dist[i][j] + 1
                    q.append((ni, nj))

    # Step 3: answer queries
    out = []
    for _ in range(t):
        i, j, p = map(int, input().split())
        i -= 1
        j -= 1

        if p <= dist[i][j]:
            out.append(g[i][j])
        else:
            diff = p - dist[i][j]
            if diff % 2 == 0:
                out.append(g[i][j])
            else:
                out.append('1' if g[i][j] == '0' else '0')

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```网格存储为字符串以节省内存使用。 BFS 队列从所有已经有相同颜色邻居的单元开始。 这确保我们只从真正不稳定的地区扩张。 

距离数组对每个单元开始交替的时间进行编码。 查询处理是恒定时间的。 

一个常见的实施错误是忘记时间比较必须是`p <= dist[i][j]`与严格的`<`。 正确的界限是不稳定开始的时间`dist`，所以就在那时第一次翻转发生。

 ## 边缘情况

 完全均匀的网格使每个单元格最初都不稳定，因此 BFS 将所有距离标记为零。 系统立即进入交替奇偶校验行为。 

棋盘网格没有相同颜色的邻接，因此所有距离保持无限。 查询始终返回初始颜色。 

像 1x1 这样的小网格永远不会翻转，因为没有邻居会触发不稳定，因此 BFS 队列保持为空，距离保持无限。
