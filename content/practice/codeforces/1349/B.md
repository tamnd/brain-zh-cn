 ## 解决方案
 ## 问题理解

 我们收到了几个独立的查询。 每个查询提供一个整数序列和一个目标值$k$。 我们可以重复选择序列的任何连续段，并用该段的中值替换该段中的每个元素。 中位数定义为对段进行排序后位于中间的元素，长度为偶数时选择中间靠下的元素。 

问题是，在应用任意数量的此类段操作之后，是否有可能使整个数组等于$k$。 

关键的困难在于每个操作都是高度非局部的：单个段操作一次覆盖许多位置，并且写入的值取决于该段的顺序统计数据而不是总和或极值。 这使得问题感觉可能需要跟踪许多可能的状态，但约束排除了这一点。 总共有$n \le 10^5$，任何显式模拟操作或探索段的解决方案都会失败，因为即使检查所有段也已经是二次的了。 

一个常见的微妙失败案例来自于假设中值运算可以自由地“创建”新值。 例如，如果$k$最初没有出现，人们可能仍然希望通过混合较小和较大的值来构造它。 这是不正确的，因为操作生成的每个值都必须已经是所选段中的元素之一。 中位数始终是该段的现有元素。 

另一种误导情况是当$k$存在于数组中但似乎“被困”。 例如，即使$k$存在，并不总是可以将其传播到整个数组，具体取决于值在其周围的分布方式。 

## 方法

 强力解释将尝试对所有可到达的数组进行建模。 从任何当前数组中，我们可以尝试每个段，计算其中值，应用操作，然后继续。 这创建了一个巨大的分支过程。 每一步都考虑$O(n^2)$段，并且每个转换都会以一种快速爆炸而难以处理的方式改变状态空间。 即使对于小$n$，这种方法变得不可行，因为可达状态的数量呈指数增长。 

关键的见解是我们根本不需要模拟该过程。 相反，我们要问的是要实现最终状态必须满足哪些结构条件。 由于每个操作都会用其现有值之一（中值）替换段，因此任何操作都不能引入尚不存在的值。 这立即意味着如果最终数组全部是$k$， 然后$k$必须已经存在于初始数组中。 

第二个观察是关于何时$k$可以“传播”。 为扩大一个区域$k$使用中值运算，我们需要找到中值变为的段$k$。 这需要该细分市场保持平衡$k$，这意味着它必须包含两边的值$k$。 如果除$k$严格位于一侧，那么没有段可以产生新的$k$-超出现有区域的主导区域。 

所以问题减少到检查数组是否包含$k$，以及是否分布在$k$并不是片面的。

 ## 算法演练

 我们独立处理每个查询。 

1. 扫描数组判断是否$k$存在。 如果不存在，我们可以立即断定不可能获得完全由以下内容组成的数组$k$。 这是因为中位数总是从所选段中的现有元素中提取。 
2. 计算是否存在至少一个严格小于的元素$k$。 
3. 计算是否存在至少一个严格大于的元素$k$。 
4. 如果每个元素都已经等于$k$，我们返回“YES”，因为不需要任何操作。 
5. 否则，只有当两者都小于-时，我们才返回“YES”$k$和一个大于$k$元素存在。 如果一侧缺失，我们返回“NO”。 

最后一步背后的直觉是传播$k$除了最初出现的情况之外，我们还需要以下片段$k$可以作为重新平衡值后的中位数。 这种再平衡需要双方的价值观$k$。 如果数组完全位于$k$，那么每个中位数都位于同一侧，并且$k$不可能在所有地方都占据主导地位。 

### 为什么它有效

 中值运算绝不会在所选段之外引入新值，因此$k$最初必须存在。 一次$k$存在，扩大其影响力的唯一方法是通过中位数评估为$k$，这需要存在小于和大于的值$k$。 如果数组相对于$k$，每个分段中位数也保持一边倒，防止任何进一步的结构变化朝着统一$k$大批。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        has_k = False
        has_less = False
        has_greater = False
        
        for x in a:
            if x == k:
                has_k = True
            elif x < k:
                has_less = True
            else:
                has_greater = True
        
        if not has_k:
            print("NO")
        elif all(x == k for x in a):
            print("YES")
        else:
            if has_less and has_greater:
                print("YES")
            else:
                print("NO")

if __name__ == "__main__":
    solve()
```该实现将数组分为三个逻辑类别$k$：相等、更小、更大。 存在检查$k$是必要的，因为如果没有初始发生，则任何中值运算序列都无法引入它。 

最终的决策逻辑直接遵循结构特征：要么数组已经是统一的，要么它必须包含数组两侧的值$k$允许超出初始发生的任何传播。

 自从$k = 3$不会出现在任何地方，任何操作都无法引入它。 每个中位数都是从现有段值中选择的，因此值 3 是无法达到的。

 ## 边缘情况

 一种边缘情况是当$n = 1$。 该数组已经是统一的，因此答案仅取决于该单个值是否等于$k$。 如果是的话，答案就是“是”，否则就是“否”。 

另一种情况是当所有值都严格小于$k$或严格大于$k$。 即使$k$出现在数组中的某处，丢失值谱的一侧会阻止任何中值运算稳定在周围$k$在新区域，这阻止了完全传播。 

最后一个微妙的情况是$k$存在但不是分布的“中心”。 如果每个值都在一侧$k$，则每个线段中位数都停留在该侧，因此任何操作都无法将 (k` 的影响扩大到孤立位置之外。
