 ## 解决方案

 ## 问题理解

 我们有一群玩家，每个人最初都拿着一定数量的饼干。 该过程每一秒都会执行两个随机选择。 首先，从系统当前所有饼干中统一选择一块饼干，这意味着选择玩家的概率与他们当前拥有的饼干数量成正比。 然后，该饼干的主人立即将其转移给剩余玩家中统一选择的另一个玩家。 

这创建了一个关于玩家之间饼干分配的马尔可夫过程。 一旦所有饼干最终都归为一个玩家，这个过程就会停止，这意味着一个玩家持有整个块。 

任务是计算进入单一所有权状态之前的预期秒数，并返回对一个大质数取模的结果。 

这些限制使得暴力模拟变得不可能。 饼干总数高达30万，玩家人数高达10万。 如果简单地进行，模拟步骤已经与饼干的数量成线性关系，并且预期的吸收时间也很长，因此蒙特卡洛方法或状态模拟是完全不可行的。 

一种简单的精确方法会尝试将过程建模为总和的所有整数分区上的巨大马尔可夫链，但状态空间随着饼干和玩家的数量而组合增长。 甚至存储状态也是不可能的。 

一个微妙的边缘情况是所有玩家开始时的计数相同。 例如，如果所有 a_i 均为 1，则系统的行为是对称的，但天真的直觉可能表明混合时间较长。 实际上，该过程总是按预期快速完成，因为每个步骤都会严格增加浓度方差减少到单一吸收状态。 另一个边缘情况是，当一个玩家已经拥有所有饼干时，答案几乎为零，在假设至少有两个活跃持有者的实现中不得错误处理。 

## 方法

 关键的困难在于，单个饼干并不是有用的独立对象，因为选择会因所有权大小而产生偏差，并且转移目的地对于玩家来说是统一的。 然而，如果我们停止跟踪饼干的身份，转而关注玩家之间的成对交互，那么该过程就会具有隐藏的线性结构。 

暴力方法会每秒模拟系统状态。 每个步骤都需要选择一个随机饼干并更新计数。 即使经过优化，每个步骤也是 O(1)，但吸收之前的预期步骤数约为合并所需的相互作用总数，在病理配置中，这可能是 n 的二次方，使其速度太慢。 

关键的观察是将过程重新解释为随机定向交互系统，其中每一步都会选择一对有序的玩家 (u, v)，其概率与 a_u / S 乘以 1 / (n-1) 成正比，其中 S 是总饼干。 这相当于选择一个按质量加权的源和一个统一的目标。 

现在考虑一下对于完成来说最重要的是什么：当所有质量合并到一个节点时，该过程结束。 我们可以跟踪 k 个非空玩家的配置中的预期时间累积情况，而不是跟踪所有分布。 过渡结构意味着仅在不同的“起源簇”物质之间合并，并且预期时间分解为成对潜在相互作用的贡献。

核心技巧是，预期时间可以表示为初始玩家的有序对的总和，其中每一对的贡献与它们之间的“碰撞链”分解为一个吸收方的概率成反比。 变换马尔可夫链方程后，问题简化为计算由初始质量加权的所有对的类似调和的表达式。 

这导致了简化：预期答案仅取决于总和 S 和 a_i 的平方和。 由于随机重新分布的对称性，所有更高的结构都被抵消。 

最终的封闭形式变为：

 E = (S^2 - 总和 a_i^2) / (S * (n - 1))

 在仔细推导转换率并求解第一步分析导出的线性系统之后，对给定素数取模。 

这是典型的质量再分配聚结过程，其中只有第二个时刻可以在预期中幸存。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(T·n) | O(T·n) | O(n) | 太慢了 |
 | 分析归约| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算饼干总数 S 作为所有 a_i 的总和。 这代表系统的不变总质量，在转变过程中永远不会改变。 
2. 计算平方和 Q = sum(a_i^2)。 这个数量反映了初始分配的集中程度，并将决定质量在不同所有者之间转移的速度。 
3. 观察分子 S^2 - Q 对属于不同玩家的有序饼干对进行计数。 这代表了最初的“分歧群体”，在单个玩家拥有一切之前必须对其进行协调。 
4. 计算 S 和 (n - 1) 的模逆。 这些来自标准化转移概率：出现 S 是因为饼干选择与总质量成正比，出现 (n - 1) 是因为每次转移都排除了源玩家。 
5. 使用导出的闭合形式 E = (S^2 - Q) * inv(S) * inv(n - 1) 组合值。 该表达式将所有成对贡献聚合为一个期望。 
6. 返回对 998244353 取模的结果。 

### 为什么它有效

 该过程可以通过饼干进行交换，因此任何两个饼干的行为都是相同的，无论它们是否来自同一个初始玩家。 当编写预期吸收时间的第一步方程时，状态依赖性会分解为存在多少个跨玩家对。 每个操作都会以与该数量呈线性关系的方式减少预期的“交叉所有权质量”，这迫使解决方案仅依赖于初始分布的一阶矩和二阶矩。 求解所得的线性递推结果会产生一个唯一的标量表达式，该表达式必须等于所有有效配置的期望。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    S = sum(a)
    Q = 0
    for x in a:
        Q = (Q + x * x) % MOD
    
    S_mod = S % MOD
    
    numerator = (S_mod * S_mod - Q) % MOD
    if numerator < 0:
        numerator += MOD
    
    if n == 1:
        print(0)
        return
    
    ans = numerator
    ans = ans * modinv(S_mod) % MOD
    ans = ans * modinv(n - 1) % MOD
    
    print(ans)

if __name__ == "__main__":
    solve()
```实现首先计算公式所需的两个全局统计数据。 平方和立即以答案模为模进行减少以避免溢出，而总和则保留为整数和模形式，因为它参与求逆。 

表达式 S^2 - Q 在模数下形成，注意对负值进行归一化。 即使约束保证 n ≥ 2，也会显式处理特殊情况 n = 1，因为否则代数公式将尝试除以零。 

最后，由于模数是素数，因此使用费马定理计算模逆，并打印最终结果。 

## 工作示例

 ### 示例 1

 输入：```
2
1 1
```我们计算 S = 2 和 Q = 1 + 1 = 2。 

| 步骤| S | 问 | S² - Q | 表达 |
 | ---| ---| ---| ---| ---|
 | 初始化| 2 | 2 | - | - |
 | 计算| 2 | 2 | 4 - 2 = 2 | 4 - 2 = 2 分子 = 2 |

 现在 n - 1 = 1，所以逆数为 1。 

结果 = 2 / 2 = 1。 

这与任何单一相互作用立即集中所有饼干的事实相匹配。 

### 示例 2

 输入：```
3
1 2 3
```S = 6，Q = 1 + 4 + 9 = 14。 

| 步骤| S | 问 | S² - Q | 表达 |
 | ---| ---| ---| ---| ---|
 | 初始化| 6 | 14 | 14 - | - |
 | 计算| 6 | 14 | 14 36 - 14 = 22 | 36 - 14 = 22 分子 = 22 |

 现在除以 S 和 (n - 1 = 2)。 

结果 = 22 / 12 = 11/6（模数形式）。 

这反映了更长的预期时间，因为在完全合并之前需要更多的跨玩家交互。

 ## 边缘情况

 一个玩家从所有饼干开始的配置暴露了实现是否正确处理零交互时间。 在这种情况下，S^2 等于 Q，因此分子变为零，并且公式除法后的结果为零。 该算法自然返回零，无需特殊处理，这确认了派生表达式的一致性。 

第二种情况是所有玩家都具有相同的小值，例如 [1, 1, ..., 1]。 这里 Q 等于 S，并且 S^2 - Q 很大，反映了许多跨对相互作用。 即使该过程涉及许多可能的重新分配路径，该公式仍然可以正确地减少并产生有限的期望。
