 ## 解决方案
 ## 问题理解

 有容量的气球`1, 2, ..., n`以及含有整数量氦气的气罐。 每个罐必须恰好分配给一个气球，并且罐中的氦气量不能分开。 气球接收的氦气不能超过其容量。 

目标不是最大化氦气总量。 相反，在选择分配后，我们会查看填充到其容量的最小部分的气球。 我们想让最糟糕的气球尽可能充满。 

输入给出了气球的数量和所有罐中的氦气量。 输出是最大可能的值`f`这样每个气球最终至少可以有`f`其容量已满。 如果甚至不存在一项有效的避免爆炸的分配，那么答案是`-1`。 

约束条件`n <= 2 * 10^5`排除任何尝试多次作业的情况。 有`n!`气球和罐子之间可能配对，因此即使对于非常小的输入，直接搜索也是不可能的。 需要有一个有效的解决方案`O(n log n)`或类似的，因为对几十万个值进行排序是可以接受的，但二次工作则不行。 

第一个边缘情况是一个对于所有可能的匹配来说都太大的罐子。 例如：```
1
2
```唯一有容量的气球`1`，但罐内含有`2`单位。 正确的输出是：```
-1
```仅优化最小分数的粗心解决方案可能会输出正值，因为罐子已“满”，但它忽略了爆炸约束。 

另一个棘手的情况是空罐：```
3
0 2 3
```罐子分类后成为`0, 2, 3`。 第一个气球得到空罐，所以最小分数是`0`。 正确的输出是：```
0.0
```假设每个气球都能收到一定数量的解决方案在这里会失败。 

第三种情况是大罐子应该与大气球搭配：```
3
1 1 3
```排序后的赋值给出分数`1/1`,`1/2`， 和`3/3`，所以答案是`0.5`。 将最大的罐子放在最小的气球上的贪婪方法将立即做出无效的分配。 

## 方法

 暴力解决方案将尝试所有可能的罐排列。 对于每个作业，它将检查是否有气球爆炸并计算最小填充分数。 这种方法是正确的，因为它检查了每种可能的排列，但作业的数量是`n!`，它几乎立即变得不可用。 

不太极端的版本将对答案进行二分搜索，并对每个可能的分数运行匹配算法。 对于固定分数`x`，每个气球的尺寸`s`需要一个罐子，其中包含`x*s`和`s`氦。 通用的匹配算法可以工作，但没有必要，因为气球具有非常特殊的结构。 

关键的观察结果是气球容量已经排序：`1, 2, ..., n`。 如果罐子越来越多地分类为`c1 <= c2 <= ... <= cn`，最好的分配是将最小的罐子与最小的气球配对，将第二小的罐子与第二小的气球配对，依此类推。 

原因是，将较大的罐分配给较小的气球只会使容量限制更加困难，而将较小的罐移向较小的气球可以提高满足所有下限和上限的机会。 排序后，我们只需要独立检查每个位置即可。 

气球用`i`，指定的容器必须满足：```
x * i <= ci <= i
```上限检查气球是否爆炸。 下限决定了最小可能的分数。 最好的答案就是最小的值`ci / i`排序后，假设所有上限均有效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 按非降序对所有罐数量进行排序。 排序顺序代表我们需要考虑的唯一分配，因为最小的罐子应该分配到最小的气球。 
2.检查已分类的罐子所在位置`i`反对气球`i + 1`。 如果罐内含有超过`i + 1`氦气，气球会爆炸并且不存在有效的分配。 
3. 对于每个有效的气球，计算分数`canister / capacity`。 答案是这些分数中的最小值，因为目标是最大化填充最少的气球。 
4. 以足够的精度打印最小分数。 

为什么有效：排序后，罐子的每个前缀都包含最小的可用数量。 如果最小的`k`罐子可以装满最小的`k`气球按排序顺序排列，任何其他分配都无法改善最弱的气球，因为将较大的罐子移动到较小的气球只会消耗更好的资源，但它的用处不大。 因此，排序后的配对给出了最大可能的最小分数。 该配对中的最小比率正是限制气球。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n_line = input().strip()
    if not n_line:
        return
    n = int(n_line)
    c = list(map(int, input().split()))
    c.sort()

    ans = 1.0
    for i, x in enumerate(c, start=1):
        if x > i:
            print(-1)
            return
        ans = min(ans, x / i)

    print("{:.10f}".format(ans))

if __name__ == "__main__":
    solve()
```代码首先对罐子进行排序，以便贪婪配对成为可能。 循环使用`start=1`因为气球的容量是`1`通过`n`， 不是`0`通过`n-1`。 

条件`x > i`检查爆炸规则。 这必须在计算答案之前发生，因为溢出的气球会使整个作业变得不可能。 

变量`ans`存储迄今为止看到的最弱的气球分数。 Python 浮点精度在这里就足够了，因为所需的误差容限是`1e-6`。 

Python 中不存在整数溢出问题。 在具有固定宽度整数的语言中，仍然应该小心地进行比较，因为原始值可能大到`200000`。

 ## 边缘情况

 对于溢出罐的情况：```
1
2
```排序后的列表包含一个具有值的罐子`2`。 该算法将其与气球容量进行比较`1`并检测到`2 > 1`，所以它返回`-1`在计算任何分数之前。 

对于空罐：```
3
0 2 3
```排序顺序不变。 分数是`0/1`,`2/2`， 和`3/3`。 最小值是`0`，这是最好的答案，因为一个气球必须保持空状态。 

对于顺序很重要的情况：```
3
1 1 3
```排序后的分配给出了气球容量`1, 2, 3`用氦气`1, 1, 3`。 分数是`1`,`0.5`， 和`1`。 算法返回`0.5`。 首先将最大的罐子分配给最小的气球不会改善最小分数，并且可能在更复杂的输入中创建无效状态。
