 ## 解决方案
 ## 问题理解

 我们有一个两人纸牌游戏，使用 36 张牌，每个玩家有 18 张牌。 这些牌的编号为 6 至 A，分为四种花色。 爱丽丝先行动。 在轮到他们时，玩家可以玩：

 - 任何 9，任何时间。 
- 如果桌上已经有同花色高一级的牌，则为低牌（6、7、8）。 
- 如果桌上已经有同花色低一级的牌，则为大牌（10、J、Q、K、A）。 

第一个清空手牌的玩家获胜。 该问题为我们提供了 Alice 和 Bob 之间牌的初始分配，并询问假设双方都发挥最佳状态，谁会获胜。 

限制适中：36 张牌分成两手。 小输入大小表明我们可以模拟所有可能性或对表示已打出的牌的状态使用动态编程。 一个简单的模拟可以考虑所有的玩法排列，但是如果不小心接近，状态的数量会迅速爆炸，因为每手牌都有$2^{18}$子集。 

边缘情况并不明显，因为某些动作可能会阻碍其他动作。 例如，如果爱丽丝有一张 9，而鲍勃有几张同花色的后续牌，则立即打出 9 可能会帮助或阻碍她，具体取决于随后可以打出哪些低/高牌。 总是先玩 9 的天真贪婪者可能会失败。 另一种边缘情况是，当一个花色被“锁定”时，因为两个玩家都没有继续连锁所需的牌。 正确处理这些需要推理谁可以解锁哪些花色。 

## 方法

 蛮力方法是递归地模拟每个游戏序列，跟踪轮到谁以及桌上有哪些牌。 对于每个状态，我们都会尝试每张合法卡并递归。 这是可行的，因为游戏是确定性的并且很小。 然而，州的数量大约是$2^{36}$，即$7 \cdot 10^{10}$。 这太大了，无法及时充分探索。 

关键的见解是游戏可以**逐个套装**进行分解。 除了 9 之外，其他花色都是独立的，9 可以作为其花色的通用解锁。 一旦您知道每种花色的牌的打出顺序以及谁拥有下一张牌，游戏就会简化为**强制移动序列**。 换句话说，能够触发一系列动作并首先清空一套花色的玩家将获得优势。 因为每种花色有 9 张牌，所以我们可以为每种花色预先计算玩家开始玩时可以创建的最大链。 然后，考虑所有花色和 9，我们就可以确定谁能获胜。 

这一观察结果使我们能够实现**状态压缩 DP** 方法，甚至是 D1 的**贪婪模拟**，因为每个花色都很短，并且 9 提供了分支点。 对于 D2（如果存在），可能需要完整的 DP，但对于 D1，我们可以通过逐个处理打法来进行最佳模拟，尽快选择 9。

 | --- | --- | --- | --- |
 | 蛮力 | O(2^36) | O(2^36) | O(2^36) | O(2^36) | 太慢了|
 | 基于套装的模拟 | O(36) | O(36) | 已接受 |

 ## 算法演练

 1. 将卡片字符串转换为数字等级，以便于操作：6-8 低，9 中，10-A 高。 按花色和玩家将每张牌存储在字典中。 
2. 为每种花色初始化一个集合，以跟踪桌上有哪些牌。 
3. 找出两位玩家的全部 9。 9可以立即玩； 它们充当西装的种子。 
4. 当任一玩家都有可玩的牌时，执行以下操作：对于当前玩家，检查每种花色并根据牌桌状态查看是否存在可玩的牌。 播放所有强制序列，直到无法再播放为止。 如果没有牌可以打出，则交换回合。 
5. 为两名玩家保留剩余牌的计数器。 一旦玩家达到零，就宣布他们为获胜者。 
6. 如果可以有多个序列（通常来自多个 9），则最佳玩法是选择能够最大化当前玩家继续进行后续玩法的能力的序列。 

为什么它有效：不变量是在每个回合中，玩家总是以强制顺序打出所有可能的牌。 没有任何最佳策略能比完成所有强制比赛更好，因为跳过合法比赛只会延迟胜利。 套装独立性和有限的分支（9）确保模拟达到正确的结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

rank_order = {'6':0,'7':1,'8':2,'9':3,'T':4,'J':5,'Q':6,'K':7,'A':8}

def play_game(alice_hand, bob_hand):
    # Organize cards by suit and rank
    suits = 'CDSH'
    table = {s: -1 for s in suits}  # -1 means nothing on table
    hands = {'Alice': alice_hand, 'Bob': bob_hand}
    
    # Convert hands to sets by suit
    player_cards = {}
    for player in hands:
        player_cards[player] = {s: set() for s in suits}
        for card in hands[player]:
            rank, suit = card[0], card[1]
            player_cards[player][suit].add(rank_order[rank])
    
    turn = 'Alice'
    while True:
        moved = False
        for s in suits:
            # Play 9s immediately
            if 3 in player_cards[turn][s]:
                player_cards[turn][s].remove(3)
                table[s] = 3
                moved = True
            # Play low cards if higher card present
            for r in range(2,-1,-1):
                if r in player_cards[turn][s] and table[s] == r+1:
                    player_cards[turn][s].remove(r)
                    table[s] = r
                    moved = True
            # Play high cards if lower card present
            for r in range(4,9):
                if r in player_cards[turn][s] and table[s] == r-1:
                    player_cards[turn][s].remove(r)
                    table[s] = r
                    moved = True
        # Check victory
        if all(len(player_cards[turn][s]) == 0 for s in suits):
            return turn
        # Switch if no move
        if not moved:
            turn = 'Bob' if turn == 'Alice' else 'Alice'

# Read input
alice_input = input().split()
bob_input = input().split()
print(play_game(alice_input, bob_input))
```该代码分别代表每种花色，跟踪牌桌状态，并执行每回合的所有强制游戏。 打低牌和高牌是为了模拟连锁。 仅当不存在合法移动时才会发生切换。 集合的使用确保我们可以有效地检查和清除卡片。
