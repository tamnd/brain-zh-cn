 ## 解决方案
 ## 问题理解

 我们被要求模拟将多个文件从一台服务器复制到另一台服务器的过程。 每个文件的大小以字节为单位，并且复制是连续的，一次一个字节。 有两个进度指示器：第一个显示当前复制文件的百分比，第二个显示复制的所有文件的总体百分比。 两个百分比在每个字节后都被降低到最接近的整数。 

输入给出文件数量`n`以及它们的大小的数组。 输出是同时出现在两个进度条上的从 0 到 100 的所有整数。 也就是说，在复制过程中的某个时刻，当前文件的进度和总进度都会向下舍入到相同的整数。 

限制很小：每个文件最多 1000 字节，最多 100 个文件。 这意味着最坏情况下复制的总字节数为100,000，逐字节模拟是可行的。 

当文件大小不均匀地除以 100 时，就会出现不明显的边缘情况。 例如，大小为 6 的文件给出的进度值为 0、16、33、50、66、83 和 100。一种简单的方法，仅检查`100/a_i`可能会错过中间值。 另一个边缘情况是多个大小为 1 的文件：两个进度条都会直接从 0 跳转到 100，无需中间步骤，并且算法仍必须包含 0 和 100。 

## 方法

 最直接的方法是暴力破解：模拟复制每个文件的每个字节，计算当前文件的百分比和总百分比，并存储出现在两个条上的所有整数。 这是正确的，因为进度条会确定性地更新并且总字节数很小。 然而，这种方法单独迭代每个字节。 在最坏的情况下，对于 100 个每个 1000 字节的文件，我们模拟 100,000 个步骤。 虽然这对于给定的约束是可行的，但没有必要。 

关键的见解是我们不需要模拟每个字节。 对于每个文件，当前文件的进度仅在以下情况下改变：`floor(100*x/a_i)`增加，总进度也类似。 因此，我们可以计算每个整数百分比出现的字节范围。 对于每个整数`p`从0到100，我们可以检查是否存在`x`在文件中这样`floor(100*x/a_i) == p`和`floor(100*(sum_previous + x)/total) == p`。 由于文件大小很小，因此检查所有文件从 0 到 100 的所有整数是有效的。 这将问题从逐字节模拟减少到每个文件的每个百分比的范围检查。

 | --- | --- | --- | --- |
 | 蛮力 | O(总和(a_i)) | 奥(101) | 接受小尺寸 |
 | 优化百分比检查 | O(n * 101) | 奥(101) | 已接受且干净|

 ## 算法演练

 1. 计算所有文件的总大小。 这是整体进度计算所必需的。 
2. 初始化一个集合来存储可以出现在两个进度条上的所有百分比。 
3. 迭代每个文件。 跟踪此文件之前复制的总字节数，称为`copied_so_far`。 
4. 对于每个整数百分比`p`从 0 到 100，计算字节范围`x`当前文件的进度在哪里`p`。 这是通过解决不等式来完成的`p <= 100 * x / a_i < p + 1`。 将这些不等式转换为整数界限`x`。 
5、计算对应的字节范围`x`总进度也是`p`，使用相同的方法：`p <= 100 * (copied_so_far + x) / total < p + 1`。 
6. 检查当前文件进度和总进度的范围是否相交。 如果有，请添加`p`到结果集。 
7.处理完所有文件后，按顺序输出所有百分比。 

这样做的原因是，对于每个整数百分比，我们明确检查是否存在至少一个字节，两个进度条都显示它。 通过使用整数范围而不是单个字节，我们可以避免不必要的模拟，同时保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

total = sum(a)
result = set()
copied_so_far = 0

for size in a:
    for p in range(101):
        # current file: p <= 100 * x / size < p + 1
        l1 = (p * size + 99) // 100  # ceil(p*size/100)
        r1 = ((p + 1) * size - 1) // 100  # floor((p+1)*size/100) - 1
        
        # total: p <= 100 * (copied_so_far + x) / total < p + 1
        l2 = (p * total + 99 - copied_so_far * 100) // 100
        r2 = ((p + 1) * total - 1 - copied_so_far * 100) // 100
        
        if l1 <= r1 and l2 <= r2 and max(l1, l2) <= min(r1, r2):
            result.add(p)
    copied_so_far += size

for x in sorted(result):
    print(x)
```该代码使用整数除法仔细计算范围。`l1`和`r1`表示当前文件中产生进度的最小和最大字节索引`p`。`l2`和`r2`为总进度做同样的事情。 支票`max(l1, l2) <= min(r1, r2)`确认是否至少有一个字节满足这两个条件。
