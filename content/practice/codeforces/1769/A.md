 ## 解决方案
 ## 问题理解

 我们得到一排滑板车，按它们到目的地的初始距离排序。 小型摩托车$1$从最近的地方开始，踏板车$n$最远。 每辆踏板车都有一个等于其指数的固定标称速度，因此指数较高的踏板车会尝试移动得更快。 

道路受到限制：滑板车不能互相超越，并且必须保持至少一米的间隙。 当较快的踏板车追上较慢的踏板车时，它会被迫减速，从而保留距离约束，从而有效地形成一条移动链，其中速度通过接触向后传播。 

任务是在这些规则下精确运动一秒后确定所有滑板车的位置。 

限制很小：$n \le 100$。 这允许在短时间内进行直接模拟或贪婪的传播过程，而无需任何性能问题。 

一种常见的故障模式是单独处理踏板车并从其位置中减去其速度。 一旦更快的踏板车超越较慢的踏板车，这种情况就会打破。 另一个错误是只强制执行一次约束，而不是意识到减速会通过整个前缀向后传播。 

## 方法

 一种简单的方法以小时间步长模拟运动，更新所有位置，然后通过将滑板车推开来修复违规行为。 这在概念上可行，但不必要地繁重，并且需要在每一步仔细处理排序约束。 

关键的简化是要注意，一秒钟后，每个滑板车的位置取决于其自身的速度或前面的滑板车。 如果一辆踏板车违反了与前一辆踏板车的一米间距，则它必须恰好停在前一辆踏板车后面一米处。 这意味着我们可以从左到右计算最终位置，从而逐步强制执行约束。 

蛮力之所以有效，是因为它随着时间的推移不断地强制执行物理原理，但当我们想要直接的封闭式计算时，它就会失败。 观察到只有相对排序和单遍约束才重要，从而将问题简化为线性扫描。

 | --- | --- | --- | --- |
 | 步进模拟|$O(n \cdot T)$|$O(n)$| 太慢/不必要|
 | 单程贪婪传播 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 通过从起始位置减去速度来计算一秒后每个滑板车的原始位置。 这给出了忽略约束的基线。 
2. 按照从第一辆到最后一辆的顺序遍历滑板车。 第一个踏板车前面没有任何约束，因此它的位置保持计算结果。 
3. 对于每辆踏板车$i > 1$，将其暂定位置与滑板车的位置进行比较$i-1$。 如果落后至少一米，则保持不变。 
4.如果是踏板车$i$违反一米间隙，将其位置设置在滑板车后面正好一米处$i-1$。 这会在本地强制执行约束。 
5. 对所有踏板车继续此过程，以便每个位置仅取决于已经固定的先前位置。 

### 为什么它有效

 一秒钟后，每个踏板车要么自由移动，要么受到前面最近的较慢配置的限制。 由于约束仅取决于排序顺序中的直接前驱，因此单个从左到右的传递足以传播所有必要的调整。 一旦踏板车被修复，它就成为所有后续踏板车的新边界条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = [int(input()) for _ in range(n)]
    
    # naive move after 1 second: speed = index (1-based)
    pos = [a[i] - (i + 1) for i in range(n)]
    
    res = [0] * n
    res[0] = pos[0]
    
    for i in range(1, n):
        if pos[i] < res[i - 1] + 1:
            res[i] = res[i - 1] + 1
        else:
            res[i] = pos[i]
    
    print(*res)

if __name__ == "__main__":
    solve()
```该解决方案首先通过从每个位置减去速度来计算无约束运动。 然后，它使用向前扫描来纠正违规行为。 关键细节是约束是严格局部的：每辆踏板车只需要在该踏板车被修复后尊重正前方的那辆踏板车。 

一个微妙的问题是，修正可能会增加踏板车的位置，使其超出其初始值。 这是必要的，因为它是被前方拥堵推动的，而不是独立移动的。

 ## 边缘情况

 当滑板车开始时非常靠近时，简单的独立运动会将它们折叠到相同的位置。 相反，该算法会将后面的滑板车向前推以保持间距。 这确保了即使所有初始位置重合，最终结果也会形成具有最小间隙的严格递增序列，与系统的物理约束相匹配。
