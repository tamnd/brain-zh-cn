 ## 解决方案
 ## 问题理解

 将披萨切成相同的切片，每个切片都是由固定圆心角 θ 定义的扇形。 半径 r 与分布问题无关，因为所有切片都是全等的； 重要的只是将整个 360° 圆分成多少个相等的角块。 

从声明中，我们并没有直接给出切片的数量。 相反，我们被告知切片角度 θ，它隐式地将切片数量定义为 360 / θ，并且我们保证这对于每个测试用例来说都是一个整数。 

两个人想要分割披萨，以便两人都收到整数个整片，并且两人都得到相同数量的披萨。 由于切片无法细分，因此问题简化为检查切片总数是否为偶数。 

输入量很小，最多有 2400 个测试用例，每个用例都有恒定时间算术。 这强烈表明每个测试用例解决方案的任何 O(1) 就足够了，甚至简单的算术或模块化检查也完全在限制范围内。 任何涉及切片迭代或分解的事情都是不必要的。 

当 θ 很大时，例如 θ = 360，就会出现一种微妙的边缘情况。在这种情况下，只有一个切片，不可能将其平均分配给两个人。 另一个极端情况是 θ = 180，其中正好有两个切片并且可以进行公平的分割。 

## 方法

 思考这个问题的一个直接方法是首先计算切片数量 n = 360 / θ。 一旦我们有了n，问题就变成了n是否可以被分成两个相等的整数，也就是说n是否能被2整除。 

蛮力思维是模拟切披萨或明确计算切片数，但这已经是不必要的，因为切片数是通过简单的除法确定的。 任何围绕圆圈迭代或显式构建切片的方法仍然会在每种情况下以恒定的时间运行，但从概念上讲是矫枉过正的。 

关键的观察是，两个人之间的公平性相当于询问相同单元的总数是否为偶数。 除了保证切片全等之外，几何形状和半径没有任何作用； 只有切片计数的奇偶性很重要。 

因此，问题简化为检查 (360 / θ) % 2 == 0 是否，这可以重写为检查 360 / θ 是否为偶数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 直接切片计数| O(1) | O(1) | O(1) | O(1) | 已接受 |
 | 最佳奇偶校验| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取每个测试用例的 θ，并计算切片数量 n，即 360 除以 θ。 该问题保证了整除性，因此不会出现舍入问题。 
2. 检查n是否能被2整除。这决定了切片是否可以在不破坏任何切片的情况下分为相等的两个组。 
3. 如果n是偶数，则输出“YES”。 否则，输出“NO”。 

### 为什么它有效

 每个切片都是一个不可分割的资源单元。 任何有效的分布都只分配整个切片，因此问题简化为将 n 个相同的对象划分为两个大小相等的集合。 当且仅当 n 为偶数时，这样的划分才存在。 除了总计数之外，没有任何几何属性会影响可行性，因此奇偶校验既是必要的也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        r, theta = map(int, input().split())
        n = 360 // theta
        if n % 2 == 0:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```该解决方案独立读取每个测试用例并忽略 r，因为它不影响切片的数量。 整数除法 360 // θ 是安全的，因为该问题保证 θ 除以 360。奇偶校验直接对可行性条件进行编码。 

一个常见的实现错误是尝试对 360 / θ 进行浮点除法，然后检查奇偶校验，这可能会在其他问题中引入精度问题。 在这里，使用整数除法可以避免任何此类风险，并与切片的离散结构保持一致。

 ## 边缘情况

 当 θ = 360 时，披萨由单片组成。 该算法计算 n = 1，检测奇校验，并正确返回 NO。 

当 θ = 180 时，正好有两个切片。 计算得出 n = 2，奇偶校验为偶数，生成 YES，匹配唯一可能的公平分割。 

当 θ = 1 或 360 的任何小除数时，该算法仍然表现一致，因为它仅依赖于整数算术和奇偶校验，因此不会出现精度或缩放问题。
