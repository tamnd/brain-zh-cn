 ## 解决方案
 ## 问题理解

 我们将怪物放置在无限整数线上。 连续的怪物立即粘在一起，形成一个方块。 一次移动选择一个完整的块并将其向左或向右滑动，直到它与另一个块碰撞。 碰撞后，两个块合并。 

唯一重要的细胞是特殊细胞。 我们希望在执行任何动作序列后最大化这些特殊位置中包含怪物的数量。 

思考游戏的一个有用方法是按位置对怪物进行排序并从左到右标记它们。 怪物的顺序永远不会改变。 方块可以合并，但怪物永远不会相互交叉。 每一种最终配置都可以通过选择一些保持固定的怪物作为“锚点”来描述，而两个锚点之间的怪物则紧紧地靠在其中一个锚点上。 

输入最多包含$10^5$怪物，但仅限于$2000$特殊细胞。 这种不对称是问题的关键。 任何执行与以下成比例的功的解决方案$n^2$是无望的，而$O(nm)$动态规划是可行的，因为$10^5 \cdot 2000 = 2 \cdot 10^8$除非对转换进行了大量优化，否则仍然太大。 

一些边缘情况很容易被错误处理。 

假设怪物已经形成一个连续的块：```
monsters: 1 2 3
stars:    1 2 3
```答案是3。单独处理怪物会错误地允许不可能的重新排列，因为连续的怪物已经粘在一起了。 

另一个微妙的情况是：```
monsters: 10 20
stars:    1 2 3 4
```只有两个怪物存在，因此最终的配置不能覆盖超过两颗星星，即使星星形成很长的间隔。 

第三个陷阱是当一颗星星正好位于怪物的原始位置时。 这样的星星，不用动任何东西就可以算出来。 忘记这种转变就会失去有效的解决方案。 

## 方法

 暴力视图会尝试模拟块的合并和移动。 状态空间是巨大的，因为块可以多次移动并且可以以不同的顺序合并。 即使描述所有可到达的配置也是指数级的。 

第一个结构观察是怪物的顺序永远不会改变。 如果我们从左到右对怪物进行编号，则怪物$i$总是停留在怪物的左边$i+1$。 

第二个观察结果是，在所有移动之后，合并的每组连续怪物占据了连续的单元格段。 如果怪物$i$保持在原来的位置$a_i$，那么从左边附着到它的任何怪物都会占据以$a_i$，并且从右侧附着的任何怪物都会占据从$a_i$。 

这表明 DP 高于已排序的怪物。 

让$f_i$是使用第一个可获得的最佳答案$i$怪物。 

让$g_i$是使用第一个可获得的最佳答案$i$怪物 在该怪物的条件下$i$其本身仍保持在原来的位置。 

直接实施导致$O(n^2)$过渡。 关键的优化来自于这样一个事实：只有$m \le 2000$特殊细胞。 我们不是枚举所有先前的怪物，而是枚举特殊的单元格。 每一个有意义的转变都对应于扩大覆盖范围，直到某个特殊位置。 这减少了候选转换的数量$O(n)$到$O(m)$每个怪物。 接受的解决方案运行于$O(nm)$。

 ## 算法演练

 1.对怪物位置和特殊位置进行排序。 
2. 构建一个最多 200000 个坐标的前缀数组，以便`cnt(l,r)`返回区间内特殊单元格的数量$O(1)$。 
3. 计算`L[i]`和`R[i]`。`L[i]`是与怪物属于同一初始粘合块的最左边的怪物`i`。`R[i]`是与怪物属于同一初始粘合块的最右边的怪物`i`。 

这些数组可防止过渡非法分割已粘合的块。 
4. 维护两个DP阵列。`f[i]`= 使用第一个的最佳答案`i`怪物。`g[i]`= 使用第一个的最佳答案`i`怪物和饲养怪物`i`固定在位置`a[i]`。 
5. 初始化简单的过渡，其中怪物`i`只需贡献位于`a[i]`，如果这样的恒星存在的话。 
6. 计算`g[i]`。 

枚举每个特殊位置`b[j] ≤ a[i]`。 

如果我们想要一个结束于的打包段`a[i]`并开始于`b[j]`，那么它的长度是`a[i] - b[j] + 1`。 

该部分正好消耗`a[i] - b[j]`怪物左边的怪物`i`。 

先前的状态必须在包含第一个消耗的怪物的粘合块之前结束，因此从`f[L[i-len]-1]`。 
7. 处理完所有左扩展转换后，传播`g[i]`进入`f[i]`。 
8. 使用`g[i]`将覆盖范围向右延伸。 

枚举每个特殊位置`b[j] ≥ a[i]`。 

如果间隔`[a[i], b[j]]`被充满，然后消耗`b[j]-a[i]`额外的怪物。 

更新右边到达的整个胶合块对应的DP状态，即`R[i+len]`。 
9. 答案是`f[n]`。 

### 为什么它有效

 每个有效的最终配置都可以围绕留在其原始位置的怪物进行分解。 在两个这样的固定怪物之间，所有中间怪物必须紧密地靠在一侧。 民主党各州准确地描述了这些情况。`g[i]`代表最右边固定怪物的配置`i`。 向左扩展重建每个可能的打包段结束于`a[i]`。 右扩展重建每个可能的打包段，从`a[i]`。 这`L`和`R`修正强制执行这样的规则：最初粘合的块永远不会被分解。 

由于每个可到达的排列都有一个独特的分解为这些打包的片段，并且每次转换都精确地计算一个片段所覆盖的星星，因此 DP 探索所有合法的配置，并且从不计算非法的配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXX = 200000

def solve():
    n, m = map(int, input().split())

    a = sorted(map(int, input().split()))
    b = sorted(map(int, input().split()))

    pref = [0] * (MAXX + 1)
    for x in b:
        pref[x] += 1
    for i in range(1, MAXX + 1):
        pref[i] += pref[i - 1]

    def count_range(l, r):
        if l > r:
            return 0
        return pref[r] - (pref[l - 1] if l > 1 else 0)

    a = [0] + a

    L = [0] * (n + 1)
    R = [0] * (n + 1)

    for i in range(1, n + 1):
        if i == 1 or a[i] != a[i - 1] + 1:
            L[i] = i
        else:
            L[i] = L[i - 1]

    for i in range(n, 0, -1):
        if i == n or a[i] != a[i + 1] - 1:
            R[i] = i
        else:
            R[i] = R[i + 1]

    f = [0] * (n + 1)
    g = [0] * (n + 1)

    for i in range(1, n + 1):
        star_here = count_range(a[i], a[i])

        f[i] = max(f[i], f[i - 1] + star_here)
        g[i] = max(g[i], f[i - 1] + star_here)

        for x in b:
            if x > a[i]:
                break

            length = a[i] - x
            if length < i:
                left_index = L[i - length] - 1
                g[i] = max(
                    g[i],
                    f[left_index] + count_range(x, a[i])
                )

        f[i] = max(f[i], g[i])

        for x in reversed(b):
            if x < a[i]:
                break

            length = x - a[i]
            if length <= n - i:
                pos = R[i + length]
                f[pos] = max(
                    f[pos],
                    g[i] + count_range(a[i] + 1, x)
                )

    print(f[n])

solve()
```前缀和数组将间隔星计数变成$O(1)$手术。 如果没有它，每次转换都需要再次扫描特殊单元。`L`和`R`是实施中最微妙的部分。 如果怪物一开始占据连续的位置，它们就已经形成了一个粘合块。 任何进入此类块的转换都必须消耗整个块。 使用`L[i-len]-1`和`R[i+len]`正是如此。 

特殊单元上的循环是使解决方案通过的优化。 相反，枚举怪物会导致二次行为。

 和$n \le 10^5$和$m \le 2000$，复杂度大致为$2 \times 10^8$最坏理论界限中的简单操作，但转换被大量修剪，这是用于原始问题的公认解决方案。

 ## 边缘情况

 考虑：```
3 3
1 2 3
1 2 3
```所有怪物都已经属于一个粘合块。`L=[1,1,1]`和`R=[3,3,3]`。 任何进入该块的转换都会自动消耗整个块。 DP正确返回`3`而不是非法地分割区块。 

考虑：```
1 1
5
10
```怪物只有一只。 无法形成包含位置 10 的区间，因为每个被覆盖的单元格都必须包含怪物。 所有转变都未能获得覆盖，答案仍然存在`0`。 

考虑：```
2 4
10 20
9 10 11 12
```粗心的解决方案可能会计算所有四颗星，因为它们形成的间隔很短。 DP 明确跟踪怪物的使用情况。 覆盖四个连续的单元格需要四个怪物，但只有两个存在，所以答案正确地限制为`2`。
