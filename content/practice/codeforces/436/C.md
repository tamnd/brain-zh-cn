 ## 解决方案
 ## 问题理解

 我们被给予`k`游戏级别。 每个级别都是一个`n × m`字符网格。 电平可以通过两种不同的方式传输。 

第一个选项是从头开始发送整个网格。 由于每个信元都必须被传输，因此成本为`n * m`。 

第二种选择是仅发送相对于已传输的某个级别的差异。 如果两个级别不同`d`细胞，成本变为`d * w`。 

传输顺序不固定。 我们可以选择首先发送任何级别，并且每个后续级别可以从头开始构建或从先前发送的级别重建。 

输出需要两件事。 首先，尽可能降低总传输成本。 第二，实际的传输计划。 对于每个级别，我们必须指定它是从头开始发送的（`parent = 0`）或者它是根据先前传输的级别重建的。 

约束揭示了预期的方向。 每个级别最多包含`10 × 10 = 100`细胞。 最多可以有`1000`水平。 计算两个级别之间的差异最多需要 100 个字符比较，因此所有成对距离的计算时间约为`1000² × 100 = 10^8`最坏情况下的操作。 虽然很大，但在优化的 C++ 中仍然可以管理，并且可以接受这个问题。 一旦知道了成对成本，我们就需要一个仅针对 1000 个顶点的图算法。 

微妙的部分是始终允许从头开始传输级别。 一个常见的错误是认为每个级别都必须连接到另一个级别。 考虑：```
1 1 2 100
A
B
```改造成本为`100`，而从头开始发送关卡仅需花费`1`。 最佳答案独立发送两个​​级别的总成本`2`。 

另一个容易犯的错误是忘记了只有当改造比重建更便宜时才有用。 认为：```
1 2 2 5
AA
AB
```一个细胞中的水平不同，因此转化成本为`1 * 5 = 5`。 仅从头开始发送费用`2`。 最优解完全忽略变换边缘。 

第三个陷阱涉及传输顺序。 如果级别 3 是从级别 1 重建的，则级别 1 必须出现在输出中的较早位置。 任何有效的解决方案都必须产生与所选依赖项一致的顺序。 

## 方法

 蛮力观点是直接考虑传输顺序和父选择。 对于每个级别，我们都可以决定它是从头开始发送还是从另一个级别派生，同时也尊重父母在传输序列中较早出现的要求。 

这显然是正确的，因为每个有效的传输策略都可以通过这样的决策来描述。 不幸的是，可能性的数量呈指数级增长`k`，即使是几十个关卡也是完全不可行的。 

关键的观察是这个问题实际上是一个图问题。 

为每一层创建一个顶点。 还创建一个额外的虚拟顶点，表示“从头开始构建”。 让这个顶点编号`0`。 

连杆`i`直接到顶点`0`表示发射电平`i`从头开始。 这种优势的成本总是`n * m`。 

对于每对水平`i`和`j`，计算有多少个细胞不同。 从其他成本中重建一个`difference(i, j) * w`。 

这成为之间的边的权重`i`和`j`。 

现在考虑任何有效的传输策略。 每个级别要么从头开始，要么来自前一个级别。 这意味着每个级别都会选择一个父级。 生成的结构是一棵以顶点为根的树`0`。 

相反，任何以顶点为根的树`0`描述了有效的传输策略。 直接连接到的级别`0`是从头开始发送的。 连接到另一个级别的级别是从它重建的。 

总传输成本正是该树中边权重的总和。 

问题转化为寻找连接所有顶点的最小成本树，这正是最小生成树。 

一旦找到 MST，我们就将其定根于顶点`0`并以 DFS 或 BFS 顺序输出每个级别的父级。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳 (MST) | O(k²·n·m + k² log k) | O(k²·n·m + k² log k) | O(k²) | 已接受 |

 ## 算法演练

 1. 阅读全部`k`级别并存储它们的网格。 
2. 创建带有顶点的图`0...k`，其中顶点`0`是虚拟的“从头开始构建”节点。 
3. 每个级别`i`，添加一条边`(0, i)`有重量`n * m`。 

该边沿代表传输电平`i`直接地。 
4. 对于每对水平`(i, j)`，计算有多少个细胞不同。 

将此计数乘以`w`从而得到改造成本。 
5. 在之间添加一条边`i`和`j`与那个成本。 
6. 在所有边上运行 Kruskal 算法。 

MST 恰恰选择了最便宜的直接传输和变换组合。 
7. 建立MST 的邻接表。 
8. 在顶点处建立 MST 根`0`并执行DFS或BFS。 
9. 每次我们访问一个关卡顶点时：

 - 如果它的父级是`0`， 输出`(level, 0)`。 
- 否则输出`(level, parent)`。 
10. 将所有 MST 边的权重相加并打印总成本。 

### 为什么它有效

 每个有效的传输计划都为每个级别提供了一个确切的源，可以是虚拟根，也可以是另一级别。 该结构是一个跨越所有顶点的连通无环图，因此生成树以顶点为根`0`。 

传输计划的成本等于所选边权重的总和。 

相反，每棵生成树都以顶点为根`0`定义有效的传输计划。 边到顶点`0`意味着从头开始发送一个级别，而两个级别之间的边缘意味着传输它们的差异。 

由于该图的有效传输计划与生成树之间存在一一对应关系，因此最小化传输成本正是最小生成树问题。 Kruskal算法返回总权重最小的生成树，因此生成的传输计划是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def find(x, parent):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

def union(a, b, parent, size):
    a = find(a, parent)
    b = find(b, parent)

    if a == b:
        return False

    if size[a] < size[b]:
        a, b = b, a

    parent[b] = a
    size[a] += size[b]
    return True

def main():
    n, m, k, w = map(int, input().split())

    levels = []
    for _ in range(k):
        grid = [input().strip() for _ in range(n)]
        levels.append(grid)

    edges = []

    build_cost = n * m

    for i in range(k):
        edges.append((build_cost, 0, i + 1))

    for i in range(k):
        for j in range(i + 1, k):
            diff = 0

            a = levels[i]
            b = levels[j]

            for r in range(n):
                row_a = a[r]
                row_b = b[r]
                for c in range(m):
                    if row_a[c] != row_b[c]:
                        diff += 1

            edges.append((diff * w, i + 1, j + 1))

    edges.sort()

    parent = list(range(k + 1))
    size = [1] * (k + 1)

    mst_cost = 0
    mst_adj = [[] for _ in range(k + 1)]

    used = 0

    for cost, u, v in edges:
        if union(u, v, parent, size):
            mst_cost += cost
            mst_adj[u].append(v)
            mst_adj[v].append(u)
            used += 1

            if used == k:
                break

    result = []
    stack = [(0, -1)]

    while stack:
        node, par = stack.pop()

        for nxt in mst_adj[node]:
            if nxt == par:
                continue

            result.append((nxt, 0 if node == 0 else node))
            stack.append((nxt, node))

    print(mst_cost)
    for x, y in result:
        print(x, y)

if __name__ == "__main__":
    main()
```第一部分读取并存储每个级别。 由于每个网格最多包含 100 个单元格，因此比较两个级别的成本较低。 

图的构造准确地反映了传输规则。 来自虚拟根的边代表从头开始重建。 级别之间的边缘代表传输差异。 

克鲁斯卡尔算法是一个自然的选择，因为图是稠密的。 大致有`k² / 2`边，Kruskal 只需要对它们进行一次排序，然后执行几乎恒定时间的 DSU 操作。 

构造完MST后，图被转换为邻接表。 以顶点为根的 DFS`0`确定输出格式所需的父关系。 因为一棵树从根到每个顶点只有一条路径，所以选择的父树是明确的。 

一个微妙的细节是 MST 边缘是无向的。 DFS 方向决定哪个端点成为传输计划中的父端点。 由于每个顶点都可以从根到达，因此生成的排序始终满足父节点在其子节点之前传输的要求。

 ## 边缘情况

 考虑：```
1 1 2 100
A
B
```转换成本为 100，重建成本为 1。图包含边`(0,1)=1`,`(0,2)=1`,`(1,2)=100`。 Kruskal 选择两个根边。 输出独立地发送两个级别，总成本为 2。任何总是尝试将级别连接在一起的解决方案都是错误的。 

考虑：```
1 1 3 1
A
A
A
```所有成对变换成本均为 0。MST 包含一个成本为 1 的根边和两个级别之间的零成本边。 总成本变为 1。这证实了除非必要，否则永远不应该重建相同的级别。 

考虑：```
1 2 2 5
AA
AB
```一个细胞中的水平不同。 转换成本为 5，重建成本为 2。该图包含边`(0,1)=2`,`(0,2)=2`,`(1,2)=5`。 MST 选择两个根边，成本为 4。诸如“当只有少数单元格不同时总是进行变换”之类的贪婪规则将失败，因为乘数`w`彻底改变经济。 

最后，考虑一棵树，其中级别 3 依赖于级别 2，级别 2 依赖于级别 1。MST 边是无向的，但来自虚拟根的 DFS 可以正确定向它们。 在遍历中，父母总是出现在孩子之前，产生有效的传输顺序。
