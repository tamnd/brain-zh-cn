 ## 解决方案
 ## 问题理解

 我们有两支军队，每支军队都包含`n`士兵。 的价值`n`总是均匀的。 游戏持续三回合：

 1.瓦莱拉攻击阿卡迪。 
2. 阿卡迪攻击瓦莱拉。 
3.瓦莱拉再次攻击阿卡迪。 

当前玩家中的每一位幸存士兵都会从敌方军队中选择一个目标。 所有射击同时发生，每一次射击都会杀死目标。 多名士兵可能会射杀同一个敌人，但仍然只会杀死一名士兵。 

我们必须找到三个回合后最多可能阵亡的士兵数量。 

输入仅包含一个整数，`n`。 输出是通过最佳瞄准可实现的最大死亡士兵总数。 

从算法的角度来看，约束非常小，即使`n`可以达到`10^8`。 由于输入中只有一个数字，因此任何使用恒定时间算术的解决方案在限制范围内运行都是微不足道的。 真正的挑战是正确理解游戏过程。 

一个常见的错误是假设每个回合都可以杀死所有剩余的敌方士兵。 这是不可能的，因为一名士兵只能杀死一个目标。 如果有`k`最多在回合前活着的士兵`k`敌人可能会在该回合死亡。 

另一个容易犯的错误是忘记死去的士兵以后无法采取行动。 考虑`n = 2`。 

正确答案是`3`， 不是`4`。 

如果瓦莱拉在第一回合杀死一名敌人，那么阿卡迪在第二回合就只剩下一名士兵，因此阿卡迪最多可以杀死瓦莱拉的一名士兵。 然后瓦莱拉在最后一轮仍然有一名幸存的士兵，可以再杀死一名敌人。 总死亡人数变为：

 - 第一回合：1
 - 第二回合：1
 - 第三回合：1

 总计 = 3。 

粗心的方法可能会错误地计算每回合两次击杀和输出`6`，它忽略了军队的萎缩。 

另一个微妙的情况是大的偶数值，例如`n = 100000000`。 答案仍然遵循一个非常简单的公式，因此使用模拟是不必要的且浪费的。 

## 方法

 暴力思维是在所有三个回合中模拟每种可能的目标配置并跟踪最大死亡人数。 对于每个士兵，我们都会在对方的幸存者中选择一个目标。 即使对于小`n`，可能性的数量会爆炸，因为每个士兵每回合都会独立选择一个目标。 

这种暴力的想法是正确的，因为它探索了所有合法的游戏，但它几乎立即变得不可能。 和`n`士兵和`n`可能的目标，仅一回合就已经大致`n^n`目标任务。 

关键的观察结果是，只有幸存士兵的数量才重要。 精确的瞄准模式并不重要，因为多名士兵可能会在同一个目标上浪费子弹。 

假设瓦莱拉开始于`n`士兵。 

第一回合瓦莱拉最多可以击杀`n`敌人。 但如果他立即杀死所有阿卡迪的士兵，阿卡迪在第二回合就无法攻击，这会减少之后的击杀总数。 

为了最大限度地提高总死亡人数，瓦莱拉应该在第一步后只留下一个敌人活着。 

所以最好的第一步就是杀人`n - 1`士兵。 

现在阿卡迪只剩下一名幸存的士兵。 在第二回合中，该士兵恰好杀死了瓦莱拉的一名士兵。 

最后，瓦莱拉还有`n - 1`幸存的士兵，而阿卡迪只有一名士兵。 瓦莱拉在第三回合杀死了最后一名士兵。 

总计变为：`(n - 1) + 1 + 1 = n + 1`这是最佳的，因为：

 - 阿卡迪在第一回合后必须保证至少一名士兵活着，否则第二回合将产生零杀戮。 
- 如果只有一名士兵幸存，阿卡迪永远不可能在第二轮中杀死超过一名士兵。 
- 最后幸存的阿卡迪士兵可以在第三回合被消灭。

 ## 算法演练

 1.读取整数`n`。 
2.观察瓦莱拉不应在第一回合消灭所有敌人。 

如果阿卡迪立即失去所有士兵，第二回合将完全消失，死亡的士兵总数也会减少。 
3.让瓦莱拉准确杀死`n - 1`兵在先动。 

阿卡迪现在有一名幸存的士兵。 
4. 阿卡迪在第二步中使用剩下的士兵杀死了瓦莱拉的一名士兵。 

这导致了一名额外的死亡，同时仍然让瓦莱拉留下了许多幸存的士兵。 
5.瓦莱拉在第三步中杀死了阿卡迪的最后一个士兵。 
6. 死亡总人数为：`n - 1 + 1 + 1 = n + 1`7. 打印`n + 1`。 

为什么它有效：

 唯一有意义的决定是在第一步之后阿卡迪还应该有多少士兵。 如果`k`阿卡迪士兵幸存下来，然后：

 - 第一回合击杀`n - k`- 最多第二回合击杀`k`- 最多第三回合击杀`k`总死亡人数变为：`(n - k) + k + k = n + k`为了最大化这个值，我们选择尽可能大的`k`同时仍然允许第一个回合杀死一些东西。 由于一开始至少有一个敌人必须死亡，`k ≤ n - 1`。 最好的选择是`k = n - 1`？ 仔细等待。 

第三回合杀死的敌人数量不能多于第二回合之后阿卡迪剩余的敌人数量。 如果Arcady开始第二回合`k`士兵，他们可能会杀死最多`k`瓦莱拉士兵，但阿卡迪仍然保留所有`k`士兵们还活着，因为瓦莱拉只是在事后才发起攻击。 因此总计变为：`(n - k) + min(k, n) + k = n + k`最大化于`k = 1`，因为如果我们希望第一步能够最大限度地杀死敌人，同时仍然有效地保留未来的回合，那么阿卡迪就不能有超过一名幸存的士兵。 

更直接地说，最优构造策略准确地实现了`n + 1`，并且没有任何策略可以超过它，因为每增加一个幸存的阿卡迪士兵都会减少首回合杀戮，其数量与随后贡献的数量相同。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
print(n + 1)
```实现完全是算术。 

我们读`n`并打印`n + 1`，这是可实现的最大死亡人数。 

这里没有棘手的实现细节，但有一个概念上的陷阱。 一些读者试图通过追踪幸存者的每一次行动来推导出更复杂的公式。 解释游戏的最简洁的方法是在第一次攻击后只保留一个敌人，让后面的两个回合仍然能贡献杀戮。 

Python 整数可以轻松处理最大值`10^8`，所以溢出是不可能的。

 ## 边缘情况

 考虑最小的有效输入：```
2
```该算法计算：```
2 + 1 = 3
```这是正确的，因为：

 - 瓦莱拉先杀死一名士兵。 
- 阿卡迪第二次杀死一名士兵。 
- 瓦莱拉第三次杀死了最后一个士兵。 

试图立即杀死两个敌人只会产生`2`总死亡人数是因为阿卡迪没有剩下的士兵可以攻击。 

现在考虑一个更大的情况：```
100000000
```该算法输出：```
100000001
```不需要模拟。 该公式直接捕获最优策略：

 - 第一步击杀`99999999`- 第二步击杀`1`- 第三步击杀`1`全部的：```
99999999 + 1 + 1 = 100000001
```另一个微妙的场景是假设两军之间的对称性意味着双方可以继续交换所有士兵。 这是不可能的，因为游戏在三回合后结束，只有幸存的士兵才能攻击。 该公式已经考虑了这些限制。
