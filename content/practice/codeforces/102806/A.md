 ## 解决方案
 ## 问题理解

 我们得到一个整数数组。 对于每个元素，我们可以保留其当前值或更改其符号。 任务是确定是否存在某种符号选择可以使结果数组不减。 如果存在这样的构造，我们必须输出一个有效的结果数组。 

输入大小达到 100000 个元素，因此尝试所有可能的符号选择是不可能的。 每个元素都有两种可能的状态，这将创建 2^n 个可能的数组。 即使检查全部，也已经远远超出了 2 秒的限制。 我们需要一种方法来处理每个元素恒定的次数。 

这些值的绝对值可以大到 100000，但它们的大小不会在 Python 中产生溢出问题。 主要的困难不是算术，而是找到有效的选择序列。 错误的贪婪规则可能会失败，因为现在选择更大的值可能会使未来的元素无法放置。 

第一个边缘情况是单个元素。 例如：```
Input:
1
-5

Output:
Yes
-5
```任何单元素数组都已经是非减的。 假设至少存在一个相邻比较的解决方案可能会错误地拒绝它。 

另一个重要的情况是当只有否定选择对某些元素有效时。 考虑：```
Input:
3
5 3 1

Output:
Yes
-5 -3 -1
```正版本是递减的，但翻转所有符号给出了有效的递增序列。 只尝试保留原始标志的解决方案将会失败。 

最后一个棘手的情况是负值不够，我们必须使用正值：```
Input:
2
1 2

Output:
Yes
-1 2
```贪婪地选择负值而不检查它们是否仍然有效会产生`-1 -2`，正在减少。 

## 方法

 直接的暴力方法将枚举所有可能的符号分配。 对于每个分配，我们可以构建结果数组并检查每个相邻对是否满足非递减条件。 此方法是正确的，因为它检查每个可能的答案，但执行 2^n 次检查。 对于 n = 100000，这根本不可行。 

有用的观察是每个元素恰好有两个可能的值：`-abs(a[i])`和`abs(a[i])`。 这两者中，负值始终是较小的那个。 当从左到右处理数组时，我们只需要知道之前选择的值即可。 当前位置的最佳选择是不破坏顺序的最小值。 

为什么选择尽可能小的有效值有用？ 当前值越小，对所有后续元素的限制就越少。 如果负值可以放在前一个值之后，那么使用它总是安全的。 如果不能，则正值是唯一剩下的选项。 如果正值小于前一个值，则不存在解。 

蛮力之所以有效，是因为它探索了每一种可能的符号分配，但会失败，因为搜索空间呈指数增长。 最小的有效电流值留下最大的自由度，这一观察结果将问题简化为单个线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 首先将先前选择的值设置为负无穷大。 第一个元素没有从左侧开始的限制，因此每个有效选择都是可能的。 
2. 对于每个数组元素，考虑其两个可能的值：负绝对值和正绝对值。 负版本始终是较小的候选者。 
3. 如果否定候选值至少是先前选择的值，则选择它。 这是首选选择，因为它使当前值尽可能小。 
4. 否则，尝试正候选。 如果它至少是之前选择的值，请选择它。 
5. 如果两个候选都不起作用，则该数组无法转换为非递减数组，因此输出`No`。 
6. 处理完所有元素成功后，输出`Yes`和构建的序列。 

为什么有效：在处理每个位置后，算法会保留答案的有效前缀。 在当前位置的所有有效选择中，它存储可能的最小值。 任何可能遵循较大选择的未来元素也可能遵循这个较小的选择，因此贪婪决策永远不会消除可能的解决方案。 如果算法到达两个选择都太小的元素，则在该元素之前结束的每个可能的前缀都具有至少与存储的先前值一样大的值，因此无法继续构造。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    ans = []
    prev = -10**30

    for x in a:
        x = abs(x)

        if -x >= prev:
            cur = -x
        elif x >= prev:
            cur = x
        else:
            print("No")
            return

        ans.append(cur)
        prev = cur

    print("Yes")
    print(*ans)

if __name__ == "__main__":
    solve()
```该代码仅保留先前选择的值，因为一旦当前前缀有效，未来就不依赖于先前的元素。 变量`prev`表示构造的非递减前缀中的最后一个值。 

候选人产生于`abs(x)`而不是原始值，因为该操作允许任一符号，因此每个元素始终可以变为其大小或负大小。 检查的顺序很重要：首先测试否定候选者，因为它是较小的选项，并且为未来的职位提供了最大的灵活性。 

初始值为`prev`选择远低于任何可能的数组值。 由于输入幅度最多为 100000，`-10**30`对于这个问题，安全地表现为负无穷。

 ## 边缘情况

 对于单个元素，循环运行一次并始终接受两个可能的符号之一。 该算法从不尝试与不存在的先前元素进行比较，因此情况`n = 1`自然处理。 

对于绝对值已经递减的数组，例如：```
Input:
3
5 3 1
```该算法选择：```
-5 -3 -1
```每个下一个值都大于前一个值，因此负选择就足够了。 

对于否定选择失败的情况：```
Input:
2
1 2
```第一个元素变成`-1`。 在第二个元素处，`-2`小于`-1`，所以不能使用。 该算法尝试`2`，有效，给出：```
-1 2
```对于不可能的情况：```
Input:
3
1 0 -1
```第一个元素变成`-1`。 第二个元素只能变成`0`，所以前缀变成`[-1, 0]`。 最后一个元素只能变成`-1`或者`1`;`-1`太小并且`1`是有效的，给予`[-1, 0, 1]`。 贪心构造在这里成功了，表明许多看起来可疑的情况仍然是可能的。 

仅当某个位置的两个可用值都低于先前选择的值时，该算法才会失败。 此时，存储的前缀已经是最灵活的前缀，因此没有其他符号分配可以解决该数组。
