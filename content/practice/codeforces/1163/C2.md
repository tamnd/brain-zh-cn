 ## 解决方案
 ## 问题理解

 我们在平面上得到一组点，每个点代表一根电线杆。 每对极点都定义了一条无限直线，该线被视为“线”。 如果三个或更多的杆位于同一条线上，它们不会创建多条电线，它们仍然只为该方向贡献一根独特的电线。 

任务是计算这些不同电线有多少对相交。 如果两条线的对应线在平面上相交，则两条线相交，除非它们平行或相同，否则总是如此。 由于相同的线是由共线点集定义的，因此我们必须小心不要过多计算这些点。 

核心难点在于导线的数量不仅仅是点对的数量。 许多三元组（或更大的集合）折叠成一条线，这消除了许多潜在的线并显着改变了交叉结构。 

n 最大为 1000 的约束表明 O(n^2) 或 O(n^2 log n) 预处理就可以了。 任何立方体或更高的物体都太慢。 点对的数量约为 5×10^5，因此通过排序或散列对每对或每点进行推理是可以接受的。 

当将每对点视为单独的线时，会出现一个天真的错误。 例如，如果三个点共线，例如 (0,0)、(1,1)、(2,2)，则简单的方法会创建三根线，但正确的模型只有一根线。 这会导致交叉点计数过多，因为这些重复的“平行副本”人为地夸大了线组。 

另一个微妙的问题是处理线条表示。 使用斜率直接导致浮点精度误差。 例如，像 1/3 和 2/6 这样的斜率必须被视为相同，但浮动表示可能略有不同。 

## 方法

 暴力方法将首先构造由点对确定的所有线。 这给出了 O(n^2) 候选线。 然后，我们通过存储规范化表示（例如归一化斜率和截距或简化的方向向量加上偏移量）来对它们进行重复数据删除。 构建完一组独特的电线后，我​​们可以检查所有电线对以查看它们是否相交。 这将花费 O(m^2)，其中 m 是唯一行的数量，在最坏的情况下仍然是 O(n^2)。 这会导致 O(n^4) 的行为，这远远超出了限制。 

关键的观察是我们实际上不需要显式测试线之间的交点。 两条不同的非平行线总是恰好相交一次。 因此，交叉线对的数量等于总线对数减去平行线对数。 这将问题简化为计算有多少根电线共享同一方向。 

因此，任务变成：计算所有唯一的线，按方向对它们进行分组，并减去每组内的线对数量。 对的总数为 C(m,2)，每个方向组减去 C(k,2) 即可得出答案。 

主要的技术困难是以分离方向（用于平行分组）和位置（以确保非平行线之间的唯一性）的方式表示线。 每条线都可以使用归一化方向向量和从其中一个点计算的偏移键来表示。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^4) | O(n^4) | O(n^2) | O(n^2) | 太慢了 |
 | 最佳 | O(n^2 log n) | O(n^2 log n) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 我们为由任意一对点确定的每条不同的线构建规范表示。

1. 迭代所有 i < j 的点对 (i, j) 并计算穿过它们的直线。 这会捕获所有可能的候选线，并确保不会遗漏任何线。 
2. 将直线的方向表示为简化向量 (dx, dy)，并通过 gcd 和符号进行归一化。 这会将所有平行线分组在一起，因为平行线具有成比例的方向矢量。 
3. 构造一个完整的线路键，用于唯一标识特定线路，而不仅仅是其方向。 一种稳定的方法是将归一化方向与从一个端点计算的有符号偏移量结合起来，确保区分不同的平行线。 
4. 将每个线路键插入一组以获得所有唯一的线路。 每个唯一的键恰好对应于问题定义中的一根线。 
5. 构建一个从方向向量到有多少条独特的线共享该方向的地图。 
6. 将总线对计算为 m(m−1)/2，其中 m 是唯一线的数量。 
7. 对于大小为 k 的每个方向组，减去 k(k−1)/2，因为这些方向组是平行且不相交的。 

最终答案是所有对的数量减去不相交平行对的总和。 

### 为什么它有效

 平面中两条不同的直线相交当且仅当它们不平行。 该结构确保每条线都被唯一地表示一次，即使有许多点对定义它。 按归一化方向分组将线集划分为平行线的等价类。 对所有线对进行计数并删除类内线对，仅留下相交线对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from math import gcd
from collections import defaultdict

def norm(dx, dy):
    if dx == 0:
        return (0, 1)
    if dy == 0:
        return (1, 0)
    g = gcd(dx, dy)
    dx //= g
    dy //= g
    if dx < 0:
        dx = -dx
        dy = -dy
    elif dx == 0 and dy < 0:
        dy = -dy
    return (dx, dy)

def line_key(x1, y1, x2, y2):
    dx = x2 - x1
    dy = y2 - y1
    dxn, dyn = norm(dx, dy)

    # compute a perpendicular-based offset (stable line id)
    # line: dx*(y - y1) - dy*(x - x1) = 0
    # use c = dx*y1 - dy*x1
    c = dxn * y1 - dyn * x1
    return (dxn, dyn, c)

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    lines = set()
    dir_count = defaultdict(int)

    for i in range(n):
        x1, y1 = pts[i]
        for j in range(i + 1, n):
            x2, y2 = pts[j]
            key = line_key(x1, y1, x2, y2)
            if key not in lines:
                lines.add(key)
                dx = key[0]
                dy = key[1]
                dir_count[(dx, dy)] += 1

    m = len(lines)
    total = m * (m - 1) // 2

    bad = 0
    for k in dir_count.values():
        bad += k * (k - 1) // 2

    print(total - bad)

if __name__ == "__main__":
    solve()
```该代码枚举每对点并构建它们定义的线的规范表示。 方向被标准化，以便所有平行线映射到相同的 (dx, dy)。 偏移项 c 确保不同的平行线不会合并。 

一个微妙的点是方向归一化必须一致地固定符号； 否则，同一条线可能会以相反的方向向量出现两次。 所选规则尽可能强制 dx 为正值。 

套装`lines`确保每条几何线被计数一次，即使有许多点对生成它。 字典`dir_count`然后聚合每个方向存在多少条独特的线，这正是减去非相交线对所需的。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math
    from collections import defaultdict

    def solve():
        n = int(input())
        pts = [tuple(map(int, input().split())) for _ in range(n)]

        def gcd(a, b):
            while b:
                a, b = b, a % b
            return abs(a)

        def norm(dx, dy):
            if dx == 0:
                return (0, 1)
            if dy == 0:
                return (1, 0)
            g = gcd(dx, dy)
            dx //= g
            dy //= g
            if dx < 0:
                dx = -dx
                dy = -dy
            return (dx, dy)

        def key(x1, y1, x2, y2):
            dx, dy = x2 - x1, y2 - y1
            dx, dy = norm(dx, dy)
            c = dx * y1 - dy * x1
            return (dx, dy, c)

        lines = set()
        dirc = defaultdict(int)

        for i in range(n):
            for j in range(i + 1, n):
                k = key(*pts[i], *pts[j])

        total = m * (m - 1) // 2
        bad = sum(v * (v - 1) // 2 for v in dirc.values())
        print(total - bad)

    solve()
    return sys.stdout.getvalue().strip()

 ## 边缘情况

 一个关键的边缘情况是当许多点位于一条线上时。 对于像 (0,0)、(1,1)、(2,2)、(3,3) 这样的输入，所有 O(n^2) 对都对应于相同的几何线。 该算法将所有对折叠成一个键，从而产生大小为 1 的单向组。在计数期间，不会发生并行减法，并且由于只有一根导线，因此答案正确地变为零。 

另一种边缘情况是存在多条不同的平行线，例如 y = 0、y = 1、y = 2，每条平行线由多个点定义。 在这里，方向分组将它们合并为一类，并且减法项删除它们之间的所有交集。 每个组在内部不贡献交集，但跨组对仍保持正确计数，因为仅排除平行关系。
