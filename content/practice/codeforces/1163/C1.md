 ## 解决方案
 ## 问题理解

 我们得到了二维平面上的一组点。 每个点代表一根电线杆，每对电线杆定义一条无限直线，我们将其解释为“电线”。 然而，位于同一几何线上的多个极点仍然对应于单根导线，而不是多个副本。 因此，实际上，由至少两个极点确定的每条不同的线都是一根电线。 

任务是计算有多少对无序的电线在平面上的某个位置相交。 

当两条线对应的线不平行并且不是同一条线时，两条线之间就会发生交叉。 由于导线是无限的线，任何两条不平行的不同线恰好相交一次，因此问题简化为计算具有不同斜率的不同线对。 

输入的大小非常小，最多 50 个点。 这立即允许任何考虑所有点对或所有三元组点的解决方案。 

一个微妙但重要的问题是重复行。 如果三个或更多点位于同一条直线上，则所有这些点对都会生成相同的线，并且它们必须仅计数一次。 将每对点视为一条不同的线的简单方法会严重计算交叉点。 

当许多点共线时会出现另一种边缘情况。 例如，如果所有点都位于一条线上，则恰好只有一根线，并且答案必须为零。 简单的成对交叉计数会错误地产生正数。 

## 方法

 一个直接的想法是将每对点视为定义一条线，然后检查所有这些线对是否相交。 由于最多有 50 个点，因此最多有 1225 对点，因此候选线数最多为 1225 对。 检查所有这些线对大约需要 10^6 次操作，这仍然是可行的，但真正的困难是识别两个点对何时定义相同的几何线。 如果没有仔细的标准化，重复就会破坏正确性。 

一个更清晰的观点是首先构建一组独特的线条。 对于每一对点，我们计算它们定义的线的规范表示并将其存储在一个集合中。 这给了我们所有不同的电线。 

一旦我们有了所有独特的线，我们就需要计算它们相交的对数。 两条线只有平行时才不会相交。 因此，我们按斜率方向对线进行分组，并减去每组内线对的数量。 

这是有效的，因为相交计数相当于计算所有线对减去平行线对。 在每个斜坡组内，任何两条线都不会相交。 

关键的见解是我们永远不需要几何交集计算。 我们只需要斜率等价类和线的唯一性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解线对 | O(M²) 其中 M ≤ 1225 | O(M)| 已接受但混乱|
 | 规范线+斜率分组| O(n² log n) | O(n² log n) | O(n²) | 已接受 |

 ## 算法演练

1. 迭代每对点并构造穿过它们的线。 以标准化形式表示每条线，以便相同的几何线映射到相同的键。 这确保共线三元组不会产生重复项。 
2. 将每个唯一行存储在哈希集或字典中。 每个条目代表最终图中的一根线。 
3. 对于每条存储的线，计算其归一化的方向向量 (dx, dy) 以避免符号模糊，例如通过除以 gcd 并固定符号。 
4. 按斜率键对线进行分组。 每组代表所有彼此平行的电线。 
5. 设不同线的总数为 M。无序线对的数量为 M(M−1)/2。 
6. 对于每个大小为 k 的斜率组，减去 k(k−1)/2，因为这些对是平行且从不相交的。 
7. 剩余的值是相交对的数量。 

### 为什么它有效

 每对不同的非平行无限线恰好相交一次。 因此，唯一不应该计算的对是平行线。 通过首先折叠相同的几何线，我们确保每根线都是独一无二的。 然后按斜率分组干净地划分所有不相交的情况，仅留下有效的相交。 

正确性依赖于斜率等价是平面内平行度的完整表征。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from math import gcd
from collections import defaultdict

def norm_line(x1, y1, x2, y2):
    A = y2 - y1
    B = x1 - x2
    C = -(A * x1 + B * y1)

    g = gcd(gcd(abs(A), abs(B)), abs(C))
    if g:
        A //= g
        B //= g
        C //= g

    if A < 0 or (A == 0 and B < 0):
        A, B, C = -A, -B, -C

    return (A, B, C)

def slope_key(x1, y1, x2, y2):
    dx = x2 - x1
    dy = y2 - y1
    g = gcd(abs(dx), abs(dy))
    dx //= g
    dy //= g
    if dx < 0:
        dx, dy = -dx, -dy
    return (dx, dy)

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    lines = set()
    slope_groups = defaultdict(int)

    for i in range(n):
        for j in range(i + 1, n):
            x1, y1 = pts[i]
            x2, y2 = pts[j]

            line = norm_line(x1, y1, x2, y2)
            if line in lines:
                continue
            lines.add(line)

            slope = slope_key(x1, y1, x2, y2)
            slope_groups[slope] += 1

    m = len(lines)
    total_pairs = m * (m - 1) // 2

    parallel_pairs = 0
    for k in slope_groups.values():
        parallel_pairs += k * (k - 1) // 2

    print(total_pairs - parallel_pairs)

if __name__ == "__main__":
    solve()
```该解决方案以规范代数形式构造每条线`Ax + By + C = 0`并将其标准化，以便所有等效行折叠成同一个元组。 当多个点对位于同一条几何线上时，这可以防止重复。 

另外，斜率归一化步骤将方向向量减少为具有一致符号的减少的整数对，这允许将所有平行线分组在一起。 这种分组至关重要，因为平行线永远不会相交，因此必须将它们排除在最终计数之外。 

最后的算术步骤纯粹是组合的：从所有不同的线对开始，减去具有相同斜率的线对。

 ## 边缘情况

 完全共线配置是最重要的边缘情况。 所有点对都产生相同的标准化线，因此该组线的大小为一。 该算法正确地产生零交点，因为线对总数为零。 

第二种边缘情况是多个不相交的并行族，例如几条垂直线和几条水平线。 在这种情况下，斜率分组正确地隔离了每个族，并且减法仅删除族内对，保留所有跨族交集。
