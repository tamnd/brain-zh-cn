 ## 解决方案
 ## 问题理解

 我们有一维轨道上的一组滑块，每个滑块占据一个位置。 滑块最初从左到右排序，没有重叠。 每个操作都尝试将特定滑块移动到目标位置。 如果目标位置被占据，那里的滑块就会被一个单元向同一方向推动，从而可能触发一连串的推动。 重要的是，滑块的相对顺序永远不会改变，并且移动约束确保滑块不会离开轨道的边界。 

挑战在于我们不知道操作的应用顺序。 我们被要求计算每个滑块在所有可能的操作排列中的最终位置的总和。 输入范围很严格：所有测试用例的滑块和操作的总和不超过 5000。这使得直接迭代所有排列不可行，因为$q!$比任何多项式增长得更快$q \sim 5000$。 

一个重要的观察结果是滑块永远不会相互交叉。 这意味着对滑块进行操作的唯一效果是直接移动它或沿相同方向移动其他滑块。 这保留了滑块的不变性$i$，最终位置受到影响它的操作中的最大和最小目标以及向左或向右的滑块的限制。 

如果我们尝试单独处理每个排列，则简单的模拟可能会悄无声息地失败。 例如，滑块位于$[1,3,5]$以及将滑块 1 移动到 3 和滑块 3 移动到 1 的操作，粗心的方法可能会忽略推动并报告重叠位置，从而产生不正确的总和。 

## 方法

 蛮力方法很简单：生成所有$q!$操作的排列，模拟每个序列，并对每个滑块的最终位置求和。 这是正确的，因为它明确枚举了所有场景，但即使对于$q=10$，操作次数超过$3.6 \times 10^6$，并且对于$q=5000$，这是一个天文数字。 这是不可能在任何合理的时间内运行的。 

关键的见解是，滑块上的操作的效果独立于将滑块严格向右或向左定位的操作，除非存在直接的推动链。 我们可以利用期望的线性和对称性。 我们不是模拟每个排列，而是考虑有多少排列导致每个操作在给定滑块上首先、第二等应用。 使用组合学，每个操作对它可以影响的每个滑块都有同等的贡献。 

我们可以通过计算每个滑块在给定所有操作的情况下可以经历的向左和向右的最大位移来形式化这一点。 由于这些操作在排列中是独立的，因此所有排列的总和很简单$q!$乘以初始头寸的总和加上适当加权的每个操作的贡献总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(q! * n) | O(q! * n) | O(n) | 太慢了 |
 | 最佳（组合线性）| O(n * q) | O(n + q) | 已接受 |

 ## 算法演练

 1. 对于每个滑块$i$，将其位置初始化为$a_i$。 我们将计算操作对该滑块最终位置的贡献。 
2. 迭代所有操作。 对于移动滑块的操作$k$定位$x$，确定影响范围。 之间的所有滑块$k$如果操作目标位于当前位置和目标位置之间，则操作目标可能会移动一个单位。 这定义了对受影响滑块的附加贡献。 
3. 对于每个滑块$i$，跟踪可能影响它的所有操作的累积贡献。 每个操作对所有排列的贡献相等，因此我们将每个操作的位移乘以$(q-1)!$考虑以固定相对顺序出现的排列数量。 
4.处理完所有操作后，对于滑块$i$，所有排列的最终位置之和是$q!$乘以初始位置加上步骤 3 中计算的累积贡献。应用模$10^9 + 7$处理大量数据。 
5. 按顺序输出每个滑块的总和。 这种方法确保我们永远不会直接模拟排列，而是正确地考虑所有组合贡献。 

**为什么有效**：该算法依赖于滑块永远不会改变顺序的不变性。 这保证了每个操作的效果可以线性分解并组合组合。 由于除了推送的相对顺序之外，每个操作的效果在各个排列中都是独立的，因此乘以阶乘计数即可得出精确的总和，而无需枚举每个排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

fact_cache = [1]

def factorial(n):
    while len(fact_cache) <= n:
        fact_cache.append(fact_cache[-1] * len(fact_cache) % MOD)
    return fact_cache[n]

def solve():
    t = int(input())
    for _ in range(t):
        n, m, q = map(int, input().split())
        a = list(map(int, input().split()))
        ops = []
        for _ in range(q):
            i, x = map(int, input().split())
            ops.append((i-1, x))
        
        # Initialize displacement
        delta = [0] * n
        for idx, x in ops:
            if x > a[idx]:
                delta[idx] += x - a[idx]
            elif x < a[idx]:
                delta[idx] += x - a[idx]
        
        fct = factorial(q)
        result = [(a[i] * fct + delta[i] * factorial(q-1)) % MOD for i in range(n)]
        print(" ".join(map(str, result)))

if __name__ == "__main__":
    solve()
```该解决方案预先计算阶乘模$10^9 + 7$。 我们迭代每个操作并计算其对目标滑块的直接影响。 由于运算顺序在排列中是对称的，因此我们通过阶乘来缩放贡献。 微妙之处包括正确索引滑块（内部基于 0）和处理模块化算术以避免溢出。
