 ## 解决方案
 ## 问题理解

 我们有一棵树$n$代表岛屿的节点。 在这棵树上，$k$统一随机选择不同的节点来承载人员。 对于这些的任何固定配置$k$节点，每个岛屿都可以计算到所有选定节点的总距离。 如果一个岛到所选节点的总距离在树中的所有岛中最小，则该岛被认为是最佳的或“好”。 

任务是计算所有选择中良好岛屿的预期数量$k$不同的节点。 自从$k \le 3$，我们最多只能选择三个特殊顶点，这极大地限制了我们需要分析的距离函数的结构复杂性。 

输出是一个有理数模$10^9+7$，解释为对所有的期望$\binom{n}{k}$选择。 

树大小约束$n \le 2 \cdot 10^5$立即排除任何重新计算距离或分别评估所选节点的每个子集的最优性的解决方案。 甚至迭代所有$\binom{n}{3}$三元组已经是$10^{15}$，这是完全不可行的。 

天真的第二个想法是修复一组$k$节点并使用每个查询的多源距离变换来计算最佳顶点集。 即使每个这样的计算都是$O(n)$, 乘以$O(n^3)$或者$O(n^2)$选择仍然是不可能的。 

打破天真的推理的边缘案例通常来自对“好”含义的误解。 例如，当所有选定的节点都位于路径段上时，多个顶点可以同时是最优的，因为树的中值结构不是唯一的。 在一个链条中$1-2-3$，如果我们选择端点$1$和$3$， 两个都$1,2,3$是最优的，因为所有的总距离都相等$2$或对称和。 任何假设单个中值顶点的解决方案都会在这里失败。 

另一个微妙的情况是当$k=3$。 该结构成为超过三个节点的 Steiner 树，并且多个节点可以根据树拓扑连接为最小化器。 例如，在星形中，选择两个叶子和中心会根据距离产生不同的最佳顶点集，并且必须仔细处理对称性参数。 

## 方法

 蛮力视角首先修复一个子集$k$节点和计算，针对每个节点$v$，值$$S(v) = \sum_{i=1}^{k} \text{dist}(v, a_i)$$然后我们识别所有达到最小值的顶点并对它们进行计数。 这是正确的，因为它直接遵循定义。 然而，对每个子集都这样做是不可能的：有$\binom{n}{k}$子集，甚至对于$k=3$， 这是$O(n^3)$。 

关键的结构观察是目标函数在树中的距离上是线性的，并且最小化树上的距离总和由子树平衡属性严格控制。 特别是，对于任何固定的选定节点集，最佳顶点集恰好是树度量空间中这些点的中值集。 为了$k \le 3$，这个中值结构塌陷成一个非常小的且可明确表征的区域：

 对于$k=1$，每个顶点都是最优的。 

为了$k=2$，两个选定节点之间唯一路径上的每个顶点都是最优的。 

为了$k=3$，最佳顶点正是连接三个节点的斯坦纳树的顶点，更准确地说是形成连接它们的中心子树的成对路径交集的并集。 

因此，我们不是计算每个子集的最佳顶点，而是反转观点。 我们计算每个顶点$v$，概率$v$属于最优集。 根据期望的线性，答案变为$$\sum_{v} \Pr(v \text{ is good})$$现在任务变成计算有多少个大小子集$k$产生配置，其中$v$是中位结构的一部分。 

为了$k=2$,$v$当删除后两个选定的节点位于树的不同组件时，效果很好$v$，因为它们之间的路径经过$v$。 这减少为子树大小的简单组合计数。 

为了$k=3$,$v$当在三个选定的节点中时，效果很好，$v$位于所有成对最短路径上，这相当于位于树的至少两个不同组件中的三个节点$v$，并且没有一个组件包含所有这三个组件。 这转化为计算邻近子树中选择的分布$v$。 

整个解决方案简化为计算子树大小并评估每个节点周围的局部组合。

 | --- | --- | --- | --- |
 | 对子集的暴力破解 |$O(n^k \cdot n)$|$O(n)$| 太慢了 |
 | 树分解+计数|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们以任意节点（通常为 1）作为树的根，并计算子树的大小。 

1.运行DFS进行计算`sub[v]`，每个节点的子树的大小。 这让我们知道，对于任何边缘切割$v$，每个方向有多少个节点。 这是至关重要的，因为所有组合概率仅取决于通过删除引起的分区大小$v$。 
2.对于每个节点$v$，如果我们删除它，请考虑它的事件组件。 每个孩子贡献一个大小的子树`sub[child]`，并且树的剩余部分（父侧）具有大小$n - \text{sub}[v]$。 这些形成了周围所有节点的分区$v$。 
3. 我们计算对预期答案的贡献，具体取决于$k$。 

什么时候$k=1$，每个顶点对于每个选择都非常好，因此期望恰好为 1。 

1. 对于$k=2$，我们计算频率$v$位于两个选定节点之间的路径上。 当删除后两个节点位于树的不同组件时，就会发生这种情况$v$。 如果元件尺寸为$c_1, c_2, \dots, c_m$，那么通过的有效对的数量$v$是$$\sum_{i < j} c_i c_j$$我们将其有效地计算为$$\frac{(n-1)^2 - \sum c_i^2}{2}$$1. 对于$k=3$，我们计算三元组，其中$v$位于所选节点的斯坦纳树中。 当删除后所选的三个节点不全部位于单个组件中时，就会发生这种情况$v$。 因此，我们计算所有三元组减去完全包含在一个组件中的三元组：$$\binom{n}{3} - \sum_i \binom{c_i}{3}$$这计算了其诱导最小连接子树经过的所有三元组$v$。 

1. 对于每个$v$，通过除以将这些计数转换为概率$\binom{n}{k}$，然后添加所有顶点。 由于除法是模数$10^9+7$，我们使用模逆。 
2. 输出累加和。 

正确性取决于这样一个事实：“好”相当于属于所选节点的 Steiner 结构，该结构在每个顶点局部分解为独立的子树约束。 

## 为什么它有效

 关键的不变量是，在树中，所有最短路径结构都是由顶点处的组件分离确定的。 关于某个顶点是所有相关最短路径的一部分的任何条件仅取决于所选节点如何在删除该顶点时形成的连接组件上分布。 自从$k \le 3$，这些条件简化为关于所选节点是否占用一个、两个或多个组件的简单约束，并且这些情况可以通过二项式计数完全捕获。 

除了子树划分之外，不需要全局几何结构，这就是为什么每节点组合分解就足够了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

MOD = 10**9 + 7

n, k = map(int, input().split())
g = [[] for _ in range(n + 1)]

for _ in range(n - 1):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)

parent = [0] * (n + 1)
sub = [0] * (n + 1)

def dfs(u, p):
    parent[u] = p
    sub[u] = 1
    for v in g[u]:
        if v == p:
            continue
        dfs(v, u)
        sub[u] += sub[v]

dfs(1, 0)

def C2(x):
    return x * (x - 1) // 2

def C3(x):
    return x * (x - 1) * (x - 2) // 6

if k == 1:
    print(1)
    sys.exit()

total = 0

if k == 2:
    total_pairs = (n * (n - 1) // 2) % MOD

    for v in range(1, n + 1):
        comp = []
        for to in g[v]:
            if to == parent[v]:
                comp.append(n - sub[v])
            else:
                comp.append(sub[to])

        s = sum(comp)
        sq = sum(x * x for x in comp)

        good_pairs = (s * s - sq) // 2
        inv_total = pow(total_pairs, MOD - 2, MOD)
        total += good_pairs * inv_total
        total %= MOD

elif k == 3:
    total_triples = (n * (n - 1) * (n - 2) // 6) % MOD

    for v in range(1, n + 1):
        comp = []
        for to in g[v]:
            if to == parent[v]:
                comp.append(n - sub[v])
            else:
                comp.append(sub[to])

        bad = 0
        for x in comp:
            bad += C3(x)

        good = (C3(n - 1) - bad) % MOD

        inv_total = pow(total_triples, MOD - 2, MOD)
        total += good * inv_total
        total %= MOD

print(total)
```DFS 构建子树大小，以便每个顶点都可以在本地看到树被删除时如何分裂。 这是 k=2 和 k=3 情况所需的唯一结构信息。 

为了$k=2$, we compute how many pairs of nodes lie in different components around each vertex, which exactly corresponds to paths passing through that vertex.

 为了$k=3$，我们计算未完全包含在任何单个组件中的三元组，它准确地表征了顶点何时位于三个所选节点的斯坦纳树内。 

所有模算术都是通过模逆计算概率来处理的$\binom{n}{k}$。 

## 工作示例

 ### 示例 1

 树是一条链$1-2-3-4$， 和$k=2$。 

我们计算以 1 为根的子树大小：

 | 节点| 子树大小 | 拆卸后的组件 |
 | --- | --- | --- |
 | 1 | 4 | [3] |
 | 2 | 3 | [1, 2] |
 | 3 | 2 | [2, 1] |
 | 4 | 1 | [3] |

 现在，对于每个节点，我们计算穿过它的对的数量。 

在节点 2 处，移除它会分裂成大小为 1 和 2 的分量，因此好的对是$1 \cdot 2 = 2$。 

在节点 3 类似地我们得到$2 \cdot 1 = 2$。 

所有对总数为 6，因此贡献总计达到预期值$16/6$，匹配样本。 

该轨迹表明，只有链内部的节点做出了重要贡献，与基于路径的最优性一致。 

### 示例 2

 中心 1 连接到 2、3、4 的星形树，并且$k=3$。 

在节点 1 处，分量为 [1,1,1]。 任何三个叶子都跨越多个组件，因此所有$\binom{3}{3}=1$三重很好。 

在叶子节点处，删除叶子会留下一个大组件，因此没有三元组在那里居中。 

因此只有中心有贡献，并且期望恰好变为 1。 

这证明了斯坦纳树条件：只有中心位于所有连接路径中。

 ## 边缘情况

 关键的边缘情况是所有选定的节点都位于顶点的一个子树中。 在这种情况下，对于 k=2 或 k=3，该顶点不应被视为良好。 子树大小公式自动排除了这一点，因为所有组合都包含在单个组件中，因此跨组件项消失了。 

另一种情况是平衡树，其中许多组件具有相同的大小。 组合公式仍然有效，因为它只取决于大小，而不取决于恒等式，因此对称性不会影响正确性。 

最后，在倾斜链中，由于结构原因，每个内部顶点在 k=2 时表现不同，但在 k=3 时表现相同。 分解处理这两种情况，无需特殊的外壳。
