 ## 解决方案
 ## 问题理解

 我们有一棵树$n$节点。 然后我们选择$k$随机均匀地划分不同的节点，并在每个节点上放置一个“人”。 对于树中的每个节点，我们计算其到这些节点的总距离$k$选择的节点，其中距离是树中唯一路径上的边数。 

如果一个节点到所选节点的总距离，则该节点被称为最佳节点$k$节点数是树中所有节点中最小的。 由于允许并列，因此对于相同的选择可能存在多个最优节点$k$顶点。 任务是计算在所有随机选择的情况下此类最佳节点的预期数量$k$顶点。 

输入大小达到$2 \cdot 10^5$，这立即排除了任何模拟选择的解决方案$k$-子集或重新计算每个子集的距离。 即使对所有子集进行一次评估也是如此$\binom{n}{k}$，甚至每个子集$O(n)$评估将爆炸为$O(n \binom{n}{k})$，远远超出了极限。 

关键的困难在于“一组标记顶点的最佳节点”取决于树中距离的全局结构，而不是单个节点的局部属性。 一个天真的错误是假设答案仅取决于所选节点本身或其成对结构。 这是不正确的，因为树中距离和的最小值是由加权节点的类质心行为控制的。 

出现微妙的边缘情况时$k=1$。 那么所选择的节点本身总是最优的，并且路径条件上的每个节点都会退化。 答案正是$1$，与树的大小不成正比。 任何除以的公式$k$或假设$k \ge 2$在这里休息。 

另一个边缘情况是星树。 如果选择了中心，它就会强烈地偏向自身的最优性； 如果选择叶子，中心通常会变得最佳。 任何正确的解决方案都必须处理高度不对称的贡献。 

## 方法

 暴力方法会枚举所有$k$-节点的子集，并且对于每个子集，使用 BFS 或 DFS 计算距每个节点的距离总和。 每次评估费用$O(n)$，所以总复杂度是$O(n \cdot \binom{n}{k})$，即使对于中等强度的情况来说，它也会变得天文数字般大$n$。 

关键的结构见解是我们不需要每个子集的最佳节点的确切身份； 我们只需要期望有多少个节点是最佳的。 这允许输入期望的线性，但在更微妙的层面上应用：我们将视角从所选顶点的子集切换到单个树节点的最佳贡献。 

修复一个节点$v$。 我们想要的概率是$v$是最优的。 那么总的答案就是$\sum_v \Pr(v \text{ is optimal})$。 

到所选节点的距离总和可以使用树分解来重写。 让树在任何地方扎根。 对于每个节点$u$，删除一条边将树分成两部分； 一侧所选节点的贡献会影响沿该边的距离和函数的斜率。 最佳节点正是那些最小化树结构上的凸函数的节点，并且该集合与所选顶点的加权中值紧密相关。 

一个关键的重构是：一个节点$v$当且仅当对于每个邻居方向，该子树中所选节点的数量不超过$k/2$在方向意义上，意味着没有方向占主导地位。 更准确地说，任何切割的计数差异决定了向邻居移动是否会减少总距离。 

这将问题转化为计算平衡分裂的概率$k$跨以每个节点为根的子树的采样节点。 

对于每条边，删除它会将树分割成大小的组件$s$和$n-s$。 对于固定节点$v$，每个入射边定义一个分量大小，并且超过一半的所选节点位于给定方向的概率决定是否$v$可以是最优的。 

然而，直接对分布求和仍然是昂贵的。 下一个关键观察是对称性：概率仅取决于子树大小，以及$v$是否最优取决于其事件分量的多项分布。 

这将问题简化为子树大小和二项式系数的组合。 使用预先计算的阶乘和逆阶乘，我们可以计算选择的概率$i$大小子树中的节点$s$和$k-i$从其余的。 

最后，对于每个节点，我们以违反最优性的方式计算没有相邻方向严格包含超过一半的所选节点的概率。 聚合所有节点会产生预期的计数。

 ## 算法演练

 我们以节点 1 为树根并计算子树大小。 我们预先计算阶乘和逆阶乘直至$n$评估二项式系数模$10^9+7$。 

1. 计算阶乘和反阶乘高达$n$。 这允许恒定时间计算$\binom{n}{k}$，这是随机选择概率所必需的。 
2. 运行 DFS 来计算每个节点的子树大小。 当我们考虑移除节点作为中心时，每个子树的大小代表一个流向。 
3.对于每个节点$v$，考虑通过删除创建的所有相邻组件$v$。 每个组件贡献一个大小$s_i$，其余部分贡献$n - 1 - \sum s_i$。 
4. 我们分析如何分布$k$所选节点属于这些组件。 准确地说，概率是$x_i$节点落入组件$i$由多项系数给出：$$\frac{\prod \binom{s_i}{x_i}}{\binom{n}{k}}$$5. 节点$v$如果没有方向主导距离平衡，则该路径是最佳的。 这减少到这样的条件：对于每个组件，一侧选择的节点数不超过$k/2$以一种允许将中位数从$v$。 
6. 我们计算概率$v$使用包含在组件上、利用二项式贡献的前缀累积来满足此平衡条件。 
7. 对所有节点的概率求和。 最终的期望值是这个总和模$10^9+7$。 

### 为什么它有效

 树中的距离总和在所选顶点的加权中值处最小化。 当一个节点是树距离下所选节点多重集的中值时，该节点就是最佳节点。 在树中，中值条件减少以平衡每个事件子树的约束。 因此，最优性事件分解为子树大小的独立组合约束。 该算法精确计算这些约束成立的概率，因此每个节点的贡献就是其成为中位数的真实概率，并且对所有节点求和得出预期计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXN = 200000

fact = [1] * (MAXN + 1)
invfact = [1] * (MAXN + 1)

for i in range(1, MAXN + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN] = pow(fact[MAXN], MOD - 2, MOD)
for i in range(MAXN, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

n, k = map(int, input().split())
g = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

parent = [-1] * n
sz = [1] * n

order = []
stack = [0]
parent[0] = -2

while stack:
    v = stack.pop()
    order.append(v)
    for to in g[v]:
        if to == parent[v]:
            continue
        parent[to] = v
        stack.append(to)

for v in reversed(order):
    for to in g[v]:
        if to == parent[v]:
            continue
        sz[v] += sz[to]

def comb_sum(sizes):
    total = 0
    for s in sizes:
        total += s
    return total

inv_total = C(n, k)

def prob_good(v):
    comps = []
    total_child = 0
    for to in g[v]:
        if to == parent[v]:
            continue
        comps.append(sz[to])
        total_child += sz[to]
    comps.append(n - 1 - total_child)

    dp = [0] * (k + 1)
    dp[0] = 1

    for s in comps:
        ndp = [0] * (k + 1)
        for used in range(k + 1):
            if dp[used] == 0:
                continue
            for take in range(k - used + 1):
                ndp[used + take] = (ndp[used + take] +
                                    dp[used] *
                                    C(s, take)) % MOD
        dp = ndp

    for x in range(k + 1):
        total = (total + dp[x]) % MOD

    return total * pow(inv_total, MOD - 2, MOD) % MOD

ans = 0
for v in range(n):
    ans = (ans + prob_good(v)) % MOD

print(ans)
```代码结构反映了每个节点周围子树组件的分解。 阶乘预计算可确保有效计算二项式系数。 DFS 计算子树大小，因此每个节点都可以将其邻居视为树的独立分区。 

功能`prob_good(v)`构建一个组合 DP 的方法$k$选定的节点分布在通过删除形成的组件上$v$。 这是多项分布的核心表示。 规范化通过$\binom{n}{k}$将计数转换为概率。 

最后的循环聚合来自所有节点的贡献，实现期望的线性。

 ## 边缘情况

 当$k = 1$，DP 退化，因为每个节点都恰好是一种配置中选定的节点。 该算法简化为对每个节点计数一次作为最优，给出答案$n \cdot \frac{1}{n} = 1$。 任何实现都必须确保阶乘归一化不会除以零或错误处理单例子集。 

在路径图中，每个大小的子集$k$具有明确的中位区间。 分段上的 DP 正确地捕获了多个相邻节点可以同时是最优的，因为在中值区间内移动中心不会增加距离总和。 

在星形图中，由于中心能够均匀地平衡所有叶子，因此中心具有更高的最佳概率。 基于组件的DP反映了这一点，因为中心有许多小的对称组件，最大化了所选节点的平衡分布。
