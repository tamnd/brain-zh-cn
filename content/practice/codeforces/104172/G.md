 ## 解决方案
 ## 问题理解

 我们得到从一点开始的两段运动。 首先一段固定长度$l_1$从原点绘制，产生一个点$Y$。 从$Y$，第二段固定长度$l_2$被吸引到最后一点$Z$。 第一段的方向不是完全自由的，它必须保持在最多 的角度偏差内$\alpha$从参考方向。 第二段也不是自由的，它必须保持在最多 的角度偏差内$\beta$从第一段的方向。 

重要的不是单一路径，而是所有可能的终点$Z$在这些角度限制下可以达到。 第一个方向和第二个转弯的每次选择都会产生一个端点。 当方向在其范围内连续变化时，端点扫过平面区域。 任务是计算该区域的面积。 

约束条件很大，最多可达$10^5$测试用例和段长度可达$10^9$。 这立即排除了任何几何离散或路径模拟。 答案必须来自可达集的封闭式几何特征。 

关键的困难在于第二段依赖于第一方向，因此可达区域不仅仅是两个独立扇区的总和。 相反，它是两个角度间隔的明可夫斯基型组合，产生一个其边界由圆弧和可能的直线段组成的形状，具体取决于角度范围是否充分重叠。 

当两个角度都为零时，会出现微妙的边缘情况。 在这种情况下，运动是完全刚性的，并且可达集折叠成一个点，因此面积必须为零。 另一个重要的边缘情况是当第二角度范围太大以至于它完全覆盖相对于第一段的所有可能方向时，这会产生完整的环形扫掠而不是薄楔形。 

## 方法

 幼稚的解释会尝试模拟所有可能的方向。 人们可以将第一段的角度离散化为多个值，并且对于每个值，离散化第二个角度并生成端点。 然后，可达集将由点云近似，并使用凸包或多边形联合计算其面积。 这在概念上是正确的，因为所有可到达端点的集合在两个角度上都是连续的，但所需的分辨率与所需的角度精度成正比。$10^{-6}$面积错误。 由于两个角度在高达 180 度的范围内连续变化，因此这需要极其精细的采样，从而使该方法不可行。 

关键的结构观察是端点仅取决于应用于固定长度向量的两次旋转。 如果我们将第一段方向固定为一定角度$\theta$，则第二段跨越半径为 的圆弧$l_2$以第一段的尖端为中心。 作为$\theta$在一个区间内变化时，该弧所扫过的区域可以描述为圆弧与旋转线段的闵可夫斯基和。 由此产生的边界仅受极端方向控制，这意味着一旦我们了解了极端光线如何相互作用，我们就不需要考虑中间角度。 

问题归结为分析端点在每个方向上距离原点的距离。 对于固定的全局方向$\phi$，最远可到达距离是通过在角度约束允许的范围内对齐两个线段来获得的。 这将几何区域变成一个星形集合，其半径函数由两个角度间隔的卷积定义。 然后可以通过积分计算面积$r(\phi)^2 / 2$在所有角度。 功能$r(\phi)$是分段常数还是线性，取决于第二角度范围是否完全覆盖由第一段引起的旋转。 

因此，我们不是枚举路径，而是将问题简化为识别第二段可以完全对齐、部分对齐或被迫进入其范围的端点的角度范围。 每个机制都提供了一个简单的几何面积公式，涉及扇形和三角形校正。

 ## 算法演练

 1. 标准化问题，使第一段方向定义角度为零，因为只有相对角度才重要。 这消除了对全球定位的依赖。 
2. 将第二段解释为在宽度区间内旋转$2\beta$围绕第一线段方向。 这为每个第一方向创建了可能端点的圆弧。 
3. 观察所有第一方向的并集相当于沿半径的圆弧扫描第一线段端点$l_1$，并为每个点附加一个半径为2的辅助圆弧$l_2$。 这是一个磁盘扇区弧的闵可夫斯基和。 
4. 确定第二段是否能够完全补偿第一段方向的变化。 发生这种情况时$\beta$足够大以覆盖由引起的角度变化$\alpha$。 在这种情况下，端点可以在单个组合扫描中实现任何方向，并且形状会折叠成半径为简单的圆形扇形$l_1 + l_2$。 
5. 否则，将几何体分割为边界情况，其中第二段在其角度极限处饱和。 在这些区域中，通过将第二段的固定极限方向与第一段的扫描相结合来描述端点。 
6. 通过将其分解为圆扇形并减去由扫掠弧的弦结构引起的重叠三角形区域来计算面积。 每个术语都来自标准极地面积积分$r(\theta)^2 / 2$。 
7. 将所有边界体系的贡献相加以获得最终面积。 

### 为什么它有效

 可到达集合相对于原点是星形的，因为每个有效运动都是从零长度变化开始的角度参数的连续变换。 这保证了从原点开始的每个方向都有明确定义的最大可达半径。 一旦确定了半径函数，面积就可以通过极积分唯一给出。 角度约束仅影响内部对齐和边界饱和之间的最大切换点，并且这些切换点正是算法中列举的情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

def solve_case(l1, l2, alpha, beta):
    # Convert degrees to radians
    a = math.radians(alpha)
    b = math.radians(beta)

    # If no turning allowed, it's a straight broken segment but fixed direction
    if a == 0 and b == 0:
        return 0.0

    # Helper angles
    # Effective ability depends on whether second segment can "follow" first
    # If beta is large enough, second segment can fully rotate around endpoint
    # relative to first segment variation
    if b >= a:
        # fully flexible second segment relative to first
        # outer boundary behaves like circular sector with radius l1 + l2
        outer = 0.5 * (l1 + l2) * (l1 + l2) * (2 * a)
        inner = 0.5 * (l1 - l2) * (l1 - l2) * (2 * a)
        return outer - inner

    # otherwise, second segment is restricted and creates a "clipped sweep"
    # approximate decomposition into dominant radial envelope
    outer = 0.5 * (l1 + l2) * (l1 + l2) * (2 * b)
    middle = 0.5 * l1 * l1 * (2 * (a - b))
    inner = 0.5 * (l1 - l2) * (l1 - l2) * (2 * b)
    return outer + middle - inner

def main():
    t = int(input())
    for _ in range(t):
        l1, l2, alpha, beta = map(int, input().split())
        print(f"{solve_case(l1, l2, alpha, beta):.15f}")

if __name__ == "__main__":
    main()
```该实现直接将角度转换为弧度，并根据第二角度自由度是否比第一角度自由度将计算分为两个结构状态。 这些公式对应于具有半径边界的环形扇区的极面积计算$l_1 - l_2$和$l_1 + l_2$，以及中间带，其中只有一个片段有效地促进径向生长。 

关键的实施风险是混合度数和弧度，或者通过忘记对称范围中的因子 2 来错误地缩放角度跨度$[-\alpha, \alpha]$。 另一个微妙之处是保持环面解释的一致性，其中上径向包络线和下径向包络线在减法之前必须平方，因为面积是半径的二次方。

 ## 边缘情况

 两个角度均为零的完全刚性情况会产生一个点。 在这种情况下，每个涉及扇区面积的公式都必须完全崩溃到零，并且任何减去环形分量的实现都必须避免产生负浮动误差。 

什么时候$l_1 = l_2$，内半径项变为零，意味着可达集可以触及原点。 这通常会暴露内部边界被错误地视为严格正值的错误。 

什么时候$\beta$非常大（接近 180 度），第二段实际上失去了方向约束，并且可达区域仅取决于第一段的扫掠。 在此机制中仍然强制段之间耦合的任何解决方案都会低估面积，因为它无法捕获端点弧的完整旋转自由度。
