 ## 解决方案
 ## 问题理解

 我们得到一个正整数数组。 我们可以使用“用除以某个选定正整数时的余数替换一个值”形式的操作来重复修改各个元素。 我们可以对任何元素多次应用此操作，但禁止将元素变成零。 

执行任何此类操作序列后，我们会查看结果数组并按通常意义上计算其 GCD。 我们的目标是以最大化最终 GCD 的方式选择操作。 

关键的难点在于操作并不是简单地任意减少数字。 余数运算保留结构约束，并且并非每个较小的值都一定可以从给定的起始值到达。 

这些约束允许最多 100,000 个元素，其值最多为 1e9，因此任何尝试模拟转换或测试每个元素所有可能的最终状态的解决方案都是立即不可行的。 即使 O(n sqrt A) 方法也太慢，因为 n 和值都很大。 

“不允许零”规则产生了一个微妙的边缘情况。 例如，如果一个元素为 2，尝试进一步减少它通常会产生零并且变得非法。 特别是，从 2 开始，使用任何有效的运算序列都无法达到 1，因为每个模选择要么将其保持为 2，要么产生 0。 

另一个边缘情况是，即使一个值很小，它也可能无法自由地简化为所有中间数。 例如，4 可以达到 1，但不能达到 2 或 3。这种不均匀的可达性是天真的贪婪“将所有内容减少到目标 GCD”方法失败的主要原因。 

## 方法

 强力解释会尝试考虑每个元素的所有可能的最终值，然后计算所有组合的最佳可能 GCD。 这很快就会变成指数级的，因为每个元素都可以分支到许多可达状态，并且跨 n 个元素组合选择是很棘手的。 

更结构化的观点是扭转问题。 我们不问变换后可以形成什么 GCD，而是问什么值 d 可以作为最终数组中的公共值出现。 如果我们可以强制每个元素都恰好为 d，那么 GCD 至少为 d。 由于 GCD 的上限是以最小选择值为上限，因此最大化统一目标是最强的策略。 

这将问题简化为理解可达性：对于固定元素 a，可以使用重复的模运算将其转换为哪些值而不会达到零。 

关键的观察是，从值 a 开始，任何严格大于 a/2 且小于 a 的数字都是不可能达到的，但是从 1 到 Floor((a − 1) / 2) 的每个值最多在一次操作中可达，而任何高于该范围的值要么保持不变，要么落入不可达到的区域。 这就产生了尖锐的结构约束：每个元素要么保持自身不变，要么只能减少到相对较小的值，但不能平滑地覆盖整个区间。 

这导致对候选目标 d 的全局约束。 如果我们希望每个元素恰好变成 d，那么对于任何元素 a，要么 a 已经等于 d，要么 a 必须足够大才能通过约简达到 d。 这就要求a≥2d+1。否则，如果d位于禁止的中间区域（a/2和a之间），则无法产生。 

因此，问题就变成了检查哪些值 d 对于所有数组元素同时是“安全的”。 

直接逐日验证仍然太慢，但对数组进行排序揭示了更简单的结构。 候选 d 的唯一障碍是存在某个值 a，使得 d < a ≤ 2d 并且 a 不等于 d。 任何这样的值都会阻止构造，因为它无法转换为 d。 

这导致对排序的唯一值进行简单的扫描。

 ## 算法演练

 ### 算法演练

 1. 对数组进行排序并将其压缩为不同值的列表。 

需要排序是因为唯一的危险情况取决于值空间中的相邻值，而不是索引。 
2. 对于按升序排列的每个不同值 d，将其视为候选最终 GCD。 

如果我们可以使所有元素等于 d，那么 d 就可以实现为数组 GCD。 
3. 检查区间(d,2d]中是否存在任何值。

 如果这样的值存在并且它不等于d本身，那么d是不可能的。 原因是在允许的操作下该值不能减小到d。 
4.如果d之后的下一个不同值大于2d，则禁止区间内不存在阻塞值，因此d有效。 
5. 跟踪所有候选者的最大有效 d 并将其输出。 

### 为什么它有效

 每个元素只能贡献一个最终值，该最终值要么是其本身，要么是一个相对较小的值，最多为其当前幅度的一半。 这创建了一个硬边界：区间 (d, 2d] 中的值是“粘性”的，因为它们不能全部折叠到 d，除非它们已经等于 d。

 因此，当值集在该区间内不包含不可避免的障碍时，任何候选 d 都是有效的。 按排序顺序检查相邻值就足够了，因为任何障碍物都会显示为位于 (d, 2d] 内部的下一个较大元素。

 ## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    a.sort()
    
    # compress distinct values
    vals = []
    for x in a:
        if not vals or vals[-1] != x:
            vals.append(x)
    
    ans = 1
    
    m = len(vals)
    for i, d in enumerate(vals):
        if i < m - 1:
            nxt = vals[i + 1]
            if nxt <= 2 * d:
                continue
        ans = max(ans, d)
    
    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先对重复项进行排序和压缩，以便我们仅推理不同的量级。 对于每个候选值 d，我们只查看下一个不同的值。 如果下一个值在 2d 之内，则存在一个中间数，根据模约减规则无法将其转换为 d，因此 d 被拒绝。 否则，d是可行的并成为候选答案。 

最终的答案是最大的可行d。

 ## 边缘情况

 一种重要的边缘情况是所有元素都相等。 在这种情况下，不需要进行任何转换，答案就是这个值，因为通过保持一切不变来最大化 GCD。 

另一种情况是当值非常小并且紧密排列时，例如 4、5、6。这里，除了最大的候选值之外的每个候选值都被阻止，因为每个值在其倍增间隔内都有一个邻居。 该算法正确地拒绝了 4 和 5，并选择了 6。 

最后一种情况是当值间隔很宽时，例如 10、25、100。在这里，大多数候选值都是有效的，因为没有值落入另一个值的禁止区间，并且算法正确地将最大值识别为最佳可实现的 GCD。
