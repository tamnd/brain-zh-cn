 ## 解决方案
 ## 问题理解

 Josya 是输入的第一个参与者。 每个运动员跑五圈相同的圈，总共射击二十个目标。 十个目标从俯卧位置射击，十个目标从站立位置射击。 命中不会增加额外时间，而每次未命中都会增加 60 秒。 

对于运动员 (i)，令 (K_i) 为未击中目标的总数。 那么比赛时间，除了每次比较中取消的共同射击时间之外，是

 [
 5\cdot time_i + 60K_i。 
]

 十次俯卧射击给出了具有 10 次试验和失误概率 (1-down_i) 的二项式随机变量。 十次站立射击给出了另一个具有 10 次试验和失误概率 (1-up_i) 的二项式随机变量。 因此 (K_i) 只能取 0 到 20 之间的 21 个值。 

乔西亚登上领奖台时，最多还有另外两名运动员的成绩严格比她快。 相等并不算更快，这是比较中边界情况的主要来源。 

输入最多包含 50,000 名运动员，单圈时间最多为 600 秒。 由于可能的失误计数只有 21 次，因此较大的维度是运动员的数量，而不是可能的比赛时间范围。 (O(n^2)) 方法在最大尺寸下已经需要大约 (2.5\cdot10^9) 成对运算，这远远超出了两秒的限制。 我们需要一种方法，使每个运动员的工作量是恒定的。 

在一些边缘情况下，看似合理的实现可能是错误的。 首先，平局不能算作更快的运动员。 例如，```
4
10 1.000 1.000
10 1.000 1.000
10 1.000 1.000
10 1.000 1.000
```有答案`1.000000000000`。 每个运动员都在完全相同的时间完成比赛，因此 Josya 的速度更快的对手为零。 比较使用`<=`而不是`<`会错误地计算出并列的三名运动员。 

一分钟的处罚也创造了精确的界限。 考虑```
4
10 0.500 0.500
22 1.000 1.000
22 1.000 1.000
22 1.000 1.000
```Josya 的基本时间为 (50) 秒。 只要失误一次，她就能在（110）秒内完成比赛，与所有对手的时间完全相同。 在这种情况下，她仍然站在领奖台上。 如果失误两次或两次以上，则所有三个对手都更快。 由于 Josya 有 20 次独立射击，失误概率为 (1/2)，所以答案是

 \frac{21}{1048576}。 
]

 如果公式意外地将相等视为更快，则会丢失全部 (K=1) 贡献。 

最少的参与者人数也很特别。 如果有一名、两名或三名运动员，Josya 永远不可能有三名运动员严格领先于她，因此答案始终为 1。例如，```
1
100 0.000 0.000
```有答案`1.000000000000`，无论Josya的投篮分布如何。 

最后，精确为零或一的概率必须在不除以诸如 (1-p) 的概率的情况下起作用。 基于二项式递归的实现包含`p / (1-p)`当运动员达到概率 1 时，可以除以零。直接计算二项式项可以避免这个问题。 

## 方法

 直接的暴力解决方案将首先计算每个运动员每种可能的失误计数的概率，然后枚举其失误计数的每种组合。 每个运动员有 21 种可能的总数，因此对于 (n) 名运动员来说，有 (21^n) 种可能的比赛结果。 即使忽略每个结果也需要按其概率进行加权的事实，对于 (n=50000) 来说，这已经是无可救药的大了。 

蛮力之所以有效，是因为完整的失误计数分配完全决定了所有比赛时间。 它失败了，因为我们实际上不需要知道每个运动员的确切结果。 对于固定的 Josya 结果，每个参赛者都可以简化为一次伯努利赛事：该参赛者是否严格地比 Josya 完成得快？ 

这一观察完全改变了问题。 将 Josya 的未击中次数固定为 (k)。 对于每个其他运动员 (i)，我们可以计算

 [
 q_i(k)=P(\text{运动员}i\text{ 完成得比 Josya}\mid K_J=k 快)。 
]

 一旦(k)确定，不同参赛者的项目是独立的。 我们只关心成功伯努利事件的次数是 0、1 还是 2，因为任何 3 或更多的值都意味着 Josya 错过领奖台。 

我们可以维护一个三态动态规划数组。 最初，速度更快的运动员的概率为 1。处理完具有比 Josya 更快的概率 (q) 的竞争对手后，通过保持当前计数或将其增加 1 来更新状态。 我们放弃以上两种状态，因为它们永远无法对答案做出贡献。 

剩下的问题是如何有效地计算(q_i(k))。 让 Josya 错过单圈时间 (T) 和 (k)，而竞争对手 (i) 错过单圈时间 (t_i) 和 (j)。 当以下情况时，竞争对手绝对更快：

 [
 5t_i+60j < 5T+60k。 
]

 除以 5 给出

 [
 t_i+12j < T+12k。 
]

 对于固定 (k)，允许的最大整数 (j) 为

 [
 m=\left\lfloor\frac{T+12k-t_i-1}{12}\right\rfloor.
 ]

 因此 (q_i(k)) 就是运动员 (i) 最多 (m) 次失误的概率。 由于（m）在相关时总是在0到20之间，因此我们可以预先计算每个运动员失误次数的累积分布函数。 

(k)只有21个可能的值。 对于每一个，我们处理所有 (n-1) 个竞争者并维护三个 DP 状态。 这给出了 (O(21n)) 最终计算。 计算每个运动员的 21 值失误分布也需要恒定的工作量，因为它是两个大小为 11 的二项式分布的卷积。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(21^n)) | (O(n)) | (O(n)) | 太慢了|
 | 最佳| (O(21n)) | (O(21n)) | 已接受 |

 ## 算法演练

 1. 读取 Josya 的单圈时间和投篮概率，然后读取其余运动员。 (n) 之后的第一行输入描述了 Josya，因此她必须与竞争对手分开。 
2. 对于每位运动员，构建其失误总数的概率分布。 俯卧部分是二项式分布，有 10 次试验和失误概率 (1-down_i)，而站立部分有 10 次试验和失误概率 (1-up_i)。 对这两个分布进行卷积可得出 0 到 20 次总未命中的概率。 
3. 将每个参赛者的失误分布转换为累积分布。 为从 0 到 20 的每个 (x) 存储 (F_i[x]=P(K_i\le x))。累积形式使我们能够在常数时间内回答比 Josya 更快的查询。 
4. 计算从 0 到 20 的所有 (k) 的 Josya 自身分布 (P_J[k]=P(K_J=k))。我们将分别以 (k) 的每个可能值为条件。 
5. 修复特定的 Josya 未命中计数 (k)。 除去一般射击时间后，她的有效比赛时间为（5T+60k）。 对于竞争对手 (i)，计算

 [
 m_i=\left\lfloor\frac{T+12k-t_i-1}{12}\right\rfloor.
 ]

减一是将严格不等式转换为整数上限。 如果没有它，精确的平局将被错误地视为更快的完成。 

1. 如果(m_i<0)，竞争对手(i)不可能更快，所以设置(q_i=0)。 如果 (m_i\ge20)，则每次可能的失误计数都会使该竞争对手更快，因此设置 (q_i=1)。 否则使用 (q_i=F_i[m_i])。 
2.用DP数组对竞争对手进行一一处理`dp`。 它的三个条目代表恰好 0、1 或 2 个已处理的竞争对手严格比 Josya 快的概率。 对于概率 (q) 更快的竞争对手，转换为

 [
 new_0=dp_0(1-q),
 ]

 [
 new_1=dp_1(1-q)+dp_0q,
 ]

 [
 new_2=dp_2(1-q)+dp_1q。 
]

 拥有三个或更多更快竞争对手的州被排除在外，因为它们永远无法让乔西亚登上领奖台。 

1. 所有参赛者处理完毕后，`dp[0] + dp[1] + dp[2]`是 Josya 登上领奖台的条件概率 (K_J=k)。 将其乘以 (P_J[k]) 并将其添加到全局答案中。 
2. 对所有 21 个可能的 Josya 未命中计数重复 DP，并打印结果概率。 

### 为什么它有效

 修复 Josya 的失误次数 (k) 就完全修复了她的比赛时间。 对于每个参赛者来说，跑得更快的事件就是伯努利事件，其概率恰好是该参赛者在导出阈值处的漏数 CDF。 不同的运动员独立投篮，因此这些伯努利事件是独立的。 

DP不变量是在处理了一些竞争对手之后，`dp[x]`是那些经过处理的竞争对手中的 (x) 个严格比 Josya 快的概率，对于 (x\in{0,1,2})。 每个新的参赛者要么留在更快的组之外，要么加入其中，并准确地进行规定的转换。 由于只有最多计数到 2 才能登上领奖台，因此放弃更大的计数不会失去任何有效结果。 

最后，Josya 未命中计数的 21 个可能值是不相交且详尽的。 通过 Josya 相应的漏算概率对每个条件登上领奖台的概率进行加权，即可准确给出所需的总概率。 

## Python 解决方案```python
import sys
from array import array

input = sys.stdin.readline

C10 = [1, 10, 45, 120, 210, 252, 210, 120, 45, 10, 1]

def distribution(down, up):
    # Number of misses in the 10 prone shots.
    miss_down = 1.0 - down
    prone = [
        C10[k] * (miss_down ** k) * (down ** (10 - k))
        for k in range(11)
    ]

    # Number of misses in the 10 standing shots.
    miss_up = 1.0 - up
    standing = [
        C10[k] * (miss_up ** k) * (up ** (10 - k))
        for k in range(11)
    ]

    # Convolution: total misses range from 0 to 20.
    dist = [0.0] * 21
    for i in range(11):
        pi = prone[i]
        for j in range(11):
            dist[i + j] += pi * standing[j]

    return dist

def solve():
    n = int(input())

    t0, down0, up0 = input().split()
    t0 = int(t0)
    down0 = float(down0)
    up0 = float(up0)

    # Store competitors' lap times separately. Their CDFs are
    # stored transposed: cdfs[m][i] is competitor i's P(K <= m).
    times = []
    cdfs = [array('d') for _ in range(21)]

    for _ in range(n - 1):
        t, down, up = input().split()
        t = int(t)
        down = float(down)
        up = float(up)

        times.append(t)

        dist = distribution(down, up)
        cur = 0.0
        for k in range(21):
            cur += dist[k]
            cdfs[k].append(cur)

    josya = distribution(down0, up0)

    ans = 0.0
    competitors = n - 1

    for k in range(21):
        pj = josya[k]
        if pj == 0.0:
            continue

        dp0, dp1, dp2 = 1.0, 0.0, 0.0

        for i in range(competitors):
            # Competitor is faster iff
            # 5 * times[i] + 60 * misses
            # < 5 * t0 + 60 * k.
            #
            # Equivalent to
            # 12 * misses < t0 + 12*k - times[i].
            #
            # Maximum integer misses is floor((D - 1) / 12).
            D = t0 + 12 * k - times[i]
            m = (D - 1) // 12

            if m < 0:
                q = 0.0
            elif m >= 20:
                q = 1.0
            else:
                q = cdfs[m][i]

            nq = 1.0 - q

            ndp2 = dp2 * nq + dp1 * q
            ndp1 = dp1 * nq + dp0 * q
            ndp0 = dp0 * nq

            dp0, dp1, dp2 = ndp0, ndp1, ndp2

        ans += pj * (dp0 + dp1 + dp2)

    print(f"{ans:.12f}")

if __name__ == "__main__":
    solve()
```这`distribution`函数首先创建两个二项式分布。 指数是未命中的次数，而剩余指数是命中的次数。 当命中概率恰好为 0 或 1 时，直接编写公式可以避免被零除。 

卷积结合了十个俯卧镜头和十个站立镜头。 每个分布中只有 11 项，因此每个运动员的 121 次乘法是持续的工作。 

累积分布存储在`array('d')`对象而不是嵌套的 Python 浮点数列表。 最多存储 (21\cdot49999) 个值，并且 double 占用 8 个字节，因此数值数据大约需要 8.4 MB。 这使内存使用量保持在 256 MB 限制以下。 

比较使用`D = t0 + 12 * k - times[i]`。 表达式`(D - 1) // 12`是故意的。 例如，如果`D`正好是 12，条件是`12 * misses < 12`，因此只允许零失误。 公式给出`(12 - 1) // 12 = 0`。 使用`D // 12`会错误地允许一次失误，并将平局变成竞争对手的胜利。 

DP 仅保留三个状态，因为所需的赛事最多有两名速度更快的运动员。 第四种状态永远不会对答案做出贡献，因此存储它只会增加不必要的工作。 

Python 中不可能出现整数溢出，并且所有概率计算都使用双精度浮点。 所需的误差为(10^{-9})，而计算仅涉及小概率分布和大约一百万个DP转换，因此产生的浮点误差安全地在所需的容差范围内。 

## 工作示例

 官方的样本是```
4
45 0.700 0.700
60 0.800 0.800
90 0.900 0.900
120 1.000 1.000
```它的输出是```
0.675394632273
```对于圈速为 60 的参赛者和圈速为 45 的 Josya 来说，更快的条件变为

 [
 60+12j < 45+12k。 
]

 允许的最大参赛者失误次数为 (k-2)。 对于圈速为90和120的运动员，对应的阈值是(k-4)和(k-6)。 负阈值的概率为零。 该算法针对每个可能的 Josya 未命中计数评估这些 CDF，然后运行三态 DP。 

从全确定性竞赛中获得更透明的跟踪：```
4
10 1.000 1.000
10 1.000 1.000
10 1.000 1.000
10 1.000 1.000
```每个运动员都有零失误，概率为 1，因此 Josya 也有零失误。 

| 已处理的竞争对手 | 更快的概率 (q) |`dp[0]`|`dp[1]`|`dp[2]`|
 | --- | --- | --- | --- | --- |
 | 开始| 0 | 1 | 0 | 0 |
 | 1 | 0 | 1 | 0 | 0 |
 | 2 | 0 | 1 | 0 | 0 |
 | 3 | 0 | 1 | 0 | 0 |

 对于 Josya 唯一可能的失误次数 (k=0)，具有相同单圈时间的参赛者必须失误次数少于零才能更快。 它的阈值是(-1)，所以它的更快概率为零。 每次参赛后都会保留不变式，登上领奖台的条件概率为 1。 

对于边界示例```
4
10 0.500 0.500
22 1.000 1.000
22 1.000 1.000
22 1.000 1.000
```Josya 的失败总数遵循 20 次试验和概率 (1/2) 的二项分布。 

| 乔西亚 (Josya) 失手 (k) | (P(K_J=k)) | 竞争对手门槛（米）| 更快的概率 (q) | 有条件登上领奖台的概率 |
 | --- | --- | --- | --- | --- |
 | 0 | (1/2^{20}) | (-6) | 0 | 1 |
 | 1 | (20/2^{20}) | (-1) | 0 | 1 |
 | 2 | (190/2^{20}) | 4 | 1 | 0 |
 | 3 至 20 | 剩余概率| 至少 5 | 1 | 0 |

 对于（k=1），Josya 的时间为（50+60=110）秒，正好等于每位参赛者的干净时间（5\cdot22=110）。 阈值为 (-1)，因此没有竞争对手算得更快。 对于 (k=2)，Josya 需要 120 秒，而所有三名参赛者都在 110 秒内完成，因此 DP 以三名速度更快的运动员结束，贡献为零。 

最终的答案是

 \frac{21}{1048576}
 \约0.0000200271606445。 
]

 该迹线说明了为什么阈值计算中的严格不等式至关重要。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | (O(21\cdot121\cdot n + 21n)) = (O(n)) | 每个运动员的两个 11 元素二项分布进行卷积，然后 21 个 Josya 结果中的每一个都用三个 DP 状态处理每个运动员。 |
 | 空间| (O(21n)) | 我们存储每位参赛者的 21 个累积概率以及单圈时间。 |

 常数因子很小，因为最大失误计数固定为 20。对于 50,000 名运动员，主要 DP 仅执行约 100 万个运动员转换，而分布结构执行约 600 万个简单算术运算。 紧凑型`array('d')`存储还使内存使用量远低于 256 MB。

 ## 边缘情况

 同等时间的情况由`D - 1`在阈值公式中。 为了```
4
10 1.000 1.000
10 1.000 1.000
10 1.000 1.000
10 1.000 1.000
```Josya 有 (k=0)，并且对于每个竞争对手 (D=0)。 公式给出 (m=(-1)//12=-1)，因此每个更快的概率都为零。 民主党仍保留`(1, 0, 0)`答案正是 1。 

精确的一分钟边界的处理方式类似。 为了```
4
10 0.500 0.500
22 1.000 1.000
22 1.000 1.000
22 1.000 1.000
```当Josya有1次失误时，(D=0)，给予(m=-1)。 两位选手在 110 秒内打成平手，因此他们更快的概率正确为零。 当 Josya 有两次失误时，（D=60），给予（m=4），并且每个干净的参赛者都严格更快。 因此，该算法准确地保留 (k=0) 和 (k=1) 情况，生成 (21/1048576)。 

对于单个参与者来说，```
1
100 0.000 0.000
```根本没有竞争对手的转变。 DP 开始于`(1, 0, 0)`对于每个可能的 Josya 未命中计数，Josya 分布的总和为 1。因此，答案为 1，不需要主算法中的任何特殊情况。 

对于等于 0 或 1 的确定性射击概率，直接二项式公式仍然有效。 如果命中概率为 1，则每个正未命中计数的概率为零。 如果命中概率为 0，则只有最大未命中计数的概率为 1。 由于实现永远不会除以命中或未命中概率，因此两个端点的处理都不会出现数值异常。
