 ## 解决方案
 ## 问题理解

 我们有`2n`不同的卡片，编号为`1`通过`2n`。 他们被随机分为`n`成对，每对送给一位客人。 客人的分数是其配对中两张牌的总和。 我们需要恰好一位客人获得最高分数的概率。 

输入的是客人人数，`n`。 由于有`2n`卡片，每个随机结果都是卡片成对的完美匹配。 输出是具有唯一最大分数的概率，以模表示`10^9 + 7`。 

约束条件`n <= 10^5`排除枚举配对，甚至排除与可能配对的数量成比例的工作。 完美匹配的数量`2n`卡是`(2n-1)!!`，增长速度极快。 我们需要一种观察，将随机匹配减少到恒定大小的事件，给出`O(1)`阅读后的解决方案`n`。 

最小的情况是`n = 1`。 只有一名客人，因此该客人自动成为获胜者，但不可能有多名获胜者。 正确的概率是`1`， 不是`0`。 将“唯一最大值”解释为需要两个不同的客人进行比较的粗心解决方案将错误地拒绝这种情况。 

为了`n = 2`，存在三种可能的卡配对`1,2,3,4`。 他们是`{1,2},{3,4}`,`{1,3},{2,4}`， 和`{1,4},{2,3}`。 前两个具有唯一的最大值，而最后一个具有总和`5`和`5`，所以正确的概率是`2/3`。 只检查是否卡的解决方案`3`和`4`属于不同的客人会犯这个错误，因为第一次配对也会将他们分开，但决定性的比较是在他们的伙伴之间。 

## 方法

 直接方法将生成每个可能的配对`2n`卡片，计算所有`n`对总和，并计算最大值恰好出现一次的配对。 这是正确的，因为它检查了每个可能的随机结果并直接应用定义。 然而，配对的数量是`(2n-1)!!`。 即使是为了`n = 10`，这已经是`19!! = 654729075`，因此详尽的枚举几乎是不可行的。 在`n = 10^5`，搜索空间更大。 

有用的观察来自于观察两张最大的牌，`2n`和`2n-1`。 让卡与`2n`是`x`，以及与以下配对的卡`2n-1`是`y`。 第一对的得分为`2n + x`，而第二对有得分`2n-1 + y`。 

其他每一对最多完全由牌组成`2n-2`，所以它的总和最多为`4n-5`。 更直接地说，在所有不包含的对中`2n`，可以出现的最大的牌是`2n-1`。 因此该对包含`2n-1`在所有不包含的对中得分最高`2n`。 

因此，包含`2n`是唯一的获胜者`2n + x > 2n - 1 + y`,

 这相当于`x > y`。 

这将整个问题简化为比较两张最大牌的伙伴。 

有一种特殊情况。 如果`2n`和`2n-1`如果它们配对在一起，那么它们显然是同一个客人，并且它们的伙伴不是两张单独的牌。 该客人有金额`4n-1`，它严格大于所有其他可能的对总和，因此这个结果实际上给出了唯一的获胜者。 因此，两张最大的牌的配对是有利的。 

如果它们没有配对在一起，对称性告诉我们，`2n`比以下伙伴更大或更小的可能性是相同的`2n-1`。 不存在第三种可能性，因为两个伙伴是不同的。 因此，唯一获胜者的条件概率是`1/2`当最大的牌分开时。 

两张特定卡在均匀随机完美匹配中配对的概率为`1/(2n-1)`，因为在确定了合作伙伴之后`2n`, 每一个其他的`2n-1`卡的可能性是一样的。 

因此`P = 1/(2n-1) + (1 - 1/(2n-1)) * 1/2`这简化为`P = n/(2n-1)`。 

该公式还给出`1`为了`n = 1`，完全按照要求。

 | --- | --- | --- | --- |
 | 蛮力 | O((2n-1)!! * n) | O((2n-1)!! * n) | O(n) | 太慢了|
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`。 有`2n`卡，所以最大的两张卡是`2n`和`2n-1`。 
2. 考虑这两张卡配对在一起的情况。 其概率为`1/(2n-1)`, 因为卡`2n`正好有`2n-1`可能的合作伙伴，都同样有可能。 
3. 如果两张最大的牌成对，则他们的客人拥有总和`4n-1`，绝对最大可能的对和。 该客人自动成为唯一的获胜者。 
4. 否则，让`x`成为...的合作伙伴`2n`和`y`的合伙人`2n-1`。 该对包含`2n`击败包含的对`2n-1`恰好在什么时候`x > y`。 
5. 以最大的牌分开为条件，两个伙伴是对称的。 交换身份`2n`和`2n-1`交换事件`x > y`和`x < y`，所以每个都有概率`1/2`。 
6. 合并两种情况。 概率是`1/(2n-1) + (2n-2)/(2n-1) * 1/2 = n/(2n-1)`。 
7. 计算该分数模`10^9 + 7`通过乘法`n`通过模逆`2n-1`。 

为什么它有效：每种可能的匹配都恰好属于两种情况之一，要么两张最大的牌配对，要么它们分开。 在第一种情况下，立即就会有一个独特的获胜者。 在第二种情况下，包含的对`2n-1`是包含的对的最强竞争对手`2n`，所以获胜者是唯一的，当合作伙伴`2n`比以下的伙伴大`2n-1`。 对称性使得两种可能的排序同样可能，给出概率`1/2`。 这些情况涵盖了每个匹配，因此得到的概率是准确的。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())

    numerator = n
    denominator = 2 * n - 1

    answer = numerator * pow(denominator, MOD - 2, MOD) % MOD
    print(answer)

if __name__ == "__main__":
    solve()
```代码直接推导即可。`numerator`是`n`， 和`denominator`是`2n-1`，因此期望的概率表示为`n / (2n-1)`。 

蟒蛇的`pow(a, MOD - 2, MOD)`计算模逆`a`使用快速求幂。 这有效是因为`MOD = 10^9 + 7`是素数并且`2n-1`小于`MOD`对于给定的约束，因此它不能被模数整除。 

在求最终余数之前执行乘法。 Python 整数不会溢出，但模约化仍然使值保持较小并遵循预期的模运算。 

没有专门的分支机构`n = 1`。 公式自然给出`1 / 1 = 1`，因此边界情况的处理无需任何单独的逻辑。

### 示例 1

 对于`n = 1`, 有卡`1`和`2`，并且它们必须构成唯一的一对。 

| n | 2n | 2n-1 | 2n-1 概率 |
 | --- | --- | --- | --- |
 | 1 | 2 | 1 |`1 / 1`|

 两张最大的牌必然是配对的。 唯一的客人得分最高，因此唯一获胜者的概率为`1`。 算法输出`1`。 

### 示例 2

 对于`n = 2`，卡片是`1,2,3,4`。 公式给出`2/3`。 

| n | 2n | 2n-1 | 2n-1 概率最大的牌配对 | 概率分离| 最终概率|
 | --- | --- | --- | --- | --- | --- |
 | 2 | 4 | 3 |`1/3`|`2/3`|`1/3 + (2/3)(1/2) = 2/3`|

 在三种可能的配对中，`{3,4}`一起给出一个独特的获胜者，`{1,2},{3,4}`还有一个独特的获胜者，同时`{1,4},{2,3}`实际上是第三对，也有一个独特的获胜者。 等等，这个直接枚举表明所有三个配对都有一个唯一的获胜者，所以正确的概率是`1`， 不是`2/3`。 

这暴露了为什么之前的对称性计算必须小心处理。 什么时候`2n`和`2n-1`是分开的，该对包含`2n`有分数`2n+x`，而这对包含`2n-1`有分数`2n-1+y`。 不平等确实是`x > y`，但是对于`n=2`，分居后剩下的合伙人是`1`和`2`，并且每次匹配中都出现一个排序。 在`{1,4},{2,3}`，我们有`x=1,y=2`，所以包含的对`4`有总和`5`，而这对包含`3`有总和`5`。 这是平局。 其他分离匹配`{2,4},{1,3}`有`x=2,y=1`，产生总和`6`和`4`。 

因此，三个匹配中只有两个有唯一的获胜者，正确的概率是`2/3`。 跟踪证实合作伙伴比较是决定性事件。

 ## 边缘情况

 对于`n = 1`，输入是`1`。 正好有两张牌，`1`和`2`，而且他们一定会去见同一个客人。 概率是`1`。 公式给出`1/(2-1) = 1`，因此不需要特殊情况。 

为了`n = 2`，输入是`2`。 最大的两张牌是`4`和`3`。 如果他们配对，得分为`7`，这是唯一最大的。 如果它们分开，则剩余的牌`1`和`2`。 配对`4`和`2`给出分数`6`和`4`，所以获胜者是唯一的，同时配对`4`和`1`给出两个分数`5`，产生领带。 三个匹配中恰好有两个成功，给出概率`2/3`。 

分母`2n-1`不得意外地被替换为`2n`。 卡片`2n`正好有`2n-1`可能的合作伙伴，而不是`2n`，因为它不能与自身配对。 为了`n = 2`， 使用`2n`会错误地声称最大的两张牌以概率配对`1/4`，而正确的概率是`1/3`。 

最大的两张牌在一起的情况也必须算成功。 他们的综合得分是`4n-1`，它比其他所有对的总和都大。 忽略这种情况会错误地将事件视为平局或无关紧要，从而失去整个事件`1/(2n-1)`对答案的贡献。 

最后，模输出不应与普通分数相混淆。 为了`n = 2`，数学答案是`2/3`，但所需的输出是`2 * 3^{-1} mod (10^9+7) = 666666672`。 该代码精确地计算该模块化表示，而不是尝试浮点除法。
