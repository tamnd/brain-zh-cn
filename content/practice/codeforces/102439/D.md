 ## 解决方案
 ## 问题理解

 有 (n) 个灯泡，因此俱乐部的配置是长度为 (n) 的二进制向量。 开关是另一个二进制向量。 按下开关意味着将其向量与当前配置进行异或，因为每个对应位为 1 的灯泡都会被切换。 

每个开关仅在连续的几天间隔内可用。 每天，Dima 都可以使用当天可用的交换机的任何子集，包括空子集。 每天的问题是可以生产多少种不同的灯泡配置。 

关键的代数观察是按下开关的顺序并不重要。 如果某一天的可用开关是向量 (v_1,v_2,\ldots,v_k)，则每个可达配置都具有以下形式

 [
 c_1v_1\oplus c_2v_2\oplus\cdots\oplus c_kv_k,
 ]

 其中每个 (c_i) 要么为零，要么为一。 因此，可达配置恰好是域 GF(2) 上可用向量的线性跨度。 

如果向量的秩为 (r)，则它们的跨度恰好包含 (2^r) 个不同的向量。 所以原来的问题相当于计算每天的活跃开关向量集合的秩。 

这些界限迫使我们无法每天独立重建高斯基。 我们可以有 (d=q=500,000)，即使每天一次通过所有开关也已经需要 (2.5\cdot10^{11}) 次开关检查。 二次或 (O(nq d)) 方法是完全不可能的。 

输入格式中还隐藏着一个有用的约束。 每个开关描述恰好包含 (n) 位，所有此类字符串的总长度最多为 (500,000)。 因此

 [
 nq\le500,000。 
]

 这就是高斯基解决方案变得实用的原因。 尽管 (n) 本身可以是 (500,000)，但在这种情况下只能有一个开关。 相反，如果有（500,000）个开关，则（n=1）。 

有几种边缘情况，简单的实现可能会处理不当。 

考虑调零开关：```
1 1 1
1 1 0
```唯一的开关没有改变任何东西。 因此跨度的等级为零，所以答案是`1`， 不是`2`。 粗心地计算开关而不是独立向量的实现会给出错误的结果。 

重复的开关是另一个陷阱：```
2 2 1
1 1 10
1 1 10
```两个开关都可用，但它们代表相同的向量。 等级为一，所以答案为`2`。 将每个可用开关视为独立的二元选择会错误地产生`4`。 

间隔端点也必须包含在内。 例如：```
2 2 2
1 2 10
2 2 01
```第一天只有第一个向量可用，给出`2`配置。 第二天，两个独立向量都可用，给出`4`。 正确的输出是`2 4`。 将正确端点解释为独占端点的实现将在第二天丢失第二个开关。 

## 方法

 最直接的方法就是独立地处理每一天。 对于固定的一天，收集间隔包含该天的每个开关，并将其向量插入到 GF(2) 上的高斯基中。 如果所得基的秩为 (r)，则输出 (2^r)。 

这是正确的，因为高斯消元法准确地告诉我们可用开关提供了多少个独立方向。 然而，在最坏的情况下，可能会有 (500,000) 天和 (500,000) 次切换。 每天处理每个开关可能需要 (250,000,000,000) 次开关检查，甚至不考虑消除成本。 

拯救我们的结构是每个开关在一个时间间隔内都是活动的。 我们可以将一个开关存储在一个线段树上，而不是询问一天中有哪些开关处于活动状态，从而准确地覆盖该开关处于活动状态的日期。 

区间可以用 (O(\log d)) 个线段树节点表示。 在树的深度优先遍历期间，存储在节点处的每个开关对于该节点下方的每个叶子都是活动的。 我们可以将所有此类向量插入到一个线性基中，递归地访问子项，然后在从节点返回时撤消插入。 

撤销高斯消元法听起来很困难，因为普通消元法会破坏信息。 解决方案是使用一个基础，其中每次成功的插入都会创建一个新的主元。 我们记住创建了哪个枢轴，并且在回滚时只需清除该枢轴即可。 由于递归处理按反向插入顺序回滚，因此后面的向量不能依赖于已删除的基础条目。 

将二进制向量表示为一个 Python 整数使得实现特别方便。 按位 XOR 在 GF(2) 上执行向量加法，并且`bit_length()`给出最高的设置位，这是基础使用的枢轴。 

线段树处理时间间隔，而回滚基础处理切换之间的线性相关性。 这两部分结合在一起，因为每个递归节点都代表一个天数范围，在该天数范围内存储在该节点的所有向量都同时可用。 

比较结果为：

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(ndq)) 的简单实现 | (O(nq)) | 太慢了|
 | 最佳 | (O(nq\log d)) 最坏情况 | (O(q\log d+n)) | 已接受 |

 界限 (nq\le500,000) 使最佳时间大致为 (O(500,000\log 500,000))，实际常数取决于需要多少高斯基约简。 

## 算法演练

 1. 读取每个开关并将其二进制字符串转换为整数。 位(i)表示灯泡(i)是否被切换。 整数表示允许我们使用普通的 XOR 来执行向量加法。 
2. 在 (1) 到 (d) 的时间内构建隐式线段树。 对于 ([l,r]) 上可用的开关，将该区间分解为规范线段树节点，其范围加起来完全等于 ([l,r])。 将开关向量存储在每个这样的节点中。 
3.维护由每个基向量的最高设置位索引的线性基。 要插入向量 (x)，请重复查看其最高设置位。 如果相应的主元已经存在，则对 (x) 中的现有基向量进行异或。 如果主元为空，则将 (x) 放在那里并将等级加一。 
4. 每当插入创建新的主元时，将该主元记录在回滚堆栈中。 如果向量减少到零，则它与当前基础线性相关，因此不需要记录任何内容。 
5. 递归遍历线段树。 在节点处，记住当前回滚堆栈大小，然后插入存储在该节点处的每个向量。 所有这些向量在整个节点范围内都是活跃的，因此它们属于每个后代日的基础。 
6. 如果该节点是代表第 (i) 天的叶子，则当前基础恰好包含该天可用的独立开关。 如果它的等级是 (r)，则写 (2^r\bmod(10^9+7)) 作为第 (i) 天的答案。 
7. 对于内部节点，递归处理两个子节点。 基础在两个子级之间共享，但每个子级都准确接收在其范围内有效的向量以及从其祖先继承的向量。 
8.处理完一个节点后，重复弹出回滚堆栈，直到到达保存的检查点。 对于每个删除的主元，清除该基础条目并降低排名。 这会将基础恢复到进入节点时的状态。 

### 为什么它有效

 在每个线段树节点上，不变的是线性基精确地包含其间隔完全覆盖从根到该节点的路径的开关。 当到达叶子时，该路径对应于一天，因此基础恰好包含当天活动的所有开关。 高斯消除保留了跨度，同时删除了相关向量，这意味着它的秩恰好是可达配置空间的维度。 GF(2) 上的 (r) 维向量空间恰好包含 (2^r) 个向量，因此每个叶子产生的值恰好是可达光配置的数量。 

回滚是正确的，因为插入是以相反的顺序撤消的。 成功的插入会占用先前空的枢轴，并且在其之后进行的每个插入都会先被删除。 因此，清除记录的主元可以恢复先前的基础，而不影响旧的基础向量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1_000_000_007

def solve():
    n, q, d = map(int, input().split())

    # Use a power-of-two segment tree.
    size = 1
    while size < d:
        size <<= 1

    # events[v] contains vector integers assigned to segment-tree node v.
    # None avoids creating millions of empty Python lists.
    events = [None] * (2 * size)

    for _ in range(q):
        l, r, s = input().split()
        l = int(l) - 1
        r = int(r)

        # One object is shared by all segment-tree copies of this switch.
        vec = int(s, 2)

        l += size
        r += size

        while l < r:
            if l & 1:
                if events[l] is None:
                    events[l] = [vec]
                else:
                    events[l].append(vec)
                l += 1

            if r & 1:
                r -= 1
                if events[r] is None:
                    events[r] = [vec]
                else:
                    events[r].append(vec)

            l >>= 1
            r >>= 1

    # basis[p] is the vector whose highest set bit is p.
    basis = [0] * n
    changes = []
    rank = 0

    pow2 = [1] * (n + 1)
    for i in range(1, n + 1):
        pow2[i] = (pow2[i - 1] * 2) % MOD

    ans = [0] * d

    def add_vector(x):
        nonlocal rank

        while x:
            p = x.bit_length() - 1
            b = basis[p]

            if b:
                x ^= b
            else:
                basis[p] = x
                changes.append(p)
                rank += 1
                return

    def rollback(checkpoint):
        nonlocal rank

        while len(changes) > checkpoint:
            p = changes.pop()
            basis[p] = 0
            rank -= 1

    sys.setrecursionlimit(1_000_000)

    def dfs(v, left, right):
        checkpoint = len(changes)

        ev = events[v]
        if ev is not None:
            for x in ev:
                add_vector(x)

        if right - left == 1:
            if left < d:
                ans[left] = pow2[rank]
        else:
            mid = (left + right) >> 1
            dfs(v << 1, left, mid)
            dfs(v << 1 | 1, mid, right)

        rollback(checkpoint)

    dfs(1, 0, size)

    sys.stdout.write(" ".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```输入转换`int(s, 2)`是中心表示技巧。 最左边的字符变为高位，但确切的方向并不重要，因为异或和线性相关性不受一致重命名坐标的影响。 

区间转换使用半开区间`[l, r)`。 输入间隔`[l,r]`首先通过从零开始的坐标减去一来更改为从零开始的坐标`l`，而右端点保持不变。 因此，开关在输入日激活`1..3`变为半开范围`[0,3)`。 这是避免迭代线段树分解中端点错误的便捷方法。 

这`events`数组有大小`2 * size`， 在哪里`size`至少是二的最小幂`d`。 空节点表示为`None`。 这在 Python 中很重要，因为创建数百万个空列表会消耗比所需更多的内存。 

基为每个可能的枢轴位存储一个向量。 当向量具有最高位时`p`，现有的`basis[p]`可以消除那一点。 最终，要么向量变为零，证明依赖性，要么到达未使用的枢轴并成为新的独立基向量。 

回滚堆栈仅包含主元索引，而不包含整个基础的副本。 假设插入创建了枢轴`p`。 那一刻`basis[p]`为零。 在此插入之前，以后的每个插入都会被撤消，因此清除`basis[p]`准确恢复之前的状态。 

答案预先计算为`pow2[r]`。 排名永远不会超过`n`，所以只有`n+1`权力是必要的。 Python 整数不会溢出，但减少模数 (10^9+7) 的幂可以使存储的答案保持较小。 

即使当`d`本身不是二的幂。 叶子至少有索引`d`被忽略。 区间分解仅插入真实的天数，因此这些人造叶子永远不会影响有效答案。

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | (O(nq\log d)) 最坏情况 | 每个开关都存储在 (O(\log d)) 个线段树节点中，并且每个基础插入最多执行 (O(n)) 个主元消除 |

 ## 边缘情况

 零向量自然由基处理。 为了```
1 1 1
1 1 0
```整数表示为零，所以`add_vector(0)`立即返回而不创建枢轴。 等级保持为零，叶子接收`2^0 = 1`。 该开关存在，但按下它无法更改灯光配置。 

重复向量也通过高斯消除而不是通过计数开关来处理。 为了```
2 2 1
1 1 10
1 1 10
```第一个`10`创建一个枢轴。 第二个`10`与现有的基向量进行异或并变为零。 只剩下一个支点，所以答案是`2`。 

包含的右端点通过转换来处理`[l,r]`进入从零开始的半开范围`[l-1,r)`。 为了```
2 2 2
1 2 10
2 2 01
```第一个开关占据两个叶子，而第二个开关仅占据第二个叶子。 因此，第一片叶子具有排名第一并产生`2`，而第二个叶子有两个独立的向量并产生`4`。 

没有可用开关的一天也有效。 空的开关子集始终存在，因此即使活动集为空，也可以达到全关配置。 那么基础的等级为零，答案正是一。 

最后，向量可以比机器字长得多。 Python 的任意精度整数在这里很有用，因为直接表示 (500,000) 位向量，并且 XOR 在内部对所有机器字进行运算。 输入保证可防止这种大向量情况与大量开关同时发生，因为 (nq\le500,000)。
