 ## 解决方案
 ## 问题理解

 给定一个正多边形$n$顶点，每个顶点用正整数标记。 目标是在多边形内绘制不重叠的三角形，以最大化其顶点处的数字的乘积之和。 每个三角形将其顶点乘积贡献给分数，并且三角形不允许共享任何正面积。 

输入由多个测试用例组成，每个测试用例通过以下方式描述一个多边形$n$和一个整数数组$a_1, \dots, a_n$。 输出是每个多边形可达到的最大分数。 

关键限制是$3 \le n \le 400$和总和$n^3$所有测试用例最多$400^3$。 这表明$O(n^3)$解决方案是可以接受的，但任何更糟糕的解决方案，例如$O(n^4)$，会太慢。 边缘情况包括所有数字都相等的多边形，或者最佳解决方案可能涉及选择单个三角形而不是多个较小的三角形，因为组合较小的三角形会减少总体乘积之和。 例如，在标记为 [2,1,3,4] 的四边形中，选择顶点为 1,3,4 的三角形会得到 24，而组合较小的三角形可能会得到更少的结果。 

## 方法

 蛮力方法考虑所有可能的不重叠三角形集。 为了$n$顶点数，三角形的数量为$O(n^3)$，并且检查重叠会增加额外的复杂性。 这是正确的，但效率低下，因为验证每个组合都会逐级增长，远远超过了可行的计算$n = 400$。 

观察结果是，多边形是规则且凸的，因此如果仔细选择，不共享边的三角形是不重叠的。 这建议采用类似于“矩阵链乘法”或“多边形三角剖分”的动态编程方法，其中我们递归地考虑子多边形及其最大可实现分数。 具体来说，如果我们选择一个带有顶点的三角形$i, j, k$在子多边形内部$[i, j, k]$，我们可以将剩余的多边形分割成独立的子多边形并分别求解。 这确保我们永远不会绘制重叠的三角形。 

因此，我们将问题简化为使用 DP 计算所有子多边形的最大乘积和。 让`dp[l][r]`是从顶点开始的多边形线段可获得的最大分数$l$到$r$沿着顺时针顺序。 递归是：```
dp[l][r] = max(dp[l][k] + dp[k][r] + a[l]*a[k]*a[r]) for l<k<r
```此递归考虑选择一个具有端点的三角形`l`和`r`和一些中间顶点`k`。 迭代所有段和长度填充 DP 表$O(n^3)$，在给定约束的情况下这是可行的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n! 对于三角形) | O(n^3) | O(n^3) | 太慢了|
 | 动态规划| O(n^3) | O(n^3) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1.扩展数组`a`通过将多边形连接到自身来轻松处理多边形的圆度。 这允许对环绕多边形的线段进行线性索引。 
2. 初始化一个2D DP数组`dp[l][r]`带零，其中`l`和`r`是扩展数组中段的索引。 
3. 迭代段长度从 3 到$n$，因为三角形至少需要 3 个顶点。 
4. 对于每个段`[l, r]`给定长度，考虑所有中间顶点`k`这样`l < k < r`。 
5. 计算绘制三角形的分数`(l, k, r)`加上左右子段的最高分数（`dp[l][k]`和`dp[k][r]`）。 
6. 更新`dp[l][r]`从所有可能的值中获得最大值`k`。 
7.填完DP表后，答案就是最大值`dp[l][l+n-1]`对于所有起始索引`l`从 0 到`n-1`，确保我们考虑多边形的所有旋转。 

为什么它有效：DP 不变量确保`dp[l][r]`始终存储该段的最优解`[l, r]`。 在不相交子段中选择的三角形不重叠，并且通过检查所有中间顶点`k`，我们保证考虑每一个可能的三角测量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        # duplicate array for circularity
        a = a * 2
        dp = [[0] * (2*n) for _ in range(2*n)]
        
        for length in range(3, n+1):
            for l in range(0, 2*n - length + 1):
                r = l + length - 1
                for k in range(l+1, r):
                    dp[l][r] = max(dp[l][r], dp[l][k] + dp[k][r] + a[l]*a[k]*a[r])
        
        ans = 0
        for start in range(n):
            ans = max(ans, dp[start][start+n-1])
        print(ans)
```代码首先复制数组`a`处理圆形段，然后填充 DP 表中的所有段长度。 嵌套循环通过选择中间顶点来计算每个段的最大乘积和`k`。 最后，它在多边形的所有旋转版本中选择最大分数。
