 ## 解决方案
 ## 问题理解

 我们在二维整数网格上绘制了几个圆圈。 每个圆的中心都在 x 轴上，因此每个中心都有以下形式的坐标$(x_i, 0)$，每个圆都有一个半径$r_i$。 任务是统计有多少个整数格点$(x, y)$至少位于其中一个圆内，包括边界上的点。 

点属于圆的几何条件是标准欧氏距离：点对圆有效$i$如果$(x - x_i)^2 + y^2 \le r_i^2$。 我们必须取所有这些圆的并集并计算该并集中的整数点。 

约束结构是关键信号。 所有测试用例的半径总和最多为$2 \cdot 10^5$，这意味着虽然可能有很多圆，但它们的总“垂直高度贡献”是有界的。 这立即表明，只要每个半径单位被处理一次或恒定次数，迭代所有圆的所有垂直层是可行的。 

检查大边界框中每个整数点的简单方法很快就会失败。 即使是一个有半径的圆$10^9$跨越巨大的 x 范围，使得强力网格扫描变得不可能。 

当圆圈严重重叠时，会出现更微妙的失败情况。 例如，如果许多圆共享同一中心，则重复计算就会产生风险，除非按 x 坐标仔细合并覆盖范围。 

## 方法

 直接的暴力方法会迭代每个圆，然后迭代每个整数$x$在其水平跨度中，计算可能的最大值$y$使用$y = \lfloor \sqrt{r_i^2 - (x - x_i)^2} \rfloor$，并标记所有点$(x, y)$在一组中。 这在原则上是正确的，但生成的点的数量可以与所有圆的总面积成正比。 单个半径的圆$r$已经做出贡献$O(r^2)$点，当半径很大时，这变得完全不可行。 

关键的观察结果是圆以 x 轴为中心。 这意味着我们可以逐列分解问题。 对于固定整数$x$，每个圆贡献一个垂直间隔$[-h, h]$， 在哪里$h = \lfloor \sqrt{r_i^2 - (x - x_i)^2} \rfloor$。 该 x 坐标处所有圆的并集成为一条线上垂直线段的并集。 

我们不是跟踪单个点，而是计算每个 x 的整数 y 值。 问题归结为对任何圆覆盖的所有整数 x 列求和，合并重叠后该列中覆盖的整数 y 值的数量。 

由于每个半径单位总共只在所有圆上贡献 O(1) 个不同的 x 列（因为半径为 r 的每个圆跨越 2r+1 个 x 值，并且 r 的总和为 m），因此我们可以迭代每个圆并处理它覆盖的每个 x。 

在每个 x 处，我们计算相应的高度间隔并获取该列贡献的最大 y 范围。 为了避免圆之间的重复计算，我们使用字典汇总每个 x 的贡献，并保留最大半径导出的高度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(\sum r_i^2)$|$O(\sum r_i^2)$| 太慢了|
 | 最佳 |$O(m)$|$O(m)$| 已接受 |

 ## 算法演练

 1. 对于每个测试用例，创建一个映射`best[x]`存储坐标 x 处的最大垂直半径贡献。 

这是必要的，因为多个圆可能覆盖相同的 x，并且只有最大的垂直跨度对于计算 y 点很重要。 
2. 对于每个以$x_i$有半径$r_i$，迭代所有整数偏移量$dx$从$-r_i$到$r_i$。 

这枚举了圆的水平投影内的每个整数 x 坐标。 
3. 对于每个$dx$，计算实际的 x 位置$x = x_i + dx$，并计算该切片的最大高度：$$h = \left\lfloor \sqrt{r_i^2 - dx^2} \right\rfloor$$这直接来自于重新排列圆方程。 
4. 更新`best[x] = max(best[x], h)`。 

我们只关心每个 x 处的最大垂直范围，因为较小的圆圈完全包含在该切片处的较大圆圈内。 
5. 处理完所有圆后，迭代所有存储的 x 值`best`。 对于每个 x，添加$2 \cdot h + 1$到答案，因为整数 y 值的范围是$-h$到$h$。 
6. 输出累加和。 

### 为什么它有效

 对于每个固定整数 x，满足至少一个圆约束的点集形成以 y = 0 为中心的垂直间隔的并集。因为所有圆都以 x 轴为中心，所以这些间隔是对称的并按高度嵌套。 因此，联合折叠为单个区间，其边界仅由该 x 处的最大半径导出高度确定。 该算法通过仅存储每个 x 坐标的最大高度来保留此不变性，确保不会重复计算重叠并且不会遗漏任何有效点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        xs = list(map(int, input().split()))
        rs = list(map(int, input().split()))

        best = {}

        for x0, r in zip(xs, rs):
            r2 = r * r
            for dx in range(-r, r + 1):
                x = x0 + dx
                y2 = r2 - dx * dx
                h = int(y2 ** 0.5)
                if x in best:
                    if h > best[x]:
                        best[x] = h
                else:
                    best[x] = h

        ans = 0
        for h in best.values():
            ans += 2 * h + 1

        print(ans)

if __name__ == "__main__":
    solve()
```该代码通过扫描整数 x 跨度来处理每个圆。 平方根计算确定该切片的垂直范围，并且仅存储最大值可确保正确合并重叠。 最终求和将每个垂直跨度转换为其精确的整数格点数量。 

一个微妙的点是整数平方根。 在这里使用浮点平方根是安全的，因为半径总体上足够小，但在更严格的设置中，可以用整数安全的 sqrt 替换它，以避免接近完美平方的精度边缘情况。

 ## 边缘情况

 一个微妙的边缘情况是完全遏制。 如果一个小圆在相同的 x 范围内完全位于一个较大的圆内，则圆上的简单联合可能会重复计算垂直切片。 该算法通过仅存储每个 x 的最大高度来避免这种情况。 例如，对于以半径为 1 和 5 的同一点为中心的圆，每个 x 切片均由半径为 5 的圆主导，并且较小的圆永远不会独立做出贡献。 

另一种边缘情况是圆几乎没有在一个点上接触。 在该 x 坐标处，两个圆都产生有效高度，但同样只有最大值才是重要的，并且共享边界点仅计算一次$2h+1$对称。 

最后一种情况是中心相距很远的极度稀疏。 即使如此，字典仍然很小，因为它只包含某个圆实际达到的 x 值，并且每个圆都准确贡献$2r_i+1$这样的位置，尊重总半径的全局限制。
