 ## 解决方案
 ## 问题理解

 我们得到一个固定的无限四叉树结构，其中每个节点代表一个轴对齐的正方形，其边长是 2 的幂，并且其坐标与相同的比例对齐。 每个节点都精确对应一个这样的方块，并且每个方块都递归地分为四个相等的子方块。 

对于每个测试用例，我们在平面上给出一个具有整数坐标的矩形区域。 任务是将这个矩形精确地表示为四叉树节点的并集，并最小化所需的节点数量。 

关键的限制是我们不能选择任意的矩形。 每个选定的棋子必须是规范四叉树正方形之一。 这立即将问题转变为固定分层网格上的几何分解任务，而不是自由平铺问题。 

约束条件测试用例数量较多，可达一万个，但坐标范围最多只有一百万个。 这种组合表明每个测试必须以坐标大小的对数时间运行，因为在所有测试用例中，几何上的线性扫描都太慢。 任何在每次测试中探索四叉树大部分的解决方案都必须仔细确保访问的节点总数与最终答案保持比例。 

当矩形边界未与任何四叉树单元对齐时，会出现微妙的边缘情况。 在这种情况下，尝试从一个角开始获取最大正方形的天真贪婪策略通常会失败，因为它要么在区域之外重叠，要么留下未覆盖的间隙，从而迫使过度分裂。 另一个常见错误是尝试独立分解 x 和 y，这忽略了四叉树节点是正方形而不是矩形的事实。 

## 方法

 暴力方法将直接模拟四叉树。 从覆盖整个坐标空间的根节点开始，我们递归地决定每个节点是否完全在目标矩形内部、完全在目标矩形外部或部分重叠。 如果完全在里面，则将其视为一个节点； 如果部分重叠，我们分成四个孩子继续。 

这种方法是正确的，因为它尊重四叉树节点的精确定义。 然而，在最坏的情况下，矩形与四叉树网格非常“不对齐”，递归可能会深入下降并探索许多节点。 尽管总坐标深度只有大约二十级，但如果进行不必要的重新计算或无法正确修剪，跨许多测试用例的重复分支仍然会使幼稚的实现面临风险。 

关键的观察是，每当一个节点完全包含在矩形中时，我们应该立即停止并将其计为 1。 这是最优的，因为用其子节点替换完整节点只能增加使用的节点数量。 相反，如果一个节点不相交，我们立即丢弃它。 该结构保证我们永远不需要探索与矩形边界相交的节点之外的节点。 

这将问题转化为固定树上的有界 DFS，其中每个测试用例最多访问每个节点一次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 完整的四叉树模拟 | O(访问的节点数) 最坏情况大常量 | O(深度) | 最坏情况下执行速度太慢 |
 | 剪枝四叉树 DFS | O(答案·log C) | O(log C) | 已接受 |

 ## 算法演练

 我们从概念上将坐标平面嵌入到一个完整的四叉树中，该四叉树以足够大的正方形为根，足以覆盖输入中的所有坐标。 一个方便的选择是边长为 2^20 的正方形，因为 10^6 可以轻松放入其中。

1. 我们从覆盖整个空间的根正方形开始。 
2. 对于每个当前方形节点，我们检查其与查询矩形的关系。 如果节点完全位于矩形之外，我们将丢弃它。 这避免了浪费时间探索不相关的区域。 
3. 如果该节点完全位于矩形内部，我们将该节点作为答案的一部分，并在该节点处停止递归。 这是最佳的，因为与进一步分割相比，使用较大的节点可以减少节点总数。 
4. 如果节点与矩形部分重叠，我们将其分成四个相等的象限，并对每个子节点进行递归。 
5. 最终的答案是在此过程中完全包含在矩形中的节点总数。 

关键决策是第 3 步。一旦完全包含某个节点，最好立即采取该节点，因为任何进一步的分解都会增加所选节点的数量，而不会提高覆盖范围。 

### 为什么它有效

 四叉树形成平面的分层分区，其中每个节点恰好是其四个子节点的并集。 这意味着矩形的任何有效表示都可以转换为完全包含在矩形中的一组最大四叉树节点。 用节点本身替换完全覆盖节点的任何后代集可以严格减少或保留节点的数量。 因此，采用最大完全包含节点的贪婪选择保证了最小性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXB = 20
SIZE = 1 << MAXB

def solve():
    l1, r1, l2, r2 = map(int, input().split())
    
    def dfs(x1, x2, y1, y2, lx, rx, ly, ry):
        if x2 <= lx or rx <= x1 or y2 <= ly or ry <= y1:
            return 0
        if lx >= x1 and rx <= x2 and ly >= y1 and ry <= y2:
            return 1
        
        mx = (lx + rx) >> 1
        my = (ly + ry) >> 1
        
        return (
            dfs(x1, x2, y1, y2, lx, mx, ly, my) +
            dfs(x1, x2, y1, y2, mx, rx, ly, my) +
            dfs(x1, x2, y1, y2, lx, mx, my, ry) +
            dfs(x1, x2, y1, y2, mx, rx, my, ry)
        )

    print(dfs(l1, r1, l2, r2, 0, SIZE, 0, SIZE))

t = int(input())
for _ in range(t):
    solve()
```该解决方案在范围内隐式构建固定四叉树`[0, 2^20)`在两个维度上。 每个递归调用处理一个方形节点。 该逻辑仔细区分了三种情况：无交叉、完全包含和部分重叠。 

一个常见的实现陷阱是混合包含和排除边界。 这里所有间隔都被视为半开，这可以保持分裂干净并避免边界处的差一问题。 

另一个微妙的点是，我们从不尝试通过在递归后合并兄弟节点来“优化”。 这是不必要的，因为 DFS 已经保证我们只计算最大的完全包含的四叉树节点。

 ### 示例 1

 输入矩形是`[0,1] × [1,2]`。 根正方形部分相交，因此我们将其分割，直到达到单位正方形。 只有一个叶节点完全匹配。

### 示例 2

 输入矩形是`[1,3] × [1,3]`。 没有更大的四叉树方块与该区域对齐，因此 DFS 不断分裂，直到达到四个单位方块。 

| 节点范围 | 关系 | 行动|
 | --- | --- | --- |
 | [1,3]×[1,3] | 部分 | 分裂|
 | 四个 1×1 节点 | 里面满了| 全部 4 个 |

 这演示了最坏的情况，其中答案等于区域中单位单元的数量，并且算法正确地退回到叶级分解。

 ## 边缘情况

 边界对齐的矩形，例如`[0,2] × [0,2]`通过立即合并到更高级别的单个四叉树节点来处理，因为 DFS 尽早发现完全包含并避免不必要的分裂。 

完全未对齐的矩形，例如`[1,3] × [1,3]`强制完全分解为单位方块，算法在计算叶子之前正确到达最深层次，确保不遗漏覆盖和不过度合并。
