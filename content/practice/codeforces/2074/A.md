 ## 解决方案
 ## 问题理解

 我们在平面上有四个固定点。 它们的坐标始终与轴对齐：其中一个位于负 x 轴上$(-l, 0)$，x 轴正方向上的一个$(r, 0)$，负 y 轴上的一个$(0, -d)$，以及 y 轴正方向上的一个$(0, u)$。 每个测试用例中唯一的自由度是四个距离$l, r, d, u$。 

任务是确定这四个点按某种顺序连接时是否可以作为某个正方形的顶点。 我们不允许移动积分； 我们只能决定是否存在形成无自交正方形的有效排序。 

每个测试用例的约束非常小，每个值都在 1 到 10 之间，但最多可以有$10^4$测试用例。 这促使我们对每个案例进行恒定的时间检查。 任何尝试点顺序排列的方法在理论上仍然是可以接受的，因为只有 24 种排列，但是在许多测试用例中重复进行几何检查会使直接的暴力破解变得不够干净。 

一个微妙的边缘情况来自于这些点不是任意的这一事实。 它们总是在轴上，因此几何形状受到严格限制。 天真的直觉可能是“如果所有四个距离都相等，则它始终是一个正方形”，但这还不够，除非我们还确保这些点实际上可以按正方形顺序连接而不会交叉边缘。 

例如，如果$l = r = d = u = 2$，我们显然可以形成一个以原点为中心的旋转正方形。 但是，如果一侧较大，则说$l = 1, r = 2, d = 3, u = 4$，这些点在每个方向上的拉伸程度不同，并且没有刚性正方形可以连接它们。 

关键的隐藏要求是对称性：以原点为中心、边与对角线平行的正方形需要在所有四个方向上具有相等的延伸。 

## 方法

 强力方法将尝试考虑四个给定点的所有排列，并检查任何排序是否形成有效的正方形。 对于每个排列，我们将计算四个边长并验证相等性，并确保对角线匹配并且形状是非自相交的。 由于每个测试用例有 24 种排列，最多$10^4$测试用例，这产生了大约$2.4 \times 10^5$检查，这已经很好了，但是对于这种受约束的配置，每个排列的几何验证是不必要的开销。 

关键的观察结果是，这四个点已经固定在轴上，并且由它们形成的任何正方形必须以原点为中心。 这是因为在使用这些轴对齐极值的任何正方形中，相对的点对称地分布在两个轴上。 

对于以原点为中心的正方形，顶点必须位于$(\pm a, 0)$和$(0, \pm a)$在此特定配置中旋转 45 度或对齐后。 在此问题中，由于点严格轴对齐，因此唯一可能的正方形是距原点的所有四个距离都相等的正方形。 这意味着$l = r = d = u$。 

因此整个问题简化为一次相等性检查。

 ## 算法演练

 我们独立处理每个测试用例并直接比较四个值。 

1. 阅读$l, r, d, u$。 这些表示每个点沿轴距离原点有多远。 这完全决定了几何形状。 
2. 检查四个值是否相等。 此条件强制在所有四个方向上完美对称，这是以原点为中心的正方形所必需的。 
3. 如果相等，则输出“Yes”，否则输出“No”。 

### 为什么它有效

 正方形的所有顶点与其中心的距离相等。 在此配置中，唯一可能的中心是原点，因为每个点都位于其中一个轴上。 要使形状成为正方形，所有四个顶点必须沿垂直方向距中心的半径相等。 给定的结构将这些方向固定到轴本身，因此保持相等边长和直角的唯一方法是使距原点的所有四个距离精确匹配。 任何不平衡都会导致边缘不相等或四边形扭曲而无法满足方形约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    l, r, d, u = map(int, input().split())
    if l == r == d == u:
        print("Yes")
    else:
        print("No")
```解决方案是直接实现对称条件。 链式相等检查确保所有四个方向都相同，这是唯一有效的配置。 

不需要额外的数据结构或几何计算，因为输入已经编码了完整的空间约束。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(sys.stdin.readline())
    out = []
    for _ in range(t):
        l, r, d, u = map(int, sys.stdin.readline().split())
        out.append("Yes" if l == r == d == u else "No")
    return "\n".join(out)

 ## 边缘情况

 一种边缘情况是三个值相等且其中一个值略有不同，例如$l = r = d = 5, u = 4$。 该算法正确地输出“否”，因为相等性检查立即失败。 从几何角度来看，这会拉伸一个轴并破坏旋转对称性。 

另一种情况是两个相反的方向不同但另一对匹配，例如$l = r = 7, d = u = 3$。 尽管两个轴独立对称，但轴之间的不匹配会阻止形成正方形，因为边长会根据方向而不同。 

最后，在完全平等的情况下，例如$l = r = d = u = 1$，检查通过并且配置对应于完美居中的正方形。
