 ## 解决方案
 ## 问题理解

 我们给定一个二进制字符串，并希望将其转换为排序顺序，这对于二进制字符串意味着所有`0`s出现在所有之前`1`s。 

一个操作允许我们选择一个其值不增加的子序列。 由于字符串只包含`0`和`1`，这样的子序列只能看起来像一些`1`s 后面跟着一些`0`s。 然后我们就地反转所选的子序列。 

该任务不仅是确定最小操作数，而且是输出实现该最小数的有效操作序列。 

限制非常小。 所有字符串的总长度最多为 1000，因此即使每个测试用例的二次工作也是可以接受的。 真正的挑战是发现操作的结构。 

一个微妙的点是我们正在处理子序列，而不是子字符串。 所选位置不必是连续的。 

考虑字符串`0011111`。 已经排序了。 任何始终执行操作的解决方案都是不正确的，因为最小操作数为零。 

考虑`10100`。 错位的字符是最左边的`1`应该向右移动并且最右边`0`应该向左移动。 交换相邻字符的简单策略是可行的，但不会尊重问题中定义的操作。 

考虑`111000`。 该字符串远未排序，但仔细选择的单个操作就足够了。 忽略这一观察会导致解决方案使用不必要的许多操作。 

## 方法

 蛮力的观点是考虑反复修复反转。 反转是一对，其中`1`出现在 a 之前`0`。 人们可以尝试移动字符，直到字符串排序。 这种方法是不必要的，并且不会利用操作的特殊结构。 

关键的观察来自于检查二进制字符串中有效子序列的样子。 由于子序列必须是非递增的，因此它可以包含任意集合`1`s 以及任何集合`0`稍后出现。 当该子序列反转时，每个选择的`1`向右侧移动，每一个选择`0`向左侧移动。 

现在将字符串与其排序版本进行比较。 当前字符串包含的每个位置`1`但排序后的字符串包含`0`是一个放错地方的`1`。 类似地，当前字符串包含的每个位置`0`但排序后的字符串包含`1`是一个放错地方的`0`。 

都错位了`1`s发生在所有错位之前`0`s。 如果我们将这些位置精确地收集到一个子序列中，那么该子序列由一些`1`s 后面跟着一些`0`s，满足运行要求。 反转它会将每个选定的字符立即放置到正确的位置。 

这意味着每个未排序的字符串都可以通过一次操作来修复。 如果字符串已经排序，我们需要零操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 模拟反转修复 | O(n²) | O(n) | 不必要|
 | 与排序字符串比较 | O(n log n) | O(n log n) | O(n) | 已接受 |

 由于字母表只是`{0,1}`，甚至排序步骤也可以用计数零来代替，但是排序的标准实现已经足够快了。 

## 算法演练

 1. 对于当前字符串，创建其排序版本。 
2. 查找原始字符串与已排序字符串不同的每个索引。 
3. 存储所有此类索引。 
4. 如果没有不同的索引，则字符串已经排序。 输出`0`。 
5.否则，输出`1`因为一次操作就足够了。 
6. 将收集到的索引输出为所选子序列。 

第 6 步有效的原因是左侧每个不匹配的位置都会贡献一个`1`必须向右移动，而右侧每个不匹配的位置都会贡献一个`0`必须向左移动。 因此，收集到的子序列是一个序列`1`s 后面跟着`0`s，对操作有效。 

### 为什么它有效

 让`t`是字符串的排序版本。 

每当`s[i] != t[i]`, 位置处的字符`i`必须参与任何成功的转型。 由于数量`0`沙`1`s 不变，不匹配的位置自然分为两组：包含额外的位置`1`s 和包含额外内容的位置`0`s。 

全部额外`1`在所有额外的事情之前撒谎`0`s。 因此，不匹配位置的字符形成非递增子序列。 反转该子序列会交换两个组，并将每个不匹配的位置放入其正确的值中。 反转后，整个字符串变为等于`t`。 

因此，每当字符串尚未排序时，一次操作就足够了，而当字符串已经排序时，则需要零次操作。 这是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        s = input().strip()

        target = ''.join(sorted(s))

        pos = []
        for i in range(n):
            if s[i] != target[i]:
                pos.append(i + 1)

        if not pos:
            print(0)
        else:
            print(1)
            print(len(pos), *pos)

solve()
```该解决方案首先构建排序后的目标字符串。 必须纠正原始字符串与目标字符串不同的每个位置。 这些位置正是单个操作中使用的索引。 

索引按递增顺序打印，这是必需的，因为它们形成子序列。 该问题使用基于 1 的索引，因此每个位置都报告为`i + 1`。 

最常见的实现错误是忘记基于 1 的转换。 另一个常见错误是尝试输出多个操作，即使一个操作对于每个未排序的二进制字符串始终足够。

import sys
import io

def run(inp: str) -> str:

    t = int(input())
    out = []

    for _ in range(t):

        else:
            out.append("1")

 ## 边缘情况

 考虑输入`1`后面跟着字符串`0`。 排序后的版本是相同的，因此不匹配集为空。 该算法立即输出零操作。 

考虑字符串`111000`。 排序后的版本是`000111`。 每个位置都不同，因此选择所有六个索引。 所选择的子序列是`1 1 1 0 0 0`，这是非增加的。 将其反转直接产生排序后的字符串。 

考虑字符串`001011`。 排序后的版本是`000111`。 不匹配仅发生在中间位置。 准确选择这些位置可以避免接触已经正确的字符，并且一次反转可以完全修复字符串。 

这些情况说明了中心不变量：不匹配位置始终形成有效的非递增子序列，并且反转该子序列可以同时解决每个不匹配。
