 ## 解决方案
 ## 问题理解

 该问题要求我们确定一个简单投票场景的结果。 选民分为三类：一些人保证投赞成票，一些人保证投反对票，还有一些人尚未决定。 输入给出每组的计数。 目标是预测投票的最终结果：正面、负面、中立或不确定。 如果赞成票严格超过反对票，则结果为积极；如果反对票严格超过赞成票，则为消极结果；如果相等，则为中立；不确定未知选民是否可以根据他们的投票方式改变结果。 

约束非常小：每次计数最多为 100，因此投票者总数最多为 300。这使我们能够推理所有可能性，而不必担心效率。 小范围内的迭代不存在性能问题，但我们仍然应该通过分析可能的投票总数范围来寻求恒定时间的解决方案。 

非明显的边缘情况包括未知选票可能翻转结果的情况。 例如，如果赞成票和反对票相等，并且至少有一名未知选民，则结果是不确定的，因为一票就可能打破平衡。 另一种边缘情况是，即使将所有未知票数分配给另一方（例如 10 个赞成票、2 个反对票和 3 个未知票），一方仍占主导地位。 在这里，结果肯定是积极的，即使所有未知的选票都投了反对票。 

## 方法

 暴力方法会考虑未知选民投票的所有方式。 如果有`z`未知的选民，有`z+1`在赞成票和反对票之间分配它们的方法。 对于每个分布，我们计算最终结果。 如果所有结果都相同，则为最终结果； 否则，结果是不确定的。 这有效是因为`z`最多 100，所以我们最多计算 101 种可能性。 虽然这个问题在实践中是可行的，但没有必要并且可以简化。 

关键的观察是我们只需要赞成票和反对票之间的最小和最大可能差异。 如果所有未知选民都投反对票，则差异最小；如果全部投票赞成，则差异最大。 如果两个极端给出相同的符号，则结果确定。 否则，是不确定的。 这将问题简化为几次比较，从而产生 O(1) 解决方案。

 ## 算法演练

 1. 读取代表保证赞成票的三个整数`x`，保证投反对票`y`，以及未知的选票`z`。 
2. 计算最大可能的净投票差异为`x + z - y`，假设所有未知的投票都是赞成票。 
3. 计算最小可能的净投票差异为`x - (y + z)`，假设所有未知的投票都是反对票。 
4. 如果最大值和最小值都严格为正数，则打印“+”，因为即使在最坏的情况下，赞成票也会超过反对票。 
5. 如果最大值和最小值都严格为负数，则打印“-”，因为在未知投票的所有可能分配中，否决票占主导地位。 
6. 如果最大值和最小值都为零，则打印“0”，因为无论未知票数，票数都是平局。 
7. 否则，打印“？”，表示未知投票的不同分配可能会产生不同的结果，使得结果不确定。 

为什么有效：通过仅考虑极端情况，我们可以捕获所有可能的结果。 任何未知选票的分布都会产生这两个极端之间的结果。 如果两个极端导致相同的结果，则所有中间分布也会导致相同的结果。 如果极端情况产生不同的结果，则存在产生每个结果的某些分配，这意味着不确定性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

x, y, z = map(int, input().split())

max_diff = x + z - y
min_diff = x - (y + z)

if min_diff > 0:
    print("+")
elif max_diff < 0:
    print("-")
elif min_diff <= 0 <= max_diff and max_diff == 0 and min_diff == 0:
    print("0")
else:
    print("?")
```该代码读取投票计数并计算极端投票差异，然后根据这些极端情况决定结果。 微妙之处在于仔细处理零情况：如果两个极端都恰好为零，则结果是中性的。 否则，如果极值跨越零，结果是不确定的。 不需要循环或额外的数据结构。

 ## 边缘情况

 当未知的选票可以改变结果时，比如`1 0 1`，算法正确计算`max_diff = 2`和`min_diff = 0`。 由于极端值并不都是严格的正值、负值或恰好为零，因此输出为“？”，捕获不确定性。 

当所有投票都已知且平衡时，例如`2 2 0`，两个极值均为零，输出为“0”。 

当一方在票数未知的情况下仍占主导地位时，例如`10 2 3`，极端情况是`11`和`5`，都是积极的，因此算法打印“+”，正确确认了赞成票的主导地位。
