 ## 解决方案
 ## 问题理解

 我们被要求将编号为 1 到 n 的棋子放置在 m × m 的网格上。 每个棋子 i 都放置在具有整数坐标的单元格中。 该约束将几何图形与索引联系起来：对于任意两个块 i 和 j，它们位置之间的曼哈顿距离必须至少是它们标签的绝对差。 

因此，如果两个棋子的编号接近，则它们在棋盘上可以接近，但如果它们的索引相距很远，则它们在物理上也必须很远。 任务不仅是检查可行性，而且是构建一种在尽可能最小的方板上工作的布置。 

输入只是n，即件数。 输出首先是可能的最小边长 m，然后是所有块 1 到 n 的坐标。 

约束 n ≤ 1000 意味着如果在各种可能性中重复，每个候选板尺寸的立方或更差的构造已经太慢了，但真正的限制是概念性的：我们必须导出最佳 m 的直接构造，而不是测试板。 

天真的思维的一个微妙的失败案例是假设只考虑相邻索引的贪婪布局。 例如，像 (i, 1) 这样将棋子放置在一条直线上会失败，因为对于索引上相距较远但空间上相距较远的棋子对来说，一个方向上的距离不够。 另一个错误是尝试随机或螺旋放置，但不能保证每对都满足全局不等式，因为条件对所有对都是二次的。 

关键的困难在于该条件将索引差异与曼哈顿距离耦合，这表明索引顺序应与单调几何路径对齐。 

## 方法

 一个蛮力的想法是固定棋盘尺寸 m 并尝试放置所有 n 个点，同时检查每对的约束。 对于给定的排列，这是 O(n²)，如果我们还搜索 m 或尝试通过回溯构造布局，状态空间就会呈指数增长。 即使检查单个候选排列对于 n 最多 1000 个也是可以管理的，但生成一个候选排列才是真正的问题。 

关键的观察结果是条件仅取决于 |i − j| 在右侧。 这强烈建议对点进行排列，使得索引的每次增量使点在曼哈顿距离中最多移动 1，因为这样任意两个点 i 和 j 都满足链上的三角不等式：

 距离(i, j) ≥ 步距之和 ≥ |i − j| 如果每一步贡献恰好为 1。 

因此，我们想要一条穿过网格单元的路径，该路径访问 n 个位置，其中连续位置的曼哈顿距离恰好为 1。如果我们这样做，那么在 i 和 j 之间，网格内的最短路径给出的距离至少为 j − i，因为我们沿着路径每一步至少累积 1。 

这将问题简化为在网格上嵌入长度为 n 的简单路径，同时最小化边界框。 打包此类路径的最紧凑方法是蜿蜒穿过行：从左到右，然后从右到左，每次向下移动一行。 这将创建一个类似哈密顿路径的矩形遍历。 

为了最小化 m，我们需要足够的单元来容纳 n 个位置，因此 m 必须满足 m² ≥ n。 事实证明这已经足够了，因为在 m × m 网格上的蛇遍历会访问所有 m² 单元并保留所需的步骤属性。 

因此答案是 m = ⌈√n⌉，我们只需以交替方向逐行填充网格即可。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数/O(n²) 检查 | O(n) | 太慢了 |
 | 最佳| O(n) | O(1) 额外（不包括输出） | 已接受 |

 ## 算法演练

1. 计算最小整数 m，使得 m × m 至少为 n。 这确保了我们有足够的单元格来放置所有的棋子。 
2. 将棋子按行优先遍历网格，但每行方向交替。 在偶数行上从左到右，在奇数行上从右到左。 
3. 将片段 i 分配给本次遍历中第 i 个访问过的单元格。 
4.放置n块后停止，忽略剩余的单元格。 

交替方向确保连续索引始终在相邻单元格之间移动，无论是水平移动还是在行边界处垂直移动。 这保证了索引中的每一步对应的曼哈顿距离恰好为 1。 

### 为什么它有效

 考虑任何连续的索引 i 和 i+1。 通过构造，它们在蛇形路径中相邻，因此它们的曼哈顿距离恰好为 1。对于任何对 i < j，它们之间沿序列的任何路径都由 j − i 个这样的单位步骤组成。 根据三角不等式，端点之间的曼哈顿距离至少为步距之和，因此至少为 j − i。 这与所要求的条件完全匹配，因此构造是有效的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

m = 1
while m * m < n:
    m += 1

coords = []

for r in range(m):
    if len(coords) >= n:
        break
    if r % 2 == 0:
        for c in range(m):
            coords.append((r + 1, c + 1))
            if len(coords) == n:
                break
    else:
        for c in range(m - 1, -1, -1):
            coords.append((r + 1, c + 1))
            if len(coords) == n:
                break

print(m)
for r, c in coords:
    print(r, c)
```m 的计算确保了最小的网格尺寸。 遍历在 m × m 网格上构建哈密顿路径，并在 n 步后将其截断。 行奇偶校验开关至关重要，因为如果没有它，行端点之间的垂直跳跃将会太大。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input())
    m = 1
    while m * m < n:
        m += 1

    coords = []
    for r in range(m):
        if len(coords) >= n:
            break
        if r % 2 == 0:
            for c in range(m):
                coords.append((r + 1, c + 1))
                if len(coords) == n:
                    break
        else:
            for c in range(m - 1, -1, -1):
                coords.append((r + 1, c + 1))
                if len(coords) == n:
                    break

    out = [str(m)]
    out += [f"{r} {c}" for r, c in coords]
    return "\n".join(out)

 ## 边缘情况

 当 n = 1 时，算法设置 m = 1 并输出单个单元格 (1, 1)。 没有任何对违反约束，因此该构造是非常有效的。 

对于 n = m²，遍历会填充整个网格。 每个相邻对仍然由单位曼哈顿步连接，并且所有较长的距离都由这些步的串联覆盖，因此不等式适用于所有对。 

对于刚好高于完美平方的 n，例如 10，我们移动到 m = 4 并部分填充最后一行。 路径属性不依赖于网格的完整性，只依赖于连续的邻接，因此截断不会破坏正确性。
