 ## 解决方案
 ## 问题理解

 在这个问题中，我们有两支足球队正在进行一场比赛。 每支球队一开始都有一定数量的球员，用`a1`和`a2`。 整场比赛，裁判显示`n`给球员出黄牌。 每支球队都有黄牌阈值：一线队球员如果收到黄牌就会被罚下场`k1`黄牌，第二队一名球员被罚下场`k2`黄牌。 裁判丢失了哪些球员收到牌的记录，我们需要在仅给出总数的情况下确定可能被罚下场的球员的最小和最大人数。 

输入代表球员的数量、他们的个人黄牌限制以及所显示的黄牌总数。 输出是两个整数：被罚下场的最小可能人数和可能被罚下的最大人数。 

约束很小：所有值最大为 1000。这允许采用直接数学方法，而无需担心性能，因为这些范围上的操作的计算成本可以忽略不计。 当黄牌数量小于球员阈值总和时，就会出现一个重要的边缘情况。 在这种情况下，有可能没有球员被罚下场。 另一种极端情况是，黄牌总数超过了在不导致最大罚牌数的情况下可以分配的黄牌数量； 最多送别人数不能超过参赛选手总数。 

一种幼稚的方法可能会尝试模拟将每张黄牌分发给各个玩家，但仔细计数足以解决这个问题，而无需迭代所有牌。 

## 方法

 蛮力方法将迭代每个`n`黄牌，按一定顺序将黄牌分配给球员，并计算有多少人被罚下场。 这原则上是有效的，但是`n`最多`a1*k1 + a2*k2`在最坏的情况下可能是 1,000,000，因此没有必要逐卡迭代。 模拟是正确的，但冗长且低效。 

关键的见解是根据阈值而不是单独的卡分配进行推理。 对于被罚下场的最少玩家数量，我们希望尽可能均匀地分布牌，以便在必要时没有玩家达到罚下阈值。 如果黄牌总数少于`a1*(k1-1) + a2*(k2-1)`，我们可以避免送走任何人。 否则，最小数量就是超出安全分配范围的多余卡牌。 为了最大化，我们首先将牌集中在门槛最小的玩家身上，并尽可能多地送走。 这将问题简化为简单的算术。

 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 对于大型来说太慢`n`|

 ## 算法演练

 1. 计算在不送走任何人的情况下可以提供的最大安全卡片数量：`(a1*(k1-1) + a2*(k2-1))`。 这意味着给每个球员比他们的送出门槛少一个。 从总数中减去这个`n`找出必须被罚下场的最少球员人数。 如果结果为负，请将其设置为零，因为送别人数不能少于零。 
2. 对于最多被罚下的玩家数量，我们希望先贪婪地向阈值最低的玩家分发牌。 计算如果我们以最佳方式发放卡片以实现最多的送别，则每个团队可以有多少次送别。 这简直就是`min(a1, n // k1)`对于一线队和`min(a2, n // k2)`对于第二个团队，将两者相加。 这里`//`是整数除法，表示每个团队可以达到的完整阈值的数量。 
3. 返回计算出的最小和最大数字作为答案。 

为什么有效：该算法之所以有效，是因为最小和最大数量完全由阈值总和和黄牌总数决定。 分散牌或集中牌不需要跟踪单个玩家； 总数就足够了。 我们使用的属性，即每个玩家可以吸收的属性`k1-1`或者`k2-1`安全地刷卡`n // k`代表圆满送别，保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a1 = int(input())
a2 = int(input())
k1 = int(input())
k2 = int(input())
n = int(input())

# Minimum number of players sent off
safe_cards = a1 * (k1 - 1) + a2 * (k2 - 1)
min_sent_off = max(0, n - safe_cards)

# Maximum number of players sent off
max_sent_off = min(a1, n // k1) + min(a2, n // k2)

print(min_sent_off, max_sent_off)
```在这个解决方案中，我们首先计算卡片的安全分配以实现最小计算。 对于最大值，整数除法很快就能告诉我们每个团队可以吸收多少个完整阈值。 边缘处理，如负最小值，是通过`max(0, ...)`。 不需要循环，因此性能是常数时间。
