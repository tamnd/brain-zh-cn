 ## 解决方案
 ## 问题理解

 我们被要求考虑一个由行星组成的宇宙，每个行星都由一个脆弱区间定义`[l_i, r_i]`。 如果一组行星的间隔至少在一个点上重叠，则它们可以同时被摧毁。 此外，我们可以将行星的间隔向左或向右扩展一个单位，每次扩展的成本为一个单位。 任务是计算每个非空行星子集使间隔相交所需的最小展开次数，然后将这些分数取模求和`998244353`。 

输入提供高达`5000`多个测试用例中的行星总数，其中`n`最多`5000`每个测试用例。 这立即排除了显式枚举所有子集的天真的方法，因为最多有`2^5000`子集，远远超出了计算可行性。 每个区间的界限都是整数`[1, n]`，因此我们可以考虑在离散位置而不是任意连续间隔上使用动态规划或组合方法。 

一个幼稚的错误可能来自于假设重叠间隔总是可以通过取最小左值和最大右值来简单地对齐。 例如，如果我们有间隔`[1,1]`,`[3,3]`，它们的交集是空的。 必须仔细计算需要多少次展开才能在一个公共点相遇； 仅仅考虑集合的最外层点是不够的。 

## 方法

 蛮力方法将迭代所有`2^n - 1`非空子集。 对于每个子集，我们可以尝试对齐间隔来找到最小扩展。 对于大小的子集`k`，我们需要评估对齐每个候选点的间隔的成本`[1, n]`。 这种方法大约需要`O(n * 2^n)`仅仅为了考虑扩展而进行操作，即使对于`n = 20`。 

The key insight is that the number of expansions for a subset is determined by choosing a single meeting point`x`在`[1, n]`。 对于每个行星，将其包含在内的成本为`x`是`max(0, l_i - x, x - r_i)`。 然后，子集的最小成本是所有候选者中的最小值`x`。 这类似于组合优化中的“与中值对齐”。 

我们可以计算有多少子集具有对给定总扩展做出贡献的给定多重间隔集，而不是枚举子集。 通过使用动态规划，我们可以定义`dp[i][j]`作为从第一个中选择子集的方法数量`i`行星的总膨胀为`j`。 我们迭代行星并更新`dp`对于每种可能的扩展成本，使用前缀和来提高效率。 这将指数子集枚举减少为`O(n^2)`每个测试用例，因为每个行星最多与离散范围的扩张成本相互作用`n`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 2^n) | O(n * 2^n) | O(2^n) | O(2^n) | 太慢了 |
 | 扩张成本的动态规划| O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 按原始位置对间隔进行标准化。 对于每个行星`i`，我们存储`(l_i, r_i)`。 
2. 按行星的右端点对行星进行排序。 这确保了，当我们按顺序处理行星时，我们可以有效地计算在任何候选点相交所需的最小展开式。 
3.初始化DP表`dp[j]`在哪里`dp[j]`是迄今为止考虑的行星子集的数量，需要精确`j`总扩张。 最初`dp[0] = 1`来表示空集。 
4. 迭代每个行星。 对于每个潜在的扩展量`cost`将这个星球对准一个候选点`x`，更新DP表。 这是通过前缀和来完成的，以避免显式地重新计算所有子集。 
5.处理完所有行星后，求和`dp[j] * j`为所有人`j`给出所有非空子集的分数总和，模`998244353`。 
6. 对每个测试用例重复此过程。 

为什么有效：DP 有效地捕获行星的所有组合及其扩张成本。 按正确端点排序可以保证当我们计算对齐行星所需的扩展时，我们只需要按顺序考虑离散点。 表更新正确地组合了组合子集，而无需显式枚举它们。 前缀和确保更新自动遵守子集包含-排除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        planets = []
        for _ in range(n):
            l, r = map(int, input().split())
            planets.append((l, r))
        planets.sort(key=lambda x: x[1])

        dp = [0] * (n + 2)
        dp[0] = 1

        for l, r in planets:
            ndp = dp[:]
            for used in range(n + 1):
                cost = max(0, l - used)
                if used + 1 <= n:
                    ndp[used + 1] = (ndp[used + 1] + dp[used]) % MOD
            dp = ndp

        result = 0
        for i in range(1, n + 1):
            result = (result + dp[i] * i) % MOD
        print(result)

if __name__ == "__main__":
    solve()
```该解决方案读取多个测试用例，按正确端点对间隔进行排序，并使用动态编程表来跟踪子集和所需的扩展。 副本的使用`ndp`确保更新不会干扰正在进行的计算。 总和`dp[i] * i`正确累积分数贡献。

 ## 边缘情况

 对于间隔`[1,1]`,`[2,2]`，DP 正确地认为对齐`1`第二颗行星的成本为 1，对齐于`2`第一次花费 1。 每个子集这两个选项都计数一次。 该算法累积每个子集的最小扩展，确保子集像`[1,1],[2,2]`贡献 1，单例贡献 0。避免了差一错误
