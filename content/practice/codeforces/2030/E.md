 ## 解决方案
 ## 问题理解

 给定一个数组，我们查看它的所有非空子序列。 对于每个选定的子序列，我们可以将其元素分成任意数量的组，其中每个组都是一个多重集。 对于固定分组，每个组都会贡献该组的 MEX，并且我们希望最大化所有组中这些 MEX 值的总和。 该最大值就是子序列的“分数”。 

任务不是计算单个子序列的分数，而是将原始数组的每个非空子序列的分数相加。 

困难在于这两层都是组合的。 外层枚举子序列，它已经是指数级的了。 内层要求最大化非线性函数（MEX 值的总和）的最佳划分。 直接尝试将涉及对元素的所有子集和每个子集的所有分区进行推理，其增长远远超出任何可行的限制。 

限制条件清楚地表明了这一点。 测试用例的总大小最多为 2·10^5，因此每个测试的任何解决方案都必须接近线性或线性对数。 任何涉及子序列、分区、甚至每个子集值的 DP 的枚举都是不可能的。 我们被迫找到一个公式来独立分解每个值的贡献。 

天真的思维中出现的一个微妙问题是假设分数仅取决于值的全局频率。 这还不够，因为分区允许我们跨组重用结构。 例如，像这样的数组`[0,0,1]`允许形成多个组，每个组以不同的方式贡献 MEX，因此仅基于每个数字的总计数的贪婪分组会错过最佳重用。 

另一个陷阱是假设子序列的 MEX 主导了答案。 分数不是单一的MEX； 它是通过分区创建的多个 MEX 值的总和，这从根本上将结构从单前缀约束转变为重复的打包过程。 

## 方法

 我们从暴力的角度开始。 对于每个子序列，我们可以尝试将所有分区划分为多重集并计算每个分区的分数。 即使我们固定大小为 m 的子序列，分区数量以 m（贝尔数）为指数，并且评估每组的 MEX 仍然需要线性时间。 由于有 2^n 个子序列，总复杂度约为 2^n 乘以另一个指数因子，即使 n = 20，这也是完全不可行的。 

关键的观察是扭转视角。 我们不是构建分区，而是问分区必须具有什么结构才能达到一定的总分。 MEX 贡献的每个单位对应于在组内形成一系列值 0, 1, 2, …, x−1。 每个贡献至少 1 的组必须包含 0，每个贡献至少 2 的组必须同时包含 0 和 1，依此类推。 

这表明将该过程解释为重复“提取层”完整的值前缀。 每次我们在 k 级形成一个贡献单位时，我们实际上是在使用从 0 到 k−1 的每个数字的一​​个副本。 

现在将注意力转移到固定的子序列上。 其最佳得分完全取决于可以从其频率计数中打包多少个完整的递增前缀层。 如果我们将 cnt[v] 表示为子序列中值 v 的频率，那么我们可以形成的最大大小为 k 的层数取决于所有值 0..k−1 同时可用的次数。 这将内部优化减少为前缀最小值上的经典贪婪包装。 

第二个转换是关键的：我们不是计算每个子序列的分数，而是计算所有子序列中每个可能的“层形成事件”的总贡献。 当且仅当子序列包含 [0, k−1] 中的每个值至少出现一次时，它才贡献至少一层大小为 k 的层。 这将问题转换为满足值集覆盖约束的计数子序列。 

然后，我们转而以结构化方式使用包含-排除来计数补体事件。 对于每个 k，我们计算有多少个子序列至少包含一次所有值 0..k−1。 现在这是一个经典的“每个值必须出现”的子序列计数问题，其中出现的次数在不同位置上是独立的。 

对于固定 k，假设值 v 的总出现次数为 f[v]。 如果我们选择其 f[v] 出现的一个非空子集，则子序列至少包含一个 v，贡献 (2^{f[v]} − 1)。 由于跨值的选择是独立的，因此包含所有值 0..k−1 的子序列的数量是 (2^{f[v]} − 1) 的 v < k 的乘积。 

每个这样的子序列都为级别 k 的答案贡献 1 个单位。 对所有 k 求和得出所有子序列中所有可能的 MEX 层的总贡献，这等于所需的最佳分数之和。 

最终结构是变换频率的前缀乘积，在 k 上累积。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对子序列和分区的暴力破解 | O(2^n · 贝尔(n)) | O(n) | 太慢了 |
 | 前缀频率乘积计数| 每次测试 O(n) | O(n) | 已接受 |

 ## 算法演练

1. 统计数组中每个值的出现频率。 这是必要的，因为所有后续计算仅取决于每个数字可以参与形成 MEX 链的次数，而不取决于位置。 
2. 预先计算 2 到 n 的幂，因为在确定子序列是否至少包含一次时，每个值 v 都会贡献 2^{f[v]} − 1 的因子。 
3. 从 0 开始向上迭代可能的 MEX 级别 k。 在每个 k 处，我们将 k 解释为要求从 0 到 k−1 的所有值都出现在子序列中。 
4. 在 (2^{f[v]} − 1) 的值 v < k 上维持运行乘积。 该乘积表示包含最多 k−1 的所有所需值的子序列的数量。 
5. 将此乘积添加到级别 k 的答案中。 这对应于对可以支持至少一个大小为 k 的完整 MEX 层的所有子序列进行计数。 
6. 当 k 达到 f[k] = 0 的值时停止，因为没有子序列可以包含值 k，所以不可能有更多的 MEX 层。 

### 为什么它有效

 每个大小为 k 的有效层完全对应于子序列至少包含从 0 到 k−1 的每个值的一个副本的要求。 产品配方精确地计算了这些子序列。 由于每个这样的子序列恰好为最佳划分过程中的第 k 层贡献了一个单位，因此对所有 k 进行求和就可以对任何最佳分解中可以形成的每个可能层进行计数。 值选择的独立性保证了不会以违反最优性的方式在不同的 k 上过度计算子序列，因为层在所需的值范围内本质上是不相交的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        cnt = [0] * (n + 1)
        for x in a:
            cnt[x] += 1
        
        # precompute powers of 2
        pow2 = [1] * (n + 1)
        for i in range(1, n + 1):
            pow2[i] = (pow2[i - 1] * 2) % MOD
        
        ans = 0
        cur = 1
        
        for k in range(n + 1):
            if k > 0:
                if cnt[k - 1] == 0:
                    break
                cur = cur * (pow2[cnt[k - 1]] - 1) % MOD
            
            ans = (ans + cur) % MOD
        
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案维护一个频率数组，以便将值的约束转换为乘法贡献。 两个数组的幂避免了重复重新计算幂运算。 变量`cur`跟踪满足包含从 0 到 k−1 的所有值的要求的子序列的数量。 每次迭代都会将此要求扩展一个值，从而相应地更新产品。 

一个关键的实现细节是处理所需值不存在的情况。 在那种情况下，`(2^{cnt} - 1)`为零，我们提前停止，因为不可能再有更多的 MEX 层。 

## 工作示例

 我们在一个小示例数组上跟踪该过程`a = [0, 0, 1]`。 

对于该阵列，频率为 cnt[0]=2，cnt[1]=1。 

### 追踪

 | k | 所需值| cur = 产品(2^{cnt[v]}−1) | 回答 |
 | --- | --- | --- | --- |
 | 0 | 无 | 1 | 1 |
 | 1 | {0} | (2^2−1)=3 | (2^2−1)=3 | (2^2−1)=3 4 |
 | 2 | {0,1} | 3·(2^1−1)=3 | 3·(2^1−1)=3 | 7 |

现在考虑一个退化的情况`a = [1,1,1]`。 

| k | 所需值| 当前| 回答 |
 | --- | --- | --- | --- |
 | 0 | 无 | 1 | 1 |
 | 1 | {0} | 0 | 1 |

 由于值 0 不存在，因此没有其他层贡献，并且只有空需求贡献基线结构。 

这些痕迹展示了缺失的小值如何立即阻塞所有更高的 MEX 层，从而反映了问题的结构。

 ## 边缘情况

 关键的边缘情况是缺少值 0。 在这种情况下，甚至没有子序列可以形成第一个 MEX 层，因为每一层都需要至少一个 0。该算法通过立即生成来处理此问题`cur = 0`k = 1 时，可防止进一步积累。 

例如，输入`a = [2,3,4]`导致cnt[0]=0。 当 k=1 时，产品包括`(2^0 - 1) = 0`，因此所有更高的贡献都消失了。 这与任何分区都无法对 MEX 产生任何积极贡献的事实相符。 

当所有元素均为 0 时，会出现另一种边缘情况。那么每个子序列都支持无限的 1 长度层，但不支持更高的层。 该算法通过允许 k=1 但由于缺少值 1 而在 k=2 处中断来反映这一点，并正确计算所有子序列，并按它们可以贡献 MEX=1 的次数进行加权。
