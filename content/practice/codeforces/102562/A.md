 ## 解决方案
 ## 问题理解

 该游戏由六列十二行棋盘组成。 最下面的八行是真正的游戏区域，而上面的四行仅在棋子落下时使用。 一些单元格最初被阻塞，并且每个放置的块将其占用的单元格永久地变成阻塞的单元格，直到移除整行。 

输入给出最多五个四格棋子的序列以及可见棋盘的初始块单元。 对于每一块，Ben 都可以旋转它、水平移动它、让它落下。 目标不是找到一种可能的游戏，而是选择使完成的行中获得的总得分最大化的动作。 

件数的小限制是关键约束。 正常的俄罗斯方块模拟会有大量可能的位置，但对于棋子最终落地的位置只需做出五个决定。 如果可以有效地压缩每个单件放置，则可以进行详尽的搜索。 

粗心的实施通常会在三个地方失败。 第一个是忘记旋转本身在旋转过程中受到碰撞的限制。 最终方向可能看起来有效，但可能无法到达，因为中间旋转位置与阻塞单元重叠。 

第二个错误是错误地清除行。 放置一次后，多行可能会消失，并且所有已删除行上方的行会一起向下移动。 例如，用一个正方形块完成两行中最后一个缺失的单元格，两行都会消失并且得分为 300，而不是两个单独的 100 分。 

第三个错误是允许将棋子放置在额外的行中。 下落区域的存在只是为了让棋子进入棋盘。 合法的最终放置必须将每个占用的单元格都放在底部八行内。 

## 方法

 直接的解决方案是模拟每个可能的移动序列。 从生成位置开始，我们可以随时尝试五种选择：向左移动、向右移动、顺时针旋转、逆时针旋转或向下移动。 每当该棋子无法再向下移动时，我们可以选择将其放置并继续下一个棋子。 

这是正确的，因为每个合法游戏都是通过该搜索树的一条路径。 然而，分支因子很大，许多不同的移动序列都达到相同的最终位置。 尽管路径数量很少，但路径数量增长很快。 

重要的观察是，得分仅取决于每个放置棋子的最终位置，而不取决于到达该棋子的移动顺序。 对于一个当前棋子和一个棋盘状态，我们可以对所有可到达的下降状态进行广度优先搜索。 这给出了每个可能的合法着陆位置，而无需存储所有移动历史记录。 

在生成一块的所有可能的着陆点后，我们递归地尝试每一个。 由于只有五块，因此递归达到的棋盘状态数量仍然是可控的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 所有运动序列的 O(5^M) | O(M)| 太慢了|
 | 最佳| O(所有 DFS 状态中可到达的放置数量) | O(DFS 状态数) | 已接受 |

 ## 算法演练

1. 将板存储为 12 个位掩码。 设置位意味着单元不可用。 位操作使冲突检查的时间恒定。 
2. 预先计算每个四格骨牌的四次旋转。 每次旋转都存储为相对于工件原点的占用单元列表。 
3. 对于当前片段，从生成状态开始运行 BFS。 状态包含原点坐标和旋转索引。 从每个州尝试五种可能的动作。 仅当旋转和移动的棋子的所有单元格都位于棋盘内部并且不与被阻止的单元格重叠时，才会添加过渡。 
4. 每当 BFS 状态无法向下移动时，它就是一个可能的着陆位置。 如果它的所有单元格都在真实的八行区域内，则模拟将棋子放置在那里。 
5. 放置一块后，将其单元格标记为已封闭。 找到所有完全填充的行，将其删除，将其上方的行向下移动，然后将已删除行数的分数相加。 
6. 递归到下一个片段。 答案是所有选项中最高分。 如果棋子没有合法的着陆位置，则当前分支结束。 

为什么它有效：

 BFS 准确地枚举了合法移动可到达的状态，因为 BFS 图中的每条边都是一个有效的游戏移动。 只有在不可能向下移动后才能放置棋子，因此收集所有可能的位置。 然后，递归搜索检查每件作品的最终位置的每一个合法选择。 由于没有跳过任何合法游戏，并且每个模拟游戏的得分都是正确的，因此找到的最大值就是最佳得分。 

## Python 解决方案```python
import sys
from functools import lru_cache

input = sys.stdin.readline

pieces = {
    'I': [(0, 1), (1, 1), (2, 1), (3, 1)],
    'O': [(1, 0), (2, 0), (1, 1), (2, 1)],
    'T': [(1, 0), (0, 1), (1, 1), (2, 1)],
    'L': [(0, 0), (0, 1), (0, 2), (1, 2)],
    'J': [(1, 0), (1, 1), (1, 2), (0, 2)],
    'S': [(1, 0), (2, 0), (0, 1), (1, 1)],
    'Z': [(0, 0), (1, 0), (1, 1), (2, 1)],
}

def rotate(shape):
    res = []
    for x, y in shape:
        res.append((3 - y, x))
    minx = min(x for x, y in res)
    miny = min(y for x, y in res)
    return [(x - minx, y - miny) for x, y in res]

rots = {}
for c, s in pieces.items():
    cur = s
    arr = []
    for _ in range(4):
        if cur not in arr:
            arr.append(cur)
        cur = rotate(cur)
    rots[c] = arr

def solve():
    n = int(input())
    seq = input().strip()

    board = [0] * 12
    lines = [input().strip() for _ in range(8)]
    for i, line in enumerate(lines):
        r = 7 - i
        for j, c in enumerate(line):
            if c == '#':
                board[r] |= 1 << j

    def valid(shape, x, y, b):
        for dx, dy in shape:
            nx = x + dx
            ny = y - dy
            if nx < 0 or nx >= 6 or ny < 0 or ny >= 12:
                return False
            if b[ny] & (1 << nx):
                return False
        return True

    def place(shape, x, y, b):
        nb = b[:]
        for dx, dy in shape:
            nb[y - dy] |= 1 << (x + dx)

        removed = 0
        keep = []
        for row in nb:
            if row == 63:
                removed += 1
            else:
                keep.append(row)

        while len(keep) < 12:
            keep.append(0)

        return keep, removed * (removed + 1) * 50

    def landings(piece, b):
        ans = set()
        q = [(0, 11, 0)]
        seen = {(0, 11, 0)}
        head = 0
        while head < len(q):
            x, y, r = q[head]
            head += 1
            shape = rots[piece][r]

            down = (x, y - 1, r)
            can_down = valid(shape, x, y - 1, b)
            if not can_down:
                if all(y - dy < 8 for dx, dy in shape):
                    ans.add((x, y, r))

            nxt = []
            for nx, ny, nr in [
                (x - 1, y, r),
                (x + 1, y, r),
                (x, y - 1, r),
                (x, y, (r + 1) % len(rots[piece])),
                (x, y, (r - 1) % len(rots[piece]))
            ]:
                if (nx, ny, nr) not in seen:
                    if valid(rots[piece][nr], nx, ny, b):
                        seen.add((nx, ny, nr))
                        q.append((nx, ny, nr))
        return ans

    @lru_cache(None)
    def dfs(idx, state):
        b = list(state)
        if idx == n:
            return 0

        best = 0
        piece = seq[idx]

        for x, y, r in landings(piece, b):
            nb, gain = place(rots[piece][r], x, y, b)
            best = max(best, gain + dfs(idx + 1, tuple(nb)))

        return best

    print(dfs(0, tuple(board)))

solve()
```董事会代表是主要的实施细节。 每行都是一个六位整数，因此检查一个片段是否与一行碰撞只需要几个位操作。 内部行编号从底部的零开始，自然地匹配重力。 

BFS 使用原始游戏规则而不是仅检查最终坐标。 这可以避免接受无法到达的旋转。 生成原点位于顶部额外行，因此初始状态使用第 11 行。 

行清除代码会立即删除所有整行。 删除后，空行会追加到顶部，因为已清除行上方的行会向下下降。 

Python 整数在这里不会溢出，因为最大分数与其限制相比很小。 记忆键在使用了每个数量的棋子后存储完整的棋盘，这合并了通向相同未来的不同历史。

 ## 边缘情况

 第一个边缘情况是无法到达的旋转。 一块的方向可能适合最终位置，但所需的旋转移动可能会在转动时发生碰撞。 BFS 检查每个中间状态，因此永远不会生成此类非法放置。 

第二种边缘情况是多个同时行清除。 如果某个展示位置一次填充两行，则根据该单个事件中删除的行数计算分数。 清除函数在移位之前对所有完整行进行计数，因此它会生成所需的三角形分数。 

第三个边缘情况是额外的行。 棋子在掉落时可以暂时占据这些行，但不能放置在那里。 布局检查要求每个占用的单元具有小于八的内部行，以防止无效的最终状态。
