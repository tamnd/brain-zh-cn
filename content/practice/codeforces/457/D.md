 ## 解决方案
 ## 问题理解

 我们有一个$n \times n$宾果游戏板。 每个单元格包含一个不同的数字，选自$1$到$m$，并且每个有效的棋盘都有相同的可能性。 

板子生成后，正好$k$调用不同的数字。 每一套$k$数字是同样可能的。 如果某个单元格的号码出现在被叫号码中，则该单元格将被标记。 

如果一行的所有单元格都被标记，则该行被认为是完整的。 在相同条件下，一列是完整的。 如果董事会以$r$完整的行和$c$完整的列，得分为$$2^{r+c}.$$任务是计算预期分数。 

这些约束完全排除了任何模拟或基于状态的方法。 该板包含多达$300^2 = 90000$细胞，和$m$可以大到$100000$。 即使迭代行或列的子集也是不可能的。 我们需要一个公式将期望减少到少量的组合状态。 

第一个陷阱是假设行和列是独立的。 他们不是。 如果一行完整，则会改变另一行或一列完整的概率，因为它们共享被调用的数字。 

例如：```
n = 2
m = 4
k = 3
```如果顶行完整，则该行中的两个号码都必须属于被叫集。 这会影响完成与行相交的列的概率。 

另一个容易犯的错误是试图适应特定的电路板布局。 棋盘本身是随机的。 该解决方案必须同时对两个随机过程进行平均。 

当所需的标记单元超过被叫号码的数量时，会出现第二种微妙的情况。```
n = 3
m = 20
k = 4
```任何需要标记五个或更多不同单元格的事件的概率为零，因为只调用了四个数字。 正确的实现必须自动为这些项生成零。 

第三种边缘情况是最小的板：```
1 2 1
```有一个细胞。 有概率$1/2$它的编号被调用，给出分数$2$。 否则得分为$1$。 

期望是$$\frac12 \cdot 2 + \frac12 \cdot 1 = 1.5.$$但板号本身是随机的。 对棋盘代数和被叫数进行平均给出了官方答案$2.5$。 任何忘记随机性来源的推导都是错误的。 

## 方法

 暴力方法将枚举所有可能的棋盘和所有可能的被叫号码集，计算每个结果的分数，并对结果进行平均。 

板数为$$\frac{m!}{(m-n^2)!},$$被叫集数为$$\binom{m}{k}.$$即使对于微小的投入来说，这也是天文数字。 

蛮力在概念上是正确的原因是分数仅取决于哪些行和列变得完整。 挑战在于找到一种方法来计算这些事件而不枚举板。 

关键的观察来自重写乐谱。 

让$R_i$是该行的指标$i$已完成，并且$C_j$是该列的指标$j$已完成。 

然后$$2^{R_i} = 1 + R_i$$因为$R_i$是$0$或者$1$。 

所以$$2^{\sum R_i + \sum C_j} = \prod_{i=1}^{n}(1+R_i) \prod_{j=1}^{n}(1+C_j).$$现在展开产品：$$\prod_{i}(1+R_i)\prod_{j}(1+C_j) = \sum_{A,B} \left( \prod_{i\in A} R_i \right) \left( \prod_{j\in B} C_j \right),$$在哪里$A$是行的子集并且$B$是列的子集。 

取期望并使用线性，

 E[\text{分数}] = \sum_{A,B} P(\text{}A\text{ 中的所有行完成，}B\text{ 中的所有列完成)。 

这将问题转化为计算概率。 

认为$|A|=a$和$|B|=b$。 

对于每个选定的行，我们都需要$n$细胞被标记。 对于每个选定的列，我们还需要所有$n$细胞被标记。 该联盟包含$$t = an + bn - ab$$细胞，因为$ab$行-列交叉点被计算两次。 

所有这些$t$单元格包含不同的数字。 当所有这些号码都属于被叫话机时，该事件就会发生。 

如果$t$具体数字必须出现在$k$称为数字，概率为$$\frac{\binom{m-t}{k-t}}{\binom{m}{k}} = \frac{(k)_t}{(m)_t}.$$至关重要的是，这仅取决于$t$，而不是选择的实际行和列。 

所以每一对$(a,b)$贡献$$\binom{n}{a} \binom{n}{b} \cdot \frac{\binom{m-t}{k-t}}{\binom{m}{k}}.$$只有$(n+1)^2$的可能值$(a,b)$，这最多是$301^2$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数为$n^2$和$m$| 巨大| 太慢了|
 | 最佳 |$O(n^2 + n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 预先计算所有二项式系数$\binom{n}{i}$为了$0 \le i \le n$。 

自从$n \le 300$，我们可以使用迭代构建它们$$\binom{n}{i} = \binom{n}{i-1} \cdot \frac{n-i+1}{i}.$$2. 预计算$$p[t] = \frac{\binom{m-t}{k-t}}{\binom{m}{k}}$$对于每一个$0 \le t \le n^2$。 

开始于$p[0]=1$。 为了$t \ge 1$,$$p[t] = p[t-1] \cdot \frac{k-t+1}{m-t+1}.$$一次$t>k$，概率变为零。 
3. 迭代所有可能数量的选定行$a$和选定的列$b$。 
4. 计算$$t = an + bn - ab.$$这正是这些行和列的并集中的单元格数量。 
5. 添加$$\binom{n}{a} \binom{n}{b} p[t]$$到答案。 
6. 如果累计答案超过$10^{99}$， 打印$10^{99}$。 

### 为什么它有效

 扩大后$$\prod_i(1+R_i)\prod_j(1+C_j),$$每个术语对应于选择行的子集和列的子集。 指标的乘积等于$1$恰好当所有选定的行都完成时，并且等于$0$否则。 

该事件的概率仅取决于属于这些细胞系的细胞集。 他们的工会包含$$an+bn-ab$$不同的细胞。 由于所有棋盘编号都是不同的，因此该事件相当于要求这些不同的数字出现在$k$称为数字。 

因此，每个子集对都准确地贡献了其发生的概率，并且对所有子集对求和给出了预期分数。 没有术语被省略，也没有术语被计算两次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())

    max_t = n * n

    choose = [0.0] * (n + 1)
    choose[0] = 1.0
    for i in range(1, n + 1):
        choose[i] = choose[i - 1] * (n - i + 1) / i

    p = [0.0] * (max_t + 1)
    p[0] = 1.0

    limit = min(k, max_t)
    for t in range(1, limit + 1):
        p[t] = p[t - 1] * (k - t + 1) / (m - t + 1)

    ans = 0.0

    for a in range(n + 1):
        ca = choose[a]
        for b in range(n + 1):
            t = a * n + b * n - a * b
            if t > k:
                continue

            ans += ca * choose[b] * p[t]

    if ans > 1e99:
        print("1e99")
    else:
        print("{:.10f}".format(ans))

solve()
```数组`choose`存储所有值$\binom{n}{i}$。 使用乘法递归可以避免阶乘并保持数值稳定$n=300$。 

数组`p`存储一组固定的概率`t`不同的数字完全包含在被调用的集合中。 递归计算比重复计算二项式系数要快得多。 

表达式```
t = a * n + b * n - a * b
```是解中最重要的计数公式。 减法删除了计算两次的行列交叉点。 

支票```
if t > k:
    continue
```立即处理所有不可能的事件。 如果超过`k`需要不同的数字，概率恰好为零。 

所有计算均使用浮点。 官方答案允许相对误差$10^{-9}$，双打在这里就足够了。

 ## 边缘情况

 考虑：```
3 20 4
```完整的行已经需要三个标记的单元格。 两个完整的行需要六个不同的单元格。 

该算法计算$$t = an + bn - ab.$$为了$a=2, b=0$,$$t = 6.$$自从$6 > k = 4$，该贡献将立即被跳过。 这与真实概率相符，恰好为零。 

现在考虑：```
2 4 4
```四个号码全部被叫出。 每个单元格都被标记。 每一行每一列都是完整的。 

分数始终是$$2^{2+2}=16.$$在算法中，$$p(t)=1$$对于每一个$t \le 4$。 子集展开变成$$\sum_{a=0}^{2}\binom{2}{a} \sum_{b=0}^{2}\binom{2}{b} = 2^2 \cdot 2^2 = 16.$$最后，考虑：```
1 2 1
```行和列实际上是同一个单元格。 粗心的解决方案可能会将它们视为两个独立的需求。 我们的联合公式给出$$t = 1 + 1 - 1 = 1,$$因此重叠处理正确。 概率是使用一个所需的单元而不是两个来计算的。
