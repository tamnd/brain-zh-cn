 ## 解决方案
 ## 问题理解

 我们得到一个仅由 0 和 1 组成的二进制字符串。 任务是确定是否可以通过恰好翻转字符串的一个连续段来使其成为回文。 翻转一个段意味着将该段中的每个 0 更改为 1，并将每个 1 更改为 0。 

例如，对于一个字符串`10010`，翻转前三个字符会产生`01110`，这是一个回文。 字符串长度最多可达 100,000，测试用例最多可达 10,000 个。 由于长度总和不超过 200,000，因此我们需要一个相对于每个测试用例的字符串长度呈线性运行的解决方案。 尝试所有可能的分段的二次解将导致大约 10^10 次操作，这是不可行的。 

棘手的部分是我们只允许**一次翻转**，而不是多次。 这引入了几种边缘情况。 如果字符串已经是回文，我们什么也不做——我们仍然必须翻转一个段，可能是最小的段。 例如，`11`是一个回文，但翻转任一字符都会产生`01`或者`10`，两者都不是回文。 这凸显了检查翻转某些片段以实现回文的能力的重要性，而不仅仅是检查字符串当前是否是回文。 

另一种微妙的情况发生在长度为 3 的字符串上，例如`010`。 如果我们翻转中间的字符，它仍然是回文。 如果我们翻转外面的两个，它仍然是回文。 这些小案例说明，准确的段选择至关重要，我们必须考虑字符串中左右不匹配之间的重叠。 

## 方法

 蛮力方法将迭代所有可能的段`[l, r]`并翻转它们以查看生成的字符串是否是回文。 段数为 O(n^2)，检查回文的成本为 O(n)。 这给出了 O(n^3) 的最坏情况复杂度，这对于`n`最多 10^5。 

关键的见解是关注**不匹配的职位**。 要使字符串成为回文，索引处的每个字符`i`必须与索引处的字符匹配`n-i-1`。 如果它们已经匹配，我们可以忽略它们。 如果它们不同，则翻转段必须覆盖其中一个字符，但不能覆盖另一个字符，从而有效地反转一个字符以匹配另一个字符。 

通过计算不匹配对的数量，我们可以推断：

 - 如果有 **0 个不匹配**，则该字符串已经是回文。 翻转任何长度为 1 的段将恰好创建一个不匹配对，但翻转偶数长度字符串中的单个字符仍然可以产生有效的回文。 实际上，长度检查以及字符串长度是否允许段翻转就足够了。 
- 如果存在**恰好 1 个不匹配对**，则翻转覆盖其中一个不匹配字符的段即可修复该问题。 如果该段包含一对字符中的一个以及可选的更多字符，而不会在其他地方产生额外的不匹配，则这是可能的。 
- 如果存在**多于 1 个不匹配对**，我们需要检查这些不匹配是否是连续的或者可以通过单个连续翻转来覆盖。 像这样的不匹配模式`0110`在位置 0-3 和 1-2 处存在不匹配； 中间两个翻转一下就可以修复它。 如果不匹配在模式中不相邻且不能被一个段覆盖，则这是不可能的。 

更简单的实现方法是用两个指针从左、右向中心迭代。 数一下其中的位置`s[left] == s[right]`相对`s[left] != s[right]`。 如果不匹配的计数为零，我们可以翻转任何单个字符。 如果计数为 1 或者不匹配形成连续块，则答案为“是”。 否则，答案是否定的。 这将问题简化为线性扫描，每个测试用例为 O(n)，这是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 两指针不匹配计数 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.初始化两个指针：`l = 0`和`r = n - 1`。 
2. 将指针移向中心。 对于每对`(s[l], s[r])`，检查它们是否相等。 如果相等，则无需执行任何操作，移动`l`向前和`r`落后。 
3. 如果它们不相等，则将其标记为不匹配。 存储第一个和最后一个不匹配位置。 增量`l`并减少`r`。 
4. 扫描结束后，统计不匹配的总数。 如果存在零个不匹配，则该字符串已经是回文。 翻转任何单个字符（如果长度为奇数，则翻转中间字符）将保持回文结构。 返回“是”。 
5. 如果存在不匹配，则检查所有不匹配索引是否形成连续的块。 这可以通过验证第一个和最后一个不匹配之间的距离等于不匹配的数量来确定。 如果是这样，覆盖该段的单个翻转将解决所有不匹配问题。 返回“是”。 
6. 如果不匹配是不连续的，则任何单个段都无法修复该字符串。 返回“否”。 

这样做的原因是每个不匹配都需要在两个位置之一上进行一次反转。 连续翻转可以一次反转多个位置。 如果所有不匹配都位于一个连续的段中，则翻转该段会同时对齐所有不匹配对。 非连续不匹配需要多次单独的翻转，这违反了仅一次操作的约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        
        l, r = 0, n - 1
        mismatches = []
        while l < r:
            if s[l] != s[r]:
                mismatches.append(l)
            l += 1
            r -= 1
        
        if not mismatches:
            print("Yes")
            continue
        
        first, last = mismatches[0], mismatches[-1]
        if last - first + 1 == len(mismatches):
            print("Yes")
        else:
            print("No")

if __name__ == "__main__":
    solve()
```该代码初始化指针并收集不匹配索引。 如果不匹配索引是连续的，则一次翻转即可修复所有差异。 如果没有不匹配，则翻转任何最小段将使字符串保持回文。 边缘条件（例如奇数长度字符串）自然由指针迭代处理。
