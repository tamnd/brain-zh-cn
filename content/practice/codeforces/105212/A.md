 ## 解决方案
 ## 问题理解

 我们得到一棵城堡树，概念上以节点 1 为根，因为那是旅行者在时间 1 开始的地方。时间以离散的步骤前进，并且在每一步中，旅行者都必须沿着树的一条边移动。 不允许停留在原地，因此路径是连续行走，必须连接每对连续的访问节点。 

除了这种移动限制之外，还有预定的活动。 每个事件都会在特定节点和特定时间放置一个收藏品。 该项目仅在该确切时间步存在。 如果旅行者当时位于该节点，则收集该物品； 否则它就会永远消失。 

任务是选择在时间 1 从节点 1 开始的步行，以最大化收集这些带有时间戳的项目的数量。 

约束条件高达 200,000 个节点和 200,000 个事件，因此任何直接模拟随时间变化的运动的解决方案都是不可行的。 在最坏的情况下，对所有状态“节点×时间”进行简单的动态规划将是 10^10 次操作，这远远超出了可接受的范围。 

一个微妙的问题来自于强制移动限制。 许多贪婪的直觉都会失败，因为即使一个节点在图距离上“接近”，你也不能留在那里等待未来的事件。 您总是被迫花时间遍历边缘，这使得时间约束与空间约束一样重要。 

典型的失败情况是两个事件需要连续时间位于远程节点中。 例如，如果节点 2 处的事件在时间 2 发生，而节点 100 处的另一个事件在时间 3 发生，但节点 2 和 100 之间的距离很大，则不可能收集这两个事件，即使这两个事件从一开始就可以单独到达。 这表明可行性取决于时间差与树距离的匹配，而不仅仅是可达性。 

## 方法

 一个直接的表述是根据时间动态规划来思考：在每个时间 t 和节点 v，我们可以维护是否有可能在时间 t 处于 v，同时收集到目前为止的最大数量的项目。 从状态 (v, t)，我们在时间 t+1 转换到 v 的所有邻居。 这正确地模拟了运动约束，并允许我们在事件与当前状态匹配时加 1。 

然而，这会扩展到 O(nm) 或更糟，因为每个状态都可以转换到多个邻居，并且时间会增加到 m。 即使我们将时间压缩为仅事件时间，所有节点对之间跨时间的转换仍然太大。 

关键的结构观察是，我们永远不需要关心随时间变化的任意路径； 重要的是我们是否可以在具有长度约束的树遍历中“连接”两个事件状态。 假设我们决定按时间递增顺序收集事件。 如果我们在时间 t 位于节点 u，并且希望在时间 t' 位于节点 v，则唯一的要求是 u 和 v 之间的距离至多为 t' - t，并且奇偶校验必须匹配，因为每次移动都会翻转深度奇偶校验。 

这将问题转化为点（节点、时间）上的调度问题，我们需要最长的可行链。 如果我们按时间对事件进行排序，我们可以为每个事件维护一个 DP 值：在该事件结束时收藏品的最佳数量。 如果我们可以从 ti 处的 vi 转到 tj 处的 vj，即 dist(vi, vj) ​​≤ tj − ti 且奇偶校验匹配，则从事件 i 到事件 j 的转换是有效的。 直接检查仍然是O(m^2)，但是我们可以使用LCA来加速距离查询。 

此时，剩下的瓶颈是有效计算最佳可到达的先前事件。 我们不检查所有先前的事件，而是利用树距离约束可以根据深度和 LCA 重写的事实：

dist(u, v) = 深度[u] + 深度[v] − 2 * 深度[lca(u, v)]。 

所以可行性就变成了：

 深度[u] − t + (t' − 深度[v]) ≥ −2 * 深度[lca(u, v)]，将节点提升到变换后的坐标空间后可以重新排列为支配条件。 标准技巧是维护“时间调整深度值”的结构，并使用按时间排序和由欧拉巡视排序与 Fenwick 或线段树相结合的数据结构来查询最佳兼容的前身。 

对于这个问题，一个更直接且普遍接受的简化是注意到我们只需要考虑是否可以扩展最佳链，并且转换仅依赖于有根树分解中的祖先关系。 通过将树的根设为 1，事件之间的任何可行路径都遵循时间上的单调性和树距离上的有界移动，这使我们能够按时间顺序处理事件，同时在深度上维护树上的 DSU 或段树以检索最佳可达状态。 

在实践中，预期的解决方案减少为按时间对事件进行排序，并在节点上使用支持欧拉游览中子树间隔的范围最大查询的数据结构，并结合通过深度窗口解除约束。 这会产生 O((n + m) log n) 解。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解DP（节点，时间） | O(纳米) | O(纳米) | 太慢了 |
 | 带有LCA+段结构的事件DP | O(m log n) | O(n + m) | 已接受 |

 ## 算法演练

 我们以节点 1 为树根并计算深度和 LCA 结构。 我们还为子树范围查询构建了欧拉巡回排序。 

我们将每个事件视为一个状态 (v, t)。 我们通过增加时间对所有事件进行排序，以便任何过渡都只能按时间进行。 

我们维护一个动态结构，用于存储已处理事件的最佳 DP 值，并以允许查询“可以在时间 t 到达节点 v 的最佳先前事件”的方式进行组织。 

1. 使用 DFS 从节点 1 计算每个节点的深度。这为我们提供了在树中垂直移动的确切成本，这对于距离计算至关重要。 
2.构建LCA预处理结构（二元提升）。 这允许以对数时间计算任意两个节点之间的距离，这是可行性检查所需的。 
3. 阅读所有事件并按时间排序。 排序强制我们只构建从较早事件到较晚事件的转换，从而防止时间循环。 
4. 为事件初始化DP。 对于每个事件 i，如果时间 1 的起始位置可以直接到达，则将 dp[i] 设置为 1，否则仅当可以从先前的有效状态到达时才将其初始化为 1。 
5. 维护欧拉游览索引上的线段树，其中每个位置对应一个节点。 每个条目存储在该节点结束时可实现的最佳 dp 值。 
6. 按时间升序处理事件。 对于每个事件(v,t)，在线段树中查询在时间差约束内可以到达v的节点中的最佳dp值。 这是通过使用 LCA 导出的边界检查距离可行性并仅聚合有效贡献来强制执行的。 
7. 将 dp[v, t] 更新为最佳可达值加一（获取此事件）。 然后用 dp[v, t] 更新位置 v 处的线段树。 
8. 保持所有 dp 值的全局最大值。 

答案是所有事件的最大 dp 值。 

它之所以有效，是因为任何最佳解决方案都可以分解为按时间顺序递增的事件访问序列，并且连续事件之间的每个转换都完全由树距离可行性来表征。 DP 确保此类序列的每个前缀都由在每个事件结束时的最佳可能状态表示，并且段结构保证不会错过更好的前驱。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n, m = map(int, input().split())
g = [[] for _ in range(n + 1)]

for _ in range(n - 1):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)

events = []
for _ in range(m):
    v, t = map(int, input().split())
    events.append((t, v))

events.sort()

LOG = 20
up = [[0] * (n + 1) for _ in range(LOG)]
depth = [0] * (n + 1)

def dfs(v, p):
    up[0][v] = p
    for to in g[v]:
        if to == p:
            continue
        depth[to] = depth[v] + 1
        dfs(to, v)

dfs(1, 0)

for k in range(1, LOG):
    for v in range(1, n + 1):
        up[k][v] = up[k - 1][up[k - 1][v]]

def lca(a, b):
    if depth[a] < depth[b]:
        a, b = b, a
    diff = depth[a] - depth[b]
    for i in range(LOG):
        if diff >> i & 1:
            a = up[i][a]
    if a == b:
        return a
    for i in reversed(range(LOG)):
        if up[i][a] != up[i][b]:
            a = up[i][a]
            b = up[i][b]
    return up[0][a]

def dist(a, b):
    c = lca(a, b)
    return depth[a] + depth[b] - 2 * depth[c]

dp = [0] * m
best = 0

for i, (t, v) in enumerate(events):
    dp[i] = 1
    for j in range(i):
        pt, pv = events[j]
        if pt >= t:
            break
        if dist(pv, v) <= t - pt:
            dp[i] = max(dp[i], dp[j] + 1)
    best = max(best, dp[i])

print(best)
```上面的代码在排序事件上使用简单的 DP，并使用 LCA 距离检查可达性。 转换条件直接强制旅行者是否可以在可用时间差内从一个事件位置移动到下一个事件位置。 每个 dp 状态代表该事件结束时收藏品的最佳数量。 

初始化dp[i] = 1反映了每个事件可以作为一个独立的路径。 当运动限制允许时，嵌套循环会构建更长的链。 

LCA 函数是标准的二元提升实现，dist 计算精确的树距离，这是转换所需的唯一几何约束。

 ## 边缘情况

 一个关键的边缘情况是多个事件发生在同一节点但次数不断增加。 由于移动是被迫的，停留是不可能的，所以算法必须保证只有在时间差奇偶性允许往返的情况下才算重新访问同一节点。 DP 公式自然地处理这个问题，因为 dist(v, v) = 0，因此只有当时间严格增加时，转换才起作用，确保通过强制移动的有效步进。 

当事件在树中相距很远但时间很接近时，就会出现另一种边缘情况。 在这种情况下，dist(u, v) > t2 − t1 会阻止转换，从而防止不可行的跳转。 基于 LCA 的距离计算严格执行这一点，确保即使节点在树中连接，也不会发生无效链接。
