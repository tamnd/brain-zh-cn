 ## 解决方案
 ## 问题理解

 每种查看模式将库存分组为不同大小的页面`a_i`。 如果库存包含`k`物品，然后游戏显示$b_i = \left\lceil \frac{k}{a_i} \right\rceil$该模式下的页面。 

Vasya 不知道其实际价值`k`，仅此而已`2 ≤ k ≤ x`。 在查看任何内容之前，他会选择一些模式子集。 看到所有相应的页数后，他必须能够确定`k`独一无二。 

我们被赋予了所有的价值观`a_i`，并且我们必须找到唯一重建所需的最小模式数`k`。 如果没有子集有效，我们输出`-1`。 

约束条件`n ≤ 10^5`立即排除任何比较所有模式子集的方法。 即使检查所有可能的库存大小对也已经花费了大约`10^18`操作时`x`很大。 我们需要一些接近的东西`O(n log n)`或者`O(n log x)`。 

价值`x`可以达到`10^9`，因此迭代所有可能的库存大小是不可能的。 任何成功的解决方案都必须象征性地推理区间和整除性，而不是枚举候选者。 

当多种模式具有相同的页面大小时，会出现微妙的边缘情况。 

例子：```
n = 3, x = 10
a = [2, 2, 2]
```所有三种模式都提供完全相同的信息。 使用更多副本并没有帮助。 独立计算模式的粗心贪婪解决方案将错误地回答`3`，而正确答案是`-1`因为价值观就像`3`和`4`总是产生相同的观察结果。 

当众数在上限附近没有给出有用的区别时，就会出现另一种棘手的情况。 

例子：```
n = 1, x = 5
a = [100]
```对于每一种可能的库存规模`2`到`5`，页数始终为`1`。 幼稚的实现可能认为一种模式就足够了，因为它会产生输出，但输出永远不会改变。 

最困难的极端情况是理解多种模式如何组合。 

例子：```
n = 2, x = 6
a = [2, 3]
```观察结果是：

 | k | 上限(k/2) | 上限(k/3) |
 | --- | --- | --- |
 | 2 | 1 | 1 |
 | 3 | 2 | 1 |
 | 4 | 2 | 2 |
 | 5 | 3 | 2 |
 | 6 | 3 | 2 |

 价值观`5`和`6`仍然无法区分，所以答案是`-1`。 仅检查模式的成对唯一性的幼稚方法会错误地得出结论：将它们组合起来就足够了。 

## 方法

 蛮力解释很简单。 对于每种可能的库存规模`k`从`2`到`x`，计算向量$\left(\left\lceil\frac{k}{a_1}\right\rceil,\left\lceil\frac{k}{a_2}\right\rceil,\dots\right)$然后尝试所有模式子集并检查生成的投影向量是否唯一地标识每个`k`。 

这是正确的，因为当某些选定的模式为它们生成不同的页数时，两个库存大小是可以准确区分的。 

问题在于规模。 即使存储所有向量也已经成本`O(nx)`，这变成`10^14`最坏情况下的操作。 尝试子集的情况会呈指数级恶化。 

关键的观察是具有页面大小的模式`a`不区分同一区间内的数字：$((t-1)a,\; ta]$该区间内的每个数字都会产生页数`t`。 

这意味着每种模式都会划分范围`[2, x]`成块。 组合多个模式对应于使这些分区相交。 我们希望每个最终块都包含一个整数。 

现在是至关重要的数论见解。 

假设有两个数`u < v`对于某种模式来说仍然无法区分`a`。 然后：$\left\lceil\frac{u}{a}\right\rceil = \left\lceil\frac{v}{a}\right\rceil$当没有倍数时，就会发生这种情况`a`严格之间`u`和`v`。 

对于连续的数字`k`和`k+1`，它们是可区分的当且仅当`a`划分`k`。 

这改变了整个问题。 区分每个整数与下一个整数，对于每个`k`在`[2, x-1]`我们至少需要选择一个`a_i`划分`k`。 

所以任务就变成了：

 选择最少数量的值`a_i`这样每个整数都来自`2`到`x-1`可被至少一个选定值整除。 

现在观察另一个简化。 如果`a > x-1`，它没有划分任何有用的东西。 如果`a = 1`，它划分了所有内容，但提供了完全无用的信息，因为页数每一步都会相同地增加。 

唯一有意义的除数是介于`2`和`x-1`。 

更重要的是，如果我们选择一些`a > 1`，那么所有的倍数`a`成为可区分的界限。 分离每个相邻的对，每个数字`k`从`2`到`x-1`本身必须作为所选模式中的除数出现。 否则`k`被揭开。 

这意味着唯一可能成功的集合正是所有整数`2, 3, ..., x-1`。 

所以：

 - 如果有任何整数`[2, x-1]`输入中不存在，答案是`-1`。 
- 否则，模式的最小数量等于该范围内不同整数的数量，即`x-2`。 

整个看似困难的分区问题分解为一个简单的覆盖范围论证。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(nx + 2^n) | O(nx + 2^n) | O(nx) | 太慢了 |
 | 最佳| O(n) | O(x) 或 O(n) | 已接受 |

 ## 算法演练

 1.读取所有值`a_i`。 
2.插入每个`a_i`成一个集合。 

我们只关心除数是否至少存在一次。 重复模式提供相同的信息。 
3. 对于每个整数`k`从`2`到`x-1`，检查是否`k`存在于集合中。 

原因来自于相邻的数字。 来区分`k`从`k+1`，某些选择的模式必须满足：$k \equiv 0 \pmod{a}$自从`a > k`不能分开`k`，以及任何适当的除数`k`也可以划分附近的数字，而不精确地创建边界`k`，唯一有保证的分隔符是`a = k`。 

1. 如果有任何数字`[2, x-1]`缺失，输出`-1`。 
2.否则输出`x-2`。 

我们需要所有这些模式，并且正确使用它们是有效的。 

### 为什么它有效

 具有页面大小的模式`a`精确地以倍数改变其输出`a`。 这对`(k, k+1)`是可区分的，当且仅当某些选定的模式在这两个值之间发生变化，这意味着某些选定的模式`a`划分`k`。 

为了唯一区分所有可能的库存大小，每个相邻的对都必须是可区分的。 如果在所有选定的模式下即使有一对相邻的值保持相等，则这两个库存大小会产生相同的观察结果。 

对于给定的`k`, 任何除数`a`分开的`k`和`k+1`必须划分`k`。 最强的可能的分隔符是`a = k`。 如果`k`本身不存在于可用模式中，因此无法保证该边界的分离。 因此，来自的每个整数`2`到`x-1`必须存在于模式之中。 

选择所有这些显然是有效的，因为模式`k`之间的边界完全分开`k`和`k+1`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, x = map(int, input().split())

    if n > 0:
        a = list(map(int, input().split()))
    else:
        a = []

    s = set(a)

    for v in range(2, x):
        if v not in s:
            print(-1)
            return

    print(x - 2)

solve()
```实现很短，因为数学简化消除了所有复杂的结构。 

套装`s`存储所有可用的模式尺寸。 重复项会被自动丢弃，因为相同的模式永远不会提供额外的信息。 

该循环检查每个所需的分隔符值`2`到`x-1`。 即使缺少一个值也意味着无法唯一标识该数字与下一个数字之间的边界。 

答案就变成了`x-2`因为区间内正好有那么多所需的整数。 

一个微妙的细节处理`n = 0`。 该语句允许这样做，因此无条件读取第二行将失败。 该代码可以防止这种情况。 

另一个重要的细节是循环范围：```
range(2, x)
```这正确地包括`x-1`并排除`x`。 我们只需要区分里面相邻的对`[2, x]`，即：```
(2,3), (3,4), ..., (x-1,x)
```## 工作示例

import sys
import io

def solve():
    input = sys.stdin.readline

    n, x = map(int, input().split())

    if n > 0:
        a = list(map(int, input().split()))
    else:
        a = []

    for v in range(2, x):

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

 ## 边缘情况

 考虑：```
5 5
2 2 2 3 3
```该集合变为：```
{2, 3}
```该算法检查：

 -`2`， 展示
-`3`， 展示
-`4`, 失踪

 它输出`-1`。 

这证实了重复模式不会增加信息。 每个副本模式`2`产生完全相同的页数。 

现在考虑：```
1 5
100
```套装是：```
{100}
```第一个所需值是`2`，它不存在，所以答案是`-1`。 

事实上，所有库存规模均来自`2`到`5`在此模式下生成一页。 

最后，考虑最小的可能范围：```
0 2
```里面没有相邻对`[2,2]`，所以循环结束`range(2, 2)`是空的。 该算法打印：```
0
```这是正确的，因为当只有一种库存大小可能时，Vasya 无需检查任何模式就已经知道答案。
