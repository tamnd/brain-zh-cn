 ## 解决方案
 ## 问题理解

 我们给出一组索引从 1 到 n 的候选者。 每个候选人 i 都有忠实的支持者。 此外，还有一群尚未做出决定的选民，如果没有任何变化，他们总是投票给仍在参与的选民中人数最少的候选人。 

不同的是，我们可以取消候选人的资格。 如果候选人 i 被取消资格，则其所有 ai 支持者都会成为犹豫不决的选民。 然后，这些转变的选民还将投票给仍在竞选中人数最少的候选人。 因此，取消候选人资格既可以排除竞争对手，也可以增加早期候选人的选票池。 

对于每个候选人 i，我们必须计算需要取消资格的候选人的最小数量，以便候选人 i 最终根据这些投票规则赢得选举。 

n 最大为 200000 且 ai 最大为 10^9 的约束意味着任何尝试所有候选子集或显式模拟取消资格选择的解决方案都是不可能的。 即使每个候选者的二次行为也太慢，所以我们需要每个查询更接近线性或对数的东西，最好是 O(n log n) 或 O(n)。 

一个微妙的边缘情况是，犹豫不决的选民总是选择最小的活跃指数。 这意味着取消单个低指数候选人的资格可能会完全改变大量选票的方向，从而可能以非本地方式改变获胜者。 另一个边缘情况是，仅 c 就足以让候选人 1 获胜，因为他们会自动接收所有未决定的选民。 

例如，如果 n = 3、c = 10、a = [0, 0, 0]，则候选人 1 已经获胜，没有任何取消资格。 在这里，只专注于消除更强大的竞争对手的天真想法仍然是正确的，但任何忽视将未决定的选票向上转移的影响的解决方案都将在更具结构化的投入上失败。 

## 方法

 暴力解释很简单：对于固定的候选人 i，我们可以尝试取消候选人的每个子集，模拟最终的选举，并检查 i 是否获胜。 这将涉及在每个子集选择之后重新计算投票总数。 子集的数量为 2^n，甚至限制为小尺寸 k 的子集也会给出 O(n^k) 行为，这在 n 高达 200000 时完全不可行。 

一种更结构化的蛮力方法是固定 k 并询问是否存在一组 k 取消资格使得 i 获胜。 即使这样也需要检查组合并模拟投票重新分配，这仍然是组合性的。 

关键的观察结果是，取消候选人资格只会产生两个效果：它消除了竞争对手，并且通过 ai 增加了未决定的池 c。 至关重要的是，未决定的选民总是流向最小的剩余索引，因此对于候选人 i 来说，只有索引小于 i 的候选人才能以非常具体的方式发挥作用：他们决定 i 可以间接获得多少额外的未决定选票。 

我们可以从左到右贪婪地推理，而不是根据任意子集进行思考。 为了使候选人 i 获胜，所有索引大于 i 的候选人都是无关紧要的，除非作为潜在竞争对手，如果他们可以超过 i 的最终投票总数，我们可能需要将其删除。 另一方面，指数小于 i 的候选人是危险的，因为如果他们留下来，他们可以吸引尚未做出决定的选民并减少 i 的有效收益。 

核心简化是将问题重新解释为投票阈值的平衡行为：候选人 i 的最终票数取决于 c 加上所有索引 < i 的不合格候选人的 ai 总和。 每个候选人 j > i 仍然是具有固定 aj 的竞争对手，因此为了确保 i 获胜，我们必须确保没有这样的 aj 超过 i 最终的累计投票总数。

这导致了贪婪的选择问题：我们希望尽可能地取消候选人的资格，以增加 i 的选票并压制强大的竞争对手。 相对于 i 对候选进行排序并选择最佳删除成为核心思想，可以通过维护候选优势结构并选择对 i 帮助最大的最小成本删除来解决。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力子集 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了|
 | 贪心+排序+选择 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们独立处理每个候选 i，但我们避免通过推理前缀和后缀贡献来从头开始重新计算所有内容。 

1. 确定候选人 i 作为潜在获胜者。 将所有其他候选者分为两组：索引小于 i 的组和索引大于 i 的组。 
2. 如果没有人被取消资格，则计算候选人 i 的基线投票。 这是 c 加上 ai 加上尚未决定的选民当前转向候选人 1 的效果，因此如果 i > 1，候选人 i 最初不会收到 c。 这表明，在不取消资格的情况下，只有候选人 1 可以从尚未决定的选民中受益，因此指数较高的候选人需要进行结构性改变才能获得 c。 
3.观察到，为了使i具有竞争力，我们可能需要删除一些索引小于i的候选者，使得i成为一些不合格候选者前缀中最小的剩余索引。 这是我开始收到尚未决定的选票的唯一方法。 
4. 对于固定数量的 k 次取消资格，最佳策略始终是选择其去除给 i 带来最大利益的候选人。 删除候选者 j < i 会给未定池带来好处 ai ，并且如果 j 很强的话还会消除潜在的竞争对手效应。 
5. 为了最小化 k，我们根据所有候选者 j ≠ i 帮助 i 获胜的“有效性”对它们进行排序。 既是强有力的竞争对手，又拥有大人工智能的候选人是最有价值的移除对象。 
6. 然后，我们按照收益递减的顺序贪婪地删除候选人，直到满足“i 的最终选票严格大于所有剩余候选人的选票，或者平局有利于 i”这一条件。 
7. 这个贪婪过程中使用的移除次数就是候选 i 的答案。 

关键的不变量是，在贪婪删除的每一步中，我们都保持剩余候选者的最佳配置，以最大化 i 每次删除的获胜利润。 因为每次删除对 i 的投票总数和竞争对手集都有单调影响，所以首先选择影响最大的删除可以保证如果我可以通过 k 个删除获胜，那么贪婪过程将在 k 个步骤中实现它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, c = map(int, input().split())
    a = list(map(int, input().split()))

    # We compute answers independently; this is the clean conceptual solution.
    # (Optimized versions exist, but this keeps logic faithful to the reasoning.)

    res = []

    for i in range(n):
        # candidate i
        need = 0

        # current vote for i if nobody removed:
        # only candidate 1 gets c, so i gets nothing unless i == 1
        votes_i = a[i]

        # simulate: we will greedily "activate" undecided votes by removing candidates < i
        gain_pool = c
        used = 0

        # collect all candidates except i
        others = []
        for j in range(n):
            if j == i:
                continue
            others.append((a[j], j))

        # sort by descending contribution heuristic:
        # removing someone gives us their ai into pool
        others.sort(reverse=True)

        current_i = a[i] + (c if i == 0 else 0)
        current_best = max(a[j] for j in range(n) if j != i)

        for val, j in others:
            if current_i > current_best or (current_i == current_best and i < j):
                break
            used += 1
            current_i += val
            current_best = max(current_best, 0)
            current_best = max([a[k] for k in range(n) if k != i and k != j] + [0])

        res.append(str(used))

    print(" ".join(res))

if __name__ == "__main__":
    solve()
```代码遵循贪心解释：对于每个候选人，它按照 ai 递减的顺序重复删除候选人，将其支持者累积到对候选人 i 的未定池效应中。 停止条件检查 i 是否在规则下严格占主导地位，包括按索引打破平局。 

主要的微妙之处在于正确地模拟了这样一个事实：犹豫不决的选民总是流向最小的活跃指数。 这就是候选 1 在初始化时表现不同的原因。 该实现通过向候选人 1 提供初始 c 贡献来对待这一点，而其他人必须通过删除来获得对它的访问权。 

## 工作示例

 ### 示例 1

 输入：```
3 1
2 0 3
```我们评估每位候选人。 

对于候选者 1，它已经收到 c = 1 未决定票，因此其总数为 3，而其他为 0 和 3。平局有利于较小的索引，因此候选者 1 至少已经达到所需的强度，需要零删除。 

对于候选人2来说，它需要以价值3超过候选人3。删除候选人3会将其支持者转化为未定票，间接给候选人2足够的推动力。 

对于候选人 3，它已经拥有最大的原始支持，但它最初并没有从未决定的选票中受益，因此它需要删除两名较早的候选人来改变投票动态。 

| 我| 初始强度| 主要竞争对手| 搬迁| 最终状态|
 | --- | --- | --- | --- | --- |
 | 1 | 2 + 1 | 3 | 0 | 胜利|
 | 2 | 0 | 3 | 1 | 轮班后获胜 |
 | 3 | 3 | 2 | 2 | 孤立的胜利|

 这一轨迹表明，指数较低的候选人自然会主导尚未做出决定的选民，除非取消资格而改变他们的投票权。 

### 示例 2

 输入：```
2 3
0 10
```对于候选人 1，尚未决定的选民都投给了它，因此它立即获得了 3 票。 候选人 2 有 10 个，但没有收到任何 c，除非候选人 1 被删除。 删除候选人 1 会将所有未决定的选票转移给候选人 2，因此取消一次资格就足够了。 

| 我| 初始 i 票 | 竞争对手| 搬迁| 结果 |

 这演示了关键机制：删除最小的索引候选者会重新分配整个未决定的池。

 ## 边缘情况

 一个关键的边缘情况是仅 c 就已经确定了获胜者。 对于像 n = 5、c = 100 和所有 ai = 0 这样的输入，候选人 1 总是获胜，没有任何取消资格。 该算法反映了这一点，因为候选者 1 开始时可以完全访问 c，并且不需要删除来提高其位置。 

另一个边缘情况是当单个非常大的 ai 存在于高索引时。 例如，如果a[n]非常大，那么它之前的候选人必须触发一系列取消资格的行为，以重新引导尚未决定的选民并压制那个占主导地位的竞争对手。 贪婪移除顺序通过首先优先考虑大型 AI 移除来解决此问题，确保尽早消除最强的阻止者。 

最后一个微妙的情况是打破平局决定结果。 如果候选人 i 与指数较低的候选人票数相同，我就输了。 在检查停止条件时，算法必须确保严格不等式，而不仅仅是相等。
