 ## 解决方案
 ## 问题理解

 我们有一棵有根树，每个顶点都有权重。 树结构由父数组描述，因此除根之外的每个节点都只有一个父节点，并且整个图是连通且非循环的。 

称为刺猬的有效结构是通过选择中心顶点来定义的$v$然后选择至少两条简单路径从$v$，每个都经过不同的邻居$v$，并且所有这些路径的边长必须完全相同。 长度允许为零，相当于停留在中心而不移动。 刺猬是这些路径上所有顶点的并集，其权重是所有包含顶点的权重之和，中心计算一次。 

任务是在中心的所有选择和等长分支的所有有效集合上找到这种结构的最大可能权重。 

约束条件达到$n = 5 \cdot 10^5$，这立即排除了任何二次方$n$。 甚至$O(n \log^2 n)$解决方案需要仔细处理，任何以简单的方式重复重新计算每个节点每个深度的方法都会太慢。 

一些边缘情况值得牢记。 如果所有权重都为负，那么如果允许零长度解释，最好的刺猬可能会折叠到单个顶点，因为我们仍然需要选择至少两条路径，但它们都可能是微不足道的。 在星形树上，最佳解决方案通常以根为中心，长度为 1 或 0，具体取决于权重。 在链上，结构退化，获得两个相等分支的唯一有效方法通常是长度为零。 

一种幼稚的方法是尝试每个中心$v$, 每个长度$L$，以及来自不同邻居的每对分支，独立计算最佳路径。 这立即变得不可行，因为即使计算固定的最佳下行路径$v$跨越所有$L$每个节点已经花费了线性时间。 

## 方法

 核心难点是对于一个固定的中心$v$，我们需要知道，对于每个可能的深度$L$, 最佳路径从$v$进入其每个相邻的子树。 一旦我们有了这个，答案就是$v$是通过对每个$L$，其邻居中两个最大的此类值的总和加上$a[v]$。 

对于每个节点，暴力方法都会计算$v$，在其子树的所有深度上的 DP，其中$dp[v][L]$是最佳路径长度和$L$开始于$v$。 这个 DP 自然地被定义为子级的合并：将每个子级的数组移动 1 并取最大值。 问题是这些数组的大小可以是$O(n)$链状树中的每个节点，因此总工作量变为$O(n^2)$。 

关键的观察是，合并后我们永远不需要完全分离每个子项。 对于每个节点$v$，对于每个深度$L$，我们只关心所有孩子中最好的两个贡献。 这意味着我们不是单独跟踪每个子节点，而是对于每个节点和深度，仅维护来自不同子树的前两个值。 

这导致了树上经典的从小到大合并DP，其中每个节点存储将深度映射到最佳和次佳路径和的结构。 处理节点时，我们将子节点一个接一个地合并，始终将子节点的移位 DP 插入到当前结构中，同时每个深度仅保留两个最佳值。 

由于每个子树结构在摊销意义上仅合并为一个较大的子树结构的对数次数，因此这种方法保持足够快$n = 5 \cdot 10^5$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 在所有节点和深度上进行强力 DP |$O(n^2)$|$O(n^2)$| 太慢了|
 | 从小到大的 DP 以及每个深度的前两个值 |$O(n \log n)$摊销|$O(n \log n)$| 已接受 |

 ## 算法演练

 我们以节点 1 为树根（或使用给定的父关系）并按后序处理节点。 

1. 对于每个节点$v$，我们维护一个类似字典的结构$dp[v]$对于每个深度$d$，我们存储从以下位置开始的路径的最佳两个值$v$，向下进入其子树，恰好$d$边缘。 每个值表示沿着该路径的节点权重的总和。 这种结构压缩了所有子贡献，而不将它们分开。 
2.初始化各个节点$v$仅与$dp[v][0] = (a[v], -\infty)$，意味着长度为零的路径仅由节点本身组成。 第二个值是一个占位符，指示最初仅存在一条平凡路径。 
3. 处理子进程$v$逐个。 对于一个孩子$c$，我们首先将所有深度移动$dp[c]$增加一，因为从$c$向上至$v$将其长度增加一并添加$a[v]$到所有这样的路径。 这会产生从以下位置开始的路径的候选贡献$v$并进入子树$c$。 
4. 将这些移位后的值合并为$dp[v]$。 对于每个深度$d$，我们现在可能有来自不同孩子的多个候选人。 我们只保留每个深度的最佳两个值，因为最终的刺猬只需要两个分支。 
5. 合并所有子项后，我们计算以$v$。 对于每个深度$d$，我们查看存储在中的前两个值$dp[v][d]$，并用它们的总和更新答案。 这对应于选择两个长度相等的不同分支$d$。 
6. 全局答案是所有节点和所有深度的最大值。 

微妙的部分是，合并必须在每个深度的前两个值的级别上保持子级之间的分离。 这确保了当我们稍后选择两个分支时，它们确实来自不同的子树。 

### 为什么它有效

 对于任意固定中心$v$和深度$d$，任何有效的刺猬都会选择从不同邻居开始的两条不相交的路径$v$。 每条这样的路径完全位于一个子子树中。 因此刺猬的贡献$(v, d)$正是该深度上两个最大的独立子贡献的总和。 由于我们在合并所有子项后保留每个深度的前两个值，因此我们准确地保留了重建最佳选择所需的信息。 没有其他信息影响可行性或最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

from collections import defaultdict

n = int(input())
p = list(map(int, input().split()))
a = list(map(int, input().split()))

g = [[] for _ in range(n)]
for i, par in enumerate(p, start=1):
    g[par - 1].append(i)

# dp[u]: dict depth -> (best1, best2)
# stored as lists for speed: dict of depth -> [best1, best2]
def merge_into(big, small, shift):
    for d, (best, second) in small.items():
        nd = d + shift
        val = best
        if nd not in big:
            big[nd] = [val, -10**30]
        else:
            if val > big[nd][0]:
                big[nd][1] = big[nd][0]
                big[nd][0] = val
            elif val > big[nd][1]:
                big[nd][1] = val

def dfs(u):
    dp = {0: [a[u], -10**30]}

    for v in g[u]:
        child = dfs(v)

        # shift child by +1 and merge into dp[u]
        for d, (b1, b2) in child.items():
            nd = d + 1
            val = b1 + a[u]

            if nd not in dp:
                dp[nd] = [val, -10**30]
            else:
                if val > dp[nd][0]:
                    dp[nd][1] = dp[nd][0]
                    dp[nd][0] = val
                elif val > dp[nd][1]:
                    dp[nd][1] = val

    # compute answer contribution at u
    for d, (b1, b2) in dp.items():
        if b2 != -10**30:
            ans[0] = max(ans[0], b1 + b2)

    return dp

ans = [-10**30]
dfs(0)
print(ans[0])
```DFS为每个节点构建了一个自下而上的结构。 每个`dp[u]`字典存储按深度分组的最佳向下路径总和，每个条目仅保留前两个值。 在合并期间，子贡献会移动一条边，并通过添加当前节点权重进行调整，因为每条路径都通过所有中间节点锚定在中心。 

答案更新步骤仅使用已存储在同一深度桶中的对，确保两个分支具有相等的长度并且来自不同的子树。 

## 工作示例

 ### 示例 1

 考虑一棵小树，其中节点 1 连接到 2 和 3，并且 2 和 3 都是叶子。 

| 节点| 深度 | 最佳1 | 最佳2 |
 | --- | --- | --- | --- |
 | 2 | 0 | a2 | -inf|
 | 3 | 0 | a3| -inf|
 | 1 | 0 | a1 | -inf|
 | 1 | 1 | a1+a2 | a1+a3 |

 在节点 1，深度 1 有两个来自节点 2 和 3 的分支。该算法正确地识别出最好的刺猬使用两个子节点，给出总计$a1 + a2 + a3$。 

该轨迹表明，等深度分组自然会强制分支的对称性。 

### 示例 2

 考虑具有任意权重的链 1-2-3-4。 

| 节点| 深度 | 最佳1 | 最佳2 |
 | --- | --- | --- | --- |
 | 4 | 0 | a4| -inf|
 | 3 | 0 | a3| -inf|
 | 3 | 1 | a3+a4 | -inf|
 | 2 | 0 | a2 | -inf|
 | 2 | 1 | a2+a3 | -inf|
 | 2 | 2 | a2+a3+a4 | -inf|

 在任何节点上，我们都不会获得相同正深度的两个有效分支，因此答案会崩溃为最佳的单个顶点贡献。 这证明了至少两个相等分支的要求如何防止链状结构形成大刺猬。

 ## 边缘情况

 在中心有许多子节点的星形树中，该算法存储多个深度零和深度一贡献。 合并步骤确保只有前两个子分支很重要，并且所有额外的分支都将被忽略，除非它们改善了两个最佳值之一。 

在一条长链中，除了端点之外的每个节点都只有一个向下的延续，因此任何深度都不会累积两个独立的贡献。 因此，dp 结构永远不会触发有效对，并且答案会减少到最佳单节点值。 

在具有混合正负权重的树中，即使包含负中间节点，较深的路径也可以优于较浅的路径。 DP 正确地执行这些操作，因为它始终考虑完整路径总和，而不是每个节点的本地选择。
