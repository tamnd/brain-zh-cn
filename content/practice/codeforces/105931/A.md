 ## 解决方案
 ## 问题理解

 该大学正在招收最多`n`学生总数。 每个学生都必须属于两类之一。 

如果学生支付学费，他们会贡献固定金额`a`到大学。 

如果学生获得奖学金，他们的资金来自赞助商。 赞助商最多支持`b`学生，金额线性减少：第一个奖学金给`b`，第二个给出`b - 1`，依此类推，直到第 k 个奖学金给出`b - k + 1`。 

大学决定多少学生`k`总数中`n`将成为奖学金获得者，但限制是`k`不能超过`b`。 全部剩余`n - k`学生是付费学生。 目标是选择`k`这样，从学费加上赞助中收到的总资金就可以最大化。 

产出就是可实现的最大总收入。 

约束条件允许`n`,`a`， 和`b`最多`10^9`。 这立即排除了任何尝试每个可能值的方法`k`并在线性时间内重新计算结果。 甚至迭代所有`k`是不可能的，因为`k`本身可以达到`10^9`。 

直接模拟也是有问题的，因为学术部分涉及对递减的算术级数求和，该级数在`k`。 任何幼稚的每个学生模拟都会太慢。 

当一个人尝试贪婪的推理时，例如总是获得尽可能多的奖学金或总是更喜欢付费学生，就会出现一种微妙的失败案例。 例如，如果`a`很小，对于早期价值观而言，奖学金可能仍然更好`k`但更糟糕的是，当边际奖学金降至以下时`a`。 这会创造总利润的峰值，而不是单调的行为，因此局部决策会失败。 

## 方法

 暴力方法会尝试所有可能数量的奖学金学生`k`从`0`到`min(n, b)`。 对于每个选择，我们将收入计算为`(n - k) * a`加上算术级数的总和`b + (b - 1) + ... + (b - k + 1)`。 

在 O(k) 中计算每个和将使解决方案在最坏的情况下为 O(n^2)，这太大了。 即使我们使用算术级数公式来计算 O(1) 中的每个候选，我们仍然需要测试最多`10^9`的值`k`，这是不可能的。 

关键的观察结果是目标函数不是任意的。 奖学金金额的平方`k`，学费部分是线性的`k`。 总函数变为凹二次函数`k`。 这意味着它有一个峰值，一旦我们超过它，该值只会下降。 

这种结构使我们能够避免搜索整个范围。 我们不是枚举所有值，而是通过分析计算峰值的位置，并且仅检查恒定数量的附近候选值以及边界值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(min(n, b)) 或更糟 | O(1) | O(1) | 太慢了|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将总利润表示为以下函数：`k`， 在哪里`k`是奖学金学生的数量。 其余`n - k`学生缴纳学费，贡献`(n - k) * a`。 奖学金贡献是一个算术级数`k`条款开始于`b`。 
2. 使用封闭式公式重写奖学金金额。 总和变为`k * (2b - k + 1) / 2`。 这消除了任何迭代的需要。 
3. 将两个部分组合成一个表达式，仅依赖于`k`。 简化后，问题简化为最大化二次函数`k`超过整数范围`[0, min(n, b)]`。 
4. 确定该函数是凹函数，因为系数为`k^2`是负数。 这保证了单个最大点，因此我们只需要定位峰值而不需要穷举搜索。 
5. 使用导数思想计算实值最优点，得出`k* = (2b - 2a + 1) / 2`。 这代表奖学金的边际收益与固定学费收益相平衡。 
6. 自从`k`必须是整数，考虑周围最接近的整数`k*`。 还包括边界值`0`和`min(n, b)`因为最优值可能位于可行区间之外或受到约束限制。 
7. 评估每个候选人的利润`k`并取最大值。 

### 为什么它有效

 利润函数超过`k`是凹二次方程，这意味着它在单个峰的两侧都减小。 任何整数最大值必须位于实际最优值的下限或上限或有效区间的边界处。 通过仅检查这些点，我们保证捕获全局最大值，而无需枚举所有可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def calc(n, a, b, k):
    # tuition part + scholarship part
    return (n - k) * a + k * (2 * b - k + 1) // 2

def solve():
    n = int(input())
    a = int(input())
    b = int(input())

    max_k = min(n, b)

    # continuous optimum
    k_star = (2 * b - 2 * a + 1) / 2

    candidates = set()

    for x in [0, max_k]:
        candidates.add(x)

    for x in [int(k_star), int(k_star) + 1]:
        candidates.add(x)

    best = 0
    for k in candidates:
        if 0 <= k <= max_k:
            best = max(best, calc(n, a, b, k))

    print(best)

if __name__ == "__main__":
    solve()
```功能`calc`无需模拟，直接评估利润公式。 这很重要，因为逐个学生扩展该过程是不可行的。 

候选集包括边界和解析最优值周围的邻域。 铸件`k_star`为整数并检查下一个值，确保我们不会由于地板效应而错过离散最大值。

 ## 边缘情况

 一种边缘情况是当`a`数额如此之​​大，以至于任何奖学金都会立即减少总利润。 例如，`n = 5`,`a = 10`,`b = 3`。 该函数位于`k = 1`相比之下已经减少了`k = 0`。 该算法仍然可以正确处理这个问题，因为`k = 0`明确包含在候选者中，确保不会错过最大的机会。 

另一种边缘情况发生在`b`小于`n`。 例如，`n = 10`,`b = 3`,`a = 1`。 即使学生很多，奖学金也不能超过3个。算法正确地将搜索范围限制在`min(n, b)`，所以它永远不会评估无效值`k`。 

最后的边缘情况是二次峰值位于可行区间之外。 例如，如果计算出`k*`为负数，例如当`a`相比之下非常大`b`，有效最大值出现在`k = 0`。 由于该算法始终检查边界值，因此它可以正确处理这种情况，而无需依赖分析峰值。
