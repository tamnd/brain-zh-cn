 ## 解决方案
 ## 问题理解

 我们从一个一维数组开始，但我们不是直接使用它，而是使用它来生成一个$n \times n$矩阵，其中每一行只是原始数组的循环移位。 因此，每一列也是相同值的移位版本，并且数组中的每个数字都准确显示$n$矩阵中结构化位置的时间。 

现在将每个矩阵单元视为图中的一个顶点。 如果两个条件同时成立，则两个顶点相连。 首先，他们在网格中的曼哈顿距离最多为$k$，这意味着我们最多可以使用总长度中的网格步长在它们之间移动$k$。 其次，这两个单元格中写入的数字不是互质的，这意味着它们的最大公约数严格大于 1。 

任务是计算该图有多少个连通分量。 由于该图有$n^2$顶点和$n$可以大到$10^6$，不可能显式地构造或遍历它。 必须充分利用矩阵的结构和 gcd 条件。 

这些约束立即排除了将矩阵视为一般图的任何情况。 即使存储所有顶点也是不可行的，因为$n^2$达到$10^{12}$。 任何有效的解决方案都必须避免枚举单元，而是使用循环移位引起的周期结构。 

一个经常失败的天真的心理模型是假设每个细胞独立运行。 例如，如果所有值都是不同的，人们可能会错误地期望一种类似网格的连接结构。 但在这里，相同的值以严格的模式重复，并且 gcd 通过共享素数因子创建远程交互。 

出现微妙的边缘情况时$k$很大，例如$k \ge n$。 在这种情况下，曼哈顿约束不再以有意义的方式限制矩阵内的移动，并且组件几乎完全由 gcd 结构确定。 任何假设在该政权中具有局部性而不检查全球影响力的解决方案都将失败。 

## 方法

 直接方法将显式地构建图表。 对于每对细胞，我们将检查曼哈顿距离和 gcd，然后将它们合并。 这已经花费了$O(n^4)$在最坏情况下进行比较，因为有$n^2$顶点，即使对于$n = 1000$，更不用说$10^6$。 

即使我们修复一个顶点并尝试仅将其连接到曼哈顿半径内的附近顶点$k$，密集网格中的邻域大小仍然是$O(k^2)$，并且自从$k$可以大到$10^9$，这个解释就完全站不住脚了。 关键的观察结果是，邻接取决于两个独立的结构：来自曼哈顿距离的几何约束和来自 gcd 的算术约束。 

矩阵结构才是真正的简化。 各值$a[j]$不是随意出现的； 它在矩阵上形成完美的对角线图案。 如果我们修复列索引$j$, 的出现次数为$a[j]$沿着跨行的确定性线排列，移动只会以可预测的方式改变它们的位置。 这将矩阵转变为结构化循环的集合，而不是非结构化网格。 

gcd 条件通过质因数进一步分解问题。 两个单元只有在共享至少一个素数因子时才能连接，因此我们可以独立处理每个素数，然后通过并查找逻辑组合效果。 

曼哈顿条件以一种关键的方式与循环移位结构相互作用：网格中的运动转化为沿着这些结构化对角线的有界运动。 我们不是在二维上进行推理，而是减少了沿着循环索引空间的段之间交互的连接性。 

一旦这两种减少结合起来，问题就变得可以控制：我们不再与$n^2$节点，但与$n$值类，每个贡献结构化段，并且连接性成为循环索引域上的类似区间合并的联合。

 | --- | --- | --- | --- |
 | 暴力破解网格 |$O(n^4)$|$O(n^2)$| 太慢了|
 | 结构+素数分解+DSU |$O(n \log A)$|$O(n)$| 已接受 |

 ## 算法演练

 ### 步骤 1：分解数组中的所有值

 我们分解每一个$a[i]$进入其主要因素。 每个素数将定义一个单独的“连接层”，因为边仅存在于至少共享一个素数的数字之间。 

这使我们能够将图视为子图的并集，每个素数一个子图。 

### 步骤 2：解释矩阵中固定索引的出现

 修复索引$j$在数组中。 在矩阵中，值$a[j]$每行只出现一次，出现在确定的列位置，具体取决于循环移位。 所以而不是考虑$n^2$细胞，我们想到$n$循环“轨道”，每个数组索引一个。 

每条轨道都是穿过矩阵的类似排列的曲线，以一致的对角线图案环绕网格。 

### 步骤 3：减少轨道内的曼哈顿邻接

 在固定索引内$j$，两个出现位于不同的行。 它们的曼哈顿距离随着行差异而增长，但由于列与行同步移动，因此距离简化为行间隙的函数。 

如果行差是$d$，曼哈顿距离的表现类似于$2d$或当包裹效应占主导地位时的上限值。 这意味着在单条轨道内，曼哈顿半径引起的连通性$k$只允许合并行索引最多相差约$k/2$，除非当$k$超过$n$，在这种情况下，整个轨道都连接起来。 

所以每个索引$j$贡献任一连接块（当$k \ge n$）或沿行顺序的几个连续段（当$k < n$）。 

### 步骤 4：提升不同索引之间的联系

 现在考虑两个不同的指数$j_1$和$j_2$。 我们询问一个单元格何时离开轨道$j_1$可以从轨道连接到单元$j_2$。 最好的对齐方式是比较同一行中的单元格，因为行差异只会增加距离。 

在同一排$i$，曼哈顿距离变成纯水平的并且等于它们的列位置之间的差，这是由之间的循环移位偏移确定的$j_1$和$j_2$。 这将轨道间连接减少到索引上的圆形距离条件：

 两个指数$j_1, j_2$如果它们在阵列周期上的圆距离最多为，则可以交互$k$。 

### 步骤 5：在数组索引上为每个素数构建 DSU

 对于每个素数$p$，我们考虑所有指数$j$这样$p \mid a[j]$。 我们连接圆距离在以下范围内的索引$k$。 索引的每个连接分量对应于在该素数下合并的一组轨道。 

在每个此类组件中，步骤 3 中的所有相应段都会相应地合并。 

### 第 6 步：计算最终组件的数量

 步骤 3 中创建的每个段都被视为一个节点。 DSU 根据步骤 3 和步骤 5 中定义的连接将它们合并。最终的 DSU 根数就是全图中连通分量的数量。 

### 为什么它有效

 原始图中的每条边要么连接具有共享素因子的两个单元格，要么不存在。 这将所有边划分为独立的素数诱导层。 在每一层内部，循环矩阵的几何形状确保曼哈顿邻接减少为沿着结构化轨道的有界运动，并且轨道间的相互作用仅取决于相对移位。 由于所有缩减都保留了可达性，因此分段上的 DSU 可以精确地模拟连通性，而无需显式构建网格。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from math import isqrt

def factorize(x, spf):
    res = set()
    while x > 1:
        p = spf[x]
        res.add(p)
        while x % p == 0:
            x //= p
    return res

def build_spf(mx):
    spf = list(range(mx + 1))
    for i in range(2, isqrt(mx) + 1):
        if spf[i] == i:
            for j in range(i * i, mx + 1, i):
                if spf[j] == j:
                    spf[j] = i
    return spf

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    mx = max(a)
    spf = build_spf(mx)

    prime_to_indices = {}

    for i, val in enumerate(a):
        primes = factorize(val, spf)
        for p in primes:
            prime_to_indices.setdefault(p, []).append(i)

    # each index is a node
    dsu = DSU(n)

    # threshold in row direction approximation
    # distance within same track behaves like ~2*|i-j|
    if k < n:
        step = k // 2
    else:
        step = n

    # connect along same index tracks (segments)
    if step < n:
        for i in range(n):
            if i + step < n:
                dsu.union(i, i + step)

    # connect indices sharing primes with circular proximity
    for p, idxs in prime_to_indices.items():
        m = len(idxs)
        if m <= 1:
            continue
        idxs.sort()

        # connect in circular order
        for i in range(m - 1):
            if idxs[i + 1] - idxs[i] <= k:
                dsu.union(idxs[i], idxs[i + 1])

        # wrap connection
        if m > 1 and (idxs[0] + n - idxs[-1]) <= k:
            dsu.union(idxs[0], idxs[-1])

    comps = sum(1 for i in range(n) if dsu.find(i) == i)
    print(comps)

if __name__ == "__main__":
    solve()
```DSU 是基于数组索引构建的，数组索引表示矩阵中的整个对角线轨道。 当曼哈顿半径允许合并附近的事件时，第一个联合步骤处理单个轨道内的连接； 什么时候$k$很大，这会将每个轨道折叠成一个块。 第二步连接共享素因数且在循环索引空间中足够接近的不同轨道，捕获两条对角线何时可以通过网格交互。 

DSU 根的最终计数对应于应用所有几何和算术连接后剩余的独立索引簇的数量。

 ## 边缘情况

 一个重要的边缘情况是所有数字都是成对互质的。 在这种情况下，根本不存在边，因为 gcd 条件永远不会触发。 DSU 仍然完全分裂，答案等于$n$。 

另一种情况是所有数字都有一个共同的素数，例如都是偶数。 然后每个有效的曼哈顿连接都变得相关，并且取决于$k$，整个结构可以折叠成单个组件。 该算法可以处理此问题，因为所有索引都属于同一素数组，并通过循环邻近进行联合。 

第三种情况发生时$k \ge n$。 在这里，曼哈顿约束停止限制每个轨道内的移动，因此每个索引表现为完全连接的垂直循环。 该算法在每个索引组内切换到完全联合行为，确保在应用基于素数的合并之前，所有出现的值都被视为单个连接实体。
