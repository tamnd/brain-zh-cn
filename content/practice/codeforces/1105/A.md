 ## 解决方案
 ## 问题理解

 我们得到了棍子长度的列表，并且允许我们用任何其他正整数替换每个长度。 将一根棍子从其原始长度更改为新长度的成本恰好是两个值之间的绝对差值。 目标不是使所有棒子相等，而是使每根棒子“接近”选定的整数目标$t$，在所有变化之后，每个最终长度必须位于距离 1 之内$t$。 这意味着每根最后的棍子都必须以以下三个值之一结束：$t-1$,$t$， 或者$t+1$。 

我们可以自由选择修改哪根棍子以及修改的值$t$。 目标是最小化总修改成本。 

约束条件$n \le 1000$和$a_i \le 100$立即表明，对所有选择和分配采用三次或更差的方法是不必要的，但如果仔细限制的话，仍然可能是可以容忍的。 然而，真正的简化来自于原始值和最终值都位于非常小的整数范围内的事实。 这意味着任何最佳目标$t$不需要很大，事实上只有接近输入范围的值才重要。 

天真的思维的一个微妙的失败案例是假设我们可以贪婪地将每根棍子舍入到最接近的$t-1, t, t+1$。 虽然这部分是正确的，但困难的部分是选择最好的$t$。 例如，如果我们选择一个较差的$t$，局部最优舍入仍然会产生全局昂贵的配置。 

另一个错误是假设$t$应接近数组的平均值或中位数。 这是错误的，因为引入“三桶”约束后，成本函数不再围绕单个中心对称。 

边缘情况示例：

 输入：```
3
1 100 100
```如果我们猜测$t = 50$，我们被迫将值映射到{49,50,51}，这使得两端的成本都很大。 但更好的选择是$t = 100$，其中只有一个元素发生显着移动。 

这表明候选人$t$必须明确评估而不是推断。 

## 方法

 蛮力的想法很简单：尝试每个可能的整数$t$，对于每根棍子，计算将其移入的最便宜的方式$\{t-1, t, t+1\}$。 对于固定的$t$, 每根棍子贡献$\min(|a_i-(t-1)|, |a_i-t|, |a_i-(t+1)|)$。 将所有棍子相加即可得出总成本。 这是正确的，因为每根棍子都是独立的一次$t$是固定的。 

这种方法的问题是范围$t$。 理论上，$t$是无界的，但实际上成本函数仅围绕输入值发生有意义的变化。 如果$t$远远超出范围$[1, 100]$，每根棍子都映射到一个非常遥远的值，并且成本只会单调增加。 所以我们只需要测试一下$t \in [1, 100]$，这使得暴力破解完全可行。 

关键的观察结果是，变换仅取决于到三个相邻整数的距离，并且所有原始值都位于一个小的有界范围内。 这折叠了搜索空间$t$到一个恒定大小的间隔。

 ## 算法演练

 我们迭代所有候选值$t$，计算变换所有棍子的成本，并保留最好的结果。 

1. 限制搜索范围$t$到 1 到 100，因为所有棒长度都在此范围内，并且最佳解决方案不需要超出该范围。 这使搜索保持有限，而不会丢失有效的最佳值。 
2. 对于每位候选人$t$，将运行成本变量初始化为零。 
3. 对于每个棒长度$a_i$，计算将其转换为以下之一的最小成本$t-1, t, t+1$，同时确保所有目标值保持正值。 这意味着忽略无效的选择，例如$t-1 = 0$。 
4.将此最小成本添加到当前的总成本中$t$。 由于决策之间不存在耦合，因此此步骤对每根棍子都是独立工作的。 
5. 处理完所有木棍后，将总成本与迄今为止找到的最佳成本进行比较。 如果较小，则存储成本和相应的$t$。 
6.检查完所有内容后$t$，输出最好的一对。 

### 为什么它有效

 对于任何固定的$t$，每根棍子都被最优地分配给最接近的允许目标值$\{t-1, t, t+1\}$。 这种局部最优性也是全局最优性，因为成本是跨棒的累加性的，并且不存在链接不同棒之间的分配的约束。 因为每一位候选人$t$明确评估后，保证能找到所有有效配置的全局最优值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    best_cost = 10**18
    best_t = 1

    for t in range(1, 101):
        cost = 0
        for x in a:
            cur = abs(x - t)
            if t - 1 >= 1:
                cur = min(cur, abs(x - (t - 1)))
            cur = min(cur, abs(x - (t + 1)))
            cost += cur

        if cost < best_cost:
            best_cost = cost
            best_t = t

    print(best_t, best_cost)

if __name__ == "__main__":
    solve()
```该代码直接实现了每个$t$评价策略。 唯一微妙的细节是防范$t-1 = 0$，因为长度必须保持正值。 其他一切都是成本分解的直接转化。 

外循环枚举候选目标。 内循环独立评估每根棍子。 明确采用三个可能目标桶中的最小值。

 ## 边缘情况

 一种边缘情况是所有值都相同。 该算法评估所有$t$，但在$t = a_i$，每根棍子都映射到自己，产生零成本。 该实现正确地捕获了这一点，因为三个候选者中的最小值包括完全匹配。 

另一种情况是当值紧密聚集但存在单个异常值时，例如`[1, 1, 100]`。 为了$t = 1$，这两个小值的成本为零，而异常值则支付 99，总计为 99。对于$t = 2$，成本变得稍微更加平衡，但仍然由异常值主导。 该算法明确评估两个区域并选择最佳区域。 

当最优值出现时，就会出现边界情况$t$接近 1。在这种情况下，$t-1$无效，并且实现避免使用它。 成本计算仍然正确地仅考虑有效目标，确保不包括非法分配。
