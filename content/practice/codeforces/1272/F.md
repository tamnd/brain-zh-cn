 ## 解决方案
 ## 问题理解

 我们有两个括号序列，`s`和`t`，单独作为括号序列可能无效。 任务是生成有效的最短括号串（平衡且正确嵌套）并且包含`s`和`t`作为子序列。 子序列允许跳过字符，因此`s`和`t`必须按顺序出现，但不一定连续出现。 

输入大小很小：每个字符串最多 200 个字符。 这意味着我们可以负担具有三次或二次时间复杂度的算法，但任何比$O(n^3)$会太慢。 我们必须小心避免枚举所有可能的插入或所有序列交错的解决方案。 

当一个或两个序列本身已经有效、一个序列完全嵌套在另一个序列内或序列具有高度不平衡的前缀时，就会出现边缘情况。 例如，如果`s = "((("`和`t = ")))"`，输出必须是`"((()))"`; 简单地连接字符串的简单方法将给出`"((()))))"`这是无效的。 同样，如果`s`或者`t`为空，输出应该只是非空字符串的常规括号补全。 

## 方法

 蛮力方法会尝试一切可能的交错方式`s`和`t`同时插入额外的支架来平衡它们。 从概念上讲，我们可以尝试在所有位置插入左括号和右括号以使合并序列有效。 这在原则上是正确的，但是可能性的数量随着长度的增加而呈指数增长。`s`和`t`- 远远超出可行的计算，即使在$n = 200$。 

更快解决方案的关键观察是，我们可以将此问题建模为最短公共超序列问题，但有一个额外的约束：该序列必须作为括号序列保持有效。 括号序列的状态可以通过未闭合“(”括号的当前计数来捕获。这激发了动态编程方法，我们跟踪每个前缀的有效超序列的最小长度`s`和`t`以及开括号中每个可能的当前平衡。 

正式地，我们定义`dp[i][j][b]`作为包含的最短序列`s[:i]`和`t[:j]`作为当前余额的子序列`b`开括号。 我们可以逐步添加“(”或“)”，只要我们不这样做`b`负数，这确保序列保持有效。 这将问题从指数时间减少到立方时间，因为最多有 200×200×200 = 8,000,000 个状态，这完全符合 2 秒的限制。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(n+m)) | O(2^(n+m)) | O(2^(n+m)) | O(2^(n+m)) | 太慢了|
 | 最佳（前缀 DP + 平衡）| O(n * m * (n+m)) | O(n * m * (n+m)) | O(n * m * (n+m)) | O(n * m * (n+m)) | 已接受 |

 ## 算法演练

 1.初始化一个DP表`dp[i][j][b]`存储第一个的最短字符串`i`的字符`s`和第一个`j`的字符`t`有平衡`b`。 开始于`dp[0][0][0]`作为空字符串。 
2. 对于每个州`(i, j, b)`在表中，考虑两个可能的后续步骤： 添加`'('`或添加`')'`。 添加`'('`将余额加一，同时添加`')'`将其减一。 仅添加`')'`如果`b > 0`以维持有效的序列。 
3. 添加括号时，检查它是否与中的下一个字符匹配`s`和/或`t`。 If it matches`s[i]`, 增量`i`在新的状态下。 同样，如果匹配`t[j]`, 增量`j`。 这确保了当当前字符在超级序列中被消耗时，我们仅在字符串中前进。 
4. 如果新字符串比该状态之前记录的任何字符串短，则用新字符串更新 DP 表。 这保证了我们始终构建尽可能最短的序列。 
5. 填充DP表后，答案就是存储在的字符串`dp[len(s)][len(t)][0]`，其中两个序列都被完全包含并且余额为零，从而确保有效的括号序列。 

工作原理：在每一步中，DP 都会捕获迄今为止决策可能产生的所有可能序列，保持当前字符串有效并包含所有消耗字符的不变性。 该状态明确包含余额，因此无法构造无效序列。 当多条路径导致相同状态时，通过始终选择较短的字符串，我们确保生成的序列最小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

s = input().strip()
t = input().strip()

n, m = len(s), len(t)

# BFS with states (i, j, balance)
queue = deque()
queue.append((0, 0, 0))
visited = {}
visited[(0, 0, 0)] = ""

while queue:
    i, j, b = queue.popleft()
    cur = visited[(i, j, b)]
    
    if i == n and j == m and b == 0:
        print(cur)
        break

    for c in "()", :
        nb = b + 1 if c == '(' else b - 1
        if nb < 0:
            continue
        ni = i + (i < n and s[i] == c)
        nj = j + (j < m and t[j] == c)
        key = (ni, nj, nb)
        new_str = cur + c
        if key not in visited or len(new_str) < len(visited[key]):
            visited[key] = new_str
            queue.append(key)
```BFS 确保我们始终首先探索最短的序列。 余额`b`跟踪开括号的数量。 我们只允许`b >= 0`为了保持有效性，我们增加序列指针`s`和`t`仅当当前括号匹配时。 这保证了输出包含两者`s`和`t`作为子序列并且是最小的。
