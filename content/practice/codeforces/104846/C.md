 ## 解决方案
 ## 问题理解

 我们有几个箱子，每个箱子里装有一定数量的硬币。 两个朋友想要分割硬币，以便每个箱子最终对他们两人都有同等的贡献，但只有当硬币数量相等时，箱子才能“兑现”。 如果一个箱子里有奇数个硬币，我们可以将所有硬币从一个箱子移到另一个箱子中，从而有效地合并一堆硬币，直到我们决定处理它们。 

一旦箱子被处理，它的硬币就会平均分配给两个朋友，所以一个箱子$x$硬币贡献$x/2$给每个人硬币，但前提是$x$甚至在处理的那一刻。 

任务不是输出一系列动作，而是计算在最佳合并箱子并处理它们后每个朋友最终可以获得的最大硬币数量。 

尽管该声明谈论的是单个箱子，但关键的结构自由是我们可以重复移动整堆硬币，这意味着我们可以在决定分割哪些硬币之前有效地将硬币任意重新排列成新的组。 

从约束的角度来看，我们显然处于线性状态：只有价值的总和和奇偶性才重要。 任何尝试显式模拟合并选择的解决方案都会变得二次或更糟，并且一旦出现就会立即失败$n$变大。 

一个常见的错误是认为各个箱子都有独立的贡献。 例如，人们可能会尝试首先贪婪地处理偶数箱子并忽略奇数箱子。 这会在以下情况下中断$1, 1, 8$，其中首先合并奇数箱子会增加可用的偶数质量。 

另一个陷阱是假设奇怪的箱子本质上是无用的。 例如，在输入中$3, 1, 1$，两个奇数箱子可以合并成$2$，使它们完全可用。 单独治疗每个箱子会失去这种效果。 

## 方法

 暴力解释将尝试所有将箱子合并成组的方法，然后决定哪些组变得均匀并进行处理。 每个分组都会改变总和，对于每个分组，我们将计算可以分配多少硬币。 的分区数$n$项目呈超指数增长，甚至将我们限制为成对合并也会导致指数搜索空间。 一旦这种方法很快就变得不可行$n$超过一个小数目。 

关键的观察是合并完全消除了结构：我们永远不会受到硬币来自哪个原始箱子的限制。 任何合并序列都允许我们将硬币重新排列成任意堆，这意味着系统唯一真正的不变性是所有硬币的总和，以及当总和为奇数时我们是否可以消除单个剩余硬币。 

一旦我们以这种方式看待这个过程，问题就不再是箱子的问题，而是有多少硬币可以配对的问题。 每一次操作都有效地允许我们重新排列代币，以便除了可能的一枚代币之外的所有代币都参与有效的均匀分配。 这将问题简化为最大化我们可以在全球范围内形成多少完整的硬币对。 

这直接得出这样的结论：除了可能一枚无法配对的剩余硬币之外，每个朋友都收到了所有硬币的一半。

 ## 算法演练

 我们处理一次输入并计算所有箱子中的硬币总数。 

1. 计算所有的总和$a_i$。 这代表可用于分裂的材料总量。 合并操作不会改变这个总和，因此它是唯一重要的全局量。 
2. 观察总和的奇偶性。 如果总数是偶数，则每个硬币都可以以某种排列方式与另一个硬币配对，因此所有硬币都对分裂做出了充分贡献。 
3. 如果总数是奇数，则无论我们如何合并箱子，都将不可避免地只有一枚硬币保持未配对状态，因为合并会保持总奇偶性。 该单一代币不能成为任何有效均分的一部分，并且实际上变得无法使用。 
4.最终答案是可用币的一半，意思是$\lfloor \text{sum} / 2 \rfloor$。 

### 为什么它有效

 合并允许任意重新分配硬币，因此原始箱子的身份无关紧要。 在所有操作中幸存下来的唯一约束是奇偶性：分裂需要偶数总数，并且每个有效的分裂都会成对消耗硬币。 由于配对是全局且不受限制的，因此最好的结果是在整个多重集合中配对尽可能多的硬币。 最多一枚硬币可以保持不成对，因此最大可用质量是不超过总和的最大偶数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

total = sum(a)
print(total // 2)
```实施直接反映了减少。 总和累加一次，整数除以二自动处理偶数和奇数情况，无需显式奇偶校验。 

一个微妙的点是不需要模拟合并。 尽管该声明强调移动整个箱子，但此操作仅用于证明任意重组是可能的，而不需要显式执行。

 ## 边缘情况

 单胸部输入，例如$10$测试解决方案是否错误地尝试要求合并到另一个箱子。 这里算法简单地计算$10 // 2 = 5$，它匹配唯一可能的分割。 

像这样的奇数配置$1, 1, 1$测试剩余的奇偶校验是否是全局处理的，而不是每个箱子处理的。 总和为3，所以答案变为1，反映出最优合并后一枚硬币无法配对。 

一个大的全偶案例，例如$2, 4, 6, 8$确认逻辑没有引入人为约束。 总和是 20，完全配对总是可以实现的，给每个朋友 10。
