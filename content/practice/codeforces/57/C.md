 ## 解决方案
 ## 问题理解

 我们被要求计算长度数组的数量`n`包含从 1 到 的整数`n`使得数组要么完全不减，要么完全不增。 换句话说，每个连续元素必须要么不小于前一个元素，要么不大于前一个元素。 结果应以 1,000,000,007 为模输出。 

输入是单个整数`n`，它确定数组长度和允许的元素范围。 约束条件可达`10^5`为了`n`，并且输出可能是一个非常大的数字，因此简单的枚举是不切实际的。 

小阵列会出现边缘情况，特别是`n = 1`和`n = 2`。 为了`n = 1`，数组`[1]`很简单，既不减也不增，所以答案是 1。对于`n = 2`，有四个有效数组：`[1,1]`,`[1,2]`,`[2,1]`,`[2,2]`。 忽略重复数字的天真方法可能会低估这里的数字。 

关键的微妙之处在于认识到每个数组并不局限于严格递增或递减的序列； 平等是允许的。 这意味着具有重复数字的数组是完全有效的。 

## 方法

 暴力解决方案将尝试生成所有`n^n`可能的长度数组`n`值从 1 到`n`，然后过滤那些不减少或不增加的。 虽然这在理论上是有效的，但数组的数量呈指数增长。 为了`n = 10^5`，即使每微秒生成一个数组也会比时间限制长得多。 因此，蛮力是不可行的。 

关键的见解是这个问题相当于计算重复的组合。 长度不减的数组`n`可以表示为选择`n`元素来自`1..n`允许重复。 重复组合的公式为`C(n + k - 1, k)`， 在哪里`k`是数组的长度，`n`是可能值的数量。 这里，`k = n`，所以非减数组的数量是`C(2n - 1, n)`。 

根据对称性，非递增数组遵循相同的计数逻辑。 但是，在此方法中，完全恒定的数组会被计数两次，一次作为非递减数组，一次作为非递增数组。 正好有`n`常量数组`[1,1,...,1]`,`[2,2,...,2]`, ...,`[n,n,...,n]`。 为了纠正重复计算，我们减去`n`。 

因此，最终的公式是`2 * C(2n - 1, n) - n`。 因为数字很大，所以必须使用模运算。 预计算阶乘和模逆允许`O(1)`每个组合的计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^n) | O(n^n) | O(n^n) | O(n^n) | 太慢了 |
 | 组合| O(n) 预计算，O(1) 查询 | O(n) | 已接受 |

 ## 算法演练

 1. 预先计算阶乘模`10^9 + 7`最多`2n - 1`。 这是有效计算组合所必需的。 如果不预先计算，重复阶乘计算就会超出时间限制。 
2. 使用费马小定理预先计算阶乘的模逆。 自从`10^9 + 7`是素数，模逆`x`模数`10^9 + 7`是`x^(mod-2) % mod`。 将这些逆元存储在数组中。 
3. 计算`C(2n - 1, n)`使用阶乘和逆阶乘数组：`fact[2n-1] * inv_fact[n] * inv_fact[n-1] % mod`。 
4. 将组合乘以 2 以考虑非递减和非递增序列。 
5. 减法`n`纠正重复计算的常量序列。 应用模数`10^9 + 7`减去后处理潜在的负面结果。 
6. 输出结果。 

为什么有效：非递减数组直接对应于重复的组合。 相同的逻辑适用于非递增数组。 重复计数仅发生在我们精确纠正的常量序列上。 该算法使用预计算和模运算来保持在时间和内存限制内。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def modinv(x, mod):
    return pow(x, mod - 2, mod)

def solve():
    n = int(input())
    max_fact = 2 * n
    fact = [1] * (max_fact)
    inv_fact = [1] * (max_fact)
    
    for i in range(1, max_fact):
        fact[i] = fact[i - 1] * i % MOD
    
    inv_fact[max_fact - 1] = modinv(fact[max_fact - 1], MOD)
    
    for i in range(max_fact - 2, -1, -1):
        inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD
    
    def comb(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * inv_fact[b] % MOD * inv_fact[a - b] % MOD
    
    result = (2 * comb(2 * n - 1, n) - n) % MOD
    print(result)

solve()
```第一部分预先计算阶乘和模逆，允许`comb(a,b)`在恒定时间内计算组合。 我们小心地处理模减法以避免负结果。

 ## 边缘情况

 对于`n = 1`，算法计算`2*C(1,1) - 1 = 2*1 - 1 = 1`，正确计算单元素数组。 为了`n = 2`,`2*C(3,2) - 2 = 6 - 2 = 4`, 正确计数`[1,1],[1,2],[2,1],[2,2]`。 预计算确保大`n`得到有效处理。 模减法小心地避免了负面结果，否则如果`2*comb`小于`n`（不是这里的情况，而是一般保护措施）。
