 ## 解决方案
 ## 问题理解

 我们被要求找到边长为 _n_ 的正方形周长上的两点之间的最短距离。 该正方形与轴对齐，因此其角位于 (0,0)、(n,0)、(0,n) 和 (n,n)。 保证这两个点位于边缘，而不是内部。 输入给出了正方形的大小和两点的坐标。 输出是一个整数 - 沿正方形边的最小距离，而不是穿过内部的欧几里得距离。 

由于正方形的边是直的且与轴对齐，因此从一点到另一点的任何路径都必须沿着周边移动，可能顺时针或逆时针移动。 例如，如果这些点位于相邻边，则最短路径可能直接沿着连接它们的角。 如果这些点位于相对侧，则可能存在多条不同长度的周边路线。 

约束 (1 ≤ n ≤ 1000) 很小。 沿着所有周边点迭代的蛮力方法可能有效，但它会很不优雅。 由于周长最多为 4000 个单位 (4 * 1000)，因此任何显式枚举边的解决方案仍然可以轻松运行。 当点位于同一边缘、拐角处或相对边缘时，就会出现边缘情况 - 粗心的距离公式可能会重复计算或错过较短的路线。 

一个棘手的情况是当两个点位于相对侧但未垂直或水平对齐时。 例如，n=5，点(0,1)和(5,3)。 天真地取沿每个轴的曼哈顿距离之和，建议路径长度为 7，但沿周长，顺时针路线是 1→0 角，然后围绕底部边缘：距离为 5 + 3 = 8。我们必须明确地将周长视为一个环。 

## 方法

 暴力法将周长视为一系列点。 人们可以按顺序枚举沿所有四个边缘的所有点，将周长展平为线性数组，并测量两个给定点的索引之间的距离。 这是可行的，因为周长很小（最多 4*n = 4000 点）。 复杂度是 O(n) 并且可以通过，但是有点麻烦并且没有必要。 

关键的观察结果是，周长可以视为长度为 4*n 的一维环。 每个点沿着这个循环映射到一个坐标。 例如，从 (0,0) 开始顺时针移动，左边缘映射到位置 0 → n、下边缘 n → 2n、右边缘 2n → 3n 和上边缘 3n → 4n。 一旦我们将两个点转换为它们的周长位置，最短距离就是沿环路的顺时针和逆时针距离的最小值：`min(abs(p1 - p2), 4*n - abs(p1 - p2))`。 

这种见解避免了显式迭代并推广到任何正方形大小，捕获所有边缘情况。 周长距离环绕的观察自然地将 2D 问题简化为 1D 模算术问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（枚举所有周边点）| O(n) | O(n) | 可接受但冗长|
 | 最佳（地图点到周边坐标）| O(1) | O(1) | O(1) | O(1) | 优雅快速|

 ## 算法演练

 1.定义从点开始的映射`(x, y)`将正方形周长上的坐标转换为沿周长的线性坐标，从 (0,0) 开始并顺时针移动。 对于左边缘上的点`(0, y)`，将其映射到`y`。 在底部边缘`(x, 0)`，映射到`n + x`。 在右边缘`(n, y)`，映射到`2*n + (n - y)`。 在顶部边缘`(x, n)`，映射到`3*n + (n - x)`。 
2. 将此映射应用于两个输入点。 这会产生两个位置`p1`和`p2`沿着一维周界环。 
3. 计算顺时针距离`abs(p1 - p2)`。 
4. 计算逆时针距离：`4*n - abs(p1 - p2)`。 
5. 输出顺时针和逆时针距离的最小值。 

工作原理：周长映射保留了沿方形边缘的相对距离。 两点之间的最短路径必须沿着该环顺时针或逆时针方向。 由于总周长是`4*n`，这两种可能性中的最小值给出了正确答案。 该方法统一处理所有边缘情况，包括同一边缘、相邻边缘或相对边缘上的点，无需特殊的分支逻辑。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def perimeter_distance(n, x1, y1, x2, y2):
    def to_perimeter(x, y):
        if x == 0:
            return y
        elif y == n:
            return 3 * n - x
        elif x == n:
            return 2 * n - y
        else:  # y == 0
            return n + x
    
    p1 = to_perimeter(x1, y1)
    p2 = to_perimeter(x2, y2)
    
    dist = abs(p1 - p2)
    return min(dist, 4 * n - dist)

n, x1, y1, x2, y2 = map(int, input().split())
print(perimeter_distance(n, x1, y1, x2, y2))
```映射函数`to_perimeter`沿着循环显式地将 2D 坐标转换为 1D 位置。 我们仔细检查边缘条件：左、上、右、下。 计算沿环路的绝对距离后，我们将其与周边的互补距离进行比较，以捕获较短的路径。 所有计算均为整数； 不需要浮点。
