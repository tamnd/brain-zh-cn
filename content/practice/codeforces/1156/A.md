 ## 解决方案
 ## 问题理解

 我们得到了一系列几何图形。 每个数字代表三种形状之一：

 -`1`= 圆圈
 -`2`= 等腰三角形，其高度等于底边长度
 -`3`= 正方形

 每个图形都被刻入前一个图形中，并选择尽可能大的尺寸。 由于每个三角形和正方形的方向都是固定的，因此每对连续的图形都有唯一的相对位置。 

我们的任务不是重建坐标。 我们只需要确定所有连续的图形对之间出现多少个不同的接触点。 有时，两个图形沿着整个线段接触，而不是在孤立的点上接触。 在这种情况下，答案是无限的。 

人物数量最多只有100个，数量很少。 任何扫描序列几次的算法都足够快。 挑战纯粹是几何性的：理解每对图形类型如何相互作用。 

第一个陷阱是接触次数不取决于实际尺寸。 因为每个图形都被最大限度地内接，所以每对图形类型总是产生相同的接触点图案。 

第二个陷阱是无限情况。 例如：```
2
2 3
```特殊三角形内切的正方形沿其整个底边接触三角形。 该边包含无限多个点，因此正确的输出是```
Infinite
```第三个陷阱是某些三元组需要修正。 考虑```
3
3 1 2
```一个正方形包含一个圆形，而圆形又包含一个三角形。 天真地添加对贡献给出`4 + 3 = 7`，但一个接触点在几何上算两次。 正确答案是6。这个特殊的配置是观察问题的关键。 

## 方法

 强力几何方法将尝试重建每个图形的精确坐标，计算连续图形边界之间的交点，合并相等的点，并检测是否存在重叠段。 

这样的解决方案不必要地复杂。 虽然`n ≤ 100`，精确地表示圆形、三角形和正方形会导致困难的几何计算，涉及无理坐标和重复点检测。 

真正的结构要简单得多。 由于每个图形都最大限度地内接并且方向是固定的，因此任何连续对的相互作用仅取决于它们的类型。 

我们可以分析一次所有可能的对。 

对于圆和三角形，三角形的三个顶点位于圆上，给出三个接触点。 

对于圆形和正方形，正方形的四个顶点位于圆上，从而提供四个接触点。 

对于三角形和圆形，圆与三角形的三条边相接触，得到三个接触点。 

对于正方形和圆形，圆与正方形的四个边相接触，产生四个接触点。 

对于三角形和正方形，或者正方形和三角形，这些图形共享整个边段。 接触点的数量是无限的。 

这立即减少了处理相邻对的问题。 

还剩下一个细节。 顺序```
3 1 2
```创建一个配置，其中点从`(3,1)`以及从开始计算的点`(1,2)`重合。 官方的几何分析表明，每次出现连续三元组`(3,1,2)`将总数减少一。 

蛮力几何完全消失。 我们只需要一个小的查找表和一个特殊的校正。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 强力几何重建| 非常大的实现复杂度| O(n) | 不切实际|
 | 配对分析+特殊三重校正| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取图形类型的顺序。 
2. 扫描每个相邻的对。 
3. 如果这对是`(2,3)`或者`(3,2)`， 打印`"Infinite"`并停止。 

这两种组合产生公共侧段而不是孤立的接触点。 
4. 否则将这一对的贡献添加到答案中。 

唯一可能的有限对是：

 -`(1,2)`或者`(2,1)`贡献`3`-`(1,3)`或者`(3,1)`贡献`4`5. 处理完所有对后，扫描每个连续的三元组。 
6. 对于每次出现`(3,1,2)`, 减去`1`从答案中。 

这消除了独特的重复计算接触点。 
7. 打印`"Finite"`以及由此产生的计数。 

### 为什么它有效

 两个允许的图形类型之间的每个最大铭文都会产生与比例无关的固定接触图案。 因此，接触点的总数是对贡献的总和。 

出现无限多个接触点的唯一方法是当正方形和特殊三角形共享整个边段时。 这些正是成对的`(2,3)`和`(3,2)`。 

在所有有限配置中，相邻对贡献的接触点之间唯一的重叠发生在三元组中`(3,1,2)`。 对每个这样的三元组减一即可删除重复的点。 没有其他三元组会产生重复的接触点。 因此，该算法对每个不同的触摸点仅计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

ans = 0

for i in range(n - 1):
    x = a[i]
    y = a[i + 1]

    if (x == 2 and y == 3) or (x == 3 and y == 2):
        print("Infinite")
        sys.exit(0)

    if x + y == 3:
        ans += 3
    else:
        ans += 4

for i in range(n - 2):
    if a[i] == 3 and a[i + 1] == 1 and a[i + 2] == 2:
        ans -= 1

print("Finite")
print(ans)
```第一个循环处理相邻对。 任何三角形与正方形的邻接都会立即使答案无穷大，因此程序立即终止。 

对于有限对，只有两种可能性。 圆形-三角形对贡献三个接触点，而圆形-正方形对贡献四个接触点。 因为相邻的数字肯定是不同的，所以检查`x + y == 3`足以识别圆形与三角形的组合`(1,2)`和`(2,1)`。 

第二个循环对每个应用进行校正`(3,1,2)`三倍。 错过这个调整是这个问题中最常见的错误。 

无需特殊处理`(2,1,3)`是需要的。 仅有的`(3,1,2)`创建重复的接触点。

import io
import sys

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    n = int(input())

    ans = 0

        else:
            ans += 4

            ans -= 1

    return f"Finite\n{ans}\n"

# infinite case

# minimum size finite
assert run("2\n1 2\n") == "Finite\n3\n"

 ## 边缘情况

 ### 与正方形相邻的三角形

 输入：```
2
3 2
```第一对是`(3,2)`。 该算法立即检测到两个禁止的邻接之一并打印：```
Infinite
```不需要进一步处理，因为共享段已经创建了无限多个接触点。 

### 特别三人组`(3,1,2)`输入：```
3
3 1 2
```这对贡献给出`4 + 3 = 7`。 

三重扫描恰好找到了一次`(3,1,2)`并减一。 

最终答案变成：```
Finite
6
```仅对贡献求和的解决方案将错误地输出 7。 

### 包含无限对的较长序列

 输入：```
5
1 3 2 1 3
```算法流程`(1,3)`成功，然后遇到`(3,2)`。 

因为这对已经创建了无限多个接触点，所以正确的输出是：```
Infinite
```其余数字无关紧要。 任何在发现这样的一对后继续计数的实现都有可能为无限配置产生有限的答案。
