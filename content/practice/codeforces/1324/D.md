 ## 解决方案
 ## 问题理解

 我们得到一个主题列表，每个主题都有两个不同的分数。 一个分数衡量该主题对老师来说有多有趣，另一个分数衡量对学生来说有多有趣。 对于任意两个不同的主题$i$和$j$，我们想知道他们的配对是否是“教师青睐的”，即教师兴趣的组合超过学生兴趣的组合：$$a_i + a_j > b_i + b_j.$$任务是数出有多少对$(i, j)$和$i < j$满足这个条件。 

重新解释这一点的一个有用方法是将两个数组折叠为每个主题的单个派生值：$$d_i = a_i - b_i.$$那么条件就变成：$$d_i + d_j > 0.$$因此，我们正在计算转换后的值总和为正数的对。 

约束允许最多$2 \cdot 10^5$主题。 对所有对进行二次扫描将需要大约$2 \cdot 10^{10}$最坏情况下的比较，这远远超出了 Python 中 2 秒的限制可以处理的范围。 这立即排除了暴力枚举。 

一个常见的微妙陷阱是符号对称性处理不当。 例如，如果许多值都是负数，那么“计算正数并相乘”之类的天真的想法就会失败，因为混合对很重要。 另一个问题是来自其他语言的溢出直觉，但这里 Python 避免了它； 真正的挑战是高效订购。 

边缘情况包括所有差异均为正（每对都有效）和全部为负（没有一对有效）。 在这种极端情况下，没有正确分离排序结构的粗心实现仍然可能会产生不正确的部分计数。 

## 方法

 暴力解决方案检查每一对$(i, j)$，计算$a_i + a_j$，将其与$b_i + b_j$，并在条件成立时递增计数器。 这是正确的，因为它直接实现了好对的定义。 然而，它需要粗略地评估$n(n-1)/2$对，这大约是$2 \cdot 10^{10}$操作时$n = 2 \cdot 10^5$，使其不可行。 

关键的简化来自于使用差异重写不等式$d_i = a_i - b_i$。 现在的条件是$d_i + d_j > 0$，或等价地$d_i > -d_j$。 这将问题转化为排序数组上的经典计数任务：对于每个元素，我们想知道其右侧有多少元素大于其负数。 

排序可以实现二分查找或两指针扫描。 排序后，对于每个$d_i$，我们可以找到第一个位置$j$这样$d_j > -d_i$，以及除此之外的所有元素都贡献有效对。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了|
 | 排序+二分查找/两个指针|$O(n \log n)$|$O(1)$额外（或$O(n)$)| 已接受 |

 ## 算法演练

 我们使用转换后的数组来解决问题$d$。 

1. 计算$d_i = a_i - b_i$对于每个主题。 

这隔离了每个主题对不等式的贡献，以便配对成为一个简单的求和条件。 
2. 对数组进行排序$d$按非递减顺序。 

排序为我们提供了单调结构，这对于有效计算有多少元素超过阈值至关重要。 
3. 对于每个索引$i$，定义阈值$-d_i$。 

我们想数一下有多少个$j > i$满足$d_j > -d_i$。 这将配对条件转换为范围计数问题。 
4.使用二分查找（或两个指针）定位第一个索引$pos$在哪里$d[pos] > -d_i$。 

所有指数均来自$pos$到$n-1$结成有效的合作伙伴$i$，因为它们满足不等式。 
5. 添加$n - \max(pos, i+1)$到答案。 

我们确保只计算与$j > i$以避免重复。 
6. 总捐款额$i$。 

当按排序顺序处理较小的索引时，每个有效对都只计算一次。 

### 为什么它有效

 正确性取决于两个属性。 首先，将不等式改写为$d_i + d_j > 0$保持等价性而不改变解空间。 其次，排序确保对于固定的$i$，有效的集合$j$索引形成数组的后缀，因为$d_j > -d_i$定义单调条件。 这种单调性保证二分搜索或两个指针捕获所有有效的伙伴，而不会丢失或重复计算任何对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

d = [a[i] - b[i] for i in range(n)]
d.sort()

ans = 0

import bisect

for i in range(n):
    # we need d[j] > -d[i] with j > i
    target = -d[i]
    pos = bisect.bisect_right(d, target)
    if pos <= i:
        pos = i + 1
    ans += n - pos

print(ans)
```代码首先构造差异数组，该数组对某个主题更受教师喜爱还是更受学生喜爱进行编码。 排序会组织这些值，以便所有比较都减少到范围查询。 

对于每个位置，我们计算有效合作伙伴可以开始使用的最小索引`bisect_right`。 然后，我们确保只计算严格大于当前索引的索引。 最后的减法`n - pos`有效地统计所有有效的合作伙伴。 

一个微妙的细节就是调整`if pos <= i`，这可以防止计算第二个索引不满足的对$j > i$。 如果没有这种更正，自配对或反向排序将被错误地包括在内。

 | 我| d[i] | -d[i] | pos (第一个 d[j] > -d[i]) | 对贡献|
 | ---| ---| ---| ---| ---|

def solve():
    input = sys.stdin.readline
    n = int(input())

    import bisect
    ans = 0

 ## 边缘情况

 当所有$a_i = b_i$， 每一个$d_i = 0$，因此没有一对满足严格的不等式。 该算法对零进行排序，并且找不到具有正和的索引，从而正确地生成零。 

当所有$a_i$比$b_i$， 每一个$d_i$是正的，所以每一对都有贡献。 排序后，各阈值$-d_i$是负数，所以每个后缀都是有效的，算法总和为$n(n-1)/2$。 

当所有$a_i$小于$b_i$， 每一个$d_i$是负数。 即使排序后，也没有对的总和为正值，因此所有二分搜索都会返回超出有效范围的位置，按预期产生零。
