 ## 解决方案

 ## 问题理解

 我们有一棵树，每个顶点的颜色要么是白色要么是黑色。 对于每个顶点$v$，我们想要查看树的所有连接子图，其中包括$v$，并在其中选择一个使分数最大化的分数，分数定义为白色顶点数减去黑色顶点数。 

另一种思考方式是每个节点都做出贡献$+1$如果它是白色的并且$-1$如果是黑色的。 对于每个顶点$v$，我们希望任何连接的节点集上的节点值的最大可能总和必须包含$v$。 

约束条件$n \le 2 \cdot 10^5$立即排除任何重新计算每个节点全局搜索的方法。 尝试从每个顶点运行 BFS 或 DP 的简单解决方案将花费$O(n^2)$最坏的情况，也远远超出了期限。 甚至$O(n \log n)$每个节点都是不可行的； 我们需要一个线性或近线性的解决方案。 

一个微妙的困难是，在任何有根意义上，节点的最佳子树不一定是它自己的子树。 它可以向各个方向扩展，不同的顶点会有重叠的最优结构。 另一个潜在的陷阱是假设采用整个树或固定根子树给出答案，这是不正确的，因为包含大的负区域会降低分数。 

例如，考虑一条链：```
1 - 2 - 3 - 4
colors: 1 0 0 1
```对于顶点 2，取整棵树得出总和$0$，但包含 2 的最优连通子树只是$\{2\}$给予$-1$，所以即使局部修剪也很重要。 对于顶点 3，最好的是$\{3,4\}$与总和$0$，而不是整棵树。 这表明我们必须仔细控制贡献的传播方式。 

## 方法

 我们首先考虑暴力策略。 对于每个顶点$v$，我们可以将其视为根并探索包含它的所有连接的子树。 这相当于枚举所有连接的归纳子图，其中包括$v$，在一般树中是指数的。 即使我们将自己限制在邻居子集上的 DP，状态的数量仍然呈指数增长。 另一种更结构化的暴力是将树扎根于$v$并运行一个允许选择子子树的DP，但它只捕获向下的子树，而错过了通过不同根向上的扩展。 对每个节点重复此操作会导致$O(n^2)$总体而言，转换速度太慢$2 \cdot 10^5$。 

关键的观察结果是，该问题是树上最大子数组和的变体，但具有所选子图必须包含根顶点的附加约束。 这提出了一个双向动态编程思想：首先为每个节点计算其向下子树的最佳贡献，然后从父节点传播信息，以便每个节点也知道通过向上扩展可以获得什么。 

第一个 DP 通道是经典的树 DP：定义$down[v]$作为开始于的连通子树的最佳总和$v$并且只会向下。 这是使用后序遍历计算的。 

第二关是重新生根。 我们传播附加价值$up[v]$，代表我们可以从子树之外获得的最佳贡献$v$，仅限于保持连接并通过父方向的路径。 组合$down[v]$和$up[v]$允许我们计算每个节点的最佳答案，就好像它是结构的中心一样。 

这正是一种结构，其中子节点的贡献除了通过父节点之外都是独立的，从而允许线性重新定位。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数 /$O(n^2)$|$O(n)$| 太慢了|
 | 树 DP + 重新生根 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们为每个节点分配一个值$w[v]$， 在哪里$w[v] = 1$如果白色和$w[v] = -1$如果是黑色的。 

### 第 1 步：任意给树生根

 我们在节点 1 处建立树。这不会改变答案，因为每个有效的连通子树都可以相对于任何根进行描述。 

### 步骤 2：计算向下贡献

 我们计算$down[v]$，连通子树的最佳总和必须包括$v$并且只扩展到它的孩子。 

对于每个节点$v$，我们从$down[v] = w[v]$。 然后对于每个孩子$u$，我们考虑扩展到该孩子是否会提高分数。 如果$down[u] > 0$，我们将其添加到$down[v]$。 否则，我们会忽略它。 

这是有效的，因为如果子子树贡献负增益或零增益，则包括它不会改善任何植根于的连接结构$v$。 

### 步骤3：第一次DFS遍历

 我们计算$down[v]$使用后序 DFS，确保子项在其父项之前得到处理。 

### 步骤 4：使用重新根计算答案

 我们现在将信息从父母传播给孩子。 让$ans[v]$是顶点的最佳答案$v$。 

最初，$ans[v] = down[v]$当植根于 1 时。 

离开父母时$v$给孩子$u$，我们必须考虑到$u$可以从其子树之外的所有事物中获得贡献。 我们传递一个值$up[u]$这代表了最好的贡献$v$的一侧不包括$u$的子树。 

计算$up[u]$，我们结合：

 - 家长的贡献$v$,
 - 兄弟姐妹的贡献$u$，
- 和$w[v]$本身。 

关键的想法是，每个节点将其邻居视为独立的分支，我们只需要知道其中最好的正贡献。 

### 步骤 5：合并结果

 对于每个节点$v$，最终答案是：$$ans[v] = w[v] + \sum \max(0, best\_branch\_contribution)$$其中分支包括子级和向上方向。 

### 为什么它有效

 该算法依赖于这样一个不变量：对于任何节点，包含该节点的最优连通子树都可以通过其邻居分解为独立的分支。 每个分支要么贡献正收益，要么完全被排除在外。 重新定位 DP 确保每个节点都被视为潜在中心，并且所有事件方向都在正确的上下文中精确评估一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n = int(input())
a = list(map(int, input().split()))

g = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

w = [1 if x == 1 else -1 for x in a]

parent = [-1] * n
down = [0] * n

order = []

def dfs(v, p):
    parent[v] = p
    down[v] = w[v]
    for to in g[v]:
        if to == p:
            continue
        dfs(to, v)
        if down[to] > 0:
            down[v] += down[to]

dfs(0, -1)

ans = [0] * n
ans[0] = down[0]

def reroot(v, p):
    ans[v] = down[v]
    for to in g[v]:
        if to == p:
            continue

        # remove contribution of child and recompute "up" effect
        if down[to] > 0:
            down[v] -= down[to]

        if down[v] > 0:
            down[to] += down[v]

        reroot(to, v)

        if down[v] > 0:
            down[to] -= down[v]
        if down[to] > 0:
            down[v] += down[to]

    ans[v] = max(ans[v], w[v])

reroot(0, -1)

print(*ans)
```该代码实现了两遍策略。 第一个 DFS 计算向下贡献，其中每个节点仅聚合正子贡献。 重新定位功能尝试将有益贡献从父方转移到每个子方，临时修改值以模拟视角转换。 关键思想是只有积极的贡献才值得传播，因此消极的分支总是被排除在外。 

一个微妙的实现问题是我们修改`down`重新生根期间就位。 这需要递归后仔细恢复以保持正确性。 该结构确保在任何时刻，`down[v]`反映了当前根方向的正确贡献。

 ## 边缘情况

 一种重要的边缘情况是所有节点都是黑色的。 在这种情况下，每个子树和都是非正的，每个节点的最佳选择就是节点本身，给出零。 该算法处理此问题是因为所有贡献都是负的，因此 DP 中不会添加任何子项，并且每个答案都会减少到零。 

另一种情况是具有一个白色中心和许多黑色叶子的星图。 中心的最佳子树仅包括其自身，但对于叶子，它包括中心以及可能存在的其他积极贡献。 重新生根确保每片叶子都将中心的贡献视为向上的分支。 

最后一种情况是一条长链，其中正数被负数分隔开。 该算法正确地切断了负片段，因为它们在向下的 DP 中不会贡献正增益，并且重新根仅重新组合有益的片段，确保不会强制包含有害节点。
