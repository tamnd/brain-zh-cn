 ## 解决方案
 ## 问题理解

 给定两个长度相等的数组，其中一个数组是固定的，另一个可以任意排列。 选择第二个数组的顺序后，我们将其值逐个位置地分配给第一个数组。 从这个成对数组中，我们为每个段计算该段内成对乘积的总和，然后对所有段求和该数量。 

重新表述计算的一个有用方法是考虑每个位置同时对多个分段做出贡献。 位置 i 处的一对贡献 a_i * b_i，但它会被计入包含 i 的每个子数组中。 因此，最终目标不仅仅是局部总和，而是加权总和，其中每个位置 i 的系数等于覆盖它的段数。 

这立即将问题变成了加权分配任务：每个位置都有一个仅由其索引确定的固定权重，而 b 中的值可以进行排列以尽可能以最佳方式匹配这些权重。 

高达 200,000 的约束 n 强制任何解决方案避免二次构造或子数组的显式枚举。 即使对每个排列进行线性扫描也是不可能的，因为单独的 b 就有 n！ 安排。 任何正确的解决方案都必须将所有子阵列的贡献压缩为单个每个位置系数，然后解决匹配问题。 

朴素推理的一个微妙的失败案例是假设将大 a_i 与小 b_i 配对始终是最佳的。 这种直觉是错误的，因为 a_i 并不是直接的权重； 真实权重取决于有多少个区间包含 i。 例如，靠近数组中心的位置包含在比边界位置更多的子数组中，因此无论其原始 a_i 值如何，它们都应该主导分配。 

## 方法

 我们从字面定义开始。 对于每个子数组 [l, r]，我们计算其中的 a_i * b_i 之和，然后对所有 (l, r) 求和。 扩展它给出了双重计数结构：每个位置 i 出现在从 i 或之前开始并在 i 或之后结束的每个子数组中。 此类子数组的数量为 i * (n - i + 1)。 因此，总目标变成了位置上的单个总和，其中每个项 a_i * b_i 乘以仅取决于 i 的固定系数。 

一旦认识到这种变换，问题就变成了：我们有固定的权重 w_i = i(n - i + 1)，并且我们希望将 b 的值分配给位置，以最小化总和 a_i * b_{perm(i)} * w_i，或者等效地最小化 b 的多重集和加权 a 之间的点积。 

标准交换参数适用。 如果两个位置具有不同的权重，则如果较大的 b 与较小的权重配对，则交换指定的 b 值可以改善答案。 这正是对两个序列进行相反方向排序的条件。 

因此，我们通过保持每个索引的 w_i 固定来隐式对 a_i * w_i 进行排序，并按升序对 b 进行排序，然后将最小的 b 与 a_i 的最大有效权重贡献相匹配。

 ## 算法演练

1. 计算每个位置i的贡献权重为w_i = i * (n - i + 1)。 这会计算有多少个子数组包含位置 i，因此它将原始嵌套子数组总和转换为位置的线性组合。 
2. 通过将 a_i 与 w_i 配对，形成表示每个位置对最终答案影响程度的值，因为每个 a_i 与其包含在子数组中的频率成比例地贡献。 
3. 按其引发的重要性 w_i * a_i 结构对数组 a 进行排序，但由于 w_i 每个索引都是固定的，因此我们通过位置影响进行排序，而不是直接修改 a。 
4. 按升序对数组 b 进行排序，以便在造成总影响最小的情况下使用较小的值。 
5. 贪婪地分配b值：将最小的b与最大的位置影响力（最大的w_i）匹配，将最大的b与最小的w_i匹配。 
6. 将结果累加为 a_i * b_assigned[i] * w_i 的 i 之和，最后取模。 

核心推理步骤是，将子数组折叠为每个位置的权重后，问题就变成了重排不等式实例。 该结构保证分配给不同权重的两个 b 值之间的任何反转都可以交换，以降低总成本。 

### 为什么它有效

 重写目标后，每个位置独立贡献为 w_i * a_i * b_{perm(i)}。 权重 w_i 是仅由索引确定的固定常数。 最终的和是两个序列之间的点积：一个固定系数序列和 b 乘以 a_i 的一个排列。 重排不等式指出，通过按升序对一个序列进行排序，并按降序对另一个序列进行排序，可以实现最小点积。 任何偏差都会产生反转，可以交换该反转以减少或维持成本，因此排序的配对是全局最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

# compute positional weights
w = [0] * n
for i in range(n):
    w[i] = (i + 1) * (n - i)

# pair a with weights
pairs = [(w[i] * a[i], i) for i in range(n)]
pairs.sort(reverse=True)

b.sort()

res = 0
for i in range(n):
    val, idx = pairs[i]
    res = (res + val * b[i]) % MOD

print(res)
```代码中的关键转换是首先构建位置权重。 因子 (i+1)(n-i) 编码有多少个子数组包含索引 i。 一旦完成，嵌套子数组结构就会完全消失，我们只使用线性数组。 

通过降低权重a_i对对进行排序可以确保最大的贡献在对齐后得到最小的b值，这是重排不等式的最佳方向。 

一个常见的实施错误是忘记权重公式中从 1 开始的索引。 使用 i * (n - i) 而不是 (i+1)(n-i) 会错误地移动所有权重并破坏子数组的组合计数。

import sys, io

def solve():
    import sys
    input = sys.stdin.readline
    MOD = 998244353

    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    w = [(i + 1) * (n - i) for i in range(n)]
    pairs = sorted([(w[i] * a[i], i) for i in range(n)], reverse=True)
    b.sort()

    ans = 0
    for i in range(n):
        ans = (ans + pairs[i][0] * b[i]) % MOD
    print(ans)

    sys.stdin = io.StringIO(inp)

    import io as _io
    out = _io.StringIO()
    with redirect_stdout(out):
        solve()

 ## 边缘情况

 关键的边缘情况是 b 的所有值都相等。 在这种情况下，任何排列都会产生相同的结果，并且算法不得依赖于意外的排序稳定性。 加权步骤本身就决定了答案，排序不应该改变正确性。 

当 a 严格递增而 b 严格递减时，会出现另一种边缘情况。 一种简单的方法可能会尝试直接匹配它们，但正确的行为完全取决于位置权重，而不是原始大小。 该算法处理这个问题是因为按加权贡献排序主导了 a 的原始排序。 

第三种情况是 n = 1，其中子数组结构崩溃，答案简化为单个乘法。 权重公式仍然有效，因为 (1)(1) 正确计算了包含该元素的单个子数组。
