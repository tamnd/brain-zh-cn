 ## 解决方案
 ## 问题理解

 我们使用长度数组`n`，其中每个元素都是来自的整数`0`到`2^m - 1`。 

如果存在某个连续子数组，其异或为，则序列称为“wool”`0`。 我们被要求计算有多少序列是_不是_羊毛，这意味着每个连续子数组都有非零异或。 

答案必须以模计算`10^9 + 9`。 

首先要注意的是，子数组上的异或自然连接到前缀异或。 如果我们定义$$p_i = a_1 \oplus a_2 \oplus \cdots \oplus a_i$$和`p_0 = 0`，然后对子数组进行异或`[l, r]`等于$$p_r \oplus p_{l-1}$$当两个前缀异或相等时，子数组异或恰好为零。 

所以问题就偷偷问了：

 “有多少数组产生成对不同的前缀异或`p_0, p_1, ..., p_n`？”

 这种重新表述就是整个问题。 

约束足够大，无法进行强力枚举。 两者都`n`和`m`可以达到`10^5`。 数组的数量是$$(2^m)^n = 2^{mn}$$即使对于中等值来说，这也是一个天文数字。 任何以二次方式迭代每个位置的数组、子集或异或状态的解决方案都将失败。 

目标复杂度大致呈线性或对数关系`n`和`m`。 

有几种容易被忽略的边缘情况。 

如果`n >= 2^m`，答案自动为零。 只有`2^m`可能的前缀异或值，但我们需要`n + 1`不同的价值观，因为`p_0`。 根据鸽巢原理，重复是不可避免的。 

例如：```
n = 2, m = 1
```允许的值为`{0, 1}`。 

只有两种可能的前缀异或，但我们需要三个不同的值：$$p_0, p_1, p_2$$不可能，所以正确答案是`0`。 

粗心的实现可能会尝试计算带有负项的下降阶乘，并意外地产生垃圾而不是零。 

另一个微妙的情况是包含零的数组。 任意元素`a_i = 0`立即创建一个长度为 1 的零异或子数组。 

例如：```
n = 1, m = 3
```允许的号码是`0..7`。 

唯一价值`0`是禁止的，所以答案是`7`。 

一个有缺陷的推导，忘记了`p_i != p_{i-1}`会错误地计算所有`8`数组。 

## 方法

 蛮力方法很简单。 生成每个长度的数组`n`，对每个子数组计算异或，并检查是否有任何异或等于零。 

有`2^{mn}`数组。 即使我们使用前缀异或来优化子数组异或计算，每个数组仍然需要检查所有`O(n^2)`子数组。 

总复杂度变为$$O(2^{mn} \cdot n^2)$$即使输入很小，这也是无望的。 

一旦我们使用前缀异或重写条件，问题就变得可以管理。 

定义：$$p_0 = 0$$

$$p_i = a_1 \oplus a_2 \oplus \cdots \oplus a_i$$然后：$$a_i = p_i \oplus p_{i-1}$$前缀异或的每个选择都唯一地确定数组。 

一个子数组`[l, r]`恰好在以下情况下异或为零：$$p_r = p_{l-1}$$因此，当所有前缀异或都不同时，序列就不是羊毛。 

现在问题变成了组合问题。 

有`2^m`可能的异或值。 

我们已经修好了`p_0 = 0`。 

来选择`p_1`，我们可以使用除`0`，给予：$$2^m - 1$$选择。 

为了`p_2`，我们必须避免使用这两个值：$$2^m - 2$$选择。 

继续这个过程：$$(2^m - 1)(2^m - 2)\cdots(2^m - n)$$这只是一个下降阶乘。 

如果`n >= 2^m`，其中一个因数变为零，所以答案为零。 

整个问题简化为模乘法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^{mn} \cdot n^2)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n + \log m)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 阅读`n`和`m`。 
2. 计算$$K = 2^m \pmod{10^9+9}$$使用快速模幂。 

1.如果`n >= K`在普通整数算术中，答案必须为零，因为我们需要`n + 1`不同的前缀异或值，但仅`K`价值观是存在的。 

自从`2^m`可能很大，我们不直接计算它。 我们只需要知道是否`2^m <= n`。 

因为`n ≤ 10^5`，我们可以安全地检查：

 - 如果`m >= 17`， 然后`2^m > 10^5`， 所以`n < 2^m`自动地
 - 否则计算`1 << m`1. 初始化`answer = 1`。 
2. 对于每一个`i`从`1`到`n`，乘以：$$answer \gets answer \times (K - i)$$模数`10^9 + 9`。 

这对应于在每一步选择一个新的不同前缀异或。 

1. 打印最终答案。 

### 为什么它有效

 不变的是处理后的位置`i`，前缀异或值$$p_0, p_1, \dots, p_i$$都是不同的。 

在步骤`i`， 确切地`i`异或值已被使用，因此有：$$2^m - i$$的有效选择`p_i`。 

每个有效的不同前缀异或序列都对应于一个数组，因为：$$a_i = p_i \oplus p_{i-1}$$每个数组都生成一个前缀异或序列。 

因此，计算有效数组与计算逐步选择不同前缀异或值的方法相同。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 9

def solve():
    n, m = map(int, input().split())

    # Check whether 2^m <= n without overflow
    if m < 17 and (1 << m) <= n:
        print(0)
        return

    total = pow(2, m, MOD)

    ans = 1

    for i in range(1, n + 1):
        ans = (ans * (total - i)) % MOD

    print(ans)

solve()
```第一个重要的细节是早期的零检查。 

数学条件为：$$n \ge 2^m$$但直接计算`2^m`可能会变得不必要的大。 自从`n`至多是`100000`， 任何`m >= 17`自动满足：$$2^m > 100000$$所以根据鸽巢原理答案不能为零。 只是很小`m`值需要显式检查。 

变量`total`商店：$$2^m \bmod MOD$$这对于以后的所有乘法来说已经足够了，因为每个操作都是模数`MOD`。 

循环相乘：$$(2^m - 1)(2^m - 2)\cdots(2^m - n)$$完全匹配组合推导。 

减法必须在模乘之前进行。 忘记这里的括号是错误的常见来源。

import sys, io

MOD = 10**9 + 9

def solve():
    input = sys.stdin.readline

    n, m = map(int, input().split())

    if m < 17 and (1 << m) <= n:
        print(0)
        return

    ans = 1

    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out

    solve()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.getvalue().strip()

assert run("3 2\n") == "6", "sample 1"

# minimum input
assert run("1 1\n") == "1", "single nonzero value"

# impossible because n >= 2^m

 ## 边缘情况

 考虑：```
2 1
```只有两种异或状态：`0`和`1`。 

该算法检查：$$2^1 = 2$$自从`n = 2`，我们需要`3`不同的前缀异或，这是不可能的。 早期状况恢复`0`。 

这可以避免意外计算：$$(2-1)(2-2)=0$$经过许多不必要的运算后通过模运算。 

现在考虑：```
1 3
```允许的值为`0..7`。 

该算法计算：

 | 步骤| 因素 | 回答 |
 | --- | --- | --- |
 | 开始| - | 1 |
 | 我 = 1 | 8 - 1 = 7 | 8 - 1 = 7 | 7 |

 唯一的禁止数组是`(0)`因为单个零已经形成了零异或子数组。 

该算法会自动处理这个问题，因为`p_1`不能等于`p_0 = 0`。 

最后考虑：```
3 1
```这里：$$2^1 = 2$$但我们需要四个不同的前缀异或。 

早期支票立即返回`0`。 

如果没有这项检查，粗心的实现可能会继续乘以负值模`MOD`，产生无意义的非零答案。
