 ## 解决方案
 ## 问题理解

 我们需要准确保留数组中的 (k) 个元素，同时保留它们的原始顺序。 一旦选择了这些元素，它们就会形成一个循环：连续选择的元素贡献其总和，最后选择的元素也与第一个元素配对。 所选子序列的成本是这 (k) 对总和中最大的一个。 我们希望成本尽可能最小。 

困难的部分是子序列不仅仅是穿过数组的路径。 最终元素还必须与第一个元素兼容，因此通常的从左到右动态编程方法会丢失有关起始元素的信息。 

该数组最多可包含 (200,000) 个元素，每个值最大可为 (10^9)。 在最坏的情况下， (O(n^2)) 算法已经需要大约 (4\cdot10^{10}) 次操作，远远超出了 3 秒限制所允许的范围。 对于每个问题，我们基本上需要线性或 (O(n\log n)) 工作，并且最好没有依赖于 (k) 的因素。 

有几种边缘情况很容易被错误处理。 首先，最后一个和第一个选定元素之间的循环对很重要。 例如，```
5 3
5 1 100 1 5
```通过选择 (1,1,5) 得到答案 (6)，其中 (5) 来自数组的任一端。 仅检查普通线性顺序中的小元素之间的间隙的检查将错过此选择，并且可能错误地报告只能选择两个元素。 

确切的边界 (w_i = X/2) 也很重要。 为了```
3 3
10 10 10
```答案是（20）。 测试 (X=20) 时，等于 (10) 的值必须归类为小值，因为 (10+10=20)。 使用严格的不等式而不是 (2w_i\le X) 会错误地拒绝答案。 

没有小元素的情况也必须明确处理。 为了```
3 3
10 11 12
```唯一可能的子序列是整个数组，其循环对和为(21,23,22)，所以答案为(23)。 一种可行性检查，假设始终至少有一个小元素可以访问不存在的端点或意外地声明阈值可行。 

最后，当已经有至少 (k) 个小元素时，根本不需要大元素。 为了```
4 3
1 2 3 100
```答案是（5），使用（1,2,3）。 坚持在每个间隙中添加一个大元素的方法可能会使答案变得不必要的大。 

## 方法

 直接暴力方法很简单。 枚举每组 (k) 个索引，保留它们的顺序，计算 (k) 个循环相邻和，并保留最小最大值。 这是正确的，因为每个可能的子序列都被明确考虑。 它的成本是 (\Theta!\left(\binom nk k\right))，在 (n) 中呈指数增长。 在 (k=n/2) 附近，候选者的数量大致为 (2^n/\sqrt n)，因此总工作量约为 (2^n\sqrt n)。 对于 (n=200,000)，这是不太可行的。 

有用的视角改变是停止直接构造最优子序列。 相反，假设我们知道一个候选答案 (X)，并询问某个长度为 (k) 的有效子序列是否最多具有每个循环相邻和 (X)。 这个谓词是单调的：如果 (X) 可行，则每个较大的值也可行。 这立即给出了答案的二分搜索。 

现在考虑一个固定阈值 (X)。 如果将一个元素称为小元素

 [
 2w_i\le X,
 ]

 否则就很大。 总和最多为 (X) 的每一对必须至少包含一个小元素。 两个大元素在所选循环中不能相邻，因为它们的总和严格大于 (X)。 这是中心结构观察。 

还有一个更强有力的事实。 当在阈值（X）下最大化可以选择的元素数量时，我们总是可以假设每个小元素都被选择。 假设缺少一个小元素。 查看循环中紧邻其前后的选定小元素。 在这两个选定的小元素之间最多可以有一个选定的大元素。 如果有，则用缺少的小元素替换该大元素。 替换仍然与两个相邻的小元素兼容，因为两个值最多为 (X/2)。 如果相邻小元素之间没有选中的元素，则只需添加缺少的小元素即可。 因此，选择所有小元素永远不会减少可实现的最大子序列长度。 

一旦所有的小元素都被修复，问题就变得简单多了。 两个连续的小元素之间没有其他小元素，因此间隙仅包含大元素。 最多可以选择其中一项。 最好的候选者就是该差距中的最小值。 如果两个边界小值是 (a) 和 (b)，则候选 (x) 恰好在以下情况下有效：

 [
 x+\max(a,b)\le X.
 ]

 最后一个小元素和第一个小元素之间的循环间隙是通过对最后一个小元素之后的后缀和第一个小元素之前的前缀取最小值来处理的。 

一次从左到右的扫描可以计算所有小元素并找到每个间隙中的最小值。 因此，一次可行性检查是 (O(n))，二分查找答案只需要大约 31 次检查，因为所有对和都位于 (2) 和 (2\cdot10^9) 之间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (\Theta!\left(\binom nk k\right)) | (O(k)) | 太慢了 |
 | 最佳| (O(n\log 10^9)) | (O(n)) | (O(n)) | 已接受 |

 ## 算法演练

1. 二分查找最小可行阈值(X)。 使用 (0) 作为不可行的下界，使用 (2\max(w_i)) 作为可行的上限，因为每对数组元素的和最多为 (2\max(w_i))。 
2. 对于固定的 (X)，将满足 (2w_i\le X) 的每个值分类为小值。 任何两个小值都可以相邻，因为它们的和最多为 (X)。 任何两个大值不能相邻，因为它们的总和超过 (X)。 
3. 扫描数组并对小元素进行计数。 如果它们的计数已经至少为 (k)，则阈值是可行的，因为任何 (k) 个小元素形成有效循环。 
4.如果没有小元素，阈值是不可能的。 每个有效循环必须包含一个小元素，因为每条边都需要至少一个端点，其值最多为 (X/2)。 
5. 对于每对连续的小元素，找到它们之间的最小值。 由于该区间内没有小元素，因此该区间内的每个候选元素都很大，并且最多只能选择一个候选元素。 
6. 令连续的小值是(a)和(b)，并且令(m)严格地是它们之间的最小值。 我们可以准确地从这个间隙添加一个元素
 [
 m+\max(a,b)\le X.
 ]
 最大值是必要的，因为插入的元素必须与两个边界小元素形成有效对。 
7、处理最后一个小元素和第一个小元素之间的循环间隙。 它的候选者是最后一个小位置之后的元素和第一个小位置之前的元素。 这两个区域的最小值是该间隙的最佳可能额外元素。 
8. 可选择元素的最大数量是小元素的数量加上允许一个有效大元素的间隙的数量。 如果该计数至少为(k)，则阈值(X)是可行的。 
9. 继续二分查找，直到剩下最小的可行阈值。 

可行性检查背后的不变性是，在修复所有小元素后，每个剩余的间隙都是独立的，并且最多贡献一个额外的选定元素。 我们已经证明，最佳最大基数选择可以包含每个小元素，因此精确考虑这些间隙不会丢失任何解决方案。 在一个间隙内，选择其最小值是最佳的，因为边界值是固定的，并且较小的候选值对于任何相邻对来说都不会更差。 因此，计算出的计数正是 (X) 下可以选择的最大元素数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(n, k, w):
    def feasible(x):
        half = x // 2

        small_count = 0
        first_small = -1
        last_small = -1

        extra = 0
        gap_min = None

        for i, value in enumerate(w):
            if value <= half:
                small_count += 1

                if first_small == -1:
                    first_small = i
                else:
                    if gap_min is not None:
                        if gap_min + max(w[last_small], value) <= x:
                            extra += 1
                            if small_count + extra >= k:
                                return True

                last_small = i
                gap_min = None
            else:
                if first_small != -1:
                    if gap_min is None or value < gap_min:
                        gap_min = value

        if small_count == 0:
            return False

        if small_count >= k:
            return True

        # The cyclic gap contains the suffix after the last small
        # element and the prefix before the first small element.
        wrap_min = None

        for i in range(last_small + 1, n):
            if wrap_min is None or w[i] < wrap_min:
                wrap_min = w[i]

        for i in range(0, first_small):
            if wrap_min is None or w[i] < wrap_min:
                wrap_min = w[i]

        if wrap_min is not None:
            if wrap_min + max(w[last_small], w[first_small]) <= x:
                extra += 1

        return small_count + extra >= k

    lo = 0
    hi = 2 * max(w)

    while lo + 1 < hi:
        mid = (lo + hi) // 2
        if feasible(mid):
            hi = mid
        else:
            lo = mid

    return hi

def main():
    n, k = map(int, input().split())
    w = list(map(int, input().split()))
    print(solve_case(n, k, w))

if __name__ == "__main__":
    main()
```这`solve_case`函数包含整个优化。 外部二分搜索仅询问是否可以实现特定的最大对和。 

里面`feasible`,`half = x // 2`实现精确条件 (2w_i\le X)。 整数除法是有​​意进行的，因此当 (X) 为奇数时，(\lfloor X/2\rfloor) 的值被分类为小值。`first_small`和`last_small`确定循环间隙的端点。`gap_min`存储自前一个小元素以来的最小元素。 一旦找到另一个小元素，间隙就完整了，最多可以贡献一个大元素。 

条件使用`max(w[last_small], value)`， 不是`min`。 插入的值必须与两个相邻的小值兼容，因此它必须满足两个不等式。 同样，它必须不大于 (X-\max(a,b))。 

环绕间隙在扫描后单独处理。 它的最小值是最后一个小元素之后的后缀和第一个小元素之前的前缀中的最小值。 这是问题的循环性质与普通线性子序列不同的唯一地方。 

Python 整数具有任意精度，因此总和如`2 * max(w)`不要溢出。 二分查找使用`lo + 1 < hi`， 和`lo`已知不可行并且`hi`已知是可行的，这可以避免相差一的错误。

 ## 边缘情况

 对于循环间隙情况```
5 3
5 1 100 1 5
```考虑(X=6)。 小元件位于位置 (2) 和 (4)。 它们之间的间隙包含(100)，因此它不能提供额外的元素。 循环间隙包含位置 (5) 和 (1)，两者的值为 (5)。 由于边界小值是 (1) 和 (1)，因此 (5) 中的任何一个都是有效的，因为 (5+1=6)。 检查计数 (2+1=3) 个可选元素并接受 (X=6)。 

对于精确的半阈值，```
3 3
10 10 10
```测试 (X=20) 给出`half = 10`。 每个值都满足 (w_i\le10)，因此所有三个元素都很小。 由于小元素的数量已经是 (k=3)，因此检查立即接受 (20)。 诸如 (2w_i<X) 之类的严格测试会将所有三个值分类为大，并错误地拒绝正确答案。 

对于没有小元素的情况，```
3 3
10 11 12
```考虑（X=20）。 小的阈值是（10），所以值（10）实际上很小，检查不会失败。 在 (X=19) 处，阈值变为 (9)，因此不存在小元素，检查立即返回 false。 这为二分搜索提供了不可行 (19) 和可行 (23) 之间的正确转换，这是唯一可能子序列的实际最大对和。 

对于有足够小元素的情况，```
4 3
1 2 3 100
```在 (X=5) 处，较小的值是 (1) 和 (2)，因为 (2\cdot2=4\le5)，而 (3) 和 (100) 较大。 只有两个小元素，所以我们还需要一个。 (1) 和 (2) 之间的间隙不包含任何元素，而其他间隙包含 (3) 或 (100)。 如果放置在错误的间隙中，候选(3)与(2)兼容，但与(1)不兼容，有效选择是子序列(1,2,3)，其最大循环对和是(5)。 扫描正好在此阈值处接受。
