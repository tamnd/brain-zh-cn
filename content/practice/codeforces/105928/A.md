 ## 解决方案
 ## 问题理解

 我们得到了几个测试用例。 每个测试用例中有多个串，每个串有一定数量的肉块。 瓦蕾莎吃每根串时，首先随机均匀地选择两侧（左或右）中的一侧，然后为该串上的每个连续部分交替选择两侧。 

这种交替模式意味着一旦起始侧固定，该串的左右咬合分布就完全确定了。 唯一的随机性是每个串的初始选择。 

当所有串都吃完后，我们看左磨牙和右磨牙总共咬了多少口。 如果这些总数之间的绝对差最多为 1，则膳食被认为是平衡的。 任务是计算该事件的概率并以 998244353 为模输出。 

所有测试用例中串的总数最多为 2 · 10^5 的约束意味着我们需要在总输入大小方面有一个线性或接近线性的解决方案。 n 或 ai 之和的任何二次方都是不可能的，因为 ai 可以大到 10^9，所以我们无法模拟单件水平的进食。 该结构必须仅依赖于奇偶校验或类似的压缩统计数据。 

一个天真的解释会尝试模拟每个串并直接跟踪左右不平衡。 这已经失败了，因为人工智能可能非常庞大，甚至每个串模拟也会太慢。 

一个更微妙的失败案例来自于独立处理每个串，而没有注意到只有奇偶性才重要。 例如，如果我们只跟踪总长度，我们会错误地认为尺寸为 2 和 3 的串的行为相似，但像 a = 3 这样的单个串实际上会引入不平衡的可能性，而 a = 2 则不会。 

## 方法

 蛮力的想法是明确地模拟随机性。 对于每个串，我们选择一个起始侧，然后交替分配每个部分并跟踪所得的左减右差。 对于 n 个串，这会导致起始面有 2^n 种可能的选择，并且对于每种配置，我们将模拟所有串，给出 O(n·2^n)。 即使 n 约为 30，也会发生爆炸。 

关键的观察结果是，每个串对最终的不平衡都有独立的贡献，并且其贡献仅取决于其长度是偶数还是奇数。 

如果串的长度均匀，则交替的两侧可确保两侧都收到正好一半的碎片，无论起始侧如何。 所以它对不平衡的贡献为零。 

如果串的长度为奇数，则一侧会多收到一根。 如果我们从左边开始，左边的相对贡献度+1； 如果我们从右侧开始，右侧将获得 +1，这意味着贡献为 +1 或 -1 的概率相同。 

因此，整个问题简化为独立随机变量的总和，每个变量要么是 0（对于偶数串），要么是 ±1（对于奇数串）。 如果 k 是奇数长度串的数量，我们需要 k 个独立 ±1 变量之和位于 {−1, 0, 1} 中的概率。 

这是一个标准的二项式分布问题。 如果我们将 +1 映射到成功，将 −1 映射到失败，则总和变为 S = k − 2X，其中 X 是 -1 个选择的数量。 我们只计算有多少个 X 值导致有效的 S。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力模拟 | O(n·2^n) | O(n·2^n) | O(n) | 太慢了|
 | 奇偶校验约简的组合学| 每次测试 O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将问题简化为计算奇数长度串的 ±1 贡献的配置。

1. 数一下有多少串长度为奇数。 将此号码称为 k。 只有这些串会影响不平衡，因为即使是串，无论起始端如何，其贡献也始终为零。 
2. 观察每个奇数串以 1/2 的概率独立贡献 +1 或 -1。 所以我们有效地对 k 个独立的对称随机变量求和。 
3. 令X为贡献-1的串的数量。 那么总和就变成 S = k − 2X。 
4. 我们希望 S 在 {−1, 0, 1} 中。 对于该集合中的每个目标值 t，求解 k − 2X = t，得到 X = (k − t) / 2。 
5. 对于 [0, k] 范围内的每个有效整数 X，添加二项式系数 C(k, X)。 这会计算产生这种不平衡的有效符号分配的数量。 
6. 分配总数为 2^k，因此概率为（有效二项式之和）/2^k 模 998244353。 
7. 预先计算高达 2 · 10^5 的阶乘和逆阶乘，以在 O(1) 中回答二项式查询，并使用快速求幂来计算 2^k 的模逆。 

### 为什么它有效

 每个串的贡献仅取决于奇偶性，并且这些贡献是独立的。 转换为 ±1 变量之和保留了独立性并充分表征了最终的不平衡。 最终余额的条件仅取决于总和，因此通过二项式系数计算有效符号分配与概率空间完全匹配，不会遗漏或重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAXN = 200000 + 5

fact = [1] * MAXN
invfact = [1] * MAXN

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def ncr(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

def solve():
    t = int(input())
    arr_cases = []
    max_k = 0

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        k = sum(x & 1 for x in a)
        arr_cases.append(k)
        max_k = max(max_k, k)

    for i in range(1, max_k + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact[max_k] = modpow(fact[max_k], MOD - 2)
    for i in range(max_k, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    inv2 = (MOD + 1) // 2

    for k in arr_cases:
        total = modpow(2, k)
        ans = 0

        def add(x):
            return ncr(k, x)

        for tval in [-1, 0, 1]:
            x = k - tval
            if x % 2 == 0:
                x //= 2
                ans = (ans + ncr(k, x)) % MOD

        ans = ans * modpow(total, MOD - 2) % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```该代码首先将每个测试用例压缩到奇数长度串的数量。 阶乘和逆阶乘构建一次直至达到所需的最大 k，从而实现恒定时间二项式计算。 对于每个测试用例，我们枚举三个可能的目标不平衡值并将它们转换为有效的二项式指数。 最终归一化使用模逆除以 2^k。 

一个微妙的点是，我们从不单独模拟奇偶校验提取之外的串，这使得解决方案对于整个约束范围足够有效。 

## 工作示例

 考虑带有串的单个测试用例`[1, 2, 3]`。 奇数串为 1 和 3，因此 k = 2。 

我们计算所有可能的结果：

 | 串烧 1 | 串烧3 | S |
 | --- | --- | --- |
 | +1 | +1 | 2 |
 | +1 | −1 | 0 |
 | −1 | +1 | 0 |
 | −1 | −1 | −2 |

 有效和为 {−1, 0, 1}，因此只有 S = 0 在这里起作用。 4 种情况中有 2 种会发生这种情况，概率为 1/2。 

现在考虑`[1, 1, 1]`，所以 k = 3。 

我们列出所有金额：

 | 配置| S |
 | --- | --- |
 | + + + | 3 |
 | + + − | 1 |
 | + − + | 1 |
 | − + + | 1 |
 | + − − | −1 |
 | − + − | −1 |
 | − − + | −1 |
 | － － － | −3 |

 有效总和为 −1, 0, 1，因此我们从 8 个配置中算出 6 个有效配置，得出 3/4。 

这些痕迹表明，我们仅有效地处理超过 ±1 个选择的二项分布。

 ## 边缘情况

 一种边缘情况是所有串的长度均等。 在这种情况下 k = 0，因此不存在随机选择。 总和始终为 0，这已经在要求的范围内。 该算法产生 C(0,0) / 1 = 1，匹配正确的确定性结果。 

另一个边缘情况是 k = 1。单个奇数串贡献 ±1，因此最终总和始终在 [-1, 1] 范围内。 该公式正确计算两种配置并除以 2，得出概率 1。 

最后一个微妙的情况是当 k 很大但大多数 ai 是偶数时。 该解决方案将所有结构压缩为 k，因此运行时间仅取决于奇数值的数量而不是原始输入大小，从而避免了大 ai 值带来的任何溢出或性能问题。
