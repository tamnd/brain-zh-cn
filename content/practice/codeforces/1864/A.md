 ## 解决方案
 ## 问题理解

 该问题给了我们三个整数： 起始值`x`, 结束值`y`，和长度`n`。 我们需要构建一个数组`a`长度`n`开始于`x`并结束于`y`，是严格递增的，并且具有严格递减的连续差异。 换句话说，如果`b_i = a_{i+1} - a_i`， 然后`b`应形成严格递减序列。 

这很棘手，因为条件`b`限制连续元素之间可能的间距。 例如，第一个差值必须大于第二个差值，第二个差值必须大于第三个差值，依此类推。 如果范围从`x`到`y`相对于`n`，可能无法同时满足严格递增和严格递减的差异。 

限制很小：`x`,`y`≤ 1000，`n`≤ 1000，并且`t ≤ 1000`。 这意味着解决方案的运行时间大致为`O(n)`每个测试用例是可以接受的。 所有序列的强力枚举是不可行的，因为序列的数量以组合方式增长，但贪婪或数学构造是可行的。 

一个重要的边缘情况出现时`n`是 3，这是最小尺寸。 在这里，我们只需要两个区别。 例如，`x=1, y=3, n=3`这是不可能的，因为我们需要两个严格减少的正差异。 唯一可能的一对`(d1, d2)`和`d1 > d2 > 0`需要`d1 + d2 = y - x = 2`。 但最小的递减正整数对是`(2,1)`，总和为 3，大于 2。所以正确的输出是`-1`。 

## 方法

 暴力方法会尝试所有长度的序列`n`开始于`x`并结束于`y`，检查严格增加和减少的差异。 对于每一个可能的选择`a_2`， 然后`a_3`等等，算法将验证差异是否减小。 这是指数级的`n`显然不可行`n=1000`。 

更快解决方案的关键观察是长度严格递减的差分序列`n-1`可以用逆序的连续整数来表示。 假设我们将差异定义为`d, d-1, d-2, ..., d-(n-2)`。 这些差值的总和必须等于`y-x`， IE。，```
d + (d-1) + (d-2) + ... + (d-(n-2)) = (n-1)*d - (n-2)*(n-1)/2 = y - x
```从这个方程中，我们可以求解最大整数`d`满足总和条件，同时保持所有差异为正。 一次`d`确定后，序列`a`通过从以下位置开始顺序添加差异来重建`x`。 这种贪婪方法之所以有效，是因为减少总距离之和的连续差值会产生有效序列，并且使用最大起始差值可确保所有差值保持正值。

 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |

 ## 算法演练

 1. 计算总差`diff = y - x`。 这是我们减少分歧必须达到的总和。 
2. 从最后一个可能的差异开始`d = 1`并增量检查长度递减序列的总和`n-1`可以匹配`diff`。 使用公式`(n-1)*d - (n-2)*(n-1)/2`。 我们需要`d`尽可能大，同时保持所有差异为正。 
3.一次`d`确定后，生成差异序列为`[d, d-1, ..., d-(n-2)]`。 
4. 初始化`a[0] = x`并迭代地添加每个差异以生成序列的其余部分。 
5.如果没有阳性`d`满足求和方程，返回`-1`对于该测试用例。 

为什么它有效：求和公式确保差值序列恰好覆盖了`x`到`y`。 使用连续递减的整数可以保证差异严格递减，并且从`x`产生一个严格递增的数组。 不变的是，在每一步，剩余距离可以以正差递减的方式分布在剩余位置之间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x, y, n = map(int, input().split())
        total = y - x
        found = False
        for d_last in range(1, total + 1):
            # Sum of n-1 decreasing differences starting from d
            # Let largest difference be d
            # Sum = (n-1)*d - (n-2)*(n-1)//2
            d = (total + (n-2)*(n-1)//2) // (n-1)
            if d*(n-1) - (n-2)*(n-1)//2 == total and d > 0:
                a = [x]
                curr = x
                for i in range(n-1):
                    curr += d
                    a.append(curr)
                    d -= 1
                print(" ".join(map(str, a)))
                found = True
                break
        if not found:
            print(-1)

if __name__ == "__main__":
    solve()
```该解决方案首先使用导出公式计算最小起始差异。 它通过在每一步将差值减一来构造数组。 循环检查`d_last`可以优化，但这种形式很清晰并且在限制范围内工作。 关键的微妙之处包括确保差异保持正值并且总和完全等于`y - x`。
