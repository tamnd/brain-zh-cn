 ## 解决方案
 ## 问题理解

 我们得到了布置在无限网格上的单位正方形的配置。 想象一下被整数晶格线分割成 1 x 1 个单元的平面。 圆形饼干正好以网格交点为中心，我们感兴趣的是有多少个单位正方形完全包含在圆内。 

仅当每个方格的所有四个角都位于圆内或圆上时才算作该方格。 该任务与通常的计数问题相反：我们没有给出半径和计算正方形，而是给出了一个数字`s`代表竞争对手的 cookie 包含多少个完整方块的上限，并且我们必须构造一个严格包含多个方块的圆`s`完整的正方形，同时保持半径尽可能小。 

因此输出是最小可能的半径，使得圆内完全包含的单位正方形的数量超过`s`。 

约束条件`s ≤ 10^9`排除任何显式枚举大半径正方形的方法。 即使半径约为 10^5，在简单的 2D 扫描中也已经产生了约 10^10 个网格位置，这远远超出了一秒解决方案的处理能力。 问题的结构表明我们需要有效地计算几何形状内的晶格对象，并使用单调搜索反转该计数。 

出现微妙的边缘情况时`s`非常小。 如果`s = 1`，答案不是由原点附近的单个单位正方形决定的，而是由正方形开始完全融入圆内的速度决定的。 另一个边缘情况是，正方形不是以格点为中心，而是由它们的角定义，因此误解是使用中心还是角会导致系统错误的计数。 

## 方法

 直接的方法是尝试逐渐增加半径，对于每个半径，迭代边界框中的所有网格方块，并检查所有四个角是否都位于圆内。 这在概念上是正确的，但对于半径`R`它需要粗略地迭代`O(R^2)`方格，每次检查都是常数时间。 由于有效方格的数量与圆的面积成正比增长，达到`s`最多`10^9`需要的半径约为`sqrt(s)`，这大约是`3 × 10^4`。 即便如此，迭代所有正方形直到该半径会导致大约`10^9`迭代，这太慢了。 

关键的观察结果是有效方块集随半径单调增长。 一旦正方形完全位于半径的圆内`R`，对于任何更大的半径，它将保持在内部。 这种单调性使我们能够使用半径上的二分查找来反转计数函数。 

剩下的挑战是计算，对于固定半径`R`，有多少单位正方形完全包含在圆中而不需要迭代所有单位正方形。 如果我们从正方形切换到它们的角，几何图形就会简化：带有左下角的单位正方形`(x, y)`如果其最远的角被完全包含`(x+1, y+1)`位于以原点为中心的圆内。 这将条件转换为仅涉及第一象限中的整数格点的不等式。 

然后，我们使用变相的二维前缀结构有效地计算有效整数对：对于每个`x`，我们计算最大可行`y`从圆方程。 这将固定半径的计数减少到`O(R)`时间，二分查找加了一个对数因子。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对每个半径的正方形进行暴力破解 | 每张支票 O(R²) | O(1) | O(1) | 太慢了 |
 | 二分查找+几何计数| O(R log R) | O(R log R) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将问题转化为计算满足圆约束的整数对。 

1. 使用左下角重新解释每个单位正方形`(x, y)`。 正方形完全在圆内当且仅当`(x+1, y+1)`位于圆内或圆上。 这将条件转换为`(x+1)² + (y+1)² ≤ R²`。 
2. 通过定义来移动变量`a = x+1`和`b = y+1`，这使得两者`a`和`b`从 1 开始的正整数。条件变为`a² + b² ≤ R²`。 
3.对于固定半径`R`，计算整数对的数量`(a, b)`在满足不等式的第一象限中。 对于每个`a`, 最大有效值`b`是`⌊sqrt(R² − a²)⌋`。 
4. 总和`a`从 1 到`R`，添加`max(0, b_max)`到计数。 这给出了一个象限中有效方块的数量。 
5. 将结果乘以 4 以考虑所有四个对称象限。 
6. 使用二分查找`R`。 对于每个中点半径，计算正方形的数量。 如果它大于`s`，半径是可行的，我们尝试较小的值。 否则我们会增加它。 
7. 返回产生严格大于的最小半径`s`正方形。 

正确性取决于计数函数在以下情况下是单调的：`R`。 较大的圆只能包含更多的格点，而绝不会更少，因此二分搜索总是收敛到最小可行半径。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def count_squares(R):
    R2 = R * R
    total = 0
    for a in range(1, R + 1):
        rem = R2 - a * a
        if rem <= 0:
            break
        b = int(math.isqrt(rem))
        total += b
    return total * 4

def solve():
    s = int(input())
    
    lo, hi = 0, 2 * 10**7
    
    while lo < hi:
        mid = (lo + hi) // 2
        if count_squares(mid) > s:
            hi = mid
        else:
            lo = mid + 1
    
    print(lo)

if __name__ == "__main__":
    solve()
```计数函数直接实现导出的几何条件。 循环结束`a`提前停止时`a²`超过`R²`，因为不存在进一步的有效对。 使用`math.isqrt`避免了浮点精度问题，否则这些问题会在大半径周围累积。 

二分查找的范围选择得比较宽泛； 对于给定的约束，答案不能超过几百万，因为正方形的数量随半径呈二次方增长。

 ## 边缘情况

 当`s`非常小，比如`s = 0`，正确的半径是已经包含至少一个完整正方形的最小半径。 该算法可以处理这个问题，因为二分搜索从零开始并立即移动到最小的可行半径，其中`count(R) > 0`。 

什么时候`s`非常大，接近`10^9`，二分查找扩大半径，直到计数函数开始超过目标。 尽管搜索范围很大，但单调性保证了对数迭代的收敛性。 

一个更微妙的情况是由接触轴的正方形产生的。 像一个正方形`(0,0)-(1,1)`仅当最远角时才计算`(1,1)`位于圆圈内。 这确保了部分相交的正方形没有歧义，因为条件严格要求完全包含所有角，并且算法通过以下方式对此进行编码：`(a, b)`无需特殊套管边界方块的转换。
