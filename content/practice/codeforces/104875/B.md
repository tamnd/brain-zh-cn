 ## 解决方案
 ## 问题理解

 给定一个垂直的圆柱形瓶子，高度为$h$和半径$r$。 瓶子里装满了部分水，达到一定高度$x$，从底部开始测量。 水面上方的剩余空间充满空气。 水和空气被视为具有恒定密度的连续材料$d_w$和$d_a$，而瓶子本身没有重量。 

我们要优化的物理量是瓶子直立时空气和水柱组合的质心的垂直位置。 由于圆柱体的横截面积是恒定的，因此几何形状仅影响比例，而不影响质量沿高度的相对分布。 目标是选择$x \in [0, h]$使得质心尽可能低。 

输出是代表最佳水高的实数。 

约束很小，所有参数最多为 1000，因此$O(1)$或者$O(\log n)$预计有解析解。 任何对可能值进行采样的方法$x$Finely 会不必要地缓慢且不太精确，但仍然可行； 然而，问题的结构强烈建议采用封闭式解决方案。 

一些边缘行为值得期待。 如果瓶子是空的（$x=0$），只有空气起作用。 如果已满（$x=h$），只有水起作用。 假设最佳值必须位于端点的天真的方法会失败，因为由于上面的轻空气和下面的重水之间的对比，中间混合物可以降低质心。 

## 方法

 强力解释将尝试许多候选填充高度$x$，计算每个的质心，并选择最佳的。 每次评估都需要沿高度积分质量分布，但由于密度是分段常数，因此可以在恒定时间内计算出来。 精细分辨率采样是可行的，但如果我们依赖离散化，则没有必要，而且数值不稳定。 比如说，步长为$10^{-6}$，我们已经接近精度要求的极限，但这仍然隐藏了问题的真实结构。 

关键的观察结果是系统是具有均匀横截面的一维系统，因此问题简化为沿区间的加权平均值。 质心成为有理函数$x$，由二次分子形成（来自积分$z$）和线性分母（来自总质量）。 这使得目标变得平滑且可微分$(0, h)$，允许我们通过求解单导数方程而不是数值搜索来找到最优值。 

一旦以封闭形式重写，导数就简化为二次方程，其解直接产生最佳填充高度。

 ## 算法演练

 我们得出质心作为填充高度的函数$x$，然后将其最小化。 

1. 将瓶子建模为垂直段$[0, h]$与密度$d_w$在$[0, x]$和$d_a$在$[x, h]$。 横截面积是恒定的，因此它在所有比率中都会抵消。 
2. 计算总质量（直到面积系数不变）。 水的贡献$d_w x$，空气也有贡献$d_a (h - x)$。 所以总质量是$$M(x) = d_a h + (d_w - d_a)x.$$3. 计算底部周围的力矩。 水的贡献$\int_0^x z d_w dz = d_w x^2/2$。 空气贡献$\int_x^h z d_a dz = d_a(h^2 - x^2)/2$。 所以总的时刻是$$N(x) = \frac{d_a h^2 + (d_w - d_a)x^2}{2}.$$4. 质心是$f(x) = N(x)/M(x)$。 常数因子$1/2$为了最小化可以忽略。 
5. 定义$A = d_w - d_a$，这是积极的。 然后最小化$$g(x) = \frac{d_a h^2 + A x^2}{d_a h + A x}.$$6. 差异化$g(x)$使用商规则并将导数的分子设置为零。 这产生$$A x^2 + 2 d_a h x - d_a h^2 = 0.$$7. 求解该二次方程并求正根：$$x = \frac{-2 d_a h + \sqrt{4 d_a^2 h^2 + 4 A d_a h^2}}{2A}.$$8. 化简平方根项：$$d_a^2 + d_a A = d_a d_w,$$所以解决方案变成$$x = h \cdot \frac{\sqrt{d_a d_w} - d_a}{d_w - d_a}.$$### 为什么它有效

 功能$g(x)$是光滑的$(0, h)$由凸二次函数和线性函数的比率产生。 这保证了可行区间内的单个驻点。 由于导数可简化为只有一个正根的二次方程$[0, h]$，该根必须是全局最小化器。 边界点对应于纯空气或纯水的简并情况，无论何时，驻点都严格控制它们$d_w > d_a$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def solve():
    h, r, da, dw = map(int, input().split())
    
    A = dw - da
    # avoid floating instability in degenerate reasoning
    x = h * (math.sqrt(da * dw) - da) / A
    print(x)

if __name__ == "__main__":
    solve()
```实现直接遵循导出的封闭形式。 半径$r$永远不会出现在最终表达式中，因为在计算质量和力矩时恒定的横截面积会被抵消。 唯一微妙的部分是计算平方根$\sqrt{d_a d_w}$，应该以双精度完成； 所需的公差$10^{-6}$很容易满足。

 ### 示例 1

 输入：```

```我们计算$A = 3$， 和$\sqrt{d_a d_w} = \sqrt{4} = 2$。 

| 步骤| 表达 | 价值|
 | ---| ---| ---|
 | 计算开方|$\sqrt{1 \cdot 4}$| 2 |
 | 分子|$2 - 1$| 1 |
 | 分母|$4 - 1$| 3 |
 | x|$22 \cdot 1/3$| 7.3333... |

 最佳位置位于瓶子上方的三分之一处，因为空气比水轻得多，因此增加水最初会通过降低质心来改善平衡，但最终由于总质量浓度的增加而再次升高。

 ## 边缘情况

 当$d_w$仅略大于$d_a$，最优的$x$移动接近于零，因为加水会快速增加质量，而不会显着改善中心位置。 该公式可以处理这个问题，因为分子$\sqrt{d_a d_w} - d_a$变小，符合预期限制。 

什么时候$d_a$相比之下非常小$d_w$，平方根占主导地位，解接近于$h$，反映出空气几乎不贡献质量，而水的位置主导了质心。 

什么时候$d_a$和$d_w$非常接近，分母$d_w - d_a$变小，但分子由于膨胀而按比例缩小$\sqrt{d_a d_w}$。 这种取消可以防止数值膨胀并使浮点运算下的表达式保持稳定。
