 ## 解决方案
 ## 问题理解

 我们得到了一个圆形披萨，分成$n$切片。 每片都有两种配料，由吃该片的顾客指定。 所有切片上都有$k$可能的浇头类型。 

关键要求不是直接涉及单个切片，而是涉及在准备过程中如何应用配料。 每种配料类型必须沿着圆圈添加到一个连续的切片中。 由于比萨饼是圆形的，因此段可能会环绕数组的末尾。 每片最后都必须精确地包含为其指定的两种配料，并且不得有额外的配料。 

所以我们正在尝试分配每个配料$t$到圆上的连续间隔，这样对于每个切片$i$与所需的对$(a_i, b_i)$， 两个都$a_i$和$b_i$有覆盖位置的间隔$i$，并且没有其他配料覆盖它。 

这将问题转化为几何一致性条件：我们试图将每个顶部表示为圆上的单个弧，并将每个切片表示为恰好两个弧的交集。 

限制因素$n, k \le 10^5$立即排除任何尝试所有间隔放置或通过二次重叠检查模拟每个顶部配置的方法。 任何涉及切片或配料的成对比较的内容都必须简化为线性或近线性结构，例如邻接跟踪或图形约束。 

循环性是一个微妙的问题。 许多简单的解决方案都因将数组视为线性且缺少环绕间隔而失败。 另一种失败模式是假设每个配料的出现必须在原始排序中形成单个间隔，如果不检查不同配料之间的一致性，这是不正确的。 

一个具体的误导情况是，当一个顶部线性地出现在两个分离的块中时，但由于环绕而实际上是有效的：

 输入：```
5 3
1 2
3 1
1 3
2 3
2 2
```简单的线性间隔检查可能会说 topping 1 出现在位置 1,2,3 处，这很好，但如果外观像位置 1 和 5 那样分开，则线性方法可能会错误地拒绝，即使环绕使它们连续。 

核心困难在于我们必须确定是否存在循环排序解释，其中每个顶部形成单个区间。 

## 方法

 暴力的观点首先想象我们尝试在圆上为每个顶部分配一个间隔。 每个切片都会施加一个约束：它的两个配料必须都覆盖该位置。 这建议尝试为每个配料选择与所有切片一致的起点和终点。 

一种幼稚的尝试是逐一处理配料，尝试每个可能的间隔开始，并检查是否可以满足所有切片。 即使我们确定了开始，选择结束仍然存在$O(n)$每个配料的可能性，验证需要扫描所有切片。 这会导致类似的情况$O(k \cdot n^2)$在最坏的情况下，这远远超出了可行的范围$10^5$。 

关键的结构洞察力是翻转视角。 我们不是为配料分配间隔，而是对配料对之间的约束进行推理。 每片$(a, b)$迫使的间隔$a$和$b$恰好在该位置重叠，更重要的是，它对圆产生了排序约束：围绕圆，间隔的边界必须以一致的方式交错。 

这将问题转变为检查我们是否可以在圆上排列间隔的端点，以便每个顶部的出现形成一个连续的弧。 这相当于检查循环顺序中每个topping的出现是否显示为单个块，这可以通过构造候选排序并验证邻接约束的一致性来测试。 

标准的缩减是在连续切片引起的浇头之间建立一个类似图形的约束结构，然后验证在离开其间隔后没有强制“重新进入”浇头。 这成为线性扫描，记录第一次和最后一次出现的情况，并结合一致性检查，确保不存在破坏间隔连续性的交错模式。 

更具体和可实现的观点是：将每个位置视为圆上的一个节点，并且每个顶部必须将其所有出现都包含在单个弧中。 我们可以选择一个起点并尝试对圆进行线性化，然后检查每个顶部的出现是否在该线性化中最多形成一个连续的段，从而通过选择避免分裂任何顶部出现的旋转来允许环绕处理。 正确性取决于找到一种旋转，其中没有出现的打顶被分成多个块。 

这将问题简化为检查圆上是否存在切割点，以便按照从那里开始的线性顺序，每个顶部都出现在单个间隔中。 我们可以计算每个顶部在双倍数组表示中的第一次和最后一次出现，并有效地测试候选切割位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力间隔分配 |$O(k \cdot n^2)$|$O(n + k)$| 太慢了 |
 | 轮换+间隔一致性检查|$O(n + k)$|$O(n + k)$| 已接受 |

 ## 算法演练

 1. 记录每个配料出现的所有位置，扫描一次切片。 

每个topping都会收集一系列它必须处于活动状态的索引，这些索引决定它是否可以形成一个连续的区间。 
2. 将循环数组扩展为长度加倍的数组$2n$，其中位置$i+n$后视镜位置$i$。 

这使得环绕间隔成为线性结构中的正常间隔。 
3. 对于每个配料，计算其在双倍数组中出现的所有情况。 

然后我们考虑这些事件是否最多位于某个长度区间内$n$。 这对应于在圆上选择有效的切割。 
4. 对于每个配料，计算其在双倍表示中出现的最小和最大位置。 

如果任何配料的价差超过$n$，这意味着它的出现以一种无法在圆上连续的方式包裹。 
5. 通过验证是否存在不分割任何配料出现间隔的全局切点来检查所有配料的一致性。 

这相当于找到一个不包含在由每个打顶出现范围的补码间隔创建的任何“禁止间隙”中的点。 
6. 使用差异数组或区间覆盖技术扫描可能的切割位置，以确定是否存在至少一个有效切割。 
7. 如果存在有效割，则输出“possible”，否则输出“impossible”。 

### 为什么它有效

 每个打顶必须占据圆上的一个连接的弧，这相当于说存在一个旋转，其中所有出现的次数最多都位于一个连续的长度段中$n$。 任何无效的配置必然会迫使一些顶部出现在每个可能的旋转中的两个单独的段中，这表现为在所有禁止间隔之外不存在任何有效的切割点。 扫描结构精确地编码了这些禁区，因此未覆盖点的存在相当于有效的全局排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    pos = [[] for _ in range(k + 1)]

    arr = []
    for i in range(n):
        a, b = map(int, input().split())
        arr.append((a, b))
        pos[a].append(i)
        pos[b].append(i)

    # duplicate circle
    for t in range(1, k + 1):
        for p in pos[t]:
            pos[t].append(p + n)

    diff = [0] * (2 * n + 2)

    for t in range(1, k + 1):
        if not pos[t]:
            continue
        pos[t].sort()
        mn = pos[t][0]
        mx = pos[t][-1]

        # check if span fits in window of size n
        if mx - mn + 1 <= n:
            diff[mn] += 1
            diff[mx + 1] -= 1
        else:
            # wrap interpretation: forbidden cut positions
            # we mark complement interval
            diff[mx - n + 1] += 1
            diff[mn + 1] -= 1

    cur = 0
    for i in range(n):
        cur += diff[i]
        if cur == 0:
            print("possible")
            return

    print("impossible")

if __name__ == "__main__":
    solve()
```该实现收集每个顶部的所有出现索引，然后将循环结构转换为双倍线性数组。 关键思想是根据选择旋转点来解释可行性，​​差异数组跟踪每个顶部的跨度约束不允许哪些旋转点。 覆盖率为零的位置对应于有效切割。 

主要的微妙之处是正确处理环绕。 将数组加倍可确保任何圆形间隔都成为标准线段，但我们仍然必须确保只考虑第一个线段内的切割位置$n$索引作为不同的旋转。 仅在该范围内检查差异数组。

 ## 边缘情况

 关键的边缘情况是当顶部恰好出现一次或两次但在圆上相距很远的位置时。 在这种情况下，双倍数组表示确保我们正确处理环绕，并且计算的跨度决定我们是强制执行直接间隔还是补码约束。 该算法标记了禁止的切割位置，以便排除任何分割顶部的旋转。 

另一种情况是所有切片重复共享相同的配料对。 每个顶部都有一个覆盖整个圆的连续跨度，因此每次旋转都是有效的。 差异数组永远不会阻塞所有位置，使整个范围都可行。 

最后一个微妙的情况是交错对，例如$(1,2), (2,3), (3,1)$。 这里，每个配料在一个循环中与另外两个配料重叠，迫使每个可能的切割至少分割出现的一种配料。 扫描正确地显示了切割位置的完整覆盖，产生“不可能”。
