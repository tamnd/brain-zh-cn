 ## 解决方案
 ## 问题理解

 我们给出了一个排列，即一个长度数组$n$包含来自的每个整数$1$到$n$按某种顺序恰好一次。 我们的任务是使用修改连续段的特定操作将该数组转换为递增顺序。 

每个操作的工作方式如下：我们选择两个索引$l < r$这样左端点的值严格大于右端点的值，然后我们对整个子数组进行排序$l$到$r$按递增顺序。 我们最多可以应用这个操作$\lfloor n^2 / 2 \rfloor$次，并且我们必须输出一个有效的操作序列，以保证最终的数组已排序。 

限制很小：$n \le 100$，以及总计$n$所有测试用例最多是$10^4$。 这立即告诉我们，每个测试用例的任何二次方法都是可以接受的，但我们仍然需要小心，因为操作本身不是任意的。 我们不允许对任何线段进行自由排序，只能对那些端点形成反转的线段进行排序。 

一个微妙的点是该操作并不总是可以在任意间隔上使用。 例如，即使一个段严重未排序，我们也无法选择它，除非左端点大于右端点。 像“继续对整个数组进行排序”这样的天真的想法是无效的，因为即使中间不是，整个数组的端点也可能已经按递增顺序排列。 

另一种失败模式是假设我们可以使用大段排序直接“修复”每个数字的位置。 这会中断，因为条件$a_l > a_r$即使该段内部明显包含反转，也可能会失败。 

所以关键的困难是操作受到限制，我们必须在这些限制内工作，同时仍然确保全局排序。 

## 方法

 暴力思维是使用允许的操作来模拟强大的排序过程，反复搜索其排序可减少无序的有效段。 人们可以尝试扫描所有对$(l, r)$，检查可行性，应用排序，然后重复直到排序。 这在概念上是正确的，因为每个操作都会减少反转或重新组织结构，但在计算上是浪费的。 重复检查和应用操作可能会导致$O(n^3)$或者在许多步骤中出现更糟糕的行为，并且该过程的结构不足以保证操作数量的明确限制。 

关键的观察结果是，当应用于长度为二的线段时，操作变得极其简单和可靠。 如果我们选择相邻的索引$i$和$i+1$，那么条件$a_i > a_{i+1}$正是邻居之间反转的定义。 发生这种情况时，对段进行排序$[i, i+1]$相当于交换两个元素。 这将问题转化为标准的相邻交换排序过程。 

一旦我们认识到长度为两个段的每个允许的操作都只是反转相邻对的交换，我们就恢复冒泡排序。 冒泡排序保证使用至多反转次数作为交换对任何排列进行排序，并且排列最多有$n(n-1)/2$反转，符合允许的限制。 

因此，我们没有尝试以复杂的方式利用“强大”的段排序操作，而是将自己限制在最简单的有效使用上，并且这已经足以在所需的范围内对数组进行排序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解段模拟 |$O(n^3)$|$O(1)$| 太慢/无结构|
 | 相邻逆排序（冒泡排序）|$O(n^2)$|$O(1)$| 已接受 |

 ## 算法演练

 我们模拟冒泡排序，但我们没有显式交换，而是在长度为 2 的段上使用允许的操作。 

1. 从左到右重复扫描数组，寻找相邻的反转。 
2.每当我们找到一个索引时$i$这样$a_i > a_{i+1}$，我们应用该操作$l=i$和$r=i+1$。 

这是有效的，因为操作所需的条件完全满足。 
3.操作对段进行排序$[i, i+1]$，它只是交换两个元素，将较小的元素放在左侧。 
4. 继续扫描，因为此交换可能与前一个元素创建了新的反转。 
5. 重复遍历数组，直到没有剩余的相邻反转。 

操作的数量自然受到排列中反转数量的限制。 每个操作恰好删除相邻元素之间的一个反转，而冒泡排序保证通过相邻交换最终消除每个反转。 

### 为什么它有效

 关键的不变量是每个操作都严格减少数组的总反转计数。 由于每个操作都会交换相邻的反转对，因此该对随后不再是反转，并且不会在同一方向上引入涉及该对的新反转。 由于反转计数是有限且非负的，因此该过程必须终止。 当没有剩余相邻反转时，数组将进行全局排序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    ops = []
    
    # Bubble-sort using allowed operations
    for _ in range(n):
        for i in range(n - 1):
            if a[i] > a[i + 1]:
                # valid operation since a[i] > a[i+1]
                ops.append((i + 1, i + 2))
                
                # applying "sort segment of length 2"
                a[i], a[i + 1] = a[i + 1], a[i]
    
    print(len(ops))
    for l, r in ops:
        print(l, r)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```该实现直接将每个相邻的反转交换记录为一次操作。 关键细节是我们必须在记录操作后立即更新数组，因为后面的比较取决于当前状态。 

嵌套循环实现有界冒泡排序：最多$n$遍，每遍扫描最多$n$元素，这足以$n \le 100$。
