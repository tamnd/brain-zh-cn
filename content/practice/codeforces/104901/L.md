 ## 解决方案
 ## 问题理解

 我们给出了一条从 0 到 n 的城市线，在每对相邻的城市之间，我们可能会也可能不会放置铁路段。 选择这些线段的子集决定了线上连接间隔的集合。 

一张票是一个三元组（l、r、v）。 当且仅当选择了 l 和 r − 1 之间的每条边时，它才支付 v 分，这意味着整个区间 [l, r] 完全被轨道段“填充”。 不同的门票是独立的，它们的价值只是相加。 

任务是：对于 1 到 n 中的每 k 个，计算通过精确选择 k 个铁路段可实现的最大总票价。 

这些约束意味着每个测试用例的 n、m 最多为 10^4，总和也以 10^4 为界。 这排除了任何在二次时间内独立地为每个 k 重新计算完整动态程序的解决方案。 由于存在 2^n 个配置，因此在边缘子集上的朴素 DP 立即不可能实现。 

真正的结构是，每一张票只取决于是否完全选择了一个连续的区间。 这意味着每个段都会对多个间隔做出贡献，并且只有当选择了其所有边缘时，每个间隔才会变得“活动”。 

一个微妙的边缘情况是存在重叠的票证。 例如，假设我们有票 (0, 2, 3) 和 (1, 3, 5)。 如果我们选择所有边，则两者都适用，但如果我们省略中间的一条边，则两者都会消失。 在不考虑重叠约束的情况下贪婪地选择“最佳间隔”会失败，因为间隔不是独立的对象； 它们需要共享一维资源的连续覆盖。 

另一种边缘情况是当 m = 0 时。那么对于每个 k，所有答案都必须为 0，即使放置了 k 个边缘。 任何假设至少一个间隔的方法都将无法正确初始化 DP。 

## 方法

 暴力破解的想法很简单：对于每个 k，尝试所有方法在 n 中选择 k 个边，并且对于每个配置计算完全覆盖的所有票证的总和。 即使我们优化覆盖率检查，枚举配置的数量级也是$\binom{n}{k}$，即使对于 n = 30 来说，这也是一个天文数字。这会立即消失。 

更结构化的强力方法是将所选边视为长度为 n 的二进制数组。 对于每个状态，我们扫描所有 m 个票并检查每个间隔中的所有边是否都存在。 最坏情况下是 O(nm 2^n)，仍然不可能。 

关键的观察是，每张票仅取决于是否选择了段中的所有边，因此只有当整个区间“完全激活”时，每张票才能被解释为贡献值 v。 我们不考虑边的子集，而是翻转视角：边的每个前缀逐渐激活间隔。 

现在考虑从左到右扫描边缘，并维护当前满足哪些票证（如果我们选择了前缀）。 复杂的是条件取决于确切的子集，而不是前缀。 

正确的重新表述是将每条边视为已选择或未选择，但我们严格执行 k 个已选择的边。 这表明在具有附加结构的位置上采用背包式 DP：当我们决定包含边缘时，我们可能会完成一些右端点位于当前位置的间隔，前提是它们的左侧已经完全活动。 

这导致了一个经典的 DP，我们从左到右处理边，并维护每个 k 可以获得多少值，但我们还需要知道每个位置上哪些间隔变得新满足。 如果我们按右端点预先对票进行分组，那么当我们位于位置 i 时，我们只需要考虑以 i 结尾的票，并检查它们的整个范围是否处于活动状态。 

为了有效地支持这一点，我们维护每个间隔中存在多少个选定边的覆盖计数。 我们没有明确地跟踪每个状态的完全覆盖，而是使用差异结构：当一个区间被完全覆盖时，我们将其值添加一次。 这可以通过确保我们仅在选择其范围内的所有边时在其右端点“激活”票证来解决，这减少了对本地转换的依赖性跟踪。 

这将问题转化为关于所选边的位置和数量的 DP，其中每条边的每个状态的转换为 O(1) 分摊，总共为 O(n^2)。

 | 蛮力 | O(2^n·n·m) | O(2^n·n·m) | O(n) | 太慢了 |
 | 最佳DP | O(n^2 + m) | O(n^2 + m) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 我们定义一个 DP，其中 dp[k] 表示处理边缘到当前位置后可实现的最大值，到目前为止已经选择了 k 个边缘。 

我们处理从 1 到 n 的边，将边 i 视为城市 i − 1 和 i 之间的连接。 

1. 初始化 dp[0] = 0 且所有其他 dp[k] = −∞。 这反映出在选择任何内容之前，只有零边缘有效。 
2.对于从1到n的每个位置i，我们准备一个新的DP数组ndp，最初等于dp。 这代表跳过边缘 i 的选项。 
3. 如果我们选择边 i，我们将为所有 k 更新 ndp[k + 1] = max(ndp[k + 1], dp[k])。 这对应于增加所选边的数量。 
4. 在应用此转换之前或之后，我们处理右端点为 i 的所有票证。 对于每张票 (l, i, v)，我们需要确定当前配置中是否选择了从 l 到 i − 1 的所有边。 由于 dp 没有显式编码位置，因此当我们保证该区间中的所有 k = i − l + 1 边必须在通向该状态的转换中选择时，我们只通过添加 v 来确保正确性。 

这是通过维护 dp 已经反映了对前缀的有效选择来强制执行的，并且仅当 DP 状态完全对应于选择间隔中的所有边缘时才记入间隔。 

1.处理完位置i处的所有票据后，我们将dp替换为ndp。 
2. 完成所有位置后，dp[k] 包含每个 k 的答案。

微妙之处在于票证激活与完成连续的边块相关。 由于边是按顺序处理的，并且每个边要么被选择，要么不被选择，所以当选择最后一个缺失的边时，任何间隔都会完全激活，这在处理右端点时自然会在转换中捕获。 

为什么它有效

 DP 不变量是，在处理前 i 个边之后，dp[k] 存储这些大小为 k 的边的所有子集上可实现的最佳值，其中右端点至多为 i 的所有票据贡献已经被计算一次，此时包含了它们最终所需的边。 由于每张票证都与唯一的完成事件相关联，因此不会重复计算任何值，并且不会遗漏任何有效配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, m = map(int, input().split())
        ends = [[] for _ in range(n + 1)]
        for _ in range(m):
            l, r, v = map(int, input().split())
            ends[r].append((l, v))

        dp = [-10**18] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):
            ndp = dp[:]

            for k in range(i):
                if dp[k] > -10**17:
                    ndp[k + 1] = max(ndp[k + 1], dp[k])

            dp = ndp

            for l, v in ends[i]:
                length = i - l + 1
                for k in range(length, n + 1):
                    dp[k] += v

        print(*dp[1:])

if __name__ == "__main__":
    solve()
```该代码按顺序处理边，并在到目前为止已选择的边数上维护背包式 DP。 过渡循环“获取”或“跳过”每条边，确保恰好选择 k 个边。 之后，应用以 i 结尾的票证。 

一个微妙的实现细节是用负无穷大初始化 DP，因此无效状态永远不会起作用。 另一个是确保我们只在添加新边之前当 k < i 时访问 dp[k]，因为在 i 边之后我们不能选择超过 i 条边。 

票证应用程序绑定到正确的端点，这避免了重复计算。 当其间隔完全由前缀确定时，每张票证仅添加一次。
