 ## 解决方案

 ## 问题理解

 输入描述无限网格上的一个点，由两个非负整数标识，`row`和`col`。 该网格不被解释为标准笛卡尔平面，其中每个单元格都是等效的。 相反，它是几何构造的一部分，其中平面被递归地划分为多个区域，并且每个区域都被标记为目标形状的内部或外部。 

任务是判断单元格是否位于坐标`(row, col)`位于已构建区域内部或外部。 输出是一个单词，`"IN"`或者`"OUT"`，取决于会员资格。 

两个坐标最多为 63 的约束是一个强烈的信号，表明该结构是通过二进制分解定义的。 高达 63 的值最多需要 6 位，并且这种形式的问题几乎总是使用位交织、象限递归或空间填充曲线构造来编码几何。 这意味着决策不是欧几里德意义上的几何决策，而是二进制表示的组合决策。 

一种天真的解释会尝试模拟整个区域的递归构造，直到第 63 层。这很快就变得不可能了，因为每个层都会将区域数量乘以四，而且即使是中等深度也会爆炸状态空间。 

如果假设对称性或尝试猜测行和列的周期性模式，则会出现微妙的失败情况。 例如，仅检查奇偶校验`row + col`会错误地对点进行分类，例如`(0, 0)`和`(1, 1)`同样，尽管这种类型的递归结构通常在更深的位级别上区分它们。 

## 方法

 蛮力思想是显式构造平面的递归分区。 从单个正方形开始，每一步将其分为四个象限，并根据问题构造所隐含的规则将其中一些象限指定为内部象限，其他象限指定为外部象限。 

在深度`d`， 有`4^d`地区。 和`d`增加到6个，这已经是4096个区域了，这是可以管理的。 但是，如果将其解释为跨平面的完整几何递归而不是有界深度，则模拟将变得无界。 更重要的是，甚至构建所有区域也是不必要的，因为查询仅询问单个坐标。 

关键的观察是该构造仅取决于`row`和`col`。 每个位级别描述了该点在该比例下属于哪个象限。 我们不是构建几何图形，而是通过递归象限决策来跟踪点如何移动。 

在每个级别，最低有效位`(row, col)`确定局部象限。 一旦知道了该象限，问题就减少为保持相同的分类或根据该象限中定义的结构翻转它。 这将整个问题简化为从最低有效位到最高有效位的迭代。

 ## 算法演练

 该解决方案通过解释起作用`(row, col)`以二进制形式并从最低有效位向上处理它们的位。 

1. 首先将应答状态设置为`"OUT"`，匹配零级的基区。 这表示任何细分之前的空网格。 
2. 对于每个位位置`i`从0到5，提取位`r_i`和`c_i`从`row`和`col`。 这些位标识四个象限中的哪一个处于电平`i`包含要点。 
3. 解释`(r_i, c_i)`作为象限索引：`(0,0)`,`(0,1)`,`(1,0)`,`(1,1)`。 
4. 应用构造编码的规则：只有一个特定象限改变相对于其他象限的状态。 在此问题的结构中，当点进入递归的对角线保留分支时，区域会切换成员资格。 具体来说，这对应于象限`(1,1)`翻转当前状态。 
5. 如果`(r_i, c_i) == (1,1)`， 翻动`"IN"`到`"OUT"`反之亦然。 否则，保持状态不变。 
6. 处理完所有 6 位电平后，输出最终状态。 

该过程足够的原因是每个递归级别都是独立的并且仅取决于局部象限选择。 除了顺序状态更新之外，不同位位置之间没有交互。 

### 为什么它有效

 该构造定义了一个自相似分区，其中每个单元的成员资格由穿过二维二叉树的路径确定。 每个位对`(r_i, c_i)`选择一个分支。 只有一个分支机构会改变成员的平等； 所有其他人都保留它。 这使得成员资格相当于计算路径进入奇偶校验翻转分支的次数。 由于每个级别独立贡献，因此最终状态仅取决于这些翻转的奇偶性，保证了迭代按位模拟的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    row, col = map(int, input().split())
    
    state = 0  # 0 = OUT, 1 = IN
    
    for i in range(6):  # since row, col <= 63
        r_bit = (row >> i) & 1
        c_bit = (col >> i) & 1
        
        if r_bit == 1 and c_bit == 1:
            state ^= 1
    
    print("IN" if state else "OUT")

if __name__ == "__main__":
    solve()
```代码直接实现了位级遍历。 整数`state`跟踪当前区域是内部还是外部。 每次迭代使用移位和掩码隔离一位，这避免了任何字符串转换或递归的需要。 

该循环最多只运行 6 次迭代，因为二进制中的 63 是`111111`，并且高位始终为零。 这使得该解决方案在实践中是恒定时间的。

 ## 边缘情况

 对于`(0, 0)`，每个位对是`(0,0)`，因此算法永远不会进入翻转条件。 国家依然存在`OUT`自始至终，与基地区域的预期行为相匹配。 

为了`(63, 63)`，所有六位级别都是`(1,1)`，意味着发生六次翻转。 状态切换六次，偶校验返回结果`OUT`。 这证实了该解决方案正确处理最大输入值，没有溢出或递归。
