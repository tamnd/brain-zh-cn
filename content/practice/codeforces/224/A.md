 ## 解决方案
 ## 问题理解

 我们给出三个正整数，表示长方体的三个面在单个顶点处相交的面积。 每个区域对应于两个边长的乘积：一个面是边的乘积$a$和$b$， 其他$b$和$c$，第三个$a$和$c$， 在哪里$a$,$b$， 和$c$是未知的边长。 我们的任务是确定这个平行六面体所有 12 条边的总和。 由于每条边都出现在总共 12 条边中的 4 条中，因此所有边的总和为$4(a + b + c)$。 

输入约束很简单：所有面部面积都是不超过的正整数$10^4$，并且有效的平行六面体始终存在。 面积的较小上限意味着我们所做的任何算术都保持在标准整数范围内。 没有大型数组或序列，因此该算法必须仅对三个整数进行操作。 一个微妙的点是，输入可能对应于立方体（所有面积相等）或高度不对称的形状（例如，区域 2、3、6），因此任何解决方案都必须处理满足乘积关系的所有整数三元组。 

一种简单的方法可能会尝试枚举所有可能的整数三元组$a$,$b$,$c$乘以给定区域，但区域之间的结构化关系允许直接公式。 如果粗心的解决方案假设所有边都相等或尝试独立地对各个区域求平方根而不考虑它们之间的一致性，则可能会产生错误的结果。 

## 方法

 蛮力方法是迭代所有可能的整数$a$,$b$， 和$c$这样$1 \le a, b, c \le 10^4$，检查每对是否乘以相应的面部区域。 这是可行的，因为每个区域的边界为$10^4$，但最坏情况下的操作次数是$O(10^4 \cdot 10^4 \cdot 10^4)$，这远远超出了 2 秒的限制，使得暴力破解变得不切实际。 

最佳方法来自于观察每个区域是两条边的乘积。 将区域表示为$x = ab$,$y = bc$,$z = ac$。 将所有三个相乘得出$xyz = (ab)(bc)(ac) = a^2 b^2 c^2 = (abc)^2$，让我们能够求解体积$abc = \sqrt{xyz}$。 一旦我们知道$abc$，我们可以隔离每条边：$$a = \sqrt{\frac{x \cdot z}{y}}, \quad b = \sqrt{\frac{x \cdot y}{z}}, \quad c = \sqrt{\frac{y \cdot z}{x}}$$这会产生整数结果，因为该问题保证了有效的平行六面体。 找到后$a$,$b$， 和$c$，我们将边的总和计算为$4(a + b + c)$。 这种方法只需要一些算术运算和平方根，时间复杂度为$O(1)$和恒定的空间。

 | 蛮力 | O(10^{12}) | O(10^{12}) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取代表在一个顶点相交的面的面积的三个整数。 将它们表示为$x$,$y$， 和$z$。 
2. 计算乘积$xyz$。 对该乘积求平方根即可求出平行六面体的体积：$V = \sqrt{xyz}$。 这是有道理的，因为$(abc)^2 = xyz$。 
3. 使用面积关系单独计算每条边的长度：

 -$a = \sqrt{\frac{x \cdot z}{y}}$-$b = \sqrt{\frac{x \cdot y}{z}}$-$c = \sqrt{\frac{y \cdot z}{x}}$4. 计算所有边的总和：$4(a + b + c)$。 打印该值。 

这是可行的，因为三个面部区域之间的关系唯一地确定了正整数的边长。 不变量是$ab = x$,$bc = y$， 和$ac = z$。 如上所述求解每个边可以保证这些不变量准确地保持。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

x, y, z = map(int, input().split())

a = int(math.isqrt(x * z // y))
b = int(math.isqrt(x * y // z))
c = int(math.isqrt(y * z // x))

print(4 * (a + b + c))
```我们在平方根内部使用整数除法来确保结果是整数，然后再取`isqrt`，它安全地返回整数平方根，没有浮点舍入错误。 使用`math.isqrt`避免精度问题并保证精确的整数结果，这对于竞争性编程的正确性至关重要。

 ## 边缘情况

 对于像这样的立方体输入`1 1 1`，算法计算`a = b = c = 1`和输出`12`，正确处理平等场景。 对于高度不对称的输入，例如`2 3 6`，计算产生边缘`a = 2`,`b = 1`,`c = 3`, 总和`24`，正确反映不同的边长。 由于整数运算，该公式不会产生浮点不匹配，并且`math.isqrt`，确保准确计算所有有效的平行六面体。
