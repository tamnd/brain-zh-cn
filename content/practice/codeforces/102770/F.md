 ## 解决方案
 ## 问题理解

 输入描述了两个二元分类器。 每个分类器采用 N 维样本向量并计算其坐标的加权和，然后将该值移动一个偏差。 最终数字的符号就是分类器的答案。 我们需要构建一个样本向量，其两个分类器最终位于零的两侧。 值为零是不够的，因为所需的两个答案的乘积必须严格为负数。 

特征数量可以达到200个，而测试用例数量最多为10个。这排除了枚举可能样本或依赖于坐标范围大小的方法。 坐标是实数，因此有用的运算是代数变换和线性求解而不是搜索。 这些系数是小整数，这也意味着精心构造的答案可以符合所需的输出限制。 

有几种情况可能会破坏仅检查两个感知器在代数上是否不同的实现。 如果两个感知器始终输出零，则它们不满足条件。 例如：```
1
1
0 0
0 0
```正确的输出是：```
No
```因为每个样本都会给出输出 0 和 0，其乘积不为负。 

另一个陷阱是假设不同的权重向量总是意味着存在解决方案。 如果权重相同但偏差将分类器分开，则可以存在解决方案。 例如：```
1
1
1 0
1 -1
```选择 x = 1 会给出分类器值 1 和 0，但这仍然无效。 选择 x = 2 给出值 2 和 1，同样无效。 这两个分类器总是相等的，所以答案是：```
No
```仅比较参数的粗心实现可能会得出错误的结论。 

相反的情况也会出现。 当偏差足够大时，相同的权重仍然可以得到相反的结果。 例如：```
1
1
1 0
1 2
```选择 x = -1 给出值 -1 和 1，因此答案存在。 该算法必须推理实际的线性函数，而不仅仅是它们的系数。 

## 方法

 直接方法将尝试猜测样本坐标的值并评估两个感知器。 由于每个坐标都是实数，因此不存在有限的搜索空间。 即使将搜索限制在网格内也将需要大量的候选者，并且会错过网格点之间的有效答案。 

有用的观察是，应用符号之前的每个感知器输出都是仿射函数。 我们只关心两个结果值，而不关心各个坐标。 样本向量被变换为二维平面上的点(f1(x),f2(x))。 我们需要这个点进入第一个值为正而第二个值为负的象限，或者相反的象限。 

如果两个权重向量是独立的，我们就可以独立地控制这两个值。 两个独立的行给出排名第二，因此有两个坐标，其贡献可用于求解任何所需的感知器值对。 我们可以直接请求值1和-1。 

如果权重向量的秩为一，则两个加权和都取决于单个变量。 问题变成找到一个值 t，其中两个一维线性函数具有相反的符号。 它们的符号仅在根处发生变化，因此检查这些根产生的间隔就足够了。 

如果等级为零，则两个分类器都是常量，无需构建任何内容。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 无法绑定| O(1) | O(1) | 太慢了 |
 | 最佳| O(N) | O(N) | 已接受 |

 ## 算法演练

 1. 读取两个感知器并将它们的权重向量与它们的偏差分开。 
2. 检查两个权重向量是否有两个独立的坐标。 找到两个索引 i 和 j，其中相应 2 x 2 矩阵的行列式不为零。 如果它们存在，则将所有其他坐标设置为零并求解两个方程，迫使感知器值变为 1 和 -1。 这两个坐标就足够了，因为两个权重向量跨越整个二维输出空间。 
3. 如果秩为零，则两个权重向量都为零。 答案固定在两个偏见上。 如果一个偏置为正而另一个偏置为负，则输出零坐标。 否则输出“否”。 
4. 如果等级为 1，则选择一个非零权重向量 u。 每个加权和都是 u dot x 的倍数，因此引入 t = u dot x。 两个分类器值变为a_t+b1和c_t+b2。 计算任一表达式变为零的根，然后测试这些根周围的间隔。 
5. 当在排名一的情况下找到有效的 t 时，通过将所有贡献放入绝对值最大的 u 坐标中来创建样本向量。 将该坐标设置为 t/u[i] 即可得到 u dot x = t，同时保持打印值较小。 

为什么它有效：

 该算法之所以有效，是因为感知器值对完全由样本向量的线性映射确定。 在第二级中，地图可以到达输出平面中的每个点，包括 (1,-1)。 在第一级中，可到达的点形成一条线，并且线性函数的符号只能在其零处改变。 测试零之间的每个间隔涵盖了所有可能的符号模式。 在等级 0 中，输出永远不会改变，因此检查常量就足够了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(n, a, b):
    w1, b1 = a[:n], a[n]
    w2, b2 = b[:n], b[n]

    nz1 = any(x != 0 for x in w1)
    nz2 = any(x != 0 for x in w2)

    if not nz1 and not nz2:
        if b1 > 0 and b2 < 0 or b1 < 0 and b2 > 0:
            return " ".join(["0"] * n)
        return "No"

    if nz1 and nz2:
        p = -1
        q = -1
        for i in range(n):
            for j in range(i + 1, n):
                det = w1[i] * w2[j] - w1[j] * w2[i]
                if det != 0:
                    p, q = i, j
                    break
            if p != -1:
                break
        if p != -1:
            det = w1[p] * w2[q] - w1[q] * w2[p]
            r1 = 1 - b1
            r2 = -1 - b2
            x = [0.0] * n
            x[p] = (r1 * w2[q] - w1[q] * r2) / det
            x[q] = (w1[p] * r2 - r1 * w2[p]) / det
            return " ".join("{:.10f}".format(v) for v in x)

    if nz1:
        u = w1[:]
        c = None
        for i in range(n):
            if u[i] != 0:
                c = w2[i] / u[i]
                break
    else:
        u = w2[:]
        c = None
        for i in range(n):
            if u[i] != 0:
                c = w1[i] / u[i]
                break
        b1, b2 = b2, b1
        c, _ = 1 / c, None

    roots = []
    if abs(c) > 1e-15:
        roots.append(-b2 / c)
    roots.append(-b1)

    roots = sorted(set(roots))
    candidates = [0.0]
    if roots:
        candidates.append(roots[0] - 1)
        for i in range(len(roots) - 1):
            candidates.append((roots[i] + roots[i + 1]) / 2)
        candidates.append(roots[-1] + 1)

    for t in candidates:
        v1 = b1 + t
        v2 = b2 + c * t
        if v1 * v2 < 0:
            idx = max(range(n), key=lambda i: abs(u[i]))
            x = [0.0] * n
            x[idx] = t / u[idx]
            return " ".join("{:.10f}".format(v) for v in x)

    return "No"

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        ans.append(solve_case(n, a, b))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```该代码首先处理零秩情况，因为这是样本对输出没有影响的唯一情况。 二级搜索寻找非零行列式，这正是两个坐标可以独立控制两个分类器值的条件。 

排名一部分使用单个参数 t 重写了问题。 所选向量 u 是权重的非零方向，因此每个可能的样本都对应于某个可达的 t。 根部是唯一可以改变符号的地方，因此检查它们周围的间隔就足够了。 

将 t 转换回坐标时，该实现使用 u 中的最大系数。 这会减少打印坐标的大小并使结果保持在允许的范围内。

 ## 边缘情况

 全零情况在任何线性代数之前处理。 对于输入：```
1
1
0 0
0 0
```该算法认为两个权重向量都不能改变其输出。 由于两个偏差都为零，因此没有正负对，因此它打印“No”。 

排名第一的情况是错误解决方案失败的主要地方。 考虑：```
1
1
1 0
2 0
```该算法将问题简化为 t。 值为 t 和 2t。 唯一的根是 t = 0，并且两个区间都有匹配的符号。 由于不存在有效间隔，因此它正确报告“否”。 

独立权重情况是通过求解两个方程而不是搜索来处理的。 例如：```
1
2
1 0 0
0 1 0
```行列式不为零，因此算法可以分别强制第一输出和第二输出。 将目标值设置为 1 和 -1 会立即给出有效样本。
