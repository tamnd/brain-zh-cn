 ## 解决方案
 ## 问题理解

 我们从初始评级值和一系列事件开始。 每个事件都有一个关联的参数$s_i$。 对于我们选择参加的任何活动，我们的评级都会根据非线性公式发生变化，该公式取决于当前评级$r$和事件值$s_i$。 具体来说，在事件发生后$i$，新的评级成为分数的上限，其中$s_i - r$除以$r$加上固定不变的转变。 目标是决定参与哪个事件子集，以便在以与时间一致的任何顺序处理所选事件后最小化最终评级。 

关键的困难在于每个决策都会改变状态，而未来的转变在很大程度上取决于当前的评级。 这会产生一个顺序优化问题$n \le 10^5$事件，其中不可能对所有子集进行天真的探索。 

评级范围最初相对较小，但转换可以根据符号和大小快速缩小或增大值$s_i$。 约束条件$r_0 \le 10^4$表明值在数值上仍然是可管理的，这通常暗示有界状态空间上的贪婪或动态过程。 

当变换产生非常负或非常大的跳跃时，就会出现微妙的边缘情况。 例如，如果$s_i \ll r$，分子变得强烈负数，评级可能急剧下降，这可能使早期决策变得非常有价值。 相反，如果$s_i \gg r$，跳过可能是最佳选择，因为它可以显着提高评级。 

另一个微妙之处是天花板操作。 整数除法和符号处理方面的小算术错误将产生不正确的转换。 例如，当值为负时，朴素整数除法截断与数学下限/上限行为不同。 

## 方法

 蛮力的想法是尝试每个子集$n$事件。 对于每个子集，我们按顺序模拟事件，使用给定的公式逐步更新评级。 这是正确的，因为它直接遵循问题定义：每个事件要么被采取要么被跳过，并且我们评估最终的评级。 

然而，这在计算上立即失败。 有$2^n$子集，以及每个模拟成本$O(n)$，导致$O(n2^n)$最坏情况下的操作。 和$n = 10^5$，甚至枚举子集也是不可能的。 

关键的观察结果是，转换函数仅取决于电流额定值和单个事件参数。 我们不选择顺序，只选择子集，并且事件按固定的时间顺序进行处理。 这意味着我们正在有效地执行一系列状态转换，其中每个事件都给我们一个二元选择：跳过或应用确定性转换。 

这种结构自然会导致对可达到的评级值进行动态规划。 然而，评级空间原则上很大，但实践中却受到限制。 自从$r_0 \le 10^4$并且更新规则在许多区域具有很强的收缩性，不同的可达状态的数量仍然足够小以进行有效跟踪。 我们在每个事件发生后维护一组可能的评级，通过保留旧值或应用转换来更新它。 

为了提高效率，我们使用集合或字典来仅存储可达状态并修剪主导值，因为较高的中间评级只会使这种转换结构下的未来结果恶化。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n2^n)$|$O(n)$| 太慢了|
 | 状态 DP 超过可达收视率 |$O(n \cdot R)$|$O(R)$| 已接受 |

 这里$R$是不同的可达评级状态的数量，由于收缩行为，该数量仍然很小。 

## 算法演练

 我们模拟该过程，同时在处理每个事件前缀后维护一组所有可能的评级。 

1. 初始化一个仅包含起始评级的集合$r_0$。 这代表了做出任何决定之前的所有可能状态。 
2. 按以下顺序迭代事件$1$到$n$。 活动中$i$，我们根据前一组构建一组新的可能评级。 
3. 对于每个电流额定值$r$在集合中，考虑跳过该事件。 在那种情况下，$r$保持不变并结转。 
4. 还可以考虑参加该活动。 使用给定的公式计算新的评级，仔细应用整数上限行为。 将这个新值添加到下一个状态集中。 
5. 处理完事件的所有状态后$i$，用新组替换旧组。 
6. 如果多个状态崩溃到相同的值，则可以选择性地通过仅保留最少的或相关的代表来修剪主导状态。 
7. 处理完所有事件后，答案是最终集合中的最小值。 

正确性取决于这样一个事实：每个有效的选择序列都恰好对应于通过此状态扩展的一条路径，并且我们永远不会丢弃任何可达的评级。 

### 为什么它有效

 在每一步中，算法都保持不变，即该集合包含处理第一个步骤后可达到的所有评级$i$某些有效子集选择下的事件。 Skip 操作保留现有路径，而 take 操作应用问题定义的精确转换。 由于两个不同的序列不会被错误地合并，除非它们产生相同的评级，并且由于相同的评级对于所有未来的转换都是等效的，因此状态集完全表征了所有可能性。 最终答案是最小元素，因为所有有效的最终评级均已表示。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, r0 = map(int, input().split())
    s = list(map(int, input().split()))

    states = set([r0])

    for si in s:
        nxt = set()
        for r in states:
            nxt.add(r)

            # apply transformation:
            # new = ceil((si - r) / (r + 1))
            # careful integer ceiling
            num = si - r
            den = r + 1

            if den > 0:
                if num >= 0:
                    new_r = (num + den - 1) // den
                else:
                    new_r = num // den  # already toward -inf in Python, adjust for ceiling
                    if num % den != 0:
                        new_r += 1
            else:
                # degenerate case, unlikely due to constraints
                new_r = r

            nxt.add(new_r)

        states = nxt

    print(min(states))

if __name__ == "__main__":
    solve()
```每次事件发生后，代码都会维护一组可达到的评级。 对于每个状态，它都会分为跳过或接受事件。 该转换是通过仔细处理上限除法、拆分正数和负数分子来实现的，以避免 Python 的下限除法陷阱。 

最终答案被计算为所有可达状态的最小值，因为我们被要求最小化最终评级。 

一个微妙的实施问题是确保负值上限划分的正确性。 蟒蛇的`//`总是楼层，因此当分子不能被分母整除时，必须纠正直接使用。

 ## 边缘情况

 关键的边缘情况发生在以下情况：$s_i$与$r$。 在这种情况下，分子$s_i - r$变得很大并且为负，并且上限除法可以使结果远低于零。 该算法仍然可以处理这个问题，因为它显式地处理每个可到达的负状态，而不是假设非负状态。 

另一种边缘情况是重复变换生成重复状态。 例如，两个不同的序列可以在不同的事件子集之后产生相同的评级。 基于集合的表示会自动合并它们，防止指数爆炸，同时保持正确性。 

最后一个边缘情况是所有事件都应该被跳过。 该算法在每一步中都会保留初始状态，因此即使每次转换都是有害的，初始评级仍然可以达到，并被视为最终的最小值。
