 ## 解决方案
 ## 问题理解

 我们被要求指定街道上房屋的高度，以最大化总利润。 街上有`n`可用位置，每个位置都可以容纳一座房屋，其高度介于`0`和`h`。 高层房子的利润`a`是`a^2`。 

有`m`城市限制。 每个限制指定一个连续的位置范围`[l_i, r_i]`, 高度限制`x_i`，以及处罚`c_i`。 如果该范围内最高的房子超过`x_i`, 处罚`c_i`从利润总额中扣除。 我们的任务是选择高度以使利润减去罚金后的总和最大化。 

限制很小：`n, h, m ≤ 50`。 这意味着算法大约可以达到`O(n * h^2 * m)`或者`O(h^n)`通过修剪可能是可行的。 因为两者`n`和`h`最大为 50，天真地尝试每种高度组合（`h^n`）显然是不切实际的。 边缘情况涉及覆盖单个位置的范围、具有不同限制的重叠范围或等于的限制`0`或者`h`。 例如，如果限制说“spot”`1`不能超过高度`0`，一种简单的方法，将所有高度分配给`h`会招致不必要的处罚。 

## 方法

 蛮力方法将迭代所有可能的高度分配。 对于每个作业，计算平方和并减去违反限制的所有罚款。 作业数量为`O((h+1)^n)`，这对于`n = 50`。 

更系统的方法是将这个问题视为**高度限制传播问题**。 每项限制都有效地限制了其范围内房屋的高度。 如果限制施加最多`x_i`，那么每个位置的最佳高度`[l_i, r_i]`不能超过`x_i`且不产生罚款`c_i`。 由于利润是二次方的，并且随着高度的增加而增加，因此我们希望将每栋房子设置得尽可能高，而无需支付不必要的罚款。 

关键的见解是我们可以**为每个位置分配影响它的所有限制的最小值**，然后对平方求和。 这是有效的，因为每个限制都可以独立应用：一旦我们确定了每个位置的上限以避免罚款，只有当我们愿意支付罚款时，增加超过该上限的高度才有利可图，但支付罚款永远不会比选择限制下的最大高度更好。 因此，我们可以计算每个位置允许的最大高度，然后减去如果我们决定违反限制而产生的罚款。 

由于限制和惩罚很小且范围很短，因此直接模拟是有效的。 我们初始化一个数组`height_limit`和`h`对于所有职位。 对于每个限制，我们更新位置`[l_i, r_i]`与电流限制的最小值和`x_i`。 此后，最优分配为`height[i] = height_limit[i]`对于所有职位。 最后，将总利润计算为平方和减去仍然违反的任何限制的罚款（如果我们决定忽略某些限制）。 在实践中，因为问题想要最大的利润并且所有罚款都是正数，所以违反上限永远不是最佳选择，因此我们可以简单地强制执行最小高度限制。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((h+1)^n * m) | O(n) | 太慢了 |
 | 最佳 | O(n * m) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`height_limit`尺寸的`n`有价值`h`。 这代表在任何处罚之前每个位置允许的最大高度。 
2. 对于每项限制`(l_i, r_i, x_i, c_i)`，迭代位置`l_i-1`到`r_i-1`并更新`height_limit[pos] = min(height_limit[pos], x_i)`。 这确保我们永远不会超过上限，从而避免罚款。 
3. 初始化`profit = 0`。 
4. 对于每个位置`i`在`[0, n-1]`， 添加`height_limit[i]^2`到`profit`。 这捕获了强制限制下的最大增益。 
5. 无需扣除罚款，因为限制已经执行。 返回`profit`。 

为什么它有效：保持不变的是在每一步，`height_limit[i]`是最大高度`i`这不会引发任何罚款。 任何大于此限制的高度都会因罚款而减少利润，而任何较小的高度都会减少平方增益。 因此分配是全局最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, h, m = map(int, input().split())
height_limit = [h] * n

for _ in range(m):
    l, r, x, c = map(int, input().split())
    for i in range(l-1, r):
        height_limit[i] = min(height_limit[i], x)

profit = sum(a * a for a in height_limit)
print(profit)
```第一个块读取输入并初始化最大可能高度。 循环限制可确保每个房屋不超过限制限制。 最终的计算结果是平方和，这是正确的，因为二次利润随着高度达到极限而增加。 使用`l-1`和`r`确保正确的基于 0 的索引。
