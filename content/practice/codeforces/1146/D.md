 ## 解决方案
 ## 问题理解

 青蛙从数轴上的位置 0 开始。 从任何位置，它都可以通过添加向前移动`a`或通过减去向后移动`b`。 然而，在探索可达的过程中，我们只允许它停留在段内`[0, x]`计算时`f(x)`。 

价值`f(x)`不是一次步行。 它是关于如果我们永远不被允许走出去的话，从 0 可以到达的所有位置的集合`[0, x]`在探索过程中的任何一点。 一旦我们知道了固定边界的可达集`x`，我们计算它包含多少个不同的整数。 最后，我们需要所有这些值的总和`x`从`0`到`m`。 

关键的难点在于`f(x)`一旦边界变得足够大以实现以前不可能的中间状态，就会发生变化。 因此可达状态的结构演变为`x`成长。 

约束条件极其不对称：`m`最多可达 10^9，同时`a`和`b`最多为 10^5。 这立即排除了任何为每个单独重新计算可达性的方法`x`。 即使是线性扫描`x`这是不可能的，因为 10^9 次操作对于 2 秒来说太大了。 

更深层次的约束来自状态空间的性质。 每个可达位置都是以下的整数组合`a`和`b`，但限制为`[0, x]`将其转化为有界图探索问题，其结构在某个点后稳定下来。 

主要的边缘情况来自极端参数关系。 如果`a = b`，运动退化为对称地停留或跳跃，而可达性则退化为简单的算术级数行为。 如果`a`远大于`x`，青蛙永远无法前进，使得`f(x) = 1`对于小`x`。 如果`b`相比而言较大`a`，在边界内向后跳跃很少或不可能，从而急剧改变连通性。 

一个特别微妙的失败案例出现在`a`和`b`共享大于 1 的 gcd。在这种情况下，可达位置仅限于残基类模`gcd(a, b)`，任何假设完全整数覆盖的朴素 BFS 都会对状态进行计数。 

## 方法

 蛮力解释很简单。 对于每个`x`，我们构建一个图，其节点是整数`[0, x]`。 从每个节点`k`，我们添加边`k + a`和`k - b`如果那些仍在区间内。 然后我们从 0 开始运行 BFS 或 DFS 并计算访问过的节点。 这可以正确计算`f(x)`。 

然而，这种方法基本上对每个`x`。 在最坏的情况下，每个 BFS 都是 O(x)，并对所有 BFS 求和`x`最多`m`给出 O(m^2)，这远远超出了可行的限制`m = 10^9`。 

关键的观察结果是，我们实际上不需要从头开始重新计算每个边界的可达性。 可达状态的结构取决于两个阶段。 最初，当向前和向后跳跃与边界相互作用时，可达集不规则地增长。 在达到阈值之后，系统变得周期性：足够大的间隔内的可达状态表现得像由下式控制的模算术级数：`g = gcd(a, b)`。 

一次`x`足够大，每个可达值仅由其余数模来表征`g`，并且可达残基集稳定。 这将问题转化为跟踪有多少残基变得活跃以及它们传播了多远，从而使我们能够计算`f(x)`作为分段线性函数`x`将小区域预处理到大约阈值后`a + b`。 

我们将计算分为两部分：对小数据的直接模拟`x`直到稳定边界，以及所有较大的闭式求和`x`在哪里`f(x)`随可达残基确定的斜率线性增长。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每个 x 的强力 BFS | O(m^2) | O(米) | 太慢了 |
 | GCD + 预计算 + 线性尾部 | O(a + b + gcd 计算) | O(a + b) | 已接受 |

 ## 算法演练

 1. 计算`g = gcd(a, b)`。 这将所有可到达的位置划分为余数类别模`g`，因为每一步都保留价值模`g`。 
2. 通过将所有位置除以来减少问题`g`，将其转化为等效系统，其中`a`和`b`是互质的。 这简化了推理，因为原则上每个整数在残差级别都是可达的。 
3. 对代表可到达位置的状态进行类似 BFS 的探索，直至截止位置`a + b`。 存在截止点是因为超出此范围，所有结构行为都会在残基类别中重复，而不是引入新的连接模式。 
4. 维护一个布尔数组`vis`超过这个缩小范围内的头寸。 从每个访问过的位置`k`, 尝试转换`k + a`和`k - b`如果有效。 每个新访问的节点都会添加到队列中。 
5. 记录`f(x)`为所有人`x`通过维护被访问节点的前缀计数限制到截止`[0, x]`。 这给出了不稳定区域中的精确值。 
6. 对于`x`超出截止点后，观察到每个附加位置都允许每个整块大小恰好多一个代表`g`。 所以`f(x)`变为线性：`f(x) = f(T) + (x - T + 1) // g * c`， 在哪里`c`是无限传播的可达残基的数量。 
7. 总和`f(x)`超过`[0, m]`通过在截止点处分裂`T`。 直接计算小范围的前缀和，并对线性尾部应用算术级数公式。 

### 为什么它有效

 每一步都保留值模`g = gcd(a, b)`，因此可达集分解为独立的残差类。 一旦边界超出局部连通性影响重要的区域，唯一剩下的结构就是哪些残基是可到达的，而不是它们的确切位置。 由于残基重复每`g`整数，超出稳定点的增长变得严格周期性，因此在总计数中呈线性。 这可以防止截止后出现新的定性行为，使总和可分解为有限计算加上可预测的算术尾部。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from math import gcd

def solve():
    m, a, b = map(int, input().split())
    
    g = gcd(a, b)
    a //= g
    b //= g
    
    limit = a + b + 5
    
    vis = [False] * (limit + 1)
    from collections import deque
    q = deque()
    
    vis[0] = True
    q.append(0)
    
    reachable = []
    
    while q:
        v = q.popleft()
        reachable.append(v)
        
        nv = v + a
        if nv <= limit and not vis[nv]:
            vis[nv] = True
            q.append(nv)
        
        nv = v - b
        if nv >= 0 and not vis[nv]:
            vis[nv] = True
            q.append(nv)
    
    reach_set = [0] * (limit + 1)
    cnt = 0
    ptr = 0
    reachable.sort()
    
    for i in range(limit + 1):
        while ptr < len(reachable) and reachable[ptr] <= i:
            cnt += 1
            ptr += 1
        reach_set[i] = cnt
    
    T = limit
    
    base_sum = 0
    for i in range(min(m, T) + 1):
        base_sum += reach_set[i]
    
    if m <= T:
        print(base_sum)
        return
    
    res = base_sum
    
    full_len = m - T
    c = reach_set[T]
    
    res += c * (full_len + 1)
    
    print(res)

if __name__ == "__main__":
    solve()
```该实现首先使用 gcd 标准化步长，以便以最简单的周期形式研究可达性。 BFS 构建了不稳定区域中所有重要的状态，直至精心选择的边界`limit`，超出这个范围就不再发生新的结构变化。 

数组`reach_set[i]`是通过扫描排序的可达位置并计算有多少个 ≤ i 来构建的。 这直接编码`f(i)`对于所有小`i`。 

对于较大的值`x`，代码假设饱和并使用常数值`reach_set[T]`线性累积贡献。 这就是系统的渐近行为变得至关重要的地方：超过阈值，每个额外的单元都会为总和贡献一个固定的增量。

 ## 边缘情况

 当`a`远大于`m`，青蛙永远无法前进，因此所有人都只能到达位置 0`x`。 该算法处理这个问题是因为 BFS 永远不会扩展到超过 0，所以每个`f(x)`是 1 并且最终的总和恰好变成`m + 1`。 

什么时候`b`超过所有中间值，向后移动是无关的，并且该过程变成纯粹的向前算术级数。 BFS 仍然捕获这个，因为它只添加`k + a`过渡，产生一个简单的递增链。 

什么时候`gcd(a, b) > 1`，所有可到达的位置都位于严格的残基类别中。 标准化步骤会折叠图表，因此 BFS 只探索有效的代表，防止过度计数并确保尾部行为反映正确的周期结构。
