 ## 解决方案
 ## 问题理解

 我们有一棵有根的树`n`节点，其中节点`1`是根。 除根节点外，每个节点都指定了一个父节点。 叶子是任何没有子节点的节点。 任务是将所有叶子划分为非空组，使得包含任何组的最小子树不与任何其他组的最小子树重叠。 我们想要计算此类分区的总数以 998244353 为模。 

输入由定义树的父列表组成。 每个元素`p[i]`表示该节点`i+2`是一个孩子`p[i]`。 该树可以有 200,000 个节点那么大，因此任何在`n`几乎肯定会太慢。 这意味着对所有叶分区进行强力枚举是不可行的，因为分区的数量可能呈指数级增长。 因此，该算法必须利用树结构来聚合线性或近线性时间内的可能性。 

边缘情况很微妙。 一棵树可能只有一个叶子，在这种情况下只有一个有效分区。 根直接连接到所有叶子的星形树需要仔细计算分区，因为根下叶子的每种组合都会产生不同的子树结构。 如果我们不小心地在树中自下而上传播分区计数，那么在这种对称结构中很容易出现错误计数。 

## 方法

 一种简单的方法是枚举叶子的所有分区，然后对于每个分区，计算每个组的最小子树并检查重叠。 这在原则上是正确的，但完全不切实际，因为`k`叶子随着贝尔数的增长而增长`k`，这是超指数的。 为了`k = 20`叶子，有超过 5×10^13 的分区，远远超出了我们的处理能力。 

关键的见解是使用树上的动态规划自下而上地解决问题。 考虑任意节点`v`。 如果`v`是一片叶子，它只能形成一个包含自身的单一群体。 如果`v`是一个内部节点，它的子节点可以形成单独的组，也可以以在父节点的子树中不重叠的所有方式组合。 对于每个节点，DP 应该存储在其子树中划分叶子的方式数量，其中节点本身要么包含在某个组中，要么不包含在某个组中。 这自然会转化为乘法公式：如果内部节点有多个子节点，则该节点的有效分区数是子节点的乘积（将子子树作为单独组包含的方式数量加上在此节点将其合并为更大组的方式数量）。 通过从叶到根递归计算，我们覆盖了所有有效分区，而无需显式枚举它们。

 | ---| ---| ---| ---|
 | 蛮力 | O(贝尔(k) * n) | O(n + k) | 太慢了 |
 | 树上的DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 从父列表构造树。 对于每个节点，维护其子节点的列表。 这使我们能够自下而上地导航树以进行动态编程。 
2. 定义递归函数`dfs(v)`返回以节点为根的子树中叶子分区的方式数`v`。 如果`v`是叶子，返回1，因为单个叶子只能形成单个组。 
3. 对于内部节点，迭代每个子节点`c`并递归计算`dfs(c)`。 维持一个倍增的运行产品`(dfs(c) + 1)`对于每个孩子。 这`+1`考虑到不将子级的叶子隔离为单独组的选项，而是有效地将它们合并到父级组中。 
4. 计算所有子项的乘积后，减去 1 以排除所有子项都合并为空的选项，这对应于空的叶子集。 结果就是节点下叶子的有效分区数`v`。 
5. 返回结果`dfs(1)`以 998244353 为模。 

为什么它起作用：在每个节点上，我们本质上是为每个子节点选择是让其叶子形成自己的组还是将它们合并到包含父节点的更大组中。 乘法原理确保我们对所有组合进行计数，并且减 1 会删除无效的空组合。 由于我们只遍历树一次并在每个节点的恒定时间内合并子结果，因此该算法既正确又高效。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

MOD = 998244353

def solve():
    n = int(input())
    parents = list(map(int, input().split()))
    tree = [[] for _ in range(n + 1)]
    for i, p in enumerate(parents, start=2):
        tree[p].append(i)

    def dfs(v):
        if not tree[v]:  # leaf
            return 1
        res = 1
        for c in tree[v]:
            res = res * (dfs(c) + 1) % MOD
        return (res - 1) % MOD

    print(dfs(1))

if __name__ == "__main__":
    solve()
```第一部分根据父数组构造树的邻接表。 这`dfs`函数检查节点是否是叶子并在这种情况下返回 1。 对于内部节点，我们乘以`(dfs(c) + 1)`超过所有儿童`c`并在最后减1以避免计算空组合。 模运算确保我们尊重问题的约束。 我们增加了递归限制，因为深树可能会超过 Python 的默认递归深度。
