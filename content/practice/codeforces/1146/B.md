 ## 解决方案
 ## 问题理解

 我们得到了 Bob 经过非常具体的构建过程后生成的最终字符串。 鲍勃最初有一些隐藏的字符串`s`。 从这个字符串中，他删除了每个字符串，形成了第二个字符串`'a'`字符，同时保持其余字符的顺序。 然后他连接原始字符串`s`使用这个过滤后的版本，生成最终的字符串`t`。 

所以`t`由两部分组成：第一部分是一些未知的字符串`s`，第二部分是`s`与所有`'a'`字符被删除。 

任务是重建任何有效的原始字符串`s`可以产生`t`。 如果不存在这样的字符串，我们必须报告失败。 

约束条件`|t| ≤ 100000`意味着任何解在字符串的长度上都必须是线性的或接近线性的。 任何二次的，例如尝试所有分割点并通过重新计算过滤后的字符串来验证每个候选点，都会太慢，因为它可能需要以下顺序：$10^{10}$最坏情况下的操作。 

一个微妙的问题是由于两者之间如何划分的模糊性而产生的。`s`和`s'`已确定。 如果我们错误地猜测了分割，我们可能会接受规则实际上无法生成的字符串。 另一个边缘情况是当`s`不包含`'a'`根本没有字符。 在这种情况下`s' = s`，所以最终的字符串变成`t = ss`，完美的复制。 许多简单的解决方案都因未正确处理这种对称性而失败。 

当后半段出现另一个极端情况时`t`包含只能来自删除的字符`'a'`字符，但前半部分的结构与该删除模式不一致。 这种不匹配是算法必须检测到的。 

## 方法

 暴力方法会尝试每一个可能的分割位置`i`在字符串中`t`, 治疗`t[:i]`作为候选人`s`并验证是否连接`s`和`s`减`'a'`产生`t`。 对于每个分割，构建`s'`需要 O(n)，并且与后缀进行比较也需要 O(n)，导致每次拆分的时间为 O(n²)，在简单的实现中总共需要 O(n³)。 和`n = 10^5`，这是不可能的。 

关键的观察结果是`t`强烈限制分裂必须发生的地方。 第二部分`t`正是`s`与所有`'a'`已删除，因此它不包含`'a'`字符并保留所有其他字符的相对顺序。 这意味着后缀`t`不能包含`'a'`根本没有，并且必须匹配前缀的过滤版本。 

我们不是随意猜测，而是颠倒构造逻辑。 假设我们选择一个候选前缀`s = t[:i]`。 我们可以确定性地计算什么`s'`必须通过删除所有`'a'`字符来自`s`，然后检查是否`t[i:]`完全匹配。 由于后缀长度取决于非后缀的数量`'a'`字符，可以通过仅尝试长度一致的位置来找到正确的分割。 

这将问题简化为线性扫描，我们在几个仔细确定的位置测试可行性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们重建`s`通过以受控方式迭代可能的分割点。 

1. 计算非的数量`'a'`整个字符串中的字符`t`。 该值决定了过滤部分的大小`s'`必须是。 自从`s'`等于`s`与所有`'a'`删除后，其长度必须等于非`'a'`中的字符`s`，并且还必须匹配后缀长度`t`。 
2.让`k`是非的数量`'a'`中的字符`t`。 后缀`s'`必须完全由那些组成`k`字符按顺序排列，因此它必须与后缀对齐`t`长度`k`。 
3.设置候选分割位置`i = len(t) - k`。 这强制后缀`t`正好足够长来表示`s'`。 
4. 采取`s = t[:i]`作为候选原始字符串。 
5. 构建`s'`通过扫描`s`并删除每个`'a'`。 
6.比较这个生成的`s'`和`t[i:]`。 如果匹配，则返回`s`。 
7. 否则，不存在有效的重建。 

正确性来自于后缀完全由非`'a'`的结构`s`。 一旦我们确定了有多少非`'a'`字符存在时，分割位置就固定，消除了歧义。 

### 为什么它有效

 该算法依赖于一个结构不变量：后缀`t`必须恰好是`t`包括所有非`'a'`隐藏的人物`s`。 因为去除`'a'`保留顺序并仅删除一种字符类型，所有其他字符的相对顺序不变并完全保留在`s'`。 因此，任何有效的解决方案都必须对齐后缀`t`与非`'a'`前缀的投影。 如果此对齐失败，则没有替代拆分可以修复它，因为更改拆分会更改前缀和后缀长度，从而破坏所需的相等性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = input().strip()
    n = len(t)

    # count non-'a' characters in t
    k = sum(1 for c in t if c != 'a')

    # suffix must be exactly the non-'a' projection
    i = n - k
    if i < 0:
        print(":(")
        return

    s = t[:i]
    expected = []

    for c in s:
        if c != 'a':
            expected.append(c)

    if "".join(expected) == t[i:]:
        print(s)
    else:
        print(":(")

if __name__ == "__main__":
    solve()
```代码首先测量有多少个字符`t`将生存`'a'`移动。 这决定了后缀必须有多长。 然后它相应地修复分割点。 

过滤步骤明确地重建`s'`从候选前缀中提取并将其与后缀进行比较。 这可以避免猜测并确保正确性，即使字符重复或`s`不包含`'a'`。 

唯一微妙的地方是计算`i = n - k`。 这是有效的，因为后缀必须完全包含所有非`'a'`字符，其计数全局固定为`t`。

 输入：```

```这里`k = 8`，因为有 8 个非`'a'`人物。 所以`i = 12 - 8 = 4`。 

| 步骤| 前缀`s`| 已过滤`s'`| 后缀`t[i:]`|
 | ---| ---| ---| ---|

 过滤后的前缀与后缀不匹配，因此本次分割无效。 尝试其他分割将违反固定长度约束，因此该特定字符串不存在有效的重建。 

这演示了不匹配的排序如何立即破坏有效性。

 ## 边缘情况

 一种边缘情况是字符串完全由以下内容组成`'a'`。 算法集`k = 0`，因此分割点成为完整的字符串。 过滤后的前缀为空并与后缀匹配，产生正确的输出。 

另一种情况是当没有`'a'`根本没有字符。 然后`s' = s`， 所以`t`必须完全是`ss`。 该算法通过要求相等的前缀和后缀长度来自动强制执行此操作，并且仅当字符串完全重复时才会成功。 

第三种情况是当非`'a'`字符交错`'a'`以打破对齐的方式。 例如，如果后缀需要一个无法通过简单删除来获得的字母序列`'a'`从任何前缀开始，在比较重构时相等性检查立即失败`s'`后缀，防止错误接受。
