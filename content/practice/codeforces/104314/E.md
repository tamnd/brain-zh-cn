 ## 解决方案
 ## 问题理解

 我们有一个代表群岛的网格。 每个单元格要么是陆地，标记为`1`，或水，标记为`0`。 任何两个上、下、左、右接触的陆地单元都属于同一个岛屿，因此网格自然地分裂成多个连接的组件`1`s。 

任务是通过将一些水细胞变成陆地，将所有岛屿连接成一个陆地。 每个操作恰好翻转一个`0`进入`1`。 目标是确定此类翻转的最小次数，以便在所有变化之后，整个网格中恰好存在一个连接的土地组成部分。 

关键是我们不允许移动土地或任意形状地添加桥梁，只能将水单元转化为土地，并且连通性严格是四向的。 

这些约束意味着单元总数最多为 10^6。 这排除了比大约 O(nm log nm) 或二次行为更糟糕的情况。 对网格进行线性扫描是可行的，但必须仔细控制来自多个源的重复 BFS 或洪水填充，以便每个单元仅处理恒定次数。 

当试图在不认识全球结构的情况下直接贪婪地“种植”岛屿时，就会产生一种天真的误解。 例如，考虑棋盘图案：```
101
010
101
```每个`1`是孤立的，所以每个细胞都是自己的岛屿。 一种幼稚的方法可能会尝试在本地连接附近的岛屿，但没有意识到所有岛屿都需要成为一个连接的组件，并且中间的水单元可能服务于多个连接。 

当岛屿几乎已连接（除了狭窄的对角线间隙）时，会出现另一种边缘情况：```
100
000
001
```这里最短的连接需要仔细选择中间路径，而不是贪婪地连接最近的端点。 

核心困难是认识到问题是要求在 4 向运动下连接网格图中的多个组件所需的最少翻转次数，这表明最短路径或多源扩展结构而不是独立的成对连接。 

## 方法

 一个蛮力的想法是考虑每对岛屿并计算连接它们必须转换的最小水单元数量。 如果有 K 个岛屿，这会导致 K^2 对，对于每对，我们将计算通过水单元的最短路径，每次都有效地在网格上进行 BFS。 由于每个 BFS 的成本为 O(nm)，因此变为 O(K^2 nm)，即使 K 适中，这也远远超出了限制。 

即使我们尝试通过独立运行每个岛的 BFS 来改进它，我们仍然最终会在同一网格结构上重复重新计算重叠的工作。 

关键的观察是，连接所有岛屿相当于同时从所有岛屿逐渐向外扩展土地。 如果我们对待所有`1`将水细胞作为多源 BFS 中的初始源，然后为每个水细胞分配一个距离，该距离等于到达陆地所需的最小翻转次数。 然而，这仅给出了到最近岛屿的距离，而不是所有岛屿的完整连接。 

为了实现全面连通，我们将问题重新解释为找到使不同岛屿的扩张相交所需的最少水层数。 换句话说，我们想要从不同岛屿出发的两个 BFS 波首次相交的最小距离。 这相当于计算任意两个组件之间的最短桥。 

一种更直接、更简单的观点是认识到任何最终相连的陆地都必须包括至少一个连接所有岛屿的跨越结构。 连接网格中组件的最便宜方法（水膨胀的每一步成本为 1）是将其视为多源最短路径，其中每个岛同时膨胀，并且我们跟踪来自不同源的膨胀何时发生冲突。 

这导致了两阶段 BFS 方法：首先标记岛屿，然后运行多源 BFS，其中每个岛屿在其边界处向外扩展，距离为 0，然后我们检测不同岛屿前沿之间的第一个交汇点。 该相遇距离对应于所需的最少翻转次数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力成对 BFS | O(K^2·纳米) | O(纳米) | 太慢了 |
 | 来自所有岛屿的多源 BFS | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1. 首先扫描网格并识别出所有连通分量`1`使用 BFS 或 DFS。 每个组件都分配有一个唯一的岛屿标识符。 这一步确保我们可以区分每个陆地单元属于哪个扩张波。 
2. 收集所有岛屿的所有边界单元。 边界单元是具有至少一个相邻水单元的陆地单元。 这些是唯一可以影响向水中膨胀的细胞。 
3. 初始化一个包含所有边界陆地单元的多源 BFS 队列，每个边界单元都标有其岛屿 ID 和距离 0。我们还维护一个距离网格，对于水，初始化为 -1，对于陆地，初始化为 0。 
4. 在网格上执行 BFS。 对于每个弹出的单元格，我们尝试扩展到其四个邻居。 如果邻居是水，我们给它分配当前的岛id和距离+1，然后将其推入队列。 
5. 如果我们遇到一个已经访问过但从不同岛屿 ID 到达的邻居，我们就发现了两个扩展波之间的碰撞。 答案是两侧距离的总和，这对应于连接岛屿所需的水单元的数量。 
6. 返回 BFS 期间遇到的最小此类碰撞值。 

原因是 BFS 按翻转次数的递增顺序扩展。 两个不同的岛屿前沿第一次相遇时，我们就找到了全局最佳连接。 

### 为什么它有效

 每个水单元都被分配了距任何岛屿边界的最小距离，但更重要的是，BFS 确保膨胀以递增的翻转顺序进行。 当两个不同的岛屿标签在一个单元格处或跨越边缘相​​遇时，组合距离反映了连接这两个岛屿的水中的最短路径。 由于 BFS 首先探索所有最短扩展，因此第一次碰撞必须在所有可能的岛间连接中是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    grid = [list(input().strip()) for _ in range(n)]

    dirs = [(1,0),(-1,0),(0,1),(0,-1)]

    comp = [[-1]*m for _ in range(n)]
    cid = 0

    # 1. label islands
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '1' and comp[i][j] == -1:
                q = deque([(i,j)])
                comp[i][j] = cid
                while q:
                    x, y = q.popleft()
                    for dx, dy in dirs:
                        nx, ny = x+dx, y+dy
                        if 0 <= nx < n and 0 <= ny < m:
                            if grid[nx][ny] == '1' and comp[nx][ny] == -1:
                                comp[nx][ny] = cid
                                q.append((nx, ny))
                cid += 1

    # 2. multi-source BFS from all land
    dist = [[-1]*m for _ in range(n)]
    owner = [[-1]*m for _ in range(n)]
    q = deque()

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '1':
                dist[i][j] = 0
                owner[i][j] = comp[i][j]
                q.append((i,j))

    ans = float('inf')

    while q:
        x, y = q.popleft()
        for dx, dy in dirs:
            nx, ny = x+dx, y+dy
            if 0 <= nx < n and 0 <= ny < m:
                if dist[nx][ny] == -1:
                    dist[nx][ny] = dist[x][y] + 1
                    owner[nx][ny] = owner[x][y]
                    q.append((nx, ny))
                else:
                    if owner[nx][ny] != owner[x][y]:
                        ans = min(ans, dist[nx][ny] + dist[x][y])

    print(ans)

if __name__ == "__main__":
    solve()
```第一阶段为每个岛分配一个稳定的身份，以便以后的 BFS 扩展可以检测两个不同岛何时相遇。 如果没有这个标签，我们就会错误地合并来自同一岛屿的扩展。 

第二阶段将所有陆地单元视为同时 BFS 源。 每个水单元都被分配了从某个岛屿到达它的最小距离。 关键的实现细节是我们存储距离和起源岛 ID，使我们能够检测不同来源之间的冲突。 

答案更新使用`dist[nx][ny] + dist[x][y]`，它对应于两个扩展前沿在一条边上相遇的距离之和。 这是寻找两个多源区域之间最短路径的离散模拟。 

## 工作示例

 ### 示例 1

 输入：```
3 3
101
010
101
```我们从四个岛屿开始，每个角落`1`是它自己的组件。 

| 步骤| 细胞| 距离 | 业主| 行动|
 | ---| ---| ---| ---| ---|
 | 1 | (0,0) | (0,0) | 0 | 一个 | 启动 BFS |
 | 2 | (0,2) | 0 | 乙| 启动 BFS |
 | 3 | (2,0) | 0 | C | 启动 BFS |
 | 4 | (2,2) | 0 | d | 启动 BFS |
 | 5 | (1,1) | 1 | 一个 | 第一个水到达|

 当 BFS 扩展时，以相同的成本从多个方向到达中心单元。 不同所有者之间的第一次碰撞发生在距离 1 处，因此答案为 1。 

这证实了对角对称并不重要，重要的是曼哈顿通过水的最短扩张。

| 步骤| 细胞| 距离 | 业主| 行动|

这表明，即使存在多条最短路径，BFS 也能保证最早的相遇对应于最优桥。

 ## 边缘情况

 一种微妙的情况是，标记后岛屿已经连接，但 BFS 仍在运行。 例如：```
3 3
111
111
111
```这里实际上只有一个岛屿。 BFS 永远不会发现不同所有者之间的冲突，因此答案将保持无限。 正确的实现必须要么防止这种情况，要么依赖于至少有两个岛屿的保证。 

另一种情况是狭窄的走廊：```
1 5
10001
```BFS从两端对称扩展。 在中心单元，两个波在总共 2 步后相遇，给出答案 3。该算法正确地考虑了两侧的距离，而不仅仅是一侧的距离。 

最后的边缘情况是多个岛屿在同一 BFS 级别的同一水单元中相遇。 该算法自然地处理这个问题，因为所有权是按单元跟踪的，任何不同的所有者都会触发有效的候选答案，确保不会错过最佳连接。
