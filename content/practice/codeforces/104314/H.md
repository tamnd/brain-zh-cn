 ## 解决方案
 ## 问题理解

 我们得到一小组卡片，每张卡片显示一对整数。 其中一张卡是秘密的“奖品”卡。 第一个玩家只能看到该牌左边的数字，第二个玩家只能看到右边的数字。 根据这些片面的观点和他们交换的公开推理，他们最终准确地推断出哪张卡是奖品。 

对话不是装饰，它是整个约束系统。 每一个陈述都消除了不可能的候选卡。 我们的任务是对这个消除过程进行逆向工程，并确定哪张卡仍然能够始终在所有扣除中幸存下来。 

关键的困难在于，每个玩家不仅要推理自己的信息，还要推理其他玩家能够或不能推断出的信息，甚至推理出其他玩家知道自己知道的信息。 

约束很小，最多 100 张卡片，值最多 100。这立即告诉我们，任何解决方案都可以自由地多次模拟所有卡片的推理。 三次甚至适度嵌套的二次推理过程是可以接受的，但是任何需要对子集进行指数搜索的过程都是不必要的。 

微妙的边缘情况来自重复的值。 多张卡可以共享相同的左侧号码或相同的右侧号码。 这很重要，因为两个玩家的知识取决于有多少候选者与给定的观察到的数字保持一致。 独立处理对而不考虑频率影响的幼稚方法将会失败。 

例如，如果一个正确的数字在所有牌中只出现一次，那么任何看到它的玩家都会立即知道该牌。 如果它出现多次，则玩家不会出现。 对于左边的数字也是如此。 对话的整个逻辑取决于这些基于频率的消除与其他玩家可以推断出的高阶推理相结合。 

## 方法

 暴力解释将尝试每张牌作为潜在的奖品，并从头开始模拟完整的对话。 对于每张候选卡，我们都会反复重新计算每个玩家所知道的信息、他们可以推断出的关于对方的信息以及陈述的顺序是否一致。 这很快就会变得昂贵，因为每次模拟本身都需要重复扫描所有卡片并重复过滤候选集。 在最坏的情况下，这种直接模拟会在每个逻辑步骤的 N 张卡上引入多次嵌套传递，从而导致高常数因子和不必要的复杂性。 

关键的观察是对话是单调消除的。 每条声明都会删除与迄今为止已建立的内容不一致的卡牌。 我们可以逐步计算全局过滤器，而不是动态模拟每个候选者的知识。 

首先，我们确定哪些牌与第一个玩家兼容，第一个玩家能够自信地断言第二个玩家不知道奖品，同时自己也不知道。 这转化为对整个集合中左右值的频率的结构约束。 

修剪之后，我们通过检查哪些正确值在剩余的可能性中唯一地标识一张牌来模拟第二个玩家的反应。 这产生了第二个缩减集。 

最后，我们模拟第一个玩家更新的知识，并确保只有一个候选者与所有推论保持一致。 

这将大量推理的对话转变为一系列卡片上的确定性过滤步骤。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每个候选人的暴力破解模拟 | O(N3) | O(N) | 实践太慢|
 | 全局迭代过滤 | O(N²) | O(N) | 已接受 |

 ## 算法演练

 ### 第 1 步：构建频率表

我们计算每个左值和每个右值在所有卡片上出现的次数。 这些频率代表了每个数字单独提供的信息量。 

仅出现一次的数字可以立即识别，而重复的数字会产生歧义。 

### 第 2 步：识别与第一个玩家的确定性一致的牌

 我们首先确定哪些牌可以在以下陈述中幸存下来：“我知道你不知道奖品卡，我也不知道。”

 仅当满足以下两个条件时，卡片才会被保留：

 1. 它的左值在所有牌中至少出现两次，否则第一个玩家会立即知道该牌。 
2. 对于每张共享其左值的牌，其对应的右值必须在所有牌中至少出现两次。 这确保了第二位玩家无法从正确的数字中唯一地识别奖品。 

我们将满足这些条件的所有牌收集到一组 V 中。 

### 第三步：模拟第二个玩家的扣分

 现在我们假设第一个语句已经做出，所以只有 V 仍然是可能的。 

对于 V 中卡片中的每个正确值，我们计算 V 中有多少张卡片具有该正确值。 

第二位玩家说他们现在知道奖品卡了。 这意味着对于真正的奖品卡，其正确的值必须在 V 中恰好出现一次，否则就会存在歧义。 

我们将 V 过滤到一个新的集合 V2 中，其中仅包含其正确值在 V 中只出现一次的卡片。 

### 第四步：模拟第一个玩家的最终扣除

 在听到第二位玩家的声音后，第一位玩家也得出结论，奖品是已知的。 这意味着在 V2 中，只有一张卡可以共享正确的左侧一致性。 

我们计算 V2 内左值的计数，并仅保留左值在 V2 中恰好出现一次的卡片。 

### 步骤 5：输出

 剩下的单张卡就是奖品。 

### 为什么它有效

 每个步骤都对应于对话所隐含的逻辑必要条件。 有效的奖品卡不得违反对话中的任何声明。 每个过滤步骤都会准确地删除那些与至少一个发言者的确定性相矛盾的卡片。 由于真正的奖品必须同时满足所有陈述，因此它必须能够通过每个过滤器。 最后一步保证了唯一性，因为最后一个语句断言了完全标识。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    cards = []
    
    left_freq = {}
    right_freq = {}

    for _ in range(n):
        a, b = map(int, input().split())
        cards.append((a, b))
        left_freq[a] = left_freq.get(a, 0) + 1
        right_freq[b] = right_freq.get(b, 0) + 1

    # Step 1: filter by first player's statement
    valid = []
    for a, b in cards:
        if left_freq[a] >= 2 and right_freq[b] >= 2:
            valid.append((a, b))

    # Step 2: simulate second player's knowledge in valid set
    right_count = {}
    for a, b in valid:
        right_count[b] = right_count.get(b, 0) + 1

    valid2 = []
    for a, b in valid:
        if right_count[b] == 1:
            valid2.append((a, b))

    # Step 3: simulate first player's final deduction
    left_count = {}
    for a, b in valid2:
        left_count[a] = left_count.get(a, 0) + 1

    final = None
    for a, b in valid2:
        if left_count[a] == 1:
            final = (a, b)

    print(final[0], final[1])

if __name__ == "__main__":
    solve()
```第一个预处理步骤构建频率表，以便我们可以评估每张卡片的全局模糊度。 这可以避免以后重复重新计算计数。 

第一个过滤阶段强制执行第一个玩家对自己的无知和其他玩家的无知的确定所隐含的约束。 这会尽早排除结构上不可能的候选者。 

第二阶段重新计算缩减集内的频率，因为第二个玩家的扣除发生在第一个消除步骤之后，因此必须在更新的宇宙中对其进行评估。 

最后阶段从第一个玩家的更新角度强制执行唯一性，确保只有一张牌与所有陈述保持一致。

 过滤后，仅`(6, 3)`在所有阶段都保持一致，所以这就是答案。 

这表明，在任何特定于对话的推理之前，早期的全局模糊性约束已经消除了大多数候选者。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    from collections import defaultdict

    input = _sys.stdin.readline

    n = int(input())
    cards = []
    lf = {}
    rf = {}

    for _ in range(n):
        a, b = map(int, input().split())
        cards.append((a, b))
        lf[a] = lf.get(a, 0) + 1
        rf[b] = rf.get(b, 0) + 1

    valid = [(a,b) for a,b in cards if lf[a] >= 2 and rf[b] >= 2]

    rc = {}
    for a,b in valid:
        rc[b] = rc.get(b, 0) + 1
    v2 = [(a,b) for a,b in valid if rc[b] == 1]

    lc = {}
    for a,b in v2:
        lc[a] = lc.get(a, 0) + 1

    ans = [(a,b) for a,b in v2 if lc[a] == 1][0]
    return f"{ans[0]} {ans[1]}\n"
