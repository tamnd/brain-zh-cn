 ## 解决方案
 ## 问题理解

 我们得到了一条长条$m$，最初都涂有颜色$0$。 然后是颜色$1$通过$n$一一应用。 每种颜色$i$通过选择一个段来应用$[a_i, b_i)$当前是单色的，并用颜色重新绘制它$i$。 

最后，每个单元段$[j-1, j)$有固定的最终颜色$c_j$，其中每个$c_j$是在$[1, n]$。 每种颜色$1 \dots n$在最终配置中至少出现一次。 

任务是统计有多少个有效的段操作序列$(a_i, b_i)$可以准确地生产出最终的彩色条带。 

关键的困难在于，每个重绘操作都必须作用于在绘画时完全是一种颜色的片段，因此早期的操作以嵌套和高度结构化的方式约束所有后续的操作。 

这些限制以非常具体的方式发挥作用。 条带长度$m$取决于$10^6$，因此任何对每个位置进行二次转换的解决方案$m$是不可能的。 不过颜色数量很少，$n \le 500$，这表明只要我们避免迭代每个转换的所有位置，任何对颜色或结构间隔的动态编程都是可行的。 

一个微妙的问题是，相同的最终着色可以由许多不明显独立的不同区间历史产生。 例如，即使是简单的交替模式，例如$1,2,1$，可能的第一个颜色绘制段$1$改变颜色的可能性$2$，因为中间单色约束取决于先前绘制的块。 

一个天真的错误是认为每种颜色都对应于它的最终连续段。 这会立即失败，因为由于稍后重新着色，一种颜色可能会被绘制在多个不相交的最终块中。 另一个错误是假设每个颜色区间必须覆盖其整个最终出现范围； 实际上，早期的操作可能会以最终状态中不可见的方式暂时合并或分割区域。 

## 方法

 暴力视图会尝试向后模拟该过程或枚举每种颜色的所有可能间隔。 对于每种颜色$i$，我们将选择一个当前为单色的有效段，并递归地继续。 即使我们修剪无效状态，可能的段选择数量也是巨大的：每种颜色都可能应用于$O(m^2)$段，并且有$n$颜色，提供远远超出任何可行限制的搜索空间。 

关键的结构洞察力是反转视角。 我们不考虑向前绘制，而是询问最终数组中必须存在什么结构才能存在有效的重绘操作序列。 

当颜色$i$应用时，它会绘制当时为单色的连续片段。 在最终配置中，这意味着颜色所在的区域$i$最后应用形成一个部分，其内部完全由后来绘制的较高指数的颜色“主导”。 这创建了一个嵌套结构：每种颜色的最后一个应用的行为就像一个间隔，对早期的颜色进行分区和细化。 

这导致了经典的区间 DP 解释。 我们将问题压缩为考虑最终数组的片段并计算有多少有效的“构造历史”产生该片段。 转换取决于选择与影响区域的最后操作相对应的分割点。 

关键的观察是对于任何细分市场$[l, r]$，里面最后涂的颜色一定是某种颜色$x$出现在该段中的操作以及绘制的操作$x$必须恰好覆盖了一个子段，其中$x$成为主要的“最后涂漆”颜色。 一旦我们修复了这个枢轴，左右部分就成为独立的子问题。 

这将问题转化为区间上的 DP，但直接区间上的 DP$[l, r]$是$O(m^2)$，太大了。 第二个关键优化是过渡仅取决于颜色变化的边界，因此我们可以使用最近的出现来压缩过渡并维护每个位置而不是每个间隔的 DP 状态。 

最终的优化解决方案简化为结构化 DP，其中每个位置充当边界，并且过渡累积由相同颜色的出现引起的有效分割的贡献。

 ## 算法演练

 我们根据最终数组的间隔定义DP，但以压缩的方式计算它。 

1.我们对每种颜色的位置进行预处理。 对于每种颜色，我们知道它出现的所有索引。 这使我们能够推断出与上次绘制颜色相对应的有效片段。 
2. 我们定义$dp[l][r]$作为完全构造该段的方法的数量$[l, r]$。 自从$m$很大，我们从来没有明确地建立所有这样的状态； 相反，我们使用增量结构计算每个右端点的转换。 
3.我们迭代端点$r$从左到右。 对于每个$r$，我们考虑所有可能的左边界$l$有效的最后一个操作可能结束于$r$。 这些边界是由相同颜色的出现确定的$c_r$，因为只有那些可以作为最终重绘影响位置的锚点$r$。 
4.对于固定颜色$x = c_r$，我们保持之前出现的位置$x$。 每对连续出现定义一个段，其中最后一个操作涉及$x$可以开始和结束。 我们汇总所有此类有效选择的贡献。 
5. 我们维护前缀 DP 和，以便从$l$到$r$可以计算为$O(1)$，并且我们通过存储每种颜色的累积贡献来避免重新计算内部总和。 
6.我们为每个职位积累贡献$r$进入最终答案或进入向前传播的 DP 状态。 

该结构确保每个有效的绘画序列唯一对应于每个间隔的一个分解点，因此每个序列只被计数一次。 

### 为什么它有效

 每个有效序列都有一个明确定义的“最后操作”，影响任何给定的间隔$[l, r]$。 该操作必须对应于间隔内出现的颜色，并且其段边界必须与该颜色在应用时可以作为连续块存在的区域对齐。 通过修复最后一个操作，区间的其余部分成为不相交线段上的独立子问题。 这保证了DP对整个构造空间的划分没有重叠或遗漏。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, m = map(int, input().split())
    c = list(map(int, input().split()))

    # last occurrence tracking per color
    pos = [[] for _ in range(n + 1)]
    for i, x in enumerate(c):
        pos[x].append(i)

    # dp[i]: number of ways to finish at position i
    dp = [0] * (m + 1)
    dp[0] = 1

    # prefix sum of dp
    pref = [0] * (m + 2)
    pref[0] = 1

    # last occurrence pointer per color
    ptr = [0] * (n + 1)

    for r in range(1, m + 1):
        col = c[r - 1]

        # advance pointer
        ptr[col] += 1

        # basic contribution: extend from previous position
        dp[r] = dp[r - 1]

        # additional contributions from same color structure
        # (compressed transitions over occurrences)
        for i in range(ptr[col]):
            l = pos[col][i] + 1
            dp[r] = (dp[r] + pref[r - 1] - pref[l - 1]) % MOD

        pref[r] = (pref[r - 1] + dp[r]) % MOD

    print(dp[m] % MOD)

if __name__ == "__main__":
    solve()
```该代码在片段的前缀上维护 DP。 数组`dp[r]`表示在位置“结束”的有效结构的数量`r`，解释为已经完全解决了该点的结构。 前缀和数组`pref`允许快速聚合范围内的贡献，而无需重复重新计算总和。 

颜色先前出现的循环是编码关键约束的内容，即有效的重绘段必须与最终配置中的单色结构对齐。 每个出现边界定义了一个潜在的分段分割，其中可以应用该颜色的最后一次重绘。 

使用前缀和的减法确保我们只计算完全位于有效子段内的配置。

 ## 边缘情况

 一个关键的边缘情况是所有位置共享相同的颜色。 在这种情况下，每个重绘操作都必须嵌套在同一区域上，因此有效序列的数量根据选择嵌套间隔的方式数量而增长。 该算法通过对相同颜色出现的重复前缀积累来处理这个问题，确保所有分割点都被计算在内。 

另一个边缘情况是严格交替，例如$1,2,1,2,\dots$，其中每种颜色重复出现多次。 在这里，每次出现都会创建一个新的有效段边界，并且 DP 必须累积所有这些出现的贡献，而不仅仅是最后一次出现的贡献。 基于前缀的聚合确保这些多重结构分解不会崩溃。 

最后一种边缘情况是颜色出现在高度聚集的块中。 即使一种颜色出现在一个连续的块中，较早出现的颜色仍然会影响可以形成多少个有效的重绘间隔，并且 DP 正确地计算多个嵌套间隔历史记录，而不是将它们折叠为单个选择。
