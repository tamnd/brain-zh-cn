 ## 解决方案
 ## 问题理解

 我们得到一系列点，每个点最多有 10 个坐标。 我们必须将此序列切割成几个连续的块。 每个点都属于一个块。 

对于任何块，其成本定义为该块内任意两点之间的最大 L1 距离。 分区的总分是块成本的总和，我们希望最大化这个总和。 

因此，该结构是一个经典的“将数组拆分为段”问题，但段值不是像 sum 或 max 这样的简单范围统计。 相反，它取决于曼哈顿距离下最多 10 个维度的几何直径。 

输入的大小迫使我们形成非常具体的思维方式。 当 n 达到 100000 时，任何尝试显式考虑所有 O(n^2) 段边界的解决方案都是不可能的。 即使每个段为 O(n log n) 也太慢了，因为我们可能需要 O(n) 段。 维度 m 很小，最多 10，这是我们可以利用的唯一结构弱点。 这强烈表明 m 中的指数行为是可以接受的，而 n 中的任何二次行为则不可接受。 

一个微妙的困难是，细分成本不是单调的或累加的。 向线段添加新点可以极大地增加直径，并且实现直径的点对的身份取决于整个集合。 这使得贪婪分裂变得不可靠。 

当人们假设段的成本仅由原始空间中的端点决定时，就会出现天真的错误。 例如，在一维中，这是可行的，因为成本只是最大值减去最小值。 但在更高维度中，实现最大 L1 距离的对不一定以跨维度一致的方式处于坐标极端，因此基于端点的推理会立即中断。 

另一种失败模式来自于试图增量地维持段成本，并在成本超过某个阈值时贪婪地削减。 由于不同细分市场的成本通过动态规划相互作用，局部决策无法扩展到全局最优。 

## 方法

 暴力策略会尝试所有可能的分区。 有 2^(n-1) 种分割方式，对于每个线段，我们通过检查其内部的所有点对来计算其直径。 这已经为每个分区提供了 O(n^2)，导致指数爆炸远远超出了可行性。 

更结构化的暴力 DP 将 dp[i] 视为前缀 i 的最佳答案，并尝试每个先前的切割位置 j。 对于每个 (j, i)，我们计算段 j+1..i 的成本。 这将问题简化为 O(n^2) 段，但天真地计算每个段成本为 O(nm)，给出 O(n^3 m)，这仍然太大了。 

关键的观察是曼哈顿距离在固定维度中的表现。 两点 A 和 B 之间的 L1 距离可以重写为线性投影的符号图案上的最大值。 对于 {+1, -1}^m 中的符号向量 s，定义变换值 v_s(x) = sum s_k x_k。 那么L1距离成为|v_s(A) - v_s(B)|的s范围内的最大值。 这意味着 L1 下的集合的直径是 2^m 线性一维范围内的最大值：对于每个符号模式，我们在该段上取 max v_s 减去 min v_s 。 

这将几何问题简化为多个一维范围问题。 现在，段的成本是最多 1024 个预测（最大值减去最小值）的最大值。 

这种结构使我们能够在扫描段时维护每个符号模式的运行最大值和最小值，并有效地评估段成本。 剩下的困难是将其集成到段端点上的 DP 中，同时保持总复杂度约为 O(n * 2^m)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力分区+配对检查 | 指数| O(1) | O(1) | 太慢了|
 | 具有朴素段重新计算的 DP | O(n^3 m) | O(n) | 太慢了|
 | DP 与 L1 投影技巧 | O(n·2^m) | O(n·2^m) | O(n·2^m) | O(n·2^m) | 已接受 |

## 算法演练

 我们将每个点转换为 2^m 个转换值，每个符号模式一个。 这是核心还原步骤。 

## 算法演练

 1. 对于 [0, 2^m) 中的每个点 i 和每个符号模式 s，计算 v[i][s]，即坐标的符号和。 这让我们可以使用一维差异来评估 L1 距离。 目的是用多个标量范围问题代替向量距离问题。 
2. 将 dp[i] 定义为使用前 i 点可获得的最大分数。 我们从左到右逐步构建它。 
3. 为了计算 dp[i]，我们尝试每一个可能的最后切割位置 j，这意味着最后一段是 j+1 到 i。 这给出 dp[i] = max over j of dp[j] + cost(j+1, i)。 该结构是正确的，因为任何最佳分区都必须以某个最终段结束。 
4. 对于固定的 i 和 j，我们为每个符号模式 s 维护窗口 j+1..i 上 v[*][s] 的最小值和最大值。 我们在将 j 从 i 向后移动到 1 的同时更新这些。这允许每个符号模式每步进行恒定时间更新。 
5. 对于每个 j，我们通过扫描所有符号模式并取最大值（当前最大值减去当前最小值）来计算段 j+1..i 的成本。 这会产生该段的精确 L1 直径。 
6. 我们取所有j中最好的一个来获得dp[i]，并继续。 

这样做的原因是 L1 直径分解确保每个段成本都由 2^m 投影之一完全捕获。 每个投影的行为都类似于一维范围，其中极值可以随着我们扩展或缩小线段而增量更新。 DP 枚举所有有效的最后一段，并且投影技巧确保准确计算每个段的成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = [list(map(int, input().split())) for _ in range(n)]

    P = 1 << m

    # precompute sign vectors
    sign = []
    for mask in range(P):
        s = []
        for j in range(m):
            if mask & (1 << j):
                s.append(1)
            else:
                s.append(-1)
        sign.append(s)

    # transform points
    v = [[0] * P for _ in range(n)]
    for i in range(n):
        for mask in range(P):
            s = sign[mask]
            val = 0
            for j in range(m):
                val += s[j] * a[i][j]
            v[i][mask] = val

    INF = 10**30
    dp = [-INF] * (n + 1)
    dp[0] = 0

    for i in range(1, n + 1):
        maxv = [-INF] * P
        minv = [INF] * P

        best = 0

        # extend left boundary j
        for j in range(i - 1, -1, -1):
            for s in range(P):
                x = v[j][s]
                if x > maxv[s]:
                    maxv[s] = x
                if x < minv[s]:
                    minv[s] = x

            # compute segment cost j..i-1
            cost = 0
            for s in range(P):
                diff = maxv[s] - minv[s]
                if diff > cost:
                    cost = diff

            best = max(best, dp[j] + cost)

        dp[i] = best

    print(dp[n])

if __name__ == "__main__":
    solve()
```该解决方案首先将每个点压缩为所有 2^m 有符号投影，这是使曼哈顿距离可分解为独立标量极值的唯一方法。 

DP 循环固定右端点 i。 然后，它将左端点 j 向后移动，更新每个投影的 min 和 max 数组。 这种增量维护避免了从头开始重新计算段统计信息。 通过扫描所有投影，以 O(2^m) 每 j 重新计算分段成本。 

一个微妙的点是 dp[0] 被初始化为 0，允许第一个段从索引 1 开始。另一个是 maxv 和 minv 必须为每个 i 重置，因为每个 dp 转换都考虑一个新的右端点。 

## 工作示例

 ### 示例1（简化结构）

 考虑一个类似一维的小型情况，其中 m = 1，值为`[1, 3, 0, 1]`。 

对于每个 i，我们向左展开：

 | j | 段 | 分钟| 最大| 成本| dp[j] + 成本 | 最好的|
 | --- | --- | --- | --- | --- | --- | --- |
 | 3 | [1] | 1 | 1 | 0 | dp[3] | dp[3] | 0 |
 | 2 | [0,1]| 0 | 1 | 1 | dp[2]+1 | 1 |
 | 1 | [3,0,1]| 0 | 3 | 3 | dp[1]+3 | 3 |
 | 0 | [1,3,0,1] | 0 | 3 | 3 | dp[0]+3 | 3 |

 这显示了扩展 j 如何增量更新极值，以及 dp 如何累积最佳分割。 

### 示例2（多维投影思想）

 在 m = 2 中取两个点：(0,0)、(1,2)。 

符号模式为 (++)、(+-)、(-+)、(--)。 他们的预测：

 | 点| ++ | +- | -+ | --|
 | --- | --- | --- | --- | --- |
 | (0,0) | (0,0) | 0 | 0 | 0 | 0 |
 | (1,2) | 3 | -1 | 1 | -3 |

 对于该段，每个投影都会产生一个范围，最大范围为3，等于L1距离。 这证实了为什么扫描所有投影可以捕获真实直径。

 ## 边缘情况

 单个元素输入表明 DP 正确地允许长度为 1 的段，其成本为零，因为不存在对。 该算法初始化 dp[0] = 0 并且从不强制无效段，因此 dp[1] 正确变为 0。 

当所有点都相同时，每个投影的范围为零，因此每个段中的 maxv 等于 minv。 成本计算始终产生零，并且 DP 为所有状态累加零，与正确答案相匹配。 

对于严格增加的一维输入，每个段成本等于其跨度。 该算法正确评估所有可能的分割点，并确定最佳分割是单个段，因为分割减少了总跨度。
