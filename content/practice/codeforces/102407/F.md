 ## 解决方案
 ## 问题理解

 我们有一个非负值数组 a 1 ​ ,…,a n ​，每个观众一个值。 每位警察观看一个连续的区间 [l i ,r i ]。 该官员的注意力是其区间内当前值的总和，因此所有官员的总注意力是所有区间总和的总和。 

亚瑟可能会降低观众的价值观。 如果观众 j 减少了 d j ​，则 0≤d j ​ ≤a j ​，总减少量满足

 j=1 Σ n ​ d j ​ ≤k。 

目标是在这些减少后最大限度地减少所有官员的注意力总和。 

关键是要独立地观察一位观众。 假设观众 j 恰好属于 c j ​ 个警察区间。 将 a j 减一会使总注意力减少 c j ​，因为每一位 c j ​官员都会失去一个单位的注意力。 因此，亚瑟预算的每个单位都有不同的值，仅取决于 c j​。 

我们首先需要所有 c j​。 由于最多可以有 m=10 6 个间隔，因此向每个间隔的每个位置添加一个将过于昂贵。 差异数组使我们能够在恒定时间内处理每个间隔，并使用一个前缀和恢复所有覆盖计数。 

界限 n≤10 5 意味着 O(n 2 ) 方法已经太大了，具有多达 10 10 个基本操作。 军官的数量可以达到10 6，因此每个区间处理一次是合适的规模。 k值可以达到10 12 ，因此即使n很小时，每减少一个单位执行一次迭代的算法也是不可能的。 Python 还需要仔细的输入处理，因为读取和处理一百万个间隔占据了运行时间。 

有几种边界情况可能会悄无声息地破坏实现。 如果k=0，则什么都不能改变。 例如，```
1 1 0
5
1 1
```答案是 5。总是花费整个预算的解决方案会错误地尝试将值降低到允许的值以下。 

如果k超过所有a j​的总和，亚瑟可以将每个观众减少到零。 例如，```
2 1 100
3 4
1 2
```答案为 0，而不是负值。 头寸的减少幅度受其原始价值的限制。 

仅包含一个端点的区间也需要正确的差值数组边界。 为了```
2 1 1
5 7
2 2
```唯一被覆盖的位置是第二个位置，因此 k=1 的答案是 11。更新 r 而不是 r+1 处的差异数组，或者混合从零开始和从一开始的索引，也可能错误地使第一个位置也被覆盖。 

最后，一名观众可以由多名警官保护，而另一名观众则仅由一名警官保护。 为了```
3 2 5
4 4 4
1 3
2 2
```覆盖计数为 1,2,1。 亚瑟应该首先将所有四个可能的单位花在观众 2 上，因为那里的每个单位都会消除两个单位的总注意力。 简单地选择最大的 a j 或按原始顺序处理观众的策略无法实现实际目标。 

## 方法

 直接的蛮力策略可以一次考虑一个单位的 Arthur 预算。 对于每个单元，检查所有n个观众，找到一个当前覆盖计数最大且其值仍为正的观众，将其减一，然后重复。 这是正确的，因为从观众 j 移除的每个单元都会使目标精确地减少 c j ​，因此最佳可用单元始终是具有最大 c j ​的单元。 

问题是 k 可以是 10 12。即使找到最好的观众只需要 O(n)，该过程也可能需要

 O(nk)=O(10 17 )

 操作。 事实上，观众可以减少许多单位，这意味着没有理由在每个单位之后重新考虑相同的覆盖计数。 

解决这个问题的观察结果是，属于同一观众的所有单位都具有完全相同的值。 如果观众 j 的覆盖范围为 c j ​，则所有可用的 a j 单位都准确保存 c j ​。 因此，我们可以按覆盖范围计数而不是按单个单位对预算进行分组。 

计算完所有 c j ​后，通过减少 c j ​对观众进行排序。 亚瑟应该首先完全减少覆盖率最高的观众，然后继续下一个覆盖率值。 如果剩余预算落在一名观众的价值范围内，则仅删除该数量的单位。 这是与暴力方法相同的贪婪决策，但所有相同的决策都被压缩为一个操作。 

初始总注意力也可以直接写为

 j=1 Σ n ​ a j ​ c j ​ .

 如果我们将观众 j 减少 d j ​，则目标也会减少 d j ​ c j ​。 由于每个 d j 花费一个单位的预算并提供 c j 的收益，因此按降序获取收益是最佳的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(nk+m) | O(n) | 太慢了|
 | 最佳 | O(m+nlogn) | O(n) | 已接受 |

 ## 算法演练

 1. 创建差异数组`diff`长度为n+1。 对于每个警察间隔 [l,r]，在 l 处加 1，在 r+1 处减 1。 这表示间隔在 l 处开始贡献并在 r 之后立即停止贡献。 
2. 取前缀和`diff`。 在位置 j 处，结果值恰好是 c j ​，即观看观众 j 的警察数量。 
3. 计算初始总注意力为 Σa j ​ c j ​。 这相当于对每个官员的时间间隔求和，但在已知覆盖计数后可以在 O(n) 内完成。 
4. 将每个观众的覆盖范围 c j ​与其可用数量 a j ​配对，然后按覆盖范围降序对这些对进行排序。 从覆盖范围为 c j 的观众中移除的单位可以节省 c j 单位的注意力，因此较大的覆盖范围总是可以更好地利用预算。 
5. 遍历已排序的观众。 对于观众 j，删除

 x=min(a j ​ ,剩余 k ​ )

 单位。 从答案中减去 xc j ​，并从剩余预算中减去 x。 如果预算变为零，就停止。 

1. 打印结果总计。 如果预算大于所有观众价值的总和，则每个价值最终都会减少到零，所以答案自然会变成零。 

### 为什么它有效

 目标可以重写为 Σ j ​ a j ​ c j ​，其中 c j ​是包含位置 j 的区间数。 将观众 j 减少 1 会花费 Arthur 的一单位预算，并使目标恰好减少 c j ​。 因此，每个可用的减少单位都是一个具有值 c j​的独立项目，并且观众 j 恰好提供了 j 个这样的项目。 按价值降序排列这些项目可以最大化任何预算的总减少量，这完全相当于最小化最终注意力。 因此，贪心遍历会产生最优解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    a = list(map(int, input().split()))

    diff = [0] * (n + 1)

    for _ in range(m):
        l, r = map(int, input().split())
        diff[l - 1] += 1
        diff[r] -= 1

    coverage = [0] * n
    cur = 0
    for i in range(n):
        cur += diff[i]
        coverage[i] = cur

    total = 0
    items = []

    for value, cnt in zip(a, coverage):
        total += value * cnt
        items.append((cnt, value))

    items.sort(reverse=True)

    for cnt, value in items:
        if k == 0:
            break

        take = min(value, k)
        total -= take * cnt
        k -= take

    print(total)

if __name__ == "__main__":
    solve()
```输入数组是在间隔之前读取的，因为只有在重建覆盖计数之后才需要这些值。 差异数组使用从零开始的位置：原始区间 [l,r] 变为加法`l - 1`和减法`r`。 自从`r`恰好是最后一个从零开始的覆盖索引之后的一个位置，前缀和将间隔停止在正确的位置。 

前缀循环维护`cur`作为当前活动间隔的数量。 最后，`coverage[i]`是区间包含观众 i+1 的官员数量。 

表达式`value * cnt`是观众对初始答案的全部贡献。 Python 整数具有任意精度，这在这里很有用，因为总数可能比 32 位整数大得多。 事实上，j​可以是 10 7 ，并且多达 10 6 名军官可以覆盖同一个观众。 

排序`(cnt, value)`以相反的顺序将更大的覆盖范围放在第一位。 二次排序依据`value`不会影响正确性，因为具有相同覆盖范围的观众会提供相同值的减少。 这`take`表达式同时处理正常情况和剩余预算小于当前观众价值的情况。 

该代码从不对每单位 k 执行一次迭代。 这是很重要的，因为 k 可能是 10 12。每个观众在排序后都会被处理一次。

 ## 边缘情况

 ### 零预算

 对于```
1 1 0
5
1 1
```覆盖范围为 c 1 ​ =1，初始答案为 5，循环立即停止，因为`k == 0`。 结果仍然是5。没有进行人为减少。 

### 预算大于所有可用值

 对于```
1 3 100
7
1 1
1 1
1 1
```单个观众的覆盖范围为 3，因此初始答案为 21。该算法采用所有 7 个可用单元，将答案减少 7⋅3=21。 剩余预算为 93，但没有可以减少的内容，因此结果为 0。 

### 间隔仅触及一个位置

 对于```

5 6 7
1 1
3 3
2 2
```差异数组更新产生覆盖范围 1,1,1。 初始总数为5+6+7=18。 有了两个单位的预算，算法可以从任何观众身上去除两个单位，每个单位节省一个单位的总注意力，所以答案是 16。这具体验证了减法`diff[r]`不会意外地过早地删除间隔一个位置。 

### 不同的覆盖计数

 对于```
3 2 2
4 4 4
1 3
2 2
```覆盖计数为 1,2,1。 最初的关注点是

 4·1+4·2+4·1=16。 

首先处理中间的观众。 从中删除两个单位，节省 2⋅2=4，因此答案变为 12，而不是 18。

    """3 2 2

2 2

```此案例是核心正确性测试。 基于最大原始 a j 的策略在这里会碰巧平局，但基于位置或区间顺序的策略很容易选择错误的观众。 按覆盖范围排序可以直接捕获决定每次减少效益的数量。
