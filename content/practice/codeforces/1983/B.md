 ## 解决方案
 ## 问题理解

 我们有两个网格，`a`和`b`，每个尺寸`n`经过`m`。 网格中的每个单元格都包含从 0 到 2 的值。我们的目标是变换网格`a`进入网格`b`多次使用特定操作。 该操作允许我们选择任何大小至少为 2×2 的子矩形，并将两个对角相对的角增加 1 模 3，而其他两个角增加 2 模 3。问题是是否存在这样的操作序列来使得`a`等同于`b`。 

限制条件适中：`n`和`m`每项最多 500 个，总和`n`和`m`所有测试用例的数量不超过 500。这意味着每个测试用例的算法运行时间应该约为 O(nm)。 任何尝试所有可能的矩形或移动序列的简单暴力方法都是立即不可行的，因为在最坏的情况下有 O(n²m²) 个矩形。 

边缘情况包括像 2×2 这样的小网格、具有统一值（全零或全一）的网格，或者只需要角调整的网格。 在值从 2“环绕”回 0 的情况下，单独递增单元格或忽略模 3 行为的简单方法将会失败。例如，将全零的 2×2 网格转换为全二需要仔细选择哪些角要递增 1 或 2 以满足模算术。 

## 方法

 蛮力方法很简单：重复尝试每个可能的矩形和两个对角线选择，直到网格`a`比赛`b`。 每个操作影响 4 个单元格，我们可以重复尝试每个矩形。 每个测试用例需要 O(n²m² × 操作数)，这对于 n, m ≈ 500 来说显然太慢了。 

关键点是该运算在模 3 上是线性的，并且每个运算仅影响矩形的角。 由于矩形上的运算是模 3 加法，因此该问题简化为“角点差传播”问题。 具体来说，我们可以决定之间的差异`a`和`b`逐个单元格并尝试使用 2×2 子矩形将其从左上角“推”到右下角。 每个2×2块都可以独立调整，这样在处理完除最后一个之外的所有行和除最后一个之外的所有列之后，网格的右下角由其余的唯一确定。 这将问题简化为检查最后一行和最后一列的简单一致性条件。 

换句话说，我们可以仅使用从每个单元 (i, j) 开始的 2×2 子矩形（其中 i < n 且 j < m）贪婪地逐行和逐列地修复差异。 该操作允许这样做，因为增加 2×2 块的左上角也会以受控方式影响相邻单元。 一旦除了最后一行和最后一列之外的所有行和列都对齐，我们检查最后一行和最后一列是否与模 3 匹配。如果匹配，则可以进行转换。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n² m² × 操作数) | O(纳米) | 太慢了 |
 | 贪婪 2×2 传播 | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1.读取输入网格`a`和`b`并计算差异网格`diff[i][j] = (b[i][j] - a[i][j]) % 3`。 这表示每个单元格需要以 3 为模递增多少。 
2. 迭代除最后一行和最后一列之外的所有单元格（即，[0, n-2] 中的 i 和 [0, m-2] 中的 j）。 对于 2×2 块的每个左上角：

 - 让`x = diff[i][j]`。 我们需要通过以下方式将 x 添加到 2×2 块的四个角来“消除”这种差异：

 - 添加`x`到`diff[i][j]`（左上角），`diff[i][j+1]`（右上角），`diff[i+1][j]`（左下），以及`diff[i+1][j+1]`（右下）使用运算规则模 3。 
- 具体来说，将左上角增加`x`(mod 3)，右上角和左下角为`2*x`(mod 3)，右下角为`x`（模3）。 此后，`diff[i][j]`变为零，并且差异正确传播到其他三个角。 
3. 处理完所有 2×2 块后，检查最后一行和最后一列。 如果最后一行或最后一列中的任何剩余差值模 3 为非零，则输出“NO”。 否则，输出“YES”。 

为什么有效：每个操作都会修复 2×2 块左上角的差异，而不会破坏之前固定的单元格。 通过从左上到右下的顺序处理，所有依赖关系都得到正确处理。 模 3 算术保证传播的差异始终可以被最后一行和最后一列吸收。 不变量是处理完cell(i,j)后，`diff[i][j]`为零且未来不会改变。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = [list(map(int, list(input().strip()))) for _ in range(n)]
        b = [list(map(int, list(input().strip()))) for _ in range(n)]
        
        diff = [[(b[i][j] - a[i][j]) % 3 for j in range(m)] for i in range(n)]
        
        for i in range(n - 1):
            for j in range(m - 1):
                x = diff[i][j]
                diff[i][j] = 0
                diff[i][j+1] = (diff[i][j+1] + 2*x) % 3
                diff[i+1][j] = (diff[i+1][j] + 2*x) % 3
                diff[i+1][j+1] = (diff[i+1][j+1] + x) % 3
        
        possible = True
        for i in range(n):
            if diff[i][m-1] != 0:
                possible = False
                break
        for j in range(m):
            if diff[n-1][j] != 0:
                possible = False
                break
        
        print("YES" if possible else "NO")

solve()
```解释：`diff`网格捕获所需的模 3 增量。嵌套循环使用 2×2 操作模式传播差异。 检查最后一行和最后一列可确保一致性。 使用模运算可确保不会溢出并正确从 2 回到 0。
