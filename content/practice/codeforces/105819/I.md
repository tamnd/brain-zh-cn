 ## 解决方案
 ## 问题理解

 我们在无限网格上有一组房屋。 塔放置在某个位置`(r, c)`可以为不在其西边且具有价值的每一栋房屋提供服务`row + column`不比塔大`row + column`。 建造一座塔的成本是它的行数。 

关键是改变我们看待房子的方式。 对于一个房子`(r, c)`，定义一个区间：```
[c, r + c]
```覆盖这座房子的塔必须选择不大于的左边界`c`和右边界不小于`r + c`。 该塔的成本恰好是所选覆盖间隔的长度。 因此，覆盖一组房屋相当于用一个更大的间隔覆盖它们的间隔。 它的成本是最大右端点减去最小左端点。 

该任务要求使用最多的最小总成本`i`每个塔`i`从`1`到`n`。 

房屋数量可达`200000`，因此任何尝试房屋的每个子集或在所有房屋和所有可能的塔楼数量上构建动态编程表的方法都会太慢。 在大约几秒钟的限制下，我们需要`O(n log n)`或关闭解决方案。 坐标可以大到`10^9`，因此算法不能依赖于网格大小。 

不明显的情况来自重叠的区间。 一个天真的解决方案可能会认为每一个额外的塔总是有帮助的，但分割重叠的间隔并不会降低成本。 例如：```
1
5 10
```间隔为`[10, 15]`，所以一塔成本`5`答案是：```
5
```一种粗心的实施方式，将单栋房屋视为需要一座塔楼，其成本等于`r + c`会输出`15`，混淆了塔的对角线位置及其成本。 

另一个重要的情况是当两栋房屋的覆盖区间相交时：```
2
3 5
2 6
```间隔是`[5, 8]`和`[6, 8]`。 一座塔可以同时满足成本`3`，并且两座塔的成本仍然最低`5 + 4 = 9`除非我们强制建立单独的塔。 因为我们最多被允许`i`塔，答案是：```
3 3
```贪婪地为每栋房子建造一座新塔的错误方法会忽略重叠间隔应该保持在一起的事实。 

最后的边缘情况是间隔完全分开时：```
2
1 1
8 8
```间隔是`[1,2]`和`[8,16]`。 一座塔成本`15`，而两座塔的成本`1 + 8 = 9`。 该算法必须认识到在间隙处分裂是有益的。 

## 方法

 一种直接的方法是尝试将所有可能的房屋分组为塔楼。 对于每个组，我们找到最小和最大变换值并计算塔的成本。 这是正确的，因为一座塔完全由它所覆盖的房屋中最小的柱子和最大的对角线值决定。 然而，可能的分区数量是指数级的，因此无法使用。 

一个更实用的蛮力想法是对间隔进行排序并使用动态规划，其中`dp[k]`使用存储最佳成本`k`前几个间隔之间的组。 这还是需要考虑之前的很多分割点。 和`n = 200000`，即使是优化的`O(n^2)`版本将需要大约 400 亿次操作。 

重要的观察是，将房屋改造成间隔后，问题就变成用分段覆盖间隔。 如果我们从每个间隔一段开始，则总成本是所有单独间隔长度的总和。 每当我们合并两个相邻的组时，唯一的额外成本来自它们之间的差距。 如果间隔重叠，则合并不需要任何成本。 如果有尺寸差距`g`，合并会增加成本`g`。 

因为每个合并成本都是独立的，所以减少塔的最佳方法是首先消除最大的间隙。 开始于`n`组中，每次我们跨过一个间隙合并时，我们都会将塔的数量减少一个，并增加该间隙的成本。 因此，可以通过对所有有用的差距进行排序来构建答案。 

其过程是：

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了|
 | 间隔合并与排序间隙 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.改造每栋房子`(r, c)`进入一个区间`[c, r + c]`。 这是有效的，因为当塔的间隔包含房屋的间隔端点时，塔正好覆盖房屋。 
2. 按左端点对所有间隔进行排序。 排序后，所有可以重叠的区间都会出现在彼此旁边，因此我们只需要检查相邻的区间即可。 
3. 从左到右扫描时合并间隔。 保持当前的合并间隔。 如果下一个间隔在当前间隔结束之前开始，则这两个间隔属于同一连接组件，并且不需要额外的塔。 否则，它们之间就会存在差距，而在那里分裂就可以准确地挽救这个差距。 
4. 如果每个连接的组件都单独覆盖，请计算总成本。 这是塔数量最多的情况下的最佳成本。 
5. 存储连续组件之间的每个间隙。 每个间隙代表将两个组件强行装入一座塔时所付出的额外成本。 
6. 按降序对间隙进行排序。 减少塔的数量`n`下降到`1`，反复合并最大的剩余间隙。 每次合并后的运行成本给出了相应塔数的答案。 

其原理：连接组件内的间隔通过链重叠，因此不可避免地有一个线段覆盖该组件。 唯一的选择是是否加入不同的组件。 连接两个组件会精确地增加它们之间的距离，不同的间隙不会相互影响。 首先选择要删除的最大间隙可以最大限度地减少所有可能的合并次数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    intervals = []

    for _ in range(n):
        r, c = map(int, input().split())
        intervals.append((c, r + c))

    intervals.sort()

    base = 0
    gaps = []

    left, right = intervals[0]

    for l, r in intervals[1:]:
        if l <= right:
            if r > right:
                right = r
        else:
            base += right - left
            gaps.append(l - right)
            left, right = l, r

    base += right - left

    gaps.sort(reverse=True)

    ans = [0] * n
    cur = base

    components = len(gaps) + 1
    ans[components - 1] = cur

    for gap in gaps:
        cur += gap
        components -= 1
        ans[components - 1] = cur

    for i in range(1, n):
        if ans[i] == 0:
            ans[i] = ans[i - 1]

    print(*ans)

if __name__ == "__main__":
    solve()
```代码首先创建转换后的间隔。 正确的端点使用`r + c`，而左端点只是`c`。 

排序后，扫描找到连接的组件。 变量`base`独立存储覆盖每个组件的成本。 间隙列表包含当我们组合两个相邻组件时我们损失的确切数量。 

最后的循环处理从最大到最小的间隙。 每处理一个间隙就相当于少使用一个塔。 由于输出要求“最多”`i`塔，答案被填充，以便未使用的较大塔数量保持最佳可用值。 

边界处理很重要。 最后一个组件必须添加在循环之后，否则最后的间隔消失。 所有算术都使用Python整数，因此大坐标不会导致溢出。

import sys
import io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.readline

    n = int(data())
    intervals = []
    for _ in range(n):
        r, c = map(int, data().split())
        intervals.append((c, r + c))

    intervals.sort()
    base = 0
    gaps = []

    l, r = intervals[0]
    for nl, nr in intervals[1:]:
        if nl <= r:
            r = max(r, nr)
        else:
            base += r - l
            gaps.append(nl - r)
            l, r = nl, nr

    base += r - l
    gaps.sort(reverse=True)

    ans[cnt - 1] = cur

        cur += g
        cnt -= 1
        ans[cnt - 1] = cur

    for i in range(1, n):
        if ans[i] == 0:
            ans[i] = ans[i - 1]

    return " ".join(map(str, ans))

 ## 边缘情况

 对于单栋房屋，例如：```
1
5 10
```间隔是`[10,15]`。 该算法没有产生间隙，因此只有一个组件，成本为`15 - 10 = 5`。 这可以避免将塔的对角坐标与其行成本混淆。 

对于重叠间隔：```
2
3 5
2 6
```间隔是`[5,8]`和`[6,8]`。 扫描会立即合并它们，因为第二个间隔在第一个间隔结束之前开始。 组件的数量保持为 1，因此每个答案都是相同的。 这可以处理额外的塔无法降低价格的情况。 

对于分开的间隔：```
2
1 1
8 8
```扫描创建两个组件并记录间隙`8 - 2 = 6`。 对于两个塔，成本是组件长度的总和，`1 + 8 = 9`。 当只允许一座塔时，算法将间隙加回去，产生`15`。 结果与填补空白空间所需的费用相匹配。
