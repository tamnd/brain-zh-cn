 ## 解决方案
 ## 问题理解

 我们有一个 3 行的板，$n$列。 唯一可用的部分是多米诺骨牌大小$2 \times 1$，可以垂直或水平放置。 任务是数出整个过程有多少种不同的方式$3 \times n$可以无重叠且不留空单元格地覆盖矩形。 

输入包含表示列数的单个整数。 输出是该板的完整平铺数量。 

界限$n \le 60$is very small. 甚至一个$O(n^2)$或者$O(n^3)$解决方案很容易足够快。 重要的是找到正确的复发方式。 尝试直接枚举所有平铺很快就变得不可行，因为可能性的数量呈指数级增长。 

一些边缘情况很容易被忽略。 

考虑```
1
```该板包含三个单元。 每个多米诺骨牌覆盖两个单元，因此覆盖奇数个单元是不可能的。 正确答案是```
0
```粗心的实现可能会尝试盲目应用递归并产生正值。 

另一个例子是```
2
```答案是```
1
```对于一个对象来说，只有一种平铺模式$3\times2$长方形。 缺少基本情况将使所有后续值都不正确。 

一个更大的例子是```
4
```谁的答案是```
4
```由于只能使用偶数宽度，因此忘记单独处理奇数值会导致一半输入的答案错误。 

## 方法

 暴力方法将递归地将多米诺骨牌放入第一个未覆盖的单元格中，并继续下去，直到棋盘填满。 由于每个放置都会创建多个分支，因此状态数量呈指数级增长。 为了$n=60$，配置的数量是巨大的，远远超出了一秒钟内可以探索的范围。 

从概念上讲，蛮力起作用的原因是每个完整的平铺都只生成一次。 它的弱点是它会重复地重新计算等效的部分板。 

观察较小的值可以揭示出很强的模式。 奇数宽度总是有零路。 对于偶数宽度，序列开始$$1,1,4,16,64,\dots$$对于宽度$$0,2,4,6,8,\dots$$每次我们添加两列时，都会有两个独立的选择来扩展之前的每个平铺。 最后，$$f(n)=2f(n-2)$$对于甚至$n$。 

这一观察结果将问题转化为一个微小的动态规划问题。 开始于$f(0)=1$，每次相加两列时，我们都会重复乘以 2。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 读取值$n$。 
2.如果$n$是奇数，立即打印 0 因为 a$3\times n$板包含$3n$细胞，这很奇怪。 多米诺骨牌覆盖了两个单元，因此不可能存在完美的平铺。 
3、初始化答案为1，对应空板$f(0)=1$。 
4. 反复将宽度增加两列，每次将答案乘以 2。 

递归来自于这样的事实：每一对额外的列都引入了两个独立的扩展模式。 

1. 输出结果值。 

### 为什么它有效

 不变的是处理后的宽度$i$，变量`ans`等于 a 的平铺数量$3\times i$长方形。 最初，宽度为零是这样，因为有一个空的平铺。 每增加两列，可能性的数量就会增加一倍，因此不变量仍然有效。 当宽度$n$已达到，`ans`等于所需的平铺数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

if n % 2 == 1:
    print(0)
else:
    ans = 1
    for _ in range(n // 2):
        ans *= 2
    print(ans)
```第一步检查宽度是否为奇数。 由于单元格总数为奇数，因此不可能完全覆盖，因此答案立即为零。 

对于偶数宽度，变量`ans`存储当前处理宽度的平铺数量。 它从基本情况开始$f(0)=1$。 每次迭代对应于添加两列，并且每次这样的扩展都会使有效平铺的数量加倍。 

Python 整数会自动增长到任意大小，因此即使是$n=60$安全贴合，无需担心溢出。 

循环完全运行`n // 2`次。 使用整数除法可以避免出现差一错误$n=0$或者$n=2$。
