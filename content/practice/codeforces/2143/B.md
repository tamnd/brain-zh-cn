 ## 解决方案
 ## 问题理解

 我们被要求购买一套单独价格的产品，同时使用折扣券将总成本降至最低。 每张优惠券都允许您选择固定数量的产品，并免费获得其中最便宜的产品。 每张优惠券只能使用一次，任何产品不得属于多个优惠券组。 目标是找出在所有产品中使用优惠券的最便宜的方式。 

输入由多个测试用例组成。 对于每种情况，我们都知道产品的数量、价格和优惠券价值。 输出是每个测试用例的最小成本。 约束条件高达$2 \cdot 10^5$产品和优惠券在所有测试用例中相结合，任何解决方案都必须大致在线性或线性算数时间内工作，排除任何二次方$n$或者$k$。 

当许多优惠券的大小为 1 时，会出现一种微妙的边缘情况。在这种情况下，每张优惠券都可以让我们免费获取一种产品。 粗心的做法可能会忽略分组并首先应用较大的优惠券，而不考虑免费单一产品的可能性。 例如，如果我们有价格为 5, 3, 2, 1 的产品和优惠券 [1,1,3]，则最佳解决方案是在两件最便宜的商品上使用两张 1 尺寸优惠券，在剩余的两件和一件已经免费的商品上使用 3 尺寸优惠券。 忽略凭证大小顺序可能会产生更高的总成本。 

另一个边缘情况是优惠券数量超过产品数量，或者优惠券大小大于剩余产品数量。 我们必须妥善处理这些问题，切勿尝试分配超出可用的产品。 

## 方法

 强力解决方案将尝试将产品分配给凭证的所有可能的分配方式，计算每种组合的总成本。 这显然是正确的，但不可行。 例如，有 20 种产品和 10 张优惠券，分组数量是天文数字，使得任何显式搜索都是不可能的。 

关键的观察是，最便宜的产品应该首先与最大的优惠券配对，因为优惠券使一组中最便宜的产品免费。 如果我们将产品按降序排列，将优惠券按升序排列，我们可以贪婪地将最小的优惠券分配给最便宜的未分配产品，确保免费产品确实是未分配产品中最便宜的。 这使我们能够通过每张优惠券最大限度地节省费用。 对于任何优惠券中不包含的产品，我们只需支付全价。 

该问题结构允许采用两指针贪婪解决方案：一个指针指向最昂贵的未分配产品，另一个指针指向最便宜的未分配产品。 通过仔细地从最大到最小分配优惠券，我们确保永远不会浪费优惠券并始终最大限度地降低总成本。

 | 最佳| O(n log n + k log k) | O(n log n + k log k) | O(n + k) | 已接受 |

 ## 算法演练

 1. 按降序排列产品价格。 这确保了最左边的产品是最昂贵的，我们总是在优惠券组中支付。 最右边的产品将是最便宜且可能免费的产品。 
2. 按升序对凭证大小进行排序。 我们希望将最小的优惠券分配给最便宜的产品，因为它只能免费一种产品，而较大的优惠券将覆盖更昂贵的产品。 
3.初始化两个指针：`i`在产品数组的开头（最昂贵）和`j`最后（最便宜）。 
4. 从最大到最小迭代凭证。 对于每张优惠券的尺寸`x`，我们添加`x-1`最昂贵的未分配产品占总成本。 这对应于`a[i]`通过`a[i+x-2]`如果从`i`。 然后递增`i`经过`x-1`跳过这些付费产品。 
5. 对于每张优惠券，付款后`x-1`产品，该组中最便宜的产品是隐式免费的，因此它对应于`a[j]`。 递减`j`将其标记为已使用。 
6. 分配所有优惠券后，任何剩余产品`i`和`j`均单独全额支付。 将它们添加到总成本中。 

为什么有效：在每个步骤中，我们保证优惠券免费提供最便宜的未分配产品，并首先支付更昂贵的产品。 通过对优惠券进行升序排序，对产品进行降序排序，我们确保不会浪费优惠券，也不会不必要地支付更便宜的产品。 两指针方法保证每个产品仅使用一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        a.sort(reverse=True)
        b.sort()
        
        total = 0
        i = 0
        j = n - 1
        
        # process vouchers from largest to smallest
        for voucher in reversed(b):
            if voucher == 1:
                # free the cheapest remaining product
                total += a[i]
                i += 1
            else:
                # pay for the most expensive x-1 products
                total += sum(a[i:i + voucher - 1])
                i += voucher - 1
                j -= 1  # free the cheapest in this group
        
        # pay full price for remaining products
        while i <= j:
            total += a[i]
            i += 1
        
        print(total)

if __name__ == "__main__":
    solve()
```该解决方案首先对产品和凭证进行排序，以方便贪婪分配。 两点方法确保首先支付最昂贵的产品，同时优惠券有效地免费免费提供最便宜的产品。 微妙之处在于正确处理尺寸为 1 的凭证，直接释放单个产品，并确保`i`和`j`指针永远不会错误地重叠。
