 ## 解决方案
 ## 问题理解

 我们给定一个整数序列，每个整数都在 1 到 n 之间，并且我们想要计算可以“着色”为红色或蓝色的子序列，以便子序列中的每个反转都有不同颜色的端点。 反转是一对索引 i < j，使得 i 处的元素大于 j 处的元素。 输出是此类子序列的总数模 10^9 + 7。 

对于较小的 n，特别是此版本中的 n ≤ 300，我们可以负担每个测试用例具有三次甚至二次时间的算法，因为操作总数将保持在大约 10^7-10^8 范围内，这对于 3 秒的限制是可以接受的。 然而，我们不能直接枚举所有 2^n 子序列，因为 2^300 是一个天文数字。 这排除了任何单独生成每个子序列的简单解决方案。 

一些边缘情况很突出。 如果所有元素都相等，则不存在反转，因此每个子序列自动有效。 对于严格递减的子序列，我们必须交替颜色以满足所有反转。 如果我们忽略这些模式并尝试盲目计数，我们很容易多算或少算好的子序列。 例如，像 [4, 3, 1] 这样的序列有反转 (4,3), (4,1), (3,1)； 任何着色都必须在这些对之间分配不同的颜色，这限制了有效的着色。 

## 方法

 暴力方法将枚举每个子序列，检查所有反转，并查看是否存在有效的红/蓝色着色。 可以使用二分图检查来检查每个子序列：将每个元素视为顶点，在形成反转的元素之间绘制边，并检查图是否是二分图。 复杂度为 O(2^n * n^2)，因为对于每个 2^n 子序列，我们可以检查 O(n^2) 对。 显然，对于 n = 300 来说这是不可行的。 

关键的见解是，这个问题相当于计算序列“反演图”的二分诱导子图。 我们可以使用动态规划来代替生成子序列。 将 dp[i] 定义为以位置 i 结尾的好子序列的数量。 对于每个 i，只要附加 a_i 不会产生无效的着色冲突，我们就可以扩展以索引 j < i 结尾的现有良好子序列。 我们可以跟踪每个子序列端点处的最小值和最大值，以快速检查反转是否会违反二分性。 因为 n ≤ 300，所以 O(n^2) DP 是可行的。 这将问题简化为 i 和 j 上的可管理嵌套循环，以结构化方式计算子序列的扩展，而不是枚举所有子序列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(n) | 太慢了|
 | 最佳DP | O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1、初始化一个长度为n+1的DP数组dp，其中dp[i]统计以a_i结尾的好子序列。 我们还维护一个前缀总和以有效地捕获较小长度的子序列。 
2. 对每个i设置dp[i] = 1，表示仅由a_i组成的子序列。 这确保了每个单元素子序列都被计数。 
3. 将 i 从 0 迭代到 n-1。 对于每个 i，从 0 到 i-1 迭代 j。 如果 a_j ≤ a_i，则任何以 j 结尾的良好子序列都可以通过包含 a_i 来安全地扩展，而不会创建无效的反转着色。 将 dp[j] 添加到 dp[i]。 此步骤增量地构建子序列，尊重二分着色属性，因为我们只扩展“兼容”的较小元素。 
4. 将所有 dp[i] 值相加，得到非空好子序列的总数。 加 1 来解决空子序列，这非常好。 
5. 每次加法时应用模 10^9 + 7 以防止整数溢出。

保持的不变量是 dp[i] 始终包含恰好在索引 i 处结束的好子序列的数量。 每次我们将 dp[j] 添加到 dp[i] 时，我们只考虑可以合法地用 a_i 扩展的序列，因此不会出现无效的着色。 所有 dp[i] 的最终总和给出了良好非空子序列的总数，添加空子序列即可完成计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    dp = [0] * n
    for i in range(n):
        dp[i] = 1  # subsequence of length 1
        for j in range(i):
            if a[j] <= a[i]:
                dp[i] = (dp[i] + dp[j]) % MOD
    result = (sum(dp) + 1) % MOD  # add empty subsequence
    print(result)
```每个 dp[i] 初始化确保对单元素子序列进行计数。 嵌套循环仅检查小于或等于当前元素的先前元素，确保子序列中的反转不会造成着色冲突。 对所有子序列求和并加 1，包括空子序列。 我们在每次加法时使用模来防止溢出并保持正确性。
