 ## 解决方案
 ## 问题理解

 我们得到一个整数序列，并可以通过排序来重新排列它。 排序后，我们计算总的“相邻差异成本”，它是排序序列中每对连续元素之间的绝对差异之和。 任务就是输出这个最终值。 

换句话说，我们将数组重新排序为非递减顺序，然后测量从左到右遍历时它从一个元素到下一个元素“拉伸”的程度。 这是排序后的单遍计算。 

的约束条件为$n$很小，最多 100，并且值可以高达$10^5$。 这立即告诉我们，任何$O(n^2)$或者$O(n \log n)$解决方案很容易足够快。 即使是简单的排序也会在运行时占据主导地位并且是可以接受的。 

一个微妙的点是绝对值和很大程度上取决于排序。 如果不进行排序，相邻差异可能会任意大或任意小，具体取决于排列。 跳过排序的简单方法显然会产生不正确的结果。 

一个典型的错误是计算原始数组而不是排序后的数组的差异。 例如，给定输入`[3, 1, 2]`，原总和为`|3-1| + |1-2| = 2 + 1 = 3`，而正确的排序计算给出`|1-2| + |2-3| = 1 + 1 = 2`。 这种不匹配表明排序不是可选的。 

另一个边缘情况是所有值都相等。 排序后的数组保持不变，结果必须为零。 任何意外使用有符号差异而不是绝对值的实现仍然可以通过一些测试，但在混合符号情况下会失败。 

## 方法

 强力解释是尝试数组的所有排列，计算每个排列的相邻差和，并可能根据解释取最小值或一些所需的值。 在这个问题中，由于明确需要排序，因此暴力视图变得不必要，但它作为心理模型仍然有用：我们正在寻找一种排序，使序列结构化到足以轻松评估。 

枚举所有排列成本$n!$配置以及每次评估成本$O(n)$，即使对于$n = 10$。 这会导致阶乘爆炸。 

关键的观察是，这个问题并不要求我们优化排列。 它明确告诉我们先排序。 一旦数组排序完毕，结构就变得单调。 在排序数组中，计算总相邻差异的最佳方法就是遍历一次。 没有其他排序可供考虑，因此组合爆炸消失了。 

因此，解决方案减少为两个操作：排序和线性累加。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（所有排列）|$O(n! \cdot n)$|$O(n)$| 太慢了|
 | 排序+扫描|$O(n \log n)$|$O(1)$或者$O(n)$| 已接受 |

 ## 算法演练

 ### 步骤

 1.读取整数$n$和数组$a$。 这是一个单一的测试用例，因此我们处理一次。 
2. 按非降序对数组进行排序。 这确保了相邻元素在全局意义上尽可能接近值，消除了任意排序效应。 
3. 初始化累加器变量`ans = 0`。 这将存储相邻绝对差的总和。 
4. 从索引迭代`1`到`n - 1`。 对于每个位置，计算`a[i] - a[i-1]`。 因为数组是排序的，所以这个差总是非负的，所以绝对值是不必要的。 
5. 将每个差异添加到`ans`。 
6. 输出`ans`。 

### 为什么它有效

 排序后，序列是单调非递减的，因此每个相邻差值等于连续顺序统计量之间的真实差距。 任何其他排序都会引入更大的跳跃或多次重复小的局部差异。 排序顺序使每个元素精确地参与连续值之间的最小必要转换，因此相邻差异的总和是唯一确定的，并且可以从排序数组直接计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))
    
    a.sort()
    
    ans = 0
    for i in range(1, n):
        ans += a[i] - a[i - 1]
    
    print(ans)

if __name__ == "__main__":
    solve()
```实现很简单。 排序是就地完成的，这使得内存使用量最小化。 循环从索引1开始，以避免对索引0进行边界检查。由于数组是排序的，因此我们用直接减法代替绝对差，这样可以避免不必要的函数调用并简化逻辑。 

一个常见的错误是忘记排序或计算`abs(a[i] - a[i-1])`在原始数组上。 两者都会违反问题中描述的预期转换。

 ## 边缘情况

 一种重要的边缘情况是所有元素都相同。 用于输入`[7, 7, 7, 7]`，排序不执行任何操作，并且每个相邻差异为零。 该算法产生`0`因为每次减法都会产生零，从而确认没有意外累积。 

另一种情况是输入已经排序。 为了`[1, 2, 3, 4, 5]`，算法没有进行结构上的改变，扫描直接计算连续间隙的总和，这通过构造是正确的。 

第三种情况是逆序。 为了`[5, 4, 3, 2, 1]`，排序将其转化为`[1, 2, 3, 4, 5]`，之后计算与已排序的情况相同。 这表明该算法对于初始排序是不变的，并且仅依赖于多重集结构。
