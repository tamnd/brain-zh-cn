 ## 解决方案
 ## 问题理解

 我们正在使用两个整数间隔。 一个区间定义了所有有效值$x$，另一个定义了所有有效值$y$。 我们被要求数一下有多少对$(x, y)$可以这样形成$x$从其区间中选择，$y$从它的区间中选择，它们的总和恰好是一个固定的目标值$n$。 

从几何角度来看，您可以将其视为对位于直线上的平面中的矩形内的格点进行计数$x + y = n$。 每个有效对对应于该对角线段上的单个整数点。 

约束很大：端点最多可达$10^9$。 这立即排除了迭代所有值$x$或者$y$。 任何循环的解决方案$10^9$在典型的时间限制内元素是不可能的。 我们需要一种方法来在恒定时间内分析计算交叉点的大小。 

当人们假设对于每一个$x$在$[l_1, r_1]$，值$y = n - x$如果位于以下位置则自动有效$[l_2, r_2]$没有仔细跟踪间隔重叠。 例如，如果$n = 20$,$x = 1$力量$y = 19$，即使两个区间各自都很大，它也可能位于第二个区间之外。 正确性完全取决于变换范围的重叠，而不仅仅是每个端点是否存在解。 

当变换空间中的间隔根本不相交时，就会出现另一种极端情况。 例如，如果最小可能的总和$l_1 + l_2$已经大于$n$，或最大可能的总和$r_1 + r_2$小于$n$，则不存在解。 不考虑可行性界限的简单方法可能仍会尝试对对进行计数并产生不正确的正值。 

## 方法

 暴力方法会枚举所有可能的$x$在$[l_1, r_1]$, 计算$y = n - x$，并检查是否$y$位于里面$[l_2, r_2]$。 这是正确的，因为它直接强制执行所有约束。 然而，它的运行时间与第一个间隔的大小成正比，在最坏的情况下是$10^9$。 即使在$10^8$每秒的操作次数，这远远超出了实际限制。 

关键的观察结果是方程$x + y = n$删除一个自由度。 一次$x$被选择，$y$是固定的。 而不是扫描全部$x$，我们可以准确地确定哪个$x$值产生有效的$y$。 条件$l_2 \le n - x \le r_2$可以重写为不等式$x$，它将问题转化为在一维中查找两个区间的交集。 

从$l_2 \le n - x \le r_2$，我们推导出：$$n - r_2 \le x \le n - l_2$$如此有效$x$必须同时位于$[l_1, r_1]$并在$[n - r_2, n - l_2]$。 答案就是这两个区间的交集的长度。

 | 蛮力 |$O(r_1 - l_1 + 1)$|$O(1)$| 太慢了|

 ## 算法演练

 ### 1. 将条件转换为$y$进入界限$x$我们重写$y = n - x$里面$l_2 \le y \le r_2$，生产$n - r_2 \le x \le n - l_2$。 此步骤消除了对$y$，将问题简化为单个变量。 

### 2. 计算有效有效区间$x$我们现在有两个限制$x$: 原始区间$[l_1, r_1]$，以及变换后的区间$[n - r_2, n - l_2]$。 有效的$x$值必须同时满足两者。 

### 3. 取两个区间的交集

 交集间隔为：$$L = \max(l_1, n - r_2), \quad R = \min(r_1, n - l_2)$$此步骤是合理的，因为两个约束是独立的并且必须同时成立。 

### 4. 计算交集中的整数点

 如果$L \le R$，整数的个数是$R - L + 1$。 否则，就没有有效的对。 

### 为什么它有效

 每个有效对$(x, y)$唯一对应于一个整数$x$满足两个区间约束。 转变$y = n - x$在有效对和有效之间是双射的$x$-价值观。 该算法不会丢弃或重复计算任何值，因为每个步骤都保留约束的等价性，仅将它们重写为单变量形式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

l1, r1, l2, r2, n = map(int, input().split())

left = max(l1, n - r2)
right = min(r1, n - l2)

if left <= right:
    print(right - left + 1)
else:
    print(0)
```代码直接实现了区间变换。 唯一的微妙之处是仔细处理边界算术。 表达式`n - r2`和`n - l2`定义第二个区间在 x 轴上的有效投影。 服用`max`和`min`确保我们同时尊重这两个约束。 最后的条件防止负间隔长度，这对应于空交集。

 正好有一个有效的$x = 10$, 给予$y = 10$。 这证实了只有边界点满足两个区间。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    l1, r1, l2, r2, n = map(int, sys.stdin.readline().split())

    return str(max(0, right - left + 1))

 ## 边缘情况

 一种边缘情况是变换后的区间完全位于原始区间之外。 例如，输入：```
1 3 10 20 5
```我们计算变换后的边界：$5 - 20 = -15$,$5 - 10 = -5$。 如此有效$x$从第二个约束是$[-15, -5]$。 与 的交集$[1, 3]$给出空范围，因为$L = 1$,$R = -5$， 和$L > R$。 算法正确输出 0。 

另一种情况是当两个区间都崩溃到满足总和约束的单个点时：```
7 7 13 13 20
```变换后的边界是$20 - 13 = 7$和$20 - 13 = 7$，所以两个区间都精确地变为$[7,7]$。 交集是一个单点，算法返回 1。这证实了退化区间是自然处理的，无需特殊分支。
