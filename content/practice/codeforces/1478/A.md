 ## 解决方案
 ## 问题理解

 Nezzar 有一系列球，每个球都标有来自非递减数组的数字。 他想用尽可能少的颜色给球上色，规则是，如果我们隔离所有相同颜色的球，它们的数量必须严格增加。 严格递增序列要求每个后续数字都大于前一个数字。 对于单个球或孤立的元素，这很简单。 

输入由多个测试用例组成。 每个测试用例都给出数组的长度和数组本身。 球上的数字范围从 1 到$n$，并且该数组是非递减的。 输出必须是每个测试用例所需的最小颜色数。 

限制很小：$n$最多为 100，并且最多有 100 个测试用例。 这允许算法$O(n^2)$在时间限制内舒适运行的复杂性。 然而，不小心处理重复的数字可能会产生错误的答案。 例如，在数组中`[1,1,2,2,3]`，一种简单地尝试从左到右贪婪地分配颜色而不考虑重叠的简单方法可能会使用不必要的颜色。 正确答案是 2，因为我们可以为重复的数字替换颜色：`[1,2,1,2,1]`。 

边缘情况包括所有数字都相同的数组、具有单个元素的数组以及数字严格递增的数组。 这些场景测试算法是否正确计算重复元素。 

## 方法

 暴力方法是尝试为每个球分配所有可能的颜色，并检查每种颜色的结果序列是否严格递增。 虽然正确，但这种方法的复杂性呈指数级增长$n$甚至对于$n=20$。 

关键的观察结果是，所需的最小颜色数量由数组中任何单个数字的最大频率决定。 每个重复的数字都需要进入单独的颜色，以保持每种颜色的严格递增条件。 例如，如果数字 2 出现了 3 次，那么我们必须至少有三种颜色，因为任何颜色最多可以容纳 2 出现一次。 

因此，最佳的方法是统计每个数字的频率并取最大值。 这将问题简化为一个简单的计数问题，其时间复杂度相对于$n$。 自从$n$虽然很小，但这种方法非常有效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k^n) | O(k^n) | O(n) | 太慢了|
 | 最佳| 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，请阅读$n$和数字数组。 
3. 初始化一个频率字典或数组来统计每个数字出现的次数。 
4. 迭代数组并增加每个数字的计数。 
5. 找出所有数字中的最大频率。 
6. 打印此最大频率作为所需的最小颜色数。 

为什么有效：任何数字的最大频率都代表最紧的瓶颈。 任何颜色都不能包含多次出现的相同数字，因此每个重复的数字必须拆分为多种颜色。 任何小于最大频率的情况都会违反对某些数量的严格增加的要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import Counter

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    freq = Counter(a)
    print(max(freq.values()))
```该代码使用有效地读取输入`sys.stdin.readline`。`Counter`自动计算每个数字出现的频率。 使用`max(freq.values())`直接提取最高频率，对应最少的颜色数。 这可以避免手动循环和潜在的差一错误。 

## 工作示例

 **样品1：**

 输入：`[1, 1, 1, 2, 3, 4]`| 数量 | 频率|
 | --- | --- |
 | 1 | 3 |
 | 2 | 1 |
 | 3 | 1 |
 | 4 | 1 |

 最大频率为 3，因此我们需要 3 种颜色。 

**样本2：**

 输入：`[1, 1, 2, 2, 3]`| 数量 | 频率|
 | --- | --- |
 | 1 | 2 |
 | 2 | 2 |
 | 3 | 1 |

 最大频率为 2，因此我们需要 2 种颜色。 

这些痕迹表明算法根据重复的数字正确识别颜色要求。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | 每个测试用例 O(n) | 计数频率是线性的，找到最大值与唯一数字的数量是线性的，最多n |
 | 空间| 每个测试用例 O(n) | 计数器字典存储每个唯一数字的频率，最多 n 个条目 |

 给定$n \le 100$和$t \le 100$，总操作最多为$100*100=10^4$，完全在 1 秒限制之内。 

## 测试用例```python
import sys, io
from collections import Counter

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = Counter(a)
        output.append(str(max(freq.values())))
    return "\n".join(output)

 ## 边缘情况

 对于`[2,2,2,2]`，算法计算 2 出现 4 次。最大频率为 4，因此输出 4。这正确地反映了我们需要 4 种颜色，因为没有两个编号为 2 的球可以共享一种颜色。 

为了`[1]`，1 的频率为 1，最大频率为 1，输出为 1。单元素数组始终需要一种颜色。 

为了`[1,2,3,4]`，所有数字都是不同的，最大频率为 1，输出为 1。这证实了算法正确处理严格递增的序列，没有不必要的颜色。 

所有边缘情况都表明该算法是稳健的并且完全符合问题的要求。
