 ## 解决方案
 ## 问题理解

 Vasya 目前担任军衔`a`在军队中并希望最终获得军衔`b`。 从级别移动`i`排名`i + 1`需要固定的年数，存储在数组中`d`。 

数组有长度`n - 1`因为正好有`n - 1`连续等级之间的转换。 例如，`d[0]`代表从军衔升级所需的年数`1`排名`2`， 和`d[1]`代表从军衔升级所需的年数`2`排名`3`。 

达到等级`b`，瓦夏必须按顺序通过每一个中级。 这意味着总时间只是之间所有转换成本的总和`a`和`b`。 

限制非常小。`n`至多是`100`，因此即使对数组进行简单的循环也足够快。 二次解也能轻松通过，因为在最坏的情况下它的表现约为`10,000`运营。 这个问题的重点是仔细索引而不是优化。 

错误的主要来源是差一索引，因为排名是从`1`，而 Python 中的数组的索引来自`0`。 

考虑这个例子：```
4
1 2 3
2 4
```正确答案是：```
5
```我们需要时间`2`到`3`，即`2`，并从`3`到`4`，即`3`。 他们的总和是`5`。 

粗心的实现可能会错误地从索引求和`2`通过`4`，或包含错误的边界。 

另一个容易犯的错误是包含一个额外的段。 

例子：```
5
10 20 30 40
1 3
```正确输出：```
30
```所需的转换是`1 -> 2`和`2 -> 3`，所以答案是`10 + 20 = 30`。 

如果有人不小心通过索引求和`3`，他们会错误地包括过渡`3 -> 4`并得到`60`。 

## 方法

 最直接的做法就是逐级模拟晋升路径。 从排名开始`a`，我们反复添加进入下一个等级所需的年数，直到达到`b`。 

这种蛮力方法已经足够有效了，因为最多有`99`总共的转变。 在最坏的情况下，我们对整个数组求和一次，这只是`O(n)`运营。 

这样做的原因是晋升结构是完全线性的。 从等级出发只有一条可能的路径`a`排名`b`。 不需要分支、最短路径逻辑或动态编程。 每个有效的旅程必须经过相同的连续转换。 

更复杂的解决方案会增加不必要的开销。 关键的观察结果是答案恰好是连续子数组的总和`d`。 

具体来说，从级别上移动`a`排名`b`，我们需要：```
d[a-1] + d[a] + ... + d[b-2]
```一旦我们认识到每个数组元素代表连续等级之间的一条边，实现就变成了一个简单的范围总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 在这个问题中，强力方法和最优方法实际上是相同的，因为约束很小并且结构是线性的。 

## 算法演练

 1.读取整数`n`，等级数。 
2.读取数组`d`长度`n - 1`。 

每个元素代表从一个级别晋升到下一个连续级别所需的年数。 
3. 读取整数`a`和`b`。 

Vasya 目前排名`a`并且想要达到排名`b`。 
4. 初始化`answer = 0`。 

该变量累计所需的总年数。 
5. 迭代索引`a - 1`最多`b - 2`。 

这些正是瓦夏必须完成的转变。 
6. 添加每个相应的值`d`进入`answer`。 
7. 打印`answer`。 

### 为什么它有效

 每个元素`d[i]`对应于等级的转变`i + 1`排名`i + 2`。 从等级出发旅行`a`排名`b`，Vasya 必须完成其间的每个连续转换。 

该算法精确地总结了那些所需的转换，而不是其他。 由于排名中只有一条可能的路径，因此该总和是唯一确定的并且始终正确。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
d = list(map(int, input().split()))
a, b = map(int, input().split())

answer = 0

for i in range(a - 1, b - 1):
    answer += d[i]

print(answer)
```前两行读取等级数以及连续等级之间的转换成本。 

关键的细节是循环范围：```
range(a - 1, b - 1)
```认为`a = 2`和`b = 4`。 我们需要过渡：```
2 -> 3
3 -> 4
```这些对应于数组索引：```
1 and 2
```在Python中，`range(1, 3)`准确地产生这些指数。 

循环之前停止`b - 1`，这可以防止达到等级后意外地包括下一个转换`b`。 

该解决方案使用恒定的额外内存，因为它仅存储输入数组和一个累加器变量。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    n = int(input())
    d = list(map(int, input().split()))
    a, b = map(int, input().split())

    ans = 0

    for i in range(a - 1, b - 1):
        ans += d[i]

    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output

# provided sample
assert run("3\n5 6\n1 2\n") == "5\n", "sample 1"

print("All tests passed!")

 ## 边缘情况

 考虑尽可能最小的输入：```
2
7
1 2
```整个系统只有一次转变。 该算法使用索引运行一次循环`0`并添加`7`。 输出变为：```
7
```这确认了循环正确处理最小边界。 

现在考虑目的地距离几排的情况：```
5
10 20 30 40
1 5
```循环遍历索引`0`,`1`,`2`， 和`3`。 

运行总计变为：```
10
30
60
100
```最终的答案是：```
100
```这验证了每个所需的转换都只包含一次。 

最后，考虑一下经典的差一陷阱：```
5
10 20 30 40
1 3
```该算法仅通过索引进行迭代`0`和`1`。 

总和变为：```
10 + 20 = 30
```过渡`3 -> 4`不包括在内，因为循环在索引之前停止`2`。 这确认了正确处理右边界。
