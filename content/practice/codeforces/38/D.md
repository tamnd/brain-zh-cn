 ## 解决方案
 ## 问题理解

 我们将立方体一一堆叠起来。 每个立方体都是轴对齐的，它在地面上的投影是正方形。 由于立方体是实际的立方体，因此边长由正方形底决定。 

立方体`i`直接放置在立方体的顶部`i-1`。 它们的投影与正区域重叠，因此上面的立方体总是与前一个立方体物理接触。 问题不在于新的立方体是否接触到前一个立方体，而是整个塔在重力作用下是否保持平衡。 

如果每个立方体都支撑其上方所有立方体的总质心，则塔是稳定的。 对于立方体`i`，考虑来自的所有立方体`i`到顶部。 它们的组合质心必须严格位于立方体之间的重叠区域内`i-1`和立方体`i`。 如果它离开了那个区域，立方体`i`坠落、施工停止，所有更高的立方体都无关紧要。 

输入给出每个正方形底面对角的坐标。 从这些坐标我们可以得出：

 - 边长，
 - 立方体质量，等于`side^3`,
 - 广场中心。 

我们必须输出保持稳定的立方体的最大前缀。 

限制很小，仅`n ≤ 100`。 这完全改变了问题。 我们不需要先进的几何结构或优化技巧。 一个`O(n^3)`解决方案已经很小，大约一百万次操作。 

危险的部分不是性能，而是正确的物理建模。 

一个常见的错误是仅检查当前立方体的中心是否位于重叠区域内。 实际情况取决于接触面上方整个子塔的质心。 

考虑这个例子：```
3
0 0 10 10
4 0 14 10
8 0 18 10
```第二个和第三个立方体很好地重叠，每个立方体中心都位于与前一个立方体重叠的内部。 但上面的立方体一起将质心向右移动足够远，使得下面的接触变得不稳定。 

另一个简单的错误是使用非严格的不等式。 质心必须严格保持在支撑区域内。 触及边界意味着零容忍的完美平衡，问题将其视为坠落。 

例子：```
2
0 0 2 2
1 0 3 2
```x 方向的重叠为`[1, 2]`。 如果质心正好变成`1`或者`2`，塔不稳定。 

第三个微妙的问题是每个中间塔都必须保持稳定性。 即使是立方体`1..5`在一起以某种方式再次稳定下来，答案仍然是由第一次失败决定的。 

例子：```
4
0 0 10 10
7 0 17 10
8 0 18 10
0 0 10 10
```如果立方体 3 已经导致崩溃，则立方体 4 永远不会被放置在现实中。 

## 方法

 蛮力思想直接遵循物理学。 

对于每个前缀`1..k`，我们测试塔是否稳定。 为了测试稳定性，我们从上到下处理支撑。 用于立方体之间的支撑`i-1`和`i`，我们计算立方体的质心`i..k`。 如果该点严格位于立方体的重叠矩形内`i-1`和`i`，支持仍然存在。 否则塔就会倒塌。 

质心计算很简单：$$cx = \frac{\sum m_j x_j}{\sum m_j}$$类似地对于`cy`。 

这是有效的，因为每个支撑只关心其上方的总质量。 

幼稚的实现每次都会从头开始重新计算这些总和。 对于每一个`k`，对于每一个支持`i`，我们扫描所有立方体`j ≥ i`。 那成本`O(n^3)`。 

和`n = 100`， 甚至`100^3 = 10^6`操作完全没问题。 官方的难度来自于几何推理，而不是运行时。 

尽管如此，我们仍然可以使用后缀累积来简化实现。 在向下迭代时，我们保持当前支撑上方所有立方体的总质量和加权坐标和。 然后每个质心查询变成`O(1)`。 

关键的观察是，一旦我们知道支撑上方的组合质心，支撑就是独立的。 我们永远不需要明确地模拟扭矩或力。 均匀重力和轴对齐立方体将一切简化为检查点是否位于矩形内。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n²) | O(n) | 已接受 |

 ## 算法演练

 1. 读取所有立方体并标准化它们的坐标，以便`x1 < x2`和`y1 < y2`。 
2. 对于每个立方体，计算：

 - 边长`a = x2 - x1`，
- 大量的`m = a^3`,
 - 中心坐标：$$cx = \frac{x1 + x2}{2}, \quad cy = \frac{y1 + y2}{2}$$1. 迭代塔的大小`k`从`1`到`n`。 我们测试是否是立方体`1..k`形成一座稳定的塔。 
2. 对于每个`k`，流程支持从上到下。 

立方体之间的支撑`i-1`和`i`必须携带立方体`i..k`。 
3、维护：

 - 总质量高于当前支撑，
 - 加权 x 总和，
 - 加权 y 总和。 

最初，这些仅包含立方体`k`。 当我们向下移动时，我们添加更多的立方体。 
4. 计算立方体的质心`i..k`：$$com_x = \frac{sx}{sm}, \quad com_y = \frac{sy}{sm}$$1.计算立方体之间的重叠矩形`i-1`和立方体`i`：$$lx = \max(x1_{i-1}, x1_i)$$

$$rx = \min(x2_{i-1}, x2_i)$$y 也类似。 

1. 检查质心是否严格位于重叠部分内：$$lx < com_x < rx$$

$$ly < com_y < ry$$如果任一条件失败，则立方体`i`失去平衡，答案是`k-1`。 

1. 如果所有支撑都存活，则继续下一步`k`。 
2. 如果每个前缀都稳定，则输出`n`。 

### 为什么它有效

 对于任何支撑表面，静态平衡中唯一重要的是该表面上方所有物体的总质心的投影。 如果该突出部分位于支撑区域内，则重力不会产生倾翻扭矩。 如果它离开该区域，塔就会旋转并坠落。 

该算法针对每个前缀塔中的每个支撑精确检查此条件。 由于测试了每个可能的故障点，并且每个测试都符合物理稳定性标准，因此该算法不会错误地对塔进行分类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    cubes = []

    for _ in range(n):
        x1, y1, x2, y2 = map(int, input().split())

        if x1 > x2:
            x1, x2 = x2, x1
        if y1 > y2:
            y1, y2 = y2, y1

        side = x2 - x1
        mass = side ** 3

        cx = (x1 + x2) / 2.0
        cy = (y1 + y2) / 2.0

        cubes.append((x1, y1, x2, y2, mass, cx, cy))

    for k in range(n):
        sm = 0.0
        sx = 0.0
        sy = 0.0

        for i in range(k, -1, -1):
            x1, y1, x2, y2, mass, cx, cy = cubes[i]

            sm += mass
            sx += mass * cx
            sy += mass * cy

            if i == 0:
                continue

            px1, py1, px2, py2, _, _, _ = cubes[i - 1]

            lx = max(px1, x1)
            rx = min(px2, x2)

            ly = max(py1, y1)
            ry = min(py2, y2)

            com_x = sx / sm
            com_y = sy / sm

            eps = 1e-9

            if not (lx + eps < com_x < rx - eps and
                    ly + eps < com_y < ry - eps):
                print(k)
                return

    print(n)

solve()
```第一部分将坐标归一化并计算一次所有物理量。 稍后使用中心而不是原始几何体可以保持实现的紧凑性。 

外循环增量测试前缀。 什么时候`k = 4`，例如，我们正在检查立方体是否`1..5`保持稳定。 

在该循环内，我们通过支撑向下移动，同时保持累积的质量信息。 这避免了重复重新计算质心。 

重叠矩形是使用区间交集来计算的。 由于该问题保证了连续立方体之间的正重叠，`lx < rx`和`ly < ry`始终保持几何形状。 

严格的不平等至关重要。 恰好位于边界上的质心是不稳定的。 浮点比较使用微小的 epsilon 来避免精度噪声。 

另一个微妙的点是更新的顺序。 我们首先添加立方体`i`进入累积总和，然后测试支持度`(i-1, i)`。 该支撑物承载立方体`i..k`，不仅仅是上面的立方体`i`。

 ## 边缘情况

 考虑严格边界情况：```
2
0 0 4 4
2 0 6 4
```立方体 2 有中心`x = 4`。 与立方体 1 的重叠为`[2,4]`。 由于中心正好位于边界上，因此支撑不稳定。 

该算法计算：

 | 数量 | 价值|
 | --- | --- |
 | 重叠| (2,4) |
 | 质心| 4 |
 | 检查 | 2 < 4 < 4 | 2 < 4 < 4

 最后一个不等式失败，所以答案变成`1`。 

现在考虑累积不平衡：```
3
0 0 10 10
4 0 14 10
8 0 18 10
```立方体3单独稳定在立方体2上。危险的部分是下部支撑。 

对于立方体 1 和 2 之间的支撑：

 | 数量 | 价值|
 | --- | --- |
 | 群众 | 1000 和 1000 |
 | 中心 | 9 和 13 |
 | 组合 COM | 11 | 11
 | 重叠| (4,10) |

 自从`11`位于重叠区域之外，下方支撑失效。 该算法在处理向下累积和时检测到这一点。 

最后，考虑坐标标准化：```
2
4 4 0 0
1 1 3 3
```第一个方格以相反的顺序给出。 如果没有标准化，边长将变为负值并且重叠逻辑会中断。 

该算法交换坐标，使每个方块变成：```
(0,0)-(4,4)
(1,1)-(3,3)
```归一化后，所有几何计算都能正常工作，输出为`2`。
