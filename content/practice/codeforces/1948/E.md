 ## 解决方案
 ## 问题理解

 我们被要求构建一个图表$n$以一种非常具体的方式处理顶点：每个顶点接收一个不同的整数$1$到$n$，然后我们连接两个顶点$i$和$j$如果它们的索引差和值差之和不超过给定阈值，则具有边缘$k$。 构造好图后，我们需要将其划分为最少数量的派，每个顶点恰好属于一个派。 我们被要求输出整数对顶点的分配和团划分。 

输入给出多个测试用例，每个测试用例指定$n$和$k$。 小界限$n \le 40$允许具有组合步骤的算法，这对于较大的图是不可行的。 约束条件$k \le 2n$意味着许多顶点可以潜在地连接，但不一定是全部。 尝试每个整数排列以最小化派系数量的简单解决方案太慢了，因为有$n!$可能的任务，即使对于$n=15$。 

边缘情况发生时$k$非常小或非常大。 例如，如果$k \ge 2(n-1)$，那么无论整数分配如何，每个顶点都连接到每个其他顶点，因此该图是单个团。 相反，如果$k = 1$，只有索引和值相差最小的顶点才能连接，可能会迫使每个顶点进入自己的集团。 不考虑这些极端情况的粗心实现可能会输出不可能的分区。 

## 方法

 蛮力方法就是尝试所有的方法$n!$的排列$[1, 2, \dots, n]$，为每个构建图，然后计算最小派分区。 对于每个排列，检查边缘需要$O(n^2)$，并且找到最小的派系覆盖是一个 NP 难题。 即使与$n=10$，这会导致超过 300 万种排列，这对于$n$最多 40 个。 

关键的见解是添加边缘的条件仅取决于差值之和$|i-j| + |a_i - a_j|$。 为了最大限度地提高连通性，我们希望指数和值沿相反方向变化，以便它们的差异相互补偿。 一种简单的方法是按大小块分配整数$k$，确保同一块中的任意两个顶点满足$|i-j| + |a_i - a_j| \le k$。 具体来说，按顺序对顶点进行编号并按升序分配连续整数可以实现这一点。 那么团划分就自然而然地发生了：同一块中的顶点形成一个团。 

我们可以通过将顶点划分为不同大小的组来形式化这一点$\lceil n/k \rceil$。 在每个组内，索引差值与分配的整数差值之和永远不会超过$k$。 每个团体都成为一个派系。 这种建设性的策略完全避免了暴力搜索，并保证了问题约束下的最小派系数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n! * n^2) | O(n! * n^2) | O(n^2) | O(n^2) | 太慢了 |
 | 构造性块分配 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和$k$。 为顶点分配初始化一个数组$a$和派系标签$c$。 
2. 确定最少的派系数量，$q$， 作为$\lceil n/k \rceil$。 每个派系最多有$k$顶点以确保连通性。 
3. 将整数从 1 到$n$。 这确保了每个整数都是不同的（根据需要）。 
4. 将顶点划分为连续大小的块$k$。 为块中的所有顶点分配相同的团标签。 最后一个块可能小于$k$。 
5.输出整数赋值数组$a$, 派系数量$q$，以及派系标签$c$。 

为什么有效：对于同一块中的任意两个顶点，它们的索引差最多为$k-1$并且它们的整数差最多为$k-1$，所以他们的总和最多是$2(k-1) < 2k$，满足边缘条件。 超出阈值的不同块中的顶点之间不存在边，这保证了每个块都是最大的并形成团。 这保证了最少的派系数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(range(1, n+1))
    
    # minimal number of cliques
    q = (n + k - 1) // k
    
    # assign clique labels
    c = []
    for i in range(n):
        c.append(i // k + 1)
    
    print(' '.join(map(str, a)))
    print(q)
    print(' '.join(map(str, c)))
```该解决方案首先读取测试用例的数量。 对于每种情况，它都会构建整数数组$a$作为从 1 到$n$。 最小团数是通过上限除法计算的。 团标签是通过将顶点索引除以来分配的$k$并加一以确保标签从 1 开始。使用整数除法可确保块的大小达到$k$。 打印遵循所需的输出格式。
