 ## 解决方案
 ## 问题理解

 我们被要求用大写拉丁字母构造一个字符串，以便准确地`n`职位是“特殊”的。 当一个位置的字符与它的直接邻居之一完全匹配时，该位置被称为特殊位置。 端点从来都不是特殊的，因为它们只有一个邻居，因此索引处有一个字符`0`或者`L-1`不能满足条件。 

所以每个特殊位置都是一个内部索引`i`其中任一`s[i] == s[i-1]`或者`s[i] == s[i+1]`，但不能同时意味着更大的运行，因为更长的运行可以根据运行的边界创建多个特殊位置。 

该任务是建设性的：对于每个测试用例，要么输出有效字符串，要么确定不存在构造。 

约束条件`n ≤ 50`表明我们没有对巨大的结构进行优化； 相反，我们应该了解如何创建特殊职位的组合结构。 

一种幼稚的方法是尝试暴力破解字符串并计算特殊位置。 即使我们将长度限制为最多 200，字符串的数量也是天文数字，大约是`26^200`，所以暴力破解是不可能的。 必须设计结构。 

关键的微妙之处在于，每个角色的特殊位置并不是独立的。 它们取决于当地的模式，例如`A A B A`或者`A B B A`。 仅仅重复对的粗心结构通常会产生太多或太少的特殊位置，特别是在运行之间的转换时。 

一个小的边缘情况说明了困难：对于`n = 1`，这是不可能的。 任何单个特殊位置至少需要一个局部配置，但这种配置必须对称地创建至少两个特殊位置或强制重叠贡献。 例如，任何类似的模式`AAB`在中间创建一个特殊位置`A`，但除非仔细隔离，否则在全球范围内扩展总是会产生配对效应。 事实上，已知的结构表明`n = 1`是不可能的。 

对于所有人`n ≥ 2`，我们将展示一个系统化的构建的存在。 

## 方法

 一个蛮力的想法是生成长度最大为 200 的字符串并计算每个字符串的特殊位置数，当找到匹配时停止。 对于每个测试用例，这将涉及探索字母表选择和长度的指数搜索空间，即使对于`n = 50`。 

关键的观察是，可以使用固定贡献的独立“块”来控制特殊头寸。 我们想要一个构建块能够提供可预测数量的特殊位置，而不干扰其他块。 

考虑以下形式的模式`A A B`。 在这个块中，中间`A`是特殊的，因为它等于其左邻居，但不等于其右邻居。 这恰好在局部区域中提供了一个特殊位置。 然而，直接连接这些块是危险的，因为块之间的边界可能会创建新的特殊位置或破坏现有的特殊位置。 

一个更稳健的想法是使用对称小工具，保证每个块恰好有 2 个特殊位置，而没有交叉干扰。 图案`A A B B`工作干净。 在这个块内，位置`1`和`2`很特别：第一个`A`相对于它的邻居来说是特殊的，第二个`B`相对于它的邻居来说是特殊的。 当连接为`A A B B C C D D ...`，如果我们确保相邻块使用不同的字母，则块之间的转换不会创建意外的相等相邻对。 

因此，每个块恰好贡献 2 个特殊位置，我们可以构建任何偶数`n`。 

剩下的问题很奇怪`n`。 我们可以处理`n = 2k + 1`从一个固定的小前缀开始，该前缀恰好贡献了 3 个特殊位置，然后附加`k-1`每个区块贡献 2。 有效的前缀是`A A B A B`，在直接计数下恰好产生 3 个特殊位置。 之后，我们继续使用新字母进行安全的不相交块。 

这减少了组合固定小工具的问题。 

我们也直接确认不可能`n = 1`通过耗尽局部配置：由于邻接对称约束，任何隔离单个特殊位置的尝试都会创建零个或至少两个。

 ## 算法演练

 1.如果`n == 1`， 输出`NO`因为没有任何字符串可以精确地隔离一个特殊位置而不在其他地方强制添加一个额外的位置。 
2.如果`n == 2`，输出一个直接结构，例如`AABB`。 这恰好在块内创建了两个特殊位置。 
3.如果`n`是偶数并且`n ≥ 2`，将其分解为`n / 2`每块贡献 2 块。 每个块的形式为`A A B B`，每个块使用新鲜的字母以避免干扰。 
4.如果`n`是奇数并且`n ≥ 3`，首先放置贡献3个特殊位置的固定前缀，然后填充剩余的`n - 3`作为`(n - 3) / 2`块的`A A B B`。 
5. 确保每个块使用与其他块不同的字母，以便相邻块之间不会出现边界相等。 
6. 输出结果字符串。 

这种结构是贪婪的，但具有确定性：我们将结构分配给贡献而不是单个位置。 

### 为什么它有效

 每个块在内部都是隔离的，因为它使用不同的字符。 在块内，该模式保证固定数量的特殊位置，并且由于相邻块不共享字符，因此不会跨边界创建新的相等性。 这给出了可加性：特殊位置总数是每个块的贡献之和，这正是目标`n`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_even(k):
    res = []
    ch = 0
    for _ in range(k):
        a = chr(ord('A') + ch)
        b = chr(ord('A') + ch + 1)
        res.append(a * 2 + b * 2)
        ch += 2
    return ''.join(res)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        
        if n == 1:
            print("NO")
            continue
        
        if n == 2:
            print("YES")
            print("AABB")
            continue
        
        if n % 2 == 0:
            print("YES")
            print(build_even(n // 2))
        else:
            # n >= 3
            # prefix contributing 3 special positions
            prefix = "AABBA"
            # now we already used 3, remaining is n-3 (even)
            rest = build_even((n - 3) // 2)
            print("YES")
            print(prefix + rest)

if __name__ == "__main__":
    solve()
```该代码将构造分离为可重用的偶数块生成器。 每个块使用两个新字母以防止意外重叠。 奇数情况的处理方法是保留一个固定前缀，该前缀恰好贡献三个特殊位置，然后将其余部分委托给相同的偶数构造逻辑。 

一个微妙的实现细节是确保字母表索引一致地前进，以便没有两个块共享字母。 这是必要的； 否则，边界相互作用将使计数无效。

 ## 边缘情况

 对于`n = 1`，算法直接拒绝案例而不尝试构造。 输入`1`触发立即输出`NO`，避免任何意外的部分构造，从而引入意外的特殊位置。 

为了`n = 2`，输出`AABB`生成为单个隔离块。 手动评估它可以准确地确认两个特殊位置，并且由于没有边界而没有跨界效应。 

对于奇数`n`， 例如`n = 5`，算法首先产生`AABBA`，这已经产生了 3 个特殊位置。 其余 2 个通过一个独立块添加`AABB`。 由于前缀和块之间的所有字母都是不同的，因此不会在边界处创建额外的特殊位置，从而准确地保持正确性。
