 ## 解决方案
 ## 问题理解

 我们得到一排石头，其中每块石头都有一种颜色，由字符串表示。 目标是变换该行，以便没有两个相邻的石头具有相同的颜色。 我们不允许重新排列石头； 相反，我们可以移除石头。 任务是确定所需的最小删除次数，以便剩余序列中没有连续的相同字符。 

换句话说，我们希望通过删除尽可能少的字符来将字符串压缩为“严格交替邻接”序列。 最终序列必须保留原始顺序，但允许任意数量的删除。 

此问题中的输入大小很小（典型的 Codeforces 版本的 n 最多为 50），这立即表明即使具有小常数的二次或线性扫描也足够了。 任何超出 O(n²) 的操作都是不必要的，甚至 O(n²) 也太过分了。 

当字符串已经有效或所有字符都相同时，就会出现关键边缘情况。 

例如，如果输入是`BRBG`，没有两个邻居是相等的，所以答案是 0。如果输入是`RRRRR`，我们必须只保留一个字符，因此我们删除 4 个。 

朴素方法的一个微妙的失败模式是尝试“模拟删除”，同时向前迭代而不仔细处理移动索引。 例如，在`RBBR`，如果你贪婪地删除而不重新检查新的相邻对，你可能会错误地删除超过必要的数量，或者在一次删除后结构发生变化而错过。 

正确的解决方案完全避免模拟，而是直接计算结构。 

## 方法

 暴力破解的想法是明确尝试删除字符子集并检查结果字符串是否没有相等的相邻对。 对于每个子集，我们重建字符串并在 O(n) 时间内验证它。 由于有 2ⁿ 子集，即使对于适度的 n，这也很快变得不可行； 当 n = 50 时，这是一个天文数字，完全无法使用。 

关键的观察是，我们实际上不需要决定保留哪些字符，只需决定原始字符串中存在多少个连续的相等对。 每当我们看到两个相同的相邻字符时，至少必须删除其中一个。 如果我们从左到右扫描并计算有多少个位置 i 满足 s[i] == s[i−1]，则每次出现这样的情况都代表最佳策略中需要的一个删除。 

这是可行的，因为任何长度为 k 的相同字符的最大块都可以减少为单个字符，需要恰好 k−1 次删除。 将所有运行的结果相加即可得到答案。 

这将问题从组合选择问题转变为对相同字符运行的线性传递。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力子集 | O(2ⁿ·n) | O(2ⁿ·n) | O(n) | 太慢了 |
 | 扫描相同字符的运行 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 开始从左到右扫描字符串，维护删除计数器。 
2.对于从1开始的每个位置i，将当前字符与前一个字符进行比较。 
3. 如果它们相等，则增加删除计数器，因为必须删除其中之一才能打破邻接关系。 
4. 继续浏览该字符串而不对其进行修改。 
5. 扫描完成后输出增量总数。 

每个增量完全对应于连续的相同字母块中的一个“额外”字符，该字符不能保留在最终的有效序列中。 

### 为什么它有效

 字符串可以唯一地分解为相同字符的最大段。 在长度为 k 的段中，任何有效的最终序列最多只能保留该段中的一个字符，因为保留两个字符将立即违反邻接规则。 因此，该片段的最小删除量为 k−1。 对所有段求和 k−1 相当于计算 s[i] == s[i−1] 的转换，这正是该算法的作用。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    s = input().strip()

    deletions = 0

    for i in range(1, n):
        if s[i] == s[i - 1]:
            deletions += 1

    print(deletions)

if __name__ == "__main__":
    solve()
```该解决方案依赖于单个线性扫描。 变量`deletions`准确跟踪原始字符串中存在多少个相邻的相等对。 我们从不修改字符串，这避免了贪婪模拟方法中常见的索引移位错误。 

循环从索引 1 开始，因为每次比较都是针对前一个字符。 这避免了越界检查并干净地捕获每个邻接一次。

 ## 边缘情况

 单字符字符串不包含相邻对，因此扫描永远不会递增计数器，并且输出正确为 0。该算法自然地处理此问题，因为循环从索引 1 开始并且永远不会执行。 

完全统一的字符串，例如`RRRRR`每一步都会产生一个增量，恰好累积 n−1 次删除。 这符合只能保留一个字符的要求。 

Strings with alternating structure like`RGBRGB`不产生相等的相邻对，因此删除计数保持为零，从而确认不会触发不必要的删除。 

具有混合块的字符串，例如`RBBR`表明只有内部重复才重要。 两个连续的 B 恰好贡献了一个缺失，并且没有其他位置影响结果。
