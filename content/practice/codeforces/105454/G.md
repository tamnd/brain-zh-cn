 ## 解决方案
 ## 问题理解

 我们正在处理存在两篮子苹果的情况。 一篮子含有已知数量$X$，第二个包含未知的正数$Y$，严格小于$X$。 所以苹果的总数是$S = X + Y$，我们知道$1 \le Y \le X-1$，这意味着$X+1 \le S \le 2X-1$。 

一群兄弟首先将所有苹果均分。 然后一个姐妹加入，所有的苹果又被收集起来，同一组现在也包括了姐妹。 关键的限制是两个部分都完全均匀，没有剩余的苹果。 此外，每个兄弟在第二级比赛中收到的苹果都比第一级比赛中少了一个苹果。 

任务不是重建苹果的数量，而是确定可能存在多少个兄弟。 在所有符合约束的有效配置中，我们必须输出可能的最小和最大兄弟数。 

约束条件$X \le 10^{18}$强制每个测试用例的任何解决方案至多是对数或常数时间。 任何迭代所有可能的兄弟计数的方法都太慢，因为候选者的数量可能会达到大约$10^9$或更多。 

隐藏变量引起了一个微妙的问题$Y$。 天真的方法可能会尝试所有可能的方法$Y$然后检查每个兄弟数的整除条件。 这会立即导致二次或更差的搜索空间，并且无法在约束下工作。 

第二个常见的陷阱是忘记二除法包括姐妹，这会改变除数$k$到$k+1$。 缺少这一点会导致不正确的线性方程和不一致的约束。 

## 方法

 设兄弟数为$k$。 在第一次分裂中，每个兄弟都收到$\frac{S}{k}$， 在哪里$S = X+Y$。 在第二次分裂中，有$k+1$人，所以每个人都会收到$\frac{S}{k+1}$。 声明说差异恰好是一个苹果，所以$$\frac{S}{k} - \frac{S}{k+1} = 1$$蛮力的想法是尝试所有的值$k$，并且对于每个，尝试所有有效的$Y$，检查两个除法是否是整数并且差值条件成立。 自从$X$可以达到$10^{18}$,$Y$也可以很大，并且$k$范围大约可以达到$\sqrt{X}$或更多。 这导致搜索空间不可行。 

关键的观察结果是上面的方程完全破坏了结构。 差异简化为$$S \cdot \frac{1}{k(k+1)} = 1$$哪些力量$$S = k(k+1)$$所以苹果的总数完全由下式决定$k$。 这消除了$Y$完全。 自从$S = X + Y$，我们得到$$Y = k(k+1) - X$$现在的情况$1 \le Y \le X-1$变成$$X+1 \le k(k+1) \le 2X-1$$所以问题简化为找到所有整数$k$这样$k(k+1)$位于固定区间内。 这是一个单调二次函数，因此有效$k$形成一个连续的线段，我们只需要最小和最大的整数解。

 ## 算法演练

 我们将条件重写为$k$，然后求解两个边界不等式。 

1. 将苹果总数表示为$S = k(k+1)$。 这直接来自于简化两个等分之间的差异条件。 
2. 将未知的第二个篮子大小转换为$Y = S - X = k(k+1) - X$。 这将未知量与已知量联系起来$X$。 
3. 强制第二个篮子的有效性：因为它必须包含至少一个苹果且少于$X$，我们得到$1 \le k(k+1) - X \le X-1$。 
4. 重新排列为纯约束$k$：$X+1 \le k(k+1) \le 2X-1$。 这消除了对$Y$。 
5. 求解下界不等式$k(k+1) \ge X+1$通过找到最小的整数$k$其二次值达到阈值。 
6. 求解上界不等式$k(k+1) \le 2X-1$通过找到最大的整数$k$即不超过阈值。 

结果是一个连续的有效区间$k$，所以答案就是这个区间的端点。 

### 为什么它有效

 功能$f(k) = k(k+1)$对于正整数是严格递增的。 一旦我们将问题转化为边界问题$f(k)$在一个区间内，每个有效解恰好对应一个整数$k$，并且没有间隙。 这保证了计算第一个和最后一个整数解能够充分表征所有可能的兄弟数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def floor_sqrt(x):
    r = int(x ** 0.5)
    while (r + 1) * (r + 1) <= x:
        r += 1
    while r * r > x:
        r -= 1
    return r

X = int(input())

# k(k+1) >= X+1
low = X + 1
high = 2 * X - 1

def min_k(low):
    # k^2 + k - low >= 0
    # k >= (-1 + sqrt(1 + 4*low)) / 2
    t = floor_sqrt(1 + 4 * low)
    return ( -1 + t + 1 ) // 2

def max_k(high):
    # k^2 + k - high <= 0
    # k <= (-1 + sqrt(1 + 4*high)) / 2
    t = floor_sqrt(1 + 4 * high)
    return ( -1 + t ) // 2

l = min_k(low)
r = max_k(high)

print(l, r)
```实现的核心是将二次不等式转换为整数平方根计算。 由于值上升到$10^{18}$，浮点平方根不安全，因此使用受控整数平方根。 

这`min_k`函数计算最小整数$k$满足下界。 它使用二次公式并注意向上舍入。 这`max_k`函数对上限执行相同的操作，但向下舍入。 

正确性取决于使用整数安全的平方根计算； 即使很小的浮点精度误差也可能使边界移动一位并破坏正确性。

 ## 边缘情况

 对于$X = 4$，尽可能小的输入，有效范围极其严格。 不平等减少到$5 \le k(k+1) \le 7$，并且仅$k = 2$满足这一点。 该算法正确计算平方根边界并返回单个值区间。 

对于大型$X$， 例如$X = 10^{18}$，界限涉及到的数字$2 \cdot 10^{18}$。 使用整数平方根可以避免浮点精度问题。 计算的边界保持稳定，因为所有运算都是基于整数的，确保不会因舍入而发生相差一的错误。
