 ## 问题理解

 两名玩家轮流从一堆$N$糖果。 第一个玩家开始，每次移动时，玩家都会移除一定数量的糖果，但数量必须是 2 的幂，这意味着移动集是$1, 2, 4, 8, 16, \dots$。 谁拿走最后一颗糖果，谁就获胜。 

任务是确定完美比赛下的结果。 如果第一个玩家（Potap）可以强行获胜，我们输出 1。如果第二个玩家（Vitya）可以强行获胜，我们输出 2。如果游戏结果不是唯一确定的，我们输出 3。 

约束条件$N \le 10^{18}$迫使我们避免任何国家对立场的探索。 甚至对所有值进行动态规划$N$是不可能的，因为$N$远远超出了$10^7$。 任何解决方案都必须将问题简化为封闭形式的表征或从二进制结构计算出的极少数情况。 

移动集的大小不受限制会产生一个微妙的问题。 尽管每次移动都限制为 2 的幂，但最大的移动取决于$N$，这常常会导致人们对贪婪游戏是否有效感到困惑。 另一个边缘情况是较小的值$N$，其中前几个位置有时可能会暗示稍后会打破的模式。 

例如，当$N = 1$，第一个玩家立即获胜。 什么时候$N = 3$，第二个玩家在最佳玩法下获胜，因为每一步都会留下失败的位置。 然而，对于稍大的值，如果天真地解释，结构就会变得不规则，这就是为什么直接模拟移动“取两个不超过的最大幂”的原因$N$”未能捕捉到最佳发挥。

 ## 方法

 暴力方法将游戏建模为整数的状态图$0$到$N$，其中来自每个州$x$我们过渡到$x - 2^k$为所有人$2^k \le x$。 如果每个州至少有一次向失败州移动，则该州获胜。 这在原则上是正确的，并且可以通过动态规划来计算。 

问题在于规模。 状态数为$N$，每个州最多有$O(\log N)$过渡。 即使我们只考虑最多$10^6$，该结构已经变得昂贵，并且对于$10^{18}$这是完全不可行的。 暴力破解依赖于枚举所有可到达的位置，这是真正的瓶颈。 

关键的观察是所有移动大小都是 2 的幂，因此每次移动都会修改$N$以结构化的方式。 这意味着游戏从根本上讲是关于位操作而不是整数的组合搜索。 我们可以推断在最佳游戏下最低有效位如何演变，而不是跟踪所有可能的减法。 

重新解释游戏的一个有用方法是，每次移动都会从某个位置删除一个 1 位，或者有效地减去 2 的幂，这与二进制奇偶校验和最低设置位干净利落地相互作用。 这将状态空间简化为关于移动奇偶性和二进制形式的尾随移动的结构的推理。 

一旦使用了这种二进制结构，游戏就会根据是否$N$是奇数、2 的幂，或者具有更复杂的二进制模式。 这些案例足以确定第一个玩家是否可以强行获胜，或者结果是否取决于导致问题意义上的模糊解决方案的最佳选择。

 ## 算法演练

 该解决方案完全由二进制表示的属性驱动。 

1.如果$N = 1$，第一个玩家拿走唯一的糖果并立即获胜。 这是基本终端位置。 
2. 检查是否$N$是二的幂。 这可以使用标准身份来完成$N \& (N - 1) = 0$。 在这种情况下，第一个玩家总是可以拿走$N$一招立即结束比赛。 
3.如果$N$不是二的幂，检查它是否具有以下形式$2^k - 1$，意味着所有二进制位都是 1。这个类很特殊，因为每次移动都会减去 2 的幂，并且总是创建一个具有非常结构化的二进制形状的数字，迫使对手做出对称响应。 
4. 对于所有剩余值，该位置包含二进制形式的 0 和 1 位的混合。 在这些情况下，第一个玩家的举动会迫使第二个玩家进入失败配置，因为在减去 2 的幂时结构不会保持对称。 

最终的决策是通过分类做出的$N$分为这三个结构类别并返回相应的结果。 

### 为什么它有效

 每一步都对应于减去 2 的一次幂，这会以受控方式精确修改一位，可能会导致借位。 关键的不变量是游戏状态完全由尾随模式和最高设置位分布决定。 这强烈地限制了状态的演化，以至于只有少数规范的二进制形式在最佳游戏下表现不同。 

因为每个可达状态都是由确定性位转换而不是任意分支决定的，所以位置属于一小组等价类。 在每个类别中，最佳游戏都是强制的，而不取决于任意选择。 这将游戏分解为确定性分类问题。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    # case 1: single candy
    if n == 1:
        print(1)
        return
    
    # case 2: power of two
    if n & (n - 1) == 0:
        print(1)
        return
    
    # case 3: all ones in binary (2^k - 1)
    if (n & (n + 1)) == 0:
        print(2)
        return
    
    # general case
    print(1)

if __name__ == "__main__":
    solve()
```第一个分支处理简单的终止状态。 

第二个分支使用标准位技巧检测 2 的幂。 这是第一个玩家可以通过一次移动消除所有糖果的唯一情况，这始终是最佳的。 

第三个分支检测以下形式的数字$2^k - 1$。 这些正是其二进制表示仅由 1 组成的整数，并且它们的行为不同，因为每次减法都会引入进位，从而为第二个玩家保留某种对称性。 

所有剩余的数字都属于混合二进制结构，其中第一个玩家可以立即强制不对称并获胜。

 ## 边缘情况

 最小的情况$N = 1$立即终止游戏，算法通过基本条件正确地将其分类为第一个玩家获胜。 

为了$N = 2^k$，该算法识别单组位结构并返回第一玩家获胜。 例如，$N = 16$满足$16 \& 15 = 0$，因此分类正确。 

为了$N = 2^k - 1$， 例如$N = 7$，条件$(N \& (N+1)) = 0$触发，第二个玩家被宣布为获胜者。 这捕获了完全饱和的二元形式，其中每一步都会引入有利于第二个玩家的响应对称性。 

对于混合情况，例如$N = 6$, 二进制$110$，这两个特殊条件都不适用，因此算法返回先手获胜，这反映了位结构中的不对称性破坏了全 1 情况下可用的防御对称性。
