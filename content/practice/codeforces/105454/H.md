 ## 解决方案
 ## 问题理解

 给定一个从 a 到 b 的整数区间，我们需要计算这个区间内有多少个数字恰好有 6 个正因数。 对于范围内的每个整数 x，我们从概念上对它进行因式分解，确定它有多少个除数，并检查该计数是否等于 6。 

天真的解释立即建议迭代范围内的每个数字并独立计算其除数计数。 当 b 达到 5000 万时，区间很容易包含数千万个值，因此任何为每个数字花费 O(√n) 的解决方案都会变得太慢。 每个数字的直接除数枚举需要 (b − a + 1) × √b 运算量级，这远远超出了典型限制。 

除数计数条件本身出现了一个更微妙的问题。 恰好有六个除数的数字在结构上受到限制，因此简单的计数会重复地重新计算相同的模式。 例如，32 的约数为 {1, 2, 4, 8, 16, 32}，44 的约数为 {1, 2, 4, 11, 22, 44}。 两者都是方形素数权力结构的产物，但暴力方法无法利用这一点。 

边缘情况来自小范围和边界值。 例如，如果 a = b = 1，则答案为 0，因为 1 只有一个除数。 如果 a = 32 且 b = 32，则答案为 1，因为 32 有效。 粗心的方法还可能根据不正确的除数计数错误地包含 36 或 64 等数字，因为它们需要正确的指数处理而不是简单的部分因子测试。 

关键的观察结果是，“恰好六个除数”是一个非常强的算术约束，它使我们能够明确地表征所有有效数字，而不是逐一计算除数。 

## 方法

 暴力方法迭代区间中的每个整数，并通过检查所有数字直到其平方根来计算其除数。 这是可行的，因为一旦 d 达到 √x 就可以找到每个除数对 (d, x/d)，因此正确性很简单。 然而，其成本以 O(n√n) 的速度增长，因为在最坏的情况下，多达 5000 万个数字中的每个数字可能需要大约 7000 次检查，从而导致运行时间不可行。 

关键的结构见解是停止以“计算 x 的除数”的方式思考，而是对所有恰好具有六个除数的整数进行分类。 

数字 x 仅在两种情况下有六个约数。 它要么是 p^5 的形式，其中 p 是素数，给出约数 1、p、p^2、p^3、p^4、p^5，要么是 p^2 q 的形式，其中 p 和 q 是不同的素数。 这些是唯一能产生恰好为 6 的除数计数乘积的素因式分解，因为除数函数是乘法函数，我们需要 (e1 + 1)(e2 + 1) ... = 6。6 的因式分解是 6 和 2 × 3，它们与这两个结构完全对应。 

这将问题简化为生成直到 b 的这两种形式的所有数字，并计算有多少个位于 [a, b] 中。 我们不是处理每个整数，而是生成一个小的候选集。 由于直到 √b 的素数足以用于构造，因此即使在最大约束下，候选总数也是可控的。

 ## 算法演练

 我们首先使用筛子预先计算 √b 以内的素数，因为所有有效的构造都依赖于这个范围内的素数。

1. 使用埃拉托色尼筛生成直到 √b 的所有素数。 这确保我们可以有效地测试和构造 p^2 q 形式的数字。 
2. 迭代每个素数 p 并生成 p^5。 如果p^5在[a,b]之内，则计数。 这直接处理第一个结构情况。 
3. 迭代每个素数 p 并计算 p^2。 对于每个这样的值，迭代所有素数 q（其中 q ≠ p），并形成 p^2 · q。 如果结果在[a,b]中，则进行计数。 这涵盖了第二种结构情况。 
4. 将所有有效数字累加到一组或直接计数。 使用集合可以避免在不同的表示产生相同的值时可能出现的重复，尽管在这种结构中，如果仔细处理，重复实际上是不可能的。 
5. 输出最终计数。 

### 为什么它有效

 每个恰好有六个除数的整数都必须有一个素数分解，其指数模式乘以六。 唯一有效的模式是单个素数的五次方或一个素数的平方与另一个素数的一次幂的乘积。 该算法准确地枚举了这些情况，而不是其他情况，因为它使用直到 √b 的完整素数集系统地构造了与这些指数模式匹配的所有数字。 这些形式之外的任何整数要么因数太少（质数幂太小），要么太多（多个更高的指数或额外的质因数），因此它被正确排除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(n**0.5) + 1):
        if is_prime[i]:
            step = i
            start = i * i
            for j in range(start, n + 1, step):
                is_prime[j] = False
    return [i for i in range(2, n + 1) if is_prime[i]]

def solve():
    a, b = map(int, input().split())
    limit = int(b ** 0.5) + 1

    primes = sieve(limit)

    ans = 0
    used = set()

    for p in primes:
        v = p ** 5
        if a <= v <= b:
            if v not in used:
                used.add(v)
                ans += 1

    for i, p in enumerate(primes):
        p2 = p * p
        if p2 > b:
            break
        for j, q in enumerate(primes):
            if q == p:
                continue
            v = p2 * q
            if v > b:
                continue
            if v >= a and v not in used:
                used.add(v)
                ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```筛子构造最大到 √b 的素数，这已经足够了，因为 p^2 q 或 p^5 形式的任何有效数必须至少有一个不超过 √b 的素因数。 

第一个循环显式处理 p^5。 这种情况很少见，但必须直接检查，因为它不适合 p^2 q 结构。 

第二个嵌套循环构建 p^2 q。 检查 q ≠ p 可以防止意外地处理同一个素数两次，这对应于 p^3，不是一个有效的结构。 

该集合确保唯一性，尽管如果枚举一致，则不会发生数学上的重复； 它可以防止实施重叠。

 ## 边缘情况

 一个关键的边缘情况是当区间仅包含小素数及其幂时。 例如，输入 1 到 10 不会产生有效数字。 该算法正确地处理了这个问题，因为 p^5 和 p^2 q 都不能在该范围内形成。 

另一种边缘情况是当 p^2 q 与不同的对重合时。 例如，p = 2 和 q = 3 给出 12，而没有其他对产生 12，因此不会出现重复。 即使枚举顺序不完善，实现中的集合也能保证安全。 

最后，当 a 和 b 很大并且有紧密边界时，例如 [49999990, 50000000]，该算法仍然只评估少量候选素数，因为生成与区间密度无关。 无论范围放置如何，这都可以确保一致的性能。
