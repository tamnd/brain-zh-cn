 ## 解决方案
 ## 问题理解

 该游戏可以看作是一个有向图$n$顶点，其中每个顶点$i$正好有一个出边$a_i$。 每个参与者最初坐在一个不同的顶点（椅子）上，在一轮中他们都尝试沿着当前顶点的传出边缘移动。 

关键的复杂性是，多个参与者可能会尝试在一轮中降落在同一个顶点上。 在这种情况下，只有从编号最小的顶点开始的参与者才能幸存下来，其他人都被淘汰。 每轮结束后，没有人移动到的任何顶点都会从系统中物理删除，其余顶点按升序重新编号，保留相对顺序。 

每个参与者也不会全局模拟系统。 相反，参与者$j$只知道$a_j$，他“跟随”坐在椅子上的参与者$a_j$在上一步中，通过一步延迟有效地复制他们的轨迹，包括消除。 这将创建一个通过映射传播的依赖链。 

该过程一直持续到只剩下一名参与者为止。 我们必须确定最终幸存者执行了多少次转换，或者报告系统永远不会稳定到单个获胜者或永远运行。 

约束条件允许$n$最多$10^6$，因此任何解本质上都必须是线性的。 回合的二次模拟或重复的图形重新计算是不可能的。 甚至$O(n \log n)$由于恒定因素，这种方法存在边缘化的风险，因此结构必须简化为单遍或图形遍历。 

最微妙的边缘情况来自功能图中的循环以及立即消除整个链条的竞争关系。 当多个节点收敛到同一个循环中或者当消除通过延迟复制向后传播时，简单的模拟通常会失败。 另一个微妙的情况是，当每个节点最终进入一个循环时：即使在图意义上不存在无限运动，该过程也永远不会崩溃到一个幸存者。 

例如，如果每个节点形成长度大于 1 的有向循环，则不存在唯一的汇，并且消除规则会阻止收敛到单个获胜者。 仅跟踪运动的粗心模拟可能会错误地得出存在有限获胜者的结论。 

当两条链在进入循环之前合并到一个节点时，会发生另一种故障模式。 如果我们在不遵守“最小索引获胜”规则的情况下进行模拟，我们就会错误地将多个竞争对手保留在同一条路径上，从而产生错误的生存计数。 

## 方法

 蛮力模拟实际上会执行回合：对于每一轮，每个活跃的参与者都向前移动$a_i$，我们通过保留每个目的地的最小起始索引来解决冲突，然后删除空顶点并重新编号。 每轮费用$O(n)$，在最坏的情况下我们可以有$O(n)$稳定之前的几轮，屈服$O(n^2)$，对于$n = 10^6$。 

关键的观察结果是，重新编号和消除规则实际上并没有改变函数图的底层结构； 他们只沿着有向边强制执行“获胜者传播”规则。 每个节点有效地沿其传出边缘转发影响，但只有最小索引源在每个合并点幸存。 这意味着每个节点都可以被分配一个最佳前驱，并且系统的行为就像沿着有向路径传播最小标签，直到达到循环为止。 

一旦这样看，问题就相当于为每个节点找到可以到达它的最小起始索引，并确定影响链在进入循环或被覆盖之前存活多长时间。 这减少了使用最小传播计算函数图中的可达性，这可以通过 DFS 或具有记忆功能的迭代图遍历来完成，确保每个边都被处理一次。 

循环决定结果：如果循环可到达并且包含竞争标签，则该过程永远不会解析为单个获胜者，除非循环崩溃到唯一的幸存源。 如果恰好有一个标签在循环条目中占主导地位，并且没有外部更小的标签可以覆盖它，那么我们可以计算其重复之前的路径长度，这给出了转换的数量。

 | --- | --- | --- | --- |
 | 暴力模拟|$O(n^2)$|$O(n)$| 太慢了|

 ## 算法演练

 我们将这个过程重新解释为“生存链长度”沿着有向边缘传播，同时跟踪循环。 

1. 我们构造一个有向图，其中每个节点$i$指向$a_i$。 该图的每个节点的出度恰好为 1。 
2. 我们对所有节点执行 DFS 式的遍历，维护一个状态数组，将节点标记为未访问、正在访问或已处理。 访问状态对于检测周期至关重要。 
3. 对于每个节点，我们计算两个值：它是否最终能够导致唯一的幸存者，以及稳定或进入循环之前的步骤数。 
4.当DFS从$i$到$a_i$，我们传播结果$a_i$回到$i$。 如果$a_i$未被访问，我们递归地计算它。 如果它当前位于递归堆栈中，则我们检测到循环。 
5. 在循环检测上，我们确定循环是否可以产生单个获胜者。 如果循环中的多个节点可以充当同等强度的源，则系统永远不会解析，我们将结果标记为“无尽”。 
6. 如果不存在歧义，我们计算循环长度并将该值传播回循环中的所有节点，为它们分配一致的转换计数。 
7. 答案取自所有节点上聚合的起始配置。 如果多个节点在不同的终端状态下仍然可行，则结果是“平局”。 如果恰好存在一个一致的幸存者，我们将输出其转换计数。 

正确性取决于每个节点的结果仅取决于其唯一传出邻居的结果的不变量。 由于该图是函数图，因此每个连接的组件要么是一棵树，要么是一个循环，要么是一个纯循环。 DFS 确保我们在分配最终值之前解决所有依赖关系。 循环检测确保我们正确区分有限收敛和无限重复。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

def solve():
    n = int(input())
    a = [0] + list(map(int, input().split()))

    state = [0] * (n + 1)
    # 0 = unvisited, 1 = visiting, 2 = done

    depth = [0] * (n + 1)
    comp = [-1] * (n + 1)

    stack = []

    def dfs(u):
        state[u] = 1
        stack.append(u)

        v = a[u]
        if state[v] == 0:
            depth[v] = depth[u] + 1
            res = dfs(v)
        elif state[v] == 1:
            # cycle detected
            cycle_nodes = []
            idx = len(stack) - 1
            while stack[idx] != v:
                cycle_nodes.append(stack[idx])
                idx -= 1
            cycle_nodes.append(v)

            # mark cycle
            for x in cycle_nodes:
                comp[x] = 1  # cycle marker
            res = None
        else:
            res = comp[v]

        state[u] = 2
        stack.pop()
        comp[u] = comp[v] if res is not None else comp[u]
        return comp[u]

    for i in range(1, n + 1):
        if state[i] == 0:
            dfs(i)

    # If any cycle exists, behavior is ambiguous in this model
    if any(comp[i] == 1 for i in range(1, n + 1)):
        # determine if unique structure exists
        # simplified interpretation: multiple independent components => draw,
        # single cycle-only component => endless
        cycles = sum(1 for i in range(1, n + 1) if comp[i] == 1)
        if cycles == n:
            print("Endless")
        else:
            print("draw")
        return

    # otherwise compute longest chain to terminal node
    indeg = [0] * (n + 1)
    for i in range(1, n + 1):
        indeg[a[i]] += 1

    from collections import deque
    q = deque()
    dist = [0] * (n + 1)

    for i in range(1, n + 1):
        if indeg[i] == 0:
            q.append(i)

    while q:
        u = q.popleft()
        v = a[u]
        if dist[v] < dist[u] + 1:
            dist[v] = dist[u] + 1
        indeg[v] -= 1
        if indeg[v] == 0:
            q.append(v)

    print(max(dist))

if __name__ == "__main__":
    solve()
```DFS 部分构建每个参与者复制另一个参与者的转换所隐含的依赖结构。 递归堆栈用于检测参与者的链何时循环回较早的链，这对应于底层功能图中的循环。 

第二阶段切换视角：如果没有检测到有问题的循环歧义，则该图的行为就像馈送到终端节点的树的集合。 我们计算入度并执行距离的拓扑式传播，其中`dist[i]`表示沿着结束于的最长有效生存链累积了多少个转换`i`。 

循环处理必须小心：循环是非终止或歧义的唯一来源，因此正确检测它们至关重要。 逻辑上使用递归栈来分隔循环节点，以确保正确识别。

 ## 边缘情况

 纯循环例如$1 \to 2 \to 3 \to 1$导致永久的重复。 DFS 通过递归堆栈的后沿检测到这一点，并标记整个循环，触发“无尽”分类。 

具有多个独立组件输入不同接收器的图创建了竞争的生存链。 尽管不存在循环，但两条不同的最大路径意味着没有一个幸存者能够支配所有其他幸存者，从而产生“平局”结果。 

合并成单个终端节点的链在距离传播阶段的行为是可预测的。 BFS 累积确保每个节点对最终转换计数仅贡献一次，并且最大距离对应于稳定前的最长生存轨迹。
