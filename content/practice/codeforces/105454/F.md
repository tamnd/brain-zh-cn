 ## 解决方案
 ## 问题理解

 给定一个循环字母表，编号从 1 到$C$。 单词只是这些数字的序列，我们感兴趣的是查找模式单词的出现$W$在多个文本中。 但是，子字符串不仅在与以下内容相同时才被视为匹配：$W$，而且当它的所有字符在这个循环字母表中移动相同的量时也是如此。 

换句话说，如果我们选择一些移位值$k$，那么每个字符$x$在模式中变成$x + k$（环绕大小字母$C$）。 如果我们可以选择单个移位，则文本的子字符串是有效的$k$将整个模式转换为该子字符串。 

每个查询字符串都是一个文本，对于每个文本，我们必须输出模式可以在某种统一循环移位下出现的所有起始位置。 

这些约束立即排除任何二次子串比较。 所有查询的总文本长度最多为$10^6$，并且模式可以达到$5 \cdot 10^5$。 这迫使每次测试都采用线性或近线性方法，理想情况下对模式进行一次预处理，并对所有文本进行流式匹配。 

当模式长度为 1 时，会出现微妙的边缘情况。在这种情况下，文本中的任何单个字符在选择适当的移位后都会匹配，因此每个位置都是有效的。 一个简单的基于差异的解决方案必须显式处理这个问题，因为否则它会产生一个空的差异模式，并且可能会错误地匹配所有内容或不匹配任何内容，具体取决于实现。 

另一个重要的极端情况是环绕行为。 由于移位是模数$C$，差异还必须以模计算$C$，否则负值或不一致的范围会破坏匹配。 

## 方法

 暴力解决方案将尝试每个文本中每个可能的起始位置，并尝试确定是否存在转变$k$对齐图案。 对于固定的起始位置，我们可以计算$k = T[i] - W[0]$模数$C$，然后验证所有字符。 这需要花费$O(|W|)$每个位置，导致$O(|T| \cdot |W|)$每个文本，在最坏的情况下变成$10^{11}$操作而且速度太慢。 

关键的观察是，在全局转变下唯一重要的是连续字符之间的相对差异。 如果两个序列相差均匀移位，则它们的相邻差值模数相同$C$。 这完全消除了未知的偏移，并将问题转换为差异数组上的精确模式匹配。 

一旦我们将模式和每个文本都转换成它们的差异表示，任务就变成了两个整数序列的标准子串匹配。 使用 Knuth-Morris-Pratt (KMP) 可以有效地解决这个问题，因为它可以在线性时间内找到组合输入大小上所有出现的模式。

 | --- | --- | --- | --- |
 | 蛮力 | (O(N \cdot | W | )) |
 | 差异+KMP | (O(N + | W | )) |

 ## 算法演练

 我们将问题简化为匹配差异序列。 

1. 阅读模式$W$。 如果其长度为1，则存储此特殊情况并直接输出每个文本的所有位置。 这是有效的，因为任何单个字符都可以转换为任何其他字符。 
2. 将模式转换为差异数组，其中每个元素是$(W[i] - W[i-1] + C) \bmod C$。 

这对模式如何从一个字符变化到下一个字符进行编码，与全局变化无关。 
3. 在此模式差异数组上构建 KMP 失效函数（前缀函数）。 这使我们能够在扫描每个文本时有效地跟踪部分匹配。 
4. 对于每个文本，使用相同的公式计算其差异数组。 当且仅当两个子串的差异数组完全匹配时，此步骤保留了两个子串在统一移位下匹配的属性。 
5. 使用模式差异数组作为模式，对文本差异数组运行 KMP。 每次我们达到完整匹配时，我们都会在原始文本中记录有效的起始位置。 起始索引对应于原始文本中的位置，而不是差异数组，因此我们移动一位。 
6. 重置不同文本之间的 KMP 状态，因为匹配项不能跨越它们。 

为什么这样有效：均匀循环移位会添加一个常数$k$到子串的每个元素。 当我们减去连续元素时，这个常数就会抵消。 因此，差异数组唯一地表示字符串的所有移位版本的等价类。 匹配差异数组对于有效移位的存在来说既是必要的也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_kmp(p):
    m = len(p)
    pi = [0] * m
    j = 0
    for i in range(1, m):
        while j and p[i] != p[j]:
            j = pi[j - 1]
        if p[i] == p[j]:
            j += 1
        pi[i] = j
    return pi

def solve():
    C = int(input())
    
    W = list(map(int, input().split()))
    W.pop()  # remove trailing 0
    m = len(W)

    N = int(input())

    if m == 1:
        for _ in range(N):
            T = list(map(int, input().split()))
            T.pop()
            n = len(T)
            if n == 0:
                print("0")
            else:
                print(" ".join(str(i) for i in range(1, n + 1)) + " 0")
        return

    # pattern differences
    P = [(W[i] - W[i - 1]) % C for i in range(1, m)]
    pi = build_kmp(P)

    for _ in range(N):
        T = list(map(int, input().split()))
        T.pop()
        n = len(T)

        if n < m:
            print("0")
            continue

        # text differences
        S = [(T[i] - T[i - 1]) % C for i in range(1, n)]

        res = []
        j = 0
        for i in range(len(S)):
            while j and S[i] != P[j]:
                j = pi[j - 1]
            if S[i] == P[j]:
                j += 1
            if j == len(P):
                start = i - len(P) + 2
                res.append(str(start))
                j = pi[j - 1]

        if res:
            print(" ".join(res) + " 0")
        else:
            print("0")

if __name__ == "__main__":
    solve()
```该实现首先将模式和文本标准化为差异数组，消除未知的循环移位。 KMP 前缀函数针对模式差异计算一次，然后对每个文本重复使用。 

最微妙的细节是索引。 差异数组比原始字符串短一个元素，因此当匹配在位置结束时`i`差异数组中，原文对应的起始位置为`i - m + 2`。 

单字符模式的情况必须分开，因为它的差异表示是空的，统一处理它会破坏 KMP 逻辑。 

## 工作示例

 考虑一个小字母表，其中$C = 5$。 让图案成为$W = [1, 3]$，和一段文字$T = [2, 4, 1, 3]$。 

模式差异数组为$[2]$， 自从$3 - 1 = 2$。 

文本差异数组为$[2, 2, 2]$。 

现在我们运行 KMP：

 | 我| S[i] | j（匹配长度）| 行动|
 | --- | --- | --- | --- |
 | 0 | 2 | 1 | 比赛开始|
 | 1 | 2 | 1 | 不匹配后备然后匹配 |
 | 2 | 2 | 1 | 比赛继续，找到完整匹配|

 完全匹配发生在差异数组中的位置 0、1 和 2，对应于原始文本中的起始位置 1、2 和 3。 

这表明文本中的每个相邻对都与模式具有相同的差异，这意味着子字符串始终是模式的移位版本。 

现在考虑第二个没有匹配的例子。 

让$W = [1, 2, 4]$，所以模式差异是$[1, 2]$。 

让$T = [3, 5, 6, 1]$, 给出差异$[2, 1, 2]$。 

| 我| S[i] | j | 行动|
 | --- | --- | --- | --- |
 | 0 | 2 | 0 | 没有匹配 |
 | 1 | 1 | 0 | 没有匹配|
 | 2 | 2 | 0 | 没有完全对齐|

 没有段与模式差异完全匹配，因此不会输出起始位置。

 ## 边缘情况

 长度为 1 的模式是最重要的退化情况。 由于不存在相邻差异，因此标准转换会产生空模式。 如果简单地对待，KMP 要么到处匹配，要么不匹配，具体取决于空模式的处理方式。 正确的行为是每个位置都是有效的，因为任何单个值都可以转换为任何其他值。 

第二种边缘情况是由环绕差异引起的。 例如，在小字母表中$C = 5$，从 5 到 1 的转换应该产生 1 的差异，而不是 -4。 模归一化可确保一致性，如果没有它，相同的移位子串将错误地无法匹配。 

最后，多个文本不得允许 KMP 状态延续。 每个文本都是独立的，因此在扫描新字符串之前必须重置前缀匹配状态。 如果不重置，匹配可能会错误地跨越文档边界，从而产生误报。
