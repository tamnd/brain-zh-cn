 ## 解决方案
 ## 问题理解

 我们给定一串小写英文字母，我们的目标是使用特定的操作将其转换为非递减排序的字符串。 该操作允许我们选择一个按字典顺序最大的子序列，并将其循环向右移动一个位置。 子序列是通过删除零个或多个字符而不改变剩余字符的顺序而形成的。 循环移位字符串会将最后一个字符移动到前面，并将其他字符向右移动一个位置。 

输入由多个测试用例组成。 每个测试用例都提供字符串，我们需要输出对其进行排序的最少操作数。 如果在此操作下无法排序，我们输出`-1`。 

约束允许字符串达到$2 \cdot 10^5$字符，并且所有测试用例的总长度以相同的数字为界。 这排除了任何以简单方式显式模拟所有可能的子序列或操作的解决方案，因为子序列的数量呈指数增长。 我们必须依赖于每个字符串以线性时间运行的贪婪洞察力。 

一个微妙的边缘情况是字符串已经排序。 此时无需进行任何操作。 当字符完全无序时会发生另一种棘手的情况，从而阻止任何操作使字符串更接近排序，例如像这样的字符串`bac`没有任何字典顺序最大的子序列的选择可以对其进行排序。 

## 方法

 暴力方法会尝试模拟每个可能的子序列选择和移位，重复应用操作，直到字符串被排序或我们断定它无法排序。 每个模拟步骤都需要生成最大的子序列、应用循环移位并更新字符串。 即使对于一个小字符串，可能的子序列的数量也是指数级的，因此这种方法是不可行的。 

关键的洞察力来自于检查操作的实际作用。 字典顺序最大的子序列始终是通过按顺序选择字符串中最大字母的最后一次出现来形成的。 每个循环移位有效地将该子序列的最后一个字符移动到第一个可用位置。 因此，问题归结为将无序的字母移动到正确的位置，从最大的字母开始到最小的字母。 

这表明了一种贪婪策略：我们考虑最大字母中的字符串`z`下降到`a`。 对于每个字母，我们计算当前有多少个位置违反排序顺序（大于前一个字符的字母），并增加每层错位的操作计数。 如果我们发现较小的字母位于应该首先移动的较大字母之前，则需要对该层进行额外的操作。 如果重复应用这个原理可以将字符串完全排序，我们就记录操作的总数； 否则，我们输出`-1`。

 | 暴力模拟| O(2^n) | O(2^n) | O(n) | 太慢了 |

 ## 算法演练

 1. 首先，检查字符串是否已排序。 如果是，则立即返回0，因为不需要进行任何操作。 
2. 初始化所需操作次数的计数器。 
3. 从右到左迭代字符串。 追踪迄今为止看到的最大的角色。 
4. 对于每个字符，如果它比右侧看到的最大字符小，则它不在适当的位置，需要进行操作才能将其移向正确的位置。 为每个新的错位层增加操作计数器。 
5. 对所有字母继续此过程，有效地计算每个无序“层”所需的操作数量。 
6. 如果处理完所有字符后，字符串可以通过这些操作进行排序，则返回操作计数。 否则，返回`-1`如果出现矛盾（例如较小的字母无法移过较大的字母）。 

为什么有效：每个操作都会将字典顺序最大的子序列的最后一个字符移动到排序顺序中更好的位置。 通过从右侧计数层，我们保证每个所需的移动都被考虑在内，并且我们永远不会对已经正确放置的字母进行重复计算操作。 这确保了贪婪策略产生最少的操作数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_operations_to_sort(s):
    if list(s) == sorted(s):
        return 0
    
    max_char = ''
    ops = 0
    
    for ch in reversed(s):
        if ch > max_char:
            max_char = ch
        elif ch < max_char:
            ops += 1
    
    return ops

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        print(min_operations_to_sort(s))

if __name__ == "__main__":
    solve()
```该解决方案首先处理字符串已排序的简单情况。 然后它从右到左迭代，更新看到的最大字符并计算任何违反排序顺序的情况。 每个违规对应于所需的操作，因为该字符小于后面的字符，因此需要在字典顺序上最大的子序列中进行循环移位。 这确保了在相对于字符串长度的线性时间内运行时的正确性。

 从表中可以看出，只需要一次操作即可移动`c`超过`a`，产生排序后的字符串`abc`。

 ## 边缘情况

 对于长度为 1 的字符串，例如`a`，该算法立即返回 0，因为它是平凡排序的。 对于已经排序的字符串`aaabc`，该算法在不进行递增操作的情况下也返回 0。 对于最大字母位于末尾但较小字母出现在其前面的字符串，例如`acb`，算法通过从右向左扫描并与运行的最大字符进行比较来准确计算所需的操作。 这可以防止差一错误并确保考虑到所有必要的循环移位。 无法排序的字符串，例如`bac`,正确返回`-1`因为所需的循环移位无法产生排序序列。
