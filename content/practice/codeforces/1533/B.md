 ## 解决方案
 ## 问题理解

 我们得到了几个测试用例，每个测试用例都由不同整数的排序数组组成。 将这些数字视为数轴上的固定点。 一个查询点$y$被选择，并且函数返回数组中最接近的点$y$基于绝对距离。 

当存在唯一的最近点时，该函数表现正常。 仅当以下情况时才会失败$y$与两个不同数组值的距离完全相同，因为这样就有两个有效答案，并且平局未定义。 

所以任务不是模拟查询。 相反，我们必须确定是否存在任何整数$y$这将恰好落在两个数组元素之间的“连接位置”。 

输入大小很大：所有测试用例的元素总数达到$2 \cdot 10^5$，这排除了每个测试用例的任何二次方。 尝试所有候选查询点或检查值之间的所有整数位置的任何解决方案都会太慢，因为数字之间的间隙可能高达$10^9$，使得枚举变得不可能。 

一个常见的错误是假设关系可能涉及不相邻的元素。 例如，人们可能认为一个点可能同样接近于$x_i$和$x_j$即使两者之间存在值。 这是不可能发生的，因为任何中间点总是更接近内部值之一。 另一个微妙的错误是忘记了$y$必须是整数。 非整数的中点不会产生有效的碰撞，即使它是几何居中的。 

## 方法

 蛮力的想法是迭代最小和最大数组元素之间的所有整数值，并且对于每个$y$，计算最近的阵列点。 如果两分平局，我们就宣布成功。 这在逻辑上是正确的，但完全不可行。 取值范围可以达到$10^9$，因此即使是单个测试用例也可能需要数十亿次检查。 

关键的观察是，平局只能发生在非常结构化的情况下。 对于任意两个相邻元素$x_i$和$x_{i+1}$，更接近的点集$x_i$位于它们中点的左侧，并且该集合更接近$x_{i+1}$位于右侧。 平局恰好发生在中点。 

因为我们只关心整数$y$，这个中点必须是一个整数，只有当$x_i + x_{i+1}$是均匀的。 这将整个问题简化为检查任何相邻对是否具有均匀差异。 

这将看似几何搜索转变为对相邻差异的简单扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力胜过一切$y$|$O(\text{range} \cdot n)$|$O(1)$| 太慢了|
 | 检查相邻奇偶校验 |$O(n)$每个测试用例|$O(1)$| 已接受 |

 ## 算法演练

 我们将问题简化为检查排序数组中的相邻对。 

1. 读取点数组，该数组已排序并且不包含重复项。 这种排序确保任何候选者的平局都必须发生在邻居之间。 
2. 对于每一个相邻的对$(x_i, x_{i+1})$，计算差值$d = x_{i+1} - x_i$。 
3.如果$d$是偶数，我们立即知道存在一个整数中点$y = \frac{x_i + x_{i+1}}{2}$。 在这个值下，两个端点的距离相等，这保证了崩溃。 
4. 如果没有相邻对有偶数差，则得出结论：数组中任何位置都不存在整数中点，因此不可能存在平局。 
5. 对所有测试用例独立重复此过程。 

关键的决策点是步骤 3，因为它将算术结构直接与数轴上的几何对称性联系起来。 

### 为什么它有效

 任意一点$y$最接近由连续元素之间的垂直平分线界定的数轴的连续区域。 这些边界恰好出现在相邻对的中点处。 由于数组是排序的，因此每个模糊区域仅由邻居定义，并且没有进一步的对可以在不被中间点支配的情况下竞争。 因此，有效崩溃点的存在相当于某些相邻对之间存在整数中点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    x = list(map(int, input().split()))
    
    ok = False
    for i in range(n - 1):
        if (x[i + 1] - x[i]) % 2 == 0:
            ok = True
            break
    
    print("YES" if ok else "NO")
```该实现直接遵循只有相邻差异才重要的观察结果。 一旦找到有效的对，循环就会提前停止，这对于大型数组包含早期偶数间隙时的效率非常重要。 

一个微妙的细节是我们计算的是差值而不是总和。 两者在奇偶校验方面是等效的，但减法避免了对大中间值的任何担忧，即使 Python 可以安全地处理大整数。

 ## 边缘情况

 对于大小为 2 的数组，整个决策会分解为单个奇偶校验。 如果两个值相差奇数，则没有整数正好位于中间，因此不可能发生崩溃。 如果差值是偶数，则中点是整数并且总是会引发歧义。 

对于大型稀疏数组，相同的逻辑仍然成立，因为中间点不会影响基于邻接的 Voronoi 边界。 即使值相差很远，也只有距离的奇偶性才重要，而不是大小。 

对于等差数列等具有均匀间距的序列，答案完全取决于步长。 如果步长是偶数，则每个相邻对都会生成有效的中点，从而产生崩溃。 如果步长是奇数，则没有中点是整数，并且函数始终保持安全。
