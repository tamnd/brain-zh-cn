 ## 解决方案
 ## 问题理解

 有`m + n + 1`总共有不同的卡牌。 史莱克最初认识自己`m`牌，驴子知道自己的牌`n`卡片，一张卡片藏在桌子上。 没有人直接知道隐藏的卡牌。 

玩家轮流轮流，史莱克先行动。 在每个回合中，玩家可以立即猜测隐藏的牌，或者询问对手是否拥有某些特定的牌。 如果对手持有该牌，则该牌将被展示并永远从游戏中移除。 否则对手只会回答“不”。 

猜错就会立即失败。 正确的猜测立即获胜。 两位球员都打得非常完美，并且都知道对方也打得非常完美。 我们必须计算史莱克获胜的概率和驴子获胜的概率。 

唯一的输入是`(m, n)`, the initial number of cards held by Shrek and Donkey. 输出是两个概率，其总和为`1`。 

约束条件达到`1000`，对于二次动态规划来说很小，但对于基于显式卡配置的任何状态空间来说太大了。 纸牌的可能分布有指数级的多种，因此我们需要将游戏压缩成更小的数学状态。 

关键的观察是卡的身份并不重要。 只有计数才重要。 在任何时候，游戏状态完全取决于每个玩家仍然拥有多少张未知牌。 这将问题减少到大约一百万个州，这是可以管理的。 

一些边缘情况很容易被错误处理。 

如果一名玩家从零牌开始，答案不会自动失败。 例如：```
0 3
```史莱克什么都不知道，但从他的角度来看，可能的隐藏牌只有四张。 任何猜测都有概率成功`1/4`，与示例输出匹配。 

另一个微妙的情况是：```
0 0
```总共只有一张牌，并且它是隐藏的。 史莱克立即猜测并以概率获胜`1`。 

一个常见的错误想法是认为提出问题总是比猜测更好。 当玩家已经确定地知道隐藏的牌时，这种情况就会失败。 例如：```
1 0
```史莱克知道自己的牌，所以隐藏的牌一定是仅存的一张。 他以概率立即获胜`1`。 

一个更危险的错误是将游戏建模为随机提问。 玩家是最优的，而不是随机的。 每个问题的选择都是为了最大化获胜概率，而最佳移动取决于未来的递归状态。 

## 方法

 蛮力公式将跟踪每个玩家仍然持有的确切牌组，并递归地模拟每个法律问题和猜测。 这是正确的，因为一旦概率包含在状态中，游戏就是完美信息之一。 

问题在于状态空间的大小。 高达`2001`卡片总数，可能的隐藏分布的数量是天文数字。 即使对于三十张牌，状态图也已经不可行。 

关键的观察是对称性。 卡牌的名称并不重要，重要的是还剩下多少种可能性。 

假设轮到你了，目前有：

 -`a`只有对手可能持有的牌，
 -`b`只有你才能持有的卡片，
 -`1`隐藏卡。 

从你的角度来看，每张未知的牌都同样有可能被隐藏。 询问一张卡片要么消除一种可能性，要么揭示改变计数的信息。 两张状态相同的卡可以互换。 

这意味着游戏状态崩溃为`(a, b)`连同轮到谁了。 

现在我们可以定义一个动态编程状态：`dp[a][b]`= 当前玩家知道后最终获胜的概率`b`牌和对手可能知道`a`牌。 

来自一个州`(a, b)`，当前玩家有两种行动。 

他们可能会立即猜到。 由于有`a + 1`从他们的角度来看隐藏牌的可能性，成功概率为：$$\frac{1}{a+1}$$或者他们可能会询问对手可能持有的一张牌。 

如果对手真的有，这种情况有概率发生`a / (a+1)`，该牌被移除，同一玩家在状态下再次移动`(a-1, b)`。 

如果该卡实际上是隐藏的，这种情况有概率发生`1 / (a+1)`，回合在状态下传递给对手`(b, a-1)`。 

这个递归结构就是整个游戏。 

暴力方法会失败，因为它不必要地区分卡的身份。 对称性观察将状态空间减少到只有大约一百万个状态，从而允许记忆 DP。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解卡牌分发 | 指数| 指数| 太慢了|
 | DP 上的卡片计数 | O(百万) | O(百万) | 已接受 |

 ## 算法演练

 1. 定义`dp[a][b]`作为当对手可能拥有时当前玩家获胜的概率`a`未知牌且当前玩家知道`b`牌。 
2. 处理基本情况`dp[0][b] = 1`。 

当对手没有剩余可能的私牌时，隐藏的牌就完全确定了，因此当前玩家立即猜对。 
3. 对于每个州`(a, b)`和`a > 0`，立即考虑猜测的选项。 

隐藏卡均匀分布在`a + 1`可能性，所以立即猜测给出概率：$$\frac{1}{a+1}$$1. 考虑询问对手可能出的一张牌。 

有概率：$$\frac{a}{a+1}$$对手实际上有这张牌。 它被删除，当前玩家继续`(a-1, b)`。 

1. 否则所询问的卡片被隐藏。 

这种情况发生的概率为：$$\frac{1}{a+1}$$轮次发生变化，角色互换。 对手的获胜概率为`(b, a-1)`是`dp[b][a-1]`，因此当前玩家的概率变为：$$1 - dp[b][a-1]$$1. 结合询问的两个结果：$$\frac{a}{a+1} dp[a-1][b] + \frac{1}{a+1}(1 - dp[b][a-1])$$1.当前玩家选择猜测和询问中较好的一个：$dp[a][b]=\max\left(\frac1{a+1},\frac{a}{a+1}dp[a-1][b]+\frac1{a+1}(1-dp[b][a-1])\right)$1. 按升序填写表格`a + b`。 每个转换仅引用较小的状态，因此此顺序保证已经计算出依赖关系。 
2.最终答案是`dp[n][m]`因为最初史莱克看到`n`可能属于驴子并且知道自己的牌的牌`m`牌。 

为什么它有效：

 国家`(a, b)`充分捕获与未来决策相关的所有信息。 剩下的每张未知牌都是对称的，因此任何策略都不能依赖于牌的身份。 递归枚举了每个最佳第一步：要么立即猜测，要么提出问题。 请求转换分为仅有的两个可能的结果，并按其确切概率进行加权。 由于双方玩家随后都发挥最佳状态，因此递归状态已经包含正确的延续值。 通过感应`a + b`，每个 DP 条目等于真正的最优获胜概率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

m, n = map(int, input().split())

MAX = max(m, n)

dp = [[0.0] * (MAX + 1) for _ in range(MAX + 1)]

for b in range(MAX + 1):
    dp[0][b] = 1.0

for s in range(1, 2 * MAX + 1):
    for a in range(1, min(MAX, s) + 1):
        b = s - a

        if b < 0 or b > MAX:
            continue

        guess = 1.0 / (a + 1)

        ask = (
            (a / (a + 1)) * dp[a - 1][b]
            + (1.0 / (a + 1)) * (1.0 - dp[b][a - 1])
        )

        dp[a][b] = max(guess, ask)

shrek = dp[n][m]
donkey = 1.0 - shrek

print(f"{shrek:.12f} {donkey:.12f}")
```DP 表存储每对的概率`(a, b)`最大输入大小。 

基行`dp[0][b] = 1`代表当前玩家已经确定地知道隐藏牌的位置。 

外循环通过增加来迭代`a + b`。 这个顺序很重要，因为重现取决于`(a-1, b)`和`(b, a-1)`，两者的总大小都较小。 

转换分别计算两种法律策略。 猜测概率很简单。 提问转换会在问题失败后仔细处理角色交换。 价值`dp[b][a-1]`代表回合变化后对手的获胜概率，所以我们减去`1`。 

一个常见的实施错误是忘记第二个分支交换玩家的视角。 使用`dp[a-1][b]`两个分支都会产生错误的答案。 

另一个微妙之处是浮点精度。 所需的容错能力是`1e-9`，所以Python`float`就足够了。

 ## 边缘情况

 考虑：```
0 0
```整个游戏中只有一张牌，而且是隐藏的。 DP 立即使用基本案例`dp[0][0] = 1`。 史莱克猜出了唯一可能的牌并稳操胜券。 

现在考虑：```
1 0
```史莱克拥有一张牌，驴子没有一张，因此隐藏的牌是唯一确定的。 算法再次达到`dp[0][1] = 1`。 总是尝试先询问的粗心实施将会失败，因为没有人可以询问。 

最后考虑：```
0 3
```递归变为：$$dp[3][0] = \max\left( \frac14, \frac34 dp[2][0] + \frac14 (1 - dp[0][2]) \right)$$自从`dp[0][2] = 1`，请求分支折叠为：$$\frac34 \cdot \frac12 + \frac14 \cdot 0 = \frac38$$但`dp[2][0]`本身最优地成为`1/2`，最终导致`dp[3][0] = 1/4`。 

重要的细节是，失败的问题立即给对手带来胜利的状态。 递归通过术语处理这个问题：$$1 - dp[b][a-1]$$如果没有角色互换，这种可能性就会被高估。
