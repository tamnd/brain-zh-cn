 ## 解决方案
 ## 问题理解

 我们有一个L形的走廊，宽度`a`和`b`在两个树枝上。 固定长度的长方形棺材`l`必须移动通过角落。 棺材可以在平面内自由滑动和旋转，但永远不能离开地板，所以每个中间位置都必须留在走廊内。 

任务是计算最大可能的宽度`w`这样大小的矩形`l × w`可以通过转弯。 

这不是一个简单的轴对齐拟合问题。 长矩形在拐角处移动时仍然可以通过旋转来通过。 整个困难来自于找到棺材几乎不接触走廊墙壁的关键方向。 

输入限制在数值上很小，最多可达`10^4`，但几何形状是连续的。 没有有限的状态空间可供搜索。 尝试粗离散化的所有角度是危险的，因为答案需要`1e-7`精确。 该解决方案必须适用于浮点几何并可靠地收敛。 

主要隐藏的困难是，有些棺材即使宽度无限小也无法通过。 例如：```
1 1 100
```一个长方形`100`无论单位角变得多么薄，都无法弯曲。 正确的输出是：```
My poor head =(
```一个简单的实现，只检查是否`w ≤ min(a,b)`会错误地接受这个案例。 

当走廊宽度相等且棺材较短时，会出现另一种微妙的情况：```
2 2 1
```答案是`1`， 不是`2`。 棺材的宽度永远不能超过它自己的长度，因为声明保证`l ≥ w`。 忘记此限制会产生无效的答案。 

更几何的边缘情况发生在精确的可行性边界附近。 考虑：```
1 2 2.5
```棺材只能通过很小的宽度。 如果不仔细处理比较，接近此阈值的数值不稳定很容易导致误报。 

## 方法

 蛮力的想法很简单。 修复候选宽度`w`，然后尝试多个旋转角度`θ`。 对于每个角度，计算旋转的矩形在拐角时是否可以同时放入两个走廊分支内。 

固定角度的几何形状是可控的。 如果矩形旋转了`θ`，它在水平和垂直方向上的投影决定了它在每个分支中占据多少空间。 如果存在满足所有几何约束的某个角度，棺材就会通过。 

蛮力问题是精度问题。 假设我们扫描一百万个角度并对宽度进行二分搜索六十次迭代。 那已经大致变成了`6 × 10^7`几何评估。 更糟糕的是，离散角度根本上是不可靠的，因为最佳角度可能位于采样值之间。 

关键的观察结果是，对于固定宽度，描述所需空间的量在有效角度间隔内是平滑且单峰的。 这使得三元搜索变得适用。 

问题背后的经典几何事实是：当矩形旋转通过直角角时，当它同时接触所有四个限制壁时，就会出现临界条件。 成角度`θ`，所需的长度贡献是$$\frac{a-w\cos\theta}{\sin\theta} + \frac{b-w\sin\theta}{\cos\theta}$$如果该表达式在所有有效角度上的最小值至少为`l`，那么棺材就可以过去了。 

所以完整的解决方案变成：

 1.二分查找答案`w`。 
2. 对于每个候选宽度，三元搜索最小化所需长度表达式的角度。 
3. 检查可实现的最小所需长度是否至少为`l`。 

强力扫描明确地扫描所有角度。 优化的解决方案利用平滑性和凸性来连续搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(B·A) | O(1) | O(1) | 太慢且数字不可靠 |
 | 最佳| O(B·T) | O(1) | O(1) | 已接受 |

 这里，`B`是二分搜索迭代的次数，`T`是三元搜索迭代的次数。 

## 算法演练

 1. 首先处理平凡的上限。 由于棺材宽度不能超过走廊宽度或棺材本身长度，所以答案最多是`min(a, b, l)`。 
2. 定义候选宽度的可行性检查`w`。 
3. 对于固定角度`θ`，计算当矩形接触关键墙壁时可以容纳的最大棺材长度：$$f(\theta)= \frac{a-w\cos\theta}{\sin\theta} + \frac{b-w\sin\theta}{\cos\theta}$$这个公式来自于将矩形分解为两个走廊分支。 

1. 限制角度`(0, π/2)`。 在此范围之外，几何形状是对称的或无效的。 
2. 使用三元搜索`θ`最大化`f(θ)`。 

该函数是单峰的，因为几何形状从一种限制壁配置平滑过渡到另一种限制壁配置。 有一个最佳转向方向。 

1. 如果最佳可实现值`f(θ)`至少是`l`，然后宽度`w`是可行的。 
2. 二分查找宽度`w`。 如果宽度可行，则更大的宽度会变得更困难，而不是更容易，因此可行性是单调的。 
3.经过足够的迭代后，输出二分查找的下界。 
4. 如果结果宽度实际上为零，则打印`"My poor head =("`。 

### 为什么它有效

 对于固定宽度，通过拐角的每个可能的运动都对应于某个旋转角度。 限制配置正是当矩形紧密接触走廊边界时。 导出的表达式计算可以以该角度通过的最大矩形长度。 

三元搜索找到最大化该可实现长度的角度。 如果再好的角度也无法容纳长度`l`，则不存在运动。 如果有一个角度有效，棺材就可以连续移动通过这个角落。 

二分查找是正确的，因为增加宽度只会缩小可用空间。 一旦宽度变得不可能，任何更大的宽度也是不可能的。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    a, b, l = map(float, input().split())

    def best_length(w):
        lo = 1e-12
        hi = math.pi / 2 - 1e-12

        for _ in range(100):
            m1 = lo + (hi - lo) / 3
            m2 = hi - (hi - lo) / 3

            f1 = (
                (a - w * math.cos(m1)) / math.sin(m1)
                + (b - w * math.sin(m1)) / math.cos(m1)
            )

            f2 = (
                (a - w * math.cos(m2)) / math.sin(m2)
                + (b - w * math.sin(m2)) / math.cos(m2)
            )

            if f1 < f2:
                lo = m1
            else:
                hi = m2

        theta = (lo + hi) / 2

        return (
            (a - w * math.cos(theta)) / math.sin(theta)
            + (b - w * math.sin(theta)) / math.cos(theta)
        )

    def can(w):
        return best_length(w) + 1e-10 >= l

    lo = 0.0
    hi = min(a, b, l)

    for _ in range(100):
        mid = (lo + hi) / 2

        if can(mid):
            lo = mid
        else:
            hi = mid

    if lo < 1e-8:
        print("My poor head =(")
    else:
        print("{:.10f}".format(lo))

solve()
```外部二分搜索计算最大可行宽度。 搜索间隔从零开始，到走廊宽度和棺材长度之间的最小物理极限结束。 

内部三元搜索针对旋转角度进行优化。 使用`0`或者`π/2`直接会导致除以零，因此该实现使用与边界的微小偏移。 

被优化的函数是从接触壁配置导出的几何表达式。 较大的值意味着走廊可以容纳在该宽度和角度下更长的棺材。 

三元搜索内部的比较很容易向后进行。 我们希望角度产生最大的可行长度，因此搜索保留函数值较大的一侧。 

中的 epsilon`can()`避免精确边界附近的精度故障。 如果没有它，浮点舍入可能会错误地拒绝可行的宽度。 

最后检查反对`1e-8`处理语句所需的特殊不可能情况。

 ## 边缘情况

 考虑不可能的情况：```
1 1 100
```二分搜索重复测试较小的宽度。 即使当`w`变得很小，三元搜索发现最大可实现的车削长度仍然远低于`100`。 由于没有正宽度通过可行性检查，因此答案收敛到零并且程序正确打印：```
My poor head =(
```现在考虑短棺材案例：```
2 2 1
```从几何角度来看，更宽的矩形可以穿过走廊本身。 但问题需要`w ≤ l`。 二分查找上限初始化为`min(a, b, l)`，因此该算法从不考虑大于棺材长度的无效宽度。 

一个对精度敏感的例子是：```
1 2 2.5
```可行宽度非常接近可能与不可能之间的过渡。 这`1e-10`可行性检查中的容差可防止浮点舍入拒绝数学上有效但在数值上因微小误差而偏离的宽度。 

最后，考虑一个对称的大情况：```
10000 10000 10000
```最佳答案正是`10000`。 三元搜索在数值上保持稳定，因为角度间隔避免了正弦或余弦变为零的奇异端点。
