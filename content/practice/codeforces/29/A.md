[CF 29A - 吐痰问题](https://codeforces.com/problemset/problem/29/A)

 **评分：** 1000
 **标签：** 暴力破解
 **求解时间：** 1m 12s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 每头骆驼都站在数轴上的唯一坐标处。 骆驼在位置`x`准确地向位置吐痰`x + d`。 如果另一头骆驼站在那里，它就会被击中。 我们需要确定是否存在一对骆驼，其中一只骆驼会撞到另一只。 

假设骆驼A站在`x1`和吐距离`d1`。 它瞄准的是位置`x1 + d1`。 骆驼B站在`x2`和吐距离`d2`。 如果出现以下情况，两只骆驼就会互相吐口水：```
x1 + d1 = x2
x2 + d2 = x1
```输入给出每只骆驼的位置和吐口距离。 输出是`"YES"`如果至少存在一对相互对，否则`"NO"`。 

限制非常小。 骆驼最多有 100 只，因此即使是直接检查每一对骆驼的算法也是完全没问题的。 所有对的双循环最多执行`100 * 100 = 10,000`检查，这对于 2 秒的限制来说很小。 这立即告诉我们我们不需要复杂的数据结构或优化技巧。 

有一些容易被忽略的边缘情况。 

骆驼可能会向左而不是向右吐口水，因为`d`可以是负数。 例如：```
2
5 -2
3 2
```骆驼在`5`目标`3`，和骆驼在`3`目标`5`，所以答案是`"YES"`。 假设所有吐槽都正确的粗心解决方案将在这里失败。 

另一个微妙的情况是一只骆驼撞到另一只骆驼，但反之则不然：```
2
0 2
2 5
```骆驼在`0`击中骆驼`2`，但骆驼在`2`目标`7`。 正确答案是`"NO"`。 有缺陷的实现可能只检查一只骆驼是否可以击中另一只骆驼，而不是检查相互瞄准。 

第三种情况涉及多只骆驼，其中只有一对骆驼可以工作：```
4
0 3
3 -3
10 1
20 -5
```正确答案是`"YES"`因为前两只骆驼互相吐口水。 一旦找到任何有效的对，算法就必须停止。 

## 方法

 最直接的方法是对每对骆驼进行比较。 对于每对`(i, j)`，我们检查是否是骆驼`i`准确地向骆驼吐口水`j`，还有骆驼`j`准确地向骆驼吐口水`i`。 
以前，骆驼`i`是`(xi, di)`和骆驼`j`是`(xj, dj)`，然后他们互相吐口水：```
xi + di = xj
xj + dj = xi
```这种强力方法是正确的，因为每个可能的对都会被检查。 如果输入中的任何位置都存在有效的对，我们最终将对其进行测试。 

时间复杂度为`O(n²)`因为我们检查所有有序对。 和`n ≤ 100`，最多 10,000 次比较，这是微不足道的。 

由于约束已经很小，因此不需要更高级的优化。 我们可以将骆驼位置存储在哈希图中并尝试更快地搜索目标，但增加的复杂性在这里没有带来任何实际好处。 成对解决方案已经快速、简单且易于验证。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力配对检查 | O(n²) | O(1) | O(1) | 已接受 |
 | 哈希映射查找 | O(n) 平均 | O(n) | 已接受但没有必要 |

 ## 算法演练

 1. 读出骆驼的数量。 
2. 将每只骆驼成对存放`(x, d)`在哪里`x`是位置并且`d`是吐出距离。 
3. 迭代所有不同的骆驼对`(i, j)`。 
4. 对于每一对，计算目标位置：```
camel i targets xi + di
camel j targets xj + dj
```5.检查是否驼峰`i`目标骆驼`j`和骆驼`j`目标骆驼`i`。 

这意味着检查：```
xi + di == xj
xj + dj == xi
```6. 如果两个条件都成立，则立即打印`"YES"`并终止。 

我们可以提前停下来，因为问题只问是否至少存在一对这样的。 
7. 如果检查了所有对但没有满足条件，则打印`"NO"`。 

### 为什么它有效

 该算法对每对可能的骆驼只检查一次。 只有当每只骆驼的唾液准确地落在另一只骆驼的位置上时，一对才被接受。 由于“互相吐口水”的定义正是这两个方程，因此算法不会错过有效的一对，也不会错误地接受无效的一对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
camels = []

for _ in range(n):
    x, d = map(int, input().split())
    camels.append((x, d))

for i in range(n):
    xi, di = camels[i]

    for j in range(i + 1, n):
        xj, dj = camels[j]

        if xi + di == xj and xj + dj == xi:
            print("YES")
            sys.exit()

print("NO")
```该程序首先将所有骆驼读入列表中`(position, distance)`对。 

嵌套循环迭代每个唯一的对。 使用`j`从`i + 1`避免两次检查同一对骆驼，并避免将骆驼与自身进行比较。 

在循环内部，条件直接符合相互吐槽的数学定义。 第一个相等性检查是否存在camel`i`击中骆驼`j`。 第二个检查相反方向。 

一旦找到有效的对，程序就会打印`"YES"`并立即退出。 提前终止使实施变得简单并避免不必要的工作。 

不存在溢出问题，因为 Python 整数可以轻松处理这些范围。 负吐出距离也很自然地起作用，因为加法处理数轴上的两个方向。

 ## 边缘情况

 考虑吐口水向左移动的情况：```
2
5 -2
3 2
```该算法检查该对：```
5 + (-2) = 3
3 + 2 = 5
```两个条件都成立，因此打印`"YES"`。 负距离很自然地起作用，因为计算只是整数加法。 

现在考虑一下单方面的打击：```
2
0 2
2 5
```该算法计算：```
0 + 2 = 2
2 + 5 = 7
```第一个条件成功，但第二个条件失败。 由于同时需要两者，因此该对被拒绝，最终答案变为`"NO"`。 

最后，考虑只有一对匹配的多只骆驼：```
4
0 3
3 -3
10 1
20 -5
```该算法按顺序测试对。 当它到达前两只骆驼时：```
0 + 3 = 3
3 + (-3) = 0
```该对满足条件，因此算法立即打印`"YES"`无需浪费时间检查剩余的对。
