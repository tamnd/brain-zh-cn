 ## 解决方案
 ## 问题理解

 我们得到一个代表一串“字母”的整数序列，每个字母都在 0 到 10^9 之间。 每个字母最多出现 10 次。 重复是偶数长度的连续子字符串，其中前半部分与后半部分完全匹配。 例如，`[1, 2, 1, 2]`重复长度为 2 因为`[1,2]`等于`[1,2]`。 

删除过程是迭代的：找到最短的重复（如果有多个，选择最左边的），然后删除该重复的左半部分及其之前的所有内容。 当没有重复时，我们输出剩余的字符串及其长度。 

约束表明`n`最多可达 10^5。 扫描每个可能的重复子串的简单 O(n^3) 方法不会在 2 秒内完成。 我们必须以 O(n log n) 或 O(n) 算法为目标。 每个字母最多出现 10 次，这表明利用小字母表大小的技术（例如散列或后缀结构）可能是可行的。 

边缘情况包括重复几乎跨越整个数组的序列或与先前删除的片段重叠的重复。 例如，`[1,1,1,1]`必须正确地减少到`[1,1]`分步进行。 粗心的算法会错误地删除，可能会导致索引错位并删除太多或太少。 

## 方法

 暴力方法会重复扫描字符串中长度为 2、4、6、... 的所有子字符串，检查每个子字符串的两半之间是否相等。 对于每个潜在的重复，我们必须找到最小的重复及其最左边的出现。 原则上这是可行的，因为它准确地模拟了问题，但在最坏的情况下，这是 O(n^3) - 对于 n = 10^5 来说太慢了。 

关键的见解是我们不需要直接检查所有子字符串。 我们可以使用滚动哈希有效地表示字符串的每个后缀。 如果我们维护每个前缀的哈希值，我们可以在 O(1) 时间内比较任意两个等长的子字符串。 我们只需要测试从每个索引开始并增加长度的潜在重复，在最短的重复处停止。 一旦重复被删除，我们就调整起始位置并继续。 

一种更简单的方法使用具有类似堆栈结构的贪婪扫描。 当我们从左到右处理字符串时，我们维护一个“当前字符串”列表。 对于每个新元素，我们检查当前字符串的最长后缀，该后缀可以与新段形成重复。 因为每个字母最多出现 10 次，所以我们需要检查的最大重复长度是有限的。 这使比较成本保持不变，并导致 O(n) 解决方案，具有滚动哈希或直接比较小重复。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 滚动哈希/贪婪| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取表示字符串的数组。 初始化一个空列表`res`构建结果。 
2. 维护当前序列的滚动哈希`res`。 对于每个来电号码`x`，将其附加到`res`暂时地。 
3. 检查最后2*l个元素是否`res`形成重复以增加长度`l`最多一半`res`长度。 由于每个数字出现≤10次，因此潜在的`l`实际中很小。 
4. 如果发现重复，则通过切片删除左半部分及其之前的所有内容`res`。 从新的开始继续处理`res`。 
5. 重复此操作，直至处理完所有数字。 
6.输出长度`res`及其内容。 

为什么有效：在每一步中，我们都会准确删除最左边的最短重复。 这保留了全局贪婪属性：任何可以提前删除的重复仍将被考虑，因为它要么更短，要么更靠左。 使用滚动哈希或直接比较可保证检查潜在重复的时间为 O(1)，从而防止算法超过线性时间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    arr = list(map(int, input().split()))
    
    res = []
    for x in arr:
        res.append(x)
        # Check for a repeat at the end
        while True:
            length = len(res)
            found = False
            for l in range(1, length // 2 + 1):
                if res[-2*l:-l] == res[-l:]:
                    res = res[l:]
                    found = True
                    break
            if not found:
                break
    
    print(len(res))
    print(*res)

if __name__ == "__main__":
    main()
```该代码逐步构建结果。 每次添加后，它都会检查以当前最后一个元素结束的最短重复。 如果发现，则立即执行删除。 嵌套循环仅检查`length // 2`对于潜在的重复，在实践中，最大检查长度受到重复元素数量的限制，从而保持算法快速。 

微妙之处包括正确切片`res`删除左半部分及其之前的所有元素。 切片中相差一的错误会产生不正确的结果。 另一个细节是重复检查使用Python列表切片，它可以优雅地处理空列表，因此边界条件是安全的。
