 ## 解决方案
 ## 问题理解

 我们给出一个由三阶固定线性递推定义的序列。 前三个值固定为 1、1 和 2。后面的每个值都是通过前三个值的加权和生成的，特别是前一项加上前一项的两倍加上前第三项的三倍，然后将结果模数减少$10^9 + 7$。 任务是计算$n$- 该序列的第一个值，其中$n$可以非常大，最多$10^{12}$。 

关键的结构细节是这不是“构建阵列”问题。 递归定义了确定性序列，但索引范围使得直接模拟变得不可能。 哪怕走一百万步也好，但是$10^{12}$步骤迫使我们以压缩的代数形式表示过渡。 

约束条件$n \le 10^{12}$排除任何依赖于迭代状态而无需额外结构的线性时间甚至对数时间方法。 任何有效的解决方案都必须减少重复应用递归到可以求幂或以其他方式跨越大索引间隙的东西。 

一些边缘情况比它们最初出现时更重要。 什么时候$n = 1, 2, 3$，答案由初始化直接给出，不能通过递归逻辑处理。 

对于小错误，最危险的故障模式是移动索引。 例如，如果有人对待$a_0, a_1, a_2$作为初始值而不是$a_1, a_2, a_3$，那么转换矩阵幂将减少 1，在所有重要测试中产生看起来正确但不正确的输出。 另一个常见问题是忘记所有算术都必须取模$10^9+7$在乘法的每一步，不仅是在最后，在没有大整数的语言中，它会默默地溢出。 

## 方法

 暴力解释很简单：从前三个值开始，重复应用递归，直到达到索引$n$。 每个步骤都会花费恒定的时间，所以这会运行在$O(n)$。 这在数学上是正确的，因为每一项仅依赖于前三项，因此不会丢失任何状态。 失败纯粹是计算性的：对于$n = 10^{12}$，这将需要大约一万亿次操作，这远远超出了任何可行的时间限制。 

关键的观察结果是，递归是线性的，并且仅取决于先前值的固定大小窗口。 这意味着系统的演化可以表示为乘以常数转移矩阵。 我们可以将此矩阵求幂，而不是一次推进一步$n-3$，并将其应用于初始状态向量$[a_3, a_2, a_1]$。 矩阵求幂减少了从线性时间到对数时间的重复转换$n$，因为可以通过重复平方来执行求幂。 

这将问题转化为有效计算 3×3 矩阵幂，然后将其应用于基向量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n)$|$O(1)$| 太慢了 |
 | 矩阵求幂|$O(\log n)$|$O(1)$| 已接受 |

 ## 算法演练

 我们将递归编码为状态转换。 所在位置的状态$i$是包含最后三个值的向量，经过排序以便乘以固定矩阵产生下一个状态。 

1. 定义状态向量为$[a_i, a_{i-1}, a_{i-2}]$。 这种排序确保序列前移对应于线性变换。 
2. 构造转移矩阵$T$这样：$$a_{i+1} = a_i + 2a_{i-1} + 3a_{i-2}$$这成为第一行$T$，而其余​​行只是将值沿着状态向量向下移动。 该结构在一次操作中对循环和内存更新进行编码。 
3.如果$n \le 3$，立即返回预定义值，因为不需要转换。 
4. 否则计算$T^{n-3}$使用二进制求幂。 每个平方步骤由两个线性变换组成，并且此类步骤的数量是对数$n$。 这样做的原因是线性变换的重复应用是关联的，因此适用求幂规则。 
5. 将结果矩阵乘以初始状态向量$[a_3, a_2, a_1] = [2, 1, 1]$。 结果的第一个坐标就是答案。 

### 为什么它有效

 在每一步，状态向量都完全捕获计算下一个值所需的所有信息。 转移矩阵精确地再现了递推式，因此乘以$T$将序列前进一个索引而不进行近似。 由于矩阵乘法正确地构成了转移，$T^k$准确地代表$k$反复应用复发。 这保证了求幂后的计算状态与索引处的真实序列值相匹配$n$，与大小无关$n$是。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mul(a, b):
    n = 3
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        for k in range(n):
            if a[i][k]:
                aik = a[i][k]
                for j in range(n):
                    res[i][j] = (res[i][j] + aik * b[k][j]) % MOD
    return res

def mat_pow(mat, p):
    n = 3
    res = [[0]*n for _ in range(n)]
    for i in range(n):
        res[i][i] = 1

    base = mat
    while p > 0:
        if p & 1:
            res = mat_mul(res, base)
        base = mat_mul(base, base)
        p >>= 1
    return res

def solve():
    n = int(input())
    if n == 1:
        print(1)
        return
    if n == 2:
        print(1)
        return
    if n == 3:
        print(2)
        return

    T = [
        [1, 2, 3],
        [1, 0, 0],
        [0, 1, 0]
    ]

    Tn = mat_pow(T, n - 3)

    init = [2, 1, 1]
    ans = 0
    for i in range(3):
        ans = (ans + Tn[0][i] * init[i]) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该代码直接根据递归系数构建转移矩阵。 第一行对应于下一项如何从前三行形成，而下面的行则实现状态的转变。 指数是$n-3$因为基态已经代表位置 3。 

乘法例程在每个算术运算中都是完全模块化的，这可以防止溢出并确保模数约束下的正确性。

 ## 边缘情况

 对于$n = 1, 2, 3$，该算法完全绕过矩阵求幂并返回硬编码的初始值。 例如，输入$n = 2$直接映射到输出 1，无需构造或乘以任何矩阵。 

为了$n = 4$，算法执行单个转换。 矩阵幂变为$T^{1}$，这正是转移矩阵本身，因此乘以初始向量会产生正确的第四项。 

对于非常大的$n$， 例如$n = 10^{12}$，求幂循环运行大约 40 次迭代。 每次迭代都会平方或乘以 3×3 矩阵，并且状态保持一致，因为每个操作都是以模为基础执行的$10^9+7$，确保值永远不会溢出并且始终对应于有效的序列状态。
