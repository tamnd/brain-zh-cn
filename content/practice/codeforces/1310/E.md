 ## 解决方案

 ## 问题理解

 我们从一个数组开始，它的值完全不受限制，除了它的长度最多为$n$。 从任何这样的数组中，我们重复应用转换：我们忘记实际值并仅保留它们的频率结构。 具体来说，我们用一个新的多重集替换该数组，该多重集由每个不同值在前一个值中出现的次数组成。 重复这个过程$k$times 产生一系列“频率的频率”压缩。 

任务不是计算给定数组的此转换。 相反，我们最多考虑每个可能的非空数组长度$n$，应用操作$k$次，并计算结果可以出现多少个不同的多重集。 

关键的困难在于输入空间不是单一结构，而是整个频率模式宇宙，大小可达$n$。 这种转换会迅速缩小信息，但不是以统一的方式，并且不同的初始数组在多次应用后可能会崩溃到相同或不同的状态。 

限制因素$n, k \le 2020$立即排除任何直接枚举数组甚至分区的方法。 数组的数量呈指数增长$n$，因此任何正确的解决方案都必须完全在整数分区的空间及其频频运算下的转换中起作用。 

一个微妙的边缘情况是$k = 0$，其中答案只是最大大小的所有非空多重集的数量$n$，它已经很大但结构为分区。 另一种边缘情况是当数组是均匀的时，例如$a = [1,1,\dots,1]$，其中重复的应用程序立即崩溃为尺寸递减的单个链。 

最重要的结构困难是该操作不可逆并且不保留基数。 两个截然不同的频率分布可以在几次迭代后合并，这使得朴素 DP 超过值是不可能的。 

## 方法

 直接方法会尝试枚举所有可能的数组，其大小可达$n$，计算它们的频率分布，并模拟$k$步骤。 即使我们将自己限制在频率向量上，整数分区的数量$n$已经是指数级的$\sqrt{n}$，并且在分区之间应用转换会进一步增加复杂性。 这很快就变得不可行了$n = 2020$。 

关键的观察结果是，该过程仅取决于分区的形状，更重要的是，重复应用$f$最终导致一个稳定的状态，其中分区根据每种大小存在多少部分而变得“自我描述”。 我们不跟踪显式分区，而是跟踪分区在直方图压缩下如何演变。 

一个更有用的观点是将数组解释为某个整数的分区$m \le n$，其中每个部分代表一个值的出现。 正在申请$f$转换一个分区$m$到另一个整数的分区$m'$，前一个分区中的零件数。 这创建了一个确定性的尺寸缩减链：$m$，我们转到该分区的部分数量的分区。 

因此，每个初始结构都会生成一系列分区大小：$$m_0 \to m_1 \to m_2 \to \dots \to m_k$$其中每个$m_{i+1}$是分区中的部分数量$m_i$。 

组合核心变成：计算有多少个可能的长度分区链$k$可以以任何有效状态结束，聚合所有起始大小，最多可达$n$。 

我们定义一个 DP，在其中对按部分数量分组的分区进行计数。 让$dp[t][i]$是之后到达分区结构的方法数$t$应用程序的当前总大小是$i$。 转换取决于有多少个分区$i$正好有$j$部分，因为它们决定了下一个可能的状态。 

经典的组合事实是$i$恰好与$j$parts 等于 Ferrers 图适合的分区数$j \times (i-j)$网格，并且可以通过分区上的前缀 DP 来计算：$$p[i][j] = p[i-1][j-1] + p[i-j][j]$$这是适应有限零件计数的标准分区递归。 

然后我们模拟$k$每层聚合可能的部件数量，折叠所有大小的分区$i$对大小分区的贡献$j$。 

最终的答案是之后所有可能的终端分区状态的总和$k$所有初始尺寸的步长可达$n$。

 ## 算法演练

 我们围绕按大小对分区进行计数并跟踪在重复的“获取部分数量”转换下大小如何变化来构建解决方案。 

1.我们预先计算分区计数$p[i][j]$， 在哪里$i$是被划分的整数并且$j$是分区中的零件数。 这是使用经典的递归来完成的，该递归通过引入新部件或扩展现有部件来增量地构建分区。 该表足够的原因是转换$f$仅取决于分区有多少部分，而不取决于其中的实际值。 
2. 我们定义一个关于步长和大小的 DP 表。 在第 0 步，每个尺寸$i \le n$恰好提供了一种开始方式，因为我们正在考虑导致大小为分区结构的所有可能的数组$i$。 这会初始化所有分区大小的状态空间。 
3. 对于每一步$t$，我们根据大小分配贡献$i$到所有可能的下一个尺寸$j$，通过多少个分区进行加权$i$正好有$j$部分。 这种转变直接模拟了我们应用时发生的情况$f$：每个分区的大小$i$折叠到等于其部件数量的新尺寸。 
4. 我们累积之后的所有状态$k$转变。 最终答案是所有大小的所有 DP 状态的总和，因为之后的任何结果分区$k$无论其最终大小如何，步骤都是有效的。 

### 为什么它有效

 每个数组都会按频率对其值进行划分，并应用$f$将该分区转换为另一个分区，其大小仅由前一个分区中的部分数量决定。 这将整个过程简化为分区大小上的马尔可夫链，其中转换是通过受限分区数精确计数的。 由于我们通过 DP 隐式枚举所有分区，因此每个有效的转换路径都只计算一次，并且不会引入无效结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n, k = map(int, input().split())

    # p[i][j]: number of partitions of i with exactly j parts
    p = [[0] * (n + 1) for _ in range(n + 1)]
    p[0][0] = 1

    for i in range(1, n + 1):
        for j in range(1, i + 1):
            p[i][j] = (p[i - 1][j - 1] + p[i - j][j]) % MOD

    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        dp[i] = 1  # each size is initially reachable

    for _ in range(k):
        ndp = [0] * (n + 1)
        for i in range(1, n + 1):
            if dp[i] == 0:
                continue
            for j in range(1, i + 1):
                ndp[j] = (ndp[j] + dp[i] * p[i][j]) % MOD
        dp = ndp

    print(sum(dp) % MOD)

if __name__ == "__main__":
    main()
```民主党`p[i][j]`是标准的精确部分分区表。 至关重要的是，我们使用递归形式而不是显式生成分区，因为即使对于中等程度的直接枚举也会导致组合爆炸$n$。 

外DP`dp[i]`跟踪我们可以以多少种方式结束总大小的分区$i$经过给定次数的变换后。 每次迭代都会根据尺寸传播质量$i$到可能的下一个尺寸$j$，通过多少个分区进行加权$i$正好有$j$部分。 

最终的总和计算了之后所有可到达的终端分区大小$k$步骤。

 输入：```

```我们首先计算分区计数：

 对于$i = 3$，分区为：

 -$3$→ 1 部分
 -$2+1$→ 2 部分
 -$1+1+1$→ 3 部分

 所以$p[3][1]=1, p[3][2]=1, p[3][3]=1$。 

初始DP为：

 | 我| dp[i] | dp[i] |
 | ---| ---|
 | 1 | 1 |

 | 3 | 1 |

 一步之后：

 | 我| 计算| dp'[i]|
 | ---| ---| ---|
 | 1 | 从 i=1, j=1 | 1 |

 最终答案是$1 + 2 + 3 = 6$。 

这证实了每个初始大小根据其分区中所有可能的部件数量做出贡献。

 ## 边缘情况

 对于$n = 1$，唯一的数组是单个元素，并且每个应用程序$f$保持不变。 DP保持单一状态$dp[1]=1$，因此输出保持为 1，无论$k$。 

为了$k = 0$，不发生任何变换。 每个尺寸$i \le n$恰好贡献了一个有效结构，DP 总和变为$n$，匹配每个单例数组大小独立贡献的事实。 

对于像这样的均匀数组$[1,1,\dots,1]$，第一个转换立即将结构折叠为单元素分区，该分区被正确捕获，因为具有一个部分的分区始终确定性地映射到转换表中的大小 1。
