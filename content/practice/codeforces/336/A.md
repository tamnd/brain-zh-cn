 ## 解决方案
 ## 问题理解

 我们在原点给出一个点，在另一个点$(x, y)$定义一个与坐标轴对齐的矩形。 这个矩形只是原点和原点之间所有点的集合$(x, y)$，因此它的边与轴平行，并且跨越平面中固定的轴对齐区域。 

任务是构造一个直角等腰三角形，其中一个顶点固定在原点。 另外两个顶点，$A$和$C$，必须具有整数坐标，其中$x_1 < x_2$。 三角形必须是直角且等腰，这意味着以直角相交的两条腿具有相等的长度并且是垂直的。 

在完全包含给定矩形的所有三角形中，我们必须选择面积最小的三角形，并输出$A$和$C$。 

约束条件$|x|, |y| \le 10^9$清楚地表明，任何依赖于密集几何搜索或坐标枚举的解决方案都是不可能的。 任何可行的解决方案都必须将问题减少到恒定数量的算术运算。 

一个微妙的点是矩形可以位于任何象限，因为$x$和$y$可能是负数。 这意味着如果不小心处理，诸如“两个坐标均为正”之类的对称假设可能会悄悄破坏解决方案。 

一个常见的失败案例是选择与错误的轴方向对齐的三角形腿。 例如，如果假设两个点必须位于第一象限，则像这样的输入$x = -10, y = 5$立即打破了这样的逻辑，因为矩形向原点左侧延伸。 

真正的挑战不是几何模拟，而是确定包围轴对齐矩形的最小轴对齐直角等腰三角形。 

## 方法

 蛮力想法会尝试枚举候选位置以获得分数$A$和$C$在隐式网格上并测试三角形是否是直角等腰三角形并包含矩形。 对于每个候选对，我们将验证遏制和计算区域。 即使将坐标限制在合理的边界框内，对的数量也会在可能的坐标范围内呈二次方增长，其数量级为$10^9$。 这导致操作次数远远超出了可行性。 

三角形的结构消除了几乎所有的自由度。 一个顶点固定在原点的直角等腰三角形完全由从原点开始的两条垂直等长线段确定。 这意味着两条腿必须位于两个垂直方向上，并且两个端点必须位于以下形式的线上$y = x$,$y = -x$，或其坐标轴旋转。 

关键的观察结果是，为了包含矩形，三角形必须在 x 和 y 方向上延伸足够远以覆盖矩形的最远角。 限制因素是最大$|x|$和$|y|$，因为矩形的极值点是$(0,0)$和$(x,y)$。 任何封闭的对称直角等腰三角形必须至少沿两个轴方向延伸那么远。 

这将问题简化为构造一个边有长度的三角形$d = \max(|x|, |y|)$。 一旦比例固定，最佳配置就变得确定了：通过将其端​​点放置在相反方向的轴上来形成三角形，以便斜边跨越包含矩形的边界正方形。 

然后，我们变换坐标的符号以确保无论象限如何都包围矩形，但构造本身仅取决于绝对值。

 ## 算法演练

 1. 使用以下公式计算沿轴覆盖矩形所需的最大距离$d = \max(|x|, |y|)$。 这代表任何封闭对称结构所需的最小半对角线。 
2. 在相对于原点对称轴对齐的位置构造两个三角形顶点。 一个位于正对角线方向，另一个位于相反轴方向，使腿垂直且相等。 
3. 选择坐标$A = (0, d)$和$C = (d, 0)$当矩形位于第一象限方向时。 这形成一个直角等腰三角形，其腿位于轴上。 
4. 根据绝对值隐式调整方向$x$和$y$，因为所需的三角形大小仅取决于大小，而不取决于符号。 
5. 输出两个构造点确保$x_1 < x_2$，这自然成立，因为$0 < d$。 

### 为什么它有效

 任何一个顶点位于原点的直角等腰三角形，其边沿两个等长的垂直方向对齐。 为了包含矩形，三角形的两个坐标范围必须至少与矩形沿每个轴的最大范围一样大。 该要求迫使腿长至少为$\max(|x|, |y|)$。 Once that bound is met, the smallest-area configuration is the one that uses exactly that length, since any larger triangle strictly increases area without improving containment.

 ## Python 解决方案```python
import sys
input = sys.stdin.readline

x, y = map(int, input().split())

d = max(abs(x), abs(y))

# Construct a minimal right isosceles triangle with legs on axes
x1, y1 = 0, d
x2, y2 = d, 0

print(x1, y1, x2, y2)
```该代码首先读取相对矩形顶点的坐标。 它将几何图形简化为单个标量值，即最大绝对坐标，它确定了三角形的必要比例。 

然后，该构造将一个点放置在 y 轴上，将另一个点放置在 x 轴上，距离$d$。 这保证了等长的垂直腿，确保直角和等腰条件。 

订购条件$x_1 < x_2$自动满足，因为$0 < d$自此以来所有有效输入都成立$x$和$y$均非零。

 ## 边缘情况

 对于一个坐标为负数的输入，例如$(-7, 3)$，矩形向原点左侧延伸。 该算法忽略符号并使用绝对值，因此$d = 7$。 它构建了$(0,7)$和$(7,0)$，它仍然形成一个有效的封闭三角形，因为该矩形适合在锚定于原点的边长为 7 的边界正方形内。 

对于高度不平衡的输入，例如$(10^9, 1)$，结构仅根据最大幅度坐标进行扩展，确保沿较小维度不会进行不必要的缩放。
