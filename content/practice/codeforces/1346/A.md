 ## 解决方案
 ## 问题理解

 我们给出了参与者总数和固定乘数。 参与者必须被分成四个连续的组，其中每个下一组都恰好是$k$比前一个大一倍。 一旦第一个组的大小确定，其余的就完全按照几何级数确定：$$n_1,\; k n_1,\; k^2 n_1,\; k^3 n_1$$它们的总和必须等于总和$n$。 

所以任务是重建一个有效的几何分解$n$用比率分解为四项$k$。 

从计算角度来看，约束非常小。 每个测试用例仅需要常量算术运算。 即使在最大$t = 1000$，线性扫描甚至重复算术是不必要的，所以$O(t)$解决方案就足够了。 任何涉及大范围循环或搜索的解决方案$n$将是不必要的和矫枉过正的。 

一些边缘情况在概念上很重要。 什么时候$k = 1$，所有四组都是相等的，所以答案简化为分裂$n$分成四等份。 什么时候$k > 1$，第一组变小，因为较高的幂很快就主导了总和。 该问题保证存在整数解，因此我们不需要处理不可行的情况。 

## 方法

 一个天真的想法是尝试所有可能的值$n_1$。 对于每个候选人，计算$n_1 + k n_1 + k^2 n_1 + k^3 n_1$并检查它是否等于$n$。 这有效但没有必要。 表达式简化为$$n = n_1 (1 + k + k^2 + k^3)$$所以我们只需要计算一个除法：$$n_1 = \frac{n}{1 + k + k^2 + k^3}$$蛮力视图之所以有效，是因为它直接测试序列的结构，但它变得浪费，因为关系是线性的$n_1$。 关键的观察结果是，四项形成固定的几何和，因此总和只是第一项的常数倍。 这将问题简化为计算单个商，然后通过乘法重建剩余值。

 ## 算法演练

 1. 读取数值$n$和$k$对于每个测试用例。 这些定义了一个几何结构，其中一旦第一组已知，所有四个组就被固定。 
2. 计算几何和系数$$S = 1 + k + k^2 + k^3$$这代表了多少次$n_1$被计入总数中。 
3. 计算$n_1 = n / S$。 这是可行的，因为该问题保证了可分性。 如果不能保证，我们需要验证，但这里的构造确保了一致性。 
4. 将其余组构造为$n_2 = k n_1$,$n_3 = k^2 n_1$， 和$n_4 = k^3 n_1$。 每个步骤都直接遵循进程的定义。 
5. 按顺序输出四个值。 

### 为什么它有效

 参与者总数恰好是固定比例的几何级数之和$k$。 每个有效的解决方案都必须唯一地匹配该结构，因为一旦$n_1$是固定的，所有其他值都已确定。 该方程将问题简化为求解一个变量中的单个线性方程，因此构造的解是唯一的候选解，因此是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())

        S = 1 + k + k * k + k * k * k
        n1 = n // S

        n2 = n1 * k
        n3 = n2 * k
        n4 = n3 * k

        print(n1, n2, n3, n4)

if __name__ == "__main__":
    solve()
```该代码直接编码问题的代数结构。 唯一微妙的一点是正确计算几何和并确保使用整数除法。 存在的保证确保$n$可以整除$S$，所以楼层划分是安全的。 

计算$n_2, n_3, n_4$迭代地避免重新计算能力$k$，这使实现保持干净并避免了具有固定整数大小的语言中的溢出问题。 Python 自然地处理大整数，因此不需要额外的预防措施。

 ## 边缘情况

 当$k = 1$，几何和变为$4$，所以每个组都必须精确地$n/4$。 该算法自然会处理这个问题，因为$S = 4$所有乘法都保持相等。 

什么时候$k$很大，$k^3$主导总和，使得$n_1$非常小。 计算仍然有效，因为由于问题陈述中的保证，所有值都保持整数。 

什么时候$n$正好等于几何和$S$，解产生$n_1 = 1$，产生最小有效配置$1, k, k^2, k^3$，确认边界情况行为。
