 ## 解决方案
 ## 问题理解

 该问题要求我们在持续的编程训练营期间安排最大数量的讲座`n`天。 每天要么是正常的一天，我们可以举办讲座，要么是游览日，不允许讲座。 正常情况下，我们安排的时间不能超过`k_1`任意一天的讲座以及任意连续几天的讲座总和不得超过`k_2`。 目标是确定全天可以分配的最大讲座总数，同时遵守这些限制。 

输入由多个测试用例组成。 每个测试用例都提供天数、每天和每对讲座的限制，以及表示哪些天是短途旅行的二进制字符串。 每个测试用例的输出是一个整数，即可能的最大总讲座数。 

关键的限制是`n`可以大到 5000，`k_1`和`k_2`最多可以有 200,000 个，并且最多可以有 50 个测试用例。 这表明具有复杂性的算法`O(n^2)`在最坏的情况下，每个测试用例都会太慢，因为`5000^2 * 50`操作量约为十亿。 我们需要一种在每个测试用例的线性或线性时间内工作的方法。 

一个微妙的方面是，连续的日子通过`k_2`约束。 一个幼稚的方法可能会尝试分配`k_1`每个非游览日都有讲座，但这可能违反成对总和约束。 当几个短途旅行日连续或处于边缘时，会出现另一种边缘情况； 该算法必须正确重置此类片段中的讲座累积量。 

例如，如果我们有`n = 4`,`k_1 = 3`,`k_2 = 4`日期字符串是`1101`，然后是一种幼稚的分配方法`k_1`到处都会产生`[3, 3, 0, 3]`， 但`3 + 3 = 6`超过`k_2 = 4`。 正确的分配是`[2, 2, 0, 3]`，总共产生 7。 

## 方法

 蛮力方法是迭代每个非游览日并尝试从`0`到`k_1`，同时检查连续日总和约束。 对于每一天，我们都会跟踪可能的累计总数和最后一天的有效计数。 这可以作为动态编程解决方案来实现`dp[i][x]`代表当天最大总讲座数`i`如果有一天`i`有`x`讲座。 每次更新都需要检查所有`x`和`y`连续几天配对。 在最坏的情况下，与`n = 5000`和`k_1 = 200,000`，这种方法是不可行的，因为它需要`O(n * k_1^2)`运营。 

关键的见解来自于观察`k_2`约束可以表示为相对于其邻居一天可以花费多少时间的上限。 如果`k_2 >= 2 * k_1`，那么连续约束永远不会绑定，我们可以简单地赋值`k_1`每个非游览日。 否则，如果`k_2 < 2 * k_1`，那么对于每对连续的非游览日，我们可以分配给每个日的最大值限制为`floor(k_2 / 2)`。 这减少了将新兵训练营分成连续的非游览日块的问题，并分配`k_1`或者`floor(k_2 / 2)`每天，根据需要交替进行，类似于邻居互相约束的“栅栏绘画”问题。 

该观察结果允许线性时间解决方案。 我们可以扫描天数字符串，识别连续非游览天数的片段，并针对每个片段，通过交替填充允许的最大值来计算最大讲座数，但决不超过`k_2`在任何连续的对上。 游览日充当自然分隔符，重置交替。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * k_1^2) | O(n * k_1^2) | O(n * k_1) | O(n * k_1) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2.对于每个测试用例，解析`n`,`k_1`,`k_2`和日期字符串。 
3. 计算`max_pair = min(k_1, k_2 // 2)`。 这表示考虑连续天数限制时可以安全分配到一天的最大讲座数。 
4. 初始化总讲座的计数器。 
5. 从左到右扫描日期字符串。 保持连续非外出日的长度。 
6. 每当遇到偏移日或字符串结尾时，处理前一段连续的非偏移日。 对于一段长度`L`，最大总讲课数为`L * max_pair + (L // 2) * (k_2 - 2 * max_pair)`如果`k_2 < 2 * k_1`，或者简单地`L * k_1`如果`k_2 >= 2 * k_1`。 
7. 在每个游览日重置航段计数器并继续。 
8、处理完所有段后，输出累计总讲课数。 

不变的是，在连续的非游览日的每个时段，指定的讲座都不会违反每日限制`k_1`以及连续日的总金额限额`k_2`。 游览日自然是分开的，所以我们不需要考虑跨境违规。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k1, k2 = map(int, input().split())
    s = input().strip()
    
    max_pair = min(k1, k2 // 2)
    total = 0
    count = 0
    
    for ch in s + '0':
        if ch == '1':
            count += 1
        else:
            if count > 0:
                # maximum lectures in this segment
                segment_total = count * max_pair + (count // 2) * (k2 - 2 * max_pair)
                total += segment_total
                count = 0
    print(total)
```该解决方案每天精确扫描一次，并处理连续非游览日的各个部分。 追加`'0'`最后确保最后一段的处理无需特殊的边界检查。 使用整数除法可确保我们在分割附加讲座时遵守连续天的限制。
