 ## 解决方案
 ## 问题理解

 我们有`n`足球运动员，编号为`1`到`n`。 

每次练习都包括将所有玩家分成两个非空队。 经过几次练习后，我们希望每对球员至少被分开一次，这意味着存在一些将两名球员分到相反球队的做法。 

任务不仅是构建这样一个时间表，而且是使用尽可能少的练习。 

输入仅包含一个整数`n`。 输出必须首先打印最小练习数，然后通过列出两个团队之一来描述每个练习。 任何最佳结构都被接受。 

约束条件`n ≤ 1000`足够小，我们可以明确输出所有团队。 挑战不在于计算复杂性，而在于发现最少数量的实践并构建它们。 

思考这个问题的一个有用方法是为每个玩家分配一个二进制代码。 每一次练习都对应一位位置。 在训练中，患有比特病的球员`0`去一支球队和有位的球员`1`去另一支队伍。 当两个玩家的代码有些不同时，他们就会被分开。 

由于最多有 1000 个玩家，因此最多 10 位的二进制表示就足够了，因为`2^10 = 1024`。 

有一些微妙的边缘情况。 

为了`n = 2`，仅存在一对。 将玩家 1 与玩家 2 进行一次练习就足够了。 

输入：```
2
```一种有效的输出是：```
1
1 1
```一个粗心的实现总是输出`⌈log2 n⌉`在某些实践中，不考虑小值的实践可能会意外地创建一个空团队。 

另一种边缘情况发生在`n`不是二的幂。 

输入：```
5
```我们需要三种实践，因为`2^2 = 4 < 5 ≤ 8 = 2^3`。 有些位置可能包含非常不均匀的分割，但每次练习都必须保持两队非空。 如果现有播放器中的位位置仅包含零，则盲目打印所有位位置而不进行检查的实现将是不正确的。 

最后一个微妙之处是玩家编号从 1 开始。使用数字`1..n`直接作为二进制代码可以将所需的位数增加一位。 清洁施工使用代码`0..n-1`。 

## 方法

 蛮力观点是直接考虑成对的玩家。 有`n(n-1)/2`对。 我们可以重复设计实践并检查哪些对已经分开。 这样的搜索很快就会变成组合搜索，因为每次练习都是将玩家分为两个非空组。 即使对于中等`n`，可能的分区数量是巨大的。 

当我们询问实践提供什么信息时，真实的结构就会出现。 实践只能告诉我们每个球员位于分区的哪一侧。 如果我们执行`m`练习时，每位球员都会收到`m`- 位签名描述其在所有实践中的团队分配。 

当两名球员的签名不同时，他们至少会被分开一次。 如果两个玩家有相同的签名，他们总是出现在同一边并且永远不会分开。 

这将问题转化为编码问题。 我们需要`n`独特的签名。 和`m`位，最多有`2^m`不同的签名，所以：$$2^m \ge n$$因此：$$m \ge \lceil \log_2 n \rceil$$这给出了答案的下限。 

同样的观察立即给出了一个解释。 指定玩家`i`的二进制表示`i-1`。 由于价值观`0,1,\dots,n-1`是不同的，所有签名都是不同的。 对于每个位的位置，创建一个练习，根据该位将玩家分开。 

每对玩家都有不同的二进制表示，因此它们有些不同。 在相应的练习中，他们被安排在相对的队伍中，满足要求。 

下限和构造匹配，证明了最优性。

 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n log n) | O(n log n) | 已接受 |

 ## 算法演练

 1. 计算最小整数`m`这样`2^m ≥ n`。 
2. 给球员编号`0`到`n-1`内部。 这些值用作唯一的二进制代码。 
3. 对于每个位位置`b`从`0`到`m-1`，创建一种实践。 
4. 实践中`b`，放置每个代码有 bit 的玩家`b`等于`1`进入一线队。 
5. 所有剩余的球员自动属于第二队。 
6、输出每次练习第一队的队员。 

为什么只输出有位的玩家是安全的`1`？ 自从`2^m ≥ n`，使用的最高位位置是必要的。 对于每一位位置`b < m`, 至少存在一个带位的代码`b = 1`以及至少一个带有位的代码`b = 0`之中`0..n-1`。 因此，两队均非空队。 

### 为什么它有效

 每个玩家都会收到一个唯一整数的二进制表示`0`到`n-1`。 

考虑任意两个不同的玩家。 它们分配的整数不同，因此它们的二进制表示形式至少在一位位置上不同。 在对应该位的练习中，一名球员属于第一队，另一名球员属于第二队。 因此，每对至少分开一次。 

现在考虑最少的练习次数。 后`m`练习中，每个球员都只能用一个来形容`m`位签名。 最多有`2^m`独特的签名。 既然所有`n`玩家必须有不同的签名，我们需要`2^m ≥ n`。 因此至少`⌈log₂ n⌉`实践是必要的。 

我们的施工完全使用`⌈log₂ n⌉`实践，所以它是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    m = 0
    while (1 << m) < n:
        m += 1

    print(m)

    for b in range(m):
        team = []
        for i in range(n):
            if (i >> b) & 1:
                team.append(str(i + 1))

        print(len(team), *team)

solve()
```第一个循环计算表示所需的最小位数`n`不同的代码。 

有编号的玩家`i + 1`接收内部代码`i`。 使用`0..n-1`很重要，因为正是`n`需要不同的代码，这可以避免浪费一个代码值。 

对于每个位位置，该解决方案收集代码中包含以下内容的所有玩家`1`在那一点。 这些球员组成了一线队。 其他人都隐含地属于第二团队。 

一个微妙的问题是输出格式只需要列出一支球队。 剩下的玩家自动组成另一队。 

另一个微妙的点是证明上市团队永远不会空。 自从`m`是最小值`2^m ≥ n`，下面的每一位位置`m`显示为`1`其中至少有一个数字`0..n-1`。 因此，每一份印刷的练习赛都至少包含一名球员。

## 测试用例```python
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n = int(input())

    m = 0
    while (1 << m) < n:
        m += 1

    out = [str(m)]

    for b in range(m):
        team = []
        for i in range(n):
            if (i >> b) & 1:
                team.append(str(i + 1))
        out.append(f"{len(team)}" + ("" if not team else " " + " ".join(team)))

    return "\n".join(out)

# provided sample
assert run("2\n") == "1\n1 2"

# minimum size
assert run("2\n").splitlines()[0] == "1"

# first non-power of two
assert run("3\n").splitlines()[0] == "2"

# power of two
assert run("8\n").splitlines()[0] == "3"

# maximum size
assert run("1000\n").splitlines()[0] == "10"

 ## 边缘情况

 考虑：```
2
```该算法计算`m = 1`。 玩家1收到代码`0`，玩家2收到代码`1`。 单次练习将玩家 2 置于所列团队中，将玩家 1 置于另一团队中。 唯一的一对立即分开。 

考虑：```
5
```该算法计算`m = 3`。 第三个练习只包含玩家 5，因为只有代码`100`具有最高位设置。 这仍然有效，因为两队都保持非空。 粗心的实现可能会错误地拒绝这种高度不平衡的分区。 

考虑：```
8
```这里`m = 3`确切地。 每个玩家都会收到一个独特的 3 位代码`000`到`111`。 该构造完全达到了下界，表明不需要第四次练习。 成对分离属性直接源于二进制表示的唯一性。
