 ## 解决方案
 ## 问题理解

 我们需要打印一个`n × n`使用字符的棋盘。 白色方块表示为`.`和黑色方块`#`。 左上角的方块是白色的，颜色在水平和垂直方向上交替变化，就像真正的棋盘上一样。 

输入包含单个整数`n`，给出了电路板的尺寸。 输出必须包含`n`线，每条线都有`n`描述棋盘的一行的字符。 

限制非常小。 自从`1 ≤ n ≤ 9`，即使单独生成每个单元最多也需要`81`运营。 任何合理的解决方案都足够快。 该任务不是关于优化，而是关于正确再现交替颜色图案。 

一个常见的错误是起始颜色错误。 例如：

 输入：```
1
```正确输出：```
.
```左上角的方块是白色的，所以第一个字符必须是`.`。 开始于`#`会反转整个板。 

另一个简单的错误是仅在每行内部交替，但忘记连续的行必须以相反的颜色开始。 

输入：```
2
```正确输出：```
.#
#.
```粗心的实施可能会产生：```
.#
.#
```因为它以相同的颜色重新启动每一行。 

第三个错误来源是差一索引。 颜色取决于行位置和列位置的总和是偶数还是奇数。 使用基于一的索引而不调整奇偶校验逻辑可能会翻转整个板。 

## 方法

 最直接的方法是检查每个方块并确定其颜色。 对于每个位置`(row, col)`，我们决定它是否应该包含`.`或者`#`，将该字符附加到当前行，并打印完成的行。 

这种蛮力方法已经足够了，因为只有`n²`细胞。 和`n = 9`，最坏的情况仅包含`81`职位。 

关键的观察结果是棋盘颜色交替。 如果我们从零开始索引行和列，那么位置为偶数`row + col`与左上角方块的颜色相同，而奇数位置`row + col`有相反的颜色。 

由于左上角的方块是白色的，表示为`.`，我们简单地输出：```
.
```什么时候`(row + col)`是偶数，并且```
#
```什么时候`(row + col)`很奇怪。 

这让我们可以通过简单的奇偶校验独立地确定每个单元。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) 不包括输出 | 已接受 |
 | 最佳| O(n²) | O(1) 不包括输出 | 已接受 |

 对于这个问题，暴力方法和最优方法实际上是相同的，因为每个单元格都必须出现在输出中。 

## 算法演练

 1.读取整数`n`。 
2. 迭代每行索引`i`从`0`到`n - 1`。 
3. 逐个字符构建当前行。 
4.对于每个列索引`j`从`0`到`n - 1`, 计算`(i + j) % 2`。 
5. 如果结果是`0`, 附加`.`因为这个正方形与左上角的正方形具有相同的颜色。 
6. 否则附加`#`因为颜色必须交替。 
7. 构建行后，打印它。 

### 为什么它有效

 棋盘上相邻方格之间的颜色交替。 水平或垂直移动一步会改变奇偶校验`row + col`，因此奇偶校验完全按照颜色应有的方式交替。 左上角的正方形`(0,0)`奇偶校验为偶数且为白色。 每个奇偶校验的方格都会收到`.`，每个具有奇校验的方格都会收到`#`，精确生成所需的棋盘图案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

for i in range(n):
    row = []
    for j in range(n):
        if (i + j) % 2 == 0:
            row.append('.')
        else:
            row.append('#')
    print(''.join(row))
```程序首先读取电路板尺寸。 

外循环处理行，内循环处理列。 对于每个位置`(i, j)`，奇偶性`i + j`决定颜色。 偶数奇偶校验对应于相同的颜色`(0, 0)`，它是白色的，表示为`.`。 奇校验对应于`#`。 

每行都累积在一个列表中，并使用以下方法转换为字符串`''.join(row)`。 这可以避免重复连接字符串并保持实现的简洁。 

最常见的实施错误是颠倒奇偶校验规则。 自从`(0,0)`必须是白色，偶数奇偶校验必须映射到`.`而不是`#`。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n = int(input())
    out = []

    for i in range(n):
        row = []
        for j in range(n):
            row.append('.' if (i + j) % 2 == 0 else '#')
        out.append(''.join(row))

    return '\n'.join(out)

# provided sample
assert run("4\n") == ".#.#\n#.#.\n.#.#\n#.#.", "sample 1"
