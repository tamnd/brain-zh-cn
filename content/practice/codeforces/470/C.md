 ## 解决方案
 ## 问题理解

 任务是评估以下形式的简单算术表达式`a?b`在哪里`a`和`b`是 1 到 999 之间的整数，并且`?`是集合中的单个运算符`+`,`-`,`*`,`/`， 或者`%`。 从概念上讲，这只是采用两个数字并应用指定的操作，然后打印结果整数。 

输入是包含不带空格的表达式的单行字符串。 这意味着我们不能依赖空格的标准标记化； 我们需要识别字符串中的运算符，相应地拆分两个数字，然后执行操作。 

限制很小：数字始终在 1 到 999 范围内，这正好适合标准 32 位整数。 整数除法`/`必须向零截断，并且取模`%`返回除法的余数。 因为输入只是一行，所以性能不是问题； 任何正确的解决方案都可以在 2 秒内运行良好。 

非明显的边缘情况包括涉及除法或模数的表达式，特别是确保永远不会尝试除以零。 这里保证两者`a`和`b`至少为 1，因此不会发生被零除的情况。 另一个微妙之处是解析：由于输入没有空格，因此需要正确提取多位数字，并且如果运算符是`-`，这可能会与负号混淆。 然而，这里所有的数字都是正数，所以第一个`-`发现肯定是操作员。 

## 方法

 一种简单的方法是使用 Python 来计算表达式`eval()`将输入读取为字符串后的函数。 这有效是因为`eval()`可以直接解析算术字符串，但是使用`eval()`由于潜在的安全问题以及它模糊了解析的逻辑，因此在竞争性编程中不鼓励这样做。 

标准方法是扫描输入字符串以查找运算符。 一旦我们找到它，它之前的一切就都消失了`a`之后的一切都是`b`。 然后我们使用一个简单的条件或字典将运算符字符映射到相应的Python操作。 这既简单又高效，因为输入保证只有一个运算符并且数字很小。 

在这里，没有必要在所有拆分上测试所有运算符的强力想法，因为只有一个运算符，因此一次通过即可找到它。

 ## 算法演练

 1. 读取输入字符串并去除周围的空格以确保干净的解析。 这确保了意外的尾随换行符不会干扰到整数的转换。 
2. 逐个字符扫描字符串，直到找到运算符。 由于操作员保证是其中之一`+`,`-`,`*`,`/`,`%`并且只有一个，第一个出现的是运算符。 
3. 在运算符处分割字符串。 它前面的子串是`a`以及它后面的子字符串`b`。 将两个子字符串转换为整数。 
4. 根据运算符，执行相应的运算：加法、减法、乘法、整数除法或取模。 
5. 将结果打印为整数。 对于除法，Python 的`//`运算符正确处理截断除法。 

为什么它有效：该算法在评估之前的任何点都保持不变量，`a`和`b`正是输入字符串中的整数值，并且运算符被正确识别。 输入中没有其他操作或歧义，因此会产生正确的算术结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

expr = input().strip()

for i, c in enumerate(expr):
    if c in '+-*/%':
        op_index = i
        break

a = int(expr[:op_index])
b = int(expr[op_index+1:])
op = expr[op_index]

if op == '+':
    result = a + b
elif op == '-':
    result = a - b
elif op == '*':
    result = a * b
elif op == '/':
    result = a // b
elif op == '%':
    result = a % b

print(result)
```第一个循环通过从左到右扫描来查找运算符。 将字符串切片转换为整数可确保正确处理多位数。 从运算符字符到算术运算的条件映射实现了精确的求值规则。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    expr = input().strip()
    for i, c in enumerate(expr):
        if c in '+-*/%':
            op_index = i
            break
    a = int(expr[:op_index])
    b = int(expr[op_index+1:])
    op = expr[op_index]
    if op == '+':
        result = a + b
    elif op == '-':
        result = a - b
    elif op == '*':
        result = a * b
    elif op == '/':
        result = a // b
    elif op == '%':
        result = a % b
    return str(result)

# provided sample
assert run("123+456") == "579", "sample 1"

# custom cases
assert run("1+1") == "2", "minimum values"
assert run("999*999") == "998001", "maximum values"
assert run("100-100") == "0", "equal numbers subtraction"
assert run("999/3") == "333", "integer division"
assert run("100%3") == "1", "modulo operation"

 ## 边缘情况

 对于表达式`1+1`，算法正确找到`+`在索引 1 处，解析`a=1`和`b=1`，输出 2。对于`999/3`，它识别`/`在索引 3 处，解析`a=999`和`b=3`，执行整数除法`//`，产生 333。对于`100%3`，它识别`%`和输出 1。在每种情况下，切片和运算符检测都很稳健，并且算法无需特殊处理即可生成正确的结果，因为保证输入与预期格式匹配。
