 ## 解决方案
 ## 问题理解

 给定一个仅由数字组成的字符串，任务是确定数字“666”是否作为连续序列出现在该字符串内的任何位置。 如果是，则输出应为“YES”，否则输出应为“NO”。 这是一个模式检测问题，而不是数值计算问题，因此数字的实际大小无关紧要； 我们将输入纯粹视为字符序列。 

该字符串可以短至一位数字，也可以长至 100 位数字。 由于 100 对于现代计算极限而言是一个非常小的数字，因此我们不需要高度复杂的算法。 即使检查每个可能的长度为 3 的子串的方法也能高效运行，因为此类子串的最大数量约为 98。 

非明显的边缘情况涉及短于三位数的字符串，其中不可能将“666”作为子字符串。 例如，输入“66”必须输出“NO”。 另一种边缘情况是“666”出现在字符串的开头或末尾，例如“666123”或“123666”。 仅扫描字符串中间的粗心实现可能会错过这些事件。 包含长度超过 3 的重复数字的字符串（如“6666”）仍应生成“YES”，因为重复序列中存在长度为 3 的连续子字符串。 

## 方法

 一种天真的暴力方法将涉及迭代字符串中长度为三的每个子字符串并检查它是否匹配“666”。 这种方法是正确的，因为它显式地检查每个候选者，但如果字符串比我们的约束允许的长得多，它就会变得低效。 最坏情况下的检查次数大约为`n-2`比较，其中`n`是字符串长度。 对于最大长度 100，这只是 98 次检查，这很简单。 

最佳方法依赖于 Python 的内置子字符串搜索。 这`in`操作员可以在相对于字符串长度的线性时间内检查字符串中是否包含“666”。 这避免了手动索引，减少了样板代码，并正确处理所有边缘情况。 关键的见解是，这个问题简化为简单的模式成员资格检查，而 Python 为此提供了高度优化的机制。

 ## 算法演练

 1. 读取输入字符串并去除所有尾随换行符或空格字符。 这确保我们只处理数字本身。 
2. 使用以下命令检查输入字符串中的任意位置是否包含字符串“666”`in`操作员。 这样可以一次有效地扫描字符串。 
3. 如果找到“666”，则打印“YES”。 否则，打印“NO”。 

为什么它有效：该算法保持了我们已经扫描字符串以查找特定模式“666”的不变式。 由于我们在线性扫描中检查整个字符串，因此不可能丢失有效的子字符串。 正确性源于 Python 中的子字符串成员资格是精确的并且尊重连续性，这符合问题要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

p = input().strip()

if "666" in p:
    print("YES")
else:
    print("NO")
```一线进口`sys`并重新绑定`input`到`sys.stdin.readline`用于快速输入读取。 我们立即删除所有尾随空格以避免漏报。 这`in`运算符对字符串执行线性扫描以检查连续序列“666”。 最后，我们根据是否找到子字符串打印正确的响应。

 ## 边缘情况

 少于三个字符的字符串不能包含“666”，例如“66”。 该算法返回“NO”，因为`in`运算符检查长度为 3 的所有连续子字符串，但没有找到。 对于长于三的重复六，例如“6666”，算法仍返回“YES”，因为子字符串“666”存在于多个位置处。 由于搜索会扫描整个字符串而不跳过任何位置，因此可以正确检测到开头或结尾的子字符串（例如“666123”或“123666”）。
