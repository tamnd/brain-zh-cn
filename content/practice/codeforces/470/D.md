 ## 解决方案
 ## 问题理解

 我们被要求实现一个简单的凯撒密码。 输入给了我们一个密钥`k`，0 到 25 之间的整数，表示消息中的每个字母应在字母表中向前移动多少个位置。 消息本身是一串大写拉丁字母，长度范围为1到10个字符。 我们的任务是通过应用此转换来输出加密消息。 

这些约束使这个问题变得简单：由于消息非常短，我们不需要担心算法的效率。 即使是循环每个字符并执行算术来移动它的简单实现也将在微秒内运行。 唯一的微妙之处是正确地环绕字母表。 例如，将“Z”移动 1 应生成“A”。 粗心的实现可能会尝试添加`k`直接转换为 ASCII 值，并忘记对 26 进行换行，这会给出无效字符。 

当移位为 0 时，会出现另一种边缘情况。在这种情况下，加密的消息应该与输入相同，并且总是添加一个简单的实现`k`如果应用模数，则换行模 26 将正确处理此问题。 

## 方法

 自然而然地出现了一种暴力方法。 对于消息中的每个字符，我们通过减去“A”的 ASCII 值将其转换为字母表中从 0 开始的位置。 然后我们添加`k`并取模 26 来处理换行。 最后，我们通过添加 'A' 的 ASCII 值将其转换回字符。 这适用于任何输入，因为每个操作都是恒定时间的，并且最多有 10 个字符。 由于输入量很小，暴力方法在这里是完全可以接受的。 不需要在时间复杂度方面进行任何优化。 关键的见解是认识到凯撒密码只是 26 个字母的模算术。 这使得实现既简单又数学精确。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(n) | 已接受 |
 | 最佳| O(n) | O(n) | 已接受 |

 在这种情况下，强力方法和最佳方法实际上是相同的，因为问题的约束允许我们单独处理每个角色，而不必担心性能。 

## 算法演练

 1.读取加密密钥`k`来自输入。 这个整数告诉我们每个字母要移动多少个位置。 
2. 读取一串大写字母的原始消息。 我们将独立处理每封信件。 
3. 初始化一个空列表或字符串来构建加密消息。 我们在 Python 中选择列表是为了提高效率，因为循环中的字符串连接效率较低。 
4. 迭代每个字符`c`在消息中。 转变`c`通过计算到其从 0 开始的字母表索引`ord(c) - ord('A')`。 
5. 添加`k`到该索引并应用模 26。这可确保移位正确环绕字母表。 
6. 通过添加将结果索引转换回字符`ord('A')`并将其附加到结果列表中。 
7. 处理完所有字符后，将列表连接成单个字符串并打印。 

工作原理：每个字符都独立映射到其正确的移位值，并且模运算保证索引始终保持在字母表的范围内。 该过程保留了字母的顺序，仅根据凯撒密码规则转换每个字母，因此正确性直接来自算术。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

k = int(input())
message = input().strip()

encrypted = []

for c in message:
    index = ord(c) - ord('A')
    shifted = (index + k) % 26
    encrypted.append(chr(shifted + ord('A')))

print(''.join(encrypted))
```在此解决方案中，我们首先读取密钥和消息。 我们从消息中删除换行符以防止它影响结果。 每个字符都转换为索引，以模 26 移位，然后转换回字符。 使用列表来累积字符可以避免重复连接字符串的低效率。 最后，我们加入该列表以形成最终的加密消息。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    k = int(input())
    message = input().strip()
    encrypted = []
    for c in message:
        index = ord(c) - ord('A')
        shifted = (index + k) % 26
        encrypted.append(chr(shifted + ord('A')))
    return ''.join(encrypted)

 ## 边缘情况

 如果密钥为0，则每个字母保持不变。 例如，`0`和`HELLO`产生`HELLO`。 该算法计算`(index + 0) % 26`对于每个字母，每次都返回原始索引。 

当字母位于字母表末尾时（例如“Z”），按任何正数移动`k`以 26 为模进行换行。对于输入`1`和`Z`，算法计算`(25 + 1) % 26 = 0`，映射到“A”，正确处理环绕。 对于所有“Z”和班次 1 的消息，每个字母都映射到“A”，正如自定义测试中所确认的那样。
