 ## 解决方案
 ## 问题理解

 任务是计算两个长度相等的字符串之间的汉明距离。 实际上，您正在比较两个字母序列并计算有多少位置包含不同字符。 每个不匹配对距离的贡献正好为 1。 例如，比较`CODECHEF`和`TOPCODER`，每个字母不同的位置将总数加一，产生距离 6。 

输入约束很简单：字符串的长度在 1 到 100 之间。这意味着问题规模非常小，因此即使是显式逐一比较每个字符的解决方案也能在时间限制内顺利运行。 内存也不是问题，因为我们只需要存储两个短字符串和一个计数器。 主要的边缘情况涉及长度为 1 的最短字符串、相同的字符串或每个字符都不同的字符串。 例如，字符串`A`和`A`应该产生一个距离`0`， 然而`A`和`B`生产`1`。 粗心的实现可能会意外地忽略第一个或最后一个字符，或者当字符串相同时错误计数。 

## 方法

 由于输入量较小，暴力方法也是此处的最佳方法。 您可以并行迭代字符串，比较相同索引处的字符。 每次字符不同时，您都会增加一个计数器。 在循环结束时，计数器包含总汉明距离。 这个方法是正确的，因为它直接实现了汉明距离的定义：不同位置的数量。 

对于此问题，没有更快的渐近算法，因为您必须至少检查每个字符一次以确定它是否匹配或不同。 任何通过预处理或巧妙的位操作进一步优化的尝试只会使解决方案变得复杂，而不会改善运行时间，因为 n ≤ 100。唯一潜在的陷阱是索引中的差一错误以及忘记正确处理长度为 1 的字符串。

 ## 算法演练

 1. 读取两个输入字符串。 由于保证字符串长度相等，因此不需要额外的检查。 
2. 将计数器变量初始化为零。 这将保持汉明距离。 
3. 迭代从 0 到 n-1 的字符串索引。 对于每个索引，比较两个字符串中的字符。 
4. 如果字符不同，则将计数器加一。 这直接捕获了汉明距离的定义。 
5. 迭代完成后，打印计数器。 这表示不匹配位置的总数。 

为什么它有效：该算法保持一个不变量，即计数器始终等于迄今为止看到的不匹配字符的数量。 通过迭代每个位置并检查字符一次，我们保证不会遗漏或重复计算任何不匹配。 由于考虑了每个索引，最终的计数器正是汉明距离。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s1 = input().strip()
s2 = input().strip()

distance = 0
for c1, c2 in zip(s1, s2):
    if c1 != c2:
        distance += 1

print(distance)
```该解决方案使用快速输入读取两个字符串。 这`strip()`调用会删除任何可能导致错误不匹配的尾随换行符。 循环使用`zip`同时迭代两个字符串，这比使用索引计数器更干净。 每次不匹配都会增加距离计数器。 最后，我们打印结果。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    s1 = input().strip()
    s2 = input().strip()
    distance = sum(1 for c1, c2 in zip(s1, s2) if c1 != c2)
    return str(distance)

# provided sample

 ## 边缘情况

 对于最小的字符串，例如`A`和`B`，算法初始化`distance = 0`，比较唯一的字符，由于它们不同而递增一次，然后打印`1`。 对于相同的字符串，例如`XYZXYZ`和`XYZXYZ`，计数器永远不会增加，产生`0`。 每个字符都不同的字符串，例如`AAAA`和`BBBB`，在每个索引处递增计数器，生成字符串的长度作为距离。 在所有情况下，迭代不变式都确保正确性，并且解决方案处理所有可能的输入范围。
