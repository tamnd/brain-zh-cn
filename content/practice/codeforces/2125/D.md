 ## 解决方案
 ## 问题理解

 我们正在与一系列$m$细胞。 每个单元格最终必须被恰好一个选定的间隔覆盖。 

有$n$候选片段。 各段$i$覆盖一个连续的范围$[l_i, r_i]$，但不保证它存在。 相反，它以概率独立出现$p_i / q_i$。 解决所有随机性后，我们查看实际存在的段集。 我们想要这些活动段形成线的完美划分的概率：从 1 到$m$恰好被一个活动段覆盖，没有重叠，也没有间隙。 

输出是这个概率模$998244353$，表示为模分数。 

约束条件达到$2 \cdot 10^5$段和$2 \cdot 10^5$细胞。 这立即排除了枚举段的所有子集，因为即使$2^n$是一个天文数字。 在最坏的情况下，即使是段上的二次 DP 也会太慢，因此任何解决方案都必须以类似于排序端点上的线性或近线性时间的方式处理间隔。 

当多个段重叠同一区域时，会出现一个微妙的问题。 一种幼稚的解释可能建议独立处理每个单元，但独立性会立即打破，因为片段跨越范围。 另一个常见的陷阱是乘以形成平铺的段的概率，而不校正不存在的段：正确的计算必须包括存在概率和干扰段的排除。 

一个小的边缘案例阐明了这个困难。 认为$m=2$，有段$[1,2]$和$[1,1],[2,2]$。 一种幼稚的方法可能会认为“要么我们采用大段，要么采用两个小段”，但正确性条件要求精确覆盖而没有重叠。 如果这三个都出现，则配置无效，即使每个小区都被覆盖。 这表明我们必须确保覆盖范围的唯一性，而不仅仅是覆盖范围。 

## 方法

 蛮力的想法很简单：枚举段的每个子集，计算其发生的概率，并检查它是否形成有效的平铺$[1,m]$。 对于每个子集，我们将通过标记单元格或排序间隔并确保它们形成不相交的链来验证覆盖范围。 这已经花费了$O(n \cdot m)$或者$O(n \log n)$每个子集取决于验证，并且有$2^n$子集，因此总数是指数级的并且不可用。 

关键结构是有效配置的行为必须类似于线路的链式分解。 如果我们固定选择哪些段，则“每个单元仅被覆盖一次”的条件会强制所选段将其划分为完全匹配的连续非重叠块$[1,m]$。 这意味着任何有效的配置都对应于选择精确平铺前缀间隔的段序列。 

现在考虑翻转视角。 我们没有直接对子集进行推理，而是将概率分为两部分：段的独立存在，以及从这些现有段中选择有效平铺的组合结构。 这表明 DP 位于段的正确端点上。 

对于每个段，我们将其视为在位置结束的平铺的潜在最后一块$r$。 如果一个段$[l,r]$被选为最后一件作品，然后是之前的所有作品$l$必须已经形成有效的平铺$[1,l-1]$。 这给出了从$l-1$到$r$。 

存在片段的概率贡献是$p_i/q_i$，虽然缺席有助于$(q_i-p_i)/q_i$。 一个标准技巧是分解全局的所有分母。 我们将最终答案乘以所有结果的乘积$q_i^{-1}$稍后进行调整，在加权系统中有效地工作，其中每个部分贡献$p_i$或者$(q_i-p_i)$取决于它是用于选定的平铺结构还是排除在外。 

主要的简化变成了加权间隔 DP：计算平铺前缀的方法，其中每个段根据是否被选为结构边缘贡献乘法权重，并且转换仅发生在段端点处。 

我们在位置上维护一个 DP 数组，其中$dp[i]$表示形成正确的前缀平铺的总加权概率质量$[1,i]$。 对于每个结束于$r$，我们添加过渡$l-1$到$r$乘以该段的概率权重。 为了清楚地考虑独立性，我们预先计算乘法因子，以便每个部分都做出贡献$p_i \cdot inv(q_i)$当使用时，而不使用时由规范化隐式处理。 

这将问题转化为端点上的经典区间 DP，可在排序段上以线性时间求解。

 ## 算法演练

 1. 对于每个分段，使用以下公式将其概率转换为模块化形式：$prob_i = p_i \cdot q_i^{-1}$。 这让我们可以使用模算术而不是分数。 
2. 为每个右端点构建一个邻接结构$r$，我们存储所有以$r$成对$(l, prob_i)$。 这是必要的，因为 DP 转换取决于段端点。 
3. 初始化一个DP数组，其中$dp[i]$存储形成有效的精确前缀平铺的总概率$[1,i]$。 放$dp[0] = 1$，因为空前缀通常是有效的。 
4.从1扫位置到$m$。 在每个位置$i$, 计算$dp[i]$通过将所有结束于的部分的贡献相加$i$。 各段$(l,i)$贡献$dp[l-1] \cdot prob_i$。 这表示扩展有效的平铺$[1,l-1]$有一个段覆盖$[l,i]$。 
5.最终答案是$dp[m]$，因为它精确计算所有有效的全覆盖瓷砖。 

### 为什么它有效

 恰好覆盖每个单元一次的任何有效的段配置都会导致将线独特地划分为连续的块。 每个块恰好对应一个选定的段。 DP 通过选择每个前缀的最后一个块来枚举这些分区。 因为分段是独立的，并且我们直接乘以它们的存在概率，所以每个有效的平铺仅以正确的概率权重贡献一次。 无效重叠永远不会出现，因为转换仅从精确的前缀边界延伸，从而强制执行严格的分区结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, m = map(int, input().split())
    ends = [[] for _ in range(m + 1)]

    for _ in range(n):
        l, r, p, q = map(int, input().split())
        prob = p * modinv(q) % MOD
        ends[r].append((l, prob))

    dp = [0] * (m + 1)
    dp[0] = 1

    for i in range(1, m + 1):
        total = 0
        for l, prob in ends[i]:
            total = (total + dp[l - 1] * prob) % MOD
        dp[i] = total

    print(dp[m])

if __name__ == "__main__":
    solve()
```该实现依赖于按右端点对段进行分组，以便每个 DP 状态仅处理相关的转换。 这避免了$O(nm)$扫描每个位置的所有段。 

模逆用于将每个概率转换为域元素。 由于概率在选定的段之间独立相乘，因此这种表示在模算术下保留了正确性。 

一个微妙的实现细节是初始化$dp[0]=1$。 如果没有这个，第一段将永远无法正确贡献，因为每个有效的平铺都必须从位置 1 开始。 

## 工作示例

 ### 示例 1

 输入：```
3 3
1 2 1 3
3 3 1 2
1 3 2 3
```我们计算概率：

 - [1,2]：1/3
 - [3,3]：1/2
 - [1,3]：2/3

 我们跟踪 DP：

 | 我| 以 i 结尾的段 | dp[i] 计算 | dp[i] | dp[i] |
 | --- | --- | --- | --- |
 | 0 | - | 基地| 1 |
 | 1 | - | 没有段结束 | 0 |
 | 2 | [1,2]| dp[0] * 1/3 | dp[0] * 1/3 | 1/3 | 1/3
 | 3 | [3,3], [1,3] | dp[2]*1/2 + dp[0]*2/3 | 5/18 |

 所以最终的答案是$5/18$，匹配样本。 

这证实了 DP 正确地枚举了两种可能的平铺：使用完整的段，或分成两部分。 

### 示例 2

 输入：```
2 2
1 2 1 2
1 1 1 1
```概率：

 - [1,2] = 1/2
 - [1,1] = 1

 DP:

 | 我| 以 i 结尾的段 | dp[i] | dp[i] |
 | --- | --- | --- |
 | 0 | - | 1 |
 | 1 | [1,1]| 1 |
 | 2 | [1,2]| dp[0]*1/2 = 1/2 | dp[0]*1/2 = 1/2 |

 最终答案是$1/2$。 

这表明 DP 可以正确处理单例平铺和全覆盖替代方案。

 ## 边缘情况

 一个关键的边缘情况是，多个段在同一区域上严重重叠，从而迫使不兼容的切片之间发生竞争。 例如，考虑全部覆盖的段$[1,m]$。 在有效配置中只能使用一个这样的段，DP 自然会处理这一点，因为每个段独立地贡献一个转换，并且转换的总和代表互斥的选择。 

另一种情况是，除非选择特定细分市场，否则覆盖范围存在差距。 假设只有一个段覆盖$[1,3]$中间分区没有其他内容。 DP 强制通过该段进行唯一有效的转换，如果其概率较低，它会直接相应地缩放最终结果。 

第三种情况涉及许多段以不同的起点结束于同一位置。 DP 正确地将所有可能的最后一步选择累积到同一状态中，确保不会重复计算任何配置，因为每个分块恰好对应于每个前缀处的一个最终段。
