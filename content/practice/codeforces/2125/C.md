 ## 解决方案
 ## 问题理解

 如果一个数在素数分解中没有一个素数是单位数素数，则该数被称为好数。 唯一的个位数素数是 2、3、5 和 7，因此当一个数不能被这四个素数中的任何一个整除时，它就是好数。 

任务是计算一个范围内有多少个整数$[l,r]$满足这个性质。 

这些限制完全改变了我们思考问题的方式。 区间端点可以大到$10^{18}$，因此将数字一一分解是不可能的。 即使迭代该区间也是不可能的，因为该范围本身最多可以包含$10^{18}$数字。 我们需要一个直接作用于端点的计数公式。 

关键的观察结果是，该定义仅取决于能否被四个特定素数整除。 我们不关心一个数是否包含更大的素数，因为每个素数至少有两位数是允许的。 

一些边缘情况很容易被忽略。 

考虑范围：```
13 37
```答案是 7，而不是 25。这个区间内的大多数数字都可以被 2、3、5 或 7 整除，因此必须排除。 

考虑：```
11 11
```答案是 1。数字 11 本身就是一个两位素数，所以它很好。 

考虑：```
14 14
```答案是 0。虽然 14 只包含一次素数 7，但这足以使它变坏。 多重性并不重要。 

考虑：```
49 49
```答案是 0。一些解决方案错误地仅检查出现一次的小于 7 的质因数。 自从$49=7^2$，它仍然可以被 7 整除并且仍然不好。 

问题实际上是要求不能被 2、3、5 或 7 中的任何一个整除的整数的个数。 

## 方法

 强力解决方案会迭代区间中的每个数字，对其进行因式分解，并验证所有质因数是否至少为 10。这是正确的，因为它直接实现了定义。 

不幸的是，即使检查单个长度间隔$10^{18}$是不可能的。 对一个数进行因式分解大约需要$O(\sqrt n)$工作，并且可能有$10^{18}$要检查的数字。 

关键的观察是，当且仅当一个数字不能被 2、3、5 或 7 整除时，该数字才是好数字。 

这将问题转化为经典的计数问题。 不要直接识别好数字，而是计算所有可被这四个素数中的至少一个整除的数字，然后从总数中减去它们。 

每当我们需要同时计算可被多个集合整除的数字时，包含-排除就是自然的工具。 仅涉及四个素数，因此子集的数量很少：$$2^4=16.$$对于任何$x$， 让$F(x)$表示好整数的个数$[1,x]$。 

可被素数的特定子集整除的整数的个数等于$$\left\lfloor \frac{x}{\operatorname{lcm}(\text{subset})} \right\rfloor.$$由于质数是不同的，因此 LCM 只是它们的乘积。 

应用包含-排除给出可被至少一个禁止素数整除的整数的计数。 从中减去$x$产量$F(x)$。 查询的答案变为$$F(r)-F(l-1).$$| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O((r-l+1)\sqrt r)$|$O(1)$| 太慢了|
 | 最佳|$O(2^4)$每个测试用例|$O(1)$| 已接受 |

 ## 算法演练

 设禁忌素数为：$$P=\{2,3,5,7\}.$$对于给定值$x$， 定义$F(x)$作为好整数的数量$[1,x]$。 

1. 开始于`bad = 0`。 
2. 枚举每个非空子集$\{2,3,5,7\}$。 
3. 计算子集中素数的乘积。 由于质数不同，该乘积也是它们的最小公倍数。 
4. 计算有多少个整数$[1,x]$可以被这个产品整除：$$\left\lfloor \frac{x}{\text{product}} \right\rfloor.$$5. 如果子集大小为奇数，则将此数量添加到`bad`。 
6. 如果子集大小是偶数，则从`bad`。 

这正是包含排除原则。 
7. 处理完所有子集后，`bad`等于中的整数个数$[1,x]$能被至少一个禁止素数整除。 
8. 计算$$F(x)=x-bad.$$9. 对于每个查询$[l,r]$， 输出$$F(r)-F(l-1).$$### 为什么它有效

 当一个数至少属于其中一个集合时，它就是坏数$$A_2,A_3,A_5,A_7,$$在哪里$A_p$包含可被整除的数字$p$。 

包含-排除计算并集的大小$$|A_2\cup A_3\cup A_5\cup A_7|$$确切地。 每个能被一个禁止素数整除的数字贡献一次。 每个可以被多个禁止素数整除的数字都可以通过包含-排除的交替符号来纠正。 

从总计数中减去联合大小$x$使这些数字完全不能被任何禁止的素数整除。 这些正是好的数字，所以$F(x)$是正确的。 服用$F(r)-F(l-1)$将计数限制为请求的间隔。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

PRIMES = [2, 3, 5, 7]

def count_good(x):
    if x <= 0:
        return 0

    bad = 0

    for mask in range(1, 16):
        prod = 1
        bits = 0

        for i in range(4):
            if mask & (1 << i):
                prod *= PRIMES[i]
                bits += 1

        cnt = x // prod

        if bits & 1:
            bad += cnt
        else:
            bad -= cnt

    return x - bad

def solve():
    t = int(input())

    ans = []

    for _ in range(t):
        l, r = map(int, input().split())
        ans.append(str(count_good(r) - count_good(l - 1)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```功能`count_good(x)`计算前缀中好整数的数量$[1,x]$。 

掩码上的循环表示所有非空子集`{2,3,5,7}`。 由于只有四个素数，因此恰好存在十五个非空子集。 

对于每个子集，我们计算其乘积和前缀内的倍数。 奇数大小的子集贡献正向，偶数大小的子集贡献负向，匹配包含-排除。 

表达式`x - bad`将坏数的计数转换为好数的计数。 

最终答案使用标准前缀计数技术：$$\text{answer}=F(r)-F(l-1).$$所有算术都适合 64 位整数，因为最大的中间乘积是$$2\cdot3\cdot5\cdot7=210,$$而Python整数无论如何都支持任意精度。
