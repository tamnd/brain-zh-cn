 ## 解决方案
 ## 问题理解

 我们从放置在一个坐标处的机器人开始$(a,b)$在无限网格上，我们想将其移回原点$(0,0)$。 每个动作都是通过选择一对来定义的$(dx,dy)$两个组件之间的位置$0$和$k$，然后从当前位置减去该向量。 所以机器人的每一个动作都会向左移动$dx$并向下$dy$。 同一对$(dx,dy)$可以重复使用，但只有第一次需要花费1，之后就免费了。 

真正的决定不是最小化移动次数，而是最小化我们使用的不同移动向量的数量。 一旦引入向量，就可以任意多次重复使用，无需额外费用。 

约束条件达到$10^{18}$对于坐标和$k$，因此任何依赖于迭代可能的向量或逐步构建路径的解决方案都是不可能的。 整个解决方案必须将问题简化为向量的可分性或结构特性的推理。 

一个关键的微妙之处是机器人可以混合不同的向量。 天真的直觉可能表明我们需要一个单一的向量来达到$(a,b)$确切地说，但这不是必需的。 我们只需要一组允许的向量，其总和等于$(a,b)$。 

当贪婪方法试图重复减去类似的东西时，就会出现常见的失败情况$(k,k)$或者$(k,0)$。 例如，如果$(a,b)=(3,5)$和$k=2$，贪婪地使用最大移动会失败，因为没有单个移动可以直接到达目标，并且错误地混合方向可能会导致不必要的不​​同向量。 

另一个微妙的边缘情况是当$a$和$b$足够独立，我们需要多个运动“方向”，但仍然足够小，两个精心选择的向量可以精确地跨越两个坐标。 

## 方法

 成本结构将问题转化为最小化重复使用可以表达向量的不同向量的数量$(a,b)$作为总和，每个向量受以下约束$0 \le dx,dy \le k$。 

强力的观点是考虑允许向量的所有可能的子集，并且对于每个子集尝试查看是否$(a,b)$可以表示为这些向量的非负整数组合。 这立即失败，因为有$(k+1)^2$可能的向量，最多可达$10^{36}$，甚至使枚举变得不可能。 

关键的见解是，我们实际上并不关心使用向量多少次，只关心它是否出现。 那么问题就变成了：向量内最少有多少个向量？$k \times k$其非负线性组合可以生成的网格$(a,b)$？ 

由于所有向量都位于第一象限，因此每个组合都保持单调性，并且我们使用小型生成集有效地覆盖了 2D 锥体中的点。 在二维中，如果选择正确，任何目标始终可以使用最多两个向量来表示，除非其中一个坐标强制采用简并结构。 

因此，答案简化为检查一个向量是否足够，否则确定两个向量是否足够，否则需要三个向量。 

仅当两个坐标均可被边界内的同一步长整除时，单个向量就足够了，这意味着$(a,b)$其本身必须位于由某些物体产生的射线上$(dx,dy)\le k$，这正是可能的$\max(a,b)\le k$或者当该对可以缩小为有效的有界整数向量时。 

如果一个向量不够，我们会问是否可以找到两个向量$(x_1,y_1)$和$(x_2,y_2)$这样：$$a = \alpha x_1 + \beta x_2,\quad b = \alpha y_1 + \beta y_2$$对于一些非负整数$\alpha,\beta$。 在有界坐标的二维中，这总是可能的，除非两个坐标都需要多个“单位方向”，而这种情况仅当两个坐标都需要时才会发生。$a > k$和$b > k$，并且它们不能通过共享斜率对齐。 

结构的简化导致了清晰的分类：

 如果$\gcd(a,b)$允许一个方向在边界内，答案是1； 否则答案为 2，除非两个坐标都超过$k$以强制三个独立方向的方式，这在这种结构下永远不会发生，所以答案最多总是 2。 

因此最终的逻辑简化为检查是否$(a,b)$本身作为一个动作是可行的，否则两个动作就足够了。

 ## 算法演练

 我们将问题转化为决定需要多少个不同的步骤向量。 

1. 检查是否可以用一个向量来完成。 这就要求存在$(dx,dy)$这样反复应用它就可以准确地达到$(a,b)$。 这意味着$(dx,dy)$必须除以两个坐标：$a = t \cdot dx$,$b = t \cdot dy$，以及两者$dx,dy \le k$。 最好的候选人是$(a,b)$如果两者都在范围内，则为自身。 
2.如果$\max(a,b) \le k$，那么我们可以选择单一操作$(a,b)$并一举完成。 
3. 否则，我们通过缩小来检查一个向量是否仍然可以工作。 如果$\gcd(a,b) = g$，则原始方向为$(a/g, b/g)$。 如果这个原始向量的两个分量都是$\le k$，我们可以反复使用它。 
4. 如果原始方向超过$k$，那么没有一个向量可以精确地生成两个坐标，因为任何有效的生成器必须位于同一射线上，但不大于$k$。 
5. 在这种情况下，我们使用两个向量。 一个可以独立处理类似水平的进度和另一个类似垂直的进度，并且因为两个轴都是单调的并且独立有界，所以两个方向总是足够的。 

### 为什么它有效

 所有移动都是相加的，并且仅限于第一象限，因此每个解决方案都对应于分解$(a,b)$转化为向量的总和$[0,k]^2$。 任何有效的分解都会崩溃为二维中最多两个独立方向的最小生成集。 如果单个方向符合边界，它会生成一个完全覆盖目标的 1 级圆锥体。 如果不是，则目标必然需要至少两个独立的方向，并且在二维中，两个方向足以跨越可到达晶格中的任何点。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        a, b, k = map(int, input().split())
        
        # If we can directly jump to (0,0) in one move
        if max(a, b) <= k:
            out.append("1")
            continue
        
        # Check if a single direction can generate both
        g = math.gcd(a, b)
        x = a // g
        y = b // g
        
        if x <= k and y <= k:
            out.append("1")
        else:
            out.append("2")
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该代码首先处理目标点本身是有效移动的简单情况，因为这会立即给出成本 1。然后它会减少向量$(a,b)$使用 gcd 到其原始方向。 如果该方向适合允许的框，则重复使用它即可构造目标，而不需要任何其他向量。 否则，我们得出结论，至少需要两个不同的向量，所以答案是 2。 

一个微妙的点是仅检查原始方向就足够了。 如果它的任何缩放版本适合边界，则图元也必须适合，因此该条件既是必要的也是充分的。

 ## 边缘情况

 当一个坐标远大于$k$，但另一个很小。 例如，$(a,b,k) = (100,1,50)$。 直接检查失败的原因是$100 > 50$。 最大公约数是$1$，所以原始方向是$(100,1)$，这也超过了$k$。 该算法正确输出 2，因为没有任何单一有界方向可以重现这种不平衡的斜率。 

另一种情况是两个坐标相等且足够小，例如$(5,5,10)$。 这里直接条件立即成功，答案是 1。 gcd 路径也证实了这一点，因为原始方向是$(1,1)$，它位于界限内，强化了重复对角线移动就足够了。 

最后一个微妙的情况是$(a,b)$共享一个大的gcd但减少的方向仍然违反界限，例如$(30,45,10)$。 原语是$(2,3)$，它符合限制，因此只需要一个向量。 这表明缩小比例是检测可行性的正确方法，而不是原始坐标。
