 ## 解决方案
 ## 问题理解

 六名玩家中的每一位都以 1 级神奇宝贝开始。 将神奇宝贝提升等级$k-1$达到水平$k$，我们必须准确地花费$k-1$体验水晶。 

For each player, we are given a target level$a_i$。 我们必须确定需要多少水晶才能将神奇宝贝从1级一直提升到1级$a_i$，并输出所有六名玩家的答案。 

目标水平可以大到$10^9$。 这立即排除了任何逐一模拟升级的方法。 单个神奇宝贝可能需要近十亿个升级步骤，这远远超出了一秒的时间限制。 

关键的挑战不是玩家的数量，因为总是有六个人。 挑战在于计算非常大的目标级别的总晶体成本，而无需迭代每个中间级别。 

有一些边缘情况很容易被错误处理。 

假设目标级别已经是 1：```
1 1 1 1 1 1
```正确的输出是：```
0 0 0 0 0 0
```无需升级。 粗心的公式可能会意外地包含一个额外的项并产生肯定的答案。 

考虑目标级别 2：```
2 2 2 2 2 2
```正确的输出是：```
1 1 1 1 1 1
```Only the upgrade from level 1 to level 2 is required, costing exactly 1 crystal. 这里经常出现相差一的错误。 

最大级别也很重要：```
1000000000
```答案大约是$5 \times 10^{17}$，它不适合 32 位整数。 Languages with fixed-width integer types require 64-bit arithmetic. Python handles this automatically, but the mathematical size should still be kept in mind.

 ## 方法

 A direct simulation is the most natural starting point. 如果目标水平是$a$，我们可以添加每次升级的成本：$$1 + 2 + 3 + \cdots + (a-1)$$这是有效的，因为从 1 级升级到 2 级需要花费 1，从 2 级到 3 级需要花费 2，依此类推，直到最终升级到级别$a$。 

问题是运行时间。 为了$a=10^9$，我们将为单个玩家执行大约 10 亿次加法。 虽然只有六名玩家，但数十亿的运算速度还是太慢了。 

观察结果是，所需的总和是一个众所周知的算术级数：$$1+2+\cdots+n=\frac{n(n+1)}{2}$$这里$n=a-1$，因此总晶体成本变为$$\frac{(a-1)a}{2}$$无论级别有多大，该公式都会在恒定时间内计算答案。 由于只有六个输入，我们只需应用公式六次并打印结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 每个玩家 O(a) | O(1) | O(1) | 太慢了|
 | 最佳| 每个玩家 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读六个目标级别。 
2. 对于每个目标级别$a$，计算总晶体成本为：$$\frac{a(a-1)}{2}$$这是从 1 级到 1 级的所有升级成本的总和$a$。 
3. 存储六个计算值。 
4. 输出六个答案，以空格分隔。 

### 为什么它有效

 达到水平$a$，神奇宝贝必须执行每次升级：$$1 \to 2,\quad 2 \to 3,\quad \ldots,\quad (a-1)\to a$$这些升级的成本为：$$1,2,3,\ldots,a-1$$所需晶体总数恰好是这些整数的总和。 算术级数公式指出$$1+2+\cdots+(a-1)=\frac{a(a-1)}{2}$$由于算法为每个玩家精确计算该值，因此每个输出都是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

levels = list(map(int, input().split()))

ans = [a * (a - 1) // 2 for a in levels]

print(*ans)
```The program reads the six target levels into a list.

 对于每个级别`a`，它评估`a * (a - 1) // 2`，这是之前导出的算术级数公式。 使用整数除法是因为结果始终是整数。 

答案收集在一个列表中，并打印在一行上，以空格分隔，匹配所需的输出格式。 

A common off-by-one mistake is to compute`a * (a + 1) // 2`。 这将从 1 到`a`，但最终的升级成本仅为`a - 1`，所以正确的公式是`a * (a - 1) // 2`。 

Python 整数会自动扩展到任意大小，因此即使是最大的可能答案$a=10^9$被安全处理。

```这是正确的，因为神奇宝贝从 1 级开始，不需要升级。
