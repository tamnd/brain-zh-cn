 ## 解决方案
 ## 问题理解

 我们被要求构造一个大小为$n \times m$在哪里$n$和$m$保证是均匀的。 约束是每个像元必须恰好有两个值与其自身值不同的邻居。 邻居被定义为直接相邻的四个单元格。 输入由多个测试用例组成，每个测试用例指定$n$和$m$，输出是满足邻居约束的任何矩阵。 

由于两个维度都是均匀且相当小的（$2 \le n,m \le 50$），我们可以负担得起运行在$O(nm)$每个测试用例的时间。 一种简单的方法会尝试测试所有二进制矩阵，但是有$2^{nm}$的可能性，这是完全不可行的。 该问题保证所有给定输入都存在解决方案，因此我们的目标是建设性的：找到始终满足邻居属性的模式。 

边缘情况包括最小矩阵$2 \times 2$以及两个尺寸相等且更大的情况，例如，$50 \times 50$。 粗心的方法可能会尝试交替行或列而不考虑四个邻居，从而产生具有两个以上不同邻居的单元格。 

## 方法

 暴力方法将生成所有$2^{nm}$矩阵并检查邻居属性。 每张支票都需要$O(nm)$，但仅这一代就很棘手。 即使尝试一次翻转一位也不会超出非常小的范围$n$和$m$。 

关键的见解是，重复的 2x2 块模式确保每个单元格恰好有两个不同的邻居。 如果我们将一个块定义为```
1 0
0 1
```并将其平铺在矩阵上，每个单元格都有两个具有相同值的邻居和两个具有不同值的邻居。 因为$n$和$m$是均匀的，我们可以精确地平铺这个块而不破坏图案。 这会自动保证邻居条件。 我们还可以翻转 1↔0 并得到另一个有效的解决方案，给出多个正确的矩阵。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(nm) * nm) | O(2^(nm) * nm) | O(纳米) | 太慢了|
 | 块瓷砖| O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，请阅读$n$和$m$。 
3.初始化一个空的$n \times m$矩阵。 
4. 对于每个单元格$(i,j)$，将其值计算为$(i \bmod 2) \oplus (j \bmod 2)$。 此表达式在行和列上交替使用 1 和 0，以形成平铺的 2x2 块图案。 
5. 逐行打印矩阵。 

工作原理：每个 2x2 块保证水平和垂直相邻的单元格在棋盘图案中不同。 由于该块平铺在大小均匀的矩阵上，因此每个内部和边界单元都恰好有两个具有不同值的邻居。 异或模式确保平铺是无缝的并满足问题约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    for i in range(n):
        row = []
        for j in range(m):
            row.append((i % 2) ^ (j % 2))
        print(" ".join(map(str, row)))
```该解决方案有效地读取输入并动态构建矩阵。 这`(i % 2) ^ (j % 2)`确保棋盘图案中的交替值。 除了一次存储一行之外，我们不需要额外的内存，而且由于 Python 使用从零开始的索引，因此不会出现逐一错误。

 ## 边缘情况

 对于 2x2 矩阵：```
2 2
```我们的算法产生：```
0 1
1 0
```左上角的单元格有邻居 (0,1) 和 (1,0)，它们都是不同的。 四个单元中的每一个都恰好有两个不同的邻居，满足约束。 这证实了该算法对于最小的输入可以正确工作，并且可以自然地缩放到更大的偶数维度。
