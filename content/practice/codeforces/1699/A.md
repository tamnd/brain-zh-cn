 ## 解决方案
 ## 问题理解

 我们被要求构造三个整数$a$,$b$， 和$c$，每个都位于一个大范围内$10^9$，使得涉及成对 XOR 值的特定表达式与给定的目标数字匹配$n$。 该表达式将每对的 XOR 相加：$(a \oplus b) + (b \oplus c) + (a \oplus c)$。 

关键的困难不是评估 XOR，而是选择使这三个成对 XOR 相加精确的值$n$，或者证明不存在这样的三元组。 

输入包含多个独立的查询。 对于每一个，我们要么输出任何有效的三元组，要么$-1$如果不可能的话。 自从$n$可以大到$10^9$最多有$10^4$测试用例时，我们需要为每个用例进行恒定时间的构建。 

出现微妙的边缘情况时$n = 1$。 快速尝试小值表明表达式$(a \oplus b) + (b \oplus c) + (a \oplus c)$总是产生偶数。 例如，如果独立考虑所有位，则每个位对总和贡献 0 或 2。 这已经暗示了奇怪的$n$不能被代表。 简单的搜索会错过这种结构限制，并错误地尝试构建奇数值。 

另一个陷阱是假设将两个变量设置为相等或使用简单的算术级数总是有效的。 虽然可以手动修补一些小值，但需要一个尊重按位独立性的通用模式。 

## 方法

 一个蛮力的想法是尝试所有三元组$(a, b, c)$在一个合理的范围内并计算表达式。 即使我们将值限制在几千个这样的小范围内，在最坏的情况下这仍然是三次方，导致数十亿次操作。 这远远超出了可行的范围。 

关键的观察是可以通过仔细选择位模式而不是搜索值来控制表达式。 XOR 在每一位上的表现都是独立的，因此我们可以逐位地思考问题。 

当我们检查简单的结构化三元组时，就会出现一个关键的恒等式。 如果我们修复$a = 0$，表达式简化为：$$(a \oplus b) + (b \oplus c) + (a \oplus c) = b + (b \oplus c) + c$$现在我们想要调整贡献，使它们的总和等于$n$。 我们不直接解决这个问题，而是尝试表示$n$作为两个数字的组合，其异或结构很简单。 

适用于所有人的标准结构$n$就是分裂$n$分成相等的两半：$$n = 2x$$并选择：$$a = x,\quad b = 0,\quad c = x$$现在计算：$$a \oplus b = x,\quad b \oplus c = x,\quad a \oplus c = 0$$所以总和变成$x + x + 0 = 2x = n$。 

这在任何时候都有效$n$是均匀的。 对于奇数$n$，奇偶校验论证表明不可能，所以我们输出$-1$。 

暴力方法会失败，因为它忽略了 XOR 中的结构并将问题视为数字搜索。 最佳解决方案之所以有效，是因为异或对位进行线性化，从而允许通过受控贡献进行直接构造。

 ## 算法演练

 1. 阅读$n$。 如果$n$为奇数，立即输出$-1$。 这是因为由于位贡献的成对对称性，表达式的计算结果始终为偶数。 
2. 计算$x = n / 2$。 我们的目标是将总贡献均匀地分布在两个相等的异或项上。 
3. 构造三元组$a = x$,$b = 0$,$c = x$。 此选择确保两个 XOR 对准确贡献$x$而第三个的贡献为零。 
4. 输出三元组。 

### 为什么它有效

 XOR 中的每个位位置独立贡献。 对于任何一点$a$和$c$匹配，它们的 XOR 为零。 自从$b = 0$, 异或与$b$保留值$a$和$c$。 这创建了两个完全相同的贡献，等于$x$, 总结为$n$。 该结构保证非负性并保持在范围内，因为$x \le 10^9 / 2$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    if n % 2 == 1:
        print(-1)
    else:
        x = n // 2
        print(x, 0, x)
```该解决方案直接应用上面导出的构造。 奇偶校验首先处理不可能的情况。 一次$n$被确认为偶数，除以二给出对称结构中使用的精确值。 

选择$b = 0$很重要，因为它在 XOR 下保留值，避免位之间任何意外的取消。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        if n % 2 == 1:
            out.append("-1")
        else:
            x = n // 2
            out.append(f"{x} 0 {x}")
    return "\n".join(out)

 ## 边缘情况

 对于$n = 1$，算法因奇校验而立即拒绝。 输入触发检查$n \bmod 2 = 1$，并且不进行进一步的计算，产生$-1$。 

为了$n = 0$，如果考虑的话，相同的结构产量$x = 0$， 导致$(0, 0, 0)$，异或和为$0$，这是一致的。 

对于较大的偶数值，例如$n = 10^9$，计算集$x = 5 \cdot 10^8$。 所有值都保持在范围内，并且 XOR 结构不受大小的影响，因为只有位模式很重要。
