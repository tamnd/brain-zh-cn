 ## 解决方案
 ## 问题理解

 我们被要求计算给定括号序列的所有非空子序列的总和。 每个子序列都有一个“分数”，定义为严格比其自身“更好”的最长正则括号子序列的长度。 常规括号序列是括号正确匹配的序列，例如`()()`或者`(())`。 如果第一个序列作为前缀严格更长，或者在第一个不同位置它有一个左括号，而另一个序列有一个右括号，则一个序列比另一个序列更好。 

输入提供多个测试用例。 每个测试用例给出最多 100 个括号的序列。 在所有测试用例中，总长度不超过 100。这个较低的上限至关重要，因为它使我们能够考虑对于较大序列来说不可能的解决方案。 例如，直接迭代长度为 100 的字符串的所有子序列将涉及$2^{100}$可能性，这是不可行的。 这表明需要动态编程方法而不是真正的强力枚举。 

边缘情况出现在非常短的序列中，尤其是长度 1。单个左括号或右括号从来都不是规则的，因此它的分数始终为零。 本身是规则的但没有严格更好的子序列的序列也产生零。 例如，序列`()`没有严格更好的子序列，因为删除括号会使它更短，而不是更好。 误解“更好”的关系可能会导致计算错误的子序列。 

## 方法

 一个天真的方法会枚举所有$2^n - 1$非空子序列。 对于每个子序列，我们将检查其所有子序列以找到更好的最长正则子序列。 最坏情况的复杂度为$O(4^n)$因为对于每个$2^n$我们可能会再次检查子序列$2^n$里面的子序列。 即使对于$n = 20$。 

关键的见解是组合地重新解释问题。 我们可以使用动态规划来计算字符串中每个位置对可能的规则序列的贡献。 我们不是明确地跟踪每个子序列，而是跟踪用一定数量的不匹配的左括号可以形成常规括号序列的有多少种方式（`balance`）。 当添加右括号时，可以扩展具有正平衡的序列以形成新的规则序列。 

此外，问题归结为计算与后来的闭括号匹配的左括号的序列，因为只有左括号可以比第一个不同位置的右括号“更好”。 这允许我们迭代字符串一次并更新由当前左括号的余额索引的 DP 数组，计算可以扩展到更长序列的子序列。 模块化算术确保我们保持在大计数的限制范围内。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(4^n) | O(4^n) | O(2^n) | O(2^n) | 太慢了|
 | 动态规划（平衡跟踪）| O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个DP数组`dp`长度`n+1`， 在哪里`dp[b]`存储以当前位置结束且有余额的子序列的数量`b`无与伦比的`(`括号。 开始于`dp[0] = 1`，代表空序列。 
2. 迭代字符串中的每个字符`s`。 
3.对于每个字符，维护一个新的DP数组`ndp`:

 - 如果角色是`(`，对于每个现有余额`b`, 增量`ndp[b+1]`经过`dp[b]`。 这表示将左括号附加到所有现有子序列。 
- 如果角色是`)`，对于每个余额`b > 0`, 增量`ndp[b-1]`经过`dp[b]`。 这将在所有现有序列中以正平衡结束一个无与伦比的左括号。 
4.处理完一个字符后，添加`ndp`回到`dp`。 还维护一个单独的变量`score_sum`我们添加刚刚关闭至少一个括号的序列数（`b`递减）。 这捕获了有助于“更好”子序列的序列。 
5.最后，`score_sum`模数$998244353$是字符串的总分。 

这个想法是，DP 自然地跟踪所有子序列的余额，并且每次右括号减少正余额时，它都会有助于产生更好的子序列。 这避免了在捕获组合计数时显式枚举每个子序列。 

为什么它有效：DP 不变式是`dp[b]`始终表示以当前字符结尾的子序列的计数`b`无与伦比的`(`。 因为只有序列`b > 0`可以扩展`)`形成新的规则序列，更新`score_sum`每当`)`添加了`b > 0`正确计算所有更好的子序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    
    dp = [0] * (n+1)
    dp[0] = 1
    score_sum = 0
    
    for c in s:
        ndp = dp[:]
        if c == '(':
            for b in range(n, 0, -1):
                ndp[b] = (ndp[b] + dp[b-1]) % MOD
        else:  # c == ')'
            for b in range(1, n+1):
                ndp[b-1] = (ndp[b-1] + dp[b]) % MOD
            score_sum = (score_sum + sum(dp[1:])) % MOD
        dp = ndp
    
    print(score_sum)
```DP 数组跟踪每个余额的子序列计数。 遇到时`(`，我们扩展子序列以增加平衡。 在`)`，我们减少余额并将具有正余额的子序列之和添加到`score_sum`，反映刚刚形成“更好”的正则子序列的序列。 我们复制`dp`到`ndp`在每个步骤中防止覆盖当前迭代所需的计数。 模运算可确保计数保持在限制范围内。
