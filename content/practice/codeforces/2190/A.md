 ## 解决方案
 ## 问题理解

 我们被要求分析一个二进制字符串上的两人游戏，其中 Alice 先走，Bob 轮流跟随。 轮到玩家时，玩家可以选择字符串的任何严格非递增子序列，并将其重新排列为非递减。 实际上，这意味着找到一系列连续或不连续的位置，其中至少包含一个`1`和一个`0`，然后对该序列进行排序，以便所有`0`是第一位的`1`是最后来的。 当不存在有效的移动时，游戏结束，最后移动的玩家获胜。 

输入由多个测试用例组成。 每个测试用例给出一个长度的字符串`n`只含有`0`沙`1`s。 输出需要确定最佳玩法下的获胜者，如果 Alice 能够获胜，则通过列出她应该选择的位置来指定她的第一步。 

的限制`n`达到`2·10^5`每个测试用例，测试用例的总和也上限为`2·10^5`，排除任何试图模拟所有可能的移动或子序列的暴力解决方案。 枚举每个潜在移动的简单方法需要检查 O(n²) 或更差的子序列，这对于最大的输入是不可行的。 

当字符串已经按非降序排序时，会出现一个重要的边缘情况，例如`0000`或者`111`。 在这种情况下，不存在任何移动，因为任何子序列都只包含`0`或仅`1`s，所以鲍勃立即获胜。 另一个微妙的情况是当字符串有一个反转时，例如`10`或者`101`。 在这里，Alice 可以直接选择包含反转的子序列，对其进行排序，并有可能立即结束游戏。 

## 方法

 蛮力方法将尝试模拟游戏：对于每个回合，生成包含两者的所有非递增子序列`0`和`1`，应用该移动，然后递归地确定下一个玩家的获胜者。 虽然原则上是正确的，但这种方法很快就会变得棘手，因为即使对于`n = 1000`，最坏情况下子序列的数量大约为 2ⁿ，远远超出了合理的计算限制。 

最佳方法的关键见解是游戏完全由反转的位置决定 - 反转的位置`1`发生在`0`。 唯一可以改变弦的动作就是翻转这些反转。 更正式地说，计算职位数量`i`在哪里`s[i] = 1`和`s[j] = 0`对于某些人来说`j > i`。 如果这个数字为零，则字符串已经是非递减的，所以鲍勃立即获胜。 否则，爱丽丝总是可以选择减少反转次数的着法。 此外，反转的奇偶性决定了获胜者：如果恰好存在一个反转，Alice 可以立即删除它并获胜； 如果有多个，Alice 的第一步应该选择最左边的`1`s 和最右边`0`形成反转，对它们进行排序，然后继续以最佳方式播放。 

最佳方法减少为从字符串的两端扫描以找到第一个和最后一个位置`0`和`1`需要交换。 这使我们能够在 O(n) 时间内为 Alice 构建有效的第一步。 在这第一步之后，任何后续的游戏都遵循相同的逻辑，但我们只需要识别第一个获胜的棋步，而不是模拟整个游戏。

 | 蛮力 | O(2ⁿ) | O(2ⁿ) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取字符串`s`长度`n`。 
2.初始化两个指针：`l = 0`和`r = n-1`。 移动`l`前进直到`s[l] = 1`并移动`r`向后直到`s[r] = 0`。 目标是找到最左边的`1`和最右边的`0`那些不正常的。 如果`l >= r`，字符串不减，Bob 立即获胜。 
3. 否则，创建两个列表：一个用于索引`1`s 从左开始到`l`，另一个用于指数`0`s 从右开始到`r`。 这些索引形成了 Alice 可以排序的第一个有效子序列。 
4. 对组合索引列表进行排序以按升序产生移动。 
5、输出`Alice`、走势中的指数数量以及指数本身的列表。 

为什么它有效：该算法识别出一个最小子序列，其中包含之间的所有反转`1`s 在左边并且`0`是在右边。 对此子序列进行排序可以减少反转次数，并确保 Alice 在字符串尚未排序的情况下可以强制获胜。 正确性来自于任何移动都必须改变弦，而最左边的`1`s 和最右边`0`s 保证有效的子序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        
        l, r = 0, n - 1
        while l < n and s[l] == '0':
            l += 1
        while r >= 0 and s[r] == '1':
            r -= 1
        
        if l >= r:
            print("Bob")
        else:
            ones = [i+1 for i in range(l) if s[i] == '1']
            zeros = [i+1 for i in range(r, n) if s[i] == '0']
            move = ones + zeros
            move.sort()
            print("Alice")
            print(len(move))
            print(*move)

if __name__ == "__main__":
    solve()
```代码首先识别最左边的`1`和最右边的`0`形成反转。 它收集的索引`1`s 在左边并且`0`将右边的s转化为一步，排序，输出结果。 快速 I/O 用于有效处理大量输入。 通过使用可以避免相差一错误`i+1`因为该问题需要基于 1 的索引。
