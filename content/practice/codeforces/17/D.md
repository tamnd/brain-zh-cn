 ## 问题理解

 尼克想要列出给定长度的所有数字`n`在基地`b`，其中数字范围从 0 到`b-1`，但数字不能以 0 开头。他的记事本中的每一页都准确保存`c`数字。 我们被要求计算他填写的最后一页上出现了多少个数字。 

输入由三个整数组成：`b`（基地），`n`（号码长度），以及`c`（每页数）。 输出是一个整数：最后一页上的数字计数。 

对于约束条件，两者`b`和`n`最多可达 10^105。 这立即排除了任何尝试显式枚举数字甚至构建大小数组的解决方案`b^n`。 即使标准 64 位整数也无法存储这些值，因此我们必须进行数学推理并将数字作为大整数或模/指数形式进行操作。 页数，`c`，达到 10^9，这是可以管理的，但我们仍然无法线性迭代到`b^n`。 

当数字总数恰好整除时，会出现微妙的边缘情况`c`。 例如，如果有 12 个数字，每页有 4 个数字，则所有页都已满，因此最后一页有 4 个数字。 一种简单的方法，只需计算`b^n % c`如果不处理精确的整除性，将返回 0，这是不正确的； 在这个问题中，在这种情况下的最后一页应该报告`c`。 另一个边缘情况是最小输入：`b = 2`,`n = 1`,`c = 1`，其中仅存在一个数字。 

## 方法

 蛮力方法很简单：生成所有`n`- 基数中的数字`b`，跳过那些从零开始的，计算它们，并填充 size 的页面`c`。 虽然在概念上是正确的，但这种方法需要计算`b^n`数，这是不可能的`n`大至 10^5 或更大。 均匀计算`b^n`直接使用重复乘法会太慢，并且会生成远远超出标准整数类型的数字。 

关键的观察是我们不需要数字本身，只需要它们的计数。 有效总数`n`- 基数中的数字`b`是`(b-1) * b^(n-1)`。 第一个数字可以是以下任意数字`1`到`b-1`, 给予`b-1`选项，以及剩余的每个`n-1`数字可以是`0`到`b-1`, 给予`b^(n-1)`选项。 一旦我们知道了总计数，问题就简化为一个简单的模算术运算，以确定最后一页上还剩下多少个数字。 

因此，问题简化为计算`(b-1) * b^(n-1) % c`。 因为`b`和`n`可能非常大，我们需要有效地执行模幂运算，这可以通过平方求幂来完成。 这个方法允许我们计算`b^(n-1) % c`无需存储`b^(n-1)`明确地。 最后，如果结果为`(b-1) * b^(n-1) % c`为零，这意味着最后一页已满，所以我们应该返回`c`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(b^n) | O(b^n) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 解析输入值`b`,`n`， 和`c`作为整数。 自从`b`和`n`可以有数百位数字，它们应该被视为任意精度整数。 
2. 计算指数`n-1`确定最后的选择数`n-1`数字。 
3. 使用模幂进行计算`b^(n-1) % c`。 这确保我们永远不会计算或存储巨大的数字`b^(n-1)`直接地。 模幂通过重复平方来工作`b`并减少模数`c`每一步，每次将指数减半。 
4. 将结果乘以`(b-1)`并取模`c`再次：`remaining = ((b-1) * pow(b, n-1, c)) % c`。 这给出了最后一页上的数字数量。 
5. 如果`remaining`为零，这意味着最后一页完全满了，所以我们输出`c`。 否则，输出`remaining`。 

为什么它有效：在每一步，我们都维护计数模数`c`。 由于恒等性，模幂保证了正确性`(x*y) % m = ((x % m)*(y % m)) % m`。 乘法`(b-1)`通过剩余计数正确地缩放序列数。 检查零可以处理精确的整除边缘情况，确保正确报告最后一页。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

b, n, c = map(int, input().split())

# compute number of numbers on the last page
# pow supports three arguments: pow(base, exp, mod)
remaining = (b - 1) * pow(b, n - 1, c) % c
if remaining == 0:
    remaining = c

print(remaining)
```该代码使用快速 I/O 读取输入来处理潜在的大整数。 这`pow`Python 中的函数可以高效计算`b^(n-1) % c`使用平方求幂。 乘以`(b-1)`缩放第一位数字的计数，并且`% c`确保我们保持在页面限制之内。 最后的零检查处理最后一页完全填满的情况。
