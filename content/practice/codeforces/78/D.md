 ## 解决方案
 ## 问题理解

 我们被要求计算一个弓箭手可以通过半径为 _k_ 的圆形攻击完全覆盖多少个六角形单元，其中弓箭手位于单元的中心。 每个六边形的边长为 1。仅当单元格中的每个点都位于圆内时，该单元格才算被覆盖。 输入是单个整数_k_，输出是满足该条件的单元格总数。 

_k_ 的范围最大为 10^6。 如果我们尝试通过计算大网格的距离来对弓箭手周围的每个单元进行强力检查，则操作数量很快就会变得不可行，因为候选单元的数量大致随圆面积 O(k²) 的增长而增长。 对于上限 k=10^6，这将涉及大约 10^12 次检查，远远超过 2 秒的时间限制。 

当 _k_ 值较小时，尤其是 _k = 1_ 时，会出现关键的边缘情况。 弓箭手只能覆盖自己的单元格，因此输出应该为 1。如果粗心地假设至少有 7 个单元格（中心单元格加上 6 个邻居单元格），那将是错误的。 另一个潜在的陷阱是错误计算圆边界上的单元格。 因为只有当**所有点**都位于圆内时，单元才被视为受到攻击，因此即使中心在内部，中心位于边界附近的单元也可能被排除。 

## 方法

 蛮力方法将枚举弓箭手周围边长大致为 _k_ 的大型六边形网格，检查从弓箭手到每个六边形的每个顶点的欧几里得距离，并计算所有顶点落在半径内的单元格。 这是正确的，因为它直接实现了定义，但它需要对 k² 单元进行 O(k²) 距离检查，并且每个单元有 6 个顶点，这使得 k = 10^6 时不可行。 

关键的见解来自于观察六边形瓷砖的对称性。 中心单元周围的六边形层形成环：中心单元是第 0 层，它的 6 个邻居是第 1 层，下一个周围的环有 12 个单元，依此类推。 每层对应于距中心的整数“十六进制距离”。 如果圆半径至少为从中心到该六角形最远顶点的距离，则层 _r_ 中的单元格完全位于圆内。 从层_r_六角形的中心到其最远顶点的距离随_r_线性增长，具体为r × √3（边心到顶点的距离）。 使用它，我们可以计算圆可以覆盖的完整层的最大数量，然后按层数对单元求和。 前 _n_ 层中的单元数量为 1 + 6 × (1 + 2 + ... + n) = 1 + 3 × n × (n + 1)。 一旦我们知道最大覆盖层，这就给出了 O(1) 公式。 

这种方法大大降低了复杂性，因为我们不再迭代每个单元格。 唯一的计算是找到适合圆的最大层，然后应用公式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(k²) | O(1) | O(1) | 对于 k 达到 10^6 来说太慢 |
 | 层配方| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 用层来表示六边形平铺：中心单元为层 0，周围 6 个单元为层 1，接下来的 12 个单元形成层 2，依此类推。 每层 r 有 6 × r 个单元。 
2. 计算从弓箭手单元格中心到 r 层单元格最远点的距离。 对于边长为 1 的六边形，中心到顶点的距离为 1。到 r 层最远顶点的距离为 r × √3 + 1。 
3.确定最大层数_n_，使得该层中任何六边形的中心到最远顶点的距离不超过k。 求解 r × √3 + 1 ≤ k，得出 r ≤ (k - 1)/√3。 
4. 使用六边形层的求和公式。 完全覆盖的单元总数为 1（中心单元）加上各层的总和：1 + 6 × (1 + 2 + ... + n) = 1 + 3 × n × (n + 1)。 
5. 打印结果。 

为什么有效：六角形层均匀生长，并且该公式考虑了完全包含的层中的所有单元格。 仅检查层边界可确保我们不包括部分覆盖的单元，满足单元的所有点必须位于圆内的问题要求。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

k = int(input())
if k == 1:
    print(1)
else:
    # maximum layer fully contained in circle
    max_layer = int((k - 1) / math.sqrt(3))
    # sum of cells in layers
    result = 1 + 3 * max_layer * (max_layer + 1)
    print(result)
```此代码首先单独处理简单的情况 k = 1，因为该公式将给出 0 层。 然后，它使用几何关系 r × √3 + 1 ≤ k 计算适合圆内的完整层的最大数量。 整数除法确保我们只计算完全包含的层。 最后，闭合公式 1 + 3 × n × (n + 1) 有效地生成总细胞计数。 仔细注意差一错误和浮点舍入`int()`。 

## 工作示例

 对于 k = 3：

 | 步骤| 最大层 | 结果 |
 | ---| ---| ---|
 | 计算 max_layer | int((3-1)/√3) = int(2/1.732) = 1 | - |
 | 计算结果 | 1 + 3_1_2 = 1 + 6 = 7 | 7 |

 该表确认中心细胞周围的一层完全位于圆圈内，总共产生 7 个细胞，与样本输出匹配。 

对于 k = 5：

 | 步骤| 最大层 | 结果 |
 | ---| ---| ---|
 | 计算 max_layer | int((5-1)/√3) = int(4/1.732) = 2 | - |
 | 计算结果 | 1 + 3_2_3 = 1 + 18 = 19 | 19 | 19

 这表明两层被完全覆盖，产生 19 个单元。

 ## 边缘情况

 当 k = 1 时，圆不能完全覆盖任何相邻的六边形。 该算法计算`max_layer = int((1-1)/√3) = 0`，产生 1 个细胞，这是正确的。 对于 k = 2，圆仍然太小，无法完全覆盖六个邻居。 计算`max_layer = int((2-1)/√3) = 0`确保只计算中央细胞。 这些检查证实基于层的方法可以正确处理小半径，而不会过度计算部分单元格。
