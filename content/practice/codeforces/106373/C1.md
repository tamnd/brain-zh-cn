 ## 解决方案
 ## 问题理解

 我们给定一个字符串，需要确定它包含多少个不同的非空子字符串。 如果两个子字符串的字符序列相同，则认为它们是相同的，即使它们出现在不同的位置。 

输入是小写英文字母表上的单个字符串。 输出是可以从中形成的唯一子字符串值的数量。 

该任务的直接解释建议采用每对可能的开始和结束位置，创建该子字符串并将其存储在一个集合中。 这适用于小字符串，但可能的子字符串数量呈二次方增长。 如果字符串长度为$n$， 有$n(n+1)/2$按位置划分子字符串，并存储其内容可以使总工作量接近$O(n^3)$。 对于较大的值$n$，这远远超出了正常的时间限制。 

棘手的情况是具有许多重复模式的字符串。 例如，输入：```
aaaa
```答案是：```
4
```子串是`a`,`aa`,`aaa`， 和`aaaa`。 如果粗心地计算位置而不是不同的字符串，则会返回 10，因为有 10 个可能的间隔。 

另一种情况是：```
ababa
```答案是：```
9
```重复的子串如`a`,`b`,`ab`， 和`aba`只能计算一次。 任何仅检查子字符串是否出现在之前而不有效地表示所有先前子字符串的方法都可能变得太慢。 

最终的边界情况是单个字符：```
x
```答案是：```
1
```恰好有一个非空子字符串，即字符串本身。 

## 方法

 最简单的方法是生成每个子字符串并将其插入到集合中。 这是正确的原因很简单：集合仅保留每个不同字符串的一个副本，因此在处理所有间隔后，其大小就是所需的答案。 

问题是工作量。 有$O(n^2)$子串，构建每个子串可能需要最多$O(n)$时间。 最坏情况的复杂度变为$O(n^3)$，这不适合当$n$很大。 

关键的观察是子串不是独立的。 当我们将字符串扩展一个字符时，许多子字符串与先前的前缀共享。 后缀自动机准确地存储了我们在合并等效状态时所需的有关字符串的所有子字符串的信息。 

后缀自动机中的每个状态代表一组具有相同结束位置集的子串。 状态存储该组中子串的最大长度以及由其后缀链接表示的最长后缀的长度。 添加字符时引入的新子字符串的数量是这两个值之间的差。 

如果一个州有`len[v]`作为它代表的最长子串长度，其后缀链接指向`link[v]`，那么它贡献：$$len[v] - len[link[v]]$$唯一的子串。 将所有状态相加得出最终答案。 

暴力解决方案尝试直接比较字符串。 相反，后缀自动机对所有等效的子串历史进行分组，将工作减少为线性传递。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(n²) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 从仅包含初始状态的空后缀自动机开始。 该状态表示空子串。 
2. 从左到右处理字符串的字符。 对于每个新字符，通过创建表示以当前位置结尾的所有子字符串的新状态来扩展自动机。 
3. 当当前字符没有转换时，按照后缀链接进行操作。 添加从这些状态到新状态的转换。 这记录了在此结尾的每个新子字符串。 
4. 如果现有转换已存在，请检查当前结构是否有效。 如果现有状态的长度关系错误，则创建克隆状态。 克隆允许正确分隔具有相同转换的不同子字符串。 
5. 插入整个字符串后，迭代所有状态。 对于每个州，添加`len[state] - len[link[state]]`到答案。 这会计算该状态中首次出现的子字符串长度。 

为什么它有效：

 每个不同的子字符串都对应于后缀自动机中的一条路径。 状态表示长度在以下范围内的所有子串`len[link[state]] + 1`和`len[state]`。 这些长度是该状态贡献的独特的新子串。 由于状态对所有可能的子串进行了划分，因此对它们的贡献求和只会对每个不同的子串进行一次计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class State:
    __slots__ = ("next", "link", "length")

    def __init__(self):
        self.next = {}
        self.link = -1
        self.length = 0

def solve(s):
    states = [State()]
    last = 0

    for ch in s:
        cur = len(states)
        states.append(State())
        states[cur].length = states[last].length + 1

        p = last
        while p != -1 and ch not in states[p].next:
            states[p].next[ch] = cur
            p = states[p].link

        if p == -1:
            states[cur].link = 0
        else:
            q = states[p].next[ch]
            if states[p].length + 1 == states[q].length:
                states[cur].link = q
            else:
                clone = len(states)
                states.append(State())
                states[clone].next = states[q].next.copy()
                states[clone].length = states[p].length + 1
                states[clone].link = states[q].link

                while p != -1 and states[p].next.get(ch) == q:
                    states[p].next[ch] = clone
                    p = states[p].link

                states[q].link = clone
                states[cur].link = clone

        last = cur

    ans = 0
    for i in range(1, len(states)):
        ans += states[i].length - states[states[i].link].length

    return ans

s = input().strip()
print(solve(s))
```这`State`对象存储自动机所需的三个值。 转换字典表示由字符标记的边缘，`link`指向后缀链接，并且`length`存储由状态表示的最长子串。 

在插入过程中，`last`始终指向代表整个已处理前缀的状态。 添加新字符时，后缀链接后面的循环将添加所有缺少的转换。 这些转换对应于以当前字符结尾的子字符串。 

克隆创建部分是实现的微妙部分。 如果不进行克隆，两组不同的子串可能会错误地共享一个状态，从而导致最终计数太小。 克隆复制过渡，但最大长度较小，在保留自动机结构的同时拆分组。 

最终循环从state开始`1`因为状态`0`代表空字符串。 每个状态仅贡献其后缀链接尚未计算的长度。 

## 工作示例

 对于输入：```
aaa
```自动机状态的贡献如下：

 | 状态| len[状态] | len[链接[状态]] | 贡献 |
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 1 |
 | 2 | 2 | 1 | 1 |
 | 3 | 3 | 2 | 1 |

 总计为：$$1 + 1 + 1 = 3$$不同的子串是`a`,`aa`， 和`aaa`。 此跟踪显示重复的字符如何不会创建重复的答案。 

对于输入：```
ab
```各国贡献：

 | 状态| len[状态] | len[链接[状态]] | 贡献 |
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 1 |
 | 2 | 2 | 0 | 2 |

 总计为：$$1 + 2 = 3$$子串是`a`,`b`， 和`ab`。 第二个状态贡献了两个新的长度，因为两者`ab`和`b`在新位置结束。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 每个字符最多创建两个状态，后缀链接操作是线性摊销的。 |
 | 空间| O(n) | 一个后缀自动机最多包含`2n - 1`州。 |

 该算法对每个字符处理一次，并且从不显式枚举子字符串。 这就是为什么即使字符串长度很大，它仍然保持快速的原因。

 ## 边缘情况

 对于`aaaa`，该算法创建一个状态链。 每个新状态仅贡献一个额外的长度，因为每个较长的子串已经由前一个后缀表示。 最终的贡献是`1`,`1`,`1`， 和`1`，给出正确答案`4`。 

为了`ababa`, 重复出现`a`,`b`， 和`aba`被合并到相同的自动机状态中。 贡献公式可以防止它们被多次计算，所以答案变成`9`而不是子串位置的数量。 

对于单个字符输入`x`，仅存在一个非空子串。 自动机有一个具有贡献的真实状态`1 - 0`，所以它返回`1`。
