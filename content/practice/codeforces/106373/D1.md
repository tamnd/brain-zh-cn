 ## 解决方案
 ## 问题理解

 给定一个无向平面图。 每个顶点代表一个必须接收以下之一的对象`k`颜色。 如果每条边都连接不同颜色的两个顶点，则着色有效。 任务是计算存在多少个有效的颜色分配。 

输入包含多个测试用例。 对于每种情况，我们都知道顶点数、边数和可用颜色数。 以下几行描述了边缘。 输出是每个图表的正确着色数量。 

D1 版本使图形保持较小。 最大的图只有大约十几个顶点，这排除了大型实例所需的多项式方法，但允许仔细优化的指数算法。 简单的枚举会尝试每种可能的颜色分配，这需要`k^n`尝试。 即使是为了`n = 14`和`k = 7`，这是数十亿种可能性，因此搜索顺序和修剪是整个解决方案。 

在一些边缘情况下，简单的实现可能会失败。 没有边的图将每个分配作为有效的着色。 例如：```
1
3 0 2
```答案是`8`，因为三个顶点中的每一个都可以独立选择任一颜色。 仅在看到边缘后才计算选择的程序可能会错误地返回零。 

该语句并不期望包含自循环的图，但如果它出现，它将具有零有效着色，因为顶点必须与其自身不同。 

完整图是另一个有用的边界情况。 例如：```
1
3 3 2
1 2
2 3
1 3
```答案是`0`，因为三个相互相邻的顶点需要三种不同的颜色。 仅检查每个顶点是否具有至少一种可能颜色的贪婪实现可能会错过这种全局冲突。 

## 方法

 最直接的解决方案是为顶点一一指定颜色，并检查当前选择是否与已着色的邻居冲突。 这是正确的，因为每个可能的分配都会被考虑一次。 然而，最坏的情况探索`k^n`州。 该算法将大部分时间花在探索分支上，这些分支最终会因为很久以后发现的冲突而失败。 

关键的观察结果是顶点数量很少，因此目标不是完全避免指数行为。 相反，我们需要使指数树尽可能小。 我们使用 DSATUR 启发式回溯搜索。 选择颜色的下一个顶点作为当前在其彩色邻居中看到最多不同颜色的顶点。 此类顶点受到的约束最大，因此无效分支会更早被拒绝。 

搜索保持当前的部分着色。 对于选定的顶点，我们尝试其彩色邻居未使用的每种颜色。 一旦分配了所有顶点，就找到了一种有效的颜色。 

蛮力之所以有效，是因为图很小，但当它把时间浪费在错误的选择上时，就会失败。 DSATUR 通过更早地暴露矛盾来减少搜索空间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k^n) | O(k^n) | O(n) | 没有修剪太慢|
 | DSATUR 回溯 | 最坏情况为 O(k^n)，实际中要小得多 | O(n + m) | 已接受 |

 ## 算法演练

 1. 将图存储为邻接表。 我们还保留一个边缘矩阵，以便检查颜色是否可用是恒定的时间。 
2. 维护一个包含每个顶点当前颜色的数组。 值为`-1`表示顶点尚未着色。 
3. 选择下一个饱和度最高的顶点。 饱和度是其彩色邻居中当前存在的不同颜色的数量。 如果多个顶点的饱和度相同，则选择相邻顶点较多的那个。 
4. 尝试每一种颜色`0`到`k - 1`它不会出现在已经有颜色的邻居中。 暂时分配颜色并继续递归。 
5. 当所有顶点都着色后，为答案加一，因为已达到完整的有效分配。 

为什么它有效：递归的不变性是搜索维护的每个部分着色在所有着色顶点上都已经有效。 该算法仅使用不破坏任何边缘约束的颜色来扩展此部分解决方案。 每个有效的最终着色都具有通过递归树的一条路径，因为算法最终以相同的顺序为每个顶点分配相同的颜色。 因此，不会漏掉任何颜色，也不会重复计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(n, m, k, edges):
    adj = [[] for _ in range(n)]
    mat = [[False] * n for _ in range(n)]

    for u, v in edges:
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
        mat[u][v] = True
        mat[v][u] = True

    color = [-1] * n
    ans = 0

    def choose_vertex():
        best = -1
        best_sat = -1
        best_deg = -1

        for v in range(n):
            if color[v] != -1:
                continue

            used = set()
            for u in adj[v]:
                if color[u] != -1:
                    used.add(color[u])

            sat = len(used)
            deg = len(adj[v])

            if sat > best_sat or (sat == best_sat and deg > best_deg):
                best = v
                best_sat = sat
                best_deg = deg

        return best

    def dfs(done):
        nonlocal ans

        if done == n:
            ans += 1
            return

        v = choose_vertex()

        forbidden = [False] * k
        for u in adj[v]:
            if color[u] != -1:
                forbidden[color[u]] = True

        for c in range(k):
            if not forbidden[c]:
                color[v] = c
                dfs(done + 1)
                color[v] = -1

    dfs(0)
    return ans

def main():
    t = int(input())
    out = []

    for _ in range(t):
        n, m, k = map(int, input().split())
        edges = []
        for _ in range(m):
            u, v = map(int, input().split())
            edges.append((u, v))
        out.append(str(solve_case(n, m, k, edges)))

    print("\n".join(out))

if __name__ == "__main__":
    main()
```邻接列表用于启发式，因为它可以让我们快速检查邻居。 邻接矩阵在这里并不是严格必要的，但保持表示明确可以避免冲突检查稍后更改时出现错误。 

这`choose_vertex`函数实现 DSATUR 规则。 重要的细节是饱和度计算不同颜色，而不是相邻颜色的数量。 连接到三个红色邻居的顶点的饱和度为一，而不是三。 

递归函数每次更改一个顶点，并且返回后始终恢复旧状态。 这种回滚允许搜索树的不同分支共享相同的数组。 

Python 整数具有任意精度，因此答案计数器不会溢出。 该问题保证最终答案符合要求的范围。

 ## 边缘情况

 对于空图，例如：```
1
3 0 2
```搜索不会将任何颜色标记为禁止。 每个递归分支都会存活，直到所有顶点都被分配，产生`2^3 = 8`。 

对于颜色较少的完整图表：```
1
3 3 2
1 2
2 3
1 3
```前两个顶点可以接收不同的颜色，但第三个顶点禁止接收两种颜色。 该分支立即结束，并且所有其他分支都以同样的方式失败，产生零。 

对于单个顶点：```
1
1 0 5
```递归选择唯一的顶点并尝试五种可能的颜色。 每一种都会产生一种完整的颜色，所以答案是五。 这也验证了当图不包含边并且不需要递归深度时终止条件有效。
