 ## 解决方案
 ## 问题理解

 该问题要求我们找到无限棋盘上修改后的马可以攻击给定国王和王后的所有位置。 马的移动由两个正整数定义，$a$和$b$，所以它可以跳跃$a$一个方向上的正方形和$b$垂直方向上的正方形，就像普通骑士的缩放版本。 棋盘坐标可以是任何整数对，包括负数，并且国王和王后被放置在特定的不同单元格中。 

输入给出了多个测试用例中马的移动大小以及国王和王后的坐标。 对于每个测试用例，输出都是一个数字：骑士同时威胁两个棋子的位置数。 棋盘是无限的，因此没有边缘限制； 我们只关心相对于国王和王后的放置组合的可能性。 

约束表明$a$和$b$可以达到$10^8$并且最多可以有 1000 个测试用例。 这排除了任何检查每个可能的板单元或在大范围内迭代的强力方法 -$O(a \cdot b)$或者$O(x_{\text{max}} \cdot y_{\text{max}})$算法会太慢。 该解决方案必须直接使用相对坐标而不是绝对板扫描。 

当国王和王后以任何马的动作都无法从单一位置到达两者的方式对齐时，就会出现微妙的边缘情况。 例如，如果它们位于同一水平线上，但它们的水平距离不精确$2a$或者$2b$，骑士永远无法分叉它们。 粗心的解决方案可能会假设每一对单元都至少有一个分叉位置，从而产生错误的结果。 

## 方法

 暴力方法在概念上很简单：对于包含国王和王后的足够大的矩形上的每个潜在的骑士位置，检查骑士是否攻击两者。 这是有效的，因为我们确切地知道骑士可以攻击的位置：偏移的位置$(\pm a, \pm b)$或者$(\pm b, \pm a)$从骑士的位置。 然而，所需的矩形可能达到$10^8$宽度或高度。 迭代所有这些位置会导致最坏情况下的操作计数为$10^{16}$，这是不可行的。 

关键的见解是骑士的攻击模式是对称的。 我们可以枚举一个骑士相对于一个棋子（比如国王）的所有可能的相对位置，并检查相同的位置是否也攻击另一个棋子（皇后），而不是枚举所有棋盘单元。 每个骑士恰好有八种可能的攻击位置。 因此，问题归结为检查相对于国王的这八个位置中的每一个，是否也会使马远离王后恰好移动一步。 

这将具有巨大搜索空间的问题转变为每个测试用例具有恒定、有界搜索空间的问题。 蛮力原则上有效，但由于大小而失败，而我们只需要检查八个“与国王相关”的候选位置的观察让我们可以在恒定的时间内解决每个测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O（大矩形）| O(1) | O(1) | 太慢了 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算国王和王后之间的相对坐标差：$dx = x_Q - x_K$和$dy = y_Q - y_K$。 我们只需要考虑这些差异，因为棋盘是无限的，只有相对定位才重要。 
2. 生成相对于国王的所有八个可能的骑士位置。 他们是$(\pm a, \pm b)$和$(\pm b, \pm a)$。 这些代表骑士攻击国王所需的位置。 
3. 对于每个候选位置，计算骑士的假设坐标：$x_N = x_K + \delta_x$,$y_N = y_K + \delta_y$。 
4. 检查同一位置的骑士是否也攻击皇后。 这要求与皇后坐标的绝对差匹配$(a, b)$或者$(b, a)$。 从数学上来说，$(|x_N - x_Q|, |y_N - y_Q|)$应该等于$(a, b)$或者$(b, a)$。 
5. 计算满足两种攻击的每个候选者。 输出测试用例的计数。 

为什么它有效：每个骑士位置要么是有效的分叉，要么不是； 通过系统地检查与国王相关的所有职位，我们保证不会遗漏任何候选人。 马移动的对称性确保考虑所有八种可能性，并且绝对差检查确认马也攻击后。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def count_forks(a, b, kx, ky, qx, qy):
    candidates = [(a, b), (a, -b), (-a, b), (-a, -b),
                  (b, a), (b, -a), (-b, a), (-b, -a)]
    count = 0
    for dx, dy in candidates:
        nx, ny = kx + dx, ky + dy
        dxq, dyq = abs(nx - qx), abs(ny - qy)
        if (dxq, dyq) == (a, b) or (dxq, dyq) == (b, a):
            count += 1
    return count

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    kx, ky = map(int, input().split())
    qx, qy = map(int, input().split())
    print(count_forks(a, b, kx, ky, qx, qy))
```我们生成八个相对移动，计算每个马的绝对位置，并使用绝对差比较其与后的距离。 使用`abs`确保我们正确处理负偏移量。 每个候选人都会被检查一次。
