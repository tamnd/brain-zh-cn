 ## 解决方案
 ## 问题理解

 我们有两个数组，`a`和`b`，长度`n`。 我们的目标是转型`a`进入`b`使用允许我们选择任何连续子数组并将其所有值替换为该子数组的最大值的操作。 换句话说，我们只能增加段内的元素以匹配该段的局部最大值。 问题问是否可以实现`b`从`a`使用零个或多个此类操作。 

限制因素很大。 每个数组最多可达`2*10^5`元素，所有测试用例的总和上限为`2*10^5`。 尝试每个可能的子数组的简单解决方案是不可行的，因为子数组的数量是二次的`n`。 这迫使我们寻找线性或近线性的解决方案。 

微妙的边缘情况包括以下情况`b[i] < a[i]`在任何索引处。 由于我们的操作只能增加价值，任何这样的情况发生都会立即使转变变得不可能。 当我们有重复的数字时会出现另一种边缘情况`b`比它们的邻居大`a`- 我们需要确保有足够的灵活性`a`“增长”到所需的值，而不受早期约束的阻碍。 例如，`a = [1,1]`和`b = [1,2]`无法工作，因为里面没有 2`a`才能向前传播。 

## 方法

 蛮力方法很简单：对于每个元素`a[i] != b[i]`，我们可以尝试找到最短的线段，包括`i`我们可以用该段的最大值替换所有值。 重复此操作直到`a`比赛`b`原则上是正确的。 每个替换操作与段长度成线性关系，并且最多可以有`n`要考虑的部分。 在最坏的情况下，每个测试用例的时间复杂度为 O(n²)，这对于`n`最多`2*10^5`。 

解锁更快解决方案的关键观察是我们不需要模拟每个操作。 由于操作只允许增加值并传播现有值，因此无论在哪里都不可能进行转换`b[i] < a[i]`。 对于索引，其中`b[i] > a[i]`，我们必须在某个地方有一个更大的可用值`a`可以使用连续的段向前传播。 具体来说，对于每个不同的数字`b`，我们需要知道我们是否有足够的该数字的实例`a`或者可以使用较小的数字来创建它。 因为`b`的边界是`n`，我们可以维护每个数字的计数，并贪婪地确保每个数字所需的`b`可以直接来自`a`或间接来自先前建立的细分市场。 

这将问题转化为线性扫描：遍历`b`从左到右，检查每个`b[i]`至少与`a[i]`以及我们以前是否遇到过或可以生成该数字。 我们使用简单的数据结构（例如堆栈或频率计数器）来跟踪可用于传播的数字。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化频率计数器`freq`尺寸的`n+1`跟踪每个数字仍可用于传播的次数。 所有数字都从零开始。 
2. 迭代数组`a`和`b`从左到右。 对于每个索引`i`，首先检查是否`b[i] < a[i]`。 如果是，则输出`NO`立即，因为我们无法减少值。 
3.如果`b[i] == a[i]`，继续下一个索引； 无需任何操作。 
4. 如果`b[i] > a[i]`，检查是否`freq[b[i]] > 0`。 如果是，则递减`freq[b[i]]`并继续，因为我们可以使用较早出现的`b[i]`填补`a[i]`。 如果不是，则转换是不可能的，我们输出`NO`。 
5. 每当`a[i] == b[i]`并且值大于1，递增`freq[a[i]-1]`表示该数字现在可以向前传播以进行下一步。 这会跟踪可用的“资源”，以增加较小的数量以达到目标。 
6. 如果循环结束而没有遇到阻塞条件，则输出`YES`。 

保证正确性的不变量是`freq[x]`总是代表我们可以使用的次数`x`在未来的职位上增加较小的数量。 我们从不过度消耗某个数字，也从不尝试减少值，而这是操作所禁止的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        possible = True
        freq = [0] * (n + 2)
        
        for i in range(n):
            if b[i] < a[i]:
                possible = False
                break
            if b[i] > a[i]:
                if freq[b[i]] > 0:
                    freq[b[i]] -= 1
                else:
                    possible = False
                    break
            if a[i] > 1:
                freq[a[i]-1] += 1
        
        print("YES" if possible else "NO")

if __name__ == "__main__":
    solve()
```第一个循环读取测试用例和数组的数量。 这`freq`数组用于跟踪数字的潜在传播，确保每当`b[i]`大于`a[i]`，有一个先前的数字可以支持增加。 递增`freq[a[i]-1]`在处理指数模型后，这个数字现在可以为未来的增长做出贡献。 操作顺序至关重要——递增`freq`在检查下一个元素之前会破坏不变量。
