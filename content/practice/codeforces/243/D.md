 ## 解决方案
 ## 问题理解

 我们得到一个 _n_×_n_ 网格，代表一个由堆叠在塔中的单位立方体建造的城市。 网格的每个单元格都包含一个整数，指示该位置塔的高度。 Petya 在水平面中沿着方向向量 _(vx, vy)_ 从很远的距离观察城市。 问题是从这个角度可以看到多少个单独的立方体。 

如果沿观察方向没有其他立方体直接阻挡该立方体，则该立方体是可见的。 因为视点无限远，所以问题简化为 2D 投影问题：我们只需要跟踪沿平行于向量 _(vx, vy)_ 的线遇到的最大高度。 如果一个立方体比该线上的任何立方体都高，则它是可见的。 

约束适中：_n_ ≤ 1000，高度最大可达 10^9。 方向矢量分量是 ±10^4 以内的整数。 由于 n 很小，因此复杂度约为 O(n²) 的算法是可以接受的，但任何 O(n³) 或更糟糕的算法都会太慢。 边缘情况包括负向量分量、零高度和单塔网格，其中仅最顶部的立方体计数。 例如，如果单行高度为 [1,3,2] 并且向量沿着该行，则只有位置 1、2 处的立方体以及 2 和 3 中的额外高度可能是可见的，具体取决于方向； 忽略向量方向的幼稚迭代会计算错误的立方体。 

## 方法

 暴力方法是模拟来自每个立方体的每条射线，并检查它是否与之前的另一个立方体相交。 对于大小为 n×n 且高度最大为 h 的网格，这会导致每条射线的检查次数为 O(n²·h)，总共为 O(n²·h·n²)，这对于上限 n = 1000 和 h = 10^9 来说是不可行的。 即使将光线减少到每个立方体一条光线也无济于事，因为沿方向向量迭代以检测遮挡仍然很昂贵。 

关键的见解是，从沿着 _(vx, vy)_ 的远处观察，立方体只能阻挡同一条线上沿着该向量更远的其他立方体。 我们可以沿着斜率 vy/vx 的线将网格划分为序列，并从视点按顺序沿着这些线处理立方体。 沿着每个序列，只有比目前看到的最大高度高的立方体才会对可见计数产生影响。 通过仔细选择处理顺序，我们可以避免将每个立方体与其他立方体进行检查，从而将问题简化为沿每行进行排序的线性扫描。 

我们通过考虑 vx 和 vy 的符号来标准化方向，以确定行和列的扫描顺序。 对于每个对角线或反对角线（取决于向量），我们跟踪看到的最大高度，并且对于序列中的每个塔，可见立方体是塔的高度与迄今为止的最大值（如果为正）之间的差。 这准确地捕获了突出到先前障碍物上方的立方体。

 | ---| ---| ---| ---|
 | 蛮力 | O(n^4) | O(n^4) | O(n^2) | O(n^2) | 太慢了 |

 ## 算法演练

 1. 通过方向向量的符号对方向向量进行归一化。 如果 vx < 0，我们将从右向左迭代列； 如果 vy < 0，则从下到上迭代行。 如果 vx = 0，我们纯粹沿着行扫描，如果 vy = 0，我们纯粹沿着列扫描。 
2. 确定处理单元格的顺序。 从面向视点的一侧开始，沿着垂直于矢量的线处理单元。 对于整数向量，我们可以通过根据向量符号求和或减去行索引和列索引来定义扫描顺序。 
3. 对于扫描中的每一行，初始化一个变量`max_height`到 0。这将跟踪迄今为止沿着该线看到的最高的立方体。 
4. 按照从视点到更远处的顺序沿线迭代。 对于每个单元格，计算`visible = max(0, a[i][j] - max_height)`。 这会计算该单元贡献的新可见立方体的数量。 
5. 添加`visible`到总计数和更新`max_height = max(max_height, a[i][j])`。 
6. 对覆盖整个网格的所有线重复此操作。 

原理：沿着观察方向的每条线，立方体会阻挡其后面所有不高的立方体。 通过以正确的顺序进行扫描并保持当前的最大高度，每个立方体的贡献将被精确计算一次。 没有立方体被重复计算，因为每个立方体仅与沿其线更靠近视点的立方体进行比较。 不变的是`max_height`始终表示沿线到当前位置的最高立方体。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, vx, vy = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

total = 0

# Determine row and column sweep direction
row_range = range(n) if vy >= 0 else range(n-1, -1, -1)
col_range = range(n) if vx >= 0 else range(n-1, -1, -1)

# The key idea is to sweep along diagonals aligned with vector signs
for sum_idx in range(2*n - 1):
    max_height = 0
    # For each diagonal where i+j == sum_idx (or i-j == sum_idx for other signs)
    for i in row_range:
        j = sum_idx - i
        if j < 0 or j >= n:
            continue
        h = a[i][j]
        visible = max(0, h - max_height)
        total += visible
        max_height = max(max_height, h)

print(total)
```该代码根据矢量符号定义扫描顺序。 我们迭代对角线，使得每条对角线代表一组沿向量垂直线对齐的单元格。 我们维持`max_height`沿扫描方向跟踪最高的立方体，我们将当前高度与当前高度之间的正差相加`max_height`到可见总数。 通过仔细计算对角线索引可以避免相差一的错误，并且我们只处理一次所有单元格。
