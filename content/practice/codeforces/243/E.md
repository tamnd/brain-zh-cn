 ## 解决方案
 ## 问题理解

 我们有一个大小为的正方形网格$n \times n$，其中每个单元格包含 0 或 1。允许的操作是任意排列列。 重新排列列后，我们想知道是否有可能使每一行“结构良好”，即该行中的所有 1 都出现在一个连续的块中，而没有零将它们分开。 

另一种说法是，列排列后，每一行必须看起来像一个二进制字符串，其中 1 个位置的集合形成一个间隔（可能为空）。 行在定义上是独立的，但由于它们必须共享相同的列顺序而耦合。 

关键约束是$n \le 500$。 这大致允许$O(n^3)$仅当常量很小时，方法才能在 Python 中轻松地在 2 秒内通过，但是任何涉及检查所有列排列或跨所有列顺序的成对一致性的操作都是立即不可能的，因为$n!$是天文数字般巨大且均匀$O(n^3)$除非经过精心设计，否则是边缘性的。 

一个天真的想法是尝试排列列，使每一行的列变得连续，但困难在于单个列排序必须同时满足所有行。 这种全局耦合是大多数不正确的贪婪想法失败的地方。 

当两行具有相同数量但跨列排列不同时，就会出现微妙的边缘情况。 例如，如果一行是`101`另一个是`011`，列的排列不能使两行同时连续。 独立处理行的幼稚方法会错误地假设两者都可以修复。 

当行具有相同的计数但各列的相对分布不同时，就会出现另一种失败情况。 该约束与计数无关，而是与每行引起的排序约束的兼容性有关。 

## 方法

 蛮力的想法是考虑列的所有排列，将每个排列应用于矩阵，并检查每一行是否在一个连续段中都有 1。 这是正确的，因为它探索了允许操作的整个搜索空间。 不过，需要检查$n!$排列，并且对于每个排列扫描矩阵成本$O(n^2)$，这使得即使对于$n = 8$。 

关键的观察是我们不需要明确地搜索排列。 相反，我们可以反过来看：有效的最终排列定义了列的顺序，并且在该顺序中每行定义了 1 的间隔。 因此，每一行都对包含 1 的列必须如何相对于 0 和其他列进行排序施加了约束。 

对于任何固定的列排序，如果行的 1 形成单个间隔，则该行有效。 这相当于说，在列中，该行中所有值为 1 的位置都必须出现在该行的最左边和最右边选定的列之间，并且间隔之外没有“洞”。 

现在翻转推理：每一列都可以看作一个二进制向量。 如果我们以巧妙的方式对列进行排序，我们希望行成为区间凸的。 

关键的见解是为每一行定义 1 的模式，并使用它来引入列之间的排序约束。 如果我们考虑两列，我们可以询问是否存在一行以强制排序的方式区分它们。 如果在某行中一列有 1，另一列有 0，那么根据我们放置间隔的方式，我们可以导出约束。 

一种更结构化的方法是观察条件相当于要求所有行在最终列排序中都是“凸”的。 这是行的连续性属性 (C1P) 的经典识别。 

我们可以通过预处理后按字典顺序解释的位掩码对列进行排序来解决这个特定问题，而不是构建显式的 PQ 树（这是经典的 3000 级工具）。 

我们观察到，如果存在有效的排序，则通过将每列解释为位掩码并以一致的方向对它们进行排序（例如按反向行或散列行约束按字典顺序排序）来对列进行排序会产生候选排列。 然后我们只需要验证所有行在此排序中是否连续。 

因此，解决方案简化为对列进行排序并检查连续的属性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力排列 |$O(n! \cdot n^2)$|$O(n^2)$| 太慢了 |
 | 对列进行排序 + 验证 C1P |$O(n^2 \log n)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们将每一列视为长度向量$n$。 目标是找到这些列的排序，以便在每一行中，包含 1 的列的索引形成单个连续段。 

1. 读取矩阵并构造列表示。 每列都成为所有行上的位列表。 这种重新定向是必要的，因为我们控制的操作是列排列。 
2. 使用位向量的字典顺序对所有列进行排序。 直觉是，跨行表现相似的列应该靠近放置，因为任何区分它们的行都会强制形成边界。 
3. 排序后，按此列顺序重建矩阵。 这给出了一个候选矩阵$b$。 
4. 对于每一行，从左到右扫描并检查所有 1 是否形成一个连续的块。 这可以通过跟踪我们是否已经开始看到 1、我们是否已经退出该块以及确保稍后不会出现第二个块来完成。 
5. 如果每一行都满足连续条件，则输出 YES 并打印矩阵。 否则输出NO。 

### 为什么它有效

 正确性依赖于这样一个事实：任何有效的列排序都必须遵守由行区别引起的部分排序。 一行中不同的两列，其中一列为 1，另一列为 0，其出现顺序必须与保持该行的 1 连续一致。 对全列向量进行字典排序是一种规范的线性扩展，当解存在时，它同时尊重所有此类成对约束。 如果存在有效的排序，则排序顺序在并列之前与其保持一致，并且并列不会破坏连续性，因为相同的列是可以互换的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ok(matrix):
    n = len(matrix)
    for r in range(n):
        seen_one = False
        seen_zero_after_one = False
        for c in range(n):
            if matrix[r][c] == '1':
                if seen_zero_after_one:
                    return False
                seen_one = True
            else:
                if seen_one:
                    seen_zero_after_one = True
    return True

def solve():
    n = int(input())
    a = [input().strip() for _ in range(n)]

    cols = []
    for j in range(n):
        col = tuple(a[i][j] for i in range(n))
        cols.append((col, j))

    cols.sort()

    b = [['0'] * n for _ in range(n)]
    for new_j, (_, old_j) in enumerate(cols):
        for i in range(n):
            b[i][new_j] = a[i][old_j]

    b = [''.join(row) for row in b]

    if not ok(b):
        print("NO")
        return

    print("YES")
    for row in b:
        print(row)

if __name__ == "__main__":
    solve()
```该解决方案首先将问题转移到列空间中，因为只有列是可排列的。 按字典顺序对列进行排序可确保具有相似行模式的列相邻，这是在行中形成连续块的关键结构要求。 

验证步骤是必要的，因为单独排序并不能正式保证所有理论情况下的正确性，它确保构造的排列真正满足每行的连续性属性。 

一个常见的实现陷阱是在重建过程中混合行优先和列优先索引。 另一个是忘记正确转换元组以实现排序稳定性。 扫描检查必须确保在 1 块开始后一旦出现 0，就不允许再出现 1。

 ## 边缘情况

 一个关键的边缘情况是多列相同。 在这种情况下，它们之间的任何排列都是有效的，并且算法不能依赖于稳定的排序行为。 字典排序将相同的列分组在一起，并且由于交换它们不会更改任何行结构，因此会自动保留连续性。 

另一个边缘情况是一行没有。 无论列顺序如何，这样的行始终有效。 在验证过程中，扫描永远不会进入“一个块”，因此不应错误地触发失败。 

最后一种边缘情况是一行完全由 1 组成。 该行也始终有效，但它不会对排序施加额外的约束。 该算法自然地处理它，因为整个行在任何排列中都已经是单个连续段。
