 ## 解决方案
 ## 问题理解

 我们被要求选择一个整数点$x$在一条线上使得$(k+1)$- 距的最小距离$x$最小化给定的点集。 每个查询都给我们$n$排序的整数$a_1, a_2, \dots, a_n$代表 上的点$OX$轴和一个整数$k$。 功能$f_k(x)$通过计算绝对距离来定义$x$对每个$a_i$，对它们进行排序，然后选择$(k+1)$-th 值。 目标是选择$x$最大限度地减少$f_k(x)$。 

约束很严格：$n$可以达到$2 \cdot 10^5$以及所有的总和$n$跨查询也至多$2 \cdot 10^5$。 这排除了任何迭代所有可能的解决方案$x$整个范围内的值，最高可达$10^9$。 我们需要一个线性解$n$每个查询，或者最坏的情况$O(n \log n)$，保持在时间限制以下。 

非明显的边缘情况包括以下场景：$k = 0$或者$k = n-1$。 为了$k = 0$,$f_0(x)$是到任意点的最小距离，所以最优$x$必须与现有点之一重合。 为了$k = n-1$,$f_{n-1}(x)$是到任意点的最大距离，在极值点的中点处最小。 粗心的方法假设固定公式而不检查边界可能会为这些极端情况产生错误的答案$k$价值观。 

## 方法

 蛮力方法很简单：对于每个整数$x$在范围从$a_1$到$a_n$，计算所有距离，对它们进行排序，然后选择$(k+1)$-第最小距离。 这是正确的，但速度非常慢，因为排序$n$距离可达$10^9$可能的$x$值是不可行的。 甚至仅迭代给定的点作为候选点并计算所有点的距离$n$会是$O(n^2)$在最坏的情况下，这对于$n \approx 2 \cdot 10^5$。 

关键的见解是$f_k(x)$仅取决于$k$-th 最近邻居。 由于点已排序，因此$(k+1)$第一个最近距离为$x$可以通过考虑长度段来实现$k$在已排序的数组中。 具体来说，对于任意$x$， 这$(k+1)$-第一个最近的点将是一些$a_i$在数组中，最小值出现在$x$被放置在中点$a_i$和$a_{i+k}$。 这将问题减少到迭代所有$i$从$0$到$n-k-1$，计算中点$(a_i + a_{i+k}) // 2$，并选取值$x$最大限度地减少到线段端点的距离。 这是线性的$n$每个查询并避免在每个候选点进行排序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 迭代索引$i$从$0$到$n-k-1$。 每个片段来自$a_i$到$a_{i+k}$代表$k+1$连续点。 任何$x$在此区间之外选择不能减少$(k+1)$- 该段的最小距离，因此最佳$x$必须位于这个区间内。 
2. 对于每个线段，计算中点$m = (a_i + a_{i+k}) // 2$。 配售$x$在此中点平衡到线段中第一个点和最后一个点的距离，最小化$|x - a_i|$和$|x - a_{i+k}|$。 
3. 追踪最小距离$d = a_{i+k} - a_i$跨越所有细分市场。 当较小的$d$找到，更新候选人$x$到相应的中点。 
4. 迭代所有段后，选择的$x$对应于具有最小长度的段。 这保证了$f_k(x)$被最小化。 

为什么它有效：$(k+1)$- 一点的最小距离$x$是由$k$- 周围最近的邻居$x$。 最小距离是通过平衡实现的$x$在最小长度段内$k$在排序点中，这确保了最远的$k+1$最近的点尽可能接近。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        min_len = float('inf')
        ans = 0
        for i in range(n - k):
            length = a[i + k] - a[i]
            if length < min_len:
                min_len = length
                ans = (a[i] + a[i + k]) // 2
        print(ans)

solve()
```解决方案读取查询的数量，然后针对每个查询读取$n$,$k$，以及排序后的数组。 它迭代所有可能的长度段$k+1$，计算线段长度并用最小线段的中点更新答案。 使用整数除法可确保$x$是一个整数。 每个查询都会打印最终答案。
