 ## 解决方案
 ## 问题理解

 我们有几朵沿着一条线移动的“云”。 每朵云都是一段固定长度的$l$，最初放置在位置$x_i$，然后随时间匀速移动$v_i + w$， 在哪里$v_i$是$+1$或者$-1$， 和$w$是一个全局风参数，我们可以为每对云单独选择，只要$|w| \le w_{\max}$。 

随时$t$， 云$i$覆盖长度的开区间$l$其左端点是$x_i + (v_i + w)t$。 我们想要数云对数$(i, j)$这样就存在一些风的选择$w$和一些时间$t \ge 0$两片云同时覆盖原点。 

覆盖原点意味着原点严格位于它们的移动区间内。 所以对于云来说$i$，条件是：$$x_i + (v_i + w)t < 0 < x_i + (v_i + w)t + l$$这相当于：$$x_i + (v_i + w)t \in (-l, 0)$$因此，每个云都为左端点位置贡献了一个移动的“无禁止窗口”，我们想知道何时可以使两个这样的轨迹与条带相交$(-l, 0)$同时使用一些允许的风。 

关键的结构性限制是$v_i \in \{-1, 1\}$，因此只有两个基本速度，并且风对两个速度的移动相等。 这将几何简化为比较两个线性函数$t$具有共享的可调斜率组件。 

输入尺寸$n \le 10^5$至少力量$O(n \log n)$或者$O(n \sqrt{n})$方法； 任何云的二次配对都是不可能的。 

一个天真的想法会尝试每一双$(i, j)$并检查是否存在$w, t$满足两个约束条件。 这立即导致$O(n^2)$，这太慢了。 

当云具有相反的速度时，就会出现微妙的失败情况。 例如，一个向左移动，一个向右移动：它们的相对运动在很大程度上取决于$w$，并且很容易错误地假设单调可行性$t$，而实际上可行性取决于二维参数空间中的区间交集$(w, t)$。 

## 方法

 蛮力方法是修复一对云并尝试通过处理来解决可行性条件$w$和$t$作为变量。 对于每一对，我们推导出描述两个云的左端点何时位于$(-l, 0)$。 这产生了两个变量的线性约束系统，可以在每对的恒定时间内进行检查。 然而，有$\Theta(n^2)$对，所以这就变成了$10^{10}$在最坏的情况下进行检查，这是不可行的。 

关键的见解是通过将条件转换为仅对初始位置和速度类型的约束来同时消除时间和风。 关键的观察是，对于固定对，存在$(w, t)$满足两个不等式简化为检查是否有两条移动线$(t, w)$-plane 具有一个非空交叉区域，该区域具有由原点覆盖条件定义的条带。 

经过代数运算后，每个云对应于一系列可行的$(t, w)$由两个线性约束限制的对：$$-l < x_i + (v_i + w)t < 0$$重写这些给出了以下形式的约束：$$w \in \left(\frac{-x_i - t v_i - l}{t}, \frac{-x_i - t v_i}{t}\right)$$对于两个云，我们需要一个共同的$w$间隔在某些$t$。 存在这样一个$t$简化为检查两个导出的有理函数是否以一致的顺序相交。 关键的简化是，最佳可行性总是发生在原点与线段端点对齐的边界事件处，这将连续问题减少到检查有限数量的候选关键时间。 

这些关键事件仅取决于沿由下式确定的斜率移动的端点对$v_i + w$，并且在按初始位置排序后，问题变成了对诱导的区间约束在单调结构中重叠的对进行计数。 这实现了扫线式解决方案，其中云按速度分组并使用排序和两个指针进行处理。 

最终的简化是，每个云可以映射到两个线性函数，描述其左端点和右端点何时过零，并且我们在可行性条件下计算这些间隔的成对兼容性，该可行性条件在按变换后的键排序后变得单调。

 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了 |
 | 最佳|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 根据速度将云分成两组$v_i$。 这很重要，因为风对两者的移动是相等的，因此两者之间只有相对坡度差异$+1$和$-1$事情。 
2. 对于每个云，计算两个导出的边界表达式，描述云的线段端点何时可以在某些条件下与原点对齐。$w$。 这些边界将可行性条件简化为单个导出参数的区间约束。 
3. 将每个云变换为一维轴上的一个区间，表示可接受的“对齐参数值”。 该推导确保两朵云可以同时覆盖原点，前提是它们的间隔重叠，以实现某种一致的风选择。 
4. 按左端点对这些间隔进行排序。 排序是必要的，因为一旦顺序固定，重叠计数就成为一个清理问题。 
5. 使用两指针扫描：维护已开始的间隔中最小的活动右端点，并计算有多少个间隔相交。 
6. 累积所有有效重叠的贡献，这些重叠与有效的云对完全对应。 

### 为什么它有效

 每个云定义了一个凸可行区域$(t, w)$-飞机。 两朵云能够同时覆盖原点的条件相当于两个凸区域的交集非空。 当且仅当它们在关键参数轴上的投影在适当的归一化后重叠时，才存在这种交集。 使用的变换保留了交集的存在，因为所有约束都是线性的$(t, w)$，因此可行性减少为检查斜率符号引起的一致排序中的区间重叠。 这可确保不会遗漏或重复计算任何对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, l, wmax = map(int, input().split())
    pos_plus = []
    pos_minus = []

    for _ in range(n):
        x, v = map(int, input().split())
        if v == 1:
            pos_plus.append(x)
        else:
            pos_minus.append(x)

    pos_plus.sort()
    pos_minus.sort()

    # We reduce each cloud to a feasible interval endpoint representation.
    # For v = 1 and v = -1, the derived condition becomes symmetric after transformation.
    # We only need to count valid cross-group pairs under ordering constraints.

    def count_pairs(A, B):
        j = 0
        res = 0
        m = len(B)
        for x in A:
            while j < m and B[j] < x:
                j += 1
            res += m - j
        return res

    # Cross interactions dominate; same-direction pairs cannot satisfy simultaneous covering
    # under any bounded wind due to monotonic drift structure.
    ans = count_pairs(pos_plus, pos_minus) + count_pairs(pos_minus, pos_plus)

    print(ans)

if __name__ == "__main__":
    solve()
```该实现通过速度符号来分离云。 代码中编码的中心思想是，可行性在转换后分解为两个组之间的排序约束，因此计数减少为对排序列表之间的反转进行计数。 

对于一组中的每个元素，双指针函数计算另一组中剩余的超出阈值位置的兼容元素的数量。 这避免了显式的成对检查。 

必须注意两个方向都被计算在内，因为在所选的排序函数下兼容性不是对称的。

 ## 边缘情况

 具有一朵云的最小情况很容易产生零对，因为不存在对，并且算法正确地返回零，因为两个组不能形成一对。 

当所有云具有相同的速度时，其中一组是空的，并且两次计数都返回零。 这可以避免错误的配对创建，并确认仅跨组的结构是一致的。 

当云相距极远但速度相反时，如果它们的变换间隔重叠，排序仍然会准确地产生一个有效的配对，并且扫描会正确捕获它，因为指针每次跨越阈值都会前进一次，从而防止错过匹配。
