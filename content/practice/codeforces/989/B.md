 ## 解决方案

 ## 问题理解

 我们给定一个长度的字符串$n$由三种类型的字符组成：固定零、固定一和通配符点。 每个点都可以独立地变为0或1。替换所有点后，我们得到一个完全具体的二进制字符串。 

我们还得到一个整数$p$。 据说字符串有句点$p$当每个字符都处于位置时$i$匹配位置处的字符$i+p$，只要两个位置都存在。 换句话说，将字符串移动$p$不会在定义比较的任何位置更改它。 

任务是确定我们是否可以为所有点赋值，以便生成的字符串没有句点$p$。 如果可能的话，我们必须构造一个这样的作业。 否则，我们必须报告不可能。 

限制条件$n \le 2000$建议$O(n^2)$推理是安全的。 每次构造尝试的任何线性或近线性都是可以接受的，而所有的指数计数$2^{\#dots}$由于点的数量可能很大，因此分配是不可行的。 

当已知字符强制的结构已经确定了周期的所有比较时，就会出现微妙的失败情况$p$。 例如，如果每个位置$i$和$i+p$由于固定字符，可以比较的内容已经一致，那么点不能引入任何分歧，答案必须是“否”。 相反，如果存在一对我们有自由的，我们就可以强制不匹配。 

## 方法

 直接的暴力解决方案将尝试所有点的分配，填充字符串，并检查句点是否$p$成立。 检查单个任务成本$O(n)$，并且有$2^k$作业在哪里$k$是点数。 即使对于中等程度的人来说，这也很快变得不可行$k$， 自从$n$最多可达 2000。 

关键的观察是我们不需要全局推理所有分配。 期间条件$p$纯粹是本地的：它只比较对$(i, i+p)$。 如果我们在任何这样的对中创建不匹配，则该字符串立即不再是周期性的。 

这表明了一种建设性的方法。 首先，我们尝试满足已知角色施加的所有强制约束。 如果一个点与一个已知值配对，如果我们想要周期性，它必须与该值匹配。 如果两者都已知并且发生冲突，那么周期性就已经不可能了，我们就完成了。 解决强制传播后，我们检查是否存在任何对$(i, i+p)$其中两个位置要么是自由的，要么可以是不同的。 如果存在这样的一对，我们可以显式地分配值来打破周期性。 否则，所有对都被锁定为相等，这意味着不能违反周期性。 

最终的构建成为一种有针对性的“打破一个约束”策略，而不是探索所有任务。

 ## 算法演练

 我们考虑职位之间的限制$i$和$i+p$。 如果字符串要保持周期性，则每个这样的对都强制相等。 

1. 迭代所有索引$i$从$1$到$n-p$。 对于每对$(i, i+p)$，检查两个字符。 
2. 如果两个字符都是固定且不同的（一个是0，另一个是1），那么无论我们如何填充点，周期性都已经不可能了。 在这种情况下，我们可以安全地输出字符串的任何完成。 
3. 否则，如果至少一侧是点或两者相等，则这对不会帮助我们自动打破周期性。 我们继续检查所有对。 
4. 如果我们找到一对$(i, i+p)$如果至少一个位置是一个点，而另一个位置是已知的或者也是一个点，我们尝试强制不匹配：分配点，以便$s[i] \ne s[i+p]$。 
5. 为了构造一个有效的答案，我们首先复制字符串并任意替换剩余的点（例如用 0），然后通过翻转一侧显式强制选定的一对不同。 
6. 如果不存在这样的对，我们可以引入不匹配，则意味着每对要么已经固定相等，要么以强制相等的方式完全确定。 在这种情况下，任何构造都不能打破周期性，因此我们输出“No”。 

### 为什么它有效

 字符串有句点$p$恰好当每个索引对$(i, i+p)$匹配。 这些对形成独立的约束； 没有位置与其自身的移动链接之外的任何对相互作用。 这意味着打破周期性需要打破至少其中一个约束。 

如果每一对已经被固定字符强制相等，那么点就不能在不违反其他地方固定约束的情况下引入分歧。 相反，如果至少存在一对我们仍然具有灵活性，我们可以在本地分配值以创建不匹配，而不会影响其他对，因为每个位置仅参与一个与违规有关的比较方向。 

因此，单个“灵活对”的存在对于构造有效的非周期性完成是必要且充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, p = map(int, input().split())
    s = list(input().strip())

    # try to force a mismatch in any (i, i+p) pair
    for i in range(n - p):
        j = i + p

        if s[i] != '.' and s[j] != '.' and s[i] != s[j]:
            # already broken periodicity, just fill dots arbitrarily
            for k in range(n):
                if s[k] == '.':
                    s[k] = '0'
            print("".join(s))
            return

    # build a baseline valid fill
    t = s[:]
    for i in range(n):
        if t[i] == '.':
            t[i] = '0'

    # try to introduce a mismatch in some pair
    for i in range(n - p):
        j = i + p
        if s[i] == '.' or s[j] == '.':
            t[i] = '0'
            t[j] = '1'
            print("".join(t))
            return

    print("No")

if __name__ == "__main__":
    solve()
```第一个循环扫描固定输入中已经矛盾的一对。 如果存在这样的一对，我们就立即完成，因为周期性已经不可能了； 我们只需要一致地解决点。 

第二阶段通过用零替换所有点来构建完全具体的基线字符串。 这给出了要修改的有效周期性候选结构。 

第三阶段试图在包含至少一个灵活位置的一对中引入故意的不匹配。 更改两个位置是安全的，因为每个位置仅受其自身的约束$i$和$i+p$关系，我们只需要一个违规比较。 

最后的“否”情况仅在每对都完全固定且一致且无法打破相等性时才会发生。

 ## 边缘情况

 已经满足周期性的完全固定的字符串迫使答案为“否”。 在这种情况下，每对$(i, i+p)$已经相等并且不存在引入不匹配的点。 算法到达最后一个分支并打印“No”，这符合要求。 

当关键对中的每个位置都是点时，构造步骤将它们分别指定为 0 和 1。 由于这些位置仅根据其偏移对进行检查，因此这保证了破坏的周期性而不干扰其他约束。 

当整个字符串中只有一个点时，只要它出现在任何一对中就足够了$(i, i+p)$。 该算法在扫描过程中检测到这一点并将其用作断点，即使在最小变化情况下也能确保正确性。
