 ## 解决方案
 ## 问题理解

 我们得到了几个测试用例。 在每个测试用例中，都有一个圆形教室，$k$编号的座位按循环排列$1$到$k$。 其中一些座位被占用$n$学生，以及每个学生$i$坐在已知的座位位置$a_i$。 所有占用的座位都是不同的，因此我们可以将学生视为放置在圆圈上的点。 

任务是挑选两名学生，使他们的座位之间沿圆圈的距离尽可能大。 距离是按顺时针或逆时针方向沿圆圈行走的最短距离来测量的。 

所以从概念上讲，我们给出了圆上的一组点，我们需要找到具有最大圆距离的点对。 

输出不是距离本身，而是达到该距离的两个学生的指数。 如果多对达到相同的最大距离，则任何有效对都是可接受的。 

限制因素在这里非常重要。 我们最多可以有$10^4$测试用例，所有测试用例的学生总数最多为$2 \cdot 10^5$。 座位数$k$可以大到$10^9$，所以我们不能做任何线性依赖于$k$。 任何解决方案都必须在与每个测试用例的学生数量基本呈线性的时间内发挥作用。 

一个天真的想法是计算所有成对距离。 这立即变得太慢了：对于$n = 2 \cdot 10^5$, 一个完整的$O(n^2)$检查顺序为$4 \cdot 10^{10}$比较，这远远超出了任何时间限制。 

有一些边缘情况往往会破坏不正确的贪婪尝试。 

如果所有学生都聚集成一条短弧线，比如座位$[1, 2, 3, 4]$在一个大小的圆上$100$，最好的一对显然是端点，但是任何只考虑相邻差异的方法都可能无法意识到环绕距离的问题。 

例如，如果学生几乎均匀分布$1, 4, 7, 10$在一个大圆上，如果我们忘记循环环绕，最大距离可能来自按排序顺序不相邻的一对。 

最后，循环性质引入了一个经典的陷阱：最大间隙不一定是原始顺序中的连续点之间，除非我们明确处理环绕段。 

## 方法

 暴力方法检查每对学生并使用以下公式计算他们的圆距离$\min(|x-y|, k-|x-y|)$。 这是正确的，因为它直接评估定义的所有可能性。 不过需要计算$O(n^2)$每个测试用例对。 和$n$最多$2 \cdot 10^5$总的来说，这是不可行的。 

关键的结构观察是，问题本质上是关于圆上的极端分离。 如果我们对学生位置进行排序，唯一重要的候选点是按循环顺序排列的相邻点。 这是因为任何不相邻的点之间沿圆都有另一个点，这严格降低了它们在一个方向上相距最远的可能性，同时增加了相反的弧度，并且最大圆距离始终对应于遍历圆时连续点之间的最大间隙。 

一旦我们对位置进行排序，我们就会计算连续元素之间的间隙，包括最后一个元素和第一个元素之间的环绕间隙（考虑循环性质）。 产生最大差距的一对学生对应于在最短路径距离方面在圆上相距最远的一对学生。 

与其直接考虑距离，不如考虑“两点之间哪条弧最小”更稳定。 最大化最短路径相当于最大化排序圆形排列中的互补弧间隙。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$每个测试用例|$O(1)$| 太慢了|
 | 排序+相邻间隙|$O(n \log n)$总计 |$O(n)$| 已接受 |

 ## 算法演练

 1. 阅读所有学生的位置并记住其原始索引。 我们需要索引，因为输出是学生标签，而不是位置。 
2. 按座位顺序对学生进行排序。 排序将循环结构转换为线性表示，其中邻接变得有意义。 
3. 计算排序数组中每个连续对之间的循环间隙。 对于两个相邻位置$x_i$和$x_{i+1}$，差距是$x_{i+1} - x_i$。 对于最后一个和第一个元素，间隙是$(k - x_n) + x_1$，代表环绕圆。 
4. 找出产生最大差距的一对连续学生。 该间隙对应于圆上最大的空弧。 
5. 答案是位于最大差距端点的一对学生。 输出它们的原始索引。 

我们关注间隙而不是直接距离的原因是，两点之间的最短圆距离由它们定义的两个弧中较小的一个确定。 最大化最短距离相当于找到最大的空弧并选择其端点。 

### 为什么它有效

 在圆上，任何一组点都将圆周划分为连续点之间的弧。 对于任意两个在圆顺序上不相邻的点，在绕圆的两个可能的方向上都至少存在一个中间点，这意味着它们之间的两条圆弧之一由多个较小的圆弧组成。 这防止了这样的一对跨越最大可能的最小距离，因为当所选择的对限定最大空弧的边界时总是实现最佳分离。 因此，最优对必须对应于已排序的循环顺序的相邻点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        # store (position, index)
        arr = [(a[i], i + 1) for i in range(n)]
        arr.sort()
        
        best_gap = -1
        best_pair = (1, 2)
        
        # check consecutive pairs
        for i in range(n - 1):
            gap = arr[i + 1][0] - arr[i][0]
            if gap > best_gap:
                best_gap = gap
                best_pair = (arr[i][1], arr[i + 1][1])
        
        # wrap-around gap
        wrap_gap = (k - arr[-1][0]) + arr[0][0]
        if wrap_gap > best_gap:
            best_pair = (arr[-1][1], arr[0][1])
        
        print(*best_pair)

if __name__ == "__main__":
    solve()
```排序步骤将问题从全局配对搜索减少为局部邻接检查。 配对跟踪使用原始索引，以便排序不会破坏所需的输出格式。 环绕检查至关重要，因为圆没有自然的起点或终点，如果不包括它，就会错过最佳对跨越边界的情况$k$和$1$。

 ## 边缘情况

 对于$n = 2$，只有一对，因此算法应该直接返回这两个索引。 排序间隙逻辑仍然有效，因为线性间隙和回绕间隙实际上是相同的。 

对于均匀分布的点，例如$1, 3, 5, 7$在大圆上，相邻间隙和环绕间隙都可能相连。 该算法正确地处理了这个问题，因为它只需要任何最大值，而不是唯一的答案。 

对于最优对跨越最大位置和最小位置之间边界的情况，例如$1$和$k$，环绕计算是必不可少的。 如果没有它，算法将错误地假设内部间隙始终占主导地位。
