 ## 解决方案
 ## 问题理解

 我们得到一个一维的单元格网格，每个单元格都带有一个整数值，可以是正数也可以是负数。 玩家从指定位置开始并执行固定长度的移动序列$|s|$。 每一步要么向左，要么向右，或者未知。 未知的移动可以分配给任一方向。 

每次玩家进入一个单元格时，他们都会收集其价值，包括重新访问。 起始单元格对分数没有贡献。 超出左边界或右边界不会停止该过程：玩家会停留在边界单元上，如果他们尝试进一步向外移动，则会再次有效地收集其值。 

任务是为所有未知的移动分配方向，以使访问单元格上收集的总和最大化。 

关键的困难在于运动选择会影响未来的位置，进而影响多次收集哪些单元格值。 由于重访是允许的，甚至是在边界处强制重访，所以问题不在于找到一条简单的路径，而在于选择塑造轨迹的方向，以最大化重复增益。 

约束允许多个测试用例，总和$n$所有运动字符串的总长度大约为 2000。这立即排除了任何模拟所有运动字符串的解决方案$2^{\text{number of question marks}}$分配，因为它呈指数增长，即使对于中等字符串也变得不可行。 

对位置和索引的完整状态进行简单的动态规划是合理的，但仍然需要仔细优化，因为对位置和时间的直接 DP 将是$O(n \cdot |s|)$每个测试，只有当转换简单且有效重用时才是可接受的。 

打破朴素推理的边缘情况来自边界弹跳和重复访问。 

一个例子是当除一个边界单元之外的所有值均为负时，例如：

 输入：

 n = 3，k = 2

 a = [ -5, 100, -5 ]

 s =“LLLL”

 天真的贪婪者可能会尝试远离中心或避免再次访问，但正确的策略是故意在边界单元上反复弹跳，以最大化重复的 +100 增益。 

另一个棘手的情况是，最佳策略涉及首先远离高价值区域以设置重复回报。 例如：

 输入：

 n = 5，k = 3

 a = [10, -100, 50, -100, 10]

 s =“？？？”

 简单的方法可能会保持在 50 左右，但最佳游戏可能会在 10 到 50 之间跳跃，具体取决于强制移动与边界的相互作用。 

这些案例表明，问题不仅仅在于每一步的局部问题； 最佳决策取决于长期的回访模式。 

## 方法

 暴力解决方案将尝试所有问号分配，模拟结果路径，并计算分数。 每次模拟费用$O(|s|)$，并与$q$问号的复杂性变成$O(2^q \cdot |s|)$。 自从$|s|$可以达到 2000，即使对于$q \approx 25$。 

关键的观察是系统的状态完全由当前位置和字符串中的索引确定。 未来的分数仅取决于这两个值，而不取决于我们如何达到它们。 这表明随着时间和位置的动态规划。 

然而，关于分配方向的所有可能性的直接DP仍然在每个“？”处分支。 重要的结构简化在于，每一步要么将位置增加或减少恰好 1，并且边界处的无效移动会陷入自循环。 一旦选择了方向，这使得转换具有确定性。 

因此，我们可以定义一个 DP，在处理前 i 个动作并在位置 j 结束后跟踪可能的最佳得分。 在固定步长处，如果我们位于位置 j，向左或向右移动总是会产生一个结果位置。 当移动为“？”时，我们会尝试两个方向并获得更好的结果。 

转换在每步 n 中呈线性，给出$O(n \cdot |s|)$，在约束条件下是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解分配| (O(2^q \cdot | s | )) |
 | DP 位置和步数 | (O(n \cdot | s | )) |

 ## 算法演练

 我们构建了一个动态规划表，为每一步存储在每个位置结束时可达到的最佳分数。 

1. 初始化一个DP数组，其中`dp[x]`表示处理当前动作前缀并处于位置后的最佳分数`x`。 我们首先将除初始位置之外的所有值设置为负无穷大，初始位置以零分数开始，因为起始单元格不被计算在内。 
2. 从左到右迭代一系列动作。 在每一步中，我们构造一个新的 DP 数组`ndp`表示应用当前移动后的结果。 
3. 对于每个位置`x`，如果在当前 DP 中可达，我们考虑移动。 如果字符是“L”，我们过渡到`x-1`，但如果`x`已经在左边界了，我们停留在`x`。 我们将结果单元格的值添加到分数中。 
4. 同样，如果字符是“R”，我们移动到`x+1`，或停留在`x`如果在右边界，则添加相应的单元格值。 
5. 如果字符是“？”，我们评估两种可能性：将其视为“L”和“R”，然后传播两种转换，保持每个目标单元格的最大分数。 
6.处理完当前步骤的所有位置后，我们替换`dp`和`ndp`并继续。 

答案是最终 DP 数组中的最大值。 

### 为什么它有效

 DP 状态准确地捕获了对未来决策重要的因素：当前位置和累积分数。 任何在相同移动次数后以相同位置结束的两个历史在未来都可以互换，因为未来的转换仅取决于位置和下一步移动，而不取决于如何到达该位置。 这建立了一个最佳子结构：前缀的最佳结果足以进行最佳扩展，并且仅保留每个位置的最大分数可以保持正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    s = input().strip()

    INF = -10**30

    # dp[position]
    dp = [INF] * n
    dp[k - 1] = 0

    for ch in s:
        ndp = [INF] * n

        for i in range(n):
            if dp[i] == INF:
                continue

            def relax(nxt):
                ndp[nxt] = max(ndp[nxt], dp[i] + a[nxt])

            if ch == 'L' or ch == '?':
                if i == 0:
                    relax(0)
                else:
                    relax(i - 1)

            if ch == 'R' or ch == '?':
                if i == n - 1:
                    relax(n - 1)
                else:
                    relax(i + 1)

        dp = ndp

    print(max(dp))

if __name__ == "__main__":
    solve()
```代码直接遵循DP定义。 唯一的微妙之处是正确处理边界移动：我们不是跳过过渡，而是将它们映射回相同的索引，这可以正确地模拟边界单元上的重复步进。 

这`relax`函数确保如果多条路径到达同一位置，则仅保留最好的分数。

 ## 边缘情况

 临界边缘情况是起始位置位于边界处。 在这种情况下，任何强制向外移动都会陷入原地不动，并且 DP 必须将其视为仍收集边界值的有效自转移。 该算法可以处理此问题，因为转换显式地将出界移动映射回同一索引。 

另一个边缘情况是所有动作都是“？”。 DP 必须在每一步中探索两个方向，但仍将所有可能性压缩为每个位置的单个最佳值。 由于我们从不分支到超出位置的单独状态，因此避免了指数爆炸。 

第三种情况是内部单元格存在负值但边界为正值。 最优策略在边缘处振荡，这是自然发现的，因为 DP 反复倾向于保持或返回高值边界状态的转换。
