 ## 解决方案
 ## 问题理解

 我们得到一个实数数组，其总和恰好为零。 每个数字都有固定的小数精度，因此每个值都可以被视为具有已知小数部分的有理数。 

任务是将每个实数转换为整数，但有一个限制：每个值只能独立向下舍入或向上舍入。 对于每个索引，所选整数必须是原始数字的下限或上限。 为每个元素选择这两个选项之一后，所得整数的总和必须仍然恰好为零。 

这会在其他独立的舍入决策之间产生耦合。 如果我们将所有内容四舍五入，总和就会变得太小。 如果我们将所有内容四舍五入，总和就会变得太大。 该解决方案必须平衡这些局部舍入选择，以便满足全局总和约束。 

限制最多允许 100,000 个数字。 这立即排除了探索舍入选择的所有组合的任何方法，因为每个元素都有两个选项并且搜索空间是指数的。 任何有效的解决方案都必须是线性或近线性的。 

当许多数字都是整数时，就会出现微妙的边缘情况。 对于这些值，下限和上限是相同的，因此它们不会为平衡过程提供灵活性。 当小数部分极小或极接近 1 时，会出现另一种边缘情况，因为除非仔细处理，否则浮点解释可能会表明不同的舍入行为。 

## 方法

 暴力策略将为每个元素分配其下限或上限，然后检查所得总和是否为零。 由于每个元素有两个选择，这导致$2^n$的可能性。 即使是为了$n = 30$，这已经变得不可行了，并且在$n = 10^5$这是完全不可能的。 

关键结构是每个数字与其下限相差范围内的小数部分$[0, 1)$。 如果我们定义$x_i = \lfloor a_i \rfloor$，然后只要数字还不是整数，就选择上限，将值恰好增加 1。 这将问题转化为选择一个指数子集来“加 1”，以便总和修正可以补偿因将所有内容下底而产生的赤字。 

如果我们将所有楼层相加，我们就会得到一个基线值。 由于原始总和为零，因此零与此基线之间的差是一个整数值，必须通过选择一些元素进行向上舍入来精确校正该整数值。 每次向上舍入都为总和贡献了+1，因此任务变为精确选择所需数量的带小数部分的索引。 

所需的向上轮数是完全确定的，我们可以贪婪地选择任何有小数部分的轮数。

 | ---| ---| ---| ---|
 | 蛮力 |$O(2^n)$|$O(n)$| 太慢了 |
 | 最佳|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将每个数字转换为其下限值并跟踪哪些数字是非整数。 

1. 计算每个数字的下限并将其存储为所有位置的基本整数选择。 这给出了一个有效的起点，该起点永远不会超过向下舍入的目标总和。 
2. 计算这些下限值的总和。 由于地板永远不会增加值，因此该总和小于或等于零。 
3. 零与该总和之间的差是必须向上舍入的元素数量。 每次向上舍入都会使总和恰好增加 1，因此这个差异直接告诉我们需要进行多少次调整。 
4. 识别数字不是整数的所有索引。 这些是唯一可以进行四舍五入的位置。 
5. 准确选择这些指数所需的数量，并从下限到上限增加它们的值。 任何选择都有效，因为每个选择对总和调整的贡献相同。 
6. 输出最终值。 

### 为什么它有效

 该算法依赖于守恒量：必须仅使用 +1 增量将总和从楼层总和调整为零。 由于每个非整数元素正好贡献一个可能的 +1 调整，而整数元素则不贡献任何内容，因此可行性仅取决于将所需的调整计数与可用的小数位置相匹配。 由于原始总和恰好为零，因此所需的调整保证为整数且在可用小数元素的数量内。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = []
floors = []
fractional = []

sum_floor = 0

for i in range(n):
    x = float(input())
    f = int(x // 1)
    a.append(x)
    floors.append(f)
    sum_floor += f
    
    if abs(x - f) > 1e-12:
        fractional.append(i)

need = -sum_floor  # how many we must round up

b = floors[:]

for i in fractional[:need]:
    b[i] += 1

print("\n".join(map(str, b)))
```该代码首先读取所有值并使用截断计算它们的整数下限`// 1`。 这对于 Python 中的正数和负数都适用，因为`//`执行楼层划分语义。 

我们累加所有楼层的总和。 Since the final answer must sum to zero, the number of upward adjustments required is`-sum_floor`。 

我们收集符合向上舍入条件的指数，这意味着它们还不是整数。 这些是唯一可以贡献 +1 调整的位置。 

最后，我们准确地取`need`此类指数并增加其下限价值。 由于每个增量恰好贡献一个总和单位，这保证了最终总和为零。 

一个微妙的点是确保我们正确检测小数值，尽管采用浮点表示。 容差检查可以避免对值进行错误分类，例如`3.00000000001`由于精密噪声。

 ## 边缘情况

 当所有数字都已经是整数时，小数列表为空，并且`need`变为零。 该算法保持每个值不变，从而自动保留所需的总和。 

当所有数字都是负分数时，仅在舍入效应之后总和为零，下限总和变为负值，并通过可用的分数位置进行精确补偿。 选择机制确保我们永远不会尝试使用不存在的调整能力。 

当值非常接近整数时，浮点容差可确保正确分类为小数和整数类别。 该算法的正确性取决于一致的识别而不是精确的二进制表示。
