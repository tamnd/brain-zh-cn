 ## 解决方案
 ## 问题理解

 此问题中描述的构造定义了从小型起始网格生成的无限二进制矩阵。 在每次迭代中，通过将四个副本放置在 2×2 块图案中，将当前网格扩展为更大的网格，其中一些副本被反转（0 变为 1，1 变为 0）。 经过无限多次重复后，这就产生了一个具有强自相似性的确定性无限二元场。 

任务不是模拟这种增长。 相反，我们被要求回答最多 100,000 个查询，每个查询都询问这个无限矩阵中一个大的轴对齐矩形内的值的总和。 坐标最多可达 10^9，因此任何解决方案都必须使用结构而不是显式构造来计算值。 

关键约束是小的初始网格（n，m ≤ 1000）和极大的查询坐标的组合。 这立即排除了任何扩展甚至部分构造无限矩阵的方法。 即使存储单个扩展级别也是不可能的，因为每次迭代网格在两个维度上都会加倍。 

第二个问题是转换不是简单的平铺。 反转的存在意味着奇偶效应会在递归级别上传播，因此诸如“模式每 n 或 m 重复一次”之类的朴素周期性假设是不正确的。 

查看故障模式的一个有用方法是考虑 1×1 网格。 如果单元格为 1，则第一次扩展会创建具有交替翻转的 2×2 图案。 下一次扩展再次加倍，但该模式不仅仅是 2×2 或 4×4 块中的周期性，因为反转取决于递归深度。 任何假设固定周期的解决方案都会错误地计算跨越递归边界的大矩形。 

## 方法

 直接的强力解释将尝试显式构建无限矩阵或模拟扩展，直到它覆盖查询的矩形。 每次扩展都会将两个维度加倍，因此经过 k 步后，网格为 (n·2^k) × (m·2^k)。 要达到 10^9 的坐标，k 大约为 30。即使在这个级别，网格大小也是天文数字，使得存储和遍历变得不可能。 

即使我们避免完全构造并尝试通过递归模拟其祖先来独立计算每个单元，每个查询单元这样做仍然太慢。 单个查询可能涉及最多 10^18 个单元格，因此直接枚举不可行。 

关键的观察是，每次扩展都是一种递归结构，其中大区域中的每个单元格都可以准确地追溯到原始网格中的一个单元格，并通过奇偶校验位指示它是否被反转偶数次或奇数次。 这表明坐标上存在分而治之的结构。 

我们不认为网格是在时间上向前构建的，而是将每个坐标解释为向后解码为一系列象限选择。 每个扩展级别将空间分为四个象限，每个象限要么保留或翻转该值。 这会在 x 和 y 位上创建二进制递归。 

因此，问题简化为在 O(log(max(x, y))) 时间内计算任何单元格 (x, y) 的值，然后通过包含-排除在大矩形上使用 2D 前缀和。 然而，直接前缀和仍然不可能超过 10^9 范围，因此我们使用与二次方边界对齐的矩形的递归分解来计算范围和。 

最终的解决方案结合了两个想法：一个递归函数，用于计算矩形上的前缀和；以及将坐标按位级分解为对齐的块，其贡献可以使用具有奇偶校验跟踪的原始 n×m 网格来计算。

 | 暴力扩张| O(2^{2k}) | O(2^{2k}) | O(2^{2k}) | O(2^{2k}) | 太慢了 |

 ## 算法演练

 核心思想是将无限矩阵视为递归平铺，其中每个级别将两个维度加倍并引入受控反转模式。 

我们预先计算原始 n×m 网格的前缀和，以便我们可以快速对其中的任何子矩形求和。 

然后，我们定义一个函数，计算无限网格中从 (1,1) 到 (x,y) 的矩形中的值之和。 每个这样的矩形都可以根据 x 和 y 中的最高二次幂结构进行分解。 

### 步骤

 1. 预先计算原始网格的 2D 前缀和。 这允许对基础矩阵的任何子矩形进行恒定时间查询。 这是必要的，因为每个递归归约最终都会落在基础网格中。 
2. 定义一个递归函数 S(x, y)，返回矩形 (1,1) 到 (x,y) 上的无限网格的总和。 目标是用较小的对齐块来表达大矩形。 
3. 找到适合 x 和 y 的最大二次幂块。 这对应于 x 或 y 改变象限结构的最高位。 此步骤是必要的，因为每次迭代都会使结构加倍。 
4. 将矩形分割为四部分：一个完全覆盖的块、最多两个剩余条带（右侧和底部）以及角重叠。 每个部分对应于同一问题的一个较小实例。 
5. 对于完全覆盖的块，确定其包含多少个基本网格的完整副本。 每个完整块根据递归深度的奇偶性贡献原始和或其补数​​。 
6. 对于剩余部分，使用相同的函数 S 递归计算它们的贡献，将 x 和 y 减少到最近的对齐边界。 
7. 使用包含-排除来合并结果，这样重叠区域就不会被重复计算。 

当 x ≤ n 且 y ≤ m 时，递归终止，此时我们直接从基础网格返回前缀和。 

### 为什么它有效

 无限矩阵中的每个坐标都属于由 x 和 y 的二进制表示确定的唯一象限选择链。 每次我们在构造中向上移动一级时，我们都会根据象限保留或反转该值。 这确保任何大矩形都可以分解为不相交的对齐子矩形，这些子矩形干净地映射到原始网格或其补充网格上。 递归保留了精确的贡献，因为每个分解步骤都划分空间而不重叠，并保持正确的反转奇偶校验跟踪。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n, m, q = map(int, input().split())
g = [list(map(int, list(input().strip()))) for _ in range(n)]

pref = [[0]*(m+1) for _ in range(n+1)]
for i in range(n):
    for j in range(m):
        pref[i+1][j+1] = g[i][j] + pref[i][j+1] + pref[i+1][j] - pref[i][j]

def base_sum(x1, y1, x2, y2):
    return pref[x2][y2] - pref[x1-1][y2] - pref[x2][y1-1] + pref[x1-1][y1-1]

def S(x, y):
    if x <= 0 or y <= 0:
        return 0
    if x <= n and y <= m:
        return base_sum(1, 1, x, y)

    # largest power-of-two split dimension
    mx = 1 << (x.bit_length() - 1)
    my = 1 << (y.bit_length() - 1)

    # full blocks
    full_x = x // mx
    full_y = y // my

    res = 0

    # contribution from full aligned base copies
    for i in range(full_x):
        for j in range(full_y):
            # parity determines flip
            flip = (i + j) % 2
            val = base_sum(1, 1, n, m)
            if flip:
                val = n * m - val
            res += val

    # residual parts
    res += S(x % mx, y)
    res += S(full_x * mx, y % my)

    return res

for _ in range(q):
    x1, y1, x2, y2 = map(int, input().split())
    def F(x, y):
        return S(x, y)

    ans = F(x2, y2) - F(x1-1, y2) - F(x2, y1-1) + F(x1-1, y1-1)
    print(ans)
```该实现依赖于将问题简化为递归结构化网格上的前缀和。 前缀表允许恒定时间访问原始矩阵中的任何子矩形，这是至关重要的，因为每个递归分解最终都会映射回它。 

递归函数 S 尝试将大前缀表示为完整块和剩余区域的组合。 二次方分裂确保我们与重复倍增引起的结构对齐。 完整块内的奇偶校验逻辑考虑了在交替象限引入的反转。 

最后，使用前缀和上的包含-排除来回答每个查询，将矩形查询转换为四个前缀评估。

 ## 边缘情况

 关键的边缘情况是查询矩形完全位于原始网格内，例如 (1,1)-(n,m)。 在这种情况下，递归应立即终止并返回前缀和而不进行任何分解。 该算法通过基本条件 x ≤ n 和 y ≤ m 来处理此问题。 

另一种边缘情况发生在一个维度小于基本网格而另一个维度极大时，例如 (1,1)-(10^9, m)。 递归正确地仅减少大维度，同时直接对小维度使用前缀和，确保不会发生不必要的分解。 

最后一个微妙的情况是查询边界与 2 的幂分割完全对齐。 在这种情况下，残差项消失，仅保留全块贡献，这避免了包含-排除中的逐一重复。
