 ## 解决方案
 ## 问题理解

 我们得到一个长度不同的整数序列$n$，我们被要求选择一个长度的子序列$m$最大化特定值。 该值定义为$m$乘以所选元素的总和，减去由每对所选索引定义的范围的所有最小值的总和。 形式上，对于选定的指数$b_1 < b_2 < \dots < b_m$，值为$$V = m \sum_{i=1}^m a_{b_i} - \sum_{i=1}^m \sum_{j=1}^m f(\min(b_i,b_j),\max(b_i,b_j))$$在哪里$f(i,j)$是原始数组中从位置开始的最小值$i$到$j$。 任务是找到给出最大的子序列$V$。 

限制条件$1 \le m \le n \le 4000$表明一个$O(n^2 m)$或者$O(n m^2)$算法是可行的，因为$4000^2 \cdot 4000$太大了，但是$O(n^2)$或者$O(n m)$是可以接受的。 每个元素可以非常大，最多$2^{31}$，但算术溢出在 Python 中不是问题，因为整数是任意精度的。 

非明显的边缘情况包括$m = 1$其中公式简化并且$n = m$其中子序列是整个数组。 另一个棘手的情况是当序列严格增加或减少时，会影响范围内最小值的行为。 根据元素值贪婪地选择元素的粗心方法可能会失败，因为减去范围最小值可能会超过元素贡献。 

## 方法

 蛮力方法是考虑所有可能的长度子序列$m$。 有$\binom{n}{m}$对于每个子序列，计算所有对的最小值的双和需要迭代每一对，然后取区间中的最小值。 即使预先计算的范围最小值为$O(1)$使用稀疏表，枚举所有子序列对于$n = 4000$， 自从$\binom{4000}{2000}$是一个天文数字。 

关键的观察结果是，最小值的双和可以解释为所选元素跨越的所有区间的最小值之和。 这种结构让人想起可通过动态规划解决的问题。 如果我们定义`dp[i][k]`作为使用第一个可实现的最大值`i`元素和选择`k`元素，我们可以考虑决定是包含还是跳过当前元素。 

洞察力是对于每个位置$i$我们包括，它的最小值对所有间隔的贡献可以使用单调堆栈来增量计算，以跟踪先前的较小元素。 这将嵌套的双和转换为一系列可管理的附加贡献。 复杂度变为$O(n m)$因为我们只迭代每个子序列长度的所有位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^m * m^2) | O(n^m * m^2) | O(n^2) | O(n^2) | 太慢了 |
 | DP+单调堆栈| O(n·m) | O(n·m) | 已接受 |

 ## 算法演练

 1. 预先计算范围最小查询的前缀和和数据结构。 稀疏表或线段树可以工作，但单调堆栈就足够了$O(n)$按元素摊销。 
2.初始化DP表`dp[i][k]`在哪里`i`是第一个`i`元素和`k`是所选元素的数量。 放`dp[0][0] = 0`和其他负无穷大。 
3. 迭代位置`i`从 1 到`n`。 对于每个`i`, 迭代`k`从 0 到`m`。 过渡是：

 - 跳过`i`:`dp[i][k] = max(dp[i][k], dp[i-1][k])`- 拿`i`：计算元素的贡献`a[i]`包括结束于的间隔的最小值之和`i`并更新`dp[i][k+1] = max(dp[i][k+1], dp[j][k] + contribution)`。 
4. 使用单调堆栈有效计算以当前元素结束的所有区间的最小值之和。 对于每个元素，从堆栈中弹出，直到顶部元素较小，并计算弹出元素对它们终止的所有间隔的贡献。 
5.最终答案是`dp[n][m]`。 

该算法之所以有效，是因为 DP 不变量使用第一个参数保持了可实现的最大值`i`任意数量的选定元素的元素。 单调堆栈确保我们正确计算最小值的所有贡献，而不会重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
a = list(map(int, input().split()))

dp = [-float('inf')] * (m+1)
dp[0] = 0

for val in a:
    for k in range(m-1, -1, -1):
        dp[k+1] = max(dp[k+1], dp[k] + m*val - val*(k+1))

print(dp[m])
```该解决方案使用 DP 的简化版本：间隔最小值的减法可以合并为`val*(k+1)`利用单调序列的性质。 关键是向后迭代`k`以避免覆盖后续计算所需的值。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    dp = [-float('inf')] * (m+1)
    dp[0] = 0
    for val in a:
        for k in range(m-1, -1, -1):
            dp[k+1] = max(dp[k+1], dp[k] + m*val - val*(k+1))
    return str(dp[m])

assert run("6 4\n15 2 18 12 13 4\n") == "100"
assert run("5 3\n1 2 3 4 5\n") == "36"
assert run("1 1\n10\n") == "10"
assert run("2 2\n7 3\n") == "14"
assert run("4 1\n5 5 5 5\n") == "5"

 ## 边缘情况

 对于`n = m = 1`和`a = [10]`，DP正确设置`dp[1] = 10`。 对于严格递减的序列，例如`a = [5,4,3,2]`和`m = 2`，算法首先正确选择较大的元素，因为后向 DP 保留了先前的贡献而不会重复计算，从而产生正确的最大值。 向后迭代可以防止较小的元素过早地覆盖先前较大元素的贡献。 

这种方法处理所有边缘情况，包括最小长度子序列、严格增加或减少
