 ## 解决方案
 ## 问题理解

 我们有两种类型的瓷砖：单位长度的片段（1×1 边）和通过以直角连接两个片段形成的 L 形片段。 罗杰想要使用所有这些图块来完全填充尺寸为轴对齐的矩形网格$n \times m$对于一些正整数$n$和$m$。 每个段和L形片都可以旋转，但任何片都不能拆分或部分使用。 任务是确定这样的矩形是否存在，如果存在，则返回任何有效尺寸。 

输入是$p$和$q$，表示线段和 L 形图块的数量。 两个数字最多可达$10^8$，它足够大，任何简单的矩形枚举或尝试将各个块一块一块地放置都是不可行的。 我们需要一个针对每个测试用例进行基本恒定时间计算的解决方案。 

当我们只有段或只有 L 形图块时，就会出现边缘情况。 例如，如果$p = 5$和$q = 0$，1×5 或 5×1 网格工作。 如果$p = 0$和$q = 1$，容纳单个L形瓷砖的最小网格是2×2。 粗心的算法可能会错过这些最小的情况或产生非整数维度。 

## 方法

 蛮力方法将枚举所有可能的$n$和$m$直到某个合理的界限，并检查线段和L形块的数量是否能够恰好填充网格的周长和内部连接。 这在原则上是正确的，因为每一个$n \times m$网格有$2nm - n - m$边缘，其中一些必须由 L 形贡献，一些由单位段贡献。 然而，随着$p, q \le 10^8$, 枚举$n$和$m$最多$10^4$或者$10^5$至少需要$10^8$每个测试用例的操作超出了时间限制。 

关键的见解是每个 L 形部件以直角覆盖两个部分。 因此，如果我们计算网格边的总数，$total\_edges = 2nm - n - m$，它必须等于 L 形件加上独立单元段所贡献的段数。 每个 L 恰好贡献 2 个边，因此使用的总段为$p + 2q$。 这给出了丢番图方程：$$2nm - n - m = p + 2q$$保理收益率：$$(2n - 1)(2m - 1) = 4(p + 2q) + 1$$现在问题简化为对单个整数进行因式分解并检查它是否可以表示为$(2n-1)(2m-1)$对于正整数$n$和$m$。 对一个数进行因式分解$4\cdot10^8+1$效率足够高$O(\sqrt{N})$每个测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N²) | O(1) | O(1) | 太慢了 |
 | 通过丢番图方程进行因式分解| O(√(p+q)) | O(√(p+q)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，计算使用的段总数：$S = p + 2q$。 这代表填充网格所需的所有边。 
2. 将边方程变换为因式分解形式：$X = 4S + 1$。 这保证了$X$很奇怪。 
3. 枚举所有整数因子$X$。 对于每个因素$f$和$f \le \sqrt{X}$，辅助因子是$X // f$。 
4. 对于每对因素$(f, X//f)$，检查两者是否可以写成$2n-1$和$2m-1$对于正整数$n$和$m$。 这是有效的，如果$f$和$X//f$很奇怪。 然后计算$n = (f+1)//2$,$m = (X//f + 1)//2$。 
5. 如果这样的整数$n$和$m$存在，输出它们。 如果没有因式分解产生正整数，则输出 -1。 

为什么它有效：方程式$2nm - n - m = p + 2q$精确计算网格中的所有段。 转变为$(2n-1)(2m-1) = 4(p+2q)+1$保证我们只考虑整数解。 枚举因素可确保找到所有有效网格（如果存在）。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        p, q = map(int, input().split())
        S = p + 2*q
        X = 4*S + 1
        found = False
        for f in range(1, int(math.isqrt(X)) + 1):
            if X % f == 0:
                g = X // f
                if f % 2 == 1 and g % 2 == 1:
                    n = (f + 1) // 2
                    m = (g + 1) // 2
                    if n > 0 and m > 0:
                        print(n, m)
                        found = True
                        break
        if not found:
            print(-1)

if __name__ == "__main__":
    solve()
```代码直接实现了分解方法。 使用`math.isqrt`避免浮点错误。 检查两个因子是否均为奇数可确保`n`和`m`是整数。 第一个有效对的提前退出就足够了，因为该问题允许任何有效维度。 

## 工作示例

 ### 示例 1

 输入：```
1
1 1
```计算`S = 1 + 2*1 = 3`。 然后`X = 4*3 + 1 = 13`。 13 的因数是 1 和 13。两者都是奇数。 计算`(n,m) = ((1+1)//2, (13+1)//2) = (1,7)`这是有效的。 输出`1 7`。

 这表明分解直接产生解决方案。 

### 示例 2

 输入：```
1
2 2
```计算`S = 2 + 2*2 = 6`。 然后`X = 4*6 + 1 = 25`。 25 的因数：(1,25)、(5,5)。 计算`(n,m)`:

 - (5,5) → (3,3) 有效

 该代码返回第一个有效对`(1,13)`。 这表明多种解决方案是可能的，并且任何一个都是可以接受的。
