 ## 解决方案
 ## 问题理解

 我们有一组参与者必须被分配到帐篷里，每个帐篷最多可容纳三个人。 参与者分为三种类型，他们对共享帐篷的意愿有不同的限制。 

内向的人根本拒绝共用一个帐篷，所以每个内向的人都必须单独占据一个帐篷。 外向的人则是相反的极端：每个人都坚持在一个只有三个人的完整帐篷里，这意味着每个外向的人都必须与另外两个参与者分组。 通用型很灵活，可以单独占用一个帐篷，也可以与另一个人一起占用一个帐篷，也可以与另外两个人一起占用一个帐篷，只要帐篷的大小不超过三个。 

任务是决定是否可以在尊重所有限制的情况下将每个人分配到帐篷，如果可以，则尽量减少使用的帐篷数量。 

输入大小最多为 10^4 个测试用例，每种类型的计数高达 10^9。 这立即排除了对个人的任何模拟。 任何正确的解决方案都必须将每个测试用例简化为常数时间算术。 

一种幼稚的方法可能会尝试一步步贪婪地填满帐篷，反复形成有效的群体，直到人用完为止。 这种模拟是危险的，因为分配的顺序会影响可行性。 例如，如果太早消耗普遍性，我们以后可能无法完成完整的外向小组。 

当外向的人即使使用了所有共性之后也不能被放入完整的三人组时，就会出现一个关键的边缘情况：

 输入：```
0 1 1
```一个外向的人和一个普遍的人不能组成一个有效的三人团体，而且外向的人不能独自一人或在一个不完整的帐篷里。 正确的输出是`-1`。 首先将共性放在其他地方的贪婪算法可能会错误地得出可行性结论，让外向者陷入困境。 

当内向者在推理早期消耗太多帐篷而没有考虑到稍后可能需要共性来完成外向群体这一事实时，另一个微妙的失败就会出现。 

这些观察结果表明，在计算剩余的帐篷之前，我们必须全面地推断外向的人需要多少共性。 

## 方法

 蛮力的解释就是字面意义上的建造帐篷。 我们反复尝试将外向的人分成三人一组，然后将内向的人放入单个帐篷，最后将共性分配给任何剩余的空位。 对于每个测试用例，我们可能会尝试外向群体和剩余帐篷之间所有可能的共性分布。 

然而，状态空间随着参与者数量的增加而增长。 即使是处理每个人一次的简化模拟，每个测试用例仍然面临 O(a + b + c) 的风险，在所有输入的最坏情况下，这将变成 10^14 次操作。 这太慢了。 

问题的结构表明了更直接的分解。 内向的人是固定的：他们总是每人只消耗一顶帐篷。 外向的人也很严格：他们必须恰好由三个人组成一组，因此他们贡献 b 个帐篷，但如果 b 不能整除为完美的三元组，则可能需要共相的帮助。 共性是唯一灵活的资源，它们的作用是填补外向群体中缺失的位置，并在之后形成剩余的部分群体。 

关键的见解是首先对待外向群体。 每个完全外向的小组都会消耗一个三号帐篷。 如果 b % 3 非零，则其余 1 或 2 个外向者需要共性来完成他们的组； 否则，如果没有足够的通用性，则配置是不可能的。 在满足了外向者的要求后，剩下的通用性只能通过分成三个一组来减少帐篷的数量。 

这将问题简化为简单的算术而不是赋值搜索。

 ## 算法演练

 我们独立处理每个测试用例。 

1. 首先为每个性格内向的人分配一个帐篷。 这是被迫的，因为内向的人无法分享。 我们开始回答`a`。 
2. 接下来，以三人一组的方式应对外向的人。 每三个外向者组成的完整组恰好消耗一个帐篷，所以我们添加`b // 3`到答案。 
3. 计算余数`r = b % 3`。 这代表了无法形成完整群体的剩余外向者。 
4.如果`r > 0`，我们必须用普遍性来完成最后一个不完整的外向群体。 如果我们有少于`3 - r`普遍存在，我们无法满足外向约束并返回`-1`。 
5. 如果可以完成最后一组，我们将扣除所需的通用项。 不完整的小组仍然贡献一顶帐篷，所以我们添加`1`到答案。 
6. 现在我们还有剩余的共性。 他们可以自由地分成三组，每组形成一个帐篷。 添加`(c_remaining) // 3`到答案。 
7. 如果打包后仍有通用物品，它们仍会占据帐篷，但由于每个帐篷最多可容纳三人，因此剩余的通用物品最多只能形成一个额外的部分帐篷。 然而，这已经通过整数除法解决了，因为剩下的 1-2 个通用数仍然需要一个帐篷。 

一个更紧凑的公式出现了：在处理完外向者之后，只需通过填充剩余的点，然后将三元组分组，将剩余的普遍性贪婪地添加到帐篷中。 

### 为什么它有效

 该算法通过刚性来区分参与者。 内向者和外向者施加了固定的结构约束，而共性是一种仅用于修复不完整的外向群体或填补剩余能力的资源。 不变的是，在处理完外向者之后，每个帐篷要么完全确定，要么正好有一个或两个空闲槽，并且在形成新帐篷之前总是将通用项放入这些槽中。 由于当可以避免使用新帐篷时，在部分填充的结构中放置未使用的通用物品永远不会有好处，因此贪婪的包装是最佳的，并且不能增加帐篷的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b, c = map(int, input().split())

        # introverts always need their own tents
        ans = a

        # handle extroverts in full groups of 3
        ans += b // 3
        r = b % 3

        if r:
            need = 3 - r
            if c < need:
                print(-1)
                continue
            c -= need
            ans += 1

        # pack remaining universals
        ans += (c + 2) // 3

        print(ans)

if __name__ == "__main__":
    solve()
```该代码首先将每个内向者分配到一个单独的帐篷，因为没有其他配置有效。 然后，它将外向的人分成三人一组。 任何剩余的外向者都会迫使建立一个额外的帐篷，但前提是存在足够的共性来完成该群体。 

表达式`(c + 2) // 3`是一种标准方法，用于计算需要多少个帐篷才能将剩余的通用物品最佳地打包成最多三个一组。 它隐式处理部分最终组，没有特殊情况。 

一个常见的错误是在解决外向余数之前尝试放置共相。 这破坏了可行性检查，因为通用性可能会在不需要的地方被消耗，从而无法完成所需的外向群体。

 ## 边缘情况

 一个关键的边缘情况是，外向的人在三人一组后留下一两个剩余的人。 例如，考虑`0 1 2`。 如果没有另外两个人，一个外向的人就无法形成一个有效的帐篷，所以这两个普遍性就足够了。 该算法检测到`r = 1`, 检查`c >= 2`，并完成一个帐篷。 

另一个边缘情况是，当共性很丰富但由于严格的内向要求而无关紧要时。 为了`3 0 10`，内向的人立即消耗掉三个帐篷，剩下的共性就简单地形成了`10`人们进入`4`帐篷 (3,3,3,1)，总计`3 + 4 = 7`。 

最后，当根本没有外向者时，问题就归结为将内向者和共性分开。 该算法仍然有效，因为外向分支没有任何贡献，并且通用性使用上限除法进行了最佳分组。
