 ## 解决方案
 ## 问题理解

 我们被要求构造一个长度为整数的序列`n`，其中每个元素位于`1`和`k`，并且序列必须是非递减的。 最重要的是，该问题提供了三种类型的附加约束。 第一种类型禁止在特定位置使用特定值。 第二种和第三种类型将总和不等式置于元素对上。 我们的任务是构造满足所有约束的任何序列或报告不存在序列。 

关键的观察是`k`非常小（最多 10 个），而`n`可以很大（最多 2×10^4）。 这表明枚举单个元素的可能性是可行的，但暴力破解所有序列将呈指数级爆炸。 类型 2 和类型 3 的约束涉及元素对，因此任何快速尝试每个序列的天真的尝试都会变得棘手。 还有一点是数组必须是非递减的。 这意味着一旦一个元素被限制为至少某个值，它后面的所有元素都会继承该下限。 类似地，早期索引的上限向前传播。 

当约束通过传播间接发生冲突时，会出现不明显的边缘情况。 例如，如果`a1 + a2 ≥ 5`和`a2 + a3 ≤ 4`，如果`k`很小。 另一个棘手的情况是类型 1 约束与单调性相结合：禁止一个索引处的值可能会迫使后面的值超过`k`因为序列不能递减。 

粗心的方法可能会尝试按顺序独立地满足每个约束。 例如，设置`a[i] = 1`当类型 2 或 3 约束涉及求和时，除非禁止将失败，因为这些约束连接远距离元素，而不仅仅是邻居。 一个具体的例子是`n = 3, k = 3`有限制`1 2 1`和`3 1 3 5`。 只需设置最小允许值即可`[1, 2, 3]`，如果解释不正确，就会违反总和约束。 

## 方法

 暴力解决方案将枚举所有长度的序列`n`之间有元素`1`和`k`。 对于每个序列，它将检查所有约束。 时间复杂度为`O(k^n * m)`，即使对于最小的非平凡的情况也是不可行的`n`。 正确性来自于详尽的检查：如果任何序列满足所有约束，就会找到它。 对于更大的情况会失败`n`因为`k^n`呈指数级增长。 

最佳解决方案的关键见解是`k`非常小，因此我们可以将每个位置的允许值表示为集合或位掩码。 每个类型 1 约束都会直接从该位置删除一个值。 当与单调性结合时，类型 2 和类型 3 约束可以表示为单个元素的边界。 对于类型 2，`a[i] + a[j] ≤ x`和`i < j`意味着`a[i] ≤ x - 1`最多如果`a[j]`至少为 1。类似地，类型 3 意味着下限。 由于数组是非递减的，因此下界为`i`向前传播并向后传播上限。 这允许约束传播方法：迭代更新范围直到它们稳定。 如果任何范围变空，则该序列是不可能的。 

我们可以总结一下这些方法：

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(k^n * m) | O(k^n * m) | O(n) | 太慢了|
 | 约束传播| O(n * k + m) | O(n) | 已接受 |

 ## 算法演练

 1.初始化两个数组`low`和`high`长度`n`，表示每个位置允许的最小值和最大值。 放`low[i] = 1`和`high[i] = k`。 
2. 立即应用类型 1 约束。 对于约束禁止`a[i] = x`，我们不存储所有禁止的值，而是在最终赋值期间通过跳过它来处理它，如果`x`等于`low[i]`并在界限内递增。 
3. 应用类型 2 约束。 对于约束`a[i] + a[j] ≤ x`和`i < j`，更新上限：`high[i] = min(high[i], x - 1)`和`high[j] = min(high[j], x - 1)`如果需要的话。 这确保了即使是最小值也不会违反总和。 
4. 应用类型 3 约束。 对于约束`a[i] + a[j] ≥ x`，更新下界：`low[i] = max(low[i], x - k)`和`low[j] = max(low[j], x - k)`，尊重最大可能值`k`。 
5. 通过向前传播下界来强制单调性：对于每个`i`从 1 到 n-1，设置`low[i+1] = max(low[i+1], low[i])`。 向后传播上限：for`i`从n-2到0，设置`high[i] = min(high[i], high[i+1])`。 
6.如果在任何位置`low[i] > high[i]`，不存在解； 输出-1。 
7. 构造最终数组。 对于每个位置，选择`a[i] = low[i]`。 如果该位置处的类型 1 约束禁止该值，则选择范围内的下一个值`[low[i], high[i]]`这是允许的。 如果不存在这样的值，则输出-1。 

## 为什么它有效

 保持的不变量是对于每个索引`i`, 区间`[low[i], high[i]]`包含可以出现在的所有值`i`不会立即违反任何类型 2、3 或单调性约束。 约束传播确保边界反映所有间接依赖关系。 最终作业来自`low[i]`向上保证顺序不降，同时遵守允许的间隔，并且类型 1 异常在本地处理。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        low = [1] * n
        high = [k] * n
        forb = [[] for _ in range(n)]
        constraints = []
        for _ in range(m):
            data = list(map(int, input().split()))
            if data[0] == 1:
                _, i, x = data
                forb[i - 1].append(x)
            else:
                constraints.append(data)
        for c in constraints:
            if c[0] == 2:
                _, i, j, x = c
                i -= 1
                j -= 1
                high[i] = min(high[i], x - 1)
                high[j] = min(high[j], x - 1)
            else:
                _, i, j, x = c
                i -= 1
                j -= 1
                low[i] = max(low[i], x - k)
                low[j] = max(low[j], x - k)
        for i in range(1, n):
            low[i] = max(low[i], low[i - 1])
        for i in range(n - 2, -1, -1):
            high[i] = min(high[i], high[i + 1])
        possible = True
        res = []
        for i in range(n):
            val = low[i]
            while val in forb[i] and val <= high[i]:
                val += 1
            if val > high[i]:
                possible = False
                break
            res.append(val)
        if possible:
            print(*res)
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```该代码首先读取测试用例的数量并初始化每个位置的下限和上限。 单独收集类型 1 约束来处理禁止值。 类型 2 和类型 3 约束直接更新边界。 单调性是在前向和后向传递中强制执行的。 最终的数组是通过在每个位置选择最低的可用值来构建的，跳过禁止的值。 如果某个位置没有有效值，`-1`被打印。
