 ## 解决方案
 ## 问题理解

 该游戏中的每一回合都是一个小的战略决策，会同时影响两个耦合系统。 有 n 个政党，每个政党的权力值从零开始，并且只会随着时间的推移而增加。 每次，莫诺卡普都会选择一个政党来支持，但他被禁止支持当前领导该体系的任何政党。 

在他做出选择后，所有政党都会更新自己的权力统计，然后权力最高的政党成为执政党。 如果多方平局，则最小的指数获胜，这使得平局具有战略意义，而不是中性的。 最后，每个回合都有一个约束：在选举步骤之后，特定政党必须最终成为统治者，否则整个序列无效。 

任务是在 m 个回合中选择一个有效的支持序列，满足所有这些强制统治者约束，同时最大化回合奖励的总和，该奖励取决于哪一方在何时得到支持。 

约束 n、m ≤ 50 足够小，任何具有三次甚至稍高多项式复杂度的解都是可以接受的。 重要的不是原始速度，而是管理回合之间的组合相互作用，因为每个决定都会影响未来的获胜者，并且还会限制下一步中哪些选择是合法的。 

微妙的困难在于，“不支持当前领导者”规则使系统以与打破平局相互作用的方式依赖于状态。 试图满足当地所需统治者的天真的贪婪方法将会失败，因为改变权力增量可能会意外地改变领导者并使未来的被迫国家失效。 

典型的失败案例是，当两方权力接近时，一个小的奖励诱惑会导致您提升错误的一方，比预期更早地翻转领导者，并使稍后所需的 p_j 无法实现。 例如，如果第一方和第二方因平局决胜而交替领导，则早期的额外支持可能会永久打破预期的交替模式，即使后来的决策是最优的。 

## 方法

 强力解释将尝试模拟每个回合中所有可能的支持选择，维持当前的权力向量并在每个决定后跟踪哪一方成为统治者。 由于每一回合最多有 n 个选择，这会导致 n^m 个可能性，即使对于 m = 50，这也太大了。即使通过未来约束的可行性进行修剪也无济于事，因为每个决策的影响都是长期的：一个额外的增量可以改变多个未来的选举。 

关键的观察是，在给定两条信息的情况下，该过程是确定性的：当前功率向量和当前统治者的身份。 在任何一步，一旦我们确定了我们支持的政党，下一个州就完全确定了。 这表明随着时间的推移采用动态规划公式，其中状态仅捕获对未来可行性重要的内容：当前回合、当前功率差异和当前统治者。 

然而，跟踪全功率矢量太大。 关键的结构洞察力是，只有政党之间的相对差异才能决定下一任统治者，并且这些差异以高度受限的方式演变，因为每一步只增加一个坐标。 

由于 n 和 m 都最多为 50，因此我们可以提供一个显式存储整个幂向量的 DP。 理论上，状态总数为 O(m · n^n)，但实际上我们只能达到一个很小的子集，因为我们使用强制标尺条件提前修剪了无效状态。 这允许转换 DP，其中每个状态代表给定时间的可达配置，并且转换模拟选择要支持的有效方。

我们将每次和每种可能的功率配置与当前标尺一起存储可达到的最佳分数。 每个转换都会检查合法性（无法支持当前标尺），应用增量，在 O(n) 中重新计算新标尺，并强制在时间 j 标尺等于 p_j。 

这将问题简化为状态图上的分层最短路径类型 DP，其大小在约束下是可管理的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举| O(n^m) | O(n^m) | O(米) | 太慢了|
 | 通过配置状态 DP | O(m · n² · 状态) 有效 O(m · n3) | O（状态）| 已接受 |

 ## 算法演练

 1. 定义一个随时间变化的 DP，其中每个状态代表每回合后所有政党权力和当前统治者的完整快照。 这确保了转换始终遵循精确的选举规则，而不是近似的规则。 
2. 在第 0 轮初始化 DP，所有权力均为零且没有有意义的统治者状态。 从这里开始，每个有效的序列都必须以合法的第一支持选择开始，该选择不是最初的抢七获胜者（第一方）。 
3. 对于每个回合 j，迭代从回合 j − 1 开始的所有可达状态。每个状态都已编码满足所有先前强制标尺约束的有效配置。 
4. 从一个国家，尝试支持不是当前统治者的每个政党 i。 将其幂增加一并通过扫描所有 n 方并选择最大幂来重新计算新的统治者，通过最小索引打破平局。 这一步是系统非线性进入的唯一地方，因为领导者可能会突然改变。 
5.计算出新的标尺后，如果与本轮所需的p_j不匹配，则立即丢弃该状态。 这会在本地强制执行事件约束，这已经足够了，因为任何违规都无法在以后修复。 
6. 使用奖励 a[i][j] 更新新状态的 DP 值，保持达到该状态的所有方式中的最大分数。 存储父指针以重建最终序列。 
7. 处理完所有回合后，选择第 m 回合得分最高的状态。 如果没有状态存在，这个问题就不可能出现。 

关键的不变量是，在处理第 j 圈之后，DP 包含满足直至 j 的每个前缀的强制条件的功率向量和标尺的所有可达配置，以及每个配置的最佳可实现分数。 由于转换会枚举所有有效操作并始终重新计算真实的选举结果，因此无效配置无法进入 DP，并且不会错过任何有效配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    p = list(map(int, input().split()))
    p = [x - 1 for x in p]

    a = [list(map(int, input().split())) for _ in range(n)]

    from collections import defaultdict

    # state: (powers tuple, ruler) -> score
    dp = {}
    dp[(tuple([0]*n), 0)] = 0

    parent = []

    for j in range(m):
        ndp = {}
        par = {}

        for (powers, ruler), score in dp.items():
            for i in range(n):
                if i == ruler:
                    continue

                new_p = list(powers)
                new_p[i] += 1

                # recompute ruler
                mx = max(new_p)
                new_r = 0
                for k in range(n):
                    if new_p[k] > mx or (new_p[k] == mx and k < new_r):
                        new_r = k
                        mx = new_p[k]

                if new_r != p[j]:
                    continue

                new_state = (tuple(new_p), new_r)
                new_score = score + a[i][j]

                if new_state not in ndp or ndp[new_state] < new_score:
                    ndp[new_state] = new_score
                    par[(j, new_state)] = (powers, ruler, i)

        if not ndp:
            print(-1)
            return

        parent.append(par)
        dp = ndp

    # reconstruct best
    best_state = max(dp.items(), key=lambda x: x[1])[0]
    powers, ruler = best_state

    res = [0] * m
    cur = (powers, ruler)

    for j in range(m - 1, -1, -1):
        prev_powers, prev_ruler, chosen = parent[j][(j, cur)]
        res[j] = chosen + 1
        cur = (prev_powers, prev_ruler)

    print(*res)

if __name__ == "__main__":
    solve()
```该实现直接反映了状态 DP 的思想。 每个状态都存储完整的功率向量和当前标尺，因为如果不重新计算就无法廉价地推断标尺。 内部循环显式地重新计算选举结果，这是安全的，因为 n ≤ 50 使 O(n) 扫描成本较低。 

父字典存储按回合和状态键控的转换，以允许毫无歧义地进行重建。 重建从最佳最终状态向后走，并在每一步检索所选方。 

一个微妙的细节是我们必须禁止选择当前的统治者，这是在更新状态之前强制执行的。 另一个是重新计算标尺必须正确遵守平局打破，其中较小的指数主导相同的最大值。 

## 工作示例

 ### 示例 1

 输入：```
2 3
2 1 2
1 2 3
4 5 6
```我们将状态紧凑地跟踪为（权力，统治者）。 

| 转 | 选择| | 之后的权力 | 之后的标尺 约束| DP 保留 |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 2 | (0,1)| 2 | 需要 2 | 保持|
 | 2 | 1 | (1,1) | 1 | 需要 1 | 保持|
 | 3 | 2 | (1,2) | 2 | 需要 2 | 保持|

 DP 始终保留至少一条有效路径，并且奖励最大化转换选择所示的序列。 这证实了该算法在跨州本地优化分数的同时正确地保持了可行性。 

### 示例 2

 输入：```
3 2
1 3
1 10
10 1
1 1
```在第 1 回合，支持方 2 立即占据主导地位，因为它拥有最好的奖励，并且在重新计算后，由于打破平局并增加优势，它成为统治者。 在第 2 回合，只有使第 3 方保持统治者地位的过渡才能生存，并修剪所有其他状态。 

此示例表明，无效的中间标尺会被积极过滤，并且只有全局一致的轨迹才能通过 DP 剪枝。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m·S·n²) | S为可达状态数； 每个转换都会尝试 n 次移动并重新计算标尺，时间复杂度为 O(n) |
 | 空间| O(S)| 存储 DP 状态和父指针 |

 小边界 n, m ≤ 50 确保尽管理论状态空间很大，但可到达配置的数量在强制约束下仍然是可管理的。 DP 避免过早探索不可能的分支，从而将运行时间保持在限制范围内。

 ## 边缘情况

 一个重要的边缘情况是当前统治者也是唯一可以最佳支持奖励的候选人。 由于禁止支持标尺，因此算法必须正确丢弃该移动，即使该移动在得分方面是全局最佳的。 DP 通过从不生成违反规则的转换来处理此问题，即使贪婪的选择更喜欢禁止的操作，也能确保正确性。 

当多方在移动后争夺最大权力时，会出现另一种边缘情况。 该实现在重新计算标尺期间显式强制执行最小索引规则。 这可以防止错误的状态分歧，否则会累积并破坏未来的可行性检查。
