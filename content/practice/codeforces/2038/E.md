 ## 解决方案
 ## 问题理解

 我们被要求通过向任何桶中添加粘土来最大化一系列连接桶中第一个桶中的水量。 每个桶都有一个水柱，相邻的桶通过给定高度的水平管道连接。 水可以在连接的桶之间自由流动，但是当粘土柱达到或超过管道高度时，管道就会被堵塞并阻止水流动。 粘土增加了底部的体积，并且不与水混合，因此它的行为就像一个固体塞子。 

输入给出每个桶的初始水量和管道高度。 输出应该是在添加任何粘土顺序后第一个桶中可达到的最大水量。 该问题保证初始配置处于平衡状态，这意味着水位与管道连接一致。 

约束表明最多 200,000 个桶，管道高度和体积最多 10^6。 这排除了任何每次增量添加粘土的强力模拟，因为这可能需要数十亿次操作。 我们需要一个与桶数成线性关系或最坏的 O(n log n) 的解决方案。 

当第一根管道的高度非常低时，会出现不明显的边缘情况。 例如，如果两个桶以高度开始`[1, 100]`它们之间的管道位于高处`2`，将粘土添加到第二个桶中会立即堵塞管道并防止水流回第一个桶中。 简单地添加粘土而不考虑管道高度的天真贪婪方法会高估第一桶中可达到的水量。 

## 方法

 蛮力方法会反复尝试将一单位粘土添加到某个桶中，通过模拟流经管道的流量重新计算所有桶中的平衡水位，然后重复，直到无法进一步改进为止。 这在原则上是正确的，但操作次数可能与所需的粘土总量成正比，对于 2×10^5 桶来说，最多为每桶 10^6，这显然是不可行的。 

更快解决方案的关键见解是，第一个桶只能收集最初由保持畅通的路径连接的桶中的水。 每根管道可视为最大允许水差：如果管道位于高处`h`，第一个桶不能容纳比`h`减去第一个桶中已有的粘土。 扩展这一点，我们可以从左到右传播“有效高度限制”。 第一个桶中可达到的最大水量受到初始水位中最小值的限制，该初始水位是根据沿每个桶的路径调整的管道高度而调整的。 

具体来说，我们从左到右遍历桶。 在每个桶中，如果我们要以最佳方式浇注粘土，我们会计算可以到达第一个桶的最大水量。 对于桶 1，这是无界的。 对于桶 2，管道高度减去桶 2 中的粘土给出了极限，依此类推。 第一个桶中的最终水量是同时满足所有管道约束的最大总量。 这可以在线性时间内完成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 总粘土) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 从数组开始`max_water`代表从左到右考虑桶时第一个桶中最终可以容纳的最大水量。 初始化`max_water[0]`第一个桶中装有初始水。 
2. 从第二个开始迭代桶。 桶用`i`，第一桶的水量受到管道高度的限制`h_{i-1}`以及前一桶可容纳的最大水量。 放`max_water[i]`到`min(max_water[i-1], h_{i-1}) + v[i]`。 这确保了不会破坏管道，并且我们会考虑已经存在的水。 
3. 前向传递后，最后一个值`max_water`表示考虑到所有桶后可以流向第一个桶的最大水量。 由于我们的目标只是第一个桶，因此答案是第一个桶中的水加上正确桶提供的任何额外水，但不超过管道限制。 
4. 为了考虑部分贡献，请注意，如果总水量超过管道高度，则平衡会按比例分配水。 因此，第一桶的水可以计算为累积约束下的最小值：对于桶的每个前缀，最多`i`，桶 1 中的最大高度是管道高度减去累积体积之差。 这可以通过使用最小值的前向累积来有效地完成。 

### 为什么它有效

 该算法之所以有效，是因为第一个桶中的最大水量是由从第一个桶到其他桶的任何路径上最严格的约束确定的。 每根管道都限制水的输送。 通过采用这些限制的最小值，我们保证不会超过任何管道，并且我们收集理论上可移动到第一个桶的所有水。 从左到右传播约束可以捕获每个管道和桶的累积效应，而无需模拟每次粘土添加。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
v = list(map(int, input().split()))
h = list(map(int, input().split()))

# Initialize the maximum water in first barrel with its own volume
max_water = v[0]

# Track the current effective height of water including contributions
current_height = v[0]

for i in range(n - 1):
    # The pipe limits how much water can move back
    current_height = min(current_height, h[i])
    # Water in the next barrel adds to the total
    current_height += v[i + 1]

# The final water in the first barrel
print(f"{current_height:.15f}")
```该解决方案首先读取桶的数量及其初始体积。 我们初始化第一桶水。 然后我们迭代管道。 在每一步中，我们都会通过管道高度来限制当前的累积水量，并添加下一桶的水。 最后高精度打印累计高度。 使用`min`确保管道不被破坏，这是关键属性。

2 4
```| 我| 当前高度 | 行动|

 | 0 | 1 | 桶 1 |

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    v = list(map(int, input().split()))
    h = list(map(int, input().split()))
    current_height = v[0]
    for i in range(n - 1):
        current_height = min(current_height, h[i])
        current_height += v[i + 1]
    return f"{current_height:.15f}"
