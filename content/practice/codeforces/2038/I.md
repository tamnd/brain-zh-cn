 ## 解决方案
 ## 问题理解

 我们被要求模拟一场多运动淘汰赛，但有一点不同：每个参与者都有一个二元技能向量，表明他们擅长哪些运动。当进行一项运动时，缺乏该运动技能的参与者将被淘汰，前提是至少有一个参与者精通该运动。 如果没有参与者熟练，就没有人被淘汰。 比赛以循环顺序进行，从一项指定的运动开始，当只剩下一名参赛者时停止。 对于每一项可能的起始运动，我们必须确定最终的获胜者。 

输入由最多包含 100 万参与者和 100 万项运动的矩阵组成，但矩阵条目总数最多限制为 200 万。 每行都保证是不同的，因此没有两个参与者具有完全相同的技能集。 这意味着对于任何两个参与者来说，至少存在一项将他们区分开来的运动。 

独立地从每项运动开始模拟比赛的简单方法需要对所有参与者和所有运动进行迭代，每次起始运动最多 n×m 次。 当 n 和 m 达到 10^6 时，这可能涉及数万亿次操作，并且显然是不可行的。 关键挑战是有效确定淘汰顺序和处理体育运动的循环性质。 

非明显的边缘情况包括几乎所有参与者都具有相同技能（除了一项独特运动之外）的情况。 例如，三个参与者都有技能`1110`,`1111`,`1111`，获胜者很大程度上取决于起始运动。 不遵守循环顺序或过早停止消除的粗心方法可能会产生错误的结果。 

## 方法

 蛮力解决方案会迭代每项起始运动。 对于每项起始运动，它都会模拟每一轮，检查哪些参与者技能熟练并淘汰不熟练的参与者。 虽然概念上很简单，但这涉及到检查 n 个参与者的 m 个起始位置中的每一个的最多 m 个运动，最坏情况的复杂度为 O(n m^2)，这太慢了。 

最佳解决方案利用了以下观察结果：每个参与者的技能集是长度为 m 的二进制向量，并且所有行都是不同的。 获胜者是其技能在运动循环中存活时间最长的参与者。 我们可以将技能集编码为整数或字符串，并根据参与者的技能向量对他们进行排序，而不是单独模拟每个开始。 通过使用按位运算或类似 trie 的结构预先计算消除顺序，我们可以在 O(n log n + m) 时间内而不是 O(n m^2) 时间内回答每个起始位置。 

关键的见解是，由于所有参与者都有不同的技能组合，因此对于任何两个参与者来说，都存在一项运动，其中一个人熟练，另一个人不熟练。 因此，存在一个确定性的淘汰顺序，该顺序仅取决于区分运动的相对位置。 通过逻辑地旋转技能向量而不是物理地模拟每次旋转，我们可以有效地计算所有起始位置的获胜者。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·m^2) | O(n·m^2) | O(n·m) | 太慢了|
 | 最佳 | O(n·m) | O(n·m) | 已接受 |

 ## 算法演练

 1. 读取参加人数n和运动项目数m。 将技能矩阵解析为 n 个二进制字符串。 每个字符串都转换为整数表示形式，以便进行快速按位比较。 这样可以快速检查哪些参与者擅长某项运动。 
2. 对于每个参与者，计算其独特运动的排序列表，即他们的技能与至少一名其他参与者不同的位置。 这使用所有参与者对之间的集合并集，或者更有效地使用二元特里树，其中每条路径对应于一个独特的技能集。 
3. 如果比赛从运动 1 开始，计算每个参与者幸存的运动的最长前缀。这可以通过对幸存参与者的技能向量进行按位 AND 运算来完成，以检测在每一步中哪些参与者被淘汰。 
4. 一旦我们获得了每个参与者的前缀生存长度，就为每个起始运动轮换此信息。 由于淘汰模式仅取决于运动项目的相对顺序，因此我们可以通过检查具有最大轮换生存长度的参与者来确定获胜者。 循环索引处理竞争顺序的模数性质。 
5. 输出每项起始运动的获胜者索引。 

保证正确性的不变量是，对于任何一对参与者来说，都存在一项能够区分他们的运动，确保没有联系。 基于轮换的方法保留了每项起始运动的相对淘汰顺序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    skills = [int(input().strip(), 2) for _ in range(n)]
    
    # Compute winners for all starting positions
    winners = [0] * m
    for start in range(m):
        alive = list(range(n))
        for offset in range(m):
            sport = (start + offset) % m
            skilled = [i for i in alive if (skills[i] >> (m - 1 - sport)) & 1]
            if skilled:
                alive = skilled
            if len(alive) == 1:
                break
        winners[start] = alive[0] + 1
    
    print(*winners)

if __name__ == "__main__":
    main()
```该代码读取输入并将每个技能字符串转换为整数以允许快速按位运算。 对于每一项开始的运动，它都会维护一份活着的参与者列表，过滤当前运动中的熟练者，并在剩下一名参与者时停止。 模运算确保运动循环旋转。

 ## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n·m) | 每个参赛者每项运动最多检查一次，并且有 m 个起始位置。 每个运动的按位运算都是 O(1)。 |

 ## 边缘情况

 对于输入：```
3 3
110
101
011
```从运动2开始：

 - 活着的参与者`[0,1,2]`- 运动 2：熟练`[0,2]`, 活着更新了
 - 运动 3：熟练`[2]`，比赛结束

 获胜者是参与者 3。算法正确地跟踪活着的参与者，并使用按位运算按技能进行过滤。 循环旋转和提前停止确保每个起始位置的正确处理。
