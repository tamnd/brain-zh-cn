 ## 解决方案
 ## 问题理解

 我们给出了目标表面积$C$，保证是两个不同素数的乘积。 除此之外，我们还得到了一份清单$M$可用边长，其中列表中的每个元素也是素数。 

任务是从这个列表中选择两个不同的素数，使得它们的乘积等于$C$。 由于池必须是矩形而不是正方形，因此我们不能两次选择相同的数字，并且所选的两个素数必须不同。 输出只是先较小的，然后是较大的。 

约束条件$C \le 10^{18}$意味着我们不能使用朴素的试除法来分解它$C$，但我们一般不需要完全分解，因为列表已经限制了候选者。 候选人人数$M \le 2 \cdot 10^5$表明对列表的线性或近线性扫描是可以接受的，但对列表的任何二次扫描都是不必要的，因为问题的结构允许直接验证补集。 

关键的微妙之处在于，这两个因素$C$保证出现在列表中，因此我们不需要搜索任意除数，只需搜索给定集合内的成员资格即可。 

一个天真的错误是尝试列表中的所有配对并检查他们的产品。 那需要$O(M^2)$操作，其中在$M = 2 \cdot 10^5$导致$4 \cdot 10^{10}$检查一下，是完全不可行的。 

另一个可能的失败是迭代素数并检查整除性$C \bmod P_i = 0$，然后尝试寻找$C / P_i$通过线性搜索。 如果没有散列，这会退化为$O(M^2)$再次。 正确的做法必须使成员资格检查的时间恒定。 

## 方法

 蛮力的想法很简单：尝试列表中的每一对素数，并检查它们的乘积是否等于$C$。 这是正确的，因为解决方案保证存在于列表中。 然而，它会检查所有$\binom{M}{2}$对，当$M$很大。 

我们可以通过改变视角来改善这一点。 我们可以固定一个数字，而不是选择两个数字并将它们相乘$p$并计算另一个必须是什么：$q = C / p$。 自从$C$保证是两个不同素数的乘积，如果$p$是其中之一，那么$q$也必须是列表中的素数。 

这将问题简化为成员资格测试问题：对于每个$p$，检查是否$C$可以整除$p$，如果是，检查是否$C/p$存在于列表中。 使用哈希集可以进行这两种操作$O(1)$平均而言，将完整的解决方案转变为线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力配对检查 |$O(M^2)$|$O(1)$| 太慢了 |
 | 哈希集补码检查 |$O(M)$|$O(M)$| 已接受 |

 ## 算法演练

 我们依赖这样一个事实：正确的一对恰好是$C$，并且两者都保证出现在输入列表中。 

1. 阅读$C$,$M$，以及素数列表。 我们将所有素数存储在哈希集中以进行恒定时间查找。 这使我们能够快速检查候选补集是否存在。 
2. 迭代每个素数$p$在列表中。 每个$p$是池的潜在边长。 
3. 检查是否$p$划分$C$。 如果不是，它就不能是正确对的一部分，因为两个有效因子必须精确相乘$C$。 
4. 如果$p$划分$C$, 计算$q = C / p$。 这是唯一可能的合作伙伴$p$在有效的解决方案中。 
5. 检查是否$q$存在于允许的素数集合中。 如果是这样，我们就找到了所需的两个边长。 
6. 按排序顺序输出该对，以便较小的值首先出现。 

### 为什么它有效

 正确性依赖于结构$C$。 自从$C$是两个不同素数的乘积，它恰好有两个素数。 任何有效的解决方案都必须准确使用这两个数字。 因此，任何$p$从划分的列表中$C$并产生一个补充因子$q$也出现在列表中的必须是两个正确答案之一。 哈希集确保我们检测到的成员资格没有歧义或重复，并且自动满足独特性条件，因为保证了因素是独特的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    C = int(input())
    M = int(input())
    arr = list(map(int, input().split()))
    
    s = set(arr)
    
    for p in arr:
        if C % p == 0:
            q = C // p
            if q in s and q != p:
                print(min(p, q), max(p, q))
                return

if __name__ == "__main__":
    solve()
```该解决方案首先将所有可用边长放入一个集合中，从而实现补集的恒定时间成员资格检查。 然后我们扫描每个候选人$p$。 可分性检查$C \bmod p = 0$尽早过滤掉不相关的素数，避免不必要的集合查找。 

当找到有效除数时，我们计算其补数并验证它是否存在于集合中。 条件$q \ne p$强制执行池不是正方形的要求，尽管问题保证了不同的素数，所以这主要是一个安全防护措施。 

一旦找到有效的对，我们立即打印并终止，因为分解的唯一性保证不存在第二个有效的解决方案。

 ## 边缘情况

 一个微妙的边缘情况是有效因子对以相反的顺序出现在输入列表中。 例如：

 输入：```
21
4
7 2 3 5
```在这里，算法仍然表现正确。 它首先检查 7，计算$21/7 = 3$，并在集合中找到它，因此输出$3 7$。 排序约束在输出时使用进行处理`min`和`max`，因此输入顺序并不重要。 

另一种情况是非因数素数整除$C$由于溢出问题，整数运算不正确。 在 Python 中，这种情况不会发生，但在固定宽度语言中，需要谨慎使用 64 位整数，因为$C$可以达到$10^{18}$。 

最后一种情况是输入列表包含两个因素，但一个出现较早，一个出现较晚。 根据扫描顺序，算法可能提前或延迟终止，但正确性不受影响，因为任何有效的遇到都会立即产生唯一的解决方案。
