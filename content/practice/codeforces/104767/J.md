 ## 问题理解

 我们被给予$N$标记点放置在圆上，每个可能的字符串都绘制为两个不同点之间的直线段，但只允许某些字符串集。 除共享端点外，字符串不得相交，因此绘制的图形相对于点的凸位置是平面的。 

每个钉子都恰好有两个事件串，除了两个特殊的钉子，每个钉子都只有一个事件串。 这迫使整个结构成为一条简单的路径，仅访问每个钉一次：内部顶点的度数为 2，两个端点的度数为 1，因此不可能有分支。 

任务是计算可以绘制多少个不同的此类非交叉完整路径$N$凸多边形上的标记点，其中如果两个图形使用完全相同的一组边，则它们被认为是相同的。 

约束条件$N \le 1000$排除任何显式枚举结构的尝试。 任何尝试探索边的选择或通过回溯增量构建图的解决方案都会发生组合爆炸。 可行的解决方案必须将问题简化为封闭形式，或者最坏的情况是$O(N)$或者$O(N \log N)$计算，因为模运算下$10^9+7$是必须的。 

朴素推理的一个微妙的失败案例是假设任何顶点排列都对应于有效的非交叉路径。 例如，与$N=4$，序列$1 \to 3 \to 2 \to 4$无效，因为边缘$(1,3)$和$(2,4)$叉。 约束是几何的，而不是纯粹的组合。 

另一个常见的错误是假设必须首先固定或独立选择端点。 实际上，端点的选择和内部结构是不可分割的； 单独计算它们就严重超出了计算范围。 

## 方法

 蛮力方法会尝试生成所有排列$N$顶点，将每个顶点解释为路径，并检查其边是否形成凸多边形上的非交叉集。 即使验证一种排列也需要检查$O(N)$边，并且有$N!$排列，导致$O(N! \cdot N)$，即使对于$N=20$。 

关键的结构观察是，任何有效的配置不仅仅是一条路径，而且是凸多边形上的非交叉哈密顿路径。 此类对象具有很强的递归分解功能：选取一条边将多边形划分为两个独立的子问题，因为非交叉边无法跨该划分进行连接。 

这导致了二元选择结构。 一旦边在路径中固定，每个剩余的顶点都必须以保持平面性的方式连接，并且在每一步中，构造都会沿着边界分成左右区域。 每个内部决策对应于选择顶点在演化路径中附着于哪一侧，并且这些选择变得独立。 

这种独立性将问题分解为内部顶点上的二进制赋值的纯粹计数，并结合循环起始位置的选择。 

由此产生的闭合形式变为$N \cdot 2^{N-3}$。

 ## 算法演练

 我们推导并计算公式$N \cdot 2^{N-3}$。 

1. 固定任意顶点作为循环上的参考点。 该结构在旋转下是对称的，因此没有顶点有特殊的几何约束。 
2. 观察任何有效配置都是单一哈密顿路径。 一旦隐式选择端点，其余顶点将被迫采用非交叉插入顺序。 
3. 将构造植根于路径的选定端点。 从该端点开始，路径重复延伸到未使用的顶点，同时保留非交叉约束。 在每一步中，未使用的顶点在边界上形成一个连续的区间。 
4. 每次路径延伸穿过内部顶点时，该顶点恰好有两个可用边，可以在其中连接其剩余未使用的邻居，对应于确定如何分割剩余间隔的二元决策。 
5. 正好有$N-3$这种独立的二元决策。 这是因为在固定端点后，剩余的$N-2$顶点贡献$N-3$不受几何形状影响的内部附着步骤。 
6. 每个二元选择都是独立的，产生一个因子$2^{N-3}$。 
7.最后，施工的起始位置可以锚定在任意位置。$N$顶点，贡献一个乘法因子$N$。 

最终的答案是：$$\text{ans} = N \cdot 2^{N-3} \bmod (10^9+7)$$### 为什么它有效

 非交叉条件迫使图的行为类似于凸多边形的递归二元分解。 每次将新的内部顶点合并到路径中时，它都会将剩余的未访问顶点分成两个不相交的边界区间。 这些间隔不再相互作用，因此该顶点的决策独立于所有先前的选择。 这创建了独立二元决策的乘积，它精确地解释了指数项，而循环的对称性则解释了线性因子。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modexp(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    n = int(input().strip())
    if n <= 2:
        print(1)
        return
    ans = n * modexp(2, n - 3) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```该实现是封闭形式的直接翻译。 快速求幂计算$2^{n-3}$在对数时间内。 乘以$n$取模$10^9+7$。 

极端情况出现在$N=2$，其中指数变为负数。 这对应于连接两个顶点的唯一单边，因此答案分别定义为 1。

 ## 边缘情况

 对于$N=2$，公式$N \cdot 2^{N-3}$需要$2^{-1}$，这在模运算中没有意义。 在这种情况下，唯一可能的配置是用一根绳子连接两个钉子，因此答案为 1。 

对于$N=3$，每个有效的配置都必须在一条路径中连接所有三个顶点。 公式给出$3 \cdot 2^0 = 3$，对应于端点的三种可能选择，每个端点产生唯一的非交叉路径。
