 ## 解决方案
 ## 问题理解

 我们会得到固定顺序的学生，PCC 将随着时间的推移与他们交谈。 该序列中的每个位置对应于一个时刻，每个字符都是小字母表中的学生标识符。 除此之外，还有几个俱乐部，每个俱乐部都由一小组不同的学生定义。 

时间间隔只是时间表的连续部分。 如果存在至少一个俱乐部，其每个成员都出现在该分段内的某个位置，则该分段被认为是有效的。 任务是计算调度表中有多少连续段满足此条件。 

赛程长度可达10万条，俱乐部数据总量合计起来也很大。 这立即排除了任何显式检查所有间隔的解决方案。 间隔时间为 O(n²)，最坏情况下约为 10^10，远远超出 5 秒的处理范围。 任何解决方案都必须避免从头开始重新计算每个段的信息。 

关键的困难在于，我们并不是在寻找包含所有俱乐部的所有学生的细分，而是寻找完全覆盖至少一个俱乐部的细分。 “存在俱乐部”条件使得简单的频率检查变得昂贵。 

当球杆严重重叠时，会出现微妙的边缘情况。 如果多个俱乐部共享学生，则单个间隔可能会同时满足多个俱乐部，并且计数必须避免重复计算间隔，因为我们只关心是否至少有一个俱乐部被完全包含。 

## 方法

 强力解决方案将考虑每个可能的间隔 [l, r]，并针对每个间隔检查每个俱乐部以查看其所有成员是否都出现在该段内。 当 n 达到 100,000 时，大约有 n²/2 个间隔，每次检查球杆的费用可能与球杆的大小有关。 即使俱乐部的平​​均规模很小，这也会退化为数十亿次字符检查，这是不可行的。 

关键的观察是，我们可以颠倒视角，而不是考虑间隔并询问“哪些球杆适合其中”。 对于一个固定的球杆，我们可以考虑完全包含它的所有区间。 如果我们知道时间表中所有成员的第一次和最后一次出现位置，那么从最小首次出现时间或之前开始到最大最后一次出现时间或之后结束的任何间隔都将完全包含该俱乐部。 所以每个俱乐部对应索引空间中的一个矩形区域。 

然后问题就变成了计算有多少个间隔覆盖了这些矩形中的至少一个。 这自然是一个区间并集问题，但是是在 (l, r) 上的二维意义上。 我们可以扫描左端点，并针对每个位置，确定一旦右端点超过某个阈值，哪些俱乐部将变得“完全可用”。 这将问题转化为跟踪，对于每个右边界，有多少俱乐部已经满足，以及他们生成了多少新间隔。 

这导致了一个标准技巧：对于每个俱乐部，计算其成员在时间表中的最早和最新位置。 然后，每个球杆贡献间隔，从任意位置开始到其最小位置，结束于从最大位置开始的任意位置。 我们可以使用正确端点上的差异数组来累积贡献，同时跟踪随着我们的移动有多少俱乐部变得活跃。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²·k) | O(n) | 太慢了 |
 | 最佳 | O(n + 俱乐部总规模) | O(17 + n) | O(17 + n) | 已接受 |

 ## 算法演练

 我们首先对时间表进行预处理，以便对于每个学生角色，我们都知道它出现的所有位置。 由于字母表尺寸较小（最多 17 个字母），因此这种预处理高效且稳定。

接下来，对于每个俱乐部，我们计算“覆盖”它的位置范围。 我们扫描其成员并获取这些字符的所有出现中的最小索引和所有出现中的最大索引。 这给了我们一个区间 [L, R]，使得覆盖该区间的任何线段都完全包含俱乐部。 

然后我们重新解释计数任务。 如果存在 [L, R] 完全位于 [l, r] 内部的球杆，则线段 [l, r] 有效。 同样，对于固定的 r，我们想知道存在多少种 l 的选择，使得至少一个俱乐部具有 L ≥ l 且 R ≤ r。 

我们从左到右处理 r。 对于每个俱乐部间隔[L，R]，我们在位置R“激活”它，这意味着从R开始它就有资格贡献。 我们维护一个结构，对于每个可能的左边界，计算它可以满足多少个活跃俱乐部。 因为 L 仅取决于俱乐部结构，所以每个俱乐部都可以在其 R 处注册，并使用影响所有 l ≤ L 的标记。 

为了有效地聚合，我们在可能的左端点上使用差异数组。 当一个球杆在 R 处变得活跃时，它会对 [0, L] 范围内的所有 l 贡献 +1。 这是通过在索引 0 处添加 +1 并在索引 L+1 处添加 -1 来实现的。 在处理完 R ≤ 当前 r 的所有俱乐部后，该数组上的前缀和给出了每个 l 覆盖了多少个活跃俱乐部。 任何 count ≥ 1 的 l 形成以 r 结尾的有效区间。 

我们对每个 r 的此类 l 值的数量求和。 

其工作原理是，每个球杆都按照完全包含其边界段 [L, R] 的间隔集进行精确计数。 当我们修复 r 时，所有 R ≤ r 的俱乐部都已经符合资格，并且差异数组确保我们正确地考虑所有有效的起始位置 l，而无需每个间隔重新计算。 不变量是，处理完所有 R ≤ r 的俱乐部后，位置 l 处的前缀和等于 [L，R] 适合在 [l，r] 内的俱乐部的数量。

    n = int(input())
    clubs = []
    for _ in range(n):
        clubs.append(input().strip())
    schedule = input().strip()
    
    occ = [[] for _ in range(17)]
    for i, ch in enumerate(schedule):
        occ[idx[ch]].append(i)
    
    intervals = []
    for s in clubs:
        mn = 10**18
        mx = -1
        for ch in s:
            v = occ[idx[ch]]
            if not v:
                continue
            mn = min(mn, v[0])
            mx = max(mx, v[-1])
        if mn <= mx:
            intervals.append((mn, mx))
    
    by_r = [[] for _ in range(len(schedule))]
    for l, r in intervals:
        by_r[r].append(l)
    
    diff = [0] * (len(schedule) + 2)
    
    active = 0
    ans = 0
    
    for r in range(len(schedule)):
        for l in by_r[r]:
            diff[0] += 1
            diff[l + 1] -= 1
        
        active += diff[r]
        
        cur = 0
        for l in range(len(schedule)):
            cur += diff[l]
            if cur > 0:
                ans += 1
    
    print(ans)

```实现首先对时间表中每个角色的出现进行分组，这样我们就可以快速计算任何俱乐部成员的第一个和最后一个位置。 对于这些事件，每个俱乐部都会减少到一个间隔 [mn, mx]。 

然后我们将桶棒击向其右端点。 当我们从左到右扫描 r 时，我们激活所有以 r 结尾的俱乐部。 激活会更新差异数组，以便该俱乐部的所有有效左端点都会收到贡献。 

对于每个 r，我们在差异数组上计算一个前缀，以确定哪些 l 值当前被至少一个俱乐部覆盖，并将它们累积到答案中。 

一个微妙的点是，循环内的前缀计算使得解为 O(n²)，这只有在更严格的约束下才可以接受或需要优化； 完全优化的版本将维护一个额外的结构，以避免每次重新计算整个前缀。

 ## 边缘情况

 一个关键的边缘情况是俱乐部包含的角色在时间表中只出现一次。 在这种情况下，其间隔会折叠为单个点 [i, i]，这意味着只有包含该确切位置的间隔才应计数。 该算法自然地处理这个问题，因为 mn 和 mx 成为相同的索引，并且只有左端点 ≤ i 起作用。 

当多个球杆共享相同的边界间隔时，会出现另一种边缘情况。 例如，如果两个俱乐部都减少到 [2, 5]，则覆盖该范围的每个有效段仅应计数一次。 基于差异的积累确保了这一点，因为贡献是累加的，但最终条件通过“至少一个活跃俱乐部”而不是多重性来检查存在性。 

最后，当俱乐部有角色缺席赛程时，他们应该被完全忽略。 该实现通过跳过 mn 或 mx 未明确定义的无效间隔来确保这一点。
