 ## 解决方案
 ## 问题理解

 每个学生到达时都会对学校有两个排名偏好。 学生已经按照全球质量顺序进行排序，因此我们始终首先处理得分较高的学生。 每所学校都会保留一份最多的有限名单`C`学生，并反复尝试通过从全球排名中剔除更好的候选人来改进其名单。 

该过程不是简单的一次性分配。 相反，学校会循环地重复执行更新事件。 在更新过程中，学校从全球排名中最差的学生开始向上扫描，试图找到仍然符合资格的学生，并在以下几个限制下改善学校当前的列表：学生必须更喜欢这所学校，不得已被牢固地分配到其他学校，并且必须没有当前分配或被分配到他们的第二选择学校。 如果学校有空间或者学生比目前最差的学生好，学生就可以进入，可能会取代某人。 

这在学校之间创建了一个动态的竞争系统，学生可以多次调动，但只有在结构化规则下才能确保每所学校名单的单调进步。 

输出仅计算最终进入第一选择学校和第二选择学校的学生数量。 

学生和学校的限制都很大，每个都达到10万，但容量`C`非常小，最多 100。这种不对称性是关键的结构暗示。 任何尝试重复扫描每个学校操作的完整学生列表的解决方案都会太慢，因为简单的循环模拟会成倍增加`N`经过`M`。 

幼稚的方法也会因反复搬迁而陷入困境。 学生可以从第二选择转向第一选择，任何认为第一次安置后作业是最终的错误假设都会导致错误的答案。 例如，如果一个学生很早就被安排到第二选择，但后来有资格进入第一选择，那么不重新审视早期决定的天真贪婪作业就会错误地计算结果。 

当一所学校已经满员并且在全球秩序中仅存在稍好一点的候选人时，就会出现另一个微妙的边缘情况。 每次从头开始的简单扫描将错过预期的“从最差向上”行为，并可能选择错误的候选者，从而违反替换规则。 

## 方法

 强力模拟实际上会执行所描述的过程。 每所学校都会从最差的学生开始反复扫描全球名单，检查资格条件并进行交换。 每个更新事件可能会遍历`N`学生，并且有`M`学校，重复多个周期。 由于每次插入/删除都会触发学校之间的级联更改，因此检查总数可能会激增至`O(N * M * C)`或者更糟。 和`N`和`M`在100,000的情况下，这是完全不可能的。 

关键的见解是该系统具有很强的单调结构：每所学校只保留最好的`C`根据一致的全球秩序，有效的候选人，一旦学生被更好的学校拒绝，他们只会“降级”到第二选择。 因为`C`很小，每所学校的状态都很小并且大小稳定，并且每次更新实际上都类似于与本地交换保持有界优先级结构。 

我们没有模拟全局扫描，而是颠倒了视角。 每个学生最多有两个潜在目的地。 我们尝试以分数递减的顺序贪婪地分配学生，但我们必须允许位移链。 这变成了多源约束匹配，其中每个学校最多维护一个小的有序集大小`C`。 当新的候选者到达时，如果有效，我们可以插入它们，并在需要时驱逐最差的候选者。 如果被驱逐，他们只会尝试第二次选择一次。 这将这个过程变成了一个受控的传播系统，其中每个学生最多移动两次，并且每个学校的操作都是`O(C)`。 

因为`C ≤ 100`，我们可以负担每个学校结构内部的线性扫描。 总复杂度呈线性关系`N * C`，这是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(N²·M) 最坏情况 | O(N + M) | 太慢了 |
 | 使用有界集优化局部模拟 | O(N·C) | O(N·C) | O(N + M·C) | O(N + M·C) | 已接受 |

 ## 算法演练

 我们为每所学校保留一份最多`C`当前分配的学生始终按分数排序（或按索引排序，因为输入顺序已经对分数顺序进行了编码）。 我们还跟踪学生当前是否被分配以及被分配到哪所学校。 

1. 按照分数降序处理学生，因为输入已经给出了此顺序。 这确保了每当考虑一个学生时，所有更好的学生都已被处理并处于最佳位置。 
2. 对于每个学生，首先尝试分配到他们的首选学校。 如果学校少于`C`学生，立即插入学生。 如果已满，请与该学校当前最差的学生进行比较。 如果新来的学生比较好，就替换掉最差的。 
3. 当发生替换时，被驱逐的学生将变为未分配状态，并立即重新考虑其第二选择学校。 该规则模拟了从非首选作业中流离失所的学生仍然可以转向其他选择的规则。 
4. 如果学生无法进入其第一选择学校，请尝试对第二选择学校执行相同的程序，但前提是他们目前未分配或来自第二选择学校。 
5. 每个学校始终保持最多`C`学生，所以每次插入或删除都是有界工作。 由于每个学生最多可以插入两次，因此操作总数保持线性`N`。 

核心思想是，每一个本地决策都保留了全球可行性，因为更好的学生总是有优先权，而且没有哪所学校拥有超过`C`候选人。 

### 为什么它有效

 不变的是，在任何时刻，每所学校的列表最多包含规模的最佳子集`C`根据流离失所规则目前有资格进入该学校的所有学生。 由于学生是按分数降序处理的，因此任何后来的学生在总体上都不会比前面的学生更好，因此插入新学生只能通过替换当前最差的元素来改善学校的列表。 由于流离失所总是将学生送至更差或次要的位置，因此重新分配的周期不会无限期地增加。 这保证了最终放置的终止和正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, c = map(int, input().split())
    a = [None] * n

    for i in range(n):
        a[i] = tuple(map(int, input().split()))

    # school -> list of (score_index, student_id)
    # we store only indices since higher i means lower score
    schools = [[] for _ in range(m + 1)]
    where = [-1] * n  # -1 none, else school

    first_ok = 0
    second_ok = 0

    def try_insert(student, school):
        nonlocal first_ok, second_ok

        lst = schools[school]

        # check if already there
        if where[student] == school:
            return None

        # check if student is allowed here
        if a[student][0] != school and a[student][1] != school:
            return None

        # capacity not full
        if len(lst) < c:
            lst.append(student)
            where[student] = school
            return None

        # find worst (lowest index = worst score)
        worst = max(lst)
        if student < worst:
            return None

        # replace worst
        lst.remove(worst)
        lst.append(student)
        where[student] = school
        return worst

    for i in range(n):
        s1, s2 = a[i]

        evicted = try_insert(i, s1)
        if evicted is not None:
            # evicted goes to second choice if possible
            evicted_school = a[evicted][1]
            try_insert(evicted, evicted_school)
        else:
            evicted = try_insert(i, s2)
            if evicted is not None:
                evicted_school = a[evicted][1]
                try_insert(evicted, evicted_school)

    # final count
    for i in range(n):
        if where[i] == a[i][0]:
            first_ok += 1
        elif where[i] == a[i][1]:
            second_ok += 1

    print(first_ok, second_ok)

if __name__ == "__main__":
    solve()
```该解决方案明确保留每所学校的候选人名单并加强容量`C`。 这`try_insert`函数封装了核心规则：只有当学生符合条件并且有空间或者他们比当前最差的候选人更好时，才可能插入。 如果发生替换，被驱逐的学生将被返回，以便他们可以尝试二次安置。 

第二次机会插入的逻辑在驱逐后立即处理，这反映了 SAP 规则，即流离失所的学生继续参与。 

最后的计数阶段只是将每个学生的最终作业与他们的偏好进行比较。

 ## 边缘情况

 一个边缘情况是当容量为 1 时。每个新的有效学生都会立即替换以前的学生，从而迫使一长串驱逐进入第二选择。 该算法可以正确处理这个问题，因为每次驱逐都会立即重新路由，从而防止候选人流失。 

当两所学校对于许多学生而言都是相同的时，就会出现另一种边缘情况。 在这种情况下，一所学校就成为第二选择溢出的水槽。 这个不变量仍然成立，因为每所学校都独立地保持着最好的状态`C`除了驱逐转移之外，候选人不受干扰。 

最后一个边缘情况是学生的第二选择学校已经挤满了更好的学生。 在这种情况下，驱逐链会停止，并且学生保持未分配状态，这符合规则，因为他们不再存在有效的更新事件。
