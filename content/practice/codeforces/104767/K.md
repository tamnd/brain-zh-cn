 ## 解决方案
 ## 问题理解

 我们正在离散的几何环境中工作。 想象一个以原点为中心的球体$D$维整数格。 每个格点与原点的欧几里德距离最多为$R$被认为是球体的“内部或表面”。 

对于每个这样的整数点$(x_1, x_2, \dots, x_D)$，我们将其贡献计算为其坐标的绝对值之和，即$|x_1| + |x_2| + \cdots + |x_D|$。 任务是将球体内所有格点的贡献相加。 

输出是总和模$10^9 + 7$。 

输入限制从外观上看很小，$D, R \le 50$，但是几何对象组合起来是巨大的。 即使对于像这样的适度值$D = 10, R = 20$，球中整数点的数量是天文数字。 这立即排除了任何直接枚举点的可能性。 

天真的尝试会迭代超立方体中的所有整数向量$[-R, R]^D$，检查每个是否位于球体内部，并累积贡献。 这已经产生了$(2R+1)^D$候选人，在最坏的情况下是$101^{50}$，完全不可行。 

一个更微妙的陷阱来自对称性的滥用。 人们可能会尝试只计算正数中的点并乘以$2^D$，但是对于零坐标的点则失败，因为符号翻转不会产生不同的点。 任何不仔细考虑坐标对称性的解决方案都会多算或少算贡献。 

## 方法

 核心困难在于我们要对球形约束上的可分离函数求和$\ell_2$-norm，而函数本身是$\ell_1$-喜欢。 该结构在每个坐标中都是对称的，并且在符号变化下不变，因此第一个简化是仅使用非负坐标，然后正确相乘。 

暴力方法枚举球中的所有整数点并直接将它们的坐标贡献相加。 这在概念上是简单且正确的，因为它遵循字面定义。 然而，它的成本随着网格点的数量而增加。$D$-ball，其行为呈指数增长$D$。 即使限制为超立方体，状态空间也变为$(2R+1)^D$，这远远超出了计算极限。 

关键的结构观察是，我们可以将问题重新解释为逐维求和坐标贡献，而不是对点求和。 一旦我们计算出有多少个有效点在该坐标中具有给定的绝对值，每个坐标就会独立贡献。 这将问题从枚举完整向量减少到计算有多少部分向量存在于具有有限剩余半径的较低维度中。 

这自然会导致尺寸和平方半径上的动态规划公式。 我们定义状态来跟踪构建部分向量的方式以及总计的方式$\ell_1$贡献已经积累。 该转换是一次附加一个坐标，迭代该坐标的所有可能的整数值并更新配置计数和贡献增量。 

球体约束变成了坐标平方和上的类似背包的条件，而目标则线性累加绝对值。 因为$D, R \le 50$，尺寸和半径平方上的 DP$R^2$是可行的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对所有格点进行暴力破解 |$O((2R+1)^D)$|$O(D)$| 太慢了 |
 | DP 与尺寸和平方半径的关系 |$O(D \cdot R^3)$|$O(D \cdot R^2)$| 已接受 |

 的立方因数$R$来自迭代所有坐标值并分布平方半径过渡。 

## 算法演练

 我们使用半径平方$S = R^2$。 让$dp[d][s]$第一个表示两个量$d$维度：精确选取具有总平方范数的整数坐标的方法数量$s$，以及所有此类配置的绝对值总和。 

我们一起维护计数和捐款金额。 

1. 初始化零维度的 DP。 恰好有一个具有平方范数的空向量$0$和贡献$0$。 这给出了$dp[0][0] = (1, 0)$。 
2.一一加工尺寸。 在每个维度$i$，我们通过选择一个值来扩展所有先前的状态$x \in [-R, R]$。 平方范数增加$x^2$，贡献增加$|x|$乘以现有配置的数量。 
3. 对于每个先前状态的平方和$s$，我们迭代所有可能的$x$。 如果$s + x^2 \le R^2$，我们更新新的状态。 配置数量成倍增加，贡献同时累加之前的贡献副本和新增的贡献副本$|x|$成本乘以配置数量。 
4.处理完所有维度后，我们将所有状态最多以平方范数求和$R^2$，收集总贡献。 

为什么转换是正确的源于坐标的独立性。 每个扩展步骤将先前的部分向量视为固定的，并枚举新维度中的所有有效扩展，通过平方半径加法精确保留球体约束。 

### 为什么它有效

 球体内的每个晶格点都是通过一次选择一个坐标来唯一构造的。 DP 按其平方范数对点进行分组，并聚合相同的子问题。 由于每个坐标选择都是独立的，并且仅通过加法平方约束相互作用，因此状态完全捕获了所有必要的信息。 贡献累积在坐标上是线性的，因此将其分布在扩展上可以保持正确性，而无需重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    D, R = map(int, input().split())
    S = R * R

    # dp[s] = (count, sum_abs)
    dp = [(0, 0)] * (S + 1)
    dp[0] = (1, 0)

    for _ in range(D):
        ndp = [(0, 0) for _ in range(S + 1)]
        for s in range(S + 1):
            cnt, sm = dp[s]
            if cnt == 0:
                continue
            for x in range(-R, R + 1):
                ns = s + x * x
                if ns > S:
                    continue
                ncnt, nsm = ndp[ns]
                nc = cnt
                # update count
                ncnt = (ncnt + nc) % MOD
                # update sum: previous sums replicated + added abs(x) for each vector
                nsm = (nsm + sm + cnt * abs(x)) % MOD
                ndp[ns] = (ncnt, nsm)
        dp = ndp

    ans = 0
    for cnt, sm in dp:
        ans = (ans + sm) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```该实现在平方半径上维护一个 DP 阵列。 对于每个维度，它通过尝试所有坐标值来构建一个新的 DP 层。 关键的微妙之处在于，先前维度的贡献保持不变，而每个新坐标都会增加$|x|$对于先前状态中计数的每个配置一次。 

每次更新时都会应用模数以防止溢出，因为即使对于中等程度的情况，计数也会呈指数增长$D$。

 ## 边缘情况

 堕落的案例$R = 0$只留下原点。 DP 使用贡献为零的单个空向量进行初始化，并且没有任何转换添加新状态，因为所有$x \neq 0$均无效。 最终答案仍然为零，这与唯一的点没有任何贡献的事实相匹配。 

为了$D = 1$，DP 折叠成一个简单的整数枚举$[-R, R]$。 每个状态直接对应于单个坐标值，并且平方半径尺寸变得无关紧要。 该算法正确地简化为对对称区间上的绝对值求和，这与预期的算术结构相匹配，而没有任何重复计算。
