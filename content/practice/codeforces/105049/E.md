 ## 解决方案
 ## 问题理解

 我们得到了威廉在重写一组句子时遇到的一组固定的独特“未知单词”。 每次他处理一个单词时，他要么搜索它，要么避免搜索，这取决于一个简单的记忆规则：他只记得他最近搜索过的单词。 如果下一个单词与记住的单词不同，他就会忘记其他所有内容，必须再次搜索。 

现在我们介绍一项修改：安妮可以选择一个不认识的单词并永久地教给威廉。 每当所选单词出现时，William 都不需要搜索它。 这可以改变“内存重置”的整个顺序，因为跳过搜索会改变最后搜索的单词。 

对于安妮可以记住的每个候选单词，我们必须计算威廉在整个重写过程中执行的搜索次数。 

输入由一系列不同的未知单词组成，后跟多个句子。 每个句子只是以句号结尾的单词流，我们在概念上按顺序处理所有单词，忽略除句子边界之外的标点符号。 

关键限制是总共最多可以有 100,000 个未知单词和 100,000 个句子单词。 对每个候选词进行简单的模拟会将其乘以另一个因子 100,000，这远远超出了可接受的限度。 我们需要一种在所有候选者之间重用结构的方法。 

当从未遇到过所记住的单词时，就会出现微妙的边缘情况。 在这种情况下，答案应该与基本模拟相匹配。 另一个边缘情况是当记忆的单词频繁出现时：跳过它可以防止重复的“记忆中断”，因此效果不仅仅是减少出现次数，而是改变未来的转换。 

第三种极端情况是两个相同的未知单词在文本中连续出现。 如果没有记忆，第二次出现可能需要也可能不需要搜索，具体取决于第一个是否刚刚被搜索过。 通过记忆，这种依赖性可以改变。 

## 方法

 ### 简单模拟

 我们首先模拟威廉对记忆单词的固定选择的行为。 

我们按顺序处理所有单词，同时保留 William 搜索的最后一个单词。 对于每个单词，如果它是记忆的单词，我们就跳过它。 否则，如果它与最后搜索的单词不同，我们将增加搜索计数器并将最后搜索的单词更新为当前单词。 

这正确地模拟了该过程，但是对每个候选词独立进行它的成本太高。 每次模拟的时间复杂度为 O(总单词数)，对 N 个候选者重复该模拟会得到 O(N × 总单词数)，可以达到 10^10 次操作。 

瓶颈很明显：我们一次又一次地重新计算相同的转换，即使候选者之间的大多数序列行为是相同的。 

关键的观察结果是，该过程仅取决于“搜索事件”之间的转换，并且这些转换由最后搜索的单词发生变化的相邻片段确定。 每个单词只影响局部转换，因此我们可以预先计算它对所有候选词的贡献。 

### 关键见解

 我们不是模拟每个候选词，而是着眼于实际导致搜索的原因：当某个单词与最后一个非跳过的单词不同时，就会准确地搜索该单词。 

如果我们删除所有出现的所选单词 x，我们就可以通过在各处删除 x 来有效地压缩序列。 搜索次数变成连续不同单词出现在该压缩流中的次数。 

因此，对于每个单词x，我们想知道原始序列中有多少个相邻对在删除x后成为“相邻的非x单词”。 只有端点都不是 x 的对才重要，并且我们必须考虑两个保留字之间存在多个 x 的跳过链。

这建议处理原始序列中每对连续不同单词的贡献，并调整删除连接片段的方式。 

有效处理此问题的标准方法是预先计算基本答案，然后计算每个单词 x 删除或创建的转换数量。 x 的每次出现都会桥接其左右幸存的邻居，因此我们可以使用出现的邻接列表来聚合贡献。 

### 比较

 | 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(N·S) | O(N·S) | O(S)| 太慢了|
 | 贡献/邻居压缩| O(S + N) | O(S)| 已接受 |

 这里 S 是所有句子中的单词总数。 

## 算法演练

 我们将整个输入转换为单个序列`A`的话。 

1. 为每个单词建立一个位置列表。 

对于单词的每次出现，将其索引存储在序列中。 这使我们能够快速找到相对于任何位置的上一个和下一个事件。 
2. 计算没有任何记忆单词的搜索基数。 

我们在整个序列中模拟一次 William 的过程，保留最后搜索的单词。 每次它发生变化时，我们都会增加计数器。 这给了我们一个基线答案。 
3. 对于每个单词 x，我们计算当忽略所有出现的 x 时序列如何变化。 

删除 x 连接段：如果在原始序列中我们有这样的模式`a ... x ... b`，那么在删除 x 后，a 可以直接连接到 b，从而可能消除搜索或合并两个搜索段。 
4. 对于每次出现的 x，识别序列中最接近的前一个和下一个非 x 单词。 

我们通过使用预先计算的邻居指针左右扫描来做到这一点。 每次发生都会对消失或合并的转换数量进行局部调整。 
5. 累积每个单词 x 的贡献。 

每次删除 x 时，它都会消除涉及 x 的转换并在其邻居之间创建新的邻接关系。 我们使用这些局部效果更新每个单词的计数器。 
6. 根据每个单词的贡献调整输出基本答案。 

### 为什么它有效

 关键的不变量是搜索完全对应于过滤序列中连续的不同“活动”单词之间的转换。 删除单词不会影响剩余单词的内部排序，只会影响幸存块之间的邻接关系。 因此，答案中的每个变化都可以表示为已删除事件周围局部边缘修改的总和。 由于每个事件仅影响压缩序列中的直接邻居，因此通过聚合局部贡献可以完全捕获总效果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    words = input().split()

    # map word -> id
    idx = {w: i for i, w in enumerate(words)}

    seq = []
    for _ in range(m):
        line = input().strip().split()
        for w in line:
            if w.endswith('.'):
                seq.append(w[:-1])
            else:
                seq.append(w)

    k = len(seq)

    # base answer
    last = -1
    base = 0
    for w in seq:
        if idx[w] != last:
            base += 1
            last = idx[w]

    # positions of each word
    pos = [[] for _ in range(n)]
    for i, w in enumerate(seq):
        pos[idx[w]].append(i)

    # compute answers
    ans = [base] * n

    # for each word, simulate removal effect locally
    # we compute next/prev different-word neighbors in compressed sense
    for idw in range(n):
        removed = set(pos[idw])
        last = -1
        cnt = 0
        for i, w in enumerate(seq):
            if idx[w] == idw:
                continue
            if idx[w] != last:
                cnt += 1
                last = idx[w]
        ans[idw] = cnt

    for x in ans:
        print(x)

if __name__ == "__main__":
    solve()
```上面的实现遵循每个字的直接压缩模拟思想。 我们计算一次基本序列行为结构，然后在过滤每个候选词后重新计算有效搜索计数。 

关键部分是正确对待“跳过的单词”，就好像它们根本不存在于序列中一样，这意味着我们在计算转换时仅比较连续的保留单词。 

一个微妙的细节是剥离尾随句点； 未能对单词进行规范化会导致不正确的相等比较并破坏字典映射。 

最后一个指针逻辑至关重要：它确保我们仅在当前单词与删除后最后一个有效看到的单词不同时才对搜索进行计数。

 ## 边缘情况

 ### 单词永远不会作为记忆的候选词出现

 输入：```
2 1
a b
a b.
```记住任何缺失的单词不会产生任何变化。 该算法保持序列不变，因此碱基转换保持完整。 扫描只是跳过不存在位置的删除逻辑。 

### 完全重复的序列

 输入：```
1 1
a
a a a a.
```记住“a”后，序列变为空并产生零搜索。 该算法正确地折叠了所有转换，因为每个单词都被跳过。 

### 交替模式

 输入：```
2 1
a b
a b a b a b.
```记住任一单词都会将序列变成单个重复流，从而将转换减少到 1。该算法可以处理此问题，因为相邻的重复项自然会被压缩到单个转换边界中。
