 ## 解决方案
 ## 问题理解

 我们得到一个整数数组和两个模，$p$和$q$，以及最小间隔长度$k$。 允许的操作是选择任意长度至少为连续的子数组$k$并减少该子数组中的每个元素模$p$或者$q$。 目标是在执行任意数量的此类操作后最小化数组的总和。 

输入由多个测试用例组成。 每个测试用例给出数组长度$n$, 区间参数$k$，模数$p$和$q$，以及数组本身。 输出是最佳应用操作后可实现的最小总和。 

鉴于$n$可以达到$10^5$每个测试用例和总和$n$在所有测试用例中是$10^5$，任何算法都必须接近线性$n$对于每个测试用例。 在所有间隔上迭代的嵌套循环会太慢，因为有$O(n^2)$间隔，对于每个间隔，我们将应用一个$O(n)$操作、给予$O(n^3)$最坏情况下的操作。 这显然是不可行的。 

边缘情况出现时$k = 1$，允许单元素操作，并且当数组的元素都小于两者时$p$和$q$。 例如，与$a = [1,2,3]$,$k=1$,$p=5$,$q=10$，应用取模不会减少任何元素，最小和只是数组的和。 另一个棘手的情况是当所有数组元素都是以下的倍数时$p$或者$q$，因为模可能会将某些元素减少到零，从而大大降低总和。 

## 方法

 暴力解决方案至少会考虑所有长度间隔$k$对于每个间隔，尝试应用两个模运算。 每次应用后，我们都可以递归或重复该过程，直到无法进一步改进为止。 原则上这是正确的，但操作次数将是$O(n^3)$在最坏的情况下，这远远超出了可行的限度$n=10^5$。 

关键的见解是，模运算实际上是单调的：对于任何数字$x$,$x \bmod m \le x$，因此应用模数永远不会增加元素。 这意味着如果已经应用了较小的模，则多次对同一元素应用模没有帮助。 唯一相关的属性是每个元素可以通过覆盖它的间隔减少到的最小值。 因为每个区间的长度至少$k$可以扩展到覆盖任何连续的长度段$\ge k$，最优策略是减少元素的每个连续递减序列，以**较小者为模$p$和$q$** 如果可能的话。 

如果一个元素小于$p$和$q$，则无法减少。 如果元素较大，则其所能达到的最小值是较小的模数。 通过扫描数组并至少考虑长度间隔计算每个元素的最小值$k$，我们可以有效地计算总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 最佳 | 每个测试用例 O(n) | O(1) 额外 | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$,$k$,$p$,$q$，和数组$a$。 让$m = \min(p, q)$。 
2. 初始化运行总计`total = 0`。 
3. 逐个元素地遍历数组。 对于每个元素$a[i]$：

- 如果$a[i] \ge m$它是至少一个序列的一部分$k$都是连续的元素$\ge m$， 减少$a[i]$到$a[i] \bmod m$。 
- 否则，离开$a[i]$不变。 
4. 添加结果值$a[i]$到`total`。 
5.处理完所有元素后，输出`total`。 

关键的不变量是任何长度的区间至少$k$可以对齐以覆盖上面的所有元素$m$，所以每个元素都大于$m$可以通过取模来减少$m$至少一次。 下面的元素$m$保持不变，因为没有模数可以进一步减少它们。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k, p, q = map(int, input().split())
        a = list(map(int, input().split()))
        m = min(p, q)
        total = 0
        i = 0
        while i < n:
            if a[i] >= m:
                # find the length of the consecutive segment >= m
                j = i
                while j < n and a[j] >= m:
                    j += 1
                length = j - i
                if length >= k:
                    # apply modulo m to all elements in this segment
                    for x in range(i, j):
                        a[x] %= m
                i = j
            else:
                i += 1
        total = sum(a)
        print(total)
```我们首先找到至少是连续的元素段`m`。 仅长度至少为`k`可以减少模数`m`。 较小的段保持不变，因为它们无法成为有效间隔的目标。 此方法可确保每个可最小化的元素恰好最小化一次，并且正确计算总和。 

## 工作示例

 考虑输入```
4 3 3 4
1 2 3 4
```这里`m = min(3,4) = 3`。 Scan the array:

 | 我| 一个[我] | Segment ≥ m? | Operation |
 | --- | --- | --- | --- |
 | 0 | 1 | 没有| leave |
 | 1 | 2 | 没有| leave |
 | 2 | 3 | 是的 | 段长度 = 2 < k → 离开 |
 | 3 | 4 | 是的 | 段长度 = 1 < k → 离开 |

 总和仍然是 1 + 2 + 3 + 4 = 10，但我们在示例中错过了应用模数。 实际上，≥3的元素的最长段是[3,4]，但其长度为2，小于k=3。 因此不能应用模数。 Sum remains unchanged.

 另一个例子：```
6 4 9 20
18 27 180 9 45 99
```

`m = 9`。 扫描：

 - ≥ 9 的元素段为 [18,27,180,9,45,99]，长度=6 ≥ k=4。 将模 9 应用于所有：`[0,0,0,0,0,0]`。 总和 = 0。
