 ## 解决方案
 ## 问题理解

 我们得到了多个独立的查询。 每个查询提供一个区间$[l, r]$，我们需要构造两个正整数$a$和$b$这样它们的总和就位于这个区间内的某个地方，同时$a$和$b$具有大于一的公约数。 如果不存在这样的对，我们必须报告不可能性。 

查看任务的另一种方式是我们试图表示一些整数$s \in [l, r]$作为两个不互质的数字的和。 自从$\gcd(a, b) \neq 1$，两个数字必须至少共享一个质因数，这强烈限制了它们的结构：它们必须都是某个整数的倍数$d \ge 2$。 

约束足够严格，每个测试用例的任何解决方案都必须是常数或对数。 多达 500 个查询和值$10^7$，任何二次方$r-l$或者涉及候选对的枚举将立即失败。 当间隔跨越数百万时，在最坏的情况下，对间隔进行线性扫描已经太慢了。 

当间隔极小时，尤其是当$r - l = 0$或者$1$。 例如，当$l = r = 2$，唯一可能的总和是$2$，唯一的分解是$(1,1)$，其中有 gcd$1$。 同样，当$l = 2, r = 3$，两个可能的和 2 和 3 不能用非互质对形成。 尽管较大的间隔通常很容易，但这些小的间隔迫使不可能。 

核心困难不在于一旦选择了合适的和就构造对，而是决定这样的和何时存在于区间内。 

## 方法

 暴力方法会尝试所有可能的和$s \in [l, r]$，并且对于每个$s$，迭代所有对$(a, b)$这样$a + b = s$，检查是否$\gcd(a, b) \neq 1$。 这很快就变得不可行。 对于固定金额$s$， 有$O(s)$对，并且在一个大的区间上求和会导致大约$10^{14}$最坏情况下的操作。 

关键的观察是扭转视角。 我们不是构造任意对，而是将结构强加到它们中。 如果$\gcd(a, b) \ge 2$，那么两个数都可以被某个数整除$d \ge 2$。 我们可以写$a = d x$,$b = d y$，然后总和变为$a + b = d(x + y)$。 这意味着总和本身必须以受控方式合成，具体来说它必须至少是$2d$，并且它必须表示为$d$。 

最简单的构造完全避免了对因素的推理。 如果我们选择任何偶​​数$s$，我们可以设置$a = s/2$和$b = s/2$, 给予$\gcd(a, b) = a \ge 1$。 为了确保 gcd 严格大于 1，我们希望$a = b$至少为 2，所以$s \ge 4$甚至可以完美地工作。 

So the problem reduces to finding an even integer$s \in [l, r]$和$s \ge 4$。 一旦我们有了这样一个$s$，我们输出$(s/2, s/2)$。 

现在唯一剩下的问题是何时存在这样的偶数。 如果$r < 4$，不存在有效的总和，因为最小的可用总和是 4。否则，如果区间包含至少 4 的任何偶数，我们可以构造一个答案。 如果$l$是偶数并且$l \ge 4$，我们立即完成。 如果$l$是奇数，下一个候选人是$l+1$，然后我们检查它是否在区间内。 

这将每个测试用例的时间减少到恒定。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O((r-l)\cdot r)$|$O(1)$| 太慢了 |
 | 最佳 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1.如果$r < 4$， 输出$-1$。 

任何有效的构造都要求总和至少为 4，因为 gcd 大于 1 的最小对是$(2,2)$。 
2. 找到最小的偶数$s$这样$s \ge l$。 

如果$l$是偶数，那么$s = l$。 否则$s = l + 1$。 这确保我们选择第一个候选总和，保证两个分量都是整数。 
3.如果$s > r$， 输出$-1$。 

这意味着该区间不包含偶数，因此不可能进行有效的对称构造。 
4.否则输出$a = s/2$,$b = s/2$。 

这保证了$a + b = s \in [l, r]$和$\gcd(a, b) = a \ge 2$。 

### 为什么它有效

 该结构强制两个数字相同，因此它们的 gcd 等于数字本身。 选择偶数总和可确保该值至少为 2，从而使 gcd 变得不平凡。 唯一真正的约束是间隔内有效偶数和的可用性，并且奇偶校验准确地捕获了该条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    l, r = map(int, input().split())

    if r < 4:
        print(-1)
        continue

    s = l if l % 2 == 0 else l + 1

    if s > r:
        print(-1)
    else:
        a = b = s // 2
        print(a, b)
```代码独立处理每个测试用例。 早期检查`r < 4`消除所有即使是最小的有效对也不可能的情况。 变量`s`是该范围内的第一个偶数候选，使用简单的奇偶调整计算得出。 如果该候选人超过`r`，区间不包含偶数，因此不能形成对称对。 否则，将总和平均分割即可产生所需的对。 

一个常见的错误是尝试搜索任意 gcd 结构。 这是不必要的，因为相同的对已经最大化了 gcd 并最小化了约束。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        l, r = map(int, input().split())
        if r < 4:
            out.append("-1")
            continue
        s = l if l % 2 == 0 else l + 1
        if s > r:
            out.append("-1")
        else:
            a = b = s // 2
            out.append(f"{a} {b}")
    return "\n".join(out)

 ## 边缘情况

 当$l = r < 4$，算法立即拒绝，因为不存在足够大的总和来允许两个数字共享一个非平凡的除数。 例如，$l = r = 3$仅产生可能的分解$(1,2)$和$(2,1)$，均具有 gcd 1。 

当区间仅包含奇数时，例如$[5,5]$或者$[7,9]$如果范围内没有偶数，奇偶校验调整会产生一个候选$s = l + 1$，但它位于区间之外。 算法正确输出$-1$，反映出不可能形成相等的两半。 

当区间包含单个偶数时$s \ge 4$，构造变得精确：$a = b = s/2$。 例如，$l = r = 8$给出$(4,4)$，gcd=4，满足最大强度的要求。
