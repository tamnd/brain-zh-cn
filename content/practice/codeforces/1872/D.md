 ## 解决方案
 ## 问题理解

 我们得到了从 1 到 n 的数字排列，并且我们可以以任何顺序排列这些数字。 一旦排列确定，我们就会使用仅关注某些位置的规则对其进行评估。 

有两组立场很重要。 每个可被 x 整除的索引都会对分数产生正向贡献，而每个可被 y 整除的索引都会对分数产生负向贡献。 如果某个位置可被 x 和 y 整除，则其值仅减去一次，但我们必须小心，因为同一位置也计入正集中。 

因此，分数完全取决于三类指数中的数值大小：仅能被 x 整除的指数、仅能被 y 整除的指数和可被两者整除的指数。 

目标是安排排列，使大量的人落在他们做出积极贡献的位置，而少数人落在他们减少分数的位置。 

约束条件最多为 n = 10^9，测试用例最多为 10^4。 这立即排除了任何迭代所有位置或显式构造排列的方法。 即使每个测试用例是线性的也太大了。 

唯一可行的解​​决方案必须将问题简化为使用算术而不是迭代来计算每个类别中有多少个位置。 

当 x 和 y 相等或其中一个除另一个时，就会出现常见的失败情况。 例如，当 x = y 时，每个索引都是正数和负数，因此每个贡献都会抵消，无论排列如何，答案都必须始终为 0。 另一个微妙的情况是 x 和 y 共享倍数，因为除非仔细处理，否则这些索引会重复计算。 

## 方法

 暴力策略会尝试每种排列并计算每种排列的分数。 对于每个排列，我们扫描所有索引并累积贡献。 这是 n 的阶乘，即使 n = 10 也是不可能的。 

一个稍微不那么幼稚的想法是修复排列并模拟贪婪的放置，但这仍然需要明确地对所有 n 个位置进行推理。 核心困难在于，位置的贡献仅取决于可分性，而不取决于局部结构，因此任何每个位置的模拟都会变成 O(n)。 

关键的观察是，职位的实际身份并不重要。 只有每个类别有多少个位置才重要，一旦知道了这些数量，我们就可以将最大的数字分配给最有利的位置。 

我们将指数分为三组。 令 A 为可被 x 整除的索引。 令 B 为可被 y 整除的索引。 重叠 C 是可被 lcm(x, y) 整除的索引。 C 中的指数同时出现在 A 和 B 中，这意味着它们贡献的净效应为零，因为它们各加和减一次。 

因此，只有 A \ C 中的指数有正贡献，而 B \ C 中的指数有负贡献。 那么最优策略很简单：将最大的数字分配给 A \ C，将最小的数字分配给 B \ C。其他一切都是中性的。 

我们将问题简化为计算有多少个索引落入 A、B 和 C，这可以通过楼层划分来完成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | 每次测试 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 使用 n // x 计算有多少个索引可以被 x 整除。 这些是候选人的积极立场。 
2. 使用 n // y 计算有多少个索引可被 y 整除。 这些是候选的负面职位。 
3. 使用 n // lcm(x, y) 计算有多少个索引可被 x 和 y 整除。 这些是贡献取消的重叠位置。 
4. 消除两个计数中的重叠部分。 有效正持仓变为 pos = n // x - n // lcm(x, y)，有效负持仓变为 neg = n // y - n // lcm(x, y)。 
5. 从概念上对逻辑进行排序：我们要分配值 1..n。 最大值应位于正位置，最小值应位于负位置。 
6. 将正位置的贡献计算为最大 pos 数的总和，即从 n-pos+1 到 n 的总和。 
7. 计算负数位置的贡献减去最小负数的总和，即从 1 到负数的总和。 
8. 输出差值。 

为什么有效：排列自由度允许将值任意分配给位置，并且分数与值呈线性关系。 通过排序对齐可以最大化排列上的线性目标，因此通过位置权重进行贪婪分配是最佳的。 唯一重要的部分是正确解决重叠索引，这样就不会重复计算任何位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def lcm(a, b):
    import math
    return a // math.gcd(a, b) * b

t = int(input())
for _ in range(t):
    n, x, y = map(int, input().split())

    g = lcm(x, y)

    pos = n // x - n // g
    neg = n // y - n // g

    # sum of largest pos numbers
    pos_sum = pos * (2 * n - pos + 1) // 2

    # sum of smallest neg numbers
    neg_sum = neg * (neg + 1) // 2

    print(pos_sum - neg_sum)
```该代码首先计算最小公倍数以识别重叠索引。 这种重叠至关重要，因为这些立场相互抵消，并且不能影响任何一方。 

然后，我们计算排除后有多少位置产生正向和负向贡献。 一旦知道了这些计数，问题就简化为对算术序列求和：正贡献的最大值和负贡献的最小值。 

算术公式避免构造任何数组并确保每个测试用例的恒定时间计算。

 ## 边缘情况

 当x等于y时，每个指标都有正贡献和负贡献。 在这种情况下，n // x 等于n // y 并且也等于n // lcm，因此pos 和neg 都变为零。 该算法直接产生 0，无需特殊分支。 

当 x 除 y 或 y 除 x 时，重叠在其中一个集合中占主导地位。 例如，如果 x = 2 且 y = 4，则每个可被 4 整除的索引都已计入可被 2 整除的值中。n // lcm 的减法正确地消除了这些重叠，只留下真正的独占贡献。 

当x或y为1时，其中一组包括所有索引。 该算术仍然适用，因为楼层划分正确地计算了所有位置，并且重叠处理可以防止重复计算。
