 ## 解决方案
 ## 问题理解

 每只蜘蛛都会选择一个接收者。 我们可以将其视为一个有向图，其中每个顶点的出度恰好为 1。 最初，每只蜘蛛都拥有一个毛绒玩具。 

在一年中，当前拥有毛绒玩具的每只蜘蛛都会沿着其输出边缘发送一个毛绒玩具。 所有传输同时发生。 蜘蛛收到毛绒玩具后，最多只能保留一个。 如果有几只毛绒玩具到达，其中一只会幸存，其余的会被丢弃。 

因为蜘蛛要么有毛绒玩具，要么没有，所以系统的状态只是一个二进制数组。 如果某个顶点当前拥有一个毛绒玩具，则让该顶点处于活动状态。 一年后，如果至少有一个活动的前任顶点指向该顶点，则该顶点处于活动状态。 

任务是找到状态与前一年状态相同的第一年。 

图的结构很特别。 由于每个顶点都有一个出边，因此每个连接组件都由一个有向循环组成，其中有向树馈送到该循环中。 这个观察结果是整个问题的关键。 

所有测试用例的顶点总数最多为$2 \cdot 10^5$。 任何重复模拟年份的算法很容易变得二次。 解决方案围绕$O(n)$每个测试用例都是必需的。 图遍历（例如 DFS、循环检测和距离计算）很容易足够快。 

有几种边缘情况很容易被误解。 

考虑一个纯循环：```
1 -> 2 -> 3 -> 1
```每个顶点始终只有一个毛绒玩具。 状态永远不会改变。 由于根据定义，第 1 年不可能稳定，因此答案为 2。 

输入：```
1
3
2 3 1
```输出：```
2
```在第 1 年立即开始检查稳定性的模拟将错误地输出 1。 

现在考虑一个循环的链：```
3 -> 2 -> 1 <-> 4
```最初所有顶点都是活动的。 经过足够长的时间后，只有循环顶点保持活动状态。 稳定时间取决于最深的树顶点距循环的距离。 

输入：```
1
4
4 1 2 1
```答案不是周期长度。 它由树顶点到环的最大距离确定。 

另一个常见的错误是假设每个活动顶点都会永远存在。 没有传入边缘的叶子在一步后就会消失，并且永远不会返回。 

例如：```
1
3
2 1 2
```状态演变为：```
111
110
110
```答案是3。 

仅分析循环而忽略树的解决方案将错过这种行为。 

## 方法

 最直接的方法是模拟。 

将当前活动集表示为二进制数组。 每年，从每个活动顶点向其接收者发送一个毛绒玩具。 如果顶点至少收到一个毛绒玩具，则将其标记为明年活动的顶点。 比较连续的状态，一旦它们相等就停止。 

这是正确的，因为它完全遵循流程定义。 

问题是稳定可能需要很多年。 尽管简单版本稳定得足够快，模拟可能看起来很诱人，但该图可能包含长链。 在最坏的情况下我们可能会执行$O(n)$转换，每个转换都需要$O(n)$工作，导致$O(n^2)$运营。 

为了做得更好，我们需要了解该流程实际上在做什么。 

让$S_t$是一年中活动顶点的集合$t$。 一个顶点属于$S_{t+1}$如果至少有一个前任属于$S_t$。 

最初每个顶点都是活动的。 

顶点存活时间为$k$恰好存在长度有向路径的年份$k$结束于该顶点。 在函数图中，每条足够长的路径最终都会达到一个循环。 循环上的顶点始终存在。 树顶点最终会消失，因为一旦活动退回到循环，就无法在更远的地方重新生成它。 

所有树顶点消失后，只有循环顶点保持活动状态。 从那时起，状态就永远不会改变。 

这意味着稳定年份仅由任何周期中最深的树决定。 

假设一个顶点距离$d$从其周期开始，通过跟踪传出边缘直至到达周期来测量。 这样的顶点可以存活一年$d+1$然后消失。 最后一次变化发生在最大距离顶点消失时。 

如果最大距离是$D$， 然后：```
year 1 : initial state
year D+1 : deepest vertices still present
year D+2 : they disappear
year D+3 : state repeats
```答案变成：$$D + 2$$对于仅由循环组成的图，$D = 0$，给出答案$2$，完全按照要求。 

因此，问题简化为找到从任何顶点到其组件中的循环的最大距离。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟|$O(n^2)$|$O(n)$| 太慢了 |
 | 函数图分析|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 根据接收者数组构建函数图。 
2. 计算每个顶点的入度。 
3. 对入度为零的顶点使用 Kahn 算法。 

每个移除的顶点都在所有循环之外。 反复删除入度为零的顶点后，循环顶点仍然保留。 
4. 将所有剩余顶点标记为循环顶点。 

在函数图中，卡恩的过程删除每个树顶点并留下每个循环顶点。 
5. 将所有循环顶点的距离初始化为零。 
6. 以逆卡恩顺序遍历移除的顶点。 

当一个顶点指向距离已知的后继顶点时，设置：$$dist[v] = dist[next[v]] + 1$$这计算从顶点到其周期的边数。 
7. 求最大距离$D$所有顶点之间。 
8. 输出$D + 2$。 

如果该图仅包含循环，则$D=0$，给出答案2。 

### 为什么它有效

 卡恩算法精确地删除了不属于有向循环的顶点。 每个移除的顶点最终都会达到一个循环，并且以相反的顺序处理移除可以保证已经计算出顶点的后继距离。 

计算值$dist[v]$正是跟随传出边缘达到循环所需的步数。 

距离上的一个顶点$d$全年保持活跃$d+1$，因为存在一条长度为$d$从该顶点到一个循环。 年后$d+1$，活动无法再到达它。 当最大距离的顶点消失时，最终的状态发生变化。 如果$D$是最大距离，消失发生在几年之间$D+1$和$D+2$，所以第一个重复状态是年份$D+2$。 

由于每个顶点要么属于一个环，要么具有通往环的唯一路径，因此最大距离完全决定了稳定时间。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        r = [x - 1 for x in map(int, input().split())]

        indeg = [0] * n
        for v in r:
            indeg[v] += 1

        q = deque()
        for i in range(n):
            if indeg[i] == 0:
                q.append(i)

        order = []

        while q:
            v = q.popleft()
            order.append(v)

            to = r[v]
            indeg[to] -= 1
            if indeg[to] == 0:
                q.append(to)

        dist = [0] * n

        for v in reversed(order):
            dist[v] = dist[r[v]] + 1

        max_dist = max(dist)
        ans.append(str(max_dist + 2))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```入度计算准备了卡恩算法。 卡恩删除的每个顶点都属于一棵通向某个循环的树。 

数组`order`存储移除顺序。 反向处理是关键的实现细节。 当向后处理一个顶点时，它的后继顶点已经更接近一个循环，因此它的距离是已知的。 

循环顶点永远不会出现在`order`，所以它们的距离自然保持为零。 这避免了对各个周期的任何特殊处理。 

最终的答案是`max_dist + 2`。 额外的两年来自问题的年份编号。 距离零对应于第一次交换后已经稳定的图，其答案是 2 而不是 0 或 1。

 ## 边缘情况

 考虑尽可能最小的图：```
1
2
2 1
```两个顶点形成一个环。 卡恩的算法不会删除任何内容，因此每个距离都保持为零。 最大距离为零，产生答案$0+2=2$。 第一次交换后状态没有变化，第 2 年是第一个稳定的年份。 

考虑一条长链：```
1
5
2 1 2 3 4
```该图包含循环$1 \leftrightarrow 2$和链条$5 \to 4 \to 3 \to 2$。 

卡恩按顺序删除顶点：```
5, 4, 3
```向后处理给出：```
dist[3] = 1
dist[4] = 2
dist[5] = 3
```最大距离是 3，所以答案是 5。最深的顶点正是控制稳定性的。 

最后，考虑多个组件：```
1
6
2 1 4 3 4 5
```有两个循环：```
1 <-> 2
3 <-> 4
```和一条链子：```
6 -> 5 -> 4
```距离为：```
1,2,3,4 : 0
5 : 1
6 : 2
```最大距离为 2，因此答案为 4。该算法自然会同时处理所有组件，因为卡恩算法和反向距离计算在整个函数图上是全局的。
