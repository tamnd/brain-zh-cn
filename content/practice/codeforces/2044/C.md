 ## 解决方案
 ## 问题理解

 我们被要求将猴子分配到教室里正好有两排的座位上`m`各有座位。 猴子分为三类：`a`只会坐在第一排的猴子，`b`只坐在第二排的猴子，以及`c`没有偏好的猴子。 每个座位只能容纳一只猴子。 目标是最大化就座的猴子总数。 

输入给出`t`测试用例。 每个测试用例指定每排的座位数`m`和计数`a`,`b`,`c`。 每个测试用例的输出都是一个整数，即可以坐下的猴子的最大数量。 

考虑到约束条件，每个`m`,`a`,`b`， 和`c`可以大到$10^8$，并且最多可以有$10^4$测试用例。 这立即排除了任何单独迭代所有座位或所有猴子的解决方案。 我们需要对每个测试用例进行直接算术计算。 

非明显的边缘情况包括特定行猴子的数量超过座位数的情况，或者特定行猴子的总数量少于总座位数时，为灵活座位留出空间`c`猴子。 例如，如果`m = 3`,`a = 6`,`b = 1`,`c = 1`，第一行只能取其中的3个`a`猴子，剩下的`a`猴子落座。 第二排有3个座位，只有1个`b`猴子和1`c`猴子，总共 2 只。粗心的方法可能会尝试违背猴子的喜好在行之间“移动”猴子，从而产生不正确的总数。 

## 方法

 蛮力方法会尝试一一为每只猴子安排座位，检查排的偏好和座位可用性。 这原则上是正确的，但太慢了，因为猴子的总数可以达到$3 \cdot 10^8$迭代每只猴子会花费太长时间。 

关键的见解是这是一个纯粹的算术问题。 每行最多可容纳`m`猴子，所以坐在第一排的猴子数量是最少的`a + c`和`m`，在第 2 行中，它是最小值`b + remaining_c`和`m`。 然而，一个更简单且等效的计算是在每排中分别容纳尽可能多的座位：第 1 排最多可容纳`m`猴子，优先考虑`a`首先，然后是任何剩余的`c`。 这同样适用于第 2 行。`c`猴子很灵活，最大总数是`min(a + c, m) + min(b + c, m)`，但我们必须小心不要重复计算`c`。 正确的公式是座位`a`最多`m`,`b`最多`m`，然后使用每行的剩余容量`c`猴子。 这将解决方案简化为每个测试用例的简单常数时间计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(a + b + c) | O(1) | O(1) | 太慢了|
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，读取值`m`,`a`,`b`,`c`。 
3. 计算放置后第一排的可用座位数`a`猴子：`space1 = max(0, m - a)`。 这代表可以容纳灵活的猴子的座位。 
4. 计算放置完后第二排的可用座位数`b`猴子：`space2 = max(0, m - b)`。 
5. 数量`c`可以坐下的猴子受到总剩余空间的限制：`c_used = min(c, space1 + space2)`。 
6. 坐着的猴子总数是`min(a, m) + min(b, m) + c_used`。 这确保了我们永远不会超出行容量并尊重所有猴子的偏好。 
7. 打印每个测试用例的总计。 

为什么它有效：我们总是将每一行填充到其最大容量，同时尊重特定于行的约束。 在特定排的猴子入座后，灵活的猴子只会占据剩余的座位。 这保证了我们在不违反任何偏好的情况下最大化坐着的猴子数量。 由于每个运算都是算术运算，因此即使对于最大的输入，解决方案也足够快。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    m, a, b, c = map(int, input().split())
    row1 = min(a, m)
    row2 = min(b, m)
    remaining_c = min(c, (m - row1) + (m - row2))
    print(row1 + row2 + remaining_c)
```代码首先读取测试用例的数量。 对于每个测试用例，我们通过将特定于行的猴子限制为行容量来计算每行可以坐下的猴子数量。 然后，我们计算有多少只灵活的猴子（`c`）可以放入剩余的座位并将这些数字相加。 使用`min`确保我们永远不会超出容量。 使用`max(0, ...)`这里是不必要的，因为`min(c, ...)`自然处理剩余空间为零的情况。
