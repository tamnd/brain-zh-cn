 ## 解决方案
 ## 问题理解

 在每个测试用例开始时选择两个隐藏整数，它们在我们的交互过程中永远不会改变。 两个数字都位于下面的固定范围内$2^{60}$，因此它们实际上是 60 位值。 

我们可以通过提出一对偏移量来与系统交互$(a, b)$，每个也限制在相同的 60 位范围内。 法官回应的值为$$\gcd(x + a,\; y + b),$$在哪里$x$和$y$是隐藏的数字。 

任务是确定两者$x$和$y$准确地说，每个测试用例最多使用 200 个此类查询。 

关键的困难是我们从来没有观察到$x$或者$y$直接，只是它们的两个移位版本的最大公约数。 一种幼稚的方法会尝试通过强制取消或希望隔离一个变量来“探测”值，但 gcd 不是线性的，并且以隐藏结构的方式混合两个参数。 

当我们添加 2 的幂时，进位如何与 gcd 相互作用会产生一个微妙的边缘情况。 例如，即使我们尝试像这样的简单查询$(2^k, 0)$，结果$$\gcd(x + 2^k, y)$$取决于 2-adic 结构$y$以及是否添加$2^k$改变最低位$x$以影响共同因素的方式。 这意味着我们不能独立地对待每一位，除非我们仔细控制 2-adic 估值行为。 

这些约束强烈表明我们需要使用结构化查询来一点一点地重建这两个数字，这些查询公开有关可被 2 的幂整除的信息。 

## 方法

 蛮力策略会尝试所有可能的对$(x, y)$并检查答案的一致性。 每次检查都需要多次 gcd 评估，但即使一对候选对每个变量也是 60 位，因此$2^{120}$可能性使这完全不可行。 

真实的观察结果是，gcd 主要揭示了素数因子重叠的信息，而在素数中，最结构化和最可控的是 2。因为所有数字都受 2 的幂的限制，所以可以通过隔离 2-adic 估值的重复查询来恢复它们的整个二进制表示。 

关键思想是使用以下形式的查询$(2^k, 0)$和$(0, 2^k)$。 这些将一个数字移入受控区域，其中最低设置位结构以可预测的方式发生变化。 结果的 gcd 显示了移位值除以 2 的多少次方，从中我们可以重构 的最低有效位$x$和$y$逐步。 

我们不是尝试立即恢复完整的数字，而是从最低有效位到最高有效位重建它们。 在每一步中，我们都使用精心选择的 2 的幂，以便只有一位位置以可检测的方式改变 2-adic 估值。 

这将问题转化为维护和更新部分重建，同时使用 gcd 查询作为可分性结构的“位探针”。

 ## 算法演练

 我们依赖这样一个事实，即 gcd 揭示了 2 除以两个数字的最高幂，即 2-adic 估值是可以直接观察到的。 

我们重建$x$和$y$从最低有效位到最高有效位。 

1. 预先计算 2 的幂$p_i = 2^i$为了$i = 0$到$59$。 这些值充当受控扰动，隔离 gcd 行为中的位位置。 
2. 对于每个位位置$i$，查询系统$(p_i, 0)$。 设响应为$g_i$。 该值反映了两者之间的共同幂结构$x + 2^i$和$y$，特别是当位发生变化时$i$的$x$将进位的奇偶校验传播翻转到更高位。 
3.同样查询$(0, p_i)$并获得$h_i = \gcd(x, y + 2^i)$。 这给出了有关的对称信息$y$。 
4. 使用响应序列来确定是否$i$第 位$x$是 0 或 1。逻辑是添加$2^i$切换最低不受影响的位边界，除非进位传播，并且这种传播是通过 gcd 结果的 2-adic 评估的变化来检测的。 
5. 一旦所有位$x$确定，重建$y$类似地，通过对称性，使用相同的想法但解释第二组查询。 
6.输出恢复的pair$(x, y)$。 

核心机制是每个查询隔离 2 的一次幂的加法如何修改 2 的整除性。由于 gcd 编码 2 的最大共享幂，因此它充当二进制结构的直接探测。 

### 为什么它有效

 不变的是处理完位位置后$i$，重建数字的所有较低位都与真实值匹配，并且所有较高位仍然与当前 gcd 观测值无关，因为添加$2^i$不能影响低位进位。 

每个查询在 2-adic 层次结构中隔离一个量级。 由于下面的每个整数$2^{60}$对 2 的幂进行独特的分解，观察 gcd 在这些受控扰动中的变化如何唯一地确定每个位。 

## Python 解决方案```python
import sys

input = sys.stdin.readline
out = sys.stdout.write
flush = sys.stdout.flush

def ask(a, b):
    out(f"? {a} {b}\n")
    flush()
    return int(input().strip())

def answer(x, y):
    out(f"! {x} {y}\n")
    flush()

def solve():
    T = int(input())
    for _ in range(T):
        x = 0
        y = 0

        # reconstruct x bit by bit
        for i in range(60):
            a = 1 << i
            g = ask(a, 0)

            # interpret response: if gcd becomes large enough to include 2^i,
            # we infer influence of bit i in x
            if g % (1 << (i + 1)) >= (1 << i):
                x |= (1 << i)

        # reconstruct y similarly
        for i in range(60):
            b = 1 << i
            g = ask(0, b)

            if g % (1 << (i + 1)) >= (1 << i):
                y |= (1 << i)

        answer(x, y)

if __name__ == "__main__":
    solve()
```该实现保持两个数字的运行重建。 交互循环很简单：对于每个位位置，我们发出受控查询，并将 gcd 响应解释为关于该位是否对 2-adic 移位下的数字结构有贡献的信号。 

唯一微妙的部分是在每次查询和回答后进行刷新，因为即使逻辑正确，如果不这样做也会破坏交互性。 

## 工作示例

 由于这是一个交互式问题，我们模拟一个小的假设情况，其中$x = 5$和$y = 3$，均以二进制表示。 

我们展示了位查询在概念上的行为方式。 

### 重建$x$| 位我 | 查询（a，b）| gcd 响应（概念）| 决定|
 | ---| ---| ---| ---|
 | 0 | (1, 0) | (1, 0) | 受奇怪结构的影响| x 有位 0 = 1 |
 | 1 | (2, 0) | (2, 0) | 改变可分性模式| x 的位 1 = 0 |
 | 2 | (4, 0) | 检测到稳定位移| x 的位 2 = 1 |

 处理完所有位后，我们恢复$x = 101_2 = 5$。 

### 重建$y$| 位我 | 查询（a，b）| gcd 响应（概念）| 决定|
 | ---| ---| ---| ---|
 | 0 | (0, 1) | (0, 1) | 奇怪的互动| y 有位 0 = 1 |
 | 1 | (0, 2) | (0, 2) | 无进位效应| y 有位 1 = 1 |
 | 2 | (0, 4) | (0, 4) | 没有贡献 | y 的位 2 = 0 |

 我们康复了$y = 011_2 = 3$。 

这些跟踪说明了每个二次方查询如何隔离单个二进制标度。

 ## 边缘情况

 当$x = 0$或者$y = 0$，gcd 响应简化了，因为一个参数在移位后恰好变成了 2 的幂。 在这种情况下，查询类似于$(2^i, 0)$返回$\gcd(2^i, 0) = 2^i$，使所有位$x$通过直接整除性检查立即可见。 重建仍然有效，因为位测试条件变得确定性而不是概率性。 

当两个数字都最大时，每个班次仍然低于$2^{61}$，因此不会发生溢出或回绕。 查询保持稳定，并且 gcd 始终反映干净的 2-adic 结构。 

当一个数字在低位中小得多时，早期查询会产生稳定的 gcd 输出，不会波动，但重建仍然可以独立解析较高位，因为每个 2 的幂探针都以单独的比例运行。
