 ## 解决方案
 ## 问题理解

 我们得到一个有根二叉树，其中每个节点都有一个颜色值。 每个节点最多有两个子节点，并且子节点明确指定为左指针和右指针（如果不存在则为零）。 根是节点 1。 

有效路径定义为一系列节点，其中每个下一个节点都是前一个节点的子节点。 所以我们只是在树上向下行走，而不是向上移动或分支。 该路径必须至少包含两个节点，并且路径上的每个节点必须共享相同的值。 

任务是计算树中存在多少个这样的向下的单色链。 

一个关键的观察结果是，每条有效路径都是通过选择起始节点并重复跟踪其子节点之一而完全确定的，同时值保持相同。 

约束 n ≤ 500 非常小。 这立即表明 O(n^2) 甚至 O(n^3) 解决方案是安全的，我们不需要大量优化或复杂的数据结构。 对每个节点进行完全遍历就足够了。 

一个微妙的边缘情况是分支节点可以产生多个有效路径，因为每个子节点独立地延续链。 此外，允许重叠路径，这意味着只要起点不同，同一节点就可以是许多有效路径的一部分。 

例如，考虑一个由三个节点 1 → 2 → 3 组成的链，所有值都相等。 有效路径为 (1,2)、(1,2,3) 和 (2,3)。 仅计算最大链的简单方法会错过较短的子路径，因此我们必须明确考虑所有起始位置。 

## 方法

 暴力策略是将每个节点视为潜在的起点，并尝试沿每个可能的子方向向下延伸，同时节点值保持相等。 对于每个起始节点，我们执行 DFS 或迭代行走，每次移动到新节点时，我们都会将从起始节点到该节点的路径记录为有效候选节点。 

在大小为 n 的树中，在最坏的情况下，来自一个节点的单个 DFS 可能会遍历 O(n) 个节点。 对每个节点重复此操作会导致 O(n^2) 遍历步骤。 由于 n ≤ 500，这会导致大约 250,000 次操作，这是微不足道的。 

然而，该结构允许更清洁的配方。 我们可以为每个节点计算有多少条从该节点开始的有效链，而不是从头开始为每个节点重新计算链。 如果节点 u 有一个具有相同值的子节点 v，则从 v 开始的每个链都可以向上扩展 u，加上直接对 (u, v)。 这会沿着边缘创建一个简单的重复。 

所以核心洞察是，这不是全局路径问题，而是通过值相等过滤的边缘上的局部扩展问题。 每个节点贡献通过扩展到具有匹配值的子节点而形成的链。 

我们可以使用 DFS 计算结果，其中每个节点返回从其开始的有效下行链的数量，然后我们从这些返回中累积全局答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 来自每个节点的强力 DFS | O(n^2) | O(n^2) | O(n) | 已接受 |
 | 树上带有 DP 的单个 DFS | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 根据输入构建树表示，存储每个节点的左子节点和右子节点。 
2.定义DFS函数`dfs(u)`计算有多少条有效链从节点 u 开始。 该函数假设我们只允许扩展到具有相同值的子项。 
3. 初始化全局计数器`ans = 0`。 这将存储长度至少为 2 的所有有效路径。 
4. 对于每个节点 u，计算其子节点的贡献：

 - 如果子 v 存在且`a[v] == a[u]`，那么我们可以形成一条从 u 开始并立即到达 v 的链。 
- 我们还通过在前面添加 u 来扩展从 v 开始的所有链。 
5. 内部`dfs(u)`，计算：

 - 开始于`count = 1`，表示仅由 u 组成的链（内部用于扩展，尚未算作有效输出，因为单个节点是无效路径）。 
- 对于每个匹配的孩子 v，调用`dfs(v)`首先，然后：

 - 添加 1 到`ans`为直接边路径 (u, v)。 
- 添加`dp[v]`到`ans`，表示所有从 v 开始并经过 u 扩展的较长链。 
- 添加`dp[v]`到`count`，因为你可以从 v 延伸所有链。 
6. 返回`count`对于节点u。 

解释这一点的一个有用方法是每个节点充当向下单色链的生成器。 返回的值告诉有多少条这样的链从该节点开始，全局答案聚合了通过扩展这些开始形成的所有非平凡链。 

### 为什么它有效

 每个有效路径在路径中都有一个唯一的最高节点（路径中的节点中最接近根的节点）。 当向下看时，该节点是起点。 我们的 DFS 确保每个这样的起始节点将所有扩展向下计数一次。 

每个扩展对应于遵循保持值相等的子边缘。 由于树是非循环的并且我们仅向下移动，因此不存在通过不同递归路线的路径重复。 每个有效链在其最顶层节点都被精确计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(1000000)

n = int(input())
val = [0] + list(map(int, input().split()))

left = [0] * (n + 1)
right = [0] * (n + 1)

for i in range(1, n + 1):
    l, r = map(int, input().split())
    left[i] = l
    right[i] = r

ans = 0

def dfs(u):
    global ans
    dp = 1

    for v in (left[u], right[u]):
        if v == 0:
            continue
        dfs(v)
        if val[v] == val[u]:
            ans += 1
            ans += dp_v[v]
            dp += dp_v[v]

    dfs.dp_cache[u] = dp
    return dp

dfs.dp_cache = {}
dp_v = dfs.dp_cache

dfs(1)

print(ans)
```此实现执行后序遍历，以便在父级之前处理子级。 对于每个节点，我们依赖于其子节点之前计算的结果。 字典`dfs.dp_cache`存储从每个节点开始的有效向下链的数量。 

关键的实现细节是我们将 DP 存储的角色与递归分开。 价值`dp[u]`表示有多少条从 u 开始的有效下行链（包括单节点链）。 我们只使用`dp[v]`当延伸穿过匹配值边缘时。 

我们还仔细分离了计数逻辑：`ans`只计算长度至少为 2 的链，因此我们仅在扩展到子项时才明确添加贡献。

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    sys.setrecursionlimit(1000000)

    n = int(input())
    val = [0] + list(map(int, input().split()))
    left = [0] * (n + 1)
    right = [0] * (n + 1)

        l, r = map(int, input().split())
        left[i] = l

                ans += dp[v]
                dp[u] += dp[v]

    dfs(1)
    return str(ans)

 ## 边缘情况

 具有单边的最小树已经揭示了仅对长度至少为 2 的路径进行计数的要求。 用于输入`1 1`对于单个子节点，该算法仅计算一条路径，即边缘本身，因为不再存在扩展。 

在完全等值链中，每个节点都贡献多条重叠路径。 DFS 确保每个扩展在从父子关系形成时就被计数，从而防止递归分支之间的重复。 

在星形树中，根有多个具有相同值的子节点，每个子节点独立贡献。 该算法单独处理每个子树并将结果聚合到根中，确保兄弟子树之间没有交互。
