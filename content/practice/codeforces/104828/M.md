 ## 问题理解

 我们给出了关于一条线上的三个连续线段的两个观察到的约束。 想一个点$x$作为第一段的开始。 这种像猫一样的生物有三个长度相等的节段$len$：第一个跨度$[x, x+len]$，第二个跨度$[x+len, x+2len]$，第三个跨度$[x+2len, x+3len]$。 这里重要的是相邻线段共享端点并且每个线段具有相同的长度。 

两个观察者看不到确切的位置。 人们只知道第一个转变点$x$和中间过渡点$x+len$两者都位于一个区间内$[a,b]$。 另一个知道中间的过渡点$x+len$和最后一个过渡点$x+2len$都躺在里面$[c,d]$。 

所以中间的点$x+len$同时受到两个区间的约束，而其他两个端点分别受到一个区间的约束。 

任务是确定最大可能值$len$以至于存在一些真实的$x$同时满足所有四个不等式，然后以两位小数精度输出最大长度。 

所有输入的约束都很小，值最大为 10000。这立即排除了浮点搜索或繁重计算的任何需要。 直接的几何推理方法就足够了，因为可行性条件仅取决于区间重叠和线性不等式。 

当有效配置退化为$len = 0$，这意味着所有三个关键点都重合。 问题明确允许这样做，所以我们不能将其视为无效。 

## 方法

 一个蛮力的想法是尝试所有可能的值$len$以小增量检查是否有相应的$x$存在。 对于每位候选人$len$，我们将尝试解决不平等系统：$a \le x \le b$,$a \le x+len \le b$,$c \le x+len \le d$,$c \le x+2len \le d$。 

检查固定方案的可行性$len$可以通过导出边界来完成$x$，但迭代所有可能的实际值$len$具有足够的精度将需要细粒度的步进，而这将是低效且数值脆弱的。 

关键的洞察力是停止思考$x$作为主要变量。 相反，我们消除它并将所有内容直接表达为约束$len$。 每个不等式涉及$x$成为线性界限$x$，并将它们组合起来产生有效的区间$x$对于给定的$len$。 那么问题就变成了：找到最大的$len$使得这些诱导区间相交。 

从$a \le x \le b$，我们已经有了一个基本范围$x$。 

从$a \le x+len \le b$，我们得到$a-len \le x \le b-len$。 

从$c \le x+len \le d$，我们得到$c-len \le x \le d-len$。 

从$c \le x+2len \le d$，我们得到$c-2len \le x \le d-2len$。 

对于固定的$len$，所有这些约束必须重叠，因此我们将所有相应的区间相交$x$。 这给出了一个单一的可行性条件，表示为不等式$len$。 最大可行$len$当可行区域收缩到至少一对约束变得严格的边界时，就会发生这种情况。 

这将问题转变为检查通过使区间端点相等而形成的少量候选临界值。 由于所有约束都是线性的$len$，最优解必须出现在这些交点之一。 

我们通过强制下限和上限之间的重叠条件来导出候选边界$x$-间隔。 这减少到恒定数量的线性表达式$len$，最大可行值是经过一致性检查后由这些约束引起的最小上限。

 ## 算法演练

 我们将所有约束重新表述为不平等$x$，每个都表示为一个区间，具体取决于$len$。 

1、从四个约束入手：$x \in [a,b]$,$x+len \in [a,b]$,$x+len \in [c,d]$,$x+2len \in [c,d]$。 
2. 将每个转换为边界$x$。 这会产生四个间隔：$[a,b]$,$[a-len, b-len]$,$[c-len, d-len]$,$[c-2len, d-2len]$。 
3.对于固定的$len$，计算所有这些间隔的交集。 这是通过取所有下限的最大值和所有上限的最小值来完成的。 
4. 当且仅当最大下限小于或等于最小上限时，该配置才可行。 
5. 可行性条件单调$len$: 如果某个$len$有效，任何较小的值也有效。 这使我们能够搜索最大有效值$len$在实线上使用二分查找。 
6. 执行二分查找$len \in [0, 10000]$。 对于每个中间值，使用区间交集条件检查可行性。 
7. 收敛后，输出所得的最大值$len$四舍五入到小数点后两位。 

### 为什么它有效

 可行性条件由一组线性不等式定义$len$。 每个不等式都限制$x$到一个区间，其端点线性移动为$len$增加。 作为$len$成长，一切皆有可能$x$-范围单调缩小或移动，这意味着一旦交集变空，对于所有更大的区域来说它仍然是空的$len$。 这保证了单调性并证明了二分搜索的合理性。 正确性源于以下事实：任何有效的配置都必须对应于这些间隔的非空交集，并且每个这样的交集都由导出的边界完全捕获。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ok(l, a, b, c, d):
    low = max(a, a - l, c - l, c - 2*l)
    high = min(b, b - l, d - l, d - 2*l)
    return low <= high

a, b, c, d = map(float, input().split())

lo, hi = 0.0, 10000.0

for _ in range(80):
    mid = (lo + hi) / 2
    if ok(mid, a, b, c, d):
        lo = mid
    else:
        hi = mid

print(f"{lo:.2f}")
```该实现直接对算法中导出的可行性条件进行编码。 功能`ok`计算给定的候选长度是否允许所有可能位置的非空交集$x$。 每个界限完全对应于用以下方式重写的四个约束之一$x$。 二分搜索运行固定次数的迭代，这足以在给定输入规模的情况下实现双精度稳定性。 

关键的实现细节是将所有内容保持为浮点并避免在可行性检查期间进行整数舍入。 由于输出只需要两位小数，因此通过 80 次迭代达到 1e-6 左右的精度就足够了。

 ## 边缘情况

 关键边缘情况是所有端点重合时，例如输入`0 0 0 0`。 可行性检查变为：$low = max(0, 0, 0, 0) = 0$,$high = min(0, 0, 0, 0) = 0$,

 如此均匀$len = 0$是有效的。 该算法正确返回 0.00，因为二分查找从不拒绝零。 

另一种情况是当第二个区间非常宽时，比如`0 1 0 10000`。 这里来自第一个区间的约束完全占主导地位。 为了$len = 1$，我们得到：$low = max(0, -1, 0, -2) = 0$,$high = min(1, 0, 10000, 9999) = 0$,

 所以它在边界上仍然是可行的。 任何稍大的值都会破坏可行性，因此算法收敛到 1.00。 

当通过移位边界而不是原始间隔的紧密交集实现最佳值时，就会出现最终的结构边缘情况。 该公式已经考虑到了这一点，因为所有约束都对称地包含在`max(low)`和`min(high)`计算，确保不遗漏边界条件。
