 ## 解决方案
 ## 问题理解

 我们正在一个几何环境中工作，其中每个敌人都由平面中的一个圆圈表示，而玩家则固定在原点。 从原点开始，钩子沿着直线向某个方向发射。 如果射线与圆相交或接触圆，则认为圆被某个方向“击中”。 在同一条射线相交的所有圆中，只有沿着射线的第一个圆很重要。 

任务不是模拟射击。 相反，我们需要确定有多少敌人是“可钩住的”，因为从原点起至少存在一个方向，该圆圈是第一个被击中的圆圈。 

同样，每个圆从原点（它是最近的相交障碍物）贡献一些方向的角度间隔，并且我们必须计算有多少个圆具有非空的可见角度区域。 

每个圆都由其圆心和半径给出。 玩家位于原点，保证不会位于任何圆内或太靠近任何圆。 圆彼此之间也很好地分开，这可以防止边界退化重叠并确保干净的角度排序。 

测试用例中的约束总共达到一百万个圆圈。 这立即排除了任何比较所有对或以二次甚至接近二次形式对每个圆进行几何排序的解决方案。 每个测试用例的解决方案必须本质上是线性的或线性的。 

天真的几何直觉会建议扫描角度并保持活动圆，但如果不仔细减少，这将成为连续间隔重叠问题，每次测试可能有 1e5 个间隔。 

如果试图仅处理每个圆的中心角，则会出现微妙的失败情况。 例如，角度相似但距离和半径不同的两个圆可能具有重叠的可见性，并且较近的圆可以在非平凡的角度范围内完全遮蔽较远的圆。 忽略半径会导致错误的计数，因为可见性不仅仅由中心方向决定。 

## 方法

 强力解释是从原点离散化方向，或者对于每个圆，尝试通过将其与所有其他圆进行比较来计算其第一次命中的角度间隔。 对于固定圆，这需要检查沿着与其边界相切的方向，任何其他圆是否沿着该射线更接近原点。 这立即成为一个全对几何优势问题，并且每个测试用例的成本为 O(n^2)，这远远超出了可行的范围。 

关键的结构观察是，对于每个圆，只有以原点周围的角度顺序“位于前面”的其他圆才重要，并且圆之间的关系取决于比较沿某个方向的径向距离。 这是一个经典的变换问题：将每个圆转换为它主导射线的角度区间，然后计算有多少个圆具有非空主导区间。 

推理这个问题的标准方法是固定一个方向并考虑哪个圆沿着该射线最近。 如果我们扫描从 0 到 2π 的角度，则最近的圆的身份仅在两个圆沿射线距离相等的边界事件处发生变化。 这些边界事件对应于从原点看去的圆之间的切线。 在给定的分离约束下，每对贡献恒定数量的转换，并且总体结构简化为对角度事件进行排序并执行扫描。 

因此，问题变成：对于每个圆，计算与该射线相交的所有圆中距离最小的圆的角度范围。 如果该范围非空，则算作一个圆。

这会导致对源自原点的每个圆的切线方向的角度事件进行扫描。 距离条件确保每个圆贡献有限数量的事件，因此对所有事件进行排序决定了复杂性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1)-O(n) | O(1)-O(n) | 太慢了 |
 | 带有事件排序的角度扫描 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们首先将每个圆转换为相对于原点的角度信息。 对于以 (x, y) 为圆心、半径为 r 的圆，我们计算其圆心的极角 θ 以及距原点的欧几里得距离 d。 

接下来，我们计算角半宽度 α，使得从原点开始，圆对向从 θ − α 到 θ + α 的方向。 这来自标准几何：α 是到中心的线与从原点到圆的切线之间的角度，使用 sin(α) = r / d 计算。 

这为我们提供了角度圆上光线与圆相交的间隔。 

然而，仅仅相交还不够。 我们需要圆圈成为第一个命中的目标。 强分离约束下的关键简化是，沿着每个方向，最近的圆对应于沿着该射线具有最小投影距离的圆，并且排序仅在由圆之间的相切事件定义的边界处改变。 这些边界可以通过角度排序和局部优势推理隐式地预先计算。 

所以我们按如下方式进行。 

1. 计算每个圆的 (θ, d, r)，其中 θ 是圆心的角度。 
2. 对于每个圆，计算其角间隔 [θ − α, θ + α]。 通过将与 0 交叉的间隔分成两段，将间隔标准化为圆形范围。 此步骤将圆形几何形状转换为线性扫描域。 
3. 将所有间隔端点收集为事件，标记它们是否正在进入或离开圆的可见范围。 
4. 按角度对所有事件进行排序。 
5. 扫过各个角度，保持活跃圆圈的候选结构。 在每个事件中，更新当前与射线相交的圆。 
6. 对于连续事件之间的每个角段，确定沿该方向具有到原点投影的最小距离的圆。 由于活动集仅在事件边界发生变化，因此该最小值在每个段内保持稳定。 
7. 标记成为至少一个线段中唯一最小值的圆圈。 

处理完所有事件后，计算有多少个圆圈被标记为唯一可见。 

正确性取决于以下事实：在连续切线事件之间的任何开放角度间隔内，圆沿射线相交的顺序不会改变，因此最近相交圆的身份是固定的。 

## 为什么它有效

 对于任何固定方向，来自原点的射线与圆的子集相交。 其中，第一次命中是通过最小化沿射线的距离来确定的。 仅当光线与圆边界相切或穿过两个圆产生相等投影距离的几何事件时，此顺序才会发生变化。 这些事件由从相切角导出的间隔端点精确捕获。 

因此，答案中的每一个变化都由事件边界来解释。 在连续事件之间，解空间是不变的，因此每个段计算一次最小值就足够了。 任何在某个方向上真正“第一次命中”的圆必须在至少一个这样的不变分段中最小，以保证不会错过计数。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        circles = []
        
        events = []
        
        for i in range(n):
            x, y, r = map(int, input().split())
            d = math.hypot(x, y)
            theta = math.atan2(y, x)
            
            if d <= 0:
                continue
            
            # guard, but constraints say valid
            if d <= r:
                alpha = math.pi / 2
            else:
                alpha = math.asin(min(1.0, r / d))
            
            l = theta - alpha
            rr = theta + alpha
            
            circles.append((d, i))
            
            events.append((l, i, 1))
            events.append((rr, i, -1))
            
            # wrap around
            if l < -math.pi:
                events.append((l + 2 * math.pi, i, 1))
                events.append((rr + 2 * math.pi, i, -1))
        
        events.sort()
        
        active = set()
        best_in_segment = [False] * n
        
        idx = 0
        m = len(events)
        
        def current_best():
            if not active:
                return None
            return min(active, key=lambda i: circles[i][0])
        
        while idx < m:
            angle = events[idx][0]
            
            while idx < m and events[idx][0] == angle:
                _, i, t = events[idx]
                if t == 1:
                    active.add(i)
                else:
                    active.discard(i)
                idx += 1
            
            # next segment starts, but we evaluate after update
            if active:
                b = min(active, key=lambda i: circles[i][0])
                best_in_segment[b] = True
        
        print(sum(best_in_segment))

if __name__ == "__main__":
    solve()
```该代码实现了圆切线引起的角间隔上的事件扫描。 每个圆都提供两个主要的角度边界和可能包裹的重复项。 活动集维护当前与射线方向相交的圆。 在处理给定角度的所有事件后，我们评估哪个圆在活动圆之间具有最小距离，并将其标记为在该段中可见。 

使用Python集合与重复相结合`min`不是渐近最优的，但反映了解决方案的概念结构。 在生产竞赛解决方案中，将使用平衡结构或按距离键控的线段树来避免每个线段的 O(n) 扫描。 

一个微妙的实现点是角度环绕。 因为角度位于圆上，所以穿过 -π/π 的区间必须被分割，否则排序无法表示循环连续性。

 ## 边缘情况

 一种重要的边缘情况是圆几乎与原点共线。 在这种情况下，角间隔几乎缩小到零，并且多个圆基本上沿着同一条射线竞争。 该算法处理此问题是因为所有此类圆在角度上都重叠，但在任何段中仅标记了最小距离圆。 

另一种情况是跨越 -π/π 边界的区间缠绕。 角跨度穿过不连续性的圆被分成两个事件，确保扫描在线性域上保持正确。 如果没有这种分割，圆可能会错误地显示为远离有效方向。 

第三种情况是两个圆具有几乎相同的角度边界。 分离条件确保没有精确的简并，因此事件排序保持稳定，并且没有打破平局的歧义影响正确性。
