 ## 解决方案
 ## 问题理解

 我们得到一个以混合表示形式编写的数字，它看起来像一个整数部分，后面跟着一个可能具有重复模式的小数部分。 目标是确定最小的整数基数$c$这样这个数字就可以精确地用基数表示$c$使用有限数字展开式。 

整数部分与答案无关，因为任何整数都可以不受限制地用任何基数编写。 真正的困难在于小数部分，它要么是有限的，要么最终是周期性的。 周期性结构意味着数字始终是有理数，因此任务简化为理解其分数值如何表现为分数$\frac{x}{y}$，然后确定何时可以在基数中精确表示这样的分数$c$。 

从社论中描述的约束来看，关键的隐藏结构是答案仅取决于分数约化后的分母的质因数分解。 周期长度或精度范围的大值意味着十进制表示的简单扩展是不可能的。 任何模拟数字或对大型展开式执行直接基数转换的方法都将超出时间限制，因为分母可以在周期长度中呈指数增长。 

当小数部分恰好为零或化简后变成整数时，会出现微妙的边缘情况。 在这种情况下，正确答案是$1$，因为每个整数都可以用基数表示$1$在这个抽象的表述中。 当小数部分简化为一个分数时，会出现另一种极端情况，该分数的分母与除由其质因数构造的基数之外的所有相关基数互质； 忽略取消会导致对答案的错误高估。 

## 方法

 一种直接的方法是将分数表达式显式转换为有理数。 一旦我们有了分数$\frac{x}{y}$，我们可以尝试候选基地$c$并模拟该数字是否允许终止表示。 然而，这在计算上是不可行的，因为$y$可能会非常大，并且候选人的数量会无组织地增长。 当分母呈指数增长时，即使检查每个碱基的整除条件也会太慢。 

关键的见解是基础的代表性$c$仅取决于分数的分母在约简后是否具有与以下内容兼容的质因数$c$。 特别是，当用基数表示数字时$c$，对应于几何展开式的分母引入了因子$c^k - 1$和权力$c$。 这将问题转化为关于约化分母和以下形式的表达式之间素因数分解对齐的问题$c^k$和$c^k - 1$。 

一旦我们认识到分数可以分解为涉及$10^m$以及重复部分的几何级数，分母的结构为 2 和 5 次幂以及类似 reunit 项的乘积$10^k - 1$。 该任务简化为剥离分子和分母之间的共享质因数并确定最小$c$保留分母结构中的所有不可约素数。 

蛮力法失败是因为它忽略了代数结构并以数值方式处理问题。 最佳解决方案之所以有效，是因为它将基本表示约束转换为素数指数的乘法约束。

 ## 算法演练

 我们首先将给定的数字转换为一个有理分数。 整数部分根据其位置乘以适当的 10 次方或底次方，小数部分表示为有限前缀与重复后缀的几何级数之和。 

接下来，我们将所有内容统一到以下形式的公分母上$10^m(10^k - 1)$， 在哪里$m$是非重复部分的长度，$k$是周期长度。 此步骤是必要的，因为在简化之前必须将终止部分和重复部分合并为一个分数。 

构造完分子和分母后，我们通过计算它们的最大公约数来减少分数。 这消除了所有不影响代表性的共享因素。 

然后我们将分母分解为三个概念成分：2 和 5 的幂$10^m$，以及剩余的因子$10^k - 1$。 这种分离至关重要，因为 2 和 5 的行为与 10 进制相关结构中的所有其他素数不同。 

对于素数 2 和 5，我们计算它们的分子和分母指数，并尽可能地取消。 这决定了这些素数是否保留在最终分母中。 

对于素数来自$10^k - 1$，我们对该项进行因式分解，并再次删除与分子的任何重叠。 剩下的未消去的素数形成了决定答案的不可约结构。 

最后，我们将分母中所有剩余的素数相乘。 本产品为最小底座$c$可以支持原始数字的有限表示。 

### 为什么它有效

 在每个阶段，分数都会被转换，但不会改变其值，仅改变其表示形式。 取消过程确保我们使用完全减少的有理数。 关键的不变量是任何有效的基本表示必须消除所有与基本或重新单位因子的幂不相容的分母素数。 由于我们明确地分离并跟踪所有可能的抵消源，因此不会丢失或错误地引入素数因子，因此剩余素数的最终乘积是最小且足够的。

def factorize(n):
    f = {}
    d = 2
    while d * d <= n:
        while n % d == 0:
            f[d] = f.get(d, 0) + 1
            n //= d
        d += 1
    if n > 1:
        f[n] = f.get(n, 0) + 1
    return f

def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

 ## 边缘情况

 一种重要的边缘情况是化简后小数部分恰好为零。 对于像这样的输入$0.0$，分数为零并且没有有意义的分母结构。 该算法立即返回 1，因为没有素数来约束底数。 

另一种情况是分数化简为整数，例如$0.9$，等于 1。虽然它看起来有一个分母，但归约却完全消除了它。 然后，分解步骤在空分母上运行，留下空乘积，其计算结果为 1，与正确答案匹配。 

最后一个微妙的情况是当周期性部分引入像这样的重报时$10^k - 1$与前缀共享因子。 在这种情况下，朴素乘法会重复计算素数，但完全 gcd 减少可确保在因式分解之前消除这些重叠，从而保持正确性。
