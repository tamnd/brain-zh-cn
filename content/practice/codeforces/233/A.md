 ## 解决方案
 ## 问题理解

 我们需要构造一个数字排列`1`到`n`有两个条件。 

第一个条件是`p[p[i]] = i`对于每个位置`i`。 应用排列两次必须返回到原始索引。 这意味着每个元素都指向其伙伴。 

第二个条件是`p[i] != i`对于每一个`i`。 任何元素都不允许停留在自己的位置上。 

总之，这些条件迫使排列完全由指数对之间的互换组成。 如果`i`映射到`j`， 然后`j`必须映射回`i`，并且都不能映射到自己。 

输入包含单个整数`n`，排列的大小。 输出要么是一个有效的完美排列，要么是`-1`如果不存在这样的排列。 

约束很小，`n ≤ 100`，所以性能不是问题。 即使是蛮力在技术上也适用。 真正的挑战是识别隐藏在条件中的数学结构。 

棘手的情况来自于奇数值`n`。 

例如：

 输入：```
1
```输出：```
-1
```只有一种可能的排列，`[1]`，但它违反了`p[i] != i`。 

另一个重要案例：

 输入：```
3
```粗心的方法可能会尝试：```
2 1 3
```前两个头寸形成有效的互换，但头寸`3`映射到自身，这是被禁止的。 

最小的有效情况是：

 输入：```
2
```输出：```
2 1
```这里：`p[1] = 2`

`p[2] = 1`应用排列两次会返回到原始索引，并且没有位置保持固定。 

## 方法

 强力解决方案将生成每种大小的排列`n`并检查是否满足这两个条件。 检查本身很简单。 对于每个索引`i`，验证`p[p[i]] == i`和`p[i] != i`。 

这是可行的，因为约束很小，但阶乘增长很快就会变得不合理。 甚至`10!`已经意味着超过 300 万种排列。 一旦我们理解了条件的含义，就不需要进行全面的暴力搜索。 

关键的观察是排列必须完全由不相交的对组成。 

认为`p[i] = j`。 自从`p[p[i]] = i`，我们立即得到：```
p[j] = i
```所以每个元素都必须属于一个 2 循环：```
i <-> j
```单元素循环是被禁止的，因为`p[i] != i`。 

这意味着数组必须分成对。 这只有在以下情况下才可能实现：`n`是均匀的。 

一旦我们看到了这一点，构建就变得微不足道了。 我们简单地交换相邻的数字：```
1 <-> 2
3 <-> 4
5 <-> 6
...
```例如，当`n = 6`:```
2 1 4 3 6 5
```应用排列两次会将每个索引返回到其自身。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n! × n) | O(n! × n) | O(n) | 概念上太慢|
 | 最佳 | O(n) | O(1) 不包括输出 | 已接受 |

 ## 算法演练

 1.读取整数`n`。 
2. 检查是否`n`很奇怪。 

如果`n`为奇数，打印`-1`并停止。 完美排列完全由对组成，因此奇数个元素总是留下一个不成对的元素。 
3. 否则，迭代来自的数字`1`到`n`的步骤`2`。 
4. 对于每对`(i, i + 1)`， 输出：```
i + 1, i
```这将创建一个 2 周期：```
i -> i + 1
i + 1 -> i
```5. 打印构建的排列。 

### 为什么它有效

 每对`(i, i + 1)`形成互换。 对于该对内的任何元素，应用一次排列会移动到伙伴，再次应用它会返回到原始位置。 

例如：```
p[i] = i + 1
p[i + 1] = i
```然后：```
p[p[i]] = p[i + 1] = i
```没有元素映射到自身，因为每个元素都会与另一个元素交换。 

由于整个排列是由独立的 2 循环组成的，因此条件适用于所有索引。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    if n % 2 == 1:
        print(-1)
        return

    ans = []

    for i in range(1, n + 1, 2):
        ans.append(str(i + 1))
        ans.append(str(i))

    print(" ".join(ans))

solve()
```代码中处理的第一个条件是是否`n`很奇怪。 奇数大小的集合无法完全划分为对，因此不存在完美的排列。 

循环前进`2`每次都是因为我们成对处理索引。 对于每对`(i, i + 1)`，数字以相反的顺序附加。 这直接创建了所需的 2 周期结构。 

该实现在列表中使用字符串，以避免在输出构造期间重复进行整数到字符串的转换。 

界限很小，但解决方案仍然以线性时间运行，并使用与竞争性编程约定一致的快速输入风格。

 | 迭代 | 我| 附加值| 当前排列 |

 | 2 | 3 | 4, 3 | 2 1 4 3 | 2 1 4 3

```验证：

 | 位置 | p[i] | p[i] p[p[i]] | p[p[i]] |

 ## 边缘情况

 第一个关键边缘情况是`n = 1`。 

输入：```
1
```该算法立即检查奇偶校验：```
1 % 2 == 1
```由于该值为奇数，因此会打印：```
-1
```这是正确的，因为唯一可能的排列是：```
1
```这违反了要求`p[i] != i`。 

另一个微妙的情况是任何更大的奇数值，例如：

 输入：```
3
```该算法再次检测奇校验并打印：```
-1
```这避免了一个常见的错误，即有人只交换前两个元素：```
2 1 3
```此处，第三个位置映射到其自身，因此排列无效。 

具有最大允许偶数值的边界情况是：

 输入：```
100
```该算法生成：```
2 1 4 3 6 5 ...
```每个相邻对形成一个有效的 2 周期。 没有一个索引是不匹配的，并且在整个范围内所有条件都保持满足`1`到`100`。
