 ## 解决方案
 ## 问题理解

 我们有一辆车辆，它可以消耗多个电池的能量，同时在数轴上行驶。 每个电池开始充满电并贡献固定的可用距离，一个充电单位等于一公里。 关键的自由度是，每行驶一公里，我们就可以选择从哪个电池消耗能量，只要该电池仍有剩余电量。 

沿途有一些特殊的点，每个点都与特定的电池类型相关。 当车辆到达这样的点时，该特定电池会立即重新充满，如果同一电池存在多个充电站，这种情况可能会发生多次。 

目标是计算车辆从零位置开始可以行驶多远，假设我们总是对每一步使用的电池做出最佳选择。 

这些约束表明每个测试用例的解决方案必须是线性或接近线性的。 所有测试用例中的电池和充电站总数仅限于数十万个，这排除了任何每公里模拟或任何每步重复扫描所有电池的方法。 任何依赖于一次走一个单位的路径的方法都是立即不可能的，因为头寸高达十亿。 

一个微妙的边缘情况来自于站点位置和电池使用之间的相互作用。 天真的解释可能表明我们只关心总能量，但站点位于特定坐标。 如果车辆无法到达下一站，任何未来的补充都变得无关紧要。 例如，如果总初始能量为 5 并且第一个站点位于位置 10，则即使存在后续站点，车辆也会在 5 处停止。 这意味着可行性取决于累积能量，而不仅仅是容量总和。 

## 方法

 思考这个问题的强力方法是逐公里地模拟运动。 在每一步中，我们都会选择任何具有剩余电量的电池并减少它。 当我们到达一个站点位置时，我们立即给相应的电池充电。 

这种做法是正确的，因为它完全遵循规则，但在规模上立即失败。 如果答案距离约为 10^9，即使是单个测试用例也需要数十亿步，而对于多达 10^4 个测试用例，这变得完全不可行。 

关键的观察结果是，系统中的任何内容都不取决于我们如何在电池之间分配消耗，只取决于可用的总能量以及何时释放额外的能量。 每个电池最初提供固定数量的可用能量，每个站提供一个电池的额外完全补充。 

由于我们可以自由选择每公里使用哪个电池，因此没有理由浪费未来的充电潜力：每当电池充电时，我们总是可以决定稍后使用它。 这意味着每个站都有效地将其相关电池的额外全部容量贡献给总能量池。 

因此，我们不需要跟踪每公里的行为，而只需计算可用的总能量：初始能量加上所有充电事件。 最大可能距离受到总能量的限制，并且还受到以下事实的限制：如果能量在到达最后一个站点之前耗尽，我们就无法超越最后一个站点的位置。 

事实上，由于无论来自哪种电池，所有能量都是等效的，因此问题归结为计算单个总能量预算。

 ## 算法演练

 我们计算车辆可以获得多少总能量。

1. 从所有初始电池容量的总和开始。 这代表零位置立即可用的所有能量。 
2. 对于每个充电站，添加其充电的电池的全部容量。 每个充电站都会贡献一次额外的完全充电事件，因此它会根据电池的容量增加总可用能量。 
3. 总可达距离是所有收集能量的总和，因为每单位能量可以准确地转换为一公里的行程。 
4. 最终答案就是这个总和，因为一旦能源可用，没有其他约束限制重用或分配。 

重要的推理步骤是电池特性不会限制消耗。 充值不会创建依赖链； 它只是增加了所有能量单位都可以互换的系统中的总可用能量。 

### 为什么它有效

 在任何时刻，车辆只关心所有电池是否至少有一个单位的可用能量。 由于每公里都允许切换，因此任何电池的能量都可以用来立即延长行程。 站点仅增加额外的能量； 他们从不限制电池的使用或施加订购限制。 因此，这个过程相当于随着时间的推移积累能量单位并将其一一消耗，使总和成为决定可达性的唯一量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        
        total = sum(a)
        
        for _ in range(m):
            x, ttype = map(int, input().split())
            total += a[ttype - 1]
        
        out.append(str(total))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```代码的第一部分读取每个测试用例，并通过对所有电池容量求和来累积初始能量。 这直接代表遇到任何站点之前的总可用距离。 

第二部分处理每个站。 由于充电站将特定电池完全充电至其最大容量，因此它会再次将完全相同的容量贡献给总可用能量。 因此我们添加`a[tj]`对于每个站。 

最后，我们输出每个测试用例的累计总数。 

一个关键的实现细节是输入中电池类型的 1 索引。 每个站点引用从1开始的电池索引，因此我们在访问数组时减1。

 ### 示例 1

 最终的答案是所有这些贡献的总和。 这表明车站对总能量起到了附加作用。 

这证实了站点的顺序并不重要，因为每个站点独立地贡献了固定的数量。

| 步骤| 活动 | 总能量|

 车辆只是耗尽所有初始能量并停止。 这验证了当 m = 0 时公式正确简并。

 ## 边缘情况

 当没有充电站时，计算减少为初始容量的纯和。 该算法直接处理这个问题，因为站上的循环不执行任何操作，只留下初始总和。 

当所有站点都以同一电池为目标时，该算法仍然有效，因为每个站点都会再次独立地添加该电池的容量。 这符合每个站都是一次独立充值事件，而不是一次性升级的解释。 

当站点数量较多但容量较小时，仍然可以以 64 位整数安全地计算总能量，因为最大累积量受站点数量乘以最大电池容量的限制，而最大电池容量保持在标准 64 位限制内。
