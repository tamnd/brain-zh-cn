 ## 解决方案
 ## 问题理解

 我们被要求确定最小的可能角度，其顶点位于原点，可以将所有给定的人体模型包围在一个平面上。 每个人体模型都有坐标$(x_i, y_i)$，并且没有人体模型位于原点本身。 输出应该是该角度的高精度测量值。 

具体来说，想象一下站在原点并转头看所有的人体模型。 该问题要求在头部不离开原点的情况下看到每个人体模型所需的最小“视野”。 如果所有人体模型都在半平面内，则该角度可能小于 180 度，但如果人体模型几乎完全围绕原点，则该角度可能接近 360 度。 

约束条件给出$n$最多$10^5$，以及之间的坐标$-1000$和$1000$。 由于 2 秒的时间限制，这允许算法大致在$O(n \log n)$范围。 任何二次方 ($O(n^2)$）将执行高达$10^{10}$操作，这太慢了。 

需要注意的边缘情况包括人体模型位于同一条线上或分布在所有象限的配置。 例如，两个人体模型$(1, 0)$和$(-1, 0)$需要180度角。 幼稚的方法可能会低效地计算成对的角度，或者忘记将角度包裹在$360^\circ$边界。 

## 方法

 暴力方法会考虑每对人体模型并计算它们在原点处的角度。 对于每一对，您可以检查所有其他人体模型是否位于这两个点定义的楔形内。 这是可行的，因为任何最小封闭角的边缘都必须穿过两个人体模型。 然而，检查所有$O(n^2)$配对并验证所有$n$每个给定点$O(n^3)$操作，这对于$n = 10^5$。 

关键的观察是每个人体模型对应于来自原点的方向向量。 我们可以使用反正切函数计算该向量的角度。 按升序对所有角度进行排序让我们可以看到沿单位圆的连续人体模型。 最小封闭角是连续角之间最大间隙的补角。 这减少了问题$O(n^3)$到$O(n \log n)$因为排序在复杂性中占主导地位。 

这是有效的，因为圆的最大空“切片”对应于我们不需要看到任何人体模型的方向。 通过减去这个差距$360^\circ$，我们获得覆盖所有点所需的最小角度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 排序和间隙| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取所有人体模型的坐标。 每个点将表示为$(x_i, y_i)$。 
2. 使用双参数反正切函数计算每个点相对于原点的角度，$\text{atan2}(y, x)$。 这给出了之间的角度（以弧度为单位）$-\pi$和$\pi$。 
3. 将角度归一化到范围内$[0, 2\pi)$。 这可以避免负值并简化间隙计算。 
4. 按升序对所有角度进行排序。 连续的角度对应于围绕原点按顺时针顺序排列的点。 
5. 计算连续角度之间的间隙，记住还要考虑最后一个角度和第一个角度之间的间隙（环绕）$2\pi$。 
6. 找出最大的差距。 最小围角是这个最大间隙的补角，即$2\pi - \text{largest gap}$。 
7. 使用因子将结果从弧度转换为度数$180 / \pi$。 
8. 以足够的精度打印答案。 

这里的不变量是排序点之间的最大角度间隙决定了我们不需要覆盖的圆的部分。 通过排除这个间隙，我们获得了包含所有人体模型的最小角度。 由于最大的间隙不能包含任何人体模型，这保证了正确性。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

n = int(input())
angles = []

for _ in range(n):
    x, y = map(int, input().split())
    angle = math.atan2(y, x)
    if angle < 0:
        angle += 2 * math.pi
    angles.append(angle)

angles.sort()
max_gap = 0

for i in range(n):
    next_i = (i + 1) % n
    gap = angles[next_i] - angles[i]
    if gap < 0:
        gap += 2 * math.pi
    max_gap = max(max_gap, gap)

min_angle = 2 * math.pi - max_gap
print("{:.10f}".format(min_angle * 180 / math.pi))
```我们首先读取所有点并使用计算角度`atan2`，它可以正确处理所有象限中的点。 将角度归一化为$[0, 2\pi)$避免负值。 排序确保我们可以按循环顺序计算连续的间隙。 使用模算术处理环绕间隙。 转换为度数可确保最终输出符合所需的精度。
