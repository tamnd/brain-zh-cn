 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，其中每个元素至少与前一个元素一样大，最多是前一个元素的两倍。 我们被要求为每个元素分配一个加号或减号，以形成一个位于零和数组第一个元素之间的和。 输出只是与每个元素对应的一串加号和减号。 

每个元素位于前一个元素和前一个元素的两倍之间的约束至关重要。 它确保数量适度增长并防止剧烈波动。 由于数组长度可达 100,000，因此任何解决方案都必须以线性时间运行。 尝试所有可能的加号和减号组合将涉及$2^n$的可能性，这是完全不可行的。 我们需要一种有效的方法$O(n)$。 

当第一个元素为零时，会出现棘手的边缘情况。 那么总和必须恰好为零，这迫使第一个元素被小心地添加或减去。 另一个微妙的情况是，当数字增长得足够快时，如果所有符号均为正，则总和将超过第一个元素。 在这种情况下，某些符号必须为负才能使总数保持在范围内，并且选择必须平衡总和限制的前向传播。 

## 方法

 蛮力方法就是尝试所有的方法$2^n$加号和减号的序列。 对于每个序列，我们计算总和并检查它是否在所需的范围内。 这适用于小型阵列，但对于小型阵列则不可能$n = 10^5$。 

更快解决方案的关键见解来自于增长限制。 因为每个元素至少是前一个元素并且最多是双倍，所以我们可以跟踪一个运行间隔$[min\_sum, max\_sum]$每个元素后可能的总和。 最初，间隔为$[0, 0]$。 对于每个元素，添加它会将间隔向上延伸该元素，减去它会将间隔向下延伸。 处理完每个元素后，我们将结果区间与$[0, a_1]$因为最终的总和必须在这个范围内。 这是一种贪婪区间传播方法。 

一旦我们完成处理，我们就知道有一系列符号可以将总和保持在范围内。 我们可以通过从最终总和向后走并以保持间隔属性的方式为每个元素选择加号或减号来重建实际符号。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 贪心区间传播| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化两个数组`low`和`high`长度$n$跟踪每个索引的最小和最大可能总和。 放`low[n] = high[n] = 0`作为基本情况。 
2. 从最后一个元素到第一个元素处理数组。 在位置`i`，包括后可能的总和`a[i]`通过延长间隔获得`i+1`。 减法`a[i]`给出`low[i+1] - a[i]`和`high[i+1] - a[i]`。 添加`a[i]`给出`low[i+1] + a[i]`和`high[i+1] + a[i]`。 
3. 将这些新区间与约束相交`[0, a_1]`因为总和必须在这个范围内。 这给出了新的间隔`[low[i], high[i]]`。 
4.处理完所有元素后，`low[0]`和`high[0]`包含从第一个元素开始的允许总和范围。 我们可以选择这个范围内的任何值作为目标总和。 
5. 从第一个元素向前走，重建符号序列。 在每一步中，选择`+`如果减去当前元素使剩余总和保持在允许的区间内； 否则选择`-`。 

工作原理：间隔跟踪从当前索引到结束可以实现的所有总和，同时遵守最终总和约束。 向后传播间隔可以保证向前始终存在有效的符号序列。 该问题保证了解决方案的存在，因此交集运算永远不会消除所有可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

low = [0] * (n + 1)
high = [0] * (n + 1)

# propagate intervals backward
for i in range(n-1, -1, -1):
    lo = low[i+1] - a[i]
    hi = high[i+1] - a[i]
    lo2 = low[i+1] + a[i]
    hi2 = high[i+1] + a[i]
    low[i] = max(0, min(lo, lo2))
    high[i] = min(a[0], max(hi, hi2))

# reconstruct sequence
res = []
s = 0  # current sum
for i in range(n):
    if low[i+1] <= s + a[i] <= high[i+1]:
        res.append('+')
        s += a[i]
    else:
        res.append('-')
        s -= a[i]

print(''.join(res))
```后向区间计算确保我们知道每一步可能的和的范围。 前向重建选择一个有效的选择，使总和保持在范围内。 使用`low[i+1] <= s + a[i] <= high[i+1]`确保下一笔金额仍然可行。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 我们对数组进行两次处理，一次向后进行间隔处理，一次向前进行重建。 |
 | 空间| O(n) | 我们储存`low`和`high`数组和结果数组。 |

 线性时间和空间足以`n ≤ 10^5`和元素值高达$10^9$。
