 ## 解决方案
 ## 问题理解

 我们被要求建立一个长度严格递增的序列$k$，其中每个元素都位于$1$和$n$。 在所有这些序列中，我们并不是最大化值本身，而是基于连续差异的派生数量。 

对于任何有效序列$a$，我们计算由以下形式形成的差异数组$a_2-a_1, a_3-a_2, \dots, a_k-a_{k-1}$。 序列的分数是该差异数组中出现的不同值的数量。 任务是构造任何有效的递增序列来最大化该分数。 

关键的限制是$k$和$n$两者都最多为 40，这立即告诉我们该解决方案不需要繁重的算法机制。 任何$O(k^2)$或者甚至每个测试用例轻微的建设性推理就足够了，因为最多有 819 个测试用例。 

一种简单的方法可能会尝试枚举所有递增序列并计算分数，但即使对于$n = 40$, 组合数$\binom{40}{k}$变得巨大。 即使对于中等$k$，这远远超出了可行性。 

一种更微妙的失败模式来自于试图尽早最大化差距的贪婪结构。 例如，人们可能会尝试始终选择最大可能的下一个元素以增加差异的多样性。 这可能会适得其反，因为它会降低以后的灵活性，通常会将所有剩余的差异折叠成重复的或大或小的间隙，从而降低而不是增加清晰度。 

另一个常见的错误是假设最大化不同差异的数量需要最大化差异的大小。 那不是真的。 独特性仅取决于平等结构，而不取决于大小。 

## 方法

 蛮力的想法很简单：生成所有长度严格递增的序列$k$从$[1,n]$，计算每个的差异数组，并计算不同值。 这是正确的，因为它直接评估定义。 然而，序列的数量本质上是组合的，大致呈指数关系$n$，甚至对于$n=40$这是完全不可行的。 

关键的观察是我们不需要深入探索结构。 我们只关心有多少_不同的间隙值_我们可以强制进入一个长度$k-1$差值数组。 由于只有$k-1$差距，绝对最大可能的答案是$k-1$，当所有差异都明显时实现。 

构建问题变成：我们能否构建一个递增数组，使得所有连续差异都不同？ 是的，更重要的是，我们可以使用简单的模式以受控的方式做到这一点。 

我们从小增量开始，逐渐增加步长以避免重复。 直接且安全的构造是使用单位步骤构建初始前缀，然后引入单个较大的跳跃，然后再次继续使用单位步骤但进行移位，以便不会重复先前的差异。 

对于这个问题，一个更简单、标准的最优构造是从 1 开始，贪婪地选择下一个元素，使得差异变为$1, 2, 3, \dots$尽可能长。 一旦我们达到了一个点，我们就不能继续下去，除非超过$n$，我们改用恒定的剩余步骤，不会以有害的方式重复早期的值。 因为$n \le 40$，我们可以安全地确保我们永远不会超出界限，同时保留接近最大数量的不同差异，这在这种约束结构下是最佳的。 

官方解决方案中使用的更直接的建设性见解是，我们总是可以构建一个数组，其中差异是$1,2,3,\dots$直到我们没有空间了。 这立即最大化了多样性，因为所有差异都因构造而被迫不同。 

选择第一个元素，以便所选差值的总和不超过$n$。 然后我们贪婪地扩展。

 ## 算法演练

 我们从受控增加间隙的想法向后构建数组。 

1. 从一个空列表开始，并将当前值设置为 1。这保证了我们保持在界限内并简化了推理。 
2. 从 1 开始依次判定差异。 在步骤$i$，我们尝试使用差异$i$。 这确保了所有选定的差异本质上是不同的，因为每个差异都是严格递增的。 
3. 在每个选定的差异之后，通过将新值添加到最后一个值来将新值附加到数组中。 由于所有差异都是正数，因此这会自动保持严格增加。 
4. 一旦添加下一个值超过，就停止增加差值$n$。 到那时，我们就不能在不违反上限的情况下继续增加差距。 
5.如果我们还没有生产$k$元素，通过从最后一个值添加恒定步长 1 来填充剩余的槽。 这不会引入影响最优性的重复差异，因为我们已经在约束下尽可能最大化了不同的大差异。 

基本思想是，尽可能长时间地增加差异可以保证所有这些差异都是不同的。 唯一的限制是施加的总和约束$n$，在某些情况下会强制提前截止。 

### 为什么它有效

 该构造保证差异数组以严格递增的正整数序列开始，因此每个前缀差异都是唯一的。 一旦我们不能再在不违反界限的情况下增加下一个差异$n$，任何延续都不能在不破坏可行性的情况下引入新的明显差异。 因此，最大化不同差异的前缀是最佳的，并且任何剩余步骤都不能将分数提高到超出总和所限制的可实现的最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        k, n = map(int, input().split())

        a = [1]
        cur = 1
        d = 1

        while len(a) < k:
            if cur + d <= n:
                cur += d
                a.append(cur)
                d += 1
            else:
                break

        while len(a) < k:
            cur += 1
            a.append(cur)

        print(*a)

if __name__ == "__main__":
    solve()
```代码直接反映了建设性的想法。 我们维持当前值和从 1 开始并不断增长的候选差异。 第一个循环构建不断增长的间隙的最大严格递增序列，直到达到边界$n$。 第二个循环用单位增量填充剩余位置，这是安全的，因为我们仅在耗尽有意义的增长后才使用它。 

一个微妙的点是我们必须检查`cur + d <= n`在应用跳跃之前。 这可以防止超出允许范围并确保所有值保持有效。 第二个循环肯定会终止，因为最坏的情况是我们重复加 1，直到达到$k$元素。

 ## 边缘情况

 当$k = n$，唯一有效的序列是$1,2,\dots,n$。 该算法自然会产生此结果，因为每当不再可能进行更大的跳跃时，它就会不断加 1。 

什么时候$n$相对于快速增加的差异来说很小，贪婪的增长几乎立即停止。 在这种情况下，序列变成一个简单的连续链，它仍然满足约束并在严格界限下最大化可实现的明显差异。
