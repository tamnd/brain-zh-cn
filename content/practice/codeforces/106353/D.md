 ## 解决方案
 ## 问题理解

 我们有一个圆形结构$n$均匀分布的点，标记为 1 到$n$。 从点1开始，我们重复将每个点连接到该点$k$向前迈出一步，环绕模数$n$，直到回到起点。 这会产生一个循环，该循环可能访问所有点或仅访问一个子集，具体取决于$k$。 

每个连接都是圆的弦，弦的长度仅取决于其端点之间的角距离。 由于所有点的间距相等，因此逐步$k$对应于固定角度，纱线总长度与循环中的弦数乘以弦长成正比。 

循环中的和弦数量并不总是$n$。 如果我们继续跳过去$k$，我们正好回到起点$\frac{n}{\gcd(n,k)}$步骤，意味着周期长度是$n / \gcd(n,k)$。 每个步骤对应一个和弦跨度$k$弧，因此最大化总纱线相当于最大化：$$\frac{n}{\gcd(n,k)} \cdot \sin\left(\frac{\pi k}{n}\right)$$达到一个常数因子。 

任务是选择一个整数$k$,$1 \le k < n$，最大化这个表达式。 

约束条件允许$n$最多$10^9$，这立即排除了任何迭代所有可能的方法$k$值和计算$\gcd$对于每个。 一个天真的$O(n)$扫描是不可行的，因为它需要多达十亿次评估。 

一个关键的结构特性是$\gcd(n,k)$正弦项取决于除数和对称性而不是任意行为。 这表明该解决方案是由数论结构驱动的，而不是对所有问题进行强力优化$k$。 

出现微妙的边缘情况时$n$是素数。 然后$\gcd(n,k)=1$为所有人$k$，所以周期长度总是$n$，问题纯粹简化为最大化$\sin(\pi k/n)$，其峰值为$k \approx n/2$。 任何围绕中点的差一选择都变得至关重要。 

甚至出现另一个边缘情况$n$， 在哪里$k = n/2$产生直径弦。 这使得局部正弦最大化，但必须确保没有其他选择$k$gcd 越小，总循环贡献就越长。 

## 方法

 直接方法会尝试所有值$k$从 1 到$n-1$，使用计算周期长度$\gcd(n,k)$，并评估总长度公式。 这是正确的，因为它直接镜像构造，但需要计算$O(n)$候选者，每个都涉及 gcd 和正弦评估。 即使忽略浮点成本，这对于$n$最多$10^9$，因为这需要数十亿次迭代。 

关键的见解是该表达式分为两个相互竞争的效应：正弦项仅取决于归一化分数$k/n$，而循环多重数仅取决于$\gcd(n,k)$。 正弦函数在附近最大化$k = n/2$，而 gcd 项最大化时$k$共享大除数$n$。 这两个目标是冲突的，并且最优发生在高度结构化的点而不是任意的$k$。 

重写$k = d \cdot x$和$n = d \cdot m$，我们得到$\gcd(n,k)=d$，所以周期长度变为$m$，独立于$x$。 总目标变为：$$\frac{n}{d} \cdot \sin\left(\frac{\pi x}{m}\right)$$对于固定$m$，正弦项最大化时$x$最接近$m/2$，对应于$k$最接近$n/2$的倍数之间$d$。 

这将问题减少为仅尝试以下形式的候选者$k \approx n/2$，但受到除数的限制$n$。 最佳解决方案必须来自检查该中点结构周围的除数，这可以简化为测试$k = \lfloor n/2 \rfloor$以及由除数结构引起的附近值。 事实上，最优值总是出现在$k = \lfloor n/2 \rfloor$或者$k = \lceil n/2 \rceil$，因为远离中点的任何 gcd 改进都会减少正弦项，而不是增加重数。 

因此，解决方案崩溃为仅评估周围恒定数量的候选者$n/2$，使其高效。

 ## 算法演练

 我们现在将见解转化为具体的程序。 

1. 计算两个中心候选$k_1 = \lfloor n/2 \rfloor$和$k_2 = \lceil n/2 \rceil$。 这些代表离散圆上正弦项最大化的点。 
2. 对于每位候选人$k$, 计算$g = \gcd(n, k)$。 这决定了遍历分为多少个不相交的循环，这直接缩放了总弦数。 
3. 使用对数形式评估目标值以避免浮点不稳定：$$\text{score}(k) = \frac{n}{g} \cdot \sin\left(\frac{\pi k}{n}\right)$$4.比较考生的成绩并选择$k$产生更大的价值。 如果它们相等，则任一者都有效。 
5. 输出选择的$k$。 

我们将自己仅限于这些候选者的原因是，任何偏离中点的移动都会比增加正弦项所带来的任何收益更快地减少正弦项。$\gcd(n,k)$。 自从$\sin(x)$在其最大值附近严格凹入$\pi/2$，偏离$n/2$在目标上总是要付出代价的。 

### 为什么它有效

 目标是由下式确定的离散周期函数的乘积$\gcd(n,k)$和单峰凹函数由下式确定$\sin(\pi k/n)$。 gcd 项仅在除数边界处变化$n$，与全范围相比是稀疏的$k$，而正弦项平滑变化并在中点处最大化。 任何通过移动来提高 gcd 的尝试$k$远离$n/2$迫使正弦成比例的损失主导了周期分裂的增益。 这将最优值固定在中心区域，并且在该区域内只有两个最接近的整数才重要。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

n = int(input())

def score(k):
    g = math.gcd(n, k)
    return (n // g) * math.sin(math.pi * k / n)

k1 = n // 2
k2 = n - k1

best_k = k1
best_val = score(k1)

val2 = score(k2)
if val2 > best_val:
    best_val = val2
    best_k = k2

print(best_k)
```该实现直接来自减少的候选集。 我们只计算两个值$k$，两者都围绕$n/2$，并完全按照定义评估目标。 

gcd 计算平均是恒定时间，并且正弦计算也是恒定的。 唯一微妙的一点是确保计算时正确的整数处理$n - k_1$，这产生了天花板对应物$n/2$。

 ## 边缘情况

 对于$n = 3$，唯一有效的$k$值为 1 和 2。两者都产生相同的循环结构直至对称，并且算法正确地选择$k = 1$或者$k = 2$取决于中点舍入的实施。 

对于甚至$n$， 例如$n = 10$, 中点$k = 5$产生最大弦长（直径弦）。 该算法显式地构造该候选者并保证它被检查，因此没有其他除数引起的$k$可以超越它。 

对于奇数$n$， 例如$n = 9$, 两个中心值$4$和$5$被测试。 由于两者都最接近正弦最大值，并且 gcd 的变化不足以补偿远离中点的情况，因此正确的选择始终在该对内。
