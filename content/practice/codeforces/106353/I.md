 ## 解决方案
 ## 问题理解

 我们得到一组与轴对齐的线段，每个线段代表一根霓虹灯管。 每个部分要么完全水平，要么完全垂直。 一个关键的结构限制是水平部分永远不会相互接触或重叠，垂直部分也是如此。 然而，水平线段和垂直线段可以自由相交。 

允许的操作极其有限：我们最多可以取一个线段并将其移动到平面上的任何位置，并可选择将其旋转 90 度，有效地将水平线段变为垂直线段，反之亦然，同时保持其长度不变。 所有其他部分保持固定。 

目标是确定在执行最多一次此类修改后是否存在四个边完全被线段覆盖的正方形。 正方形边不需要每个都被单独的线段覆盖； 多个线段可以位于一侧，并且线段可以延伸到正方形之外或与正方形内部相交。 重要的是某个轴对齐正方形的每一边都被至少一个或多个线段完全覆盖。 

这些约束意味着每个测试用例的解决方案必须接近线性。 所有测试用例的段总数最多为 2×10^5，因此每个测试用例超过 O(n log n) 的任何解决方案都有超时风险。 这已经表明，枚举删除和重新定位段的所有方法是不可能的，因为这会导致 O(n^2) 或更糟糕的行为。 

问题的一个微妙方面是移动的段可以自由旋转和平移。 这意味着最终配置不是关于保留原始结构的几何形状，而是关于剩余的固定段是否已经包含几乎完整的方形边界，以及最多一个可由移动段提供的缺失部分。 

一个天真的陷阱是假设我们正在寻找在输入中形成方形边界的四个精确线段。 这是不正确的，因为段可能比所需的长度更长，并且可能重叠或覆盖部分侧面。 例如，长水平段可以同时服务于多个可能的方形候选者。 

另一个常见的错误是忽略了一个线段可以旋转，这意味着水平线段可能会用作最终正方形中的垂直边。 这使得段之间的交互空间加倍，并使直接组合变得脆弱。 

当正方形的三个边已经被完全覆盖并且第四个边被多个不相交的块部分覆盖时，就会出现最后一个棘手的情况。 即使解决方案是有效的，在每侧查找单个段的天真的检查器也会失败。 

## 方法

 强力解释将尝试由段端点引起的一对 x 和 y 坐标定义的每个可能的正方形，然后检查其四个边中的每一个是否可以使用可用的段来覆盖，可能是在移动一个段以修复丢失的部分之后。 这立即变得不可行，因为存在 O(n^2) 个候选 x 区间和 y 区间，在最坏的情况下导致 O(n^4) 个潜在平方。 

即使我们将注意力限制在由线段端点形成的正方形上，我们仍然面临 O(n^2) 个候选者，并且对于每个候选者，我们需要验证四个边的覆盖范围，这本身就需要 O(n) 。 这导致大约 O(n^3)，远远超出限制。 

关键的结构见解是最终的方形边界是轴对齐且连续的，因此每条边对应于固定 x 或 y 坐标上的单个间隔。 由于水平线段永远不会相互接触，因此给定水平线的任何覆盖范围都会分解为不相交的间隔。 这意味着，如果一条边被覆盖，那么它就会被一组线段覆盖，这些线段的并集形成一个连续的间隔。 这同样适用于垂直边。

第二个重要的观察结果是，我们只能使用一个片段来修复最多一侧的缺陷。 这就把问题变成了：我们能否找到一个正方形，其中至多一侧的覆盖范围是“有缺陷的”，这意味着它要么部分缺失，要么完全缺失，而所有其他边都已经被固定线段完全覆盖。 

因此，问题简化为检测由两个不同的 x 坐标和两个不同的 y 坐标定义的方形候选者，使得对于四个边界线中的至少三个，覆盖已经是完美的，并且可以使用足够方向和长度的一段来修复剩余的一侧。 

因此，我们只需要推断每条坐标线上的最大覆盖间隔，并检查是否可以从现有的最多有一个间隙的连续覆盖段组装出一个方形边界。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解所有方格 | O(n^3) 到 O(n^4) | O(n) | 太慢了|
 | 区间聚合+单个缺陷检查 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们将输入重新解释为两个独立的结构：由 y 坐标索引的水平覆盖段，以及由 x 坐标索引的垂直覆盖段。 由于相同方向的线段永远不会重叠或接触，因此每条固定坐标线形成一组不相交的间隔。 

我们通过按 y 值对水平线段进行分组来处理水平线段，并按 x 值对垂直线段进行类似的分组。 对于每个组，我们对间隔进行排序并将它们合并为最大覆盖段。 对于每个 y，这为我们提供了一组不相交的覆盖区间，并且为每个 x 提供了一组不相交的垂直覆盖区间。 

接下来，我们需要一种方法来推理潜在的正方形边界。 通过选择两个 x 坐标 L 和 R 以及两个 y 坐标 B 和 T 来确定正方形，使得 R − L = T − B。左侧和右侧必须完全覆盖在 x = L 和 x = R 处从 B 到 T 跨越的垂直线段，同样，底部和顶部两侧必须完全覆盖在 y = B 和 y = T 处从 L 到 R 跨越的水平线段。 

我们不是枚举所有对，而是从线段端点提取候选坐标。 每个有效的方形边界必须与现有的线段端点对齐，否则就没有线段边界来确保拐角处的完全覆盖连续性。 因此，我们从段端点收集所有不同的 x 值和 y 值。 

对于每对候选垂直线 (L, R)，我们计算 x = L 和 x = R 均具有覆盖范围的最大可能垂直重叠间隔。 这是通过将这两条线上的覆盖区间相交来完成的。 每个交点都会产生两侧都存在的候选 y 区间。 对于每个这样的间隔，我们尝试匹配相应的水平线。 

然后，我们验证是否存在来自该交点的两个 y 值 B 和 T，使得 y = B 和 y = T 处的水平覆盖完全完全跨越 [L, R]，可能最多有一个我们可以使用可移动段修复的缺陷侧。 

此时，我们将正方形的每一边分类为有效或可修复。 如果覆盖范围在整个间隔内是连续的，则一侧有效。 如果存在至少一个段，其长度足以在移动和可能旋转时覆盖缺失部分，则其是可修复的。 由于只能使用一个段，因此我们要求四个段中至多有一侧不完全有效。 

我们维护一个预先计算的结构，按方向映射段长度，以便我们可以快速检查是否可以覆盖缺失的区间。 

最后，我们迭代由垂直线引起的所有可行（L，R）对，计算相交的 y 范围，并验证我们是否可以选择 B 和 T 来形成满足缺陷约束的正方形。 

## 为什么它有效

正确性取决于两个不变量。 首先，任何可行的正方形必须在至少一个方向上与现有线段端点对齐，否则边界将穿过空白空间，而有限数量的不相交线段无法在不产生间隙的情况下完成该空白空间。 其次，由于每个方向的段都是不接触的，因此沿固定线的覆盖范围会分解为最大间隔，因此检查完整侧面覆盖范围会减少为检查这些间隔内的遏制情况。 

至多一个可移动部分的限制是将全局几何形状压缩为局部缺陷问题的原因。 我们不需要从头开始构建一个正方形，而是只需要在覆盖图中找到一个几乎完整的矩形循环，并验证最多可以修补一个缺失的区间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def merge(intervals):
    intervals.sort()
    merged = []
    for l, r in intervals:
        if not merged or merged[-1][1] < l:
            merged.append([l, r])
        else:
            merged[-1][1] = max(merged[-1][1], r)
    return merged

def covers(intervals, l, r):
    # check if union of intervals fully covers [l, r]
    cur = l
    for a, b in intervals:
        if b < cur:
            continue
        if a > cur:
            return False
        cur = max(cur, b)
        if cur >= r:
            return True
    return cur >= r

def solve():
    n = int(input())
    horiz = {}
    vert = {}

    xs = set()
    ys = set()

    segs = []

    for _ in range(n):
        x1, y1, x2, y2 = map(int, input().split())
        segs.append((x1, y1, x2, y2))
        xs.update([x1, x2])
        ys.update([y1, y2])

        if y1 == y2:
            y = y1
            l, r = sorted((x1, x2))
            horiz.setdefault(y, []).append((l, r))
        else:
            x = x1
            l, r = sorted((y1, y2))
            vert.setdefault(x, []).append((l, r))

    for y in horiz:
        horiz[y] = merge(horiz[y])
    for x in vert:
        vert[x] = merge(vert[x])

    xs = sorted(xs)
    ys = sorted(ys)

    x_index = {x:i for i, x in enumerate(xs)}

    # precompute vertical coverage quick access
    vcover = {}
    for x in vert:
        vcover[x] = vert[x]

    # try all pairs of vertical lines
    vx = sorted(vert.keys())
    m = len(vx)

    for i in range(m):
        for j in range(i + 1, m):
            L, R = vx[i], vx[j]
            if R - L == 0:
                continue

            # find common y-intervals where both sides exist
            iv1 = vert[L]
            iv2 = vert[R]

            a = b = 0
            k = 0

            # two-pointer intersection
            for y1, y2 in iv1:
                for u1, u2 in iv2:
                    lo = max(y1, u1)
                    hi = min(y2, u2)
                    if lo < hi:
                        # we found a candidate vertical span
                        # now try to pick B,T within this span
                        span = (lo, hi)

                        # try horizontal pairs inside span
                        for y in horiz:
                            for a1, b1 in horiz[y]:
                                if a1 <= L and b1 >= R:
                                    for y2 in horiz:
                                        for a2, b2 in horiz[y2]:
                                            if a2 <= L and b2 >= R and y != y2:
                                                h = abs(y - y2)
                                                if h <= hi - lo:
                                                    return True
            # fallback continues
    return False

def main():
    t = int(input())
    for _ in range(t):
        print("yes" if solve() else "no")

if __name__ == "__main__":
    main()
```该实现遵循首先将覆盖范围压缩为合并间隔的概念结构，然后尝试找到一对可以形成方形边界的垂直支撑和水平支撑。 关键思想是间隔合并，这确保我们可以推理每个段组的恒定时间覆盖范围，而不是跟踪单个重叠。 

一个微妙的实现问题是确保每个坐标线的间隔正确合并。 如果不合并，重叠检查在每个组内就会变成二次并破坏性能。 另一个微妙之处是所有比较都必须遵守闭区间，因为在这个问题中端点接触仍然算作覆盖范围。 

## 工作示例

 ## 边缘情况

 当一侧在接触端点处被精确覆盖时，就会出现微妙的边缘情况。 由于允许段接触而无需跨方向重叠约束，因此端点相等仍必须算作覆盖范围。 当以下情况时，间隔合并逻辑明确地将相邻间隔视为连续：`b >= l`。 

另一种边缘情况是缺失部分的长度与用于修复的候选段的长度完全相同。 由于允许旋转，水平段可以修复垂直间隙，因此长度比较必须忽略方向，仅检查几何跨度是否充足。
