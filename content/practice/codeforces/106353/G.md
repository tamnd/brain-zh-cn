 ## 解决方案
 ## 问题理解

 我们得到了一系列排成一行的不同高度。 我们可以选择一些人，然后只对那些选定的人进行自由重新安排，而其他人则完全保持在原来的位置。 完成此操作后，整条线必须形成“山形”，这意味着如果我们从左到右观察高度，它们会严格增加到某个点，然后严格减少。 

我们的目标不是明确构建最终的安排，而是最大限度地减少我们需要搬迁的人数。 如果一个人被包含在位置被重新排列的选定子集中，那么他们就会“移动”。 

考虑这个问题的一个有用方法是，我们不移动的人将其位置和高度固定在最终配置中。 所以这些没有变化的人一定已经按照他们当前从左到右的顺序融入了最终的山地顺序。 

n 最大为 5 × 10^5 的约束迫使 n 中的任何二次方立即失败。 即使 O(n log^2 n) 也处于临界状态，但可能是可以接受的，因此解决方案必须依赖于具有高效数据结构的经典最长子序列技术。 

当使用贪婪或局部决策时，会出现微妙的失败情况。 例如，尝试独立选择最佳峰值或独立地在左侧强制执行递增顺序而不协调两侧，会导致无法满足递减后缀的矛盾。 正确的结构必须将山视为单个一致的子序列，而不是两个不相关的贪婪结构。 

## 方法

 蛮力的观点是选择我们保持固定的人子集，然后尝试看看是否可以重新排列剩余的人，以便整个序列变得双调。 对于每个子集，我们将模拟固定位置是否可以嵌入到有效的山脉序列中。 由于有 2^n 个子集，这立即是不可行的，甚至尝试优化每个子集的可行性检查仍然太慢。 

关键的观察是，自由地重新排列所选子集意味着唯一重要的约束是我们不移动的人员的相对顺序一致性。 如果一个人没有移动，他们的位置就是固定的，所以在最终的序列中他们的相对顺序被保留。 这意味着我们固定的一组人必须已经形成最终山脉序列的有效子序列。 

因此，我们不考虑如何转移人们，而是翻转视角：我们希望保留尽可能多的已经在某些有效的双调子序列上撒谎的人。 如果我们最大化这样一个子序列的大小，那么剩下的人正是我们必须移动的人。 

这将问题简化为在原始数组中查找最长的双调子序列。 一旦我们知道该值，答案就是 n 减去该长度。 

双调子序列可以在其峰值处分解为严格递增部分，随后是严格递减部分。 对于每个被视为峰值的位置 i，我们计算以 i 结束的最长递增子序列和以 i 开始的最长递减子序列。 将这些组合起来可以得到峰值位于 i 的最佳双调子序列。 

我们使用 Fenwick 树（或任何 log n LIS 结构）有效地预先计算这两个部分。 一次计算以每个索引结尾的 LIS。 右侧第二遍计算反转值的 LIS，这对应于原始方向上递减的子序列。 取最佳分割点即可得到答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对子集的暴力破解 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 双调 LIS 与 Fenwick 树 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

1. 对于每个位置 i，计算恰好在 i 处结束的最长严格递增子序列的长度。 这捕获了每个元素作为峰左侧的效果。 
2. 为了有效地计算，从左到右处理元素，同时维护以高度为键控的 Fenwick 树。 对于每个 i，查询所有较小高度中的最佳值并加一。 
3. 对于每个位置 i，计算从 i 开始的最长严格递减子序列的长度。 这代表我们可以将山延伸到所选山峰右侧的距离。 
4. 通过从右向左处理，将每个值 a[i] 映射到 n - a[i] + 1，从而将递减变为递增，从而将其简化为递增子序列问题。 
5. 在反向遍历过程中维护第二棵 Fenwick 树。 对于每个位置 i，查询较小的变换高度中的最佳值并进行相应更新。 
6. 对于每个位置 i，将其视为山峰并计算 dp_inc[i] + dp_dec[i] - 1，因为峰被计数两次。 
7. 取所有 i 的最大值。 最终答案是 n 减去这个最大双调子序列长度。 

### 为什么它有效

 任何有效的最终配置都对应于一个人的子序列，其相对从左到右的顺序被保留，并且其身高形成双调序列。 相反，任何双调子序列都可以保持固定，而所有其他元素都可以移动并任意放置到剩余位置。 这在最大化固定人员和找到最长双调子序列之间建立了直接等价关系，因此没有任何解决方案可以胜过这种分解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def update(self, i, v):
        while i <= self.n:
            if v > self.bit[i]:
                self.bit[i] = v
            i += i & -i

    def query(self, i):
        res = 0
        while i > 0:
            if self.bit[i] > res:
                res = self.bit[i]
            i -= i & -i
        return res

n = int(input())
a = list(map(int, input().split()))

dp_inc = [0] * n
bit = Fenwick(n)

for i in range(n):
    x = a[i]
    best = bit.query(x - 1)
    dp_inc[i] = best + 1
    bit.update(x, dp_inc[i])

dp_dec = [0] * n
bit = Fenwick(n)

for i in range(n - 1, -1, -1):
    x = n - a[i] + 1
    best = bit.query(x - 1)
    dp_dec[i] = best + 1
    bit.update(x, dp_dec[i])

best = 1
for i in range(n):
    best = max(best, dp_inc[i] + dp_dec[i] - 1)

print(n - best)
```第一遍使用高度上的芬威克树计算在每个位置结束的递增子序列。 每个查询都会检索迄今为止看到的所有较小高度中的最佳子序列长度。 

第二遍反转数组并转换值，以便减少的子序列变成增加的子序列。 重复使用相同的 Fenwick 逻辑，这可以保持实现对称并避免编写单独的递减 DP。 

最后，每个索引都被视为潜在峰值，我们通过减一仔细合并两个 DP 值，以避免重复计算峰值元素。

 ## 边缘情况

 完全递增序列如`1 2 3 4 5`对于具有空的递减部分的山形有效。 该算法处理此问题是因为 dp_inc 在最后一个元素处变得最大，而 dp_dec 在各处都保持为 1，因此最佳双调长度为 n 并且不需要移动。 

完全递减序列如`5 4 3 2 1`对称地工作，其中 dp_inc 到处都是 1，dp_dec 在第一个元素处最大。 峰值仍然提供完全覆盖，因此同样不需要移动。 

单个元素输入很容易形成一座有效的山，并且两个 Fenwick 都传递返回 1，在减法后产生零移动。
