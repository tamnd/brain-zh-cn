 ## 解决方案
 ## 问题理解

 每种糖果类型都附有两个数字。 有$a_i$库存中该类型的糖果，以及每种糖果的成本$b_i$硬币。 

对于每种类型，我们必须选择包装尺寸$d_i$。 唯一的限制是整个库存必须分成相等的包，因此$d_i$必须划分$a_i$。 

一包的价格变成$$c_i = b_i \cdot d_i.$$选择所有包装尺寸后，我们获得一系列包装价格$$c_1,c_2,\dots,c_n.$$如果该块中的每个包具有完全相同的价格，则单个价格标签可以覆盖连续的块。 目标是选择包装尺寸，以使所需的连续等价块的数量尽可能小。 

所有测试用例组合的长度最多为$2 \cdot 10^5$。 这立即排除了任何尝试搜索除数或在每个段内执行昂贵的成对检查的方法。 我们需要一些接近线性或$O(n \log C)$， 在哪里$C$是所涉及数字的大小。 

微妙之处在于我们并不是直接选择最终的包装价格。 每个价格必须采用以下形式$b_i \cdot d_i$， 和$d_i$必须划分$a_i$。 

一个常见的错误是只考虑成对兼容性。 例如：```
(a,b):
(6,2)
(10,3)
(15,5)
```前两种类型可能共享一个有效的套装价格，后两种类型可能共享另一种有效的套装价格，但可能没有一个价格同时适用于所有三种类型。 必须立即检查整个段的状况。 

另一个容易犯的错误是使用除数$d_i$直接地。 实际的限制是关于普通包装价格$X$，而不是关于使$d_i$平等的。 

例如：```
a=6, b=2
a=10, b=3
```共同价格$X=6$有效是因为$$d_1 = 6/2 = 3,\qquad d_2 = 6/3 = 2.$$包装尺寸不同，但包装价格相同。 

## 方法

 暴力的观点是考虑每一个可能的细分市场，并询问该细分市场内的所有糖果类型是否可以共享一个共同的包装价格。 如果一个段有效，则它可以由一个价格标签表示。 

问题是，即使天真地检查一个段也是昂贵的。 每种糖果类型都有可分性约束，并且有$O(n^2)$段。 和$n$最多$2 \cdot 10^5$，这是完全不可行的。 

关键的观察结果来自于重写普通包装价格的条件。 

假设某个细分市场使用共同价格$X$。 

自从$$X = b_i \cdot d_i,$$我们知道$X$必须能整除$b_i$。 

还，$$d_i = \frac{X}{b_i}$$必须划分$a_i$。 两边同时乘以$b_i$,$$X \mid (a_i b_i).$$因此，每种糖果类型都有两个条件：$$b_i \mid X,$$和$$X \mid a_i b_i.$$对于整个细分市场来说，$X$必须是：

 1. 每个的倍数$b_i$。 
2. 每个的除数$a_i b_i$。 

满足第一个要求的最小数是$$L = \operatorname{lcm}(b_i).$$满足第二个要求的最大数是$$G = \gcd(a_i b_i).$$有效的$X$当某个倍数存在时恰好存在$L$划分$G$。 这恰恰发生在$$L \mid G.$$对于不断增长的细分市场，这将问题转化为维护：$$L = \operatorname{lcm}(b_i),$$和$$G = \gcd(a_i b_i).$$段有效当且仅当$$G \bmod L = 0.$$现在解决方案变得贪婪。 只要条件保持为真，就扩展当前段。 一旦它变为 false，从同一位置开始的更大的段就不再有效，因为添加更多元素只能减少 gcd 并增加 lcm。 我们必须开始一个新的部分。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$或者更糟|$O(1)$| 太慢了 |
 | 最优贪心 + GCD/LCM |$O(n \log C)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 从第一种糖果类型开始一个新的段。 
2. 维护当前段的两个值：$$G = \gcd(a_i b_i)$$在该段上，并且$$L = \operatorname{lcm}(b_i)$$超过该段。 
3. 当新的糖果类型到达时，计算：$$G'=\gcd(G, a_i b_i),$$

$$L'=\operatorname{lcm}(L,b_i).$$4. 检查是否$$G' \bmod L' = 0.$$如果成立，则放大的段仍然可行，因此替换$G,L$经过$G',L'$。 
5. 如果条件不满足，则扩大段不存在通用包装价格。 完成当前段，增加答案，然后开始一个仅包含当前糖果类型的新段。 
6. 继续，直到处理完所有糖果类型。 
7. 这个贪心过程形成的线段数量就是所需价格标签的最小数量。 

### 为什么它有效

 对于某个航段，当且仅当该航段的 lcm 为$b_i$除以该段的 gcd$a_i b_i$。 

当我们延长一个线段时，gcd只能保持不变或减小，而lcm只能保持不变或增大。 一旦整除条件失效，添加更多元素就无法修复它。 左边只能变大，右边只能变小。 

这种单调性使得贪婪策略成为最优策略。 每一段都尽可能地延伸。 任何解决方案都必须在条件变得不可能的第一个位置开始一个新的价格标签，因此贪婪分区使用尽可能少的段数。 

## Python 解决方案```python
import sys
from math import gcd

input = sys.stdin.readline

def lcm(a, b):
    return a // gcd(a, b) * b

t = int(input())

for _ in range(t):
    n = int(input())

    ans = 1
    g = 0
    l = 1

    for _ in range(n):
        a, b = map(int, input().split())

        ng = gcd(g, a * b) if g else a * b
        nl = lcm(l, b)

        if ng % nl == 0:
            g = ng
            l = nl
        else:
            ans += 1
            g = a * b
            l = b

    print(ans)
```该实现直接反映了数学条件。 

变量`g`存储所有值的 gcd$a_i b_i$在当前段中。 变量`l`存储所有的 lcm$b_i$当前段中的值。 

对于每种新的糖果类型，我们都尝试扩展该细分市场。 如果整除条件仍然成立，我们保留扩展。 否则，我们从当前糖果类型开始一个新的段。 

一个实施细节是`g`被初始化为零。 自从$$\gcd(0,x)=x,$$这让第一个元素自然地初始化该段。 

另一个细节是 lcm 计算：```
a // gcd(a, b) * b
```除法在乘法之前执行，以避免中间值不必要的增长。

 ## 边缘情况

 考虑完全由一种糖果类型组成的片段：```
1
2
10 7
20 3
```第一种糖果类型始终自行形成有效段，因为选择$d_1=1$给出有效的包装价格。 该算法开始于`G=a_1b_1`和`L=b_1`，并且清楚地`G % L = 0`。 

现在考虑 lcm 增长过快的情况：```
1
3
2 2
3 3
5 5
```在前两种类型之后，$$G=\gcd(4,9)=1,$$

$$L=\operatorname{lcm}(2,3)=6.$$自从$1 \not\equiv 0 \pmod 6$，该段必须被分割。 任何更大的段只会进一步降低 gcd 并进一步增加 lcm，因此故障是永久性的。 

最后，考虑即使包装尺寸不同但仍存在共同价格的情况：```
1
2
6 2
10 3
```我们有$$G=\gcd(12,30)=6,$$

$$L=\operatorname{lcm}(2,3)=6.$$因为$6 \bmod 6 = 0$，该段有效。 常见的套装价格是$X=6$，给出包装尺寸$3$和$2$。 这证实了包装尺寸的相等是无关紧要的； 只有包装价格平等才重要。
