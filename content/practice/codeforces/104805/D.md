 ## 解决方案
 ## 问题理解

 我们得到一个整数$n$，我们必须决定是否可以构造一个具有某个边长的正方形绘画$k$， 在哪里$k \le n$，在对“绘画”的非常具体的解释下。 

这幅画不仅仅是一个统一的细胞网格。 相反，它必须表示一个分解$k \times k$将正方形分成更小的轴对齐正方形，每个正方形都完全覆盖画布，没有重叠或间隙。 这些较小的方块中的每一个都被分配了四种颜色中的一种。 最终可见输出是一个大小的网格$k \times k$，其中每个晶胞继承它所属的小方块的颜色。 

邻接还有一个额外的限制：如果两个彩色区域沿着整条边接触，它们必须具有不同的颜色。 仅接触角落并不重要。 

所以任务本质上是选择一个有效的$k$并构建一个平铺$k \times k$将网格划分为正方形，然后用四种颜色为这些正方形着色，以便共享边缘的任意两个正方形具有不同的颜色。 如果不存在这样的结构，我们输出$-1$。 

约束条件$n \le 1000$这表明任何涉及对分区或几何结构进行大量搜索的解决方案都会太慢。 由于网格可能的正方形平铺数量随面积以超多项式增加，因此枚举所有正方形剖分的强力尝试呈爆炸式增长。 

样本中隐藏着更微妙的约束。 什么时候$n = 1$，解是平凡存在的。 什么时候$n = 2$或者$n = 3$，不存在解。 这立即表明并非每个$n$无论着色能力如何，甚至可以进行有效的几何分解。 

关键的结构限制是只有在整体完整的情况下才能施工。$k \times k$网格可以解释为划分为单位正方形，这意味着$n = k^2$。 任何其他分解成不等正方形都会产生尴尬的剩余区域或不兼容的边界结构。 

一个天真的错误是假设我们总是可以将一个正方形平铺成任意数量的更小的正方形。 例如，人们可能会尝试分解一个$3 \times 3$将网格分成三个正方形，但任何尝试都不可避免地会留下矩形碎片，或者违反了每个碎片本身都是正方形的要求。 

另一个常见的陷阱是只关注颜色，假设一旦给出一个网格，4 种颜色就足够了。 虽然对于固定网格来说确实如此，但真正的困难在于对于给定的网格分解本身是否可能$n$。 

## 方法

 暴力方法会尝试生成所有可能的平铺$k \times k$网格精确地$n$每个较小的正方形$k \le n$，然后测试是否存在有效的着色。 即使对于中等$k$，正方形瓷砖的数量是巨大的，因为正方形的每个放置都以分支方式限制了未来的放置。 这导致几何和分区结构中的指数搜索空间。 

关键的观察结果是几何条件比最初出现的要严格得多。 一个正方形通常不能分解为任意数量的较小正方形。 事实上，如果我们将自己限制在不重叠的轴对齐正方形上，这些正方形恰好覆盖了$k \times k$区域，最简单且唯一始终有效的统一结构是将单元分解为$k^2$细胞。 

一旦我们接受唯一一致有效的结构是完整的单元网格，问题就变成了选择$k$这样$n = k^2$。 然后剩下的任务就变成了纯粹的网格上的图形着色问题，可以使用使用所有四种颜色的重复 2x2 模式来解决。 

因此，整个问题简化为检查是否$n$是一个完美的正方形。 如果不是，则不存在有效的构造。 如果是的话，我们设置$k = \sqrt{n}$并使用固定的周期图案为网格着色。

 ## 算法演练

 ### 算法演练

 1. 计算$k = \lfloor \sqrt{n} \rfloor$并检查是否$k \cdot k = n$。 如果不是，就没有办法形成一致的正方形平铺，所以我们立即输出$-1$。 拒绝很早就发生，因为任何非正方形区域都不能分解为均匀的区域$k \times k$正方形块的网格，而不引入剩余的几何形状。 
2. 将画布尺寸设置为$k \times k$。 此时，我们将每个单元格解释为一个单独的正方形区域。 
3. 使用网格上重复的 2x2 图案指定颜色。 对于坐标处的单元格$(i, j)$，我们映射这对$(i \bmod 2, j \bmod 2)$四种颜色之一$\{Y, O, P, L\}$。 这保证了任何两个水平或垂直相邻的单元格的颜色不同。 
4. 输出$k$接下来是构建的网格。 

### 为什么它有效

 正确性取决于两个结构属性。 首先，施工仅在以下情况下进行：$n$是一个完美的正方形，意味着网格可以解释为均匀的$k \times k$分解。 不需要更高级别的正方形划分，因为每个单位单元已经形成有效的正方形区域。 

其次，着色函数确保相邻单元之间的每条边在 2x2 周期内连接 2D 棋盘中的两个不同奇偶校验对。 由于每次水平或垂直移动都会翻转至少一个坐标奇偶性，因此相邻单元格总是接收不同的颜色。 这满足了所有接触区域的约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())

k = int(n ** 0.5)
if k * k != n:
    print(-1)
    sys.exit()

colors = ['Y', 'O', 'P', 'L']

# 2x2 periodic assignment
mapping = {
    (0, 0): 'Y',
    (0, 1): 'O',
    (1, 0): 'P',
    (1, 1): 'L'
}

print(k)
for i in range(k):
    row = []
    for j in range(k):
        row.append(mapping[(i % 2, j % 2)])
    print(''.join(row))
```该解决方案首先验证输入是否形成完美的正方形。 此步骤至关重要，因为它可以防止尝试构建尺寸无法与一致的方形平铺相对应的网格。 

然后使用确定性周期性模式填充网格。 2x2 映射的选择很重要，因为它是保证四种不同颜色同时确保在两个方向上满足邻接约束的最小模式。 

一个微妙的细节是整数平方根必须小心处理。 直接使用浮点 sqrt 而不进行验证可能会引入精度问题，因此整数检查$k \cdot k = n$是必须的。

 ## 边缘情况

 对于$n = 1$，算法正确识别$k = 1$并输出一个单色单元格。 没有邻接约束，因此任何颜色分配都是有效的，并且固定映射仍然会产生正确的结果。 

对于非平方值，例如$n = 2$或者$n = 3$，算法立即拒绝。 尝试构建网格将隐式假设非整数边长，这打破了方形画布分区的几何解释。 

对于更大的完美正方形，例如$n = 100$，结构与单元数量成线性比例。 周期性的着色模式继续保证邻接分离，除了本地奇偶校验之外不需要任何全局协调。
