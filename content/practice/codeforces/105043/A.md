 ## 解决方案
 ## 问题理解

 我们得到一个数字$n$。 想象一下写出所有整数$1$到$n$在一张纸上。 在此集合上执行两个独立的操作：每个能被 2 整除的数字用一种颜色标记，每个能被 3 整除的数字用另一种颜色标记。 一个号码可能会获得一分、两分或无分。 

任务是计算有多少个数字正好得到一分。 换句话说，我们想要整数$[1, n]$可以被 2 或 3 整除，但不能同时被两者整除。 

约束条件$n \le 10^9$立即排除任何迭代所有数字的方法。 线性扫描需要多达十亿次操作，在典型的 Codeforces 限制下，这在 Python 中太慢了。 任何可行的解决方案都必须使用整除性的算术属性来计算答案。 

当一个数字既能被 2 又能被 3 整除时，就会出现一种微妙的边缘情况。例如，$n = 6$，即使数字 6 能同时被 2 和 3 整除，也不应对其进行计数。简单地独立计算 2 的倍数和 3 的倍数的简单方法将过量计算这些数字，除非进行更正。 

## 方法

 蛮力方法很简单。 我们迭代从 1 到$n$，检查每个是否能被 2 或 3 整除，并确保它不能被两者整除。 这是正确的，因为它直接对条件进行编码。 然而，它执行$n$检查，当$n$达到$10^9$。 

关键的观察结果是，能被 2 和 3 整除会产生周期性结构。 2 的倍数每 2 个数字出现一次，3 的倍数每 3 个数字出现一次，可被两者整除的数字每出现一次$\mathrm{lcm}(2,3) = 6$。 这使我们能够用计算算术级数来代替迭代。 

我们计算三个量：有多少个数字可以被 2 整除，有多少个数字可以被 3 整除，以及有多少个数字可以被 2 整除。 然后我们应用包含-排除来计算那些可以被两个条件之一整除的数。 

最终的表达式变为：$$\#(2 \text{ only}) + \#(3 \text{ only}) = (A + B - 2C)$$在哪里$A = \lfloor n/2 \rfloor$,$B = \lfloor n/3 \rfloor$， 和$C = \lfloor n/6 \rfloor$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n)$|$O(1)$| 太慢了|
 | 最佳|$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 计算$A = \lfloor n/2 \rfloor$，可被 2 整除的整数个数$[1, n]$。 这将计算所有将接收第一种颜色的数字。 
2. 计算$B = \lfloor n/3 \rfloor$，可被 3 整除的整数个数$[1, n]$。 这将计算所有将接收第二种颜色的数字。 
3. 计算$C = \lfloor n/6 \rfloor$，能同时被 2 和 3 整除的整数个数。这些正是获得两个分数的数字，因为$\mathrm{lcm}(2,3) = 6$。 
4. 将最终答案计算为$A + B - 2C$。 每个能被两者整除的数字都被计算两次$A + B$，但我们想将它们完全排除在“恰好一个标记”集合之外，因此我们将它们减去两次。 

### 为什么它有效

 中的每个整数$[1, n]$恰好属于四个不相交类别之一：既不能被 2 整除，也不能被 3 整除，只能被 2 整除，只能被 3 整除，或者可以被两者整除。 表达式$A + B - 2C$将值 1 分配给“only 2”和“only 3”类别中的元素，并将值 0 分配给所有其他类别。 这种对齐保证了计算出的总和与具有一个标记的数字计数完全匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

A = n // 2
B = n // 3
C = n // 6

print(A + B - 2 * C)
```代码直接实现了上面导出的包含排除公式。 整数除法是安全的，因为我们计算的是整数倍数。 计算时间恒定，并且仅使用几个整数变量。 

一个常见的错误是忘记减去两倍的重叠部分。 仅减去一次就会计算出能被 2 和 3 整除的数字，就好像它们贡献了一个有效分数，但它们应该贡献零。 

## 工作示例

 ### 示例 1：$n = 5$| 步骤| A = ⌊n/2⌋ | B = ⌊n/3⌋ | C = ⌊n/6⌋ | 表达 |
 | --- | --- | --- | --- | --- |
 | 价值观 | 2 | 1 | 0 | A + B - 2C = 3 |

 数字为 1、2、3、4、5。有效数字为 2（只能被 2 整除）、3（只能被 3 整除）和 4（只能被 2 整除）。 结果是 3，与计算相符。 

这证实了公式正确地计算了只有一个除数条件处于活动状态的数字。 

### 示例 2：$n = 8$| 步骤| A = ⌊n/2⌋ | B = ⌊n/3⌋ | C = ⌊n/6⌋ | 表达 |
 | --- | --- | --- | --- | --- |
 | 价值观 | 4 | 2 | 1 | A + B - 2C = 4 |

 数字为 1 到 8。有效数字为 2、3、4、8。数字 6 被排除在外，因为它在 A 和 B 中计数了两次，但通过减去 2C 进行了修正。 

该迹线显示了重叠去除对于避免计算可被两者整除的数字至关重要。

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

 ## 边缘情况

 ###案例$n = 1$输入：```
1
```这里$A = 0$,$B = 0$,$C = 0$。 该算法输出 0。唯一存在的数字是 1，它既不能被 2 也不能被 3 整除，因此不应被计算在内。 该公式正确返回 0。 

###案例$n = 6$输入：```
6
```我们计算$A = 3$,$B = 2$,$C = 1$。 结果是$3 + 2 - 2 = 3$。 贡献的数字是 2、3 和 4。数字 6 被排除，因为它属于重叠类，并且通过减去其贡献的两倍来完全删除。 这证实了共享倍数的正确处理。
