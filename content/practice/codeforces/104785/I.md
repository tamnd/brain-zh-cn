 ## 解决方案
 ## 问题理解

 飞机上有两个刚性结构：插头和插座。 每个结构由三个圆形销或孔组成。 每个圆都有一个圆心和一个半径，并且在每个结构中，三个圆都是成对不相交的。 

每个结构中的三个圆圈之一被指定为接地连接器，始终是输入中的第一个。 另外两个圆圈代表AC引脚，在插头与插座匹配时可以互换身份。 

任务是确定是否可以仅使用刚性变换（即平移和旋转）来移动插头，以便每个插头引脚都能插入相应的插座孔中。 接地必须与接地完全匹配，而其他两个引脚可以互换。 如果插头销的中心精确对齐且其半径不大于孔半径（公差最大为 1e-6），则插头销适合插座孔。 

如果存在有效的放置，我们必须输出 YES，然后提供插头中心的一种有效的转换配置。 输出配置必须保留所有成对距离精确到精度误差，这意味着我们不允许使形状变形，只能移动和旋转它。 

输入大小是恒定的，正好是六行，因此渐近复杂度是无关紧要的。 困难完全是几何上的：识别刚性运动下的一致性并处理匹配两个非地面点的模糊性。 

主要的边缘情况来自 AC 引脚排列。 幼稚的方法可能会错误地修复排序并拒绝有效的交换。 另一个微妙的问题是旋转后重建坐标时的数值稳定性，特别是当点几乎共线或非常接近时。 

例如，如果插头的两个交流插针相对于插座互换，则强制索引对齐的简单匹配将会失败，即使绕地面旋转 180 度可能会使它们完美匹配。 

## 方法

 蛮力观点很简单。 我们尝试了各种方法将两个非接地插头引脚分配给两个非接地插座孔。 对于每个分配，我们尝试找到将插头映射到插座的严格转换。 由于我们只有三个点，因此通过固定地面点和一个附加点的方向来唯一确定刚性变换。 

对于每个映射选择，我们计算插头和插座之间的地面到第二点和地面到第三点之间的距离以及两个非接地点之间的距离是否匹配。 如果它们匹配，我们就可以明确地重建变换。 

简单的成本是恒定的时间，因为输入大小是固定的，但概念上的暴力强调了关键结构：问题简化为检查两个标记的三角形是否全等，直至交换两个顶点。 

关键的观察结果是，这正是一个具有一个锚定顶点和一个可能的反射的三角形全等问题。 一旦地面点固定，其他两点就在平面中旋转时确定，唯一的模糊性是映射是保留还是交换三角形的方向。 

因此，解决方案简化为尝试非地面点的两种可能的排列，并尝试使用矢量对齐重建刚性变换。 一旦我们选择了一个有效的映射，我们就使用旋转将一个向量从插头到插座对齐，将其应用于第二个和第三个点，并输出转换后的坐标。

 ## 算法演练

 我们将插头和插座中的第一个点视为锚点，并将与其相关的所有内容对齐。

1.修复地面点对应关系。 我们平移这两种结构，以便插头接地在概念上位于原点，并且我们将所有其他点视为相对于地面的向量。 这完全消除了翻译问题。 
2. 提取两个插头向量和两个插座向量。 这些代表每个结构中其余销钉的几何形状。 
3. 尝试插头和插座非接地点之间的两种可能的匹配。 一种映射保持顺序，另一种映射交换它们。 这是必要的，因为交流引脚是可互换的并且方向未知。 
4. 对于每个映射，检查插头和插座之间的三对距离是否匹配到公差范围内。 这确保了三角形在某些刚性变换下全等。 
5. 如果映射有效，则计算将一个插头向量与其匹配的插座向量对齐的旋转。 我们使用标准二维旋转通过点积和叉积来实现这一点，构造旋转的余弦和正弦。 
6. 将此旋转应用于两个非接地插头点，然后平移结果，使接地点与插座接地点匹配。 
7. 输出YES和变换后的坐标。 

关键思想是，一旦一条边对齐，整个配置就固定了，当且仅当三角形在所选映射下全等时，第三个点就会自动就位。 

### 为什么它有效

 固定地面点会消除平移自由度。 此后，任何有效的解决方案都必须是绕原点的纯旋转。 平面中的旋转完全是通过将单个非零向量映射到另一个相等长度的向量来确定的。 如果一对匹配的点存在这种旋转，则它会正确或错误地映射第二个点。 距离检查确保一致性，保证只有真正一致的匹配才能通过。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

EPS = 1e-9

def read():
    x, y, r = map(float, input().split())
    return (x, y, r)

def sub(a, b):
    return (a[0] - b[0], a[1] - b[1])

def dist2(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return dx*dx + dy*dy

def rotate(v, cos_t, sin_t):
    x, y = v
    return (x*cos_t - y*sin_t, x*sin_t + y*cos_t)

plug = [read() for _ in range(3)]
sock = [read() for _ in range(3)]

pg = plug[0]
sg = sock[0]

p = [sub(plug[i], pg) for i in range(3)]
s = [sub(sock[i], sg) for i in range(3)]

# indices 1 and 2 are swappable
ok = False
best = None

for perm in [(1, 2), (2, 1)]:
    i, j = perm

    v1p, v2p = p[i], p[j]
    v1s, v2s = s[1], s[2] if perm == (1, 2) else (s[2], s[1])

    # check distances match
    def d2(u, v):
        return dist2(u, v)

    if abs(d2(v1p, (0,0)) - d2(v1s, (0,0))) > 1e-6:
        continue
    if abs(d2(v2p, (0,0)) - d2(v2s, (0,0))) > 1e-6:
        continue
    if abs(d2(v1p, v2p) - d2(v1s, v2s)) > 1e-6:
        continue

    # compute rotation from v1p -> v1s
    xp, yp = v1p
    xs, ys = v1s

    denom = xp*xp + yp*yp
    if denom < 1e-12:
        continue

    cos_t = (xp*xs + yp*ys) / denom
    sin_t = (xp*ys - yp*xs) / denom

    r1 = rotate(p[1], cos_t, sin_t)
    r2 = rotate(p[2], cos_t, sin_t)

    # check consistency
    if abs(dist2(r1, (0,0)) - dist2(s[1], (0,0))) > 1e-6:
        continue
    if abs(dist2(r2, (0,0)) - dist2(s[2], (0,0))) > 1e-6:
        continue

    ok = True
    best = (r1, r2)
    break

if not ok:
    print("NO")
else:
    print("YES")
    print(f"{sg[0]:.10f} {sg[1]:.10f}")
    print(f"{sg[0] + best[0][0]:.10f} {sg[1] + best[0][1]:.10f}")
    print(f"{sg[0] + best[1][0]:.10f} {sg[1] + best[1][1]:.10f}")
```代码首先将两个结构重新居中，使接地引脚成为原点参考。 这简化了向量比较的所有检查。 

核心逻辑是非接地引脚的两种可能分配的排列循环。 对于每个分配，它都会验证所有成对平方距离是否匹配。 这可以确保在尝试计算旋转之前三角形形状相同。 

旋转是通过使用点积和叉积公式将一个向量与另一个向量对齐而导出的，这避免了显式的角度计算并保持较高的数值稳定性。 旋转后，将隐式确定第二个点并对照套接字进行检查。 

最后，输出通过添加插座地面位置来重建绝对坐标。

 ### 示例 1

 我们考虑这样一种情况，即两个结构形成相同的三角形，直到最后两个点的排列。 

| 步骤| 行动| 价值观 |
 | ---| ---| ---|
 | 1 | 地面对准| 插头和插座接地于 (1,1) |

 | 3 | 距离检查 | 所有平方距离都匹配 |

 该迹线显示了不需要旋转的微不足道的全等。 已确认的不变量是，相同的成对距离意味着存在刚性运动。

 这说明了为什么必须测试这两种排列。 固定排序会错误地拒绝这种情况。

 ## 边缘情况

 一种边缘情况是两个非地面点围绕地面点对称，形成等腰配置。 在这种情况下，交换它们会产生相同的距离集，因此只有正确的旋转检查才能区分有效映射和无效映射。 

另一种边缘情况是来自地面的其中一个向量的数字精度长度接近于零。 在这种情况下，计算旋转会变得不稳定，因为归一化除以一个很小的值。 该算法通过在构造旋转之前检查分母来避免这种情况，确保不会发生未定义的行为。 

最后的边缘情况是两种结构都有效但仅在反射方面有所不同。 由于此处不允许在刚性运动中反射，因此点交叉结构自然会拒绝两个非地面点上方向无法一致匹配的情况。
