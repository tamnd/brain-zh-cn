 ## 解决方案
 ## 问题理解

 我们在单位圆形空地的边界上得到一组固定位置，其中每个位置都用角度（以度为单位）来描述。 将这些位置视为可以安装栅栏柱的允许锚点。 我们还对允许使用的帖子数量进行了限制。 

一旦我们选择了其中一些允许的点，我们就将它们按圆形顺序连接起来，形成一个内切于圆的简单多边形。 目标是最多选择允许的顶点数，以便多边形包围最大可能的面积。 

几何形状在这里很重要：所有选定的顶点都位于半径为 1 公里的圆上，因此多边形始终是循环的。 唯一的决定是选择哪个点子集。 

限制很小：最多 100 个候选点和最多 100 个可用帖子。 这立即排除了任何指数子集枚举，因为单独选择子集已经导致组合爆炸。 围绕 O(n^3) 或 O(n^2 p) 的解决方案是现实的，但任何以 n 为指数的解决方案都不现实。 

一些微妙的情况值得牢记。 首先，允许选择较少的点，因此如果配置不利，最佳答案可能不会使用所有可用的帖子。 其次，这些点按角度顺序给出，但多边形是循环的，因此必须正确处理最后一个和第一个选定点之间的环绕边。 例如，如果角度是`[0, 120, 240]`我们选择所有三个，最后的边缘来自`240`回到`0 + 360`，而不是不存在的“下一个线性索引”。 

另一个问题是，天真的贪婪策略（例如重复选择局部面积增加最多的点）可能会失败，因为面积取决于圆周围的全局间距，而不是局部成对改进。 

## 方法

 如果我们尝试暴力破解该问题，我们将枚举大小的每个子集，直到`p`，对所选点进行排序，并使用鞋带公式或圆弧段分解计算多边形面积。 对于每个子集，计算面积需要 O(p) 时间，并且子集的数量约为$\sum_{k=3}^{p} \binom{n}{k}$，即使 n = 50 也是不可行的。 

一旦我们将视角从多边形几何切换到圆形间隙，结构就会变得更简单。 对于内接于圆的多边形，面积可以分解为沿圆的连续顶点的贡献。 如果我们以递增的角度顺序沿圆移动，则每条边都会贡献一个三角形，其面积与$\sin(\Delta \theta)$， 在哪里$\Delta \theta$是连续选定点之间的角度间隙。 当半径为1 km时，常数因子是固定的，优化时可以忽略。 

那么问题就变成了：选择最多`p`角度，最大化$\sin(\text{gap})$覆盖由所选组形成的所有圆形间隙。 

一旦以这种方式构建，我们就会看到一个典型的结构：我们正在选择圆上的点的子序列并优化相邻差异的函数。 关键的困难是循环依赖，因为最后选择的点连接回第一个点。 

我们通过将一个选定点固定为起始锚点来消除这种循环依赖性。 如果我们将每个可能的起点视为多边形的第一个顶点，我们就会从该起点将圆线性化为链，并允许 DP 超过递增的索引。 对于固定的起点，我们计算在每个可能的最后一个顶点处结束的最佳链，同时精确选择`k`点。 

这导致了对索引和所选点的数量的动态编程解决方案，其中转换仅取决于先前选择的顶点和角间隙的正弦。 

复杂度变为 O(n^2 p)，因为对于每个开始和每个状态，我们都会扫描先前的候选者。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力子集 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了 |
 | DP 圆链 | O(n^2 p) | O(n^2 p) | O(np)| 已接受 |

 ## 算法演练

 1. 将所有角度按排序顺序转换为圆形数组，并将度数转换为弧度，因为正弦计算需要弧度。 这确保了所有间隙计算都是一致的。 
2. 通过附加每个角度加号来复制角度数组$2\pi$。 这使我们能够将环绕段表示为线性间隔，而无需特殊情况处理。 
3.修复起始索引`i`在原始数组中。 该起点充当多边形的第一个顶点并消除旋转模糊性。 
4. 运行动态规划，其中`dp[j][k]`表示以索引结束时可实现的最大正弦间隙总和`j`准确地选择了`k`从固定点开始的顶点`i`。 
5. 初始化`dp[i][1] = 0`，因为单个顶点还没有贡献边。 
6. 对于每个下一个索引`j > i`，并且对于每个可能的先前索引`t < j`, 过渡自`t`到`j`添加一个顶点：`dp[j][k] = max(dp[j][k], dp[t][k-1] + sin(angle[j] - angle[t]))`。 

此步骤沿着递增的角度逐边构建多边形。 
7. 填充 DP 为固定起点后，通过连接最后选择的顶点来闭合多边形`j`回到起始顶点`i + 2π`，添加`sin((i + 2π) - angle[j])`。 
8. 取所有有效终点和所有终点的最大值`k ≤ p`。 
9. 将最终总和乘以单位圆上三角形面积对应的几何常数：半径平方的一半。 由于半径为 1 公里，如果需要，请仔细转换为平方米。 

### 为什么它有效

 关键的不变量是每个 DP 状态都代表一个最优的部分多边形，其顶点从固定锚点开始严格按角度顺序增加。 由于每个有效的循环多边形都可以旋转，使其任何顶点成为起点，因此固定起点并不排除最佳解决方案。 每个过渡都保留角度顺序，因此不会出现交叉边，并且每个可行的多边形都对应于某个起始点和终点选择的 DP 路径。 目标在连续的边上进行加法分解，因此最优子结构成立：一旦最后选择的顶点固定，最佳完成仅取决于该顶点和剩余选择的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def solve():
    n = int(input().strip())
    p = int(input().strip())
    ang = list(map(float, input().split()))

    # convert to radians
    ang = [a * math.pi / 180.0 for a in ang]

    # duplicate for circular handling
    a = ang + [x + 2 * math.pi for x in ang]
    m = len(ang)

    best = 0.0

    for i in range(m):
        # dp[j][k] = best ending at j using k points
        dp = [[-1e18] * (p + 1) for _ in range(2 * m)]
        dp[i][1] = 0.0

        for j in range(i + 1, i + m):
            for k in range(2, p + 1):
                best_val = -1e18
                for t in range(i, j):
                    if dp[t][k - 1] > -1e17:
                        gap = a[j] - a[t]
                        best_val = max(best_val, dp[t][k - 1] + math.sin(gap))
                dp[j][k] = best_val

        for j in range(i + 1, i + m):
            for k in range(1, p + 1):
                if dp[j][k] > -1e17:
                    gap = (a[i] + 2 * math.pi) - a[j]
                    best = max(best, dp[j][k] + math.sin(gap))

    # area factor: (R^2 / 2), R = 1000 m
    best *= 0.5 * 1000 * 1000
    print(best)

if __name__ == "__main__":
    solve()
```DP 阵列跟踪以固定起始角度锚定的部分多边形。 三重嵌套循环反映了先前点的过渡，扩展了有效的递增顶点序列。 最后的循环通过将边添加回移动的起始角度来闭合多边形$2\pi$，它正确地模拟了圆形环绕。 

一个常见的实施陷阱是忘记必须循环处理角度。 如果没有重复，跨越 360 度边界的转换就会破坏顺序。 另一个微妙的问题是直接在内部使用度数`sin`，即使 DP 结构保持正确，它也会默默地产生错误的几何形状。

 ### 示例 1

 输入角度：`[0, 120, 180, 240, 270]`， 和`p = 4`。 

我们固定从 0 开始。 

| 步骤| 选定的顶点 | 最后一个顶点 | k | 当前值|

 闭合边加上 sin(90°)。 

该迹线显示了 DP 如何仅累积来自角间隙的贡献，以及当最后一个间隙较大时，最终的闭合边缘如何主导结构。

 输入：`[0, 90, 180, 270]`,`p = 3`。 

| 步骤| 选定的顶点 | 最后一个顶点 | k | 价值|

 | 开始| [0]| 0 | 1 | 0 |

 闭合边加上 sin(90°)。 

这表明，当点彼此相对时，某些边没有任何贡献，并且当存在更好的配置时，DP 自然会避免依赖此类转换。

 ## 边缘情况

 所有点均匀分布的配置凸显了贪婪策略中微妙的失败模式。 每个间隙都是相同的，因此任何子集看起来都是局部最优的，但只有完全对称才能产生最大面积。 DP 正确评估所有链长度并捕获该全局最优值。 

当点彼此完全相对时，间隙的正弦变为零。 幼稚的实现可能会错误地将其视为无效或跳过它，但在这个公式中，它只是一个中立的贡献。 DP仍然正确地考虑通过这些点的路径，并可以根据后续结构决定它们是否有用。 

当 p 等于 n 时，该算法有效地计算所有点的最佳循环排序。 DP 仍然有效，因为它从不假设更少的选择是首选，并且它统一评估所有 k 到 p。
