 # 问题理解

 任务是选择将多少勺热水和冷水放入杯子中，以使所得混合物的温度恰好为 80 度。 热水有温度`t1`，冷水有温度`t2`，所需的输出是一对卷`v1`和`v2`。 在所有可能的配对中，我们需要使用勺子总数最少的一对。 

混合规则规定混合后的总热量必须与两个温度的加权平均值相匹配。 对于这个问题，这意味着：`t1 * v1 + t2 * v2 = 80 * (v1 + v2)`约束告诉我们，热水温度永远不会低于 80，冷水温度始终低于 80。这些值足够小，即使检查许多组合也可以满足要求，但方程有足够的结构可以在常数时间内直接求解。 无需模拟或搜索。 

主要的边缘情况来自于使混合物的一侧变得不必要或使比例变得非常简单的温度。 如果`t1`已经80度了，仅热水就已经达到了所需的温度。 用于输入`80 20`，正确的输出是`1 0`。 仅基于一般比率公式的粗心解决方案可能会被零除，因为`t1 - 80`变为零。 

另一种极端情况是温差不互质。 用于输入`100 20`，差异是`20`和`60`。 原始比例为`v1 : v2 = 60 : 20`，但最小的有效对是`3 : 1`。 不减少分数的解决方案将输出不必要的大值。 

第三种情况是两个温差的公约数已经大于一，但其中一侧接近目标值。 用于输入`81 79`，所需比例为`1 : 1`，所以答案是`1 1`。 仅从一侧搜索或使用浮点计算可能会在此处引入舍入错误。 

# 方法

 一个简单的方法是尝试每对勺子的数量。 我们可以迭代所有`v1`和`v2`0到1000之间的值，检查是否满足等式，并保留具有最小和的对。 这是正确的，因为每个允许的答案都会被考虑。 最坏的情况检查大约一百万对，因为大约有`1001 * 1001`组合。 

蛮力方法适用于给定的限制，但它隐藏了问题的数学结构。 如果允许的勺子数量变得更多，组合的数量将呈二次方增长并很快变得不切实际。 

有用的观察结果来自于重新排列温度方程：`t1 * v1 + t2 * v2 = 80 * v1 + 80 * v2`移动项给出：`(t1 - 80) * v1 = (80 - t2) * v2`左侧描述了热水将温度升高到 80 度以上的程度，右侧描述了冷水将温度降低到 80 度以下的程度。这两种效应必须精确平衡。 

这给出了两个体积之间的直接比率。 热水量必须与`80 - t2`，而冷水量必须与`t1 - 80`。 通过最大公约数减小该比率可以得到最小的可能整数解。

 # 算法演练

 1. 读取热水和冷水温度。 
2. 检查热水温度是否正好为 80。在这种情况下，添加任意量的冷水只会使温度偏离目标，因此一勺热水和零勺冷水是最小的有效答案。 
3. 计算两个温差：`hot_difference = t1 - 80`和`cold_difference = 80 - t2`。 这些值代表每种类型的水使混合物温度偏离目标的程度。 
4. 求两个差值的最大公约数。 将两个值除以该除数会减小比率，同时保持平衡方程成立。 
5、输出`cold_difference / gcd`作为热水量和`hot_difference / gcd`就像冷水的量一样。 如此设置这些值是因为当冷水远低于 80 时需要更多的冷水，而当热水远高于 80 时需要更多的热水。 

为什么有效：每个有效的混合物都必须满足方程`(t1 - 80) * v1 = (80 - t2) * v2`。 这意味着两个体积必须具有相同的比例以及相反的温差。 该算法精确地构造该比率并除以最大公约数，产生满足方程的最小正整数对。 由于任何其他有效对都将是该减少对的倍数，因此不能存在更小的总交易量。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t1, t2 = map(int, input().split())

    if t1 == 80:
        print(1, 0)
        return

    a = t1 - 80
    b = 80 - t2

    g = __import__("math").gcd(a, b)

    print(b // g, a // g)

if __name__ == "__main__":
    solve()
```第一部分处理热水已经达到目标温度的特殊情况。 通式假设热水贡献80以上的正热量，因此这种情况需要单独处理。 

变量`a`和`b`存储与目标温度的两个偏差。 该方程表示热水量与冷水偏差相关，冷水量与热水偏差相关，这就是为什么最终输出以相反的顺序使用它们。 

最大公约数用于减小比率。 如果没有这种减少，答案仍然会满足方程，但不会有最小可能的勺子总数。 

所有计算都使用整数，因此不存在浮点精度问题。 这些值也远低于 Python 的整数限制，因此不必担心溢出。

import sys
import io
import math

def solve_data(inp: str) -> str:
    old_stdin = sys.stdin

 # 边缘情况

 用于输入`80 20`，算法立即检测到热水温度等于所需温度。 它输出`1 0`，因为仅一勺热水就能产生 80 度的混合物。 仅使用公式的实现可能会失败，因为热温差为零。 

用于输入`100 20`，算法计算`hot_difference = 20`和`cold_difference = 60`。 最大公约数为 20，因此减少的比率为`60 / 20 = 3`和`20 / 20 = 1`。 输出是`3 1`，使用最少数量的勺子。 

用于输入`81 79`，算法计算`hot_difference = 1`和`cold_difference = 1`。 它们的最大公约数是 1，因此不需要约简。 输出`1 1`表明距目标距离相等需要两种水量相等。
