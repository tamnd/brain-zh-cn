 ## 解决方案
 ## 问题理解

 我们需要将给定的正整数写为最多五个整数立方的和。 输入的数字可能非常大，最多可达$10^{100000}$，所以它不能适合普通的整数类型。 输出是最多五个整数的列表，其立方加起来等于输入，或者`-1`如果找不到这样的表示。 

数字的大小改变了整个方法。 对可能的立方根进行线性扫描是不可能的，因为即使存储输入也已经需要 100000 个十进制数字。 该算法必须处理大整数并且仅使用少量算术运算。 Python 内置的任意精度整数在这里很适合，因为与算术本身的成本相比，操作数量很小。 

一个常见的错误是试图寻找小立方根。 例如，对于输入`1000000000000`，检查立方体直到数字的立方根仅适用于普通大小的整数，但这里输入的长度使得这种枚举毫无意义。 另一个错误是假设只有正立方才有用。 负立方体是必不可少的，因为它们允许取消大项。 

关键的边缘情况是小值和余数不寻常的值。 用于输入`1`，正确答案是一个立方体，`1^3`。 在处理余数之前始终减去大结构的方法可能会意外地创建不必要的负值或在处理小数时失败。 用于输入`5`，答案可以是五份`1`，而仅基于除以六的构造还必须正确处理剩余的残数。 

## 方法

 蛮力方法会尝试在数字的立方根周围找到五个整数，并测试每种可能的组合。 这是正确的，因为检查每个可能的元组最终会找到一种表示（如果存在）。 问题在于可能性的数量。 如果该数字的大小约为$M$，大约有$M^{1/3}$可能的立方根，五个嵌套选择大致创建$M^{5/3}$组合。 和$M=10^{100000}$，这甚至是不可能的。 

有用的观察来自于身份$$(y+1)^3+(y-1)^3+(-y)^3+(-y)^3=6y$$这意味着任何能被六整除的数字都可以用四个立方写出来。 每个整数都有一个从 0 到 5 模六的余数，并且每个这样的余数本身就是一个模六的整数立方。 我们可以先删除余数，然后将恒等式应用于剩余的可整除部分。 

整个问题变成了恒定数量的大整数运算。 我们找到一个小立方体$r^3$与输入模六具有相同的余数，计算$y=(x-r^3)/6$，并使用身份$6y$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(M^(5/3)) | O(1) | O(1) | 太慢了 |
 | 最佳| O(d^2) 其中 d 是位数 | O(d) | 已接受 |

 ## 算法演练

 1. 计算输入数模六的余数。 模六的立方涵盖了所有可能的余数，因此选择一个小整数`r`从`0`到`5`其立方体具有相同的余数。 
2. 减法`r^3`从数字来看。 剩余值保证能被六整除，因为两个值具有相同的模六余数。 
3.将剩余值除以六得到`y`。 
4. 使用身份$$(y+1)^3+(y-1)^3+(-y)^3+(-y)^3=6y$$并附加`r`作为第五个立方体。 如果`r`为零，则不需要打印，因为允许的立方体较少。 

不变的是，在第二步之后，剩余的值恰好是六的倍数。 第四步中的恒等式用四个立方表示倍数，而去除的余数则用一个立方表示，因此最终的和总是等于原始数字。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    x = int(input().strip())

    r = None
    for i in range(6):
        if (i * i * i - x) % 6 == 0:
            r = i
            break

    ans = []

    if r != 0:
        ans.append(r)

    y = (x - r * r * r) // 6

    if y != 0:
        ans.extend([y + 1, y - 1, -y, -y])

    if not ans:
        ans.append(0)

    print(len(ans))
    print(*ans)

if __name__ == "__main__":
    solve()
```该程序首先仅搜索六个候选者，因为模六的余数只有六种可能性。 这与输入大小无关。 

变量`y`最多可以包含 100000 个数字，但 Python 整数可以直接处理这个问题。 表达式`(x - r * r * r) // 6`是安全的，因为前面的循环保证了可分性。 

什么时候`y`为零，四个立方体恒等式会产生冗余的零项。 该代码忽略了它们，只打印必要的余数立方体。 答案仍然满足五个数字的限制。 

## 工作示例

 用于输入`5`，所选择的余数立方为：

 | x| r | y | 输出立方体|
 | ---| ---| ---| ---|
 | 5 | 5 | 0 | 5 |

 该算法认识到`5^3`具有相同的余数`5`模六因为`125 mod 6 = 5`。 由于剩余部分为零，因此只有立方体`5^3`是需要的。 

用于输入`17`，我们得到：

 | x| r | y | 输出立方体|
 | ---| ---| ---| ---|
 | 17 | 17 5 | -19 | -19 5、-18、-20、19、19 |

 这是一个有效的结构，因为四个大立方体的总和为$6y$，最后的立方体恢复了去除的残留物。 输出不需要与样本匹配，只需满足方程即可。

 ## 边缘情况

 用于输入`1`，算法发现`r = 1`， 所以`y = 0`。 它只打印`1`，并且立方之和恰好为一。 这避免了从一般恒等式中产生不必要的术语。 

用于输入`6`，余数为零，所以`r = 0`和`y = 1`。 生成的立方体是`2, 0, -1, -1`，其立方总和为$$8+0-1-1=6$$零项可以省略，但保留或删除它并不影响正确性。 

对于非常大的值，该算法从不将数字转换为数字或迭代其大小。 它仅执行恒定数量的算术运算，因此 100000 位数字的输入的处理方式与小输入相同。
