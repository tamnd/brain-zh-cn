 ## 解决方案
 ## 问题理解

 输入是一个乱序的字符集合，最初来自于一个接一个地写几个表情符号。 字符顺序丢失，但每个字符出现的总数被保留。 任务是恢复任何可能的表情符号列表，这些表情符号可以准确地产生这个多组字符，然后打印每个恢复的表情符号并以`LOL`。 

重要的细节是字符的顺序并不重要。 我们不是在输入中搜索子字符串。 我们正在解决一个重建问题，其中唯一可用的信息是每个字符的频率。 

输入长度可达10000个字符。 尝试所有可能的表情符号组合的解决方案很快就会变得不可能，因为组合的数量随着表情符号的数量呈指数增长。 由于只有 16 种可能的表情符号类型，因此预期的解决方案必须利用它们的字符结构而不是输入长度。 计算字符数并进行恒定大小的算术就足够了，因为问题的昂贵部分不是字符串长度而是找到有效的分解。 

一些边缘情况可能会破坏简单的实现。 一个常见的错误是假设表情符号可以通过外观贪婪地删除。 例如，输入```
:-0
```包含一个零、一个破折号、一个冒号。 只能代表`:-0`， 不是`:-`再加上其他东西，因为不存在仅由剩余部分组成的表情符号。 

另一个棘手的情况是两个包含括号的表情符号之间的交互。 考虑：```
;:((
```粗心的做法可能会决定`;-)`或者`;-(`由于分号而必须出现。 正确的解释是：```
;-(
:(
```分号只是告诉我们其中一个分号表情符号存在，而括号和冒号则决定其余选择如何平衡。 

最后一个边缘情况是带有重复符号的长表情符号：```
[:|||:]
```三个竖条是该表情符号所独有的，但冒号字符与许多其他表情符号相同。 仅计算冒号的数量是不够的。 方括号标识了这些表情符号的确切数量。 

## 方法

 直接方法是将 16 个表情符号中的每一个视为一个变量，并尝试每个表情符号的所有可能数字。 对于每一个可能的选择，我们都会将结果字符频率与输入频率进行比较。 这是正确的，因为每个有效答案都对应于一个这样的选择。 

问题在于搜索空间。 如果我们有多达 10000 个字符，甚至几个表情符号只有几个可能的值，那么组合的数量就会变得巨大。 蛮力搜索会重复探索相同的不可能状态，并且无法轻松地适应约束。 

表情符号的结构提供了更好的路线。 大多数表情符号都包含其他表情符号不包含的字符。 例如，`\`,`P`,`D`,`C`,`8`,`E`,`%`,`X`,`~`,`[`和`]`每个人都会立即识别出一种表情符号类型。 一旦知道这些计数，只有六个表情符号仍然不明确：```
;-)
;-(
:)
:(
:-0
:-|
```其余方程足够小，可以直接求解。 的计数为`0`和`|`给`:-0`和`:-|`。 分号、右括号和左括号计数为剩余的四个表情符号创建了一个小系统。 该系统有一个自由变量，因此有效范围内的任何值都有效。 

关键的观察是我们不需要重建原始顺序。 字符频率已经包含足够的信息来恢复有效的多组表情符号。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 可能的表情符号数量呈指数增长 | O(1) | O(1) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算输入字符串中每个字符的出现次数。 重建仅取决于这些频率，因此可以完全忽略原始顺序。 
2. 使用仅出现在一个表情符号中的字符直接确定其数量。 人物`\`,`P`,`D`,`C`,`8`,`E`,`%`,`X`,`~`,`[`和`]`立即揭晓其对应表情符号的数量。 方括号计数给出了`[:|||:]`，波浪号计数给出了`:~(`。 
3. 计算数量`:-0`来自零数量的表情符号。 每个零都必须来自`:-0`,`8-0`， 或者`%0`，而后两者已经确定。 
4. 计算数量`:-|`来自竖条数量的表情符号。 剩下的每组三个条都属于`[:|||:]`，所以剩余的条必须来自`:-|`。 
5. 解决剩下的四个表情符号计数。 让`a`,`b`,`c`， 和`d`代表`;-)`,`;-(`,`:)`， 和`:(`。 分号计数给出`a + b`，右括号计数给出`a + c`，以及删除后左括号的计数`:~(`给出`b + d`。 

选择最小有效值`a`。 如果`b + d`太小，无法覆盖所有分号，请增加`a`因此。 这使得所有四个值都非负。 
6. 根据恢复的数量输出每个表情符号，并以`LOL`。 

为什么有效：每种表情符号类型都以其对字符数的贡献来表示。 独特的字符固定了九种表情符号类型，没有歧义。 其余六种类型受精确频率方程的约束。 最后四个方程描述了唯一剩余的不确定性，并选择任意值`a`在有效范围内为所有其他变量生成非负值，同时保留每个字符计数。 由于最终的多重集与原始频率相匹配，因此生成的表情符号是有效的恢复。 

## Python 解决方案```python
import sys
from collections import Counter

input = sys.stdin.readline

def solve():
    s = input().rstrip("\n")
    cnt = Counter(s)

    ans = []

    def add(name, amount):
        for _ in range(amount):
            ans.append(name)

    # Unique-character emoticons
    add(":-\\", cnt["\\"])
    add(":-P", cnt["P"])
    add(":D", cnt["D"])
    add(":C", cnt["C"])
    add("8-0", cnt["8"])
    add(":-E", cnt["E"])
    add("%0", cnt["%"])
    add(":-X", cnt["X"])
    add(":~(", cnt["~"])
    add("[:|||:]", cnt["["])

    # Determined by remaining unique symbols
    zero_count = cnt["0"] - cnt["8"] - cnt["%"]
    pipe_count = cnt["|"] - 3 * cnt["["]

    add(":-0", zero_count)
    add(":-|", pipe_count)

    # Remaining four emoticons
    semis = cnt[";"]
    close = cnt[")"]
    open_par = cnt["("] - cnt["~"]

    # b + d = open_par, a + b = semis, a + c = close
    a = max(0, semis - open_par)
    b = semis - a
    c = close - a
    d = open_par - b

    add(";-) ", 0)  # keeps the function shape clear, never adds output

    ans.extend([";-)"] * a)
    ans.extend([";-("] * b)
    ans.extend([":)"] * c)
    ans.extend([":("] * d)

    sys.stdout.write("\n".join(ans))
    sys.stdout.write("\nLOL\n")

if __name__ == "__main__":
    solve()
```该程序首先构建一个频率表，这是加扰操作后所需的唯一表示。 辅助函数用于从唯一字符直接获知计数的表情符号。 

的计数为`:-0`和`:-|`在减去共享这些字符的表情符号的贡献后计算。 这个顺序很重要。 如果我们直接使用零或条的总数，程序会意外地创建额外的表情符号。 

最后四个计数是通过代数得出的。 的选择`a`是保持的最小值`d`非负数。 任何较大的有效值都可以，但最小的有效值使构造具有确定性并且易于验证。 

输出部分使用重复列表扩展而不是重复打印。 当输入包含许多表情符号时，这可以避免不必要的 I/O 开销。

 ## 边缘情况

 对于这个案例：```
:-0
```该程序看到一零。 的计数为`8`和`%`都为零，所以零属于`:-0`。 答案恰好包含一个`:-0`，并且没有发明其他表情符号。 

对于不明确的括号情况：```
;-(:(
```计数由一个分号、两个左括号和一个右括号组成。 方程给出一`;-(`和一个`:(`。 该算法不会贪婪地消耗分号。 它解决了整套人物关系。 

对于长表情符号：```
[:|||:]
```方括号计数立即给出 1`[:|||:]`。 该算法在计算之前减去它的三个垂直条`:-|`，防止三个条被误解为三个独立的管道表情符号。 

对于包含多次重复相同表情符号的大型输入，该算法仅在扫描时递增计数器，然后重复答案列表。 它从不执行搜索，因此运行时间随着输入大小线性增长。
