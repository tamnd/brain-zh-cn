 ## 解决方案
 ## 问题理解

 该电路由几个相同的未知电阻器组成。 每级包含一个已知电阻和一个神秘电阻并联，然后所有级串联。 输入给出了级数、整个电路的总电阻以及每级的已知电阻值。 任务是恢复神秘电阻的阻值。 

如果未知电阻为`x`，具有已知电阻的单级的贡献`ri`是$$\frac{ri \cdot x}{ri + x}$$因为两个电阻是并联的。 总电路电阻是所有级上这些值的总和，因此我们需要找到`x`这样$$\sum_{i=1}^{k}\frac{r_i x}{r_i+x}=R$$级数可以达到1000级，并且每个已知电阻都可以很大。 这排除了尝试许多可能的电阻值或使用许多项执​​行符号方程求解的方法。 有用的特性是所需的精度仅为`10^-6`，因此大约 60 到 100 次迭代的迭代数值方法很容易足够快。 解决方案围绕`O(k log precision)`操作非常适合，因为它每次迭代最多只对最多 1000 个值执行简单求和。 

少数情况下可能会破坏粗心的实现。 一个常见的错误是假设答案总是接近已知的最大电阻。 例如，使用输入```
1 5
10
```正确的输出是`10.000000`，因为唯一的阶段有阻力$$\frac{10x}{10+x}=5$$这给出了`x=10`。 固定上限，例如`100000`会在更大的可能答案上失败。 

另一个问题是过早停止二分搜索。 和```
3 11
3 12 30
```答案是`6.000000`。 几次迭代可能会找到看起来很接近但不满足所需精度的近似值。 函数变化平滑，因此多次迭代很便宜并且避免了这个问题。 

第三种边缘情况是目标恰好是已知电阻之和的一半。 例如，```
2 10
10 10
```有答案`10`，因为每个平行对都贡献`5`。 算法必须允许上限达到该值，而不是当搜索间隔仅仅变小时就停止。 

## 方法

 一种直接的方法是尝试神秘电阻器的可能值并计算所得的总电阻。 由于阻力是一个连续值，我们无法准确枚举所有候选值，并且对精细网格的简单扫描将需要大量检查。 即使范围被限制为一百万个可能的值并且每​​次检查只需要`k`操作，最坏的情况已经需要大约 10 亿次操作`k=1000`。 

有用的观察结果是总电阻是未知电阻的单调函数。 什么时候`x`增加，每个单独的并联电阻$$\frac{r_i x}{r_i+x}$$也增加。 这意味着只有一个答案，我们可以对 的值使用二分查找`x`。 

蛮力方法之所以有效，是因为评估候选值很容易，但它会失败，因为通过逐个尝试值来找到足够准确的候选值的成本太高。 未知电阻和最终电路电阻之间的单调关系让我们在每次迭代后丢弃一半的搜索空间。 

搜索间隔可以从零开始。 通过重复加倍来动态找到上限，直到计算出的电阻至少变为`R`。 所要求的答案保证存在，因为最大可能的电路电阻接近所有已知电阻的总和，并且该语句保证目标不超过该值的一半。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(k * 尝试值的数量) | O(1) | O(1) | 太慢了 |
 | 最佳| O(k 对数精度) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 存储已知电阻并定义一个函数来计算所选神秘电阻值的总电路电阻`x`。 该函数将每一级的并联电阻相加，这给出了如果未知电阻器存在时电路将具有的电阻`x`。 
2. 从下限开始`0`和上限`1`。 将上限加倍，直到计算出的阻力至少达到目标`R`。 这会创建一个包含真实答案的区间，而无需对未知电阻器的大小进行任何假设。 
3. 在此区间重复二分查找。 取中间值并计算其产生的电路电阻。 如果结果小于`R`，未知电阻一定更大，因此将下限向上移动。 否则，未知电阻小于或等于该值，因此将上限向下移动。 
4. 执行足够的迭代，使间隔远小于所需的误差。 大约 100 次迭代就足够了，因为每次迭代间隔都会缩小一半。 
5. 输出最终的中点作为神秘电阻的估计值。 

其原理：计算出的总电阻相对于未知电阻严格增加。 每个二分搜索决策都是基于此顺序，因此当中点产生太小的阻力时，每个较小的值也无效。 当它产生太大的电阻时，再大的值也无效。 搜索区间始终包含真实答案，重复减半使区间收敛于该答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    k, R = map(int, input().split())
    r = list(map(int, input().split()))

    def calc(x):
        total = 0.0
        for v in r:
            total += v * x / (v + x)
        return total

    lo = 0.0
    hi = 1.0

    while calc(hi) < R:
        hi *= 2.0

    for _ in range(100):
        mid = (lo + hi) / 2.0
        if calc(mid) < R:
            lo = mid
        else:
            hi = mid

    print("{:.10f}".format((lo + hi) / 2.0))

if __name__ == "__main__":
    solve()
```这`calc`函数直接实现候选神秘电阻值的电气公式。 它使用浮点运算，因为答案不一定是整数并且所需的精度是小数。 

上限搜索是动态的而不是固定的。 这避免了依赖猜测的最大答案，并处理未知电阻器大于每个已知电阻器的情况。 由于所需的答案范围受到输入约束的限制，加倍很快就会完成。 

二分搜索运行固定次数的迭代，而不是检查 epsilon 条件。 这避免了精确的极端情况并提供了有保证的收缩量。 一百次迭代留下的精度远高于所需的精度`10^-6`。 

Python 浮点值在这里就足够了，因为最大的中间值足够小，并且最终答案只需要小数点后六位数字。

 ## 边缘情况

 对于单级情况```
1 5
10
```正在搜索的函数是$$f(x)=\frac{10x}{10+x}$$二分查找从小范围开始，扩大上限，直到函数至少达到`5`，然后收敛到`x=10`。 它不依赖于具有多个阶段。 

对于精确的边界情况```
2 10
10 10
```总已知电阻为`20`，而目标恰好是其中的一半。 正确答案是`10`。 在`x=10`，每个阶段贡献$$\frac{10\cdot10}{10+10}=5$$所以总数是`10`。 动态上限允许搜索包含该值。 

对于所有电阻都相等的情况，```
3 3
3 3 3
```答案是`1`。 每个阶段贡献$$\frac{3\cdot1}{3+1}=0.75$$总计是`2.25`，因此算法继续搜索，直到找到恰好给出的值`3`。 单调检查处理重复值，没有任何特殊情况。 

对于最大值，```
4 100000
100000 100000 100000 100000
```未知的电阻是`100000`。 初始上限太小，但加倍很快就达到包含答案的范围。 然后，搜索的工作方式与较小情况下的相同，这说明了为什么动态上限比硬编码限制更安全。
