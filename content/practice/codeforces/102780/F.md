 ## 解决方案
 ## 问题理解

 游戏是根据单词进行的，但字母的顺序并不重要。 一次移动只关心每个字母还剩下多少份。 如果一个字母出现多次，玩家可以删除一个副本，删除两个副本，或删除该字母的所有剩余副本。 使剩余字母总数为零的玩家获胜。 

输入是一个大写单词，最多 40 个字符。 输出表明，如果两个玩家都选择最佳移动，则哪个玩家具有获胜策略。 最初的问题来自2019年俄罗斯中部地区竞赛。 

较小的字长意味着对所有游戏状态的简单搜索一开始看起来是可能的。 然而，可能的状态数量会迅速增长，因为字母的每种不同分布都会产生不同的位置。 探索所有状态的解决方案可以接近指数时间，即使对于长度 40，这也是不必要的。我们需要找到每个字母计数的数学属性。 

主要的边缘情况来自于将移动视为普通删除。 粗心的解决方案可能会认为计数可被三整除的字母总是失败，因为删除一个或两个字母类似于外卖游戏。 这会失败，因为删除所有副本是一个特殊的举动。 例如，输入`AAA`有答案`Alice`。 计数为三，但爱丽丝可以立即删除所有三个字母。 

另一个常见的错误是忽略只出现一次的字母。 用于输入`A`，答案是`Alice`因为唯一的一步就是删除最后一个字母。 仅检查对或完整组的解决方案会错误地将其标记为失败。 

第三种边缘情况是整个单词没有单一的游戏价值。 用于输入`AB`，答案是`Bob`，因为每个字母都是独立贡献的，并且它们的效果相互抵消。 仅查看总长度的解决方案将错过这种交互。 

## 方法

 直接的方法是对当前的单词状态进行建模并递归地尝试每一个可能的动作。 对于每个字母，我们可以将其计数减一，如果可能的话将其减二，或者将其设置为零。 如果递归状态至少有一个动作导致失败状态，那么它就是胜利。 否则就是输了。 

这种强力方法是正确的，因为它完全遵循最佳游戏的定义。 问题在于州的数量。 由于有 26 个可能的字母数，即使是一个短单词也可以创建许多不同的分布。 最坏的情况是字母数量呈指数级增长，因为每个可能的删除子集都可以作为单独的状态出现。 

改变问题的观察是每种字母类型的行为都像一个独立的游戏组件。 这是一个标准的公正游戏情况，其中每个组件都有一个 Grundy 值，整个位置是通过对这些值进行异或确定的。 

只考虑出现的一个字母`c`次。 让`g(c)`为其 Grundy 值。 它的动作去`c - 1`,`c - 2`， 和`0`当这些动作存在时。 计算第一个值给出：

 | 计数 | 格兰迪价值|
 | ---| ---|
 | 0 | 0 |
 | 1 | 1 |
 | 2 | 2 |
 | 3 | 3 |
 | 4 | 1 |
 | 5 | 2 |
 | 6 | 3 |

 该模式每计数三次就会重复一次。 可被三整除的正计数的值为 3，而其他计数的值为等于其余数。 

整个单词只是 26 个字母值的异或。 如果异或不为零，爱丽丝可以移动到零异或位置并获胜。 如果异或为零，则每一步都会给鲍勃带来获胜位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳| O(n + 26) | O(26) | 已接受 |

 ## 算法演练

 1. 计算每个大写字母在单词中出现的次数。 游戏状态仅取决于这些频率，而不取决于字母的位置。 
2. 对于每个出现频率的字母`c`，计算其 Grundy 值。 如果`c`为零，则无任何贡献。 否则，使用`c % 3`并将余数零替换为值 3。 
3. 将所有 26 个值异或在一起。 异或结合了不同字母代表的独立游戏。 
4. 打印`Alice`当异或非零时。 打印`Bob`当异或为零时。 

最后一步起作用的原因是零异或位置在公正的组合游戏中失败。 非零异或位置总是可以移动到零异或位置，而零异或位置不能移动到另一个零异或位置。 

为什么它有效：

 每个字母频率都是一个独立的堆。 一次移动只会改变其中的一堆，不会影响其他的。 Grundy 值总结了一堆未来的所有可能。 因此，所有堆值的异或就是该字的完整值。 如果该值为零，则双方都面临失败状态。 如果它不为零，则当前玩家有一个使异或为零的举动，使对手处于失败状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()

    cnt = [0] * 26
    for ch in s:
        cnt[ord(ch) - ord('A')] += 1

    x = 0
    for c in cnt:
        if c:
            value = c % 3
            if value == 0:
                value = 3
            x ^= value

    print("Alice" if x else "Bob")

if __name__ == "__main__":
    solve()
```数组`cnt`存储独立的游戏组件。 它们只有 26 个，因此实现不需要模拟动作。 

Grundy 转换仅针对正频率进行。 零频率字母的值为零并且不影响异或。 对三的倍数进行特殊处理是必要的，因为一堆大小为 3 的堆并不等于一堆大小为 0 的堆。 删除所有字母的动作会改变重复模式。 

最终的异或存储在`x`。 Python 整数不会溢出，尽管这里的值无论如何都非常小。 输入包含一个单词，因此一次调用`readline`就足够了。 

## 工作示例

 对于`ZADACHA`，字母数为：

 | 信| 计数 | 格兰迪价值| 当前异或 |
 | ---| ---| ---| ---|
 | 一个 | 3 | 3 | 3 |
 | C | 1 | 1 | 2 |
 | d | 1 | 1 | 3 |
 | 哈 | 1 | 1 | 2 |
 | Z| 1 | 1 | 3 |

 最终的异或非零，所以爱丽丝获胜。 

为了`WORD`，计数为：

 | 信| 计数 | 格兰迪价值| 当前异或 |
 | ---| ---| ---| ---|
 | 西 | 1 | 1 | 1 |
 | 哦| 1 | 1 | 0 |
 | 右 | 1 | 1 | 1 |
 | d | 1 | 1 | 0 |

 最终的异或为零，所以鲍勃获胜。 

这些痕迹显示了为什么结果取决于字母频率而不是单词的原始顺序。

 ## 边缘情况

 用于输入`AAA`，该算法以频率 3 计数一个字母。 它的 Grundy 值为 3，因此异或为 3，并打印 Alice。 这可以处理删除所有副本比获取一份或两份副本更好的情况。 

用于输入`A`，计数为 1，Grundy 值为 1。异或非零，因此 Alice 通过删除唯一的字母立即获胜。 

用于输入`AB`，两个字母的频率均为 1，且贡献值均为 1。异或变为`1 ^ 1 = 0`，所以位置正在丢失。 每一步都只留下一个字母，而对手则删除最后一个字母。 

对于包含 40 个相同字母的单词，计数为 40。Grundy 值为`40 % 3 = 1`，所以位置获胜。 该算法处理最大输入大小，而不依赖于可能的移动次数。
