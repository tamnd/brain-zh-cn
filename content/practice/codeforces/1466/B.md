 ## 解决方案
 ## 问题理解

 该任务要求我们最大化歌曲的多样性，其中歌曲表示为正整数（音符）序列。 多样性只是序列中不同音符的数量。 Athenaeus 最初创作了这首歌，但每个音符可以选择增加 1。我们的目标是确定在此规则下可实现的最大可能数量的不同音符。 

输入提供多个测试用例。 每个测试用例都以音符数开始\(n\)，后跟一个排序列表\(n\)代表音符的整数。 约束表明\(n\)可以大到\(10^5\)在单个测试用例和所有测试用例的总和中\(n\)所有测试用例最多也\(10^5\)。 这排除了具有 \(O(n^2)\) 复杂度的算法，因为这可能需要最多\(10^{10}\)运营。 因此，任何解决方案都必须以大致线性或每个测试用例的 O(n log n) 时间运行。 

边缘情况包括所有音符都相等的序列。 例如，如果输入是`1 1 1 1`，简单地增加一些音符就会产生序列`1 2 3 4`，实现最大多样性 4。粗心的方法可能只计算原始不同值而不考虑增量选项，从而产生错误的输出 1。另一个边缘情况是最小输入`1`其中不可能有增量，多样性自然为1。 

## 方法

 暴力方法可以尝试递增或保留每个音符的每种组合，然后计算所得的不同数字。 这是正确的但不可行：\(n = 10^5\)， 有\(2^{10^5}\)组合，远远超出计算极限。 

关键的观察结果是笔记是排序的。 这种结构允许一种贪婪的方法：按顺序处理音符，并为每个音符分配尚未出现的最小可能值。 对于每个注释，首先尝试保持不变。 如果该数字已经出现，则将其增加 1。这可确保每个音符对不同集合的贡献最大，而不超过 1 增量津贴。 

这种方法之所以有效，是因为数组已排序并且增量很小（最多 1）。 通过尝试在每一步分配最小的可用数量，我们可以避免冲突并确保不同值的最大数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 贪心排序 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一个集合或字典来跟踪哪些音符值已被使用。 
2. 按排序顺序遍历笔记。 
3. 对于每个音符，首先尝试使用其原始值。 如果集合中没有，请添加。 
4. 如果原始值已被使用，请将注释加 1，然后尝试添加该值。 
5. 处理完所有音符后，集合的大小就是可实现的最大多样性。 
6. 对每个测试用例重复此操作。 

为什么有效：在每一步中，我们都会将尽可能小的未使用音符分配给当前元素。 由于数组已排序，所有未来的音符都大于或等于当前的音符。 因此，分配最小的可用值可以保证我们以后不会阻止潜在的不同值。 没有任何最佳分配能够比这个贪婪过程产生更多不同的值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_diversity(notes):
    used = set()
    for note in notes:
        if note - 1 > 0 and (note - 1) not in used:
            used.add(note - 1)
        elif note not in used:
            used.add(note)
        else:
            used.add(note + 1)
    return len(used)

t = int(input())
for _ in range(t):
    n = int(input())
    notes = list(map(int, input().split()))
    notes.sort()
    print(max_diversity(notes))
```该解决方案首先读取测试用例的数量。 对于每个测试用例，都会读取注释序列并对其进行排序，以确保贪婪分配正确工作。 这`max_diversity`函数使用一组来跟踪已使用的数字，尝试为每个音符分配尽可能小的值。 微妙之处包括考虑`note - 1`仅当它是正数时，因为音符必须保持正整数。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        notes = list(map(int, input().split()))
        notes.sort()
        used = set()
        for note in notes:
            if note - 1 > 0 and (note - 1) not in used:
                used.add(note - 1)
            elif note not in used:
                used.add(note)
            else:
                used.add(note + 1)
        output.append(str(len(used)))
    return "\n".join(output)

 ## 边缘情况

 用于输入`1\n3\n2 2 2\n`，算法首先尝试`2-1=1`对于第一个音符，然后分配`2`和`3`到其余的注释。 最终使用的集合是`{1,2,3}`，给出多样性 3。仅计算不同原始音符的简单方法将返回 1，这证明了带有增量的贪婪分配的重要性。 

对于最小的输入`1\n1\n1\n`，只有一个注释。 该算法尝试`1-1=0`但丢弃它，因为它是非正数，分配`1`，多样性为 1。这证实了算法正确处理下边界。
