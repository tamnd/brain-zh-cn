 ## 解决方案
 ## 问题理解

 机器人每天搬运固定序列的箱子。 在两天之间，它恰好接受一次润滑，并且我们可以选择该润滑的时刻。 盒子一移动就开始损坏机器人，并且每小时都会造成损坏，直到下次润滑。 任务是在盒子的循环顺序中选择最佳点，以使一天内的总损坏尽可能小。 

输入包含多个独立的场景。 对于每个盒子，我们都会收到盒子的数量及其质量。 输出是选择最佳润滑力矩后可能的最小总损坏。 

约束条件允许所有场景下的盒子总数达到$2 \cdot 10^5$。 这排除了在重新计算整个损坏时检查每个可能的润滑位置，因为这需要$O(n^2)$工作并且可以到达约$4 \cdot 10^{10}$运营。 我们需要每个场景的线性解决方案。 

棘手的部分是润滑力矩是圆形的。 最后一个框之后的时刻与第一个框之前的时刻相同，因此将序列视为简单的线可能会引入额外的情况或错过最佳位置。 

例如，考虑：```
1
3
5 1 5
```正确答案是：```
16
```粗心的实施可能只检查盒子之后的位置，而忘记第一个盒子之前的润滑也是有效的。 对于这种情况，在第二个框之后达到最小值，但循环解释使得可以正确导出递归。 

另一个常见错误是使用 32 位整数。 为了：```
1
5
10000000 10000000 10000000 10000000 10000000
```答案比$2^{31}$，因此窄整数算术的实现将会溢出。 

## 方法

 直接的解决方案是模拟每个可能的润滑时刻。 对于循环序列中的每个可能的切割，我们可以计算每个盒子持续损坏机器人的时间并添加相应的贡献。 有$n$可能的削减，并计算其中之一需要$O(n)$, 给予$O(n^2)$时间。 和$n=100000$，这远远超出了可能的范围。 

有用的观察结果是相邻的润滑位置几乎相同。 如果我们将润滑点向前移动一步，除了我们刚刚经过的盒子之外，每个盒子都会保持相同的损坏时间。 该盒子从造成一小时的损害变为造成整个周期的损害。 

让$cur$是在第一个盒子之前进行润滑时造成的损坏。 将润滑点移至箱后$i$将该盒子的贡献增加$n-1$小时。 原因是下一个循环中该箱体从润滑前的最后一个箱体变为润滑后的第一个箱体。 因此，变化是：$$cur = cur + (n-1)\cdot a_i$$这给出了一个简单的递归。 我们计算第一个位置一次，然后通过序列旋转润滑点，同时保持当前答案。 遇到的最小值就是结果。 

蛮力之所以有效，是因为每个可能的位置都是独立检查的。 循环之所以有效，是因为连续位置仅相差一项可预测的调整。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算第一个盒子之前进行润滑时的损坏。 第一个盒子会损坏机器人$n$小时，第二个为$n-1$小时，依此类推，直到最后一个盒子，损坏一小时。 这给出了旋转过程的起始值。 
2. 将此值存储为当前最小答案。 第一个位置是有效候选位置，因此必须包含在内。 
3.将润滑点移至箱体前$i$到后箱$i$。 通过添加更新当前伤害$(n-1)\cdot a_i$。 这是由于将剪切移动一个位置而引起的唯一变化。 
4. 每次轮班后，将当前损坏与迄今为止找到的最佳答案进行比较。 最小值即为最佳润滑力矩。 

为什么它有效：

 在按顺序旋转切割时，每个可能的润滑位置都会出现一次。 递归给出了两个相邻位置之间的精确差异，因此维护的值始终是当前切割的真实伤害。 由于所有候选人都经过检查并保留最小值，因此最终答案必须是最优的。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        cur = 0
        for i, x in enumerate(a):
            cur += x * (n - i)

        best = cur

        for i in range(n):
            cur += (n - 1) * a[i]
            if cur < best:
                best = cur

        ans.append(str(best))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```初始循环在第一个盒子之前建立润滑损坏。 对于第一个框，系数是$n$，第二个是$n-1$，一直持续到最后一个系数变为$1$。 

第二个循环应用旋转公式。 每一步都会将润滑点移过一个框，因此唯一需要的更新是添加$(n-1)$乘以盒子的质量。 

Python 整数自动处理涉及的大值。 除了输入序列之外，该实现不存储任何额外的数组，从而保持较小的内存使用量。

 ## 边缘情况

 对于最小尺寸的情况：```
1
2
1 1
```初始值为$1 \cdot 2 + 1 \cdot 1 = 3$。 移动润滑点无法改善它，因此答案仍然是 3。算法会处理这个问题，因为在任何旋转之前都会检查初始位置。 

对于同等质量：```
1
4
7 7 7 7
```每个旋转都有相同的形状，因此每个位置都会造成相同的伤害。 循环仍然有效，因为每次更新都会添加相同的数量，并且最小值仍然有效。 

对于圆形边界：```
1
3
5 1 5
```该算法首先在第一个盒子之前评估润滑，然后轮流遍历所有可能的切割。 它从不假设最佳点必须在特定框之后，因此它可以正确找到最小值。
