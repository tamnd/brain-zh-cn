 ## 解决方案
 ## 问题理解

 这个问题要求我们恢复虎猫类生物缺失的中尾的可能长度。 三个尾长分别是`a`,`b`， 和`c`， 在哪里`a < b < c`。 我们已经知道最短和最长的长度，但缺少中间的长度。 我们还被给予`m`，这是出现在中的所有不同质因数的乘积`a * b * c`，也称为乘积的根式。 我们需要最小和最大的可能值`b`，或报告不存在这样的值。 最初的问题来自 Codeforces Gym 106190。 

输入包含几个独立的案例。 每个案例给出`m`,`a`， 和`c`。 答案是一对值：最小有效中尾长度和最大有效中尾长度。 中间长度必须严格保持在两个已知长度之间。 

重要的限制是`a`和`c`至多是`10^6`， 尽管`m`可以大到`10^18`。 这立即排除了尝试所有可能的因式分解`m`或做与其价值成正比的工作。 上界为`c`关键是：每一个可能的答案`b`小于`10^6`，所以我们只需要推理相对较小的候选数。 

主要的边缘情况来自于将激进的产品与原始产品混淆。 一个数可以多次包含同一个素数，但根式只关心素数是否存在。 

例如：```
Input:
210 5 21

Output:
6 20
```粗心的方法可能会尝试要求`b`恰好是缺少素因数的乘积。 缺失的素因数是`2 * 3 = 6`， 但`20`也有效，因为它只添加素数`2`再次。 激进分子依然存在`2 * 3 * 5 * 7`。 

另一个棘手的情况是当`a`或者`c`已经包含一个不存在于的素数`m`。```
Input:
35 5 7

Output:
-1 -1
```这里`a * c = 35`，所以根式已经包含`5`和`7`。 价值`m`只有`5`和`7`也是如此，但是之间的任何中间值`5`和`7`是不可能的，因为唯一的候选人是`6`，其根式加上素数`2`。 

第三种情况是当`m`包含双方都不包含的质数。```
Input:
12 2 6

Output:
-1 -1
```产品`a * c`已经给出了质因数`2`和`3`。 唯一可能的中间值将介于`2`和`6`，但是该区间内的每个数字要么引入了禁止素数，要么没有正确改变根式。 

## 方法

 直接的解决方案是测试每一个可能的中尾长度。 对于每一个`b`从`a + 1`到`c - 1`，我们可以计算`a * b * c`并将其与`m`。 这是正确的，因为该范围包含所有可能的答案。 问题在于重复工作量。 如果每个测试都有`c`附近`10^6`，检查每个候选者并分解每个候选者对于许多测试用例来说成本太大。 

关键的观察是我们实际上并不需要整个产品。 根式仅取决于出现的素数。 一、因素`a`和`c`并收集他们已经贡献的所有主要因素。 如果这些素数之一不在`m`，答案是不可能立即出现。 

现在考虑素数`m`。 其中一些已经存在于`a * c`。 其余素数必须出现在`b`。 打电话给他们的产品`need`。 每个有效`b`必须是的倍数`need`。 

还有一项限制。`b`不能引入任何外部素数`m`，因为这会使最终的根式太大。 所以删除需要的部分后`need`，剩余的乘数只能使用来自的素数`m`。 

自从`b < 10^6`，我们可以生成所有素因数属于允许集合的数，并找到最小和最大的倍数`need`在区间内`(a, c)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((c-a) * sqrt(c)) | O((c-a) * sqrt(c)) | O(1) | O(1) | 太慢了|
 | 最佳| 每次测试的 O（生成的候选者数量），以低于 10^6 的值为界 | O(候选人数量) | 已接受 |

 ## 算法演练

 1.因素`a`和`c`并存储它们独特的素因数。 我们需要这些素数，因为它们已经被迫出现在最后的部首中。 
2.因素`m`成其独特的素因数。 如果`m`包含一个质数较小的边数不解释，我们稍后会强制它变成`b`。 
3. 检查每个质因数`a`和`c`存在于`m`。 如果失败，则没有值`b`可以从根式上去掉一个多余的素数。 
4. 计算`need`，每个素数的乘积`m`缺少的`a * c`。 这是所需的最低主要贡献`b`。 
5. 生成仅由以下素因数构成的所有值`m`。 对于每个生成的值`x`，乘以`need`如果它保持在以下水平`c`。 结果是候选的中间长度。 
6. 在所有候选者中严格大于`a`并且严格小于`c`，保留最小值和最大值。 

一代人工作的原因是每一个有效的`b`可以分为两部分。 一部分包含必须添加的缺失素数，另一部分仅增加已允许素数的幂。 生成器准确地创建了这些可能的额外部件。 

为什么它有效：最后的根式是质因数的并集`a`,`b`， 和`c`。 检查保证`a`和`c`不包含禁用素数。 所需部分保证`b`提供每一个缺失的素数`m`。 生成的乘数无法添加新的素数，因此每个接受的候选素数都恰好具有所需的根式。 每个有效`b`也可以用这种形式表示，因此不会错过任何答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def factor(x):
    res = []
    d = 2
    while d * d <= x:
        if x % d == 0:
            res.append(d)
            while x % d == 0:
                x //= d
        d += 1 if d == 2 else 2
    if x > 1:
        res.append(x)
    return res

def solve_case(m, a, c):
    fm = set(factor(m))
    fa = factor(a)
    fc = factor(c)

    for p in fa + fc:
        if p not in fm:
            return -1, -1

    need = 1
    base = set(fa + fc)
    for p in fm:
        if p not in base:
            need *= p

    allowed = list(fm)
    limit = c // need

    vals = [1]
    for p in allowed:
        cur = []
        for x in vals:
            y = x
            while y * p <= limit:
                y *= p
                cur.append(y)
        vals += cur

    ans_min = 10**18
    ans_max = -1

    for x in vals:
        b = x * need
        if a < b < c:
            ans_min = min(ans_min, b)
            ans_max = max(ans_max, b)

    if ans_max == -1:
        return -1, -1
    return ans_min, ans_max

def main():
    t = int(input())
    out = []
    for _ in range(t):
        m, a, c = map(int, input().split())
        x, y = solve_case(m, a, c)
        out.append(f"{x} {y}")
    print("\n".join(out))

main()
```这`factor`函数只存储不同的质因数，因为重复的幂对于根式来说并不重要。 找到因素后`m`，代码首先拒绝不可能的情况，其中`a`或者`c`在目标部首之外引入素数。 

变量`need`代表强制部分`b`。 剩余的生成值仅允许使用以下素数`m`，这可以防止意外创建更大的部首。 

生成循环通过将现有值乘以允许的素数来增加数字。 极限是`c // need`因为乘以`need`稍后仍须保留下面的候选人`c`。 严格的不等式检查是必要的，因为中间尾部必须位于两个已知尾部之间，而不是等于它们。

 ## 边缘情况

 当`m`是`1`，任何地方都不可能出现素因数。 唯一可能的值是完全由超出范围的质因数组成的数字`m`，这意味着唯一可用的数字是`1`。 发电机从`1`，所以它正确地找到了这种情况。 

什么时候`a`或者`c`包含不在其中的素数`m`，算法在搜索之前拒绝这种情况。 例如：```
35 5 7
```已知的尾部已经迫使质数`5`和`7`，但目标部首与任何附加的中间值不兼容。 答案依然存在`-1 -1`。 

当缺失的素数有一个大的乘积时，`need`本身可以接近`c`。 生成的乘数非常小，但最终的间隔检查阻止返回`a`或者`c`作为一个假答案。 这可以处理严格不等式周围的边界错误。
