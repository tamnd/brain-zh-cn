 ## 解决方案
 ## 问题理解

 该问题给出了两个长度相同的数组。 一个数组，调用它`a`，已修复并表示系统的损坏状态。 我们需要构造另一个数组`b`大小相同，每个元素在 0 到 10^9 之间，在非常具体的约束下：对于每个位置`i`，绝对差值`|a_i - b_i|`一定是奇数。 

用更简单的话来说，每个位置都是独立的，对于每个索引我们必须选择一个数字`b_i`具有相反的奇偶性`a_i`。 如果`a_i`是偶数，`b_i`一定是奇数。 如果`a_i`是奇数，`b_i`必须是均匀的。 

这里对值的大小的约束不是限制性的，因为 0 和 1 都是偶数和奇数的有效代表，并且它们总是在允许的范围内。 

输入大小可以很大，所有测试用例的总元素数最多可达 2·10^5。 这立即表明任何二次甚至对数线性的每个元素的大量计算都是不必要的。 每个测试用例的直接线性构造就足够了，因为我们只决定每个测试用例`b_i`独立。 

值得检查的一个微妙点是索引之间是否存在任何隐藏的耦合。 天真的阅读可能会暗示一些全局结构，但条件纯粹是每个元素。 这就消除了对排序、动态编程或贪婪平衡的任何需要。 

边缘情况主要与奇偶校验和边界值有关。 例如，如果`a_i = 0`，我们仍然必须产生一个奇数，并且如果`a_i = 10^9`，我们仍然需要在范围内进行偶数或奇数调整。 这总是可能的。 

## 方法

 蛮力思维会尝试将值分配给`b`通过扫描每个位置的所有可能的候选者并检查奇偶条件是否成立。 对于每个索引`i`，人们可以迭代从 0 到 10^9 的所有值并选择一个有效的值。 这原则上是正确的，因为条件很容易验证，但每个元素的搜索空间是 10^9 种可能性，这导致在最坏情况下大约 10^14 次操作`n`很大。 那是完全不可行的。 

关键的观察结果是，约束不要求优化，只要求可行性，并且仅取决于奇偶校验。 一旦条件简化为奇偶校验匹配，每个位置恰好有两个等价类：具有相同奇偶校验的数字和具有相反奇偶校验的数字。 我们总是可以自由地从正确的班级中挑选任何代表。 

这将问题从“在大范围内搜索”转变为“为每个元素选择两个固定值之一”。 一个方便的构造是绘制每个偶数`a_i`到 1 以及每个奇数`a_i`为 0。这始终满足奇偶校验翻转条件并保持在范围内。

 ## 算法演练

 1. 对于每个测试用例，读取数组`a`。 除了处理每个值之外，我们不需要存储任何东西，但存储简化了实现。 
2. 对于每个元素`a_i`，确定其奇偶性。 这是通过检查来完成的`a_i % 2`。 
3.如果`a_i`是偶数，赋值`b_i = 1`。 这保证了`|a_i - b_i|`是奇数，因为偶数减去奇数总是奇数。 
4.如果`a_i`为奇数，赋值`b_i = 0`。 这再次保证了奇数差，因为奇数减偶数是奇数。 
5. 输出构造好的数组。 

步骤 3 和 4 背后的原因是我们故意使用尽可能小的代表来强制奇偶校验反转。 使用 0 和 1 就足够了，因为奇偶校验在加 2 的情况下不变，我们只关心差值是否能被 2 整除。 

### 为什么它有效

 保持的不变量是对于每个索引`i`，奇偶性`b_i`总是不同于奇偶校验`a_i`。 由于奇偶校验完全确定差异是偶数还是奇数，这保证了`|a_i - b_i|`总是很奇怪。 索引之间不存在交互作用，因此独立满足每个位置就足以满足整个数组约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    res = []
    for x in a:
        if x % 2 == 0:
            res.append(1)
        else:
            res.append(0)
    
    print(*res)
```该解决方案独立读取每个测试用例并一次性构建答案。 唯一重要的实现细节是保持输出生成简单，因为对于大输入，循环内的打印可能会更慢。 

这里一个常见的错误是试图通过选择类似的东西来“优化”值`x + 1`或者`x - 1`。 这在许多情况下也是有效的，但这是不必要的，并且在以下情况下可能存在溢出或边界问题的风险：`a_i = 10^9`。 使用固定奇偶校验代表可以避免所有此类问题。

 ## 边缘情况

 对于`a_i = 0`，该结构仍然可以正常工作：因为 0 是偶数，所以我们分配`b_i = 1`, 给予`|0 - 1| = 1`，这是奇数且在范围内。 无需特殊处理。 

对于像这样的大值`a_i = 10^9`，奇偶校验仍然是明确定义的，并且分配 0 或 1 使结果保持有效。 不存在溢出或边界违规的风险，因为我们从不尝试镜像或增加输入值。 

对于交替奇偶校验输入，每个索引都是独立的，因此输出只是按元素翻转奇偶校验而没有任何干扰，从而确认不存在全局一致性约束。
