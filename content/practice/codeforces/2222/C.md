 ## 问题理解

 我们得到一个奇数长度的正整数序列。 任务是将这个序列划分为连续的子数组，每个子数组的长度为奇数，以便所有这些子数组共享相同的中位数。 我们的目标是最大化此类分区中的子数组数量。 每个子数组的中位数被定义为子数组排序后的中间元素。 

关键的挑战来自两个相互交织的限制。 首先，子数组的长度必须是奇数。 其次，所有中位数必须相同。 由于数组长度是奇数，因此允许使用单元素子数组。 这立即表明，如果所有元素都相等，我们可以将数组划分为`n`单元素子数组。 

的限制`n`和总和`n^2`暗示着一个`O(n^2)`解决方案是可以接受的。 具体来说，总和为`n^2`所有测试用例不超过`5000^2`，这意味着我们可以提供在二次时间内检查所有子数组或所有位置的解决方案。 然而，检查每个奇数长度子数组的共同中位数的简单暴力是浪费的，并且可以通过观察序列中的模式来优化。 

边缘情况包括所有元素都相同的序列、中位数位于数组末端的序列以及变化较大的序列。 仅检查连续相等元素的简单方法可能会在中位数在不明显位置重复的序列中失败。 

## 方法

 暴力方法将迭代所有可能的分区，检查每个子数组的奇数长度并计算其中值。 这是可行的，因为任何有效的分区都可以通过起始位置和结束位置的枚举来构建。 主要问题是重复计算每个候选子数组的中值成本`O(n log n)`每个子数组，大约有`O(n^2)`子数组，给出`O(n^3 log n)`复杂。 这太慢了。 

关键的见解是，不需要从头开始为每个子数组重新计算中位数。 由于所有中位数必须相同，因此我们可以尝试将数组中的每个元素作为候选中位数。 然后我们可以将数组转换为相对于该中位数的“分数数组”：`+1`如果元素更大，`-1`如果更小，并且`0`如果相等。 对于具有此中位数的子数组，子数组必须包含更多等于或高于中位数的元素而不是低于中位数的元素，并适当计算中位数元素。 这将问题简化为找到最长的前缀和序列，其中元素相对于候选中值的“平衡”是非负的。 

一旦数组转换为分数数组，就可以使用动态规划方法：`dp[i]`表示以索引结尾的有效分区的最大数量`i`。 每个子数组都从较早的奇数索引开始，并且具有非负余额。 通过迭代所有候选中位数，我们可以确定全局最大值。 问题的结构——奇数长度的子数组和唯一的中位数——允许我们检查每个候选者`O(n^2)`无需重复对子数组进行排序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3 log n) | O(n^3 log n) | O(n^2) | O(n^2) | 太慢了 |
 | 最佳 | O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1. 将数组中的所有唯一元素识别为候选中位数。 由于只有中位数本身可以定义有效的子数组，因此迭代这些候选数组可确保不会错过任何可能性。 
2. 对于每个候选中位数，将数组变换为差值数组：`+1`对于大于中位数的元素，`-1`对于较小的元素，以及`0`对于元素相等。 这捕获了中位数周围的相对平衡。 
3. 在此差异数组上初始化前缀和数组。 索引处的前缀和`i`表示从开始到结束的累计余额`i`-th 元素。 
4. 对于每个索引`i`在数组中，使用动态规划来计算以 结尾的最大分区数`i`。 考虑每个先前的索引`j`这样子数组`[j+1..i]`前缀和数组中具有奇数长度和非负余额。 更新`dp[i] = max(dp[i], dp[j] + 1)`因此。 
5. 给定候选中位数的结果是中值中的最大值`dp`大批。 跟踪所有候选中位数的全局最大值。 

工作原理：通过相对于候选中位数转换数组并使用前缀和，我们保证任何选定的子数组都满足奇数长度中位数条件。 动态编程确保重叠子数组的计数正确，并且子数组的总数最大化。 该方法是详尽的，因为每个唯一的数组元素都被尝试作为中位数，并且每个分区都被评估平衡和奇数长度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_subarrays(a):
    n = len(a)
    ans = 1
    for median in set(a):
        diff = [0] * n
        for i, val in enumerate(a):
            if val > median:
                diff[i] = 1
            elif val < median:
                diff[i] = -1
            else:
                diff[i] = 0
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + diff[i]
        last_occurrence = {}
        last_occurrence[0] = 0
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            dp[i] = dp[i - 1]
            for j in range(i - 1, -1, -2):
                if prefix[i] - prefix[j] >= 0:
                    dp[i] = max(dp[i], dp[j] + 1)
        ans = max(ans, dp[n])
    return ans

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(max_subarrays(a))
```此代码首先将每个数组转换为相对于候选中位数的分数数组。 计算前缀和以进行有效的子数组检查，并使用动态编程来查找有效分区的最大数量。 通过检查子数组是否具有正确的索引奇偶校验来确保对奇数长度的仔细处理。
