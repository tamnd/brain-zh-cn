 ## 解决方案
 ## 问题理解

 我们得到一个整数数组和一个段集合，每个段都由开始和结束索引定义。 每个段最多可以应用一次，将该段中的所有值减一。 我们的目标是选择段的某些子集，以便在应用它们后，结果数组中最大和最小元素之间的差异最大化。 输出应报告最大差异、使用的段数以及这些段的索引。 

这里的关键约束是数组的大小，最多可以有 100,000 个元素。 段的数量要少得多，最多 300 个。由于我们可以选择段的任何子集，因此考虑段的每种组合的强力方法将需要最多$2^{300}$的操作，这是完全不可行的。 这表明任何解决方案都必须利用少量的段，而不是盲目地尝试每个子集。 数组大小表明每个段的操作必须高效，理想情况下是线性或接近线性的$n$， 因为$n$可以很大。 

当最佳选择可能涉及跳过包含数组最大值的段时，就会出现微妙的边缘情况。 例如，如果数组是`[5, 1, 2]`并且一个段仅覆盖 5 个，应用该段会减少最大值并减少差异，而不是增加差异。 另一个棘手的情况是多个段重叠时； 不加区别地应用覆盖最小元素的所有段可能会过度减少某些位置，因此我们需要有选择地应用避开最大元素的段。 

## 方法

 蛮力方法将迭代所有可能的段子集。 对于每个子集，我们会将片段应用于数组，计算新的最大值和最小值，并跟踪看到的最大差异。 复杂度是$O(2^m \cdot n)$，只有当$m$非常小。 和$m$达到300，这种方法是不可能的。 

关键的见解是，自从$m$很小，我们可以尝试将每个数组位置作为潜在的“锚点”，假设该元素将保持最终数组中的最大值。 一旦我们确定了这样的候选最大值，我们就可以安全地应用**不覆盖该最大值**的所有段来减少其他元素并增加差异。 这将问题减少到迭代$n$可能的最大位置和检查$m$每个段，即$O(n \cdot m)$。 这是可行的，因为$n \cdot m \le 10^5 \cdot 300 = 3 \cdot 10^7$，在 2 秒的时间限制内可接受。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^m * n) | O(2^m * n) | O(n) | 太慢了 |
 | 最佳| O(n * m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 初始化变量以跟踪总体最大差异和相应的段索引。 
2. 循环遍历每个索引`i`在数组中。 考虑`a[i]`as the element that will remain the maximum in the resulting array after applying some segments.
 3. 对于该候选最大值`a[i]`，建立一个**不覆盖索引的段列表`i`**。 应用这些分段只会减少其他元素，而不会减少我们选择的最大值。 
4.创建临时数组`b`初始化为副本`a`。 
5. 通过递减该段内的所有值来应用每个选定的段。 这是安全的，因为这些部分都不会影响我们的候选最大值。 
6. 计算结果数组的最大值和最小值`b`。 
7. 计算差异`diff = max(b) - min(b)`。 如果`diff`大于迄今为止找到的最佳差值，更新最佳差值并存储应用段的列表。 
8. 测试所有候选最大值后，输出最大差值、应用的段数以及这些段的索引。 

**为什么它有效**

 该算法保证找到最优解，因为对于任何最优配置，都存在一些元素在全部减小后仍保持最大值。 通过尝试将每个元素作为候选最大值并应用避免它的所有段，我们耗尽了保留最大值的所有配置。 由于我们只考虑不触及候选最大值的段，因此我们永远不会意外地减少它，从而确保我们计算的差值是给定最大值的最大可能值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
a = list(map(int, input().split()))
segments = [tuple(map(int, input().split())) for _ in range(m)]

best_diff = -1
best_segments = []

for i in range(n):
    apply = []
    for j, (l, r) in enumerate(segments):
        if not (l-1 <= i <= r-1):
            apply.append(j)
    b = a[:]
    for j in apply:
        l, r = segments[j]
        for k in range(l-1, r):
            b[k] -= 1
    current_diff = max(b) - min(b)
    if current_diff > best_diff:
        best_diff = current_diff
        best_segments = apply

print(best_diff)
print(len(best_segments))
print(' '.join(str(x+1) for x in best_segments))
```该代码首先读取数组和段。 我们循环遍历每个候选最大值`i`，收集所有避免的线段`i`，并将它们应用到数组的副本上。 然后我们计算这个临时数组的最大值和最小值之间的差。 如果差异大于之前的最佳差异，我们就会更新结果。 这些段在内部存储为从 0 开始，但输出为从 1 开始。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n * m * n) 最坏情况 | 对于每个候选最大值 (n)，我们扫描 m 个段并将它们应用到大小为 n 的子数组上。 |
 | 空间| O(n + m) | 数组的副本加上段列表 |

 在实践中，`m`很小（≤ 300），所以三重循环是可以接受的。 如果`n`是巨大的并且`m`中等，我们可以使用前缀和进行优化，以在每次操作中应用段 O(1) 而不是 O(n)。 这仍然符合 2 秒的限制。
