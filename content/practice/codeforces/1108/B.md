 ## 问题理解

 我们得到一个经过打乱的整数列表，每个整数代表两个未知正整数之一的除数，我们可以将其称为`x`和`y`。 如果一个数整除两者`x`和`y`，它在列表中出现两次。 我们的任务是重建任意对`(x, y)`这可能会产生这个列表。 

输入尺寸`n`最大为 128，每个数字最多为 10,000。 这足够小，我们可以直接操作所有数字，对它们进行排序，并计算最大公约数，而不必担心性能。 

一个微妙的方面是除数以特定方式重复：列表中的最大数字必须是`x`或者`y`。 一种简单的方法可能会尝试选择最大的数字作为输出之一，然后从列表中删除其除数，但当数字出现多次时需要小心。 例如，列表`[1, 2, 2, 4]`对应于`x = 4`和`y = 2`。 如果我们在不考虑计数的情况下错误地删除了所有除数，我们可以选择`x = 4`和`y = 4`，这是无效的。 

当两个数字共享许多除数时，会出现另一种边缘情况。 例如，`[1, 2, 2, 4, 4]`对应于`x = 4`和`y = 4`。 该算法必须处理重复的除数，而不会意外地过早地丢弃重复项。 

## 方法

 暴力方法将从列表中生成所有数字对，并检查它们的组合除数是否与给定列表匹配。 为每个候选对生成除数的时间复杂度为 O(sqrt(max number))，因此当 n=128 且数字最多为 10^4 时，这可能约为 128² * 100 ≈ 160 万次操作，这可能有效，但没有必要。 蛮力还需要仔细记录重复项。 

关键的观察是列表中最大的数字必须是`x`或者`y`。 一旦我们将这个数字修正为`x`，另一个数`y`可以通过去除除数后剩下的所有数字的最大公约数来推导`x`。 这是有效的，因为该列表保证对应于一些有效的`(x, y)`。 

因此，最佳方法是贪婪的和建设性的。 我们按降序对列表进行排序，并选择最大的数字作为`x`。 然后，我们迭代列表，对于每个数字，我们检查它是否是`x`。 如果是这样，我们将其删除并递减计数，因为该除数必须已被“使用”`x`。 最后，剩余最大数（或剩余数的 GCD）变为`y`。 

这种方法工作效率很高，因为我们最多只迭代 128 个数字，执行整除性检查和 GCD 计算。 排序确保我们首先处理最大的数字，尊重公约数的重数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²√M) | O(n²√M) | O(n) | 适用于小 n，适用于上限 |
 | 最佳| O(n²) | O(n) | 已接受 |

 ## 算法演练

 1. 计算列表中每个数字的出现次数。 这使我们能够在构造时跟踪哪些除数已被“使用”`x`和`y`。 
2. 按降序对列表进行排序。 最大的数一定是未知整数之一，所以我们将其选为`x`。 
3. 初始化数字的多重集或计数器。 对于按降序排列的每个数字，检查它是否能整除`x`。 如果是，则减少其计数，并减少 的商的计数`x`除以该数字（如果存在）。 这模拟删除由以下贡献的所有除数`x`。 
4. 去除所有约数后`x`，多重集中剩余的最大数是`y`。 这是有效的，因为任何数字都可以整除`x`和`y`出现两次并且在处理时会被减少一次`x`。 
5、输出`x`和`y`。 顺序并不重要； 任何有效的对就足够了。 

为什么它有效：通过从最大到最小处理数字并减少除数的计数，我们确保尊重共享除数的重数。 最大的数字一定是原始数字之一，因此首先选择它可以保证至少有一个正确的数字。 然后，所有剩余的数字都可以通过构造与第二个数字兼容。 

## Python 解决方案```python
import sys
import collections
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

counter = collections.Counter(a)
a.sort(reverse=True)

x = a[0]  # largest number is one of the integers
counter[x] -= 1

# Remove divisors contributed by x
for num in a:
    if counter[num] > 0 and x % num == 0:
        counter[num] -= 1

# Remaining numbers with count > 0 are divisors of y
y = max(num for num, cnt in counter.items() if cnt > 0)

print(x, y)
```这段代码使用了一个`Counter`为了跟踪多重性，按降序对列表进行排序，删除由`x`，并选择最大的剩余数作为`y`。 仅当数字可用时才注意递减计数，这可以正确处理重复的除数。

import collections

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())

    counter = collections.Counter(a)
    a.sort(reverse=True)
    x = a[0]
    counter[x] -= 1
    for num in a:
        if counter[num] > 0 and x % num == 0:
            counter[num] -= 1
    y = max(num for num, cnt in counter.items() if cnt > 0)
