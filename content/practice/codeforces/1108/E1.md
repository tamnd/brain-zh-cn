 ## 解决方案
 ## 问题理解

 我们得到一个整数数组和其索引上的区间集合。 每个区间代表一个操作：如果我们选择它，该范围内的每个位置都会精确地减少 1。 每个选定的区间独立应用，因此如果一个位置被多个选定的区间覆盖，则其值会减少覆盖该位置的选定区间的数量。 

应用任何间隔子集后，我们获得一个新数组。 目标是选择一个子集，使结果数组的最大元素和最小元素之间的差异最大化。 

关键的结构是我们不能直接任意修改元素。 每个操作都会从连续段中减去 1，因此索引 i 处的最终值为：

 原始值减去覆盖i的所选段的数量。 

约束很小，n 和 m 最大为 300，这立即表明对索引或段的二次推理是可行的。 每个状态的任何三次或更高的探索仍然是可以接受的，但是分段上的指数需要修剪或结构。 

本地推理时会出现微妙的故障模式。 一个天真的想法是认为我们应该始终尝试独立地向下推最大元素或进一步向下推最小元素，但这两种效果是耦合的，因为段影响范围，而不是单个索引。 例如，减少包含当前最大值和最小值的区域可能会根据重叠模式缩小或扩大范围。 

另一个常见的错误是假设贪婪地挑选仅影响当前最大值或最小值的段就足够了。 一个小例子说明了为什么会失败：如果两个段部分重叠，则仅选择一个段可能比选择两个段更能减少全局分布。 

正确的解决方案必须评估每个索引被所选段覆盖的次数，但选择是全局的并且受到区间结构的限制。 

## 方法

 暴力解释是尝试段的所有子集。 对于每个子集，我们计算每个索引的覆盖计数并评估生成的数组范围。 这是正确的，但有 2^m 种可能性，在 m = 300 时这是完全不可行的。 

我们需要一种方法将子集选择变成结构化的东西。 关键的观察结果是，目标仅取决于有多少段覆盖每个索引，但这些覆盖计数来自选择整个区间。 这表明了差异数组的观点：选择一个段会为覆盖数组中的范围贡献+1。 因此，最终的操作相当于在段上选择一个二元向量并对它们的区间贡献求和。 

关键的洞察力是颠倒视角。 我们不考虑“我们应该选择哪些部分”，而是考虑“我们想要在阵列上实现什么样的覆盖模式”。 段的任何子集都会产生一个覆盖数组 c[i]，结果值为 a[i] - c[i]。 我们想要最大化 max(a[i] - c[i]) - min(a[i] - c[i])。 

这可以重写为：

 max_i a[i] - c[i] 减去 min_j a[j] - c[j]。 

所以我们想要选择一个子集来最大化两个位置 i 和 j 之间的差异。 固定 i 和 j 给出了段选择方面的线性目标。 对于每个段，它贡献 +1、-1 或 0，具体取决于它是覆盖 i、覆盖 j 还是同时覆盖两者。 这将问题转化为最大化每对 (i, j) 子集的权重，这可以使用分段分类贪婪地解决。 

每个段相对于 (i, j) 分为四类：

它既不涵盖，只涵盖 i，只涵盖 j，或两者都涵盖。 只有“i only”有助于增加差异，而“j only”会损害差异，而“both”则抵消。 因此，对于fixed(i,j)，我们取所有包含i但不包含j的段，并排除包含j但不包含i的段。 涵盖两者或两者均不涵盖的细分市场是中性的。 

因此，对于每对 (i, j)，可实现的最佳值为：

 (a[i] - a[j]) + (#segments 仅覆盖 i) - (#segments 仅覆盖 j)

 这可以通过扫描所有段来计算。 

最后，我们选取​​所有对 (i, j) 中最好的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对子集的暴力破解 | O(2^m·n) | O(2^m·n) | O(n) | 太慢了 |
 | (i, j) | 上的成对优化 O(n^2 m) | O(n^2 m) | O(n) | 已接受 |

 ## 算法演练

 1. 迭代所有有序索引对 (i, j)。 我们将 i 解释为候选最大位置，j 解释为候选最小位置。 这编码了调整后最大化 a[i] - a[j] 的目标。 
2. 对于每一对，初始化一个等于 a[i] - a[j] 的跑分。 这是未选择任何细分的基线贡献。 
3. 对于每个段 [l, r]，确定它如何与 i 和 j 相互作用。 如果 i 位于段内而 j 不在段内，则选择它会降低相对于 a[j] 的 a[i]，从而增加分数。 如果 j 位于内部而 i 不在内部，则选择它会降低分数。 包含两者或两者都不包含的段不会影响差异。 
4. 对于覆盖 i 但不包括 j 的每个线段加 +1，对于覆盖 j 但不包括 i 的每个线段减 1。 假设我们选择所有有益的部分并避免有害的部分，这将计算可实现的最佳贡献。 
5. 跟踪产生最大分数的最佳对 (i, j)，并存储该对的哪些片段被计数为正数。 这些是我们选择的部分。 
6. 输出最佳得分以及对应的选定分段索引。 

正确性依赖于这样一个事实：对于固定的 (i, j)，每个分段对目标都有独立的影响。 除了附加贡献之外，分段之间没有任何交互，因此最佳子集由本地每个分段的符号决策确定。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    seg = []
    for _ in range(m):
        l, r = map(int, input().split())
        seg.append((l - 1, r - 1))

    best_val = float("-inf")
    best_choice = []

    for i in range(n):
        for j in range(n):
            cur = a[i] - a[j]
            chosen = []

            for idx, (l, r) in enumerate(seg):
                in_i = l <= i <= r
                in_j = l <= j <= r

                if in_i and not in_j:
                    cur += 1
                    chosen.append(idx + 1)
                elif in_j and not in_i:
                    cur -= 1

            if cur > best_val:
                best_val = cur
                best_choice = chosen

    print(best_val)
    print(len(best_choice))
    print(*best_choice)

if __name__ == "__main__":
    solve()
```实现直接遵循成对优化思想。 i 和 j 上的双循环选择候选极值位置。 对于每个细分市场，会员资格检查决定其贡献。 仅存储改善所选对的差异的片段。 

一个微妙的点是，我们只存储被视为“对 i 有利”的段，因为这些是我们在该对的最佳子集中主动选择的段。 对配对有害的部分会被简单地忽略。 无论哪种方式，中性部分都无关紧要。 

## 工作示例

 ### 示例 1

 输入：```
n = 3
a = [2, -2, 3]
segments = [ [1,3], [2,3] ]
```我们评估对 (i, j)。 考虑 (i = 2, j = 0)：

 | 步骤| 表达| 价值|
 | --- | --- | --- |
 | 基地| a[2] - a[0] | a[2] - a[0] | a[2] - a[0] 3 - 2 = 1 | 3 - 2 = 1
 | 段1 | 涵盖两者 → 没有变化 | 1 |
 | 段2 | 仅涵盖 i → +1 | 2 |

 这对的最佳值是 2。 

现在考虑（i = 2，j = 1），相似的评估给出不同的分数。 该算法检查所有对并选择最佳的。 

此跟踪显示段贡献如何仅取决于相对于所选端点的遏制，而不取决于全局结构。 

### 示例 2

 输入：```
n = 4
a = [1, 3, -1, 2]
segments = [[1,2],[2,4],[1,4]]
```对于配对 (i = 1, j = 2)：

 | 细分 | 涵盖我 | 涵盖 j | 效果|
 | --- | --- | --- | --- |
 | [1,2]| 是的 | 是的 | 0 |
 | [2,4]| 没有| 是的 | -1 |
 | [1,4]| 是的 | 是的 | 0 |

 分数变为 (1 - 3) - 1 = -3。 

其他对可能会产生更好的值，并且该算法会系统地探索所有内容。 

这表明重叠的部分会以可预测的方式抵消，只有不对称的覆盖才重要。

 ## 边缘情况

 关键的边缘情况是 i 和 j 位于相同的段覆盖模式中。 考虑：```
a = [5, 1, 5]
segments = [[1,3]]
```对于 i = 0 和 j = 2，两者都被唯一的段覆盖，因此该段没有任何贡献。 该算法正确地产生分数 0 变化，结果为 a[i] - a[j] = 0。 

这证实了覆盖两个端点的段是中立的，并且永远不会扭曲决策。 该算法自然地处理这个问题，因为它只将段分类为四种不相交的情况，并且“两种”情况被明确忽略。
