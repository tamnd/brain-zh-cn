 ## 解决方案
 ## 问题理解

 我们在数轴上得到两条线段，每条线段都由其端点定义。 对于每个查询，我们需要从第一段中选取一个整数点，从第二段中选取一个整数点，使得这些点不同。 这些线段可以完全重叠、部分重叠或根本不重叠，但可以保证存在解决方案。 任务是为每个查询输出任何有效的不同点对。 

约束条件很简单。 端点可以大到$10^9$，但我们最多只有 500 个查询。 这意味着如果范围很大，我们无法承担尝试段端点之间的所有整数的算法。 然而，由于问题保证存在解决方案并且范围是连续整数，因此我们可以通过每个查询的恒定时间决策来解决这个问题。 

当线段重叠或重合时，会出现不明显的边缘情况。 例如，如果第一个段是 [1, 2]，第二个段是 [1, 2]，则对最左边点的简单选择将给出 (1, 1)，这违反了独特性要求。 该解决方案必须检测到此类冲突并从其中一个段中选择不同的整数，例如 (1, 2) 或 (2, 1)。 

## 方法

 强力方法将枚举第一段中的所有整数和第二段中的所有整数，检查第一对不同的整数。 虽然正确，但这种方法可能需要迭代$10^9$最坏情况下是整数，这是不可行的。 

最优方法利用了问题的简单性。 我们可以先选择第一段的左端点作为候选点$a$。 然后我们尝试将第二段的左端点作为候选$b$。 如果$b$是一样的$a$，我们可以安全地选择第二段的右端点。 问题的保证确保这总是会产生有效的对。 这将问题简化为简单的条件选择，每个查询以恒定的时间运行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((r1-l1+1)*(r2-l2+1)) | O(1) | O(1) | 太慢了 |
 | 最佳| 每个查询 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个查询，读取端点$l_1, r_1, l_2, r_2$。 
2. 设置第一个点$a$到$l_1$，第一段中最左边的整数。 这是一个自然的选择，因为它保证$a$位于段内。 
3.暂定第二点$b$到$l_2$，第二段中最左边的整数。 
4. 如果$a$等于$b$， 调整$b$到$r_2$，第二段中最右边的整数。 自从$l_2 < r_2$,$r_2$保证不同于$a$如果$a = l_2$。 
5、输出$a$和$b$。 

为什么它有效：在每个查询中，我们选择$a$和$b$直接从线段的端点开始。 第一个选择失败的唯一情况是两个左端点重合。 在这种情况下，我们选择第二段的右端点，保证与$a$由于严格的不平等$l_2 < r_2$。 问题的保证保证不需要其他特殊处理。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

q = int(input())
results = []

for _ in range(q):
    l1, r1, l2, r2 = map(int, input().split())
    a = l1
    b = l2
    if a == b:
        b = r2
    results.append(f"{a} {b}")

print("\n".join(results))
```该代码首先读取查询的数量。 对于每个查询，它提取四个端点。 第一点$a$始终设置为$l_1$，以及第二点$b$最初是$l_2$。 如果两点重合，我们就移动$b$到$r_2$。 结果被收集并打印在一个块中，以避免循环中缓慢的 I/O。

 ## 边缘情况

 当线段重合时，例如 [3, 7] 和 [3, 7]，算法最初选择$a = 3$和$b = 3$。 既然他们是平等的，$b$移位到 7，产生 (3, 7)，这是有效的。 对于不相交的线段，不会发生调整，只需简单选择左端点即可。 对于在单个点重叠的片段，例如 [1, 2] 和 [2, 3]，算法选择 (1, 2)，这也满足独特性条件。 这些示例涵盖了所有非显而易见的场景。
