 ## 解决方案
 ## 问题理解

 我们得到一个数字字符串。 对于每个长度精确的子串`k`，我们必须计算执行一次压缩操作后的最小可能长度。 

压缩是通过将字符串拆分为偶数个非空片段来定义的$$t_1,t_2,t_3,t_4,\dots$$并更换每一对$(t_{2i-1},t_{2i})$通过字符串$t_{2i}$重复$t_{2i-1}$次。 由于只有最终长度很重要，因此一对的贡献为$$(\text{numeric value of } t_{2i-1}) \cdot |t_{2i}|.$$任务是找到尽可能小的总贡献。 

第一个障碍是输入的大小。 字符串长度可以达到$2\cdot10^5$，我们需要答案$n-k+1$视窗。 任何为每个窗口独立地重新计算动态程序的算法都是没有希望的。 甚至$O(k)$每个窗口的工作变成$O(nk)$，已经存在了$4\cdot10^{10}$最坏情况下的操作。 

关键的难点在于分割位置不固定。 我们必须同时优化分区并回答所有滑动窗口查询。 

一个不明显的结构事实是，每个最佳解决方案都使用长度恰好为 1 的奇数索引片段。 假设某个奇数部分至少包含两个数字。 将其写为$10a+b$， 在哪里$b$是它的最后一位数字，并让下面的偶数块有长度$L$。 这对的贡献是$$(10a+b)L.$$移动最后一位数字$b$从奇数块到偶数块的前面。 新的贡献变为$$a(L+1).$$新值总是较小，因此任何最佳划分都可以改进，直到每个奇数部分都包含一位数字。 这一观察结果是问题变得易于处理的全部原因。 

一个常见的错误是在 DP 状态内允许多位奇数块。 例如，在`"5999"`人们可能会考虑使用`"59"`作为乘数。 这毫无帮助，因为将数字从乘法器移到重复块中总是会降低成本。 

另一个微妙的情况是窗户，例如`"111"`。 最优划分为`"1" | "11"`，给出长度$2$。 独立对待每个角色会产生$3$，这不是最佳的。 

## 方法

 对于单个固定字符串，自然的暴力破解想法是尝试将每个分区分成交替的乘法器块和重复块。 分区的数量是指数级的，因此这仅用作正确性参考。 

上面的结构引理完全改变了情况。 由于每个奇数块的长度为一，因此扫描字符串时唯一重要的信息是当前活动乘数的数字。 

这导致动态规划公式只有九个有意义的乘法器状态。 

暴力破解之所以成功，是因为它探索了所有有效的分区。 它的失败是显而易见的：即使是长度为 100 的字符串也已经拥有了天文数字般的分区。 

每个乘法器块的长度为 1 的观察结果将问题转换为恒定数量状态上的最短路径式 DP。 一旦 DP 具有恒定的维度，每个字符都可以表示为最小加转移矩阵。 子串答案成为连续区间内矩阵的乘积。 

现在问题不再是字符串了。 它变成：

 “给定一系列小的最小加矩阵，计算每个长度间隔的乘积`k`”。

 线段树可以工作，但它仍然执行太多的矩阵乘法。 关键的观察是每个查询长度都是相同的。 将矩阵序列分割成大小的块`k`允许使用最多一个后缀产品和一个前缀产品来回答每个查询。 矩阵乘法的总数变为线性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力分区| 指数| 指数| 太慢了 |
 | 每个窗口的DP |$O(nk)$|$O(1)$| 太慢了 |
 | 最小加矩阵+块乘积|$O(nA^2)$,$A=11$|$O(nA^2)$| 已接受 |

 ## 算法演练

 1. 证明最佳分区中每个奇数索引块的长度恰好为 1。 
2. 构建一个DP，其状态存储当前乘数的位数。 
3.让`dp[i][d]`是处理第一个之后的最小成本`i`字符并具有乘数`d`。 
4. 存在两种转变。 

一个字符可以扩展当前的偶数块。 这增加了答案`d`。 

角色可以启动新的乘数块。 前一个偶数块结束，新的乘数成为前一个字符。 
5. 将这些转换编码为最小加矩阵。 
6.引入两个辅助状态，用于存储DP所需的最小值。 这会产生一个$11\times11$每个位置的矩阵。 
7. 对于任何子串，答案等于将其矩阵的乘积应用于固定的初始向量并读取一个指定的状态。 
8. 将矩阵序列分割成大小的块`k`。 
9. 在每个块内，预先计算前缀乘积和后缀乘积。 
10.对于窗户`[l,r]`:

 如果窗口从块边界开始，则其矩阵乘积是存储的前缀乘积。 

否则，窗口恰好穿过一个块边界，因此其乘积为$$\text{suf}[l]\cdot \text{pre}[r].$$11. 将乘积应用于初始向量并输出结果答案状态。 

### 为什么它有效

 DP 状态准确地捕获了评估未来贡献所需的信息：当前乘数位数。 偶数块的每次扩展都会再次贡献该数字，这就是为什么转换成本在乘数中是线性的。 

结构引理保证不排除任何最优解。 每个有效的最优分区对应于一条经过DP的路径，并且每个DP路径对应于一个有效的分区。 最小加矩阵乘积计算所有此类路径中的最小成本。 

块分解是正确的，因为每个查询间隔具有相同的长度`k`。 任何间隔要么与整个块后缀重合，后跟块前缀，要么完全位于一个块内。 预先计算的乘积准确地重建了区间乘积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10 ** 18
A = 11

def mul(X, Y):
    Z = [[INF] * A for _ in range(A)]
    for i in range(A):
        xi = X[i]
        zi = Z[i]
        for k in range(A):
            v = xi[k]
            if v >= INF:
                continue
            yk = Y[k]
            for j in range(A):
                nv = v + yk[j]
                if nv < zi[j]:
                    zi[j] = nv
    return Z

def vec_mul(vec, M):
    res = [INF] * A
    for i in range(A):
        if vec[i] >= INF:
            continue
        base = vec[i]
        row = M[i]
        for j in range(A):
            nv = base + row[j]
            if nv < res[j]:
                res[j] = nv
    return res

def solve():
    n, k = map(int, input().split())
    s = input().strip()

    base = [[INF] * A for _ in range(A)]

    for d in range(9):
        base[d][d] = d + 1
        base[d][10] = d + 1

    base[10][9] = 0

    mats = [None] * (n + 1)

    prev = 0
    for i in range(1, n + 1):
        cur = ord(s[i - 1]) - ord('1')
        M = [row[:] for row in base]
        M[9][prev] = prev + 1
        M[9][10] = prev + 1
        mats[i] = M
        prev = cur

    def block_id(pos):
        return (pos - 1) // k

    num_blocks = (n + k - 1) // k

    pre = [None] * (n + 1)
    suf = [None] * (n + 2)

    for b in range(num_blocks):
        L = b * k + 1
        R = min(n, (b + 1) * k)

        pre[L] = mats[L]
        for i in range(L + 1, R + 1):
            pre[i] = mul(pre[i - 1], mats[i])

        suf[R] = mats[R]
        for i in range(R - 1, L - 1, -1):
            suf[i] = mul(mats[i], suf[i + 1])

    start = [INF] * A
    start[10] = 0

    ans = []

    for l in range(1, n - k + 2):
        r = l + k - 1

        if (l - 1) % k == 0:
            prod = pre[r]
            cur = vec_mul(start, prod)
        else:
            cur = vec_mul(start, suf[l])
            cur = vec_mul(cur, pre[r])

        ans.append(str(cur[10]))

    print(" ".join(ans))

solve()
```实现直接遵循矩阵公式。 每个位置贡献一个稀疏最小加转移矩阵。 矩阵维度只有十一，因此仔细编写的乘法足够快。 

前缀和后缀乘积在每个长度块内单独计算`k`。 这是最关键的优化。 线段树会引入额外的对数因子和更多的矩阵乘法。 

答案提取步骤对每个查询使用相同的初始向量。 窗口之间的唯一区别是表示该间隔的矩阵乘积。

 ## 边缘情况

 考虑：```
2 2
11
```唯一的分区是`"1" | "1"`。 结果长度是`1`。 DP 以数字开始乘法器`1`，然后创建一个单字符偶数块。 应答状态变为`1`。 

考虑：```
3 3
111
```粗心的实现可能会迫使每个字符成为单独的对并获得成本`3`。 正确的分区是`"1" | "11"`，其成本为`2`。 扩展现有偶数块的转换可以正确处理这种情况。 

考虑：```
4 4
5999
```幼稚的方法可能会带来事半功倍的效果`"59"`。 结构引理表明移动尾随`9`进入下一个块总是会降低成本。 DP 永远不需要多位乘法器的状态，这正是恒定状态公式正确的原因。
