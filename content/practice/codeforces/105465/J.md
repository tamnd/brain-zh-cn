 ## 解决方案
 ## 问题理解

 我们得到一个长度的数组`2n`。 我们重复选取当前数组中的两个相邻元素，将其删除，并获得等于这两个值的绝对差的分数。 完全这样做之后`n`有时，数组会变空。 任务是最大化此类相邻删除的所有可能序列的总分。 

关键对象不仅仅是原始数组，而是删除后产生的数组序列。 每个操作都会将大小减少两倍，并且邻接始终是相对于当前压缩数组定义的。 

约束条件`Σ n ≤ 2 · 10^5`意味着每个测试用例的任何解决方案都必须大致呈线性或对数线性。 任何依赖于整个范围内的立方间隔 DP 的东西都太慢，因为单个测试用例已经可以达到`n = 2 · 10^5`，这将使`O(n^2)`边界和`O(n^3)`不可能的。 

一个微妙的点是邻接是动态的。 天真的解释可能会将其视为选择任何索引配对，但这并不总是有效。 然而，许多不正确的贪婪方法都会失败，因为它们忽略了删除如何改变邻接性并意外地假定对之间的独立性。 

典型的失败案例如下所示：如果数组是`[1, 100, 2, 99]`，贪婪地采用局部最佳相邻对，例如`(1,100)`和`(2,99)`很好，但在其他配置中，局部决策会阻碍更好的全局匹配。 困难在于配对选择会影响未来的邻接结构。 

## 方法

 蛮力视图是模拟在每一步选择相邻对的所有可能方法。 在每个州，最多有`O(n)`选择，并且状态的数量呈指数级增长，因为每次删除都会更改剩余数组的结构。 即使通过间隔记忆，分裂成相邻配对去除序列的方式数量也对应于类似加泰罗尼亚语的结构，导致至少`O(n^3)`如果我们尝试计算每个子数组和配对点的最佳结果，则间隔 DP。 

关键的观察结果是，该过程总是一次删除两个元素，并且从不重新排序元素，仅压缩它们。 这意味着最终结果仅取决于元素的配对方式，而不取决于操作的确切顺序。 任何有效的操作序列都会导致原始位置之间的完美匹配，并且每个这样的匹配都可以通过某些相邻删除序列来实现。 

一旦我们接受了这种等价性，问题就变成了：我们必须选择一对`2n`使配对值的绝对差之和最大化的值。 

目标简化了，因为对于任何一对`(x, y)`，贡献是`max(x, y) - min(x, y)`。 在所有对中，这变为所选大元素的总和减去每对中所选小元素的总和。 为了最大化总数，我们希望大值尽可能多地充当最大值，小值尽可能多地充当最小值。 

这是通过对数组进行排序并将最小的与最大的、第二小的与第二大的配对等来实现的。 直观上，这最大化了每对内部的间隙，并且邻接的结构约束不会阻止实现这种匹配。 

因此，最优策略简化为排序和配对极端。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力间隔 DP 操作 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 太慢了 |
 | 对极端进行排序和配对 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们独立地减少每个测试用例。 

1.读取数组并按非降序排序。 排序暴露了小值和大值的全局结构，这最终决定了可实现的最大差异。 
2. 从两端对称地配对元素：最小的与最大的、第二小的与第二大的，依此类推。 每个这样的对都贡献了数组中两个元素之间的最大可能分布。 
3. 累计差值总和`a[2n-1-i] - a[i]`为了`i`从`0`到`n-1`。 
4. 输出该总和作为测试用例的答案。 

配对对称位置有效的原因是，一旦我们承诺全局排序，每对都会独立做出贡献。 由于绝对差值在固定对上是线性的，因此单独最大化每对也会使总数最大化。 

### 为什么它有效

 排序后，任何配对都可以看作是为一对中的每个元素分配“高角色”或“低角色”。 总分是所有对的最高分减去最低分的总和。 为了最大化这一点，我们希望始终将最大值指定为高值，将最小值指定为低值。 极端配对在每一步都严格执行这种分离，因此没有其他配对可以提高总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()
        ans = 0
        for i in range(n):
            ans += a[2*n - 1 - i] - a[i]
        out.append(str(ans))
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```代码直接遵循归约。 排序是唯一重要的步骤； 之后，通过从排序数组的两端开始索引来实现对称配对。 使用`2*n - 1 - i`确保我们始终将最大的剩余元素与最小的剩余元素匹配，而无需显式构造对。 

必须注意有效地读取输入，因为跨测试的总数组大小可以达到`2 · 10^5`。

 ## 边缘情况

 完全相等的数组，例如`[5, 5, 5, 5, 5, 5]`无论配对策略如何，始终产生零。 该算法对其进行排序并将相等的元素配对，因此每个差异都为零并且输出保持正确。 

严格递增的数组，例如`[1, 2, 3, 4, 5, 6]`强调解决方案是否正确配对极值而不是按原始顺序排列的相邻元素。 排序使结构清晰，配对`(1,6), (2,5), (3,4)`产生最大可能的总和。 

小投入，例如`n = 1`确保索引逻辑不会中断。 代码直接计算`a[1] - a[0]`，匹配唯一有效的操作。
