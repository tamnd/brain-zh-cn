 ## 解决方案
 ## 问题理解

 我们得到一个仅包含以下内容的数组`1`和`-1`。 我们必须将该数组的索引分为`k`组。 每个组都被视为原始顺序的子序列，这意味着我们保持相对顺序但不要求连续性。 

对于任何子序列，我们定义一个值`f(b)`作为该子序列内的最大子数组和。 因为元素只是`±1`，这相当于运行 Kadane 算法并将结果限制为零，因为允许使用空子数组并产生零。 

任务是分配每个位置`i`到标签来自`1`到`k`因此在所有子序列中，最差（最大）`f`值尽可能小。 

输出只是标签数组，而不是子序列本身。 

限制条件很大：总计`n`所有测试用例最多可达`2e5`。 这排除了每个测试用例的任何二次方。 甚至`O(n log n)`必须简单且紧凑，任何尝试重新计算多个分区的子数组值的解决方案都将立即失败。 

一个微妙的点是子序列不是连续的，因此将数组划分为段的天真的直觉并不直接适用。 另一个陷阱是解释`f(b)`错误：因为空子序列有价值`0`，任何没有正积累的群体都是有效安全的。 

重要的边缘情况：

 单个大块`1`s，例如`1 1 1 1`，其中任何分组都必须控制连续正值的增长。 

交替序列如`1 -1 1 -1`，贪婪的平衡可能会意外地集中积极因素。 

极端`k = n`，其中每个元素都是单独的，并且答案通常是最佳的。 

极端`k = 1`，其中所有内容都被强制归为一组。 

## 方法

 蛮力的观点是尝试将所有索引分配到`k`分组和计算`f`对于每个组。 即使忽略作业的组合爆炸，计算`f`对于每个组都需要扫描子序列，并且分配数量呈指数级增长，因此这立即是不可能的。 

一种更有条理的强力方法是尝试逐步建立团队并维护 Kadane 价值观。 即使如此，每个分配选择都会以非局部方式影响未来的子数组和，因此状态空间变得巨大。 

关键的观察是，目标不是独立优化所有组，而只是确保没有组积累太多连续有效的结果。`+1`不间断的贡献`-1`。 自从`-1`重置或减少运行金额，我们想要分配`1`各组之间的浓度均匀，同时确保没有任何一个组的浓度太高。 

关键的简化是根据周期性分配来思考。 如果我们以循环方式分配元素`k`组，然后每个组接收通过数组间隔开的元素。 此间距可防止长时间连续运行`1`避免在单个组内积累。 每个小组实际上都看到了阵列的“稀疏”版本，其中大的正块被分解。 

最佳结构正是这种均匀分布：分配位置`i`分组`i mod k`。 这保证了任何连续的运行`1`s 尽可能均匀地分割，最小化最坏情况的子序列和。 任何与均匀性的偏差都会更加集中`1`s 进入组的子集，增加它们的最大子数组和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力作业 | 指数| O(n) | 太慢了 |
 | 循环分布| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和`k`。 我们将确定性地为每个索引分配一个组号。 
2. 从左到右迭代数组。 对于职位`i`，将其分配给组`(i % k) + 1`。 这确保了各组之间的均匀分布。 
3. 输出赋值数组。 

唯一不明显的部分是为什么简单的循环分配就足够了。 直觉是任何子序列的最差子数组和都由有多少个子序列驱动`1`s 按该顺序连续着陆。 通过循环分配指数，我们确保连续`1`原始数组中的 s 在投影后被分成不同的组，因此没有一个组会积累长时间不间断的正向条纹。 

### 为什么它有效

 每个组接收的元素间隔大致为`k`原始数组中的位置。 任何连续的段`t`原始数组中的贡献最多`⌈t/k⌉`任何一个组。 自从`-1`s 保持不变，它们进一步打破了潜在的积累。 这可以防止任何组形成大的正前缀和，边界`f`所有组均统一。 因为每个组都被对称对待，所以没有组变得比其他组更差，因此所有组的最大值被最小化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        res = [(i % k) + 1 for i in range(n)]
        out.append(" ".join(map(str, res)))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案实际上并不取决于`a[i]`，仅在位置上。 这是有意为之的：目标的结构允许纯粹的位置构建。 

关键的实现细节是使用从零开始的索引进行模块化分配和移位`+1`用于输出标签。 这可以避免相差一的错误，否则会改变整个分组模式并破坏对称性。

 ## 边缘情况

 对于`k = 1`，循环分配退化为进入组 1 的所有元素。该算法产生`1 1 1 ...`，这是正确的，因为不可能有其他分配。 

为了`k = n`，每个元素都属于自己的组。 循环规则产生不同的标签，确保最大程度的分离。 

对于长时间运行的`1`比如`1 1 1 1 1 1`，循环分配防止任何组接收超过`⌈n/k⌉`运行中的元素。 例如与`k = 3`，组变得均匀交错`[1,1]`,`[1,1]`,`[1,1]`，因此每个组的 Kadane 值都是紧密有界的。 

对于交替模式，例如`1 -1 1 -1 1`， 这`-1`已经防止了累积，并且循环分配保留了这种分离，而无需在组内引入新的邻接关系。
