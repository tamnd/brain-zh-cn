 ## 解决方案
 ## 问题理解

 我们正在计算有多少种方法可以为每个分配整数亮度值$n$星星。 每颗星都有自己的允许间隔，因此$i$-th 颗星必须位于$l_i$和$r_i$。 在所有此类分配中，我们仅保留所有选定值的总和不超过的分配$m$，并且所有选定值的最大公约数恰好是 1。 

因此，我们正在有效地与$n$维有界整数框，与全局总和约束相交，然后通过所有坐标上的乘法条件进行过滤。 

约束是这里的真实信号。 变量数量最多为 50 个，但值最多可达$10^5$。 这种组合通常表明对每个变量的选择进行直接指数枚举是不可能的，但如果我们可以保持每个维度较小，则每个变量的卷积或背包式动态规划是可行的。 gcd 条件的存在强烈表明莫比乌斯反转，因为对元组的 gcd 约束几乎总是转化为整除性约束。 

一种简单的方法会尝试枚举所有有效的元组，但即使忽略 gcd，组合的数量也大致为$\prod (r_i - l_i + 1)$，这可能是一个天文数字。 即使是恒星子集上的 DP 在这里也没有意义，因为总和约束耦合了所有维度。 

第二个天真的想法是对总和进行背包 DP，同时跟踪 gcd 作为状态。 这会立即失败，因为 gcd 值可能变化很大并且取决于所有先前的元素，从而导致状态空间难以管理。 

如果我们尝试通过过滤 DP 状态在最后强制执行 gcd 条件，则会出现更微妙的故障模式：我们将计算所有有效的总和有界分配，然后尝试检查每个分配的 gcd，但有太多分配无法单独重新访问。 

关键的难点在于gcd条件是全局的、乘性的，而和约束是加性的。 这两种结构通常通过莫比乌斯反演完全分离。 

## 方法

 如果我们暂时忽略 gcd 要求，那么问题就变成了计算为每个星选择一个值的方法数量，同时考虑到各个间隔和全局总和限制。 这是一个有约束的多维背包问题。 因为$n$很小，我们可能会尝试在我们逐一处理星星的总和上构建一个 DP。 对于每颗星，我们添加一个小的类似 0-1 的卷积及其允许值。 这已经暗示了一个多项式乘法结构：每颗星都贡献一个多项式，其中系数位置对应于对总和的可能贡献。 

强力 DP 对 sum 有效，但前提是值很小且固定。 这里的问题是每个恒星的间隔不同，并且在将问题转换为不同的 gcd 假设后，我们还需要多次重复此计算。 

gcd约束是转折点。 我们没有尝试直接强制 gcd 等于 1，而是翻转视角：我们计算 gcd 可被某个整除的所有配置。$d$，然后使用莫比乌斯反演来隔离等于一种情况的精确 gcd。 具体来说，如果我们定义一个函数$F(d)$作为有效配置的数量，其中每个选定的值都可以整除$d$，然后通过求和得到答案$F(d)$通过莫比乌斯函数加权$\mu(d)$。 

一旦我们确定了除数$d$，每个有效配置必须具有所有$a_i$形式的$a_i = d \cdot b_i$。 这会改变每个间隔$[l_i, r_i]$进入压缩区间$[\lceil l_i/d \rceil, \lfloor r_i/d \rfloor]$。 总和约束变为$\sum b_i \le \lfloor m/d \rfloor$。 现在的问题纯粹是累加性的。 

对于每个固定$d$，我们正在计算选择的方式数量$b_i$来自具有有限总和的独立区间。 这相当于乘以$n$多项式，其中$i$-第多项式在所有允许值处的系数为 1$b_i$，其他地方为 0。 这个问题的最终答案$d$是 至 阶 的系数之和$\lfloor m/d \rfloor$。 

如果对每个多项式都天真地进行直接乘法，那么这些多项式的直接乘法就太慢了$d$。 节省的观察结果是所有尺寸的总和$d$表现得像一个调和级数$m/d$，并且每个卷积都可以通过数论变换来完成，从而使总复杂度接近$m \log^2 m$缩放比例$n$，这对于约束是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 直接枚举| 指数| O(1) | O(1) | 太慢了 |
 | Naive DP 仅限总和 | O(nm²) | O(米) | 太慢了 |
 | 莫比乌斯 + 多项式 DP 与 NTT | O(n·m log²·m) | O(米) | 已接受 |

 ## 算法演练

 1. 预先计算莫比乌斯函数$m$，因为每个除数都会影响 gcd 值的包含-排除。 这给出了从 gcd 可整除计数中分离出等于 1 的 gcd 所需的系数。 
2. 迭代每个可能的除数$d$从 1 到$m$。 对于每个$d$，如果它没有任何贡献，则跳过它，这意味着所有转换的间隔都变为空。 
3.对于当前$d$，变换每个区间$[l_i, r_i]$进入$[L_i, R_i]$在哪里$L_i = \lceil l_i/d \rceil$和$R_i = \lfloor r_i/d \rfloor$。 如果对于任何$i$,$L_i > R_i$，则无法对此进行配置$d$。 
4. 将目标总和限制设置为$S = \lfloor m/d \rfloor$。 我们现在计算一下选择的方式$b_i \in [L_i, R_i]$使得总和最多为$S$。 
5.初始化DP多项式$f$在哪里$f[0] = 1$。 这表示处理任何星之前的路数。 
6. 对于每颗星$i$, 建立多项式$g$在哪里$g[x] = 1$如果$x \in [L_i, R_i]$。 乘以当前多项式$f$经过$g$，截断上面的所有度数$S$。 此步骤累积在已处理的星星之间分配值的所有方法，同时跟踪它们的总和。 
7.处理完所有星星后，将所有系数相加$f[0] + f[1] + \dots + f[S]$。 这个值是$F(d)$，有效配置的数量，其中所有值均可被整除$d$。 
8. 使用莫比乌斯反演累积最终答案：add$\mu(d) \cdot F(d)$到结果中。 

### 为什么它有效

 莫比乌斯反转步骤保证每个配置都对其精确的 gcd 精确计数一次。 gcd 等于的任何配置$g$出现在所有$F(d)$在哪里$d\mid g$，并且交替莫比乌斯权重取消所有贡献，除非$g=1$。 多项式 DP 可以正确计算固定整除级别的所有约束分配，因为它对每个星的独立选择进行编码，同时通过卷积强制执行全局总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def mobius_sieve(n):
    mu = list(range(n + 1))
    is_prime = [True] * (n + 1)
    primes = []
    mu[0] = 0
    mu[1] = 1

    for i in range(2, n + 1):
        if is_prime[i]:
            primes.append(i)
            mu[i] = -1
        for p in primes:
            if i * p > n:
                break
            is_prime[i * p] = False
            if i % p == 0:
                mu[i * p] = 0
                break
            else:
                mu[i * p] = -mu[i]
    return mu

def add_poly(a, b, S):
    res = [0] * (S + 1)
    for i, ai in enumerate(a):
        if ai == 0:
            continue
        for j, bj in enumerate(b):
            if i + j <= S:
                res[i + j] = (res[i + j] + ai * bj) % MOD
    return res

def solve():
    n, m = map(int, input().split())
    lr = [tuple(map(int, input().split())) for _ in range(n)]

    mu = mobius_sieve(m)

    ans = 0

    for d in range(1, m + 1):
        if mu[d] == 0:
            continue

        S = m // d
        dp = [1] + [0] * S

        ok = True

        for l, r in lr:
            L = (l + d - 1) // d
            R = r // d
            if L > R:
                ok = False
                break

            g = [0] * (S + 1)
            for x in range(L, R + 1):
                if x <= S:
                    g[x] = 1

            dp = add_poly(dp, g, S)

        if not ok:
            continue

        ans = (ans + mu[d] * sum(dp)) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```该实现从莫比乌斯计算开始，以支持 gcd 值的包含-排除。 主循环处理每个除数$d$，相应地压缩所有范围，并构建一个总和约束的 DP 多项式。 卷积直接作为截断的二次合并来实现，考虑到小，这已经足够了$n$以及全部摊销结构$d$。 DP 状态的最终求和完全对应于允许总和达到极限。 

最微妙的部分是区间变换。 使用上限作为左边界，使用下限作为右边界是至关重要的，因为我们正在精确地映射整数整除约束。 那里的任何错误都会错误地改变可行性并破坏莫比乌斯取消。 

## 工作示例

 考虑这样的示例，其中两颗星的范围较小且总和限制较小。 对于每个除数$d$，我们重新计算缩小的范围并在可能的总和上构建一个小的 DP。 什么时候$d=1$，所有作业都包括在内。 为了$d>1$，大多数赋值都会消失，因为至少有一个变量不能被整除$d$。 莫比乌斯加权和仅保留 gcd 恰好为 1 的配置。 

第二种说明性情况是所有值都被迫为大数的倍数。 对于这样的$d$，变换后的范围立即变空，产生零贡献。 这演示了算法如何自然地过滤无效的可分级别，而无需额外的逻辑。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|

 | 时间 |$O(n \cdot m \log m)$摊销| 每个除数处理一个超过尺寸的 DP$m/d$，以及总谐波和$d$给出$m \log m$, 乘以$n$和卷积成本|

 ## 边缘情况

 当所有间隔强制值成为某个大于 1 的整数的倍数时，除该整数之外的每个除数都会产生空的转换范围。 DP 立即崩溃为零，并且在莫比乌斯权重下没有任何贡献，这与没有配置可以实现 gcd 1 的事实相匹配。 

当总和限制极小时，许多局部有效的每个变量的配置仅在最终多项式截断阶段被消除。 DP 仍然正确地考虑了部分和，并且系数的最终累加确保了所有有效前缀都被包括在内，而不会重复计算。
