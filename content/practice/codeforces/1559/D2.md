 ## 解决方案
 ## 问题理解

 我们有两个不同的森林，建立在同一组顶点（从 1 到 n）上。 每个森林已经是非循环的，但它们可能有多个连接的组件。 任务是添加尽可能多的新无向边，但有一个严格的限制：我们添加的每条边都同时插入到两个森林中，并且在所有插入之后，两个图必须仍然是森林。 

这意味着任何选定的边都不能在两个图中创建循环。 因此，仅当 u 和 v 当前位于第一个森林中的不同连通组件以及第二个森林中的不同连通组件中时，才允许 u 和 v 之间存在边。 

输出不仅是此类边的最大计数，而且还是达到此最大值的边的显式列表。 

高达 100000 的约束 n 迫使任何解都接近线性或线性算数时间。 重复检查所有顶点对的简单策略将需要 n 次方检查，这远远超出了两秒内可以完成的范围。 即使在添加每个边后从头开始重新计算连接性的方法也会重复遍历两个图的大部分，并且在这种规模下会立即失败。 

当只在一片森林中贪婪地思考时，就会出现一个微妙的问题。 如果我们只确保永远不会在第一个森林中创建循环，我们就可以轻松连接已经位于第二个森林的同一组件中的两个顶点，这将在那里创建一个循环。 同样，仅仅贪婪地尊重第二片森林也是不够的。 关键的困难在于两种连接结构同时发展。 

如果我们尝试预先计算两个森林中的连接组件，然后任意连接组件对，则会出现另一种失败情况。 一旦我们添加了一条边，两个组件结构都会发生变化，因此静态组件视图立即变得无效。 

## 方法

 强力观点是考虑所有顶点对，并针对每对顶点检查它们是否位于两个森林的不同组件中。 如果是，我们添加边缘并合并组件。 每次添加后，我们都会重新计算连接性或通过重复搜索动态维护它。 

这在原则上是正确的，因为它始终尊重森林约束，但成本却令人望而却步。 存在 O(n²) 条候选边，并且每次连接检查或更新的成本至少为朴素形式的 O(n)，在最坏的情况下会导致三次行为。 

关键的结构观察是，每个森林由一组不相交的组件维护，添加一条边相当于同时合并每个 DSU 中的一个组件。 因此，我们正在两个分区系统的交叉点上有效地工作。 我们想要重复选取两个分区中不同集合中的一对顶点，并同时合并这些集合。 

重要的简化是，一旦两个端点位于任一 DSU 中的同一组件中，我们就无需重新考虑边缘。 这样的一对永久无效。 这种单调性允许贪婪的扫描策略：我们可以遍历顶点并维护一个只前进的移动候选指针。 

我们维护两个 DSU 结构，每个森林一个。 在任何时刻，有效边是其端点位于不同DSU1组件和不同DSU2组件中的边。 我们以受控方式反复搜索这样的一对并添加它，同时合并两个 DSU。 

这将问题从全局对选择减少到顶点上的局部两指针搜索，其中每次失败的检查都会从未来的考虑中永久消除至少一个候选对。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 通过重新计算进行强力配对检查 | O(n3) | O(n) | 太慢了 |
 | DSU+贪婪二指针扫描| O(n α(n)) | O(n α(n)) | O(n) | 已接受 |

 ## 算法演练

 我们维护两个不相交的集合联合结构，DSU1 和 DSU2，代表摩卡森林和戴安娜森林的连通性。 我们还保留一个列表来存储我们决定添加的边。 

1. 初始化 DSU1 和 DSU2，将所有节点作为单独的组件。 然后合并每个相应 DSU 中的所有给定边。 这在两个图中都设置了初始森林结构。 
2. 设置两个指针i 和j。 指针 i 将作为第一个端点候选，j 将搜索 i 的兼容伙伴。 
3. 固定i并确保j始终严格大于i。 如果 j 尚未有效，则将 j 设置为 i + 1。这可以避免重复对并保持搜索方向一致。 
4. 当 i 和 j 已经属于 DSU1 中的同一组件或者它们属于 DSU2 中的同一组件时，向前移动 j。 禁止这样的对，因为添加该边会在至少一个森林中形成循环。 
5. 如果j移动超过n，则意味着i没有有效的伙伴。 在这种情况下，我们增加 i 并重新开始搜索，并相应调整 j。 
6. 如果我们找到有效的 j，我们将边 (i, j) 添加到答案中，并合并 DSU1 和 DSU2 中的 i 和 j。 这反映出两个森林都接受了这个边缘。 
7. 合并后，我们不会从头开始搜索。 我们继续更新 DSU，因为一些以前无效的对可能仍会被跳过，但不会丢失正确性。 我们从当前的 i 和 j 位置重复搜索。

### 为什么它有效

 DSU 不变式是，在每个结构内，组件始终是当前连接的正确表示，并且每个添加的边都会同时严格减少两个 DSU 中的组件数量。 每条选定的边都连接两个森林中的两个不同组成部分，因此两个森林都不会获得循环。 

贪婪扫描确保每个被拒绝的对 (i, j) 对于固定 i 永久无效，因为条件 DSU1 或 DSU2 相等意味着将来的合并无法分离已连接的节点。 这种单调性保证了 j 只在整个过程中向前移动，从而限制了总工作量。 

该算法是最优的，因为任何有效的解决方案只能连接两个 DSU 中不同组件中的顶点，并且我们在不违反约束的情况下贪婪地耗尽所有此类可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))
        self.size = [1] * (n + 1)

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True

n, m1, m2 = map(int, input().split())

d1 = DSU(n)
d2 = DSU(n)

for _ in range(m1):
    u, v = map(int, input().split())
    d1.union(u, v)

for _ in range(m2):
    u, v = map(int, input().split())
    d2.union(u, v)

edges = []

i = 1
j = 2

while i <= n:
    if j <= i:
        j = i + 1

    while j <= n and (d1.find(i) == d1.find(j) or d2.find(i) == d2.find(j)):
        j += 1

    if j > n:
        i += 1
        continue

    edges.append((i, j))
    d1.union(i, j)
    d2.union(i, j)

print(len(edges))
for u, v in edges:
    print(u, v)
```该解决方案首先使用输入边构建两个森林的 DSU 表示。 这确保了连接查询的摊销时间是恒定的。
