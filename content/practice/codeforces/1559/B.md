 ## 解决方案
 ## 问题理解

 我们得到一排位置，每个位置都有一个图块，该图块最终必须涂成红色或蓝色。 一些图块已经固定，而另一些图块是空白的，可以指定任一颜色。 

在我们最终确定所有颜色后，我们支付的成本等于共享相同颜色的相邻对瓷砖的数量。 每当两个邻居匹配时，成本就会增加一。 任务是填充所有空白，使成本尽可能小，并输出达到此最小值的任何颜色。 

关键的观察结果是成本仅取决于相邻相等性。 这意味着我们并不是试图匹配全局模式，只是为了尽可能避免长时间运行相同的颜色。 

约束很小：每个测试的长度最多为 100，并且最多有 100 个测试。 这允许每次测试使用任何线性甚至二次方法，但排除所有填充物的指数计数，这种计数会像 2 的空白数次方一样增长，并且很快变得不可行。 

一些边缘情况很重要。 

如果字符串已经完全固定并且像“RBRBRB”这样交替，则成本已经为零并且不需要任何更改。 如果忽略固定约束，尝试“优化”的幼稚方法可能会错误地改变强制结构。 

如果所有字符都是“？”，则任何交替模式（例如“BRBRBR ...”或“RBRBRB ...”）都会实现零成本，这是最佳的。 总是以固定颜色开始而不考虑对称性的粗心贪婪仍然有效，但这只是因为两种颜色是等效的。 

如果固定字符在强制长段方面不一致，例如“R???R”，则任何解决方案都必须尊重端点，并且不能在不对齐边界的情况下简单地自由交替。 

## 方法

 暴力策略会尝试将所有颜色分配给空白位置。 对于每个分配，我们计算线性时间内相邻相等对的数量。 如果有 k 个空白，则会产生 2^k 种可能性，并且每次评估成本为 O(n)，从而导致 O(n · 2^k)。 即使 n = 100，k 也可能很大，使得这种方法速度极其缓慢。 

关键的结构见解是相邻的冲突纯粹是局部的。 每个位置仅与其紧邻的位置交互。 这意味着我们不需要独立决定所有空白； 相反，我们可以从左到右贪婪地构建解决方案，同时保持与已决定的邻居的一致性。 

关键的简化是，一旦字符被固定，固定字符之间的任何空白段都表现为约束插值问题。 在这样的段内，我们只关心端点是否强制匹配或不匹配，并且我们可以以尽可能避免相等邻接的方式进行贪婪填充。 这导致了标准构造：从左到右传播约束，确保每个位置尽可能与其左邻居不同，但尊重固定颜色。 

这将问题简化为单遍构造。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·2^k) | O(n·2^k) | O(n) | 太慢了 |
 | 最优贪心构造 | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们从左到右构建最终的字符串。

1.替换所有'?' 与占位符并准备填充字符串。 目标是在尊重固定约束的同时决定每个位置。 
2. 对于第一个位置，如果是'？'，则任意指定为'B'。 没有左邻居，因此这里不会影响任何成本。 
3. 对于从 1 到 n-1 的每个位置 i，根据两条规则决定其颜色。 如果 s[i] 是固定的（“B”或“R”），我们必须保留它。 否则，如果可能的话，我们选择与 s[i - 1] 不同的颜色。 
4. 当 s[i] 为 '?' 时，将其赋值为 s[i - 1] 的相反值。 这可以防止在位置 i - 1 和 i 处创建相等的相邻对。 
5. 如果 s[i] 是固定的并且与 s[i - 1] 匹配，我们接受成本贡献，因为我们无法更改固定字符。 如果不同，我们只需继续。 
6. 继续直到字符串末尾，确保每个决策在给定先前选择的情况下都是局部最优的。 

输出是完全构造的字符串。 

### 为什么它有效

 在每个位置，我们最小化 i - 1 和 i 之间的边的贡献。 如果存在自由选择，我们总是选择一种避免与前一个字符相等的颜色。 如果由于固定的约束而没有自由选择，我们就被迫接受成本。 由于每条边都被独立处理一次，因此后面的决策不能改善或恶化早期的边，因此贪婪的选择是全局最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = list(input().strip())

        # handle first position
        if s[0] == '?':
            s[0] = 'B'

        for i in range(1, n):
            if s[i] == '?':
                # choose opposite of previous
                s[i] = 'R' if s[i - 1] == 'B' else 'B'

        print(''.join(s))

if __name__ == "__main__":
    solve()
```实现直接遵循从左到右的构造。 第一个位置是任意初始化的，因为它没有左约束。 随后的每个“？” 被分配与其前身相反的颜色，确保在可能的情况下不会引入新的相等相邻对。 

固定字符自然会覆盖贪婪选择：当 s[i] 已经是“R”或“B”时，我们只需保留它，然后算法继续进行。 这是安全的，因为固定约束定义了成本中不可避免的边缘，并且我们不会尝试修改它们。

 ## 边缘情况

 对于完全未知的字符串，例如`?????`，该算法以“B”开头并确定性地交替。 每个步骤仅取决于前一个字符，因此整个结构是一致的并产生零个相邻相等对。 

对于已经最优的配置，例如`BRBR`，该算法从不修改固定字符，只是简单地传递，保留了零成本结构。 

对于单字符输入，初始化可以安全地处理邻居的缺失，因为不存在邻接，因此不能创建或删除任何缺陷。
