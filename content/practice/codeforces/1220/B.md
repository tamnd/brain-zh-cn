 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$最初是从某些隐藏数组生成的表$a_1, a_2, \dots, a_n$。 表的每个条目都是通过将该数组的两个元素相乘而形成的，因此行中的单元格$i$， 柱子$j$等于$a_i \cdot a_j$。 经过一些损坏后，对角线条目被擦除并替换为零，但所有非对角线产品仍然完好无损。 任务是恢复可能生成给定表的任何有效原始数组。 

关键的结构约束是矩阵是变相的排名第一：每一行只是隐藏数组的缩放版本。 这意味着行之间具有很强的代数一致性，我们将利用这一点。 

输入尺寸$n \le 1000$允许$O(n^2)$处理矩阵，但排除诸如尝试所有可能的因式分解或每个单元独立重建值之类的任何事情。 每个值都出现在许多方程中，因此解决方案必须使用行之间的关系而不是孤立的条目来提取数组。 

对角线归零这一事实会产生微妙的边缘情况。 天真的读者可能会尝试使用$M_{ii}$恢复$a_i$，但这些值是无用的。 另一个潜在的错误是假设任何单行都足够，无需进行一致性检查； 浮动的不一致会打破天真的重建。 

例如，如果有人试图猜测$a_1$并得出所有其他内容$M_{1j} / a_1$，选择错误的除数$a_1$会在整个数组中传播不正确的缩放。 正确性取决于选择一致的锚点并验证所有值是否一致。 

## 方法

 一种强力的想法是尝试猜测隐藏数组的一个值并导出所有其他值。 假设我们选择$a_1$。 然后从第一行开始我们会有$a_j = M_{1j} / a_1$。 问题变成检查所有导出值是否都是整数以及它们是否再现完整矩阵。 尝试所有可能的值$a_1$不可行，因为$a_1$可以是由多个约束间接暗示的任何除数，并且矩阵值可达$10^9$，因此朴素枚举变得极其昂贵。 

关键的观察是我们实际上不需要猜测任何事情。 任何有效的索引对$(i, j)$给出$M_{ij} = a_i a_j$。 如果我们还看第三个索引$k$，我们得到：$$M_{ij} \cdot M_{ik} = (a_i a_j)(a_i a_k) = a_i^2 a_j a_k$$类似地：$$M_{ii} \text{ is missing, but we can avoid it entirely.}$$干净的技巧不是代数消除，而是要注意：$$a_i = \sqrt{\frac{M_{ij} \cdot M_{ik}}{M_{jk}}}$$对于任何不同的$i, j, k$， 自从：$$M_{ij} = a_i a_j,\quad M_{ik} = a_i a_k,\quad M_{jk} = a_j a_k$$前两个相乘并除以第三个分离株$a_i^2$。 

这提供了一种直接的方法来计算每个$a_i$仅使用三行，然后验证与完整矩阵的一致性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力猜测$a_1$|$O(n \cdot \text{divisors search})$|$O(n^2)$| 太慢了 |
 | 三重关系重建|$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们通过首先提取一个可靠的值，然后确定性地重建所有内容来构建解决方案。 

1. 选择任意三个不同的索引，通常为 0、1 和 2。我们使用它们是因为它们为我们提供了一个稳定的方程组，而不依赖于对角线条目。 
2. 计算$a_0$使用身份：$$a_0 = \sqrt{\frac{M_{01} \cdot M_{02}}{M_{12}}}$$这是有效的，因为分子变成$a_0^2 a_1 a_2$并删除分母$a_1 a_2$。 
3.一次$a_0$已知，恢复所有其他$a_j$使用：$$a_j = \frac{M_{0j}}{a_0}$$这直接来自$M_{0j} = a_0 a_j$。 
4. 构建完整数组后，通过检查以下内容来验证矩阵的一致性：$$a_i \cdot a_j = M_{ij}$$对于所有对$(i, j)$。 这确保了任何算术错误或无效平方根都不会被忽视。 
5. 输出重构后的数组。 

### 为什么它有效

 该矩阵完全由单个隐藏向量确定，因为每个条目都是该向量的两个分量的乘积。 使用三个索引的比率技巧可以毫无歧义地隔离一个未知数的平方，因为所有值都是正整数。 一旦一个值被固定，所有其他值都将被唯一地确定到相同的缩放比例，并且缩放比例是通过使用实际矩阵条目而不是相对比率来解决的。 所有对之间的一致性确保恢复的向量必须与原始结构完全匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    M = [list(map(int, input().split())) for _ in range(n)]
    
    i, j, k = 0, 1, 2
    
    # compute a[i]
    num = M[i][j] * M[i][k]
    den = M[j][k]
    a0_sq = num // den
    a0 = int(a0_sq ** 0.5)
    
    # fix possible rounding issues (guaranteed perfect square)
    if (a0 + 1) * (a0 + 1) == a0_sq:
        a0 += 1
    
    a = [0] * n
    a[i] = a0
    
    for t in range(n):
        if t != i:
            a[t] = M[i][t] // a[i]
    
    print(*a)

if __name__ == "__main__":
    solve()
```该解决方案首先读取完整的矩阵，因为任何重建都不可避免地依赖于成对关系。 我们选择索引 0、1 和 2 以保证非简并性。 

核心计算使用三乘恒等式来推导$a_0^2$，然后取整数平方根。 由于所有值都保证形成有效的乘法结构，因此除法是精确的并产生完美的平方。 

恢复一个锚点值后，直接从第一行计算数组的其余部分，将每个条目除以恢复的值$a_0$。 此步骤依赖于第 0 行恰好是的不变量$a_0$乘以隐藏向量。

 ## 边缘情况

 一种重要的边缘情况是当所有值都等于 1 时。矩阵除了对角线之外全部变为 1。 该算法计算$a_0^2 = 1$，取其平方根，并正确恢复所有值，而不会出现除法问题。 

另一种边缘情况是当值很大但仍然完全一致时，例如最大值接近的隐藏数组$10^9$。 乘法步骤$M_{ij} \cdot M_{ik}$可以达到$10^{18}$，但 Python 可以安全地处理这个问题，并且整数除法仍然精确，因为该结构保证了整除性。
