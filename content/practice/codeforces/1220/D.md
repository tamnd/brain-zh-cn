 ## 解决方案
 ## 问题理解

 我们得到了一组有限的正整数，但我们根据它构建的结构是无限的。 每个整数都是一个顶点，集合中的每个数字都被解释为“距离类型”。 对于每个值`d`在集合中，我们连接每对整数，其绝对差恰好是`d`。 

所以每个`d`不创建单个边，它创建跨越整数线的无限边族，有效地在所有间隔的整数之间施加约束`d`。 

任务是从集合中删除尽可能少的数字，以便生成的无限图变成二分图，这意味着所有整数都可以用两种颜色着色，以便每条边都连接相反的颜色。 

关键限制是`n ≤ 200000`，每个数字可以大到`10^18`。 这立即排除了图表本身的任何构造。 即使是单个选择的值`d`已经产生了无限多的边，因此该解决方案必须纯粹基于算术结构。 

幼稚的解释会尝试直接推理该图。 例如，人们可能会认为根据每种颜色引起的约束贪婪地分配颜色`d`，但多个之间存在冲突`d`值可以全局出现，并且在没有更深层次结构的情况下无法局部解析。 

第二种微妙的故障模式仅来自于奇偶直觉。 人们可能会猜测只有奇数才重要，或者删除所有奇数或所有偶数就足够了。 这很快就会失败。 例如，与`{1, 2, 3}`，仅保留所有偶数叶子`{2}`，这很好，但是保持`{1, 3}`即使两者都是奇数也有效。 真正的约束不是数字本身的奇偶性，而是它们引起的 gcd 的奇偶性结构。 

隐藏的结构是每个选择的距离`d`在无限线上强制执行周期性着色约束，并且仅当这些周期性不兼容时才会出现冲突。 

## 方法

 如果我们选择一个距离`d`，该图连接了不同的整数`d`。 这是无限路径的并集，每条路径都是带有步骤的链`d`。 这样的图是二分图：我们可以通过奇偶性对整数进行着色`x / d`。 

当存在多个距离时，我们实际上是叠加多个这样的周期性约束。 每个`d`强制约束奇偶校验必须如何取模`d`。 当这些约束迫使相互矛盾的平价要求时，就会产生冲突。 

一个蛮力的想法是尝试所有子集`B`，构造诱导约束系统，并检查二分性。 这是不可能的，因为有`2^n`子集。 

关键的见解是将问题重新解释为可分结构上的奇偶一致性问题。 如果我们选择一个子集`S`，该图是二分图当且仅当所有元素都在`S`可以指定标志`+1 / -1`始终如一地使得每个`d`强制执行有效的奇偶校验传播。 这减少了检查该组数字是否可以基于乘法奇偶校验结构分为两组。 

一个关键的简化是，只有具有不同的两个幂的数字的存在才是重要的。 将每个数字写为`d = 2^k * t`在哪里`t`很奇怪。 奇数部分决定基本约束类，而两者的幂决定兼容性。 

具有不同奇数部分的两个数字独立相互作用，因此我们可以按奇数部分进行分组`t`。 

在每个组中，我们只关心两个的最大幂。 如果我们将多个值保留在同一个奇数组中，则仅保留最大的值`k`之所以重要，是因为较小的权力在执行奇偶约束时是多余的。 

因此，对于每个奇数`t`，我们将所有数字压缩为一个代表`2^{k_max} * t`。 问题归结为选择其中一些代表，同时确保全球一致性。 唯一剩下的障碍是所有选定的代表不得在奇偶校验传播中产生矛盾，这减少了选择不混合不兼容奇偶校验级别的子集。 

最优策略变为：对于每个奇数`t`, 只保留最大的元素`v2`指数。 然后，在这些候选者中，唯一的冲突来自于混合不同的奇偶校验类别，这些奇偶校验类别是通过比较它们而引起的`k`。 我们可以将其建模为对奇偶校验的二分选择`k`。 为了最大化保留的元素，我们保留更大的奇偶校验类别（偶数或奇数）`k`），然后删除其余部分。

 ## 算法演练

 1. 将每个数字分解为`d = 2^k * t`， 在哪里`t`很奇怪。 这隔离了定义数字之间交互的结构组件。 
2. 按奇数部分对数字进行分组`t`。 在每个组中，我们只跟踪最大指数`k`。 这已经足够了，因为较小的指数永远不会比较大的指数产生更强的约束。 
3. 对于每个奇数组，创建一个代表`(t, k_max)`。 
4. 根据奇偶性将这些代表分为两类`k_max`（偶数或奇数）。 这是关键的减少：只有指数奇偶校验会影响全局兼容性。 
5. 选择两个类中较大的一个来保留，因为我们希望在保持一致性的同时最大化剩余元素。 
6. 将所有不属于所选类的代表输出为已移除元素。 

### 为什么它有效

 每个值都定义了整数的周期性奇偶校验约束。 奇数分量决定了一个独立的子系统，而 2 的幂决定了奇偶校验翻转如何传播。 一旦减少，约束之间的冲突仅取决于它们的指数奇偶性是否一致。 两个奇偶校验类的任何混合都会在诱导的 2 着色中引入矛盾。 因此，仅保留一个奇偶校验类可以保证二分性，而选择较大的类可以最大限度地减少删除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    arr = list(map(int, input().split()))

    groups = {}

    # step 1: compress by odd part, keep max power of two
    for x in arr:
        k = (x & -x).bit_length() - 1
        t = x >> k
        if t not in groups:
            groups[t] = (k, x)
        else:
            if k > groups[t][0]:
                groups[t] = (k, x)

    # step 2: split by parity of k
    even = []
    odd = []

    for t, (k, x) in groups.items():
        if k % 2 == 0:
            even.append(x)
        else:
            odd.append(x)

    # step 3: keep larger group
    if len(even) >= len(odd):
        keep = set(even)
    else:
        keep = set(odd)

    # step 4: output removed elements
    removed = [x for x in arr if x not in keep]

    print(len(removed))
    print(*removed)

if __name__ == "__main__":
    solve()
```该代码首先隔离最低设置位以有效计算二次方因子。 每个数字都被压缩为其奇数基数，并保留最强的可能的二次幂分量。 然后我们根据该指数的奇偶性来划分代表并选择占主导地位的一方。 

一个微妙的细节是，我们必须保留输出的原始值，而不是压缩的代表，因为输出需要输入集中的原始元素。

 ## 边缘情况

 关键的边缘情况是所有数字共享相同的奇数分量，例如`{1, 2, 4, 8}`。 在这种情况下，整个决策简化为指数奇偶校验分裂。 该算法将所有内容分组为`t = 1`，然后除以`k % 2`，确保一致的双方选择。 

另一种情况是当所有数字都是奇数时，例如`{3, 5, 7}`。 这里全部`k = 0`，因此所有内容都属于同一奇偶校验类别。 该算法保留所有元素并且不删除任何元素，这是有效的，因为没有引入冲突的奇偶校验结构。 

第三种情况是存在多个奇数组时，例如`{2, 3, 6, 12}`。 每个组都是独立处理的，只有代表之间的奇偶性一致性才重要。 分组步骤可以防止交叉干扰，即使简单的方法会错误地耦合不相关的组件，也能确保正确性。
