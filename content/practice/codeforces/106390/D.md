 ## 解决方案
 ## 问题理解

 我们有一系列木板，每块木板都有一个长度。 一张床架需要四块木板：两块木板应具有一种长度，另外两块木板应具有另一种长度。 由于不能保证精确相等的长度，因此我们通过计算每对内部的绝对差来测量每对与完美的距离。 

为了`k`床，我们必须选择`4k`木板并将它们分成`2k`对。 目标是最小化所有这些对内的差异之和。 所选择的索引的描述顺序并不重要，因为我们可以自由决定哪些木板形成对。 

木板数量可达`5 * 10^5`所有测试用例。 由于这种大小的限制，尝试许多子集或配对的方法是不可能的。 甚至`O(n^2)`工作量太大，因此解决方案需要接近排序复杂性。 

棘手的部分是认识到选择错误的配对结构可能会默默地失去最佳结果。 例如，考虑：```
1
4 1
1 2 3 4
```答案是：```
2
```粗心的方法可能会将最小的与最大的配对，从而导致`(1,4)`和`(2,3)`有成本`3 + 1 = 4`。 最好的配对是`(1,2)`和`(3,4)`, 给予`1 + 1 = 2`。 

另一种边界情况是当许多木板具有相同长度时：```
1
5 1
2 1 2 1 2
```答案是：```
0
```有足够的相等长度来创建两个完美的对。 任何只寻找严格增加长度的方法都会错误地错过这一点。 

## 方法

 直接的暴力解决方案将尝试决定哪个`4k`保留木板，然后尝试不同的配对方式。 即使在选择了平板支撑之后，可能的配对数量也会快速增长。 对于大量输入，这远远超出了时间限制。 

关键的观察结果是，在对木板长度进行排序后，最佳对总是由相邻值组成。 假设我们有两对和四个排序值：`a <= b <= c <= d`如果我们将极端配对为`(a,d)`和`(b,c)`，成本为：`d - a + c - b`如果我们将邻居配对为`(a,b)`和`(c,d)`，成本为：`b - a + d - c`第一个和第二个成本之间的差异是`2(c-b)`，它是非负的。 因此，交叉配对或跳远永远无法改善答案。 

这意味着问题变得简单得多。 将所有木板长度排序，然后取`2k`排序数组中的相邻对。 最小的`2k`相邻的间隙本身不一定足够，因为所选的对不能重叠，但因为我们需要精确`2k`对并且每对消耗两个连续元素，最佳构造是取第一个`4k`将木板分类并连续配对。 

我们不需要考虑跳过木板的原因是，两个选定木板之间未使用的木板只会增加穿过该区域的任何对木板的间隙。 移除未使用的木板并使用更近的邻居不会使答案变得更糟。

 | --- | --- | --- | --- |
 | 蛮力 | 指数| O(n) | 太慢了|
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 按非递减顺序对所有木板长度进行排序。 排序将潜在有用的对放在一起，因为接近的值会产生尽可能小的差异。 
2.看第一个`4k`按顺序排列的木板。 这些是将用于床的木板。 任何后来的木板至少都和这些一样大，并且不能比替换这些选择中的一个更好地形成一对。 
3. 连续配对选定的木板。 添加位置之间的差异`0`和`1`,`2`和`3`，依此类推，直到`4k`板材经过加工。 
4. 输出累加和。 结果是可能的最小偏差。 

为什么它有效：

 排序后，每个最优对都可以转化为相邻对，而不会增加其成本。 如果两个选定的木板之间有其他选定的木板，则将它们匹配在一起会比匹配更接近的值留下更大的距离。 重复应用此交换参数将删除所有不相邻的对。 第一个`4k`排序好的木板就足够了，因为任何跳过的木板都会比选定的木板大，并且只能使替换对相距更远。 因此最小的连续配对`4k`木板是最佳选择。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        a.sort()

        res = 0
        need = 4 * k

        for i in range(0, need, 2):
            res += a[i + 1] - a[i]

        ans.append(str(res))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```该解决方案首先对数组进行排序，因为整个参数取决于长度的顺序。 Python 整数处理最多可能的值`10^18`，因此不需要特殊的溢出处理。 

只有第一个`4k`值被访问。 循环增加了 2，因为每次迭代都会消耗一对。 边界正好是`4k`，因为每张床都需要四块木板，并且有`k`床。 

内存使用量来自存储木板长度列表。 该算法不需要额外的数据结构。

 ## 边缘情况

 对于这个案例：```
1
4 1
1 2 3 4
```该算法对值进行排序，取出所有四个木板，并形成对`(1,2)`和`(3,4)`。 累计成本为`1 + 1 = 2`，避免配对相距较远的值的常见错误。 

为了：```
1
5 1
2 1 2 1 2
```排序给出：```
1 1 2 2 2
```该算法只需要前四个值：```
1 1 2 2
```这些对是`(1,1)`和`(2,2)`，所以偏差为`0`。 额外的木板是不必要的，因为已经可以形成最小数量的对。 

对于非常大的木板长度，例如：```
1
4 1
1000000000000000000 999999999999999999 5 6
```排序给出：```
5 6 999999999999999999 1000000000000000000
```两对差异是`1`和`1`，所以答案是`2`。 计算仍然正确，因为 Python 整数支持任意精度。
