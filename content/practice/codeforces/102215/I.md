 ## 解决方案
 ## 问题理解

 我们有一个 (a \times a) 方形画布和一个 (b \times b) 方形画笔。 画笔正好从左上角开始，因此画布的这个（b \times b）部分已经被绘制了。 画笔只能水平或垂直滑动，画笔的每个位置都会绘制其覆盖的正方形区域。 在绘制画布的每个点之前，我们需要画笔中心移动的最小总距离。 官方声明确认答案始终是整数。 

约束对于恒定时间算术来说足够小，但对于排除任何与面积成比例的模拟来说又足够大。 当 (a) 与 (10^6) 一样大时，画布可以包含 (10^{12}) 个单位单元。 因此，在最坏的情况下，二次模拟将执行万亿次运算，远远超出 2 秒的限制所允许的范围。 即使在边长上进行线性扫描也是不必要的，因为几何形状具有可以直接求和的重复结构。 

第一个边缘情况是 (a=b)。 最初的画笔已经覆盖了整个画布，所以答案是零。 例如，输入`1 1`必须产生`0`。 始终添加至少一侧遍历的实现将错误地产生肯定的答案。 

第二种边缘情况是画笔正好穿过画布两次，例如 (a=4,b=2)。 答案是（6），而不是（8）。 粗心的实现可能会计算出四个完整边的长度（a-b=2），但最后阶段不需要另一个完整的环，因为剩余区域可以作为路径的终端部分处理。 

当 (a) 刚好高于 (2b) 的倍数时，例如 (a=7,b=3)，会出现第三种边缘情况。 答案是（14）。 这里最里面的剩余正方形的边 (1) 小于画笔。 将最后一个方块视为另一个普通环会产生差一错误。 最后的剩余部分必须单独处理。 

第四种边缘情况是能被 (2b) 精确整除。 对于(a=6,b=3)，答案是(9)。 如果我们简单地使用 (a \bmod 2b=0) 作为最终余数，公式会错误地将余数视为零。 最后一个完整的层必须被视为终端层。 封闭式实现通过减少完全递归层的数量并用 (2b) 替换零余数来处理此问题。 

## 方法

 直接模拟可以将画布视为网格并重复移动画笔，同时记录哪些单元格已被绘制。 在最小刷的情况下（b=1），必须访问每个单位单元，并且最优路径包含（a^2-1）个单位长度的移动。 对于最大输入(a=10^6,b=1)，即(999999999999)次移动。 因此，单个绘制单元的模拟是 (\Theta(a^2))，最坏情况的规模为 (10^{12}) 操作。 

蛮力方法之所以有效，是因为可以明确地检查每个运动，但它会失败，因为当我们向内移动时，会重复相同的几何图案。 关键的观察是，画笔绘制了正方形的外层后，未绘制的部分本身就是一个较小的正方形。 它的边长正好比前一个小 (2b)。 这就把几何问题变成了递归问题。 

假设当前未绘制的正方形的边长为 (x)。 如果 (x>2b)，则画笔必须扫过其四个侧面才能到达边界的每个部分。 画笔的中心沿每侧移动距离 (x-b)，因为中心范围从一个极限位置到另一个极限位置，画笔的 (b/2) 延伸超出每一端。 因此，完整的层成本

 [
 4(x-b)。 
]

 在这一层之后，剩余的未绘制的正方形有边

 [
 x-2b。 
]

 所以同样的推理可以再次应用。 

最终剩下的边最多变成(2b)。 这是递归的最后部分。 如果剩余边为 (r) 且 (b<r\le 2b)，则剩余正方形可以通过遍历三条边来完成，成本为

 [
 3(r-b)。 
]

 如果 (r\le b)，画笔已经覆盖了剩余的方块。 在用于最终封闭形式的紧凑递归中，该终端贡献由 (r-b) 表示。 它可以是负的，因为这是对前面的完整层遍历的修正，而不是独立的负运动。 这种递推及其代数展开给出了公认的封闭形式。 

令 (d) 为使用 (4(x-b)) 规则的完整外层的数量。 它们当前的边长是

 [
 a,\quad a-2b,\quad a-4b,\quad \ldots,\quad a-2(d-1)b。 
]

 他们的总成本是

 [
 4\sum_{i=0}^{d-1}\left(a-(2i+1)b\right)。 
]

 里面的和是一个算术级数：

 [
 da-b(1+3+5+\cdots +(2d-1))。 
]

 前 (d) 个奇数之和为 (d^2)，因此完整层的成本

 [
 4(da-d^2b)。 
]

 剩下的一边是

 [
 r=a-2db。 
]

 如果(r\le b)，则终端修正为(r-b)。 如果(r>b)，则为(3(r-b))。 

在计算(r)之前有一种特殊情况。 如果 (a) 可被 (2b) 整除，则使用 (d=a/(2b)) 将留下 (r=0)，尽管最后一层实际上是大小为 (2b) 的终端层。 相反，我们将 (d) 减一并设置 (r=2b)。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(a^2)) | (O(a^2)) | 太慢了 |
 | 递归环求和| (O(a/b)) | (O(a/b)) 如果递归实现 | 正确但不必要 |
 | 闭式算术 | (O(1)) | (O(1)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 读取画布面 (a) 和刷子面 (b)。 唯一需要的数量是这两个长度，因为最佳路径完全取决于同心方形层的顺序。 
2. 使用整数除法计算 (d=a/(2b)) 并计算 (r=a\bmod(2b))。 除法告诉我们边可以被 (2b) 减少多少次，而余数标识终端层。 
3. 如果 (r=0)，则将 (d) 减 1 并用 (2b) 替换 (r)。 这将最终的精确层视为终端层，而不是发明一个空的剩余正方形。 
4. 计算 (d) 完整层的贡献为
 [
 4(da-d^2b)。 
]
 这直接来自对所有层边长 (4(x-b)) 求和。 
5. 计算终端贡献。 当(r\le b)时，加上(r-b)。 当(r>b)时，添加(3(r-b))。 这两种情况对应于画笔是否已经覆盖了最终区域或者需要三次最终遍历来绘制它。 
6. 添加完整层贡献和终端贡献并打印结果。 所有运算均为整数运算，因此不存在浮点精度问题。 

### 为什么它有效

 不变的是，在每个完整的层之后，已绘制的区域正是该层生成的外边界，唯一仍然重要的区域是边长减少了 (2b) 的正方形。 对于每个非终端层，绘制整个边界需要画笔中心到达对应于该层的四个角的四个极限位置。 由于移动仅限于水平和垂直方向，因此访问所有四个极端位置都需要周长贡献 (4(x-b))。 一旦该层完成，相同的论点适用于较小的正方形。 当剩余边至多为 (2b) 时，该过程结束，其中终端公式给出了最短可能的最终遍历。 这样，总和就算出了一条可行路径，并匹配了每一层所需的不可避免的距离。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b = map(int, input().split())

    d = a // (2 * b)
    r = a % (2 * b)

    if r == 0:
        d -= 1
        r = 2 * b

    ans = 4 * (d * a - d * d * b)

    if r <= b:
        ans += r - b
    else:
        ans += 3 * (r - b)

    print(ans)

if __name__ == "__main__":
    solve()
```第一部分计算可以删除多少个完整的 (2b) 厚层。 变量`d`是使用四边公式的层数，而`r`是最后一层的侧面。 

可分性检查值得特别注意。 为了`a = 4, b = 2`，普通除法给出`d = 1`和`r = 0`。 正确的解释是零完整层，后跟边 (4) 的终端层，因此代码将这些值更改为`d = 0`和`r = 4`。 

表达式`4 * (d * a - d * d * b)`是算术级数和。 Python 整数具有任意精度，因此最大输入的答案几乎为 (10^{12})，不需要特殊的整数类型。 

终端条件使用`r <= b`，而不是`r < b`，因为其边恰好是画笔边的剩余正方形已经完全适合画笔内部。 这个边界条件使得`1 1`正确产生零。 

该代码不执行递归，也不分配网格。 它完全使用输入值和恒定数量的整数变量。

 ## 边缘情况

 对于`1 1`，我们有 (d=0) 和 (r=1)。 由于 (r\l​​e b)，终端贡献为 (r-b=0)，因此算法打印`0`。 最初的画笔已经绘制了整个画布，并且该公式不会发明任何运动。 

为了`4 2`，除以(2b=4)后的余数为零。 算法改变`d`从 (1) 到 (0) 的变化`r`从（0）到（4）。 最终贡献变为(3(4-2)=6)。 这正是捕获错误处理零余数的实现的情况。 

为了`3 1`，我们得到 (d=1) 和 (r=1)。 完整层贡献 (4(3-1)=8)，而终端校正为 (1-1=0)。 结果是`8`，它对应于从左上角开始访问所有九个晶胞的最短路径。 

为了`6 3`，(a) 正好是(2b)。 经过可分性调整后，`d=0`和`r=6`。 最终情况是(r>b)，所以答案是(3(6-3)=9)。 这抓住了整个问题由一个终端层组成的边界。 

为了`1000000 1`，画笔是单个点，因此必须访问每个单位单元。 公式返回`999999999999`，匹配官方示例中最大的答案。
