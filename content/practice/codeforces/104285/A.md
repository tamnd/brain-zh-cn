 ## 解决方案
 ## 问题理解

 我们得到了一条 DNA 链，在字母表上写成字符串`{A, T, C, G}`。 生物学为我们提供了构建互补链的精确转换规则：首先反转原始序列，因为两条链的运行方向相反，然后使用固定的配对规则替换每个核苷酸`A ↔ T`和`C ↔ G`。 

任务是准确模拟每个测试用例的转换。 输入提供了多个独立的 DNA 字符串，对于每个字符串，我们必须以与从 5' 端到 3' 端相同的从左到右方向输出互补链。 

约束足够小，每个测​​试用例的任何线性变换都足够了。 每个字符串的长度最多为 100，并且最多有 2000 个测试用例，因此即使是简单的每例 O(n) 解决方案也能在限制内轻松运行。 处理的字符总数最多为 200000 个，这对于 Python 来说是微不足道的。 

唯一可能导致实现失败的微妙之处是忘记了反转步骤。 一个简单的解决方案是仅应用替换而不进行反转，从而生成看起来有效的 DNA 字符串，但方向错误。 

例如，如果`s = "ATCG"`, 直接代入得到`"TAGC"`，但正确的过程首先相反：`"GCTA"`然后替换为`"CGAT"`。 

另一个可能的错误是替换后应用反转。 这也会给出错误的结果，因为补码会改变符号，而不是位置，因此运算顺序是固定的。 

## 方法

 强力解释将显式构造反向字符串，然后再次应用映射规则进行迭代。 这已经是线性时间并且有效，因为转换纯粹是本地的：一旦知道每个字符在反转字符串中的位置，就会独立映射。 

如果我们直接从末尾到开头迭代字符串并动态构建结果，我们也可以将其视为单次传递。 这消除了对显式反向副本的需要。 

关键的观察结果是，转换分解为两个独立的部分：索引的排列（逆序）和字符的替换。 由于每个元素的复杂度都是 O(1)，并且除了排序之外不相互依赖，因此我们可以将它们融合到一个通道中。 

暴力方法对每个字符串执行两次线性扫描。 优化版本执行其中一项，但渐近两者都是 O(n)。 改进主要是常数因子简化。

 | --- | --- | --- | --- |
 | 蛮力（反向+地图）| O(n) | O(n) | 已接受 |
 | 最优（单次反向迭代）| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取字符串`s`。 该字符串代表从 5' 端到 3' 端的一条 DNA 链。 
2. 准备核苷酸之间的映射：`A → T`,`T → A`,`C → G`,`G → C`。 这对生物配对规则进行编码，并独立应用于每个角色。 
3. 从最后一个字符到第一个字符遍历字符串。 这隐式地执行反转步骤，而不构造新的反转字符串。 
4. 对于反向遍历期间遇到的每个字符，使用映射替换它并将结果附加到输出缓冲区。 
5、处理完所有字符后，输出构造好的字符串。 

我们以相反顺序迭代而不是显式反向迭代的原因是，它可以避免额外的内存分配，同时保持正确性。 由于反转后每个位置都是独立的，因此流式传输变换是等效的。 

### 为什么它有效

 DNA 变换是两个函数的组合：`P`反转索引和替换`C`映射每个字符。 因为`C`逐点作用，不依赖于邻居或全局结构，组合`C(P(s))`可以通过在排列索引顺序上的一次遍历中应用这两个操作来计算。 这确保了每个角色在其正确的最终位置上精确地变换一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    mp = {
        'A': 'T',
        'T': 'A',
        'C': 'G',
        'G': 'C'
    }

    out = []
    for _ in range(t):
        n = int(input())
        s = input().strip()

        res = []
        for i in range(n - 1, -1, -1):
            res.append(mp[s[i]])
        out.append("".join(res))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案构建直接字符映射并从右到左处理每个字符串。 循环结束`i = n-1 ... 0`隐式执行反转。 每个字符使用字典查找转换一次，时间复杂度为 O(1)。 为了提高效率，结果会累积在一个列表中，并且每个测试用例连接一次。 

使用`strip()`确保尾随换行符不会干扰索引。 输出被缓冲以避免重复写入。

 ## 边缘情况

 对于单字符输入，例如`A`，算法读取索引0，将其直接映射到`T`，并产生`"T"`。 由于反转对单个元素没有影响，因此正确性仅取决于映射表，该表仍然有效。 

对于像这样的输入`ATCG`，遍历顺序变为`G → C → T → A`。 每个字符都是独立映射的，产生`C → G`,`G → C`,`T → A`,`A → T`，连接到`"CGAT"`。 这证实了反转是通过迭代方向隐式处理的，并且不需要单独的数组。
