 ## 解决方案
 ## 问题理解

 我们得到了从 1 到 n 的数字排列。 目标是将此排列按升序排序，但我们不允许直接按照交换的执行顺序输出交换。 相反，我们必须首先输出交换操作列表，然后接收系统将按字典顺序对这些操作进行排序并按排序顺序执行它们。 

每个操作都是一对索引 (x, y)，这意味着我们交换数组中位置 x 和 y 处的元素。 当所有操作都按增加 x 排序，并在 x 绑定时按 y 排序后，按该顺序应用它们必须将排列转换为恒等排列。 

关键的困难是我们不直接控制执行顺序。 我们只控制交换的多重集，排序步骤将对它们重新排序。 因此，该构造必须在按字典顺序排序的执行下有效。 

约束允许每个测试用例 n 最多 100000 个，总 n 最多 1000000 个。这排除了任何二次方，例如模拟任意交换序列或重复搜索放错位置的元素。 我们需要每个测试用例都是线性或接近线性的结构。 

一种简单的方法是模拟冒泡排序并在发生交换时发出交换。 这会失败，因为冒泡排序依赖于时间排序，但这里执行顺序是按索引全局排序的。 另一个天真的尝试是使用选择交换直接排序（将正确的元素交换到位置 i）。 这也会失败，因为涉及较小指数的掉期可能会比预期更早执行并破坏预期的中间结构。 

当多个交换共享相同的左索引时，会出现微妙的边缘情况。 例如，如果我们产生像 (2, 5)、(2, 3)、(4, 5) 这样的交换，它们的执行顺序就会变成 (2, 3)、(2, 5)、(4, 5)，除非仔细设计，否则这可能与我们预期的顺序不匹配。 这意味着解决方案在交换的生成方式方面必须本质上是单调的。 

## 方法

 核心挑战是间接控制执行顺序。 由于交换是按 (x, y) 排序的，因此我们希望设计交换，使得该排序顺序已经与正确的排序过程兼容。 

一个蛮力的想法是重复选择最小的错位元素，并使用直接交换与其正确位置将其交换到位。 如果按该顺序执行，则会产生有效的排序序列。 然而，排序顺序约束完全打破了这一点，因为涉及较小索引的交换总是首先执行，而不管预期的顺序如何。 这破坏了任意交换序列的正确性。 

关键的观察是，我们可以通过仅生成在字典顺序下自然安全的交换来强制正确性。 一种有效的方法是模拟插入式排序，但要确保交换始终涉及固定的锚结构，以便排序不会干扰。 

实现此目的的一种简洁方法是使用确定性过程将排列构建为恒等式，其中使用仅涉及增加左端点的交换将每个元素移动到其正确位置。 我们构建交换的方式是模仿使用始终遵循字典顺序的交换序列将每个值带到其正确的索引。 

一个有用的重新表述是考虑将值 i 放入位置 i 。 我们处理从 1 到 n 的值，确保当我们固定位置 i 时，我们输出的所有交换要么具有左端点 i 要么具有更大的索引，因此较早的交换不会错误地影响后面的结构。 

这导致了一种结构，我们维持值的位置，并使用类似相邻的修正将每个值交换到其目标，表示为与受控端点的一般交换。

最终的构造最多产生 n 次交换，因为每个元素都在恒定的摊销操作中移动到位。

 ## 算法演练

 该构造依赖于跟踪每个值当前所在的位置，并以受控方式将其交换到正确的位置。 

1. 构建一个数组 pos，使得 pos[v] 是排列中值 v 的当前索引。 这让我们可以在 O(1) 时间内找到任何值。 
2. 将 v 从 1 迭代到 n，因为我们希望将值按升序放置到正确的位置。 
3. 对于每个值 v，虽然 pos[v] 不等于 v，但我们通过将其与当前位置 v 处的元素交换来将其移向目标位置 v。这是通过在 pos[v] 和 v 之间执行交换来完成的。 
4. 每次交换 (i, j) 后，更新数组和 pos 数组，以使位置保持一致。 
5. 将每个交换 (i, j) 记录在列表中。 
6. 输出所有记录的交换。 关键的属性是交换是按照确定的顺序生成的，该顺序与增加的左端点对齐。 

步骤 3 正确的原因是，将 pos[v] 与 v 交换使值 v 更接近其最终目的地，而不会以破坏正确性的方式干扰已经固定的前缀。 

### 为什么它有效

 当我们处理值 v 时，所有小于 v 的值都已经固定在正确的位置。 交换 (pos[v], v) 仅涉及在排列的结构良好的状态下至少为 v 的索引。 这确保了较早的位置在修复后永远不会被修改。 由于交换是按照其左端点行为的递增顺序生成的，因此字典排序不会以有害的方式改变其预期的执行顺序。 该结构保持了位置 1 到 v-1 已经正确并且不再被触及的不变量，因此未来的交换不会破坏它们。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a = [0] + a  # 1-indexed

    pos = [0] * (n + 1)
    for i in range(1, n + 1):
        pos[a[i]] = i

    ops = []

    for v in range(1, n + 1):
        while pos[v] != v:
            i = pos[v]
            j = v

            ops.append((min(i, j), max(i, j)))

            ai, aj = a[i], a[j]
            a[i], a[j] = a[j], a[i]
            pos[ai], pos[aj] = pos[aj], pos[ai]

    print(len(ops))
    for x, y in ops:
        print(x, y)

if __name__ == "__main__":
    solve()
```该代码维护排列数组和反向查找表，因此每次交换的时间复杂度为 O(1)。 使用直接交换将每个值重复拉向其正确位置，确保每次迭代的进展。 

一个微妙的实现细节始终将交换存储为排序对（最小值，最大值）。 这是必需的，因为执行顺序取决于排序对，而不是我们打印端点的顺序。

 ## 边缘情况

 一种重要的边缘情况是排列已经排序。 该算法不执行交换，因为对于所有 v pos[v] == v，因此操作列表保持为空，这在约束 k ≤ n 下有效。 

另一种情况是完全逆转。 对于输入 [n, n-1, ..., 1]，每个值 v 在单个操作中直接交换到位置 v，因此该过程在线性时间内终止，最多进行 n/2 次交换。 

一个微妙的情况是，值几乎正确，但形成一个长循环，例如 [2, 3, 4, 5, 1]。 该算法通过首先修复 1 来打破循环，这会通过结构进行级联校正，而无需重新访问已经固定的位置，从而确保没有无限循环或冗余交换。
