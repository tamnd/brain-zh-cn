 ## 解决方案
 ## 问题理解

 我们从一棵树开始，其顶点编号为 1 到 n。 最初，每个顶点 i 都带有不同的颜色 i，因此配置只是放置在节点上的身份排列。 

唯一允许的操作是选择一条边，交换其端点处的两种颜色，然后永久删除该边。 由于一条边只能使用一次，因此每个操作序列都对应于选择一些边的子集并决定使用它们的顺序，但树结构保证只要所选边有效，顺序就不会影响最终的可达配置。 

最终状态是通过沿着所使用的边缘移动颜色而产生的跨节点的颜色排列。 该问题询问可以获得多少种不同的最终颜色排列。 

输入大小 n 最大可达 150000，这排除了对边的排列或子集的任何指数探索。 任何解决方案都必须在大致线性或接近线性的时间内将问题减少到树上的结构计数。 试图模拟交换或枚举可达状态的解决方案是立即不可行的，因为即使排列的数量也是 n!。 

局部思考会产生一个微妙的问题。 人们可能认为每条边独立地允许交换或不交换，给出 2^(n−1) 个结果。 这是错误的，因为交换是相互作用的：使用一条边将颜色移动到子树中，从而改变了未来交换的作用。 另一种不正确的方法是将交换视为相邻节点上的任意换位并假设独立性，这忽略了树中路径施加的全局一致性约束。 

当树是简单路径时，会出现第二种边缘情况。 即使在那里，可达排列也并非段的所有排列，除非正确处理奇偶校验约束。 任何忽略奇偶性或二分性的简单模型都将在小路径图上失败。 

## 方法

 关键的困难在于操作是边缘上的本地交换，但其效果是标签的全局移动。 由于边在使用后被删除，因此每条边沿其关联分量最多贡献一次转置。 

重新解释该过程的一个有用方法是将每条边视为潜在的匹配操作，该操作要么交换两个端点标签，要么有效地让组件合并和传播排列。 使用边缘后，两个端点断开连接，但交换的信息已经传播。 

如果我们查看选择用于交换的固定边子集，则产生的效果是，在由这些边形成的每个连接组件内，颜色根据沿该组件的边缘转置生成的组进行完全排列。 因为树没有循环，所以由所选边引起的每个连接组件本身就是一棵树，并且任何树都允许生成与由其二分结构引起的奇偶校验约束一致的所有排列。 

关键的简化是翻转视角：我们考虑构建一个结构，其中每个节点要么充当“固定根”，要么参与可逆交换组件，而不是选择要交换的边。 可到达的配置完全对应于将树划分为通过删除一些边而形成的组件，并且在每个组件内，可实现的排列的数量仅由其大小和结构决定。

更深入的群论观察表明，在大小为 k 的树组件上，如果该组件是二分的（所有树都是二分的），则沿边的交换会精确地生成 k 个元素上的交替组，但奇偶校验约束消失，因为边在使用后被删除，只要尊重连通性，就允许沿路径任意转置。 这导致了一个关键的简化：每个连接的组件都对其节点贡献阶乘自由度。 

因此，该过程简化为：每个最终状态对应于将节点划分为通过删除一些边形成的组件，并且每个大小为 s 的组件贡献 s！ 该组件内可能的标签分配。 答案变成了所有边子集的总和，但我们不是枚举它们，而是在树结构上使用 DP。 

我们将树生根并自下而上地处理它。 对于每个节点，我们根据它是否向上连接来计算其子树可以排列多少种方式。 这种转换类似于计算选择父项和子项之间的边是“剪切”还是“保留”的方法，并结合结果组件的阶乘贡献。 

这导致了一个经典的树DP，其中我们为每个节点计算一个类似多项式的贡献，该贡献使用组合系数合并子子树，最终产生按子树大小归一化的贡献的乘积。 最终的封闭形式大大简化了：答案是n！ 乘以特定乘法 DP 中累积的子树大小贡献的倒数所有节点的乘积。 

这种结构的出现是因为顶点的每个排序都可以唯一地分解为每个子树何时分离的选择。 

生成的最优解决方案完全避免了枚举子集，并使用 DFS 以线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解边缘子集 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了|
 | 子树组合上的树DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们以节点 1 为树的根。对于每个节点，我们计算两个量：其子树的大小和表示该子树贡献的有效内部配置数量的 DP 值。 

1. 从根运行 DFS 来计算子树大小。 每个节点都会累加其子节点的大小，再加上自身的大小。 这是必要的，因为每个贡献取决于每个边缘决策下分组的节点数量。 
2. 在同一 DFS 期间，计算聚合子节点贡献的每个节点的 DP 值。 对于叶节点，DP 值为 1，因为只有一种方式来排列单个元素。 
3. 当处理具有子节点 v1, v2, ..., vk 的节点 u 时，我们认为每个子子树可以保持连接状态，也可以通过其连接边分离。 关键是合并子子树对应于其节点的交错排列，这引入了多项系数。 
4. 迭代地合并子贡献。 假设我们已经合并了一些总大小为 S 且 DP 值为 dp_u 的子项。 当添加大小为 sz[v] 和 dp[v] 的子 v 时，合并的方式数乘以 C(S + sz[v], sz[v]) 乘以 dp[v]。 这说明了在组合排序中选择子子树的位置。 
5. 处理完所有子树后，dp[u] 表示以 u 为根的子树的有效配置数。 
6. 最终答案是 dp[1]，对 998244353 取模。 

组合系数使用阶乘和最多 n 的模逆来计算。 预先计算阶乘和逆阶乘以计算 O(1) 中的二项式系数。 

### 为什么它有效

维护的不变式是 dp[u] 计算在 u 的子树中排列所有节点的方式数量，以便考虑由边缘交换操作引起的相对排序。 每次合并子子树时，我们都会有效地选择其节点如何与已处理的节点交错，并且由于树结构确保了不相交的子树，因此这种交错在子树之间是独立的。 由于每个有效的最终配置都唯一对应于一系列此类合并，因此不会对任何配置进行两次计数，并且不会遗漏任何配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

MOD = 998244353

def solve():
    n = int(input())
    g = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact[n] = pow(fact[n], MOD - 2, MOD)
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def C(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    parent = [0] * (n + 1)
    sz = [0] * (n + 1)
    dp = [1] * (n + 1)

    def dfs(u, p):
        parent[u] = p
        sz[u] = 1
        dp[u] = 1
        for v in g[u]:
            if v == p:
                continue
            dfs(v, u)
            sz[u] += sz[v]

            dp[u] = dp[u] * dp[v] % MOD
            dp[u] = dp[u] * C(sz[u] - 1, sz[v]) % MOD

    dfs(1, 0)
    print(dp[1])

if __name__ == "__main__":
    solve()
```该实现预先计算阶乘和逆阶乘以支持恒定时间二项式系数计算。 DFS 计算子树大小并自下而上构建 DP。 

过渡`C(sz[u] - 1, sz[v])`编码在父级子树排序中已累积的节点中为子子树选择位置。 乘以`dp[v]`整合了孩子的内部安排，而孩子之间的相乘则强化了独立性。 

根结果是有效全局配置的总数。 

## 工作示例

 考虑一棵由三个节点组成的小树：1 连接到 2，连接到 3。 

我们隐式计算阶乘并从 1 开始运行 DFS。 

| 节点| 儿童加工| sz[u] | dp[u] | 说明|
 | --- | --- | --- | --- | --- |
 | 3 | 叶| 1 | 1 | 基本情况|
 | 2 | v = 3 | 2 | 1 * C(1,1)=1 | 插入子树只有一种方法 |
 | 1 | v = 2 | 3 | 1 * C(2,2)=1 | 最终汇总|

 结果为 1，意味着在这种合并解释下，此结构中只能到达一种不同的配置。 

该跟踪演示了子树合并如何处理线性链，而不引入结构之外的额外组合分支。 

现在考虑一颗中心为 1、叶子为 2、3、4 的星形。 

在节点 1 处，我们按顺序合并叶子。 

第一片叶子之后：sz=2，dp=1

 第二片叶子之后：sz=3, dp=1 * C(2,1)=2

 第三片叶子之后：sz=4, dp=2 * C(3,1)=6

 这与叶子可以交错成 3 个的事实相匹配！ 围绕中心排序的方式。 

该跟踪强调分支节点通过子树的多项式插入贡献组合爆炸。

 ## 边缘情况

 对于单个节点，没有边可以执行交换，因此唯一可能的图片是初始图片。 DP正确初始化dp[1] = 1并立即返回。 

对于路径图，每个子树合并都按顺序发生，并且二项式系数结构折叠为 1 链，确保不会引入人工分支。 DFS 确保每个节点仅合并一次，从而保持正确性。 

对于星图，所有叶子都是连接到中心的独立子树。 每次叶子插入都会根据二项式系数乘以交错数量，并且算法正确地累积与叶子附着顺序排列相对应的阶乘增长。
