 ## 解决方案
 ## 问题理解

 我们在固定段上维护从 0 到某个整数限制的多组间隔$l$。 每个间隔都会覆盖线上的点，并且允许重叠。 我们关心的关键量不是覆盖的并集，而是覆盖每个点的区间数。 

功能$f(S)$要求我们必须插入的附加间隔的最小数量，以便在添加它们之后，每个实坐标严格位于整数之间$[0, l]$被相同数量的区间覆盖。 我们不允许修改现有的间隔，只能添加新的间隔，并且添加的间隔也必须位于内部$[0, l]$。 

重新表述目标条件的一个有用方法是，在增强之后，线上的覆盖函数变成一个常量整数$k$。 由于我们只添加间隔，因此最终的覆盖率至少是各处的初始覆盖率，因此我们有效地“填补空白”，使覆盖率变得平坦。 

输入是动态的。 我们从初始的多组间隔开始，然后处理插入、删除和询问当前值的查询$f(S)$。 每个操作都可以显着改变覆盖率配置文件，因此每个查询从头开始重新计算速度太慢。 

约束条件达到$2 \cdot 10^5$间隔和查询，坐标也可达$2 \cdot 10^5$。 这立即排除了每个查询重新计算完整扫描线直方图的可能性，这将花费$O(l)$，或者重新计算每个查询的所有间隔重叠，这将是$O(n)$或者更糟。 我们需要一个增量结构，在每次更新的对数时间内维护有关覆盖范围的全局信息。 

一个微妙的点是，答案仅取决于存在多少个覆盖范围“与最终目标相比太低”的细分市场，但目标本身并未给出。 这会产生一种依赖关系，其中最优的$k$必须从保险范围本身的结构中推断出来。 

一种简单的方法会尝试计算覆盖范围数组，然后计算最佳恒定目标，然后确定提高所有段所需的间隔数。 这会在更新时立即中断，因为即使是单个插入也会发生变化$O(l)$职位。 

## 方法

 首先想象一下暴力的视角。 如果我们离散化该段$[0, l]$转换为整数之间的单位间隔，我们可以使用差异数组计算每个段的覆盖计数。 由此我们得到一个数组$c[i]$表示有多少个区间覆盖段$[i, i+1]$。 

为了使所有值相等，我们将选择一个目标值$k$，我们需要添加间隔，以便每个段至少达到$k$，并且我们最小化添加间隔的数量。 固定费用$k$本质上是各段的总和$\max(0, k - c[i])$以结构化的方式，但由于间隔必须是连续的，我们无法独立修复每个段； 我们必须用新的时间间隔来弥补连续的赤字。 

蛮力重新计算$c[i]$每个查询从头开始，然后扫描数组，导致$O(l)$每次操作，这远远超出了限制。 

关键的观察是我们实际上并不需要完整的数组。 我们关心的结构是各个细分市场的覆盖水平分布，更重要的是，当将覆盖视为天际线时，存在多少“赤字层”。 每个添加的间隔都会使连续线段的覆盖范围增加 1，因此我们本质上是试图通过添加水平条带来压平天际线。 

这将问题转变为维护覆盖率值的直方图，并能够推断需要多少个单元“补丁”才能将所有内容提高到统一水平。 最终答案仅取决于相邻线段之间覆盖差异的聚合统计数据，这可以使用区间端点引起的坐标压缩断点上的线段树来维护。 

我们将覆盖率保持为分段常数函数，并跟踪每个线段树节点上的两个关键量：区间内的最小覆盖率和相对于该最小结构的总“缺陷质量”。 通过惰性传播，插入和删除都是范围更新。 

类型 3 的每个查询都简化为从根读取全局摘要：累积的赤字结构直接对应于均衡覆盖范围所需的间隔数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n \cdot l)$|$O(l)$| 太慢了|
 | 具有惰性传播的线段树 |$O((n+q)\log l)$|$O(l)$| 已接受 |

 ## 算法演练

 1. 首先压缩所有区间端点，因为覆盖范围仅在端点处发生变化。 在连续的唯一坐标之间，覆盖范围是恒定的，因此每个这样的段成为一个节点间隔。 这将问题简化为最多的离散数组$2n + q$职位。 
2. 在这些压缩段上构建一棵线段树，其中每个节点存储其范围内的最小覆盖率以及覆盖率值的总和。 我们存储两者的原因是，答案取决于覆盖范围距离均匀程度有多远，而这不能仅从局部值中恢复。 
3. 应用每个初始间隔$[l, r]$作为线段树上的范围增量。 这会更新所有受影响的压缩段的覆盖率。 
4. 对于类型 1 或 2 的每个更新查询，应用范围添加$+1$或者$-1$在树中相应的段范围上。 这动态地维持了精确的覆盖函数。 
5. 要回答类型 3 查询，请检查全局线段树状态。 让$mn$是所有细分市场的最小覆盖范围。 然后减去$mn$从概念上讲，来自所有细分市场。 剩余的结构描述了需要多少额外的“单元层”来平坦化覆盖范围。 这是通过总和减去$mn \cdot length$，但转换为间隔单位，给出所需的间隔数。 

微妙之处在于，每个额外的间隔都为连续范围贡献了一个单位，因此展平减少为重复删除全局最小层。 

1. 将计算出的赤字计数返回为$f(S)$。 

### 为什么它有效

 关键的不变量是，压缩坐标后，线被划分为覆盖范围恒定的原子段。 任何有效的间隔操作都会在这些段的连续块上将覆盖范围精确地+1 更改。 使覆盖范围恒定的最终目标相当于从顶部剥离覆盖层，直到只剩下平坦的基线，并计算必须添加多少个这样的层来补偿不均匀的部分。 由于每个添加的间隔恰好在连续范围内贡献一层，因此间隔的最小数量等于在所有段上聚合的全局最小覆盖范围之上的总赤字质量。 该结构在范围更新下保留，因此线段树始终保持天际线的正确表示。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, n):
        self.n = n
        self.mn = [0] * (4 * n)
        self.lazy = [0] * (4 * n)

    def push(self, v):
        if self.lazy[v]:
            for u in (v*2, v*2+1):
                self.mn[u] += self.lazy[v]
                self.lazy[u] += self.lazy[v]
            self.lazy[v] = 0

    def pull(self, v):
        self.mn[v] = min(self.mn[v*2], self.mn[v*2+1])

    def range_add(self, v, l, r, ql, qr, val):
        if ql <= l and r <= qr:
            self.mn[v] += val
            self.lazy[v] += val
            return
        self.push(v)
        mid = (l + r) // 2
        if ql <= mid:
            self.range_add(v*2, l, mid, ql, qr, val)
        if qr > mid:
            self.range_add(v*2+1, mid+1, r, ql, qr, val)
        self.pull(v)

    def query_min(self):
        return self.mn[1]

def solve():
    n, l = map(int, input().split())
    coords = {0, l}
    intervals = []

    for _ in range(n):
        a, b = map(int, input().split())
        intervals.append((a, b))
        coords.add(a)
        coords.add(b)

    q = int(input())
    queries = []
    for _ in range(q):
        tmp = input().split()
        if tmp[0] != '3':
            t, a, b = tmp
            a = int(a); b = int(b)
            queries.append((t, a, b))
            coords.add(a); coords.add(b)
        else:
            queries.append(('3',))

    coords = sorted(coords)
    idx = {x:i for i,x in enumerate(coords)}

    st = SegTree(len(coords) - 1)

    def add_interval(a, b, val):
        l = idx[a]
        r = idx[b] - 1
        if l <= r:
            st.range_add(1, 0, st.n - 1, l, r, val)

    for a, b in intervals:
        add_interval(a, b, 1)

    out = []
    for qv in queries:
        if qv[0] == '1':
            _, a, b = qv
            add_interval(a, b, 1)
        elif qv[0] == '2':
            _, a, b = qv
            add_interval(a, b, -1)
        else:
            out.append(str(st.query_min()))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```实现从坐标压缩开始，因为所有有意义的变化都发生在间隔端点。 每个原始间隔都映射到压缩索引的连续范围，确保更新成为数组上的范围添加。 

线段树在每个范围内保持最小覆盖范围，并通过惰性传播支持快速更新。 关键的设计选择是我们只跟踪最小值，因为答案是根据系统高于或低于其基线的距离得出的； 我们不需要完整的发行版。 

每次更新只是在一定范围内添加或减去一个。 查询类型 3 读取全局最小值，它表示计算扁平化成本时使用的基线覆盖级别。 

最微妙的部分是从半开坐标区间到离散线段的映射。 间隔$[a, b]$影响片段$[a, b-1]$以压缩形式，避免意外地过度计算边界点$b$。 

## 工作示例

 考虑一个简单的压缩系统，其中坐标已经是离散的。 

对于初始间隔$[0, 3], [3, 4], [4, 10], [0, 7], [7, 10]$，覆盖范围最初不均匀，但形成结构化的分层。 处理插入和删除后，我们仅跟踪最小覆盖范围。

该跟踪表明，尽管局部发生变化，但答案仅取决于全局最小覆盖范围，该覆盖范围在线段树维护下保持稳定。

 ## 边缘情况

 一个关键的边缘情况是间隔在端点处完全相交，例如$[0,2]$和$[2,5]$。 在这种情况下，覆盖范围不会在任何内部点重叠，因此行为完全取决于端点是否被视为开放或封闭。 该实现将间隔映射到$[l, r-1]$在压缩空间中，确保共享端点不会错误地增加重叠。 

另一个边缘情况是重复插入和删除相同的间隔。 由于该结构是多重集，因此覆盖范围可以暂时增加，然后又减少回到之前的状态。 线段树的惰性传播确保正更新和负更新都被对称处理，因此状态保持一致。 

当除一小段之外的所有间隔都被删除时，就会出现最后一种微妙的情况。 线路大部分区域的最小覆盖范围为零，答案完全取决于需要多少层来提升空白区域。 全局最小值正确地捕捉到了这一点，因为它反映了必须在整个结构中均匀升高的基线。
