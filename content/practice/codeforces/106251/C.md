 ## 解决方案
 ## 问题理解

 我们给出了从 1 到 n 的整数的排列，这意味着每个位置都恰好指向另一个位置，并且每个位置都只指向一次。 这种结构可以看作是一个有向图，其中每个节点恰好有一个出边和一个入边，因此该图分解为不相交的有向循环。 

任务是将三种颜色中的一种分配给每个节点，以便每个循环都在特定模式下着色。 对于长度均匀的循环，我们必须沿循环交替使用两种颜色。 对于奇数长度的循环，我们仍然沿着循环交替两种颜色，但一个节点无法干净地适应交替，因此它接收第三种不同的颜色。 

输出只是分配给从 1 到 n 的每个索引的颜色。 

尺寸排列达到典型 Codeforces 限制（通常约为 2 倍 10^5 或 10^6）所隐含的约束，立即排除了对元素对的任何二次模拟。 任何重复访问节点或每个周期扫描数组的方法都会太慢。 需要线性遍历，这意味着每个节点必须被访问恒定的次数，最有可能的是通过标记访问过的节点并直接遍历循环。 

当所有周期的长度均为一时，会出现一种微妙的边缘情况。 例如，如果排列为 [1]，则循环的长度为奇数并且由单个节点组成。 简单的交替着色方法会尝试分配两种颜色，但无法一致地分配第三种颜色，但正确的输出只是该节点必须使用特殊颜色着色。 

另一个边缘情况是大型单循环，例如 [2, 3, 4, ..., n, 1]。 如果它的长度是奇数，则必须有一个节点成为特殊颜色，并且如果粗心的实现在周期中重新开始着色或无法在遍历中保留状态，那么粗心的实现可能会意外地分配两个特殊节点。 

## 方法

 强力方法将重复选择一个未访问的节点，遵循排列指针直到返回到起点，然后在存储完整循环的同时尝试分配颜色。 这已经接近最优，但如果实施效率低下，它可能会多次重新扫描或重新行走循环，从而在最坏的情况下导致二次行为，其中存在长度为 n 的单个循环并且使用重复扫描来检测结构。 

关键的观察结果是，排列结构保证了划分为不相交的循环，并且每个循环都可以独立处理。 一旦我们进入一个循环，我们就可以一次遍历它，记录或直接分配颜色，并且永远不会再次访问它的节点。 这消除了对局部循环结构之外的全局推理的任何需要。 

因此，最佳解决方案是对所有节点进行一次遍历，每当遇到未访问的节点时启动循环遍历，并根据循环内的奇偶校验位置动态对节点进行着色。 如果循环长度是奇数，我们会在完成交替模式后故意为最后一个节点分配特殊颜色。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力循环重新扫描 | O(n^2) | O(n^2) | O(n) | 太慢了|
 | 循环分解一次| O(n) | O(n) | 已接受 |

 ## 算法演练

1. 维护一个所有节点都初始化为 false 的访问数组。 这确保每个节点恰好属于一个已处理的循环，并且在以后的遍历中永远不会重新访问。 
2. 迭代从1到n的所有节点。 每当发现一个未访问的节点时，它就成为新循环的起点。 
3. 重复沿着排列指针遍历循环，直到回到起始节点。 遍历时，按照节点在循环中出现的顺序收集列表中的节点。 这种顺序很重要，因为着色取决于循环中的相邻情况。 
4. 收集完循环后，确定其长度k。 如果 k 是偶数，则使用两种颜色沿列表交替分配颜色，确保循环中的相邻节点接收不同的颜色。 
5. 如果 k 是奇数，则为前 k 减去一个节点分配交替颜色，然后为最后一个节点分配特殊的第三种颜色。 这解决了奇偶校验不匹配的问题，奇偶校验不匹配导致奇数周期上不可能出现纯双色交替。 
6. 将分配的颜色存储在按节点索引的输出数组中。 

这种遍历安全的原因是，一旦我们离开一个节点，跟随它的出边总是保持在同一个循环内，所以我们永远不会意外地合并或分裂结构。 

### 为什么它有效

 该排列保证每个节点恰好位于一个简单的有向循环中，这意味着图分解为不相交的闭环。 在循环内，每个节点在循环顺序的无向意义上恰好有两个邻居。 交替两种颜色在长度均匀的循环中效果非常好，因为环绕时奇偶校验是一致的。 在奇数长度的循环中，奇偶校验在每个边沿后翻转，因此返回到起点会产生矛盾，这可以通过在一个节点处中断交替来解决。 由于循环是不相交的，因此对一个循环进行着色永远不会限制另一个循环，因此独立处理是有效的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = [0] + list(map(int, input().split()))

    vis = [False] * (n + 1)
    color = [''] * (n + 1)

    for i in range(1, n + 1):
        if vis[i]:
            continue

        cycle = []
        cur = i

        while not vis[cur]:
            vis[cur] = True
            cycle.append(cur)
            cur = p[cur]

        k = len(cycle)

        if k % 2 == 0:
            for j in range(k):
                color[cycle[j]] = 'R' if j % 2 == 0 else 'B'
        else:
            for j in range(k - 1):
                color[cycle[j]] = 'R' if j % 2 == 0 else 'B'
            color[cycle[-1]] = 'G'

    print("".join(color[1:]))

if __name__ == "__main__":
    solve()
```核心实现直接遵循循环提取。 访问数组可以防止跨周期重新访问节点，确保线性复杂度。 循环列表保留顺序，以便交替着色沿边缘保持一致。 唯一微妙的决定是通过为最后收集的节点分配特殊颜色来处理奇数循环，这是有效的，因为遍历顺序与循环顺序相匹配。 

## 工作示例

 考虑由 p = [2, 1, 4, 3] 给出的大小为 4 的排列。 这形成两个循环：(1, 2) 和(3, 4)。 

| 步骤| 当前节点| 到目前为止已建成的自行车| 行动|
 | ---| ---| ---| ---|
 | 1 | 1 | [1] | 访问 1 |
 | 2 | 2 | [1, 2] | 沿着边回到 1 并停止 |
 | 3 | 3 | [3] | 开始新的周期|
 | 4 | 4 | [3, 4] | 闭环 |

 两个周期的长度相同，因此我们交替颜色。 循环(1、2)变为R、B，循环(3、4)变为R、B。 

现在考虑 p = [2, 3, 1]，长度为 3 的单个循环。 

| 步骤| 当前节点| 到目前为止已建成的自行车| 行动|
 | ---| ---| ---| ---|
 | 1 | 1 | [1] | 开始 |
 | 2 | 2 | [1, 2] | 继续 |
 | 3 | 3 | [1,2,3]| 返回开始 |

 由于循环长度是奇数，节点 1 和 2 得到交替的颜色 R 和 B，而节点 3 得到 G。 

这些示例证实了遍历顺序与循环结构相匹配，并且每个循环内的着色独立地保持一致。

 ## 边缘情况

 单节点循环（例如 n = 1 且 p1 = 1）会产生长度为 1 的循环。 遍历只收集该节点，由于长度是奇数，算法直接为其分配特殊颜色。 循环逻辑仍然有效，因为循环在返回到起点后立即终止。 

诸如 n = 5 且 p = [2, 3, 4, 5, 1] 之类的全连接循环是通过按顺序收集所有节点来处理的。 着色为前四个节点分配交替颜色，然后将第五个节点放入特殊颜色槽中。 遍历确保只有一个节点接收到特殊颜色，因为循环列表只包含每个节点一次，并且最后一个位置由遍历顺序唯一定义。
