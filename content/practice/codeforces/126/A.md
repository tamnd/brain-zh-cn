 ## 解决方案
 ## 问题理解

 我们有两个水龙头。 第一个在一定温度下产生水`t1`，第二个温度`t2`， 在哪里`t1 ≤ t0 ≤ t2`。 

冷水龙头可以提供任意整数流量`0`到`x1`，热水龙头可以提供任意整数流量`0`到`x2`。 如果我们选择流量`y1`和`y2`，所得混合温度为$$\frac{t_1y_1+t_2y_2}{y_1+y_2}.$$我们的目标是选择允许范围内的整数流量，以便最终的温度至少为`t0`。 在所有有效选择中，我们想要最接近的温度`t0`。 由于温度可能无法完全达到，我们尽量减少上述超出的温度`t0`。 

如果多种选择产生相同的温度，鲍勃更喜欢浴液填充得更快，因此我们最大化总流量`y1 + y2`。 

限制可达`10^6`，所以对所有可能的对进行暴力破解`(y1, y2)`最多需要`10^12`检查，这在两秒钟之内是完全不可能的。 任何可接受的解决方案都必须利用温度公式的数学结构。 

一个微妙的点是目标是字典顺序的。 首先尽量减少上面的温差`t0`，然后最大化总流量。 填充速度更快的解决方案不允许牺牲温度质量。 

另一个容易犯的错误是忘记温度必须至少为`t0`。 例如：```
t1 = 10, t2 = 70, t0 = 25
```一定温度下的混合物`24.9`更接近于`25`比混合物在`25.1`，但由于温度低于目标而无效。 

还有一种情况是仅使用冷水是最佳的。```
10 70 100 100 10
```任何数量的冷水本身就已经具有准确的温度`10`，与目标匹配。 最好的选择是`(100, 0)`因为在所有精确匹配中，它填满浴缸的速度最快。 

最后，当`t1 = t2 = t0`，每个有效混合物都具有准确的目标温度。 答案很简单，就是最大总流量，即`(x1, x2)`。 

## 方法

 直接蛮力会尝试每一对$$0 \le y_1 \le x_1,\quad 0 \le y_2 \le x_2.$$对于每一对，我们计算结果温度，丢弃以下那些`t0`，并按照要求的排序保留最佳候选者。 

推理很简单并且完全正确，但复杂性是$$O(x_1x_2).$$由于两个极限都可以达到`10^6`，这大致变成`10^{12}`迭代次数远远超出了可以执行的范围。 

关键的观察是，一旦我们确定了一个流速，另一个流速​​基本上就由温度约束决定。 

假设我们固定热水量`y2`。 我们需要$$\frac{t_1y_1+t_2y_2}{y_1+y_2}\ge t_0.$$相乘并重新排列给出$$(t_0-t_1)y_1 \le (t_2-t_0)y_2.$$对于固定的`y2`，最大有效`y1`是$$y_1= \left\lfloor \frac{(t_2-t_0)y_2}{t_0-t_1} \right\rfloor.$$为什么我们想要最大的有效值`y1`？ 因为增加`y1`降低温度。 由于我们正在寻找最接近的温度`t0`从上面来看，我们需要尽可能多的冷水，同时仍然保持有效。 

现在仅`y2`尚待一一列举。 自从`x2 ≤ 10^6`，迭代所有可能的热水流量是完全可行的。 

对于每个`y2`，我们计算最大的允许值`y1`，上限为`x1`，并评估所得混合物。 这将搜索从二维减少到一维。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(x1·x2) | O(x1·x2) | O(1) | O(1) | 太慢了|
 | 最佳 | O(x2) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将答案初始化为`(1, 0)`。 问题保证`x1 ≥ 1`，因此至少始终存在一个有效选择。 
2. 迭代`y2`从`0`到`x2`。 
3.如果`t0 = t1`，仅每份冷水就已经完全满足了目标。 在这种特殊情况下，最佳冷水量就是`x1`。 
4. 否则计算$$y_1= \left\lfloor \frac{(t_2-t_0)y_2}{t_0-t_1} \right\rfloor.$$这是仍能保持混合物温度至少的最大冷水流量`t0`。 

1.由于水龙头容量有限，更换`y1`经过`min(y1, x1)`。 
2.忽略大小写`y1 = 0`和`y2 = 0`因为温度是不确定的。 
3. 将候选混合物与当前最佳答案进行比较。 

不使用浮点运算，而是通过交叉乘法比较温度：$$\frac{t_1y_1+t_2y_2}{y_1+y_2}.$$如果超过以上，则候选人更好`t0`较小。 如果余量相等，优先选择余量较大的一个`y1+y2`。 

1. 存储最佳候选并继续。 
2. 输出所选对。 

### 为什么它有效

 对于任何固定的`y2`，增加`y1`由于添加了更多冷水，因此降低了最终温度。 在所有有效值中`y1`，最大的有效温度产生的温度最接近`t0`从上面。 任何较小的值只会使温度更高并且更糟。 

由于该算法会检查所有可能的`y2`，并为每个人选择独特的最佳`y1`，考虑每个潜在的最佳解决方案。 最终的比较完全遵循问题的顺序：首先最小化上面的温度过高`t0`，然后最大化总流量。 因此，所选择的对是全局最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t1, t2, x1, x2, t0 = map(int, input().split())

    best_y1 = 1
    best_y2 = 0

    best_num = t1
    best_den = 1

    for y2 in range(x2 + 1):
        if t0 == t1:
            y1 = x1
        else:
            y1 = ((t2 - t0) * y2) // (t0 - t1)
            if y1 > x1:
                y1 = x1

        if y1 == 0 and y2 == 0:
            continue

        num = t1 * y1 + t2 * y2
        den = y1 + y2

        if num < t0 * den:
            continue

        cur_diff_num = num - t0 * den
        best_diff_num = best_num - t0 * best_den

        left = cur_diff_num * best_den
        right = best_diff_num * den

        better = False

        if left < right:
            better = True
        elif left == right and den > best_den:
            better = True

        if better:
            best_y1 = y1
            best_y2 = y2
            best_num = num
            best_den = den

    print(best_y1, best_y2)

solve()
```该循环枚举了每种可能的热水流量。 对于每一个，从温度约束导出的公式给出了仍然保持温度至少的最大冷水流量`t0`。 

该实现从不使用浮点数。 最小化的数量为$$\frac{\text{temperature}-t_0}{1},$$可以写成$$\frac{\text{num}-t_0\cdot\text{den}}{\text{den}}.$$使用交叉乘法比较两个这样的分数。 这避免了精度问题并保持安全，因为 Python 整数具有任意精度。 

特殊情况`t0 == t1`值得关注。 导出的公式将除以零，因此必须单独处理。 在这种情况下，每一量的冷水都是有效的，并且使用最大可能的量可以提供最低的温度和最快的填充速度。

 ## 边缘情况

 ### 目标等于冷水温度

 输入：```
10 70 100 100 10
```一般公式除以`t0 - t1 = 0`。 该算法通过设置显式处理这种情况`y1 = x1`对于每一个`y2`。 

候选人`(100, 0)`达到准确的目标温度。 任何积极的`y2`使水更热，从而离目标更远。 输出正确：```
100 0
```### 目标等于热水温度

 输入：```
10 70 100 100 70
```约束变为$$(70-10)y_1 \le 0.$$仅有的`y1 = 0`是可能的。 该算法精确计算并最终选择：```
0 100
```这是最快的精确匹配。 

### 所有温度相同

 输入：```
5 5 10 20 5
```每种混合物都有准确的温度`5`。 主要目标与所有候选人息息相关，因此只有总流量很重要。 

该算法比较相等的温度过高并选择最大的分母`y1+y2`，生产：```
10 20
```它以最大容量使用两个水龙头。 

### 只需轻轻一按即可获得最佳答案

 输入：```
20 100 5 5 20
```纯净的冷水已经完全达到了目标。 任何热水都会不必要地升高温度。 

该算法评估所有`y2`，发现`y2 = 0`给出零超额，并返回：```
5 0
```这是正确的字典顺序最优解。
