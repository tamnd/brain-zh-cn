 ## 解决方案
 ## 问题理解

 我们有一个大小为的正方形网格$n \times n$，每个单元格必须用红色或蓝色两种颜色之一着色。 如果每个单元格恰好有两个与其自身颜色相同的邻居（共享一侧），则着色被认为是有效的。 

因此，每个单元格都会查看其上、下、左、右邻居（当它们存在时），并且在这些相邻单元格中，必须恰好有两个与其颜色匹配。 边界上的像元具有较少的邻居，因此仅使用现有的邻居来解释它们的条件。 

任务是确定每个给定的颜色是否存在$n$，如果是，则输出一个有效的配置。 

约束允许最多$t \le 100$测试用例和$n \le 1000$，总和为$n^2$最多跨测试$10^6$。 这意味着任何解决方案$O(n^2)$每个测试用例是可以接受的，但是任何三次或涉及多次迭代内重复的每单元模拟都会太慢。 

对所有内容进行暴力分配$2^{n^2}$网格显然是不可能的。 即使尝试贪婪地分配颜色和局部回溯也会爆炸，因为每个单元格的有效性取决于全局结构，而不仅仅是局部一致性。 

小尺寸时会立即出现微妙的边缘情况。 为了$n = 1$，单个细胞没有邻居，因此它不可能有完全相同的两个相同颜色的邻居，从而使答案不可能。 为了$n = 2$，每个单元格恰好有两个邻居，因此条件简化为“两个邻居必须与单元格的颜色匹配”，这迫使整个网格成为单色，这实际上是有效的。 为了$n = 3$，满足条件的尝试失败，因为角点和中心约束冲突，并且没有周期性模式可以同时满足所有度数。 

试图在满足局部约束的同时逐行分配颜色的简单方法通常会失败，因为修复一行会迫使相邻行出现矛盾。 

## 方法

 强力的观点是逐个单元格分配颜色，并检查最后条件是否成立。 从概念上讲，这是可行的，因为验证很简单：对于每个单元格，计算匹配的邻居并检查它是否等于 2。 成本是$O(n^2)$每个配置，但配置的数量是指数级的，所以这是立即不可行的。 

为了贪婪地改进这一点，人们可能会尝试在保持部分有效性的同时分配颜色，以确保每个单元格都有“目标”数量的匹配邻居。 失败点在于决策在两个方向上传播：设置一个单元会影响其邻居，但这些邻居稍后也会约束原始单元，因此局部贪婪决策并不稳定。 

关键的结构见解是停止考虑局部约束，而是寻找全局重复模式，其中每个细胞都具有相同的局部环境。 如果每个内部细胞都看到相同的邻居模式，则条件会自动变得一致，并且要么到处成立，要么不成立。 

“恰好两个相同颜色的邻居”的要求表明了固定的度数模式，而在网格中满足这种统一约束的最简单方法是使用周期性平铺。 一个$2 \times 2$重复块是自然的候选者，因为它保证所有内部单元具有相同的邻域结构。 

如果我们尝试这样的块：```
BB
BB
```内部的每个单元格的所有邻居（最多四个）都等于其自身，这使得每个内部单元格有 4 个匹配的邻居，而不是 2 个，因此失败。 

下一次尝试是棋盘图案，但这给出了零个匹配的邻居，这也失败了。 

正确的结构来自于跨两个奇偶校验类的混合结构，确保每个单元在水平或垂直方向上看到两个完全相同的邻居。 其中一种模式是沿斜率 1 的对角线强制相等，从而在两个方向上创建配对邻接。 表达这一点的一种简洁方式是：$$color(i, j) = (i + j) \bmod 2 \text{ with a controlled flip on alternating rows}$$但更具体地说，解决这个问题的方法是构建重复的$2 \times 2$形式的块：```
R R
B B
```这确保了每一行中的邻居成对匹配，并且垂直邻接的结构使得每个单元格可以准确地看到两个相同颜色的邻居：一个水平的和一个垂直的，具体取决于位置。 

然而，这种模式仅在以下情况下始终有效：$n$是均匀的。 什么时候$n$为奇数时，奇偶校验不匹配会在边界处强制出现不成对的行，从而破坏均匀度条件。 这就是奇数尺寸失败的原因。 

所以完整的解决方案变成了一个奇偶性论证：甚至$n$承认瓷砖结构，奇怪$n$没有。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力分配+验证| 指数|$O(n^2)$| 太慢了|
 | 贪心局部赋值|$O(n^2)$存在回溯风险|$O(n^2)$| 失败案例|
 | 定期 2×2 构造 + 奇偶校验 |$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1.首先检查是否$n$是均匀的。 如果是奇数，则立即断定不存在有效的构造，因为任何统一的平铺都会在边界行处中断，并且无法全局保留所需的邻居计数。 
2.如果$n$是偶数，使用重复构造逐行构建网格$2 \times 2$图案。 这确保了每个局部邻域在整个网格中重复相同，因此我们只需要验证一个代表性单元格。 
3. 对于每对行$i$和$i+1$，以两块为一组填充列。 在每个块中，水平分配相同的颜色，并垂直交替使用颜色对，以便每列也形成一致的垂直配对。 
4. 输出结果网格。 

### 为什么它有效

 该结构强制每个单元都属于一个统一的单元$2 \times 2$平铺的所有邻接关系在平移之前都是相同的。 在这种平铺中，每个单元格恰好有两个具有相同颜色的邻居，因为每个颜色类在行和列方向上形成长度为 2 的不相交链。 由于每个单元都位于相同的本地环境中，因此验证一个单元会隐式验证所有其他单元，从而使条件全局一致。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())

        if n % 2 == 1:
            print("NO")
            continue

        print("YES")
        for i in range(n):
            row = []
            for j in range(n):
                # 2x2 repeating block:
                if (i // 2 + j // 2) % 2 == 0:
                    row.append('R')
                else:
                    row.append('B')
            print("".join(row))

if __name__ == "__main__":
    solve()
```代码直接实现了一个$2 \times 2$定期平铺。 表达式`i // 2`和`j // 2`将网格分组为大小为 2 的块，其总和的奇偶性会在块之间交替颜色。 这确保了水平和垂直方向的一致性，因此每个单元都具有相同的邻域结构。 

早期拒绝奇数$n$在不尝试构建的情况下处理不可能的情况。 

一个常见的实施错误是使用`(i + j) % 2`，这会产生一个棋盘格并且无法满足邻居计数要求，或者忘记整数除法分组，这会破坏$2 \times 2$结构完整。

```每个单元格恰好有两个邻居（因为每个单元格有 2 或 3 个邻居，具体取决于位置），并且所有单元格都匹配，因此条件成立。 

这证实了即使是最小的有效偶数案例也可以在构建中工作。

 ## 边缘情况

 对于$n = 1$，算法立即拒绝它，因为当不存在两个相同颜色的邻居时，没有任何单元可以满足涉及两个相同颜色邻居的要求。 输入`1\n1\n`触发早期检查并输出`NO`。 

为了$n = 2$，该构造产生完全均匀的块。 每个单元格的邻域都符合规则，因为所有邻居都是相同的，因此每个单元格都满足条件。 

对于更大的甚至$n$, 重复的$2 \times 2$平铺可确保边界效应不会破坏结构，因为每个边界单元仍然位于完整的块内，并且具有与内部单元相同的邻接模式。
