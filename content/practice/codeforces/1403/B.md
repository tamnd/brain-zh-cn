 ## 解决方案
 ## 问题理解

 我们有一棵树`N`节点，通过连接`N-1`边缘。 每个节点都可以是叶子，定义为仅具有一条边的节点。 清理树涉及选择两个不同的叶子并将它们之间的最短路径上的所有边缘标记为已清理。 每个边缘可以多次清洁，但路径中使用的叶子不能重复使用。 清洁的总成本是每个选定路径中的边数之和。 

对于每个`Q`变化，额外的叶子被添加到原始树中的特定节点，我们需要计算清理修改后的树的最小成本。 如果根据规则不能完全清理树，答案是`-1`。 

约束允许最多`10^5`节点和`10^5`在所有变体中总共添加了叶子。 这意味着任何复杂度高于`O(N + D_i)`每个变化可能会太慢。 暴力方法，例如模拟每对可能的叶子或明确标记路径，将因组合爆炸而失败。 

当叶子数量为奇数时，会出现不明显的边缘情况。 由于清理总是去除两片叶子之间的边缘，因此如果叶子总数是奇数，则一片叶子无法配对，从而使树无法完全清理。 当所有叶都连接到同一内部节点时，会出现另一种边缘情况。 路径长度很短，算法必须避免重复计算。 

## 方法

 一种简单的暴力方法会列出所有叶对并递归地选择要清理的路径。 每个选择都需要在树中找到最短路径，这可以使用 BFS 来完成。 然而，即使有`O(N)`BFS，叶子对的数量为`O(L^2)`在哪里`L`是叶子的数量。 和`N = 10^5`,`L`可以接近`N`，使得这种方法不可行。 

关键的见解是，清洁树的最佳方式对应于沿树的直径配对叶子，或者以每片叶子仅使用一次的方式。 特别是，每条边必须被至少一条路径覆盖。 叶子数量为奇数的树无法完全清洁。 否则，最小成本等于树中的边数。 每个额外的叶子都会使叶子数量增加一个，并改变总叶子的奇偶性，这会使清洁变得不可能。 

因此，解决方案减少为在每个变体中添加额外的叶子后对叶子进行计数。 如果叶子总数是奇数，则答案是`-1`。 否则，答案是增广树中的边总数，即`N - 1 + D_i`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(L^2 * N) | O(L^2 * N) | O(N) | 太慢了 |
 | 最佳 | 每个变化 O(N + D_i) | O(N) | 已接受 |

 ## 算法演练

 1. 读取树并构建邻接表，统计每个节点的度数。 度数为 1 的节点是叶子。 
2. 对于每个变体：

 a. 计算原始树的叶子数量。 

b. 添加`D_i`额外的叶子。 每个新叶子都连接到一个指定的节点，该节点可能是也可能不是叶子。 每次添加都会使叶子总数增加一。 

c. 检查叶子总数的奇偶性。 如果是奇数，则打印`-1`。 

d. 如果是偶数，则最小成本等于边的总数，即原始的`N - 1`加上额外叶子的数量`D_i`。 
3. 打印每个变体的结果。 

**为什么有效：** 每条边都必须包含在某些叶到叶路径中。 叶子配对保证每条边至少被计数一次。 由于每片叶子最多使用一次，奇数数量的叶子会留下一个不成对的叶子，使得清洁变得不可能。 这个不变量保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    N, Q = map(int, input().split())
    deg = [0] * (N + 1)
    for _ in range(N - 1):
        u, v = map(int, input().split())
        deg[u] += 1
        deg[v] += 1
    
    leaf_count = sum(1 for i in range(1, N + 1) if deg[i] == 1)
    
    for _ in range(Q):
        arr = list(map(int, input().split()))
        D_i = arr[0]
        # new leaves always increase leaf count
        total_leaves = leaf_count + D_i
        if total_leaves % 2 == 1:
            print(-1)
        else:
            print(N - 1 + D_i)

if __name__ == "__main__":
    main()
```该解决方案首先计算原始树的叶子数。 对于每个变异，它只需要调整叶子计数并检查奇偶性。 总成本就是增强树中边的总数。 这避免了显式路径计算或 BFS，并随输入线性缩放。 

## 工作示例

 **示例输入的变体 2**

 | 节点| 学位| 叶子？ |
 | ---| ---| ---|
 | 1 | 1 | 是的 |
 | 2 | 2 | 没有 |
 | 3 | 1 | 是的 |
 | 4 | 2 | 没有 |
 | 5 | 3 | 没有 |
 | 6 | 1 | 是的 |
 | 7 | 1 | 是的 |

 原始叶子： 1, 3, 6, 7 → 计数 = 4。 

额外的叶子添加到节点 4 → 叶子总数 = 5。奇数 → 输出 = -1。 

**变化3**

 叶子 = 4（原始）+ 2 片额外叶子 → 总叶子 = 6，偶数。 

最小成本 = 增强树中的边 = 7 - 1 + 2 = 8 → 输出 = 8。 

这证实了算法正确地检查奇偶校验并计算成本。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(N + sum(D_i)) | O(N + sum(D_i)) | 读取边 O(N)，每个变体 O(D_i) 读取额外的叶子并计算成本 |
 | 空间| O(N) | 邻接表和度数组 |

 该算法轻松地符合以下约束`N ≤ 10^5`和`sum(D_i) ≤ 10^5`。

 ## 边缘情况

 如果所有叶子都连接到同一节点，则添加额外的叶子可以更改奇偶校验。 例如，一颗星有 4 个叶子和 1 个额外的叶子 → 叶子总数 = 5，奇数 → 输出 = -1。 如果我们添加 2 个额外的叶子 → 叶子总数 = 6，甚至 → 成本 = 边 + 2。该解决方案可以正确处理这些基于奇偶校验的约束，而无需显式路径计算。
