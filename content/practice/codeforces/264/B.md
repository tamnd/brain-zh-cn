 ## 解决方案
 ## 问题理解

 我们得到一个严格递增的正整数列表。 从这个列表中，我们想要选择一个同样严格递增的子序列，但对邻接性有一个额外的约束：每当两个连续的选定数字在子序列中彼此相邻出现时，它们必须至少共享一个公共素数因子。 

任务是找到这样一个子序列的最大可能长度。 

因为输入已经排序，所以我们永远不需要担心重新排序，只需担心跳过元素。 唯一真正的困难是根据 gcd 大于 1 来决定哪些元素可以跟随哪个元素。 

约束 n 高达 100000 和值高达 100000 意味着任何检查所有对或计算所有转换的 gcd 的解决方案都将太慢。 对所有对进行简单的动态规划将需要 O(n^2) 次转换，这在最坏的情况下大约是 10^10 次操作，并且无法通过。 

当数字共享多个素因数时，就会出现一个更微妙的问题。 像 12 这样的数字可以独立地通过 2 或 3 连接链，并且仅跟踪每个数字的单个“最佳先前值”的错误解决方案将丢失有效的转换。 

当多个元素共享一个小的质因数但索引相距很远时，就会出现另一种失败情况。 例如，许多 2 的倍数与 3 的倍数交织需要在每个素数上推进多个竞争状态，而不仅仅是全局最佳状态。 

## 方法

 强力思想是将其视为有向无环图中的最长路径：如果 i < j 且 gcd(a[i], a[j]) > 1，每个索引 i 都可以转换到 j。我们将 dp[j] 计算为所有有效 i 上的最佳 dp[i] + 1。 这直接符合定义并且是正确的，但是每次检查所有对并计算 gcd 会导致二次时间。 

关键的观察结果是 gcd(a[i], a[j]) > 1 意味着它们至少共享一个素因子。 我们可以不用考虑成对的 gcd 检查，而是考虑素因数：每个数字都属于几个“素数通道”。 如果存在素数 p 并且两者均可被 p 整除，则从 x 到 y 的序列步骤是有效的。 

这将问题转化为对于每个素数 p 维护以可被 p 整除的数字结尾的最佳子序列。 处理数字 a[i] 时，我们将其分解并查看其所有素数。 以 a[i] 结尾的最佳序列是 1 加上与其素数相关的所有 dp 状态中的最大值。 计算 dp[i] 后，我们更新所有这些素数状态。 

这是可行的，因为每个有效的转换都必须经过至少一个共享素数，因此我们不会通过聚合每个素数的最佳值而错过任何连接。

 ## 算法演练

 我们维护一个字典或数组 best[p]，其中 best[p] 存储任何可被素数 p 整除的已处理数字的最大 dp 值。 

我们还计算 dp[i]，即以 a[i] 结尾的最佳子序列长度。 

### 步骤

 1. 预先计算 max(a[i]) 之前所有数字的最小质因数。 这允许快速分解每个元素。 这是避免重复重新计算素数所必需的。 
2. 为 100000 以内的所有素数 p 初始化一个数组 best[p] = 0。这会跟踪以可被 p 整除的数字结尾的最佳子序列。 
3. 从左到右迭代数组，因为子序列必须遵守顺序。 
4. 对于当前数字 x = a[i]，将其分解为不同的素数 p1, p2, ..., pk。 此步骤标识该号码可以通过的所有“通道”进行连接。 
5. 计算 dp[i] = 1 + max(best[p1], best[p2], ..., best[pk])。 如果 x 没有有用的连接，则 dp[i] = 1。 
6. 更新所有 best[pk] = max(best[pk], dp[i]) 以便将来的数字可以从此数字扩展。 

### 为什么它有效

在处理过程中的任何时刻，best[p] 表示已处理元素中以某个可被 p 整除的数字结尾的最长有效序列。 当我们处理一个新数字时，任何有效的前任数字都必须与其共享至少一个素因数，因此它必须出现在这些最佳[p]状态之一。 对所有素数取最大值可确保我们考虑每个可能的有效转换，而更新最佳值可确保我们为未来元素保留最佳子结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXV = 100000

# smallest prime factor sieve
spf = list(range(MAXV + 1))
for i in range(2, int(MAXV ** 0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, MAXV + 1, i):
            if spf[j] == j:
                spf[j] = i

def factorize(x):
    primes = []
    while x > 1:
        p = spf[x]
        primes.append(p)
        while x % p == 0:
            x //= p
    return primes

n = int(input())
a = list(map(int, input().split()))

best = [0] * (MAXV + 1)
ans = 0

for x in a:
    primes = factorize(x)
    cur = 1
    for p in primes:
        cur = max(cur, best[p] + 1)
    for p in primes:
        best[p] = max(best[p], cur)
    ans = max(ans, cur)

print(ans)
```筛子建立最小的质因数，因此每个数字都可以相对于其值以对数时间分解。 在处理过程中，每个元素都被分解为其不同的素数。 我们通过查询所有基于素数的状态来计算以该数字结尾的最佳链，然后在计算 dp 后更新这些状态。 

一个微妙的细节是在分解过程中删除重复素数。 如果不删除重复项，重复的质因数（例如十二分之二）会人为地夸大转换。 基于 SPF 的压缩可确保每个数字对每个素数进行一次考虑。

 ## 边缘情况

 一种边缘情况是所有数字本身都是素数。 例如`2 3 5 7 11`。 每个数字都没有与其他数字共享的质因数，因此正确答案始终为 1。该算法会处理此问题，因为每个 best[p] 都从零开始，并且不会在数字之间重复使用质数。 

另一种情况是单个数字内重复素数，例如 12 = 2 × 2 × 3。如果不删除重复项，算法将错误地对同一素数的转换进行双重计数。 基于 SPF 的分解可确保每个素数每个数字使用一次，因此 dp 保持正确。 

最后的边缘情况是密集的重叠因素，例如`6 10 15`。 这里多个素数在不同方向连接。 每个素数最佳数组正确地合并这些路径，因为每个数字在计算 dp 后同时更新其所有素数，从而防止过早覆盖。
