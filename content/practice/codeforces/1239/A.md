 ## 解决方案
 ## 问题理解

 我们被要求计算大小的“随机图片”的数量$n \times m$，其中每个单元格要么是黑色，要么是白色。 根据伊万的定义，如果每个单元格最多有一个相同颜色的相邻单元格，则图片被认为是随机的。 这里，邻接是水平或垂直的。 

输入由两个整数组成$n$和$m$，表示行数和列数。 输出是有效图片的数量模$10^9 + 7$。 限制因素$1 \le n, m \le 100{,}000$表明任何迭代所有可能图片的解决方案都是不可行的，因为图片总数为$2^{n \cdot m}$，即使对于$n = m = 20$。 这迫使我们寻找组合或代数方法，理想情况下$O(n + m)$在复杂性上。 

要考虑的边缘情况包括最小的网格（$1 \times 1$或者$1 \times m$）和实际上是线的网格。 例如，一个$1 \times 5$网格每个单元最多只有两个相邻约束，而$1 \times 1$grid 简单地满足该条件。 同样，对于长而细的网格，例如$1 \times 100{,}000$，简单的 2D 模拟将会失败。 

## 方法

 暴力方法会枚举所有$2^{n \cdot m}$可能的着色并检查邻接规则。 每次检查都会扫描所有单元格并计算相同颜色的邻居。 虽然正确，但这对于大型企业来说显然是不可能的$n$和$m$自从$2^{100{,}000}$大得难以想象。 

关键的见解是行和列的约束在计数可能性方面是独立的。 “至多一个相同颜色的相邻单元格”的条件简化为沿每一行或每一列的线性递归。 如果我们定义$f(k)$作为长度有效的一维序列的数量$k$如果没有一个单元格具有多个相同颜色的邻居，这正是斐波那契数列。 每个单元格要么继续以前的颜色（如果以前的颜色只出现一次），要么切换。 对于一行长度$m$， 有$F_{m+2}$有效序列； 类似地对于长度的列$n$。 

但是，我们必须避免重复计算，因为行和列序列在网格单元处相交。 组合技巧是将图片视为“行主导”或“列主导”，并使用包含排除原则组合计数。 具体来说，图片总数是沿行的序列和沿列的序列之和减去多计的恒定图案（全白和全黑）。 这减少到$F_{n+2} + F_{m+2} - 2$， 在哪里$F_k$是$k$-th 斐波那契数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(n*m)) | O(2^(n*m)) | O(n*m) | 太慢了 |
 | 最佳| O(n + m) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 预先计算斐波那契数模$10^9 + 7$最多$\max(n, m) + 2$。 这是必要的，因为行和列的长度可达$100{,}000$，我们需要$F_{n+2}$和$F_{m+2}$。 模运算可防止溢出。 
2.让$fib[n+2]$表示$(n+2)$-th 斐波那契数。 对于每行的长度$m$， 有$fib[m+2]$有效序列。 对于每列的长度$n$， 有$fib[n+2]$有效序列。 
3. 合并计数。 每个有效的行配置都可以垂直镜像，每个有效的列配置都可以水平镜像。 为了避免重复计算完全单色图片（全白或全黑），请减去 2。公式变为$total = fib[n+2] + fib[m+2] - 2$。 
4. 输出结果取模$10^9 + 7$，确保非负值。 

为什么有效：斐波那契数列的出现是因为一行中的每个附加单元格都可以匹配先前的颜色（如果允许）或切换颜色。 此递归捕获所有有效序列，而无需显式枚举它们。 通过对行主导和列主导的计数求和并减去双重计数的全相等配置，我们一次获得所有有效图片。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def main():
    n, m = map(int, input().split())
    max_len = max(n, m) + 2
    
    fib = [0] * (max_len + 1)
    fib[0], fib[1] = 1, 1
    for i in range(2, max_len + 1):
        fib[i] = (fib[i-1] + fib[i-2]) % MOD

    result = (fib[n+1] + fib[m+1] - 2) % MOD
    print(result)

if __name__ == "__main__":
    main()
```斐波那契数组初始化为`fib[0] = fib[1] = 1`匹配以任一颜色开始的序列的组合计数。 循环将序列填充到所需的长度（模数）$10^9 + 7$。 然后，我们计算行和列可能性的总和，减去 2 以删除重复计数的全单色图片，并打印结果模$10^9 + 7$。 通过仔细索引可以避免差一错误`n+1`和`m+1`。
