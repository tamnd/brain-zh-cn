 ## 解决方案
 ## 问题理解

 我们得到了必须进行的足球比赛的确切数量，并且我们需要找到在特定锦标赛格式下产生恰好那么多场比赛的每一个可能的初始球队数量。 

比赛以淘汰赛开始，但前提是剩余球队的数量为偶数。 在每一轮比赛中，球队都会配对，每对进行一场比赛，一半的球队被淘汰。 

最终剩下的队伍数量变成奇数。 如果只剩下一支球队，比赛将立即结束。 否则，所有剩余球队将进行完整的循环赛，每对球队只相遇一次。 

输入是单个整数`n`，所需的游戏总数。 输出是每个初始团队计数，从而准确地得出`n`游戏，按升序打印。 

约束是关键困难。 的价值`n`可以大到`10^18`，因此任何直接尝试多个候选团队计数的算法都是不可能的。 甚至迭代到`√n`已经在附近了`10^9`最坏情况下的操作。 我们需要一个运行时间仅与所涉及数字的大小成对数关系的解决方案。 

一些边缘情况很容易被忽略。 

考虑`n = 1`。 粗心的解决方案可能会假设每场有效的锦标赛最终都会进入循环赛阶段。 那是错误的。 从两支球队开始，进行一场淘汰赛，然后决出获胜者。 正确的输出是：```
2
```考虑`n = 3`。 有两个有效答案：```
3
4
```从三支球队开始，立即进行三场比赛的循环赛。 从四支球队开始，进行两场淘汰赛，剩下两支球队，然后再进行一场淘汰赛，总共三场比赛。 仅搜索奇数团队计数的解决方案将会错过`4`。 

另一个微妙的情况是当两个不同的幂除以相同的答案结构时。 不同的初始团队数量可以产生相同的游戏总数，因此我们必须收集所有有效的解决方案并对它们进行排序，而不是在第一场比赛后停止。 

## 方法

 最直接的方法是尝试所有可能的初始团队人数`m`，模拟锦标赛，计算比赛场数，并检查是否等于`n`。 

模拟很简单。 重复将团队人数减半，同时添加`m/2`每次游戏。 当奇数时`k`保留，添加`k(k-1)/2`循环赛。 

这种暴力方法是正确的，因为它完全遵循锦标赛规则。 问题在于搜索空间。 答案可能比`10^9`，事实上有效的团队数量可能约为`10^18`。 列举候选人是完全不可行的。 

锦标赛的结构给出了更好的描述。 

假设初始团队数量为$$m = 2^t \cdot k$$在哪里`k`很奇怪。 

第一轮淘汰赛结束后，队伍数量为$$2^{t-1}k$$第二次之后，$$2^{t-2}k$$等等。 

恰好之后`t`消除阶段，`k`团队仍然存在，并且`k`很奇怪。 

淘汰赛贡献$$2^{t-1}k + 2^{t-2}k + \cdots + k$$这是$$k(2^t-1).$$最后循环赛贡献$$\frac{k(k-1)}2.$$因此每个有效的锦标赛都满足$$n = k(2^t-1)+\frac{k(k-1)}2.$$重新整理后，$$n=\frac{k(2^{t+1}+k-3)}2.$$现在搜索空间变得很小。 自从`k`是奇数且正数，并且`2^t ≤ 10^{18}`, 指数`t`只能取大约六十个值。 

对于固定的`t`，方程变为二次`k`：$$k^2+(2^{t+1}-3)k-2n=0.$$我们可以使用整数运算来解决这个问题。 对于每一个可能的`t`，检查二次方程是否有正奇整数根。 每个这样的根都给出有效的团队计数$$m=2^t k.$$这将问题从搜索减少到`10^{18}`考生只需要检查大约六十个指数。

 ## 算法演练

 1.让`n`是所需的游戏数量。 
2. 迭代所有指数`t`从`0`向上同时`2^t ≤ 10^18`。 
3.对于当前`t`， 定义$$a = 2^{t+1}-3.$$方程变为$$k^2+ak-2n=0.$$1. 计算判别式$$D=a^2+8n.$$仅当存在整数解`D`是一个完美的正方形。 

1.让`s = √D`。 如果`s² ≠ D`，跳过该指数。 
2. 二次公式给出$$k=\frac{-a+s}{2}.$$检查分子是否为正且偶数。 

1. Verify that`k`是正且奇数。 只有奇数值对应于所有淘汰阶段后剩余的球队。 
2. 构建$$m = 2^t k.$$1. 重新计算锦标赛比赛数`m`使用导出公式并验证它等于`n`。 这可以防止任何算术错误。 
2. 存储每个有效的`m`。 
3. 处理完所有指数后，对答案进行排序并打印。 如果不存在，则打印`-1`。 

### 为什么它有效

 每个初始团队计数可以唯一地写为`m = 2^t k`在哪里`k`很奇怪。 比赛总是准确无误地进行`t`消除阶段，然后停止`k`团队。 

消除阶段的贡献正好`k(2^t-1)`比赛，循环赛阶段的贡献正好`k(k-1)/2`游戏。 因此每个有效的解决方案必须满足$$n=\frac{k(2^{t+1}+k-3)}2.$$相反，每当奇数正整数`k`对于某些情况满足这个方程`t`, 团队计数`m=2^t k`准确地产生`n`游戏。 该算法枚举所有可能的指数`t`，找到所有整数根`k`，因此发现每个有效的初始团队恰好计数一次。 

## Python 解决方案```python
import sys
from math import isqrt

input = sys.stdin.readline

def main():
    n = int(input())

    ans = []

    p = 1  # 2^t
    while p <= 10**18:
        a = 2 * p - 3
        D = a * a + 8 * n

        s = isqrt(D)
        if s * s == D:
            num = s - a

            if num > 0 and num % 2 == 0:
                k = num // 2

                if k > 0 and k % 2 == 1:
                    games = k * (p - 1) + k * (k - 1) // 2

                    if games == n:
                        ans.append(p * k)

        p <<= 1

    ans.sort()

    if not ans:
        print(-1)
    else:
        print("\n".join(map(str, ans)))

if __name__ == "__main__":
    main()
```该循环枚举了所有可能的值`2^t`。 在超过之前，这样的值少于六十个`10^18`，这就是该算法非常快的原因。 

对于每个指数，我们推导出奇余数的二次方程`k`。 判别测试至关重要。 仅当判别式是完全平方时，具有整数系数的二次方程才有整数根。 

表达式```
num = s - a
```直接来自二次公式。 我们必须验证它是正数并且能被二整除，否则`k`不是整数。 

游戏计数的最终重新计算完全通过整数运算来执行。 Python 的任意精度整数消除了溢出问题，但验证步骤仍然有用，因为它保证只输出真正有效的解决方案。

 ## 边缘情况

 考虑输入：```
1
```该算法检查每个指数。 为了`t = 1`，它发现`k = 1`, 给予`m = 2`。 结果游戏计数恰好为一。 这证实了淘汰赛后立即结束的锦标赛得到了正确处理。 

考虑输入：```
3
```两个不同的指数值产生有效根。 该算法记录了两者`3`和`4`，对它们进行排序，然后打印两者。 任何在第一场比赛之后停止的解决方案都会在这里失败。 

考虑输入：```
2
```每个判别检查要么失败，要么产生无效的根。 答案列表仍为空，算法打印`-1`。 当没有锦标赛结构可以生成所请求的游戏数量时，这可以验证正确的处理。 

考虑附近非常大的输入`10^18`。 该算法仍然只检查大约六十个指数值。 所有算术都是用整数执行的，Python 的任意精度整数可以安全地处理大于`10^18`没有溢出。
