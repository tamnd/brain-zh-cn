 ## 解决方案
 ## 问题理解

 我们有一个 3×3 的幻方，其中主对角线上的三个单元格已被擦除。 缺失的细胞是`(0,0)`,`(1,1)`， 和`(2,2)`，并在输入中显示为零。 所有其他值都是已知的。 

幻方有一个公和`S`。 每行、每列和两条对角线之和必须精确`S`。 我们的任务是恢复三个缺失的对角线值，使完整的正方形成为有效的幻方。 

正方形的大小是固定的。 总是有正好九个单元格和正好三个未知值。 由于输入大小永远不会增长，因此任何执行少量恒定工作量的算法实际上都是瞬时的。 挑战不在于效率，而在于发现确定缺失值的代数关系。 

一个常见的错误是尝试仅满足行总和。 例如：```
0 1 2
3 0 4
5 6 0
```使所有行相等并不自动使列和对角线相等。 有效的解决方案必须同时满足每个幻方条件。 

另一个微妙的情况是正确的对角线值并不完全相同。```
0 2 7
9 0 1
4 8 0
```盲目地用一个常数值填充对角线的解决方案可能会失败。 三个缺失的数字通常不同，并且必须根据目标幻数和进行计算。 

## 方法

 一个蛮力的想法是尝试三个缺失的对角单元格的所有可能值。 由于每个值都保证最多是`10^5`，这需要最多`(10^5)^3 = 10^15`组合。 尽管棋盘很小，但检查千万亿的组合是完全不可行的。 

关键的观察结果来自于查看仅包含一个未知值的行。 

假设魔幻总和是`S`。 

第一行包含：```
a ? b
```其总和必须是`S`，因此缺失的对角线值是唯一确定的：```
x = S - (known values in row)
```同样的论点也适用于第二行和第三行。 一次`S`众所周知，每个丢失的对角线条目都会立即确定。 

这将问题简化为寻找幻数之和。 

请注意，除了一个对角单元格之外，每一列仅包含已知值。 如果我们计算不包括对角线位置的行总和：```
r0 = a[0][1] + a[0][2]
r1 = a[1][0] + a[1][2]
r2 = a[2][0] + a[2][1]
```然后```
x0 = S - r0
x1 = S - r1
x2 = S - r2
```对于 3×3 幻方来说，一个方便的事实是完成的行总和之一必须等于公共幻方和。 我们可以选择`S`使得结果值满足平方。 

标准公认的解决方案利用了问题的微小规模。 我们选择一个对角线值，导出`S`，从它们的行计算另外两个对角线值，并检查完成的正方形是否是魔术。 由于保证存在有效答案并且所有值最多`10^5`，尝试来自的值`1`到`100000`是完全可以接受的。 

仅有的`100000`测试候选总和，每次测试检查固定的 3×3 板。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解三个单元 | O(10^5) | O(10^5) | O(1) | O(1) | 太慢了|
 | 尝试一个对角线值，验证平方 | O(10⁵) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取 3×3 网格。 
2.尝试每一个可能的正值`x`从`1`到`100000`对于左上角的对角线单元格。 
3. 第一行的总和必须等于幻数总和。 计算：```
S = x + a[0][1] + a[0][2]
```4. 使用这个幻数求和，确定另外两个缺失的对角线值：```
a[1][1] = S - a[1][0] - a[1][2]
a[2][2] = S - a[2][0] - a[2][1]
```每行总和必须为`S`，所以这些值是强制的。 
5. 如果计算值不为正或超过，则拒绝该候选者`100000`。 
6. 检查所有三行总和、所有三列总和以及两个对角线总和。 
7. 如果每个总和都等于`S`，打印完成的正方形并停止。 

### 为什么它有效

 对于第一个缺失对角线单元格的任何选定值，第一行立即确定候选幻数和`S`。 一次`S`是固定的，其余两个对角线条目是唯一确定的，因为它们的行也必须总和为`S`。 

该算法检查第一个缺失单元格的每个可能的合法值。 由于该问题保证存在有效的幻方并且所有条目最多`100000`，在搜索过程中必须出现正确的值。 当它完成时，所有行、列和对角线检查都会成功，并且算法会输出有效的幻方。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a = [list(map(int, input().split())) for _ in range(3)]

for x in range(1, 100001):
    b = [row[:] for row in a]

    b[0][0] = x
    S = b[0][0] + b[0][1] + b[0][2]

    b[1][1] = S - b[1][0] - b[1][2]
    b[2][2] = S - b[2][0] - b[2][1]

    if not (1 <= b[1][1] <= 100000 and 1 <= b[2][2] <= 100000):
        continue

    ok = True

    for i in range(3):
        if sum(b[i]) != S:
            ok = False

    for j in range(3):
        if b[0][j] + b[1][j] + b[2][j] != S:
            ok = False

    if b[0][0] + b[1][1] + b[2][2] != S:
        ok = False

    if b[0][2] + b[1][1] + b[2][0] != S:
        ok = False

    if ok:
        for row in b:
            print(*row)
        break
```搜索变量`x`代表缺失值`(0,0)`。 一旦选择了该值，第一行就确定了候选幻数和。 

然后，直接根据行要求确定中心和右下角的对角单元格。 这些值不需要猜测。 

验证步骤明确检查每个幻方条件。 由于该板仅包含九个单元，因此执行所有八个总和检查实际上是恒定时间。 

积极性和上限检查很重要。 候选者可能会生成一个行总和，迫使其中一个缺失值超出允许的范围。 在测试正方形之前必须丢弃此类候选者。

 ## 边缘情况

 考虑输入：```
0 5 5
5 0 5
5 5 0
```正确的魔幻和是`15`。 当算法尝试`x = 5`，它将剩余的对角线值计算为`5`和`5`。 每行、每列、每对角线都变成`15`，所以正方形被接受。 这证实了相等的对角线值被正确处理。 

现在考虑：```
0 1 6
3 0 7
4 9 0
```成功的候选人是`x = 8`, 给予`S = 15`。 该算法将剩余的对角线条目计算为`5`和`2`。 由于对角线值不同，任何假设所有三个缺失单元格相同的解决方案都会失败。 根据行总和进行显式计算可以避免这种错误。 

最后，考虑一个产生非正值的候选：```
0 2 7
9 0 1
4 8 0
```如果`x = 3`， 然后`S = 12`，这迫使右下角的单元格变成`0`。 魔方条目必须为正，因此候选人会立即被拒绝。 积极性检查可防止无效的板被接受。
