 ## 解决方案
 ## 问题理解

 给定一个整数序列，并要求我们提取_无序_的最短子序列。 如果一个序列完全非递减或完全非递增，则该序列被认为是有序的。 换句话说，如果每个连续的对要么从不减少，要么从不增加，则序列是有序的。 我们的任务是找到打破这种模式的最小子序列。 

输入由单个整数组成$n$指定序列长度，后跟$n$整数。 输出应报告最短无序子序列（如果存在）的长度及其元素从 1 开始的索引。 

和$n$最多$10^5$和 2 秒的时间限制，任何比线性复杂度更差的解决方案都可能太慢。 一个$O(n^2)$所有三元组的暴力搜索已经$10^{10}$在最坏的情况下进行操作，这显然是不可行的。 这表明需要单通道或近线性扫描方法。 

边缘情况很微妙。 如果所有元素都相等，则不存在无序子序列，因此输出必须为零。 如果序列只有一个或两个元素，则任何子序列都是平凡排序的。 我们还需要处理严格增加或减少的序列，这些序列看起来有“变化”，但实际上并没有破坏单调性。 

## 方法

 简单的解决方案将检查长度为 3 的所有子序列，检查它们是否有序。 这是有效的，因为任何无序子序列必须至少具有三个元素：两个元素始终是有序的。 检查长度数组中的每个三元组$n$大致需要$n^3$操作，这对于$n = 10^5$。 

关键的见解是最短的无序子序列的长度始终为 3。假设我们找到三个连续的元素$a_i, a_j, a_k$在哪里$i < j < k$这样$a_i < a_j > a_k$或者$a_i > a_j < a_k$。 任何超过三个元素的无序序列都包含这样的三元组。 因此，我们只需要扫描数组一次，检查连续元素的每个三元组。 一旦三元组违反单调性，我们就可以立即输出它。 

这一观察降低了复杂性$O(n^3)$到$O(n)$具有恒定的空间。 我们只需要当前元素及其直接邻居来检测无序三元组。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将整数序列读入数组。 
2. 如果序列长度小于3，则立即输出0。 两个元素总是有序的。 
3. 使用索引迭代数组$i$从 1 到$n-2$。 对于每个三元组$(a[i-1], a[i], a[i+1])$，检查订购条件。 
4. 如果中间元素严格大于两个邻居（$a[i-1] < a[i] > a[i+1]$）或严格小于两个邻居（$a[i-1] > a[i] < a[i+1]$), 输出三元组长度 3 及其从 1 开始的索引$i, i+1, i+2$。 立即终止。 
5. 如果循环结束时没有找到任何无序三元组，则输出 0。 

为什么有效：该算法保证找到最短的无序子序列，因为任何非单调的三个元素的序列都是最小的。 扫描连续的三元组可确保我们永远不会错过这样的子序列。 长度为 2 的序列不能违反顺序，因此 3 是正确的最小长度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

if n < 3:
    print(0)
else:
    found = False
    for i in range(1, n-1):
        if (a[i-1] < a[i] > a[i+1]) or (a[i-1] > a[i] < a[i+1]):
            print(3)
            print(i, i+1, i+2)
            found = True
            break
    if not found:
        print(0)
```该代码首先处理长度小于三的序列。 然后，它对每个连续的三元组恰好检查一次。 该条件明确检查“峰”或“谷”形态。 使用从 1 开始的索引符合问题要求。 一个微妙的点是，相等并不算作破坏顺序：条件使用严格的不平等。

 ## 边缘情况

 对于具有重复元素的序列，例如，`2 2 2`，算法检查连续的三元组。 不满足严格的不等式，因此输出0。对于长度为2的序列，如`1 2`，初始检查立即返回 0。对于在开头、中间或结尾处具有最小无序子序列的序列，算法始终标识遇到的第一个此类三元组。
