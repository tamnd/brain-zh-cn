 ## 解决方案
 ## 问题理解

 我们得到一个由非常简单的算法生成的整数序列：从一些初始长度序列开始`m`，并重复选择一个元素并在其后面紧接着插入其值加一，直到序列达到 length`m + k`。 我们的任务是相反的：给定最终序列，我们需要确定可以生成它的最短可能初始序列的长度。 

输入由多个测试用例组成，每个测试用例都有一个序列`a`长度`n`。 每个测试用例的输出是一个整数：最小起始序列的长度。 因为`n`可以大到 300,000 并且总和`n`所有测试用例不超过 300,000 个，我们需要一个每个序列以大致线性时间运行的解决方案。 

关键的难点在于，序列中的连续数字有时可以通过重复插入生成，但有时却不能。 例如，给定序列`[1,2,3,4,5]`，所有数字都是连续加1，所以单个起始数字`1`就足够了。 相比之下，对于`[1,3,5,7,9]`，没有数字比其前一个数字多 1，因此唯一有效的起始序列是序列本身。 尝试通过模拟插入来重建每个可能的初始序列的简单实现对于大型数据来说太慢了。`n`。 

不明显的边缘情况包括上升和下降的序列，或者具有不遵循简单增量模式的重复数字。 例如，`[1,2,5,6,5]`有一个下降，所以你不能开始`1`独自的; 你至少需要三个数字来解释增量和下降。 

## 方法

 蛮力方法是尝试所有可能的长度从 1 到`n`，并模拟插入过程，直到我们匹配给定的序列。 这在理论上是正确的，但操作次数大致为`O(n^2)`在最坏的情况下，这是不可行的`n`高达 300,000。 

有效解决方案的关键观察是序列中的元素`a[i]`可能是由前一个元素生成的`a[i-1]`如果`a[i]`等于`a[i-1] + 1`。 如果此条件成立，则当前元素不需要起始序列中的新元素； 它可以通过在前一个元素之后插入来生成。 否则，新元素必定是初始序列的一部分。 因此，问题简化为计算“断点”的数量，其中`a[i]`不等于`a[i-1] + 1`。 每个断点对应于初始序列中所需的元素。 

这种观察允许对阵列进行线性扫描，每当增量模式中断时就增加计数器。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 线性扫描| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.初始化一个计数器`ans`到 1. 我们总是需要至少第一个元素作为初始序列的一部分。 
2. 从第二个元素到最后一个元素迭代序列。 
3. 对于每个元素`a[i]`，将其与前一个元素进行比较`a[i-1] + 1`。 
4. 如果`a[i]`正是`a[i-1] + 1`，继续，因为该元素可以通过插入算法生成，而无需增加初始序列的长度。 
5. 否则，增加`ans`，因为该元素不可能由前一个元素生成，并且必须是初始序列的一部分。 
6.处理完所有元素后，输出`ans`对于测试用例。 

为什么它有效：序列中的每个元素要么是通过递增前一个元素而生成的，要么必须已经存在于初始序列中。 初始序列中的元素数量对应于连续增量模式被破坏的次数。 这个不变量保证了我们计算起始元素的最小数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        ans = 1  # the first element is always in the initial sequence
        for i in range(1, n):
            if a[i] != a[i-1] + 1:
                ans += 1
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先读取测试用例的数量。 对于每个序列，我们初始化`ans`到 1，然后循环遍历序列，将每个元素与其前一个元素加一进行比较。 如果连续增量被打破，我们就增加`ans`。 开始的选择`ans`at 1 自动处理第一个元素，并且我们仅在连续模式中的真正中断时递增。 使用`sys.stdin.readline`确保大输入量的快速 I/O。

 ## 边缘情况

 对于所有数字都相等的序列`[2,2,2,2]`， 每个`2`不能由先前生成`2`因为该算法只生成`x_i+1`。 算法增量`ans`对于每个中断，产生 4，这是正确的。 对于严格递减序列`[5,4,3,2]`，每一步都会打破`+1`模式，所以`ans`在每个位置递增，得到 4，即最小序列长度。 对于长度为 1 的序列`[100]`，答案为 1，因为初始序列必须至少包含一个元素。
