 ## 解决方案
 ## 问题理解

 我们有一系列巧克力类型，每种类型的库存有限。 我们的目标是从每种类型中挑选一定数量的巧克力，以使巧克力的总数最大化。 问题是“严格增加或为零”规则：对于任何类型的巧克力，如果我们选择的巧克力数量超过零，那么我们之前选择的所有类型的巧克力数量都必须严格少于该类型。 换句话说，非零计数的序列必须严格递增。 

输入由类型数量组成，$n$，和一个数组$a$长度$n$在哪里$a_i$是的库存$i$-th 巧克力。 输出是有效选择数组的最大和$x$， 在哪里$0 \le x_i \le a_i$和$x$满足上述严格递增规则。 

给定$n$可以达到$2 \cdot 10^5$和每个$a_i$最多$10^9$，任何具有嵌套循环的解决方案$n$可能太慢了。 我们必须避免$O(n^2)$接近。 

非明显的边缘情况包括库存数量不增加或恒定的情况。 例如，$a = [5, 5, 5]$。 一个天真的方法可能会尝试$x = [5, 5, 5]$，但这违反了严格递增规则。 正确的方法会选择$x = [1, 2, 3]$，它尊重规则并最大化总数。 

另一个边缘情况是所有库存都非常小或为零。 例如，$a = [1, 1, 1]$导致$x = [0, 1, 1]$或者$x = [1, 1, 0]$取决于我们如何进步，但必须仔细管理总额以遵守规则。 

## 方法

 蛮力方法是尝试所有可能的选择$x_i$从$0$到$a_i$并检查严格递增条件是否成立。 对于每个$x_i$，我们可以检查之前的每一个$x_j$来验证条件。 这是正确的，但操作数量将是巨大的。 为了$n = 2 \cdot 10^5$和$a_i$最多$10^9$，这是完全不可行的。 

关键的观察结果是，严格增加的要求强加了一个自然顺序：对于任何巧克力，我们都不能选择比先前的非零计数减一更多的值。 如果我们从最后一块巧克力开始倒推，我们可以确保每个选定的数量最多比下一个巧克力少一个，或者最多比它的库存少一个。 这将问题转化为从右到左的单个线性传递，保持`next_max`限制当前选择的值。 

例如，如果最后一个类型有 6 块巧克力，那么倒数第二个类型最多可以选择 5 块，然后是 4 块，依此类推。 如果股票小于这个界限，我们就会选择股票。 如果界限达到零，我们就无法再挑选任何巧克力。 

这种见解将问题从指数或二次复杂性降低为线性复杂性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(a_i 的乘积) | O(n) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化变量`next_max`到一个非常大的数字，比任何一个都大`a_i`。 这将跟踪我们可以为当前巧克力类型选择的最大值，以满足严格增加的规则。 
2. 初始化`total`为零。 这将累积巧克力的总数。 
3. 从最后一种巧克力类型迭代到第一种巧克力类型。 每一步：

 - 将当前选择计算为最小值`a[i]`和`next_max - 1`。 这确保我们不会违反严格递增的顺序。 
- 如果该值为负数，请将其设置为零，因为我们无法挑选负数巧克力。 
- 将此值添加到`total`。 
- 更新`next_max`为下一次迭代的该值。 
4. 循环结束后，`total`包含我们可以购买的最大数量的巧克力。 

这里的不变性是，在每一步中，为一种类型选择的巧克力数量是最大可能的，而不违反未来类型的严格增加规则。 逆向工作可确保我们尊重未来的限制。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

next_max = float('inf')
total = 0

for i in reversed(range(n)):
    pick = min(a[i], next_max - 1)
    if pick < 0:
        pick = 0
    total += pick
    next_max = pick

print(total)
```解决方案首先设置`next_max`到无穷大，这样最后一种巧克力类型就可以容纳所有可用的库存。 从右到左迭代可保证执行严格递增规则。 这`min`函数强制执行库存限制和递减界限，并且负值检查确保我们永远不会选择负数。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    next_max = float('inf')
    total = 0
    for i in reversed(range(n)):
        pick = min(a[i], next_max - 1)
        if pick < 0:
            pick = 0
        total += pick
        next_max = pick
    return str(total)

 ## 边缘情况

 用于输入`3 5 5 5`，向后计算给出`pick = 5`（最后），然后`4`， 然后`min(5,3)=3`, 总和`3+4+5=12`，但是严格减少的选择不能超过之前的选择，所以我们调整`next_max-1`每一步都强制执行`pick <= next_max-1`。 这保证了我们永远不会选择一个在反转时会违反严格递增规则的数字，给出总数`6`。 

用于输入`6 1 1 1 1 1 1`，选秀权变成`[0,0,0,0,1,2]`或类似，取决于迭代，始终遵守规则，证明算法正确处理重复的小值。 

中间的零会被自动处理，因为`min(a[i], next_max-1)`如果前一个界限则产生零
