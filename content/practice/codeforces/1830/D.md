 ## 解决方案
 ## 问题理解

 每个测试用例都给出一棵树，我们必须为每个顶点分配一个 0 或 1 的标签。一旦标签固定，每对顶点都会在树中定义一条唯一的简单路径，我们会沿着该路径查看标签的序列。 该对的贡献由未出现在该路径上的最小非负整数决定，在此二进制设置中，该整数仅取决于该路径是否包含 0、1、两者或都不包含。 

我们对所有顶点对（包括两个端点是同一顶点的平凡对）的贡献求和。 目标是选择二进制标签以使总和最大化。 

所有测试用例的输入大小总共达到二十万个节点，因此任何解决方案在每个测试中都必须基本上是线性的或线性的。 节点数量或对数量的二次行为是立即不可能的，因为仅顶点对的数量就是 O(n^2)，这远远超出了可行的限制。 

天真的尝试会尝试所有标签，甚至只是通过检查每对和计算路径内容来评估固定标签，但由于对的数量，即使计算单个标签的贡献也需要 O(n^2) 工作。 另一个常见的陷阱是尝试通过树遍历独立处理每条路径，这会在重叠的路径上默默地重复工作，并导致立方或接近立方的行为。 

真正的困难在于，贡献取决于标签沿路径的全局交互，而不是独立的局部边缘。 然而，树结构强烈限制了路径的行为方式，这就是允许彻底简化的原因。 

## 方法

 蛮力视图很简单：为每个节点分配 0 或 1，然后迭代所有节点对，提取它们之间的路径，计算该路径是否仅包含 0、仅包含 1 或两者，然后添加相应的值。 这是正确的，但它检查 θ(n^2) 对，并且每对至少花费 O（路径长度），给出链上 θ(n^3) 个最坏情况。 即使删除路径重新计算仍然留下 θ(n^2)，它太大了。 

关键的观察结果是，在任何路径上，该值仅取决于端点是否位于相同的颜色结构中或者路径是否跨越两种颜色。 这表明我们应该避免考虑单独的路径，而是理解着色如何将树划分为单色连接的组件。 

如果两个相邻顶点共享相同的颜色，则它们属于同一组件，并且该组件内的每一对顶点与交叉组件的对的贡献不同。 关键的见解是，在树中，任何与图形的正确双色的偏差都会创建单色边缘，该边缘会合并组件并增加组件内部的二次惩罚，而不会在其他地方提供足够的补偿。 这将最佳结构推向树的正确二分着色。 

一旦我们将自己限制在树的有效二分上，每条路径的结构就会变得统一：不同顶点之间的每条路径都会交替颜色，这意味着它总是包含两种颜色，因此总是为非对角线对贡献最大可能值。 剩下的自由度只是二分的哪一侧分配为 0，哪一侧分配为 1，这仅影响单顶点路径。 

这将问题从全局组合优化转化为树二分的简单计数问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对所有标签和配对进行暴力破解 | O(2^n · n^2) | O(2^n · n^2) | O(n) | 太慢了 |
 | 最优二分结构 | O(n) | O(n) | 已接受 |

 ## 算法演练

1. 运行 BFS 或 DFS 来计算树的二分。 每个节点都被分配一个奇偶校验类，形成两个集合 A 和 B。这总是可能的，因为每棵树都是二分的。 
2. 将一个部分指定为颜色 0，另一部分指定为颜色 1。只有两种选择：A 为 0，B 为 1，或者相反。 
3. 完成一项这样的作业并分析贡献。 对于任何两个不同的节点，它们之间的路径会交替颜色，因此它同时包含 0 和 1，这迫使路径值为 2。这意味着每个非对角线对贡献 2。 
4. 分别计算对角线对的贡献。 单个顶点贡献单元素数组的 mex：如果该顶点的颜色为 0，则为 1；如果该顶点的颜色为 1，则为 0。 
5. 因此，总值变为所有无序不同顶点对的 2 之和，加上颜色为 0 的顶点数。 
6. 由于唯一的自由度是二分的哪一侧被标记为 0，因此选择二分的较大一侧作为颜色 0 以最大化对角线贡献。 

### 为什么它有效

 树二分确保每条边都连接相反的颜色。 两个不同顶点之间的任何路径必须至少穿过一条边，并且每条边都会翻转颜色，因此该路径必须包含两种颜色。 这迫使每个非对角线对达到最大可能的 mex 值 2。 

任何引入单色边的替代着色都会将顶点合并为更大的同色连通组件。 这会在大小为 k 的组件内创建 θ(k^2) 对，其贡献降至 2 以下，而最多只能改善线性许多对角线贡献。 在树上，这种不平衡总是使得这种偏差不是最优的，因此纯二分可以最大化完全混合路径的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        g = [[] for _ in range(n)]
        for _ in range(n - 1):
            a, b = map(int, input().split())
            a -= 1
            b -= 1
            g[a].append(b)
            g[b].append(a)

        color = [-1] * n
        q = deque([0])
        color[0] = 0

        cnt = [0, 0]

        while q:
            v = q.popleft()
            cnt[color[v]] += 1
            for to in g[v]:
                if color[to] == -1:
                    color[to] = color[v] ^ 1
                    q.append(to)

        a, b = cnt[0], cnt[1]

        # all non-diagonal pairs contribute 2
        ans = n * (n - 1)

        # diagonal contributions: nodes colored 0 contribute 1
        ans += max(a, b)

        print(ans)

if __name__ == "__main__":
    solve()
```BFS 分配树的有效二分区并计算两个部分的大小。 公式`n * (n - 1)`考虑到所有有序非对角对在无序对的原始求和中各贡献 2。 唯一剩下的自由度是哪一侧被标记为 0，因此我们添加较大的分区大小。 

一个微妙的点是这个问题计算对$u \le v$，表示无序对加上对角线。 期限$n(n-1)$完全对应于$2$贡献高于一切$\binom{n}{2}$不同的对。 对角线处理通过零的计数干净地分开。

 ## 边缘情况

 单节点树直接暴露对角线规则：唯一的路径贡献单个值的 mex，这取决于所选的颜色，并且算法正确地为该节点选择颜色 0。 

双节点树确保二分逻辑正确处理最简单的边。 它们之间的路径始终贡献 2，最佳选择是将颜色 0 分配给一个端点以获得最佳对角线贡献。 

在星形树中，二分大小变得高度不平衡。 该算法将颜色 0 分配给较大的叶面，这会最大化贡献 +1 的顶点数量，同时将所有交叉对保持为值 2，匹配二分参数隐含的最佳结构。
