 ## 解决方案
 ## 问题理解

 我们得到一个小矩形蛋糕，分成正方形网格。 每个方块要么有浆果，要么是空的。 鼠标从蛋糕的左上角开始，只能向右或向下移动，直到到达右下角。 目标是计算如果老鼠试图最大化浆果摄入量，她会沿着她选择的路径吃掉多少浆果。 

输入将蛋糕表示为`H × W`字符网格，其中`H`是行数并且`W`是列数。 每个单元格包含`'*'`对于浆果或`'.'`为空。 输出是一个整数，即沿着从左上角到右下角的有效路径可以收集的浆果的最大数量。 

约束非常严格：`H`和`W`最多 5 个。这个小尺寸使我们能够考虑对于大网格来说太慢的方法。 特别是，即使对从左上角到右下角的所有路径进行暴力枚举也是可行的，因为路径总数最多为`C(H+W-2, H-1)`，这最多是`C(8,4) = 70`。 

当路径受到网格边缘的限制或者浆果沿着某些行或列聚集时，就会出现不明显的边缘情况。 例如，如果顶行是空的，所有浆果都在底行，那么总是喜欢立即可见浆果的粗心贪婪方法可能会选择错误的路径。 当网格处于`1×N`或者`N×1`，其中鼠标只有一条可能的路径。 正确的解决方案必须能够毫无错误地处理这些小尺寸。 

## 方法

 简单的暴力方法会枚举从左上角到右下角的所有有效路径。 对于每条路径，我们都会计算收集到的浆果数量并返回最大值。 这种方法之所以有效，是因为路径的数量由以下组合限制`(H+W-2 choose H-1)`。 在 5×5 网格的最坏情况下，这是`C(8,4) = 70`路径，并且每条路径都经过`O(H+W)`评估步骤，总共最多给出 560 个操作。 虽然在这里可行，但这种方法不能推广到更大的网格，并且正确实施起来很繁琐。 

更优雅和通用的方法使用动态编程。 我们定义`dp[i][j]`作为可以从左上角收集的浆果的最大数量`(0,0)`到细胞`(i,j)`。 关键的见解是到达细胞`(i,j)`，鼠标必须来自上面的单元格`(i-1,j)`或从左侧的单元格`(i,j-1)`。 因此递推关系为`dp[i][j] = max(dp[i-1][j], dp[i][j-1]) + (1 if cell (i,j) has a berry else 0)`。 这将问题简化为填充一个简单的`H×W`表，简单明了并保证正确性。 蛮力思想之所以有效，是因为它会检查所有路径，但动态编程利用重叠的子问题来更有效、更干净地计算相同的结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(C(H+W-2, H-1)·(H+W)) | O(H+W) | 此处可行但冗长 |
 | 动态规划| O(H·W) | O(H·W) | 已接受 |

 ## 算法演练

 1.读取高度`H`和宽度`W`，并将蛋糕网格存储为字符串列表。 
2. 初始化一个`dp`尺寸表`H×W`， 在哪里`dp[i][j]`将存储收集到的最大浆果到达细胞`(i,j)`。 
3. 迭代所有单元格`(i,j)`按行主顺序。 对于每个单元格，确定到达它的最佳方式：

 - 如果`i > 0`， 考虑`dp[i-1][j]`作为从上面的单元收集的浆果的数量。 
- 如果`j > 0`， 考虑`dp[i][j-1]`作为从左侧单元格收集的浆果数量。 
- 取这两个值中的最大值。 如果`(i,j)`有浆果，加1。 
- 特殊情况：左上角单元格`(0,0)`没有上面或左边的邻居，所以`dp[0][0]`如果有浆果则为 1，否则为 0。 
4. 填写表格后，值为`dp[H-1][W-1]`是老鼠沿着有效路径可以收集的最大浆果。 

这有效的原因是`dp[i][j]`始终正确地代表细胞的最佳解决方案`(i,j)`。 由于鼠标只能向右或向下移动，因此任何路径`(i,j)`必须来自左侧或上方。 通过在每一步中取两种可能性的最大值并添加当前单元格的浆果（如果存在），我们确保我们永远不会低估最佳路径。 这个不变量适用于整个网格。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

H, W = map(int, input().split())
cake = [input().strip() for _ in range(H)]

dp = [[0] * W for _ in range(H)]

for i in range(H):
    for j in range(W):
        best_from_above = dp[i-1][j] if i > 0 else 0
        best_from_left = dp[i][j-1] if j > 0 else 0
        dp[i][j] = max(best_from_above, best_from_left) + (1 if cake[i][j] == '*' else 0)

print(dp[H-1][W-1])
```该代码初始化 DP 表并按行优先顺序迭代，以用最大可收集的浆果填充每个单元格。 我们通过检查是否来处理边界`i > 0`和`j > 0`。 最后一个单元格包含答案。 使用`strip()`确保输入中的尾随换行符不会影响单元格内​​容比较。
