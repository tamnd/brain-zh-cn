 ## 解决方案
 ## 问题理解

 该陈述以图片形式给出，但任务本身非常小。 我们收到一个整数`a`，其值介于`-100`和`100`。 图像中显示的表达式计算结果为相同的数字`a`，因此必须打印的答案只是输入值本身。 

由于只有一个整数且其大小很小，因此任何复杂性讨论几乎都是无关紧要的。 即使是恒定的工作量也绰绰有余。 读取数字并立即打印，运行时间可以忽略不计，并且使用恒定的内存。 

实现可能出错的唯一情况是由于对图片的误解而不是算法问题引起的。 

考虑输入```
1
```正确的输出是```
1
```错误地解释图像并执行一些不必要的算术的读者可能会产生不同的答案。 

另一个例子是```
-100
```正确的输出是```
-100
```负值是有效输入，因此必须准确保留符号。 

## 方法

 一种暴力方法是从图片中解码数学表达式，对其进行评估，然后打印结果。 由于只涉及一个数字，因此这已经只需要不断的工作并且是完全可以接受的。 

关键的观察结果是图像中的表达式在数学上等同于变量本身。 一旦认识到这一点，就不再需要计算了。 答案正是所读取的数字。 

暴力方法之所以有效，是因为计算表达式会给出正确的值。 通过观察公式总是会崩溃，简化步骤甚至消除了微小的计算量`a`。

 ## 算法演练

 1.读取整数`a`从输入。 
2. 输出`a`不变。 

这是正确的原因是语句中显示的表达式完全简化为原始变量。 

### 为什么它有效

 不变量很简单：公式表示的值始终等于`a`。 由于算法输出的值与读取的值相同，因此它与问题所需的数学量相匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

# solution
a = int(input())
print(a)
```程序首先使用快速输入读取整数。 由于只有一个值，因此不需要循环或辅助数据结构。 

唯一微妙的一点是保留标志。 转换为`int()`自动处理正数和负数。 直接打印该值可以避免意外更改该值的可能性。

 ## 边缘情况

 错误的常见来源是假设图片需要额外的计算。 考虑```
1
```算法读取`a = 1`并立即打印`1`。 由于表达式等于变量本身，因此这是正确的答案。 

另一个重要的情况是最小允许值：```
-100
```算法读取`a = -100`和打印`-100`。 不执行算术运算，因此符号和大小保持不变。 

同样的推理适用于之间的所有值`-100`和`100`，包含在内。 答案始终是输入的数字。
