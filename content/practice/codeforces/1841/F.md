 ## 解决方案
 ## 问题理解

 我们被要求模拟一个战略城市建设游戏，其中 Monocarp 可以接受或拒绝到达他的城市的生物群。 每个群体都包含一定数量的人类、兽人、精灵和矮人。 每个生物都会对由总人口和所有居民的幸福感总和组成的全局得分做出贡献。 幸福是由友好和敌对关系来定义的：同一种族的生物会增加彼此的幸福感，而敌对种族的生物会减少彼此的幸福感。 具体来说，人类和兽人彼此敌对，精灵和矮人彼此敌对。 

输入给出为`n`组，每个组由四个非负整数描述，指定每个种族的生物数量。 我们的任务是决定接受哪些群体以使总分最大化，总分计算为居民总数加上所有个人幸福值的总和。 

限制因素很重要：`n`最大可达30万，每个人口数可达10^9。 这排除了任何评估每个可能的组子集的暴力方法，因为会有 2^300,000 个子集，这在计算上是不可行的。 该算法必须在大约 O(n log n) 或 O(n) 时间内运行，大量使用结构和累积属性而不是穷举搜索。 

可能会阻碍幼稚实现的边缘情况包括仅包含敌对生物的组。 例如，一个由 10 名人类和 0 名兽人组成的群体绝对是有益的，而由 5 名人类和 10 名兽人组成的群体可能会降低总幸福感。 盲目地接受一个群体而不考虑它对幸福的净影响可能会产生次优的分数。 此外，需要小心处理空组或具有极大值的组，以避免整数溢出。 

## 方法

 暴力方法将枚举组的所有子集，计算每个子集的最终人口和幸福度，并返回最大分数。 每个子集计算都需要对人口进行求和并在种族之间成对地计算幸福度，从而导致 O(n * 2^n) 操作。 即使对于 n = 20，这也是不可行的，而当 n = 3*10^5 时，这是不可能的。 

关键的见解是观察到一个团体对总分的贡献可以表示为该团体在每场比赛中的计数与该城市当前总计数的线性函数。 让`H`,`O`,`E`,`D`表示迄今为止城市中的人类、兽人、精灵和矮人总数。 新群体的幸福贡献值得重视`a, b, c, d`是：```
(a*(H) - a*(B)) + (b*(O) - b*(A)) + (c*(E) - c*(D)) + (d*(D) - d*(C))
```在哪里`A, B, C, D`是当前人类、兽人、精灵、矮人的总数。 重新排列后，幸福贡献与友好计数和敌对计数之间的总差呈线性关系。 如果我们定义：```
x = humans - orcs
y = elves - dwarves
```然后，问题简化为选择组的子集来最大化以下线性函数的总和：`x`和`y`。 因为每个组的贡献相对于`x`和`y`，我们可以利用几何中的策略：按组中的“斜率”对组进行排序`(x, y)`平面并应用贪心选择。 具体来说，可以根据奇偶性对组进行分类`(humans + orcs) - (elves + dwarves)`，问题就简化为最大化这些线性投影的总和。 最终的解决方案使用排序和贪婪方法结合前缀和来有效计算总分。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 2^n) | O(n * 2^n) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读全部`n`分组并存储计数`(a, b, c, d)`在一个列表中。 这些代表每个群体中的人类、兽人、精灵和矮人。 这设置了优化步骤的输入。 
2. 对于每个组，计算两个派生值：`x = humans - orcs`和`y = elves - dwarves`。 这些差异编码了敌对互动对幸福感的净影响。 每个新组对分数的贡献为：`x`和`y`。 
3. 认识到总分是总人口加上幸福贡献的总和。 添加一个群体的幸福贡献可以表示为`a*(H-B) + b*(O-A) + c*(E-D) + d*(D-C)`，这简化了`x`和`y`并且与当前总数单调。 
4. 为了最大化总分，按符号对组进行分类`x`和`y`。 积极的群体`x`和`y`会增加当前的总数，从而增加幸福感，应该被接受。 具有负面贡献的群体需要仔细评估。 由于得分函数在此变换空间中是凸的，因此最优选择简化为贪婪策略：按总和对组进行排序`x + y`或其绝对值，如果总分增加则接受它们。 
5. 迭代排序后的组，维护人类、兽人、精灵、矮人的累积总数。 对于每个组，计算其对总分的边际贡献（如果添加）。 如果边际贡献非负，则接受该组并更新总数； 否则，跳过它。 这确保了每次添加都会严格提高分数。 
6. 处理完所有组后，将最终总分计算为总人口加上迭代过程中跟踪的总幸福感贡献之和。 

为什么有效：在每一步中，我们只接受提高总分的小组。 幸福贡献的线性关系为`(x, y)`保证先前被拒绝的组的任何组合都不会提高分数，因为任何被拒绝的组只会减少当前的累积总和。 贪婪选择是安全的，因为贡献函数在友好和敌对种族的净差异中是超模的，使得局部最优选择成为全局最优。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
groups = [tuple(map(int, input().split())) for _ in range(n)]

# Compute derived values
vals = []
for a, b, c, d in groups:
    x = a - b
    y = c - d
    vals.append((x, y, a + b + c + d))

# Sort by slope in the (x, y) plane to maximize contribution
vals.sort(key=lambda t: -(t[0] + t[1]))

total_score = 0
H = O = E = D = 0

for x, y, total in vals:
    delta = x*(H - O) + y*(E - D) + total
    if delta >= 0:
        H += x + (x < 0)*(-x)  # recover actual humans
        O += (H-O) - x
        E += y + (y < 0)*(-y)
        D += (E-D) - y
        total_score += delta

print(total_score)
```在这个解决方案中，我们首先将每个组转换为沿着敌对友好轴的净贡献，然后按他们的预计得分排序。 棘手的部分是正确计算累积的幸福贡献并确保准确更新组总数。 贪婪步骤由得分函数的凸性证明`(x, y)`空间。
