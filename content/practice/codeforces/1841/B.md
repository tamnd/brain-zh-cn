 ## 解决方案
 ## 问题理解

 我们从一个空数组开始，并一一接收数字。 

对于每个传入值`x`，我们必须决定将其附加到当前数组是否能让数组保持“美丽”。 如果是，我们将永久附加它。 否则我们会忽略它。 每次查询后我们输出`1`如果附加了该值并且`0`如果被拒绝了。 

一个漂亮的数组有一个非常具体的结构。 必须可以旋转数组，使其按非降序排序。 另一种说法是，数组是一个排序序列，可能已在一个位置被剪切并环绕。 

例如：`[1,2,3,4,5]`很漂亮，因为它已经排序了。`[3,7,7,9,2,3]`很漂亮，因为在之前的位置旋转`2`给出`[2,3,3,7,7,9]`。`[5,2,2,1]`并不美观，因为没有旋转产生排序序列。 

所有测试用例的查询总数最多为`2 · 10^5`。 任何在每次插入后重新扫描整个数组的解决方案都需要大约$$O(q^2)$$最坏情况下的操作，可以达到大约`4 · 10^10`运营。 这已经远远超出了极限。 

我们需要一个以恒定或对数时间处理每个查询的解决方案。 

一些边缘情况很容易处理不当。 

考虑：```
1
5
1 2 3 0 2
```接受的数组变成`[1,2,3,0]`。 旋转点出现后，附加`2`有效，因为第二段仍然是非递减的并且`2 ≤ 1`是假的。 仅检查本地排序的粗心实现将接受无效值。 

另一个棘手的情况是：```
1
4
5 1 2 6
```接受后`5`和`1`，数组是`[5,1]`，其中已经包含了唯一的掉落物。 追加`6`必须被拒绝，因为旋转的排序顺序将被破坏。 仅查看最后接受的元素会错误地允许它。 

重复也很重要：```
1
5
1 1 1 1 1
```每个值都应该被接受。 严格比较而不是非严格比较会拒绝有效的插入。 

## 方法

 暴力解决方案直接遵循定义。 

每次查询后，临时附加新值并测试结果数组是否美观。 为此，请找到每个可能的旋转并检查旋转后的数组是否已排序。 对于长度的数组`k`，这花费了`O(k²)`时间。 甚至是一个稍微改进的版本，可以检查所有旋转`O(k)`仍然导致`O(q²)`总工作量，因为每次查询后都会重复测试。 

关键的观察是，一个漂亮的数组最多可以包含一个顺序递减的位置。 

对于旋转排序数组：```
3 7 7 9 2 3
```正好有一滴：```
9 -> 2
```下降之前的一切都是不减的，下降之后的一切也是不减的。 

当我们构建数组时，我们只需要知道该水滴是否已经出现。 

设第一个接受的值为`first`。 

在下降出现之前，数组只是不减的。 可以附加至少与最后接受的值一样大的任何值。 

当我们看到一个值小于最后接受的值时，我们正在尝试创建唯一的旋转点。 仅当新值不大于时才允许这样做`first`。 否则，任何旋转都无法使数组排序。 

下跌存在后，每个未来值必须满足两个条件：

 它必须保持第二段不减少，因此它必须至少是当前的最后一个值。 

它必须保持在第二段的范围内，因此不能超过`first`。 

这些条件足以表征每个有效插入。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(q²) | O(q) | 太慢了 |
 | 最佳 | O(q) | O(q) | 已接受 |

 ## 算法演练

 1. 从一个空的接受数组开始。 
2.无条件接受第一个查询。 单元素数组总是很漂亮。 
3. 将第一个接受的值存储为`first`。 
4. 维护一个布尔值`wrapped`。`wrapped = False`表示旋转点尚未出现。`wrapped = True`意味着我们已经创建了独特的掉落。 
5. 对于每个新值`x`，检查当前最后接受的值。 
6. 如果`wrapped`是`False`：

如果`x >= last`，接受它。 数组保持不减。 

否则我们将尝试创建旋转点。 仅当以下情况时才接受`x <= first`。 如果接受，设置`wrapped = True`。 
7. 如果`wrapped`是`True`：

接受`x`仅当两个条件都成立时：`x >= last`

`x <= first`第一个条件保留第二段的非降序。 第二个条件保持旋转点之后的每个元素不大于第一段的开头。 
8. 输出`1`对于可接受的值和`0`对于被拒绝的值。 

### 为什么它有效

 不变的是，接受的数组始终由一个已排序的段或两个仅由一滴分隔的已排序段组成。 

什么时候`wrapped`是`False`，该阵列尚未使用其 drop。 我们可以继续排序的段，或者通过插入不大于第一个元素的值来创建唯一的drop。 

什么时候`wrapped`是`True`，掉落已经存在。 任何未来的元素都属于第二段。 它必须至少与该段中的前一个元素一样大，并且最多与数组的第一个元素一样大。 否则，旋转排序就变得不可能。 

每个被接受的插入都会保留这个不变性，而每个被拒绝的插入都会违反它。 由于漂亮数组恰好是最多有一个这样的落差和相应边界约束的数组，因此该算法是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        q = int(input())
        xs = list(map(int, input().split()))

        ans = []

        arr = []
        wrapped = False
        first = None

        for x in xs:
            if not arr:
                arr.append(x)
                first = x
                ans.append('1')
                continue

            last = arr[-1]

            ok = False

            if not wrapped:
                if x >= last:
                    ok = True
                elif x <= first:
                    ok = True
                    wrapped = True
            else:
                if last <= x <= first:
                    ok = True

            if ok:
                arr.append(x)
                ans.append('1')
            else:
                ans.append('0')

        print(''.join(ans))

if __name__ == "__main__":
    solve()
```第一个接受的值成为永久参考点`first`。 以后的每个决策都基于传入值、当前最后接受的值和`first`。 

变量`wrapped`记录唯一减少是否已被使用。 在使用之前，该数组的行为类似于正常的非递减序列。 一旦使用，每个未来值都必须保持在区间内`[last, first]`。 

一个微妙的细节是`wrapped`仅当创建掉落的值被实际接受时才会更改。 拒绝的值不得影响状态。 

另一个细节是非严格比较的使用。 允许相等的值，因为目标阶数是非递减的而不是严格递增的。

 ## 边缘情况

 考虑：```
1
4
5 1 2 6
```该算法接受`5`，然后接受`1`因为`1 <= first`。 这将创建旋转点并设置`wrapped = True`。 

价值`2`满足`1 <= 2 <= 5`，所以被接受。 

价值`6`违反`6 <= first`，所以被拒绝。 

输出是：```
1110
```这是完全正确的，因为一旦发生换行，旋转的排序数组就不能包含大于第一个段的元素。 

现在考虑重复项：```
1
5
1 1 1 1 1
```每次插入都满足非递减条件。 不需要包装。 

输出是：```
11111
```使用严格比较会错误地拒绝相等的值。 

最后考虑：```
1
5
3 4 5 1 0
```接受后`1`，包装已经存在。 

最终值`0`小于当前最后接受的值`1`，所以它会产生第二个水滴。 该算法拒绝它，因为`0 >= last`是假的。 

输出变为：```
11110
```这证明了中心不变量：一个漂亮的数组可能只包含一个减少。 一旦使用了该减少，所有后面的值都必须保留在第二个排序段内。
