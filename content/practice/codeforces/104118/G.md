 ## 解决方案
 ## 问题理解

 我们给定一个固定的步长$k$。 我们还被赋予$n$时间间隔，每个间隔代表特定商品销售的天数范围。 

商家根据我们选择的起始日期定期出现$s$。 一旦我们选择$s$，商家出现的日期$s, s+k, s+2k,\dots$。 仅当这些商家访问日中至少有一个落在该商品的销售间隔内时，才能购买每件商品$[L_i, R_i]$。 

我们的任务是选择开始日期$s$以便商人访问的算术级数与尽可能多的商品间隔相交。 我们想要最大化有多少个区间包含至少一个与以下值一致的值：$s \bmod k$。 

重新构造一下，每天都按其余数模分类$k$。 一旦我们选择$s$，我们正在修复残基类别$r = s \bmod k$。 然后商人在所有与以下一致的日子里访问$r$模数$k$，问题就变成了计算有多少个区间至少包含一个带余数的数字$r$。 

所以目标简化为：选择一个残基$r \in [0, k-1]$最大化间隔数量$[L_i, R_i]$包含至少一个与以下内容一致的整数$r \pmod{k}$。 

约束条件很大：最多$2 \cdot 10^5$间隔和值高达$10^9$，因此任何针对残基的暴力破解都是不可能的。 当以下情况时，解决方案必须明确避免迭代所有残基：$k$很大。 

朴素推理的一个微妙的失败案例是假设我们可以选择与最多间隔开始或结束匹配的残基。 例如，考虑$k=3$和间隔$[1,1], [2,2], [3,3]$。 每个间隔都是“紧密的”，并且每个残基恰好捕获一个间隔，但稍微移动间隔可能会完全破坏这种启发式方法，因为覆盖范围取决于间隔是否包含残基类中的任何数字，而不是端点。 

另一种失败情况是将间隔视为每个残基独立贡献，而不考虑一个间隔可能覆盖多个残基这一事实。 

## 方法

 蛮力的想法很简单：尝试每一个残留物$r$从$0$到$k-1$。 对于每个间隔$[L, R]$,检查是否存在一个整数$x$这样$x \equiv r \pmod{k}$和$L \le x \le R$。 这个条件相当于检查第一个数字是否与$r$在或之后$L$位于内$R$。 

对于固定的$r$，我们可以计算，对于每个区间，它是否被覆盖$O(1)$，所以每个剩余成本$O(n)$，导致$O(nk)$。 这立即失败，因为$k$可以达到$10^9$，使均匀$10^5$残留不可能。 

关键的观察是每个区间并不关心 的确切值$r$，仅关于哪些余数取模$k$出现在里面。 每个区间对应于模圆上的一个连续范围，但我们可以翻转视角：我们不是迭代残基，而是将每个区间分配给它覆盖的所有残基，并计算每个残基接收到多少个区间。 

如果我们从模算术的角度思考，结构就会变得更加清晰。 对于一个间隔$[L, R]$，“坏”的残基是那些没有数字一致的残基$r$位于区间内。 这些正是完全避开间隔的残基，形成间隙图案。 我们可以为每个间隔计算补集结构，而不是直接标记覆盖范围：失败的残基是那些最接近的残基数之前的残基$L$或之后$R$。 

一个更有用的变换是注意到每个间隔以周期性的方式对残差施加约束。 对于固定残基$r$，区间内的第一个候选者是：$$x = L + ((r - L) \bmod k)$$如果$x \le R$，然后残差$r$在此时间间隔内有效。 

该不等式定义了有效残基的连续范围，但它可能会环绕模数$k$。 因此，每个间隔贡献一个或两个范围$[0, k-1]$，并且我们希望残差在所有这些范围内具有最大重叠。 

我们将每个间隔转换为长度圆轴上最多两段$k$，然后在所有线段端点上使用扫描线。 自从$k$很大，我们只处理端点，而不是所有残基。 

每个间隔最多贡献两个事件，所以我们得到$O(n)$段。 对端点进行排序和扫描可以有效地为我们提供最大重叠点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解残留物 |$O(nk)$|$O(1)$| 太慢了|
 | 间隔至残留扫描线|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们想要将每个区间转换为留数集合$r$这样$[L, R]$包含一些数字一致$r \pmod{k}$。 

1. 对于每个间隔$[L, R]$，计算可以“命中”区间的第一个和最后一个可能的残基。 这是通过映射条件来完成的$L \le r + t k \le R$对于某个整数$t$进入约束条件$r$。 
2. 将条件重写为查找所有$r$使得存在一个整数$t$和：$$L \le r + tk \le R$$这相当于检查残差类是否与区间相交。 
3. 观察固定$r$，区间内最小的候选者是$x = L + ((r - L) \bmod k)$。 如果该值在$R$，余数有效。 
4. 不是单独检查残基，而是反转条件：确定哪些残基$r$移动的位置落在该区间内。 这会在模圆上产生一段连续的有效残基。 
5. 对于每个间隔，计算该段。 如果该段没有回绕，则直接记录为$[a, b]$。 如果包裹起来，则将其分成$[a, k-1]$和$[0, b]$。 
6. 将所有段转换为扫描事件：段开始时+1，段结束后-1。 
7. 按位置对事件进行排序并扫过残留线以累积覆盖率。 
8. 扫描过程中遇到的最大前缀和就是答案。 

### 为什么它有效

 修复残留物$r$。 当算术级数中至少有一个元素时，它就有助于给出区间的答案$r, r+k, r+2k,\dots$位于里面$[L, R]$。 该转换将此隶属条件转换为残基上的几何区间，确保每个区间准确地贡献于正确的残基集，而不会重复。 然后，扫描线对每个残基计算包含该残基的间隔数量，并且最大重叠恰好对应于最佳起始残基。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def add_interval(events, l, r, val, k):
    if l <= r:
        events.append((l, val))
        events.append((r + 1, -val))
    else:
        events.append((l, val))
        events.append((k, -val))
        events.append((0, val))
        events.append((r + 1, -val))

def solve():
    n, k = map(int, input().split())
    events = []

    for _ in range(n):
        L, R = map(int, input().split())

        L_mod = L % k
        R_mod = R % k

        if R - L + 1 >= k:
            events.append((0, 1))
            events.append((k, -1))
            continue

        if L_mod <= R_mod:
            events.append((L_mod, 1))
            events.append((R_mod + 1, -1))
        else:
            events.append((L_mod, 1))
            events.append((k, -1))
            events.append((0, 1))
            events.append((R_mod + 1, -1))

    events.sort()

    cur = 0
    ans = 0
    for pos, delta in events:
        cur += delta
        if cur > ans:
            ans = cur

    print(ans)

if __name__ == "__main__":
    solve()
```该代码处理每个间隔并将其转换为一组残差贡献。 关键分支是间隔长度至少为的情况$k$，因为每个残基类都会出现在区间内的某个位置，所以它贡献了一个完整的范围$[0, k-1]$。 

对于较短的间隔，我们依赖模块化端点。 有效残基的间隔要么是单个连续段，要么是环绕段，这就是我们在需要时分成两个的原因。 

扫描线汇总了所有贡献。 排序确保我们按顺序处理残基位置，并且运行总和跟踪有多少个间隔支持每个残基。

 ## 边缘情况

 临界边缘情况是当间隔长度至少为$k$。 在这种情况下，每个残基都出现在该区间内，因此它必须提供完全覆盖。 例如：

 输入：```
1 5
1 100
```该算法检测到$R - L + 1 \ge k$并分配全范围覆盖。 然后，扫描线均匀地递增所有残基，得到答案 1。 

另一个边缘情况是环绕间隔。 考虑：```
1 5
4 6
```余数模 5：

 - 4 至 6 圈，从 4 → 0 → 1

 该算法分为 [4,4] 和 [0,1]。 扫描线正确累积残基 0 和 4 的覆盖范围，确保不会丢失有效匹配。
