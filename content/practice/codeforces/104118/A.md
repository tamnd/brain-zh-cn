 ## 解决方案
 ## 问题理解

 我们被赋予一个函数$f(x)$定义在实数上，但分为三个区域$x$。 每个区域使用不同的公式：最左边是一个线性表达式，中间是另一个线性表达式，右边是一个三次多项式。 

任务不是导出常量，因为问题已经提供了使函数在任何地方都平滑的唯一值。 相反，我们使用单个整数输入的固定系数直接评估函数$x$。 输入保证很小，介于$-10$和$10$，所以我们只需要常数时间的评估。 

关键的结构细节是该函数是分段的。 这意味着计算的唯一重要部分是决定哪个公式适用于给定的$x$。 一旦选择了正确的段，评估就是简单的算术。 

这里的一个天真的错误是误解区间边界。 左边的部分包括$x \le -3$，中间部分包括$-3 < x \le 2$，正确的部分包括$x > 2$。 边界点$-3$和$2$因此尤为重要。 例如，在$x = -3$，即使两个公式都是有效的表达式，使用错误的分支也会完全改变答案。 

由于输入范围很小，因此不存在性能问题。 任何在恒定时间内评估一个分支的正确实现就足够了。 

## 方法

 强力解释将尝试完全按照编写的方式对函数进行编码，甚至可能尝试计算或验证可微分条件。 这在这里是不必要的，因为系数已经是固定的。 剩下的唯一工作是对分段表达式求值一次。 

关键的观察结果是该函数完全由区间隶属度决定。 我们不需要微积分推理或符号操作。 我们只需要检查在哪里$x$谎言并应用相应的公式。 

暴力破解工作仍然会在每个查询的恒定时间内运行，但它可能会引入不必要的复杂性，例如重新计算公式或处理符号表达式。 最佳方法将一切简化为三个直接计算和几次比较。

 ## 算法演练

 我们首先使用提供的常量重写该函数，以便评估变得机械。 

为了$x \le -3$，函数是$f(x) = -(x + 4) + 8 = -x + 4$。 

为了$-3 < x \le 2$，函数是$f(x) = -2x + 1$。 

为了$x > 2$，函数是$f(x) = x^3 - 14x + 17$。 

现在计算变成了一个简单的决策过程。 

1.读取整数$x$。 这是唯一的输入值并完全确定分支。 
2. 检查是否$x \le -3$。 如果这个条件成立，计算$-x + 4$。 该分支对应于最左边的线性段，因此没有其他相关项。 
3. 否则，检查是否$x \le 2$。 如果这是真的，请计算$-2x + 1$。 这是中间部分，包括两者$x = -2$和$x = 2$，因此不等式必须包含在右端点上。 
4. 如果以上都不成立，则$x > 2$。 计算$x^3 - 14x + 17$。 这是唯一剩余的区域，因此不需要额外的检查。 

正确性来自于这三个区间形成了实线的完整的、不重叠的划分。 每个可能的整数输入都恰好属于一个分支，因此只应用一个公式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

x = int(input().strip())

if x <= -3:
    print(-x + 4)
elif x <= 2:
    print(-2 * x + 1)
else:
    print(x**3 - 14 * x + 17)
```该实现直接反映了间隔逻辑。 第一个条件处理所有值，包括$-3$，所以必须先检查。 第二个条件自动暗示范围$-3 < x \le 2$因为之前的分支排除了较小的值。 其他一切都属于立方体情况。 

唯一的微妙之处是确保保留条件的顺序。 错误地重新排序可能会导致边界值，例如$-3$或者$2$被分配给错误的表达式。

 考虑$x = -3$。 这位于第一个区间，因为$x \le -3$，所以我们计算$-(-3) + 4 = 7$。

 ## 边缘情况

 最重要的边缘情况正是位于$x = -3$和$x = 2$。 

为了$x = -3$，输入触发第一个分支，因为条件是$x \le -3$。 计算公式为$-(-3) + 4 = 7$。 如果程序员错误地使用严格不等式或首先检查中间分支，则该值将错误地落入线性中间公式。 

为了$x = 2$，第二个分支适用，因为它被定义为$x \le 2$。 计算变为$-2 \cdot 2 + 1 = -3$。 如果条件写错为$x < 2$， 然后$x = 2$会错误地跳转到三次表达式，产生完全不同的结果。 

这两种情况都表明，正确性并不取决于算术，而是取决于保留精确的区间划分。
