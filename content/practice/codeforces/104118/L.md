 ## 解决方案
 ## 问题理解

 我们得到一个由模数下的线性递推生成的确定性序列。 从初始值开始`s`，每个下一个值都是通过将前一个值乘以`a`，添加`b`，然后对一个大素数进行模减`p`。 这创建了一个最终循环的单个无限序列，因为它存在于大小有限的空间中`p`。 

对于每个测试用例，我们都会被问到一个直接可达性问题：从`s`，在序列首次达到目标值之前需要多少次转换`v`，如果有的话。 如果它从未出现，我们必须报告不可能。 

的约束条件为`p`至关重要。 自从`p`高达约 21 亿且为素数，状态空间足够大，以至于简单地模拟序列可能会非常昂贵。 在最坏的情况下，每个测试用例可能需要遍历几乎所有`p`在发现任何一个之前说明`v`或检测周期。 对于多达 40 个测试用例，对整个空间进行任何线性扫描都是不可行的。 

一个微妙的边缘情况是序列是周期性的但周期非常大。 例如，即使`v`保证会出现，它可能只出现在很长的前缀之后。 另一个边缘情况是当`v`等于`s`，其中正确答案为零，任何从下一个状态开始搜索的方法都会错误地错过这一点。 

## 方法

 直接模拟方法是最自然的起点。 我们重复应用递归并将每个生成的值与`v`。 这是正确的，因为序列是完全确定的，所以我们第一次遇到`v`给出最小索引. 然而，在最坏的情况下，这种方法可能会降低到每个测试用例的 O(p)，因为序列可能不会重复，直到覆盖大部分状态空间。 

关键的结构观察是，这是有限域上的线性函数。 过渡`x -> a x + b (mod p)`是双射，当`a != 0 (mod p)`，自此以来一直保持在这里`a > 0`和`p`是素数。 这意味着该序列是状态空间的排列，并且每个状态都位于单个循环或带尾部的循环上，具体取决于我们是否对方程进行变换。 

我们可以将递推式转化为封闭形式，而不是盲目地模拟。 什么时候`a != 1`，我们可以移动序列以删除常数项。 让`c = b * (a - 1)^{-1} mod p`，并定义`y_n = x_n - c`。 那么递归就变成了`y_n = a * y_{n-1} mod p`，这是纯粹的乘法。 这将问题简化为求解离散对数：找到最小的`n`这样`a^n * (s - c) ≡ (v - c) (mod p)`。 

这正是一个模离散对数问题，可以用 O(√p) 中的婴儿步巨步来解决。 自从`p`约为2e9，√p约为46000，可行。 

对于特殊情况`a = 1`，递归变为纯线性：`x_n = s + n * b mod p`，我们可以用模逆 if 来解决它`b != 0`。 

因此，我们将每个测试用例简化为离散对数问题或模算术方程。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 每次测试 O(p) | O(1) | O(1) | 太慢了|
 | 代数 + BSGS / 模块化数学 | 每次测试 O(√p) | O(√p) | 已接受 |

 ## 算法演练

 我们根据是否复发来不同地对待复发`a`等于 1。 

1. 检查是否`a == 1`。 在这种情况下，序列是算术级数模`p`。 该值演变为`x_n = s + n * b mod p`。 这避免了所有乘法复杂性。 
2.如果`a == 1`，处理两个子情况。 如果`b == 0`，序列是恒定的，所以我们只有在以下情况下才会成功`s == v`。 如果不相等，则无解。 
3.如果`a == 1`和`b != 0`，重写方程`s + n b ≡ v (mod p)`作为`n b ≡ v - s (mod p)`。 自从`p`是素数并且`b != 0`，我们计算模逆`b`并解决`n ≡ (v - s) * b^{-1} mod p`。 结果必须标准化为最小的非负残差。 
4. 现在考虑`a != 1`。 我们首先计算递归的不动点，即值`c`令人满意`c = a c + b mod p`。 求解给出`c = b * (1 - a)^{-1} mod p`。 这种转变删除了附加项。 
5. 将起始值和目标值变换到移位空间中：`y_s = s - c`和`y_v = v - c`, 全部取模`p`。 
6.如果`y_s == 0`，那么序列永远保持为零，所以唯一有效的答案是`y_v == 0`。 
7. 否则我们将递归减少到`y_n = a^n * y_s mod p`。 我们想要最小的`n`这样`a^n ≡ y_v * y_s^{-1} mod p`。 
8. 计算模逆`y_s`，形成目标比率，求解离散对数`a^n ≡ target mod p`使用婴儿步巨人步。 答案是最小的非负数`n`。 

### 为什么它有效

 关键的不变量是减去不动点将仿射变换转换为有限域中的纯乘法。 一旦采用乘法形式，每个状态都被唯一地表示为`a`乘以初始偏移量。 因为`p`是素数，每个非零元素都有一个逆元，因此变换保留结构，除了零之外不会发生碰撞。 然后，离散对数步长准确地表征了可达性，并且 BSGS 保证我们找到最小的指数，因为它枚举了直到循环大小的所有可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from math import isqrt

def modinv(x, p):
    return pow(x, p - 2, p)

def bsgs(g, h, p):
    # solve g^x = h mod p
    if h == 1:
        return 0
    m = isqrt(p) + 1

    table = {}
    cur = 1
    for j in range(m):
        if cur not in table:
            table[cur] = j
        cur = cur * g % p

    factor = pow(g, m * (p - 2) % (p - 1), p)
    # g^{-m} mod p

    gamma = h
    for i in range(m + 1):
        if gamma in table:
            return i * m + table[gamma]
        gamma = gamma * factor % p

    return None

def solve_case(a, b, s, p, v):
    if a == 1:
        if b == 0:
            return 0 if s == v else None
        return (v - s) * modinv(b, p) % p

    c = b * modinv((1 - a) % p, p) % p

    ys = (s - c) % p
    yv = (v - c) % p

    if ys == 0:
        return 0 if yv == 0 else None

    rhs = yv * modinv(ys, p) % p

    return bsgs(a, rhs, p)

T = int(input())
for _ in range(T):
    a, b, s, p, v = map(int, input().split())
    ans = solve_case(a, b, s, p, v)
    print(ans if ans is not None else "IMPOSSIBLE")
```该实现首先将仿射和乘法情况分开，因为混合它们会导致不必要的反转。 模逆使用费马小定理，因为`p`是素数。 

婴儿步巨人步例程构建了一个幂的哈希表`g`直到 √p，然后使用模幂逆以大小 √p 的跳跃向后行走。 一个常见的陷阱是计算`g^{-m}`不正确； 它必须以模数完成`p`, 不是模数`p-1`。 

仿射变换步骤也很微妙。 定点计算使用`(1 - a)^{-1}`模数`p`，并且需要小心地将所有东西都放在里面`[0, p)`减法之前。 

## 工作示例

 考虑样本重现`(a, b, s, p) = (7, 1, 2, 31)`和目标`v = 24`。 自从`a != 1`，我们计算不动点。 

固定点是`c = 1 * (1 - 7)^{-1} mod 31 = (-6)^{-1} mod 31 = 26`。 移动给出`y_s = 2 - 26 ≡ 7`和`y_v = 24 - 26 ≡ 29`。 

我们解决`7^n * 7 ≡ 29 mod 31`， 或者`7^n ≡ 29 * 7^{-1}`。 该算法将其简化为离散对数计算，并且 BSGS 找到与序列一致的最小指数。 

| 步骤| 价值|
 | --- | --- |
 | c | 26 | 26
 | y_s | 7 |
 | y_v | 29 | 29
 | 目标比率| 29 * 9 = 5 | 29 * 9

 该表显示了仿射结构如何分解为单个模指数方程。 这证实了转换步骤的正确性。 

现在考虑一个更简单的算术情况`(a, b, s, p) = (1, 3, 10, 17), v = 2`。 

我们解决`10 + 3n ≡ 2 mod 17`, 给予`3n ≡ 9`， 所以`n ≡ 3`。 

| 步骤| 价值|
 | --- | --- |
 | s | 10 | 10
 | v | 2 |
 | b^{-1} | 6 |
 | n | 9 * 6 模 17 = 3 |

 该迹线证实了模求逆处理和归一化为最小非负解的正确性。

 ## 边缘情况

 当序列恒定时会出现一种边缘情况。 例如，如果`a = 1`和`b = 0`，那么每一项都等于`s`。 算法立即返回`0`如果`s == v`，否则返回不可能。 任何尝试在这里应用模逆的方法都会失败，因为`b^{-1}`不存在。 

另一种边缘情况是当仿射到乘法变换中移位起始变为零时。 在这种情况下，序列会立即崩溃到一个固定点。 该算法在尝试离散对数之前显式检查此条件，以防止无效反转。 

最后的边缘情况是离散对数无解。 尽管转换干净地减少了问题，但并非每个目标都位于由`a`。 在这种情况下，BSGS 例程返回失败，并且主求解器正确地将其转换为`"IMPOSSIBLE"`。
