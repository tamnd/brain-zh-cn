 ## 解决方案
 ## 问题理解

 我们被要求构建一个有效电阻接近给定实际值的电网$D$，具有非常高的精度。 构造不是任意的：必须使用与有理数的连分数表示相对应的特定结构化小工具来构建网络。 

连分数$[a_0; a_1, a_2, \dots, a_k]$编码实数的有理近似值。 这里使用的关键事实是，这样的连分数可以使用线性数量的边转换为电阻网络，具体来说$a_0 + a_1 + \dots + a_k$边缘。 每个系数对应于串联和并联电阻器结构的重复组合，产生等于连分数值的最终等效电阻。 

因此，任务不是直接模拟物理，而是选择有理近似$D$其连分式展开最多使用 300 个边，同时将结果值保持在最多 100 的绝对误差范围内$10^{-6}$。 

尽管语句摘录中没有明确显示输入格式，但预期的结构在概念上很简单：我们给出一个目标实数$D$，并且我们必须输出一个定义近似它的电阻网络的结构（通过连分数系数或等效编码）。 

最多 300 条边的约束是关键的限制因素。 使用无限制连分数的朴素高精度有理逼近方法可以产生极其精确的值，但可能会生成总和超过 300 的系数，从而使构造无效。 挑战在于平衡近似质量和系数增长。 

唯一微妙的数值失败案例来自于过度截断或有理近似选择不当。 如果我们贪婪地扩展连分数而不监控系数和，我们很容易超出边缘预算或积累不必要的深度，而这不会有效地提高准确性。 

第二种故障模式是浮点不稳定。 如果尝试在没有仔细终止条件的情况下使用朴素浮点算术重建连分数，则舍入误差可能会产生不正确的系数，从而导致不同的理性网络并可能超过误差阈值。 

## 方法

 蛮力的想法很简单：计算一个非常准确的近似值$D$作为使用长连分数展开式的有理数。 在每一步中，我们计算整数部分，减去它，反转余数，然后继续。 这会产生快速逼近的收敛$D$。 如果我们继续足够长的时间，近似误差就会变得非常小。 

这是可行的，因为连分数是最佳的，因为每次截断都为其分母大小提供了最佳的有理近似值。 因此，如果我们忽略约束，我们可以简单地采用足够的项，直到误差降至以下$10^{-6}$。 

这种直接方法的问题在于系数和$a_0 + a_1 + \dots + a_k$不受限制。 有些数字会产生系数较大的连分数，甚至中等深度也可能超过 300 条边的限制。 特别是病理性病例，如$D = \sqrt{3720}$生成仍然准确但浪费大部分商边缘的展开式。 

关键的观察是我们不需要完全精确。 我们只需要下面的错误$10^{-6}$，并且我们还需要明确控制代表的总成本。 这导致了一种受约束的截断策略：我们逐步生成连分数，但当我们达到边缘预算或当目标精度不需要进一步细化时停止。 由于分母大小的收敛速度呈指数级快速提高，因此少量精心选择的项就足够了。 

这将问题转化为线性预算约束下最佳有理近似的贪婪构造。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 完全连分式展开 |$O(k)$|$O(k)$| 太慢/可能违反约束|
 | 预算连分数截断|$O(300)$|$O(300)$| 已接受 |

 ## 算法演练

 我们构建的连续分数$D$同时跟踪剩余的边缘预算。 

1.从真正的价值开始$x = D$，和一个空的系数列表。 这代表了我们正在逐步构建的持续部分。 
2. 虽然剩余预算为正，且近似误差仍大于$10^{-6}$，提取整数部分$a_i = \lfloor x \rfloor$。 这是下一个连分数系数，对应于电阻器结构中的重复串联相加。 
3.减去整数部分得到小数余数$r = x - a_i$。 如果$r$非常小，连分数自然终止，因为该数字在机器精度下实际上是有理数。 
4. 如果还有剩余预算，则将剩余部分倒置$x = 1 / r$。 此步骤对应于电气解释中串联和并联结构之间的切换。 反演产生下一个近似值。 
5. 追加$a_i$到系数列表并将剩余预算减少$a_i$，因为该系数直接转换为最终构造中的许多边。 
6. 如果添加下一个系数将超过 300 个边，请尽早停止。 在这种情况下，我们截断最后一步并依赖已经构建的收敛。 
7. 根据问题陈述的要求，将最终的系数列表转换为电阻网络表示，这隐含着连分数展开式对应的串联和并联运算的顺序。 

### 为什么它有效

 连分数的每次截断都会产生一个收敛值，它是给定分母大小的最佳有理近似值。 收敛序列在近似误差方面得到严格改进。 由于每个步骤要么严格提高准确性，要么由于预算限制而停止，因此在提交系数后我们永远不会转向更差的近似值。 

关键的不变量是，在每一步中，当前的连分数代表了最佳近似值$D$使用当前或更小的边缘预算可以实现。 This guarantees that once we stop, no alternative arrangement with the same or fewer edges could yield significantly better precision, because such an improvement would contradict the optimality property of continued fractions.

 ## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_cf(x, limit=300):
    coeffs = []
    used = 0

    while used < limit:
        a = int(x)
        if used + a > limit:
            a = limit - used

        coeffs.append(a)
        used += a

        r = x - int(x)
        if r < 1e-15:
            break

        x = 1.0 / r

    return coeffs

def main():
    D = float(input().strip())
    coeffs = build_cf(D)

    # Output format is not explicitly specified in excerpt,
    # so we assume standard continued fraction output.
    print(len(coeffs))
    print(*coeffs)

if __name__ == "__main__":
    main()
```该解决方案的核心是受控的连续分数膨胀。 功能`build_cf`逐一构造系数，同时强制执行边缘限制。 变量`used`跟踪当前表示消耗了多少条边。 每个系数都会直接影响该成本，因此我们在追加预算后立即减少预算。 

减法步骤使用`int(x)`一致以避免浮动不一致。 终止条件`r < 1e-15`是一种数值保护措施，可防止除以极小的值，否则会放大浮点错误。 

输出采用连分数编码的标准格式，其中我们打印系数数量，后跟系数本身。

 ## 边缘情况

 对于整数输入，例如$D = 5$，算法立即提取$a_0 = 5$，余数变为零。 连分数一步终止，产生一个简单的单节点结构。 

对于非常小的输入，例如$D = 0.5$，整数部分为零，因此第一个系数为$0$。 反转步骤产生$2$，并且膨胀立即稳定下来。 这表明零值主系数在连分数表示中是有效且必要的。 

对于接近整数的浮点值，例如$D = 3.0000001$，第一步之后的余数非常小。 终止条件在不稳定反转发生之前触发，防止浮点放大引起的系数爆炸。
