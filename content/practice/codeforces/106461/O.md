 ## 解决方案
 ## 问题理解

 我们正在计算有序的整数对$(a, b)$两个数字都在范围内$1 \le a, b < 2^N$。 每个数字都用精确表示$N$位。 

该条件通过应用于以下三个值的三角形不等式来表达：$a$和$b$，但是在使用 XOR 和 AND 恒等式进行代数变换之后，它就变成了干净的位级要求。 为了使一对有效，当我们比较时$a$和$b$一点一点地，三种不同类型的位位置一定都出现在某个地方：

 必须存在至少一位两个数字都为 1 的地方。 必须存在至少一位其中两个数字都为 1 的地方。$a$有 1 和$b$有 0。必须存在至少一位，其中$b$有 1 和$a$有 0。 

所以问题归结为计算有多少长度-$N$对的按位配置$(a_i, b_i)$满足所有三个非零模式在所有位置上至少出现一次。 

由于每个位位置独立贡献四种状态之一$(0,0), (1,0), (0,1), (1,1)$，整个空间有大小$4^N$。 这些限制是全局性的：我们禁止错过三个特定状态中的任何一个。 

约束条件$N \le 10^?$这里没有明确显示，但是封闭式解决方案的存在和 Codeforces 典型的时间限制意味着我们必须评估以下表达式：$O(1)$或者$O(\log N)$。 任何枚举超过$2^N$或者$4^N$即使对于中等程度的人来说也是不可能的$N$， 自从$4^{30}$已经超过$10^{18}$。 

当人们错误地假设独立性并在不强制执行全局存在约束的情况下乘以概率或每位计数时，就会出现微妙的失败情况。 例如，将每一位独立计数为“如果有助于三角形形成则有效”，错误地过度计算了所需模式根本不会出现的配置。 问题在于该条件是针对位而不是针对每位存在的。 

## 方法

 蛮力法考虑每一对$(a, b)$，直接检查三角形条件，并计算有效对。 每次检查都是恒定时间，但是有$2^N$选择$a$和$2^N$为了$b$, 给予$4^N$总对。 这几乎立即变得不可行。 

关键的观察是从数字移动到位位置。 每个位都贡献四个独立类别之一：均为零，仅$a$， 仅有的$b$，或两者兼而有之。 约束要求在这些类别中，最后三个非零模式都至少出现一次$N$职位。 

那么问题就变成了：统计字符串的长度$N$在大小为 4 的字母表上，使得三个指定符号都至少出现一次。 这是针对缺失符号的经典包含-排除设置。 

我们从一切出发$4^N$作业。 然后我们减去至少缺少一个所需符号的情况。 如果符号被禁止，则每个位置有 3 个选择，给出$3^N$。 如果缺少两个符号，则每个位置仅保留 2 个选择，即$2^N$。 如果这三个状态都缺失，则只剩下一个状态，即$1$。 

应用包含-排除会产生一个封闭公式：$$4^N - 3 \cdot 3^N + 3 \cdot 2^N - 1$$| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(4^N)$|$O(1)$| 太慢了|
 | 最优（包含-排除）|$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 我们将问题简化为计算按位赋值$N$独立立场。 

1. 将每个位位置视为选择四种状态之一：$(0,0), (1,0), (0,1), (1,1)$。 这会将数字转换为序列而不是二进制整数。 
2. 认识到有效性仅取决于所有三个非平凡状态是否在整个序列中至少出现一次。 全零对状态是无关紧要的。 
3、从无限制序列总数开始，即$4^N$。 
4. 减去至少缺少一个所需状态的序列。 如果我们禁止一种状态，则每个位置有 3 个选择，给出$3^N$。 有3个这样的状态，所以减去$3 \cdot 3^N$。 
5. 添加缺少两个状态的序列，因为它们被减去了两次。 如果两个状态被禁止，则只剩下 2 个状态，给出$2^N$。 有$\binom{3}{2} = 3$这样的对，所以添加$3 \cdot 2^N$。 
6. 减去缺少所有三个所需状态的序列。 只剩下中立状态，准确贡献$1$配置。 

### 为什么它有效

 每个无效配置都根据其缺少的所需位模式子集进行分类。 包含-排除确保在纠正过度减法后每个配置都被精确计数一次。 分解是完整的，因为每个序列都可以唯一地映射到三个所需类别中的缺失符号集。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    pow4 = 4 ** n
    pow3 = 3 ** n
    pow2 = 2 ** n
    
    ans = pow4 - 3 * pow3 + 3 * pow2 - 1
    print(ans)

if __name__ == "__main__":
    solve()
```实现直接反映了导出的公式。 每个功率对应于限制每个位置允许的位对状态。 减法和加法项对缺失的位模式类别实施包含-排除。 由于 Python 本身可以处理大整数，因此不需要模数。 

一个常见的错误是尝试独立计算每个位的组合，但这种错误会失败，因为要求的是模式的全局存在，而不是每个位置的有效性。

 ## 边缘情况

 对于$N = 1$，仅存在一位，因此不可能同时实现“仅a”、“仅b”和“双一”模式。 该算法评估：$4 - 9 + 6 - 1 = 0$，符合没有任何配置可以满足所有约束的事实。 

为了$N = 2$，同样的限制仍然存在，因为只有两个位置，但需要三个不同的模式。 公式给出：$16 - 27 + 12 - 1 = 0$，并且包含-排除正确地取消了所有无效配置，而不会产生误报。 

对于较大的$N$， 例如$N = 3$，算法自然地开始计算有效分布，例如将每个所需的模式放置在不同的位位置。 该公式得出 6，对应于为每个所需状态分配至少一个位置，同时允许其余位置自由变化的方式。
