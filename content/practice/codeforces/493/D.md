 ## 解决方案
 ## 问题理解

 我们有一个$n \times n$木板。 白皇后从左上角开始$(1,1)$，黑皇后从右上角开始$(1,n)$。 每隔一个方格包含一个绿色棋子。 

移动是强制性的。 在每个回合中，玩家必须与他们的皇后一起吃掉一些棋子。 被捕获的棋子可能是绿色棋子或对方的皇后。 皇后的移动与国际象棋中的完全相同，沿着行、列或对角线移动，并且不能跳过棋子。 

玩家在两种情况下都会失败。 第一个是当他们开始回合时没有可用的合法捕获。 第二次是当他们的后被对手的上一步棋吃掉时。 

输入仅包含电路板尺寸$n$。 我们必须确定哪位玩家在完美发挥下获胜。 如果白方获胜，我们也必须输出白方的第一步棋。 在所有获胜的第一步中，我们需要具有最小行的一步，然后是最小列的一步。 

约束是问题中最能揭示问题的部分。 电路板尺寸可以大到$10^9$。 构建董事会是不可能的。 即使每平方存储一位也需要太多的内存。 任何对单个单元进行推理或逐步模拟游戏的解决方案都将立即被排除。 

这表明该游戏必须具有非常简单的数学结构。 整个解决方案需要从仅依赖于$n$。 

第一个不明显的边缘情况是$n=2$。 

输入：```
2
```皇后们沿着第一排直接互相攻击。 白棋可以立即吃掉黑棋。 

输出：```
white
1 2
```如果一个粗心的解决方案假设两个皇后都必须继续吃掉棋子，那么就会错过这个即时的胜利。 

另一个重要案例是$n=3$。 

输入：```
3
```输出：```
black
```乍一看，白棋似乎有很多合法的棋步。 事实上，每一个安全的举动都是被迫的。 两个皇后都沿着各自的纵队向下移动，直到白棋最终不得不进入中间纵队并被捕获。 仅基于步数的简单分析很容易预测错误的获胜者。 

最后一个重要的情况是任何大于 2 的偶数板尺寸。 

输入：```
4
```输出：```
white
2 2
```获胜的棋步不是角棋棋步。 确切的平方很重要，因为该语句要求按字典顺序最小的获胜第一步。 

## 方法

 暴力方法可以明确地对游戏状态进行建模。 我们可以表示两个皇后和所有剩余棋子的位置，生成每个合法的移动，并用极小极大计算获胜者。 

对于一块尺寸的板$n$， 有$n^2$正方形，几乎所有最初都包含棋子。 状态数量随着捕获数量呈指数增长。 即使对于非常小的电路板，这也是不可行的。 和$n$最多$10^9$，单独构造初始位置是不可能的。 

关键的观察结果是棋盘上完全布满了棋子。 由于皇后不能跳过棋子，因此每个皇后最初只能捕获沿其攻击方向之一相邻的棋子。 

让我们检查一下游戏结构而不是单个位置。 

对于奇数$n$，有一个中心柱。 任何进入其中的女王都会受到对方女王的攻击。 最佳游戏迫使两个皇后尽可能长时间地呆在自己的侧栏中。 他们逐渐向下移动。 最终白方第一个被迫进入中柱，之后黑方吃掉白后并获胜。 

对于甚至$n$，没有中心柱。 白方可以立即移动到方格$(2,2)$。 此步棋后，局面变得对称，但黑棋必须先做出反应。 在失败的配置中，白棋实际上将棋子交给了黑棋。 这是均匀棋盘尺寸的标准获胜策略。 

显着的结果是获胜者仅取决于平价$n$。 

如果$n$奇数，黑胜。 

如果$n$相等，白棋胜，所需步法是$(2,2)$。 为了$n=2$，这也是$(1,2)$，因为白棋可以立即吃掉黑棋，并且该棋步具有尽可能小的行。

 ## 算法演练

 1. 读取值$n$。 
2.如果$n$为奇数，打印`"black"`。 

对于奇怪的棋盘尺寸，最佳游戏会导致第二个玩家被迫获胜。 
3. 否则，打印`"white"`。 

即使棋盘大小也能为第一名玩家赢得位置。 
4. 如果$n=2$，打印移动`(1, 2)`。 

白棋可以立即吃掉黑棋。 
5. 否则，打印移动`(2, 2)`。 

这是每个偶数中按字典顺序最小的获胜第一步$n \ge 4$。 

### 为什么它有效

 游戏完全简化为平价。 

对于奇怪的棋盘尺寸，填满的棋盘迫使两个皇后进行一系列对称的捕获。 白棋是第一个必须离开安全边柱并进入被黑棋攻击的方格的棋手。 由于白棋先走，白棋首先到达这个失败的时刻。 

对于均匀的棋盘尺寸，白方可以移动到$(2,2)$，在保持对称性的同时为黑方创造了奇怪大小的失败结构。 黑方成为最终面临强制失败棋步的棋手。 由于最终的位置对于玩家移动来说是失败的，所以白方获胜。 

因为该语句要求最小的获胜步法，$(2,2)$为所有大于两个的偶数板选择，而$(1,2)$是立即获胜的捕获，当$n=2$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

if n % 2 == 1:
    print("black")
else:
    print("white")
    if n == 2:
        print("1 2")
    else:
        print("2 2")
```第一个决定检查电路板尺寸的奇偶性。 整个博弈论分析都崩溃到这个单一条件。 

什么时候$n$很奇怪，答案只有一行，因为黑方获胜，而白方不存在获胜的棋步。 

什么时候$n$势均力敌，我们也必须输出必胜的先手棋。 特殊情况$n=2$单独处理是因为白棋可以直接吃掉黑后。 对于每个更大的均匀板，$(2,2)$是所需的动作。 

不需要循环、递归或大型数据结构。 该解决方案完全符合以下价值$n$。

def solve():
