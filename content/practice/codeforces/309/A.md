 ## 解决方案
 ## 问题理解

 我们被要求计算圆形跑道上跑步者之间的预期碰撞次数。 每个跑步者都从沿着跑道长度的不同位置开始`l`并以相同的概率选择顺时针或逆时针运行。 所有跑步者以每单位时间一米的相同速度跑步，精确跑完`t`时间单位。 当两个跑步者在同一点相遇时，我们将其视为碰撞。 如果一对跑步者在多个时刻相遇，则可能会发生多次碰撞。 

输入给我们`n`, 跑步人数,`l`轨道的长度，`t`他们运行的时间，以及一系列`n`沿轨道排序起始位置。 输出是一个实数 - 之后所有跑步者之间的预期碰撞总数`t`时间单位，精度高达10^-6。 

和`n`最多 10^6 且`t`和`l`达到 10^9 时，对每个时间单位的位置进行任何强力模拟都是不可行的。 每个时间单位模拟每一对将导致多达 10^15 次操作，这远远超出了 2 秒的时间限制。 因此，我们必须利用均匀速度和对称性来导出预期的碰撞，而无需模拟每个时间步长。 

边缘情况包括只有一个跑步者（没有碰撞）、跑步者聚集在一起使得同一对跑步者可能发生多次碰撞，以及与`t`，尽管有多个跑步者，这可能不会导致碰撞。 

## 方法

 最简单的方法是迭代所有成对的跑步者，模拟每个时间单位的位置，并计算碰撞次数。 这是有效的，因为当两个跑步者占据同一位置并且有一个小的碰撞时，碰撞就会发生。`n`和`t`，它会正确地累积计数。 然而，随着`n`最多 10^6 且`t`最多 10^9，迭代`t`步骤是不可能的，最坏情况下的操作计数为 O(n^2 * t)，这是不可接受的。 

关键的见解是考虑对称性和均匀速度。 每对跑步者有 50% 的机会朝相反的方向跑步。 仅当它们彼此靠近时才会发生碰撞。 我们可以计算两个跑步者之间的距离，并确定如果他们朝相反的方向跑步，他们会相遇多少次，而不是模拟每个时间单位。 在圆形轨道上，这相当于它们沿相反方向行驶的距离之和达到轨道长度的次数。 由于每个方向选择都是独立的，因此每对的预期碰撞次数乘以 0.5，然后对所有对进行求和。 

这将问题简化为对跑步者的位置进行排序并计算其中有多少个起点`2 * t`每个跑步者都领先几米，环绕圆圈。 这可以通过在排序数组上使用两指针技术来有效地完成，从概念上扩展它以处理循环性质。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 * t) | O(n^2 * t) | O(n) | 太慢了 |
 | 两分球预期 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对跑步者的起始位置进行排序，尽管输入保证它们已经排序。 排序可确保两指针扫描正确工作。 
2. 通过添加概念性地复制轨道位置`l`到每个原始位置，形成一个“环绕”数组。 这样可以轻松处理圆形距离，而无需在循环中进行模运算。 
3.初始化两个指针：`i`迭代原始的`n`跑步者，以及`j`追踪可到达的最远跑步者`2 * t`距跑步者顺时针距离`i`。 
4. 对于每个跑步者`i`， 进步`j`直到跑者到达指定位置`j`超过`2 * t`前面。 之间的跑步人数`i+1`和`j-1`代表所有可以碰撞的跑步者`i`及时`t`如果它们朝相反的方向移动。 
5. 将所有这些计数相加并乘以 0.25。 因子 0.25 来自两个独立的 50% 概率：跑步者的机会`i`一个顺时针移动，另一个逆时针移动。 
6. 以足够的浮点精度输出结果总和。 

为什么有效：不变的是，对于每个跑步者，两指针窗口准确地计算有效碰撞距离内的所有跑步者。 乘以 0.25 将计数转换为独立方向选择的预期碰撞次数。 由于每个跑步者对每对进行一次计数，因此此方法可以正确计算预期的总碰撞次数，而不会遗漏或重复计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, l, t = map(int, input().split())
a = list(map(int, input().split()))

# Duplicate array to handle circular wrap
b = a + [x + l for x in a]

ans = 0
j = 0
for i in range(n):
    while j < len(b) and b[j] - a[i] <= 2 * t:
        j += 1
    ans += j - i - 1  # runners in range after i

# Each collision has probability 1/4
print("{0:.10f}".format(ans * 0.25))
```我们首先有效地读取并解析输入。 我们扩展数组以考虑圆形距离，然后使用两指针方法查找其中的所有对`2 * t`距离。 减法`i + 1`确保我们只计算当前跑步者之前的跑步者，以避免重复计算。 乘以 0.25 表示每个跑步者有 50% 的机会朝相反方向移动。 结果被格式化为十位小数以满足精度要求。
