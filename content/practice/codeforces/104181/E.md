 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$网格，其中每个单元格由其行确定$i$和列$j$。 该单元格中的值是整数除法结果$\left\lfloor \frac{j}{i} \right\rfloor$。 换句话说，每一行$i$通过将所有列索引除以形成$i$，向下舍入。 

任务不是构建网格，而是计算有多少个单元格包含给定值$k$。 

因此，我们实际上没有填写表格，而是被问到：在所有对中$(i, j)$和$1 \le i, j \le n$, 有多少满足$$\left\lfloor \frac{j}{i} \right\rfloor = k.$$约束条件$n \le 100000$立即排除所有的直接枚举$n^2$细胞。 完整的网格评估需要最多$10^{10}$行动，这远远超出了任何可行的时间限制。 

当逐行思考时，会出现一个更微妙的问题。 即使我们修复了一排$i$，扫描所有列$j$每行仍然是线性的，再次导致$O(n^2)$。 

边缘情况来自边界附近的楼层划分行为：

 当$k = 0$，我们正在计算对，其中$j < i$。 例如，与$n = 4$， 排$i = 3$贡献$j = 1,2$，因为两者都给出零。 一个简单的实现假设$j / i \ge 1$总是会想念这整个地区。 

什么时候$k = n$，只有极其受限的对才能满足$j = i \cdot k$，并且许多行没有任何贡献。 任何盲目假设每个的方法$k$经常出现会多算。 

关键的困难在于每行都会产生长的连续的相等值范围，而不是独立的每个单元格行为。 

## 方法

 暴力解决方案直接评估每一对$(i, j)$，计算$j // i$，并检查它是否等于$k$。 这是简单且正确的，但它需要$n^2$运营。 和$n = 10^5$， 这是$10^{10}$分裂，这是不可能的。 

函数的结构$\left\lfloor \frac{j}{i} \right\rfloor$完全改变了画面。 对于固定的$i$，该值在时间间隔内保持恒定$j$。 具体来说，所有$j$在$$[k \cdot i, (k+1)\cdot i - 1]$$产生价值$k$，只要他们留在$[1, n]$。 

这将每一行从一系列单独的检查转换为范围交集问题。 而不是迭代所有$j$，我们计算有多少个整数位于重叠部分$[k i, (k+1)i - 1]$和$[1, n]$。 

这将每一行的工作时间减少到恒定，使整个解决方案呈线性$n$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了|
 | 每行范围|$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 ## 算法演练

 1.修复行索引$i$。 我们想要计算有多少列$j$满足$\left\lfloor \frac{j}{i} \right\rfloor = k$。 而不是检查每个$j$，我们将条件解释为范围约束$j$。 
2. 将条件重写为不等式：$$k \le \frac{j}{i} < k+1.$$乘以$i$给出：$$k i \le j < (k+1)i.$$自从$j$是一个整数，这成为包含范围：$$j \in [k i, (k+1)i - 1].$$3. 将此范围与有效列边界相交$[1, n]$。 实际有效段变为：$$L = \max(1, k i), \quad R = \min(n, (k+1)i - 1).$$如果$L > R$，该行贡献零值。 
4、有效数量$j$对于这一行是$\max(0, R - L + 1)$。 将此贡献添加到答案中。 
5. 对所有人重复$i$从$1$到$n$，累加总数。 

### 为什么它有效

 每行划分为不相交的间隔，其中楼层划分是恒定的。 值的区间$k$直接从楼层除法的定义导出，并且恰好包含那些产生值的整数$k$。 由于这些间隔对于不同的情况来说是精确的且不重叠的$k$，将它们的交集与$[1, n]$对每个有效单元格精确计数一次，不会重复或遗漏。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

ans = 0

for i in range(1, n + 1):
    L = k * i
    R = (k + 1) * i - 1

    if R < 1 or L > n:
        continue

    L = max(L, 1)
    R = min(R, n)

    if L <= R:
        ans += R - L + 1

print(ans)
```实现直接遵循导出的区间逻辑。 每次迭代计算固定行的有效列段$i$，然后将其夹紧到网格边界。 支票`R < 1 or L > n`跳过根本没有贡献的行，这在以下情况下尤其重要：$k = 0$，因为原始公式产生负或零下限。 

必须注意整数边界。 表达式`(k + 1) * i - 1`至关重要，因为在转换回整数范围之前上限是排除的。 缺少`-1`导致差一的过度计数。

 ## 边缘情况

 当$k = 0$，区间变为$[0, i-1]$，但有效$j$从 1 开始。算法通过钳位来处理这个问题$L = \max(1, 0)$，所以每一行都准确贡献$i-1$值时$i \le n$。 例如，与$n = 4$， 排$i = 3$收益率区间$[1,2]$，给出两个有效的单元格，匹配楼层划分的定义。 

什么时候$k i > n$，下限超出网格范围，并且该行没有任何贡献。 这自然消除了大$i$对于固定的$k$，这就是为什么即使对于大的总和也能快速稳定$n$。 例如，与$n = 10$,$k = 3$, 行$i \ge 4$通常会产生空的交叉点，并且循环安全地跳过它们。 

什么时候$(k+1)i - 1 < 1$，这仅发生在极小的情况下$i$什么时候$k = 0$，该算法尽早检测无效范围并完全避免负索引行为。
