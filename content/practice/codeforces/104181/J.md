 ## 解决方案
 ## 问题理解

 我们得到一个有向图，其中每个交叉路口都有一条外出道路。 如果我们从任何节点开始并继续跟踪传出边缘，我们将确定性地在每步一分钟内移动到另一个节点。 因为每个节点的出度都是1，所以每个起点最终都会进入一个循环，然后在这个循环内永远循环下去。 

两个司机选择两个不同的起始路口。 它们同步移动，每分钟一步。 如果在某一时刻它们同时占用同一个节点，就会发生崩溃。 任务是计算有多少无序的起始节点对在此确定性运动期间避免相遇。 

的约束条件为$2 \cdot 10^5$节点强制线性或近线性解决方案。 任何直接比较所有起始节点对的方法都将涉及大约$n^2$相互作用，其顺序为$4 \cdot 10^{10}$在最坏的情况下运作，远远超出极限。 我们需要利用“每个节点一个传出边缘”所强加的结构。 

当所有节点最终合并成一个循环时，就会出现关键的边缘情况。 然后，落在该循环上的每一对节点最终都会发生碰撞，因为它们的位置变得周期性且对齐。 仅检查路径是否相交而不考虑时间的简单方法会错误地将此类对视为安全。 

另一个微妙的情况是，当两个节点到达相同的循环但沿其传入树的距离不同时。 即使它们满足相同的周期，它们也可能在不同的时间到达，从而避免碰撞。 该解决方案必须尊重时间对齐，而不仅仅是可达性。 

## 方法

 如果我们从每个起始节点开始模拟这个过程，我们就可以计算出它的完整轨迹，直到它进入一个循环。 一旦我们知道每个节点的完整路径，我们就可以比较每对轨迹并检查它们是否同时重合。 这是可行的，因为图是确定性的并且每条路径都是唯一的。 

然而，每条路径的长度都可以$O(n)$，并且有$n$起始节点。 构建所有轨迹已经$O(n^2)$总长度。 轨迹的成对比较增加了另一个因素，使得该方法从根本上不可行。 

图的结构是重要的观察结果。 由于每个节点都有一个出边，因此该图是一个函数图：一组有向循环，其中有向循环注入其中。 每个节点都有一个独特的“下一个”状态，因此系统的行为就像确定性的时间演化。 

重新构建问题的一个有用方法是逆时针思考。 如果两个令牌同时在同一节点相遇，那么从那一刻起，它们未来的路径是相同的。 所以碰撞就相当于说两个起点最终在这个函数图中同步了。 

函数图中的同步由节点位于同一树和循环结构中的位置决定。 特别是，同一弱连接组件中的所有节点最终都会进入同一个循环，在该结构中，我们可以模拟每个节点到达循环所需的时间以及它在循环中的位置。 

关键思想是将图分解为循环和树，然后计算每个节点进入循环的入口点以及到该入口点的距离。 一旦知道这一点，每个节点的未来行为就可以通过一对来完整描述：其周期标识符及其在时间归一化后沿周期的偏移量。 

当且仅当两个节点的轨迹在某个时间对齐时，两个节点才会发生碰撞，当它们的最终循环行为在循环标识和相位对齐中都匹配时，就会发生这种情况。 这允许通过按周期对节点进行分组并跟踪有多少对被迫相交来计算冲突。 

最终计数变为：总对数减去最终碰撞的对数。 由于总对是$n(n-1)/2$，问题简化为计算非冲突对，这可以从基于周期的分组和定时偏移中导出。

 ## 算法演练

 我们通过将函数图分解为其循环和树传入结构来解决问题，然后计算有多少对不可避免地相遇。 

1. 首先，我们使用标准的基于入度的剥离过程（类似卡恩拓扑去除）检测图中的所有循环。 永远不会被删除的节点属于循环。 这是有效的，因为在函数图中，当从叶子向内剥离时，每个非循环节点最终其入度减小到零。 
2. 我们为每个周期分配一个唯一的标识符并记录其长度。 循环中的每个节点都会获得沿该循环的位置索引。 该索引稍后将代表其周期性状态。 
3. 对于不在循环中的每个节点，我们计算它到它最终到达的循环的距离并记录它进入哪个循环。 这可以通过在循环去除后以逆拓扑顺序处理节点来完成。 
4. 现在我们按周期对节点进行分组。 在每个循环组内，我们考虑循环中的节点以及馈入其中的树中的节点。 重要的观察是不同周期中的节点永远不会发生碰撞，因为它们的轨迹永远不相交。 
5. 对于每个循环组，我们计算有多少对节点永远不会相遇。 在单循环系统中，如果两个节点的最终位置在各自的进入时间之后对齐，则两个节点会发生碰撞。 我们观察到碰撞将节点划分为由其最终循环阶段确定的等价类，而不是模拟时间。 
6. 对于每个周期，我们计算在考虑了它们的距离到周期偏移以周期长度为模之后有多少节点映射到每个周期位置。 共享相同有效相类的节点保证最终会面。 
7. 对于一个周期的大小$k$，如果一个类有大小$s$， 然后$\binom{s}{2}$该类中的对是冲突对。 我们从组件内的总对中减去这些。 
8. 对所有组件求和得出总碰撞对。 答案是总对减去碰撞对。 

### 为什么它有效

 每个节点最终都恰好进入一个有向循环并且永远不会离开它。 进入后，其位置以等于周期长度的固定周期周期性演变。 当且仅当两个节点的状态在某个时刻重合时，两个节点才会发生碰撞，这要求它们属于同一循环分量并具有一致的相位对齐。 按有效周期阶段进行分组可以准确捕获哪些节点及时同步。 由于同步在每个阶段类内是传递的，因此对每个类内的组合进行计数会考虑所有且仅冲突对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    nxt = [0] * n
    indeg = [0] * n

    for i in range(n):
        v = int(input()) - 1
        nxt[i] = v
        indeg[v] += 1

    from collections import deque
    q = deque(i for i in range(n) if indeg[i] == 0)
    removed = [False] * n

    while q:
        u = q.popleft()
        removed[u] = True
        v = nxt[u]
        indeg[v] -= 1
        if indeg[v] == 0:
            q.append(v)

    cycle_id = [-1] * n
    pos = [-1] * n
    cid = 0

    for i in range(n):
        if not removed[i] and cycle_id[i] == -1:
            cur = i
            cycle_nodes = []
            while cycle_id[cur] == -1:
                cycle_id[cur] = cid
                cycle_nodes.append(cur)
                cur = nxt[cur]

            for j, node in enumerate(cycle_nodes):
                pos[node] = j
            cid += 1

    dist = [0] * n
    order = []

    indeg2 = [0] * n
    for i in range(n):
        indeg2[nxt[i]] += 1

    q = deque()
    for i in range(n):
        if indeg[i] == 0:
            q.append(i)

    while q:
        u = q.popleft()
        order.append(u)
        v = nxt[u]
        indeg[v] -= 1
        if indeg[v] == 0:
            q.append(v)

    for u in reversed(order):
        v = nxt[u]
        if cycle_id[u] == -1:
            dist[u] = dist[v] + 1
            cycle_id[u] = cycle_id[v]
        else:
            dist[u] = 0

    from collections import defaultdict

    groups = defaultdict(list)

    for i in range(n):
        if pos[i] != -1:
            key = (cycle_id[i], pos[i])
        else:
            key = (cycle_id[i], (dist[i] + pos[nxt[i]]) % 1)
        groups[key].append(i)

    def C2(x):
        return x * (x - 1) // 2

    total = C2(n)
    bad = 0

    for g in groups.values():
        bad += C2(len(g))

    print((total - bad) % MOD)

if __name__ == "__main__":
    solve()
```代码的第一部分使用入度剥离删除循环外部的所有节点。 这隔离了图的循环核心。 第二遍识别循环组件并在每个循环内分配索引。 之后，我们将距离从非循环节点传播回循环，有效地测量每个节点距离进入周期性行为有多远。 

分组步骤是我们尝试将节点分类为保证冲突的等价类的地方。 每个类都旨在表示最终同步到相同重复状态的节点。 最后的减法将删除每个类中的所有对。 

关键的微妙之处在于循环结构主导行为，并且所有树路径都崩溃为循环阶段，使得分组足以计算不可避免的冲突。 

## 工作示例

 ### 示例 1

 输入：```
3
2
1
1
```我们首先跟踪循环检测。 节点 1 转到 2，节点 2 转到 1，形成长度为 2 的循环。节点 3 转到 1，因此它是进入循环的同一组件的一部分。 

| 节点| 下一页 | 循环中| 周期 ID | 职位| 距离 |
 | ---| ---| ---| ---| ---| ---|
 | 1 | 2 | 是的 | 0 | 0 | 0 |
 | 2 | 1 | 是的 | 0 | 1 | 0 |
 | 3 | 1 | 没有| 0 | - | 1 |

 所有节点最终都会进入同一个循环。 节点 3 与周期同步，但有延迟，仅产生部分对齐约束。 计算安全对的结果是 2。 

这证实了树节点不会自动产生冲突，除非时序对齐匹配。 

### 示例 2

 输入：```

2
1
1
5
4
4
```我们有两个循环：一个涉及 1 和 2，另一个涉及 4 和 5。节点 3 和 6 馈入这些结构。 

| 节点| 循环 | 进入| 笔记|
 | ---| ---| ---| ---|
 | 1 | 一个 | 循环| 循环节点|

 | 3 | 一个 | 通过 1 | 树|

这个例子表明，分解成独立的循环组件是至关重要的，因为相互作用不交叉组件。

 ## 边缘情况

 一种边缘情况是图是单个循环。 在这种情况下，每个节点都会立即到达循环，并且所有节点都是对称的。 该算法将所有节点视为属于同一循环类，并且所有对在单个组内一致计数。 

另一个边缘情况是长链进入循环。 这里节点到循环的距离不同，如果分组忽略时间偏移，则会错误地合并或拆分碰撞类。 距离传播确保节点被区分，直到它们的周期阶段完全确定行为。 

第三种边缘情况是多个不相交的循环。 由于循环之间没有路径交叉，不同循环中的节点永远不会相遇。 循环分解步骤强制执行这种分离，确保组件之间不会发生无效的冲突计数。
