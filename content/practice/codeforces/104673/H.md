 ## 解决方案
 ## 问题理解

 我们正在制作一张由无向道路连接的村庄图。 我们控制的一个机器人从村庄S出发，想要到达目标村庄F。它只在晚上移动，每天晚上它要么穿过一条路到达邻近的村庄，要么留在原地。 

第二个机器人从一个已知的村庄 T 开始。我们无法控制它。 每天晚上，它必须沿着一条路精确地移动到邻近的村庄。 随着时间的推移，它的位置是完全不可预测的，只是它总是遵循长度等于经过的夜晚数的有效行走。 

关键的限制是，如果两个机器人在同一天位于同一个村庄，系统就会失败。 这意味着，在每天晚上的运动之后，当两个机器人在白天“休息”时，它们绝不能占据同一个节点。 夜间跨越相反方向的边缘时相遇是无害的； 只有在同一时间步长处于同一顶点才重要。 

我们需要找到我们的机器人到达 F 所需的最少夜晚数，同时保证无论第二个机器人如何移动，这种碰撞都不会发生。 如果不存在这样的安全策略，答案是不可能的。 

约束很大，最多有 100,000 个节点和 200,000 条边。 这排除了任何探索所有路径或以指数方式联合模拟两个机器人的方法。 解决方案在图的大小上应接近线性或近线性，通常为 O(N + M)。 

一个微妙的困难是第二个机器人是对抗性的。 即使它没有选择特定的路径，我们也必须假设它总是试图使碰撞成为可能。 这意味着我们需要考虑它在每个时间步可能占据的所有顶点。 

一个天真的错误是认为我们只需要避免从 T 开始的最短路径距离随着时间的推移而增加。 例如，在一个循环中，第二个机器人可以延迟到达顶点或重新访问节点，这意味着它可以出现在比单个最短路径层建议的更多位置。 

当认为避免 T 的 BFS 层就足够时，就会出现另一种故障模式。 考虑一个三角形图，其中 T 是一个顶点。 经过两步后，对手可以处于与最短路径相同奇偶性的任何顶点，这意味着不安全区域随时间交替，并且不是简单的“生长球”意义上的单调。 

## 方法

 直接的暴力策略将模拟两个机器人随时间的所有可能状态。 在每个时间步，我们都会跟踪对手的每个可能的位置以及我们的机器人的所有可到达的位置。 状态空间成为节点和时间的乘积，并且转换在两侧都有大量分支。 即使忽略时间，配对位置也已经给出了 O(N²) 的可能性，加上时间使其变得无限。 这很快就变得不可行。 

关键的观察是我们实际上并不需要第二个机器人的确切位置。 我们只需要知道它是否可能在给定时间位于给定顶点。 

这将问题简化为对手方的可达性问题。 根据 T，我们计算最短距离 d(v)。 如果一个顶点距离 d(v)，那么在时间 t，如果对手能够完成以 v 结束的恰好 t 个步骤的步行，那么对手就可以到达 v。因为它可以重新访问边缘，所以唯一的限制是奇偶性：一旦它可以在 d(v) 步中到达 v，它也可以在 d(v) + 2、d(v) + 4 中到达它，依此类推。 

因此每个顶点在特定时间变得不安全：所有 t 使得 t ≥ d(v) 并且 t 与 d(v) 具有相同的奇偶性。 这给出了一个干净的时间相关的禁止集。

现在我们的机器人执行最短路径搜索，但时间作为状态的一部分。 在时间 t，仅当 v 在时间 t 不是不安全时，位于顶点 v 才有效。 由于时间每晚恰好增加 1 个，因此我们在（节点、时间奇偶校验）上运行 BFS。 奇偶校验就足够了，因为安全性仅取决于 t 是否符合相对于 d(v) 的奇偶校验条件，以及 t 是否超过阈值。 

这将问题转化为每个节点两层的分层图搜索，跟踪偶数和奇数时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力联合模拟 | 指数| 指数| 太慢了|
 | 具有对手可达性的时间奇偶性 BFS | O(N + M) | O(N) | 已接受 |

 ## 算法演练

 1. 从 T 运行 BFS 来计算每个顶点的最短距离 d(v)。 这表示对手首次到达每个顶点的最短时间。 
2.对于每个顶点v，确定它第一次变得不安全的时间。 如果 d(v) 是偶数，则在 d(v)、d(v)+2、d(v)+4 等时刻是不安全的。 如果 d(v) 为奇数，则相同的模式在奇数次成立。 这种周期性结构是我们需要从对手那里获得的唯一信息。 
3. 定义一个状态为 (u, p)，其中 u 是一个顶点，p 是到达该顶点的时间奇偶性。 奇偶校验就足够了，因为每次移动时间都会确定性地增加 1。 
4. 从(S,0)开始初始化BFS。 初始时间为零。 
5. 从状态 (u, t) 开始，尝试所有向邻居 v 的移动以及留在 u 的选项。 每次移动都会将时间增加到 t+1。 
6. 在接受移动到 (v, t+1) 之前，检查 v 在时间 t+1 是否安全。 这意味着 t+1 < d(v) 或 (t+1 - d(v)) 是奇数。 
7. 如果该状态是安全的且之前未被访问过，则将其推入BFS队列。 
8. 我们第一次在任何奇偶状态下达到 F 时都会给出最少的住宿天数。 

正确性依赖于 BFS 按时间递增顺序探索状态这一事实。 一旦访问了状态 (v, p)，任何稍后到达相同的 (v, p) 只会增加时间，而不能改善安全条件，因为不安全条件单调依赖于固定奇偶校验类内的时间。 

## 为什么它有效

 对手的移动约束减少到每个顶点的确定性时间可达集。 我们不是跟踪其确切位置，而是对顶点在给定时间奇偶性内变得永久危险的时间进行分类。 我们的 BFS 避免了这些禁止的时间顶点对。 因为我们的机器人的每个有效策略都对应于这个时间扩展图中的一条路径，并且 BFS 找到了最短的此类路径，所以首先到达 F 是所有安全策略中的最佳策略。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    N, M, F, T, S = map(int, input().split())
    g = [[] for _ in range(N)]
    for _ in range(M):
        a, b = map(int, input().split())
        g[a].append(b)
        g[b].append(a)

    INF = 10**18
    dist = [INF] * N
    q = deque([T])
    dist[T] = 0

    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] == INF:
                dist[v] = dist[u] + 1
                q.append(v)

    def unsafe(v, t):
        d = dist[v]
        if d == INF:
            return False
        if t < d:
            return False
        return (t - d) % 2 == 0

    dq = deque()
    dq.append((S, 0))
    visited = [[False, False] for _ in range(N)]
    visited[S][0] = True

    t = 0
    while dq:
        size = len(dq)
        for _ in range(size):
            u, p = dq.popleft()

            if u == F:
                print(t)
                return

            # stay
            nt = t + 1
            if not unsafe(u, nt):
                if not visited[u][nt % 2]:
                    visited[u][nt % 2] = True
                    dq.append((u, nt % 2))

            # move
            for v in g[u]:
                if not unsafe(v, nt):
                    if not visited[v][nt % 2]:
                        visited[v][nt % 2] = True
                        dq.append((v, nt % 2))

        t += 1

    print("death")

if __name__ == "__main__":
    solve()
```该解决方案将对手的行为分离到预处理 BFS 中，然后将主要任务视为具有时间相关有效性的受约束最短路径。 实现中唯一微妙的一点是访问是通过顶点和时间奇偶性来跟踪的，而不是通过绝对时间来跟踪的，而安全检查仍然使用完整的时间值。 这种组合可以在不爆炸状态空间的情况下实现正确性。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(N + M) | T 中的一个 BFS 加上时间奇偶校验状态上的一个 BFS，每个边缘处理常数次 |

 这些约束允许线性图遍历，因此即使对于 200,000 条边，这也能轻松地满足限制。

 ## 边缘情况

 当目的地已经是起始节点时，就会出现一种边缘情况。 该算法在 (S, 0) 处初始化 BFS，由于 S 等于 F，因此它立即在零时刻终止，没有任何转换，这符合不需要移动的要求。 

当对手从相对于图的某些部分断开的组件开始时，就会出现另一种情况。 在这种情况下，许多顶点到 T 的距离是无限的，因此永远不会不安全。 BFS 正确地将它们视为始终安全，因此唯一的约束成为从 S 到 F 的结构可达性。 

循环图中出现了一种更微妙的情况，其中奇偶校验交替允许对手重新进入以前无法到达的状态。 基于距离的不安全函数已经通过允许重复的安全窗口始终匹配奇偶校验来捕获这一点，确保 BFS 永远不会错误地假设安全在单个时间步长后变得永久。
