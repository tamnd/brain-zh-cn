 ## 解决方案
 ## 问题理解

 我们有一个非常大的矩形网格，大小为$W \times H$。 每个单元格最初未被访问。 单个起始单元$(X, Y)$在游戏开始前已被标记为已访问。 从那一刻起，两名玩家交替行动，从第一位玩家开始。 

移动包括获取割草机的当前位置并将其移动到与当前单元格共享一侧的相邻单元格，前提是之前尚未访问过目标单元格。 每次访问某个单元格时，它就会永久无法使用。 无法做出有效动作的玩家失败。 

尽管描述提到了“当前方块”，但该游戏实际上是在网格上构建自我回避行走：每次移动都会将一条路径延伸到一个新的未访问过的单元格，并且该路径永远不会重新访问顶点。 

关键的困难来自于约束。 两个尺寸都可以大到$10^9$，这排除了任何网格遍历、模拟或图形搜索。 任何解决方案都必须将问题简化为基于网格图的结构属性的恒定时间检查，而不是显式探索。 

当网格极小时，会出现微妙的边缘情况。 为了$1 \times 1$，唯一的单元格在开始时就已经被访问过，因此不可能移动，第一个玩家立即失败。 在稍大的网格中，人们很容易对起始位置进行局部推理，但这种直觉会被打破，因为游戏并不依赖于局部瓶颈。 相反，网格的全局结构占主导地位。 

## 方法

 直接模拟将跟踪访问过的单元格并尝试所有可能的移动。 从每个状态开始，游戏最多会分支到四个方向，并且路径会动态演变。 这很快就变成了图上的最长路径式游戏，即使对于中等网格，这在计算上也是不可行的，更不用说$10^9 \times 10^9$。 

真正的简化来自于认识到网格是一个具有强哈密顿特性的大型连通二分图。 众所周知，矩形网格允许哈密顿路径在非常一般的条件下恰好覆盖每个单元一次。 即使删除一个任意起始单元后，剩余的图仍然是连接的，并且仍然支持访问所有剩余顶点的哈密顿路径。 

这完全改变了观点。 我们不是问玩家如何选择动作，而是问游戏在最佳玩法下持续多长时间。 由于玩家被迫移动到之前未访问过的单元格，因此每次移动都会消耗一个单元格，并且如果玩家可以遍历所有可到达的单元格而不会过早陷入困境，则游戏长度将固定为剩余单元格的数量。 

因此，结果简化为一个简单的奇偶校验问题。 如果可用的步数为奇数，则第一个玩家完成最后一步并获胜。 否则，第二个玩家获胜。 

除了从网格中删除一个顶点之外，起始单元格是无关紧要的。

 | ---| ---| ---| ---|
 | 暴力破解游戏模拟| 指数| O(宽·高) | 太慢了|

 ## 算法演练

 1. 计算网格中的单元总数：$W \times H$。 

这代表割草机可能到达的所有可能位置。 
2. 减去一个单元格以说明游戏开始前已经访问过的起始位置。 

该游戏在剩余的未访问单元上有效地进行。 
3. 判断剩余移动次数是否为$W \times H - 1$，是奇数还是偶数。 

这种势均力敌决定了在最佳发挥下谁能走最后一步。 
4. 如果剩余格数为奇数，则输出“Win”，否则输出“Lose”。 

关键的推理步骤是，最佳游戏允许玩家始终延长路径，直到消耗掉所有剩余的单元格，而不会过早地将自己阻塞在这种大小的网格中。 

### 为什么它有效

 删除单个单元后网格仍保持连接，并且矩形网格允许覆盖所有顶点的哈密顿路径。 这意味着存在一系列有效的移动，它们恰好访问每个剩余单元格一次。 由于两个玩家都被迫沿着这个路径结构移动而不能跳过或重新访问，所以游戏长度固定为可用单元格的数量。 因此，获胜者完全取决于该长度是奇数还是偶数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

W, H, X, Y = map(int, input().split())

remaining = W * H - 1

if remaining % 2 == 1:
    print("Win")
else:
    print("Lose")
```整个解决方案将游戏分解为单个算术观察。 坐标$(X, Y)$不会以任何有意义的方式影响连接或奇偶校验，因此它们会被读取但不会被使用。 

唯一微妙的实现细节是避免不必要的数据结构。 自从$W$和$H$如果很大，则应直接使用 Python 整数计算乘积，而无需担心溢出。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    W, H, X, Y = map(int, input().split())
    remaining = W * H - 1
    return "Win" if remaining % 2 == 1 else "Lose"

# provided samples
assert run("6 1 4 1") == "Win"

 ## 边缘情况

 唯一真正堕落的情况是$1 \times 1$网格。 起始单元已被访问，因此从一开始就不存在任何移动，第一个玩家立即失败。 该公式自然地处理了这个问题：$1 \cdot 1 - 1 = 0$，这是偶数，产生“Lose”。 

第二种微妙的情况是当一维为 1 时。网格变成一条线，但相同的奇偶校验逻辑仍然适用，因为路径仍然完全可遍历。 尽管直觉表明“分裂”，但分裂并没有发生； 网格只是一个路径图，剩余长度在最优决策下是完全可玩的。 

在所有情况下，奇偶校验的减少避免了对矩形网格的连通性和哈密顿性之外的几何进行推理的需要。
