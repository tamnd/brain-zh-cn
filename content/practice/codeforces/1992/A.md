 ## 解决方案
 ## 问题理解

 我们得到三个小整数，代表对产品有贡献的三个因素的初始大小。 我们关心的最终数量是这三个数字的乘积，并且我们最多可以通过执行五次操作来改进它。 每个操作都将三个数字中的一个恰好加一。 

目标是以最大化最终产品的方式在三个变量之间分配最多五个单位增量。 由于每个值都很小，因此每次增量都会对产品产生明显的影响，但效果取决于我们选择增加哪个变量。 

限制非常严格：三个数字中的每一个都最多为 10，而我们只有 5 次操作。 这立即排除了对复杂数据结构或优化技术的任何需要。 甚至枚举五个增量的所有可能分布也是可行的，因为将 5 个相同增量拆分为 3 个变量的方法数量很少。 

当所有增量都集中在一个变量而不是分布在多个变量上时，就会出现一种微妙的边缘情况。 例如，从 (10, 1, 10) 开始，将所有 5 个增量放入中间，得到 10 × 6 × 10 = 600，而以不同方式分散它们会得到严格更小的乘积，因为一旦中间因子不再很小，它就会以乘法方式占主导地位。 总是增加当前最小值的天真的贪婪策略在这里可能会失败，因为它通过乘法忽略了变量之间的相互作用。 

另一种边缘情况是当值已经平衡时，例如 (3, 3, 3)。 在这里，均匀分配增量往往比集中增量效果更好，并且这种平衡无法通过纯粹的局部决策规则来捕获。 

## 方法

 暴力方法会尝试一切可能的方法为三个变量分配最多五个增量。 每个增量可以到达三个位置之一，因此我们有效地选择长度最多为 5 的序列，其中每个位置有三个选择。 这导致最多 3^5 = 243 个序列用于恰好五次操作，如果我们考虑“提前停止”选项，则数量甚至更少。 对于每个序列，我们计算结果的乘积。 

这种方法是正确的，因为它明确地检查每个有效的操作序列。 问题不在于正确性，而在于结构：它通过不同的操作顺序多次探索相同的状态。 尽管 243 很小，但我们可以进一步简化，注意增量的顺序并不重要，只关心每个变量增量的次数。 

这一观察结果将问题简化为将最多五个相同的增量分配到三个桶中。 每个分布都可以用三个非负整数 (x, y, z) 表示，使得 x + y + z ≤ 5。这样的三元组的数量足够小，可以直接枚举，并且对于每个三元组，我们计算 (a + x)(b + y)(c + z)。

 ## 算法演练

 1. 迭代 x 从 0 到 5 的所有可能值，表示添加到第一个数字的增量。 
2. 对于每个 x，迭代 y 从 0 到 5 − x 的所有可能值，表示添加到第二个数字的增量。 这可确保我们的操作总数不会超过 5 次。 
3. 计算 z 作为剩余运算：z = 5 − x − y。 
4. 计算乘积 (a + x) × (b + y) × (c + z)。 
5. 跟踪所有有效三元组 (x, y, z) 的最大乘积。 
6. 检查所有配置后输出最大值。

关键思想是每个有效的操作序列都精确对应一个三元组 (x, y, z)。 这消除了排序冗余，同时保留了完整性。 

### 为什么它有效

 乘积的值仅取决于每个变量递增的次数，而不取决于递增的顺序。 由于每个操作独立地将一个变量恰好加 1，因此任何五个操作的有效序列都相当于三个变量之间的计数分布。 穷尽所有这些分布可以保证不会错过任何可能的最终状态，并且由于我们计算每个分布的乘积，因此找到的最大值是全局最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c = map(int, input().split())
    
    best = 0
    
    for x in range(6):
        for y in range(6 - x):
            z = 5 - x - y
            val = (a + x) * (b + y) * (c + z)
            best = max(best, val)
    
    print(best)
```该方案直接实现了所有有效增量分布的枚举。 嵌套循环强制执行总增量不超过五的约束。 将 z 计算为余数可确保每个有效分配都被精确计算一次。 

该乘积以整数算术计算，没有 Python 中溢出的风险。 通过跟踪最大值来贪婪地更新答案。

 ## 边缘情况

 一个关键的边缘情况是当一个变量开始时比其他变量小得多。 对于输入 (10, 1, 10)，总是递增最小变量的贪婪策略可能看起来是正确的，但实际上它在这里仍然是最优的，只是因为约束太小了。 枚举方法可以自然地处理它。 

追踪 (10, 1, 10)，算法评估 5 个增量的所有分布。 一种关键配置是 x = 0、y = 5、z = 0，产生 600，它主导所有其他分配。 该算法可以正确识别这一点，而无需推理边际收益。 

另一个边缘情况是所有值都相等。 对于 (3, 3, 3)，对称性保证许多分布平局或接近平局。 该算法仍然检查所有组合并返回正确的最大值，而不依赖于对称参数。 

最后，当一个变量从 1 开始时，任何早期提升它的分配都可以占主导地位，但最佳分割取决于与其他两个变量的相互作用。 详尽的分布检查确保不会遗漏任何细微的不平衡。
