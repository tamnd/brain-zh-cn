 ## 解决方案
 ## 问题理解

 我们被要求计算从 1 到 _n_ 有多少数字**不能被给定整数集中的任何数字整除，称为命中指标。 每个指标都保证与其他指标互质，并且有 _k_ 个指标，每个指标最多 1000 个。从概念上讲，想象伊戈尔的英雄拥有力量_n_挥舞着属性编码在指标中的武器； 伤害对应于 1…_n_ 中“幸存”的数量可被这些指标中的任何一个整除。 

这些约束为我们提供了有关算法选择的直接线索。 _n_ 最大可达 10^13，这排除了任何单独检查每个数字的算法。 即使线性迭代也是不可能的，因为这需要 10^13 次操作。 _k_ 相对较小，最多 100，并且指标很小（≤1000），因此使用指标子集的组合技术是可行的。 

当 _n_ 小于任何指标时，就会出现不明显的边缘情况。 例如，如果 _n_ = 3 并且指标为 5、7、11，则没有一个数字可以被任何指标整除，因此答案为 3。假设至少有一个数字始终可以被每个指标整除的天真的方法在这里会失败。 另一个潜在的陷阱是计算子集组合中指标的乘积时整数溢出； 我们必须小心，因为有些产品可能会超过10^13。 

## 方法

 暴力方法很简单：迭代从 1 到 _n_ 的所有整数，对照所有 _k_ 个指标检查每个整数，并计算那些不能被其中任何一个整除的整数。 这可以正确工作，但需要 O(n * k) 次操作，在最坏的情况下可以达到 10^15。 这远远超出了可接受的限度。 

关键的观察结果是所有指标都是成对互质的。 这使我们能够使用**包含-排除原则**。 对于任何指标子集，我们可以计算有多少个数字可以被它们的乘积整除。 如果子集包含奇数个指标，我们将其贡献相加； 如果偶数，我们将其减去。 使用这个，我们只需要考虑 2^k 个子集，如果我们修剪乘积超过 _n_ 的子集，这对于 k ≤ 100 是可行的。 互质性确保任何子集的最小公倍数只是其元素的乘积，从而简化了计算。 

暴力破解之所以有效，是因为它能够正确地一一检查整除性，但对于大 _n_ 则失败。 包含-排除方法之所以有效，是因为互质保证了按乘积计算倍数可以准确捕获重叠，而不会重复计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * k) | O(1) | O(1) | 太慢了 |
 | 包容-排除| O(2^k)（按乘积 ≤ n 剪枝）| O(k) | 已接受 |

 ## 算法演练

 1. 读取整数_n_和_k_，然后读取指标列表_a_。 
2. 初始化变量`count_divisible`至 0； 它将存储可被至少一个指标整除的数字总数。 
3. 迭代指标的所有非空子集。 用 1 到 2^k - 1 之间的位掩码表示子集。 
4. 对于每个子集，计算其元素的乘积。 如果乘积超过 _n_，则跳过该子集，因为没有任何数字 ≤ _n_ 可以被它整除。 
5. 确定子集对的贡献`count_divisible`。 如果子集大小为奇数，则添加floor(n/product)； 如果偶数，则减去下限（n / 乘积）。 这就是包含-排除公式。 
6. 处理完所有子集后，答案为`n - count_divisible`，代表不能被任何指标整除的数字。 

保证正确性的不变量是包含-排除原理正确地计算可被至少一个元素整除的数字，当子集具有奇数基数时相加，当子集具有偶数时相减。 互质性确保乘积完全对应于最小公倍数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from itertools import combinations
from math import prod

def main():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    count_divisible = 0
    for mask in range(1, 1 << k):
        subset = []
        for i in range(k):
            if mask & (1 << i):
                subset.append(a[i])
        p = 1
        for x in subset:
            if p > n // x:
                p = n + 1
                break
            p *= x
        if p > n:
            continue
        if len(subset) % 2 == 1:
            count_divisible += n // p
        else:
            count_divisible -= n // p
    print(n - count_divisible)

if __name__ == "__main__":
    main()
```该解决方案通过检查仔细处理整数溢出`p > n // x`相乘之前。 这可以防止乘积超过 10^13。 位掩码的使用使我们能够有效地生成子集，并且奇/偶检查实现了包含-排除符号。 减法`n - count_divisible`最后给出了不受所有指标影响的准确数字。

 ## 边缘情况

 当_n_小于所有指标时，如`n=3`和指标`[5,7]`，包含-排除算法正确地跳过产品 > n 的子集。 每个子集乘积都超过 n，所以`count_divisible`仍为 0，结果为 3。 这表明当不存在倍数时，该算法不会错误地减去数字。 

当指标为 1 时，所有数字都是可整除的，因此算法正确地识别出每个包含 1 的子集都有助于`count_divisible`，导致剩余数字为零。 支票`p > n // x`防止在使用小指标处理大 n 时溢出，例如 n=10^13 和指标 1000。
