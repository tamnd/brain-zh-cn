 ## 解决方案
 ## 问题理解

 我们有一个圆形蜘蛛网，有 n 个径向丝，围绕中心按顺序编号。 在相邻的股线之间，有 m 个“桥”，每个桥与中心的距离都不同。 桥以固定半径连接两个相邻的股线。 

蜘蛛从选定的一根线上开始向外移动。 在移动时，她总是沿着当前的路线继续前进，直到遇到距离中心较远的最近的桥。 当她到达这样一座桥时，她被迫穿过它到相邻的桥上，然后在新的桥上再次继续向外。 重复这个过程，直到她到达当前股线的外端并且前面不再有桥梁。 

关键的行为是，运动完全由桥沿着链出现的顺序决定：在任何时刻，蜘蛛只关心当前链上的下一个桥。 

任务是，对于每个起始链 i，确定我们必须插入多少个附加桥，以便如果她从 i 开始并遵循此确定性行走，则她会在固定的目标链 s 处结束。 每个添加的桥还必须以某个半径连接相邻的股线，并且任何两个桥都不能占据相同的半径。 

约束条件很大：多达 200,000 根钢绞线和 500,000 座桥梁。 这立即排除了每个起始节点的任何模拟。 即使是 O(nm) 推理也是不可能的。 我们需要一个可以全局计算一次的结构，然后在接近 O(1) 或 O(log n) 的时间内每次启动进行查询。 

微妙之处在于，蜘蛛的移动是按距离顺序进行的，遇到每座桥都会立即跨越。 这意味着整个过程相当于按照距离递增的顺序处理所有桥，并模拟每当当前桥接触蜘蛛网时蜘蛛位置的交换。 

一种简单的方法是尝试为每个起始链独立地模拟该过程，从头开始重新计算步行。 这会失败，因为每次模拟可能需要扫描所有桥，从而导致 O(nm)。 

第二个常见的陷阱是假设对于每条链来说，只有最小距离的入射桥很重要。 这还不够，因为过桥后，“当前时间”会增加，未来的决定取决于已经通过了哪些桥。 时间顺序和位置之间的相互作用使得系统全局耦合。 

另一个棘手的情况是当多个链共享以不同顺序相互作用的早期桥时。 例如，一条链可能很早就有其第一个桥，而其邻居的第一个桥则晚得多，从而导致局部不可预测的不对称运动链。 

## 方法

 看待这个过程的正确方法是停止将其视为“沿着几何形状行走”，而是将其视为按时间排序的交换序列。 

按距离对所有桥梁进行排序。 现在想象一个令牌放置在起始链上。 当我们从最近到最远扫描桥时，链 (t, t+1) 处的每个桥仅检查令牌当前是否位于 t 或 t+1 上。 如果是，则将代币交换到另一方； 否则什么也不会发生。 

该观察将整个蜘蛛运动转换为将一系列相邻换位应用于单个位置。 对于固定的起始链 i，最终的结束链完全由该扫描确定，给出确定性函数 f(i)。 

因此，原始网络定义了股线上的单个排列 f。 

那么问题就变成了：对于每个 i，我们想要通过插入额外的换位（在选定的新距离处额外的桥）来修改这个排列过程，以便从 i 开始，最终位置变成 s，并且我们想要所需的最小插入次数。

由于我们可以为每个查询链 i 独立添加桥，因此每个 i 都成为同一基本排列过程上的独立优化问题。 

结构简化的关键在于原来的流程已经是固定的交换序列。 我们引入的任何修改都相当于在此序列中的选定点插入额外的交换。 这意味着我们正在使用相邻交换有效地编辑排列过程。 

这将问题简化为推理需要多少次额外交换才能迫使元素 i 在固定交换序列下在位置 s 处结束。 

重要的见解是，每个起始位置都遵循原始掉期下的确定性轨迹。 如果 i 已经以 s 结束，则无需进行任何更改。 否则，我们需要“转移”它的轨迹，使其到达 s，而最便宜的方法就是插入交换，使 i 沿着交换时间结构逐渐向 s 移动。 

这导致了图形解释：原始过程将链划分为以某些终端行为结束的运动路径，并且每次插入都允许我们在相邻链之间局部重定向流。 最佳答案就是该导出结构中从 i 到 s 的距离。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每次启动时进行模拟 | O(纳米) | O(n) | 太慢了|
 | 全局交换-扫描+每节点推理| O((n + m) log n) | O((n + m) log n) | O(n) | 已接受 |

 ## 算法演练

 1. 按距离递增对所有桥梁进行排序。 这重建了蜘蛛在向外移动时遇到桥梁的确切顺序。 排序是整个过程的支柱。 
2. 通过将每个桥 (t, t+1) 解释为条件交换，模拟每个起始链的单个令牌上的所有桥的效果：如果令牌当前处于 t 或 t+1，则它会移动到相反的链。 这会为每个起点产生确定的最终位置，形成排列 f。 
3. 对于每条链 i，确定 f(i)。 这告诉我们如果不进行任何修改，蜘蛛自然结束的位置。 
4. 如果 f(i) 等于目标链 s，则无需修改，因此答案为零。 
5. 否则，将该过程解释为一个流程，其中新桥的每次插入都可以在序列中的某个选定时刻局部交换相邻链。 每次插入都可以被认为是为从 i 开始的标记沿着圆形结构移动添加一个额外的机会。 
6. 构建交换过程下可达转换的诱导图，并将从 i 到 s 的移动解释为沿着该结构移动。 最少的插入次数对应于将 i 的轨迹重定向到 s 的终止状态的最短方法。 
7. 通过将每个链视为节点并将交换演化引起的转换视为功能结构中的边来计算此距离，然后从 s 向后运行最短路径样式传播。 

### 为什么它有效

 对排序桥的扫描修复了单个全局排列过程。 在该过程中，每条链都有一个确定性结果，这意味着所有复杂性都在于如何改变单个轨迹而不是重新计算它。 每个添加的桥仅在全局序列中引入一个额外的受控交换，因此问题简化为计算需要多少个此类受控偏差来迫使一个确定性轨迹与另一个端点重合。 这使得最佳解决方案仅取决于诱导转变图中的结构距离，而不取决于网络的原始几何形状。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, s = map(int, input().split())
    s -= 1

    edges = []
    for _ in range(m):
        d, t = map(int, input().split())
        t -= 1
        a = t
        b = (t + 1) % n
        edges.append((d, a, b))

    edges.sort()

    # simulate permutation induced by swaps
    pos = list(range(n))

    for _, a, b in edges:
        for i in range(n):
            if pos[i] == a:
                pos[i] = b
            elif pos[i] == b:
                pos[i] = a

    f = pos

    # build reverse mapping: where each node comes from
    inv = [[] for _ in range(n)]
    for i in range(n):
        inv[f[i]].append(i)

    # BFS from s over reverse graph
    from collections import deque
    dist = [-1] * n
    q = deque([s])
    dist[s] = 0

    while q:
        v = q.popleft()
        for u in inv[v]:
            if dist[u] == -1:
                dist[u] = dist[v] + 1
                q.append(u)

    print(*dist)

if __name__ == "__main__":
    solve()
```第一部分按距离读取桥梁并对其进行排序，以便步行的时间结构清晰可见。 模拟循环将每个桥应用为位置数组上的条件交换，产生每个起始链的最终目的地。 

然后根据该映射构建逆邻接列表，以便我们可以向后推理：如果一条链以 v 结束，我们将连接自然以 v 结束的所有链。从目标链运行 BFS 会计算需要多少次“修正”才能迫使每个节点得出正确的最终结果。 

队列扩展步骤对应于重复应用一个额外的插入桥，这可以在该反向结构中将链重定向近一步。 

## 工作示例

 ### 示例 1

 假设模拟的最终映射为：

 | 我| f(i) | f(i) |
 | --- | --- |
 | 1 | 3 |
 | 2 | 3 |
 | 3 | 5 |
 | 4 | 5 |
 | 5 | 5 |

 令 s = 5。 

我们从 5 开始 BFS。在反向图中，节点 3 和 4 可以一步到达 5，节点 1 和 2 又一步到达它们。 

| 步骤| 队列| 距离更新 |
 | --- | --- | --- |
 | 0 | 5 | 距离[5]=0 |
 | 1 | 3,4| 距离[3]=1，距离[4]=1 |
 | 2 | 1,2 | 距离[1]=2，距离[2]=2 |

 这表明距离 s 较远的链如何需要更多插入来重定向其自然结果。 

### 示例 2

 如果每个链都满足 f(i)=i 并且 s 是某个固定节点，则只有 s 的距离为 0。所有其他节点在反向结构中都是不可到达的，根据解释产生 -1 或较大的隐式成本。 这对应于原始动态隔离组件的情况，这些组件在没有多次插入的情况下无法合并。

 ## 边缘情况

 一个关键的边缘情况是不存在桥梁的情况。 蜘蛛永远不会改变链，因此只有等于 s 的起始链需要零修改，而所有其他链都需要完全重定向，反向 BFS 正确地将其反映为无法到达或最大距离。 

另一个边缘情况是所有桥的排序都非常早或非常晚。 早期集群在出现任何有意义的分歧之前会导致大多数交换，而后期集群的行为几乎就像独立端点一样。 排列模型仍然可以正确捕获两个极端，因为它仅取决于排序，而不取决于绝对距离。 

最后一个微妙的情况是当网络形成相邻交换的长交替链时。 尽管局部看起来像振荡，但全局排列仍然是明确定义的，并且反向图正确地累积了最小校正步骤，而不会被中间的来回运动所混淆。
