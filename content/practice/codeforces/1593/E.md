 ## 解决方案
 ## 问题理解

 我们得到一棵无根的树和重复的修剪过程。 在一次操作中，当前度数最多为 1 的每个顶点都会被同时删除。 这意味着所有叶子都会消失，并且在退化情况下，单个剩余顶点或单个边也会消失，因为它们的端点也被视为定义下的叶子。 

我们精确地重复此操作 k 次，并想知道在所有轮次同时去除叶子之后还剩下多少个顶点。 

从约束中观察到的关键是所有测试用例的顶点总数最多为 4 · 10^5。 这立即表明，任何对每个操作重复进行全图遍历的解决方案都太慢，因为每次测试 k 本身可能大到 2·10^5。 简单的模拟会重新计算叶子并逐层删除它们，每一步可能会接触到所有边缘，这在最坏的情况下会导致 O(nk) 行为。 

一个微妙的点是，该过程并不是对删除之外的边缘进行结构重新排列。 一旦顶点被移除，它就永远不会再回来，并且移除会从外部到中心分层进行。 

打破天真的思维的边缘情况是小树：

 k ≥ 1 的单个节点在第一次操作后应该立即变空，而不是停留在 1。 

双节点树在第一次操作后也会变空，因为两个端点同时都是叶子。 

一棵星形树很快倒塌：一次手术后，只剩下中心； 第二次之后，它就消失了。 

这些案例表明，该过程从根本上讲是关于到树“核心”的距离，而不仅仅是动态度更新。 

## 方法

 直接模拟会维护度数、重复收集所有当前叶子、删除它们并更新邻居。 这是正确的，因为每个操作都与定义完全匹配。 然而，重新计算叶集 k 次可能会退化为重复扫描图的大部分。 在长路径中，每轮仅删除两个顶点，因此该过程需要 O(n) 轮，并且每轮可能花费 O(n)，总体上为 O(n^2)。 

关键的结构见解是，一个顶点会一直存在，直到距离它 k 以内的所有顶点都被移除为止。 换句话说，每个顶点的“死亡时间”等于它距最近叶子的距离，以同时移除的层数来衡量。 

如果我们逆转这个过程，我们不会将叶子向外剥落，而是将叶子视为起点并向内传播。 所有叶子都在时间 1 死亡，它们的邻居在时间 2 死亡，依此类推。 这是一个多源 BFS，其中所有初始叶节点同时从距离 1 开始。 

因此，问题就变成了计算每个节点到最近叶子的距离。 之后，保留距离严格大于 k 的任何节点。 

这将问题从重复的结构更新转变为树上的单个 BFS。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 重复除叶模拟| 最坏情况 O(nk) | O(n) | 太慢了 |
 | 来自叶子的多源 BFS | O(n) | O(n) | 已接受 |

 ## 算法演练

1. 计算每个顶点的度数。 这是识别初始叶子所必需的，因为叶子正是度数 ≤ 1 的节点。 
2. 初始化一个包含所有叶子的队列，并为它们分配距离 1。这些代表在第一个操作中删除的顶点。 
3. 从此队列运行 BFS。 当处理节点 u 时，传播到尚未分配距离的邻居 v。 指定 dist[v] = dist[u] + 1。该模型表明，在删除外层中的所有顶点后，v 成为叶子。 
4. BFS完成后，每个顶点都有一个值dist[v]，代表它被移除的轮次。 
5. 计算有多少个顶点满足 dist[v] > k。 这些是在 k 个完全修剪操作中幸存下来的顶点。 

这样做的原因是 BFS 的每一层都精确对应一轮叶子去除。 最初，只有真叶是可移除的。 一旦它们被移除，一些内部顶点就会变成新的叶子，这正是下一个 BFS 边界。 由于每轮所有移除同时发生，BFS 正确地模拟了移除深度的并行扩展。 

不变的是，在 BFS 级别 d 开始时，所有 dist ≤ d 的顶点都已在 d 操作中被识别为可移除，并且所有剩余的未访问顶点都严格位于树核心的较深处。 这确保了正确性，因为树结构保证除了从叶子向内移动之外不存在替代的更短的移除路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    t = int(input())
    for _ in range(t):
        line = input().strip()
        while line == "":
            line = input().strip()
        n, k = map(int, line.split())

        adj = [[] for _ in range(n)]
        deg = [0] * n

        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            adj[u].append(v)
            adj[v].append(u)
            deg[u] += 1
            deg[v] += 1

        dist = [-1] * n
        q = deque()

        for i in range(n):
            if deg[i] <= 1:
                dist[i] = 1
                q.append(i)

        remaining = n

        while q:
            u = q.popleft()
            if dist[u] > k:
                continue
            remaining -= 1
            for v in adj[u]:
                if dist[v] == -1:
                    dist[v] = dist[u] + 1
                    q.append(v)

        print(remaining)

if __name__ == "__main__":
    solve()
```邻接表存储树结构，而度数标识初始叶子。 BFS 队列同时使用所有叶子进行播种，这确保第一层对应于第一个剪枝操作。 

距离数组对移除时间进行编码。 值 1 表示在第一次操作后删除，2 表示在第二次操作后删除，依此类推。 

剩余计数器跟踪 k 次操作后仍有多少顶点未删除。 仅当我们处理 BFS 内的节点直至时间 k 时，我们才会递减它。 

一个微妙的点是处理测试用例之间的空行； 输入格式包含它们，因此我们在读取 n 和 k 之前显式跳过空行。 

## 工作示例

 我们追踪一个小路径树：1-2-3-4。 

最初，叶子是 1 和 4。 

| 步骤| 队列| 分布作业 | 删除 |
 | ---| ---| ---| ---|
 | 初始化| [1,4]| 1:1、4:1 | 0 |
 | 流行 1 | [4,2]| 2:2 | 1 |
 | 流行 4 | [2,3]| 3:2 | 2 |
 | 流行 2 | [3] | - | 3 |
 | 流行 3 | []| - | 4 |

 这里 dist 表明 1 和 4 在第 1 轮中死亡，2 和 3 在第 2 轮中死亡。如果 k = 1，则仅保留 2 个顶点。 

现在考虑一颗星，中心为 1，叶子为 2、3、4、5。 

| 步骤| 队列| 分布作业 | 删除 |
 | ---| ---| ---| ---|
 | 初始化| [2,3,4,5] | 所有叶子 dist=1 | 0 |
 | 流行叶| [1] | 1 得到 dist=2 | 4 |
 | 流行 1 | []| - | 5 |

 这证实了中心的存活时间比叶子长了整整一轮。 

这些痕迹表明 BFS 层与修剪轮次完全对应。

 ## 边缘情况

 单个顶点树显示了操作的退化行为。 BFS 将该顶点初始化为距离为 1 的叶子，并且由于 k ≥ 1，因此将其视为立即删除，产生输出 0。 

双顶点树是类似的：两个节点最初都是叶子，都接收距离 1，并且在第一次操作后没有留下任何顶点。 BFS 同时处理两者，确保端点之间没有不对称性。 

长链展示了该过程的分层性质。 两端的叶子从距离 1 开始，它们的邻居变为距离 2，依此类推，直到中心。 该算法可以正确分配不断增加的距离，而无需显式模拟每轮修剪。
