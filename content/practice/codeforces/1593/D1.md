 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 在每个测试用例中都有一个偶数长度的数组。 我们可以重复选择任意位置并减去一个固定的正整数$k$来自那个元素。 相同$k$用于所有操作，但每个操作仅影响一个选定的索引。 

在执行任意数量的此类减法之后（每个位置可能有不同的计数），数组将变得完全一致，这意味着每个元素都等于相同的最终值。 任务是确定最大可能的$k$这是可以实现的。 如果有效值没有上限$k$，我们必须输出$-1$。 

关键的隐藏结构是每个元素都按大小步长独立减少$k$。 因此，每个最终值都必须可以仅使用大小减量从原始值到达$k$，这立即意味着模块化约束：所有元素必须以相同的残差类模结尾$k$。 

限制非常小。 每个测试最多有 40 个数字，总输入大小最多为 100 个整数。 这意味着任何解决方案大约$O(n^2)$甚至$O(n^3)$每个测试都是完全安全的，我们可以自由计算成对差异或 gcd。 

当所有数字都相同时，会出现微妙的边缘情况。 在这种情况下，任何$k$有效是因为我们可以执行零操作，所以答案是无界的并且必须是$-1$。 另一个棘手的情况是当每个整数的模数都相等时，只有当所有值都相同时才会发生这种情况。 直接计算差异的 gcd 而不检查这种情况的简单方法会错误地输出 0 或某个无效值。 

## 方法

 直接的暴力想法是尝试所有可能的值$k$直到数组中的最大差异。 对于每位候选人$k$，我们将模拟是否可以仅使用递减将所有值转换为共同的最终值$k$。 对于固定的$k$，这意味着检查所有元素是否模全等$k$，这可以在$O(n)$。 自从$k$可以大到$10^6$，这给出了最坏情况的复杂度约为$10^6 \cdot n$，这已经是临界点，但单独来看仍然可以接受。 然而，这是不必要的并且在概念上是浪费的。 

关键的观察是该操作保留了模余数$k$。 如果我们希望所有数字在减去倍数后变得相等$k$，那么所有原始数字必须相差$k$。 这意味着$k$必须除掉所有差异$a_i - a_j$。 所以有效的$k$值恰好是所有成对差异的 gcd 的正除数。 

这减少了计算数组差异上的单个 gcd 的问题。 一旦我们计算出 gcd，该值就是可能的最大值$k$。 唯一的例外是当所有元素都相同时，在这种情况下所有差异为零且 gcd 为零，这意味着$k$是无界的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解 k |$O(n \cdot \max a)$|$O(1)$| 太慢/不必要|
 | 差异的 GCD |$O(n^2)$|$O(1)$| 已接受 |

 ## 算法演练

 1.固定数组的一个元素作为参考点，通常$a_0$。 目标是了解所有其他值如何通过允许的操作与其相关。 
2. 计算绝对差异$|a_i - a_0|$为所有人$i$。 这些差异表示每个元素距共同目标值的距离。 
3. 计算所有这些差异的 gcd。 每个差异都约束有效$k$来划分它，因此累积 gcd 会同时捕获所有约束。 
4. 如果处理完所有元素后gcd为零，则意味着所有值都相同。 在这种情况下，任何积极的$k$有效，因为不需要实际更改，因此输出$-1$。 
5. 否则，输出计算出的 gcd 作为最大有效值$k$，因为任何较大的值都无法除以至少一个差值。 

### 为什么它有效

 每次运算减去$k$来自单个元素，它保留每个值模$k$。 因此，所有元素必须全等模$k$在最后。 只有当所有初始元素都已经对模全等时，这才有可能$k$，这相当于说每个差异$a_i - a_j$可以整除$k$。 所有这些差异的gcd是满足这个条件的最大整数，因此它正是最大可行$k$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from math import gcd

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        base = a[0]
        g = 0
        
        for x in a[1:]:
            g = gcd(g, abs(x - base))
        
        if g == 0:
            print(-1)
        else:
            print(g)

if __name__ == "__main__":
    solve()
```该解决方案将所有值锚定到第一个元素并累积绝对差的 gcd。 使用绝对值可以避免符号问题，因为整除性是对称的。 将 gcd 初始化为零可确保第一个差值正确地播种值。 

关键的实现细节是处理所有平等的情况。 当每个元素都等于底数时，所有差异都为零，并且 gcd 保持为零，从而触发正确的$-1$输出。

 ## 边缘情况

 当所有元素相同时，每个差异都为零，并且 gcd 计算永远不会从其初始值增加。 算法正确地保持了$g = 0$并返回$-1$，匹配任何一个事实$k$有效，因为不需要任何操作。 

对于这样的输入：```
4
5 5 5 5
```循环只计算零，所以$g$保持为 0，输出为$-1$。 

当值形成严格的算术级数时，例如：```
4
10 14 18 22
```与基数的差异是$0, 4, 8, 12$，并且 gcd 稳定在 4。任何选择的尝试$k > 4$失败是因为它没有除掉所有间隙，因此算法正确输出 4。
