 ## 解决方案
 ## 问题理解

 我们得到一个仅由左括号和右括号组成的字符串。 任务是确定该序列是否平衡，这意味着它可以代表数学表达式中括号的正确排列。 换句话说，每个左括号必须有一个匹配的右括号，并且括号必须正确嵌套。 例如，“(())()”是平衡的，因为每个“(”都以正确的顺序结束，而“(()”则不是，因为一个左括号保持不匹配，而“)(”则不是，因为右括号出现在任何匹配的左括号之前。

 输入字符串长度保证在 1 到 100 个字符之间。 这个小的上限意味着任何具有线性时间复杂度或更好的算法都是可以接受的。 由于限制较低，二次或更复杂的解决方案也可以运行得足够快，但简单和清晰是首选。 要注意的边缘情况包括以右括号开头的序列、以左括号结尾的序列、中间具有不匹配括号的序列以及完全由一种类型的括号组成的序列。 例如，字符串“)”应返回“NO”，因为如果没有前面的左括号，则无法出现右括号。 同样，“(((”应该返回“NO”，因为额外的左括号仍然不匹配。

 ## 方法

 暴力方法会尝试检查每个可能的子字符串，看看它是否形成有效的括号序列。 这涉及递归或迭代地将每个左括号与右括号配对并验证所有嵌套序列。 虽然正确，但这种方法具有指数时间复杂度，在最坏的情况下为 O(2^n)，并且在考虑到约束的情况下是不必要的。 即使对于长度为 20 或更长的字符串，随着检查数量的爆炸性增长，它显然也变得过大了。 

最佳方法利用简单的计数机制，使用单个整数作为余额计数器。 我们从左到右迭代字符串，增加每个左括号的计数器并减少每个右括号的计数器。 如果计数器变为负数，则表明出现了右括号而没有匹配的左括号，因此该序列立即无效。 处理整个字符串后，仅当计数器为零时序列才是平衡的，这意味着所有左括号都已与右括号匹配。 这种方法适用于 O(n) 时间和 O(1) 空间，因为我们只需要一个整数来维持平衡。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将计数器变量初始化为零。 当我们扫描序列时，该计数器将跟踪不匹配的左括号的净数量。 
2. 迭代字符串中的每个字符。 如果字符是左括号“(”，则增加计数器，因为还有一个不匹配的左括号。如果字符是右括号“)”，则减少计数器，因为已经匹配了一个不匹配的左括号。 
3. 如果在迭代期间的任何时候计数器变为负值，则立即打印“NO”并终止。 这表明右括号出现在相应的左括号之前，导致序列不平衡。 
4. 迭代整个字符串后，检查计数器。 如果它恰好为零，则打印“YES”，因为每个左括号都有一个匹配的右括号。 否则，打印“NO”，因为某些左括号仍然不匹配。

工作原理：计数器维护一个不变量，表示当前不匹配的左括号的数量。 负值表示无效状态，末尾的零值确认每个括号都已正确匹配和嵌套。 这个不变量保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
balance = 0

for char in s:
    if char == '(':
        balance += 1
    else:  # char == ')'
        balance -= 1
    if balance < 0:
        print("NO")
        sys.exit()

print("YES" if balance == 0 else "NO")
```该解决方案读取输入并删除尾随换行符。 余额计数器从零开始。 对于每个字符，我们根据括号类型调整计数器。 如果余额在任何时候变为负值，我们立即打印“NO”并终止，这表明序列无法平衡。 循环结束后，检查balance是否为零以确保所有括号都匹配。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    out = io.StringIO()
    with redirect_stdout(out):
        s = input().strip()
        balance = 0
        for char in s:
            if char == '(':
                balance += 1
            else:
                balance -= 1
            if balance < 0:
                print("NO")
                return
        print("YES" if balance == 0 else "NO")
    return out.getvalue().strip()

# Provided sample
assert run("(()(()))()") == "YES", "sample 1"

# Custom cases
assert run("(") == "NO", "single opening"
assert run(")") == "NO", "single closing"
assert run("()()()") == "YES", "repeated balanced pairs"
assert run("((()))") == "YES", "nested balanced"
assert run("((())") == "NO", "unmatched opening inside"
assert run("())(") == "NO", "early closing unmatched"

 ## 边缘情况

 对于以右括号开头的字符串，例如“)”，余额在步骤 1 立即变为负数，触发“NO”。 对于像“(((”这样以不匹配的开头结尾的字符串，余额在末尾为正，导致“NO”。在像“((()))”这样的完美嵌套序列中，计数器正确递增和递减，以零结束，确认“YES”。该算法正确处理所有提前终止和最终余额检查的情况。
