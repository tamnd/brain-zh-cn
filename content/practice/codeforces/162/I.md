 ## 解决方案
 ## 问题理解

 我们得到一个整数，必须决定它是否满足一个非常具体的素数属性。 

如果通过重复删除最左边的数字形成的每个后缀仍然是质数，则认为数字是可截断的。 例如，从`9137`，我们检查：`9137`,`137`,`37`,`7`四个数都是素数，所以答案是`"YES"`。 

该号码还必须不包含数字`0`。 像这样的值`103`即使某些后缀碰巧是质数，也会立即失败，因为定义明确禁止零。 

输入限制最多为`10^7`，它足够小，以至于直接素性测试是完全实用的。 对一个数字进行平方根素性检查大约需要`O(sqrt(n))`运营。 由于数量高达`10^7`最多有8位数字，我们只需要测试最多8个后缀。 即使在最坏的情况下，这也只是几万次算术运算，远远低于时间限制。 

棘手的部分不是性能，而是正确生成和验证每个后缀。 

一个容易犯的错误是忘记单位数字后缀也必须是素数。 

考虑：```
19
```后缀是：`19`,`9`虽然`19`本身就是素数，`9`不是，所以正确答案是`"NO"`。 

另一个常见的错误是忽略对零的限制。 

考虑：```
1013
```后缀是：`1013`,`13`,`3`它们都是素数，但这个数字仍然失败，因为它包含一个零。 正确答案是`"NO"`。 

第三个微妙的问题是治疗`1`作为素数。 

考虑：```
11
```后缀是：`11`,`1`自从`1`不是素数，答案一定是`"NO"`。 

使用不正确的素性测试的粗心实现可能会意外地接受它。 

## 方法

 最直接的解决方案是生成每个后缀并独立测试它是否是素数。 

假设数字表示为字符串。 我们可以重复删除第一个字符：```
9137
137
37
7
```对于每个值，我们都会运行素性测试。 如果任何后缀是合数，或者原始数字包含零，我们立即回答`"NO"`。 

这种蛮力想法已经足够快了，因为输入很小。 一个数字最多`10^7`最多有 8 个后缀。 每个素性测试最多花费`O(sqrt(n))`，这大约是`3162`最坏情况下的迭代。 即使将它们相乘也会产生非常小的运行时间。 

不需要筛选、预处理或概率素性测试。 这些约束的设计使得直接的试除能够轻松通过。 

关键的观察结果是后缀的数量非常少。 我们不会搜索许多候选数字，而是仅验证最多 8 个值的一个链。 这将问题简化为重复的素性检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 使用朴素除数检查最多 n 的暴力破解 | 每个后缀 | O(n) O(1) | O(1) | 概念上太慢|
 | 使用平方根素性测试进行最优 | O(d × sqrt(n)) | O(d × sqrt(n)) | O(1) | O(1) | 已接受 |

 这里，`d`是位数，最多 8 位。 

## 算法演练

 1. 将整数读取为字符串。 

使用字符串使后缀生成变得简单，并避免重复的数字提取逻辑。 
2. 检查字符串中是否包含数字`'0'`。 

如果是，立即打印`"NO"`因为可截断素数不允许包含零。 
3. 生成数字的每个后缀。 

对于索引`i`，后缀是`s[i:]`。 
4. 将每个后缀转换为整数并测试它是否是质数。 

一个数是素数，如果：

 - 至少是 2
 - 没有整数`2`到`sqrt(x)`划分它
 5. 如果任何后缀不是素数，则打印`"NO"`并停止。 
6. 如果所有后缀都是质数，则打印`"YES"`。 

### 为什么它有效

 该算法直接匹配可截断素数的定义。 

每个有效的后缀都会被检查一次。 在任何素性测试之前强制执行零限制。 素性测试正确拒绝`1`以及所有合数。 

既然答案是`"YES"`仅当所有后缀满足素数条件时，并且`"NO"`否则，算法是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_prime(x):
    if x < 2:
        return False

    d = 2
    while d * d <= x:
        if x % d == 0:
            return False
        d += 1

    return True

def solve():
    s = input().strip()

    if '0' in s:
        print("NO")
        return

    for i in range(len(s)):
        value = int(s[i:])

        if not is_prime(value):
            print("NO")
            return

    print("YES")

solve()
```该解决方案首先将数字读取为字符串，因为后缀自然以这种方式表示。 使用字符串切片可以避免手动算术删除前导数字。 

零检查首先发生，因为它是立即取消资格。 如果数字已经违反了定义，则没有理由花时间进行素性测试。 

这`is_prime`函数使用标准试除法直至平方根。 如果存在合数，则最多至少有一个因数`sqrt(x)`，因此没有必要检查超出该点的情况。 

条件`x < 2`很关键。 没有它，后缀`1`会被错误地视为素数。 

循环遍历每个后缀`s[i:]`。 一旦一个后缀失败，算法就会提前退出`"NO"`。 这使得实施简单而高效。
