 ## 解决方案
 ## 问题理解

 我们被要求取一个正整数并将其表示为素数的乘积，显示每个素数在因式分解中出现的次数。 例如，数字 245 可以表示为 5 乘以 7 两次，因此输出将为 5_7_7。 输入是单个整数 n，限制在 2 到 10000 之间。输出是按非降序排列的质因数，通过重复打印每个因数来反映多重性。 

n 的上限为 10000，允许我们考虑执行大约 10^6 次操作而不会达到时间限制的算法，因此简单的试除法是可行的。 然而，粗心的实现可能会在处理小边缘情况时出错，例如素数本身、素数的完全平方数或具有多个重复小因子的数。 例如，n = 13 应该输出 13，而不是产生空因式分解，而 n = 16 应该输出 2_2_2_2，而不仅仅是 2_8 或 4*4，因为我们只需要素因数。 

## 方法

 最直接的方法是从 2 迭代到 n，并重复将 n 除以任意能整除它的数。 每个分区对应于该因子的一次出现。 这种蛮力方法之所以有效，是因为我们最终会尝试直到 n 的每个整数，因此我们将捕获所有质因数。 对于 n = 10000，在最坏的情况下，这可能需要 10000 次迭代，并且每次迭代都可能涉及重复的除法，从而导致大约 O(n) 复杂度。 对于 n ≤ 10000，这是可以接受的，但我们可以做得更好。 

关键的见解是我们只需要检查 n 的平方根以内的除数。 任何大于 √n 的因子都必须与一个较小的因子配对，因此一旦我们除掉所有较小的因子，任何剩余的 n 本身都必须是素数。 这显着减少了迭代次数，将潜在的 O(n) 方法转变为 O(√n)，这要快得多，而且在 n ≤ 10000 的情况下实现起来仍然很简单。 

最佳方法将试除法结合到 √n 以及处理此后剩余的素数。 通过在找到后立即打印每个因子，我们自然地保持了所需的非递减顺序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(1) | O(1) | 接受 n ≤ 10000 |
 | 最优（√n试除）| O(√n) | O(√n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 从输入中读取整数 n。 这就是我们需要分解的数字。 
2、初始化变量d为2，代表当前候选除数。 我们从 2 开始，因为它是最小的素数。 
3. 当 d*d ≤ n 时，检查 n 是否能被 d 整除。 如果 n % d == 0，则打印 d（或存储它）并将 n 除以 d。 重复此步骤，直到 n 不再能被 d 整除。 这捕获了因式分解中 d 的所有幂。 
4. 将 d 加 1 并重复步骤 3。我们只需要向上到 √n，因为任何大于 √n 的因子都会有一个相应的已被除掉的较小因子。 
5. 循环结束后，如果 n > 1，则打印 n，因为它是剩余的素因数。 这处理 n 本身是素数或剩下一个大素数因子的情况。 

为什么有效：在每一步中，我们都会除掉可用的最小质因数。 不变量是 n 始终是尚未因式分解的剩余部分，并且所有小于 d 的素数都已被完全除掉。 这保证了我们不会错过任何因子，并且因子以非降序输出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
d = 2
factors = []

while d * d <= n:
    while n % d == 0:
        factors.append(str(d))
        n //= d
    d += 1

if n > 1:
    factors.append(str(n))

print('*'.join(factors))
```代码一步步遵循算法。 我们将因素列表维护为字符串，以便于与“*”连接。 内部 while 循环确保捕获每个素数的所有幂。 递增 d 确保我们测试直到 √n 的所有可能的除数。 最后，如果 n 大于 1，则追加 n 覆盖任何剩余的大于 √n 的素数。 一个常见的错误是忘记了最后的检查，这会为素数或具有大素因数的数字给出错误的结果。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())

    factors = []

    while d * d <= n:
        while n % d == 0:
            factors.append(str(d))
            n //= d
        d += 1

    if n > 1:

    return '*'.join(factors)

 ## 边缘情况

 对于像 13 这样的素数，循环检查除数到 √13 不会除掉任何东西。 循环之后，n 仍然是 13，因此附加它可以确保正确捕获素数。 对于像 16 这样的单个素数的幂，内部循环将 2 除四次，证明重复因子被正确计算。 对于同时具有小素数和大素数的数字（例如 10000），该算法可以正确捕获多次出现的 2 和 5，而不会丢失任何因数。 此方法避免了常见错误，例如在第一个因子后停止或忘记处理 √n 以上的剩余素数。
