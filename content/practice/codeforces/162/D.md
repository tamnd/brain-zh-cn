 ## 解决方案
 ## 问题理解

 我们得到一个包含可打印 ASCII 字符的字符串。 其中一些字符可能是来自的数字`'0'`到`'9'`。 任务是删除每个数字并按原始顺序打印剩余的字符。 

该声明提到字符在删除后向左移动，但该细节仅描述了字符串删除在概念上的工作原理。 我们实际上并不需要模拟重复删除。 最终结果只是非数字字符的子序列。 

输入的长度最多为100个字符，非常小。 即使是效率低下的方法也能在限制范围内轻松适应。 具有重复删除的二次解最多执行大约 10,000 个字符操作，这对于 3 秒的限制来说是微不足道的。 尽管如此，最干净的解决方案还是扫描一次字符串并直接构建答案。 

有几种边缘情况可能会悄然破坏粗心的实现。 

仅包含数字的字符串应生成空行。 

输入：```
12345
```正确输出：```

```有缺陷的实现可能会意外打印空格或无法打印换行符。 

数字可能出现在任何地方，而不仅仅是出现在末尾。 

输入：```
a1b2c3
```正确输出：```
abc
```仅删除第一位数字或提前停止的错误解决方案将在此处失败。 

该字符串可能包含非字母或数字的符号。 

输入：```
VK-Cup-2012!
```正确输出：```
VK-Cup-!
```连字符和感叹号必须保留。 仅删除数字字符。 

## 方法

 最直接的暴力破解想法是重复搜索一个数字并将其从字符串中删除。 由于字符串在 Python 中是不可变的，因此每次删除都会创建一个新字符串，因此删除一个字符会花费线性时间。 如果字符串有长度`n`，然后我们一位一位地删除数字，总的复杂度就变成了`O(n^2)`在最坏的情况下。 

对于这个问题，即使这种方法也足够快，因为`n ≤ 100`。 尽管如此，它还是做了不必要的工作。 每次删除都会向左移动字符，这意味着相同的字符可能会被复制多次。 

更好的观察是我们永远不需要物理删除字符。 最终答案完全由非数字字符组成。 我们可以从左到右扫描一次并将每个非数字字符附加到结果中，而不是修改原始字符串。 

这将工作量减少到对字符串的一次传递。 每个字符检查一次，最多附加一次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 已接受 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取输入字符串。 
2. 创建一个空列表来存储我们想要保留的字符。 
3. 逐个字符地遍历字符串。 
4. 对于每个字符，检查它是否是数字。 

在Python中，`ch.isdigit()`回报`True`对于数字字符和`False`否则。 
5. 如果该字符不是数字，则将其附加到结果列表中。 

我们保留所有字母、标点符号和符号不变。 
6. 处理整个字符串后，将收集到的字符连接成一个最终字符串。 
7. 打印结果。 

### 为什么它有效

 该算法对每个字符只处理一次。 在扫描过程中，它保留所有非数字字符的相对顺序，因为它们的附加顺序与输入中出现的顺序相同。 每个数字都会被跳过，因此输出中不会出现任何数字。 由于每个字符都被跳过或仅附加一次，因此生成的字符串正是删除了所有数字的原始字符串。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()

result = []

for ch in s:
    if not ch.isdigit():
        result.append(ch)

print("".join(result))
```程序首先读取输入字符串。 使用`strip()`从输入中删除尾随换行符。 

这`result`list 存储在过滤步骤中幸存下来的所有字符。 使用列表是有效的，因为附加字符是`O(1)`，而重复连接字符串会创建许多临时字符串。 

该循环独立地检查每个字符。 如果`isdigit()`回报`False`，该字符将添加到答案中。 数字被完全忽略。 

最后，`"".join(result)`将收集到的字符转换为最终的字符串。 如果每个字符都是数字，则列表保持为空并且`join`正确地产生一个空字符串。
