 ## 解决方案
 ## 问题理解

 我们需要计算`n`- 第一个五边形数。 五边形数形成由直接数学公式生成的序列：$$P_n = \frac{3n^2 - n}{2}$$输入包含单个整数`n`，输出是该公式针对序列中该位置的值。 

限制非常小。 自从`n`至多是`100`，即使是非常低效的解决方案也会立即运行。 在 3 秒的限制内，包含数百个操作的循环是微不足道的。 这也意味着我们不需要先进的优化技术、预计算或特殊的数据结构。 

唯一真正的风险是错误地执行公式。 一个常见的错误是误解运算符优先级或忘记除以`2`。 例如，如果有人写：```
3 * n * n - n / 2
```而不是：```
(3 * n * n - n) // 2
```结果变得错误，因为只有`n`除以`2`。 

考虑输入：```
2
```正确的计算是：$$\frac{3 \cdot 2^2 - 2}{2} = \frac{12 - 2}{2} = 5$$粗心的实施可能会产生`11`或者`10`取决于放错位置的括号。 

另一个微妙的问题是使用浮点除法。 五边形数始终是整数，因此整数运算是最干净的方法。 使用`/`在 Python 中创建一个浮点数，这是不必要的，并且可能会引入格式问题。 使用`//`将答案保留为整数。 

例如：```
1
```正确输出：```
1
```使用浮点除法可能会打印`1.0`，这将被拒绝。 

## 方法

 最直接的方法就是一一生成五边形数。 连续五边形数之间的差线性增长：$$P_n - P_{n-1} = 3n - 2$$开始于`1`，我们可以重复添加这些差异，直到达到`n`-th 值。 这是有效的，因为序列是增量定义的。 和`n ≤ 100`，这种方法很容易满足限制，因为它只执行大约一百次迭代。 

这种方法的缺点是它忽略了精确值已经由直接公式给出的事实。 尽管迭代方法在这里足够快，但它执行了不必要的工作。 

关键的观察是问题实际上提供了答案的封闭形式表达式。 由于公式直接计算`n`-th 值，我们可以在常数时间内立即评估它。 

暴力方法之所以有效，是因为序列很短，但公式让我们可以跳过所有中间值并直接跳转到答案。

### 为什么它有效

 五边形数的公式在数学上定义为：$$P_n = \frac{3n^2 - n}{2}$$该算法针对给定的情况精确计算该表达式`n`。 由于实现直接匹配序列的定义，因此保证生成的值是正确的`n`- 第一个五边形数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

answer = (3 * n * n - n) // 2

print(answer)
```程序首先读取整数`n`。 

主要计算使用五边形序列的精确数学定义。 表达式：```
(3 * n * n - n) // 2
```匹配：$$\frac{3n^2 - n}{2}$$括号很重要，因为减法必须在除法之前进行。 没有它们，Python 只会除最后的`n`经过`2`，改变公式的含义。 

该解决方案使用`//`而不是`/`所以结果仍然是一个整数。 五边形数保证是整数，因此整数除法是正确的运算。 

由于计算仅涉及少量算术运算，因此实现可以立即运行。

import sys
import io

def solve():
    import sys

 ## 边缘情况

 最小可能的输入是：```
1
```该算法计算：$$\frac{3 \cdot 1^2 - 1}{2} = \frac{2}{2} = 1$$程序打印：```
1
```这证实了对序列进行索引时不存在差一错误。 

另一个容易失败的地方是运算符优先级。 考虑：```
2
```正确的评价是：$$\frac{3 \cdot 2^2 - 2}{2} = 5$$该实现显式使用括号：```
(3 * n * n - n) // 2
```因此减法发生在除法之前，从而防止结果错误。 

最大输入为：```
100
```该算法计算：$$\frac{3 \cdot 100^2 - 100}{2} = \frac{30000 - 100}{2} = 14950$$Python 整数可以轻松处理这个范围，因此不存在溢出风险。
