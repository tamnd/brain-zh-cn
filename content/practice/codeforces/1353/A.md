 ## 解决方案
 ## 问题理解

 我们给定一个数组长度`n`以及所需的总金额`m`。 任务是将非负整数分配给长度为 的数组`n`使得所有元素的总和等于`m`。 在所有此类数组中，我们希望有一个使总“相邻跳跃”尽可能大的数组，其中每次跳跃都是相邻元素之间的绝对差。 

最大化的表达式测量从左到右读取时数组振荡的程度。 平面数组产生零，而大值和小值之间的交替会从每次转换中产生很大的贡献。 

限制条件非常大：`n`和`m`可以达到`10^9`，并且最多可以有`10^4`测试用例。 这立即排除了显式构造数组或模拟任何与`n`。 任何解决方案都必须将每个测试用例简化为常数时间算术。 

天真的尝试会尝试分发`m`以不同的模式遍历数组并计算所得的差异总和。 即使我们只尝试为每个测试用例模拟一个候选数组，构建或迭代`n`元素是不可能的。 

出现微妙的边缘情况时`n = 1`。 没有相邻的对，所以无论什么，答案总是零`m`。 另一个角落是当`n = 2`，答案变得简单`|a1 - a2|`约束下`a1 + a2 = m`，通过将所有质量推入一侧来最大化。 

## 方法

 暴力的观点是尝试所有可能的长度数组`n`与总和`m`，计算它们的相邻差异，并跟踪最大值。 即使我们将自己限制为整数组合`m`，可能性的数量呈指数增长`m`并与`n`。 即使对于很小的输入，这也是完全不可行的。 

关键的结构观察是，放置在数组中的每个值单位只有在不对称的位置之间移动时才会产生差异。 为了最大化相邻差异，我们希望数组尽可能在高值和低值之间交替。 然而，我们受到总质量的限制`m`，所以我们不能在任何地方自由地分配大的交替值。 

事实证明，最佳结构非常简单：我们将所有非零质量放置在两种极端模式中，具体取决于`n`。 什么时候`n = 1`，不存在相邻对。 什么时候`n = 2`，我们放置`m`完全在一侧。 什么时候`n ≥ 3`，我们可以实现完整的“之字形”模式，其中值在零和非零之间交替，并且除了边界限制之外，每个质量单位对总差值的贡献是两倍。 这导致封闭式结果最大值为`2 * m`什么时候`n ≥ 3`， 和`m`什么时候`n = 2`。 

这样做的原因是，放置在内部位置的每个单元可以在转换中计数两次，一次在进入时，一次在离开时，并且交替结构确保平坦段中不会浪费质量。

 ## 算法演练

 我们将每个测试用例简化为仅基于以下内容的直接公式`n`和`m`。 

1.如果`n == 1`， 返回`0`。 不存在相邻元素，因此不存在差异。 
2.如果`n == 2`， 返回`m`。 我们能做的最好的就是分开`m`进入`(m, 0)`或者`(0, m)`, 给予差异`m`。 
3.如果`n >= 3`， 返回`2 * m`。 我们可以构造一个交替模式，例如`[0, m, 0, 0, 0, ...]`重新排列成之字形，其中所有质量运动在过渡过程中都会贡献两倍。 

步骤 3 起作用的关键原因是，在至少三个位置的情况下，我们总是可以将质量分开，使其被零包围，从而允许它在相邻的转换中“进入”和“退出”。 

### 为什么它有效

 目标的价值仅取决于连续位置之间的变化。 放置在数组中的每个正单元最多可以对绝对差之和做出两次贡献，一次是当它从零（或更低的值）接近时，一次是当它返回零（或更低的值）时。 通过至少三个插槽，我们始终可以在所有质量周围排列零，以避免贡献之间的干扰，从而使`2m`可实现的和最大的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        if n == 1:
            print(0)
        elif n == 2:
            print(m)
        else:
            print(2 * m)

if __name__ == "__main__":
    solve()
```该解决方案独立读取每个测试用例并应用直接的用例区分。 实现依赖于这样一个事实：答案仅取决于`n`和`m`，因此不需要构建数组。 

唯一的微妙之处是确保 Python 整数乘以 2，它可以安全地处理高达`2 * 10^9`在限制范围内。

 ## 边缘情况

 对于`n = 1`，算法返回`0`立即地。 有输入`n = 1, m = 100`，不存在相邻对，因此无论分布如何，计算值在结构上都为零。 条件`n == 1`直接强制执行这一点。 

为了`n = 2`，算法返回`m`。 如果我们采取`n = 2, m = 7`，分割总和的唯一方法是`(7, 0)`或者`(3, 4)`或任何分区。 最好的情况总是将所有质量放在一侧，产生差异`7`。 分行`n == 2`捕捉到这个确切的行为。 

为了`n ≥ 3`， 考虑`n = 3, m = 4`。 算法返回`8`。 有效的构造是`[0, 4, 0]`，生产`|0-4| + |4-0| = 8`。 这表明即使在应用的最小情况下也可以实现加倍效果。
