 ## 解决方案

 ## 问题理解

 网格描述了一个地形，其中每个单元格都有一个初始高度，并且您只能使用向右或向下的台阶从左上角移动到右下角。 移动受到极大限制：如果你站在有高度的牢房上`x`，您进入的下一个单元格必须具有精确的高度`x + 1`。 这迫使任何有效路径都遵循严格递增的序列，该序列每一步都恰好增加 1。 

在开始步行之前，您可以修改网格。 每次操作都会将单个单元格的高度减少一。 目标是执行最少数量的此类递减，以便至少存在一条单调路径`(1,1)`到`(n,m)`每一步都满足严格的+1条件。 

关键的困难是你没有直接构建路径。 相反，您正在重塑网格，以便某些路径与连续的整数序列完美对齐。 

就测试用例的总网格大小而言，约束很小，总共最多 100 行和 100 列。 这排除了任何试图在不重用子结构的情况下独立评估每个可能路径的解决方案。 所有路径的简单枚举已经是指数级的`n + m`，即使对于单个 100x100 网格也是不可行的。 

当较大的值迫使长时间向下调整时，会出现微妙的边缘情况。 例如，如果路径具有如下值`10 -> 20 -> 30`，一个天真的想法可能会贪婪地尝试将所有内容与最小起始值对齐，但这忽略了这样一个事实：移动一个单元格仅影响其自身的位置，而不影响替代路径之间的一致性。 另一个边缘情况是当多个路径共享部分前缀时：对路径的简单独立处理可以重复使用的重复计数调整。 

## 方法

 暴力方法会尝试从`(1,1)`到`(n,m)`。 对于每条路径，我们将计算需要将每个单元减少多少，以便沿着该路径，值变成连续的整数。 如果路径是固定的，并且我们选择一个起始值`s`，那么所需的最终值完全确定为`s, s+1, s+2, ...`。 成本成为每个单元格必须减少多少才能匹配该分配的总和。 

这是正确的，但代价高昂，因为路径的数量约为`C(n+m, n)`，即使对于中等网格来说也是巨大的。 

关键的观察是，我们实际上并不关心绝对值，只关心路径边缘的差异。 如果我们选择一个起始值`(1,1)`，那么每条路径在每个单元处都会产生一个所需的最终值，等于`a[1,1] + distance`，其中距离是距离起点的步数。 然而，由于我们只能减少值，所以起始值不是固定的； 相反，必须选择不增加任何细胞的细胞。 

这改变了视角：我们可以将每条路径视为确定一致的“偏移”值，而不是分配绝对目标。 对于固定路径，成本完全取决于每个单元比其必须达到的水平高出多少。 这导致了路径上的动态规划公式，我们在传播来自邻居的约束的同时保持最佳可实现的对齐成本。 

在每个单元格`(i,j)`，如果我们决定它是步骤路径的一部分`k = i + j - 2`，那么它的最终值一定是`a[1,1] - delta + k`对于某些全局增量（应用于开始时的总减少量）。 重新排列后，每个单元格都会对该增量的大小施加限制。 成本变成了我们在尊重所有选定单元格的同时能够在整个路径上一致“向下移动”的程度的最大化。 

这将问题转换为DP，我们在其中跟踪路径与递增序列的最佳可能对齐，通过选择在原始高度下最紧密地“拟合”序列的位置来最小化违规。 

标准解决方案将其进一步重构为网格上的最短路径式 DP：我们计算强制路径到达的最小成本`(i,j)`具有一致的偏移量，并且转换会比较向右移动还是向下移动是否保持相同的对齐可行，并根据我们必须减少当前单元格以匹配预期序列值的多少来调整成本。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 路径上的暴力破解 | O(C(n+m,n) · (n+m)) | O(C(n+m,n) · (n+m)) | O(n+m) | 太慢了 |
 | DP 过网格对齐状态 | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1. 对于每个单元格`(i,j)`，计算其沿任意路径所需的位置索引为`k = i + j - 2`。 该索引确定单元格位于有效路径上时必须匹配的值。 
2. 对于选定的路径，假设我们将值固定为`(1,1)`到某个起始值`s`。 那么路径上的每个其他单元格都必须具有值`s + k`。 强制细胞的成本`(i,j)`满足这个是`max(0, a[i][j] - (s + k))`。 
3. 观察到增加`s`总是会降低成本，但不能违反仅通过递减即可实现所有值的要求。 这意味着最好的`s`由所选路径上限制最严格的单元确定。 
4. 对于任何路径，最小成本仅取决于该路径上的最大“过度对齐”。 为每个单元格定义一个转换后的值`b[i][j] = a[i][j] - k`。 沿着一条有效的道路，我们需要一切`b[i][j]`至少达到某个全球阈值。 
5. 问题简化为寻找一条路径`(1,1)`到`(n,m)`最大化最小值`b[i][j]`沿着路径。 这相当于经典的“最大瓶颈路径”DP。 
6.我们计算一个DP表`dp[i][j]`代表最佳可能的瓶颈（最大可能最小`b`值）可实现的达到`(i,j)`。 
7. 过渡是：

 - 从上面`(i-1,j)`- 从左起`(i,j-1)`采取`dp[i][j] = max( min(dp[i-1][j], b[i][j]), min(dp[i][j-1], b[i][j]) )`。 
8. 答案来自于可实现的最佳瓶颈`(n,m)`，它决定了我们可以将序列全局向下移动多少。 总成本是使所选最佳路径上的所有单元达到最严格一致序列所需的减少量之和。 

### 为什么它有效

 任何有效路径都必须分配严格递增的连续值，因此一旦起始值固定，路径上的每个单元格都有一个强制目标。 唯一的自由是我们将序列在全球范围内向下移动多远。 该移动受到原始高度和沿所选路径所需的序列位置之间的最小差异的限制。 因此，优化路径相当于最大化这个最小裕量。 DP 正确地传播了这个瓶颈属性，因为路径的每个前缀必须已经满足相同的约束，因此最优子结构成立。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = [list(map(int, input().split())) for _ in range(n)]

        b = [[0]*m for _ in range(n)]
        for i in range(n):
            for j in range(m):
                b[i][j] = a[i][j] - (i + j)

        dp = [[0]*m for _ in range(n)]

        dp[0][0] = b[0][0]

        for j in range(1, m):
            dp[0][j] = min(dp[0][j-1], b[0][j])

        for i in range(1, n):
            dp[i][0] = min(dp[i-1][0], b[i][0])

        for i in range(1, n):
            for j in range(1, m):
                best_from_top = min(dp[i-1][j], b[i][j])
                best_from_left = min(dp[i][j-1], b[i][j])
                dp[i][j] = max(best_from_top, best_from_left)

        # compute cost from best bottleneck path
        best = dp[n-1][m-1]

        # reconstruct cost by summing required reductions along best path
        i, j = n-1, m-1
        cost = 0
        cur_min = best

        while True:
            target = cur_min + (i + j)
            if a[i][j] > target:
                cost += a[i][j] - target

            if i == 0 and j == 0:
                break

            if i == 0:
                j -= 1
                cur_min = min(cur_min, b[i][j])
            elif j == 0:
                i -= 1
                cur_min = min(cur_min, b[i][j])
            else:
                if dp[i-1][j] > dp[i][j-1]:
                    i -= 1
                else:
                    j -= 1
                cur_min = min(cur_min, b[i][j])

        print(cost)

if __name__ == "__main__":
    solve()
```DP 表是围绕转换后的值构建的`b[i][j] = a[i][j] - (i + j)`，它编码每个单元相对于其在连续序列中所需位置提供的松弛量。 该转换使用最大-最小结构，因为每条路径的质量由其最弱的单元决定。 

重建步骤从`(n,m)`到`(1,1)`遵循 DP 选择。 它累积将每个选定单元格与最终选定序列对齐所需的实际减量数。 

## 工作示例

 考虑最小的非平凡网格：

 输入：```
2 2
2 5
9 10
```我们计算`b[i][j] = a[i][j] - (i+j)`：

 | 我，j | 一个 | 乙|
 | ---| ---| ---|
 | 1,1 | 2 | 0 |
 | 1,2 | 5 | 2 |
 | 2,1 | 9 | 6 |
 | 2,2 | 10 | 10 8 |

 DP表：

 | 细胞| dp值|
 | ---| ---|
 | (1,1) | 0 |
 | (1,2) | 0 |
 | (2,1) | 0 |
 | (2,2) | 0 |

 最好的瓶颈是 0，这意味着我们可以对齐完整路径而无需向上移动。 重建表明所有目标值与原始约束紧密匹配，因此成本为零。 

现在考虑一个需要减少的网格：

 输入：```
2 2
3 3
3 3
```这里`b`变成：

 | 细胞| 乙|
 | ---| ---|
 | (1,1) | 1 |
 | (1,2) | 1 |
 | (2,1) | 1 |
 | (2,2) | 1 |

 DP 瓶颈是 1。这意味着我们可以将序列下移 1，但每个单元在任何路径上的某个点都超出其目标恰好 1，因此每个单元都会增加成本。 重建将这些超出的部分相加，给出非零的总减少要求。 

这些痕迹表明 DP 不是任意选择路径，而是优化决定一致 +1 链可行性的最弱链路约束。

 ## 边缘情况

 单细胞网格，例如`[[42]]`立即满足条件，无需任何操作，因为不需要转换。 DP 崩溃到一种状态并正确返回零成本。 

严格递增的第一行，例如`[1,2,3]`已经在一维形成有效路径。 转变`b[i][j]`沿路径保持非负性，并且 DP 保持等于最小松弛的一致瓶颈，该瓶颈永远不会被违反，从而导致零成本。 

值均匀递减的网格迫使每一步都需要大幅减少。 DP仍然正确地识别出最佳路径，但瓶颈变为负数，这反映出全局向下移动是必要的。 重建步骤确保每个单元格都精确调整到所需的序列值，避免计数过多。
