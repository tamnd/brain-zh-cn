 ## 解决方案

 ## 问题理解

 我们被赋予了一个$n \times n$网格，其中每个单元格都以一个标记开始。 在一次移动中，我们选择一个标记并将其移动到八个相邻单元格中的任何一个，包括对角线。 令牌可以堆叠，并且对同一单元格中最终出现的数量没有限制。 目标是将所有令牌放入一个单元格中，同时最大限度地减少移动总数。 

由于每个单元格最初都包含一个令牌，因此我们可以将该任务视为选择一个最终的“目标”单元格并将所有其他令牌移入其中。 每个令牌贡献的成本等于 8 向移动下到所选目标的最短路径距离。 

关键的隐藏结构是8个方向的运动对应于切比雪夫距离。 对于一个细胞$(i, j)$和目标$(x, y)$，距离为：$$\max(|i-x|, |j-y|)$$所以问题就变成了：选择一个中心单元，使所有网格单元的切比雪夫距离之和最小。 

约束条件$n \le 5 \cdot 10^5$测试总和有界意味着我们无法模拟网格操作或迭代所有$n^2$细胞。 任何解决方案都必须将网格简化为一维求和公式$O(1)$或者$O(n)$每次测试。 

一个微妙的边缘情况是$n = 1$。 网格的一个单元格中已包含所有标记，因此答案为零。 任何公式都必须自然地处理这个问题，而无需特殊的外壳。 

当推理对称性时，会出现另一种隐式边缘行为。 因为$n$很奇怪，有一个独特的中心单元。 任何正确的解决方案都必须隐含地使用这个事实； 否则，平均多个中心之间的距离会导致错误的重复计算或分数推理。 

## 方法

 暴力解决方案将尝试每个可能的目标单元$(x, y)$，计算每个单元格到它的距离，并对所有贡献求和。 每次评估费用$O(n^2)$，并且有$O(n^2)$目标，导致$O(n^4)$，即使对于$n = 200$。 

我们可以通过分离坐标来显着减少这种情况。 切比雪夫距离$\max(|i-x|, |j-y|)$在 2D 中很尴尬，但对称性有帮助：我们观察到中心周围的每一层贡献均匀，而不是直接对所有单元求和。 

将棋盘视为围绕中心的同心方形“环”。 所有细胞都处于一定距离$k$形成一个正方形边的边界$2k+1$。 该环中的每个令牌必须至少移动$k$到达中心的步骤，并且准确地$k$是可以实现的。 所以每一层贡献：$$(\text{number of cells in ring}) \cdot k$$对于尺寸的网格$n$，中心距$0$，并且有来自的层$1$到$\frac{n-1}{2}$。 这$k$第-层贡献了该层正方形的周长。 周长计数简化为$8k$，因此总成本变为：$$\sum_{k=1}^{(n-1)/2} 8k^2$$这将问题转化为封闭形式的平方和，消除了对$n^2$。

 ## 算法演练

 1. 观察到所有令牌独立地向选定的中心单元移动，因此总成本是从每个单元到中心的最短路径距离的总和。 这使我们能够单独处理每个单元，而不是模拟移动。 
2. 确定 8 个方向的运动使距离等于切比雪夫距离。 这用基于方形层的简单几何解释取代了路径模拟。 
3.注意最优目标是唯一的中心单元$(\frac{n}{2}, \frac{n}{2})$，因为对称性确保任何偏差都会增加至少一个对称区域的总距离。 
4. 将网格分成围绕中心的同心方形环。 最外环有半径$\frac{n-1}{2}$，以及每个环$k$包含距中心最大坐标距离恰好为的所有单元格$k$。 
5. 计算有多少个单元恰好位于环上$k$。 边长的正方形$2k+1$减去边的平方$2k-1$给出：$$(2k+1)^2 - (2k-1)^2 = 8k$$所以每个环包含$8k$细胞。 

1.其中每一个$8k$令牌必须至少移动$k$向内迈进，这个界限很紧，因为路径总是可以单调地选择朝向中心。 
2. 将来自所有环的贡献相加$k = 1$到$k = \frac{n-1}{2}$，将每层的计数乘以距离。 
3. 有效评估每个测试用例生成的封闭形式。 

### 为什么它有效

 每个像元恰好属于距中心一个切比雪夫距离层，并且每一层对总成本都有独立贡献。 分解为不相交的环可确保不会重复计算，并且距离下界$k$对于戒指$k$是紧的，因为对角线移动允许同时减少两个坐标。 这保证了总层成本与最小总移动次数完全匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        k = (n - 1) // 2
        # sum_{i=1..k} 8*i*i
        # = 8 * sum i^2
        s = k * (k + 1) * (2 * k + 1) // 6
        print(8 * s)

if __name__ == "__main__":
    solve()
```该解决方案将网格问题简化为单个算术表达式。 变量$k$表示距中心的最大切比雪夫半径。 直接使用平方和公式，避免迭代。 

一个常见的错误是求和$8k$而不是$8k^2$。 第一项对每层的单元进行计数，但每个单元也会产生移动成本$k$，其中引入了第二个因素$k$。

 ## 边缘情况

 对于$n = 1$，我们有$k = 0$，因此总和为空，结果为零。 该公式无需特殊处理，自然会返回零。 

对于非常大的$n$， 例如$n = 499993$，值$k$变大，并且平方和中的中间乘积超过 32 位限制。 使用Python整数可以避免溢出，并且封闭式表达式可以确保恒定时间计算。 

对于最小的奇数尺寸，例如$n = 3$，正好有一个环。 该公式简化为$8 \cdot 1^2 = 8$，与所有 8 个外部单元距中心距离为 1 的事实相匹配。
