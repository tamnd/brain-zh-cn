 ## 解决方案
 ## 问题理解

 我们有一组固定在三维空间中的无人机。 每架无人机 i 都有坐标 (x_i, y_i, z_i) 和权重 w_i。 我们可以自由选择特殊主无人机在任何整数坐标（x，y，z）的位置。 选择位置的成本定义为所有无人机到该点的欧几里德距离平方的总和乘以无人机的重量。 

换句话说，每架无人机贡献 w_i 倍 ((x - x_i)^2 + (y - y_i)^2 + (z - z_i)^2)，我们希望选择 (x, y, z) 来最小化这个总值。 如果多个整数点达到相同的最小成本，我们必须返回字典顺序最小的那个，这意味着我们更喜欢先较小的 x，然后是 y，然后是 z。 

这些约束允许最多 100000 架无人机，坐标最多 200000 个，权重最多 1000 个。这会立即排除任何从网格中尝试候选位置或评估每个维度 200000 范围内所有点的目标的方法。 即使在 x 和 y 上进行二维扫描也是不可能的，因为搜索空间在坐标范围内是立方的。 

一个关键的结构观察是成本完全分解为 x、y 和 z 上的独立总和。 也就是说，该表达式展开为三个独立的一维二次函数的和，每个函数对应一个坐标轴。 

一个天真的误解是认为坐标由于欧几里得距离而相互作用。 典型的错误方法是将其视为几何中值问题或尝试在没有权重的情况下进行坐标中值，这两种方法都会失败。 

当多个加权配置产生相同的最佳值时，就会出现微妙的边缘情况。 例如，如果所有点都是对称的，则存在多个整数最小化器，并且字典顺序成为决定因素。 任何独立解决每个维度的方法都必须确保一致的打破平局。 

## 方法

 蛮力的想法很简单：尝试输入坐标范围内的每个可能的整数坐标（x，y，z）并计算每个选择的总成本。 这是正确的，因为它直接评估目标函数的定义。 然而，每个维度的坐标范围最多为 200000 个，这意味着大约有 8 × 10^15 个候选点。 即使评估单个点也会花费 O(n)，导致总运行时间达到天文数字，大约需要 10^21 次操作，这是完全不可行的。 

关键的见解是以代数方式扩展目标函数。 对于固定维度（例如 x），所有无人机的贡献为

 Σ w_i (x - x_i)^2

 扩展这给出

 Σ w_i (x^2 - 2x x_i + x_i^2)

 可以重写为

 x^2 Σ w_i - 2x Σ (w_i x_i) + 常数

 这是 x 中的凸二次函数。 整数上的凸二次方程在其实值最小值附近有一个全局最小值。 相同的结构对于 y 和 z 独立成立。 

因此，问题简化为最小化三个独立的一维加权二次函数。 每个问题都可以通过计算加权平均值然后检查其周围最接近的整数候选来解决。 

由于该函数是凸函数，因此仅评估实际最优值周围恒定数量的整数点就足够了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·R^3) | O(n·R^3) | O(1) | O(1) | 太慢了 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 这里R是坐标范围大小，大约是200000。 

## 算法演练

 我们独立对待 x、y 和 z，因为目标是三个可分离二次表达式的和。

1. 计算总重量W = Σ w_i。 这表示每个维度的加权平均值的归一化因子。 
2. 计算加权和 S_x = Σ w_i x_i, S_y = Σ w_i y_i, S_z = Σ w_i z_i。 这些编码点的“质量”沿每个轴的位置。 
3. 计算每个坐标的实值极小值 S_x / W、S_y / W、S_z / W。这是每个二次函数的驻点，通过将导数设置为零而获得。 
4. 由于我们需要整数坐标，因此考虑每个实数最小化器周围的候选整数。 对于每个维度，检查加权平均值的下限和上限周围的一个小邻域，通常最多两个或三个值。 凸性确保整数上的全局最小值位于该邻域内。 
5. 对于候选 x、y、z 值的每个组合，直接使用定义计算全部成本。 
6. 跟踪遇到的最低成本。 如果多个三元组达到相同的成本，则通过比较 (x, y, z) 选择字典顺序最小的一个。 

### 为什么它有效

 每个坐标贡献一个独立的凸二次函数。 凸性保证任何局部最小值都是全局最小值，并且对于整数域，最优值必须位于实值驻点附近。 由于全部成本是三个独立凸函数的总和，因此独立地最小化每个坐标（使用正确的整数舍入）会产生全局最小化器。 通过在评估后比较完整的候选者来显式地处理字典顺序的平局打破，即使存在多个整数最小化器也确保正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    sx = sy = sz = sw = 0
    
    points = []
    for _ in range(n):
        x, y, z, w = map(int, input().split())
        sx += x * w
        sy += y * w
        sz += z * w
        sw += w
        points.append((x, y, z, w))
    
    # real-valued candidates
    def candidates(s, wsum):
        if wsum == 0:
            return [0]
        base = s / wsum
        c = int(base)
        return [c - 1, c, c + 1, c + 2]
    
    cx = candidates(sx, sw)
    cy = candidates(sy, sw)
    cz = candidates(sz, sw)
    
    best_cost = None
    best = (10**30, 10**30, 10**30)
    
    def cost(x, y, z):
        res = 0
        for xi, yi, zi, wi in points:
            dx = x - xi
            dy = y - yi
            dz = z - zi
            res += wi * (dx*dx + dy*dy + dz*dz)
        return res
    
    for x in cx:
        for y in cy:
            for z in cz:
                c = cost(x, y, z)
                cand = (x, y, z)
                if best_cost is None or c < best_cost or (c == best_cost and cand < best):
                    best_cost = c
                    best = cand
    
    print(best[0], best[1], best[2])

if __name__ == "__main__":
    solve()
```该实现首先聚合加权和来识别每个坐标中的连续最小化器。 然后，它围绕每个最小化器生成一个小的离散候选集，并使用原始成本定义准确地仅评估这些点。 候选对象上的嵌套循环的大小是恒定的，因此它们不会影响渐近复杂度。 

通过存储最佳三元组并在成本平齐时直接比较元组来处理字典序要求。

 ## 边缘情况

 退化的情况是所有无人机的位置都相同。 加权平均值等于同一坐标，因此候选集会折叠到该单个点。 该算法直接评估它并返回它，保持正确性。 

当加权平均值恰好位于两个整数之间时，会出现另一种边缘情况。 例如，如果平均值为 2.5，则必须检查 2 和 3。 候选一代包括两个邻居，直接评估可确保选择正确的一代。 如果两者给出相同的成本，则词典比较选择较小的坐标。 

最后一种边缘情况是权重极度不平衡。 单个大 w_i 主导了总和，将最佳坐标推向无人机的位置。 由于候选生成以加权平均值为中心，这已经反映了这种优势，因此该算法仍然包含正确的区域并对其进行准确评估。
