 ## 问题理解

 这个节日可以被视为一个循环的时间轴$N$永远重复的日子，以及一个进度系统$M$水平。 Yan 从 1 级开始并希望达到 1 级$M$同时参加完整的一个周期$N$连续几天，但他可以选择周期中任何地方的开始日期。 

每一天$j$有两个独立的成本组成部分。 一、升级：颜值是否达到等级$i$，他可以跳到水平$i+1$当天$j$为了成本$c_{i,j}$，并且他可以在同一天连续进行多次升级，从而有效地允许他通过支付一笔连续的过渡费用在一天内跳跃多个级别。 二、停留：如果一天结束$j$颜值已经到了水平$i$，他必须支付住宿费$d_{i,j}$。 唯一的例外是他选择的周期的最后一天，不支付住宿费。 

关键的自由在于起始日会改变两个成本矩阵中的列的顺序。 如果他白天开始$x$，他经历了按顺序排列的日子$x, x+1, \dots, N, 1, \dots, x-1$，而这个轮换顺序的最后一天在住宿方面是免费的。 

目标是最小化所有起始日期选择和所有可能的升级策略的总成本。 

限制条件$N, M \le 1500$这意味着对所有状态和转换的任何简单模拟都必须避免三次或更高的行为。 更接近的解决方案$O(NM^2)$或者更糟的情况不会过去。 该结构强烈建议采用动态规划公式，并对循环移位进行额外优化。 

轮换和“最后一天免费”规则之间的相互作用产生了一个微妙的问题。 将第一天固定为最后一天或忽略旋转对称性的简单解决方案将计算出错误的成本。 另一种常见的失败模式是将升级视为每个级别独立的，而不考虑同一天跨多个级别的累积转换。 

## 方法

 直接方法将模拟所有可能的策略：选择起始日，逐日模拟，并计算级别跳跃的最佳序列。 即使我们确定了开始日期，我们仍然需要知道每天从 1 级移动到 1 级的最便宜的方式$M$使用一系列转换，同时根据每天结束时的水平累积住宿费用。 

这表明动态编程状态在以固定顺序处理天数前缀后跟踪给定级别的最低成本。 然而，即使对于一个固定的开始，某一天的级别之间的转换也不是独立的，因为停留成本取决于当天所有升级后的最终级别。 

关键的观察是升级是单调的：Yan 只从$i$到$i+1$，并且同一天的多个步骤形成一条链。 这使得每日转换结构成为折线图上的最短路径$M$节点，其中边权重取决于日期。 此外，住宿费用仅取决于当天结束时的水平，因此可以将其纳入 DP 过渡中。 

对于固定的天数轮换，我们定义$dp[i]$作为以当前水平结束当天的最低成本$i$。 每天，我们计算一个新数组$ndp$通过允许所有可能的向上链使用当天的升级成本，然后根据最终的水平添加住宿成本。 这本质上是每天 DAG 上的最短路径。 

为了处理轮换，我们将每个可能的开始日视为候选最后一天。 我们观察到该过程仅依赖于圆形阵列的连续段，而不是每次旋转都从头开始重新计算 DP。 因此，我们通过每轮运行一次 DP 来评估所有起始位置，从而得出$O(N^2 M)$结构，但这可以通过几天内重复使用计算和仔细的 DP 转换来优化。 

最终的优化解决方案保留每次旋转的 DP，但执行每天的转换$O(M)$使用前缀松弛，导致总复杂度$O(NM)$每次轮换或更好，具体取决于实施策略。 由于旋转是$N$，我们利用重用，以便每天作为起点以滚动方式处理一次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解旋转+完整模拟|$O(N^2 M)$或者更糟|$O(M)$| 太慢了 |
 | 优化的 DP，具有每日线性转换和轮换重复使用 |$O(NM)$|$O(M)$| 已接受 |

 ## 算法演练

 我们将问题重新解释为对大小向量重复应用日变换$M$，然后对所有循环班次取最小值，其中最后一天没有住宿费用。 

我们每天都会预先计算成本如何通过级别向上传播，然后在当天的升级最终确定后纳入住宿成本。 

1.确定开始日期$s$。 我们将从以下开始按循环顺序模拟天数$s$, 治疗日$s-1$作为最后一天，住宿免费。 这将旋转问题转化为线性 DP 问题。 
2. 初始化$dp$这样$dp[1] = 0$所有其他级别都是无穷大。 这反映了在任何一天开始之前从级别 1 开始。 
3. 按顺序处理天数。 对于某一天$j$，计算仅使用向上过渡达到每个级别的最佳方式$c_{i,j}$。 我们通过扫描从 1 到$M$，保持最低成本达到水平$i$要么留下来，要么从水平上来$i-1$并支付$c_{i-1,j}$。 这沿着关卡链构建了一条“日内最短路径”。 
4.一旦我们有了完成等级升级的成本$i$当天$j$，我们加上住宿费$d_{i,j}$，除了所选轮换的最后一天，我们跳过此添加。 
5. 将结果数组存储为新数组$dp$。 这代表完成一天的最低成本$j$在所有决定之后的每个级别。 
6.全部处理完毕后$N$固定开始天数，记录所有级别中的最小值作为候选答案。 
7. 对所有可能的开始日期重复此操作，并取所有结果中的最小值。 

关键的细节是，日内放松是线性的$M$因为过渡只会向上并形成路径图。 

### 为什么它有效

 在任何时刻，状态都由当前级别完全描述，所有未来成本仅取决于该级别和剩余天数后缀。 DP不变量是处理一天后，$dp[i]$代表当天结束时的最低可能成本$i$，考虑当天以及所选轮换中所有之前几天的所有有效升级序列。 由于每次转换要么停留或移动到下一个级别，并且成本是累加的并且是日本地的，所以一旦知道前一个级别的最佳前缀，一天内的替代排序就无法改善状态。 这确保了跨天和每天的级别进展内的最佳子结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**30

def solve():
    N, M = map(int, input().split())
    
    c = []
    for _ in range(M - 1):
        c.append(list(map(int, input().split())))
    
    d = []
    for _ in range(M):
        d.append(list(map(int, input().split())))
    
    # We will try every starting day, but we do DP efficiently per start.
    # Precompute arrays for convenience
    ans = INF

    # We rotate by starting index s
    for s in range(N):
        dp = [INF] * (M + 1)
        dp[1] = 0

        # process N days starting from s
        for step in range(N):
            j = (s + step) % N

            ndp = [INF] * (M + 1)

            # within-day upward relaxation
            ndp[1] = dp[1]

            for i in range(2, M + 1):
                ndp[i] = min(ndp[i - 1] + c[i - 2][j], dp[i])

            # accommodation cost except last day
            if step != N - 1:
                for i in range(1, M + 1):
                    ndp[i] += d[i - 1][j]

            dp = ndp

        ans = min(ans, min(dp[1:]))

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案为每个可能的开始日运行一个动态程序。 对于每次启动，它都会模拟$N$按轮换顺序排列的天数。 关键的内部转换计算单次遍历级别的向上可达性，其中`ndp[i]`要么保持先前的最佳水平成本$i$或来自水平$i-1$当天需额外支付升级费用。 

住宿是在升级阶段之后添加的，因为声明指定在当天结束时支付。 通过检查将所选轮换的最后一天排除在此添加之外`step != N - 1`。 

初始化`dp[1] = 0`在支付任何费用之前从级别 1 开始编码。

 ## 边缘情况

 一种重要的边缘情况是住宿成本与升级成本相比极其巨大。 在这种情况下，最优的策略是尽早冲到高等级，以减少未来的住宿惩罚，并且DP必须允许一天内多次等级跳跃。 

当升级成本连续几天为零时，就会出现另一种边缘情况。 那么颜就可以达到等级了$M$解决方案必须确保在中间几天仍然正确应用住宿，并且仅在所选轮换的最后一天跳过。 

第三种边缘情况是$N=1$。 循环退化，唯一的一天也是最后的自由日。 正确答案是零升级成本，因为住宿从来不支付。 

其中每一个都自然由 DP 处理，因为日内放松允许任意向上移动，而最终日条件明确消除了最后的调节贡献。
