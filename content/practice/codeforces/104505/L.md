 ## 解决方案
 ## 问题理解

 我们得到一个无向连通图$N$顶点和$M$边缘。 每个顶点代表一个旅游景点，边代表可以双向行驶的街道。 两个景点之间的距离定义为该图中通常的最短路径长度。 

有效的旅游线路是由长度至少为三的一系列不同顶点描述的类似循环的路线，其中序列中的连续顶点通过街道连接，并且最后一个顶点也连接回第一个顶点。 序列中的每个顶点必须在该电路中恰好出现一次。 

目标是将所有顶点划分为最少数量的此类电路，其中每个顶点恰好属于一个电路。 我们必须输出这个最小数量的电路以及电路本身，或者$-1$如果不可能的话。 

约束条件$N \le 10^5$和$M \le 10^6$排除任何尝试枚举循环或测试顶点子集的方法。 任何解在图的大小上都必须接近线性或近线性。 

一个关键的困难是图结构本身必须存在循环。 1 度的顶点会立即产生麻烦，因为它不能位于任何简单的循环上。 例如，在像四节点链这样的树中，根本不存在循环，因此不存在有效分区，答案必须是$-1$。 相反，四个节点上的完整图允许包含所有顶点的单个循环，因为每对都是连接的。 

当图已连接且具有许多边但仍包含 1 阶顶点或桥时，就会出现微妙的边缘情况。 即使距离可以满足给定的四点条件，这样的图也不能支持任何有效的电路覆盖。 

## 方法

 简单的方法将尝试显式构造图中的所有简单循环，然后选择将顶点划分到这些循环中。 在最坏的情况下，即使枚举所有循环也是指数级的，因为密集图可以包含指数级的许多简单循环。 之后，选择最小覆盖范围就成为循环中的集合划分问题，这在这种规模下也是棘手的。 

关键的观察是声明中给出的度量条件极其严格。 四点不等式是树度量的经典表征。 然而，该图是未加权的，并且度量来自简单图中的最短路径，而不是任意加权树嵌入。 

在这种情况下，图的结构崩溃了：最短路径距离表现一致的唯一方法是图在覆盖所有顶点的循环所需的连通性方面表现得像一个完整的图。 任何缺失的边都会创建无法同时放置在有效循环覆盖中的顶点，同时遵守度量条件隐含的结构。 

这将问题简化为结构检查：要么图是完整的，在这种情况下我们可以在所有顶点上形成单个哈密顿循环，要么不是，在这种情况下某些顶点不能包含在任何有效的电路分区中，并且答案是不可能的。 

在有效情况下构造答案很简单：输出一个包含任意顺序所有顶点的单个循环。

 ## 算法演练

 1. 读取图并计算每个顶点的度数，同时处理所有边。 这提供了一种直接的方法来检测每对顶点是否连接。 
2. 通过验证每个顶点都有度来检查图是否完整$N-1$并且边的数量恰好是$N(N-1)/2$。 这是必要的，因为任何丢失的边都会立即阻止构建包含所有顶点的单个循环。 
3. 如果图形不完整，则输出$-1$。 原因是，在问题结构隐含的约束下，任何缺失的邻接都会迫使至少一个顶点在完整的循环覆盖中无法使用。 
4. 如果图是完整的，则通过以任意顺序列出所有顶点（例如从 1 到$N$，然后返回到第一个顶点。 
5、输出$K = 1$接下来是构建的循环，确保序列的长度至少为 3，这是保证的$N \ge 1$但有效周期需要$N \ge 3$。 如果$N < 3$，答案是不可能的。 

### 为什么它有效

 核心约束迫使图的最短路径几何以极其严格的方式运行。 任何缺失的边都会引入其​​最短路径距离无法与一致放置在覆盖所有节点的不相交循环内相协调的顶点。 因此，唯一可行的配置是每对顶点都直接连接，这允许单个哈密顿循环覆盖所有顶点。 在这种情况下，划分为多​​个电路是不必要的，并且不能改善解决方案的大小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    
    deg = [0] * (n + 1)
    edges = set()

    for _ in range(m):
        a, b = map(int, input().split())
        if a > b:
            a, b = b, a
        edges.add((a, b))
        deg[a] += 1
        deg[b] += 1

    if n < 3:
        print(-1)
        return

    if m != n * (n - 1) // 2:
        print(-1)
        return

    for i in range(1, n + 1):
        if deg[i] != n - 1:
            print(-1)
            return

    print(1)
    print(n, *range(1, n + 1))

if __name__ == "__main__":
    main()
```该实现首先读取所有边缘并跟踪度数。 决定性的检查是边缘计数和均匀度条件，它们一起证明完整性，而无需显式验证所有对。 如果任一条件失败，则该图无法支持覆盖所有顶点的完整循环，因此程序立即返回$-1$。 

当图完成时，构造的电路只是顶点的自然排序。 由于每对顶点都是连接的，因此序列中的每个连续对都是有效的，并且返回第一个顶点的最终边也存在。

 ## 边缘情况

 两节点图立即失败，因为不存在长度至少为三的环。 该算法通过以下方式捕捉到这一点：$N < 3$在任何结构验证之前进行检查。 

在树等稀疏连接图中，度数条件失败，因为叶子的度数始终为 1。完整性检查无需搜索循环即可检测到这一点。 

在几乎完整但缺少单个边的图中，边计数检查已经失败。 即使没有明确检查度数，之间的不匹配$M$和$N(N-1)/2$保证不可能，因此不会产生错误的循环。
