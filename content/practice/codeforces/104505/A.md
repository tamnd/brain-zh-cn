 ## 解决方案
 ## 问题理解

 我们正在工作$k$维网格空间，其中有一个大的轴对齐超立方体$A$从原点到点的跨度$(n, n, \dots, n)$。 在这个大超立方体中，我们考虑每个可能的较小轴对齐整数坐标超立方体$B$完全适合里面$A$。 每个这样的立方体都是通过选择起始角和边长来定义的，并且所有有效选择的可能性相同。 

任务是计算随机选择的立方体的预期超体积$B$。 超体积很简单$(\text{side length})^k$，因为我们在$k$方面。 答案必须作为模分数输出$10^9 + 7$，这意味着我们有效地计算$\frac{p}{q} \bmod (10^9 + 7)$在哪里$p/q$是最低条件下的预期值。 

输入约束很大：$n$可以达到$10^9$，所以任何解都线性依赖于$n$或者迭代所有可能的立方体是不可能的。 维度$k$可以达到$2 \times 10^5$，它排除了任何二次或每维嵌套模拟，但仍然允许线性或近线性依赖$k$。 

出现微妙的边缘情况时$n = 1$。 在这种情况下，恰好有一个边长为 1 的立方体，因此无论怎样，答案始终为 1$k$。 任何组合公式都必须正确退化到这种微不足道的情况。 另一个潜在的陷阱是误解立方体的计数：立方体不仅由边长决定，还由位置决定，因此较大的立方体的位置较少，这会严重影响概率分布。 

## 方法

 暴力方法将枚举所有可能的边长$s$从$1$到$n$,数数有多少个$k$维立方体的边长$s$适合里面$A$，并累积它们对交易量的总贡献。 

对于固定边长$s$，放置的数量是$(n - s + 1)^k$，因为在每个维度中我们选择一个起始坐标$0$到$n - s$。 每个这样的立方体都贡献体积$s^k$，所以总贡献为：$$s^k \cdot (n - s + 1)^k$$立方体总数为：$$\sum_{s=1}^{n} (n - s + 1)^k$$所以蛮力会计算：$$\frac{\sum_{s=1}^{n} s^k (n - s + 1)^k}{\sum_{s=1}^{n} (n - s + 1)^k}$$这在数学上是正确的，但迭代到$10^9$是不可能的。 即使$k$的范围很小，$n$使得直接枚举变得不可行。 

关键的见解是转换表达式，以便对$n$变成代数而不是枚举。 该结构是对称的：每个立方体在每个维度上都是独立确定的，因此我们不考虑边长分布，而是将期望重新解释为独立的一维贡献的乘积。 

在每个维度中，选择一个立方体对应于选择两个整数$l_i \le r_i$在$[0, n]$，边长为$r_i - l_i$。 在维度上，这些选择是独立且相同的。 这将产品的期望降低为单个一维期望的幂：$$\mathbb{E}[\text{volume}] = \mathbb{E}[(\text{side length})^k] = (\mathbb{E}[\text{side length}])^k$$因此，整个问题简化为计算随机选择的段的预期长度$[0, n]$，然后将其上电$k$。 

对于一维，长度段的数量$d$是$n - d + 1$， 所以：$$\mathbb{E}[d] = \frac{\sum_{d=1}^{n} d(n - d + 1)}{\sum_{d=1}^{n} (n - d + 1)}$$分子和分母都成为闭式多项式和，可以简化为涉及以下的表达式：$n$,$n^2$， 和$n^3$。 这消除了对迭代的依赖并导致$O(1)$计算基本期望，然后快速求幂以求幂$k$。

 | --- | --- | --- | --- |
 | 蛮力 |$O(n)$|$O(1)$| 太慢了 |
 | 最佳|$O(\log k)$|$O(1)$| 已接受 |

 ## 算法演练

 ### 1.通过段端点重新解释立方体

 每个$k$- 维立方体是通过在每个维度中独立选择一对来确定的$(l_i, r_i)$和$0 \le l_i < r_i \le n$。 边长为$r_i - l_i$。 这会将几何对象转换为独立的一维选择。 

其有用的原因是体积成为跨维度相同随机变量的乘积。 

### 2. 将产品的期望降低到期望的幂

 由于每个维度都是独立且相同地采样的，因此每个维度的边长具有相同的分布。 超体积是$k$相同的随机变量，所以：$$\mathbb{E}[\prod_{i=1}^k X_i] = (\mathbb{E}[X])^k$$这是有效的，因为$X_i$是独立且同分布的。 

### 3. 计算一维中的预期线段长度

 在一维中，对于固定长度$d$， 有$n - d + 1$有效段。 所以：$$\mathbb{E}[X] = \frac{\sum_{d=1}^n d(n - d + 1)}{\sum_{d=1}^n (n - d + 1)}$$分母是线段总数：$$\sum_{d=1}^n (n - d + 1) = \frac{n(n+1)}{2}$$分子展开为：$$\sum d(n+1) - \sum d^2$$这简化了使用：$$\sum d = \frac{n(n+1)}{2}, \quad \sum d^2 = \frac{n(n+1)(2n+1)}{6}$$这产生了一个封闭式有理函数$n$。 

### 4. 转换为模分数

 计算分子和分母模$10^9+7$，然后将分子乘以分母的模逆。 

### 5. 上台$k$最终的期望是$(\mathbb{E}[X])^k$。 使用快速求幂。 

### 为什么它有效

 整个转换依赖于跨维度的独立性和分段选择的统一结构。 每个立方体都唯一对应于独立一维段的元组，因此概率空间可以清晰地分解。 这确保了期望分解为单个基本期望的幂，而不会丢失任何权重信息。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, k = map(int, input().split())

    n %= MOD

    # sums
    # S1 = sum d
    S1 = n * (n + 1) % MOD * modinv(2) % MOD
    # S2 = sum d^2
    S2 = n * (n + 1) % MOD * (2 * n + 1) % MOD * modinv(6) % MOD

    # numerator = sum d(n - d + 1) = (n+1)S1 - S2
    num = ((n + 1) % MOD * S1 - S2) % MOD

    # denominator = sum (n - d + 1) = n(n+1)/2
    den = S1

    # expected 1D length
    inv_den = modinv(den)
    exp1 = num * inv_den % MOD

    # final answer = exp1^k
    print(pow(exp1, k, MOD))

if __name__ == "__main__":
    solve()
```该代码首先使用封闭式求和导出一维中的预期边长。 分母重复使用算术级数和，而分子则结合了线性和二次和。 模逆在模数下干净地处理除法。 最后，求幂应用了跨维度的独立性。 

一个微妙的实现细节是重用$S1$为分母，这避免了重新计算第二个相同的公式。 减法时需要小心，以保持模数为正值$10^9+7$。

 ## 边缘情况

 对于$n = 1$，算法正确归约，因为$S1$和$S2$化简为 1，分子和分母相等，产生$E[X] = 1$。 提升至任意幂$k$将结果保持为 1，与只有一个可能的立方体这一事实相匹配。 

对于大型$n$，所有算术都是模数完成的$10^9+7$，因此避免了直接整数溢出。 封闭式公式确保我们永远不会迭代到$n$，所以即使像这样的极端值$n = 10^9$除了模块化缩减之外，其行为与小输入相同。 

对于大型$k$，重复乘法会太慢，但快速求幂可确保对数缩放。 该算法仅取决于基本期望，因此即使$k = 2 \times 10^5$，业绩保持稳定。
