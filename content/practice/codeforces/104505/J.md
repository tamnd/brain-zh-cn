 ## 解决方案
 ## 问题理解

 我们有一个系统$m$符号，每个符号最初处于两种状态之一，以及一组$n$开关（杠杆）。 每个杠杆都连接到两个不同的符号。 拉动杠杆会翻转两个连接符号的状态：0 变为 1，1 变为 0。杠杆最多只能使用一次，并且我们可以选择拉动杠杆的任何子集。 

目标是确定是否存在杠杆子集，以便在应用所有翻转后，所有杠杆的最终配置$m$符号匹配给定的目标二进制字符串。 如果存在，我们必须输出杠杆的任何有效子集。 

每个杠杆有效地切换两个位置，因此问题在于选择其端点在每个顶点处引起奇偶校验变化的边，以匹配初始状态和目标状态之间所需的最终差异。 

约束条件很大：最多$5 \cdot 10^5$杠杆和符号。 这排除了任何考虑边缘子集或在密集矩阵上执行高斯消除的方法。 甚至$O(n^2)$对边或顶点进行推理是不可能的。 必须利用该结构，以便每条边都被处理恒定的次数。 

当杠杆引起的图形断开连接时，就会出现微妙的边缘情况。 每个连接的组件必须独立地满足奇偶校验条件。 例如，如果一个组件有奇怪的总失配，但没有边缘可以在内部纠正它，那么答案是不可能的。 当组件内不匹配节点的天真贪婪配对假设任意配对总是可能的时，就会发生另一种失败情况； 事实上，周期很重要。 

## 方法

 如果我们将每个符号视为一个节点，将每个杠杆视为无向边，那么选择一个杠杆对应于切换两个端点。 让我们定义一个值$d[v]$作为顶点处初始状态和目标状态之间的异或$v$。 然后我们需要选择边，使得对于每个顶点$v$，所选入射边的数量等于$d[v]$模 2。 

这是一个经典的公式：我们想要一个边的子集，其关联奇偶性与给定的顶点奇偶性向量相匹配。 用线性代数术语来说，这是用图的关联矩阵求解 GF(2) 上的系统。 

蛮力方法会尝试尝试所有边缘子集，甚至限制到大小的子集$n$，检查生成的顶点奇偶性。 那是$O(2^n \cdot m)$，完全不可行。 

一种更结构化的尝试是将其视为线性方程并在$m$变量和$n$方程。 这仍然太大：矩阵是稀疏的，但一般消除仍然会降级为粗略$O(nm)$。 

关键的观察是我们只需要任何有效的解决方案，而不是所有的解决方案。 在图上，可以通过逐个组件构建解决方案来满足奇偶校验约束。 在连接的组件内，我们可以选择一棵生成树并使用它来向上或向下推动奇偶校验。 这将问题简化为树状传播，其中剩余奇偶校验可以沿边缘固定。 

我们对每个连接的组件求根，计算不匹配，并通过 DFS 贪婪地配对或传播奇怪的东西。 每条边都会考虑一次，然后我们逐步构建答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n \cdot m)$|$O(m)$| 太慢了|
 | 最佳|$O(n + m)$|$O(n + m)$| 已接受 |

 ## 算法演练

 我们将符号建模为顶点，将杠杆建模为边。 

1. 计算失配数组$d[v]$， 在哪里$d[v] = a[v] \oplus target[v]$。 这表示顶点是否$v$需要从事件选择的边进行奇数次翻转。 
2. 使用所有杠杆为图构建邻接表。 
3. 维护一个已访问数组和一个列表来存储选定的边。 
4.对于每个未访问的顶点，执行DFS以提取其连接组件的生成树。 DFS 将返回以节点为根的子树是否具有必须向上推的奇数奇偶校验要求。 
5. 在DFS期间，首先处理子进程。 对于一个孩子$u$，递归计算其奇偶校验余额。 如果子节点返回它仍然有未满足的奇偶校验（值 1），我们必须选择当前节点和子节点之间的边。 选择这条边会翻转两个端点，因此我们记录该杠杆并切换当前节点的奇偶校验要求。 
6. 处理完所有子节点后，将当前节点更新后的奇偶校验要求返回给其父节点。 
7. 处理完完整组件后，检查根是否满足奇偶校验。 如果不是，则该配置是不可能的，因为没有父边来修复它。 

关键的微妙之处在于，选择一条边可以局部解决奇偶校验，但会向上传播翻转，从而允许校正向根方向移动。 

### 为什么它有效

 DFS 维护一个不变量：在处理节点的子树之后，该子树中的所有顶点（可能除了根）都已经仅使用子树内部的边来满足其奇偶校验约束。 任何剩余的不匹配都表示为向上进位的单个位。 因为每条边最多使用一次，并且仅当子子树报告奇怪的需求时，我们永远不会在已处理的子树中引入不一致。 如果一个组件有一个有效的解决方案，那么这种向上传播将与可行的边选择完全匹配； 如果不是，则组件的根以未解析的奇偶校验结束，证明不可能。 

## Python 解决方案```python
import sys
sys.setrecursionlimit(10**7)
input = sys.stdin.readline

n, m = map(int, input().split())

g = [[] for _ in range(m)]
for i in range(n):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append((v, i))
    g[v].append((u, i))

target = list(map(int, input().split()))

visited = [False] * m
used_edge = [False] * n
answer = []

def dfs(v, parent):
    visited[v] = True
    need = target[v]

    for to, eid in g[v]:
        if to == parent:
            continue
        if not visited[to]:
            child_need = dfs(to, v)
            if child_need:
                used_edge[eid] = True
                answer.append(eid + 1)
                need ^= 1

    return need

for i in range(m):
    if not visited[i]:
        root_need = dfs(i, -1)
        if root_need:
            print(-1)
            exit()

print(len(answer))
print(*answer)
```邻接列表存储每个杠杆的两个端点及其索引，以便我们可以重建所选的集合。 DFS 返回一个奇偶校验位，指示以顶点为根的子树是否仍需要从其父边翻转。 

这`need`变量表示节点当前未解析的奇偶校验。 每次子树返回 1 时，我们都会激活该边，这会翻转子需求并使用 XOR 切换父需求。 这反映了应用杠杆的效果。 

一个常见的陷阱是忘记 DFS 树不是任意的：仅使用树边来传播奇偶校验。 后边缘被忽略以防止重复计数。 另一个微妙的问题是递归深度，因为图可以是一条长链，最多可达$5 \cdot 10^5$。 

## 工作示例

 ### 示例 1

 输入：```
2 3
1 2
2 3
1 0 1
```我们建立一条链条$1 - 2 - 3$。 目标失配向量全为零，因此不需要翻转。 

| 节点| 需求传入 | 儿童加工| 边缘选择| 更新需求 |
 | --- | --- | --- | --- | --- |
 | 3 | 1 | 无 | 无 | 1 |
 | 2 | 0 | 3 返回 1 | (2,3) | 1 |
 | 1 | 1 | 2 返回 1 | (1,2) | 0 |

 DFS 从 1 开始，通过链传播需求，并选择两条边来一致地解析奇偶校验。 这表明奇偶校验校正向上传播，直到根平衡。 

### 示例 2

 输入：```
3 2
1 2
2 3
0 0 1
```我们有一条链，但只有节点 3 需要翻转。 

| 节点| 需求传入 | 儿童加工| 边缘选择| 更新需求 |
 | --- | --- | --- | --- | --- |
 | 3 | 1 | 无 | 无 | 1 |
 | 2 | 0 | 3 返回 1 | (2,3) | 1 |
 | 1 | 0 | 2 返回 1 | (1,2) | 1 |

 根以未解决的奇偶校验结束，因此不存在解决方案。 该算法正确输出-1。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |$O(n + m)$| 在 DFS 遍历邻接表期间，每个杠杆仅处理一次 |
 | 空间|$O(n + m)$| 最坏情况下的图表示和递归堆栈 |

 约束允许最多$5 \cdot 10^5$节点和边，因此线性时间遍历完全符合限制。 内存使用量与图表大小保持线性关系。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque

    n, m = map(int, input().split())
    g = [[] for _ in range(m)]
    for i in range(n):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append((v, i))
        g[v].append((u, i))

    target = list(map(int, input().split()))
    vis = [False] * m
    ans = []

    sys.setrecursionlimit(10**7)

    def dfs(v, p):
        vis[v] = True
        need = target[v]
        for to, eid in g[v]:
            if to == p:
                continue
            if not vis[to]:
                child = dfs(to, v)
                if child:
                    ans.append(eid + 1)
                    need ^= 1
        return need

    for i in range(m):
        if not vis[i]:
            if dfs(i, -1):
                return "-1\n"
    return str(len(ans)) + ("\n" + " ".join(map(str, ans)) if ans else "")

 ## 边缘情况

 目标奇偶校验具有奇数和的断开组件无法修复，因为每条边都会翻转两个顶点，从而保留全局奇偶校验。 DFS 最终将在根处返回一个非零值，从而触发拒绝。 

长链强调递归深度。 该算法仍然对每条边处理一次，但如果不增加递归限制，它会在 Python 中崩溃。 

具有多个都需要校正的子节点的节点演示了贪婪配对起作用的原因：每个返回 1 的子节点都强制选择一个边缘，并且切换可确保不会向上泄漏双重校正。
