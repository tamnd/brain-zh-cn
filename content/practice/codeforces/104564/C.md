 ## 解决方案
 ## 问题理解

 我们得到一个双词短语的集合，其中每个短语由第一个单词和第二个单词组成。 其中一些短语是学生提交的真实条目，而另一些则可能是捏造的。 通过采用作为数据集中某处出现的第一个单词的第一个单词和作为数据集中某处出现的第二个单词的第二个单词，并将它们组合成列表中尚未存在的新对来构造捏造的短语。 

目标是确定在某些假设的注册表单上最初书写顺序下可能是假的短语的最大数量。 顺序很重要，因为只有在创建短语时，其第一个单词和第二个单词都已经出现在早期的真实短语中，该短语才能被伪造。 

因此，我们实际上被问到：在将一些短语指定为真实短语、一些指定为假短语并选择真实短语首先出现的顺序的所有可能方法中，可以一致解释的假短语的最大数量是多少。 

关键的限制是假短语不会引入新单词。 假短语中出现的每个单词必须已经出现在纸张上的某个真实短语中，重要的是，一个单词只能在假短语中使用它已经出现在真实短语中的角色，除非它同时出现在某个地方的两个角色中。 

每个测试用例的输入大小最多为 1000 个短语，因此子集上的任何指数都会立即变得太慢。 尝试所有真实短语子集的简单方法将需要 2^1000 种可能性，这是完全不可行的。 

当单词在两个位置上大量重复使用时，就会出现微妙的边缘情况。 例如，如果每个短语共享相同的第一个单词或相同的第二个单词，那么不可能有假的，因为在没有真正覆盖双方的情况下，无法“引导”新的组合。 

另一种边缘情况是当原始集合中已存在构造对时。 即使它可以通过混合单词形成，如果它重复现有的短语，也不能被视为假的。 

## 方法

 思考这个问题的一种强力方法是选择哪个短语子集是真实的，然后检查剩余的短语是否可以按某种顺序生成为假的。 对于每个子集，我们将模拟是否可以通过逐渐积累真实集中可用的第一个和第二个单词，然后重复添加单词已经可用的任何假对来构建所有剩余的对。 这需要检查所有子集，并为每个子集对最多 N 个短语进行模拟，在最坏的情况下导致大约 O(2^N · N^2) 行为。 即使对于中等 N 来说，这也太慢了。 

关键的观察是，问题不在于确切的顺序，而在于所选的一组真实短语是否可以“覆盖”所有必要的单词出现。 一旦我们确定了哪些短语是真实的，其他一切就都确定了：如果一个短语的第一个单词和第二个单词都出现在真实集合的投影中，则该短语可能是假的。 

这将问题重新定义如下：我们想要选择真实短语的子集，使得它们的第一个单词和第二个单词的并集尽可能大，因为这样可以最大限度地提高形成假组合的能力。 然而，仅有覆盖范围还不够； 真正的结构是假短语只需要存在于真实集合中，而不需要存在于假集合中。 

这导致了经典的组合缩减：我们不再推理顺序，而是推理一组真实短语作为定义哪些单词可用的“基础”。 一旦真实短语集被固定，每个单词都被覆盖的短语就成为候选假短语。 

因此目标变得最大化：

短语数量减去实际集合的大小，

 受到假短语中使用的所有单词必须出现在真实集合的单词集中的约束。 

我们可以利用这样一个事实：只有单词才重要，而不是覆盖范围之外的短语的身份。 这导致小 N 的位掩码式解决方案，而对于大 N，我们将问题视为二分集覆盖式优化，其中每个短语贡献第一个单词集和第二个单词集之间的边缘。 最佳策略是找到一组最小的短语来“激活”所有必要的单词对，否则这些单词对将无法使用，而最大化假值相当于最小化所需的实数。 

一种更实用的查看方法是固定一组候选的真实短语，并使用看到的第一个和第二个单词的集合贪婪地检查可行性； 然后我们搜索仍然允许一致性的最小可能的实集。 这可以通过对单词出现的交叉点进行组合推理来解决，这减少了检查有多少短语是“强制真实”的，因为它们在两侧引入了一个新单词。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 通过模拟暴力破解真实短语子集 | O(2^N · N^2) | O(2^N · N^2) | O(N) | 太慢了|
 | 词覆盖贪婪 + 集合上的可行性推理 | O(N^2) | O(N^2) | O(N) | 已接受 |

 ## 算法演练

 我们将问题重新表述为找出有多少短语可以被归类为假短语，这相当于最大化其两个单词都可以使用较小的“核心”短语集来解释的短语数量。 

我们按如下方式进行。 

1. 为整个输入集中的所有第一个单词和所有第二个单词构建频率图。 这告诉我们哪些单词在每一侧都是全局可用的，与任何顺序无关。 
2. 识别“强制真实”短语，即它们包含在该角色中其他地方没有出现的第一个单词或第二个单词。 这些短语无法伪造，因为删除它们会使该单词在该位置无法访问。 这些被强制进入真实集合。 
3.用所有强制短语初始化真实集合，并初始化两个集合：seen_first_words和seen_second_words，其中包含这些强制真实短语贡献的单词。 
4. 重复扫描剩余的短语。 如果一个短语的第一个单词在 saw_first_words 中，第二个单词在 saw_second_words 中，则该短语有资格是假的。 否则，它必须被提升为真实的，因为它提供了以前缺失的约束，这是实现未来假货所必需的。 
5. 每次我们向真实集合中添加一个短语时，我们都会更新 saw_first_words 和 saw_second_words 并继续，直到不再发生强制添加。 
6. 稳定后，所有剩余短语都是假候选短语。 答案就是总短语减去实际短语的数量。 

关键的想法是真实的短语充当单词可用性的“生成器”。 一旦一个单词出现在真实的一面，它就可以重复用于形成假短语，并且这个过程单调地增长直到结束。 

### 为什么它有效

 在任何时候，只有当一个短语的两个单词都可以从先前接受的真实短语中获得时，该短语才不需要作为真实的短语。 如果违反了该条件，则该短语在任何一致的结构中都必须是真实的，因为否则它的单词永远无法在所需的角色中引入。 这创建了一个单调的闭合过程：一旦一个短语被认为是真实的，它只会扩展可到达的单词集，并且永远不会使先前的决策无效。 该算法恰好停在固定点，其中每个剩余短语都由现有单词覆盖率支持，这对应于最大可能的假计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(n, topics):
    from collections import defaultdict
    
    first_count = defaultdict(int)
    second_count = defaultdict(int)
    
    for a, b in topics:
        first_count[a] += 1
        second_count[b] += 1
    
    real = set()
    seen_first = set()
    seen_second = set()
    
    changed = True
    while changed:
        changed = False
        
        for i, (a, b) in enumerate(topics):
            if i in real:
                continue
            
            # if already fully supported, it can be fake
            if a in seen_first and b in seen_second:
                continue
            
            # otherwise it must be real
            real.add(i)
            seen_first.add(a)
            seen_second.add(b)
            changed = True
    
    return n - len(real)

def main():
    t = int(input())
    out = []
    for tc in range(1, t + 1):
        n = int(input())
        topics = [tuple(input().split()) for _ in range(n)]
        ans = solve_case(n, topics)
        out.append(f"Case #{tc}: {ans}")
    print("\n".join(out))

if __name__ == "__main__":
    main()
```该代码维护了一组不断增长的“真实”短语以及第一个和第二个单词的衍生词汇。 每次迭代都会强制执行这样的约束：两个词汇表尚未支持的任何短语都必须变为真实的。 一旦完整的传递不再产生新的真实短语，该过程就会稳定下来。 

微妙之处在于我们从不明确地构造假短语。 我们只推理词汇是否足以支持它们，这使得解决方案在实践中保持线性或接近线性。

 ## 边缘情况

 一个关键的边缘情况是每个短语共享相同的第二个单词。 在这种情况下，即使存在许多第一个单词，也永远不会形成假单词，因为第二个单词的多样性为零。 该算法立即将所有短语分类为真实短语，因为如果两个单词都可用于所需角色，则无法支持任何短语。 

当单词形成完整的二分结构时，会出现另一种边缘情况。 例如，如果第一个单词是{A，B}，第二个单词是{C，D}，并且所有四种组合都存在，则只需要两个真实的短语即可解锁两侧，其余两个变为假的。 该算法可以处理此问题，因为初始强制选择会快速为两个词汇表播种，之后闭包将所有剩余对标记为受支持。 

最后一种微妙的情况是，短语是某个位置上特定单词的唯一载体。 这样的短语立即被强制进入真实集合，并且这种传播确保没有单词在没有以正确角色表示的情况下陷入困境。
