 ## 解决方案
 ## 问题理解

 给定一组不同的整数，我们需要将它们分成两个子集，以便每个子集中所有对之间的最小异或尽可能大。 分区的值是两个子集成本中较小的一个。 每个元素必须恰好属于一个子集。 对于少于两个元素的集合，成本定义为$2^{30}$。 

输入大小可达$2 \times 10^5$整数，每个都小于$2^{30}$。 这意味着任何在集合上使用嵌套循环来计算所有对的异或的解决方案都将太慢。 对所有可能的分区进行暴力搜索，即$O(2^n)$，显然是不可能的。 甚至计算所有成对异或$O(n^2)$将达到$4 \times 10^{10}$操作处于上限。 

问题的微妙部分是 XOR 的行为就像二进制空间中的距离度量。 XOR 中的相邻数字可能在数字上不相邻，因此基于值排序的简单尝试可能会失败。 当某个子集只有一个元素时，会出现另一种边缘情况，在这种情况下，成本默认为$2^{30}$。 粗心的实现可能会忽略这一点并将其视为零。 

例如，给定`[0, 1, 2]`，分裂成`[0,1]`和`[2]`给出子集成本`1`和`2^30`。 两者中的最小值是 1。始终平衡子集大小的简单方法可能会选择`[0,2]`和`[1]`产生更差的最小值 1。算法必须考虑 XOR 结构，而不仅仅是计数。 

## 方法

 暴力解决方案是生成所有$2^n$分区，并通过迭代每个子集中的所有对来计算每个分区的成本。 这是正确的但不可行，因为$n = 2 \times 10^5$，分区的数量是天文数字，每次成本计算需要花费$O(n^2)$。 

最佳解决方案的关键在于以二进制形式解释整数。 集合中的 XOR 最小值由数字不同的最高位确定。 这表明采用递归分而治之的方法。 如果我们检查最高有效位，我们可以将数字分为两组：该位中包含 0 的组和包含 1 的组。为了最大化最小 XOR，我们必须仅在必要时才将不同分区中的数字配对。 如果任一组为空，则最佳分割发生在下一个较低位。 

递归继续向下进行，将每个数字分配给两个子集之一，同时确保同一子集中元素的 XOR 很大。 这相当于构造一个二叉树并在每个节点递归地分裂。 通过根据位分割分配编号来确定最佳分区。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(n) | 太慢了 |
 | 最佳 | O(n log MAX_BIT) | O(n log MAX_BIT) | 已接受 |

 ## 算法演练

 1. 将每个数字转换为其 30 位的二进制表示形式，因为数字小于$2^{30}$。 这使我们能够检查从最高有效位到最低有效位的位。 
2. 定义一个采用索引列表和位位置的递归函数。 如果位位置小于 0 或列表只有一个元素，则将所有剩余元素分配给一个子集并返回。 
3. 根据当前位将列表划分为两个子列表：一个子列表用于该位为 0 的元素，另一个子列表用于该位为 1 的元素。 
4. 如果两个子列表均非空，则在下一个较低位递归地拆分两个子列表。 如果子列表为空，则继续拆分非空子列表。 递归确保较高位不同的元素更有可能被分离，从而最大化每个子集中的最小 XOR。 
5. 回溯时，根据每个元素属于拆分的哪一侧，为每个元素分配子集标识符（0 或 1）。 一致地翻转标识符以维持子集划分。 
6. 所有递归完成后，将分区输出为 0 和 1 的字符串，对应于子集。 

工作原理：递归遵循最小异或由元素之间的最高差异位决定的属性。 通过尽早用不同的位分隔数字，我们可以避免在同一子集中创建小的 XOR 值。 这种每比特的贪婪选择是全局最优的，因为较高的位总是对 XOR 值贡献更多，而只有当较高的位相同时才考虑较低的位。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def xor_partition():
    n = int(input())
    a = list(map(int, input().split()))
    ans = [0] * n

    def solve(indices, bit):
        if bit < 0 or len(indices) <= 1:
            for i in indices:
                ans[i] = 0
            return
        zeros, ones = [], []
        for i in indices:
            if (a[i] >> bit) & 1:
                ones.append(i)
            else:
                zeros.append(i)
        if not zeros:
            solve(ones, bit - 1)
        elif not ones:
            solve(zeros, bit - 1)
        else:
            solve(zeros, bit - 1)
            for i in ones:
                ans[i] = 1
            solve(ones, bit - 1)

    solve(list(range(n)), 29)
    print(''.join(map(str, ans)))

xor_partition()
```该解决方案从增加递归限制开始，因为分而治之可以深入到大$n$。 递归函数根据当前位对索引进行分区。 0 或 1 的赋值是在递归时完成的。 如果分区的一侧为空，则算法将继续处理非空一侧。 否则，中的元素`ones`组被分配给子集 1，我们继续两边递归。 这确保了子集之间的异或在较高位处最大化。
