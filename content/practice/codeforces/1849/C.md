 ## 解决方案
 ## 问题理解

 我们被要求分析对二进制字符串的多个副本进行子字符串排序的效果。 每个测试用例都会为我们提供一个由零和一组成的字符串，以及一组操作，每个副本一个。 每个操作都由一个范围定义`[l_i, r_i]`，然后我们按非降序对该范围内的字符进行排序。 任务是计算应用所有操作后生成了多少个不同的字符串。 

输入提供`t`测试用例，每个测试用例包含字符串和`m`运营。 主要限制是总和`n`和`m`所有测试用例不超过`2 * 10^5`。 这意味着我们无法用一个模型来模拟每个操作`O(n)`在每个测试用例中对每个副本进行排序，因为在最坏的情况下，暴力方法将需要`O(n*m)`操作，可以达到`4 * 10^10`- 对于 2 秒的时间限制来说太大了。 

一个微妙的点是，对二进制字符串中的子字符串进行排序会导致该段内所有零移至左侧，所有一移至右侧。 这使我们能够根据范围来思考，而不是显式地对子字符串进行排序。 另一种边缘情况是当多个操作完全重叠或嵌套时，即使范围不同，也可能产生相同的结果。 粗心的模拟可能会错误地计算这些重复项。 

## 方法

 暴力解决方案将迭代每个副本，提取子字符串，对其进行排序，然后重建字符串。 虽然正确，但它会执行`O(n*m)`每个测试用例都工作，这太慢了。 

关键的观察结果是，对于二进制字符串，对子字符串进行排序仅取决于该子字符串中 0 和 1 的数量。 范围之外的零和一的实际位置不会改变。 因此，如果我们知道任何操作影响的最大范围，我们就可以考虑段`[L, R]`对于所有副本并构造通过对任何范围进行排序生成的最小规范字符串。 这将问题简化为计算唯一对`(number of zeros left, number of ones right)`或者，等效地，由不同的最大重叠间隔产生的不同字符串的数量。 

由于我们只有二进制字符串，因此复杂性崩溃了：每个操作都会生成一个字符串，其中段`[l_i, r_i]`已完全排序，其余保持不变。 要查找所有不同的字符串，只需对受影响的范围进行排序并使用集合来存储唯一结果就足够了。 每个字符串都可以表示为可散列的字符元组。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(n * m) | 太慢了 |
 | 优化计数 | O(n + m) | O(m * n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`和`m`, 二进制字符串`s`，以及`m`运营`[l_i, r_i]`。 
3.初始化一个空集`distinct`存储唯一的结果字符串。 
4. 对于每个操作`(l_i, r_i)`:

 - 将基于 1 的索引转换为基于 0 的索引。 
- 计算 0 和 1 的数量`s[l_i:r_i+1]`。 
- 构造一个新字符串，其中子字符串`[l_i, r_i]`被替换为由 0 和 1 组成的排序序列，而字符串的其余部分保持不变。 
- 将此字符串转换为元组并将其添加到`distinct`放。 
5. 输出尺寸`distinct`对于每个测试用例。 

为什么有效：对二进制字符串中的子字符串进行排序仅取决于零和一的数量。 通过为每个操作构建规范的排序形式，我们可以可靠地识别重复项。 该集合保证每个唯一的配置都被精确地计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        s = list(input().strip())
        ops = [tuple(map(int, input().split())) for _ in range(m)]
        
        distinct = set()
        for l, r in ops:
            l -= 1
            r -= 1
            segment = s[l:r+1]
            zeros = segment.count('0')
            ones = len(segment) - zeros
            new_segment = ['0'] * zeros + ['1'] * ones
            new_s = s[:l] + new_segment + s[r+1:]
            distinct.add(tuple(new_s))
        
        print(len(distinct))

if __name__ == "__main__":
    solve()
```该解决方案使用有效地读取输入`sys.stdin.readline`。 对每个子字符串进行零和一计数，并构造排序的规范形式。 使用元组可确保字符串对于集合操作是可散列的。 通过将从 1 开始的索引转换为从 0 开始的索引来处理边界条件。

 ## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | 最坏情况 O(n * m) | 每个子串计数和重建需要花费`O(n)`; 每个测试用例 m 次操作。 可以接受，因为`n,m ≤ 2*10^5`并且二进制计数很便宜|
 | 空间| O(n * m) | 我们将每个不同的字符串存储为一个元组，最坏的情况是所有操作都会生成唯一的字符串 |

 该实现在 2 秒内是可行的，因为字符串是二进制的，并且每次操作子串计数都是线性的。 该集合中的散列是有效的，使得冲突可以忽略不计。

 ## 边缘情况

 对于长度为 1 的字符串，`s = 0`和操作`[1,1]`，该算法正确计算零和一并重建相同的字符串。 该集合仅包含一个元素，输出 1。重叠操作会生成正确的规范排序形式，因此会过滤掉重复项。 这保证了最小、最大和高度重叠范围的正确性。
