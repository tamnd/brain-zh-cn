 ## 解决方案
 ## 问题理解

 我们总共得到$n$石头。 Georgiy 首先确定一堆尺寸$p$，然后根纳迪分割剩余的$N = n - p$将石头放入任何正整数堆大小的多重集合中。 

分割固定后，所有桩都参加 Nim 游戏，通过所有桩大小的 XOR 来确定获胜者。 Georgiy 首先行动，但一旦我们将游戏转化为标准 Nim 条件，这个细节就无关紧要了：当所有桩大小的 XOR 为零时，第一个玩家就输了。 

由于 Georgiy 已经贡献了一堆尺寸$p$，根纳迪获胜的条件变成了对其分区的纯粹约束。 如果我们将根纳迪的桩尺寸表示为$a_1, a_2, \dots, a_k$，则获胜条件为$$p \oplus a_1 \oplus a_2 \oplus \dots \oplus a_k = 0,$$这相当于$$a_1 \oplus a_2 \oplus \dots \oplus a_k = p.$$所以任务是纯粹的组合：计算有多少个无序分区$N = n - p$存在使得各部分的 XOR 等于$p$。 

限制条件$n \le 500$立即提出基于求和动态规划的解决方案。 困难不在于总和约束本身，而在于额外的 XOR 约束，它以一种阻止在简单分区 DP 中独立处理它们的方式耦合所有部分。 

一个简单的方法是枚举所有分区$N$。 即使是为了$N = 50$，分区数量已经有数万个，并且在$N = 500$它变得像天文数字一样大。 第二个天真的想法是通过 DP 计数独立处理每个堆大小，但 XOR 取决于非局部方式出现的奇偶校验。 

出现微妙的边缘情况时$p = 0$。 然后我们计算分区$N$其 XOR 为零。 另一个极端情况是$N = 0$，其中正好有一个“空分区”，其异或为零，所以答案是$1$如果$p = 0$， 否则$0$。 

## 方法

 暴力解决方案将生成所有正整数的多重集，总和为$N$，计算它们的异或，并计算那些等于$p$。 从概念上讲，这是可行的，因为每个分区都只被考虑一次，但分区的数量呈指数增长$\sqrt{N}$。 为了$N = 500$，这远远超出了任何可行的计算。 

关键的观察结果是 XOR 的行为与奇偶校验呈线性关系。 如果一个数字$k$出现$c_k$次，则其对 XOR 的贡献为：

 k \oplus k \oplus \dots \text{(c_k 次)} = \begin{cases} 0 & c_k \text{ 偶数} \\ k & c_k \text{ 奇数} \end{cases}

 因此，只有每个重数的奇偶性对于 XOR 来说很重要，而实际的重数对于总和约束仍然很重要。 

这建议分割每个值的贡献$k$分成两个独立的选择：“偶数份$k$”或“奇数份$k$”，额外的松弛由成对的贡献$k$，每对增加总和$2k$不改变异或。 

这将问题转化为分层背包，其中每个值$k$贡献无限数量的大小步数$2k$，并可选择通过添加一个额外的选项来切换 XOR$k$。 

我们维持 DP over sum 和 XOR 值。 每个步骤都会处理所有出现的固定的$k$，使用以下副本更新所有求和的方法$k$，同时跟踪是否总数$k$使用的是偶数或奇数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 枚举分区 | 指数| O(N) | 太慢了|
 | DP over sum 和 XOR 与奇偶校验分解 |$O(N^2 \cdot X)$|$O(N \cdot X)$| 已接受 |

 这里$X$是 XOR 值的范围，边界为$2^9 = 512$自从$p < 500$。 

## 算法演练

 我们定义一个 DP 状态，在其中跟踪使用到目前为止处理的堆大小与给定 XOR 形成给定和的方法有多少种。 

1.让$N = n - p$。 我们初始化一个DP表`dp[s][x]`，表示求和的方式数$s$与异或值$x$使用允许的桩尺寸的一些子集。 最初，`dp[0][0] = 1`。 
2. 我们迭代堆大小$k = 1$到$N$。 在每一步中，我们都会合并所有出现的大小$k$。 
3.对于固定的$k$，我们将结构分为两个概念组。 在第一组中，我们使用偶数个$k$的，仅贡献$2k$到总和并且没有异或变化。 在第二组中，我们使用奇数个$k$的，其行为类似于偶数情况，但有一个额外的强制$k$添加到总和并进行异或翻转$k$。 
4. 我们首先计算仅偶数个的转换$k$被使用。 这相当于一个无界的背包，里面有硬币$2k$，独立应用于每个 XOR 状态。 
5. 然后，我们通过采用偶数结果状态，将总和移位，对奇数情况重用相同的结构$k$，并通过切换异或$k$，然后再次允许任意数量$2k$除此之外还有补充。 
6.全部处理完毕后$k$，最终的答案是`dp[N][p]`，因为我们需要总和$N$XOR 等于 Georgiy 的堆。 

### 为什么它有效

 在每个阶段，每个整数$k$是独立处理的，并且每个有效的多重集都重要$k$唯一地表示为偶数基线加上一定数量的对，或者奇数基线加上一定数量的对。 对结构保证了总贡献被大小步长完全捕获$2k$，而 XOR 仅取决于基线是偶数还是奇数。 这种分离可确保不会遗漏任何配置，并且不会对任何配置进行两次计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, p, mod = map(int, input().split())
    N = n - p

    if N == 0:
        print(1 % mod if p == 0 else 0)
        return

    MAXX = 512

    dp = [[0] * MAXX for _ in range(N + 1)]
    dp[0][0] = 1

    for k in range(1, N + 1):
        # next DP starts as current dp (we will rebuild it)
        ndp = [[0] * MAXX for _ in range(N + 1)]

        for s in range(N + 1):
            for x in range(MAXX):
                val = dp[s][x]
                if not val:
                    continue

                # even contribution: add 0, 2k, 4k, ...
                t = s
                while t <= N:
                    ndp[t][x] = (ndp[t][x] + val) % mod
                    t += 2 * k

                # odd contribution: add k + 0, 2k, 4k, ...
                t = s + k
                x2 = x ^ k
                while t <= N:
                    ndp[t][x2] = (ndp[t][x2] + val) % mod
                    t += 2 * k

        dp = ndp

    print(dp[N][p] % mod)

if __name__ == "__main__":
    solve()
```该代码遵循顺序处理每个可能的堆大小的结构。 对于每个先前可到达的状态，它以以下步骤分配质量$2k$，对应于添加成对大小的桩$k$。 第二个循环处理至少一个的情况$k$使用，它翻转 XOR 并将总和移动$k$，之后仍可以自由添加其他对。 

总和、异或和步长上的嵌套循环是概念分解为偶数和奇数重数的直接实现。 

## 工作示例

 ### 示例 1

 输入：```
8 3 1000
```这里$N = 5$，目标异或为$p = 3$。 

我们只跟踪总和为 5 的状态。DP 逐渐构建 5 个分区，其中只有两个多重集产生等于 3 的 XOR：

 一个是$[3,1,1]$，另一个是$[2,1,1,1]$。 

最终相关状态的紧凑轨迹：

 | 总和 | 异或值 | 计数贡献 |
 | ---| ---| ---|
 | 5 | 3 | 2 |

 所以答案是2。 

### 示例 2

 输入：```
5 2 1000
```这里$N = 3$，目标异或为2。 

3 的所有分区是：$[3], [2,1], [1,1,1]$它们的异或值为：$3, 2 \oplus 1 = 3, 1 \oplus 1 \oplus 1 = 1$没有一个等于 2，所以答案是 0。 

这表明，即使当分区存在大量时，XOR约束也可以消除所有可能性。

 ## 边缘情况

 当$N = 0$，恰好有一种空的方式来形成桩。 DP正确初始化`dp[0][0] = 1`，并且由于没有发生任何转换，因此结果为 1 当且仅当$p = 0$，否则为 0。 

当$p = 0$，目标异或为零。 这种情况并没有简化DP结构，但是将最终的查找改为`dp[N][0]`，其中自然包括 XOR 在内部抵消的所有分区。 

什么时候$k > N$，没有过渡$k$贡献，因为无法形成尺寸大于剩余总和的堆。 循环结构自然会跳过这些贡献，因为所有`s + k`或者`s + 2k`超出界限。
