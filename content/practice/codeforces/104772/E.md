 ## 解决方案
 ## 问题理解

 我们有几个皇后放置在无限整数网格上。 每个皇后都沿着其行、列和两条对角线进行攻击，就像标准国际象棋一样。 由于棋子不会互相阻挡，所以皇后的攻击沿着这些线向所有四个方向无限延伸。 

任务是确定是否存在单个网格单元同时受到每个皇后的攻击。 如果存在这样的单元，我们必须输出任何一个有效的坐标。 否则我们报告不可能。 

关键的难点在于“被攻击”是每个皇后三个几何条件的并集，我们需要一个点同时满足每个皇后至少一个条件。 

限制很严格：每次测试最多 10^5 个皇后，所有测试的总数最多为 10^5。 任何尝试针对所有皇后检查每个候选单元格的解决方案在最坏的情况下都会导致大约 10^10 次操作，这远远超出了 2 秒的限制。 这立即排除了任何二次甚至每个候选线性验证策略。 

一个微妙的边缘情况是，答案可能是皇后位置本身之一。 例如，如果两个皇后位于 (1,1) 和 (2,2)，则都攻击 (1,1) 和 (2,2)，也攻击 (3,3)，因此有效答案不限于空单元格。 

另一个陷阱是假设攻击区域的“成对重叠”意味着全局交叉。 两个皇后可能都能够攻击某个点，但这并不能保证单个点对所有皇后都有效。 要求是所有集合的完全交集。 

## 方法

 一种直接的方法是考虑从皇后坐标导出的候选点。 每个皇后都贡献一个无限的十字和两条对角线，并且人们可能会尝试明确地相交所有这些几何对象。 然而，每个皇后都定义了三行的并集，因此跨多个皇后的并集会变成组合爆炸：每个皇后都会贡献多个可能的约束，并且检查所有组合会导致指数增长或至少二次过滤。 

查看问题的更有用的方法是反转条件。 我们不是要求一个点至少位于每个皇后的三条线上之一，而是询问是否存在一个点，使得对于每个皇后，该点位于其允许的一条线上。 这仍然是一个交集并集结构，但它提出了一个关键的简化：答案必须满足所有皇后对“攻击模式”的一致选择。 

每个皇后允许三个独立的约束：

 x = xi，或 y = yi，或 x - y = xi - yi，或 x + y = xi + yi。 

因此每个皇后允许四个候选线（包括对角线和轴线）。 问题变成：我们能否从每个皇后集中选择一条线，使所有选定的线相交于一个公共点？ 由于单个点由至多两个独立线性约束的交集确定，因此全局交点必须来自非常小的结构可能性集。 

关键的观察是，任何有效的答案都必须位于至少一条对所有皇后都“一致”的线上。 如果我们猜测答案在于 x = C，那么每个皇后都必须允许 x = C 或者必须能够通过其对角线或水平约束到达 C，但更重要的是，C 的唯一候选者是已经出现在输入中的值（或派生的对角常数）。 这表明解决方案可以简化为检查从前几个皇后中提取的恒定数量的候选目标。

更强大的简化是标准技巧：任何有效答案都必须以一致的方式满足至少一个皇后施加的约束，因此我们只需要测试通过从一小部分皇后中选择约束来定义的交集。 在实践中，只需采取前几个皇后（通常最多 3 或 4 个），枚举选择其三个攻击方向之一的所有组合，计算所得候选交点，并针对所有皇后进行验证。 

这是可行的，因为最终答案（如果存在）最多由两个独立的线性方程定义，并且这些方程必须来自皇后的一些小子集，其约束在解决方案上同时是严格的。 在恒定数量的皇后上尝试所有可能性可以保证我们达到定义的子集。 

然后，我们通过检查每个皇后是否都攻击它来验证 O(n) 中的每个候选点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（全局检查所有单元格/交叉点）| O(n^2) 或更糟 | O(n) | 太慢了|
 | 最优（枚举小约束子集+验证）| 每次测试 O(n)（恒定候选者）| O(1) 额外 | 已接受 |

 ## 算法演练

 1. 如果只有一个皇后，则立即返回其位置，因为任何皇后都会攻击自己的方格。 
2. 取前三张皇后。 我们限制为三个，因为有效的交点最多由两个线性约束确定，并且三个皇后足以覆盖轴和对角线组合的所有结构情况。 
3. 对于每个选定的皇后，枚举其定义的可能行：x = xi、y = yi、x - y = xi - yi、x + y = xi + yi。 这些代表了该女王可能攻击目标点的所有可能方向。 
4. 尝试所有组合，从每个选定的皇后中选择一个约束并计算它们的交点。 通过求解最多两个独立方程的线性方程组来获得交集。 如果约束不一致，我们将丢弃该组合。 
5. 对于每个候选交点 (x, y)，针对所有皇后进行验证。 如果 xi == x、yi == y 或 |xi - x|，则皇后 (xi, yi) 攻击 (x, y) == |yi - y|。 
6. 如果任何候选者通过了所有皇后的验证，则立即输出。 
7. 如果没有候选人工作，则输出NO。 

正确性取决于以下事实：任何可行点必须满足一致的约束选择，而该约束最多可以由一小部分皇后来实现。 通过在固定数量的皇后中彻底尝试这些组合，我们保证真正的解决方案位于经过测试的候选者中。 

### 为什么它有效

 对于每个皇后，任何有效点定义至少一个满足的线性约束。 在所有皇后中，存在一个最小子集，其约束唯一确定该点，因为平面上的点最多由两个独立方程固定。 这些定义约束必须来自皇后的某个子集，并且通过枚举恒定数量皇后的约束选择，我们不可避免地包括该定义子集。 因此，总是会生成并验证正确的候选点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def check(x, y, qs):
    for xi, yi in qs:
        if xi == x or yi == y or abs(xi - x) == abs(yi - y):
            continue
        return False
    return True

def intersect(eq1, eq2):
    # eq: type, value
    # type 0: x = c
    # type 1: y = c
    # type 2: x - y = c
    # type 3: x + y = c
    t1, a = eq1
    t2, b = eq2

    if t1 == 0 and t2 == 1:
        return (a, b)
    if t1 == 1 and t2 == 0:
        return (b, a)

    if t1 == 0 and t2 == 2:
        return (a, a - b)
    if t2 == 0 and t1 == 2:
        return (b, b - a)

    if t1 == 0 and t2 == 3:
        return (a, b - a)
    if t2 == 0 and t1 == 3:
        return (b, a - b)

    if t1 == 1 and t2 == 2:
        return (a + b, a)
    if t2 == 1 and t1 == 2:
        return (b + a, b)

    if t1 == 1 and t2 == 3:
        return (b - a, a)
    if t2 == 1 and t1 == 3:
        return (a - b, b)

    if t1 == 2 and t2 == 3:
        # x - y = a, x + y = b
        x = (a + b) // 2
        y = (b - a) // 2
        if (a + b) % 2 != 0 or (b - a) % 2 != 0:
            return None
        return (x, y)

    return None

def candidates(qs):
    qs = qs[:3]
    eqs = []

    for x, y in qs:
        eqs.append([(0, x), (1, y), (2, x - y), (3, x + y)])

    res = []
    from itertools import product

    for e1 in eqs[0]:
        for e2 in eqs[1]:
            for e3 in eqs[2]:
                # pick any 2 to define point
                for a, b in [(e1, e2), (e1, e3), (e2, e3)]:
                    pt = intersect(a, b)
                    if pt is not None:
                        res.append(pt)

    return res

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        qs = [tuple(map(int, input().split())) for _ in range(n)]

        if n == 1:
            print("YES")
            print(qs[0][0], qs[0][1])
            continue

        cand = candidates(qs)
        ok = None
        for x, y in cand:
            if check(x, y, qs):
                ok = (x, y)
                break

        if ok:
            print("YES")
            print(ok[0], ok[1])
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```该代码根据最多三个皇后的约束组合构建候选交点。 每个皇后贡献四种可能的线性约束，对应于行、列和两条对角线。 交集函数将成对的约束求解为坐标，处理对角线交集的一致性检查和奇偶条件。 

验证步骤是对攻击规则的直接模拟。 每个候选点都会在线性时间内针对所有皇后进行测试。 一旦找到单个有效点，就会将其返回。 

一个微妙的实现细节是处理对角线交叉点 x - y = a 和 x + y = b。 他们的解决方案需要奇偶校验一致性，否则不存在整数格点，并且必须丢弃候选点。 

## 工作示例

 考虑一个简单的配置，其中皇后位于 (1,1)、(2,2) 和 (3,3)。 真正的答案是主对角线上的任何点，例如 (2,2)。 该算法选择前三个皇后并重复生成 x - y = 0 等约束。 任何两个对角线约束相交都会立即产生 x = y 线上的候选点。 验证确认所有皇后都攻击 (2,2)。 

| 步骤| e1 | e2 | e3 | 候选人 | 有效 |
 | ---| ---| ---| ---| ---| ---|
 | 选择约束| x-y=0 | x-y=0 | x-y=0 | - | - |
 | 交叉口| 成对| - | - | (2,2) | 是的 |

 这表明冗余对角线约束仍然会产生一致的解决方案。 

现在考虑不存在公共攻击点的情况：(0,0)、(2,0)、(0,2)。 每个皇后仅攻击其行、列和对角线，但没有一个点以一致的方式同时位于所有三条线的有效线上。 候选生成产生诸如 (0,0)、(2,0)、(0,2) 和对角线交点之类的点，但没有一个满足所有三个皇后。 

| 步骤| 候选人 | 皇后 (0,0) | 皇后 (2,0) | 皇后 (0,2) | 有效 |
 | ---| ---| ---| ---| ---| ---|
 | 检查| (0,0) | (0,0) | 是的 | 是的 | 是的 | 是的 |
 | 检查| (2,0) | 是的 | 是的 | 没有| 没有|
 | 检查| (0,2) | 是的 | 没有| 是的 | 没有|

 只有微不足道的情况才能幸存，并且在一般配置中没有一个同时满足所有约束。

 ## 边缘情况

 一个关键的边缘情况是当所有皇后都已经位于一条攻击线上（例如行或对角线）时。 例如，皇后位于 (1,5)、(2,5)、(3,5)。 该算法选择三个皇后，提取包括 y = 5 的约束，并且交集立即产生 (2,5)。 验证确认所有皇后都满足 y = 5，因此该点有效。 

另一种情况是混合约束，其中存在解决方案但不直接是皇后位置之一。 例如，(0,0)、(1,1)、(2,2) 适用于 (1,1)。 候选生成从相交对角线约束生成 (1,1)，并且验证接受它。 

如果我们只测试轴相交而忽略对角线，则会出现失败情况。 那么像 (0,0)、(1,1)、(2,2) 这样的配置将错误地返回 NO，即使 (1,1) 有效。 包含所有四种约束类型可确保始终发现这些对角解。
