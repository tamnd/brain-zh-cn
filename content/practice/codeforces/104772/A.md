 ## 解决方案
 ## 问题理解

 我们得到了 2D 平面上的点的集合。 每个点代表一个具有整数坐标的位置。 任务是将所有这些点放在一起，并确定其边与坐标轴平行且包含每个点的最小矩形的面积。 

更具体地说，想象一下拉伸与 x 和 y 方向对齐的橡皮筋，使其包围所有给定的点。 由最左、最右、最下、最上位置形成的矩形定义了我们关心的区域。 输出是该矩形的面积。 

如果所有点都位于一条垂直或水平线上，则矩形会向一个方向折叠，并且面积变为零。 

约束足够小，我们只需要扫描所有点一次或两次。 即使点的数量很大，例如多达 200,000 个，任何每个点执行恒定工作量的解决方案就足够了。 这立即排除了任何尝试检查点对或构造凸包等几何结构的方法，因为这些方法至少会引入二次或对数线性开销，而这对于轴对齐外壳来说是不必要的。 

一些边缘情况对于正确性很重要。 如果只有一个点，则面积必须为零，因为宽度和高度都为零。 如果所有点共享相同的 x 坐标，则无论 y 变化如何，宽度都为零。 类似地，如果全部共享相同的 y 坐标，则高度为零。 

作为具体的故障案例，请考虑点 (0, 0)、(0, 5)、(0, 10)。 错误地假设非退化矩形的简单方法可能仅基于 y 范围返回正面积，但正确的宽度为零，因此面积为零。 

另一个微妙的情况是出现负坐标时，例如 (-3, 2)、(4, -1)、(-2, 7)。 任何错误初始化 min 和 max 的解决方案（例如从 0 而不是第一个点开始）都可能计算出错误的边界框。 

## 方法

 蛮力的想法是考虑每对点并将它们视为候选轴对齐矩形的对角。 对于每一对这样的点，我们将检查所有其他点是否位于矩形内部或边界上，并计算其面积。 这是有效的，因为任何有效的封闭矩形都必须具有由某些点子集定义的边界。 

然而，这种方法在最坏的情况下执行 O(n^3) 操作：O(n^2) 个候选矩形，对于每个候选矩形，我们扫描 O(n) 个点来验证包含性。 即使有像 n = 10^4 这样的适度约束，这也是不可行的。 

关键的观察结果是，轴对齐的封闭矩形完全仅由四个值确定：所有点之间的最小 x 坐标、最大 x 坐标、最小 y 坐标和最大 y 坐标。 一旦知道了这些极端情况，关于分数分布的其他信息就不再重要了。 

这将问题从对的组合搜索减少为单遍聚合问题。 我们只需在扫描一次输入时跟踪这四个值即可。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 太慢了 |
 | 最佳（最小/最大扫描）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

1、一一读取所有点，同时维护四个变量：min_x、max_x、min_y、max_y。 这些跟踪到目前为止看到的边界框。 
2. 将 min_x 和 min_y 初始化为非常大的值，将 max_x 和 max_y 初始化为非常小的值。 这可确保第一个点正确设置所有边界，而无需特殊的大小写。 
3. 对于每个点 (x, y)，更新 min_x = min(min_x, x)、max_x = max(max_x, x)，对于 y 也类似。 随着新极端的发现，此步骤逐渐扩大边界矩形。 
4. 处理完所有点后，将宽度计算为 max_x - min_x，将高度计算为 max_y - min_y。 这些代表点集沿每个轴的完整跨度。 
5. 将宽度和高度相乘以获得最终面积。 
6. 直接输出结果。 

每次更新正确的原因是任何有效的封闭轴对齐矩形必须具有位于极值点或超出极值点的边界。 任何具有较小边界的候选矩形将排除至少一个点，并且对于最小包围体来说任何较大的矩形都是不必要的。 

### 为什么它有效

 在输入的每个前缀处，变量 min_x、max_x、min_y 和 max_y 表示迄今为止处理的点的精确边界框。 当新点到达时，只有这四个值可能会改变外壳。 由于最终的矩形仅取决于全局极值，因此增量维护这些值可以保证在最后一个点之后，我们拥有包含所有点的精确最小轴对齐矩形。 任何内部点的配置都不能在不违反包含极值点的情况下改变边界。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    min_x = float('inf')
    max_x = float('-inf')
    min_y = float('inf')
    max_y = float('-inf')
    
    for _ in range(n):
        x, y = map(int, input().split())
        if x < min_x:
            min_x = x
        if x > max_x:
            max_x = x
        if y < min_y:
            min_y = y
        if y > max_y:
            max_y = y
    
    width = max_x - min_x
    height = max_y - min_y
    print(width * height)

if __name__ == "__main__":
    solve()
```该实现保持逻辑严格流式传输，因此它从不存储所有点。 使用无穷大的初始化避免了第一个点的特殊情况，并防止坐标为负时出现错误。 

即使所有点都相同，减法步骤也是安全的，因为宽度和高度都为零。

 ## 边缘情况

 单点输入同时设置最小值和最大值，因此宽度和高度在整个执行过程中都保持为零，从而产生区域零而无需任何特殊分支。 

当所有点都位于垂直线上时，例如每个点的 x = 2，max_x 和 min_x 保持相等，因此宽度为零。 该算法仍然正确更新 y 边界，但最终的乘法将该面积压缩为零。 

当所有点都位于水平线上时，会出现对称行为，高度为零。 

对于负坐标，用无穷大进行初始化可确保第一次比较正确捕获实际值。 例如，从 (−3, 2) 开始，立即将 min_x 和 max_x 设置为 −3，将 max_y 设置为 2，从而防止在初始化使用零时出现任何不正确的偏差。
