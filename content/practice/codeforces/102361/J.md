 ## 解决方案
 ## 问题理解

 只有小数点后的数字才重要。 令小数部分的长度为 (n)。 候选重复部分必须是观察到的小数位的后缀，因为重复必须在 Sumika 测量的最后继续。 

假设候选后缀总共出现了 (p) 个数字，包括重复块的可能不完整的最终副本，并且其最短的有效重复块的长度为 (l)。 其可靠性为

 [
 a p-b l。 
]

 对于固定的 (p)，第一项 (ap) 已经确定。 由于 (b>0)，结束于该位置的最佳候选始终是具有最小可能周期 (l) 的候选。 因此，问题是为每个后缀长度 (p) 找到该后缀的最短周期。 

小数部分最多可包含 (10^7) 位数字。 检查所有后缀长度和句点长度对的算法在这种规模下已经太大了。 即使 (O(n^2)) 工作也意味着最大尺寸下大约 (10^{14}) 次迭代，而 (O(n^3)) 字符比较实现可以达到大约

 [
 \sum_{p=1}^{n}\frac{p(p-1)}2
 =\frac{n(n+1)(n-1)}6
 ]

 字符比较，当（n=10^7）时，大约为（1.67\times10^{20}）。 我们需要一个线性时间字符串算法，而且我们也只需要线性内存。 

有几种边界情况可能会使看似正确的实现失败。 答案可能是否定的。 例如，与```
1 2
0.5
```唯一可能的重复部分是 (p=1,l=1)，所以答案是 (-1)。 将答案初始化为零会错误地产生零。 

整数部分必须完全忽略。 例如，```
5 3
123.1020
```与样本的答案完全相同`1.1020`，即`9`。 处理整个字符串的实现会构建错误的周期。 

最后的重复允许不完整。 为了```
2 1
0.102
```反转的小数串是`201`。 其长度为 3 的前缀具有最短周期 2，因此 (p=3,l=2)，给出 (6-2=4)。 将候选者限制在划分观察长度的时间段内会错过这种候选者。 

长度一的小数部分也是有效的。 为了```
7 10
42.8
```只有 (p=l=1)，所以答案是 (-3)。 这可以捕获单字符边界和否定答案。 

## 方法

 直接的解决方案是枚举每个可能的后缀长度 (p)。 对于每个后缀，它将尝试所有可能的重复长度 (l)，检查距离 (l) 处的字符是否在整个后缀中一致。 如果检查成功，则候选者具有可靠性 (ap-bl)，并且由于 (b) 为正，我们可以保留该后缀的最小有效值 (l)。 

这是正确的，因为每个合法的重复部分都是某个后缀的句点，并且检查所有可能的 (l) 会检查每个合法的选择。 问题在于重复字符串比较的数量。 对于长度为 (p) 的后缀，测试所有候选长度可能需要 (\Theta(p^2)) 字符比较，在最坏的情况下总体给出 (\Theta(n^3))。 即使子字符串比较被优化到足以使每次检查的时间恒定，简单地检查每对 ((p,l)) 仍然是 (O(n^2))，这对于 (10^7) 个字符来说太大了。 

有用的观察是每个候选者都是原始分数字符串的后缀。 反转小数字符串。 原始字符串中长度为 (p) 的后缀在反转后的字符串中变为长度为 (p) 的前缀。 因此，我们将问题转化为寻找每个前缀的最短周期。 

这正是KMP前缀功能提供的信息。 对于长度为 (p) 的前缀，令其前缀函数值为 (k)，即其最长的固有前缀（也是后缀）的长度。 长度为 (k) 的边界意味着前 (k) 个字符和后 (k) 个字符重合。 这两个相等区域之间的距离是(p-k)，并且该距离是前缀的周期。 由于 (k) 是最长的可能边界，因此 (p-k) 是最短的可能周期。 

因此，如果反转的小数串是 (t) 且其前缀函数是 (\pi)，则对于每个前缀长度 (p)，

 [
 l=p-\pi[p-1]。 
]

 出现的长度简单为(p)，因此其最佳可靠性为

 [
 a p-b(p-\pi[p-1])。 
]

 我们在构建 KMP 前缀函数时为每个前缀计算此值。 

暴力方法之所以有效，是因为它明确地测试了每个可能的句点，但会失败，因为重复比较相同的字符以查找密切相关的后缀。 逆向将所有相关后缀转换为前缀，KMP 重用连续前缀之间的边界信息，将整个问题减少到线性时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(n^3)) 直接周期检查 | (O(n)) | (O(n)) | 太慢了 |
 | 最佳| (O(n)) | (O(n)) | (O(n)) | (O(n)) | 已接受 |

 ## 算法演练

 1. 读取(a)、(b)和小数字符串，然后丢弃小数点以下的所有内容。 整数部分在可靠性计算中没有作用，因此保留它只会浪费内存并使字符串处理变得复杂。 
2. 将小数位反转。 候选重复部分必须到达原始观察字符串的末尾，因此每个候选对应一个后缀。 反转后，该后缀成为前缀，这正是 prefix 函数处理的形式。 
3. 为反转小数字符串分配 KMP 前缀函数数组。 对于位置 (i)，设 (\pi[i]) 为`t[:i+1]`这也是它的后缀。 
4. 使用标准 KMP 回退规则构建前缀函数。 当下一个字符与当前边框不匹配时，重复将边框长度 (j) 替换为 (\pi[j-1])。 这些回退会跳过已知比较失败的整组字符。 
5. 对于每个以位置 (i) 结尾的前缀，设置 (p=i+1)。 其最长边界的长度为 (\pi[i])，因此其最短周期为

 [
 l=p-\pi[i]。 
]

 给出最短有效重复部分的原因是边界周期关系。 长度为 (k) 的边界使字符串在 (p-k) 个位置后重复，并且最长的边界产生最小的此类距离。 

1. 计算

 [
 a p-b l
 ]

 对于这个前缀并更新最大值。 由于 (p) 从 1 增加到整个分数长度，因此每个可能出现的长度都被考虑一次。 

1. 输出最大值。 答案必须使用第一个候选值 (a-b) 进行初始化，而不是零，因为所有可靠性值都可能为负数。 

### 为什么它有效

 考虑原始小数字符串中任何合法的重复部分。 因为它在末尾仍然重复，所以出现的所有数字都形成了小数字符串的某些后缀。 让该后缀包含 (p) 位数字。 将小数串反转后，相同的字符形成长度为（p）的前缀。 

对于这个前缀，每个有效的重复块长度都是前缀的一个周期。 如果其最长边界的长度为(k)，则(p-k)是一个句点。 由于没有边界可以比 (k) 长，因此没有周期可以比 (p-k) 短。 因此，KMP 值恰好给出了该固定 (p) 的最小可能值 (l)。 

对于固定的 (p)，可靠性为 (ap-bl)，并且 (b) 为正。 (l) 越小，可靠性越高。 因此，仅考虑 (l=p-\pi[p-1]) 不会丢失最佳候选。 由于检查了每个可能的 (p)，因此算法找到的最大值是所有合法重复部分的最大可靠性。 

## Python 解决方案```python
import sys
from array import array

input = sys.stdin.readline

def solve():
    a, b = map(int, input().split())
    s = input().strip()

    # Only the fractional part matters.
    frac = s.split('.', 1)[1]
    n = len(frac)

    # A signed 32-bit integer is enough for every prefix-function value.
    # Using array instead of a Python list keeps memory close to O(n) bytes
    # rather than O(n) Python objects.
    pi = array('i', [0]) * n

    if n == 0:
        print(a - b)
        return

    # Prefix of length 1: p = 1, l = 1.
    ans = a - b

    # We need suffixes of frac, so process the reversed string.
    t = frac[::-1]

    j = 0
    for i in range(1, n):
        while j > 0 and t[i] != t[j]:
            j = pi[j - 1]

        if t[i] == t[j]:
            j += 1

        pi[i] = j

        p = i + 1
        l = p - j
        value = a * p - b * l

        if value > ans:
            ans = value

    print(ans)

if __name__ == "__main__":
    solve()
```第一输入行提供 (a) 和 (b)，而第二行包含完整的观察到的小数。`split('.', 1)[1]`精确提取小数部分，因此小数点之前的数字永远不会参与 KMP。 

反转的字符串`t`之所以创建，是因为相关候选数字是原始小数位的后缀。 索引处的前缀函数值`i`描述长度的前缀`i+1`，它对应于原始方向上完全相同长度的后缀。 

这`pi`数组使用四字节有符号整数。 每个前缀函数值最多为 (n) 和 (n\le10^7)，因此 32 位有符号整数就足够了。 这种选择在 Python 中很重要，因为一千万个 Python 整数的普通列表可能会消耗数百兆字节，而类型化数组会紧凑地存储相同的值。 

KMP 循环开始于`i = 1`because the first character always has prefix-function value zero. 变量`j`是当前的边框长度。 在不匹配的情况下，`j = pi[j - 1]`跳转到下一个较小的边界，而不是从头开始比较。 

After computing`pi[i]`，前缀长度为`p = i + 1`。 最短周期为`p - pi[i]`，因此可靠性是直接根据这两个值计算的。 减法顺序很重要，因为 (a p-b l) 可能为负数。 

Python integers have arbitrary precision, so there is no overflow concern in the implementation. 然而，在 C++ 解决方案中，乘积大约可以达到 (10^{16})，因此`long long`是必须的。 

KMP 后备循环看起来嵌套在主循环内，但其总体工作仍然是线性的。 每一次成功的角色匹配都会增加`j`，而每个回退都严格减少`j`。 在整个计算过程中，回退操作的数量受到增加数量的限制，从而给出 (O(n)) 总工作量。 

## 工作示例

 ### 示例 1

 小数部分是`1020`。 反转它给出`0201`。 

| 前缀长度 (p) | 前缀 | (\pi[p-1]) | 周期 (l=p-\pi[p-1]) | 可靠性（5p-3l）| 迄今为止最好的|
 | --- | --- | --- | --- | --- | --- |
 | 1 |`0`| 0 | 1 | 2 | 2 |
 | 2 |`02`| 0 | 2 | 4 | 4 |
 | 3 |`020`| 1 | 2 | 9 | 9 |
 | 4 |`0201`| 0 | 4 | 8 | 9 |

 前缀长度为三时，`020`有边框`0`长度为一。 从前缀长度中删除该边界得到句点 (3-1=2)。 倒退对应原来的后缀`020`，其重复块是`02`，出现三位数。 其可靠性为(5\cdot3-3\cdot2=9)，为最优。 

关键点是，最佳候选不一定是完整的重复次数。 前缀`020`包括`02`后跟第一个字符`0`另一个副本。 允许部分最终副本。 

### 示例 2

 小数部分是`1212`，所以反转后的字符串是`2121`。 

| 前缀长度 (p) | 前缀 | (\pi[p-1]) | 周期 (l=p-\pi[p-1]) | 可靠性 (2p-l) | 迄今为止最好的|
 | --- | --- | --- | --- | --- | --- |
 | 1 |`2`| 0 | 1 | 1 | 1 |
 | 2 |`21`| 0 | 2 | 2 | 2 |
 | 3 |`212`| 1 | 2 | 4 | 4 |
 | 4 |`2121`| 2 | 2 | 6 | 6 |

 对于完整的前缀`2121`，最长的边界是`21`，长度为二。 因此最短周期是(4-2=2)。 在原始方向上，这对应于重复部分`12`，它出现在所有四个观察到的数字中。 其可靠性为(2\cdot4-1\cdot2=6)。 

该跟踪还说明了为什么仅检查没有部分重复的前缀是不够的。 长度为 3 的前缀有句点 2，尽管 3 不能被 2 整除。

## 边缘情况

 对于否定答案，请考虑```
1 2
0.5
```小数串的长度为 1，因此反转后的字符串也是`5`。 它的前缀函数值为零，给出 (p=1) 和 (l=1)。 唯一的可靠性是 (1\cdot1-2\cdot1=-1)。 该算法开始于`ans = a - b`，因此它保留了这个负结果，而不是意外地将其替换为零。 

对于单个小数位，请考虑```
7 10
42.8
```该算法提取`8`，将其反转为`8`，并且除了初始前缀之外没有 KMP 迭代。 周期为 1，可靠性为 (7-10=-3)。 这里没有隐藏特殊的字符串模式情况，因此普通初始化已经处理最小的有效输入。 

对于不完整的最终重复，请考虑```
2 1
0.121
```小数串是`121`，并且反转给出`121`。 前缀函数值为 (0,0,1)。 在 (p=3) 处，最长边界的长度为 1，因此 (l=3-1=2)。 候选人是原来的后缀`121`，解释为周期`12`接下来是第一个数字`1`。 其可靠性为(2\cdot3-1\cdot2=4)。 要求 (p) 是 (l) 倍数的解决方案将错误地丢弃该候选。 

对于整数部分边界，考虑```
5 3
987654321.1020
```小数点后，算法准确地看到`1020`，产生相同的反转字符串`0201`以及与第一个样本相同的四个候选者。 最大剩余量`9`。 这证实整数部分不会影响 (p)、(l) 或可靠性。 

对于重复的数字，请考虑```
2 1
0.1111
```反转后的字符串仍然是`1111`。 它的前缀函数值为(0,1,2,3)，因此对于完整前缀(p=4)，最短周期为(4-3=1)。 可靠性为 (2\cdot4-1=7)，胜过所有较短的前缀。 这个案例练习了 KMP 边界的长链，并确认后备结构可以处理最大重复，而不会退化为二次工作。
