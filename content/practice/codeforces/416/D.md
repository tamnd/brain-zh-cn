 ## 解决方案
 ## 问题理解

 我们给定一个长度序列$n$，其中每个位置要么是固定的正整数，要么是未知的（标记为$-1$）。 任务是将这个数列解释为由几个算术级数依次连接而成的。 在每个段内，连续元素必须相差一个常量值，并且段不能重叠。 

未知位置可以用我们选择的任何正整数填充，只要所有已知值保持不变。 目标是选择这些填充并将生成的完整序列拆分为尽可能少的算术级数段。 

所以真正决定的不仅仅是在哪里拆分，还有如何赋值$-1$以避免强制额外拆分的方式进行条目。 

约束条件$n \le 2 \cdot 10^5$立即排除任何试图明确考虑所有分段的行为。 所有段端点上的二次或更差的 DP 会太慢，因为$O(n^2)$转变将超出可接受的限度几个数量级。 解决方案必须是线性或近线性的，每个位置只有局部决策。 

一个微妙的困难来自于如何$-1$相互作用具有一致性。 一种幼稚的方法可能会在可能的情况下尝试贪婪地扩展一段，但单个已知值可能会追溯性地产生矛盾。 

例如，考虑如下模式：```
3 5 -1 9
```如果我们假设差异为 +2，则缺失值将变为 7，并且一切都是一致的。 但如果我们有：```
3 5 -1 10
```相同的假设差异在最后一个位置中断。 不检查未来约束的贪婪扩展可能会失败。 

另一种边缘情况是长度为 1 的段隐式出现。 被未知包围的单个已知值可能会以多种不兼容的方式扩展，并且不正确的贪婪选择可能会人为地增加段计数。 

关键的困难在于必须对序列进行分区，同时选择与每个段中所有固定点一致的差异。 

## 方法

 暴力方法会尝试一切可能的方法将数组划分为段，并针对每个段尝试检查是否可以将值分配给$-1$因此所有固定值都位于单个算术级数上。 

对于一个段$[l, r]$，检查可行性涉及从两个已知值推导公差或验证所有已知值的一致性。 通过预计算，每次检查都是$O(1)$，但是分区的数量是指数级的，大致$2^{n-1}$，即使对于$n = 50$。 

一个更加结构化的 DP 将定义$dp[i]$作为覆盖前缀的最小段数$1..i$，并尝试所有先前的分割点。 这给出了$O(n^2)$过渡。 即使对每个段进行恒定时间的可行性检查，这对于$2 \cdot 10^5$。 

关键的观察是，在任何有效段内，一旦确定了差异，每个下一个值都会被强制，除非它是$-1$。 这意味着我们可以在一致性允许的范围内贪婪地扩展一个段，并且只有在一致性破坏时才重新启动。 

唯一真正的复杂之处是事先不知道段的差异。 然而，一旦我们遇到段中的前两个固定值，它就会被确定。 从那时起，每个后续的固定值要么同意要么强制削减。 

这将问题简化为从左到右扫描，同时保持当前段的隐含算术结构。

 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n)$|$O(n)$| 太慢了 |
 | 最佳|$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 我们从左到右处理数组，维护当前段及其隐含的算术级数。 

1. 在位置1开始一个新的段。我们还不知道它的共同点。 
2. 继续前进，直到遇到第一对允许我们定义差异的已知值。 如果到目前为止该段的固定点少于两个，则差异保持未定义并且该段可以自由适应。 
3. 一旦我们在同一段内看到两个固定值，我们就计算所需的差值$d$。 这完全锁定了段的结构。 
4. 继续扫描。 对于每个新职位：

 - 如果该值为$-1$，它总是一致的并且不限制任何东西。 
- 如果已知，我们检查它是否与当前段隐含的预期值匹配。 

如果不匹配，则该段必须在此位置之前结束。 
5. 当发生不匹配时，我们增加段计数并从当前位置重新开始一个新段。 新的段再次开始，没有固定的差异。 
6. 继续直到数组末尾。 

一个微妙的问题是我们如何处理没有差异的初始阶段。 在该阶段，任何分配给$-1$可以选择保持一致性，因此我们永远不会强制分裂，除非已知值与已经建立的级数相矛盾。 

### 为什么它有效

 每个段在其内部所有固定值必须符合单个算术级数的约束下得到最大程度的扩展。 一旦两个固定值定义了唯一的差异，该段就会变得刚性。 从那时起，每个元素都有一个独特的期望值。 如果出现矛盾，则不重新分配$-1$可以在不破坏固定值之一的情况下修复它，因此此时分裂是不可避免的。 

这创建了一个贪婪的结构：每个段都在逻辑上尽可能地扩展，并且任何早期的分割都不能提高段的总数，因为延迟分割永远不会减少未来的约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    segments = 1

    # current segment state
    d = None
    first = None
    prev = None
    prev_val = None

    for i in range(n):
        if a[i] == -1:
            # unknown value does not constrain anything
            if prev is not None:
                prev += 1  # placeholder progression step, value irrelevant
            continue

        if first is None:
            first = a[i]
            prev = i
            prev_val = a[i]
            continue

        if prev_val is None:
            prev_val = a[i]
            d = (a[i] - first) // (i - prev)
            prev = i
            continue

        # expected value from progression
        dist = i - prev
        expected = prev_val + d * dist

        if expected != a[i]:
            segments += 1
            # reset segment
            first = a[i]
            prev = i
            prev_val = a[i]
            d = None
        else:
            prev = i
            prev_val = a[i]

    print(segments)

if __name__ == "__main__":
    solve()
```该实现跟踪当前段是否已确定其算术级数。 变量`first`存储段中的第一个固定值，而`prev_val`和`prev`一旦第二个固定值出现，帮助定义差异。 

这个逻辑依赖于这样一个事实：一旦`d`一旦建立，每个新的固定元素都可以在恒定时间内得到验证。 当发现不匹配时，我们会在该索引处重新启动该段。 

处理时需要小心$-1$，因为它们无助于确定或验证进展。 该代码有效地跳过它们而不更新约束。 

一个常见的陷阱是错误地假设差异可以重复更新； 一旦固定，它必须在该段中保持不变。

 ## 边缘情况

 一个关键的边缘情况是，序列在开始时仅包含一个已知值，而其他一切直到很久以后才知道。 该算法保持段打开而不修复差异，因此它不会过早锁定到不正确的结构。 当第一个第二固定值出现时，从这两点开始一致地设置差值。 

另一种情况是差异解决后立即出现矛盾。 例如：```
3 5 7 10
```该段在 7 之前变得有效，差值+2，但 10 打破了它。 该算法在第一次无效比较时检测到这一点，并在 10 处开始一个新分段，确保最小分段。 

第三种情况是交替已知和未知值，可以支持多种解释。 由于未知数永远不会用于强制约束，因此该算法仅对固定值做出反应，从而防止过度约束段结构。
