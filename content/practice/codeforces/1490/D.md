 ## 解决方案
 ## 问题理解

 我们给出了长度的排列$n$，这是一个包含从 1 到$n$正好一次。 任务是将这种排列视为构造二叉树的一种方式：根是最大的元素，其左侧的元素递归地形成左子树，右侧的元素递归地形成右子树。 对于排列中的每个元素，我们要计算其在这棵树中的深度，其中根的深度为 0，其子元素的深度为 1，依此类推。 

输入由多个测试用例组成。 对于每个测试用例，第一行是排列长度$n$第二行包含排列本身。 输出是与排列中每个元素相对应的深度列表。 

鉴于$n \le 100$并且最多可以有 100 个测试用例，算法必须有效地处理大约 10,000 个元素。 任何复杂性比以下更差的方法$O(n^2)$每个测试用例可能会开始感觉很慢，但是对于这个问题，即使是简单的递归方法也是可以接受的，因为$n$很小。 关键边缘情况包括长度为 1 的排列（其中唯一元素是根且深度为 0），以及已经按升序或降序排序的排列，这会创建倾斜树。 

如果幼稚的实现没有围绕最大元素正确分割数组或忘记在递归期间跟踪深度，则可能会失败。 例如，对于一个排列`[1,2,3,4]`，最大为4，所以元素的深度为0,1,2,3`[1,2,3,4]`如果我们错误地递归的话。 

## 方法

 蛮力方法是从字面上模拟树的构造。 对于每个子数组，我们找到最大值，分配其深度，然后递归调用左右子数组。 这是可行的，因为树定义是递归的，并且最大元素始终定义根。 主要成本是重复扫描子数组以找到最大值。 为了$n=100$，最坏的情况是扫描长度的子数组$n, n-1, n-2, \dots, 1$，总共大约$n^2/2$每个测试用例的操作。 考虑到问题的限制，这是可以接受的。 

最佳方法本质上是相同的，因为输入大小很小。 不需要高级数据结构。 我们可以将其干净地实现为一个递归函数，该函数采用子数组和深度，查找最大元素，分配其深度，然后在左右子数组上递归。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 已接受 |
 | 递归DFS | O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取长度的排列$n$。 
2.初始化一个数组`depths`长度$n$来存储结果。 
3. 定义递归函数`assign_depth(l, r, d)`在哪里`l`和`r`是当前子数组索引（包括），以及`d`是当前深度。 
4. 在`assign_depth`， 如果`l > r`，立即返回，因为子数组为空。 
5. 查找子数组中最大元素的索引`a[l:r+1]`。 分配`depths[max_index] = d`。 
6. 递归调用`assign_depth(l, max_index - 1, d + 1)`为左子树分配深度。 
7. 递归调用`assign_depth(max_index + 1, r, d + 1)`为右子树分配深度。 
8. 递归完成后，打印`depths`测试用例的数组。 

工作原理：每次递归调用都确保当前子数组的最大元素成为该子树的根。 通过传递当前深度`d`在递归中，我们正确地分配每个元素的深度。 递归自然地将数组分成左子节点和右子节点，保留问题中定义的树结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        depths = [0] * n

        def assign_depth(l, r, d):
            if l > r:
                return
            # find max element in current subarray
            max_index = l
            for i in range(l, r + 1):
                if a[i] > a[max_index]:
                    max_index = i
            depths[max_index] = d
            # recurse on left and right subarrays
            assign_depth(l, max_index - 1, d + 1)
            assign_depth(max_index + 1, r, d + 1)

        assign_depth(0, n - 1, 0)
        print(' '.join(map(str, depths)))

if __name__ == "__main__":
    solve()
```代码首先读取测试用例的数量。 对于每个测试用例，它读取排列并初始化`depths`大批。 这`assign_depth`函数处理深度的递归分配。 它搜索当前子数组中的最大元素，分配深度，并递归处理左右分区。 使用索引而不是切片数组可以避免在每个递归步骤创建新列表，从而节省内存并简化深度跟踪。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n^2) | O(n^2) | 每次递归通过扫描子数组来找到最大元素。 最坏情况是 n + (n-1) + ... + 1 = O(n^2) |
 | 空间| O(n) | 递归深度最多为 n，加上`depths`大小为 n 的数组 |

 考虑到约束条件$n \le 100$和$t \le 100$，这种复杂性完全在限制范围内。 内存使用量极小，并且递归深度不会超过Python默认的递归限制。
