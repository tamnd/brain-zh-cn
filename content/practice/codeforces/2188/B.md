 ## 解决方案
 ## 问题理解

 我们得到一排用二进制字符串表示的座位，其中`1`表示有一个学生坐在那里并且`0`表示有空座位。 最初没有两个学生是相邻的。 我们的目标是增加更多的学生，直到没有更多的学生可以入座，但我们必须通过增加尽可能少的学生来做到这一点。 输出是最终就座的学生人数，包括原始学生和新添加的学生。 

关键的限制是两个学生不能坐在相邻的座位上。 这意味着当我们想要安置新学生时，我们必须检查两个邻居以确保它们都是空的。 所有测试用例的输入大小总共可以达到 2 × 10^5 个席位，这排除了任何在嵌套循环中重复检查每个席位的解决方案，因为在最坏的情况下可能会达到 10^10 次操作。 

边缘情况包括长度为 1 的行、完全空的行、学生交替的行或学生在边界附近的行。 幼稚的方法可能会因为不处理边缘或在新学生最佳间距时重复计算座位而导致错误计数。 

例如，考虑`s = "00000"`。 仅仅将一名学生放在第一个座位并不足以使该排无法容纳更多学生。 最佳位置是 1 号和 4 号座位，总共 2 名学生。 如果不小心从左到右贪婪地没有间距，就会将学生排在 1、2、4 号座位上，这样就多算了。 

## 方法

 暴力方法会重复扫描字符串，找到第一个相邻的空座位，将学生放在那里，然后重复，直到无法放置更多座位。 这是有效的，因为每个位置都是有效的，并且最终会填补所有可能的位置。 然而，如果我们重复扫描一个很长的空行，在最坏的情况下这可能是 O(n^2)，这对于 n 高达 2 × 10^5 来说太慢了。 

关键的观察结果是，问题简化为计算可以容纳连续空座位块的不相邻学生的最大数量。 在已占用的座位（或行边界）之间，长度连续零的任何段`k`可以主持`ceil(k / 2)`额外的学生。 这来自于贪婪的选择：每隔一个座位安排一个学生可以确保最小的增加和最大的覆盖范围。 通过将行拆分为这些零块并对结果求和，我们实现了可扩展到输入限制的 O(n) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，读取行长度`n`和二进制字符串`s`。 
3. 初始化计数器`students`为零以跟踪就座学生总数。 
4. 从左到右遍历字符串。 使用索引`i`扫描座位。 
5. 如果当前座位`s[i]`是`1`, 增量`students`通过设置跳过下一个座位`i += 2`。 这确保我们不会违反邻接约束。 
6. 如果当前座位`s[i]`是`0`，检查邻居：如果前一个（或边界）和下一个座位都是`0`（或边界），将学生放在这里，递增`students`，然后跳过下一个座位`i += 2`。 
7. 否则，移动到下一个座位`i += 1`。 
8.处理完整行后，输出`students`对于该测试用例。 

为什么有效：在每个位置，我们要么考虑已经就座的学生，要么贪婪地将新学生放置在零段中而不违反邻接性。 安排一名学生后跳过下一个座位可确保没有两个学生相邻。 每个空的部分都得到了最大限度的利用，并且这个过程永远不会错过给学生安排座位的机会。 全部的总和`students`counts 给出了不可能有更多座位的最小总数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def min_total_students():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        students = 0
        i = 0
        while i < n:
            if s[i] == '1':
                students += 1
                i += 2
            elif s[i] == '0':
                left_empty = (i == 0) or (s[i-1] == '0')
                right_empty = (i == n-1) or (s[i+1] == '0')
                if left_empty and right_empty:
                    students += 1
                    i += 2
                else:
                    i += 1
            else:
                i += 1
        print(students)

if __name__ == "__main__":
    min_total_students()
```代码首先读取输入并迭代每个测试用例。 它使用 while 循环来有效地扫描座位，当学生已经在场或可以放置时增加计数器。 左右检查正确处理边界条件，确保不会出现越界错误。 放置后跳过下一个座位可以防止邻接冲突。

 ## 边缘情况

 对于单排座位`s = "0"`，算法放置一名学生并终止。 对于像这样的行`"10001"`，该算法正确地计算了现有学生的数量，并识别出两段零，其中每段可以放置一个学生，总共 3 个。 所处理的每个席位要么直接贡献要么被跳过的不变量确保没有邻接违规。 边界检查`i == 0`或者`i == n-1`防止索引错误并确保学生坐在边缘的最佳位置。
