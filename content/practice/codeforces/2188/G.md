 ## 解决方案
 ## 问题理解

 我们有一排由门连接的房间，每扇门都有一个自动打开的时间，并且每个房间可能包含一把钥匙。 您在时间 0 从房间 1 开始，目标是找到到达每个后续房间的最短时间。 移动受到门是否打开的限制，并且可以使用沿途捡到的钥匙打开关闭的门。 您一次最多可以携带一把钥匙，并且可以在任何房间拿起或放下钥匙。 

输入提供多个测试用例。 每个测试用例指定门的数量、每扇门的自动打开时间以及指示初始钥匙所在位置的二进制字符串。 每个测试用例的输出是一个整数列表，其中每个整数表示到达紧邻每扇门右侧的房间所需的最短秒数。 

问题规模很大：每个测试用例最多 200,000 个门，总共 10,000 个测试用例，这意味着我们可能总共需要处理 2×10^5 个门。 这排除了每秒的任何幼稚模拟。 随着时间步长迭代的蛮力方法会太慢，因为时间可能高达 2×10^5，并且移动决策可能会增加操作次数。 

当门打开之前房间里有钥匙可用，或者门打开晚于使用钥匙到达门所需的时间时，就会出现微妙的边缘情况。 例如，房间的起始位置可能有一把钥匙，但下一扇门在时间 0 打开。您可以立即使用钥匙，即使门计划稍后打开。 只等待门打开的粗心算法会高估最短时间。 

## 方法

 暴力方法会模拟每一秒并维持状态：当前房间、是否携带钥匙以及关键位置。 每一秒，你都会打开时机已到的门，拿起或放下钥匙，然后向左或向右移动。 这对于正确性是有效的，但时间复杂度为 O(max(a_i) * n)，对于最坏情况的输入来说，这可能是 4×10^10 次操作，并且是不可行的。 

关键的见解是，可以通过预先计算两个方向的最早到达时间来解决该问题。 对于每个房间，您可以通过等待门打开或使用钥匙从左侧到达该房间的最早时间是`max(time_needed_to_reach_prev_room + 1, door_open_time)`。 如果房间里有钥匙，您可以立即打开隔壁的门，而无需等待。 同样，从任何房间向右移动，如果门自动打开的时间晚于您可以使用钥匙打开门的最短时间，则最早到达时间将由两者中较小的一个确定。 

另一个观察结果是，由于您最多可以携带一把钥匙，因此唯一相关的钥匙是您左侧房间中的钥匙。 您不需要跟踪密钥删除，因为最佳策略从不要求删除密钥供以后使用； 您将立即在遇到的第一扇被堵住的门上使用它。 这通过动态编程方法将问题简化为简单的线性扫描，计算按顺序到达每个房间的最短时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n * 最大(a_i)) | O(n) | 太慢了 |
 | 线性 DP 扫描 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`dp`尺寸的`n+1`存储到达每个房间的最短秒数。 放`dp[0] = 0`因为我们在时间 0 从房间 1 开始。 
2. 从左到右遍历门。 门用`i`连通房`i`到`i+1`, 到达房间的最短时间`i+1`正在等待门自动打开`a[i]`或立即使用钥匙（如果房间里有钥匙）移动`i`。 计算`dp[i+1]`作为最大值`dp[i] + 1`和`a[i] + 1`如果没有钥匙可以立即使用。 
3.如果房间`i`包含一把钥匙，考虑到您可以立即使用钥匙开门`i`。 这给出了`dp[i+1] = min(dp[i+1], dp[i] + 1)`。 这`+1`说明在当前秒结束时移动到下一个房间。 
4. 对所有门重复此过程。 在最后，`dp[i+1]`包含到达房间的最短时间`i+1`考虑等待自动打开和最佳使用可用钥匙。 
5. 输出计算结果`dp[1:]`对于每个测试用例。 

为什么它有效：该算法保持了以下不变式：`dp[i]`是到达房间的最短时间`i`。 在每一步，我们要么等待门口，要么立即使用钥匙。 由于门只能打开一次，而且最初每个房间的钥匙仅限一把，摄影指导永远不会低估时间。 无需跟踪丢失的密钥，因为最佳路径永远不会涉及存储密钥的不必要的弯路。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        s = input().strip()
        dp = [0] * (n + 1)
        for i in range(n):
            # arrive at room i+1 either by waiting for door a[i] or using a key
            dp[i + 1] = max(dp[i] + 1, a[i] + 1)
            # if key is present in room i, consider using it immediately
            if s[i] == '1':
                dp[i + 1] = min(dp[i + 1], dp[i] + 1)
        print(' '.join(map(str, dp[1:])))
        
if __name__ == "__main__":
    solve()
```该代码反映了 DP 算法。 线路`dp[i+1] = max(dp[i] + 1, a[i] + 1)`确保您在门打开之前不会移动，除非您使用钥匙。 下一行检查是否有钥匙，这允许立即移动到下一个房间。 我们不追踪钥匙掉落情况，因为只有第一个被封锁的门对于最佳时间来说很重要。 通过仔细索引门和房间可以避免相差一的错误。
