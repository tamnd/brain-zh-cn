 ## 解决方案
 ## 问题理解

 给定一个整数数组并要求找到最大的整数$k$这样，通过重复交换差值至少为 的任意两个元素，可以将数组排序为非降序$k$。 如果没有这样的$k$存在，我们返回$-1$。 本质上，$k$表示允许交换的限制：较大的$k$也就是说，我们可以执行的交换越少，因此找到最大可行的$k$测试数组可排序结构的限制。 

输入提供多个测试用例，每个测试用例都有一个最大长度的数组$2 \cdot 10^5$，并且所有测试用例的所有数组长度之和不超过$2 \cdot 10^5$。 这意味着任何时间复杂度大致为线性或线性对数的算法$n$每个测试用例是可以接受的。 二次解决方案，例如尝试所有可能的交换，将达到$O(n^2) = 4 \cdot 10^{10}$在最坏的情况下，这太慢了。 

存在不明显的边缘情况。 如果数组已经排序，则任何$k > 0$看起来很“小猪”，因为从技术上讲我们不需要任何交换。 在这些情况下，最大的小猪$k$实际上是未定义的，因此问题需要返回$-1$。 具有所有相同元素的数组属于这一类。 另一种微妙的情况是当数组只有一个元素时，不可能进行交换； 再次，答案应该是$-1$。 粗心的方法可能总是根据数组中的差异返回正整数，而不检查是否确实需要任何交换，从而导致错误的答案。 

## 方法

 蛮力方法会迭代所有可能的方法$k$从 1 到数组中最大元素差异的值。 对于每个$k$，我们至少可以模拟任何有差异的货币对之间的交换$k$并检查数组是否已排序。 这原则上可行，但速度非常慢，因为每次模拟都可能需要$O(n^2)$时间，并且可能有$O(n)$候选人$k$价值观。 总的来说，这将超过$O(n^3)$，这对于$n$最多$2 \cdot 10^5$。 

关键的见解是认识到唯一重要的交换是将元素连接到全局最小值和最大值。 如果数组已经排序，则不需要交换，答案是$-1$。 否则，任何无序的元素必须能够与最小或最大元素交换以到达其正确位置。 因此，最大的小猪$k$是最大值和每个不合适元素之间以及最小值和每个不合适元素之间差异的最小值。 排序后的数组提供了一个参考来检测哪些元素不合适。 

这将问题转化为线性扫描：计算数组的最小值和最大值，将每个元素与其在排序数组中的位置进行比较，并跟踪到任一端的最小距离。 这一观察结果将解简化为$O(n \log n)$用于排序和$O(n)$对于扫描，这对于给定的约束来说足够有效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组并确定其长度$n$。 
2. 如果数组只有一个元素，则输出$-1$并继续。 不可能进行交换。 
3. 计算数组的排序版本。 如果排序后的数组与输入相同，则输出$-1$因为不需要交换。 
4. 确定数组的全局最小值和最大值。 
5. 初始化一个变量来跟踪最大可行值$k$，从0开始。 
6. 迭代数组。 对于每个与其在排序数组中的位置不匹配的元素，计算其最小值和最大值的差值。 更新最大的$k$作为这些差异的最大值。 
7. 扫描完所有元素后，输出计算出的最大的$k$。 

关键的不变量是任何无序的元素必须能够与最小或最大的元素交换以到达其正确的位置。 因此，最大的小猪$k$完全由数组的极值和错位元素的位置决定。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    if n == 1:
        print(-1)
        continue
    
    sorted_a = sorted(a)
    if a == sorted_a:
        print(-1)
        continue
    
    mn, mx = min(a), max(a)
    k = 0
    for i in range(n):
        if a[i] != sorted_a[i]:
            k = max(k, abs(a[i] - mn), abs(a[i] - mx))
    print(k)
```该代码首先处理简单的情况：长度为 1 的数组和已经排序的数组。 数组的排序版本用于识别放错位置的元素。 通过将每个元素与最小值和最大值进行比较，我们确定最大的$k$允许所有必需的交换。 一个常见的陷阱是忘记比较最小值和最大值的差异，这可能导致低估$k$。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())

        n = int(input())
        a = list(map(int, input().split()))
        if n == 1:
            output.append("-1")
            continue
        sorted_a = sorted(a)
        if a == sorted_a:
            output.append("-1")
            continue
        mn, mx = min(a), max(a)
        k = 0
        for i in range(n):
            if a[i] != sorted_a[i]:
                k = max(k, abs(a[i]-mn), abs(a[i]-mx))
        output.append(str(k))
    return "\n".join(output)
