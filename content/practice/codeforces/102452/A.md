 ## 解决方案
 ## 问题理解

 我们有一组轴对齐的矩形，其内部从不重叠。 矩形可以沿着边缘或点相接触，因此最终的图形可以是一个连接的形状、多个不相连的形状或带有孔的形状。 

对于每个测试用例，我们必须找到整个图形通过反射不变的每条线。 每行必须打印为

 [
 斧头+通过=c，
 ]

 三个系数具有最大公约数 (1)。 如果存在多个轴，则它们的归一化系数三元组必须按字典顺序降序打印，因为这给出了字典顺序最大的串联答案。 官方限制为 (2) 秒和 (512) MB，所有测试用例总共最多 (10^5) 个矩形。 

大的坐标范围是我们不应该构建网格或检查单个晶胞的线索。 坐标可以在（10^8）左右，而可以有（10^5）个矩形，因此与坐标大小成正比的任何东西都是不可能的。 在 (10^5) 个矩形和 2 秒限制的情况下，(O(n^2)) 几何比较将在考虑常数因子之前执行大约 (10^{10}) 对检查。 我们需要一种表示，其中每个矩形仅贡献恒定的工作，并且整个测试用例的处理时间约为 (O(n\log n)) 或更好。 

第一个微妙的情况是矩形可能会接触。 例如，```
1
2
0 0 2 1
1 1 2 2
```形成L形图形。 点 ((1,1)) 是并集的角，即使它不是第一个矩形的角。 仅独立存储一个矩形角的方法可能会错过此类边界转弯。 正确答案是不对称，下面的解决方案通过所有矩形角的奇偶性来处理触摸点。 

另一个微妙的情况是中心具有半整数坐标的矩形。 为了```
1
1
0 0 1 1
```四个对称轴是```
4
2 0 1 1 1 1 1 -1 0 0 2 1
```纵轴是(x=\frac12)，所以它的原始整数方程是(2x=1)，而不是用浮点运算写成(x=1/2)。 使用双倍坐标可以避免每次小数计算。 

第三种情况是几个矩形沿着整个边缘接触。 例如，```
1
2
0 0 1 1
1 0 2 1
```只是一个 (2\times1) 矩形。 它的答案是```
2
1 0 1 0 2 1
```将每个矩形边界视为最终边界的一部分的粗心实现会错误地将共享边视为边界段。 

最后，该图形可以具有多种对称性，并且所要求的顺序很重要。 对于上面的单位正方形，归一化三元组是 ((2,0,1))、((1,1,1))、((1,-1,0)) 和 ((0,2,1))。 按字典顺序降序对它们进行排序是所需输出的一部分，而不仅仅是表示选择。 

## 方法

 直接几何方法将首先构造所有矩形的所有边界段。 最多有 (4n) 个原始片段。 对于每个可能的对称轴，我们可以将每个边界段与其他每个段进行比较，并检查反射是否将一个段映射到另一个段。 这是正确的，因为多边形边界完全由其线段决定，但将 (O(n)) 条线段与 (O(n)) 个其他线段进行比较的成本为 (O(n^2))。 在 (n=10^5) 的情况下，即使一次这样的检查也可以达到大约 (1.6\times10^{11}) 段比较，这远远超出了时间限制。 

关键的观察结果是对称轴的方向受到极大限制。 图形的每个边界段都是水平或垂直的。 跨对称轴的反射必须将水平或垂直线段映射到另一个水平或垂直线段。 垂直轴或水平轴显然具有此属性。 对于斜轴，水平和垂直方向可以交换的唯一方法是在 (45^\circ) 处，给出两个对角方向的斜率 (1) 和 (-1)。 因此，轴最多有四个可能的方向。 

每个候选者的位置也受到边界框的强制。 反射保留整个图形的最小和最大 (x) 坐标，因此垂直对称轴必须是这两个坐标的中点。 同样的论点固定水平轴。 对角对称还必须保留边界框，因此它必须穿过边界框的中心。 因此只有四个候选行。 

我们仍然需要一种紧凑的方法来测试候选人是否真的保留了整个数字。 有用的观察是矩形角奇偶校验。 在每个点，计算有多少个矩形角以模 (2) 为模数。 具有奇校验的点正是边界的转折点。 当几个矩形接触时，它们边界的贡献沿着共享部分成对抵消，奇偶校验精确地保留了边界改变方向的位置。 这与官方竞赛解决方案的边界论证中使用的奇偶性思想相同。 

一旦知道了所有奇奇偶校验角，测试轴就变成了集合成员问题。 反射候选轴上的每个奇数角，并要求反射点是另一个奇数角。 如果所有奇数角都有伙伴，则保留整个边界，因为连续的转折点决定了它们之间的轴对齐边界段。 相反，真正的对称性必须将每个边界转弯映射到另一个边界转弯，因此它不会意外地通过此测试。 

还有一个实施细节。 在做其他事情之前，我们将每个坐标加倍。 如果原始边界框具有双极值 (X_{\min},X_{\max},Y_{\min},Y_{\max})，则定义

 [
 d_x=X_{\min}+X_{\max},\qquad d_y=Y_{\min}+Y_{\max}。 
]

 它们是中心坐标的两倍。 反射公式仅包含整数加法和减法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(n^2)) | (O(n)) | (O(n)) | 太慢了|
 | 最佳| (O(n)) 预期 | (O(n)) | (O(n)) | 已接受 |

 哈希集的实现需要 (O(n)) 预期时间。 平衡树实现将给出官方社论中所述的 (O(n\log n)) 界限。 

## 算法演练

1. 读取每个矩形并将所有四个坐标乘以 (2)。 将其四个双角插入奇偶校验组中。 如果已经存在角，请将其移除； 否则插入它。 同时，维护最小和最大双倍 (x) 和 (y) 坐标。 

奇偶校验操作很重要，因为两个矩形可以共享边界块。 共享贡献发生两次并取消，而真正的边界转向却有奇怪的发生率。 
2. 计算

 [
 d_x=X_{\min}+X_{\max},\qquad d_y=Y_{\min}+Y_{\max}。 
]

 边界框的实际中心是 ((d_x/2,d_y/2))。 将 (d_x,d_y) 保持为整数可以让每个反射保持积分。 
3. 测试横向候选。 双点 ((x,y)) 穿过水平中心的反射为

 [
 (x,,2d_y-y)。 
]

 由于 (d_y) 已经代表中心的两倍，因此我们的双坐标系中的正确表达式是

 [
 (x,,2d_y-y)。 
]

 原始坐标中的候选线为(2y=d_y)。 
4. 测试垂直候选人。 反射是

 [
 (2d_x-x,,y),
 ]

 对应的线是(2x=d_x)。 
5. 用斜率 (1) 测试对角线。 穿过边界框中心且方向为 ((1,1)) 的线的反射会交换中心坐标：

 [
 (x,y)\mapsto
 (d_x+(y-d_y),,d_y+(x-d_x))。 
]

 其在原坐标下的方程为

 [
 2x-2y=d_x-d_y。 
]
 6. 用斜率 (-1) 测试对角线。 反射是

 [
 (x,y)\mapsto
 (d_x-(y-d_y),,d_y-(x-d_x)),
 ]

 对应于

 [
 2x+2y=d_x+d_y。 
]
 7. 对于每个候选，迭代奇偶集中的每个点。 如果其反映点不存在，则拒绝该候选人。 否则继续检查。 仅当每个奇数边界转弯都有其反映的对应项时，才接受候选者。 

我们不需要检查边界上的任意点。 在两个连续的转弯之间，边界是直的水平或垂直线段，并且反射将端点映射到反射线段的端点。 因此，匹配每一圈就足以匹配整个边界。 
8. 将每个接受的行转换为原始整数系数。 将所有三个系数除以它们的最大公约数。 如果其第一个非零系数为负，则将整个三元组乘以 (-1)。 这为每条几何线提供了一个规范表示。 
9. 按字典顺序降序对生成的三元组进行排序并打印它们。 因为每个三元组恰好有三个条目，所以三元组的字典顺序递减正是串联输出按字典顺序最大所需的顺序。 

### 为什么它有效

 不变的是奇偶校验集恰好包含并集边界的转折点。 反射对称必须将边界匝映射到边界匝，因此每个真正的对称性都会通过点反射测试。 相反，如果每个边界转弯在四种可能的反射之一下映射到另一个边界转弯，则每对连续转弯之间的轴对齐段映射到相应的边界段。 因此完整的边界被保留。 由于反射将有界区域映射到有界区域，因此保留边界也就保留了图形本身。 

四个候选方向是详尽的，因为轴对齐的矩形边界仅包含水平和垂直线段。 保留这些方向的反射要么是水平的，要么是垂直的，或者交换水平和垂直的，从而给出斜率 (1) 和 (-1)。 它们的位置是由边界框强制的。 因此，不可能忽略任何可能的对称性。 

## Python 解决方案```python
import sys
from math import gcd

input = sys.stdin.readline

def primitive(a, b, c):
    g = gcd(abs(a), gcd(abs(b), abs(c)))
    a //= g
    b //= g
    c //= g

    if a < 0 or (a == 0 and b < 0):
        a = -a
        b = -b
        c = -c

    return (a, b, c)

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())

        corners = set()

        min_x = 10**30
        max_x = -10**30
        min_y = 10**30
        max_y = -10**30

        for _ in range(n):
            x1, y1, x2, y2 = map(int, input().split())

            x1 *= 2
            y1 *= 2
            x2 *= 2
            y2 *= 2

            for p in ((x1, y1), (x1, y2), (x2, y1), (x2, y2)):
                if p in corners:
                    corners.remove(p)
                else:
                    corners.add(p)

            min_x = min(min_x, x1)
            max_x = max(max_x, x2)
            min_y = min(min_y, y1)
            max_y = max(max_y, y2)

        dx = min_x + max_x
        dy = min_y + max_y

        ok = [True, True, True, True]

        for x, y in corners:
            if ok[0]:
                p = (x, 2 * dy - y)
                if p not in corners:
                    ok[0] = False

            if ok[1]:
                p = (2 * dx - x, y)
                if p not in corners:
                    ok[1] = False

            if ok[2]:
                p = (dx + y - dy, dy + x - dx)
                if p not in corners:
                    ok[2] = False

            if ok[3]:
                p = (dx - y + dy, dy - x + dx)
                if p not in corners:
                    ok[3] = False

            if not any(ok):
                break

        ans = []

        if ok[0]:
            ans.append(primitive(0, 2, dy))

        if ok[1]:
            ans.append(primitive(2, 0, dx))

        if ok[2]:
            ans.append(primitive(2, -2, dx - dy))

        if ok[3]:
            ans.append(primitive(2, 2, dx + dy))

        ans.sort(reverse=True)

        out.append(str(len(ans)))
        out.append(" ".join(str(v) for triple in ans for v in triple))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```这`corners`set 仅存储奇数次出现。 对于每个矩形角，切换成员资格实际上是一个 XOR 运算，因此出现两次的点消失，出现奇数次的点保留。 

坐标加倍后边界值保持不变。 这就是候选方程可以直接构建为整数三元组的原因。 例如，如果实际纵轴为（x=3.5），则`dx`是(7)，候选者是(2x=7)。 

四个反射公式直接写在双坐标中。 对于水平候选点，高度加倍的点`y`已反映高度`2 * dy - y`。 其他三个公式遵循相同的中心坐标变换。 

这`ok`array 允许已经被否决的候选人停止进行哈希查找。 这是一个小的常数因子优化，但很有用，因为每个幸存的候选者都会检查每个边界转弯。 

这`primitive`函数首先除以完整的三数 gcd。 符号约定使用第一个非零系数，因此 (x-y=0) 和 (-x+y=0) 等方程仅接收一个表示形式。 Python 整数还避免了固定宽度实现中可能出现的溢出问题，尽管此处的值完全在 64 位范围内。 

决赛`reverse=True`排序是故意的。 该问题要求字典顺序最大的扁平序列，因此最大的系数三元组必须首先出现，然后是下一个最大的，依此类推。

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |

 ## 边缘情况

 ### 单个矩形

 对于```
1
1
0 0 2 1
```边界框中心为 ((1,\frac12))。 水平反射保留矩形，给出 (2y=1)，垂直反射给出 (x=1)。 对角线候选失败，因为矩形不是正方形。 经过归一化和字典序排序后，输出为```
2
1 0 1 0 2 1
```该算法从不假设每个矩形都有四种对称性。 

### 沿边相连的矩形

 对于```
1
2
0 0 1 1
1 0 2 1
```两个矩形共享线段 (x=1,0\le y\le1)。 共享段的每个端点作为矩形角出现两次，因此从奇偶校验集中取消。 共享段本身不是外部边界的一部分。 剩余的边界恰好是 (2\times1) 矩形的边界，因此两个幸存轴是 (x=1) 和 (y=\frac12)。 

这就是为什么独立处理每个输入矩形边界是错误的，而角奇偶校验自然会消除内部贡献。 

### 矩形在一点相接触

 对于```
1
2
-1 -1 0 0
0 0 1 1
```公共点 ((0,0)) 由两个矩形贡献并从奇偶校验集中消失。 其余边界匝围绕通过公共点的两条对角线对称。 两条接受的线路是

 [
 x+y=0
 ]

 和

 [
 x-y=0。 
]

 原始三元组是 ((1,1,0)) 和 ((1,-1,0))，第一个三元组首先打印，因为它按字典顺序更大。 

### 半整数对称中心

 对于```
1
1
0 0 1 1
```中心是 ((\frac12,\frac12))。 将坐标加倍得到`dx = 1`和`dy = 1`，所以纵轴直接表示为(2x=1)，横轴直接表示为(2y=1)。 不会计算任何浮点中点。 

这也是为什么反射公式对于整数和半整数轴位置都一致有效的原因。 

### 大负系数

 考虑```
1
1
-100000007 100000006 -100000006 100000007
```纵轴是

 [
 x=-100000006.5,
 ]

 所以它的原方程是

 [
 2x=-200000013。 
]

 标准化程序不能盲目地强制常数为正值。 符号约定基于第一个非零系数，它保持表示的唯一性并给出`(2, 0, -200000013)`。 

### 不对称

 第一个官方样本包含两个矩形，其排列方式使得四种可能的反射都无法保留边界。 该算法仍然计算来自同一边界框的所有四个候选者，并在找到丢失的反射转弯后拒绝每个候选者。 结果很简单```
0
```空奇偶校验集测试从来都不是有效非空数字的特殊情况，因为外边界必然包含转弯。 因此，该算法可以对每个输入使用相同的反射测试。 

### 多个连接组件

 这些矩形不必形成一个连通分量。 奇偶校验集仅包含每个组件的边界匝数。 对称性必须正确反映每个组件，因此同时检查完整的奇偶校验集可以处理断开的数字，而无需任何额外的连接组件逻辑。 

### 多个对称轴

 方形联合可以通过所有四个候选测试。 该算法独立记录所有这些，独立标准化它们，然后才对它们进行排序。 这种分离是必要的，因为候选生成顺序是几何顺序，而所需的输出顺序是字典顺序。
