 ## 解决方案
 ## 问题理解

 我们有`n`排列成一条线的平面。 粒子从左侧外侧开始，随着衰变年龄向右移动`k`。 

每当粒子穿过平面时，它总是继续沿同一方向移动。 如果其年龄大于一，该平面还会创建一个年龄小一且方向相反的新粒子。 粒子之间从不相互作用，因此每个粒子都独立演化。 

任务是计算整个过程完成后存在多少个粒子。 由于数字增长很快，因此需要对答案取模`10^9+7`。 

限制非常小。 全部的总和`n`值最多是`1000`，以及所有的总和`k`值也至多`1000`。 这已经表明动态规划解决方案大致具有`O(nk)`状态很容易足够快。 甚至一个`O(nk(n+k))`解决方案可以通过，但指数模拟是不可能的，因为粒子本身的数量变得巨大。 

有几种情况很容易处理不当。 

什么时候`k = 1`，粒子永远不会创建副本。 例如，```
1
3 1
```产生```
1
```在每个平面上盲目创建反射粒子的模拟会错误地产生更多粒子。 

当只有一个平面时，反射粒子会立即离开系统，因为在其方向上不再有平面。 例如，```
1
1 3
```产生```
2
```假设粒子总是反复弹跳的递归实现会过度计数。 

方向也很重要。 考虑```
1
2 3
```答案是```
4
```二龄反射粒子向左移动，在离开前仅遇到一个平面。 将所有粒子视为总是遍历所有粒子`n`飞机给出了错误的计数。 

## 方法

 最直接的想法就是模拟每一个粒子。 每当一个粒子到达一个平面时，就会继续原来的粒子，并可能创建一个新的粒子，随着年龄减少一，朝相反的方向移动。 

这种方法是正确的，因为粒子永远不会碰撞或相互影响。 问题是粒子的数量呈指数增长。 即使对于中等值`k`，总数就变得太大了。 

关键的观察是，一个粒子完全由三个信息描述：它的当前位置、它的方向和它的剩余年龄。 这些数量具有相同值的两个粒子将产生完全相同数量的后代。 

假设一个粒子当前位于平面上`i`，随着年龄向右移动`j`。 穿过平面后，原粒子向平面移动`i+1`，还是随着年龄的增长`j`。 如果`j > 1`，反射粒子向平面移动`i-1`随着年龄的增长`j-1`。 

相同的描述适用于向左移动的粒子。 这会产生重叠的子问题，从而使动态编程变得自然。 

我们可以利用对称性，而不是显式地存储方向。 定义`dp[i][j]`作为年龄粒子产生的粒子数`j`从飞机开始`i`并向最近的一端移动。 平面索引编号为`1`到`n`。 

当这样的粒子穿过平面时`i`，原始粒子继续向边界移动并贡献`dp[i-1][j]`，而反射粒子会反转方向，其行为与从镜像位置开始的粒子完全相同`n-i+1`随着年龄的增长`j-1`。 

这给出了```
dp[i][j] = dp[i-1][j] + dp[n-i+1][j-1]
```与基本情况```
dp[0][j] = 1
dp[i][1] = 1
```因为到达边界意味着仅保留当前粒子，并且第一龄粒子永远不会分裂。

 | 最佳 | O(nk) | O(nk) | O(nk) | O(nk) | 已接受 |

 ## 算法演练

 1.创建二维表`dp`尺寸的`(n+1) × (k+1)`。 
2. 设置每个`dp[i][1]`到`1`因为第一年龄的粒子不能创造新的粒子。 
3. 设置每个`dp[0][j]`到`1`因为已经通过所有平面的粒子只会生存并贡献自己。 
4. 工艺年龄从`2`最多`k`。 
5. 对于每个年龄段，处理以下位置：`1`到`n`。 
6. 计算```
dp[i][j] = dp[i-1][j] + dp[n-i+1][j-1]
```模数`10^9+7`。 

第一项对应于继续向边界延伸的原始粒子。 第二项对应于反射粒子，其方向反转且年龄减一。 
7. 所需答案是`dp[n][k]`，它表示初始粒子在第一个平面之前开始并向右移动。 

### 为什么它有效

 国家`dp[i][j]`总是代表年龄粒子产生的粒子总数`j`仍然有确切的`i`当前方向上可用的平面。 

穿越最近的位面将未来分成两个独立的部分。 一枝留老`j`只剩下一架飞机了。 另一个分支反转方向，失去一个年龄单位，并看到互补的一组位面。 每个可能的粒子演化都属于这两个分支之一，因此递归对每个粒子计数一次且仅一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

t = int(input())
queries = []
max_n = 0
max_k = 0

for _ in range(t):
    n, k = map(int, input().split())
    queries.append((n, k))
    max_n = max(max_n, n)
    max_k = max(max_k, k)

dp = [[0] * (max_k + 1) for _ in range(max_n + 1)]

for i in range(max_n + 1):
    dp[i][1] = 1

for j in range(1, max_k + 1):
    dp[0][j] = 1

for j in range(2, max_k + 1):
    for i in range(1, max_n + 1):
        dp[i][j] = (dp[i - 1][j] + dp[max_n - i + 1][j - 1]) % MOD

ans = []

for n, k in queries:
    cur = [[0] * (k + 1) for _ in range(n + 1)]

    for i in range(n + 1):
        cur[i][1] = 1

    for j in range(1, k + 1):
        cur[0][j] = 1

    for j in range(2, k + 1):
        for i in range(1, n + 1):
            cur[i][j] = (cur[i - 1][j] + cur[n - i + 1][j - 1]) % MOD

    ans.append(str(cur[n][k]))

print("\n".join(ans))
```该表存储按剩余飞机和剩余寿命索引的状态。 第一列初始化为 1，因为年龄一的粒子永远不会生成后代。 第零行也是一行，因为到达边界意味着粒子简单地退出。 

该转变利用了系统的对称性。 在穿过最近的平面后，反射粒子准确地看到对面的平面，这解释了指数`n - i + 1`。 

循环的顺序很重要。 年龄`j`取决于年龄`j-1`，所以年龄是从小到大处理的。 在同一年龄段内，位置是从左到右处理的，因为`dp[i]`取决于`dp[i-1]`。 

每次加法后立即应用模运算以避免溢出。

 ## 边缘情况

 考虑```
1
3 1
```算法初始化`dp[i][1]=1`对于每一个`i`。 不执行任何转换，因为没有更小的年龄可供依赖。 答案是`1`，这与从未创建任何副本的事实相符。 

考虑```
1
1 3
```该表变为

 | 我| j | 价值|
 | --- | --- | --- |
 | 0 | 1 | 1 |
 | 1 | 1 | 1 |
 | 1 | 2 | 2 |
 | 1 | 3 | 2 |

 第一次穿过后的反射粒子在其方向上没有留下任何平面，因此计数保持为 2。 

考虑```
1
2 3
```递归计算```
dp[1][2]=2
dp[2][2]=3
dp[1][3]=2
dp[2][3]=4
```反射的二龄粒子向左移动时只有一个可用平面。 使用`n-i+1`正确捕捉这种不对称性并避免过度计数。
