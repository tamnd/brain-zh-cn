 ## 解决方案
 ## 问题理解

 该问题要求我们找到给定的整数$n$, 最小整数$x$大于或等于$n$使得最大公约数$x$并且其各位数字之和大于1。 换句话说，我们想要$x \ge n$和$gcd(x, s(x)) > 1$， 在哪里$s(x)$是数字的总和$x$。 输入由多个测试用例组成，每个测试用例给出一个数字$n$，输出是满足此条件的每个测试用例的一个整数。 

约束条件允许$n$最多$10^{18}$直至$10^4$测试用例。 一种简单的迭代方法$n$向上并计算$gcd(x, s(x))$如果每次检查都非常快，那么对于每个候选人来说都是可行的。 自从$10^{18}$是巨大的，我们无法负担任何在最坏情况下线性扫描大范围数字的解决方案。 每次检查都涉及计算数字之和，然后计算 gcd，这对于单个数字来说都很快。 

边缘情况包括数字，其中$n$本身已经满足条件，即数字之和为素数的数字，或正好低于“好”候选数字的数字。 例如，如果$n = 75$，75 和 12 的 gcd 是 3，所以答案是 75 本身。 如果$n = 11$,$gcd(11,2) = 1$，所以我们需要移动到 12，其中$gcd(12,3) = 3$。 粗心的实施可能会跳过检查$n$本身并且总是首先递增，从而产生错误的答案。 

## 方法

 蛮力方法很简单：从$n$，计算数字之和，用数字计算 gcd，并检查它是否大于 1。如果不大于，则增加数字并重复。 这是可行的，因为每个数字都是独立的，并且 gcd 计算非常快。 然而，在最坏的情况下，我们可能需要检查许多连续的数字才能找到有效的$x$。 考虑到这些限制，我们可能会运气不好得到一些数字，但实际上数字之和最多为 162（对于 18 位数字），因此一个数字的 gcd 几乎总是大于 1，其数字之和在几步之内。 这在实践中允许简单的线性扫描。 

使问题易于处理的关键见解是连续数字很少违反 gcd 条件。 数字之和变化缓慢，许多数字与其数字之和共享公约数。 因此，只需增加$n$考虑到问题的限制，直到满足条件为止既正确又有效。 不需要复杂的数学公式或预先计算，因为线性扫描只需要每个测试用例进行几次迭代。

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，读取整数$n$。 
3. 初始化$x = n$作为候选人编号。 
4. 重复以下步骤，直到有效$x$发现：

 1. 计算数字之和$x$。 这是通过转换来完成的$x$转换为字符串并对每个字符的整数值求和。 
2. 计算$gcd(x, \text{sum of digits})$。 Python 的内置`math.gcd`函数可以有效地处理这个问题。 
3. 如果gcd大于1，则输出$x$并停止此测试用例的循环。 
4. 否则，增加$x$减 1 并继续循环。 
5. 移至下一个测试用例。 

工作原理：循环不变式是，对于检查的每个数字，要么满足 gcd 条件，要么递增到下一个整数。 因为整数是离散的并且严格递增，所以第一个数字是`gcd(x, s(x)) > 1`保证是最小的。 该算法始终考虑输入$n$本身，因此它不会跳过有效的解决方案。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    x = n
    while True:
        s = sum(int(d) for d in str(x))
        if math.gcd(x, s) > 1:
            print(x)
            break
        x += 1
```代码首先读取测试用例的数量。 对于每个测试用例，它读取$n$并开始检查$x = n$。 使用生成器表达式迭代数字的字符串表示形式来计算数字之和。 这`math.gcd`函数有效地计算两个数字的 gcd。 如果满足条件，我们打印$x$并停止。 否则，我们增加$x$并继续。 循环保证终止，因为有效$x$总是存在并且很快就能找到。

 ## 边缘情况

 对于输入`n = 1`，算法检查`gcd(1,1) = 1`，增加到 2，并发现`gcd(2,2) = 2 > 1`。 输出正确 2. 对于`n = 10^18`, 各位数字之和为 1,`gcd(10^18,1) = 1`，增加到 10^18 + 1 (`gcd(10^18 + 1,1) = 1`)，然后 10^18 + 2，`gcd(10^18 + 2,2) = 2`，正确生成 10^18 + 2。该算法可以处理边界和大值而不会溢出，因为 Python 整数是任意精度的。 它还可以正确识别输入本身满足 gcd 条件的情况，例如`n = 75`，立即打印输入。
