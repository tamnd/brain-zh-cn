 ## 解决方案
 ## 问题理解

 该问题模拟了无限数轴上的竞赛。 爱丽丝从位置开始`a`。 奖品出现在两个可能的位置之一，`x`或者`y`，并且 Bob 必须选择一个不同的整数起始位置才能知道出现哪一个。 如果鲍勃选择的位置比爱丽丝的起始位置更接近两个可能的奖品位置，则鲍勃获胜。 

对于每个测试用例，输入给出三个位置`a`,`x`， 和`y`。 输出询问 Bob 是否存在保证获胜的有效起始位置。 位置很小，但测试用例的数量可能很大，因此解决方案应避免每个测试用例探索太多可能的位置。 对于多达数千个案例，检查恒定数量的候选者的方法是理想的，而无需在大坐标范围内进行扫描。 

主要困难在于鲍勃需要一个位置能够同时击败爱丽丝到达两个目的地。 仅检查一个目的地可能会产生误导，因为接近的点`x`可能太远了`y`。 

一个常见的错误是忘记鲍勃不能从爱丽丝的位置开始。 例如：```
1
5 3 1
```正确的输出是：```
YES
```粗心的方法可能会尝试始终选择中点或选择爱丽丝的对面而不检查确切的距离。 Bob可以在这里选择位置`2`，这是距离`1`来自两个目标。 爱丽丝是距离`2`从`3`和距离`4`从`1`。 

另一个边缘情况是当 Alice 已经位于两个可能的奖品位置之间时：```
1
3 1 5
```正确的输出是：```
NO
```任何靠近的位置`1`移动得更远`5`，以及任何接近的位置`5`移动得更远`1`。 由于爱丽丝正好位于中间，所以鲍勃无法在两侧击败她。 

## 方法

 一个直接的蛮力想法是尝试 Bob 的每个可能的整数起始位置。 对于每个候选人职位`b`，我们检查是否：```
|b - x| < |a - x|
and
|b - y| < |a - y|
```如果某个位置满足两个不等式，那么答案是肯定的。 这是正确的，因为条件直接描述了获胜的要求。 

问题是决定测试多少个位置。 如果坐标很大，检查每个可能的点就会太慢。 尽管这个特定版本的坐标很小，但预期的观察结果是答案仅取决于位置`a`相对于而言的谎言`x`和`y`。 

两个目标位置将线划分为多个区域。 如果Alice不在两个目标之间，Bob可以选择一个更接近中间区间的点`x`和`y`，因为该方向减少了两个距离。 如果爱丽丝位于两个目标之间，则她已经处于其中一个目标的最佳一侧，任何移动都会使一侧变得更糟。 

关键的见解是，唯一重要的是是否`a`位于由 形成的线段之外`x`和`y`。 如果`a`在外部，向该线段移动一步会缩短到两个端点的距离。 如果`a`在内部，不存在这样的运动。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(坐标范围) | O(1) | O(1) | 不必要|
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取三个位置`a`,`x`， 和`y`。 
2. 找到较小和较大的奖品位置。 让他们成为`low`和`high`。 这给出了可能出现奖品的部分。 
3.检查Alice的位置是否在该段之外。 如果`a < low`或者`a > high`，鲍勃可以向该细分市场迈出一步，并更接近两个可能的奖品。 
4. 打印`YES`如果 Alice 位于段之外，则打印`NO`。 

其工作原理是基于距离在直线上的表现。 当爱丽丝位于两个目标之外时，每次向间隔移动都会缩短两个距离。 当她在里面时，两个目标位于相对的两侧，因此改善一个距离需要恶化另一个距离。 

为什么它有效：

 不变量是鲍勃需要一个更接近每个可能的奖品位置的位置。 之间的段`x`和`y`包含平衡两个目标的所有位置。 从该段外部向内移动会缩短到两端的距离。 从段内部来看，每个位置都已经在目标之间，因此没有方向可以同时减小两个距离。 这与算法检查的条件完全匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        a, x, y = map(int, input().split())

        low = min(x, y)
        high = max(x, y)

        if a < low or a > high:
            ans.append("YES")
        else:
            ans.append("NO")

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```代码首先读取测试用例的数量并独立处理每个测试用例。 对于每种情况，它都会创建包含两个可能的奖品位置的区间。 

条件`a < low or a > high`检查 Alice 是否在该区间之外。 如果是，鲍勃可以向内移动并改善这两个距离。 如果不是，则爱丽丝位于目标之间，鲍勃不能保证获胜。 

位置上没有循环，因此不存在边界或溢出问题。 唯一要避免的实现细节是与`x`和`y`直接直接执行而不对其进行排序，因为两个目标位置可能以任一顺序出现。

 ## 边缘情况

 对于这个案例：```
1
5 3 1
```该算法将奖品位置排序为`low = 1`和`high = 3`。 爱丽丝在`5`，大于`high`，所以她在该段之外。 算法返回`YES`。 鲍勃可以选择位置`2`，给出距离`1`和`1`，而爱丽丝有距离`2`和`4`。 

对于这个案例：```
1
3 1 5
```排序后的区间为`[1, 5]`。 爱丽丝就在里面。 算法返回`NO`。 向左目标的任何移动都会增加到右目标的距离，而向右目标的移动会增加到左目标的距离。 

对于等间距情况，例如：```
1
0 2 4
```Alice 也在目标之间，所以答案是`NO`。 重要的一点是，恰好位于中间并不能为鲍勃创造优势。 单一起点无法同时改善双方。
