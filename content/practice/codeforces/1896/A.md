 ## 解决方案
 ## 问题理解

 我们得到了一个排列和一个非常具体的交换操作。 

仅允许在某个位置进行交换`i`其中元素是局部最大值。 换句话说，`a[i]`必须大于它的两个邻居。 当存在这样的位置时，我们可以交换`a[i]`元素紧邻其右侧。 

任务不是实际对排列进行排序。 我们只需要确定某些有效操作序列是否最终可以将排列转换为递增顺序。 

限制小得惊人。 排列长度最多为10，测试用例最多为5000个。 对所有可达状态的强力搜索实际上是可能的，因为状态空间的边界为`10!`，但这仍然远远大于必要的。 该问题是围绕对操作可以改变什么和不能改变什么的简单观察而设计的。 

主要陷阱是假设元素可以通过重复交换自由移动。 该操作受到极大限制。 

考虑：```
3
3 1 2
```第一个元素是`3`。 没有涉及位置 1 的有效操作，因为该操作只允许索引从 2 到`n-1`。 排列永远无法排序，所以答案是`NO`。 

另一个容易被忽略的情况是：```
5
1 3 2 5 4
```这看起来只是部分排序，但两者`3`和`5`是局部最大值。 执行允许的交换给出：```
1 3 2 5 4
→ 1 2 3 5 4
→ 1 2 3 4 5
```答案是`YES`。 

最重要的边缘情况是最小的元素尚未位于最前面。 

例子：```
5
2 1 3 4 5
```排列几乎已排序，但元素`1`永远不能移动到位置 1。答案是`NO`。 

了解为什么会发生这种情况可以直接找到解决方案。 

## 方法

 暴力方法会将每个排列视为一种状态，并重复应用每个有效操作。 我们可以执行图搜索并检查排序的排列是否可达。 

这有效是因为`n ≤ 10`，但仍然没有必要。 在最坏的情况下，最多有`10! = 3,628,800`州。 即使许多状态无法访问，但探索数千个测试用例的状态也将是过多的。 

关键的观察结果来自于检查第一个元素发生了什么。 

每个允许的操作都使用之间的索引`2`和`n-1`并交换位置`i`和`i+1`。 

位置`1`从未被触及。 

这意味着排列的第一个元素永远不会改变。 

排序排列中的第一个元素必须是什么？ 由于该数组是一个排列`1..n`，排序后的排列总是以`1`。 

所以如果第一个元素不是`1`，排序是不可能的。 

令人惊讶的是，如果第一个元素已经等于`1`，排序总是可能的。 

为什么？ 每个元素大于`1`最终可以通过一系列有效的局部最大交换向右移动。 官方的解决方案观察是`1`固定在前面既是必要的也是充分的。 

整个问题简化为检查单个值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(可达状态数) | O(可达状态数) | 不必要|
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读出排列。 
2. 检查第一个元素。 
3. 如果第一个元素等于`1`， 打印`"YES"`。 

排序排列必须以`1`，以及当`1`已经固定在前面，允许的操作足以对剩余元素进行排序。 
4. 否则打印`"NO"`。 

第一个位置永远不能参与任何操作，因此与`1`永远无法被取代`1`。 

### 为什么它有效

 不变量是位置 1 永远不会改变。 

每次操作都会交换位置`i`和`i+1`在哪里`2 ≤ i ≤ n-1`。 由于从不涉及位置 1，因此第一个元素在整个过程中保持不变。 

的排序排列`1..n`必须开始于`1`。 如果第一个元素不是`1`，达到排序排列是不可能的。 

相反，如果第一个元素是`1`，剩余元素始终可以使用允许的局部最大交换重新排列为排序顺序。 这一事实是问题背后的核心观察，并且使条件变得充分必要。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    if a[0] == 1:
        print("YES")
    else:
        print("NO")
```实现直接遵循证明。 

对于每个测试用例，我们读取排列并仅检查其第一个元素。 不需要模拟。 

一个常见的错误是试图明确地对交换进行建模。 该操作看起来像一个排序过程，但第一个位置上的不变量完全决定了答案。 

另一个可能的错误是检查排列是否已经排序。 排列例如：```
1 3 2
```最初没有排序，但答案仍然是`"YES"`因为允许的操作可以完成排序。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        ans.append("YES" if a[0] == 1 else "NO")

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out
