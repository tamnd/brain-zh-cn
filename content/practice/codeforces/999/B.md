 ## 解决方案
 ## 问题理解

 我们得到一个已经通过涉及重复反转前缀的确定性过程进行转换的字符串。 原始字符串是未知的，并且生成最终字符串的过程是完全指定的：对于长度的每个除数，从最大到最小，我们反转该长度的前缀。 

关键的困难在于这些逆转严重重叠。 字符串中的每个位置都会移动多次，最终的顺序隐藏了转换的顺序。 我们被要求在应用任何反转之前重建原始字符串。 

输入大小很小，字符串长度最多为 100。这立即表明 O(n^2) 重建或模拟就足够了。 任何尝试强力排列的解决方案都是不必要的，但即使尝试，阶乘增长也是无关紧要的，因为 n 很小。 

这里的边缘情况主要是结构性的，而不是与性能相关的。 当 n 等于 1 时，没有任何操作会更改字符串，因此输出与输入相同。 当 n 为素数时，只有 1 和 n 是约数，因此恰好存在一个有意义的反转。 简单的前向模拟很容易，但不正确的反转顺序会导致错误的重建。 

一种常见的失败模式是直接模拟加密而不了解可逆性。 另一种方法是尝试按除数递增顺序反转所有前缀，而不是逐步重建原始序列。 

## 方法

 前向过程以除数递减顺序应用前缀反转。 每个操作仅依赖于前缀，而不依赖于后缀交互。 这种结构使得变换以非常受控的方式可逆。 

一个强力的想法是生成候选原始字符串，模拟加密过程，并将其与目标进行比较。 虽然正确，但每次模拟的成本为 O(n^2)，并且尝试所有排列的成本为 O(n!)。 即使仅限于单个候选者，也不需要重复模拟。 

关键的见解是前缀反转是对合，这意味着每个反转都是它自己的反转。 然而，顺序很重要。 如果我们在加密中按 d1, d2, ..., dk 的顺序反转前缀，那么在解密中我们必须以相反的顺序应用相同的操作：dk, ..., d2, d1。 

但还有一个更简单的结构观察。 由于在加密期间按降序处理除数，因此应用的最后一个有意义的转换对应于大于 1 的最小除数。这意味着在解密期间，我们通过按除数递增顺序应用前缀反转来重建字符串。 

我们可以计算 n 的所有除数，对它们进行排序，并模拟按排序顺序对加密字符串应用前缀反转。 这会重建原始字符串，因为每次反转都会消除前向过程中相应步骤的影响。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 候选人的暴力模拟| O(n^3) 或更糟 | O(n) | 太慢/不必要|
 | 逆除数模拟 | O(n √n) | O(n √n) | O(n) | 已接受 |

 ## 算法演练

1. 计算n的所有除数。 每个除数对应于加密过程中使用的一个前缀反转操作。 我们需要它们，因为它们定义了转换序列。 
2. 按升序对除数进行排序。 这种排序至关重要，因为我们正在通过有效地撤销反转的分层结构来重建原始字符串。 
3. 从加密字符串 t 作为我们的工作数组开始。 我们将其视为可变字符列表以支持有效的前缀反转。 
4. 对于按排序顺序的每个除数 d，将前缀从索引 0 反转为 d − 1。应用此步骤是因为它反转了在前向过程中更改前缀的效果。 
5.处理完所有除数后，该数组代表原始字符串s，因此我们将其输出。 

### 为什么它有效

 加密过程中的每个操作都是对每个除数仅应用一次的前缀反转，但按降序排列。 前缀反转是自逆的，因此应用相同的反转两次可以恢复该前缀段的原始顺序。 

除数的嵌套结构确保在加密过程中较小的前缀在较大的前缀之后进行转换，这意味着它们的效果位于最终排列的“内部”。 通过按升序应用反转，我们从最里面的结构向外剥离变换。 这可以保持每一步的一致性，因为每次反转仅影响尚未恢复的前缀。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())
t = list(input().strip())

divs = []
for i in range(1, n + 1):
    if n % i == 0:
        divs.append(i)

divs.sort()

for d in divs:
    t[:d] = reversed(t[:d])

print("".join(t))
```该解决方案首先将字符串读入可变列表，以便可以有效地执行前缀反转。 除数是通过检查直到 n 的所有整数来计算的，考虑到较小的约束，这已经足够了。 

排序确保我们以正确的重建顺序应用转换。 每个前缀反转都是使用 Python 切片实现的，它干净地表达了操作，无需手动交换逻辑。 

最终连接将列表转换回字符串以进行输出。

 ## 边缘情况

 当 n = 1 时，除数集仅为 {1}。 该算法应用长度为 1 的前缀反转，使字符串保持不变，因此输出等于输入。 

对于素数 n，假设 n = 5，除数为 1 和 5。该算法首先反转前缀 1，不执行任何操作，然后反转整个字符串，恢复加密所强加的原始排序结构。 逐步逆转正确地撤消了单个有意义的转换。 

对于高度复合的n（例如12），在1、2、3、4、6、12处发生多个重叠的前缀反转。每个步骤仅修改与先前恢复的结构一致的前缀，因此后面的操作不会使先前的更正无效。
