 ## 解决方案

 ## 问题理解

 我们有一组围坐在桌子周围的玩家和多套纸牌。 每个玩家都有一个“偏好值”。 每个玩家必须收到完全相同数量的牌，并且每张牌必须分配给一个玩家。 

一旦分配确定，每个玩家只看他们收到的牌中有多少符合他们的首选值。 如果玩家准确地收到$t$匹配的牌，它们对总分的贡献是$h_t$，其中评分序列严格递增$t$。 零场比赛的玩家没有任何贡献。 

任务是将所有卡牌分配给玩家，使所有玩家的分数总和最大化。 

约束的结构已经说明了很多。 我们有多达 500 名玩家，但每个玩家最多只能收到 10 张牌。 这个小界限$k$是关键的结构性约束。 这意味着对于每个玩家，我们最多只需要考虑 10 个可能的“匹配计数”，任何尝试在不压缩的情况下单独跟踪所有卡牌分配的解决方案都会失败。 同时，卡牌总数可达5000张，无法单独处理卡牌； 我们必须按价值汇总它们。 

一种幼稚的方法是尝试将每张卡牌贪婪地分配给玩家或模拟分配。 这种情况很快就会被打破，因为卡牌的价值取决于全局分组效应：将一张卡牌交给一个玩家会阻止其帮助另一个玩家，并且卡牌的好处不是线性的，而是取决于玩家已经拥有多少张匹配的卡牌。 

一个稍微结构化但仍然不正确的贪婪想法是将每张牌交给当前受益最大的玩家。 这会失败，因为每次分配后边际收益都会发生变化，而未来的分配取决于早期的选择。 

一个关键的隐藏困难是多个玩家可能共享同一个最喜欢的号码。 相同价值的卡牌成为共享资源，必须在所有喜欢它的玩家之间进行最佳分配。 

暴露不正确的贪婪推理的边缘情况包括许多玩家拥有相同的最喜欢的数字但很少有匹配的牌的情况。 例如，如果十名玩家都喜欢价值 1，但只有三张价值 1 的牌存在，则任何策略都必须决定哪些玩家获得 1 场比赛，哪些球员没有获得任何比赛。 均匀分布卡牌或任意分配卡牌的幼稚方法可能会错过“激活”部分奖励的最佳玩家选择。 

另一个微妙的情况是当$h_t$小的增长非常快$t$。 那么最好将比赛集中到较少的玩家身上，而不是平均分配。 任何假设平均分配是最优的解决方案在这里都会失败。 

## 方法

 蛮力视角是考虑对玩家的每一次卡牌分配。 对于每张卡，选择其中之一$n$球员，尊重能力$k$。 这立即给出了粗略的$n^{kn}$最坏情况下的可能性，即使对于很小的投入来说，也是天文数字。 即使按值修剪也没有多大帮助，因为依赖性不是局部于卡牌而是局部于最终的每个玩家计数。 

结构洞察力是停止考虑单独的卡片，而是按价值对所有内容进行分组。 对于固定值$x$，假设有$c$该值的卡片，并假设$m$玩家有最喜欢的价值$x$。 只有这些玩家才关心这些卡牌。 对于每个这样的玩家，我们只关心有多少$c$他们收到的卡片最多$k$。 

所以问题就变成了：对于每个价值组，独立地将相同的物品（相同价值的卡片）分配到箱子（玩家）中，每个箱子都有容量$k$，而一个箱子的收益仅取决于它收到的物品数量。 这是一个经典的背包式 DP 相对于玩家的价值。 

我们按价值来处理玩家的价值。 对于固定值，我们计算每个玩家如果收到$t$匹配这个值，然后我们选择如何分配可用的$c$其中的卡片。 自从$k \le 10$，我们可以做一个 DP，我们逐一处理玩家并跟踪到目前为止已经分配了多少张具有该值的牌。 

对于每个玩家，我们尝试所有可能数量的牌$t$从 0 到$k$，以剩余卡为界，并相应地转换 DP 状态。 

关键的减少是值是独立的，因为不同值的卡牌在玩家的该值的比赛计数中永远不会相互作用。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（单独分配每张卡）| 指数| O(1)-O(nk) | O(1)-O(nk) | 太慢了|
 | 按值分组 DP | O(nk²) | O(nk) | O(nk) | 已接受 |

 ## 算法演练

 我们单独处理每个不同的卡值，并将最佳贡献积累到全局答案中。 

1. 计算每张牌值出现的次数。 对于每个值$x$，我们知道存在多少张牌。 
2. 按玩家最喜欢的号码对他们进行分组。 对于每个值$x$, 收集所有最喜欢的玩家$x$。 只有这些玩家才能从有价值的卡牌中受益$x$。 
3. 对于固定值$x$，定义一个 DP 数组，其中$dp[i][j]$表示考虑第一个因素后的最大总增益$i$该组中的玩家并且分布准确$j$价值卡$x$。 
4. 初始化$dp[0][0] = 0$，以及所有其他状态都是不可能的。 
5. 对于该组中的每个玩家，计算转换：

 对于每个当前分配$j$，尝试给这个玩家$t$卡，在哪里$0 \le t \le k$和$j + t \le c_x$。 

添加的增益为$h_t$。 

我们更新$dp[i+1][j+t]$因此。 

这样做的原因是每个玩家的奖励仅取决于他们自己的比赛数量，而不取决于这些比赛如何在其他人之间分配。 
6. 对所有玩家进行价值处理后$x$，获取该组的最佳可实现值并将其添加到全局答案中。 
7. 对所有不同的值重复此操作。 

所有值的最终总和就是答案。 

### 为什么它有效

 关键的不变量是对于每个值$x$，DP充分探索了所有有效分布$c_x$感兴趣的玩家之间存在相同的物品$x$，同时保留最佳子结构：一旦我们决定玩家获得多少物品，他们的贡献就变得固定并且独立于其他人，除了剩余容量限制。 由于值是独立的，并且玩家只能从每个值的自己的比赛中获益，因此单独优化每个值并求和是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    cards = list(map(int, input().split()))
    fav = list(map(int, input().split()))
    h = [0] + list(map(int, input().split()))

    from collections import defaultdict

    cnt = defaultdict(int)
    for x in cards:
        cnt[x] += 1

    players_by_val = defaultdict(list)
    for i, x in enumerate(fav):
        players_by_val[x].append(i)

    ans = 0

    for val, players in players_by_val.items():
        c = cnt[val]
        if c == 0:
            continue

        m = len(players)

        dp = [[-1] * (c + 1) for _ in range(m + 1)]
        dp[0][0] = 0

        for i in range(m):
            ndp = [[-1] * (c + 1) for _ in range(m + 1)]
            for j in range(c + 1):
                if dp[i][j] < 0:
                    continue
                cur = dp[i][j]
                for t in range(k + 1):
                    if j + t > c:
                        break
                    val_gain = cur + h[t]
                    if ndp[i + 1][j + t] < val_gain:
                        ndp[i + 1][j + t] = val_gain
            dp = ndp

        best = 0
        for j in range(c + 1):
            best = max(best, dp[m][j])

        ans += best

    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先将输入压缩为频率计数和玩家组，确保我们永远不会直接处理单个卡牌。 然后 DP 会根据每个值独立运行。 

转换循环显式尝试所有分配$k$每个玩家的牌数。 帽子$c + 1$确保我们永远不会超出可用卡数。 使用$-1$因为不可能状态会阻止无效转换的传播。 

最终聚合只是将每个值组的最佳贡献相加，因为不存在跨值耦合。 

## 工作示例

 ### 示例 1

 输入：```
n=4, k=3
cards: 1 3 2 8 5 5 8 2 2 8 5 2
fav:   1 2 2 5
h:     2 6 7
```我们独立处理每个值。 

对于值 2，有多张牌并且有两个玩家感兴趣。 

| 步骤| 玩家| 已分配的卡片 | DP 状态摘要 |
 | --- | --- | --- | --- |
 | 1 | P2（最爱=2）| 尝试 t=0..3 | 分配早期质量|
 | 2 | P3（最爱=2）| 继续分配| 最佳分离浓缩物匹配|

 最佳解决方案最终为两名玩家提供了足够的比赛来达到目标$h_2 = 6$每个，而其他人则接受不同的价值观。 值 8 没有任何贡献，因为没有玩家喜欢它。 

最终总和变为：

 玩家1：2个，玩家2：6个，玩家3：6个，玩家4：7个，总共21个。 

这证实了 DP 正确地集中了相同价值的牌，而不是均匀地分布它们。 

### 示例 2（已构建）

 输入：```

```我们有：

 值 1：3 张牌，1 名玩家

 值 2：2 张牌，1 名玩家

 值 3：1 张牌，1 名玩家

 每个组都是独立的。 

对于值 1，将两张牌都交给单个玩家会产生$h_2 = 10$。 剩余卡未使用或与他人无关。

 对于值 3，只有一张卡存在，因此贡献为$h_1 = 1$。

 ## 边缘情况

 一种微妙的边缘情况是当某个值出现在牌中但没有玩家喜欢它时。 该算法自然会忽略它，因为该值的玩家列表为空，因此其贡献为零。 这可以防止意外浪费 DP 运行。 

另一种情况是牌的数量少于想要它们的玩家的数量。 例如，如果三名玩家想要一个值，但只有一张牌存在，则 DP 确保只有一名玩家获得$t=1$和其他人得到$t=0$, 最大化$h_1$对于单个作业，而不是错误地分配零贡献。 

第三种情况是当$h_t$增长迅速，因此即使有多个玩家符合资格，也最好将所有牌集中到一个玩家身上。 DP 明确评估所有分配，因此当它产生更高的总奖励时，它自然会选择这种集中分配。
