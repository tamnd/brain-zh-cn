 ## 解决方案
 ## 问题理解

 我们被要求数出固定金额有多少种不同的方式$N$可以使用 50、100 和 200 面额的纸币准确支付，其中每种面额可以使用任意次数。 没有找零的概念，因此有效的方法就是将这些钞票组合起来，其总和等于$N$。 

如果使用的 50、100 或 200 卢布纸币数量不同，则两种方式被视为不同。 选择音符的顺序并不重要，只有最后的才是重要的。 

从计算的角度来看，我们正在计算以下形式的方程的整数解：$$50a + 100b + 200c = N$$在哪里$a, b, c \ge 0$。 

约束条件$N \le 10^6$已经排除了天真地枚举所有三元组的可能性。 在最坏的情况下，对可能的计数进行三次甚至二次扫描会太慢，因为$N / 50 = 20000$，这使得嵌套循环可能很大，但如果仔细限制的话仍然可以管理。 关键是将问题简化为单个循环或直接计数。 

边缘情况立即从可分性中出现。 如果$N$不能被 50 整除，因此没有解决方案，因为所有面额都是 50 的倍数。例如，输入 36 根本无法形成，因此答案必须为 0。忘记这一点的幼稚实现将浪费时间进行无用的迭代。 

另一个微妙的情况是$N = 0$。 正确的解释是，只有一种方式可以实现零支付：根本不使用纸币。 任何错误地初始化答案或跳过空组合的实现都将在此处失败。 

最后，像这样的小值$N = 50$应恰好产生一个解，而更大的倍数（例如 200）应反映跨多个面额的所有有效分解。 

## 方法

 直接暴力法是尝试所有可能的200卢布纸币数量，然后尝试所有可能的100卢布纸币数量，并计算是否可以用50卢布纸币组成剩余的总和。 对于每对$(b, c)$，我们计算：$$r = N - 200c - 100b$$并检查是否$r \ge 0$并能被 50 整除。如果是，我们增加答案。 

这是有效的，因为每个有效的解决方案都对应于一对$(b, c)$，然后唯一确定 50 卢布纸币的数量。 

复杂性取决于有多少个值$c$和$b$我们尝试。 自从$c \le N/200$和$b \le N/100$，最坏的情况大约是$O((N/200) \cdot (N/100)) = O(N^2)$最差缩放意义上的迭代。 和$N$最多$10^6$，这太慢了。 

关键的观察结果是我们不需要显式迭代所有 50 卢布纸币。 一旦我们修好$b$和$c$，值$a$是唯一确定的。 所以问题归结为计算有效值$(b, c)$满足可分性约束的对，这可以在$O(N/200)$通过迭代$c$并解决$b$从算术上来说。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解 (b, c) |$O((N/200)(N/100))$|$O(1)$| 太慢了 |
 | 修复 200 秒，解决 100/50 |$O(N/200)$|$O(1)$| 已接受 |

 ## 算法演练

 我们重写方程：$$50a + 100b + 200c = N$$将所有内容除以 50：$$a + 2b + 4c = M$$在哪里$M = N / 50$。 如果$N$不能被 50 整除，答案立即为零。 

我们现在计算非负整数解$a + 2b + 4c = M$。 

### 步骤

 1. 检查是否$N \bmod 50 \neq 0$。 如果是，则返回 0，因为有效纸币的组合无法形成这样的总和。 这立即消除了不可能的情况。 
2. 设置$M = N / 50$。 现在问题变成了以标准化单位计算解，这简化了算术并避免了重复的乘法。 
3. 迭代 200 卢布纸币的数量$c$。 每个$c$贡献$4c$单位为总和。 最大可能$c$是$M // 4$，因为在这个缩放系统中每个单位值 4。 
4.对于每个固定$c$，计算剩余金额：$$rem = M - 4c$$这表示仅使用 50 和 100 钞票组成的部分。 
5. 现在我们计算以下解决方案：$$a + 2b = rem$$对于固定的$b$,$a$被唯一确定为$a = rem - 2b$，所以我们只需要有效的$b$这样$rem - 2b \ge 0$。 

有效数量$b$值为：$$\left\lfloor \frac{rem}{2} \right\rfloor + 1$$6.将此计数添加到每个的答案中$c$，累积所有有效分解。 

### 为什么它有效

 每个解决方案$(a, b, c)$由其值唯一标识$c$。 对于每个固定$c$，剩余方程简化为一维计数问题$b$，其中每个有效$b$恰好对应于一个有效的$a$。 这将完整的解决方案空间划分为不相交的切片，索引为$c$，因此对所有切片求和只会对每个解决方案进行一次计数，不会重复或遗漏。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input().strip())

    if N % 50 != 0:
        print(0)
        return

    M = N // 50
    ans = 0

    for c in range(M // 4 + 1):
        rem = M - 4 * c
        ans += rem // 2 + 1

    print(ans)

if __name__ == "__main__":
    solve()
```该实现直接遵循归一化单位的简化方程。 一开始的整除性检查至关重要，因为跳过它会错误地将不可能的情况视为具有分数解。 

循环结束$c$代表确定200卢布纸币的数量。 然后将剩余金额分配在 100 至 50 卢布纸币之间，其中每张 100 卢布纸币消耗 2 个标准化单位。 表达式`rem // 2 + 1`计算 100 卢布纸币的所有可能数量，从 0 到剩余金额允许的最大数量。

 ## 边缘情况

 对于$N = 0$，算法集$M = 0$。 循环运行一次$c = 0$, 给予$rem = 0$并做出贡献$0 // 2 + 1 = 1$。 这可以正确计算空组合。 

对于非 50 的倍数，例如$N = 36$，早期检查立即返回 0。如果没有这个保护，整数除法将默默地产生不正确的标准化值并过度计算不可能的状态。 

对于小精确倍数，例如$N = 50$，无需特殊套管，循环结构仍然有效。 和$M = 1$， 仅有的$c = 0$是有效的并且恰好产生一种配置，与预期的解释相匹配。
