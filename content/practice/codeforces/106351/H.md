 ## 解决方案
 # 问题理解

 给定一个正整数的集合`A`。 我们必须分配另一个正整数`B_i`每一个元素，让每一个产品`A_i * B_i`是完全相同的值。 在所有可能的分配中，我们需要所有选择的总和最小`B_i`。 约束条件是`N`最多`2 * 10^5`，而每一个`A_i`至多是`20`。 

关键的限制是每个值都很小`A_i`。 由于只涉及几个可能的质因数，因此可以通过质因数分解而不是通过大型通用算法来处理所有乘积的共同值。 尝试公共产品的可能值的解决方案将立即失败，因为答案可能会变得比输入值大得多。 和`N = 200000`，我们需要一个接近线性时间的算法。 

主要的边缘情况来自包含不同素数幂的重复值和数字。 例如，如果输入是：```
3
2 2 2
```正确的输出是：```
3
```常见的产品可以是`2`，给每一个`B_i = 1`，所以总和是`3`。 粗心的实现可能会将所有数字相乘并将其用作目标，从而产生更大的答案。 

另一个重要的情况是当一个数字已经包含素数的更大幂时：```
3
2 4 8
```正确的输出是：```
7
```最小的共同产品是`8`, 给予`B = [4, 2, 1]`。 一般来说，仅使用数组中看到的最大值是不够的，因为公共乘积必须可以被每个值整除。 

# 方法

 一种直接的方法是寻找尽可能小的公共值`X`使得每个`A_i`划分`X`。 一次`X`已知，每个值都是强制的，因为`B_i = X / A_i`。 这是正确的，因为选择通用产品后就没有自由了。 

然而，尝试可能的值`X`是不可能的。 即使输入很小，最小公倍数也可以快速增长，并且没有允许枚举的有用上限。 

改变问题的观察结果是，公积必须恰好是所有乘积的最小公倍数`A_i`。 任何有效的普通乘积都是 LCM 的倍数，选择更大的倍数只会增加每个`B_i`。 因此，最佳目标是LCM本身。 

因为每一个`A_i`至多是`20`，我们只需要保留每个质因数的最大指数`2`到`20`。 例如，如果数字包含`2`,`4`， 和`8`，LCM需要`2^3`。 找到这些素数指数后，我们重建 LCM 并计算所需的总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 无法绑定| O(1) | O(1) | 太慢了|
 | 最佳| O(N) | O(1) | O(1) | 已接受 |

 # 算法演练

 1. 计算输入中出现的每个素数的最大幂。 

因为每个值最多都是`20`，唯一相关的素数是`2`,`3`,`5`,`7`,`11`,`13`,`17`， 和`19`。 对每个数字进行因式分解是一项持续的工作。 
2. 根据这些最大幂建立最小公倍数。 

LCM 包含任何输入数所需的最大指数的每个质因数。 这是能被所有数整除的最小数`A_i`。 
3. 添加`LCM / A_i`对于每个输入值。 

如果常见的产品是`LCM`， 然后`A_i * B_i = LCM`， 所以`B_i`是唯一确定的。 

为什么有效：每个有效的解决方案都会选择一些数字`X`可以被每一个整除`A_i`。 最小的数字是 LCM。 任何其他有效的`X`是 LCM 的倍数并且至少一样大，这使得每个值`X / A_i`至少与`LCM / A_i`。 因此，LCM 分配使总和最小化。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    primes = [2, 3, 5, 7, 11, 13, 17, 19]
    best = [0] * len(primes)

    for x in a:
        for i, p in enumerate(primes):
            cnt = 0
            while x % p == 0:
                x //= p
                cnt += 1
            if cnt > best[i]:
                best[i] = cnt

    lcm = 1
    for p, e in zip(primes, best):
        lcm *= p ** e

    ans = 0
    for x in a:
        ans += lcm // x

    print(ans)

if __name__ == "__main__":
    solve()
```第一个循环提取素数指数。 由于数字很小，重复除法比存储一般因式分解结构更快、更简单。 

变量`best`存储LCM信息。 对于每个素数，它都会记住迄今为止遇到的最大指数。 LCM 重建将每个质数与其存储的指数相乘一次。 

最后的循环使用整数除法，因为保证 LCM 可被每个输入值整除。 Python 整数还避免了溢出问题，尽管最终答案对于典型的竞争性编程限制来说仍然足够小，因为数字的最大 LCM 可达`20`是有限的。

 # 边缘情况

 对于重复值的情况：```
3
2 2 2
```该算法发现素数的最大指数`2`是 1，所以 LCM 是`2`。 每个值都贡献`2 / 2 = 1`，给出答案`3`。 该方法从不将重复值相乘，因此可以避免高估目标。 

对于主功率情况：```
3
2 4 8
```因子数为`2^1`,`2^2`， 和`2^3`。 存储的最大指数为 3，产生的 LCM 为`8`。 贡献是`4`,`2`， 和`1`，给出最小可能的总和`7`。 

对于单个元素：```
1
15
```一个数字的最小公倍数就是该数字本身。 唯一可能的选择是`B_1 = 1`，所以答案是`1`。 该算法自然会处理这个问题，因为不需要与其他值进行比较。
