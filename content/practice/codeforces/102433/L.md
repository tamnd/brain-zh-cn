 ## 解决方案
 ## 问题理解

 此问题中的运算是普通的十进制乘法，但有一个关键的变化：只要多个乘积位于相同的小数位置，它们的总和就会以 10 为模，因此不会有进位移动到下一个位置。 

如果未知数的位数为a 0 ​ ,a 1 ​ ,…，从右向左数，则其无进位方格中k位置的数字为

 c k ​ ≡ i=0 Σ k ​ a i ​ a k−i ​ (mod10)。 

给定 N 的十进制位数，最多 25 位，并且需要无进位平方恰好为 N 的最小正十进制整数。如果不存在这样的整数，我们打印`-1`。 

25 位数字的限制排除了枚举可能的根。 如果 N 有 25 位数字，则其根最多可以有 13 位数字，因此直接搜索将检查最多 9⋅10 12 个正候选。 即使对每个候选人进行非常便宜的检查也将远远超出一秒的限制。 

第一个结构限制是长度。 正 m 位数字有一个无进位平方，其最高可能的非零位置是 2m−2，因为前导数字与其自身相乘，并且不能以 10 为模变为零，除非前导数字为零，这是禁止的。 因此结果恰好有 2m−1 位。 偶数长度的 N 永远不可能有正的无进位平方根。 

例如，`15`有两位数，所以答案是`-1`。 当答案在结构上不可能时，仅搜索候选根到某个数字界限的粗心实现可能会浪费时间搜索。 

最低有效数字也必须是模 10 的平方。可能的余数为 0、1、4、5、6、9。 因此`2`立刻就不可能了。 简单地为最不重要的位置选择任意数字的搜索将探索许多可能被立即拒绝的分支。 

也可能有多个有效根，因此找到任何根是不够的。 为了`121`， 两个都`11`和`99`是无进位平方根，因为`99`进位被丢弃后，数字为 1,2,1。 所需答案是`11`。 按升序搜索数字可以让我们获得最小的根，而不必随后对所有解决方案进行排序。 

最后，根内部可能包含零数字。 例如，13位数字`1000000000000`有无进位正方形`1000000000000000000000000`。 将零视为数字位数较少会错误地拒绝这种有效情况。 

## 方法

 直接的方法是用所需的位数枚举每个可能的正根，计算其无进位平方，并将其与 N 进行比较。这是正确的，因为每个可能的答案都经过显式测试。 对于 25 位 N，根有 13 位，给出 9⋅10 12 个可能的根。 如果直接计算无进位平方，则本身需要 O(13 2 ) 位运算，因此暴力方法是没有希望的。 

有用的观察结果是结果数字是从右到左确定的。 假设我们已经知道 a 0 ​ ,…,a k−1 ​ 并且想要确定 a k ​。 k 位置处的系数为

 ck ​ ≡a 0 ​ a k ​ +a 1 ​ a k−1 ​ +⋯+a k−1 ​ a 1 ​ +a k ​ a 0 ​ (mod10)。 

除了包含 k 的两个项外，所有项都是已知的。 因此

 ck ​ ≡S k ​ +2a 0 ​ a k ​ (mod10),

 其中 S k ​仅取决于先前选择的数字。 

更方便的索引是从最低有效侧生成数字。 在位置 k，从 0 到 9 的每个候选数字都可以根据已知的正方形前缀进行测试。 由于未知数字出现在系数为 2 模 10 的线性表达式中，因此最多有两个可能的值可以工作。 第一个数字具有特殊方程 a 0 2 ​ ≡c 0 ​ (mod10)，对于每个可能的目标数字也最多有两个根。 

这将搜索从大约 10 13 个可能性更改为最多 2 13 =8192 个分支。 一旦知道了所有根数字，我们就验证正方形的剩余高位。 这与使递归数字构造在这里有效的前缀原理相同：无进位平方的前 k+1 位数字仅取决于根的前 k+1 位数字。 

由于候选项是在每个位置按递增的数字顺序生成的，因此找到的第一个完整根是最小的根。 或者，我们可以保留所有有效根中的最小值，这使得正确性论证独立于遍历顺序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(10 n/2 n 2 ) | O(10 n/2 n 2 ) | O(n) | 太慢了|
 | 数字DFS | O(2 n/2 n 2 ) | O(2 n/2 n 2 ) | O(n) | 已接受 |

 这里n≤25是N的位数。 

## 算法演练

 1. 将 N 作为字符串读取，并令 n 为其位数。 如果 n 是偶数，则立即打印`-1`。 m 位正数的无进位平方始终恰好有 2m−1 位，因此不会出现偶数长度目标。 
2. 设m=(n+1)/2，即根的唯一可能位数。 按照从最低有效位到最高有效位的顺序存储 N 的数字，因为递归构造将朝该方向进行。 
3. 开始深度优先搜索，不选择根数字。 在位置 k=0 处，尝试从 0 到 9 的每个数字 x 并保持满意的数字

 x 2 mod10=N 0 ​ .

 这是未知数字在卷积中仅出现一次的唯一位置。 
4. 对于后面的每个位置 k，尝试从 0 到 9 的每个数字 x。暂时设置 a k ​ =x 并计算

 ( i=0 Σ k ​ a i ​ a k−i ​ )mod10。 

仅当等于目标数字 N k 时才继续递归。 新检查的结果数字不能依赖于位置 k 之外的任何根数字，因此拒绝此处的分支永远不会丢弃有效的解决方案。 
5. 当选择位置 m−1 时，要求该数字非零。 否则，假定的根的位数将少于 m，这与步骤 1 中的长度计算相矛盾。 
6. 一旦所有 m 个根数字都固定下来，计算从位置 m 到 2m−2 的每个剩余平方数字，并将其与 N 进行比较。这些位置是根中不包含新的未知数字的第一个位置，因此在构建下半部分时无法检查它们。 
7. 将每个完整的有效数字数组转换为整数，并保留最小的一个。 如果没有分支到达有效的完整方块，则打印`-1`。 

### 为什么它有效

 在递归深度 k 处，k 以下的每个根数字都已固定。 位置 k 处的无进位平方数仅取决于根数字 a 0 ​ ,…,a k ​，因此检查该数字是否准确确定当前的部分根是否仍然可以得出解决方案。 每个有效的根都遵循一个通过所有这些检查的分支，因此无法对其进行修剪。 相反，通过所有 m 个根数字接受的分支会针对 N 的每个数字进行全面检查，因此每个报告的根都是真正有效的。 取所有有效根中的最小值恰好给出所需的最小正根。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(s):
    n = len(s)

    # A carryless square of an m-digit positive number
    # has exactly 2*m-1 digits.
    if n % 2 == 0:
        return "-1"

    m = (n + 1) // 2

    # Target digits, least significant first.
    target = [ord(ch) - ord('0') for ch in reversed(s)]

    # Root digits, least significant first.
    a = [0] * m
    best = None

    def dfs(k):
        nonlocal best

        if k == m:
            # The lower m digits were already checked while constructing
            # the root. Check the remaining digits of the square.
            for pos in range(m, n):
                total = 0
                lo = pos - (m - 1)
                hi = m - 1

                for i in range(max(0, lo), hi + 1):
                    j = pos - i
                    if 0 <= j < m:
                        total += a[i] * a[j]

                if total % 10 != target[pos]:
                    return

            value = 0
            for d in reversed(a):
                value = value * 10 + d

            if best is None or value < best:
                best = value
            return

        start = 0
        end = 10

        # The most significant digit must be nonzero.
        if k == m - 1:
            start = 1

        for x in range(start, end):
            a[k] = x

            total = 0
            for i in range(k + 1):
                total += a[i] * a[k - i]

            if total % 10 == target[k]:
                dfs(k + 1)

    dfs(0)

    return "-1" if best is None else str(best)

def main():
    s = input().strip()
    print(solve_case(s))

if __name__ == "__main__":
    main()
```输入保留为字符串，因为目标可以包含 25 位数字，尽管 Python 本身可以轻松处理这样的整数。 更重要的是，显式存储数字使无进位卷积变得自然。 

数组`target`是相反的所以`target[0]`是个位数。 根数组`a`使用相同的方向，这使得位置处的系数`k`简单的总和`a[i] * a[k-i]`。 

期间`dfs(k)`，只有位置处的系数`k`需要检查。 其所有术语最多涉及指数`k`，所以未来的选择不能改变这个系数。 这是算法的关键剪枝条件。 

选择所有根数字后的上限检查从位置开始`m`。 以下职位`m`在递归过程中已经被检查过。 对于 13 位根，正方形有位置`0`通过`24`，因此循环正确检查位置`13`通过`24`。 

Python整数具有任意精度，因此将根转换为整数时不存在溢出问题。 最大的根只有13位。 

仅当以下情况时才应用非零限制`k == m - 1`。 零在所有较低位置都完全有效。 较早应用限制会错误地拒绝根，例如`1000000000000`。

 ## 边缘情况

 目标数字的个数为偶数是不可能的。 为了`15`，长度为 2，但正 m 位根总是产生 2m−1 位数字，这是奇数。 算法返回`-1`在启动 DFS 之前，避免不必要的搜索。 

最后一位不是模 10 的二次余数的目标也是不可能的。 为了`2`，第一个方程需要 0 2 ​ ≡2(mod10)。 没有十进制数字有这样的平方余数，因此 DFS 没有存活分支并返回`-1`。 

多个根不得导致返回任意答案。 为了`121`，根包括`11`和`99`。 DFS 探索可能的数字并验证完整的平方，同时`best`存储最小数值根。 结果的答案是`11`。 

前导零不得被视为较短根的一部分。 为了`1000000000000000000000000`，目标有25位，所以根必须有13位。 根`1000000000000`正好有这个长度，它唯一的非零卷积项是它的前导数字的平方，产生 25 位的目标。 该实现允许每个较低位置为零，但要求代表最高有效数字的最终根数字非零。 

一位数的情况也锻炼了递归的边界。 为了`6`，根只有一位数，因此没有更高的系数需要验证。 单位方程单独给出有效根`4`和`6`，最小值为`4`，匹配所需的答案。
