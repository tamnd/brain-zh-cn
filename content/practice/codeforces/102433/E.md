 ## 解决方案
 ## 问题理解

 我们有一个小写字符串，我们想要计算它选择的字符都不同的子序列。 子序列由我们选择的位置决定，因此选择第一个`a`从`aab`并选择第二个`a`是不同的子序列，即使两者都产生单字符字符串`a`。 空子序列也是有效的。 

关键问题并不在于字母的顺序。 一旦我们决定选择哪些位置，它们的原始顺序就会自动给出一个子序列。 对于彩虹子序列，每个字母可以贡献零个选定位置或恰好一个选定位置。 这一观察将问题转化为独立选择的产物。 

字符串的最大长度`100000`，因此检查所有子序列的算法是完全不可行的。 有`2^n`子序列，对于`n = 100000`。 即使是具有二次时间的算法，大约`10^10`最大尺寸的操作将远远超出一秒的限制。 我们需要一个线性或近线性的解决方案。 

有几种边缘情况可能会导致粗心的实施失败。 为了`a`，正确答案是`2`，因为我们可以选择`a`或者什么都不选择。 忘记空子序列的实现将返回`1`。 

为了`aaa`，答案是`4`。 我们可以不选择这三个位置中的任何一个，或者只选择这三个位置中的一个。 选择两个位置是无效的，因为生成的子序列两次包含相同的字母。 一个常见的错误是计算不同的结果字符串而不是不同的位置选择，这会错误地只给出`2`，即空字符串和`a`。 

为了`aab`，答案是`6`。 有效子序列是空子序列、三个单字符子序列和两个包含 1 的有效长度为 2 的子序列。`a`和`b`。 的两种选择`a`之所以不同，是因为他们使用的位置不同。 

## 方法

 直接的解决方案将枚举位置的每个子集。 对于每个子集，我们可以检查所选字符并检查是否有字母出现两次。 这是正确的，因为位置的每个子集恰好代表一个子序列。 然而，有`2^n`子集，并且检查每个子集本身可能需要花费`O(n)`时间。 由此产生的最坏情况复杂度是`O(n 2^n)`， 和`2^100000`最大输入大小的候选子序列。 即使产生这些候选人也是不可能的。 

有用的观察结果是，彩虹子序列独立地对每个字母施加了极其简单的限制。 假设这封信`c`发生`cnt[c]`原始字符串中的次数。 在彩虹子序列中，正好有`cnt[c] + 1`这封信的可能性：不选择它出现的任何一个，或者只选择其中一个`cnt[c]`发生。 

这些选择在不同字母之间是独立的。 如果我们选择出现一次`a`并且出现一次`b`，它们的位置已经决定了子序列中的顺序。 我们不需要做出额外的订购选择。 因此，每个字母选择的每一种组合都恰好产生一个有效的彩虹子序列，并且每个有效的彩虹子序列恰好对应于一个这样的组合。 

由于有 26 个小写字母，因此总数为

 [
 \prod_{c='a'}^{'z'} (cnt[c] + 1)。 
]

 通过为每个字母选择零次出现来自然地包含空子序列。 

暴力破解之所以有效，是因为子序列完全由其选定的位置决定，但它会失败，因为位置子集的数量呈指数级增长。 每个字母可以独立选择零次或一次的观察结果将问题简化为计算 26 个频率并乘以 26 个小因子。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |`O(n 2^n)`|`O(n)`| 太慢了|
 | 频率产品|`O(n + 26)`|`O(26)`| 已接受 |

 ## 算法演练

 1. 创建一个频率数组，其中每个小写字母都有一个条目。 扫描一次字符串并增加每个字符对应的频率。 这给了我们可以选择每个字母的可能位置的数量。 
2. 初始化答案`1`。 这表示未选择任何字母的单一选择，即空子序列。 
3. 对于每个小写字母，将答案乘以`cnt[c] + 1`并减少它的模数`11092019`。 该因子计算该字母的所有可能性：选择不出现或仅选择其出现之一。 
4. 打印最终产品。 由于每个字母的选择都是独立的，因此该产品只会对每个彩虹子序列计数一次。 

### 为什么它有效

 考虑任何彩虹子序列。 对于每个字母，记录它是否不存在，或者如果存在，则选择该字母的哪个出现。 由于子序列不包含重复的字母，因此该描述对于每个字母都有一个选择：如果不存在，则为零个选择；如果存在，则选择其出现之一。 相反，这些每个字母选择的任何集合最多为每个字母选择一个位置，因此当按原始顺序读取时，所选位置始终形成彩虹子序列。 因此，彩虹子序列和由 计算的组合之间存在一一对应的关系

 [
 \prod_c (cnt[c]+1)。 
]

 乘法精确计算所需的对象，包括空子序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 11092019

def solve():
    s = input().strip()

    cnt = [0] * 26
    for ch in s:
        cnt[ord(ch) - ord('a')] += 1

    ans = 1
    for x in cnt:
        ans = ans * (x + 1) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```第一个循环构建频率数组。 由于输入仅包含小写英文字母，`ord(ch) - ord('a')`将每个字符直接映射到范围中`0`通过`25`。 

第二个循环应用乘积公式。 开始于`ans = 1`是必要的，因为必须计算空子序列。 对于出现的一封信`x`次，乘以`x + 1`考虑了省略该字母或选择其出现之一的所有方法。 

每次乘法后都会应用模数。 Python 整数不会溢出，但在整个计算过程中保持值减少对于所需的答案来说是自然的，并且使中间值保持较小。 频率因子不存在相差一的问题：如果一个字母出现一次，它的因子是`2`，代表“不选择它”和“选择它唯一的出现”； 如果它出现零次，它的因子是`1`并且没有任何效果。 

## 工作示例

 ### 示例 1：`aab`频率计数为`a = 2`和`b = 1`，而其他所有字母的频率为零。 该产品因此成为`(2 + 1)(1 + 1) = 6`。 

| 人物 | 频率| 因素 | 运行答案|
 | ---| ---| ---| ---|
 |`a`| 2 | 3 | 3 |
 |`b`| 1 | 2 | 6 |
 |`c`通过`z`| 0 | 各 1 个 | 6 |

 三个选择对于`a`分别选择两个出现的情况、选择第一个出现的情况或选择第二个出现的情况。 两个选择对于`b`是选择还是不选择。 它们的组合给出六个有效子序列，包括空子序列。 

### 示例 2：`icpcprogrammingcontest`非零频率是`c = 3`, 八个字母与频率`2`，即`g`,`i`,`m`,`n`,`o`,`p`,`r`， 和`t`，以及三个带有频率的字母`1`，即`a`,`e`， 和`s`。 

| 频率组 | 字母数量 | 每个字母的系数 | 贡献|
 | ---| ---| ---| ---|
 | 3 | 1 | 4 | 4 |
 | 2 | 8 | 3 | 6561 | 6561
 | 1 | 3 | 2 | 8 |
 | 0 | 14 | 14 1 | 1 |

 最终的答案是

 [
 4 × 3^8 × 2^3 = 209952。 
]

 该迹线说明了为什么在计算频率后不需要考虑实际位置。 每次我们从每个选定的字母中选择一次出现时，原始索引会自动建立子序列顺序。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |`O(n + 26)`| 一次对字符进行计数，然后将 26 个因子相乘。 |
 | 空间|`O(26)`| 仅存储每个小写字母的频率。 |

 和`n`最多`100000`，该算法仅对输入执行一次线性扫描，然后执行 26 个恒定大小的操作。 与枚举或比较子序列的任何方法不同，这很容易在预期限制内。 

## 测试用例```python

import io

MOD = 11092019

def solution(s):
    cnt = [0] * 26

    for ch in s:
        cnt[ord(ch) - ord('a')] += 1

    ans = 1
    for x in cnt:
        ans = ans * (x + 1) % MOD

    return str(ans)

def run(inp: str) -> str:
    return solution(inp.strip())

# Provided samples
assert run("aab") == "6", "sample 1"
assert run("icpcprogrammingcontest") == "209952", "sample 2"

# Minimum-size input
assert run("a") == "2", "single character"

# All characters equal

# Every character distinct

```| 测试输入| 预期产出 | 它验证了什么 |
 | ---| ---| ---|

 |`aaa`|`4`| 重复字母和基于位置的子序列 |

## 边缘情况

 对于单字符输入`a`，频率`a`是`1`，所以它的因子是`2`。 每个其他角色都贡献一个因素`1`。 最终的答案是`2`，对应于空子序列和包含唯一位置的子序列。 

为了`aaa`，频率`a`是`3`，所以答案是`3 + 1 = 4`。 四个选项都选no`a`、选择位置一、选择位置二或选择位置三。 该算法从不计算一对位置，因为单个字母在彩虹子序列中只有一个选择槽。 

为了`aab`，因素是`3`为了`a`和`2`为了`b`，生产`6`。 这捕获了对不同的结果字符串进行计数而不是对不同的位置选择进行计数的错误。 两个子序列包含`a`和`b`可以使用两者中的任何一个`a`位置，因此必须将它们都计算在内。 

对于每个小写字母只包含一次的字符串，每个子序列自动都是彩虹。 有`2^26`位置的子集，乘积公式准确给出`2`对于 26 个字母中的每一个，产生`2^26`。 这将检查算法是否正确处理最大可能数量的不同字母。 

为了`100000`的副本`a`，答案是`100001`。 只能选择一个位置，因为选择两个位置会重复`a`。 该算法直接从单因素中获得这一点`100000 + 1`，证明大频率不需要对位置进行动态编程。
