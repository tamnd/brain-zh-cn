 ## 解决方案
 ## 问题理解

 该问题给出了三根整数长度的木棍，并允许我们精确选择一根木棍并将其扩展至任意数量`k`。 新的三个长度必须形成一个三角形，任务是找到该三角形的最大可能面积。 该运算可以使用分数扩展，因此最终的边长不限于整数。 输入包含多个测试用例，每个测试用例提供三个原始棒长度和允许的最大延伸。 输出是每种情况下可实现的最大三角形面积。 

长度和`k`至多是`10^4`，但是测试用例的数量可能会使暴力方法变得昂贵。 时间限制需要直接的数学解决方案。 即使有合理数量的候选，尝试每一个可能的新长度的解决方案也是不必要的，因为该区域对于固定的边对有一个简单的最大点。 每个测试用例我们需要恒定的工作量。 

有几种边缘情况可能会破坏粗心的实现。 如果在使用扩展之前最佳三角形已经存在，则答案不应增加任何边。 例如：```
1
3 4 5 10
```有边的直角三角形`3, 4, 5`已有面积`6`。 将边增加到任意大的值会使三角形不太平衡，并且不会增加面积。 始终添加完整内容的解决方案`k`向一边可能会得到错误的答案。 

另一个问题是，理想的边长可能在允许的范围内，但不在上限。 例如：```
1
3 4 1
```如果我们延长边长`1`，其他边是`3`和`4`。 当第三条边为最大时，面积最大`5`，而不是当它尽可能地延长时。 总是创建尽可能长的棍子的贪婪方法会错过实际的最佳值。 

第三种情况是理想长度小于当前边长。 例如：```
1
10 3 3 5
```边长`10`与另外两侧相比已经太长了。 既然我们无法缩短它，最好的选择就是保持它不变并考虑延长另一条边。 

## 方法

 一种简单的方法是尝试每根棍子的每种可能的延伸，计算所得的三角形面积，并保留最大值。 面积计算本身可以使用海伦公式来完成。 这是有效的，因为每个有效的最终三角形都会被检查，所以必须找到答案。 

问题是扩展可以是任何实数，而不仅仅是整数。 即使我们将自己限制为整数长度，尝试所有可能性也需要检查`10^4`每个测试用例中三根棍子中每根棍子的值。 这给了周围`3 * 10^4`每个案例的面积计算，并且搜索仍然不会涵盖分数答案。 真正的问题是答案是由几何决定的，而不是由枚举决定的。 

对于两条边的固定选择，第三条边具有使三角形面积最大化的唯一长度。 假设固定边是`b`和`c`，我们可以延伸的边是`a`。 使用海伦公式，面积的平方取决于`a²`作为二次表达式。 它的最大值恰好出现在有效区间的中点`a²`，这给出：```
a² = b² + c²
```这意味着延长边的最佳可能长度是由其他两条边形成的直角三角形的斜边。 因为我们只能增加边并且最多只能增加`k`，只需将目标长度调整到允许的范围即可。 我们对延长棒的三种可能选择中的每一种重复此计算，并取最大面积。 

蛮力之所以有效，是因为它会搜索可能三角形的整个空间。 观察到每一侧都有一个几何最佳值，我们可以用三个恒定时间计算来代替无界搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 如果仅限于整数扩展，则为 O(3k) | O(1) | O(1) | 对于实值扩展来说太慢且不完整 |
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取三个棍长和允许的最大延伸长度。 
2. 尝试将三根棍子中的每一根作为将要伸出的一根。 对于选定的一方`x`，设另外两侧为`y`和`z`。 理想长度为`x`是：```
sqrt(y*y + z*z)
```如果其他两侧保持固定，则这是面积达到最大值的点。 
3. 将理想长度限制为实际可能的长度。 所选边不能短于其原始长度，也不能超过其原始长度加上`k`。 

最终长度变为：```
min(max(ideal, x), x + k)
```下界处理边已经长于几何最佳值的情况。 上限处理最优需要太多扩展的情况。 
4. 使用 Heron 公式计算所得三边长的面积。 
5. 保留三个选项中找到的最大区域并打印。 

为什么有效：对于任何固定的边对，面积仅取决于剩余的边。 当剩余边的平方等于其他两条边的平方和时，该函数出现最大值。 该算法精确检查每个可能的延伸棒的最佳点，然后仅在允许的操作范围无法达到该点时进行调整。 由于每种可能的操作都会选择这三根棍子中的一根，因此必须考虑最佳可能的三角形。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def triangle_area(a, b, c):
    s = (a + b + c) / 2
    value = s * (s - a) * (s - b) * (s - c)
    return math.sqrt(max(0.0, value))

def solve_case(a, b, c, k):
    sides = [a, b, c]
    ans = 0.0

    for i in range(3):
        x = sides[i]
        y = sides[(i + 1) % 3]
        z = sides[(i + 2) % 3]

        best = math.sqrt(y * y + z * z)
        new_x = min(max(best, x), x + k)

        current = sides[:]
        current[i] = new_x
        ans = max(ans, triangle_area(current[0], current[1], current[2]))

    return ans

def main():
    t = int(input())
    out = []

    for _ in range(t):
        a, b, c, k = map(int, input().split())
        out.append("{:.9f}".format(solve_case(a, b, c, k)))

    print("\n".join(out))

if __name__ == "__main__":
    main()
```这`triangle_area`函数使用Heron 公式。 这`max(0.0, value)`当三角形接近退化时，guard 可以防止由浮点精度引起的微小负值。 

主循环测试每根棍子是否可伸展。 表达式`sqrt(y*y + z*z)`直接来自几何最优值。 钳位操作是关键的实现细节，因为最佳数学长度可能在区间之外`[x, x + k]`。 

复制的边列表可防止在测试一种可能性时意外修改原始长度。 由于所有计算都使用浮点值，因此 Python 中不存在整数溢出问题，但将计算保留在`float`形式是必要的，因为最终答案可能包含小数。

import io
import math

def triangle_area(a, b, c):
    s = (a + b + c) / 2
    return math.sqrt(max(0.0, s * (s - a) * (s - b) * (s - c)))

 ## 边缘情况

 对于原始三角形已经是最优的情况：```
1
3 4 5 10
```该算法检查延伸每一边。 当边`5`考虑到，距其他两侧的理想长度恰好是`5`，因此夹具保持其不变。 计算出的面积仍为`6`。 

对于最佳长度不是最大可能长度的情况：```
1
3 4 1 10
```延长边长时`1`，理想的长度是：```
sqrt(3² + 4²) = 5
```算法选择`5`， 不是`11`。 这会产生尽可能大的面积。 

对于理想长度小于当前边的情况：```
1
10 3 3 5
```边长`10`理想目标约为`4.24`，但不允许减少。 夹子将其保持在`10`。 另外两个选择仍然被检查，所以答案来自于最好的合法修改。 

这些情况正是仅基于“添加最大数量”的方法失败的地方。 该解决方案之所以成功，是因为它搜索几何最佳值，而不是猜测应该使用多少扩展。
