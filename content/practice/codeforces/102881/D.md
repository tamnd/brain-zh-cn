 ## 解决方案
 ## 问题理解

 我们有一个由无向图表示的国家。 一个人在第 0 天从一个未知的城市开始，每天可以留在同一个城市或通过一条道路。 唯一可用的信息是按时间顺序排列的炸弹爆炸列表。 每条爆炸记录都给出了一天和一个城市，这意味着炸弹是在不晚于爆炸日的某一天在该城市安放的。 炸弹保证按照放置的顺序爆炸，因此第一个日志条目对应于第一个放置的炸弹，第二个条目对应于第二个放置的炸弹，依此类推。 

任务是计算有多少个起始城市可以产生完整的爆炸日志。 

该图最多有2000个城市和10000条道路，而爆炸记录的数量可以达到1000000条。城市数足够小，可以计算每对城市之间的信息，但处理每条可能的路径是不可能的。 涉及所有起始城市、所有事件以及所有可能的移动序列的方法将远远超出限制。 数以百万计的事件迫使我们在进行一些预处理后使用 O(q) 或接近 O(q) 的扫描。 

主要的边缘情况来自这样一个事实：炸弹在放置后不需要立即爆炸。 例如，第 10 天在 3 号城市爆炸的炸弹可能是在第 2 天安放的，因此使用爆炸日作为确切的访问日会给出错误的结果。 另一个问题是，即使爆炸日间隔很大，种植顺序也很重要。 例如：```
3 2 2
1 2
2 3
1 3
2 1
```正确的输出是：```
1
```第二枚炸弹一定是在第一枚炸弹之后放置的。 一个粗心的解决方案，只检查起始城市是否可以独立到达每个爆炸城市，可能会计数更多的城市。 

另一个边缘情况是没有时间在连续放置的炸弹之间移动。 例如：```
2 1 2
1 2
1 1
1 2
```正确的输出是：```
0
```如果总部位于城市 1，则第一枚炸弹必须在城市 1 的第 0 天放置，但第二枚炸弹也必须在其之后放置。 没有任何一天可以从城市 1 搬到城市 2。 

## 方法

 直接的方法是尝试每一个可能的总部城市，并模拟是否可以满足爆炸序列。 即使使用预先计算的最短路径，这也需要针对每个起始城市反复检查每个事件。 最坏的情况约为 O(nq)，即对最大输入进行大约 2 * 10^9 检查并且无法通过。 

关键的观察是我们不需要追踪炸弹安放的确切日期。 我们只需要知道每枚炸弹可能被放置的时间有多晚。 假设最后一颗炸弹是在不晚于 d 的某一天在 c 市安放的。 它最晚可能的种植时间就是d。 沿着原木向后移动，前一个炸弹必须放置得足够早，以便该人有足够的时间从其城市步行到下一个炸弹的城市。 

如果第 i 个炸弹在城市 c_i 并且下一个炸弹可以在不晚于时间 L_(i+1) 放置，那么第 i 个炸弹可以不晚于以下时间放置：

 L_i = min(d_i, L_(i+1) - dist(c_i, c_(i+1)))

 计算出L_1后，第一弹只需要总部能够在L_1天内到达c_1即可。 每个有效的总部恰好是一个到 c_1 的最短路径距离至多为 L_1 的城市。 

图的大小使得从每个城市通过 BFS 的所有对最短路径都是可行的，因为图是未加权的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(nq) | O(n) | 太慢了|
 | 最佳| O(n(n+m)+q) | O(n²) | 已接受 |

 ## 算法演练

 1. 计算每对城市之间的最短距离。 由于道路成本相同，因此每个城市运行一次 BFS。 由此产生的距离矩阵让我们立即回答在任意两个炸弹位置之间移动需要多少时间。 
2.阅读爆炸日志并保持日期和城市的顺序。 事件按时间顺序给出，但我们需要从最后一颗炸弹向后进行计算。 
3. 从上一个事件开始。 它最晚可能的种植时间就是它的爆炸日，因为没有更晚的炸弹可以限制它。 
4. 从倒数第二个事件移至第一个事件。 对于每个炸弹，将其截止日期缩短到到达下一个炸弹所需的最短时间。 也尊重自己的爆炸日作为上限。 
5. 找到第一颗炸弹最晚可能的植入时间后，统计与第一颗炸弹城市距离不超过该值的所有城市。 

向后扫描背后的不变性是，处理完炸弹 i 后，存储的截止日期是炸弹 i 可以安放的最晚日期，同时仍允许其后的每个炸弹按顺序安放。 转换正好减去下一步所需的最小行程时间，因此每个可能的计划都必须满足计算的界限。 相反，只要边界保持非负值，在前一个炸弹之后根据需要立即放置每个后续炸弹就会构建一个有效的时间表。 

## Python 解决方案```python
import sys
from collections import deque
from array import array

input = sys.stdin.readline

def solve():
    n, m, q = map(int, input().split())

    graph = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        graph[u].append(v)
        graph[v].append(u)

    dist = []
    for s in range(n):
        cur = [-1] * n
        cur[s] = 0
        dq = deque([s])
        while dq:
            u = dq.popleft()
            for v in graph[u]:
                if cur[v] == -1:
                    cur[v] = cur[u] + 1
                    dq.append(v)
        dist.append(cur)

    days = array('i')
    cities = array('h')
    for _ in range(q):
        d, c = map(int, input().split())
        days.append(d)
        cities.append(c - 1)

    latest = days[-1]
    for i in range(q - 2, -1, -1):
        latest = min(latest - dist[cities[i]][cities[i + 1]], days[i])
        if latest < 0:
            print(0)
            return

    first = cities[0]
    ans = 0
    for x in range(n):
        if dist[x][first] <= latest:
            ans += 1
    print(ans)

solve()
```BFS 阶段构建向后动态计算使用的距离矩阵。 由于该图未加权，因此每个 BFS 给出了在城市之间移动所需的最少天数。 

存储事件的数组避免了 Python 列表存储一百万条记录的大量内存开销。 反向循环只需要当前截止时间和下一个城市关系，因此整个事件列表不重复。 

反向循环中的减法是重要的实现细节。 在应用当前爆炸日限制之前，我们减去连续炸弹位置之间的距离。 如果该值变为负数，则即使最早的种植顺序也无法满足日志。

 ## 边缘情况

 对于不可能的排序示例：```
2 1 2
1 2
1 1
1 2
```最后一颗炸弹的截止日期为 1。向后移动，第一颗炸弹需要在第 0 天之前放置，因为需要一天时间才能移动到第二个城市。 第一个炸弹在第 1 天爆炸，因此截止日期仍为 0。没有城市可以在零日内到达第一个炸弹城市，同时满足所需的排序，因此答案为 0。 

对于单个炸弹：```
4 2 1
1 2
3 4
5 1
```炸弹可以在第 0 天到第 5 天的任何时间放置在城市 1。总部可以是城市 1 或城市 2，但不能是城市 3 或 4，因为它们是断开连接的。 该算法仅检查到第一个炸弹城市的距离，这恰好给出了这两种可能性。
