 ## 解决方案
 ## 问题理解

 该问题描述了一排植物。 植物`i`从身高开始`h_i`并增长`g_i`每个时间单位之后的单位。 我们需要找到第一个整数时间`t`当植物从左到右按高度非递减顺序排列时。 如果订单永远无法排序，我们必须报告`-1`。 

输入给出了植物的数量、初始高度和生长速率。 当每个相邻对满足时，输出是最小的非负整数矩`height[i] <= height[i + 1]`。 

重要的观察是最终条件仅取决于相邻植物。 如果每株植物都不比下一株高，则对整个序列进行排序。 对于每个相邻对，我们只需要知道不等式何时成立。 

约束条件`n <= 100000`意味着检查多次可能的方法是不可能的。 答案可能非常大，因为身高和增长率可以达到`10^9`，因此按时间进行二分查找需要仔细处理，并且是不必要的。 我们需要一个解决方案来处理每个相邻对一次，给出`O(n)`算法。 

一个常见的错误是模拟逐步增长。 例如，如果一种植物比另一种植物生长得快得多，则穿越时间可能是数十亿或更多，这使得模拟毫无希望。 另一个错误是只检查最高和最低的植物。 排序是本地属性，因此每个相邻的对都很重要。 

考虑输入：```
3
5 4 3
1 2 3
```正确的输出是`1`。 时`0`高度是`5, 4, 3`，未排序。 过了一会儿他们就变成了`6, 6, 6`。 一个粗心的实现，只检查最大值是否最终不再是最大值，可能会忽略中间关系也是必需的这一事实。 

另一个边缘情况是两种植物具有相同的生长速率但生长顺序错误。```
2
10 5
3 3
```正确的输出是`-1`。 它们的差异永远不会改变，因此第一株植物将始终保持较高。 除以增长差异而不处理零的实现在这里将会失败。 

## 方法

 直接的方法是模拟时间。 每时每刻，我们都会更新所有植物的高度并检查序列是否已排序。 这是正确的，因为我们实际上是在遵循问题所描述的过程。 然而，第一个有效时间可能非常长。 如果答案就在身边`10^9`，模拟需要大约`10^14`操作，因为每个时间步都会检查所有`n`植物。 

有用的观察是每个相邻对都给出了时间的数学限制。 对于植物`i`和`i + 1`，我们需要：`h_i + g_i * t <= h_(i+1) + g_(i+1) * t`重新排列给出：`(g_i - g_(i+1)) * t <= h_(i+1) - h_i`这是一个关于`t`。 如果左边的植物生长得更快，不平等就会产生时间上限。 如果合适的植物生长得更快，就会产生一个下限。 如果两个增长率相等，则初始排序永远不会改变。 

收集所有下限和上限后，答案就是满足它们的最小非负整数。 蛮力之所以有效，是因为它直接搜索时间线，但不平等方法之所以有效，是因为每一对都同时描述了整个未来关系。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(答案 * n) | O(1) | O(1) | 太慢了 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 从可能的答案范围开始。 最小有效时间为`0`，因此将下界初始化为`0`。 上限是无限的。 
2. 对于每对相邻的植物，比较它们未来的高度。 维持的条件是：`h_i + g_i*t <= h_(i+1) + g_(i+1)*t`重新排列这个不等式可以告诉我们这对是否限制最早可能的时间或最晚可能的时间。 
3.如果`g_i - g_(i+1)`为正值时，左边的植物长得更快。 该对只能在某个最大时间之前保持排序，因此我们更新上限。 
4.如果`g_i - g_(i+1)`为负值时，右边的植物长得更快。 该对最终会变得正确，但只有在最短时间之后，所以我们更新下限。 
5. 如果`g_i - g_(i+1)`为零，两种植物总是变化相同的量。 它们的顺序永远不会改变，因此最初的比较决定了答案是否可能。 
6. 处理完所有对后，如果下限大于上限，则没有时间满足所有条件。 否则，下界是第一个有效的整数矩。 

为什么它有效：每个排序序列必须满足每个相邻的不等式。 该算法将每个不等式转换为对可能的时间值的限制。 所有限制的交集正是整个序列排序时的次数集合。 取该交点中的最小非负值即可给出所需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    h = list(map(int, input().split()))
    g = list(map(int, input().split()))

    low = 0
    high = 10**30

    for i in range(n - 1):
        dg = g[i] - g[i + 1]
        dh = h[i + 1] - h[i]

        if dg == 0:
            if dh < 0:
                print(-1)
                return
        elif dg > 0:
            high = min(high, dh // dg)
        else:
            need = (-dh + (-dg) - 1) // (-dg)
            low = max(low, need)

    if low <= high:
        print(low)
    else:
        print(-1)

if __name__ == "__main__":
    solve()
```该代码保留两个变量，表示所有有效时间的交集。`low`存储最早可能的答案，同时`high`存储最新的可能答案。 

对于正增长差异，整数除法是安全的，因为不等式需要`t <= dh / dg`。 如果`dh`为负数，结果上限变为负数，这会自动使最终范围无效，因为时间不能为负数。 

对于负增长差异，代码计算除法的上限。 这是必需的，因为时间必须是整数。 此处使用正常的整数除法会以错误的方向舍入负值，并且可能会产生太小一个单位的答案。 

数值可以达到`10^9`，而答案可能会超出32位整数限制，因此Python的任意精度整数自然避免了溢出问题。

 ## 边缘情况

 对于相同的增长率，该算法不会尝试除法。 例如：```
2
10 5
3 3
```生长差异为零，第一株植物开始较高。 由于两种植物的生长速度相同，因此差异`5`永远不会改变。 算法立即返回`-1`。 

对于单个植物：```
1
100
50
```不存在违反排序条件的相邻对。 初始下限保持不变`0`，所以答案是`0`。 

对于在分数时间内精确排序的情况，整数上限很重要：```
2
10 0
1 3
```不等式变为`10 + t <= 3t`， 所以`10 <= 2t`， 意义`t >= 5`。 该算法使用天花板除法并返回`5`，这是条件成立时的第一个整数矩。 

对于冲突的限制，算法会检测到空范围。 例如，一对可能需要`t >= 5`而另一个则需要`t <= 3`。 由于没有整数可以同时满足两者，因此最终检查`low <= high`失败，答案是`-1`。
