 ## 解决方案
 ## 问题理解

 我们给出了一组关于未知整数的约束$y$。 每个约束描述了与值的比较$x$，但含义取决于运算符。 一些限制说$y$必须严格大于或小于$x$，其他人允许平等。 每一行还告诉我们该陈述是真是假。 

而不是直接推理$y$，更容易根据值的范围进行思考$y$被允许采取。 每个语句要么限制$y$高于某个阈值或低于某个阈值。 “是”的答案会收紧不等式方向上的有效范围，而“否”的答案会翻转条件并收紧相反的方向。 

因此，任务简化为维护仍然可能的所有整数的间隔$y$。 最初，$y$可以是任何整数，但当我们处理每个约束时，我们会缩小这个间隔。 最后，如果区间非空，我们可以输出其中的任意整数。 否则，约束就会相互矛盾。 

输入大小足够小，处理每个约束一次就足够了。 即使在最大限制下，对约束的线性扫描也完全在时间限制内，因此任何比$O(n)$是不必要的。 关键的观察是，我们永远不需要显式存储候选者，只需要当前的可行区间。 

当约束不一致但最终仅揭示矛盾时，就会出现微妙的边缘情况。 当严格和非严格不等式紧密重叠时会发生另一个棘手的情况，例如组合$y > x$和$y \le x$，这使得不可能有整数。 此外，如果使用哨兵值，则必须仔细处理大边界以避免溢出问题。 

## 方法

 强力解释会尝试大范围内的每个可能的整数，例如$-2 \cdot 10^9$到$2 \cdot 10^9$，并检查它是否满足所有约束。 从概念上讲，这是可行的，因为我们可以直接测试每个查询的有效性，但最坏的情况需要迭代数十亿个值，并且每个检查都会扫描所有约束，从而导致操作数量不可行。 

关键的见解是每个约束仅修改边界。 像“$y > x$“ 或者 ”$y \le x$” 不依赖于任何具体值$y$，仅无论它位于阈值之上还是之下。 这意味着我们可以将所有约束压缩为两个数字：可能的最低上限和可能的最高下界。 一旦我们正确解释每个查询，每个步骤仅更新这两个值。 

我们不是模拟所有候选者，而是维持一个间隔$[L, R]$。 每个语句要么引发$L$或降低$R$，取决于条件是满足还是拒绝。 处理完所有约束后，可行性简化为检查是否$L \le R$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(K \cdot V)$在哪里$V \approx 4 \cdot 10^9$|$O(1)$| 太慢了 |
 | 间隔追踪|$O(K)$|$O(1)$| 已接受 |

 ## 算法演练

 我们解释每个约束并维护一个有效间隔$y$。 

1. 初始化$L = -2 \cdot 10^9$,$R = 2 \cdot 10^9$。 这与允许的输出范围相匹配，并确保我们永远不会过早地排除有效答案。 
2. 对于“运算符”形式的每个约束$x$，答案”，确定什么值$y$满足它。 
3. 将语句转换为区间限制：

 如果该陈述为真，我们直接应用约束。 

如果为假，我们应用相反的约束。 

For example, if the statement is “$y > x$”，答案是“是”，那么$L$变成$x+1$。 

如果答案是“否”，那么$y \le x$， 所以$R$变成$x$。 
4. 同样处理所有四个运算符：

 “>”和“>=”根据真值调整下限。 

“<”和“<=”根据真值调整上限。 
5.处理完每个约束后，更新$L$和$R$与新的限制相交。 
6. 处理完所有约束后，检查可行性：

 如果$L > R$，没有整数满足所有条件，因此输出“Impossible”。 

否则输出任意整数$[L, R]$， 例如$L$。 

关键思想是每个查询都会消除数轴的下段或上段，因此可行集始终保持单个区间。 

### 为什么它有效

 在每一步中，有效整数集恰好是前一个可行集与从当前语句导出的半行约束的交集。 由于两者都是区间，因此它们的交集也是区间。 这确保仅用两个边界表示状态不会丢失任何信息。 如果存在解，则它必须位于所有约束的最终交集处，如果交集为空，则没有整数可以同时满足所有陈述。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def apply(L, R, op, x, truth):
    if op == '>':
        if truth == 'Y':
            L = max(L, x + 1)
        else:
            R = min(R, x)
    elif op == '>=':
        if truth == 'Y':
            L = max(L, x)
        else:
            R = min(R, x - 1)
    elif op == '<':
        if truth == 'Y':
            R = min(R, x - 1)
        else:
            L = max(L, x)
    else:  # <=
        if truth == 'Y':
            R = min(R, x)
        else:
            L = max(L, x + 1)
    return L, R

def solve():
    n = int(input())
    L, R = -2_000_000_000, 2_000_000_000

    for _ in range(n):
        op, x, ans = input().split()
        x = int(x)
        L, R = apply(L, R, op, x, ans)

    if L > R:
        print("Impossible")
    else:
        print(L)

if __name__ == "__main__":
    solve()
```这`apply`函数隔离将每个语句转换为边界更新的逻辑。 这避免了混合解析和推理，这是实现中经常发生错误的地方。 

主循环只是一步一步地细化间隔。 最终决定仅取决于该间隔是否能够满足所有约束条件。

 ## 边缘情况

 当所有约束将间隔推至单个值时，就会出现仅边界情况。 例如，如果我们要求$y \ge 5$,$y \le 5$，区间变为$[5,5]$。 该算法正确输出 5，因为两个更新都收敛到同一边界。 

当一个约束消除了所有有效整数时，就会发生矛盾情况，例如$y > 10$其次是$y \le 10$。 第一步设定$L = 11$，第二组$R = 10$，生产$L > R$。 最终检查立即发现不可能。 

当语句为假并反转不等式方向时，就会发生符号翻转边缘情况。 例如， ”$y < x$”回答“不”变成$y \ge x$。 该实现通过显式地根据真值进行分支来处理此问题，确保正确保留严格性并且不会发生相差一错误。
