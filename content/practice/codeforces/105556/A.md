 ## 解决方案
 ## 问题理解

 我们在由两个端点定义的平面中给出了一条直线段。 从这个单独的线段，我们必须构造另一个线段，使得新的线段具有完全相同的长度，并且当两者延伸成无限线时，新的线段与原始线段垂直。 该任务不要求唯一的答案，只要满足这两个几何条件，任何有效的构造都会被接受。 

每个测试用例提供四个整数，表示原始线段端点的坐标。 输出必须是形成第二段的另一对端点。 没有限制新线段必须与原始线段相交或与其共享任何点。 

坐标范围很大，可达$10^8$输入的大小可达$10^9$用于输出。 这排除了任何依赖于密集搜索或平面离散化的几何构造。 测试用例的数量可以大到$10^4$，因此每种情况都必须在常数时间内仅通过少量算术运算来解决。 

尝试通过扫描网格中可能的端点来搜索有效垂直线段的简单方法会立即失败，因为即使是很小的搜索空间$10^5 \times 10^5$每个测试用例的候选人已经超出了许多数量级的时间限制。 

一个微妙的边缘情况是原始线段与轴对齐或具有非常大的斜率。 例如，如果该段是$(0,0)$到$(1,0)$，任何有效答案都必须是垂直的并且有长度$1$。 尝试使用浮点算术标准化方向向量的粗心实现可能会引入精度误差并产生稍微不正确的坐标，从而导致垂直或长度条件失败。 

另一种边缘情况是当线段很长或涉及负坐标时，例如$(-10^8, -10^8)$到$(10^8, 10^8)$。 该解决方案在计算方向向量时必须避免溢出，并且必须保持在整数范围内。 

## 方法

 蛮力的想法是考虑允许输出范围内的所有整数点对，并检查它们形成的线段是否与原始线段具有相同的长度并与其垂直。 这在概念上是有效的，因为欧几里得几何是明确定义的，穷举搜索最终会找到有效的解决方案。 

然而，候选片段的数量约为$O((10^9)^4)$如果天真地对待，因为每个端点都有两个坐标。 即使限制在一个合理的本地社区中，每个测试用例仍然留下太多的可能性。 蛮力方法失败了，因为它忽略了垂直向量的代数结构。 

关键的观察是片段可以表示为向量。 如果原线段有方向向量$(dx, dy)$，那么任何垂直线段都必须有一个与其正交的方向向量，这意味着它们的点积为零。 二维中的标准垂直向量是$(dy, -dx)$或者$(-dy, dx)$。 这些保证满足正交性条件。 

一旦我们固定了垂直方向向量，它的长度就会自动等于原始线段，因为交换坐标会保留平方范数：$dx^2 + dy^2 = dy^2 + dx^2$。 因此，我们不需要任何标准化或缩放。 

这将问题简化为简单地计算垂直向量并将其放置在平面上的任何位置。 最简单的选择是将其锚定在原点，产生端点$(0,0)$和$(dy, -dx)$。

 ## 算法演练

 1. 读取给定线段的端点，并计算其方向向量作为第二个点和第一个点之间的差。 这隔离了真正重要的几何信息，忽略了绝对位置。 
2.设向量为$(dx, dy)$。 例如，通过交换分量并对其中之一求反来构造垂直向量$(dy, -dx)$。 此步骤依赖于 2D 中的垂直度对应于 90 度旋转这一事实。 
3. 使用任意起点构造输出段。 最简单的选择就是从原点开始$(0,0)$并结束于$(dy, -dx)$。 
4. 输出这两点作为答案。 

选择原点的原因是平移不会影响长度或垂直度，因此固定一个端点可以消除不必要的自由度。 

### 为什么它有效

 转变$(dx, dy) \rightarrow (dy, -dx)$保留平方长度，因为两个向量都有范数$dx^2 + dy^2$。 它还保证了正交性，因为它们的点积是$dx \cdot dy + dy \cdot (-dx) = 0$。 由于输出段是直接从该向量定义的，因此无论它放置在平面中的哪个位置，都满足两个必需的条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    x1, y1, x2, y2 = map(int, input().split())
    
    dx = x2 - x1
    dy = y2 - y1
    
    # perpendicular vector
    px, py = dy, -dx
    
    # anchor at origin
    print(0, 0, px, py)
```关键的实现细节是使用整数算术计算差异向量，这完全避免了精度问题。 垂直向量是通过直接交换和变号得到的，在给定的约束下是恒定时间且安全的。 对于负坐标或退化斜率不需要特殊处理，因为构造是纯代数的。

 ## 边缘情况

 对于像这样的水平段$(0,0)$到$(5,0)$，算法计算$(dx, dy) = (5,0)$和输出$(0,-5)$。 所得线段与长度垂直$5$，与原始方向的点积为零，因此垂直度完全成立。 

对于像这样的垂直段$(2,3)$到$(2,10)$，向量是$(0,7)$输出变成$(7,0)$，产生等长的水平线段。 

对于具有负坐标的线段，例如$(-3,-4)$到$(1,2)$，向量变为$(4,6)$输出是$(6,-4)$。 平方长度匹配并且点积为零，即使两个端点均为负，也能确认正确性。
