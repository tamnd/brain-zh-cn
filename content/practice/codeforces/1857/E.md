 ## 解决方案
 ## 问题理解

 我们得到了几个测试用例。 在每个测试用例中，我们从数轴上放置的点列表开始。 对于每一点，我们选择一个特殊的位置`s`，然后我们连接`s`到每一点`x_i`由整数线上的一段。 因此，每个原始点都成为其坐标和坐标之间的一个区间`s`。 

对于任何固定的整数位置`p`在数轴上，我们将其“功率”定义为有多少个线段覆盖了该位置。 如果许多段重叠`p`，其功率高。 对于给定的选择`s`，我们不要求单个位置的功率，而是要求所有整数位置的总功率总和`1`到`10^9`。 这个总数相当于对所有段覆盖的整数点的数量进行求和。 

任务是：对于每个测试用例，我们必须计算每个可能选择的总数`s`， 在哪里`s`被限制为输入坐标之一。 

约束很严格：所有测试用例的总点数最多为`2·10^5`，并且最多可以有`10^4`测试用例。 任何为每个候选人独立重新计算答案的解决方案`s`在线性时间内会退化到大约`O(n^2)`总体来说，速度太慢了。 

一个天真的方法是，对于每个`s`，构建所有段并显式计算覆盖长度。 这已经花费了`O(n)`每`s`，并且由于有`n`选择，这变成`O(n^2)`每个测试用例。 和`n`最多`2·10^5`，这是远远超出可接受范围的。 

主要的微妙之处在于重叠的部分以结构化的方式做出附加贡献。 每个片段都贡献自己的长度，并且仅通过这些长度如何聚合来重叠，而不是通过显式的逐点模拟。 

打破天真的思维的边缘情况包括许多点共享同一坐标的情况，或者所有点都位于坐标的一侧的情况`s`，使所有线段指向同一方向。 另一个微妙的情况是当`s`是极端的（最小或最大），导致所有段对齐，最大化重叠结构。 

## 方法

 蛮力的想法很简单：对于每个候选人`s`，计算每个区间`[min(x_i, s), max(x_i, s)]`，然后对于范围内的每个整数点，计算覆盖范围。 这可以通过观察总功率总和等于间隔长度之和减去重叠来稍微优化，但即使计算总覆盖范围也明确需要扫描一个大的坐标范围，直到`10^9`，这是不可能的。 

关键的观察是我们永远不需要模拟各个点的覆盖范围。 所有位置的权力之和恰好是所有段的长度之和。 各段`[a, b]`贡献`b - a + 1`总计，无论是否重叠。 所以对于给定的答案`s`就是所有的总和`i`的`|x_i - s| + 1`。 

这将问题转化为评估，对于每个`s`，表达式：$$\sum |x_i - s| + n$$常数`n`与优化无关，因此核心任务是有效计算许多候选中心的绝对差之和。 这是一个经典的排序+前缀和问题：一旦数组排序完毕，我们就可以将贡献拆分为左侧的元素`s`以及右边的，并在 O(1) 中计算每个部分。 

蛮力之所以有效，是因为它直接评估距离，但它失败了，因为重复计算绝对差是二次的。 绝对值分成两个线性分量的观察结果允许前缀和在预处理后将每个查询压缩到恒定时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了 |
 | 排序 + 前缀和 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 我们继续利用排序后的绝对距离结构。 

1. 对坐标数组进行排序。 这确保了对于任何选择的`s`，其左侧和右侧的所有元素形成连续的组。 
2. 构建排序数组的前缀和，以便我们可以在恒定时间内计算任何前缀或后缀的和。 
3. 对于每个索引`i`， 对待`x[i]`作为中心`s`。 将数组拆分为左侧的元素`i`和权利`i`。 
4. 计算左侧的贡献为`s * i - sum(left)`。 这表示总距离`s`到所有较小的元素。 
5. 计算右侧的贡献为`sum(right) - s * (n - i - 1)`。 这表示到较大元素的总距离。 
6. 添加`n`来解释`+1`每段的长度。 
7. 输出每个位置的结果。 

每个步骤都通过利用前缀和将潜在的线性扫描减少为恒定时间算术。 

### 为什么它有效

 正确性来自于将绝对值分解为方向贡献。 一旦排序，每个元素要么贡献`s - x_i`或者`x_i - s`，取决于位置。 前缀总和保留两组的精确总和，因此每个查询都会准确地重建完整总和，而无需重新计算。 不需要跟踪重叠结构，因为段重叠已经被吸收到加性长度解释中。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        x = list(map(int, input().split()))
        
        x.sort()
        
        pref = [0] * (n + 1)
        for i in range(n):
            pref[i + 1] = pref[i] + x[i]
        
        total = pref[n]
        res = []
        
        for i in range(n):
            s = x[i]
            
            left_sum = s * i - pref[i]
            right_sum = (total - pref[i + 1]) - s * (n - i - 1)
            
            res.append(left_sum + right_sum + n)
        
        print(*res)

if __name__ == "__main__":
    solve()
```该代码首先对数组进行排序，以便可以通过前缀和来处理所有距离。 前缀数组存储累积和，允许直接计算每个候选两侧的和`s`。 对于每个位置，左贡献计算为之间的差距`s`和所有较小的元素，并且正确的贡献是对称的。 

决赛`+ n`考虑到每个段都贡献其端点包含（`+1`每个间隔的长度）。 这很容易被忘记，因为从几何覆盖到绝对差异的转换隐藏了它。 

一个微妙的点是索引：在计算权利贡献时，我们排除`x[i]`本身使用`pref[i + 1]`，确保我们不会重复计算中心。

 ## 边缘情况

 当所有点都相同时，无论什么，每个线段都是相同的`s`，并且该公式可分解为每个元素的恒定贡献。 该算法处理这个问题是因为前缀和使左右贡献都为零，只留下常数`+n`。 

当只有一个点时，没有左分区或右分区，因此两个贡献都为零，答案正是`1`，匹配单个单位长度段。 

当值极其分散时，前缀和公式仍然有效，因为它从不依赖于坐标密度，只依赖于聚合和，因此 Python 整数中不会出现溢出或精度问题。
