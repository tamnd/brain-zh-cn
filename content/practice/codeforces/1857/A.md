 ## 解决方案
 ## 问题理解

 给定一个整数数组，需要决定是否可以将其分为两个非空组，使得每个组的和具有相同的奇偶性——均为偶数或均为奇数。 每个组必须至少包含一个元素。 输入由多个测试用例组成，每个测试用例都有一个长度在 2 到 50 之间的数组，元素范围在 1 到 50 之间。 

每个测试用例的输出都是简单的“是”或“否”，指示这种着色是否可能。 因为数组长度很小（最大 50），所以我们不需要大量优化，但我们应该避免对所有分区进行强力枚举，这将是 n 的指数。 

当所有数字具有相同奇偶校验时，就会出现不明显的边缘情况。 例如，一个数组`[2,4]`只有偶数。 分成两组将始终产生均偶数的和，这满足奇偶校验条件。 相反，数组`[1,2]`有一个奇数和一个偶数，因此任何拆分都会产生不同奇偶校验的和，答案应该是“否”。 包含至少一个奇数和一个偶数元素的数组通常提供更大的灵活性。 

## 方法

 暴力解决方案将尝试将数组的每个可能的分区分成两个非空组并检查总和的奇偶校验。 对于n个元素，有$2^n - 2$可能的非空分割。 对于 n=50，这大约是$10^{15}$，远远超出了1秒内可行的范围。 

关键的见解来自观察奇偶校验行为。 模 2 的和仅取决于奇数的计数。 如果数组包含至少一个奇数元素和至少一个偶数元素，则始终可以将它们分开，使得两组的总和具有相同的奇偶校验。 如果所有元素都是偶数，则任何非空拆分都会产生偶数和，从而满足条件。 如果所有元素都是奇数，则总和为奇数，分成两个非空组会产生一个奇数和，一个奇数和减去一个奇数，结果为偶数，因此奇偶性不同，“NO”正确。 

因此，问题简化为计算奇数和偶数元素。 如果数组同时包含奇数和偶数元素或所有元素都是偶数，则答案为“是”。 如果所有元素都是奇数且 n > 1，则答案为“否”。

 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |

 ## 算法演练

 1. 对于每个测试用例，读取数组长度n和数组a。 
2. 初始化奇数和偶数元素的计数器。 
3. 迭代 a 的每个元素。 如果是奇数，则增加奇数计数器； 否则，增加偶数计数器。 
4. 检查条件：如果奇数和偶数都至少为 1，则输出“YES”。 
5. 如果所有元素都是偶数，则输出“YES”。 
6. 如果所有元素均为奇数且 n > 1，则输出“NO”。 

为什么有效：和的奇偶性仅取决于每个组中元素的奇偶性。 每个奇偶校验中至少有一个元素可以让我们根据需要平衡总和。 仅包含偶数的数组始终会产生相同奇偶校验的和，而仅包含奇数的数组在分成两个非空组时始终会产生不相等的奇偶校验和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    odd = sum(1 for x in a if x % 2)
    even = n - odd
    if odd and even:
        print("YES")
    elif even == n:
        print("YES")
    else:
        print("NO")
```该代码对奇数和偶数进行计数，并应用算法中概述的条件。 使用`sum(1 for x in a if x % 2)`避免手动迭代并保持代码简洁。 边界情况是自然处理的：具有所有偶数元素的数组返回“YES”，具有所有奇数元素的数组返回“NO”。

 ## 边缘情况

 对于`[1,3]`，两个数都是奇数。 计数得出奇数=2，偶数=0。 条件`odd and even`是假的，`even == n`为 false，因此它正确输出“NO”。 为了`[2,4]`，奇数=0，偶数=2。`even == n`为 true，因此输出为“YES”。 奇数和偶数混合的数组，例如`[1,2,3]`, 满足`odd and even`，所以输出为“YES”。 该算法自动处理所有边界情况，无需特殊情况分支。
