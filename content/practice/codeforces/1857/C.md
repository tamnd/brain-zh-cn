```这很好。 

现在看第二个测试用例：```

```代码期望`n = 2`元素，但下一行仅包含一个整数：```

```什么时候`i = 1`，它尝试访问：```

0 -2 0 3 5
```根本不匹配前缀最大算法的行为。
