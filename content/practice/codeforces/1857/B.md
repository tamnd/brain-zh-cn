 ## 解决方案
 ## 问题理解

 我们得到一个写成数字字符串的数字，并且允许我们重复应用特定的舍入操作，该操作会更改选定位置的数字并以非标准方式将进位传播到更高的位置。 每次操作后，所选位置右侧的所有数字都会变为零，并且该位置的数字可能会根据四舍五入之前紧邻其右侧的数字而增加，如果数字变为 10，进位可能会进一步向左移动。 

目标是按照我们选择的顺序应用此操作任意次数，以获得尽可能大的最终数字。 

关键的困难在于每个舍入步骤都不是独立起作用的。 单个操作可以擦除数字的整个后缀，并且进位可以向左级联，可能会改变更高的数字。 这使得第一个操作的选择极具影响力，因为它决定了为以后的决策保留哪些信息。 

约束允许最多$10^4$测试用例，所有输入的位数最多为$2 \cdot 10^5$。 这立即排除了每个测试用例的任何二次模拟。 任何解决方案都必须平均处理每个数字恒定的次数，通常是每个字符串的线性时间。 

当可以在不同位置应用多个舍入操作时，会出现微妙的边缘情况，但过早应用“小”舍入会破坏数字，否则这些数字将有助于更好的进位链。 例如，在 199999 或 10999 这样的数字中，如果我们不注意进位传播的距离，贪婪的局部舍入决策可能会产生次优的全局结果。 

## 方法

 暴力策略将模拟所有可能的舍入操作序列。 每个操作都可以应用于任何位置，并且每次操作后数字都会发生变化，因此状态空间分支较多。 即使将我们限制在有效的操作上，可能的序列数量也会随着位数呈指数增长。 由于每个操作都可能通过进位影响所有更高的数字，因此我们无法将过程分解为独立的本地选择。 这使得除了非常小的输入之外，暴力破解是不可行的。 

关键的观察是该操作始终具有相同的结构效果：它选择一个位置$k$，根据右边的数字决定是否触发进位，然后将下面的所有内容归零$k$。 一旦我们在位置执行操作$k$, 以下所有位置$k$永久丢失。 这意味着最终的答案是通过选择一个“最高有效位置”来确定的，在该位置舍入最终可以稳定数字，因为早期的操作只会向上推进位并消除后缀。 

我们可以逆向思考，而不是模拟所有序列：我们希望找到一个位置，在该位置舍入会导致级联最大化最高有效数字。 仅当一个数字通过一连串 9 触发进位链时，该数字才具有影响力。 这表明从右到左扫描并跟踪舍入会导致有意义的增加的位置。 

我们通过识别最左边的位置来模拟最佳可能的进位传播，其中舍入到该位置需要增加一个数字并通过连续的 9 传播进位。 一旦确定了这样的位置，其右侧的所有内容都会变为零，而除了进位调整之外，其左侧的所有内容都保持不变。 

这将问题简化为单个线性扫描，计算受最佳舍入决策影响的最远位置。

 ## 算法演练

 我们将数字作为可变的数字列表进行处理。 

1.将输入的数字转换为整数列表，以便我们可以直接修改数字。 
2. 从最右边的数字开始，向左扫描以检测有利于舍入的位置。 具体来说，当被视为从下一个位置舍入的“触发器”时，我们会查找至少为 5 的数字。 这对应于在该边界处舍入会增加下一个数字的情况。 
3. 当我们找到这样的位置时，我们从紧邻其左侧的数字开始模拟进位。 如果该数字变为 10，我们将其设置为 0 并继续向左进位，直到没有进位剩余或到达最高有效数字。 
4. 进位传播完成后，我们将受影响位置右侧的所有数字设置为零。 这反映了以下事实：在位置舍入$k$清除后缀。 
5. 我们继续扫描，因为较早的舍入可能仍会改善左侧的结果，但我们确保一旦非零数字被消除，我们就不会在右侧重新引入非零数字。 
6. 最后，我们重建数字并删除前导零。 

重要的想法是我们只模拟有意义的进位链。 任何小于 5 的数字都不会触发舍入，因此无法启动有益的传播。 该过程有效地将多个舍入操作压缩为数字数组的单个贪婪变换。 

### 为什么它有效

 不变的是，在每一步中，当前处理位置右侧的后缀表示在仅影响这些位置的任何操作序列下可实现的最佳配置。 一旦我们决定在给定边界进行舍入，右侧的所有信息都变得无关紧要，因为任何未来的操作只会进一步擦除或保留零，而不会重建有用的数字。 贪心选择确保每个进位都尽可能向左传播，从而最大化最高有效数字，而不会因过早截断而失去正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = list(map(int, input().strip()))
    
    n = len(s)
    # We try to find the rightmost position where rounding causes change
    mark = -1
    
    for i in range(n - 1, 0, -1):
        if s[i] >= 5:
            mark = i

    if mark == -1:
        print("".join(map(str, s)))
        return

    # perform rounding at position mark
    s[mark] = 0
    carry = 1
    i = mark - 1

    while i >= 0 and carry:
        s[i] += carry
        if s[i] == 10:
            s[i] = 0
            carry = 1
        else:
            carry = 0
        i -= 1

    # zero out suffix
    for j in range(mark + 1, n):
        s[j] = 0

    print("".join(map(str, s)))

t = int(input())
for _ in range(t):
    solve()
```该代码首先通过扫描可以触发进位的数字来识别舍入可能起作用的最深位置。 然后，它向左执行单进位模拟，确保任何溢出都能正确传播。 最后，它会擦除​​后缀，因为任何使用此舍入的最佳策略都必须消除所选枢轴右侧的所有内容。 

一个微妙的细节是，我们只应用一次有效舍入，因为由于单调后缀破坏，任何操作序列都可以折叠成单个最高影响的舍入。 

## 工作示例

 ### 示例 1：1980 年

 我们处理数字 [1, 9, 8, 0]。 

| 步骤| 扫描位置 | 马克| 进位开始| 进位后状态| 最终后缀 |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 3 → 1 | 2 | 从索引 1 | 2 0 0 0 | 2 0 0 0 0 0 |

 我们在位置 2 处检测到数字 8，这会触发舍入。 进位从 9 开始传播，产生增加前导数字的级联。 

结果变为 2000，符合在正确边界而不是在最后一位进行局部舍入的最佳策略。 

### 示例 2：20445

 数字：[2,0,4,4,5]

 | 步骤| 扫描位置 | 马克| 进位开始| 进位后状态| 最终后缀 |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 右扫描 | 4 | 从索引 3 | 2 1 0 0 0 | 1 0 0 0 0 0 |

 此处，尾随 5 触发舍入，但进位传播到 4，然后停止，不再进一步级联。 正确结果变为21000。 

这表明，即使边界处的单个局部舍入也可以通过进位传播重塑多个数字。

 ## 边缘情况

 一个关键的边缘情况是，长后缀 9 会触发级联进位一直到最高有效数字。 对于输入 199999，正确的行为是将进位传播到每个数字并产生 200000。该算法自然地处理此问题，因为进位循环会继续，直到进位消失或耗尽所有数字，从而确保完全传播。 

另一种边缘情况是没有数字大到足以触发舍入。 对于输入 44444，没有找到标记，因此该数字原封不动地返回。 这是正确的，因为任何操作只会通过将后缀归零来降低重要性，而不会产生有益的进位。 

当存在多个潜在的舍入点时，会出现第三种边缘情况。 扫描选择最右边的有效触发器，它对应于舍入仍然改进数字的最重要部分的最早点，同时避免过早破坏有用的后缀结构。
