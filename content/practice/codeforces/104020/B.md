 ## 解决方案
 ## 问题理解

 我们得到一条描述岛屿从西到东横截面的折线。 端点位于海平面，每个内部点都严格高于海平面。 在连续的点之间，地形是线性的，因此整个岛屿边界是 x 轴上方的一串直线段，从零高度开始和结束。 

从岛外的某个角度，我们拍摄日出（从西向东）或日落（从东向西）的照片。 在那张照片中，部分可见景观挡住了大海。 重要的是海平面的可见程度（以角度测量），而不是距离。 仅当相机的视线不被岛屿遮挡时，大海才被视为可见。 

任务是选择平面上的视点和方向（东或西），以使大海可见方向的总角跨度最大化。 输出是以度为单位的最大角度。 

输入大小高达 50,000 个点，因此任何尝试所有线段对或所有视点进行几何检查的解决方案都会太慢。 n 中的任何二次方都会立即被排除，因为在最坏的情况下它需要大约 25 亿次运算。 

一个关键的微妙之处在于，答案不是关于地形上的单个最佳点；而是关于地形上的单个最佳点。 相反，不同的视点可能会暴露地平线的不同可见间隔。 这通常会导致天真的方法错误地假设固定的相机位置，通常在一个端点或峰值，这不能保证是最佳的。 

第二个陷阱是将可见度视为简单的高度比较。 阻挡是有角度的：较远的较高峰值比较近的较低峰值可以阻挡更多的地平线，因此仅通过高度进行线性扫描会失败。 

## 方法

 强力解释是固定一个视点，然后通过检查多边形的每个部分来计算海平面的哪些部分是可见的。 对于固定视点，我们可以计算每个顶点或线段相对于相机的角度范围并保持可见性包络。 对所有候选视点执行此操作的成本已经很高，但更糟糕的是，“相关视点”集沿平面是连续的，而不是离散的。 离散化到所有顶点仍然需要 O(n²) 可见性计算。 

关键的观察结果是，对于可见性而言，重要的不是完整的几何形状，而是从视点到地形的斜坡的上包络线。 当沿单调方向（东或西）扫描视点时，仅当新线段成为角度顺序中的最大值时，阻挡光线集才会发生变化。 这在结构上与维护凸包或单调的斜坡堆叠相同。 

对于固定方向（例如日落），我们可以想象站在西边很远的地方，以便所有光线有效地按角度排序。 每个地形顶点都会从视点贡献一条光线，并且只有这些光线的上包络线很重要。 最大可见海对应于该包络线上连续“活动”阻挡方向之间的间隙。 

因此，问题简化为计算地形引起的凸链上间隙的角跨度，这可以使用类似于计算二维凸包的堆栈结构在线性时间内完成。 

我们按顺序考虑所有部分，并从视点保持“活动斜坡”的结构。 每当新段创建的坡度比之前的段更小时，它就会删除之前的贡献，因为它们已被完全阻塞。 这产生了一个单调结构，其角间隙与可见的海洋间隔完全对应。 最终的答案是连续幸存方向之间的角度之和。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 单调斜率包络 | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们聚焦日落方向； 日出是对称的，可以通过反转输入或交换方向来处理。 

1. 将连续点之间的每个线段转换为方向向量(dx,dy)。 每个向量对应于水平面上方的一个角度，但我们避免在这个阶段直接计算角度。 
2. 从左向右扫描并维护一堆表示从最左视点看到的上角度包络线的线段。 每个段由其斜率 dy/dx 表示，但我们使用交叉乘法来比较斜率以避免浮点错误。 
3. 对于每个新段，重复检查堆栈中的最后一个段。 如果新段产生的坡度小于或等于堆栈顶部的坡度，则顶部段将被完全阻挡并移除。 这是合理的，因为从同一侧观察时，除了较陡的部分之外，无法看到具有较小坡度的部分。 
4. 一旦堆栈按斜率递减顺序单调，则推送新段。 该堆栈现在表示定义可见海洋间隔的角度边界的可见山脊线。 
5. 使用atan2(dy, dx) 将堆栈中的每个线段转换为其角度。 连续的角度定义了封锁海域和可见海域之间的边界。 
6. 计算连续边界角度之间的差值。 该总和是海洋的总可见角度测量值。 
7. 从相反方向重复相同的过程（颠倒顺序）以计算日出能见度，并取两个结果的最大值。 

### 为什么它有效

 在水平方向足够远的任何视点处，地形段按角度的排序与按坡度的排序一致。 单调堆栈确保我们仅保留形成此角度排序的上包络线的段。 堆栈删除的任何线段永远不会成为该方向上任何有效视点的上包络线的一部分，因为后面的更陡峭的线段在每个相关的光线方向上都占主导地位。 因此，剩余的段精确地定义了可见光线和被阻挡光线之间的边界。 它们的角度之间的间隙精确地对应于没有地形遮挡大海的方向，因此将这些间隙相加就得到了总的可见角跨度。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def build_angles(points):
    # returns list of angles of upper envelope segments
    stack = []

    def slope(i):
        x1, y1 = points[i]
        x2, y2 = points[i+1]
        return (y2 - y1, x2 - x1)

    def cross(a, b, c, d):
        return a * d - b * c

    for i in range(len(points) - 1):
        dy1, dx1 = slope(i)
        while stack:
            dy0, dx0 = stack[-1]
            # if new slope >= old slope, keep monotone decreasing
            if dy0 * dx1 <= dy1 * dx0:
                stack.pop()
            else:
                break
        stack.append((dy1, dx1))

    angles = []
    for dy, dx in stack:
        angles.append(math.atan2(dy, dx))
    return angles

def solve(points):
    ang1 = build_angles(points)
    pts_rev = points[::-1]
    ang2 = build_angles(pts_rev)

    def span(angles):
        if not angles:
            return 0.0
        angles.sort()
        res = 0.0
        for i in range(1, len(angles)):
            res += angles[i] - angles[i-1]
        return res

    return max(span(ang1), span(ang2)) * 180.0 / math.pi

def main():
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n)]
    print(f"{solve(points):.10f}")

if __name__ == "__main__":
    main()
```该实现首先将地形压缩成方向段。 单调堆栈强制只保留对上角度包络有贡献的斜率。 每个幸存的线段都使用 atan2 转换为角度，这是安全的，因为由于从左到右的排序，dx 始终为正。 

反转处理对称情况，因为在镜像 x 轴排序后，一侧的日落视图相当于另一侧的日出视图。 

跨度计算对角度进行排序并对连续差值求和。 这是有效的，因为剩余的可见方向形成不相交的角度间隔，其总测量值恰好是按排序顺序的间隙之和。 

必须注意，斜率比较是通过交叉乘法完成的，以避免精度问题，因为直接浮动除法会在大坐标上引入浮动误差。

 ## 边缘情况

 当多个连续段具有相同的斜率时，会出现微妙的边缘情况。 在这种情况下，简单的堆栈逻辑可能会保留重复项并人为地分割应该是单个角度边界的内容。 该算法通过删除斜率比较中具有非严格不平等的线段来解决此问题，确保共线边缘折叠成单个代表方向。 这可以防止计算零宽度角间隙。 

当最高峰极其狭窄时，会出现另一种边缘情况。 在这种情况下，许多周围的线段被移除，只留下两条主光线。 该算法仍然表现正确，因为堆栈将结构精确地减少到这两个边界方向，并且角度跨度计算自然会产生单个连续的可见间隔。 

最后，当地形接近对称时，日出和日落计算会产生非常相似的围护结构。 取最大值可确保选择产生稍宽角度间隙的方向，即使因斜率离散化而产生差异。
