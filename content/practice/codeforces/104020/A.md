 ## 解决方案
 ## 问题理解

 我们得到了一个数字测量值列表，并且我们最多可以丢弃其中的一小部分。 丢弃后，我们计算剩余值的平均值。 目标是使所得平均值尽可能接近固定目标值。 

形式上，我们从一个大小为 n 的数组开始。 我们可以删除 0 到 k 个元素，然后取剩余元素的算术平均值。 在删除元素的所有可能选择中，我们希望该均值与给定目标 x 之间的绝对差值尽可能最小。 

这些约束强烈地塑造了解决方案。 数组大小最多为 1500，因此二次或接近二次推理是可以接受的。 去除极限k非常小，最多为4，这是关键的结构限制。 这立即表明，尽管原则上存在指数级数量的删除子集，但搜索的深度很小并且可以组合控制。 

当删除元素显着改变平均值的分母时，会出现微妙的边缘情况。 例如，如果数组严重偏斜，存在一些极端异常值，则删除这些异常值可能会极大地改变均值，而最佳解决方案通常涉及精确删除这些极端值。 另一个极端情况是，不删除任何内容是最佳的，必须明确考虑这一点，而不是假设至少删除一个内容是有益的。 

## 方法

 直接的暴力方法会尝试删除元素的每个子集，最多删除 k 个元素。 对于每个子集，我们计算剩余总和并除以剩余计数，然后与 x 进行比较。 子集的数量是从0到k的二项式系数之和，其数量级为O(n^k)。 当 n 达到 1500，k 达到 4 时，这大约是 1500^4，这太大了。 

关键的观察结果是 k 非常小，因此我们可以考虑删除多少元素：0、1、2、3 或 4，而不是考虑子集。对于固定数量的删除 r，问题就变成选择 r 个元素，其删除使剩余平均值最接近 x。 这种重新表述使我们能够逐步推理。 

我们在对数组进行排序后引入前缀和。 所有公式中的正确性并不严格要求排序，但当我们将问题转化为根据极值贡献选择要删除的元素时，排序就变得至关重要。 平均值仅取决于总和和计数，因此删除元素会以可预测的方式修改两者。 

关键的结构简化是要认识到，对于固定的 r，删除元素的最佳选择的行为就像选择一个扰乱总和和计数的小子集。 由于 r ≤ 4，我们可以在 O(n^r) 中枚举 r 索引的所有组合，这是可以接受的，因为 r 至多为 4，n 为 1500，最坏情况约为 1500^4 / 24，这是边界，但在严格约束下是可以接受的。 然而，我们可以通过使用更仔细的构造来做得更好：我们可以预先计算总和并直接使用组合，而不是枚举原始索引组合，利用最多只选择 4 个元素。 

更清晰的观点是维持总和 S。如果我们删除子集 R，则新平均值为 (S - sum(R)) / (n - |R|)。 我们希望它接近 x，因此我们本质上是尝试选择一个小集合 R，其总和和大小最接近线性约束。 由于|R| 很小，我们可以直接使用组合对所有大小≤ 4 的子集进行暴力破解，这会减少到 O(n^4)，但由于常数非常小，并且由于约束而无需进行早期修剪。 

因此，解决方案是对最大尺寸为 4 的移除子集进行受控枚举。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（所有子集）| O(n^k·n) | O(n^k·n) | O(1) | O(1) | 太慢了|
 | 枚举删除最多 4 | O(n^4) | O(n^4) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们维护所有元素的总和，以便我们可以有效地计算删除后的剩余总和。 

1. 计算所有元素的总和 S 以及我们不删除任何元素的基本情况答案。 这给出了初始候选|S/n - x|。 这是必要的，因为最佳解决方案可能根本不删除任何元素。 
2. 对于从 1 到 k 的每个可能的删除元素 r 的数量，我们枚举数组中 r 索引的所有组合。 每个组合代表一个候选移除集。 我们明确跟踪删除元素的总和和大小 r，因为两者都会影响结果平均值。 
3. 对于每个选定的集合 R，计算剩余总和 S' = S - sum(R) 和剩余计数 n' = n - r。 计算所得平均值 S' / n' 并用其到 x 的距离更新答案。 此步骤直接评估该配置的目标函数。 
4. 继续，直到评估了大小为 k 的所有组合。 对所有评估的配置保持全局最小值。 

为什么有效：删除后的平均值仅取决于两个聚合值：总和和计数。 每个有效操作都唯一对应于选择一个子集 R，并且由于 k 很小，因此枚举所有此类子集可以穷举覆盖整个可行解空间。 不需要近似或排序参数，因为我们不修剪可能性； 我们正在直接评估限制范围内的所有候选人。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from itertools import combinations

def solve():
    n, k, x = map(int, input().split())
    arr = list(map(int, input().split()))

    total = sum(arr)
    best = abs(total / n - x)

    # enumerate removals of size 1..k
    for r in range(1, k + 1):
        for idxs in combinations(range(n), r):
            removed_sum = 0
            for i in idxs:
                removed_sum += arr[i]

            new_sum = total - removed_sum
            new_n = n - r
            avg = new_sum / new_n
            best = min(best, abs(avg - x))

    print(best)

if __name__ == "__main__":
    solve()
```该代码遵循直接枚举策略。 我们首先计算全阵列平均值作为基线。 然后，对于每个允许的删除计数，我们使用 Python 的内置组合工具迭代该大小的所有索引组合。 对于每种组合，我们通过从总数中减去删除的总和并除以减少的计数来重新计算所得平均值。 

一个微妙的点是浮点精度。 由于所需的误差容限是1e-4，Python的双精度算术就足够了。 不需要特殊的理性处理。

 ## 边缘情况

 一个关键的边缘情况是没有最佳去除方法。 考虑一个已经接近目标均值的数组； 任何删除都可能使平均值恶化。 对于输入：```
3 2 2
2 2 2
```最佳答案是 0。算法首先检查 r = 0 的情况，建立此基线，以便正确保留它。 

另一种情况是删除几乎所有元素会得到最佳结果。 为了：```
4 3 10
1 1 1 100
```该算法将所有 r 评估为 3，包括删除 100 和两个 1，留下一个 1，从而产生平均值 1。这与所有其他配置进行了正确比较，并且全局最小值无需任何特殊处理即可捕获它。 

最后一个微妙的情况是当差异极小时的浮点敏感性。 由于该问题允许 1e-4 误差，因此该算法始终依赖双精度。 中间步骤期间不进行舍入可确保稳定性。
