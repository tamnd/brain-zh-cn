 ## 解决方案
 ## 问题理解

 我们得到了一系列音频幅度。 每个幅度都有助于“感知响度”的概念，该概念由其值的平方定义。 系统将平均感知响度测量为所有位置上这些平方值的平均值。 

我们可以对每个幅度应用单个正比例因子。 缩放后，序列必须准确地保持其形状，仅均匀拉伸或收缩。 目标是选择此比例因子，以便新的振幅平方平均值恰好变为给定的目标值 x。 存在一种特殊情况：如果所有输入幅度均为零，则无论 x 如何，输出都必须保持全零。 

输入大小最多可达 100000 个元素，幅度可达 10^6。 这立即排除了 n 中的任何二次方。 任何有效的解决方案都必须在线性时间内计算数组的全局属性，然后应用常数变换。 

一个微妙的边缘情况是总能量为零。 例如，如果输入是`0 0 0`，则平方和为零。 任何缩放因子仍然会产生零，因此如果处理不当，就会发生除以零的情况。 

另一种边缘情况是当 x 为零但输入不全为零时。 例如，`1 2 3`x = 0 需要缩小到零，这在严格的正缩放因子下是不可能的，除非我们将其解释为极限缩放。 然而，预期的解释仍然是代数的：缩放因子变为零，这会产生全零并与 x 完全匹配。 

## 方法

 一种直接的方法是尝试“搜索”比例因子 c。 如果我们选择一个候选 c，我们可以通过将每个幅度乘以 c 并重新计算平方均值来计算所得的平均平方值。 此检查的时间复杂度为 O(n)，因此对 c 进行二分搜索将给出 O(n log 精度)。 这会起作用，但没有必要。 

关键的观察结果是缩放与正方形的相互作用非常清晰。 如果每个值 ai 变为 c·ai，则每个平方项变为 c²·ai²。 这意味着平均感知响度恰好按 c² 缩放。 除了平方和之外，元素之间不存在相互作用。 

因此，整个问题简化为一个变量的单个方程。 令 S 为输入的平方和。 原始平均值为 S/n。 按 c 缩放后，新平均值变为 (c² · S) / n。 我们希望它等于 x，所以我们直接求解：

 c²·S / n = x

 这给出了

 c = sqrt(x·n / S)

 唯一剩下的问题是处理 S = 0。只有当所有幅度都为零时才会发生这种情况，并且该问题明确要求在这种情况下返回所有零。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 缩放因子的暴力搜索 | O(n 对数精度) | O(1) | O(1) | 已接受但没有必要 |
 | 直接公式| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们计算一次平方和，从封闭式方程中导出比例因子，并将其应用于每个元素。 

## 步骤

 1. 读取 n 和 x，然后读取幅度数组。 这是我们要统一转换的原始信号。 
2. 计算所有 i 的 S = sum(ai²)。 这捕获了有关响度的所有信息，因为目标仅取决于幅度的平方。 
3. 如果S为零，则每个幅度都为零，因此输出数组不变。 由于会发生除以零的情况，因此无法得出有意义的缩放因子。 
4. 否则计算比例因子 c = sqrt(x · n / S)。 这直接来自于匹配所需的均方值和结果均方值。 
5. 将每个幅度乘以 c，并以足够的精度输出结果。 

## 为什么它有效

 关键的属性是变换是乘法的并且跨坐标独立。 平方消除了符号相互作用，并将目标转化为 c² 下 S 的线性函数。 因为约束仅取决于平方均值，所以不需要保留比率； 只有全球能源才是重要的。 一旦 S 固定，就只有一个比例因子将其映射到 x，因此构造的解决方案必须符合所需的平均值。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

def solve():
    n, x = map(int, input().split())
    a = list(map(int, input().split()))
    
    s = 0
    for v in a:
        s += v * v
    
    if s == 0:
        print(*a)
        return
    
    c = math.sqrt(x * n / s)
    res = [v * c for v in a]
    print(*res)

if __name__ == "__main__":
    solve()
```该实现直接反映了导出的公式。 平方的累加使用整数运算来避免精度问题。 唯一的分支是零能量情况，它可以防止被零除。 缩放步骤是一个简单的线性传递。 

## 工作示例

 ### 示例 1

 输入：

 n = 5，x = 6

 a = [0, 1, -2, 3, -4]

 首先计算S：

 | 我| 艾| 人工智能² |
 | --- | --- | --- |
 | 1 | 0 | 0 |
 | 2 | 1 | 1 |
 | 3 | -2 | 4 |
 | 4 | 3 | 9 |
 | 5 | -4 | 16 | 16

 S = 30

 计算比例因子：

 c = sqrt(6 * 5 / 30) = sqrt(1) = 1

 缩放后的数组保持不变。 

这说明了原始能量已经与目标匹配的情况。

## 复杂度分析

 | 测量 | 复杂性 | 说明|

 该解决方案很容易满足约束条件，因为它只对数组执行两次线性传递，并且每个元素除了乘法之外没有大量计算。

 ## 边缘情况

 全零输入是结构上唯一的特殊情况。 对于像这样的输入`0 0 0`，S 为零，因此计算 c 将涉及除以零。 该算法显式检查这一点并返回不变的数组。 

对于像这样的输入`1 2 3`x = 0，S = 14，因此 c 变为零。 将每个元素乘以零会产生全零，这与所需的目标完全匹配。 

对于像这样的单元素数组`[5]`，S = 25 并且缩放行为正确，生成调整为直接匹配目标平均值的单个值，因为元素之间没有交互。 

这些情况证实该公式可以处理简并构型和一般构型，而无需在零能量检查之外进行额外的分支。
