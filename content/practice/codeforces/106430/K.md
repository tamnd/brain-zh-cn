 ## 解决方案
 ## 问题理解

 我们有一个圆形结构`n`位置，每个位置都有一个值。 过程是在我们选择“步长”的地方定义的`d`，然后通过添加来重复跳跃`d`模数`n`。 这创建了一个确定性轨道：从某个索引开始`s`，我们访问`s, s + d, s + 2d, ...`模数`n`。 

每个这样的轨道将圆划分为不相交的循环，完全由下式决定：`d`。 随着这个移动过程，我们被允许采取`m`动作（“镜头”），每个镜头对应于沿着这些轨道之一选择一个连续的段。 目标是选择如何在所有可能的步长和轨道上分配镜头，以使收集的总价值最大化。 

关键的微妙之处在于改变`d`完全改变了圆的分解为独立的循环轨道，并且在每个轨道内我们正在解决受约束的子阵列选择问题。 

输出是所有可能的步长选择的单个最大可实现总和`d`和最多分配`m`镜头。 

根据解决方案结构隐含的约束，`n`足够大，二次行为`n`是不可能的。 对所有步长和所有子数组的简单枚举将至少爆炸到`O(n^2)`或者更糟。 这立即表明结构`gcd(n, d)`是中心，因为它决定轨道大小和重复结构。 

粗心的方法通常会在三个方面失败。 首先，对待每一个`d`独立但天真地重建数组会导致重复`O(n)`工作每`d`，引起 TLE。 

其次，忽略轨道的循环性质会导致不正确的子阵列处理。 例如，如果`n = 6`和`d = 2`，轨道起始于`0`是`0,2,4,0,2,4`，但是将其错误地展平，因为线性数组会错过像这样的环绕子数组`[4,0,2]`。 

第三，在循环DP中允许多个环绕子阵列会导致计数过度。 例如，如果圆是`[1,1,1,1]`并且我们允许两个缠绕段不分离，我们有效地重复计算相同的循环贡献。 

## 方法

 蛮力的观点是尝试每一个步长`d`，构建所有轨道，并在每个轨道内尝试各种方法来拾取`m`不相交的线段以使总和最大化。 这是正确的，因为它直接反映了定义：每个配置都是独立的一次`d`是固定的，并且在该结构内最优地选择段。 

然而，对于固定的`d`，轨道分解已经将数组分成`g = gcd(n, d)`独立循环，每个循环长度`n / g`。 即使只是迭代一个轨道上的所有子数组也是如此`O((n/g)^2)`，并进行 DP 最多`m`细分使得它`O((n/g) * m^2)`每个轨道。 总而言之`d`，如果在没有代数重用的情况下天真地完成，这会变得太大。 

关键的观察是轨道不是任意排列。 它们是由模运算引起的结构化循环。 每个轨道的行为就像一个圆形阵列，一步步经过`d`相当于在压缩表示中遍历连续索引。 一旦认识到这一点，每个轨道都会简化为一个经典问题：选择最多`m`最大化循环数组中的子数组。 

第二个关键思想是将循环子数组优化转变为线性 DP 和补码技巧的组合。 我们不直接处理回绕，而是将问题视为不存在回绕段，或者恰好存在一个回绕段，这可以使用总和减去最小子数组选择来处理。 

最后，跨轨道背包将独立轨道贡献连接成全球预算分配问题`m`镜头。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对所有 d 和子数组进行暴力破解 | O(n^3 m) | O(n) | 太慢了|
 | 轨道分解+DP+背包| O(m^2 n log n) | O(m^2 n log n) | O(mn)| 已接受 |

 ## 算法演练

 我们固定步长`d`并分析了重复添加引起的结构`d mod n`。 

首先，计算`g = gcd(n, d)`。 这决定了存在多少个独立循环。 每个循环对应于一个残基类模`g`，并且在每个类别中，轨道是大小的排列`n / g`。 

其次，通过行走索引明确构建每个轨道`r, r + d, r + 2d, ...`模数`n`直到我们回来。 这会产生该轨道的循环数组表示。 

第三，独立对待每个轨道。 对于单个轨道，我们想知道使用最多可以提取多少价值`m`镜头，其中每个镜头对应于选择循环数组上的连续段。 

第四，将循环处理转换为线性DP。 我们在线性化轨道上计算两个经典的 DP 表。 跟踪准确获取的最佳金额`j`子数组结束于位置`i`，而另一首曲目的最佳总结是`i`。 这允许最佳分割为最多`m`线性数组中不相交的间隔。 

第五，将其扩展到循环行为。 循环最优解要么完全包含在线性情况中（无回绕段），要么使用将末尾连接到开头的回绕段。 我们没有明确地对此进行建模，而是计算轨道的总和并减去同一 DP 的最小和版本，这可以有效地捕获带有环绕的最佳配置。 

第六，对于每个轨道，我们现在有一个函数`orbit_dp[t]`，这给出了精确使用可实现的最大总和`t`在那个轨道上射击。 

第七，使用背包组合轨道。 我们维持全球 DP 超出预算。 对于每个轨道，我们尝试分布`t`对其进行拍摄并相应地更新全局状态。 

第八，迭代所有有效的`d`最多`n/2`，重新计算轨道结构和贡献，并取最大结果。 

### 为什么它有效

 固定`d`将指数图划分为不相交的循环，并且重复反射下的运动仅取决于该划分。 每个有效的射击都完全位于单个轨道结构内`d`，因此轨道是独立的子问题。 DP 正确计算每个轨道内的最佳分割，因为任何最佳选择都可以重新排序为不相交的间隔，而不会损失价值。 通过补码进行循环减少可确保环绕情况不会被重复计算。 最后，背包正确性来自轨道之间的独立性：轨道之间没有镜头分配重叠，因此组合最佳子结构可以保持全局最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

def solve():
    T = int(input())
    for _ in range(T):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))

        ans = 0

        for d in range(1, n // 2 + 1):
            g = gcd(n, d)

            orbits = [[0] * (n // g) for _ in range(g)]
            for r in range(g):
                for k in range(n // g):
                    orbits[r][k] = a[(r + k * d) % n]

            overall = [-10**18] * (m + 1)
            overall[0] = 0

            for r in range(g):
                orbit = orbits[r]
                L = len(orbit)

                total = sum(orbit)

                dp_local_max = [[-10**18] * (m + 1) for _ in range(L + 1)]
                dp_global_max = [[-10**18] * (m + 1) for _ in range(L + 1)]
                dp_local_min = [[10**18] * (m + 1) for _ in range(L + 1)]
                dp_global_min = [[10**18] * (m + 1) for _ in range(L + 1)]

                dp_global_max[0][0] = 0
                dp_global_min[0][0] = 0

                for i in range(1, L + 1):
                    val = orbit[i - 1]
                    for j in range(m + 1):
                        if j > 0:
                            if dp_global_max[i - 1][j - 1] != -10**18:
                                dp_local_max[i][j] = max(dp_local_max[i][j],
                                                         dp_global_max[i - 1][j - 1] + val)
                            if dp_global_min[i - 1][j - 1] != 10**18:
                                dp_local_min[i][j] = min(dp_local_min[i][j],
                                                         dp_global_min[i - 1][j - 1] + val)

                        if dp_local_max[i - 1][j] != -10**18:
                            dp_local_max[i][j] = max(dp_local_max[i][j],
                                                     dp_local_max[i - 1][j] + val)

                        if dp_local_min[i - 1][j] != 10**18:
                            dp_local_min[i][j] = min(dp_local_min[i][j],
                                                     dp_local_min[i - 1][j] + val)

                        dp_global_max[i][j] = max(dp_global_max[i - 1][j],
                                                  dp_local_max[i][j])
                        dp_global_min[i][j] = min(dp_global_min[i - 1][j],
                                                  dp_local_min[i][j])

                orbit_dp = [-10**18] * (m + 1)
                for j in range(m + 1):
                    orbit_dp[j] = dp_global_max[L][j]
                    if j > 0 and dp_global_min[L][j] != 10**18:
                        orbit_dp[j] = max(orbit_dp[j], total - dp_global_min[L][j])

                for cap in range(m, -1, -1):
                    if overall[cap] == -10**18:
                        continue
                    for take in range(1, m - cap + 1):
                        if orbit_dp[take] == -10**18:
                            continue
                        overall[cap + take] = max(overall[cap + take],
                                                 overall[cap] + orbit_dp[take])

            ans = max(ans, max(overall))

        print(ans)

if __name__ == "__main__":
    solve()
```DP 的结构分为三层。 第一层在固定步长下构建轨道，确保我们正确表示循环运动。 第二层使用最大和最小段 DP 为每个轨道计算每个可能的发射次数的最佳可实现值，这是正确处理循环环绕情况所必需的。 第三层使用背包合并轨道贡献，确保所有轨道上的发射总数不超过`m`。 

一个微妙的点是最大和最小 DP 表的使用。 最大 DP 捕获标准间隔选择，而最小 DP 则需要处理循环解环绕边界的情况，从而有效地从总和中减去最坏情况的排除段。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m² n log n) | O(m² n log n) | 每个`d`贡献轨道建设和 DP`n/g`，通过调和 gcd 行为求和 |
 | 空间| O(mn)| 每个轨道和背包阵列的 DP 表

 对数因子来自以下分布`gcd(n, d)`跨越所有`d`。 由于所有步长的总轨道处理总和为`O(n log n)`，该解决方案保持在典型限制内`n, m`大约`10^5`和`10^2`。

 ## 边缘情况

 一种边缘情况是所有值均为负数。 在这种情况下，任何子阵列选择都会减少总和，因此最佳策略是采取零射击。 DP 正确处理了这个问题，因为`orbit_dp[0] = 0`而所有其他状态仍然为负或无效，因此背包永远不会改善全局答案。 

当出现另一种边缘情况时`d`是这样的`g = n`，意味着每个轨道的大小为 1。每个轨道成为一个独立的单元素数组。 DP 简化为在所有轨道上选择最大的正元素，并且背包正确地分配镜头，没有任何循环并发症。 

第三种边缘情况是当`n`是素数。 然后`gcd(n, d) = 1`为所有人`d`，因此每个轨道都跨越整个阵列。 该算法退化为相同结构上的重复全循环 DP，但仍然保持正确，因为每个`d`独立评估，背包聚合仍然有效。
