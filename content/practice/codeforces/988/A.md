 ## 解决方案

 ## 问题理解

 我们得到了一份学生名单，每个学生都有一个评分值。 任务是准确地选择一个子集`k`学生，使得没有两个被选中的学生具有相同的评分。 输出不是评分本身，而是原始列表中所选学生的指数。 

因此，问题简化为扫描数组，同时选择之前未见过的值的位置，直到我们收集到`k`有效的索引，否则我们就会用完不同的值。 

限制非常小：`n ≤ 100`和`a_i ≤ 100`。 这立即排除了对高级数据结构或优化的任何需要。 即使是二次或简单的线性扫描也足够了。 一次通过一组就足够了。 

答案不存在的唯一情况是数组包含的内容少于`k`独特的价值观。 这样的话，无论我们怎么选学生，都达不到规模`k`同时保持评级不同。 

当重复项在数组中占主导地位时，会出现微妙的边缘情况。 例如，如果所有值都相同并且`k > 1`，我们必须立即拒绝。 另一种情况是存在重复项，但足够多的不同值分散在数组的后面； 贪婪扫描必须确保我们仍然选择所有不同的值，并且不会因为任何排序假设而过早陷入困境。 

## 方法

 强力解释是尝试所有大小子集`k`并检查所有选择的值是否不同。 这将涉及检查以下组合`n`选择`k`，并且对于每个子集验证唯一性，即使对于小数据也会导致爆炸`n`。 在最坏的情况下，子集的数量约为 2ⁿ，即使限制为固定大小 k 仍然会给出 O(nᵏ) 行为，这对于该问题来说是不必要的。 

问题的结构表明了一个更简单的观察：我们不需要全局搜索。 我们只需要任何`k`独特的价值观。 由于我们可以输出任何有效的子集，因此我们可以贪婪地从左到右扫描并选择每个新评级的第一次出现。 这是可行的，因为选择的顺序并不重要，并且只要其值之前未被使用过，每个索引都同样有效。 

暴力破解会失败，因为它会探索不相关的组合，而贪婪解决方案会起作用，因为唯一性是可以逐步强制执行的本地属性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2ⁿ·n) | O(2ⁿ·n) | O(k) | 太慢了 |
 | 使用 Set 进行贪婪扫描 | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们逐步构建答案，同时跟踪我们已经使用的评级。 

1.初始化一个空集`used`存储我们已经选择的评级和一个空列表`ans`存储选定的索引。 该集合对于在恒定时间内检查唯一性是必要的。 
2. 从索引中迭代学生`1`到`n`。 对于每个学生，我们检查他们的评分是否已经在`used`。 此检查确保我们只选择不同的值。 
3. 如果未使用评分，我们将该学生的索引添加到`ans`并将评级标记为已使用。 我们实际上致力于让该学生作为他们评分的代表。 
4. 如果出现以下情况，请尽早停止`ans`达到尺寸`k`。 那时我们已经有了一个有效的团队，继续下去不会改变正确性。 
5、循环结束后，检查是否`ans`有尺寸`k`。 如果不是，则意味着我们遇到的数量少于`k`整个阵列中的评级不同，因此不可能组建有效的团队。 

### 为什么它有效

 关键的不变量是`used`始终包含准确的评级集`ans`。 每次我们添加一名学生时，我们都会引入一个以前未见过的评级，以保证所有选定的指数都对应于不同的值。 由于我们处理每个元素，如果少于`k`存在不同的评级，算法将耗尽数组而不达到大小`k`，正确地发出不可能的信号。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = list(map(int, input().split()))

used = set()
ans = []

for i in range(n):
    if a[i] not in used:
        used.add(a[i])
        ans.append(i + 1)
        if len(ans) == k:
            break

if len(ans) < k:
    print("NO")
else:
    print("YES")
    print(*ans)
```该解决方案使用一组来跟踪所看到的评分，并使用一个列表来存储所选索引。 一旦我们收集了足够多的不同元素，循环就会提前停止，这避免了不必要的工作，但考虑到小的约束，这对于正确性来说并不是必需的。 

通过输出仔细处理索引`i + 1`因为该问题使用从 1 开始的索引。

 ## 边缘情况

 当所有学生都具有相同的评分时，算法在耗尽数组之前仅添加一个索引。 用于输入`n = 4, k = 2, a = [7,7,7,7]`,`used`变成`{7}`和`ans = [1]`。 循环结束后，大小检查失败，算法正确输出`"NO"`。 

当数组恰好包含`k`不同的价值观，例如`1 2 3`和`k = 3`，每次迭代都会添加一个新索引。 算法达到大小`k`正好在最后一步并提前停止，确认正确终止。 

当重复项与不同值混合时，例如`1 2 1 3 2 4`，该集合确保只有第一次出现才起作用。 即使重复出现较早，它们也不会干扰收集足够的不同值，并且最终结果仍然有效。
