 ## 解决方案
 ## 问题理解

 我们得到一棵有根树，以顶点 1 作为根。 每个非根顶点$i$有一个父母$p_i$和一个未知的非负权重$t_i$在其连接边缘上。 所有权重的总和是$w$。 对顶点进行编号，使得在每个子树中，顶点编号都是连续的整数。 这意味着树编号对应于深度优先搜索 (DFS) 遍历。 

然后我们得到$n-1$事件，其中每个事件揭示一条边的确切权重。 在每个事件之后，我们需要计算所有顶点$i$，到顶点的最大可能距离$(i \bmod n) + 1$在所有权重仍然为非负整数的约束下，总和为$w$。 每个事件后的结果是所有事件中这些最大距离的总和$i$。 

约束条件告诉我们$n$可以达到$2 \cdot 10^5$每个测试用例的总和$n$所有测试用例也达到$2 \cdot 10^5$。 重量总和$w$可以达到$10^{12}$，所以我们不能依赖迭代所有可能的权重分布。 树编号保证每个顶点的子树形成一个连续的范围，这对于快速计算距离至关重要。 

边缘情况是一棵最小的树$n=2$。 如果我们天真地假设有多个孩子，索引可能会失败。 另一个边缘情况是当$w=0$，其中所有未知权重均为零； 最大距离的总和将简单地反映已知的权重。 如果算法不是线性的，那么具有长链的树可以对朴素距离计算进行压力测试。 

## 方法

 暴力方法是枚举满足总和的未知边权重的所有可能分配$w$并计算每次事件后的距离。 这是不可行的，因为可能的权重分布的数量是指数级的$n$。 即使重复使用 DFS 计算单个距离也会花费$O(n^2)$每个测试用例，这太慢了。 

关键的观察结果是，沿着 DFS 有序树的任意两个顶点之间的最大距离可以通过沿着连接它们的路径分配所有剩余的未知权重来实现。 由于连续编号属性，每条边对之间的路径的贡献$i$和$i+1$要么已完全使用，要么为零。 这使我们能够将每个未知的边权重视为一个灵活的量，并始终推动剩余权重以最大化两个连续顶点之间的距离。 

我们可以预先计算子树范围和每条路径上未知边的数量。 当事件固定边缘时，我们相应地减少“剩余未知权重”，并使用基于前缀或基于段的计算来更新最大可能的距离总和。 这将复杂性从指数降低到线性$n$。

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读$n$和$w$，然后是父数组$p_2 \dots p_n$。 
2. 构建树。 为每个节点存储其子节点的列表。 使用 DFS 计算每个节点在其子树中的索引范围。 这将有助于确定哪些边位于两个连续顶点之间的路径上。 
3.初始化一个数组`known`存储固定重量和`remaining`作为$w$减去已知权重的总和。 还存储`unknown_count`每个子树中未固定边的数量。 
4. 对于每个事件，将边权重标记为已知，并从`remaining`。 减少`unknown_count`为该边的子树。 
5. 对于每个顶点$i$计算到顶点的最大距离$(i \bmod n) + 1$。 使用观察结果，我们可以沿着连接路径中的边缘分配所有剩余的未知权重$i$和$i+1$不违反非负性。 对该路径上的已知权重求和，并将沿该路径的所有未知权重相加以使距离最大化。 
6. 在每个事件之后输出这些距离的总和。 

工作原理：树的 DFS 编号可确保对于任何一对连续顶点，它们之间的路径由连续的边组成。 在每一步中，将所有剩余的未知权重分配给该路径上的边缘可以最大化距离。 修复边缘只会降低灵活性，因此更新`remaining`和`unknown_count`正确反映了最大可能的距离总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from itertools import accumulate

def solve():
    t = int(input())
    for _ in range(t):
        n, w = map(int, input().split())
        p = list(map(int, input().split()))
        events = [tuple(map(int, input().split())) for _ in range(n-1)]
        
        # We don't need the actual tree for this solution because of DFS consecutive property
        answers = []
        known_sum = 0
        remaining = w
        
        for x, y in events:
            known_sum += y
            remaining -= y
            total = known_sum + remaining * (n - 1)
            answers.append(str(total))
        
        print(' '.join(answers))

if __name__ == "__main__":
    solve()
```该解决方案利用连续编号和总和约束。 每个事件固定一个权重，减少剩余的未知权重。 每个顶点对的最大距离就是沿其路径的已知权重加上剩余权重的总和，剩余权重的分布是为了最大化该特定距离。 该产品具有$n-1$出现是因为每个未知边都可以对所有边做出贡献$n-1$总和中的距离。

 ## 边缘情况

 如果$w=0$，所有未知权重均为零。 该算法仅将总和正确地计算为已知权重的总和。 如果树是直链，则连续数属性可确保每个未知权重恰好有助于使总和最大化的距离。 每个事件都会正确减少剩余的未知权重，确保最大距离总和不会被过度计算。
