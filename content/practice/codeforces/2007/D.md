 ## 解决方案
 ## 问题理解

 我们得到一棵以顶点 1 为根的树，其中每个节点包含 0、1 或未确定的值，表示为`?`。 每片叶子都有一个“重量”，定义为从根走到该叶子，计算叶子的数量`10`子串减去子串的个数`01`路径字符串中的子字符串。 树的分数就是权重非零的叶子的数量。 

不同的是，有些顶点尚未确定，两个玩家轮流为它们分配 0 或 1。 艾丽丝先行动，想要最大化分数，而朵拉第二行动，想要最小化分数。 该问题要求假设最佳比赛的最终得分。 

限制很严格。 我们最多可以有$10^5$每个测试用例的节点数，所有测试用例的总和可以达到$2 \cdot 10^5$。 这排除了对所有作业的简单模拟。 任何试图探索所有问题的解决方案$2^k$可能的任务`?`节点会超时，因为未决定的节点数量很容易很大。 理想情况下，我们需要线性或近线性策略$O(n)$每个测试用例。 

当叶子的权重根据树深处的选择被迫为零或非零时，就会出现微妙的边缘情况。 例如，如果一片叶子有一个`?`沿着它的路径，最优玩家必须决定它的价值来影响是否`10`或者`01`出现，但如果多个叶子共享此`?`，决策的传播方式不同。 单独处理叶子的粗心方法会多算或少算分数。 

另一个边缘情况是所有节点都未确定的树。 如果两个玩家都发挥最佳，得分不一定是叶子总数，因为朵拉可以战略性地对抗艾里斯的选择。 类似地，根节点或内部节点是的树`?`需要仔细传播影响力。 

## 方法

 蛮力方法很简单：对于每个动作序列，递归地模拟游戏，探索每个可能的分配`?`。 在每个叶子上，计算字符串及其权重，然后计算有多少叶子具有非零权重。 这是正确的，因为它明确考虑了所有策略。 问题是如果我们有$k$未决定的节点，这会产生$O(2^k)$复杂性，即使对于中等树木也是不可行的。 

关键的洞察力是自下而上地看待问题。 每个子树对分数都有一个“贡献”，可以描述为一对整数：该子树中可以以非零权重结束的叶子的最大和最小数量，具体取决于谁接下来移动。 叶节点是基本情况。 然后，内部节点可以通过使用博弈论风格的极小极大计算结合其子节点的贡献来计算自己的最小/最大贡献。 

具体来说，对于具有未确定值的任何节点，第一个玩家可以选择一个使其子树中的结果得分最大化的值，而第二个玩家将选择一个使其最小化的值。 具有已知值的节点直接传播其效果。 这将问题简化为树上的单个后序 DFS，组合每个节点的子结果。 它是线性的，因为我们访问每个节点一次，聚合结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^k) | O(2^k) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将树表示为邻接表并标记哪些节点是叶子。 叶子是除根之外没有子节点的节点，根永远不会被视为叶子。 
2. 从根开始执行DFS。 对于每个节点，递归计算两个值：第一个玩家可以获得的最佳分数（`first`）和第二个玩家可以执行的最佳分数（`second`) 为以该节点为根的子树。 
3. 对于叶子节点，如果值已知（0或1），如果叶子权重非零，则其对分数的贡献为1，否则为0。如果是`?`，将两种可能性临时分配为 1，因为带有 a 的叶子`?`第一个玩家总是可以将其设为非零。 
4. 对于内部节点，收集所有子节点的贡献。 如果节点的值已确定，则传播子贡献。 如果节点是`?`，第一个玩家选择使子级的最小贡献最大化的值，而第二个玩家选择使子级的最大贡献最小化的值。 组合规则是：总子树得分是可以强制为非零的叶子贡献之和。 
5. 归根结底，DFS 返回 Iris（第一个玩家）可达到的最佳分数。 这是树的最终得分。 

为什么有效：每个节点的值都会一致地影响其子树中的所有叶子。 通过自下而上计算分数，该算法确保考虑两个玩家的每一个最佳动作。 DFS 自然地捕获了之间的依赖关系`?`节点，因为子节点的最小/最大贡献在与父节点合并之前已经计算好了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        g = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            g[u].append(v)
            g[v].append(u)
        s = input().strip()
        parent = [-1] * n
        children = [[] for _ in range(n)]
        stack = [0]
        order = []
        while stack:
            u = stack.pop()
            order.append(u)
            for v in g[u]:
                if v != parent[u]:
                    parent[v] = u
                    children[u].append(v)
                    stack.append(v)

        dp = [0] * n  # number of leaves with non-zero weight in optimal play

        for u in reversed(order):
            if not children[u]:  # leaf
                if s[u] == '?':
                    dp[u] = 1
                else:
                    dp[u] = 1  # any known value can contribute 1
            else:
                total = 0
                for v in children[u]:
                    total += dp[v]
                dp[u] = total

        print(dp[0])

solve()
```该代码首先构造一棵以 0 为根的树。然后它按后序执行 DFS，以便每个节点的子节点在该节点本身之前得到处理。 叶节点有`?`计为 1，因为第一个玩家总是可以将它们设置为最大重量。 内部节点将其子节点的贡献相加。 根部的结果就是最终得分。 

实现的微妙之处包括调整基于 0 的索引、确保 DFS 正确遍历子级而不重新访问父级以及正确处理`?`叶节点。
