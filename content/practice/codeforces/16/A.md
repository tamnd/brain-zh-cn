 ## 解决方案
 ## 问题理解

 我们有一个代表国家国旗的矩形网格。 网格中的每个单元格都有一种颜色，编码为 0 到 9 的数字。标志的尺寸为$n$行按$m$列。 目标是根据新的 ISO 标准确定旗帜是否为“条纹”。 如果每行都包含相同颜色的单元格，并且连续的行不共享相同的颜色，则标志会出现条纹。 

输入很小，有$n, m \leq 100$。 这意味着即使是$O(n \cdot m)$解决方案是可以接受的，因为单元总数最多为 10,000 个，这对于现代 CPU 来说是微不足道的。 

一些不明显的边缘情况包括具有单行的标志，其中没有可以比较的前一行，以及具有单列的标志，其中每行仍然需要统一。 例如，带有一行三个单元格的标志`111`应该返回`YES`因为该行中的所有单元格都是相同的，即使上面或下面没有行来比较颜色。 另一个棘手的情况是当两个相邻行意外地共享相同的颜色时，例如`111`其次是`111`。 这应该返回`NO`因为条纹不明显。 

## 方法

 强力方法会迭代每个单元格，检查两个条件：每一行是统一的，并且每个连续行都与前一行不同。 这是正确的，因为问题明确定义了有效标志的属性。 复杂度是$O(n \cdot m)$，对于这个问题的规模来说这是可以接受的。 

关键的见解是我们可以简化检查：我们只需将每个单元格与该行的第一个单元格进行比较，而不是反复验证每个单元格与行中的每个其他单元格。 如果任何单元格不同，则该行无效。 为了检查连续行，我们只需将当前行的第一个单元格与前一行的第一个单元格进行比较。 这减少了不必要的比较，但不会改变渐近复杂度。 

暴力破解之所以有效，是因为它明确地检查了每个需求，但对行优先单元格比较的观察降低了认知和实现的复杂性，使代码更干净且不易出错。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·m) | O(1) | O(1) | 已接受 |
 | 优化行优先检查 | O(n·m) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读尺寸$n$和$m$来自输入并将标志存储为字符串列表，其中每个字符串代表一行。 这保留了行结构以便于检查。 
2. 从第一行开始迭代每一行。 对于每一行，检查所有单元格是否相同。 将行中的每个字符与第一个字符进行比较。 如果有任何字符不同，则输出`NO`并停止。 
3. 如果当前行不是第一行，则将其第一个字符与上一行的第一个字符进行比较。 如果相同则输出`NO`并停止。 
4. 如果所有行都通过了两项检查，则输出`YES`。 

**为什么有效：** 该算法通过将所有单元格与行的第一个单元格进行比较来确保每行都是统一的。 通过检查连续行的第一个单元格，可以确保相邻行不同。 这两个检查满足条纹标志的定义。 无需其他检查，因为颜色数字保证为 0-9。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
flag = [input().strip() for _ in range(n)]

for i in range(n):
    row = flag[i]
    if any(c != row[0] for c in row):
        print("NO")
        sys.exit(0)
    if i > 0 and row[0] == flag[i - 1][0]:
        print("NO")
        sys.exit(0)

print("YES")
```该代码首先将标志读入字符串列表。 这`any(c != row[0] for c in row)`构造有效地检查行均匀性。 第二个条件确保条纹不同。 使用`sys.exit(0)`当发现违规时立即终止程序，这避免了对剩余行的不必要的迭代。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()
    n, m = map(int, input().split())
    flag = [input().strip() for _ in range(n)]
    for i in range(n):
        row = flag[i]
        if any(c != row[0] for c in row):
            print("NO")
            return sys.stdout.getvalue().strip()
        if i > 0 and row[0] == flag[i - 1][0]:
            print("NO")
            return sys.stdout.getvalue().strip()
    print("YES")
    return sys.stdout.getvalue().strip()

# Provided sample
assert run("3 3\n000\n111\n222\n") == "YES", "sample 1"

# Custom cases
assert run("1 5\n33333\n") == "YES", "single row"
assert run("5 1\n1\n2\n3\n4\n5\n") == "YES", "single column, distinct"
assert run("2 4\n7777\n7777\n") == "NO", "repeated color"
assert run("3 3\n123\n456\n789\n") == "NO", "row not uniform"
assert run("3 2\n11\n22\n22\n") == "NO", "last two rows same"

 ## 边缘情况

 具有一行的标志，例如：```
1 4
4444
```算法检查行均匀性：`all(c == row[0] for c in row)`通过。 由于没有前一行，因此跳过相邻行检查。 输出是`YES`。 

具有一列的标志：```
3 1
1
2
2
```行均匀性很容易通过，因为每一行都有一个单元格。 最后两行的相邻行检查失败，因为`2 == 2`。 输出是`NO`。 

这些示例证实该算法可以正确处理最小尺寸和边缘比较。
