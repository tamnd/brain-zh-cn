 ## 解决方案
 ## 问题理解

 我们从一个显示器开始，其尺寸为`a × b`。 两个值都是整数。 我们想要缩小这个显示器，以便新的尺寸保持精确的宽高比`x : y`。 

新显示器必须同时满足三个条件。 

首先，两个维度都必须保持整数。 

二、新的宽度不能超过`a`，并且新的高度不能超过`b`，因为我们只允许缩小显示器尺寸。 

三、在所有有效的缩减监视器中与比率`x : y`，我们想要面积尽可能最大的一个。 

纵横比条件意味着最终尺寸必须如下所示：$$(k \cdot x,\ k \cdot y)$$对于某个正整数`k`。 

约束条件达到`2 · 10^9`，它立即排除了任何一一迭代所有可能的宽度、高度或缩放因子的方法。 在竞争性编程限制内，循环运行数十亿次是不可能的。 我们需要一个恒定时间或对数时间的解决方案。 

棘手的部分是该比率可能尚未降低。 例如，如果`x = 6`和`y = 4`，那么该比率实际上等于`3 : 2`。 如果我们忘记首先简化，我们可能会错误地得出一些有效答案是不可能的结论。 

考虑这个例子：```
a = 10
b = 10
x = 6
y = 4
```如果我们使用`(6k, 4k)`直接取最大有效值`k`是`1`, 给予`(6, 4)`与面积`24`。 

但降低比例后`3 : 2`，我们可以使用`k = 3`, 给予`(9, 6)`与面积`54`，它要大得多。 

当一个维度成为限制因素时，就会出现另一种边缘情况。```
a = 8
b = 5
x = 4
y = 3
```粗心的实现可能会首先最大化宽度并尝试`(8, 6)`，超出了高度限制。 

正确的方法是认识到两个尺寸必须同时适合。 最大有效缩放因子为：$$k = \min\left(\left\lfloor \frac{a}{x} \right\rfloor,\ \left\lfloor \frac{b}{y} \right\rfloor\right)$$降低比例后。 

一种更微妙的情况是不存在有效的阳性监测器。```
a = 1
b = 1
x = 2
y = 3
```即使是最小的保持比例显示器也需要尺寸`(2, 3)`，这不适合。 正确的输出是：```
0 0
```有缺陷的实现可能会意外输出负值、小数值或`(2, 3)`没有仔细检查边界。 

## 方法

 暴力方法会尝试所有可能的缩放因子`k`并检查是否`(k·x, k·y)`适合里面`(a, b)`。 在所有有效选择中，我们会保留面积最大的一个。 

这是有效的，因为每个有效的监视器都具有比率`x : y`必须是某个整数倍`(x, y)`。 问题是搜索空间的大小。 如果`a = b = 2 · 10^9`和`x = y = 1`， 然后`k`可以大到`2 · 10^9`。 迭代数十亿个候选者的速度太慢了。 

关键的观察结果是该面积单调增长`k`。 

面积等于：$$(kx)(ky) = k^2xy$$自从`x`和`y`是固定正数，最大化面积与最大化面积完全相同`k`。 

因此，我们不需要测试每个候选者，而只需要最大的整数`k`满意：$$kx \le a$$

$$ky \le b$$这给出：$$k \le \left\lfloor \frac{a}{x} \right\rfloor$$

$$k \le \left\lfloor \frac{b}{y} \right\rfloor$$最大有效值就是这两个限制中较小的一个。 

还有一个重要的细节。 计算前`k`，我们必须降低比率`(x, y)`通过它们的最大公约数。 否则，我们会人为地强制显示器尺寸大于必要的尺寸。 

例如，比率`100 : 50`真的是`2 : 1`。 使用未缩减的版本严重限制了可能的缩放因子。 

将两个数字除以后`gcd(x, y)`，算法就变成了一些算术运算和一次gcd计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(min(a/x, b/y)) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(log(min(x, y))) | O(log(min(x, y))) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取四个整数`a`,`b`,`x`， 和`y`。`a`和`b`是监视器限制，而`x : y`是所需的纵横比。 
2. 计算`g = gcd(x, y)`。 

该比例不得减少。 除以 gcd 得出最小当量比。 
3. 更换：$$x \leftarrow \frac{x}{g}$$

$$y \leftarrow \frac{y}{g}$$这一步之后，`x`和`y`是互质的。 
4. 计算最大可能的比例因子：$$k = \min\left(\left\lfloor \frac{a}{x} \right\rfloor,\ \left\lfloor \frac{b}{y} \right\rfloor\right)$$任何较大的值都会违反至少一个维度限制。 
5、输出：$$(k \cdot x,\ k \cdot y)$$如果`k = 0`，这会自动变为`0 0`，意味着不存在有效的简化监视器。 

### 为什么它有效

 降低比例后，每个有效的显示器都具有宽高比`x : y`有形式`(kx, ky)`对于某个整数`k ≥ 0`。 

显示器约束要求两个尺寸都适合：$$kx \le a$$

$$ky \le b$$所以每一个有效的`k`必须满足：$$k \le \left\lfloor \frac{a}{x} \right\rfloor$$和$$k \le \left\lfloor \frac{b}{y} \right\rfloor$$取最小值给出最大的可行比例因子。 

由于面积等于：$$(kx)(ky) = k^2xy$$和`x`,`y`是固定正整数，面积严格增加为`k`增加。 最大有效`k`总是产生最大可能的面积。 

首先降低比率是必要的，因为所有等效的宽高比都应代表同一系列的显示器。 使用未减少的值会跳过有效的候选者。 

## Python 解决方案```python
import sys
from math import gcd

input = sys.stdin.readline

a, b, x, y = map(int, input().split())

g = gcd(x, y)

x //= g
y //= g

k = min(a // x, b // y)

print(k * x, k * y)
```解法直接遵循数学推导。 

第一个重要的步骤是降低比率`gcd`。 如果没有这个，算法可能会产生小于最佳的监视器。 自从`x`和`y`可以大到`2 · 10^9`，使用欧几里得算法是理想的，因为它以对数时间运行。 

标准化后，代码计算最大可能的缩放因子`k`。 整数除法在这里至关重要。 我们需要仍然适合监视器范围的最大整数乘数。 

操作顺序很重要。 我们在计算除法之前先减小比率。 如果我们使用未减少的值计算限制，我们可能会低估有效的缩放因子。 

Python 整数会自动避免溢出，但这种逻辑在 64 位语言中也是安全的，因为最大可能的乘积是：$$2 \cdot 10^9$$它非常适合有符号 64 位整数。 

该实现自然会处理不可能的情况。 如果其中之一`a // x`或者`b // y`等于零，那么`k = 0`，打印结果变为`0 0`。

import sys, io
from math import gcd

def solve():
    input = sys.stdin.readline

    a, b, x, y = map(int, input().split())

    g = gcd(x, y)

    x //= g
    y //= g

    k = min(a // x, b // y)

    print(k * x, k * y)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

 ## 边缘情况

 考虑未降低比率的情况：```
10 10 6 4
```该算法计算：$$gcd(6,4)=2$$所以比率变成`(3,2)`。 

然后：$$k = \min(10//3,\ 10//2)=\min(3,5)=3$$最终的监视器是：```
9 6
```如果我们跳过约简，我们只会得到`(6,4)`，其面积要小得多。 

现在检查一个不可能的配置：```
1 1 2 3
```这个比例已经降低了。 缩放因子变为：$$k = \min(1//2,\ 1//3)=\min(0,0)=0$$该算法输出：```
0 0
```这正确地表明没有阳性监测器可以满足该比率。 

最后，考虑一个维度是瓶颈的情况：```
8 5 4 3
```我们计算：$$k = \min(8//4,\ 5//3)=\min(2,1)=1$$结果变成：```
4 3
```即使宽度允许缩放`2`，身高没有。 取两个限制中的最小值可保证两个维度同时保持有效。
