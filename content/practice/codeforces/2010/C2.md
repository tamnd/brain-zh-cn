 ## 解决方案
 ## 问题理解

 我们被要求确定给定的字符串是否可能是由网络中非常具体的传输错误导致的。 当一条消息出现时会出现错误`s`连续发送两次，并且第二个副本以某个非零长度与第一个副本部分重叠。 换句话说，第一个消息的后缀与第二个消息的前缀完全一致，并且网络将它们合并。 该重叠部分必须严格小于全长`s`，因此完全重复的消息或完全串联的副本不会被视为错误。 

输入是单个字符串`t`表示收到的消息，最长可达 400,000 个字符。 如果没有可能的原始消息，则输出为“NO”`s`这可以解释`t`通过合并，或“是”后跟一个可能的`s`。 

约束意味着暴力方法会尝试每一种可能的分割`t`进入重叠副本太慢。 二次算法将涉及检查每个可能的前缀后缀对的重叠，这大致是`O(n^2)`操作为`n ≈ 4·10^5`。 这远远超出了 2 秒运行时间的可行限制。 这告诉我们需要一种线性或近线性方法。 

非明显的边缘情况包括：

 - 出现重复但不重叠的消息。 例如，`abcabc`是简单的重复`abc`，不是错误。 幼稚的方法可能会错误地认为这是一个错误。 
- 完全统一的消息，例如`aaaa`。 在这里，多个长度可能存在重叠，但合并后的消息仍然可能不明确。 
- 非常短的消息，例如`ab`，其中所需的最小重叠是一个字符。 

如果未能正确处理这些问题，将会导致误报。 

## 方法

 蛮力方法很简单：对于每个可能的重叠长度`k`从 1 到`len(t) - 1`，取第一个`len(t) - k`作为候选消息的字符`s`并检查最后是否`len(t) - k`的字符`t`匹配第一个`len(t) - k`的字符`s`。 如果找到匹配，则返回`s`。 这在概念上可行，但需要检查`O(n)`候选重叠并比较最多可达的字符串`O(n)`每个长度，导致`O(n^2)`复杂。 为了`n ≈ 4·10^5`，这太慢了。 

关键的见解是这个问题相当于找到最长的正确前缀`t`这也是一个后缀。 这是字符串哈希或 Knuth-Morris-Pratt (KMP) 前缀函数的经典用例。 如果我们计算前缀函数`t`，它告诉我们每个位置的最长边框的长度（前缀也是后缀）。 适当长度的边框`k`严格介于 0 和`len(t)`与合并错误中的有效重叠完全对应。 一旦我们知道这一点`k`，我们可以重构`s`作为`t[0:len(t) - k]`。 

因此，最优解在时间上是线性的，并使用前缀函数或字符串散列来找到最大边界。 使用滚动哈希也是可能的，但 KMP 前缀函数更简单，避免模运算，并保证正确性而不会发生冲突。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 前缀函数 (KMP) | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算前缀函数`pi`对于字符串`t`。 对于每个`i`,`pi[i]`存储最长的适当前缀的长度`t[0..i]`这也是一个后缀。 
2.考虑价值`k = pi[-1]`。 这是整个字符串的最长边框的长度`t`。 
3. 检查是否`k`严格介于 0 和`len(t) // 2`。 如果`k == 0`没有重叠； 如果`k == len(t)`或者`k == len(t) // 2`和`t`完全重复，我们将其视为非错误。 
4.如果`k`有效，原消息`s`是`t[0:len(t) - k]`。 
5. 否则，输出“NO”。 

为什么它有效：前缀函数不变式保证`pi[i]`始终代表有效边界。 通过查看`pi[-1]`，我们找到可能导致合并的最大重叠。 如果不存在正的正确边界，则不可能出现合并错误。 KMP 计算确保线性时间，每个字符恰好扫描一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = input().strip()
    n = len(t)
    pi = [0] * n
    
    for i in range(1, n):
        j = pi[i - 1]
        while j > 0 and t[i] != t[j]:
            j = pi[j - 1]
        if t[i] == t[j]:
            j += 1
        pi[i] = j
    
    k = pi[-1]
    if k == 0 or k == n:
        print("NO")
    else:
        s = t[:n - k]
        print("YES")
        print(s)

if __name__ == "__main__":
    main()
```第一部分读取输入并初始化前缀函数数组。 循环充满`pi`根据标准KMP更新，当字符不匹配时小心回滚。 计算出最大边界后`k`，我们检查有效性：`0 < k < n`。 如果有效，`s`只是排除重叠后缀的子字符串。 边界条件如`k = n`处理完整的重复，这不是错误。
