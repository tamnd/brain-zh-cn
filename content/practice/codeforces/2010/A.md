 ## 解决方案
 ## 问题理解

 任务是计算整数序列的交替和。 具体来说，对于每个序列，您从第一个数字开始，添加它，减去第二个数字，添加第三个数字，减去第四个数字，然后继续这种交替模式。 输入提供多个序列，每个序列都有其长度和序列本身，并且输出必须为每个序列生成一个表示此交替和的整数。 

限制很小：每个序列最多有 50 个元素，最多可以有 1000 个序列。 每个整数最多为 100。这意味着对每个序列进行简单的线性传递将无需考虑性能问题，因为在最坏的情况下我们将处理 50,000 个数字，这对于现代 CPU 来说是微不足道的。 在 Python 中，整数溢出不是问题，因为整数是任意精度的。 

要考虑的边缘情况包括仅具有一个元素的序列、具有所有相同数字的序列以及所有数字均为偶数或奇数的序列。 例如，如果序列只是`[100]`，交替和是`100`。 如果序列是`[100, 100]`，交替和是`0`。 幼稚的实现可能会意外地从减法开始或使符号错位，从而导致错误的结果。 

## 方法

 最直接的方法是直接模拟。 迭代序列的每个元素，保持运行总和。 对于每个元素，根据其在序列中的位置决定是添加还是减去它：添加第一个元素，减去第二个元素，依此类推。 此方法之所以有效，是因为序列长度很小，并且操作计数与序列大小呈线性关系。 

可以稍微简化实现的见解是认识到交替符号对应于将每个元素乘以`+1`或者`-1`取决于它的索引。 如果索引从零开始，则符号为`1`对于偶数指数和`-1`对于奇数索引。 这消除了条件逻辑并将问题简化为简单的乘积之和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个测试用例 O(n) | O(1) | O(1) | 已接受 |
 | 基于符号的乘法 | 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 考虑到限制，这两种方法都足够快。 

## 算法演练

 1.读取测试用例数量`t`。 这告诉我们将处理多少个序列。 
2. 循环每个测试用例。 对于每个测试用例：

 1.读取序列的长度`n`。 
2. 阅读`n`将序列的整数放入列表中`a`。 
3. 初始化变量`total`为零。 这将存储运行交替总和。 
4. 循环每个元素`a[i]`按顺序：

 - 如果索引`i`是偶数，加`a[i]`到`total`。 
- 如果索引`i`是奇数，减去`a[i]`从`total`。 
5.处理完序列后，打印`total`。 
3. 重复，直到处理完所有测试用例。 

为什么它有效：通过根据索引交替符号，我们保证第一个元素被添加，第二个元素被减去，依此类推。 这完全符合交替和的定义。 由于每个数字只处理一次，因此不会遗漏任何值，并且不变量`total`始终保持正确的交替总和，直到维持当前索引。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    total = 0
    for i in range(n):
        if i % 2 == 0:
            total += a[i]
        else:
            total -= a[i]
    print(total)
```代码首先读取`t`然后迭代每个测试用例。 对于每个序列，它读取`n`和整数。 变量`total`跟踪交替总和。 如果索引为偶数，则循环添加该元素；如果索引为奇数，则循环减去该元素。 使用`i % 2`保证始终添加第一个元素，保留交替模式。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total = 0
        for i in range(n):
            if i % 2 == 0:
                total += a[i]
            else:
                total -= a[i]
        print(total)
    return output.getvalue().strip()

 ## 边缘情况

 对于像这样的单元素序列`[100]`，该算法添加第一个元素并且从不减去，结果是`100`，这是正确的。 对于像这样的二元素序列`[100, 100]`，该算法添加第一个元素并减去第二个元素，给出`0`。 在 50 个元素的最大尺寸序列中，全部等于`1`，交替和为零，因为加法和减法完全抵消。 索引由`i % 2`正确处理奇数和偶数序列长度，无需特殊情况。
