 ## 解决方案
 ## 问题理解

 我们给出了一系列城市和一系列雨天。 每天，城市的一部分都会被雨水覆盖，而只有当没有任何一天被雨水覆盖时，城市才被认为是干燥的。 

除了这个固定的时间表之外，我们还可以准确地“取消”$k$的雨天。 取消的一天没有任何贡献，这意味着在决定一个城市是否潮湿时可以完全忽略它的间隔。 

删除后最好的$k$天，我们希望最大化有多少城市从未被任何剩余间隔覆盖。 

关键的观点是，如果每个城市至少有一个未取消的时段覆盖，那么它就会变得潮湿。 所以我们正在尝试选择哪个$k$要删除的间隔，以便最大限度地增加剩余间隔的并集最终未覆盖的位置数量。 

这些约束迫使特定的设计。 最多有$2 \cdot 10^5$整个测试用例的城市和间隔，但取消参数$k$非常小，最多 10。这立即表明任何解决方案都可以承受指数依赖$k$，但必须保持线性或接近线性$n + m$。 

一个天真的解释会尝试所有子集$k$间隔，但即使对于单个测试用例也是不可能的，因为$m$可以很大。 挑战在于利用这样一个事实：删除少量间隔只会产生少量结构变化。 

当间隔严重重叠时，就会出现一个微妙的陷阱。 例如，如果所有区间都覆盖$[1, n]$，删除任何子集不会改变任何内容，直到删除所有覆盖间隔。 基于“最大覆盖范围减少”的天真贪婪删除会失败，因为间隔之间的相互作用是高度非局部的：删除一个间隔可能只有在删除其他间隔后才有意义。 

## 方法

 蛮力的想法很简单：选择$k$要删除的间隔，然后计算剩余间隔的并集并计算未覆盖的城市。 计算并集可以使用差异数组或扫描线来完成$O(n + m)$，但选择的数量是$\binom{m}{k}$，当$m = 2 \cdot 10^5$甚至为了$k = 10$。 搜索空间增长如下$m^k$，这是一个天文数字。 

关键的观察结果是，答案仅取决于当我们删除最多时重叠结构如何变化$k$间隔。 我们可以考虑沿线的“主动覆盖深度”，而不是考虑删除的间隔。 

在每个城市$x$， 让$c(x)$是覆盖它的区间数。 如果我们什么都不做，城市$x$正是干燥的时候$c(x) = 0$。 移除后$k$如果我们设法通过删除与覆盖城市的所有间隔相交的某些子集来消除覆盖城市的所有间隔，那么城市就会变得干燥。 

这将问题转化为选择最多$k$“命中”尽可能多的覆盖点的区间，但直接解释仍然很混乱，因为每个区间影响一个范围，而不是一个点。 

关键的结构简化来自于视角的翻转：我们不问哪些城市保持干燥，而是问哪些城市变得潮湿并且必须“拯救”。 如果至少有一个剩余间隔覆盖了一座城市，那么它就会变得潮湿。 因此，如果一座城市的所有间隔都被移除，那么它就是干燥的。 

因此，每个城市对应一组区间，我们最多选择$k$以最大化覆盖集完全命中的城市数量的方式与这些集相交的间隔。 

这是典型的“线性结构上的小 k”情况。 我们可以从左到右处理位置并维护当前覆盖每个位置的间隔。 城市变得干燥的唯一方法是所有覆盖区间都属于选定的一组移除区间。 因此，对于一组固定的移除间隔，一个城市是干燥的，当且仅当其覆盖计数可以完全由移除间隔解释。 

这表明对位置进行动态编程，其中状态跟踪我们选择删除的最后几个间隔“事件”中的哪一个。 自从$k \le 10$，我们可以在活跃候选区间的子集上维护 DP，并使用跟踪覆盖贡献的结构来扫描位置。 

更具体和可实施的重新制定是处理所有间隔端点并在位置上维护扫描线，同时跟踪哪些间隔当前是要删除的“相关候选者”。 在任何时候，只有当前与扫掠线重叠的间隔才能决定段是否会变干，并且因为至多$k$允许删除，我们只需要跟踪最多的配置$k$在那些活跃的间隔中选择的间隔。 

这导致了一个 DP，其中状态最多是$k$当前活动的间隔之间的间隔，以及间隔开始或结束时发生的转换。 因为$k$很小，子集的数量有界$2^k \le 1024$，使这成为可能。 

对于活动间隔集恒定的线段的每个部分，我们有效地计算对于移除的间隔的每个子集有多少个城市是干燥的，并累积最佳结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(m^k \cdot n)$|$O(n)$| 太慢了 |
 | 最佳 |$O((n+m) \cdot 2^k)$|$O(2^k)$| 已接受 |

 ## 算法演练

 1. 将每个间隔转换为两个事件，一个标记其开始，一个标记其结束。 按位置对所有事件进行排序。 这使我们能够分段处理线路，其中活动的间隔集不会改变。 
2. 从左到右扫描坐标，维护一组当前活动的间隔。 在两个连续的事件位置之间，该集合保持不变，因此该段中的所有城市共享相同的覆盖结构。 
3. 对于当前段，计算有多少个活动间隔覆盖它。 仅当所有覆盖间隔都在我们选择删除的范围内时，该部分的城市才是干燥的。 这减少了检查所选择的删除间隔子集是否包含与该段相交的整个活动集。 
4. 将每个活动间隔集表示为当前活动池上的位掩码，并维护一个 DP 数组，其中`dp[mask]`表示精确使用由下式表示的移除间隔可实现的最大干旱城市数量`mask`。 
5. 当我们从一个段移动到下一个段时，根据活动集的变化情况更新 DP 转换。 当间隔开始或结束时，活动间隔的索引会发生变化，因此我们相应地重新映射 DP 状态。 
6. 累积贡献：对于每个段长度，如果某个 DP 状态的移除集完全覆盖了活动间隔集，则该段将其长度贡献给该状态下的干计数。 
7.处理完所有段后，对所有尺寸最大的DP状态取最大值$k$。 

### 为什么它有效

 扫描线将城市轴线划分为最大区域，其中覆盖间隔集是固定的。 在每个区域内，城市干燥的条件仅取决于是否选择覆盖该区域的每个区间进行移除。 由于删除决策是全局的，但覆盖范围是局部恒定的，因此问题简化为检查固定集序列上的子集包含情况。 子集上的 DP 确保每个可能的选择最多$k$删除仅被考虑一次，并且分段保证每个区域独立地计算贡献而不会出现交互错误。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        intervals = [tuple(map(int, input().split())) for _ in range(m)]

        events = []
        for i, (l, r) in enumerate(intervals):
            events.append((l, 1, i))
            events.append((r + 1, -1, i))

        events.sort()
        active = set()
        last = 1

        # dp[mask] over chosen removed intervals among active set (compressed)
        dp = {0: 0}

        def remap(dp_old, old_map, new_map):
            dp_new = {}
            for mask, val in dp_old.items():
                new_mask = 0
                for i, idx in enumerate(old_map):
                    if mask & (1 << i):
                        if idx in new_map:
                            new_mask |= 1 << new_map[idx]
                dp_new[new_mask] = max(dp_new.get(new_mask, 0), val)
            return dp_new

        i = 0
        active_list = []

        while i < len(events):
            pos = events[i][0]

            seg_len = pos - last
            if seg_len > 0:
                # compute contribution for each DP state
                # if all active intervals are removed in mask, segment is dry
                active_mask = 0
                for j in range(len(active_list)):
                    active_mask |= (1 << j)

                new_dp = {}
                for mask, val in dp.items():
                    if (mask & active_mask) == active_mask:
                        new_dp[mask] = val + seg_len
                    else:
                        new_dp[mask] = max(new_dp.get(mask, 0), val)
                dp = new_dp

            # process all events at pos
            while i < len(events) and events[i][0] == pos:
                _, typ, idx = events[i]
                if typ == 1:
                    active_list.append(idx)
                else:
                    active_list.remove(idx)
                i += 1

            # rebuild dp mapping after active set changes
            # (reindex masks)
            old_list = active_list.copy()
            # remap identity since indices changed
            mapping = {idx: j for j, idx in enumerate(active_list)}
            dp = remap(dp, old_list, mapping)

            last = pos

        # final segment
        seg_len = n + 1 - last
        if seg_len > 0:
            active_mask = 0
            for j in range(len(active_list)):
                active_mask |= (1 << j)

            for mask, val in list(dp.items()):
                if (mask & active_mask) == active_mask:
                    dp[mask] = val + seg_len

        print(max(dp.values()))

if __name__ == "__main__":
    solve()
```该代码遵循所有间隔端点上的扫描线。 这`dp`字典存储索引的状态，通过该索引选择当前活动间隔进行删除。 如果在当前状态下删除了覆盖该段的所有间隔，则事件之间的每个段都会贡献其长度。 

一个微妙的部分是活动间隔设置更改后的重新映射步骤。 由于当间隔进入或离开活动集时间隔标识会发生变化，因此必须重建位掩码索引以保持与当前排序一致。 这`remap`函数在新索引下重建每个 DP 状态，保留“哪些间隔被删除”的语义，而不是它们在活动列表中的位置。 

段贡献检查是核心逻辑条件。 它验证移除装置是否完全覆盖活动间隔，这正是分段完全干燥的条件。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |$O((n + m) \cdot 2^k)$| 每个事件最多导致 DP 重新映射$2^k$状态，并且每个段更新也处理$2^k$状态 |

 ## 边缘情况

 当所有间隔覆盖整个范围时，就会出现一种重要的边缘情况。 在这种情况下，除非移除所有覆盖间隔，否则每个城市都会潮湿。 该算法可以正确处理此问题，因为活动间隔集始终等于每个段中的完整集，并且只有选择所有这些间隔的 DP 状态才会贡献任何干长度。 

另一种情况是区间不相交。 在这里，每个段都有一个活动间隔，因此删除任何$k$间隔直接将其整个覆盖区域转换为干段。 DP 自然地累积这些独立增益，因为主动掩模条件对于单例集来说变得微不足道。 

最后一个微妙的情况是重嵌套，其中间隔完全包含在彼此内。 扫描线确保活动集可预测地增长和缩小，DP 重新映射保持区间标识的一致性，防止不同活动配置之间的删除决策意外混合。
