 ## 解决方案
 ## 问题理解

 原始网络是一个连通的多重图。 每个节点都有一个当前度数，即连接到该节点的光纤链路的数量。 新网络必须是一棵树，因为它需要每对节点之间只有一条路由。 一棵树总是有精确的`n - 1`边缘。 目标是选择节点度数与尽可能多的节点的旧度数匹配的任何树，然后打印最小数量的更改节点和一棵这样的树。 

对于线性或近线性图算法来说，约束足够小。 该图最多可以有`10000`节点和`100000`边，因此重复尝试可能的树或对总度数使用动态规划是不切实际的。 我们需要利用树度序列的结构。 

一些边缘情况很容易被忽略。 如果输入图已经是一棵树，则每个度都可以保持不变。 例如：```
4 3
0 1
1 2
2 3
```答案是`0`，因为现有的边已经形成了一棵有效的树。 

另一种情况是密集图，其中每个顶点都有很大的度数：```
4 4
0 1
1 2
2 3
3 0
```每个节点都有度`2`，但是四个顶点的树有度数和`6`， 不是`8`。 保持所有四个学位是不可能的。 仅检查度数序列是否是图形的粗心解决方案将会失败，因为树的总和条件更严格。 

最后一个极端情况是许多顶点都有度数`1`。 叶子非常有价值，因为它们不消耗内部学位预算。 例如：```
5 4
0 1
0 2
0 3
0 4
```这些度已经是一个树度序列。 中心保持学位`4`所有叶子都保持度数`1`。 

## 方法

 强力解决方案可以尝试构建许多可能的树，并将它们的度序列与输入进行比较。 由于标记树的数量是`n^(n-2)`，即使对于很小的值，这也是不可能的`n`。 即使将搜索限制为可能的度数序列也没有足够的帮助，因为可能保留度数的顶点子集的数量是`2^n`。 

关键的观察是树度序列有一个非常简单的条件。 对于每个顶点，将其贡献定义为`degree - 1`。 在任意树中：```
sum(degree - 1) = n - 2
```有度数的顶点`1`贡献为零。 如果我们决定保留一些顶点，它们的总贡献不能超过`n - 2`。 任何缺失的贡献都可以分配给已更改的顶点。 

问题变成选择其值的最大顶点数`degree - 1`适合容量`n - 2`。 由于每个选定的项目具有相同的重要性值，因此我们应该首先选择贡献最小的项目。 

选择要保留的顶点后，所有剩余的顶点都可以更改。 我们将所有剩余的贡献分配给其中一个，并让其他人离开。 任何满足树和的正度序列都可以实现为一棵树，我们可以用标准的 Prüfer 序列构造来构建它。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) 或更糟 | O(n) | 太慢了 |
 | 最佳 | O(n log n + n) | O(n log n + n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算原图中每个节点的度。 将每个学位转化为贡献`degree - 1`。 
2. 按贡献度对顶点进行排序，在总和不超过的情况下，取贡献度最小的`n - 2`。 

所选择的顶点是在某些树中能够保留其原始度数的顶点。 选择最小的贡献可以最大化适合固定树度预算的顶点数量。 
3. 将所有其他顶点标记为已更改。 树所需的剩余贡献是：`remaining = n - 2 - sum(kept contributions)`。 

将整个值分配给一个已更改的顶点。 它的最终度数变为`remaining + 1`。 每个其他发生变化的顶点的贡献为零，因此它变成了叶子。 
4. 使用生成的度序列构造一棵树。 

一种方便的方法是创建 Prüfer 序列。 有度数的顶点`d`准确地出现`d - 1`普吕弗序列中的时间。 解码该序列会生成一棵具有所需度数的树。 

为什么它有效：

 保留的顶点最多有总贡献`n - 2`，因此剩余贡献始终是非负的。 将所有剩余贡献添加到已更改的顶点会产生有效的树度序列，因为总贡献恰好变为`n - 2`。 贪心选择是最优的，因为每个保留的顶点都会花费`degree - 1`相同容量的单位，因此使用最小的成本可以保留尽可能多的顶点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    deg = [0] * n
    for _ in range(m):
        a, b = map(int, input().split())
        deg[a] += 1
        deg[b] += 1

    order = sorted(range(n), key=lambda x: deg[x] - 1)

    keep = [False] * n
    used = 0
    cnt = 0
    for v in order:
        if used + deg[v] - 1 <= n - 2:
            used += deg[v] - 1
            keep[v] = True
            cnt += 1

    ans = []
    new_deg = [1] * n
    changed = []
    for i in range(n):
        if keep[i]:
            new_deg[i] = deg[i]
        else:
            changed.append(i)

    if changed:
        rem = n - 2 - sum(new_deg[i] - 1 for i in range(n) if keep[i])
        new_deg[changed[0]] = rem + 1

    prufer = []
    for i in range(n):
        for _ in range(new_deg[i] - 1):
            prufer.append(i)

    leaves = [i for i in range(n) if new_deg[i] == 1]
    import heapq
    heapq.heapify(leaves)

    edges = []
    for x in prufer:
        leaf = heapq.heappop(leaves)
        edges.append((leaf, x))
        new_deg[leaf] -= 1
        new_deg[x] -= 1
        if new_deg[x] == 1:
            heapq.heappush(leaves, x)

    if len(leaves) == 2:
        a = heapq.heappop(leaves)
        b = heapq.heappop(leaves)
        edges.append((a, b))

    out = [str(n) + " " + str(n - 1)]
    out.extend(f"{a} {b}" for a, b in edges)
    print(cnt)
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```第一部分仅计算度数。 在此之后，原始边缘本身就不再相关，因为新网络可能使用任意无线链路。 

贪心选择使用`degree - 1`而不是程度，因为这是每棵树中都有固定总数的数量。 按此值排序给出保留顶点的最大数量。 

Prüfer 序列构造是度到边的最终转换。 序列长度正好是`n - 2`，并且顶点的每次出现都会将其最终度数减一。 叶子堆保证解码始终选择有效的叶子。

 ## 边缘情况

 当原始图已经是一棵树时，容量计算会保留每个顶点，因为总贡献恰好是`n - 2`。 该构造重新创建具有相同度数序列的树。 

当图的总度数过多（例如循环）时，贪婪步骤会删除昂贵的顶点，直到贡献适合。 删除的顶点将转换为叶子或一个更高阶的连接器，因此最终序列的总和仍然正确。 

当许多顶点都是叶子时，它们的贡献为零，因此贪心过程会自动保留它们。 这与叶子是树中保存成本最低的顶点这一事实相符。
