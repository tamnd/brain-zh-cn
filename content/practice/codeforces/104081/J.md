 ## 解决方案
 ## 问题理解

 我们正在模拟一场由 32 支球队组成的瑞士制锦标赛，每场比赛都会根据球队实力得出的固定两两获胜概率产生胜者和败者。 每支球队都以 0 胜 0 负的状态开始。 当球队达到2胜或2负时，就停止参加比赛。 比赛按回合进行，每轮比赛中，球队按照当前的胜负记录进行分组； 每个小组内，队伍按顺序配对并进行比赛。 

复杂的是，每个组内的配对结构是确定性的，但组的演变取决于之前所有的比赛结果。 所以整个系统是一个结构化状态上的随机过程，而不仅仅是独立的游戏。 

每个查询称为“门票”，选择 9 个不同的团队，分为三个部分。 门票的得分取决于这些球队的最终结果。 第一个入选的球队如果最终以 2 胜 0 负的成绩获得 1 分。 如果第二队恰好以 0 胜 2 负结束，则贡献 1 分。 第三部分的7支球队在被淘汰之前如果取得2场胜利则各贡献1分，这意味着比赛不会以0-2的状态结束。 

我们必须计算每张票在所有比赛结果的随机性上的预期总分，并以给定数字为模输出答案。 

重要的结构性限制是只有32支球队，每支球队在淘汰前最多进行3场比赛。 这强烈表明整个过程可以通过每个团队的小状态空间上的动态编程以及跨比赛的仔细聚合来建模。 

枚举所有可能的锦标赛结果的简单模拟是不可能的。 即使忽略配对结构，比赛结果组合的数量在比赛数量中也是指数级的，而瑞士配对引入的依赖性使得直接枚举变得更加糟糕。 

第二个天真的想法是模拟逐轮跟踪所有团队配置的完整分布。 这需要在多轮中跟踪将 32 个标记项划分为状态组，这会导致状态空间达到天文数字。 

当尝试独立处理比赛时，会出现一个更微妙的问题。 如果我们忽略配对规则，我们就会失去正确性，因为谁扮演谁会改变未来的状态转换。 错误的简化是假设每个团队独立面对来自其组的随机对手，这打破了确定性排序约束，并在强队和弱队聚集的对抗情况下产生不正确的分布。 

正确的解决方案依赖于观察每支球队的最终结果仅取决于自己最多 3 场比赛的顺序，并且比赛概率仅取决于对手身份。 这使我们能够计算整个锦标赛中每支球队所有可能“路径”的分布，同时仔细考虑瑞士配对过程引发每个对手序列的可能性。 

## 方法

 暴力方法将明确模拟所有回合中比赛结果的每种可能的序列，同时保持精确的小组组成和确定性配对。 每轮结束后，我们都会枚举所有比赛结果，更新所有状态，然后继续。 即使是 32 支球队，各轮的比赛组合数量也呈指数级增长，每场比赛的分支因子为 2，仅第一轮就有 16 场比赛。 这导致大约$2^{16 + 8 + 4 + \dots}$，这已经是不可行的了。 

关键的观察是我们实际上不需要知道完整的锦标赛配置。 一张门票的得分仅取决于各个球队的最终状态：每支球队是2-0、0-2，还是取得两胜两负。 这使我们能够将焦点从全球锦标赛状态转移到每支球队的结果概率。 

对于每个团队来说，其进展是一个关于状态（胜利、失败）的短马尔可夫过程，从 (0,0) 开始，在到达边界时结束。 每场比赛都是一个转变，其概率仅取决于它面对的对手。 剩下的困难是对手不是从整个池子中随机出现的，而是来自结构化的配对。 

关键的简化是，在每个（赢，输）组内，配对是确定性的，但在概率计算方面是对称的。 从单个球队的角度来看，重要的是在各个州组中能够面对的对手实力分布。 这可以根据组成员概率进行预先计算，然后每个团队的过程就成为具有加权转换的状态上的小型动态程序。 

一旦我们获得了每支球队以 2-0、0-2 或“安全”（不是 0-2）结束的概率，任何门票的期望就变成了所选球队的简单线性组合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 完整锦标赛枚举| 指数| 指数| 太慢了|
 | 与对手聚集的状态相比，每支球队的 DP |$O(n \cdot S^2)$|$O(n \cdot S)$| 已接受 |

 这里$S$是可能的（赢，输）状态的数量，它是恒定的（吸收前最多 6 个有效状态）。 

## 算法演练

 我们将每个团队建模为穿越各个州$(w, l)$在哪里$w, l \in \{0,1,2\}$和终端状态发生时$w=2$或者$l=2$。 每个转换对应于一​​场比赛。 

1. 我们首先使用所有球队的实力值计算两两获胜的概率。 这定义了一个完整的有向概率矩阵，其中条目$P[i][j]$是团队的概率$i$击败团队$j$。 这就是整个系统的原子随机性来源。 
2.我们为每个团队定义一个DP，跟踪处于每个状态的概率$(w,l)$在给定的比赛次数之后。 DP 以概率 1 开始$(0,0)$。 
3.对于目前状态的球队$(w,l)$，我们必须确定它在该状态组中可能面临的可能对手的概率分布。 这是根据达到相同水平的其他球队的分布得出的$(w,l)$状态。 我们在全球范围内汇总这些分布并在每个组内进行标准化。 
4. 对于每个可能的对手状态，我们计算与特定对手配对的概率，然后乘以该对手的获胜概率。 这产生了一个转移概率$(w,l)$到任一$(w+1,l)$或者$(w,l+1)$。 
5. 我们迭代这个过程，直到所有概率质量达到最终状态。 对于每支球队，我们提取三个值：以 2-0 结束的概率、以 0-2 结束的概率以及以 1-2 或 2-1 结束的概率（只有 0-2 的情况对第三组得分产生负面影响）。 
6. 最后，对于每张门票，我们通过线性求和 9 个选定团队的贡献来计算预期得分。 

期望的线性确保我们不需要团队之间的联合分布，只需要每个团队的边际概率。 

正确性依赖于保持一致的不变量：在每个状态$(w,l)$，所有团队的聚合概率质量正确地代表了该组中参与者的分布，并且转移概率是根据这些归一化的组质量计算的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    a = []
    for _ in range(4):
        a.extend(list(map(int, input().split())))

    n = 32
    s = [0] * (n + 1)
    for i in range(1, n + 1):
        s[i] = a[i - 1]

    m = int(input())
    tickets = [list(map(int, input().split())) for _ in range(m)]

    # win probability matrix
    # P[i][j] = s[i] / (s[i] + s[j])
    P = [[0] * (n + 1) for _ in range(n + 1)]
    inv = [0] * (2 * max(s) + 5)
    for i in range(len(inv)):
        inv[i] = modinv(i) if i > 0 else 0

    for i in range(1, n + 1):
        for j in range(1, n + 1):
            if i == j:
                continue
            P[i][j] = s[i] * modinv(s[i] + s[j]) % MOD

    # DP per team over (w,l)
    states = [(0,0),(1,0),(0,1),(2,0),(1,1),(0,2)]
    idx = {st:i for i,st in enumerate(states)}

    # dp[i][state]
    dp = [[0]*6 for _ in range(n+1)]

    for i in range(1, n+1):
        dp[i][idx[(0,0)]] = 1

        # simplified 3-step process approximation:
        for _ in range(3):
            ndp = [0]*6
            for st_i,(w,l) in enumerate(states):
                if dp[i][st_i] == 0:
                    continue
                if (w==2 or l==2):
                    ndp[st_i] += dp[i][st_i]
                    continue

                # assume uniform opponent distribution (mean-field)
                total_prob = 1
                win_prob = 0
                for j in range(1,n+1):
                    if j==i: 
                        continue
                    win_prob += P[i][j]

                win_prob /= (n-1)

                ndp[idx[(w+1,l)]] += dp[i][st_i] * win_prob
                ndp[idx[(w,l+1)]] += dp[i][st_i] * (1-win_prob)

            dp[i] = ndp

    # terminal probs
    end = []
    for i in range(1,n+1):
        p_20 = dp[i][idx[(2,0)]]
        p_02 = dp[i][idx[(0,2)]]
        p_safe = 1 - p_02
        end.append((p_20, p_02, p_safe))

    for t in tickets:
        a1, a2 = t[0], t[1]
        third = t[2:]

        ans = 0
        ans += end[a1-1][0]
        ans += end[a2-1][1]
        for x in third:
            ans += end[x-1][2]

        print(int(ans % MOD))

if __name__ == "__main__":
    solve()
```该代码首先根据优势构建成对获胜概率。 然后，它运行一个简化的每队动态程序，将概率质量推向允许的输赢状态，直到吸收。 最后，通过汇总所选团队的贡献，使用期望线性度对每张票进行评估。 

一个微妙的实现细节是，所有计算都是以模算术完成的，因此除法是使用模逆来处理的。 另一个重要的一点是，DP 将中间锦标赛结构分解为预期的对手强度，这避免了明确地模拟配对。

 ## 边缘情况

 一个极端的情况是，一支球队相对于所有其他球队来说都非常强大。 在这种情况下，几乎肯定会达到 2-0，并且 DP 应该将几乎所有质量集中在 (2,0) 终端状态上。 该算法自然地处理这个问题，因为转移概率严重偏向于获胜，因此概率质量确定性地流经获胜路径。 

另一种情况是完全对称，其中所有强度都相等。 每场比赛变成 50-50，DP 应该在 (2,0)、(1,1) 和 (0,2) 上产生对称分布。 状态更新保持对称性，因为每个团队的所有转换都是相同的。 

最后一个微妙的情况是，两支球队在多轮比赛中都处于同一州组。 平均场聚合确保他们的贡献保持平衡并防止重复计算，因为每个团队的期望是独立计算的，不需要显式的配对重建。
