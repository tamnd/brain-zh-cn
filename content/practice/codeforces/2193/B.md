 ## 解决方案
 ## 问题理解

 我们得到了从 1 到 n 的数字排列，这意味着这个范围内的每个数字都恰好出现一次。 我们可以选择这个排列的一个连续段并将其反转。 我们的目标是通过恰好一个这样的反转来产生字典顺序上最大的排列。 字典序比较的工作方式类似于字典顺序：在两个序列不同的第一个索引处，数字较大的序列被认为较大。 

对于输入，我们收到多个测试用例。 每个测试用例都会给我们排列的长度和排列本身。 每个测试用例的输出是由一个最佳片段反转产生的排列，该最佳片段反转使字典顺序中的序列最大化。 

约束告诉我们 n 可以达到 200,000，并且所有测试用例的 n 总和也是 200,000。 这限制了我们每个测试用例的 O(n) 或 O(n log n) 解决方案，因为任何二次方程都会超出时间限制。 边缘情况包括长度为 1 或 2 的非常小的排列、已按降序排序的排列以及最大数字位于末尾的排列。 粗心的方法可能只是反转第一个递减的段或包含最大值的第一个段，但如果最佳反转需要将段拉伸到末尾或跳过较小的数字，则可能会失败。 

例如，给定`[3,2,1,4]`，天真的方法可能会逆转`[3,2,1]`到`[1,2,3,4]`，按字典顺序比反转小`[3,2,1,4]`到`[4,1,2,3]`。 

## 方法

 一种强力方法是尝试每对可能的索引（l，r）进行反转，反转该段，并按字典顺序比较结果。 这样的段有 O(n^2) 个，每次反转检查序列的成本为 O(n)，使得暴力方法的复杂度为 O(n^3)。 对于n达到2×10^5，这是完全不可行的。 

关键的观察是，字典顺序最大排列总是从可以移到前面的最大可能数字开始。 反转段允许我们将任何元素带到第一个位置，在所有此类移动中，最佳的移动是将最大的数字移动到第一个位置，同时反转尽可能少的元素，以保持后续数字尽可能大。 

具体来说，我们首先找到排列的最大元素。 然后，我们将段从数组开头反转到该最大元素的索引。 这会将最大元素放在前面，序列的其余部分遵循的顺序确保较小的数字不会不必要地阻塞后面较大的数字。 这是有效的，因为第一个位置在字典比较中占主导地位，因此将最大的数字放在那里总是最佳的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取 n 和排列 p。 
2. 确定p中最大元素的位置。 将此作为索引`i_max`。 
3. 反转从排列开始到的段`i_max`包容性。 
4. 输出修改后的排列。 

这样做的原因是第一个元素在字典顺序中是最重要的。 将最大的元素放在第一个位置可以保证最大可能的前缀。 反转超出最大元素或首先选择较小的元素只会减少第一个有效值，从而产生较小的字典排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        i_max = p.index(max(p))
        # Reverse from start to the max element's index
        p[:i_max+1] = reversed(p[:i_max+1])
        print(' '.join(map(str, p)))

if __name__ == "__main__":
    solve()
```该解决方案使用有效地读取所有输入`sys.stdin.readline`为了速度。 我们使用 Python 找到最大值`max`和`index`，其时间复杂度为 O(n)。 反转切片是就地完成的，保持空间不变。 通过记住 Python 中的切片在末尾是互斥的，可以避免差一错误，因此`p[:i_max+1]`正确包含位于`i_max`。 

## 工作示例

 用于输入`[3,2,1,4]`,`max(p)=4`在索引 3 处。 倒车`[3,2,1,4]`从开始到索引 3 给出`[4,1,2,3]`，这是字典顺序上最大的排列。 

| 步骤| p|
 | ---| ---|
 | 原创| [3,2,1,4] |
 | 逆转0-3 | [4,1,2,3] |

 用于输入`[3,1,2]`,`max(p)=3`在索引 0 处。反转`[3]`树叶`[3,1,2]`不变。 

| 步骤| p|
 | ---| ---|
 | 原创| [3,1,2]|
 | 逆转 0-0 | [3,1,2]|

 这些痕迹表明，算法可以正确识别最大值何时已位于前面，否则将其向前移动。

 ## 边缘情况

 当排列长度为1时，例如`[1]`，反转段`[0,0]`什么都不做并正确输出`[1]`。 对于最大值已经位于第一个位置的排列，例如`[4,3,2,1]`，算法识别出`i_max=0`并反转长度为一的段，使数组保持不变。 在这两种情况下，算法都不会执行不必​​要的反转并保持正确性。 对于像这样的排列`[2,1]`，算法识别出`2`作为索引 0 处的最大值并且不执行反转，输出`[2,1]`正确。
