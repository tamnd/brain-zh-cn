 ## 解决方案
 ## 问题理解

 我们得到一棵树，它是一个连通的无环图，其中$n$顶点，每个顶点都有一个关联的整数值。 我们可以重复执行的操作是，如果一个顶点的剩余邻居值的总和与它自己的值在奇偶性上不同，则删除该顶点。 也就是说，如果邻居的总和是奇数而顶点是偶数，或者反之亦然，我们可以将其删除。 一旦移除，顶点及其所有边都会消失，可能会改变其邻居的总和。 任务是决定是否可以按照此规则顺序删除所有顶点，并且如果可能，输出任何有效的删除序列。 

约束很严格：$n$可以达到$2 \cdot 10^5$并且最多可以有$10^4$测试用例。 重复扫描所有顶点以查找可移动候选点的简单模拟将需要$O(n^2)$在最坏的情况下，这对于上限来说太慢了。 我们需要一个在所有测试用例中的顶点总数接近线性的解决方案。 

关键边缘情况是其邻居都具有与其自身相同的奇偶校验和的顶点。 如果树很小，请说$n = 3$如果值为 [2, 1, 4]，并且边将它们线性连接，则可能没有顶点满足开始时的奇偶校验条件。 如果粗心地假设任何树都是可移动的，就会错误地输出 YES。 另一个棘手的情况发生在叶子较多的树上，其中删除叶子会改变邻居的总和，并使先前阻塞的顶点被删除。 该算法必须仔细考虑动态更新邻居总和。 

## 方法

 暴力方法很简单：在每一步中，扫描所有顶点，计算其当前邻居的值的总和，并删除奇偶校验和不同的顶点。 重复此操作，直到所有顶点都被删除或不存在这样的顶点。 这在概念上是正确的，但效率极低。 为了$n$顶点，每次扫描可能需要$O(n)$，在最坏的情况下我们执行$n$拆除，导致$O(n^2)$每个测试用例的操作。 对于大树来说这将会超时。 

优化的关键见解是以深度优先的方式处理树，同时尊重奇偶性。 一旦叶子被移除，它的值就会影响其父节点的邻居总和，然后可能满足移除条件。 通过任意对树进行生根并执行 DFS，我们可以在后序遍历中删除顶点，同时在本地检查奇偶校验条件。 后序遍历确保在顶点本身之前考虑顶点的所有子节点，从而有效地模拟邻居和的动态更新，而无需每次显式重新计算和。 这将复杂性降低到$O(n)$每个测试用例。 

后序 DFS 之所以有效，是因为顶点的奇偶校验仅取决于当前邻居的总和。 当我们首先处理子项时，我们保证任何移除效果都会向上传播。 如果在处理完所有子树后无法移除根本身，则无法完全移除该树。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | DFS / 后序贪婪 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取顶点数$n$和顶点值数组$a$。 构造表示树的邻接表。 
2. 选择任意顶点作为根。 一个方便的选择是顶点 1。 
3. 定义一个 DFS 函数，递归处理当前顶点的子节点。 对于每个孩子，首先调用 DFS。 
4. 处理完所有子节点后，检查当前顶点与其当前尚未删除的邻居之和的奇偶校验。 如果奇偶校验不同，则将此顶点标记为可移除并将其附加到移除序列中。 
5. 继续DFS，直到访问完从根可到达的所有顶点。 如果在任何时候子树中没有顶点可以被删除，则回溯，并且最终如果无法删除根，则声明“NO”。 
6. DFS之后，如果移除序列包含所有$n$顶点，输出 YES 和序列。 否则输出NO。 

工作原理：通过后序处理，每个顶点都在其子节点之后被考虑，确保邻居总和准确地反映在移除条件中。 任何叶顶点或具有满足奇偶性的顶点都可以被删除，并且删除会将效果传播到父级。 不变量是，在每一步，如果一个顶点在序列中，则它满足该时刻的奇偶校验条件。 由于每次删除都是有效的并且最终会考虑所有顶点，因此算法会在可能的情况下生成正确的序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        adj = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            adj[u].append(v)
            adj[v].append(u)
        
        removed = [False] * n
        result = []
        
        def dfs(v, parent):
            for u in adj[v]:
                if u == parent:
                    continue
                dfs(u, v)
            S_v = sum(a[u] for u in adj[v] if not removed[u])
            if (S_v % 2) != (a[v] % 2):
                removed[v] = True
                result.append(v + 1)
        
        dfs(0, -1)
        if len(result) == n:
            print("YES")
            print(" ".join(map(str, result)))
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```邻接表有效地表示了树。 我们使用布尔数组`removed`跟踪哪些顶点已被取出。 DFS 是后序的，因此我们首先递归地删除子节点，然后在其邻居和奇偶校验允许的情况下删除当前顶点。 这`result`数组捕获序列。 仔细的索引可确保顶点的输出从 1 开始。 设置高递归限制可以防止深层树的堆栈溢出。
