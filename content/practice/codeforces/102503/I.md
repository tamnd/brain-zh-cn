 ## 解决方案
 ## 问题理解

 我们有`n`人，每个人都需要一定的服务时间`a_i`。 有`k`独立收银员。 队列是分配给一个收银员的人员的有序列表，一个人的等待时间是同一队列中排在他们前面的每个人的总服务时间。 

我们的目标不是最小化每个人都完成之前的时间。 它是为了最小化所有启动延迟的总和。 在找到可能的最短总等待时间后，我们必须计算有多少种不同的线路安排达到了这一要求。 

对于一条包含有服务时间的人员的固定线路`x1, x2, ..., xm`，最好的顺序始终是从小到大。 贡献变为：`(m-1)x1 + (m-2)x2 + ... + 1*x(m-1) + 0*xm`约束条件允许`n`达到`100000`，总的`n`在所有测试中也受`100000`。 这排除了尝试将所有人员分配到线路甚至所有分区的任何操作。 解必须接近线性或`O(n log n)`。 排序是可以接受的，但指数或二次方法则不行。 

棘手的情况来自于收银员的数量和同等的服务时间。 

如果每个人都有足够的收银员，那么就没有人需要等待。 例如：```
1
3 5
4 4 4
```答案是：```
0 60
```有`5 * 4 * 3`为三人选择不同的收银员方式。 只计算人员排列的解决方案会错过收银员的选择​​。 

另一个微妙的情况是相等的值。 为了：```
1
3 2
5 5 5
```最短等待时间为`5`，但是三个人的每一个最优摆放位置都要计算在内。 将相等的值视为可区分的排序位置而不进行组合计数会给出错误的答案。 

## 方法

 暴力解决方案将尝试所有可能的人员分布`k`行以及每行内的每个顺序。 对于每一种安排，它可以计算总的等待时间并保留最好的一个。 这是正确的，因为它直接检查每种可能性，但排列数量的增长速度超过指数。 和`n = 100000`，即使产生其中的一小部分也是不可能的。 

有用的观察来自于查看系数。 一行中最后一个人贡献系数`0`，他们前面的人贡献系数`1`,下一个贡献系数`2`， 等等。 总等待时间是`a_i`乘以这些系数。 

为了使结果最小化，最长的服务时间必须获得最小的系数。 这与排序背后的交换参数相同：如果较大的值比较小的值具有更大的系数，则交换它们会减少总数。 

唯一剩下的问题是哪些系数可用。 每个非空收银员贡献一个带有系数的槽位`0`。 之后，收银员中每增加一个人都会创建系数`1, 2, 3, ...`。 为了避免产生较大的系数，额外的人员必须尽可能均匀地分配给收银员。 

让：`extra = n - k`是不是队伍中最后一个人的人数。 如果`n >= k`，每个收银员可以有一个最终人。 我们分发`extra`之间的系数槽`k`线。 如果：`extra = q * k + r`那么每个系数`1`到`q`出现`k`次数、系数`q+1`出现`r`次。 

计数部分遵循相同的顺序。 一旦系数槽固定，值较大的人就必须填充较小的系数。 等值可以交换，因此我们处理等值组并计算它们可以以多少种方式占用可用的标记槽。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1、对服务时间进行排序。 排序让我们应用交换参数：较大的值必须放入较小的等待系数中。 
2.如果`k >= n`，最短等待时间为零，因为每个人都可以收到自己的收银员。 安排数量是指派出纳员的人员数量：`k * (k-1) * ... * (k-n+1)`。 

1. 否则，创建系数桶。 有`k`带系数的槽`0`。 让`extra = n-k`,`q = extra // k`， 和`r = extra % k`。 添加`k`每个系数的槽位`1`通过`q`，然后添加`r`带系数的槽`q+1`。 
2. 将从大到小的排序后的人分配到从小到大的系数槽中，计算最小值。 系数列表的第一部分给出了最终的等待总和。 
3. 通过将具有相同价值观的人放在一起来计算最佳分配。 对于每个值组，取系数最小的当前可用槽的数量。 如果组仅使用系数桶的一部分，请选择将哪些标记槽与组合一起使用。 选择槽位后，等值组内的人可以自由排列。 

为什么它有效：

 系数表示将调度问题转化为固定成本的赋值问题。 通过均匀分布额外的人来最小化系数多重集，因为将一个额外的人从较长的队伍移动到较短的队伍会减少现有的最大系数。 一旦系数固定，重排不等式证明以系数相反的顺序对值进行排序可以得到最小和。 计数过程准确地枚举了当相等的值创建多个最佳分配时仍然可能的选择。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

MAXN = 100000
fact = [1] * (MAXN + 1)
invfact = [1] * (MAXN + 1)

for i in range(1, MAXN + 1):
    fact[i] = fact[i-1] * i % MOD

invfact[MAXN] = pow(fact[MAXN], MOD - 2, MOD)
for i in range(MAXN, 0, -1):
    invfact[i-1] = invfact[i] * i % MOD

def comb(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n-r] % MOD

def solve_case(n, k, a):
    if k >= n:
        ways = 1
        for i in range(n):
            ways = ways * (k - i) % MOD
        return 0, ways

    a.sort()

    coeff = []
    extra = n - k
    q, r = divmod(extra, k)

    coeff.extend([0] * k)
    for c in range(1, q + 1):
        coeff.extend([c] * k)
    coeff.extend([q + 1] * r)

    ans = 0
    for x, c in zip(a, sorted(coeff, reverse=True)):
        ans += x * c

    buckets = []
    i = 0
    while i < n:
        j = i
        while j < n and a[j] == a[i]:
            j += 1
        buckets.append((a[i], j - i))
        i = j

    cnt = {}
    for c in coeff:
        cnt[c] = cnt.get(c, 0) + 1

    levels = sorted(cnt)
    ptr = 0
    rem = [cnt[x] for x in levels]

    ways = 1

    for _, size in reversed(buckets):
        need = size
        used_slots = 0
        while need:
            take = min(need, rem[ptr])
            ways = ways * comb(rem[ptr], take) % MOD
            rem[ptr] -= take
            need -= take
            used_slots += take
            if rem[ptr] == 0:
                ptr += 1
        ways = ways * fact[size] % MOD

    return ans % MOD, ways

def main():
    t = int(input())
    out = []
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        x, y = solve_case(n, k, a)
        out.append(f"{x} {y}")
    print("\n".join(out))

if __name__ == "__main__":
    main()
```预处理计算阶乘和逆阶乘，因此每个组合查询都是恒定时间。 这是必需的，因为等值组可能会跨系数桶分裂。 

的建设`coeff`遵循演练中的平衡分配论点。 该列表准确地包含了最佳排列中可用的等待系数。 

对于最小答案，将排序值与反转系数配对会将最大值放置在最小系数处。 

为了计数，代码存储每个系数级别剩余的槽数。 当处理一组相等的值时，它选择哪些标记的槽接收该值，并乘以该组中人员的内部排列数。 

所有涉及答案的算术都以模数执行`10^9+7`。 最短等待时间本身可以超过32位整数，因此直接使用Python整数。

 ## 边缘情况

 当收银员比人多时，算法会避免创建系数桶并直接对单射分配进行计数。 这处理了每个人都可以立即开始的情况。 

当所有服务时间相等时，仅靠排序无法确定唯一的位置。 基于组的计数步骤保留了相同人之间的所有有效交换。 

什么时候`n`仅略大于`k`，正系数很少。 例如，与`n=5`和`k=4`，只有一个人必须等待，因此系数列表变为`[0,0,0,0,1]`。 该结构在没有特殊情况的情况下处理了这个问题。 

什么时候`k=1`，每个系数来自`0`到`n-1`恰好出现一次。 该方法成为经典的通过增加服务时间进行排序的单线调度规则。
