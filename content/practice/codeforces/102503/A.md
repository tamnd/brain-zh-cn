 ## 解决方案
 ## 问题理解

 我们有四个人身高`v`,`a`,`r`， 和`p`。 我们必须选择其中的三个人并将这三个人堆叠在一起。 所得高度是他们三个个体高度的总和。 如果该金额至少为，则过山车接受结果人员`h`。 

任务是确定四个可能的三组中的至少一组是否达到要求的高度。 如果存在这样的组，我们打印`WAW`; 否则，我们打印`AWW`。 

输入包含前四行的四个高度，后跟所需的最小高度`h`。 每个值都在 12 到 150 之间，因此值很小，整数运算就足够了。 更重要的是，正好有四个人，也就是说只有四个人。`C(4,3) = 4`可能要检查的组。 即使是直接的穷举搜索也会执行恒定数量的添加和比较，因此 1 秒的时间限制远非限制性的。 

如果不小心编写条件，有一些边界情况可能会导致错误的实现。 首先，准确达到所需的高度就足够了。 例如，有高度`12, 12, 12, 20`和`h = 36`，选择三个身高的人`12, 12, 12`准确地给出`36`，所以正确的输出是`WAW`。 使用`>`而不是`>=`会错误打印`AWW`。 

当唯一成功的组中包含最高的人时，就会出现第二种情况。 例如，有高度`12, 12, 12, 20`和`h = 44`，三个最大的高度之和为`44`，所以答案是`WAW`。 仅检查前三个输入值的实现将错过有效组。 

第三种情况是，即使是三个最高的人也太矮了。 有高度`20, 20, 20, 20`和`h = 61`，每个可能的组都有高度`60`，所以答案是`AWW`。 事实上，四个人一起就能到达`80`没有帮助，因为形成的人必须恰好包含三个人。 

## 方法

 暴力解决方案可以简单地枚举每组三个人，将他们的身高相加，然后检查总和是否至少为`h`。 这是完全正确的，因为每一个法律选择都经过审查。 四个人的话，正好有`C(4,3) = 4`因此，最坏的情况需要四次加法和四次比较，直到枚举的恒定开销。 

对于给定的问题，这种强力方法实际上不会变得太慢。 输入大小固定为四人，因此其运行时间为`O(1)`。 在通用版本中`n`人们，检查每个三元组需要`O(n^3)`，这可能会变得昂贵。 然而，对于这个特定的 Codeforces 问题，`n = 4`，使得详尽的方法既简单又被完全接受。 

我们可以更紧凑地进行相同的观察。 在所有三人组中，总和最大的组由三个最高的人组成。 如果这三个人达不到`h`，没有其他组可以。 如果可以的话，该群体本身就是一个有效的选择。 因此，对四个高度进行排序并检查三个最大值也可以在恒定时间内解决问题，尽管排序是不必要的。 

直接枚举更可取，因为它准确地反映了任务的定义，并避免引入问题不需要的操作。 关键的见解是搜索空间仅包含四种选择。

 ## 算法演练

 1.将四个高度读入数组，读取需要的高度`h`。 将高度保持在一起可以很容易地推理出每一个可能的三组。 
2. 枚举四个高度中三个不同位置的每种组合。 只有四种组合，因此可以直接检查每个合法组。 
3. 对于每个组合，计算其三个高度的总和并与`h`。 使用`>=`因为身高恰好达到最低允许身高的人可以骑行。 
4. 如果任意总和至少为`h`，立即打印`WAW`。 找到一个成功的组就足够了，因为问题询问是否至少存在一个有效的组。 
5. 如果四种组合都比较失败，则打印`AWW`。 此时，每个可能的三组都已被检查，因此不存在有效的排列。 

### 为什么它有效

 不变的是，在检查任意数量的组合后，每个检查的组合都被正确分类为足够高或太矮。 该算法检查所有四个可能的三组。 如果打印出来`WAW`，它找到了一个组，其总和至少为`h`，所以答案是有效的。 如果打印出来`AWW`，每个可能的组的总和如下`h`，因此不存在有效的组。 由于该算法考虑了每一个合法的选择，因此它不会错过一个解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

v = int(input())
a = int(input())
r = int(input())
p = int(input())
h = int(input())

heights = [v, a, r, p]

for i in range(4):
    for j in range(i + 1, 4):
        for k in range(j + 1, 4):
            if heights[i] + heights[j] + heights[k] >= h:
                print("WAW")
                sys.exit()

print("AWW")
```四个高度存储在一个列表中，以便组合循环可以统一工作。 三个嵌套循环使用`i < j < k`，这保证了每三个人的集合只被考虑一次，并且没有人被选择两次。 

比较使用`>= h`，满足所形成的人的身高可以恰好是阈值的要求。 一旦找到有效的三元组，`sys.exit()`终止程序，因为检查任何剩余的三元组无法改变答案。 

Python 中不存在整数溢出问题，即使在具有固定宽度整数类型的语言中，此处最大可能的和也仅为`150 + 150 + 150 = 450`。 

输入仅包含一个测试用例，因此不存在外部测试用例循环。 所要求的`input = sys.stdin.readline`form 仍然用于高效且标准的竞争性编程输入处理。

 所有四个法律团体都失败了，因为`60 < 61`。 算法进入最终阶段`print("AWW")`，产生正确的输出。 

### 示例 2

 高度是`24, 55, 42, 69`， 和`h = 143`。 

|`i`|`j`|`k`| 选定的高度| 总和|`sum >= h`|
 | --- | --- | --- | --- | --- | --- |
 | 0 | 1 | 2 | 24、55、42 | 121 | 121 没有 |
 | 0 | 1 | 3 | 24、55、69 | 148 | 148 是的 |

 第二组已经到达`143`，所以算法打印`WAW`并退出而不需要检查剩余的两个组合。 这说明了为什么算法可以在找到一个有效组后立即停止。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    heights = [int(input()), int(input()), int(input()), int(input())]
    h = int(input())

    for i in range(4):
        for j in range(i + 1, 4):
            for k in range(j + 1, 4):
                if heights[i] + heights[j] + heights[k] >= h:
                    return "WAW"

    return "AWW"

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    try:
        return solve()
    finally:
        sys.stdin = old_stdin

# Provided samples
assert run("20\n20\n20\n20\n61\n") == "AWW", "sample 1"
assert run("24\n55\n42\n69\n143\n") == "WAW", "sample 2"

# Minimum-size values, and exactly reaching the threshold.
assert run("12\n12\n12\n12\n36\n") == "WAW", "minimum values at boundary"

# Maximum-size values, with a threshold that is exactly reachable.
assert run("150\n150\n150\n12\n450\n") == "WAW", "maximum values at boundary"

# All groups are one unit short of the threshold.
assert run("20\n20\n20\n20\n61\n") == "AWW", "just below threshold"

# The only successful group contains the fourth input value.
assert run("12\n12\n12\n20\n44\n") == "WAW", "valid group uses fourth person"

print("All tests passed.")

 ## 边缘情况

 平等边界由`>=`比较。 用于输入```
12
12
12
12
36
```第一个三元组有总和`12 + 12 + 12 = 36`。 自从`36 >= 36`，算法立即返回`WAW`。 一个实现使用`>`会错误地拒绝此案。 

由于嵌套循环不优先考虑任何输入位置，因此处理了第四人称必不可少的情况。 为了```
12
12
12
20
44
```前三个三元组的总和如下`44`，但是包含高度的组合`12, 12, 20`达到`44`。 当循环到达索引时`1, 2, 3`，条件成功，输出为`WAW`。 

四个人就够了，三个不行的情况也能正确处理。 和```
20
20
20
20
61
```每个合法三元组都有高度`60`。 该算法从不将所有四个人一起考虑，因为该任务只允许形成的人中的三个人。 每个三元组都失败，所以输出是`AWW`。 

最后，最大值不需要任何特殊处理。 和```
150
150
150
12
450
```前三人已经到达`450`，正是所需的高度。 算法打印`WAW`，Python 的整数运算直接处理总和，没有任何溢出问题。
