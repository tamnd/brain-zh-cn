 ## 解决方案
 ## 问题理解

 给定一个由不同正整数组成的数组，我们的任务是从长度至少为 2 的任何连续子数组中找到可能获得的最大“幸运数字”。 “幸运数字”被定义为子数组中最大和第二大元素的按位异或。 

输入由数组长度组成$n$和$n$整数本身。 输出是一个整数：所有子数组中最大的幸运数。 

和$n$最多$10^5$每个数字最多$10^9$，检查所有子数组的简单方法是不可行的。 大致有$n^2/2$子数组，对于每个子数组，找到两个最大的数字需要$O(r-l)$，导致$O(n^3)$算法。 对于时间限制来说，这显然太慢了。 

当数组按升序或降序排序时，会出现不明显的边缘情况。 例如，对于`s = [1, 2, 3, 4]`，最大幸运数字为`4 XOR 3 = 7`。 仅检查相邻对或试图维持“当前最大值”而不考虑第二大值的粗心方法可能会错过正确答案。 

另一个微妙之处是只有连续的子数组才重要。 最大的总数与数组中第二大的数进行异或并不总是答案。 例如，在`s = [1, 100, 2]`，全局最大值为 100，但某些子数组中的第二个最大值可能是 2 或 1，从而产生不同的 XOR 值。 

## 方法

 暴力方法的工作原理是迭代所有子数组，找到每个子数组中的两个最大数字，计算它们的异或，并跟踪最大值。 这是正确的，因为它会检查每个可能的候选者，但它需要粗略地$O(n^3)$操作：有$O(n^2)$子数组，并计算每个子数组中的两个最大数字$O(n)$。 为了$n = 10^5$，这是完全不切实际的。 

关键的见解是，在任何子数组中，最大幸运数字是由两个最大数字之一生成的，当在数组中从左到右考虑时，这两个数字**值相邻**。 这是因为，如果您查看 XOR 运算，就会发现距离最大值更远的较小数字永远不会比数组中的直接邻居贡献更大的 XOR。 

这将问题简化为仅检查数组中的**连续对**数字及其运行最大值。 可以使用基于堆栈的方法：从左到右迭代，维护递减的数字堆栈，并且对于每个新数字，与从堆栈中弹出的元素计算异或。 这有效地捕获了所有可以产生最大幸运数字的候选子数组。 

子数组中的最大 XOR 总是通过当前数字和左侧的前一个较大邻居，或者当前数字和右侧的前一个较大邻居来实现，这一观察结果让我们可以将问题简化为$O(n^2)$到$O(n)$在实践中。

 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 太慢了 |
 | 基于堆栈的优化 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个空栈和一个变量`ans = 0`追踪最大幸运数字。 
2. 迭代每个元素`x`在数组中。 
3. 当堆栈非空时：

 1. 计算 XOR`x`与堆栈顶部的元素。 
2. 更新`ans`如果这个 XOR 大于当前的`ans`。 
3.如果栈顶大于`x`， 休息。 否则，弹出顶部元素。 
4. 推`x`到堆栈上。 
5. 重复此操作，直至处理完所有元素。 
6. 打印`ans`。 

堆栈维护着从左到右递减的数字序列。 计算出的每个 XOR 都是最大幸运数字的候选者。 我们不需要显式检查所有子数组，因为任何其他元素都会产生比这些对之一更小的 XOR。 

**为什么有效：** 递减堆栈中的每一对相邻数字都代表一个子数组，其中一个是最大值，另一个是第二个最大值。 通过对照从堆栈中弹出的元素检查每个数字，我们可以有效地检查可以产生更大 XOR 的所有子数组。 不会错过任何候选者，因为任何小于当前顶部的数字都不会与先前元素产生比直接邻居更大的异或。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
s = list(map(int, input().split()))

stack = []
ans = 0

for x in s:
    while stack:
        ans = max(ans, stack[-1] ^ x)
        if stack[-1] > x:
            break
        stack.pop()
    stack.append(x)

print(ans)
```该方案直接实现了基于堆栈的方法。 我们迭代每个数字，将其与递减堆栈进行比较，并计算异或。 中断条件确保我们只按降序保留数字，并且弹出较小的数字保证我们不会错过连续子数组中潜在的第二个最大值。 使用快速输入`sys.stdin.readline`确保程序在 1 秒的时间限制内运行$n \le 10^5$。

 ## 边缘情况

 对于像这样的严格升序数组`[1, 2]`，算法正确计算`1 XOR 2 = 3`。 堆栈最初有 1，然后将 2 与 1 进行比较，在压入之前产生正确的幸运数字。 

对于严格降序数组`[3, 2, 1]`，堆栈确保每个数字与其最左边的邻居进行比较。`3 XOR 2 = 1 XOR`
