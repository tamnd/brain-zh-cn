 ## 解决方案
 ## 问题理解

 我们得到了一个一维的位置带，其中一些位置包含聚光灯。 每个聚光灯照亮其位置周围的连续部分，并以固定的范围向外扩展。 任务是在综合考虑所有聚光灯后确定线路上的最终总照明覆盖范围。 

您可以将输入视为聚光灯中心和固定照明半径的列表。 每个聚光灯在数轴上贡献一个间隔，并且重叠的照明区域应该合并而不是多次计数。 输出是所有照明间隔的并集的总长度。 

关键的困难在于，当间隔严重重叠时，天真地独立处理每个点会导致计数过多。 

从复杂性的角度来看，如果有多达 100000 个聚光灯，则检查所有对或单独标记每个单元位置的解决方案太慢。 在最坏的情况下，间隔上的二次方法将执行大约 10^10 次运算，这在典型限制下是不可行的。 如果坐标范围很大，即使是密集网格标记方法也会失败，因为内存和时间会随着坐标大小而爆炸。 

当所有聚光灯完全重叠时，会出现微妙的边缘情况。 例如，如果所有中心都相同并且半径很大，则每个聚光灯都会产生相同的间隔。 简单的求和会错误地乘以该覆盖范围。 

当聚光灯相距较远以致没有间隔重叠时，会出现另一种边缘情况。 在这种情况下，答案只是所有单独覆盖长度的总和，并且任何合并逻辑都不能由于不正确的排序或边界处理而意外地合并不相关的段。 

## 方法

 蛮力的想法很简单。 对于每个聚光灯，我们将其转换为线上的间隔，例如从中心减去半径到中心加半径。 然后，我们明确标记布尔数组或集合中的每个覆盖单元位置，并计算覆盖了多少个唯一位置。 

这是正确的，因为它直接模拟照明过程。 但是，当坐标值较大或坐标范围稀疏时，它会失败。 如果坐标跨度最大为 10^9，则不可能创建该大小的数组。 即使我们压缩坐标，迭代每个区间内的每个单位位置也可能导致总计 10^9 次操作。 

关键的观察结果是，问题简化为计算间隔并集的总长度。 一旦每个聚光灯转换为一个间隔，我们就不需要再推理各个点了。 我们只需要合并重叠的区间并将它们的长度相加即可。 

通过起始坐标对间隔进行排序使得该结构可利用。 排序后，重叠间隔会连续出现，因此我们可以从左到右扫描并维护当前活动的合并段。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(R) 或 O(n·R) | O(R)| 太慢了|
 | 排序+合并间隔| O(n log n) | O(n log n) | O(n) | 已接受 |

 这里R代表坐标范围或总覆盖的离散位置。 

## 算法演练

 我们将每个聚光灯转换为一个间隔，然后按排序顺序贪婪地合并它们。

1. 对于每个聚光灯，计算其覆盖间隔为[中心 - 半径，中心 + 半径]。 这将几何照明转化为标准间隔问题。 
2. 按左端点对所有间隔进行排序。 排序可确保任何重叠都必须与先前处理的间隔发生，因此我们永远不需要重新访问较早的段。 
3. 将当前间隔初始化为第一个排序间隔，并将运行答案初始化为零。 
4. 对剩余的间隔进行一一迭代。 
5. 对于每个新间隔，将其与当前合并的间隔进行比较。 
6. 如果新的间隔在当前间隔结束后开始，则不存在重叠。 将当前间隔的长度添加到答案中并开始新的当前间隔。 这是安全的，因为未来的间隔不会因排序而向后重叠。 
7. 如果新间隔与当前间隔重叠或接触，则扩展当前间隔的右端点以覆盖并集。 这保留了正确性，因为重叠覆盖范围不应重复计算。 
8. 处理完所有区间后，将最终的当前区间长度添加到答案中。 

这种贪婪合并起作用的原因是，在扫描中的任何点，当前间隔表示迄今为止看到的所有彼此重叠的间隔的完整并集。 由于间隔已排序，任何未来的间隔要么与该并集重叠，要么完全在其之后开始，并且任何较早的间隔都不能超出已合并的范围。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, r = map(int, input().split())
    intervals = []
    
    for _ in range(n):
        x = int(input())
        intervals.append((x - r, x + r))
    
    intervals.sort()
    
    ans = 0
    cur_l, cur_r = intervals[0]
    
    for l, r in intervals[1:]:
        if l > cur_r:
            ans += cur_r - cur_l
            cur_l, cur_r = l, r
        else:
            if r > cur_r:
                cur_r = r
    
    ans += cur_r - cur_l
    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先构建所有照明范围并将它们成对存储。 排序确保我们按照起始位置的升序处理间隔，这是贪婪合并工作所必需的。 

变量`cur_l`和`cur_r`维持当前活跃的合并覆盖范围。 每当出现差距时，就会最终确定前一段并添加到答案中。 如果存在重叠，我们只扩展右边界。 

一个常见的实现陷阱是忘记在循环结束后添加最后一个活动段，这将失去最终的贡献。 

## 工作示例

 考虑具有三个聚光灯和半径 2 的输入：```
centers: 1, 4, 10
```间隔变为：```
[-1, 3], [2, 6], [8, 12]
```排序顺序是一样的。 

| 步骤| 当前间隔 | 新间隔 | 行动| 总答案 |
 | ---| ---| ---| ---| ---|
 | 1 | [-1, 3] | [2, 6] | 合并 → [ -1, 6 ] | 0 |
 | 2 | [-1, 6] | [8, 12] | 关闭[-1,6]，开始新的 | 7 |

 最终区间 [8,12] 加 4，因此总数为 11。 

该轨迹显示了如何将重叠间隔合并到单个连续区域中，从而防止重复计数。

centers: 0, 10, 20 with r = 1

```| 步骤| 当前间隔 | 新间隔 | 行动| 总答案 |
 | ---| ---| ---| ---| ---|
 | 1 | [-1, 1] | [9, 11] | 关闭[-1,1]，开始新的 | 2 |
 | 2 | [9, 11] | [19, 21] | 关闭[9,11]，开始新的| 4 |

 最后一段添加 2 个，总共 6 个。 

这证实了非重叠区域是独立处理的。

 ## 边缘情况

 如果所有聚光灯共享相同的位置，则每个间隔都是相同的。 该算法仍然有效，因为排序使它们保持相邻，并且合并仅扩展一次，没有冗余计数。 

例如：```
3 5
10
10
10
```所有区间均为 [5,15]。 第一个间隔初始化当前段，并且每个后续间隔都被完全包含，因此不会发生任何更改。 最终答案是10。 

当间隔恰好接触边界时，例如 [0,2] 和 [2,5]，算法将它们视为重叠，因为`l > cur_r`相等时为假。 这可确保连续的覆盖范围正确合并到长度为 5 的单个段中。 

如果只有一个聚光灯，则循环永远不会执行，直接返回最后一段，避免空迭代逻辑中的相差一错误。
