 ## 解决方案
 ## 问题理解

 我们得到了一系列动物物种，代表动物进入等待队列的顺序。 最终的离开顺序并不固定，因为当它们的物种对被列为兼容时，相邻的动物可以交换位置。 任务是找到当所有动物最终离开时可能出现的按字典顺序排列的最小物种序列。 

输入描述了物种集、可能相互交叉的物种对以及原始序列。 输出是包含相同动物的另一个序列，但根据字典顺序排列为最早可能的离开顺序。 

关键的困难在于互换是本地的。 动物不能随意走到前面。 要向左移动穿过另一只动物，必须允许它与该动物的物种交换。 限制条件告诉我们，物种最多只有200个，但动物却多达10万只。 这排除了模拟交换或探索可能的排列，因为可达订单的数量可能是指数级的。 该算法必须几乎线性地处理序列，每个物种只需少量额外工作。 

有几个容易被忽视的案例。 如果一个物种根本没有朋友，那么它的动物就无法超越任何不同的物种。 例如：```
2 0 3
A
B
A B A
```答案是：```
A B A
```总是选择出现在任何地方的最小物种的粗心贪婪方法会输出`A A B`，这是不可能的，因为第二个`A`无法跨越`B`。 

另一个棘手的情况是同一物种的重复出现。 相同的物种不需要交叉许可，因为输出只关心物种名称，而不关心个体动物。 例如：```
2 0 3
A
B
A A B
```答案是：```
A A B
```将相同物种视为阻止对的解决方案将错误地阻止这两个物种`A`动物不再被放在一起考虑。 

第三种情况是较晚出现的一个物种被较早出现的同一物种所阻止。 例如：```
3 1 4
A
B
C
A B C B
A B
```答案是：```
A B C B
```最后一个`B`之前无法移动`C`虽然`B`小于`C`， 因为`B`必须穿越`C`，并且不允许进行交换。 

## 方法

 直接方法将尝试生成所有可到达的序列。 每个允许的相邻交换都会创建另一个可能的状态，因此我们可以对状态执行广度优先搜索并保留找到的最小序列。 这是正确的，因为每一个合法的交换都经过探索。 然而，即使只有少数动物，可能的状态数量也可以接近`N!`，使得完全不可能`N = 100000`。 

有用的观察是我们实际上不需要模拟交换。 相反，我们可以描述哪些动物被迫在其他动物之前停留。 

考虑一只动物的位置`i`。 如果存在更早物种的动物`X`那不是该物种的朋友`i`，那么动物在`i`永远不能在那个较早的动物面前移动。 这就产生了一个优先约束：较早的动物必须在当前的动物之前离开。 

重要的细节是我们只需要每个阻塞物种的最新出现情况。 如果存在较早出现的同一物种，则最新的一个是必须通过的最近的障碍。 如果可以对最新出现的物种进行杂交，那么同一物种的所有早期出现的物种也可以进行杂交。 

这些优先约束形成有向非循环图。 每个动物都是一个节点，以及一条边`a`到`b`意思是动物`a`必须在动物之前离开`b`。 任何有效的离开顺序都是该图的拓扑排序。 

在所有拓扑排序中，可以通过重复选择最小的可用节点来找到字典序最小的拓扑排序。 这是拓扑排序的标准优先级队列版本。 

蛮力之所以有效，是因为它探索了每一个法律命令，但它失败了，因为命令太多。 只有不可交换的先前物种才会产生限制，这一观察结果使我们能够将问题压缩到 DAG 中并贪婪地解决它。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳 | O(N * S + N log N) | O(N * S + N log N) | O(N + S²) | 已接受 |

 ## 算法演练

 1. 读取物种并为每个物种分配一个整数 id。 存储哪些物种可以交换。 
2. 从左到右扫描输入序列并创建动物之间的依赖图。 对于当前物种的动物`x`，检查每个物种`y`以前已经出现过。 如果`y`不允许交换`x`，添加最近的边缘`y`当前动物的发生情况。 

边缘意味着前一个动物必须先离开，因为当前的动物无法越过它。 
3. 扫描时保持每个物种的最新位置。 处理事件后，更新该物种的最新位置。 
4. 计算依赖图中所有节点的入度。 每个入度为零的节点都可以合法地成为下一个离开的动物。 
5. 将所有当前可用的动物放入按其物种名称排序的最小堆中。 反复删除最小的物种，将其附加到答案中，并减少其传出邻居的入度。 
6. 继续，直到所有动物都被移走。 产生的顺序是所需的离开顺序。 

为什么它有效：

 该图准确地包含了动物之间无法通过的限制。 如果从一种动物到另一种动物存在边缘，则每个有效序列都必须保持该顺序。 如果没有依赖边，较早的动物不会阻止较晚的动物到达前面。 因此，每个有效的离开顺序都对应于该图的拓扑排序。 

在卡恩算法的每一步中，可用的节点正是可以在不违反任何限制的情况下移动到前面的动物。 选择最小的可用物种总是安全的，因为在任何有效的排序中，不可用的动物都不能出现在它之前。 重复此选择会在每个位置给出尽可能小的前缀，因此整个序列按字典顺序是最小的。 

## Python 解决方案```python
import sys
import heapq

input = sys.stdin.readline

def solve():
    S, L, N = map(int, input().split())

    names = [input().strip() for _ in range(S)]
    ids = {name: i for i, name in enumerate(names)}

    friend = [[False] * S for _ in range(S)]
    for _ in range(L):
        a, b = input().split()
        x, y = ids[a], ids[b]
        friend[x][y] = True
        friend[y][x] = True

    seq = [ids[x] for x in input().split()]

    graph = [[] for _ in range(N)]
    indeg = [0] * N

    last = [-1] * S

    for i, x in enumerate(seq):
        for y in range(S):
            if last[y] != -1 and y != x and not friend[x][y]:
                graph[last[y]].append(i)
                indeg[i] += 1
        last[x] = i

    heap = []
    for i in range(N):
        if indeg[i] == 0:
            heapq.heappush(heap, (names[seq[i]], i))

    ans = []

    while heap:
        _, u = heapq.heappop(heap)
        ans.append(names[seq[u]])

        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                heapq.heappush(heap, (names[seq[v]], v))

    print(" ".join(ans))

if __name__ == "__main__":
    solve()
```第一部分将物种名称映射到整数标识符。 整数 ids 使朋友矩阵和以后的比较时间恒定。 

图构建是解决方案的核心。 在扫描序列时，`last[y]`存储最新出现的物种`y`。 当当前动物看到无法与其交换的先前物种时，最新发生的事件是最近的不可避免的阻碍因素，因此从该发生事件到当前事件会添加一条边缘。 

拓扑排序阶段使用堆而不是普通队列。 正常的拓扑排序会产生任何有效的排序，但问题要求最小的字母顺序。 堆总是删除最小的可用物种。 

不存在相差一的问题，因为节点通过其原始的从零开始的位置来表示动物。 仅当依赖关系被删除时，入度才会更新，并且当必须在其之前的所有动物都已输出时，节点才进入堆。

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(N * S + N log N) | O(N * S + N log N) | 创建依赖项时，每只动物都会检查所有物种，并且每个堆操作都会处理一只动物 |

 物种数量只有200个，因此检查每种动物的所有物种最多需要大约2000万次操作。 图和堆处理与动物数量呈线性或接近线性，这符合以下限制：`N = 100000`。

 ## 边缘情况

 对于没有友谊的情况：```
2 0 3
A
B
A B A
```该算法从第一个边缘创建一条边`A`到`B`， 因为`B`无法跨越`A`。 第二个`A`还取决于`B`如果`B`出现在它面前。 堆永远不会错误地暴露第二个`A`阻塞之前`B`，产生唯一有效的答案。 

对于重复的相同物种：```
2 0 3
A
B
A A B
```两人`A`动物之间不会产生依赖关系。 在检查互换时，只有不同的物种才重要。 该图从第一个开始就不包含边`A`到第二个`A`，所以两者之前都可用`B`，给出正确的结果`A A B`。 

对于较晚的事件被较早的事件阻止：```
3 1 4
A
B
C
A B
A B C B
```处理最终结果时`B`, 最新的`C`发生是一个阻碍因素，因为`B`和`C`不是朋友。 该图添加了`C -> B`，所以最后的`B`不能跳到前面`C`。 拓扑排序遵循此限制并返回最小的可达序列。
