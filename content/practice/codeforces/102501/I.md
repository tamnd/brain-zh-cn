 ## 解决方案
 ## 问题理解

 道格拉斯进行了一个经典的捕获和再捕获实验来估计老鼠种群的规模。 

第一天，他就抓住了`n1`老鼠，标记所有它们，然后释放它们。 第二天，他就钓到了`n2`老鼠，其中`n12`已经被标记了。 我们的任务不是手动计算估计，而是简单地评估 Chapman 估计器$$\left\lfloor \frac{(n_1+1)(n_2+1)}{n_{12}+1}\right\rfloor-1$$并打印结果整数。 

输入恰好由三个整数组成，因此不涉及搜索、模拟或优化。 每个值最多为10000，制作最大的乘积$$(10000+1)^2 = 100020001,$$它很容易适合 32 位有符号整数。 无论如何，Python 整数具有任意精度，因此溢出永远不是问题。 

唯一需要的工作是计算一次乘法、一次整数除法和一次减法。 任何超出常数时间的算法都是不必要的。 

一个微妙的实现错误是使用浮点运算而不是整数运算。 例如，使用输入```
10000 10000 3
```正确的结果是```
25004999
```使用浮点除法然后转换为整数可能仍然适用于这些限制，但依赖浮点是不必要的，并且可能会在类似问题中引入舍入误差。 整数整除直接符合数学定义。 

另一个容易犯的错误是忘记最后减一。 用于输入```
1 1 1
```公式变成$$\left\lfloor\frac{2\cdot2}{2}\right\rfloor-1
=2-1
=1,$$所以正确的输出是```
1
```仅打印商将错误地产生`2`。 

第三个常见错误是忽略了公式中添加的内容。 用于输入```
0 0 0
```正确的计算是$$\left\lfloor\frac{1\cdot1}{1}\right\rfloor-1=0,$$所以答案是```
0
```使用`n1 * n2 / n12`甚至会被零除。 

## 方法

 强力解释将尝试通过考虑每种可能的种群大小、检查哪些值与观察到的捕获兼容、甚至模拟重复实验来估计种群。 这种方法在数学上是不必要的，并且如果慷慨地选择搜索范围，则可能需要检查数百万个候选值。 

问题陈述已提供 Chapman 估计量作为所需的估计值。 人口规模不是我们必须通过算法推断的东西。 我们只需要将三个输入值代入给定的表达式并计算结果。 

关键的观察结果是估算器已经包含了所需的楼层操作。 整数整除运算计算出完全相同的值，而不使用浮点运算。 之后，减一并打印结果。

 ## 算法演练

 1.读取三个整数`n1`,`n2`， 和`n12`。 
2. 计算分子`(n1 + 1) * (n2 + 1)`。 该公式在相乘之前明确将两个捕获计数加一。 
3. 将分子除以`n12 + 1`使用整数除法。 这与估算器中的下限操作完全匹配。 
4. 从商中减一以获得查普曼估计。 
5. 打印结果整数。 

### 为什么它有效

 该算法是问题中给出的数学定义的直接实现。 整数取整除法计算$$\left\lfloor\frac{(n_1+1)(n_2+1)}{n_{12}+1}\right\rfloor,$$这正是估计器的第一部分。 之后减一即可精确地完成公式，因此计算值与所需的估计值相同。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n1, n2, n12 = map(int, input().split())

answer = ((n1 + 1) * (n2 + 1)) // (n12 + 1) - 1
print(answer)
```该程序首先从标准输入读取三个整数。 

下一行直接计算公式。 乘法在除法之前执行，保留精确的整数运算。 使用`//`是必不可少的，因为数学表达式需要商的下限。 

最后，程序减一并打印结果。 不需要特殊情况，因为`n12 + 1`始终至少为一，因此不会发生被零除的情况。

## 测试用例```python
import sys
import io

def solve():
    input = sys.stdin.readline
    n1, n2, n12 = map(int, input().split())
    print(((n1 + 1) * (n2 + 1)) // (n12 + 1) - 1)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    solve()
    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return out.getvalue()

 ## 边缘情况

 考虑输入```
0 0 0
```该算法计算`(0 + 1) * (0 + 1) = 1`，除以`0 + 1 = 1`，得到`1`，并减一以产生`0`。 每个运算都有明确的定义，因为分母永远不为零。 

考虑输入```
1 1 1
```分子是`(1 + 1) * (1 + 1) = 4`。 除以`1 + 1 = 2`给出`2`，减一产生`1`。 这证实了最终的减法是估计器的一部分并且不能被省略。 

考虑输入```
10000 10000 3
```分子是`10001 × 10001 = 100020001`。 整数整除除以`4`产量`25005000`，减去 1 得到`25004999`。 计算完全保持在整数算术范围内，避免任何舍入问题，同时处理最大允许的乘法。
