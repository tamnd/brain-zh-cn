 ## 解决方案
 ## 问题理解

 输入是树高度的有序列表。 每一种可能的变化都对应于一棵二叉树，其节点从左到右读取时都具有完全相同的高度序列。 每个节点的父节点的高度必须不大于其子​​节点，因此任何区间内的最小高度必须放置在该区间的根处。 

任务是计算有多少种不同的二叉树形状满足这些规则。 相同的高度是唯一引起歧义的原因。 如果某个区间的最小值出现多次，则这些位置中的任何一个都可以成为根，从而创建多个可能的结构。 

序列长度可达一百万，因此区间动态规划解法是不可能的。 所有子数组的递归将需要二次或更糟的工作，这远远超出了两秒限制所允许的范围。 该算法必须仅处理每个位置恒定的次数。 

主要边缘情况是所有值都相等的序列。 例如：```
3
5
5
5
```答案是`5`，因为这三个节点可以组成任意二叉树形状。 假设最小位置是唯一的解决方案将错误地返回一个。 

另一个重要的情况是分离相等的最小值：```
3
1
2
1
```答案是`2`。 两个节点的高度`1`可以排列为另一个的左子或右子。 将相等的值视为独立的最小值会错过这种相互作用。 

## 方法

 直接递归解决方案遵循定义。 对于一个区间，找到最小值，尝试将每次出现的最小值作为根，然后将其余两个区间的答案相乘。 这是正确的，因为每棵有效树都具有该区间的一个根位置。 

问题是相等值的数组会产生最糟糕的递归。 对于长度`n`，状态数量是二次的，尝试所有最小位置会增加另一个因素。 最坏的情况变得远远大于允许的操作数量。 

关键的观察结果是，相等的最小值表现为一个组。 假设出现一个区间的最小高度`k`次。 那些`k`节点构成任意二叉树的节点，而它们之间的间隙仅包含较大的值并且可以独立求解。 排列方式的数量`k`最小节点是`k`th 加泰罗尼亚号码。 

剩下的问题是如何有效地找到这些群体。 最小笛卡尔树给出了所需的分解。 我们用单调堆栈构建它。 在值相等的情况下，通过将最左边的最小值保留为父节点来解决关系，这使得相等的最小节点出现在右链上。 每一条这样的链都对应一个加泰罗尼亚因素。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 太慢了|
 | 笛卡尔树 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 根据序列构建最小笛卡尔树。 这棵树的中序遍历是原始序列，每个节点不大于其子​​节点。 单调堆栈结构保证了线性时间。 
2. 预先计算加泰罗尼亚语数字`N`。 如果一条链包含`k`最小节点相等，其贡献为`Catalan(k)`。 
3. 从下到上遍历笛卡尔树。 处理节点时，在值保持相等的情况下跟随右子节点。 这给出了完整的相等最小节点组。 
4. 乘以该链上悬挂的每个左子树的答案，乘以该链之后的子树的答案，然后乘以链长度的加泰罗尼亚数。 
5. 为根存储的答案是有效品种的数量。 

不变量是每个处理过的笛卡尔子树代表原始序列的一个连续区间。 该区间的根是其最小值。 相等的最小节点恰好形成根组的选择，并且每个剩余的子区间都是独立的，因此将这些贡献相乘将每个有效树恰好计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def solve():
    n = int(input())
    a = [int(input()) for _ in range(n)]

    if n == 0:
        print(1)
        return

    cat = [0] * (n + 1)
    cat[0] = 1
    for i in range(1, n + 1):
        s = 0
        for j in range(i):
            s = (s + cat[j] * cat[i - 1 - j]) % MOD
        cat[i] = s

    left = [-1] * n
    right = [-1] * n
    stack = []

    for i in range(n):
        last = -1
        while stack and a[stack[-1]] > a[i]:
            last = stack.pop()
        if stack:
            right[stack[-1]] = i
        if last != -1:
            left[i] = last
        stack.append(i)

    root = stack[0]

    ans = [0] * n
    group = [0] * n

    order = [(root, 0)]
    while order:
        u, state = order.pop()
        if state == 0:
            k = 0
            v = u
            while v != -1 and a[v] == a[u]:
                k += 1
                v = right[v]
            group[u] = k
            order.append((u, 1))

            v = u
            while v != -1 and a[v] == a[u]:
                if left[v] != -1:
                    order.append((left[v], 0))
                v = right[v]
            if v != -1:
                order.append((v, 0))
        else:
            res = cat[group[u]]
            v = u
            while v != -1 and a[v] == a[u]:
                if left[v] != -1:
                    res = res * ans[left[v]] % MOD
                v = right[v]
            if v != -1:
                res = res * ans[v] % MOD
            ans[u] = res

    print(ans[root] % MOD)

if __name__ == "__main__":
    solve()
```笛卡尔树结构使用包含当前右脊柱的堆栈。 当较小的值到达时，较大的节点将被删除并成为新节点的左子树。 相等的值不会被删除，因此最左边的相等最小值仍高于后面的相等值。 

动态遍历是迭代的，因为树的深度可以是一百万。 第一次访问发现等值链并调度所有独立子树。 第二次访问结合了他们已经计算出的答案。 

加泰罗尼亚语计算使用标准递归：`C[n] = sum(C[i] * C[n - 1 - i])`在哪里`C[0] = 1`。 这与可能的二叉树的数量相匹配`n`节点。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 笛卡尔树构造和树遍历每次都会接触每个节点恒定的次数。 |
 | 空间| O(n) | 树数组、动态编程值和堆栈每个位置存储一个条目。 |

 输入限制需要线性处理。 该解决方案避免了所有区间枚举并在内存限制内处理最大尺寸序列。

## 边缘情况

 对于单个元素：```
1
7
```只有一棵可能的树。 笛卡尔树有 1 个节点，组大小为 1，并且`Catalan(1)=1`。 

对于所有相等的值：```
4
3
3
3
3
```该算法构建了长度为四的右链。 它不会将四个独立答案相乘。 相反，它识别一个最小组并使用`Catalan(4)=14`。 

对于由较大元素分隔的值：```
3
1
2
1
```两个最小节点成为笛卡尔树中的一条等值链。 链长为二，给出`Catalan(2)=2`，而中间子树贡献一。 最终的答案是`2`。
