 # 问题理解

 我们有几个冰山，每个冰山都由其边界上的点的有序列表来描述。 这些点形成一个简单的多边形，这意味着边界永远不会跨越自身。 任务是找到所有多边形的总表面积并打印该面积的整数部分，这意味着向下舍入。 

输入大小是围绕几何数据总量较小这一事实而设计的。 多边形最多可以有 1000 个，每个多边形最多有 50 个顶点，因此顶点总数最多为 50000 个。这排除了重复比较每对顶点或扫描大坐标网格的算法。 基于网格的解决方案是不可能的，因为坐标可以大到 10^6，从而为单个方向创建 10^12 个单元格的区域。 预期的解决方案需要处理每个顶点恒定的次数。 

主要的边缘情况来自多边形区域的表示方式。 多边形可以顺时针或逆时针列出，两种描述都代表同一个物理冰山。 假设一个方向的粗心实施可能会产生否定的答案。 

例如：```
1
4
0 0
0 1
1 1
1 0
```正确的输出是：```
1
```这些点是按顺时针方向给出的，因此鞋带公式中的符号面积为负值。 获取该值而不应用绝对值会错误地产生负结果。 

另一种边缘情况是面积不是整数的多边形。```
1
3
0 0
1 0
0 1
```正确的输出是：```
0
```该三角形的面积为0.5，所需的操作是丢弃小数部分。 四舍五入到最接近的整数会给出不同的答案，因此实现必须保持精确的双倍面积。 

## 方法

 最直接的方法是尝试直接测量每个多边形的内部。 一种可能的方法是创建边界矩形内所有坐标的网格并测试每个单元格。 这是可行的，因为坐标定义了一个平面，但对于这个问题它立即失败。 在两个维度上跨越 0 到 10^6 的多边形需要检查大约 10^12 个单元格，这远远超出了允许的时间。 

更好的几何观察是多边形区域不依赖于其内部的单独形状。 边界点包含足够的信息。 通过将每个顶点连接到固定原点，可以将多边形划分为三角形。 使用叉积计算每个连续顶点对的有符号面积贡献：

 [
 x_i y_{i+1} - y_i x_{i+1}
 ]

 这些贡献的总和是多边形有符号面积的两倍。 该符号仅告诉我们顶点排序的方向，因此取绝对值会得到实际的双倍面积。 

蛮力方法之所以有效，是因为它直接对冰覆盖的区域进行建模，但忽略了边界中存储的少量信息。 多边形面积可以从边界点恢复的观察结果将问题从依赖于坐标大小减少到仅依赖于顶点数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(边界框面积) | O(边界框面积) | 太慢了|
 | 鞋带配方| O(顶点总数) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取每个多边形并按顺序存储其顶点。 顺序很重要，因为鞋带公式使用边界周围的成对相邻点。 
2. 对于从顶点开始的每条边`i`到顶点`i + 1`，添加叉积贡献`x_i * y_{i+1} - y_i * x_{i+1}`到多边形的双倍符号区域。 
3. 取多边形累计值的绝对值。 这消除了顶点是顺时针还是逆时针给出的影响。 
4. 将每个多边形的双倍面积添加到全局总数中。 冰山不重叠，因此可以简单地将它们的面积相加。 
5. 使用整数除法将最终加倍的区域除以二。 这给出了去除小数部分后所需的值。 

为什么它有效：

 鞋带公式是通过将连续多边形边和原点形成的三角形的有符号面积相加而得出的。 多边形内部的每个三角形只贡献一次，而由原点创建的外部区域则通过相反的符号抵消。 由于多边形很简单，因此结果正是多边形的有符号面积。 取绝对值给出实际面积，对加倍面积求和可以保持精确性，直到最终截断。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n_line = input().strip()
    if not n_line:
        return
    n = int(n_line)

    total_twice = 0

    for _ in range(n):
        p = int(input())
        points = []
        for _ in range(p):
            x, y = map(int, input().split())
            points.append((x, y))

        twice = 0
        for i in range(p):
            x1, y1 = points[i]
            x2, y2 = points[(i + 1) % p]
            twice += x1 * y2 - y1 * x2

        total_twice += abs(twice)

    print(total_twice // 2)

if __name__ == "__main__":
    solve()
```输入是逐个多边形处理的，因为每个冰山都是独立的。 顶点列表被临时存储，因为在计算最终边时最后一个顶点必须连接回第一个顶点。 

边缘循环使用`(i + 1) % p`处理多边形的闭合边。 如果没有模运算，从最后一个点回到第一个点的边缘将会丢失，这是错误答案的常见原因。 

计算是使用双倍面积而不是浮点数来执行的。 由于所有坐标都是整数，因此每个鞋带贡献也是整数。 保持该值准确可以避免精度错误，并使最终的向下取整运算只是整数除法。 

Python 整数会自动增长到超出固定的机器大小，这在这里很有用，因为总叉积可能约为 10^16。

 ## 边缘情况

 顺时针多边形产生与逆时针多边形相同的物理冰山，但鞋带总和改变了符号。 对于输入：```
1
4
0 0
0 1
1 1
1 0
```累计面积翻倍为`-2`。 该算法将其转换为`2`在将其添加到答案之前，产生正确的输出`1`。 

具有分数面积的多边形不得是圆角的。 为了：```
1
3
0 0
1 0
0 1
```加倍的面积是`1`，所以整数除法给出`1 // 2 = 0`。 该算法完全遵循所需的楼层行为。 

多边形的最后一条边是另一个微妙的情况。 为了：```
1
3
0 0
2 0
0 2
```最后一条边来自`(0,2)`回到`(0,0)`。 模运算包括该边缘，产生双倍面积`4`和输出`2`。 即使处理了所有列出的点，忽略该边缘也会产生错误的结果。
