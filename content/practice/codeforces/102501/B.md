 ## 解决方案
 ## 问题理解

 输入描述了花园中动物的普查。 第一行之后的每一行都包含一个物种的名称。 任务是确定一个物种的种群数量是否严格大于其他所有物种的种群数量总和。 如果存在这样的物种，我们会打印它的名字。 否则，我们打印`NONE`。 

可以使用计数重写条件。 如果一个物种出现`x`次之间`N`动物，所有其他物种一起出现`N - x`次。 我们需要一个物种`x > N - x`，这相当于`2x > N`。 这意味着答案必须是严格多数物种。 

的极限为`N`正在达到`2 * 10^5`意味着每只动物只能被加工几次。 将每个物种与其他物种进行比较的方法可能需要大约`N^2`如此规模的操作太多了。 我们需要一个线性或近线性的解决方案。 

有少数情况很容易处理不当。 如果最大的物种恰好占动物的一半，那是不够的，因为要求很严格。 例如：```
4
cat
dog
cat
dog
```正确的输出是：```
NONE
```粗心的解决方案检查`>=`而不是`>`会错误地选择`cat`或者`dog`。 

另一种边缘情况是只有一只动物时。 唯一的物种出现的次数比所有其他物种的总和还要多，因为另一侧的大小为零。```
1
lion
```正确的输出是：```
lion
```假设必须至少有两个不同物种的解决方案在这里可能会失败。 

最后一个微妙的情况是，存在多个物种，但其中一个物种勉强跨过门槛。```
5
bird
bird
bird
fish
frog
```正确的输出是：```
bird
```数量是三，而其他每个物种总共有两只动物。 在最大计数仍然不够的情况下，仅寻找最常见的物种而不检查多数条件的解决方案可能会产生错误的答案。 

## 方法

 一种直接的方法是对每个物种进行计数，然后分别测试每个物种。 建立计数后，我们可以对每个物种进行计数，并将其计数与所有其他计数的总和进行比较。 该方法是正确的，因为它检查了语句中的确切条件。 然而，如果通过扫描每个候选物种的所有物种来实施得不好，比较的数量可能会达到动物数量的平方。 和`N = 200000`，这可以接近四百亿次运算，这是不可行的。 

有用的观察结果是该条件仅取决于最大计数。 如果某个物种的动物数量比所有其他物种的总和还要多，那么该物种也一定是最常见的物种。 我们只需要知道哪个物种的频率最大，以及它的频率是否大于`N / 2`。 

这允许简单的两遍解决方案。 首先，计算每个物种出现的次数。 其次，寻找数量满足的物种`2 * count > N`。 字典可以有效地处理计数，并且总工作量与动物的数量成正比。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(N^2) | O(N^2) | O(N) | 太慢了 |
 | 最佳 | O(N) | O(N) | 已接受 |

 ## 算法演练

 1. 读取所有物种名称并使用哈希图计算它们的出现次数。 每只动物都为其物种计数器贡献一个增量，因此这一步捕获了完整的种群分布。 
2. 将动物总数存储为`N`。 具有频率的物种的多数条件`c`是`c > N - c`，这与`2 * c > N`。 
3. 迭代频率图并找到任何满足的物种`2 * count > N`。 由于两个不同的物种不可能同时拥有超过总种群的一半，因此找到一个有效的物种就足够了。 
4. 如果没有物种满足条件，则输出`NONE`。 

为什么有效：所需物种的数量必须大于其他所有物种的总和。 这意味着它的数量必须超过所有动物的一半。 在计算出正确的频率后，该算法会准确检查每个物种的这一属性。 任何有效的答案都会通过这个条件，而无效的物种则无法通过它，因为不平等恰恰是所需多数的定义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n_line = input().strip()
    if not n_line:
        return

    n = int(n_line)
    count = {}

    for _ in range(n):
        species = input().strip()
        count[species] = count.get(species, 0) + 1

    for species, freq in count.items():
        if freq * 2 > n:
            print(species)
            return

    print("NONE")

if __name__ == "__main__":
    solve()
```该字典存储每个物种的出现次数。 Python 字典提供平均恒定时间插入和查找，因此处理所有输入行保持线性。 

最终的循环不需要与其他物种进行比较。 表达式`freq * 2 > n`已经代表这个物种是否比所有剩余动物的总和还要大。 使用乘法代替除法以避免整数除法的任何边界问题。 

Python 中不存在整数溢出问题，因为整数在需要时会自动增长。 输入读数使用`sys.stdin.readline`，适合线路数较多的情况。 

## 工作示例

 对于第一个样本：```
3
frog
fish
frog
```计数过程为：

 | 阅读动物 | 当前计数 | 检查 |
 | ---| ---| ---|
 | 青蛙| 青蛙: 1 | 继续 |
 | 鱼 | 青蛙: 1, 鱼: 1 | 继续 |
 | 青蛙| 青蛙：2，鱼：1 | 继续 |

 最终计数为`frog = 2`和`fish = 1`。 自从`2 * 2 > 3`,`frog`是一个有效的答案。 

对于第二个样本：```
4
cat
mouse
mouse
cat
```计数过程为：

 | 阅读动物 | 当前计数 | 检查 |
 | ---| ---| ---|
 | 猫 | 猫：1 | 继续 |
 | 鼠标| 猫：1，老鼠：1 | 继续 |
 | 鼠标| 猫：1，老鼠：2 | 继续 |
 | 猫 | 猫：2，老鼠：2 | 继续 |

 两个物种都有频率`2`。 大多数测试给出`2 * 2 > 4`，这是错误的，所以答案是`NONE`。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(N) | 每个物种名称被读取一次，每个存储的频率被检查一次。 |
 | 空间| O(N) | 在最坏的情况下，每种动物都有不同的物种名称，因此字典会存储 N 个条目。 |

 最大输入大小为`200000`动物。 线性传递很容易满足可用时间限制，并且字典大小在内存限制内。 

## 测试用例```python
import sys
import io

def solution(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    data = sys.stdin.readline
    n = int(data())
    count = {}

    for _ in range(n):
        s = data().strip()
        count[s] = count.get(s, 0) + 1

    ans = "NONE"
    for s, c in count.items():
        if c * 2 > n:
            ans = s
            break

    sys.stdin = old_stdin
    return ans

assert solution("3\nfrog\nfish\nfrog\n") == "frog", "sample 1"
assert solution("4\ncat\nmouse\nmouse\ncat\n") == "NONE", "sample 2"

assert solution("1\nlion\n") == "lion", "single animal"
assert solution("5\na\na\na\nb\nc\n") == "a", "bare majority"
assert solution("6\nx\nx\ny\ny\nz\nz\n") == "NONE", "exact half"
assert solution("200000\n" + "bird\n" * 200000) == "bird", "maximum size all equal"
```| 测试输入| 预期产出 | 它验证了什么 |
 | ---| ---| ---|
 |`1`单一物种的动物|`lion`| 处理尽可能小的输入。 |
 | 五种动物中一个物种的三个副本 |`a`| 检查边界上方的严格多数。 |
 | 三个物种数量相等 |`NONE`| 检查精确的一半条件并防止`>=`错误。 |
 | 二十万个相同物种|`bird`| 确认线性方法可以处理最大输入大小。 |

 ## 边缘情况

 精确一半的情况由乘法检查处理。 为了：```
4
cat
dog
cat
dog
```字典包含`cat: 2`和`dog: 2`。 算法检查`2 * 2 > 4`，这对两者都是假的，所以它打印`NONE`。 

一种动物的情况是有效的，因为唯一的频率是`1`，条件变为`2 * 1 > 1`，这是事实。 该算法无需特殊处理即可打印唯一的物种。 

勉强多数的情况：```
5
bird
bird
bird
fish
frog
```产生`bird: 3`,`fish: 1`， 和`frog: 1`。 支票`2 * 3 > 5`成功了，所以`bird`被返回。 该算法不需要知道其他物种的确切总和，因为多数不等式已经捕获了它。
