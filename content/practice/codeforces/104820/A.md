 ## 解决方案
 ## 问题理解

 两个玩家从数轴开始：爱丽丝在位置$a$, Bob 处于位置$b$， 和$a < b$。 每一秒爱丽丝以固定的整数速度向右移动$c$，鲍勃以固定整数速度向右移动$d$。 鲍勃的速度$d$已知，但爱丽丝忘记了自己的速度$c$。 她记得的是，她的速度是经过选择的，以便在某个整数时间$t \ge 0$，两名球员占据完全相同的位置。 

任务不是重建单个有效速度，而是计算有多少个整数值$c$使这样的会议成为可能。 

会议的条件是存在一个整数$t \ge 0$这样$$a + ct = b + dt.$$重新排列给出$$(c - d)t = b - a.$$所以区别$b-a$必须能整除$c-d$，以及符号$c-d$确定爱丽丝是否可以追上或者她是否已经更快。 

约束条件允许$a, b, d$最多$10^{12}$，所以任何迭代所有可能的方法$c$立刻就不可能了。 甚至迭代到$b-a$当差距很大时就无法实现。 

一个微妙的边缘情况是爱丽丝已经比鲍勃慢了。 如果$c \le d$， 然后$c-d \le 0$，而爱丽丝只有在同一点开始时才能见到鲍勃，这是明确禁止的，因为$a < b$。 所以有效的解决方案必须满足$c > d$，将搜索空间减少到上面的正偏移量$d$。 

另一个重要的细节是会议时间$t$必须是整数。 这将问题转化为可分条件$b-a$，并且使任何仅考虑实值时间的推理无效。 

## 方法

 思考问题的一个直接方法是尝试所有可能的整数速度$c$并检查是否存在一个整数$t$满足方程$$a + ct = b + dt.$$对于固定的$c$，我们计算差异$b-a$并检查是否可以表示为$t(c-d)$对于某个整数$t \ge 0$。 这相当于检查是否$c-d$划分$b-a$。 然而，迭代所有$c$最多$10^{12}$太慢了，因为每次检查都是恒定时间，但范围很大。 

关键的观察结果是，问题仅取决于速度之间的差异，而不取决于它们的绝对值。 让$k = c - d$。 然后$k$必须是一个正整数，使得$k \mid (b-a)$。 一次$k$已修复，我们恢复$c = d + k$。 这将问题转化为计算正因数$b-a$。 

因此，我们不计算速度，而是计算单个数字的除数，最多是$10^{12}$。 计算除数可以在$O(\sqrt{n})$通过检查成对的因素。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解结束$c$|$O(b-a)$|$O(1)$| 太慢了|
 | 除数枚举 |$O(\sqrt{b-a})$|$O(1)$| 已接受 |

 ## 算法演练

 让$n = b - a$。 

1. 计算距离$n = b - a$。 这隔离了确定会议是否可能的唯一数量。 
2. 将应答计数器初始化为零。 这将计算有效的速度差异$k$。 
3. 迭代所有整数$i$从$1$到$\lfloor \sqrt{n} \rfloor$。 每个$i$被视为潜在除数候选者$n$。 
4. 如果$i$划分$n$， 然后$i$贡献有效值$k$，还有$n/i$贡献另一个值，除非它们相等。 原因是每个除数对应一个有效的速度差$k = c-d$，以及每一个这样的$k$准确定义一个有效的$c$。 
5. 仔细计算所有此类除数，确保当$i^2 = n$，除数只计算一次。 
6. 输出总计数。 

### 为什么它有效

 等式$a + ct = b + dt$减少到$(c-d)t = n$， 所以$c-d$必须是一个正因数$n$。 相反，每个正因数$k$的$n$通过选择产生有效的解决方案$t = n/k$和$c = d + k$，它始终是一个正整数。 这在有效速度之间建立了一一对应关系$c$和正因数$b-a$，所以计数有效$c$正好计算除数$b-a$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b, d = map(int, input().split())
    n = b - a

    ans = 0
    i = 1
    while i * i <= n:
        if n % i == 0:
            ans += 1
            if i * i != n:
                ans += 1
        i += 1

    print(ans)

if __name__ == "__main__":
    solve()
```代码首先将问题压缩到计算中$n = b-a$。 然后计算除数$n$使用标准平方根方法。 每个除数对应于一个有效的选择$c$， 因为$c = d + k$和$k$是以下任意约数$n$。 该循环仔细处理完全平方的情况以避免重复计算。 

一个微妙的实现点是$d$永远不会出现在除数计数逻辑中。 它只会改变最终值$c$，但不影响有效数量$k$存在。

 ## 边缘情况

 当$b-a = 1$，该算法仅检查$i = 1$，恰好找到一个除数，并返回 1。这对应于唯一可能的速度差异$k = 1$，这会产生有效的会议时间$t = 1$。 

什么时候$b-a$是一个完全平方数，例如$n = 36$，循环到达$i = 6$。 除数$6$应该只计算一次，并且条件`if i * i != n`通过避免重复计算来确保正确性。 

什么时候$n$是素数，仅$1$和$n$被计算在内。 该循环正确地识别了两个除数，准确地反映了两个有效的速度差，因此反映了两个有效值$c$。
