 ## 解决方案
 ## 问题理解

 我们有两种评分系统：一种使用从 1 到 n 的分数，另一种使用从 1 到 m 的分数。 第一个系统中的一些分数被认为等于第二个系统中的一些分数，但问题并没有给我们任意对。 相反，样本暗示的结构是，等效性的行为就像两个系统之间的统一缩放：对应于相同相对“质量水平”的值只要代表最大值的相同分数就会对齐。 

从这个角度来看，如果 m 尺度中的分数 x 对应于 n 尺度中的某个分数 y，如果两者都表示相同的归一化位置，则意味着 x / m = y / n。 当 x 是 m / gcd(n, m) 的倍数时，这样的对正好存在，因为两个尺度之间的共享分数网格由它们的最大公约数确定。 

该任务简化为计算有多少个 [1, m] 范围内的整数 x 实际出现在这个共享网格中。 

对于 n 和 m，约束都达到 10^18，因此任何迭代值或构造数组的解决方案都是不可能的。 即使 O(min(n, m)) 也太大了。 解决方案必须将问题减少到对大整数进行恒定数量的算术运算。 

当 n 和 m 互质时，会出现微妙的边缘情况。 那么唯一共享的归一化点是分数形式的端点 0 和 1，它仅对应于 m 尺度中的值 m 本身。 例如，当 n = 3 且 m = 4 时，只有一个值匹配。 

另一种边缘情况是当 n = m 时。 在这种情况下，每个分数都与自身匹配，因此答案是 m。 仅计算“正确映射的内部点”的天真的解释会错误地错过端点。 

## 方法

 如果我们尝试直接模拟等价，我们需要检查 [1, m] 中的每个 x 是否存在 [1, n] 中的 y，使得 x / m = y / n。 检查这种情况需要合理减少或扫描所有候选者。 即使单次传递 m 到 10^18 也是不可能的。 

关键的观察结果是，分数 x / m 和 y / n 相等意味着交叉乘法：x * n = y * m。 任何有效对都对应于两个网格上的共享有理点。 所有这些点的集合正是由n和m的最小公倍数结构生成的格子。 

连续匹配 x 值之间的间距为 m / gcd(n, m)。 这是通过将等式重写为 x = k * (m / gcd(n, m)) 来实现的，其中 k 的范围涵盖所有整数，使得相应的 y 保持在 [1, n] 范围内。 由于 k 的范围可以从 1 到 gcd(n, m)，因此 x 恰好有 gcd(n, m) 个有效值。 

因此，问题简化为计算 gcd(n, m)，它直接计算 m 尺度中存在多少个等当点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | [1, m] | 中 x 的暴力枚举 O(米) | O(1) | O(1) | 太慢了|
 | 最优使用gcd结构| O(log min(n, m)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取两个整数n和m。 这些定义了我们通过比例对齐进行比较的两个离散尺度。 
2. 计算 g = gcd(n, m)。 这捕获了保持两个尺度之间比例相等的最大步长。 
3. 认识到 m 尺度中的每个有效匹配分数必须采用 k * (m / g) 的形式，其中 k 是从 1 到 g 的整数。 
4. 得出有效分数的个数正好是g。 

此枚举起作用的原因是，将 n 和 m 除以它们的 gcd 将分数 n/m 减少到最低项。 两个序列之间的对齐点恰好出现在这个减少的步长的倍数处。 

### 为什么它有效

任何有效的对应关系都满足 x / m = y / n。 重新排列得到 x * n = y * m。 设 g = gcd(n, m)，并写出 n = g * n' 和 m = g * m'，其中 n' 和 m' 互质。 方程变为 x * n' = y * m'。 由于 n' 和 m' 没有公因数，因此 x 必须能被 m' 整除，y 必须能被 n' 整除。 对于某个整数 k，这会强制 x = k * m' 和 y = k * n'。 约束 1 ≤ x ≤ m 和 1 ≤ y ≤ n 意味着 k 的范围恰好从 1 到 g，产生 g 个有效值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from math import gcd

n, m = map(int, input().split())
print(gcd(n, m))
```整个解决方案依赖于计算最大公约数。 数学模块实现使用高效的欧几里德算法，适用于最大 10^18 的值。 

唯一的微妙之处是不需要额外的标准化或边界处理。 两个端点都被隐式包括在内，因为 gcd 计数已经考虑了完整的对齐点，包括对应于 n 时的最大分数 m。 

## 工作示例

 ### 示例 1：n = 5，m = 10

 我们计算 g = gcd(5, 10) = 5。 

| 步骤| 价值|
 | --- | --- |
 | n | 5 |
 | 米 | 10 | 10
 | gcd(n, m) | gcd(n, m) | 5 |
 | 答案| 5 |

 五个匹配点对应于分数 1/5、2/5、3/5、4/5 和 5/5，它们映射到 10 尺度中的 2、4、6、8 和 10。 这证实了所有均匀间隔的比例水平都被计算在内。 

### 示例 2：n = 3，m = 4

 我们计算 g = gcd(3, 4) = 1。 

| 步骤| 价值|
 | --- | --- |
 | n | 3 |
 | 米 | 4 |
 | gcd(n, m) | gcd(n, m) | 1 |
 | 答案| 1 |

 只有端点 4 对应于有效的共享分数 (1)，因此 m 尺度中仅存在一个分数。

import sys, io
from math import gcd

def solve():

    old_stdin = sys.stdin

    solve()

    sys.stdin = old_stdin

 ## 边缘情况

 当n = m时，gcd等于n，所以答案为n。 例如，输入 7 7 生成 gcd(7, 7) = 7，这意味着 m 尺度中的所有七个分数直接对应于 n 尺度中的相同位置。 

当 n 和 m 互质时，例如 7 和 13，gcd 为 1。算法返回 1，反映只有端点在归一化空间中对齐。 该计算不需要任何特殊处理，因为欧几里得算法自然地将对简化为这种情况。 

当一个值非常大而另一个值非常小时（例如 10 和 10^18），gcd 仍然捕获完整结构。 欧几里得算法快速减少 10^18 模 10，留下 gcd 10。
