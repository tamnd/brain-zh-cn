 ## 解决方案
 ## 问题理解

 我们有一个代表山表面的矩形网格。 每个单元格包含一个整数值，可以是正数或负数。 路径代表在此网格上的行走：您从第一行中的任何单元格开始，使用四个基本方向在相邻单元格之间移动，并且永远不允许您向上移动。 您也不能多次访问同一个牢房。 当你从底行走出网格时，路径结束，路径的值是所有访问过的单元格的总和。 

任务是计算这些移动规则下的最大可能路径总和。 

网格大小达到 1500 x 1500，这意味着大约有 225 万个单元。 任何试图明确探索所有路径的解决方案都是不可能的，因为即使是这样一个网格上的一个小的分支因子也会导致指数行为。 这迫使我们采用动态编程解决方案，对每个单元进行少量恒定次数的处理，理想情况下为 O(nm)。 

一个微妙的困难是水平移动和“禁止重访”约束的结合。 即使向上运动被禁止，水平运动仍然会在底层图表中产生潜在的循环。 简单的最短或最长路径松弛将会被破坏，因为标准图算法假设非循环性或允许以受控方式重新访问。 在这里，正确性取决于确保在每一行中，我们只考虑简单的路径，但仍然有效地传播最佳可实现的总和。 

经常打破简单方法的一种边缘情况是，最佳路径在下降之前需要在一行内进行较长的水平绕行。 例如，考虑像这样的行`[1, -100, 1]`随后是一行`[100, 100, 100]`。 最好的策略是在下降之前小心地穿过顶行，但是天真的“总是立即下降”的贪婪方法将完全错过最佳结构。 

如果假设每个单元都可以从左到右独立处理，就会出现另一个问题。 水平移动会产生跨行的依赖性，因此单次从左到右的传递是不够的。 

## 方法

 强力解释会将每个单元视为图中的一个节点，其四个邻居都有边，但不允许向上的边。 然后，我们将尝试计算从任何顶行节点到任何底部出口节点的最大路径总和，而无需重新访问节点。 这本质上是一般图中的最长简单路径问题，计算起来很困难。 即使没有重新访问，行内的分支结构也允许指数数量的路径，并且在最坏的情况下直接探索它们将需要 O(4^(nm)) 的量级。 

关键的结构观察是，尽管水平移动在底层图中引入了循环，但“无向上移动”约束会导致行的强大层结构。 所有运动要么在一行内，要么严格向下。 这建议逐行处理网格，其中单元格的状态仅取决于上面的行以及同一行内的水平传播。 

这将问题变成了一个动态规划系统，一旦我们知道从上面输入的最佳值，就可以独立解决每一行。 剩下的挑战是，在一行中，我们必须考虑任意水平行走，而无需重新访问单元格。 这可以通过模拟行内路径值的最佳传播的两个方向扫描来处理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力路径| 指数| O(纳米) | 太慢了|
 | 具有水平松弛的行式 DP | O(纳米) | O(米) | 已接受 |

 ## 算法演练

 我们逐行处理网格，将每个单元格的最佳可实现总和作为来自上方或之前水平移动的输入值。 

### 步骤

 1. 初始化第一行的 DP 数组，其中每个条目只是该单元格的值。 这反映出我们可以从任何顶部单元开始。 
2. 对于每个后续行，首先通过将其网格值添加到直接上方单元格的最佳值来计算每个单元格的临时 DP 值。 这捕获了所有垂直到达的路径。 
3. 对行执行从左到右的扫描。 对于每个单元格，通过考虑从同一行内的左邻居移动并添加当前单元格值来更新其最佳值。 这模拟了向右水平延伸路径。 
4. 使用相同的逻辑执行从右到左的扫描，允许从右侧传播。 这确保了需要在行内转弯的路径被正确捕获。 
5. 两次扫描后，该行的 DP 值表示在所有有效的行内移动之后在每个单元格结束的最佳可能总和。 
6. 对所有行重复此过程，始终覆盖 DP 数组。 
7. 最终答案是最后一行 DP 数组中的最大值，因为我们可以从任何底部单元格退出网格而无需额外成本。 

### 为什么它有效

 关键的不变量是，在处理第 r 行之后，每个像元处的 DP 值表示以该像元结束的任何有效路径的最大总和，并遵守第 1 行到第 r 行中的所有移动规则。 水平扫描正确解析了所有行内简单路径，因为任何最佳水平移动都可以分解为一系列单调扩展，这些扩展由从左到右和从右到左的松弛捕获。 由于行之间的移动严格向下，因此未来的行无法改善过去的行状态，从而保留最佳子结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]
    
    dp = grid[0][:]

    for r in range(1, n):
        new_dp = [0] * m
        
        for c in range(m):
            new_dp[c] = dp[c] + grid[r][c]

        for c in range(1, m):
            new_dp[c] = max(new_dp[c], new_dp[c-1] + grid[r][c])

        for c in range(m-2, -1, -1):
            new_dp[c] = max(new_dp[c], new_dp[c+1] + grid[r][c])

        dp = new_dp

    print(max(dp))

if __name__ == "__main__":
    solve()
```该实现一次仅保留一个 DP 行，因为较早的行在处理后无需重新访问。 

第一个初始化步骤直接编码在顶行任意位置开始的自由度。 垂直过渡只是添加当前单元格值，因为从上方进入单元格是唯一允许的向下行间移动。 

两个水平通道是关键部分。 从左到右的传递假设我们可以将结束于前一个单元格的最佳路径延伸到当前单元格。 从右到左的传递反映了这一点，确保对称性，以便在向右移动后需要向左移动的路径也被覆盖。 如果没有两次通过，就会错过一行中的一些最佳之字形路径。

 ## 边缘情况

 大小为 1 x 1 的最小网格可以正确处理，因为初始化直接将 DP 设置为单元值，并且不会发生任何转换。 

单行情况可确保算法正确模拟不受限制的水平移动，而无需任何垂直过渡。 两次扫描将最佳段和完全传播到行中。 

单列将问题简化为从上到下的简单路径。 DP 递归变成累积和，并且水平扫描没有效果，因为没有水平邻居，这证实了该算法不会引入虚假转换。
