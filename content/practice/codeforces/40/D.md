 ## 解决方案
 ## 问题理解

 该序列以两个固定值开始：$$d_1 = 2,\quad d_2 = 13$$之后的每一年，种群都满足以下两个递归规则之一：$$d_i = 12d_{i-2}$$或者$$d_i = 13d_{i-1} - 12d_{i-2}$$我们给定一个巨大的整数$A$，最多 300 位十进制数字，并且必须确定某些有效序列是否可以包含$A$在某个位置。 

这项任务比检查某一特定序列中的成员资格更为微妙。 不同年份的不同复发选择创造了许多可能的序列。 如果$A$可能出现的情况下，我们必须尽可能报告每年的指数。 然后，在这些年里，我们必须列出也可能出现在这些相同位置的所有其他人口值。 

数字大小完全改变了问题的性质。 300 位整数无法适应固定宽度类型，但 Python 整数可以自然地处理这个问题。 真正的挑战不是算术溢出，而是理解所有可达值的结构。 

暴力生成序列是没有希望的。 每个位置都有两种可能性，所以之后$n$年已经有$2^{n-2}$序列。 即使是为了$n=100$，这是一个天文数字。 

隐藏的结构是，两次递推都是线性的，并且第二次递推具有非常特殊的形式。 利用该结构将指数状态空间压缩成极小的东西。 

一些边缘情况很容易被错误处理。 

假设输入是：```
2
```答案是肯定的，因为$d_1=2$。 从第二年开始处理的粗心实现会错误地拒绝它。 

另一个危险的情况是：```
13
```这对应于第 2 年。同样，需要特殊处理，因为重复仅从第 3 年开始。 

一个更有趣的案例是：```
24
```我们可以得到：$$d_3 = 12d_1 = 24$$但不是从第二次复发开始，因为：$$13\cdot13 - 12\cdot2 = 145$$假设每年只有一个可能值的实现在这里会失败。 

最困难的概念边缘情况是许多不同的序列在相同位置崩溃为相同值。 我们不计算序列。 我们正在收集独特的可实现的价值观。 

## 方法

 直接的暴力方法将递归地生成每个有效的序列前缀。 

开始于$(2,13)$，对于每对$(d_{i-2}, d_{i-1})$，我们分支为：$$d_i = 12d_{i-2}$$和$$d_i = 13d_{i-1} - 12d_{i-2}$$这是正确的，因为它完全遵循定义。 问题在于分支因素。 按年份$n$， 有$2^{n-2}$可能的路径。 一旦值超过甚至停止$A$没有多大帮助，因为数字可能会不规律地增长。 

关键的观察结果是，每个生成的值实际上是 12 的幂乘以 2 或 13。 

让我们仔细检查这两个转变。 

如果我们申请：$$d_i = 12d_{i-2}$$那么我们只需将前面的一项乘以 12 即可。 

对于第二次重复：$$d_i = 13d_{i-1} - 12d_{i-2}$$假设前两项是：$$d_{i-2}=2\cdot12^a,\quad d_{i-1}=13\cdot12^a$$然后：$$d_i =13(13\cdot12^a)-12(2\cdot12^a) =(169-24)12^a =145\cdot12^a =13\cdot12^{a+1}$$相同的配对结构会自我复制。 

这揭示了完整的行为：

 每年，可达到的值是：$$2\cdot12^k$$或者$$13\cdot12^k$$指数由奇偶校验确定。 

整个状态空间崩溃成两条确定性链。 

问题变成了纯算术。 我们反复划分$A$到 12 并检查我们最终是达到 2 还是 13。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n)$|$O(2^n)$| 太慢了 |
 | 最佳 |$O(\log_{12} A)$|$O(1)$| 已接受 |

 ## 算法演练

 1.读取整数$A$作为一个大整数。 
2. 立即处理两个基值。 

如果$A=2$，则第 1 年有效。 

如果$A=13$，则第 2 年有效。 
3、反复划分$A$可以被 12 整除，但可以被 12 整除。 

每一次划分都对应着通过递归结构向后退一步。 
4. 计算我们除以 12 的次数。 

设这个数为$k$。 然后：$$A = B\cdot12^k$$在哪里$B$不能被12整除。 
5.检查剩余基值$B$。 

如果$B=2$，则该值出现在年份：$$2k+1$$因为从2开始的链占据奇数位置。 

如果$B=13$，则该值出现在年份：$$2k+2$$因为从 13 开始的链占据偶数位置。 
6. 如果两个条件都不成立，则打印 NO。 
7. 否则打印 YES，然后打印有效年份。 
8. 计算同一年可能出现的所有其他值。 

在奇数年，唯一可达到的值是：$$2\cdot12^k$$在偶数年，唯一可达到的值是：$$13\cdot12^k$$由于查询的值已经占用了该槽，因此没有其他选择。 
9. 打印零个替代值。 

### 为什么它有效

 递归保留了非常严格的结构。 开始于$(2,13)$，每个可达的相邻对的形式为：$$(2\cdot12^k,\ 13\cdot12^k)$$对于某个整数$k\ge0$。 

第一次递归变换：$$2\cdot12^k \rightarrow 2\cdot12^{k+1}$$第二个变换：$$(2\cdot12^k,\ 13\cdot12^k) \rightarrow 13\cdot12^{k+1}$$这两种操作都不能创建任何其他素因数或系数。 通过归纳，每个可达值都必须恰好是这两种形式之一。 

相反，每个这样的值都可以通过重复应用适当的递归来达到。 表征是完整的，因此算法不会错过任何有效答案或接受无效答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    A = int(input().strip())

    x = A
    k = 0

    while x % 12 == 0:
        x //= 12
        k += 1

    if x == 2:
        print("YES")
        print(1)
        print(2 * k + 1)
        print(0)
    elif x == 13:
        print("YES")
        print(1)
        print(2 * k + 2)
        print(0)
    else:
        print("NO")

solve()
```该实现直接反映了数学特征。 

该循环从输入数字中去除 12 的所有因数。 循环结束后，剩余值确定序列是源自从 2 开始的奇数位置链还是从 13 开始的偶数位置链。 

变量`k`计算除以 12 的次数。每次除法对应于序列中前进两年，因为乘以 12 会保留奇偶校验类别。 

公式：$$2k+1$$和$$2k+2$$直接来自可达值的交替结构。 

一个微妙的问题是，答案总是包含一个有效的年份。 不同的重复选择永远不会在同一奇偶校验级别创建多个不同的值。 整个过程在减少12次方后是确定性的。 

Python 大整数足以满足 300 位数字的限制，因此不需要自定义算术。

 ## 边缘情况

 考虑输入：```
2
```该算法永远不会进入除法循环，因为 2 不能被 12 整除。减少后的值仍为 2$k=0$。 计算出的年份为：$$2\cdot0+1=1$$输出是正确的。 

现在考虑：```
13
```再次没有分裂发生。 减少后的值为 13，因此算法识别偶数位置链并计算：$$2\cdot0+2=2$$这正确映射到第 2 年。 

一个更微妙的情况是：```
288
```执行轨迹：

 | x| k |
 | --- | --- |
 | 288 | 288 0 |
 | 24 | 1 |
 | 2 | 2 |

 减少后的值变为 2，得出：$$2\cdot2+1=5$$的确：$$d_5 = 2\cdot12^2 = 288$$最后考虑一个无效值：```
144
```执行轨迹：

 | x| k |
 | --- | --- |
 | 144 | 144 0 |
 | 12 | 12 1 |
 | 1 | 2 |

 减少后的值为 1，既不是 2 也不是 13。算法打印 NO。 

这会捕获 12 的纯幂且没有所需系数的数字。
