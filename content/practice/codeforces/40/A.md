 ## 问题理解

 该平面使用以原点为中心的同心环进行着色。 两个连续整数距离之间的每个环都会交替颜色。 边界本身，即距原点距离为整数的所有点，始终为黑色。 

为了一点`(x, y)`，我们需要确定该点是位于黑色边界上还是位于白色区域内。 随着距离从原点向外延伸，图案会交替变化。

 如果`d`是一个整数，答案是立即`"black"`因为该点恰好位于圆边界上。 

否则，颜色取决于该点属于哪个环。 半径之间的区域`0`和`1`是黑色的，之间`1`和`2`是白色的，之间`2`和`3`又变黑了，等等。 换句话说，距离的整数部分决定了颜色奇偶性。 

坐标范围很小，最多只能达到`1000`以绝对值表示。 即使是低效的解决方案也能快速运行。 不过，问题主要在于正确解释几何形状和处理浮点陷阱。 

棘手的部分是检测距离是否恰好是整数。 使用浮点比较的粗心实现可能会失败，因为像这样的值`sqrt(25)`可能会在内部变成`4.99999999997`或者`5.00000000001`。 

考虑一下这一点：```
3 4
```距离正好是`5`，所以答案一定是`"black"`。 浮点比较如`sqrt(x*x+y*y) == int(sqrt(...))`是不安全的。 

另一个微妙的情况是起源：```
0 0
```其距离为`0`，它是一个整数，所以该点是黑色的。 某些实现意外地使用奇偶校验逻辑对其进行分类并产生错误的结果。 

另一个容易错过的情况是边界内的点：```
2 2
```距离约为`2.828`，位于`2`和`3`。 由于间隔`[2,3)`对应黑色区域，答案是`"black"`。 使用舍入而不是地板会错误地将其移动到下一个环中。 

## 方法

 思考这个问题的一种强力方法是想象所有具有整数半径的同心圆。 我们可以反复增加半径，直到找到该点之外的第一个圆。 一旦我们知道了环索引，我们就可以通过奇偶校验来确定颜色。 

这是有效的，因为颜色仅在穿过整数半径圆时才会改变。 由于坐标最多为`1000`，最大可能距离大致为`1414`，所以即使扫描所有半径也只需要大约`1400`迭代。 

尽管如此，几何形状还是提供了一条直接的捷径。 我们真正需要的唯一信息是：

 1. 距离是否为整数。 
2. 否则，奇偶校验`floor(distance)`。 

观察结果来自于颜色如何逐环交替。 每个环`[k, k+1)`具有完全由以下因素决定的固定颜色`k`。 

我们可以计算：$r^2 = x^2 + y^2⟦PROTECT_11⟧k⟦PROTECT_12⟧(x)^2 + (y)^2 = 3.0^2$滑块更新圆方程的中心和半径。-10-8-6-4-2246810-6-4-2246

 如果`r²`是一个完全正方形，点是黑色的。 

否则，让：$k = \lfloor \sqrt{x^2+y^2} \rfloor$什么时候`k`是均匀的，该区域是黑色的。 什么时候`k`是奇数，该区域是白色的。 

这消除了所有迭代，并通过尽可能使用整数运算来避免浮点精度问题。

 ## 算法演练

 1.读取坐标`x`和`y`。 
2. 计算距原点的平方距离：$s = x^2 + y^2$使用平方距离可以避免不必要的浮点运算。 
3. 计算整数平方根`s`。 

让`r = isqrt(s)`。 

这给出了最大的整数，使得`r² ≤ s`。 
4. 检查是否`r * r == s`。 

如果为真，则该点恰好位于整数半径的圆上，因此打印`"black"`。 
5. 否则，使用以下方法确定环索引`r`。 

自从`r = floor(distance)`，该点属于环面`[r, r+1)`。 
6.如果`r`是偶数，打印`"black"`。 

如果`r`为奇数，打印`"white"`。 

颜色从中心开始交替，其中半径间隔`[0,1)`是黑色的。 

### 为什么它有效

 每个整数半径圆充当两个区域之间的边界。 间隔`[0,1)`是黑色的，`[1,2)`是白色的，`[2,3)`再次变成黑色，并且这种交替会永远持续下去。 

对于不在边界上的任何点，其颜色仅取决于其距原点距离的整数部分。 价值`floor(distance)`唯一标识包含该点的环面。 偶数索引对应于黑色区域，奇数索引对应于白色区域。 

检查平方距离是否是完全平方数可以正确检测边界点，而不会出现浮点错误。 

## Python 解决方案```python
import sys
from math import isqrt

input = sys.stdin.readline

x, y = map(int, input().split())

s = x * x + y * y
r = isqrt(s)

if r * r == s:
    print("black")
else:
    if r % 2 == 0:
        print("black")
    else:
        print("white")
```该程序首先计算平方距离而不是实际距离。 这更安全，因为整数运算是精确的。 

功能`isqrt`使用纯整数运算返回平方根的下限。 这避免了可能出现的精度问题`sqrt`。 

条件`r * r == s`检查距离是否为精确整数。 这些点始终是黑色的，因为每个边界圆都是黑色的。 

如果该点不在边界上，则奇偶校验为`r`决定戒指颜色。 中心区域从黑色开始，因此偶数环为黑色，奇数环为白色。 

一个常见的错误是使用`round(sqrt(...))`而不是`floor`。 环是由间隔定义的，因此地板是正确的操作。

import sys, io
from math import isqrt

def solve():
    input = sys.stdin.readline

    x, y = map(int, input().split())

    s = x * x + y * y
    r = isqrt(s)

    if r * r == s:

    sys.stdout = backup_stdout
