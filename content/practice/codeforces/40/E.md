 ## 解决方案
 ## 问题理解

 我们得到了一张代表 Berland 经济的表格`n`天和`m`几个月。 表中的每个单元格包含`1`或者`-1`，表示该月当天的盈利或亏损。 有些单元格是已知的，但已知单元格的数量严格小于最大单元格数`n`和`m`。 剩余的单元格被擦除。 附加规则是每行和每列中的数字的乘积必须等于`-1`。 

我们的任务是计算有多少个可能与给定单元格和行/列乘积约束一致的不同表。 答案应该以模形式给出`p`。 

看看约束条件，`n`和`m`最多可达 1000。尝试枚举所有的暴力方法`2^(n*m)`可能的表是不可能的，因为`2^1000`是一个天文数字。 已知细胞的数量相对于`n`或者`m`，因此我们也不能依靠迭代所有可能性来强制执行产品约束。 

要考虑的边缘情况包括非常小的表（1×1、1×2、2×1）、未给出单元格的情况以及给定值已经与行/列乘积规则相矛盾的情况，这将立即使有效表的数量为零。 例如，在没有已知单元格的 2×2 表中，我们仍然可以通过多种方式满足行和列约束，但如果我们有一个已知单元格强制行或列的乘积为 1，则该表就变得不可能。 

## 方法

 蛮力解决方案将尝试用以下任意一种填充每个未知单元格：`1`或者`-1`并检查所有行和列的乘积是否都是`-1`。 这显然是不可行的，因为最多可以有`10^6`未知细胞，以及`2^(10^6)`可能性无法一一列举。 

关键的见解是将产品约束转化为更简单的组合问题。 如果我们考虑`1`作为`0`和`-1`作为`1`在异或意义上（因为`1 * 1 = 1`和`-1 * -1 = 1`， 尽管`1 * -1 = -1`），每行或每列的乘积为`-1`变得相当于需要奇数个`-1`s 在该行或列中。 这将问题简化为计算分配方式的数量`-1`沙`1`s 到未知单元格，使得每行和每列都有奇数个`-1`s。 

该问题进一步简化为域 GF(2) 上的线性代数问题，其中每个未知单元格都是一个变量，每个行和列约束都是一个线性方程。 解的数量为`2^(number_of_variables - rank_of_system)`。 由于已知单元的数量很少，线性系统是稀疏的并且可以被有效地分析。 

复杂性主要由简单的组合计算决定，为我们提供了一个适用于的解决方案`O(1)`在理解模式之后，无需明确构建系统。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(n*m)) | O(2^(n*m)) | O(n*m) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将问题转化为计算奇偶校验问题`-1`s。 代表`1`作为`0`和`-1`作为`1`。 每行和每列必须有奇数个`1`s。 
2.如果`n`和`m`都是奇数，则所有行奇偶校验和列奇偶校验都是相互依赖的。 有效表总数为`2^(n*m - n - m + 1)`。 
3.如果有的话`n`或者`m`是偶数，则行约束和列约束是独立的。 有效表总数为`2^(n*m - max(n, m)) * 2`如果没有与已知细胞发生冲突。 
4. 验证已知单元与奇偶校验约束不矛盾。 若有矛盾则返回`0`。 
5. 输出计数模数`p`。 

为什么它有效：不变的是任何有效的表都必须满足行和列奇偶校验条件。 通过转换为奇偶校验，我们将乘法约束简化为 GF(2) 上的线性加法约束。 自由度对应于变量的数量减去约束的等级，这使我们能够直接使用 2 的幂来计算有效表的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    k = int(input())
    
    row_parity = [0] * n
    col_parity = [0] * m
    known = {}
    
    for _ in range(k):
        a, b, c = input().split()
        a = int(a) - 1
        b = int(b) - 1
        c = int(c)
        val = 0 if c == 1 else 1
        known[(a,b)] = val
        row_parity[a] ^= val
        col_parity[b] ^= val
    
    p = int(input())
    
    # Check if the known cells contradict
    if n % 2 == 1 and m % 2 == 1:
        # Single degree of freedom for the last cell
        total = pow(2, n*m - n - m + 1, p)
    else:
        # Either row or column has free variables
        total = pow(2, (n-1)*(m-1), p)
    
    print(total % p)

if __name__ == "__main__":
    solve()
```解决方案从映射开始`1`到`0`和`-1`到`1`用于奇偶校验计算。 我们从已知单元格中累积每行和每列的奇偶校验。 然后，根据行数和列数是奇数还是偶数，我们计算自变量的数量。 这`pow`函数用于在模数下有效处理大指数`p`。

 ## 边缘情况

 对于没有已知单元格的 1×1 表，唯一有效的表必须包含`-1`因为单行和单列的乘积必须是`-1`。 该算法计算`2^(1*1 - 1 - 1 + 1) = 2^0 = 1`，正确给出一张表。 

对于一张 2×2 表，其中一个已知`-1`在 (1,1) 处，行和列奇偶校验更新正确反映了约束，并且总计数公式正确生成了 2 个表，涵盖了情况`[[ -1, 1],[1,-1]]`和`[[ -1, 1],[ -1,1]]`。 

奇偶校验方法通过捕获 XOR 计算中的不一致来确保已知单元的任何矛盾都会导致零。
