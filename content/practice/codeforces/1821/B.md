 ## 解决方案
 ## 问题理解

 我们有两个整数数组，原始数组`a`和修改后的数组`a'`。 修改包括选择一个连续的子数组`a`并按非降序排序以产生`a'`。 我们的任务是确定该子数组的边界，`l`和`r`，使用基于一的索引。 如果多个子数组可以导致`a'`，我们选择长度最长的一个，如果仍然存在平局，则任何有效答案都足够。 

该问题保证了`a'`不同于`a`并且恰好有一个子数组已排序。 每个测试用例最多可以有`2 * 10^5`元素，以及总和`n`所有测试用例不超过`2 * 10^5`。 这意味着我们需要一个在每个测试用例中运行大致线性时间的解决方案，因为二次解决方案可以达到`10^10`最坏情况下的操作，对于 2 秒的限制来说太大了。 

需要注意的边缘情况包括以下情况：`a`和`a'`发生在数组的开头或末尾，或者当要排序的子数组包含重复值时。 例如，如果`a = [1, 2, 1]`和`a' = [1, 1, 2]`，算法必须正确识别跨越第一个到第三个元素的子数组。 在这些情况下，仅查看第一个或最后一个不匹配而不扫描整个数组的简单方法可能会返回错误的边界。 

## 方法

 暴力方法会尝试尝试每一对`(l, r)`并检查是否对该子数组进行排序`a`产量`a'`。 这显然是正确的，但太慢了。 大致有`n*(n+1)/2`可能的子数组，对于每个子数组，我们都会执行排序和比较。 对每个候选子数组进行排序需要`O(k log k)`在哪里`k`是子数组长度。 在最坏的情况下，这会导致超过`O(n^3)`操作，这是不可行的`n`最多`2 * 10^5`。 

关键的观察结果是，排序后的子数组完全对应于其中的位置`a`和`a'`不同。 如果我们从左边遍历，第一个索引在哪里`a[i] != a'[i]`标志着开始`l`的子数组。 同样，从右边扫描，最后一个索引在哪里`a[i] != a'[i]`标志着结束`r`。 对子数组进行排序`l`到`r`在`a`将准确产生`a'`，因为该问题保证只有一个子数组已排序。 这将复杂性降低到单个线性遍历来查找`l`和`r`，然后是验证或可选的排序步骤。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化`l = 0`和`r = n - 1`。 
2.遍历数组`a`从左边。 第一个索引`i`在哪里`a[i] != a'[i]`变成`l`。 这捕获排序操作更改值的最早位置。 
3.遍历数组`a`从右边。 第一个索引`i`（从最后开始）哪里`a[i] != a'[i]`变成`r`。 这捕获了受排序影响的最新位置。 
4. 由于输出中数组的索引为 1，因此两者都加 1`l`和`r`。 
5. 返回`(l + 1, r + 1)`作为答案。 

为什么它有效：排序仅影响连续块，其中`a`不同于`a'`。 根据定义，该块之外的元素不会发生变化。 识别第一个和最后一个不同的位置可以保证我们捕获必须已排序的整个子数组。 超出这些索引将包括未更改的元素，从而违反了问题约束。 此方法始终生成最长的子数组，因为任何较小的子数组都不会匹配`a'`完全。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a_prime = list(map(int, input().split()))

        l = 0
        while l < n and a[l] == a_prime[l]:
            l += 1

        r = n - 1
        while r >= 0 and a[r] == a_prime[r]:
            r -= 1

        # convert to 1-based indexing
        print(l + 1, r + 1)

if __name__ == "__main__":
    solve()
```解决方案首先读取测试用例的数量。 对于每个测试用例，它读取`n`,`a`， 和`a'`。 左边界`l`通过从头开始扫描直到发现不匹配来识别，而正确的边界`r`从末尾扫描即可找到。 这`while`循环保证我们在精确的边界处停止。 转换为基于 1 的索引是必要的，因为 Python 数组是 0 索引的，而问题需要 1 索引的输出。

 | 测量| 复杂性 | 说明|
