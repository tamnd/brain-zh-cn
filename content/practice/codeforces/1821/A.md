 ## 解决方案
 ## 问题理解

 我们得到一个由数字和问号组成的字符串。 每个问号代表一个未知的数字，我们想要计算所有可以通过用数字替换问号形成的正整数，这样得到的数字没有前导零。 输入由多个这样的字符串组成，每个字符串代表一个单独的测试用例，对于每个字符串，我们必须输出匹配正整数的总数。 

关键限制是字符串长度最多为 5 个字符，这意味着完整问号字符串的可能性总数最多为$10^5 = 100,000$。 这足够小，即使是简单的基于乘法的组合方法也能在时间限制内轻松运行。 

不明显的边缘情况来自前导零和个位数字符串。 例如，模板`0`无法匹配任何正整数，因为零不是正数。 像这样的模板`?5`是有效的，但是`05`不是，因为禁止使用前导零。 另一个微妙之处是单字符问号，例如`?`，可以匹配数字`1`通过`9`，给出 9 个有效数字，而不是 10。 

## 方法

 强力方法是生成所有可能的问号替换，将每个候选字符串转换为整数，然后计算其中有多少个整数是正数且没有前导零。 这是有效的，因为最大长度为 5，在最坏的情况下最多给出 100,000 个候选`?????`。 对于单个模板，我们可以循环遍历所有替换并检查，但这需要嵌套循环或递归，这很麻烦。 

使最佳方法变得微不足道的关键观察是每个模板的有效整数的数量可以通过简单的组合直接计算。 每个问号代表 10 种可能性，但第一个字符如果是问号则不能为零。 因此，我们可以将每个位置的可能性数相乘：对于第一个字符，如果是问号，则有 9 个选项（`1-9`），否则只有1。剩下的位置，问号代表10个选项，数字固定。 该乘法立即给出总数。

 | --- | --- | --- | --- |
 | 蛮力 | O(10^长度) | O(1) | O(1) | 有效，但没有必要 |
 | 最佳 | 每个测试用例的 O(长度) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 这控制我们重复计算的次数。 
2. 对于每个模板字符串`s`，检查第一个字符。 如果是问号，则可以是以下任意数字`1`到`9`。 如果是数字`0`，字符串不能代表正整数，所以答案是零。 
3. 将计数器初始化为 1。这将累积可能性的数量。 
4. 将计数器乘以第一个字符的选项数。 对于问号，乘以 9； 对于非零数字，乘以 1。 
5. 对于字符串中剩余的每个字符，如果是问号，则将计数器乘以 10（数字`0`到`9`)，否则乘以 1，因为它是固定的。 
6. 处理完所有字符后输出计数器。 这给出了与模板匹配的正整数的数量。 

工作原理：该算法保持了计数器始终等于通过替换已处理位置生成的有效整数总数的不变性。 每个乘法步骤都准确地考虑了该位置的独立选择数量，并且第一个字符检查确保我们永远不会包含带有前导零的数字。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    s = input().strip()
    if s[0] == '0':
        print(0)
        continue
    count = 1
    for i, c in enumerate(s):
        if c == '?':
            if i == 0:
                count *= 9
            else:
                count *= 10
    print(count)
```该代码使用有效地读取所有测试用例`sys.stdin.readline`。 第一个字符检查可防止计算以零开头的无效数字。 对于每个字符，如果它是问号，则正确的可能性数量会相乘。 这种方法避免了嵌套循环和递归，并且以相对于字符串长度（最多为 5）的线性时间运行。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    res = []
    for _ in range(t):
        s = input().strip()
        if s[0] == '0':
            res.append("0")
            continue
        count = 1
        for i, c in enumerate(s):
            if c == '?':
                count *= 9 if i == 0 else 10
        res.append(str(count))
    return "\n".join(res)

 ## 边缘情况

 模板`0`立即触发第一个字符检查，返回 0，因为零不是正数。 为了`?`作为单字符模板，乘法计算 9 个选项 (1-9)，而不是 10 个，正确避免了零。 模板如`03`或者`0?`很早就被抓住了，像这样的模板`?0?`第一个字符乘以 9，其余每个问号乘以 10，得到 90`?0`或 900 为`?0?`，尊重前导零规则。 该算法一致地处理所有单位数和多位边缘情况。
