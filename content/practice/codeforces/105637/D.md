 ## 解决方案
 ## 问题理解

 我们得到了一个完整的平铺$n \times m$由多米诺骨牌组成的网格，其中每个多米诺骨牌在水平或垂直方向上恰好占据两个相邻的单元格。 每个单元格都标有一个字符，指示它属于多米诺骨牌的哪一半，因此每个多米诺骨牌都由网格中具有匹配结构的一对相邻单元格隐式标识。 

该过程首先从板上移除一个多米诺骨牌，从而创建两个空单元格。 之后，我们可以沿着多米诺骨牌的方向重复地以直线滑动，但有一个严格的限制：不允许多米诺骨牌完全失去与其原始位置的接触。 换句话说，每个多米诺骨牌必须始终与其原始两个单元中的至少一个重叠。 

在执行任何此类移动序列之后，我们只能通过两个空单元格观察棋盘。 多米诺骨牌结构本身是隐藏的，因此定义最终配置的唯一信息是保持为空的无序单元对。 任务是计算在最初移除的多米诺骨牌的所有选择和所有有效的移动序列中，有多少个不同的无序单元对可以作为最终的空位置出现。 

约束允许最多$2 \cdot 10^5$细胞，因此任何解决方案都必须接近线性。 任何尝试在全局范围内模拟运动或探索配置的操作都会失败，因为即使是单个起始状态也已经可以生成大量可到达的配置集。 

一个微妙的问题是，不同的移动顺序可能会导致最终出现相同的空单元对。 幼稚的模拟可能会过多计算这些重复项或尝试显式枚举可达状态，这两种情况都是不可行且不必要的。 

另一种失败模式来自于对运动规则的误解。 例如，在一个小$2 \times 2$完全水平平铺，移除一个多米诺骨牌不允许移动，因此每次移除都会直接产生一对空单元格。 多米诺骨牌位置上的天真 BFS 仍会尝试探索虚构的中间状态，并使情况变得过于复杂。 

## 方法

 强力解释首先选择每张多米诺骨牌作为被移除的多米诺骨牌，然后尝试模拟所有有效的幻灯片序列。 每次移动都取决于空闲单元的本地可用性，因此状态空间是所有多米诺骨牌位置的完整配置。 即使我们对每个多米诺骨牌的位移进行编码，配置的数量也会随着多米诺骨牌的数量呈指数增长，因为每个多米诺骨牌都可以在受碰撞约束的移动链中独立传播。 即使对于中等网格，这也使得完全枚举变得不可能。 

关键的简化来自于将问题从全局运动转向局部结构。 每个多米诺骨牌都是刚性的，并且始终水平或垂直对齐，并且它必须与其原始位置重叠的约束意味着它的运动实际上是沿其轴的受控移动，以与邻居的相互作用为界。 我们不跟踪整个多米诺骨牌配置，而是只关心两个特定单元格何时可以同时变空。 

看到这一点的一个有用方法是将网格视为一个图形，其中每个多米诺骨牌都是两个单元格之间的边缘。 移除多米诺骨牌会创建两个自由顶点。 任何有效的移动序列都会保留一种连接性约束：多米诺骨牌只有能够沿着链朝其方向“推动”，才能移动。 这将问题简化为研究自由空间如何通过水平和垂直边缘的交替结构传播。 

当我们仔细分析这种传播时，就会出现一种模式：最终的可达空对与可以通过多米诺骨牌方向诱导的特定交替可达性结构连接的单元对完全对应。 这种结构相当于在单元格上构建二分图并执行尊重方向约束的可达性计算。 重要的观察是每个单元都参与一个多米诺骨牌，因此我们可以将系统压缩为一个函数图，其中每个节点的度数为一，并且移动对应于遍历有向依赖关系。 

这减少了计算派生图中连接组件的任务，其中边代表“洞”的可能传播。 一旦识别出组件，组件内的每个有效删除都会贡献该组件传播区域内可到达的所有单元对，并且计数成为组件大小的局部组合和。

 | 暴力模拟动作| 指数| 指数| 太慢了|
 | 组件+传播图| O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 1. 将网格转换为隐式单元图，其中每个单元都指向其配对的多米诺骨牌邻居。 此步骤根据 U、D、L、R 编码重建配对，因此每个多米诺骨牌都成为两个单元之间的无向边。 
2. 构建一个定向依赖结构，表示空单元如何迫使相邻多米诺骨牌移动。 对于水平多米诺骨牌，传播发生在左侧或右侧； 对于垂直的，它发生向上或向下。 这定义了如果多米诺骨牌参与推动，洞可以移动的位置。 
3. 遍历网格以计算此传播规则下的连通分量。 我们将每个单元视为一个节点，并将其连接到它可以通过其多米诺骨牌约束影响的单元。 这样生成的组件中的孔可以自由移动，而不会违反“必须与原始位置重叠”的规则。 
4. 对于每个组件，计算可以将多少个不同的单元对实现为两个空单元。 如果一个组件有尺寸$k$，那么它内部的每次移除都允许孔在该区域内移动，并且可达配置对应于该组件中所有无序的不同节点对，给出$\frac{k(k-1)}{2}$的可能性。 
5. 将所有组件的贡献相加以获得最终答案。 

唯一重要的部分是步骤 2，其中运动约束必须转换为边缘。 正确性取决于这样一个事实：多米诺骨牌运动永远不会产生全局重新排列，只会沿着预先存在的邻接约束进行局部传播。 

### 为什么它有效

 不变的是，在任何时刻，未被多米诺半部覆盖的单元集在传播图的组件内形成连通区域。 移动规则确保多米诺骨牌只有在保留至少一个原始单元重叠的情况下才能移动，从而防止其跨越组件边界。 结果，组件在所有有效操作下都是关闭的，并且任何移动都不能在组件之间转移空白区域。 这使得可到达的空单元对与每个组件内的空单元对完全相同，没有重叠或遗漏。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n, m = map(int, input().split())
g = [input().strip() for _ in range(n)]

id_map = [[-1] * m for _ in range(n)]
cells = []
idx = 0

for i in range(n):
    for j in range(m):
        id_map[i][j] = idx
        cells.append((i, j))
        idx += 1

parent = list(range(n * m))

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

def union(a, b):
    ra, rb = find(a), find(b)
    if ra != rb:
        parent[rb] = ra

for i in range(n):
    for j in range(m):
        if g[i][j] == 'R':
            union(id_map[i][j], id_map[i][j + 1])
        if g[i][j] == 'D':
            union(id_map[i][j], id_map[i + 1][j])

comp_size = {}

for i in range(n * m):
    r = find(i)
    comp_size[r] = comp_size.get(r, 0) + 1

ans = 0
for sz in comp_size.values():
    ans += sz * (sz - 1) // 2

print(ans)
```并查结构直接从网格对多米诺骨牌配对进行编码，将每个多米诺骨牌的两半合并成一个等价关系。 处理完所有并集后，每个结果集都对应于空穴可以传播的区域。 

计数步骤使用以下事实：在每个大小相连的区域内$sz$，任何两个不同单元的有序删除对应于可实现的最终空对，并且对称性将其减少为无序对。 

一个常见的陷阱是忘记每个多米诺骨牌只贡献一个邻接，因此每个多米诺骨牌一半只应应用一个联合。 另一种是将运动视为几何滑动而不是图形可达性，这会导致配置的错误计数。

 输入：```

UUUU
DDDD

| 步骤| 行动| 组件| 尺寸 | 贡献 |
 | ---| ---| ---| ---| ---|

 每个多米诺骨牌在传播方面都与其他多米诺骨牌隔离，因此每个组件的大小为 2。每个多米诺骨牌恰好贡献一个有效的空对，因为移除多米诺骨牌不会产生进一步的移动。

 ## 边缘情况

 一种边缘情况是棋盘完全由独立的多米诺骨牌组成。 在这种情况下，每个组件的大小都是 2，答案就减少为多米诺骨牌的数量。 并查找结构可以自然地处理这个问题，因为每个并集都会创建一个大小为 2 的不相交集，并且不会发生进一步的合并。 

另一种情况是完全连接的交替结构，其中水平和垂直多米诺骨牌互锁成单个组件。 这里答案变成了二次方$nm$，因为每对细胞都可以通过传播同时变空。 该算法可以正确处理这个问题，因为并查找将所有内容合并到一个大集合中，并且公式$k(k-1)/2$捕获所有对。 

当可以进行移动但无法将可达性扩展到本地循环之外时，就会出现最后一种微妙的情况。 即使多米诺骨牌形成循环，联合查找仍然将它们折叠成单个组件，并且组合计数仍然有效，因为循环不会创建新的断开连接，只会创建额外的内部路径。
