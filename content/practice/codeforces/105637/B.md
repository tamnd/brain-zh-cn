 ## 解决方案
 ## 问题理解

 该问题描述了一条长度为直线的道路\(f\)通向节日地点 位置\(f\)。 有\(n\)目前这条道路上的汽车。 每辆车都有一个已知的位置\(x_i\)，以距道路起点的距离和恒定速度来测量\(v_i\)。 所有汽车都向节日驶去，因此它们的位置随时间线性增加，直到到达\(f\)。 

任务是确定哪辆车最先到达节日。 由于每辆车均以匀速行驶，因此车辆到达时间\(i\)就是到终点的剩余距离除以其速度，\((f - x_i) / v_i\)。 答案是该时间最小的汽车的索引。 保证没有两辆车同时到达，因此有一个唯一的答案。 

限制很小：\(n \leq 100\),\(f \leq 10^4\)，并且速度也受\(100\)。 这意味着即使使用基本算术进行简单的 \(O(n)\) 扫描也绰绰有余。 任何计算每个到达时间一次并直接比较它们的解决方案都将立即运行。 不需要排序或高级数据结构，因为输出只是一小部分集合中的最小值。 

有一些边缘情况值得明确说明。 如果汽车已就位\(f\)，那么它的到达时间为零，如果没有其他车也为零（问题保证不会发生），则必须选择它。 如果多辆汽车从相同位置出发但速度不同，那么速度更快的汽车显然会获胜，因为剩余距离相同。 如果比较的话就会出现一个微妙的错误\(x_i / v_i\)而不是 \((f - x_i) / v_i\)，它会计算从开始时间而不是结束时间，完全颠倒逻辑。 

另一个容易的陷阱是使用浮点除法并不小心直接比较时间。 虽然这在限制下有效，但它是不必要的，并且比比较交叉产品以避免精度问题更稳健。 

## 方法

 解决这个问题最直接的方法就是对最终的比赛结果进行数值模拟。 对于每辆车，计算到达终点所需的时间，然后选择最小值。 这是正确的，因为汽车之间的运动是均匀且独立的，因此到达时间完全决定了顺序。 

在此设置中，暴力视图已经是最佳的。 即使我们想象以小的时间步长重新计算位置，这也意味着重复更新所有\(n\)汽车超过大量台阶的时间\(f\)，导致类似 \(O(n \cdot f)\) 的结果，鉴于运动是线性的并且可以用封闭形式表示，这是不必要的。 

关键的观察是每辆车的状态完全由单个标量值概括：其到达的剩余时间\(f\)。 一旦我们计算每辆车一次，问题就减少到找到最小值\(n\)价值观。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 随着时间的推移进行残酷模拟 | \(O(n \cdot f)\) | \(O(1)\) | 太慢了|
 | 直接时间计算 | \(O(n)\) | \(O(1)\) | 已接受 |

 ## 算法演练

 1. 阅读\(n\)和\(f\)，它定义了存在多少辆汽车以及终点线所在的位置。 

2. 初始化变量以跟踪迄今为止看到的最佳（最小）到达时间以及相应的汽车索引。 将最佳时间初始化为大于任何可能的实际值非常重要，以便第一辆车始终成为基线。 

3. 每辆车\(i\)，读取其位置\(x_i\)和速度\(v_i\)。 

4. 计算到节日的剩余距离：\(d_i = f - x_i\)。 这代表汽车还需要行驶多远。 

5. 概念性地计算到达时间：\(t_i = d_i / v_i\)。 我们没有实际除法，而是使用交叉乘法进行比较以避免精度问题：我们比较\(d_i \cdot v_{\text{best}}\)和\(d_{\text{best}} \cdot v_i\)。 

6. 如果当前汽车比最知名的汽车更早到达，则更新最佳时间表示并存储该汽车的索引。 

7、处理完所有车辆后，输出到达时间最短的车辆索引。 

### 为什么它有效

 在每一步中，该算法都保持这样的不变性：所存储的汽车是所有处理的汽车中到达时间最短的汽车。 使用数学上等效的分数排序将每辆新车与该候选车进行比较。 由于到达时间是严格可比的并且不存在联系，因此不变量确保在扫描所有汽车后，存储的索引对应于全局最小值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def better(d1, v1, d2, v2):
    return d1 * v2 < d2 * v1

n, f = map(int, input().split())

best_idx = -1
best_d = 0
best_v = 1

for i in range(1, n + 1):
    x, v = map(int, input().split())
    d = f - x

    if best_idx == -1:
        best_idx = i
        best_d, best_v = d, v
    else:
        if better(d, v, best_d, best_v):
            best_idx = i
            best_d, best_v = d, v

print(best_idx)
```该代码将当前最佳候选者维护为一对 \((d, v)\)，而不是显式存储时间。 这避免了浮点运算并使用交叉乘法保持比较精确。 辅助比较函数对排序进行编码\(d_1 / v_1 < d_2 / v_2\)在整数算术中。 

初始化与`best_idx = -1`确保始终选择第一辆车作为基线。 随后的每一辆车都会与它进行比较，只有在发现更小的到达时间时才会进行更新。

 | 空间| \(O(1)\) | 仅存储少量标量变量 |

 和\(n \leq 100\)，该解决方案远远低于任何时间限制约束。 即使在更严格的设置中，线性扫描仍然保持最佳状态，因为每个输入元素都必须至少检查一次。

 ## 边缘情况

 单车输入是微不足道的，因为没有比较； 该算法正确地将第一辆车初始化为最好的并立即输出。 

当一辆车起步非常接近目的地但速度极慢，而另一辆车起步较远但速度更快时，算法会正确比较完整比率而不是原始距离。 例如，与\(f = 100\)、汽车 \((x=90, v=1)\) 和 \((x=0, v=10)\)，计算的时间为\(10\)和\(10\)，但该问题不保证任何联系，因此严格的不平等会一致地决定。 

当多辆车共享相同位置时，比较只会降低速度，因为它们的剩余距离相同。 叉乘规则自然地简化为选择较大的\(v\)，这符合更快的汽车总是从相同的起点获胜的直觉。
