 ## 解决方案
 ## 问题理解

 我们得到了平面上的一组点。 每个点都充当激光发生器，每对发生器都通过直激光段连接。 因此，对于 n 个点，系统形成一个完整的几何图，其中每条边都是两个给定坐标之间的线段。 

我们从原点出发，想要到达第一象限中的遥远目的地。 只要我们避免接触任何发生器点或连接它们的任何线段，运动在平面上是完全自由的。 使路径可行的唯一方法是删除一些生成点； 删除生成器也会删除与其相关的所有段。 

任务是计算必须删除的最小生成器数量，以便从原点到目的地至少存在一条不与任何剩余线段或点相交的连续曲线。 

这些约束意味着测试用例中的 n 最大可达 10^6，因此任何检查所有点对的解决方案都是不可能的。 所有段的二次构造也立即被排除，因为边的数量是 O(n^2)，即使对于中等 n 来说，这也是一个天文数字。 

关键的几何困难在于这些线段在平面上形成密集的障碍物。 然而，由于运动不受限制并且仅拓扑分离很重要，因此结构简化为理解这些点如何将平面划分为区域以及将原点区域连接到第一象限中的无穷大需要哪些最小删除。 

一种简单的方法会尝试显式构建所有线段的排列，并计算起点和目的地是否位于平面细分的同一面上。 这在计算和概念上都失败了，因为这种排列具有二次复杂度。 

一种更微妙的故障模式来自于假设只有位于起点和目的地“之间”的点才重要。 例如，点在原点周围形成凸障碍的配置仍然会阻止所有逃生路线，即使没有任何逃生路线直接位于起点和终点之间的线段上。 

## 方法

 暴力心理模型是将每个片段视为障碍，并尝试检查所有片段的补集的连通性。 人们可以想象构建由交叉点引起的完整平面图，然后运行区域连通性测试。 这在概念上是正确的，因为问题是询问两个点是否位于平面布置的同一个面上。 

然而，构建 O(n^2) 段之间的所有交集是不可行的。 即使存储它们也是不可能的，并且在面上运行任何 BFS 都需要与排列复杂度成正比的时间，在最坏的情况下，对于相交和面来说是 θ(n^4)。 

关键的观察是我们实际上并不需要完整的安排。 这些线段都是由点确定的，创建“密封”障碍物的唯一方法是通过在原点周围强制拓扑分离的配置。 该问题简化为确定最小的点集，这些点的移除会破坏所有此类封闭结构。 

一个关键的重新表述是考虑原点周围所有点的角度顺序。 两点之间的每条线段都与从原点开始的方向之间的角度扫描相交。 如果我们保留一组角度位置过于“分散”的点，那么它们之间的完整图就会产生一个障碍，将原点包围在其凸包结构中。 因此，障碍物取决于我们必须移除多少点，以便剩余点位于不会完全环绕原点的区域中。

这将问题简化为选择可以放置在从原点看去的开放半平面内的最大点子集。 同样，我们希望保持角坐标位于某个长度严格小于 π 的区间内的点的最大数量。 删除所有其他部分可确保没有任何段可以完全环绕并隔离原点。 

因此，答案变为 n 减去围绕原点形成半圆的最大点数。 这是一个经典的圆形扫描问题，可以通过对角度进行排序并在双倍数组上使用两指针窗口来解决。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 段的强力排列 | O(n^2) 或更糟 | O(n^2) | O(n^2) | 太慢了 |
 | 角扫+两指针| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算每个点相对于原点的极角。 这将几何位置转换为循环排序问题，其中方向而不是距离更重要。 
2. 按升序对角度进行排序。 排序为圆形域提供了线性结构，这是应用滑动窗口所必需的。 
3. 通过将每个角度加上 2π 来复制排序的角度列表。 这可以处理环绕间隔，以便可以将圆形窗口视为线性段。 
4. 使用两个指针 l 和 r 维护一个角度差严格小于 π 的窗口。 当条件成立时，贪婪地展开 r。 
5. 对于每个 l，计算可达到的最大 r。 跟踪所有起始位置的最大窗口大小。 该窗口表示半圆中包含的点的最大子集。 
6. 最终的答案是n减去这个最大窗口大小。 

两指针扩展起作用的原因是，一旦角度排序，角度差的条件就是单调的。 增加r只能增加角度跨度，因此每个指针最多移动n次。 

### 为什么它有效

 任何完全适合于相对于原点的开放半平面内的点集都不能形成围绕原点的闭合角度包裹。 因此，这些点之间的所有诱导线段都停留在不完全围绕原点的区域内，从而留下一条通往无穷远的连续逃逸路径。 相反，如果点不包含在任何半圆中，则它们的完整图形必然会创建一个覆盖，以防止单调逃逸方向。 因此，最大化半圆内的保留集直接最小化了破坏所有封闭结构所需的移除次数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        angles = []
        for _ in range(n):
            x, y = map(int, input().split())
            angles.append(math.atan2(y, x))

        angles.sort()
        m = len(angles)

        ext = angles + [a + 2 * math.pi for a in angles]

        ans = 0
        r = 0
        for l in range(m):
            while r < l + m and ext[r] - ext[l] < math.pi:
                r += 1
            ans = max(ans, r - l)

        print(n - ans)

if __name__ == "__main__":
    solve()
```该解决方案首先使用 atan2 将每个点转换为其角度表示，它可以正确处理所有象限和边缘情况。 排序将这些方向排列在一个圆圈上。 通过添加 2π 移位重复项来扩展数组，可以在不进行模块化算术的情况下处理环绕间隔。 

两指针循环保持有效的角度跨度严格小于 π。 对于每个左边界，右指针尽可能前移。 r - l 之差表示有多少个点位于该半圆窗口中。 该值的最大值是最大的可生存子集。 

从 n 中减去该值即可得出所需的最小移除次数。

 ## 边缘情况

 当多个点非常靠近半圆的 π 边界时，就会出现微妙的边缘情况。 滑动窗口条件使用角度差的严格不等式，这确保彼此完全相反的点不会同时被包括在内。 如果两个点相差 π，则它们不能同时属于有效的开放半圆窗口，并且算法会正确排除该配对。 

另一种边缘情况是当点几乎与原点共线时。 在这种情况下，所有角度都紧密聚集，并且两指针窗口将覆盖整个集合，从而产生零去除的答案。 该算法可以自然地处理这个问题，因为角度差仍然远低于 π，因此 r 会扩展到所有点。 

最后一种边缘情况是环绕式，其中最佳半圆穿过 -π 到 π 边界。 复制的数组确保该间隔被表示为连续的段，因此滑动窗口仍然可以找到正确的最大值，而无需特殊的套管。
