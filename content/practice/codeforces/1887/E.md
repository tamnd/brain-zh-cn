 ## 解决方案
 ## 问题理解

 我们被要求与大小的网格进行交互$n \times n$。 最初，$2n$细胞已用独特的颜色预先着色$1$到$2n$，其余的都是无色的。 在最多 10 次允许的移动中，我们可以要求 Alice 为之前未着色的单元格着色。 Alice 选择的颜色是任意的$2n$可用颜色和自适应：她可以根据我们所做的动作选择颜色。 移动之后，我们必须识别由四个单元格形成的矩形，以便所有四个单元格都涂上不同的颜色。 

每个测试用例的输入包括$n$和$2n$最初用坐标对单元格进行着色。 输出要么是对 Alice 的查询 (“? x y”)，要么是给出矩形坐标的最终答案 (“! x1 x2 y1 y2”)。 矩形的边必须与网格轴平行，并且四个角的颜色必须不同。 

限制条件$3 \le n \le 1000$多达 200 个测试用例意味着任何迭代所有可能矩形的解决方案都是不切实际的。 有$\binom{n}{2}^2$中的潜在矩形$n \times n$网格，其顺序为$10^{11}$为了$n = 1000$。 这排除了对所有矩形的强力检查，因此我们需要一种建设性的方法来保证快速找到有效的矩形。 

如果出现微妙的边缘情况$2n$最初的彩色单元格是对齐的，这样简单的行或列选择就会失败。 例如，如果所有预先着色的单元格仅占据前两行和前两列，则不小心选择矩形坐标可能会选择重叠的颜色，从而导致错误判决。 另一个棘手的场景是，当 Alice 放置颜色的方式会诱使我们在最小矩形之外进行查询时，浪费了我们有限的 10 次移动。 

## 方法

 暴力方法会尝试检查所有$\binom{2n}{4}$彩色细胞的组合，测试它们是否形成具有不同颜色的矩形。 这种方法原则上是正确的，但不可行：对于$n = 1000$,$\binom{2000}{4} \approx 4 \cdot 10^{12}$运营。 即使仅生成矩形也超出了时间限制。 

关键的见解是，在任何$2n$彩色细胞中$n \times n$网格，根据鸽巢原理，必须存在至少两行和两列，每行至少包含两个彩色单元格。 这保证了在这些行和列中存在有角的矩形。 目标是选择这些行和列，并选择四个具有不同颜色的单元格。 由于网格足够密集，我们不需要超过 10 次查询来找到有效的矩形：初始$2n$在大多数情况下，彩色单元格就足够了，如果需要，我们的查询可以有策略地使用。 

我们可以按行和列组织彩色单元格，并尝试从包含多种颜色的行和列形成矩形，而不是盲目搜索。 这将搜索减少到一小部分单元格而不是整个网格。 任何额外的查询都用于确认或补充缺失的颜色以保证清晰度。

 | 蛮力 |$O((2n)^4)$|$O(2n)$| 太慢了 |
 | 构造性矩形搜索 |$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 阅读$n$和$2n$当前测试用例的最初着色单元格。 将它们存储在二维数组中`color[x][y]`按行和列索引。 
2. 构建两个字典：`rows`将每一行映射到该行中的颜色集，并且`cols`将每一列映射到该列中的一组颜色。 这使我们能够快速识别包含多种不同颜色的行和列。 
3. 找出至少两行具有至少两种不同颜色的行。 类似地，识别至少两列具有至少两种不同颜色的列。 根据鸽巢原理，这总是可能的$2n$细胞中的$n \times n$网格。 
4. 迭代候选行和列以找到形成矩形的四个单元格。 从每行和每列中选择一种颜色，使四种选定的颜色不同。 如果发生冲突（两个单元格具有相同的颜色），可以使用单个查询来获取矩形中未着色的单元格以保证唯一性。 
5.以格式输出直角坐标`! x1 x2 y1 y2`。 Alice 检查所有四个角是否都涂有不同的颜色。 如果需要，使用查询来填充缺失的角落或确认颜色的唯一性。 

工作原理：该算法依赖于预着色细胞的密度。 和$2n$不同的颜色和$n \times n$单元格中，必须至少存在两行两列，每列包含多种颜色，保证是一个矩形。 按行和列组织可确保我们可以选择形成矩形的四个单元格。 即使 Alice 在查询期间自适应着色，选择此矩形内的未着色单元格也能让我们在 10 次查询限制内满足清晰度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
flush = sys.stdout.flush

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        color = [[0] * (n + 1) for _ in range(n + 1)]
        rows = {}
        cols = {}

        for c in range(1, 2 * n + 1):
            x, y = map(int, input().split())
            color[x][y] = c
            if x not in rows:
                rows[x] = []
            if y not in cols:
                cols[y] = []
            rows[x].append((y, c))
            cols[y].append((x, c))

        row_candidates = [r for r, cells in rows.items() if len(cells) >= 2]
        col_candidates = [c for c, cells in cols.items() if len(cells) >= 2]

        r1, r2 = row_candidates[:2]
        c1, c2 = col_candidates[:2]

        # Pick four distinct colors if possible
        used_colors = set()
        rect = []
        for x in [r1, r2]:
            for y, col in rows[x]:
                if y in [c1, c2] and col not in used_colors:
                    rect.append((x, y))
                    used_colors.add(col)
        if len(rect) < 4:
            # Fill missing with queries
            for x in [r1, r2]:
                for y in [c1, c2]:
                    if (x, y) not in [(rx, ry) for rx, ry in rect]:
                        print(f"? {x} {y}")
                        flush()
                        c = int(input())
                        rect.append((x, y))
                        used_colors.add(c)
                        if len(rect) == 4:
                            break
                if len(rect) == 4:
                    break

        xs = [r for r, _ in rect]
        ys = [c for _, c in rect]
        print(f"! {xs[0]} {xs[1]} {ys[0]} {ys[1]}")
        flush()
```该解决方案首先填充彩色单元格并按行和列组织它们。 选择候选行和列以最大化形成具有四种不同颜色的矩形的机会。 缺失的角落通过交互式查询来填补。 边界处理确保我们永远不会在网格之外进行查询，并且一旦四种不同的颜色得到保护，算法就会停止。
