 ## 解决方案
 ## 问题理解

 我们得到一个有向图，其中每个顶点代表一种货币，每条边代表一个交换操作。 如果我们从货币出发`u`到货币`v`，金额并不是简单地乘以汇率，它还会在转换前损失固定费用。 具体来说，如果我们目前持有一定数量`A`以货币形式`u`，然后使用交换后我们最终得到`r * (A - f)`以货币形式`v`。 

拉米首先借了一些钱`z1`以货币形式`0`。 然后，他可以应用任何交换序列，可能会多次重新访问货币，并且最终必须返回到货币`0`有一些最终金额`z2`。 目标是找到最小的整数`z1`这样就存在一个开始和结束于的交换序列`0`和`z2 > z1`。 

关键的困难在于每次交换都是仿射的而不是纯粹的乘法。 每条边将值转换为线性函数，因此长路径组成嵌套的线性表达式而不是简单的乘积。 

这些限制表明简单地枚举路径是不可能的。 对于多达 500 种货币和 4000 个交易所，任何探索所有路径甚至所有简单循环的方法都是不可行的。 乘积约束仅确保数值稳定性并防止短路径上的极端爆炸，但它不会降低组合复杂性。 

考虑周期时会出现一个微妙的问题。 一个周期可能会盈利，也可能不会盈利，具体取决于启动资金。 对于大价值来说看起来有利可图的周期可能不适用于小价值，因为费用变得相对更加重要。 这种对初始金额的依赖性是核心的复杂性。 

简单的最短路径或最长路径方法会失败，因为路径的“权重”取决于当前状态值，而不仅仅是路径结构。 同样，在固定权重图中检测正循环是不够的，因为有效权重取决于起始资本。 

## 方法

 蛮力的想法是确定一个起始量`z1`，模拟所有可能的交换序列，并计算货币的最佳可能最终金额`0`。 每条路径定义了以下形式的线性变换`z2 = a * z1 - b`， 在哪里`a`是利率和的乘积`b`是累计转换费用。 然后我们检查是否有任何路径满足`a * z1 - b > z1`。 

这立即变得不可行，因为路径数量呈指数增长。 即使限制为简单的路径也无济于事，因为循环正是可以改善结果的，而循环意味着重复的重新访问。 

关键的观察是，对于任何固定路径，不等式可以重新排列为`(a - 1) * z1 > b`。 如果一条路径有`a <= 1`，无论怎样它都永远无法盈利`z1`。 如果`a > 1`，它会产生一个阈值`z1 > b / (a - 1)`。 这意味着每个周期都会贡献候选人所需的最低启动资金，而答案是所有此类阈值中的最小值。 

剩下的挑战是枚举所有周期仍然是不可能的。 相反，我们翻转视角：对于`z1`，我们询问是否存在任何序列在返回货币时增加超出起始金额的序列`0`。 这成为仿射变换系统上的可达性问题，可以使用贝尔曼-福特风格的值松弛来解决。 

由于可行性随着`z1`增加，我们可以二分查找最小的有效值`z1`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 枚举所有路径/循环 | 指数| O(n) | 太慢了|
 | 二分查找+ Bellman-Ford 松弛 | O(log X·n·m) | O(n + m) | 已接受 |

 ## 算法演练

 我们将问题转化为决策问题：对于固定的启动资金`x`，决定Rami是否可以以货币结束`0`严格超过`x`。 

### 1. 将交换建模为仿射变换

 每条边`u -> v`定义一个函数`f(A) = r * A - r * f_fee`。 我们都存储`r`和有效减法项`c = r * f_fee`。 

这允许沿着路径进行合成，而无需从头开始重新计算。 

### 2. 固定候选起始值

 我们假设 Rami 从 amount 开始`x`在节点`0`。 我们计算在此起始条件下每个节点可达到的最佳可能数量。 

目标是看看我们是否可以返回到节点`0`价值超过`x`。 

### 3. 使用松弛传播最佳可达值

 我们维持`dist[v]`作为节点可实现的最大数量`v`。 最初`dist[0] = x`，所有其他都是负无穷大。 

对于每条边`u -> v`，我们应用：`dist[v] = max(dist[v], r * dist[u] - c)`。 

我们重复这个放松`n - 1`次，它捕获了所有简单路径的改进。 

### 4. 检测有益循环

 如果之后`n - 1`放松我们仍然可以改进一些`dist[v]`，然后一个循环增加了这个值`x`。 然而，我们只关心最终能影响货币的周期`0`。 

为了解决这个问题，我们向前传播“循环影响”：标记任何仍然可以放松的节点，并检查这些节点是否可以到达`0`在反向图中。 

如果是，那么任意大的改进都是可能的，这意味着返回到`0`增益超过`x`是可以实现的。 

### 5. 检查固定 x 的可行性

 在松弛和周期检测之后，我们检查是否`dist[0] > x`。 如果存在直接改进或循环辅助改进，则该值`x`是可行的。 

### 6.二分查找答案

 我们利用单调性：如果起始值`x`是可行的，那么任何更大的起始值也是可行的，因为缩放会增加所有不等式的左侧。 

我们二分查找最小的`x`在`[0, given_limit]`。 

### 为什么它有效

 每条路径定义一个线性变换`z2 = a * z1 - b`。 可行性仅取决于是否`z1 < (b / (a - 1))`对于某个周期`a > 1`。 Bellman-Ford 松弛隐式计算固定的最佳可实现仿射变换`z1`，循环检测确保我们捕获无限的扩增情况。 二分搜索隔离了至少一种有利可图的转换成为可能的最小阈值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**30

def check(n, adj, radj, x):
    dist = [-INF] * n
    dist[0] = x

    updated = [-1] * n

    for i in range(n - 1):
        changed = False
        for u in range(n):
            if dist[u] == -INF:
                continue
            for v, r, c in adj[u]:
                val = r * dist[u] - c
                if val > dist[v] + 1e-12:
                    dist[v] = val
                    changed = True
        if not changed:
            break

    for u in range(n):
        if dist[u] == -INF:
            continue
        for v, r, c in adj[u]:
            val = r * dist[u] - c
            if val > dist[v] + 1e-12:
                updated[v] = 1

    if updated[0] == 1:
        return True

    from collections import deque
    q = deque()
    vis = [False] * n

    for i in range(n):
        if updated[i] == 1:
            q.append(i)
            vis[i] = True

    while q:
        u = q.popleft()
        if u == 0:
            return True
        for v in radj[u]:
            if not vis[v]:
                vis[v] = True
                q.append(v)

    return dist[0] > x

def solve():
    n, m, x = input().split()
    n = int(n); m = int(m); x = float(x)

    adj = [[] for _ in range(n)]
    radj = [[] for _ in range(n)]

    for _ in range(m):
        u, v, r, f = input().split()
        u = int(u) - 1
        v = int(v) - 1
        r = float(r)
        f = float(f)
        adj[u].append((v, r, r * f))
        radj[v].append(u)

    lo, hi = 0.0, x
    ans = -1

    for _ in range(60):
        mid = (lo + hi) / 2
        if check(n, adj, radj, mid):
            ans = mid
            hi = mid
        else:
            lo = mid

    if ans < 0:
        print(-1)
        return

    print(int(ans + 1e-9))

if __name__ == "__main__":
    solve()
```该代码将决策过程与答案搜索分开。 每条边都存储缩放后的费率和有效费用贡献，因此每次松弛都是仿射转换的直接应用。 浮点比较通过小 epsilon 来稳定，以避免边界情况下的精度问题。 

循环检测阶段是必要的，因为贝尔曼-福特仅捕获简单路径的改进，而盈利的解决方案通常依赖于重复有益的循环。 

二分搜索是对实数值进行的，但最终答案被截断为整数，因为问题要求最小整数起始量。

 ## 边缘情况

 一个关键的边缘情况是，当一个周期的利率乘积大于 1 但仍然无法盈利时，因为费用在较小的起始值中占主导地位。 在这种情况下，贝尔曼-福特可能会显示较大值的增加`x`，但是二分查找正确地拒绝了小的候选者。 

另一种情况是存在改进但无法实现货币化`0`。 反向可达性过滤可确保未连接回目标的循环不会错误地影响答案。
