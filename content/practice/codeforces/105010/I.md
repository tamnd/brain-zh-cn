 ## 解决方案
 ## 问题理解

 每个候选人都可以纯粹由以下哪一个代表$m$他们属于少数群体。 所以每个申请人都对应于一组尺寸的子集$m$，并且该池包含所有$2^m$可能的子集。 

选择规则禁止选择两个候选，其中一个子集包含在另一个子集中。 如果候选人$A$拥有所有少数群体$B$可能还有更多，然后$A$严格来说被认为是更多样化的，并且两者不能同时选择。 如果两个候选对应于完全相同的子集，则只有一个副本很重要，但由于池已经包含每个子集一次，因此重复不会影响结构。 

因此，问题简化为选择尽可能多的子集，使得所选子集不包含在另一个所选子集中。 

输入仅给出$m$，所以任务是纯粹的组合：在一个的所有子集中$m$-元素集，我们想要最大的族，没有包含关系。 

约束条件$m \le 4000$排除子集上的任何指数构造。 甚至迭代所有$2^m$子集是不可能的。 任何解决方案都必须在多项式时间内有效$m$，理想情况下约为$O(m^2)$或更好。 

当尝试贪婪选择时，就会出现一种常见的失败情况，例如在没有理由的情况下获取固定大小的所有子集或任意混合大小。 例如，与$m = 3$，选择子集$\{1\}, \{1,2\}, \{2\}$失败是因为$\{1\} \subset \{1,2\}$，即使尺寸略有不同，也违反了规则。 

## 方法

 这里的结构是按包含排序的子集的布尔格。 该限制表明我们不能在这个偏序集中选择两个可比较的元素，因此我们正在寻找最大的反链。 

暴力尝试将枚举所有子集并尝试所有可能的选择，检查每对的包含条件。 即使我们将自己限制为子集，候选家族的数量也是$2^{2^m}$，即使对于$m = 10$。 稍微不那么极端的蛮力会尝试所有子集并维持贪婪构造，但是任何仅基于子集大小或字典顺序的贪婪规则都会失败，因为包含取决于结构，而不是顺序。 

关键的结构见解是子集包含由基数层控制。 相同大小的子集彼此之间永远不会存在包含关系。 大小的任意子集$k$不能包含大小的另一个子集$k$，并且它不能包含在大小的另一个子集中$k$要么，因为遏制严格增加了规模。 这意味着固定基数的每个“级别”形成一个有效的独立集。 

这将问题简化为选择布尔晶格的一层或多层完整层。 我们希望最大化我们可以采用的子集数量，同时保持在单个层内或组合层而不引入可比性。 然而，两个不同层的任意组合都会创建包含关系，因为每组大小$k$包含在许多尺寸集合中$k+1$。 所以我们被迫停留在一个水平上。 

问题变成选择最大的二项式系数层，根据斯佩纳定理，该二项式系数层在中间层最大化。 因此答案是$\binom{m}{\lfloor m/2 \rfloor}$。

 | --- | --- | --- | --- |
 | 对子集的暴力破解 | 指数| 指数| 太慢了 |
 | 中间层组合学 |$O(m)$或者$O(m^2)$|$O(m)$| 已接受 |

 ## 算法演练

 该解决方案直接由计算单个二项式系数得出。 

1. 观察到最佳选择必须来自相同大小的子集，因为任何大小差异都会引入包含。 这减少了选择固定大小的所有子集的问题$k$。 
2.大小子集的个数$k$是$\binom{m}{k}$。 我们希望最大化这个价值$k$。 二项式系数形成对称单峰序列。 
3. 最大值出现在$k = \lfloor m/2 \rfloor$。 所以答案是$\binom{m}{\lfloor m/2 \rfloor}$。 
4. 计算阶乘高达$m$，然后使用模逆来评估模下的二项式系数$998244353$。 
5. 返回结果。 

为什么它起作用可以从子集偏序集的结构中得出。 任何有效的选择都是反链。 斯佩纳定理指出，布尔格中最大的反链恰好是最大的中间层，没有其他构造可以超过它，因为任何集合族都可以向中间“移动”，而不会减小大小，同时保留反链属性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    m = int(input().strip())
    
    fact = [1] * (m + 1)
    for i in range(1, m + 1):
        fact[i] = fact[i - 1] * i % MOD
    
    inv_fact = [1] * (m + 1)
    inv_fact[m] = pow(fact[m], MOD - 2, MOD)
    for i in range(m, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD
    
    k = m // 2
    ans = fact[m] * inv_fact[k] % MOD * inv_fact[m - k] % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```阶乘数组编码$n!$值以素数为模。 逆阶乘数组是使用费马小定理构建的，允许在模下进行除法。 

的选择$k = m // 2$直接反映了布尔格的中间层。 不需要其他组合结构。 

## 工作示例

 ### 示例 1：$m = 2$我们计算最大 2 的阶乘。 

| 步骤| 价值|
 | --- | --- |
 |$k$| 1 |
 |$\binom{2}{1}$| 2 |

 所以答案是2，对应子集$\{1\}$和$\{2\}$。 

这证实了选择中间层可以避免任何包含冲突，因为两个单例都不包含另一个。 

### 示例 2：$m = 3$| 步骤| 价值|
 | --- | --- |
 |$k$| 1 |
 |$\binom{3}{1}$| 3 |

 最优族是所有单例子集。 任何包含 2 元素子集的尝试都会强制排除其包含的单例，因此中间层是最佳的。

 ## 边缘情况

 当$m = 1$，唯一的子集是$\emptyset$和$\{1\}$。 中间层是$k = 0$, 给予$\binom{1}{0} = 1$。 该算法正确地计算了这一点，因为$m // 2 = 0$。 

什么时候$m = 2$，两个单例子集形成最优反链。 计算选择$k = 1$，产生$\binom{2}{1} = 2$，匹配正确的选择。 

什么时候$m$很大，比如$m = 4000$，阶乘计算保持线性$m$，并且不需要子集枚举。 该算法完全依赖于预先计算的组合而不是结构枚举，因此它保持在限制范围内。
