[CF 317A - 完美配对](https://codeforces.com/problemset/problem/317/A)

 **标签：** 暴力破解
 **求解时间：** 1m 1s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们有两个整数，$x$和$y$和目标阈值$m$。 如果两个数字中至少有一个大于或等于，则认为一对是_m-perfect_$m$。 从一对开始$(x, y)$，我们可以执行一项操作，删除其中一个数字并将其替换为两个数字的总和。 目标是找到使该对完美所需的最少操作数，或者确定这是不可能的。 

整数可以非常大，最多可达$\pm 10^{18}$，这排除了尝试所有可能的和序列的天真的暴力尝试。 输出是一个数字：最小操作数或$-1$如果没有序列可以到达目标。 

当两者都出现时，就会出现关键的边缘情况$x$和$y$是非正的，而$m > 0$。 在这种情况下，重复将两个非正数相加永远不会达到$m$。 例如，使用输入$-5, -3, 2$，总和$-5$和$-3$仍为负数，因此目标无法实现。 另一种微妙的情况是当一个数字已经大于或等于$m$，这立即意味着需要零操作。 

## 方法

 最简单的方法是模拟每个可能的操作序列。 在每一步中，我们可以替换$x$或者$y$和$x + y$，递归地生成两个新状态。 这种方法原则上是正确的，因为它探索了每一种可能性，但它很快就变得不切实际。 即使对于适度的值，递归树也会呈指数增长，从而导致$O(2^n)$状态，这远远超出了 1 秒的时间限制。 

允许有效解决方案的观察结果是，我们应该始终用两个数字之和替换较小的数字。 通过这样做，每个操作都最大化较小数字的增长，保证序列达到$m$以最少的步骤。 如果较小的数为非正数且较大的数小于$m$，我们首先通过必要时交换来确保较小的数字为负数，而较大的数字为正数。 如果两个数字都是非正数并且$m > 0$，这个问题是不可能的。 

通过这种方法，较小的数字大致按照类似斐波那契数列的方式增长，因为每次操作都会将当前较大的数字添加到较小的数字上。 这导致了一个有效的$O(\log m)$算法，因为每一步都会增加至少一个数字。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最优（替换较小的）| O(log m) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取整数$x, y, m$。 确保$x \le y$必要时进行交换。 这简化了以后关于替换哪个数字的推理。 
2.如果$y \ge m$，这对已经_m-perfect_了。 打印 0 并停止。 
3.如果$y \le 0$和$m > 0$, 不可能达到$m$。 打印-1并停止。 任何以两个非正数开头的和序列都不能变为正数。 
4. 初始化计数器`ops = 0`。 尽管`y < m`，执行以下操作：

 - 添加`y`到`x`（替换较小的数字）并在必要时交换以维持`x <= y`。 
- 增量`ops`1.
 5.一次`y >= m`， 打印`ops`。 

**为什么它有效：** 保持的不变量是`y`始终是较大的数字。 替换较小的数字可确保序列尽可能快地增长到`m`。 由于每一步都严格增加数字的总和，并且预先处理负数，因此该算法保证了最少的操作次数或正确识别不可能的情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    x, y, m = map(int, input().split())
    
    if x > y:
        x, y = y, x
    
    if y >= m:
        print(0)
        return
    
    if y <= 0:
        print(-1)
        return
    
    ops = 0
    while y < m:
        x += y
        if x > y:
            x, y = y, x
        ops += 1
    
    print(ops)
```**说明：** 我们一开始就交换`x`数字越小，简化主循环。 循环不断地添加`y`到`x`最大化增长。 每次操作后交换可确保`x`始终是较小的数字。 处理`y <= 0`早期边缘情况可以防止无限循环或不必要的计算。 得益于 Python 的任意精度算术，该解决方案可以优雅地处理极大的整数。

 负数很快被克服，算法收敛到`y >= m`高效。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(log m) | 每一步将较小的数字至少增加较大的数字的值，因此操作数在差距中是对数的`m`。 |
 | 空间| O(1) | O(1) | 仅维护少数变量，不需要递归或额外的数据结构。 |

 即使对于最大的输入，时间复杂度也很容易满足 1 秒的限制，并且内存使用量也很少。

 ## 边缘情况

 用于输入`-5 -3 2`，两个数字都是非正数。 该算法检测到`y <= 0`和`m > 0`在开始并打印`-1`。 用于输入`1 0 2`，循环替换`x`和`1+0=1`，交换，然后再次替换`1+1=2`达到`m`。 正确计算的最小操作数为 2。每个边缘情况都确认初始检查和循环不变量足以保证正确性。
