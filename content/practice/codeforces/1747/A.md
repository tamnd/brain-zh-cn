 ## 解决方案
 ## 问题理解

 给定一个整数序列，我们必须将其分成两个不相交的组。 每个元素必须恰好属于一个组，并且两个组都允许为空。 

一旦分割确定，我们就计算每组的总和。 然后我们取每个和的绝对值并查看这两个量值之间的差异。 目标是在所有可能的分区上最大化这种差异。 

关键的困难在于，我们优化的不是简单的线性和，而是绝对值的差，这使得目标对正数和负数在两组之间的分布非常敏感。 

约束条件很大，最多可达\(2 \cdot 10^4\)测试用例和总数组长度可达\(2 \cdot 10^5\)。 这立即排除了任何二次或子集枚举方法。 任何解决方案都必须在线性时间内处理每个测试用例。 

一个常见的陷阱来自于过于字面地解释表达式并试图将元素贪婪地分配给两个连续的和。 当混合符号时，这通常会失败。 

例如，考虑一个天真的想法，尝试通过始终将下一个元素放入当前较小的绝对和组来平衡总和。 输入时```
[10, -10]
```即使最佳答案很明显，这也可能根据订单和领带处理而表现不一致\(0\)。 

表达式的结构表明，只有正数和负数的总贡献很重要，而不是将它们排列成两个任意集合。 

## 方法

 暴力解决方案将枚举所有\(2^n\)将元素分配到两个组中。 对于每项作业，我们计算两组总和并评估目标。 这是正确的，但呈指数增长，甚至对于\(n = 30\)。 

关键的简化来自于根据总和以及我们如何划分符号来重写目标。 

令总和为\(S = \sum a_i\)。 任何分区对应于选择一个子集\(A\)为了\(s_1\)，其余的形成\(s_2\)。 然后$$
s_1 = \sum_{i \in A} a_i, \quad s_2 = S - s_1.
$$所以目标就变成了$$
|s_1| - |S - s_1|.
$$现在观察这个表达式仅取决于多远\(s_1\)来自\(S/2\)，但受到以下事实的限制\(s_1\)是任意有符号值的子集和。 

我们没有对分区进行推理，而是将正贡献和负贡献分开。 让$$
P = \sum_{a_i > 0} a_i, \quad N = \sum_{a_i < 0} a_i.
$$最佳策略是将所有正数分组为一组，将所有负数分组为另一组，因为在同一组中混合符号只会减少绝对大小。 

然后我们比较两种极端的配置：
 将所有数字归为一组，或按符号拆分。 

如果所有内容都在一组中，则值为$$
|S| - 0 = |P + N|.
$$如果我们将正数和负数分开：$$
|P| - |N|.
$$自从\(P \ge 0\)和\(N \le 0\)，这变成了$$
P - (-N) = P + |N|.
$$所以答案就是以下的最大值：$$
|P + N| \quad \text{and} \quad P + |N|.
$$但\(P + |N| = \sum |a_i|\)， 尽管\(|P + N|\)至多是\(\sum |a_i|\)，所以第二种情况总是占主导地位或匹配。 因此最优值为：$$
\sum |a_i|.
$$这将整个问题简化为对绝对值求和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力 | \(O(2^n)\) | \(O(n)\) | 太慢了|
 | 最佳 | \(O(n)\) | \(O(1)\) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取整数数组。 我们还没有尝试任何划分，因为目标的结构允许直接简化。 

2. 计算每个元素的绝对值并累加它们的总和。 这对应于将每个元素视为对目标贡献其最大可能的大小，而不管符号如何。 

3. 输出该总和作为测试用例的答案。 

### 为什么它有效

 目标奖励最大化两组总和的大小之间的距离。 任何元素至少对一侧有积极贡献，并且以减少积极和消极贡献之间抵消的方式分配它只会降低可实现的幅度。 最佳配置将每个元素的贡献隔离为绝对幅度形式，这是在组内没有发生取消时实现的。 这直接导致绝对值之和作为全局最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        out.append(str(sum(abs(x) for x in a)))
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```实现很简单：每个测试用例都是独立处理的，我们避免存储不必要的中间结构。 唯一的微妙之处是确保快速输入和批处理输出，因为循环内的 Python 字符串打印可能会变慢\(2 \cdot 10^4\)测试用例。

 ## 边缘情况

 对于完全由零组成的数组，每个分区在两组中产生的总和为零，并且该算法正确返回零，因为所有绝对值都为零。 对于单元素数组，答案等于该元素的绝对值，因为它完全确定一组总和。 对于交替较大的正值和负值，解保持稳定，因为每个元素都是通过绝对累加独立处理的，从而防止任何抵消效应影响结果。
