 ## 解决方案
 ## 问题理解

 我们被要求确定在正整数数组上进行的两人游戏中的获胜者。 爱丽丝先行动。 每回合，玩家都会检查数组的第一个元素。 如果为零，则玩家立即失败。 否则，玩家从第二个元素开始选择数组中的一个位置，将第一个元素减一，然后与所选元素交换。 游戏交替继续，直到玩家无法移动，这恰好发生在第一个元素变为零时。 

输入由多个测试用例组成。 每个测试用例都提供数组的大小和数组元素。 如果双方都发挥最佳，输出就是每场比赛的获胜者。 

约束条件允许`n`达到 100,000 并且总和`n`所有测试用例达到20万个。 任何尝试模拟每个单独动作的解决方案都可以轻松执行以下顺序：`10^9`如果数组元素很大，则在最坏的情况下进行操作。 这排除了简单的模拟。 我们需要一种方法来直接计算获胜者，每个测试用例使用少量操作，最好是 O(n)。 

在第一个元素不是最大的数组中会出现一个重要的微妙之处。 例如，考虑`[1, 10]`。 一种幼稚的方法可能会假设减少`a_1`一个总是有利于第一个玩家，但在这里，如果处理不当，第二个大元素会让第一个玩家创建一个失败的位置。 所有元素相等的数组、第一个元素为最小或最大的数组以及大小为 2 的数组都具有稍微不同的动态，必须一致地处理。 

## 方法

 蛮力方法会模拟每一个动作。 在每一轮，我们都会迭代所有可能的索引`i >= 2`，递减第一个元素，交换它，并递归地确定获胜者。 这种做法是正确的，但不可行。 对于大小的数组`n = 10^5`和`a_1 = 10^9`，模拟将需要比允许的更多的操作。 

关键的见解来自于观察第一个元素的作用。 任何转弯都会减少`a_1`一个。 其他元素的位置仅在它们最终移动到前面时才重要。 如果`a_1`是数组中最小的元素，要移动的玩家将被迫首先将其减少到零，从而使下一个玩家处于获胜位置。 相反，如果`a_1`不是最小的，玩家可以将更大的元素交换到前面，有效地将第一个元素的负担“传递给”对手。 

由此，我们看到结果主要取决于将第一个元素与数组的其余部分进行比较。 如果`a_1`严格大于其余的总和，则第一个玩家可以强行获胜。 如果`a_1`最小，第一个玩家就输了。 对于大小为 2 的数组，获胜者仅由两个元素之间的差异奇偶性决定。 捕获所有情况的精确公式是检查第一个元素是否严格大于其余元素的最大值； 如果是这样，爱丽丝立即获胜； 否则，获胜者取决于将所有元素减少到零所需的移动总数的奇偶性。

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读`n`和数组`a`。 
2. 计算所有数组元素的总和并确定最大元素。 
3. 检查最大元素是否等于第一个元素。 如果`a_1`严格地说，是最大的元素，爱丽丝总是可以用较小的元素交换它，并有策略地减少它以强制获胜。 否则，要移动的玩家将面临最小元素在前面的情况，并且将被迫首先将其减少到零。 
4. 计算总移动次数，等于所有元素的总和。 如果总数为奇数，则爱丽丝获胜； 如果相等，鲍勃获胜。 这是有效的，因为每次移动都会使总和恰好减少 1，因此奇偶性决定了谁进行了最后一步。 
5. 输出测试用例的获胜者。 

为什么有效：该算法依赖于每次移动都会严格将数组的总和减一的不变量。 被迫将最终非零元素减少到零的玩家失败。 通过跟踪总和奇偶校验，我们抽象出了各个交换，因为交换不能阻止第一个元素最终被减少。 比较`a_1`与数组的其余部分一起确保我们捕获第一个元素占主导地位的边缘情况并允许对游戏进行战略控制。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total = sum(a)
        max_val = max(a)
        if max_val > total - max_val:
            print("Alice")
        elif total % 2 == 1:
            print("Alice")
        else:
            print("Bob")

if __name__ == "__main__":
    main()
```该解决方案首先计算数组的总和并确定最大元素。 如果最大元素严格大于剩余元素之和，Alice 总能确保第一个元素在她的回合中永远不为零，从而保证胜利。 否则，我们依赖于移动总和的奇偶性：奇数总计为 Alice 提供最后一步，偶数总计为 Bob 提供最后一步。 这可以处理任何长度和值的数组，避免直接模拟。

 ## 边缘情况

 对于数组`[1,1]`，Alice 无法避免将最后一个非零元素留给 Bob。 总和是 2，偶数，所以鲍勃赢了。 为了`[1000000000,1]`，第一个元素在总和中占主导地位，因此爱丽丝可以减少它并交换以始终防止鲍勃有获胜的举动。 所有元素都相等的数组测试奇偶校验逻辑：如果总和为奇数，则爱丽丝获胜；如果总和为奇数，则爱丽丝获胜。 如果相等，鲍勃获胜。 这些边缘情况证实最大比较和总和奇偶校验捕获了游戏中的完整场景集。
