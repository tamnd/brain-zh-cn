 ## 解决方案
 ## 问题理解

 我们得到两个长度相等的字符串，由 20 个字母组成的小字母表组成。 我们从字符串 A 开始，希望使用特定操作将其转换为字符串 B。 

一个操作的工作方式如下：选择一个字母 x。 查看 A 中当前等于 x 的所有位置，并选择这些位置的任意子集。 然后将所有选定的位置重新着色为某个字母 y。 关键限制是您只能对当前具有相同字母 x 的位置进行操作，但在这些位置中您可以自由选择任何子集。 

任务是计算使 A 完全等于 B 所需的最少此类操作数，或者确定这是不可能的。 

重要的结构特征是，除了共享相同当前字母的位置可以在一次移动中一起修改这一事实之外，每个位置都是独立发展的。 这会在位置之间产生耦合，这种耦合很容易被忽视：更改一个字母的一次出现可能会同时影响许多位置，但将它们分成不同的未来行为就是成本出现的地方。 

约束条件很大，测试用例的总长度高达 100000 个。 任何尝试模拟每个位置的转换或搜索每个字符的操作序列的解决方案都会太慢。 解决方案必须将问题简化为对 20 个字母字母表进行简单计数。 

当多个位置共享相同的源字母但需要不同的目标字母时，会出现微妙的边缘情况。 一种简单的方法可能会假设每个位置的成本都是独立的，从而导致不匹配或每个位置最短路径的计数，但这忽略了在共享同一当前字母的多个位置之间重用一个操作的能力。 例如，如果 A 是“aab”，B 是“bcc”，则每个位置策略会建议 3 次移动，但最佳重用首先通过同时处理两个“a”位置来给出 2 次移动。 

另一个常见的陷阱是假设这只是字母上的最短路径问题。 这种解释失败了，因为操作不会独立影响单个标记； 它们同时影响相同字母的整个子集，为每个源字母创建共享结构。 

## 方法

 蛮力的想法是直接模拟操作。 在每一步中，我们都会选择当前字符串中存在的字母 x，选择其位置的子集，并尝试所有可能的目标字母 y。 这导致了一个巨大的分支因子：每个状态都有指数级的子集选择和 y 的 20 个选择。 即使我们压缩状态，可能的字符串配置的数量也是天文数字，即使对于很小的n，探索也是不可行的。 

关键的观察结果是，职位仅通过当前字母进行交互。 当前持有相同字母的所有仓位从有效操作的角度来看是无法区分的。 重要的不是各个位置，而是每个源字母最终必须到达多少个不同的目标字母。 

修复 A 中的字母 x。考虑 A[i] = x 的所有位置。 在这些位置中，B 分配了一些目标字母集。 例如，假设这些目标是 {b, c, d}。 我们最终必须将 x 组拆分为子组，最终形成这些不同的字母。 

每次我们执行涉及字母 x 的移动时，我们都可以将选定的 x 位置子集分配给新字母。 然而，一旦我们将 x 拆分为不同的字母，这些生成的字母就不再是 x 组的一部分，因此以后对 x 的操作不会影响它们。 这意味着每个不同的目标字母实际上至少要花费 x 的一个“分支动作”。

有一个微妙的节省：如果 x 本身是其目标之一，我们可以将 x 视为自然的“基状态”，并避免显式地花费一步来保留它。 所有其他目标字母都需要远离 x 的一个转换步骤。 因此，每个字母 x 的成本纯粹取决于 A 具有 x 的位置中 B 中出现的不同字母的数量。 

不再链或中间转换会降低此成本，因为任何中间转换仍然会消耗一个操作，并且不会帮助 x 的不同分支合并回一起。 

因此，问题简化为按初始字符对位置进行分组，并计算每个组需要多少个不同的目标字符。

 | --- | --- | --- | --- |
 | 暴力模拟操作 | 指数| 指数| 太慢了|
 | 计算每个字母组的不同目标 | O(n + 20²) | O(20²) | 已接受 |

 ## 算法演练

 我们独立处理每个测试用例。 

1. 对于字母表中的每个字母 x，收集所有字母 B[i]，使得 A[i] = x。 

这构建了从每个源字母到所需目标字母集的映射。 
2. 对于每个字母 x，计算其集合 S 中不同目标字母的数量。 

这表示从 x 开始的组必须分裂成多少个不同的最终状态。 
3. 如果S 为空，则x 不会出现在A 中并且没有任何贡献。 
4. 否则，如果x本身在S中，则目标之一已经是原始字母。 我们可以保留该子集，而无需花费额外的步骤。 贡献是|S| − 1.
 5. 如果 x 不在 S 中，则每个目标都需要与 x 进行单独的转换，因此贡献为 |S|。 
6. 将所有字母 x 的贡献相加以获得答案。 

### 为什么它有效

 每个源字母都定义了一个独立的位置池，只有在保留该字母时才能一起执行这些位置。 这些位置中的每个不同的目标字母都会迫使该池中发生至少一个分离事件。 由于一旦子集离开 x，它就不会重新进入，因此这些分隔不能在不同的目标字母之间重复使用。 唯一的例外是保留 x 本身，它不需要任何操作，当 x 位于其自己的目标中时，有效地将所需的分离次数减少 1。 这一不变量（即每个目标字母恰好对应于其源组中的一个必要分支）完全确定了最小移动次数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input().strip())
        A = input().strip()
        B = input().strip()

        targets = [set() for _ in range(20)]

        for i in range(n):
            x = ord(A[i]) - 97
            y = ord(B[i]) - 97
            targets[x].add(y)

        ans = 0
        for x in range(20):
            if not targets[x]:
                continue
            k = len(targets[x])
            if x in targets[x]:
                ans += k - 1
            else:
                ans += k

        print(ans)

if __name__ == "__main__":
    solve()
```该代码为每个字母构建一组所需的目标字母。 集合很小，因为字母表大小固定为 20，因此即使对于较大的 n，这也是有效的。 

最后的循环应用上面导出的规则：每个源字母贡献其目标集的大小，或者如果它包含其自身，则贡献较少的大小。 结果是对所有字母进行累加。

 ## 边缘情况

 如果 A 已经等于 B，则每个目标集 S[x] 要么为空，要么仅包含 x。 对于这些字母，贡献变为零，因为 k = 1 且 x ∈ S[x]，因此 k − 1 = 0。算法正确返回 0。 

如果 A 中的某个字母从未出现，则它的集合保持为空并且没有任何贡献，这避免了答案的意外膨胀。 

如果一个字母的所有出现都映射到一个不同的字母，则成本恰好为 1，这反映出整个组可以在一次操作中重新着色，而不管大小。 

这些案例证实，分组逻辑在简并和完全混合的配置中表现一致。
