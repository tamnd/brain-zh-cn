 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，并要求计算有多少个索引的四元组$(i, j, k, l)$满足两者$i < j < k < l$和$a[i] = a[k]$,$a[j] = a[l]$。 换句话说，我们想要两对匹配值，其中第一和第三位置保持相同的值，第二和第四位置保持相同的值，并且索引严格递增。 

输入提供多个测试用例。 对于每个测试用例，我们首先读取数组的大小$n$然后是数组本身。 我们保证所有的总和$n$跨测试用例不超过 3000。这意味着任何算法的运行时间大约为$O(n^2)$每个测试用例的时间应该足够快，但任何事情$O(n^3)$或者更糟糕的是，在最坏的情况下可能会超时。 

简单的实现可能会尝试使用四个嵌套循环来枚举所有四元组。 这是正确的，但非常慢：最坏情况下的操作计数约为$n^4$，其顺序为$8 \times 10^{13}$操作如果$n = 3000$，显然不可行。 

简单的解决方案可能会错过的边缘情况包括所有元素都相等的数组。 例如，如果数组是$[2, 2, 2, 2, 2]$，四个指数的每种组合都是有效的。 另一个微妙的情况是某些值仅出现一次或两次； 该算法必须正确地跳过无法形成有效对的组合。 

## 方法

 蛮力解决方案很简单：迭代所有四元组$(i, j, k, l)$有四个嵌套循环并检查相等条件。 这在理论上是可行的，因为它直接实现了定义，但它是不切实际的，因为它具有时间复杂度$O(n^4)$。 

允许更快解决方案的关键观察是认识到对于固定的$j$和$k$，我们可以有效地计算出合适的数量$i$和$l$指数。 具体来说，如果我们修复中间的两个索引$j$和$k$, 有效数量$i < j$这样$a[i] = a[k]$只是之前该值的计数$j$，以及有效的数量$l > k$这样$a[j] = a[l]$是该值之后的计数$k$。 将这两个计数相乘得出四元组的数量$j, k$一对。 这将问题减少到$O(n^2)$，这对于$n \le 3000$。 

这种方法之所以有效，是因为问题围绕中间索引对称：外部值仅取决于之前的值$j$以及之后$k$，允许我们预先计算前缀和后缀计数以避免重复计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^4) | O(n^4) | O(1) | O(1) | 太慢了 |
 | 前缀/后缀计数 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和数组$a$。 我们将独立处理每个数组。 
2. 初始化一个变量来累积答案。 
3. 迭代$j$从索引 1 到$n-2$和$k$从$j+1$到$n-1$。 这些代表四元组中中间的两个索引。 
4. 对于每对$(j, k)$, 计算索引的数量$i < j$在哪里$a[i] = a[k]$。 这可以通过迭代第一个来完成$j$元素并检查相等性。 
5. 统计索引数量$l > k$在哪里$a[l] = a[j]$。 这是通过迭代来完成的$k+1$到$n-1$并检查平等性。 
6. 将这两个计数相乘即可得到该特定四元组的数量$(j, k)$组合，并将其添加到累积答案中。 
7. 迭代完所有之后$(j, k)$对，输出测试用例的答案。 

为什么有效：在每一步，算法都会显式地计算有效值$i$前$j$并且有效$l$后$k$。 将这些计数相乘可确保有效外部索引的所有组合仅被考虑一次。 自从$j < k$被强制执行，所有四元组都满足$i < j < k < l$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    ans = 0
    for j in range(1, n - 2 + 1):
        for k in range(j + 1, n - 1):
            count_i = 0
            for i in range(j):
                if a[i] == a[k]:
                    count_i += 1
            count_l = 0
            for l in range(k + 1, n):
                if a[l] == a[j]:
                    count_l += 1
            ans += count_i * count_l
    print(ans)
```该代码读取测试用例的数量并单独处理每个测试用例。 对于每个$(j, k)$对，数数有多少$i$满足$a[i] = a[k]$以及有多少$l$满足$a[l] = a[j]$。 将这些计数相乘即可得出该对贡献的四元组的数量。 仔细选择范围可确保$i < j < k < l$，并且所有循环都通过正确使用 Python 的基于 0 的索引来避免差一错误。
