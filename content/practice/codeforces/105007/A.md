 ## 解决方案
 ## 问题理解

 该网格描述了一个由矩形单元格布局的狗公园。 每个单元格要么是空的，用点标记，要么包含 1 到 9 之间的单个数字，代表狗在该位置的身高。 在公园里的所有狗中，只有一只具有最大的高度，任务是定位它的位置并使用从 1 开始的索引报告它的行和列。 

输入比普通列表稍微多一些的原因是数据是空间的。 我们不仅提取最大值，还跟踪它在 2D 结构内出现的位置。 因此，输出不是值本身，而是包含最大数字的单元格的坐标。 

约束很小，两个维度都达到 100。这意味着最多存在 10,000 个单元。 任何扫描每个单元格恒定次数的解决方案都足够快。 即使是对网格进行简单的全面扫描也在一定范围内，而任何试图变得比必要的更聪明的事情都不会获得任何有意义的性能优势。 

一个微妙的错误通常来自输入解析。 每行都是一串字符，而不是空格分隔的值。 将其视为整数列表或错误地分割可能会移动列或合并行，从而产生不正确的坐标。 另一个常见问题是忘记答案必须基于 1，因为编程语言通常从 0 开始索引。 

这里重要的边缘情况主要是结构性的而不是算法性的。 大小为 1×1 的网格是有效的，并且必须返回 (1, 1)。 所有狗除了一个最大值之外都具有相同高度的网格保证是唯一的，但是粗心的实现将答案更新为“大于或等于”而不是严格大于可能会错误地覆盖遇到的第一个最大值。 包含许多点和一个数字的网格还可以测试解析是否正确跳过非狗单元格。 

## 方法

 最直接的方法是扫描网格中的每个单元格，检查它是否包含数字。 如果确实如此，我们会将其与迄今为止看到的最佳高度进行比较，并在出现较大值时更新我们存储的最佳值和坐标。 这是可行的，因为网格很小并且每个单元格都被检查一次。 

暴力变体在概念上会尝试每个单元格作为候选答案，然后再次扫描整个网格以验证它是否是最大值。 这将涉及比较每对单元，在最坏的情况下导致大约 O((NM)^2) 操作。 当 N 和 M 达到 100 时，这是不必要的开销，并且在问题的更受约束的版本中存在效率低下的风险。 

关键的观察结果是，该问题仅需要具有位置跟踪的一组有限值的全局最大值。 单元之间没有依赖性，没有顺序约束，也不需要预处理。 这将任务简化为单遍累积问题：在遍历网格一次的同时保持迄今为止看到的最好结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力配对检查 | O((NM)^2) | O((NM)^2) | O(1) | O(1) | 太慢了 |
 | 单程扫描| O(NM) | O(1) | O(1) | 已接受 |

 ## 算法演练

1.读取维度N和M，然后将网格逐行读取为字符串。 这保留了空间结构，以便每个字符恰好对应于网格中的一个单元格。 
2. 初始化一个变量来存储迄今为止找到的最大高度。 将其设置为低于可能的最小数字，以便任何有效的狗会立即替换它。 
3. 初始化两个变量来存储迄今为止找到的最佳位置的坐标。 
4. 从 0 到 N−1 迭代每行索引 i。 
5. 在每行内，从 0 到 M−1 迭代每个列索引 j。 
6. 如果当前单元格包含数字而不是点，则将其转换为整数并与当前最大值进行比较。 如果更大，则更新最大值，并将(i,j)记录为新的最佳位置。 
7. 扫描完所有单元格后，使用从 1 开始的索引输出存储的坐标。 

我们仅在看到严格更大的值时才进行更新的原因与保证最高的狗是唯一的有关。 这确保了我们永远不需要打破平局的逻辑； 第一次出现的最大值是正确的并且保持稳定。 

### 为什么它有效

 在扫描的每一步，算法都保持不变，即存储的位置对应于迄今为止处理的网格部分中遇到的最高的狗。 由于每个单元格都被访问一次并且比较相对于高度是单调的，因此这个不变量保证了一旦处理完整个网格，存储的位置必须对应于全局最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    
    best_val = -1
    best_i = 0
    best_j = 0

    for i in range(n):
        row = input().strip()
        for j in range(m):
            c = row[j]
            if c != '.':
                val = ord(c) - ord('0')
                if val > best_val:
                    best_val = val
                    best_i = i
                    best_j = j

    print(best_i + 1, best_j + 1)

if __name__ == "__main__":
    solve()
```该解决方案依赖于对网格的单次传递。 转换`ord(c) - ord('0')`避免较慢的整数解析并且是安全的，因为输入保证单位数字。 坐标在计算期间以基于 0 的索引存储，并仅在输出时转换为基于 1 的索引，从而防止更新期间出现偏一错误。 

一个常见的实现错误是在检查值是否严格更大之前更新坐标，或者使用`>=`而不是`>`。 这会错误地覆盖先前出现的最大值，这是不必要的，并且可能会使正确性推理变得复杂。 另一个微妙的问题是忘记从每行中删除换行符，这可能会改变索引或引入无效字符。

 ## 边缘情况

 1×1 网格是最简单的结构。 该算法将最佳值初始化为低于任何有效数字，因此会立即选择单个单元格并将其返回为 (1, 1)。 没有任何迭代可能会错误地覆盖此结果。 

最大值出现在第一个单元格的网格测试后面的比较是否错误地替换了已经最优的答案。 因为更新仅发生在严格更大的值上，所以一旦存储了第一个最大值，它就保持不变，除非出现更大的值，而这在正确的输入中不会发生。 

大部分由点填充的网格可确保安全地忽略非数字字符。 扫描只是跳过这些单元格，保持最佳值不变，直到遇到数字。
