 ## 解决方案
 ## 问题理解

 我们给出了一个起始整数和一个目标整数。 从起始值开始，我们可以重复应用两种变换之一：如果当前值是偶数，我们可以将其替换为自身的三半，如果该值大于一，我们可以将其减一。 我们可以以任意顺序和任意次数应用这些操作，并且我们想知道最终是否有可能准确达到目标值。 

关键的困难在于，根据奇偶校验，操作的行为会有很大不同。 除了 1 之外，“减一”操作始终可用，并且它允许完全控制逐步达到任何较小的数字。 “乘以三半”运算仅适用于偶数，它可以快速增加值，但只能沿着有限的整数子集。 确定性减量和条件增长操作之间的相互作用以简单的方式创建了一个不单调的状态空间。 

每个测试用例都是独立的，并且两个数字都可以大到十亿。 这立即排除了任何试图模拟所有可能状态的搜索策略。 即使是适度的分支因子也会爆炸，因为在多达 10,000 个测试用例上重复分支将使任何整数上的 BFS 或 DFS 都不可行。 

一种幼稚的方法可能会尝试将此视为图可达性问题并从 x 运行 BFS。 这会失败，因为转换可能会无限地增加值，因此状态空间甚至不是明显有限的。 例如，从 2 开始，我们可以转到 3，然后回到 2，然后再回到 3，依此类推，形成一个循环，除非仔细限制，否则朴素的 BFS 将无限期地探索该循环。 

另一个微妙的问题是“乘以 3/2”运算在简单的整数保留方式中是不可逆的。 如果我们尝试将过程从 y 反转到 x，我们就会面临歧义：许多值可以在不同路径下映射到同一目标，但并非所有值都是整数约束下的有效前驱。 

正确的解决方案依赖于这样的观察：结构受到足够的控制，使得从 y 进行贪婪的向后推理是可能的，但前提是我们了解何时增长是有利的以及何时递减占主导地位。 

## 方法

 强力方法将每个整数建模为节点，并将转换建模为边。 从 x 开始，我们将在适用的情况下尝试这两种操作并搜索 y。 每个节点最多可以生成两个邻居，并且值可以增加，这意味着如果没有更深入的了解，我们无法严格限制搜索空间。 即使我们人为地将值限制为 max(x, y) 的几倍，病态情况仍然会强制执行 + 和 - 操作的长交替序列。 这使得暴力方法在实践中有效地呈指数增长。 

关键的见解是扭转观点。 我们不是将 x 向前推，而是问如何从先前的状态获得 y。 减量操作相反变为“+1”，始终有效。 乘法运算变成“除以 1.5”，但前提是结果值为整数并且满足前向条件（均匀性）。 这立即极大地限制了向后分支：大多数数字最多只有一个有效的乘法前驱。 

然而，直接从 y 向后模拟仍然很尴尬，因为向前方向的递减允许任意微调，这意味着系统不是纯粹的乘法。 关键的结构观察是，减量使我们能够在低于我们选择的任何“峰值”的整数之间完全可达，而乘法运算是显着向上跳跃的唯一方法。 因此，问题简化为检查我们是否可以达到 y 位于由 x 的受控向上扩展生成的可达区间内的状态。

一种更具操作性的方法是从 x 向前模拟，但要积极修剪：每当值超过 y 时，只有递减是有用的，因为进一步的乘法只会进一步增加它。 因此，唯一有意义的向上转变是那些不超过 y 太多的转变，一旦超过 y，我们只能减少。 这将问题转换为有界可达性过程，该过程相对于 y 的距离是单调的。 

因此，我们可以运行受控搜索，当它使我们保持在有效范围内时，我们重复应用乘法，否则依赖于 y 的递减。 状态空间变小，因为任何大于大约 2y 的数字都是无用的，因为即使重复除以 1.5 也无法在不经过一长串已经相当于直接调整的减量的情况下有效地将其恢复回来。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 状态上的强力 BFS | O(exp) | O(exp) | 太慢了|
 | 通过剪枝进行受控正向模拟 | 每次测试摊销 | O(log max(x, y)) O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每个测试用例并模拟从 x 到 y 的受控转换。 

1. 如果x已经等于y，我们立即返回YES，因为不需要任何操作。 
2、如果x大于y，我们只需要使用减操作即可。 由于我们可以重复减一，所以直到 y 的每个整数都是可达的，所以我们返回 YES。 
3. 如果 x 小于 y，只要有利，我们就会尝试使用乘法运算使 x 向 y 方向增长。 
4. 当x严格小于y时，我们检查x是否是偶数。 如果是，我们计算应用乘法运算的结果。 如果该结果没有过于激进地超出 y，我们就应用它； 否则，我们会通过反向推理（在正向模拟中对应于重复的结构缩减）回退到向 y 递增。 
5.如果x是奇数并且小于y，我们应用精神上唯一可用的前向操作，该操作从更高的构造状态递减； 在实现方面，我们依赖于这样一个事实：奇数状态必须来自递减序列，因此我们通过增量调整向最接近的偶数结构移动。 
6. 我们继续下去，直到 x 达到 y，或者我们确定进一步的乘法只会导致远离 y，而无法进行校正。 

关键的指导原则是递减给出了向下的完全连通性，因此唯一重要的决定是我们是否可以生成一系列乘法展开序列，该序列恰好落在 y 上或穿过可通过递减到达 y 的区域。 

### 为什么它有效

 该系统具有方向不对称性：减量允许在任何相邻整数之间移动，而乘法仅对偶数进行运算并扩展状态空间。 任何操作序列都可以重新排列，以便所有乘法步骤发生在最后的递减块之前，而不会改变可达性。 这是因为减量操作永远不会带来新的乘法机会，而这在以前是不可能的，而且会使排序无效。 因此，我们只需要确定是否可以使用乘法从 x 得到某个中间值 x'，使得 x' ≥ y 且 x' 可以约简为 y。 由于 y 以上的所有整数都可以达到 y，因此问题简化为检查我们是否可以使用允许的乘法转换达到任何值 ≥ y。 这将搜索减少到一个小的有界扩展过程。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x, y = map(int, input().split())

        if x >= y:
            print("YES")
            continue

        # work forward from x while possible
        seen = set()
        stack = [x]

        ok = False

        while stack:
            v = stack.pop()
            if v == y:
                ok = True
                break
            if v > y * 2:
                continue
            if v in seen:
                continue
            seen.add(v)

            # operation 1: if even, 3v/2
            if v % 2 == 0:
                stack.append(v * 3 // 2)

            # operation 2: v - 1
            if v > 1:
                stack.append(v - 1)

        print("YES" if ok else "NO")

if __name__ == "__main__":
    solve()
```该代码从 x 执行有界 DFS，同时修剪相对于 y 变得太大的值。 条件`v > 2*y`确保我们不会探索乘法增长在没有过多线性递减序列的情况下不可能返回的区域。 访问集可防止状态 2 和 3 之间的循环。 

这两个转换直接对允许的操作进行编码。 终止条件检查探索期间是否达到 y。

 ## 边缘情况

 关键的边缘情况是 x 已经大于 y 时。 该算法立即返回 YES，因为重复递减始终允许精确下降。 例如，输入`10 3`可以简单地通过七个递减来求解，并且算法在初始比较检查中捕获了这一点。 

另一种边缘情况是 x = 1 时。从 1 开始，唯一可能的移动实际上受到限制，因为无法应用乘法。 如果 y 大于 1，我们必须完全依赖其他路径的前向增长，这是不可能从 1 开始的。算法正确地处理了这个问题，因为 BFS 永远不会从 1 生成大于 1 的值。 

第三种情况是重复乘法在 y 周围振荡而没有精确命中它。 例如，从 2 开始，我们得到 3，然后在不递减的情况下无法返回到 2，并且仔细跟踪可确保我们不会由于访问集而在 2 和 3 之间无限循环。
