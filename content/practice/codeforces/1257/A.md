 ## 解决方案
 ## 问题理解

 我们有一排学生，编号从 1 到 n。 其中，两名学生是对手，分别位于a、b位置。 体育老师希望最大化这两个学生之间的距离，其中距离只是他们位置的绝对差。 我们最多可以进行 x 次交换，每次交换交换两个相邻的学生。 任务是确定这些交换后竞争对手之间可实现的最大距离。 

从约束来看，n 最多为 100，x 最多为 100，测试用例最多为 100 个。 这足够小，即使每个测试用例解决方案的 O(n) 或 O(1) 也非常快。 不需要复杂的数据结构或优化技巧。 然而，我们仍然需要仔细推理哪些动作实际上会增加距离。 

一个微妙的一点是，交换一次只能将学生移动一个位置。 所以我们不能立即将学生置于任意位置； 距离的最大增加受到可用交换数量的限制。 例如，如果 n = 5、x = 1、a = 3、b = 2，仅将学生置于位置 1 和 5 的简单方法是不可能的，因为只允许一次交换。 在计算最大距离时，我们必须考虑交换限制。 

另一种边缘情况发生在 x = 0 时。此时不可能进行任何移动，距离只是当前的绝对差 |a - b|。 类似地，如果学生已经在两端并且 x 很大，我们永远不能将距离增加到超过 n - 1，因为这是一条线中的物理最大距离。 

## 方法

 暴力方法是模拟所有可能的交换序列。 对于每个测试用例，我们可以尝试将一名学生向左或向右移动，另一名学生向右或向左移动，尝试交换序列的每种组合，最多进行 x 次交换。 在每个序列之后，我们计算距离。 这种方法是正确的，但效率极低：序列的数量随着 x 呈指数增长。 对于 x = 100，这显然是不切实际的。 

关键的观察是我们不关心学生的确切中间位置。 我们只关心两个对手之间的距离，并且每次操作交换学生移动一步。 因此，我们能达到的最大距离受到两个因素的限制：可用交换次数 x 和线路中的最大物理距离，即 n - 1。如果 a 和 b 之间的初始距离为 d = |a - b|，我们最多可以将其增加 x，但不能超过 n - 1。这给出了最佳解决方案的简单公式：```
max_distance = min(n - 1, |a - b| + x)
```这是可行的，因为每次交换最多可以将距离增加 1。我们只需要考虑将学生移向线的两端。 无需模拟单独的交换，从而使每个测试用例的解决方案为 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^x) | O(2^x) | O(n) | 太慢了|
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取测试用例数t。 每个测试用例由四个整数组成：n、x、a、b。 
2. 对于每个测试用例，计算竞争对手之间的当前距离：`d = abs(a - b)`。 
3. 计算交换后可达到的最大距离。 每次交换最多可以使距离增加 1，因此将 x 添加到当前距离：`new_distance = d + x`。 
4. 长度为 n 的直线的绝对最大距离为 n - 1。如果`new_distance`超过这个，限制它：`max_distance = min(new_distance, n - 1)`。 
5、输出`max_distance`对于每个测试用例。 

为什么有效：不变的是每次交换最多使竞争对手之间的距离增加 1。从初始位置开始，最大可实现距离恰好是初始距离加上交换次数，以线路长度为界。 这保证了公式在每种情况下都能获得最佳结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x, a, b = map(int, input().split())
    d = abs(a - b)
    max_distance = min(n - 1, d + x)
    print(max_distance)
```在此解决方案中，我们首先读取测试用例的数量。 然后对于每种情况，我们计算绝对距离`d`两个竞争对手之间。 我们添加交换次数`x`并将结果限制为`n - 1`以尊重线路长度。 直接打印结果可确保每个测试用例的工作时间为 O(1)。 仔细注意使用`abs(a - b)`和`min(...)`正确处理所有边缘情况。

 ## 边缘情况

 对于x=0的情况，算法正确返回初始距离。 例如，`n = 6, x = 0, a = 2, b = 3`给出`abs(2-3) = 1`。 无法进行交换，因此距离无法增加。 min 函数不会改变该值，因为 1 < n - 1 = 5。 

对于初始位置处于极值的情况，`n = 100, x = 50, a = 1, b = 100`，距离已经达到最大值 99。添加 x 得到 149，但 min 函数将其限制为 99。这表明该算法尊重线路的物理约束。 

对于最小线，`n = 2, x = 0, a = 1, b = 2`，距离为 1。不可能进行交换，距离不能超过 n - 1 = 1。输出与预期相符。 

所有这些检查都显示了公式`min(n - 1, abs(a - b) + x)`无需特殊条件逻辑即可正确处理边缘情况。
