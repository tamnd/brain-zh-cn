 ## 解决方案
 ## 问题理解

 我们得到一个由字符“0”、“1”和“?”组成的字符串以及两个整数`a`和`b`表示最终字符串必须包含的“0”和“1”的总数。 任务是替换每个“？” 使用“0”或“1”，使得字符串成为回文，同时与计数完全匹配`a`和`b`。 回文要求字符串向前和向后读取相同的内容，因此位置上的每个字符`i`必须与位置处的字符匹配`n-i-1`。 

该问题同时结合了两个约束：保持回文性质并匹配“0”和“1”的精确计数。 所有测试用例的字符串长度最多可达200​​,000，测试用例数量可达10,000。 这意味着我们的解决方案必须以每个字符串的线性时间运行，因为二次或强力方法会涉及太多操作。 

当存在冲突的固定字符时，就会出现微妙的边缘情况（例如，索引处的“0”）`i`索引处有一个“1”`n-i-1`）或者当剩余的“0”或“1”数量不能满足“？”时 替代品。 另一个棘手的情况是奇数长度的字符串，中间字符是“？”； 该算法必须确保中间字符的分配与其余计数一致。 

## 方法

 暴力方法将枚举所有可能的“？”替换 与“0”或“1”，然后检查每个候选者的回文属性并计算正确性。 这种方法原则上是正确的，但由于每个“？”而变得不可行。 可能性的数量加倍，导致“？”数量呈指数级复杂性。 对于长度最大为 2*10^5 的字符串，这是不可能的。 

关键的见解是我们不需要尝试所有组合。 回文约束使我们能够将已知值传播到其镜像位置，从而减少“？”的数量 来填补。 具体来说，如果`s[i]`是 '？' 但`s[n-i-1]`是'0'，那么我们必须替换`s[i]`与“0”。 传播之后，我们可以检查计数是否`a`和`b`仍然是可以实现的。 然后，对于剩余的“？”对，我们可以贪婪地在镜像位置分配“0”或“1”，用完剩余的计数。 如果字符串的长度为奇数，中间的字符如果是“？”，则可以独立分配，前提是我们仍然有可用的计数。 

这种方法是线性的，因为每个位置最多被访问两次：一次用于传播，一次用于填充剩余的“？”。 每对以恒定的时间检查冲突和计数不足。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将字符串转换为字符列表以进行可变操作。 使用以下命令初始化剩余“0”和“1”的计数器`a`和`b`，减去字符串中现有“0”和“1”的计数。 
2. 将已知角色传播到其镜像位置。 对于每个索引`i`在字符串的前半部分，如果`s[i]`是 '？' 和`s[n-i-1]`不是，更换`s[i]`和`s[n-i-1]`并减少相应的计数器。 如果两个位置固定且不相等，则输出`-1`作为解决方案是不可能的。 
3. 传播后，检查是否有任何计数器变为负值。 如果是，则输出`-1`因为我们无法满足所需的计数。 
4. 填写剩余的“?”对 在字符串的前半部分。 对于每对`(i, n-i-1)`都是“？”，如果至少还有 2 个零，则分配“0”，否则如果至少有 2 个零，则分配“1”。 相应地更新计数器。 如果两者都不可能，则输出`-1`。 
5. 如果字符串长度为奇数，则单独处理中间字符。 如果是“？”，则如果剩余 1 个零，则分配“0”；如果剩余 1 个，则分配“1”。 如果没有可用的计数，则输出`-1`。 
6. 填充所有位置后，零和一的计数器应恰好为零。 如果没有，则输出`-1`。 否则，将列表连接回字符串并输出。 

工作原理：该算法保持了不变性，即在每次传播和填充步骤之后，当前的部分字符串仍然可以完成为满足计数的回文。 立即检测到冲突，防止出现无效的解决方案。 剩余 '?' 的贪婪分配 之所以有效，是因为一旦冲突解决，任何对都可以独立分配，并且可以跟踪总计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b = map(int, input().split())
        s = list(input().strip())
        n = len(s)
        possible = True

        # Step 1: initial count deduction
        a -= s.count('0')
        b -= s.count('1')

        # Step 2: propagate known characters
        for i in range(n // 2):
            j = n - i - 1
            if s[i] == '?' and s[j] != '?':
                s[i] = s[j]
                if s[i] == '0': a -= 1
                else: b -= 1
            elif s[i] != '?' and s[j] == '?':
                s[j] = s[i]
                if s[j] == '0': a -= 1
                else: b -= 1
            elif s[i] != '?' and s[j] != '?' and s[i] != s[j]:
                possible = False
                break

        if a < 0 or b < 0:
            possible = False

        # Step 3: fill remaining '?'
        for i in range(n // 2):
            j = n - i - 1
            if s[i] == '?' and s[j] == '?':
                if a >= 2:
                    s[i] = s[j] = '0'
                    a -= 2
                elif b >= 2:
                    s[i] = s[j] = '1'
                    b -= 2
                else:
                    possible = False
                    break

        # Step 4: handle middle character if odd length
        if n % 2 == 1 and s[n // 2] == '?':
            if a > 0:
                s[n // 2] = '0'
                a -= 1
            elif b > 0:
                s[n // 2] = '1'
                b -= 1
            else:
                possible = False

        if possible and a == 0 and b == 0:
            print("".join(s))
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```该解决方案首先考虑固定字符以减少剩余的零和一的数量。 然后它传播镜像值来解析“？” 确定性地。 剩余的“?”对 被贪婪地填充，这是有效的，因为回文对称性允许我们同时分配两个位置。 最后，如果需要的话，中间的字符会被单独处理。 任何冲突或计数违规都会立即导致`-1`。
