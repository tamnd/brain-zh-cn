 ## 解决方案
 ## 问题理解

 我们被要求找到最小的正整数$n$使其除数之和等于给定数字$c$。 形式上，除数和函数$d(n)$将所有能除的数字相加$n$均匀地包括$1$和$n$本身。 例如，$d(6) = 1 + 2 + 3 + 6 = 12$。 给定一个整数$c$，我们必须判断是否存在$n$这样$d(n) = c$，如果是，则返回最小的此类$n$。 如果没有这样的$n$存在，我们返回$-1$。 

输入由多个测试用例组成，每个测试用例给出一个整数$c$最多$10^7$。 和$t \le 10^4$测试用例，我们无法计算$d(n)$天真地为所有人$n \le 10^7$反复。 一种简单的暴力方法来检查每个$n$通过求和它的除数将取$O(n \sqrt{n})$每个测试用例，考虑到最坏情况的输入，速度非常慢。 我们需要一种更智能的方法来有效地预先计算所有可能的信息$c$。 

边缘情况包括$c = 1$， 在哪里$n = 1$是唯一有效的解决方案。 另一个微妙的点是许多数字，例如$c = 2$或者$c = 5$，不对应于任何$n$。 一种天真的方法，假设所有人都存在解决方案$c$在这些输入上会失败。 我们还需要考虑小合数的除数之和，例如，$c = 12$对应于$n = 6$， 但是也$c = 18$对应于$n = 12$。 算法必须选择最小值$n$。 

## 方法

 蛮力方法将迭代$n = 1$到某个上限（例如$10^7$), 计算$d(n)$通过检查所有除数$\sqrt{n}$，并将结果存储在从除数和到最小的映射中$n$生产它。 虽然正确，但这种方法的复杂度大约为$O(n \sqrt{n}) = O(10^7 \cdot 3162)$，这对于$t = 10^4$查询。 

关键的观察是我们可以预先计算所有的除数和函数$n$最多$10^7$使用类似筛子的方法。 除数和函数本质上是乘法函数，可以通过迭代倍数来计算。 具体来说，对于每个$i$从 1 到$N$，我们添加$i$到$d[j]$对于所有倍数$j = i, 2i, 3i, \dots, N$。 这使我们能够计算$d(n)$为所有人$n$在$O(n \log n)$时间。 一旦我们有$d(n)$为所有人$n$，我们可以将每个除数和值映射到最小值$n$产生它的。 预处理后，回答每个查询就变成了简单的字典查找$O(1)$时间。 

暴力法之所以有效，是因为计算$d(n)$很简单，但是当$n$量大，多次查询需要重复计算。 观察结果表明$d(n)$可以计算出所有$n$via multiples 将问题简化为快速预处理步骤，从而可以快速回答数千个查询。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个查询 O(n√n) | O(1) | O(1) | 太慢了|
 | 使用 Sieve 进行预计算 | O(n log n) 预处理，每个查询 O(1) | O(n) | 已接受 |

 ## 算法演练

 1. 定义最大值$N = 10^7$因为没有输入$c$超过这个值。 初始化一个数组$d$尺寸的$N + 1$存储每个的除数和$n$。 
2. 迭代$i$从 1 到$N$。 对于每个$i$, 迭代多个$j = i, 2i, 3i, \dots, N$，并添加$i$到$d[j]$。 这将计算所有数字的除数和函数$N$高效。 
3.初始化字典$answer$将每个可能的除数和值映射到最小值$n$生产它。 为了$n$从 1 到$N$， 如果$d[n]$尚未进入$answer$， 店铺$answer[d[n]] = n$。 这确保了最小$n$被记录。 
4. 对于每个查询$c$，检查是否$c$存在于$answer$。 如果是，则输出$answer[c]$; 否则，输出$-1$。 

为什么有效：筛子般的积累保证了$d[n]$为每个正确计算$n$最多$10^7$。 通过存储每个除数和值的第一次出现，我们确保最小$n$产生的总和被保留。 任何查询都不会产生错误的答案，因为所有可能的总和都已预先计算并正确映射。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAX_C = 10**7
d = [0] * (MAX_C + 1)
for i in range(1, MAX_C + 1):
    for j in range(i, MAX_C + 1, i):
        d[j] += i

answer = {}
for n in range(1, MAX_C + 1):
    if d[n] not in answer:
        answer[d[n]] = n

t = int(input())
for _ in range(t):
    c = int(input())
    print(answer.get(c, -1))
```第一个块使用筛子计算所有除数和。 第二个块确保我们存储最小的$n$对于每笔金额。 最后，使用字典查找在恒定时间内回答查询。 一个微妙的点就是迭代$n$从 1 到$N$用于测绘； 颠倒顺序将打破“最低限度”$n$”保证。
