 ## 解决方案
 ## 问题理解

 我们需要从左到右构建一个固定数组（S）。 在任何时候，我们都可以输入一个新元素，将纸张上已经存在的任何子字符串复制到剪贴板中，或者将整个剪贴板附加到纸张上。 打字成本 (X)、复印成本 (Y) 和每次粘贴成本 (Z)。 剪贴板在粘贴后仍然存在，因此相同的复制子字符串可以粘贴多次。 

输入包含 (T) 个独立的测试用例。 每个测试用例给出目标长度 (n)、三个操作成本 (X,Y,Z) 以及 (S) 的 (n) 个整数值。 所需的输出是精确生产目标阵列所需的最小总成本，其次是所需的`Case #x:`前缀。 

最大的 (n) 为 5000，原始竞赛给出了慷慨的 15 秒时间限制和 1024 MB 内存。 (O(n^3)) 解决方案在最坏的情况下已经考虑了大约 (5000^3=125) 十亿个候选者，因此它不是一个现实的选择。 (O(n^2)) 算法是自然目标。 输入还表明至少 80% 的测试具有 (n\le1000)，这使得精心实施的二次解特别合适。 

有几种边缘情况可能会使表面上合理的解决方案变得错误。 对于单元素目标，例如`1 5 1 1`其次是`7`，答案是 5，因为还没有什么可以复制的。 假设每个最终状态都来自粘贴的解决方案可能会失败。 

第二种情况是`4 10 1 1`其次是`1 1 1 1`。 答案是 14。我们输入第一个`1`如果有 10 个，请复制 1 个，然后粘贴 3 次，再添加 3 个。 对每次粘贴收取复制成本的解决方案将错误地获得 16。 

第三种情况是`4 10 1 1`其次是`1 2 1 2`。 答案是 22。我们输入`1 2`，复制该二元素子字符串，然后粘贴一次。 重复的子字符串从位置 0 开始，并从位置 2 开始粘贴。粗心的边界检查可能会意外拒绝这种情况，因为源和目标相邻。 

最后，重复的子字符串不必是紧邻其前面的子字符串。 在`6 10 8 8`和`1 2 2 1 2 3`，输入前三个值，然后`1 2`从位置 0 和 1 复制并粘贴到前三个值之后。 这创造了`1 2 2 1 2`，之后最后的`3`键入，给出 56。仅搜索与当前前缀直接相邻的重复的解决方案会错过此构造。 

## 方法

 一个简单的动态程序会考虑 (S) 的每个前缀，并且对于每个可能的粘贴，它会尝试将已构造的前缀的每个子字符串作为可能的剪贴板内容。 如果已经对子串相等性进行了预处理，则每个 (O(n)) 个前缀都有 (O(n^2)) 个候选源子串，从而给出 (O(n^3)) 个转换。 对于 (n=5000)，最坏情况下大约有 1250 亿个候选转换。 如果还逐个字符检查子字符串相等性，则复杂性会变得更糟。 

暴力DP是正确的，因为每个合法的粘贴都必须复制纸上已经存在的一些子字符串，因此枚举每个可能的源和每个可能的目的地涵盖了每个合法的操作序列。 问题是大多数这些源选择都是等效的。 复制特定子字符串的成本并不取决于该子字符串出现的位置，稍后唯一重要的是剪贴板的内容。 

关键的观察是向后看粘贴。 假设我们要附加的下一个块的长度为 (j)，并且它等于在位置 (t) 结束的某个较早出现的块。 一旦该块位于剪贴板中，我们就可以键入该出现位置和最终粘贴位置之间的所有内容，而无需更改剪贴板。 因此，“保留此剪贴板，键入一些字符，然后粘贴”操作的整个序列可以由一个 DP 转换来表示。 

还有一个额外有用的单调性属性。 假设相同的块出现在位置 (t_1<t_2) 处结束。 从剪贴板位于 (t_1) 处的块的状态开始，我们可以键入从 (t_1) 到 (t_2-1) 的字符，而无需更改剪贴板。 因此，

 [
 dp[t_2][j]\le dp[t_1][j]+(t_2-t_1)X。 
]

 重新整理后，

 [
 dp[t_2][j]-t_2X\le dp[t_1][j]-t_1X。 
]

 因此，在同一块的所有出现中，最早出现的总是至少对于这种类型的转换来说同样好。 我们不需要尝试每一次发生的事情。 我们只需要每个子字符串第一次出现的位置。 

后缀自动机准确地给出了该信息。 每个子串对应于从初始状态开始的一条路径，并且由相同状态表示的所有子串具有相同的结束位置集合。 如果`firstpos[v]`存储状态 (v) 表示的子串的最早结束位置，然后遍历长度为 (j) 的子串后，其第一次出现结束于`firstpos[v]`。 这是后缀自动机的标准首次出现属性。 

我们可以通过从每个位置开始并向前遍历后缀自动机来枚举所有 (O(n^2)) 子串。 对于每个子字符串，我们记录其最早出现的情况。 然后 DP 仅有 (O(n^2)) 个状态，并且每个状态有 (O(1)) 个工作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力DP | (O(n^3)) | (O(n^2)) | 太慢了|
 | 最优DP+后缀自动机| (O(n^2)) | (O(n^2)) | 已接受 |

 ## 算法演练

 1. 为目标数组构建后缀自动机。 每个状态都存储其最大表示子串长度、后缀链接、转换以及出现的最早结束位置。 当在处理位置(p)时创建正常状态时，其最早结束位置是(p)。 创建克隆时，它会继承其克隆状态的最早位置。 
2. 预先计算每个子串最早出现的时间。 对于每个起始位置(l)，从自动机根开始并一一消耗(S_l,S_{l+1},\ldots)。 消耗 (S_l\ldots S_r) 后，当前状态表示该子字符串，因此`firstpos[state] + 1`是该子字符串最早出现的前缀长度。 存储该值对 ((l,r))。 
3. 定义`dp[i][j]`for (j>0) 作为构造前 (i) 个元素的最小成本，同时在剪贴板中具有子字符串 (S[i-j])，此状态在粘贴之前立即有用。 定义`dp[i][0]`当剪贴板内容不相关时，构造前 (i) 元素的最小成本。 
4. 初始化`dp[0][0]=0`。 价值`best[i]`，定义为所有最小值`dp[i][j]`，表示当我们不关心剪贴板中的内容时构造前 (i) 个元素的最便宜的方法。 
5. 计算`dp[i][0]`，输入第 (i) 个元素。 前一个剪贴板可以是任何东西，所以最便宜的前一个状态是`best[i-1]`。 因此
 [
 dp[i][0]=最佳[i-1]+X。 
]
 6. 对于从 1 到 (i) 的每个 (j)，考虑将粘贴以完成前缀的块 (B=S[i-j])。 设 (l=i-j)，因此该块必须从前 (l) 个元素内的某个位置复制。 
7. 如果 (B) 出现以某个前缀长度 (t\le l) 结尾，我们可以最优地构造前 (l) 个元素，复制 (B)，然后立即粘贴它。 这给出了
 [
 dp[i][j]\le best[l]+Y+Z。 
]
 复制源可以是任何有效的事件，因为它的位置对成本没有影响。 
8. 剪贴板可能已包含 (B)。 令 (t) 为 (B) 出现结束处的最早前缀长度。 从`dp[t][j]`，在该出现位置和所需粘贴位置之间键入 (l-t) 元素，然后粘贴剪贴板。 这给出了
 [
 dp[i][j]\le dp[t][j]+(l-t)X+Z。 
]
 9. 采取最小的可用转换并更新`best[i]`。 按升序处理前缀可保证每个引用的 DP 状态都已计算完毕。 
10.最终答案是`best[n]`，因为在构建完整的目标之后，我们不再关心剪贴板中还剩下什么。 

正确性不变量是每个 DP 状态都代表其指示前缀的可实现构造，并且可以创建新前缀的每个可能的最终操作都由两个粘贴转换之一或通过键入来覆盖。 粘贴过渡要么在粘贴之前立即复制所需的块，要么从较早的状态开始，其中相同的块已位于剪贴板中并在键入时保留该剪贴板。 最早出现的情况就足够了，因为通过在保留相同剪贴板的同时键入，可以从较早出现的情况到达任何较晚出现的情况，这永远无法改进表达式`dp[t][j] - t*X`。 因此，每个最优构造都有一个由递归表示的转换，并且由递归产生的每个转换都对应于合法的打字机操作。 

## Python 解决方案```python
import sys
from array import array

input = sys.stdin.readline

INF = 4_000_000_000_000_000_000

def build_suffix_automaton(s):
    nxt = [{}]
    link = [-1]
    length = [0]
    first = [-1]

    last = 0

    for pos, ch in enumerate(s):
        cur = len(nxt)
        nxt.append({})
        link.append(0)
        length.append(length[last] + 1)
        first.append(pos)

        p = last

        while p != -1 and ch not in nxt[p]:
            nxt[p][ch] = cur
            p = link[p]

        if p == -1:
            link[cur] = 0
        else:
            q = nxt[p][ch]

            if length[p] + 1 == length[q]:
                link[cur] = q
            else:
                clone = len(nxt)
                nxt.append(nxt[q].copy())
                link.append(link[q])
                length.append(length[p] + 1)
                first.append(first[q])

                while p != -1 and nxt[p].get(ch) == q:
                    nxt[p][ch] = clone
                    p = link[p]

                link[q] = clone
                link[cur] = clone

        last = cur

    return nxt, first

def solve_case(n, X, Y, Z, s):
    nxt, first = build_suffix_automaton(s)

    # earliest[l, r] = prefix length at which s[l:r+1]
    # first occurs in the whole string.
    #
    # Row l contains substrings starting at l:
    # [l,l], [l,l+1], ..., [l,n-1].
    total_occ = n * (n + 1) // 2
    earliest = array('H', [0]) * total_occ

    for l in range(n):
        v = 0

        # Start of row l in the triangular array.
        base = l * n - l * (l - 1) // 2

        for r in range(l, n):
            v = nxt[v][s[r]]
            earliest[base + (r - l)] = first[v] + 1

    # dp[i][j], 0 <= j <= i, stored in triangular form.
    #
    # Row i has i+1 entries.
    total_dp = (n + 1) * (n + 2) // 2
    dp = array('q', [INF]) * total_dp

    dp[0] = 0

    best = [INF] * (n + 1)
    best[0] = 0

    for i in range(1, n + 1):
        base_i = i * (i + 1) // 2

        # Type S[i-1]. The clipboard is irrelevant afterwards.
        cur_best = best[i - 1] + X
        dp[base_i] = cur_best

        for j in range(1, i + 1):
            l = i - j

            # Substring s[l:i] starts at l and has length j.
            base_l = l * n - l * (l - 1) // 2
            t = earliest[base_l + j - 1]

            if t <= l:
                # Construct prefix l, copy the block, paste it.
                cand = best[l] + Y + Z
                if cand < cur_best:
                    cur_best = cand

                # The block is already in the clipboard at prefix t.
                # Type the gap, then paste.
                idx_tj = t * (t + 1) // 2 + j
                cand = dp[idx_tj] + (l - t) * X + Z
                if cand < cur_best:
                    cur_best = cand

            dp[base_i + j] = cur_best

        best[i] = cur_best

    return best[n]

def main():
    T = int(input())

    out = []

    for tc in range(1, T + 1):
        n, X, Y, Z = map(int, input().split())
        s = list(map(int, input().split()))

        ans = solve_case(n, X, Y, Z, s)
        out.append(f"Case #{tc}: {ans}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```后缀自动机结构是标准的。 每个新附加的值都会创建一个正常状态，其`first`位置是当前数组索引。 克隆不是新出现的，因此它继承了被克隆状态的第一个出现位置。 这正是回答首次出现的查询所需的属性。 

这`earliest`array 使用三角形布局，因为有 (n(n+1)/2) 个非空子字符串。 对于固定的起始位置`l`，该行包含来自的所有结束位置`l`通过`n-1`。 使用 16 位无符号数组是安全的，因为每个存储的前缀长度最多为 5000。 

DP 使用相同的三角思想。 排`i`包含`dp[i][0]`通过`dp[i][i]`，因此细胞总数为 ((n+1)(n+2)/2)。 有符号的 64 位整数就足够了，因为即使是全类型解决方案的成本也最多 (5000\cdot10^9=5\cdot10^{12})，而最优解决方案的成本不能超过此。 

最微妙的边界条件是`t <= l`。 这里`l=i-j`是附加最终块之前的前缀长度。 事件结束于`t=l`有效，因为其源端恰好在目标端开始处结束。 事件结束后`l`会与正在生成的块重叠，并且在粘贴时不可能存在于纸张上。 

第二个 DP 转换使用`best[l]`，不是特定的剪贴板状态，因为复制会覆盖剪贴板。 复制之前存在的任何剪贴板都是无关紧要的。 相反，第三个转换必须使用`dp[t][j]`，因为它依赖于在键入中间字符时保留现有的剪贴板。 

## 工作示例

 ### 示例 1

 目标是`1 2 3 1 2 3`所有三个成本都等于 1。重要的状态是最终成为最优的状态。 

| 前缀长度`i`| 剪贴板长度`j`| 最早出现`t`| 过渡 |`dp[i][j]`|`best[i]`|
 | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | | 类型 | 1 | 1 |
 | 2 | 0 | | 类型 | 2 | 2 |
 | 3 | 0 | | 类型 | 3 | 3 |
 | 4 | 1 | 1 | 保持`1`， 类型`2 3`, 粘贴| 4 | 4 |
 | 5 | 2 | 2 | 构造3，复制`1 2`, 粘贴| 5 | 5 |
 | 6 | 3 | 3 | 构造3，复制`1 2 3`, 粘贴| 5 | 5 |

 在前缀长度为 3 时，输入的成本为 3。`1 2 3`作为前三个元素出现在那里，因此在长度为 6 时，我们可以将其复制为 1 并将其粘贴为 1。最终成本为 (3+1+1=5)，与示例输出匹配。 

该跟踪还说明了原因`t=l`必须被接受。 对于最终的三元素粘贴，源占据位置 0 到 2，目标从位置 3 开始。源恰好在边界处结束`l=3`。 

### 示例 2

 目标是`1 2 2 1 2 3`，其中 (X=10) 和 (Y=Z=8)。 

| 前缀长度`i`| 剪贴板长度`j`| 最早出现`t`| 过渡 |`dp[i][j]`|`best[i]`|
 | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | | 类型`1`| 10 | 10 10 | 10
 | 2 | 0 | | 类型`2`| 20 | 20 |
 | 3 | 0 | | 类型`2`| 30| 30|
 | 4 | 1 | 1 | 早点使用`1`，类型间隙，粘贴| 38 | 38 38 | 38

 | 6 | 0 | | 类型最终`3`| 56 | 56 56 | 56

 键转换发生在前缀长度 5 处。前三个值`1 2 2`打字花费30。 接下来的两个值是`1 2`，这已经发生在位置 0 和 1 处。复制成本为 8，粘贴成本又为 8，因此长度为 5 的前缀成本为 46。最终`3`成本 10，给出 56。 

此示例说明了为什么源出现不需要与目标相邻。 来源`1 2`位于最开始处，而粘贴在第三个元素之后开始。

 ## 边缘情况

 对于长度为一的目标，例如```
1
1 5 1 1
7
```不存在较早出现的任何非空子字符串。 唯一可访问的结构是键入单个值。 DP 集`dp[1][0]`到`best[0]+X=5`，答案是5。 

对于没有重复的目标，例如```
1
3 10 1 1
1 2 3
```每个候选块在其自己的目的地都有其第一次出现，因此其最早的结束位置大于粘贴之前可用的前缀长度。 两种粘贴过渡均被拒绝。 因此，DP 输入所有三个值，给出 30。 

对于正好发生在边界处的情况，考虑```
1
4 10 1 1
1 2 1 2
```计算最终的二元素块时，(i=4)、(j=2) 和 (l=i-j=2)。 街区`1 2`首先以结束前缀长度 (t=2) 出现。 由于 (t\le l)，源在目标启动之前完全可用。 长度为 2 的前缀成本为 20，复制成本为 1，粘贴成本为 1，即 22。 

对于重复的单个值，请考虑```
1
4 10 1 1
1 1 1 1
```输入第一个值后，剪贴板可以包含它。 同一个剪贴板可以粘贴三次。 总数为(10+1+3=14)。 DP 不会对后来的粘贴收取额外的复制费用，因为第三次转换保留了现有的剪贴板。 

最大尺寸情况使用 5000 个相同值（X=Y=10^9）和（Z=1）。 输入一个值需要花费 (10^9)，复制需要花费另一个值 (10^9)，其余 4999 个值可以粘贴 4999 个值。结果是 (2,000,004)。 使用 64 位存储可防止算术溢出，并且二次表保持在竞赛的 1024 MB 内存限制内。
