 ## 问题理解

 我们有`N`提交的解决方案。 解决方案`i`测量了最坏情况下的运行时间`T[i]`。 对于每个查询，一个字符串`S`将每个解决方案归类为坏解决方案（`0`）， 好的 （`1`），或不确定（`?`）。 

我们需要最小的正整数时间限制`X`满足实际施加限制的每个分类。 一个糟糕的解决方案必须至少采用极限的两倍，因此对于每个位置`S[i] = '0'`我们需要`T[i] >= 2X`。 

一个好的解决方案必须符合限制的一半，因此对于每个位置`S[i] = '1'`我们需要`T[i] <= X / 2`,

 这相当于`X >= 2T[i]`。 

问号根本不附加任何条件。 如果没有正整数`X`满足所有这些不等式，答案是`-1`。 

对于每个查询，输入给出一个长度的分类字符串`N`。 输出是一个整数，最小有效时间限制，或者`-1`如果分类相互矛盾。 

这里`N`和`Q`至多都是`1000`，因此检查每个查询的每个解决方案最多需要`10^6`字符时间比较。 当使用简单的整数运算实现时，这完全在 Python 中的一秒限制之内。 不需要复杂的数据结构或次线性查询算法。 每个解的最大运行时间仅为`10^6`，所以普通的 Python 整数也足够了。 

主要边缘情况来自仅包含一种类型的约束解决方案的分类。 考虑```
1
10
1
0
```一个糟糕的解决方案必须满足`10 >= 2X`， 所以`X <= 5`。 最小的正值是`1`，答案是`1`。 假设下限和上限都存在的粗心实现可能会错误地拒绝这种情况。 

现在考虑```
1
10
1
1
```一个好的解决方案需要`X >= 20`，所以答案是`20`。 这里没有上限。 将上限初始化为零的实现会错误地得出不存在答案的结论。 

另一个重要的情况是边界相等：```
2
10 20
1
01
```糟糕的解决方案有时间`10`, 给予`X <= 5`，而好的解决方案还有时间`20`, 给予`X >= 40`。 这些区间不相交，所以答案是`-1`。 由于不等式是包容性的，例如`T = 10`和`X = 5`对于不好的解决方案是有效的，同时替换`>=`经过`>`会引入一个相差一的错误。 

最后，问号可以消除所有限制：```
3
5 100 20
1
???
```每个正整数都是有效的，所以最小值是`1`。 尝试从数值推断约束而不检查相应字符的解决方案可能会产生不必要的较大值。 

## 方法

 直接的方法是独立处理一个查询。 对于每个位置，检查其特征。 如果是的话`0`，不等式`T[i] >= 2X`给出一个上限`X <= floor(T[i] / 2)`。 如果是的话`1`，不等式`T[i] <= X / 2`给出一个下界`X >= 2T[i]`。 我们保留最强下界和最强上限。 扫描整个字符串后，结果区间内的最小正整数就是答案。 

对于给定的约束，这种强力描述已经是最佳的。 人们可以通过尝试每一种可能的积极因素来制定一种更字面的暴力算法`X`并检查所有`N`解决方案。 自从`T[i] <= 10^6`，没有理由尝试超出粗略范围的值`2 * 10^6`，但在最坏的情况下，这仍然需要大约`10^9`检查`1000`查询，这太慢了。 

关键的观察是条件不是任意的。 每个好的解决方案都只说明了这一点`X`必须足够大，每个糟糕的解决方案都只能说明这一点`X`必须足够小。 因此，整个查询仅由两个数字表示：最大下限和最小上限。 

蛮力之所以有效，是因为每个单独的约束都很容易验证，但如果我们搜索候选值，它就会失败`X`。 所有约束都可以压缩为一个下限和一个上限，这一观察结果让我们可以在一次查询扫描中确定答案。 自从`NQ <= 10^6`，这种直接扫描很容易足够快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对候选人进行暴力破解`X`|`O(Q * N * Tmax)`|`O(1)`| 太慢了 |
 | 边界交叉点 |`O(QN)`|`O(1)`除了输入| 已接受 |

 ## 算法演练

 1.对于当前查询，初始化下界`L`到`1`。 这表示时间限制必须是正整数的要求。 初始化上限`R`到无穷大，因为最初没有限制阻止`X`从大。 
2. 扫描全部`N`查询字符串的位置及其运行时间。 
3. 如果当前字符是`1`，解必须满足`T[i] <= X / 2`。 乘以二得出`X >= 2T[i]`，所以更新`L`到`max(L, 2T[i])`。 我们保留最大值，因为所有好的解决方案必须同时得到满足。 
4. 如果当前字符是`0`，条件是`T[i] >= 2X`, 给予`X <= T[i] / 2`。 自从`X`是一个整数，这意味着`X <= floor(T[i] / 2)`。 更新`R`到`min(R, T[i] // 2)`因为每个糟糕的解决方案都会有一个上限。 
5.忽略每一个`?`。 这样的解决方案没有时间限制。 
6.扫描查询后，进行比较`L`和`R`。 如果`L <= R`，有效的整数值恰好是来自`L`通过`R`，所以最小有效值为`L`。 如果`L > R`，所需区间为空，答案为`-1`。 

### 为什么它有效

 处理完查询的任何前缀后，`L`是最小值`X`满足迄今为止看到的每一个好的解决方案约束，同时`R`是满足迄今为止所见的每个不良解决方案约束的最大值。 好的解决方案只会增加`L`，而糟糕的解决方案只会减少`R`，所以在完整扫描之后间隔`[L, R]`恰好包含满足所有约束的整数值。 如果区间非空，则选择`L`是最优的，因为每个较小的正整数都会违反至少一个好解约束。 如果区间为空，则没有任何值可以满足所有约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**30

def solve():
    n = int(input())
    t = list(map(int, input().split()))

    q = int(input())
    answers = []

    for _ in range(q):
        s = input().strip()

        lower = 1
        upper = INF

        for ti, c in zip(t, s):
            if c == '1':
                lower = max(lower, 2 * ti)
            elif c == '0':
                upper = min(upper, ti // 2)

        if lower <= upper:
            answers.append(str(lower))
        else:
            answers.append("-1")

    sys.stdout.write("\n".join(answers))

if __name__ == "__main__":
    solve()
```前两行输入提供解决方案的数量及其运行时间。 运行时间只存储一次，因为它们由每个查询共享。 

对于每个查询，`lower`开始于`1`，不为零，因为时间限制必须为正。`upper`从足够大的值开始，因为查询可能根本不包含不好的解决方案。 

为了一个好的解决方案，`2 * ti`是精确的下界。 对于一个糟糕的解决方案，`ti // 2`是精确的整数上限。 楼层划分是必要的，因为`X`本身必须是一个整数。 例如，如果`ti = 7`，条件`7 >= 2X`允许`X <= 3`， 不是`X <= 3.5`。 

该代码仅更新边界`0`和`1`。 问号被故意忽略，因为分配它任一类型都会引入查询实际上不需要的约束。 

Python 中不存在溢出问题，即使在固定宽度语言中，这里的最大界限也只是`2 * 10^6`。 这`zip`循环完全处理`N`运行时数组和查询字符串的对应位置。

 ## 边缘情况

 当每个角色都`?`，根本没有任何限制。 为了```
3
5 100 20
1
???
```初始界限是`lower = 1`和`upper = INF`，并且扫描不会改变这两个值。 答案是`1`。 这直接处理查询不包含有用信息的情况。 

当没有好的解决方案时，数据就没有下限。 为了```
1
10
1
0
```上限变为`10 // 2 = 5`， 尽管`lower`停留`1`。 答案是`1`，因为每一个正数`X`从`1`通过`5`是有效的，我们需要最小的一个。 

当没有不好的解决方案时，就没有有限的上限。 为了```
1
10
1
1
```下界变为`2 * 10 = 20`， 尽管`upper`保持无限。 答案是`20`。 

必须接受完全平等。 和```
2
10 40
1
01
```糟糕的解决方案给出了`X <= 5`，而好的解决方案给出了`X >= 80`，所以答案是`-1`。 要直接查看包含边界，请使用```
2
10 5
1
01
```这里糟糕的解决方案需要`X <= 5`，好的解决方案需要`X >= 10`，所以答案又是`-1`。 如果值为```
2
20 5
1
01
```糟糕的解决方案给出了`X <= 10`好的解决方案给出了`X >= 10`， 所以`X = 10`有效且答案准确`10`。 严格比较会错误地拒绝这种情况。 

最后，整数除法对于奇数运行时间很重要。 认为```
1

1
0
```条件是`7 >= 2X`，所以最大的有效整数`X`是`3`。 该算法计算`7 // 2 = 3`，给出正确的间隔`[1, 3]`。 使用浮点除法不是必需的，并且可能会使边界处理不太清晰。 整数公式准确地捕捉了条件。
