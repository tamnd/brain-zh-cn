 ## 解决方案
 ## 问题理解

 我们的肉量是均匀的，`N`和两只鳄鱼。 Vasya 选择两个正整数件数`A`和`B`。 总的肉必须由相同数量的每种尺寸的肉组成，因此如果有`m`尺寸件数`A`和`m`尺寸件数`B`， 然后`N = m(A + B)`。 

这些碎片每隔`K`顺序秒数`A, B, A, B, ...`。 鳄鱼只有在完成了前一个棋子后才能捕获新的棋子。 如果两条鳄鱼同时获得自由，则较强壮的鳄鱼将获得棋子。 每公斤吃完只需要一秒钟。 

我们需要输出任何正整数`A`和`B`两条鳄鱼吃掉的总量之间的差异尽可能小。 

界限`N <= 10^9`立即排除枚举所有可能的块尺寸对。 可以有以下顺序`N^2`正对，这远远超出了一秒解决方案所能检查的范围。 关键是答案只取决于如何`K`与`N/2`和`N-1`，所以最终的算法只需要常数时间和常数内存。 

粗心的解决方案可能会错误处理三种边界情况。 为了`N = 4, K = 1`，选择`A = B = 2`是最优的。 第一个棋子在零时间被强鳄鱼抓住，但当第二个棋子在时间一到达时，鳄鱼仍在吃东西，所以弱鳄鱼得到了它。 检查鳄鱼是否严格在下一次投掷之前完成而不是允许同时完成算作可用的模拟可能会导致这种情况错误。 

为了`N = 4, K = 2`，选择`A = B = 2`不平衡食物。 当第二个棋子被抛出时，强壮的鳄鱼就完成了任务，因此它立即符合资格并接住了第二个棋子。 最优结构为`A = 3, B = 1`，给予强鳄鱼3公斤，弱鳄鱼1公斤。 边界处的相等性是常见的差一误差的根源。 

为了`N = 4, K = 3`，没有任何一块可以让强大的鳄鱼忙到第二次抛出，因为即使是最大的第一块也最多有 3 的大小。`A = 1, B = 3`是有效的，但是强壮的鳄鱼抓住了两块并吃掉了全部4公斤。 假设弱鳄鱼必须得到一些肉的解决方案将错误地寻求不可能的平衡。 

## 方法

 直接的暴力解决方案可以枚举每个正对`(A, B)`，拒绝对`A + B`不分开`N`，并模拟剩余每一对的所有投掷。 模拟是正确的，因为每条鳄鱼的状态完全取决于它最后一次捕获一块的时间和该块的大小。 

问题在于候选人的数量。 如果我们简单地列举所有积极的`A`和`B`和`A + B <= N`， 有`1 + 2 + ... + (N - 1) = N(N - 1)/2`有序对，大约是`5 * 10^17`什么时候`N = 10^9`。 即使在模拟之前拒绝无效对也无法使该方法变得可行。 

一旦我们看到数字，结构就变得简单多了`m`成对的碎片。 自从`N = m(A+B)`， 如果`m >= 2`， 然后`A + B <= N/2`。 

这个单一的不平等是决定性的。 什么时候`K >= N/2`，这种结构中的每个部分最多都有尺寸`K`，所以在抓住一块后，强壮的鳄鱼在下一次投掷时就获得了自由。 由于强壮的鳄鱼只要获得自由就会获胜，因此它会抓住每一块。 

因此，当`K >= N/2`，任何向弱小的鳄鱼提供肉的有用尝试都必须使用`m = 1`。 那么正好有两块，尺寸`A`和`B`， 和`A+B=N`。 第一个棋子属于强壮的鳄鱼。 只有当第一块当时仍然被吃掉时，第二块才能到达弱鳄鱼手中`K`，这意味着`A > K`。 

这将整个优化减少为选择尽可能小的`A`满意的`A > K`。 那是`A = K+1`, 给予`B = N-K-1`, 每当`K <= N-2`。 

什么时候`K < N/2`，还有更好的可能性。 我们可以将每种尺寸各取一件`A = B = N/2`。 自从`A > K`第二块到的时候，强壮的鳄鱼还在忙碌。 弱小的鳄鱼抓住了它，所以两只鳄鱼都收到了`N/2`千克，最佳差值为零。 

什么时候`K >= N-1`，即使是两件式结构中尽可能最大的第一件也无法满足`A > K`， 因为`A <= N-1`。 弱小的鳄鱼无法接受任何东西，所以不可避免的差异是`N`。 我们可以使用`A = 1, B = N-1`，这让强大的鳄鱼吃掉了一切。

 ## 算法演练

 1. 比较`K`和`N/2`。 如果`K < N/2`， 选择`A = B = N/2`。 第一件作品让强壮的鳄鱼忙碌了超过`K`秒，所以第二块落入弱鳄鱼手中。 两者收到的金额相同，这是可能的绝对最小差异，零。 
2.如果`K >= N/2`，考虑是否`K < N-1`。 在此范围内选择`A = K+1`和`B = N-K-1`。 第一件作品的持续时间长于`K`秒，所以当第二块到达时，强壮的鳄鱼正在忙碌。 弱小的鳄鱼得到第二块。 自从`A`是在下一次投掷之后持续存在的最小可能的第一块，这可以最大限度地减少所产生的差异`A-B`。 
3.如果`K >= N-1`， 选择`A = 1`和`B = N-1`。 强壮的鳄鱼在第二次投掷之前完成了第一块，并接住了第二块。 它吃掉所有`N`公斤，并且没有任何建筑可以给弱小的鳄鱼任何肉，所以这是最佳的。 

### 为什么它有效

 中心不变量是，每当`A+B <= N/2`和`K >= N/2`，两种可能的块尺寸最多为`K`，所以强壮的鳄鱼在下一次投掷时总是自由的。 因此，每种尺寸的每个结构至少有两个副本，可以为强壮的鳄鱼提供一切食物。 

什么时候`K < N/2`, 施工`A=B=N/2`给出的差异为零，无法改进。 什么时候`K >= N/2`，任何能够喂食弱鳄鱼的结构都必须具有每种尺寸的恰好一个，因为所有至少有两对的结构都可以将所有东西喂给强鳄鱼。 有了两块，弱小的鳄鱼恰好在什么时候收到第二块`A>K`，所以最小可能的有效`A`是`K+1`。 这最大限度地减少了`A-B`，证明每个分支都返回最优结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N, K = map(int, input().split())

    if 2 * K < N:
        A = N // 2
        B = N // 2
    elif K < N - 1:
        A = K + 1
        B = N - K - 1
    else:
        A = 1
        B = N - 1

    print(A, B)

solve()
```第一个分支使用`2 * K < N`而不是`K < N / 2`，避免浮点运算。 自从`N`是偶数，`N/2`是一个整数，而严格的不等式恰恰是一个大小的条件`N/2`当下一块到达时，它仍在被吃。 

在第二个分支中，`A = K+1`故意大于`K`。 如果我们使用`A = K`，强壮的鳄鱼将在第二次投掷时准确地完成第一块，并有资格抓住它。 该问题明确指出，同时完成和投掷允许鳄鱼尝试新的棋子。 

表达式`B = N-K-1`恰好是正数，同时`K < N-1`。 这就是为什么第二个分支停在`K = N-1`。 在最后一个分支中，`A = 1`和`B = N-1`均为正数且总和为`N`，因此每种尺寸都恰好有一件。 

所有值最多为`10^9`，因此 Python 整数可以轻松处理每个计算。 无需模拟。

 ## 边缘情况

 对于`N = 4, K = 1`，算法采用`A = B = 2`。 第一块在时间 0 到时间 2 被吃掉，而第二块在时间 1 到达。因此，强鳄鱼很忙，弱鳄鱼得到第二块。 结果是`2 2`，给出相等的总数。 

为了`N = 4, K = 2`，吃边界上的平等会改变结果。 和`A = B = 2`，强壮的鳄鱼正好在第二个棋子被抛出时完成，所以它也抓住了第二个棋子。 该算法改为选择`A = 3, B = 1`。 强鳄鱼一直忙碌到时间 3，而弱鳄鱼在时间 2 捕获 1 公斤的碎片。所得差值是 2，并且不可能有更小的正差，因为任何两块结构将第二块交给弱鳄鱼需要`A > 2`。 

为了`N = 4, K = 3`，我们在`K >= N-1`分支和输出`1 3`。 强壮的鳄鱼在时间 1 吃完第一块，因此两只鳄鱼在时间 3 都是自由的。强壮的鳄鱼赢得了同时尝试，并吃掉了第二块。 由于每个可能的第一块最多有大小`N-1 = 3`，没有第一块可以让强鳄鱼忙到时间 3。因此弱鳄鱼无法获得任何肉，造成差异`N`不可避免的。
