 ## 解决方案
 ## 问题理解

 我们有一条由 (N) 个单元格组成的环形道路。 蚂蚁编号 (i) 从直升机当前等待的单元格开始，因此每只蚂蚁死亡后起始单元格前进一个位置。 蚂蚁最初有足够的寿命来行走 (K) 个单元。 蘑菇出现在先前蚂蚁死亡的牢房中。 当蚂蚁到达蘑菇时，它会吃掉蘑菇并获得额外的寿命。 如果它吃（P）蘑菇，它的总步行距离是

 [
 S(P)=K+\左\lfloor\压裂K2\右\rfloor+
 \左\lfloor\frac K3\右\rfloor+\点+
 \left\lfloor\frac K{P+1}\right\rfloor。 
]

 当蚂蚁准确返回自己的起始单元时，任务就成功了。 由于道路有 (N) 个单元格，因此当其总距离可被 (N) 整除时，就会发生这种情况。 我们需要该蚂蚁的数量，如果没有蚂蚁成功，则为 (-1)。 

边界足够大，足以排除对细胞或大量蚂蚁的任何模拟。 (N)和(K)都可以达到(10^9)，因此即使是(O(N))、(O(K))或(O(NK))算法也无法使用。 该解决方案必须将过程减少到恒定数量的状态。 

有几个地方很容易犯差错。 例如，使用输入`7 4`，第一只蚂蚁死在单元格 5，而不是单元格 4，因为它移动了四次。 第二只蚂蚁从单元格 2 开始，经过三步到达单元格 5，吃掉那里的蘑菇，并获得额外的 (\lfloor4/2\rfloor=2) 步。 它的总距离为 6，因此它在单元格 1 处死亡。仅在蚂蚁完成基本 (K) 移动后才将蘑菇视为可用的模拟将错误地错过此交互。 

另一个边界情况是`2 1`。 第一只蚂蚁走过一个细胞并死亡，因此它不会回到起点。 第二只蚂蚁正好从蘑菇上开始，立即吃掉它，但是（\lfloor1/2\rfloor=0），所以它仍然只走一个单元格。 这个过程永远重复，答案是`-1`。 需要正距离才能到达蘑菇的解决方案会在起始单元格中错误地处理蘑菇。 

案例`6 4`给出答案`2`。 第一只蚂蚁走过四个细胞并死亡。 第二只蚂蚁吃掉了那个蘑菇，并获得了两个额外的单元格，给出了总距离（4+2=6），正好是一个完整的圆。 仅检查 (K) 是否能被 (N) 整除会错过这个有效的英雄。 

## 方法

 直接模拟将保留所有蘑菇的位置，沿着圆圈移动每只蚂蚁，并在到达蘑菇或死亡时停止。 这在概念上很简单并且是正确的，因为它完全遵循该过程。 问题是（N）可以是（10^9），而直升机可以永远释放蚂蚁。 在最坏的情况下，模拟可能需要 (\Theta(N)) 或更多蚂蚁运动，每个运动都可能检查蘑菇信息。 这远远超出了一秒的限制。 

有用的观察是蘑菇的数量永远不需要变大。 在第一只蚂蚁之后，有一个蘑菇。 如果一只蚂蚁吃掉了那个蘑菇，它就吃掉了所有现有的蘑菇，所以当它死时，只剩下一个新蘑菇。 如果蚂蚁不吃现有的蘑菇，它就会创造第二个蘑菇。 然后下一只蚂蚁就会吃掉它们。 

最后一句话是关键部分。 假设一只拥有一个现有蘑菇的蚂蚁在其初始 (K) 细胞期间未到达该蘑菇。 该蘑菇是由一只吃了一个蘑菇的蚂蚁创造的，因此它的距离来自于

 [
 A=K+\左\f层K/2\右\r层。 
]

 当前蚂蚁创造出另一个蘑菇后，新蘑菇比下一只蚂蚁领先 (K-1) 个细胞。 下一只蚂蚁吃掉它并获得 (\lfloor K/2\rfloor) 个细胞，总共得到 (A) 个细胞。 老蘑菇也在那些 (A) 细胞内，因此两种蘑菇都被消耗掉了。 因此，最多有两个蘑菇。 

这意味着第一只蚂蚁之后的每只蚂蚁只能根据它吃的蘑菇数量进行分类 (P\in{0,1,2})。 因此，它的步行距离只是三个值之一：

 [
 S(0)=K,
 ]

 [
 S(1)=A=K+\左\f层 K/2\右\r层，
 ]

 [
 S(2)=B=K+\左\lfloor K/2\右\rfloor+
 \左\l地板K/3\右\r地板。 
]

 一旦知道了蚂蚁的 (P)，(P) 的下一个值也就确定了。 如果（P=0），那么后面有两个蘑菇，所以下一只蚂蚁会把两个蘑菇都吃掉。 如果 (P=1) 或 (P=2)，则恰好留下一个新蘑菇。 它与下一个起始单元的距离是

 [
 (S(P)-1)\bmod N。 
]

 如果该距离最大为 (K)，则下一只蚂蚁在其初始生命周期内到达该距离并具有 (P=1)。 否则有(P=0)。 

只有三种可能的状态，因此最多在几次转换后状态会重复。 从那时起，该过程是周期性的。 由于与某个州相关的步行距离永远不会改变，如果它在第一次访问该州时不能被 (N) 整除，那么以后它就永远不会被 (N) 整除。

 ## 算法演练

 1. 单独对待第一只蚂蚁。 它不吃蘑菇，所以它的距离是（K）。 如果 (K=N)，则返回到起始单元格，答案为`1`。 
2. 计算

 [
 A=K+\左\f层K/2\右\r层。 
]

 第二只蚂蚁总是到达第一只蚂蚁创造的蘑菇。 如果 (A) 能被 (N) 整除，则第二只蚂蚁是英雄，所以返回`2`。 

1. 第二只蚂蚁之后，只剩下一个蘑菇。 它到第三只蚂蚁起始单元的距离是

 [
 d=(A-1)\bmod N。 
]

 减一来自直升机在释放下一只蚂蚁之前顺时针移动一个单元格。 

1. 如果 (d\le K)，第三只蚂蚁吃掉了这个蘑菇，因此与第二只蚂蚁的状态完全相同。 由于 (A) 已被检查且不能被 (N) 整除，因此该状态将永远重复，答案为`-1`。 
2. 如果(d>K)，第三只蚂蚁不吃蘑菇。 它行走 (K) 个单元并产生第二个蘑菇。 第四只蚂蚁因此吃掉了这两种蘑菇。 
3. 计算

 [
 B=K+\左\l地板 K/2\右\r地板+
 \左\l地板K/3\右\r地板。 
]

 如果 (B) 能被 (N) 整除，则第四只蚂蚁返回到它的起始单元格，所以答案是`4`。 

1. 否则第四只蚂蚁只留下一个蘑菇。 它的下一只蚂蚁要么吃掉该蘑菇并进入已经考虑的 (P=1) 状态，要么不吃它并返回到 (P=0) 状态。 在任何一种情况下，相同的有限状态序列都会重复，因此后来的蚂蚁都无法成为英雄。 返回`-1`。 

该算法背后的不变性是，在第一只蚂蚁之后，在蚂蚁开始之前总是最多有一个蘑菇，除了前一只蚂蚁没有吃任何东西并因此为下一只蚂蚁留下两个蘑菇的特殊情况。 这两种蘑菇总是一起食用。 因此，未来完全取决于当前的蚂蚁是否吃零个、一个或两个蘑菇。 由于每个这样的状态都有固定的步行距离，因此在第一次出现时检查是否能被 (N) 整除就足够了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N, K = map(int, input().split())

    # Ant 1 eats no mushrooms.
    if K % N == 0:
        print(1)
        return

    # An ant eating exactly one mushroom.
    one = K + K // 2

    if one % N == 0:
        print(2)
        return

    # After ant 2, there is one mushroom.
    # Its distance from ant 3's starting cell is (one - 1) mod N.
    d = (one - 1) % N

    # Ant 3 eats the same single mushroom.
    # The state then repeats forever.
    if d <= K:
        print(-1)
        return

    # Ant 3 eats no mushroom, so ant 4 gets two mushrooms.
    two = one + K // 3

    if two % N == 0:
        print(4)
        return

    print(-1)

if __name__ == "__main__":
    solve()
```第一个条件处理唯一可能的（P=0）状态，不存在蘑菇。 由于 (K\le N)，第一只蚂蚁成为英雄的唯一方法是 (K=N)，尽管使用`K % N`使条件直接匹配数学定义。 

变量`one`是(S(1))。 第二只蚂蚁总是吃掉第一只蘑菇，所以这是它的确切步行距离。 检查`one % N`立即判断ant 2是否成功。 

表达式`(one - 1) % N`表示新蘑菇相对于下一个起始单元格的位置。 模是必要的，因为蚂蚁可能已经走了不止一整圈。 将此距离与`K`确定下一只蚂蚁是否到达蘑菇而无需任何额外的生命周期。 

如果距离超过（K），第三只蚂蚁什么也不吃。 这创造了两种蘑菇共存的唯一情况。 第四只蚂蚁吃掉了两者，所以它的距离是`one + K // 3`。 不需要更多的钱，因为没有一只蚂蚁可以吃掉三个蘑菇。 

Python 整数具有任意精度，因此诸如`one`和`two`即使它们的值超过 (10^9) 也是安全的。 代码中还使用了`% N`而不是显式的单元数算术，避免了所有循环索引和相关的差一错误。

 ## 边缘情况

 对于`2 1`，第一只蚂蚁从单元格 1 走到单元格 2 并创建了一个蘑菇。 第二只蚂蚁从 2 号单元开始，因此它会立即吃掉该蘑菇。 额外的距离为 (\lfloor1/2\rfloor=0)，蚂蚁会从一个单元格走到单元格 1。下一只蚂蚁开始吃新蘑菇，并表现出相同的行为。 由于步行距离不能被 2 整除，因此算法达到重复 (P=1) 状态并输出`-1`。 

为了`7 4`，一个蘑菇的值为 (A=6)。 第三只蚂蚁在距离 ((6-1)\bmod7=5) 处看到剩余的蘑菇，该距离大于 (K=4)，因此它什么也没吃。 这为第四只蚂蚁创造了两个蘑菇。 其距离为 (B=6+\lfloor4/3\rfloor=7)，且 (7\bmod7=0)，因此算法输出`4`。 

为了`6 4`，第一只蚂蚁不是英雄，因为 (4\not\equiv0\pmod6)。 第二只蚂蚁吃了一个蘑菇并行走 (4+\lfloor4/2\rfloor=6) 个单元格。 由于 (6\bmod6=0)，它返回到起始位置，算法输出`2`。 

为了`5 3`，一个蘑菇的距离为 (4)，不能被 5 整除。下一个蘑菇的距离为 (3)，正好等于 (K)，因此第三只蚂蚁确实吃掉了它。 一只蘑菇的状态会永远重复。 比较使用`<= K`， 不是`< K`，因为一只蚂蚁在其当前生命结束时到达蘑菇，并在死亡前吃掉它。 因此正确的结果是`-1`。 

为了`1000000000 1000000000`，第一只蚂蚁正好行走 (10^9) 个单元格，这是一个完整的圆周。 答案是立即`1`。 这也说明了为什么即使在最大约束值下也不需要单元数组、模拟计数器或每个单元状态。
