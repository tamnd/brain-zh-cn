 ## 解决方案
 ## 问题理解

 我们得到一个整数序列，并要求提取一个向前和向后读取相同的子序列，附加约束是其长度必须是偶数。 在所有这些有效的子序列中，我们想要尽可能最长的一个，并且我们必须输出它的长度和一个实现它的具体子序列。 

子序列意味着我们可以从数组中删除元素，但不能对剩余的元素进行重新排序。 回文子序列意味着如果我们按顺序写入所选元素，则该序列围绕其中心对称。 长度的额外限制甚至意味着我们实际上是在中心周围构建相等值的镜像对，而没有中间不匹配的元素。 

数组大小高达 100000，并且值很大但有界。 这立即排除了对子序列或对的任何二次或三次推理。 任何涉及枚举子序列或尝试所有拆分的事情都会爆炸。 甚至$O(n^2)$配对检查太慢。 

一个微妙的限制是每个值至少出现两次并且数组是随机生成的。 这强烈表明我们不应该依赖病理结构，而是依赖使用相等值对的简单频率驱动结构。 

一个天真的但诱人的错误是假设我们可以独立地将相等的值配对并任意连接所有这些对。 这打破了子序列约束，因为顺序很重要。 

例如，如果数组是`[1, 2, 1, 2]`, 配对`1-1`和`2-2`独立地给出类似的东西`1 2 2 1`，这是有效的。 但如果我们有一个更交错的安排，比如`[1, 2, 3, 1, 3, 2]`，如果我们不尊重所选位置的排序，粗心的配对可能会产生无法排列成有效子序列回文的索引。 

真正的挑战不是计算存在多少对，而是确保所选的对可以嵌入到单个递增索引序列中。 

## 方法

 暴力方法将尝试所有子序列并测试每个子序列是否是偶数长度回文，并跟踪最大长度。 有$2^n$子序列，以及每次检查的成本$O(n)$，即使对于$n = 40$，更不用说$10^5$。 

一种更结构化的蛮力想法是固定一个中心并向外扩展，类似于回文检查。 这适用于子字符串，而不是子序列，因为子序列不需要连续性。 一旦允许删除，扩展逻辑就会失去结构，我们再次被迫进行组合选择。 

关键的观察是有效偶数回文中的每个元素都必须与另一个相同值的出现配对。 因此，整个问题简化为选择相等值对并以镜像方式排列它们。 这将问题从子序列选择转换为相同值的配对实例。 

因此，最佳可能长度是我们可以在所有值上形成的不相交对总数的两倍。 对于出现的值$f$时代，我们可以贡献$\lfloor f/2 \rfloor$对。 对所有值求和，得到最大对数。 

剩下的问题是构造：我们必须输出一个有效的子序列，而不仅仅是它的长度。 我们使用的结构是在扫描数组时贪婪地形成对，然后以保留子序列递增索引顺序的方式输出它们。

 | --- | --- | --- | --- |
 | 蛮力 | 指数| O(n) | 太慢了|
 | 频率配对+贪婪构造| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们处理数组并使用它们的出现位置动态构建相等值对。 

1. 从左到右遍历数组，同时为每个值维护一个已看到但尚未配对的索引列表。 当我们看到一个值已经出现了不匹配的情况时，我们立即使用该值的最早可用索引形成一对。 这种贪婪的配对确保我们最大化不相交对的数量。 
2. 每次我们形成一对时，我们都会存储两个索引。 在整个扫描过程中，这会产生尽可能多的对，因为每个值每两次出现恰好贡献一对，并且我们永远不会浪费一次出现。 
3. 收集完所有对后，我们构建最终的子序列。 我们将每对中的第一个元素作为左半部分，将第二个元素作为右半部分。 
4. 我们按第一个索引对对进行排序。 这确保左半部分在原始数组中按位置递增顺序排列。 
5. 我们按该顺序输出左侧索引的值，然后按相反顺序输出右侧索引的值。 这创建了一个回文。 

按首次出现排序起作用的原因是，所有左侧索引在构造的序列中严格递增，并且所有右侧索引以反向对称方式放置在它们之后，这保证了有效的子序列排序。 

### 为什么它有效

 每对在原始数组中恰好贡献两个位置，其中左侧索引严格小于右侧索引。 通过按左索引对对进行排序，所有左端点都会增加。 当反转时，右端点对称对齐，但仍然对应于构造的子序列顺序中左半部分之后的有效位置。 这保证了所选索引的序列严格增加到中点，然后在分配给镜像后半部分时继续增加，同时保留子序列的有效性和回文结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    pos = {}
    pairs = []

    for i, x in enumerate(a):
        if x not in pos:
            pos[x] = []
        pos[x].append(i)

        if len(pos[x]) >= 2:
            j = pos[x].pop()
            i0 = pos[x].pop()
            pairs.append((i0, j, x))

    pairs.sort(key=lambda t: t[0])

    left = [x for _, _, x in pairs]
    right = [x for _, _, x in reversed(pairs)]

    res = left + right

    print(len(res))
    print(*res)

if __name__ == "__main__":
    solve()
```该代码维护每个值的索引堆栈。 每当出现第二个未使用的事件时，我们立即将其与前一个事件配对。 这种贪婪配对保证我们提取最大数量的不相交对而无需回溯。 

按第一个索引对对进行排序是将独立对的集合转变为全局一致的子序列的步骤。 如果没有这种排序，构造的序列可能会违反索引单调性。 

最后的连接是标准的回文结构：左半部分接着反转的右半部分。

 ## 边缘情况

 关键的边缘情况是相同值的出现高度分离并与其他值交错。 即使在这种情况下，贪婪配对仍然有效，因为配对发生在每个值本地，并且不依赖于全局结构。 

考虑：```
1 2 1 3 2 3
```算法对`(1,2)`每个值的位置独立于其他值。 即使值交错，每对仍然有效，因为随后通过按第一个索引排序恢复顺序。 

另一种边缘情况是当一个值在数组中占主导地位时。 例如：```
5
1 1 1 1 1
```形成的对是`(0,1)`和`(2,3)`，留下一个未使用的元素。 该算法正确地仅输出偶数长度，并自动丢弃剩余部分。 

最后的边缘情况是最小输入大小，其中仅存在一对。 该算法直接输出该对，没有任何排序复杂性。
