 ## 解决方案
 ## 问题理解

 我们被要求在四种类型的操作下维护一个数组：追加一个元素、删除最后一个元素$k$元素，回滚最后的更改（可以是追加或删除），并查询当前数组中不同元素的数量。 每个查询都按顺序处理，回滚仅影响最近的修改，而不影响查询本身。 

输入最多包含一百万个查询，并且添加的每个元素可以大到一百万。 查询类型`?`询问不同元素的数量最多出现 100,000 次。 这意味着我们无法在每次查询时从头开始重建不同元素的集合，因为重新计算一组长度可达$10^6$会太慢。 我们也无法存储每次更改的阵列的完整快照，因为这会超出内存限制。 

一种简单的方法是直接模拟阵列，并在每个`?`查询，将其转换为集合以计算不同元素的数量。 虽然这在逻辑上是正确的，但最坏的情况是对长度高达 1,000,000 的数组进行 100,000 次查询，导致$O(10^{11})$运营。 这对于 3 秒的限制来说显然是不切实际的。 

不明显的边缘情况包括重复回滚、交替追加和删除以及多个相同的数字。 例如，如果数组是`[1,2,2,3]`我们删除两个元素，数组变成`[1,2]`。 如果我们随后回滚，它必须精确返回到`[1,2,2,3]`，正确保存计数。 不仔细存储历史记录的幼稚实现将产生`[1,2,3]`或一些不正确的状态。 

## 方法

 暴力方法将维护一个简单的数组列表并按字面处理每个查询。 对于追加`+ x`， 添加`x`到列表中。 拆除用`- k`，切掉最后一个`k`元素。 用于回滚`!`，维护快照堆栈并恢复到之前的快照。 对于不同的查询`?`，将数组转换为集合并返回其大小。 虽然逻辑上是正确的，但这种方法在速度和内存方面都失败了：存储大型数组的快照以进行回滚会消耗过多的空间，并且重复计算不同元素的速度太慢。 

关键的见解是我们不需要整个数组来进行回滚或不同计数。 相反，我们可以使用堆栈来增量地表示数组并存储撤消操作所需的信息。 对于不同的计数，我们维护元素的频率图。 每次追加都会增加添加元素的频率，每次删除都会降低频率，而每次回滚只是反转上次频率更改。 对于删除，我们将删除的元素存储在历史记录中，以便回滚可以准确地恢复它们。 这确保了$O(1)$每次更改更新以及$O(1)$使用具有正计数的频率图键检索不同计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(q * n) | O(q * n) | 太慢了 |
 | 最佳 | O(q) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个空列表`a`对于数组，频率字典`freq`将元素映射到其当前计数以及历史堆栈`history`存储回滚的更改。 
2. 对于每个查询，读取操作类型。 如果是的话`+ x`, 附加`x`到`a`, 增量`freq[x]`加 1，然后推`('+', x)`到`history`。 历史记录条目将允许稍后撤消此附加。 
3. 如果查询是`- k`，删除最后一个`k`元素来自`a`。 对于每个删除的元素，减少其频率`freq`。 将删除的元素列表存储为元组`('-', removed_elements)`在`history`允许回滚。 
4. 如果查询是`!`, 弹出最后一个操作`history`。 如果它是一个追加`('+', x)`，删除最后一个元素`a`并减少`freq[x]`。 如果是删除的话`('-', removed_elements)`，将所有删除的元素追加回`a`并增加它们的频率`freq`。 
5. 如果查询是`?`，返回键的数量`freq`具有正计数，给出当前不同元素的数量。 

工作原理：频率图始终反映当前的数组组成，准确地计算每个元素。 历史堆栈保证每次回滚都精确地反转最后的修改，无论是追加还是删除。 这保留了数组内容和不同元素计数，确保每个元素的正确性`?`询问。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import defaultdict

def main():
    q = int(input())
    a = []
    freq = defaultdict(int)
    history = []
    results = []

    for _ in range(q):
        line = input().strip()
        if line[0] == '+':
            x = int(line[2:])
            a.append(x)
            freq[x] += 1
            history.append(('+', x))
        elif line[0] == '-':
            k = int(line[2:])
            removed = []
            for _ in range(k):
                val = a.pop()
                freq[val] -= 1
                removed.append(val)
            history.append(('-', removed))
        elif line[0] == '!':
            if not history:
                continue
            op, data = history.pop()
            if op == '+':
                val = a.pop()
                freq[val] -= 1
            else:
                for val in reversed(data):
                    a.append(val)
                    freq[val] += 1
        else:  # '?'
            distinct_count = sum(1 for v in freq.values() if v > 0)
            results.append(str(distinct_count))
    
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```该解决方案使用`defaultdict(int)`简化频率管理。 对于回滚，仔细颠倒追加和删除以恢复数组和频率计数。 反转删除的元素可确保保留数组的原始顺序。
