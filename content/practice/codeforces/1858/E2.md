 ## 解决方案
 ## 问题理解

 我们被要求在处理四种类型的查询时维护一个动态数组：追加一个数字，删除最后一个$k$数字，回滚最后的更改（追加或删除），并报告数组中不同数字的数量。 该数组最初是空的。 每次回滚都会撤消最近的更改，因此多次连续回滚可以回溯更改的历史记录。 

输入在线：我们一次收到一个查询，并且必须回答`?`在读取下一个查询之前立即查询。 查询数量$q$可以达到$10^6$和总数`?`查询次数最多为$10^5$。 附加的数字可以大到$10^6$。 

给定约束条件，任何扫描数组以计算每个数组上不同元素的方法`?`查询太慢。 暴力方法可能需要$O(n^2)$在最坏的情况下，这是不可接受的$q = 10^6$。 此外，我们需要有效地支持撤消操作，这排除了在没有巧妙的历史跟踪机制的情况下简单使用 Python 列表或集合的可能性。 

不明显的边缘情况包括连续回滚、回滚删除和重复元素。 例如，考虑以下序列：```
+ 1
+ 2
- 2
!
?
```后`- 2`，数组为空。 回滚删除操作`!`恢复`[1,2]`。 不跟踪完整更改历史记录的粗心实现可能无法正确恢复数组或错误计算不同元素。 

## 方法

 一个简单的解决方案是将数组维护在列表中，执行`+`和`-`操作，并通过转换为集合来计算不同元素的数量`?`查询。 可以通过在每次更改后存储数组的完整副本来处理回滚。 这是正确的，但是重复复制数组会产生成本$O(n)$每次更改。 和$q = 10^6$， 这是$O(n^2)$时间和记忆，这是不可能的。 

关键的见解是我们不需要完整的阵列副本来实现回滚。 我们可以将操作历史记录存储在堆栈中，其中每个操作只记录足够的信息来撤消它。 对于追加`+ x`， 店铺`('add', x)`。 用于删除`- k`，存储已删除元素的列表。 回滚只是从该历史记录中弹出最后一个操作并应用相反的操作。 为了有效地计算不同元素的数量，我们维护一个`Counter`当前元素。 这允许`?`要运行的查询$O(1)$因为我们可以增量地跟踪不同元素的数量。 通过将更改堆栈与频率计数器相结合，我们可以有效地支持追加、删除、回滚和不同计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(q * n) | O(n * q) | 太慢了 |
 | 堆栈+计数器| O(q) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个空列表`a`存储当前数组，a`Counter`目的`freq`跟踪每个数字的频率，一个变量`distinct_count`存储当前不同元素的数量和堆栈`history`存储过去的操作。 
2. 对于每个查询，解析其类型：

 1. 对于`+ x`, 附加`x`到`a`, 增量`freq[x]`。 如果`freq[x]`之前为零，增量`distinct_count`。 推`('add', x)`到`history`。 
2. 对于`- k`, 弹出最后一个`k`元素来自`a`并减少它们的计数`freq`。 如果任何计数降至零，则递减`distinct_count`。 推`('remove', [removed_elements])`到`history`。 
3.为了`!`, 弹出最后一个操作`history`:

 - 如果是的话`('add', x)`，删除最后一个元素`a`并减少`freq[x]`。 如果`freq[x]`变为零，递减`distinct_count`。 
- 如果是的话`('remove', removed_elements)`, 附加`removed_elements`回到`a`并增加`freq`对于每个。 如果任何计数之前为零，则增加`distinct_count`。 
4. 对于`?`， 打印`distinct_count`并立即刷新输出。 
3. 继续下一个查询。 

为什么它有效：`history`堆栈保证回滚始终正确撤消最后的更改。 这`freq`计数器记录每个数字出现的次数，确保`distinct_count`总是准确的。 所有操作均在`a`和`freq`都反映在`history`，所以每次回滚都会恢复`a`以及不同数字的精确计数。 

## Python 解决方案```python
import sys
from collections import Counter

input = sys.stdin.readline
output = sys.stdout.write

a = []
freq = Counter()
distinct_count = 0
history = []

q = int(input())
for _ in range(q):
    line = input()
    if line[0] == '+':
        x = int(line[2:])
        a.append(x)
        if freq[x] == 0:
            distinct_count += 1
        freq[x] += 1
        history.append(('add', x))
    elif line[0] == '-':
        k = int(line[2:])
        removed = []
        for _ in range(k):
            val = a.pop()
            freq[val] -= 1
            if freq[val] == 0:
                distinct_count -= 1
            removed.append(val)
        removed.reverse()  # preserve original order
        history.append(('remove', removed))
    elif line[0] == '!':
        op = history.pop()
        if op[0] == 'add':
            val = a.pop()
            freq[val] -= 1
            if freq[val] == 0:
                distinct_count -= 1
        else:
            removed = op[1]
            for val in removed:
                if freq[val] == 0:
                    distinct_count += 1
                freq[val] += 1
            a.extend(removed)
    else:  # '?'
        output(f"{distinct_count}\n")
        sys.stdout.flush()
```该解决方案使用`Counter`有效地维持频率。 每个`+`或者`-`操作更新`distinct_count`在$O(1)$每个元素。 回滚反映了这些更新。 每次后刷新输出`?`确保符合在线查询要求。
