 ## 解决方案
 ## 问题理解

 我们得到一个表示一排树的二进制字符串，其中每个位置要么是橡树，要么是冷杉。 最终排列的质量仅取决于两个数字：最长的连续 0 块和最长的连续 1 块。 如果我们称这些值为$l_0$和$l_1$，得分计算为$a \cdot l_0 + l_1$， 在哪里$a$从 1 到$n$。 

在评估之前，我们最多允许翻转$k$位置，将零变成一或一变成零，目标是最大化每个固定值的分数$a$。 问题是我们必须为每个单独回答这个优化$a$。 

困难在于更改一个细分市场会影响两者$l_0$和$l_1$以耦合的方式。 增加一个通常需要牺牲另一个，并且翻转可以用于延长运行或合并片段。 

约束足够小$n \le 3000$每个测试用例和总和$n$也以 3000 为界，这排除了比粗略更糟糕的情况$O(n^2)$每个测试用例。 这强烈表明每个起始位置的二次或接近二次动态规划或贪婪构造。 

一个天真的想法是尝试所有可能的最终字符串$k$翻转并计算其$l_0, l_1$。 这是不可能的，因为状态的数量是指数级的$n$。 

当贪婪方法试图独立最大化零或一时，会出现更微妙的失败情况。 例如，在像这样的字符串中`01010`，花费翻转来构建一个长的零块会破坏潜在的块，反之亦然。 正确的解决方案必须同时探索两者之间的权衡。 

## 方法

 蛮力的观点是将每个最终配置视为由我们如何将翻转分配给位置来确定。 如果我们尝试最多的所有子集$k$翻转，我们会生成$\sum_{i=0}^k \binom{n}{i}$的可能性，这已经是指数级的。 即使我们将其压缩为 DP 位置和翻转计数，我们仍然需要评估结果字符串的最大游程长度，这会增加一个额外的长度$O(n)$，导致$O(n^3 k)$或者更糟。 

关键的结构观察是，分数仅取决于最佳零段和最佳一段，而不取决于它们的位置或多重性。 这意味着我们不需要跟踪整个字符串，只需要跟踪翻转后零和一的“最佳可能间隔”的存在。 

现在修复我们想要最大化连续零的候选段。 如果我们选择一个区间$[l, r]$并强制它变成全零，成本就是里面的1的数量。 通过剩余的翻转，我们可以扩展这个结构，或者同时在其他地方构建一个竞争的部分。 对称论证对于 1 成立。 

关键的减少是考虑在最优解决方案中，$l_0$和$l_1$来自翻转后原始字符串中的连续段，并且可以通过滑动窗口来独立评估每个这样的段，该窗口计算使子串统一需要多少次翻转。 

因此，我们为每个间隔预先计算使其全为零或全一所需的最小翻转。 由此我们得出，对于每个可能的长度，可实现的最佳长度$l_0$和$l_1$。 最后，我们将它们结合起来：对于每个$a$，我们选择在构建最佳零游和最佳一游之间进行翻转。 

更有效的重新制定可以避免明确地分割翻转。 对于每个长度$L$，我们最多使用$k$翻转，然后保持前缀最大值。 这会产生所有可实现的对$(l_0, l_1)$，之后我们通过权衡计算凸包并评估$a \cdot l_0 + l_1$为所有人$a$。 

由于两个维度在段长度和翻转方面都是单调的，因此结构变得凸出，从而允许对段大小进行双指针式优化。

 ## 算法演练

 我们构造两个辅助数组：一个用于测量将子字符串变为全零的成本，另一个用于测量将子串变为全 1 的成本。 使用前缀和，我们可以查询每个区间$O(1)$，允许我们评估所有区间$O(n^2)$。 

1. 预先计算 0 和 1 的前缀和，这样我们就可以快速计算出均匀化任何区间需要多少次翻转。 
2. 对于每个间隔$[l, r]$，计算使其全为零的成本作为其内部 1 的数量，并类似地计算使其全为 1 的成本作为其内部 0 的数量。 
3.对于每个区间，如果成本$\le k$，我们可以保证至少有一段长度$r-l+1$该值完全一致。 
4. 维护数组 best0[len] 和 best1[len]，其中 best0[len] 是 k 次翻转内可实现的零游程的最大长度，对于 1 也类似。 
5. 压缩这些数组，使它们变得单调：如果我们能达到长度$x$，我们还可以实现任何更小的长度。 
6.对于每一个可能的$a$，计算最佳值$a \cdot l_0 + l_1$通过迭代所有可行的$l_0$，并将其与最兼容的配对$l_1$不超过翻转预算冲突。 
7. 由于两个数组都是单调的，因此我们可以使用仅向前移动的指针来评估每次测试的线性时间内的最佳配对。 

关键的想法是增加$l_0$需要花费更多的翻转，这减少了可用的结构$l_1$。 单调结构保证我们一旦前进就永远不需要重新考虑之前的状态。 

### 为什么它有效

 每个可行的解决方案都对应于选择两个不相交或部分重叠的区间，它们代表翻转后的最佳零游程和最佳一游程。 任何此类构造的成本正是在这些间隔内纠正的不匹配数量。 由于每个间隔都经过明确评估，并且可实现的最佳长度在成本上是单调的，因此所得到的权衡曲线$l_0$和$l_1$是凸的。 两点评估正确地找到该曲线上每个斜率的最佳点$a$，因为目标$a \cdot l_0 + l_1$在权衡空间中是线性的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        s = input().strip()

        pref0 = [0] * (n + 1)
        pref1 = [0] * (n + 1)

        for i, ch in enumerate(s, 1):
            pref0[i] = pref0[i - 1] + (ch == '0')
            pref1[i] = pref1[i - 1] + (ch == '1')

        best0 = [0] * (n + 1)
        best1 = [0] * (n + 1)

        for l in range(n):
            for r in range(l, n):
                ones = pref1[r + 1] - pref1[l]
                zeros = pref0[r + 1] - pref0[l]
                length = r - l + 1

                if ones <= k:
                    best0[length] = max(best0[length], length)
                if zeros <= k:
                    best1[length] = max(best1[length], length)

        for i in range(n - 1, 0, -1):
            best0[i] = max(best0[i], best0[i + 1])
            best1[i] = max(best1[i], best1[i + 1])

        res = []
        j = 0
        for a in range(1, n + 1):
            while j + 1 <= n and best0[j + 1] * a + best1[j + 1] >= best0[j] * a + best1[j]:
                j += 1
            res.append(str(best0[j] * a + best1[j]))

        print(" ".join(res))

if __name__ == "__main__":
    solve()
```前缀数组允许恒定时间间隔计数，这使得段上的二次枚举变得可行。 嵌套循环计算在翻转预算内使任何子串一致的可行性，干净地分隔零和一。 

单调传播步骤确保如果可以实现较长的均匀段，则所有较短的长度也被视为可实现，这是稍后正确的贪婪评估所必需的。 最后的指针扫描利用了这样一个事实：$a$增加，则最优选择为$l_0$单调变化。 

## 工作示例

 考虑字符串`0110`和$k = 1$。 

我们计算最佳分段：

 | 区间选择 | 翻转至全 0 | 翻转至全部 1 | 可以用吗？ |
 | --- | --- | --- | --- |
 | 0-1 | 1 | 1 | 是的 |
 | 0-3 | 2 | 2 | 没有|
 | 1-2 | 1-2 0 | 0 | 是的 |
 | 2-3 | 2-3 1 | 1 | 是的 |

 由此我们导出 best0 和 best1 数组作为可实现长度的单调函数。 

为了$a = 1$，该算法更喜欢平衡两个值，选择一个适中的$l_0$和$l_1$。 作为$a$增加，它转向最大化$l_0$，因为它的系数占主导地位。 

现在考虑`101101`与 (k = 2`.

 我们可以通过翻转里面的零来创建一个长的零段`010010`-类似区域，但这样做会减少可用区域。 权衡曲线变得非线性，算法通过最佳长度聚合隐式跟踪这一点。 指针移位显示了多高$a$值逐渐优先考虑零游程长度而不是一游程长度。

 ## 边缘情况

 完全统一的字符串，例如`00000`或者`11111`确保算法正确处理其中之一的情况$l_0$或者$l_1$始终为零。 区间枚举仍然标记所有段可行，并且单调传播确保最佳长度简单地$n$。 

高度交替的字符串，例如`101010`强调这样一个事实：如果不花费多次翻转，就不存在长的统一片段。 该算法正确地将 best0 和 best1 限制为较小的值，因为每个间隔都会产生较大的不匹配成本。 

零翻转案例$k = 0$迫使算法完全依赖于原始的最长游程，并且基于前缀的间隔检查正确地减少为简单的游程长度提取。
