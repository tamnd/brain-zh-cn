 ## 解决方案
 ## 问题理解

 我们有一个系统，其中两个角色共享固定数量的相同蜜罐。 最初，底池在双方之间随机分配，但只有双方至少获得一底池的情况下才允许进行分配。 由于罐子是无法区分的，唯一重要的是 Pooh 有多少个罐子，可以是 1 到 1 之间的任何值$n-1$，每个可能性均等。 

在最初的分裂之后，系统以离散的轮次演化。 在每一轮中，可能会发生以下三件事之一。 有概率$p$，一个罐子从 Pooh 移动到 Heffalump，使 Pooh 的计数减一。 有概率$q$，一个罐子从 Heffalump 移动到 Pooh，使 Pooh 的计数增加一。 有概率$r$，没有任何变化。 如果 Pooh 达到 0 底池或$n$盆，该过程永久停止。 

任务是考虑固定轮数$i$，并计算两个条件同时成立的概率。 首先，这个过程还没有被吸收，这意味着双方都没有达到零底池。 二、之后的配置$i$rounds 与初始配置完全相同。 

约束足够小，状态空间基本上是线性的$n$， 自从$n \le 26$，但步数可以高达 1600。这立即表明每个测试用例的二次或三次动态规划解决方案是可以接受的，而任何随时间或状态变化的指数则不可接受。 

一个微妙的点是答案取决于初始随机分割。 我们不跟踪单个起始状态，而是跟踪 Pooh 底池计数所有可能起始值的平均值。 另一个重要的约束是吸收规则。 任何到达 0 或$n$必须完全排除，即使它后来在概念上返回到相同的配置。 

一个幼稚的错误是忽略吸收并将其视为整数上的无限制随机游走。 这会错误地计算跨越边界的路径。 另一个错误是通过混合来自不同起始位置的转换来错误地平均状态，这违反了我们返回到相同初始配置（而不仅仅是任何匹配配置）的要求。 

## 方法

 直接的暴力方法将模拟所有可能的序列$i$从每个可能的初始分割开始的回合。 每轮会分为三个结果，所以之后$i$步骤有$3^i$每个起始状态可能的历史。 即使对于中等$i$，这变得不可行，因为$3^{1600}$是一个天文数字。 即使修剪由于吸收而导致的无效状态也不足以降低分支因子以使其可行。 

关键的观察结果是，该系统是一个小状态空间上的马尔可夫链，该状态空间由以下整数值组成：$1$到$n-1$，吸收边界为$0$和$n$。 之后处于某种状态的概率$t$步骤仅取决于上一步，而不取决于完整的历史记录。 这使我们能够随着时间的推移用动态规划代替指数枚举。 

然而，我们还需要第二层结构。 该条件需要返回到原始状态，这意味着我们不能简单地计算之后的分布$i$混合初始分布的步骤。 我们必须分别跟踪每个可能的起始状态的转换，然后根据均匀初始分布组合结果。 

这导致了一个干净的公式：对于每个起始值$s$，计算从以下位置开始的约束随机游走的概率$s$又是在$s$后$i$一步一步地前进，却从未触及界限。 这是一个关于状态和时间的标准 DP，因为$n$很小，每次启动时独立运行它仍然保持高效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举|$O(3^k)$|$O(k)$| 太慢了 |
 | 每个启动状态的 DP |$O(n^2 \cdot k)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将这个过程解释为状态上的随机游走$1$通过$n-1$，其中状态$x$意味着维尼有$x$罐子。 

1. 对于每种可能的起始状态$s$，初始化一个 DP 数组，其中仅$dp[s] = 1$。 这代表该过程从配置开始的确定性$s$，在任何转换发生之前。 
2. 迭代时间步长$1$到$k$，在每一步更新一个新的 DP 数组。 每个转变根据一轮的三个可能结果来分配概率质量。 
3.来自一个州$x$，系统可以移动到$x-1$有概率$p$， 到$x+1$有概率$q$，或停留在$x$有概率$r$。 仅当结果状态保持在以下范围内时，我们才应用这些更新$[1, n-1]$。 
4. 任何可能发生的转变$0$或者$n$被丢弃。 这对应于吸收，并且这些路径对未来状态没有贡献。 
5.完成后$i$步骤，记录$dp[s]$，它表示从$s$，系统返回到$s$没有吸收。 
6. 对所有起始状态重复此操作$s \in [1, n-1]$，然后对结果进行平均，因为初始配置在这些状态上是均匀随机的。 

### 为什么它有效

 DP 状态隐式编码位置和生存。 表中的每个概率质量对应于一条未被吸收的有效路径。 由于转变是逐步应用的并且永远不会重新引入吸收状态，因此无效的轨迹不能重新进入系统。 概率的线性确保对独立起始状态求和然后求平均值与原始随机初始化完全匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        p, q, r = map(float, input().split())
        k = int(input())

        m = n - 1
        inv_m = 1.0 / m

        answers = [0.0] * k

        for s in range(1, n):
            dp = [0.0] * n
            dp[s] = 1.0

            for t in range(k):
                ndp = [0.0] * n

                for x in range(1, n):
                    val = dp[x]
                    if val == 0:
                        continue

                    ndp[x] += val * r

                    if x - 1 >= 1:
                        ndp[x - 1] += val * p

                    if x + 1 <= n - 1:
                        ndp[x + 1] += val * q

                dp = ndp
                answers[t] += dp[s] * inv_m

        for v in answers:
            print(f"{v:.6e}")

if __name__ == "__main__":
    solve()
```该解决方案为每个可能的初始分裂构建单独的概率演化。 DP 数组表示每轮后 Pooh 底池计数的分布，条件是未触及吸收边界。 

内部转换步骤直接应用三种可能的结果。 边界检查确保转换到状态$0$或者$n$完全被忽略，符合达到这些状态时游戏立即结束的规则。 

每个时间步长都会贡献回到该特定初始值的起始状态的概率。 我们累积这些贡献并除以$n-1$最后隐含地通过平均。 

输出格式使用科学记数法来匹配所需的精度约束。 

## 工作示例

 考虑示例案例$n = 3$，其中唯一有效的起始状态是$1$和$2$。 

对于每个起始状态，我们跟踪概率质量如何随时间演变。 下表显示了在求平均之前，在每个步数之后回到相同状态的概率。 

### 跟踪每次启动

 | 步骤| 开始 = 1（返回概率）| 开始 = 2（返回概率）|
 | --- | --- | --- |
 | 1 | r | r |
 | 2 | r^2 + pq | r^2 + pq | r^2 + pq | r^2 + pq |
 | 3 | 通过边界路径衰减| 通过边界路径衰减|
 | 4 | ... | ... |
 | 5 | ... | ... |

 每一步的最终答案是两列的平均值。 

这表明一般不需要对称性，但对初始状态进行平均会强制状态空间两端的贡献一致。 

第二个有用的健全性检查是这样的$r = 1$，没有任何运动发生。 在这种情况下，每个状态都永远保持固定，因此对于每个状态，返回到相同状态的概率始终恰好为 1$i$，这与 DP 行为相匹配，因为仅存在自循环。 

## 复杂度分析

 ## 边缘情况

 一种重要的边缘情况是运动概率将质量直接推入吸收状态。 例如，与$n = 3$，从状态开始$1$，任何降低状态的转换都会立即结束游戏。 DP 通过在添加过渡之前检查边界来正确丢弃该质量。 

另一个边缘情况是当$r$非常接近 1。在这种情况下，大多数概率质量保持不变，并且数值稳定性比组合结构更重要。 DP 保持稳定，因为概率是增量累积的，无需减法。 

最后一种情况是当$k = 1$。 在这里，答案只是一步后保持相同状态的概率，对所有开始进行平均。 DP 简化为单个过渡层，并且不涉及更深层次的历史。
