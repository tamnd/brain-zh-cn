 ## 解决方案
 ## 问题理解

 我们需要找到正整数 (x) 和 (y)，使得

 [
 x^2-y^2=n,
 ]

 其中 (0\le n\le 2^{60})，并且 (x) 和 (y) 最多只能为 (2^{62}-1)。 如果存在这样的一对，我们可以输出其中的任何一个。 否则，我们打印`No`。 

关键是表达式是平方差，因此可以分解为

 [
 (x-y)(x+y)=n。 
]

 当 (n>0) 时，两个因子均为正，并且它们具有相同的奇偶性，因为它们的总和为 (2x)。 这将问题从搜索两个未知整数转变为寻找 (n) 的合适因式分解。 

对于逐一尝试直到 (n) 的值的算法来说，上限 (2^{60}) 太大。 即使是 (O(\sqrt n)) 算法，在最坏的情况下也会执行大约 (2^{30}) 次迭代，这在较低级语言中已经是数亿次操作，而不是解决此问题的适当策略。 我们需要利用代数结构。 Python 整数也不存在固定宽度溢出问题，尽管在构造答案时数学界限仍然很重要。 

在几种边缘情况下，粗心的分解方法可能会产生无效的对。 对于 (n=0)，选择 (x=y=1) 有效，因为问题需要正整数，而选择 (x=y=0) 会违反该要求。 对于 (n=1)，明显的因式分解 (1\cdot1) 给出 (x=1) 和 (y=0)，这是无效的，所以正确答案是`No`。 对于 (n=4)，具有相同奇偶性的因子的唯一正分解是 (2\cdot2)，再次给出 (y=0)，因此正确答案也是`No`。 对于(n=2)，因式分解(1\cdot2)具有不同奇偶性的因子，因此它不能对应整数(x)和(y)，正确答案是`No`。 

## 方法

 直接方法可以尝试 (y) 的可能值，计算 (y^2+n)，并检查它是否是完全平方数。 它是正确的，因为每个有效的解决方案都有一些正数 (y)，并且检查所有相关值最终得出该解决方案。 但是，在搜索完成之前，可能存在 (\sqrt n) 个候选者。 对于 (n=2^{60})，这大约是 (2^{30}) 次迭代，因此最坏的情况约为 10.7 亿次候选检查。 对于输入由单个整数组成的问题来说，这工作量太大了。 

有用的观察是因式分解

 [
 x^2-y^2=(x-y)(x+y)。 
]

 假设 (a=x-y) 和 (b=x+y)。 然后(ab=n)，我们可以恢复

 [
 x=\frac{a+b}{2},\qquad y=\frac{b-a}{2}。 
]

 为了使它们成为整数，(a) 和 (b) 必须具有相同的奇偶校验。 如果(n)是奇数，则(n)的每个因子都是奇数，所以我们可以简单地选择(a=1)和(b=n)。 这会产生

 [
 x=\frac{n+1}{2},\qquad y=\frac{n-1}{2}。 
]

 这对于奇数 (n\ge3) 有效。 情况 (n=1) 产生 (y=0)，因此必须单独拒绝。 

如果(n)能被(4)整除，我们可以选择(a=2)和(b=n/2)。 两个因数都是偶数，因此所得 (x) 和 (y) 都是整数：

 [
 x=\frac{n/2+2}{2}=\frac n4+1,
 \qquad
 y=\frac{n/2-2}{2}=\frac n4-1。 
]

 我们需要(y>0)，这意味着(n/4>1)，所以(n\ge8)。 因此，从 (8) 开始的 (4) 的每个倍数都有一个解。 特殊情况(n=0) 与(x=y=1) 分开处理。 

其余正整数与 (2\pmod4) 以及 (1) 和 (4) 完全相同。 它们没有有效表示为两个正平方之差。

 | 最佳| (O(1)) | (O(1)) | (O(1)) | (O(1)) | 已接受 |

 ## 算法演练

 1. 如果(n=0)，则输出(x=1,y=1)。 它们的平方相等，因此它们的差为零，并且两个数都是正数。 
2. 如果(n=1)或(n=4)，输出`No`。 对于 (n=1)，唯一的因式分解是 (1\cdot1)，对于 (n=4)，唯一可行的同奇偶性因式分解是 (2\cdot2)。 在这两种情况下，结果 (y) 均为零。 
3. 如果(n)是奇数，则选择(a=x-y=1)和(b=x+y=n)。 由于两者都是奇数，因此重构给出整数值
 [
 x=(n+1)/2,\qquad y=(n-1)/2。 
]
 对于每个奇数 (n\ge3)，(y) 都是正数。 
4. 如果 (n) 能被 (4) 整除，则选择 (a=2) 和 (b=n/2)。 两个因子都是偶数，对于 (n\ge8) 我们有 (b>a)，所以
 [
 x=n/4+1,\qquad y=n/4-1
 ]
 是正整数。 
5. 如果前面的情况都不适用，则输出`No`。 这样的正数 (n) 与 (2\pmod4) 全等，因此它不能写成具有相同奇偶性的两个因子的乘积。 

### 为什么它有效

 对于任何正解，设置 (a=x-y) 和 (b=x+y) 给出 (ab=n)，其中 (a) 和 (b) 具有相同的奇偶校验。 如果(n)为奇数，则因子(1)和(n)满足该要求。 如果 (n) 可被 (4) 整除，则因数 (2) 和 (n/2) 均为偶数。 这些构造直接产生正整数，除了两种小情况 (n=1) 和 (n=4) 之外，其中构造的 (y) 为零。 

相反，如果 (n\equiv2\pmod4)，任何因式分解 (ab=n) 都必须包含一个奇数因数和一个偶数因数，因为它们的乘积正好有一个因数 (2)。 这些因子不能等于 (x-y) 和 (x+y)，因为这两个量始终具有相同的奇偶性。 因此不存在解决方案。 情况(n=0)单独处理。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    if n == 0:
        print("Yes")
        print(1, 1)
        return

    if n == 1 or n == 4:
        print("No")
        return

    if n & 1:
        x = (n + 1) // 2
        y = (n - 1) // 2
        print("Yes")
        print(x, y)
        return

    if n % 4 == 0:
        x = n // 4 + 1
        y = n // 4 - 1
        print("Yes")
        print(x, y)
        return

    print("No")

if __name__ == "__main__":
    solve()
```第一个分支在任何因式分解逻辑之前处理 (n=0)，因为因式分解参数假设正因数，而 (0) 具有简单的正解 (1^2-1^2=0)。 

对 (1) 和 (4) 的检查可防止公式生成 (y=0)。 对于 (n=1)，奇数公式给出 ((x,y)=(1,0))。 对于 (n=4)，可被四整除的公式给出 ((x,y)=(2,0))。 两者都违反了 (y\ge1) 的要求。 

表达式`n & 1`检查 (n) 是否为奇数。 整数除以二是安全的，因为相应的分子是偶数。 在能被四整除的分支中，`n // 4`是精确的，因此两个构造的值都是整数。 

Python中不存在溢出问题。 即使在固定宽度的 64 位实现中，输入也最多为 (2^{60})，而构造的值远低于 (2^{62}-1)。 对于奇数 (n)，为 (x\le2^{59})，对于可被 (4) 整除的 (n)，为 (x\le2^{58}+1)。

 3=1\cdot3。

 数字 (2) 是正数，既不是 (1) 也不是 (4)，也不是奇数，并且不能被 (4) 整除。 因此，它属于不可能的情况。 

| 步骤| (n) | 奇怪的？ | 能被4整除吗？ | 结果 |

 ## 边缘情况

 ### (n=0)

 对于输入```
0
```算法立即选择 (x=y=1)。 方程变为

 [
 1^2-1^2=0。 
]

 特殊分支是必要的，因为正数 (n) 的因式分解参数不适用于零。 粗心的实现可能会输出 (0,0)，但零并不是输出条件允许的自然正值。 

### (n=1)

 对于```
1
```奇怪的结构会选择

 [
 x=\frac{1+1}{2}=1,\qquad y=\frac{1-1}{2}=0。 
]

 方程本身是正确的，因为 (1^2-0^2=1)，但 (y=0) 是禁止的。 (1) 没有其他分解，所以正确的结果是```
No
```### (n=4)

 对于```
4
```可被四整除的结构给出

 [
 x=4/4+1=2,\qquad y=4/4-1=0。 
]

 同样，方程在数值上是正确的，但 (y) 不是正数。 因式分解 (4=2\cdot2) 完全对应于 (x-y=x+y=2)，这会强制 (y=0)。 因此正确的输出是`No`。 

### (n=2)

 对于```
2
```没有有效分解为两个相同奇偶性的正因子。 唯一的因子对是 (1\cdot2)，其奇偶性不同。 由于 (x-y) 和 (x+y) 始终具有相同的奇偶性，因此任何正整数对 (x,y) 都不能产生等于 (2) 的平方差。 算法到达最后一个分支并打印`No`。 

### (n=8)

 这是第一个具有有效解的四的正倍数。 该建筑给出了

 [
 x=8/4+1=3,\qquad y=8/4-1=1。 
]

 确实，

 [
 3^2-1^2=9-1=8。 
]

 因式分解为 (8=(3-1)(3+1)=2\cdot4)，并且两个因式都是偶数。 此示例标记了无效情况 (n=4) 之后的确切边界。 

### (n=2^{60})

 最大输入可以被四整除，所以

 [
 x=\frac{2^{60}}4+1=2^{58}+1,
 \qquad
 y=\frac{2^{60}}4-1=2^{58}-1。 
]

 他们的平方差是

 [
 (2^{58}+1)^2-(2^{58}-1)^2
 =4\cdot2^{58}
 =2^{60}。 
]

 这两个值都远小于 (2^{62}-1)，因此即使在最大可能的输入下，该结构仍安全地保持在所需的输出范围内。
