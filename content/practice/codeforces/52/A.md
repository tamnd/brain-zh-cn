 ## 解决方案
 ## 问题理解

 我们得到一个整数列表，其中每个数字都是 1、2 或 3。目标是转换序列，使所有数字都相同，并且我们希望使用尽可能少的替换次数来实现此目的。 每次替换都包括将一个数字更改为其他两个值中的任意一个。 输入以整数开头`n`指定序列的长度，后跟`n`整数。 输出是一个整数，表示所需的最小更改数量。 

看看约束条件，`n`可以大到一百万。 这立即排除了迭代所有可能的替换序列或尝试每种转换组合的算法，因为它们的时间复杂度会爆炸。 线性时间方法在这里是可以接受的，因为`n`最多为 10^6，并且 10^6 到 10^7 数量级的操作将在 2 秒的时间限制下轻松运行。 

要考虑的边缘情况包括所有数字都相同的序列、每个数字出现完全相同次数的序列以及只有一个元素的序列。 例如，如果序列是`[2]`，不需要替换，答案是`0`。 如果序列是`[1, 2, 3]`，那么最好的选择是将所有数字都设为 1、2 或 3，需要进行两次更改。 

## 方法

 蛮力方法很简单。 您可以尝试使所有数字等于 1，然后全部等于 2，最后全部等于 3，计算每种情况下所需的更改数量，然后取最小值。 该方法是正确的，因为这三个目标值之一必然会产生最小数量的替换。 该方法的成本与`3 * n`因为对于每个目标数字，我们必须扫描整个数组以计算不匹配的数量。 在这个问题中这是可以接受的，因为`3 * 10^6`操作是可以管理的，但在更严格的时间设置或更大的数字范围内，这种方法会变得低效。 

进一步优化问题的关键在于认识到我们根本不需要模拟更改序列。 重要的是每个数字出现的次数。 如果我们知道 1、2、3 的计数，则最小替换次数就是总长度减去最大计数。 这是因为最佳选择是将所有元素转换为已经出现最频繁的数字。 这将问题简化为简单的计数问题，可以通过数组的单次传递来解决。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(3 * n) | O(3 * n) | O(1) | O(1) | 已接受 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化三个计数器，每个数字一个：`count1`,`count2`， 和`count3`。 每个人都会记录 1、2 和 3 在序列中出现的次数。 这是我们决定最佳替换策略所需的最少信息。 
2. 迭代序列中的每个数字。 如果数字为 1，则递增`count1`。 如果是2，则递增`count2`。 否则递增`count3`。 这样计数可以确保我们在一次线性传递中获得完整的频率图。 
3. 确定三个计数中的最大频率。 这表示我们应该将序列的其余部分转换为的数字。 让`max_count`成为最大的`count1`,`count2`， 和`count3`。 
4. 所需的最少替换是序列的总长度减去此最大计数，`n - max_count`。 这是可行的，因为最大计数元素已经正确，并且必须更改其余元素以匹配。 

为什么它有效：在每个点，我们都会维护每个可能值的出现次数。 由于我们可以将任何数字更改为任何其他数字，因此最佳策略始终是选择最常出现的值并转换其余的值。 没有其他策略需要更少的更改，因为与最常见数字的任何偏差都必然需要更改更多元素。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

count1 = count2 = count3 = 0
for num in a:
    if num == 1:
        count1 += 1
    elif num == 2:
        count2 += 1
    else:
        count3 += 1

max_count = max(count1, count2, count3)
print(n - max_count)
```该代码首先使用以下命令有效地读取输入`sys.stdin.readline`对于大输入尺寸。 然后它为序列中的每个可能值初始化计数器。 在迭代过程中，每个数字都会增加适当的计数器，确保不会发生相差一的错误。 计数后，我们计算最大计数并将其减去`n`以获得最少的替换次数。 该算法避免了不必要的数据结构，保证了O(1)的空间。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())

    count1 = count2 = count3 = 0
    for num in a:
        if num == 1:
            count1 += 1
        elif num == 2:
            count2 += 1
        else:
            count3 += 1
