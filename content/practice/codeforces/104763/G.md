 ## 解决方案
 ## 问题理解

 我们得到一个目标字符串，它代表字母表 {A, T, C, G} 上的基因组序列。 我们还有一组可用的 DNA 片段，每个片段也是同一字母表上的字符串。 每个段都可以任意多次重复使用，并且我们可以按顺序连接选定的段以形成更长的字符串。 目标是准确构建目标基因组。 

第一个目标是最大限度地减少总共使用的段数，其中每个段的使用都单独计数，即使它是稍后重用的同一段。 

第二个目标对构造增加了结构性限制：我们不允许将相同的段紧接着其本身放置。 多次使用一个段仍然可以，但是连续两次选择不能相同。 

这些约束将基因组长度和片段数量限制为最多 1000，片段长度也最多为 1000。这立即表明，任何尝试显式模拟所有串联或以指数方式探索片段序列的方法都将失败。 即使是位置和段上的二次或三次 DP 也必须小心处理，因为如果不使用字符串匹配结构进行优化，简单转换可能会达到大约 10^9 次操作。 

一些边缘情况很容易被忽略。 

一种情况是基因组根本无法形成，因为所有片段都缺少某些特征。 例如，具有片段[“A”]的基因组“ACTG”显然无法完成，答案为-1。 

另一种情况是，即使存在有效的平铺，贪婪扩展也会失败。 例如，具有片段[“A”，“AA”]的基因组“AAAA”不能通过始终采用最长匹配来最佳解决，因为在选择“AA”之后，贪婪方法可能会因未来的约束而陷入困境。 

第二个约束引入了另一种微妙的故障模式。 如果覆盖某个区域的唯一方法需要连续重复同一片段两次，那么即使覆盖范围不受限制，答案也变得不可能。 例如，无法形成具有片段[“AA”]的基因组“AAAA”，因为它需要连续使用“AA”两次。 

## 方法

 如果我们忽略连续重复的限制，问题就简化为将字符串拆分为最少数量的字典单词，其中每个单词都是一个段。 这是图中位置上的经典最短路径：从索引 i 开始，如果子字符串与段 s 匹配，我们可以跳转到 i + len(s)。 天真的想法是通过 DFS 或 BFS 在由当前位置和最后使用的段标识组成的状态上尝试每个可能的段序列。 

这种强力探索大小为 O(n · N) 的状态空间，其中 n 是基因组长度，N 是片段数量，但每次转换可能需要长度高达 1000 的子串比较。在最坏的情况下，分支很高，重复重新计算使其在实践中呈指数增长。 

关键的结构观察是我们只关心基因组中的位置和最后使用的片段。 基因组位置是线性索引，因此这成为分层图上的最短路径问题：每一层对应于一个位置，并且转换对应于匹配从该位置开始的片段。 “没有连续的相同段”约束只是删除连续两次重复使用相同段标签的转换。 

这立即建议对位置进行动态编程，其中每个状态存储通过给定的最后使用的段到达该位置的最佳答案。 由于段是不同的并且 N 很小，因此我们可以对它们进行索引并将过渡视为边缘。

为了有效地找到在某个位置匹配的段，我们预先计算或直接检查从每个位置开始的所有段。 给定约束条件，直接的 O(n · N · L) 方法是可以接受的，因为最坏情况的比较总数约为 10^9 次，但在实践中，提前停止不匹配和 Python 字符串切片优化就足够了。 更结构化的解决方案将使用滚动哈希或特里树，但这里没有必要。 

第二个约束仅改变转移规则，而不改变状态结构。 我们只是禁止从段 i 移动到段 i。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（串联上的 DFS）| 指数| O(n) | 太慢了 |
 | DP 超过位置和最后一段 | 最坏情况 O(n²·N) | O(n·N) | O(n·N) | 已接受 |

 ## 算法演练

 我们将每个状态视为“我们已经匹配了长度为 i 的前缀，并且最后使用的段是 j”。 我们希望使用最少数量的片段来到达完整的基因组。 

1. 初始化 DP 表，其中 dp[i][j] 是形成以段 j 结尾的前缀 G[0:i] 所需的最小段数。 除了 dp[0][*] 之外，所有值都以无穷大开始，dp[0][*] 为零，因为在开始之前没有使用任何段。 
2.对于从0到|G|的每个位置i，我们尝试扩展构造。 在位置 i，我们考虑使用每个段 s_k。 
3. 如果段 s_k 与子串 G[i:i+len(s_k)] 匹配，我们可以从位置 i 转换到 i + len(s_k)。 这表示将该段放置在构造中的下一个部分。 
4. 转换时，我们必须强制执行限制，即不能连续两次重复使用同一段。 因此，如果前一段是 k，我们会跳过该转换。 
5. 对于以 i 结尾的所有有效的 prev 状态，我们用 dp[i][prev] + 1 更新 dp[i + len(s_k)][k]，再次遵守限制。 
6. 处理完所有位置后，答案是所有段 j 上的最小 dp[|G|][j]。 如果没有状态可达，则输出-1。 

这样做的原因是，每个有效的构造都对应于通过这些状态的一条路径，并且每个状态都记录到达给定最后一段的前缀的最佳步数。 由于所有转换都添加了一个片段，并且我们探索了所有有效的位置，因此我们不能错过更好的分解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**9

def solve():
    n = int(input())
    G = input().strip()
    m = len(G)

    seg = [input().strip() for _ in range(n)]
    lens = [len(s) for s in seg]

    dp = [[INF] * n for _ in range(m + 1)]
    dp[0] = [0] * n

    for i in range(m + 1):
        for last in range(n):
            if dp[i][last] == INF:
                continue
            cur_cost = dp[i][last]

            for k in range(n):
                if k == last:
                    continue
                L = lens[k]
                if i + L <= m and G[i:i + L] == seg[k]:
                    if cur_cost + 1 < dp[i + L][k]:
                        dp[i + L][k] = cur_cost + 1

    ans = min(dp[m])
    print(-1 if ans == INF else ans)

if __name__ == "__main__":
    solve()
```该代码维护一个按位置和最后使用的段索引的二维 DP 表。 外循环迭代所有位置，并且对于每个可达状态，它尝试所有可能的下一段。 子字符串检查强制放置的有效性。 

一个微妙的细节是 dp[0] 初始化为全零，表示在开始之前我们没有“最后一段”，因此可以首先选择任何段。 这是通过允许位置 0 处的所有最后状态为有效开始来建模的。 

我们还明确禁止 k == last，它编码了相同段不能连续使用的约束。

 ## 边缘情况

 当某个分段是前进的唯一方法但使用它会强制立即重复时，就会出现困难的边缘情况。 考虑带有片段[“AA”]的基因组“AAAA”。 DP 从位置 0 开始，可以使用“AA”移动到位置 2，但在位置 2 处，除了“AA”之外，没有有效的下一段。 该转换被禁止，因为它重复相同的段，因此永远不会到达 dp[4] 并且输出变为 -1。 由于邻接约束，DP 正确地阻止了唯一可能的平铺。 

另一种情况是多个片段长度严重重叠，例如基因组“ATATAT”具有片段[“AT”、“TA”、“A”、“T”]。 DP 探索多种分解，但始终保留每个状态的最小计数。 在位置 2，“AT”和“A”+“T”路径均存在，并且状态压缩确保即使路径在结构上不同，也仅保留最小的段计数。 

第三种情况是存在长段，但由于未来的限制而不是最佳的。 例如，如果一个片段匹配一个大前缀，但稍后强制重复，则 DP 仍会在每个位置评估较小的片段，以确保不会错过全局最优序列。
