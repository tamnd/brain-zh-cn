 ## 解决方案
 ## 问题理解

 我们维护一个数组，最多$10^5$数字。 有两种操作可以在线进行。 

第一个操作更改单个数组元素。 

第二个操作要求对段进行加权和。 权重来自由参数确定的特殊周期性“之字形”序列$z$， 在哪里$2 \le z \le 6$。 

对于固定的$z$，序列看起来像$$1,2,\dots,z,z-1,\dots,2,1,2,\dots$$并永远重复。 

例如：$$z=2:\quad 1,2,1,2,1,2,\dots$$

$$z=3:\quad 1,2,3,2,1,2,3,2,\dots$$

$$z=4:\quad 1,2,3,4,3,2,1,2,\dots$$对于查询$(l,r,z)$，我们必须计算$$\sum_{i=l}^{r} a_i \cdot S^{(z)}_{i-l+1}$$在哪里$S^{(z)}$是因子的锯齿序列$z$。 

挑战在于数组和查询都是动态的。 我们必须回答最多$10^5$运营。 

每个查询的直接计算会扫描整个间隔。 在最坏的情况下，一个查询可能涵盖所有$10^5$元素，并且可能有$10^5$此类查询。 这大约需要$10^{10}$乘法，这是完全不可能的。 

小界限$z$是关键线索。 虽然数组很大，但可能的锯齿形因素只有五个：$2,3,4,5,6$。 

一个微妙的边缘情况来自这样一个事实：查询总是在位置开始锯齿形模式$l$，不在位置$1$。 

考虑：```
a = [10,20,30]
query: l=2, r=3, z=2
```权重为：```
1,2
```不是```
2,1
```因为该模式在查询的左边界处重新开始。 任何仅通过绝对索引存储全局权重模式的解决方案都会产生错误的答案。 

另一个容易犯的错误是假设周期是$2z$。 例如：```
z=3
1 2 3 2 1 2 3 2 ...
```真实的时期是$$2z-2 = 4.$$使用期限$6$会使所有查询错位。 

更新后出现第三个陷阱。 

例子：```
a = [1,1,1]
update position 2 -> 100
query (1,3,2)
```答案就变成了$$1\cdot1+100\cdot2+1\cdot1=202.$$如果更新没有反映在与相关残基类别关联的每个数据结构中，则未来的答案将变得不正确。 

## 方法

 暴力解决方案很简单。 对于每个查询，生成锯齿形权重并从$l$到$r$, 积累$$a_i \cdot \text{weight}.$$一点更新费用$O(1)$，但是范围查询成本$O(r-l+1)$。 和$10^5$运算和长度间隔$10^5$，运行时间达到$10^{10}$，远远超出了极限。 

关键的观察结果是只有五个锯齿形因素是可能的。 

对于固定的$z$，之字形序列是周期性的。 让$$P_z = 2z-2.$$为了$z \le 6$,$$P_z \le 10.$$这意味着分配给数组位置的每个权重仅取决于其索引最多模 10。 

假设我们修复了一个特定的$z$。 对于每个残基类模$P_z$，我们构建一个 Fenwick 树来存储属于该残基类的值。 

那么我们可以问：

 “其中所有数组值的总和是多少$[l,r]$其索引与残差一致$k$模数$P_z$？”

 每个残基类别都从锯齿形图案中贡献恒定的权重。 由于最多有 10 个残基，因此整个查询变成最多 10 个 Fenwick 范围查询的总和。 

更新也很容易。 当$a_p$变化，我们为每个可能的情况更新相应的残基类芬威克树$z$。 只有五个值$z$，因此每次更新都会涉及恒定数量的结构。 

暴力破解会失败，因为它会反复重新计算各个元素的贡献。 周期性结构使我们能够聚合所有共享相同残差以周期为模的位置，从而将每个查询减少到少量恒定数量的 Fenwick 操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n)$每个查询 |$O(1)$| 太慢了 |
 | 最佳 |$O(\log n)$每次操作 |$O(n)$| 已接受 |

 ## 算法演练

 ### 预计算

 对于每个锯齿形因子$z \in \{2,3,4,5,6\}$:

 1. 计算其周期$P = 2z-2$。 
2. 建立一个完整周期的锯齿形权重。 
3.创建$P$芬威克树，每个残数模一棵$P$。 
4. 插入每个数组元素$a_i$进入芬威克树对应$i \bmod P$。 

### 更新操作

 1. 令当前位置的值$p$变老了。 
2. 计算$$\Delta = v - old.$$1. 对于每个 Z 字形因子$z$:

 - 计算$P=2z-2$。 
- 查找残留物$p \bmod P$。 
- 添加$\Delta$到索引处相应的 Fenwick 树$p$。 
2. 存储新的数组值。 

每个 Fenwick 树始终包含其残基类别的当前数组值。 

### 查询操作

 1. 让$P=2z-2$。 
2. 对于每个残留物$r$模数$P$, 获取里面数组值的总和$[l,r]$其索引属于该残基类别。 
3. 确定哪个锯齿权重对应于该残基。 

图案从位置开始$l$，因此残基类别必须相对于$l$。 
4. 将每个残差类别总和乘以其相应的权重。 
5. 添加所有贡献。 

残基数最多为10，因此只需要恒定数量的Fenwick范围查询。 

### 为什么它有效

 对于固定的$z$，之字形序列每隔$P=2z-2$职位。 每个索引具有相同的余数模$P$相对于给定的对齐方式，始终接收相同的权重。 

因此，查询可以分解为余数类模$P$。 芬威克树给出了请求间隔内每个残基类别贡献的总数组值。 将每个类总和乘以其适当的锯齿形权重会产生与逐个元素求和完全相同的总和。 更新保留了这种不变性，因为每个修改的位置都会在包含它的所有残基类结构中更新。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, idx, delta):
        n = self.n
        bit = self.bit
        while idx <= n:
            bit[idx] += delta
            idx += idx & -idx

    def sum(self, idx):
        res = 0
        bit = self.bit
        while idx > 0:
            res += bit[idx]
            idx -= idx & -idx
        return res

    def range_sum(self, l, r):
        return self.sum(r) - self.sum(l - 1)

def build_pattern(z):
    p = 2 * z - 2
    arr = []
    for i in range(1, z + 1):
        arr.append(i)
    for i in range(z - 1, 1, -1):
        arr.append(i)
    return arr

def solve():
    n = int(input())
    a = [0] + list(map(int, input().split()))

    structures = {}

    for z in range(2, 7):
        period = 2 * z - 2
        pattern = build_pattern(z)

        trees = [Fenwick(n) for _ in range(period)]

        for i in range(1, n + 1):
            trees[i % period].add(i, a[i])

        structures[z] = (period, pattern, trees)

    m = int(input())
    out = []

    for _ in range(m):
        q = list(map(int, input().split()))

        if q[0] == 1:
            _, p, v = q
            delta = v - a[p]
            a[p] = v

            for z in range(2, 7):
                period, pattern, trees = structures[z]
                trees[p % period].add(p, delta)

        else:
            _, l, r, z = q

            period, pattern, trees = structures[z]

            ans = 0

            for residue in range(period):
                s = trees[residue].range_sum(l, r)

                offset = (residue - (l % period)) % period
                weight = pattern[offset]

                ans += s * weight

            out.append(str(ans))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现为每个可能的锯齿形因子存储一个 Fenwick 树家族。 对于固定期限$P$, 残留物$r$恰好包含索引满足的数组位置$i \bmod P=r$。 

查询逻辑是微妙的部分。 锯齿形模式从查询的左端点开始，而不是从索引 1 开始。表达式```
offset = (residue - (l % period)) % period
```计算该残差出现在相对于查询开始的周期性模式内的位置。 

芬威克树按原始数组位置进行索引。 这允许普通的范围和查询而无需任何坐标转换。 

所有算术都使用 Python 整数，它可以安全地处理最大可能的答案。

 ## 边缘情况

 考虑：```
3
10 20 30
1
2 2 3 2
```模式为$z=2$是$1,2$。 该算法计算残差类和并将它们移位$l=2$。 位置 2 接收权重 1，位置 3 接收权重 2。结果是$$20+60=80.$$任何使用绝对索引而不是查询开始来对齐权重的实现都会错误地生成$70$。 

考虑：```
5
1 1 1 1 1
1
2 1 5 3
```期间是$2z-2=4$，不是 6。权重是```
1 2 3 2 1
```给予$$9.$$该算法以 4 为模存储数据，因此可以正确表示重复结构。 

考虑：```
3
1 1 1
2
1 2 100
2 1 3 2
```更新后，增量为 99。算法将该增量应用于每个受影响的 Fenwick 结构。 然后查询计算$$1\cdot1+100\cdot2+1\cdot1=202.$$由于所有结构都会立即更新，因此不会保留陈旧值，并且答案是正确的。
