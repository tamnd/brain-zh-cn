 ## 解决方案
 ## 问题理解

 我们有两个二进制矩阵。 一个转变`(x, y)`意味着该细胞`(i, j)`第一个矩阵与单元格进行比较`(i + x, j + y)`第二个矩阵的。 

对于固定班次，重叠因子是重叠单元的乘积之和。 由于所有值都是`0`或者`1`，产品贡献`1`恰好当两个重叠单元格都包含`1`。 

查看问题的另一种方法是仅查看包含以下内容的位置`1`。 对于给定的班次，重叠因子只是`1`单元格（每个表中的一个）在应用该转变后变得对齐。 

我们必须找到使该计数最大化的任何转变。 

两个矩阵的维数最多为`50 × 50`。 这意味着每个矩阵最多包含`2500`细胞。 检查每个可能的转变和每个单元对的解决方案将执行数千万次操作。 这并不是很大，但有一个更清晰的观察，可以直接得出预期的解决方案。 

事实上，矩阵只包含`0`和`1`是关键的结构属性。 仅包含以下位置`1`事情。 由于保证每个矩阵至少包含一个`1`，我们可以完全专注于这些位置。 

一个常见的错误是只考虑重叠区域。 最佳移位可能会将一个矩阵的大部分放置在另一个矩阵之外。 例如：```
A:
1

B:
1
```每个班次都会产生重叠因子`1`或者`0`。 移位值本身不受矩阵维度的限制。 

另一个容易犯的错误是计算错误方向的位移。 如果一个`1`第一个矩阵位于`(r1, c1)`和一个`1`第二个矩阵是在`(r2, c2)`，对齐它们的移位是：```
x = r2 - r1
y = c2 - c1
```反转减法会产生相反的移位并计算错误的对齐。 

当多个班次达到相同的最大重叠时，会出现最后一个微妙的情况。 该语句允许任何最佳答案，因此我们只需要记住计数最大的一个班次。 

## 方法

 最直接的解决办法就是尝试一切可能的转变。 由于矩阵最多为`50 × 50`，行移位范围大致为`-49`到`49`，列移位的作用相同。 对于每个班次，我们可以扫描所有单元格并计算重叠的单元格对。 

这种方法是正确的，因为它确实评估了每个候选轮班的重叠因子。 问题是效率。 有大约`100 × 100 = 10,000`可能的班次，每个班次可能需要扫描最多`2500`细胞。 最坏情况下的成本约为 2500 万次电池检查。 

关键的观察是只有含有`1`有助于重叠因子。 

假设一个`1`第一个矩阵位于`(ra, ca)`和一个`1`在第二个矩阵中位于`(rb, cb)`。 这两个单元格恰好在一个转变下对齐：```
(rb - ra, cb - ca)
```如果许多对产生相同的偏移，则所有这些对在该偏移下同时对齐。 

这将问题转化为计数问题。 对于每对由`1`从第一个矩阵和`1`从第二个矩阵计算对齐它们的移位并计算每个移位出现的次数。 

具有最大频率的移位正是产生最大数量的重叠对的移位。 

由于每个矩阵最多包含`2500`，最多有`2500 × 2500 = 6.25`万对。 这完全符合 Python 的限制。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(na·ma·nb·mb) 通过所有移位和扫描 | O(1) | O(1) | 已被接受，但不太优雅 |
 | 最佳 | O(A·B) 其中 A 和 B 是 1 的计数 | 最坏情况下的 O(A·B) | 已接受 |

 ## 算法演练

 1. 读取两个矩阵。 
2.提取包含的每个单元格的坐标`1`在第一个矩阵中。 
3. 提取包含的每个单元格的坐标`1`在第二个矩阵中。 
4. 从shift创建哈希图`(x, y)`到它的频率。 
5. 对于每一个`1`细胞`(ra, ca)`在第一个矩阵和每个`1`细胞`(rb, cb)`在第二个矩阵中，计算：```
x = rb - ra
y = cb - ca
```增加轮班频率`(x, y)`。 

这种转变是对齐这两个细胞的独特翻译。 
6. 跟踪频率最大的班次。 
7. 输出该班次。 

### 为什么它有效

 考虑任何固定班次`(x, y)`。 

一对`1`当且仅当：```
rb = ra + x
cb = ca + y
```重新排列给出：```
x = rb - ra
y = cb - ca
```因此，每个贡献对恰好对应于一次移位的发生`(x, y)`在我们的计数过程中。 

相反，每对都算作轮班`(x, y)`在这种转变下变得一致并做出贡献`1`到重叠因子。 

因此，为移位存储的频率恰好等于其重叠因子。 最大化频率可以最大化重叠因子，这证明了正确性。 

## Python 解决方案```python
import sys
from collections import defaultdict

input = sys.stdin.readline

def solve():
    na, ma = map(int, input().split())

    ones_a = []
    for i in range(na):
        row = input().strip()
        for j, ch in enumerate(row):
            if ch == '1':
                ones_a.append((i, j))

    nb, mb = map(int, input().split())

    ones_b = []
    for i in range(nb):
        row = input().strip()
        for j, ch in enumerate(row):
            if ch == '1':
                ones_b.append((i, j))

    cnt = defaultdict(int)

    best_shift = (0, 0)
    best_count = -1

    for ra, ca in ones_a:
        for rb, cb in ones_b:
            shift = (rb - ra, cb - ca)
            cnt[shift] += 1

            if cnt[shift] > best_count:
                best_count = cnt[shift]
                best_shift = shift

    print(best_shift[0], best_shift[1])

if __name__ == "__main__":
    solve()
```代码的第一部分提取包含的所有位置`1`。 其他所有单元格都是无关的，因为涉及零的乘积永远不会对重叠因子产生影响。 

嵌套循环枚举每一对`1`细胞。 对于每一对，我们计算对齐它们的唯一移位。 字典计算每个班次有多少对投票。 

当班次计数超过当前最大值时，我们将其存储为最佳答案。 由于该语句接受任何最佳移位，因此不需要平局逻辑。 

使用从零开始的坐标而不是从一开始的坐标不会影响计算的平移。 减法的两个端点都移动相同的常数，因此差值保持相同。 

不存在溢出问题，因为坐标差异最多约为`50`在幅度上。

 ## 边缘情况

 考虑两个矩阵，每个矩阵包含一个`1`:```
1 1
1
1 1
1
```唯一的一对产生移位`(0,0)`。 该转变的频率是`1`，所以算法返回`(0,0)`。 不需要计算重叠面积。 

考虑这样一种情况，最佳移位将一个矩阵大部分移到另一个矩阵之外：```
1 2
10
2 2
00
01
```的位置是`(0,0)`和`(1,1)`。 他们的对齐偏移是`(1,1)`。 该算法计算该对并返回`(1,1)`即使大多数细胞位于重叠区域之外。 这是正确的，因为重叠因子仅取决于对齐的因子。 

考虑多个最佳答案：```
1 2
11
1 2
11
```两班轮班`(0,0)`和其他几个可能会在处理过程中收到计数，但是`(0,0)`达到最大重叠系数`2`。 如果在另一个示例中另一个移位与最大值相关，则算法将返回最先达到最大值的那个。 该语句明确允许任何最佳答案，因此这种行为是有效的。 

最后，考虑一下常见的符号错误。 如果一个`1`出现在`(0,0)`在第一个矩阵中和`(1,1)`在第二个矩阵中，对齐移位为：```
(1 - 0, 1 - 0) = (1,1)
```使用`(0 - 1, 0 - 1)`会产生`(-1,-1)`，这会将第二个矩阵向错误的方向移动。 该算法一致地计算`rb - ra`和`cb - ca`，避免这个错误。
