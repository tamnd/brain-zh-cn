 ## 解决方案
 ## 问题理解

 我们得到一个从 1 到 n 的整数序列和一个奇数 k。 在一次操作中，我们可以从当前序列中选取任意 k 个元素，计算它们的中值，然后删除剩余的 k-1 个元素，只留下中值。 我们重复此操作任意次。 对于每个测试用例，我们都会被问到是否可以将原始序列缩减为长度为 m 的特定目标序列 b（按严格递增顺序给出）。 

输入参数 n 和 k 可以非常大，在所有测试用例中最多可达 2·10^5，并且我们最多可能有 1000 个测试用例。 朴素模拟中的每个步骤都涉及选择子集并重复计算中位数，这很快就会变成指数，因为 n 元素序列的 k 元素子集的数量巨大。 因此，单纯的模拟是不可行的。 对于每个测试用例，约束要求 n 采用线性或近线性方法。 

当目标序列 b 包含位于原始序列最开始或最末尾的元素时，就会出现一个重要的边缘情况。 例如，如果 b 包含 1 但 k=3，我们无法删除元素以使 1 生存，除非我们将其包含在所选 k 元素组的中位数中。 类似地，如果 b 包含 n，我们需要它被选为中位数才能生存。 如果目标序列 b 只是数组中心的单个元素，如果 k 不够大以正确隔离它，则可能无法到达。 简单的方法可能无法认识到元素相对于数组末端的位置限制了哪些元素可以生存。 

## 方法

 蛮力方法是模拟选择 k 个元素、计算它们的中值并删除其余元素的所有可能方式。 我们将递归或迭代地尝试所有操作序列，直到序列减少到长度 m，然后检查它是否与 b 匹配。 这种方法是正确的，但不可行，因为 k 元素子集的数量是 n 的组合。 即使对于 n=50 和 k=5 的适度值，也有超过 200 万个可能的第一步。 当n达到2·10^5时，这是完全不可能的。 

关键的观察是可以根据立场重新构建问题。 每个操作都会将序列大小减少 k-1，并且中位数始终保留。 为了从长度为 n 的原始序列到达长度为 m 的目标序列 b，我们需要恰好删除 n-m 个元素。 每个操作都会删除 k-1 个元素，因此我们正好需要 (n-m) / (k-1) 次操作。 如果 (n-m) 不能被 k-1 整除，则目标不可能实现。 b 的每个元素的左侧和右侧必须有足够的元素，以便它可以作为某个选定的 k 元素组中的中位数出现。 具体来说，b 中的第 i 个元素必须满足：考虑到我们可以在每侧删除的元素数量，它不能太靠近左端或太靠近右端。 这将问题转化为每个元素的简单算术检查，该算术检查在 m 中呈线性，使其可行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O( (n 选择 k) ^ (n-m) ) | O(n) | 太慢了|
 | 最佳 | 每个测试用例 O(m) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 计算需要删除的元素数量，n - m。 计算所需的步骤数：steps = (n - m) // (k - 1)。 如果 (n - m) 不能被 k-1 整除，则打印 NO 并返回此测试用例，因为不可能以整数步减少到目标长度。 
2. 计算每个候选中位数左侧和右侧可以移除的元素数量。 对于目标序列中的每个元素 b[i]，原始序列中其左侧可以存在的最大元素数为 i * (k-1)，因为每个先前的中值运算最多删除 k-1 个元素。 同样，右侧元素的最大数量为 (m-i-1) * (k-1)。 检查 b[i] 是否在有效范围内：b[i] 在原始序列（从 1 开始）中的位置必须满足 left ≤ b[i]-1 ≤ n-right。 如果没有元素满足此要求，则打印 NO。 
3. 如果所有元素都通过检查，则打印 YES。 这里的贪婪原则是 b 的每个元素作为其中一个步骤中的中位数存活下来，并且被足够的元素包围以填充所选组的剩余 k-1 个点。 这些操作总是可以贪婪地安排而不会发生冲突，因为我们只检查位置可行性。 

为什么它有效：不变的是 b 的每个元素必须作为某个大小为 k 的组中的中位数出现。 检查确保每个候选元素两侧都有足够的元素来填充该组。 由于移除的元素总数等于 n-m 并且 k 是奇数，因此序列总是可以从外部向 b 的中位数贪婪地减少。 这保证了正确性，而无需显式模拟每个操作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_form_sequence(n, k, m, b):
    steps_needed = n - m
    if steps_needed % (k - 1) != 0:
        return "NO"
    left_remove = 0
    right_remove = 0
    for i in range(m):
        left_max = i * (k - 1)
        right_max = (m - i - 1) * (k - 1)
        pos = b[i] - 1
        if pos < left_max or pos > n - 1 - right_max:
            return "NO"
    return "YES"

t = int(input())
for _ in range(t):
    n, k, m = map(int, input().split())
    b = list(map(int, input().split()))
    print(can_form_sequence(n, k, m, b))
```该代码首先检查要删除的元素总数是否能被 k-1 整除。 然后，它迭代目标序列的每个元素，并验证它在原始序列的左侧和右侧是否有足够的空间来显示为中位数。 从基于 1 的索引到基于 0 的索引的转换很微妙，但通过在比较位置时从 b[i] 中减去 1 来处理。 仔细考虑边界条件以避免相差一的错误。
