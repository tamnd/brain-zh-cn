 ## 问题理解

 任务是重建一组四个整数，表示盒子中的糖果数量，使得三个属性相等：算术平均值、中位数和范围。 我们以任意顺序给出这四个数字（0 到 4）的一些子集。 输出应确认是否可以为缺失的框分配值以满足条件，如果可以，则提供任何有效的分配。 

算术平均值是四个数字之和除以四，中位数是排序后两个中间数字的平均值，极差是最大和最小数字之间的差。 为了使条件成立，这三个数字必须相等。 这种平等对数字产生了强烈的约束：一旦设置了最小和最大的数字，其他两个通常会被强制或受到强烈限制。 

给定盒子的数量，$n$，较小，为 0 到 4，并且糖果数量本身为中等，为 1 到 500。这表明对缺失数字的可能配置进行暴力破解或枚举方法是可行的，因为缺失数字很少（最多 4 个），并且所有可能的候选数字都在合理范围内。 

当所有给定的框都相同或仅给出极端数字时，就会出现不明显的边缘情况。 例如，如果$n=2$并且两个数字都是 1，满足条件的唯一方法是将两个较大的数字相加，使得中位数、均值和极差都重合。 粗心的实现可能无法考虑数字可以重复以及给定数字的多重排序是可能的。 

## 方法

 最简单的方法是暴力破解所有可能的包含给定数字的四个数字组。 对于每个候选者，对其进行排序，计算平均值、中位数和极差，并检查它们是否相等。 这是可行的，因为最多有四个数字，并且这些值可以限制在 1 到 500 的范围内（或扩展到$10^6$根据问题陈述）。 然而，暴力破解变得乏味，因为组合的数量虽然有限，但需要仔细检查以避免不必要的排列。 

关键的见解是有四个数字$x_1 \le x_2 \le x_3 \le x_4$，算术平均值、中位数和极差都等于一个数字$d$意味着一个简单的结构：四个数字可以用以下形式表示$[a, b, c, d] = [m - k, m - k, m + k, m + k]$或其排列，其中$m$是中位数/平均值/范围。 由此，我们只需要考虑一些候选模式：要么所有数字都相等，要么数字形成两个相等的对。 一旦给出一些数字，通常可以使用代数直接计算缺失的数字。 

该解决方案通过枚举可能包含给定数字的所有有效“特殊四元组”，并检查缺失的数字是否落在允许的范围内来进行。 这种方法将问题简化为一小组算术计算和条件检查。

 ## 算法演练

 1. 阅读$n$以及现有糖果计数的列表。 对现有数字进行排序以简化有关最小、最大和中值位置的推理。 
2. 枚举“特殊数字”所有可能的候选值$d$表示平均值=中位数=范围。 根据丢失框的可能数量，使用从有效四元组结构导出的公式计算丢失框的潜在值。 例如，如果我们有两个数字并想要一个模式$[x, x, y, y]$，求解$y$就给定的数字而言。 
3. 对于每个候选，检查缺失的数字是否为整数并且位于允许的范围 1 到$10^6$。 
4. 如果至少存在一项有效分配，则输出“YES”和缺失的数字。 否则，输出“NO”。 

工作原理：任何满足平均值 = 中位数 = 范围属性的四元组必须要么所有数字都相等，要么是两个相等对的形式。 通过根据这些模式系统地应用代数关系来查找缺失的数字，我们可以生成所有可能的解决方案，而无需进行详尽的枚举。 这些约束保证如果存在正整数解，它将在 1 到$10^6$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = sorted([int(input()) for _ in range(n)])
    
    # Helper to check if all numbers in a list are within 1..10^6
    def valid(lst):
        return all(1 <= x <= 10**6 for x in lst)
    
    # Try to complete the list to a special quadruple
    for x in range(1, 10**6 + 1):
        # All equal pattern
        if n == 0:
            print("YES")
            print(x)
            print(x)
            print(x)
            print(x)
            return
        if n == 1:
            needed = [x, x, x]
            if valid(needed):
                print("YES")
                for b in needed:
                    print(b)
                return
        if n == 2:
            b = 2 * x - sum(a)
            if valid([b, b]):
                print("YES")
                print(b)
                print(b)
                return
        if n == 3:
            b = 4 * x - sum(a)
            if valid([b]):
                print("YES")
                print(b)
                return
        if n == 4:
            if sum(a)/4 == x and (a[1]+a[2])/2 == x and a[3]-a[0] == x:
                print("YES")
                return
    print("NO")

if __name__ == "__main__":
    solve()
```代码系统地尝试每个候选特殊号码$x$并根据现有盒子的数量填写缺失的数字。 有效性检查确保数字保持在范围内。 排序简化了中值计算并增强了一致性。 特殊情况$n=0$或者$n=4$被明确处理。

 计算$b = 2*2 - (1+2) = 1$产生 [1,1] 缺失，给出四元组 [1,2,1,1]，不满足平均值 = 中位数 = 范围。 算法返回“NO”。
