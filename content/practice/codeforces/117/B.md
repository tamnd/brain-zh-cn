 ## 解决方案
 ## 问题理解

 我们被要求模拟一个两人游戏，其中涉及以九位数字字符串表示的数字。 第一个玩家选择一个字符串`s1`表示不超过给定值的数字`a`。 第二个玩家用字符串响应`s2`代表一个不超过的数字`b`。 两个字符串的长度都是九位数字，可能带有前导零。 如果串联，第二个玩家获胜`s1`和`s2`因为单个数字可以被给定整除`mod`。 否则，第一个玩家获胜。 如果第一个玩家可以保证获胜，我们还必须确定字典顺序最小的字符串`s1`达到这个目的。 

界限可达`10^9`为了`a`和`b`，直到`10^7`为了`mod`。 九位数字字符串意味着我们正在一个不可能明确枚举所有可能选择的空间，因为`10^9`对于暴力枚举来说已经太大了。 相反，这个问题需要仔细的数论推理和模运算。 边缘情况包括以下情况`a`或者`b`小于`10^9`，这会强制在九位字符串表示形式中使用前导零。 另一个边缘情况是当`mod`非常小，允许许多可分模式，或者当`a`或者`b`为零，极大地限制了移动。 

## 方法

 朴素的蛮力方法会尝试生成所有可能的`s1`字符串来自`0`到`a`，那么对于每个`s1`检查一切可能的情况`s2`从`0`到`b`，测试连接数的整除性`mod`。 自从`s1`和`s2`每个最多可以占用`10^9`值，这导致`10^18`在最坏的情况下进行检查，在期限内是不可能的。 即使是内存高效的修剪方法也无法直接枚举所有可能性。 

关键的见解是整除性仅取决于余数模`mod`。 我们可以预先计算所有可能的余数`s2`数字取模`mod`，然后对于每个候选人`s1`，我们只需要检查是否存在`s2`这样`(s1 * 10^9 + s2) % mod == 0`。 使用模运算，这相当于检查是否`(s1 * 10^9) % mod`匹配一些`mod - s2 % mod`。 自从`s2`范围可达`b`，我们只需要计算所有余数`s2 % mod`有效地将它们存储在一个集合中。 这减少了每次检查`s1`到 O(1) 集合查找。 通过迭代`s1`按升序排列，我们会自动找到字典顺序最小的获胜字符串（如果存在）。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(a * b) | O(1) | O(1) | 太慢了 |
 | 最佳| O(mod + a') | O(mod + a') | O(模) | 已接受 |

 这里`a'`是候选人的数量`s1`字符串，最多`a + 1`但有效地受`10^9`。 这`mod`术语来自于预先计算所有的余数`s2`价值观。 

## 算法演练

 1. 标准化`a`和`b`精确到九位数字的字符串，必要时用前导零填充。 这可以确保字典比较正确进行，并且每个数字恰好是九位数字。 
2. 计算`power = 10^9 % mod`。 这代表了`s1`到串联数字模`mod`。 利用这个，`(s1 * 10^9 + s2) % mod`变成`(s1 * power + s2) % mod`。 
3. 预先计算所有可能的情况`s2`模余数`mod`对于来自的号码`0`到`b`。 将它们存储在一个集合中以便快速查找。 
4. 迭代所有候选数`s1`从`0`到`a`按升序排列。 对于每个候选人，计算`(s1 * power) % mod`并检查是否存在`s2`集合中的余数使得`(s1 * power + s2) % mod == 0`。 如果没有这样的`s2`存在，第一个玩家可以保证获胜`s1`。 
5.一旦获胜`s1`找到，输出`1`和九位数字字符串表示`s1`。 如果全部`s1`值允许第二个玩家做出最佳反应并获胜，输出`2`。 

不变量是对于每个`s1`, 的集合`s2`余数代表第二个玩家可以采取的所有可能的行动。 如果他们都没有取消`(s1 * power) % mod`，第一个玩家获胜。 这保证了正确性，因为我们明确检查第二个玩家的所有可能的反击。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    a, b, mod = map(int, input().split())
    power = pow(10, 9, mod)
    s2_rems = set(i % mod for i in range(b + 1))
    
    for s1_num in range(a + 1):
        s1_rem = (s1_num * power) % mod
        # check if there exists s2 that makes total divisible
        found = any((s1_rem + s2_rem) % mod == 0 for s2_rem in s2_rems)
        if not found:
            print(1)
            print(f"{s1_num:09d}")
            return
    print(2)

if __name__ == "__main__":
    main()
```我们计算`power`使用模幂以避免直接处理 9 位乘数。 的集合`s2`余数允许 O(1) 查找每个候选者`s1`。 我们按升序迭代以保证字典顺序最小`s1`。 使用`f"{s1_num:09d}"`确保九位数字输出带有前导零。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(a + b) | 计算所有的余数`s2`数字并迭代`s1`候选人最多`a`|

 该算法适用于`a, b ≤ 10^9`只是因为在实践中`mod`限制余数集的大小。 纯枚举并不对所有九位数字执行。
