 ## 解决方案
 ## 问题理解

 电梯遵循完全确定性的循环。 

从楼层开始`1`在某个时间`0`，每秒爬一层楼，直到到达楼层`m`，然后立即反转方向并回到地板`1`，再次每秒移动一层楼。 到达楼层后`1`，相同的模式永远重复。 

对于每个参与者，我们知道三件事。 我们知道他们开始的楼层、他们想要到达的楼层以及他们到达起始楼层的时刻。 如果电梯当前停在该楼层，则参与者立即进入。 任务是计算到达目的地楼层的最早可能时间。 

关键细节是电梯方向很重要。 一个向上走的人不能在电梯到达他们的楼层时就简单地进入电梯。 他们必须在向上通过时登机。 这同样适用于向下运动。 

这些限制完全排除了模拟。 最多可以有`10^5`查询，楼层和时间都可以大到`10^8`。 即使对于一个查询，逐秒模拟也需要多达数十亿次操作。 我们需要一个`O(1)`每个参与者的公式。 

一些边缘情况很容易被错误处理。 

考虑有人已经站在目标楼层。 

输入：```
1 10
5 5 100
```输出：```
100
```电梯在这里无关紧要。 粗心的实现仍然可能会计算等待时间和移动。 

当电梯准确到达楼层时，会出现另一个棘手的情况`t`。 

输入：```
1 4
1 2 0
```输出：```
1
```时`0`，电梯已到楼层`1`，因此参与者立即进入。 如果我们不小心要求严格延迟到达，我们就会错误地等待下一个周期。 

方向不匹配也会导致错误。 

输入：```
1 4
2 4 3
```输出：```
9
```时`3`，电梯确实到了楼层`2`，但它正在向下移动，因为序列是：`1 -> 2 -> 3 -> 4 -> 3 -> 2 -> 1`。 

参与者想要向上，因此请及时登机`3`是没用的。 他们必须等到下一次向上访问的时间`7`。 

第一层和最后一层的行为有所不同，因为电梯在那里反转方向。 

输入：```
1 5
5 1 4
```输出：```
8
```时`4`，电梯正好在楼层`5`并立即开始向下移动，以便参与者可以立即登机。 错误地对待转折点常常会导致相差甚远的错误。 

## 方法

 强力解决方案实际上可以模拟电梯随时间的移动。 每一秒，我们都会跟踪电梯楼层和方向，对于每个参与者，我们都会等待电梯到达正确的楼层，同时朝所需的方向移动。 

这在逻辑上是有效的，因为电梯路径是确定性的。 最终，每个有效的登机时刻都会在模拟过程中出现。 

问题在于规模。 电梯周期长度为`2 * (m - 1)`，几乎可以达到`2 * 10^8`。 即使为每个参与者模拟一个完整的周期也太慢了。 和`10^5`参与者，操作计数变得完全不可行。 

重要的观察结果是电梯运动是周期性的。 

对于一个楼层`x`：

 如果电梯向上移动，则到达楼层`x`有时：```
x - 1 + k * cycle
```如果电梯向下移动，则到达楼层`x`有时：```
(m - x) + (m - 1) + k * cycle
```在哪里：```
cycle = 2 * (m - 1)
```一旦我们知道了所需的方向，我们就可以直接计算出大于或等于的第一个有效登机时间`t`。 

假设参与者想要向上。 那么我们需要第一次：```
x - 1 + k * cycle >= t
```我们可以计算`k`用简单的算术代替模拟。 

登机后，行程时间仅为：```
abs(f - s)
```整个问题变成了每个查询的恒定时间算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(1) | O(1) | 太慢了 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.计算电梯周期长度：```
cycle = 2 * (m - 1)
```过了这么多秒，电梯返回楼层`1`在相同的状态下。 
2. 对于每个参与者，首先检查是否`s == f`。 

如果参与者已经从目的地出发，答案很简单`t`。 
3. 确定所需的运动方向。 

如果`f > s`，参与者必须在向上通过时登机。 

否则，他们必须在向下通过时登机。 
4. 计算电梯第一次到达楼层的时间`s`向所需的方向。 

对于向上运动，一个周期内的基址访问时间为：```
base = s - 1
```对于向下运动：```
base = (m - 1) + (m - s)
```5. 找到最小的非负整数`k`这样：```
base + k * cycle >= t
```这是天花板划分：```
k = max(0, (t - base + cycle - 1) // cycle)
```6. 登机时间变为：```
board = base + k * cycle
```7. 添加行驶距离：```
answer = board + abs(f - s)
```### 为什么它有效

 电梯轨迹每次都完美重复`2 * (m - 1)`秒。 对于每一楼层和方向对，每个周期内恰好有一个访问时间。 该算法计算规范的访问时间并直接跳转到电梯到达时间不早于的第一个周期`t`。 

由于电梯每秒不间断地移动一层楼，因此从`s`到`f`登机后总是准确无误`abs(f - s)`。 由于我们总是选择最早的有效登机时间，因此到达时间最短。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    cycle = 2 * (m - 1)

    ans = []

    for _ in range(n):
        s, f, t = map(int, input().split())

        if s == f:
            ans.append(str(t))
            continue

        if f > s:
            base = s - 1
        else:
            base = (m - 1) + (m - s)

        if t <= base:
            board = base
        else:
            k = (t - base + cycle - 1) // cycle
            board = base + k * cycle

        arrival = board + abs(f - s)
        ans.append(str(arrival))

    print("\n".join(ans))

solve()
```第一部分计算周期长度。 电梯路径从`1`最多`m`并回到`1`正好需要`2 * (m - 1)`秒。 

对于每个查询，特殊情况`s == f`立即处理。 忘记这种情况通常会产生错误的答案，因为一般的登机逻辑假设参与者必须实际乘坐电梯。 

变量`base`代表电梯到达楼层时一个周期内的第一个时刻`s`向所需的方向。 

对于向上旅行：```
base = s - 1
```因为电梯从楼层开始`1`在某个时间`0`并每秒爬一层楼。 

对于向下行程：```
base = (m - 1) + (m - s)
```电梯先花`m - 1`几秒钟到达顶楼，然后又一秒钟`m - s`秒下降到地板`s`。 

天花板除法步骤是核心算术技巧：```
(t - base + cycle - 1) // cycle
```这将计算所需的最小完整周期数，以便访问时间至少为`t`。 

实施中认真处理`t <= base`分别地。 如果没有该分支，除法表达式中可能会出现负值。 

Python 整数可以轻松处理这里的最大值，因为答案仍然低于`10^9`。

 ## 边缘情况

 考虑参与者已经在目标楼层开始的情况。 

输入：```
1 10
5 5 100
```该算法立即检测到`s == f`并返回`100`。 根本没有登机逻辑运行。 这避免了意外地迫使参与者不必要地乘坐电梯。 

现在考虑确切的电梯到达时间。 

输入：```
1 4
1 2 0
```对于向上运动：```
base = 1 - 1 = 0
```自从：```
t = 0
```算法立即出现：```
board = 0
arrival = 0 + 1 = 1
```平等案件很重要。 使用严格的比较会错误地将登机延迟一个完整的周期。 

方向不匹配是另一种微妙的情况。 

输入：```
1 4
2 4 3
```周期长度为：```
6
```向上访问楼层`2`发生在：```
1, 7, 13, ...
```向下访问发生在：```
5, 11, ...
```参加者准时到达`3`，所以附近的访问都不起作用。 该算法正确地选择了下一次向上访问的时间`7`，生产：```
7 + 2 = 9
```最后，考虑顶层转折点。 

输入：```
1 5
5 1 4
```对于向下运动：```
base = (5 - 1) + (5 - 5) = 4
```自从`t == base`，在下行阶段，登机立即在顶层进行。 旅行时间是`4`，因此到达时间变为`8`。 

This confirms the reversal behavior is handled correctly without any off-by-one errors.
