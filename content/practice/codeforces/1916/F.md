 ## 解决方案
 ## 问题理解

 我们得到了学校学生的社交图谱，其中有一些已知的友好关系。 学生总数为$n_1 + n_2$， 在哪里$n_1$和$n_2$是两个不同群体所需的规模：计算机科学家和数学家。 每个学生都可能是其他人的朋友，这些友谊形成了一个相互联系的网络，因此即使在删除一个人之后，其他人仍然通过某种路径保持联系。 

我们的任务是将所有学生准确地分成两组大小$n_1$和$n_2$，这样在每个小组中，任何两个学生都可以通过仅涉及该小组成员的友谊来相互联系。 换句话说，每个群体必须形成原始社交图的连通子图。 可能存在多个分区，任何有效的解决方案都是可接受的。 

约束条件告诉我们，所有测试用例中的学生总数不超过 2000，好友总数不超过 5000。这意味着$O(N+M)$或者$O((N+M)\log N)$每个测试用例的方法是可行的，但是任何对每个测试用例的学生数量进行二次运算的解决方案都是有风险的。 

非明显的边缘情况包括已经是单链或星形的图，或者当一组的大小为 1 时。例如，如果$n_1 = 1$和$n_2 = 4$，并且友谊图是一条由 5 个节点组成的简单线，如果为单例组选择多个学生，则始终选择固定连接组件的简单方法可能会失败。 另一个微妙的情况是当图形有循环时； 任何分区都必须尊重连通子图约束，而不是任意分配任何学生。 

## 方法

 暴力解决方案将考虑大小的所有子集$n_1$并检查归纳子图是否连通。 这原则上是正确的，但完全不可行，因为子集的数量会组合增长并检查连接成本$O(N+M)$每个子集。 对于最坏的情况$n_1 + n_2 \approx 2000$，这种方法将花费太长时间。 

实现高效解决方案的关键观察来自于有保证的连接属性。 由于该图是 2 顶点连接的（删除任何一个节点都会使图保持连接），因此每个连接的组件都是鲁棒的。 这意味着我们可以通过从任何起始节点执行 BFS 或 DFS 来安全地增长一个组，取第一个$n_1$我们为一组遇到的节点。 其余节点自动形成连通子图，因为无法通过删除已分配的节点来断开原始图。 这种见解将问题简化为简单的图形遍历，并结合仔细计数以尊重组大小。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（所有子集 + 连接性检查）| O(2^(N) * (N+M)) | O(2^(N) * (N+M)) | O(N+M) | 太慢了 |
 | BFS/DFS 组选择 | O(N+M) | O(N+M) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，请阅读$n_1$,$n_2$， 和$m$，随后是$m$友谊联系。 
2. 构建友谊图的邻接表。 每个学生都表示为一个节点，每个友谊都是一条无向边。 
3. 初始化一个大小为visited的数组$n_1+n_2$跟踪哪些学生被分配到一个组。 
4. 从任何未访问的节点启动 DFS（或 BFS）。 当我们遍历图表时，将学生添加到第一组，直到我们收集到$n_1$学生。 
5. 一旦第一组达到规模$n_1$，将剩余未访问的学生标记为属于第二组。 由于该图是全连通且 2 顶点连通的，因此剩下的这些学生形成连通子图，满足问题的约束。 
6. 以任意顺序输出两组，确保每组恰好包含规定数量的学生。 

工作原理：不变的是连接组件的任何 DFS 或 BFS 遍历都会按连接顺序访问节点。 通过之后停止$n_1$节点，我们保证这些节点形成一个连通子图。 其余节点也保持连接，因为删除 2 顶点连接图的连接子图会使其余节点保持连接。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10000)

def solve():
    t = int(input())
    for _ in range(t):
        n1, n2, m = map(int, input().split())
        n = n1 + n2
        adj = [[] for _ in range(n)]
        for _ in range(m):
            a, b = map(int, input().split())
            adj[a-1].append(b-1)
            adj[b-1].append(a-1)
        
        visited = [False]*n
        group1 = []

        def dfs(u):
            if len(group1) >= n1:
                return
            visited[u] = True
            group1.append(u)
            for v in adj[u]:
                if not visited[v]:
                    dfs(v)

        dfs(0)
        group2 = [i for i in range(n) if i not in group1]

        print(' '.join(str(x+1) for x in group1))
        print(' '.join(str(x+1) for x in group2))

if __name__ == "__main__":
    solve()
```DFS 从第一个学生开始，并准确地填充第一组$n_1$节点。 因为图是连通的，所以所有这些节点都是连通的。 其余节点自动形成第二组。 我们小心地处理索引，因为输入是从 1 开始的，但 Python 列表是从 0 开始的。 我们还确保一旦第一个组达到其所需的大小就停止 DFS，以避免意外添加太多节点。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N+M) | 我们用DFS最多遍历每个节点和边一次。 |
 | 空间| O(N+M) | 邻接表存储边，访问数组存储N个节点。 |

 给定$N \le 2000$和$M \le 5000$，这非常适合 1 秒的时间限制。
