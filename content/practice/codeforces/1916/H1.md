 ## 解决方案
 ## 问题理解

 我们正在研究一个$n \times n$其条目位于大小有限域中的矩阵$p$，意味着每个条目都是一个整数模$p$算术的行为类似于域上的线性代数。 对于每个可能的排名$r$，我们想要计算有多少个这样的矩阵具有精确的排名$r$，并报告所有这些计数$r \le k$, 取模$998244353$。 

这里矩阵的秩是由行（或列）跨越的向量空间的维数，因此它捕获矩阵包含多少个独立方向。 A级$0$矩阵是全零矩阵，而rank$n$矩阵是满秩可逆矩阵。 

困难在于$n$可以大到$10^{18}$，因此任何构建甚至迭代行或列的方法都是不可能的。 唯一可用的结构是代数计数公式，它依赖于$n$,$p$， 和$r$，而不是显式矩阵构造。 

一个关键的限制是$k \le 5000$，所以我们只需要前几个等级。 虽然$n$是巨大的，$r$计算量仍然很小，这强烈表明答案必须取决于由以下索引的产品$r$，不是由$n$。 

一个常见的失败案例是将问题视为$n$很小并尝试高斯消除枚举。 例如，当$n=3, p=2$，排名分配已经很重要了，并且暴力破解$2^{9}$矩阵有效，但对于$n=100$，这变得不可能。 另一种失败模式是忽略排名计数取决于同时选择独立的行和列空间，而不仅仅是选择子空间维度。 

## 方法

 一个天真的方法是生成所有$n \times n$矩阵超过$\mathbb{F}_p$，通过高斯消除计算它们的排名，并增加计数器。 这是正确的，因为等级是明确定义的，并且高斯消除在字段上是精确的。 然而，矩阵的数量是$p^{n^2}$，甚至对于$n=10$这已经是天文数字了。 瓶颈在于枚举和排名计算，这使得这完全不可行。 

关键的结构观察是一个秩矩阵$r$可以分解如下：选择一个$r$维列空间，选择一个$r$维行空间，然后选择一个可逆$r \times r$他们之间的地图。 这是标准秩因式分解的观点。 

这建议将计数分为三个独立的部分：

 首先，选择一个$r$的维子空间$\mathbb{F}_p^n$为列空间。 这样的子空间的数量就是高斯二项式系数$\binom{n}{r}_p$。 

其次，选择一个$r$维行空间，独立，再次贡献$\binom{n}{r}_p$。 

第三，在这些空间之间选择可逆线性变换，这会贡献可逆的数量$r \times r$矩阵超过$\mathbb{F}_p$，表示为$|GL(r, p)|$。 

然而，这会导致计算过多，因为相同的矩阵可以通过所选子空间的不同基来表示。 正确的分解通过隐式固定高斯二项式结构内的基数来解决这个问题。 最终已知身份的数量$n \times n$秩矩阵$r$超过$\mathbb{F}_p$是：$$\frac{\prod_{i=0}^{r-1} (p^n - p^i)^2}{\prod_{i=0}^{r-1} (p^r - p^i)}$$这个公式来自于构建等级$r$逐行矩阵，同时确保线性独立性，然后通过除以选择行空间基数的方式数来纠正计数过多。 

现在我们利用约束$k \le 5000$。 我们只计算小值$r$，这样我们就可以增量地构建产品。 唯一的依赖$n$出现在$p^n$，这是恒定的$r$并且可以使用快速求幂来预先计算一次。 

强力失败的发生是因为它独立地处理每个矩阵，而最优解决方案则计算子空间和线性映射的结构化选择，将问题压缩为简单项的乘积。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(p^{n^2} \cdot n^3)$|$O(n^2)$| 太慢了 |
 | 最佳 |$O(k \log n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. Precompute$q = p^n \bmod M$using fast modular exponentiation. 该值表示每个维度可用的可能线性组合的数量，并将在每次排名计算中重复使用。 
2. 每个等级$r$,建立分子$\prod_{i=0}^{r-1} (q - p^i)^2$。 这对应于选择$r$顺序独立的列和行方向，其中每个步骤都会删除先前跨越的方向。 
3. 计算分母$\prod_{i=0}^{r-1} (p^r - p^i)$，它说明了在内部选择基础的方法数量$r$维空间。 这纠正了由同一子空间的不同基础表示引起的过度计数。 
4. 增量计算每个答案$r=0$到$k$，更新分子和分母乘积$O(1)$每一步使用连续排名之间的递归关系。 
5. 使用模逆除以模下的分母$998244353$，保证有限域算法的正确性。 

### 为什么它有效

 该算法是等级分解的直接枚举$A = UV$， 在哪里$U$和$V$对列和行空间进行编码。 每个等级$r$矩阵唯一对应于一个选择$r$维图像空间，$r$维核补，以及它们之间的可逆变换。 乘积项计数有序的独立向量选择，而分母消除了对基础选择的依赖。 由于每个矩阵在基本变化之前都具有精确的一个秩分解，因此计数是准确的，并且不会遗漏或重复计算任何配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n, p, k = map(int, input().split())

q = modpow(p, n)

# precompute powers of p up to k
pows = [1] * (k + 1)
for i in range(1, k + 1):
    pows[i] = pows[i - 1] * p % MOD

ans = [0] * (k + 1)

num = 1
den = 1

ans[0] = 1

for r in range(1, k + 1):
    # update numerator: multiply by (q - p^(r-1))^2
    x = (q - pows[r - 1]) % MOD
    num = num * x % MOD * x % MOD

    # update denominator: multiply by (p^r - p^(r-1))
    den = den * ((pows[r] - pows[r - 1]) % MOD) % MOD

    ans[r] = num * pow(den, MOD - 2, MOD) % MOD

print(*ans)
```代码首先计算$p^n$因为它在每个等级术语中重复出现。 然后它预先计算$p$因为形式的表达$p^i$出现在分子和分母更新中。 

该循环维护排名公式的运行乘积。 在每一步，分子都会获得添加一个独立维度的贡献，通过减去已占用的跨度来表示。 分母校正新形成的子空间的内部基础选择。 模求逆仅用于累加分母，这避免了循环内重复昂贵的求幂。 

一个微妙的实现细节是模数减法的处理。 两个都$q - p^i$和$p^r - p^{r-1}$必须标准化回$[0, MOD)$在乘法之前避免负残差传播。

 ## 边缘情况

 当$k = 0$，算法立即输出 1，因为只有一个 0 阶矩阵，即全零矩阵。 完全跳过循环，分子和分母从 1 开始的不变式确保了正确性。 

什么时候$n = 1$，只有等级 0 和 1 是可能的。 该公式简化为计算单个条目是零还是非零，并且表达式产生$1$和$p-1$分别匹配预期的结构$\mathbb{F}_p$。 

什么时候$p = 2$，减法大大简化，并且许多中间值以输出模数为模而崩溃为 0 或 1。 该实现仍然有效，因为所有操作都是模数进行的$998244353$, 不是模数$p$，即使在最小的字段中也能保持组合计数的正确性。
