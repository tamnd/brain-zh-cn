 ## 解决方案
 ## 问题理解

 我们从一个未知的数组开始`a`所有元素的乘积恰好是`2023`。 一些`k`元素被删除，留下数组`b`长度`n`。 

任务是确定这样的原始数组是否存在。 如果可以的话，我们必须输出任何有效的一组`k`删除了号码。 将所有数字相乘后`b`和我们输出的所有数字，结果必须完全相同`2023`。 

关键的观察结果是元素的顺序并不重要。 只有产品才重要。 如果剩余数字的乘积已经太大或者不是`2023`，没有办法完成数组。 否则，我们可以选择被移除的数字，其乘积可以填充缺失的因子。 

限制非常小。 两个都`n`和`k`至多是`5`，并且最多有`100`测试用例。 即使对多种可能性进行详尽的搜索，也能轻松满足限制。 尽管如此，这个问题仍然有一个简单的数学解决方案，每个测试用例都以恒定的时间运行。 

有几个容易被忽视的案例。 

假设剩余的产品不能划分`2023`。 

输入：```
1
2 1
5 2
```的产品`b`是`10`。 自从`2023`不能被整除`10`，任何额外整数的集合都不能精确地得到最终产品`2023`。 正确答案是：```
NO
```一个粗心的解决方案，只检查产品是否小于`2023`会错误地接受这个案例。 

当剩余的乘积已经等于时，会发生另一个重要的情况`2023`。 

输入：```
1
1 1
2023
```缺失的产品是`1`。 由于我们必须输出恰好一个被移除的数字，因此我们可以输出：```
YES
1
```价值`1`保留总产品。 坚持寻找一个大于的因数的解决方案`1`会失败的。 

第三种边缘情况是需要多个删除的数字时。 

输入：```
1
1 3
1
```剩下的产品是`1`，因此删除的数字必须乘以`2023`。 一个有效的答案是：```
YES
2023 1 1
```我们只需要任何有效的集合`k`数字。 忘记了准确输出的要求`k`值会产生无效的答案。 

## 方法

 一个蛮力的想法是尝试所有可能的集合`k`删除数字并检查它们的乘积是否乘以`b`, 等于`2023`。 

这是有效的，因为目标产品是固定的并且非常小。 然而，即使有很小的限制，如果我们允许任意候选值，搜索空间也会快速增长。 该方法依赖于猜测因素和探索组合，这是不必要的。 

问题的结构表明了一个更简单的方向。 预先知道原始产品：```
2023 = 7 × 17 × 17
```让```
P = product of all elements in b
```如果原数组存在，则```
P × (product of removed numbers) = 2023
```这立即意味着`P`必须划分`2023`。 

如果`2023 % P != 0`，不存在解。 

否则缺少的产品是```
M = 2023 / P
```现在我们正好需要`k`删除了乘积为的数字`M`。 

最简单的施工是放置`M`作为第一个删除的数字并填充剩余的`k - 1`职位与`1`。 他们的产品仍然`M`，所以条件满足。 

这将整个问题简化为一次可分性检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 候选因子数量呈指数增长 | O(k) | 不必要|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算乘积`P`给定数组中的所有元素`b`。 
2. 检查是否`2023`可以整除`P`。 

如果`2023 % P != 0`， 输出`"NO"`因为删除的数字的集合不能精确地得到总乘积`2023`。 
3. 否则计算缺失因子：```
M = 2023 / P
```4. 输出`"YES"`。 
5. 将删除的数字构造为：```
[M, 1, 1, ..., 1]
```恰好与`k`数字。 
6. 输出该列表。 

### 为什么它有效

 让`P`是剩余数组的乘积。 

如果`P`不分开`2023`，那么删除的数字的任何乘积都必须等于`2023 / P`，它不是整数。 由于所有数组元素都是整数，因此不能存在有效的原始数组。 

如果`P`划分`2023`， 定义`M = 2023 / P`。 构造的移除数有乘积```
M × 1 × 1 × ... × 1 = M
```因此，重建数组的所有元素的乘积为```
P × M = P × (2023 / P) = 2023.
```施工总是准确地生产`k`数字，因此每个接受的案例都会产生有效的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())
    b = list(map(int, input().split()))

    prod = 1
    for x in b:
        prod *= x

    if 2023 % prod != 0:
        print("NO")
    else:
        print("YES")
        missing = 2023 // prod
        ans = [missing] + [1] * (k - 1)
        print(*ans)
```The first part computes the product of the remaining elements. 自从`n ≤ 5`并且每个值最多是`2023`，该乘积很容易适合 Python 的整数算术。 

可分性测试是整个可行性检查。 如果余下的乘积不是`2023`，重建是不可能的。 

当可以重建时，代码会计算缺失的因子`2023 // prod`。 该值成为第一个被删除的元素。 其余位置均已填满`1`，这不会改变产品并保证准确`k`打印数字。 

乘法的顺序无关紧要，因为只有最终的乘积才重要。

# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    out = []
    t = int(input())

    for _ in range(t):
        n, k = map(int, input().split())
        b = list(map(int, input().split()))

        prod = 1
        for x in b:
            prod *= x

        if 2023 % prod != 0:
            out.append("NO")
        else:
            out.append("YES")
            missing = 2023 // prod
            ans = [missing] + [1] * (k - 1)
            out.append(" ".join(map(str, ans)))

    return "\n".join(out) + "\n"

# sample-style checks

1 289 1 1
"""

"""

 ## 边缘情况

 考虑：```
1
2 1
5 2
```的产品`b`是`10`。 该算法检查：```
2023 % 10 = 3
```由于余数不为零，因此输出：```
NO
```没有整数因子可以变换`10`进入`2023`。 

考虑：```
1
1 1
2023
```的产品`b`已经是`2023`。```
M = 2023 / 2023 = 1
```该算法输出：```
YES
1
```乘以`1`保持总产品不变。 

考虑：```
1
1 3
1
```的产品`b`是`1`， 所以```
M = 2023
```构造的移除数为：```
2023 1 1
```他们的产品依然是`2023`，并且根据需要恰好产生了三个数字。 

考虑：```
1
3 1
7 17 7
```的产品`b`是```
833
```自从```
2023 % 833 != 0
```算法输出：```
NO
```这表明即使每个元素单独划分`2023`，它们的组合乘积可能不会，并且可分性检查正确地捕获了故障。
