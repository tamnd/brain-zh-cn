 ## 解决方案
 ## 问题理解

 我们被要求数一下有多少个$n \times n$有限大小域上的矩阵$p$（整数以素数为模$p$）有一个确切的排名$r$，对于每一个$r$从 0 到$k$。 关键细节是$n$可以非常大，最多$10^{18}$， 但$k$相对较小，最多$5 \cdot 10^5$。 输出是模数$998244353$，所以我们不需要精确的大数，只需要它们的残数。 

输入数字代表矩阵维度$n$，字段大小$p$，以及最大排名$k$来计算。 输出包括$k+1$整数，每个都计算秩恰好为 0, 1, 2, ... 的矩阵的数量，$k$。 秩为零意味着零矩阵。 秩$n$意味着满级。 

这些约束意味着我们不能直接枚举矩阵。 暴力方法生成$p^{n^2}$矩阵是不可行的，因为$p^{n^2}$天文数字般增长。 我们唯一的希望是利用有限域上矩阵的代数结构。 小界限$k$暗示该解决方案可能涉及依赖于的公式$k$，而不是$n$，或使用快速求幂。 

边缘情况出现在非常小的情况下$n$或者$k$。 例如，如果$n = 1$和$p = 2$，正好有两个$1 \times 1$矩阵：0（等级 0）和 1（等级 1）。 当计算像这样的产品时，基于阶乘的简单方法可能会失败$\prod_{i=0}^{r-1} (p^n - p^i)$如果$r > n$或者模幂运算处理不正确。 另一个微妙之处是秩为零：它始终是一个矩阵，即零矩阵。 

## 方法

 蛮力方法是迭代所有$p^{n^2}$矩阵，计算每个等级并统计结果。 虽然在概念上是正确的，但它是完全不切实际的，因为即使对于$n = 5$和$p = 2$，矩阵的数量是$2^{25} = 33{,}554{,}432$。 这远远超出了可行的计算范围$n \sim 10^{18}$。 

更快的方法使用已知的数量公式$n \times n$秩矩阵$r$在有限大小的域上$p$。 计数是$$\#\text{rank-}r = \prod_{i=0}^{r-1} \frac{(p^n - p^i)^2}{p^r - p^i} \quad \text{for } r > 0,$$以及恰好一个矩阵$r = 0$。 这来自线性代数：分子计算选择的方式数量$r$线性独立的行和$r$线性独立的列，而分母则纠正由于可逆而导致的过度计数$r \times r$子矩阵。 每一项都可以计算模$998244353$使用模幂、逆和类似阶乘的乘积。 因为$k$很小，我们只计算项$r = 0, \dots, k$，不是全部$n$。 对于非常大的$n$，我们计算$p^n \mod 998244353$有效地使用快速求幂。 

关键的观察是，尽管$n$很大，我们从不迭代所有行或列； 我们只操纵权力$p$和长度的乘积$r \le k$。 这使我们能够将时间复杂度降低到大约$O(k^2)$模运算$998244353$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(p^{n^2} n^3)$|$O(n^2)$| 太慢了 |
 | 最佳 |$O(k^2)$|$O(k)$| 已接受 |

 ## 算法演练

 1. 预计算幂$p$模数$998244353$对于值高达$k$。 这是必要的，因为像这样的术语$p^n - p^i$反复出现。 使用快速求幂来计算$p^n \mod 998244353$。 
2. 初始化答案列表$ans[0] = 1$对于排名 0。 
3. 每个等级$r$从 1 到$k$，将分子计算为$\prod_{i=0}^{r-1} (p^n - p^i)^2 \mod 998244353$。 计算分母为$\prod_{i=0}^{r-1} (p^r - p^i) \mod 998244353$。 使用模逆来除以模数。 
4. 设置$ans[r] = numerator \times modular\_inverse(denominator) \mod 998244353$。 
5. 打印全部$ans[r]$为了$r = 0$到$k$。 

为什么有效：该公式计算秩矩阵的确切数量$r$对独立的行和列使用组合选择，并通过除以可逆的数量来纠正重复计算$r \times r$矩阵。 模运算确保即使非常大也不会溢出$n$，和计算能力模$998244353$允许有效处理巨大的指数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, b, mod):
    res = 1
    a %= mod
    while b > 0:
        if b & 1:
            res = res * a % mod
        a = a * a % mod
        b >>= 1
    return res

def modinv(x):
    return modpow(x, MOD-2, MOD)

def solve():
    n, p, k = map(int, input().split())
    ans = [0] * (k+1)
    ans[0] = 1

    p_pows = [1]*(k+1)
    p_n_mod = modpow(p, n, MOD)
    for i in range(1, k+1):
        p_pows[i] = p_pows[i-1] * p % MOD

    for r in range(1, k+1):
        numer = 1
        denom = 1
        for i in range(r):
            numer = numer * (p_n_mod - p_pows[i]) % MOD
            numer = numer * (p_n_mod - p_pows[i]) % MOD
            denom = denom * (p_pows[r] - p_pows[i]) % MOD
        ans[r] = numer * modinv(denom) % MOD

    print(" ".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```该代码首先定义模幂和模反函数。 我们预先计算$p^i \mod 998244353$为了$i \le k$以避免重复求幂。 分子对每一项进行平方以考虑独立的行和列选择。 分母除掉由于可逆子矩阵而导致的多算。 模逆处理模数下的除法。 最终答案收集在`ans`并打印出来。
