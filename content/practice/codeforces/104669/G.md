 ## 解决方案
 ## 问题理解

 我们正在处理无限二维网格上的两个代理。 一个名叫 Keys 的智能体每秒在四个基本方向之一上精确地移动一个网格步长。 搬家后，凯斯在他刚刚离开的牢房上留下了一张永久的“海报”。 

第二个特工 Tortles 每秒都会跟随 Keys 移动。 在一秒钟之内，乌龟要么留在原地，要么沿着总长度恰好为 2 的曼哈顿路径移动，这实际上意味着他每秒最多可以穿越两个网格边缘，但不能单步移动。 

乌龟有两个目标。 首先，他最终必须访问并清理凯斯曾经访问过并留下海报的每一个牢房。 只有当所有海报都消失之后，追求才有意义。 其次，在清理完成后的某个时刻，他必须与凯斯呆在同一个牢房里。 

输入给出两个代理的初始坐标。 我们被要求计算最小秒数，直到 Tortles 能够保证清理所有海报并最终捕获钥匙（假设两者都发挥最佳）。 

坐标范围达到 10^9，这立即排除了随时间移动或网格遍历的任何模拟。 任何有效的解决方案都必须将相互作用压缩为仅取决于初始几何形状的封闭形式表达式。 

一个常见的微妙问题是将 Tortles 的运动误解为曼哈顿距离 ≤ 2 或恰好为 2。正确的解释允许保持静止或沿着曼哈顿总长度恰好为 2 的任何路径移动，这实际上表现为“L1 每秒的速度 2”。 

另一个潜在的陷阱是对海报的过度思考。 Keys 会留下完整的路径痕迹，但 Tortles 不需要独立地最小化整个路径上的行程； 最佳游戏将一切都简化为两个移动点之间的单一追逐约束。 

## 方法

 暴力解释将逐秒模拟两个玩家。 Keys 选择一个方向，Tortles 通过探索哪条两步路径可以最大限度地减少未来成本，同时清理新生成的海报来做出最佳响应。 这变成了一个分支博弈树，其中每个状态都取决于访问单元的完整历史记录。 由于钥匙可以在 4 个方向上移动，而 Tortles 可以在许多两步路径中进行选择，因此状态数量随着时间呈指数增长。 即使对于很短的距离，超过几十步也是不可行的。 

关键的简化来自于将问题分解为两个相互作用的运动，而不是一组不断增长的访问约束。 对可行性而言唯一重要的是 Tortles 能够以多快的速度减少曼哈顿的分离，而 Keys 则积极尝试增加分离。 海报追踪不会引入额外的约束，因为每个海报都位于 Keys 的路径上，一旦 Tortles 能够随着时间的推移匹配 Keys 的位置，他必然会以不比最终追逐约束差的方式穿过所有中间访问的单元格。 

这将问题简化为曼哈顿度量标准中的追逐游戏，其中 Keys 以每秒 1 的速度移动，而 Tortles 实际上以每秒 2 的速度移动，但重要的顺序是 Keys 每轮首先移动。 这种排序稍微削弱了 Tortles 的优势，但并没有改变线性关系。 

整个问题归结为跟踪曼哈顿距离在最佳对抗性游戏下如何演变。

 ## 算法演练

 令 Tortles 和 Keys 之间的初始曼哈顿距离为$D = |X_1 - X_2| + |Y_1 - Y_2|$。 

1. 计算$D$从给定的坐标。 这表示在轴对齐移动的最佳对齐情况下网格上的初始分离。 
2. 观察一整秒的交互。 Keys 首先移动，因此他可以通过沿着网格轴直接远离 Tortles 来将曼哈顿距离增加至多 1。 
3. Keys移动后，Tortles以两步曼哈顿移动来响应，通过沿着最短路径移动到Keys的新位置，可以将距离最多减少2。 
4.在一秒钟内结合两种效果。 每轮的距离变化对于 Keys 最多为 +1，对于 Tortles 最多为 −2，在 Keys 的最佳情况下和 Tortles 的最佳响应中，净减少至少 1。 
5. 因此，之后$t$秒，乌龟最多可以将初始距离缩短$t$，而 Keys 可能最多增加了它$t$，而海龟最多可以减少$2t$。 捕获的约束变为$2t \ge D + t$，这简化为$t \ge D$。 
6. 输出$D$，因为它是满足捕获条件的最小整数时间。 

### 为什么它有效

 不变的是，两个智能体之间的曼哈顿距离在 Tortles 移动之前最多可以增加 1，而在 Tortles 移动之后最多可以减少 2。 这限制了每秒的净进度，仅取决于初始距离，而不取决于 Keys 所采用的特定路径。 由于 Keys 的最优策略始终是最大化分离，而 Tortles 的最优策略始终是最小化分离，因此系统的行为就像离散时间上的线性微分不等式，其紧解正是初始曼哈顿距离。 

发布者机制不会改变这个不变量，因为每个发布的单元格都位于 Keys 的轨迹上，一旦 Tortles 以最佳方式到达 Keys，他必然会在一条高效的追逐路径中穿过所有中间位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        x1, y1, x2, y2 = map(int, input().split())
        dist = abs(x1 - x2) + abs(y1 - y2)
        out.append(str(dist))
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案计算每个测试用例的曼哈顿距离。 这直接匹配导出的最佳捕获时间。 

实现很简单，但关键是不需要模拟或状态跟踪。 每个测试用例的一切都简化为一个算术表达式。

 ## 边缘情况

 当两个玩家从同一个单元格开始时，曼哈顿距离为零，答案也为零。 该算法直接处理这个问题，因为绝对差计算立即产生 0。 

当运动纯粹是水平或垂直时，距离减少到单个绝对差。 由于第二个坐标贡献为零，因此该公式仍然适用，无需修改。 

对于较大的坐标值，例如允许范围的对角，由于整数是无界的，减法和绝对值运算在 Python 中仍然是安全的，并且结果直接反映了完整的曼哈顿跨度，没有中间溢出风险。
