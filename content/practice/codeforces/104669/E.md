 ## 解决方案
 ## 问题理解

 我们得到一个非负整数，并要求通过对其二进制表示的转换来重新解释它。 该过程在描述上很简单，但在执行上稍显间接。 首先，我们以二进制形式写入数字，不带任何前导零，这意味着我们只保留从最高有效位 1 到最低有效位的有效位。 然后我们将这些位的顺序反转为字符串。 最后，我们将这个反转的位串解释为一个新的二进制数，并将其转换回以 10 为基数的整数。 

关键的微妙之处在于，转换纯粹是位上的位置转换。 除了二进制分解和重构之外，不会对值本身执行任何算术。 这意味着问题本质上是关于位操作而不是数论或组合学。 

对输入大小的限制（最多 10^18）意味着二进制表示最多有 60 位。 任何在 O(log N) 时间内处理该数字的解决方案就足够了。 这立即排除了任何试图在高达 N 的线性范围内模拟位操作或在超出数字位长度的大型结构上执行重复的重字符串操作的方法。 

当人们认为反转适用于固定宽度的二进制表示时，就会出现天真的误解。 例如，填充到 64 位并反转会产生不同的结果。 该问题明确禁止原始表示中出现前导零，因此不得引入填充。 

另一个常见的边缘情况是零本身。 如果输入为0，则其二进制表示为“0”。 反转仍会产生“0”，并且输出仍为 0。如果不明确处理此问题，任何假定至少有一个前导 1 位的实现都将在此失败。 

## 方法

 思考这个问题的强力方法是显式构造数字的二进制字符串，将其反转，然后再次将其解释为二进制数。 将数字转换为二进制需要 O(log N) 时间，因为每一步都除以 2。反转长度为 log N 的字符串也是 O(log N)，并且从反转的字符串重建数字也是 O(log N)。 这已经完全符合约束条件。 

然而，我们可以通过观察反转在结构上的作用来完全避免构建完整的字符串。 当我们从 N 的最低有效位提取位时，这些位将成为输出中的最高有效位。 这意味着我们可以通过按提取顺序移位和添加位来增量构建结果，而不是存储字符串并反转它。 

核心见解是，反转二进制表示相当于从最低有效位到最高有效位读取 N 的位，然后通过左移并插入每个提取的位来构造一个新数字。 这消除了对字符串操作的任何需要，并使整个过程保持纯粹的算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(log N) | O(log N) | 已接受 |
 | 最佳| O(log N) | O(1) | O(1) | 已接受 |

 ## 算法演练

1. 从给定数字开始，并将空结果初始化为零。 当我们处理位时，结果将累积相反的二进制解释。 
2. 当数字大于零时，使用模 2 或按位与 1 重复提取其最低有效位。该位正是反转二进制串中的下一个符号。 
3. 将结果左移一位，为新位腾出空间。 这确保了较早提取的位在最终数字中占据较高的有效位置。 
4. 将提取的位添加到结果中。 这会将反转的二进制数字附加到正确的位置。 
5. 将原数右移一位，丢弃处理后的位并移至下一位。 
6. 继续，直到所有位都被消耗。 构建的结果就是最终的答案。 

对于输入为零的特殊情况，循环不执行，正确的输出直接为零。 

### 为什么它有效

 在每次迭代中，我们都在有效地模拟反向位串的构造。 不变的是，处理 k 位后，结果恰好包含原始二进制表示的最后 k 位的反转前缀，且顺序正确。 由于原始数字中的每个新位在左移后都附加到结果的最低有效侧，因此在整个过程中保留了位置正确性。 没有位被覆盖或放错位置，并且当所有有效位都被消耗时，该过程准确地终止。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    res = 0

    while n > 0:
        res = (res << 1) | (n & 1)
        n >>= 1

    print(res)

if __name__ == "__main__":
    solve()
```该实现读取该数字，然后从最低有效位到最高有效位重复使用其二进制表示形式。 每一步将结果左移并插入提取的位。 这直接构建了反向二进制解释，而无需显式构建字符串。 

一个微妙的点是更新步骤中的操作顺序。 表达式`(res << 1) | (n & 1)`确保在插入新位之前移动当前结果，从而保留位置结构。 使用加法而不是按位 OR 在这里也可以工作，因为插入的位始终为 0 或 1，但 OR 的意图更明确。

 ## 边缘情况

 零输入是唯一结构退化的情况，因为它在主循环中不产生迭代。 用于输入`0`，二进制表示为`0`，算法立即输出`0`因为累加器从未被修改。 

用于输入`1`，二进制表示是单个位。 循环运行一次，提取`1`，并将其放入结果中，产生`1`。 这证实了该算法可以正确处理最小非零结构，而不需要特殊的外壳。 

对于 2 的幂的输入，例如`2`或者`8`，二进制表示有一个高位，后跟零。 反转将高位移动到最低有效位置。 循环自然地实现了这一点，因为零会在不设置位的情况下进行移位，并且最后的 1 位最终位于正确的反转位置。
