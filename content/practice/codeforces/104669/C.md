 ## 解决方案
 ## 问题理解

 我们得到一个数字$n$，我们必须输出整数的排列$1$到$n$。 对于每个位置$i$，我们计算一个由索引与放置在那里的值相乘形成的值，即$i \cdot p_i$。 目标是安排排列，以便尽可能多的这些产品是不同的。 

由于有$n$职位，我们永远不能拥有超过$n$独特的产品。 真正的问题是我们是否总能达到这个上限，或者碰撞是否不可避免。 

考虑失败案例的一个有用方法是两个职位生产相同的产品。 例如，如果$i \cdot p_i = j \cdot p_j$，那么该构造就“浪费”了一个可能的独特值。 幼稚的方法可能会尝试随机排列或贪婪交换，但这些可能会意外地创建没有明显模式的重复产品，特别是因为产品取决于索引和价值。 

约束条件$n \le 2 \cdot 10^5$表明我们无法模拟或搜索排列。 任何涉及检查许多候选人或回溯作业的方法都会太慢。 我们需要一个直接的构造来保证线性时间内不同产品的最大数量。 

值得注意的边缘情况是较小的值$n$， 尤其$n = 1$，答案很简单，而且非常大$n$，其中关于成对碰撞的任何二次推理都是不可能的。 一个微妙的陷阱是假设大多数排列自然地产生不同的产品，这是错误的，因为像这样的对称分配$p_i = n+1-i$经常创造重复的值。 

## 方法

 一个蛮力的想法是生成一个排列并计算数组中出现的不同值的数量$i \cdot p_i$，尝试通过在发现碰撞时交换元素来改进它。 这将需要反复重新计算产品并检查许多配置之间的冲突。 在最坏的情况下，每次调整都需要扫描$O(n)$值，并且重复这样做至少会导致$O(n^2)$行为，这对于$n = 2 \cdot 10^5$。 

关键的观察是，我们实际上并不需要通过位置之间的相互作用来最大化任何东西。 我们只需要确保所有$n$产品是不同的，这是理论上的最大值。 因此，问题简化为构造一个排列，使得映射$i \mapsto i \cdot p_i$是单射的。 

保证单射性的一个简单方法是消除乘积序列中的所有结构对称性。 最直接的构造是保持排列不变，设置$p_i = i$。 在这种情况下，每个产品都变得$i^2$，并且由于函数$i^2$在正整数上严格递增，所有值自动不同。 

这消除了对参数配对、贪婪匹配或冲突处理的任何需要。 暴力斗争来自于试图管理不同指数之间的交互，但身份排列完全解耦了这些交互。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力交换来修复碰撞 |$O(n^2)$|$O(n)$| 太慢了 |
 | 身份排列$p_i = i$|$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 构造长度排列$n$其中位置的值$i$是$i$。 这意味着我们只需输出数字$1$到$n$为了。 其动机是使每个产品依赖于单个变量而不是相互作用的变量对。 
2. 从概念上计算乘积为$i \cdot p_i = i \cdot i$。 我们实际上不需要存储它们，但是这一步澄清了每个位置都映射到一个完美的正方形。 
3. 直接输出构造好的排列。 

### 为什么它有效

 构建的序列产生产品$1^2, 2^2, 3^2, \dots, n^2$。 由于函数$i^2$对于整数严格递增$i \ge 1$，没有两个指数可以产生相同的产品。 这保证了所有$n$产品独特，实现最大可能的价值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    print(*range(1, n + 1))

if __name__ == "__main__":
    solve()
```该解决方案依赖于打印身份排列。 关键的实现细节是不需要额外的数组或计算。 输出格式直接满足排列要求。 

不存在相差一的问题，因为 Python 的`range(1, n+1)`自然地生成准确所需的索引。

 ## 边缘情况

 对于$n = 1$，该构造输出单元素排列$[1]$，并且产品集仅包含$1$，这是非常不同的。 

为了$n = 2$，输出$[1, 2]$生产产品$1$和$4$，它们是不同的，证实即使是最小的重要情况也无需调整即可工作。 

对于大型$n$，结构保持稳定，因为每个产品仅取决于其指数，因此位置之间的相互作用不存在隐藏冲突的可能性。
