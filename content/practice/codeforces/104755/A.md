 ## 解决方案
 ## 问题理解

 我们得到了一个简短的海报文字和一支可以使用三种固定颜色书写的笔。 每种颜色的容量都是有限的，即可以使用的字符数量。 关键约束不是单个字符的自由着色，而是将字符类型划分为三种颜色。 

文本中的每个字符都属于以下三个类别之一：字母、数字或标点符号。 文本中存在空格，但不属于这些类别，因此不会消耗任何颜色的墨水。 任务是决定我们是否可以为每个类别分配不同的颜色，以便该类别中的字符总数不超过该颜色的可用墨水。 

换句话说，我们必须将字母、数字和标点符号单射到蓝色、黄色和红色的颜色集上，并且在选择此映射后，每个类别的计数必须符合其分配的容量。 

输入限制很小，文本长度最多为 1000。这立即表明计算和检查恒定数量的配置就足够了，因为只有 3 个类别，因此只有 6 种可能的分配。 

一个天真的但重要的陷阱是假设颜色可以在一个类别内混合。 例如，尝试将字母拆分为多种颜色将违反每个类别必须指定一种颜色的规则。 另一个微妙的问题是忘记忽略不属于任何类别的空格。 

一个可能发生错误的小例子是：

 输入：

 ICPC

 1 1 10

 字母 = 4，标点符号 = 0，数字 = 0。如果我们错误地允许将字母拆分为不同颜色，我们可能会错误地得出可行性结论，但问题不允许这样做。 

正确的输出是：

 否

 因为根据赋值约束，在某些映射中 4 会超过 1 和 10。 

## 方法

 蛮力的想法是尝试将三个类别分配给三种颜色的所有可能的分配。 对于每个作业，我们计算文本中字母、数字和标点符号的总数，然后检查每个类别是否适合其分配的容量。 

由于正好有 3 个类别和 3 种颜色，因此映射数量为 3 阶乘，即 6。对于每个映射，我们扫描整个文本一次以计算类别频率。 如果最大长度为 1000，则最多会产生约 6000 个字符检查，即使在严格的限制下，这也是微不足道的。 

关键的见解是，该结构不是动态的，也不是排列之外的组合。 类别内的字符之间不存在依赖关系，仅在聚合计数和固定容量之间存在依赖关系。 这将问题从看似赋值或 DP 的问题简化为常数因子排列检查问题。 

蛮力已经运行得足够快，但概念上的简化是认识到唯一的自由度是类别到颜色映射的 6 种排列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力排列 | O(6·n) | O(6·n) | O(1) | O(1) | 已接受 |
 | 最优（同样的想法，优化） | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们首先计算三个值：文本中字母的数量、数字的数量和标点符号的数量。 空格被完全忽略。 

之后，我们尝试将三个类别分配给三种可用颜色的所有可能的分配。 每个分配将一个类别计数与一个容量限制配对。 

对于每个分配，我们检查所有三个类别计数是否小于或等于其分配的容量。 如果我们找到至少一项有效的作业，我们可以立即得出结论，该海报是可能的。 

如果六个作业都不满足约束条件，则答案是不可能的。

### 为什么它有效

 每个有效的解决方案完全对应于在三个类别和三种颜色之间选择双射。 由于每种颜色的容量是固定的，因此可行性仅取决于所选配对是否同时尊重所有三个不等式。 枚举所有双射可以保证不会遗漏任何有效的映射，并且独立检查它们可以确保正确性，因为类别一旦分配就不会相互作用。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    b, y, r = map(int, input().split())
    s = input().rstrip('\n')

    letters = digits = punct = 0

    punct_set = set([',', '-', ';', ':', '.', '!', '?'])

    for ch in s:
        if ch == ' ':
            continue
        if ch.isalpha():
            letters += 1
        elif ch.isdigit():
            digits += 1
        else:
            punct += 1

    counts = [letters, digits, punct]
    caps = [b, y, r]

    import itertools

    for perm in itertools.permutations(caps):
        ok = True
        for i in range(3):
            if counts[i] > perm[i]:
                ok = False
                break
        if ok:
            print("Yes")
            return

    print("No")

if __name__ == "__main__":
    solve()
```该代码首先使用简单的字符分类将文本分为三个所需的类别。 使用检测字母`isalpha`, 数字使用`isdigit`，除空格之外的所有其他内容都被视为标点符号。 这与问题定义相匹配，因为标点符号被明确限制为一个小的已知集合，但分类规则由后备分支安全地捕获。 

然后，我们将三个计数和三个容量视为多重集。 通过排列容量，我们模拟了所有可能的颜色分配给类别。 每个排列都会在恒定时间内独立检查。 

一个微妙的点是确保排除空格，因为它们出现在文本中但不属于任何类别。 明确的`continue`干净地处理这个问题。

 ## 边缘情况

 当一个类别为空时，就会出现一种微妙的边缘情况。 例如：

 输入：```
1 1 1
abc123
```这里标点符号为零。 该算法仍然将标点符号视为计数为 0 的类别，并且它映射到任何颜色的任何分配仍然有效，因为 0 ≤ 容量始终成立。 排列检查自然可以适应这一点，无需特殊处理。 

另一个边缘情况是所有字符都属于一个类别：

 输入：```
10 10 10
abcdef
```计数为字母 = 6、数字 = 0、标点符号 = 0。该算法会检查所有排列，以及将字母分配给容量 ≥ 6 的任何映射都会成功。 由于至少存在一个这样的映射，因此输出是正确的`Yes`。 

最后一种边缘情况涉及紧密耦合，其中只有一种特定的排列起作用。 暴力排列循环确保仍然可以找到这一点，因为每个双射都是独立测试的并且不应用启发式修剪。
