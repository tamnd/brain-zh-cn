 ## 解决方案
 ## 问题理解

 我们正在研究一维几何设置，其中垂直结构是固定的，但水平放置很重要。 在高度 2 处有一条天花板线，在高度 0 处有一个地板，在高度 1 处有一个中间“屏幕”，其中包含给定 x 坐标的固定孔。 灯只能安装在天花板线上，每盏灯发出的光线都是直射，穿过这些孔并继续向下到达地板。 

位置单灯$c$不直接选择楼层点。 相反，它的光必须穿过位置处的孔$a_i$，并且该光线继续呈直线，直到击中地板。 每对这样的$(c, a_i)$准确确定地板上的一个照明点。 关键的限制是我们只能照亮一组规定的楼层坐标，并且每个被照亮的点都必须属于该组，并且其他楼层位置都不能接收到光。 

输入给出两组 x 坐标：中线上的孔位置以及地板上所需的照明位置。 任务是决定我们是否可以在天花板上放置一些灯，以便所有穿过孔的光线的联合准确地照射到所需的地板上，而外面没有任何东西。 如果可能的话，我们还必须构建一种有效的灯配置。 

限制条件$n, m \le 2000$暗示二次或稍微超二次推理是可以接受的，但任何隐式探索所有$O(nm)$以非结构化方式配对可能会影响数以千万计的衍生国家。 这意味着我们需要一个可以快速验证每个候选配置的公式，或者有效配置的结构受到严格限制的公式。 

过度照明会产生微妙的边缘情况。 配置可能会正确击中所有必需的地板点，但也会意外地通过其他孔生成额外的点。 例如，如果一盏灯通过一个孔产生一个正确的地板点，它仍然会通过每隔一个孔产生额外的点，并且这些点也必须属于目标集。 仅将某些孔与某些楼层点匹配而不检查全局一致性的简单方法将接受无效的构造。 

另一个问题是重复生成。 单个灯可以生成多个楼层点，因此将其视为灯和目标点之间的一对一映射是不正确的，除非我们证明这种减少总是可能的。 

## 方法

 第一个自然的尝试是直接从几何角度思考。 固定灯位置$c$和一个洞$a$。 线路经过$(c,2)$和$(a,1)$以可预测的 x 坐标延伸到地板。 求解直线方程给出直接代数映射：$$b = 2a - c$$因此，每个灯都会通过灯位置周围的反射式对称性将所有孔位置转换为地板点。 

这立即表明了一种强力策略：尝试通过将孔与所需的地板点配对而得出的所有可能的灯位置。 如果有一个洞$a_i$旨在为最低点做出贡献$b_j$，那么灯的位置被迫为$c = 2a_i - b_j$。 一旦我们假设这样一盏灯，我们就可以模拟它的所有输出并验​​证它们是否保持在允许的楼层设置内。 

这是正确的，但价格昂贵。 有$O(nm)$候选灯，每次验证都需要检查所有$n$洞，导致$O(n^2 m)$操作，在最坏的情况下太大了。 

关键的观察结果是有效的灯受到极大的限制。 一旦灯位$c$是固定的，每个孔独立产生一个地板点$2a_i - c$，并且所有这些都必须位于目标集中。 这意味着每个候选灯完全由所有孔的全局一致性条件决定，而不仅仅是一对匹配的灯。 问题简化为寻找任何价值$c$使得所有孔的变换后的集合包含在给定的楼层集合中，然后选择足够的此类灯来准确地覆盖所有需要的点。 

这使我们能够将视角从构建映射转移到使用目标楼层位置上的哈希集有效地验证候选转换。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解孔底对 |$O(n^2 m)$|$O(m)$| 太慢了|
 | 候选生成+全局验证|$O(nm)$平均 |$O(m)$| 已接受 |

 ## 算法演练

 1. 将所有必需的楼层点存储在哈希集中，以进行恒定时间的成员资格检查。 这是必要的，因为每个有效性测试都会重复查询生成的点是否被允许。 
2. 枚举所有对$(a_i, b_j)$并计算候选灯位置$c = 2a_i - b_j$。 这是一盏灯能够与至少一个产生至少一个所需地板点的孔相一致的唯一方法。 
3. 对于每位候选人$c$，通过迭代所有孔来验证它。 对于每个孔位置$a_k$，计算诱导地板点$2a_k - c$。 如果任何这样的点不在所需的楼层集中，则丢弃该候选点。 
4. 如果候选通过验证，则将其存储为有效的灯位置。 由于多对可能会生成相同的$c$，使用集合对结果进行重复数据删除。 
5. 输出所有有效的灯位置。 每个有效灯独立地仅产生允许的楼层点，因此所有此类灯的联合不能引入禁止点。 

正确性取决于这样一个事实：每个有效的解决方案都必须包含其位置显示为来自至少一对孔-地板的反射的灯。 任何有效的灯必须满足$c = 2a_i - b_j$对于某些对，因此我们不会通过这种方式限制候选者而错过任何可行的配置。 

### 为什么它有效

 当且仅当每个孔都将其映射到允许的楼层集时，灯才有效。 这是对单个值的全局约束$c$，与它是如何被发现的无关。 枚举从一对支撑导出的所有值可保证完整性，因为任何有效的灯都必须通过至少一个孔来解释至少一个观察到的地板点。 一旦找到这样的候选者，全面验证将强制没有孔产生无效的楼层位置，这正是问题的要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    B = set(b)
    candidates = set()

    # generate all possible lamp positions from one supporting pair
    for ai in a:
        for bj in b:
            c = 2 * ai - bj
            candidates.add(c)

    good = []

    for c in candidates:
        ok = True
        for ai in a:
            if (2 * ai - c) not in B:
                ok = False
                break
        if ok:
            good.append(c)

    if not good:
        print("No")
        return

    print("Yes")
    print(len(good))
    print(*good)

if __name__ == "__main__":
    solve()
```实现首先将目标楼层点编码在哈希集中，这对于验证期间的恒定时间成员资格检查至关重要。 嵌套循环使用导出公式构造所有候选灯位置$c = 2a_i - b_j$。 虽然这会产生$O(nm)$对于候选者，使用一组来删除重复项，这很重要，因为多个支持对可以导致相同的灯位置。 

然后通过重建所有孔的所有楼层输出来验证每个候选者。 内循环是关键的正确性步骤：它确保没有孔产生无效的地板点。 在大多数无效情况下，尽早中断故障可以防止不必要的工作。 

最终输出简单地列出了所有有效的灯，这对应于选择在候选空间中找到的所有一致的变换。 

## 工作示例

 考虑孔所在的样本$[0, -1, 1]$所需楼层点数为$[4, 0, -2, 2]$。 

对于每一对，我们生成候选灯，例如$c = 2 \cdot 0 - 4 = -4$,$c = 2 \cdot 1 - 2 = 0$， 等等。 过滤后，仅$c = 0$仍然有效，因为它会产生底点$\{0, 2, -2, 2\}$，所有这些都包含在目标集中。 

| 候选人$c$| 孔检查结果 | 有效 |
 | --- | --- | --- |
 | -4 | 产生超出设定的值 | 没有 |
 | 0 | set | 中的所有映射值 是的 |
 | 2 | 产生超出设定的值 | 没有 |

 这证实了该算法仅隔离全局一致的灯，而不仅仅是局部合理的灯。 

现在考虑一个较小的情况$n=2, m=2$，孔位于$[3,4]$，以及所需楼层点数$[2,6]$。 从配对中派生的每个候选灯都无法验证，因为一个孔总是产生不在集合中的底点。 这演示了全局检查如何消除部分一致的配置。

 ## 边缘情况

 一个关键的边缘情况是多个候选者倒塌到同一灯位置时。 例如，不同的孔底对可以生成相同的值$c$，并且未能进行重复数据删除将会对灯进行过多计数，并可能会误导下游推理。 该算法通过在验证之前将候选者存储在集合中来处理此问题。 

当候选人通过除了一个洞之外的所有洞时，就会出现另一种边缘情况，从而产生一个无效的底线点。 即使该无效点在数值上“接近”有效点，也必须完全拒绝它。 对所有漏洞的全面扫描可确保不接受部分有效性。 

最后一种边缘情况是根本不存在候选者。 当孔-地板关系的结构不一致并且候选集变空时，就会发生这种情况。 该算法立即正确地输出“否”，因为甚至没有可行的灯位置可以局部解释通过孔的单个楼层点。
