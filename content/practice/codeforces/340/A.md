 ## 解决方案
 ## 问题理解

 我们被要求计算 Iahub 和 Floyd 在特定范围内绘制的砖块数量。 这些砖块用从 1 开始的连续整数进行编号。Iahub 从砖块 _x_ 开始绘制每第 _x_ 个砖块，而 Floyd 从砖块 _y_ 开始绘制每个第 _y_ 个砖块。 我们只对编号在 _a_ 和 _b_ 之间（含）且由两者绘制的砖块感兴趣。 

输入由四个整数组成：_x_、_y_、_a_ 和 _b_。 输出是一个整数，表示两者绘制的砖块数量。 

约束告诉我们 _x_ 和 _y_ 最多为 1000，因此任何使用这些作为直接步长的算法都是可行的。 范围 [_a_, _b_] 可以达到 2·10⁹，这使得在整个区间上进行强力模拟变得不切实际。 对 [_a_, _b_] 中的每个块进行简单循环可能需要 2·10⁹ 迭代，这远远超出了 1 秒的执行时间。 

当 _a_ 小于 _x_ 和 _y_ 时，就会出现边缘情况。 例如，如果 _x_ = 5、_y_ = 7、_a_ = 1、_b_ = 10，我们必须正确包含落在 [1, 10] 中的 5 和 7 的第一个倍数。 粗心的楼层划分或四舍五入可能会排除它。 另一种边缘情况是当 _a_ 等于 _b_ 时，例如 _x_ = 3、_y_ = 3、_a_ = 6、_b_ = 6。如果一块砖块是由两者都绘制的，则算法必须正确计算一块砖块的数量。 

## 方法

 暴力方法很容易描述。 我们迭代从 _a_ 到 _b_ 编号的每个砖块。 对于每个砖块，我们检查它是否可以被 _x_ 和 _y_ 整除。 如果是，我们就增加一个计数器。 这是正确的，因为当且仅当砖块的数量可以被两个步长整除时，砖块才会被两者绘制。 这种方法的问题是最坏的情况：如果 _b - a_ 的数量级为 2·10⁹，则循环将执行数十亿次迭代，这太慢了。 

最佳解决方案的关键见解是，当且仅当它是 _x_ 和 _y_ 的最小公倍数 (LCM) 的倍数时，才可以对砖块进行绘制。 一旦我们知道了 LCM，比如 _z_，问题就简化为计算区间 [_a_, _b_] 中 _z_ 的倍数。 这可以通过数学方式完成，而无需迭代每个砖块。 为了计算某个范围内 _z_ 的倍数，我们计算直到 _b_ 的倍数，减去严格小于 _a_ 的倍数，差值给出 [_a_, _b_] 中的计数。 这种方法避免了任何每块模拟并以恒定的时间运行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(b - a + 1) | O(1) | O(1) | 对于大 b-a 来说太慢 |
 | 最佳 | O(log(最大(x, y))) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算 _x_ 和 _y_ 的最大公约数 (GCD)。 这是有效计算 LCM 所必需的。 使用公式`LCM(x, y) = x * y // GCD(x, y)`确保我们通过在乘法之前除法来避免整数溢出。 
2. 计算 _x_ 和 _y_ 的 LCM，我们称之为 _z_。 当且仅当一块砖的数量是 _z_ 的倍数时，两个画家都会绘制一块砖。 
3. 计算_z_ 有多少个倍数小于或等于_b_。 这是由`b // z`。 
4. 计算_z_ 严格小于_a_ 的倍数。 这是由`(a - 1) // z`。 将这两个计数相减得出 [_a_, _b_] 内 _z_ 的倍数。 
5. 打印结果。 

不变的是，区间 [_a_, _b_] 中 _z_ 的每个倍数都只计算一次。 该区间内没有其他数字是 _x_ 和 _y_ 的倍数，因此计数是准确的。 该算法永远不需要检查单个砖块，即使对于非常大的范围也非常有效。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from math import gcd

x, y, a, b = map(int, input().split())

def lcm(u, v):
    return u * v // gcd(u, v)

z = lcm(x, y)
count = b // z - (a - 1) // z
print(count)
```第一部分读取输入并导入`gcd`Python 数学库中的函数。 这`lcm`函数有效地计算最小公倍数。 计算`b // z - (a - 1) // z`计算的倍数`z`在所需的范围内，如果 _a_ 本身是倍数，请注意将其包括在内。 减法`(a - 1) // z`确保当 _a_ 本身是倍数时我们不会少算。

## 测试用例```python
import sys, io
from math import gcd

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    x, y, a, b = map(int, input().split())
    z = x * y // gcd(x, y)
    return str(b // z - (a - 1) // z)

# Provided sample
assert run("2 3 6 18\n") == "3", "sample 1"

 ## 边缘情况

 当范围开始低于第一个倍数时，减法`(a - 1) // z`确保不会少算。 例如，x = 2，y = 3，a = 1，b = 5，z = 6。倍数 ≤ b = 0，倍数 < a = 0，计数 = 0。如果 _a_ 本身是倍数，如 a = 6，b = 6，则倍数 ≤ b = 1，倍数 < a = 0，计数 = 1，正确包括砖块。 由于算术计数方法，该算法自然可以处理长度为 1 的范围、从倍数开始的范围以及大范围。
