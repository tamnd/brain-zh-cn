 ## 解决方案
 ## 问题理解

 我们得到一个数组`p`长度`n`其中某些位置包含从 1 到`n`其他都是零。 正整数不会出现多次。 零是占位符，我们可以将其替换为缺失的数字，以便数组成为 1 到 1 的正确排列`n`。 一旦我们有了有效的排列，我们就将排列的成本定义为需要对整个排列进行排序的最小连续子段的长度。 

任务是最大化这个成本。 也就是说，我们希望将缺失的数字放入零，以便我们必须排序以修复排列的子段尽可能长。 每个测试用例的输出是一个整数，即可实现的最大成本。 

约束条件告诉我们`n`可以大到 2 * 10^5，并且总和`n`所有测试用例最多为 2 * 10^5。 这排除了尝试所有方法来填充零的任何强力解决方案，因为缺失数字的排列数量呈阶乘增长。 相反，我们需要一种在线性时间内工作的方法`n`。 

非明显的边缘情况包括所有元素均为零的数组、已排序的数组或所有缺失数字都聚集在一端的数组。 例如，一个数组`[0, 0, 0]`最大成本为 3，因为我们可以放置数字，使数组变成`[3, 1, 2]`我们需要对整个数组进行排序。 另一方面，`[1, 2, 3, 0]`成本为 0，因为唯一缺少的数字是 4，它位于末尾，并且数组已排序。 粗心的方法可能只是简单地计算零或忽略现有数字的位置，从而在这些边缘情况下产生错误的答案。 

## 方法

 一种简单的方法会尝试各种方法用缺失的数字填充零，构建排列，并通过扫描要排序的最小段来计算成本。 计算给定排列的段成本可以通过查找数组从左侧开始乱序的第一个位置和从右侧开始乱序的最后一个位置来完成。 然而，这需要生成零的阶乘组合，这对于`n`最多 2 * 10^5。 

关键的观察结果是，最大成本对应于从第一个零开始并以最后一个零结束的子数组。 放置在零段之外的任何数字要么不会增加排序成本，要么会降低排序成本。 因此，我们可以识别数组中零的第一个和最后一个位置。 然后，最大可能的成本是这些位置之间的距离，通过考虑末端已经正确放置的数字来调整。 具体来说，该零段之外的数字已经是有序的并且不会增加成本。 

这将问题简化为查找数组中的第一个和最后一个零位置，并将差值加一作为最大可能成本。 我们不需要显式地构造排列； 零的位置单独决定了我们可以强制不排序的最大段长度。

 | --- | --- | --- | --- |
 | 蛮力 | O(n! * n) | O(n! * n) | O(n) | 太慢了|
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和数组`p`。 
2. 初始化`first_zero`和`last_zero`至-1。 
3. 从左到右迭代数组。 当我们遇到第一个零时，将其索引存储在`first_zero`。 
4.继续迭代更新`last_zero`每当遇到零时。 到数组末尾时，`last_zero`将包含最后一个零的索引。 
5. 如果没有零（`first_zero`仍为-1)，该数组已经是一个完整的排列，因此最大成本为0。 
6. 否则，最大成本为`last_zero - first_zero + 1`。 这对应于覆盖所有零的连续段的长度，这是我们可以通过巧妙地放置缺失的数字来强制排序的最大子段。 
7. 打印测试用例的最大成本。 

为什么它有效：零的位置定义了一个连续的数字缺失的段。 通过放置缺失的数字以创建最大的无序，我们可以确保第一个零和最后一个零之间的整个段都需要排序。 该段之外的数字是固定的，不会增加分类成本。 因此，段长度是可实现的最大成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    
    first_zero = -1
    last_zero = -1
    
    for i in range(n):
        if p[i] == 0:
            if first_zero == -1:
                first_zero = i
            last_zero = i
    
    if first_zero == -1:
        print(0)
    else:
        print(last_zero - first_zero + 1)
```该代码首先读取测试用例的数量。 对于每个测试用例，它读取数组大小和数组本身。 然后它扫描数组以找到第一个和最后一个零。 如果没有找到零，则数组已完成并已排序，因此它会打印 0。否则，它会计算覆盖所有零的段的长度。 使用单次遍历数组可确保 O(n) 复杂度，并且只需要几个变量，因此空间使用量为 O(1)。 

## 工作示例

 **示例1：**`p = [1, 0, 4, 0, 5]`| 我| p[i] | p[i] 第一个零 | 最后零 |
 | --- | --- | --- | --- |
 | 0 | 1 | -1 | -1 |
 | 1 | 0 | 1 | 1 |
 | 2 | 4 | 1 | 1 |
 | 3 | 0 | 1 | 3 |
 | 4 | 5 | 1 | 3 |

 段长度：3 - 1 + 1 = 3。 

这表明算法正确识别了该段`[0, 4, 0]`作为可能未排序的最大的一个。 

**示例2：**`p = [0, 0, 0]`| 我| p[i] | p[i] 第一个零 | 最后零 |
 | --- | --- | --- | --- |
 | 0 | 0 | 0 | 0 |
 | 1 | 0 | 0 | 1 |
 | 2 | 0 | 0 | 2 |

 段长度：2 - 0 + 1 = 3。 

所有零构成完整数组，提供最大的无序性。
