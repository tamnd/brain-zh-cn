 ## 解决方案
 ## 问题理解

 我们给出了塔高度的序列，并且需要计算保留“左侧可见性”和“右侧可见性”集的子序列。 更具体地说，当你从左边看时，你只能看到比之前所有塔都高的塔，而从右边看，你看到的塔比右边所有塔都高。 我们的任务是计算原始序列的所有子序列，这些子序列从两端给出相同的可见高度集。 

对于输入，每个测试用例给出塔的数量`n`和高度数组`a`。 输出是有效子序列的模数`998244353`。 

约束很严格：`n`可以达到`3·10^5`在单个测试用例中，最多有`10^4`测试用例，但所有的总和`n`跨测试用例不超过`3·10^5`。 这排除了每个测试用例复杂性低于 O(n log n) 的解决方案，因为 O(n^2) 解决方案在最坏的情况下需要 ~10^10 次操作，这显然太慢了。 内存使用也必须是线性的`n`。 

非明显的边缘情况包括严格增加或减少的序列，或包含重复的最大高度。 例如，在`[3, 3, 3]`，左能见度为`{3}`正确的可见度是`{3}`。 假设严格递增序列或未能考虑重复元素的简单算法可能会低估子序列。 

## 方法

 暴力方法很简单：生成所有 2^n 子序列，计算它们的左右可见集，并检查与原始序列的相等性。 出于正确性目的，这可以正确工作，但不可行。 对于 n=20，有超过一百万个子序列； 对于 n=3·10^5，这是一个天文数字。 

关键的见解来自可见性定义中固有的单调性。 左可见性仅取决于前缀最大值。 如果我们考虑每个值对 L(a) 和 R(a) 的贡献位置，我们就会意识到：

 1. 每个对 L(a) 有贡献的最大值必须按照其第一次出现时从左到右的顺序在子序列中至少出现一次。 
2. 同样，R(a) 的每个最大值必须按照其最后一次出现的从右到左的顺序出现。 
3. 对 L(a) 或 R(a) 没有贡献的值可以在任何地方出现任意多次，因为它们不影响可见性。 

这将问题转化为组合计数问题，并限制第一次和最后一次出现。 具体来说，我们可以从左到右处理序列以识别左侧最大值，并从右到左处理序列以识别右侧最大值。 然后，解决方案减少为乘以在固定位置之间包含或排除非最大元素的方法数量，这可以通过前缀乘积或 DP 方法来完成。 

这种观察允许采用线性扫描方法，仔细记录哪些元素是必需的以及哪些元素可以自由变化。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.从左到右扫描序列并构建`L(a)`，左侧可见高度的集合，以及 L(a) 中每个元素的第一次出现索引。 这捕获了必须出现在子序列中以保持左侧可见性的位置。 
2.从右向左扫描构建`R(a)`，右可见高度的集合，以及 R(a) 中每个元素最后出现的索引。 这些职位也是强制性的。 
3. 组合约束：对于 L(a) 和 R(a) 中的每个元素，其在子序列中的索引必须位于左可见性的第一次出现和右可见性的最后一次出现之间。 如果这些约束不兼容（第一个 > 最后一个），则答案为零。 
4. 一旦固定了强制位置，就确定强制位置之间要素的“差距”。 不在 L(a) 或 R(a) 中的元素可以自由包含或排除，从而给出`2^k`每个间隙的选项，其中 k 是该段中空闲元素的数量。 将这些贡献乘以模`998244353`。 
5. 返回所有段的乘积作为有效子序列的总数。 

保证正确性的不变量是我们计算的每个子序列都以正确的顺序包含左右可见性所需的所有元素，并且所有剩余元素都可以独立选择而不影响可见性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def count_valid_subsequences(a):
    n = len(a)
    left_max = []
    current_max = -1
    first_pos = {}
    for i, val in enumerate(a):
        if val > current_max:
            current_max = val
            left_max.append(val)
            first_pos[val] = i

    right_max = []
    current_max = -1
    last_pos = {}
    for i in reversed(range(n)):
        val = a[i]
        if val > current_max:
            current_max = val
            right_max.append(val)
            last_pos[val] = i
    right_max.reverse()

    mandatory = sorted(set(left_max) | set(right_max), key=lambda x: first_pos.get(x, last_pos[x]))

    prev_index = -1
    result = 1
    for val in mandatory:
        start = first_pos.get(val, last_pos[val])
        end = last_pos.get(val, first_pos[val])
        if start > end:
            return 0
        free_elements = end - start - 1
        result = result * pow(2, free_elements, MOD) % MOD
        prev_index = end
    return result

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(count_valid_subsequences(a))

if __name__ == "__main__":
    main()
```该实现直接遵循算法步骤。`first_pos`和`last_pos`捕获所需的边界，以及的乘积`2^k`对于自由元素计算组合选择。 这`pow`具有模数的函数可以有效地处理大幂。 对强制元素进行排序可确保遵守顺序约束。 

## 工作示例

 取序列`[4, 2, 4, 8, 3]`。 

| 步骤| 左最大 | 右最大 | 第一个位置 | 最后位置 |
 | ---| ---| ---| ---| ---|
 | 左扫描 | [4, 8] | | {4:0, 8:3} | |
 | 右扫描 | | [3,8]| | {3:4,8:3} |
 | 强制| [4,8,3]| | | |
 | 差距| 4 到 8 之间：1 个元素 (2) -> 2^1=2 | 8 和 3 之间：1 个元素 (4) -> 2^1=2 | 产品 = 4 | 乘以强制单例的选择 = 1 |

 这再现了 5 的示例输出。 

另一个序列`[1,2,3,2,1]`: 左最大值`[1,2,3]`, 右极大值`[1,2,3]`。 强制位置与序列索引完全对齐，不留下任何空闲元素。 只有序列本身起作用。 输出为1。

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
