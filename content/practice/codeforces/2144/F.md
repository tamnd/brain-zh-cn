 ## 解决方案
 ## 问题理解

 我们给定几个括号字符串，每个括号字符串的长度最多$k$，并且我们必须将每个字符串恰好分配给一组。 对于每个组，我们还构造一个长度精确的单个“参考”常规括号序列$k$。 组的规则是分配给它的任何字符串都不能作为该参考序列内的连续子字符串出现。 

常规括号序列的行为类似于平衡括号表达式。 在几何视图中，它对应于永远不会低于零并且最终返回到零的戴克路径。 这种解释很重要，因为子串约束转化为对此类路径的本地段的约束。 

输出要求最小组数，对于每一组，我们必须输出一个有效长度 -$k$常规序列加上分配给它的索引。 

关键的困难在于每个组都受到全局避免条件的约束：所选序列必须避免该组中的所有禁止子串。 因此分组不是每个字符串独立的，这是一个全局兼容性问题。 

限制很小：$n \le 50$,$k \le 50$。 这立即排除了任何指数$k$每组，但仍然允许指数$n$或者$2^k$式DP。 自从$k$很小，我们可以考虑构建一个长度-$k$结构并直接检查禁止的子字符串。 

一个微妙的边缘情况是字符串根本不能出现在任何有效组中。 如果字符串本身已经“太大”（即它出现在长度为每个可能的正则括号序列中），就会发生这种情况$k$。 例如，如果一个字符串已经是一个完整的 Dyck 路径前缀，并且必须出现在任何补全中的某个位置，那么就不可能避免它。 一种幼稚的方法可能会假设每个字符串总是可以通过仔细选择的序列来避免，但事实并非如此。 

另一种失败情况是由于忽略重叠相互作用而产生的：两个字符串在序列中可能单独可以避免，但它们在一起会产生矛盾，因为它们的禁止位置与所有可能的结构重叠。 

## 方法

 蛮力的想法是考虑每个可能的分区$n$串成组。 对于每个组，我们尝试构造一个有效的长度-$k$常规括号序列，避免该组中的所有字符串作为子字符串。 可以通过前缀状态上的 DP 或暴力生成所有长度的 Dyck 序列来完成构造$k$，然后检查子串约束。 

的分区数$n=50$是巨大的（贝尔数字），已经存在$10^{47}$，因此分区枚举是不可能的。 即使我们修复了多个组，检查分配的可行性仍然是组合爆炸性的。 

关键的观察结果是，不同的禁止字符串的数量很少，并且每个约束在很强的意义上都是局部的：长度的字符串$L \le k$禁止任何候选序列中可以匹配的一组位置。 我们没有对分区进行推理，而是翻转了观点：我们尝试首先构造候选正则序列，然后根据字符串是否是该序列的子串来贪婪地分配字符串。 

这表明了一种结构，其中每个有效组对应于精心选择的 Dyck 单词，并且每个字符串被分配给避免它的任何 Dyck 单词。 自从$k \le 50$，我们可以枚举候选 Dyck 词或按需构造它们，同时确保覆盖所有字符串。 组的最小数量对应于选择 Dyck 单词的最小集合，使得每个字符串都被至少一个选定的单词避免，并且通过哪个单词避免它来诱导分组。 

这变成了一个字符串集合上的类似封面的结构，其中每个候选 Dyck 单词定义了它避免的字符串集合。 因为$k$很小，我们可以通过 DP 生成 Dyck 字，然后使用位掩码 DP 贪婪地或精确地选择最小覆盖$n \le 50$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力分区+验证| 指数为$n$和戴克一代| 高| 太慢了 |
 | DP over Dyck字+位掩码覆盖|$O(C_k \cdot n)$|$O(C_k + 2^n)$| 已接受 |

 这里$C_k$是加泰罗尼亚语号码$k$，最多大约是$2.5 \times 10^4$为了$k=50$，所以生成是可行的。 

## 算法演练

 核心思想是枚举所有长度的正则括号序列$k$，并且对于每个这样的序列计算它避免将哪些输入字符串作为子字符串。 然后，我们选择序列的最小子集，其“避免集”的并集覆盖所有字符串。 

1.生成所有长度有效的正则括号序列$k$。 这是通过递归 DP 来完成的，该 DP 跟踪当前平衡并确保其永远不会变为负数并以零结束。 这恰好产生了加泰罗尼亚家族的规模$C_{k/2}$。 
2. 对于每个生成的序列，检查每个输入字符串$s_i$并判断是否$s_i$显示为子字符串。 如果没有出现，则该序列是有效的“主机”$s_i$。 
3. 用大小的位掩码表示每个序列$n$，其中位$i$是 1 如果$s_i$不是该序列的子串。 
4. 现在我们要选择这些掩码的最小数量，以便它们的按位或涵盖所有$n$字符串。 这是一个小宇宙的经典套装封面。 
5. 对字符串子集运行 DP：let$dp[mask]$是精确覆盖覆盖字符串集所需的最小序列数。 初始化$dp[0]=0$。 
6. 对于每个序列掩码，放松转换：对于每个状态$mask$， 更新$mask \cup seq\_mask$。 
7. 存储父指针以重建选择的序列。 
8. DP之后，如果$dp[(1<<n)-1]$为无穷大，输出-1。 否则，重建所选序列并将每个字符串分配给避免它的任何序列。 

正确性取决于每个组可以由单个 Dyck 词独立表示，并且分组约束仅取决于避免，而不取决于字符串之间的内部交互。 

它的工作原理来自于分组问题的压缩：我们不是首先构建组，而是枚举所有可能的组代表（有效的 Dyck 词），并让每个代表定义一个可行的组。 任何最佳分组都必须对应于这些代表的某个子集，因为每个有效组都至少有一个有效的戴克序列见证其可行性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from functools import lru_cache

n, k = map(int, input().split())
s = [input().strip() for _ in range(n)]

# generate all regular bracket sequences of length k
res = []

def gen(cur, bal):
    if len(cur) == k:
        if bal == 0:
            res.append(cur)
        return
    if bal < 0 or bal > k - len(cur):
        return
    # add '('
    gen(cur + "(", bal + 1)
    # add ')'
    if bal > 0:
        gen(cur + ")", bal - 1)

gen("", 0)

# precompute substring checks
def contains(a, b):
    return b in a

m = len(res)

mask = [0] * m

for i in range(m):
    for j in range(n):
        if s[j] not in res[i]:
            mask[i] |= (1 << j)

INF = 10**9
dp = [INF] * (1 << n)
par = [-1] * (1 << n)
choice = [-1] * (1 << n)

dp[0] = 0

for i in range(m):
    w = mask[i]
    if w == 0:
        continue
    for st in range((1 << n) - 1, -1, -1):
        if dp[st] == INF:
            continue
        nxt = st | w
        if dp[nxt] > dp[st] + 1:
            dp[nxt] = dp[st] + 1
            par[nxt] = st
            choice[nxt] = i

full = (1 << n) - 1
if dp[full] == INF:
    print(-1)
    sys.exit()

groups = []
cur = full

while cur:
    i = choice[cur]
    prev = par[cur]
    groups.append(i)
    cur = prev

groups.reverse()

assign = [[] for _ in groups]

for idx, gi in enumerate(groups):
    for j in range(n):
        if s[j] not in res[gi]:
            assign[idx].append(j + 1)

print(len(groups))
for gi, members in zip(groups, assign):
    print(res[gi])
    print(len(members))
    print(*members)
```解决方案首先生成长度为所有有效的 Dyck 字$k$。 生成使用平衡变量来强制括号结构的正确性。 每个完成的序列都保证是一个规则的括号序列。 

对于每个 Dyck 单词，我们计算一个位掩码，指示它避免哪些输入字符串。 子字符串检查是直接的，因为$k$和$s_i$很小。 

然后，我们使用字符串子集上的 DP 来解决这些掩码上的最小集合覆盖。 该转换是单调的，因为添加序列只会增加覆盖范围。 父指针允许重建所选序列。 

最后，我们通过重新检查子字符串条件来重建组，以将每个字符串分配给适当的选定 Dyck 单词。

 ## 边缘情况

 当字符串本身非常受限制时，就会出现极端情况，例如`"(((("`和$k=4$。 在这种情况下，大多数 Dyck 单词都会将其包含为子字符串。 该算法可以正确处理此问题，因为此类单词在其掩码中仅具有该字符串的零位，并且 DP 避免依赖它们进行覆盖。 

另一种情况是没有 Dyck 单词避免特定字符串。 然后每个掩码都将该位设置为零，从而无法完全覆盖。 完全掩码的 DP 状态永远不会达到，算法输出`-1`，满足所需的不可能条件。 

最后一个微妙的情况是多个 DP 路径产生相同的最小组数。 父指针重建确保了一致的选择，而不需要打破平局逻辑，因为任何有效的最小覆盖都是可以接受的。
