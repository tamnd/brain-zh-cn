 ## 解决方案
 ## 问题理解

 棋盘是一个整数网格，其中每个单元格都由其行和列标识。 每个单元格已经包含一个数字，并且我们可以应用一个非常具体的转换，一次影响恰好四个单元格：任何大小至少为 2 x 2 的矩形子网格的角。一对对角角以 1 模 3 递增，而另一对角对角以 2 模 3 递增。 

问题是我们是否可以使用任意数量的此类操作将初始网格转换为目标网格。 

一个关键的约束是操作仅触及矩形的角，这强烈表明大多数网格在某种结构化线性约束下是不变的，而不是可以逐个单元自由编辑。 这通常预示着一个问题，其答案取决于一小组全局属性，而不是构建明确的移动序列。 

尽管网格可以达到 500 x 500，但总输入大小是可控的，因此每个测试解决方案预计为 O(nm)。 任何模拟操作或搜索变换序列的尝试都是立即不可行的，因为即使一个操作也是 O(1)，但可能的矩形数量是 O(n^2 m^2)，这使得暴力破解完全无法使用。 

不明显的困难在于理解该操作保留了网格的哪些属性。 粗心的方法会尝试贪婪地修复单元格或模拟局部校正，但这会失败，因为每个操作都会同时影响四个角并引入远程依赖性。 

典型的故障案例看起来像一个 2 x 2 网格。 假设我们从```
0 0
0 0
```并想要达到```
1 0
0 0
```一个天真的想法可能是对唯一的矩形应用操作。 但是任何操作都会同时更改两个对角单元格，因此不可能仅更改一个角而不影响另一个角。 这立即暗示个体细胞的独立性被打破。 

## 方法

 强力解释是将每个矩形操作视为可能的移动，并尝试将变换表示为此类移动的序列。 每次移动都会修改四个单元格，因此我们可以尝试跟踪状态并搜索与目标网格匹配的序列。 

问题在于，即使表示状态转换也变得很棘手。 以 3 为模的 n × m 网格的配置数量为 3^(nm)，并且转换形成密集的隐式图。 即使是状态上的 BFS 也是不可能的。 

关键的观察是每个运算都有一个非常严格的代数结构。 如果我们指定坐标 (i, j)，则每个操作都会选择 (i1, j1)、(i1, j2)、(i2, j1)、(i2, j2) 并添加固定模式：两个对角得到 +1 mod 3，另外两个得到 +2 mod 3。 

这种结构建议寻找守恒量。 我们不是跟踪整个网格，而是检查每个单元格在每个角色中受到影响的次数（正对角线与负对角线）。 解决此类问题的一个经典技巧是将一切都简化为模 3 的线性方程组。 

如果我们考虑初始网格和目标网格之间的差异，我们想要检查这些矩形操作是否可以生成差异矩阵。 关键的简化是，每个有效的操作都可以分解为除了沿着某些边界相互作用之外相互抵消的贡献。 简化代数后，唯一的独立约束减少为单个全局不变量：具有交替奇偶校验结构的网格上的总和保留模 3。 

这将问题简化为检查变换后的网格是否与初始网格的不变量匹配。 由于操作保留了该不变性，因此任何不匹配都会导致转换变得不可能。 如果不变量匹配，则可以建设性地证明可以组合操作来以实现任何有效配置的方式调整单元。 

该结构类似于其他网格变换问题，其中矩形操作降低了边界条件的自由度。

 ## 算法演练

 1. 计算差异网格 d，其中每个单元格为 (target[i][j] - 初始[i][j]) 模 3。这会隔离需要实现的目标，而不是直接使用两个网格。 
2. 请注意，任何有效的操作序列都必须保留源自矩形角对奇偶加权和的贡献方式的全局约束。 我们计算代表此不变量的 d 上的单个累加值。 
3. 迭代所有单元，并根据 (i + j) % 2 将它们的贡献累积到两个奇偶校验类中。一个类实际上从操作的某些角落接收 +1 贡献，另一个类接收 +2 贡献，这减少到模 3 的有符号和。 
4. 将差异网格得到的不变量与零进行比较。 如果它非零，则任何操作序列都无法产生所需的转换。 
5. 如果为零，则返回变换是可能的。 

这样做的原因是每个允许的操作都会以保留单元格值的相同线性组合的方式更改网格。 因此，任何可达状态都必须位于该不变量下的同一等价类中。 相反，这些操作足以生成满足它的所有配置，因为矩形操作跨越受该单一关系约束的完整解空间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = [list(map(int, input().split())) for _ in range(n)]
    b = [list(map(int, input().split())) for _ in range(n)]

    diff = 0

    for i in range(n):
        for j in range(m):
            d = (b[i][j] - a[i][j]) % 3
            if (i + j) % 2 == 0:
                diff = (diff + d) % 3
            else:
                diff = (diff - d) % 3

    print("YES" if diff % 3 == 0 else "NO")

if __name__ == "__main__":
    solve()
```该代码首先将问题压缩到差异网格中，以便每个单元格独立地表示所需的更改。 然后，它累积奇偶加权和，这是所有允许的操作所保留的不变量。 基于 (i + j) % 2 的交替符号编码了矩形角在操作规则下如何相互作用。 最后，对结果进行模 3 检查。 

重要的主要实现细节是模算术的一致处理，特别是确保减法不会在模归一化之外产生负值。 奇偶校验分割必须完全匹配，否则不变量会破坏并产生漏报。

 ## 边缘情况

 一种微妙的边缘情况是初始网格和目标网格之间只有一个单元格不同。 在这种情况下，该算法会计算一个非零不变量，因为该单一差异有助于一个奇偶校验类而无需取消。 由于每个操作总是修改成对对角结构中的单元格，因此没有操作序列可以隔离单个单元格更改。 

另一种边缘情况是网格是均匀的但到处移动相同的值。 即使每个单元都发生变化，交替奇偶校验和也会抵消，因为偶数和奇数贡献的数量相等，相互抵消，因此不变量保持为零，并且算法正确地接受变换。
