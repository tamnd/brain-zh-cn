 ## 解决方案
 ## 问题理解

 该任务要求我们查看数组中每对有序的位置。 一对`(i, j)`，我们通过添加两个选定的元素来形成一个值。 有`N²`这样的值是因为选择第一和第二位置是独立的选择。 我们需要找到`K`- 所有这些对和中的第最小值。 

简单版本允许`N`最多 500 个，最多 20 个测试用例。 这意味着直接`O(N²)`方法每个测试用例大约有 250,000 次操作，这是可以接受的。 但是，如果我们添加额外的工作，例如对所有内容进行排序`N²`求和，创建的值数量也是25万个，排序还是可以的。 预期的解决方案通常是使用对和的特殊结构，而不是具体化所有内容，因为它也教授用于更大变体的技术。 

数组中的值可以大到`10^9`的绝对值，所以答案可以达到`2 * 10^9`。 解决方案必须使用可以安全保存这些值的整数类型。 Python 整数会自动处理这个问题。 

第一个棘手的情况是当`K`指重复的和。 例如：```
1
3 4
1 1 5
```这对总和是：```
2 2 6
2 2 6
6 6 10
```正确答案是`6`为第四个最小值。 仅存储唯一总和的解决方案将错误地返回`10`。 

另一种边缘情况出现为负值：```
1
2 2
-5 -1
```总和是`-10, -6, -6, -2`，所以答案是`-6`。 假设答案是肯定的或错误地初始化其边界的二分搜索将在此处失败。 

## 方法

 最简单的方法是生成每一个可能的对。 对于每个索引`i`，我们尝试每个索引`j`并附加`a[i] + a[j]`到一个列表中。 全部生成后`N²`求和，我们对列表进行排序并取出位置上的元素`K - 1`。 

这是有效的，因为排序将完整的多重总和集完全按照所需的顺序放置。 问题是我们创建了一个大的中间数组并支付了排序成本。 生成值的数量是`N²`，并对它们进行排序成本`O(N² log(N²))`。 对于简单的限制，这可以通过，但如果约束增加，它就不能很好地扩展。 

改进解决方案的观察结果是，对原始数组进行排序后，我们可以回答一个不同的问题：“有多少对和小于或等于 X？” 如果我们能快速回答这个问题，我们就可以二分查找包含至少 K 个和的最小 X。 

对于固定值`X`，考虑一个排序数组。 对于每个左边的元素`a[i]`，所有有效的合作伙伴根据实现形成后缀或前缀。 由于数组是已排序的，因此我们可以使用两个指针。 从右边最大的索引开始，如果`a[i] + a[j]`大于`X`，我们移动`j`左边。 当它生效时，每个索引`0`到`j`也有效，添加`j + 1`可能的合作伙伴。 

蛮力之所以有效，是因为它明确地看到了每一个可能的总和。 更快的方法有效，因为排序顺序让我们可以一次计算许多总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N² log(N²)) | O(N² log(N²)) | O(N²) | 简易版本已接受 |
 | 对答案进行二分搜索 | O(N log V + N log N) | O(N log V + N log N) | O(1) 额外 | 已接受 |

 这里`V`是可能答案的范围，大约`2 * 10^9`，所以二分查找大约需要 31 次迭代。 

## 算法演练

 1. 对数组进行排序。 排序顺序让我们可以计算有多少对的总和低于所选值，而无需检查每对。 
2. 将二分查找范围设置为从最小可能的对和到最大可能的对和。 最小可能的和由两个最小的元素创建，最大可能的和来自两个最大的元素。 
3. 对于当前中间值`mid`，计算有多少个有序对`(i, j)`满足`a[i] + a[j] <= mid`。 
4. 为了有效计数，请保留指针`j`从已排序数组的末尾开始。 对于每一个`i`， 减少`j`而当前的对太大了。 一次`a[i] + a[j]`是有效的，每个索引来自`0`到`j`与`i`，所以添加`j + 1`到计数。 
5. 如果计数至少为`K`，答案可能是`mid`或更小，因此将二分搜索右边界向下移动。 否则，总和不够小，因此将左边界向上移动。 
6. 当搜索结束时，左边界是至少有的最小值`K`对总和不超过它。 

为什么有效：计数函数是单调的。 如果一个值`X`至少有`K`总和不大于它，每个较大的值也至少有`K`总和。 如果它少于`K`，每个较小的值也少于`K`。 二分查找找到条件成立的第一个值，这正是`K`-第最小总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    def count_pairs(x):
        res = 0
        j = n - 1
        for i in range(n):
            while j >= 0 and a[i] + a[j] > x:
                j -= 1
            res += j + 1
        return res

    left = a[0] + a[0]
    right = a[-1] + a[-1]

    while left < right:
        mid = (left + right) // 2
        if count_pairs(mid) >= k:
            right = mid
        else:
            left = mid + 1

    return str(left)

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        ans.append(solve_case())
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```首先对数组进行排序，因为计数函数依赖于单调顺序。 如果不进行排序，移动指针将无法代表所有可能的伙伴。 

这`count_pairs`函数维护一个指针`j`在整个扫描过程中仅向左移动。 这就是为什么计数是`O(N)`而不是`O(N²)`。 的价值`j`永远不会为每个新的重置`i`。 

二分查找使用`left < right`而不是搜索索引，因为我们正在寻找一个值，而不是一个位置。 最终值`left`是至少包含的第一个总和阈值`K`对。 

界限是根据实际的最小和最大可能总和计算的。 这可以正确处理负数并避免对输入范围的假设。

 ## 边缘情况

 对于重复的情况：```
1
3 4
1 1 5
```排序后的数组仍然存在`[1, 1, 5]`。 按排序顺序排列的对和是`2, 2, 2, 2, 6, 6, 6, 6, 6`。 在二分查找过程中，阈值是`2`数到四对，所以答案变成`2`。 该算法计算出现次数，而不是不同值，因此可以自然地处理重复项。 

对于负值情况：```
1
2 2
-5 -1
```搜索开始于`-10`到`-2`。 检查时`-6`, the counting step finds that the first element can pair with both elements, while the second element cannot exceed the threshold. 计数达到二，所以答案是`-6`。 负范围有效，因为边界直接来自数组值。
