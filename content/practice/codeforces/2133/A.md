 ## 解决方案
 ## 问题理解

 我们被要求决定是否可以将一系列齿轮排列成一条线，使得最左边的齿轮以每秒一转的速度旋转，最右边的齿轮恰好以每秒一转的速度旋转。 每个齿轮都有多个齿，任何齿轮相对于其相邻齿轮的速度与齿数比成正比。 具体来说，如果一个齿轮$y$齿驱动齿轮$x$牙齿高速旋转$z$，下一个齿轮的转速为$z \cdot y / x$。 我们获得了多个测试用例，每个测试用例最多有 100 个齿轮，齿数在 2 到 100 之间。 

问题简化为排列整数$a_1, \dots, a_n$使得沿线的连续比率的乘积等于 1。如果排列的序列是，则明确地写出该乘积$b_1, b_2, \dots, b_n$，最终齿轮速度为$$1 \cdot \frac{b_1}{b_2} \cdot \frac{b_2}{b_3} \cdots \frac{b_{n-1}}{b_n} = \frac{b_1}{b_n}.$$因此，当且仅当第一个和最后一个齿轮的齿数相同时，最右边的齿轮才能以速度 1 旋转。 这是关键的简化：所有中间齿轮都取消。 

鉴于此，问题相当于检查是否存在可以放置在序列两端的齿轮数。 

边缘情况包括当所有齿轮具有相同数量的齿时，这通常是“是”，或者当没有数字出现至少两次时，这是“否”。 例如，如果齿轮是`[2, 3]`，两种安排都不满足要求。 

约束足够小，可以进行简单的计数：$n$最多 100 个并且$t$最多 1000 个$O(n^2)$蛮力方法是可行的，但计算出现次数是$O(n)$每个测试用例都更干净。 

## 方法

 蛮力方法将尝试齿轮的所有排列并模拟每个齿轮的旋转。 为了$n = 100$， 有$100!$排列，这是天文数字般巨大且不可行的。 甚至不需要模拟每个排列的比率，因为最终速度仅取决于第一个和最后一个档位。 

关键的观察是比率望远镜：连续的乘积$\frac{y}{x}$简化为$\frac{b_1}{b_n}$。 这将问题从模拟齿轮运动简化为简单检查第一个齿轮和最后一个齿轮是否相等。 因此，最佳解决方案是检查输入中是否有任何牙齿数至少出现两次。 如果是的话，我们可以把它放在两端，把剩下的齿轮任意排列在中间。 如果不是，则没有任何安排可以满足要求。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（模拟所有排列）| O(n!) | O(n) | 太慢了 |
 | 计算出现次数，检查重复项 | 每个测试用例 O(n) | O(100) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 每个测试用例将被独立处理。 
2. 对于每个测试用例，读取齿轮数$n$他们的牙齿数在一个列表中$a$。 
3. 使用字典或数组计算每个牙齿的出现次数。 这将使我们知道哪些数字出现多次。 
4. 检查是否有任何计数至少为 2。如果存在这样的计数，则打印“YES”。 否则，打印“NO”。 
5. 继续执行下一个测试用例，直到处理完所有测试用例。 

工作原理：最右边齿轮的速度仅取决于排列中的第一个和最后一个齿轮，因为中间传动比相互抵消。 在两端放置一个重复的齿轮可以保证比率乘积等于 1，满足条件。 不需要其他安排，检查就足够了，也是必要的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    gears = list(map(int, input().split()))
    counts = {}
    found = False
    for x in gears:
        counts[x] = counts.get(x, 0) + 1
        if counts[x] >= 2:
            found = True
            break
    print("YES" if found else "NO")
```该解决方案读取每个测试用例，使用字典计算每个牙齿编号的出现次数，并在任何数字出现两次时提前中断。 早期的中断确保我们在找到解决方案后不会不必要地处理剩余的数字。 我们使用`dict.get`简化递增计数而不需要条件检查。 

## 工作示例

 输入样本`[2, 5, 5]`:

 | 齿轮| 计数| 发现 >=2？ |
 | ---| ---| ---|
 | 5 | {5:1} | 没有 |
 | 5 | {5:2} | 是的 |

 该算法打印“YES”。 

输入`[2, 2, 3]`:

 | 齿轮| 计数| 发现 >=2？ |
 | ---| ---| ---|
 | 2 | {2:1} | 没有 |
 | 3 | {2:1, 3:1} | 没有 |

 没有数字出现两次，因此算法打印“NO”。 

这些痕迹表明该算法正确识别是否存在要放置在两端的重复项。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | 每个测试用例 O(n) | 对每个齿轮的出现次数进行计数与齿轮的数量呈线性关系。 |
 | 空间| O(100) | 最大不同牙齿数为 99 (2-100)，因此字典是有界的。 |

 和$t \le 1000$和$n \le 100$，这会导致最多 100,000 次操作，完全在 1 秒限制之内。 

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        gears = list(map(int, input().split()))
        counts = {}
        found = False
        for x in gears:
            counts[x] = counts.get(x, 0) + 1
            if counts[x] >= 2:
                found = True
                break
        output.append("YES" if found else "NO")
    return "\n".join(output)

# provided samples
assert run("5\n2\n5 5\n4\n6 3 6 9\n2\n2 3\n7\n30 10 12 10 10 9 18\n5\n2 4 8 16 32\n") == "YES\nYES\nNO\nYES\nNO", "sample 1"

# custom cases
assert run("1\n2\n2 2\n") == "YES", "all equal"
assert run("1\n3\n2 3 4\n") == "NO", "all distinct, small n"
assert run("1\n4\n3 3 4 5\n") == "YES", "one duplicate in middle"
assert run("1\n100\n" + " ".join(str(i) for i in range(2, 102)) + "\n") == "NO", "large n, all distinct"
```| 测试输入| 预期产出 | 它验证了什么 |
 | ---| ---| ---|
 |`[2,2]`| 是 | 最小尺寸，全部相等 |
 |`[2,3,4]`| 否 | 小n，全部不同|
 |`[3,3,4,5]`| 是 | 一份不在末尾的重复项 |

 ## 边缘情况

 该算法通过计数并立即找到重复的齿轮来处理所有齿轮都相同的情况。 例如，`[5, 5, 5]`产生“YES”，因为 5 出现了 3 次。 当所有齿轮都不同时，例如`[2, 3, 4]`，字典计数显示没有重复项，算法输出“NO”。 具有 100 个不同值的最大尺寸输入仍然有效地生成“NO”，因为计数字典仍然很小并且永远不会触发早期中断。
