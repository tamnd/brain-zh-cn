 ## 解决方案
 ## 问题理解

 我们给出了一个由有向无环图表示的下界门户网络。 每个门户可能与其他门户有直接连接，但不存在循环。 任务是在这个隐藏的 DAG 中找到最长的路径。 挑战来自交互：我们不能直接看到边缘，但我们可以向 Steve 查询一组门户和一个起始门户，他将仅使用该组门户中的门户告诉我们从该门户开始的最长路径的长度。 

门户数量$n$最多 500，我们最多允许$2n$查询。 这很重要，因为查询每个可能路径的简单解决方案将需要指数数量的查询，远远超出允许的范围$2n$。 DAG 属性保证路径不能重新访问同一门户，因此我们可以推断拓扑顺序。 

不明显的边缘情况包括门户断开连接的情况。 例如，如果网络有两个完全独立的子图，则从一个子图进行查询将永远不会到达另一个子图，因此假设连通性的粗心方法可能会低估路径长度。 同样，如果 DAG 有多个分支，则很容易将局部最大路径误认为是全局最大值。 

## 方法

 强力方法是尝试通过查询每个子集或节点对来重建整个邻接结构。 这在原则上是正确的：通过反复询问单节点扩展，可以确定存在哪些边。 然而，对于$n = 500$，所需的查询数量至少呈二次方增长$n$，迅速超过$2n$限制。 

关键的见解是我们不需要整个 DAG 结构。 由于网络是 DAG，因此每条路径都可以表示为拓扑顺序。 如果我们可以维护一系列门户，使得每个新门户都插入到与最长路径查询一致的位置，我们就可以增量地构建一个最大长度路径。 我们可以通过使用二分搜索和查询子段将新的门户插入到现有序列中，从而有效地找到其在拓扑顺序中的位置，而无需重建所有边。 

这将问题从“在未知 DAG 中查找最长路径”减少为“使用以下命令将门户插入到与 DAG 一致的列表中”$O(n \log n)$查询”，它适合$2n$查询限制因为$n \le 500$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | Brute Force全DAG重建| O(n^2) 次查询 | O(n^2) | O(n^2) | 太慢，超过查询限制 |
 | 使用最长路径查询进行增量插入| O(n log n) 次查询 | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个空列表`path`它将按照与最长路径的拓扑顺序一致的顺序存储门户。 
2. 对于每个门户$v$从 1 到$n$：

 a. 对当前数据使用二分查找`path`list 来确定插入的位置$v$不会减少最大路径长度。 对于索引之间的候选插入`l`和`r`,查询子列表包括`v`查看起始于的最长路径的长度$v$。 

b. 如果长度与当前最大长度相比有所增加`path`， 插入$v$那里。 
3.所有入口插入后，列表`path`包含形成 DAG 中最大长度路径的序列。 
4.使用需要的输出路径`! k v1 v2 ... vk`格式。 

为什么它有效：不变的是在每一步，`path`维护一系列门户，使得每个连续的子序列代表这些门户上的最长路径。 DAG 属性保证不存在循环，因此二分搜索可以正确识别任何新门户的插入点，而不会使以前的放置无效。 每个查询都直接测试插入入口的效果，确保最终的序列对应于真正的最长路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def query(x, S):
    print(f"? {x} {len(S)} {' '.join(map(str, S))}")
    sys.stdout.flush()
    res = int(input())
    if res == -1:
        exit()
    return res

def solve_case():
    n = int(input())
    path = []

    for v in range(1, n + 1):
        if not path:
            path.append(v)
            continue

        l, r = 0, len(path)
        while l < r:
            m = (l + r) // 2
            S = path[m:] + [v]
            res = query(v, S)
            if res == len(S):
                r = m
            else:
                l = m + 1
        path.insert(l, v)

    print(f"! {len(path)} {' '.join(map(str, path))}")
    sys.stdout.flush()

def main():
    t = int(input())
    for _ in range(t):
        solve_case()

if __name__ == "__main__":
    main()
```每个门户都以保留拓扑顺序的方式插入。 二分查找最多保证$\log n$每个门户的查询数，将总数保持在$2n$。 我们在每个查询后刷新输出以满足交互式问题约束。

 ## 边缘情况

 断开连接的节点是自然处理的：如果节点无法扩展现有路径，二分搜索会将其插入到末尾，为该节点创建长度为 1 的路径。 DAG 中的多个分支由插入逻辑处理：二分搜索确保根据查询的响应将入口插入到保留最长可达路径的位置。 这保证了构造的序列对应于所有场景下的最大长度路径，包括稀疏和密集 DAG。
