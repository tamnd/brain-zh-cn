 ## 解决方案
 ## 问题理解

 我们在 ASCII 艺术竞赛中获得了三位人工智能创意助理（Gemini、ChatGPT 和 Claude）的分数。 每个分数都是80到100之间的整数。组织者希望决定评委的分数是否足够一致以公布最终结果。 规则很简单：如果最高分和最低分相差至少10分，评委必须“再次检查”； 否则，公布的结果是三个分数的中位数。 这里的中位数表示如果将三者排序的话，会出现在中间的分数。 

输入是代表分数的三个整数的单行，输出是单行，“再次检查”或“最终 X”，其中 X 是中位数。 约束非常小：只有三个整数，因此我们选择的任何算法都将在恒定时间内运行。 然而，非明显的边缘情况包括所有三个分数相等、一个极端有两个分数、另一个极端有一个分数，或者分数相差正好 10。例如，如果分数是 80、90、90，则最大和最小之间的差值正好是 10，因此程序应打印“再次检查”。 粗心的方法可能会通过选择错误的中间元素或使用排它不等式来错误地计算中位数。 

## 方法

 这里的暴力方法是对三个分数进行排序。 对三个元素的列表进行排序很简单； 然后我们可以直接选取中间的值作为中位数，并检查最大值和最小值之间的差异。 这是有效的，因为排序保证我们可以可靠地识别最小值、最大值和中值。 尽管排序通常是 O(n log n)，但对于三个元素来说，它实际上是恒定时间，因此性能不是问题。 

稍微优化的方法可以避免完全排序。 我们可以使用简单的条件逻辑计算最小值、最大值和中值。 最小值是三个分数中最小的，最大值是最大的，中位数可以通过将所有三个分数相加并减去最小值和最大值来找到。 这样可以通过更少的比较产生相同的结果，而且很优雅。 三个数字的中位数等于总和减去最小值和最大值的观察结果允许我们完全避免排序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对三个分数进行排序 | O(1) | O(1) | O(1) | O(1) | 已接受 |
 | 最小/最大/求和技巧 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 这两种方法实际上都是恒定时间，因为输入大小固定为 3。 

## 算法演练

 1.将三个分数读入变量`g`,`c`， 和`l`。 这是我们从输入到内部表示的直接映射。 
2. 计算最高分`mx`使用`max(g, c, l)`。 这将确定得分最高的人工智能助手。 
3. 计算最低分数`mn`使用`min(g, c, l)`。 这确定了得分最低的人工智能助手。 
4.如果有差异`mx - mn`大于或等于10，打印“再次检查”并停止。 这强制执行了分数过于分散的规则。 
5. 否则，将中位数分数计算为`g + c + l - mx - mn`。 这是可行的，因为从总和中减去最小值和最大值会得到中间值。 
6. 打印“final”，然后打印中位数分数。 

工作原理：该算法明确识别极值以检查一致性标准，并且 sum-minus-min-max 技巧可以正确计算中位数，因为只有三个元素。 任何中间状态都不能违反规则，因为所有三个变量总是以相同的方式进行比较。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

g, c, l = map(int, input().split())

mx = max(g, c, l)
mn = min(g, c, l)

if mx - mn >= 10:
    print("check again")
else:
    median = g + c + l - mx - mn
    print(f"final {median}")
```该解决方案有效地读取输入并将其直接映射到三个整数变量。 考虑到分数范围的限制，最大值和最小值的计算既简单又安全。 中位数计算避免了排序，并且即使两个分数相等也是稳健的。 打印使用 f 字符串以提高可读性，并确保输出格式与问题所期望的完全匹配。

 ## 边缘情况

 分数相差 10 的边缘情况通过比较来处理`mx - mn >= 10`。 例如，使用输入`80 90 90`,`mx=90`和`mn=80`， 所以`mx - mn=10`，满足再次检查条件。 该算法不会在此处错误地打印中位数。 同样，当所有分数相等时，`mx=mn`，因此差值为 0，中位数等于任意分数，这是正确的。 这证实了该算法尊重平等条件和边界差异条件。
