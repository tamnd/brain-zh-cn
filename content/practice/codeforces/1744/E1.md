 ## 解决方案
 ## 问题理解

 我们有四个正整数$a, b, c, d$这样$a < c$和$b < d$。 任务是找到两个数$x$和$y$满意的$a < x \le c$和$b < y \le d$使得产品$x \cdot y$可以整除$a \cdot b$。 如果不存在这样的对，我们必须返回$-1 -1$。 

本质上，我们需要找到略大于$a$和$b$其乘积与 的倍数一致$a \cdot b$。 挑战不仅仅是选择多个$a$和$b$但要遵守严格的界限$c$和$d$。 

限制条件适中：$a, b, c, d \le 10^5$直至$10$测试用例。 这允许算法大致$O(c-a + d-b)$每个测试用例在最坏的情况下，但任何接近$O(c \cdot d)$太慢了，因为$c \cdot d$可以接近$10^{10}$。 

非明显的边缘情况包括以下情况$a$和$b$没有允许范围内的倍数。 例如，如果$a = 12$,$c = 14$,$b = 21$,$d = 24$, 的最小倍数$a$大于$a$是 24，超过$c$。 一种天真的选择方法$x = 2a$和$y = 2b$如果超出范围可能会失败。 

## 方法

 蛮力方法会迭代所有$x$在$(a, c]$和所有$y$在$(b, d]$并检查是否$x \cdot y$可以整除$a \cdot b$。 这对于正确性是有效的，因为它明确地测试了所有候选者。 然而，在最坏的情况下，大约有$(c-a) \cdot (d-b)$对。 如果$c-a \approx 10^5$和$d-b \approx 10^5$，这产生$10^{10}$的操作，这是不可行的。 

关键的观察是，如果我们修复$x$是 的倍数$a$大于$a$，我们可以尝试最小的倍数。 相似地，$y$应该是的倍数$b$大于$b$。 我们可以选择$x = \lceil \frac{a+1}{a} \rceil \cdot a = 2a$作为第一候选人。 然后我们选择$y$作为最小倍数$b$这使得$x \cdot y$可除以$a \cdot b$。 

因为$x$是的倍数$a$，我们只需要$y$是 的倍数$b$。 所以$y = \lceil \frac{b+1}{b} \rceil \cdot b = 2b$如果在范围内，则有效。 如果任一候选人超出允许范围$(a, c]$或者$(b, d]$，不存在解。 

这将问题从检查所有对减少到检查每个变量最多几个倍数，从而提供非常快速的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((c-a)*(d-b)) | O(1) | O(1) | 太慢了|
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取整数$a, b, c, d$。 
2. 计算最小倍数$a$严格大于$a$。 这是$x = a \cdot 2$。 如果$x > c$， 输出$-1 -1$并继续。 
3. 计算最小倍数$b$严格大于$b$。 这是$y = b \cdot 2$。 如果$y > d$， 输出$-1 -1$并继续。 
4. 返回$x, y$作为解决方案。 

为什么有效：任意倍数$a$大于$a$乘以任意倍数$b$大于$b$产生一个可除以的乘积$a \cdot b$。 我们选择最小的倍数以保持在范围内。 如果最小的倍数已经超出了界限，则无法容纳更大的倍数，因此$-1 -1$是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c, d = map(int, input().split())
    
    # smallest multiple of a greater than a
    x = ((a + a) // a) * a
    if x <= a:
        x += a
    if x > c:
        print(-1, -1)
        continue
    
    # smallest multiple of b greater than b
    y = ((b + b) // b) * b
    if y <= b:
        y += b
    if y > d:
        print(-1, -1)
        continue
    
    print(x, y)
```说明：我们计算第一个倍数$a$多于$a$将其加倍。 这同样适用于$b$。 我们明确检查边界$c$和$d$返回之前。 该公式确保没有相差一的错误，并且整数运算避免了浮点数。
