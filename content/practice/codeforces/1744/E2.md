 ## 解决方案
 ## 问题理解

 我们被要求找到两个数字`x`和`y`在给定的区间内，使得它们的乘积可以被其他两个数字的乘积整除。 形式上，给定四个整数`a < c`和`b < d`，我们必须找到整数`x`和`y`满意的`a < x ≤ c`,`b < y ≤ d`， 和`(x * y) % (a * b) == 0`。 如果不存在这样的数字，我们输出`-1 -1`。 

输入很大：`a, b, c, d`可以达到`10^9`，但测试用例数量很少（`t ≤ 10`）。 这意味着任何检查所有对的解决方案`(x, y)`在范围内太慢，因为候选对的数量最多可达`(c-a) * (d-b)`这大约是`10^18`在最坏的情况下。 

容易错误处理的边缘情况包括范围`[a+1, c]`或者`[b+1, d]`非常紧，或者当`a * b`大于作为除数的任何一个范围。 例如，如果`a=12, b=21, c=14, d=24`，没有`x`在`(12,14]`和`y`在`(21,24]`其乘积可被整除`252`，所以输出必须是`-1 -1`。 幼稚的方法可能会错误地假设乘法`a+1`和`b+1`总是有效。 

## 方法

 蛮力方法将迭代所有整数`x`在`(a, c]`和所有`y`在`(b, d]`，检查是否`x * y % (a * b) == 0`。 This is correct in principle, but it has a worst-case complexity of`(c-a) * (d-b)`可以达到`10^18`。 即使只有 10 个测试用例，这也是不可行的。 

解锁快速解决方案的关键观察是我们不需要检查每个数字。 我们可以与倍数一起工作。 如果我们能找到任意倍数`a`那在于`(a, c]`以及任意倍数`b`在`(b, d]`，那么他们的乘积可以除以`a * b`。 更一般地，我们只需要其中一个数字是其各自基数的倍数，另一个可以调整以使乘积可整除。 

一个系统的方法是尝试选择`x`作为最小倍数`a`大于`a`且小于或等于`c`，类似地对于`y`作为`b`大于`b`且小于或等于`d`。 如果不存在这样的倍数，我们可以尝试对称选择：选择`y`作为`b`并调整`x`是 的倍数`a`满足整除性。 如果两个选择都不在界限之内，则没有解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((c-a)*(d-b)) | O(1) | O(1) | 太慢了|
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算最小倍数`a`严格大于`a`。 这可以通过计算来完成`x = ((a // a) + 1) * a`，但更简单地说，`x = 2 * a`始终作为第一候选人。 检查是否`x ≤ c`。 
2.如果`x ≤ c`，那么我们需要`y`这样`(x * y) % (a * b) == 0`和`b < y ≤ d`。 自从`x`已经是的倍数`a`，就足以使`y`的倍数`b`。 选择最小的倍数`b`大于`b`：`y = 2 * b`。 检查是否`y ≤ d`。 
3. 如果两者都`x`和`y`拟合边界，输出它们。 这保证了`x * y`可以整除`a * b`。 
4. 如果第一个候选人失败，交换角色：尝试`y = 2 * b`作为起点并选择`x`作为最小倍数`a`这样`(x * y) % (a * b) == 0`和`a < x ≤ c`。 这通常会减少到最小倍数`a`多于`a`与兼容`y`。 
5. 如果两次尝试都失败，则输出`-1 -1`。 

为什么它有效：我们只考虑`a`和`b`因为如果没有大的乘数，倍数之外的任何数字都无法满足整除性。 该算法探索允许范围内的最小倍数，确保正确性，同时避免在整个区间内进行强力迭代。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b, c, d = map(int, input().split())
        # Try x = first multiple of a > a
        x = (a // a + 1) * a  # always 2 * a
        if x > c:
            x = -1
        # Try y = first multiple of b > b
        y = (b // b + 1) * b  # always 2 * b
        if y > d:
            y = -1
        if x != -1 and y != -1:
            print(x, y)
        else:
            # Alternative: try scaling x by smallest factor so that y in range
            found = False
            for mul_x in range(2, (c // a) + 1):
                x_candidate = a * mul_x
                min_y = ((a * b + x_candidate - 1) // x_candidate)
                y_candidate = b * ((min_y + b - 1) // b)
                if x_candidate <= c and b < y_candidate <= d:
                    print(x_candidate, y_candidate)
                    found = True
                    break
            if not found:
                print(-1, -1)

if __name__ == "__main__":
    solve()
```此代码首先尝试最简单的候选倍数。 如果超出范围，它会系统地搜索兼容的`x`和`y`使用整数除法来确定最小倍数`b`满足每个候选人的整除性`x`。 计算这些倍数时，相差一的错误很常见，因此要注意正确舍入。
