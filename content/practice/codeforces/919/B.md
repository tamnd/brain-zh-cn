 ## 解决方案
 ## 问题理解

 当正整数所有十进制数字之和恰好为 10 时，该正整数被称为“完美”。 

我们给定一个整数`k`，我们必须输出`k`-数字和等于10的最小正整数。排序是通常的数字排序。 例如，第一个完全数是`19`因为`1 + 9 = 10`，第二个是`28`， 等等。 

约束非常小。 我们只需要第一个`10,000`完美的数字。 这立即表明，一一生成候选人是可行的。 挑战不是处理巨大的输入大小，而是找到一种干净的方法来按升序枚举完美数字。 

一个有用的观察是数字和为 10 的数字并不罕见。 在最初的几十万个整数中，已经有很多了。 自从`k ≤ 10000`，即使是简单的搜索也会在时间限制内轻松完成。 

有一些边缘情况值得检查。 

用于输入```
1
```答案是```
19
```一个粗心的解决方案，从开始搜索`10`并且忘记检查每个数字可能会错过第一个有效值。 

用于输入```
2
```答案是```
28
```如果解决方案意外地计算了数字总和为_至多_ 10 而不是_准确_ 10 的数字，则会错误地包含以下值：`10`。 

对于较大的头寸，如果生成逻辑有缺陷，重复计数可能会成为问题。 例如，两者`109`和`190`数字总和为 10。我们必须对每个不同的整数精确计数一次并保留数字顺序。 

## 方法

 最直接的想法是按升序检查正整数。 对于每个整数，计算其数字之和。 当总和等于 10 时，增加一个计数器。 当计数器达到`k`，输出当前数。 

这种方法是正确的，因为它以严格递增的顺序检查整数，并精确计算数字和为 10 的整数。当计数器变为`k`，我们发现了`k`-最小的完全数。 

剩下的问题是它是否足够快。 答案是肯定的。 万分之一的完全数并不是很大，计算数字和只需要很少的运算。 即使在 2 秒的限制内检查几十万个数字也是微不足道的。 

还有一个小观察结果经常出现在公认的解决方案中。 每个完美数都以某个数字结尾，并附加一个尾随`0`不改变数字和。 人们可以从这一事实推导出一种更专门的生成方法。 然而，约束是如此之小，以至于简单的枚举解决方案已经完全足够并且更容易推理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举| O(N log N) | O(N log N) | O(1) | O(1) | 已接受 |
 | 直接生成观察| O(k log N) | O(k log N) | O(1) | O(1) | 已接受 |

 这里`N`表示找到答案之前检查的最大数量。 

## 算法演练

 1. 阅读`k`。 
2. 初始化计数器`found = 0`。 
3. 开始按升序检查整数，从`1`。 
4. 对于当前整数，计算其十进制数字之和。 
5. 如果数字和等于`10`, 增量`found`。 
6.如果`found == k`，输出当前整数并停止。 
7. 否则继续下一个整数。 

关键思想是数字按升序处理。 每个有效数字只计算一次，因此`k`-第一次我们遇到的有效数字必须对应于`k`-最小的完全数。 

### 为什么它有效

 每一步，`found`等于已检查的所有整数中遇到的完美数的数量。 

这个不变量最初是正确的，因为没有处理任何整数并且`found = 0`。 每当检查一个新整数时，我们都会增加`found`恰好当该整数完美时。 Thus the invariant remains true after every iteration.

 Since integers are visited in increasing order, when`found`首先变成`k`， 确切地`k`完美数已经出现，直到当前整数（包括当前整数）。 因此当前的整数正是`k`-最小的完全数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def digit_sum(x):
    s = 0
    while x:
        s += x % 10
        x //= 10
    return s

def solve():
    k = int(input())
    
    found = 0
    num = 1
    
    while True:
        if digit_sum(num) == 10:
            found += 1
            if found == k:
                print(num)
                return
        num += 1

solve()
```功能`digit_sum`使用重复除以 10 计算十进制数字的总和。 

主循环按升序扫描整数。 每当一个数字的数字和为 10 时，计数器就会增加。 一旦计数器到达`k`，打印当前号码。 

最常见的错误是计数逻辑中的差一错误。 比较必须在计数器递增之后进行，因为当前数字本身可能就是答案。 

Python 整数是无界的，因此不存在溢出问题。
