 ## 解决方案
 ## 问题理解

 我们得到一个有向图，其中每个顶点都带有一个小写字母。 有效的行走遵循从一个节点到另一个节点的有向边，只要我们尊重方向，我们就可以重新访问节点和边。 

对于任何这样的步行，我们都会查看沿着访问的节点遇到的字母序列。 游走的值定义为沿该序列的任何单个字母的最大频率。 例如，如果步行生成字符串“abaca”，则最佳字母是“a”，它出现了 3 次，因此值为 3。 

任务是找到具有最大可能值的步行。 如果存在一个循环允许我们无限期地累积某个字母的出现次数，则答案是无界的，我们必须返回 -1。 

输入大小高达 300,000 个节点和边。 这立即排除了任何枚举路径或执行指数探索的方法。 即使 O(n²) 在实践中也太大了，所以我们被迫采用线性或接近线性的图遍历策略。 

当图形包含有向循环时，会出现微妙的边缘情况。 如果该循环是可达的并且至少包含一个贡献特定字母的节点，那么通过无限循环，我们可以无限制地增加该字母的计数。 例如，如果节点 1 → 2 → 3 → 1 形成一个循环并且所有节点都有字母“a”，则答案为 -1。 一个简单的 DFS 会跟踪最佳路径总和而不检测重访，这会错误地将循环视为有限的并产生有界答案。 

另一个问题是，即使存在循环，也并非所有循环都意味着无穷大。 如果存在循环，但我们正在计算循环中不存在的字母，则循环无助于增加该字母的频率。 正确的推理取决于跟踪特定于字母的积累，而不仅仅是可达性。 

## 方法

 暴力策略将尝试探索图中的所有路径并计算沿每条路径的字母频率。 人们可以想象从每个节点进行 DFS，维护一个 26 长度的频率数组并更新全局最大值。 这对于小图来说在概念上是正确的，但会失败，因为每个节点可能会通过许多路径重新访问，并且循环会创建无限多次游走。 即使我们将自己限制在简单的路径上，有向图中的路径数量也可以呈指数级增长。 

关键的见解是扭转观点。 我们没有考虑路径，而是将其视为 DAG 上的最长路径问题，但有一点不同：我们需要 26 个独立的动态程序，每个字母一个。 对于每个字母 c，我们想要计算 c 沿着以每个节点结束的任何路径出现的最大次数。 

如果图表没有循环，这将很简单。 我们可以对图进行拓扑排序并放松转换：对于每条边 u → v，我们向前传播最佳值。 循环的存在打破了这一点，但我们可以使用卡恩算法检测循环。 如果我们无法按拓扑顺序处理所有节点，则存在环，并且由于任何环都可以沿着一条路径重复遍历，因此这意味着沿着某个可达环至少有一个字母可能会出现任意大的累积。 在这种情况下，我们返回-1。 

因此，该解决方案成为循环检测和 DAG 结构上的多源动态编程的结合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 路径上的暴力 DFS | 指数| O(n) | 太慢了|
 | 每个字母的拓扑排序 + DP | O(26·(n + m)) | O(26·(n + m)) | O(26·n) | O(26·n) | 已接受 |

 ## 算法演练

 我们独立处理每个字母，并使用拓扑排序上的 DP 来计算最佳可能计数。

1. 构建邻接表并计算所有节点的入度。 这为我们准备了卡恩算法，当图是非循环时，该算法以有效的拓扑顺序处理节点。 
2.初始化DP表`dp[v][c]`表示字母出现的最大次数`c`沿着任何以节点结束的路径`v`。 最初全为零。 如果节点`v`本身有字母`c`，我们设置`dp[v][c] = 1`。 
3. 将所有入度为0的节点压入队列。 这些是任何路径的有效起点。 
4. 重复弹出一个节点`u`从队列中取出 DP 值并将其传播到其邻居`v`。 对于每个字母`c`，我们尝试更新：`dp[v][c] = max(dp[v][c], dp[u][c] + (1 if s[v] == c else 0))`。 

此步骤确保任何最佳路径结束于`u`可以扩展到`v`。 
5. 每当我们放松一条边时，就减少目标节点的入度。 如果变为零，则将其推入队列。 这保持了正确的拓扑处理顺序。 
6. 保留已处理节点的计数器。 如果队列结束后我们还没有处理完所有节点，则存在循环。 在这种情况下，返回 -1，因为可以使用某个循环无限地重复遍历，从而使答案无界。 
7. 处理后，答案是所有dp[v][c]中的最大值。 

DP 背后的推理是 DAG 中的任何有效路径都可以根据拓扑顺序进行分解，并且最优子结构成立，因为将最佳路径扩展到邻居可以保留最优性。 

### 为什么它有效

 核心不变量是当一个节点`u`从队列中弹出，所有路径都以`u`已经充分考虑了DP值。 这是通过拓扑排序保证的：每个传入的边`u`源自已处理过的节点。 

所以，`dp[u][c]`最终确定时`u`已处理，并且所有未来对邻居的更新都正确地建立在完整的子问题解决方案的基础上。 由于每个非循环图都承认拓扑排序，这确保我们按照依赖顺序恰好探索所有有效路径一次。 

如果存在环，卡恩算法无法处理所有节点，这意味着不存在有效的拓扑排序。 这恰好对应于循环的存在，在这个问题中意味着沿着某些路径无限重复的可能性，因此返回 -1 是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    s = input().strip()

    g = [[] for _ in range(n)]
    indeg = [0] * n

    for _ in range(m):
        x, y = map(int, input().split())
        x -= 1
        y -= 1
        g[x].append(y)
        indeg[y] += 1

    dp = [[0] * 26 for _ in range(n)]

    for i in range(n):
        dp[i][ord(s[i]) - 97] = 1

    q = deque([i for i in range(n) if indeg[i] == 0])
    visited = 0

    while q:
        u = q.popleft()
        visited += 1

        for v in g[u]:
            for c in range(26):
                val = dp[u][c] + (1 if ord(s[v]) - 97 == c else 0)
                if val > dp[v][c]:
                    dp[v][c] = val

            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)

    if visited < n:
        print(-1)
        return

    ans = 0
    for i in range(n):
        ans = max(ans, max(dp[i]))
    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案依靠卡恩算法来强制执行非循环处理顺序。 DP 表在边缘松弛期间就地更新，每个状态代表直到该节点的每个字母的最佳可实现频率。 一个常见的实现陷阱是忘记初始化`dp[i][s[i]] = 1`，这会错误地将起始节点视为其自身字母的出现次数为零。 

另一个微妙之处是循环检测：仅仅检查节点是否被重新访问是不够的。 正确的标准是拓扑处理是否完成所有节点。

5 4

```我们仅跟踪字母“a”的关键状态。 

| 步骤| 节点| dp 在节点 (a) | 行动|
 | --- | --- | --- | --- |
 | 初始化| - | [1,0,1,1,1] 每个节点基础 | 从标签初始化 |
 | 流程 1 | 1 | 传播到 2,3 | dp[2]=1, dp[3]=2 |
 | 流程 3 | 3 | dp[3]=2 | dp[3]=2 传播到 4 |
 | 流程 4 | 4 | dp[4]=3 | dp[4]=3 | 传播到 5 |
 | 流程 5 | 5 | dp[5]=3 | dp[5]=3 | 决赛|

 最佳路径沿 1 → 3 → 4 → 5 累积三个“a”字符，确认输出 3。 

### 示例 2

 输入：```
3 3
aaa
1 2
2 3
3 1
```| 步骤| 队列状态| 加工| 检测到循环|
 | --- | --- | --- | --- |
 | 初始化| [1,2,3]可能形成循环| 部分加工| 入度永远不会完全清除 |

 处理后，由于循环1→2→3→1，并未访问到所有节点。算法立即返回-1。 

这证实了当字母可以无限累积时，图中任何可达的循环都会导致无界值。

 ## 边缘情况

 最小节点图测试初始化行为。 对于标记为“a”的单个节点，没有边，因此 DP 应直接返回 1。算法初始化 dp[0][a] = 1 并立即处理它，产生正确的结果。 

全循环图测试无界增长检测。 在三角形循环 1 → 2 → 3 → 1 中，所有节点的入度永远不会降至零，因此卡恩算法处理的节点少于 n 个。 被访问的计数器检测到这一点并返回 -1，正确地表示无限累积潜力。
