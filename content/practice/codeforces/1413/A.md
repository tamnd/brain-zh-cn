 ## 解决方案
 ## 问题理解

 每个测试用例都会给出附加到“门”的偶数长度整数的集合。 这些整数充当系数。 我们必须为每个位置分配另一个非零整数，以便对的加权和恰好抵消为零。 正式来说，对于每个职位$i$，我们选择一个值$b_i$，要求两个序列的点积为零：$\sum a_i b_i = 0$。 每一个选择的$b_i$也必须非零并保持在范围内$[-100, 100]$。 

所以任务不是关于优化或独特性。 它纯粹是构造性的：对于每个输入数组，我们必须输出另一个满足单个线性约束的相同长度的数组。 

约束条件$n \le 100$每个测试用例和$T \le 1000$最多意味着$10^5$values overall. 任何在线性时间内处理每个测试用例的解决方案就足够了。 由于我们只需要构造值，因此即使每个元素的恒定时间策略也足够了。 

一种简单的方法是尝试搜索任意整数赋值$b_i$满足方程，可能通过求解一般线性丢番图方程或尝试随机分配。 这是不必要的，而且可能不稳定。 

当一个人试图分配所有的数据时，就会出现一种天真的推理的微妙失败案例。$b_i = 1$。 那么总和就变成了$\sum a_i$，不能保证为零。 例如，对于输入$[1, 2]$，这给出了$3 \ne 0$，所以它立即失败。 另一个天真的想法可能是设置一个值来取消所有其他值，但这可能会违反边界约束$|b_i| \le 100$。 

关键的困难是同时满足非零约束并保持较小的值，同时强制执行精确取消。 

## 方法

 蛮力的想法是将值分配给$b_1, \dots, b_n$一项一项地检查我们是否可以完成剩余的值以满足线性方程。 这变成了在一个大致大小的空间中的搜索$200^n$，即使对于$n = 10$。 

一种更结构化的尝试是将问题视为求解一个线性方程$n$未知数。 这是不确定的，因此存在无限多个解。 挑战不在于存在，而在于找到具有小整数值且没有零的解决方案。 

关键的观察是$n$是均匀的。 这使我们能够在本地而不是全局配对索引并强制取消。 我们不是求解所有变量的一个方程，而是在每一对中构造零贡献。 如果我们能够确保每对独立贡献为零，则整个总和将自动变为零。 

难度降低为每对的构建$(a_i, a_j)$, 两个非零整数$(b_i, b_j)$这样：$$a_i b_i + a_j b_j = 0$$这总是可以通过选择$b_i = a_j$和$b_j = -a_i$。 这直接取消，因为：$$a_i a_j + a_j (-a_i) = 0$$这种结构尊重所有限制，因为$|a_i|, |a_j| \le 100$， 所以$b_i$和$b_j$也保持在界限内并且非零。

 | ---| ---| ---| ---|
 | 暴力搜索 | 指数| O(n) | 太慢了 |
 | 配对构建| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们独立处理每个测试用例。 

1.读取数组$a$长度$n$。 目标是构造一个匹配数组$b$。 
2. 以两个位置为一步遍历数组，考虑对$(a_{2k}, a_{2k+1})$。 我们对元素进行分组的原因是每对元素将独立地满足零和约束。 
3. 对于每一对，分配$b_{2k} = a_{2k+1}$和$b_{2k+1} = -a_{2k}$。 这确保了该对对总和的贡献恰好为零。 
4. 输出构造好的数组。 

正确性取决于每个索引在成对中仅使用一次的事实，因此没有剩余元素保持未配对。 

### 为什么它有效

 每对贡献：$$a_{2k} b_{2k} + a_{2k+1} b_{2k+1} = a_{2k} a_{2k+1} + a_{2k+1} (-a_{2k}) = 0$$由于总和是成对零的和，因此全局和为零。 该结构从未引入零值$b$，并且值保持在界限内，因为它们直接取自输入数组，该数组的绝对值以 100 为界。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    out = []
    
    for _ in range(T):
        n = int(input())
        a = list(map(int, input().split()))
        
        b = [0] * n
        
        for i in range(0, n, 2):
            b[i] = a[i + 1]
            b[i + 1] = -a[i]
        
        out.append(" ".join(map(str, b)))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案读取每个测试用例并直接构建输出数组。 循环增加 2，保证安全访问对，因为$n$甚至得到保证。 每次分配都是恒定时间，因此整个构造是线性的。 

唯一微妙的一点是确保符号正确：交换和求反是必不可少的。 任何其他没有符号翻转的排列都会破坏取消属性。

 ## 边缘情况

 一个关键的边缘情况是当值具有很大的幅度但符号相反时。 例如，$a = [100, -100]$。 建设产生$b = [-100, -100]$。 贡献变为$100 \cdot (-100) + (-100)\cdot(-100) = -10000 + 10000 = 0$，因此即使迹象混杂，取消仍然有效。 

另一种情况是当所有值都相等时，例如$a = [7, 7, 7, 7]$。 该算法将它们配对为$(7,7)$两次，产生$(7,-7)$在每一对中。 每对独立抵消，因此不会发生交叉干扰。 

最后，当交替的符号出现时$[1, -1, 1, -1]$，该方法仍然有效，因为它从不依赖于全局结构，只依赖于成对取消。
