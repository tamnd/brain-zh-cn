 ## 解决方案
 ## 问题理解

 我们得到了一个集合$n$带标签的图块，其中每个图块带有一对整数$(a_i, b_i)$。 我们的任务是计算有多少种方法可以对这些图块进行重新排序，以便生成的序列可以避免两种非常具体的故障模式。 

如果在重新排序之后，第一坐标的序列不递减或者第二坐标的序列不递减，则重新排列的序列被认为是坏的。 如果两个坐标序列都不是按非降序排序的，则该序列是好的。 

所以我们不会检查一种固定的顺序。 相反，我们考虑索引的所有排列$1 \ldots n$，应用每个排列对对重新排序，并计算有多少个结果序列是好的。 

困难在于，“坏”不是局部结构，而是某一维度上的全局单调性。 序列可能因不同的原因而变得糟糕，具体取决于所有元素之间的联系和排序如何相互作用。 

约束条件$n \le 3 \cdot 10^5$排除任何明确检查排列的方法。 甚至$O(n^2)$方法太慢。 该解决方案必须依赖于排序结构和对点的等价类的组合计数。 

当许多对共享相同的第一或第二坐标时，会出现微妙的边缘情况。 例如，如果所有$a_i$相等，则每次排列都会使第一个序列非递减，因此答案必定为零。 仅检查严格排序而不是非递减排序的幼稚方法会错误地将其视为部分安全。 

另一个棘手的情况是所有对都相同。 那么两个坐标序列总是非递减的，所以每个排列都是不好的，答案又是零。 

## 方法

 蛮力的想法很简单：尝试索引的每个排列，构造结果序列，并检查其第一个坐标是否不递减或第二个坐标是否不递减。 这是正确的，因为它直接遵循定义。 然而，排列的数量是$n!$，即使对于$n = 10$。 检查步骤本身是$O(n)$，导致总体$O(n \cdot n!)$复杂性，这是完全不可行的。 

关键的观察结果是，“按第一或第二坐标排序”的条件仅取决于投影到一个轴上时元素的相对顺序。 如果我们对所有对进行排序$a_i$，我们公开了一个结构，其中违反第一个条件对应于该顺序的反转。 同样，排序依据$b_i$暴露第二个条件的结构。 

与其直接计算好的排列，不如计算所有排列并减去那些不好的排列更容易。 如果排列按以下顺序排序，则排列是不好的$a$或排序依据$b$。 我们还必须处理重叠：按两者排序的排列会被计算两次，并且必须进行更正。 

这将问题简化为计算由排序引起的两个全阶的线性扩展$a$并由$b$。 重叠结构是通过对相同的对进行分组并使用由相等值形成的块上的组合来控制的。 一旦分组，有效排列的数量取决于组大小的阶乘和两个单调排列的仔细减法。 

最终的结构分解为计数排列，同时确保我们同时避免两种单调排序，这是通过对两个排序配置进行包含-排除来实现的。

 | ---| ---| ---| ---|
 | 蛮力 |$O(n \cdot n!)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们通过分离排列可能变得糟糕的两种方式来构建解决方案，然后小心地将它们从完整的集合中删除。 

1. 按第一个坐标对对进行排序$a_i$。 这给出了一个规范的排序，其中任何保持该顺序的排列都是“坏的”$a$”。
 2. 按第二个坐标对对进行排序$b_i$。 这同样定义了“坏的排列”的集合$b$”。
 3. 计算有多少种排列产生了按以下顺序排序的序列$a$。 这只有在连接时才有可能$a$允许在相等的组内重新排列，因此这种排列的数量是相同频率的阶乘的乘积$a$-按两个坐标分组后的块。 
4. 类似地计算按以下顺序排序的排列$b$，再次考虑相同的重数$b$- 块。 
5. 计算同时由两者排序的排列$a$和$b$。 当相同的对被分组并且序列遵循两个排序顺序时，这种情况就会发生，这通常会减少到对相同的分组进行分组$(a_i, b_i)$对。 
6. 应用包含-排除：$$\text{answer} = n! - (\text{sorted by } a + \text{sorted by } b - \text{sorted by both})$$减法确保我们一次性删除所有不良排列。 

### 为什么它有效

 核心不变量是对的多重集的任何排列都必须恰好落入以下四个类别之一：$a$仅，排序依据$b$仅、按两者排序或均不排序。 前三类恰恰是不良案例或它们的重叠。 由于这些类别是由全序约束定义的，因此它们的计数仅取决于投影下相等元素的频率结构。 这些结构化集合的包含-排除保证了不会重复计算或遗漏任何排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

def solve():
    n = int(input())
    a = []
    b = []
    pairs = []
    
    for _ in range(n):
        x, y = map(int, input().split())
        a.append(x)
        b.append(y)
        pairs.append((x, y))
    
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    
    def count_sorted_by(key):
        arr = sorted(pairs, key=key)
        res = 1
        i = 0
        while i < n:
            j = i
            while j < n and key(arr[j]) == key(arr[i]):
                j += 1
            res = res * fact[j - i] % MOD
            i = j
        return res
    
    total = fact[n]
    
    by_a = count_sorted_by(lambda x: x[0])
    by_b = count_sorted_by(lambda x: x[1])
    
    both = 1
    arr = sorted(pairs)
    i = 0
    while i < n:
        j = i
        while j < n and arr[j] == arr[i]:
            j += 1
        both = both * fact[j - i] % MOD
        i = j
    
    ans = (total - by_a - by_b + both) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```该代码预先计算阶乘，以便快速计算相同组内的排列。 功能`count_sorted_by`按坐标排序后对元素进行分组，并乘以块大小的阶乘，这反映了保持单调性的内部重新排列。 

最后的包含-排除步骤通过减去两种类型的不良排序并恢复它们的交集来构造良好排列的数量。 

一个微妙的实现细节是，在计算交集情况时，相等分组必须使用完整的对比较。 仅使用一个坐标会导致重叠计数过多。 

## 工作示例

 ### 示例 1

 输入：```
3
1 1
2 2
3 1
```我们计算阶乘：$3! = 6$。 

排序依据$a$给出每个组的大小为 1，所以$by\_a = 1$。 

排序依据$b$形成一种结构，其中值不会严格无间断地增加，再次导致$by\_b = 1$。 

相同的对都是不同的，所以$both = 1$。 

| 数量 | 价值|
 | ---| ---|
 | 总计 | 6 |
 | by_a | 1 |

 | 两者 | 1 |

 回答：$$6 - 1 - 1 + 1 = 5$$该迹线显示了大多数排列的良好程度，仅排除了结构化单调排列。

 ## 边缘情况

 完全一致的序列，例如$(1,1)$重复$n$times 迫使每个排列都变得不好，因为两个坐标序列保持不变，因此不递减。 该算法通过两个投影中的阶乘分组来处理此问题，使所有计数相等并在包含排除后产生零。 

两个坐标中严格递增的序列会产生相反的极端。 除恒等之外的每个排列都至少打破一个顺序，因此大多数排列都是好的。 按坐标排序的计数会缩减为 1，并且包含-排除仅正确减去两个单调排列，而不会过度计数。
