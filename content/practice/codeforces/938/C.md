 ## 解决方案

 ## 问题理解

 问题不是要求我们直接构造一个矩阵，而是要求我们在滑动窗口限制下推理出二值网格的最佳填充属性。 

我们想象一个$n \times n$网格充满了零和一。 该约束表明，如果我们采取任何连续的$m \times m$在该网格内的正方形中，它必须至少包含一个零。 所以我们被禁止创建$m \times m$全 1 会阻塞网格中的任何位置。 

对于固定对$(n, m)$，在所有有效网格中，存在最大可能数量。 该值仅取决于有多少不相交的结构$m \times m$可以通过策略性地放置零来“阻止”区域。 任务是相反的：我们给出了一个期望的答案值$x_i$，并且我们必须构造任意对$(n_i, m_i)$使得 1 的最佳数量恰好等于$x_i$。 

就测试数量而言，限制很小，但数量本身却高达$10^9$。 这立即排除了任何模拟矩阵的尝试，甚至排除了通过枚举进行推理的可能性$n, m$。 该解决方案必须依赖于对答案如何作为函数的表现的封闭式理解$n$和$m$，然后反转该函数。 

天真的方法会尝试小事$n, m$对，通过网格上的贪婪平铺或 DP 计算最大数量，并匹配目标$x$。 这在两个方面是失败的。 首先，计算单个的答案$(n, m)$对本身很昂贵，因为它取决于重叠的全局结构$m \times m$视窗。 其次，即使速度很快，搜索空间$n, m \le 10^9$太大了。 

更微妙的失败来自于以简单的方式假设任一参数的答案都是单调的。 例如，固定$m$并不断增加$n$不简单地线性缩放答案，因为禁止子矩阵之间的重叠会产生边界效应。 

关键的困难在于答案函数是分段线性的$n$一次$m$是固定的，反演需要了解其斜率结构。 

## 方法

 蛮力视角首先想象对于每一对$(n, m)$，我们尝试尽可能密集地放置，同时确保每个$m \times m$块至少包含一个零。 直接模拟会尝试贪婪地放置并在满时回溯$m \times m$块变成全1。 即使我们限制自己检查整个网格的有效性，我们仍然需要检查所有$O(n^2)$窗户，每个窗户的成本$O(m^2)$，导致$O(n^2 m^2)$每个配置，这是完全不可行的。 

结构洞察就是翻转观点。 我们不再考虑禁止的全一正方形，而是考虑零如何“覆盖”所有$m \times m$子矩阵。 每个零恰好影响一组$m \times m$包含它的正方形。 最佳结构最终形成周期性平铺：零充当带间距的网格$m$，确保每一个$m \times m$区域至少与一个零相交。 一旦该结构达到最佳状态，剩余的结构就会简单地填充所有未覆盖的单元格。 

这导致了最大数量的简单公式。 如果我们划分$n \times n$网格成大小块$m \times m$，最坏情况的最佳排列的行为就像以周期性方式为每个此类块放置一个零。 所需的零数大约为$\lceil \frac{n}{m} \rceil^2$，并且每个零“声明”除了执行覆盖范围之外没有其他结构。 于是答案就变成了：$$\text{ones} = n^2 - \lceil n/m \rceil^2$$精确的推导取决于观察到每个块一个零在最佳平铺结构中既是必要的又是充分的，并且任何更密集的零填充不会改善约束，而只会不必要地减少约束。 

现在反转问题就清楚了。 我们被给予$x = n^2 - k^2$对于某个整数$k = \lceil n/m \rceil$。 我们需要构造任意对$(n, m)$使得这成立。 这减少了寻找整数的过程$n, k$和$n^2 - k^2 = x$， IE。$(n-k)(n+k) = x$，然后选择$m$符合$k = \lceil n/m \rceil$。 一个简单且始终有效的构造是选择$n = k$仅当$x = 0$，以及其他因素$x$作为两个彼此接近的整数来保持$n$积分并确保$m = n/k$行为正确。 

一个方便的建设性技巧是设置：$$n = \left\lfloor \frac{x + 1}{2} \right\rfloor + 1, \quad k = n - 1$$这确保了$n^2 - k^2 = 2n - 1$，覆盖所有奇数，然后稍作调整以表示一般$x$通过选择适当的因子对。 

最后的观察是，我们只需要每个有效的表示$x$，并非所有解决方案的完整表征。

 ## 算法演练

 构建依赖于表达$x$作为两个平方之差$n^2 - k^2$，然后导出有效的$m$从结构解释$k = \lceil n/m \rceil$。 

1.处理小案$x = 0$。 我们设定$n = 1, m = 1$，这会产生一个单单元格网格，在不违反条件的情况下不能放置任何单元格。 这与所需的答案完全匹配。 
2. 对于$x > 0$,构造整数$n$和$k$这样$n^2 - k^2 = x$。 这是通过选择分解来实现的$x$进入$(n-k)(n+k)$。 我们选择因子，以便两个结果值都是整数并且$n > k$。 
3. 计算$n = \frac{a + b}{2}$和$k = \frac{b - a}{2}$， 在哪里$a \cdot b = x$。 这确保了平方差恒等式准确成立。 
4. 设置$m$以便$\lceil n/m \rceil = k$。 满足这一点的直接方法是选择$m = \left\lfloor \frac{n}{k} \right\rfloor$，这保证了上限条件匹配$k$当使用有效因子对仔细构建时。 
5、输出$(n, m)$。 

### 为什么它有效

 关键的不变量是最佳网格值仅取决于有多少$m \times m$覆盖区域需要在每个子方格中强制为零。 该数量减少为单个整数参数$k = \lceil n/m \rceil$，目标函数变成平方差$n^2 - k^2$。 通过构建$n$和$k$通过因式分解$x$，我们保证最优值与目标完全匹配，并且导出的$m$保留所需的上限关系。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x = int(input())
        
        if x == 0:
            print(1, 1)
            continue
        
        # find a factorization x = a * b with same parity (to form n, k)
        a = 1
        b = x
        for i in range(1, int(x**0.5) + 1):
            if x % i == 0:
                a, b = i, x // i
                # ensure correct parity for (a + b) / 2 integer n
                if (a + b) % 2 == 0:
                    break
        
        # construct n, k from difference of squares
        n = (a + b) // 2
        k = (b - a) // 2
        
        # ensure k > 0
        if k == 0:
            n += 1
            k = 1
        
        # choose m so that ceil(n/m) = k
        # a safe choice is m = n // k
        m = n // k
        if m == 0:
            m = 1
        
        print(n, m)

if __name__ == "__main__":
    solve()
```该代码遵循平方差构造。 它首先处理退化的情况$x = 0$。 对于积极的$x$，它搜索除数对$(a, b)$并尝试确保正确的奇偶校验，以便$n = (a+b)/2$和$k = (b-a)/2$是整数。 

调整时$k = 0$防止塌陷成无效结构$x$是具有简并因子对的完全平方。 最后，$m$被选为商$n // k$，它强制执行之间的预期缩放关系$n$以及所需覆盖块的数量。 

微妙的一点是确保$k$对应有效数量$m \times m$覆盖群体； 这就是为什么构建依赖于具有匹配奇偶性的因子对。

 ## 边缘情况

 零情况是唯一真正退化的配置。 什么时候$x = 0$， 任何$n > 1$和$m > 1$仍然允许至少一个有效的放置，除非构造完全受到约束，因此最安全的一致表示是最小网格$1 \times 1$，这很容易迫使答案为零。 

另一个微妙的情况是当$x$是一个完美的正方形。 朴素的因素分裂可能会产生$a = b$，导致$k = 0$，这打破了解释$k = \lceil n/m \rceil$。 该算法通过调整显式地修复了这个问题$n$向上以确保非零$k$，恢复代数分解和网格结构之间的有效映射。
