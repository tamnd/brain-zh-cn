 ## 解决方案
 ## 问题理解

 我们得到一个整数集合，每个整数都以标准十进制形式编写。 任务是查看每个数字，仅提取其第一个非零数字，并计算从 0 到 9 的每个数字在整个集合中作为前导数字出现的频率。 输出本质上是前导数字的频率分布。 

思考这个问题的一个有用方法是，每个数字都被简化为一个标签，即它的最高有效数字，并且我们被要求在数据集中聚合这些标签。 一旦识别出前导数字，数字的内部结构（例如尾随数字或什至超出第一位数字的大小）就不再重要。 

如果输入大小达到典型的竞争性编程限制，例如最多 10^5 或更多数字，那么任何尝试在嵌套循环中逐位处理数字或低效执行重复转换的解决方案仍然可以，只要每个数字在 O（数字长度）内处理即可。 由于每个数字的长度受到其十进制表示形式的限制，因此每个数字的线性扫描就足够了，并且可以在总输入大小中得出整体线性时间解决方案。 

一些边缘情况很容易处理不当。 像这样的数字`7`很简单，但是像这样的数字`1000`必须对数字做出贡献`1`， 不是`0`。 如果允许负数，粗心的实现可能会意外地对待`-3`作为前导数字`-`，这是不正确的； 我们必须始终跳过标志。 如果号码是`0`，前导数字是`0`，这也是一个有效的频率桶，不应被忽略。 例如，给定输入`0 0 10`，正确的输出将反映两个零和一个一，因为`10`贡献领先数字`1`。 

## 方法

 一种强力解释是将每个数字视为整数并重复除以 10，直到只剩下一位数字。 对于每个数字，这需要 O(d) 时间，其中 d 是位数。 对于 n 个数字，这会产生 O（总位数），这在实际意义上已经是最佳的，但它可能涉及重复的整数除法运算以及对负数和零的仔细处理。 

另一种简单但稍微干净的暴力方法是将每个数字转换为字符串并直接访问其第一个字符。 这完全避免了算术并使逻辑更加透明。 但是，如果不小心实现，重复的字符串切片或不必要的解析开销仍然可能会在非常大的输入中稍微减慢速度。 

关键的观察是，我们不需要解释超出规范化字符串形式的第一个字符的数字。 读取输入后，提取第一个非符号字符就足够了。 这将问题简化为对输入的单次传递，其中每个元素恰好为大小为 10 的频率数组贡献一个增量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每个数字的重复除法 | O(n·d) | O(1) | O(1) | 已接受 |
 | 字符串第一位数字提取 | O(n·d) | O(1) | O(1) | 已接受 |

 这两种方法在输入大小上都是有效的线性的，但基于字符串的方法通常是最简单且最不容易出错的。 

## 算法演练

 1. 将所有数字读取为字符串而不是整数，因为字符串形式保留前导数字而不进行任何算术操作。 这可以避免溢出或符号处理问题。 
2.初始化一个数组`cnt`大小为 10，全为零。 每个索引对应0到9的一个数字，我们将在那里累积计数。 
3. 对于每个数字字符串，从头开始扫描，直到找到不是减号的字符。 第一个这样的字符是数字的前导数字。 此步骤很重要，因为负数可能包含前导`-`，必须忽略它。 
4. 将第一个数字字符转换为整数并递增`cnt[digit]`除 1。这会直接将数字分类到其前导数字桶中。 
5. 处理完所有数字后，按数字 0 到数字 9 的顺序输出计数。 

### 为什么它有效

 每个数字恰好贡献一个前导数字，并且该数字由其十进制表示形式中的第一个非符号字符唯一确定。 该算法永远不会修改或重新解释超出该点的数字，因此输入元素和频率数组中的增量之间存在一对一的映射。 由于每个元素都被独立且恰好处理一次，因此累积计数既完整又正确。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    cnt = [0] * 10

    for _ in range(n):
        s = input().strip()
        i = 0
        while i < len(s) and s[i] == '-':
            i += 1
        if i < len(s):
            d = ord(s[i]) - ord('0')
            cnt[d] += 1

    print(*cnt)

if __name__ == "__main__":
    solve()
```该解决方案将每个数字作为字符串读取，并避免除了提取第一个有意义的数字之外的任何数字转换。 循环跳过`-`如果存在负值，则字符可确保正确性，即使此问题的许多实例仅使用非负整数。 

频率阵列`cnt`大小固定，因此更新时间恒定。 最终的打印语句在一行中输出完整的分布。 

一个微妙的点是我们没有显式地去除前导零。 这是故意的，因为像这样的数字`"007"`仍然有领先数字`0`，第一个非符号字符正确地捕获了它。

 ## 边缘情况

 对于完全由零组成的输入，例如：```
3
0
0
0
```该算法处理每个字符串，找到`'0'`作为第一个非符号字符，并递增`cnt[0]`三次。 输出正确地变成一个向量，索引 0 处为 3，其他位置处为零。 

对于负个位数输入，例如：```
3
-1
-9
-3
```每个字符串都会跳过`-`并立即读取该数字，分别产生 1、9 和 3 的计数。 该符号从不参与分类，因此不会访问无效索引。 

对于带有前导零的数字，例如：```
3
007
0002
09
```第一个非符号字符始终是`'0'`，因此所有贡献都正确地转到数字 0。该算法不会压缩或标准化数字，这确保了前导零信息完全按照要求保留。
