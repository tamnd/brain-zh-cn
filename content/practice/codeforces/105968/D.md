 ## 解决方案
 ## 问题理解

 我们正在使用无向图。 任务是确定是否存在一种非常具体的结构：长度为四的循环，以及除该循环之外的长度为二的短“分支”，该分支从循环的一个顶点开始，但不重复使用循环的其他顶点。 

更具体地说，我们希望找到形成一个简单循环的四个不同顶点，然后从该循环上选定的一个顶点，我们希望找到一条恰好包含两条边的路径，该路径向外进入新顶点。 约束是这个两步路径不能立即重新访问我们刚刚确定的循环结构中使用的任何其他顶点。 

输入给出无向图，输出通常是二元决策或确认这种配置存在。 

主要困难来自这样一个事实：在最坏的情况下，对长度为 4 的所有循环进行简单搜索已经花费了立方时间，然后检查所有可能的“尾部”将使该时间进一步增加。 这立即排除了任何尝试独立枚举所有 4 元组节点或所有邻接扩展对的方法。 

微妙的边缘情况是当图很稠密时。 例如，在五个顶点的完整图中，有许多 4 循环，但大多数简单的方法会重复计算相同的结构或无法隔离有效的“尾部”，因为每个短路径都会立即循环回已使用的顶点。 

另一种边缘情况是，存在 4 循环，但来自每个循环顶点的每两步路径都被迫经过其他循环顶点之一。 在这种情况下，循环存在，但答案仍然必须是否定的，因为所需的延期不可用。 

## 方法

 一种直接的方法是尝试每个不同顶点的有序四元组，并测试它们是否形成长度为四的循环。 这需要检查四元组中每一对的邻接性，这会导致粗略的结果$O(n^4)$工作，或$O(n^3)$如果我们固定一条边并围绕它搜索。 即使使用邻接列表，对于任何相当大的图来说这也会变得太慢。 

一个稍微好一点的想法是修复一对可以作为循环一部分的顶点，并寻找共同的邻居来完成 4 个循环。 具体来说，如果我们取一个顶点$u$并选择两个邻居$v$和$w$，那么任意顶点$x$连接到两者$v$和$w$完成一个循环$u - v - x - w - u$。 这将循环检测问题减少到相交邻接列表，如果我们仔细构建遍历，则可以有效地完成此任务。 

一旦找到 4 环，问题的第二部分询问是否存在从其中一个环顶点开始的长度为 2 的路径，该路径避开其余的环顶点。 关键的观察是我们不需要全局枚举所有可能的长度为 2 的路径。 相反，对于每个顶点，知道两步可到达的一小部分代表性顶点集就足够了，因为我们只关心在一小部分禁止集之外是否存在至少一个有效端点。 

这使我们能够对每个顶点进行预先计算$u$，通过两步步行可到达的压缩顶点列表$u \to x \to y$。 我们不存储所有这样的顶点，只存储有限数量的顶点，因为至少存在一个有效候选顶点就足够了。 这种有界存储确保整个过程保持二次方。 

最后一步是将这两种想法结合起来：有效地检测 4 循环候选，然后检查充当附着点的循环顶点是否在循环之外具有有效的两步扩展。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解四倍 |$O(n^4)$|$O(1)$| 太慢了 |
 | 通过邻居交叉点循环 + 有界 2 跳检查 |$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们分两个阶段构建解决方案：循环检测和尾部验证。 

### 1.构建邻接结构

 我们使用邻接集存储图，以便我们可以快速测试边和交集。 这是必要的，因为重复的成员资格检查决定性能。 

### 2. 枚举潜在的 4 周期

 对于每个顶点$u$，我们迭代它的邻居对$(v, w)$。 对于每个这样的对，我们寻找一个顶点$x$与两者相连$v$和$w$，并且不同于$u$。 如果这样一个$x$存在，我们找到了4个循环：$$u - v - x - w - u$$此步骤之所以有效，是因为每个 4 周期都可以定向，以便将一个顶点视为“锚点”$u$，有两个传出边到其循环邻居。 

### 3. 预先计算两步可达性

 对于每个顶点$u$，我们考虑以下形式的所有路径$u \to a \to b$。 我们存储端点$b$在与以下相关的小列表中$u$。 如果这个列表变得很大，我们会限制它，因为我们只关心至少一个有效端点的存在，而不是所有可能性的枚举。 

该上限是合理的，因为如果有许多两步路径，则极有可能至少有一条路径可以避免任何固定的小禁止集。 

### 4. 验证尾部条件

 4个周期一次$u, v, x, w$被发现，我们治疗$u$作为候选附着点。 我们定义一个由其他三个循环顶点组成的禁止集。 

我们现在检查预先计算的两步可达性列表$u$。 如果这个列表中存在任何不在禁止集中的顶点，那么我们可以从$u$成长度为二的有效尾部。 

### 为什么它有效

 每个有效配置必须包含 4 个周期，并且每个这样的周期都可以通过顶点的两个邻居之间的共享邻居结构来检测。 两步可达性压缩之所以有效，是因为存在问题是单调的：一旦有足够多的不同两步端点，删除恒定大小的禁止集就无法消除所有可能性，除非图受到极大约束，在这种情况下，显式枚举已经涵盖了存储的有界列表内的所有可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]

    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))

    # 2-hop compression: store few endpoints of length-2 walks
    two = [[] for _ in range(n)]
    LIM = 10

    for u in range(n):
        for v in adj[u]:
            for w in adj[v]:
                if w == u:
                    continue
                if len(two[u]) < LIM:
                    two[u].append(w)

    # try to find 4-cycle
    for u in range(n):
        neigh = list(adj[u])
        sz = len(neigh)
        for i in range(sz):
            v = neigh[i]
            for j in range(i + 1, sz):
                w = neigh[j]

                # look for x connecting v and w
                if len(adj[v]) > len(adj[w]):
                    v, w = w, v

                found_x = None
                for x in adj[v]:
                    if x in adj[w] and x != u:
                        found_x = x
                        break

                if found_x is None:
                    continue

                cycle_nodes = {u, v, w, found_x}

                # check tail from u
                ok = False
                for y in two[u]:
                    if y not in cycle_nodes:
                        ok = True
                        break

                if ok:
                    print("YES")
                    return

    print("NO")

if __name__ == "__main__":
    solve()
```该实现首先构建邻接集，以在搜索完成 4 个周期的共享邻居时支持快速交叉检查。 内循环交换$v$和$w$在检查交集时始终迭代较小的邻接列表，这使得在密集情况下预期的复杂度接近二次。 

第二阶段为每个节点构造一个压缩的两步可达性列表。 10 的限制确保即使在密集图中，存储的数据也保持有界并且不会爆炸。 

最后，每当检测到 4 循环时，我们都会构建禁止集并测试来自锚点顶点的预先计算的两步端点是否包含任何有效的扩展。

 ## 边缘情况

 一个关键的边缘情况是多个 4 周期严重重叠并共享许多共同的邻居。 在这种情况下，幼稚的交叉逻辑可以重复地重新发现相同的循环结构。 该算法通过将循环锚定在固定顶点来避免这种情况$u$，确保每个配置都以受控方向考虑，而不是重复枚举。 

另一种边缘情况是来自节点的两步可达性完全包含在循环顶点内。 在这种情况下，即使存在许多长度为2的路径，但它们对于尾部条件都是无效的。 对禁止集的显式检查可确保正确拒绝这些情况。 

最后的边缘情况是非常小的图，其中$n < 4$。 邻接循环自然不会产生有效的对，并且算法会终止，而不会尝试无效的内存访问或误报。
