 ## 解决方案
 ## 问题理解

 两个物体在数轴上严格向右移动。 人类从机器人前方一米处开始匀速移动`v1`米每秒，意思是之后`t`人类精确前进的秒数`t · v1`超出其初始偏移米。 

机器人起步时比人类落后一米，但速度并不恒定。 第一秒跑 1 米，第二秒跑 2 米，以此类推，但每秒的速度上限为`v2`。 一旦机器人达到速度`v2`，它继续精确地移动`v2`米每秒每秒。 

我们被要求找到最小的整数时间`t`这样之后`t`整整几秒，机器人距起点的总距离严格大于人类的位置。 

约束条件允许`v2`最多 2 · 10^9，因此任何解决方案都必须避免逐秒模拟。 在最坏的情况下，随着时间的推移线性扫描将需要多达数十亿次迭代，这是不可行的。 

一个微妙的问题是从加速到限制速度的转变。 忽略上限或在达到上限时错误处理精确秒数的幼稚方法将产生错误的答案。 另一个常见的陷阱是差一推理：该问题明确要求在整数秒后严格超车，而不是在一秒内。 

例如，如果假设进行连续的相等性检查而不是离散的步骤，那么人们可能会得出结论，会议时间就足够了。 但该语句严格要求整数倍的位置更大，因此相等不计算在内。 

## 方法

 直接模拟每秒跟踪两个位置。 机器人的速度每秒增加 1，直到击中`v2`，之后保持不变。 每一步都会更新两个位置并检查机器人是否超过了人类。 

这种方法是正确的，但太慢了，因为机器人可能需要`v2`几秒钟才能达到全速，并且`v2`本身可以大到 2 · 10^9。 更糟糕的是，我们可能需要在超车时刻之前进行模拟，从而使最坏情况下的运行时间与答案呈线性关系。 

关键的观察结果是机器人的运动自然地分为两种状态。 在第一种情况下，由于速度线性增加，因此距离呈三角形增长。 在第二种情况下，其距离随斜率线性增长`v2`。 人总是随着斜率线性成长`v1`。 自从`v2 > v1`，一旦机器人达到全速，相对间隙就会线性变化，并且最终必须恰好一次过零。 

这意味着我们可以在任何时间以封闭形式计算两个位置函数`t`。 然后我们需要找到最小的整数`t`这样`robot(t) > human(t)`。 谓词在时间上是单调的：一旦机器人超车，它就会永远保持领先，因为它的有效斜率永远不会小于人类的斜率。 这允许随着时间的推移进行二分搜索。 

唯一剩下的细节是有效计算机器人的距离。 对于时间`t`， 如果`t <= v2`，我们使用总和`1 + 2 + ... + t`。 否则我们对第一个求和`v2`条款，然后添加`(t - v2) · v2`。

 ## 算法演练

 我们定义一个函数来计算双方参与者的位置`t`seconds.

 1. 将人的位置计算为`human(t) = 1 + t · v1`。 1 米的初始偏移量在整个运动过程中保持不变，只有速度有助于增长。 
2. 分两个阶段计算机器人的距离。 如果`t <= v2`，机器人仍在加速，所以它的距离是第一个的总和`t`整数，即`t · (t + 1) / 2`。 这直接来自于速度增加的算术级数。 
3.如果`t > v2`，分割运动。 机器人首先完成完整的三角阶段`v2`, 贡献`v2 · (v2 + 1) / 2`。 之后以匀速移动`v2`为了`(t - v2)`秒，贡献`(t - v2) · v2`。 
4. 定义谓词`f(t)`这是真的，如果`robot(t) > human(t)`。 我们想要最小的`t`这成立。 
5.观察`f(t)`是单调的。 一旦机器人完全领先，其速度优势就确保它永远不会再落后。 
6. 执行二分查找`t`在足够大的范围内，例如达到甚至恒定速度的值`v2`就能保证超车。 安全上限是`2 * 10^18`在最糟糕的理论推理中，但实际上`2 * v2 + 5`就足够了，因为饱和后间隙是线性的。 
7.返回最小的`t`在哪里`f(t)`是真的。 

### 为什么它有效

 机器人的位置函数凸至`v2`由于增量增加，并且随后与斜率成线性关系`v2`。 人的位置是一条有斜度的直线`v1`。 自从`v2 > v1`，当机器人达到上限速度后，机器人和人类位置之间的差异变成具有正斜率的线性函数。 这保证了从非正差异到正差异的单一转换，使谓词在时间上单调并验证二分搜索。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def robot_pos(t, v2):
    if t <= v2:
        return t * (t + 1) // 2
    tri = v2 * (v2 + 1) // 2
    return tri + (t - v2) * v2

def human_pos(t, v1):
    return 1 + t * v1

def ok(t, v1, v2):
    return robot_pos(t, v2) > human_pos(t, v1)

def solve():
    v1, v2 = map(int, input().split())
    
    lo, hi = 0, 1
    while not ok(hi, v1, v2):
        hi *= 2
    
    while lo + 1 < hi:
        mid = (lo + hi) // 2
        if ok(mid, v1, v2):
            hi = mid
        else:
            lo = mid
    
    print(hi)

if __name__ == "__main__":
    solve()
```该实现直接编码机器人的两相距离函数和人类的线性函数。 这`ok`函数是二分搜索中使用的单调谓词。 的指数扩张`hi`确保我们总是找到足够大的搜索间隔而无需猜测上限。 

一个常见的错误是忘记了人类的初始偏移，这会使比较精确地偏移 1 米，并影响早期边缘情况下的最终答案。 另一个微妙的点是使用`>=`而不是`>`; 平等显然是不够的，因为机器人必须严格领先。

 ## 边缘情况

 一个重要的边缘情况是机器人和人类在最终答案之前变得平等。 在第一个样本中，在`t = 4`两个位置完全匹配，但正确答案是`t = 5`。 该算法可以正确处理此问题，因为谓词使用严格的不等式，因此相等不会触发成功。 

另一种边缘情况是在机器人达到最大速度之前发生超车。 例如与`v1 = 2, v2 = 4`，机器人赢了`t = 4`，尽管它仍在加速。 三角和的公式正确地反映了这种情况，因此不需要特殊处理。 

最后的边缘情况是非常大的值`v1`和`v2`。 由于该解决方案仅使用算术和对数搜索，因此它不依赖于模拟深度，并且由于 Python 的任意精度整数，所有中间值都安全地适合 64 位整数。
