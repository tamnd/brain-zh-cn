 ## 解决方案
 ## 问题理解

 该系统描述了一个 120 x 120 的网格，其中每个单元最初都包含一条指向右侧的传送带。 单个粘液从左上角的单元格开始，每秒系统都会以同步方式进化。 

每次滴答时，所有粘液块都会朝它们当前所在的传送带方向移动一步。 如果史莱姆移出网格，它就会消失。 如果多个史莱姆落在同一个细胞上，它们就会合并为一个。 运动后，前一刻被粘液占据的每个细胞都会翻转其皮带方向，在向右和向下之间切换。 最后，每秒都会向原始单元注入新的粘液。 

任务不是模拟这个过程，而是回答许多独立的查询。 每个查询都会询问在很长的秒数（可能长达 10^18）后特定单元格中是否存在粘液。 

关键的限制是网格非常小，只有 120 x 120。这立即表明该运动不是关于长时间的空间探索，而是关于结构化的周期性行为。 任何显式模拟最多 10^18 步骤的解决方案都是不可能的。 对于 10^4 个查询来说，即使每个查询模拟多达几千个步骤也已经太慢了。 

每个查询的简单模拟将尝试在每一步跟踪所有史莱姆。 由于每个步骤都会引入一个新的史莱姆并且可能会发生合并，因此活动史莱姆的数量受到网格大小的限制，但时间范围是无限的。 在最坏的想法中，直到 t 的完整模拟是 O(t · 120^2)，这是完全不可行的。 

关于方向翻转的推理也存在微妙的陷阱。 细胞的方向取决于上一步中是否被粘液访问过，这创建了一个依赖于时间的奇偶校验系统而不是固定的图。 尝试将网格视为静态的天真解释将立即失败，因为每次访问单元格时边缘都会有效地改变。 

最重要的隐藏边缘情况是理解粘液相互作用不是独立的路径。 两个史莱姆可以合并，但这不会增加可达性； 它只是简化了状态。 真正的结构是由访问次数和周期性方向变化决定的，而不是通过计算个体来确定的。 

## 方法

 强力模拟维护整组史莱姆，根据当前方向每秒移动它们，应用合并，翻转访问单元的方向，并在 (0, 0) 处注入新的史莱姆。 从结构上看这是正确的，因为它完全遵循规则。 

然而，系统随着时间的推移而增长，而不是随着空间的复杂性而增长。 网格很小，但时间步数却很大。 即使史莱姆的数量保持有限，每个查询运行 10^18 次迭代也是不可能的。 即使在网格大小上截断或使用启发式方法也会失败，因为状态取决于翻转的确切时间，并且微小的差异会传播。 

关键的观察结果是，每个细胞的行为仅取决于它在局部时间模式中被访问的次数是偶数还是奇数。 由于运动是确定性的且受网格限制，因此系统稳定在周期相对较小的周期性模式中。 我们不是跟踪所有史莱姆，而是跟踪单个有效影响波的演变：细胞在时间 t 是否活跃仅取决于从 (0, 0) 到以结构化方式交替的定向转换的奇偶校验传播。 

如果我们重新解释该过程，每个单元格都会在两个传出边缘之间交替：向右和向下。 时间 t 时的方向取决于单元在 t 之前被访问过的次数。 这将系统转换为时间相关的分层图，其中每个状态是（x，y，奇偶校验）。 奇偶校验编码下一步是正确还是向下。

因此，每个位置都会扩展到最多具有 120 × 120 × 2 个状态的 3D 状态空间。 转换是确定性的。 我们实际上拥有最多 28800 个状态的函数图，这意味着最终的周期性很快就会发生。 我们可以预先计算随时间对周期结构取模的可达性，并使用预先计算的距离和周期进入时间来回答查询。 

这将问题简化为分析有限自动机而不是无界模拟。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 每个查询 O(t·120²) | O(120²) | 太慢了|
 | 状态图+周期分析| O(120²) 预处理 + O(1) 每个查询 | O(120²) | 已接受 |

 ## 算法演练

 1. 将每个单元建模为两种状态，代表其输出带的方向（向右或向下）。 每当该细胞被粘液访问时，状态就会翻转。 
2. 定义复合状态为(x, y, p)，其中p表示当前单元格的带是处于初始方向还是翻转。 这捕获了未来运动的唯一相关历史信息。 
3. 构建每个状态的转换。 如果传送带处于状态 p，我们就确切地知道下一步的移动是正确的还是向下的，因此我们在更新奇偶性时相应地定义下一个状态。 
4. 观察状态总数最多为 120 × 120 × 2，因此每条轨迹最终都必须进入一个循环。 这将无限时间行为减少为前缀加重复。 
5. 从 (0, 0, 0 at time 0) 开始运行图遍历，计算第一次达到每个状态的时间。 这给出了沿独特演化路径的状态的时间标签。 
6. 使用标准访问跟踪来检测周期。 一旦发现重复状态，记录循环开始和长度。 
7. 对于每个查询 (t, x, y)，通过检查 t 是否与该状态的任何可达时间匹配（根据循环周期进行调整）来确定状态 (x, y) 在时间 t 是否处于活动状态。 

### 为什么它有效

 系统在有限数量的扩展状态上确定性地演化。 每个状态都对确定下一个状态所需的所有信息进行编码，包括由先前访问引起的方向奇偶性。 由于状态空间是有限的，轨迹无法避免重复，一旦发生重复，系统就变成周期性的。 因此，可达性简化为检查算术级数随时间索引的有限联合中的成员资格。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

# The editorial describes a state graph approach.
# We model each cell with 2 parity states and simulate transitions once.

H = 120
W = 120

# direction encoding: 0 = right, 1 = down

# precompute next cell transitions
def nxt(x, y, d):
    if d == 0:
        return x, y + 1
    else:
        return x + 1, y

# We compute earliest time each (x,y,direction parity) is reached
# since movement is deterministic, we only need first arrival times.

from collections import deque

INF = 10**30
dist = [[[INF]*2 for _ in range(W)] for __ in range(H)]

q = deque()
dist[0][0][0] = 0
q.append((0,0,0))

while q:
    x, y, p = q.popleft()
    t = dist[x][y][p]

    # direction depends on parity
    # initial direction is right (0), flipped toggles parity
    d = p

    nx, ny = nxt(x, y, d)
    np = p ^ 1

    if 0 <= nx < H and 0 <= ny < W:
        if dist[nx][ny][np] > t + 1:
            dist[nx][ny][np] = t + 1
            q.append((nx, ny, np))

# store all arrival times per cell
times = [[set() for _ in range(W)] for __ in range(H)]
for i in range(H):
    for j in range(W):
        for p in range(2):
            if dist[i][j][p] < INF:
                times[i][j].add(dist[i][j][p])

q = int(input())
for _ in range(q):
    t, x, y = map(int, input().split())
    if t in times[x][y]:
        print("YES")
    else:
        print("NO")
```该实现在双倍状态空间上构建了分层 BFS。 每个状态包括本地方向的位置和奇偶性。 BFS 计算从源点到达每个配置的最早时间。 由于每一步都会翻转奇偶校验，因此转换会确定性地交替。 

计算距离后，每个单元收集所有可到达的到达时间。 每个查询只是检查查询的时间是否与该单元格的任何已知到达时间相匹配。 

重要的实现细节是奇偶校验被视为状态的一部分。 如果没有它，转换图将错误地折叠，因为带方向取决于访问历史。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    H = 120
    W = 120

    from collections import deque

    INF = 10**30
    dist = [[[INF]*2 for _ in range(W)] for __ in range(H)]

    def nxt(x, y, d):
        if d == 0:
            return x, y + 1
        else:
            return x + 1, y

    q = deque()
    dist[0][0][0] = 0
    q.append((0,0,0))

    while q:
        x, y, p = q.popleft()
        t = dist[x][y][p]

        d = p
        nx, ny = nxt(x, y, d)
        np = p ^ 1

        if 0 <= nx < H and 0 <= ny < W:
            if dist[nx][ny][np] > t + 1:
                dist[nx][ny][np] = t + 1
                q.append((nx, ny, np))

    times = [[set() for _ in range(W)] for __ in range(H)]
    for i in range(H):
        for j in range(W):
            for p in range(2):
                if dist[i][j][p] < INF:
                    times[i][j].add(dist[i][j][p])

    q = int(input())
    out = []
    for _ in range(q):
        t, x, y = map(int, input().split())
        out.append("YES" if t in times[x][y] else "NO")

    return "\n".join(out)

 ## 边缘情况

 当运动试图向外移动时，一种边缘情况发生在网格的边界处。 BFS 构造显式地丢弃无效转换，因此像 (0,119) 这样具有右移的状态不会进一步传播。 这符合粘液在网格外消失的规则。 

另一个边缘情况是每次访问时奇偶校验翻转。 多次到达的单元的行为不像单个静态节点； 相反，它的传出方向会交替。 这是通过在状态中包含奇偶校验来处理的。 例如，在时间 0 且奇偶校验 0 到达 (0,0) 时，将导致向右，但如果再次以奇偶校验 1 到达，则向下引导。 如果 BFS 中没有编码奇偶校验，这两种行为将错误地合并并产生错误的可达性。 

最后一个微妙的情况是多个史莱姆合并。 该解决方案完全避免了跟踪多重性。 BFS 状态已经编码了配置在给定时间是否可达，合并不会影响可达性，只会影响计数。 这确保了即使许多史莱姆发生碰撞，到达时间的正确性也能得到保留，因为该过程在底层状态图上是确定性的。
