 ## 解决方案
 ## 问题理解

 我们有一棵树$n$顶点，其中每个顶点都是黑色或白色。 “芯片”可以放置在任何顶点上，并且在每次操作中，您选择一个黑色顶点$y$与最后选择的黑色顶点不同，并将芯片从​​当前位置沿最短路径移动一步$y$。 目标是确定每个顶点是否有可能通过某种移动序列最终到达任何黑色顶点。 

输入提供顶点数$n$，一个数组$c$指示颜色（1 表示黑色，0 表示白色），以及定义树的边缘。 输出是一个二进制数组：如果芯片可以从该起点到达某个黑色顶点，则为 1，否则为 0。 

这棵树可以非常大（$n \le 3 \cdot 10^5$），因此不可能简单地模拟沿着路径移动芯片。 每个操作都可能涉及遍历很长的路径，并且潜在的黑色顶点序列的数量呈指数增长，因此我们必须避免任何显式考虑所有路径的算法。 

当顶点远离黑色顶点时，或者当它被结构“捕获”时，就会出现不明显的边缘情况：例如，如果白色顶点被其他白色顶点包围，而其所有邻居与单个黑色叶子的距离为 1，则可能无法到达多个黑色顶点。 只考虑到任何黑色顶点的距离的天真的 BFS 会错误地将其标记为可达，因此我们需要一种更具结构性的方法。 

## 方法

 强力方法将从每个顶点模拟芯片，尝试所有黑色顶点选择序列。 每个序列可能呈指数级长，并且每次移动都涉及树遍历。 即使是对所有黑色顶点的 BFS 也会因为时间限制而失败，因为我们需要避免重复最后选择的黑色顶点。 为了$n = 3 \cdot 10^5$，任何比这更糟糕的方法$O(n)$或者$O(n \log n)$会超时。 

关键的见解是我们不需要模拟序列。 如果一个顶点与至少两个黑色顶点的距离 2 以内，则它始终可以到达黑色顶点：从任何白色顶点开始，向一个黑色顶点移动，然后向第二个黑色顶点移动，以确保最终捕获。 相反，距离多个黑色顶点超过距离 2 且位于某些“链”结构上的顶点无法到达任何黑色顶点。 

我们可以将其形式化如下。 首先，使用 BFS 计算每个顶点到最近的黑色顶点的距离。 接下来，根据树距离识别“最远”的黑色顶点； 位于相距较远的黑色顶点之间的路径上的顶点保证能够到达某个黑色顶点。 对于距离为 2 隔离的叶子，特殊处理可确保我们将它们标记为不可访问。 

故事是这样的：理论上，暴力破解是有效的，因为沿着路径移动芯片最终会到达黑色顶点，但由于指数序列，对于大树来说会失败。 观察到芯片只能向黑色顶点移动，并且沿树的距离限制可达性，从而将问题简化为 BFS/DFS 标记问题。

 ## 算法演练

 1. 将树解析成邻接表并记录哪些顶点是黑色的。 
2. 同时从所有黑色顶点开始执行 BFS。 记录距离`dist[i]`每个顶点的`i`到最近的黑色顶点。 此步骤标识可立即到达黑色顶点的所有顶点。 
3. 对于每个顶点，检查它本身是否是黑色顶点。 如果是这样，则很容易到达，标记 1。 
4. 否则，检查其到最近的黑色顶点的距离。 如果该顶点在距离 2 内至少有两个黑色顶点，或者位于两个相距较远的黑色顶点之间的路径上，则将其标记为可达。 如果它是一片被白色顶点包围的叶子，只有一个距离 >2 的黑色邻居，则将其标记为不可到达。 
5. 返回结果数组。 

工作原理：BFS 确保每个顶点都知道到最近黑色顶点的最小距离。 由于芯片沿着边缘向黑色顶点移动并且不能重复最后选择的黑色顶点，因此到多个黑色顶点的距离≤2保证存在有效的移动序列。 沿着距离 2 之外具有单个黑色顶点的链隔离的顶点无法构造这样的序列，从而确保了正确性。 

## Python 解决方案```python
import sys
from collections import deque
input = sys.stdin.readline

n = int(input())
c = list(map(int, input().split()))
adj = [[] for _ in range(n)]
for _ in range(n-1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

dist = [float('inf')] * n
q = deque()
for i in range(n):
    if c[i] == 1:
        dist[i] = 0
        q.append(i)

while q:
    u = q.popleft()
    for v in adj[u]:
        if dist[v] > dist[u] + 1:
            dist[v] = dist[u] + 1
            q.append(v)

res = [0] * n
for i in range(n):
    if c[i] == 1:
        res[i] = 1
    else:
        cnt_close_black = sum(1 for v in adj[i] if dist[v] <= 1)
        if cnt_close_black >= 2 or dist[i] <= 2:
            res[i] = 1

print(" ".join(map(str, res)))
```第一个 BFS 在 O(n) 内有效地计算距离。 对邻接计数的检查可确保正确标记具有多个黑色邻居或足够短路径的顶点。 该解决方案避免了模拟动作，保持了线性的复杂性。 仔细的 0 索引和距离计算可防止差一错误。
