 ## 解决方案
 ## 问题理解

 我们得到一个短字符串，其中每个字符出现一次或两次。 任务是对字符进行排列，以便每当一个字母出现两次时，所有这些字母的两次出现之间的间隔都是相同的。 

另一种看待它的方法是，对于每个重复的字母，如果它的位置是$i$和$j$，那么值$j - i$对于出现两次的所有字母必须是相同的常数。 出现一次的字母没有任何限制。 

字符串长度最多为 52，并且最多有 26 个不同的字母，每个字母最多出现两次。 这立即告诉我们，任何尝试所有排列的构造都是不必要的。 甚至$52!$远远超出了可行的限制，但即使是更结构化的蛮力，例如回溯放置，在实践中仍然会呈指数级增长。 

一个关键的观察结果是，唯一有意义的约束是以相等的间距配对重复的字母。 单次出现的字母是自由变量，可以插入到任何地方而不影响约束。 

经常打破天真的想法的边缘情况是重复字母在输入中分散和交错的情况。 例如，在像这样的字符串中`abacbc`，自然配对距离不同，任何解决方案都必须全局重新排序，而不是局部调整配对。 另一个微妙的情况是没有字母出现两次，例如`ac`，其中每个排列都是有效的并且约束完全消失。 

## 方法

 强力解释是尝试字符串的所有排列并检查所有重复字母是否具有相等的距离。 这是正确的，但立即不可行，因为即使长度为 20 也已经产生$20!$排列。 

一旦我们重新解释条件，问题的结构就会变得更简单。 假设我们决定所有重复的字母必须具有形成具有相同间隙的对的位置。 如果我们固定最终的排列，每个重复的字母占据两个位置，其差异是一个常数$d$。 因此，任务变成构建一个字符串，其中每个重复的字母都放置在位置上$(i, i + d)$对于一些固定的$d$。 

我们可以直接构造这样的结构，而不是搜索排列。 由于每个字母最多出现两次，因此我们只需要分配位置对。 我们可以选择一个间距$d$，然后贪婪地将每个重复的字母放入遵守此间距的插槽中。 由于字符串长度较小且重复次数有限，尝试了所有可行的$d$贪婪地追求价值观和填补职位总是成功的。 

大多数解决方案中使用的更简单、更标准的见解甚至更强大：我们不需要明确选择$d$。 我们可以通过将所有第二次出现的情况以一致的顺序相对于第一次出现的统一偏移量来构建答案。 以结构化模式对字母进行排序并分配位置可自动保证相等的间距。 

最简单的构造是将所有出现两次的字符放置在连续的块模式中：第一次出现在一个序列中，第二次出现以固定移位镜像，而单例则任意插入到剩余的槽中。

 | ---| ---| ---| ---|
 | 蛮力排列 | O(n!) | O(n) | 太慢了 |
 | 结构建筑| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 关键思想是按频率对字母进行分组，然后将它们按受控顺序放置，以强制所有重复字母的距离相同。 

1.统计每个字符出现的频率。 我们将角色分为出现一次的角色和出现两次的角色。 这种分类至关重要，因为只有重复的字母才会产生限制。 
2. 将所有出现两次的字母收集到一个列表中并对其进行排序。 排序并不是严格要求正确性的，但它确保了确定性并简化了有关放置的推理。 
3. 为重复的字母构建两个序列：一个序列代表它们第一次出现，另一个序列代表它们第二次出现。 核心思想是，我们将以递增的顺序放置第一次出现的位置，而以移位但对齐的顺序放置第二次出现的位置，以便每一对共享相同的间隙。 
4. 将所有单次出现的字母放入任何剩余位置。 这些字母不限制距离，因此可以在不影响结构的情况下插入它们。 
5. 通过以强制恒定移位的方式交错第一次出现和第二次出现的结构来构造最终字符串。 一种自然的方式是以相同的相对顺序将所有第一次出现的情况放置在前段中，将所有第二次出现的情况放置在后段中。 
6. 输出构造好的字符串。 

### 为什么它有效

 正确性来自于对重复字母强制执行严格的位置模板。 一旦所有第一次出现都被分配了位置$p_1 < p_2 < \dots < p_k$，第二次出现被分配位置$p_1 + d, p_2 + d, \dots, p_k + d$，每个重复的字母自动有距离$d$。 由于该构造确保所有对具有相同的相对偏移量，因此任何字母都不能违反该约束。 单一出现的字母不受约束，因此不能破坏条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    s = input().strip()

    freq = {}
    for ch in s:
        freq[ch] = freq.get(ch, 0) + 1

    ones = []
    twos = []

    for ch in freq:
        if freq[ch] == 1:
            ones.append(ch)
        else:
            twos.append(ch)

    twos.sort()
    ones.sort()

    # Build result in a simple constructive pattern:
    # first all singles, then first occurrences, then second occurrences
    res = []

    # place singletons first
    for ch in ones:
        res.append(ch)

    # first occurrences
    for ch in twos:
        res.append(ch)

    # second occurrences
    for ch in twos:
        res.append(ch)

    print("".join(res))
```该代码首先计算频率，然后将字符分为单个组和重复组。 它对两个组进行确定性结构排序。 该结构首先放置所有单次出现的字符，然后是第一次出现的重复字母，最后是第二次出现的重复字母。 

这种布局确保所有重复的字母具有相同的间距，因为每个重复的字符都被分割在相同的两个连续块之间，使它们的距离等于单个块的大小加上排序引起的偏移量。 距离的确切值并不重要，重要的是相等。 

## 工作示例

 ### 示例 1：`abcdcba`我们计算频率：全部`a, b, c, d`出现两次。 没有单身人士。 

我们分开：

 -个=[]
 - 二元 = [a, b, c, d]

 排序后：[a,b,c,d]

 我们构造：

 | 步骤| 块 | 第一块 | 第二块 | 结果 |
 | ---| ---| ---| ---| ---|
 | 初始化| []| []| []| “” |
 | 首先重复 | []| a b c d | []| “abcd”|
 | 重复第二个 | []| a b c d | a b c d | “abcdabcd”|

 最终字符串：`abcdabcd`每个字母出现两次，间距相同，均为 4。 

这表明即使原始顺序是任意的，该结构也强制执行统一配对。 

### 示例 2：`oelhl`频率：

 - o：1，e：1，h：1，l：2

 拆分：

 - 个 = [e, h, o]
 - 两 = [l]

 施工：

 | 步骤| 块 | 第一块 | 第二块 | 结果 |
 | ---| ---| ---| ---| ---|
 | 初始化| []| []| []| “” |
 | 单打 | 呃呃| []| []| “埃霍”|
 | 第一个| 呃呃| 我| []| “埃霍尔”|
 | 第二个| 呃呃| 我| 我| “埃霍尔l”|

 最终字符串：`eholl`单个重复的字母`l`由于只有一对，因此通常满足相等间距。 单例不会干扰任何约束。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        s = input().strip()

        freq = {}
        for ch in s:
            freq[ch] = freq.get(ch, 0) + 1

        ones = []
        twos = []

        for ch in freq:
            if freq[ch] == 1:
                ones.append(ch)
            else:
                twos.append(ch)

        ones.sort()
        twos.sort()

        res = ones + twos + twos
        out.append("".join(res))

    return "\n".join(out)

# provided samples
assert run("3\noelhl\nabcdcba\nac\n") in [

# custom cases

assert run("1\nabcdef\n") == "abcdef", "all singles"
assert run("1\naaaabb\n") != "", "multiple duplicates"

 ## 边缘情况

 当字符串不包含重复字母时，频率分割仅产生单例。 在像这样的输入中`ac`，算法将两个字母放入单例块中并直接输出。 由于不存在任何约束，因此任何排序都是有效的，并且算法正确地避免了不必要的结构。 

当所有字母都重复时，例如`abcdcba`，单例块是空的。 该结构折叠成已排序的重复列表的两个相同的一半。 后半部分保证了相同的间距，因为每个字母对都由完全相同的段长度分隔。 

当单个字母在多个单例中重复时，例如`oelhl`，单例前缀只是将重复字母的两次出现均等地移动。 由于所有重复项共享相同的前缀，因此它们出现之间的距离保持一致，并且单例放置不会干扰相对间距。
