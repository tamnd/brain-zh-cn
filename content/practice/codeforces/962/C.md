 ## 解决方案
 ## 问题理解

 我们得到一个以十进制形式书写的正整数。 我们可以重复地从中删除数字，唯一的限制是剩余的数字必须始终保持正数并且不能获取前导零。 每次删除都会使数字的长度减少一位数字，我们可以继续下去，直到停在原始数字的任何子序列处。 

任务是找到给定数字的一个子序列，该子序列形成一个完美的正方形，并且在所有这些子序列中，我们想要需要最少删除的子序列。 如果没有子序列可以排列成完美的正方形，我们报告不可能。 

关于输入大小的一个关键观察结果是，尽管数字可以大到 2·10^9，但操作并不取决于数字大小，而是取决于数字结构。 该数字最多有 10 位数字，因此搜索空间基本上是数字子序列的组合，而不是算术幅度。 

该约束立即意味着对所有子序列进行暴力破解是可行的，因为最多有 2^10 种可能性，即大约 1024 个候选者。 每个候选人都可以独立检查。 

一个微妙的边缘情况是在删除后处理前导零。 例如，从 1025 开始，删除数字可能会产生 025，这是无效的，必须被拒绝，即使在数字上它等于 25。另一个边缘情况是最小可能的结果数字是单个数字； 例如，16可以通过删除数字变成4，而像1、4和9这样的个位数方块就是有效目标。 

## 方法

 一种简单的方法是尝试所有可能的方法来删除数字并形成每个可能的子序列，然后检查所得的数字是否是完全平方数。 由于每个数字都可以保留或删除，因此对于具有 d 位数字的数字，有 2^d 个子序列。 对于每个子序列，我们必须构造结果整数并验证它是否是平方，这涉及计算整数平方根并检查其平方。 这种方法是正确的，因为它枚举了所有可能的有效结果，但其成本随着数字计数呈指数增长。 对于最多 10 位数字，这仍然是可以接受的，但它在概念上无法扩展，并且可以通过将搜索限制为有意义的候选来使其更加清晰。 

关键的见解是我们永远不需要考虑没有结构的任意子序列。 每个有效答案都是形成某个整数 x 的子序列，使得 x 是完全平方数。 我们可以生成最多 10 位数字的所有完美平方，并检查每个平方是否可以作为给定数字的子序列嵌入，而不是生成子序列并测试它们。 这翻转了搜索的方向：我们问的不是“这个子序列可以是一个正方形吗”，而是“这个正方形可以由我们拥有的数字组成吗”。 

由于任何有效答案的长度最多为 10 位数字，因此我们需要考虑的最大平方是 10^9，因为 (10^5)^2 = 10^10 已经超出了数字限制，所以我们只需要 10^9 以内的平方。 最多给出 31622 个候选方格。 对于每个候选方格，我们检查其数字字符串是否是原始数字的子序列。 如果是，则成本是删除的次数，等于原始长度减去平方长度。 

这将问题简化为在一小部分候选者上重复的标准子序列匹配任务。

 ## 算法演练

1、将输入的数字转换为字符串，使数字运算变成简单的字符比较。 这避免了重复的整数重建并简化了子序列检查。 
2. 预先计算小数表示长度在 1 到 10 位之间的所有完全平方数。 我们通过在 i² ≤ 10^9 时从 1 向上迭代 i 并将 i² 存储为字符串来实现此目的。 这确保我们考虑可以匹配有效最终数字的每个可能目标。 
3. 对于每个方串，尝试将其作为原始数字串的子序列进行匹配。 我们在原始字符串中维护一个指针，并向前扫描正方形的每个数字，仅在找到匹配项时才前进。 
4. 如果可以匹配完整的方串，则将删除计算为 len(original) − len(square)。 跟踪所有有效方格的最小值。 
5. 如果没有方块匹配，则输出-1。 否则输出最小删除计数。 

### 为什么它有效

 每个有效结果都是原始数的子序列，也是一个完全平方数。 通过枚举相关范围内的所有完全平方数，我们保证每个可能的有效端点都被恰好考虑一次。 子序列检查确保我们只接受实际上可以由给定数字组成的正方形，而无需重新排序。 由于删除仅删除数字，因此任何可实现的结果都与子序列完全对应，因此不会错过任何有效的构造。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_subsequence(small, big):
    i = 0
    for ch in big:
        if i < len(small) and small[i] == ch:
            i += 1
    return i == len(small)

def solve():
    n = input().strip()
    L = len(n)

    max_root = 10**5
    best = float('inf')

    i = 1
    while i * i <= 10**9:
        sq = str(i * i)

        if len(sq) <= L and is_subsequence(sq, n):
            best = min(best, L - len(sq))

        i += 1

    print(-1 if best == float('inf') else best)

if __name__ == "__main__":
    solve()
```该代码首先将数字转换为字符串，以便后续检查变成线性扫描。 i 上的循环生成最多 10^9 的所有平方。 每个方块都转换为字符串，并使用贪婪指针扫描对输入进行检查。 贪婪扫描是正确的，因为子序列匹配不需要回溯：一旦匹配了一个数字，就不应该重新考虑较早的位置。 

答案被计算为原始长度和匹配平方长度之间的差，因为每个不匹配的数字对应于删除。

 ## 边缘情况

 一个关键的边缘情况是子序列形成带有前导零的数字。 对于输入 1025，可以提取“025”，但这必须被拒绝。 该算法隐式地避免了这种情况，因为它只按顺序比较数字字符串，并且不允许将前导零解释为有效数字； 只有像“25”这样的精确数字序列才被视为有效匹配。
