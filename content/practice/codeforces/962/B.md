 ## 解决方案

 ## 问题理解

 火车车厢里给我们安排了一排座位。 有些座位已经被占满了，其余的都空着。 我们希望让尽可能多的学生坐在空座位上。 每个学生都属于两种类型之一，限制简单但严格：两个相邻的座位不能容纳同一类型的学生。 然而，程序员旁边的运动员是允许的，所以唯一禁止的邻接是相同类型。 

被堵塞的座位将这一排分成连续的空单元的独立部分。 在每个部分中，我们决定放置多少学生以及如何改变他们的类型。 由于学生除了类型之外是可以互换的，因此问题就变成了贪婪地填充每个部分，同时尊重两种类型的可用计数。 

限制最多为 200,000 个席位，因此任何尝试所有布局或对分配进行回溯的解决方案都太慢。 针对分段或配置的二次或指数方法将无法生存。 我们需要线性扫描或贪婪构造来处理每个段一次并做出局部最优决策。 

当段很长并且我们提前用完一种类型时，就会出现微妙的边缘情况。 例如，如果我们有一个很长的空块，并且只有一种类型的学生，我们就不能在该块中填充多个座位，因为否则会违反邻接关系。 另一个边缘情况是当段很短或孤立时，贪婪填充可能看起来微不足道，但仍然与剩余的全局计数相互作用。 

## 方法

 一个蛮力的想法是处理每个空段，并尝试所有可能的方法用 A 和 B 学生填充它，同时尊重邻接规则。 对于长度为 k 的线段，每个座位可以是 A 或 B，但受到邻居的约束，导致状态空间在最坏的情况下增长为 2^k。 即使基于剩余计数 a 和 b 进行修剪，当 k 很大时，配置的数量也变得不可行。 

关键的观察是，在任何部分中，一旦我们决定了第一名的学生，如果我们充分利用它，该部分的其余部分将被迫进入交替模式。 这减少了从组合放置到槽的贪婪消耗的问题。 我们没有探索配置，而是简单地遍历每个部分，并尽可能放置一个学生，选择不违反邻接性并且在我们的柜台中仍然可用的类型。 

我们永远不需要展望当前席位之外的情况，因为唯一的限制是本地邻接性和剩余计数。 这使得问题成为对字符串的线性贪婪扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最优贪心 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们从左到右处理字符串，处理由阻塞位置分隔的连续的空座位块。

1. 扫描字符串并识别连续“.”的片段 人物。 每个段都可以独立处理，因为“*”充当分隔符，防止跨边界相邻。 
2. 对于每个航段，我们尽量一个一个地填满。 在每个位置，我们决定放置哪种类型的学生。 
3. 在一节开始时，我们认为前一个座位实际上是“堵塞”或空的，因此只要有剩余的学生，我们就可以自由选择任何一种类型。 
4. 对于该段的每个座位，我们尝试放置一名学生。 如果两种类型都可用，我们会选择保留未来灵活性的一种，但更简单且正确的策略是在尊重计数的同时贪婪地交替。 实际上，我们只是尝试在每个座位上放置一名学生，从仍然可用的类型中进行消费，并确保我们不会放置与之前放置的学生相同的类型。 
5. 如果一种类型用完，即使还有座位，我们也可能会被迫跳过分配，因为禁止连续分配同类型的学生。 在这种情况下，我们会继续扫描，但仅在有效时放置。 
6. 我们累积所有分段的已安置学生总数并输出。 

关键的想法是，在一个分段中，我们只依赖于最后排名的学生类型和剩余人数。 这确保我们永远不需要修改之前的决定。 

### 为什么它有效

 该算法认为，在任何段内，构造的序列永远不会包含两个相邻的相同类型。 每个放置都遵循构造的邻接约束。 此外，每个安置只消耗一名可用的学生，并且我们仅在两个约束（可用性和邻近性）允许的情况下进行安置。 由于段是独立的，并且我们在可能的情况下从不跳过有效的放置，因此在全局约束下每个段的结果是最大的。 

贪婪的本质是安全的，因为在可能的情况下放置有效学生的任何偏差只会减少总数，并且除非由于缺乏有效的学生类型而被迫，否则留空座位没有任何好处。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, a, b = map(int, input().split())
    s = input().strip()

    def take(prev, a, b):
        # returns which type to take, or None
        if prev == 'A':
            if b > 0:
                return 'B'
            if a > 0:
                return 'A'
        else:
            if a > 0:
                return 'A'
            if b > 0:
                return 'B'
        return None

    ans = 0
    i = 0

    while i < n:
        if s[i] == '*':
            i += 1
            continue

        # process segment
        j = i
        while j < n and s[j] == '.':
            j += 1

        prev = None
        for k in range(i, j):
            if a == 0 and b == 0:
                break

            if prev is None:
                if a >= b and a > 0:
                    prev = 'A'
                    a -= 1
                elif b > 0:
                    prev = 'B'
                    b -= 1
                elif a > 0:
                    prev = 'A'
                    a -= 1
                else:
                    break
                ans += 1
            else:
                if prev == 'A':
                    if b > 0:
                        prev = 'B'
                        b -= 1
                        ans += 1
                    else:
                        break
                else:
                    if a > 0:
                        prev = 'A'
                        a -= 1
                        ans += 1
                    else:
                        break

        i = j

    print(ans)

if __name__ == "__main__":
    solve()
```该代码首先将这一排分成空座位的片段。 对于每个段，它贪婪地构建一个有效的交替序列。 这`prev`变量跟踪最后放置的类型，因此我们永远不会放置相同的相邻学生。 最初的选择偏向于较大的剩余池，这有助于避免长段中一种类型的早期耗尽。 其余逻辑强制严格交替，同时尊重剩余计数。 

一个常见的微妙之处是确保一旦无法放置任何有效类型，我们就停止放置在段中。 另一个是正确重置`prev`在每个新航段，由于堵塞的座位完全打破了相邻关系。

 ## 边缘情况

 当字符串仅包含阻塞的座位时，算法立即跳过所有字符并输出零，因为没有形成任何段。 例如，`n = 5, s = "*****"`导致任何段循环内都不会进行迭代，因此答案仍为 0。 

当存在单个长段但只有一种类型可用时，算法会将一名学生恰好放置在第一个座位上，然后由于邻接限制而无法进一步放置。 用于输入`n = 6, a = 10, b = 0, s = "......"`，扫描将一名学生置于位置 1 并停止该段，正确生成 1。 

当存在多个短段时，每个段都会重置`prev`，确保独立性。 例如`*..*..*`被视为三个段，每个段独立运行，没有任何邻接状态的交叉污染。
