 ## 解决方案

 ## 问题理解

 给定两个长度固定的二进制字符串$n$，描述两个机器人在一组任务中的行为方式。 对于每个任务$i$，第一个机器人要么解决，要么不解决，第二个机器人也是如此。 Polycarp 指定一个正整数分数$p_i \ge 1$每个任务的得分，机器人的总得分就是它解决的任务得分的总和。 

自由在于选择价值观$p_i$，但有一个限制：我们希望第一个机器人最终的总得分严格高于第二个机器人。 在所有此类有效分配中，我们希望最小化最大的分配值。 

任务之间的交互是完全独立的，除非通过这个全局最大约束。 每项任务要么对两个机器人有同等的贡献，要么只对其中一个机器人有贡献，要么没有。 这种结构表明，重要的不是绝对值$p_i$，但是它们如何放大两个机器人之间的差异。 

限制因素$n \le 100$意味着即使对任务进行二次或三次推理也是可行的，但一旦确定了正确的聚合，解决方案最终将是线性的。 关键的难点是每个$p_i$不固定为一个小集合，它可以独立变化，因此不可能对分配进行简单的搜索。 

当两个机器人在每项任务上表现相同时，就会出现微妙的边缘情况。 在这种情况下，任何作业都会产生相同的分数，因此严格的优势是不可能的。 当第一个机器人从未解决第二个机器人解决的任务时，就会出现另一种失败情况，因为那时无论得分如何，第一个机器人都永远无法获得优势。 

## 方法

 暴力方法会尝试所有可能的值分配$p_i$达到一定限度$K$，检查是否存在使第一个机器人得分更大的作业。 即使对于固定的$K$， 每个$p_i$有$K$选择，所以这是$K^n$，即使对于微小的$n$。 

关键的观察结果是分数差异与所选值呈线性关系。 每项任务对机器人之间的差异要么有积极的影响，要么有消极的影响，要么根本没有影响。 由于我们控制每个系数$p_i$独立于内$[1, K]$，最优策略是将正贡献尽可能高，负贡献尽可能低。 

这将整个问题简化为计算有多少任务帮助第一个机器人和有多少任务帮助第二个机器人，然后在极端任务下平衡它们的贡献$p_i$。

 ## 算法演练

 我们通过比较机器人的行为对每个任务进行分类。 让我们定义三组：两个机器人解决的任务、仅由第一个机器人解决的任务以及仅由第二个机器人解决的任务。 

然后，我们推理如何分配值以最大化有利于第一个机器人的分数差异，同时尊重最大值$K$。 

1. 计算第一个机器人而不是第二个机器人解决了多少任务。 打电话给这个$A$。 这些任务会产生积极的差异，因此我们希望它们尽可能大，这意味着我们为它们分配价值$K$。 
2. 计算第二个机器人而不是第一个机器人解决了多少任务。 打电话给这个$B$。 这些任务会产生负差异，因此我们希望它们尽可能小，这意味着我们为它们分配价值$1$。 
3. 两个机器人解决的任务或两者都不解决的任务对两个机器人的贡献相同，因此无论分配如何，它们的贡献都会在差异中抵消。 
4. 在最优分配下，分数差变为$A \cdot K - B$。 
5. 我们需要这个差值严格为正，所以我们要求$A \cdot K > B$。 
6. 如果$A = 0$，那么差值总是$-B$，它永远不会变成正数，除非$B = 0$，但即便如此，两个机器人仍然平等，因此严格的不平等是不可能的。 
7. 否则，最小有效$K$是满足的最小整数$K > \frac{B}{A}$，即$\left\lfloor \frac{B}{A} \right\rfloor + 1$。 

### 为什么它有效

 关键的不变量是每个任务对分数差异的贡献都是独立且线性的，并且每个系数$p_i$仅在下方和上方有界。 由于正贡献和负贡献可以分开并独立推向极端，因此任何最佳解决方案都必须满足这些界限：最大化正差异任务的权重并最小化负差异任务的权重。 这保证了没有混合分配可以优于构造的极值分配，因此不等式检查$A \cdot K - B$充分体现了可行性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
r = list(map(int, input().split()))
b = list(map(int, input().split()))

A = 0
B = 0

for i in range(n):
    if r[i] == 1 and b[i] == 0:
        A += 1
    elif r[i] == 0 and b[i] == 1:
        B += 1

if A == 0:
    print(-1)
else:
    K = (B // A) + 1
    print(K)
```该解决方案将任务分为唯一影响差异的两类。 该循环是线性的并直接构造计数。 最终公式直接来自求解不等式$A \cdot K > B$在整数约束下。 

一个常见的错误是尝试独立地为所有四种可能的模式赋值； 只有不对称模式对优化很重要。 另一个微妙之处是处理$A = 0$，其中除法无效并且答案总是不可能的。 

## 工作示例

 ### 示例 1

 输入：```
5
1 1 1 0 0
0 1 1 1 1
```这里的分类是：

 | 我| r | 乙| 类型 | 效果|
 | ---| ---| ---| ---| ---|
 | 1 | 1 | 0 | 一个 | + |
 | 2 | 1 | 1 | 中立 | 0 |
 | 3 | 1 | 1 | 中立 | 0 |
 | 4 | 0 | 1 | 乙| - |
 | 5 | 0 | 1 | 乙| - |

 所以$A = 1$,$B = 2$。 我们需要$1 \cdot K > 2$， 所以$K = 3$。 

这演示了单个强正任务如何可以补偿多个负任务，但只能通过增加最大允许值来实现。 

### 示例 2

 输入：```
3
1 0 1
1 0 1
```两个机器人在每项任务上的行为都相同，因此不存在$A$或者$B$贡献。 我们得到$A = 0$,$B = 0$。 差异始终为零，因此严格的支配是不可能的，产生$-1$。 

这表明，尽管可以任意分配分数，但相同的行为会消除任何可控的影响力。

 ## 边缘情况

 当两个机器人解决完全相同的一组问题时，每个任务都属于中性类别。 该算法产生$A = 0$，立即触发不可能条件。 尽管可以任意分配分数，但每次分配都会产生相同的总数，因此没有任何配置可以满足严格的优越性。 

当第二个机器人主宰所有任务时，每个贡献都是负面的或中性的。 计算出的$B > 0$和$A = 0$再次迫使失败。 这表明，条件不仅仅与总数有关，而且与至少一个杠杆的存在有关，第一个机器人可以在其中获得相对优势。
