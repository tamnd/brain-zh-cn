 ## 解决方案
 # 问题理解

 我们有一组由平面上的点表示的信标塔。 当由三座塔构建的三角形的一条边正好位于整个点集的边界上时，该三角形被认为是特殊的。 用几何术语来说，一侧必须是凸包边，而另外两侧必须穿过这组点，以便剩余的塔出现在这些线的两侧。 

对于每个塔，我们查看包含它的所有特殊三角形，并将其分数定义为这些三角形中的最小面积。 任务是找到所有塔的最高分数。 如果一座塔不能属于任何特殊三角形，那么它就没有任何贡献。 

输入最多包含 5000 个具有不同坐标的点，并且没有三个点位于同一直线上。 这个尺寸是关键限制。 在最坏的情况下，所有三元组的三次解将检查大约 1250 亿个三角形，这远远超出了 1 秒所允许的极限。 我们需要一个接近二次的解决方案，因为 5000 的平方提供 2500 万次运算，这在优化的 Python 中是现实的。 

几何条件看起来很复杂，但凸包给出了主要的简化。 当三角形的一条边是凸包边时，它就是整个点集的支撑边。 一旦船体边缘固定，几乎每三个点就会创建一个有效的三角形。 唯一无效的第三个点是该边的两个相邻的外壳顶点，因为它们会创建另一个外壳边。 

一些边缘情况可能会破坏直接实现。 如果所有点都在三角形外壳上，则不存在有效的三角形。 

例如：```
3
0 0
1 0
0 1
```没有答案，因为唯一的三角形的所有三个边都在凸包上。 所需的条件恰好要求这样的一侧，因此输出将是`0`。 

另一种情况是凸四边形：```
4
0 0
4 0
4 4
0 4
```使用三个连续的外壳顶点的三角形是无效的，因为它有两个或三个外壳边。 如果粗心的解决方案仅检查所选边是否是船体边缘，则会错误地计算这些三角形。 正确的输出基于两个对角三角形，其面积加倍为 16，所以答案是`8.0000000000`。 

当点位于内部时，就会出现第三个问题。 例如：```
5
0 0
10 0
10 10
0 10
5 5
```中心点可以参与具有外壳边缘的有效三角形，但四个角需要正确处理相反的外壳顶点选择。 仅将外壳顶点视为可能的三角形顶点的实现会错过有效答案。 

# 方法

 直接的方法是尝试每一个三重点。 对于每个三角形，我们可以测试它的三个边并计算整个三角形的支撑线有多少条。 如果恰好一侧符合条件，我们就会更新每个顶点的答案。 这是正确的，因为它直接遵循定义。 然而，有 O(n3) 个三元组，并且根据所有点检查三角形会增加另一个因素，得到 O(n⁴)。 当n等于5000时，这是完全不可行的。 

有用的观察是，唯一需要特殊的一侧是凸包边缘。 我们首先构建凸包。 然后我们只检查由一个船体边缘和第三个点形成的三角形。 

考虑船体边缘 AB。 任意点 C 创建一个以 AB 为支撑边的三角形 ABC。 三角形具有另一条支撑边的唯一情况是当 C 是 A 或 B 的两个船体邻居之一时。这两个选择被排除在外。 每一个其他点都恰好给出一个支撑面。 

这减少了检查每个船体边缘与每个点的问题。 最多有 n 条船体边缘，因此总工作量为 O(n²)。 对于每个有效组合，我们使用叉积计算加倍面积。 保持双倍面积可以避免浮点错误，直到最终除法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n⁴) | O(n) | 太慢了 |
 | 最佳 | O(n²) | O(n) | 已接受 |

 # 算法演练

 1. 使用单调链算法构建所有点的凸包。 船体给出了唯一可能满足支撑线条件的边。 
2. 如果外壳的顶点少于四个，则返回零。 三角形外壳不能包含只有一条外壳边的三角形。 
3. 对于每对连续的船体顶点 A 和 B，将 AB 视为唯一所需的船体边。 A 和 B 的两个外壳邻居是唯一不能用作第三个顶点的点。 
4. 扫描所有点 C。跳过 A、B 和两个禁止的邻居。 对于每个剩余点，计算三角形 ABC 的两倍面积并更新 C 的最小值。 
5. 处理完每个船体边缘后，每个点存储包含该点的最小有效三角形区域。 答案是这些值中最大的一个。 

这样做的原因是每个有效的三角形必须恰好包含一个船体边缘。 该算法枚举每个可能的船体边缘和每个可能的第三个顶点，以防止其他两侧成为船体边缘。 由于每个有效三角形都出现在该枚举中，因此不会遗漏任何候选三角形。 由于每个枚举候选都满足邻居排除规则，因此不会使用无效三角形。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(a, b, c):
    return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

def convex_hull(points):
    pts = sorted(points)

    def build(seq):
        hull = []
        for p in seq:
            while len(hull) >= 2 and cross(hull[-2], hull[-1], p) <= 0:
                hull.pop()
            hull.append(p)
        return hull

    lower = build(pts)
    upper = build(reversed(pts))
    return lower[:-1] + upper[:-1]

def solve():
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n)]

    hull = convex_hull(points)
    h = len(hull)

    if h < 4:
        print("0.0000000000")
        return

    index = {p: i for i, p in enumerate(hull)}
    best = [10**30] * n

    for i in range(h):
        a = hull[i]
        b = hull[(i + 1) % h]

        forbidden = {
            hull[(i - 1) % h],
            hull[(i + 2) % h],
            a,
            b
        }

        for j, c in enumerate(points):
            if c in forbidden:
                continue
            area2 = abs(cross(a, b, c))
            if area2 < best[j]:
                best[j] = area2

    ans = max(best)
    if ans == 10**30:
        print("0.0000000000")
    else:
        print("{:.10f}".format(ans / 2))

if __name__ == "__main__":
    solve()
```这`convex_hull`函数删除中间点，同时仅保留外边界。 因为输入保证没有三点共线，所以使用`<= 0`是安全的并且只保留真实的外壳顶点。 

主循环只考虑每个船体边缘一次。 禁止集包含端点和两个相邻的外壳顶点。 这些正是会在三角形中创建额外的船体边缘的选择。 

面积计算使用绝对叉积。 这给出了三角形面积的两倍整数，避免了比较期间的精度问题。 仅在打印最终结果时才会除以二。 

最终计算不需要解决方案中创建的字典，可以将其删除。 该实现使结构接近几何解释，而实际更新仅依赖于坐标。

import sys, io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.read().strip().split()
    sys.stdin = old

    if not data:
        return ""

    it = iter(data)
    n = int(next(it))
    points = [(int(next(it)), int(next(it))) for _ in range(n)]

    def cross(a, b, c):
        return (b[0]-a[0])*(c[1]-a[1]) - (b[1]-a[1])*(c[0]-a[0])

    def hull(ps):
        ps = sorted(ps)

        def make(arr):
            res = []
            for p in arr:
                while len(res) >= 2 and cross(res[-2], res[-1], p) <= 0:
                    res.pop()
                res.append(p)
            return res

        return make(ps)[:-1] + make(reversed(ps))[:-1]

    h = hull(points)
    if len(h) < 4:
        return "0.0000000000\n"

    best = [10**30] * n
    for i in range(len(h)):
        a = h[i]
        b = h[(i + 1) % len(h)]
        bad = {a, b, h[(i-1) % len(h)], h[(i+2) % len(h)]}
        for j, c in enumerate(points):
            if c not in bad:
                best[j] = min(best[j], abs(cross(a, b, c)))

    return f"{max(best) / 2:.10f}\n"

 # 边缘情况

 对于三角形船体：```
3
0 0
1 0
0 1
```船体尺寸为三。 该算法立即返回零，因为由这些点组成的每个三角形都有三个支撑边。 

对于凸四边形：```
4
0 0
4 0
4 4
0 4
```船体尺寸为四。 当选择底部边缘时，两个相邻的角将被排除，只留下相对的角。 该算法会计算该三角形，因为剩下的两条边是四边形的对角线而不是船体边缘。 

对于内点：```
5
0 0
10 0
10 10
0 10
5 5
```处理外壳边缘时，永远不会排除中心点。 该算法计算其与每个可能的有效船体边缘的距离并记录最小的双倍面积。 这可以处理不属于凸包的点，而无需任何单独的情况。 

仅在检查了每个船体边缘后才获取最终的最大值，因此点是通过其最紧密的可能框架而不是通过单个方便的三角形来判断的。
