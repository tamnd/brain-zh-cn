 ## 解决方案
 ## 问题理解

 我们得到了两组有序的整数，表示巨大数轴上的振动位置。 我们可以执行选择枢轴位置的操作`k`，并且每个振动都严格位于`k`向左进一步移动一步，每次振动都严格位于`k`向右移动一步，任何东西都准确无误`k`保持静止。 

关键在于，一次操作不会移动单个点，它同时将配置扩展到远离所选枢轴的位置。 用不同的枢轴重复此操作会以结构化的方式改变配置，任务是确定我们是否可以将初始配置准确地转换为目标配置。 

输入大小高达二十万点，因此任何尝试模拟操作序列或搜索每步枢轴选择的方法都会立即变得太慢。 即使单个操作也已经影响所有点，因此模拟许多操作会成倍增加成本。 

一个微妙的问题是转变不是局部的。 点的移动取决于枢轴位于其左侧或右侧的所有操作，因此独立思考每个元素很快会导致不一致。 另一个隐藏的困难是该操作可以同时向相反方向移动不同的线段，因此即使存在有效序列，逐个点的贪婪匹配也可能会失败。 

一个简单的推理可能会出错的小例子是尝试匹配每个`a_i`到`b_i`通过检查某些操作是否可以访问它们来独立地进行操作。 例如，与`a = [1, 3, 5]`和`b = [2, 3, 6]`，每个点看起来都可以通过某些操作单独移动，但是操作的共享结构将所有元素耦合在一起，因此独立的可行性会产生误导。 

## 方法

 暴力方法会尝试模拟操作序列。 对于每个可能的枢轴`k`，我们对数组应用全局变换，然后尝试组合这些操作来达到目标​​。 即使将我们限制在一组有限的候选主元中，仍然会留下一个分支过程，其中每个步骤都会重新计算`O(n)`。 高达`2 * 10^5`元素，即使是几百次操作也已经超出了任何合理的时间限制，使得这种方法完全不可行。 

关键的观察是停止根据操作序列进行思考，而是对所有操作的净效果进行建模。 每个操作位置`k`对每个点贡献一个固定的符号效应：左边的点`k`减一，右边的点`k`增加一。 这意味着每次操作都会引起数轴上的全局线性“斜率变化”。 

一旦我们切换视角，我们就会意识到唯一有意义的结构是这些斜率变化如何在排序数组中的连续点之间累积。 该变换简化为控制相邻元素之间的位移差异，结果对所需的移位施加了单调性约束。 

这减少了检查位移是否来自的问题`a_i`到`b_i`形成一个序列，其差异与间隔之间的非负贡献所生成的一致。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| 指数 / O(n·运算) | O(n) | 太慢了|
 | 差异建模| O(n) | O(n) | 已接受 |

 ## 算法演练

 让我们将每个点所需的位移定义为`d_i = b_i - a_i`。 

我们现在推理单个操作如何影响这些位移。 如果我们在位置应用一项操作`k`，那么左边的每个点`k`减少 1，右侧每点增加 1。 这会产生影响点之间相对差异的结构化变化。 

关键的一步是检查两个连续的点`a_i < a_{i+1}`。 考虑位移差有多大`d_{i+1} - d_i`可能会因操作而改变。 仅其枢轴严格位于之间的操作`a_i`和`a_{i+1}`造成这种差异，并且每个这样的操作都准确地贡献`+2`到`d_{i+1} - d_i`。 

于是我们得到一个结构方程：`d_{i+1} - d_i = 2 * (number of operations with pivot in (a_i, a_{i+1}))`由此我们立即得到两个约束。 首先，每个差异`d_{i+1} - d_i`必须为非负数，因为它是操作计数的两倍。 其次，每个这样的差异必须是均匀的。 

我们现在将这些条件转化为决策程序：

 1. 计算`d_i = b_i - a_i`对于所有指数。 
2. 检查顺序`d`是非减的。 这确保了间隔之间不会出现负操作计数。 
3. 检查每个相邻的差异`d_{i+1} - d_i`是均匀的。 这保证了每个区间内的操作次数是一个整数。 
4. 如果两个条件都成立，则可以进行转化； 否则是不可能的。 

要理解为什么这已经足够了，请注意连续之间的每个间隔`a_i`和`a_{i+1}`可以分配独立数量的操作，具体由下式确定`(d_{i+1} - d_i) / 2`。 任何剩余的全局偏移都可以通过将操作放置在所有点的范围之外来处理，这会平等地影响每个元素并且不会干扰差异。 

### 为什么它有效

 该算法隐式地重建了有效的操作枢轴多重集。 关键的不变量是位移向量`d_i`可以分解为数轴上不相交区间的贡献。 每个间隔对其左侧和右侧的所有点进行统一贡献，其方式仅以受控的加性方式影响相邻差异。 因为这些贡献是独立的且非负的，所以可行性降低到检查所有区间贡献是否作为有效计数存在。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    d = [b[i] - a[i] for i in range(n)]
    
    for i in range(n - 1):
        if d[i] > d[i + 1]:
            print("NO")
            return
        if (d[i + 1] - d[i]) % 2 != 0:
            print("NO")
            return
    
    print("YES")

if __name__ == "__main__":
    solve()
```该代码直接计算位移数组，然后强制执行两个导出条件：单调性和偶差性。 单调性检查对应于确保没有间隔需要负数的操作，这是不可能的，因为操作计数不能为负。 

奇偶校验确保连续原始位置之间的每个间隔允许整数个操作，因为每个操作恰好贡献两个单位的差异。 

不需要其他约束，因为全局偏移总是可以由所有点范围之外的操作产生。

 ## 边缘情况

 一个关键的边缘情况是当所有点都已经匹配时，其中每个`d_i = 0`。 该算法检查差异，找到全零，然后立即接受。 This corresponds to doing zero operations or applying symmetric far-away operations that cancel out.

 Another case is a minimal configuration with two points where only one point shifts incorrectly. 例如`a = [1, 2]`,`b = [1, 3]`产生`d = [0, 1]`，由于差异是奇数，所以奇偶校验失败。 该算法正确地拒绝了这种情况，因为没有任何操作序列可以在相邻点之间产生单个单元的不平衡。 

第三种微妙的情况是位移是单调的，但由于宇称性而不可行。 例如`d = [0, 2, 3]`正在增加，但最后一步有奇怪的差异，因此即使值本身看起来一致，它也会被拒绝。 这反映出每个间隔都以恰好为两个的块进行贡献，因此奇数跳跃在结构上是不可能的。
