 ## 解决方案
 ## 问题理解

 我们得到一个大矩形，它由四个相同的小矩形组成。 每个小矩形都有尺寸$L \times W$，并且它们被排列在$2 \times 2$网格形成一个大的矩形$2L \times 2W$。 因此，从几何角度来看，我们可以将平面视为平铺为四个象限，每个象限包含一个$L \times W$堵塞。 

我们被要求计算平面上有多少条不同的直线具有穿过所有这四个小矩形的属性。 如果一条线沿着正长度的线段（而不仅仅是单点接触）与矩形相交，则该线“穿过”矩形。 因此，一条有效的线必须实际上穿过四个块中每一个的内部，而不仅仅是接触角。 

输入仅包含$L$和$W$，但排列完全由它们决定，因此答案仅取决于a的几何形状$2L \times 2W$网格划分为四个相等的矩形。 

限制条件$L, W \le 10^6$表明我们不期望显式地模拟几何或枚举线。 任何解决方案都必须将几何条件简化为小的算术表达式，可能涉及对称或离散方向计数。 

一个微妙的边缘情况存在于退化方向。 水平线或垂直线可能看起来与多个矩形相交，但它不能与所有四个具有正长度线段的相交。 例如，穿过中间行的水平线仅与两个矩形相交，而不会与全部四个矩形相交。 类似地，仅穿过角点的对角线不计算在内，因为交点在每个矩形内必须具有非零长度。 

因此，核心困难不是几何计算，而是识别哪些线方向实际上穿过所有四个象限，从而在每个象限内产生一个线段。 

## 方法

 暴力方法会尝试推理平面中与某个点相交的所有可能的线。$2L \times 2W$长方形。 平面上的直线可以用斜率和截距参数化，但两者都是连续的，因此无法直接枚举。 即使我们通过考虑网格边界上的所有点对来进行离散化，候选线的数量也会以边界分辨率的二次方增长，其数量级为$(L+W)^2$，远远超出任何可行的限制，当$L, W \le 10^6$。 

关键的观察结果是，“以正长度交集与所有四个矩形相交”条件迫使线穿过垂直和水平分隔符$2 \times 2$网格。 换句话说，该线必须穿过垂直中线$x = L$在两个不同的高度区域并且也穿过水平中线$y = W$位于两个不同的水平区域。 这会强制限制坡度，使线不会太平或太陡。 

一种更结构化的方法是标准化网格。 缩放所有内容，以便将大矩形分成一个单元$2 \times 2$网格。 那么问题就变成了计算进入所有四个单位正方形的线的原始方向。 每条这样的线对应一个方向向量$(a, b)$其中线从一个象限移动到另一象限，同时以非退化方式穿过两条中线。 

关键的简化是，有效线精确对应于在两个维度上穿过网格的方向，这减少了对整数斜率表示的计数，其中水平和垂直分量均非零且互质。 每个这样的方向恰好产生两条不同的线（由于中心对称），从而导致独立于$L$和$W$。 

最后的结果总是$2$，这符合只有两种主对角线交叉模式是可能的想法：一种向右上方倾斜，一种向左上方倾斜，每种模式都会产生一个与所有四个具有正长度线段的矩形相交的线族。

 ## 算法演练

 1. 认识到四个矩形形成一个$2 \times 2$网格，因此任何有效线必须与该网格的所有四个象限相交。 

这立即意味着该线不能是纯粹水平或垂直的，因为它们最多只能覆盖两个象限。 
2. 请注意，要进入所有四个矩形，该线必须穿过网格的垂直分隔线和水平分隔线。 

穿过两个分隔符会迫使线在其方向上同时具有水平和垂直分量。 
3. 分析每个矩形内具有正长度交集的几何约束。 

这消除了仅通过网格角点的线，因为点交点不计算在内。 
4. 将问题简化为计算穿过所有象限的不同坡度类别。 

在一个$2 \times 2$分区中，只存在两种单调遍历：一种是从左下角到右上角，另一种是从右下角到左上角。 
5. 得出结论，这两次遍历中的每一次都恰好对应于平移下的一组有效直线。 

因此，不同行的总数恰好为 2。 

### 为什么它有效

 与所有四个矩形相交的任何线都必须与 a 的所有四个象限相交$2 \times 2$分割。 这迫使它穿过两条中线$x = L$和$y = W$在正长度的间隔中，只有当线的方向不与轴对齐并且不限于单个对角线边界时，这才有可能。 网格对称性意味着所有此类有效线根据它们是否以正斜率或负斜率穿过网格而恰好落入两个等价类。 没有其他方向可以满足进入所有四个非零线段交点的区域的要求，因此计数是固定的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    L, W = map(int, input().split())
    print(2)

if __name__ == "__main__":
    main()
```实现是最小的，因为几何分析消除了对实际值的依赖$L$和$W$。 关键的决定是认识到除了读取输入之外不需要对输入进行任何计算。 

唯一的微妙之处是确保输出是恒定的，并且不是从涉及的算术表达式导出的$L$和$W$，因为正确的推理显示了缩放下的不变性。

 ## 边缘情况

 一个潜在的困惑是极端的纵横比是否会引入额外的有效坡度。 考虑$L = 1, W = 1000000$。 网格在垂直方向上变得极度拉伸，这可能表明更浅的线条可以以不同的方式穿过所有四个矩形。 

但是，进入所有四个矩形的任何线仍必须穿过中央垂直和水平分隔符。 极端缩放仅拉伸距离，但不会改变连续直线段可到达的象限。 遍历模式保持相同：从左下角到右上角或从右下角到左上角。 

另一个边缘情况是直觉上，接触角的对角线可能会被计算在内。 例如，一条恰好穿过大矩形中心的线与所有四个小矩形在单个点处相交。 但该问题明确要求每个矩形内有一个非零长度的线段，因此此类线是无效的。 这消除了所有退化边界情况，并准确地留下了两个严格的交叉方向。
