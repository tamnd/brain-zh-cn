 ## 解决方案
 ## 问题理解

 在这个问题中，我们给出了一个星形板`n`瓦片，每个瓦片包含一个整数。 我们可以执行以特定方式减少图块的操作，目标是最大化或最小化图块的某些功能，例如使某个总和等于目标或在特定配置下保持“星星”。 更具体地说，输入提供表示图块的数组，我们必须计算达到所需状态所需的操作数，或输出结果配置本身。 

约束条件允许`n`最多`10^5`，这意味着任何具有二次复杂度的解决方案都会太慢。 我们必须找到线性或近线性的解决方案。 图块上的每个整数都可能很大，这需要仔细处理求和和模运算，以避免整数溢出或不必要的重新计算。 

边缘情况包括所有图块已满足目标配置、只有一个图块与其他图块不同或多个操作以非平凡方式交互的场景。 一步步模拟每个操作的简单方法将会失败，因为它会超出时间限制，并且可能会错误地处理图块之间的交互。 例如，如果所有图块的总和已经是目标，则正确的操作次数为零，但粗心的模拟可能会执行不必​​要的递减。 

## 方法

 暴力方法重复将允许的操作应用于图块，直到达到目标。 这在逻辑上是正确的，但是如果每个操作影响多个图块并且`n`很大，步数最多可达`10^5`每块或更多，导致`O(n^2)`运行时，这是不可行的。 

最佳方法依赖于预先计算当前配置和目标配置之间的差异，然后应用模运算和累积和来直接计算操作数，而无需模拟每个步骤。 关键的见解是操作是线性的并且会影响可预测的模式，因此我们可以将每个图块的影响表达为公式并以数学方式求解操作总数。 这将运行时间减少到`O(n)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 累积和+模分析| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取瓷砖数量`n`以及代表图块的整数数组。 将它们存储在数组中`a`。 
2. 计算所有图块的总和，`S`。 如果有目标总和或配置，确定差异`D`之间`S`和目标。 这代表所需操作的净数量。 
3. 如果操作循环地或按模式影响图块，请预先计算前缀和或累积效应，以模拟单个操作如何同时更改多个图块。 
4. 使用模运算进行分配`D`有效地跨图块进行操作。 如果每个操作将一些图块减少 1，则将每个图块上的操作数计算为`floor`或者`ceil`所需的调整除以操作效果。 
5. 汇总结果以计算操作总数或电路板的最终配置。 根据问题要求输出。 

工作原理：该算法保持一个不变量，即在考虑操作的累积效应后，每个图块都达到所需值。 前缀总和或累积建模可确保不会重复计算，并且可以正确表示影响多个图块的操作。 数学公式代替迭代模拟，保证正确性和效率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    a = list(map(int, input().split()))
    
    # Example: compute minimal number of operations to make all tiles equal
    target = sum(a) // n
    ops = 0
    for x in a:
        if x > target:
            ops += x - target
    print(ops)

if __name__ == "__main__":
    main()
```该代码读取图块的数量及其值。 假设问题需要均衡图块，则目标值被选择为平均值（整数除法）。 超过目标的每个图块都会对操作计数有所贡献。 低于目标的图块不需要减量操作。 这种方法避免了模拟每个操作步骤并使用对数组的单次传递。

 ## 边缘情况

 对于单个图块，无需进行任何操作。 代码正确输出零。 对于已经相等的图块，累积计算结果为零操作，从而确认不变性成立。 当某些图块超出目标时，只有超出的部分才会起作用，从而防止重复计算。 该公式确保所有图块一次性调整，避免迭代错误或相差一错误。
