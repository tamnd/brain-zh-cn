 ## 问题理解

 游戏共有三名参与者：Fyodor、Matroskin 和 Sharik。 他们每个人都选择三个经典动作之一：`rock`,`paper`， 或者`scissors`。 只有当一个玩家的动作同时击败其他两个玩家的动作时，该玩家才会获胜。 任务是判断这样的玩家是否存在并打印他们的标识符，或者打印`?`如果该轮没有唯一的获胜者。 最初的任务使用通常的规则：石头胜剪刀，剪刀胜布，布胜石头。 

输入由三个字符串组成，每个字符串按固定顺序对应每个参与者。 输出是单个字符：`F`,`M`， 或者`S`对于相应的获胜者，或`?`当没有人可以被宣布为获胜者时。 

约束很小，因为输入总是包含恰好三个动作。 这意味着任何检查三个玩家之间所有可能关系的解决方案都将在恒定时间内运行。 不需要先进的数据结构或算法。 主要挑战不是性能，而是正确处理游戏逻辑并避免对于两人石头剪刀布正确但对于三人玩家错误的假设。 

第一个棘手的情况是所有玩家都选择相同的动作。 例如：```
rock
rock
rock
```正确的输出是：```
?
```没有一个玩家能打败其他两个，因为每次比较都是平局。 粗心的解决方案可能会将重复的举动视为“多数”并错误地选择获胜者。 

另一个棘手的情况是，当两个玩家有相同的动作，而第三个玩家有一个输给它的动作时：```
paper
rock
rock
```正确的输出是：```
F
```纸玩家击败了两个石头玩家。 一个常见的错误是认为两个相等的着法总是消除获胜的可能性，但在这个游戏中，一个着法可以击败另外两个相同的着法。 

最后的边缘情况是所有三个动作都不同：```
scissors
paper
rock
```正确的输出是：```
?
```每一步棋都击败另一步棋，又输给另一步棋，所以没有人主宰整个团队。 

## 方法

 一种直接的方法是按字面模拟定义。 对于每个玩家，将他们的动作与其他两个动作进行比较，并检查两个比较是否都获胜。 如果恰好有一个玩家满足此条件，则该玩家就是答案。 这是有效的，因为获胜者完全是通过与其他两个参与者的成对比较来定义的。 

暴力版本会检查恒定数量的案例。 对于三个玩家，它只执行几次比较，因此它的操作次数已经很少了。 在有许多玩家的较大变体中，尝试与所有其他参与者对抗每个可能的获胜者将变得昂贵，但这个问题没有这种结构。 

关键的观察是，只有三种可能的走法，获胜者必须是唯一一个走法击败其他走法的玩家。 我们不需要计算分数或模拟回合。 我们只需要认识到三种获胜模式：`rock`反对两个`scissors`,`scissors`反对两个`paper`， 和`paper`反对两个`rock`。 

暴力破解之所以有效，是因为参与者的数量是固定的，但更简单的模式检查消除了不必要的比较，并使逻辑更容易验证。

 ## 算法演练

 1. 按照参赛者的顺序读出三个动作。 保持顺序很重要，因为输出字母取决于原始玩家的位置。 
2. 检查每种可能获胜的情况。 如果玩家的棋步相对于被击败的棋步出现两次，则玩家获胜。 例如，`rock`当另外两步都是时就获胜`scissors`。 
3. 如果这些模式之一匹配，则打印相应玩家的字母。 三个有效模式不能重叠，因为两个不同的动作不能同时击败相同的两个动作。 
4. 如果没有一个获胜模式匹配，则打印`?`。 这包括平局和循环情况，其中每一步都有赢家和输家。 

为什么它有效：

 有效的获胜者必须击败两个对手。 在石头剪刀布中，只有一个动作能够击败三种可能的相反动作中的每一种。 因此，唯一可能获胜的配置是重复一个动作来对抗它击败的两个动作。 该算法会检查每个此类配置，因此如果存在获胜者，它将找到该玩家。 如果没有匹配的配置，则没有人击败两个对手，这意味着结果正确未知。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

def solve():
    moves = [input().strip() for _ in range(3)]

    if moves[0] == "rock" and moves[1] == "scissors" and moves[2] == "scissors":
        print("F")
    elif moves[0] == "scissors" and moves[1] == "paper" and moves[2] == "paper":
        print("F")
    elif moves[0] == "paper" and moves[1] == "rock" and moves[2] == "rock":
        print("F")
    elif moves[1] == "rock" and moves[0] == "scissors" and moves[2] == "scissors":
        print("M")
    elif moves[1] == "scissors" and moves[0] == "paper" and moves[2] == "paper":
        print("M")
    elif moves[1] == "paper" and moves[0] == "rock" and moves[2] == "rock":
        print("M")
    elif moves[2] == "rock" and moves[0] == "scissors" and moves[1] == "scissors":
        print("S")
    elif moves[2] == "scissors" and moves[0] == "paper" and moves[1] == "paper":
        print("S")
    elif moves[2] == "paper" and moves[0] == "rock" and moves[1] == "rock":
        print("S")
    else:
        print("?")

if __name__ == "__main__":
    solve()
```该程序首先将三个输入字符串存储在一个数组中，其中索引`0`是费奥多尔，索引`1`是 Matroskin，索引`2`是沙里克。 这保留了输入顺序和所需输出字母之间的连接。 

条件块直接对获胜状态进行编码。 每个块描述一个参与者选择一个击败其他两个参与者的相同动作的动作。 由于只有九种可能的获胜安排，因此明确检查它们可以避免紧凑问题中的错误。 

决赛`else`处理每个剩余的状态。 它包括所有平局、所有三种不同走法的情况以及没有玩家击败两个对手的情况。

rock
```该算法会检查所有可能的获胜模式，但一无所获。 虽然步数相等，但没有一个玩家击败另外两个，因此输出为`?`。 

对于输入：```
paper
rock
rock
```该算法达到了费奥多尔的论文击败两块石头的条件。 它立即确定费奥多尔为获胜者并打印`F`。 

对于输入：```
scissors
paper
