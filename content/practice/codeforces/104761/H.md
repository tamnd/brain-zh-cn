 ## 解决方案
 ## 问题理解

 我们被要求为给定数量的命令设计一个二进制码本$K$。 每个命令都是偶数长度的二进制字符串$Len$，我们必须分配$K$不同的字符串。 

这些字符串不是任意的。 它们必须满足两个结构性约束。 首先，每个字符串必须包含相同数量的 1。 其次，如果我们查看所有选定字符串中的任何位位置并计算该位置有多少个字符串为 1，那么这些计数在各个位置上必须几乎一致，最多相差 1。 

在所有可能的有效结构中，我们想要尽可能最小的偶数长度$Len$，并且我们必须输出任何有效的集合$K$字符串实现它。 

关键的困难在于约束以两种不同的方式耦合字符串。 一个约束是每个字符串（固定汉明权重），另一个约束是每个位置（平衡列总和）。 这迫使结构非常对称：我们本质上是在构建一个高度规则的关联矩阵，具有固定的行和和几乎相等的列和。 

限制足够小，我们可以承受$Len \le 100$， 但$K$可以达到$10^4$，因此我们必须避免任何依赖于枚举所有二进制字符串或组合搜索的构造。 

一种简单的方法会尝试生成给定长度的所有字符串，并选择一个平衡行和列约束的子集。 这会立即失败，因为即使对于$Len = 20$，候选人的数量是$2^{20}$，太大了。 

一种更微妙的失败模式来自于尝试贪婪地为每个位置分配一个。 例如，如果我们尝试独立填充每个位置，同时强制每行具有固定的权重，则很容易导致冲突或不平衡的列计数，而这些冲突或不平衡的列计数无法在不破坏唯一性或统一行权重的情况下进行本地纠正。 

核心挑战是认识到该结构足够对称，可以直接构建而不是搜索。 

## 方法

 我们可以将问题重新解释为构造一个二元矩阵$K$行和$Len$列。 每行都有相同的总和，例如$R$，每列都有一个总和$\lfloor KR/Len \rfloor$或者$\lceil KR/Len \rceil$。 

蛮力的观点是修复$Len$，然后尝试该长度的所有可能的二进制字符串的行的所有子集，并测试行一致性和列平衡是否成立。 这是行和列的组合，并且呈指数增长$Len$。 即使与$Len = 20$，大小子集的数量$K$是一个天文数字，检查每个候选集的列平衡也很昂贵。 

关键的见解是扭转观点。 我们不是独立选择字符串，而是构建一个结构化的字符串族，其中两个属性都是自动的。 一个自然的候选者是将字符串解释为循环移位或循环结构上的间隔模式的指示向量。 

我们选择一个长度$Len$每个字符串有固定数量的 1$R$。 那么每个字符串都可以看作是一个选择$R$之间的位置$Len$。 如果我们排列所有字符串，使每一列的使用频率几乎相同，那么我们本质上是在分布$K \cdot R$均匀分布的$Len$位置，这迫使列总和通过构造来平衡。 

剩下的问题是如何在保持相同的行权重的同时保证独特性。 标准结构是处理以下每个整数$0$到$K-1$作为精心选择的维度上的二进制表示，并使用循环移位或平衡组合设计将其嵌入到恒定权重空间中。 最小的$Len$结果是我们至少可以表示的最小偶数$K$不同的常量权重向量，同时保持列总和平衡，这是通过选择最小的偶数来实现的$Len$和$\binom{Len}{Len/2} \ge K$。 然而，因为$Len \le 100$，我们可以直接搜索并构造。 

一次$Len$是固定的，我们使用按字典顺序生成常量字符串并取第一个$K$。 恒定权重选择的对称性确保了在所有字符串中，每个位置的使用频率相同，最多有一个差异，因为所有位置在坐标排列下都是对称的。

 ## 算法演练

 1. 找到最小的偶数$Len$使得至少存在$K$长度的二进制字符串$Len$具有相同数量的。 我们可以安全地使用$Len = 2, 4, 6, \dots$直到$\binom{Len}{Len/2} \ge K$，因为中间层最大化了可用的恒定权重字符串。 这保证了可行性和最小性。 
2.固定重量$R = Len / 2$。 这种选择最大化了位位置之间的对称性，这对于平衡列计数是必要的。 
3、生成所有长度字符串中按字典顺序排列的二进制字符串$Len$恰好与$R$那些。 每个字符串对应选择$R$职位出$Len$，词典生成确保确定性覆盖而不重复。 
4. 拿第一个$K$生成的字符串。 这确保了所有字符串的结构都是不同的。 
5、输出$Len$和选定的字符串。 

为什么它有效是基于对称性。 全部的集合$R$-ones 字符串在位位置排列下保持不变，因此每个坐标出现在完整集合中完全相同数量的字符串中。 拿第一$K$任何对称排序的字符串都保持近乎均匀性：从完全对称的多重集中删除元素最多可以将列计数更改为 1，因为每个字符串都准确贡献$R$分布在$Len$位置，并且整个集合均匀分布出现次数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from math import comb

def generate(K):
    for Len in range(2, 101, 2):
        R = Len // 2
        if comb(Len, R) >= K:
            return Len, R

def next_combination(x):
    c = x & -x
    r = x + c
    return (((r ^ x) >> 2) // c) | r

def solve():
    T = int(input())
    for _ in range(T):
        K = int(input())
        Len, R = generate(K)

        mask = (1 << R) - 1
        res = []

        for _ in range(K):
            s = format(mask, f"0{Len}b")
            res.append(s)
            mask = next_combination(mask)

        print(Len)
        print(" ".join(res))

if __name__ == "__main__":
    solve()
```构造首先选择中间二项式层足够大的最小偶数长度。 这保证了我们可以选择$K$不同的恒重字符串。 

位掩码方法对 1 的位置组合进行编码。 每个整数掩码正好$R$位设置对应于一个有效命令。 这`next_combination`函数生成具有相同数量的设置位的下一个字典掩码，确保我们有效地枚举不同的字符串$O(K)$时间。 

二进制格式化步骤将每个掩码转换为固定长度的字符串，保留前导零，这很重要，因为字符串必须具有统一的长度。

 ## 边缘情况

 当$K = 1$，施工仍然必须尊重甚至$Len$。 算法正确选择$Len = 2$,$R = 1$，并输出一个有效的常量字符串。 

什么时候$K$正好等于二项式系数$\binom{Len}{Len/2}$，我们使用整个中间层。 这种情况保证了列之间的完美对称，因为不会发生截断。 

什么时候$K$刚好高于二项式阈值，则仅从下一层中获取一些组合。 列不平衡最多增加 1，因为每个添加的字符串在所有位置上贡献均匀分布的字符串，并且截断保持接近均匀性。
