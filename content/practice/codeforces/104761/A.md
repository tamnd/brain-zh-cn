 ## 解决方案
 ## 问题理解

 我们被要求找到第一象限中与原点距离恰好为的所有格点$D\sqrt{2}$。 对距离进行平方可以消除平方根，因此我们实际上是在搜索所有非负整数对$(x, y)$这样$$x^2 + y^2 = 2D^2.$$在所有这些点中，我们只输出那些$x \le y$，并且最终列表必须按递增排序$x$。 

约束条件$D \le 10^6$意味着右侧的常数可以大到$2 \cdot 10^{12}$。 尝试每一对的天真的方法$(x, y)$最多$2D$需要大约$4 \cdot 10^{12}$检查，这是完全不可行的。 甚至检查所有$x$仅价值观就给出了$2 \cdot 10^6$迭代，这是边界，但如果每次迭代都是恒定时间，那么在 Python 中仍然可以管理。 

一个更重要的微妙之处是有效的解决方案非常稀疏。 对于固定的$D$，该方程描述了半径圆上的格点$\sqrt{2}D$，并且这样的圆通常具有很少的整数点。 这种稀疏性使得$O(D)$或稍微更好的枚举可以接受。 

一个循环遍历所有内容的简单实现$x$，计算$y^2 = 2D^2 - x^2$，并检查它是否是一个完美的平方已经接近预期的解决方案，但如果以沉重的开销或不小心重复浮点平方根来实现，则会面临性能问题。 

## 方法

 解决这个问题的一种直接方法是修复一个坐标，例如$x$，并计算相应的$y$从方程$y^2 = 2D^2 - x^2$。 如果结果是完全平方数，我们就接受该对。 

这是可行的，因为每个有效的解决方案都必须完全满足方程，因此扫描所有可能的解决方案$x$保证不会遗漏任何解决方案。 然而，这种暴力扫描的执行次数可达$2D$迭代，并且在每次迭代中我们进行平方根和验证。 和$D = 10^6$，这大约是 200 万次迭代，这只是在可接受的边缘，但如果不仔细实现，Python 中的速度仍然可能很慢。 

使用高斯整数重写方程可以得到更具结构性的观察结果。 身份$$x^2 + y^2 = 2D^2$$可以分解为$$(x + iy)(x - iy) = 2D^2.$$自从$2 = (1+i)(1-i)$，我们可以将解决方案重写为以下形式$$x + iy = (1+i)(u + iv),$$扩展到$$x = u - v,\quad y = u + v.$$代入回去给出$$x^2 + y^2 = 2(u^2 + v^2),$$所以我们将问题简化为寻找整数对$(u, v)$这样$$u^2 + v^2 = D^2.$$这种变换很有用，因为它将原始约束变成了一个标准问题：在半径为 1 的圆上查找格点$D$。 每对这样的$(u, v)$直接生成解$(x, y)$，除了强制执行非负性之外，不需要进一步的过滤。 

我们现在只需要枚举解决方案即可$u^2 + v^2 = D^2$，这比扫描所有的要稀疏得多$(x, y)$对。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对 (x, y) | 进行暴力破解$O(D^2)$|$O(1)$| 太慢了 |
 | 扫描 x 并检查方块 |$O(D)$|$O(1)$| 可以接受但处于边缘|
 | 高斯简化为 (u, v) |$O(D)$最坏的情况，通常要少得多|$O(1)$| 已接受 |

 ## 算法演练

 1. 修正方程$u^2 + v^2 = D^2$，代表半径圆上的所有格点$D$。 我们将枚举所有有效的整数对$(u, v)$和$u, v \ge 0$。 
2. 迭代$u$从$0$到$D$。 对于每个值，计算$v^2 = D^2 - u^2$。 这确保我们只考虑与等式一致的候选者。 
3. 检查是否$v^2$是一个完美的正方形。 如果不是，则丢弃此$u$。 如果是，则计算$v = \sqrt{v^2}$并验证它是一个整数。 
4. 对于每个有效对$(u, v)$，使用变换构建原始问题的解决方案$$x = u - v,\quad y = u + v.$$这保证了$x^2 + y^2 = 2D^2$。 
5. 仅保留解决方案$x \ge 0$。 这个条件相当于$u \ge v$，因此我们隐式过滤无效案例。 
6. 存储每个有效的$(x, y)$对结果进行配对和排序$x$在输出之前，因为枚举顺序为$u$不严格保证排序$x$。 

### 为什么它有效

 关键的不变量是每个表示$u^2 + v^2 = D^2$恰好对应于一个有效的结构$x = u - v, y = u + v$满意的$x^2 + y^2 = 2D^2$。 变换是可逆的：任何解决方案$(x, y)$可以映射回$(u, v)$通过$u = (x + y)/2$,$v = (y - x)/2$，它必须是整数，因为$x + y$和$y - x$分享平价。 这种双射确保不会遗漏任何解决方案，也不会引入无效的解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

def solve():
    D = int(input())
    D2 = D * D
    res = []

    for u in range(D + 1):
        v2 = D2 - u * u
        if v2 < 0:
            continue
        v = int(math.isqrt(v2))
        if v * v != v2:
            continue

        x = u - v
        y = u + v

        if x < 0:
            continue

        res.append((x, y))

    res.sort()
    print(len(res))
    for x, y in res:
        print(x, y)

if __name__ == "__main__":
    solve()
```代码直接实现了归约$(u, v)$表示。 使用`isqrt`在检查完美平方时避免浮点不准确。 需要排序，因为不同$(u, v)$配对可以产生相同或无序的解决方案$x$价值观。 

条件`x < 0`在变换后强制执行所需的象限限制，并且还隐式确保我们仅保留对称解的规范一半。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import isqrt

    D = int(sys.stdin.readline())
    D2 = D * D
    res = []

    for u in range(D + 1):
        v2 = D2 - u * u

    out += [f"{x} {y}" for x, y in res]
    return "\n".join(out)

 ## 边缘情况

 一个关键的边缘情况是当$u < v$，产生负数$x = u - v$。 例如，与$u = 0, v = D$，我们得到$x = -D$，位于允许区域之外。 该算法显式过滤这些情况，这确保我们在变换后仅保留第一象限中的点。 

另一个边缘情况是当$v = 0$，对应于$u = D$。 这产生了点$(x, y) = (D, D)$，它始终有效并形成最小保证解。
