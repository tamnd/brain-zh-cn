 ## 解决方案
 ## 问题理解

 我们从一些小矩阵开始`b`。 一次镜像操作使其高度加倍。 上半部分保持不变，下半部分变为以相反顺序写入的上半部分的行。 

例如，如果当前矩阵是：```
A
B
C
```镜像后变成：```
A
B
C
C
B
A
```该过程可能会重复多次。 从未知矩阵开始`b`，经过多次镜像最终得到给定的矩阵`a`。 

任务是确定原始矩阵中可能的最小行数`b`。 

矩阵仅包含`0`和`1`，但实际值并不重要。 重要的是两行是否相同。 

限制很小。 两个维度最多为`100`，所以即使是一个`O(n^2 * m)`解决方案很容易足够快。 行比较成本`O(m)`，并且最多有`100`行，我们可以承受矩阵的多次完整扫描。 

棘手的部分是理解重复镜像在结构上实际上意味着什么。 

每次镜像后，整个矩阵变得围绕其中心对称。 再次重复该操作可以递归地保留该对称性。 这意味着最终的矩阵必须可以通过重复删除对称的一半来简化。 

一些边缘情况很容易被错误处理。 

考虑一个只有一行的矩阵：```
1 3
0 1 0
```答案是`1`。 粗心的实现可能会尝试永远缩小或假设高度必须均匀。 

另一个微妙的情况是矩阵仅在最外层对称但不是递归的：```
4 1
0
1
1
0
```答案是`2`， 不是`1`。 

整个矩阵是对称的，因此一次约简是有效的：```
0
1
```但是这个剩余的矩阵本身并不是通过镜像生成的，因为它的行不同。 

一个常见的错误是只检查整个矩阵是否对称一次。 

奇数大小的矩阵也很重要：```
3 1
0
1
0
```答案是`3`。 

镜像总是使行数加倍，因此除了原始矩阵之外的每个生成的矩阵都具有偶数高度。 自从`3`很奇怪，根本不可能进行收缩操作。 

## 方法

 蛮力方法是向后模拟该过程。 

假设我们当前有一个矩阵`k`行。 如果`k`是偶数，我们可以检查上半部分是否等于反转的下半部分。 如果这个条件成立，那么矩阵可以通过镜像其上半部分来生成，因此我们将矩阵缩小到它的第一个`k / 2`行并继续。 

最终不可能再减少，当前高度是最小的有效答案。 

为什么这有效？ 因为镜像是完全确定性的。 如果一个矩阵是由一些较小的矩阵创建的，那么它的前半部分唯一地确定后半部分。 父矩阵必须是什么从来没有含糊之处。 

暴力法在这里已经足够快了。 每次减少时我们最多比较`n / 2`行对，以及每行比较成本`O(m)`。 由于高度每次都会减半，因此总工作量受以下限制：```
n*m + (n/2)*m + (n/4)*m + ...
```这是`O(n*m)`全面的。 

关键的观察结果是重复镜像会产生递归对称性。 有效的约简不仅仅是当前矩阵对称一次。 约简后，较小的矩阵必须再次满足相同的性质。 

这种递归结构使得贪婪归约达到最优。 只要可以减少，立即采取它永远不会有坏处，因为任何有效的原始矩阵都必须位于前半部分内。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力递归检查| O(n²·米) | O(1) | O(1) | 已接受 |
 | 最优迭代减半 | O(n·m) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 逐行读取矩阵。 
2. 设当前行数为`k = n`。 
3.同时`k`是偶数，尽量减少矩阵。 
4.比较行`i`从上半部分开始`k - 1 - i`从下半部分开始`0 ≤ i < k/2`。 

这会检查下半部分是否与上半部分正好相反，这是镜像矩阵的定义。 
5. 如果任何一对不同，请立即停止。 

当前矩阵无法通过再一次镜像操作来生成，因此不可能进一步减少。 
6. 如果所有对都匹配，则替换`k`和`k / 2`。 

该矩阵可能是从其上半部分生成的，因此我们继续寻找更小的原点。 
7.当循环停止时，输出`k`。 

### 为什么它有效

 该算法保持了第一个不变式`k`行形成一个有效的候选矩阵，可以在一定数量的镜像后生成原始输入。 

每当矩阵满足镜像属性时，唯一可能的先前状态是其上半部分。 缩小到那一半可以保持正确性。 

如果镜像属性失败，则不存在更小的前驱。 任何镜像操作总是在两半之间创建完美的反向对称，因此违反此条件使得进一步减少变得不可能。 

因为每次成功的归约都会严格将矩阵减半，所以该过程最终会达到尽可能小的大小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = [input().split() for _ in range(n)]

    k = n

    while k % 2 == 0:
        half = k // 2
        ok = True

        for i in range(half):
            if a[i] != a[k - 1 - i]:
                ok = False
                break

        if not ok:
            break

        k = half

    print(k)

solve()
```该矩阵存储为行列表。 每行都保存为字符串列表，因为我们只需要行之间的相等比较。 

变量`k`代表当前的活动高度。 最初它等于`n`，完整矩阵高度。 

在循环内部，我们仅在以下情况下尝试减少：`k`是均匀的。 镜像总是使行数加倍，因此奇数大小的矩阵无法进一步减少。 

比较：```
a[i] != a[k - 1 - i]
```直接检查所需的对称性。 上半部分的顶行必须与下半部分的底行匹配，第二行必须与倒数第二行匹配，依此类推。 

一个微妙的细节是我们从不物理地创建更小的矩阵。 我们简单地减少`k`。 相关行始终位于第一行`k`原始数组的行。 

另一个容易犯的错误是比较：```
a[i] != a[half + i]
```它检查普通回文一半而不是镜像一半。 下半部分必须以相反的顺序出现。

 ## 边缘情况

 考虑奇数高度的情况：```
3 1
0
1
0
```该算法开始于`k = 3`。 自从`k`是奇数，循环永远不会开始，答案仍然存在`3`。 

这是正确的，因为镜像总是使行数加倍。 没有任何镜像序列可以从较小的矩阵产生奇数大小的矩阵。 

现在考虑仅在一级对称的矩阵：```
4 1
0
1
1
0
```该算法检查：```
row0 == row3
row1 == row2
```两者都成功了，所以`k`变成`2`。 

接下来它检查：```
row0 == row1
```这失败了，所以算法停止并输出`2`。 

这说明了为什么递归检查很重要。 单个对称层不足以完全减小尺寸`1`。 

最后，考虑所有行都相等：```
8 1
1
1
1
1
1
1
1
1
```每次对称性检查都会成功：```
8 -> 4 -> 2 -> 1
```算法正确输出`1`，最小可能的原始矩阵。
