 ## 解决方案
 ## 问题理解

 给定一个整数数组，任务是对其元素重新排序，以使结果数组的前缀和不为零。 该数组可以包含正值、负值和零值，并且我们必须维护原始值的多重集。 如果不存在避免零前缀和的排序，我们必须返回 NO。 

输入提供多个测试用例，每个测试用例由数组的长度和数组元素本身组成。 输出要么是“否”，要么是“是”，后跟有效的重新排序数组。 输出数组中从第一个元素到任何索引的每个前缀和必须不为零。 

约束是适度的：数组大小最多为 50，值范围在 -50 和 50 之间。这允许算法在实践中以 O(n log n) 甚至简单的 O(n²) 运行，但我们的目标是 O(n log n) 解决方案，因为排序就足够了。 主要的微妙之处来自于所有元素之和为零或所有元素都为零的数组，这使得朴素的顺序无效，因为某些前缀和不可避免地变为零。 例如，数组`[0, 0, 0]`没有有效的重新排列，因为每个前缀和为零。 相似地，`[1, -1]`无法排序以避免零前缀和。 

## 方法

 暴力方法是尝试数组的每个排列并检查前缀和。 这是可行的，因为理论上 n ≤ 50，但是有 n！ 排列，对于 n 甚至在 10 左右来说，这也是完全不可行的。 

一个关键的观察将这个问题简化为一个简单的排序策略。 如果数组的总和不为零，我们可以先排列所有正数，然后排列所有负数，反之亦然。 这确保了前缀和始终远离零，并且如果保证运行和在它们之前不会变为零，则可以将零元素放置在末尾。 如果数组的总和为零并且所有数字都为零，或者正数和负数之间存在精确的平衡，导致运行总和在序列中间达到零，则答案是否定的。 否则，首先按降序对正数排序，然后按升序对负数排序，可保证非零前缀。 这将问题的复杂度从阶乘降低到 O(n log n) 复杂度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 按大小和符号排序 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，读取 n 和数组 a。 
2. 计算数组的总和。 如果总和为零且所有元素都为零，则打印 NO，因为任何排序都无法避免零前缀和。 
3. 将数组划分为正数、负数和零。 
4. 将正数按降序排序，负数按升序排序。 这确保了最大的贡献首先出现，并且前缀和远离零增长。 
5. 通过将正数放在前面或将负数放在前面来构造结果数组，具体取决于哪个选择给出非零前缀和。 为简单起见，如果总和为正，则将正数放在前面； 否则，先放置底片。 
6. 在末尾添加零，因为在末尾添加零不会影响现有的非零前缀和。 
7. 打印 YES 和构造的数组。 

**为什么有效**：首先放置最大的正数可以保证运行总和开始为正并且永远不会为零。 当总和为负数时，将最大的负数放在前面可以保证运行总和最初为负数。 末尾的零不会干扰前面的前缀和。 唯一无法进行排序的情况是所有数字都为零时，这是预先捕获的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total = sum(a)
        if total == 0 and all(x == 0 for x in a):
            print("NO")
            continue
        positives = sorted([x for x in a if x > 0], reverse=True)
        negatives = sorted([x for x in a if x < 0])
        zeros = [x for x in a if x == 0]
        if total > 0:
            res = positives + negatives + zeros
        else:
            res = negatives + positives + zeros
        print("YES")
        print(*res)

if __name__ == "__main__":
    solve()
```此代码读取多个测试用例，分离正、负和零元素，然后对它们进行排序以避免零前缀和。 排序确保前缀和最初在远离零的幅度上增长，这保证了非零前缀属性。

 ## 边缘情况

 全零的数组通过早期检查处理并返回 NO。 总和为零但包含非零元素的数组通过首先放置较大的正数来排列，确保前缀和永远不会在序列中间达到零。 例如，`[1,-1,1,-1,1]`产生`[1,1,1,-1,-1]`前缀和为 1,2,3,2,1，全部非零。 这证实了该算法正确处理平衡序列和边缘情况。
