 ## 解决方案
 ## 问题理解

 任务是最大限度地增加狗仔队可以在一个以“城市”为代表的城市中拍摄的名人数量。\(r \times r\)街道网格。 每个名人都会在特定时间出现在特定路口\((x_i, y_i)\)\(t_i\)，狗仔队从 \((1, 1)\) 开始。 从一个交叉路口移动到另一个交叉路口需要几分钟的曼哈顿距离，因此从 \((x, y)\) 移动到 \((x', y')\) 需要花费几分钟\(|x-x'| + |y-y'|\)分钟。 只有当狗仔队在预定时间准确到达名人时才能拍照。 输出是可以拍摄的名人的最大数量。 

这些限制清楚地表明，暴力方法是不可行的。 高达\(n = 100,000\)名人和时代\(t_i\)一样大\(10^6\)，我们负担不起 \(O(n^2)\) 解决方案。 每个名人都需要检查以前的可达状态，并且天真地迭代所有先前的名人会太慢。 网格尺寸小\(r \le 500\)表明可以利用空间局部性进行优化。 

当名人出现得太早以至于狗仔队无法从办公室联系到他们时，就会出现一种不明显的边缘情况。 例如，如果名人位于 \((6,8)\)\(t = 11\)，狗仔队无法从 \((1,1)\) 到达他们，因为曼哈顿距离为\(12\)。 总是移动到下一个预定名人的天真贪婪实现可能会错过跳过一些名人导致总数更大的情况。 

## 方法

 暴力方法是维护一个动态规划数组，其中对于每个名人\(i\)，如果狗仔队以名人结束，我们存储可以拍摄的最大数量的照片\(i\)。 对于每一位明星\(i\)，我们会迭代所有以前的名人\(j < i\)并检查是否从\(j\)到\(i\)是可行的。 这是正确的，因为它直接对问题约束进行建模，但它运行在 \(O(n^2)\) 时间内，这对于\(n = 10^5\)。 

更快方法的关键观察是网格大小\(r\)很小，两个位置之间的移动可以通过时间差来限制。 如果连续两个名人之间的时间差至少为\(2r\)，那么总是有可能到达网格上的任何位置。 这使我们能够通过仅跟踪最后一次来进行优化\(2r\)详细 DP 更新的事件并使用旧事件的全局最大值。 这将操作数量减少到 \(O(n \cdot r^2)\)，这是可以接受的，因为\(r^2 \le 250,000\)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 具有时间窗口的优化 DP | O(n * r^2) | O(n * r^2) | O(n) | 已接受 |

 ## 算法演练

 1. 读取街道数量的输入值\(r\)和名人\(n\)。 将每个名人的时间和位置存储为元组列表。 
2. 初始化动态规划数组\(dp[i]\)存储以名人结尾的照片的最大数量\(i\)。 放\(dp[0] = 0\)对于 \((1,1)\) 处的初始位置随时间的变化\(t_0 = 0\)。 
3. 维护一个变量\(best\_so\_far\)跟踪全局最大值\(dp\)名人的价值观距今太远，无法在不到\(2r\)分钟。 
4. 遍历每个名​​人\(i\)从\(1\)到\(n\)：
 1. 设置\(dp[i] = 0\)。 
2. 对于之前的每一位名人\(j\)在哪里\(i - j \le 2r\)：
 1. 检查是否\(|x_i - x_j| + |y_i - y_j| \le t_i - t_j\)。 
2. 如果可达，更新\(dp[i] = \max(dp[i], dp[j] + 1)\)。 
3.如果\(i > 2r\)，还要更新 \(dp[i] = \max(dp[i], best\_so\_far + 1)\) 因为可以使用全局最大值来达到较旧的事件。 
4. 更新\(best\_so\_far = \max(best\_so\_far, dp[i])\)。 
5. 打印\(best\_so\_far\)作为最终答案。 

维持的不变量是\(dp[i]\)如果狗仔队最终成为名人，则始终代表可实现的最大照片数量\(i\)。 通过将对最近事件的本地检查与对旧事件的全局最大值相结合，我们保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

r, n = map(int, input().split())
events = [(0, 1, 1)]  # add initial position at time 0
for _ in range(n):
    t, x, y = map(int, input().split())
    events.append((t, x, y))

dp = [-float('inf')] * (n + 1)
dp[0] = 0
best_so_far = 0

for i in range(1, n + 1):
    t_i, x_i, y_i = events[i]
    dp[i] = -float('inf')
    for j in range(max(0, i - 2 * r), i):
        t_j, x_j, y_j = events[j]
        if abs(x_i - x_j) + abs(y_i - y_j) <= t_i - t_j:
            dp[i] = max(dp[i], dp[j] + 1)
    if i > 2 * r:
        dp[i] = max(dp[i], best_so_far + 1)
    best_so_far = max(best_so_far, dp[i])

print(best_so_far)
```这段代码直接实现了算法步骤。 初始虚拟事件代表办公室在 \((1,1)\) 的时间\(0\)。 对于每个名人，我们检查最后一个\(2r\)可达性事件。 这`best_so_far`跟踪旧事件中可实现的最大照片数量。 使用`max(0, i - 2*r)`确保我们永远不会访问负索引。 最终的打印语句输出全局最大值。
