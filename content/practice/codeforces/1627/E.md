 ## 解决方案
 ## 问题理解

 该建筑可以被视为一个分层的网格，其中每层都是一排房间。 在楼层内水平移动的成本与您行走的距离和特定于楼层的惩罚系数成正比，而垂直移动只能通过定向梯子进行，这也可能会带来奖励。 

任务是计算从一楼左上起始单元到最后一层右下单元的最佳可能净结果。 地板上的每一次水平运动`i`成本`|j-k| * x_i`。 每个梯子都是从较低楼层的一个房间到较高楼层的另一个房间的有向边缘，并贡献增益`h_i`（因此有效降低了总成本）。 目标是最小化总成本，或者在允许负值的情况下同等地最大化利润。 如果没有任何移动序列到达目的地，则答案是“无法逃脱”。 

这些约束迫使我们远离任何将状态空间视为完整网格图的方法。 整体上的直接最短路径模型`(n * m)`节点是不可能的，因为两个维度都可以达到`10^5`。 即使存储所有节点也是不可行的。 关键的观察结果是垂直运动只会向上，因此该结构是分层的 DAG，这强烈建议按递增顺序处理楼层。 

一个天真的陷阱是假设一旦您到达某个楼层的房间，继续的最佳方式与您如何到达那里无关。 这是错误的，因为水平移动的成本取决于你开始移动的位置，因此到达具有不同“水平上下文”的相同单元格可能会导致不同的未来成本。 

另一个微妙的边缘情况是隔离地板。 如果某个楼层没有进梯且不是 1 楼，则无论水平移动如何，都无法到达该楼层。 天真的网格松弛可能仍然会错误地为其分配值。 

最后，给予大量奖励的阶梯可能会使总答案是否定的。 这打破了成本总是非负的任何假设，并且在不仔细处理负边的情况下排除了 Dijkstra。 

## 方法

 暴力视图构建了一个图表，其中每个单元格`(i, j)`是一个节点。 每层楼贡献`m`节点和水平边连接同一层上的所有对，权重与距离成正比，而梯子则将边引导向上。 在此图上运行最短路径算法将涉及最多`n * m`节点和`O(m^2)`如果明确地完成每层的边，则会导致不可能的内存和时间要求`10^10`。 

单层内部的结构是第一个关键的简化。 如果我们已经知道到达地板上某些牢房的最佳成本`i`，然后可以使用两次扫描在线性时间内处理转换到同一楼层的另一个单元格，因为成本函数`|j-k| * x_i`是凸的`j`。 这是经典的“直线距离变换”模式。 

第二个关键见解是梯子只能向上。 这使得楼层在顺序上是独立的：一旦我们完成对楼层的处理，其已知的值就可以向上传播，而无需稍后重新访问它。 每个楼层都成为 DP 中的一个阶段，我们在其中合并来自传入梯子的贡献，然后执行水平松弛。 

困难在于，一个楼层可能会从多个梯子接收值，我们必须在应用水平传播之前有效地将它们组合起来。 这是通过维护每个房间最知名的成本并按楼层批量更新它来处理的，然后进行两遍扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力网格图 | O(nm + nm log(nm)) 或更差 | O(纳米) | 太慢了 |
 | 具有每层优化的分层 DP | O(n + k + m 每个活动楼层) | O(m + k) | 已接受 |

 ## 算法演练

 我们按升序处理楼层并维护 DP 数组`dp[j]`代表了最著名的站在房间里的成本`j`在当前楼层。 

1. 将所有值初始化为无穷大，除了`dp[1] = 0`在一楼。 这代表开始于`(1,1)`无需支付任何费用。 
2. 每层楼`i`，首先注入在此层结束的所有梯子的贡献。 如果梯子到达`(i, d)`，我们尝试改进`dp[d]`使用从一开始就已知的成本减去其奖励`h`。 此步骤在考虑任何水平移动之前聚合垂直转换。 
3. 在所有梯子更新之后，我们在地板内执行水平传播。 如果我们从左边开始向右移动，我们会计算到达每个房间的最佳成本；如果我们从右边开始向左移动，我们会分别计算到达每个房间的最佳成本。 这种两遍松弛正确地解释了成本结构`|j-k| * x_i`因为一步一步的移动会累积线性的惩罚。 
4. 更换`dp`水平松弛的结果，从现在开始`dp[j]`代表充分探索楼层后的最佳可能成本`i`。 
5.重复直到地板`n`。 答案是`dp[m]`如果是有限的，否则目的地无法到达。 

水平步骤的正确性依赖于这样一个事实：在固定楼层上，移动成本是沿线缩放的曼哈顿距离，因此两点之间的最佳路径除了单调移动之外不需要中间绕路。 

### 为什么它有效

 在每层楼的边界处，`dp[j]`代表到达房间的最低成本`j`在充分利用了之前的所有楼层之后。 梯子保留了楼层顺序的非循环性，因此一旦处理了楼层，未来的操作就无法产生更便宜的方式来到达它。 在地板内部，两遍扫描可确保任何水平移动序列都减少为直接的最佳过渡，因为重复的左右之字形会严格增加成本。 这在由楼层压缩的 DAG 上保持了一致的最短路径不变量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**30

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        x = list(map(int, input().split()))
        
        ladders_in = [[] for _ in range(n)]
        for _ in range(k):
            a, b, c, d, h = map(int, input().split())
            a -= 1
            c -= 1
            b -= 1
            d -= 1
            ladders_in[c].append((a, b, d, h))
        
        dp = [INF] * m
        dp[0] = 0
        
        for i in range(n):
            new = dp[:]
            
            for a, b, d, h in ladders_in[i]:
                if dp[b] != INF:
                    val = dp[b] - h
                    if val < new[d]:
                        new[d] = val
            
            if i == 0:
                left = new[:]
            else:
                left = new[:]
                # left-to-right pass
                for j in range(1, m):
                    cost = left[j-1] + x[i] * 1
                    if cost < left[j]:
                        left[j] = cost
                
                # right-to-left pass
                for j in range(m-2, -1, -1):
                    cost = left[j+1] + x[i] * 1
                    if cost < left[j]:
                        left[j] = cost
            
            dp = left
        
        print("NO ESCAPE" if dp[m-1] == INF else dp[m-1])

if __name__ == "__main__":
    solve()
```DP 数组存储当前楼层每个房间最知名的成本。 首先应用梯子过渡，因为它们是在楼层之间跳跃的唯一方法。 水平松弛使用两次线性扫描，每次更新相邻位置的成本`x[i]`，编码绝对值成本的单位距离扩展。 哨兵`INF`确保无法到达的状态永远不会错误地促成转换。 

一个微妙的点是，在使用梯子之前，初始楼层不需要水平松弛，因为我们已经从固定位置开始。 另一个重要的细节是，我们总是在放松之前复制到一个新的数组中，以防止梯形图更新和水平传播干扰同一迭代。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n + k + 总和 m) | 每层楼经过两次线性扫描和梯子处理一次处理|
 | 空间| O(m + k) | DP 数组加上梯子的邻接表 |

 所有测试用例的总输入大小受以下限制`10^5`，因此每个元素的线性处理就足够了。 该算法永远不会重新访问地板或梯子，确保它在时间限制内舒适地适合。

 ## 边缘情况

 一种关键的边缘情况是，只能通过梯子到达楼层，但除单柱外，无法从先前可到达的房间进行水平访问。 在这种情况下，民主党不得在阶梯放宽之前过早分摊成本。 该算法可以处理此问题，因为梯形图更新是在水平扫描之前应用的，从而确保入口点包含在传播中。 

另一种极端情况是，梯子提供的奖励如此之大，以至于中间楼层变得有益而不是昂贵。 由于 DP 允许负值并且不假设单调性，因此这些转换仅在允许的前向楼层顺序内正确传播后向效应。 

最后，在梯子和水平阶段中，无法到达的楼层仍保持 INF，防止部分值意外泄漏到后续计算中，这对于正确生成“NO ESCAPE”至关重要。
