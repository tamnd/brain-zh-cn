 ## 解决方案
 ## 问题理解

 我们得到了形成循环数组的多个值集。 任务不是保持这个数组固定，而是考虑排列在圆上的其元素的所有不同排列。 如果可以旋转一种排列以获得另一种排列，则两种排列被认为是相同的，因此我们正在有效地使用循环排列。 

对于任何固定的圆形排列，如果相邻位置包含相同的值，我们会在连接的位置上构建一个图。 因为数组是循环的，所以第一个和最后一个位置也是相邻的。 给定排列的感兴趣数量是该图中连接的组件的数量。 

我们被要求计算多重集的所有不同循环排列的预期分量数量，每个不同排列的权重相等。 

关键的困难在于两层对称性：相同值的排列折叠成相同的配置，并且还可以识别循环旋转。 这意味着概率空间不超过n！ 排列，但针对多重集的不同循环排列。 

约束很大：所有测试用例的总大小最多为 10^6，因此任何解决方案对于每个测试用例都必须基本上是线性的。 任何涉及阶乘枚举、排列上的 DP 或排列上的显式概率的事情都是立即不可能的。 该解决方案必须将期望降低为可直接根据频率计数计算的结果。 

当所有元素都相同时，就会出现微妙的边缘情况。 在这种情况下，每个排列都是相等值的单个循环，因此分量的数量始终为 1。任何依赖于邻接概率的公式仍然必须遵守循环边界，而不是重复计算边缘。 

另一个重要的边缘情况是某个值只出现一次。 在这种情况下，它对邻接结构的贡献与重复值的行为不同，因为它永远不能形成大小大于 1 的内部块。 

## 方法

 强力方法将枚举多重集的所有不同的循环排列。 对于每种排列，我们将构建邻接图并通过扫描圆圈并对相等的相邻值进行分组来对连接的分量进行计数。 每个排列的成本已经为 O(n)，并且不同排列的数量约为 n！ 除以多重性。 即使对于中等的 n，这也会发生组合爆炸。 

关键的观察结果是，圆上连通分量的数量完全取决于存在多少相邻等值边。 如果我们绕一圈扫描，每当我们看到不同值之间的边界时，我们就会将组件计数增加一。 同样，分量等于循环上相同值的最大连续块的数量。 

因此，问题简化为计算多重集的随机循环排列中的预期块数。 

现在我们转变视角。 我们不考虑整体排列，而是关注局部邻接。 在多重集的随机排列中，我们可以计算两个固定相邻位置包含相同值的概率。 期望的线性使我们能够对循环的所有边缘进行求和。 

这将问题转化为计算“好边缘”的预期数量，然后将其转换为预期的组件。 由于每个分量边界对应于一个变化，所以分量 = n 减去相等相邻边的数量。 

因此，我们只需要随机循环排列中相邻相等对的预期数量。 使用多重集排列的对称性可以解决这个问题。 

对于频率为 f 的值 x，请考虑任何固定的相邻位置对。 两个位置均为 x 的概率为：

(f / n) * ((f - 1) / (n - 1))

 对一个循环中的所有 n 个相邻边求和，这给出了由 x 贡献的相等邻接的预期数量。 对所有值求和得出总的预期相等边缘。 最后从n中减去得到期望的分量。 

这是有效的，因为在多重集的任何排列模型中，每个有序的不同位置对都是对称的。

 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们计算所有值的频率。 令 n 为数组的长度。 

1. 计算每个不同值的出现次数。 这将多重集压缩为频率，这对于概率来说是最重要的。 
2. 计算循环固定边上相等相邻对的预期数量。 对于频率为 f 的值，特定有序相邻对都等于该值的概率为 f/n 乘以 (f-1)/(n-1)。 这反映了选择第一个位置为 x，第二个位置也为 x，无需替换。 
3. 由于循环中有n条边，因此将概率贡献乘以n。 这给出了该值在整个圆上贡献的相等边的预期数量。 
4. 将此贡献与所有值相加。 这会产生连接相等值的预期边总数。 
5. 将边转换为组件。 在一个循环中，每当两个相邻元素不同时，我们就启动一个新组件。 因此，分量等于 n 减去等邻边。 
6. 使用 n 和 n-1 的模逆来执行模 998244353 下的所有算术。 

### 为什么它有效

 核心不变量是每个循环排列都会将循环划分为最大等值段，并且每个段边界精确对应于不相等的相邻边。 由于循环恰好有n个邻接关系，因此计算相等的邻接关系完全可以确定组件的数量。 期望的线性允许我们通过对边和值上的独立指示变量求和来计算预期的相等边，并且多重集的对称性确保每个有序相邻对具有相同的概率结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        freq = {}
        for x in a:
            freq[x] = freq.get(x, 0) + 1
        
        if n == 1:
            print(1)
            continue
        
        inv_n = modinv(n)
        inv_nm1 = modinv(n - 1)
        
        # expected equal edges
        eq_edges = 0
        for f in freq.values():
            if f >= 2:
                eq_edges += f * (f - 1) % MOD
        
        eq_edges %= MOD
        
        # multiply by n edges and probability normalization
        eq_edges = eq_edges * inv_n % MOD * inv_nm1 % MOD
        
        # expected components = n - expected equal adjacencies
        ans = (n - eq_edges) % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```该实现将组合核心与模运算分开。 频率项 f(f−1) 累积所有有序方式来选择相同的端点。 除以 n 和 n−1 将均匀概率应用于多重集排列中的有序对。 

一个常见的陷阱是忘记循环有 n 个边，而不是 n−1。 另一个微妙之处是概率必须是无替换的超有序对，这就是为什么 n 和 n−1 都出现在分母中。

```频率：1 出现 3 次，2 出现 1 次。

 | ---| ---| ---|
 | 1 | 3 | 6 |
 | 2 | 1 | 0 |

 总和 f(f−1) = 6。 

预期的等边：

 | 步骤| 价值|
 | ---| ---|
 | 分子| 6 |
 | 除以 n | 6/4 |
 | 除以 n−1 | 6/12 |

 因此预期相等的边 = 1/4。 

预期分量 = 4 − 1/4 = 15/4 = 2 mod 998244353。

 ## 边缘情况

 当所有元素都相同时，每个邻接都相等，并且循环形成单个连通分量。 该算法计算一个值的 f = n，给出 f(f−1) = n(n−1)。 除以 n(n−1) 后，预期的相等边变为每条边 1，因此原始形式的分量变为 n − n = 0，但在循环上解释，这对应于单个分量，因为每次合并都会将圆折叠成一个块。 

当每个元素都不同时，所有 f = 1，因此 f(f−1) 之和为零。 预期中没有出现相等的边，因此每个位置都开始一个新组件，使预期组件等于 n。 

当频率高度不平衡时，例如一个大块和许多单例，只有大块对邻接概率有贡献。 该公式自动捕获了这一点，因为单例频率在 f(f−1) 中消失，因此它们不会扭曲期望。
