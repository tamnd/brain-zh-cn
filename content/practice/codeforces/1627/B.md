 ## 解决方案
 ## 问题理解

 我们有一个用网格表示的教室，$n$行和$m$列。 每个牢房都是一个座位。 蒂娜可以准确地画画$k$粉红色的座位，哪里$k$范围从 0 到$n \cdot m - 1$。 然后拉胡尔选择一个座位，避免涂漆的座位，目标是尽可能靠近蒂娜。 蒂娜在拉胡尔之后选择了座位，试图最大限度地拉开他们之间的距离。 任务是，对于每一个$k$，确定 Rahul 和 Tina 之间的最小可能距离，假设两者都表现最佳。 

座位之间的距离是曼哈顿距离，$|r_1 - r_2| + |c_1 - c_2|$。 关键输入值是网格尺寸，输出是距离列表，每个距离一个$k$。 

限制因素很大。$n \cdot m$可以达到$10^5$，以及总和$n \cdot m$所有测试用例也受$10^5$。 这意味着任何$O((n \cdot m)^2)$方法会太慢。 我们必须找到一种与座位数量线性或接近线性缩放的方法。 边缘情况包括窄网格，例如$1 \times m$或者$2 \times 2$，如果处理不当，可能会产生不直观的距离序列。 

## 方法

 暴力方法将模拟每个过程$k$。 对于每个$k$，我们可以迭代所有组合$k$要绘制的座位，然后是拉胡尔的所有剩余座位，然后计算蒂娜的最佳座位。 这在原则上是正确的，但其复杂性是指数级的$n \cdot m$，这对于$n \cdot m = 10^5$。 

关键的观察结果是，网格中的距离最大化和最小化是由座椅相对于角落的位置驱动的。 相距最远的座位总是网格角的某种组合。 由于曼哈顿距离是线性的，因此策略选择减少为选择角落内或附近的座位。 这一观察结果使我们能够预先计算距角点的距离并对它们进行排序。 我们可以计算距每个角的曼哈顿距离，并确定之后剩余的最大可能距离，而不是模拟每个油漆选择$k$座位是“涂漆”的。 

我们可以通过相对于四个角的坐标来表示座位，对值进行排序，然后对于每个座位$k$，选择$k$- 绘制后产生最大距离的最大组合。 这将复杂性从指数降低到$O(n \cdot m \log(n \cdot m))$每个测试用例由于排序而变化，考虑到问题的限制，这是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^{n*m}) | O(2^{n*m}) | O(n*m) | 太慢了 |
 | 最佳| O(n_m log(n_m)) | O(n_m log(n_m)) | O(n*m) | 已接受 |

 ## 算法演练

 1.通过坐标枚举所有座位$(r, c)$为了$r \in [1, n]$,$c \in [1, m]$。 
2. 对于每个座位，计算其到所有四个角的曼哈顿距离：$(1,1)$,$(1,m)$,$(n,1)$， 和$(n,m)$。 座位的有效“值”是这四个距离中的最大值，因为拉胡尔想要坐得离蒂娜最近，而蒂娜想要最大化距离。 
3. 将所有座位的最大距离值收集到一个列表中。 这代表了如果蒂娜没有粉刷任何座位，拉胡尔可能面临的“最坏情况”距离。 
4. 按降序排列此列表。 最大值对应于$k = 0$（无油漆），第二大值对应于$k = 1$（一个座位涂漆）等等。 逻辑是蒂娜将首先绘制最大距离最高的座位，以最小化拉胡尔的最小距离。 
5. 逆序输出排序后的值$k = 0$到$n \cdot m - 1$，形成拉胡尔可以达到的最小距离序列$k$。 

### 为什么它有效

 不变的是，在曼哈顿网格中，两点之间的最大距离总是在其中一个角处实现。 通过考虑每个座位到各个角落的距离并进行排序，我们可以系统地确定蒂娜策略性涂漆后拉胡尔可以达到的最小距离$k$座位。 排序确保每个增量$k$移除当前对最大化距离最有效的座位，这对应于蒂娜的最优选择。 这保证了正确性，而无需显式模拟每个座位排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        seats = []
        for r in range(1, n+1):
            for c in range(1, m+1):
                dist = max(
                    r-1 + c-1,
                    r-1 + m-c,
                    n-r + c-1,
                    n-r + m-c
                )
                seats.append(dist)
        seats.sort()
        print(' '.join(map(str, seats)))

if __name__ == "__main__":
    solve()
```代码首先读取测试用例的数量。 对于每个测试用例，它枚举所有座位，计算到四个角的最大曼哈顿距离，存储这些距离，按升序对它们进行排序，然后打印它们。 按升序排序可确保第一个元素对应于$k = 0$，下一个元素$k = 1$， 等等。 我们不需要模拟蒂娜的绘画或拉胡尔的选择，因为排序的距离隐式编码了最佳游戏。
