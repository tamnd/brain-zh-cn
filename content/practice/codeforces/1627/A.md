 ## 解决方案
 ## 问题理解

 我们得到一个大小最大为 50 x 50 的小网格，其中每个单元格都是黑色或白色。 从任何黑色单元格中，我们都可以执行一项以非常特定的方式传播黑色的操作：我们选择一个黑色单元格，然后将其整行涂成黑色或将其整列涂成黑色。 每一个这样的动作都会花费一步。 

目标是使用尽可能少的操作使特定目标单元变黑。 我们不会被要求重新绘制整个网格，只是为了确保在应用这些扩展操作后一个固定坐标变黑。 

约束足够小，甚至检查每个测试用例的许多可能性也是可行的。 最多有 100 个测试用例，网格大小最多为 50 x 50，$O(nm)$甚至$O(nm(n+m))$解决方案会足够快。 

主要的微妙之处在于操作只能从现有的黑色单元触发。 这会产生依赖性：如果行或列不包含黑色单元格，则它不能用于扩展任何内容。 

一些边缘情况很容易出错：

 如果目标单元格已经是黑色，则答案为零。 即使不需要任何操作，总是尝试“传播”的简单解决方案可能会错误地返回 1。 

如果目标行或目标列中没有黑色单元格，则任何操作都不会影响目标单元格。 例如：```
3 3
WWW
WWW
WWW
target = (2,2)
```正确答案是 -1，因为任何操作都无法启动，因为任何地方都没有黑色单元格。 

更微妙的情况是目标单元格为白色，但其行和列都已包含黑色单元格。 答案不会自动是 1 或 2；而是 这些黑色细胞所在的结构很重要。 

## 方法

 暴力方法会尝试模拟所有可能的操作序列。 从每个黑色单元格中，我们可以扩展其行或列，从而产生新的网格状态。 我们重复此操作，直到目标单元格变黑。 这实际上是基于网格配置的 BFS。 

问题是每个操作都会极大地改变网格，并且可能状态的数量增长得非常快。 尽管网格很小，但状态空间的操作数量呈指数级增长，使得这种方法不可行。 

关键的观察是我们永远不需要跟踪完整的网格状态。 重要的是我们是否可以达到这样的配置：某些行或列包含可以“覆盖”目标的黑色单元格。 

如果目标单元格已经是黑色，我们就完成了。 

如果没有，我们检查是否存在与目标同一行或同一列的黑色单元格。 如果存在这样的单元格，那么一个操作就足够了：我们可以选择该单元格并绘制其行或列以覆盖目标。 

如果目标行和目标列都不包含任何黑色单元，那么即使经过任意次数的操作，也无法引入与目标对齐的黑色单元。 在这种情况下，答案是不可能的。 

这将问题简化为目标行和列中的简单存在检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（状态 BFS）| 指数| 指数| 太慢了 |
 | 最佳（行/列扫描）|$O(nm)$|$O(1)$| 已接受 |

 ## 算法演练

 1.读取网格并定位目标单元格$(r, c)$。 为了方便起见，将索引调整为从零开始。 这允许直接访问数组。 
2. 如果目标单元格已经是黑色，则输出0。不需要任何操作，因为目标已经满足。 
3. 扫描整行$r$。 如果该行中至少有一个单元格为黑色，则记录该行具有可用源。 
4. 扫描整列$c$。 如果该列中至少有一个单元格为黑色，则记录该列具有可用的源。 
5. 如果行和列都不包含任何黑色单元格，则输出-1。 没有任何起点可以影响目标位置。 
6. 否则，输出1。单个操作就足够了，因为同一行或列中的黑色单元格可以直接扩散到目标。 

### 为什么它有效

 任何操作都必须源自黑色单元。 在单次移动中影响目标单元格的唯一方法是选择共享其行或列的黑色单元格，因为这些是通过该行传播的唯一操作。 如果存在这样的黑色单元格，则一项操作会立即强制目标变为黑色。 如果任一维度都不存在，则任何操作序列都无法创建必要的对齐，因为操作永远不会在已可达的行或列之外引入黑色单元。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m, r, c = map(int, input().split())
    r -= 1
    c -= 1

    grid = [input().strip() for _ in range(n)]

    if grid[r][c] == 'B':
        print(0)
        continue

    row_has_black = any(ch == 'B' for ch in grid[r])
    col_has_black = any(grid[i][c] == 'B' for i in range(n))

    if row_has_black or col_has_black:
        print(1)
    else:
        print(-1)
```实现直接遵循算法。 第一个检查处理不需要工作的简单情况。 行和列扫描是简单的线性扫描。 关键的决定是最终条件：任一维度的存在都保证单个操作就足够了，因为可以选择黑色单元作为操作的源。 

必须小心索引，因为输入使用从 1 开始的坐标。 尽早转换可以避免重复调整。

 ## 边缘情况

 没有黑色单元格的网格表明对现有来源的严格依赖。 该算法正确检查行和列，但两者都没有找到，产生 -1。 

在任何扫描之前，都会在恒定时间内处理目标本身为黑色的网格，从而防止不必要的计算。 

仅列包含黑色单元格的网格仍然允许有效操作，因为选择该单元格并绘制其列会直接影响目标。 列的扫描保证检测到这种情况。 

存在黑色单元格但与目标行和列隔离的网格正确地产生 -1，因为没有任何操作可以在允许的移动下弥合该间隙。
