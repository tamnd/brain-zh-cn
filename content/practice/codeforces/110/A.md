 ## 解决方案
 ## 问题理解

 我们给定一个正整数，需要判断它是否是一个接近幸运的数字。 如果一个数字的幸运数字（数字等于 4 或 7）本身就是一个幸运数字，则该数字被视为接近幸运数字。 幸运数字的十进制表示形式仅包含 4 和 7。 例如，数字 40047 包含三个幸运数字（两个 4 和一个 7），并且由于 3 不是一个幸运数字，因此 40047 并不接近幸运。 另一方面，44777有五个幸运数字，因为5不是幸运数字，所以它还算不上幸运数字。 

输入范围最大为 10^18。 这意味着我们不能假设该数字适合 32 位整数，但 Python 可以自然地处理任意长度的整数。 我们也不能迭代直到 n 的所有数字，也不能对其数字执行一次以上的操作，因为 n 的长度最多可达 18 位数字。 因此，我们的算法必须以相对于位数的线性时间运行。 边缘情况包括幸运数字为零的数字、本身就是幸运数字以及非常大的数字（在 C++ 等语言中，不小心转换为其他类型可能会溢出）。 

例如，数字 4444 包含四个幸运数字。 由于4是一个幸运数字，所以4444就接近幸运了。 粗心的实现可能会忘记检查计数本身是否幸运，或者错误计数不完全是 4 或 7 的数字。 

## 方法

 暴力方法会读取数字，迭代每个数字，并针对每个数字检查它是 4 还是 7。计算完幸运数字后，可以从 1 迭代到该计数，看看是否有任何数字序列构成幸运数字。 这是正确的，但不必要地复杂； 检查数字是否只包含 4 和 7 可以在单个字符串检查中完成，而不是生成数字。 蛮力方法还可能尝试计算最多 18 位（最大位数）的所有幸运数字，这有点过分了，因为幸运数字的数量最多为 n 中的位数，即 18。 

关键的见解是，我们只需要计算幸运数字的数量，然后检查该数字本身是否仅由 4 和 7 组成。 这将问题简化为简单的两遍字符串扫描。 第一遍计算 n 中的 4 和 7。 第二遍通过检查数字来检查结果计数是否是幸运数字。 不需要其他数值运算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（检查所有数字）| O(d^2)，其中 d 是位数 | O(1) | O(1) | 不必要的复杂性 |
 | 最佳（两遍数字检查）| O(d)，其中 d ≤ 18 | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将数字作为字符串读取，以避免担心整数大小。 这使我们能够处理高达 10^18 的数字，而不会出现转换问题。 
2. 将计数器初始化为零。 迭代字符串中的每个字符。 如果字符是“4”或“7”，则增加计数器。 计算n中幸运数字的总数。 
3. 将计数器转换为字符串以检查其数字。 迭代该字符串的每个数字。 如果所有数字都是“4”或“7”，则该数字几乎是幸运的； 否则，就不是。 
4. 如果计数幸运，则打印“YES”，否则打印“NO”。 

工作原理：通过维护计数器正确跟踪幸运数字数量的不变式，然后检查该计数的幸运数字属性，我们可以保证正确地对几乎幸运数字进行分类。 每一步都直接实现问题的定义，无需对不相关的数字进行近似或迭代。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = input().strip()

lucky_count = 0
for ch in n:
    if ch == '4' or ch == '7':
        lucky_count += 1

lucky_count_str = str(lucky_count)
for ch in lucky_count_str:
    if ch != '4' and ch != '7':
        print("NO")
        break
else:
    print("YES")
```第一个循环计算幸运数字。 将计数器转换为字符串可以轻松进行第二次循环来验证计数本身是否幸运。 这`else`仅当没有时才会执行 for 循环`break`发生，意味着每个数字都是 4 或 7。这可以避免嵌套条件和差一错误。 Python 处理所有整数大小，因此对于大 n 不需要特殊处理。

 ## 边缘情况

 对于没有幸运数字的数字，例如 123，计数为 0。该算法将 0 转换为字符串“0”，其中既不包含 4 也不包含 7。for 循环检测到这一点并打印 NO。 

对于最大可能的数字 10^18 - 1，字符串表示形式为 18 个字符。 该算法计算任何 4 或 7 并自然地处理大数字，产生正确的近乎幸运的检查。 

对于计数恰好是个位数幸运数字的数字（例如 4 或 7），算法会正确地将其识别为接近幸运数字，这表明计数器的字符串转换适用于所有小计数和大计数。
