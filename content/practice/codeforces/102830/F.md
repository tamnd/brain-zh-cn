 ## 解决方案
 ## 问题理解

 我们有一个用矩形网格表示的礼堂。 有些牢房是墙壁或空地板，有些牢房是椅子，有些牢房包含插座，有些椅子上已经坐着竞争对手。 每个参赛者都属于一个由小写字母代表的团队。 

在每五分钟的间歇期间，每位参赛者都独立地尝试移至相邻的一张椅子上。 可能的目的地必须是一把空椅子，必须距离出口足够近，并且旁边不能有对方团队成员。 如果有多个目的地，则参赛者遵循固定的优先顺序：北、西、东、然后南。 所有参赛者选择目的地后，只执行不冲突的动作。 如果两个或多个参赛者选择同一把椅子，则没有人会移动到那里。 

任务是模拟给定数量的时间间隔内的过程并打印最终的礼堂状态。 

地图尺寸和模拟轮数都最多为100，因此网格最多包含10000个单元格，直接模拟是可行的。 一轮可以检查每个单元格和每个竞争对手，因此 O(I * N * M) 或 O(I * N * M * 常数) 附近的解决方案完全在限制范围内。 任何试图探索可能的未来状态的方法都是不必要的，因为这个过程是确定性的。 

主要的实现陷阱来自于在计算移动时使用错误的网格状态。 所有参赛者同时做出决定，因此任何举动都不会影响同一时间间隔内其他参赛者的决定。 例如：```
3 3 1
...
.*.
.a#
...
```正确的输出是：```
...
.*.
.a#
...
```参赛者无法进入右侧的椅子，因为该椅子距离出口不够近，因此地图保持不变。 

另一个微妙的情况是当两个竞争对手想要同一把椅子时：```
3 5 1
.....
.a#b.
.*...
```两位参赛者都可以考虑中间的椅子，但由于目的地有多个请求，因此必须取消移动。 如果不小心将竞争对手一一处理，就会错误地允许其中一个人移动。 

第三种边缘情况是竞争对手被几把可能的椅子包围。 必须严格遵守优先顺序：```
5 5 1
.....
..#..
.*a#.
..#..
.....
```如果北边的椅子有效，则正确的移动是到北边的椅子，即使东边存在另一个有效的椅子。 以任意顺序选择第一个有效方向会产生错误的结果。 

## 方法

 直接的暴力模拟是自然的起点。 对于每个间隔，扫描整个网格，找到每个竞争对手，检查四个相邻的单元格，选择第一个有效的目的地，然后一起应用所有动作。 这种方法是正确的，因为规则仅取决于当前的排列，并且每个间隔彼此独立。 

昂贵的部分不是找到答案，而是通过重复做不必要的工作来找到答案。 如果网格有 N * M 个单元且有 I 个间隔，则模拟将执行大约 I * N * M 个检查。 最大值约为 1 亿次电池检查，在该问题中这仍然是可以接受的，因为每次检查都很简单并且限制很小。 

有用的观察是该问题没有隐藏搜索。 每一步仅取决于当前网格，每轮改变一次网格。 我们可以通过将决策阶段与更新阶段分开来保留同时行为。 在第一阶段，记录每个请求的移动而不修改网格。 在第二阶段，仅应用仅请求一次的目的地。 

出口条件也可以在模拟开始之前进行简化。 无需每次移动时检查到每个出口的距离，而是使用多源广度优先搜索计算哪些单元格距离出口足够近。 然后每次移动检查就变成恒定时间查找。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(I * N * M) | O(N * M) | 已接受 |
 | 最佳 | O(N * M + I * N * M) | O(N * M + I * N * M) | O(N * M) | 已接受 |

 公认的解决方案是优化模拟。 预处理消除了重复的距离计算，而两阶段更新保持同时移动规则的正确性。 

## 算法演练

 1. 读取礼堂并从每个出口开始运行多源 BFS。 存储每个单元到最近出口的距离。 当椅子存储的距离最多为 3 时，它就可以准确地成为目的地。 
2. 重复以下过程 I 次。 在每次迭代期间，检查当前网格上的每个竞争对手并确定他们选择的目的地。 在此阶段不得更改网格，因为每个参赛者同时行动。 
3. 对于每个参赛者，按北、西、东、南的顺序检查相邻单元格。 选择第一个有空椅子、距离出口足够近且旁边没有对手的牢房。 
4. 将所选的移动存储在请求列表中。 还要计算有多少竞争对手选择了每个目标单元格。 对请求进行计数可以让我们在了解所有决策后识别冲突。 
5. 创建下一个网格状态。 对于每个记录的移动，仅当其目的地恰好有一个请求时才应用它。 原来的椅子变空，目的地接收竞争对手。 

正确性来自于保持每轮开始时的网格准确代表该轮中任何参赛者移动之前的礼堂的不变性。 决策阶段仅读取此状态，因此每个参赛者都会看到相同的情况。 更新阶段精确应用冲突规则允许的移动，这与语句的同时移动行为相匹配。 

BFS 预处理也是正确的，因为多源 BFS 为每个单元提供了到最近出口的最短路径距离。 由于通过网格的移动与出租车距离定义完全相同，因此检查该距离是否最多为 3 相当于检查在 3 次移动内是否可以到达出口。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m, intervals = map(int, input().split())
    grid = [list(input().rstrip()) for _ in range(n)]

    dist = [[10**9] * m for _ in range(n)]
    q = deque()

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '*':
                dist[i][j] = 0
                q.append((i, j))

    directions = [(-1, 0), (0, -1), (0, 1), (1, 0)]

    while q:
        r, c = q.popleft()
        for dr, dc in directions:
            nr, nc = r + dr, c + dc
            if 0 <= nr < n and 0 <= nc < m and dist[nr][nc] > dist[r][c] + 1:
                dist[nr][nc] = dist[r][c] + 1
                q.append((nr, nc))

    for _ in range(intervals):
        moves = []
        count = {}
        current = grid

        for r in range(n):
            for c in range(m):
                team = current[r][c]
                if not ('a' <= team <= 'z'):
                    continue

                chosen = None
                for dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    if not (0 <= nr < n and 0 <= nc < m):
                        continue
                    if current[nr][nc] != '#':
                        continue
                    if dist[nr][nc] > 3:
                        continue

                    blocked = False
                    for ar, ac in directions:
                        rr, cc = nr + ar, nc + ac
                        if 0 <= rr < n and 0 <= cc < m:
                            other = current[rr][cc]
                            if 'a' <= other <= 'z' and other != team:
                                blocked = True
                                break

                    if not blocked:
                        chosen = (nr, nc)
                        break

                if chosen is not None:
                    moves.append((r, c, chosen[0], chosen[1], team))
                    count[chosen] = count.get(chosen, 0) + 1

        for r, c, nr, nc, team in moves:
            if count[(nr, nc)] == 1:
                grid[r][c] = '#'
                grid[nr][nc] = team

    print('\n'.join(''.join(row) for row in grid))

if __name__ == "__main__":
    solve()
```代码的第一部分计算出口距离。 所有outlet最初都插入到队列中，这使得BFS同时从每个outlet向外扩展。 

模拟循环遵循演练中的两阶段思想。 代码记录移入`moves`并且不碰`grid`在做出决定的同时。 这避免了早期处理的竞争对手改变后来的竞争对手看到的选项的常见错误。 

方向阵故意排列为北、西、东、南。 这个顺序直接代表了问题的优先级规则。 冲突计数器使用目标坐标作为键，因此仅应用唯一的目标。 

最终的更新将两个单元格一起更改：旧位置变成空椅子，新位置被占用。 这就是为什么只有在收集了所有选择后才应用更新是至关重要的。

 ## 边缘情况

 当竞争对手没有合法目的地时，算法不会记录该人的动作。 对于单细胞情况：```
1 1 1
a
```竞争对手没有相邻单元格，因此移动列表保持为空并且网格不变。 

当多个参赛者选择同一把椅子时，算法不需要知道哪个参赛者先到达。 在：```
3 5 1
.....
.a#b.
.*...
```两个请求均被存储，目标计数变为 2，并且两个移动均不应用。 这符合竞争者避免争夺同一席位的规则。 

当竞争对手有多个有效选择时，有序方向扫描将处理决策。 第一个有效方向会立即选择，因此后面的方向不会意外覆盖更高优先级的选项。 

当请求多轮时，使用先前的最终网格作为下一个起始状态来重复相同的模拟。 由于每一轮在下一轮开始之前完全完成，因此间隔之间没有中间状态泄漏。
