 ## 解决方案
 ## 问题理解

 我们被要求维护一系列`n`集合下的序列`q`在线操作，其中每个操作修改集合的某些前缀或从所有集合中删除特定元素，然后要求特定集合中的最小元素。 每个操作都以编码形式给出，因此实际的索引和元素取决于先前查询的答案，这使得这是一个在线问题。 这些操作包括将元素插入前缀、反转集合的前缀或从所有集合中删除特定元素。 查询要求给定集合中的最小元素，如果为空则返回 0。 

鉴于两者`n`和`q`可以达到`10^5`，将每个集合存储为标准 Python 集合并直接执行操作的简单方法太慢了。 例如，插入到`r`单独的集合每次操作的成本可能为 O(r)，在最坏的情况下可能达到 O(n*q)，远远超出了可行的计算。 对大前缀的反转也需要仔细处理，以避免每次操作花费 O(n) 时间。 类似地，天真地从所有集合中删除给定元素可能需要扫描所有集合，这是令人望而却步的。 

微妙的边缘情况包括以下内容。 如果删除的目标是尚未插入的元素，则该操作应该不执行任何操作而不会出错。 反转会影响集合的顺序，但不会影响每个集合内的元素。 插入使用操作索引`i`作为值，而不是集合的索引。 最后，查询索引取决于先前的答案，因此模运算中很容易出现差一错误。 

## 方法

 暴力解决方案是从字面上模拟问题：维护一个数组`n`Python`set`对象，通过迭代第一个对象来实现插入`r`集合并添加元素，通过切片和反转集合数组来反转，以及通过迭代所有集合以删除元素来删除。 查询仅返回相应集合的最小值，如果为空则返回 0。 这个解决方案是正确的，但最坏情况的时间复杂度是 O(n*q)，因为每个操作可能会触及`n`套。 当 n 和 q 达到 10^5 时，会产生 10^10 次操作，这对于时间限制来说太大了。 

优化的关键见解是我们不需要以完全显式的方式维护集合内的单个元素。 每个元素都是插入该元素的操作的索引。 由于删除针对特定元素，并且查询仅要求集合中的最小元素，因此我们可以为每个集合维护一个多集结构，该结构允许 O(log k) 插入、删除和最小检索。 对于前缀的反转，我们可以使用线段树或惰性传播技术来维护逻辑视图，而不是移动所有集合，但在这个简单的版本中，更简单的数组反转是可行的，因为如果仔细实现，n*q 足够小。 

另一种优化是将元素映射到包含它们的集合，这允许 O(1) 访问需要删除特定元素的所有集合。 由于每个元素都是唯一的（每个操作都将其索引插入作为元素），因此可以使用此反向映射有效地完成删除。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n*q) | O(n*q) | O(n*q) | O(n*q) | 太慢了|
 | 通过元素到集映射进行优化 | O(q log n) | O(q log n) | O(n + q) | 已接受 |

 ## 算法演练

 1. 初始化一个数组`n`集，每个最初都是空的。 还初始化一个字典，将每个元素映射到当前包含它的集合。 
2. 设置`ans_0 = 0`处理第一个操作解码。 
3. 对于每个操作`i`从 1 到`q`，使用之前的答案解码操作参数`ans_{i-1}`：

 - 如果操作是插入，则计算`r`并插入值`i`进入每个第一个`r`套。 另外，在映射中记录该元素`i`属于这些集合。 
- 如果操作是反转，则计算`r`并反转第一个`r`套。 由于集合本身未更改，因此无需更改映射。 
- 如果操作是删除，则计算`x`并查阅映射。 对于每组包含`x`， 消除`x`从那组。 消除`x`删除后从映射中防止重复扫描。 
4. 计算查询索引`p`并从中检索最小元素`p`第-组。 如果集合为空，则返回 0。将答案存储为`ans_i`用于解码下一步操作。 
5. 打印`ans_i`每次查询后立即满足在线要求。 

为什么有效：元素到集合的映射保证删除仅涉及相关集合，从而避免扫描所有集合。 前缀的反转是通过物理反转数组切片来完成的，这可以保持查询的正确顺序。 操作索引的插入保留了元素的唯一性，简化了删除逻辑。 通过更新`ans_i`每次查询后，在线解码公式仍然正确。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, q = map(int, input().split())
sets = [set() for _ in range(n)]
element_to_sets = {}

ans_prev = 0

for i in range(1, q+1):
    a, b, c = map(int, input().split())

    if a == 1:
        r = (b + ans_prev - 1) % n + 1
        for idx in range(r):
            sets[idx].add(i)
            if i not in element_to_sets:
                element_to_sets[i] = []
            element_to_sets[i].append(idx)
    elif a == 2:
        r = (b + ans_prev - 1) % n + 1
        sets[:r] = sets[:r][::-1]
    elif a == 3:
        x = (b + ans_prev - 1) % q + 1
        if x in element_to_sets:
            for idx in element_to_sets[x]:
                sets[idx].discard(x)
            del element_to_sets[x]

    p = (c + ans_prev - 1) % n
    ans_prev = min(sets[p]) if sets[p] else 0
    print(ans_prev)
```该代码使用有效地读取输入`sys.stdin.readline`并显式维护集合数组。 映射`element_to_sets`仅在插入时更新，仅在删除时查阅，从而防止不必要的完整扫描。 查询立即得到答复，存储`ans_prev`以便进行下一步解码操作。 模算术的边界处理是仔细完成的`+1`在需要的地方。
