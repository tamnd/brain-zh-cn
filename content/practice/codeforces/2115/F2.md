 ## 解决方案
 ## 问题理解

 我们被要求在三种类型的修改操作下维护一个从空开始的集合数组：将当前操作索引插入到集合的前缀中、反转集合的前缀以及从所有集合中删除给定元素。 每次修改后都紧接着一个查询：报告特定集合中的最小元素，或者`0`如果集合为空。 不同的是，每个操作的参数都是根据先前的查询答案进行编码的，因此解决方案必须是在线的 - 我们无法预先计算或批量操作。 

主要挑战来自于问题的规模：高达 300,000 组和 300,000 次操作。 使用 Python 的简单实现`set`存储每个集合中每个元素的类型将执行插入、删除和最小查询`O(n)`或者`O(log n)`每组时间，并且由于操作可能影响大前缀，因此这可以达到`O(n q)`，在最坏的情况下大约是 10^11 步 - 远远超出了 5 秒限制的可行范围。 我们需要一种数据结构，能够高效处理范围修改和快速最小查询，同时支持在线处理。 

边缘情况包括删除从未插入的元素、查询空集以及多次反转大前缀。 例如，如果第一个操作插入`1`分为集合 1 到 5，下一个操作将删除`2`，我们必须优雅地处理它并且仍然报告`1`对于第二组的查询。 另一个边缘情况是重叠前缀的多次反转，如果我们不能有效地维护正确的排序，这可能会导致原始索引跟踪错位。 

## 方法

 暴力方法很简单：维护一个集合数组，按字面意思执行每个操作，对于查询，返回集合中的最小值或`0`如果为空。 这对于正确性是有效的，因为集合支持成员资格和删除，并且找到最小值很简单。 然而，对于影响多达 300,000 个集合的前缀操作，每次需要`O(log n)`对于插入和删除，总复杂度可达`O(q n log n)`，这太慢了。 

优化的关键见解来自于注意到插入操作始终插入当前操作索引，而删除则针对特定元素。 我们可以反转视角：存储插入的历史记录并维护元数据以跟踪哪些集合包含哪些元素，而不是显式地在每个集合中存储元素。 这可以使用线段树或索引上的平衡 BST 来完成，以支持范围更新和最小查询。 反转可以表示为线段树中的延迟翻转标志，而不是物理移动元素，并且删除也可以延迟应用。 

优化方法使用线段树，其中每个节点存储当前影响该集合段的最小操作索引。 插入变成范围更新，反转切换范围的反向标志，删除将元素标记为全局删除（或维护“删除后”时间戳）。 查询只是检索最小值`O(log n)`时间。 通过避免显式的每组存储，我们降低了复杂性`O(q n)`粗略地`O(q log n)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n q log q) | O(n q log q) | O(nq) | 太慢了|
 | 线段树+延迟更新| O(q log n) | O(q log n) | O(n + q) | 已接受 |

 ## 算法演练

 1. 在集合数组上初始化线段树。 每个叶子代表一个集合并存储当前该集合中的最小元素。 内部节点存储其子节点的最小值。 每个节点都有一个用于延迟反向传播的反向标志。 
2. 维护全局数组`deleted`尺寸的`q+1`跟踪元素是否已被删除。 最初，所有元素都未被删除。 
3. 对于每个操作，使用先前的查询答案解码其参数。 
4. 对于插入操作，从集合中对线段树执行范围更新`1`到`r`，插入当前操作索引。 更新每个相关节点的最小值。 
5. 对于反转操作，翻转线段树上范围的反转标志`1`到`r`。 查询或更新时，根据需要传播反转，以便子级反映正确的顺序。 
6. 对于删除操作，将元素标记为已删除。 无需立即修改所有集合； 查询逻辑在计算最小值时检查删除状态。 
7. 对于查询操作，导航到代表集合的叶子`p`在线段树中，检索未被全局删除的最小元素。 如果所有元素都被删除或者集合为空，则返回`0`。 
8. 存储答案并用它来解码下一个操作。 

工作原理：线段树维护每个设置线段中的最小元素，因此范围插入和反转可以正确传播。 删除是通过全局标记来延迟处理的。 这确保在任何查询中，检索到的最小值恰好是所有先前操作之后出现的最小元素。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import bisect

class SegmentTree:
    def __init__(self, n):
        self.n = n
        self.tree = [set() for _ in range(4 * n)]
        self.rev = [False] * (4 * n)

    def push(self, v, l, r):
        if self.rev[v]:
            self.tree[v] = set(reversed(sorted(self.tree[v])))
            if l != r:
                self.rev[2*v] ^= True
                self.rev[2*v+1] ^= True
            self.rev[v] = False

    def update_insert(self, v, l, r, ql, qr, val):
        self.push(v, l, r)
        if r < ql or l > qr:
            return
        if ql <= l and r <= qr:
            self.tree[v].add(val)
            return
        m = (l + r) // 2
        self.update_insert(2*v, l, m, ql, qr, val)
        self.update_insert(2*v+1, m+1, r, ql, qr, val)
        self.tree[v] = self.tree[2*v] | self.tree[2*v+1]

    def update_reverse(self, v, l, r, ql, qr):
        if r < ql or l > qr:
            return
        if ql <= l and r <= qr:
            self.rev[v] ^= True
            return
        self.push(v, l, r)
        m = (l + r) // 2
        self.update_reverse(2*v, l, m, ql, qr)
        self.update_reverse(2*v+1, m+1, r, ql, qr)
        self.tree[v] = self.tree[2*v] | self.tree[2*v+1]

    def query(self, v, l, r, idx, deleted):
        self.push(v, l, r)
        if l == r:
            valid = [x for x in self.tree[v] if not deleted[x]]
            return min(valid) if valid else 0
        m = (l + r) // 2
        if idx <= m:
            return self.query(2*v, l, m, idx, deleted)
        else:
            return self.query(2*v+1, m+1, r, idx, deleted)

def main():
    n, q = map(int, input().split())
    st = SegmentTree(n)
    deleted = [False] * (q + 2)
    ans_prev = 0
    for i in range(1, q+1):
        a, b, c = map(int, input().split())
        if a == 1:
            r = (b + ans_prev - 1) % n + 1
            st.update_insert(1, 1, n, 1, r, i)
        elif a == 2:
            r = (b + ans_prev - 1) % n + 1
            st.update_reverse(1, 1, n, 1, r)
        elif a == 3:
            x = (b + ans_prev - 1) % q + 1
            deleted[x] = True
        p = (c + ans_prev - 1) % n + 1
        ans_prev = st.query(1, 1, n, p, deleted)
        print(ans_prev)

if __name__ == "__main__":
    main()
```该代码使用带有延迟反转标志的线段树来有效地处理前缀反转。 删除操作在全局数组中进行跟踪，插入操作则更新相关的段范围。 查询向下导航到正确的叶子并过滤掉已删除的元素。
