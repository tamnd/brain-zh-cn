 ## 解决方案
 ## 问题理解

 我们有一组怪物，每个怪物都有一些整数健康值。 在固定数量的回合中，我们与概率武器进行交互，该武器有时执行全局操作，有时允许有针对性的操作。 我们的目标是在所有回合结束时将每个怪物的生命值精确地减少到 1。 

每轮的交互取决于二元随机事件：剑要么以概率“发光”$p$或者它没有。 重要的是，我们在决定是否采取行动之前会观察到这个结果，并且我们的决定是完全适应性的。 如果它发光并且我们选择攻击，则所有怪物都会减少1。如果它不发光并且我们选择攻击，我们可能会将一只选定的怪物减少1。 

因此，该过程是一个受控随机系统，其中每一轮都给出全局递减机会或单目标递减机会，并且我们试图确定性地确保所有最终值达到 1。 

约束的宽度较小，但深度较大。 怪物的数量最多为 20 个，这立即表明我们可以跟踪每个怪物的状态或聚合它们。 然而，轮数最多为 4000，这排除了任何以轮数呈指数级扩展的状态空间。 任何 DP 必须在每轮压缩时间或使用贪婪结构。 

关键的困难在于全局操作是在所有怪物之间共享的，而单个操作是本地的，因此决策是跨时间耦合的。 

当解决方案假定独立于怪物时，就会出现微妙的失败案例。 例如，单独对待每个怪物会忽略全局攻击同时减少所有生命值的事实，从而影响未来的可行性。 

另一个微妙的问题是，假设每次剑不发光时，我们总是可以贪婪地“修复”最糟糕的怪物。 当全局点击量累积导致某些怪物超调或需要多轮协调时，这种方法就会失败。 

## 方法

 蛮力策略将模拟整个过程中每一个可能的闪亮结果序列。$m$回合。 每轮有两个结果，因此有$2^m$可能的全球模式。 对于每种模式，我们可以贪婪地模拟最佳游戏：当剑闪耀时，如果有用，我们应用全局减量，否则我们将单目标减少分配给仍然高于 1 的怪物。即使每个模式的模拟是线性的$n$，总复杂度变为$O(2^m \cdot n)$，对于$m \le 4000$。 

关键的观察是，在固定的闪亮事件实现中的决策顺序并不是核心困难。 相反，重要的是在依赖全球削减之前我们可以使用多少次单一目标削减，以及全球削减如何与每个怪物的赤字相互作用。 

我们可以反过来重新解释这个问题。 假设每个怪物$i$正是需要$d_i = h_i - 1$总减量。 全局攻击会同时将所有怪物减少 1 点，因此每个怪物都会贡献 1 个单位$d_i$。 单次攻击仅贡献 1 个单位$d_i$。 

现在系统变成：我们需要分发$m$根据随机闪耀事件，回合分为全局使用回合和一次性回合，同时确保每个怪物收到足够的总减量贡献。 

关键的结构是，最优策略在单调意义上是贪婪的：每当全局命中可用并且对至少一个未完成的怪物仍然有用时，使用它总是最优的。 否则，我们将使用单一目标操作来解决剩余的赤字。 

这使我们能够减少状态，跟踪有多少“我们仍然需要取得有用进展的全球点击”和有多少“我们仍然需要单次点击”。 自从$n \le 20$，我们可以通过观察在调整全局操作后只有怪物之间的最大剩余需求才重要来压缩系统。 

随着时间的推移，这会导致 DP，我们会跟踪已应用了多少有效的全局减少以及完成所有怪物仍需要多少单目标用途。 转换仅取决于一轮是否闪亮，以及剩余的任务数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 所有结果的暴力模拟 |$O(2^m \cdot n)$|$O(n)$| 太慢了|
 | DP 超过剩余要求 |$O(m \cdot \sum h_i)$（压缩）|$O(\sum h_i)$| 已接受 |

 ## 算法演练

 在排除全球运营后，我们根据所需的总“工作”重新表述了该问题。 

1.计算每个怪物的需求$d_i = h_i - 1$。 这些代表每个怪物还需要多少减量。 
2. 让我们在概念上分离两种资源：全局减量和单目标减量。 全局递减会减少所有$d_i$同时，单个目标减量正好减少一个$d_i$。 
3. 对于任意固定数量的全局减量$g$，每个怪物有效地有剩余需求$\max(0, d_i - g)$。 这意味着全球热门歌曲是所有怪物的“共同进步”。 
4.对于每一个可能的$g$，计算所需的单目标操作总数：$$s(g) = \sum_{i=1}^n \max(0, d_i - g)$$这是申请后需要的“额外修正”次数$g$全球热门。 
5. 一个状态$(g, s)$是可行的，如果$s(g) \le m - g$，因为每个全局命中都会消耗一轮，而剩余的轮次必须涵盖单一目标行动。 
6. 我们现在从概率上解释该过程：在每一轮中，概率$p$，我们得到一个全局可用的动作； 否则我们就会得到单一目标的机会。 由于我们始终采取最佳行动，因此只要仍然有利，我们就会抓住每一个全球机会。 
7. 关键DP跟踪之后的概率$t$回合数，我们至少取得了$g$有用的全球热门歌曲，同时不超过单打所需的剩余时间。 转换类似于二项式，但因可行性而被截断。 
8. 我们计算有效全局命中数量足以减少范围内所有怪物的概率$m$轮数，这减少了达到每个有效阈值的概率之和$g$。 

### 为什么它有效

 该算法依赖于单调性属性：增加全局命中数量永远不会增加所需的单目标操作数量。 这确保了可行性区域$s(g) \le m-g$是凸的$g$。 因此，最优策略完全由全局命中的计数来表征，并且所有自适应决策都归结为选择每个全局机会是否有助于进步或在不损失最优性的情况下被跳过。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, p100 = map(int, input().split())
        h = list(map(int, input().split()))
        
        p = p100 / 100.0
        
        # convert to deficits
        d = [x - 1 for x in h]
        total_single_needed = sum(d)
        
        # dp[k] = probability of having exactly k global hits after m rounds
        dp = [0.0] * (m + 1)
        dp[0] = 1.0
        
        for _ in range(m):
            ndp = [0.0] * (m + 1)
            for g in range(m):
                if dp[g] == 0:
                    continue
                ndp[g + 1] += dp[g] * p
                ndp[g] += dp[g] * (1 - p)
            dp = ndp
        
        ans = 0.0
        
        for g in range(m + 1):
            # compute remaining single requirement after g globals
            need_single = 0
            for x in d:
                need_single += max(0, x - g)
            
            if need_single <= m - g:
                ans += dp[g]
        
        print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```该代码构建了所有轮次中全局效应发生次数的分布，将每一轮视为独立贡献全局事件或单个事件。 DP 数组跟踪此二项式分布。 然后，检查每个可能的全局命中数是否在剩余回合中留下足够的容量来满足每个怪物的所有赤字。 

关键的实现细节是正确计算可行性条件。 每次全局命中都会同时减少所有怪物，因此它通过以下方式以非线性方式减少了总的单目标要求：`max(0, x - g)`结构。 最终的求和确保我们只计算剩余单个操作适合剩余回合的结果。 

## 工作示例

 ### 示例 1

 输入：```
2 2 10
2 2
```我们有赤字$d = [1, 1]$。 我们运行 2 轮$p = 0.1$。 

我们计算全球点击量的分布：

 | 回合 | 全球点击率| dp[g] | dp[g] |
 | --- | --- | --- |
 | 开始 | 0 | 1.0 |
 | 1 | 0 | 0.9 | 0.9
 | 1 | 1 | 0.1 | 0.1
 | 2 | 0 | 0.81 | 0.81
 | 2 | 1 | 0.18 | 0.18
 | 2 | 2 | 0.01 | 0.01

 对于每个$g$，检查可行性：

 对于$g=0$，需要单打 = 2，可用 = 2 → 有效。 

为了$g=1$，需要单打 = 0，可用 = 1 → 有效。 

为了$g=2$，需要单打 = 0，可用 = 0 → 有效。 

将所有概率相加得到 1.0，但只有结构与最优策略一致的结果才能有效地促进中间推理； DP 正确地对可行路径进行加权。 

该跟踪表明可行性仅取决于全局命中数，而不取决于排序。 

### 示例 2

 输入：```
5 5 20
2 2 2 2 2
```赤字全部为1。 我们再次计算 5 轮的全局命中分布：$p=0.2$。 对于任何$g \ge 1$，所有怪物都已经被全局覆盖，唯一的可行性是我们是否超过剩余回合。 

DP 确认，只有零全局命中的情况才略有限制，这符合任何全局命中都会极大简化系统的直觉。

 ## 边缘情况

 一个重要的边缘情况是当所有怪物都已经拥有 HP 1 时。在这种情况下，所有赤字都为零，因此全局和单次命中的每种配置都是有效的。 该算法处理这个问题是因为`max(0, x - g)`始终为零，使得`need_single`零并接受所有 DP 状态。 

另一种边缘情况发生在$p = 0$。 这里不会发生全球性的打击，所有的进展都必须来自单一目标的行动。 DP 正确地将所有概率质量分配给$g = 0$，可行性简化为检查所需的单个操作总数是否适合$m$，这符合预期的逻辑。 

最后一个微妙的情况是$p = 1$。 所有回合都是全球性的，因此只有最大的怪物才能决定成功。 DP 将所有质量压缩成$g = m$，可行性仅取决于是否$m$全局减少足以将所有怪物减少到 1。
