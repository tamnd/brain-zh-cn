 ## 解决方案
 ## 问题理解

 我们得到一个矩形网格，其中每个单元格已经包含一个固定的`0`，一个固定的`1`，或者未知的`?`。 每个未知的细胞稍后将被独立地替换为`0`或者`1`，每个选择都有相同的概率。 完成所有替换后，我们检查最终的二元网格并检查它是否包含任何一对正交相邻的`1`细胞。 

任务不是模拟随机性，而是计算最终网格没有两个相邻网格的概率`1`细胞。 答案必须以 998244353 为模给出。 

将此视为概率约束满足问题的一种有用方法：每个`?`是一个自由的二进制变量，我们想要产生一组独立的赋值的分数`1`网格图中的单元格。 

网格大小最多为 15 x 15，因此最多有 225 个单元格。 这立即排除了任何枚举所有分配的方法`?`，因为在最坏的情况下有 2^225 种可能性，这远远超出了计算可行性。 即使 2^40 在 2 秒内也已经是临界值，因此对单元格进行暴力破解是不可行的。 

另一个天真的想法是直接生成所有有效的作业并对其进行计数，然后除以 2^{问号数量}。 这仍然需要枚举所有有效的配置，这在单元数量上是指数级的。 

第二个幼稚的错误是独立处理细胞或尝试贪婪的局部决策。 邻接约束耦合了整个网格的选择，因此局部独立性失败。 

朴素推理被打破的具体边缘情况是完全未知的 2x2 网格。 总共有 16 个作业，但只有那些没有相邻的作业`1`s 有效。 天真的“乘以每个单元的概率”方法会错误地假设独立性并过多计算有效状态。 

关键的困难是全局邻接，这表明在宽度和高度较小的网格图上存在图约束问题。 这是对行的子集进行配置文件动态规划的经典设置。 

## 方法

 暴力解决方案是迭代所有的分配`?`单元格，填充网格，并检查是否有任何相邻的对`1`s 存在。 每次检查的成本为 O(nm)，并且有 2^k 次分配，其中 k 是问号的数量。 在最坏的情况下k = 225，所以这是完全不可行的。 

即使我们只限制有效状态，网格中独立集的数量也会以 nm 为单位呈指数增长。 问题的结构表明我们应该避免枚举完整的网格，而是逐步构建解决方案。 

关键的观察结果是，邻接约束是局部的：单元仅与其左、右、上、下邻居交互。 如果我们逐行处理网格，填充一行时唯一未解决的依赖关系是与前一行的关系。 这表明对行进行位掩码动态编程，其中每个行配置对哪些单元设置为`1`。 

对于每一行，我们枚举遵守固定约束的所有有效位掩码`0`,`1`， 和`?`。 然后我们在连续的行之间进行转换，强制不发生垂直冲突，并且在一行内没有两个相邻位同时存在`1`。 

这将问题从以 nm 为单位的指数减少到以 m 为单位的指数（最多为 15），使其变得可行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^{nm} · nm) | O(2^{nm} · nm) | O(纳米) | 太慢了|
 | 带位掩码的行 DP | O(n·2^m·2^m) | O(n·2^m·2^m) | O(2^m) | O(2^m) | 已接受 |

 ## 算法演练

 我们逐行处理网格，将每一行视为长度为 m 的位掩码，其中如果单元格 (i, j) 分配为 1，则位 j 为 1。 

1. 预先计算所有不包含水平相邻 1 的有效行掩码。 这确保了行内没有违规。 任何带有`mask & (mask << 1) != 0`无效。 
2.对于每一行i，根据固定网格约束进一步过滤有效掩码。 如果某个单元被强制为 0，则该位必须为 0。如果强制为 1，则该位必须为 1。否则可以是其中之一。 
3. 定义两个行掩码之间的过渡`a`（上一行）和`b`（当前行）。 约束是不允许垂直相邻，所以`a & b == 0`。 
4. 使用动态规划`dp[i][mask]`是直到 i 行的有效配置数，其中第 i 行等于`mask`。 
5. 通过分配与第 0 行约束一致的所有有效掩码来初始化第 0 行的 dp。 
6. 对于下一行，通过迭代满足垂直兼容性的所有有效的先前掩码和当前掩码来计算 dp 转换，并累积计数。 
7. 处理完所有行后，对最后一行中的所有有效掩码求和 dp[n-1][mask]。 
8. 将结果除以 2^{number of`?`使用模逆。 

它起作用的原因是每个完整的网格分配都恰好对应于一个行掩码序列。 DP 精确地枚举那些满足所有水平和垂直邻接约束的序列，并且过滤步骤确保与固定单元格的一致性。 由于每个`?`恰好贡献了两个等概率的选择，2^k 的归一化将计数转换为均匀随机分配下的概率。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    # count question marks
    q = sum(row.count('?') for row in grid)

    # precompute powers of 2
    pow2 = [1] * (n * m + 1)
    for i in range(1, n * m + 1):
        pow2[i] = pow2[i - 1] * 2 % MOD

    inv_pow2 = pow(pow2[q], MOD - 2, MOD)

    # generate valid row masks (no adjacent 1s)
    valid_masks = []
    for mask in range(1 << m):
        if mask & (mask << 1):
            continue
        valid_masks.append(mask)

    # precompute compatibility with each row
    row_allowed = []
    for i in range(n):
        allowed = []
        for mask in valid_masks:
            ok = True
            for j in range(m):
                if grid[i][j] == '1' and not (mask >> j & 1):
                    ok = False
                    break
                if grid[i][j] == '0' and (mask >> j & 1):
                    ok = False
                    break
            if ok:
                allowed.append(mask)
        row_allowed.append(allowed)

    dp = {mask: 1 for mask in row_allowed[0]}

    for i in range(1, n):
        ndp = {mask: 0 for mask in row_allowed[i]}
        for pmask, val in dp.items():
            for cmask in row_allowed[i]:
                if pmask & cmask:
                    continue
                ndp[cmask] = (ndp[cmask] + val) % MOD
        dp = ndp

    total = sum(dp.values()) % MOD
    print(total * inv_pow2 % MOD)

if __name__ == "__main__":
    main()
```该代码首先枚举避免水平邻接并遵守固定约束的所有行状态。 然后，它对行执行标准配置文件 DP，其中转换通过确保相邻行中没有列都为 1 来强制垂直兼容性。 最终结果对所有有效分配进行计数，然后通过引入的随机选择数量进行归一化`?`。 

一个微妙的实现点是DP使用字典而不是固定数组。 这可以避免迭代无效掩码，并将状态空间限制为仅与每行约束一致的掩码。 另一个关键细节是 2^q 的模逆，它在未知细胞的均匀独立采样下正确地将原始计数转换为概率。 

## 工作示例

 ### 示例 1

 输入：```
2 5
0?100
1000?
```我们首先确定问号的数量，即 2，因此有 4 个同样可能的未知单元格分配。 

我们跟踪行掩码：

 | 行| 允许佩戴口罩 | dp 状态 |
 | --- | --- | --- |
 | 0 | 面具符合`0?100`| 初始分配 |
 | 1 | 面具符合`1000?`| 从第 0 行开始的转换 |

 DP 仅保留行之间不发生垂直重叠的配置。 

处理完这两行后，我们获得的有效分配总数等于 2。由于总共有 4 个分配，因此概率为 2/4 = 1/2 = 499122177。 

这证实了一半的随机填充避免了相邻的 1。 

### 示例 2

 输入：```
2 2
?1
01
```有一种是被迫的`1`在第一行第二列和一个强制`1`在第二行第一列。 

我们检查有效的行掩码：

 | 行| 限制条件| 有效口罩|
 | --- | --- | --- |
 | 0 | 必须有位 1 = 1 | 仅面膜10个|
 | 1 | 已修复 01 | 仅面膜01 |

 现在检查垂直兼容性：

 掩码 10（第 0 行）和 01（第 1 行）在垂直方向上不冲突，因此 DP 计数为 1。 

问号总数为 1，因此作业总数为 2。只有一项作业有效，概率为 1/2。 

然而，第 0 行已经强制`1`与第 1 行对角相邻，但对角相邻无关。 唯一的约束是垂直邻接，满足该约束，因此最终答案非零。

 ## 边缘情况

 单细胞网格`?`演示概率归一化步骤。 DP 计算一种有效配置，但概率必须除以 2，产生 1/2 模 998244353。该算法正确应用 2^q 的模逆。 

完全约束的行，例如`11`显示水平过滤。 掩码生成步骤消除了 DP 之前的所有无效状态，因此甚至不考虑任何转换。 

强制网格出现在交替位置可确保执行垂直冲突检查。 条件`pmask & cmask == 0`正确消除行间的任何重叠，即使每行单独看起来都是有效的。
