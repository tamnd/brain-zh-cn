 ## 解决方案
 ## 问题理解

 我们有一块方板，其中每个单元格可能是空的或包含一个`X`。 目标是修改棋盘，使连续块中没有行或列包含三个相同的非空符号。 换句话说，我们必须消除每次出现的长度为 3 的模式，例如`XXX`水平或垂直。 

我们可以改变角色，并且我们不会试图最小化改变。 我们只需要保证最终的配置在任何地方都不存在获胜三元组。 

约束足够大，任何方法都必须与每个测试用例的单元数量呈线性关系。 总和$n^2$至多是$4 \cdot 10^6$，因此扫描每个单元格的固定次数是可以接受的。 任何涉及重复重新检查线路或回溯的事情都会太慢。 

一个微妙的边缘情况是当三元组严重重叠时，例如像这样的长块`XXXXXX`。 仅针对第一个检测到的三元组的简单修复可能会在修改后留下新的三元组，因此正确性必须来自全局模式，而不是局部修复。 

## 方法

 暴力策略会重复扫描棋盘，查找行或列中是否出现三个连续的相同标记，然后翻转该段内的字符并重新启动。 这是正确的，因为它最终可以删除所有不良模式，但每次扫描都会花费$O(n^2)$在最坏的情况下我们可能会执行$O(n^2)$修改，导致$O(n^4)$，远远超出了极限。 

关键的观察是我们根本不需要对配置做出反应。 我们只需要直接构造一个有效的棋盘即可。 由于仅`X`出现在简单版本中，每个单元格都是`X`或空，并且约束仅关心三个连续的运行`X`。 

这表明有一个固定的周期结构。 如果我们确保在每一行和每一列中我们打破任何三个`X`，我们可以通过放置来强制执行此操作`X`仅在不以三元组对齐的位置上。 一个简单的确定性构造是保持网格不变，除了翻转精心选择的子集之外`X`单元格，以便在每一行和每一列中，三个连续单元格的任何段都包含至少一个已修改的单元格。 一种标准方法是使用基于坐标奇偶性的模式：确保在每三个连续位置中，至少有一个通过基于奇偶性的翻转而改变$(i + j) \bmod 3$。 

这保证了原始的三元组没有连续的`X`保持不变，并且由于我们只翻转受控部分的单元格，因此我们保持在允许的操作范围内。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 重复修复模拟|$O(n^4)$|$O(n^2)$| 太慢了 |
 | 模块化结构|$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 读取每个测试用例的网格并将其存储为可变字符数组。 
2. 按行优先顺序迭代网格的每个单元格。 
3. 对于每个包含`X`，根据确定性规则决定是否翻转它：使用以下命令检查其位置模 3$(i + j) \bmod 3$。 
4. 如果规则表明翻转，则更改`X`进入`.`或另一个安全字符来打破潜在的三元组。 
5. 继续，无需重新访问之前的单元，因为决策是本地性的，但是全局性的。 
6. 处理完所有单元格后输出结果网格。 

工作原理：一行或一列中的三个连续单元格的任何序列都必须包含两个具有不同残基模 3 的索引。因此，至少其中一个保证会被翻转`X`，防止任何`XXX`形成。 该构造强制执行全局周期性约束，该约束会破坏所有长度为 3 的同质段。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        grid = [list(input().strip()) for _ in range(n)]

        for i in range(n):
            for j in range(n):
                if grid[i][j] == 'X':
                    if (i + j) % 3 == 0:
                        grid[i][j] = '.'

        for row in grid:
            print(''.join(row))

if __name__ == "__main__":
    solve()
```该代码对每个单元格只处理一次并应用简单的算术规则。 模3条件是保证不存在三连续的核心结构保证`X`保持在任何方向。 该决策是本地的，但在整个网格中是一致的，这就是为什么修改后不需要额外的验证。 

一个常见的陷阱是在检测到三元组后尝试贪婪的局部修复，这会破坏之前固定的区域。 这里的变换与检测无关，因此输出是稳定的。

 ## 边缘情况

 对于完全填充的网格`X`，该算法精确翻转那些坐标和可被 3 整除的单元格。在 3x3 块中，这保证了每一行和每一列至少包含一个非`X`细胞，因此没有三元组存活。 例如：```
XXX
XXX
XXX
```单元格(1,1)、(1,4不存在)，但在水平或垂直任意3个连续段内，至少有一个位置满足取模条件并被移除。 这可以防止形成任何`XXX`图案。 

对于稀疏网格，其中很少`X`如果规则存在，则该规则可能根本不会触发任何更改，这是正确的，因为不存在禁止的模式。
