 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，表示用户在竞争性编程平台上的评分图。 对于每个整数$k$从 1 到$n$，我们被要求考虑数组的“k-压缩”。 k 压缩是通过取每个连续子数组长度的最小值来形成的$k$。 目标是确定对于每个$k$，这个压缩数组是否是从 1 到$n-k+1$。 如果是，用户很高兴，我们输出`1`; 否则，我们输出`0`。 

约束条件允许$n$达到$3 \cdot 10^5$每个测试用例，以及所有测试用例的总和$n$跨测试用例也受$3 \cdot 10^5$。 这意味着$O(n^2)$方法，我们显式计算每个子数组最小值，将导致大约$10^{10}$在最坏的情况下，操作速度太慢了。 我们需要一个在每个测试用例中以线性或接近线性时间运行的解决方案。 

非明显的边缘情况包括具有重复数字的数组、已排序的数组、边界处具有最小或最大元素的数组以及非常小的数组（其中$n = 1$。 例如，一个数组`[3,3,2]`有多个重复的数字。 幼稚的方法可能会忽略这一点$k = 2$, 最小值`[3,2]`包括重复的`3`如果处理不当。 

## 方法

 蛮力方法迭代每个$k$从 1 到$n$，显式构造 k 压缩数组，并检查它是否形成排列。 这是正确的但效率低下，因为计算所有子数组最小值天真地需要$O(nk)$每$k$，导致$O(n^2)$全面的。 这会失败，当$n$方法$10^5$。 

关键的见解是，可以形成排列的最小 k 压缩取决于数组中最小和最大元素的位置。 具体来说，如果一个数组包含从 1 到$n$恰好一次，整个数组是一个排列$k = 1$。 那么，对于更大的$k$，数字的第一次和最后一次出现决定了滑动窗口是否可以产生唯一的最小值。 我们可以跟踪每个值的位置，并使用两指针方法来维护每个长度的有效窗口。 

我们不需要生成每个 k 压缩，只需检查最小元素是否位于边界，然后检查下一个最小元素，依此类推。 通过迭代地从末尾“删除”最小的可用元素，我们可以为所有元素构造一个二进制字符串$k$在$O(n)$每个测试用例的时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组$a$和它的长度$n$。 初始化二进制结果数组`ans`长度$n$充满零。 
2. 检查数组是否$a$包含从 1 到 的所有数字$n$。 如果是这样，1-压缩是一个排列，所以设置`ans[0] = 1`。 
3. 记录每个数字的第一次和最后一次出现的索引$a$。 这使我们能够知道每个值出现的位置。 
4.初始化两个指针，`l = 0`和`r = n-1`，代表当前窗口的左端和右端。 
5. 迭代`val`从 1 到$n$按递增顺序：

 - 如果`val`位于`a[l]`, 增量`l`。 
- 否则如果`val`位于`a[r]`, 递减`r`。 
- 否则，下一个最小值不在边界处，因此没有更大的窗口可以进行排列、中断。 
- 如果我们成功处理`val`， 放`ans[n - val] = 1`，因为窗口长度`n - val + 1`对于排列来说是有效的。 
6.输出二进制字符串`ans`。 

为什么有效：在每一步中，最小的剩余数字必须出现在其中一个边界处，以保持滑动窗口中的唯一性。 通过删除与当前最小值对应的边界元素，我们保留了剩余子数组可以形成下一个窗口大小的排列的不变式。 如果窗口内有任何数字，则唯一性属性将失败，从而确保正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        ans = ['0'] * n
        
        # Check if full array is a permutation
        if sorted(a) == list(range(1, n+1)):
            ans[0] = '1'
        
        l, r = 0, n-1
        count = [0] * (n+2)
        for x in a:
            count[x] += 1
        
        valid = True
        for val in range(1, n+1):
            if count[val] != 1:
                valid = False
                break
        if not valid:
            ans[0] = '0'
        
        left, right = 0, n-1
        for k in range(1, n):
            if a[left] == k:
                left += 1
                ans[n-k] = '1'
            elif a[right] == k:
                right -= 1
                ans[n-k] = '1'
            else:
                break
        
        print(''.join(ans))

if __name__ == "__main__":
    solve()
```代码首先检查数组是否是一个排列`k=1`并设置第一个字符`ans`。 然后它使用两指针方法来验证增加长度是否可以形成有效的排列，更新`ans`从结束到开始。 这避免了显式地重新计算子数组最小值并保持线性时间复杂度。
