 ## 解决方案
 ## 问题理解

 我们得到一个无向连通图，其中每个顶点代表一个人，每条边代表一段友谊。 任务不是任意分配值，而是为每个顶点分配一个整数收入，以便每个友谊都满足一个非常严格的规则：沿着每条边，两个端点必须恰好相差 1，并且我们必须为该差异选择一个方向。 

每条边要么是有向的，这意味着我们被告知哪个端点的收入必须比另一个端点大一，要么是无向的，这意味着我们可以自由决定“+1”关系的走向。 如果我们分配收入，每条边都会成为“在与给定或选择的方向一致的某个方向上差异恰好为 1”形式的约束。 

在所有有效的分配中，我们被要求最大化最大和最小分配收入之间的差异。 如果没有分配可以满足所有约束，我们必须报告不可能性。 

关键结构是每条边都在有向意义上强制执行严格的单位步骤。 这意味着一旦方向固定，收入就变成图中的距离，其中每个边权重恰好为 1，但有方向限制。 

约束很小，允许我们将每个顶点视为图问题中的一个状态，而不需要严重的渐近。 当 n 达到 200、m 达到 2000 时，甚至 O(nm) 或 O(n^2 + m log n) 风格的推理也是可以接受的。 我们无法承受的是边缘方向的指数枚举，因为 2^2000 是不可能的。 

一些失败案例是微妙的。 

一种失败模式是假设我们总是可以贪婪地分配方向。 例如，在所有边都是无向的三角形中，任意选择方向可能会产生矛盾：循环可能会迫使严格的不等式链以非零和返回到开头，这是不可能的。 

另一种失败模式是在传播值时忽略定向约束。 如果有向边迫使 u 高于 v，但其他地方的路径意味着相反，即使局部检查通过，我们也会得到矛盾。 

第三个问题是假设该图是通常意义上的二分图。 这不是二分着色；而是二分着色。 它是一个差分约束系统，其周期之和必须为零。 

## 方法

 如果我们尝试暴力解决问题，我们将为每个无向边分配一个方向，然后检查结果约束是否一致。 这导致我们从任意根传播值并验证所有边是否满足其所需的差异的系统。 有 2^k 个选择，其中 k 是无向边的数量，并且 k 可以大到 2000，这使得这是不可行的。 

关键的观察是，一旦方向固定，问题就变成了以下形式的方程组

 a_j = a_i + 1 或 a_i = a_j + 1

 这相当于在具有加权有向边的图中分配势。 这种系统的一致性仅取决于循环总和为零。 

我们不是先选择方向，而是翻转视角。 每条边都提供一个约束，可以将其编码为变量之间的关系，而可行性则变成检查我们是否可以分配值以使所有约束同时成立。 这是一个经典的差分约束系统问题。 

然后我们优化次要目标：最大化值的范围。 一旦我们知道了可行性，最大化范围就相当于选择一个起点并让结构传播，但有一个转折：图可以分解为多个组件，并且我们实际上希望在极端之间实现最长的最短路径扩展。

我们可以将该结构解释为一个有向图，其边权重为 +1 或 -1，具体取决于方向。 有向边是固定的，无向边可以分配给任一方向，但必须一致选择，以免出现矛盾。 

解决这个问题的简洁方法是将其建模为一个图，我们尝试分配一个潜在的 a_i 并检查每条边是否可以定向，以便 |a_i - a_j| = 1，同时遵守固定方向。 这成为具有类似奇偶校验结构但具有实际整数差异的图上的约束传播问题。 

我们将其简化为构建约束图并使用带有差异分配的 BFS/DFS 检查一致性。 对于每个连接的组件，我们尝试通过将一个节点固定为 0 并传播来分配值。 如果我们遇到矛盾，这个制度就行不通。 

为了最大化范围，我们计算这些约束下每个分量的最小和最大可能值。 由于每个边缘强制执行单位步骤，因此组件中的值取决于全局移位和可能的反射。 我们计算距离并在约束一致分配中使用最远的对。 

这导致计算受约束的有向结构中的最长最短路径，这可以由 BFS 处理，因为一旦有向，所有边权重都是 ±1。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（边缘方向）| O(2^m · (n + m)) | O(2^m · (n + m)) | O(n + m) | 太慢了|
 | 约束传播+BFS/DFS | O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 我们将问题转化为约束图，其中每条边在必须一致的方向上强制执行恰好为 1 的差异。 

1. 构建邻接表示，其中每条边都成为约束关系。 对于有向边 u → v，我们强制 a[v] = a[u] + 1。对于无向边 u - v，我们暂时将其视为双向约束，允许 a[v] = a[u] + 1 或 a[u] = a[v] + 1。 
2. 我们尝试使用 BFS 在每个连接的组件上分配值。 我们选择一个未访问的节点并将其值设置为 0。从该节点开始，我们沿着边缘传播，根据所需的 +1 差异分配邻居值。 
3. 当遍历有向边 u → v 时，如果未赋值，则设置 a[v] = a[u] + 1，否则检查一致性。 如果 a[v] 已经被赋值并且与 a[u] + 1 不同，我们检测到矛盾并停止。 
4. 对于无向边，我们通过传播隐式地尝试两个方向。 在实践中，我们将每个无向边视为两个可能的有向约束，但确保 BFS 产生的任何分配都必须保持一致。 如果 BFS 强制两个方向不一致，则该组件是不可能的。 
5. 在分配值时，我们跟踪每个组件达到的最小值和最大值。 这是必要的，因为最终的答案取决于最大化全球传播。 
6. 处理完所有组件后，如果没有发现矛盾，我们将移动所有值，使全局最小值变为 0，在生成有效分配的同时保留差异。 

### 为什么它有效

 每条边都强制执行严格的单位差异约束，因此任何有效的分配都对应于图上的潜在函数，其中每条边都强制执行固定梯度。 BFS 一致地分配这些电位，任何循环矛盾都表现为对先前访问过的节点的分配不一致。 由于每个边约束都是线性且单位权重的，因此一致性检查简化为验证所有隐含方程是否一致。 一旦一致性成立，统一移动所有值就可以保持有效性，因此最大化范围会减少到选择自然的基于最小值的归一化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    
    g_dir = [[] for _ in range(n)]
    g_und = [[] for _ in range(n)]
    
    edges = []
    
    for _ in range(m):
        u, v, b = map(int, input().split())
        u -= 1
        v -= 1
        if b == 1:
            g_dir[u].append(v)
        else:
            g_und[u].append(v)
            g_und[v].append(u)
        edges.append((u, v, b))
    
    INF = 10**18
    val = [None] * n
    
    def bfs(start):
        q = deque([start])
        val[start] = 0
        mn = 0
        mx = 0
        
        while q:
            u = q.popleft()
            
            for v in g_dir[u]:
                if val[v] is None:
                    val[v] = val[u] + 1
                    mn = min(mn, val[v])
                    mx = max(mx, val[v])
                    q.append(v)
                else:
                    if val[v] != val[u] + 1:
                        return False, 0, 0
            
            for v in g_und[u]:
                if val[v] is None:
                    val[v] = val[u] + 1
                    mn = min(mn, val[v])
                    mx = max(mx, val[v])
                    q.append(v)
                else:
                    if abs(val[v] - val[u]) != 1:
                        return False, 0, 0
        
        return True, mn, mx
    
    total_min = 0
    total_max = 0
    
    for i in range(n):
        if val[i] is None:
            ok, mn, mx = bfs(i)
            if not ok:
                print("NO")
                return
            total_min = min(total_min, mn)
            total_max = max(total_max, mx)
    
    shift = -total_min
    ans = [x + shift for x in val]
    
    print("YES")
    print(total_max - total_min)
    print(*ans)

if __name__ == "__main__":
    solve()
```该代码构建两个邻接列表，一个用于强制方向边，另一个用于灵活边。 然后，它从每个未访问的节点执行 BFS，将值指定为约束图中的距离。 分配中的任何不一致都会立即拒绝该实例。 

一个微妙的实现点是，无向边被视为强制执行绝对差值 1，这是通过检查来强制执行的`abs(val[v] - val[u]) != 1`。 这确保了即使 BFS 隐式分配方向，约束也会得到遵守。 

最终的全球转变至关重要，因为只有相对差异才重要。 如果不进行移位，可能会出现负值，但问题是允许任何范围，只要标准化后的值在范围内即可。

 | 2 | 2 | 1 | 从 1 通过无向边 |

```我们尝试赋值：

 从 1 = 0 开始。然后 2 = 1, 3 = 2。但是边 (3,1) 要求 abs(2 - 0) = 1，这是错误的，因为它是 2。当使用冲突的隐含值重新访问节点 1 时，BFS 会检测到这种矛盾。

 ## 边缘情况

 一个重要的边缘情况是当无向边缘循环产生矛盾时。 在这种情况下，BFS 分配的值最终会尝试为已访问过的节点重新分配不同的值。 该算法立即检测到这种不匹配并拒绝该实例。 

另一种边缘情况是有向边施加的约束通过无向路径间接发生冲突。 即使每条边看起来都是有效的，传播的值最终在共享顶点上会不一致，这在 BFS 一致性检查期间会被捕获。 

最后的边缘情况是所有边缘都是无向的树结构。 这里，BFS 分配一个具有交替值的有效二分结构，最大范围成为单位权重意义上的树的直径，这可以通过传播自然捕获，无需额外的逻辑。
