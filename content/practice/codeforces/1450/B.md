 ## 解决方案
 ## 问题理解

 我们有几个钢球放置在平面上不同的坐标处。 带电球的作用就像一块磁铁，其半径以曼哈顿距离为单位。 当我们对一个球充电时，每个与它的曼哈顿距离最多为`k`立即移动到带电球的位置。 

目标是让所有球占据一个位置。 我们可以执行任意数量的收费操作。 对于每个测试用例，我们必须确定所需的最小操作数，否则报告无法完成。 

限制异常小。 每个测试用例最多包含100个点，并且测试用例最多有100个。 甚至一个`O(n²)`或者`O(n³)`解决方案很容易足够快。 和`n = 100`， 一个`O(n²)`算法每个测试用例仅执行 10,000 次距离检查。 

第一个边缘情况是当所有点都位于距离内时`k`某个点。 例如：```
3 3
6 7
8 8
6 9
```每个点与其他点的距离都在 3 之内。 对任何一个球充电都会立即聚集所有球，所以答案是`1`， 不是`0`。 该问题要求使所有球重合所需的最少操作次数，并且最初它们是不同的。 

当点形成连接链但没有一个点可以到达所有其他点时，会发生另一种微妙的情况：```
4 1
0 0
0 1
0 2
0 3
```每个点都与其邻居很接近，但没有一个点与其他点的距离至多为 1。粗心的解决方案可能会假设重复操作可以逐渐合并所有内容。 他们不能。 正确答案是`-1`。 

第三种边缘情况是`k = 0`。 由于所有坐标都是不同的，因此没有球可以吸引任何其他球。 答案总是`-1`。 

## 方法

 强力模拟将尝试充电操作序列并跟踪点的移动方式。 这样的搜索很快就会变得复杂，因为每次操作后状态都会发生变化，并且可能的序列数量呈指数增长。 

关键的观察结果是答案永远不会大于一。 

假设所有球最终都到达某个位置。 该最终位置必须是原始球位置之一。 球永远不会创建新的坐标。 每个动作都会复制带电球的位置。 

考虑成功序列中的最后一个操作。 此时，每个剩余的球都必须移动到带电球的位置。 因此每个球都必须已经在距离之内`k`那个带电的球。 

由于移动的球只是将其位置改变到现有球的位置，如果某个原始球可以直接吸引所有其他原始球，那么一次操作就足够了。 如果不存在这样的球，则后面的任何操作序列都无法创建该球。 

这将整个问题简化为检查是否存在一个点，其与其他点的曼哈顿距离最多为`k`。

 | ---| ---| ---| ---|

 | 检查每个候选人中心 | O(n²) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读测试用例的所有要点。 
2. 对于每一点`i`，将其视为可能的聚集点。 
3. 计算到点的曼哈顿距离`i`到其他所有点。 
4.如果所有距离最多`k`，然后是充电点`i`在一次操作中收集所有球。 输出`1`。 
5. 如果没有点满足该条件，则输出`-1`。 

### 为什么它有效

 假设存在成功的序列。 看看最后的操作。 带电的球有一定的位置`P`，这是原始球坐标之一。 成为最终合并位置一部分的每个球都必须在距离内`k`的`P`那一刻。 

由于整个过程中的所有位置都是从原始球位置复制的，因此最终聚集点必须与原始点相对应。 如果那个原点不能直接吸引其他的原点，那么就没有办法让那个点参与最终的合并。 因此，当且仅当某个原点在距离内时，解才存在`k`每个原始点。 

当存在这样的点时，一次操作立即收集所有球。 否则任何序列都无法成功。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    possible = False

    for x1, y1 in pts:
        ok = True

        for x2, y2 in pts:
            if abs(x1 - x2) + abs(y1 - y2) > k:
                ok = False
                break

        if ok:
            possible = True
            break

    print(1 if possible else -1)
```外环测试每个点作为潜在的聚集中心。 内循环验证其他所有点是否位于曼哈顿距离内`k`。 

早期的`break`语句很有用，但不是必需的。 一旦距离超过`k`，该候选人不能再工作。 一旦找到一位有效的候选人，答案就已知了。 

曼哈顿距离必须计算为：```
abs(x1 - x2) + abs(y1 - y2)
```使用欧几里德距离或平方距离可以解决不同的问题。

 ## 边缘情况

 考虑：```
1
2 0
0 0
1 0
```点之间的距离为1，超过`k = 0`。 该算法检查两个点并拒绝两个候选者。 它输出`-1`。 

考虑：```
1
2 5
0 0
3 2
```曼哈顿距离正好是 5。因为条件是距离最多`k`，两点均合格。 算法正确输出`1`。 

考虑一下链条：```
1
4 1
0 0
0 1
0 2
0 3
```中间点看起来很有希望，因为它们离邻居很近。 该算法计算到每个点的距离，发现到一个端点的距离为 2，拒绝每个候选点，并输出`-1`。 

考虑一个点占主导地位的情况：```
1
5 10
0 0
1 1
2 2
3 3
4 4
```重点`(0,0)`与其他点的曼哈顿距离最多为 8。 算法立即接受并输出`1`。 这证实了提前退出逻辑是正确的。
