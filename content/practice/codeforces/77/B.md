 ## 解决方案
 ## 问题理解

 我们得到两个随机均匀选择的实数参数。 

受害人身高`p`位于区间内`[0, a]`，和风参数`q`在于`[-b, b]`。 对于每对`(p, q)`，如果某个二次方程至少有一个实根，则砧成功撞击。 

该语句的等式为：$x^2+px+q=0$当二次方程的判别式为非负时，它就有实根。 因此，整个问题简化为计算以下概率：$p^2-4q\ge0$自从`p`和`q`统一且独立地选择，这个概率就是所有有效的区域`(p, q)`对除以矩形的总面积：$0\le p\le a,\ -b\le q\le b$从算法的角度来看，约束非常小。 我们只处理最多`10^4`测试用例，每个用例仅包含两个整数。 每个测试用例的任何恒定时间数学公式都足够快。 甚至一个`O(log n)`或者`O(sqrt n)`解决方案会很顺利地通过。 真正的挑战是导出正确的几何形状并仔细处理边界情况。 

棘手的情况来自抛物线与矩形的相互作用。 

考虑：```
a = 1, b = 100
```抛物线`q = p² / 4`与矩形高度相比保持非常低。 大多数点都失败了，所以概率接近`1/2`，不接近`1`。 

粗心的实现可能会假设抛物线总是到达顶部边界`q = b`，这里是错误的。 

另一个重要的边缘情况是：```
a = 0, b = 5
```然后`p`始终为零，因此条件变为：```
-4q >= 0
```这意味着`q <= 0`。 恰好是间隔的一半`[-5, 5]`有效，所以答案是`0.5`。 

有问题的推导通常除以`a`某处崩溃或产生 NaN 时`a = 0`。 

最后一个微妙的情况是当抛物线恰好触及顶部边缘时：```
a = 4, b = 4
```因为`a² / 4 = 4`。 

集成精确地改变了该边界处的行为。 在错误的地方使用严格的不等式可能会引入小的浮点错误或选择错误的公式。 

## 方法

 蛮力的观点很简单。 我们可以想出所有可能的矩形`(p, q)`配对并检查每个点是否满足：$q\le\frac{p^2}{4}$如果我们将矩形离散成非常精细的网格，计算有多少个单元格满足不等式，然后除以单元格总数，我们就得到了概率的近似值。 

这在概念上是有效的，因为均匀随机选择直接对应于面积比。 问题是精度。 达到`10^-6`精度，网格将需要数百万或数十亿个样本。 为了`10^4`测试用例，这变得完全不切实际。 

关键的观察结果是有效区域具有非常简单的几何形状。 

对于每一个固定的`p`，有效值`q`是：$-b\le q\le\min\left(b,\frac{p^2}{4}\right)$因此，我们可以精确地积分该间隔的高度，而不是用数字近似面积。 

自然会出现两种情况。 

如果：$\frac{a^2}{4}\le b$那么抛物线永远不会到达矩形的顶部边界。 每个的有效高度`p`是：$b+\frac{p^2}{4}$整合自`0`到`a`直接给出面积。 

如果相反：$\frac{a^2}{4}>b$然后在某个点之后，抛物线上升到矩形之上。 从那时起，每`q`价值作品。 

转换发生在：$p=2\sqrt b$这将积分分成两个简单的部分。 

整个解决方案成为每个测试用例的恒定时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(K²) | O(1) | O(1) | 太慢了|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.从二次判别条件开始。 

当满足以下条件时，方程有实根：$p^2-4q\ge0$重新排列给出：$q\le\frac{p^2}{4}$2. 从几何角度解释概率。 

所有可能的对`(p, q)`形成一个面积为矩形的区域：$2ab$答案等于：

 有效面积/总面积。 
3. 确定固定的有效垂直间隔`p`。 

自从`q`范围从`-b`到`b`，我们还需要：$q\le\frac{p^2}{4}$有效高度变为：$\min\left(b,\frac{p^2}{4}\right)+b$4. 处理抛物线永远不会到达顶边的第一种情况。 

如果：$a\le2\sqrt b$然后：$\frac{p^2}{4}\le b$对于每一个`p`在`[0, a]`。 

有效面积为：$\int_0^a\left(b+\frac{p^2}{4}\right)dp=ab+\frac{a^3}{12}$除以`2ab`给出：$\frac12+\frac{a^2}{24b}$5. 处理抛物线穿过顶边的第二种情况。 

如果：$a>2\sqrt b$然后对于`p > 2√b`， 每一个`q`价值作品。 

将区域分为两个区域。 

第一个区域，来自`0`到`2√b`，贡献：$\int_0^{2\sqrt b}\left(b+\frac{p^2}{4}\right)dp=\frac{8}{3}b^{3/2}$第二个区域，来自`2√b`到`a`，贡献整个矩形的高度：$2b(a-2\sqrt b)$求和并简化产量：$1-\frac{2\sqrt b}{3a}$6. 打印当前案例对应的公式。 

### 为什么它有效

 该算法直接计算所有成功的精确度量`(p, q)`采样矩形内的对。 对于每一个固定的`p`，我们精确计算有多少垂直区间满足判别条件。 将这些有效长度整合到所有`p`值给出了准确的成功区域。 

分为两种情况是详尽的，因为抛物线要么在整个区间内保持在矩形顶边下方，要么恰好与矩形顶边相交一次。 不可能有其他几何行为。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

t = int(input())

for _ in range(t):
    a, b = map(float, input().split())

    if b == 0:
        print("1.0000000000")
        continue

    if a * a <= 4 * b:
        ans = 0.5 + (a * a) / (24.0 * b)
    else:
        ans = 1.0 - (2.0 * math.sqrt(b)) / (3.0 * a)

    print(f"{ans:.10f}")
```该实现遵循演练的精确推导。 

第一个分支句柄`b = 0`分别地。 在那种情况下，`q`始终为零，因此二次项始终有实根，因为判别式变为`p²`。 概率正好是`1`。 

第二个分支检查抛物线是否到达矩形的顶部边界。 使用：```
a * a <= 4 * b
```避免不必要的平方根，还避免边界周围的小浮点精度问题。 

这些公式直接作为浮点表达式进行计算。 所有中间值都适合标准双精度，因为`a`和`b`至多是`10^6`。 

十位小数的格式可以轻松满足所需的精度公差。

import sys
import io
import math

def solve():
    input = sys.stdin.readline

    t = int(input())

    out = []

    for _ in range(t):

        if b == 0:

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    return sys.stdout.getvalue()

 ## 边缘情况

 考虑：```
1
0 5
```这里`p`固定为零。 条件变为：$-4q\ge0$这意味着：$q\le0$里面`[-5, 5]`，正好有一半的时间间隔有效。 该算法进入第一个公式分支，因为：```
a² <= 4b
```并计算：```
0.5 + 0 / (24 * 5) = 0.5
```这是正确的。 

现在考虑：```
1
4 4
```抛物线恰好与顶部边界相交`p = 4`。 两个导出公式产生相同的值：```
2 / 3
```实现使用`<=`在分支条件下，因此边界的处理是一致的，没有不连续性。 

最后，考虑：```
1
10 0
```然后`q`始终为零，并且每个二次方都有判别式：$p^2$这始终是非负的。 专注的`b == 0`分行回报`1.0`立即，避免公式中除以零。
