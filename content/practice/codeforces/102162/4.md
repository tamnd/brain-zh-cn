 ## 解决方案
 ## 问题理解

 该问题给出了因式分解的多项式

 [
 P(X)=(X+a_1)(X+a_2)\cdots(X+a_n),
 ]

 其中 (1\le n\le 9) 和每个 (a_i) 都是从 (-10) 到 (10) 的整数。 我们需要扩展它并以所需的紧凑符号打印得到的多项式。 官方问题是 Codeforces 100F，“Polynom”，一个特殊的实现问题，限制为 2 秒，内存为 64 MB。 

例如，

 [
 (X-1)(X+1)=X^2-1,
 ]

 所以输出是`X^2-1`。 如果

 [
 (X+1)(X+1)=X^2+2X+1,
 ]

 紧凑的输出是`X^2+2*X+1`。 该声明在概念上将每个术语描述为`C*X^K`，但省略了不必要的部分。 因此，不打印系数 (1)，不打印指数 (1)，并且常数项不包含`*X^0`。 零项被完全省略。 

小界限 (n\le9) 意味着即使是相当直接的实现也足够快。 对于普通的 Python 整数来说，系数本身也足够小，尽管 Python 无论如何都能安全地处理更大的整数。 由于次数最多为 9，因此我们永远不需要复杂的多项式算法。 有用的目标就是 (O(n^2))，它对于这些约束来说实际上是常数。 

在多种格式化情况下，正确的多项式展开可能会产生错误的答案。 用于输入```
1
0
```多项式为 (X)，因此正确的输出为`X`， 不是`1*X^1`。 后者表示相同的数学值，但不是所需的最短表示。 

为了```
1
-5
```多项式为 (X-5)，因此输出为`X-5`。 统一处理每个系数的格式化程序可能会错误地生成`X+-5`。 

为了```
2
0
0
```多项式为 (X^2)，因此输出为`X^2`。 两个低阶系数均为零且必须消失。 粗心的实现可能会打印`X^2+0*X+0`。 

最后，为了```
2
-1
1
```中间系数为零，给出`X^2-1`。 这捕获了在负系数之前打印加号或保留零中间项的常见错误。 官方样本包括这个确切的案例。 

## 方法

 获得每个系数的强力方法是直接使用多项式乘法的定义。 对于 (n) 个因子的每个子集，选择 (X) 部分或 (a_i) 部分。 大小 (k) 的子集对 (X^{n-k}) 的系数有贡献，其值等于所选 (a_i) 的乘积。 枚举所有 (2^n) 个子集并处理每个子集最多 (n) 个元素的成本 (O(n2^n))。 在最大规定值 (n=9) 下，这只是 (9\cdot512=4608) 个基本选择，因此对于原始约束来说它实际上足够快。 问题是该方法呈指数级扩展，在 (n=30) 时变为约 (30\cdot2^{30})，超过 320 亿次操作。 

更好的观察是，多项式乘法已经准确地给出了我们需要的信息，而无需单独考虑每个子集。 从多项式 (1) 开始。 处理因子 (X+a_i) 时，将当前多项式乘以该线性多项式。 如果当前系数数组为 (c)，则 (j) 度的新系数会收到两个贡献：选择 (X) 时的 (c_j) 和选择 (a_i) 时的 (a_i c_{j-1})。 当当前次数为 (k) 时，每次乘法都需要 (O(k))，因此处理所有 (n) 个因子的成本为 (O(n^2))。 

蛮力之所以有效，是因为每个系数最终都是从每个因子中选择一项而获得的乘积之和，但它会重复重建普通多项式乘法立即聚合的组合。 每个新因子只有两项的观察结果让我们可以一次性更新所有系数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(n2^n)) | (O(n)) | (O(n)) | 已接受 (n\le9)，可扩展性差 |
 | 最佳| (O(n^2)) | (O(n)) | (O(n)) | 已接受 |

 ## 算法演练

 1.读取(n)和(n)值(a_i)。 用数组表示当前多项式`coef`， 在哪里`coef[j]`是 (X^j) 的系数。 最初多项式为 (1)，因此`coef = [1]`。 
2. 处理每个因子(X+a_i)。 假设当前多项式的次数为 (k)。 创建一个长度为 (k+2) 的新数组，因为乘以线性因子会使次数增加 1。 
3. 对于每个现有系数`coef[j]`，将其添加到`new[j + 1]`。 这对应于取 (X+a_i) 的 (X) 部分，这会将次数加一。 
4. 对于相同的系数，加上`coef[j] * a_i`到`new[j]`。 这对应于取常数部分 (a_i)，使度数保持不变。 
5. 用新计算的系数数组替换当前系数数组。 处理完所有因子后，数组包含完整多项式的系数，从索引 0 处的常数项到索引 (n) 处的首项系数。 
6. 将系数从 (n) 次向下遍历到零。 跳过每个等于零的系数，因为它的项对多项式没有任何贡献。 
7. 对于每个非零系数，构造其最短表示。 对于零度，仅打印系数。 对于一级，请打印`X`当绝对系数为1时，否则打印`C*X`。 对于更高学位，请打印`X^K`当绝对系数为1时，否则打印`C*X^K`。 
8. 添加`+`在积极的非主导术语之前和`-`在否定的非主导术语之前。 对于绝对值为 1 的系数，不要打印数字系数本身。 

关键的不变量是在处理前 (i) 个因素后，`coef[j]`正是 (X^j) 的系数

 [
 \prod_{k=1}^{i}(X+a_k)。 
]

 将此多项式乘以 (X+a_{i+1}) 会为每个现有项准确创建两个贡献，一项移动一度，一项乘以 (a_{i+1})。 因此，更新可以精确计算带有一个附加因子的多项式的系数。 通过归纳，最终因子后每个系数都是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = [int(input()) for _ in range(n)]

    # coef[j] is the coefficient of X^j.
    coef = [1]

    for value in a:
        new = [0] * (len(coef) + 1)

        for j, c in enumerate(coef):
            # Take X from (X + value).
            new[j + 1] += c

            # Take value from (X + value).
            new[j] += c * value

        coef = new

    terms = []

    for power in range(n, -1, -1):
        c = coef[power]

        if c == 0:
            continue

        if power == 0:
            body = str(abs(c))
        elif power == 1:
            if abs(c) == 1:
                body = "X"
            else:
                body = f"{abs(c)}*X"
        else:
            if abs(c) == 1:
                body = f"X^{power}"
            else:
                body = f"{abs(c)}*X^{power}"

        if not terms:
            if c < 0:
                terms.append("-" + body)
            else:
                terms.append(body)
        else:
            if c < 0:
                terms.append("-" + body)
            else:
                terms.append("+" + body)

    print("".join(terms))

if __name__ == "__main__":
    solve()
```系数数组初始化为`[1]`因为多项式乘法的中性元素是常数多项式 (1)。 对于每个输入值，`new[j + 1] += c`处理 (X) 贡献并`new[j] += c * value`处理持续的贡献。 

该表示以递增的程度顺序存储，这使得乘法更新特别简单。 最终的遍历方向相反，因为标准多项式表示法首先打印最高次数。 

格式化代码故意使用`abs(c)`用于术语的主体。 该符号是单独处理的，这会阻止诸如`X+-5`。 第一项也单独处理，因为它没有收到明确的`+`符号。 

Python 整数具有任意精度，因此不存在溢出问题。 对于 (n\le9) 和 (|a_i|\le10)，系数实际上无论如何都非常小。

 ## 边缘情况

 对于最小尺寸输入```
1
0
```该算法开始于`[1]`。 乘以 (X+0) 产生`[0, 1]`。 一阶系数为 1，因此格式化程序发出`X`而不是`1*X`。 常数系数为零并消失。 

为了```
1
-10
```系数数组变为`[-10, 1]`。 一级术语是主导的`X`，而常数项为负。 由于它是第二项，因此格式化程序添加`-`然后打印它的绝对值，产生`X-10`。 

为了```
2
0
0
```第一个乘法给出`[0, 1]`，第二个给出`[0, 0, 1]`。 两个低阶系数均为零，因此唯一幸存的项是`X^2`。 打印每个度数的格式化程序会错误地生成`X^2+0*X+0`。 

为了```
2
-10
10
```第一个因素产生`[-10, 1]`。 乘以 (X+10) 得出`[−100, 0, 1]`。 中间的系数完全抵消，所以输出是`X^2-100`。 这捕获了零项处理和符号处理。 

最微妙的格式化情况是系数等于 (1) 或 (-1)。 例如，```
2
-1
-1
```给出

 [
 (X-1)^2=X^2-2X+1。 
]

 二次系数为`1`，所以就变成了`X^2`; 一阶系数是`-2`，所以就变成了`-2*X`; 常数系数为`1`，所以就变成了`+1`。 最终输出是`X^2-2*X+1`，没有不必要的系数或指数符号。
