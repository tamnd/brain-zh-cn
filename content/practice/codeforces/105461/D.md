 ## 解决方案
 ## 问题理解

 我们有一个系统，允许我们从初始位集构造新的位集$B_0$。 每个位组都有长度$n$，并且我们可以仅使用一小组操作来生成新的：左移或右移、异或以及先前构造的位集之间的或。 位的索引是从右到左定义的，因此最右边的位置是最低有效位。 

任务不是计算给定程序的结果，而是用这种受限语言设计程序。 当该程序在任何输入位集上运行时$B_0$，它必须产生一个最终的位集，其中恰好包含$B_0$，其他地方都是零。 换句话说，输出应该是表示输入中包含的两个的最低幂的位集。 

约束条件$n \le 100000$与评估程序的运行时间无关，而是与我们在概念上模拟的位集的大小有关。 真正的限制是我们只能用这种自定义语言输出最多 100 个操作，因此任何构造都必须非常紧凑。 

一个天真的误解是认为我们可以单独检查位或模拟从右到左的扫描。 这是不可能的，因为没有分支，没有比较，也没有直接访问索引。 所有转换必须是全局应用的统一按位运算。 

一种微妙的边缘情况是输入仅设置了一位。 例如，如果$B_0 = 00001000$，正确的输出是相同的位集不变。 任何假设至少两位或尝试从较低位置“传播”信息的构造在这种退化情况下仍必须保持正确性。 

另一种边缘情况是最低有效位已经位于位置 0。 任何基于移位的构造都必须避免意外地将其移位或通过异或取消它。 

## 方法

 暴力思维会尝试模拟经典的位技巧来隔离最低有效设置位：$x \& (-x)$。 但是，此操作依赖于算术否定和按位 AND，这两种操作在该语言中都不可用。 我们只有移位、异或和或，这使得直接算术构造变得不可能。 

另一个想法是使用移位和组合从右侧逐步“过滤”位，尝试删除所有较高位，同时保留最低位。 困难在于，我们无法测试特定位置是否存在某个位，因此我们必须构建二的幂的结构表示，并用它来隔离最低的活跃位置。 

关键的观察是我们不需要识别最低有效位的位置。 相反，我们可以使用加倍合并策略构建输入的完整二进制分解。 如果我们可以构建代表位范围的掩码，我们就可以重复地细化只保留最低活动段的结构，最终将其压缩为单个位。 

该构造使用了一个经典的想法：构建一系列覆盖不断增加的间隔的掩模，例如$1$,$2$,$4$,$8$等等，并以模拟右侧前缀覆盖的方式组合它们。 OR 合并累积覆盖范围，而 XOR 可用于在通过轮班对称性精心构建时取消重叠贡献。 

最终程序本质上是全角掩码的对数构造，其行为类似于“最右边的活动位提取器”。 蛮力直觉需要扫描所有位，但移位合并层次结构将其压缩为$O(\log n)$层，每个层都用恒定数量的操作进行模拟。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力扫描模拟| 条件限制下不可能| O(n) 概念 | 不允许 |
 | 双班结构 | O(log n) 次操作 | O(1) 额外结构 | 已接受 |

 ## 算法演练

 我们构建了一系列中间位组，逐步构建越来越大的移位模式。 目标是创建一个系统，该系统可以通过隔离来自移位副本的信息停止重叠的第一个点来“选择”最低设置位。 

1. 从$B_0$，输入位集。 这是唯一的信息来源，因此所有构造最终都必须依赖于它。 
2. 构建$B_1 = B_0 \;|\; (B_0 \ll 1)$。 这将创建一个掩码，其中每个设置位$B_0$也影响其左近邻居。 目的是开始向上传播存在信息。 
3. 重复合并移位版本的想法，每次将移位距离加倍。 在步骤$k$，我们将一个位集与其版本移位的位集组合起来$2^k$。 每个阶段都会以指数方式扩大影响范围，使我们能够在位集上编码类似前缀的结构。 
4. 维护在每个阶段之后，构造的bitset表示在大小的窗口中是否存在集合位$2^k$在每个位置结束。 这会将原始位转换为间隔摘要。 
5. 之后$O(\log n)$阶段，我们获得一个结构，其中每个位置编码以该位置结尾的前缀中是否存在任何位。 这有效地编码了从右到左的累积 OR。 
6. 在该累积结构的连续移位版本之间使用 XOR 来隔离第一个有效位出现的边界。 XOR 取消了重叠区域，只留下过渡点。 
7. 再次移位和组合，以将该转换标准化为与最低有效设置位对齐的单位表示。 

### 为什么它有效

 该结构保持不变：在$k$-th 倍增阶段，每个位置存储大小块内是否存在任何原始设置位$2^k$到那个位置结束。 这个不变量成立是因为 OR 保留了合并区间的存在性，并且移位正确地对齐了这些区间。 

一旦块大小超过$n$，每个位置都正确反映其右侧是否存在任何设置位。 最低有效位正是该累积信息从假转变为真的位置。 相邻累积状态之间的 XOR 唯一地隔离了该转换，因为 XOR 取消了相同的前缀区域并保留了边界。 

因为每个操作仅依赖于先前构建的有效摘要，所以不会发生错误传播，并且最终的隔离位必须对应于原始输入的最低有效设置位。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

ops = []

def add(op):
    ops.append(op)

# We build a prefix-OR style doubling structure.
# We maintain a working register cur starting from B0.
cur = 0

# We simulate power-of-two shift merging.
# We cannot actually refer to bitsets symbolically in code,
# so we output a fixed construction pattern.

# Step 1: build OR with shift 1
add("B1 = B0 << 1")
add("B2 = B0 | B1")

# Step 2: expand to 2, 4, 8, ... up to cover n
shift = 1
prev = "B2"
idx = 2

while shift < n:
    add(f"B{idx+1} = {prev} << {shift}")
    add(f"B{idx+2} = {prev} | B{idx+1}")
    prev = f"B{idx+2}"
    idx += 2
    shift *= 2

# Final isolation step using XOR of last two states
add(f"B{idx+1} = {prev} ^ ({prev} << 1)")

print(len(ops))
for op in ops:
    print(op)
```该实现构建了一个双班制链，其中每个阶段将当前结构与其自身的移位版本合并。 目的是模拟设置位影响范围呈指数增长，这是在 100 次操作限制内达到所有位置的唯一方法。 

最后的 XOR 步骤用于提取连续累积区域之间的边界。 该边界对应于最低有效设置位，因为它是累积可达性从空变为非空的第一个位置。 

一个微妙的点是我们从不尝试直接检查位。 每个转换都是统一的，并且仅依赖于先前构造的位集，这在语言约束下保持了有效性。 

## 工作示例

 考虑$n = 8$输入位集的最低设置位位于位置 2（从右侧）。 

我们跟踪概念输入在累积 OR 和变化下如何演变：

 | 步骤| 运营| 概念效果|
 | ---| ---| ---|
 | 1 |$B_1 = B_0 << 1$| 将所有位左移 |
 | 2 | (B_2 = B_0 | B_1) |
 | 3 | 双班制 | 将影响范围扩大至 4 |
 | 4 | 下一个或 | 合并更广泛的覆盖范围|
 | 决赛| 异或步骤 | 隔离边界 |

 关键的观察是，在重复加倍之后，每个位置都对其右侧是否存在任何原始位进行编码。 XOR 步骤检测此属性从 false 翻转为 true 的位置，这正是最低有效设置位。 

这个例子表明，构造不依赖于位的具体位置，只依赖于过渡边界的存在。 

例如，考虑仅设置最高位的输入$10000000$。 

| 步骤| 状态|
 | ---| ---|
 | 初始| 单个有效位|
 | 合并后 | 除边界处外，所有前缀均保持为 false |
 | 最终异或| 隔离相同的位|

 这里算法完全退化，因为在 OR 传播期间没有发生取消。 XOR 步骤不会引入杂散位，因为只有一个活动区域。 

这证实了稀疏和极端输入的正确性。

 ## 边缘情况

 一位输入，例如$B_0 = 00000001$在所有基于 OR 的结构中保持稳定。 每次移位都会产生有效范围之外的零，因此 OR 不会引入任何新的活动位。 XOR 边界步骤也完全取消，因为没有第二个活动区域可以干扰。 

当最低有效位位于最高可能位置时，重复移位永远不会使其与另一个位重叠。 OR 传播仍然标记所有可到达的前缀，但转换在位集的边界处仍然定义良好，并且 XOR 可以正确隔离它，而不会产生溢出伪影。 

仅具有一位设置位的输入表明该构造必须保持幂等性。 每个阶段都使用单调或扩展，因此任何步骤都不能破坏现有的活动位，并且最终的异或只是提取结构而不是修改存在。
