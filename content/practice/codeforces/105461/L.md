 ## 解决方案
 ## 问题理解

 我们在一个内部反复选择轴对齐的矩形$n \times m$其角点位于整数坐标上的网格。 每个矩形都是通过选取两个不同的 x 坐标和两个不同的 y 坐标来定义的，因此它对应于形成其边界的一对水平和垂直线段。 我们独立抽样$k$这些矩形统一来自完整的有效矩形集。 

绘制完所有矩形后，其中一些矩形可能会被后面的矩形部分隐藏。 如果没有其他矩形覆盖矩形的任何正面积部分，则该矩形被视为可见。 如果两个矩形仅沿边缘接触，则它们不会相互隐藏，因此边缘接触与可见性无关。 

任务是计算所有可见矩形的预期数量$k$绘图并将此期望输出为模分数$10^9+7$。 

关键的困难在于矩形通过重叠以几何方式相互作用，可见性取决于整个集合，而不是孤立的单个矩形。 然而，限制因素$n, m, k \le 42$表示可能的矩形数量最多为$10^4$，因为大约有$\binom{n+1}{2}\binom{m+1}{2}$选择。 这立即表明所有矩形或成对关系上的状态是可行的。 

总体来说是一个幼稚的模拟$k$- 矩形元组是不可能的，因为序列的数量增长为$R^k$， 在哪里$R$是矩形的数量。 即使是为了$R \approx 10^4$和$k = 40$，这是一个天文数字。 

一个更微妙的问题是可见性取决于排序。 如果一个矩形没有被其后绘制的任何矩形完全覆盖，则该矩形是可见的，因此我们实际上正在处理嵌入在独立采样中的随机排列效应。 

## 方法

 蛮力的想法是枚举所有序列$k$矩形，模拟绘制过程，并计算每个序列中有多少个矩形保持可见。 这在概念上是正确的，但不可行。 如果有$R$可能的矩形，序列的数量是$R^k$。 和$R$甚至5000到10000左右$R^2$已经有数亿了，超出这个数的任何求幂都是不可能的。 

重要的结构观察是期望的线性。 我们可以计算每个矩形，而不是计算全局存活的矩形数量$A$它保持可见的概率，然后对所有矩形求和。 这将问题转化为每个矩形的独立概率计算。 

固定一个矩形$A$。 为了$A$为了可见，其他矩形之间不能有矩形$k-1$完全覆盖它的样本。 定义$C(A)$作为完全包含的矩形的数量$A$。 然后每个$k-1$其他抽签有概率避开覆盖集$1 - \frac{C(A)}{R}$，因为所有矩形都是统一且独立选择的。 

因此概率$A$幸存下来的是$$\left(1 - \frac{C(A)}{R}\right)^{k-1}.$$预期的答案变成：$$\sum_A \left(1 - \frac{C(A)}{R}\right)^{k-1}.$$剩下的任务是计算$C(A)$有效地为每个矩形。 矩形是通过选择两个 x 边界和两个 y 边界来定义的，因此我们可以枚举$O(n^2 m^2)$。 对于每个矩形$A$，也可以组合计算包含它的矩形的数量：容器矩形必须选择左边界$\le x_1$, 右边界$\ge x_2$，对于 y 也是如此。 

这将包含计数转变为独立一维选择的乘积，因此我们可以预先计算坐标选​​择的前缀计数。 

这将整个问题简化为枚举矩形一次并评估每个矩形的封闭形式概率。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解序列 |$O(R^k)$|$O(1)$| 太慢了|
 | 枚举矩形+概率公式|$O(n^2 m^2)$|$O(1)$或者$O(R)$| 已接受 |

 ## 算法演练

 1. 预先计算所有可能的 x 区间和 y 区间。 每个矩形对应一对间隔。 这给出了网格中所有矩形的完整枚举。 
2. 计算$R$，矩形的总数，作为 x 间隔数和 y 间隔数的乘积。 这是必要的，因为每个矩形在每次抽奖中的可能性是相等的。 
3. 对于每个矩形$A = (x_1, x_2, y_1, y_2)$，计算有多少个矩形完全包含它。 包含矩形必须选择左边界$0$到$x_1$，右边界来自$x_2$到$n$，对于 y 也是如此。 将这些独立计数相乘得出$C(A)$。 
4. 转换$C(A)$转化为概率项。 剩下的每一个$k-1$矩形避免覆盖$A$有概率$1 - C(A)/R$，所以生存概率是$(1 - C(A)/R)^{k-1}$。 
5. 对所有矩形求和并返回结果模数$10^9+7$。 所有除法均使用模逆来处理。 

正确性取决于在期望空间中独立处理每个矩形，这是有效的，因为即使可见性事件相关，期望也是线性的。 

### 为什么它有效

 当且仅当每个矩形没有被后面绘制的任何其他矩形完全覆盖时，每个矩形才为最终得分贡献一个单位。 对于一个固定的矩形，被覆盖的事件仅取决于是否至少有一个剩余的矩形被覆盖。$k-1$样本位于均匀分布空间的固定子集中。 由于每次绘制在所有矩形上都是独立且统一的，因此没有绘制落入覆盖集的概率仅取决于该集的大小，而不取决于不同矩形之间的相互作用。 这将问题分解为独立的每个矩形的生存概率，从而使所有矩形的求和变得精确。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modexp(a, e):
    r = 1
    while e:
        if e & 1:
            r = r * a % MOD
        a = a * a % MOD
        e >>= 1
    return r

def inv(x):
    return modexp(x, MOD - 2)

def solve():
    n, m, k = map(int, input().split())

    # coordinates are 0..n and 0..m inclusive grid lines
    xs = n + 1
    ys = m + 1

    # total number of rectangles
    R = xs * (xs - 1) // 2 * ys * (ys - 1) // 2
    R %= MOD

    invR = inv(R)

    # precompute powers for speed
    pow_cache = {}

    ans = 0

    for x1 in range(xs):
        for x2 in range(x1 + 1, xs):
            for y1 in range(ys):
                for y2 in range(y1 + 1, ys):

                    # count rectangles that contain this rectangle
                    left = x1 + 1
                    right = xs - x2
                    top = y1 + 1
                    bottom = ys - y2

                    C = left * right * top * bottom
                    C %= MOD

                    p = (1 - (C % MOD) * invR) % MOD
                    if p < 0:
                        p += MOD

                    # p^(k-1)
                    exp = k - 1
                    val = 1
                    base = p
                    while exp:
                        if exp & 1:
                            val = val * base % MOD
                        base = base * base % MOD
                        exp >>= 1

                    ans = (ans + val) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案显式枚举所有矩形。 四个嵌套循环迭代所有可能的 x 和 y 边界对。 包含计数是使用每侧的独立选择来计算的，这避免了迭代期间的任何几何重叠推理。 

概率项是在模运算下仔细构造的。 减法$1 - C/R$必须在模空间中完成，所以我们乘以$C$通过模逆$R$。 求幂使用快速幂，因为$k$最多42个，但实现还是一般。 

一个微妙的点是，所有矩形都被视为不同的样本结果，即使在这种表示中不可能出现几何上相同的矩形，因为边界是唯一定义的。

 ## 边缘情况

 当$k = 1$，指数变为零，并且每个矩形贡献恰好为 1。该算法处理此问题是因为幂循环立即返回 1，因此总和减少为矩形总数。 

什么时候$n = 1$或者$m = 1$，网格在一个方向上实际上是一维的，因此矩形会折叠成条带。 包含公式仍然有效，因为其中一个维度只有一种可能的间隔结构，无需特殊的大小写即可产生正确的计数。 

当矩形非常小时（例如 1x1 单元格），包含计数相对于总矩形会变大。 模逆可确保概率保持明确定义，模算术中的减法可防止负中间值破坏结果。 

在所有情况下，关键的不变量是$C(A)$仅取决于几何边界，因此每个边缘配置都已编码在组合公式中，而不需要显式的几何检查。
