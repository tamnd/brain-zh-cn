 ## 解决方案
 ## 问题理解

 我们有一组学生，其中一些学生交换了作业。 每份报告都是两个学生之间的无向边，这意味着这两个学生在“作弊交互”图中相连。 

我们必须决定是否可以将所有学生分成两组：A 和 B，以便归纳结构与非常严格的模式相匹配。 在 A 组内，每对学生之间必须有一个已报告的边缘，这意味着 A 必须形成一个完整的子图。 B组内，不允许任何一对学生互相报告，这意味着B组必须形成一个独立的组。 A 和 B 之间的边没有限制。 

因此，任务是检查图是否可以划分为派系 A 和独立集 B。 

输入大小最多可达 100,000 个节点和最多 1,000,000 个边。 这立即排除了任何尝试检查所有子集或所有顶点对的解决方案。 即使是边缘上的二次工作也是临界的，因此我们应该以 N 和 M 为目标，实现线性或近线性复杂度，例如 O(N + M)。 

一个微妙的问题是，该问题不能保证超出 M 范围的连通性或稀疏结构之类的东西。 此外，不存在重复的边，因此邻接检查是明确定义的。 

一些边缘情况很重要。 

如果没有边，那么A仍然是一个团，所以A最多可以有一个节点，除非它是一个大小大于1的团，而没有边这是不可能的。 所以我们最多只能在A中放置一个节点，所有其他节点都必须去B，这很好，因为B必须是独立的，并且无边图已经满足它。 

如果图是完整的，那么我们可以将A和B中的每个人都放空。 这基本上满足了这两个条件。 

当某些节点部分连接时，就会出现棘手的情况，因为 A 需要完全连接，而 B 禁止任何内部边。 

## 方法

 一个蛮力的想法是尝试将所有可能的顶点划分为 A 和 B。对于每个子集 A，我们将检查 A 是否是团以及补集 B 是否没有边。 检查分区需要扫描 A 中的所有对并验证边是否存在，并扫描所有边以确保没有边位于 B 内。 

即使我们使用邻接矩阵进行快速边缘检查，迭代所有子集也是 O(2^N)，这对于 N 高达 10^5 来说是不可能的。 即使限制 A 的大小也无济于事，因为 A 可能很大。 

我们需要扭转观点。 我们不直接构造集合，而是分析边和非边施加的约束。 

关键的观察结果来自于用禁止模式重写条件。 

在 B 内部，不允许有边，因此图中的每条边都必须在 A 中至少有一个端点。这意味着 B 必须是一个独立的集合，因此 B 不能包含任何边的两个端点。 

在 A 内，每对都必须有一条边。 这意味着如果两个顶点没有通过边连接，则它们不能同时在 A 中。 

因此，每条非边都强制两个端点不同时位于 A 中，而每条边强制两个端点不同时位于 B 中。 

这正是补对称约束。 如果我们考虑补图，其中边变成非边，则条件是：在原始图中，A 是一个集团，因此在补图中 A 是一个独立集。 类似地，B在原图中是一个独立集。 

因此，在补图中，A和B都是独立的集合，并且原始图中的每条边都是一个约束，禁止两个端点都在B中，而每条非边禁止两个端点都在A中。这种对称性表明了一种类似二部的结构。 

更简洁的公式是为每个顶点分配一个类型：A 或 B。对于每条边 (u, v)，我们允许 A-A 或 A-B 或 B-A，但不允许 B-B。 对于每个非边 (u, v)，我们允许 B-B 或 A-B 或 B-A，但不允许 A-A。

所以边禁止 B-B，非边禁止 A-A。 这是一个成对约束系统，可以通过派生冲突图上的图着色进行测试，其中每个禁止对都施加一致性规则。 

我们在传播强制分配的顶点上构建一个约束图：如果我们将一个节点分配给 A，那么所有非邻居都不能是 A，因此它们必须是 B 或保持不受约束； 类似地，如果我们分配 B，则所有邻居都不能是 B，因此它们必须是 A 或不受约束。 该结构简化为检查我们是否可以一致地分配每个顶点，以便满足所有约束，这可以建模为 2-SAT 风格的蕴涵系统。 

然而，存在一个更简单的观察。 该条件相当于说补图在结构化方式上是二部完备的：A 中的每一对在原始图中都是连接的，因此 A 是一个团。 因此，如果我们选择 A 中的任何顶点，则 A 中的所有其他顶点都必须与其连接。 这立即意味着 A 必须包含在 A 中所有顶点的邻居集的交集中，这变得非常具有限制性。 

一种更实用的方法是猜测一个顶点属于 A。由于 A 是一个派系，因此 A 中的所有顶点必须是该顶点加上该顶点本身的共同邻居。 因此 A 必须是任何选定 A 顶点的闭邻域的子集。 同样，B 必须完全避免边缘。 

这导致了一种验证策略：尝试将每个顶点作为 A 的候选锚点（或从度结构导出的简化候选集），构造可能的 A 和 B 分区，并使用邻接集有效地验证约束。 然而，我们可以做得更好。 

最后的关键见解是将问题转化为检查补图是否可以分成具有附加结构的两个独立集合，这减少了检查图是否完整或具有非常特定的结构，其中所有缺失的边形成二分图。 这相当于检查补图的二部性。 

具体来说，我们可以观察到，如果存在这样的划分，则补图必定是二分图。 这是因为在补图中，A 和 B 必须都是独立集，因此补集的所有边都必须穿过 A 和 B。 

因此，我们隐式计算补图并检查它是否是二分图。 由于补集是密集的，我们无法显式地构建它，但我们可以使用邻接集和 BFS 进行遍历，同时使用一组剩余顶点有效地跟踪未访问的非边。 

这减少了 BFS 过度补邻接的问题，仔细维护未访问的节点和邻接查找。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^N · N^2) | O(2^N · N^2) | O(N^2) | O(N^2) | 太慢了|
 | 补充 BFS（隐式）| O(N + M) | O(N + M) | 已接受 |

 ## 算法演练

1. 为所有顶点构建邻接集，以便我们可以在 O(1) 平均时间内测试是否存在边。 这是必要的，因为补图没有显式存储，我们必须有效地推断非边。 
2. 维护一组所有未访问过的顶点。 该集合表示尚未分配给补充 BFS 中任何组件的节点。 
3. 当仍然有未访问的顶点时，选择一个作为 BFS 起点并为其分配颜色 0。这开始探索补图中的连通分量。 
4、在BFS中，当处理一个顶点u时，确定未访问集中所有与u非邻居的顶点。 这些正是补图中 u 的邻居，因此必须为它们分配相反的颜色。 
5. 为了有效地找到非邻居，迭代当前未访问的集合并过滤那些不在邻接[u]中的集合。 这避免了显式构造补边。 
6. 对于每个这样的非邻居 v，为其分配相反的颜色并将其排队以进行 BFS。 如果检测到冲突，其中顶点已经具有与所需颜色不同的颜色，则分区是不可能的。 
7. 如果 BFS 对所有组件完成且没有冲突，则存在补图的有效二分，这意味着存在所需的结构。 

### 为什么它有效

 补图解释将原始约束转换为单个要求：补图中的任何边都不能位于单个分区边内。 这正是两党性。 BFS 强制执行 2 着色，其中每个发现的补边强制执行相反的颜色。 由于每个补邻接要么通过集合差异发现，要么在不存在的情况下被忽略，因此着色尊重所有约束。 着色过程中的矛盾对应于补图中的奇数循环，这使得所需的划分不可能。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

n, m = map(int, input().split())

adj = [set() for _ in range(n + 1)]
for _ in range(m):
    u, v = map(int, input().split())
    adj[u].add(v)
    adj[v].add(u)

unvisited = set(range(1, n + 1))
color = {}

while unvisited:
    start = next(iter(unvisited))
    unvisited.remove(start)
    color[start] = 0
    q = deque([start])

    while q:
        u = q.popleft()

        # nodes in complement graph: unvisited minus neighbors in original graph
        to_visit = []
        for v in list(unvisited):
            if v not in adj[u]:
                to_visit.append(v)

        for v in to_visit:
            unvisited.remove(v)
            if v in color:
                if color[v] == color[u]:
                    print("NO")
                    sys.exit(0)
            else:
                color[v] = 1 - color[u]
            q.append(v)

print("YES")
```邻接结构存储为集合，以便边的成员资格检查是恒定时间。 BFS 使用全局未访问集，以便可以将补足邻居识别为未由原始边连接的顶点。 

一个微妙的点是我们迭代快照`list(unvisited)`因为我们在迭代过程中修改了集合。 这可以避免运行时错误并确保正确性。 

着色逻辑强制补图的二分性。 任何颜色冲突都表明补码中有奇数循环，这使得划分不可能。

 输入：```

 | 1 | 1 | 1 | 无（原始图结构中的所有邻居在第一次检查中都没有补边）| {1:0} | []|

 所有节点最终在补充 BFS 下变得一致，没有矛盾。

 ## 边缘情况

 单个顶点输入，例如`1 0`将该顶点分配给 A，并且这两个条件都成立，因为没有对违反集团或独立约束。 该算法从该节点开始 BFS，找不到互补的邻居，并立即以 YES 结束。 

具有两个孤立顶点的图，例如`2 0`产生矛盾，因为 A 需要是一个团，而大小为 2 的团需要一条不存在的边。 在处理过程中，两个节点被放置在补图的同一分量中，导致颜色冲突。 

一个完整的图就像`3 3`被接受是因为每对都满足 A 的派系要求，并且 B 可以为空。 补集上的 BFS 找不到边，因此不会发生矛盾，并且所有节点在单一颜色分配下保持一致。
