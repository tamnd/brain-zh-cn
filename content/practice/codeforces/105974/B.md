 ## 解决方案
 ## 问题理解

 任务是在将值附加到序列时维护序列。 在每次追加操作之后，一些查询会要求第 k 个最小的不同值，该值可以通过获取当前序列的任何子序列并对所选元素进行异或来获得。 允许空子序列，因此零始终是可能的答案之一。 如果存在的不同 XOR 结果少于 k 个，则查询返回 -1。 这是维护序列的 XOR 范围的查询版本。 

序列长度可以增长到 200000，每个值可以容纳 60 位。 尝试生成子序列的解决方案立即不可能，因为子序列的数量呈指数增长。 即使存储每个可到达的 XOR 值的解决方案最终也需要处理最多 2^60 个可能的值，而这些值无法装入内存。 有用的观察结果是，XOR 的行为就像位上的线性代数。 位数固定为 60，因此可以进行与位数成比例的操作。 

一些边缘情况很容易被忽略。 考虑仅包含重复值的序列。```
Input
3
1 5
1 5
2 3
```两次插入后，可能的 XOR 值只有 0 和 5。答案是 -1，而不是另一个生成的值。 计算插入元素而不是独立异或方向的解决方案在这里将失败。 

另一种情况是可以从先前的值形成一个值。```
Input
4
1 1
1 2
1 3
2 4
```可到达的值为 0、1、2、3。答案为 -1，因为只有四个不同的值。 粗心的实现可能会认为三个数字创建八个子序列并回答好像有八个不同的异或结果。 

边界情况是第一个查询。```
Input
2
2 1
2 2
```在任何插入之前，唯一可能的 XOR 是来自空子序列的 0。 第一个查询返回 0，第二个查询返回 -1。 即使没有插入数字，基也必须支持空 XOR 值。 

## 方法

 最简单的方法是保留一组可以创建的所有 XOR 值。 当新数字到达时，每个现有值可以保持不变或与新数字进行异或。 这是有效的，因为每个旧的子序列要么跳过新元素，要么接受它。 然而，经过多次操作后，该集合可以接近完整的 XOR 空间大小，最高可达 2^60。 更新和存储这么多值是不可能的。 

蛮力增长如此之快的原因是许多不同的子序列实际上是多余的。 对于 XOR，每个数字都是位向量，进行 XOR 相当于将向量相加，其中加法是以模 2 进行的。一组独立向量足以描述每个可能的 XOR 结果。 这种结构称为线性基。 

我们为每个可能的最高设置位维护一个基向量。 插入数字时，我们尝试使用现有的基向量删除其最高位。 如果数字变为零，就已经可以表示了。 如果它仍然具有没有基向量拥有的最高位，我们将其存储在那里。 由于只有 60 位，因此每次插入都很快。 

为了回答第 k 个最小的查询，基础表示一个具有恰好 2^rank 不同值的空间。 基向量可以被视为二元决策。 从最高位开始，我们通过检查该位为零的可能值来决定答案是否应该设置该位。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 每次更新 O(2^n) | O(2^60) | O(2^60) | 太慢了 |
 | 最佳| 每次操作 O(60) | O(60) | 已接受 |

 ## 算法演练

 1.维护一个数组`basis`尺寸为 60。`basis[i]`存储最高设置位为的向量`i`，如果不存在这样的向量则为零。 

当插入一个数字时，我们将其从高位减少到低位。 最高位是最重要的部分，因为两个基向量不能共享相同的最高位。 

1. 对于插入，从 59 向下扫描位到 0。如果数字的当前位为零，则不影响减少。 如果该位已经存在基向量，则将其异或。 否则，将当前数字存储为新的基向量。 

这保留了同一组可到达的 XOR 值，因为通过将一个数字与另一个可到达的数字进行异或替换，不会改变可以形成的内容。 

1. 保持当前的秩，即非零基向量的数量。 不同 XOR 值的数量为`2^rank`。 

如果查询要求 k 大于此值，则没有答案。 

1. 要找到第 k 个最小值，请从最高位向下处理基。 具有较小最高位的向量不能改变已经对较大位做出的决策。 

对于位处的基向量`i`，恰好有一半的剩余组合有位`i`等于零和一半则等于一。 如果`k`在零组内，跳过向量。 否则，取向量并减去零组的大小`k`。 

1. 返回构造的值。 

工作原理：基向量是独立的，因此每个可到达的 XOR 值都具有作为基向量子集的一种表示形式。 两种表示之间的最高差异位决定哪个值更大，这意味着从高位到低位的搜索与所有可能值的排序顺序相匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    basis = [0] * 60
    rank = 0
    ans = []

    def insert(x):
        nonlocal rank
        for b in range(59, -1, -1):
            if ((x >> b) & 1) == 0:
                continue
            if basis[b]:
                x ^= basis[b]
            else:
                basis[b] = x
                rank += 1
                return

    def kth_smallest(k):
        if k > (1 << rank):
            return -1

        res = 0
        remaining = rank

        for b in range(59, -1, -1):
            if basis[b]:
                remaining -= 1
                cnt_zero = 1 << remaining
                if k > cnt_zero:
                    k -= cnt_zero
                    res ^= basis[b]

        return res

    for _ in range(q):
        t, x = map(int, input().split())
        if t == 1:
            insert(x)
        else:
            ans.append(str(kth_smallest(x)))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```这`insert`函数是二元向量上的高斯消除步骤。 循环从第 59 位开始，因为输入值小于 2^60，因此 59 以上的位位置永远不会出现。 

查询函数首先检查请求的位置是否存在。 表达式`1 << rank`之所以有效，是因为每个独立的基向量都会使可能的 XOR 值的数量加倍。 

变量`remaining`计算在当前位之后仍有多少个基础选择尚未确定。 这给出了当前位为零的块的大小。 减去`k`仅当我们跳过整个块并选择当前位为 1 时才会发生。 

没有创建大型 XOR 值数组，因此实现保持在内存限制内。

 ## 边缘情况

 对于重复值，例如：```
3
1 5
1 5
2 3
```第一次插入创建一个基本向量。 第二次插入减少为零，因为它与现有方向相同。 排名保持为 1，因此仅存在两个值：0 和 5。第三个最小值不存在。 

对于组合成另一个值的值：```
4
1 1
1 2
1 3
2 4
```第三次插入不会增加排名，因为`1 XOR 2 = 3`。 该基仍然只有两个独立向量，给出四种可能的异或结果。 该算法正确返回-1。 

对于空序列：```
2
2 1
2 2
```等级为零，因此可达值的数量为`2^0 = 1`。 唯一的值是零，它来自于什么都不选择。 第一个查询返回零，第二个查询无法回答。
