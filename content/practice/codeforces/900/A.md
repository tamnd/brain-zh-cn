 ## 解决方案

 ## 问题理解

 我们在平面上得到一组点，但它们都不位于垂直轴上。 这意味着每个点要么严格位于 y 轴左侧，要么严格位于 y 轴右侧。 任务是检查我们是否可以恰好删除一个点，以便所有剩余的点完全位于 y 轴的一侧，这意味着所有剩余的 x 坐标要么严格为正，要么严格为负。 

所以核心问题不在于深层意义上的几何，而在于去除单个离群点后集合是否会变得“单边”。 

输入大小最多允许 100000 个点，这排除了任何二次策略，例如尝试每次删除并每次直接在 O(n) 中检查其余部分。 在最坏的情况下，这将导致大约 10^10 次操作，这对于一秒的限制来说太慢了。 我们需要线性或近线性扫描。 

关键的微妙之处在于，答案仅取决于左侧有多少个点 (x < 0) 和右侧有多少个点 (x > 0)。 y 坐标与条件无关。 

一个常见的错误是认为空间结构的重要性超出了 x 的符号。 例如，有人可能会尝试排序或检查凸性，但这些都不会影响所有剩余点是否严格位于 y 轴的一侧。 

当双方以平衡方式填充时，就会出现边缘情况。 例如，如果每一侧都有两个点，删除一个点仍然会代表两侧，所以这是不可能的。 

另一个微妙的情况是所有点都已经在一侧。 例如：

 输入：```
3
1 2
3 4
5 6
```这已经是有效的，因为删除任何一个点都会使所有剩余的点保持在正值一侧。 

一个天真的错误是假设我们必须删除一个改变边分布的点，但条件已经满足而无需任何特殊结构。 

## 方法

 暴力方法会尝试依次删除每个点，然后扫描所有剩余点以检查所有 x 值是否具有相同的符号。 对于 n 个候选者中的每一个，我们将进行另一次 O(n) 扫描，从而导致 O(n^2) 时间复杂度。 当n达到100000时，这变成了大约10^10次检查，这是不可行的。 

关键的观察结果是，删除一个点后的条件仅取决于负 x 坐标和正 x 坐标的计数。 删除后，我们想要零负数或零正数。 这意味着我们最多可以通过删除一分来“修复”一处违规行为。 

所以我们计算每边有多少个点。 如果双方都至少有两点，除去一点并不能消除双方，所以答案立即是“否”。 如果至少一侧得分为零，则答案已经是“是”。 如果一侧恰好有一个点，则删除该单点可以解决问题，因此答案为“是”。 

这将问题简化为简单的计数任务。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|
 | 最佳计数 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取所有点并根据 x 坐标的符号对它们进行分类。 我们只关心 x 是正数还是负数，而不关心精确值或 y 坐标。 
2. 计算有多少个点 x < 0 以及有多少个点 x > 0。 
3. 如果所有点都已在一侧，则返回“是”，因为删除任何单个点都会保留属性。 
4. 如果两个计数都大于 1，则返回“否”，因为删除一个点仍会在每一侧留下至少一个点。 
5. 否则，返回“是”，因为删除一侧的单个剩余点会完全消除该侧。 

### 为什么它有效

 删除后满足条件的唯一方法是最终所有剩余点都具有相同的 x 符号。 删除一个点最多可以使一侧的计数减少 1。 因此，如果双方最初都至少有两点，则任何一方都不能通过单次移除来完全消除。 相反，如果至少一侧的大小为零或一，我们总是可以删除一个点以使剩余的一组成为一侧。 

这给出了所有有效配置的完整特征。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
neg = 0
pos = 0

for _ in range(n):
    x, y = map(int, input().split())
    if x < 0:
        neg += 1
    else:
        pos += 1

# already one-sided
if neg == 0 or pos == 0:
    print("Yes")
elif neg <= 1 or pos <= 1:
    print("Yes")
else:
    print("No")
```代码直接实现了计数逻辑。 第一个条件处理所有点已经位于一侧的情况。 第二个条件捕获了通过移除单个点可以完全消除一侧的情况。 

不需要排序或几何计算，因为只有 x 的符号很重要。

 ## 边缘情况

 一种重要的边缘情况是所有点都已经位于一侧。 例如，如果每个 x 均为正数，则算法将计算 neg = 0 且 pos = n。 条件`neg == 0 or pos == 0`立即触发，输出为“Yes”。 这与删除任何点都会保留单面属性这一事实相匹配。 

另一种边缘情况是当恰好有一个点位于一侧时。 例如：

 输入：```
3
-1 2
1 3
2 4
```计数变为 neg = 1 且 pos = 2。条件`neg <= 1`是真的，所以我们可以删除单个负点，只留下正点。 该算法无需模拟移除即可正确识别这一点。 

最后的边缘情况是双方都至少有两分。 例如：```
4
-1 0
-2 0
1 0
2 0
```这里 neg = 2 且 pos = 2。没有满足任何接受条件，因此输出为“No”。 任何删除仍然会在每一侧留下至少一个点，因此单次删除不可能满足要求。
