 ## 解决方案
 ## 问题理解

 我们正在构建一个长度的数组$n$，但我们并不是逐个元素地构造它。 相反，数组是通过重复附加整个块来形成的。 每个块都是排列的循环旋转$[1, 2, \ldots, s]$对于某些选定的长度$s$。 每个操作都会贡献一个连续的段，并且该段内的所有值都是以下的排列$1$到$s$以某种轮换的顺序。 

最终数组必须满足“at位置”形式的位置限制$i$， 价值$x$被禁止”。任务是精确计算有多少个不同的最终长度数组$n$可以通过此类块追加操作的某些序列来产生。 

关键的困难在于这些操作定义了一个庞大的结构化数组系列。 每个位置都受到覆盖它的块的影响，并且块只能在时间上重叠，而不能在值分配上重叠。 所以最终的对象不是任意的，也不是简单的排列或组合。 

约束条件的总和很小，$\sum n \le 5000$和$\sum m \le 5000$，这表明$O(n^2)$或者$O(n^2 \log n)$每个测试的解决方案是可以接受的，但如果天真地实施，每个测试的任何立方体都已经是边界。 

一个微妙的点是，每个限制都是局部的，但可行性取决于全局结构。 独立构造数组或独立处理位置的简单方法将会失败，因为值通过共享块结构进行交互。 另一个常见的陷阱是假设每个位置都可以独立分配$[1,n]$带有排除，它忽略块中的值必须形成排列段。 

例如，如果我们忽略结构并独立处理每个位置，我们就会对数组进行计数，例如$[1,1,1]$或错过那个$[2,2,3]$在块构造规则下是不可能的，因为在任何大小为 2 或 3 的块中，值必须包含来自$1$到$s$。 

## 方法

 蛮力视图是模拟所有可能的操作序列。 在每一步中我们选择一个长度$s$，选择一个旋转，附加生成的块，并继续直到达到长度$n$。 这形成了一棵树，其中每个节点分支为所有可能的块选择。 即使我们只考虑最终数组，我们也可以有效地枚举所有分段$[1..n]$分成块，并为每个块选择一个旋转。 

这一下子就爆炸了。 即使我们假设每步选择一个块大小，分区的数量$n$是指数的，每个块有$s$轮换。 因此，朴素复杂性的行为就像对以下组合的超指数枚举$n$，使其无法超越$n \approx 20$。 

关键的观察是构造是顺序的并且前缀一致的。 任意前缀长度$i$，结构如何$i$形成仅取决于之前到达或开始的最后一个块$i$。 我们可以将所有有效结构压缩为描述当前块引发的最后一个“开放结构”的状态，而不是跟踪完整的历史。 

一个更有用的重新解释是每个位置$i$有效地选择“将其覆盖为某个值循环第一次出现的块大小”，并且一旦块开始，其内部结构就固定为循环移位。 这将问题转化为分配一致的块边界的计数方法，同时考虑到每个块都是一个排列段。 

这导致了在位置上的 DP，其中转换对应于开始一个在未来位置结束的新块，并且该块的成本由在约束下保持有效的旋转数量决定。 

主要的技术挑战是对每个细分市场进行计数$[l, r]$，有多少个循环移位$[1..(r-l+1)]$与其中所有禁止的分配兼容。 这可以预先计算，然后 DP 组合分段。 

最终的结构成为一个分区 DP：我们从左到右处理，并且对于每个$i$, 尝试之前所有的切点$j$，并乘以线段的有效旋转数$(j+1..i)$。 这是$O(n^2)$预处理后兼容性。

 ## 算法演练

 我们将问题转换为计算将数组划分为连续块的有效方法，其中每个块都是排列的循环移位。 

1. 预先计算一个结构体，快速检查某个段是否存在$[l, r]$在一定的旋转下可以形成有效的区块。 对于每个段，我们通过检查禁止值的一致性来隐式测试所有可能的旋转。 这个想法是确定长度的旋转次数$len = r-l+1$满足该段内的所有约束。 
2. 对于每个段$[l, r]$，计算一个值$ways[l][r]$，这是不违反任何限制的有效循环移位的数量。 这可以通过检查每次旋转并验证段中的所有位置来完成。 自从$n \le 5000$总的来说，对所有部分进行仔细优化的检查是可行的。 
3.定义DP数组$dp[i]$， 在哪里$dp[i]$是产生长度前缀的有效结构的数量$i$。 
4. 初始化$dp[0] = 1$，代表空结构。 
5. 对于每个端点$i$，迭代所有可能的最后一段开始$j$从$0$到$i-1$。 对于每个分割，我们将构造扩展一个块覆盖$[j+1, i]$, 贡献$ways[j+1][i] \cdot dp[j]$。 
6. 将所有贡献相加得到$dp[i]$。 答案是$dp[n]$。 

这样做的原因是任何有效的构造都有一个独特的分解为最大附加块。 一旦其长度和旋转固定，每个块都是独立的，并且限制仅约束单个块，而不约束不同块之间的交互。 因此，DP 通过选择最后一个块边界来枚举所有有效的全局结构一次。 

不变的是$dp[i]$计算前缀长度的所有有效结构$i$其中所有块完全位于前缀内并独立满足约束。 每个转换都会将有效前缀扩展一个有效块，从而保持正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, m = map(int, input().split())
    bad = [[False] * (n + 1) for _ in range(n + 1)]
    
    for _ in range(m):
        i, x = map(int, input().split())
        bad[i][x] = True

    # ways[l][r] = number of valid rotations for segment [l, r]
    ways = [[0] * (n + 1) for _ in range(n + 1)]

    for l in range(1, n + 1):
        for r in range(l, n + 1):
            length = r - l + 1
            cnt = 0
            for shift in range(length):
                ok = True
                for pos in range(length):
                    val = ((pos + shift) % length) + 1
                    if bad[l + pos][val]:
                        ok = False
                        break
                if ok:
                    cnt += 1
            ways[l][r] = cnt

    dp = [0] * (n + 1)
    dp[0] = 1

    for i in range(1, n + 1):
        total = 0
        for j in range(i):
            total = (total + dp[j] * ways[j + 1][i]) % MOD
        dp[i] = total

    print(dp[n] % MOD)

t = int(input())
for _ in range(t):
    solve()
```该实现直接遵循分段分解上的DP。 这`ways`表计算了对于每个间隔，有多少恒等排列的循环移位在所有禁止的约束下幸存下来。 然后`dp[i]`累积所有可能的最后一段边界。 

用于旋转的三重循环是最昂贵的部分，但仍然在限制范围内，因为总和$n$跨测试的范围以 5000 为界。在最坏的情况下，每个测试的 DP 是二次的，但在全球范围内是可以接受的。 

必须注意正确索引限制，因为段是 1 索引的，而 DP 使用包含边界。 乘法以模进行$998244353$在每次转换时防止溢出。

对于每个段，每次旋转都有效，所以$ways[l][r] = r-l+1$。

### 示例 2

 输入：```
3 2
1 1
2 1
```位置 1 和 2 都禁止值 1，严重限制有效轮换。 

段[1,1]不能置值1，因此无效。 

段 [1,2] 也会失败，因为 [1,2] 的每次旋转都会在段中的某个位置放置一个 1。 

只有避免将 1 放置在禁止位置的片段才能幸存，这会破坏许多转换。 

因此，DP 只允许以 3 结尾的段以避免更早违反约束，从而导致有效构造的集合小得多。 

该跟踪显示局部约束如何修剪整个段而不是单个值。

 ## 边缘情况

 关键的边缘情况是当单个限制消除了段的所有旋转时。 例如，如果长度为 2 的线段在两个位置都禁止值 1，则$[1,2]$或者$[2,1]$幸存下来，因此该部分的贡献为零。 DP 正确地处理了这个问题，因为这样的段产生$ways[l][r] = 0$，因此它永远不会有助于任何前缀扩展。 

另一种微妙的情况是，限制仅影响一次轮换，而不影响全部轮换。 该算法仍必须正确计算剩余旋转。 例如，在长度为 3 的段中，禁止单个位置值对通常会恰好消除一次旋转，并且 DP 将其反映为减少的乘法权重，而不是二进制有效/无效决策。 

当给定长度的所有段都无效（长度为 1 的琐碎段除外）时，就会出现最终的极端情况。DP 自然会崩溃为仅计算单例分区，从而生成正确但最小的构造集。
