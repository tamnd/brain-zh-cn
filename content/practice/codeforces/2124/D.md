 ## 解决方案
 ## 问题理解

 我们从一个数组开始，可能会重复删除元素。 删除规则很不寻常：选择长度至少为任意的子数组`k`，求其`k`-第一个最小值，并删除所选子数组中该值的一次出现。 

目标不是最小化或最大化操作数量。 我们只需要确定是否存在一些有效删除序列，从而留下回文。 

这些约束立即表明我们需要一个近线性的解决方案。 在所有测试用例中，总长度最多为`2·10^5`，所以一个`O(n log n)`算法很舒服，但任何二次方都是不可能的。 即使是单个测试`n = 2·10^5`会使`O(n²)`超过数百亿次运算。 

主要困难是了解哪些元素实际上可以被删除。 该操作是通过任意子数组定义的，因此尝试直接快速模拟删除变得毫无希望。 

一些边缘情况很容易被错误处理。 

考虑`k = 1`。```
4 1
1 1 2 1
```答案是`YES`。 每个元素都可以被删除，因为长度为 1 的子数组的第一个最小元素就是该元素本身。 假设必须保留某些值的解决方案在这里会失败。 

考虑`k = n`。```
3 3
1 2 2
```答案是`NO`。 唯一可用的子数组是整个数组。 第三小的元素是`2`，所以只有一个`2`可以删除。 删除一个后`2`，数组长度变为`2 < k`，因此无法进行更多操作。 将删除视为始终可用的幼稚方法会错误地回答`YES`。 

当数组包含临界值的许多副本时，会出现另一种微妙的情况。```
5 4
1 2 1 2 2
```答案是`YES`。 临界值的某些副本可以被删除，而其他副本必须保留。 将该值的所有副本视为永久固定是不正确的。 

## 方法

 暴力方法会尝试直接对过程进行建模。 在每个状态，我们可以枚举所有有效的子数组，确定它们的`k`-第一个最小值，生成所有可能的删除，并继续搜索。 这在理论上是正确的，因为它探索了每一个合法的操作顺序。 

状态空间几乎立即爆炸。 即使对于中等`n`，可达数组的数量变得巨大。 自从`n`达到`2·10^5`，这个方向是完全不可行的。 

突破在于描述全局可删除元素的特征。 

对数组进行排序并让`x`成为`(k-1)`- 整个数组中的第一个最小元素，使用从 1 开始的索引。 等价地，`x`是索引处的值`k-1`排序后。 

一个关键事实是`k-1`全局最小的元素永远不会全部消失。 每次删除都要求被删除的元素至少有`k-1`所选子数组内的元素不大于它。 属于全局最小的元素`k-1`位置永远无法满足这一点。 

相反的情况却出人意料地强烈。 任何不属于全局最小元素的元素`k-1`元素总是可以被删除。 官方社论证明，只要受到保护`k-1`元素仍然存在，我们可以选择一个合适的间隔，使目标元素恰好成为`k`-最小的。 

这彻底改变了问题。 

让`x`的值是`(k-1)`-第一个最小的元素。 

每个值都严格大于`x`可以自由删除，因此没有理由保留这些值。 

值严格小于`x`是不可触碰的。 

值等于`x`是灵活的部分。 有些副本属于受保护集，有些则不属于。 我们可能会删除一些副本`x`，但我们至少必须离开`k-1`要素整体。 

删除所有大于的值后`x`，我们得到一个缩减数组`b`仅由值组成`< x`和价值观`= x`。 

现在我们需要确定是否删除某些副本`x`可以使`b`一个回文。 

这就变成了一个贪心的两指针问题。 

从两端移动指针。 

如果值匹配，则保留两者。 

如果它们不同并且双方都不相等`x`，那么这两个值都受到保护并且无法删除。 答案是立即`NO`。 

如果一侧恰好等于`x`，删除该副本`x`并继续。 

这贪婪地仅删除那些`x`被迫消失的价值观。 由于我们希望保留尽可能多的元素，因此这是最好的策略。 

最后，我们计算有多少元素幸存下来。 如果少于`k-1`如果元素仍然存在，我们就会删除太多受保护的位置，这是不可能的。 否则答案是`YES`。

 ## 算法演练

 1. 对数组的副本进行排序。 
2. 查找`x`, 位置处的值`k-1`在已排序的数组中。 
3. 构建新数组`b`仅包含元素`<= x`。 

每个值大于`x`总是可以删除，所以保留它们没有任何帮助。 
4.初始化两个指针，`l = 0`和`r = len(b)-1`。 
5. 维护柜台`kept`， 最初`len(b)`。 
6. 虽然`l < r`：

 1.如果`b[l] == b[r]`，保留两个元素并将两个指针向内移动。 
2.如果`b[l] != b[r]`和`b[l] == x`，删除左侧的副本`x`, 递减`kept`，并增加`l`。 
3.如果`b[l] != b[r]`和`b[r] == x`，删除正确的副本`x`, 递减`kept`，并递减`r`。 
4. 如果双方都不相等`x`， 返回`NO`。 

内部唯一可拆卸的元件`b`是以下副本`x`。 当出现不匹配时，必须立即移除任何可拆卸的一侧。 
7、循环结束后，检查是否`kept >= k-1`。 
8. 如果为 true，则返回`YES`; 否则返回`NO`。 

### 为什么它有效

 全球最小`k-1`元素形成受保护的核心。 任何有效的最终数组都必须包含它们。 每个值大于`x`总是可移除的，因此保留这些值永远不会有助于创建回文。 

删除所有大于的值后`x`，唯一剩下的可移动元素是`x`。 在双指针扫描过程中，如果两端不同且两端不相等`x`，则两个受保护的值不一致。 由于两者都无法被删除，因此不可能有回文。 

每当一侧相等时`x`，强制删除该副本。 任何与受保护元素兼容的回文最终都必须丢弃它。 贪婪扫描恰好删除了那些副本`x`这是必要的并保留所有其他元素。 

因为该算法删除的元素的最小可能数量等于`x`，如果即使这个最大尺寸的回文候选包含少于`k-1`元素，不存在有效的操作序列。 相反，如果至少`k-1`元素保留，所需的删除可以通过上述表征来实现。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        if k == 1:
            ans.append("YES")
            continue

        s = sorted(a)
        x = s[k - 1]

        b = [v for v in a if v <= x]

        l = 0
        r = len(b) - 1
        kept = len(b)

        ok = True

        while l < r:
            if b[l] == b[r]:
                l += 1
                r -= 1
            elif b[l] == x:
                kept -= 1
                l += 1
            elif b[r] == x:
                kept -= 1
                r -= 1
            else:
                ok = False
                break

        if ok and kept >= k - 1:
            ans.append("YES")
        else:
            ans.append("NO")

    sys.stdout.write("\n".join(ans))

solve()
```第一步计算阈值`x`。 这是将始终可移动的元素与可能必须保留的元素分开的值。 

数组`b`删除所有大于的值`x`。 这些元素是无关紧要的，因为任何成功的解决方案都可以事先删除它们。 

两指针循环执行贪婪回文构造。 当两端匹配时，它们显然可以属于最后的回文。 当它们不同时，内部唯一合法的删除`b`是一个副本`x`，因此任何涉及的不匹配`x`通过删除该副本即可解决。 

变量`kept`跟踪有多少元素幸存下来。 这比事后计算删除稍微容易一些，并且可以避免在有多个副本时出现错误。`x`被删除。 

最终条件`kept >= k - 1`是必不可少的。 受保护的核心包含`k-1`元素，因此任何可行的最终数组必须至少包含那么多元素。

 ## 边缘情况

 考虑：```
1
4 1
1 1 2 1
```自从`k=1`，每个元素都是可移除的。 算法立即返回`YES`。 任何数组都可以简化为单个元素或空数组，两者都是回文。 

考虑：```
1
3 3
1 2 2
```排序后的数组是`[1,2,2]`， 所以`x=2`。 缩减后的数组仍然存在`[1,2,2]`。 

两指针扫描比较`1`和`2`。 右边等于`x`，因此将其删除。 只剩下两个元素，少于`k-1=2`解决不匹配问题后。 最终检查失败，产生`NO`。 

考虑：```
1
5 4
1 2 1 2 2
```扫描仅删除必要的副本`2`，达到一个回文，并且精确地保持`k-1`受保护的元素。 这种情况破坏了处理所有副本的解决方案`x`作为不可删除的。 

整个解决方案依赖于每个值都大于全局值的特征`(k-1)`-第一个最小值可以自由删除，而受保护的核心`k-1`最小的元素必须生存。
