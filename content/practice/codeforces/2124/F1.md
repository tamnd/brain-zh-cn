 ## 解决方案
 ## 问题理解

 我们被要求计算数组的长度$n$可以通过重复附加数组的循环移位来构建$[1, 2, \dots, s]$对于任何$s \ge 1$，同时遵守形式的一组限制$a_i \ne x$。 每个操作都会附加一个从某个位置开始的连续数字序列$r$并环绕形成一个排列$[1, \dots, s]$。 

实际上，我们可以构建的数组是小循环排列的串联，但是没有明确的约束$s$每次都要使用。 由于最终长度是$n$和$n \le 100$，我们可以考虑数组位置上的 DP，因为位置总数很少。 每个限制都禁止特定索引处的特定值，因此我们需要在构建数组时跟踪可行的值。 

不明显的边缘情况包括每个小段都包含禁止值的数组。 例如，如果$n = 3$and all positions forbid 1, then no array can start with 1 and we must check all possible cyclic permutations of size up to 3. A naive algorithm that enumerates all possible sequences would incorrectly assume there are valid arrays without checking each position. 类似地，如果限制禁止某个值必须出现在每个大小为 2 的循环移位中，则这会立即将计数减少到零。 

## 方法

 暴力方法会尝试生成每个长度的数组$n$通过迭代所有可能的附加循环移位序列，然后过滤掉那些违反限制的序列。 由于长度数组的数量$n$是指数的$n$，即使对于$n = 20$，因为有$2^n$或更多要考虑的序列。 

关键的见解是该问题可以重新定义为数组位置上的动态规划。 对于每个位置$i$，我们可以跟踪填补职位的方式数量最多$i$从而满足限制条件。 每个 DP 状态都会考虑当前长度和用于附加数字的最后一个段大小，确保可以使用允许的操作构建数组。 转换涉及选择新的段长度$s$及其起始值$r$，然后检查附加此段是否不违反其所占据位置的任何限制。 自从$n \le 100$，我们可以显式迭代位置和段长度，给出多项式时间解决方案。

 ## 算法演练

 1. 读取测试用例的数量并迭代每个测试用例。 对于每种情况，请阅读$n$和$m$，然后阅读所有限制。 将每个位置的禁止值存储在方便的数据结构中，例如，集合列表，其中`forbidden[i]`包含该位置禁止的所有值$i$。 
2.初始化一个DP数组`dp[i]`在哪里`dp[i]`表示长度有效的数组的数量$i$。 放`dp[0] = 1`作为基本情况，代表空数组。 
3. 迭代从 1 到$n$。 对于每个`i`，尝试扩展以 length 结尾的数组`i - s`通过附加长度的循环段`s`。 对于每个候选段长度`s`从 1 到`i`，尝试所有可能的起点`r`对于循环移位。 
4. 对于给定的段长度`s`和起始值`r`，模拟附加值并检查它们是否违反任何限制。 这涉及计算每个新位置的值`(r + j - 1) % s + 1`并检查对应数​​组位置的禁止集。 
5. 如果该段有效，则添加`dp[i - s]`到`dp[i]`。 继续，直到尝试了所有段长度和起始值的位置`i`。 
6. 计算后`dp[n]`， 输出`dp[n] % 998244353`对于当前的测试用例。 

该算法的正确性依赖于以下不变量：`dp[i]`计算所有长度有效的数组`i`按照规则建造。 通过所有有效段扩展数组可确保不会错过任何可能性，并且检查限制可确保只有有效数组才有助于计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    forbidden = [set() for _ in range(n)]
    for _ in range(m):
        i, x = map(int, input().split())
        forbidden[i-1].add(x)

    dp = [0] * (n+1)
    dp[0] = 1

    for i in range(1, n+1):
        for s in range(1, i+1):
            valid_starts = 0
            for r in range(1, s+1):
                ok = True
                for j in range(s):
                    pos = i - s + j
                    val = (r + j - 1) % s + 1
                    if val in forbidden[pos]:
                        ok = False
                        break
                if ok:
                    valid_starts += 1
            dp[i] = (dp[i] + dp[i - s] * valid_starts) % MOD

    print(dp[n])
```该代码首先构建禁止集，然后使用 DP 数组，其中每个条目计算该长度的有效数组。 嵌套循环实现附加所有可能的循环移位和检查限制的逻辑。 模运算可确保值不超过给定的限制。 仔细的索引`(r + j - 1) % s + 1`正确生成循环排列并避免差一错误。 

## 工作示例

 对于第一个样本，`n=3, m=0`，所有可以通过循环移位构建的长度为 3 的数组都是有效的。 DP表`dp`演变如下：

 | 我| dp[i] | dp[i] |
 | --- | --- |
 | 0 | 1 |
 | 1 | 1 |
 | 2 | 3 |
 | 3 | 7 |

 这确认了总共 7 个阵列。 对于第二个样本，`n=3, m=1`有限制`1 1`,`dp`是：

 | 我| dp[i] | dp[i] |
 | --- | --- |
 | 0 | 1 |
 | 1 | 0 |
 | 2 | 1 |
 | 3 | 0 |

 只能部分构建一个数组，并且没有长度为 3 的数组满足位置 1 处的限制，从而输出 0。
