 ## 解决方案
 ## 问题理解

 我们有一个数组，可以删除任意数量的元素，同时保留剩余元素的相对顺序。 删除后，剩余序列必须非空。 

如果在按非降序对序列的副本进行排序后，每个位置的值都发生变化，则序列称为混乱。 换句话说，如果剩余的数组是`b`它的排序版本是`c`，那么我们需要`b[i] != c[i]`对于每个索引。 

任务不是最大化或最小化任何东西。 我们只需判断原数组的某个子序列是否构成乱序，如果构成乱序，则输出任意这样的子序列。 

限制非常小。 每个测试用例最多有100个元素，并且测试用例最多有100个。 即使具有二次或三次复杂度的算法也是完全安全的。 这意味着我们应该专注于寻找简单的结构观察，而不是担心大量优化。 

主要的困难是理解什么样的子序列会成为混乱。 

考虑数组`[1, 1, 1]`。 每个非空子序列仅由 1 组成。 排序后保持不变，不存在乱序现象。 

考虑`[2, 1]`。 整个数组变成`[1, 2]`排序后。 两个立场都发生了变化，所以答案是肯定的。 

一个微妙的情况是`[2, 2, 3]`。 排序的顺序已经是`[2, 2, 3]`。 删除`3`给出`[2, 2]`，排序后仍然没有变化。 删除其中一项`2`s 给出`[2, 3]`，其排序顺序也是`[2, 3]`。 每个非空子序列都会失败，所以答案是否定的。 

粗心的方法可能会在数组尚未排序时尝试使用整个数组。 这在输入上失败，例如`[3, 1, 2]`。 整个数组并没有乱序，因为排序后我们得到`[1, 2, 3]`中间的元素变成`2`，匹配其排序位置。 我们必须验证每个位置，而不仅仅是检查数组与其排序版本的不同。 

## 方法

 最直接的蛮力想法是检查每个非空子序列。 对于每个子序列，对副本进行排序并检查每个位置是否不同。 这显然是正确的，因为它测试了所有可能的答案。 

问题是长度的数组`n`有`2^n - 1`非空子序列。 即使是为了`n = 100`，这是完全不可能的。 

关键的观察来自于观察最小的元素。 

让`mn`是当前序列中的最小值。 排序后，所有出现的`mn`必须出现在开头。 如果一个位置已经包含`mn`并在排序后保留在第一个位置中，该位置永远不会与其排序值不同。 

假设我们选择某个子序列的所有元素并对它们进行排序。 如果元素已经处于与排序顺序相同的位置，则混乱条件失败。 

思考该问题的一种更简单的方法是对原始数组进行排序并将其与原始顺序进行比较。 每个索引在哪里`a[i] != sorted_a[i]`是“好”，因为该元素已经与排序序列放置在那里的元素不同。 

每个索引在哪里`a[i] == sorted_a[i]`是“坏”，因为如果我们保持这个位置，它立即违反了混乱条件。 

这建议精确获取原始数组与其排序版本不同的位置。 让这些元素形成一个子序列`d`。 

对于每个保留位置，原始值和排序后的值都是不同的。 排序后的多重集`d`正是从排序数组中取出的相应值。 因此每一个位置`d`与其在排序版本中的位置不同，使得`d`有效的精神错乱。 

如果不存在这样的位置，则该数组已经等于其排序版本。 在这种情况下，每个元素都与其排序位置匹配，并且无法形成有效的子序列。

 | ---| ---| ---| ---|
 | 蛮力 | O(2^n · n log n) | O(2^n · n log n) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取数组`a`。 
2. 创建排序副本`b = sorted(a)`。 
3. 查找每个索引`i`这样`a[i] != b[i]`。 

这些正是与排序排列不一致的位置。 
4.收集对应的值`a[i]`到一个新数组中`ans`。 
5. 如果`ans`为空，打印`NO`。 

这意味着原始数组已经与其排序版本相同，因此不存在混乱的子序列。 
6. 否则打印`YES`，长度`ans`，以及元素`ans`。 

### 为什么它有效

 让`S`是索引集，其中`a[i] != b[i]`， 在哪里`b`是排序后的版本`a`。 

我们构建`ans`正是使用这些位置。 

排序后的版本`ans`通过取元素得到`b[i]`对于相同的指数`i ∈ S`。 这是从以下事实得出的：`b`是同一多重集的全局排序排列。 

对于每个保留的职位，我们都有`a[i] != b[i]`通过建设。 因此每个位置`ans`与其排序版本中的相应位置不同。 

因此`ans`是一种精神错乱。 

如果`S`为空，那么`a = b`，这意味着整个数组已经排序。 已排序数组的每个子序列也是已排序的，因此某些位置始终与其已排序版本一致。 任何错乱都不可能存在。 

这证明了正确性和完整性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        b = sorted(a)

        ans = []
        for i in range(n):
            if a[i] != b[i]:
                ans.append(a[i])

        if not ans:
            print("NO")
        else:
            print("YES")
            print(len(ans))
            print(*ans)

solve()
```解决方案首先对数组进行排序。 排序后的副本表示测量混乱状况所依据的目标排列。 

该循环精确收集原始值与排序数组中的值不同的索引。 这些是唯一可以参与有效答案的位置。 

如果不存在这样的位置，则数组已排序并且不存在有效的子序列。 

否则，收集到的元素会形成有效的混乱。 实现直接输出它们。 

最常见的错误是试图将指数保持在`a[i] == b[i]`。 这样的位置立即违反了排列要求，因为该值已经与其排序位置匹配。 

另一个容易犯的错误是只检查整个数组是否与其排序版本不同。 混乱需要每一个位置都不同，而不仅仅是至少一个位置不同。

 ## 边缘情况

 考虑：```
1
1
1
```排序后的副本是相同的。 没有索引满足`a[i] != b[i]`，所以答案数组为空并且算法打印`NO`。 非空乱序不可能存在，因为唯一可用的子序列是`[1]`。 

考虑：```
1
5
3 3 3 3 3
```同样，排序后的副本是相同的。 每个子序列完全由三组成，排序不会改变任何东西。 该算法正确地找到没有不同的位置并打印`NO`。 

考虑：```
1
2
2 1
```排序后的副本是`[1,2]`。 两个位置不同，因此算法保留两个元素。 得到的数组`[2,1]`已排序版本`[1,2]`，并且每个位置都不同。 算法打印`YES`。 

考虑：```
1
3
3 1 2
```排序后的副本是`[1,2,3]`。 所有三个位置都不同，因此选择整个阵列。 比较`[3,1,2]`和`[1,2,3]`，每个位置都不同，使其成为有效的混乱。 该算法输出整个数组。
