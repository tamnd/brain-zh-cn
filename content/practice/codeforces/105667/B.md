 ## 解决方案
 ## 问题理解

 我们正在研究一个网格，其中每个单元格要么被填充，要么为空，并且每个查询都会给我们一个矩形子网格。 对于每个查询，我们需要确定该矩形内的填充单元是否形成称为蛇的有效结构。 

这里的蛇不仅仅是任何相连的形状。 它的行为必须像一维路径一样，以一致的锯齿形方式访问单元格。 该区域内的每个填充单元都必须属于单个连接的组件，并且该组件必须看起来像一条每一步都会转弯但从不分支或形成循环的路径。 通俗地说，它的行为应该像一条弯曲的线，但永远不会分裂或填充块。 

输入由网格和许多矩形查询组成。 每个查询都会询问仅限于该矩形的填充单元的诱导子图是否形成有效的蛇形结构。 

约束足够大，以至于不可能根据查询重新计算连接的组件。 任何触及每个查询矩形内的每个单元格的方法都会直接导致网格大小和查询数量的乘积的最坏情况，这是远远超出可接受的。 即使每个查询的 BFS 或 DSU 重建也会超出典型限制，因为单个网格扫描已经是 N 乘 M 的线性，并且查询数量可能很大。 

一个经常失败的天真的想法是简单地为每个查询运行洪水填充，然后验证组件是否形成路径。 当查询严重重叠以及网格很大时，这种情况已经被打破，因为每个单元格都可以被重新访问很多次。 

第二个微妙的失败案例来自于仅检查连接性。 连接的区域仍然可能不是蛇。 例如，一个 2 × 2 完全填充的块已连接，但在多个方向上分支，因此它是无效的。 类似地，T 形结构被连接，但不是简单的路径。 

另一个微妙的问题是假设检查学位就足够了。 即使每个细胞的度数最多为 2，循环仍然会出现，而循环在蛇中是不允许的。 

## 方法

 蛮力策略为每个查询构建完整的图景。 对于给定的矩形，我们收集所有填充的单元格，运行图形遍历以提取连接的组件，然后验证每个组件。 验证步骤试图确保组件是没有分支或循环的简单路径。 

验证组件的一种方法是对其单元进行排序并尝试重建线性顺序。 如果该组件是一条有效的蛇，则恰好存在两种一致的坐标顺序：一种增加方向和一种反向锯齿形方向。 排序后，我们检查连续差异是否表现得像单位移动以及移动模式是否一致地交替。 这是可行的，因为蛇本质上是嵌入网格中的一条路径，一旦方向固定，就没有歧义。 

这种强力方法是正确的，因为它直接为每个查询从头开始重建结构。 故障点是运行时。 在最坏的情况下，一个查询可以覆盖整个网格，并且可能有很多查询，因此我们最终会对相同的数据进行重复的图遍历。 在最坏的情况下，这会导致大约 O(QNM) 的行为，这太大了。 

关键的见解是我们实际上不需要为每个查询重建组件。 网格可以进行全局预处理。 我们不是询问查询是否会引发蛇，而是翻转视角并询问哪些局部模式与网格中任何位置的任何蛇都不兼容。 一旦我们描述了所有禁止的本地模式的特征，每个查询就减少为检查是否有任何禁止的模式完全出现在其中。

这种转变是从每个查询的动态图推理到网格上的静态模式检测。 蛇的结构足够坚固，任何故障都必须出现在一个小的、恒定大小的配置中。 这消除了对连接重建的依赖。

 ## 算法演练

 我们依赖这样一个事实：每条无效的蛇都包含一个可以在本地检测到的小的禁止模式。 

1. 我们扫描一次网格并预先计算三个布尔前缀和表。 一种在水平方向跟踪三个连续填充单元格的出现，一种在垂直方向跟踪相同的情况，一种跟踪填充 2 x 2 方格。 这种预处理使我们能够在恒定时间内回答矩形存在性查询。 
2. 在构建这些表格时，我们为每个禁止模式标记特殊的锚单元。 对于水平三元组，我们标记每个出现的中间单元格。 对于垂直三元组，我们还标记中间的单元格。 对于 2 x 2 块，我们标记其左上角单元格。 这种标准化确保每个禁止结构都有一个规范的代表单元。 
3. 我们在这些标记的单元格上构建 2D 前缀和。 每个前缀和对应于一种禁止模式类型。 这让我们可以计算该类型的任何标记单元格是否位于查询矩形内。 
4. 对于每个查询矩形，我们检查所有三个前缀和。 如果其中任何一个报告非零计数，则该矩形包含禁止配置并且不可能是蛇。 
5. 如果没有一个前缀和检测到禁止模式，我们就断定该区域是有效的。 

### 为什么它有效

 有效的蛇是嵌入网格中的简单路径。 与路径结构的任何偏差都必须引入分支点、循环或 2 × 2 填充块，从而在遍历中强制产生歧义。 所有这些失败都至少表现为三种局部模式之一：行或列中的三个连续对齐的单元格，或 2 x 2 完全填充的正方形。 这些模式是非蛇结构的最小证书。 因为每次违规都包含这些模式之一，所以检测它们的存在相当于检测无效的蛇。 前缀和保证如果这样的模式存在于完全位于查询矩形内的任何位置，则可以通过其规范标记单元来检测到它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_prefix(mark):
    n = len(mark)
    m = len(mark[0])
    ps = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n):
        row_sum = 0
        for j in range(m):
            row_sum += mark[i][j]
            ps[i + 1][j + 1] = ps[i][j + 1] + row_sum
    return ps

def rect_sum(ps, r1, c1, r2, c2):
    return ps[r2][c2] - ps[r1][c2] - ps[r2][c1] + ps[r1][c1]

def solve():
    n, m, q = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]

    hor = [[0] * m for _ in range(n)]
    ver = [[0] * m for _ in range(n)]
    sq = [[0] * m for _ in range(n)]

    for i in range(n):
        for j in range(m - 2):
            if grid[i][j] and grid[i][j + 1] and grid[i][j + 2]:
                hor[i][j + 1] = 1

    for i in range(n - 2):
        for j in range(m):
            if grid[i][j] and grid[i + 1][j] and grid[i + 2][j]:
                ver[i + 1][j] = 1

    for i in range(n - 1):
        for j in range(m - 1):
            if grid[i][j] and grid[i][j + 1] and grid[i + 1][j] and grid[i + 1][j + 1]:
                sq[i][j] = 1

    ps_h = build_prefix(hor)
    ps_v = build_prefix(ver)
    ps_s = build_prefix(sq)

    out = []
    for _ in range(q):
        r1, c1, r2, c2 = map(int, input().split())
        r1 -= 1
        c1 -= 1

        bad = 0
        bad |= rect_sum(ps_h, r1, c1, r2, c2)
        bad |= rect_sum(ps_v, r1, c1, r2, c2)
        bad |= rect_sum(ps_s, r1, c1, r2, c2)

        out.append("YES" if bad == 0 else "NO")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案预处理三个独立的图案网格。 水平和垂直数组存储三排配置的规范标记，确保我们不会重复计算重叠模式。 方形数组存储 2 x 2 块的左上角锚点。 

前缀和结构是标准的二维累加，带有额外的行和列来支持恒定时间矩形查询。 然后，每个查询变成三个恒定时间范围总和检查。 

一个常见的实施错误是锚单元未对准。 如果我们标记三元组的最左边或最右边的单元格而不是中间的单元格，则重叠模式可能会在查询矩形边界附近被重复计算或丢失。 使用一致的规范中心可以防止这种歧义。 

另一个微妙的问题是忘记前缀和边界是半开放的。 转换输入后，实现在内部一致使用 [r1, r2) 样式索引。 

## 工作示例

 考虑一个小网格，其中有一个 2 x 2 的块出现在中心。 

输入网格：```
1 1 0
1 1 0
0 0 0
```查询：全网格。

 | 查询 | - | - | 发现 | 坏=1 |

 在查询矩形内检测到方形标记，因此答案是否定的。 这表明即使所有细胞都是连接的，该结构仍然违反了蛇形法则。 

现在考虑一条有效的直蛇：```
1 1 1 0
0 0 0 0
```查询：全网格。 

| 步骤| 何| 版本 | 平方| 正确检查|
 | --- | --- | --- | --- | --- |
 | 预处理 | 标记中间| 无 | 无 | - |
 | 查询 | 检测到 | - | - | 坏=1 |

 乍一看这可能令人惊讶，但在严格的交替转弯定义下，长度为 3 的直线并不是有效的蛇，因为它违反了运动必须交替方向且不能在连续三个步骤中保持共线的要求。 

没有直三元组的长度为 4 的锯齿形不会产生禁止模式并通过所有检查。

 ## 边缘情况

 关键的边缘情况是由三个单元形成一条直线的区域。 预处理标记每个这样的三元组的中间单元格，因此任何覆盖所有三个单元格的查询都会触发水平或垂直前缀和。 这可以防止错误地接受已经违反蛇形交替规则的短共线段。 

另一种情况是在查询边界附近重叠 2 x 2 块。 由于标记的单元格位于左上角，因此部分包含该正方形但未完全包含该正方形的查询不会对其进行计数，而任何完全包含的单元格将始终包含该锚单元格。 这保留了部分重叠下的正确性。 

最后一个微妙的情况是网格完全被填充。 每个 2 × 2 子方块都会创建一个标记单元，因此任何足够大的查询都会立即失败，这反映了这样一个事实：这样的区域包含许多分支配置并且不能是单个蛇。
