 ## 解决方案
 ## 问题理解

 该问题可以被视为一系列级别，其中每个级别贡献一定数量的元素，并且还带有一个描述其影响应用的区间。 每个级别 i 都提供 ai 单位的“利润”，但激活它会迫使我们支付取决于范围 [Li, Ri] 的惩罚。 选择一组级别的总价值不仅仅是它们的ai值之和，因为重叠的间隔会相互作用，并且重叠的惩罚不应该重复计算。 

真正的目标是选择级别的子集，以便我们最大化总增益减去总惩罚，其中惩罚的行为类似于整数位置的覆盖。 如果多个选定级别覆盖同一区域，则该区域仅受到一次惩罚，即使多个级别可能有助于覆盖该区域。 

从计算的角度来看，约束意味着比 O(n²) 更好的解决方案。 当 n 达到 200000 左右时，对级别对的简单动态编程将立即失败，因为转换需要扫描所有先前的选择。 

一个微妙的边缘情况来自重叠的间隔。 如果间隔严重重叠或嵌套，则假定级别之间独立的天真的方法要么会双重计算惩罚，要么错误地丢弃有益的组合。 例如，如果所有 Li 和 Ri 相同，则任何解决方案都必须正确地将它们视为共享单个覆盖段，无论选择多少层。 

选择非连续级别时会出现另一种边缘情况。 尽管对级别进行了索引，但由于重叠的传播方式，最佳选择可能会强制包含中间级别，这意味着跳过索引可能会使决策之间的简单独立性假设失效。 

## 方法

 直接强力方法会尝试级别的所有子集。 对于每个子集，我们计算总 ai 并计算所有间隔的并集以评估惩罚。 这是正确的，因为它明确遵守“计数并一次”规则。 然而，有 2ⁿ 子集，甚至计算每个子集的区间并集也需要 O(n)，导致 O(n·2ⁿ)，这是不可行的。 

我们需要利用区间中的结构。 关键的观察结果是区间是单调的：Li 和 Ri 都不随 i 减小。 这意味着当我们在各个级别中前进时，它们的覆盖范围会以结构化的方式表现。 一旦两个选定的间隔重叠，交互就会简化：它们之间的所有内容都表现得好像必须包含它或等效地有助于连续的合并效果。 

这种结构使我们能够维持动态编程状态，该状态仅取决于我们是继续重叠间隔链还是开始新的独立段。 我们不记住完整的子集，而是只跟踪直到 i 的最佳值以及任何先前决策点的最佳值。 

转换分为两种情况。 当前级别要么连接到先前的非重叠段，要么从 i−1 延伸一条重叠链。 这两种行为可以被编码成一个小的状态向量，该向量在自定义的最大加转换下线性演化。 一旦以这种方式表达，整个过程就变成了二维状态上的一系列类似矩阵的变换。 

因为每个级别都贡献一个固定的变换，所以我们可以将它们存储在一棵线段树中并有效地将它们组合起来。 这将问题转化为在点更新下维护矩阵的乘积，从而每次更新产生一个对数因子。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n·2ⁿ) | O(n·2ⁿ) | O(n) | 太慢了|
 | 状态DP+线段树| O((n + m) log n) | O((n + m) log n) | O(n) | 已接受 |

 ## 算法演练

我们重新解释DP，以便在每个索引i处我们维护两个量：在i或之前结束的配置的最佳值，以及所有先前状态的最佳值，无论它们是否在i结束。 

在第 i 层，我们计算两个贡献。 第一个是在 i 处开始新段的值。 这等于 ai 减去整个区间 [Li, Ri] 的惩罚，因为如果我们将 i 视为起点，我们将为其相对于先前选择的未覆盖部分支付全部成本。 第二个是将前一段从 i−1 延伸到 i 的值，它仅将右边界从 Ri−1 增加到 Ri，因此只有增量的未覆盖部分对惩罚有贡献。 

我们将它们编码为二元状态的转换。 

1. 定义一个状态向量，其中第一个分量是恰好在 i−1 处结束的最佳 DP 值，第二个分量是所有 j < i 中的最佳 DP 值。 
2. 对于级别 i，计算其独立贡献，即 ai 减去 k 乘以整个区间长度 (Ri − Li + 1)。 这对应于在 i 处开始一个新的段。 
3. 计算其扩展贡献，即 ai 减去 k 乘以新添加的右侧部分 (Ri − Ri−1)。 这对应于延伸重叠链。 
4. 将结束于 i 的 DP 更新为从任何先前的 j 开始到从 i−1 延伸之间的最大值。 
5. 通过对所有可能的转换取最大值来类似地更新全局最佳状态，因为一旦形成良好的状态，它仍然可用。 
6. 将此更新表示为 2×2 max-plus 矩阵，其中组合级别对应于矩阵乘法。 
7. 在这些矩阵上构建线段树，以便对 ai、Li、Ri 的更新可以反映在 O(log n) 中，并且数组上的完整乘积给出最终的 DP 状态。 

### 为什么它有效

 关键的不变量是任何最优选择都可以分解为片段，其中间隔要么不相交，要么形成完全连接的重叠链。 在链中，只有增量右扩展很重要，因此贡献会折叠成仅取决于先前右边界的线性形式。 在跨链中，DP 重置捕获启动新的独立段的成本。 最大加矩阵结构准确地保留了这两种模式，因此每个级别的组合都可以正确聚合延续或重新启动，而不会丢失最佳配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**30

class Node:
    __slots__ = ("a",)
    def __init__(self):
        self.a = [[-INF, -INF],
                  [-INF, -INF]]

def merge(A, B):
    C = Node()
    for i in range(2):
        for j in range(2):
            best = -INF
            for k in range(2):
                best = max(best, A.a[i][k] + B.a[k][j])
            C.a[i][j] = best
    return C

def make(a_i, L_i, R_i, k, prev_R):
    length = R_i - L_i + 1
    open_val = a_i - k * length
    add_val = a_i - k * (R_i - prev_R)

    if prev_R is None:
        add_val = open_val

    M = Node()
    M.a[0][0] = open_val
    M.a[0][1] = open_val
    M.a[1][0] = add_val
    M.a[1][1] = add_val
    return M

class SegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.size = 1
        while self.size < self.n:
            self.size *= 2
        self.seg = [Node() for _ in range(2 * self.size)]

        for i in range(self.n):
            self.seg[self.size + i] = arr[i]
        for i in range(self.size - 1, 0, -1):
            self.seg[i] = merge(self.seg[2*i], self.seg[2*i+1])

    def update(self, i, val):
        i += self.size
        self.seg[i] = val
        i //= 2
        while i:
            self.seg[i] = merge(self.seg[2*i], self.seg[2*i+1])
            i //= 2

def solve():
    n, m, k = map(int, input().split())
    a = list(map(int, input().split()))
    L = list(map(int, input().split()))
    R = list(map(int, input().split()))

    arr = []
    for i in range(n):
        prev_R = R[i-1] if i > 0 else None
        arr.append(make(a[i], L[i], R[i], k, prev_R))

    st = SegTree(arr)

    for _ in range(m):
        idx, val = map(int, input().split())
        idx -= 1
        a[idx] = val
        prev_R = R[idx-1] if idx > 0 else None
        st.update(idx, make(a[idx], L[idx], R[idx], k, prev_R))

    root = st.seg[1]
    ans = max(root.a[0][0], root.a[0][1], root.a[1][0], root.a[1][1])
    print(ans)

if __name__ == "__main__":
    solve()
```该实现为每个级别构造一个最大加转移矩阵。 每个矩阵都对我们是否开始一个新段或扩展现有段进行编码。 线段树保持其组成，因此更新后我们可以通过在结果状态矩阵中获取最大条目来查询全局最佳值。 

一个微妙的问题是可拓项如何取决于 Ri−1。 这就是为什么每个级别的矩阵在其值发生变化时必须重新计算，以及为什么转换在 ai 中不纯粹是局部的，而是取决于 Ri 结构中的邻接性。 

线段树乘法顺序很重要，因为矩阵组合是结合的但不是交换的。 该代码始终先合并左子节点，然后合并右子节点，从而保留级别的顺序。

 ## 边缘情况

 关键的边缘情况是所有间隔都相同。 在这种情况下，每个级别共享相同的 [L，R]，因此添加更多级别只会增加 ai 的收益，而每个合并段的惩罚会计算一次。 该算法可以处理这个问题，因为扩展转换总是将重复的覆盖范围折叠成单个贡献，从而防止重复计算。 

当区间严格不相交时，会出现另一种边缘情况。 在这里，没有任何扩展转换占主导地位，因此 DP 会反复重新启动。 线段树正确地捕获了这一点，因为每个矩阵都编码“开始新”和“扩展”，并且最大加组合自然地选择重新启动分支。 

第三种边缘情况是单元素输入。 只有一个级别，没有先前的状态，因此扩展项必须退化为完整区间惩罚。 该构造通过在 i = 0 时将 add_i 替换为 open_i 来显式处理此问题，从而确保初始化的正确性。
