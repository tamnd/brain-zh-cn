 ## 解决方案
 ## 问题理解

 我们得到一个长度的数组$n$。 我们重复执行一个操作$m$次，每次我们都会将一个数字添加到写在纸上的不断增长的序列中。 

每个操作都有三个随机层。 首先，我们随机打乱数组，因此数组的每个排列都有相同的可能性。 然后我们选择一个随机整数$k$统一从$1$到$n$。 最后，我们选择一个随机索引$i$统一从$1$到$k$，然后我们追加当前位置的元素$i$在打乱的数组中。 

这样做之后$m$次，我们得到一个长度的序列$m$。 任务是计算最终序列不减的概率，并将其模输出$998244353$。 

约束条件允许$n, m \le 10^6$，这排除了任何显式模拟该过程的解决方案。 即使天真地处理单个操作也涉及对所有操作的推理$n$位置，并重复此操作$m$时代已经表明我们必须将过程压缩成封闭形式的概率模型。 任何解决方案甚至$O(nm)$行为立即不可能，因为这需要最多$10^{12}$运营。 

多阶段随机性会产生微妙的边缘情况。 人们可能会错误地假设该过程以一种复杂的方式依赖于混洗数组中的位置，或者操作之间的相关性很重要。 例如，与$n=2, m=2, a=[1,2]$，很容易错误地模拟跨操作的绘制之间的依赖关系。 正确的解释是每个操作都是独立的，因为我们每次都会重新洗牌数组。 

另一个潜在的错误是将选择视为从数组中统一选取一个元素。 这并不是立即显而易见的，因为$k$-限制，并且必须仔细推导分布。 

## 方法

 暴力模拟将明确执行$m$迭代，打乱数组，模拟嵌套随机性，附加值，然后检查最终序列是否已排序。 这在概念上是简单且正确的，但每个操作至少需要$O(n)$洗牌时间加上额外的采样工作。 和$m$最多$10^6$，这变得不可行。 

关键的见解是，一旦我们分析了在打乱的数组中选择特定位置的概率，复杂的采样过程就会大大简化。 如果我们固定一个位置$j$，我们通过对所有有效的求和来计算在一次操作中选择该位置的概率$k$。 这会产生一个与位置相关的权重，但在对均匀洗牌进行平均后会发生一些令人惊讶的事情：每个数组元素都变得同样可能被选择，无论其位置如何。 整个复杂的过程分解为从多组数组元素中进行均匀采样。 

一旦进行了这种减少，每个操作就成为从值的固定分布中独立抽取的结果，其中值的概率$v$就是它在数组中的频率除以$n$。 那么问题就变成了：给定 i.i.d. 来自离散分布的样本，计算结果序列非递减的概率。 这变成了一个允许封闭形式简化的结构化动态规划问题。

 ## 算法演练

 让$p_v$表示单个操作输出值的概率$v$。 根据洗牌的对称性和位置的平均，我们得到$p_v = \frac{\text{cnt}[v]}{n}$。 

现在我们对序列进行建模$X_1, X_2, \dots, X_m$，其中每个$X_t$与分布无关地绘制$p$。 我们想要的概率是$X_1 \le X_2 \le \cdots \le X_m$。 

我们定义一个 DP 解释来构建这个事件。 

1. 定义$f[t][v]$作为之后的概率$t$步骤，序列是非递减的并且正好在值处结束$v$。 这将捕获最后一个元素固定的所有有效前缀。 
2.对于一个转换，如果我们想附加值$v$在步骤$t$，之前的值最多只能是$v$。 所以我们对之前的所有状态进行总结：$$f[t][v] = p_v \cdot \sum_{u \le v} f[t-1][u]$$因素$p_v$来自独立抽样$v$在步骤$t$。 
3.定义前缀累加：$$g[t][v] = \sum_{u \le v} f[t][u]$$这使我们能够以紧凑的形式重写转换。 
4. 代入递归式：$$g[t][v] = g[t-1][v] + f[t][v] = g[t-1][v] + p_v \cdot g[t-1][v]$$简化为：$$g[t][v] = g[t-1][v]\cdot (1 + p_v)$$5. 自从$g[0][v] = 1$，重复应用给出：$$g[m][v] = (1 + p_v)^m$$6. 恢复$f[m][v]$从前缀差异：$$f[m][v] = p_v \cdot (1 + p_v)^{m-1}$$7. 最终答案是所有可能的最后值的总和：$$\sum_v p_v \cdot (1 + p_v)^{m-1}$$关键的结构点是，一旦我们以最后一个元素为条件，前缀累积就会消除值之间的所有依赖性。 

### 为什么它有效

 整个过程简化为从值的固定分布中进行独立采样。 非递减条件仅约束排序，DP 通过跟踪最后选择的值来强制执行该约束。 前缀结构确保在每一步中，所有以某个值或低于某个值结尾的有效历史记录都聚合到一个状态中。 这导致转换仅依赖于局部乘法$1 + p_v$，使系统可以跨值分离。 一旦出现可分离性，每个值都会独立演化，从而直接导致封闭形式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n, m = map(int, input().split())
a = list(map(int, input().split()))

cnt = [0] * (n + 1)
for x in a:
    cnt[x] += 1

inv_n = modpow(n, MOD - 2)

ans = 0
for v in range(1, n + 1):
    if cnt[v] == 0:
        continue
    p = cnt[v] * inv_n % MOD
    term = p * modpow((1 + p) % MOD, m - 1) % MOD
    ans = (ans + term) % MOD

print(ans)
```实现直接反映了导出的公式。 我们首先计算基于频率的概率$p_v$对于每个值。 的模逆$n$使用是因为概率以模表示$998244353$。 

然后将每一项计算为$p_v (1 + p_v)^{m-1}$。 求幂在每个值的计算中占主导地位，但由于它是对数的，因此即使对于大型计算，整体复杂性仍然有效$n$。 

一个常见的陷阱是忘记指数仅适用于$m-1$， 不是$m$。 这是因为第一个元素仅贡献$p_v$，而后续步骤则累积乘法因子。 

## 工作示例

 ### 示例 1

 输入：```
3 2
1 1 2
```这里$p_1 = 2/3$,$p_2 = 1/3$。 

| 价值| p_v | (1 + p_v)^(m-1) | (1 + p_v)^(m-1) | 贡献 |
 | --- | --- | --- | --- |
 | 1 | 2/3 | 1 + 2/3 = 5/3 | 1 + 2/3 = 5/3 | (2/3)(5/3) |
 | 2 | 1/3 | 1/3 5/3 | (1/3)(5/3) |

 总和给出：$$\frac{10}{9} + \frac{5}{9} = \frac{15}{9} = \frac{5}{3}$$这与从分布中提取的长度为 2 的所有非递减序列的预期聚合相匹配。 

### 示例 2

 输入：```
4 3
1 2 2 4
```这里$p_1=1/4, p_2=2/4, p_4=1/4$。 

| 价值| p_v | (1 + p_v)^2 | 贡献 |
 | --- | --- | --- | --- |
 | 1 | 1/4 | 1/4 (5/4)^2 | 5/16 |
 | 2 | 1/2 | 1/2 (3/2)^2 | 9/8 |
 | 4 | 1/4 | 1/4 (5/4)^2 | 5/16 |

 总和是：$$\frac{5}{16} + \frac{18}{16} + \frac{5}{16} = \frac{28}{16} = \frac{7}{4}$$这演示了重复值如何增加概率质量以及公式如何独立聚合每个值的贡献。

 ## 边缘情况

 最小数组，例如$n=1$使每个操作具有确定性。 该公式简化为$p_1 = 1$，所以最终概率始终为 1，无论$m$，匹配每个序列都是恒定的，因此不递减的事实。 

在像这样的均匀数组中$a = [x, x, x, \dots]$，我们有$p_x = 1$，所以每一项都变成$1 \cdot 2^{m-1}$但模算术解析为 1，因为唯一可能的序列是常数。 该算法正确地将总和折叠为单个有效结果。 

在混合数组中，例如$a = [1, 2, 3]$，每个值通过其频率导出的概率独立贡献。 DP 不会混合超出前缀约束的值，并且封闭形式确保不存在交叉值干扰，与派生分布的独立结构相匹配。
