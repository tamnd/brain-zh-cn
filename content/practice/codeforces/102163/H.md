 ## 解决方案
 ## 问题理解

 将粒子视为无向图的顶点。 每个已知的纠缠关系都会给出两个顶点之间的边。 语句中的传递性意味着，如果存在从粒子 (x) 到粒子 (y) 的路径，则这两个粒子被视为纠缠，即使它们之间没有给出直接关系。 

因此，对于每个查询 ((x,y))，我们需要确定 (x) 和 (y) 是否属于图的同一连通分量。 输出是按查询顺序排列的二进制字符串。 第 (i) 个字符是`1`当两个查询的粒子通过给定的关系连接时，并且`0`否则。 

(N)、(M)、(Q)的值均可以达到(10^5)。 考虑到这样的规模和 2 秒的限制，为每个查询执行图形遍历的算法过于昂贵。 一次遍历已经可以检查 (O(N+M)) 个顶点和边，因此重复 (10^5) 次可以达到大约 (10^{10}) 个图操作。 检查每对粒子等二次工作甚至更不可行。 我们需要处理一次图，并使每个查询接近常数时间。 

在某些情况下，粗心的实施可能会产生错误的结果。 重复关系不得改变连接性。 例如，```
1
3 2 3
1 2
1 2
1 2
2 3
3 1
```粒子 1 和 2 之间只有一个实际连接，但粒子 3 是孤立的。 正确的输出是`110`因为1和2连通了，1和2又连通了，1和3没有连通。 将输入边的数量视为每条边都连接一个新组件的实现可能会对图结构做出错误的假设。 

查询还可以包含相同的粒子两次。 例如，```
1
1 1 2
1 1
1 1
1 1
```有输出`11`。 粒子总是与其自身相连，因为顶点属于与其自身相同的连通分量。 仅检查两个查询顶点之间是否存在显式边的实现在此类查询中将失败。 

最后，连接可以是间接的，而不是直接的。 考虑```
1
3 2 2
1 2
2 3
1 3
1 1
```输出是`11`。 1 和 3 之间没有直接边，但路径 (1 \rightarrow 2 \rightarrow 3) 使它们成为同一连通分量的一部分。 仅查找明确列出的对会错误地回答`0`对于第一个查询。 

## 方法

 直接的方法是构建邻接表并为每个查询运行 BFS 或 DFS。 从 (x) 开始，我们探索从 (x) 可达的所有粒子，然后检查是否到达 (y)。 这是正确的，因为图的可达性正是传递纠缠关系的定义。 

问题是重复工作。 在最坏的情况下，一个 BFS 可以访问所有 (N) 个顶点并检查所有 (M) 个边，从而为一次查询提供 (O(N+M)) 时间。 对于 (Q) 次查询，总数变为 (O(Q(N+M)))。 在最大值下，这大约是 (10^5(10^5+10^5)=2\cdot10^{10}) 次操作，远远超出了时间限制。 

有用的观察是图本身在查询之间不会改变。 每个查询都会询问有关将顶点固定划分为连通分量的相同问题。 我们不需要为每一对单独重新发现这些组件。 

不相交集并集结构（也称为并集查找）正好表示此分区。 在读取每条边 ((u,v)) 时，我们合并包含 (u) 和 (v) 的分量。 处理完所有边后，当两个粒子的 DSU 代表相等时，两个粒子就会精确连接。 每个查询都可以用两个答案来回答`find`运营。 

暴力解决方案之所以有效，是因为图遍历正确地发现了可达性，但它失败了，因为它重复地发现了相同的组件。 所有查询都引用一个固定图的观察结果使我们可以计算其连接的组件一次，并将每个查询减少为组件比较。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(Q(N+M))) | (O(N+M)) | 太慢了|
 | 最佳| (O((N+M+Q)\alpha(N))) | (O(N)) | 已接受 |

 这里 (\alpha(N)) 是反阿克曼函数，它增长得很慢，以至于对于所有实际输入大小来说它实际上都是恒定的。 

## 算法演练

 1. 创建一个 DSU 结构，每个粒子一组。 最初，每个粒子都是其自己的组件，因为尚未处理任何关系。 
2. 对于每个 (M) 个已知纠缠关系 ((u,v))，调用`union(u, v)`。 如果两个粒子已经属于同一组件，则无需进行任何更改。 否则，它们的组件将被合并，因为它们之间的边缘使得每个粒子可以从一侧到达，也可以从另一侧到达。 
3. 处理完所有关系后，读取每个查询 ((x,y)) 并计算`find(x)`和`find(y)`。 如果代表人数相等，则附加`1`到答案。 否则追加`0`。 
4. 将收集到的字符打印为一个字符串。 在列表中构建答案可以避免在处理查询时重复构建新的长字符串。 

### 为什么它有效

 DSU 不变量是，当所有已处理的边通过一个连通分量将两个粒子连接起来时，这两个粒子具有完全相同的表示。 最初这是正确的，因为每个粒子都是单独的。 当一条边连接两个不同的组件时，`union`完全合并这两个组件，保留不变性。 当两个端点已位于同一组件中时，边缘不会添加新的连接，并且保持 DSU 不变是正确的。 

每一条 (M) 条边都被处理后，DSU 分量正是整个图的连通分量。 查询询问（x）和（y）是否连通，相当于询问它们是否具有相同的代表。 因此每个输出字符都是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    output = []

    for _ in range(t):
        n, m, q = map(int, input().split())

        parent = list(range(n + 1))
        size = [1] * (n + 1)

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a, b):
            ra = find(a)
            rb = find(b)

            if ra == rb:
                return

            if size[ra] < size[rb]:
                ra, rb = rb, ra

            parent[rb] = ra
            size[ra] += size[rb]

        for _ in range(m):
            u, v = map(int, input().split())
            union(u, v)

        ans = []

        for _ in range(q):
            x, y = map(int, input().split())
            ans.append('1' if find(x) == find(y) else '0')

        output.append(''.join(ans))

    sys.stdout.write('\n'.join(output))

if __name__ == "__main__":
    solve()
```这`parent`数组存储每个 DSU 节点的父节点。 根的标识是`parent[x] == x`，所以初始化`parent`和`range(n + 1)`创建 (N) 个单独的组件。 索引零处的额外位置让我们可以直接使用粒子编号，因为输入顶点的编号范围为 1 到 (N)。 

这`size`数组支持按大小并集。 当两个不同的根合并时，较小的树会附着在较大的树下方。 这使得 DSU 树变浅。 这`find`函数还通过将每个访问的节点更改为更接近根来执行路径压缩。 这两种优化的组合给出了由 (\alpha(N)) 表示的接近恒定的摊余复杂度。 

重复的边缘自然可以通过以下方式处理`union`。 如果两个端点已经具有相同的代表，则该函数立即返回。 自边的行为方式相同，并且不需要任何特殊情况。 

该代码在回答查询之前处理所有边，这与在提出任何问题之前整个图已固定的事实相匹配。 不需要邻接表，因此实现仅使用 (O(N)) 辅助存储器。 

Python 中不存在整数溢出问题。 该实现使用迭代`find`，这也避免了 Python 中递归实现可能引起的递归深度问题。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | (O((N+M+Q)\alpha(N))) | 每条边最多执行两次近乎恒定的摊销 DSU 操作，并且每个查询执行两次`find`运营|
 | 空间| (O(N)) | 这`parent`和`size`每个数组包含 (N+1) 个条目 |

 对于 (N,M,Q\le10^5)，该算法仅对每个测试用例执行线性数量的 DSU 操作，每个操作具有有效的恒定摊余成本。 内存使用量也与 (N) 呈线性关系，在 256 MB 以内。 该方法避免了完全存储图，这使得实现和内存使用量都较小。

 ## 边缘情况

 重复的关系由相同的处理`union`与其他边一样操作。 对于输入```
1
3 2 3
1 2
1 2
1 2
2 3
3 1
```第一个`1 2`创建组件 ({1,2})，而第二个组件将被忽略，因为两个端点已经具有相同的代表。 查询产生`110`，正如预期的那样。 DSU 从不假设每个输入边都必须合并两个不同的组件。 

对于自我查询，请考虑```
1
1 1 1
1 1
1 1
```粒子 1 作为其自己的组件开始。 边缘`1 1`保持该组件不变，并且查询进行比较`find(1)`与它自己。 两个调用返回相同的根，因此输出是`1`。 (x=y) 不需要特殊分支，因为 DSU 定义已经正确处理它。 

间接连接包括```
1
3 2 1
1 2
2 3
1 3
```处理完第一条边后，粒子 1 和 2 共享一个代表。 处理第二个粒子后，粒子 3 被合并到同一组件中。 然后查询找到 1 和 3 的相同代表并输出`1`，尽管这对`1 3`从未作为输入边缘出现。 

断开连接的查询的行为相反。 和```
1
4 2 1
1 2
2 3
1 4
```组件是 ({1,2,3}) 和 ({4})。 查询比较1的代表和4的代表，不同，所以答案是`0`。 这正是组件内部直接可达性与不相关粒子之间的区别。 

最后，多个测试用例需要为每个图提供一个新的 DSU。 这`parent`和`size`数组在测试用例循环内分配，因此组件信息不会从一个测试用例泄漏到下一个测试用例。
