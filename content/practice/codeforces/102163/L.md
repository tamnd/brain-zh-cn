 ## 解决方案
 ## 问题理解

 每个学生的试卷都被编码为一个正整数。 该整数的二进制表示形式描述了学生的 True 和 False 答案：设置的位代表正确的 True 答案，而未设置的位代表 False 答案。 由于考试中的每个答案都是正确的，因此学生的分数正是其数字的二进制表示形式中设置的位数。 

例如，数字`13`是`1101`以二进制形式。 它包含三个设置位，因此相应的学生得分`3`。 

对于每个测试用例，我们都会收到一组`N`此类编码的考试试卷，并且必须以相同的顺序输出每个元素的 popcount 或设置位数。 

的价值`N`可以达到`10^5`，因此一种比较每对学生的方法，或者执行与`N^2`，立即不适合。 价值观本身最多是`10^9`，这意味着每个数字最多有 30 个二进制数字。 小的固定位宽是线性扫描就足够的关键原因。 在 1 秒的限制下，我们的目标应该是大致`O(N)`每个测试用例的工作量，每个数字只有少量恒定的处理量。 

在某些情况下，如果假设二进制表示具有特定的形状，则实现可能会出错。 考虑尽可能最小的输入：```
1
1
1
```正确的输出是：```
1
```数量`1`恰好有一个设置位。 意外地从位置 1 而不是位置 0 开始检查位的实现将错误地产生零。 

另一个边界情况是 2 的幂：```
1
3
2 4 8
```正确的输出是：```
1 1 1
```每个 2 的幂都有一个设置位。 粗心的实现会返回二进制数字的数量而不是设置的位数`2 3 4`，这是错误的数量。 

值还可以包含相邻的设置位和它们之间的零：```
1
3
3 5 10
```二进制形式是`11`,`101`， 和`1010`，所以正确的输出是：```
2 2 2
```仅检查最高或最低设置位会错过一些正确答案。 必须对整个位模式进行计数。 

## 方法

 直接的方法是将每个整数转换为二进制并检查其所有位，每当有一位出现时就递增答案`1`。 这是完全正确的，因为每个`1`二进制表示对应一个正确的问题。 

由于每`A_i`至多是`10^9`，最多有 30 位。 因此这种方法需要`O(30N)`，这简化为`O(N)`因为30是一个常数。 在Python中，最干净的实现是使用内置的整数运算`bit_count()`，它精确地执行了这个 popcount 操作，而不需要我们手动操作这些位。 

手动位计数循环也可以从第一原理中导出。 表达式`x & 1`告诉我们是否设置了最低位，并且`x >> 1`删除那一点。 重复此操作直到`x`每个设置位都变为零计数。 还有一个更好的位操作观察：`x & (x - 1)`删除最低设置位`x`。 因此，重复应用该操作对每个设置位执行一次迭代，而不是对每个二进制数字执行一次迭代。 

暴力解释对于理解为什么答案是 popcount 很有用，但不需要`O(N^2)`根本没有算法。 每个学生记录的结构独立于其他记录。 我们可以单独处理每个整数，有界 30 位表示意味着即使手动扫描也足够快。 蟒蛇的`int.bit_count()`直接给出相同的结果，并且是最简单的最优实现。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 手动位扫描| O(30N) = O(N) | O(1) 辅助 | 已接受 |
 | 内置 popcount | O(N) | O(1) 辅助 | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 每个测试用例都是独立的，因此可以单独应用相同的过程。 
2. 阅读`N`和`N`编码试卷。 我们只需要每个整数的值，因为分数完全取决于它自己的二进制表示。 
3. 对于每个整数`x`, 计算`x.bit_count()`。 这将返回二进制表示中设置的位数`x`，这正是该整数编码的正确答案的数量。 
4. 按照与输入相同的顺序存储结果计数，并将它们打印为空格分隔的一行。 保留顺序很重要，因为每个输出分数对应于输入数组中相同位置的学生。 

为什么有效：对于每个学生来说，每个二进制位置代表一个问题，一组位代表一个正确答案。 这`bit_count()`操作精确地计算那些设置的位，因此产生的值正是该学生的分数。 由于学生是按照输入顺序独立处理的，因此每个输出位置都会收到正确的分数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        ans = [x.bit_count() for x in a]
        print(*ans)

if __name__ == "__main__":
    solve()
```程序首先读取`T`，然后独立处理每个测试用例。 数组被读取为整数，并且应用列表理解`bit_count()`给每个学生记录。 

使用`bit_count()`是故意的。 问题要求的是数量`1`位，而不是二进制长度或最高设置位的位置。 Python 整数不具有 C++ 等语言的固定宽度溢出行为，因此值高达`10^9`直接处理，无需任何特殊类型。 

也不存在相差一的问题，因为`bit_count()`正确处理位位置零。 例如，`1`由位置零处的单个设置位表示，因此其计数为`1`。 

输出是由`print(*ans)`，它会在所有分数之间插入空格，并避免手动构造大型格式化字符串。 输入使用`sys.stdin.readline`，满足所需的快速 I/O 模式。

| 学生价值| 二进制表示 | 设置位数 | 输出|

 ## 边缘情况

 最小可能值是`1`，表示为二进制`1`。 对于输入```
1
1
1
```

`bit_count()`回报`1`，所以输出是```
1
```没有丢失的前导位需要考虑。 前导零是无关紧要的，因为它们不能代表正确的答案。 

2 的幂是另一个常见的错误来源。 为了```
1
3
2 4 8
```二进制形式是`10`,`100`， 和`1000`。 每个包含一组位，因此算法返回```
1 1 1
```二进制位数发生变化，但分数不变。 这将计数设置位与计数二进制长度区分开来。 

处理具有多个单独设置位的值，无需特殊情况。 为了```
1
3
3 5 10
```二进制表示是`11`,`101`， 和`1010`。 每个包含两个设置位，给出```
2 2 2
```该算法不依赖于设置位的相邻性或位置，因此正确答案之间的零没有影响。 

最后，最大允许值为`10^9`。 它的二进制表示包含 13 个设置位，因此```
1
1
1000000000
```产生```
13
```该值正好在 Python 的整数范围内，并且`bit_count()`直接处理它。 在数字边界处不需要特殊处理。
