 ## 解决方案
 ## 问题理解

 我们给出了一系列游戏记录，其中每个元素代表获取属性点或遇到属性检查。 该角色一开始的力量和智力为零。 序列中的零表示接收一个可以分配给力量或智力的属性点。 正数代表智力检定：如果角色的智力至少达到该值，则角色通过智力检定。 类似地，负数表示强度检查。 

目标是在尊重记录顺序的同时最大化通过检查的数量。 我们无法追溯分配积分：在任何位置，只能分配之前获得的积分。 

该限制规定最多可以有 200 万条记录，但最多 5000 个点。 这意味着我们不能天真地模拟所有可能的点分配； 探索所有分配的强力方法$2^{5000}$的可能性，这是完全不可行的。 相反，我们必须利用相对较少的点来限制状态空间。 边缘情况包括在任何点之前进行所有检查，这会导致通过零检查，或者所有检查仅需要一个属性但点分布在两者之间的序列，因此需要仔细分配。 

例如，考虑输入`5 2`有记录`1 -2 0 0 1`。 在这里，这两点都是在前两次检查之后出现的。 一种天真的贪婪方法在不考虑顺序的情况下分配点会错误地声称某些检查是可以通过的，但正确的答案是只有最后两项检查（在点之后）可能会通过。 

## 方法

 当我们遍历序列时，暴力方法将尝试尝试所有可能的方法来分配点。 对于每个零，我们可以增加力量或智力，并且对于每次检查，我们看看它是否通过。 状态数为$2^m$因为每个$m$点有两个分配选项。 和$m$最多 5000，这大约产生$10^{1500}$可能性，显然太大了。 

关键的观察是，虽然有很多记录，但只有分数的数量对潜在的作业很重要。 我们可以追踪可达的集合`(strength, intelligence)`当我们处理序列时级别，每当我们通过检查或获得一个点时更新计数。 动态规划方法的工作原理是存储给定分配的智力点数量的可能强度级别的一维数组。 具体来说，让`dp[i]`如果我们已经准确分配了，我们可以通过的检查的最大数量`i`指向情报； 然后剩下的`m-i`点会自动分配给强度。 我们迭代记录并更新此 DP 数组以考虑每个新点和每次检查，使用临时数组来避免过早覆盖值。 

这将状态空间从指数形式减少到`m`到`O(m^2)`，这是可行的，因为`m ≤ 5000`。 内存使用也受到控制，并且算法与`n`因为我们在更新大小为 DP 的数组时只处理每条记录一次`m+1`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^m * n) | O(2^m * n) | O(2^m) | O(2^m) | 太慢了 |
 | 最优 (DP) | O(n * m) | O(米) | 已接受 |

 ## 算法演练

 1.初始化一个DP数组`dp`长度`m+1`具有所有价值观`-1`。 各指标`i`代表分配`i`指向情报。 放`dp[0] = 0`表示最初分配的零分和通过的零检查。 
2. 迭代每条记录`r`为了。 对于每个检查或点，维护一个临时 DP 数组`new_dp`存储更新的值。 
3.如果`r`为零，迭代所有`i`从 0 到`m`。 对于每个`i`和`dp[i] >= 0`, 增量`i`代表将这个新点分配给智力和增量`dp[i]`代表将其分配给强度。 更新`new_dp`对于这两种可能性，保留通过检查的最大数量。 
4.如果`r`是一个正数（智能检查），迭代`i`从 0 到`m`。 对于每个可达的`i`,检查是否分配了智力点`i`至少是`r`。 如果是，则增加中的值`new_dp[i]`计算通过的支票； 否则保持不变。 
5.如果`r`为负（强度检查），迭代`i`从 0 到`m`。 对于每个可达的`i`，检查是否分配了强度点`m - i`至少是`abs(r)`。 如果是，则增加中的值`new_dp[i]`; 否则保持不变。 
6.处理完记录后，替换`dp`和`new_dp`并继续下一条记录。 
7. 处理完所有记录后，取最大值`dp`代表通过检查的最大数量。 

维持的不变量是`dp[i]`始终存储通过的检查的最佳数量`i`考虑到所有先前的记录，分配给情报的分数。 这确保了我们永远不会过多计算点数或忽略顺序约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
records = list(map(int, input().split()))

dp = [-1] * (m + 1)
dp[0] = 0

for r in records:
    new_dp = [-1] * (m + 1)
    if r == 0:
        for i in range(m + 1):
            if dp[i] == -1:
                continue
            # Assign point to Intelligence
            if i + 1 <= m:
                new_dp[i + 1] = max(new_dp[i + 1], dp[i])
            # Assign point to Strength
            new_dp[i] = max(new_dp[i], dp[i])
    elif r > 0:
        for i in range(m + 1):
            if dp[i] == -1:
                continue
            # Check Intelligence
            passed = dp[i] + (1 if i >= r else 0)
            new_dp[i] = max(new_dp[i], passed)
    else:
        for i in range(m + 1):
            if dp[i] == -1:
                continue
            # Check Strength
            passed = dp[i] + (1 if (m - i) >= -r else 0)
            new_dp[i] = max(new_dp[i], passed)
    dp = new_dp

print(max(dp))
```该代码将处理点与检查分开。 临时的`new_dp`array 确保此记录的更新不会干扰同一步骤中的决策。 对于零记录，会发生两次更新：一次分配给智力，一次隐式分配给力量。 对于检查，决定取决于当前分配是否满足阈值。
