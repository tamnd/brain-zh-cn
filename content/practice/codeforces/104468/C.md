 ## 解决方案
 ## 问题理解

 我们被要求构造一个从 1 到 N 的数字排列，使得恰好有一个相邻的数字之和为奇数。 其他所有相邻对的总和必须为偶数。 

仅当一个数为偶数且另一个数为奇数时，相邻和才是奇数。 因此，条件实际上是控制排列中邻居之间奇偶校验切换的次数。 我们只需要一个偶数位于奇数旁边的位置，并且其他所有相邻元素都必须具有相同的奇偶校验。 

输入由多个测试用例组成，每个测试用例给出一个值 N。对于每个 N，我们必须输出任何有效的排列。 

约束允许每个测试 N 最多 100000，总和最多 100000。这意味着我们每个测试用例都需要 O(N) 构造，因为在许多测试中重复类似 O(N log N) 的东西仍然可以，但没有必要，而且暴力排列是不可能的。 回溯或基于搜索的构造将立即失败，因为排列空间是阶乘的。 

在考虑奇偶分组时会出现一个微妙的问题。 如果我们将偶数和奇数分开，则每组中所有相邻的总和将自动为偶数。 唯一危险的地方是偶数块和奇数块之间的边界。 这立即表明排列的结构完全由我们连接这些奇偶校验块的方式控制。 

对于较小的 N，会出现边缘情况。对于 N = 2，我们必须明确检查可行性。 唯一的排列是 [1,2] 和 [2,1]，两者都恰好产生一个相邻对，并且该对是 odd+even = odd sum，因此条件成立。 对于N = 3，我们必须确保我们仍然可以精确地隔离一个混合奇偶邻接，这也是可能的，但需要正确的安排。 

一种天真的方法会尝试随机排列或贪婪交换，但如果不强制执行全局奇偶校验结构，它很容易产生多个奇和邻接。 

## 方法

 一个蛮力的想法是生成排列并检查条件。 这是通过枚举 1 到 N 的所有排列并验证邻接和来实现的。 验证是 O(N)，但是有 N！ 排列，所以即使 N = 10 也使它不可行。 搜索空间立刻爆炸。 

关键的观察结果是奇偶校验结构完全决定了条件。 在所有偶数或所有奇数的连续块内，每个相邻的和都是偶数。 获得奇数总和的唯一方法是将奇数放在偶数旁边。 所以我们只需要奇数块和偶数块之间有一个边界。 

如果我们将所有奇数分组在一起，将所有偶数分组在一起，那么如果我们将这些块连接一次，我们通常会恰好得到一个边界。 然而，如果我们不小心在块内排序，只有在混合奇偶校验时，我们可能会意外地引入额外的转换，但由于我们从不在块内混合，奇偶校验更改的数量恰好是 1。 

因此，这种结构简化为分别对奇数和偶数进行排序，然后将它们沿一个方向连接起来。 任何内部订购工作； 最简单的是增加顺序。 

我们还必须确保两个块都不为空，从而违反了条件。 如果由于约束而 N = 1 是无关的，并且对于 N ≥ 2，两个奇偶校验集都非空，因此串联始终有效。

 | 奇偶分组构造 | O(N) | O(N) | 已接受 |

 ## 算法演练

 我们使用奇偶校验分离构造排列。

1. 将 1 到 N 的数字分成两个序列：奇数和偶数。 这隔离了奇偶校验，因此我们可以控制奇偶邻接发生的位置。 
2. 按升序输出所有奇数。 在该段内，每个相邻的和都是偶数，因为 odd + odd 始终是偶数。 
3. 按升序输出所有偶数。 类似地，在偶数中，每个相邻的和都是偶数。 
4. 连接赔率和偶数。 
5. 这在最后一个奇数和第一个偶数之间创建了一个边界。 该边界恰好贡献了一个奇数和，因为它是奇数 + 偶数。 

为什么它有效

 奇数段内和偶数段内的所有相邻对都具有相等的奇偶校验端点，因此它们的和始终为偶数。 连接不同奇偶校验的唯一邻接是两个段之间的单一边界。 由于该构造恰好创建了一个这样的边界，因此该条件仅满足一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    
    odds = []
    evens = []
    
    for i in range(1, n + 1):
        if i % 2:
            odds.append(i)
        else:
            evens.append(i)
    
    res = odds + evens
    print(*res)
```该解决方案的工作原理是基于奇偶校验显式构建两个列表。 1 到 N 的循环是线性的，每个数字都分为奇数或偶数。 每个测试用例连接一次。 

关键的实现细节是我们从不交错两个列表。 任何交错都会有引入多个奇偶邻接的风险，这将违反要求。 将它们分开可以保证单一的过渡点。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        odds = []
        evens = []
        for i in range(1, n + 1):
            if i % 2:
                odds.append(i)
            else:
                evens.append(i)
        res = odds + evens
        out.append(" ".join(map(str, res)))
    return "\n".join(out)

 ## 边缘情况

 对于 N = 2，该算法产生奇数 = [1]，偶数 = [2]，因此输出为 [1,2]。 唯一的邻接是 1 + 2，它是奇数，因此条件仅成立一次。 

对于 N = 3，奇数 = [1,3]，偶数 = [2]，因此输出为 [1,3,2]。 相邻和为 1+3 = 偶数，3+2 = 奇数，恰好给出一个有效索引。 

由于N=1是约束不允许的，所以不需要特殊处理。 

对于所有较大的 N，结构保持相同：单个奇偶校验边界恰好保证一个奇数和邻接，并且没有内部块引入任何违规。
