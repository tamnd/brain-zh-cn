 ## 解决方案
 ## 问题理解

 我们有一棵树`n`顶点，每个顶点都用一个整数标记。 允许的操作让我们可以多次删除叶顶点（最多具有一条边的顶点）。 之后，树被“压缩”：任何恰好有两个邻居的顶点都被删除，并且直接连接其邻居。 最终目标是在任意序列的删除和压缩之后最大化剩余顶点上的数字总和。 

具体来说，输入提供了多个测试用例。 对于每个测试用例，我们都有顶点数、顶点上的整数数组以及树的边。 每个测试用例的输出是一个整数：可实现的最大总和。 

看看约束条件，`n`所有测试用例中最多可以有 500,000 个，每个数字的大小可以达到 10^9。 这排除了任何遍历顶点子集或模拟所有可能删除的算法。 每个测试用例我们都需要一种线性或近线性的方法。 

需要注意的边缘情况包括：

 - 只有两个顶点的树。 在这里，如果一个顶点的值为负，则删除该顶点可能是最佳选择。 
- 所有顶点值为负的树。 正确答案应该是零，因为我们可以删除所有内容。 
- 压缩显着改变结构的树，例如，正数链与星形。 

例如，有两个顶点`[-2, -5]`通过一条边连接，删除两者的总和为 0。粗心地对所有数字求和而不考虑删除的方法将返回 -7。 

## 方法

 一种简单的暴力方法是尝试每种可能的叶子删除序列，然后压缩树。 这是正确的，因为它直接实现操作，但其时间复杂度是指数级的。 每次删除都会改变树，导致组合爆炸。 和`n`最多5×10^5，这是不可能的。 

关键的见解是压缩将 2 度顶点链减少到单个边。 因此，这个问题可以用**顶点度数**来重新表述：只有度数大于 2 的顶点才会在压缩后“贡献”多条边。 叶子和 2 度顶点可以自由移除或压缩。 如果一个顶点有度数`d > 1`，它的值可以被多次计数：它可以出现在`d-1`压缩树中的边。 因此，我们可以根据减一的次数多次贪婪地添加最大的可用值。 

最佳方法是：

 1. 首先对所有顶点值求和。 
2. 计算每个顶点的度数。 
3. 对于度数大于1的顶点，将它们的值相加`degree - 1`次。 每个额外的出现都代表出现在另一个压缩边缘上的可能性。 

这种方法将问题简化为计算度数和对顶点值进行排序，在每个测试用例的最坏情况下，其时间复杂度为 O(n log n)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 基于度的贪心 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，请阅读`n`和数组`a`顶点值。 
2.初始化一个size的度数数组`n`为零。 当你阅读每条边时`(u, v)`，增加两者的度数`u`和`v`。 此后，每个条目都会告诉一个顶点有多少条边。 
3. 将结果初始化为所有顶点值的总和。 如果没有叶子被移除，这代表基线。 
4. 收集度数大于1的顶点的值。对于每个这样的具有度数的顶点`d`，将其值推入列表中`d - 1`次。 该列表表示顶点在压缩后可以额外贡献多少次。 
5. 按降序排列此列表。 迭代地，将元素一一添加到结果中。 每次相加后，将当前结果追加到输出列表中。 如果我们分阶段移除叶子，这会产生可实现的最大总和的序列。 
6. 输出最终值，该值对应于最优移除和压缩后的最大总和。 

为什么它有效：不变的是每个顶点的度数`d`最多可以算到`d-1`额外的时间，代表压缩后将存活的所有边缘。 叶子和 2 度顶点仅贡献一次； 较高度数的顶点贡献多次。 排序确保我们首先添加最大可能的贡献，从而最大化每一步的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        deg = [0] * n
        for _ in range(n-1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            deg[u] += 1
            deg[v] += 1
        
        res = sum(a)
        extra = []
        for i in range(n):
            for _ in range(deg[i]-1):
                extra.append(a[i])
        extra.sort(reverse=True)
        
        ans = [res]
        for x in extra:
            res += x
            ans.append(res)
        print(ans[-1])

if __name__ == "__main__":
    solve()
```解释：

-`deg[i]-1`关键是：每个度数大于1的顶点都可以被计数多次。 
- 排序确保我们首先添加最大值，模仿最佳叶子去除。 
- 使用`sys.stdin.readline`确保我们有效地处理大输入。 
- 该算法避免显式模拟删除或压缩，而是用基于程度的计数策略代替。
