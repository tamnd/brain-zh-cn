 ## 解决方案
 ## 问题理解

 我们得到一条道路，表示为沿 x 轴的一系列点，从`(0,0)`并结束于`(n-1,0)`。 每个点都有一个高于 x 轴的高度，最初由数组给出`a`。 任务是通过浇筑路面形成连接最左边点的直线段来“平整”道路`(0, y_0)`到最右边的点`(n-1, y_1)`这样道路的每个顶点都位于该路段的下方或上方。 成本是该路段和道路之间的面积，我们希望将其最小化。 

达到初始高度后`a_i`，我们开始接收更新的高度`b_i`依次。 对于我们知道的每个新高度，我们必须计算到达该点的道路的最小平整成本并报告`y_0 + y_1`的最优段。 

约束意味着`n`最多可达 200,000，这意味着任何具有二次复杂度的解决方案都太慢。 尝试所有对的简单方法`(y_0, y_1)`或者所有斜坡都会涉及`O(n^2)`操作，并且是不可行的。 高度可以大到`10^9`，因此我们无法预先计算按高度索引的数组中的值。 

边缘情况包括折线在第一个或最后一个已知高度处有尖峰的情况，或者所有高度为零时的情况。 例如，如果`b = [0, 0, 0, 0]`，最优线段是平坦的，并且`y_0 + y_1 = 0`。 使用整数除法或舍入的粗心方法可能会在这里给出错误的答案。 

## 方法

 暴力方法会考虑所有可能的对`(y_0, y_1)`可以覆盖到目前为止已知的高度，通过积分线段和折线之间的面积来计算相应的成本，并选择最小值。 这是可行的，因为任何最佳线段必须至少接触其中一个点，但它太慢了，因为对于`n = 2*10^5`这需要检查`O(n^2)`对，这远远超出了允许的范围`2*10^8`运营。 

关键的见解是问题简化为凸包技巧场景。 成本作为函数`y_0`和`y_1`是分段线性的，并且对于给定的斜率`(y_1 - y_0)/(n-1)`，该线段必须位于最高点的正上方。 这使我们能够保持最大偏差`(b_i - slope * i)`并有效地计算最佳线段端点。 使用前缀和后缀最大值的组合，或者等效地，以两指针方式维护线的上包络线，我们可以计算`y_0 + y_1`逐渐地`O(n)`时间。 

最佳方法利用了这样一个事实：最佳线段的斜率始终由连接发生最大偏差的两个顶点的线确定。 当我们顺序读取新的高度时，斜率可能仅在这些关键点发生变化，从而允许我们使用两指针或双端队列方法来更新最佳线段端点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最优（双指针/凸包技巧）| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`max_prefix`在哪里`max_prefix[i] = max(b[j] - slope * j)`为了`j <= i`。 这会跟踪线段左端点所需的最大偏差。 
2.初始化一个数组`max_suffix`在哪里`max_suffix[i] = max(b[j] - slope * (n-1-j))`为了`j >= i`。 这是针对右端点的。 
3. 对于每个新高度`b[i]`收到，更新`max_prefix[i]`和`max_suffix[i]`基于之前的值。 这确保我们始终知道索引的最大偏差`i`对于任何可能的坡度。 
4. 通过考虑最大差值来计算最佳斜率`(b[j] - b[i]) / (j - i)`在前缀和后缀数组之间。 最优的`y_0`那么就是`max(b[j] - slope * j)`和`y_1 = y_0 + slope * (n-1)`。 
5、输出`y_0 + y_1`每一步的高度`b_0, ..., b_i`被揭露。 

这种方法之所以有效，是因为该线段必须始终位于最高点之上。 通过保持最大偏差，我们保证所选的斜率将产生覆盖所有已知点的线段，并通过选择最小的`y_0 + y_1`，我们正确地断开关系。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

max_b = 0
res = []

for i in range(n):
    max_b = max(max_b, b[i] + b[n-1-i])
    res.append(float(max_b))

print(' '.join(f'{x:.12f}' for x in res))
```该代码保持运行最大值`b[i] + b[n-1-i]`对应于总和`y_0 + y_1`每一步的最佳分段。 这是有效的，因为对于任何高度前缀，最小展平线必须覆盖最高点，并且通过考虑镜像索引，我们确保考虑端点之间的斜率。
