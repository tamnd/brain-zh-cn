 ## 解决方案
 ## 问题理解

 我们沿着一条笔直的道路从位置 0 移动到位置 x，然后返回到 0。汽车消耗的燃油与距离成正比，每单位距离消耗一单位燃油。 不同的是，加油只能在一组固定的中间位置进行，每次我们到达其中一个位置时，油箱就会立即加满。 

问题不是模拟行程，而是确定使往返行程可行的最小油箱尺寸，因为我们可以在每次经过加油站时有策略地加油。 

旅程的结构迫使我们考虑“保证完全加油点”之间的差距。 车是0点满载出发的，所以第一站取决于我们在第一站之前能走多远。 此后，加油之间的每个航段都必须有足够的燃油容量，以便一次性通过。 

约束足够小，每个测​​试用例的任何 O(n²) 推理都是完全安全的。 当 n 最大为 50，t 最大为 1000 时，即使检查所有间隔或计算排序位置上的局部最大值也是微不足道的。 这表明该解决方案可能基于简单的扫描或直接观察，而不是任何高级数据结构。 

当最后一个站点远离 x 时，会出现微妙的边缘情况。 如果到 x 的最后一段路段较长，则该距离在往返行程中会产生两倍的影响，因为回程也必须经过该区域，而无需在 x 本身加油。 

另一种边缘情况是只有一个站点时。 然后，路径分成三个强制段：0 到车站、车站到 x 以及对称返回路径。 天真的方法可能会忘记回程反映了前向结构，从而有效地使某些段约束加倍。 

## 方法

 思考这个问题的一种强力方法是用猜测的水箱尺寸来模拟行程。 对于固定容量 C，我们从 0 步行到 x，尽可能加油，并检查是否可以到达 x 并在燃料耗尽的情况下返回。 尝试从 1 到 x 的所有可能容量并验证每个容量都是正确的。 每次模拟的成本为 O(n)，因为我们只按顺序检查站点，并且尝试所有容量的成本为 O(x · n)。 由于 x 至多为 100，因此这已经可以接受，但没有必要。 

关键的观察结果是，唯一重要的是整个行程中连续的“必须无故障到达”点之间的最大距离。 这些点是 0（所有加油站）和 x，但 x 的行为有所不同，因为它不是加油点。 

在前进的过程中，我们必须确保连续车站之间的每一段路段都是可通行的。 在回程中，相同的路段以相反的顺序出现，但有一个关键的额外约束：从最后一站返回 0 的最后一段也必须在不加油的情况下在 x 处完成，因为 x 对我们没有帮助。 

这将问题简化为查找排序序列中连续相关点（包括 0 和 x）之间的最大距离，并且对最后一段的修正在其约束中有效地加倍。 

最佳解决方案来自于注意到答案由最大间隙控制，但从最后一站到 x 的最终间隙是特殊的，因为它在往返中出现了两次。

 ## 算法演练

 我们独立处理每个测试用例。

1. 我们首先想象沿路的全套关键点：0、所有车站位置和 x。 这些点将路线划分为多个路段，每个路段都必须在没有中间加油的情况下穿过。 
2. 我们计算 0 和第一个站点之间的最大距离。 这是初始燃油需求，因为我们从 0 开始，油箱已满，但在到达第一个加油站之前无法加油。 
3. 我们计算连续站点之间的所有距离。 每个这样的部分都必须在向前和向后的行程中穿过，因此水箱必须足够大以覆盖任何这样的间隙。 
4. 我们计算最后一个站点与 x 之间的距离，但我们将其与内部间隙区别对待，因为 x 不是加油点。 该路段对于两个旅行方向都至关重要，实际上使其成为往返旅行的瓶颈。 
5. 如果我们从概念上展开回程约束，答案是所有内部车站间隙的最大值以及最后一段的两倍。 

看待这一问题的一种更清晰的方法是，最差的路段决定了避免卡在两个强制加油点之间所需的最小油箱容量。 

### 为什么它有效

 汽车行为将路线划分为由加油点分隔的独立路段。 在任何一段内，燃料只会减少，而加油会完全重置状态。 这意味着当一段长度超过水箱容量时，唯一可能发生的故障。 由于每条可行路线必须在两个方向上遍历每个线段，因此最大线段长度是绑定约束。 端点 x 处的不对称性是通过认识到最终路段在没有中间加油的情况下经过两次来处理的，这使其实际上成为最具限制性的情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x = map(int, input().split())
    a = list(map(int, input().split()))
    
    # include endpoints
    points = [0] + a + [x]
    
    # forward max gap
    ans = 0
    for i in range(1, len(points)):
        ans = max(ans, points[i] - points[i-1])
    
    # return trip effect: last segment effectively doubles constraint
    ans = max(ans, 2 * (x - a[-1]))
    
    print(ans)
```该实现显式构建了包括 0 和 x 的关键点的有序列表。 该循环计算最大相邻差异，捕获路线的所有内部约束。 最后一行纠正了由于最后一站之后直至 x 的路段在没有任何在 x 处加油的可能性的情况下所穿过的事实而引入的不对称性。 

关键的微妙之处在于最后一段乘以 2。 如果没有这一点，人们可能会低估回程要求，因为汽车在掉头后必须再次经过相同的距离。 

## 工作示例

 ### 示例 1

 输入：```
3 7
1 2 5
```点数：[0, 1, 2, 5, 7]

 我们计算差距：

 | 步骤| 积分 | 差距|
 | --- | --- | --- |
 | 0→1 | 0 到 1 | 1 |
 | 1→2 | 1 到 2 | 1 |
 | 2→5 | 2 至 5 | 3 |
 | 5→7 | 5 至 7 | 2 |

 最大内部间隙为 3。最后一段为 7 - 5 = 2，因此加倍约束为 4。最终答案为 4。 

这表明，尽管没有单个前进航段超过 3 个，但回程迫使最后航段受到更严格的处理。 

### 示例 2

 输入：```
3 6
1 2 5
```点数：[0, 1, 2, 5, 6]

 | 步骤| 积分 | 差距|
 | --- | --- | --- |
 | 0→1 | 0 到 1 | 1 |
 | 1→2 | 1 到 2 | 1 |
 | 2→5 | 2 至 5 | 3 |
 | 5→6 | 5 至 6 | 1 |

 内部最大值为 3。最后一段为 1，加倍为 2。最终答案为 3。 

这证实了最后一段并不总是占主导地位； 只有当它很大时才会影响答案。

 ## 边缘情况

 当只有一个加油站时，结构会塌陷为两段：0 到 a1 和 a1 到 x。 该算法仍然有效，因为它比较两个间隙并考虑了双倍的最终段。 这些值中的最大值正确地捕获了限制约束。 

当最后一个站点非常接近 x 时，最后一段加倍并不重要，答案完全由内部间隙驱动。 这是自然处理的，因为所有间隙的最大值已经包括那些较大的内部距离（如果存在）。 

当站均匀分布时，所有间隙都相等，算法会返回均匀的间距作为所需的储罐尺寸。 最后一段的加倍不会扭曲结果，除非最终间隙特别大，与往返的实际约束结构相匹配。
