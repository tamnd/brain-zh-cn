 ## 解决方案
 ## 问题理解

 我们被要求确定最小初始功率$x$连锁闪电法术可以击败一排怪物，无论法术如何传播，前提是我们选择第一个最佳击中的怪物。 每个怪物都有生命值$a_i$，咒语以力量开始$x$在第一个目标上，然后在每次命中时减少 1。 问题是，在第一次击中后，击中其余怪物的顺序是任意的，但必须尊重邻接性 - 下一个目标必须是先前击中的怪物的邻居。 这意味着最坏情况的传播可以将最低的剩余伤害分配给具有最高生命值的怪物。 

我们被放弃$3 \cdot 10^5$生命值高达以下的怪物$10^9$。 任何明确考虑法术命中的每种可能顺序的算法都是不可能的，因为有$n!$排列。 这表明我们需要一种方法来推理最坏的情况，而无需模拟每个序列。 需要观察的边缘情况包括非常小的数组（大小 1 或 2）、所有运行状况都相等的数组以及运行状况严格按递增或递减顺序排列的数组，因为天真的贪婪方法可能会低估最小启动功率。 

例如，如果输入是：```
3
1 10 1
```粗心的方法可能会首先选择中间的怪物，并从那里线性分配减少的伤害，认为这是最佳的。 但如果法术首先击中极端怪物，那么中间的高生命值怪物可能会幸存，除非我们选择$x$足够大。 正确的输出必须确保从最佳的第一个怪物开始，每次命中的排列都会导致每个怪物被杀死。 

## 方法

 暴力方法是尝试每个起始位置，生成剩余怪物的每个有效排列（尊重邻接性），计算每个序列所需的初始功率，并取最大值。 这在原则上是正确的，但需要$O(n! \cdot n)$最坏情况下的操作，这是不可能的$n = 3 \cdot 10^5$。 

关键的见解来自于理解，在最坏的情况下，最大的伤害减量将落在生命值最高的怪物身上。 该法术的效果本质上是，从某个位置开始，随着法术向外传播，伤害减少 1。 这可以重新构造为将数组分成两半：从所选起点开始的左段和右段。 每一段距离最远的怪物受到的伤害是距起点的距离。 为了承受最坏情况的排列，初始功率$x$必须满足$x \ge a_i + d$对于每个怪物，其中$d$是其在所选方向上距起点的距离。 

由此，我们认识到，最小初始功率是通过选择起始怪物来确定的，使得$a_i + \text{distance to start}$被最小化。 这是一个经典的一维数组优化问题，可以用$O(n)$使用前缀最大值来计算时间，而不是模拟排列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个潜在的起始怪物，计算最大值$a_i + \text{distance from start}$向右和向左。 从概念上讲，对怪物的伤害随着距离的增加而线性减少，因此最远的怪物是限制因素。 
2. 从左到右、从右到左预先计算前缀最大值。 让`pref[i]`存储最大的`a[i] - i`， 和`suff[i]`存储最大的`a[i] - (n - 1 - i)`。 这些代表了法术从起始位置向左或向右传播时所需的最坏情况的额外力量。 
3. 迭代每个起始位置并计算所需的初始功率作为左右传播值的最大值加上距离偏移。 
4. 返回所有起始位置的最小初始功率。 

这是有效的，因为无论法术如何传播，每个方向最远的怪物总是会受到相对于起始力量的最小伤害。 通过预计算`pref`和`suff`，我们将问题从考虑所有排列简化为评估每个索引的简单公式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

# precompute prefix and suffix maxima for worst-case distances
pref = [0] * n
suff = [0] * n

pref[0] = a[0]
for i in range(1, n):
    pref[i] = max(pref[i-1], a[i] + i)

suff[-1] = a[-1]
for i in range(n-2, -1, -1):
    suff[i] = max(suff[i+1], a[i] + (n-1-i))

res = float('inf')
for i in range(n):
    left = pref[i-1] if i > 0 else float('-inf')
    right = suff[i+1] if i < n-1 else float('-inf')
    max_required = max(left - i if i > 0 else 0, right - (n-1-i) if i < n-1 else 0, a[i])
    res = min(res, max_required)

print(res)
```第一个循环计算前缀最大值，假设咒语从最左边的怪物开始并向右传播。 每个`pref[i]`从索引中捕获怪物的最坏情况要求`0`到`i`。 第二个循环从右到左对后缀执行相同的操作。 当迭代每个可能的起始怪物时，我们通过检查两个方向的最坏情况并取最大值来计算所需的法术强度。 最后，最小的这个值就是答案。 

边界条件很微妙：我们必须处理`i=0`或者`i=n-1`阵列的一侧没有怪物。 这些被安全地替换为`-inf`或为零以避免影响最大值。 此外，必须小心处理整数减法，以避免距离计算中出现差一错误。
