 ## 解决方案
 ## 问题理解

 我们需要决定一个给定的正整数是否可以分成两个大小足够接近的因子。 一个数字`x`如果存在两个正整数，则被认为是右耦合`a`和`b`在哪里`a`是较小的因数，`b`是更大的因素，他们的产品正是`x`，并且较小的因子至少是较大因子的一半。 

等价地，选择除数对后`(a, b)`和`a <= b`，我们只需要检查是否`b <= 2a`。 如果存在这样的一对，则答案是`1`; 否则答案是`0`。 

输入最多包含 1000 个独立数字，每个数字都小于`2^15`，只有 32768。这个上限非常小，因此对每个数字执行数百次检查的算法很容易足够快。 尝试每对可能的因子的解决方案仍然是不必要的，因为最多有几百个可能的除数需要检查。 甚至一个`O(x)`对于这个限制，扫描是可以接受的，但是我们自然可以通过仅测试除数到平方根来减少工作量。 

有几种情况可能会因粗心的实施而被破坏。 一个常见的错误是使用浮点除法作为条件`a / b >= 0.5`，这可能会带来可避免的精度问题。 整数当量`2 * a >= b`是准确的。 

例如，输入：```
1
66
```有因素`6 * 11`。 自从`6 / 11`大于`0.5`，输出为：```
1
```仅检查平方根附近最接近的因子对并错误地假设两个因子必须相等的解决方案将错过这种情况。 

另一个边缘情况是素数：```
1
55
```唯一的因子对是`1 * 55`和`2 * 1 < 55`，所以输出是：```
0
```仅检查数字是否具有除 1 之外的因数的解决方案会给出错误的结果，因为并非每个合数都是右耦合的。 

最小可能的输入值也值得考虑：```
1
1
```因子对是`1 * 1`，并且满足条件。 正确的输出是：```
1
```从因子开始搜索的实现`2`会错误地拒绝它。 

## 方法

 直接的暴力方法是尝试每一个可能的值`a`，检查是否`a`划分`x`，然后计算`b = x / a`。 如果`a <= b`和`b <= 2a`，我们找到了有效的分解。 这种方法是正确的，因为每个可能的较小因素都会被检查。 

对于一个号码`x`，这需要检查来自的所有值`1`到`x`, 给予`O(x)`运营。 最大值接近 32768 和 1000 个测试用例，最坏的情况约为 3200 万次检查，这在许多语言中可能仍然会通过，但它忽略了因子对的数学结构。 

更好的观察是因素成对出现。 如果`a`是一个除数`x`，匹配因子为`b = x / a`。 每对中至少有一个成员不大于以下的平方根`x`，所以我们只需要检查除数`sqrt(x)`。 每当我们找到除数时`a`，我们立即知道相应的较大因子并可以测试所需的不等式。 

蛮力方法之所以有效，是因为它探索了所有可能的因式分解，但它花费时间检查不能是因子对中较小一侧的值。 平方根观察消除了那些不必要的检查，同时保留了考虑每个可能的候选对的保证。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个测试用例 O(x) | O(1) | O(1) | 接受这些限制，但没有必要 |
 | 最佳 | 每个测试用例 O(sqrt(x)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个输入数字`x`，开始检查可能的除数`1`最多`sqrt(x)`。 我们只需要搜索这个范围，因为每个大于平方根的除数都有一个已经被检查的匹配的较小除数。 
2.当一个值`a`划分`x`，计算配对因子`b = x / a`。 这对`(a, b)`代表一种可能的写法`x`作为产品。 
3. 确保`a`是较小的因数。 由于循环仅达到平方根，`a`总是小于或等于`b`。 
4. 检查是否`b <= 2 * a`。 这是原始比率条件的整数形式，避免了浮点计算。 
5. 如果任何除数对满足条件，则打印`1`。 如果循环结束时没有找到一个，则打印`0`。 

正确性来自于以下事实：`x`显示为某个除数`a`及其配对值`x / a`。 由于所有较小的因素至多`sqrt(x)`，算法检查每个可能的候选对。 该算法完全接受较大因子不超过较小因子两倍的对，这正是所需的条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(x):
    d = 1
    while d * d <= x:
        if x % d == 0:
            a = d
            b = x // d
            if b <= 2 * a:
                return 1
        d += 1
    return 0

def main():
    n = int(input())
    ans = []
    for _ in range(n):
        x = int(input())
        ans.append(str(solve_case(x)))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```功能`solve_case`独立处理一个号码。 循环变量`d`代表一个可能的较小因素，并且条件`d * d <= x`将搜索限制在必要的范围内。 

什么时候`x % d == 0`，代码找到了一个完整的因子对。 较大的因子是通过整数除法计算的，因此四舍五入不会影响结果。 比较使用`b <= 2 * a`而不是除法，这样可以避免浮点精度问题。 

乘法`d * d`这里是安全的，因为最大值`x`只有 32768。在较大的问题中，这种边界检查通常会使用`d <= x // d`以避免具有固定大小整数的语言中的整数溢出。

 ## 边缘情况

 对于最小输入：```
1
1
```循环检查除数`1`，找到这对`(1, 1)`，并验证`1 <= 2`。 算法返回`1`，正确认识到该数字可以分成两个相等的因子。 

对于素数：```
1
55
```唯一有用的因子对是`(1, 55)`。 该算法找到除数`1`并检查`55 <= 2`，失败了。 由于没有其他约数，所以答案仍然是`0`。 

对于具有远不相等的有效对的数字：```
1
66
```该算法在看到像这样的对后不会停止`(1, 66)`或者`(2, 33)`。 一直持续到除数`6`，在哪里找到`(6, 11)`。 自从`11 <= 12`，它返回`1`。 

对于完美的正方形：```
1
121
```除数`11`创建该对`(11, 11)`。 相等的因子总是满足条件，因为较大的因子与较小的因子的大小完全相同，因此输出为`1`。
