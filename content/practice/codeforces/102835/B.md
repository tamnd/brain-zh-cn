 ## 解决方案
 ## 问题理解

 任务是获取四个给定的数字并创建尽可能多的不同的非负整数。 每个有效表达式必须使用所有四个数字恰好一次。 这些数字可以重新排列、组合成多位数字，并与基本算术运算加法、减法和乘法相连接。 目标不是找到一个表达式，而是计算可以产生多少个不同的最终值。 

例如，用数字`1 1 2 1`，表达式`21 + 11`创造`32`， 尽管`111 - 2`创造`109`。 产生相同值的不同表达式仅贡献一次。 输出是所有可到达的非负结果集的大小。 

输入仅包含四位数字，因此搜索空间很小。 一个正常的问题`n = 10^5`需要接近线性的时间，但这里固定的大小完全改变了策略。 我们可以对这四个位置进行指数枚举，因为只有`2^4 = 16`子集。 挑战不在于数据量，而在于确保每种可能的表达形式都得到表达。 

棘手的部分是处理数字的所有分组方式。 粗心的解决方案可能只会尝试原始的数字顺序而错过重新排列。 用于输入`1 1 2 1`，一个永远不会形成的程序`21`会错过诸如`32`，即使它们是有效的。 

另一个常见的错误是忽略重复的结果。 用于输入`1 1 1 1`, 表达式`11 + 1 - 1`和`1 * 111`是不同的表达式，但答案仅对每个生成的整数计数一次。 正确的输出是`15`。 

最后一个边缘情况是减法产生负值。 该问题仅要求非负整数，因此不得将负的中间结果或最终结果插入到答案集中。 例如，像这样的表达式`1 - 2 - 1 - 1`不应该贡献`-3`。 

## 方法

 直接的方法是生成所有可能的表达式。 一种方法是排列四位数字，决定在何处进行串联，在结果片段之间插入运算，然后计算表达式。 这是正确的，因为每个法律表达式都可以通过这些选择来描述。 

但是，手动编写此枚举很容易出错。 由于操作可以以不同的方式嵌套，因此表达式形状的数量不断增加。 递归生成方法更干净。 它将每个数字子集视为一个较小的独立表达问题。 

在关键观察之后，蛮力的想法变得更容易管理：四位数字位置只有十六个子集。 对于每个子集，我们可以存储可以使用这些数字得出的所有值。 子集可以通过以每种可能的顺序连接其数字，或者通过分成两个较小的非空子集并将它们的值与`+`,`-`， 或者`*`。 

暴力版本重复重建相同的较小表达式，而子集动态编程版本计算每个子集一次并重用它。 最终答案来自为全套四位数字存储的值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(表达式数量) | O(表达式数量) | 概念上可行，但很容易错过案例 |
 | 最佳| O(3^4 * V^2) | O(3^4 * V^2) | O(2^4 * V) | O(2^4 * V) | 已接受 |

 这里`V`是为一个子集存储的最大值数。 由于位数固定为四位，因此很容易在限制范围内。 

## 算法演练

 1. 读取四位数字并用位置表示它们`0`到`3`。 使用位置是因为相同的数字仍然代表不同的可用图块。 
2. 构建一个递归函数，返回可从位置子集获得的所有数字。 返回的集合表示使用这些数字的每个可能的表达式。 
3. 对于子集，首先将按每个可能的顺序连接其数字而创建的所有数字相加。 这处理诸如以下的值`21`,`112`， 和`1112`。 
4. 尝试各种方法将子集划分为两个非空的不相交部分。 计算左侧和右侧部分的所有值，然后使用加法、减法和乘法合并每一对。 
5. 存储包含所有四个数字的完整子集的结果集。 删除负值，因为只有非负整数才是有效答案，然后输出剩余不同值的数量。 

这样做的原因是任何有效表达式的最后一个操作要么是串联，要么是三个算术运算之一。 如果是算术表达式，则表达式自然会分成两个较小的表达式。 递归完全遵循此结构，因此生成了每个有效的表达式。 由于每个生成的表达式都是有效的，因此不会添加不正确的值。 

## Python 解决方案```python
import sys
from functools import lru_cache
from itertools import permutations

input = sys.stdin.readline

def solve():
    digits = list(map(int, input().split()))

    @lru_cache(None)
    def dp(mask):
        res = set()
        ids = [i for i in range(4) if mask & (1 << i)]

        for p in permutations(ids):
            value = 0
            for i in p:
                value = value * 10 + digits[i]
            res.add(value)

        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other and sub < other:
                for a in dp(sub):
                    for b in dp(other):
                        res.add(a + b)
                        res.add(a - b)
                        res.add(a * b)
                        res.add(b - a)
            sub = (sub - 1) & mask

        return res

    ans = sum(1 for x in dp(15) if x >= 0)
    print(ans)

if __name__ == "__main__":
    solve()
```递归函数`dp(mask)`是解决方案的核心。 位掩码描述了哪些数字位置可用。 使用位置而不是数字值可以防止意外合并相同的数字。 

置换循环将每个可能的串联数字相加。 这是必要的，因为数字的顺序是灵活的。 对于包含数字的子集`1`和`2`， 两个都`12`和`21`必须考虑。 

子集分割循环通过要求尝试每个分区一次`sub < other`。 这可以避免进行两次相同的分割。 算术组合包括两个减法方向，因为表达式的左侧部分和右侧部分是有序的。 

Python 整数不会溢出，因此乘法是安全的。 记忆装饰器确保每个子集被评估一次，而不是被重新计算多次。

 ## 边缘情况

 对于`1 1 1 1`，算法通过不同的表达式构建许多相同的值。 因为每个子集结果都存储在一个集合中，所以像这样的表达式`1+1+1+1`和`11-7`样式重复不能夸大答案。 

为了`0 0 0 0`，串联仅产生零，并且每个算术运算也保持为零。 最后一组恰好包含一个有效的非负数，因此输出为`1`。 

对于减法产生负值的情况，例如使用数字`1 2 3 4`，结尾低于零的表达式是内部生成的，但在计数之前进行过滤。 这可以防止无效的负整数影响答案。
