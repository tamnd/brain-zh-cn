 ## 解决方案
 ## 问题理解

 我们得到一个非常小的二值图像，通常最多 10 x 10 个单元格。 每个单元格要么是空的，要么是已满的。 网格恰好包含一个由 1 组成的相连的几何图形，并且该图形保证是完美的正方形或中心三角形（直立或颠倒）。 

这里的正方形是指与网格对齐的 k x k 块，内部没有间隙。 三角形是指一排行的堆叠，其中每行的个数对称地增加或减少两个，形成居中的金字塔形状。 

任务是确定存在两种形状中的哪一种。 

约束 n ≤ 10 消除了任何优化的需要。 即使对所有行、列和形状假设进行粗暴扫描也足够快。 解决方案可以多次自由地检查每个单元。 

主要的边缘情况来自于依赖局部模式而不是全局结构。 例如，如果三角形和正方形的顶行包含连续的行，则它们可能看起来很相似，但三角形的定义特征是不断变化的行长度，而正方形在形状的所有行中保持恒定的行长度。 另一个微妙的情况是倒三角形，其中最宽的行位于顶部而不是底部。 

当只检查第一行或计算总行数而不验证结构时，粗心的方法通常会失败。 三角形和正方形有时可能具有相似的总数，例如两者都可以有 9 个，但只有一个符合所需的行模式。 

## 方法

 解决这个问题的一个蛮力方法是尝试识别所有的边界框，然后检查它是否形成一个完美的正方形或是否与某个中心柱形成一个三角形。 

对于方形检查，我们验证边界框内的所有单元格都是 1。 对于三角形检查，我们尝试每个可能的顶点行和中心列，并验证行长度是否匹配 1、3、5 等，或者倒三角形的相反模式。 这是可行的，因为网格很小，所以即使检查每个可能的中心和高度也很便宜。 

仅当网格很大时，蛮力的低效率才会出现，因为我们会尝试许多可能的中心。 这里，由于 n ≤ 10，即使是 O(n3) 或 O(n⁴) 的行为也是微不足道的。 

关键的简化是我们实际上不需要“猜测”结构。 我们可以直接检测是否所有的都形成一个填充的矩形。 如果是的话，它一定是一个正方形。 如果不是，则唯一剩余的有效结构是三角形，并且其结构强制单个中心对齐，这可以通过检查中点周围的行对称性来验证。 

这将问题简化为简单的模式验证而不是形状重建。

 ## 算法演练

 我们依赖于一个简单的观察：正方形是唯一一种形状内的每一行都具有相同数量的连续行的形状，而三角形总是具有不同的行长度。

1. 扫描网格并找到所有包含 的位置。 我们记录包含 1 的最小和最大行索引和列索引。 这给了我们形状的边界矩形。 
2. 计算该边界矩形内有多少个。 如果 1 的数量等于矩形的面积，则内部的每个单元格都被填充，这意味着该形状是一个实心矩形。 
3. 如果我们有一个实心矩形，我们检查它的高度是否等于宽度。 如果是这样，则形状是正方形，因为该问题保证只存在正方形或三角形。 
4. 如果边界矩形未完全填充，则该结构一定是三角形。 在这种情况下，我们通过认识到填充区域不能是矩形（除非它是正方形）来隐式验证它，因此唯一有效的剩余配置是三角形。 
5. 输出相应的结果。 

该实现避免了显式三角形重建，因为该问题保证了输入形状的有效性。 

### 为什么它有效

 正方形的独特之处在于，边界框的所有行都具有恒定的行长度，并且完全占据所有单元格。 任何偏离完全占用的情况都会立即破坏矩形属性，并且问题约束中唯一剩余的有效结构是三角形。 由于保证输入恰好包含一个有效形状，因此通过矩形完整性进行分类就足够了，并且不会对有效输入进行错误分类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    g = [input().strip() for _ in range(n)]
    
    cells = [(i, j) for i in range(n) for j in range(n) if g[i][j] == '1']
    
    min_r = min(i for i, j in cells)
    max_r = max(i for i, j in cells)
    min_c = min(j for i, j in cells)
    max_c = max(j for i, j in cells)
    
    total_ones = len(cells)
    area = (max_r - min_r + 1) * (max_c - min_c + 1)
    
    if total_ones == area and (max_r - min_r) == (max_c - min_c):
        print("SQUARE")
    else:
        print("TRIANGLE")
```该解决方案的工作原理是提取所有周围的紧密边界框并检查它是否被完美填充。 如果是，则形状必须是正方形，因为只有正方形才能占据完整的矩形。 否则，在问题约束下唯一剩余的有效配置是三角形。 

一个微妙的点是我们从不尝试明确地重建三角形几何。 这可以避免误解倒置三角形或偏离中心的情况而产生的错误，因为这些保证确保不存在模糊的混合。

 ## 边缘情况

 关键边缘情况是一个三角形，其边界框仍然是矩形。 例如，宽三角形可以具有看起来几乎被填满的边界矩形，但缺少内部单元。 在这种情况下，面积检查会失败，因为面积检查少于框中的总单元格数，因此将其正确分类为三角形。 

另一个边缘情况是最小有效形状大小为 2。2 x 2 正方形通过了填充度和正方形检查，而任何 2 行三角形必然会留下间隙或不均匀的行长度，导致其无法满足矩形条件。
