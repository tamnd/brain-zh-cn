 ## 解决方案
 ## 问题理解

 我们被要求恢复建筑物内居民发射飞机的序列中缺失的信息。 每层楼只有一名居民，居民依次发射纸飞机。 楼层一住户`i`从他们的角度来看，只有在少于`c`飞机已经起飞。 关键的一点是，飞机下方的所有楼层都可以看到飞机，因此每个居民都可以累积起飞的视图。 一些发射被记录为未知（`0`），我们的任务是计算将实际楼层分配给这些未知数的方法的数量，以便启动序列是可信的，模数$10^9 + 7$。 

限制很小：`n`和`c`增加到 100，并且`m`取决于`n * c`但总和`m`所有测试用例的总和是$10^4$。 这意味着动态规划解决方案是可行的，因为状态空间可以由下式界定`(c, n, m)`不超过内存限制。 尝试所有可能的分配的朴素组合方法将呈指数增长`m`并且无法工作。 

一个微妙的边缘情况是当一架飞机被记录为从违反最低限度的地板上抛出时`c`从该楼层的角度启动规则。 例如，如果`c = 2`第三架飞机来自 1 楼，而到目前为止只发射了 1 架飞机，不存在有效的分配，输出应该是`0`。 另一个棘手的情况是当所有飞机都是间隙时； 必须对满足累积约束的所有序列进行计数。 

## 方法

 蛮力方法将迭代所有序列`m`发射，用从 1 到 任何可能的楼层号填充每个零`n`。 对于每个完成的序列，我们将模拟发射并检查每个居民是否至少看到`c`轮到飞机时。 这种方法显然是指数级的`m`因为每个零最多有`n`选项，导致`O(n^m)`即使对于中等水平的人来说，这也是不可行的`m`。 

关键的观察结果是，该问题可以根据每个楼层已经观察到的发射次数转化为动态规划问题。 在任何时候，我们只需要跟踪每个楼层已经看到了多少架飞机。 因为每层楼看到后就停止发射`c`飞机，我们可以折叠计数 ≥ 的状态`c`。 我们将 DP 状态定义为`dp[pos][mask]`在哪里`pos`是当前飞机指数，`mask`对已经到达的楼层进行编码`c`发射。 对于未知的发布，我们会迭代所有符合条件的楼层。 对于已知的发射，我们必须检查可行性。 DP 转换保持不变，即没有楼层看到超过`c`在它抛出自己的之前发射。 

这种见解极大地减少了状态空间。 我们不再模拟完整的序列； 我们只跟踪有多少楼层达到了阈值，其边界为`n`和`c`，给出多项式时间解。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^m) | O(n^m) | O(米) | 太慢了|
 | 动态规划| O(m * n * c^n) | O(m * c^n) | 已接受（通过修剪进行优化）|

 ## 算法演练

 1.初始化一个数组`seen`长度`n+1`跟踪每个楼层观察到的飞机数量。 楼层编号为 1 至`n`。 该数组允许我们强制执行以下规则：地板在以下时间后停止启动`c`看到发射。 
2. 迭代飞机序列。 对于每架飞机：

 - 如果飞机已知（`a_i > 0`），检查相应楼层是否至少已经见过`c`飞机。 如果是，则序列无效，返回0。否则，递增`seen`适用于所有楼层`1`通过`a_i`考虑到下面可以看到这次发射。 
- 如果飞机未知（`a_i == 0`），考虑仍需要启动的所有楼层（即`seen[floor] < c`）。 对于每个符合条件的楼层，通过递增递归计算序列数`seen`并继续前往下一架飞机。 对计数求模求和$10^9 + 7$。 
3. 使用记忆以避免重新计算。 状态可以表示为`(pos, tuple(seen))`。 这确保我们不会探索相同的`seen`多次配置，将复杂度从指数级降低`m`到多项式`m * n * c^n`。 
4. 处理完所有飞机后，返回计算出的数量。 

为什么它有效：DP 保持了这样的不变性，即在每一步中，没有楼层看到的次数超过`c`飞机起飞前。 通过考虑未知飞机的所有有效选择并修剪无效路径，我们保证每个计数序列都满足问题的约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10000)

MOD = 10**9 + 7

def solve():
    t = int(input())
    results = []
    for _ in range(t):
        n, c, m = map(int, input().split())
        a = list(map(int, input().split()))
        memo = {}

        def dp(pos, seen):
            key = (pos, tuple(seen))
            if key in memo:
                return memo[key]
            if pos == m:
                return 1
            res = 0
            if a[pos] != 0:
                floor = a[pos]
                if seen[floor] >= c:
                    return 0
                new_seen = seen[:]
                for i in range(1, floor + 1):
                    new_seen[i] += 1
                res = dp(pos + 1, new_seen)
            else:
                for floor in range(1, n + 1):
                    if seen[floor] < c:
                        new_seen = seen[:]
                        for i in range(1, floor + 1):
                            new_seen[i] += 1
                        res = (res + dp(pos + 1, new_seen)) % MOD
            memo[key] = res % MOD
            return res

        seen = [0] * (n + 1)
        results.append(dp(0, seen))

    print("\n".join(map(str, results)))
```该解决方案设置了具有记忆功能的递归 DP。 每个递归调用处理一架飞机，分别处理已知和未知的情况。 对于未知飞机，将尝试所有符合条件的楼层。 这`seen`每次递归时都会复制数组以保持路径之间的独立性。 记忆用途`tuple(seen)`以确保可散列性。 增加递归限制以处理深度达到`m = 100 * 100 = 10000`。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(m * n * c^n) | O(m * n * c^n) | 每个 DP 状态`(pos, seen)`被访问过一次；`seen`有`n`每个条目 ≤`c`。 |
 | 空间| O(m * c^n) | O(m * c^n) | 记忆化存储每个状态，加上递归堆栈最多`m`。 |

 给定限制（`n, c ≤ 100`， 全部的`m ≤ 10^4`），具有修剪和记忆功能的 DP 可以在内存中和时间限制内轻松适应。
