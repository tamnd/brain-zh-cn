 ## 解决方案
 ## 问题理解

 我们被要求计算从建筑物发射飞机的有效序列的数量`n`地板。 每层楼恰好有一名住户，所有住户至少希望集体启动`c`飞机。 该建筑有`m`总发射量。 每次发射都会记录哪个楼层发射了它，但在这个版本中，所有发射记录都丢失了，所以每条记录都是一个空白。 我们需要计算有多少种方法可以用整数来填补这些空白`1`到`n`这样序列就可以按照规则发生。 

该规则施加了两个限制。 首先，从居民的角度来看`i`- 楼，如果他们已经看到了，他们就会停止发射`c`飞机。 其次，到一天结束时，每个居民必须至少看到`c`飞机。 在简单版本中，因为所有`a_i`缺失，问题简化为计算长度序列`m`每层楼的地方`i`至少在之后不会启动`c`已经在其楼层下方或楼层进行了发射，到最后至少有`c`每层楼都可见发射。 

考虑到约束条件（`1 <= n, c <= 100`和总计`m`在所有测试用例 ≤ 10^4 中），时间复杂度大致的算法`O(n * m * c)`是可行的。 非明显的边缘情况是`m`正是`c`，或者当`m`接近于`n * c`。 例如，如果`n = 3`,`c = 2`， 和`m = 4`，一种幼稚的方法可能会导致低层发射太晚的序列，从而使顶层不可能看到足够的发射。 序列如`[2, 3, 1, 3]`无效，因为一楼没看到`c`发射。 

## 方法

 暴力方法是生成所有长度的序列`m`值来自`1`到`n`并根据可见性规则测试每个序列。 对于每个序列，我们都会模拟每个楼层的视角，计算他们看到的飞机数量，并检查是否满足规则。 这原则上可行，但需要`n^m`在最坏的情况下进行操作，即使对于适度的人来说也是完全不可行的`n`和`m`自从`100^100`是天文数字。 

关键的观察是序列只需要确保顶层看到的时候`c`飞机，每层楼至少见过`c`以及。 这本质上是单调的：如果地板`i`看到`c`发射，那么下面的所有楼层至少都看到了`c`。 这使得该问题适合动态规划。 

让`dp[i][j]`代表分配方式的数量`j`率先推出`i`地板，这样没有地板超过`c`- 飞机限制。 我们可以推导出类似于星条组合方法的递推，但受极限限制`c`每个楼层。 具体来说，我们可以使用组合公式来进行分布`j`相同的物体变成`i`每个 bin 最多有`c`对象。 包含-排除原则使我们能够有效地计算有效序列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^m) | O(n^m) | O(米) | 太慢了|
 | DP/组合学| O(n * c) | O(n * c) | 已接受 |

 ## 算法演练

 1. 预计算阶乘和逆阶乘模`10^9 + 7`最多`n * c`。 这使我们能够快速计算组合`C(x, y)`模数`MOD`使用`fact[x] * inv_fact[y] * inv_fact[x-y] % MOD`。 
2. 对于每个测试用例，如果`m < c`，立即返回0，因为发射总量连底层都不够看`c`。 
3. 初始化`res = 0`。 该变量将累积有效序列的总数。 
4.循环`k = 1`到`n`，代表实际有助于发射的楼层数。 对于每个`k`，计算精确的序列数`k`楼层贡献非零发射。 利用包含排除原理来统计至少有多少种赋值方式`c`启动到每个`k`使得发射次数的总和等于`m`。 
5. 使用整数解数公式`x1 + x2 + ... + xk = m`和`0 <= xi <= c`对于每个楼层，可以通过组合数学和包含排除的交替总和来有效地计算。 
6. 将每项贡献添加到`res`模数`10^9 + 7`。 
7. 输出`res`。 

这里的不变性是，通过枚举贡献楼层的数量并使用有界组合分布，我们计算每个楼层至少看到的所有序列`c`飞机不超过问题所施加的限制。 包含-排除确保我们避免过度计数违反规则的序列`c`限制。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

def precompute_factorials(limit):
    fact = [1] * (limit + 1)
    inv_fact = [1] * (limit + 1)
    for i in range(1, limit + 1):
        fact[i] = fact[i - 1] * i % MOD
    inv_fact[limit] = pow(fact[limit], MOD - 2, MOD)
    for i in range(limit - 1, -1, -1):
        inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD
    return fact, inv_fact

def comb(n, k, fact, inv_fact):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

fact, inv_fact = precompute_factorials(10000)

t = int(input())
for _ in range(t):
    n, c, m = map(int, input().split())
    input()  # skip the line of zeros
    if m < c:
        print(0)
        continue
    res = 0
    for k in range(1, n + 1):
        # number of solutions to x1 + ... + xk = m with 0 <= xi <= c
        val = 0
        for i in range(k + 1):
            sign = -1 if i % 2 else 1
            val = (val + sign * comb(k, i, fact, inv_fact) * comb(m - i * (c + 1) + k - 1, k - 1, fact, inv_fact)) % MOD
        res = (res + val) % MOD
    print(res)
```该解决方案首先预先计算阶乘和逆阶乘以进行组合计算。 然后独立处理每个测试用例。 我们跳过零的输入，因为它们不携带任何信息。 我们循环遍历可能有贡献的楼层`k`并使用包含-排除来计算有效序列。 模运算可确保结果保持在范围内。
