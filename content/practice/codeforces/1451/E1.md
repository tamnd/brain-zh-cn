 ## 解决方案
 ## 问题理解

 我们得到一个大小为的隐藏数组$n$， 在哪里$n$是二的幂。 数组中的每个元素都是范围内的整数$[0, n-1]$。 目标是通过最多询问来重建数组$n+2$三种类型的查询：数组任意两个索引之间的 AND、OR 和 XOR。 收集到足够的信息后，我们必须正确输出整个数组。 

因为每个元素的边界是$n-1$，所有数字都适合$\log_2 n$位。 自从$n$可以大到$2^{16}$，我们需要避免任何要求的方法$\Theta(n^2)$查询； 和$n = 2^{16}$，这需要$2^{32}$查询，这是不可能的。 互动限制$n+2$表明我们需要一个高度结构化的策略，可能基于元素之间的按位关系，而不是检查所有对。 

一种简单的方法是尝试使用 AND 或 OR 的所有对来直接重建每个元素，但这超出了查询限制。 例如，需要注意的边缘情况包括某些元素为零或相同的数组$[0,0,1,2]$，因为如果不仔细选择索引，简单的 XOR 累积可能会混淆相同的值。 另一个微妙的情况是当所有数字都最大时（$n-1$）-我们必须确保按位求和不会溢出有关值边界的假设。 

## 方法

 暴力方法是查询每个元素和固定引用（如第一个元素）之间的所有 AND 或 OR。 对于每个元素$a_i$，我们可以计算$a_1 \text{ AND } a_i$和$a_1 \text{ OR } a_i$然后求解$a_i$。 这是可行的，因为 AND 和 OR 给出了足够的约束来重建这两个数字。 然而，这需要$2(n-1)$查询太大了$n$最多$2^{16}$。 这个想法原则上可行，但查询预算禁止它。 

关键的见解来自按位恒等式：$$x + y = (x \text{ AND } y) + (x \text{ OR } y)$$这意味着知道两个数字的 AND 和 OR 就可以得出它们的精确总和。 如果我们选择三个元素，比如说$a_1, a_2, a_3$，并计算对 (1,2)、(1,3) 和 (2,3) 的 AND 和 OR，我们可以重建它们的和。 让$S_{12} = a_1 + a_2$,$S_{13} = a_1 + a_3$， 和$S_{23} = a_2 + a_3$。 求解这三个方程给出的值$a_1, a_2, a_3$独一无二。 一次$a_1$已知，我们可以使用单个 XOR 查询找到所有其他元素，因为$a_i = a_1 \text{ XOR } (a_1 \text{ XOR } a_i)$。 

该策略使用 3 个 AND/OR 查询来重建三个元素，再加上每个剩余元素一个 XOR，给出$3 + (n-3) = n$查询，符合$n+2$限制。 问题结构——小有界整数、二次方数组大小以及和之间的线性关系——使这种方法成为最佳方法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 查询次数过多，超出限制 |
 | 最佳 | O(n) | O(n) | 已接受，使用 ≤ n+2 个查询 |

 ## 算法演练

 1. 查询对 (1,2)、(1,3) 和 (2,3) 的 AND 和 OR。 计算总和$S_{12} = \text{AND}_{12} + \text{OR}_{12}$,$S_{13} = \text{AND}_{13} + \text{OR}_{13}$,$S_{23} = \text{AND}_{23} + \text{OR}_{23}$。 这给出了这些对的精确总和。 
2. 求解$a_1$使用公式$a_1 = (S_{12} + S_{13} - S_{23}) // 2$。 这个来自系统：$$a_1 + a_2 = S_{12}, \quad a_1 + a_3 = S_{13}, \quad a_2 + a_3 = S_{23}$$从前两个分离株的总和中减去第三个分离株$2a_1 = S_{12} + S_{13} - S_{23}$。 

1. 计算$a_2 = S_{12} - a_1$和$a_3 = S_{13} - a_1$。 由于整数运算，这些是精确的； 所有数字都在范围内$[0, n-1]$。 
2. 对于每个剩余元素$a_i$和$i > 3$, 查询异或$a_1$, 给予$a_1 \text{ XOR } a_i$。 然后恢复$a_i = a_1 \text{ XOR } (a_1 \text{ XOR } a_i)$。 这是有效的，因为 XOR 会自行反转：$x \text{ XOR } y \text{ XOR } x = y$。 
3. 输出重构后的数组，前缀为“!”。 

为什么有效：三个未知数的三对和的系统总是可解为整数。 XOR 是可逆的，并且唯一地确定相对于已知参考的每个元素。 查询数正好是$n$，始终低于允许的$n+2$。 位运算永远不会溢出，因为所有元素都 ≤$n-1$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
print_flush = lambda x: (print(x), sys.stdout.flush())

def ask(op, i, j):
    print_flush(f"{op} {i} {j}")
    return int(input())

def main():
    n = int(input())
    # Step 1: Query AND and OR for first three elements
    and12 = ask("AND", 1, 2)
    or12 = ask("OR", 1, 2)
    s12 = and12 + or12

    and13 = ask("AND", 1, 3)
    or13 = ask("OR", 1, 3)
    s13 = and13 + or13

    and23 = ask("AND", 2, 3)
    or23 = ask("OR", 2, 3)
    s23 = and23 + or23

    # Step 2: Solve for a1, a2, a3
    a1 = (s12 + s13 - s23) // 2
    a2 = s12 - a1
    a3 = s13 - a1

    # Step 3: Reconstruct remaining elements using XOR
    a = [a1, a2, a3]
    for i in range(4, n+1):
        x = ask("XOR", 1, i)
        a.append(a1 ^ x)

    # Step 4: Output
    print_flush("! " + " ".join(map(str, a)))

if __name__ == "__main__":
    main()
```该解决方案首先使用成对的 AND 和 OR 确定前三个元素的精确值，从而给出它们的总和。 然后它重建所有剩余元素相对于$a_1$使用异或查询。 每个查询都会立即刷新以避免空闲限制，并且所有算术都是整数安全的，因为输入是有界的。
