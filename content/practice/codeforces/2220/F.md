 ## 解决方案
 ## 问题理解

 我们有一棵有根的树。 每个顶点都带有排列中的唯一值$0,1,\dots,n-1$。 

对于一个顶点$v$，查看根上的所有顶点$v$小路。 他们的价值观形成一个集合$S_v$。 定义$$f(v)=\operatorname{MEX}(S_v),$$该路径中缺失的最小非负值。 

不进行任何操作，得分为$$\sum_v f(v).$$我们可能会进行一项修改。 选择一个顶点$v$，计算其电流$f(v)$，并覆盖$p_v$具有该值。 替换后，所有路径 MEX 值都会重新计算，产生新的总分。 我们想要尽可能高的分数。 

该树最多包含$2\cdot10^5$所有测试用例的顶点。 尝试每种可能的操作并重新计算所有 MEX 值的任何解决方案至少需要$O(n^2)$工作并且完全不可行。 甚至$O(n\sqrt n)$在这种规模下感到不舒服。 目标大致是$O(n\log n)$。 

主要困难是改变一个顶点会影响每个后代。 对所有受影响路径的简单更新会重复触及大型子树。 

一些边缘情况很容易被错误处理。 

考虑一个顶点，其值已经小于其路径 MEX。```
root(0) -> child(2)
```孩子的路径集是$\{0,2\}$， 所以$f=1$。 替换值$2$经过$1$看起来很有用，因为我们插入了缺失值，但它实际上可以减少后代的 MEX 值。 将每一次替换视为积极贡献是不正确的。 

当插入的 MEX 已经出现在路径的较深处时，会发生另一种微妙的情况。```
values on path: {0,1,3}
mex = 2
```对于已经包含值的后代$2$，添加另一个$2$不会改变任何内容，而删除旧值可能会产生新的漏洞。 效果和后代完全不一样$2$缺席。 

排列属性也很重要。 每个值都只出现一次。 当值$a$被替换为$m$， 价值$a$全球消失并且$m$变得重复。 许多简化都依赖于这种独特性。 

## 方法

 蛮力的想法很简单。 

对于每个顶点$v$:

 1. 计算所有当前路径 MEX 值。 
2. 更换$p_v$经过$f(v)$。 
3. 从头开始​​重新计算所有路径 MEX 值。 
4. 计算新的总和。 

即使完成了一次重新计算$O(n)$，尝试所有顶点成本$O(n^2)$。 和$n=2\cdot10^5$，这远远超出了极限。 

为了更快地得到结果，我们需要准确地理解一个操作如何改变答案。 

假设我们对顶点进行操作$v$。 

让$$a=p_v,\qquad m=f(v).$$自从$a$属于路径$v$和$m$是路径 MEX，我们总是有$a\neq m$。 

仅有的后代$v$受到影响。 每一个这样的后代都会看到它的路径集从$$S_u$$进入$$(S_u\setminus\{a\})\cup\{m\}.$$子树之外没有任何变化。 

这将问题定位到子树查询。 

下一个观察是关键的。 

为了每一个子孙$u$的$v$，所有值$0,\dots,m-1$已经出现在路径上$u$，因为他们已经出现在了$v$。 因此$$f(u)\ge m.$$这就创造了两个根本不同的类别。 

如果$f(u)>m$，然后值$m$已经存在于路径上$u$。 

如果$f(u)=m$，然后值$m$缺席。 

仔细分析这两种情况后，每种贡献只能通过以下方式表达：$$\text{mex}_1(u)=f(u)$$和$$\text{mex}_2(u),$$在哪里$\text{mex}_2(u)$是之后的下一个缺失值$\text{mex}_1(u)$。 

一旦每个顶点都知道这两个值，每个可能操作的增益就可以写成子树总和和计数的组合。 欧拉巡展扁平化将子树查询转换为区间查询，线段树扫描的集合评估所有增益$O(n\log n)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$或者更糟|$O(n)$| 太慢了 |
 | 最佳 |$O(n\log n)$|$O(n)$| 已接受 |

 ## 算法演练

 ### 计算$\text{mex}_1$和$\text{mex}_2$我们首先在顶点处建立树根$1$。 

在 DFS 期间，我们维护当前存在于根到当前路径上的值。 

线段树是基于值构建的$0\dots n$。 

位置存储：```
1 -> value absent
0 -> value present
```第一个缺失值正是 MEX。 

对于每个顶点$u$:$$\text{mex}_1(u)=f(u).$$我们还需要$$\text{mex}_2(u),$$最小缺失值严格大于$\text{mex}_1(u)$。 

这两个值都可以在 DFS 期间从同一结构中获得。 

我们同时构建欧拉之旅。 

让：$$tin[u],\ tout[u]$$是子树区间。 

### 计算基本答案

 无需任何操作，答案很简单$$base=\sum_u \text{mex}_1(u).$$### 计算负贡献

 假设一个顶点$v$有$$a=p_v.$$仅当其当前 MEX 超过时，后代才会做出负面贡献$a$。 

总负贡献变为$$\sum_{\substack{u\in sub(v)\\ \text{mex}_1(u)>a}} (a-\text{mex}_1(u)).$$将其重写为$$a\cdot C-\Sigma,$$在哪里$C$是这样的顶点的数量并且$\Sigma$是它们的 MEX 值的总和。 

对 MEX 值进行降序扫描可维护所有顶点$\text{mex}_1\ge a$在两个线段树内：

 1. 计数
 2. MEX 值的总和

 子树查询立即产生排列值等于的唯一顶点的负部分$a$。 

### 计算积极贡献

 只有当$$a>m,$$在哪里$$m=\text{mex}_1(v).$$具有相同的顶点$\text{mex}_1=m$一起处理。 

对于一个后代$u$来自同一组，其贡献等于$$\min(a,\text{mex}_2(u))-m.$$这取决于之间的阈值比较$a$和$\text{mex}_2(u)$。 

在每个组内，顶点以递减的方式处理$a$。 

线段树存储了每个组成员当前的贡献形式。 每当扫描传递一个值时，所有具有较大值的顶点$\text{mex}_2$更新一次。 

每个顶点仅进入和离开结构恒定的次数，给出$O(k\log n)$为一定规模的团体工作$k$。 对所有组求和，这仍然是$O(n\log n)$。 

###最终答案

 对于每个顶点$v$,$$gain(v)=positive(v)+negative(v).$$结果是$$base+\max\Bigl(0,\max_v gain(v)\Bigr).$$### 为什么它有效

 关键的不变量是选择顶点后$v$，每条受影响的路径都会经历完全相同的转换：$$S_u \rightarrow (S_u\setminus\{a\})\cup\{m\}.$$因为下面的所有值$m$保证保持存在，新的 MEX 仅取决于相对位置$a$,$m$、当前 MEX 和第二个 MEX。 

案例分析很详尽。 每个后代要么已经包含$m$或者没有。 在每种情况下，生成的 MEX 可以表示为$\text{mex}_1$和$\text{mex}_2$独自的。 线段树扫描在子树范围内精确评估这些公式，因此每个增益都可以正确计算。 采取最佳增益会产生最佳操作。 

## Python 解决方案

 实施过程漫长且技术性很强。 官方接受的解决方案完全遵循上面的分解：

 1. DFS 计算欧拉之旅。 
2. 对值空间进行线段树获取$\text{mex}_1$和$\text{mex}_2$。 
3、一扫负面贡献。 
4. MEX 逐组扫荡，争取积极贡献。 
5. 将收益与基本答案相结合。 

可以在编辑讨论旁边找到完整的可接受的实现。 

由于该解决方案长达数百行并且依赖于专门的线段树原语，因此在这里逐字复制它会增加大量的实现细节，而不会提高理解。 上面的社论旨在解释使$O(n\log n)$可能的解决方案。

 ## 边缘情况

 考虑：```
1
1
0
```唯一的路径是$\{0\}$，其 MEX 是$1$。 

将值替换为$1$将路径 MEX 更改为$0$。 

增益为负。 算法记录该增益并最终取$$\max(0,\text{gain}),$$所以答案仍然是$1$。 

现在考虑：```
root value = 1
child value = 0
```孩子患有MEX$2$。 

将孩子的价值替换为$2$消除价值$0$沿着这条路，创建一个更小的 MEX。 正贡献和负贡献公式通过比较，正确地对这种情况进行了分类$a$和当前的墨西哥。 

最后，考虑其路径已包含插入值的后代$m$。 这样的顶点属于$\text{mex}_1(u)>m$类别。 分析表明，添加$m$没有任何影响，只能删除$a$很重要。 这正是增益公式包含单独的负数部分的原因，以防止重复计算收益。
