 ## 解决方案
 ## 问题理解

 我们有两种类型的积木：单位长度的片段和由两个以直角连接的片段组成的 L 形片段。 我们需要构建一个具有尺寸的矩形网格$n \times m$这样每件作品都只使用一次。 输入提供计数$p$对于单个段和$q$对于 L 形件。 我们的任务是找到任意一对正整数$n$和$m$允许构建这样一个网格，或者报告说这是不可能的。 

约束条件允许$p$和$q$最多$10^8$以及最多 100 个测试用例。 这排除了任何迭代所有可能的解决方案$n$和$m$天真的值，因为维度的潜在搜索空间可能是巨大的。 直接强力方法测试所有矩形$10^8$段太慢。 我们还需要考虑小的边缘情况，例如$p=1, q=2$，其中天真的平铺假设可能会错误地得出存在答案的结论。 另一个微妙之处是，L 形块可以旋转，因此它们对网格周长的贡献可能会有所不同，但它们总是恰好覆盖面积上的两个单位段。 

第一个关键观察结果是网格“覆盖的单位长度段”的总数是$2q + p$。 每个L形片贡献两段覆盖范围，每个单元段贡献一段覆盖范围。 的面积为$n \times m$网格是$n \cdot m$。 所以我们需要$n \cdot m = p + 2q$。 然而，并不是每一个因式分解$p+2q$之所以有效，是因为我们还必须匹配碎片覆盖的垂直和水平边缘的数量。 这是使朴素因式分解无效的微妙部分：沿行和列的段数必须与可用的段数一致。 

一些不明显的边缘情况包括：

 -$p=1, q=2$：覆盖的总段数为$5$，不能形成矩形区域$n \cdot m = 5$具有整数边。 输出应该是$-1$。 
-$p=2, q=10$：总段数$22$可以分解为$2 \times 11$或者$11 \times 2$。 只有与 L 形件的旋转约束相匹配的因式分解才有效。 

这些案例说明，仅仅检查面积是不够的； 我们必须考虑 L 形件所施加的面积和奇偶校验约束。 

## 方法

 蛮力方法会尝试所有可能的矩形大小$1 \le n \le p+2q$并计算$m = (p + 2q)/n$，检查网格大小是否$n \times m$可以完全填充给定的$p$和$q$。 每次检查都需要测试 L 形件和单个片段的所有排列排列。 这对于小数字来说是正确的，但对于$p, q$最多$10^8$因为它可能涉及$10^8$每个测试用例的迭代次数。 

最佳方法依赖于两个见解。 首先，所有棋子所覆盖的总面积正好是$p + 2q$。 其次，网格中的每一行和每一列都必须由 L 形片和单个段的组合覆盖，使得超出完全 L 形覆盖范围所需的“额外段”恰好是$p$。 具体来说，如果我们尝试行优先或列优先平铺，则每行最多可容纳$\lfloor m/2 \rfloor$沿其宽度呈 L 形件。 由此我们可以解出$n$或者$m$使用整数除法和模检查，生成每个因子的恒定时间公式$p + 2q$。 由于因子的数量大致为$O(\sqrt{p+2q})$，即使输入很大，算法也能快速运行。 

这减少了枚举所有除数的解决方案$p + 2q$检查剩余的单元段是否能填满未被L形件覆盖的剩余槽。 这比暴力平铺要快得多。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((p+2q) * (p+2q)) | O(1) | O(1) | 太慢了 |
 | 因式分解 + 检查 | 每个测试用例 O(√(p+2q)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，计算总覆盖率$S = p + 2q$。 这表示形成网格所需的单位长度段的总数。 
2. 枚举所有正整数对$(n, m)$这样$n \cdot m = S$。 这是通过迭代完成的$n$从$1$到$\sqrt{S}$并让$m = S / n$如果$S$可以整除$n$。 
3. 对于每位候选人$(n, m)$，检查网格是否可以准确填充$q$L 形件和$p$单个段。 有效的配置必须满足$\max(n, m) - 1 \ge q$和$p \ge 0$，反映出L形件至少需要2x1的面积并且可以旋转。 
4. 如果有效$(n, m)$找到后，将其打印并移至下一个测试用例。 如果没有配对有效，则打印$-1$。 
5. 对所有测试用例重复此操作。 

工作原理：该算法保证了正确性，因为它只考虑矩形尺寸，其乘积等于可用线段的总数，确保区域被精确覆盖。 通过检查L形件和剩余单段的放置可行性，确保没有一个件被闲置。 因式分解$S$穷举所有可能的整数网格维度，因此不会错过任何有效的解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        p, q = map(int, input().split())
        total = p + 2*q
        found = False
        i = 1
        while i * i <= total:
            if total % i == 0:
                n, m = i, total // i
                # check if L-shaped pieces can fit
                if n >= 2 and m >= 2:
                    found = True
                    print(n, m)
                    break
                if n == 1 and m >= 2 and q == (m - 1):
                    found = True
                    print(n, m)
                    break
                if m == 1 and n >= 2 and q == (n - 1):
                    found = True
                    print(n, m)
                    break
            i += 1
        if not found:
            print(-1)

if __name__ == "__main__":
    solve()
```该代码首先读取测试用例的数量。 对于每个测试用例，它计算所需的段总数。 while 循环枚举所有除数$\sqrt{S}$找到候选维度。 里面的条件检查L形棋子是否可以放置在矩形块中或沿着单行或单列放置。 这些标志确保每个测试用例仅打印一个有效答案。 边缘情况，例如$n=1$或者$m=1$明确处理以避免错误的平铺假设。
