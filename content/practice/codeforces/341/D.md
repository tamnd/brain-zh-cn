 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$矩阵最初用零填充。 该问题要求我们有效地处理两种类型的运算：一种计算子矩阵内所有元素的异或，另一种将给定值异或到子矩阵的每个元素。 每个操作指定子矩阵的左上角和右下角坐标，以及用于更新的异或值。 

输入范围很重要。$n$最多可达 1000 个，因此元素总数可达$10^6$，以及操作次数$m$可以高达$10^5$。 对于每个查询或更新迭代子矩阵的所有单元格的简单解决方案将花费$10^5 \cdot 10^6 = 10^{11}$最坏情况下的操作，远远超出了我们1秒的处理能力。 这意味着我们不能在每次操作中单独触摸每个元素； 我们需要一个能够有效地进行范围更新和范围查询的数据结构。 

需要注意的边缘情况包括单元素子矩阵、覆盖整个矩阵的子矩阵以及对同一元素的多次更新。 例如，对同一值进行异或两次应该将其抵消。 当更新重叠时，如果不正确处理范围更新，幼稚的前缀异或方法可能会给出错误的结果。 

## 方法

 蛮力方法很简单。 对于每次更新，我们循环遍历给定子矩阵中的每个元素，并将其与给定值进行异或。 对于每个查询，我们循环子矩阵并对所有值进行异或。 这种方法是正确的，但速度很慢：对于$n \times n$矩阵与$m$操作，每个操作都可能触及整个矩阵，我们最多可以有$m \cdot n^2 = 10^5 \cdot 10^6 = 10^{11}$的操作，这是不可行的。 

关键的见解是，异或在加法和减法运算下都表现良好，因为它是它自己的逆。 此属性允许我们使用 2D Fenwick 树（二元索引树），其中每个单元存储异或贡献。 标准的 2D Fenwick 树支持点更新和矩形查询，但我们可以使用包含排除原则扩展它以支持矩形更新。 这个想法是维护一个结构，在该结构中，我们可以通过适当更新四个角来将值异或到矩形，然后可以使用这些角的异或和来表达对矩形的任何查询。 这将每个操作减少到$O(\log^2 n)$，这对于给定的约束来说足够快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 * m) | O(n^2 * m) | O(n^2) | O(n^2) | 太慢了 |
 | 2D BIT（矩形更新+查询）| O(m * log^2 n) | O(m * log^2 n) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 初始化二维二叉索引树`bit`有尺寸$n+1 \times n+1$方便地处理从 1 开始的索引。 
2. 定义辅助函数`xor_update(x, y, val)`执行标准 BIT 更新：xor`val`进入 BIT 中受坐标影响的所有位置`(x, y)`。 这是核心构建块。 
3. 异或一个值`v`在一个矩形上`(x0, y0)`到`(x1, y1)`，我们应用包含-排除：

 - 异或`v`在`(x0, y0)`- 异或`v`在`(x0, y1 + 1)`- 异或`v`在`(x1 + 1, y0)`- 异或`v`在`(x1 + 1, y1 + 1)`这确保了当我们计算任何单元格的前缀异或时`(x, y)`，重叠矩形的贡献正确组合。 
4. 定义辅助函数`prefix_xor(x, y)`计算子矩阵的异或`(1,1)`到`(x, y)`使用标准 2D BIT 查询遍历。 
5. 计算任意子矩阵的异或`(x0, y0, x1, y1)`，使用前缀异或值应用包含-排除：

 - 结果 =`prefix_xor(x1, y1) ^ prefix_xor(x0-1, y1) ^ prefix_xor(x1, y0-1) ^ prefix_xor(x0-1, y0-1)`6. 处理输入中的每个操作。 如果是更新，则调用矩形更新例程。 如果是查询，则使用子矩阵前缀 xor 计算 xor 并打印结果。 

工作原理：具有包含排除功能的 2D BIT 维护所有更新的异或贡献。 每个前缀查询精确检索影响给定矩形的所有更新的异或。 由于异或是关联且自逆的，因此重叠更新可以正确取消，并且不会发生重复计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class BIT2D:
    def __init__(self, n):
        self.n = n
        self.bit = [[0] * (n + 2) for _ in range(n + 2)]

    def update(self, x, y, val):
        i = x
        while i <= self.n:
            j = y
            while j <= self.n:
                self.bit[i][j] ^= val
                j += j & -j
            i += i & -i

    def rectangle_update(self, x0, y0, x1, y1, val):
        self.update(x0, y0, val)
        self.update(x0, y1 + 1, val)
        self.update(x1 + 1, y0, val)
        self.update(x1 + 1, y1 + 1, val)

    def prefix_xor(self, x, y):
        res = 0
        i = x
        while i > 0:
            j = y
            while j > 0:
                res ^= self.bit[i][j]
                j -= j & -j
            i -= i & -i
        return res

    def query(self, x0, y0, x1, y1):
        return (self.prefix_xor(x1, y1) ^ self.prefix_xor(x0 - 1, y1) ^
                self.prefix_xor(x1, y0 - 1) ^ self.prefix_xor(x0 - 1, y0 - 1))

n, m = map(int, input().split())
bit2d = BIT2D(n)

for _ in range(m):
    cmd = list(map(int, input().split()))
    if cmd[0] == 1:
        x0, y0, x1, y1 = cmd[1:]
        print(bit2d.query(x0, y0, x1, y1))
    else:
        x0, y0, x1, y1, v = cmd[1:]
        bit2d.rectangle_update(x0, y0, x1, y1, v)
```这`BIT2D`类封装了所有 BIT 逻辑。 这`update`方法修改一个细胞及其所有祖先，并且`rectangle_update`将异或应用于四个角。 这`query`方法使用包含-排除来检索子矩阵的精确异或。 

边界处理很微妙。 我们需要`n+2`用于内部数组以避免索引溢出`x1+1`或者`y1+1`等于`n+1`。 使用从 1 开始的索引可以避免与 BIT 遍历混淆。
