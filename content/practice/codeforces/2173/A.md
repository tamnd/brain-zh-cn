 ## 解决方案
 ## 问题理解

 我们被要求在一系列课程中计划我们的睡眠时间表，每个课程要么重要，要么不重要。 该日期表示为二进制字符串，其中“1”表示重要类别，“0”表示不重要类别。 规则是，对于你参加的每一堂重要课程，你不仅要在这堂课上保持清醒，而且还要在下一堂课上保持清醒。`k`类。 不重要的课程可以自由地睡觉，除非适用强制唤醒规则。 我们的目标是最大限度地增加我们可以睡觉的课程数量。 

每个测试用例给出类的总数`n`，睡眠恢复窗口`k`，以及表示哪些类重要的字符串。 每个测试用例的输出应该是一个整数：我们可以在遵守清醒约束的情况下休眠的类的数量。 

限制很小：两者都`n`和`k`最多可以有 100 个，并且最多可以有 500 个测试用例。 这意味着即使是简单的`O(n^2)`每个测试用例的解决方案可能会起作用，但我们也可以瞄准`O(n)`解决方案，因为逻辑是顺序的。 非明显的边缘情况涉及连续的重要类或靠近字符串末尾的重要类，其中`k`窗口可能会延伸到末端之外。 

例如，考虑`n = 5, k = 2, s = "10101"`。 忽略重叠的简单方法可能会重复计算唤醒窗口，但正确的策略应该有效地处理重叠的唤醒周期。 另一个边缘情况是当`k`比其余类别大：`n = 3, k = 5, s = "100"`。 在这里，参加第一堂课迫使我们一直保持清醒。 

## 方法

 暴力方法将迭代字符串，并为每个重要的类标记下一个`k`类如强制清醒。 标记后，我们计算有多少个未标记的零以获得最大睡眠计数。 这是有效的，因为它直接模拟规则。 和`n`最多 100 个，标记最多`k`每个“1”的类最多为每个测试用例提供 100 × 100 = 10,000 次操作，对于 500 个测试用例来说这是可以接受的。 

最佳方法是我们不需要辅助数组来进行标记。 我们可以维护一个代表索引的指针，直到我们被强制唤醒。 当我们遍历类时，如果当前类索引小于该指针，我们必须保持清醒。 如果该类很重要，我们将指针更新为`i + k + 1`（因为数组是从 0 索引的）。 强制唤醒窗口之外的不重要的类可以休眠并增加我们的睡眠计数器。 这减少了簿记并使解决方案简单且线性`n`。 

关键的见解是，重叠的唤醒窗口会自然合并：在上一个唤醒窗口内参加重要的课程时，如果它比当前指针推得更远，则只会延长唤醒周期。 这确保我们永远不会少算或多算清醒的课程。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * k) | O(n) | 由于小的限制，可以接受|
 | 最佳 | O(n) | O(1) | O(1) | 已接受且干净|

 ## 算法演练

 1. 初始化`awake_until`到`-1`。 该变量跟踪您被迫保持清醒的类别索引。 
2. 初始化`sleep_count`到`0`。 这将存储您可以睡完的课程数。 
3. 迭代每个类索引`i`从`0`到`n-1`。 
4. 如果`i`大于`awake_until`并且班级并不重要（`s[i] == '0'`), 增量`sleep_count`因为你可以在这期间睡觉。 
5. 如果课程很重要（`s[i] == '1'`）， 更新`awake_until`到`max(awake_until, i + k)`。 这可以确保您保持清醒`k`重要课程之后的课程，但如果已经在之前的清醒窗口中，则保留较长的清醒时间。 
6. 迭代完成后，`sleep_count`包含您可以睡完的最大课程数。 

为什么它有效：不变的是在每个班级`i`,`awake_until`正确代表您必须保持清醒的最后一堂课。 通过更新`awake_until`使用`max`，重叠的清醒时段自然合并。 仅在以下情况下才允许睡觉`i > awake_until`并且类不重要，保证不违反强制唤醒约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    s = input().strip()
    awake_until = -1
    sleep_count = 0
    for i in range(n):
        if i > awake_until and s[i] == '0':
            sleep_count += 1
        if s[i] == '1':
            awake_until = max(awake_until, i + k)
    print(sleep_count)
```该代码初始化强制唤醒指针和睡眠类的计数器。 迭代字符串，每当类可以安全睡眠时，我们就增加睡眠计数器，并在遇到重要类时扩展强制唤醒窗口。 使用`max`确保重叠的唤醒窗口不会缩小。
