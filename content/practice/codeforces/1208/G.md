 ## 解决方案
 ## 问题理解

 我们被要求构建几个正多边形，它们都位于同一个圆上，并且我们希望尽可能地重用圆的边界点。 

每个多边形仅由它有多少个顶点决定。 如果一个多边形有$l$边，然后它使用$l$圆上等距的点。 我们可以独立旋转每个多边形，这意味着我们可以围绕圆移动其选定的一组顶点。 然而，一旦某个点被任何多边形使用，它就会成为圆上不同点的全局集合的一部分。 

任务是准确选择$k$该范围内的不同多边形大小$[3, n]$，并排列它们（以最佳旋转），以使所有多边形中使用的不同点的总数尽可能小。 

关键的交互是，如果不同的多边形的顶点集在圆的公共离散化上对齐，则它们可以共享顶点。 

约束条件$n \le 10^6$立即排除任何尝试所有尺寸子集或显式模拟几何形状的方法。 甚至存储或迭代多边形大小的所有候选组合也是不可能的。 任何有效的解决方案都必须将问题简化为除数或倍数的数论结构。 

一个天真的错误是假设选择最小的$k$多边形的大小总是使答案最小化。 这是错误的，因为重叠取决于可分性。 例如，三角形和六边形完美对齐，因为 3 除 6，从而充分重用顶点，而选择 4 和 5 则几乎没有重叠。 

当混合相对主要尺寸时，会出现另一种微妙的故障模式。 例如，尺寸为 4 和 6 的多边形共享对齐结构，但 4 和 5 则不共享对齐结构，即使 5 大于 4。任何纯粹按尺寸划分的贪婪都会中断。 

## 方法

 暴力方法会尝试选择所有子集$k$整数来自$[3, n]$，并为每个子集模拟需要多少个圆点。 对于固定集合，所需点的数量是容纳所有多边形顶点间距的最不常见结构，其对应于其边数的最小公倍数。 这需要计算所有组合的 LCM 并选择最小值。 

单独子集的数量是$\binom{n}{k}$，即使对于小规模来说也是不可行的$n$。 即使我们修复了一个子集，计算重叠也需要推理所有选定整数之间的整除关系。 这已经远远超出了时间限制。 

关键的见解是所需的圆点数完全由所选多边形大小的最小公倍数决定。 如果我们选择边长$a_1, a_2, \dots, a_k$，那么我们至少需要$\mathrm{lcm}(a_1, \dots, a_k)$等距点同时嵌入所有多边形。 然后，每个多边形对应于选择每个$\frac{\mathrm{lcm}}{a_i}$第-点。 

问题变成：选择$k$中的不同整数$[3, n]$最小化他们的LCM。 

最小化 LCM 相当于最小化所需的最高主功率覆盖范围。 最佳策略是打包彼此严重分开的数字。 我们不再考虑任意集合，而是转变视角：如果我们固定最大元素$x$，那么所有其他选择的数字应该是$x$以避免增加 LCM 超出$x$。 因此，对于固定的$x$，最好的可能集合是$x$加上尽可能多的除数$x$尽可能至少为 3 个。 

所以对于每一个$x$，我们计算有多少个有效除数$\ge 3$确实如此。 如果该计数至少为$k$，我们可以完全在除数格内形成一个集合$x$，得到答案$x$。 我们想要最小的这样$x$。 

这将问题变成了对所有数字进行除数计数筛选$n$，累积每个数字有多少个合格的除数有助于更高的倍数。

 ## 算法演练

 1. 对于每个整数$x$从 3 到$n$，将其解释为潜在的最大多边形尺寸。 我们将努力打造$k$大小全部被整除的多边形$x$，这保证了他们的 LCM 至多$x$。 
2. 创建数组`cnt[x]`跟踪有多少个有效数字$d \ge 3$划分$x$。 这是通过迭代所有可能的除数来计算的$d$并将贡献添加到的倍数$d$。 这是有效的，因为每个除数结构都在倍数之间共享。 
3. 填充后`cnt`, 扫描自$x = 3$向上并检查是否`cnt[x] >= k`。 第一个这样的$x$是可以容纳的最小圆尺寸$k$多边形。 
4.返回这个$x$作为答案。 

微妙的部分是为什么除数累加在全局而不是每个子集上起作用。 我们没有明确地构造多边形； 相反，我们正在验证是否至少有一个完整的除数闭集$k$存在于里面$[3, x]$。 如果是这样，我们可以将每个选定的除数分配为多边形大小并将所有内容嵌入其中$x$点。 

### 为什么它有效

 该算法依赖于以下不变量：如果所有选定的多边形大小都除以一个公共数$x$，那么所有多边形都可以精确地嵌入$x$圆上等距的点没有冲突。 任何重叠结构都会通过模块化对齐自动满足。 相反，任何具有最大使用点数的有效构造$x$产生一组多边形尺寸，其 LCM 不能超过$x$，这意味着它们都位于一个与除数兼容的结构中，其边界为$x$。 这使得检查除数容量足以保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, k = map(int, input().split())

    cnt = [0] * (n + 1)

    for d in range(3, n + 1):
        for m in range(d, n + 1, d):
            cnt[m] += 1

    for x in range(3, n + 1):
        if cnt[x] >= k:
            print(x)
            return

if __name__ == "__main__":
    main()
```该解决方案使用标准的类似筛子的循环构建除数频率表。 外循环选择一个候选除数$d$，并且内部循环将其贡献传播到所有倍数$m$，计算有多少个多边形尺寸除以每个可能的圆尺寸。 

最终扫描识别出最小的$x$至少支持$k$兼容的多边形尺寸。 

主要的实现陷阱是忘记多边形大小必须至少为 3，这就是累积从 3 而不是 1 或 2 开始的原因。

这表明，在 6 个点内，我们可以选择两个结构兼容的多边形尺寸，特别是 3 和 6，从而允许完全对齐。

 ## 边缘情况

 一种边缘情况是当$k = 1$。 该算法立即找到最小的$x \ge 3$至少有一个除数，即$x = 3$。 这符合单个三角形始终有效的事实。 

另一个边缘情况是当$n$是素数并且$k$很大。 例如，$n = 11$,$k = 2$。 唯一的除数关系是微不足道的，因此我们被迫转向更大的复合结构（如果存在的话）； 否则最小可行$x$只是累积足够除数密度的第一个值。 

该算法自然地处理这个问题，因为`cnt[x]`仅当除数存在时才会增长，并且素数的贡献最小，从而防止错误的早期触发。
