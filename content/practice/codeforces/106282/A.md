 ## 解决方案
 # 问题理解

 问题描述了一个简单的情况：有`n`需要将蘑菇均匀地放入`k`罐子。 如果`n`不能被整除`k`，必须收集更多的蘑菇。 目标是找到所需的最少数量的额外蘑菇，以便将蘑菇总数平均分配到所有罐子中。 

输入包含两个整数。 第一个是当前蘑菇的数量，第二个是罐子的数量。 输出是所需额外蘑菇的最少数量。 

约束允许两个值都大到`10^9`。 这立即排除了尝试模拟一一添加蘑菇的可能性，因为在最坏的情况下，答案本身可能接近于`10^9`。 即使是具有数亿次迭代的循环也太慢了。 该解决方案需要使用常数时间算法。 

主要的边缘情况来自于处理已经可整除的数字以及正确解释余数。 

考虑`n = 8`和`k = 4`。 正确的输出是`0`，因为八个蘑菇已经平均装满了四个罐子。 一个粗心的解决方案总是会增加`k - n % k`在这里仍然可以工作，但是如果执行不正确并且缺少特殊情况，它可能会返回`4`。 

另一种情况是蘑菇的数量小于罐子的数量。 例如：```
n = 3
k = 5
```正确的输出是`2`，因为再收集两个蘑菇后，就会有五个蘑菇，每个罐子一个。 一种仅检查是否存在的解决方案`n / k`已经是正数可能会错误地得出不可能进行分布的结论。 

最终的边界情况是余数接近于`k`。 例如：```
n = 17
k = 10
```正确的输出是`3`， 因为`17 + 3 = 20`，这是十七之后的第一个十的倍数。 忘记我们需要达到下一个倍数，而不仅仅是删除余数，会导致错误的答案。 

# 方法

 最简单的方法是重复添加一个蘑菇，直到总数可以被`k`。 这是有效的，因为每个有效答案都必须是一些移动的加法`n`到多个`k`。 如果我们尝试`0`， 然后`1`， 然后`2`，依此类推，第一个成功的值保证是最小的。 

问题是答案可能非常大。 认为`n = 1`和`k = 10^9`。 模拟需要近十亿次迭代才能达到有效的总数。 这远远超出了程序在典型比赛时间限制内所能完成的任务。 

关键的观察结果是整除性仅取决于除以后的余数`k`。 如果`n % k = r`， 然后`n`已经是`r`蘑菇距离之前的倍数`k`。 为了达到下一个倍数，我们需要添加`k - r`蘑菇。 唯一的例外是当`r = 0`，因为该数字已经有效，我们无需添加任何内容。 

整个问题简化为计算余数并将其转换为到下一个倍数的距离。

 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 # 算法演练

 1.读取当前蘑菇数量`n`和罐子的数量`k`。 
2. 计算`n % k`，它告诉我们在制作了尽可能多的完整组后还剩下多少蘑菇`k`尽可能。 
3. 如果余数为零，则输出`0`因为蘑菇已经可以平均分配了。 
4.否则，输出`k - (n % k)`，因为这正是从当前余数移动到下一个倍数所需的蘑菇数量`k`。 

为什么它有效：每个数字都可以被`k`是的倍数`k`。 开始于`n`，最接近的较大倍数`k`通过将余数增加到`k`。 如果余数已经为零，则最接近的有效倍数就是数字本身。 由于我们移动到最接近的可能倍数，所以添加的蘑菇数量是最少的。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
k = int(input())

rem = n % k

if rem == 0:
    print(0)
else:
    print(k - rem)
```前两行从输入中读取两个值。 没有多个测试用例，因此程序直接处理这些数字。 

余数计算是解决方案的核心。 Python 整数可以处理比以下值大得多的值`10^9`，所以不存在溢出问题。 

这`rem == 0`条件是必要的，因为`k - rem`会给`k`在这种情况下，但正确答案是零。 这是唯一需要的特殊情况。

# 测试用例```python
import sys
import io

def solve(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline
    n = int(input())
    k = int(input())

    rem = n % k
    ans = 0 if rem == 0 else k - rem

    sys.stdin = old_stdin
    return str(ans) + "\n"

 # 边缘情况

 对于`n = 8`和`k = 4`，算法计算`8 % 4 = 0`。 由于余数为零，因此立即返回`0`。 不需要额外的蘑菇，因为已经可以分发了。 

为了`n = 3`和`k = 5`，算法计算`3 % 5 = 3`。 下一个五的倍数是五，所以它计算`5 - 3 = 2`。 添加两个蘑菇后，就有五个蘑菇，每个罐子收到一个。 

为了`n = 17`和`k = 10`，算法计算`17 % 10 = 7`。 下一个十的倍数是二十，距离三。 答案`3`确认算法始终前进到最接近的有效总数，而不是简单地使用当前余数。
