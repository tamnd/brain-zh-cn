 ## 解决方案
 ## 问题理解

 我们给定一个整数区间`a`到`b`。 我们要选择一个长度`l`这样**每个**连续的长度段`l`这个区间内至少包含`k`素数。 

在满足这个条件的所有长度中，我们需要最小的一个。 如果长度不起作用，我们打印`-1`。 

另一种看待问题的方法是对于候选长度`l`，我们检查每个窗口`[x, x+l-1]`完全适合里面`[a, b]`。 仅当每个窗口至少包含`k`素数。 

区间端点最多为`10^6`。 这是关键的限制。 由于重复需要素数信息，因此预先计算所有素数`10^6`用筛子很便宜。 区间本身还可以包含最多`10^6`数字，因此任何单独检查每个窗口的每个可能长度的解决方案都会大致执行`10^12`操作，是完全不可行的。 

条件的结构表明其具有单调性质。 如果有一定的长度`l`有效，那么任何更大的长度也都有效。 较大的窗口只能包含至少与其较小的窗口一样多的素数。 这种单调性直接指向二分搜索。 

有几种容易被忽略的边缘情况。 

考虑：```
14 16 1
```区间内没有素数。 即使最大可能的窗口也包含零素数，所以答案是`-1`。 粗心的二分搜索实现可能永远不会明确验证解决方案是否存在。 

考虑：```
2 5 2
```窗户`[2,3]`包含两个素数，但是`[3,4]`仅包含一个。 仅查看几个窗口是不够的。 每个窗口都必须满足该条件。 

考虑：```
2 2 1
```该区间包含一个素数。 唯一可能的长度是`1`，这是有效的。 边界情况`a = b`经常揭示窗口处理中的差一错误。 

考虑：```
8 12 1
```唯一的素数是`11`。 长度`4`之所以有效，是因为每个长度为 4 的窗口都包含`11`，而长度`3`失败是因为`[8,10]`不包含素数。 最小有效长度不一定与连续素数之间的距离单独相关。 

## 方法

 最直接的解决办法就是尝试所有可能的长度`l`。 对于每个长度，检查该大小的每个窗口并计算它包含多少个素数。 如果所有窗口至少包含`k`质数，记录答案。 

可以使用素数值的前缀和来有效地计算窗口内的素数计数。 有了这样一个前缀和，检查一个窗口就变成了`O(1)`。 不幸的是，最多有`10^6`可能的长度和最多`10^6`每个长度的窗口。 即使在优化窗口查询之后，总工作量仍然存在`10^12`，远远超出了极限。 

关键的观察是单调性。 

假设长度`l`是有效的。 每个窗口的长度`l`至少包含`k`素数。 现在考虑任何更大的长度`L > l`。 每个长度-`L`窗口包含一些长度-`l`子窗口。 由于该子窗口已经至少包含`k`素数，较大的窗口也至少包含`k`素数。 

这意味着：

 - 无效长度优先，
 - 有效长度随后出现。 

答案是第一个有效长度，可以通过二分查找找到。 

测试候选长度`l`，我们滑动一个窗口`[a,b]`。 使用素数前缀和，我们可以在恒定时间内计算每个窗口中素数的数量。 如果任何窗口包含少于`k`素数，候选人失败。 

剩下的成分是快速素性预处理。 由于所有数字最多为`10^6`，埃拉托斯特尼的标准筛大致计算每个相关数字的素性`O(10^6 log log 10^6)`时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((b-a+1)²) | O(b) | 太慢了 |
 | 最佳 | O(b log log b + (b-a+1) log(b-a+1)) | O(b log log b + (b-a+1) log(b-a+1)) | O(b) | 已接受 |

 ## 算法演练

 1. 建立一个埃拉托色尼筛直至`b`并确定哪些数字是素数。 
2.构造前缀和数组`pref`在哪里`pref[i]`等于来自的素数个数`1`通过`i`。 
3. 定义函数`check(l)`。 
4. 对于每个起始位置`x`从`a`到`b-l+1`，计算窗口中素数的个数`[x, x+l-1]`使用：`pref[x+l-1] - pref[x-1]`5. 如果任何窗口包含少于`k`素数，返回`False`。 
6. 如果所有窗口都满足要求，则返回`True`。 
7. 在二分查找之前，验证最大可能长度是否有效。 这对应于整个区间`[a,b]`。 
8. 如果连最大长度都失败，则打印`-1`。 
9. 否则对长度进行二分查找`1`到`b-a+1`。 
10. 什么时候`check(mid)`成功，记为候选答案，继续搜索左半部分。 
11. 什么时候`check(mid)`失败，搜索右半部分。 
12. 打印找到的最小有效长度。 

### 为什么它有效

 前缀和数组保证每个窗口的素数计数都被精确计算。 这`check(l)`当每个长度时，函数精确地返回 true`l`窗口至少包含`k`素数。 

关键的性质是单调性。 如果长度`l`是有效的，任何更大的长度也是有效的，因为每个更大的窗口都包含一个有效的长度 -`l`子窗口，因此已经至少包含`k`素数。 因此，有效长度的集合形成了所有可能长度的后缀。 对这个单调谓词的二分查找找到最小的有效长度，这正是所需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b, k = map(int, input().split())

    is_prime = [True] * (b + 1)
    if b >= 0:
        is_prime[0] = False
    if b >= 1:
        is_prime[1] = False

    p = 2
    while p * p <= b:
        if is_prime[p]:
            start = p * p
            for x in range(start, b + 1, p):
                is_prime[x] = False
        p += 1

    pref = [0] * (b + 1)
    for i in range(1, b + 1):
        pref[i] = pref[i - 1] + (1 if is_prime[i] else 0)

    def count_primes(l, r):
        return pref[r] - pref[l - 1]

    def check(length):
        end_start = b - length + 1
        for start in range(a, end_start + 1):
            if count_primes(start, start + length - 1) < k:
                return False
        return True

    n = b - a + 1

    if not check(n):
        print(-1)
        return

    lo, hi = 1, n
    ans = n

    while lo <= hi:
        mid = (lo + hi) // 2

        if check(mid):
            ans = mid
            hi = mid - 1
        else:
            lo = mid + 1

    print(ans)

if __name__ == "__main__":
    solve()
```筛子计算可以出现在任何窗口中的所有数字的素数。 由于每个查询都要求间隔内的素数计数，因此随后会立即构建前缀和。 

这`check()`函数是二分查找使用的核心谓词。 它扫描候选长度的所有窗口，一旦发现一个坏窗口就拒绝该长度。 提前退出很重要，因为许多候选人很快就失败了。 

二分查找之前的存在性检查是必不可少的。 如果整个区间包含少于`k`素数，没有更小的窗口可能满足要求。 如果没有此步骤，即使不存在解，二分查找也会错误地返回某个长度。 

窗口计数使用：```
pref[r] - pref[l - 1]
```这就是为什么前缀数组的索引来自`0`。 这可以避免出现特殊情况`l = 1`。

 ## 边缘情况

 考虑：```
14 16 1
```该区间不包含素数。 最大可能的窗口是`[14,16]`，其素数计数为零。 初步的`check(n)`立即失败，因此算法打印`-1`。 二分查找永远不会开始，避免错误答案。 

考虑：```
2 2 1
```只有一扇窗户，`[2]`，包含一个素数。 存在性检查成功。 二分查找在范围内进行`[1,1]`并返回`1`。 这验证了该实现是否正确处理长度为 1 的间隔。 

考虑：```
2 5 2
```长度`2`失败，因为窗口`[4,5]`仅包含一个素数。 长度`3`失败是因为`[3,5]`仅包含一个素数。 长度`4`成功是因为唯一的窗口是`[2,5]`，包含三个素数。 该算法检查每个窗口，并且不会仅仅因为某些窗口工作而错误地接受长度。 

考虑：```
8 12 1
```唯一的素数是`11`。 对于长度`3`, 第一个窗口`[8,10]`素数为零，因此该候选者会立即被拒绝。 对于长度`4`，每个窗口包括`11`，因此候选人成功。 这证实了二分搜索所依赖的单调行为。
