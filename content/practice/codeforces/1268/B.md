 ## 解决方案
 ## 问题理解

 杨氏图可以看作是一个直方图，其柱高由非递增数组给出$a_1,a_2,\dots,a_n$。 直方图中的每个单位正方形最多可以被一个多米诺骨牌覆盖，并且每个多米诺骨牌恰好占据两个相邻的单元格，无论是垂直还是水平。 

任务是将尽可能多的多米诺骨牌放置在图中且不重叠。 

考虑形状的一种有用方法是将其视为一组网格单元。 柱子$i$包含细胞$(i,1),(i,2),\dots,(i,a_i)$。 由于高度不增加，因此每一行从左边缘开始形成一个连续的段。 

制约因素很大。 可能最多有$300\,000$列，每个高度也可以大到$300\,000$。 图的总面积大约可以达到$9 \times 10^{10}$，因此任何显式构造单元格或迭代整个图的算法都是不可能的。 甚至一个$O(n^2)$算法需要大约$9 \times 10^{10}$最坏情况下的操作。 我们需要一些线性或接近线性的东西$n$。 

一些边缘情况很容易被错误处理。 

考虑单列：```
1
3
```该图包含三个单元格。 只能放置一张垂直多米诺骨牌，所以答案是：```
1
```假设每对单元格始终可以匹配的解决方案将错误地返回$\lfloor 3/2 \rfloor = 1$这里很幸运，但推理并不能概括。 

考虑两列奇数高度：```
2
1 1
```答案是：```
1
```没有垂直放置，但一个水平多米诺骨牌覆盖了唯一的一行。 任何仅计算垂直对的方法都将返回 0。 

另一个有趣的案例是：```
2
3 3
```面积为 6，因此最多可能有 3 块多米诺骨牌。 事实上，所有 6 个单元格都可以平铺，给出答案 3。一种幼稚的局部策略，即到处贪婪地使用垂直多米诺骨牌，只会放置 2 个垂直多米诺骨牌，并留下两个不匹配的单元格。 

关键的困难是理解奇数高度的柱如何通过水平放置相互作用。 

## 方法

 暴力的观点是将每个单元格视为网格图的顶点并连接相邻的单元格。 问题变成了在该图中找到最大匹配，因为每个多米诺骨牌都覆盖了两个相邻的单元格。 

这个表述是正确的。 匹配完全对应于一组不重叠的多米诺骨牌。 不幸的是，该图每个单元包含一个顶点。 由于面积可以大到$9 \times 10^{10}$，构造图是完全不可行的。 

杨氏图的结构比任意网格提供更多的信息。 让我们首先在每列内放置尽可能多的垂直多米诺骨牌。 

一个柱子的高度$a_i$贡献$\lfloor a_i/2 \rfloor$垂直的多米诺骨牌。 如果$a_i$是均匀的，整个柱子都被覆盖。 如果$a_i$奇怪的是，只有一个细胞未被覆盖。 

唯一的问题是这些剩余的细胞会发生什么。 

对于奇数列，可以在奇数行或偶数行上选择未覆盖的单元格。 例如，高度为 5 的列可以垂直平铺，使第 1 行不被覆盖，或第 3 行不被覆盖，或第 5 行不被覆盖。 所有未覆盖的头寸具有相同的平价。 

现在看看两个相邻的奇数列。 如果它们剩下的单元格放在同一行，它们就会形成一个水平的多米诺骨牌。 由于该图是左对齐的，因此两列中存在的任何行也存在于它们之间的每一列中。 因此，连续的奇数列块可以一次将其剩余的两个配对。 

唯一重要的是平等。 

让$$S = \sum_i \left\lfloor \frac{a_i}{2} \right\rfloor$$是垂直多米诺骨牌的数量。 

每个奇数列贡献一个剩余单元格。 具有相同索引奇偶校验的连续奇数列可以将这些剩余部分配对。 简单的扫描显示，每隔两个奇数列就会创建一个额外的多米诺骨牌。 

结果的答案是$$S + \sum \left\lfloor \frac{k}{2} \right\rfloor$$在哪里$k$是最大连续段中奇数列的数量。 

更简单的实现是维护当前不匹配的奇数列的计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 细胞上的强力匹配 |$O(\text{area}^{1.5})$或者更糟|$O(\text{area})$| 太慢了 |
 | 最优奇偶贪婪|$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 初始化`answer = 0`。 
2. 初始化`pending = 0`。 

这里`pending`存储当前连续段中还有多少个奇数列尚未配对。 
3. 从左到右处理列。 
4.添加`a[i] // 2`到答案。 

这会计算可以放置在列内的所有垂直多米诺骨牌。 
5.如果`a[i]`为奇数，增量`pending`。 

奇数列贡献一个剩余单元格。 
6.如果`a[i]`是偶数，加`pending // 2`找到答案并重置`pending = 0`。 

偶数列会中断线段。 任何水平配对必须在当前最大奇数列块内完成。 
7.处理完所有列后，添加`pending // 2`到答案。 

这处理奇数列的最后一个块。 
8. 输出答案。 

### 为什么它有效

 在取出所有可能的垂直多米诺骨牌后，每个偶数高度的列都被完全覆盖，每个奇数高度的列恰好贡献一个剩余的单元格。 这些剩余的细胞是唯一可以参与额外多米诺骨牌的细胞。 

在奇数列的最大连续段内，每列的剩余单元可以放置在该段中所有列共享的行上。 然后，每对剩菜都可以连接成一个水平的多米诺骨牌。 一个段包含$k$奇数列精确产生$\lfloor k/2 \rfloor$额外的多米诺骨牌。 

不同的段由偶数列分隔。 这样的列不包含剩余单元格，因此水平多米诺骨牌不能跨越边界。 各部分的贡献是独立的。 

该算法对所有垂直多米诺骨牌进行计数，然后精确地添加从每个奇数段可获得的水平配对的最大数量，这是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    ans = 0
    pending = 0

    for x in a:
        ans += x // 2

        if x & 1:
            pending += 1
        else:
            ans += pending // 2
            pending = 0

    ans += pending // 2
    print(ans)

solve()
```第一个贡献来自垂直布局。 每个专栏独立贡献`x // 2`多米诺骨牌。 

变量`pending`跟踪奇数列的当前最大块的大小。 每当出现偶数列时，该块就会结束，因此我们立即添加`pending // 2`水平多米诺骨牌并重置计数器。 

循环后的最后添加是必要的，因为数组可能以奇数列结束。 忘记这一步是最常见的错误。 

答案可以大约为图表面积的一半，这可能超过 32 位整数限制。 Python 整数会自动处理这个问题。

 ## 边缘情况

 考虑尽可能最小的图：```
1
1
```该算法添加`1 // 2 = 0`垂直的多米诺骨牌。 该列是奇数，所以`pending = 1`。 扫描后添加`1 // 2 = 0`。 答案是 0，这是正确的，因为单个细胞不能形成多米诺骨牌。 

考虑一个奇数列：```
1
3
```该算法添加`3 // 2 = 1`垂直的多米诺骨牌。 剩下一个剩余的细胞，所以`pending = 1`。 最终的贡献是`1 // 2 = 0`。 答案变成1，这是最优的。 

考虑由偶数列分隔的两个奇数列：```
3
3 2 3
```处理中间列迫使算法关闭第一个奇数段。 第一个剩余单元格无法与最后一个单元格配对，因为偶数列不贡献剩余单元格。 计算公式为：```
vertical = 1 + 1 + 1 = 3
extra = 0 + 0 = 0
answer = 3
```这可以正确防止跨段边界的无效水平配对。 

考虑一个长奇数段：```
5
1 1 1 1 1
```不存在垂直的多米诺骨牌。 该段包含五个奇数列，因此算法添加`5 // 2 = 2`水平多米诺骨牌。 一个单元格仍未被覆盖。 答案是2，匹配最大可能的平铺。
