 ## 解决方案
 ## 问题理解

 我们被要求计算长度的序列$N$，其中每个元素都是从整数中选择的$1$到$M$，并且每对相邻元素必须是互质的，这意味着它们的最大公约数等于 1。序列中的每个位置仅取决于其直接前一个位置，因此该结构本质上是局部的，但序列可能非常长。 

约束中的关键张力来自于$N$一样大$10^8$， 尽管$M$最多 100。这立即排除了任何显式处理序列每个位置的方法。 任何迭代序列长度的解决方案都是不可能的，因为即使$O(N)$工作量已经太大了。 唯一可行的方向是压缩问题，以便减少对问题的依赖$N$变为对数或以其他方式消除，通常通过矩阵求幂或过渡系统上的快速求幂。 

一个微妙的点是，邻接条件仅取决于值，而不取决于它们的位置。 这意味着整个问题可以看作是在固定大小的图表上行走$M$，其中节点是整数$1 \dots M$，边连接互质对。 那么一个序列就是一段长度的游走$N$在此图中。 

值得隔离的边缘案例包括$N = 1$，其中任何值来自$1$到$M$是有效的，并且$M = 1$，其中唯一可能的序列是全 1。 另一个微妙的情况是，当许多数字不互质时，这可能会使图稀疏，但不会改变计数问题的指数增长性质。 

## 方法

 一种直接的方法是递归地构建所有有效序列。 我们自由选择第一个数字，然后为每个位置选择与前一个数字互质的任何数字。 这定义了大小图上的分支过程$M$。 正确性是立即的，因为它直接强制执行邻接条件。 

失败点是增长率。 即使每个节点平均只有几个邻居，序列的数量也会呈指数增长$N$。 为了$N = 10^8$，甚至无法枚举单个路径。 所以问题不在于正确性，而在于无法有效地表示重复结构。 

关键的观察是，这是一个大小固定的状态空间上的马尔可夫过程$M$。 我们只关心在之后每个值有多少种结束方式$k$步骤。 如果我们存储一个向量$dp[k][x]$表示长度序列的数量$k$以价值结束$x$，那么转换仅取决于互质性。 这变成了大小向量的线性变换$M$，可以编码为矩阵乘法。 

让$T[i][j] = 1$如果$\gcd(i, j) = 1$， 否则$0$。 然后：$$dp_{k+1}[j] = \sum_{i=1}^M dp_k[i] \cdot T[i][j]$$因此，$dp_k$随着固定值的重复乘法而演化$M \times M$矩阵。 我们需要$T^N$应用于初始向量。 自从$N$是巨大的，我们计算矩阵幂$O(M^3 \log N)$。 和$M \le 100$，这是可行的。 

我们还必须小心：$N$计算序列中元素的数量，以便发生转换$N-1$次。

 | --- | --- | --- | --- |
 | 蛮力 |$O(M^N)$|$O(N)$递归| 太慢了 |
 | 矩阵求幂|$O(M^3 \log N)$|$O(M^2)$| 已接受 |

 ## 算法演练

 1. 构造一组代表值的状态$1$到$M$。 每个状态对应于部分序列的最后一个元素。 
2. 构建转移矩阵$T$， 在哪里$T[i][j] = 1$如果$i$和$j$是互质的。 这编码了我们是否可以从价值转移$i$重视$j$一步之遥。 
3. 初始化基向量$v$在哪里$v[i] = 1$，因为任何单元素序列结束于$i$是有效的。 
4. 将序列扩展一个元素解释为将当前向量乘以$T$。 这将计数问题转换为重复的线性变换。 
5. 计算$T^{N-1}$对矩阵使用二进制求幂。 每一次乘法将两个转换系统组合成一个更长的系统。 
6. 将结果矩阵乘以基向量以获得长度序列的计数$N$以每个值结束。 
7. 对所得向量的所有条目求和以获得有效序列的总数。 

### 为什么它有效

 关键的不变量是处理后$k$步骤，状态的向量条目$i$等于长度有效序列的数量$k+1$结束于$i$。 每个扩展步骤都保留这个不变量，因为每个有效的长度序列$k+1$通过附加长度的有效前导来唯一形成$k$，并且转移矩阵精确地编码所有有效的邻接。 没有序列被重复计算或省略，因为每个转换都是独立考虑的，并且递归对于所有前驱都是详尽的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mul(a, b):
    n = len(a)
    m = len(b[0])
    p = len(b)
    res = [[0] * m for _ in range(n)]
    for i in range(n):
        ai = a[i]
        ri = res[i]
        for k in range(p):
            if ai[k]:
                aik = ai[k]
                bk = b[k]
                for j in range(m):
                    ri[j] = (ri[j] + aik * bk[j]) % MOD
    return res

def mat_pow(mat, exp):
    n = len(mat)
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        res[i][i] = 1

    while exp > 0:
        if exp & 1:
            res = mat_mul(res, mat)
        mat = mat_mul(mat, mat)
        exp >>= 1
    return res

def solve():
    N, M = map(int, input().split())

    if N == 1:
        print(M)
        return

    T = [[0] * M for _ in range(M)]
    for i in range(M):
        for j in range(M):
            if __import__("math").gcd(i + 1, j + 1) == 1:
                T[i][j] = 1

    P = mat_pow(T, N - 1)

    ans = 0
    for i in range(M):
        ans = (ans + sum(P[j][i] for j in range(M))) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案在值上构建完整的邻接矩阵$1 \dots M$，其中边表示 gcd 约束下的有效转换。 求幂使这个转换系统变得更加长度$N-1$，因为长度序列$N$有$N-1$过渡。 

乘法顺序很重要：矩阵表示从前一个状态（行）到下一个状态（列）的转换。 最终的总和汇总了所有可能的结束状态。 特殊情况$N=1$完全避免求幂，因为每个值都是有效的。

 ## 边缘情况

 对于$N = 1$，每个值来自$1$到$M$形成长度为一的有效序列。 该算法绕过矩阵求幂，直接输出$M$，它与定义匹配，因为没有第二个元素就不会应用邻接约束。 

为了$M = 1$，转移矩阵为$1 \times 1$具有单个条目$T[1][1] = 1$。 每个序列都完全由 1 组成，因此对于任何序列都只有一个有效序列$N$。 求幂步骤保留了单位矩阵的行为，并且无论长度如何，最终的总和都会产生 1。
