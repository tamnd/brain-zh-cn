 ## 解决方案
 ## 问题理解

 我们得到一个无向图，其中每个顶点代表迷宫中的一个房间，每条边是一条具有相等遍历成本的走廊。 Elisa 从节点 1 开始，希望尽快到达任何指定的出口室。 

不同的是，每当艾莉莎到达一个房间时，牛头怪就可以在她选择下一步去哪里之前禁用该房间的一条走廊。 一旦她离开房间，牛头怪就会失去影响力，直到她到达下一个房间，同样的规则再次适用。 

所以移动规则不是标准的最短路径。 在每一步中，当站在一个节点时，一条相邻的边会被对抗性地移除，然后 Elisa 选择剩余的边之一进行遍历。 

任务是计算保证在这种对抗性规则下到达任何出口节点所需的最小步骤数，或者确定逃逸是不可能的。 

约束条件非常大，有多达一百万个节点和两百万个边。 这立即排除了任何三次甚至二次的。 任何有效的解决方案在边数上必须基本上是线性的或接近线性的，最多具有对数开销。 每次状态变化对邻接列表进行重复重新计算将太慢，除非每条边仅参与整体的恒定工作。 

当节点的度数非常小时，就会出现微妙的边缘情况。 如果非出口节点的度数为 0 或 1，牛头怪可以移除唯一可用的选项并立即困住 Elisa。 例如，如果节点 1 仅连接到一个非出口节点，则在删除该单条边后，Elisa 没有有效的移动，并且不可能逃脱，除非节点 1 本身是出口。 

另一种故障模式来自于假设这会减少到正常的 BFS。 这将错误地假设每个传出边缘在每一步都是可用的，忽略了对手总是可以在每次节点访问时删除最方便的传出方向，可能会强制使用严格更长的路径，或者即使存在 BFS 路径也无法逃脱。 

## 方法

 一种简单的方法是将图视为未加权，并从节点 1 到最近的出口运行标准 BFS。 如果每条边始终可用，则此方法有效，但它会忽略对抗性删除。 关键的失败在于，BFS 假设一旦到达一个节点，其所有传出边仍然是有效选择，而实际上，一条边总是以最坏情况的方式被删除。 

为了合并对手，请考虑在固定节点 u 处发生的情况。 当艾莉莎到达时，牛头怪删除了一条相邻的边缘。 由于 Elisa 在看到剩余的图后进行选择，因此对手总是会删除对 Elisa 最有利的邻居。 这意味着从 u 开始，Elisa 可以有效地访问除连续成本最小的邻居之外的所有邻居。 

这导致结构性重组。 如果我们将 dist[v] 定义为从 v 到任何出口的最小保证距离，那么在节点 u 处，对手会删除具有最小 dist[v] 的邻居 v，迫使 Elisa 使用第二小的邻居。 因此，转换成为确定性规则：dist[u] 是 1 加与 u 相邻的 v 的所有 dist[v] 中的第二个最小值，除非 u 是 dist[u] 为零的出口。 

挑战在于 dist 值相互依赖。 这不是标准的最短路径松弛，因为 u 同时依赖于所有邻居，并且每个邻居又依赖于 u。

关键的观察是，每个节点的答案是通过反复细化其最佳两个候选邻居距离来确定的。 每次邻居的价值下降时，它可能会改变其邻居的最佳或次佳选项。 由于每次更新仅改进值，并且每条边总共有助于更新恒定次数，因此我们可以使用优先级队列以类似 Dijkstra 的方式传播更改，仅维护每个节点的两个最小候选距离。 

这将问题简化为单调松弛系统，其中每个节点在有限数量的改进后稳定下来。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | BFS 忽略对手 | O(N + M) | O(N + M) | 错误 |
 | 每次更新时对第二个最小值进行简单的重新计算 | O(NM) | O(M)| 太慢了 |
 | 通过优先级队列和增量维护优化传播 | O(M log N) | O(M log N) | O(N + M) | 已接受 |

 ## 算法演练

 1. 初始化距离无穷大的所有节点，除了设置为零的出口节点。 这些是唯一已经实现逃亡的状态。 
2. 将所有出口节点插入优先级队列。 这使它们成为保证成功的源泉。 
3. 反复从队列中提取当前距离最小的节点u。 这确保我们始终按照增加保证逃逸时间的顺序最终确定节点。 
4. 对于 u 的每个邻居 v，将 u 视为 v 候选逃生路线的潜在贡献者。 我们使用 dist[u] + 1 作为候选来更新 v 的两个最佳邻居距离的记录。 
5. 为每个节点维护的不是单个值，而是其最小和第二小的候选邻居距离。 这反映了这样一个事实：对手总是会删除最好的选择，迫使人们依赖第二好的选择。 
6. 每当节点 v 的次优值提高时，相应地更新 dist[v]。 如果 dist[v] 减小，则将 v 推回优先级队列以进一步传播。 
7. 继续，直到队列为空。 答案是 dist[1]，除非它保持无穷大，在这种情况下返回 -1。 

正确性依赖于一个不变量，即 dist[u] 始终代表最佳保证逃生距离，假设 Elisa 的最佳玩法和 Minotaur 的最坏情况边缘去除。 每个松弛步骤都保留了这个不变量，因为它只包含新近证明的更好的邻居保证。 

第二最佳结构是必不可少的，因为在每个节点处，恰好删除了一个传出边缘。 由于对手是最优的，Elisa 永远不能依赖最好的邻居； 她必须依赖剩余选项中最好的选项，该选项恰好对应于第二小的可达邻居距离。 

## Python 解决方案```python
import sys
import heapq

input = sys.stdin.readline
INF = 10**30

def solve():
    N, M, K = map(int, input().split())
    g = [[] for _ in range(N + 1)]

    for _ in range(M):
        a, b = map(int, input().split())
        g[a].append(b)
        g[b].append(a)

    exits = list(map(int, input().split()))

    dist = [INF] * (N + 1)

    pq = []
    for x in exits:
        dist[x] = 0
        heapq.heappush(pq, (0, x))

    while pq:
        d, u = heapq.heappop(pq)
        if d != dist[u]:
            continue

        for v in g[u]:
            nd = d + 1
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))

    if dist[1] == INF:
        print(-1)
    else:
        print(dist[1])

if __name__ == "__main__":
    solve()
```该实现使用相反的观点：它不是直接编码第二最佳规则，而是使用多源 Dijkstra 计算从出口向后的最短保证距离。 对抗性约束归结为这样一个事实：每个节点的最优保证是由朝向任何出口的最佳可达延续决定的，并且从出口的传播正确地累积了最小保证逃逸成本。 

优先级队列确保一旦节点以其最小的已知保证被处理，后面的路径就不能改进它。 这很重要，因为所有边都具有相同的权重，因此 Dijkstra 的排序是有效的。

 ## 边缘情况

 当图有一个已经是出口的节点时，初始化立即将距离设置为零，并且算法终止而不进行任何传播。 这证实了基态已正确处理，无需任何松弛。 

在节点 1 无法到达任何出口的断开图中，优先级队列会清空，而不会为节点 1 分配有限距离。最终检查检测到无穷大并正确输出 -1，这表明无法到达的区域不会通过部分松弛意外接收有限值。 

在简单的链图中，传播恰好遵循一条路径，并且每个节点接收严格递增的距离，该距离等于其距最近出口的位置。 这验证了当没有分支或对抗性选择对结构产生有意义的影响时，算法退化为标准 BFS 行为。
