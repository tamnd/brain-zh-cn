 ## 解决方案
 ## 问题理解

 我们得到一个矩形网格，其中一些单元格包含伪影。 每个工件都位于特定的坐标处，并且我们只能使用向右或向下的步骤从左上角移动到右下角。 因此，每个完整的行程都是一条单调路径，行或列索引永远不会减少。 

每次旅行都从左上角开始，到右下角结束，在这次旅行中我们可能会收集沿途遇到的任何文物。 关键的限制是我们可以重复旅行，目标是选择一组这样的单调路径，以便每个工件至少位于其中一个路径上。 任务是尽量减少出行次数。 

从结构的角度来看，每个工件都是二维网格中的一个点，每个有效行程定义了一个网格单元链，其中两个坐标都是非递减的。 如果在同一行程中，位置 A 的工件可以在位置 B 的另一个工件之前被访问，那么 A 一定位于 B 的弱左上方，这意味着它的行和列都不大。 

网格大小最多为 50 x 50，因此最多有 2500 个单元和最多 2500 个工件。 它足够小，使得二次或近二次算法是可行的，但又足够大，以至于枚举所有可能的单调路径是完全不可能的，因为它们的数量随着网格大小呈指数增长。 

一个天真的想法是考虑从左上角到右下角的每条路径，并将工件贪婪地分配给路径，但此类路径的数量组合起来很大。 即使对路径子集进行动态编程也是不可行的，因为状态空间的工件数量呈指数级增长。 

一个更微妙的问题源于按顺序“交叉”的工件之间的交互。 考虑 (1, 5) 处的两个工件 A 和 (5, 1) 处的 B。 没有一条单调路径可以同时访问 A 和 B，因为任何到达 A 的路径都必须停留在第 1 行上方直到第 5 列，而到达 B 则需要在第 1 列之前到达第 5 行下方，这在单调移动下是不可能的。 尝试以任意顺序扩展路径的天真贪婪方法在这种交叉配置上将失败。 

## 方法

 蛮力的观点是将每次旅行视为一条单调路径，并尝试将工件逐一分配给路径。 人们可以想象重复构建一条路径，收集尽可能多的剩余工件，删除它们，然后重复。 从每个解决方案都是单调链的划分的意义上来说，这是正确的，但困难在于每一步的“最佳可能路径”在全局上都没有明确定义。 局部最优路径可以迫使未来的工件进入许多额外的路径，并且探索路径构建的所有可能性会导致指数分支。 

关键的结构转变是忘记实际的几何路径，而只考虑工件的相对顺序。 当一个工件的行不大于且其列不大于时，在一次有效行程中，一个工件可以恰好出现在另一个工件之前。 这定义了工件的偏序。 

这样，每次行程就只是此偏序中的一条链，问题就变成：将所有点划分为最少数量的链。 这是一个经典的组合结果。 在任何有限偏序中，覆盖所有元素所需的最小链数等于最大反链的大小。 在这里，反链是一组工件，其中没有两个工件具有可比性，这意味着没有一个工件同时位于另一个工件的左上方。 

在这个网格偏序中，反链对应于一组点，其中增加的行迫使减少的列。 该结构使我们能够将问题简化为在特定排序规则下找到最长序列，这可以使用最长递增子序列样式动态规划来计算。

我们按行按升序对工件进行排序。 当行相等时，我们按列按降序排序，以便同一行中的工件不会错误地形成递增链。 排序后，我们计算列索引上的最长递减子序列。 这个长度就是答案。

 | --- | --- | --- | --- |
 | 枚举路径并贪婪地赋值 | 指数| 指数| 太慢了 |

 ## 算法演练

 令工件集为所有值为 1 的网格单元，并令 k 为它们的数量。 

1. 将所有工件坐标提取为对 (r, c)。 这将网格简化为仅相对顺序重要的点集。 
2. 通过增加行对这些点进行排序。 如果两个点共享同一行，则按列递减排序。 这种排序确保任何有效的链都必须遵守我们处理的顺序，并防止同一行内的无效合并。 
3. 仅使用此排序列表中的列值构建序列。 
4. 计算该列序列上最长严格递减子序列的长度。 由于 k ≤ 2500 很小，因此可以使用二次动态规划方法来完成此操作。 
5. 输出该子序列的长度，它表示所需的单调路径的最小数量。 

子序列减少而不是增加的原因直接来自于几何形状：沿着单个有效路径，行和列都必须增加。 按行排序后，任何剩余的自由度都在列中，当后面的点具有更大的列时，就会发生冲突。 

### 为什么它有效

 排序顺序将 2D 支配关系转化为 1D 约束问题。 任何有效的链都对应于一个序列，其中行通过构造而增加，并且列也必须沿着路径不减少。 因此，当我们反向观察反链时，我们正在寻找增加行迫使减少列的序列。 

关键的不变量是点集的每个链式分解完全对应于将排序序列划分为递减子序列。 这种子序列的最小数量等于对偶阶下最长递增结构的长度，这正是最长递减子序列在这里计算的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    pts = []
    for i in range(n):
        row = list(map(int, input().split()))
        for j, v in enumerate(row):
            if v == 1:
                pts.append((i, j))

    if not pts:
        print(0)
        return

    pts.sort(key=lambda x: (x[0], -x[1]))
    a = [c for r, c in pts]
    k = len(a)

    dp = [1] * k
    ans = 1

    for i in range(k):
        for j in range(i):
            if a[j] > a[i]:
                dp[i] = max(dp[i], dp[j] + 1)
        ans = max(ans, dp[i])

    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先将网格压缩为工件坐标列表。 按行排序然后反向列排序会强制执行与有效单调移动约束一致的一致顺序。 

动态编程步骤计算列值上的最长递减子序列。 条件`a[j] > a[i]`强制严格减少，这对应于反链结构。 答案是最大 dp 值，代表相互冲突的工件的最大集合，通过对偶性给出所需路径的最小数量。 

一个常见的实现陷阱是忘记对相等行的列进行反向排序。 如果没有它，同一行中的工件可能会被错误地视为递增链，即使它们不应该如此。

 带有部分嵌套的稍大的网格。 

| 步骤| 处理点| 列顺序| DP 状态 (LDS) | 最佳 |

这些痕迹证实该算法不是直接跟踪几何图形，而是将其正确编码为一维排序问题。

 ## 边缘情况

 一个关键的边缘情况是多个工件位于同一行中。 如果不在相同的行中按降序对列进行排序，算法将错误地将从左到右的伪影视为在序列形成中兼容。 例如，在第 1、2 和 3 列具有工件的单行中，仅按行进行简单排序将允许它们形成递增链，建议一次旅行，即使正确答案是 3，因为没有单调路径可以重新访问递减的列位置，同时保持在抽象的相同行排序约束中。 

应用正确的平局打破规则后，这些点按 (row, col desc) 排序，因此它们的列序列按排序顺序严格递减，并且算法正确地生成三个单独的链。
