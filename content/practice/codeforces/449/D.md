 ## 解决方案
 ## 问题理解

 我们得到一个数组`n`非负整数。 组是数组索引的任何非空子集。 对于选定的组，我们对这些索引处的所有值进行按位与。 

任务是计算有多少个非空组按位与等于`0`。 答案必须以模数形式报告`1000000007`。 

关键细节是我们选择的是指数，而不是值。 如果相同的数字出现多次，则不同的索引选择将被视为不同的组。 

这些约束完全决定了我们需要什么样的解决方案。 数组长度可以大到`10^6`，这会立即排除任何直接检查子集的内容。 有`2^n - 1`非空群，数量庞大。 

更有趣的约束是值范围。 每一个`a[i]`至多是`10^6`，它适合 20 位，因为：$$2^{20} = 1048576$$这意味着每个数字都可以被视为最多 20 位的掩码。 大小的状态空间`2^20 ≈ 10^6`很大但易于管理。 每当问题变得巨大时`n`但位宽较小，这通常是一个信号，表明我们应该在掩码空间而不是子集空间中工作。 

一些边缘情况很容易被错误处理。 

考虑：```
1
0
```唯一的非空组是`{0}`其 AND 等于`0`，所以答案是`1`。 忘记在正确时刻排除空子集的解决方案可能会产生错误的计数。 

考虑：```
2
1 1
```可能的组是`{1}`,`{1}`， 和`{1,1}`。 每个组的 AND 都等于`1`， 绝不`0`，所以答案是`0`。 对掩码而不是索引子集进行计数可能会意外合并重复值以及计数不足或计数过多。 

考虑：```
3
0 7 7
```任何包含零元素的群的 AND 等于`0`。 有四个这样的组：```
{0}
{0,7(first)}
{0,7(second)}
{0,7(first),7(second)}
```正确答案是`4`。 这说明了为什么索引多重性很重要。 

另一种微妙的情况是，没有单独的数字为零，但某些组合产生零：```
2
1 2
```单例组具有 AND 值`1`和`2`，但这对有：```
1 & 2 = 0
```答案是`1`。 仅仅关注个人价值观是不够的。 

## 方法

 最直接的解决方案是枚举索引的每个非空子集，计算所有选定数字的 AND，并计算有多少个结果为零。 

这是正确的，因为它准确地检查有效组的定义。 不幸的是，有`2^n - 1`非空组。 即使是为了`n = 50`，这已经是不可能的了。 和`n = 10^6`，该方法是完全不可能的。 

为了找到更好的解决方案，我们需要考虑子集的 AND 包含某些位意味着什么。 

假设我们修了一个面具`m`。 让我们计算一下有多少个数组元素包含所有位`m`。 换句话说：```
(a[i] & m) = m
```如果子集的 AND 包含所有位`m`，那么该子集中的每个元素都必须包含`m`。 

这将问题转化为对从掩码超集的数字中提取的子集进行计数。 

让：```
cnt[m]
```是其掩码是以下超集的数组元素的数量`m`。 

那么 AND 包含的非空子集的数量`m`等于：```
2^(cnt[m]) - 1
```因为这些的任何非空选择`cnt[m]`elements 保留了每一点`m`。 

现在我们有一个典型的包含-排除情况。 

定义：```
F(m) = number of non-empty subsets whose AND contains m
```我们想要：```
G(0) = number of non-empty subsets whose AND is exactly 0
```在子集格上使用莫比乌斯反演：```
G(0) = Σ (-1)^(popcount(m)) * F(m)
```其中总和涵盖所有掩码。 

剩下的挑战是计算`cnt[m]`对于每一个面具。 这正是 SOS DP（DP 子集求和）问题。 从精确值的频率计数开始，我们为每个掩码计算其值是该掩码的超集的数组元素的数量。 

整个解决方案由以下各项组成：

 1、口罩使用次数统计。 
2. SOS DP 获取超集计数。 
3.所有掩模的包含-排除。

 ## 算法演练

 ### 1. 计算每个精确掩码的出现次数

 创建一个数组`freq`尺寸的`2^20`。 

对于每个输入数字`x`，增量：```
freq[x]
```这记录了每个精确掩码出现的次数。 

### 2. 使用 SOS DP 构建超集计数

 创建：```
dp = freq
```最初`dp[m]`计数元素等于`m`。 

我们想要：```
dp[m] = number of elements whose masks are supersets of m
```对于每一位`0`到`19`，对于每个掩码：

 如果掩码中未设置该位，则添加该位打开时掩码的计数。 

正式：```
dp[mask] += dp[mask | (1 << bit)]
```20关结束后，`dp[m]`成为满足以下条件的数组元素的数量：```
(value & m) = m
```### 3. 预先计算 2 的幂

 对于每一个`i`从`0`到`n`计算：```
pow2[i] = 2^i mod MOD
```我们经常需要：```
2^(dp[m]) - 1
```这是由这些元素形成的非空子集的数量。 

### 4. 应用包含-排除

 对于每个面具：```
ways = 2^(dp[mask]) - 1
```这对非空子集进行计数，其 AND 包含以下所有位`mask`。 

如果掩码有偶数个设置位，则添加`ways`。 

如果掩码具有奇数个设置位，则减去`ways`。 

数学上：```
answer += (-1)^(popcount(mask)) * ways
```所有运算均按模进行`1000000007`。 

### 5. 标准化结果

 在计算过程中，包含-排除之和可能会变为负值。 

返回：```
(answer % MOD + MOD) % MOD
```### 为什么它有效

 SOS DP 后，`dp[m]`精确计算其掩码包含每个位的数组元素`m`。 从这些元素中选择的任何非空子集都有一个 AND，其中也包含`m`, 给予`2^(dp[m]) - 1`子集。 

AND 等于某个掩码的每个子集`A`为每一个做出贡献`F(m)`在哪里`m`是一个子掩码`A`。 布尔格上的包含-排除消除了过度计数并隔离了 AND 恰好为零的子集。 这正是子集掩码上的莫比乌斯反演公式，它保证最终的和等于 AND 为的组的数量`0`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1000000007
BITS = 20
MAX_MASK = 1 << BITS

def solve():
    n = int(input())
    arr = list(map(int, input().split()))

    freq = [0] * MAX_MASK
    for x in arr:
        freq[x] += 1

    dp = freq[:]

    for bit in range(BITS):
        for mask in range(MAX_MASK):
            if (mask & (1 << bit)) == 0:
                dp[mask] += dp[mask | (1 << bit)]

    pow2 = [1] * (n + 1)
    for i in range(1, n + 1):
        pow2[i] = (pow2[i - 1] * 2) % MOD

    ans = 0

    for mask in range(MAX_MASK):
        ways = pow2[dp[mask]] - 1

        if mask.bit_count() & 1:
            ans -= ways
        else:
            ans += ways

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```第一部分构建精确掩码的频率表。 由于值永远不会超过`10^6`，分配大小的数组`2^20`是可行的。 

SOS DP 将精确频率转换为超集频率。 当处理一位时，每个掩码都会收到来自包含一个额外所需位的掩码的贡献。 处理完所有 20 个维度后，每个状态都包含作为该掩码超集的数组元素的计数。 

功率表允许恒定时间评估`2^k`。 自从`k`可以大到`n`，预计算一次比重复求幂快得多。 

最后一个循环执行莫比乌斯反演。 偶校验掩码有正向贡献，奇奇偶校验掩码有负向贡献。 所得总和正是 AND 等于 0 的非空组的计数。 

一个常见的实施错误是尝试对精确频率而不是超集计数使用包含-排除。 反演公式仅在计算 SOS DP 值后才起作用。

 ## 边缘情况

 ### 一个零

 输入：```
1
0
```SOS DP 给出：```
dp[0] = 1
```所有其他掩码的计数为零。 包含-排除评估为：```
2^1 - 1 = 1
```算法输出`1`，对应于唯一可能的组。 

### 重复值

 输入：```
2
1 1
```共有三个非空​​组：```
{first}
{second}
{first, second}
```每个组的 AND 都等于`1`。 频率表存储多重性，因此 SOS DP 分别对两次出现的情况进行计数。 包含-排除最终产生`0`，这是正确的。 

### 仅通过组合元素产生零

 输入：```
2
1 2
```两个单例组的 AND 都不等于 0：```
1
2
```这对给出：```
1 & 2 = 0
```该算法通过超集频率对子集进行计数，而不是检查单个值。 包含-排除恰好隔离了一个 AND 等于 0 的子集，从而产生正确的答案`1`。 

### 所有元素均为零

 输入：```
3
0 0 0
```每个非空子集的 AND 都等于 0。 有：```
2^3 - 1 = 7
```这样的子集。 由于每个值都已经为零，`dp[0] = 3`所有其他掩码的计数为零。 包含-排除总和计算为`7`，完全匹配组合计数。
