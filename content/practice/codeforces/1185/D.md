 ## 问题理解

 给定一个可能未排序的整数序列，并要求我们识别一个元素，删除该元素可以使剩余的数字形成算术级数。 算术级数是连续项之间的差值恒定的数列。 输入大小可以达到 200,000 个元素，值范围从负到正 10^9，因此任何迭代所有可能的子数组或尝试每个排列的解决方案都会太慢。 我们需要一种在大致线性或线性时间（理想情况下为 O(n log n)）运行的算法。 

微妙之处来自几个不明显的案例。 首先，序列可能已经是算术级数，在这种情况下，删除第一个或最后一个元素是有效的。 其次，异常值可能出现在开始、结束或中间的某个地方，因此仅查看前几个差异的简单检查可能会错过它。 第三，所有元素都可以相等，这是一个有效的级数； 删除任何元素都会保留它。 最后，如果序列包含负数或大数，我们必须避免整数溢出并依赖精确差异。 

粗心的方法可能只是简单地检查排序元素之间的差异并删除发现的第一个不匹配，但如果异常值位于其他常规进展的中间，那么这种方法就会失败。 例如，在`[2, 4, 6, 9, 8]`，去除`9`给出`[2, 4, 6, 8]`，但删除第一个不匹配`6`错误会失败。 

## 方法

 暴力方法是尝试删除每个元素并检查剩余序列是否可以形成算术级数。 对于每次删除，对剩余数组进行排序并检查连续差异需要 O(n log n)，执行此操作 n 次会导致 O(n^2 log n) 复杂度。 当 n 达到 2·10^5 时，这太慢了。 

关键的见解是，有效的算术级数完全由其前两个元素决定。 因此，如果最多有一个额外元素，则该数列只能在某一处不能成为算术级数。 这表明我们只需要考虑删除排序数组中的前两个元素或最后一个元素。 通过对数组进行一次排序并检查差异，我们可以确定异常值是在开头、结尾还是中间的某个位置。 一旦识别出潜在的异常值，我们就可以通过扫描一次差异来进行验证，从而使整个过程保持 O(n log n) 。 

这将问题从对所有删除的非结构化检查转变为由算术级数结构引导的一小组候选删除。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 log n) | O(n^2 log n) | O(n) | 太慢了 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取序列并存储每个元素及其原始索引。 这使我们能够稍后报告原始位置。 
2. 按值对数组进行排序。 为了轻松计算连续差异并识别潜在的异常值，排序是必要的。 
3. 计算连续排序元素之间的差异。 如果不存在异常值，则有效的公差应该在整个序列中保持一致。 
4. 考虑三个候选删除：第一个元素、第二个元素和最后一个元素。 删除其中一个通常可以解决单个不匹配问题，因为任何单个异常值都必须出现在开头、结尾附近，或者作为与常规差异的第一个偏差。 
5. 对于每个候选删除，检查剩余的差异是否都相等。 如果是，则返回被删除元素的原始索引。 
6. 如果所有候选删除均不起作用，则异常值一定位于中间。 扫描排序后的数组，找到第一个偏离预期公差的差异。 删除导致不匹配的元素并验证其余元素会产生有效的级数即可给出答案。 
7. 如果没有一次删除产生有效的算术级数，则返回 -1。 

该算法之所以有效，是因为算术级数完全由其前两个元素和公差决定。 序列中只有一个额外元素，最多会偏离一个差异。 通过检查边缘的第一个差异和候选项，我们确保涵盖所有情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
arr = list(map(int, input().split()))
indexed_arr = [(val, i + 1) for i, val in enumerate(arr)]
indexed_arr.sort()

def check_remove(candidate):
    temp = [x for x in indexed_arr if x != candidate]
    if len(temp) <= 1:
        return True
    diff = temp[1][0] - temp[0][0]
    for i in range(1, len(temp)):
        if temp[i][0] - temp[i-1][0] != diff:
            return False
    return True

# Candidates: first, second, last
for candidate in [indexed_arr[0], indexed_arr[1], indexed_arr[-1]]:
    if check_remove(candidate):
        print(candidate[1])
        sys.exit(0)

# Check internal outlier
diff = indexed_arr[1][0] - indexed_arr[0][0]
for i in range(1, n):
    if indexed_arr[i][0] - indexed_arr[i-1][0] != diff:
        print(indexed_arr[i][1])
        sys.exit(0)

print(-1)
```我们将每个值与其原始索引一起存储，这样我们就可以返回被删除元素的从 1 开始的位置。 排序可以轻松计算差异。`check_remove`通过扫描连续差异来验证候选者。 首先检查候选边缘，因为它们通常可以解决简单的异常情况。 最后的循环确保我们捕获中间的异常值。 我们避免就地修改数组以保留索引。
