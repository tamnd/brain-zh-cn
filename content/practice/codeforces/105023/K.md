 ## 解决方案
 ## 问题理解

 我们得到了大小的排列$N$，然后是一长串$Q$运营。 每个操作选择一个段$[l, r]$并对该段执行左旋转，即位置处的元素$l$移动到位置$r$，并且之间的所有内容都左移一步。 

如果我们应用所有$Q$按顺序操作，我们得到最终的索引排列。 不同之处在于操作序列是循环处理的：我们可以选择一个起点$x$，应用操作$x$到$Q-1$，然后继续从$0$到$x-1$。 操作列表的每次这样的旋转都会产生可能不同的最终排列。 

对于每个旋转序列，我们计算需要多少次交换才能将结果排列恢复到排序顺序。 由于数组包含排列$1$到$N$，排序的最小交换次数等于$N$减去其排列分解的循环数。 任务是将这个值加到所有的值上$Q$操作列表的循环移位。 

约束表明$N \le 1000$，这允许$O(N^2)$或者$O(NQ)$每个单一配置的风格处理。 然而，$Q \le 10^5$，因此任何在每个班次重新计算完整排列的方法都会立即变得太慢。 每次旋转的简单模拟需要$O(Q \cdot N \cdot Q)$或者充其量$O(Q^2 N)$，这远远超出了限制。 

一个很容易打破天真的推理的微妙问题是假设每次循环移位都会产生根本不同的排列结构。 例如，根据操作序列的开始位置，人们可能会期望不同的循环计数。 这种直觉在这里是错误的，因为排列乘积的所有循环移位都是通过共轭相关的，这保留了循环结构。 

小边缘情况直觉检查会有所帮助：如果所有操作都是不相交段上的简单旋转，则最终排列仍然是排列，并且移动操作顺序不会改变底层循环类型，只会改变中间步骤的标签。 

## 方法

 一种直接的方法是模拟每个$Q$操作列表的轮换。 对于每个起始索引$x$，我们通过应用所有来重建排列$Q$按该轮换顺序进行操作，然后计算周期。 构建排列需要$O(NQ)$，并为所有人做这件事$Q$轮班给出$O(NQ^2)$，当$Q = 10^5$。 

关键的观察是操作序列形成对称群中的乘积。 让$A$是通过按给定顺序应用所有操作获得的排列，并让$P_x$是仅应用第一个形成的排列$x$运营。 操作序列的循环移位恰好对应于应用$P_x^{-1}$， 然后$A$， 然后$P_x$。 换句话说，每个移位结果都是以下的共轭$A$。 

置换群中的共轭保留了循环结构。 这意味着每个旋转序列都会产生具有完全相同的循环分解的排列，因此具有相同的循环数和相同的最小交换计数。 

所以不用重新计算$Q$排列，我们只需要计算一次应用所有运算的结果，计算其周期，然后将答案乘以$Q$。

 ## 算法演练

 ### 1. 将所有操作应用一次以获得最终排列

 我们从恒等排列开始，并按顺序应用每个旋转操作。 每个操作旋转一个段$[l, r]$剩下一步，我们通过暂时存储第一个元素并移动其余元素来实现。 

这会产生一个最终排列$A$，它代表所有操作的完整组成。 

### 2. 显式构建排列映射

 模拟之后，我们将结果数组解释为从位置的映射$i$重视$A[i]$。 这就是我们将分析其循环结构的排列。 

### 3. 计算排列中的周期

 我们遍历所有索引$1$到$N$，对于每个未访问的索引，我们遵循排列映射，直到返回到开头。 每次遍历形成一个循环。 

对排列进行排序所需的交换次数为$N - \text{cycles}(A)$。 

### 4. 乘以旋转次数

 由于操作序列的每次循环移位都会产生一个排列，该排列是以下项的共轭$A$，它们都具有相同的循环结构。 因此每一个$f(x)$相等，最终答案为：$$Q \cdot (N - \text{cycles}(A))$$### 为什么它有效

 每个操作都是索引的排列，整个过程是排列的产物。 群积中因子的循环移位将结果转换为共轭形式$P^{-1} A P$。 共轭不会改变循环长度或循环数量，只会重新标记循环内的元素。 由于最小交换仅取决于循环结构，因此操作序列的每次循环都会产生相同的交换计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def apply_ops(n, ops):
    arr = list(range(n))
    for l, r in ops:
        l -= 1
        r -= 1
        if l >= r:
            continue
        tmp = arr[l]
        for i in range(l, r):
            arr[i] = arr[i + 1]
        arr[r] = tmp
    return arr

def count_cycles(p):
    n = len(p)
    vis = [False] * n
    cycles = 0

    for i in range(n):
        if not vis[i]:
            cycles += 1
            cur = i
            while not vis[cur]:
                vis[cur] = True
                cur = p[cur] - 1
    return cycles

def solve():
    n, q = map(int, input().split())
    ops = [tuple(map(int, input().split())) for _ in range(q)]

    final_perm = apply_ops(n, ops)
    cycles = count_cycles(final_perm)

    ans = q * (n - cycles)
    print(ans)

if __name__ == "__main__":
    solve()
```模拟步骤通过应用每次旋转直接构造组合排列。 然后，循环计数器以标准方式解释排列，遵循链接直到返回起始索引。 

乘以$Q$是安全的，因为共轭参数保证所有循环移位准确地保留循环结构，因此不需要每次移位重新计算。

 ## 边缘情况

 一种常见的边缘情况是操作似乎严重依赖于顺序，这表明不同的起始旋转应该会改变排列复杂性。 例如，对于操作重叠的小排列，人们可能期望不同班次的周期计数不同。 共轭性质完全消除了这种依赖性。 

另一种边缘情况是当段旋转不会有意义地更改数组时，例如$[l, r]$其中该段已经是循环对称的。 这些操作仍然对排列产品有贡献，但它们不会影响轮班之间的周期盘点一致性。 

在所有情况下，最终的排列结构单独决定答案，并且每次循环移位都准确地保留该结构。
