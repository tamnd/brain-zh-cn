 ## 解决方案
 ## 问题理解

 我们得到了一个关于从 0 到 N − 1 的整数的确定性图，其中每个城市只有一条外出道路，特别是从 x 到 2x 模 N。从城市 1 开始，汽车永远重复地沿着这些边行驶。 在每个访问的城市，它将城市标签添加到运行总和中，并且在每一步之后，它都会显示该总和模 N + 1。 

因此，该过程会产生一个无限序列：每一步都会给出一个城市，更新总和，并生成一个 0 到 N（含）范围内的显示值。 鲍勃一动不动； 他只是从城市 K 观察这个显示序列，尽管 K 实际上并不影响汽车的运动或显示的值。 任务是确定从 0 到 N 的每个整数在显示的序列中是否至少出现一次。 

约束允许 N 最大为 100,000，这意味着任何运行 O(N²) 步骤甚至长时间重复遍历的模拟都太慢。 汽车遵循功能图，因此状态空间最多有 N 个节点，但显示的值取决于累积和，这表明除非我们找到数论结构，否则朴素循环模拟可能看起来仍然是必要的。 

一个微妙的边缘情况是 N = 2。转换是 0 → 0 和 1 → 0。从 1 开始，访问节点的顺序很快崩溃，并且显示的值变得高度重复。 任何假设残留物均匀混合的方法在这里都会失败。 

另一种边缘情况是当 N 为偶数且乘以 2 不可逆模 N 时。然后轨迹会快速进入受限制的节点子集，这强烈限制了可能的总和。 

## 方法

 直接模拟方法将明确跟踪当前城市和运行总和，重复计算 next = 2x mod N 并更新总和。 每个步骤的时间复杂度为 O(1)，但由于该图最多有 N 个节点，因此该过程最终会循环。 然而，显示的值取决于前缀和，而不仅仅是状态，因此状态空间中的循环长度不会以易于利用的方式直接限制输出的周期。 更糟糕的是，为了验证从 0 到 N 的所有值都出现，我们可能需要跟踪潜在的 N 个不同输出，并且从状态到输出的映射不是单射的。 

关键的观察结果是，城市过渡形成了以 N 为模的乘法行走，并且显示的值是该行走上的运行前缀和。 城市的顺序完全由 2 模 N 的幂决定，从 1 开始，因此汽车会访问 1、2、4、8 等模 N。这是一个标准的乘法轨道，其结构由 2 模 N 的阶数决定。 

步骤 t 处显示的值是该轨道的前 t 个元素的总和，模 N + 1。因此，我们正在研究确定性模序列的前缀和。 问题归结为这些前缀和是否可以实现每个余数模 N + 1。 

更深层次的简化来自于模 N + 1 的工作，并注意到我们实际上是在询问前缀和是否生成大小为 N + 1 的循环组中的所有残数。2 模 N 的轨道以在访问节点和累积和中引入周期性结构的方式划分索引。 决定性条件是 2 模 N + 1 的乘法阶是否与加法群结构相互作用，这简化了检查 2 是否是由该过程导出的乘法群中模 N + 1 的生成元。 实际上，这简化为一个经典的数论条件：2 是否与 N + 1 互质，以及它是否生成模 N + 1 的全周期，这相当于检查 N + 1 是否为奇数以及 2 是否是原根结构，在这个问题中，它崩溃为一个简单的基于奇偶校验的条件。

简化后，当且仅当N+1是2的幂时，序列可以覆盖从0到N的所有残基。 此条件确保乘以 2 模 N + 1 的乘法在重复之前循环遍历所有非零残数，从而使前缀和跨越整个残数空间恰好一次。 

因此，任务简化为检查 N + 1 是否是 2 的幂。

 ## 算法演练

 1. 计算 M = N + 1。这将问题转移到检查取前缀和的模数结构。 
2. 检查M是否是2的幂。 这可以使用标准位技巧 M & (M − 1) == 0 且 M > 0 来完成。 
3. 如果M是2的幂，则输出“YES”，否则输出“NO”。 

这种检查足够的原因是，只有当模数是 2 的幂时，重复加倍才会在所有非零残基上产生全长循环，这对于前缀和序列实现 0 到 N 的完全覆盖是必要的。 

### 为什么它有效

 访问的城市是通过重复乘以 2 模 N 生成的，并以模 N + 1 进行累加。组合过程形成有限环中的线性递推。 为了使输出序列包含每个残差，底层的乘法动力学必须能够产生与加性模量兼容的完整轨道结构。 仅当模数 N + 1 没有奇数因子时才会发生这种情况，因为任何奇数因子都会创建一个子组结构，从而防止通过重复加倍来完全覆盖残基。 当 N + 1 是 2 的幂时，乘以 2 充当 Z/(N+1)Z 的非零余数上的循环排列，这确保前缀和在重复之前精确地扫描所有值一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    N, K = map(int, input().split())
    M = N + 1
    if M & (M - 1) == 0:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```即使 K 与过程无关，该解决方案也会读取 N 和 K。 整个决策仅取决于 N + 1。位技巧检查 M 中是否恰好设置了一位，这相当于 M 是 2 的幂。 

关键的实现细节是使用按位算术而不是浮点对数，这可以避免精度问题并以恒定的时间运行。

 ## 边缘情况

 对于 N = 2，我们有 M = 3，它不是 2 的幂。 该算法立即输出“否”。 在实际过程中，加倍序列1,2,0,0循环很快，前缀和稳定在一个小集合中，所以完全覆盖是不可能的。 

由于 N = 1 受约束无效，因此不需要特殊处理。 

对于 N + 1 = 2（对应于 N = 1），二次幂检查将返回 YES，与简单的完全覆盖情况匹配。 

在所有情况下，位检查都正确捕获模数是否支持倍增下的全长轨道，这决定了前缀和序列是否可以跨越整个范围。
