 ## 解决方案
 ## 问题理解

 我们有一个系统$n$位置，每个位置最初容纳一名学生。 初始排列未知，用排列表示$b$。 随着时间的推移，学生们按照固定的排列反复移动$p$: 坐在位置上的学生$i$移动到位置$p_i$一步之遥。 此转换会多次应用。 

所有动作结束后，我们观察最终的安排$a$，这也是一个排列。 任务是重建一个可能的初始排列$b$这样应用排列$p$反复导致$a$经过一定数量的整轮之后，在所有有效的初始排列中，我们必须输出字典顺序最小的排列。 

关键的困难在于该过程在结构上是完全可逆的，因为$p$是一个排列，所以每个位置都位于一个循环上。 每个周期都是独立发展的，在每个周期内我们本质上都是旋转的值。 

约束条件$n \le 5 \cdot 10^5$意味着我们需要一个线性或近线性的解决方案。 任何与周期成二次方的情况都是不可能的，因为最坏情况下的周期长度可能全部为 1 或一个大周期，并且重复模拟将超出时间限制。 

当循环有多个有效对齐导致相同的最终排列时，就会出现微妙的边缘情况。 例如，如果循环长度为 4 并且最终值为$[1,2,3,4]$在某些旋转下，则多次初始旋转是有效的。 简单的重建可能会在每个周期选择任意旋转，但字典最小化会跨周期耦合选择，因为排列中较早的位置更重要。 

另一个重要的情况是，循环是独立的，但字典顺序迫使我们在一致的位置映射中选择每个循环的最小旋转，而不是贪婪地选择值。 

## 方法

 暴力方法会尝试所有可能的初始排列$b$, 模拟应用$p$直到我们到达$a$，并检查有效性。 这是立即不可行的，因为有$n!$候选人，甚至单次模拟成本$O(n)$，导致$O(n! \cdot n)$，这是一个天文数字。 

问题的结构由排列决定$p$。 每个索引都属于一个有向循环，并且应用$p$重复只是在每个周期内轮换值。 这意味着问题分解为独立的循环。 

在单个循环内，假设我们按遍历顺序列出其索引。 转变$p$充当循环移位。 最终配置$a$因此必须对应于初始配置的一些旋转$b$。 这将每个周期的问题减少为：选择在重复移位下向前映射的周期旋转以匹配$a$，并选择字典顺序最小的全局排列。 

关键的观察是，我们可以为每个周期分配一个一致的“起始偏移量”，而不是及时向前思考，这样当我们向前遍历周期时，结果排列匹配$a$。 约束来自$a$唯一地确定哪些旋转是有效的，并且我们通过将最小可能的起始值固定在循环顺序中的最早位置来按字典顺序选择最小的旋转。 

由于循环是独立的，但字典顺序与全局数组进行比较，因此我们按最小索引的升序处理循环，并贪婪地分配最小的可行旋转。

 | ---| ---| ---| ---|
 | 蛮力 |$O(n! \cdot n)$|$O(n)$| 太慢了 |
 | 循环分解|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们首先分解排列$p$进入不相交的循环。 对于每个循环，我们按遍历顺序记录其索引。 

接下来我们使用最终的安排$a$了解如何在每个循环中放置值。 由于运动仅在周期内排列，因此每个周期$a$必须与分配给该循环的值的旋转完全对应$b$。 

我们独立处理每个周期，但我们构造$b$以确保全球词典编纂最小化的方式。 

1. 识别所有周期$p$。 对于每个未访问的索引，请遵循$p$直到回到起点，按顺序记录循环。 
2. 对于每个周期，从中提取值序列$a$按循环顺序在这些位置上。 这给出了该周期的最终旋转版本。 
3. 确定将产生字典顺序上最小的可能初始排列的旋转。 由于任何旋转都是有效的，因此我们选择使循环的第一个元素尽可能小的旋转，并且如果绑定，则继续沿着循环按字典顺序最小化。 
4. 将这些选择的值写回$b$沿着相应的顺序循环位置。 

微妙之处在于“字典顺序最小”适用于整个数组，而不是循环局部数组。 然而，由于循环是不相交的，因此两个候选者之间最早的不同位置位于包含它们不同的最小索引的循环中。 因此，按照最小索引增加的顺序最小化每个循环可以保证全局最小性。 

### 为什么它有效

 每个循环都是一个独立的排列下的旋转群$p$。 最终的数组$a$修复每个周期的多组值及其循环顺序直至旋转。 任何有效的初始配置都对应于为每个周期选择一个轮换。 两个全局候选者之间的词典比较是根据它们不同的第一个索引确定的，该索引正好位于一个周期内。 在每个周期内选择字典顺序最小的旋转可以确保没有替代旋转可以在其周期的第一个受影响的索引处产生更小的前缀，因此不可能进行全局改进。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = [0] + list(map(int, input().split()))
    a = [0] + list(map(int, input().split()))

    vis = [False] * (n + 1)
    b = [0] * (n + 1)

    for i in range(1, n + 1):
        if vis[i]:
            continue

        cycle = []
        cur = i
        while not vis[cur]:
            vis[cur] = True
            cycle.append(cur)
            cur = p[cur]

        m = len(cycle)

        # values in final arrangement along cycle order
        vals = [a[x] for x in cycle]

        # find lexicographically smallest rotation of vals
        # by doubling and using minimal starting point
        best = 0
        doubled = vals * 2

        for j in range(1, m):
            for k in range(m):
                if doubled[j + k] < doubled[best + k]:
                    best = j
                    break
                if doubled[j + k] > doubled[best + k]:
                    break

        rotated = [doubled[best + k] for k in range(m)]

        for idx, pos in enumerate(cycle):
            b[pos] = rotated[idx]

    print(*b[1:])

if __name__ == "__main__":
    solve()
```解决方案首先阅读排列和最终排列。 然后它会分解$p$使用访问过的数组进入循环。 对于每个周期，它从中提取相应的值$a$，它代表该循环在所有旋转之后的样子。 

为了按字典顺序最小化，它使用简单的加倍比较来计算该周期值序列的最小旋转。 这已经足够了，因为每个周期都是独立的，我们只需要最小的循环移位。 

最后，它将旋转的序列按遍历顺序写回原始循环位置，产生初始排列。 

一个常见的陷阱是假设我们可以对循环值进行排序或贪婪地将最小的元素放在第一位。 这打破了旋转约束：值被锁定在循环顺序中，不能自由排列。 

## 工作示例

 ### 示例 1

 输入：```
n = 4
p = [2,1,4,3]
a = [3,2,1,4]
```循环分解给出$[1,2]$和$[3,4]$。 

For循环$[1,2]$，值来自$a$是$[3,2]$。 旋转次数为$[3,2]$,$[2,3]$。 最小值为$[2,3]$， 所以$b[1]=2, b[2]=3$。 

For循环$[3,4]$，值为$[1,4]$。 旋转次数为$[1,4]$,$[4,1]$。 最小值为$[1,4]$，所以不变。 

| 循环 | a 值 | 选择轮换 | b 作业 |
 | ---| ---| ---| ---|
 | [1,2]| [3,2]| [2,3]| b1=2，b2=3 |
 | [3,4]| [1,4]| [1,4]| b3=1，b4=4 |

 输出：```
2 3 1 4
```这证实了每个周期都是独立处理的，同时保持字典最小化。 

### 示例 2

 输入：```
n = 6
p = [2,1,4,5,3,6]
a = [3,1,2,4,6,5]
```周期是$[1,2]$,$[3,4,5]$,$[6]$。 

为了$[1,2]$, 值$[3,1]$，最佳旋转是$[1,3]$。 

为了$[3,4,5]$, 值$[2,4,6]$，比较旋转，最小的是$[2,4,6]$。 

为了$[6]$，保留单个元素$[5]$。 

| 循环 | a 值 | 最佳轮换 | 结果 |
 | ---| ---| ---| ---|
 | [1,2]| [3,1]| [1,3]| b1=1，b2=3 |
 | [3,4,5]| [2,4,6]| [2,4,6]| b3=2，b4=4，b5=6 |
 | [6] | [5]| [5]| b6=5 |

 输出：```
1 3 2 4 6 5
```这表明较大的循环的行为与独立旋转问题完全相同。

 ## 边缘情况

 单元素循环的行为很平常，因为只有一次有效的旋转。 该算法将其处理为长度为 1 的循环，并直接从$a$，产生唯一可能的初始值。 

对于全长循环，算法的旋转搜索会比较循环值的所有移位。 即使多个旋转看起来相似，也会一致选择字典顺序最小的，因为比较是在双倍数组中按字典顺序进行的。 

当所有循环的长度都是二时，每个循环就变成一个简单的交换决策。 由于旋转比较退化为二元素比较，该算法仍然统一处理它们。 

更微妙的情况是多个周期包含相同的值模式。 即使如此，循环独立性也确保了没有干扰，并且按循环内最小索引排序保证了确定性分配。
