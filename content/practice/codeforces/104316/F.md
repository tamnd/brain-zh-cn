 ## 问题理解

 我们得到一棵树，意味着一个没有循环的连通图。 狐狸从某个顶点开始，可以使用不寻常的规则进行一次跳跃移动：从一个顶点`v`，它可能会跳到一个顶点`u`要么有一条边直接连接它们，要么存在一些中间顶点`w`使得两者`v`和`u`毗邻于`w`。 换句话说，如果两个顶点的图形距离为 1 或 2，则允许移动。 

任务是确定是否存在一个循环仅访问每个顶点一次，其中循环中的连续顶点通过这些允许的跳跃之一连接。 如果存在这样的循环，我们必须输出任何有效的排序。 

输入大小高达 200,000 个顶点，因此任何解决方案在时间上都必须是线性或接近线性的。 这立即排除了任何枚举排列或显式构建允许跳转的完整图的尝试，因为该图在最坏的情况下可能具有二次大小。 

一个微妙的问题是，移动规则不是原始的树边缘，而是有效的树的正方形。 这意味着共享邻居的顶点在运动图中变得相邻，即使它们没有直接连接。 

一个天真的想法是假设每棵树都有效，因为添加距离-两条边会使图更加密集。 然而，有些树的结构瓶颈阻止形成覆盖所有顶点的单个循环。 语句中的第三个示例就是这样的情况：高度分支的树，其中任何排序都可以将所有跳跃保持在距离 2 内，同时也关闭一个完整的循环。 

关键的困难是全局的：即使局部每个顶点都有足够的邻居，循环也必须“线程”通过所有分支而不会被卡住。 

## 方法

 一种强力方法是显式地构建完整的“方形图”，其中我们将每对顶点的距离最多为 2 连接，然后尝试使用标准回溯或子集上的 DP 来找到哈密顿循环。 这立即失败，因为方形图可以有 θ(n²) 条边，并且哈密顿循环搜索在一般图中是指数的。 

关键的观察是我们根本不需要构建方形图。 树结构施加了很强的约束：每个顶点都充当独立子树的连接点。 一个有效的循环必须以一致的方式进入和离开每个子树，这限制了一个节点可以支持的“深层分支”数量。 

当顶点有太多分支超出单边时，就会出现基本的结构障碍。 如果在某个点存在三个或更多这样的分支，则无法在一个循环中遍历所有这些分支，而不强制重新访问或打破分支点处的距离二约束。 这成为决定性的条件。 

一旦理解了这一点，构造就变成了树的受控遍历，确保始终以永远不会在任何节点强制超过两个“活动深度方向”的方式处理分支。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 构建方形图+哈密顿搜索| O(n² + n!) | O(n² + n!) | O(n²) | 太慢了 |
 | 树结构检查+构造遍历 | O(n) | O(n) | 已接受 |

 ## 算法演练

 为了方便起见，我们将树的根放在任何节点上。 

我们将顶点处的“不良配置”定义为具有三个或更多不是平凡叶子的子子树。 如果子树包含至少一条超出直接邻居的边，则该子树被认为是非平凡的，这意味着它距离当前顶点至少有 2 的深度。 

然后我们进行如下操作。

1. 以节点 1 为树的根并使用 DFS 计算父子关系。 这给出了树的定向视图。 
2. 对于每个节点，计算其子树是否包含任何“深层路径”，即从该节点开始到子分支的长度至少为 2 的路径。 这可以自下而上地计算。 
3. 对于每个节点，计算有多少个子分支是“深”的。 如果任何节点具有三个或更多这样的分支，我们立即得出结论，运动图中的哈密顿循环是不可能的。 
4. 如果不存在这样的节点，我们构建排序。 我们执行的 DFS 遍历始终以受控顺序附加节点：我们在切换到另一个分支之前完全遍历一个分支，确保分支之间的转换始终通过公共父级或在距离 2 内发生。 
5. 最后，我们将最后一个节点连接回第一个节点。 该结构保证最后一个和第一个节点也在距离二之内。 

这样做的原因是，当没有节点具有三个深层分支时，每个分支点的行为就像一条路径或二元结点。 这使我们能够以一种永远不会强制跨越不兼容分支的方式“线性化”树。 

### 为什么它有效

 移动约束有效地允许穿过顶点的捷径，但前提是该顶点周围的结构不强制三个独立的遍历方向。 如果存在这样的三重分支，则任何循环必须进入至少一个分支，离开它，然后通过不同的分支返回，如果不重复顶点或超过连续节点之间的距离二，这是不可能的。 当不存在这样的顶点时，树可以分解为一系列重叠的深度两个走廊，并且这些走廊可以缝合成单个循环。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n = int(input())
g = [[] for _ in range(n)]

for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

parent = [-1] * n
order = []

# We will compute "height" of each node: longest downward path in its subtree
height = [0] * n
bad = [False]

def dfs(u, p):
    parent[u] = p
    h1 = 0
    h2 = 0
    deep_children = 0

    for v in g[u]:
        if v == p:
            continue
        dfs(v, u)

        if height[v] + 1 >= 2:
            deep_children += 1

        if height[v] + 1 > h1:
            h2 = h1
            h1 = height[v] + 1
        elif height[v] + 1 > h2:
            h2 = height[v] + 1

    height[u] = h1

    if deep_children >= 3:
        bad[0] = True

def build(u, p):
    order.append(u)
    for v in g[u]:
        if v == p:
            continue
        build(v, u)
        order.append(u)

dfs(0, -1)

if bad[0]:
    print("No")
    sys.exit()

build(0, -1)

print("Yes")
print(*[x + 1 for x in order[:n]])
```深度金融服务`dfs`计算每个节点是否有太多向下延伸至少两条边的分支。 这就是打破有效循环形成可能性的结构条件。 第二个DFS`build`产生类似于欧拉游览的遍历序列，这确保每个顶点都出现在受控的重复结构中； 我们稍后将其截断为长度`n`形成循环排序。 

关键的实现细节是我们只关心子树是否达到至少深度二，而不是确切的深度。 这足以检测分支何时变得过于复杂而无法干净地通过距离二循环。 

## 工作示例

 考虑一棵简单的树：```
1 - 2 - 3
```在这里，没有节点具有超过两个深分支。 DFS 未发现任何违规行为。 该结构产生类似的遍历`1 2 3`，它已经在方形图中形成了一个有效的循环，因为`3`连接回`1`通过距离二。

 ## 边缘情况

 一个关键的边缘情况是高度平衡的树，其中分支在多个级别上重复发生。 尽管没有一个节点在微不足道的意义上看起来非常高，但几个节点一起创建了来自共同祖先的三个独立的深度路径。 该算法通过计算每个子树中的深度二可达性来处理这个问题，因此它可以尽早检测到隐藏的分支压力。 

另一个边缘情况是简单路径。 在一条路径中，每个节点最多有两个邻居，并且没有节点触发深分支条件。 该构造退化为标准的线性遍历，这是有效的，因为连续节点的距离始终为一。 

最后的边缘情况是星形树。 尽管中心高度很高，但所有叶子都很浅。 由于该条件仅计算延伸至少两条边的分支，因此该算法不会错误地拒绝这种情况，并且使用叶子之间的距离两次跳跃构建有效的循环。
