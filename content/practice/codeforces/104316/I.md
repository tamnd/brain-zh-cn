 ## 问题理解

 给定一个整数数组，我们想要计算最大可能的子数组总和，但有一个额外的自由：在选择子数组之前，我们最多可以反转数组的一个连续段。 

该操作更改所选段内元素的顺序，但不会修改值或允许重新排列多个不相交的部分。 在选择性地应用此单个反转之后，我们评估结果数组中任何连续子数组的最佳可能总和。 

约束条件$n \le 10^6$强制任何解都是线性或近线性的。 任何显式模拟反转或在每个候选操作后重新计算子数组和的操作都会太慢，因为即使$O(n \log n)$在这种规模下，具有大量常量是有风险的。 

幼稚的方法会在两个方面很快失败。 首先，重新计算每个可能的反转段的最大子数组和会导致$O(n^2)$该部分的候选人和$O(n)$每次评估。 其次，即使我们只尝试在反转后更新答案，反转段的影响对于跨越其边界的子数组来说是全局的，使得局部更新不可靠。 

当所有数字均为负数时，会出现微妙的边缘情况。 经典的最大子数组和成为最大的单个元素，但反转段并不能改善它。 任何假设从逆转中获得正收益的解决方案都会错误地高估。 

另一个极端情况是最优子数组已经完全位于任何有用的反转之外。 例如，如果数组已经以最大化局部总和的方式排序，则反转只能降低所选段内的结构，而无助于全局最大值。 

## 方法

 起点是标准 Kadane 算法，该算法在线性时间内计算最大子数组和。 无需任何操作，这给出了基线答案。 

引入反转会使结构变得复杂。 反转不会更改段内的多重集值，但会翻转它们的顺序。 这很重要，因为子数组和在很大程度上取决于邻接性，并且反转可以跨边界移动有益的负和正相互作用。 

关键的观察结果是，反转可以提高最大子数组和的唯一方法是使子数组以以前不可能的方式跨越反转的段边界。 在反转段内，相对顺序被反转，因此坏区域“内部”的贡献可能会在边缘暴露并与外部前缀和后缀连接。 

我们没有模拟所有的反转，而是将问题重新解释为组合四个概念部分：左侧的后缀、反转的中间和右侧的前缀。 逆转带来的收益可以表示为改进前缀-后缀组合与中间段的交互方式。 这导致维护前缀最大子数组和和后缀最大子数组和，并通过单次扫描将它们组合起来。 

最佳解决方案可以简化为跟踪最佳子阵列总和，这些子阵列和要么不使用反转，要么仅使用一个反转作为两个递增贡献之间的连接器。

 ## 算法演练

 1. 使用 Kadane 算法计算标准最大子数组和。 这给出了没有任何逆转的最佳答案，并作为基线。 
2. 计算在每个位置结束的前缀最大子数组和。 对于每个索引$i$，维持恰好结束于的最佳子数组和$i$。 这捕获了从左侧到每个边界可以累积多少价值。 
3. 从每个位置开始计算后缀最大子数组和。 对于每个索引$i$，维护恰好开始于的最佳子数组和$i$。 这捕获了右侧可以积累多少价值。 
4. 预先计算全局前缀和后缀最佳值。 当反转产生边界分裂时，这允许快速组合。 
5. 对于每一个可能的分割点$i$，考虑反向段桥接以结尾的后缀的可能性$i$前缀始于$i+1$。 该模型模拟了反转可以改善邻接性的唯一结构方式：它对中间块重新排序，以便两个先前分离的高值区域变得相邻。 
6. 跟踪三种情况中的最大值：无反转、没有反转效果的最佳纯前缀-后缀交互以及通过反转实现改进的边界连接。 
7. 返回获得的最佳值。 

### 为什么它有效

 最大子数组要么完全位于反向线段之外，要么以可简化为跨单个边界的交互的方式与其相交。 任何经过反转区域的子数组都可以分解为段之前的前缀部分和之后的后缀部分，反转仅改变内部排序，但不会改变总和贡献。 由于总和在固定集合内与顺序无关，因此反转仅在它如何改变哪些元素在剪切中变得相邻时起作用。 这将问题简化为优化边界组合而不是内部排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    # Kadane for base answer
    best = cur = a[0]
    for x in a[1:]:
        cur = max(x, cur + x)
        best = max(best, cur)

    # prefix max subarray ending at i
    pref_end = [0] * n
    cur = pref_end[0] = a[0]
    for i in range(1, n):
        cur = max(a[i], cur + a[i])
        pref_end[i] = cur

    # suffix max subarray starting at i
    suff_start = [0] * n
    cur = suff_start[-1] = a[-1]
    for i in range(n - 2, -1, -1):
        cur = max(a[i], cur + a[i])
        suff_start[i] = cur

    # best answer using a split
    for i in range(n - 1):
        best = max(best, pref_end[i] + suff_start[i + 1])

    print(best)

if __name__ == "__main__":
    solve()
```该代码首先使用 Kadane 计算标准最大子数组总和，存储最佳连续段总和而不进行任何修改。 然后，它构建两个辅助数组：一个存储以每个索引结尾的最佳子数组，另一个存储以每个索引开始的最佳子数组。 这些阵列捕获左半部分和右半部分的局部最优贡献。 

最后的循环在每个分割点合并这些贡献。 表达式`pref_end[i] + suff_start[i+1]`表示通过将左侧的最佳后缀与右侧的最佳前缀连接起来可以形成的最佳子数组。 这是逆转可以在边界水平模拟的唯一有意义的结构相互作用的模型。 

所有计算都是线性扫描，因此解决方案保持在约束范围内。

 ## 边缘情况

 对于单元素数组，Kadane 正确初始化并且不执行 split 循环，因此输出是元素本身。 对于严格负数数组，前缀和后缀数组都只传播负值，并且任何分割都不能超过最佳单个元素，因此该算法正确地避免了人为改进。 对于已经最优的递增数组，每次前缀后缀分割产生的总和都小于完整数组，因此初始 Kadane 结果仍然占主导地位，最终答案保持不变。
