 ## 解决方案
 ## 问题理解

 我们有两行点在一条水平街道的上方和下方对齐。 在每个整数位置$i$从 1 到$n$，上面有一个咖啡馆，有重量$a_i$下侧有一家咖啡馆，有重量$b_i$。 这些权重代表每天访问每家咖啡馆的人数。 

我们可以在任何咖啡馆内投放广告。 如果我们在咖啡馆的位置放置广告$x$，这家咖啡馆变得“盲目”，这意味着它自己的访客根本看不到任何广告。 

放置的广告仅在街道对面的咖啡馆可见，且水平距离最多为$d$。 所以在楼上的咖啡馆里放了一个广告$i$被较低的咖啡馆看到$j$这样$|i - j| \le d$，前提是那些较低的咖啡馆本身不刊登广告。 同样的规则对称地适用于另一个方向。 

每家咖啡馆要么对答案贡献全部力量，要么什么也不贡献，具体取决于其访客是否至少看到一个广告。 如果一家咖啡馆有广告，无论它看到什么，它的贡献始终为零。 

目标是选择放置广告的位置，以使咖啡馆中至少看到一则广告的总人数最大化。 

重要的困难在于，放置广告同时做了两件事：它为对面的范围创造了可见性，但它也破坏了放置广告的咖啡馆的可见性。 

限制因素$n \le 1500$建议$O(n^3)$或者更糟糕的解决方案是不可行的，而$O(n^2)$动态规划方法可能是预期的。 

一个微妙的边缘情况来自这样一个事实：选择一家咖啡馆完全消除了它自己的贡献。 例如，在一个区域内的任何地方放置广告并不一定会增加答案，因为您删除的权重可能比您获得的权重更多。 

另一个重要的情况是当$d = 0$。 在这种情况下，每个广告仅影响同一索引的直接对面的咖啡馆，这将问题简化为仔细配对或选择性激活位置。 

## 方法

 蛮力的想法是尝试两边咖啡馆的所有子集。 对于每种配置，我们模拟哪些咖啡馆至少看到一个广告。 这涉及到对照对面的每个咖啡馆检查每个广告，从而得出可见性计算$O(n)$每个广告。 由于有$2^{2n}$子集，即使对于非常小的子集，这种方法也是完全不可行的$n$。 

关键的结构观察是每个广告仅影响对面的连续间隔。 位置上的单个广告$i$覆盖区间$[i-d, i+d]$。 因此，任何广告配置的效果都可以通过每侧间隔的并集来充分描述。 我们可以考虑间隔的覆盖范围以及哪些咖啡馆因投放广告而被排除在外，而不是考虑单个广告与咖啡馆的互动。 

这表明了动态规划的公式。 当我们从左向右移动时，对未来决策唯一重要的是每侧放置的最新广告，因为这决定了当前是否覆盖未来的位置。 这将问题从指数子集减少到位置上的结构化状态转换。 

我们在线路前缀上维护 DP，同时记住每侧最后选择的广告位置。 在每个索引中，我们决定是否将广告放置在顶部、底部、两者或都不放置，并相应地更新覆盖范围。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力子集 |$O(2^{2n} \cdot n)$|$O(n)$| 太慢了 |
 | 与最后选择的状态的间隔 DP |$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们从左到右处理位置并维护描述两侧最新广告展示位置的 DP 状态。 

### 1.定义DP状态

 我们定义$dp[i][j]$作为处理到某个位置后可达到的最高分数，其中最后放置在上侧的广告位于 位置$i$，下侧最后放置的广告位于位置$j$。 值 0 可以表示该侧“尚未放置广告”。 

这样做的原因是任何位置的覆盖范围仅取决于对面最近的广告，而不取决于较远的较早广告。 

### 2. 解释某个位置的覆盖范围

 在任何位置$x$，如果某个位置存在下侧广告，则上侧的咖啡馆被视为被覆盖$j$这样$|x - j| \le d$。 此条件仅取决于最近的相关广告，这正是 DP 状态存储的内容。 

同样，下层咖啡馆仅依赖于上层最后的广告。 

### 3. 增量处理位置

 我们从左到右扫描位置。 在每个位置$k$，我们考虑放置广告的所有可能性：

 我们可能不放置广告、在上层咖啡厅放置广告、在下层咖啡厅放置广告或在两者上都放置广告。 每个选择都会相应地更改最后一个广告的状态。 

当我们将广告放置在以下位置时$k$，咖啡馆位于$k$它本身没有任何贡献，因为它立即被阻止。 

### 4.添加新受影响职位的贡献

 对于每个位置$k$，在做出放置决定之前，我们计算上层咖啡馆是否位于$k$当前已被最后一个下部广告覆盖，以及下部咖啡馆是否位于$k$被最后一个上部广告覆盖。 如果它们被覆盖，它们的权重就会影响答案，除非我们选择在它们上放置广告。 

这使我们能够在本地积累贡献，同时保持全球的正确性。 

### 5. 过渡

 来自州$(i, j)$，我们转换到与位置决策相对应的状态$k$。 每次转换都会更新最后一个广告位置并添加位置的贡献$k$，取决于覆盖范围以及我们是否阻止它。 

这种结构化的演变确保每个咖啡馆都被记录一次，无论是在 DP 进程中“最终确定”还是被阻止时。 

### 为什么它有效

 关键的不变量是，在 DP 中的任何一点，与未来覆盖决策相关的唯一信息是每一侧最近的广告。 任何早期的广告都太远，无法影响未来的排名，并且任何未来的广告尚不清楚。 这将全局依赖结构减少为两个滑动影响区域，每侧一个。 由于覆盖范围纯粹是基于间隔的，并且是在独立咖啡馆之间累加的，因此 DP 状态完全捕获了所有可能影响最终分数的交互作用。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, d = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    # dp[i][j] = best result where last top ad is i, last bottom ad is j
    # we compress "no ad yet" as 0, and shift indices by +1
    dp = [[-10**18] * (n + 1) for _ in range(n + 1)]
    dp[0][0] = 0

    def covered(last, pos):
        return last != 0 and abs(last - pos) <= d

    for k in range(1, n + 1):
        ndp = [[-10**18] * (n + 1) for _ in range(n + 1)]

        for i in range(n + 1):
            for j in range(n + 1):
                cur = dp[i][j]
                if cur < 0:
                    continue

                top_cov = covered(j, k)
                bot_cov = covered(i, k)

                base_gain = 0
                if top_cov:
                    base_gain += a[k - 1]
                if bot_cov:
                    base_gain += b[k - 1]

                # 1) no ad at k
                ni, nj = i, j
                ndp[ni][nj] = max(ndp[ni][nj], cur + base_gain)

                # 2) ad on top at k
                ni, nj = k, j
                ndp[ni][nj] = max(ndp[ni][nj], cur + (base_gain if not top_cov else base_gain - a[k - 1]))

                # 3) ad on bottom at k
                ni, nj = i, k
                ndp[ni][nj] = max(ndp[ni][nj], cur + (base_gain if not bot_cov else base_gain - b[k - 1]))

                # 4) ads on both sides
                ni, nj = k, k
                gain = base_gain
                if top_cov:
                    gain -= a[k - 1]
                if bot_cov:
                    gain -= b[k - 1]
                ndp[ni][nj] = max(ndp[ni][nj], cur + gain)

        dp = ndp

    ans = 0
    for i in range(n + 1):
        for j in range(n + 1):
            ans = max(ans, dp[i][j])

    print(ans)

if __name__ == "__main__":
    solve()
```DP 表跟踪每侧最后选择的广告位置。 在每一步中，我们都会使用距离约束来计算每个咖啡馆当前是否暴露于来自对面的活跃广告。 然后，只有当它没有被在该咖啡馆投放新广告所阻止时，我们才会添加它的贡献。 

这四个转换与每个位置的可能决策完全对应，确保表示广告展示位置的每个配置。 

关键的微妙之处在于，当广告投放到咖啡馆时，要减去咖啡馆自身的重量，因为这些访客即使在范围内，也不会做出贡献。

 ## 边缘情况

 当$d = 0$，每个广告只影响正对面的咖啡馆。 DP 仍然可以正常工作，因为覆盖检查减少到索引相等，并且不会发生间隔传播。 

什么时候$d \ge n-1$，任何广告都可能覆盖整个对面。 在这种情况下，最优策略就是选择少量的高价值咖啡馆，以避免阻挡过多的本地贡献。 DP 自然会考虑到这种权衡，因为投放广告会立即消除本地收益。 

当所有值都相等时，该解决方案可以避免广告过度投放，因为额外的广告会减少本地贡献，而不会增加覆盖范围，超出单个投放良好的广告已经实现的范围。
