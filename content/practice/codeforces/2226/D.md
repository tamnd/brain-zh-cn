 ## 解决方案
 ## 问题理解

 我们得到了几个测试用例，每个测试用例都包含一个数组。 任务是决定我们是否可以使用特定操作将每个数组转换为非递减顺序：我们可以选择任何子数组，计算其最小值和最大值，然后将其反转，但前提是这两个值的总和具有奇奇偶校验。 

由于当两者之一为偶数而另一个为奇数时，总和恰好为奇数，因此该操作仅适用于最小值和最大值具有不同奇偶校验的段。 

每个测试用例的输出是一个简单的可行性检查：此类约束反转的某些序列是否可以对数组进行排序。 

这些约束意味着所有测试用例的总数组长度最多为 2×10^5，因此任何解决方案都必须在每个测试用例的线性或接近线性时间内运行。 尝试所有段或模拟操作的 O(n^2) 策略是立即不可行的。 

此类问题的常见故障模式是假设“同时具有偶数和奇数”会自动提供充分的灵活性。 这显然不是真的，因为操作取决于段中的极值，而不仅仅是两个奇偶校验的存在。 另一个微妙的陷阱是认为逆转的行为就像任意互换。 他们不这样做； 即使数组看起来很灵活，奇偶校验约束也可能阻止某些局部重新排列。 

## 方法

 暴力破解的视角很简单：重复尝试所有有效段，反转它们，并检查数组是否已排序。 每个步骤都需要扫描所有 O(n^2) 段，计算最小值和最大值，并模拟反转。 即使每个段查询都经过优化，通过反转可到达的状态数量也会呈爆炸性增长，使得这种方法对于 n 高达 2×10^5 的情况不可用。 

关键的结构观察是，对于实现任何移动唯一重要的是我们是否可以找到至少一个有效的段。 当段的最小值和最大值具有相反的奇偶校验时，该段恰好有效。 可以选择的最小可能段是长度为 2 的段，其中最小值和最大值只是两个端点。 这立即将操作条件简化为更简单的形式：当两个相邻值具有不同奇偶校验时，相邻交换是可能的。 

一旦看到这一点，就不再需要全局分析反转操作。 任何更长的有效反转都可以分解为奇偶校验不同的位置之间的一系列相邻交换。 这意味着系统的真正威力来自于能够交换相反奇偶校验的邻居，只要存在至少一个偶数和一个奇数元素，就允许元素在数组中逐渐洗牌。 

如果数组完全由具有相同奇偶校验的数字组成，则长度至少为 2 的段不能满足条件，因此不可能进行任何操作。 数组被冻结在其初始状态，只有当它已经是非递减的时候才可以排序。 

如果两个奇偶校验都存在，则至少存在一个有效的相邻交换，并且重复使用此类交换允许任意重新排序：可以通过交换相反奇偶校验邻居来“携带”数组中的元素，这最终实现标准的冒泡排序样式重新排列。

 ## 算法演练

1. 对于每个测试用例，扫描数组并确定是否存在至少一个偶数和至少一个奇数。 此单一检查捕获是否存在任何有效操作，因为长度为 2 的段是反转的最小候选者。 
2. 如果数组仅包含偶数或仅包含奇数，则立即得出无法进行操作的结论。 在这种情况下，数组无法更改，因此仅当数组已排序时答案才为“是”。 
3. 如果两个奇偶校验均出现，则断定该数组始终可排序。 至少一个偶数和一个奇数的存在保证了数组中某处可能发生相邻交换，并且这些交换足以通过重复的本地交换实现任何排列。 
4. 对于所有混合奇偶校验数组和已经排序的单奇偶校验数组输出“YES”，否则输出“NO”。 

### 为什么它有效

 决定性的不变量是数组是否包含两个奇偶校验。 如果两者都存在，则经过某种重新排列后，始终存在至少一对相邻的相反奇偶校验，并且这些对可用于在数组中传播元素。 这消除了位置刚性：元素不再被困在固定区域内。 如果仅存在一个奇偶校验，则每个子阵列都具有相同的奇偶校验极值，因此无法应用任何操作并且配置是不可变的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_sorted(a):
    return all(a[i] <= a[i+1] for i in range(len(a)-1))

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    has_even = False
    has_odd = False

    for x in a:
        if x % 2 == 0:
            has_even = True
        else:
            has_odd = True

    if has_even and has_odd:
        print("YES")
    else:
        # no operations possible at all
        print("YES" if is_sorted(a) else "NO")
```该解决方案首先在单次检查中检查奇偶校验多样性。 唯一微妙的分支是退化情况，其中所有数字共享相同的奇偶校验，在这种情况下数组是不可变的并且必须已经排序。 

这`is_sorted`仅在该退化分支中需要检查，因为否则答案总是肯定的。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        has_even = any(x % 2 == 0 for x in a)
        has_odd = any(x % 2 == 1 for x in a)

        if has_even and has_odd:
            out.append("YES")
        else:
            out.append("YES" if all(a[i] <= a[i+1] for i in range(n-1)) else "NO")

    return "".join(out)

 ## 边缘情况

 完全均匀奇偶校验阵列是系统零移动性的唯一配置。 在这种情况下，算法会正确地退回到纯粹的排序检查。 

例如，输入`[8, 6, 4, 2]`仅包含偶数。 没有段可以满足奇偶校验条件，因此数组不能改变。 该算法检测到这一点并直接评估它是否已经排序，在此生成“NO”。 

相比之下，`[3, 1, 2]`包含两个奇偶校验。 即使数组未排序，至少有一个偶数和一个奇数的存在确保了有效的相邻交换存在，因此算法正确地返回“YES”。
