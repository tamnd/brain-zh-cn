 ## 解决方案
 ## 问题理解

 给定一个整数数组，如果其最小和最大元素之和为偶数，则将其定义为时尚。 我们的任务是确定必须删除的最小元素数量，以便数组变得流行。 输入由多个测试用例组成，每个测试用例包含最多 50 个 1 到 50 之间的整数的数组。每个测试用例的输出是一个整数，指示最小删除数。 

限制很小：数组长度最多为 50，并且最多有 1000 个测试用例。 这意味着即使数组大小是二次方的方法也是可以接受的。 关键的观察是，时尚条件仅取决于最小和最大元素的奇偶性。 因此，我们不需要显式地考虑数组的每个子集。 当数组只有一个元素时，就会出现边缘情况，在这种情况下，它会自动流行，因为最小值和最大值相等，或者当所有元素都是奇数或偶数时，这可能允许直接得出结论而无需删除。 

粗心的方法会尝试随机删除元素或检查所有子集。 例如，在数组中`[1, 2, 3]`，最小值和最大值之和为`1 + 3 = 4`，这已经是偶数了，但是如果不首先检查极值之和，简单的算法可能会尝试删除不必要的元素。 

## 方法

 暴力方法是考虑数组的所有子集，计算每个子集的最小值和最大值，并检查它们的总和是否为偶数。 这保证了正确性，但速度却非常慢。 对于长度为50的数组，有`2^50`子集，这远远超出了可行的计算。 

关键的观察是，如果最小和最大元素都是偶数、都是奇数，或者如果我们删除元素直到这个条件成立，那么数组就会变得流行。 由于两个数字的和是偶数，即使两个数字具有相同的奇偶校验，因此分析数组的奇偶校验分布就足够了。 如果数组已经满足该奇偶校验条件，则需要零操作。 如果最小值和最大值具有不同的奇偶性，则最多从任一极端删除一次就足够了，但一般来说，计算偶数和奇数元素的数量可以让我们确定最小删除量：我们可以删除所有奇数或所有偶数，以强制最小值和最大值具有相同的奇偶性。 

最佳方法之所以有效，是因为它将问题从检查所有子集简化为简单地计算奇偶校验。 鉴于数组尺寸较小，这既简单又可靠。

 | --- | --- | --- | --- |
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了|
 | 最佳 | 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组并确定最小和最大元素。 这是评估总和条件的基线。 
2. 检查 min 和 max 之和是否为偶数。 如果是，请附加`0`到结果并继续，因为不需要删除。 
3. 如果和为奇数，则计算数组中偶数和奇数元素的数量。 
4. 最小移除次数为偶数元素个数和奇数元素个数中较小的一个。 删除较小奇偶校验的所有元素可确保新的最小值和最大值具有相同的奇偶校验，使总和均匀。 
5. 将此最小移除计数附加到结果中。 
6.处理完所有测试用例后，输出结果。 

工作原理：该算法保证删除后，仅保留单个奇偶校验的元素，因此剩余数组的最小和最大元素具有相同的奇偶校验。 具有相同奇偶性的两个数的和总是偶数，这满足了流行的条件。 通过选择较小的奇偶校验来删除，我们确保删除的次数最少。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
results = []

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    mn, mx = min(a), max(a)
    
    if (mn + mx) % 2 == 0:
        results.append(0)
        continue
    
    odd_count = sum(1 for x in a if x % 2 != 0)
    even_count = n - odd_count
    results.append(min(odd_count, even_count))

print('\n'.join(map(str, results)))
```该代码首先读取测试用例的数量并迭代每个测试用例。 它直接计算最小值和最大值。 检查模二之和可确保条件得到验证。 使用生成器表达式可以有效地计算奇数和偶数元素。 最后，将最小计数附加到结果中。 使用`join`一次打印所有结果可以避免多次 I/O 调用，这对于许多测试用例来说速度更快。

 ## 边缘情况

 对于单元素数组`[7]`、最小值和最大值相同。 总和是`14`，这是偶数。 算法正确输出`0`。 对于具有混合奇偶校验的阵列，例如`[1,2,3,4]`，min + max = 1 + 4 = 5 是奇数。 计算偶数（2 和 4）得出 2，计算奇数（1 和 3）得出 2。删除任一奇偶校验组都会导致 2 次删除，这是最小的。 对于数组`[2,2,2]`，总和为 4，偶数，因此返回零移除。 这些示例表明该算法可以正确处理琐碎和奇偶校验敏感的情况。
