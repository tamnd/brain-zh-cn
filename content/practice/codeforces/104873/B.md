 ## 解决方案
 ## 问题理解

 我们被要求构建一个由单位立方体组成的特定形状，绘制为方形网格。 每个单元格要么包含一个立方体，要么是空的，并且被占用的单元格必须形成“楼梯”形状。 具体来说，如果我们从下到上查看每一行，则当我们从左向右移动时，一行中占用的单元格数量不会增加。 这是常见的 Ferrers 图约束：每一行都是占用单元格的连续前缀，并且这些行长度不增加。 

最重要的是，形状在对角线 x = y 的反射下必须是对称的。 在网格术语中，这意味着占用单元的邻接矩阵是对称的，因此形状等于其转置。 每个被占用的单元格 (i, j) 意味着 (j, i) 也被占用，反之亦然。 

我们必须恰好使用 n 个单元格。 输出是一个足够大以包含形状的方形网格，我们可以自由选择其大小 m。 唯一的硬性要求是左下角的单元格必须被占据，这只是迫使形状接触费雷尔图的原点。 

约束很小：n 最多为 100。这立即排除了对所有网格配置的任何重型指数搜索。 即使是立方 DP 也可以，但任何涉及枚举网格单元所有子集的操作都是不必要的。 

如果我们尝试首先考虑任意楼梯形状，然后再强制对称，就会出现一个微妙的问题。 有效的楼梯形状已经构建完毕，但对称性迫使行和列之间存在强耦合，因此大多数简单的构造都会失败。 

一个典型的错误是将 n 的任何分区构建为不增加的行长度，然后对其进行镜像。 这几乎从不保留行结构。 例如，像 rows [4, 3, 1] 这样的形状是一个楼梯，但它的转置是 [3, 2, 1, 1]，这是不同的，因此它不是对称的。 

另一个失败案例是对称网格的贪婪填充：​​将单元格放置在镜像对中，直到达到 n。 这会破坏行和列的单调性，并可能产生不是有效楼梯的形状。 

真正的困难在于我们不是选择任意的形状，而是选择一种行结构和列结构一致的自洽形状。 

## 方法

 一个蛮力的想法是枚举 m × m 网格内所有可能的单调楼梯形状，然后测试它们是否对称并且恰好有 n 个单元。 单调形状的数量会像整数的划分数量一样增长到 100，并且对于每个形状，我们还需要验证对称性。 尽管 n 很小，但分区的搜索空间已经足够大，以至于原始生成变得混乱和冗余，因为大多数生成的形状立即违反对称性。 

关键的观察结果是对称 Ferrers 图不是任意分区。 它们有一个严格的结构：一切都由沿主对角线发生的事情决定。 每个对角单元就像一个中心，并且形状在行和列方向上均匀扩展。 

这导致了使用弗罗贝尼乌斯坐标的经典表示。 自对称 Ferrers 图完全由一系列非负整数 a1 > a2 > ... > ak 描述，其中每个 ai 表示图从第 i 个对角单元向右（向下对称）延伸多远。 每个这样的对角线贡献形成一个大小为 (2ai + 1) 的块，但这些块以受控方式沿对角线重叠，以保留楼梯结构。 

细胞总数变为 (2ai + 1) 之和。 因此，问题简化为选择变换后的总和与 n 匹配的不同非负整数。 

因为 n 最多为 100，所以我们可以使用动态规划对可能的值构造这样一个集合。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对所有楼梯形状进行暴力破解 | n 的指数 | O(n) | 太慢了 |
 | Frobenius 坐标 DP 构造 | O(n²) | O(n²) | 已接受 |

 ## 算法演练

 我们使用 Frobenius 坐标构建自共轭 Ferrers 图。 

### 步骤

 1. 我们根据选择对角线贡献来解释该结构。 每个选定的值 a 代表一个对角单元，贡献一个大小为 (2a + 1) 的块。 约束是所有选择的值必须是不同的。 
2. 我们定义一个 DP，对于 0 到 99 之间的每个可能值 a，我们决定是否包含它。 这自动保证了独特性。 
3. 设 dp[i][s] 为我们是否可以使用 i 以内的值获得总面积 s。 值 i 的贡献为 (2i + 1)。 我们通过跳过 i 或接受 i 来进行转换。 
4. 我们运行这个 DP，直到找到一个总和恰好为 n 的子集。 
5. 我们重建所选值 a1, a2, ..., ak。 
6. 我们按降序对这些值进行排序。 这种排序成为对角序列，确保沿弗罗贝尼乌斯坐标所需的严格递减。 
7. 我们构建网格。 令 k 为所选值的数量。 网格大小 m 是 k 加上最大的选定值，因为第一行沿对角线延伸 k 步加上其臂长。 
8. 我们使用标准 Ferrers 构造填充网格：对于每个对角线索引 i，我们标记一个以 (i, i) 为中心的正方形块，在所有四个方向上延伸 ai 步，并剪裁到网格。 

### 为什么它有效

 该构造强制执行自共轭费雷尔图，因为每个对角单元在行和列方向上对称地贡献。 ai 的独特性确保块正确嵌套并且不违反单调性。 每行长度等于相应的列高度，因为两者都由相同的对角线扩展规则确定。 DP 确保单元总数与 n 完全匹配，因此生成的图是有效的并且使用所有立方体。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    MAXA = 100

    # dp[i][s] = can we reach sum s using values 0..i
    dp = [[False] * (n + 1) for _ in range(MAXA + 1)]
    take = [[False] * (n + 1) for _ in range(MAXA + 1)]

    dp[0][0] = True

    for i in range(MAXA):
        for s in range(n + 1):
            if not dp[i][s]:
                continue
            # skip i
            dp[i + 1][s] = True

            # take i
            val = 2 * i + 1
            if s + val <= n and not dp[i + 1][s + val]:
                dp[i + 1][s + val] = True
                take[i + 1][s + val] = True

    if not dp[MAXA][n]:
        print(-1)
        return

    chosen = []
    i, s = MAXA, n
    while i > 0:
        if take[i][s]:
            i -= 1
            chosen.append(i)
            s -= 2 * i + 1
        else:
            i -= 1

    chosen.sort(reverse=True)
    k = len(chosen)

    if k == 0:
        print(-1)
        return

    m = k + (chosen[0] if chosen else 0)
    m = max(m, 1)

    grid = [['.' for _ in range(m)] for _ in range(m)]

    # place diagonal expansions
    for idx, a in enumerate(chosen):
        i = idx
        # expand from (i,i)
        for di in range(-a, a + 1):
            for dj in range(-a, a + 1):
                if abs(di) + abs(dj) <= a:
                    x = i + di
                    y = i + dj
                    if 0 <= x < m and 0 <= y < m:
                        grid[x][y] = 'o'

    # ensure bottom-left has a cube
    grid[0][0] = 'o'

    print(m)
    for row in grid:
        print(''.join(row))

if __name__ == "__main__":
    solve()
```DP 是变换后的权重 (2a + 1) 上的标准子集选择。 重建使用向后行走`take`表来恢复选择了哪些值。 

网格构造使用弗罗贝尼乌斯坐标的几何解释：每个对角线索引都是一个中心，我们在曼哈顿度量中绘制半径为 a 的菱形。 这是强制对称性的最直接方法，无需单独维护行和列约束。 

一个微妙的实现细节是确保网格大小 m 足够大。 我们选择 m 作为 k 加上最大臂长，因为最上面的对角单元决定了最远的水平范围。 

## 工作示例

 ### 示例 1：小 n

 输入：

 n = 5

 由于 2·2 + 1 = 5，我们可以选择单个值 a = 2。 

| 步骤| 选择| 总和|
 | ---| ---| ---|
 | 开始 | []| 0 |
 | 取 a=2 | [2] | 5 |

 网格大小变为 m = 1 + 2 = 3。 

我们以 (0,0) 为中心放置一个菱形，用 |i| 填充所有单元格 + |j| ≤ 2，在左上角产生对称的十字形。 

这证实了单个对角线贡献产生了有效的对称楼梯。 

### 示例 2：复合 n

 输入：

 n = 9

 我们可以选择 a = 3，因为 2·3 + 1 = 7，剩下的 2 不可能表示为另一个 (2a+1)，所以我们选择 a = 1 和 a = 0：

 1贡献3，0贡献1，总共4，不够，所以我们调整。 

有效的分解是 a = 2 (5) 和 a = 1 (3)，总共 8，仍然很短，所以我们添加 a = 0 (1)，得到 9。 

| 步骤| 已选套装| 总和|
 | ---| ---| ---|
 | 开始 | []| 0 |
 | 添加 2 | [2] | 5 |
 | 添加 1 | [2,1]| 8 |
 | 添加 0 | [2,1,0]| 9 |

 排序后：[2,1,0]，k = 3，m = 5。 

每条对角线都贡献一个对称的菱形，它们的嵌套确保不会出现重叠而违反单调性。

 ## 边缘情况

 一种边缘情况是当 n 非常小时，例如 1 或 2。单个对角线贡献已经迫使奇数大小，因此如果我们将自己限制得太窄，偶数值最初似乎是不可能的。 DP 通过允许多个对角项的组合来避免这种情况，包括贡献单个单元的 a = 0。 

另一种边缘情况是仅选择一个对角元素时。 在这种情况下，网格简化为居中的对称菱形。 该构造仍然会产生有效的楼梯，因为单个 Frobenius 块是微不足道的自共轭。 

最后一个微妙的情况是重建不产生任何元素。 这对应于 n = 0，这是外部约束，但代码在这种情况下通过返回 -1 来防止生成空结构。
