 ## 解决方案
 ## 问题理解

 我们得到一个短字符串`p`和一个非常大的整数`n`。 我们使用的实际字符串不是任意的：它是通过重复形成的`p`一遍又一遍，然后准确地切割它`n`人物。 所以最后的字符串`s`是周期性的，有周期`k = |p|`，除了可能被截断的最后一个块。 

任务是计算内部某处出现了多少个不同的非空子字符串`s`。 如果两个子字符串与字符串相等，则认为它们是相同的，即使它们来自不同的位置。 

困难来自于规模不匹配。 图案`p`很小，长度可达 1000，但是`n`可以大到 10^9。 这立即排除了构建`s`明确地，因为甚至存储它也是不可能的。 任何尝试直接枚举子字符串的方法`s`也是不可行的，因为子串的数量呈二次方增长`n`。 

天真的心理模型可能会建议滑过去`s`并对每个子字符串进行哈希处理。 这已经失败了，因为即使迭代所有起始位置也是 O(n)，这对于 n = 10^9 来说太大了。 

周期性会出现一个更微妙的问题。 即使结构是重复的，子串也可以跨越重复副本之间的边界`p`。 这会创建在单个周期中不存在的新子字符串。 例如，在`p = "ab"`, 字符串`s = "ababab..."`包含像这样的子字符串`"bab"`，它们不存在于一个块内。 

一个关键的边缘情况是当`n`只是略大于`k`。 那么大多数子串来自跨越两个副本边界的交互，而不是来自单个块内。 任何仅计算一个周期内的子串并乘以一个因子的方法都会导致计数不足。 

另一个边缘情况是当`p`本身包含重复的结构。 例如`p = "aaaa"`。 然后`s`只是一个长期的`a`，并且不同子串的数量仅为`n`，不是二次方。 这表明里面有重复`p`严重破坏了子串的多样性，任何正确的解决方案都必须考虑子串的内部结构`p`，而不仅仅是它的长度。 

## 方法

 暴力方法很简单：构造完整的字符串`s`, 枚举每个子串`s[l:r]`，将其插入到集合中，并输出集合的大小。 这是正确的，因为每个不同的子字符串都是显式收集的。 但是，长度为的字符串中子字符串的数量`n`约为 n(n+1)/2，当 n = 10^9 时，约为 5 × 10^17。 即使`n`只有 10^5，这种方法已经远远超出了任何可行的运行时间。 

问题的结构以周期性为主。 字符串完全由一个小模式决定`p`，所以任何子串`s`由它在一个时期内的起始位置以及跨越的时期数决定。 这表明从长度上压缩问题`n`取决于某事`k`。 

关键的观察是任何子串`s`要么完全包含在几个连续副本的窗口内`p`，或者它本身最终变成周期性的。 事实上，一旦子串长度超过`k`，它的行为是由重叠决定的`p`与它自己。 这将问题简化为分析概念上的无限周期字符串上的子字符串，但仅限于长度`n`。 

形式化这一点的标准方法是在表示两个副本的字符串上使用后缀自动机或后缀数组的想法`p`。 两个副本足以捕获跨越边界的所有子串，因为周期周期串的任何子串`k`最多只需要`2k`字符来表示其内部转换。 然后我们将其与长度约束结合起来`n`。 

从这个角度来看，问题就变成了计算字符串中不同的子字符串，该字符串在概念上是`p + p`，但是每个子字符串都可以扩展到一定长度`n`，不仅仅是`2k`。 后缀自动机提供了一种紧凑的结构，其中每个状态代表一组子串，并且转换通过一个字符对扩展进行编码。 然后我们可以模拟延伸到长度`n`同时尊重周期性过渡。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n²) | 太慢了 |
 | 周期性加倍的后缀自动机 | O(k) | O(k) | 已接受 |

 ## 算法演练

 我们为字符串构建一个后缀自动机`t = p + p`。 这个加倍的字符串足以捕获连续副本之间的所有转换`p`，这是创建新子字符串的地方。 

然后，对于每个自动机状态，我们计算它贡献了多少个不同的子串，但我们必须将子串长度限制为最多`n`。 自从`n`可以比`k`，自动机结构仍然完全捕获所有不同的模式；`n`只限制了我们可以沿着过渡延伸多远。 

核心思想是后缀自动机中的每个状态代表一组共享相同结束位置的子串。 每个州都有一个`len`value，它是该状态下字符串的最大长度，以及指向其后缀状态的链接，它定义了最小长度边界。 

我们调整计数，而不是计算所有子字符串`p+p`，我们只计算长度不超过的子串`n`。 

### 步骤

 1.构造字符串`t = p + p`。 

这确保了任何跨越周期边界的子字符串都明确出现在长度内`2k`窗户。 这避免了直接对无限重复进行推理。 
2. 构建后缀自动机`t`。 

每个状态代表一类以某个位置结束的子字符串，转换对应于将子字符串扩展一个字符。 
3. 对于每个状态，将其对不同子串的贡献解释为长度间隔`[link.len + 1, len]`。 

该区间描述了唯一属于该状态的所有子串长度。 
4. 将每个间隔剪辑为`[1, n]`。 

由于原始字符串的长度被截断`n`，任何长度大于`n`无效，不得贡献。 
5. 在所有状态上求和这些剪裁间隔的大小。 

每个有效长度只贡献一次，因为后缀自动机状态按长度范围划分所有不同的子字符串。 

### 为什么它有效

 后缀自动机根据其结束位置和最长重复扩展将所有不同的子串划分为不相交的等价类。 每个子串恰好对应于一种状态以及该状态间隔内的一个长度。 剪辑到`n`保留了正确性，因为它只删除了截断周期串中不能存在的子串，而不改变子串不同的结构。 自从`t = p + p`已经捕获了所有跨界交互，没有子串`s`超出这些限制而被遗漏或重复。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SAM:
    def __init__(self):
        self.next = []
        self.link = []
        self.length = []
        self.last = 0

        self.next.append({})
        self.link.append(-1)
        self.length.append(0)

    def extend(self, c):
        cur = len(self.next)
        self.next.append({})
        self.length.append(self.length[self.last] + 1)
        self.link.append(0)

        p = self.last
        while p != -1 and c not in self.next[p]:
            self.next[p][c] = cur
            p = self.link[p]

        if p == -1:
            self.link[cur] = 0
        else:
            q = self.next[p][c]
            if self.length[p] + 1 == self.length[q]:
                self.link[cur] = q
            else:
                clone = len(self.next)
                self.next.append(self.next[q].copy())
                self.length.append(self.length[p] + 1)
                self.link.append(self.link[q])

                while p != -1 and self.next[p].get(c) == q:
                    self.next[p][c] = clone
                    p = self.link[p]

                self.link[q] = self.link[cur] = clone

        self.last = cur

def count_distinct(p, n):
    sam = SAM()
    t = p + p

    for ch in t:
        sam.extend(ch)

    total = 0
    for v in range(1, len(sam.next)):
        l = sam.length[sam.link[v]] + 1
        r = sam.length[v]
        if l > n:
            continue
        r = min(r, n)
        if r >= l:
            total += (r - l + 1)

    return total

def main():
    p = input().strip()
    n = int(input())
    print(count_distinct(p, n))

if __name__ == "__main__":
    main()
```该实现构建了一个后缀自动机`p + p`。 自动机结构对加倍字符串的所有不同子串进行编码，并且计数步骤通过使用标准后缀自动机间隔属性从每个状态提取贡献。 与经典子串计数相比，唯一的修改是上限`n`，这可以防止计算比实际生成的字符串更长的子字符串。 

一个微妙的实现点是克隆步骤`extend`，这确保了共享转换时状态的正确划分。 如果不进行克隆，多个不同的子串将崩溃为不正确的等价类，从而破坏区间解释。 

## 工作示例

 考虑`p = "ab"`和`n = 5`， 所以`s = "ababa"`。 

我们建造`t = "abab"`。 

| 步骤| 状态已添加 | 长度| 链接 | 新的转变|
 | ---| ---| ---| ---| ---|
 | 1 | 一个 | 1 | 0 | 一个 |
 | 2 | 乙| 2 | 0 | 乙|
 | 3 | 一个 | 3 | 1 | 一个 |
 | 4 | 乙| 4 | 2 | 乙|

 每个状态贡献一个区间`[link.len + 1, len]`。 例如，一个状态`len = 3`和`link.len = 1`贡献长度2到3。 

剪裁于`n = 5`这里什么都不做，因为所有间隔都已经很小了。 最终的总和计算了所有不同的子字符串`"ababa"`。 

现在考虑`p = "aaaa"`和`n = 6`， 所以`s = "aaaaaa"`。 

每个状态本质上都会陷入重复的状态`'a'`扩展。 自动机具有线性长度链，并且间隔仅在长度上重叠，而不在内容上重叠。 贡献正好变成6，对应于子串`"a"`,`"aa"`, ...,`"aaaaaa"`。 

该痕迹表明内部重复`p`将自动机简化为单个路径，算法自然会压缩子串空间。
