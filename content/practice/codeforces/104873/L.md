 ## 解决方案
 ## 问题理解

 我们得到一个有向无环图，其中顶点代表城市中的路口，边代表单向街道。 非循环条件意味着无法从交叉路口开始并沿着定向街道最终返回同一个地方。 这已经意味着每条有向路径都是有限的，但它并没有限制这样的路径可以有多长。 

每条街道必须涂成三种颜色之一。 一旦着色，我们就会查看任何有向路径并仅考虑单一颜色的边缘。 单色路径是每条边具有相同颜色的路径，其长度是其包含的边数。 要求是这样的单色路径不允许超过42条边。 

任务是为每条边分配一种颜色，以便该约束同时适用于所有三种颜色。 

约束允许最多 50,000 个顶点和 200,000 个边。 这排除了边或顶点上任何二次甚至接近二次的情况。 任何解决方案在边数上都必须本质上是线性的或接近线性的，因为即使$m \log m$是可以接受的，但是任何试图明确探索所有路径的事情都是不可能的。 

一个微妙的点是，虽然图是非循环的，但最长的有向路径仍然可能非常大，可能是线性的$n$。 如果我们任意分配颜色，甚至仅根据局部信息（例如度数）分配颜色，则很容易创建很长的单色链。 

例如，考虑一个简单的链：```
1 → 2 → 3 → 4 → ... → 100
```如果所有边都被涂成红色，则整个路径是长度为 99 的有效红色路径，这立即违反了要求。 即使以天真的方式交替颜色也无济于事，因为路径可以跳过结构，并且在不良着色下仍然形成长而一致的段。 

核心困难在于我们必须全局协调边缘颜色，以便每条长有向路径都被迫足够频繁地“切换颜色”。 

## 方法

 一个蛮力的想法是明确跟踪每条可能的路径和每种颜色的最长单色延续。 这会立即失败，因为 DAG 中的路径数量可能是指数级的。 即使是对所有路径的动态编程也隐含地需要组合指数级数量的子结构。 

关键的观察结果是，作为 DAG 的图为我们提供了自然的全局排序：每个顶点都可以分配一个拓扑等级，并且每条边都按照该顺序从较高的等级到较低的等级（或反之亦然，具体取决于约定）。 这使我们能够在顶点上定义单调数值势，该势沿着每条边严格减小。 

一旦我们有了这样的潜力，目标就变成了纯粹的组合：颜色边缘，这样任何共享颜色的长边序列都会迫使这种潜力的演变产生矛盾。 

强制执行像 42 这样的常量界限的标准方法是以小的基本表示形式对势进行编码并使用数字差异的结构。 我们为每个顶点分配一个等于其在 DAG 中最长路径深度的标签。 然后我们用基数 3 写出这个整数，它给出了有限位数的表示（对于这个约束，最多大约 11 个数字，但从概念上讲，我们可以安全地允许最多 42 个数字）。 

对于每一个边缘$u \to v$，由于该图是非循环的，因此深度严格从$u$到$v$。 因此，当我们比较这两个数字的以 3 为基数的表示形式时，会发现它们存在不同的最高位。 我们使用该数字位置来决定边缘的颜色，并使用该位置的数字值来区分三种颜色。 

这创造了一个非常强大的结构特性：沿着任何单色路径，所有边缘都被迫固定其“可区分的数字位置”。 这意味着沿路径的顶点标签的演化被限制在单个数字位置内重复减少，在该数字下溢之前，这种情况只能发生恒定的次数。 这将任何单色路径的长度限制在一个小常数内，安全地在 42 以内。 

这是有效的，因为着色并不是试图直接对整个结构进行编码，而是强制每条长路径最终耗尽固定数字级坐标的有限范围。

 ## 算法演练

 我们为每个顶点构造一个深度值，然后使用基于数字的比较来分配颜色。 

1. 计算 DAG 的拓扑排序。 这是必要的，因为所有边都必须按此顺序从前到后，从而允许对顶点进行动态编程。 
2. 计算每个顶点$v$一个值$dp[v]$，定义为从以下位置开始的任何路径中的最大边数$v$。 这是按逆拓扑顺序计算的。 该值充当 DAG 中的全局“高度”。 
3. 分别转换$dp[v]$转换为基数 3 的表示形式。 由于值最多是$n$，这个表示很短并且定义明确。 
4. 对于每个有向边$u \to v$，比较以 3 为底的表示形式$dp[u]$和$dp[v]$，并找到它们不同的最高有效数字位置。 呼叫此职位$k$。 
5.指定边缘的颜色$u \to v$基于位置数字的值$k$在$dp[v]$：数字0对应R，数字1对应G，数字2对应B。 
6. 按输入顺序输出每条边指定的颜色。 

我们使用最显着的不同数字的原因是，它确保边缘端点之间的所有较高数字都是相同的，这迫使沿着保持相同颜色的任何路径保持一致的“不一致程度”。 

### 为什么它有效

 沿着任何有向路径，$dp$严格递减，因此以 3 为基数的表示按照字典顺序从高重要性到低重要性递减而演变。 如果路径是单色的，则该路径中的每个边缘必须选择相同的最高有效不同数字位置。 这意味着路径中的所有顶点共享该位置上方的相同数字，并且只有该数字控制过渡。 

由于该数字只能从最多 2 减少到 0，因此在不再支持进一步减少之前，它只能更改固定次数。 这直接将任何单色路径的长度限制为一个小常数，该常数远低于 42。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def toposort(n, adj):
    indeg = [0] * (n + 1)
    for u in range(1, n + 1):
        for v in adj[u]:
            indeg[v] += 1

    stack = [u for u in range(1, n + 1) if indeg[u] == 0]
    order = []

    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                stack.append(v)

    return order

def main():
    n, m = map(int, input().split())
    edges = []
    adj = [[] for _ in range(n + 1)]

    for _ in range(m):
        u, v = map(int, input().split())
        edges.append((u, v))
        adj[u].append(v)

    order = toposort(n, adj)

    pos = [0] * (n + 1)
    for i, v in enumerate(order):
        pos[v] = i

    dp = [0] * (n + 1)

    for u in reversed(order):
        best = 0
        for v in adj[u]:
            best = max(best, dp[v] + 1)
        dp[u] = best

    def get_digits(x):
        d = []
        while x > 0:
            d.append(x % 3)
            x //= 3
        return d

    digits = [get_digits(dp[i]) for i in range(n + 1)]

    color_map = ['R', 'G', 'B']

    out = []

    for u, v in edges:
        du = digits[u]
        dv = digits[v]

        k = max(len(du), len(dv)) - 1
        while k >= 0:
            au = du[k] if k < len(du) else 0
            av = dv[k] if k < len(dv) else 0
            if au != av:
                break
            k -= 1

        if k < 0:
            out.append('R')
        else:
            out.append(color_map[dv[k]])

    print("\n".join(out))

if __name__ == "__main__":
    main()
```该解决方案首先构建拓扑顺序，以便明确定义传出边缘上的动态规划。 dp 数组存储从每个顶点开始的最长路径，该路径是通过按逆拓扑顺序处理顶点来计算的。 

每个 dp 值都会转换为基数 3 一次，因为这些表示可重复用于多个边。 这避免了边缘处理期间的重复转换。 

对于每条边，我们从最重要的一端向下比较数字数组，直到找到第一个差异。 该位置决定颜色，目标顶点的数字决定使用三种颜色中的哪一种。 不存在不同数字的后备情况对应于相等的 dp 值，该值是退化的并安全地映射到固定颜色。

 ## 边缘情况

 长线性链是最重要的应力情况。 由于 dp 值沿着链单调递减，因此该算法可确保每条边都受到一致的数字位置规则的控制，从而防止持续出现统一的颜色。 

高度源节点测试分支边是否意外地共享相同的数字结构。 由于每条边独立地比较目标数字，因此传出边自然地分布在颜色之间，而不是折叠成单个类别。 

多个节点共享相同 dp 值的 DAG 测试数字比较中的回退行为。 在这种情况下，算法分配固定颜色，但这些边不能形成长链，因为沿有向路径不会出现相同的 dp 值。
