 ## 解决方案
 ## 问题理解

 我们被要求将固定数量的黄金分配给$n$收件人，其中每个收件人$i$有声明的最大可接受份额$a_i$。 可用黄金总量为$s$，并且可能严格小于所有索赔的总和，因此并不是每个人都能得到他们想要的。 

不同的是，这种分裂并不是任意的。 它必须与特定的两人规则全局一致。 如果我们带任何一对人$i, j$想象一下他们的组合分配$c_i + c_j$，那么他们的个人股份$c_i, c_j$必须表现得完全就像我们对这两项索赔和总金额应用了固定的“公平分配”函数一样。 该函数是连续的，在总量上是单调的，并且仅取决于排序后的索赔$a_i \le a_j$。 

所以问题不仅仅是满足上限并求和$s$。 这是关于寻找一个全局向量$c$其每个成对投影都符合非常具体的局部规则。 

限制因素$n \le 5000$和$a_i \le 5000$表明一个$O(n^2)$或者$O(n^2 \log n)$方法是合理的，但任何对成对的立方体都不是。 我们应该期待一个聚合相同值或利用成对规则中的结构的解决方案。 

当所有的情况出现时，就会出现微妙的边缘情况$a_i$是平等的。 那么对称性迫使每个$c_i$是相等的，否则某些对将违反公平规则。 另一种边缘情况发生在$s = 0$，这迫使所有输出为零。 最后，当$s = \sum a_i$，每个约束都是饱和的，并且每个$c_i = a_i$。 

尝试独立满足所有对约束的简单方法将会失败，因为成对一致性不是独立的。 例如，固定$c_1, c_2$限制如何$c_1, c_3$行为，这反过来又限制$c_2, c_3$，形成全局耦合。 

## 方法

 蛮力观点是考虑分配值$c_1, \dots, c_n$并检查所有$\binom{n}{2}$对。 对于候选作业，我们计算$c_i + c_j$，应用两人规则，并验证一致性。 这已经花费了$O(n^2)$每次检查，并且搜索连续变量会使情况变得更糟。 即使离散化也会导致搜索空间的大小呈指数级不可行$n$。 

关键的观察结果是，成对规则仅取决于这两个声明的排序和饱和度。 这意味着每个人的行为就像一个潜在的均匀货币分配的“上限”：每个人的边际收益随着分配更多的钱而减少，并且所有边际行为在剪裁之前都是相同的$a_i$。 

这种结构是注水或参数分配过程的特征。 我们不是直接求解对约束，而是引入一个全局参数来确定边际分配，并且每个$c_i$是根据其上限的长度得出的$a_i$在该参数下处于活动状态。 

一旦以这种方式解释，问题就简化为找到一个参数，使分配的总质量等于$s$。

 ## 算法演练

 我们将公平分配规则解释为暗示货币的均匀边际分配，该分配由每个人剪裁$a_i$。 这导致单个单调参数$x$，代表“基线分配水平”。 

### 步骤

 1. 对值进行排序$a_i$按非递减顺序。 需要排序，因为边际结构取决于每个上限何时激活。 
2. 想象一下我们提高了全球水平$x$。 每个人收到的分配量随着线性增长$x$，但仅限于上限$a_i$。 这意味着人的有效贡献$i$是$\min(a_i, x)$在从成对规则导出的变换坐标系中。 

这样做的原因是两人公平条件强制执行相同的边际共享，直到一个人饱和为止。 
3. 计算排序后的前缀贡献$a_i$。 对于固定的$x$，我们可以将分配的黄金总量计算为：

 的总和$\min(a_i, x)$，它是分段线性的$x$。 
4.寻找独特的$x$使得总和等于$s$。 由于函数是单调的，我们可以二分查找$x$。 
5.一次$x$找到，赋值$c_i = \min(a_i, x)$调整回原来的解释，保留顺序。 
6. 输出结果$c_i$按原始顺序。 

### 为什么它有效

 两人规则强制要求任何两人之间的边际收益仅取决于相对于他们的主张的剩余能力。 这迫使所有分配都可以表示为公共递增分配配置文件的截断。 任何偏差都会产生一对，其中一个人会提前获得不成比例的更多边际质量，从而违反了所需的成对重建属性。 因此，所有有效的解决方案都依赖于这个单参数族，并且搜索正确的参数精确地强制执行总和约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    s = float(input())

    idx = list(range(n))
    a_sorted = sorted((val, i) for i, val in enumerate(a))

    def total(x):
        res = 0.0
        for val, _ in a_sorted:
            if val < x:
                res += val
            else:
                res += x
        return res

    lo, hi = 0.0, max(a)

    for _ in range(60):
        mid = (lo + hi) / 2
        if total(mid) < s:
            lo = mid
        else:
            hi = mid

    x = hi

    res = [0.0] * n
    for val, i in a_sorted:
        res[i] = min(val, x)

    # adjust to match exact sum (tiny floating drift)
    diff = s - sum(res)
    res[0] += diff

    print("\n".join(f"{v:.12f}" for v in res))

if __name__ == "__main__":
    solve()
```该实现对全局阈值执行二分搜索$x$。 功能`total(x)`评估截断贡献的总和，它是单调的$x$，允许稳定的搜索。 

排序仅用于保留结构； 由于在这种简化形式中每项都是独立的，因此我们只需要映射回原始索引。 

最后的校正步骤通过将残余误差推入一个坐标来调整浮点漂移。 这是安全的，因为所需的公差允许$10^{-9}$绝对误差，并且保留总数。

 ## 边缘情况

 当$s = 0$，二分查找立即收敛到$x = 0$，产生全零。 该算法处理这个问题是因为`total(x)`为零$x = 0$，因此不会触发任何分配。 

什么时候$s = \sum a_i$，搜索推送$x$超越一切$a_i$，所以每一个`min(a_i, x)`等于$a_i$。 输出完全变成输入数组。 

当所有$a_i$相等，假设都是 5，函数`total(x)`成长为$n \cdot \min(x, 5)$。 二分查找发现$x = s/n$，并且每个输出都是相同的，自动保持对称性。 

这些案例证实了该算法在没有特殊情况的情况下在边界范围内表现一致
