 ## 问题理解

 我们被要求计算由单位立方体构建的特定类别的形状。 每个有效的配置都是一个“楼梯状”结构：从左到右排列的立方体列，其高度永远不会随着我们向右移动而增加。 所以形状可以用一系列正整数来描述$h_1 \ge h_2 \ge \dots \ge h_k$，立方体总数为$n = \sum h_i$。 

在这种单调的“类似分区”的结构之上，还有一个额外的几何约束：形状必须相对于对角线对称$x = y$。 这种对称性迫使图表在对角线上镜像自身，这仅适用于非常特定的楼梯形状。 

输入给出多个值$n$，对于每一个，我们必须计算有多少个这样的对称楼梯配置准确地使用$n$立方体。 

约束条件$n \le 2 \cdot 10^5$最多$10^4$测试用例排除了每个查询重新计算任何内容。 任何解决方案都必须粗略地进行预处理$O(N)$或者$O(N \log N)$，然后在常数时间内回答每个查询。 

一种天真的方法会尝试生成$n$并测试对称性。 这已经呈指数级增长$\sqrt{n}$，对称性检查增加了另一个因素。 即使对于中等$n$，这变得不可行。 

一个更微妙的问题是对称约束是全局的。 构造一个“看起来局部结构化”但在绘制时无法保持对角线不变性的分区很容易。 例如，像这样的分区$4 + 2 + 1$生成不对称的 Ferrers 图，尽管它作为楼梯是有效的。 

关键的困难在于对称约束不是行或列的局部约束，而是将它们耦合在一起。 

## 方法

 暴力解释是枚举所有非递增的正整数序列，总和为$n$，并为每个构造其 Ferrers 图并检查它是否等于其转置。 的分区数$n$已经是指数级的$\sqrt{n}$，因此这种方法在超出非常小的值时变得不可能$n$。 对称性检查与图表大小呈线性关系，这使得情况变得更糟。 

结构见解是关于对角线对称的楼梯与自共轭分区完全对应。 在费雷尔图术语中，采用转置交换行和列。 要求相等意味着图在这种交换下必须保持不变。 

一个经典且重要的事实是，自共轭划分$n$与以下分区处于双射状态$n$分成不同的奇怪部分。 这完全改变了问题：我们将其转换为一维选择问题，而不是二维对称条件。 

每个奇数整数$2k-1$最多可以使用一次，并贡献那么多的立方体。 所以我们正在计算奇数的子集，其总和为$n$。 这是一个标准 0/1 背包，重量为奇数。 

我们预先计算一个 DP，在其中迭代所有奇数并更新求和的方法。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（生成分区+检查对称性）| 指数| O(n) | 太慢了 |
 | DP 超过不同的奇数部分 | O(n^2 / 2) 预处理，O(1) 每个查询 | O(n) | 已接受 |
