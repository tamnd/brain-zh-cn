 ## 解决方案
 ## 问题理解

 安娜旅行时，手机充满电开始旅程并消耗电池。 在旅途中的某个时刻，当电池电量达到 20% 的固定阈值时，手机会切换到较慢的放电模式。 在该点之前，它的排水速度更快，在该点之后，它的排水速度恰好是之前的一半。 

我们被告知旅行需要`t`分钟，但对于实际问题，只有到达时的电池百分比很重要。 当安娜到达目的地时，电池电量已耗尽`p`百分比。 从那一刻起，相同的放电规则继续下去，我们被问到电池电量为零还剩多少分钟。 

约束非常小，因此任何直接计算闭合形式表达式甚至逐分钟模拟的解决方案都足够快。 真正的挑战不是性能，而是正确处理 20% 边界处的消耗率变化。 

一个微妙的边缘情况是到达时电池电量已达到或低于 20%。 在这种情况下，手机已经处于慢速模式，因此不会发生额外的相变。 总是假设开关点为 20% 的简单解决方案会错误地添加一个从未存在的额外快速阶段。 

另一个潜在的错误来自于将该声明解释为依赖于`t`。 自从`t`仅描述了抵达前发生的情况，我们已经收到了电池`p`，任何依赖于`t`在最终的计算中是不必要的并导致错误的推理。 

## 方法

 电池电量消耗分为两个线性阶段。 在正常模式下，电池电量以每分钟 1% 的恒定速率下降。 一旦达到 20%，它就会切换到经济模式，速度减半，即每分钟 0.5%。 

暴力模拟会每分钟迭代，减少电池电量，并在电量超过 20% 时切换模式。 这是可行的，因为该过程是确定性的，但它没有必要详细，并且每个查询最多需要 100 个模拟单元。 虽然在约束下仍然微不足道，但它掩盖了问题的结构。 

关键的观察结果是该过程是分段线性的。 我们可以计算每个片段持续多长时间，而不是模拟时间。 从任何起始电池电量`p`，我们要么完全保持在节能模式下，要么首先遍历下降到 20% 的线性段，然后继续保持节能模式直到零。 

这将问题简化为最多计算两个算术表达式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(p) | O(1) | O(1) | 已接受 |
 | 分段公式| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.检查启动电池电量是否充足`p`都在20%以上。 这决定了我们是否会跨越模式边界。 
2.如果`p > 20`，计算从`p`正常模式下降至 20。 由于排水量为每分钟 1%，因此该持续时间为`p - 20`。 
3. 依然如此`p > 20`，计算在 Eco 模式下从 20 降到 0 的时间。 在环保模式下，排水速度减半，因此 20% 需要 40 分钟。 
4. 将两个持续时间相加即可得到总剩余时间。 
5. 如果`p ≤ 20`，手机到达时已处于节能模式，因此直接计算时间为`p / 0.5`，这相当于`2p`。 

这种分割起作用的原因是，到达后的电池演变完全由当前水平决定，而不取决于过去的旅程长度。 

### 为什么它有效

 该系统在具有单一阈值的两个线性状态下演化。 在每个状态下，电池电量都会以与历史无关的恒定速率下降。 一旦在零时间知道状态，未来的轨迹仅取决于初始值是高于还是低于阈值。 这使得归零时间计算相当于将分段函数的至多两个线性段的长度相加。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t, p = map(int, input().split())

    if p > 20:
        # normal mode down to 20
        time_normal = p - 20
        # eco mode from 20 to 0
        time_eco = 40
        ans = time_normal + time_eco
    else:
        # already in eco mode
        ans = 2 * p

    print(float(ans))

if __name__ == "__main__":
    solve()
```该实现直接反映了分段结构。 变量`t`已读取但未使用，因为它不影响到达后的剩余生命周期。 唯一的决定点是当前电池电量是否高于 20% 阈值。 这两个公式恰好对应于两个线性消耗阶段的持续时间。 

一个常见的错误是尝试传播最初的 100% 状态或再次模拟整个过程。 这是不必要的，因为问题已经提供了旅程后的状态`p`，这完全决定了未来的演变。

 ## 边缘情况

 一个关键的边缘情况是当`p`正好是 20。在这种情况下，电池已经处于切换边界，因此不应计算正常模式段。 

对于输入：`p = 20`该算法采用 eco 分支并计算`2 * 20 = 40`分钟。 任何错误地强制正常模式相位的方法都会减去不存在的时间。 

另一种边缘情况非常小`p`，例如 1 或 2。这些值完全保持在 Eco 模式下，并且线性缩放保持有效，没有任何隐藏的过渡。 

对于非常大的`p`接近 99 时，将激活完整的两阶段计算，并且正确性取决于对两个段进行正确求和，而无需重复计算阈值区域。
