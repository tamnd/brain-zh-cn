 ## 解决方案
 ## 问题理解

 我们有一棵树$n$城市。 每个城市都有一个语言标签$1$到$k$。 城市被划分为几个不相交的组，称为联盟，但划分是任意的并且不受树的边缘限制。 

对于任何一个固定的联盟，我们不仅仅看其中的城市。 我们还考虑位于联盟两个城市之间的任何最短路径上的所有树节点。 由于该结构是一棵树，这意味着我们实际上采用了跨越联盟中所有城市的最小连通子树。 该子树正是所选节点之间所有成对路径的并集。 

一旦我们有了这个导出子树，我们就会收集其任何节点中所说的所有语言。 联盟的成本仅取决于该子树中出现了多少种不同的语言。 如果$t$语言出现后，成本是一个几何递减的总和，从$2^k$， 然后$2^{k-1}$，依此类推$t$条款。 

我们不评估单个分区。 相反，我们必须考虑一切可能的方式来分割$n$将城市组成联盟，计算每个分区的总成本，然后将所有分区的这些值相加。 

关键的困难在于单个联盟隐式扩展为子树，因此其贡献不仅取决于所选节点，还取决于连接路径上的所有节点。 这通过树结构耦合节点子集。 

限制因素$n \le 5000$和$k \le 10$表明任何指数依赖$n$是不可能的，而像这样的多项式$O(n^2)$或者$O(n^2 k)$是有道理的。 非常小的$k$强烈建议语言信息应压缩为位掩码并独立于树组合进行处理。 

理解联盟时出现了一个微妙的陷阱。 同一联盟中的两个城市会自动强制将它们之间路径上的所有节点包含在“语言支持”集中。 忽略路径的天真的子集视图会低估语言的数量。 

## 方法

 一个直接的起点是考虑枚举所有分区。 即使对于一棵树来说，分区的数量也是贝尔数$B_n$，其增长速度超过指数。 因此，暴力枚举分区是不可行的。 

更结构化的观点是颠倒求和的顺序。 我们不是迭代分区并计算其成本，而是查看所有分区内每个联盟的贡献。 每个分区只是一组不相交的块，因此总答案成为被视为块的所有可能的顶点子集的总和，乘以包含该块的分区数量。 

修复一个子集$S$形成一个联盟的顶点。 如果该子集是分区中的一个块，则剩余的$n - |S|$顶点可以任意划分，贡献一个因子$B_{n-|S|}$。 因此，整个问题简化为对所有有效子集求和$S$， 期限$$B_{n-|S|} \cdot \text{cost}(S),$$在哪里$\text{cost}(S)$取决于归纳子树中存在的语言$S$。 

结构上的复杂性在于$\text{cost}(S)$取决于不取决于$S$直接，但是基于斯坦纳闭包$S$，即连接所有节点的最小子树$S$。 这么多不同的套装$S$折叠到相同的诱导子树$T$。 这表明通过连接的子树重新分组。 

对于固定连通子树$T$，所有子集$S \subseteq T$其 Steiner 闭包恰好等于$T$贡献相同的语言集。 所以我们可以考虑每项语言成本$T$，而是计算有多少个子集$S$里面$T$生成它，加权为$B_{n-|S|}$。 

此时，障碍在于重量取决于$|S|$，不仅仅是在$T$，所以我们不能将所有内容压缩为每个子树的单个计数。 这使得边缘上的完全包含-排除变得昂贵。 

关键的简化是将语言贡献与组合分开。 自从$k \le 10$，每种语言都可以独立处理。 如果块的导出子树中至少有一个节点携带该语言，则该语言对该块有贡献。 因此，我们只需要计算与给定语言的节点集相交的连接子树。 

这将问题转化为重复树DP：对于每种语言$\ell$，我们将所有包含至少一个标记节点的连接子树的贡献相加$\ell$，加权为$B_{n-s}$， 在哪里$s$是子树的大小。 

我们通过连接子树的标准树 DP 来计算这一点，按大小维护计数，并减去避开所有语言节点的子树$\ell$。 这些是修剪树中简单连接的子树，其中$\ell$- 节点被禁止。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力分区 | 指数（贝尔数）| 指数| 太慢了 |
 | 每种语言的子树 DP |$O(k \cdot n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 我们预处理贝尔数最多$n$，因为它们将用作权重，具体取决于所选联盟之外还有多少顶点。 

对于每种语言$\ell$，我们计算两个量：树的所有连通子树，以及避开每个带有语言的节点的连通子树$\ell$。 差异给出了至少包含一次出现的子树$\ell$。 

我们执行树DP，其中每个状态按大小对连接的子树进行计数。 DP 是有根的，每个子树都是通过合并子贡献来构建的。 强制唯一性的标准方法是对固定根中最高节点是根的连接子树进行计数，这避免了不同根之间的重复计算。 

1. 预先计算贝尔数$B[0 \ldots n]$模数$998244353$。 这允许我们为每个子树大小分配正确的权重。 
2. 对于每种语言$\ell$，标记所有没有语言的节点$\ell$。 这些节点在“无禁止”版本中是允许的，而带有语言的节点$\ell$仅在回避 DP 中被排除。 
3. 运行一个树DP，以两种变体的大小按大小对连接的子树进行计数：一种在完整树上，一种在修剪树上，其中$\ell$- 节点被删除。 DP 通过组合大小分布来合并子树，因为附加子树会额外增加大小。 
4. 对于每个尺寸$s$，计算至少包含一个的连接子树的数量$\ell$-节点为$$dp_{\text{all}}[s] - dp_{\text{avoid}}[s].$$5. 对于每个这样的子树大小$s$, 添加贡献$$(dp_{\text{all}}[s] - dp_{\text{avoid}}[s]) \cdot B[n-s] \cdot w_\ell,$$在哪里$w_\ell = 2^{k+1-rank(\ell)}$。 
6. 对所有语言求和。 

正确性取决于这样一个事实：每个联盟的贡献在语言上线性分割，并且语言的存在仅取决于连接的子树是否包含该语言的至少一个节点。 

### 为什么它有效

 每个分区通过其块独立贡献。 在语言支持意义上，每个块都唯一地扩展为连接的子树。 块的成本仅取决于该子树中出现的语言，并且每种语言对几何总和的贡献独立。 这种线性使我们能够将问题分解为计算每种语言在所有可能分区的连接子树中出现的频率。 贝尔因子考虑了一旦子树被固定为块后对剩余顶点进行分区的所有方法，确保每个全局分区都被精确地计数一次。

import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    bell = [0] * (n + 1)
    bell[0] = 1
    for i in range(1, n + 1):

第二个微妙点是减去每种语言的禁止子树。 这必须针对每种语言独立完成，因为$k$足够小以允许重复 DP 运行。 

## 工作示例

 ### 示例 1

 考虑一棵小树，其中三个节点排成一行，具有两种语言。 节点被标记，以便语言出现在两端。 

我们跟踪连接的子树以及它们是否包含给定的语言。 尺寸上的 DP 生成尺寸 1、尺寸 2 和尺寸 3 子树的计数。 对于每个尺寸，我们乘以相应的贝尔重量$B[n-s]$，它说明了如何对剩余节点进行分区。

 一棵星形树，有一个中心节点和几片叶子，除了一片叶子外，所有叶子都共享一种语言。

 ## 边缘情况

 单节点树是最简单的情况，其中每个分区都由孤立的块组成。 该算法简化为仅计算单例子树，并且每个这样的子树只贡献一种语言。 由于没有子合并，DP 彻底退化。 

语言交替的路径图确保每个连接的子树必须根据其跨度中出现的语言进行仔细分类。 DP 正确区分至少包含一次给定语言的子树和不包含该语言的子树，确保即使语言均匀分布时减法也能正确工作。 

星形树强调合并逻辑：每棵子树都由是否包含中心来决定。 DP 正确捕获所有非空连接子树包括中心或为单叶，这确保大小加权贡献与贝尔乘数一致。
