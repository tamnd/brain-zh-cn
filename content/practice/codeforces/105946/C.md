 ## 解决方案
 ## 问题理解

 每个测试用例都描述一个家庭，其中一组仆人必须完成一组家务。 每项家务都有所需的工作量，每个仆人每小时都会根据分配的方式贡献工作。 

仆人每小时总是为分配给他们的家务贡献 1 个工作单位。 此外，每个仆人都有一项“最喜欢”的家务活。 如果他们在给定的时间内被分配到特定的杂务，他们会变得更有效率，并在该小时内贡献 5 个单位而不是 1 个单位。 

管家总管每小时可以独立地重新分配所有仆人，并且多个仆人可以做同样的家务。 目标是选择按小时计算的任务，以便所有杂务在最短的时间内达到或超过其所需的工作量。 

关键的输入部分是专业化列表，它告诉每个仆人他们负责哪些杂务，以及每个杂务所需的工作值。 输出是在最佳调度下完成所有杂务所需的最少小时数。 

约束很小：最多 100 个仆人和 100 项杂务，工作要求也以 100 为限。这强烈表明该解决方案不需要大量的优化结构或大的状态空间。 只要每个步骤的逻辑简单，任何涉及数小时模拟或每项工作聚合的方法都是可行的。 

当某些家务根本没有专门的仆人时，就会出现一种微妙的边缘情况。 在这种情况下，这项杂务只能使用通用的 1 单位贡献来完成，这可能会迫使完成时间更长。 另一个重要的情况是，当一项家务有许多专门的仆人时，使其比其他家务快得多，这可以主导整个日程。 

## 方法

 思考问题的一个直接方法是逐小时进行模拟。 每个小时，我们都会选择一个仆人来执行家务，并计算每个家务需要承担多少工作。 我们重复此操作，直到所有杂务完成。 这是正确的，但分支因子是巨大的，因为每个仆人每小时都可以选择任何杂务，因此每小时可能的任务数量为 c^n。 即使 n = 100，这也是完全不可行的。 

问题的结构可以更加简化。 无论如何，每个仆人每小时贡献 1 个单位的基线，并且在分配给自己的杂务时只会获得额外的 4 个单位。 这意味着系统中唯一的“额外权力”来自于将仆人与他们喜欢的家务相匹配。 

我们可以对每件琐事进行推理，而不是全局地考虑每小时的任务。 如果一项家务活有 mi 名专门从事这项工作的仆人，那么如果我们正确分配他们，每小时我们可以保证每个这样的仆人都能做出 5 的贡献。 所有剩余的仆人仍然可以每人贡献 1 个单位，但是这个基准贡献在各个杂务中是统一的，并且始终可以自由地重新分配。 

这引出了一个关键的观察结果：在最佳的时间表中，没有理由减少专家在自己的家务上的使用，因为将他们移走每小时会损失 4 个单位的生产力，而在其他地方只会增加 1 个单位。 因此，每项杂务实际上都有所有正常工作的仆人的固定每小时生产能力，加上其专家的额外奖金。 

从这个角度来看，每项杂务 i 每小时收到 n 单位的基线工作（每个仆人一份），加上每个专业为 i 的仆人额外的 4 单位。 每小时有效率为：

 n + 4 · 米

 一旦这个速率固定，每项杂务所需的时间就变得独立，并且总体答案由最慢的杂务决定。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 所有任务的暴力破解小时模拟 指数| O(1) | O(1) | 太慢了|
 | 计算每项工作的速率 n + 4·mi 并取 max ceil | O(n + c) | O(1) | O(1) | 已接受 |

 ## 算法演练

 ### 算法演练

 1. 计算每项家务 i 有多少个仆人专门从事这项工作。 将此值称为 mi。 这反映了有多少工人可以为这项杂务提高产出。 
2. 请注意，无论分配如何，每个仆人每小时贡献 1 个工作单位。 这意味着如果我们以最佳方式分配工人，每项杂务实际上都会收到每小时 n 单位的统一基线。 
3. 增加专业化优势：每个分配给自己杂务的仆人在基线之外贡献 4 个额外单位。 由于有 mi 个这样的仆人来做家务 i，因此每小时可用于该家务的额外贡献是 4·mi。 
4. 结合基线和奖励来计算杂务 i 每小时可实现的最大进度为 n + 4 · mi。 
5. 计算每项杂务所需的时间 ceil(wi / (n + 4 · mi))。 
6. 最终的答案是所有杂务中最大的一个，因为所有的事情都必须完成。 

### 为什么它有效

 关键的不变量是每个仆人每小时总是生产 1 个单位，唯一可控的优势是该仆人是否被安排做自己的家务，获得额外的 4 个单位。 由于重新分配一名专业仆人离开他们的家务严格会使总生产力降低 4 个单位，因此任何最佳时间表都不会永久牺牲专业化增益，除非家务已经完成。 这保证了每个杂务的有效吞吐量都可以使用其全套专家进行独立处理，并且除了平衡这些独立的速率之外，任何杂务之间的权衡都无法提高最大完成时间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, c = map(int, input().split())
        s = list(map(int, input().split()))
        w = list(map(int, input().split()))
        
        cnt = [0] * (c + 1)
        for x in s:
            cnt[x] += 1
        
        ans = 0
        for i in range(1, c + 1):
            rate = n + 4 * cnt[i]
            need = (w[i - 1] + rate - 1) // rate
            ans = max(ans, need)
        
        print(ans)

if __name__ == "__main__":
    solve()
```该代码首先构建一个频率表，显示有多少仆人专门从事每项家务。 这是分配约束所需的唯一结构信息。 

对于每项杂务，它计算每小时的有效贡献为 n + 4 · mi。 然后使用整数上限除法计算总时间，因为不允许使用部分时间。 

最终的答案是所有杂务中的最大答案，因为所有杂务都必须完成。 

一个常见的实现陷阱是忘记输入中的杂务是 1 索引的，而 Python 中的数组是 0 索引的，这是通过在读取 wi 时减一来处理的。

 ## 边缘情况

 当家务活没有专门的仆人时，就会出现极端情况。 在这种情况下，mi = 0，因此其速率变为n。 该算法自然地通过只给出基线贡献来处理这个问题，这正确地反映了不存在任何奖励来加速它。 

另一种情况是所有仆人都专门做同样的家务。 然后，一项杂务获得了非常高的支持率，而其他杂务仅获得基线支持。 该公式仍然适用，并且最大杂务数正确地识别了专门杂务或其他杂务是否主导了完成时间。 

最后，当所有 wi 都很小时，在大多数情况下即使一个小时也足够了。 整数上限除法确保任何非零要求仍然正确舍入，避免低估完成时间。
