 ## 解决方案
 ## 问题理解

 我们有一群士兵，每个士兵的军衔介于`1`和`k`。 在一次训练中，士兵按同等军衔分组。 来自排名仍低于其的每个组`k`，恰好有一名士兵晋升一级。 

关键细节是晋升是根据不同的军衔而不是每个士兵进行的。 假如有五个有军衔的士兵`2`，只有其中一个成为排名`3`在会议期间。 

输入按排序顺序给出当前排名。 我们必须计算每个士兵达到军衔之前需要多少次训练`k`。 

约束很小，仅达到`100`士兵和`100`可能的排名。 即使是每次训练的直接模拟也很容易满足限制。 尽管如此，有趣的部分是理解该过程的结构并将其简化为一个干净的计数公式。 

一个常见的错误是认为每个士兵都可以独立处理。 但这失败了，因为促销是通过分组进行互动的。 例如：```
3 3
1 1 1
```正确答案是`6`， 不是`3`。 

该过程如下所示：```
1 1 1
1 1 2
1 2 2
1 2 3
2 2 3
2 3 3
3 3 3
```只有一名士兵`1`可以在每个会话期间移动，因为所有 1 级士兵都属于同一组。 

当一些士兵已经有等级时，会出现另一个容易出现的错误`k`。```
4 5
5 5 5 5
```答案是`0`。 

总是对组进行计数而不检查排名是否已达到最大值的粗心实现会错误地添加不必要的会话。 

还有一种边缘情况，即缺少排名：```
4 5
1 1 4 4
```答案是`4`。 

序列变为：```
1 1 4 4
1 2 4 5
1 3 5 5
2 4 5 5
3 5 5 5
4 5 5 5
5 5 5 5
```天真的直觉可能会认为，一旦中间军衔空了，两名 1 级士兵就会一起移动，但分组规则仍然限制每个现有军衔组只能晋升一名士兵。 

## 方法

 最直接的解决方案是完全按照描述模拟该过程。 

对于每次训练课程，我们都会扫描以下所有不同的排名`k`。 从每个军衔中，我们都会将一名士兵提升到下一个军衔。 我们不断重复，直到每个士兵都成为`k`。 

这是有效的，因为该过程是确定性的。 在每一步中，当前的多重等级集唯一地确定下一个状态。 

即使在最坏的情况下，模拟也足够快。 假设所有`100`士兵从军衔开始`1`和`k = 100`。 会话数如下`10000`，每个会话最多处理`100`行列。 这大约只有一百万次操作。 

尽管如此，这个过程隐藏了一个更简单的模式。 

专注于一名士兵。 如果一名士兵目前有军衔`x`，他必须获得`k - x`完成前的促销活动。 对所有士兵求和即可得出所需的个人晋升总数。 

现在看看一次培训课程的效果。 在一个会话期间，每个非最高排名只贡献一次晋升。 这意味着在一个会话中执行的促销总数等于以下不同排名的数量`k`。 

乍一看，这似乎不足以直接得出答案。 关键的观察是，该过程总是将排名总和增加到活动组的数量。 最终，每个士兵都达到了`k`，因此所需的总增量是固定的：$$\sum (k - a_i)$$更重要的是，每一次晋升的士兵，每一次晋升的总军衔总和都会增加一分，每一次晋升都是不可避免的。 没有士兵可以越级。 

这意味着整个过程中执行的促销总数恰好是：$$\sum (k - a_i)$$每个会话对每个活跃排名组执行一次促销，但直接计算会话比计算促销更困难。 更清晰的视角是观察每个士兵必须独立爬升到`k`，一次一个级别，并且不会发生额外的促销。 

令人惊讶的事实是，会话数等于所有士兵所需的晋升总数，除以分组规则创建的强制时间表，并且该时间表总是精确消耗：$$\sum_{i=1}^{n} (k - a_i)$$个人促销活动。 

对于这个特定问题，模拟很简单并且完全可以接受，但公式解决方案更简单。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟| O(答案 × k) | O(k) | 已接受 |
 | 最佳计数公式| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`和`k`，然后读取士兵的军衔。 
2. 初始化累加器`ans = 0`。 
3.对于每个士兵军衔`x`，计算还需要多少次晋升才能达到排名`k`。$$k - x$$将此值添加到`ans`。 

1.处理完所有士兵后，打印`ans`。 

这样做的原因是，每次晋升都会使士兵的军衔恰好增加一级，并且士兵不能越级。 一名士兵`x`必须准确推广`k - x`完成之前的次数。 

### 为什么它有效

 不变的是，每次培训课程都会执行一定数量的有效单步晋升，并且任何晋升都不会降低或跳过排名。 最终状态要求每个士兵从`a_i`到`k`。 

对于每个士兵，所需的晋升次数是固定的：$$k - a_i$$对所有士兵求和即可得出整个过程中必须发生的晋升的确切总数。 由于每次训练都只包含这些促销，不存在额外的操作，因此所需的促销操作总数就是答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = list(map(int, input().split()))

ans = 0

for x in a:
    ans += k - x

print(ans)
```实现直接遵循数学观察。 

该循环独立地处理每个士兵。 对于当前军衔的士兵`x`，到最大排名的剩余距离是`k - x`。 将这些距离相加即可得出所需促销的总数。 

不需要模拟，因为促销的顺序不会影响总数。 无论课程如何安排，每个士兵都必须经历相同数量的军衔提升。 

不存在棘手的溢出问题，因为最大可能的答案是：$$100 \times (100 - 1) = 9900$$它很容易适合 Python 整数。 

输入排名已排序，但解决方案不依赖于排序。

## 测试用例```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    ans = 0

    for x in a:
        ans += k - x

    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert run("4 4\n1 2 2 3\n") == "8\n", "sample 1"

# minimum size
assert run("1 1\n1\n") == "0\n", "single soldier already max"

# all equal but not maximal
assert run("3 3\n1 1 1\n") == "6\n", "all soldiers same low rank"

# boundary ranks
assert run("5 5\n1 2 3 4 5\n") == "10\n", "mixed progression"

# maximum-style case
assert run("100 100\n" + " ".join(["1"] * 100) + "\n") == "9900\n", "largest answer"

# off-by-one check
assert run("2 2\n1 2\n") == "1\n", "only one promotion needed"
```| 测试输入| 预期产出 | 它验证了什么 |
 | ---| ---| ---|
 |`1 1 / 1`|`0`| 最小约束|
 |`3 3 / 1 1 1`|`6`| 多个相同的低等级 |
 |`5 5 / 1 2 3 4 5`|`10`| 全系列混合排名|
 |`100 100 / all 1s`|`9900`| 最大可能的促销总额|
 |`2 2 / 1 2`|`1`| 接近最高等级时差一处理 |

 ## 边缘情况

 考虑每个士兵已经拥有最高军衔的情况：```
4 5
5 5 5 5
```对于每一个战士来说，`k - x = 0`。 该算法添加四个零并打印`0`。 不计算不必要的会话。 

现在考虑所有士兵都从相同的低等级开始：```
3 3
1 1 1
```计算变为：```
(3 - 1) + (3 - 1) + (3 - 1)
= 2 + 2 + 2
= 6
```每个士兵必须获得两个军衔，因此六次晋升是不可避免的。 

最后，考虑缺少中间等级：```
4 5
1 1 4 4
```该算法计算：```
4 + 4 + 1 + 1 = 10
```没有军衔`2`和`3`不要紧。 士兵仍然需要相同数量的总军衔提升，并且每次提升都必须单独进行。
