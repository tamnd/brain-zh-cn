 ## 解决方案
 ## 问题理解

 我们得到了一个代表会议上探索空间的二维网格。 网格中的每个单元格都是一个顶点，每对相邻的顶点（上、下、左、右）都由一条边连接，边的权重表示沿该边的展品数量。 沿着边缘行走会因为上面的展品数量而增加你的“无聊感”。 

对于每个起始单元，我们被要求确定通过精确步行而产生的最小总无聊度$k$在同一单元格开始和结束的步骤。 你不能在原地停留一步，并且你可以多次穿越任何边缘，每次都数一下它的展品。 如果无法准确返回起始单元格$k$步骤，答案应该是$-1$。 

限制是网格可以大到$500 \times 500$和$k$可以达到$20$。 尝试所有长度路径的暴力方法$k$来自每个单元的路径都是不可行的，因为可能的路径数量呈指数增长$k$，网格大小会进一步增加这个值。 我们需要一种利用小最大值的方法$k$以避免明确地迭代每个路径。 

当以下情况出现时，会出现一个关键的边缘情况：$k$很奇怪。 由于我们必须在同一个单元格开始和结束，因此任何有效路径都必须由偶数步组成（奇数长度的步行无法返回到具有曼哈顿距离的网格上的起点）。 不考虑奇偶校验的简单实现可能会尝试对奇数进行不可能的计算$k$，产生不正确的值或运行时错误。 

另一个微妙之处是每条边都是双向的，但其成本在任一方向上都是相同的。 粗心的方法可能会重复计算边缘或在构建 DP 转换时无法考虑两个方向。 

## 方法

 蛮力方法将精确地枚举所有序列$k$从每个单元格开始移动，对沿每条路径的展示求和，并跟踪每个起始单元格的最小值。 这在原则上是正确的，但完全不切实际。 和$k \leq 20$和$n, m \leq 500$，每个单元的路径数大致为$4^k$，并且有$n \cdot m$单元格，给出操作计数$500 \cdot 500 \cdot 4^{20}$，这是一个天文数字。 

关键的见解是因为$k \leq 20$，我们可以对步数使用动态规划。 让$dp[s][i][j]$表示到达单元格的最小无聊度$(i, j)$正好在$s$从该单元格开始的步骤。 每一步都可以移动到四个邻居之一，并且成本会增加沿该边缘的展品。 因为网格是无向的并且边权重双向相同，所以转换很简单：对于每个单元格，$dp[s][i][j]$是最小值$dp[s-1][neighbor] + cost\_edge$超过所有有效的邻居。 我们只需要计算到$k/2$步骤因为往返长度$k$可以分成两半，每一半的长度$k/2$。 每个单元格的最终答案是$2 \times dp[k/2][i][j]$。 这大大减少了 DP 状态的数量：$k/2 \cdot n \cdot m$而不是$4^k \cdot n \cdot m$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(4^k * n * m) | O(4^k * n * m) | O(n * m) | 太慢了|
 | 动态规划| O(k * n * m) | O(n * m) | 已接受 |

 ## 算法演练

 1. 首先，读取输入并将水平和垂直边缘权重存储在单独的 2D 数组中。 这使得获取任意两个相邻单元之间的边缘权重变得容易。 
2. 检查是否$k$很奇怪。 如果是，则输出$-1$对于每个单元格并停止，因为奇数长度的步行不能仅使用单位步长返回到网格中的起点。 
3.初始化一个大小为DP的数组$n \times m$，其中每个元素代表在当前步数中到达该单元格的最小无聊度。 最初，所有值都为零，因为零步数导致零无聊。 
4.循环$steps = 1$到$k/2$。 对于每个步骤，创建一个相同大小的临时 DP 数组以保存新的最小值。 对于每个单元格$(i, j)$，将临时DP值更新为当前DP值加上移动到每个有效邻居的边权重的最小值。 
5.完成后$k/2$迭代中，DP 数组包含精确到达每个单元格的最小无聊度$k/2$远离自身。 将每个值乘以 2 以计算回程，得出最终答案。 
6. 输出最终的 DP 数组，正确格式化每一行。 

为什么它有效：DP 不变量是之后$s$迭代，$dp[i][j]$保持到达细胞的最小无聊度$(i, j)$正好在$s$步骤。 通过仅使用邻居及其边缘成本进行转换，我们可以正确捕获所有有效路径。 因为网格是无向的，任何长度的路径$k$返回起点可以将长度分成两半$k/2$，因此将半路径成本加倍即可得到正确的总无聊度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m, k = map(int, input().split())
h_edges = [list(map(int, input().split())) for _ in range(n)]
v_edges = [list(map(int, input().split())) for _ in range(n-1)]

if k % 2 == 1:
    for _ in range(n):
        print(' '.join(['-1'] * m))
    sys.exit()

dp = [[0]*m for _ in range(n)]
half_k = k // 2

for step in range(half_k):
    new_dp = [[float('inf')]*m for _ in range(n)]
    for i in range(n):
        for j in range(m):
            if i > 0:
                new_dp[i][j] = min(new_dp[i][j], dp[i-1][j] + v_edges[i-1][j])
            if i < n-1:
                new_dp[i][j] = min(new_dp[i][j], dp[i+1][j] + v_edges[i][j])
            if j > 0:
                new_dp[i][j] = min(new_dp[i][j], dp[i][j-1] + h_edges[i][j-1])
            if j < m-1:
                new_dp[i][j] = min(new_dp[i][j], dp[i][j+1] + h_edges[i][j])
    dp = new_dp

for i in range(n):
    print(' '.join(str(dp[i][j]*2) for j in range(m)))
```该代码首先分别读取和存储水平和垂直边缘权重，从而简化邻居查找。 我们立即处理异常情况$k$以避免不必要的计算。 DP循环迭代$k/2$次，以最小的移动到邻居的无聊感来更新每个单元。 最后乘以 2 即可得出返回路径。 

边界条件经过仔细处理：代码检查索引在向上、向下、向左或向右移动时是否超出范围。 使用`float('inf')`确保最小操作正确运行，没有初始偏差。
