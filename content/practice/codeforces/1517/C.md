 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$棋盘的下三角部分，其中只有对角线及其下方的单元格很重要。 在主对角线上，每个单元格包含一个从 1 到$n$，形成一个排列。 任务是将对角线下方和对角线上的单元精确地划分为$n$连接区域，每个数字对应 1 到$n$。 每个区域必须包括具有该数字的对角单元格，并且必须包含与该数字本身一样多的单元格。 最后，对角线下方的所有单元格必须恰好属于一个区域。 

从输入大小约束$n \le 500$，我们知道对角线下方和对角线上的单元格总数为$\frac{n(n+1)}{2}$，最大可达 125,000 左右。 这足够小以允许$O(n^2)$算法，但任何嵌套在另一个算法中的二次或更高的算法$O(n^2)$循环会太慢。 因此，一个$O(n^2)$或者预计会有更好的解决方案。 

非明显的边缘情况包括最小的$n=1$或者当最大的数字出现在对角线的底部时，这可能会迫使区域向下或向左生长而不重叠。 粗心的贪婪放置可能会超出界限或无法创建连接区域。 例如，如果数字 3 出现在第一行，我们必须从该单元格扩展区域以覆盖相连方向上的三个单元格，避免其他对角线数字。 管理不当会产生不正确的分区。 

## 方法

 暴力方法将尝试所有可能的方法来从对角单元格开始填充每个区域。 这将涉及递归地探索与生长区域相邻的每个空单元，直到达到所需的大小。 这种方法原则上是正确的，因为它详尽地测试了所有有效的连接形状，但速度慢得令人绝望。 为了$n=500$，要填充的单元格数量约为 125,000 个，并且递归路径的数量随着区域大小呈指数增长，使其不可行。 

关键的见解是，每个区域总是可以通过从对角单元向左或向下扩展来贪婪地填充，如果可能的话最好向下扩展。 该板是下三角形的，因此向右或向上移动是不可能的，或者会与未分配的对角线单元相碰撞。 因此，简单的贪婪 DFS 或迭代填充将始终找到有效的连通区域（如果存在）。 诀窍是按照对角线上出现的顺序处理区域，并在区域达到所需大小时停止填充。 该方法利用下三角结构来保证连通性，而无需复杂的回溯。

 | 蛮力 | O(指数) | O(n^2) | O(n^2) | 太慢了|

 ## 算法演练

 1. 阅读$n$以及对角线上的排列$p_1, \dots, p_n$。 初始化一个二维数组`board`尺寸的$n \times n$充满零。 这将存储区域的最终分配。 
2.从上到下迭代对角线单元格，处理每个单元格对应的区域$p_i$。 
3. 对于每个对角单元格$(i, i)$有号码$v = p_i$， 放`board[i][i] = v`并初始化一个计数器`remaining = v - 1`，代表该区域还需要多少个单元格。 
4. 使用贪婪扩展策略：从当前单元格开始，如果单元格为空，则首先尝试在同一行内向左移动，否则向下移动到同一列的下一行。 将区域编号分配给每个访问的单元格并递减`remaining`。 重复直到`remaining`达到零。 
5. 如果在任何一点都没有有效的单元格可以扩展（即，左侧出界或被占用，向下出界或被占用），则该解决方案是不可能的； 输出`-1`。 
6. 处理完所有对角线单元后，逐行打印电路板。 每行$i$应该只打印第一个$i$列，对应于下三角部分。 

为什么有效：在每一步中，扩展都保证保持连接，因为我们只从已分配的单元格移动到相邻的空单元格。 先左后下的贪婪偏好确保该区域适合三角形边界并避免与其他对角线单元重叠。 由于每个对角线数字都是独立处理的，并且区域永远不会相互覆盖，因此可以保持连接性和正确区域大小的不变量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
p = list(map(int, input().split()))

board = [[0] * n for _ in range(n)]

for i in range(n):
    val = p[i]
    x, y = i, i
    board[x][y] = val
    remaining = val - 1
    while remaining > 0:
        if y > 0 and board[x][y-1] == 0:
            y -= 1
        elif x + 1 < n and board[x+1][y] == 0:
            x += 1
        else:
            print(-1)
            sys.exit(0)
        board[x][y] = val
        remaining -= 1

for i in range(n):
    print(" ".join(map(str, board[i][:i+1])))
```第一部分读取输入并初始化电路板。 主循环迭代每个对角线元素，将该区域放置在其起始单元中。 如果可能的话，内部 while 循环贪婪地向左扩展，否则向下扩展。 如果两种移动都不可能，则发生失败情况。 最后，仅打印相关的下三角部分。

import sys, io

def run(inp: str) -> str:

    n = int(input())
    p = list(map(int, input().split()))
    board = [[0]*n for _ in range(n)]
    for i in range(n):
        val = p[i]
        x, y = i, i
        board[x][y] = val
        remaining = val-1
        while remaining > 0:
            if y > 0 and board[x][y-1] == 0:
                y -= 1
            elif x+1 < n and board[x+1][y] == 0:
                x += 1
            else:
                return "-1"
            board[x][y] = val
            remaining -= 1
    return "\n".join(" ".join(map(str, board[i][:i+1])) for i in range(n))
