 ## 解决方案
 ## 问题理解

 我们给出了一系列真实值$b_1, b_2, \ldots, b_n$，这可以解释为飞机在$n$检查站。 每个检查点都限制允许的高度范围，因此每个$b_i$必须位于固定区间内。 在连续的检查点之间，高度的变化也是受到限制的，因此每个第一差值$b_i - b_{i-1}$必须位于其自己的区间内。 最后，这些变化的变化也是有界的，所以第二个区别$(b_i - b_{i-1}) - (b_{i-1} - b_{i-2})$也受到限制。 

任务不是构造序列，只是确定是否存在至少一个满足所有这些区间约束的实值序列。 

这是一维链上的线性不等式系统，但二阶差分约束的存在使其明显强于标准差分约束图。 每个$b_i$不仅与它的邻居有关，而且与斜坡的演变有关。 

约束规模很大，最多可达$2 \cdot 10^5$全部的$n$跨测试用例。 任何试图在所有变量上明确保持完整几何可行性的解决方案都会太慢。 这迫使我们采用线性时间传播或区间动态规划式推理。 

一个关键的微妙之处在于值是真实的，并且问题陈述保证无穷小的扰动不会影响答案。 这是一个强烈的暗示，即不需要以符号方式处理来自精确等式链的简并，并且可以忽略具有开/闭歧义的区间传播。 

一种幼稚的方法会尝试在尊重约束的同时按顺序分配值，但这可能会在早期贪婪决策阻碍后续可行性的示例中失败。 例如，如果所有$b_i \in [0,1]$所有的差异都被迫$1$, 贪心赋值集$b_1 = 0, b_2 = 1$，但随后$b_3 = 2$立即违反其界限。 失败来自于没有跟踪每一步不仅限制当前值，而且限制未来的斜率空间。 

另一种不正确的方法是将每个约束独立地视为相邻对之间的区间可行性。 这忽略了第二个差异，即使每个局部约束都可以单独满足，第二个差异也会默默地迫使全局不一致。 

正确的方法必须不仅仅传播可能的值$b_i$，还有可行的斜率范围，并且必须确保这些斜率范围在整个链上的一致性。 

## 方法

 暴力方法会将其视为一个连续的可行性问题$n$变量和$O(n)$约束，然后尝试使用通用线性规划技术或具有精确算术的约束传播来解决它。 人们可以想象迭代地细化所有的界限$b_i$直至收敛。 每次迭代都会扫描所有约束并收紧间隔。 

原则上这是可行的，因为系统是凸的，但在最坏的情况下，它可能需要许多松弛轮次。 如果每趟费用$O(n)$，即使是一个谦虚的$O(n)$迭代次数导致$O(n^2)$的行为，这是不可能的$n = 2 \cdot 10^5$。 

关键的结构见解是二阶差分约束允许我们使用斜率变量对问题进行建模。 如果我们定义$d_i = b_i - b_{i-1}$，那么所有约束都成为局部约束$(b_i, d_i)$，更重要的是，二阶差分约束成为连续斜率的约束：$$d_{i+1} - d_i \in [z_{i+1}^-, z_{i+1}^+].$$这将问题转化为维持沿链演化的二态系统的可行区间：位置和斜率。 位置受区间边界约束，斜率受一阶差分和二阶差分边界约束。 

关键的观察是我们不需要精确的可能状态集。 每一步的可行性区域都是凸的$(b_i, d_i)$，因此可以表示为有界区间$b_i$与间隔配对$d_i$，用一致性约束将它们联系起来。 

这将问题简化为向前传播区间 DP，其中每一步都会变换一个允许的区域$(b_{i-1}, d_{i-1})$进入$(b_i, d_i)$在线性约束下，然后与给定边界相交。

 | --- | --- | --- | --- |
 | 蛮力（迭代松弛）|$O(n^2)$|$O(n)$| 太慢了|
 | 位置和坡度上的间隔 DP |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们跟踪当前高度和当前坡度的可行范围。 在步骤$i$，我们维持一个区间$[L_i, R_i]$的可能值$b_i$，和一个区间$[D_i^-, D_i^+]$对于可能的斜坡$d_i = b_i - b_{i-1}$。 

1. 将第一个位置间隔初始化为$[x_1^-, x_1^+]$。 这是唯一的限制$b_1$，因为不存在先前的点来定义斜率。 
2. 使用位置约束和一阶差分约束初始化第二个点。 我们推导出所有可能的$b_2$使得存在$b_1 \in [L_1, R_1]$和$b_2 - b_1 \in [y_2^-, y_2^+]$。 这产生了一个派生区间$b_2$并隐式定义可能的斜率$d_2$。 
3. 对于每个$i \ge 3$，我们首先计算可能的斜率范围$d_i$通过相交：

 先前斜率范围的偏移$[D_{i-1}^- + z_i^-, D_{i-1}^+ + z_i^+]$与直接约束$y_i^- \le d_i \le y_i^+$。 

此步骤确保一阶差分和二阶差分之间的一致性。 
4. 一旦斜率区间已知，我们就可以计算可达区间$b_i$通过将前一个位置间隔移动斜率间隔：$$b_i \in [L_{i-1} + D_i^-, R_{i-1} + D_i^+]$$并与相交$[x_i^-, x_i^+]$。 

此步骤强制选择的斜率实际上可以产生有效的位置。 
5. 如果在任何点位置区间或斜率区间变空，则系统不可行。 
6. 处理完所有索引后，如果我们从未得到空区间，则答案是“是”。 

关键的推理步骤是斜率完全决定位置演化，而二阶差分线性约束斜率演化，因此所有可行的配置在整个传播过程中都保持凸区间。 

### 为什么它有效

 在每个索引处$i$，我们保持所有可行部分解的不变性$i$可以由与到目前为止所有约束一致的可能位置区间和可能斜率区间来表示。 更新步骤精确计算该可行集在线性过渡下的图像$i-1$到$i$，然后与局部约束相交。 因为所有约束都是线性不等式，所以可行集仍然是凸的，并且它在每个坐标上的投影仍然是一个区间。 这保证了区间压缩不会丢失任何可行解，并且任何空区间都对应于真正的不可行。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        
        xL = [0] * (n + 1)
        xR = [0] * (n + 1)
        for i in range(1, n + 1):
            xL[i], xR[i] = map(int, input().split())
        
        yL = [0] * (n + 1)
        yR = [0] * (n + 1)
        for i in range(2, n + 1):
            yL[i], yR[i] = map(int, input().split())
        
        zL = [0] * (n + 1)
        zR = [0] * (n + 1)
        for i in range(3, n + 1):
            zL[i], zR[i] = map(int, input().split())

        # feasible range for b1
        Lb = xL[1]
        Rb = xR[1]

        # no slope defined yet, but we infer d2 from first step
        if n >= 2:
            # compute feasible b2 from b1 and y2
            newL = Lb + yL[2]
            newR = Rb + yR[2]
            Lb2 = max(xL[2], newL)
            Rb2 = min(xR[2], newR)

            if Lb2 > Rb2:
                print("NO")
                continue

            # slope d2 range induced by b2 - b1
            dL = yL[2]
            dR = yR[2]

            Lb, Rb = Lb2, Rb2
        else:
            print("YES")
            continue

        # slope interval
        dL_cur, dR_cur = dL, dR

        ok = True

        for i in range(3, n + 1):
            # update slope using second difference
            ndL = max(yL[i], dL_cur + zL[i])
            ndR = min(yR[i], dR_cur + zR[i])

            if ndL > ndR:
                ok = False
                break

            dL_cur, dR_cur = ndL, ndR

            # update position
            newL = Lb + dL_cur
            newR = Rb + dR_cur

            Lb = max(xL[i], newL)
            Rb = min(xR[i], newR)

            if Lb > Rb:
                ok = False
                break

        print("YES" if ok else "NO")

solve()
```该代码维护两个演变区间：一种用于可行高度，另一种用于可行坡度。 首先使用一阶差分约束和来自先前斜率范围的二阶差分传播来更新斜率区间。 然后，高度间隔相应地移动并与允许的边界相交。 

一个微妙的点是斜率传播必须与直接传播相交$y_i$用于更新位置之前的约束； 否则，人们可能会高估可达到的高度，并错误地使不可行的配置保持活动状态。 

更新的顺序很重要，因为坡度可行性定义了可达到的位移，只有在此之后才能安全地检查位置可行性。

 ## 边缘情况

 当所有的情况发生时，就会出现临界边缘情况$b_i$间隔折叠为单个值。 在这种情况下，该算法有效地检查所有引入的斜率和二阶差是否与固定几何形状一致。 当所需的斜率与固定差异相矛盾时，间隔更新会立即检测到不匹配，从而导致早期拒绝。 

另一种情况是斜率间隔很宽但二阶差很窄。 尽管每个步骤单独允许多个斜率，但斜率间隔的传播将逐渐缩小它们，直到发生收敛或空交点。 这可以防止隐藏的远程不一致。 

第三种情况是二阶差分到处都为零。 然后斜率必须保持恒定，并且算法简化为检查单个仿射级数是否适合所有位置间隔。 区间传播自然保持固定的斜率带，可行性纯粹由平移区间的重叠决定。
