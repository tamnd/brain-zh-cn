 ## 解决方案
 ## 问题理解

 我们得到一个整数对的集合，每个元素的范围从 1 到某个上限$n$。 我们的任务是判断是否存在两个整数$x$和$y$使得每一对至少包含这两个整数中的一个。 换句话说，$x$或者$y$必须“覆盖”每一对。 如果存在这样的选择，我们打印“YES”； 否则，“否”。 

约束很严格：$n$和$m$每个可以大到300,000。 这立即排除了会迭代所有可能的暴力方法$(x, y)$配对$O(n^2)$时间，这可能是$9 \cdot 10^{10}$运营。 相反，我们需要利用对的结构来避免明确考虑所有组合。 

当许多对共享相同的元素时，就会出现微妙的边缘情况。 例如，如果第一对是$(1, 2)$，人们可能会过早地选择$x = 1$并尝试找到$y$其他地方，但其他对喜欢$(3, 4)$将使该选择无效。 另一个棘手的情况是，当存在多个候选对来覆盖对的不同子集，但没有单一选择时$x$和$y$涵盖所有。 例如，输入：```
4 3
1 2
3 4
1 3
```即使每一对似乎与候选人“兼容”，也没有解决方案$x$或者$y$。 

## 方法

 蛮力方法很简单：迭代所有$(x, y)$与$x < y$并检查每个输入对是否至少包含其中一个。 这将涉及$O(n^2 \cdot m)$操作，这对于$n, m \sim 3 \cdot 10^5$。 每个候选对的检查是线性的$m$，但候选对的二次数量令人望而却步。 

关键的观察是第一个输入对，$(a_1, b_1)$，必须至少包含一个候选解。 如果存在解决方案，则$x = a_1$或者$x = b_1$（或者可能$y = a_1$或者$y = b_1$）。 这大大减少了我们需要检查的候选对的数量。 我们只需要尝试从第一对和与其冲突的对中导出的一小部分可能性。 

该算法通过假设进行$x$等于第一个元素$a_1$，并尝试寻找合适的$y$覆盖所有剩余的尚未包含的对$a_1$。 如果没有这样的$y$存在，我们重复该过程，假设$x = b_1$。 我们还检查涉及未涵盖的第一个“有问题”对的组合$x$。 这将候选对减少到最多四次检查，从而使算法高效。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 * m) | O(n^2 * m) | O(米) | 太慢了 |
 | 最佳| O(米) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 拿第一对$(a_1, b_1)$并尝试假设$x = a_1$。 识别所有不包含的对$a_1$。 如果没有的话，有任何$y \neq x$就足够了，答案是“是”。 
2. 在未覆盖的对中，取第一对，例如$(c, d)$，并尝试$y = c$或者$y = d$。 检查剩余的每一对是否至少包含以下之一$x = a_1$或者$y$。 如果是，则返回“YES”。 
3. 如果找不到解决方案$x = a_1$，重复相同的过程$x = b_1$。 
4. 如果两个选择都没有产生有效的结果$y$，返回“否”。 

为什么它有效：该算法依赖于以下至少一项的不变量：$x$或者$y$必须出现在每对中。 通过锚定$x$在第一对的一个元素上，我们将问题简化为找到单个兼容的$y$。 由于任何解决方案都必须包含第一对中的至少一个元素，因此尝试这四个候选方案是详尽无遗的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def check(x, pairs):
    y_candidates = []
    for a, b in pairs:
        if a != x and b != x:
            y_candidates.append((a, b))
    if not y_candidates:
        return True
    c, d = y_candidates[0]
    for y in (c, d):
        if all(x in p or y in p for p in pairs):
            return True
    return False

def main():
    n, m = map(int, input().split())
    pairs = [tuple(map(int, input().split())) for _ in range(m)]
    
    a1, b1 = pairs[0]
    if check(a1, pairs) or check(b1, pairs):
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    main()
```这`check`函数识别候选未涵盖的对$x$。 对于每个这样的对，它都会测试这两个元素是否可能$y$。 这`all`功能确保每一对都被覆盖。 这将问题减少到最多四个候选检查，从而避免了昂贵的迭代$(x, y)$组合。 边缘条件（例如包含第一个元素的所有对或仅具有一个冲突对）会自然处理。

 ## 边缘情况

 当所有对都包含第一个元素时，例如：```
3 3
1 2
1 3
1 2
```选择$x=1$立即覆盖所有对。 该算法找不到未覆盖的对并返回“YES”。 这可以正确处理解决方案很简单的情况，但如果我们只检查“有问题的”对，则可能会错过解决方案。
