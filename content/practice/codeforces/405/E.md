 ## 解决方案
 ## 问题理解

 给定一个无向连通图，并要求我们将其边完全分解为长度为 2 的路径。 每个输出块必须看起来像一个由三个顶点组成的链$x - y - z$，这意味着我们采用共享中间顶点的两条边$y$，并且原始图的每条边都必须恰好出现在一个这样的链中。 

因此，我们不是单独考虑边缘，而是尝试将它们成对分组，其中每对共享一个公共端点。 每个顶点可以充当多个此类对的中间，但每条边必须恰好属于一对，并且必须恰好使用一次。 

约束条件达到$10^5$顶点和边，这会立即排除任何二次方，例如尝试所有边配对或边上的任何全局匹配。 甚至$O(m \log m)$没问题，但是任何重复扫描邻接列表或尝试回溯选择的操作都会失败。 该结构必须在基本上线性的时间内构建。 

一个微妙的点是，配对不是边缘上的全局配对，而是顶点上的局部配对。 单个顶点可能需要将其关联边配对，但不同的顶点会竞争相同的边，具体取决于我们如何决定结构。 当按邻接顺序看到顶点时，尝试立即将顶点处的边配对的天真贪婪可能会失败，因为它忽略了配对边稍后是否可用。 

一个小的失败例子来自三角形：

 输入：```
3 3
1 2
2 3
3 1
```这里每个顶点的度数都是 2，因此存在一个有效的解决方案：每个顶点可以充当中间一次，产生一条路径。 但是，如果我们一看到顶点 1 处的边就贪婪地将其配对，则可能会将 (1,2) 与 (1,3) 配对，从而使顶点 2 和 3 具有不匹配的边，从而无法一致地完成。 正确的解决方案取决于全局一致的配对结构，而不是局部的即时决策。 

另一个边缘情况是星图：```
1 4
1 2
1 3
1 4
1 5
```顶点 1 有 4 条边，因此它可以形成两条路径，但叶子必须通过 1 配对。任何解决方案都必须仔细地将中心的边以两条为一组进行配对，这表明顶点的行为就像“缓冲区”，其中边成对匹配。 

## 方法

 强力方法会尝试将每条边视为需要伙伴相邻边，有效地搜索每个顶点处的所有关联边对，同时确保全局一致性。 这很快就变成了组合。 在度数的顶点$d$， 有$(d-1)!!$配对关联边的方法，并且由于顶点通过共享边交互，因此状态空间在图上爆炸。 即使在中等图表中，总度数也会呈指数增长，很容易超过任何限制。 

关键的观察是我们不需要立即决定所有配对。 相反，我们可以在 DFS 树中处理图并以受控方式延迟决策。 每个顶点都会积累“来自下方的未配对边”，尽可能在本地将它们配对，并向上推最多一个剩余的边。 这将全局配对问题转化为树结构上的局部奇偶传播问题。 

DFS 树至关重要，因为每条边要么指向子节点，要么返回祖先。 这为解决约束提供了一个自然的方向：孩子向上报告未解决的边缘，父母逐步决定配对。 这可以避免重新访问边缘，并确保每个边缘在首次符合条件时仅被处理一次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| O(米) | 太慢了 |
 | DFS配对策略| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 我们将图建立在任意位置（通常是顶点 1），并在图上运行 DFS，同时跟踪哪些边是 DFS 树的一部分以及哪些是后边。 

1. 从任意根运行 DFS，标记父关系并确保我们在 DFS 上下文中精确地遍历每条边一次。 DFS 树为我们提供了自下而上处理的层次结构。 
2. 对于每个顶点，维护一个“来自已处理子节点的当前未配对的关联边”的列表。 该列表表示仍需要匹配到涉及该顶点或更高顶点的长度为 2 的路径的边。 
3. 当从子节点返回时，我们收集子节点的剩余边（如果有）并将其添加到当前顶点的列表中。 该模型模拟了以下事实：未解析的边必须在当前顶点解析或进一步向上传递。 
4. 在当前顶点，重复从其列表中取出两条边并形成通过该顶点的路径。 每个这样的配对都会产生一个输出三元组$(u, v, w)$，两条边共享的地方$v$。 这一步是安全的，因为两条边都已被确认在该顶点“等待”，并且不会在其他地方使用。 
5. 如果配对后只剩下一条边，我们无法在本地解析它，因此我们将其向上传递给父级。 该模型模拟了以下想法：该顶点向其祖先贡献了一个未解决的需求。 
6. 处理完所有子节点后，如果我们位于根并且仍然有未配对的边缘，则构建是不可能的。 否则，根必须以空列表结尾。 

输出路径是在配对步骤期间收集的，而不是在 DFS 完成后收集的。 

### 为什么它有效

 DFS 确保当每条边成为已处理子树和未处理子树之间“边界”的一部分时，它都被恰好考虑一次。 关键的不变量是在处理以$v$，至多一个关联边保持不成对，并且是子树和图的其余部分之间的唯一交互点。 这迫使子树的所有内部边缘在其内部完全配对，因为任何内部不平衡都需要多个边缘逃逸，这与配对过程相矛盾。 由于每个顶点仅在两个端点都已“可用”时才在本地配对边，因此不会重用任何边，并且每个生成的三元组对应于两个不同的边。 根条件通过确保没有剩余边缘保持不匹配来强制全局一致性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    
    for i in range(m):
        a, b = map(int, input().split())
        g[a].append((b, i))
        g[b].append((a, i))
    
    used_edge = [False] * m
    visited = [False] * (n + 1)
    parent = [-1] * (n + 1)
    parent_edge = [-1] * (n + 1)

    # store pairs as (vertex, edge_id)
    ans = []

    def dfs(v):
        visited[v] = True
        stack = []

        for to, eid in g[v]:
            if used_edge[eid]:
                continue
            used_edge[eid] = True

            if not visited[to]:
                parent[to] = v
                parent_edge[to] = eid
                res = dfs(to)
                if res is not None:
                    stack.append(res)
            else:
                # back edge: treat as available at v
                stack.append((v, eid))

        # pair edges at v
        while len(stack) >= 2:
            (v1, e1) = stack.pop()
            (v2, e2) = stack.pop()

            # e1 connects (v1 - v), e2 connects (v2 - v)
            # path is v1 - v - v2
            ans.append((v1, v, v2))

        # leftover
        if len(stack) == 1:
            return stack[0]

        return None

    res = dfs(1)

    if res is not None:
        print("No solution")
        return

    if len(ans) != m // 2:
        print("No solution")
        return

    out = []
    for x, y, z in ans:
        out.append(f"{x} {y} {z}")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```DFS 的结构使得每条边在第一次遇到时都被标记为已使用，从而防止无向图中的双重遍历。 每个子树最多返回一个表示为点-边对的未解析边。 返回的对象正是算法中提到的“剩余需求”。 

配对循环是关键步骤：同一顶点的两条待处理边立即组合成有效的长度为 2 的路径。 中间的顶点始终是当前的 DFS 节点，因此从两条边都已附加到该节点的处理区域的不变量可以得出正确性。 

根检查是通过验证 DFS 是否不返回任何内容来实现的，因为任何剩余都意味着根将具有不匹配的事件边，从而无法进行完全配对。

 ## 边缘情况

 三角形图演示了循环如何在没有剩余边缘的情况下解决。 在 DFS 期间，所有边都在根处变为待处理状态，并干净地配对，生成有效的单个路径。 该算法可以处理此问题，因为每个后边都被视为在其端点处立即可用，从而确保两个待处理边始终在某个顶点相交。 

星形图显示了相反的行为。 所有叶子边缘都到达中心，但由于根部的叶子边缘数量为奇数，因此在最大配对后，一条边缘不可避免地保持不成对。 DFS 向上返回这个剩余部分，并且根检测到不可能性。 

单个路径状结构（例如四个节点的链）确认，如果端点无法完全匹配，则中间顶点的内部配对没有帮助，从而强化了全局奇偶校验条件由根强制执行。
