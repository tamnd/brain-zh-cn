 ## 解决方案
 ## 问题理解

 波利卡普斯有一定数量的糖果和一定数量的朋友。 他希望将所有糖果分配给他的朋友们，使得每个朋友都获得正数的糖果，并且获得最多糖果的朋友和获得最少糖果的朋友之间的差异尽可能小。 输入给我们两个整数：糖果总数`n`以及朋友的数量`m`。 输出应该是一个序列`m`总和为的正整数`n`，并且最大和最小整数之间的差异应最小化。 

鉴于限制条件，`n`和`m`都最多为 100。这个值足够小，任何简单的分配策略都可以高效运行，因此我们不必担心高复杂度算法的性能。 主要挑战是对分布本身的推理。 

一个重要的边缘情况是`n`不能被整除`m`。 例如，如果 Polycarpus 有 10 颗糖果和 3 个朋友，一个天真的方法可能会尝试给每个朋友`n // m = 3`糖果，但这样我们就会剩下 1 颗糖果。 正确的做法是多给一些朋友一颗糖果，以平衡分配：`[4, 3, 3]`。 另一个边缘情况是当`n`等于`m`; 每个朋友只得到一颗糖果。 一个粗心的解决方案如果不能正确处理剩余部分，那么对于任何输入都会失败`n % m != 0`。 

## 方法

 蛮力方法是尝试每一种可能的分布`n`糖果之间`m`朋友们并检查最大值和最小值之间的差异。 这保证找到最优解，但组合数量呈指数增长`n`和`m`。 具体来说，分区的数量`n`进入`m`正整数是组合的，很容易超过数千，鉴于问题的结构简单，这是不必要的。 

优化这一点的关键在于，最公平的分布始终是接近均匀的分布。 每个朋友都应该收到`floor(n / m)`或者`ceil(n / m)`糖果。 让`q = n // m`是每个朋友的糖果基数，并且`r = n % m`为余数。 确切地`r`朋友应该得到`q + 1`糖果，剩下的`m - r`朋友得到`q`糖果。 这保证了最大差异为 1，这是最小的并且无法改进，因为如果所有值都相等且`n % m != 0`，我们达不到总和`n`。

 | ---| ---| ---| ---|
 | 蛮力 | O(组合) | O(米) | 太慢了 |
 | 最佳 | O(米) | O(米) | 已接受 |

 ## 算法演练

 1. 读取整数`n`和`m`来自输入。 这些代表糖果总数和朋友数量。 
2. 计算`q = n // m`作为每个朋友应该收到的糖果的基数。 这确保每个人至少获得相同的最低金额。 
3. 计算`r = n % m`作为仍需要分发的剩余糖果。 这些额外的糖果将送给每个朋友一颗，以尽量减少最大差异。 
4. 创建尺寸列表`m`第一个在哪里`r`元素是`q + 1`和剩余的`m - r`元素是`q`。 这准确地保证了`r`朋友们会额外获得一颗糖果，平衡分配。 
5. 将列表打印为空格分隔的整数。 

为什么它有效：不变的是每个朋友至少收到`q`糖果，确切地说`r`朋友们又收到一颗糖果。 所有值的总和是`q*(m-r) + (q+1)*r = n`，这保证了正确性。 最大值和最小值之差最多为 1，这是最小的，因为分配余数需要一些朋友获得额外的糖果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
q, r = divmod(n, m)
result = [q + 1] * r + [q] * (m - r)
print(' '.join(map(str, result)))
```该代码首先使用以下方法计算商和余数`divmod`，这比单独的除法和模运算更干净。 然后通过重复构建该列表`q + 1`确切地`r`次和`q`确切地`m - r`次。 使用`join`将整数转换为字符串并以所需的格式打印它们。 通过仔细处理其余部分可以避免差一错误`r`并确保所有朋友都收到一个正整数。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    q, r = divmod(n, m)
    result = [q + 1] * r + [q] * (m - r)
    return ' '.join(map(str, result))

# provided samples

 ## 边缘情况

 当`n`等于`m`， 例如`5 5`，每个朋友正好收到 1 颗糖果。 该算法计算`q = 1`和`r = 0`。 结果列表为`[1, 1, 1, 1, 1]`。 什么时候`n`略大于`m`， 例如`7 3`，我们计算`q = 2`和`r = 1`。 第一个`r`朋友收到`q + 1 = 3`糖果，其余两人收到`2`每颗糖果。 这确保了最大差值恰好为 1，且无法减小。 该算法可以优雅地处理这两种情况，无需附加条件。
