 ## 解决方案
 ## 问题理解

 我们得到了四个小整数，代表三只熊和玛莎的大小。 熊需要三种汽车尺寸，从父亲的车到儿子的车，尺寸严格递减。 每只熊都被分配到一辆特定的汽车：最大的爸爸，中间的妈妈，最小的儿子。 

一个字的大小`a`可以进入一辆大小的汽车`b`仅当`a ≤ b`。 然而，喜欢汽车更严格：汽车与角色相比不能太大，特别是`b ≤ 2a`。 因此，每只熊都必须能够适合并“喜欢”分配给他们的汽车。 

玛莎可以进入所有三辆车，这限制了每辆车的尺寸至少是她的尺寸。 她只喜欢最小的车，这就给最小的车尺寸设置了上限。 

任务是构造满足所有约束的任何有效的汽车尺寸三元组，或确定不存在这样的三元组。 

输入值以 100 为界，因此解决方案必须在恒定时间内运行，或者在最坏的情况下在很小的范围内呈线性。 任何在大范围内迭代的方法都是不必要的，但即使是超过 100 立方的三重暴力仍然是可行的。 真正的挑战是将不等式转化为严格的界限，并注意到一旦最小的汽车被固定，中间和最大的汽车几乎直接由熊约束决定。 

当玛莎的约束与儿子熊的上限发生冲突时，就会出现边缘情况，使得系统不可行，即使所有单独的约束看起来都是一致的。 例如，如果玛莎足够大，以至于她迫使最小的汽车太大而让儿子熊不喜欢，则不存在解决方案。 

## 方法

 一个蛮力的想法是尝试所有整数三元组`(S, M, L)`这样`1 ≤ S < M < L ≤ 100`。 对于每个三元组，我们检查所有约束：每只熊必须适合并喜欢他们的汽车，而玛莎必须适合所有汽车并且只喜欢最小的汽车。 由于范围很小，最多大约有 100 立方次组合，或一百万个检查，这已经是临界点，但仍然可以接受。 

然而，这忽略了结构。 每只熊都独立地限制其分配的汽车的范围。 条件`a ≤ b ≤ 2a`将每只熊转换为有效汽车尺寸的区间。 父亲强行将最大的汽车撞上`[V1, 2V1]`，母亲进入`[V2, 2V2]`，和儿子进入`[V3, 2V3]`。 这些间隔必须符合严格的顺序。 

Masha 引入了所有三辆车之间的耦合：每辆车必须至少`Vm`，并且最小的汽车也必须最多`2Vm`。 这使得最小的汽车基本上固定在一个紧密的间隔内`[Vm, min(2Vm, 2V3)]`，既然儿子也一定喜欢。 

一旦选择了最小的汽车，就可以通过尊重顺序和上限贪婪地导出中间和最大的汽车。 该结构消除了搜索：通常只需要检查最小汽车的几个候选值`Vm`或接近它的值，并且每一个都会导致确定性构造或失败。

 | ---| ---| ---| ---|
 | 蛮力 | O(100立方) | O(1) | O(1) | 已接受但没有必要 |

 ## 算法演练

 1. 计算最小汽车的有效范围。 它必须同时满足玛莎的约束和儿子熊的约束，因此它必须位于`[Vm, ∞)`和`[V3, 2V3]`。 这给出了`S ∈ [Vm, 2V3]`。 
2. 如果该路口是空的，则没有有效的最小汽车。 在这种情况下，不存在任何解决方案。 
3. 选择候选最小汽车尺寸`S`。 一个自然的选择是`S = max(Vm, V3)`，因为如果可行的话它满足下限和上限约束。 
4. 计算中间车尺寸`M`。 它必须严格大于`S`，但也必须满足熊妈妈的约束`V2 ≤ M ≤ 2V2`。 最小的有效选择是`M = max(S + 1, V2)`。 
5. 如果`M`违反上限`M > 2V2`，这辆候选最小的汽车失败了，我们丢弃它。 
6. 计算最大汽车尺寸`L`。 必须满足`L > M`和`V1 ≤ L ≤ 2V1`。 选择`L = max(M + 1, V1)`。 
7. 如果`L > 2V1`，构建失败。 否则我们就有一个有效的三元组。 
8. 输出`(L, M, S)`。 

这种结构隐含地确保了严格的顺序并尊重每只熊的约束。 如果最初的最小汽车选择失败，则不存在其他可行的调整，因为增加`S`只会收紧约束`M`和`L`。 

### 为什么它有效

 关键的不变量是每一步都贪婪地为每辆车选择最小可行值，同时保持严格的顺序。 由于所有有效范围都是连续间隔，因此选择最小允许值永远不会妨碍该汽车有更大选择时可能存在的有效解决方案。 任何失败的发生都是由于约束的空交集而不是糟糕的本地选择。 由于每个约束形成一个凸区间，因此可行性仅取决于区间重叠，而不取决于组合结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

V1, V2, V3, Vm = map(int, input().split())

# smallest car candidate range
S = max(Vm, V3)
if S > 2 * V3:
    print(-1)
    sys.exit()

# middle car
M = max(S + 1, V2)
if M > 2 * V2:
    print(-1)
    sys.exit()

# largest car
L = max(M + 1, V1)
if L > 2 * V1:
    print(-1)
    sys.exit()

print(L)
print(M)
print(S)
```代码直接实现了贪心构造。 最小的汽车被选为与玛莎和儿子熊一致的最严格的可行值。 然后，中等和最大的汽车仅根据需要向上移动，以保持严格的顺序并满足每只熊的间隔限制。 每次可行性检查都确保我们永远不会超过该熊可接受的最大尺寸。 

一个微妙的点是，严格的不平等是由`S + 1`和`M + 1`，确保`S < M < L`无需额外的交换或重新排序逻辑。

 ## 边缘情况

 当玛莎强迫最小的汽车超过熊儿子的最大喜欢限制时，就会出现一个关键的边缘情况。 用于输入`V3 = 10, Vm = 25`，对于玛莎来说，最小的汽车必须至少是 25 辆，而对于儿子熊来说，最小的汽车必须是最多 20 辆。 交集为空，因此算法在以下情况下正确地早期拒绝：`S > 2 * V3`。 

另一个微妙的情况是，在修复最小的汽车后，中间的汽车被迫超出其允许的范围。 例如，如果`S = 50`和`V2 = 10`，算法集`M = max(51, 10) = 51`，但如果`2V2 = 20`, 支票`M > 2V2`触发失败。 这表明可行性是逐步确定的，即使个别约束看起来很宽松，也并非所有约束都能同时满足。 

最终的边界情况是所有约束都在其上限处精确对齐，例如`M = 2V2`或者`L = 2V1`。 贪婪的构造仍然有效，因为“类似”条件允许相等，并且仅通过单独强制执行严格的排序`+1`调整。
