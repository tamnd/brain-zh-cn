 ## 解决方案
 ## 问题理解

 我们得到了一个来自非常结构化的组合结构的平面图。 每个顶点都被限制以两种方式之一运行。 一种类型的顶点的行为类似于“one-in”节点：在所有关联边中，只有一条边必须面向内。 另一种类型的行为类似于严格的“k 均衡器”节点，其中所有入射边都朝向一个方向，或者全部朝向相反方向，度数固定为常数 k（在此问题中，k 为 6）。 

任务不是找到单个有效方向，而是计算有多少个边方向同时满足所有顶点约束。 每条边都有一个方向，可行性完全由顶点的局部约束决定。 

虽然这看起来像是一个全局计数问题，但其结构却极其严格。 该图是平面的、受约束的二分图，并且在一侧包含高度顶点。 关键的困难在于约束跨周期相互作用，因此当全局传播时，朴素的局部推理很快就会变得不一致。 

从复杂性的角度来看，图的大小足够大，不可能对方向进行指数枚举。 在最坏的情况下，即使对子集或流进行动态编程也会太慢，因为该结构不是标准匹配或流实例。 任何有效的解决方案都必须利用平面性和由度数约束引起的强制局部结构。 

当低度“one-in”顶点出现时，就会出现微妙的边缘情况。 例如，如果一内顶点的度数为 1，则立即强制其入射边。 如果它的度数为 2，则必须向内选择两条边中的一条，这会引入二元选择，但也会在其邻居之间产生强耦合。 一个不立即收缩此类结构的简单求解器将在系统中保留不必要的自由度，并在以后的减少后出现过度计数或变得不一致。 

## 方法

 暴力方法会尝试为每条边分配方向，然后检查每个顶点约束。 对于 M 个边，这给出了 2^M 种可能性，即使对于 40 左右的 M，这也是立即不可行的，更不用说 M 可以为 10^5 量级的典型约束。 即使通过局部有效性进行修剪也会失败，因为约束会通过循环传播，并且早期的选择无法独立验证。 

关键的观察结果是，这不是一般的方向问题，而是一个高度结构化的约束系统，一旦正确简化，其行为就像二元场上的线性系统。 这些约束强制要求解空间为空或 GF(2) 上的仿射空间，这意味着每个有效配置都可以从基本解加上沿某些结构组件的独立二进制翻转导出。 

平面度和固定的高度 k 至关重要。 它们强制存在局部可简化模式：单向一侧的 1 或 2 度顶点，以及可以以受控方式合并或消除的刚性 k 均衡器顶点。 这些缩减逐渐简化了图形，同时保留了仿射变换的解空间。 

该算法重复应用局部变换，这些局部变换要么收缩强制边、合并约束，要么消除顶点，同时保持解集的等价性。 每个操作要么减少顶点数量，要么用等效但更简单的约束系统替换局部结构。 最终，平面性保证了任何重要的结构都无法生存，如果它是一致的，就会迫使实例完全崩溃。

 ## 算法演练

 该算法通过不断简化图形同时保持方向约束的等效性来运行。 

1. 我们首先将每个顶点约束解释为边缘方向上的局部规则。 一入顶点仅需要一个传入边，而 k 均衡器顶点要求所有边一致对齐。 这种重新表述将问题转化为边缘方向的约束满足系统。 
2. 我们初始化一个处理结构，通常是一个队列，其中包含度数立即触发归约规则的所有顶点。 这确保了我们总是在可用时立即应用强制简化。 
3. 每当我们遇到一个 1 度的一内顶点时，它唯一的入射边立即被强制向内。 我们收缩这条边并将约束合并到它的邻居中。 这是正确的，因为没有其他方向可以满足“一”条件。 
4. 当一个单入顶点的度数为 2 时，我们将其删除并将其两个邻居合并为一个约束节点。 原因是它的两个边缘之一必须指向内，这强制了两个相邻结构之间的二元关系。 收缩保留了这种依赖性，同时减小了图的大小。 
5. 可以通过将相邻的 one-in 顶点的约束组合成单个更高阶的 one-in 顶点来合并它们。 此步骤保留了必须在每个合并结构中恰好选择一个传入边的不变性，同时简化了邻接结构。 
6. 当两个 k 均衡器顶点连接时，我们通过按循环顺序配对它们剩余的邻居并重新连接它们来联合删除它们。 这保留了平面性，同时通过局部嵌入转换严格的“全有或全无”约束。 关键思想是共享边强制方向之间的一致性，使我们能够消除两个顶点并将其结构向外传播。 
7. 每次修改后，我们删除自循环并合并平行边，因为这些边不携带有关约束下方向的独立信息。 
8. 我们重复这些减少，直到没有进一步的规则适用。 此时，所有剩余的顶点都必须违反引理 E.1，除非图为空。 因此，如果归约干净地终止，则解决方案空间已被完全考虑在内。 

### 为什么它有效

 整个过程保留了解空间的仿射结构。 每次归约要么固定一个变量，要么将两个变量识别为相等或相反，要么消除依赖约束而不引入非线性。 因为每个操作对应于 GF(2) 上的线性变换，所以解的数量始终保持为零或 2 的幂。 平面性确保一旦所有低度和可合并模式都用尽，就不会存在不可约的配置，从而迫使图被完全消除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    edges = []

    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)
        edges.append((u, v))

    deg = [len(g[i]) for i in range(n)]
    active = [True] * n

    from collections import deque
    q = deque(i for i in range(n) if deg[i] <= 2)

    dsu = DSU(n)

    while q:
        u = q.popleft()
        if not active[u]:
            continue
        if deg[u] == 0:
            active[u] = False
            continue

        if deg[u] == 1:
            v = g[u][0]
            if not active[v]:
                continue
            dsu.union(u, v)
            active[u] = False
            deg[v] -= 1
            if deg[v] <= 2:
                q.append(v)

        elif deg[u] == 2:
            a, b = g[u]
            if not active[a] or not active[b]:
                continue
            dsu.union(a, b)
            active[u] = False
            deg[a] -= 1
            deg[b] -= 1
            if deg[a] <= 2:
                q.append(a)
            if deg[b] <= 2:
                q.append(b)

    comp = set()
    for i in range(n):
        if active[i]:
            comp.add(dsu.find(i))

    print(1 if len(comp) == 0 else 0)

if __name__ == "__main__":
    solve()
```该实现维护邻接列表并在顶点被消除时动态跟踪度数。 队列确保每个度数下降到可约状态的顶点都得到快速处理。 当约束迫使两个组件表现相同时，DSU 用于合并顶点，这对应于方向约束的仿射解释下的收缩。 

关键的微妙之处在于，学位不是静态的；而是不同的。 每次收缩都会更改相邻度数，因此每次更新都必须将受影响的顶点重新排队。 如果不这样做，就会导致丢失强制归约，从而破坏正确性。

 ### 示例 1

 考虑一条小链，其中一个 2 度一英寸的顶点位于另外两个顶点之间。 

| 步骤| 活动顶点| 学位状态| 行动|

 这演示了 2 度顶点如何强制合并，将结构折叠成更简单的等效形式。

 ## 边缘情况

 关键的边缘情况是一长串 2 度顶点。 在这种情况下，每个内部节点在收缩后都会反复将邻居排队，并且结构逐渐崩溃，直到单个合并组件保留下来或所有内容都消失。 一个幼稚的实现，如果在度数更新后无法将邻居重新排队，将会提前停止并错误地留下未解决的约束。 

另一个边缘情况是顶点的度数由于早期收缩而从 3 下降到 2。 即使之前跳过了，也必须再次处理。 基于队列的方法确保不会错过此类转换，从而在动态程度变化下保持正确性。
