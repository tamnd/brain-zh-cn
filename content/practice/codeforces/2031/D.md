 ## 解决方案
 ## 问题理解

 我们有一排树，每棵树都有一个高度。 兔子从某个位置开始，可以使用取决于位置和高度的非常特定的规则在树之间移动。 

来自索引处的树`i`，兔子可以向两个方向跳跃。 如果它跳到左边，它必须落在一棵更高的树上。 如果它向右跳，它必须落在一棵严格来说更矮的树上。 每次移动都会翻转“高度变化的方向”：向左移动增加高度，向右移动减少高度，但索引空间中的方向是独立的。 

对于每个起始位置，我们想知道兔子通过重复这种跳跃任意次可以到达的所有树的最大高度。 

关键的挑战是兔子不仅仅在本地移动。 由于它可以通过不同方向交替增加和减少高度，因此可达索引集不是一个简单的区间。 它的行为就像一个图表，其中每个节点在严格的不平等条件下连接到许多其他节点。 

约束很严格：所有测试用例的树总数达到 500,000 棵。 任何显式考虑索引对之间转换的解决方案都会太慢。 甚至一个$O(n \log n)$每个测试用例方法都有 TLE 风险，除非每个元素都非常干净且线性。 

当贪婪地思考时，会出现一个微妙的陷阱：局部最大化下一次跳跃并不能保证全局可达性。 一个小例子说明了这一点。 

考虑`a = [3, 1, 2]`。 从索引 1 开始，可能会跳转到 2（因为 1 < 3），然后从 2 跳转到 3（因为 2 > 1 为 false，所以这条路径实际上会中断）。 可达结构同时依赖于索引排序和高度排序，因此天真的贪婪步进会失败。 

真正的困难在于可达性取决于由高度引起的全局排序结构，而不是局部邻接性。 

## 方法

 直接强力方法从每个索引开始，并使用 BFS 或 DFS 模拟所有可能的跳转。 从一个节点`i`，我们扫描所有`j < i`和`a[j] > a[i]`和所有`j > i`和`a[j] < a[i]`，推动有效的转换。 

这是正确的，但非常昂贵。 在最坏的情况下，每个节点都连接到几乎所有其他节点，因此每次开始都会探索$O(n)$过渡、给予$O(n^2)$全面的。 

关键的观察是规则总是沿着单调约束移动：向左移动严格增加高度，向右移动严格减少高度。 这意味着沿着任何有效路径，访问高度的顺序在增加和减少之间交替。 更重要的是，每一步都可以被解释为在结构化的价值排序中转向“最佳可达代表”。 

我们可以将问题重新表述为索引图，其中边缘由最近的较强或较弱邻居按排序顺序定义。 我们不需要连接到所有有效节点，而是只需要连接到每个方向上最近的候选节点，以保持可达性，因为中间节点由允许跳转的传递性主导。 

这将问题简化为构建一个捕获“左侧下一个更大”和“右侧下一个较小”关系的结构，可以使用单调堆栈或基于 DSU 的跳跃来维护该结构。 一旦构造了这个简化图，可达性就变成了组件的并集，每个节点的答案是其连接组件中的最大值。 

最后一步是计算这个隐式图上的连接分量并获取每个分量的最大值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 来自每个节点的强力 DFS |$O(n^2)$|$O(n)$| 太慢了 |
 | 单调结构+DSU组件|$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们使用单调转换隐式构造一个图，然后将可达节点合并到组件中。 

1.压缩可达性的思想：我们不允许跳转到任何有效节点，而是仅将每个索引连接到每个方向上最近的有效候选节点。 原因是任何进一步的有效跳转都可以通过中间有效步骤进行分解，而无需更改可达性端点。 
2. 使用单调堆栈构建“左侧下一个较大”和“右侧下一个较小”的结构。 对于每个索引，我们在左侧找到高度较大的最接近的索引，在右侧找到高度较小的最接近的索引。 这些成为我们明确需要的唯一边缘。 
3. 将每个索引视为图中的一个节点。 根据这些计算的转换添加边缘。 由于每个节点至多具有恒定的出边，因此图的大小保持线性。 
4. 在所有边上运行 DSU（不相交集并集）。 每当两个索引连接时，将它们合并到同一个组件中。 这汇总了所有相互可到达的位置。 
5. 在所有并集之后，计算每个 DSU 组件内的最大高度。 
6. 对于每个起始索引，输出其组件的最大高度。 

这种方法起作用的原因是，交替的单调运动总是会塌陷成一种结构，其中任何长路径都相当于一系列“最接近的可行扩展”。 一旦这些连接起来，DSU 确保在可达性下完全关闭。 

### 为什么它有效

 每个有效的移动都严格地沿着与索引移动一致的方向改变高度。 由于严格的不等式，任何非最近的跳跃都可以被最近的有效跳跃链替换，而无需跳过中间障碍物。 这创建了一个传递闭包，其中局部极值转换已经编码了完全可达性。 然后，DSU 捕获此闭包的连接组件，并且在组件内，可以通过交替的单调步骤从其他节点到达每个节点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.sz = [1] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.sz[a] < self.sz[b]:
            a, b = b, a
        self.p[b] = a
        self.sz[a] += self.sz[b]

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        dsu = DSU(n)

        # monotonic stack for next greater to left
        stack = []
        for i in range(n):
            while stack and a[stack[-1]] < a[i]:
                stack.pop()
            if stack:
                dsu.union(i, stack[-1])
            stack.append(i)

        # monotonic stack for next smaller to right
        stack = []
        for i in range(n - 1, -1, -1):
            while stack and a[stack[-1]] > a[i]:
                stack.pop()
            if stack:
                dsu.union(i, stack[-1])
            stack.append(i)

        comp_max = {}
        for i in range(n):
            root = dsu.find(i)
            comp_max[root] = max(comp_max.get(root, 0), a[i])

        out.append(" ".join(str(comp_max[dsu.find(i)]) for i in range(n)))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```DSU 结构纯粹用作连接压缩器。 每个联合对应于单调约束所隐含的直接结构可达性。 堆栈结构确保我们永远不会错过必要的连接，同时避免二次比较。 

最后一步只是分组：一旦形成组件，每个查询就变成一个恒定时间的查找。 

一个微妙的实现细节是我们没有显式地构建邻接表。 在最坏的情况下，这会带来 O(n^2) 内存的风险。 相反，联合是在堆栈处理期间直接执行的。

 ## 边缘情况

 单元素数组很简单：DSU 从不执行并集，因此组件 max 是元素本身。 该算法立即正确地返回它。 

对于像这样的严格递增序列`1 2 3 4 5`，左侧较大的边缘很少存在，但右侧较小的过渡仍然通过逆向处理中的堆栈折叠来连接节点。 DSU 确保部分分组并为每个可达区域生成正确的最大值。 

对于像这样的严格递减序列`5 4 3 2 1`，每个节点都有一个左大邻居，因此并集在整个结构中传播。 DSU 将所有内容折叠成一个组件，并且每个输出变为 5，通过交替移动来匹配完全可达性。
