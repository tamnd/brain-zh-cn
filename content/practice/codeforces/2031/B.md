 ## 解决方案
 ## 问题理解

 我们有一个数字的排列$1$通过$n$。 目标是排序后的排列$[1,2,\dots,n]$。 

当值完全不同时，唯一允许的操作交换两个相邻位置$1$。 例如，$3$和$4$可以互换，但是$3$和$5$不得。 

任务是确定是否可以使用任意数量的此类交换将排列转换为排序顺序。 

制约因素很大。 在所有测试用例中，总长度最多为$2 \cdot 10^5$。 任何模拟多次交换或重复扫描数组的算法都会变得太慢。 二次方法被排除，因为$n^2$操作将达到大约$4 \cdot 10^{10}$在最坏的情况下。 我们需要一个线性或近线性的解决方案。 

一个微妙的边缘情况是反转的相邻对。 考虑：```
2 1 3 4
```价值观$2$和$1$完全不同$1$，所以可以直接交换。 答案是`YES`。 

另一个重要案例是：```
3 1 2
```价值$3$必须向右移动，但它永远不能与任何一个交换$1$或者$2$，因为差异是$2$和$1$仅在之后$1$和$2$变得相邻。 正确答案是`NO`。 仅检查反转计数的简单方法会错过这一点。 

一个特别有启发性的例子是：```
4 2 3 1
```这对$(2,3)$可以永久交换，但价值$4$也永远无法跨越$2$或者$1$。 排列无法排序，所以答案是`NO`。 

## 方法

 暴力方法会将每个有效交换视为状态图中的一条边，并搜索排序排列是否可达。 这是正确的，因为每个合法的操作序列都对应于该图中的一条路径。 

不幸的是，有$n!$排列。 即使对于中等$n$，探索状态变得不可能。 

关键的观察是只有连续的值才能交换。 

考虑两个值的差异超过$1$， 例如$2$和$5$。 它们永远不能直接交换。 由于每个允许的操作仅交换连续的数字，因此相对顺序$2$和$5$永远不能改变。 

这意味着对于每对$x < y-1$，它们的顺序在整个过程中是不变的。 

相对顺序可能改变的唯一对是连续值：$$(1,2),\ (2,3),\ (3,4),\ \dots,\ (n-1,n).$$假设一个值距离它所属的位置不止一个位置。 解决这个问题需要改变其相对于某些非连续值的顺序，这是不可能的。 

这立即导致了简单的表征。 每个元素必须已经位于其自己的位置或与其相邻。 在排列符号中，$$|p_i - i| \le 1$$对于每个位置$i$。 

如果这个条件成立，则排列仅由不相交的相邻反转组成，例如$$[2,1,4,3,5].$$每次反转都涉及连续的值，并且可以通过一次合法交换独立修复。 

如果任何地方条件不成立，排序就不可能。

 ## 算法演练

 1. 读出排列。 
2. 扫描每个位置$i$。 
3. 检查是否$$|p_i - (i+1)| \le 1.$$该数组在代码中是从 0 索引的，因此值的正确位置$i+1$表示为$i+1$。 

1. 如果任意位置违反此条件，则输出`NO`。 

距离目的地两个或多个位置的值需要跨越非连续值，而这种情况永远不会发生。 

1、如果所有位置都满足条件，则输出`YES`。 

然后，排列完全由固定点和连续值的相邻交换组成，所有这些都可以合法地纠正。 

### 为什么它有效

 差值超过的任何两个值的相对顺序$1$永远不会改变，因为它们永远不能参与合法的交换。 

假设某个元素$x$距离其最终位置至少两个位置。 为了到达目的地，$x$必须传递一些值$y$和$|x-y|>1$。 这需要改变它们的相对顺序，这是不可能的。 

因此，每个可排序的排列必须满足$|p_i-i|\le1$采用 1 索引表示法。 

相反，如果每个元素距其正确位置最多一个位置，则排列是不相交的相邻反转的集合$(i+1,i)$。 每个这样的反转都由连续的值组成，并且可以通过单个合法交换来修复。 执行这些交换对排列进行排序。 

因此，这个条件既是必要的，也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))

        ok = True
        for i, x in enumerate(p, start=1):
            if abs(x - i) > 1:
                ok = False
                break

        ans.append("YES" if ok else "NO")

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```该实现直接检查上面证明的特征。 

循环使用`enumerate(..., start=1)`以便索引与排列的自然从 1 开始的位置匹配。 这样就避免了重复`+1`调整并消除常见的相差一错误。 

发现违规后立即停止扫描。 一旦一个元素距离其目标超过一个位置，就不需要进一步的信息。 

不执行任何模拟。 证明表明位移条件完全决定了答案。

 ## 边缘情况

 考虑：```
1
2
2 1
```位移为$1$和$1$。 算法接受。 单一合法互换交易所$2$和$1$，产生排序排列。 

考虑：```
1
3
3 1 2
```第一个元素有位移$2$。 算法立即拒绝。 价值$3$需要移过去$1$，这些值的不同之处在于$2$，因此它们的相对顺序永远不会改变。 

考虑：```
1
6
2 1 4 3 6 5
```每个位移等于$0$或者$1$。 算法接受。 每个倒置对都由连续的值组成，并且可以独立固定。 

考虑：```
1
5
5 4 3 2 1
```第一个元素有位移$4$。 算法立即拒绝。 排序需要改变许多非连续值对的相对顺序，这是任何合法操作都无法完成的。
