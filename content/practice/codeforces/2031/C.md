 ## 解决方案
 ## 问题理解

 我们被要求为长度数组中的每个位置分配一个值$n$。 这些值代表排成一行的面包上的“馅料”。 相同的填充可能会出现多次，但仅限于两个严格的规则。 

首先，如果填充物出现，它不可能只出现一次。 我们使用的每个标签必须至少出现两次。 其次，每当两个位置共享相同的标签时，这些位置之间的距离必须是完全平方数。 换句话说，每个数字的出现形成一组索引，其中每个成对距离都是平方数。 

因此，任务不是对数组进行任意“着色”，而是将索引划分为组，其中每个组的大小至少为 2，并且其结构使得组中索引之间的所有成对间隙都是完美的平方。 

限制条件很大：$n$上升到$2 \cdot 10^5$跨测试用例。 任何尝试自由分配标签然后验证每个组内所有对的方法都会太慢，因为检查成对距离是组大小的二次方，并且可能会退化为$O(n^2)$。 

小尺寸时会立即出现关键的边缘情况。 如果$n = 1$，这是不可能的，因为单个位置会强制标签只出现一次，这是禁止的。 为了$n = 2$，我们只能使用一个标签两次，但距离是$1$，这是一个完美的正方形，所以它有效。 真正的困难是理解如何大规模扩展这个结构$n$。 

一个天真的想法是尝试将位置任意分组为平方距离的对，例如 1、4、9 等。问题是，一旦多个对重叠，一致性就会破坏：一个位置不能属于两个不同的平方偏移结构，除非它们完美对齐。 因此，该结构必须是全球性的且高度规则化。 

## 方法

 第一直觉是局部思考：尝试匹配每个索引$i$与一些$i + k^2$。 如果我们贪婪地选择平方距离并形成对，我们很快就会遇到碰撞。 一个位置可以通过多次方块跳跃到达，并将其分配给一对会阻塞另一对，从而导致死胡同。 即使我们尝试回溯，可能性的数量也会呈爆炸性增长。 

关键的观察是条件是全局且对称的：如果我们想要两个位置$i$和$j$要共享一个值，那么它们的差异必须在于平方集。 这建议根据索引的有向图来思考，其中边连接$i$到$i + s^2$。 每个值对应于选择一组边，这些边形成一个结构，其中每个节点在其组内的度数至少为 1。 

突破在于认识到我们不需要任意的平方距离，我们只需要一种适用于所有值的一致模式。 我们没有混合不同的方形跳跃，而是使用一个精心选择的方形步骤结构来平铺数组，构建一个固定的配对方案。 

关键思想是基于增加平方偏移来构建链：对于每个整数$k$，我们连接由$k^2$，但我们是分层进行的，以便每个位置以受控方式恰好参与两次。 这导致将索引分组为“方形梯子”，其中每个梯子使用不断增加的方形间隙的连续段。 

一旦识别出这种结构，问题就简化为将数组划分为大小与从连续奇数平方和导出的已知构造模式相匹配的块。 这确保了每个组自然具有至少两个大小，并且每个成对差异都是通过构造而不是检查来强制执行的。

 | 暴力配对+验证|$O(n^2)$|$O(n)$| 太慢了 |

 ## 算法演练

 1.我们预先计算最大的整数$k$这样我们建立的总结构$k$不超过$n$。 这是因为建筑以可预测的分层方式增长。 
2. 我们在区块中构建区块$k$有尺寸$2k$。 加倍的原因是每一层必须确保每个标签至少出现两次，并且方形跳跃的对称性迫使配对使用。 
3. 我们将贪婪的索引按顺序分配到这些块中。 每个块对应一个不同的标签。 
4. 在每个块内，我们以对称模式放置索引，以便相应位置之间的距离匹配$k^2$。 具体来说，块的前半部分与后半部分相匹配，偏移量恰好为$k^2$。 
5. 如果在构建所有完整块后还有剩余位置，我们使用最小平方偏移 (1) 成对分配它们，因为连续位置相差 1，即$1^2$。 
6. 如果在任何时候我们都不能为剩余位置形成至少一对，我们输出$-1$。 

关键的结构决策是迫使每个标签恰好对应一个平方距离刻度$k^2$，这可以防止不同平方约束之间的冲突。 

### 为什么它有效

 每个构造的组都是内部一致的，因为分配给同一标签的所有索引都与固定偏移量配对$k^2$。 这确保任何两次出现要么是相同的对，要么是相同平方距离的重复平移，因此每个成对差异仍然是完美的平方。 Since every label appears at least twice by construction, the “no single occurrence” constraint is satisfied. The greedy block assignment guarantees full coverage without overlap, so every index is assigned exactly once.

 ## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve(n):
    if n == 1:
        return None

    res = [0] * n
    idx = 0
    label = 1

    k = 1
    while idx + 2 * k <= n:
        # assign block of size 2k
        for i in range(k):
            res[idx + i] = label
            res[idx + i + k] = label
        idx += 2 * k
        label += 1
        k += 1

    # remaining elements
    rem = n - idx
    if rem == 0:
        return res

    if rem % 2 == 1:
        return None

    # pair leftovers using label
    for i in range(0, rem, 2):
        res[idx + i] = label
        res[idx + i + 1] = label
        label += 1

    return res

t = int(input())
for _ in range(t):
    n = int(input())
    ans = solve(n)
    if ans is None:
        print(-1)
    else:
        print(*ans)
```该代码分两个阶段构建数组。 第一个循环创建尺寸逐渐变大的结构化块$2k$，其中每个块强制执行一个基于正方形的配对规则。 第二阶段使用简单的相邻配对来处理剩余部分，这是有效的，因为距离 1 是完全平方数。 

关键的实现细节是维护一个移动索引指针`idx`，确保块永远不会重叠。 另一个微妙的点是剩余元素的处理：如果余数是奇数，我们就不能满足“至少出现两次”的规则，所以我们立即失败。

 ### 示例 1

 输入：```

```我们构建块：

 | 步骤| k | idx | 块大小 | 行动|

 最终数组：```

```这表明较大的块如何吸收更多的结构，同时仍然保持内部的方形距离配对。 

### 示例 2

 输入：```
n = 3
```我们只形成一个大小为 2 的块：

 | 步骤| k | idx | 行动|
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 放置 (0,1) 标签 1 |

 剩余元素 = 1，无法组成对，因此输出为：```
-1
```这证明了剩余结构无法配对时的不可能性条件。

 ## 边缘情况

 对于$n = 1$，算法立即失败，因为标签不能出现两次。 实现在任何构造开始之前显式检查这一点，以防止意外分配单个事件。 

对于奇数$n$，构造最大块后，剩余元素数变为奇数。 该代码拒绝这种情况，因为配对剩余元素将不可避免地创建一个单例，从而违反约束。
