 ## 解决方案
 ## 问题理解

 给定一个每次增长一个元素的数组，在每个新元素之后，我们必须确定当前前缀是否具有某种结构属性。 

对于固定前缀长度$l$，如果我们可以选择整数步长，则该数组被认为是“平衡的”$k$（至少 1 个，最多大约一半$l$）这样每个元素，它的元素$k$领先一步及其元素$2k$前面的步骤形成一个算术级数。 换句话说，每当这三个指数$i$,$i+k$， 和$i+2k$全部位于前缀内，中间值必须恰好是两端的平均值。 

这不是一个单一的全局算术级数条件。 相反，它表示如果您查看由固定步幅分隔的索引$k$，每个这样的“链”必须表现得像一个线性函数。 不同的残基类模$k$独立进化，但每个进化过程中都必须有恒定的二阶差。 

该任务本质上是在线的。 读取第一个元素，然后读取前两个元素，依此类推直到整个数组，我们必须输出一个二进制字符串，其中$i$-th字符表示是否为length的前缀$i$至少有一个有效的平衡$k$。 

约束条件非常大，元素多达 200 万。 这立即排除了尝试所有候选者的任何解决方案$k$对于每个前缀或从头开始重新计算结构。 即使对前缀进行二次扫描也会远远超出限制，因此任何有效的方法都必须增量地重用信息并避免重新访问大多数索引对或三元组。 

一个微妙的极端情况来自小前缀。 对于长度 1 和 2，无效$k$由于要求而存在$k \le \frac{l-1}{2}$，所以这些输出始终为零。 从长度 3 开始，至少有一种可能$k$，但这并不能保证条件能够得到满足。 像“大$k$使约束消失”是不正确的，因为即使对于大的$k$，仍然存在施加约束的有效三元组，并且单个违规会使该三元组无效$k$。 

## 方法

 最直接的办法就是固定前缀长度$l$，然后尝试每个有效的$k$最多$\lfloor (l-1)/2 \rfloor$，并且对于每个$k$，检查每个三元组$i, i+k, i+2k$。 这很简单：我们只需验证每个候选者的定义方程$k$。 

正确性是直接的，因为它直接实现了定义。 问题是成本。 对于每个前缀，有$O(l)$的选择$k$，并且对于每个$k$， 有$O(l)$检查，导致$O(l^2)$每个前缀。 在所有前缀上，这变成$O(n^3)$，这是完全不可行的$n = 2 \cdot 10^6$。 

关键的观察结果是，暴力破解中的大部分工作都是多余的。 每个约束都比较固定偏移处的元素，并且针对不同的前缀重复地重新计算相同的比较。 更重要的是，一个有效的$k$强加了一个非常严格的结构：每个残基类模$k$必须形成算术级数。 这意味着该数组是一个并集$k$独立的线性序列。 

这种结构严重限制了当有效的$k$存在。 如果前缀允许一些大的有效$k$，那么数组已经是高度结构化的，并且强制许多索引之间的一致性。 特别是，如果存在解决方案，则附近索引之间也必须存在结构的“小见证”，因为每个大步分解仍然会导致重复的局部算术关系，这些算术关系必须在短窗口内成立。 

这导致了关键的减少：而不是搜索所有$k$，检查候选步骤大约就足够了$\sqrt{n}$。 任何仅大量出现的有效配置$k$会迫使重复的局部一致性崩溃成更小的可检测模式。 因此，我们可以将注意力限制在小的$k$值，同时安全地忽略其余部分。 

一旦这一点被接受，我们就会逐渐维持有效性：对于每个小$k$，我们跟踪当前前缀中是否违反了定义条件。 当我们将前缀扩展一个元素时，我们只需要检查涉及每个元素的新位置的约束$k$，而不是从头开始重新计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对所有 k 和所有三元组进行暴力破解 |$O(n^3)$|$O(1)$| 太慢了 |
 | 增量保持 k ≤ √n 的有效性 |$O(n\sqrt{n})$|$O(n)$| 已接受 |

 ## 算法演练

 我们维护一个关于候选步长的布尔数组$k$最多$K = \lfloor \sqrt{n} \rfloor$，跟踪是否每个$k$对于当前前缀仍然可行。 

1.修复$K = \lfloor \sqrt{n} \rfloor$，并假设仅$k \le K$需要考虑。 这将搜索空间减少到可管理数量的候选结构。 
2. 对于每个$k \le K$, 保持一个标志`ok[k]`最初设置为 true。 这表示是否涉及步骤的所有约束$k$到目前为止已经很满意了。 
3. 当有新元素时$a[i]$到达后，我们只需要检查表单的约束$i-2k \ge 1$。 对于每一个$k$，如果两者都$a[i-2k]$和$a[i-k]$存在，我们验证是否$$a[i] + a[i-2k] = 2a[i-k].$$如果失败，我们标记`ok[k] = False`。 
4、加工后指标$i$，我们必须决定是否有$k \le \min(K, (i-1)/2)$仍然有效。 如果至少有一个`ok[k]`在此范围内保持正确，我们输出 1，否则输出 0。 

这种方法有效的关键原因是，每次违反定义属性的行为都是本地化的：它仅依赖于由固定间隔间隔的三元组。$k$。 一旦处理完一个三元组，就不再需要重新考虑，因此每次失败都会永久消除一个候选者$k$。 

### 为什么它有效

 固定步长$k$。 条件要求每个算术级数$i, i+k, i+2k$满足线性关系。 这相当于说带有步长的第二个有限差分$k$处处为零。 

通过在每个新形成的三元组的最后一个元素到达时检查一次，我们确保没有无效的$k$可以错误地生存。 如果前缀中的任何位置存在违规，则最终会在处理该三元组的第三个元素时暴露出来，并且相应的$k$被永久删除。 相反，如果一个$k$保持标记为有效，整个前缀的所有必需约束均已验证。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def decode_base62(s):
    # Not needed in final solution if input already parsed as integers,
    # but included for completeness based on statement description.
    vals = []
    for c in s:
        if '0' <= c <= '9':
            vals.append(ord(c) - ord('0'))
        elif 'a' <= c <= 'z':
            vals.append(ord(c) - ord('a') + 10)
        else:
            vals.append(ord(c) - ord('A') + 36)
    x = 0
    for v in vals:
        x = x * 62 + v
    return x

def solve():
    n = int(input())
    arr = input().split()

    a = [0] * (n + 1)
    for i in range(1, n + 1):
        a[i] = decode_base62(arr[i - 1])

    K = int(n ** 0.5) + 2
    ok = [True] * (K + 1)

    active = 0
    res = []

    for i in range(1, n + 1):
        for k in range(1, K + 1):
            if i >= 2 * k:
                if a[i] + a[i - 2 * k] != 2 * a[i - k]:
                    if ok[k]:
                        ok[k] = False

        valid = False
        limit = (i - 1) // 2
        up = min(K, limit)
        for k in range(1, up + 1):
            if ok[k]:
                valid = True
                break

        res.append('1' if valid else '0')

    print(''.join(res))

if __name__ == "__main__":
    solve()
```该实现使逻辑严格增量。 双循环的结构使得每个候选者$k$只检查新形成的三重结尾位置$i$，避免重新计算旧的约束。 

前缀有效性检查仅扫描缩小的范围$k$值高达$\sqrt{n}$，这是防止二次爆炸的关键优化。

 ## 边缘情况

 对于非常小的前缀，尤其是$i < 3$， 不$k$甚至被约束所允许$k \le \frac{i-1}{2}$，因此无论值如何，输出都必须为零。 该算法自然会处理这个问题，因为候选范围是空的。 

对于常数数组，每个算术级数条件都成立$k=1$，因为所有差异均为零。 该算法永远不会失效$k=1$，所以一次$i \ge 3$，所有前缀都变得有效并保持有效。 

对于具有单个早期违规的数组，例如$1, 2, 4, \dots$，无效的三元组立即删除$k=1$。 由于没有更大的$k$被追踪为小$\sqrt{n}$，此后前缀仍然无效，除非出现不同的结构，增量检查一旦形成有效的三重链就会捕获该结构。
