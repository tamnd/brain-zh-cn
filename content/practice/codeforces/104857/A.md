 ## 解决方案
 ## 问题理解

 我们给出三个整数：一个模数$n$，和两个残基$a$和$b$，全部为正，有$n$奇数和$\gcd(a,n)=1$。 任务是恢复一个唯一的整数$x$在范围内$1 \le x \le n-1$即同时满足两个约束条件。 

第一个约束是模平方条件：当我们平方时$x$并减少它的模数$n$，我们必须获得$a$。 这是一个经典的模平方根条件，意思是$x$是平方根$a$在乘法群模中$n$。 

第二个约束条件$x$到$b$通过地板操作应用于$\sqrt{x}$。 换句话说，如果我们看平方根的整数部分$x$，它必须等于$b$。 这迫使$x$位于非常紧的数字区间内：$b^2 \le x < (b+1)^2$。 

所以我们正在寻找一个数字$x$同时位于由下式确定的小整数区间内$b$，并且还满足模二次方程模$n$。 

的限制$n$至关重要。 该声明允许$n$非常大，可达约$10^{100}$，它立即排除了任何迭代所有候选者或执行因式分解的方法$n$。 算术必须对大整数进行，但结构表明区间限制最多将搜索空间减少到$2b+1$候选人，这足够小，如果$b$本身比较适中$n$。 唯一性保证还意味着一旦我们确定了正确的候选者，就不需要歧义处理。 

一个天真的错误是忽略区间约束并尝试所有模平方根$a$，它可以产生多个模解$n$。 另一种故障模式是错误地处理楼层约束。 例如，如果$b=3$，则有效$x$必须满足$9 \le x \le 15$，但是粗心的实现可能会错误地包括$16$或排除$15$，取决于整数平方根的计算方式。 

## 方法

 暴力解释仅从模块化条件开始。 人们可能会尝试所有的值$x \in [1, n-1]$，检查是否$x^2 \bmod n = a$，然后验证是否$\lfloor \sqrt{x} \rfloor = b$。 这在逻辑上是正确的，但搜索空间是巨大的。 即使我们只考虑上限$n \approx 10^{100}$，迭代是不可能的。 成本正比于$n$，这远远超出了可行的计算范围。 

关键的观察结果是，第二个条件将搜索空间从模算术规模缩小到一个小的整数区间。 约束条件$\lfloor \sqrt{x} \rfloor = b$方法$x$必须位于连续的整数块中。 因此，我们不需要搜索整个残基类，而只需检查周围小范围内的数字$b^2$。 在此窗口内，我们测试模块化条件。 由于问题保证了唯一的解决方案，因此我们找到的第一个匹配就是答案。 

从对所有残基的暴力破解到对有界区间的暴力破解的转变是本质的简化。 模块化约束不再是我们孤立解决的问题；而是我们需要解决的问题。 它成为应用于微小候选集的过滤器。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力胜过一切$x \in [1, n-1]$|$O(n)$|$O(1)$| 太慢了 |
 | 周围间隔扫描$b^2$|$O(b)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 计算由取平方根条件定义的整数区间。 条件$\lfloor \sqrt{x} \rfloor = b$相当于$b^2 \le x < (b+1)^2$。 这给出了一个封闭的开放范围，所有有效的候选人都必须说谎。 
2. 迭代所有整数$x$在这个区间内。 该范围的大小最多为$2b+1$，它足够小，可以直接检查。 
3. 对于每位候选人$x$, 计算$x^2 \bmod n$并将其与$a$。 这直接强制执行模约束，而无需求解模方程。 
4.第一个$x$满足模块化条件的立即返回。 唯一性保证确保不存在第二个有效候选者。 

### 为什么它有效

 正确性依赖于第二个条件限制的事实$x$到独立于模数结构的连续区间。 一旦搜索被限制在这个区间内，模方程就变成了一个简单的谓词。 由于该区间中正好有一个整数满足模约束，因此扫描该区间可以保持正确性并保证终止而不会产生歧义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input().strip())
    a = int(input().strip())
    b = int(input().strip())

    L = b * b
    R = (b + 1) * (b + 1)

    for x in range(L, R):
        if 1 <= x <= n - 1 and (x * x) % n == a:
            print(x)
            return

if __name__ == "__main__":
    main()
```该实现直接将区间约束转化为边界$L$和$R$。 该循环按升序检查每个候选者，这是安全的，因为问题保证了唯一的解决方案。 额外检查$1 \le x \le n-1$确保我们尊重域，即使间隔超过模数边界，这可能发生在$(b+1)^2$很大。 

模块化检查是使用 Python 的内置大整数执行的，因此即使$x$可以很大，乘法仍然精确。 不需要模逆或因式分解。

 ## 边缘情况

 一种微妙的情况是当间隔定义为$b$超出有效域$[1, n-1]$。 例如，如果$n=10$和$b=5$， 然后$x \in [25,36)$，这完全超出了允许的范围。 循环仍然运行这些值，但条件$1 \le x \le n-1$过滤掉所有内容，因此不会考虑错误的值。 

另一个边缘情况是当$b=0$。 那么区间就变成了$x \in [0,1)$，除了潜在的之外，它不会贡献任何有效的候选者$x=0$，但问题需要$x \ge 1$，因此正确实现可以避免返回无效的解决方案。 

最后一个重要的例子是独特性。 如果多个候选者满足区间内的模块化条件，则简单扫描仍会返回第一个，但正确性会被破坏。 唯一性的保证使得算法能够保持简单和正确，而无需回溯或模代数。
