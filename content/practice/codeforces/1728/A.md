 ## 解决方案
 ## 问题理解

 我们得到了几个测试用例。 每个测试用例中有几种颜色的球，每种颜色都有一定数量的球。 所有颜色的球总数保证为奇数。 

我们反复执行这样的操作：挑选两个不同颜色的球并将它们从袋子中取出。 此操作将球的总数减少了两个，因此总数的奇偶校验永远不会改变。 由于最初的总数是奇数，因此在所有可能的移动之后，我们总是会以仅剩下一个球的方式结束。 

当无法挑选两个不同颜色的球时，该过程就会停止，而当所有剩余的球都是相同颜色时，就会发生这种情况。 任务是确定经过一些有效的操作序列后可能是最终剩余颜色的任何颜色。 

关键的困难在于我们没有模拟固定的过程。 我们可以任意选择配对，不同的选择会导致不同的最终颜色。 我们只需要输出一种可以作为最终幸存者出现的颜色。 

约束足够小，我们不需要大量优化。 每个测试用例最多有 20 种颜色，每次计数最多 100，因此即使推理所有颜色或模拟贪婪归约也是可行的。 然而，对任意配对的直接模拟仍然是不必要的，并且会掩盖结构。 

当只有一种颜色时，会出现微妙的边缘情况。 在这种情况下，根本不可能进行任何操作，答案就是那个颜色。 

另一种重要的情况是当一种颜色已经严格占主导地位时。 例如，如果一种颜色的球比所有其他颜色的球加起来多得多，则该颜色必须是最终的幸存者，因为每次操作最多从每个配对的该颜色中删除一个，并且最终所有其他颜色首先消失。 

最重要的隐藏结构是，最终答案仅取决于一种颜色是否能够在与其他颜色的所有可能取消中幸存下来，而不取决于删除的顺序。 

## 方法

 暴力的观点会尝试模拟消除成对不同颜色的球的所有可能的序列。 每个步骤最多分支为$O(n^2)$配对的选择，过程的深度是$O(\sum cnt_i)$。 即使界限很小，这也会导致状态数量呈指数爆炸，因为不同的配对可能导致不同的中间配置。 

然而，关键的观察结果是，每次移动都会从两种不同颜色中移除一个球，因此我们本质上是取消不同颜色之间的计数。 颜色幸存的唯一方法是它没有被这种取消完全耗尽。 

将配对视为重复减少两个不同的计数器。 只要至少有两种颜色保持正值，我们就会继续从两种不同颜色中删除一个单位。 这个过程一直持续到至多一种颜色保持非零为止。 

关键的见解是，最终剩余的颜色必须是不能通过与所有其他颜色配对而完全消除的颜色。 同等地，一种颜色$i$如果我们可以安排配对，使所有其他颜色都用尽而不用尽，那么它可以是最后一种$i$第一的。 

这简化为一个简单的贪婪推理：如果我们选择任何颜色并假设它是最后的幸存者，我们必须能够将每个其他球与其本身或不同颜色相匹配，而不会过早用完所选颜色。 在这种情况下，事实证明，任何具有正计数的颜色都有可能成为最终的幸存者，因为我们总是可以通过优先将其他颜色尽可能长时间地配对来延迟其删除。 

因此，问题归结为选择任何有效的颜色索引。 由于该陈述保证存在，因此任何至少有一个球的颜色都是有效答案。

 ## 算法演练

 1. 对于每个测试用例，读取颜色数量和计数数组。 
2. 扫描计数列表并选择计数大于零的任何索引。 由于所有计数受约束均为正，因此第一个索引始终有效。 
3. 输出该索引作为测试用例的答案。 

## 为什么它有效

 每次操作都会从两种不同颜色中恰好删除一个球，因此除非与其他颜色重复配对，否则任何颜色都不会消失。 由于球的总数是奇数，因此该过程必须以仅剩一个球的方式结束。 

任何时候都不存在强制最后消除特定颜色的约束。 任何颜色都可以通过选择避免耗尽颜色的配对来保留，直到所有其他颜色都被充分减少。 由于最初每种颜色都至少有一个球，并且我们可以任意选择对，因此我们总是可以构造一个序列，其中将选定的颜色留到最后。 

这种灵活性意味着除了选择有效的现有颜色之外没有结构限制。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    cnt = list(map(int, input().split()))
    print(cnt.index(max(cnt)) + 1)
```该解决方案读取每个测试用例并选择频率最大的颜色索引。 这已经足够了，因为任何具有正计数的颜色都是有效的，并且选择最大的颜色是安全的确定性选择。 

使用`max`其次是`index`确保我们总是在每个测试用例的 O(n) 时间内选择一个有效的幸存候选者，这在约束下是微不足道的。

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

        cnt = list(map(int, input().split()))

 ## 边缘情况

 当只有一种颜色时，算法立即返回索引 1，因为它是唯一可用的选择。 无法进行任何操作，这符合进程立即停止的规则。 

当所有颜色具有相同的计数时，每个索引都同样有效。 该算法始终选择第一个最大值，这仍然是正确的可能的最终颜色，因为任何选择都可以通过配对不同的颜色直到剩下一个来实现。 

当一种颜色严格占主导地位时，例如`[1, 100, 1]`，算法选择主色。 在这种情况下，任何有效的删除顺序都会自然地将该颜色保留到最后，因为其他颜色可以通过交叉配对首先耗尽。
