 ## 解决方案
 ## 问题理解

 我们得到从 1 到 的整数序列$n$。 任务是将这个序列分成两个不相交的集合$A$和$B$因此它们的总和之间的绝对差，$|sum(A) - sum(B)|$，尽可能小。 输入是单个整数$n$输出是表示这个最小差异的单个整数。 

自从$n$可以大到$2 \cdot 10^9$，显式构造序列或尝试所有分区是不可能的。 此约束意味着任何解决方案都必须在恒定时间内运行$n$。 我们无法迭代$n$元素或子集，因为即使$O(n)$时间太慢了，任何解决方案都需要$O(n^2)$或更多是完全不可行的。 

非明显的边缘情况是由 1 到 1 之间的数字和的奇偶性引起的$n$。 第一个的总和$n$自然数是$S = n(n+1)/2$。 如果$S$是偶数，理论上可以将序列分成总和相等的两个集合，产生最小差值 0。如果$S$是奇数，最小差值必须为 1，因为两个集合的总和不可能都是总和为奇数的整数。 忽略奇偶校验的简单解决方案可能会尝试手动构造集合，这对于大型集合来说太慢了$n$。 

## 方法

 暴力方法将尝试生成序列的所有子集并计算每对不相交集的总和之差。 这种方法原则上是有效的，因为检查所有分区可以保证找到最小差异。 然而，一组大小的子集的数量$n$是$2^n$。 即使是谦虚的$n$， 说$n = 30$，这已经是超过十亿种可能性了。 为了$n$最多$2 \cdot 10^9$，这是完全不可行的。 

关键点在于该序列是从 1 开始的连续整数。$n$数字是一个简单的公式：$S = n(n+1)/2$。 两个分区之间的绝对差只能为 0，如果$S$是偶数，或者 1 如果$S$很奇怪。 这种观察消除了构造集合或迭代的需要：它将问题简化为计算$S$并检查其奇偶性。 暴力推理验证了这条捷径的正确性：最小差异仅取决于总和是偶数还是奇数。

 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算从 1 到 的序列之和$n$使用公式$S = n(n+1)/2$。 该公式源自算术级数公式，不需要迭代，这使得即使对于大型$n$。 
2. 检查奇偶性$S$。 如果$S$能被2整除，其和是偶数。 否则，总和为奇数。 
3. 如果返回 0$S$是偶数，或者 1 如果$S$很奇怪。 这是最小可能的绝对差异。 原因是偶数总和可以精确地分成两半，而奇数总和在分为整数和时总会留下余数 1。 

为什么它有效：总和公式保证我们准确地捕获总和，奇偶校验确保我们选择正确的最小差异。 由于序列是严格递增的连续整数，因此没有其他分割配置可以产生比总和奇偶校验所隐含的差异更小的差异。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
total_sum = n * (n + 1) // 2
if total_sum % 2 == 0:
    print(0)
else:
    print(1)
```该代码读取单个整数$n$，使用整数除法计算总和以避免浮点错误，然后使用模运算符检查奇偶校验。 使用整数除法可确保非常大的结果的正确性$n$没有舍入错误的风险。 条件直接打印最小差异。

 ## 边缘情况

 对于$n = 1$，总和为 1，为奇数。 该算法正确输出 1。对于$n = 2$，总和为 3，也是奇数，因此算法返回 1。对于非常大的情况$n$，公式$n(n+1)/2$在 Python 中安全地处理整数溢出，并且模检查的工作原理相同。 这些案例证实了该解决方案可以正确缩放并准确处理边界条件。
