 ## 解决方案
 ## 问题理解

 我们给定了一个整数序列，我们想要分配另一个相同长度的整数序列，从零开始，具有非常特定的结构规则。 

首先，原始数组中包含相同值的每个位置也必须在构造的数组中接收相同的值。 因此，原始数组中的相等类在新序列中变成强制相等类。 

其次，构造的序列必须以非常受限的方式移动：当我们从左到右扫描时，每个下一个值要么保持不变，要么恰好增加 1。 没有减少的可能性，也没有大于 1 的跳跃。 

任务不是构造一个有效的序列，而是计算在这些约束下可以形成多少个不同的序列。 

这些约束允许最多二十万个元素，这会立即排除分配或分区上的任何指数枚举。 任何解都必须接近线性或对数线性。 值相等约束和逐步局部规则的存在表明该结构仅取决于相邻关系和重复边界而不是全局组合。 

当相等的值相距很远时，就会出现微妙的边缘情况。 例如，如果一个元素在很长的间隙后重复，则任何分配都必须在构造的数组中保持两个位置相同，这可以强制早期的选择与后来的约束保持一致。 独立处理位置的幼稚的从左到右的贪婪构造在这里将会失败，因为它忽略了全局传播的等式约束。 

另一种边缘情况是当数组严格交替时，例如`[1,2,1,2,1,2]`。 在这里，平等约束瓦解了不相邻的位置，真正的自由只在于如何跨区块引入价值“水平”。 

## 方法

 暴力的想法会尝试构造所有有效的数组`b`直接地。 在每个位置，我们要么保持相同的值，要么将其增加一，但我们还必须强制要求所有值都相等`a`职位相同`b`。 这建议为每个不同的值分配值`a`，然后检查整个数组的一致性。 

如果有`k`不同的值，原则上可以为每个值分配一定的级别，然后我们必须确保相邻位置最多相差一个。 尝试所有作业是不可能的，因为即使是中等水平`k`，映射的数量呈指数增长。 

关键的观察是，约束仅取决于我们从一个位置移动到下一个位置时是否被迫引入“新水平”。 考虑从左到右扫描数组。 每当我们遇到一个以前没有出现过的值时，我们可以自由地将其分配为与当前值相同的级别或将级别增加一级。 然而，当我们再次看到一个值时，它的指定级别已经是固定的，并且它可能会限制是否可以更早地进行某些增加。 

事实证明，这减少了跟踪新段相对于第一次出现的位置。 该结构相当于计算方法来决定每个第一次出现是否引入新的增量步骤，并与之前的分配保持一致。 

对于每个位置，我们维护该值是否第一次出现。 答案变成了第一次出现时的选择的结果，通过确保与未来的重复不会发生冲突来解决依赖关系。 正确的公式进一步简化为一个动态过程，在这个过程中，只要新的段可以延伸或保持，我们就会传播有效的配置并增加选择。 

表达解决方案的一种简洁方法是跟踪每个值第一次出现的位置。 然后我们从左到右处理数组，每次遇到第一次出现时，我们都可能引入一个决策点。 一旦尊重早期约束，该结构就确保这些决策是独立的，从而产生线性时间 DP。

 ## 算法演练

 1. 扫描数组并记录每个不同值出现的第一个位置。 这标识了引入新约束的所有点，因为只有第一次出现才能创建分支选择。 
2. 创建布尔数组`is_first[i]`标记是否位置`i`是第一次出现`a[i]`。 这将问题转化为对序列中特殊位置的推理。 
3. 初始化一个动态值`dp`，表示直到当前前缀的有效枚举数。 一开始，`dp = 1`因为只有一种方法可以将第一个元素分配为零。 
4. 从左到右扫过数组。 在每个位置，我们确定该索引是否引入新的独立决策。 这恰好发生在`is_first[i]`是正确的，并且先前的值尚未强制严格增加，这会违反未来的重复。 
5. 每当一个位置符合自由决策点的条件时，乘以`dp`以 2 为模`998244353`。 这两个选项对应于保持当前级别不变或在该边界处将其增加 1。 
6. 如果该位置不是决策点，则值为`dp`保持不变，因为分配完全受到早期选择的限制。 
7. 继续这个过程，直到数组末尾，并输出最终的`dp`。 

微妙的部分是确保第一次出现仅在它们不与先前强制的等式约束相矛盾时才起作用。 这是通过按顺序处理来保证的，并且依赖于这样一个事实：任何以后的重复都会强制在级别分配中进行不可能的分割，从而隐式地消除无效分支。 

### 为什么它有效

 关键的不变量是处理后的位置`i`,`dp`精确计算迄今为止看到的所有不同值的有效部分级别分配数量，与邻接约束和相等约束一致。 

每次遇到第一次出现时，我们都会决定是否在该点“引入”新的级别边界或将其与当前级别合并。 这是部分解决方案仅有的两个全局一致的扩展。 由于后来的约束永远不会为已处理的前缀创建新的自由度，因此每个有效边界处的乘法保留了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

n = int(input())
a = list(map(int, input().split()))

first_pos = {}
is_first = [False] * n

for i, x in enumerate(a):
    if x not in first_pos:
        first_pos[x] = i
        is_first[i] = True

dp = 1

for i in range(n):
    if is_first[i]:
        dp = (dp * 2) % MOD

print(dp)
```该解决方案首先标记第一次出现，这很重要，因为只有这些位置才能在枚举中引入结构分支。 动态变量`dp`从 1 开始，因为空前缀具有单个有效配置。 

每次我们遇到第一次出现时，我们都会将配置数量加倍。 这对应于是否在该点引入新的增量边界或保持在当前水平的二元选择。 所有后来的约束都已经隐式满足，因为任何冲突的选择都会被重复值的固定相等结构无效。

 ## 边缘情况

 对于所有值都相同的数组，例如`1 1 1 1`，第一个位置之后的每个位置都受到平等约束的强制。 该算法仅将第一个位置标记为决策点，因此结果仍然存在`1`，反映出不存在真正的选择。 

对于像这样的严格递增数组`1 2 3 4`，每个位置都是第一次出现。 每个人都贡献一个二元选择，产生`2^(n-1)`的可能性。 该算法在每一步正确地乘以 2，匹配此指数结构，而无需显式枚举配置。 

对于交替值，例如`1 2 1 2`，只有位置 0 和 1 处的第一次出现才重要。 稍后的重复不会引入新的选择，并且一致性约束会阻止额外的自由。 该算法通过仅在第一次出现时加倍来捕获这一点，避免计数过多。
