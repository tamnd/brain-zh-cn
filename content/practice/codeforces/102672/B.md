 ## 解决方案
 ## 问题理解

 我们有`n`舞者放置在整数坐标上。 几个舞者可能共享相同的坐标。 在舞蹈过程中，每个舞者以相同的概率独立地向左或向右移动一个单位。 

如果所有动作后占据的多组位置与之前完全相同，则舞蹈成功。 我们可以选择舞者的初始位置，并且需要最大化舞蹈成功的可能性。 输出是该最大概率的以 2 为底的对数。 

的价值`n`可以大到 40000。这立即排除了模拟、对舞者数量的动态编程或任何取决于可能的放置数量的方法。 解决方案必须来自于找到一种数学模式，将答案简化为直接公式。 

第一个隐藏的约束来自奇偶校验。 每个舞者恰好跨过两个整数坐标之间的一个间隙。 为了使最终配置与初始配置相匹配，每个间隙必须有相同数量的舞者在两个方向上穿过它。 这意味着舞者总数必须是平衡交叉总数的两倍。 结果，奇数的舞者永远无法工作。 

例如，对于一名舞者：```
1
```答案是`0`，因为唯一的舞者必须远离其原始坐标。 

举个偶数的例子：```
4
```最优概率是`1/8`，所以输出是：```
-3
```一个常见的错误是将所有舞者仅放在两个相邻的坐标上。 对于四个舞者，每侧放置两个只能给出一个有效的交叉模式，概率`1/16`。 更好的安排使用带有计数的三个坐标`1,2,1`，其中中间对可以以两种不同的方式交换，给出概率`2/16`。 

## 方法

 蛮力方法将尝试舞者的不同位置，并计算保持配置不变的所有可能的动作选择。 问题在于，可能的坐标选择有无限多种，即使我们将自己限制在一个很小的区间内，运动结果的数量也是`2^n`。 为了`n = 40000`，甚至检查单个位置也是不可能的。 

有用的观察是停止考虑个别舞者，而是考虑差距。 假设两个相邻占用坐标之间的间隙为`x`舞者从左向右穿过它。 一场成功的舞蹈需要`x`舞者从右到左跨越相同的间隙。 因此，每个间隙都与平衡数量的交叉相关联。 

设穿过连续间隙的次数为：```
g1, g2, ..., gk
```舞者总数正好是：```
2 * (g1 + g2 + ... + gk)
```因为每次交叉都会从每一侧贡献一名舞者。 

对于固定的间隙序列，有效动作选择的数量取决于每组舞者可以选择其方向的方式数量。 在两个间隙之间的位置`a`和`b`， 有`a + b`舞者，我们必须选择哪个`a`他们中的一些人向左走。 这有助于：```
C(a + b, a)
```方式。 

剩下的问题是如何选择间隙大小以使这些二项式系数的乘积最大化。 将交叉计数分成较小的间隙总是有帮助的。 最大的贡献来自于让每一个间隙都有尺寸`1`。 

如果有`n / 2`总交叉点且每个间隙的大小为一，则排列变为：```
1, 2, 2, ..., 2, 1
```两端各贡献一种可能的选择，而每个中间位置贡献：```
C(2,1) = 2
```有`n / 2 - 1`中间位置，因此成功的移动分配次数为：```
2^(n/2 - 1)
```可能的舞蹈总数为：```
2^n
```所以最大概率是：```
2^(n/2 - 1) / 2^n = 2^(-n/2 - 1)
```因此答案很简单：```
-n/2 - 1
```对于甚至`n`。

 | --- | --- | --- | --- |
 | 蛮力 | 指数| O(1) | O(1) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取舞者的数量`n`。 唯一需要的信息是奇偶校验`n`，因为最优概率仅取决于舞者数量是否可以分成平衡交叉。 
2.如果`n`为奇数，输出`0`。 成功的舞蹈需要每个舞者都与一个在相反方向跨越相同间隙的舞者配对，这对于奇数个舞者来说是不可能的。 
3.如果`n`为偶数，输出`-n/2 - 1`。 这是通过到处使用单位大小的间隙获得的概率的对数。 

为什么它有效：

 每一次成功的舞蹈都对应于跨越每一个间隙的平衡交叉。 交叉口总数固定为`n/2`。 将这些交叉点分成更多的间隙会增加独立选择的数量。 最好的分割方式是使每个间隙恰好包含一个交叉点。 这将创建最大可能数量的有效移动分配，即`2^(n/2-1)`。 既然所有`2^n`方向选择的可能性是相同的，概率恰好是`2^(-n/2-1)`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    if n % 2:
        print(0)
    else:
        print(-n // 2 - 1)

solve()
```该实现仅检查舞者的数量是否为偶数。 无需存储头寸或模拟任何运动，因为最佳概率完全由奇偶性和大小决定`n`。 

表达式`-n // 2 - 1`之所以有效，是因为 Python 的整数除法对于偶数来说是精确的`n`。 无需浮点计算，避免了对数输出的精度问题。

## 测试用例```python
import sys
import io

def solve_io(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    if n % 2:
        out = "0\n"
    else:
        out = str(-n // 2 - 1) + "\n"

 ## 边缘情况

 对于`n = 1`，不存在可能的平衡。 唯一的舞者必须移动到不同的坐标，因此概率为零，算法打印`0`。 

对于奇数，例如：```
5
```简单的公式可能仍会尝试计算对数值。 交叉论证表明这种情况不可能发生，因为成功的舞蹈需要每次交叉都配对，这意味着舞者的总数必须是偶数。 该算法立即检测到这一点并打印`0`。 

对于最小的偶数情况：```
2
```公式给出：```
-2 / 2 - 1 = -2
```对应于概率`1/4`。 两个相邻的舞者必须交换位置，四种可能的动作选择中的一种会成功。 

对于大输入，例如：```
40000
```该解决方案不会构造放置或枚举可能性。 它直接计算：```
-20000 - 1 = -20001
```因此不存在溢出或性能问题。
