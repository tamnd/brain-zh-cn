 ## 解决方案
 ## 问题理解

 我们有很多朋友参加披萨聚会，主人必须将圆形披萨切成完全相等的片，以便每个人（包括主人）都能吃到一片。 如果有$n$朋友们，披萨必须分成几份$n + 1$等份。 

允许的操作是在披萨上进行直线切割，每次切割都有助于形成这些相等的扇区。 目标是尽量减少生产所需的直切次数$n + 1$相同的切片。 

输入是单个整数$n$，可能大到$10^{18}$，这立即排除了任何显式模拟切割或构建几何体的方法。 任何解决方案都必须将问题简化为直接的数学计算。 

一些边缘案例揭示了问题的结构。 什么时候$n = 0$，只有一个人，所以不需要剪切。 什么时候$n = 3$，我们需要 4 个相等的切片，这需要穿过中心进行 2 次直线切割。 什么时候$n = 4$，我们需要 5 个相等的切片，并且示例建议进行 5 次切割，表明奇偶性或整除性属性很重要。 每次切割总是将切片数量增加固定量的天真的假设会失败，因为切割的行为会根据它们是否与中心相交以及它们的排列方式而有所不同。 

## 方法

 强力解释将尝试模拟放置直线切口并跟踪圆被划分为多少个区域。 每个新的切割都可以与所有先前的切割相交，以一种不平凡的方式增加切片的数量。 人们可以尝试逐步对此进行建模：从一块开始，然后尝试所有可能的切割方向，并计算形成了多少个区域。 

问题是每次切割都可以与所有先前的切割相交，所以之后$k$切割，件数可以按二次方增长$k$。 尝试模拟或搜索能够准确产生的最小配置$n + 1$等角扇区很快就会变得棘手，特别是因为$n$可以达到$10^{18}$。 

关键的观察是，我们实际上并不是在连续意义上优化几何形状，而是匹配一个非常严格的组合结构：圆的等角分区。 唯一有意义的配置来自于通过中心绘制直径或使用特殊结构，其中所有切口都像车轮的辐条一样对称排列。 这将问题简化为询问需要多少对称直切口才能形成$n + 1$围绕一个圆的角度相等。 

从这个结构中，答案可以简化为简单的奇偶校验规则。 如果$n + 1$很奇怪，我们不能使用径向切割对称地配对切片，因此我们必须绘制一整套径向切割，每个扇区一个。 如果$n + 1$是均匀的，穿过中心的每条直线都会产生两个相对的切片，因此每次切割的效率更高。 

这导致了一个基于是否$n + 1$是偶数还是奇数，这进一步简化了检查是否$n$是偶数还是奇数。

 ## 算法演练

 1.读取整数$n$，代表好友数量。 
2. 计算$k = n + 1$，所需的相等披萨片的数量。 
3.如果$n = 0$，立即输出 0，因为单个切片不需要切割。 
4.如果$k = 2$，输出 1，因为一次直线直径切割将披萨精确地分成两等份。 
5. 如果$k$为偶数，输出$k // 2$，因为每个直径状切割都会产生两个相等的相对切片。 
6. 如果$k$为奇数且大于1，输出$k$，因为每个切片必须由径向边界独立形成。 

偶数情况背后的推理来自对称性：穿过中心的直线总是产生完全相同的两个相等的一半，并且可以排列多条这样的线来将圆分成成对的相对扇形。 当扇区数量为偶数时，这种配对结构非常适合。 当它是奇数时，无法将所有扇区配对，从而迫使必须显式引入每个扇区边界的简并配置。 

### 为什么它有效

 只能在尊重旋转对称的配置中使用直线将圆划分为相等的角度区域。 直线切割总是引入一条对称线，将现有的角度区域成对划分。 这意味着有效的结构必须与中心周围的配对结构对齐。 当所需切片数量为偶数时，每个切片都可以与相反的切片配对，因此每次切割的贡献最大。 当它是奇数时，不存在完整的配对，因此该结构退化为每个边界方向一次切割，迫使线性增长。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())
k = n + 1

if k == 1:
    print(0)
elif k == 2:
    print(1)
elif k % 2 == 0:
    print(k // 2)
else:
    print(k)
```该代码直接实现了上面导出的基于奇偶校验的规则。 前两个条件处理不需要几何推理的简单情况。 偶数情况分支对配对参数进行编码，而奇数情况分支反映了对称性的缺乏，迫使每个切片边界方向进行一次切割。 

必须小心$k = 1$情况下，因为当只有一片时不需要切割。 另一个微妙之处是区分$k = 2$从一般偶数情况来看，由于公式$k // 2$否则，如果在没有解释的情况下被误用，就会错误地提出分数推理。

def run(inp: str) -> str:

 ## 边缘情况

 对于$n = 0$，我们有$k = 1$。 该算法立即返回 0，这对应于单个切片不需要切割。 

为了$n = 1$，我们有$k = 2$。 该条件显式返回 1，匹配单个直直径切割。 

对于较大的偶数值，例如$n = 10^{18} - 1$，计算简化为整数除法$k$2，由于任意精度整数，这在 Python 中仍然是安全的。 

对于奇数，例如$n = 4$， 在哪里$k = 5$，后备分支返回$k$，反映出不存在配对结构并且每个切片方向必须独立实现。
