 ## 解决方案
 ## 问题理解

 贝尔兰每年都有一定的天数。 第一年有`a`天，接下来有`a + 1`，依此类推`n`连续几年。 

一年来与`x`天，政府选择满足两个条件的一个月长度。 首先，月份长度必须是完全平方数。 其次，一定要分`x`确切地说，月数是一个整数。 在所有这些选择中，他们选择尽可能长的月份。 

如果选择的月份长度是`d²`，则该年的月数为`x / d²`。 由于每个月都需要一张纸，那么当年对答案的贡献正是：$$\frac{x}{\text{largest square divisor of }x}$$我们必须计算所有年份的总页数`a`到`a + n - 1`。 

制约因素很大。 两个都`a`和`n`可以达到`10^7`，并且区间长度也可以接近`10^7`。 通过试除法独立分解每个数字的解决方案的执行大致如下：$$10^7 \cdot \sqrt{10^7}$$在最坏的情况下进行操作，远远超出了时间限制。 

关键的挑战是我们需要有关大量连续整数范围的平方除数的信息。 这强烈建议使用类似筛子的方法进行预处理，而不是一一处理数字。 

这里有几个容易犯的错误。 

一个常见的错误想法是使用小于或等于年份长度的最大完全平方。 这还不够，因为平方必须精确地划分年份。 

例如：

 输入：```
10 1
```一年有10天。 不超过10的最大平方是9，但9不能整除10。正确的平方除数是1，所以答案是：```
10
```另一个微妙的情况是年份本身是完全平方数。 

输入：```
36 1
```最大的平方除数本身是 36，因此一年仅包含一个月，贡献为：```
1
```如果不小心实现，只搜索真除数，就会错误地返回 4 或 9。 

素数是另一个重要的边缘情况。 

输入：```
13 1
```唯一的平方除数为 1，因此贡献为：```
13
```如果实现假设每个数字都有一些更大的平方除数，那么这里将会失败。 

## 方法

 直接暴力解决方案很简单。 对于每年的长度`x`, 枚举所有整数`d`这样`d² ≤ x`。 每当`d²`划分`x`，更新最佳平方除数。 最后添加`x / best`到答案。 

这是有效的，因为定义是明确的。 我们简单地测试每一个可能的平方除数并保留最大的有效除数。 

问题是运行时间。 单个数字最多`10^7`需要粗略检查`√10^7 ≈ 3162`候选人。 执行此操作最多`10^7`年导致数百亿次操作。 

我们需要避免重复的除数搜索。 

关键的观察是我们真正需要的数量是：$$\frac{x}{\text{largest square divisor of }x}$$这个值在数论中有一个众所周知的解释。 如果我们分解：$$x = p_1^{e_1} p_2^{e_2} \cdots p_k^{e_k}$$然后最大的平方除数去除指数的每个偶数部分。 剩余值为：$$p_1^{e_1 \bmod 2} p_2^{e_2 \bmod 2} \cdots p_k^{e_k \bmod 2}$$这称为无平方核`x`。 

例如：$$108 = 2^2 \cdot 3^3$$最大的平方除数是：$$2^2 \cdot 3^2 = 36$$剩下的因子是：$$3$$所以今年贡献了3张。 

现在问题变得容易多了。 对于范围内的每个数字，我们只需要无平方核`10^7`。 

这可以通过筛子有效地计算。 

开始于`f[i] = i`。 对于每一个素数`p`, 除`f[j]`经过`p²`对所有倍数重复进行`j`的`p²`。 处理完所有素数后，`f[x]`正好变成无平方核`x`。 

总复杂度接近谐波筛复杂度并且很容易符合限制。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n\sqrt{A})$|$O(1)$| 太慢了|
 | 最佳 |$O(M \log \log M)$|$O(M)$| 已接受 |

 这里，`M = a + n - 1`。 

## 算法演练

 1. 阅读`a`和`n`，并定义`m = a + n - 1`，我们需要处理的最大年份长度。 
2. 创建数组`f`最初在哪里`f[i] = i`对于每一个`1 ≤ i ≤ m`。 

一开始，每个数字都被假定为它自己的无平方核。 
3. 构建一个筛子来识别以下素数`√m`。 

我们只关心平方在该范围内的素数。 
4. 对于每个素数`p`, 计算`sq = p * p`。 
5. 迭代所有的倍数`sq`。 

每个倍数至少包含一个因数`p²`，所以它的无平方核不应包含该平方因子。 
6. 虽然当前值可以被整除`sq`，除以`sq`。 

重复除法很重要，因为数字可能包含更高的幂，例如`p⁴`或者`p⁶`。 
7. 处理完所有素数后，`f[x]`等于无平方核`x`。 
8. 总和`f[x]`多年来`x`从`a`到`m`。 
9. 打印总数。 

### 为什么它有效

 每个整数都可以唯一地分解为素数。 认为：$$x = \prod p_i^{e_i}$$最大平方除数去除指数中的所有偶数贡献：$$\prod p_i^{2\lfloor e_i/2 \rfloor}$$划分`x`按此数量留下：$$\prod p_i^{e_i \bmod 2}$$这正是无平方核。 

筛子处理每个素数平方`p²`并从所有受影响的号码中重复删除它。 在所有这些删除之后，每个剩余的质数指数要么是 0 要么是 1，这意味着结果是无平方的。 由于去除了所有平方因子，并且仅去除了平方因子，因此最终值正是当年所需的贡献。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, n = map(int, input().split())

    m = a + n - 1

    # f[x] will become the square-free kernel of x
    f = list(range(m + 1))

    # sieve for primes
    is_prime = [True] * (m + 1)
    is_prime[0] = is_prime[1] = False

    p = 2
    while p * p <= m:
        if is_prime[p]:
            # remove p^2 factors from all multiples
            sq = p * p

            for x in range(sq, m + 1, sq):
                while f[x] % sq == 0:
                    f[x] //= sq

            # mark composite numbers
            for multiple in range(p * p, m + 1, p):
                is_prime[multiple] = False

        p += 1

    ans = 0
    for x in range(a, m + 1):
        ans += f[x]

    print(ans)

solve()
```数组`f`从恒等映射开始，所以`f[x] = x`。 当筛子运行时，平方因子将从每个条目中删除，直到仅保留无平方部分。 

重复的除法循环是必不可少的。 认为`x = 144 = 2^4 * 3^2`。 去除`2²`只有一次会留下另一个平方因子：$$144 \to 36$$但 36 仍然包含`2²`。 循环继续，直到该因素完全消失。 

素筛和去平方过程合并在一次遍历中。 该实现对复合材料进行标记与标准埃拉托斯特尼筛完全相同。 

答案可能会变得很大，可能约为：$$10^7 \cdot 10^7$$所以Python整数是必要的。 Python 会自动处理这个问题。 

内存使用量是可以接受的，因为数组大致包含`10^7`每个元素都符合 PyPy 的竞赛限制。

 ## 边缘情况

 考虑输入：```
13 1
```数字 13 是质数。 筛子永远不会去除任何平方因子，因为不存在任何平方因子。 存储的值仍然是：$$f[13] = 13$$该算法输出 13，这是正确的，因为唯一的平方除数是 1。 

现在考虑：```
36 1
```最初：$$f[36] = 36$$加工时`2² = 4`，算法重复除法：$$36 \to 9$$加工时`3² = 9`，它再次划分：$$9 \to 1$$最终贡献为1，即一个月36天。 

一个更微妙的例子是：```
72 1
```因式分解：$$72 = 2^3 \cdot 3^2$$最大的平方除数是：$$2^2 \cdot 3^2 = 36$$所以答案应该是：$$72 / 36 = 2$$筛子除去`2²`一次：$$72 \to 18$$然后删除`3²`一次：$$18 \to 2$$剩余的值正是无平方核。 

最后，考虑一个具有更高平方幂的数字：```
144 1
```因式分解：$$144 = 2^4 \cdot 3^2$$重复的除法循环消除了`2²`两次：$$144 \to 36 \to 9$$然后删除`3²`：$$9 \to 1$$如果没有重复除法，算法将错误地停止在 9 而不是 1。
