 ## 解决方案
 ## 问题理解

 我们给出一个线性同余生成器，一个经典的伪随机序列公式：$$r_i = (a \cdot r_{i-1} + b) \bmod m$$序列开始于`r0`，并且每个下一个值都是根据前一个值计算的。 由于每个值都取模`m`，只有`m`可能的状态：`0`通过`m - 1`。 

任务不是找出序列第一次重复的时间。 我们特别需要最终出现的重复周期的长度。 一个序列在进入循环之前可能有一些不重复的前缀。 

例如，与：```
a = 2
b = 6
m = 12
r0 = 11
```序列变为：```
11 -> 4 -> 2 -> 10 -> 2 -> 10 -> ...
```价值`11`仅出现一次。 此后，序列将永远交替`2`和`10`，所以周期为`2`。 

约束条件`m ≤ 100000`是关键观察。 由于每个生成的值都介于`0`和`m - 1`，序列最多可以访问`m`某些值重复之前的不同状态。 这立即排除了任何无限探索的担忧。 甚至一个`O(m)`或者`O(m log m)`解决方案很容易符合限制。 

比较每对位置的简单方法将变成二次方。 和`m = 100000`， 一个`O(m²)`算法可能需要大约`10^10`操作，远远超出了时间限制。 

棘手的部分是区分前期和实际周期。 

考虑这个输入：```
0 0 10 7
```顺序是：```
7 -> 0 -> 0 -> 0 -> ...
```正确答案是`1`， 不是`2`。 粗心的实现测量任何值的第一次和第二次出现之间的距离可能会错误地计算前期的一部分。 

另一个微妙的情况是循环立即开始：```
1 1 5 0
```序列变为：```
0 -> 1 -> 2 -> 3 -> 4 -> 0 -> ...
```整个序列从一开始就是循环的，所以答案是`5`。 

当序列到达固定点时，会发生第三种边缘情况：```
5 3 100 15
```假设序列最终变为：```
78 -> 78 -> 78 -> ...
```期间还在`1`，因为单个值会永远重复。 

## 方法

 蛮力的想法很简单。 逐步生成序列并存储每个产生的值。 每当一个值再次出现时，尝试通过比较未来的元素来确定循环长度。 

这是有效的，因为序列是确定性的。 一旦我们重新访问之前的状态，该点之后的所有内容都会重复相同。 问题是效率。 如果我们反复比较大后缀来验证候选周期，最坏情况的复杂度就会变成二次方。 

重要的观察结果是，生成器的行为就像一个有向图，其中每个节点都只有一个出边。 对于任何状态，都存在下一个状态。 这样的图总是由一条通向循环的路径组成。 

由于只有`m`在可能的状态下，第一个重复值立即标识循环的开始。 

假设值`x`首先出现在位置`p`，稍后再次出现在位置`q`。 

因为转换函数是确定性的：```
next(x) is always the same
```位置后的整个后缀`p`必须匹配位置后的后缀`q`。 这意味着周期长度很简单：```
q - p
```因此，我们只需要记住每个值出现的第一个位置，而不是存储整个序列并进行比较。 

算法变为：

 1.一一生成值。 
2. 存储每个值出现的第一个索引。 
3. 当值重复时，返回当前索引与第一次出现索引之间的差值。 

由于每个状态在重复之前最多处理一次，因此该算法以线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(平方米) | O(米) | 太慢了|
 | 最佳 | O(米) | O(米) | 已接受 |

 ## 算法演练

 1. 阅读`a`,`b`,`m`， 和`r0`。 
2. 创建字典或数组`first_seen`它存储每个值出现的第一个索引。 
3. 标记起始值`r0`如位置所见`0`。 
4. 使用以下命令重复生成下一个值：$$r = (a \cdot r + b) \bmod m$$5. 生成每个新值后增加当前位置计数器。 
6. 检查新值之前是否出现过。 
7. 如果该值是新值，则存储其第一次出现的位置并继续。 
8. 如果该值已经出现在该位置`p`，序列进入了一个循环。 周期长度为：$$\text{current position} - p$$9. 打印该长度并停止。 

### 为什么它有效

 顺序完全由其当前值决定。 如果有一些值`x`如果出现在两个不同的位置，那么两个位置的未来演化必定是相同的。 

认为：```
r_p = r_q
```和`p < q`。 

然后：```
r_{p+1} = r_{q+1}
r_{p+2} = r_{q+2}
...
```因为两个位置对相同的值应用相同的转换公式。 

这意味着该序列每次都会重复`q - p`从位置开始的步骤`p`。 由于我们停在第一个重复值处，因此该差值就是最小有效周期。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, b, m, r = map(int, input().split())

first_seen = [-1] * m
first_seen[r] = 0

pos = 0

while True:
    r = (a * r + b) % m
    pos += 1

    if first_seen[r] != -1:
        print(pos - first_seen[r])
        break

    first_seen[r] = pos
```数组`first_seen`存储每个余数出现的第一个位置。 由于每个值都在范围内`[0, m - 1]`，使用数组比使用字典更快、更简单。 

变量`pos`表示序列中当前值的索引。 我们从`r0`在位置`0`。 

在循环内，我们首先生成下一个值，然后递增位置。 顺序很重要。 如果我们在生成下一个状态之前递增，则存储的索引将错误地移动并在循环长度中产生相差一的错误。 

当我们遇到以前见过的值时，我们从当前位置减去它第一次出现的位置。 这个差异正是周期长度。 

循环保证终止，因为只有`m`不同的状态。

## 测试用例```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    a, b, m, r = map(int, input().split())

    first_seen = [-1] * m
    first_seen[r] = 0

    pos = 0

    while True:
        r = (a * r + b) % m
        pos += 1

        if first_seen[r] != -1:
            print(pos - first_seen[r])
            return

        first_seen[r] = pos

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output.strip()

# provided sample
assert run("2 6 12 11\n") == "2", "sample 1"

# minimum-size input
assert run("0 0 1 0\n") == "1", "single state"

# cycle starts immediately
assert run("1 1 5 0\n") == "5", "full modulo cycle"

# fixed point after one step
assert run("0 0 10 7\n") == "1", "constant sequence"

# off-by-one detection
assert run("2 0 7 1\n") == "3", "cycle length should be 3"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 |`0 0 1 0`|`1`| 最小可能的状态空间|
 |`1 1 5 0`|`5`| 周期立即开始 |
 |`0 0 10 7`|`1`| 预周期后的定点周期|
 |`2 0 7 1`|`3`| 捕获索引移位错误|

 ## 边缘情况

 考虑输入：```
0 0 10 7
```生成的序列为：```
7 -> 0 -> 0 -> 0 -> ...
```追踪：

 | 职位| 价值|
 | --- | --- |
 | 0 | 7 |
 | 1 | 0 |
 | 2 | 0 |

 价值`0`首先出现在位置`1`并在位置重复`2`。 算法返回`2 - 1 = 1`，这是正确的。 初始值`7`属于前期，不属于周期。 

现在考虑：```
1 1 5 0
```序列变为：```
0 -> 1 -> 2 -> 3 -> 4 -> 0
```追踪：

 | 职位| 价值|
 | --- | --- |
 | 0 | 0 |
 | 1 | 1 |
 | 2 | 2 |
 | 3 | 3 |
 | 4 | 4 |
 | 5 | 0 |

 重复值`0`第一次出现在位置`0`，所以算法返回`5`。 这证实了立即开始的循环被正确处理。 

最后，考虑：```
5 3 100 15
```假设序列达到：```
78 -> 78 -> 78 -> ...
```第一次重复发生在一步之后，因此算法计算：```
current_position - first_seen[78] = 1
```自循环仍然是一个有效的循环，算法自然会处理它，没有特殊情况。
