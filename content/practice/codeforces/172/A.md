 ## 解决方案
 ## 问题理解

 我们得到了一个城市的朋友的电话号码列表。 每个电话号码都是一串数字，并且所有数字的长度都相同。 任务是找到城市电话代码，Polycarpus 将其定义为所有这些号码共享的最长公共前缀。 换句话说，城市代码是第一次不匹配发生之前每个数字开头的数字序列。 输出是该前缀的长度，而不是前缀本身。 

这些限制告诉我们最多可以有 30,000 个数字，每个数字最多 20 位数字。 这意味着任何逐个字符比较每个数字的解决方案都是可行的，因为总比较次数最多为 30,000 次乘以 20，即 600,000 次操作，完全在 2 秒的限制内。 所有数字都具有相同长度和不同的保证消除了歧义，但我们需要处理这些数字根本不共享公共前缀的可能性。 例如，如果数字是`123`和`987`，正确的输出是 0。假设第一个字符始终匹配的天真的方法可能会默默地产生错误的答案。 

另一种边缘情况是除最后一个字符外所有数字都相同。 例如，`5550`,`5551`,`5552`。 最长的公共前缀是`555`，长度为 3。如果不正确地检查所有数字的字符相等性，粗心的实现可能会多算或少算。 

## 方法

 最直接的方法就是暴力破解。 以第一个数字作为参考，然后迭代每个字符索引并将该字符与所有其他数字中的相应字符进行比较。 在第一个不匹配处停止。 这种方法之所以有效，是因为我们只比较字符，直到发现不匹配为止。 在最坏的情况下，每个数字的每个字符都匹配，所以我们执行`n * length`比较，考虑到限制，这是可以管理的。 

一种稍微结构化的方法是使用成对归约。 从第一个数字作为当前前缀开始，然后通过将其与每个后续数字进行比较来迭代缩短它，直到它与该数字的开头匹配。 这种技术避免了重复检查我们已经知道在早期位置不同的字符，尽管对于这些小长度，性能增益是最小的。 

关键的见解是，由于字符串很短（最多 20 位数字），因此我们可以安全地逐个字符地比较所有数字，而不必担心效率。 问题的结构——固定长度的字符串、有保证的数字内容和较小的最大长度——使得暴力方法本质上是最优的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（比较所有字符串中的每个字符）| O(n * m)，m = 字符串长度 | O(1) | O(1) | 已接受 |
 | 迭代前缀缩减 | O(n * m) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取好友数量`n`以及电话号码列表。 所有数字都具有相同的长度`m`。 
2. 将第一个电话号码作为初始参考前缀。 
3. 初始化变量`prefix_length`至总长度`m`。 这表示最大可能的前缀。 
4. 迭代剩余的电话号码。 
5. 对于每个数字，从头到当前逐字符迭代`prefix_length`。 
6. 将相同位置的字符与参考编号进行比较。 如果发生不匹配，则减少`prefix_length`到不匹配的索引并跳出内循环。 
7. 继续下一个数字，进一步减少`prefix_length`如果需要的话。 
8. 处理完所有数字后，`prefix_length`保存最长公共前缀的长度。 打印出来。 

不变的是，处理完每个数字后，`prefix_length`始终反映迄今为止处理的所有号码共享的最长前缀。 没有超出的字符`prefix_length`可以是有效公共前缀的一部分，保证正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
numbers = [input().strip() for _ in range(n)]

prefix_length = len(numbers[0])

for num in numbers[1:]:
    for i in range(prefix_length):
        if num[i] != numbers[0][i]:
            prefix_length = i
            break

print(prefix_length)
```我们首先读取所有输入数字并去除换行符。 我们假设第一个数字具有最大可能的前缀。 对于每个后续数字，我们仅检查`prefix_length`因为超出它的任何字符都不能成为公共前缀的一部分。 循环在不匹配时立即中断，从而防止不必要的比较。 最后，我们打印前缀的长度，这正是问题所要求的。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    numbers = [input().strip() for _ in range(n)]
    prefix_length = len(numbers[0])
    for num in numbers[1:]:
        for i in range(prefix_length):
            if num[i] != numbers[0][i]:
                prefix_length = i
                break
    return str(prefix_length)

 ## 边缘情况

 如果除最后一个字符外所有数字都相同，则算法会在每个数字第一次不匹配时正确停止比较。 例如，`5550`,`5551`,`5552`结果`prefix_length`= 3. 对于完全不重叠的数字，例如`123`和`987`，算法立即在第一个字符处检测到不匹配并设置`prefix_length`= 0。对于单位数字，该算法会自然地处理匹配和不匹配情况，返回 1 或 0。所有边缘情况均由逐字符比较循环正确处理，并在不匹配时提前中断。
