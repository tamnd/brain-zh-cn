 ## 解决方案
 ## 问题理解

 时钟显示十位数的时间戳。 在任何时刻，每个数字每秒消耗固定量的能量，具体取决于显示的数字。 显示从时间戳开始`0000000000`，然后每秒增加一。 前导零始终存在，因此每个状态都是十个字符的数字。 

输入的是单个数字`N`，时钟运行的秒数。 在那几秒钟内，时钟显示的时间戳来自`0`通过`N - 1`。 任务是找出所有十位数字在这些显示状态期间消耗的总能量。 

数字成本是七段样式字体中的活动段数：

 | 数字| 成本|
 | ---| ---|
 | 0 | 6 |
 | 1 | 2 |
 | 2 | 5 |
 | 3 | 5 |
 | 4 | 4 |
 | 5 | 5 |
 | 6 | 6 |
 | 7 | 3 |
 | 8 | 7 |
 | 9 | 6 |

 的价值`N`可以几乎`10^10`。 直接模拟需要访问多达一百亿个时间戳，每个时间戳需要检查十位数字，这给出了大约`10^11`数字运算。 这远远超出了一秒的限制。 该解决方案必须避免迭代时间戳，而是计算每个数字在每个位置出现的频率。 

主要的边缘情况来自于显示器的固定宽度以及范围结束于的事实`N - 1`。 例如，使用输入`1`，唯一显示的值为`0000000000`。 答案是`60`，因为一秒钟亮起十个零。 从时间戳开始计数的解决方案`1`会错误地返回成本`0000000001`。 

另一个常见的错误是忘记上限是排他的。 用于输入`10`，时钟显示`0000000000`通过`0000000009`，不通过`0000000010`。 正确答案是`589`。 计算第十秒后状态的方法会添加额外的时间戳并得到错误的结果。 

第三个问题出现在最大值附近。 用于输入`9999999999`，最后显示的时间戳是`9999999998`。 价值`9999999999`不得包含在内。 计算所有十位数的值并忘记删除最后一个数字会高估答案`60`。 

## 方法

 一个简单的解决方案是模拟时钟。 对于每一秒，将时间戳转换为十位数字的字符串，添加每个数字的成本，一直持续到`N`几秒钟过去了。 这种方法很容易验证，因为它直接遵循语句。 然而，最坏的情况几乎需要处理`10^10`时间戳，即使是非常优化的实现也需要围绕`10^11`数字添加。 

显示的结构为我们提供了一种跳过这项工作的方法。 我们不必询问每个时间戳中出现了哪些数字，而是可以询问某个特定数字在所有时间戳中的特定位置中出现了多少次`0`到`N - 1`。 

例如，考虑最后一位数字。 它循环自`0`到`9`反复。 对于较高的位置，周期长度会变长，但仍保持相同的模式。 每个位置都可以通过计算完整周期和剩余部分周期来独立处理。 

对于具有位值的位置`p`，数字在大小块中重复`10 * p`。 在每个块内，每个数字都准确地保留在该位置`p`连续的数字。 完整块的数量给出了所有数字的简单贡献。 通过检查当前周期已覆盖了多少来处理这些块之后的剩余数字。 

在找到每个数字在每个位置出现的次数后，我们将这些计数乘以相应的能量成本并将所有内容相加。 十位数宽度仅意味着我们对以下位置的值重复此计算`1`通过`1,000,000,000`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(10N) | O(1) | O(1) | 太慢了|
 | 最佳| O(10 * 10) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 分别处理每个小数位，从个位开始，一直到十个显示位置中的最高位。 一个位置的贡献独立于所有其他位置，因此单独求和位置可以避免处理整个时间戳。 
2. 寻找有价值的职位`p`， 分裂`N`分成多个完整循环和余数。 一个完整的周期有长度`10 * p`，因为每个数字`0`到`9`出现为`p`连续的时间戳。 
3. 添加完整周期的贡献。 每个数字都准确显示`p`每个循环次数，循环次数为`N // (10 * p)`。 
4、处理不完整的循环。 完成循环后，当前位置从数字开始`0`。 第一个`min(remainder, p)`数值加数字`0`，下一个`p`数值加数字`1`，依此类推，直到剩余的用完。 
5. 将该位置的每个数字频率乘以该数字的能量成本，并将其添加到最终答案中。 

这样做的原因是每个小数位都遵循完美的重复模式。 个位位置每十个时间戳重复一次，十位位置每一百个时间戳重复一次，依此类推。 计算完整的重复和一次未完成的重复将每个时间戳精确地计算一次。 由于每个显示的时间戳只是其十个独立数字位置的总和，因此总能量也是这些独立位置贡献的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

cost = [6, 2, 5, 5, 4, 5, 6, 3, 7, 6]

def solve():
    n = int(input())

    ans = 0
    place = 1

    for _ in range(10):
        cycle = place * 10
        full = n // cycle
        rem = n % cycle

        for digit in range(10):
            cnt = full * place

            extra_start = digit * place
            extra_end = (digit + 1) * place

            if rem > extra_start:
                cnt += min(rem, extra_end) - extra_start

            ans += cnt * cost[digit]

        place *= 10

    print(ans)

if __name__ == "__main__":
    solve()
```数组`cost`存储显示每个数字一秒钟所需的能量。 十个位置上的循环与时钟的物理宽度匹配，因此不需要对前导零进行特殊处理。 

对于每个位置，`place`表示有多少个连续时间戳在该位置包含相同的数字。 例如，在十位上`place`是`10`，因为每个数字占据十个连续的数字。`full * place`计算完整的周期。 部分循环逻辑计算剩余时间戳和属于特定数字的间隔之间的重叠。 表达式使用`min`防止计数超出余数。 

变量`ans`可以变得大于 32 位整数范围。 Python 整数会自动增长，但具有固定大小整数的语言需要 64 位类型。 

对于显示屏的十位数字，循环恰好运行十次。 处理位置的顺序并不重要，因为每个数字位置的能量是独立的。

 ## 边缘情况

 对于`N = 1`，该算法有`full = 0`和`rem = 1`对于每个职位。 部分循环添加一次出现的数字`0`在每个位置，给出十个零，答案为`60`。 零后的时间戳不会意外包含在内。 

为了`N = 10`，单位位置有一个完整的周期，而每一个更高的位置只有一个周期的部分部分。 这将最后一位数字与前导零分开并产生`589`。 

为了`N = 9999999999`，该算法计算除`9999999999`本身，因为范围结束于`N - 1`。 如果不小心包含最后一个数字，结果会大`60`，这正是显示十个 9 一秒钟的成本。 周期计数避免了差一错误，因为所有计算都是在第一个周期上执行的`N`时间戳。
