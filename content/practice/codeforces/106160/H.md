 ## 解决方案
 ## 问题理解

 我们有两个长度相等的小写字符串，`S`和`T`。 

一个操作选择后缀`S`和一个值`k`1 到 25 之间。该后缀中的每个字符都向前移动`k`字母表中的位置，环绕自`z`回到`a`。 

任务是转型`S`进入`T`使用尽可能少的操作。 

思考这个问题的一个有用方法是忘记实际的字母，只跟踪每个位置必须移动多少。 对于每个索引`i`， 定义$$d_i = (T_i - S_i) \bmod 26$$这是该位置的总位移`i`必须收到。 

字符串长度可以大到`2 · 10^5`，因此任何考虑所有位置对或逐个字符模拟操作的算法都会太慢。 我们需要一些线性或接近线性的东西。 

棘手的部分是操作影响后缀，而不是单个位置。 先前应用的更改将继续影响所有后来的位置。 

考虑一个小例子：```
S = aaa
T = bbb
```每个岗位都需要轮换`1`， 所以```
d = [1, 1, 1]
```对整个字符串进行一次操作`k = 1`就足够了。 

粗心的方法可能会计算出三个非零位移的位置并给出答案`3`，这是不正确的。 

另一个有趣的案例是：```
S = aaa
T = aba
```然后```
d = [0, 1, 0]
```位置 2 必须获得一班，而位置 3 必须最终归零。 由于后缀运算向右传播，我们需要：```
+1 starting at position 2
+25 starting at position 3
```正确答案是`2`。 

这说明重要的不是价值观`d_i`本身，而是它们在相邻位置之间如何变化。 

## 方法

 暴力的观点是显式地构建操作。 

假设我们从左到右处理位置。 在每个索引处，我们将迄今为止累积的移位与该位置所需的移位进行比较，然后添加操作来修复差异。 这已经暗示了正确的结构，但如果通过实际更新后缀来实现，每个操作都可能会触及`O(n)`职位。 在最坏的情况下变成`O(n^2)`，这对于`n = 2 · 10^5`。 

关键的观察结果是后缀操作不会改变该后缀内两个位置之间的差异。 它仅更改后缀开始的点。 

让$$d_i = (T_i - S_i) \bmod 26$$并定义$$d_0 = 0.$$假设操作从位置开始`i`并转变为`k`。 然后每增加一次`d_j`为了`j ≥ i`经过`k`，这意味着“离散导数”唯一变化的地方是位置之间`i-1`和`i`。 

定义$$\Delta_i = (d_i - d_{i-1}) \bmod 26.$$的转变`k`从位置开始`i`准确贡献`k`到`Δ_i`没有其他地方。 

这意味着差异数组中的每个位置都是完全独立的。 

如果`Δ_i = 0`，那里不需要任何操作。 

如果`Δ_i ≠ 0`，从位置开始的单个操作`i`和`k = Δ_i`准确地创建所需的更改。 

由于一次操作可以实现 1 到 25 之间的任何值，因此每个非零`Δ_i`仅花费一次操作。 

答案很简单，就是索引的数量$$(d_i - d_{i-1}) \bmod 26 \ne 0.$$| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解后缀模拟| O(n²) | O(n) | 太慢了 |
 | 差值阵列观察| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`,`S`， 和`T`。 
2. 对于每个位置`i`, 计算$$d_i = (T_i - S_i) \bmod 26.$$这是该位置所需的总班次。 
3.让`prev = 0`，这代表`d_0`。 
4. 从左到右遍历位置。 
5. 计算$$\Delta = (d_i - prev) \bmod 26.$$这是必须从该位置开始的新移位量。 
6. 如果`Δ ≠ 0`，将答案加一。 

带移位的单个后缀操作`Δ`可以创造这种改变。 
7. 设置`prev = d_i`并继续。 
8. 输出最终计数。 

### 为什么它有效

 每个后缀操作都会影响从其起点开始的所有位置。 在所需班次的数组中`d`，这样的操作只改变一个边界：位置之间的转换`i-1`和`i`。 

数量$$\Delta_i = (d_i - d_{i-1}) \bmod 26$$准确记录必须从该位置开始多少移位`i`。 

非零`Δ_i`不能通过从其他地方开始的操作来产生，因此至少需要一项操作。 相反，一个带有shift的操作`Δ_i`正是产生了这个要求。 

因此每个非零`Δ_i`只贡献一次操作，并且每个零`Δ_i`没有贡献。 计算非零差异可以给出尽可能少的操作数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
s = input().strip()
t = input().strip()

ans = 0
prev = 0

for i in range(n):
    cur = (ord(t[i]) - ord(s[i])) % 26
    delta = (cur - prev) % 26
    if delta != 0:
        ans += 1
    prev = cur

print(ans)
```变量`cur`存储当前位置所需的总班次。 

变量`prev`存储前一个位置所需的移位。 计算```
(cur - prev) % 26
```给出差值数组值`Δ`。 

每当该值非零时，我们就需要从当前位置开始执行一个操作。 

模运算是必不可少的。 例如，从所需的班次调动`1`到所需班次`0`对应于```
0 - 1 = -1
```这应该被解释为`25`以模 26 算术。 忘记模数会错误地将这种转变视为负数。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    s = input().strip()
    t = input().strip()

    ans = 0
    prev = 0

    for i in range(n):
        cur = (ord(t[i]) - ord(s[i])) % 26
        delta = (cur - prev) % 26
        if delta != 0:
            ans += 1
        prev = cur

    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out

    solve()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.getvalue()

# provided samples

assert run("9\naaaaaaaaa\naaabbbaaa\n") == "2\n"

assert run("3\naaa\naba\n") == "2\n"

 ## 边缘情况

 考虑：```
3
aaa
aba
```所需轮班是：```
[0, 1, 0]
```该算法计算：```
Δ = [0, 1, 25]
```两个非零条目都被计数，给出答案`2`。 

一个操作启动一个`+1`在位置 2 处移位。另一个操作启动`+25`在位置 3 处移位，取消字符串其余部分的效果。 

现在考虑：```
3
aaa
bbb
```所需轮班：```
[1, 1, 1]
```差异：```
Δ = [1, 0, 0]
```只存在一个非零条目，所以答案是`1`。 这正确地捕获了整个字符串上的单个后缀操作同时影响所有三个位置。 

最后，考虑一个环绕过渡：```
2
ba
ab
```所需轮班：```
[25, 1]
```差异：```
Δ1 = 25
Δ2 = (1 - 25) mod 26 = 2
```两者都不为零，所以答案是`2`。 模算术正确地处理跨越字母表边界的转换。
