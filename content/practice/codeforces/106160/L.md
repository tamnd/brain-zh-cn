 ## 解决方案
 ## 问题理解

 我们有一个恰好有三行的网格`W`列。 三个细胞很特别。 

第一个玩家开始于`A = (1, a)`，第二个玩家开始于`B = (3, b)`，并且两者都想达到`X = (2, 1)`。 

在游戏开始之前，我们可以在任何单元格上放置障碍物，除了`A`,`B`， 和`X`。 放置障碍物后，从起始单元格到`X`是通过非阻塞单元的最短有效路径的长度。 

任务不是计算距离。 相反，我们必须构造一个迷宫，其最短路径距离满足`dist(A, X) = dist(B, X) < ∞`。 

如果不存在这样的迷宫，我们打印`Impossible`。 

宽度最多为100，因此在复杂性方面不存在算法挑战。 真正的困难是理解哪些配置是可能的并找到一个简单的构造模式。 

当一个起始位置已经在第一列中时，就会出现一种微妙的情况。 

例如：```
W = 3
a = 3
b = 1
```细胞`B`直接毗邻`X`。 由于障碍物会移除细胞，但无法移除两个幸存的相邻细胞之间的边缘，因此`B`到`X`是永久的`1`。 其他玩家不能也有距离`1`，所以答案是不可能的。 

另一种容易被忽视的情况是奇偶校验。 

考虑：```
W = 4
a = 3
b = 2
```该声明的样本表明这是不可能的。 

任意路径从`(1,a)`到`(2,1)`与曼哈顿距离具有相同的奇偶性。 每次绕行都会在网格中添加偶数个步骤。 所以每一条可能的路径`A`到`X`有奇偶性`a`，以及每条可能的路径`B`到`X`有奇偶性`b`。 

如果`a`和`b`具有不同的奇偶性，相等的距离是不可能的。 

最后，当两个起点已经相邻时`X`:```
W = 1
a = 1
b = 1
```两个距离都已经`1`，所以空迷宫有效。 

## 方法

 暴力思维会尝试搜索所有障碍物位置并使用 BFS 检查最短路径。 一个`3 × W`棋盘包含多达 300 个单元，因此障碍物配置的数量大致为`2^300`，这是完全不可行的。 

关键的观察结果是，问题几乎完全由几何决定。 

第一个有用的事实是奇偶校验。 任意路径从`(1,a)`到`(2,1)`奇偶校验等于`a`，因为曼哈顿距离是`a`每一次绕行都会使长度发生均匀的变化。 同样，每条路径从`(3,b)`到`(2,1)`奇偶校验等于`b`。 

相等的距离需要相等的奇偶性，所以`a`和`b`必须具有相同的奇偶性。 

第二个有用的事实涉及第 1 列。如果`a = 1`， 然后`A`永久毗邻于`X`， 所以`dist(A,X) = 1`无论我们设置什么障碍。 对于`b = 1`。 

这意味着：

 如果恰好是其中之一`a`和`b`等于`1`，答案是不可能。 

删除那些不可能的情况后，假设两个位置都严格位于第 1 列的右侧，并且具有相同的奇偶校验。 

让```
t = (a + b) / 2
```由于奇偶校验匹配，`t`是一个整数。 

我们建造了一个树形的走廊。 

从列的第 1 行打开水平线段`a`到专栏`t`。 

在第 3 行的列中打开一个水平线段`b`到专栏`t`。 

从列打开第 2 行`1`直通柱`t`。 

阻止其他一切。 

现在从起点到终点的每条路径`X`必须首先到达列`t`，然后沿着第 2 行移动到第 1 列。 

距离`A`变成```
|a - t| + 1 + (t - 1)
```和距离`B`变成```
|b - t| + 1 + (t - 1)
```因为`t`正好是中点，两个绝对值相等，所以距离也相等。 

生成的图是一棵树，因此没有其他捷径。

 ## 算法演练

 1.如果`a = 1`和`b = 1`，输出仅标记三个特殊单元格的空网格。 
2. 如果恰好是其中之一`a`和`b`等于`1`， 输出`Impossible`。 

从第 1 列开始的玩家永久处于远处`1`从`X`，而另一个玩家则不是。 
3.如果`a`和`b`有不同的奇偶校验，输出`Impossible`。 

每条路径从`A`到`X`有奇偶性`a`，以及每条路径`B`到`X`有奇偶性`b`。 相同的长度必须具有相同的奇偶性。 
4. 计算```
t = (a + b) / 2
```由于奇偶校验匹配，因此这是一个整数。 
5. 从充满障碍物的网格开始。 
6. 打开第 2 列第 2 行的每个单元格`1`直通柱`t`。 

这成为通往`X`。 
7. 打开第 1 行各列之间的单元格`a`和`t`，包含在内。 

这将创建包含以下内容的分支`A`。 
8. 打开第 3 行列之间的单元格`b`和`t`，包含在内。 

这将创建包含以下内容的分支`B`。 
9.放置角色`A`,`B`， 和`X`在所需的单元格中并打印网格。 

### 为什么它有效

 该建筑创造了一棵树。 从任意一个出发点到任意一个出发点的任意路线`X`必须通过列处的唯一交汇处`t`。 

路径长度从`A`等于```
|a - t| + 1 + (t - 1).
```路径长度从`B`等于```
|b - t| + 1 + (t - 1).
```自从`t`是的中点`a`和`b`，我们有```
|a - t| = |b - t|.
```因此这两个距离是相同的。 

不可能性条件也是必要的。 不同的奇偶性会导致长度相等，并且如果恰好有一个起点位于第 1 列，则一名球员将永久处于距离 1，而另一名球员则不然。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

W, a, b = map(int, input().split())

if a == 1 and b == 1:
    print("Possible")
    print("A")
    print("X")
    print("B")
    sys.exit()

if (a == 1) ^ (b == 1):
    print("Impossible")
    sys.exit()

if (a - b) & 1:
    print("Impossible")
    sys.exit()

t = (a + b) // 2

g = [['*' for _ in range(W)] for _ in range(3)]

for c in range(1, t + 1):
    g[1][c - 1] = '.'

for c in range(min(a, t), max(a, t) + 1):
    g[0][c - 1] = '.'

for c in range(min(b, t), max(b, t) + 1):
    g[2][c - 1] = '.'

g[0][a - 1] = 'A'
g[1][0] = 'X'
g[2][b - 1] = 'B'

print("Possible")
for row in g:
    print(''.join(row))
```第一个块处理奇偶校验或固定距离 1 邻接不可能实现的特殊情况`X`。 

中点`t`是建设的核心。 第二排成为公共走廊。 第一行和第三行各贡献一个分支，以列结束`t`。 

该实现首先在棋盘上填充障碍物，并且仅打开属于所需树的单元格。 这可以避免在其他地方意外留下快捷方式。 

间隔循环使用`min`和`max`，所以它们是否工作`a < t`,`a > t`， 或者`a = t`。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    data = io.StringIO(inp)
    out = io.StringIO()

    W, a, b = map(int, data.readline().split())

    if a == 1 and b == 1:
        return "Possible\nA\nX\nB\n"

    if (a == 1) ^ (b == 1):
        return "Impossible\n"

    if (a - b) & 1:
        return "Impossible\n"

    t = (a + b) // 2

    g = [['*' for _ in range(W)] for _ in range(3)]

    for c in range(1, t + 1):
        g[1][c - 1] = '.'

    for c in range(min(a, t), max(a, t) + 1):
        g[0][c - 1] = '.'

    for c in range(min(b, t), max(b, t) + 1):
        g[2][c - 1] = '.'

    g[0][a - 1] = 'A'
    g[1][0] = 'X'
    g[2][b - 1] = 'B'

    out.write("Possible\n")
    for row in g:
        out.write("".join(row) + "\n")

    return out.getvalue()

# sample-style checks
assert run("1 1 1\n") == "Possible\nA\nX\nB\n"

assert run("4 3 2\n") == "Impossible\n"

assert run("3 3 1\n") == "Impossible\n"

# custom cases
assert run("5 2 4\n").startswith("Possible")
assert run("10 5 5\n").startswith("Possible")
assert run("7 1 5\n") == "Impossible\n"
assert run("100 99 99\n").startswith("Possible")
```| 测试输入| 预期产出 | 它验证了什么 |

 |`3 3 1`| 不可能| 一开始固定在距离 1 |
 |`5 2 4`| 可能 | 典型的中点结构|
 |`10 5 5`| 可能 | 中点等于两个起点 |

 ## 边缘情况

 考虑：```
3 3 1
```玩家`B`开始于`(3,1)`，直接在下面`X`。 

之间的边缘`(3,1)`和`(2,1)`始终存在，因为两个端点都不会被阻止。 

所以：```
dist(B, X) = 1
```永远。 

玩家`A`从第 3 列开始，并且不能同时达到距离 1。该算法检测到正好有一个起点位于第 1 列并打印`Impossible`。 

现在考虑：```
4 3 2
```一切可能的平等`A → X`路径是奇数，而每个可能的奇偶性`B → X`路径是均匀的。 

相等的整数不能同时为奇数和偶数。 该算法首先检查奇偶校验并立即报告`Impossible`。 

最后，考虑：```
5 3 3
```然后：```
t = 3
```两个分支直接连接到同一连接柱中。 从开始到结束的独特路径`X`长度为 3，并且结构在没有任何特殊处理的情况下仍然有效。
