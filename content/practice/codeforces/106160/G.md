 ## 解决方案
 ## 问题理解

 迷宫是一个细胞网格，每个细胞都包含一个描述其放射性水平的数字。 旅行者从左上角的单元格开始，希望到达底部的单元格，同时仅在侧面相邻的单元格之间移动。 所选路线的危险程度取决于该路线上访问的放射性最强的小区。 任务是找到所有路径中可能的最小危险值，这意味着我们希望最高单元格值尽可能低的路径。 

网格尺寸均小于 100，因此最多有 10,000 个单元格左右。 这排除了枚举路径的算法，因为随着迷宫变大，可能行走的数量呈指数增长。 围绕 O(nm) 或 O(nm log V) 的解决方案（其中 V 是可能的放射性值的范围）很容易足够快。 

问题的微妙部分是我们并没有试图最小化路径上的值的总和。 如果该中等值是访问过的最大单元格，那么包含许多小值的路径仍然可能比包含一个中等值的路径更糟糕。 这意味着使用加法的普通最短路径算法不能直接应用。 

另一个边缘情况是答案是起始单元格本身。 例如：```
1 1
7
```正确的输出是：```
7
```仅在移动后检查单元格的粗心实现会错误地返回较小的值或因没有移动而失败。 

另一个边缘情况是只能通过高价值单元格到达目的地。 例如：```
3 3
111
999
111
```正确的输出是：```
1
```因为顶行连接在高单元周围。 贪婪地选择最小相邻单元的方法可能会陷入中间附近并错误地认为答案是 9。 

最后一个常见的错误是忽略了允许重新访问单元格的规定。 最佳路由是关于在限制下的可达性，而不是构建一条特定的简单路径。 

## 方法

 直接暴力的想法是生成从左上角到目的地的每条可能的路线，计算每条路线上的最大值，并保留最小的最大值。 这是正确的，因为考虑了所有可能的路线。 问题是路线的数量。 即使在一个小的开放网格中，每个位置都可以分支为多个选择，从而创建指数数量的可能游走。 在达到允许的最大网格大小之前很久，完整的搜索就变得不可能了。 

关键的观察是答案是一个阈值。 假设我们猜测允许的最大放射性为X。那么每个值最多为X的单元格都是可用的，而每个较大的单元格都被阻止。 原来的问题变得更加简单：我们可以仅使用可用的细胞到达目的地吗？ 

这将问题转化为可达性检查。 如果阈值 X 起作用，则每个更大的阈值也起作用，因为它只会添加更多单元格。 如果 X 不起作用，则每个较小的阈值都会失败。 这种单调属性允许对答案进行二分搜索。 

对于每个候选阈值，我们在网格上运行图形遍历。 BFS 或 DFS 标记所有可通过值不超过阈值的单元格到达的单元格。 因为只有九个可能的单元格值，所以我们也可以尝试所有阈值，但二分搜索是一种更通用的模式，适用于任何值范围。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| O(纳米) | 太慢了 |
 | 最佳 | O(nm log C) | O(纳米) | 已接受 |

 这里，C 是最大可能的单元值范围。 对于此问题，C 非常小，因为单元格包含数字，但如果值大得多，则相同的方法也适用。 

## 算法演练

 1. 找到网格中存在的最小值和最大值。 答案必须位于此区间内的某个位置，因为有效路径的最大值不能小于其访问的每个单元格，并且使用最大网格值始终允许使用每个单元格。 
2.二分查找候选阈值X。对于该值，将每个值大于X的单元格视为阻塞。 
3. 从起始单元运行 BFS。 仅当相邻单元位于网格内部、未被访问过且其值最多为 X 时才添加相邻单元。遍历回答当前限制下是否存在路径。 
4. 如果 BFS 到达目的地，则存储 X 作为可能的答案并搜索更小的阈值。 成功的阈值意味着真实答案可能会更低。 
5. 如果 BFS 无法到达目的地，则搜索更大的阈值，因为必须有更多的小区可用。 

为什么它有效：重要的不变量是 BFS 结果相对于阈值是单调的。 一旦阈值允许一条路由，每个更大的阈值也允许该路由。 一旦阈值阻止所有路由，每个较小的阈值也会阻止它们。 二分查找找到可达性从 false 变为 true 时的最小阈值，这正是路径上可能的最小最大值。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [list(map(int, input().strip())) for _ in range(n)]

    low = min(min(row) for row in grid)
    high = max(max(row) for row in grid)

    def can_reach(limit):
        if grid[0][0] > limit:
            return False

        visited = [[False] * m for _ in range(n)]
        q = deque([(0, 0)])
        visited[0][0] = True

        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        while q:
            r, c = q.popleft()

            if r == n - 1 and c == m - 1:
                return True

            for dr, dc in directions:
                nr, nc = r + dr, c + dc

                if 0 <= nr < n and 0 <= nc < m:
                    if not visited[nr][nc] and grid[nr][nc] <= limit:
                        visited[nr][nc] = True
                        q.append((nr, nc))

        return False

    answer = high
    while low <= high:
        mid = (low + high) // 2

        if can_reach(mid):
            answer = mid
            high = mid - 1
        else:
            low = mid + 1

    print(answer)

if __name__ == "__main__":
    solve()
```网格存储为整数，因此 BFS 期间的比较是直接的。 二分搜索边界是根据实际网格值初始化的，这避免了对不可能阈值的不必要检查。 

这`can_reach`函数表示算法演练中的图遍历。 为每个 BFS 重新创建访问矩阵，因为每个阈值都会创建不同的可用单元图。 

在 BFS 开始之前检查起始单元。 这可以处理单单元格的情况，并且还可以防止小于起始值的阈值被视为有效。 

二分查找使用标准下界模式。 当阈值成功时，它会被保存，并向左搜索以找到更小的有效值。 当失败时，搜索将向右移动，因为限制必须增加。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(nm log C) | 二分查找执行 O(log C) BFS 运行，每个 BFS 最多访问每个单元一次 |
 | 空间| O(纳米) | 网格和访问矩阵都使用与单元格数量成比例的空间 |

 网格的单元格少于 10,000 个，因此即使重复完全遍历也很容易在限制范围内。 如果值范围变大，该方法也可以很好地扩展。

 ## 边缘情况

 对于单细胞网格：```
1 1
7
```二分搜索最终测试阈值 7。BFS 从唯一的单元格开始，并立即发现它是目的地，因此答案是 7。该算法从不假设至少存在一个移动。 

对于网格：```
3 3
111
999
111
```阈值 1 将所有 9 值单元格标记为已阻止。 BFS 穿过顶行，然后沿着右侧向下移动，无需进入阻塞单元格即可到达目的地。 该算法返回 1，而不是沿着局部有吸引力但不正确的路线前往中心。 

对于完全均匀的网格：```
2 2
99
99
```每个低于 9 的阈值都会失败，因为起始单元本身不可用。 在阈值 9 处，BFS 通过开放网格立即到达目的地，因此正确找到的最小有效答案为 9。
