 ## 解决方案
 ## 问题理解

 我们被要求操作从 1 到 n 的整数排列。 每个排列都有一个“指纹”，它是每对连续元素的总和的排序列表。 任务是采用给定的排列并产生具有相同指纹的另一个不同的排列。 排列必须保持有效，这意味着从 1 到 n 的所有整数只出现一次。 

输入由多个测试用例组成。 每个测试用例提供排列的长度和排列本身。 输出是每个测试用例的排列，与输入不同但具有相同的指纹。 约束是适度的：n 最多为 100，测试用例的数量最多为 668。这些限制表明，每个测试用例的复杂度为二次甚至稍差的算法将有效运行，因为 100² 仅为每个用例 10,000 次操作，而 668×10,000 总体远低于 1000 万次操作。 

非常小的排列会出现一个微妙的点。 对于 n = 2，唯一与 [1, 2] 不同的排列是 [2, 1]，但这仍然有效，因为它为其唯一的对生成相同的和。 对于 n > 2，输入排列可以是排序的、反转的或随机的，但我们需要一种有保证的系统方法来生成不同的排列而不违反指纹属性。 

## 方法

 暴力方法会尝试所有n！ 长度为 n 的排列并计算每个排列的指纹，检查它是否与原始排列相匹配。 这在原则上是正确的，但完全不切实际。 对于 n = 10，有 3,628,800 种可能性； 对于 n = 100，n！ 是一个天文数字。 即使 n = 8，检查数量也会太多，无法有效运行多个测试用例。 

关键的见解是指纹仅取决于相邻元素的总和。 反转排列会保留每个相邻的和，只是顺序不同。 例如，[a, b, c, d] 的和为 [a+b, b+c, c+d]，而 [d, c, b, a] 的和为 [d+c, c+b, b+a]，其中包含完全相同的数字，但顺序可能不同。 由于指纹是排序的，因此顺序并不重要。 反转长度至少为 2 的任何排列可以保证具有相同指纹的不同排列。 

这一观察结果将问题从阶乘复杂性降低到线性时间。 我们只需读取排列，反转它，然后输出它。 这可以处理所有 n ≥ 2 的大小，尊重约束，并且实现起来很简单。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 逆排列| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取测试用例数t。 这定义了我们需要处理多少个排列。 
2. 对于每个测试用例，读取整数 n 和长度为 n 的排列 p。 
3. 反转数组 p 以产生新的排列 p'。 这是可行的，因为反转会按某种顺序保留所有相邻的和，这对于排序的指纹来说已经足够了。 
4. 输出逆排列。 不需要额外的检查，因为 n ≥ 2 保证反转的排列与原始排列不同。 

为什么有效：反转保留了排列中相邻元素的每个和。 指纹中的排序步骤消除了顺序敏感性，因此反转数组的指纹与原始指纹相匹配。 对于 n ≥ 2，反转总是与原始排列不同，满足独特性条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    p.reverse()
    print(" ".join(map(str, p)))
```该解决方案使用有效地读取输入`sys.stdin.readline`并处理多个测试用例。 使用以下方法就地反转排列`list.reverse()`，这避免了额外的内存分配。 最后，以空格分隔打印反转列表。 避免了相差一的错误，因为`reverse()`处理完整数组并且连接操作正确地将整数转换为字符串。 

## 工作示例

 对于第一个示例输入：

 | 步骤| p| 行动| 输出|
 | ---| ---| ---| ---|
 | 1 | [1, 2] | 反向| [2, 1] |
 | 2 | 隐式计算 F(p') | [2+1] = [3] | 匹配原创|

 该算法成功生成与输入不同的 [2, 1]、指纹 [3]。 

对于第二个示例输入：

 | 步骤| p| 行动| 输出|
 | ---| ---| ---| ---|
 | 1 | [2, 1, 6, 5, 4, 3] | 反向| [3, 4, 5, 6, 1, 2] |
 | 2 | 隐式计算 F(p') | [3+4,4+5,5+6,6+1,1+2] = [7,9,11,7,3] | 排序：[3,7,7,9,11] |

 指纹与原件相符。 逆转保证了独特性。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(t * n) | 每个测试用例的每次反转和输出都需要线性时间。 |

 ## 边缘情况

 对于 n = 2，输入 [1,2] 反转为 [2,1]。 指纹[3]相同，排列不同，满足问题要求。 对于像 [1,2,3,4,5] 这样的更大的排序排列，反转 [5,4,3,2,1] 会产生相同的排序指纹 [3,5,7,9] 并且与原始不同。 在所有情况下，反转足以满足指纹和独特性约束。
