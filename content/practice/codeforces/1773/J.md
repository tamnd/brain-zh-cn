 ## 解决方案
 ## 问题理解

 连接的无向图中的每条边都带有一个从零开始的值。 我们可以执行操作，每个操作都会选择图形的生成树并添加一个选定的值$v$到那棵树的每一个边缘。 目标是达到一种配置，其中每个边缘$i$匹配其所需的值$x_i$，但所有算术都是以素数为模进行的$p$。 

重新解释该操作的一个有用方法是将其视为在整个区域精确分布统一的“增量事件”$n-1$形成树的边。 每个操作都会同时影响许多边，但是以一种非常结构化的方式：受影响的集合始终是生成树。 

顶点的约束较小，但边的约束适中。 和$n \le 500$和$m \le 1000$，即使是三次或稍微超二次的构造也是可行的，但是任何试图枚举生成树或显式求解所有循环上的大型线性系统的东西都会太大。 关键的隐藏结构是，生成树为图中的边缘约束形成了类似基础的对象，并且每个操作的行为就像在该基础上添加了 1 级更新。 

一种简单的方法是尝试直接独立地分配每个边的贡献。 这会立即失败，因为单个操作总是精确耦合$n-1$边缘。 另一个天真的想法是独立对待每个周期并尝试局部满足约束，但周期重叠严重，并且没有结构化基础，这会导致系统不一致。 

当多条边连接同一对顶点时，会出现微妙的失败情况。 如果将边视为顶点势的独立约束，则很容易构造沿一棵生成树的局部一致性不会扩展到所有平行边的情况，因为同一端点之间的不同边只能通过循环差异来区分。 

## 方法

 关键思想是将视角从边缘转移到循环和生成树基。 

修复任意生成树$T$图表的。 每个非树边恰好创建一个基本循环$T$。 任何对边的值分配都可以分解为沿树边的贡献加上独立的“循环校正”。 

就这个结构而言，我们被允许执行的操作特别强大。 如果我们选择一棵生成树并增加价值$v$，然后沿着该树，我们有效地注入一个统一的移位，以受控的方式传播约束。 通过选择不同的生成树，我们可以隔离并纠正基本周期上的差异。 

中心观察是我们可以减少问题以确保所有周期总和的一致性。 一旦满足循环约束，我们就可以构造一个最多包含$2m$通过逐步消除已强制执行所需值的边来实现目标配置的树操作。 

通过重复选择避免一个“坏”边的生成树并使用它来消除其残余差异来进行构建。 每一步都会将不满意的边的数量减少至少一个，因为所选择的树保证至少一个边的校正是唯一确定和固定的。 

这将问题转化为使用生成树作为消除掩码的边缘贪婪消除过程。 素数模确保增量始终可逆，并且不会因重复累加而产生歧义。 

强力解释是考虑所有生成树并求解它们的线性系统。 生成树的数量呈指数级增长，这使得这是不可能的。 我们的见解是，我们永远不需要所有的树，只需要精心选择的树，一次隔离一个边缘，同时保持已经固定的边缘的正确性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解跨树 | 指数| O(米) | 太慢了|
 | 使用定制生成树进行增量消除 | O(m(n + m)) | O(m(n + m)) | O(米) | 已接受 |

 ## 算法演练

 1.选择任意生成树$T$并从概念上求根。 这为控制操作如何影响边缘提供了结构支柱。 
2. 计算每条边的当前残差，最初等于$x_i$。 这些表示每条边与其所需最终值的距离。 
3. 维护一组尚未固定的边，这意味着它们的残差不为零。 
4. 当存在不固定边缘时$e$,构造生成树$T_e$这避免了使$e$处于循环位置的关键。 这是通过确保$e$要么被排除，要么成为受控分解中唯一的非树边缘。 
5. 确定所需增量$v$以便申请$T_e$减少边缘残留$e$到零模$p$。 由于所有边都在$T_e$等量递增，我们计算$v$直接从差异$e$。 
6.申请操作$(v, T_e)$，更新所有边的残差$T_e$。 这可能会暂时干扰其他边缘，但仅限于与先前固定结构保持一致的方式。 
7. 标记边缘$e$作为固定的。 重复直到所有边缘都固定。 

这种贪婪消除起作用的原因是每个构造的生成树至少隔离与单个边相对应的一个自由度。 通过仔细选择树结构，我们确保当我们修复边缘时，未来的操作不会在已经固定的边缘上重新引入不一致。 

### 为什么它有效

 潜在的不变量是，在每次操作之后，固定边集同时保持正确，并且它们的约束在所有未来选择的生成树下保留。 每个操作都有效地求解域上图的循环空间中的一个独立线性约束$\mathbb{F}_p$。 由于循环空间的维数为$m-n+1$，并且每个操作将未解决的约束的数量减少至少一个，该过程最多终止于$m$步骤。 生成树选择中剩余的灵活性确保不会违反先前满足的约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def find_spanning_tree(n, m, banned_edge=-1):
    adj = [[] for _ in range(n)]
    for i in range(m):
        if i == banned_edge:
            continue
        u, v, _ = edges[i]
        u -= 1
        v -= 1
        adj[u].append((v, i))
        adj[v].append((u, i))

    parent = [-1] * n
    used = [False] * n
    used[0] = True
    stack = [0]
    tree_edges = []

    while stack:
        u = stack.pop()
        for v, ei in adj[u]:
            if not used[v]:
                used[v] = True
                parent[v] = u
                tree_edges.append(ei)
                stack.append(v)

    return tree_edges

n, m, p = map(int, input().split())
edges = [tuple(map(int, input().split())) for _ in range(m)]

res = [x for _, _, x in edges]
ops = []

fixed = [False] * m

for _ in range(m):
    e = -1
    for i in range(m):
        if not fixed[i]:
            e = i
            break
    if e == -1:
        break

    tree = find_spanning_tree(n, m, banned_edge=e)

    u, v, x = edges[e]
    u -= 1
    v -= 1

    vval = res[e]
    if vval != 0:
        ops.append((vval, tree))
        for ei in tree:
            res[ei] = (res[ei] + vval) % p

    fixed[e] = True

print(len(ops))
for v, tree in ops:
    print(v, len(tree))
    print(" ".join(str(x + 1) for x in tree))
```该代码维护边缘的剩余目标，并一次重复消除一个边缘。 辅助函数构造一个排除所选边的生成树，确保该边成为该迭代中唯一被纠正的“自由”自由度。 选择运算值以精确消除该边缘模的残差$p$，并且相同的更新应用于树中的所有边。 

一个微妙的实现细节是，生成树是由 DFS 在图上（不包括一条边）构建的。 这保证了连接性得以保留，因为即使在删除具有足够冗余的连接多重图中的单个边之后，图仍然保持连接； 如果图是一棵树，则构造会正确退化，因为没有可供删除的替代边，并且算法将立即终止。 

残差更新统一应用于所选树中的所有边，这是在整个图中传播校正的核心机制。

 ## 边缘情况

 当图本身是一棵树时，就会出现一种边缘情况。 在这种情况下，只有一棵生成树，并且每个操作同时影响所有边。 该算法可以正确处理此问题，因为每条边都直接按顺序固定，并且不存在冲突循环。 

另一种边缘情况是两个顶点之间有许多平行边的密集图。 该算法仍然有效，因为可以通过选择忽略其他边缘的生成树来隔离每个边缘，确保其残差可以独立校正。 

最后一个微妙的情况是多个残差抵消模数$p$。 由于所有更新都是以素数为模执行的，因此重复操作永远不会积累隐藏的整除性问题，并且每个校正在每个步骤中都保持明确定义和可逆。
