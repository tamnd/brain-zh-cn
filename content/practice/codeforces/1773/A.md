 ## 解决方案
 ## 问题理解

 我们给出了一个排列$a$尺寸的$n$，意味着每个数字$1$到$n$恰好出现一次。 我们可以应用两种排列$q$首先然后$p$，这样最终的位置$i$接收原来位置的值$p[q[i]]$。 换句话说，数组通过位置重新映射被排列两次。 

目标是选择$p$和$q$这样，在两次排列之后，结果数组就成为恒等排列，即位置$i$包含价值$i$。 两个都$p$和$q$一定是混乱，所以都不允许固定任何位置。 

该变换可以解释为选择一个排列$r = p \circ q$，并将其应用到职位上。 约束条件是$r$必须可分解为两个混乱，这是隐藏在语句中的真正结构限制。 

这些约束迫使$O(n)$或者$O(n \log n)$每次测试的解决方案。 自总计$n$所有测试用例的总和是$10^5$，每个测试用例的任何二次构造或图形搜索都将失败。 

当出现一个微妙的问题时$n = 1$。 只有一种排列，这基本上是一个不动点，所以任何混乱都是不可能的。 为了$n = 2$，两种排列都必须交换两个元素，因此结构受到极大限制。 另一种脆弱的情况是当排列已经具有许多不动点或单个循环时，因为构造完全取决于循环结构。 

一个天真的想法是尝试构建$p$和$q$贪婪地逐个位置定位，确保最终映射的正确性，同时避免固定点。 这失败了，因为决策是全局性的：选择$p_i$本地可以将未来的位置强制为固定点$p$或者$q$，即使存在有效的全局分配。 

## 方法

 直接的暴力方法会尝试所有的混乱对$p$和$q$，并检查是否$p(q(i)) = a^{-1}(i)$（或者同等地，该组合物是否产生同一性）。 混乱的数量大约是$n! / e$，所以对的顺序是$(n!/e)^2$，即使对于$n = 8$。 即使检查单对成本$O(n)$，使得这完全不可行。 

关键的见解是，我们应该停止从两个任意排列的角度思考，而是将问题解释为循环的分解约束。 

让$b = a^{-1}$。 我们想要：$$p(q(i)) = b(i)$$定义$r = p \circ q$。 然后$r = b$，所以我们需要表达一个固定的排列$b$作为两种混乱的组合。 

一个关键的结构事实是，任何排列都可以分解为两个排列，当且仅当它没有长度循环$1$。 这是因为有一个固定点$b$会迫使$p(q(i)) = i$，这不可能发生，因为两者$p$和$q$禁止不动点，并且它们的组合无法“修复”单元素循环而不在内部某处引入不动点。 

自从$b$只是一个排列$a$，条件等同于检查是否$a$包含恒等映射上下文中的任何固定点都是无关的； 相反，真正的条件简化为处理小循环和配对结构。 

构建过程通过对元素进行分组并以受控方式在循环内旋转来进行，确保两个中间排列在它们的组成匹配时避免固定点$b$。 标准方法是处理循环$b$并将每个循环分成两个移位层，这自然会产生两种混乱。 

一旦处理完周期，我们就分配$q$作为每个周期内的旋转并且$p$作为互补旋转。 因为这两种旋转都会移动每个元素，所以都没有固定点。

 | ---| ---| ---| ---|
 | 蛮力 |$O(n!^2 \cdot n)$|$O(n)$| 太慢了|

 ## 算法演练

 我们使用排列$b = a^{-1}$，因为我们想要将每个值映射回其正确的位置。 

1. 计算逆排列$b$， 在哪里$b[a[i]] = i$。 这将最终要求转换为索引上的直接映射。 
2. 分解$b$进入不相交的循环。 每个元素恰好属于一个循环，并且以下$b$反复停留在该循环内。 这是我们必须尊重的自然结构，因为两者$p$和$q$必须保持全局一致性。 
3.如果任何循环都有长度$1$，立即输出不可能。 长度为 1 的循环意味着某些元素在以下情况下映射到自身$b$，并且如果不在至少一个排列中创建不动点，则无法通过两个排列的组合来实现这一点。 
4.对于每个周期长度$k \ge 2$，按顺序标记其元素$c_0, c_1, \dots, c_{k-1}$。 
5. 定义$q$在每个循环内作为正向旋转：$$q(c_i) = c_{(i+1) \bmod k}$$这确保了$q$没有固定点，因为每个元素都会移动。 
6. 定义$p$作为向后旋转：$$p(c_i) = c_{(i-1) \bmod k}$$这也保证了没有不动点。 
7. 检查成分是否匹配$b$：$$p(q(c_i)) = p(c_{i+1}) = c_i$$所以这个构造是有效的。 

### 为什么它有效

 不变量是在每个周期内$b$， 两个都$p$和$q$充当相同顺序的循环移位。 这确保它们永远不会将元素映射到自身，因为每个索引都会被替换。 同时，它们的组合精确地取消了移位，从而在每个周期上产生同一性$b$，它对应于所需的映射。 

周期之间不会发生交互，因此每个周期的正确性都是独立的，因此在全局范围内也是如此。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    # inverse permutation b
    b = [0] * (n + 1)
    for i, x in enumerate(a, start=1):
        b[x] = i

    vis = [False] * (n + 1)
    p = [0] * (n + 1)
    q = [0] * (n + 1)

    for i in range(1, n + 1):
        if not vis[i]:
            cycle = []
            cur = i
            while not vis[cur]:
                vis[cur] = True
                cycle.append(cur)
                cur = b[cur]

            if len(cycle) == 1:
                print("Impossible")
                return

            k = len(cycle)
            for j in range(k):
                q[cycle[j]] = cycle[(j + 1) % k]
                p[cycle[j]] = cycle[(j - 1) % k]

    print("Possible")
    print(*p[1:])
    print(*q[1:])

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```代码首先构建逆排列，使目标结构成为一组循环。 然后它使用访问过的数组提取每个周期。 当大小为 1 的循环出现时，它就会停止，因为不存在有效的基于混乱的分解。 

在每个循环内，直接分配正向和反向旋转。 索引以循环长度为模进行仔细处理，这避免了循环两端的边界问题。 

一个微妙的实现细节是$p$和$q$存储为值的映射$1..n$，而不是循环内的位置。 这避免了循环索引和排列索引之间的混淆。

 ## 边缘情况

 当原始数组已将值放置在派生映射下的正确最终位置时，就会出现单元素循环。 在这种情况下，循环分解会产生一个长度为 1 的循环，算法会立即拒绝它，因为两者都不是$p$也不$q$可以保持元素固定，同时仍然处于混乱状态。 

对于二元交换，例如$a = [2,1]$，循环有效且长度为 2。 该算法将其沿相反方向旋转，产生两个有效的混乱。 跟踪它明确地显示每个元素都移动并且合成正确取消。 

当排列形成一个大循环时，这种构造仍然有效，因为旋转是全局明确定义的。 每个元素都被移动，确保满足混乱条件，而组合则通过取消移动来恢复身份。
