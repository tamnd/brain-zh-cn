 ## 解决方案
 ## 问题理解

 我们正在研究一个大小为矩形的网格$2n \times 2m$具有固定的国际象棋颜色：一个单元格$(i, j)$是白色的，如果$i + j$为偶数，否则为黑色。 只有白细胞对游戏很重要。 随着时间的推移，一些白色单元格通过一系列查询在“已删除”和“可用”之间切换。 

每次切换后，我们必须回答一个全局可行性问题：我们能否准确地放置$n \cdot m$国王在当前可用的白细胞上，这样就不会出现两个国王互相攻击的情况？ 国王向所有八个方向攻击，因此任何两个选定的单元格不得共享边缘或角落，这意味着它们的切比雪夫距离必须至少为 2。 

这将网格变成当前可用白色单元格集合上的图问题，其中边以切比雪夫距离 1 连接单元格。我们被问到该图是否允许一组独立的大小$n \cdot m$，但附加的约束是目标尺寸是固定的并且相对于网格结构来说相当大。 

约束很大：最多 200,000 行、200,000 列和 200,000 次更新。 这会立即排除整个网格上的任何每次查询重新计算或任何依赖于每次切换后遍历所有活动单元格的解决方案。 任何方法都必须支持对数或接近恒定的摊销更新，并且答案必须增量维护。 

一个微妙的点是只有白细胞会被切换。 黑色单元格是无关的，永远不会出现在运算中，因此有效图只是白色单元格上的诱导图。 

一个天真的错误是将其视为完整网格邻接图上的二分匹配或着色可行性问题。 这会导致每次更新后重新计算连接的约束，这太慢了。 

另一个常见的失败案例是假设由于国王禁止邻接，我们只需要检查本地邻域的更新。 当一次删除创建了一个全局“阻塞模式”，迫使多个组件进行交互时，这种情况就会被打破。 

## 方法

 直接的强力方法将维持整个网格状态，并在每次切换后尝试构建有效的布局$nm$国王。 这可以通过网格图上的贪婪放置或二分匹配风格推理来完成。 然而，即使是单个可行性检查也需要扫描所有$O(nm)$白细胞，最坏的情况下可达 4 亿个细胞。 对于 200,000 个查询，这是完全不可行的。 

关键的观察结果是，仅具有切比雪夫邻接的棋盘网格中的白细胞结构大大简化了。 上一个完整的$2n \times 2m$在棋盘上，国王的最佳放置是严格的：它对应于在较粗的尺度上选择固定的棋盘状图案。 每个$2 \times 2$块在任何最大有效配置中恰好贡献一个强制放置槽。 这意味着全局答案不取决于任意邻接，而是取决于每个这样的块是否仍然包含至少一个可用的白细胞。 

因此，我们不再推理任意独立性，而是将问题重新解释为检查是否每个$2 \times 2$宏块仍然有至少一个可用的白细胞。 如果任何块变得完全不可用，我们将失去放置所需数量的国王的能力，因为该块不再能够提供有效的放置。 

因此，问题简化为在点切换下维护是否所有$n \cdot m$块包含至少一个活跃的白细胞。 

我们为每个块维护一个计数器，跟踪它当前包含的活跃白细胞数量。 当且仅当没有块计数为零时，答案为“是”。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(nm)$每个查询 |$O(nm)$| 太慢了 |
 | 每块计数 |$O(1)$每个查询 |$O(nm)$| 已接受 |

 ## 算法演练

 我们绘制每个白细胞的图$(i, j)$到宏块$(i // 2, j // 2)$。 每个块对应一个$2 \times 2$原始网格的区域。 我们为每个块维护一个整数计数器，表示它包含多少个当前活动的白细胞。 

1. 将所有块计数器初始化为零。 我们还维护一个全局计数器，跟踪当前有多少块“空”，这意味着它们的计数器为零。 最初，所有单元格都存在，因此没有块是空的。 
2. 对于每个查询，我们切换一个白色单元格$(i, j)$。 我们计算它的块索引$(bi, bj) = (i // 2, j // 2)$。 
3. 如果单元格被删除，我们将减少其块的计数器。 如果计数器变为零，我们将增加全局空块计数器，因为该块已丢失其最后一个有效单元。 
4. 如果单元正在恢复，我们检查当前计数器。 如果更新前为零，我们将减少全局空块计数器，因为恢复后该块将不再为空。 然后我们增加块计数器。 
5. 处理完切换后，如果全局空块计数器为零，则输出“YES”，否则输出“NO”。 

关键的设计点是我们永远不需要检查相邻的方块或模拟国王的放置。 所有相关约束都归结为每个结构单元是否仍然具有至少一个可用单元。 

### 为什么它有效

 有效的配置$nm$国王只需要一名“代表”$2 \times 2$块，因为在这样的块内，任何两个白单元相互相邻或共享邻接约束，从而防止多个安全选择在全局平铺结构中同时有效。 因此，每个块必须贡献至少一个可用单元。 

相反，如果每个块至少有一个可用的白细胞，我们可以为每个块独立选择一个，因为不同块之间的交互永远不会在所选代表的级别上产生邻接冲突。 这种独立性源于国际象棋颜色网格上切比雪夫距离的固定几何形状。 

因此“不存在空块”这个条件既是充分必要的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, q = map(int, input().split())
    
    # Each block (i//2, j//2) tracks number of active white cells
    # We store only non-zero entries in a dictionary for sparsity.
    from collections import defaultdict
    cnt = defaultdict(int)
    
    empty_blocks = n * m
    active = set()
    
    def key(i, j):
        return (i >> 1, j >> 1)
    
    out = []
    
    for _ in range(q):
        i, j = map(int, input().split())
        k = key(i, j)
        
        if (i, j) in active:
            # remove
            if cnt[k] == 1:
                empty_blocks += 1
            cnt[k] -= 1
            active.remove((i, j))
        else:
            # add
            if cnt[k] == 0:
                empty_blocks -= 1
            cnt[k] += 1
            active.add((i, j))
        
        out.append("YES" if empty_blocks == 0 else "NO")
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现维护块上的哈希映射和一组活动单元以支持切换。 块索引是使用整数除以 2 计算的，这是安全的，因为每个块都是一个$2 \times 2$原始网格中的区域。 

关键细节是仅当块在零和非零之间转换时才更新全局“空块”计数。 这避免了每次查询扫描所有块。 

## 工作示例

 ### 示例 1

 输入：```
1 3 3
1 1
1 5
2 4
```我们有$1 \times 3$块，所以总共 3 个块。 

| 查询 | 细胞| 块| 块数变化 | 空块 | 回答 |
 | ---| ---| ---| ---| ---| ---|
 | 1 | (1,1) | (0,0) | (0,0) | 0 → 1 | 2 | 是的 |
 | 2 | (1,5) | (0,2) | 0 → 1 | 1 | 是的 |
 | 3 | (2,4) | (0,2) | 1 → 0 | 2 | 否 |

 第三次操作后，块(0,2)再次变空，并且至少有一个块没有可用的单元，因此配置是不可能的。 

### 示例 2

 输入：```
3 2 2
4 2
6 4
```我们总共有 6 个区块。 

| 查询 | 细胞| 块| 块数变化 | 空块 | 回答 |
 | ---| ---| ---| ---| ---| ---|
 | 1 | (4,2) | (2,1) | 0 → 1 | 5 | 是的 |
 | 2 | (6,4) | (3,2) | 0 → 1 | 4 | 是的 |

 这两个操作都会激活之前的空块，因此始终保持可行性。 

这些痕迹表明，只有块的空虚才重要，而不是块内细胞的确切空间分布。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |$O(q)$| 每个查询都会更新一个哈希条目和一组成员资格操作 |
 | 空间|$O(q)$| 每个切换单元格和每个活动块最多有一个条目 |

 这些约束允许进行 200,000 次操作，并且每次操作都在恒定的预期时间内处理，这完全符合限制。

 ## 边缘情况

 当块由于重复切换而在空和非空之间振荡时，就会出现临界边缘情况。 该算法完全依赖于检测零处的转换，因此不正确的处理将在全局计数器中显示为相差一错误。 

例如，考虑一个具有重复切换的单元格的单个块：```
1 1 4
1 1
1 1
1 1
1 1
```区块状态按照 0 → 1 → 0 → 1 → 0 演化，全局答案必须相应地交替。 该实现通过仅在跨越零阈值时更新空块计数器来确保这一点，从而在整个重复操作中保持正确性。
