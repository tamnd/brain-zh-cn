 ## 解决方案
 ## 问题理解

 农场里只有鸡和牛，农夫约翰数了一下总共有`n`腿。 鸡每只贡献 2 条腿，牛每条贡献 4 条腿。 该问题要求与总腿数一致的尽可能少的动物数量。 本质上，我们正在分发`n`将腿分为 2 条和 4 条一组，同时尽量减少动物的总和。 

输入是多个测试用例。 每个测试用例都是一个偶数`n`代表计算的总腿数。 每个测试用例的输出是一个整数：可以准确生成的动物的最小数量`n`腿。 

限制很小：`n`上升到 2000 并且`t`最多为 1000。因为`n`是有界的，任何具有线性运算的解`n`每个测试用例 (O(n)) 将在一秒内轻松运行。 我们也知道`n`总是偶数，这简化了一些边缘情况 - 我们永远不必处理奇数的边总数。 

当出现边缘情况时`n`非常小，就像`2`。 在这种情况下，唯一的可能性是一只鸡，尽管从技术上讲，有多种动物组合，总和`n`较大示例中的腿。 另一个微妙之处是，当我们最大化奶牛数量时，动物数量就会达到最少，因为每头奶牛为每只动物贡献更多的腿，从而降低了总数量。 粗心的方法可能会首先尝试将所有腿分成鸡，从而产生过多的动物。 

## 方法

 蛮力方法是迭代所有可能的奶牛数量，从 0 到`n//4`，计算鸡的剩余腿，并跟踪最少的动物总数。 这是正确的，因为它枚举了所有可行的组合。 操作次数与`n//4`每个测试用例。 和`n`最多 2000 次，每个测试用例大约需要 500 次迭代，考虑到约束条件，这是可以接受的，但这是不必要的，因为解决方案可以用数学方式表示。 

关键的见解是，最大限度地减少动物数量相当于最大限度地增加奶牛的数量。 如果每头牛有4条腿，每只鸡有2条腿，那么我们首先分配尽可能多的牛，但不超过`n`。 剩下的腿分配给鸡。 从代数上来说，如果`n`是偶数，则动物的最少数量是`n // 4`奶牛加`(n % 4) / 2`鸡。 自从`n`是偶数，`(n % 4)`是 0 或 2，因此除法总是产生一个整数。 这将问题转换为每个测试用例的简单算术计算。

 | 蛮力 | O(n) | O(1) | O(1) | 已接受但速度过慢 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 接受且高效 |

 ## 算法演练

 1. 对于每个测试用例，读取总分支数`n`。 自从`n`保证偶数，我们可以安全地除以 2 或 4，而不必担心分数。 
2. 计算奶牛的最大数量为`n // 4`。 每头牛有 4 条腿，因此使用尽可能多的牛可以减少剩余动物的数量。 
3. 将剩余的腿计算为`n % 4`。 因为`n`是偶数，即 0 或 2。 
4. 剩下的腿分配给鸡。 由于每只鸡有 2 条腿，因此鸡的数量为`(n % 4) // 2`。 
5. 将牛和鸡的数量相加，得到动物总数的最小数量。 
6. 打印每个测试用例的结果。 

为什么它有效：不变的是四足动物的最大数量总是产生最小的动物总数。 奶牛越少，就需要更多的鸡来满足相同的腿数，从而增加动物总数。 因为`n`是偶数，分配牛后剩下的腿总是能被2整除，所以鸡的计算是准确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    cows = n // 4
    chickens = (n % 4) // 2
    print(cows + chickens)
```在这段代码中，`n // 4`确定奶牛的最大数量，并且`(n % 4) // 2`决定剩下的鸡。 我们不需要任何循环或条件，因为模除法和整数除法处理所有偶数`n`。 使用`sys.stdin.readline`确保多个测试用例的快速输入。

 ## 边缘情况

 对于最小输入，n=2，算法计算`0`奶牛和`1`鸡，正确产生 1 只动物。 对于 n 不能被 4 整除但仍为偶数的情况，例如 n=6，我们分配 1 头牛和 1 只鸡，这比 3 只鸡少了动物数量，这表明最大化牛会减少动物总数。 对于较大的 n，例如 n=2000，整数除法和模运算仍然正确且快速。 该算法处理允许范围内的所有偶数 n，无需任何特殊的大小写。
