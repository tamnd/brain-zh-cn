 ## 解决方案
 ## 问题理解

 我们有一个大小为的正方形网格$n \times n$其中每个单元格包含一个零或一个一。 任务是将这个网格缩小一个因子$k$，保证可除$n$均匀。 归约通过将网格划分为$k \times k$非重叠块，其中每个块包含相同的值，并用表示该值的单个单元格替换每个块。 输出是尺寸较小的网格$(n/k) \times (n/k)$这是块压缩的结果。 

鉴于限制条件，$n$可以大到 1000，但总和$n$所有测试用例的数量最多为 1000。这意味着对所有单元格的直接迭代是可以接受的，因为我们不会超过大约$10^6$总共的操作。 当出现不明显的边缘情况时$k = 1$或者$k = n$。 如果$k = 1$，缩小后的网格与原始网格相同，因此我们必须避免无意中跳过任何行或列。 如果$k = n$，整个网格折叠成一个单元格。 在这些情况下，粗心的实现可能会尝试读取超出网格边界的索引或混淆块起点。 

## 方法

 蛮力方法很简单：迭代所有大小的块$k \times k$，选择任何有代表性的单元格（例如，左上角的单元格），并将其值放入简化的网格中。 这是正确的，因为该问题保证了块中的所有单元都是相同的。 简单的实现会检查每个块中的每个单元，但由于保证的原因，这是不必要和多余的。 

最佳方法通过每个块仅读取一个单元来利用这一保证。 这减少了工作量$(n/k)^2$每个网格的操作，考虑到限制，这是微不足道的。 观察发现，每$k \times k$块是同质的允许我们跳过所有的迭代$k^2$块中的单元格，使解决方案变得更简单、更快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 检查每个块中的所有单元格 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 由于总 n 较小而被接受 |
 | 仅检查每个块的左上角单元格 | O((n/k)^2) | O((n/k)^2) | O((n/k)^2) | O((n/k)^2) | 被接受，更简单，更快|

 ## 算法演练

 1.读取测试用例数量$t$。 每个测试用例由一个网格大小组成$n$, 折算系数$k$， 和$n$的行$n$每个字符。 
2. 对于每个测试用例，确定缩小网格的大小，即$m = n/k$。 
3. 初始化一个空列表来存储缩减后的网格。 
4. 迭代每个块行索引$i$从 0 到$m-1$。 对应的原始网格行是$i \cdot k$。 
5. 在每个块行内，迭代每个块列索引$j$从 0 到$m-1$。 对应的原始网格列是$j \cdot k$。 
6. 选取左上角的单元格$k \times k$阻塞于$(i \cdot k, j \cdot k)$并将其附加到缩小网格的当前行。 
7. 处理当前块行的所有列后，将该行追加到缩小的网格中。 
8. 逐行打印缩小后的网格。 

为什么它有效：保证一个中的所有细胞$k \times k$块相同使我们可以安全地仅选择左上角的单元格。 迭代块索引而不是单个单元可确保我们一次覆盖所有块，而不会丢失或重复任何块。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        grid = [input().strip() for _ in range(n)]
        m = n // k
        reduced = []
        for i in range(m):
            row = []
            for j in range(m):
                row.append(grid[i * k][j * k])
            reduced.append("".join(row))
        print("\n".join(reduced))

if __name__ == "__main__":
    solve()
```该解决方案首先读取测试用例的数量，然后单独处理每个测试用例。 原始网格被完全读入内存。 简化的网格是通过访问每个网格的左上角单元格来构建的$k \times k$堵塞。 缩减网格的每一行都连接成一个字符串并按顺序打印。 使用整数除法可确保正确的块索引。 这可以处理边缘情况$k=1$和$k=n$自然地，因为循环适应减小的尺寸$m = n/k$。

 ## 边缘情况

 当$k = 1$，该算法单独迭代每个单元格，有效地复制原始网格。 为了$k = n$，缩小后的网格是单个单元格。 这两种情况都无需任何特殊处理即可工作，因为循环限制计算如下$m = n/k$，在崩溃情况下变为 1 并且$n$在身份案件中。 选择始终安全地读取每个块的左上角单元格可以保证同质性，避免任何偏差或索引错误。
