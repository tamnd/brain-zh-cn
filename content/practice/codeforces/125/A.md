 ## 解决方案
 ## 问题理解

 在巴登，转换规则与现实世界不同。 一英寸等于 3 厘米，一英尺等于 12 英寸。 

我们给出的长度以厘米为单位。 任务是将长度表示为英尺和英寸的组合。 由于原始长度可能不对应于精确的整数英寸，因此我们首先需要根据语句中描述的特殊舍入规则将其舍入到最接近的整数英寸。 之后，在所有等效表示中，我们必须最大化英尺数。 

由于一英寸正好是 3 厘米，因此将厘米转换为英寸意味着计算最接近的整数$n / 3$。 该声明给出了诸如 1 厘米变为 0 英寸、2 厘米变为 1 英寸等示例，这证实了普通四舍五入到最接近的整数。 

约束很小，$1 \le n \le 10000$。 即使是低效的解决方案也很容易满足限制。 挑战不是性能，而是正确处理舍入规则，然后将英寸转换为英尺和剩余英寸。 

最常见的错误来源是舍入步骤。 

考虑输入：```
1
```我们有$1/3 = 0.333...$，四舍五入为 0 英寸。 正确的输出是：```
0 0
```总是对小数值进行四舍五入的粗心实现会错误地生成 1 英寸。 

考虑输入：```
2
```我们有$2/3 = 0.666...$，四舍五入为 1 英寸。 正确的输出是：```
0 1
```如果不小心使用楼层划分，则会产生 0 英寸。 

当四舍五入增加总英寸数足以产生额外的英尺时，会发生另一种微妙的情况。 

例如：```
35
```自从$35/3 = 11.666...$，四舍五入后的值为 12 英寸。 十二英寸等于一英尺，因此正确的输出是：```
1 0
```在舍入之前将厘米直接转换为英尺和英寸的实现将错过此转换。 

## 方法

 强力解决方案可以尝试所有可能的英尺数，将其转换回英寸，然后检查哪种表示形式与舍入长度相匹配。 由于输入大小很小，因此仍然会立即运行。 对于最多约 3333 英寸的圆形长度，我们只会测试几百种可能性。 

问题的真正结构要简单得多。 将长度转换为英寸的四舍五入整数后，最大化英尺的要求有一个明显的解释：使用尽可能多的 12 英寸组。 

问题自然地分成两个独立的部分。 

首先，计算最接近的整数英寸。 由于一英寸等于三厘米，因此我们需要最接近的整数$n/3$。 对于正整数，这完全可以通过整数算术来完成：$$\text{inches} = \left\lfloor \frac{n+1}{3} \right\rfloor$$此公式重现所需的舍入行为：

 - 1 厘米 → 0 英寸
 - 2 厘米 → 1 英寸
 - 4 厘米 → 1 英寸
 - 5 厘米 → 2 英寸

 一旦我们知道了总英寸数，最大化英尺就意味着尽可能多地采用 12 英寸的完整组。 英尺数是整数除以 12，剩下的英寸是模 12 的余数。

 ## 算法演练

 1.读取整数$n$，长度以厘米为单位。 
2. 将厘米转换为最接近的整数英寸。 

由于一英寸等于三厘米，因此精确值是$n/3$。 所需的舍入可以实现为：$$\text{inches} = (n + 1) // 3$$这是可行的，因为小数部分始终为 0、1/3 或 2/3。 
3. 计算最大英尺数。 

每英尺包含 12 英寸，因此：$$\text{feet} = \text{inches} // 12$$4. 计算剩余的英寸。$$\text{rem} = \text{inches} \bmod 12$$5、输出`feet`和`rem`。 

### 为什么它有效

 四舍五入后，长度以精确的整数英寸表示。 任何以英尺和英寸为单位的表示都必须满足：$$12 \cdot \text{feet} + \text{inches\_remaining} = \text{total\_inches}$$其余英寸在 0 到 11 之间（含）。 

整数除以 12 会产生最大可能数量的 12 英寸完整组。 余数正是完成这些组后剩余的英寸数。 由于没有任何表示形式可以包含比整数除法提供的更完整的组，因此所得的英尺数是最大的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

inches = (n + 1) // 3
feet = inches // 12
rem = inches % 12

print(feet, rem)
```第一步计算四舍五入的英寸数。 使用`(n + 1) // 3`完全避免浮点运算并完全匹配语句中的舍入规则。 

接下来的两行执行从英寸到英尺和剩余英寸的标准转换。 整数除法计算总英寸数中有多少个完整的英尺，而模数则计算剩余的英寸数。 

顺序很重要。 我们必须先将厘米值四舍五入为英寸，然后再转换为英尺。 在四舍五入之前执行转换会给出诸如 35 厘米之类的值的错误答案，其中四舍五入会将 11.666... 英寸更改为 12 英寸并创建额外的英尺。

 ## 边缘情况

 第一个棘手的情况是：```
1
```该算法计算：$$(1+1)//3 = 0$$所以总长度是 0 英寸。 然后：$$0//12 = 0,\quad 0\%12 = 0$$输出变为：```
0 0
```这符合所需的舍入规则。 

第二个棘手的情况是：```
2
```该算法计算：$$(2+1)//3 = 1$$所以圆角长度是 1 英寸。 然后：$$1//12 = 0,\quad 1\%12 = 1$$输出是：```
0 1
```这证实了 2 厘米向上舍入为 1 英寸。 

第三个棘手的情况是：```
35
```该算法计算：$$(35+1)//3 = 12$$然后：$$12//12 = 1,\quad 12\%12 = 0$$输出是：```
1 0
```此案例验证在将结果拆分为英尺和英寸之前是否已完成舍入。 如果顺序颠倒，答案就会错误。
