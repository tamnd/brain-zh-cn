 ## 解决方案
 # 问题理解

 该问题要求新放置的 TNT 块的波动性最小，以便保证现有的每个 TNT 块立即爆炸。 新的TNT可以放置在三维空间中的任何实值位置。 对于现有的 TNT`(xi, yi, zi)`波动率恒定`vi`，新 TNT 所需的波动性是其距该点的曼哈顿距离除以`vi`。 任务是选择放置位置，使所有 TNT 碎片中所需的最大波动性最小化。 

输入最多包含 20000 个 TNT 块。 每一块都对新 TNT 的可能位置产生限制。 对 TNT 块对进行二次搜索或对坐标进行网格搜索的成本太高，因为坐标可以达到一百万，而答案可以是实数。 对于此输入大小，算法需要接近线性或线性乘以小对数因子。 

一些边缘情况很容易被忽略。 如果只有一块TNT，则可以将新的TNT恰好放置在同一位置，答案为零。 

例如：```
1
5 5 5 10
```正确的输出是：```
0.00000000
```如果粗心地假设答案必须是肯定的，那么这里就会失败。 

另一个微妙的情况是最佳位置不是现有的 TNT 坐标。 考虑：```
4
0 0 0 1
1 2 0 1
3 4 0 1
2 1 0 1
```正确的输出是：```
3.50000000
```最佳点位于现有坐标之间。 仅检查整数位置或仅检查现有 TNT 位置会错过答案。 

波动常数也会改变每个点的影响。 例如：```
3
1 0 0 1
2 1 1 4
3 2 3 2
```正确的输出是：```
2.33333333
```将每个 TNT 视为具有相同的权重会错误地解决普通的几何中心问题，而不是加权版本。 

## 方法

 一种直接的方法是尝试候选位置并计算每个位置所需的波动性。 难点在于位置是连续的，不限于整数坐标。 即使我们以某种方式生成了所有有趣的坐标，比较所有可能的候选坐标也是不切实际的。 搜索空间没有自然的小界限。 

关键的观察是扭转问题。 不要问对于给定的波动性，TNT 应该放在哪里，而要问所选的波动性是否`T`就足够了。 

对于固定的`T`，每个 TNT 块都定义了一个允许位置的区域。 新的 TNT 必须在曼哈顿距离内`T * vi`来自每个现有的 TNT。 问题是所有这些区域是否至少有一个共同点。 

三维空间中的曼哈顿距离有一个有用的变换。 对于任意一点`(x, y, z)`，定义四个值：```
s1 = x + y + z
s2 = x + y - z
s3 = x - y + z
s4 = -x + y + z
```对于任意两点，它们的曼哈顿距离等于这四个变换坐标之间的最大绝对差。 这将原始的三维菱形区域转换为四个独立的区间约束。 

对于具有转换值的 TNT`s1, s2, s3, s4`, 候选波动率`T`要求：```
|S1 - s1| <= T * vi
|S2 - s2| <= T * vi
|S3 - s3| <= T * vi
|S4 - s4| <= T * vi
```四个变换后的坐标中的每一个现在只需要其间隔重叠。 如果对于每个变换后的坐标，所有间隔的交集都非空，则所选的波动率有效。 

通过二分查找可以找到答案`T`。 每个可行性检查都会扫描所有 TNT 块一次，因此完整的算法足够快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(搜索空间 × N) | O(1) | O(1) | 太慢了|
 | 最佳 | O(N log C) | O(N log C) | O(N) | 已接受 |

 这里`C`是二分查找所覆盖的数值范围。 使用固定的迭代次数可以有效地保持恒定，大约 70 次检查双精度。 

## 算法演练

 1. 改变每个TNT位置`(x, y, z)`分为四个值：```
x + y + z
x + y - z
x - y + z
-x + y + z
```该变换之所以有效，是因为曼哈顿距离成为这四个坐标之间的最大差异。 

1.二分查找答案`T`，新放置的 TNT 的波动性。 从零下限和足够大的上限开始。 
2.对于每个二分查找中点`T`，检查这种波动是否可能。 对于每个变换后的坐标，维护所有可能值的交集间隔。 
3. 对于具有波动性的TNT`v`，其变换后的坐标`a`允许新的变换后的坐标位于内部的任何位置：```
[a - T*v, a + T*v]
```将此间隔与当前全局间隔相交。 

1. 如果四个变换后的坐标区间中的任何一个变为空，`T`无法工作。 否则，`T`是可行的。 
2. 经过足够的二分搜索迭代后，输出下界作为所需的最小波动率。 

为什么它有效：

 对于固定波动率`T`，每个 TNT 片段独立地限制答案可能的变换坐标。 该变换准确地保留了曼哈顿距离，因此满足四个区间约束相当于满足原始三维距离约束。 当所有四个变换维度都具有共同的有效值时，该算法准确地声明一个值可行，这意味着存在满足每个 TNT 要求的真实点。 然后二分搜索找到最小的可行值，因为可行性是单调的：增加波动性只能扩大允许的区域。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

def solve():
    n = int(input())
    points = []

    for _ in range(n):
        x, y, z, v = map(int, input().split())
        points.append((
            x + y + z,
            x + y - z,
            x - y + z,
            -x + y + z,
            v
        ))

    def possible(t):
        low = [-10**30] * 4
        high = [10**30] * 4

        for a, b, c, d, v in points:
            vals = (a, b, c, d)
            radius = t * v

            for i in range(4):
                low[i] = max(low[i], vals[i] - radius)
                high[i] = min(high[i], vals[i] + radius)
                if low[i] > high[i]:
                    return False

        return True

    left = 0.0
    right = 3 * 10**6

    for _ in range(80):
        mid = (left + right) / 2
        if possible(mid):
            right = mid
        else:
            left = mid

    print("{:.10f}".format(right))

if __name__ == "__main__":
    solve()
```输入被读取一次，并且在应用坐标变换后存储每个 TNT。 保留转换后的值可以避免在每次二分搜索迭代期间重新计算相同的表达式。 

这`possible`函数代表可行性测试。 数组`low`和`high`存储每个变换维度的允许间隔的当前交集。 处理 TNT 时，允许的间隔会缩小`max`和`min`。 如果下端点超过上端点，则任何布局都无法满足当前的波动性。 

二分查找使用浮点值，因为答案不一定是整数。 八十次迭代足以满足要求`1e-6`精确。 的上限`3 * 10^6`是安全的，因为坐标在曼哈顿距离上最多相差 300 万，并且每个波动常数至少为 1。

 ## 边缘情况

 对于单个 TNT 案例：```
1
5 5 5 10
```二分查找检查零是否有效。 唯一 TNT 的变换间隔全部塌陷为一个点，并且它们的交集是有效的。 该算法不断减少答案，直到达到零。 

对于答案不是现有坐标的情况：```
4
0 0 0 1
1 2 0 1
3 4 0 1
2 1 0 1
```可行性检查不会尝试猜测实际位置。 相反，它会验证转换后的间隔是否重叠。 波动时`3.5`，每个变换后的区间都有一个共同的值，证明存在一些真实的点，即使它不是原始 TNT 位置之一。 

对于不同的波动率常数：```
3
1 0 0 1
2 1 1 4
3 2 3 2
```TNT具有波动性`4`对于相同的所需波动性，允许更大的距离。 区间交叉自然地通过在每次检查期间将每个半径乘以其自身的波动性常数来解释这一点。 该算法从不假设权重相等，因此结果值与问题的加权几何形状相匹配。
