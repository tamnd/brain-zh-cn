 ## 解决方案
 ## 问题理解

 房间是一个`N × M`方形地板单元网格。 伊莎贝尔想要用相同的 L 形瓷砖替换整个网格。 每个图块覆盖四个单元：三个单元成一条直线，一个额外的单元连接到一端，并且图块可以旋转。 任务是确定这些图块的某种排列是否可以覆盖整个矩形而没有间隙或重叠。 

一块图块总是恰好覆盖四个单元格，因此第一个限制来自面积。 矩形面积必须能被四整除。 然而，仅有这个条件还不够。 L-四联骨牌具有更强的奇偶性限制：每个有效矩形的面积也需要能被八整除，并且边长为一的矩形不能被覆盖，因为每个图块至少占据两行两列。 

输入值最多为 1000，这意味着解决方案应基于数学观察而不是模拟布局。 包含多达一百万个单元的网格对于搜索可能的图块排列来说已经太大了。 回溯解决方案会在许多可能的图块位置上分支并很快变得不可行。 

棘手的情况是面积可分性看起来足够但几何形状拒绝矩形的情况。 

例如，一个房间的尺寸`1 8`有八区，但答案是`NO`。 粗心的解决方案仅检查`N*M % 8 == 0`会接受它，即使单行不能包含 L 形瓷砖。 

另一个例子是`2 2`。 面积是四，但答案是`NO`。 这个矩形太小，甚至无法容纳一个 L-tetromino。 

通过条件的情况是`2 4`。 面积是八并且两个维度都大于一，所以答案是`YES`。 可以排列两块 L 形瓷砖来填充矩形。 

## 方法

 直接的方法是尝试将瓷砖一块一块地铺在地板上。 强力搜索可以选择一个未覆盖的单元格，尝试覆盖该单元格的 L 形图块的所有可能的旋转，然后递归地继续。 这是正确的，因为它探索了所有可能的平铺。 问题是可能的排列数量呈指数级增长。 即使对于中等大小的矩形，搜索树也会变得巨大，因为许多不同的图块顺序代表相同的最终排列。 

有用的观察是不需要构建精确的位置。 我们只需要识别矩形何时具有有效的平铺。 L-tetromino 覆盖四个单元格，但列着色参数给出了更严格的条件：有效的平铺始终使用偶数个平铺，这意味着总面积必须能被 8 整除。 这会立即删除许多矩形。 

剩下的问题是这个条件是否也充分。 如果两个维度都大于 1 并且面积可被 8 整除，则该矩形始终可以分割成可以平铺的更小的矩形。 当一条边是偶数时，长方形可以分为`2 × 4`块，每个这样的块可以由两个 L-四联骨牌填充。 当一侧为奇数时，面积条件强制另一侧为 8 的倍数，从而允许将矩形划分为`3 × 8`块和`2 × 4`块。 两种块类型都具有有效的 L-tetromino 平铺。 

整个问题归结为检查两个条件：房间的尺寸必须不等于一，并且其面积必须能被八整除。

 ## 算法演练

 1.读取两个房间的尺寸`N`和`M`。 
2. 检查任一维度是否等于 1。 如果是，则输出`NO`因为 L-tetromino 不能放入单行或单列中。 
3. 计算`N * M`并检查它是否能被八整除。 可整除条件捕获了由 L-tetromino 的形状产生的图块计数限制。 
4. 输出`YES`如果两个条件都满足。 否则，输出`NO`。 

为什么有效：每个有效的平铺都必须满足面积限制和尺寸限制，因此拒绝不符合任一条件的矩形是安全的。 对于满足这两个条件的每个矩形，该矩形可以分解为更小的区域，这些区域可以由 L-四联骨牌单独平铺。 这些条件既是必要的又是充分的，因此算法总是返回正确的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

if n == 1 or m == 1:
    print("NO")
elif (n * m) % 8 == 0:
    print("YES")
else:
    print("NO")
```该代码读取两个维度并立即应用算法中的两个数学检查。 第一个条件处理狭小的房间，无法放置。 第二个条件使用区域限制。 

乘法`n * m`在 Python 中是安全的，因为整数具有任意精度，尽管即使是固定宽度的 32 位整数也足以满足给定的限制，因为最大面积仅为一百万。 

没有循环，因此不存在边界遍历问题或相差一错误。 唯一可能的错误是忘记一维情况并接受面积恰好能被八整除的矩形。

## 测试用例```python
import sys
import io

def solve(data: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(data)
    n, m = map(int, sys.stdin.readline().split())

    if n == 1 or m == 1:
        ans = "NO"
    elif (n * m) % 8 == 0:
        ans = "YES"
    else:
        ans = "NO"

    sys.stdin = old_stdin
    return ans

# provided samples

assert solve("9 6\n") == "NO", "sample 2"

# custom cases

assert solve("2 4\n") == "YES", "small valid rectangle"
assert solve("2 2\n") == "NO", "area is not enough"
assert solve("1000 1000\n") == "YES", "maximum size case"

 ## 边缘情况

 对于`1 8`，算法首先发现一个维度是一并立即返回`NO`。 虽然面积可以被八整除，但每个 L-tetromino 都需要两个方向的空间，因此无法覆盖矩形。 

为了`2 2`，面积只有四。 该算法拒绝它，因为四不能被八整除。 仅基于每个图块覆盖四个单元这一事实的解决方案将错误地接受这种情况。 

为了`2 4`，算法检查两个维度都大于 1 并且面积为 8。 它返回`YES`。 这是一个有效的基础结构，其中两个 L-四联骨牌恰好覆盖了矩形。 

为了`9 6`，算法在通过尺寸检查后到达面积检查。 面积为`54`， 和`54 % 8`不为零，因此返回`NO`。 该矩形在几何上足够大，但单元数量无法划分为有效的 L-tile 组。
