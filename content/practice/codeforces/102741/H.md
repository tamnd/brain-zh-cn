 ## 解决方案
 ## 问题理解

 我们在一维走廊上有一组电击器位置，在同一条线上有一组幽灵位置。 每个鬼魂都必须通过选择一个消灭器来消除。 如果有鬼魂在远处`d`从所选的灭杀器中，消耗的能量是`d²`。 我们的目标是找到当每个幽灵被分配到最便宜的可能的灭杀器时所需的最小总能量。 答案必须以模数形式打印`10^9 + 7`。 原始问题的约束最多允许`10^5`电击器和`10^5`鬼魂，坐标可达`10^7`。 

大的输入大小立即排除了检查每个鬼魂与每个灭杀器的可能性。 直接解决方案将执行`n * m`距离计算。 两个值都等于`100000`，那就变成`10^10`计算，这远远超出了正常竞技编程所允许的时间限制。 我们需要利用所有位置都在一条线上的事实。 

关键的结构是，排序后距离鬼魂最近的电击器必须是它​​周围的两个电击器之一。 如果鬼魂位于两个相邻的灭杀器之间，远离任一灭杀器只会增加距离。 如果幽灵位于整个灭弧器范围之外，则最近的灭弧器就是最近的端点。 这意味着问题可以简化为排序和二分搜索。 

一些边缘情况可能会破坏仅考虑常见情况的实现。 

如果鬼魂正好位于电击器上，则能量贡献为零。

## 方法

 暴力解决方案很简单。 对于每个鬼魂，迭代每个 zapper，计算平方距离，并保持最小值。 这是正确的，因为该幽灵的每一个可能的分配都会被检查。 

问题是工作量。 和`n`电击器和`m`鬼魂，这表演`n * m`比较和距离计算。 在最大输入大小时，这达到`10^10`操作，速度太慢。 

重要的观察是位置是一维的。 对电击器位置进行排序后，总是在排序数组中鬼魂的插入点附近找到距离鬼魂最近的电击器。 我们不需要检查所有电击器。 

对于幽灵位置`x`，二分查找给出第一个位置至少为`x`。 这个击杀者是右边最接近的候选人。 前一个 zapper（如果存在）是左侧最接近的候选者。 右侧的任何其他 zapper 都比该第一个右侧候选者更远，并且左侧的任何其他 zapper 都比该第一个左侧候选者更远。 我们只需要比较这两个。 

蛮力之所以有效，是因为它会检查所有可能的攻击者。 观察到只有相邻的 zappers 才重要，从而将每个幽灵查询从线性时间减少到对数时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(纳米) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n log n + m log n) | O(n log n + m log n) | O(1) 额外 | 已接受 |

 ## 算法演练

 1. 读取所有电击器位置并对它们进行排序。 

排序创建了一个有序结构，其中二分搜索可以快速找到任何幽灵位置周围的灭杀器。 
2. 对于每个幽灵位置，对已排序的 zapper 执行二分搜索以找到第一个索引`i`在哪里`zappers[i] >= ghost`。 

这将可能的最近的消灭者分为两个候选者。 索引处的灭杀器`i`是右边最接近的一个，而电击器在`i - 1`是左边最接近的一个。 
3. 检查有效候选人。 

如果`i`位于数组内部，使用以下方法计算成本`zappers[i]`。 如果`i - 1`是非负的，使用以下方法计算成本`zappers[i - 1]`。 保持较小的平方距离。 
4. 将这个幽灵的最低成本添加到正在运行的答案中。 

加法后应用模数以保持整数大小易于管理。 

为什么它有效：

 对于任何幽灵位置，请考虑其周围排序的灭杀器。 比紧邻的左邻居更靠左的每个电击器都具有更大的距离，并且比紧邻的右邻居更靠右的每个电击器也具有更大的距离。 最近的电击器必须是这两个邻居之一。 该算法始终准确地检查这些候选者，因此每个幽灵都会获得尽可能小的能量成本。 将这些独立的最小成本相加即可得到最小的总能量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, m = map(int, input().split())

    zappers = []
    for _ in range(n):
        zappers.append(int(input()))

    zappers.sort()

    ans = 0

    for _ in range(m):
        x = int(input())

        left = 0
        right = n

        while left < right:
            mid = (left + right) // 2
            if zappers[mid] >= x:
                right = mid
            else:
                left = mid + 1

        best = 10**30

        if left < n:
            d = zappers[left] - x
            best = d * d

        if left > 0:
            d = zappers[left - 1] - x
            best = min(best, d * d)

        ans = (ans + best) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```zappers 的排序列表是主要的数据结构。 二分搜索实现找到下限，这意味着包含大于或等于当前幻影位置的值的第一个位置。 

变量`left`搜索后不是左邻居，就是插入位置。 如果它等于`n`，右侧没有电击器。 如果为零，则左侧没有电击器。 这两个边界检查可防止无效的数组访问。 

Python 整数不会溢出，因此即使坐标差可达`10^7`。 在具有固定宽度整数的语言中，应该使用更宽的类型来完成乘法。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n log n + m log n) | O(n log n + m log n) | 对 zappers 进行排序的成本为 O(n log n)，并且 m 个幽灵中的每一个都执行一次二分搜索。 |

 该解决方案处理`10^5`电击器和`10^5`幽灵，因为昂贵的工作在排序期间执行一次，然后是高效的对数查询。

 ## 边缘情况

 对于精确匹配，例如：```

5
10
5
```二分查找返回索引`5`。 该算法比较该候选者并发现距离为零，因此贡献为零。 

对于超出可用范围的重影：```

```第一个幽灵获取插入索引`0`，所以只有在`10`已检查。 第二个幽灵也获得插入索引`0`，给出正确的成本`100`和`25`。
