 ## 解决方案
 ## 问题理解

 我们得到玛莎的电话号码，是一串数字。 根据这个号码，她逐位生成另一个电话号码。 

新号码的第一位数字可以是以下任意数字`0`到`9`。 之后，下一个数字是根据之前选择的数字和玛莎号码的相应数字确定的。 如果先前选择的数字是`p`玛莎号码的当前数字是`a[i]`，那么下一个数字必须等于：$$\left\lfloor \frac{p + a[i]}{2} \right\rfloor \quad \text{or} \quad \left\lceil \frac{p + a[i]}{2} \right\rceil$$什么时候`p + a[i]`是偶数，两个表达式相同，并且强制使用下一个数字。 当总和为奇数时，只有两种选择。 

我们必须计算可以产生多少个不同的电话号码。 玛莎可能会也可能不会拨打她自己的号码，具体取决于此过程是否可以生成该号码。 该声明说“也许除了她自己的一个”，这意味着只有当它出现在生成的数字中时我们才必须减去它。 

输入长度最多为`50`。 这立即排除了任何显式生成所有结果电话号码的尝试，因为分支因子可以达到`2`在每个位置。 在最坏的情况下，有效序列的数量大致变为`10 * 2^49`，这是一个天文数字。 

小长度强烈暗示了对位置和数字的动态编程。 在每一步中，唯一重要的信息是之前选择的数字。 由于只有`10`可能的数字，状态空间很小。 

有几种边缘情况很容易被错误处理。 

考虑输入：```
0
```生成的数字恰好由一位数字组成，并且第一位数字可以自由选择。 全部`10`一位数字有效，包括`"0"`本身。 由于玛莎没有拨打自己的电话号码，所以答案是`9`。 

粗心的实现可能会忘记在可构造时减去 Masha 的数字。 

另一个微妙的情况是每次转换都是被迫的。 

输入：```
2222
```如果我们从任何第一位数字开始，则接下来的每个数字都将被唯一确定，因为所有总和保持偶数。 正好有`10`生成的数字。 其中之一是`"2222"`本身，所以答案是`9`。 

有缺陷的解决方案可能会错误地假设每个位置总是使可能性数量加倍。 

还有一个奇偶校验陷阱。 

输入：```
11
```假设第一个选择的数字是`0`。 第二个数字变为`0`或者`1`， 因为`(0 + 1) / 2 = 0.5`。 如果第一个选择的数字是`1`，第二位数字被迫`1`。 不同的先前数字会导致不同的分支行为，因此我们无法独立计算每个位置的选择。 

## 方法

 蛮力思想遵循字面上的过程。 我们尝试每个可能的第一个数字，递归地构造每个允许的延续，并计算不同的生成的电话号码。 

这是有效的，因为转换规则是局部的。 一旦知道了前一个数字，就可以通过一个或两个选择来确定下一个数字。 递归树正确枚举每个有效序列。 

问题在于序列数量的爆炸式增长。 每个奇数和都会创建两个分支。 在最坏的情况下，几乎每个位置都会分支，大致导致：$$10 \cdot 2^{n-1}$$和`n = 50`，这超过了`5 \times 10^{15}`州。 甚至存储结果也是不可能的。 

关键的观察是，未来仅取决于先前生成的数字，而不取决于整个前缀。 如果两条不同的构造路径在同一位置以相同的数字结束，则它们剩余的可能性是相同的。 

这种结构正是动态编程所利用的。 

我们定义：$$dp[i][d]$$作为生成以位置结尾的前缀的方法数`i`其中生成的数字等于`d`。 

来自一个州`(i - 1, prev)`，我们使用平均规则计算允许的下一个数字`a[i]`。 每个有效的转换都会对下一个 DP 层做出贡献。 

由于只有`50`职位和`10`位，状态总数很小：$$50 \cdot 10$$每个状态最多尝试两次转换，因此出于实际目的，整个解决方案以恒定时间运行。 

最后，我们将所有 DP 状态相加，得到生成的电话号码总数。 如果玛莎的原始数字本身是可构造的，那么我们就减一。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^n)$|$O(2^n)$| 太慢了 |
 | 最佳DP |$O(n \cdot 10)$|$O(10)$| 已接受 |

 ## 算法演练

 1. 读取字符串形式的电话号码，并将其转换为数字数组。 
2.初始化一个大小为DP的数组`10`。`dp[d]`表示有多少种方法可以生成当前前缀并以数字结尾`d`。 
3. 对于第一个位置，从`0`到`9`是允许的。 

放：```
dp[d] = 1
```对于所有数字`d`。 
4. 从左到右处理剩余位置。 
5. 对于每个前面的数字`prev`，计算：$$s = prev + a[i]$$6.如果`s`是偶数时，下一个数字是唯一确定的：$$nxt = s / 2$$添加所有途径`prev`进入`nxt`。 
7. 如果`s`是奇数，有两个可能的舍入值：$$\lfloor s/2 \rfloor \quad \text{and} \quad \lceil s/2 \rceil$$将当前计数添加到接下来的两个状态。 
8. 用新计算的 DP 数组替换旧的 DP 数组。 
9. 处理完所有位置后，将所有 DP 值相加。 这是生成的电话号码的总数。 
10. 检查能否生成Masha自己的号码。 

观察如果我们尝试生成准确的原始数字本身会发生什么。 在位置`i`，我们要求：$$x_i = a_i$$递归变为：$$a_i = \frac{x_{i-1} + a_i}{2}$$这意味着：$$x_{i-1} = a_i$$由于这对于每个位置都必须成立，因此原始数字的所有数字必须相等。 
11. 如果原数中所有数字都相同，则减去`1`从答案中。 

### 为什么它有效

 DP 不变量为：$$dp[d]$$始终等于生成的以数字结尾的有效前缀的数量`d`处理完当前位置后。 

每个有效生成的数字都对应于通过这些状态的一个转换序列，因为每个步骤仅取决于前一个数字和当前的原始数字。 转换规则列举了所有合法的四舍五入平均值，仅此而已。 

最终的减法是正确的，因为当且仅当每个相邻数字对相等时，原始数字才可构造。 任何不匹配都会违反再现原始数字序列所需的平均方程。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    a = list(map(int, s))
    n = len(a)

    dp = [1] * 10

    for i in range(1, n):
        ndp = [0] * 10

        for prev in range(10):
            total = prev + a[i]

            if total % 2 == 0:
                nxt = total // 2
                ndp[nxt] += dp[prev]
            else:
                ndp[total // 2] += dp[prev]
                ndp[total // 2 + 1] += dp[prev]

        dp = ndp

    ans = sum(dp)

    same = True
    for i in range(1, n):
        if a[i] != a[0]:
            same = False
            break

    if same:
        ans -= 1

    print(ans)

solve()
```DP 数组仅存储当前位置的计数。 一旦转换完成，我们就不再需要旧层，因此实现使用滚动数组而不是完整的二维表。 

转换逻辑直接反映平均规则。 当总和为偶数时，下限和上限重合，因此仅存在下一位数字。 当和为奇数时，两个相邻的整数都有效。 

最后检查玛莎自己的号码出奇的简单。 只有在整个过程中每个数字都等于先前生成的数字时，原始数字才能自我复制。 这迫使所有数字都相同。 

一个微妙的实现细节是当总和为偶数时避免重复计算。 如果我们总是添加下限和上限值，我们会意外地重复转换，因为在这种情况下这两个值相等。 

Python 整数自动处理大值，这很重要，因为计数可能呈指数增长。

 ## 边缘情况

 考虑输入：```
0
```最初每个第一位数字都是有效的，所以有`10`生成的数字。 由于原来的号码`"0"`它本身也在其中，我们减去一。 

该算法计算：

 | 步骤| 价值|
 | --- | --- |
 | 初始总计 | 10 | 10
 | 自编号存在 | 是的 |
 | 最终答案| 9 |

 现在考虑：```
2222
```每一次转变都是被迫的，因为所有的总和都是偶数。 

如果第一个数字是`2`，序列完全保持不变`"2222"`。 其他起始数字也产生独特的确定性序列。 

DP 永远不会分支，因此总数保持不变`10`。 由于原数是可构造的，因此我们减一并得到`9`。 

最后，检查：```
11
```从上一个数字开始`0`, 平均`1`给出`0.5`，可以四舍五入到任一`0`或者`1`。 

从上一个数字开始`1`, 平均`1`准确地给出`1`。 

该算法通过检查总和的奇偶性来正确区分这些情况。 偶数和创建一个转换，奇数和创建两个转换。
