 ## 解决方案
 ## 问题理解

 我们得到一个数字$n$，并且对于每个整数$i$从$0$到$n$，我们看整个$i$帕斯卡三角形的第 - 行。 对于该行中的每个条目，我们采用二项式系数$\binom{i}{j}$，将其模 2 减少，并对所有这些值求和。 最后，我们将这个数量从所有行中求和$0$到$n$。 

所以任务是计算每个 Pascal 行中出现了多少个奇数条目$n$，将这些计数加在一起，并输出模数结果$998244353$。 

约束条件清楚地表明$n$可以大到$10^{18}$，并且最多可以有$3 \cdot 10^5$测试用例。 任何尝试迭代所有值的解决方案$n$这是不可能的，因为即使是单个测试用例也可能需要多达$10^{18}$运营。 预期的解决方案必须仅取决于$n$，最多有 60 位。 

一个微妙的问题源于“$\binom{i}{j} \mod 2$”。我们并不是对二项式系数本身求和，而只是对它们的奇偶性求和。这完全改变了结构：值崩溃为 0 或 1，问题变成了组合问题而不是算术问题。另一个潜在的陷阱是尝试直接计算二项式系数或阶乘，这对于大数据来说是不可行的。$i$而且也是不必要的。 

## 方法

 直接解释将计算，对于每个$i$， 全部$i+1$二项式系数，将其模 2 减少，并计算有多少个是奇数。 这已经花费了$O(i)$每行，以及所有行直至$n$它变成$O(n^2)$，这远远超出了任何可行的限制，即使对于小$n$。 

关键的简化来自于理解二项式系数何时为奇数。 根据以 2 为底的卢卡斯定理，二项式系数$\binom{i}{j}$是奇数当且仅当每个位都设置为$j$也设置在$i$。 换句话说，行中奇数条目的数量$i$等于设置位的子集数$i$，即$2^{\mathrm{popcount}(i)}$。 

这将问题转化为计算$$\sum_{i=0}^{n} 2^{\mathrm{popcount}(i)}.$$现在结构更加清晰了。 每个数字贡献一个值仅取决于其二进制表示中出现的数量。 这表明对位进行操作而不是对值进行迭代。 

暴力破解的想法失败了，因为它枚举了直到$n$，但观察到该函数仅取决于位计数，这使我们能够按最高设置位分割范围并递归地减少问题。 

我们使用一个完整块中的所有数字的恒等式$2^k$每个位的值独立贡献，给出完整块的封闭形式和剩余前缀的递归关系。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n)$每次测试 |$O(1)$| 太慢了 |
 | 位递归 |$O(\log n)$每次测试 |$O(\log n)$| 已接受 |

 ## 算法演练

 我们定义一个函数$S(x)$作为所需的总和$0$到$x$， 意义$S(x) = \sum_{i=0}^{x} 2^{\mathrm{popcount}(i)}$。 

1.如果$x = 0$，返回 1，因为唯一的数字是 0，其 popcount 为 0，贡献$2^0 = 1$。 
2. 求两个不超过的最高次方$x$， 说$2^k$。 这划分了范围$[0, x]$分为两部分：数字来自$0$到$2^k - 1$，以及来自的数字$2^k$到$x$。 
3. 对于全块$[0, 2^k - 1]$，每个数字恰好是一个$k$-位数。 每个位独立贡献 0 或 1，一组位贡献权重的 2 倍。 这使得总贡献等于$(1 + 2)^k = 3^k$。 
4. 对于数字$[2^k, x]$，每个数字都有最高位设置，贡献固定因子 2。删除该位会留下较小的数字$[0, x - 2^k]$，因此贡献变为$2 \cdot S(x - 2^k)$。 
5. 合并两个部分：$$S(x) = 3^k + 2 \cdot S(x - 2^k).$$6. 预先计算 3 的幂和 2 的幂（最多 60 位）并评估每个测试用例的递归。 

### 为什么它有效

 递归是有效的，因为每个数字都被唯一地分解为其最高设置位和剩余的后缀。 贡献$2^{\mathrm{popcount}(i)}$分解为来自最高位的固定贡献和来自较低位的独立贡献。 整个范围干净地分成与 2 的幂对齐的不相交块，因此不会对任何值进行两次计数，也不会遗漏任何值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

pow3 = [1] * 61
for i in range(1, 61):
    pow3[i] = pow3[i - 1] * 3 % MOD

def solve_one(n: int) -> int:
    if n == 0:
        return 1

    # find highest bit
    k = n.bit_length() - 1
    highest = 1 << k

    # full block [0, 2^k - 1]
    res = pow3[k]

    # remainder
    res += 2 * solve_one(n - highest)
    return res % MOD

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        print(solve_one(n) % MOD)

if __name__ == "__main__":
    main()
```功能`solve_one`直接进行递归分解。 预先计算的`pow3[k]`给出了完整的贡献$k$位空间。 递归调用处理删除最高位后剩余的后缀。 

一个常见的错误是忘记后缀仍然具有相同的结构，只是缩放了 2 倍，因为该段中的最高位始终为 1。 

## 工作示例

 考虑$n = 3$。 我们计算$S(3)$。 

| 步骤| n | k | 3^k 贡献 | 递归部分| 结果|
 | --- | --- | --- | --- | --- | --- |
 | 1 | 3 | 1 | 3 | S(1) | 3 + 2·S(1) |
 | 2 | 1 | 0 | 1 | S(0) | 1 + 2·1 |

 现在$S(1) = 3$， 所以$S(3) = 3 + 2 \cdot 3 = 9$。 

这与直接枚举匹配：$1 + 2 + 2 + 4 = 9$。 

现在考虑$n = 5$。 

| 步骤| n | k | 3^k 贡献 | 递归部分| 结果|
 | --- | --- | --- | --- | --- | --- |
 | 1 | 5 | 2 | 9 | S(1) | 9 + 2·S(1) |
 | 2 | 1 | 0 | 1 | S(0) | 1 + 2·1 |

 所以$S(5) = 9 + 2 \cdot 3 = 15$。 

这证实了递归正确地以 2 的幂分割范围并保留了权重结构。

import sys, io

for i in range(1, 61):
    pow3[i] = pow3[i - 1] * 3 % MOD

def solve_one(n: int) -> int:
    if n == 0:
        return 1
    k = n.bit_length() - 1
    highest = 1 << k
    return (pow3[k] + 2 * solve_one(n - highest)) % MOD

 ## 边缘情况

 对于$n = 0$，递归必须立即终止。 该函数返回 1，与只有空 popcount 起作用的事实相匹配。 

对于形式的值$2^k - 1$，递归永远不会进入后缀情况。 答案就变成了$3^k$，并且实现必须确保正确计算最高位，以便不会出现差一错误移位$k$。 

对于二的幂，例如$n = 8$，分割产生一个完整的块加上一个零后缀。 后缀递归必须正确返回1； 否则，在更深的递归级别中，最高段的贡献将被低估 2 倍。
