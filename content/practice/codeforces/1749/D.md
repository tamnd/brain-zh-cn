 ## 解决方案
 ## 问题理解

 我们被要求计算长度达到的数组$n$值介于$1$和$m$其中存在多个有效的移除序列。 删除顺序是可以删除元素的顺序，使得每个元素$a_i$与删除时其在数组中的当前位置互质。 

输入是两个整数：$n$，要考虑的数组的最大长度，以及$m$，元素可以取的最大值。 输出是不明确数组的总数，模$998244353$。 

纵观边界，$n$可以达到$3 \cdot 10^5$和$m$最多$10^{12}$。 这排除了任何数组的强力枚举，因为即使生成长度为 10 的所有数组也需要$m^{10}$最坏情况下的操作。 任何解决方案都必须避免迭代单个数组，而是进行组合或数学推理。 

A key edge case arises when$n = 2$和$m = 1$。 在这种情况下，唯一的数组是$[1, 1]$，如果存在多个移除序列，则该序列是不明确的，但仔细检查表明确实存在一个序列。 类似地，所有元素均为 1 的数组通常不会有歧义，因为移除序列完全由与 1 互质的位置决定。 

## 方法

 天真的暴力方法将生成长度达到的所有数组$n$，模拟每个数组的所有可能的移除序列，并检查是否存在多个序列。 这是有效的，因为歧义的定义很明确：如果一个数组允许多个删除序列，那么它就会被计算在内。 然而，即使是长度为 20 的数组$m=10^6$使得这种方法不可行。 枚举序列随长度呈阶乘增长，所以$O(n!)$每个数组是不可能的。 

关键的见解是，只有当某个数字出现在多个可以删除的位置时，才会出现歧义。 更准确地说，仅当某个数组具有一对连续位置时才会出现歧义$i$和$i+1$这样$\gcd(a_i, i+1) = 1$和$\gcd(a_{i+1}, i) = 1$。 这允许在不违反互质条件的情况下交换两个元素的移除顺序，这正是模糊性的条件。 

一旦我们认识到这一点，问题就简化为计算长度至少为 2 且满足数组中任意位置的局部条件的数组。 因为每个元素都是独立的，所以长度不明确的数组的计数$k$是数组中至少存在一对这样的相邻对的所有位置的总和。 对于每个位置，有效值的数量就是整数的数量，最多可达$m$与该位置索引互质。 

计算整数的个数$[1, m]$有效地与给定整数互质，我们使用 Euler totient 函数$\phi(i)$。 使用这个函数，我们可以对数组进行组合计数，而无需枚举它们，因为每个位置都有$\phi(i)$对可能与其邻居产生歧义的元素的选择。

 ## 算法演练

 1. 预先计算 Euler 的 totient 函数$\phi(i)$为所有人$i \le n+1$使用筛子。 这让我们可以计算数字$[1, m]$快速与每个索引互质。$\phi(i)$是整数的个数$[1, i]$与 互质$i$，为了我们的目的，我们可以通过$\lfloor m / i \rfloor$考虑上述倍数$i$。 
2. 对于每个长度$k$从 2 到$n$，考虑每对相邻的位置$i$和$i+1$。 如果我们可以交换移除顺序，就会出现歧义。 对于职位$i$，选择的数量$a_i$与 互质$i+1$是$\phi(i+1)$（上限为$m$如果$m < i+1$）。 为了$a_{i+1}$，与 互质的数字的个数$i$是$\phi(i)$。 将这些计数相乘即可得到该位置的不明确对的数量。 
3. 因为数组中任何位置只有一对这样的值就足以产生歧义，所以我们对所有位置求和$i$在长度数组中$k$。 数组长度大于$k$有额外的位置，但它们的额外元素并不能消除歧义，因此每个计数都是独立的。 
4. 从 2 到所有长度的总和计数$n$获取不明确数组的总数。 应用模数$998244353$每一步都避免溢出。 

工作原理：Euler totient 预计算可保证每个位置的潜在值的准确计数。 通过仅分析相邻对并利用元素的独立性，我们捕获了至少可以进行一次交换的所有数组。 位置总和确保我们对所有不明确的数组进行计数，并且使用模算术可以在大的情况下保持正确性$m$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def compute_totients(limit):
    phi = list(range(limit + 2))
    for i in range(2, limit + 2):
        if phi[i] == i:
            for j in range(i, limit + 2, i):
                phi[j] -= phi[j] // i
    return phi

def main():
    n, m = map(int, input().split())
    phi = compute_totients(n + 1)
    ans = 0
    for i in range(1, n):
        count_i = min(phi[i], m)
        count_ip1 = min(phi[i+1], m)
        ans = (ans + count_i * count_ip1) % MOD
    print(ans)

if __name__ == "__main__":
    main()
```该代码首先预先计算所有位置的欧拉 totient，直到$n+1$，它可以有效地计算与每个索引互质的数字。 主循环将每个相邻对的互质数的计数相乘，并累加总模数$998244353$。 最小与$m$确保我们不会过多计算超出允许最大值的数字。
