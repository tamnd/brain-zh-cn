 ## 解决方案
 ## 问题理解

 该问题要求我们考虑由倒数函数定义的曲线，其中输入给出整数 x 坐标区间。 对于该区间内的每个非零整数，我们在该 x 坐标处绘制曲线的切线。 该切线与两个坐标轴相交并创建一个三角形。 任务是添加所有这些三角形的面积。 

输入值可以大到$10^{18}$以绝对值表示。 这立即排除了迭代区间中的每个整数，因为区间长度可以约为$2 \times 10^{18}$，远远超出任何程序可以处理的范围。 我们需要恒定时间或对数时间观察。 由于函数和正切公式在代数上很简单，因此预期的解决方案来自于简化几何表达式，而不是搜索或模拟。 

一个常见的错误是忘记零是不允许的。 例如，对于输入：```
0 0
```答案是：```
0
```没有有效的 x 坐标，因为倒数函数在零处未定义。 只计算间隔大小的程序会错误地输出 2。 

当间隔过零时，会出现另一种边缘情况。 对于输入：```
-2 2
```有效坐标是$-2,-1,1,2$，所以答案是：```
8
```粗心的实现可能会计算五个位置并包含零，从而产生不正确的结果。 

最终的边界情况是单个负值：```
-7 -7
```答案是：```
2
```当切线位于轴的另一侧时，面积不会变为负值。 三角形面积使用绝对长度。 

## 方法

 一种直接的方法是访问区间中的每个整数 x，跳过零，计算切线，计算其三角形面积，并将其添加到答案中。 这是正确的，因为它完全遵循定义。 但是，如果区间包含$10^{18}$值，循环大约需要$10^{18}$迭代，这在时间限制内是不可能的。 

关键的观察结果是，对于每个有效的 x 坐标，三角形面积都是相同的。 令所选坐标为$a$。 的导数$1/x$是$-1/x^2$，所以切线在$(a,1/a)$是$$y-\frac1a=-\frac1{a^2}(x-a)$$这简化为$$y=-\frac{x}{a^2}+\frac2a$$x 轴截距是通过设置找到的$y=0$：$$0=-\frac{x}{a^2}+\frac2a$$所以：$$x=2a$$y 轴截距为：$$y=\frac2a$$由轴和线组成的三角形的面积为：$$\frac12 \times |2a| \times \left|\frac2a\right| = 2$$每个非零整数对答案的贡献正好为 2。 几何形状消失了，整个问题变成了计算区间中有多少个非零整数。 

暴力法之所以有效，是因为每个点都可以独立处理，但它会失败，因为点太多。 代数简化让我们可以用一次区间计数代替数十亿次几何计算。

 ## 算法演练

 1. 读取区间的两个端点。 
2. 计算区间内有多少个整数。 整数的总数是$r-l+1$。 如果间隔包含零，则将其从计数中删除，因为该函数在那里未定义。 
3. 将有效整数的数量乘以 2。每个有效整数创建一个面积恰好为 2 的三角形。 

这样做的原因是答案仅由有效点的数量决定，而不是由它们的实际位置决定。 负坐标和正坐标的贡献相等，因为三角形区域使用绝对长度。 

为什么它有效：

 对于每个非零整数$x$，切线创建截距$2x$和$2/x$。 它们的绝对乘积始终为 4，因此三角形面积始终为$4/2=2$。 由于三角形是独立的，因此最终的总和只需 2 乘以允许的 x 值的数量。 删除零是唯一需要的特殊处理，因为$1/x$那里不存在。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    l, r = map(int, input().split())

    count = r - l + 1
    if l <= 0 <= r:
        count -= 1

    print(count * 2)

if __name__ == "__main__":
    solve()
```程序首先计算闭区间的大小。 这仅对端点使用算术，因此即使端点附近$10^{18}$由 Python 整数立即处理。 

零检查写为`l <= 0 <= r`，它直接描述了零是否属于区间。 如果是，则计数减一。 

最终乘以 2 应用每个有效正切三角形的常数贡献。 没有循环、浮点运算或几何计算，因此不存在精度问题。

import sys
import io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    count = r - l + 1
    if l <= 0 <= r:

    return str(count * 2)

# minimum-size style case

 ## 边缘情况

 对于输入：```
0 0
```该算法从间隔大小 1 开始。由于零位于间隔内，因此它减一并得到有效计数零。 最后的乘法结果为 0。 

对于输入：```
-2 2
```初始计数为 5，因为值是$-2,-1,0,1,2$。 检测到零的条件为真，因此计数变为 4。答案变为$4 \times 2=8$，匹配四个有效的正切三角形。 

对于输入：```
-7 -7
```区间仅包含一个值。 零条件为 false，因此计数保持为 1。答案为 2，这表明负坐标的处理方式与正坐标的处理方式相同，因为面积使用绝对距离。
