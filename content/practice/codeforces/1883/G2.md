 ## 解决方案
 ## 问题理解

 我们有两个大小相同的数组。 在做任何其他事情之前，我们可以任意重新排序每个数组。 

操作从第一个数组中删除一个元素，从第二个数组中删除一个元素。 执行一定次数的操作后，两个数组具有相同的剩余长度。 我们希望能够对剩余元素进行重新排序，以便每个位置都满足：$$a_i < b_i$$简单版本要求单个数组$a$。 在这个硬版本中，第一个元素$a$被每个值替换$x \in [1,m]$。 对于每个结果数组$$A(x)=\{x,a_2,a_3,\dots,a_n\},$$我们需要最少的操作次数，然后我们必须将所有答案相加$x$。 

所有测试用例的总大小最多为$10^5$， 但$m$可以大到$10^9$。 这立即排除了迭代所有可能的值$x$。 我们需要了解答案如何变化$x$更改并同时聚合多个值。 

一个微妙的一点是重新排序是免费的。 数组中的实际位置并不重要。 只有多重值集才重要。 

另一个容易犯的错误是直接考虑删除。 最小操作数等于不能参与有效匹配的元素数。 最大化有效对的数量通常比推理删除要容易得多。 

考虑：```
A = [3, 100]
B = [4, 5]
```贪婪的逐位置比较会失败，但重新排序后我们可以匹配$3$和$4$。 恰好一对幸存下来，所以答案是$1$， 不是$2$。 

另一个危险的情况是许多值相等时。```
A = [5, 5]
B = [5, 5]
```由于不等式是严格的，因此没有一对是有效的。 答案是$2$。 将条件视为$\le$会产生错误的结果。 

最后，因为$m$是巨大的，甚至是$O(m)$解决办法是不可能的。 答案必须可以仅使用几个范围来表达$x$。 

## 方法

 蛮力方法很简单。 

对于每一个$x$从$1$到$m$,构造数组$A(x)$。 对两个数组进行排序并计算满足的最大对数$a<b$使用标准的两指针匹配算法。 如果最大匹配大小为$M_x$，那么最少操作次数为$$n-M_x.$$这个匹配本身就是$O(n)$排序后，所以即使我们重复使用排序工作，处理所有$m$值至少需要$O(m)$时间。 自从$m$可能达到$10^9$，这是完全不可行的。 

关键的观察是只有一个元素发生变化：插入的值$x$。 其余$n-1$元素是固定的。 

而不是重新计算每个匹配$x$，我们分析匹配缺陷。 

让$B$被排序。 对于每一个$b_i$， 定义$$c_i = \#\{a \in A(x): a < b_i\}.$$其中第一$i$的元素$B$, 至多$c_i$的元素$A$足够小，可以匹配。 如果$i>c_i$，至少$i-c_i$第一个的元素$i$地位必须保持无与伦比。 

这个有序匹配问题的经典结果是最小删除次数等于$$\max_i (i-c_i).$$现在分裂$c_i$成固定部分和贡献$x$。 

让$$s_i = \#\{a_j : j\ge 2,\ a_j < b_i\}.$$然后$$c_i=s_i+[x<b_i].$$替换给出$$i-c_i = (i-s_i)-[x<b_i].$$定义$$t_i=i-s_i.$$然后是特定的答案$x$变成$$\max_i \left(t_i-[x<b_i]\right).$$每个术语都是$t_i$或者$t_i-1$。 让$$T=\max_i t_i.$$答案只能是$T$或者$T-1$。 

如果至少有一个索引$t_i=T$满足$b_i\le x$，该指数贡献$T$，所以答案是$T$。 

否则每个最大索引减一，所有剩余索引最多为$T-1$，所以答案是$T-1$。 

让$$L=\min\{b_i : t_i=T\}.$$然后：$$\text{answer}(x)= \begin{cases} T-1,& x<L\\ T,& x\ge L \end{cases}$$整个函数只有一个断点。 

总和$x\in[1,m]$现在是立即的。 

如果$$cnt=\#\{x\in[1,m]:x<L\} = \min(m,L-1),$$然后$$\sum answer(x) = (T-1)\cdot cnt + T\cdot (m-cnt) = T\cdot m-cnt.$$剩下的就是计算了$T$和$L$。 

既然两者$a_2,\dots,a_n$和$B$已排序，所有值$s_i$可以通过一次两指针扫描来计算。
