 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，并被要求计算连续子数组的数量，这些子数组的元素作为子序列出现在原始数组中**恰好一次**。 简而言之，如果当您尝试在数组中的其他任何位置找到它而不重新排列其元素时，只有一种方法可以选择这些位置，则子数组是很好的选择。 例如，`[1, 2]`在`[1, 2, 1]`很好，因为顺序`1, 2`只出现在前两个位置。 但`[1]`很糟糕，因为`1`出现多次，因此有多种方法将其选为子序列。 

输入由多个测试用例组成。 每个测试用例都有一个数组，最多可达`10^5`元素，以及所有元素的总和`n`跨测试用例最多`2*10^5`。 这立即告诉我们，任何比粗略慢的解决方案`O(n log n)`每个测试用例都会太慢。 枚举所有子数组的简单方法是`O(n^2)`每个测试用例，这显然是行不通的。 

当所有元素都相同、大小为 1 的数组或值重复交替的数组时，就会出现边缘情况。 例如，`[1, 1, 1]`如果允许任何单个元素，则只有一个长度为 1 的有效子数组，但所有更长的子数组都是无效的。`[1, 2, 1]`有子数组`[1, 2]`,`[2, 1]`,`[1, 2, 1]`行为不同。 仔细处理重复项至关重要，因为它们控制子序列是否唯一。 

## 方法

 强力方法是迭代所有可能的子数组，并且对于每个子数组，检查它作为子序列出现的次数。 天真地检查子序列需要`O(n)`每个子数组的时间，并且有`O(n^2)`子数组，因此整体复杂度为`O(n^3)`每个测试用例。 这显然不能用于`n`最多`10^5`。 

关键的见解是子数组`[a_l, ..., a_r]`作为子序列出现多次**如果子数组中的任何元素以冲突的顺序出现在其当前位置之外的其他位置**。 为了准确起见，我们可以跟踪每个值在数组中的第一次和最后一次出现。 如果子数组的所有元素在其位置之外的整个数组中**恰好出现一次**，则子数组作为子序列是唯一的。 另一种思考方式是维护一个滑动窗口，使得窗口内的元素不会在相同或重叠区域内再次出现。 这将问题简化为双指针问题，其中我们扩展右边界，同时确保窗口内的每个元素最多出现两次：一次在窗口中，一次可能在窗口外。 

一个巧妙的观察是，“坏”元素是那些第一次或最后一次出现在当前窗口内但也出现在当前窗口外的元素。 通过使用两个映射来跟踪第一次和最后一次出现，然后移动左指针以排除冲突，我们可以有效地计算有效窗口的数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(n) | 太慢了 |
 | 最佳两指针 | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 首先，为数组中的每个唯一值预先计算其第一次和最后一次出现的索引。 这使我们能够快速检查候选子数组中的元素是否出现在其他位置的冲突位置。 
2.初始化左指针`l`在 0 处迭代右指针`r`从 0 到 n-1。 我们正在有效地尝试维护一个有效的子数组`[l, r]`其中所有元素都出现在不会创建多个子序列的位置。 
3. 维护一个映射，统计每个元素在当前窗口中出现的次数。 如果我们尝试包含已出现在窗口内或违反唯一性约束的元素，请移动左指针`l`缩小窗口，直到再次满足条件。 
4. 对于每个位置`r`，结束于的有效子数组的数量`r`是`(r - l + 1)`。 将此计数添加到总数中。 这是有效的，因为扩展`r`by 1 包括所有以以下结尾的新子数组`r`具有不同的左端点。 
5. 继续直到`r`到达数组末尾。 

不变的是每一步，`[l, r]`是**结束于的最大子数组`r`作为一个子序列**，它是唯一的，因此计算其中的所有子数组可以确保我们将所有好的子数组都计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        last_occurrence = {}
        left = 0
        result = 0
        count = {}
        
        for right in range(n):
            val = a[right]
            count[val] = count.get(val, 0) + 1
            while count[val] > 1:
                count[a[left]] -= 1
                left += 1
            result += right - left + 1
        
        print(result)

solve()
```我们使用字典`count`跟踪当前窗口中发生的事件。 每当我们在窗口内遇到重复项时，我们就会移动`left`直到窗口有效。 以每个结尾的子数组的数量`right`只是窗口长度`right - left + 1`。 

边界处理很微妙：如果窗口开始从左侧缩小，我们必须小心地递减计数以避免出现减一错误。
