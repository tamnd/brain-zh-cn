 ## 解决方案
 ## 问题理解

 我们得到一个数组和一个小整数$k$， 在哪里$2 \le k \le 5$。 在一次操作中，我们可以选择任何元素并将其加一。 任务是找到所需的最少运算次数，以便所有数组元素的乘积可以被整除$k$。 

关键的观察是我们从不关心确切的产品。 我们只关心产品是否含有产品所需的主要因素$k$。 自从$k$至多是$5$，只有四个可能的值$k$:$2$,$3$,$4$， 和$5$。 这使得问题比最初出现时要小得多。 

所有测试用例的数组元素总数最多为$2 \cdot 10^5$。 任何检查每个元素恒定次数的解决方案都足够快。 涉及大状态动态规划或重复模拟操作的方法是不必要的。 

出现微妙的边缘情况时$k=4$。 整除性$4$与整除不同$2$，因为产品必须包含两个因素$2$。 例如：```
n = 2, k = 4
a = [1, 3]
```将一个元素增加到下一个四的倍数需要一次操作：```
[1, 4]
```答案是$1$。 只计算偶数的解决方案会错过这种可能性。 

另一个重要的情况是当几个元素可以共同贡献两个元素时：```
n = 3, k = 4
a = [1, 5, 9]
```使一个数能被四倍整除的成本$3$运营：```
1 -> 4
```但使两个数字相等只需要花费$2$运营：```
1 -> 2
5 -> 6
```那么乘积包含两个二之因数，所以正确答案是$2$。 

当乘积已经可以被整除时，就会出现最终的边缘情况$k$。 例如：```
n = 4, k = 5
a = [5, 4, 1, 2]
```答案是$0$。 任何算法都应该在执行进一步计算之前检查这一点。 

## 方法

 蛮力方法将尝试增量操作序列并搜索其乘积可整除的第一个状态$k$。 即使我们只考虑少量操作，分支因子也是$n$，使搜索呈指数级增长。 

问题的结构使得这是不必要的。 自从$k \le 5$，整除性仅取决于几个素因数。 

为了$k=2$,$k=3$， 和$k=5$，产品可除以$k$一旦一个数组元素可以被整除$k$。 如果当前没有元素可以整除$k$，我们只需计算将每个元素移动到下一个倍数需要多少增量$k$，然后取最小值。 

唯一有趣的案例是$k=4$。 一个产品可以被整除$4$如果它至少包含两个二的因数。 这可以通过两种不同的方式发生。 

一个元素可以被整除$4$。 

或者几个元素可能共同贡献两个元素。 自从$n \ge 2$，考虑使两个元素相等就足够了。 

答案为$k=4$是获得二之二的所有有效方法中的最小成本。

 ## 算法演练

 1. 读取数组。 
2. 间接计算当前乘积整除性。 

对于每个元素，检查其模余数$k$。 如果某个元素已经可以被整除$k$和$k \in \{2,3,5\}$，答案立即$0$。 
3.如果$k$是$2$,$3$， 或者$5$, 计算$$\min_i (k - a_i \bmod k) \bmod k.$$这是将一个元素移动到下一个倍数的成本$k$。 

1.如果$k=4$，首先计算使某个元素可被整除的最小成本$4$:$$\min_i (4 - a_i \bmod 4) \bmod 4.$$1. 计算数组中当前 2 的因数。 

对于每个元素：

 - 如果它能被$4$， 贡献$2$。 
- 否则，如果是偶数，则贡献$1$。 
- 其他贡献$0$。 
2. 如果 2 的因数总数已经至少为$2$，答案是$0$。 
3. 否则确定还需要多少个二因数。 
4. 计算使元素均匀的成本。 对于奇数元素，成本为$1$。 对于偶数元素，成本为$0$。 
5. 对这些成本进行排序，并采用获得缺失因子 2 所需的最少元素数。 
6. 最终答案是以下两者中的最小值：

 - 使一个元素可以被整除$4$。 
- 从多个元素中收集足够的两个因子。 

### 为什么它有效

 对于$k=2$,$3$， 和$5$，乘积的整除性只需要对应素数的一个因数。 单个元素可被整除$k$是充分且必要的。 

为了$k=4$，产品必须至少包含两个二之因数。 每个有效的配置要么通过一个可被四整除的元素，要么通过几个偶数元素（其组合贡献达到二的两倍）来实现这一点。 该算法明确评估两种可能性并选择更便宜的一种。 由于每个操作仅增加一个元素，因此获得所需整除条件的最便宜的方法始终是将元素移动到最接近的合格值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    if k in (2, 3, 5):
        ans = min((k - x % k) % k for x in a)
        print(ans)
        continue

    # k == 4
    ans = min((4 - x % 4) % 4 for x in a)

    twos = 0
    for x in a:
        if x % 4 == 0:
            twos += 2
        elif x % 2 == 0:
            twos += 1

    if twos >= 2:
        ans = 0
    else:
        costs = []
        for x in a:
            costs.append(x % 2)

        costs.sort()

        need = 2 - twos
        ans = min(ans, sum(costs[:need]))

    print(ans)
```该解决方案将简单的情况分开$k=2$,$3$， 和$5$从特殊情况来看$k=4$。 

为了$k=2$,$3$， 和$5$，只有最接近的倍数才重要。 表达式$$(k - x \bmod k) \bmod k$$返回零时$x$已经可以被整除$k$，否则返回所需增量的确切数量。 

为了$k=4$，第一个候选答案是使一个元素能被四整除的成本。 然后代码计算数组中已经存在的 2 的因数。 如果至少有两个可用，则该乘积已经可以被四整除。 

否则，代码会考虑将奇数元素设为偶数。 奇数元素需要一次操作，而偶数元素不需要任何操作。 对这些成本进行排序可以让我们选择获得两个缺失因子所需的最便宜的元素。 

不存在整数溢出问题，因为乘积本身从未被计算。

## 测试用例```python
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        if k in (2, 3, 5):
            out.append(str(min((k - x % k) % k for x in a)))
            continue

        ans = min((4 - x % 4) % 4 for x in a)

        twos = 0
        for x in a:
            if x % 4 == 0:
                twos += 2
            elif x % 2 == 0:
                twos += 1

        if twos >= 2:
            ans = 0
        else:
            costs = sorted(x % 2 for x in a)
            ans = min(ans, sum(costs[:2 - twos]))

        out.append(str(ans))

    return "\n".join(out)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    return solve()

assert run("1\n2 5\n7 3\n") == "2"
assert run("1\n5 5\n5 4 1 2 3\n") == "0"
assert run("1\n3 4\n1 5 9\n") == "2"
assert run("1\n3 4\n6 3 6\n") == "1"
assert run("1\n2 2\n1 1\n") == "1"
assert run("1\n2 5\n10 10\n") == "0"

 ## 边缘情况

 考虑：```
n = 4
k = 5
a = [5, 1, 1, 1]
```一个元素已经可以被五整除，因此乘积可以被五整除。 该算法计算该元素的成本为零并立即返回$0$。 

考虑：```
n = 3
k = 4
a = [2, 3, 3]
```该数组已经贡献了该值的二分之一$2$。 我们还需要一个因素。 转动任一$3$进入$4$花费一次手术。 该算法发现$twos = 1$，还需要一个因素，并返回$1$。 

考虑：```
n = 2
k = 4
a = [1, 1]
```使一个元素能被四整除需要三次运算。 制造这两个元素甚至需要两次操作。 该算法评估两种可能性并正确选择$2$。
