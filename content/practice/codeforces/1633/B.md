 ## 解决方案
 ## 问题理解

 任务是检查由“0”和“1”组成的二进制字符串，并识别一个连续的段，在该段中我们可以通过应用单个操作删除最大数量的字符。 该操作让我们选择一个子字符串并删除该子字符串中所有出现的严格少数字符。 严格少数意味着在选定的子字符串中，一个字符出现的次数严格少于另一个字符。 如果两个字符同样出现，则该操作不执行任何操作。 

输入由多个测试用例组成，每个测试用例都有一个字符串。 输出应该是每个测试用例可以删除的最大字符数。 由于字符串长度可以达到 200,000，并且所有测试用例的总输入大小也上限为 200,000，因此我们需要一个针对每个字符串以线性时间运行的解决方案。 检查所有子串的蛮力方法大约需要$O(n^2)$操作，这对于$n = 2 \cdot 10^5$。 

边缘情况包括所有字符都相同的字符串、长度为 1 的字符串以及具有交替字符的字符串。 例如，字符串`1`任何子串中都没有少数，因此输出为 0。该字符串`01`也无法删除任何字符，因为这两个字符同样出现在包含这两个字符的唯一子字符串中，导致输出为 0。未能正确处理这些情况可能会导致计数过多或忽略“严格少数”的约束。 

## 方法

 暴力解决方案将迭代每个可能的子字符串，计算该子字符串中“0”和“1”的数量，并计算少数计数。 虽然正确，但此方法是$O(n^2)$及时并且对于大字符串来说是不切实际的。 对于长度为 200,000 的字符串，我们将按以下顺序执行$2 \cdot 10^10$运营。 

关键的见解是操作的效果仅取决于所选子字符串中少数字符的出现次数。 如果我们专注于最大化删除的字符数，我们只需要找到一个字符比另一个字符出现频率更高的最大连续序列。 这个问题可以简化为 Kadane 算法的一个变体，这是一种寻找最大和子数组的经典方法。 通过将“0”和“1”映射到+1和-1（取决于我们将其视为可删除的），我们可以有效地找到使删除的字符数量最大化的段。 因为我们可以选择任何连续的子字符串，所以一个字符明显多于另一个字符的段正是我们想要的。

 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了 |

 ## 算法演练

 1. 计算字符串中“0”和“1”的总数。 整个字符串的少数字符是一个很好的候选者，因为任何主要包含少数字符的子字符串可以比使用全局少数计数删除更少的字符。 
2. 如果整个字符串中“0”的数量等于“1”的数量，则可以删除的最大字符数为零，因为该字符串的任何子字符串中都不存在严格少数。 
3. 否则，确定哪个字符是少数。 让我们将其表示为`minor`和大多数作为`major`。 
4. 将字符串映射到值数组中，以实现 Kadane 算法：少数字符的每次出现都变为 +1，多数字符的每次出现都变为 -1。 
5. 应用最大子数组和算法来查找使总和最大化的连续子串。 总和恰好对应于该子字符串中可以删除的少数字符的数量。 
6. 如果最大和为负数或零，则返回零。 否则，返回总和作为该测试用例的答案。 

为什么有效：每一步都保留了所选子串最大化去除严格少数的不变量。 Kadane 变换将问题转换为标准最大化问题，同时尊重少数/多数关系。 由于任何少数数多于多数数的子串都会产生正贡献，因此算法自然会找到最佳片段。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def max_removed(s: str) -> int:
    total_0 = s.count('0')
    total_1 = len(s) - total_0
    
    if total_0 == total_1:
        return 0
    
    minor = '0' if total_0 < total_1 else '1'
    # Transform string into array for Kadane's algorithm
    arr = [1 if c == minor else -1 for c in s]
    
    max_sum = curr_sum = 0
    for val in arr:
        curr_sum = max(val, curr_sum + val)
        max_sum = max(max_sum, curr_sum)
    
    return max_sum

t = int(input())
for _ in range(t):
    s = input().strip()
    print(max_removed(s))
```该解决方案计算每个字符的总数，确定少数，并使用简单的转换来应用 Kadane 算法。 边界条件（例如长度为 1 的字符串或具有相同数量“0”和“1”的字符串）会被显式处理。 Kadane 循环确保我们正确跟踪最大连续段，避免差一错误。
