 ## 解决方案
 ## 问题理解

 我们有两条河岸，用字符串表示`a`和`b`。 位置`i`在第一银行是为由命名的小队保留的`a[i]`，和位置`j`在第二个银行是为命名的小队保留的`b[j]`。 桥梁可以连接位置`i`和`j`仅当两个字母相等时。 

桥梁不得交叉。 如果一座桥连接`(i1, j1)`另一个连接`(i2, j2)`，然后，在对第一银行头寸进行排序后，使得`i1 < i2`，我们还必须有`j1 < j2`。 两座顺序相反的桥将在几何上交叉。 任务是在保持此顺序的同时最大化可以选择的相等字母对的数量。 原始约束允许两个字符串的长度最多为 1000。 

这个排序条件是整个问题的关键。 中选定位置的序列`a`以及相应的序列`b`形成两个子序列，并且每个选定的子序列都有相同的字母。 换句话说，桥形成两个字符串的公共子序列。 因此，答案是它们的最长公共子序列（LCS）的长度。 

1000 的限制足够大，足以排除枚举子集或尝试每个可能的桥集合的算法，但又足够小，适合二次动态规划。 一个`O(nm)`当两个字符串的长度都为 1000 时，算法最多执行一百万次状态转换，这在给定的限制下是合适的。 指数算法，例如`O(2^n)`已经不可能了`n = 1000`。 

在某些情况下，直观的实现可能会出错。 如果字符串具有完全不同的字符，例如`a = "a"`和`b = "b"`，答案是`0`。 粗心的实现对常见字母进行计数而不考虑它们的实际位置可能仍然会报告匹配。 

重复的字符也需要小心。 为了`a = "aa"`和`b = "aa"`，答案是`2`，因为两对都可以不交叉地连接。 将相同的字母视为只能使用一次会错误地返回`1`。 

即使两个字符串中都出现许多字母，顺序也很重要。 为了`a = "abca"`和`b = "acba"`，答案是`3`，使用公共子序列`"aca"`。 匹配第一个的贪心算法`a`，然后立即获取第一个可用的`b`, 只得到`2`并错过了更好的选择。 

## 方法

 最直接的暴力方法是考虑位置的每个子集`a`。 每个子集定义一个子序列`a`，我们可以检查该子序列是否出现在`b`同时维护秩序。 在所有公共子序列中，我们保留最大的一个。 这是正确的，因为每一组合法的非交叉桥都精确对应于一个公共子序列。 

有`2^n`的子集`n`- 字符串。 如果检查一个子序列`b`需要`O(m)`时间，最坏情况的工作是`O(m * 2^n)`。 和`n = m = 1000`，这取决于`1000 * 2^1000`字符级的操作，远远超出了极限。 

蛮力方法之所以有效，是因为它明确地探索了每一个合法有序的选择。 当可能的选择数量变得巨大时，它就会失败。 解锁更快解决方案的观察结果是，许多不同的部分选择具有完全相同的未来可能性。 一旦我们知道使用两个字符串的前缀可以形成多少个桥，我们就不需要记住产生该值的确切桥。 

定义`dp[i][j]`作为仅使用第一个可以建造的非交叉桥梁的最大数量`i`的职位`a`和第一个`j`的职位`b`。 考虑这些前缀的最后位置。 

如果`a[i - 1] == b[j - 1]`，我们可以连接这两个位置并获得`dp[i - 1][j - 1] + 1`。 我们也可以选择不使用这些位置之一，给出`dp[i - 1][j]`或者`dp[i][j - 1]`。 因此，`dp[i][j] = max(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1] + 1)`当字符匹配时。 

当它们不同时，最后两个位置不能直接连接，因此必须排除其中之一：`dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])`。 

这是标准的 LCS 递归，但在这里它的几何意义特别有用：选择匹配的字符会创建一座新桥，而移动到更小的前缀意味着留下一个未使用的河岸位置。 

因为每个状态只依赖于前一行和当前行，所以我们可以减少内存`O(nm)`到`O(m)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |`O(m * 2^n)`|`O(n)`| 太慢了 |
 | 最佳濒海战斗舰DP |`O(nm)`|`O(m)`| 已接受 |

 ## 算法演练

 1.读取两个字符串并设其长度为`n`和`m`。 每个字符串中的位置已经给出了沿相应河岸的顺序。 
2.创建长度为DP的行`m + 1`，最初用零填充。`dp[j]`表示迄今为止处理的第一个字符串部分和第一个字符串的最佳答案`j`第二个字符串的位置。 
3. 处理字符`a`从左到右。 对于每个新字符，创建一个新行，其第一个值为零，因为空前缀`b`不能包含任何桥。 
4. 对于每个位置`j`在`b`,比较当前字符`a[i - 1]`和`b[j - 1]`。 如果相等，则连接这两个位置是合法的，并且可以将桥添加到前面两个前缀的最优解中。 候选值为`dp[j - 1] + 1`。 
5. 无论字符是否匹配，也要考虑从任一存储体中跳过当前位置。 这些选择给出了前一行的值`dp[j]`和当前行左值`new_dp[j - 1]`。 
6. 将这些候选者中的最大值存储在`new_dp[j]`，然后在完成当前位置后用新行替换旧行`a`。 
7、处理完所有字符后，最后的DP值就是可以建立的最大不交叉桥的数量。 返回`dp[m]`。 

### 为什么它有效

 不变量是在处理完第一个之后`i`的字符`a`,`dp[j]`正是使用这些的非交叉桥的最大数量`i`字符和第一个`j`的字符`b`。 每个法律解决方案要么不使用最后两个位置中的一个，要么当他们的信件同意时，将它们用作最后​​的桥梁。 递归考虑了所有三种可能性，因此它不能丢弃最优解。 由于每次转换都保留了两家银行不断增加的头寸，因此 DP 构建的每个值都对应于一个合法的非交叉桥集。 最后，两个完整字符串的状态正是所需的最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b = input().split()

    # Keep the DP dimension small.
    if len(b) > len(a):
        a, b = b, a

    m = len(b)
    dp = [0] * (m + 1)

    for ca in a:
        new_dp = [0] * (m + 1)

        for j in range(1, m + 1):
            if ca == b[j - 1]:
                new_dp[j] = dp[j - 1] + 1
            else:
                new_dp[j] = max(dp[j], new_dp[j - 1])

            # Even when the characters match, skipping either position
            # may be better than using this particular matching pair.
            if dp[j] > new_dp[j]:
                new_dp[j] = dp[j]
            if new_dp[j - 1] > new_dp[j]:
                new_dp[j] = new_dp[j - 1]

        dp = new_dp

    print(dp[m])

if __name__ == "__main__":
    solve()
```开头的可选交换使得`b`较短的字符串。 两个字符串的递归是对称的，因此这不会改变答案。 它只会减少每个 DP 行的大小，从而减少内存使用量。`dp[j]`是前一行的值，而`new_dp[j - 1]`是当前行中紧邻左侧的值。 当字符匹配时，`dp[j - 1] + 1`代表采用新桥。 该代码仍然将其与两种跳过位置的方法进行比较，因为匹配当前两个字符不一定是最佳 LCS 的一部分。 

第一次赋值后的显式检查比编写单个嵌套稍微详细一些`max`，但它们使三种可能的转变变得可见。 他们还避免了匹配案例盲目使用的常见错误`dp[j - 1] + 1`即使不同的选择会产生更长的结果。 

Python 中不存在整数溢出问题。 答案永远不能超过较短字符串的长度，最多为 1000。`m + 1`索引为 DP 提供了一个干净的零列，因此位置`1`通过`m`直接对应字符`b[0]`通过`b[m - 1]`。

 ## 边缘情况

 对于完全不同的字符，输入`a b`产生单个 DP 比较。 自从`a != b`，两个位置都不能配对，结果保持不变`0`。 这捕获了计算位置数量而不是实际匹配字符的实现。 

对于重复的字符，`aaa aa`从零行开始并处理每一行`a`。 第一个`a`提出答案`1`，第二个`a`将其提高到`2`。 第三个字符在第二个银行上没有剩余位置，因此答案保持不变`2`。 该算法正确地重用不同的出现，而不是将字符本身视为只能使用一次。 

对于顺序敏感的情况，`abca acba`通过子序列有三个可用的匹配桥`"aca"`。 贪心方法，取第一个`a`，那么第一个可能的`b`，消耗有用的排序并仅获得两个桥。 民主党通过不同的州保持这两种可能性，最终达到`3`。 

对于最大边界，两个字符串由 1000 个副本组成`a`生产`1000`。 较短一侧的每个位置都可以匹配，并且 DP 为每个处理的位置增加一个额外的桥，直到达到 1000 个。二次工作正好约为一百万个状态转换，这是约束的预期规模。
