 ## 解决方案
 ## 问题理解

 我们给定两个正整数，`a`和`b`。 首先我们计算它们的正常总和`c = a + b`。 然后我们对所有三个数字应用相同的转换：删除每个数字`0`从他们的十进制表示形式。 

问题是变换后的方程是否仍然成立。 换句话说，删除所有零后`a`,`b`， 和`c`，我们还有：`remove_zero(a) + remove_zero(b) = remove_zero(c)`？ 

输入由两个整数组成`a`和`b`。 输出是`"YES"`如果删除零后等式仍然成立，否则`"NO"`。 

限制非常小。 两个数最多都是`10^9`，这意味着每个数字最多有 10 位数字。 任何一位一位处理数字的操作实际上都是恒定时间。 即使多次将数字转换为字符串在这里也是微不足道的。 这立即告诉我们问题不在于优化，而在于正确实施转换。 

错误的主要原因是不小心处理除零步骤。 

当转换后的数字变空时，就会出现一个简单的错误。 考虑：```
a = 1000
b = 9000
```去掉零后：```
a -> 1
b -> 9
c = 10000 -> 1
```如果数字全为零，尝试解析空字符串的粗心实现可能会崩溃。 在这个问题中，原始输入是正值且非零，但中间处理仍然需要稳健。 

另一个常见错误是仅删除前导零而不是全部零。 例如：```
a = 105
b = 106
```正确的变换：```
105 -> 15
106 -> 16
211 -> 211
```自从`15 + 16 != 211`，答案是`"NO"`。 

如果有人只去掉前导零，他们会错误地保留`105`和`106`不变。 

一个更微妙的问题来自于比较字符串而不是整数。 考虑：```
a = 500
b = 500
```去掉零后：```
500 -> 5
500 -> 5
1000 -> 1
```我们得到：```
5 + 5 = 10
1 != 10
```答案是`"NO"`。 

比较必须在转换后进行数值比较。 

## 方法

 最直接的暴力想法就是准确地模拟语句所描述的内容。 计算`c = a + b`，将所有三个数字转换为字符串，删除每个`'0'`字符，将结果转换回整数，最后比较转换后的方程。 

因为每个数字最多有 10 位数字，所以这已经在恒定时间内运行。 即使我们精确地计算操作数，我们总共也只扫描了几十个字符。 

这里没有有意义的较慢方法，但更尴尬的实现可以使用算术逐位重建数字。 例如，反复采取`% 10`，跳过零，并重建答案。 这也可以正常工作，但实施变得更容易出错，因为数字以相反的顺序到达。 

关键的观察是转换自然是一个字符串操作。 从十进制表示中删除所有零正是字符串替换的目的。 一旦我们意识到约束很小并且操作是文本的，最干净的解决方案就变得显而易见。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 逐位算术重构 | O(d) | O(1) | O(1) | 已接受 |
 | 字符串转换 | O(d) | O(d) | 已接受 |

 这里，`d`是位数，最多 10。 

## 算法演练

 1. 读取整数`a`和`b`。 

我们需要两个原始值，因为转换后的等式取决于原始总和。 
2. 计算`c = a + b`。 

问题定义了`c`这样，我们就必须对实际的和进行变换，而不是去掉零后重新计算。 
3. 创建一个辅助函数来删除所有`'0'`数字的十进制表示形式中的字符。 

将数字转为字符串，全部替换`'0'`包含空字符串的字符，然后将结果转换回整数。 
4. 将变换应用到`a`,`b`， 和`c`。 

令这些值为`na`,`nb`， 和`nc`。 
5. 检查是否`na + nb == nc`。 

如果为真，则打印`"YES"`，否则打印`"NO"`。 

### 为什么它有效

 该算法直接遵循问题的定义。 辅助函数准确地生成从十进制表示中删除每个零数字后获得的数字。 由于我们独立地应用相同的变换`a`,`b`， 和`a + b`，最终比较完全符合要求的条件。 不涉及近似或捷径，因此该算法不会产生错误的结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def remove_zeros(x):
    return int(str(x).replace('0', ''))

def solve():
    a = int(input())
    b = int(input())

    c = a + b

    na = remove_zeros(a)
    nb = remove_zeros(b)
    nc = remove_zeros(c)

    if na + nb == nc:
        print("YES")
    else:
        print("NO")

solve()
```辅助函数在一行中处理整个转换。 转换为字符串允许我们直接删除每个零`replace('0', '')`。 转换回整数给出比较所需的数值。 

操作顺序很重要。 我们必须首先计算`c = a + b`使用原始数字。 只有在那之后我们才删除零。 计算转换后的总和将解决不同的问题。 

该实现保持安全，因为原始输入是正整数，并且在删除零之后总是至少剩下一个非零数字。 例如，`1000`变成`"1"`，不是空字符串。
