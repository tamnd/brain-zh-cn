 ## 解决方案
 ## 问题理解

 我们得到一个正整数数组和许多区间查询。 对于每个查询`[l, r]`，我们只查看这些索引之间的子数组并计算一个称为其幂的值。 

如果一个数字`x`出现`k`次在子数组内，然后`x`贡献`k² * x`到答案。 最终结果是区间内所有不同值的这些贡献的总和。 

例如，在子数组中`[1, 2, 1, 1, 2]`，值`1`出现`3`时间和贡献`3² * 1 = 9`。 价值`2`出现`2`时间和贡献`2² * 2 = 8`。 总计为`17`。 

数组长度和查询次数均达到`200000`。 独立处理每个查询的简单解决方案立刻就太慢了。 即使每个查询迭代一个完整的子数组也已经花费了`O(n * q)`在最坏的情况下，这大约变成`4 * 10^10`运营。 这比 5 秒内所能容纳的内容高出几个数量级。 

价值观本身最多是`10^6`，对于按值索引的频率数组来说足够小。 一旦我们以更智能的顺序处理查询，这种观察就变得非常有用。 

一个微妙的细节是答案可能会变大。 假设所有`200000`元素等于`10^6`。 那么贡献就是：$$(200000)^2 \cdot 10^6 = 4 \cdot 10^{16}$$这不适合 32 位整数，因此实现必须使用 64 位算术。 

另一个容易犯的错误是当频率变化时错误地更新贡献。 考虑数组：```
[5, 5]
```对于间隔`[1, 2]`，正确答案是：```
2² * 5 = 20
```如果我们已经有一个`5`在当前间隔中，添加另一个`5`并不仅仅增加答案`5`。 贡献变化自：```
1² * 5 = 5
```到```
2² * 5 = 20
```所以增量实际上是`15`。 

最后一个常见错误出现在间隔边界处。 假设当前间隔为`[2, 4]`下一个查询是`[3, 4]`。 如果我们在移动指针后删除左端点，我们会意外地在窗口内保留一个额外的元素。 指针移动的顺序和更新频率必须与预期的间隔完全匹配。 

## 方法

 暴力方法独立处理每个查询。 对于每个间隔`[l, r]`，我们计算子数组内的频率并计算：$$\sum cnt[x]^2 \cdot x$$哈希图或频率数组使计数变得简单。 该方法是正确的，因为它直接遵循功率的定义。 

问题是总工作量。 单个查询可能跨越整个数组，需要`O(n)`运营。 和`200000`查询，总复杂度变为`O(nq)`，太大了。 

关键的观察结果是相邻查询经常严重重叠。 如果两个区间仅相差几个元素，则重新计算整个答案几乎会浪费之前所有的工作。 

这种结构正是 Mo 算法所利用的。 

我们不是按输入顺序回答查询，而是对它们进行排序，以便连续的查询具有相似的范围。 然后我们维持一个当前的间隔并逐渐调整它。 当间隔扩大或缩小一个元素时，我们会在常数时间内更新答案。 

假设当前频率值`x`是`f`。 

在添加另一个之前`x`，其贡献为：$$f^2 \cdot x$$添加后，贡献度变为：$$(f+1)^2 \cdot x$$增加量为：$$((f+1)^2 - f^2) \cdot x = (2f+1)\cdot x$$我们可以立即更新答案，而无需重新计算其他任何内容。 

删除元素的工作原理类似：$$f^2 \cdot x - (f-1)^2 \cdot x = (2f-1)\cdot x$$由于每次指针移动都会花费`O(1)`，总复杂度大约变为`O((n + q)\sqrt n)`，这对于约束来说足够快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(nq) | O(最大(a)) | 太慢了 |
 | 最优，Mo 算法 | O((n + q)√n) | O((n + q)√n) | O(max(a) + q) | 已接受 |

 ## 算法演练

 1. 读取数组和所有查询。 
2. 将查询转换为从零开始的索引，因为 Python 列表使用从零开始的位置。 
3. 选择块大小，通常`int(sqrt(n))`。 
4. 对查询进行排序：

 首先，包含左端点的块，

 第二，右端点。 

这种排序最大限度地减少了间隔指针在连续查询之间移动的距离。 
5. 保持当前间隔`[cur_l, cur_r]`及其当前功率值。 

最初该间隔是空的。 
6. 维护频率数组`freq[x]`存储多少次值`x`出现在当前间隔内。 
7. 定义一个`add(x)`手术。 

如果当前频率为`f`， 然后：$$answer -= f^2 \cdot x$$增加频率，$$answer += (f+1)^2 \cdot x$$这仅更新受影响值的贡献。 
8. 定义一个`remove(x)`操作类似。 

如果当前频率为`f`，删除旧的贡献，减少频率，然后添加新的贡献。 
9. 按排序顺序处理查询。 

移动`cur_l`和`cur_r`直到维护的间隔与目标查询间隔完全匹配。 
10. 一旦间隔匹配，就使用查询的原始索引将当前答案存储在结果数组中。 
11. 处理完所有查询后，按输入顺序打印答案。 

### 为什么它有效

 在每一个时刻，维护的间隔都与当前的查询范围完全匹配。 频率数组始终存储该间隔内每个值的真实出现次数。 

答案变量等于：$$\sum freq[x]^2 \cdot x$$因为每次添加或删除操作都会更新一个值的贡献，同时保持所有其他值不变。 

由于 Mo 的排序保证通过一系列有效的区间扩展和收缩来达到每个查询，因此当查询得到答复时，维护的状态始终是正确的。 

## Python 解决方案```python
import sys
from math import sqrt

input = sys.stdin.readline

def solve():
    n, q = map(int, input().split())
    arr = list(map(int, input().split()))

    queries = []

    for idx in range(q):
        l, r = map(int, input().split())
        l -= 1
        r -= 1
        queries.append((l, r, idx))

    block_size = int(sqrt(n)) + 1

    queries.sort(
        key=lambda x: (
            x[0] // block_size,
            x[1]
        )
    )

    freq = [0] * (10**6 + 1)
    answers = [0] * q

    current_answer = 0
    cur_l = 0
    cur_r = -1

    def add(value):
        nonlocal current_answer

        f = freq[value]
        current_answer -= f * f * value

        freq[value] += 1
        f += 1

        current_answer += f * f * value

    def remove(value):
        nonlocal current_answer

        f = freq[value]
        current_answer -= f * f * value

        freq[value] -= 1
        f -= 1

        current_answer += f * f * value

    for l, r, idx in queries:

        while cur_l > l:
            cur_l -= 1
            add(arr[cur_l])

        while cur_r < r:
            cur_r += 1
            add(arr[cur_r])

        while cur_l < l:
            remove(arr[cur_l])
            cur_l += 1

        while cur_r > r:
            remove(arr[cur_r])
            cur_r -= 1

        answers[idx] = current_answer

    print("\n".join(map(str, answers)))

solve()
```该解决方案首先读取所有查询并附加其原始索引。 在对 Mo 算法的查询进行排序后，我们不再按输入顺序处理它们，因此我们必须记住每个答案所属的位置。 

当前间隔开始为空`[0, -1]`。 这种表示避免了特殊情况，因为添加第一个元素只是递增`cur_r`。 

频率数组有大小`10^6 + 1`因为数组值的边界是`10^6`。 对于这个问题，使用列表比字典快得多。 

这`add`和`remove`功能是实现的核心。 一个常见的错误是在减去旧贡献之前更新频率。 代码首先删除了旧术语`f² * value`，更改频率，然后添加更新的项。 

指针移动的顺序也很重要。 当从左边收缩时，我们在递增之前删除当前左边的元素`cur_l`。 颠倒该顺序将删除错误的值。 

所有算术都使用 Python 整数，它会自动安全地处理大值。

 ## 边缘情况

 考虑最小可能的间隔：```
1 1
9
1 1
```该区间包含一次出现`9`，所以答案是：```
1² * 9 = 9
```该算法从一个空区间开始，只添加一个元素。 频率变为`1`，并且保留的答案变为`9`。 

现在考虑所有值都相等：```
5 1
3 3 3 3 3
1 5
```正确答案是：```
5² * 3 = 75
```随着元素的添加，贡献不断变化：```
1²*3 = 3
2²*3 = 12
3²*3 = 27
4²*3 = 48
5²*3 = 75
```更新公式正确地捕捉了非线性增长。 

最后，考虑缩小间隔：```
4 2
1 2 1 2
1 4
2 3
```第一个区间有频率`{1:2, 2:2}`并回答：```
4 + 8 = 12
```当搬到`[2,3]`，算法删除左边`1`和对的`2`。 

去掉左边后`1`:```
{1:1, 2:2}
1 + 8 = 9
```去掉右边后`2`:```
{1:1, 2:1}
1 + 2 = 3
```最终答案是正确的，因为在频率进一步改变之前，移除总是会更新贡献。
