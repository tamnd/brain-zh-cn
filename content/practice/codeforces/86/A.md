 ## 解决方案
 ## 问题理解

 我们有两个整数，`l`和`r`。 对于每个数字`n`在这个区间内，我们构建另一个数字，称为它的反射。 

反射是逐位创建的。 每个小数位`d`变成`9 - d`。 例如：

-`192 → 807`-`10 → 89`-`91 → 08 → 8`一个数的权重为：$$n \cdot \psi(n)$$在哪里$\psi(n)$是的反映`n`。 

任务是找到范围内所有整数中最大可能的权重`[l, r]`。 

范围可达$10^9$。 对每个数字进行强力扫描会立即变得可疑，因为间隔本身可能包含近十亿个值。 即使计算反射只需要几次操作，迭代$10^9$候选人不符合 2 秒的限制。 

关键的困难在于反射依赖于每个数字独立，因此乘积不是单调的。 较大的数字不一定会赋予较大的权重。 

有几种容易被忽略的边缘情况。 

考虑范围：```
8 10
```权重为：

 -`8 * 1 = 8`-`9 * 0 = 0`-`10 * 89 = 890`从一位数字长度过渡到另一位数字长度时，最大值会急剧跳跃。 诸如“答案接近 r”之类的天真的假设在这里失败了。 

另一个危险的情况是以许多结尾的数字`9`s:```
99 → 0
999 → 0
```他们的反射崩溃为零，因为所有数字都变成了`0`。 将前导零保留为十进制数字的粗心实现可能会错误地对待`"00"`作为一个有意义的两位数。 

对于固定位数，在有效范围的中间还存在结构性边缘情况。 对于两位数：

 | n | ψ(n) | 产品 |
 | --- | --- | --- |
 | 40 | 40 59 | 59 2360 | 2360
 | 44 | 44 55 | 55 2420 | 2420
 | 49 | 49 50 | 50 2450 | 2450
 | 50 | 50 49 | 49 2450 | 2450
 | 55 | 55 44 | 44 2420 | 2420

 最大值出现在中心周围，而不是出现在任一端点。 了解这种形状是解决方案的核心。 

## 方法

 最直接的解决方案是迭代每个整数`l`到`r`，计算其反射，将两个值相乘，并保留最大值。 

计算反射很容易。 如果一个数字是`d`，其反映数字为`9 - d`。 我们可以将数字作为字符串处理，也可以通过数学方式逐位处理。 

这种暴力方法是正确的，因为它明确地检查每个候选者。 问题在于候选人的数量。 在最坏的情况下，间隔长度接近于$10^9$。 即使每个数字只有几次算术运算，这也是远远不可行的。 

转折点来自于用代数重写反射。 

认为`n`正好有`k`数字。 让：$$M = 10^k - 1$$这是完全由以下组成的数字`9`s 与长度`k`。 

例如：

-`k = 2 → M = 99`-`k = 3 → M = 999`独立反映每个数字与以下完全相同：$$\psi(n) = M - n$$例子：$$192 \rightarrow 999 - 192 = 807$$所以权重就变成了：$$f(n)=n(M-n)$$展开给出：$$f(n) = -n^2 + Mn$$这是开口向下的二次抛物线。 其最大值出现在：$$n = \frac{M}{2}$$这改变了整个问题。 我们不需要搜索数十亿个值，而只需检查抛物线峰值附近的数字。 

有一个并发症。 该公式仅适用于位数相同的数字。 当位数发生变化时，`M`也发生变化。 自从`r ≤ 10^9`，最多有 10 个不同的数字长度需要考虑。 

对于每个数字长度：

 - 确定与的有效交集`[l, r]`- 计算中点$M/2$- 检查间隔内该中点附近最接近的整数

 因为二次方程在中心达到最大值，所以只需要恒定数量的候选。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(r - l + 1) | O(1) | O(1) | 太慢了 |
 | 最佳| O(位数) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 迭代每个可能的数字长度`k`从 1 到 10。 

自从`r ≤ 10^9`，仅存在少数数字长度。 
2. 对于当前数字长度，计算：$$M = 10^k - 1$$这是该长度的全 9 号码。 

1. 计算有效区间`k`- 也位于里面的数字`[l, r]`。 

最小的`k`- 位数为：$$10^{k-1}$$除了`k = 1`，其中最小值是`1`。 

最大`k`- 位数为：$$10^k - 1$$1. 将此数字长度间隔与`[l, r]`。 

如果交集为空，则跳过该数字长度。 
2. 该数字长度的函数为：$$f(n)=n(M-n)$$由于这是一条向下的抛物线，最大值出现在以下位置附近：$$\frac{M}{2}$$1.设：$$x = \left\lfloor \frac{M}{2} \right\rfloor$$最佳候选整数必须是`x`或者`x + 1`。 

1. 将这些候选值限制在该数字长度的有效区间内。 

还要检查间隔边界，因为中点可能位于间隔之外。 
2. 评估所有收集到的候选产品并保留全局最大值。 

### 为什么它有效

 对于固定数字长度`k`，每个数满足：$$\psi(n)=M-n$$在哪里$M=10^k-1$。 权重函数变为：$$f(n)=n(M-n)$$这是一个凹二次方程。 凹二次函数在其顶点处达到最大值，位于$M/2$。 由于我们只关心有界区间内的整数，因此最优值必须是最接近顶点的整数之一，或者如果顶点位于区间之外，则最优值必须是区间边界之一。 

我们独立地最大化每个数字的长度，以及每个数字`[l, r]`恰好属于一位数字长度的组。 在所有组中取最好的给出全局最优值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def reflection(x):
    s = str(x)
    t = ''.join(str(9 - int(c)) for c in s)
    return int(t)

def weight(x):
    return x * reflection(x)

l, r = map(int, input().split())

ans = 0

for k in range(1, 11):
    low = 1 if k == 1 else 10 ** (k - 1)
    high = 10 ** k - 1

    L = max(l, low)
    R = min(r, high)

    if L > R:
        continue

    M = high
    mid = M // 2

    candidates = {L, R}

    for x in [mid, mid + 1]:
        if L <= x <= R:
            candidates.add(x)

    for x in candidates:
        ans = max(ans, weight(x))

print(ans)
```该解决方案按数字长度对数字进行分组，因为反射公式取决于数字的位数。 

对于固定的数字长度，反射相当于从该长度的全 9 数字中减去。 为了清晰和安全，代码仍然直接计算反射。 由于仅评估恒定数量的候选人，因此效率不受影响。 

中点计算很微妙。 二次最大值出现在`M / 2`， 但`M`对于每个全 9 的数字都是奇数。 这意味着真正的最大值相等地位于两个整数之间。 我们必须检查两者`mid`和`mid + 1`。 

候选集还包括区间边界。 如果抛物线峰值位于该数字长度的有效范围之外，则该区间的最大值出现在最近的边界处。 

Python 整数自动安全地处理大型产品。 在 C++ 中，这需要 64 位整数，因为答案可能超过`2^31`。

 ## 边缘情况

 考虑输入：```
9 9
```反射：$$\psi(9)=0$$重量：$$9 \cdot 0 = 0$$该算法自然地处理这个问题。 对于一位数：$$M=9$$和：$$9(9-9)=0$$不需要对前导零进行特殊处理，因为整数转换会自动删除它们。 

现在考虑：```
8 10
```一位数的中点约为`4`，位于外面`[8,9]`。 该算法正确地回退到检查间隔边界。 

对于两位数，唯一有效的候选者是`10`，其反射变为`89`。 答案跳转自`8`到`890`。 

另一个重要的边缘情况是：```
50 50
```对于两位数：$$M=99$$反射：$$99-50=49$$重量：$$50 \cdot 49=2450$$抛物线的中点位于`49`和`50`，因此两者产生相同的最优值。 检查两者`mid`和`mid+1`保证奇数的正确性`M`。 

最后，考虑：```
999999999 1000000000
```为了`999999999`:$$\psi=0$$重量为零。 

为了`1000000000`:$$\psi=8999999999$$重量变得非常大。 

该算法独立处理两个数字长度，并正确识别 10 位数字间隔中较大的结果。
