 ## 解决方案
 ## 问题理解

 我们得到一个整数的闭区间`l`到`r`，我们需要找到这个区间内的任何数字，其十进制表示形式不重复任何数字。 换句话说，当将数字写为数字字符串时，每个字符都必须是唯一的。 

任务不是针对最小或最大值之类的东西进行优化。 该范围内的任何有效数字都是可接受的，因此只要能够可靠地找到一个这样的数字（如果存在），解决方案的结构就可以很简单。 

约束条件`r ≤ 100000`足够小，甚至检查区间中的每个数字都是可行的。 区间大小最多为`10^5`，对于每个数字，我们最多只检查 6 位数字。 这导致大约`6 * 10^5`最坏情况下的操作，对于 Python 来说完全在时间限制之内。 

当人们试图贪婪地构建一个数字或假设一种模式（例如总是选择）时，经常会出现幼稚的错误`l`如果它有效，或者尝试“修复”重复的数字。 这些方法可能会失败，因为数字唯一性是全球属性。 例如，`121`失败不是因为本地问题而是因为数字`1`出现在两个不同的位置。 

另一个微妙的边缘情况是区间中没有有效数字。 例如，`l = 110`和`r = 120`只包含像这样的数字`110, 111, 112 ...`，全部重复数字。 在这种情况下，正确的输出是`-1`。 

最后，单位数字总是满足条件，因为一开始只有一位数字。 任何实现都必须处理从`1`正确。 

## 方法

 最直接的想法就是迭代每一个整数`x`从`l`到`r`并检查其数字是否全部不同。 检查数字很简单：将其转换为字符串并验证没有字符出现多次，通常使用集合。 

这种蛮力方法之所以有效，是因为输入大小很小。 在最坏的情况下，我们检查`100000`数字，每张支票最多扫描 6 位数字。 这给出了有界的、小的常数因子工作负载。 

关键的观察结果是没有隐藏的结构可供利用。 该约束是有意设计的，以便暴力破解成为预期的解决方案。 任何组合构建数字或跳过范围的尝试都是不必要的。 

因此，我们将问题简化为扫描间隔并验证每个候选者。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((r - l + 1) * d) | O(1) | O(1) | 已接受 |
 | 最佳 | O((r - l + 1) * d) | O(1) | O(1) | 已接受 |

 这里`d ≤ 6`是每个数字的位数。 

## 算法演练

 1. 迭代每个整数`x`从`l`到`r`。 我们这样做是因为任何有效答案都必须位于这个范围内，并且没有允许安全地跳过候选的结构。 
2. 对于每个`x`，将其转换为字符串表示形式。 这使我们能够将数字视为字符并简化唯一性检查。 
3. 检查字符串中的所有数字是否不同。 我们维护一组并在扫描时插入每个数字。 如果我们看到集合中已有数字，我们会立即拒绝该数字。 
4. 如果数字通过唯一性检查，则立即输出并终止。 这是有效的，因为任何解决方案都是可以接受的。 
5. 如果循环结束没有找到任何有效数字，则输出`-1`。 

### 为什么它有效

 每个候选数字都针对所需的属性进行独立验证，并且间隔中的每个数字都被检查一次。 由于检查是准确的并且没有应用任何转换，因此不能跳过任何有效的候选者。 该算法不能错误地接受无效数字，因为使用集合成员资格测试显式检测到重复。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    l, r = map(int, input().split())
    
    for x in range(l, r + 1):
        s = str(x)
        seen = set()
        ok = True
        for ch in s:
            if ch in seen:
                ok = False
                break
            seen.add(ch)
        if ok:
            print(x)
            return
    
    print(-1)

if __name__ == "__main__":
    solve()
```核心循环直接实现了暴力扫描。 到字符串的转换仅用于数字提取，并且该集合确保恒定时间的重复检测。 尽早退出很重要，因为一旦找到有效号码，就无需进一步搜索。 

唯一需要注意的边界条件是包含范围`r + 1`在 Python 中`range`，这确保端点被检查。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O((r - l + 1) * d) | 我们扫描区间内的每个数字并检查每个数字一次 |

 最大迭代次数为`10^5`，并且每次迭代最多处理 6 位数字，因此该解决方案可以轻松满足时间和内存限制。

import sys, io

def solve():
    l, r = map(int, input().split())
    for x in range(l, r + 1):
        s = str(x)
        seen = set()
        ok = True
        for ch in s:
            if ch in seen:
                ok = False
                break
            seen.add(ch)
        if ok:
            print(x)
            return

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    old_stdout = sys.stdout
    sys.stdout = io.StringIO()
    
    solve()
    
    out = sys.stdout.getvalue().strip()
    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return out

# provided sample
assert run("121 130") == "123"

# custom cases
assert run("1 9") == "1", "single digit always valid"
assert run("11 11") == "-1", "all digits repeated"
assert run("98 102") in ["98", "102"], "cross boundary behavior"
assert run("123 123") == "123", "already valid single value"

 ## 边缘情况

 对于像这样的单值范围`11 11`，算法仅检查该数字，检测重复的数字`1`，并正确输出`-1`。 

对于第一个数字有效的范围，例如`1 9`，算法立即接受`1`并停止，表明提前终止可以防止不必要的扫描。 

对于边界转换，例如`98 102`，该算法可以正确处理不同的数字长度，无需任何特殊的大小写，因为所有数字都被统一视为字符串。 

对于所有候选人都无效的退化情况，例如`110 115`，每次迭代都无法通过唯一性检查，并且算法正确地耗尽循环并返回`-1`。
