 ## 解决方案
 ## 问题理解

 我们给出了一个尺寸的网格\(h \times w\)，最初完全是空的，以及两组约束，描述填充单元块必须从顶部和左侧延伸多远。 

对于每一行\(i\)，值\(r_i\)告诉我们第一个\(r_i\)该行中的单元格已填充，紧接着该行的单元格（如果存在）为空。 所以排\(i\)被迫看起来像填充单元格的前缀，后跟空单元格。 

对于每一列\(j\)，值\(c_j\)同样告诉我们，第一个\(c_j\)该列顶部的单元格已填充，而该列下方的下一个单元格（如果存在）为空。 

任务不是构造一个网格，而是计算有多少个不同的网格同时满足行约束和列约束，取模\(10^9+7\)。 

限制因素\(h, w \le 1000\)暗示直到\(10^6\)细胞。 需要一种检查每个单元一次或对行和列执行线性扫描的解决方案。 任何独立于行和列的二次方仍然会通过，但任何基于子集的指数或基于状态的 DP 是不可能的。 

一个关键的微妙之处在于这些约束并不能完全确定网格。 一些单元格可以保持不受约束并且可以自由选择，但前提是它们不违反由行和列引起的前缀结构。 

当行和列约束以微妙的方式矛盾时，就会出现常见的失败情况。 例如，如果某列需要在该行已强制为空的位置下方填充一个单元格，则该配置将变得无效，并且答案必须为零。 

另一个边缘情况是当\(r_i = 0\)或者\(c_j = 0\)。 这些强制整个行或列以空单元格开始，并且任何“空意味着不受约束”的天真假设都会被打破。 

## 方法

 暴力方法会尝试将每个单元格分配为已填充或为空，然后验证所有行和列前缀条件是否成立。 每次检查都需要\(O(hw)\)，并且有\(2^{hw}\)配置，即使对于非常小的网格也是完全不可行的。 

我们需要利用约束是基于前缀的这一事实，这使得每行和列都是单调的。 关键的观察是将网格重新解释为填充区域和空白区域之间边界条件的集合，而不是独立的单元。 

对于每个单元格 \((i, j)\)，考虑它是强制的还是可选的。 如果单元格同时位于行前缀和列前缀内，则该单元格将被强制填充。 如果它以违反其中一个约束的方式位于行前缀和列前缀之外，则它被强制为空。 唯一的自由发生在与其中一个约束完全兼容但不能同时被两者固定的细胞中。 

问题归结为计算这些“空闲单元”中有多少个没有矛盾地存在。 每个这样的单元格都可以独立选择，为答案贡献 2 倍的系数。 如果任何单元格收到冲突的要求（必须同时填充和空），答案将变为 0。 

因此，解决方案变成了对所有单元的线性扫描，使用以下方法计算它们的强制状态\(r_i\)和\(c_j\)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力 | \(O(2^{hw} \cdot hw)\) | \(O(hw)\) | 太慢了 |
 | 最佳 | \(O(hw)\) | \(O(1)\) 额外 | 已接受 |

 ## 算法演练

 1. 对于每个单元格\((i, j)\)，判断它是否在其行的强制填充前缀之内，意思是\(j \le r_i\)。 这告诉我们行约束是否强制它为 1。 

2、对于同一个单元格，判断是否在其列的强制填充前缀之内，意思是\(i \le c_j\)。 这告诉我们列约束是否强制它为 1。 

3. 如果两个约束都同意该单元格必须被填充，我们将其标记为固定填充。 

4. 如果两个约束都同意单元格必须为空，我们将其标记为固定空。 

5. 如果一个约束强制它被填充而另一个约束它强制它为空，则配置是不可能的，所以我们立即返回0。 

6. 如果两个约束都不强制该单元格，则该单元格是自由的，并且可以独立选择填充或空，从而为答案提供乘法因子 2。 

7. 将答案乘以所有空闲单元的模\(10^9+7\)。 

其起作用的关键原因是行约束和列约束仅施加前缀条件，因此每个单元格的状态仅取决于其在行和列中的相对位置，并且除了矛盾之外不存在全局耦合。 

### 为什么它有效

 每个行约束固定填充单元格的连续前缀，每个列约束在垂直方向上执行相同的操作。 单元格完全取决于它是否位于这些前缀内。 任何有效的网格必须同时满足两个前缀系统，因此每个单元格都属于三个类别之一：强制填充、强制空或不受约束。 独立性适用于不受约束的单元，因为没有任何约束将它们的选择与任何其他不受约束的单元联系起来； 所有交互都已通过前缀边界解决。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    h, w = map(int, input().split())
    r = list(map(int, input().split()))
    c = list(map(int, input().split()))

    # grid is 1-indexed conceptually
    ans = 1

    for i in range(h):
        for j in range(w):
            row_fill = j < r[i]
            col_fill = i < c[j]

            if row_fill and not col_fill:
                return print(0)
            if col_fill and not row_fill:
                return print(0)

            if not row_fill and not col_fill:
                ans = (ans * 2) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该实现直接对每个单元的分类进行编码。 循环遍历所有内容\(h \cdot w\)位置并检查单元格是否位于行前缀和列前缀之内。 小心的部分是索引：Python 使用从 0 开始的索引，所以\(j < r[i]\)正确地建模“首先\(r_i\)行中的单元格\(i\)”。

 矛盾检查会立即返回，因为单个不可能的单元格会使整个网格无效。 

乘法仅适用于不受任一约束固定的单元格。

 | 测量 | 复杂性 | 说明|
 |---|---|---|
 | 时间 | \(O(hw)\) | 每个单元格都会根据行和列约束检查一次 |
 | 空间| \(O(1)\) | 仅存储输入数组和正在运行的产品 |

 网格尺寸可达\(10^6\)单元格，并且通过网格的单次传递很容易在限制范围内。 该解决方案避免了任何嵌套状态或组合枚举。

 ## 边缘情况

 当两者都存在时，就会出现临界边缘情况\(r_i\)和\(c_j\)暗示同一职位的要求相互冲突。 例如，如果\(r_2 = 0\)但\(c_1 \ge 2\)，则单元格 (2,1) 被行强制清空，但被列强制填充，从而立即触发失效。 

另一个边缘情况是当所有\(r_i = w\)和所有\(c_j = h\)。 每个单元都被两个方向强制填充，只留下一个有效的配置，算法会捕获该配置，因为没有单元贡献 2 倍的因子。 

最后，当所有值都为零时，每个单元格都不受行和列前缀的约束，因此每个单元格独立贡献，产生\(2^{hw}\)。
