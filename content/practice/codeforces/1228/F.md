 ## 解决方案
 ## 问题理解

 我们从高度完美的二叉树开始`n`，这意味着每个内部节点都有两个子节点，并且所有叶子节点都位于相同的深度。 这棵树恰好包含`2^n - 1`节点并且具有非常严格的递归结构：每个子树本身就是一个完美的二叉树。 

构建完这一理想结构后，一个顶点`v`被删除。 唯一允许的修复是本地的：`v`直接连接到所有孩子`v`，保持连通性。 如果`v`是一片叶子，没有任何东西被重新连接，所以我们只需删除一片叶子。 

我们得到了最后一棵缺少一个节点的树，并且这些重新连接已经隐式应用。 任务是确定这棵树是否来自这样的删除，如果是，则识别可能是已删除节点的父节点的所有可能顶点。 

约束意味着`n ≤ 17`，所以树的大小最多约为`1.3 × 10^5`节点。 任何节点数量接近二次方的解决方案都已经太慢了。 这促使我们对子树进行结构或递归推理，而不是显式地模拟删除。 

一个微妙的困难来自对称性。 在完美二叉树中，许多顶点占据结构上相同的位置。 删除节点后，多个不同的原始配置可能会导致相同的最终树。 尝试每个可能删除的节点并重建完整树的简单方法还需要验证结构，而重复执行时这会变得昂贵。 

另一个陷阱是假设仅用学位来表征有效性。 删除后，内部节点的度数可以为 3、2 或 1，具体取决于它们是否吸收已删除节点的子节点。 显然，最终树中的 2 度节点不一定是原始树的叶子节点或内部节点。 

## 方法

 暴力解释是假设已删除的节点`v`并尝试重建原来的完美二叉树。 对于每位候选人`v`，我们会在概念上附加一个新节点，适当分割边，并检查所得结构是否是高度完美的二叉树`n`。 验证完美性需要确保每个节点都遵循严格的子树大小规则，这会花费`O(N)`每张支票。 由于有`O(N)`候选人，这导致`O(N^2)`操作，这对于`N ≈ 10^5`。 

关键的见解是完美二叉树的结构完全由子树大小决定。 原始树中的每个节点都有一个子树大小，该大小是 2 减 1 的幂。 删除节点后，整个树中只有一个地方违反了此模式：被删除节点的父节点，其子树大小恰好减少一，以及可能被删除节点的子节点，其连接性在本地发生变化。 

这建议反转该过程：我们不是猜测被删除的节点，而是将每个候选节点视为被删除节点的父节点，并验证删除该父节点的一个子节点是否可以生成观察到的树。 一旦我们确定了候选家长`p`，该结构几乎变得确定性，因为每个其他节点仍然必须表现得像其自己的子树的完美二叉树根。 

这将问题简化为在单根假设下检查子树大小和邻接约束的一致性。 完美二叉树的全局刚性保证了一旦根固定，所有节点位置都是强制的，我们只需要验证是否恰好存在一个局部缺陷。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每个节点的暴力重建 | O(N^2) | O(N^2) | O(N) | 太慢了 |
 | 每位候选家长的结构验证 | O(N log N) 或 O(N) | O(N) | 已接受 |

 ## 算法演练

 我们利用这样一个事实：完美二叉树是由其根和高度唯一确定的。 缺失的节点恰好造成了一个局部结构不一致，并且其父节点是其邻域偏离完美二元行为的唯一顶点。 

我们测试每个节点`p`作为已移除顶点的潜在父级。 

1. 将给定树的任意节点作为根，并使用 DFS 计算父子关系和子树大小。 这仅适用于结构访问； 这棵树是无向的，但我们施加了方向。 
2.对于每个候选节点`p`，考虑它的哪个邻居可能是原始完美树中丢失的孩子。 由于在完美二叉树中，每个非叶子节点恰好有两个子节点，`p`最终树中最初的度数必须为 3：两条保留的边和一个被重新路由的“丢失的子连接”。 
3. 暂时解释每个邻居`p`as either a left or right child in the original tree and check whether the remaining structure splits into two perfect binary subtrees of appropriate heights. 缺失子树的子树必须准确地解释结构偏差。 
4. 对于每一个以邻居为根的子树，验证它是否形成完美二叉树。 这是通过检查子树大小来完成的：如果子树的大小为`2^k - 1`对于某个整数`k`，其内部结构是一致的。 
5. 候选人`p`如果缺少子级的恰好一种配置导致整个树的完全一致性，则该配置是有效的。 

关键的想法是，只有一个节点打破了严格的递归大小模式，并且该破坏以受控的方式向上传播。 每个其他节点仍必须满足其子树大小为 2 的幂减一的不变量。 

### 为什么它有效

 完美二叉树是递归刚性的：每个子树本身必须是完美二叉树。 删除一个节点只会破坏一个这样的子树条件。 重新连接规则确保这种违规不会任意传播，而是被吸收到已删除节点的父节点中。 

因此，在最终的树中，除了一个节点之外的每个节点的行为都与完美二叉子树的有效根完全相同。 被删除节点的父节点是唯一一个其局部结构无法通过有效分解为两个完美子树来解释的顶点。 通过测试候选者，我们正在识别这个递归不变量以单次删除所允许的方式失败的独特点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

def solve():
    n = int(input())
    N = (1 << n) - 2

    g = [[] for _ in range(N + 1)]
    for _ in range(N - 1):
        a, b = map(int, input().split())
        g[a].append(b)
        g[b].append(a)

    parent = [0] * (N + 1)
    depth = [0] * (N + 1)
    order = []

    # root at 1
    stack = [1]
    parent[1] = -1

    while stack:
        v = stack.pop()
        order.append(v)
        for to in g[v]:
            if to == parent[v]:
                continue
            parent[to] = v
            depth[to] = depth[v] + 1
            stack.append(to)

    # compute subtree sizes
    sz = [1] * (N + 1)
    for v in reversed(order):
        for to in g[v]:
            if parent[to] == v:
                sz[v] += sz[to]

    # check perfect power form
    def is_full(x):
        return x > 0 and (x & (x + 1)) == 0  # x = 2^k - 1

    res = []

    for p in range(1, N + 1):
        deg = len(g[p])

        # candidate parent must have degree at least 2
        if deg < 2:
            continue

        # try assuming missing node is one of neighbors
        ok = False

        for bad in g[p]:
            comp_sizes = []
            for to in g[p]:
                if to == bad:
                    continue
                comp_sizes.append(sz[to])

            # we need remaining components to form two perfect subtrees
            if len(comp_sizes) != 2:
                continue

            a, b = comp_sizes

            if is_full(a) and is_full(b):
                ok = True
                break

        if ok:
            res.append(p)

    print(len(res))
    if res:
        print(*sorted(res))

if __name__ == "__main__":
    solve()
```该实现首先对树求根以获得子树大小，因为这些是我们需要的唯一全局结构信号。 关键的简化是将树视为有根的，即使原始问题是无根的； 这是有效的，因为无向树中的子树大小仅取决于所选的根，并且任何候选重建都可以与根一致地对齐。 

对于每个节点`p`，我们检查它的邻居并模拟哪条边可能对应于丢失的子项。 删除一个邻居会将剩余的事件结构拆分为多个组件； 在有效的配置中，恰好两个这样的组件必须对应于完美的二叉子树。 支票`is_full`测试子树大小是否匹配`2^k - 1`，这是完美二叉树的定义属性。 

一个微妙的实现细节是我们没有显式重建子树。 我们只依赖于预先计算的子树大小，这使复杂性保持线性。 位技巧`(x & (x + 1)) == 0`是一种紧凑的方法来检查是否`x`是这样的形式`2^k - 1`。

 ## 边缘情况

 一种边缘情况是删除的节点是叶子。 在这种情况下，最终的树仍然几乎是完美的，而父树只是失去了一个叶子孩子。 该算法可以处理这个问题，因为一个邻居的移除会产生两棵与未触及的子树完全对应的完美子树。 

另一种边缘情况是删除的节点位于根以下一级。 然后，根成为其子树大小不再对称的唯一顶点。 该检查正确地将根识别为有效候选者，因为删除适当的邻居会产生两个有效的完整子树。 

最后的边缘情况是对称的：树的不同部分中的多个顶点可以满足相同的子树大小条件。 该算法自然会收集所有这些数据，因为它不假设唯一性，只假设一致性。
