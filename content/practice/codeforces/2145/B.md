 ## 解决方案
 ## 问题理解

 我们有一副牌，编号从 1 到 n，最初排序为 1 在顶部，n 在底部。 Monocarp 执行一系列 k 操作，从顶部、底部或模糊地从任一端移除卡片。 对于每张牌，我们必须判断它是肯定被移除了，还是肯定保留了，或者我们是否无法辨别。 

输入给出卡片数量 n、动作数量 k 和长度为 k 的字符串，其中每个字符表示移除类型：“0”表示顶部，“1”表示底部，“2”表示两端。 每个测试用例的输出是一个长度为 n 的字符串，其中包含字符“+”、“-”或“?” 按顺序排列每张卡。 

约束允许 n 最大为 2×10^5，并且测试用例中所有 n 的总和最大为 2×10^5。 这排除了任何根据操作显式模拟牌组的方法，因为简单的模拟最多可以完成 O(nk) 工作，可能是 4×10^10 次操作，这太大了。 我们需要对 n 和 k 进行线性或接近线性的方法。 

“2”操作会出现微妙的边缘情况。 如果所有动作都是“2”，则可以从任一端移除任何卡。 例如，如果 n=3 且 s="22"，则不能保证任何牌都会被移除，因为我们无法判断选择了哪一端。 总是按顺序从顶部或底部移除的粗心方法会错误地将某些卡片标记为已移除。 

## 方法

 暴力方法会明确地对牌组进行建模，按照指定从前面或后面弹出牌。 对于“2”，我们需要考虑两种可能性，从而产生指数数量的状态。 即使忽略指数爆炸，仅线性模拟牌组每次操作也需要 O(n)，因为在 Python 中从列表的前面或后面删除是 O(n)，这太慢了。 

关键的观察结果是，每张牌的命运仅取决于在其被移除之前发生了多少次保证的顶部移除和底部移除。 我们可以计算 s 中“0”（顶部移除）和“1”（底部移除）的累积数量。 任何位置小于顶部移除次数的卡片都必须被移除。 任何与底部距离小于底部移除次数的卡片都必须被移除。 这些保证移除之外的牌将保留，而两端重叠的模糊“2”内的牌将被标记为“？”。 这将问题简化为简单的算术比较和累积计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(nk) | O(nk) | O(n) | 太慢了|
 | 最佳| O(n + k) | O(n) | 已接受 |

 ## 算法演练

 1.初始化计数器`top_removals`和`bottom_removals`为零。 这些将跟踪每一端的保证移除量。 
2. 迭代字符串 s。 对于每个“0”，递增`top_removals`。 对于每个“1”，递增`bottom_removals`。 对于“2”，不要增加任一计数器，因为我们无法保证它影响哪一端。 
3. 假设所有卡片都保留下来，用“+”初始化输出数组。 
4. 对于编号为 i（从 1 到 n）的每张牌，检查其相对于保证移除的位置。 如果 i ≤ top_removals，则它已从顶部删除，应标记为“-”。 如果n-i+1≤bottom_removals，则已从底部移除，应标记为“-”。 
5. 如果两个条件都不成立，但 i 处于可能受模糊“2”删除影响的范围内，则标记“？”。 如果 i ≤ top_removals + '2' 的数量或 n-i+1 ≤ Bottom_removals + '2' 的数量，就会发生这种情况。 否则，保留为“+”。 
6. 将数组连接成字符串并输出。 

这是有效的，因为我们只考虑从已知操作中保证删除。 不明确的移除不会以可预测的方式减少剩余的牌组数量，因此“？” 准确反映不确定性。 不变的是`top_removals`和`bottom_removals`始终正确计算每一端有多少张牌已被明确移除。 这些范围之外的所有剩余卡片要么肯定存在，要么不确定，算法会正确标记。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        s = input().strip()
        top = s.count('0')
        bottom = s.count('1')
        ambiguous = s.count('2')
        res = ['+'] * n
        for i in range(1, n+1):
            if i <= top or (n - i + 1) <= bottom:
                res[i-1] = '-'
            elif i <= top + ambiguous or (n - i + 1) <= bottom + ambiguous:
                res[i-1] = '?'
        print(''.join(res))

if __name__ == "__main__":
    solve()
```我们首先读取测试用例的数量。 对于每个测试用例，我们计算保证的顶部删除、底部删除和模糊删除的数量。 我们将结果初始化为全“+”。 然后，对于每张卡，如果它落入保证移除范围内，我们首先将其标记为“-”。 如果没有，我们检查它是否可能受到不明确操作的影响并标记“？”。 否则，它仍然是“+”。 使用计数而不是模拟牌组可确保线性时间并避免在从底部计算位置时出现相差一的错误。
