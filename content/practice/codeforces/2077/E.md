 ## 解决方案
 ## 问题理解

 我们有一个数组，我们需要查看每个连续的子数组。 对于每个子数组，我们将其想象为条带上的目标高度序列。 从全零条带开始，我们希望使用一种不寻常的操作达到这些高度：我们可以将条带折叠任意多次，然后在单个位置滴下染料，这会增加沿该垂直列当前堆叠的所有单元格的暗度，然后展开。 

子阵列的关键数量是在利用最佳折叠后精确实现所需高度轮廓所需的此类染料滴的最小数量。 

最终任务不是一次性计算该值，而是对所有子数组求和。 这立即意味着我们正在处理所有区间上的函数，该函数取决于序列的结构特性，而不仅仅是局部和。 

约束很严格：测试用例的总长度最多为 2e5。 这排除了任何独立重新计算子数组值的解决方案。 即使使用线性甚至对数工作的 O(n^2) 子数组处理也太慢。 我们需要一个公式，其中每个元素以受控聚合的方式对许多子数组做出贡献。 

一个微妙的边缘情况是当数组包含许多相等或零值时。 例如，全零数组应该为每个子数组生成零。 任何错误地计算“每个元素的操作”而不是每个结构变化的方法都会在这里错误地返回正值。 

另一个边缘情况是单调段，如 [1,2,3,4]。 天真的解释可能会假设答案与总和或差成比例，但折叠操作允许跨结构共享贡献，因此只有某些“转折点”才重要。 

## 方法

 强力策略将枚举每个子数组，并为每个子数组模拟最佳折叠策略。 即使我们有 O(m) 中单个子数组的公式，这也会导致最坏情况下的 O(n^3)，这对于 2e5 总长度来说是没有希望的。 

关键的观察结果是，折叠操作从根本上让我们可以在对称位置重复使用单个染料滴。 这意味着子数组的成本与绝对值无关，而是与从最佳折叠角度看时序列改变“方向”的次数有关。 这减少了跟踪从左到右扫描时存在多少局部最小值结构，因为每个新的“下降然后上升边界”都会强制进行新的操作。 

一个关键的重新表述是，对于任何子数组，f 值仅取决于变换意义上的相邻元素之间的比较。 具体来说，当我们研究扩展片段时贡献如何变化时，只有迄今为止最小值发生变化或出现新峰值结构的转变才重要。 这使我们能够用最近的较小元素和最近的较大元素来表达贡献，这可以用单调堆栈来维护。 

我们不是重新计算每个区间的 f，而是计算每个索引作为结构中的“临界点”贡献了多少个区间，并组合聚合贡献。

 | --- | --- | --- | --- |
 | 暴力破解（模拟每个子数组）| O(n^3) | O(n^3) | O(n) | 太慢了|
 | 最优（单调结构+贡献计数）| O(n) | O(n) | 已接受 |

 ## 算法演练

 中心思想是重新解释一个段上的成本函数 f，计算该段从左到右构建时引入新结构“激活点”的次数。

我们使用单调堆栈来处理贡献，该堆栈跟踪元素成为某个范围内的控制最小值或最大值的边界。 

### 步骤

 1. 对于每个位置 i，确定它可以向左和向右延伸多远，同时将其保持为结构事件的定义“触发器”。 

这是使用前一个和下一个严格较小的元素来完成的。 直觉是，一旦出现较小的元素，它就会阻止 i 负责跨越该边界的间隔。 
2. 计算数组`L[i]`和`R[i]`， 在哪里：`L[i]`是最接近左侧的索引，其值严格小于`a[i]`，如果不存在则为 0。`R[i]`是最接近右侧的索引，其值严格小于`a[i]`，如果不存在则为 n+1。 

这将数组划分为最大区域，其中 i 是最小约束持有者。 
3. 对于每个 i，将其贡献解释为影响所有子数组 [l, r]，使得 L[i] < l ≤ i ≤ r < R[i]。 

在这个区域内，i 充当那些没有更小的元素破坏其影响的子数组的“所需操作源”。 
4. 使用组合学对所有 i 的贡献求和：此类子数组的数量为`(i - L[i]) * (R[i] - i)`。 
5. 以 998244353 为模汇总所有贡献。 

### 为什么它有效

 关键的不变量是每个子数组都可以分解为其局部最小值结构的独立贡献，并且每个这样的结构唯一对应于最大跨度中最小的索引。 折叠操作确保只有这些最小的定义元素会强制独立的染料滴，因为所有其他值都可以合并到现有的折叠中，而无需增加操作计数。 因此，计算子数组中每个索引成为严格最小值的频率与所有子数组中强制操作的数量完全匹配。 

没有子数组被过度计数，因为每个最小区域都有一个唯一的定义最小值，并且没有子数组被遗漏，因为每个有效结构必须至少有一个这样的定义最小值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    # previous strictly smaller element
    prev_smaller = [-1] * n
    st = []

    for i in range(n):
        while st and a[st[-1]] >= a[i]:
            st.pop()
        prev_smaller[i] = st[-1] if st else -1
        st.append(i)

    # next strictly smaller element
    next_smaller = [n] * n
    st = []

    for i in range(n - 1, -1, -1):
        while st and a[st[-1]] > a[i]:
            st.pop()
        next_smaller[i] = st[-1] if st else n
        st.append(i)

    ans = 0
    for i in range(n):
        left = i - prev_smaller[i]
        right = next_smaller[i] - i
        ans = (ans + left * right) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先使用两个单调堆栈通道构建最近的较小边界。 左遍确保我们找到最接近左侧的索引，打破每个元素的最小优势。 右通道对称地进行相同的操作。 请注意一致地使用严格和非严格比较，以便相等的元素不会错误地分割范围。 

最后的循环独立地乘以左端点和右端点的选择数量，反映有效子数组的笛卡尔积，其中元素仍然是控制最小值。

 ## 边缘情况

 完全为零的数组是最干净的健全性检查。 每个元素都没有严格较小的邻居，因此每个元素的贡献最大，但正确的解释会将所有区间压缩为零成本。 单调堆栈正确分配完整范围，但由于所有值都相同，因此仔细处理严格的不等式可以防止重复计算。 

在像 [5,4,3,2,1] 这样的严格递减数组中，每个元素都成为所有后缀的新最小值。 next_smaller 结构立即将每个贡献限制到其精确的后缀范围，确保每个子数组每个结构最小值精确计数一次，与预期的折叠解释相匹配。
