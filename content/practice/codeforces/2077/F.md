 ## 解决方案
 ## 问题理解

 我们有两个数组，`a`和`b`, 等长`n`，包含达到某个最大值的非负整数`m`。 目标是对元素执行最小增量操作`a`或者`b`这样得到的结果对`(a, b)`在问题定义的意义上变得_good_：对于选择两个不同索引的某些操作序列`i`和`j`和一个非负整数`x`，我们可以更新`c_i := c_i & x`和`c_j := c_j | x`最终转换数组`c`进入数组`d`。 

简单来说，这意味着每个位设置`b`必须可以通过 OR/AND 运算从某些配置访问`a`。 关键的见解是，对于一对`(c, d)`好的话，数组`c`必须能够“覆盖”中设置的每一位`d`通过这些 AND/OR 运算。 对于设置的任何位`d`但不在`c`，我们必须增加一些元素`c`直到它设置了该位。 

输入允许多个测试用例，总共`n`和`m`所有测试均不超过 2·10^6。 这意味着`O(n·log m)`每个测试的算法是可以接受的，但是任何二次的`n`或者`m`会太慢。 

当出现不明显的边缘情况时`a`和`b`每个元素中已经具有相同的位。 例如，如果`a = [0, 1, 2]`和`b = [0, 1, 2]`，无需移动。 另一个边缘情况是当其中的单个元素`b`具有高位设置，其中没有元素`a`无需多次增量即可达到，例如`a = [1, 1]`,`b = [8, 1]`。 一种天真的增量方法`a`或者`b`任意地可能找不到最小的动作。 

## 方法

 蛮力方法会考虑每一个可能的增量`a`或者`b`然后模拟结果对是否良好。 这显然是不切实际的，因为数字可以达到 2·10^6 并且组合的数量呈指数增长。 

关键的观察是一点一点地推理。 对于中的每个元素`b`，我们至少需要一个元素`a`其位可以通过 AND/OR 运算进行转换以覆盖中设置的所有位`b`。 实现这一目标的最小方法是找到进行某些操作所需的最小增量数`a[i] | b[j] == b[j]`对于中的每个元素`b`。 这将问题减少到检查每个元素`a[i]`，所需的最小增量是多少`a[i] | b[j]`等于`b[j]`为所有人`j`。 通过迭代可能的目标掩码`a[i]`并计算所需的增量，我们可以有效地找到最小的总移动次数。 

因此，最佳解决方案避免直接模拟 AND/OR 运算。 相反，它利用按位属性来查找允许一个元素的最小增量`a`覆盖给定元素`b`。 这将问题从指数搜索减少为带有位操作的线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((m+1)^n) | O((m+1)^n) | O(n) | 太慢了|
 | 最佳 | O(n·m) | O(米) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组`a`和`b`并计算最大元素`m`。 这用于定义最小增量要考虑的数字范围。 
2. 初始化变量`min_moves`到大量。 这将存储所需的最小总增量。 
3. 迭代所有潜在的增量`x`从`0`到`m`可以添加到`a[i]`。 对于每个`x`，检查是否`(a[i] + x) | b[j]`可以等于`b[j]`为所有人`j`。 如果是这样，则所需的移动次数为`x`加上所需的任何增量`b`以匹配目标。 
4. 在所有方面保持全局最低限度`i`以及可能的增量`x`。 
5.检查完所有可能性后，输出`min_moves`对于该测试用例。 

为什么它有效：该算法确保对于每个元素`b`, 至少存在一个元素`a`可以通过 OR 运算到达它。 通过迭代可能的增量，我们保证找到满足按位覆盖的最小移动集，这正是定义“好”对的原因。 线性扫描与按位运算相结合，保证了不可能有更小的移动集，并且计算的每个移动都有助于使`(a, b)`好的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        res = float('inf')
        # we try to find minimal increments for 'a'
        for add_a in range(m+1):
            # apply increment to all a[i]
            valid = True
            total_moves = add_a
            for i in range(n):
                if (a[i] + add_a) | b[i] != b[i]:
                    valid = False
                    break
            if valid:
                res = min(res, total_moves)
        print(res)

if __name__ == "__main__":
    solve()
```该代码读取多个测试用例，循环遍历每个测试用例，并尝试可能的增量`a`。 对于每个增量，它检查是否`(a[i] + add_a) | b[i] == b[i]`。 如果此条件适用于所有元素，它将更新最小移动次数。 循环结束`0..m`确保我们考虑所需的所有增量，而无需模拟不必要的 AND/OR 操作。
