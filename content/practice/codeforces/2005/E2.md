 ## 解决方案
 ## 问题理解

 我们有一个序列$a$和一个$n \times m$矩阵$b$。 

游戏遵循从左到右的顺序。 移动中$k$，当前玩家必须选择一个值等于的单元格$a_k$。 如果选择的单元格是$(r,c)$，下一步的移动仅限于严格的右下子矩阵，即行$> r$和列$> c$。 

当玩家无法做出所需的动作时，他们就输了。 如果序列的最后一个元素已被选择，则下一个玩家也会失败。 

矩阵尺寸很大。 在所有测试用例中，细胞总数达到$3 \cdot 10^6$。 任何执行与以下成比例的功的解决方案$l \cdot n \cdot m$立刻就太慢了。 自从$l$至多是$1500$，唯一可行的方向是处理每个矩阵单元恒定的次数，并以某种方式压缩有关序列的所有信息。 

危险的情况是相同的值在矩阵中出现多次的情况。 一个天真的极小极大会在所有事件上分支并迅速爆炸。 

考虑```
a = [1,2]

1 1 1
1 2 1
1 1 1
```选择不同的出现次数`1`极大地改变了可用的右下区域。 将所有相等的值视为可互换会给出错误的答案。 

另一个微妙的情况是，移动可以有意选择非常靠近右下角的单元格。```
a = [1,2]

1 5
6 1
```第一个玩家可以选择右下角`1`。 剩余的子矩阵为空，因此第二个玩家立即失败。 任何仅检查是否`2`存在于矩阵中的某个位置会错误地宣告第一个玩家的损失。 

最后的陷阱是序列中的重复值。 位置的获胜状态与重要值的最早出现有关。 后来的事件不会创造新的战略状态，必须小心压缩。 

## 方法

 直接极小极大公式很简单。 

让$W_k$是当当前所需元素为时获胜选择的一组单元格$a_k$。 一个细胞$(r,c)$属于$W_k$如果每项针对此举的法律回应$k+1$正在失去。 等效地，不存在以下单元格：$W_{k+1}$在右下矩形内$(r,c)$。 

这种递归是正确的，但计算它实际上需要为每个序列位置维护一个获胜集。 即使每一层都经过处理$O(nm)$，复杂度变为$O(lnm)$，这是周围$4.5 \cdot 10^9$最坏情况下的操作。 

关键的观察结果是，我们实际上并不需要每个序列位置都有一个 DP 层。 

对于一个细胞来说，只有两条信息很重要：

 1.在其后缀矩形内可达的最小偶校验获胜序列索引。 
2.在其后缀矩形内可到达的最小奇校验获胜序列索引。 

一旦知道这两个值，我们就可以决定当前单元格本身是否创建获胜状态。 

这一切都崩溃了$l$DP 分层为两个矩阵。 

硬版本增加了另一种压缩。 对于每个值，只有在第一次重复之前在序列中第一次出现的值才是相关的。 任何稍后出现的相同值都不会产生较小的获胜指数，可以忽略。 这将序列信息减少为每个值的单个索引。 官方接受的解决方案正是使用这种压缩。 

压缩后，每个矩阵单元都被处理一次，同时保持后缀最小值，从而给出矩阵大小的线性复杂度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 序列层上的暴力 DP |$O(lnm)$|$O(nm)$| 太慢了|
 | 最优后缀-最小DP |$O(nm)$每个测试用例|$O(nm)$| 已接受 |

 ## 算法演练

 1. 对于序列中出现的每个值，存储它出现的第一个索引。 一旦某个值重复，后面出现的值就无关紧要，可以忽略。 
2. 创建两个DP表。`dp0[r][c]`存储偶校验的最小获胜序列索引，该索引可以在后缀矩形内的某处实现，起始于`(r,c)`。`dp1[r][c]`存储奇校验的类似值。 
3. 将每个条目初始化为无穷大。 
4. 从右下角到左上角处理矩阵。 
5. 在考虑当前单元格之前，传播后缀最小值：$$dp0[r][c] = \min(dp0[r+1][c], dp0[r][c+1])$$

$$dp1[r][c] = \min(dp1[r+1][c], dp1[r][c+1])$$在此步骤之后，每个表已包含来自当前位置严格下方或严格右侧的所有单元格的信息。 
6.让`p`是与当前矩阵单元中的值相对应的存储序列索引。 
7. 如果`p`具有偶奇偶性，则该单元格成为索引的获胜状态`p`当后缀矩形不包含索引的获胜状态时`p+1`。 

在压缩表示中，该条件恰好是$$p + 3 \le dp1[r+1][c+1].$$当它成立时，更新$$dp0[r][c] = \min(dp0[r][c], p).$$8. 应用奇校验的对称规则：$$p + 3 \le dp0[r+1][c+1].$$如果属实的话，$$dp1[r][c] = \min(dp1[r][c], p).$$9. 处理完整个矩阵后，第一个玩家恰好在序列索引处获胜`0`是从整个矩阵可到达的获胜偶校验状态。 

这相当于```
dp0[0][0] == 0
```这种递推是上述极小极大关系的紧凑形式。 

### 为什么它有效

 对于每个后缀矩形，`dp0`和`dp1`维护该矩形内存在的每个奇偶校验的最小获胜序列索引。 

对应序列索引的移动`p`当对手无法进入指数获胜状态时，就是获胜`p+1`在右下矩形中。 后缀最小值告诉我们这种状态是否存在。 如果不存在，则当前单元格本身成为索引的获胜状态`p`。 

由于扫描顺序是从右下到左上，因此在处理单元格时已经计算了有关所需右下矩形的所有信息。 不变量在整个扫描过程中保持不变，因此最终答案为`(0,0)`是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10 ** 9

def solve():
    t = int(input())
    out = []

    pos = {}

    for _ in range(t):
        l, n, m = map(int, input().split())
        a = list(map(int, input().split()))

        pos.clear()

        for i, x in enumerate(a):
            if x in pos:
                break
            pos[x] = i

        dp0 = [[INF] * (m + 1) for _ in range(n + 1)]
        dp1 = [[INF] * (m + 1) for _ in range(n + 1)]

        b = [list(map(int, input().split())) for _ in range(n)]

        for r in range(n - 1, -1, -1):
            for c in range(m - 1, -1, -1):

                if dp0[r + 1][c] < dp0[r][c]:
                    dp0[r][c] = dp0[r + 1][c]
                if dp0[r][c + 1] < dp0[r][c]:
                    dp0[r][c] = dp0[r][c + 1]

                if dp1[r + 1][c] < dp1[r][c]:
                    dp1[r][c] = dp1[r + 1][c]
                if dp1[r][c + 1] < dp1[r][c]:
                    dp1[r][c] = dp1[r][c + 1]

                p = pos.get(b[r][c], -1)

                if p >= 0:
                    if p % 2 == 0:
                        if p + 3 <= dp1[r + 1][c + 1]:
                            if p < dp0[r][c]:
                                dp0[r][c] = p
                    else:
                        if p + 3 <= dp0[r + 1][c + 1]:
                            if p < dp1[r][c]:
                                dp1[r][c] = p

        out.append('T' if dp0[0][0] == 0 else 'N')

    sys.stdout.write("\n".join(out))

solve()
```第一部分构建从值到序列索引的压缩映射。 仅存储每个值的第一次出现。 

两个DP表初始化为无穷大。 无限值意味着相应后缀矩形中不存在该奇偶校验的获胜序列索引。 

以相反的顺序扫描矩阵。 到......的时候`(r,c)`处理后，矩形`(r+1,c+1)`已经包含了完整的信息，这正是游戏转换所需要的区域。 

条件`p + 3 <= ...`是“对手对于下一个序列位置没有获胜状态”的压缩形式。 使用`p + 1`将是不正确的，因为表存储奇偶校验的最小获胜索引，而不是精确索引。 

答案完全取决于是否有序列索引`0`成为胜利状态。

 ## 边缘情况

 考虑```
1
1 2 2
5
1 2
3 4
```没有矩阵单元包含`5`。 DP 永远不会创建与序列索引对应的获胜状态`0`， 所以`dp0[0][0]`保持无穷大，答案是`N`。 

考虑```
1
2 2 2
1 2
5 5
5 1
```细胞`(2,2)`包含`1`。 选择它会留下一个空的右下矩形。 对手没有任何动作，所以状态立即变为必胜，答案是`T`。 

考虑```
1
3 2 2
1 1 1
1 1
1 1
```尽管该序列多次重复相同的值，但只有第一个相关的出现对压缩 DP 有贡献。 该算法仍然计算正确的获胜者，因为它跟踪每个奇偶校验的最小获胜索引，而不是单独存储每个事件。
