 ## 解决方案
 ## 问题理解

 我们被要求构造一个大小为 _n_ × _n_ 的方阵，其中 _n_ 是偶数。 矩阵必须满足四个属性。 主对角线仅包含零。 该矩阵是对称的，即第 _i_ 行、_j_ 列的元素等于第 _j_ 行、_i_ 列的元素。 每行必须包含不同的整数，每个矩阵条目都是从 0 到 _n_ - 1 的整数。输入提供 _n_，输出是满足所有这些条件的任意矩阵。 

约束允许 _n_ 最多为 1000，这意味着该算法可以在 2 秒的时间限制内轻松执行大约 10^6 次操作。 由于矩阵有 _n^2_ 个条目，因此任何线性接触每个元素的解决方案都是可接受的。 _n_ 为偶数的约束是重要的； 它排除了某些可能仅适用于奇数尺寸的幼稚配对策略。 

边缘情况出现在允许的最小 _n_ 中，即 2。这里，矩阵只是 2×2，唯一的解是 [[0,1],[1,0]]。 当 _n_ 很大时，会出现另一种微妙的情况。 如果不小心实施，任何依赖于重复检查连续重复项的方法都可能变得太慢或太复杂。 在不强制执行对称性的情况下逐行填充值的简单方法可能会在矩阵的镜像侧产生冲突。 

## 方法

 一种强力方法是尝试在每一行中放置从 0 到 _n_-1 的数字，同时检查该行是否不包含重复项、主对角线为零且保留对称性。 人们可以使用回溯来填充每个单元格，测试所有可能性。 这在理论上是正确的，但组合数量随 _n_ 呈阶乘增长，最坏情况下大约为 O((n!)^n)，对于 _n_ 达到 1000 时这是完全不可行的。 

解锁快速解决方案的关键观察是利用对称性和模运算。 我们可以填充矩阵，使每一行都是前一行的移位版本，围绕模 _n_ 进行环绕。 这会自动确保所有行都包含不同的数字，主对角线可以设置为零，并且如果仔细安排移位，则可以保留对称性。 因为 _n_ 是偶数，所以我们可以以旋转模式对条目进行配对，首先填充上三角形并对其进行镜像。 这将问题简化为每个元素的确定性公式，避免嵌套循环或回溯。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((n!)^n) | O((n!)^n) | O(n^2) | O(n^2) | 太慢了 |
 | 建设性的轮班 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 初始化一个用零填充的空 n×n 矩阵。 这可以确保主对角线正确开始。 
2. 对于从 1 到 _n/2_ 的每个偏移 _k_，我们将填充对称位置对：(i, (i+k) % n) 和 ((i+k) % n, i)。 为这些位置分配值_k_。 这保证了对称性，因为 (i,j) 和 (j,i) 都设置为相同的值。 
3. 迭代从 0 到 n-1 的所有行 _i_。 对于每一行，在三角形的上半部分放置的值恰好是 1 到 n/2，在下半部分进行镜像，确保该行中的所有数字都是不同的。 
4. 填充所有偏移量后，矩阵就完成了：所有对角线元素保持为零，对称性成立，并且每行都有 n/2 个不同的非零数字加上对角线零。 

工作原理：从 1 到 n/2 的每个数字以镜像模式在每行和每列中恰好出现两次，因此任何行中都不会出现重复项。 对角线保持为零，因为偏移量永远不会分配给 (i,i)。 通过同时填充 (i,j) 和 (j,i) 来增强对称性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
matrix = [[0] * n for _ in range(n)]

half = n // 2
for k in range(1, half + 1):
    for i in range(n):
        j = (i + k) % n
        matrix[i][j] = k
        matrix[j][i] = k

for row in matrix:
    print(' '.join(map(str, row)))
```我们首先读取 n 并初始化一个 n×n 零矩阵。 变量`half`是n/2。 对于从 1 到 n/2 的每个数字，我们将其放置在位置 (i, i+k) 和 (i+k, i) 中，使用模 n 环绕该行。 这会自动保证对称性和不同的行条目。 最后，我们逐行打印矩阵。 模运算避免了索引溢出并确保了循环模式。

 ## 边缘情况

 对于 n = 2，k=1 的循环将 1 放入 (0,1) 和 (1,0) 中。 对角线保持为零，因为 i ≠ j。 模数确保即使在边界处也能进行环绕工作。 该算法从不写入 (i,i)，因为 k ≥ 1。对于最大 n = 1000，相同的逻辑缩放。 1 到 500 中的每个值每行每列恰好出现两次，满足所有约束而不会发生冲突。 

循环模式确保对于任何偶数 n，每行都会自动接收不同的数字。 对于靠近矩阵末尾的行不需要特殊处理，因为模算术无缝地包装索引。 该结构对于所有允许的 n 值都是稳健的。
