 ## 解决方案
 ## 问题理解

 我们得到一个字符串集合，每个字符串代表一组固定的五个不同符号的完整排序。 每个有效的排序都是这五个符号的排列，因此每个字符串仅使用每个符号一次。 

在这五个符号的所有可能排列中，输入中恰好缺少一种排序。 我们的任务是确定哪个排列没有出现在给定列表中。 

输入大小很小：最多存在 119 个排列，因为五个不同元素的完整排列集大小为 120。这立即告诉我们，即使枚举所有排列或与所有可能性进行比较的解决方案在任何合理的时间限制内也是可行的，因为总搜索空间是恒定的且很小。 

一个天真的但重要的观察是每个字符串的长度只有 5，因此任何单独处理每个字符串的每个字符的方法将总共执行大约几百个字符操作。 从竞争性编程的角度来看，这实际上是常数时间。 

主要的边缘情况是概念性的而不是计算性的。 由于每个符号在每个有效排列中只出现一次，因此依赖于每个位置的频率或全局频率的方法必须遵循该结构。 假设输入已排序或假设缺失的排列仅在一个位置不同的粗心方法可能会失败。 

例如，假设符号是 A、B、C、D、E，而我们缺少`ABCDE`。 如果有人试图通过在每个位置采用最常见的字符来重建，他们可能会意外地选择已经形成现有排列的字符，因为多个排列可以在多个位置上达成一致。 除非经过仔细论证，否则正确答案不是孤立地根据位置确定的。 

## 方法

 蛮力的想法是生成五个符号的所有可能排列，并检查哪一个没有出现在输入集中。 因为正好有 5 个！ = 120 种排列，这个枚举很简单。 我们将所有给定的字符串存储在一个集合中，然后迭代 120 个候选字符串并返回不存在的字符串。 

这是有效的，因为搜索空间是完全有界的并且与输入大小无关。 一般排列问题的瓶颈是阶乘增长，但这里阶乘被固定在一个恒定的小值。 因此，对于任何现实的约束，蛮力方法已经在恒定时间内运行。 

稍微更直接的推理方法利用了所有字符串都是同一字母表上的排列这一事实。 如果我们明确地修复字母表，我们可以将每个输入字符串视为一个排列对象，并与所有排列的预先计算的列表进行比较。 这将问题简化为集合成员资格检查。 

除此之外，不需要任何有意义的渐近改进，但概念见解是问题的结构消除了搜索或贪婪重建的任何需要。 我们不是一步步构建排列，而是识别完整有限集中缺失的元素。

 ## 算法演练

 我们假设这五个符号是已知的并且是固定的，因为问题定义意味着所有排列中的字母表都是一致的。 

1. 读取所有输入字符串并将它们存储在哈希集中，以进行 O(1) 平均成员资格检查。 这使我们能够快速测试输入中是否存在候选排列。 
2.按字典顺序或任何固定顺序生成五个符号的所有排列。 这样的排列正好有 120 种。 
3. 对于每个生成的排列，将其转换为字符串。 
4. 检查输入集中是否存在该字符串。 
5. 集合中第一个没有找到的排列是缺失的，所以立即输出。 

关键的设计选择是将输入视为完整有限宇宙的成员预言，而不是尝试从部分信息重建结构。 

### 为什么它有效

 所有有效输出的集合形成给定字母表的所有排列的完整枚举。 输入包含除一个元素之外的所有元素，因此完整排列域内输入集的补集恰好包含一个元素。 由于我们明确地枚举了宇宙，因此检查成员资格可以唯一地隔离缺失的元素。 

任何两个不同的排列都不能映射到同一字符串，并且每个有效排列要么存在于输入中，要么不存在于输入中。 这保证了直接排除搜索的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from itertools import permutations

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    
    # All input strings are permutations of 5 characters
    arr = data
    sset = set(arr)
    
    # Determine alphabet from input (any string is fine)
    alphabet = sorted(arr[0])
    
    for p in permutations(alphabet):
        cand = ''.join(p)
        if cand not in sset:
            print(cand)
            return

if __name__ == "__main__":
    solve()
```该解决方案将所有排列读取到一个集合中，以便成员资格检查平均时间为常数。 字母表是从任何输入字符串中提取的，因为所有字符串都是相同五个符号的排列。 我们对其进行排序只是为了确保确定性的生成顺序，尽管任何顺序仍然有效。 

然后我们迭代所有 120 个排列并返回集合中缺少的一个。 提前返回可以确保我们在找到答案后立即停止。 

一个微妙的实现细节是立即读取整个输入。 由于行数很少，这避免了重复的 I/O 开销并保持代码简单。

不变量是，在每一步中，我们都会从确认存在于输入集中的完整排列宇宙中删除一个候选者，直到只剩下缺失的一个。

 ## 边缘情况

 一种边缘情况是缺失的排列按字典顺序位于第一个或最后一个。 在第一种情况下，算法立即终止，因为第一个生成的候选者已经不存在于集合中。 在第二种情况下，算法在找到缺失的排列之前会遍历所有 120 种排列，但仍然只执行固定数量的检查。 

另一个边缘情况是输入顺序完全打乱时。 由于我们依赖于一组成员资格，因此排序对正确性没有影响。 该算法始终与同一组候选者进行比较。 

最后一个微妙的情况是假设所有输入字符串都包含相同的字母表。 如果违反了这一点，从第一个字符串中提取字母表将是不安全的。 问题结构保证了一致性，因此从任何单个字符串重建字母表在所有输入中都是有效且稳定的。
