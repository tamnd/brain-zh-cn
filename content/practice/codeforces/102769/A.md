 ## 解决方案
 # 问题理解

 该问题描述了红球和蓝球的集合。 有`r`红球和`b`蓝色球，统一随机抽取两个球，不放回。 我们需要计算两个选定的球都是红色的概率，然后将该概率打印为约简分数。 输出格式还需要在每个答案之前提供案例编号。 

从所有可用球中选择两个球的方法总数是其中的对数`r + b`对象，即`C(r+b, 2)`。 有利的选择是仅包含红球的对，这给出了`C(r, 2)`。 所需的概率是这两个量之间的比率。 

限制很小：每种颜色数最多为 100，并且最多有 10 个测试用例。 这意味着即使是直接组合计算也很容易足够快。 不需要先进的概率技术或大量的预计算。 主要挑战不是性能，而是在减少分数和正确处理特殊值时避免错误。 

有少数情况很容易处理不当。 当只有一颗红球时，不可能选择两颗红球。 对于输入：```
1
1 5
```答案是`Case #1: 0/1`。 粗心的实现可能会计算`1 * 0 / 2 = 0`正确，但忘记减少的分母必须仍然是正数且非零。 

另一种情况是所有球都是红色的。 对于输入：```
1
5 0
```概率恰好为 1，因为每个可能的对都是红色的。 简化后的答案一定是`1/1`，不是类似的东西`10/10`。 

最后一个常见的错误是使用有序选择而不是无序对。 例如：```
1
2 1
```有一对有利的对，两个红球，总共三对。 答案是`1/3`。 计算有序抽奖得出`2 / 6`，这在数学上是相等的，但需要在输出之前进行适当的减少。 

## 方法

 直接的做法是统计可能配对的数量和成功配对的数量。 由于选择两个对象会忽略顺序，因此选择的总数为：$$\binom{r+b}{2}=\frac{(r+b)(r+b-1)}{2}$$成功的选择是：$$\binom{r}{2}=\frac{r(r-1)}{2}$$概率是第一个值除以第二个值。 该方法已经是最佳方法，因为输入值很小。 暴力模拟可以尝试每对球，检查两个球是否都是红色，并计算结果。 这仍然是正确的，但它会产生不必要的工作。 对于 200 个球，检查所有对意味着每个测试用例大约 20,000 次操作，这在这里是可以接受的，但忽略了数学结构。 

所有配对的可能性相同的观察结果让我们可以用计数来代替模拟。 一旦我们知道了有利对的数量和总对的数量，概率就只是一小部分。 我们只需要将分子和分母除以它们的最大公约数即可产生所需的不可约形式。 

蛮力之所以有效，是因为它直接对每个可能的选择进行建模，但计数公式之所以有效，是因为每对都具有相同的概率，并且可能对的数量具有封闭形式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((r+b)^2) | O((r+b)^2) | O(1) | O(1) | 接受这些限制，但没有必要 |
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取测试用例的数量并独立处理每对球的计数。 
2. 计算成功选择的数量。 可以选择两个红球`r * (r - 1) / 2`方式，因为所选球的顺序并不重要。 
3. 计算可能选择的总数。 所有球中任意两个球`r + b`可以选择球，给出`(r + b) * (r + b - 1) / 2`的可能性。 
4. 求有利数和总数的最大公约数。 将两个值除以该 gcd，从而减少分数。 
5. 使用所需的案例编号格式打印约简分数。 

除以 gcd 是必要的，因为该问题需要一个不可约分数。 当分子和分母除以相同的值时，概率本身不会改变。 

为什么有效：每对可能的球都有相同的被选择概率。 分子精确计算包含两个红球的对，而分母则计算每个可能的对。 它们的比例正是所要求的概率。 按最大公约数减少只会改变分数的表示形式，而不改变其值，因此最终输出在数学上是等价且不可约的。 

## Python 解决方案```python
import sys
from math import gcd

input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for case in range(1, t + 1):
        r, b = map(int, input().split())

        numerator = r * (r - 1) // 2
        denominator = (r + b) * (r + b - 1) // 2

        g = gcd(numerator, denominator)
        numerator //= g
        denominator //= g

        ans.append(f"Case #{case}: {numerator}/{denominator}")

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```该解决方案直接遵循计数方法。`numerator`存储成功选择的数量，以及`denominator`存储所有可能的选择。 

乘法在除法之前完成，因为组合公式需要两个连续值的乘积。 这些值足够小，因此在 Python 中不必担心整数溢出。 

gcd 操作也自然地处理特殊情况。 如果分子为零，则零和分母的最大公约数就是分母本身，因此结果变为`0/1`。 如果分子和分母相等，则 gcd 将分数减少为`1/1`。

 ## 边缘情况

 对于只有一个红球的情况：```
1
1 5
```该算法计算`1 * 0 / 2 = 0`成功的配对。 对的总数为正，因此分数变为`0/6`，并且 gcd 减少将其更改为`0/1`。 

对于每个球都是红色的情况：```
1
5 0
```好评数和总数均为`10`。 最大公约数是`10`，生产`1/1`。 这避免了打印未减少的概率。 

对于订单统计错误的情况：```
1
2 1
```正确的模型计算无序对。 有一对成功的配对，总共三对。 该算法从不区分绘制第一个红色然后第二个红色和绘制第二个红色然后第一个红色，因此它与问题描述的选择过程相匹配。
