 ## 解决方案
 ## 问题理解

 我们有一个矩形的细胞图。 干电池表示为`#`湿电池表示为`.`。 边界墙是矩形的边界，但问题要求其覆盖的矩形区域。 该矩形必须完全由干电池组成，并且必须包含查询中提到的电池。 经过一些查询后，各个单元在干和湿之间切换，我们需要回答所请求单元的最大可能面积。 

输入包含多个测试用例。 每个测试用例都会给出初始网格，然后进行操作。 更新会更改一个单元格。 查询要求包含特定位置的最大全干矩形。 

一维约束很小，但在一个测试用例中允许最多 1000 行、1000 列和 1000 次操作。 尝试每一个可能的矩形的解决方案是不可能的，因为 1000 x 1000 的网格已经有大约$10^{12}$可能的矩形。 即使使用完整的动态编程表重新计算每个查询的答案也会太慢。 我们需要一种方法，其中每个查询仅扫描网格一次。 

有用的观察结果是 1000 列自然适合机器大小的位操作。 一整行可以表示为一个整数，其中位`1`意思是干燥。 相交的行成为单个整数 AND 运算。 这使我们能够非常快速地检查候选矩形的所有列。 

有一些边缘情况会破坏粗心的解决方案。 如果查询的单元格本身是湿的，则答案为零，因为每个有效的矩形都必须包含该单元格。 

例如：```
1 1 1
.
2 1 1
```输出是：```
Case #1:
0
```仅检查相邻单元格的解决方案可能会错误地返回正区域。 

另一种情况是矩形接触棋盘的边界。 

例子：```
2 3 1
###
###
2 1 1
```答案是：```
Case #1:
6
```最佳矩形使用整个网格。 仅当两侧都有单元格时才开始扩展的代码可能会错过这种情况。 

第三个常见错误是假设矩形的高度和宽度都必须大于 1。 允许单行或单列。 

例子：```
1 4 1
####
2 1 3
```答案是：```
Case #1:
4
```只考虑二维矩形的方法在这里会失败。 

## 方法

 一种直接的方法是枚举包含查询单元格的每个可能的矩形，并测试其所有单元格是否都是干燥的。 这是正确的，因为考虑了每个有效答案，但 1000 x 1000 网格中的矩形数量约为$10^{12}$。 即使使用前缀和，检查每个查询的所有矩形也远远超出了限制。 

更好的想法是固定矩形的一个维度并计算最佳的其他维度。 对于查询单元格，每个矩形必须包含查询的行。 如果我们从该行向上延伸，我们可以维护到目前为止包含的所有行的交集。 剩下的设置位正是当前高度区间内每一行都是干的列。 

该高度间隔的最大矩形是包含查询列的这些有效列的最长连续段。 我们可以在向下延伸的同时做同样的事情。 两次扫描覆盖了矩形的每个可能的顶部和底部边界。 

其高效工作的原因是网格维度只有 1000。从算法的角度来看，将每一行表示为 Python 整数可以让每一行交集在恒定时间内发生，因为实际工作是通过优化的大整数运算来处理的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每次查询 O(n²m²) | O(1) | O(1) | 太慢了 |
 | 最佳位集扩展 | 每个查询 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将网格的每一行存储为整数位掩码。 少量`j`当列被设置`j`那行是干的。 单元更新变成对相应位的单个异或运算。 
2. 查询：`(r, c)`，从所有可用的列开始，并从行向上延伸`r`。 添加每一行后，将当前掩码与该行相交。 其余位表示当前矩形高度的每行中干燥的列。 
3. 如果查询的列从掩模中消失，则停止向该方向延伸。 任何更大的矩形也将包含该湿细胞，因此没有更多的行可以创建有效的答案。 
4. 对于每个有效的高度间隔，计算包含柱的连续干段的长度`c`。 将该宽度乘以当前高度并更新答案。 
5. 重复相同的过程，同时从行向下延伸`r + 1`。 组合两个方向会考虑包含查询单元格的矩形的每个可能的顶部和底部边框。 

为什么它有效：

 在向上扫描期间，处理来自`top`到`r`，位掩码恰好包含那些行中的每个单元格都是干的列。 最长的连续段包含`c`是该行的确切集合可能的最宽矩形。 每个有效的矩形都有一些顶行，并且该顶行出现在扫描中。 同样的论点也适用于向下扫描。 由于考虑了每个可能的垂直范围并为每个范围选择了最佳宽度，因此找到的最大区域是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def trailing_ones(x):
    return ((~x) & (x + 1)).bit_length() - 1

def width_at(mask, col):
    right = trailing_ones(mask >> col)
    left_mask = mask & ((1 << col) - 1)
    left = trailing_ones(left_mask)
    return left + right + 1

def solve_case(n, m, q, grid, queries):
    rows = []
    for s in grid:
        x = 0
        for i, ch in enumerate(s):
            if ch == '#':
                x |= 1 << i
        rows.append(x)

    all_bits = (1 << m) - 1
    ans = []

    for t, x, y in queries:
        x -= 1
        y -= 1

        if t == 1:
            rows[x] ^= 1 << y
        else:
            if ((rows[x] >> y) & 1) == 0:
                ans.append("0")
                continue

            best = 1

            mask = all_bits
            height = 0
            for i in range(x, -1, -1):
                mask &= rows[i]
                if ((mask >> y) & 1) == 0:
                    break
                height += 1
                best = max(best, height * width_at(mask, y))

            mask = all_bits
            height = 0
            for i in range(x + 1, n):
                mask &= rows[i]
                if ((mask >> y) & 1) == 0:
                    break
                height += 1
                best = max(best, height * width_at(mask, y))

            ans.append(str(best))

    return ans

def main():
    t = int(input())
    out = []

    for case in range(1, t + 1):
        n, m, q = map(int, input().split())
        grid = [input().strip() for _ in range(n)]
        queries = [tuple(map(int, input().split())) for _ in range(q)]

        out.append(f"Case #{case}:")
        out.extend(solve_case(n, m, q, grid, queries))

    print("\n".join(out))

if __name__ == "__main__":
    main()
```网格表示是主要的实现细节。 每行都会转换为整数，因此更新单元格不需要更改字符串或重建数组。 XOR 之所以有效，是因为该操作仅翻转一位。 

对于查询，`mask`从启用所有列开始。 每一次 AND 运算都会删除当前垂直范围内至少包含一个湿单元的列。 当查询列被删除时，矩形不能再包含所请求的单元格，因此扫描立即结束。 

功能`width_at`查找包含给定列的连续运行的设置位。 右侧是通过将查询位移至最低有效位置后对尾部进行计数而获得的。 左侧对查询列之前的位进行相同的操作。 

Python 整数具有任意精度，因此即使一行可以包含 1000 位，也不存在溢出问题。

 ## 边缘情况

 当查询的单元是湿的时，算法在扫描之前检查该位。 对于仅包含`.`在查询的位置，答案立即变为零，因为每个可能的矩形都将包含该湿单元。 

当最优矩形触及边界时，向上或向下扫描自然会到达行数组的边缘。 没有特殊的边界处理，因为扫描只是在最后一个有效行之后停止。 

当只有一行或一列可用时，相同的交集逻辑仍然适用。 宽度计算可以返回 1，并且面积公式可以正确处理细矩形。 算法中没有内置关于最小高度或宽度的假设。
