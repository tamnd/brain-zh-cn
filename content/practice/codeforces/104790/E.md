 ## 解决方案
 ## 问题理解

 每场考试都有固定的时间段，并且考试不会重叠。 对于每次考试，如果您没有做任何准备，您可以在正常结束时间结束考试；如果您事先投入了足够的学习时间，您也可以提前完成考试。 

关键在于准备工作并不局限于单一的连续间隔。 您可以在考试之间的任何空闲时间学习，但绝不能在考试进行期间学习。 如果您在考试结束前至少积累了考试所需的学习时间，那么该考试的实际结束时间就会提前，从而在下一次考试开始之前创造更多的空闲时间。 

任务是决定要准备哪些考试，以便在将学习时间分配到所有可用间隙后，以“准备”版本结束的考试数量最大化。 

输入给出了按时间排序的一系列检查。 每项考试都有一个开始时间、一个缩短的结束时间（如果准备好了的话）、一个正常的结束时间，以及启用较短版本所需的学习时间。 由于考试永远不会按照给定的顺序重叠，因此空闲时间的结构完全取决于您缩短哪些考试的选择。 

微妙的困难在于，选择准备考试不仅会消耗学习时间，还会改变未来的可用性，因为它减少了考试占用时间的时间。 这种减少稍后会变得可用，因此决策是全局耦合的。 

对于多达 2000 次考试，三次或更差的策略是不可行的。 尝试所有准备好的考试子集的天真想法将是指数级的。 即使在子集上进行动态规划也是不可能的。 任何有效的解决方案都必须压缩状态，以便它只跟踪累积了多少可用的学习时间，而不是确切的历史记录。 

一个常见的失败案例是将准备视为独立的。 例如，假设每次考试只需要在任何较早的空闲时间间隔内花费 ai，就会忽略准备考试也会改变未来的空闲时间。 

考虑这种情况：

 输入```
2
0 5 10 5
10 20 30 5
```如果您同时准备两者，则可以减少两个持续时间，从而创造更多时间，从而有助于准备。 贪婪的“如果可能的话现在就选择”的方法会失败，因为早期的决定会影响以后的学习时间是否存在。 

另一个陷阱是假设所有学习都必须在考试开始之前完成。 实际上，学习时间可以在之前的所有间隙中累积，因此状态是累积的，而不是每次考试的局部状态。 

## 方法

 蛮力方法会尝试准备考试的每个子集。 对于固定的子集，我们模拟时间，跟踪间隙中积累了多少学习量，并检查每次选择的考试是否可以满足。 该模拟是线性的，但有 2ⁿ 子集，这使得即使对于较小的 n，该方法也完全不可行。 

这种蛮力在概念上起作用的原因是，一旦准备好的考试集确定，时间线就是确定的。 失败是组合爆炸：每次考试都会使可能性的数量加倍。 

关键的见解是，我们实际上不需要记住选择了哪些考试，只需要记住我们当前有多少可用的学习时间，以及当我们从一个考试转到下一个考试时，它是如何演变的。 问题的结构允许动态编程解释，其中状态是每个考试边界处的累积学习时间量，并且转换模拟准备或跳过当前考试。 

重要的观察结果是，所有相关的时间变化都是相加的，并且可以表示为单个标量资源的变化。 准备考试会消耗该资源的 ai 单位，但也会通过将考试缩短 (ei − pi) 来增加未来的可用时间。 这使得问题成为一个类似背包的动态规划，其中物品既消耗资源又生成资源。 

我们将跟踪学习时间限制为 n，因为我们永远无法准备超过 n 场考试，因此超过 n 单位的松弛对于计算可以完成多少考试毫无用处。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力子集 | O(2ⁿ·n) | O(2ⁿ·n) | O(n) | 太慢了 |
 | 动态规划| O(n²) | O(n²) | 已接受 |

 ## 算法演练

 我们按时间顺序处理考试，并在每次考试前根据目前可用的学习时间制定 DP。 

每个 DP 状态代表我们在前 i 次考试中已经可以充分准备的最大考试数量，前提是我们在达到考试 i 时有一定的累积学习时间。 

1. 在第一次考试前初始化DP。 此时，还没有积累任何学习，也没有完成任何考试，因此唯一有效的状态是零可用学习时间和零准备的考试。 
2. 对于每次考试 i，首先计算上一次考试结束与当前考试开始之间的时间间隔。 任何现有的 DP 州都会获得与该差距相等的额外免费学习时间，因为这是可以不间断学习的时间。 
3. 考虑到差距后，我们考虑考试 i 的两种选择。 第一个是不准备。 在这种情况下，我们只是将当前可用的学习时间结转，因为我们没有花费任何东西，并且考试将持续到其完全结束时间，从而相应地影响下一个间隙。 
4. 第二个选择是准备考试 i。 这要求当前状态至少有ai单位的可用学习时间。 如果是这样，我们从状态中减去 ai，并将成功准备的考试数量加一。 
5. 如果我们准备考试 i，以后我们还会获得额外的空闲时间，因为考试在 pi 而不是 ei 结束。 此差异 (ei − pi) 将添加到未来转换的可用学习时间中，因为该时间在下一次考试开始之前即可使用。 
6. 评估完这两个选择后，我们将进入下一次考试，继续所有更新的 DP 状态，再次按可用学习时间进行索引。

DP 表被截断，以便学习时间永远不会超过 n，因为超过 n 单位的空闲时间无法提高准备考试的数量。 

### 为什么它有效

 在每个考试边界，DP 状态准确捕获仍然可以在未来考试中重新分配的学习时间量。 任何两个导致相同可用学习时间的历史都是可以互换的，因为未来的决策只取决于仍然可以花费多少学习时间，而不取决于如何获得学习时间。 

这种转变正确地模拟了时间的节约：间隙增加了可用时间，准备消耗了它，而成功的准备通过缩短考试来产生额外的未来间隙。 由于每个转换都是线性的并且对于相邻检查而言是局部的，因此通过将历史压缩为单个标量状态不会丢失任何隐藏的依赖性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    exams = []
    for _ in range(n):
        s, p, e, a = map(int, input().split())
        exams.append((s, p, e, a))
    
    CAP = n
    
    dp = [-10**9] * (CAP + 1)
    dp[0] = 0
    
    prev_end = 0
    
    for i in range(n):
        s, p, e, a = exams[i]
        
        gap = s - prev_end
        
        ndp = [-10**9] * (CAP + 1)
        
        for t in range(CAP + 1):
            if dp[t] < 0:
                continue
            
            nt = t + gap
            if nt > CAP:
                nt = CAP
            
            best = dp[t]
            
            ndp[nt] = max(ndp[nt], best)
            
            if t >= a:
                nt2 = t - a + (e - p)
                nt2 += gap
                if nt2 > CAP:
                    nt2 = CAP
                ndp[nt2] = max(ndp[nt2], best + 1)
        
        dp = ndp
        prev_end = e
    
    print(max(dp))

if __name__ == "__main__":
    solve()
```DP阵列对于每个可能的累积学习时间量存储已成功准备的考试的最大数量。 关键的实施细节是，我们首先吸收考试之间的时间间隙，然后再为当前考试应用过渡。 

当我们跳过考试时，除了添加间隙之外，我们会保持状态不变。 当我们准备它时，我们确保我们有足够的学习时间，减去它，加上缩短考试的收益，然后加上差距贡献。 最终的答案是所有可达的 DP 状态中最好的值。 

一个常见的错误是忘记了间隙必须应用于两个分支，因为两个选择都会到达下一个考试边界。 另一个问题是未能限制 DP 状态，从而限制了复杂性。

 ## 边缘情况

 A key edge case occurs when gaps are exactly zero or very small. In that situation, all feasibility depends entirely on whether previous exams were prepared, since no external study time is generated.

 例如：```
2
0 1 2 2
2 3 4 2
```由于时间积累不够，第一次考试无法准备，第二次考试也变得不可能。 DP 始终正确地将状态保持为零，从不发明空闲时间。 

另一个边缘情况是，准备考试所需的时间超出了未来决策所需的时间。 DP 将累积学习时间限制为 n，确保多余的松弛不会使状态空间膨胀或在等效配置之间产生人为差异。 

这保证了即使输入中出现像 10⁹ 这样的大值，DP 仍保持稳定且有界。
