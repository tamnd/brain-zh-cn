 ## 解决方案
 ## 问题理解

 我们得到两个由 0 和 1 组成的序列：`a`长度`n`和顺序`b`长度`m`。 我们想要转型`a`进入`b`使用只能修改前两个元素的两个操作`a`然后删除第一个元素。 操作 1 将第二个元素替换为前两个元素中的最小值，操作 2 将其替换为最大值。 每次操作后，第一个元素`a`被删除，有效地向前滑动序列。 

输入由多个测试用例组成，每个测试用例指定长度和序列。 如果我们可以转换，输出为“YES”`a`进入`b`，否则“否”。 最大长度为`a`和`b`是 50，测试用例的数量可以达到 2000。这些界限表明我们可以提供一个对每个测试用例的序列进行简单线性扫描的解决方案，因为 O(n·t) 最多可以进行 100,000 次操作，完全在时间限制内。 

一个微妙的点是，由于操作仅影响前两个元素，因此最后一个元素`b`必须匹配中的某些元素`a`可以通过操作传播到最后一个位置。 另一个棘手的边缘情况发生在`b`只有一个元素长。 在这种情况下，我们只需要检查最后一个元素`a`可以匹配`b[0]`并且在序列的早期存在一些灵活性，可以为`b[0]`。 

## 方法

 最简单的方法是模拟每个可能的操作序列。 开始于`a`并在每一步尝试这两种操作，直到`a`比赛`b`否则这将变得不可能。 这是可行的，因为每个测试用例的操作数最多为`n-1`每个操作都是 O(1)。 然而，操作序列的数量呈指数增长，这对于n=50来说是不可行的。 

关键的见解是我们不需要模拟每个操作序列。 仅最后一个元素`b`需要精确的最后一个元素`a`滑动后，所有前面的元素只需要满足一个条件：序列必须同时包含`0`和`1`某处如果`b[-1]`与之前的元素不同。 更具体地说，产生一个`0`或者`1`在最后一个位置`b`, 必须存在至少一个`0`和一个`1`在前缀中`a`这可以在操作过程中影响第二个元素。 这将问题减少到检查最后一个元素并验证序列是否至少包含一个`0`和一个`1`如果`m>1`。

 | 蛮力 | O(2^(n-m) * m) | O(2^(n-m) * m) | O(n) | 太慢了|
 | 最佳 | 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 识别最后一个元素`b`，称之为`b_last`。 该元素必须与中的某个元素匹配`a`滑动操作后。 由于我们重复删除第一个元素，因此只需检查是否`a[n-m]`（与第一个元素对齐的元素`b`）可用于产生`b_last`后`m-1`运营。 
2. 检查最后一个元素`a`等于最后一个元素`b`。 如果不是，立即打印“NO”，因为没有任何操作序列可以更改最后一个元素`a`全部拆除后。 
3. 对于序列`b`长于 1，确保第一个中的某处`n-1`的元素`a`至少存在一个元素等于`b[-2]`。 这保证了操作可以向前传播必要的值。 如果这样的元素不存在，则打印“NO”。 
4. 如果两项检查均通过，则打印“YES”。 

为什么有效：操作可以最小化或最大化第二个元素，这意味着任何两个连续的元素都可以相互影响。 最后一个元素`b`必须已经存在于正确的相对位置`a`。 如果`m>1`，传播值的灵活性来自于至少有一个元素的存在，该元素可以强制最小值或最大值匹配 的倒数第二个元素`b`。 其他约束都不重要，因此该检查充分表征了转换的可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    a = input().strip()
    b = input().strip()
    
    if a[n - m] != b[0]:
        print("NO")
        continue
    
    if m == 1:
        print("YES")
        continue
    
    # Check if there is any element in a[0:n-1] that equals b[1]
    possible = '1' if b[1] == '1' else '0'
    if possible in a[:n-1]:
        print("YES")
    else:
        print("NO")
```我们首先对齐`a`和`b`这样第一个元素`b`对应于`a[n-m]`。 对于长度为 1 的序列，只有比对很重要。 对于较长的序列，我们检查前缀中是否存在合适的元素来传播所需的值。 切片`a[:n-1]`确保我们不会意外检查最后一个元素，该元素已被保留用于匹配`b[-1]`。

 ## 边缘情况

 如果`b`长度为 1，如果最后一个元素的算法正确返回 YES`a`比赛`b[0]`，无论前缀如何。 例如，输入：```
1
5 1
10101
1
```这里`b`长度为 1。`a[n-1]=a[4]='1'`比赛`b[0]`，所以输出为 YES。 无需进一步检查。 

如果最后一个元素无法匹配，例如：```
1
5 1
10101
0
```

`a[4]='1' != b[0]='0'`立即触发“否”，表明该算法无需进行不必要的计算即可处理边界不匹配。
