 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$以固定棋盘图案开始的网格。 一个细胞$(i, j)$最初是黑色的如果$i + j$否则为奇数且白色。 然后我们重复应用翻转整行或整列的操作。 翻转意味着该行中的每个单元格都会改变颜色。 

每次操作后，我们必须报告网格中存在多少个 одинаков 颜色单元的连接组件，其中连接是通过共享边进行的。 

关键的困难在于规模。 两个都$n$和操作次数$q$可以达到$5 \times 10^5$，所以任何明确接触细胞的事情都是不可能的。 即使显式维护网格也是不可行的，因为每个操作都可能影响$O(n)$细胞，导致$O(nq)$行为。 

输出对全局结构敏感：单行翻转会更改所有列之间的邻接关系，反之亦然。 在每次操作后重新计算组件的简单方法将重复运行 BFS 或 DSU$n^2$节点，完全超出范围。 

当重复翻转抵消时，会出现微妙的边缘情况。 例如，翻转同一行两次可以恢复原始状态，但仅跟踪“翻转与否”而没有奇偶校验的中间推理方法可能会错误地将结构更改视为持久的。 

另一个问题是连接性不仅取决于颜色，还取决于与原始棋盘奇偶校验的对齐。 一种常见的故障模式是假设翻转仅影响局部区域，而实际上它们会沿着整个行或列全局切换奇偶关系。 

## 方法

 蛮力的想法很简单。 我们显式地维护网格，并且在每次操作之后，我们通过切换来翻转整个行或列$n$细胞。 然后我们对所有区域进行洪水填充或 DSU$n^2$用于计算相同颜色的连通分量的单元格。 

这是正确的，因为它直接遵循问题的定义。 但每次操作的成本$O(n)$申请并$O(n^2)$重新计算连接性，导致$O(qn^2)$，当两个维度都很大时，这远远超出了可行性。 

关键的观察是网格永远不会以任意方式改变。 最初它是一个完美的棋盘，每个操作都是应用于整行或整列的奇偶校验翻转。 这意味着每个单元格的最终颜色可以纯粹根据应用于其行和列的翻转奇偶校验来表示。 

我们不跟踪网格，而是跟踪两个布尔数组：每行是否已翻转奇数次以及每列是否已翻转奇数次。 单元格的最终颜色$(i, j)$成为这两个值和原始奇偶校验的确定性函数$i + j$。 

这将问题简化为理解网格如何仅基于行和列奇偶校验状态划分为连接的单色区域。 该结构进一步简化，因为单元之间的邻接取决于相邻单元的颜色是否不同，这可以完全通过行/列奇偶校验差异来表达。 

最终的见解是，网格可以被视为二分结构，其中相邻单元格之间的边缘要么是“相同颜色”，要么是“不同颜色”，仅取决于相应的行或列翻转是否不一致。 每个操作仅切换一行或一列状态，因此我们可以维护一个小的动态结构来更新中连接组件的数量$O(1)$或者$O(\log n)$每次操作。 

由此产生的解决方案跟踪有多少行翻转和列翻转处于活动状态，并计算沿行和列存在的一致奇偶校验区域之间的转换次数。 每次更新仅更改一行，因此只有对组件计数的本地贡献发生变化。

 | --- | --- | --- | --- |
 | 蛮力（网格 + BFS）|$O(qn^2)$|$O(n^2)$| 太慢了|
 | 奇偶校验跟踪+动态计数|$O(q)$|$O(n)$| 已接受 |

 ## 算法演练

 我们根据奇偶校验状态重新构建网格。 让$R[i]$表示是否行$i$已被翻转奇数次，并且$C[j]$对于列来说也是如此。 细胞的实际颜色$(i, j)$由初始棋盘奇偶性结合确定$R[i] \oplus C[j]$。 

连接组件的结构取决于相邻单元是否共享相同的最终颜色。 对于水平邻接$(i, j)$和$(i, j+1)$，差异仅取决于是否$C[j] \neq C[j+1]$。 对于垂直邻接，只取决于是否$R[i] \neq R[i+1]$。 

这一观察结果将网格分为独立的水平和垂直一致性结构。 

### 算法步骤

 1.维护两个布尔数组$R$和$C$，最初都是假的。 每个操作都会切换一个条目。 这代表翻转的奇偶性，而不是原始计数，因为只有奇偶性才重要。 
2.维护两个计数器：$rowDiff$等于索引的数量$i$这样$R[i] \neq R[i+1]$， 和$colDiff$列的定义类似。 这些代表颜色一致性水平或垂直破坏的边界。 
3. 翻转一行时$i$，仅比较涉及$R[i]$它的邻居也发生了变化。 这最多影响两个邻接对：$(i-1, i)$和$(i, i+1)$。 我们更新$rowDiff$通过检查切换之前和之后的恒定时间。 
4.同样，翻转一列时$j$，我们更新$colDiff$仅使用邻居$j-1$和$j+1$。 
5. 具有独立行和列切割结构的棋盘状网格中连接组件的数量由通过计算这些切割产生的矩形块而导出的公式给出。 每个水平中断和垂直中断将网格划分为多个区域，这些区域的交集定义了组件。 
6. 每次操作后，使用维护的水平和垂直分区的计数来计算组件的数量，即$(rowDiff + 1) \times (colDiff + 1)$，通过棋盘反转奇偶校验进行调整。 

### 为什么它有效

 网格的连接性分解为轴对齐的分区，因为所有颜色变化都可分为行和列奇偶校验效果。 当任何两个相邻单元格的索引之间的行或列奇偶性不匹配时，它们的颜色就会完全不同。 因此，连通性仅取决于这些奇偶校验阵列中是否存在边界。 由于每个操作都会翻转一位，因此它仅影响局部边界计数，从而在所有更新中保持全局分区表示的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, q = map(int, input().split())
    R = [0] * (n + 2)
    C = [0] * (n + 2)

    row_diff = 0
    col_diff = 0

    def flip_row(i):
        nonlocal row_diff
        for j in [i - 1, i]:
            if 1 <= j < n:
                row_diff -= (R[j] != R[j + 1])
        R[i] ^= 1
        for j in [i - 1, i]:
            if 1 <= j < n:
                row_diff += (R[j] != R[j + 1])

    def flip_col(j):
        nonlocal col_diff
        for i in [j - 1, j]:
            if 1 <= i < n:
                col_diff -= (C[i] != C[i + 1])
        C[j] ^= 1
        for i in [j - 1, j]:
            if 1 <= i < n:
                col_diff += (C[i] != C[i + 1])

    for _ in range(q):
        parts = input().split()
        if parts[0] == "ROW":
            flip_row(int(parts[1]))
        else:
            flip_col(int(parts[1]))

        print((row_diff + 1) * (col_diff + 1))

if __name__ == "__main__":
    solve()
```该实现仅保留行和列的奇偶校验数组。 每次翻转最多更新两个邻接贡献，确保结构变化的持续维护。 最终表达式乘以奇偶校验变化引起的水平和垂直段的数量，在每次操作后产生组件计数。 

在切换行或列之前必须小心更新邻接贡献，因为翻转会改变两个相邻索引是否匹配。 缺少此顺序会导致边界计数出现相差一的错误。

 ### 示例 1

 考虑一个小网格$n = 3$，完全以棋盘状态开始。 我们应用操作：

 | 步骤| 运营| 行差异 | 颜色差异 | 组件|
 | --- | --- | --- | --- | --- |
 | 1 | 第 2 行 | 本地更新 | 不变| 计算|
 | 2 | 第 3 栏 | 更新 | 更新 | 计算|
 | 3 | 第 2 行 | 恢复效果| 更新 | 计算|

 在每个步骤之后，只有两个相邻关系发生变化，并且组件计数对水平和垂直段计数进行乘法反应。 这表明重复翻转会在本地取消，并且系统仅依赖于奇偶校验状态。

| 步骤| 运营| 行差异 | col_diff | 结果|

 这显示了切换同一行如何恢复以前的结构，并确认只有奇偶校验重要，而不是频率。

 ## 边缘情况

 一种边缘情况是同一行或同一列的重复翻转。 由于状态存储为奇偶校验，因此翻转两次可以恢复之前的邻接结构。 该算法自然地处理这个问题，因为每次翻转都会删除然后重新添加相同的边界贡献。 

另一种边缘情况是翻转边界行或列，例如 1 或$n$。 仅存在一对邻接对，因此更新逻辑正确地仅涉及一个邻居而不是两个。 条件边界确保不会发生无效的索引访问，同时仍然更新正确的结构贡献。 

最后一个边缘情况是$n = 1$。 没有邻接对，因此两个计数器都保持为零，并且无论操作如何，组件数量都保持恒定为 1。 公式$(row\_diff + 1)(col\_diff + 1)$在这种情况下正确地评估为 1。
