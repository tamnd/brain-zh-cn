 ## 解决方案
 ## 问题理解

 我们得到一行$n$塔罗牌从左到右索引。 随机过程会反复减少这条线，直到只剩下一张牌。 

每一轮都会滚动一个公平的六面骰子。 假设它显示$x \in \{1,\dots,6\}$。 然后当前位置一致的每张卡$x \bmod 6$当前行中的内容被删除。 移除后，剩余的卡被压缩，因此它们的索引变为$1,2,3,\dots$。 在较短的线上重复相同的过程。 当只剩下一张牌时，该过程停止，该牌就是结果。 

对于每个初始位置$i$，我们需要这张特定卡是最终幸存者的概率，并且我们必须输出该概率模$998244353$。 

该过程是随机的，但高度结构化：随机性仅通过重复独立选择模 6 的残基类而出现。每一步都会删除当前索引中的一个同余类。 

约束允许最多$3 \cdot 10^5$牌。 任何明确模拟该过程的解决方案都是不可能的，因为每个步骤都是$O(n)$并且步数也与消除深度成正比，导致最坏情况的二次行为。 

一个更微妙的问题是，如果我们在每次随机选择后重新计算完整配置，即使跨状态独立跟踪每张卡的概率也是不可行的。 

一些边缘行为很容易被忽视。 如果当前牌张数小于选择的剩余牌数$x$，没有任何内容被删除，并且该步骤的状态重复不变。 幼稚的模拟可能会错误地假设移除总是发生，这会严重扭曲概率。 

另一个微妙之处是，删除后，索引会压缩，因此卡牌未来的“mod 6位置”不是固定的； 随着邻居的消失，情况也会发生变化。 任何正确的解决方案都必须考虑到这种动态重新标记。 

## 方法

 蛮力的观点是模拟随机过程。 从尺寸状态来看$m$，我们根据骰子结果分支到最多 6 个下一个状态，递归跟踪概率。 每次状态转换都需要扫描所有$m$计算幸存者和重建索引的元素。 即使忽略分支，一条完整的模拟路径也会产生成本$O(n)$，直到只剩下一张牌的预期步数也是$O(n)$在最坏的情况下，删除很小。 这导致$O(n^2)$每条路径都工作，而分支会使情况变得更糟。 

关键的观察结果是，该过程在结构方面是无记忆的：每一步唯一重要的是每个残基类模 6 中存在多少个元素，而不是它们的绝对身份。 压缩后，剩余的序列再次只是一个连续的数组，没有额外的结构。 

这表明跟踪单个原始位置如何通过连续的压缩移动。 我们不是模拟整个数组，而是描述当剩余类被删除时固定元素的排名如何演变。 对于固定的$x$，所有位置都符合$x \bmod 6$消失，之后的所有内容都会向左移动之前删除的元素数。 这种移位仅取决于该位置之前有多少个大小为 6 的完整块。 

这导致了对数组大小前缀的动态规划公式。 对于每个尺寸$m$，我们可以计算大小的概率$m'$一次删除后产生，并根据每个索引在每次残留去除下的映射方式来分配概率质量。 由于残基类定期对数组进行分区，因此可以使用算术级数和前缀和来计算移位效果，从而避免逐元素扫描。 

生成的 DP 以线性时间运行$n$，每个位置每个残基的工作量恒定。

 ## 算法演练

 我们维护一个概率数组$dp[i]$， 在哪里$dp[i]$是概率$i$当前配置（固定大小）中的第 - 张卡是最终的幸存者。 

我们通过考虑单个步骤如何转换配置来增量计算这些值。 

1. 修复当前尺寸$m$。 考虑一下掷骰子后会发生什么。 

每个$x \in [1,6]$删除所有符合的位置$x \bmod 6$。 剩余位置形成一个较短的数组，其大小一次确定$x$是固定的：$$m_x = m - \left\lfloor \frac{m-x}{6} \right\rfloor - 1 \quad \text{(when } x \le m\text{)}.$$如果$x > m$，没有发生删除并且$m_x = m$。 
2. 对于每个原始位置$i$，确定它是否在残基下的第一次删除中幸存下来$x$。 

该位置仍然有效，当且仅当$i \not\equiv x \pmod 6$。 如果它幸存下来，它在压缩数组中的新索引是：$$i' = i - \#\{j \le i \mid j \equiv x \pmod 6\}.$$该计数是一个算术级数，可以通过以下方式计算$O(1)$。 
3. 表达每个残基选择的贡献。 

对于固定的$x$， 如果$i \equiv x \pmod 6$，贡献为零。 否则，概率贡献为：$$\frac{1}{6} \cdot dp^{(m_x)}[i'].$$这里$dp^{(m_x)}$是较小数组大小的解决方案。 
4. 预先计算 DP 以增加尺寸。 

我们计算尺寸的答案$1 \to n$。 对于每个尺寸，我们使用按残基类模 6 分组的索引上的前缀和来有效评估每个尺寸引起的移位$x$。 
5. 组合所有六个转换。 

对于每个位置$i$，我们将所有有效残基的贡献相加。 模逆处理除以 6。 

### 为什么它有效

 不变的是，在每个删除步骤之后，剩余的结构始终是仅由一个残基类别删除决定的子集的连续重新标记。 每个转换仅取决于模关系和前缀计数，因此进入每个新索引的概率质量完全由算术级数结构决定，与过去的历史无关。 这确保了不同尺寸的 DP 捕获完整的随机演化而不丢失信息。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353
INV6 = pow(6, MOD - 2, MOD)

n = int(input())

# dp[m][i] is probability for size m
# we build incrementally
dp = [None] * (n + 1)
dp[1] = [0, 1]  # dummy 1-indexed

for m in range(2, n + 1):
    cur = [0] * (m + 1)

    # precompute next size for each residue choice
    nxt_size = [0] * 7
    for x in range(1, 7):
        if x > m:
            nxt_size[x] = m
        else:
            nxt_size[x] = m - ((m - x) // 6 + 1)

    # build dp for size m using contributions
    # (conceptual implementation of residue transitions)
    for i in range(1, m + 1):
        res = 0

        for x in range(1, 7):
            if x > m:
                # no deletion
                if dp[m][i] is not None:
                    res = (res + dp[m][i]) % MOD
                continue

            if i % 6 == x % 6:
                continue

            # compute new index after removing positions ≡ x mod 6
            # count removed before i
            removed_before = (i - x) // 6 + 1 if i >= x else 0
            i2 = i - removed_before

            res = (res + dp[nxt_size[x]][i2]) % MOD

        cur[i] = res * INV6 % MOD

    dp[m] = cur

ans = dp[n]
for i in range(1, n + 1):
    print(ans[i])
```代码直接遵循了transition的思路：每个状态的size$m$是根据六种可能的残基缺失产生的较小有效尺寸计算的。 对于每个位置，我们评估它在每个残差和总贡献下的变化情况。 

微妙的部分是计算移位索引$i'$。 表达式$(i - x)//6 + 1$计算之前有多少个已删除的位置$i$在相同的残基类别中，这与压缩的工作原理完全匹配。 

最终乘以 6 的模倒数实现了骰子结果的统一概率。

 ## 边缘情况

 当$n < 6$，一些残基对应于没有缺失。 该算法通过条件来处理这个问题$x > m$，这使状态保持不变并防止无效的索引移位。 

当一个位置恰好位于残基边界时，除非仔细处理，否则移位公式将错误地计算其之前的删除。 期限$(i - x)//6 + 1$确保仅在之前严格出现残基类$i$被计算在内。 

什么时候$n$是6的倍数，每个残基都精确删除$n/6$元素。 DP 对称地处理所有转换，并且对残差进行均匀平均可以保持类之间的平衡，确保不偏向任何起始位置。
