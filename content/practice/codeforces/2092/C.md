 ## 解决方案
 ## 问题理解

 我们得到了一系列塔，每个塔都有正整数高度，代表亚丝娜崇拜者的礼物。 亚丝娜将自己的礼物的美丽程度评价为最高塔的高度。 她可以重复执行一项操作：选择两座高度总和为奇数的塔，并将一个单位从一座塔转移到另一座塔，不让任何一座塔变为负值。 目标是在根据需要多次应用此操作后确定最大可能的美感。 

输入由多个测试用例组成。 每个测试用例指定塔的数量及其高度。 每个测试用例的输出都是一个整数：可实现的最大美感。 

限制因素很大。 所有测试用例中多达 200,000 个塔，每个高度高达$10^9$，任何模拟单独操作的方法都是不可行的。 简单的模拟最多可以执行$10^9$每对操作，这永远不会适合 2 秒的时间限制。 这迫使我们寻找数学模式而不是字面模拟。 

当所有塔具有相同的奇偶校验时，就会出现边缘情况。 例如，如果所有塔的高度都是偶数，则没有任何对的总和为奇数。 这种情况下根本无法进行操作，美的简直就是最大塔高。 相反，如果至少有一座偶数塔和一座奇数塔，则该操作可以在它们之间转移单位。 另一个微妙的情况是当只有一座塔时 - 无法进行任何操作，而最大的美感就是那座塔。 

## 方法

 强力方法将迭代所有的塔对，检查奇偶校验条件，并执行操作，直到没有有效的塔对为止。 这将需要嵌套循环，并且在最坏的情况下可能需要数亿次操作，这使得它不切实际。 

关键的观察结果是该操作保留了所有塔高度的总和。 它还允许我们在相反奇偶校验的塔之间重新分配单位。 因此，阻止我们最大化单个塔的高度的唯一限制是奇偶性：如果所有塔具有相同的奇偶性，则不可能进行重新分配，并且最大塔保持不变。 如果同时有奇数和偶数塔，我们可以移动单位，使所有高度单位累积在一个塔中。 在这种情况下，最大的美感就是所有塔楼高度的总和。 

最佳解决方案只是检查塔的奇偶性。 如果两个奇偶校验都存在，则返回所有高度的总和。 否则，返回最大高度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 × max(a_i)) | O(n^2 × max(a_i)) | O(n) | 太慢了|
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取塔的数量`n`和高度数组`a`。 
2.初始化两个标志，`has_odd`和`has_even`，跟踪奇数和偶数高度的存在。 
3. 迭代数组`a`。 对于每个高度，更新`has_odd`如果高度是奇数，并且`has_even`如果高度均匀的话。 
4. 计算所有高度的总和，`total`。 
5. 如果两者都`has_odd`和`has_even`为真，输出`total`作为最大的美丽。 否则，输出`max(a)`。 

为什么它有效：在允许的操作下，所有高度的总和是不变的。 该操作只能发生在奇数塔和偶数塔之间。 如果两个奇偶校验都存在，则单位可以在塔之间自由转移，从而允许一个塔累积全部总和。 如果所有塔都具有相同的奇偶性，则无法进行任何操作，并且最大的美感就是现有的最大塔。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    has_odd = has_even = False
    total = 0
    for x in a:
        total += x
        if x % 2 == 0:
            has_even = True
        else:
            has_odd = True
    
    if has_odd and has_even:
        print(total)
    else:
        print(max(a))
```代码首先读取测试用例的数量。 对于每个测试用例，它都会跟踪塔高度的奇偶性并计算总和。 使用布尔标志可确保我们有效地检测两个奇偶校验的存在，而无需额外的数据结构。 仅当可以重新分布时才使用高度总和。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        has_odd = has_even = False
        total = 0
        for x in a:
            total += x
            if x % 2 == 0:
                has_even = True
            else:
                has_odd = True
        if has_odd and has_even:
            output.append(str(total))
        else:
            output.append(str(max(a)))
    return "\n".join(output)

 ## 边缘情况

 对于单塔`[7]`，不存在任何操作。 该算法检测到仅存在一个奇偶校验并返回`7`，这是正确的。 

对于所有偶数塔的数组`[2, 4, 6]`，没有奇数，因此无法进行任何操作。 算法正确输出`6`。 

对于混合数组`[2, 2, 2, 3]`，双方都存在。 总和`2+2+2+3 = 9`返回，表明所有单位都可以累积在一座塔中。 

对于大高度`[999999999, 1]`, 双方都存在, 总和`1000000000`返回时没有溢出。 

这些示例证实该算法正确识别何时可以重新分配以及何时最大值受奇偶校验限制。
