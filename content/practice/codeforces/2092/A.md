 ## 解决方案
 ## 问题理解

 我们得到了一份羊名单，每只羊都有不同的美丽程度。 卡米尔卡可以给每只羊喂食相同数量的额外草束，有效地将所有美丽等级提高相同的整数$d \ge 0$。 在这次喂食之后，她必须选择恰好两只羊，她得到的快乐就是它们所得到的美丽水平的最大公约数（GCD）。 任务是最大化这个 GCD。 

输入由多个测试用例组成，每个测试用例指定$n$，羊的数量，其次是$n$代表美丽级别的不同整数。 每个测试用例的输出是一个整数 - 可实现的最大 GCD。 

限制条件适中：$n$最高可达100，美丽等级最高可达$10^9$，并且最多有 500 个测试用例。 因为$n$很小，算法具有$O(n^2)$每个测试用例的时间是可行的，但是暴力尝试测试每个$d$最多$10^9$是不可能的。 

关键的边缘情况包括只存在两只羊的场景，这迫使我们仔细考虑它们之间的差异。 另一个边缘情况是当美丽水平已经互质时； 添加制服$d$可能是提高 GCD 的唯一方法。 例如，对于输入`2\n1 3\n`，选择$d=1$产生 GCD 2，这是最优的。 一种幼稚的方法，忽略了添加制服的可能性$d$会错误输出1。 

## 方法

 蛮力方法很简单：对于每一个可能的$d$，计算所有最终的美丽级别并检查每对的 GCD。 这是正确的，因为它测试了所有可行的喂养方式，但在实践中完全失败了，因为$d$可以非常大，最多$10^9$，使其不可行。 

关键的见解是考虑 GCD 在均匀加法下的表现。 让选中的两只羊有颜值$x$和$y$。 添加后$d$，他们的值变成$x+d$和$y+d$，两者的 GCD 为$\gcd(x+d, y+d)$。 根据 GCD 的性质，可以简化为$\gcd(x+d, y+d) = \gcd(x - y, y + d)$。 这意味着可实现的最大 GCD 始终是某个差异的除数$y - x$。 

因此，而不是迭代$d$，我们可以迭代所有成对的羊并计算它们美丽程度的差异。 对于每一个差异$diff = y - x$, 的所有约数$diff$是候选最大 GCD。 然后，对于每个候选除数，我们检查是否存在$d$这样，将它加到所有羊上就会产生两个可被除数整除的数字。 因为我们随时可以转变$d$为了使较大的数字能够被除数整除，两只羊之间的任何差异的最大除数总是可以实现的。 因此，最优策略简化为找到任意两只羊之间的最大差异并取其除数。 

这导致了一个简单而有效的$O(n^2)$算法：迭代所有成对的羊，计算它们的差异，并记录最大差异。 最大差值的最大除数就是答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 * 最大(a_i)) | O(n) | 太慢了 |
 | 最佳 | O(n^2) | O(n^2) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取羊的数量$n$以及她们的美丽水平$a$。 
2. 初始化变量`max_beauty`达到最高的美容水平和`min_beauty`到最低限度。 区别`max_beauty - min_beauty`给出任意两只羊之间的最大差距。 
3. 卡米尔卡所能获得的最大乐趣正是这种差异，因为我们可以选择$d = max_beauty - max(a_i)$移动数字并使 GCD 等于差值。 
4. 打印该值作为测试用例的答案。 

为什么它有效：添加相同的$d$对所有数字并不会改变数字之间的差异。 两个数相加后的 GCD$d$总是可以通过取最大数和最小数之间的差来最大化。 因为美丽程度的差异决定了所有可能的GCD，全局最大值就是最大的差异本身。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    max_a = max(a)
    min_a = min(a)
    print(max_a - min_a)
```该解决方案使用有效地读取输入`sys.stdin.readline`，提取羊的数量及其美丽程度，计算最大和最小美丽程度，并输出差值。 这是有效的，因为差异捕获了添加合适的 GCD 后可实现的最大 GCD$d$。 该解决方案避免了不必要的计算，并且可以在所有约束下工作。

import sys, io

def run(inp: str) -> str:

    t = int(input())

 ## 边缘情况

 如果所有的羊都具有相同的美丽，那么差异为零。 例如，输入`3\n7 7 7`产生输出`0`。 该算法正确地识别了这一点，因为`max(a) - min(a)`是 0。 

如果只有两只羊，输入`2\n1 2`，差值是1。添加$d$不会将 GCD 增加到超过 1，因为数字是连续的； 该算法通过计算来处理这个问题`max(a)-min(a)`直接产生1。 

如果美丽水平涵盖整个范围，例如，`2\n1 1000000000`，算法计算`1000000000 - 1 = 999999999`高效且不会溢出，因为 Python 整数可以处理任意大的值。 

该方案简单、高效，并且直接利用了均匀加法下GCD最大化由最大差值决定的数学性质。
