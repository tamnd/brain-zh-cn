 ## 问题理解

 我们给定两个长度相等的比特串，`a`和`b`，代表密码。 Lady Bug 想要变换第一个字符串`a`以便它只包含零。 她可以在两个字符串的相邻元素之间执行一系列交换操作，特别是交换`a[i]`和`b[i-1]`或者`b[i]`和`a[i-1]`为了`i`从 2 到`n`。 目标是确定在任意次数的此类交换之后，字符串是否`a`可以变成全零。 

每个测试用例都给我们`n`，字符串的长度，后跟两个字符串本身。 测试用例的数量可以高达 10,000 个，并且所有测试用例的所有字符串长度总和不超过 200,000。 这意味着我们需要一个大致线性的解决方案`n`对于每个测试用例，否则对所有可能的交换进行强力模拟将会太慢。 

一个关键的边缘情况是当`a`是`1`和第一个元素`b`是`0`。 由于掉期仅涉及指数`i ≥ 2`，我们不能直接移动`1`在`a[1]`到`b[0]`或其他任何地方，这将使密码无法破解。 同样，如果`b`没有`1`s 任何可以到达的地方`1`在`a`，我们也失败了。 小的`n=2`情况很关键，因为只有少数交换可用，并且字符串可能立即无法解决。 

## 方法

 最简单的方法是模拟字符串之间所有可能的交换。 在每个索引处`i`，可以递归或迭代地尝试这两种操作，直到`a`变成全零或者所有的可能性都被耗尽。 这保证是正确的，但完全不切实际：状态数量呈指数增长`n`, 直至`2^n`，即使对于小数据，也远远超出了 1 秒的限制`n`。 

关键的洞察力是跟踪每个`1`在`a`可以“推”左`b`使用可用的掉期。 每次交换允许`1`在`a[i]`搬到`b[i-1]`或一个`1`在`b[i]`搬到`a[i-1]`。 这意味着如果我们从左到右扫描字符串，唯一的情况是`1`在`a`无法删除的是当有`1`在`a[i]`没有`1`在`b[i-1]`或者`b[i]`可以达到它。 本质上，每一个`1`在`a`在`i`必须有`b[i-1]`或后续的`b[j]`可以交换到那个位置。 

进一步的简化是，我们只需要统计总数`1`进入`a`和`b`。 对于字符串的每个前缀，累计的数量`1`进入`b`必须至少是累计数量`1`进入`a`。 如果在任何索引处累计`1`进入`a`超过那些在`b`，该过程失败，因为我们有太多`1`进入`a`无法移动的。 这将问题转化为单个线性扫描。

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`和琴弦`a`和`b`。 
3. 初始化两个计数器：`count_a`对于数量`1`进入`a`到目前为止所看到的，以及`count_b`对于数量`1`进入`b`到目前为止所看到的。 
4. 从左到右遍历字符串。 在每个索引处`i`, 增量`count_a`如果`a[i]`是`1`和`count_b`如果`b[i]`是`1`。 
5. 如果在任何时候`count_a`超过`count_b`，为此测试用例打印“NO”。 这表明还有更多`1`进入`a`比可以被“吸收”`b`直到这个指标。 
6. 如果迭代完成时没有`count_a > count_b`，打印“是”。 

为什么有效：每次交换只能移动一个`1`从`a[i]`到`b[i-1]`或来自`b[i]`到`a[i-1]`。 通过确保对于字符串的每个前缀，总数`1`进入`b`至少是`1`进入`a`，我们保证每个`1`在`a`最终可以被推入`b`使用允许的操作。 这种累积计数捕获了每个的可达性`1`无需模拟单独的交换。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = input().strip()
    b = input().strip()
    
    count_a = 0
    count_b = 0
    possible = True
    
    for i in range(n):
        if a[i] == '1':
            count_a += 1
        if b[i] == '1':
            count_b += 1
        if count_a > count_b:
            possible = False
            break
    
    print("YES" if possible else "NO")
```该代码使用有效地读取输入`sys.stdin.readline`。 它跟踪累计计数`1`两个字符串中都有 s。 循环检查是否在任何时候都有更多`1`进入`a`比可以匹配`b`。 尽早中断可以防止不必要的迭代。
