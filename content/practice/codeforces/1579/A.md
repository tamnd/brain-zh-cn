 ## 解决方案
 ## 问题理解

 我们得到一个仅包含字符的字符串`A`,`B`， 和`C`。 

我们可以一步删除其中一个`A`与一个`B`，或一个`B`与一个`C`。 删除的两个字符可以来自字符串中的任何位置。 

问题是是否可以重复执行此类删除，直到整个字符串消失。 

对于每个测试用例，我们必须打印`YES`如果某些有效的移动序列删除了每个字符，否则打印`NO`。 

限制很小。 每个字符串的长度最多为 50，并且最多有 1000 个测试用例。 即使是相对低效的方法也能轻松地适应限制。 挑战不是性能，而是发现决定是否可以完全删除的隐藏属性。 

有几种边缘情况很容易误判。 

考虑：```
AC
```正确答案是：```
NO
```一种天真的想法是，有一个`A`和一个`C`，所以也许他们会以某种方式间接取消。 他们不能。 每一个动作都需要一个`B`，并且该字符串不包含任何内容。 

另一个棘手的例子是：```
ABC
```正确答案是：```
NO
```我们可以删除其中一个`AB`然后离开`C`，或删除`BC`然后离开`A`。 在这两种情况下，一个角色永远存在。 

第三个例子是：```
ABBA
```正确答案是：```
YES
```删除两个`AB`pair 清空字符串。 只看字符串长度是否为偶数是不够的，因为许多偶数长度的字符串仍然会失败。 

## 方法

 暴力解决方案将尝试所有可能的删除顺序。 

在每一步中，我们可以选择任何有效的位置对，其中包含`A`和`B`， 或者`B`和`C`。 递归地探索所有可能性最终会告诉我们某些路径是否到达空字符串。 

这种方法是正确的，因为它明确地检查每个合法的游戏状态。 问题在于分支因素。 即使对于长度为 50 的字符串，在每个级别也可能有许多可能的对需要删除。 状态的数量呈指数级增长，并且很快就变得不切实际。 

要找到更简单的表征，请重点关注每个操作对字符数的影响。 

去除`A+B`减少的计数`A`和`B`一个。 

去除`B+C`减少的计数`B`和`C`一个。 

一个重要的观察结果是，每一步都会恰好删除一个`B`。 

如果该字符串最终被完全擦除，则每个`A`必须与一些配对`B`，以及每一个`C`还必须搭配一些`B`。 

假设计数为：```
A = a
B = b
C = c
```让`x`是`AB`搬迁和`y`是`BC`搬迁。 

为了消除所有`A`字符，我们需要：```
x = a
```为了消除所有`C`字符，我们需要：```
y = c
```每一个这样的操作都会消耗一个`B`，所以删除的总数`B`字符是：```
x + y = a + c
```为了消除所有`B`字符，我们必须有：```
b = a + c
```这个条件不仅是必要的，而且是充分的。 

如果`b = a + c`，简单地执行`a`删除类型`AB`和`c`删除类型`BC`。 由于位置并不重要并且可以选择任何匹配的字母，因此可以删除所有字符。 

整个问题简化为检查单个计数是否相等。

 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取字符串。 
2. 统计出现的次数`A`,`B`， 和`C`。 
3. 检查是否：```
count(B) = count(A) + count(C)
```这正是所有角色参与有效移除所需的条件。 
4. 如果等式成立，则打印`YES`。 
5. 否则，打印`NO`。 

### 为什么它有效

 每一个合法的动作都会消耗一个`B`。 删除全部`A`字符需要一个`B`对于每个`A`，并删除所有`C`字符需要一个`B`对于每个`C`。 因此，只有当`B`字符数等于总数`A`和`C`人物。 

相反，如果`count(B) = count(A) + count(C)`，那么每个`A`可以与独特的搭配`B`通过一个`AB`去除和每个`C`可以与独特的剩余配对`B`通过一个`BC`移动。 由于职位不受限制，因此不存在其他限制。 因此，平等既是必要的，也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    s = input().strip()

    a = s.count('A')
    b = s.count('B')
    c = s.count('C')

    print("YES" if b == a + c else "NO")
```实现直接遵循证明。 

首先我们统计每个字符出现的次数。 蟒蛇的`count()`方法完全足够，因为字符串非常短。 

唯一的决定是数量是否`B`字符数等于总和`A`和`C`人物。 如果是，我们打印`YES`; 否则我们打印`NO`。 

不存在索引问题，没有递归，也没有模拟删除。 证明表明，仅计数就可以完全确定答案。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline
    t = int(input())
    out = []

    for _ in range(t):
        s = input().strip()

        a = s.count('A')
        b = s.count('B')
        c = s.count('C')

        out.append("YES" if b == a + c else "NO")

    return "\n".join(out)

 ### 没有`B`人物

 输入：```

```计数：```

```这是错误的，所以它打印：```
NO
```这符合现实，因为每个操作都需要`B`。 

### 长度相等但不可能

 输入：```
1
ABC
```计数：```

B = 1
C = 1

```这是错误的，所以答案是：```
NO
```虽然一次去除后长度是均匀的，但不可能完全去除，因为单个`B`不能同时匹配两个`A`和`C`。
