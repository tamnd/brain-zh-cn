 ## 解决方案
 # 问题理解

 我们有一棵树`N`洞穴。 每个顶点包含一只狼蛛，并且每个狼蛛属于以下之一`K`亚种。 这些隧道形成一棵相连的树，因此任何两个洞穴之间都只有一条路径。 对于每个亚种，我们需要具有该亚种的两个顶点之间的最大距离。 如果一个亚种只出现一次，那么它的范围为零。 

输入大小达到`N = 200000`，因此检查所有狼蛛对的解决方案是不可能的。 具有所有顶点的单个亚种已经创建了大约`N^2 / 2`对，这远远超出了几秒钟内可以运行的范围。 我们需要一个接近线性或`N log N`，因为这样可以使操作数量保持在几百万左右。 

困难的部分是一个亚种的顶点不一定相连。 当整棵树是一组时，正常的树直径算法就起作用，但这里我们同时需要多个直径，每种颜色一个。 

考虑一些打破简单想法的案例。 如果每个狼蛛都有不同的亚种，则每个答案都必须为零。 例如：```
Input:
5 5
1 2 3 4 5
1 2
2 3
3 4
4 5

Output:
0
0
0
0
0
```假设每种颜色至少有两个顶点的解决方案将访问缺失的端点。 

第二个陷阱是一个亚种的顶点可以被其他亚种分开。 例如：```
Input:
5 2
1 2 1 2 1
1 2
2 3
3 4
4 5

Output:
4
2
```亚种一的三个顶点位于路径的两端和中间。 仅查看相邻的相同颜色会错过真实的直径。 

当质心使用不正确时，就会出现第三个问题。 质心的同一子子树中的两个顶点没有经过该质心的路径。 将它们通过质心的距离结合起来会高估真实距离。 

## 方法

 一种简单的方法是收集每个亚种的顶点并独立计算其直径。 对于一种颜色，我们可以选择任意顶点，运行树遍历以找到最远的顶点，然后从该顶点运行另一次遍历。 这是标准的两种 BFS 或 DFS 直径方法。 这是正确的，因为距离树的任何端点最远的顶点都包含直径端点。 

问题是重复工作。 如果一个亚种包含所有`N`顶点，单个直径计算已经花费`O(N)`。 对许多亚种重复此操作可以达到`O(NK)`，如果颜色分布不好，就会变成`O(N^2)`。 

关键的观察是图是一棵树，因此质心分解可以划分工作。 质心将树分成更小的组件。 对于每个质心，路径穿过该质心的每对有效顶点都可以通过查看它们与质心的距离来评估。 分解保证每一对顶点都被认为恰好位于其路径分裂的一个质心处。 

对于一个质心，我们对其子组件进行一一处理。 对于每个亚种，我们都会记住之前组件中看到的最大距离。 当我们在当前组件中看到相同亚种的顶点时，将其与先前的最大值相结合会给出路径穿过质心的最佳对。 处理完所有子组件后，我们递归地求解每个剩余组件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(N²) | O(N) | 太慢了|
 | 质心分解| O(N log N) | O(N log N) | O(N) | 已接受 |

 ## 算法演练

 1. 构建树并存储属于每个亚种的顶点列表。 答案数组从零开始，因为少于两个顶点的颜色已经有了正确的答案。 
2. 找到当前树组件的质心。 质心是一个顶点，其移除后留下的组件不大于当前组件的一半。 
3. 将质心视为通过它的路径的一个可能端点。 为其自己的亚种存储距离零。 
4. 对于质心的每个相邻组件，运行 DFS 来收集该组件中的每个顶点及其距质心的距离。 收集时，将每个顶点与先前处理的组件中发现的相同亚种的最佳距离进行比较。 这是可行的，因为这两个顶点之间的路径必须经过质心。 
5. 将收集到的距离合并到存储的该质心的最佳距离中。 仅保持每个亚种的最大距离就足够了，因为通过质心的最后一对仅需要两个最大距离。 
6. 将质心标记为已删除，并对每个剩余组件递归应用相同的过程。 

为什么它有效：对于同一亚种的任何两个顶点，考虑分解中的第一个质心，其中两个顶点最终位于不同的剩余组件中，或者其中一个是质心。 他们的路径穿过该质心。 该算法在那一刻准确地检查这一对并正确地组合它们的两个距离。 由于每个可能的对都是在其分离质心处考虑的，因此最大发现值是该亚种的真实直径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(1 << 25)

def solve():
    n, k = map(int, input().split())
    color = list(map(int, input().split()))
    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        g[a].append(b)
        g[b].append(a)

    removed = [False] * n
    size = [0] * n
    ans = [0] * k
    best = [None] * n

    def calc_size(u, p):
        size[u] = 1
        for v in g[u]:
            if v != p and not removed[v]:
                size[u] += calc_size(v, u)
        return size[u]

    def find_centroid(u, p, total):
        for v in g[u]:
            if v != p and not removed[v] and size[v] > total // 2:
                return find_centroid(v, u, total)
        return u

    def collect(u, p, d, arr):
        arr.append((color[u], d))
        for v in g[u]:
            if v != p and not removed[v]:
                collect(v, u, d + 1, arr)

    def decompose(u):
        total = calc_size(u, -1)
        c = find_centroid(u, -1, total)

        current = {}
        current[color[c]] = 0

        for v in g[c]:
            if removed[v]:
                continue
            nodes = []
            collect(v, c, 1, nodes)

            for col, dist in nodes:
                if col in current:
                    ans[col] = max(ans[col], current[col] + dist)

            for col, dist in nodes:
                if col not in current or dist > current[col]:
                    current[col] = dist

        removed[c] = True
        for v in g[c]:
            if not removed[v]:
                decompose(v)

    decompose(0)

    print("\n".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```这`calc_size`函数测量当前组件的大小，同时忽略已经删除的质心。 这`find_centroid`函数会进入唯一太大的子树，直到到达有效的质心。 

这`collect`DFS聚集`(color, distance)`来自质心的一个子组件的对。 单独处理子组件是至关重要的。 同一子组件中两个顶点的距离不能通过质心组合。 

这`current`字典存储已处理分支中从该质心到每种颜色的最大距离。 当扫描一个新分支时，将其顶点与`current`检查穿过质心的所有路径。 答案更新仅使用距离的加法，因此 Python 整数避免了溢出问题。 

递归限制增加是因为树 DFS 和质心递归都可能超过 Python 在大型输入上的默认递归深度。

 ## 边缘情况

 当一个亚种只出现一次时，质心过程可能会多次遇到该颜色，但字典永远不会找到第二个匹配的顶点。 答案仍然为零，因为不存在对。 

对于输入：```
5 5
1 2 3 4 5
1 2
2 3
3 4
4 5
```每个质心步骤仅记录每种颜色的一个距离。 没有发生加法，因此每个答案都保持为零。 

当相同的颜色被其他颜色分开时，该算法不依赖于亚种的连通性。 为了：```
5 2
1 2 1 2 1
1 2
2 3
3 4
4 5
```两个外部颜色`1`顶点最终被考虑在质心，在那里它们的路径被分成不同的分支。 它们的距离加起来为四，这是正确的范围。 

当许多顶点共享相同的颜色时，字典仅保留从每个质心看到的最大距离。 这是足够的，因为通过该质心的一对总是由距同一中心的两个距离组成，并且最佳对必须使用两个最大的可用值。 递归分解处理不通过当前质心的对。
