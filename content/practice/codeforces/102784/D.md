 ## 解决方案
 # 问题理解

 我们有一排幽灵，每个幽灵都有一个整数年龄。 一步操作包括选择两个年龄不同的相邻鬼魂。 年长的鬼魂击败了年轻的鬼魂并留在队伍中，但幸存下来使其长大了一岁。 年轻的鬼魂消失了。 

问题是布是否可以按某种顺序选择战斗，以便最终只剩下一个幽灵。 

输入给出了鬼魂的数量以及按当前顺序排列的年龄。 输出是`YES`如果存在某种序列的战斗只留下一个鬼魂，并且`NO`否则。 

该约束足够小，我们不需要高级数据结构。 鬼魂最多一万个，线性扫描很容易就可以承受，但直接模拟战斗就没有必要了，因为该操作的属性非常强。 任何尝试每一种可能的战斗序列的解决方案都会爆炸，因为每次移除后可能的选择数量会迅速增加。 

主要的边缘情况来自于战斗甚至无法开始的情况。 如果只有一个鬼，答案就是立即`YES`因为没有人需要被移除。 例如：```
Input:
1
7

Output:
YES
```仅搜索可能的战斗的粗心实现将错误地返回`NO`。 

另一个重要的情况是每个鬼魂的年龄都相同。 例如：```
Input:
3
5
5
5

Output:
NO
```没有两个相邻的鬼魂有不同的年龄，因此任何手术都是合法的。 该过程以三个幽灵而不是一个而停止。 

一个常见的错误是只检查队列中某处是否有多个不同的年龄。 邻接对于第一步很重要。 例如：```
Input:
4
3
3
3
4

Output:
YES
```最后两个鬼魂可以立即战斗。 但是，如果所有值都相等，则不存在这样的起点。 

# 方法

 直接的方法是模拟该过程。 我们可以尝试每一个可能的相邻对，删除较年轻的幽灵，增加较旧的幽灵，并递归地继续，直到该行有一个幽灵或无法移动。 这是正确的，因为它探索了所有可能的选择序列。 

问题是这个搜索树非常庞大。 在最坏的情况下，每个阶段都可以选择许多不同的对。 对于 10,000 个鬼魂，即使考虑所有可能序列中的一小部分也是不可能的。 

关键的观察是，第一次成功的战斗彻底改变了局势。 假设两个相邻的鬼魂有不同的年龄。 较老的获胜，并将其年龄增加一岁。 如果年龄较大的话`x`，幸存者变成`x + 1`，它比战斗之前存在的每个时代都要大。 

这创造了一个独特的最强幽灵。 那个鬼魂现在可以击败任何邻居，因为它总是比他们年长。 每次胜利后，它都会变得更旧，因此它可以继续沿着路线移动，直到其他人都离开为止。 

正因为如此，我们不需要找到战​​斗的确切顺序。 我们只需要知道是否存在第一次战斗。 当相邻的一对年龄不同时，就会发生第一次打斗。 

蛮力之所以有效，是因为它遵循所有可能的有效战斗命令，但因为有太多选择而失败。 第一次成功的战斗创造了一个不可阻挡的胜利者，这一观察将整个问题简化为检查相邻的差异。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 鬼魂数量呈指数级增长 O(N) 递归深度 | 太慢了|
 | 最佳| O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取所有鬼魂的年龄。 如果只有一个鬼魂，就返回`YES`因为已经达到了所需的最终状态。 
2. 扫描每对相邻的鬼魂并比较它们的年龄。 如果任何一对年龄不同，则返回`YES`。 

第一个不平等的相邻配对可以战斗。 在那场战斗之后，幸存者变得比之前存在的所有幽灵都古老，因此它可以消除整个剩余的队伍。 
3. 如果扫描完成后没有发现任何不相等的相邻对，则返回`NO`。 

在这种情况下，每个鬼魂都有相同的年龄，这意味着一开始就不存在合法的移动。 

为什么有效：如果存在不平等的相邻对，则第一次战斗会产生一个年龄比所有原始年龄都大的鬼魂。 由于后来的每一个对手都不比这个鬼年纪大，所以它总是能赢得下一场战斗并变得更老。 因此，所有其他幽灵最终都可以被移除。 如果不存在不相等的相邻对，则所有鬼的年龄都相同，不可能发生战斗，因此减少线是不可能的。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    ages = [int(input()) for _ in range(n)]

    if n == 1:
        print("YES")
        return

    for i in range(n - 1):
        if ages[i] != ages[i + 1]:
            print("YES")
            return

    print("NO")

if __name__ == "__main__":
    solve()
```该代码首先处理单一幽灵的情况，因为那里不需要进行比较。 然后它只检查相邻的鬼魂，因为合法的第一步需要两个具有不同年龄的相邻鬼魂。 

一旦发现可能的第一次战斗，扫描就会停止。 没有必要模拟剩下的过程，因为那场战斗之后获胜的鬼魂肯定会主宰未来的每一场战斗。 

循环使用`n - 1`比较，因此仔细选择边界以避免访问超出列表末尾的元素。

 | 索引检查 | 左年龄 | 适龄| 结果 |

 # 边缘情况

 当只有一个幽灵时，算法返回`YES`立即地。 对于输入：```
1
42
```没有战斗可进行，但队伍中已经只剩下一个幽灵了。 

当所有鬼魂的年龄相同时，每个相邻的比较都会失败。 对于输入：```
4
6
6
6
6
```扫描检查了三对，每对都有相同的年龄。 由于第一次战斗不可能发生，最终状态永远不可能包含一个幽灵，因此算法返回`NO`。 

当唯一的差异接近边界时，算法仍然成功。 对于输入：```
4
3
3
3
8
```最后一对不相等。 年龄`8`幽灵战胜了时代`3`鬼魂变成了年龄`9`，之后就可以将剩下的鬼魂一一击败了。 扫描找到这一对并返回`YES`。
