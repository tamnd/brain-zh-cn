 ## 解决方案
 ## 问题理解

 这座城市是一个`n x n`网格。 粘液来源从细胞开始`(x, y)`每秒向四个基本方向扩展一步。 后`t`秒，当一个单元格与起始单元格的曼哈顿距离最大时，该单元格就被覆盖了`t`。 任务是找到最小的`t`这样至少`k`细胞被覆盖。 

输入包含网格的边长、粘液的起始行和列以及所需的覆盖单元格数量。 当覆盖面积达到该数量时，输出是第一秒。 

网格的边长可达`10^9`，所以即使存储网格也是不可能的。 一次将粘液扩展一层的模拟也会太慢，因为答案可能接近于`10^9`。 该算法需要使用公式和对数搜索，而不是访问单元格。 

一个常见的错误是假设扩展的形状始终是完整的菱形。 城市的边界切断了钻石的一部分，尤其是当来源靠近边缘时。 例如，在一个`5 x 5`网格，源位于`(1,1)`，一秒钟后无限菱形将包含五个单元格，但实际网格仅包含三个可到达的单元格：```
Input:
5 1 1 3

Output:
0
```起始单元格已被视为已覆盖，因此答案为零。 仅检查菱形大小而不考虑边界的解决方案可能会错误地高估覆盖范围。 

另一个边缘情况是当`k = 1`。 粘液立即覆盖其起始单元，因此答案必须为零：```
Input:
100 50 50 1

Output:
0
```从 1 而不是从 0 开始的二分查找会错过这种情况。 

第三个棘手的情况是一个非常大的网格，其中源位于中间附近。 例如：```
Input:
1000000000 500000000 500000000 1000000000000000000
```答案可能非常大，因此所有涉及计数的计算都必须使用 64 位整数。 Python 整数已经可以处理这个范围。 

## 方法

 直接的方法是模拟传播过程。 在零时刻有一个细胞。 每秒添加下一个曼哈顿距离图层。 我们可以维护访问过的单元并使用 BFS 进行扩展。 这是正确的，因为粘液运动正是一个最短路径距离的过程。 

问题在于状态空间的大小。 具有半径的钻石`r`包含关于`2r^2`考虑边界之前的单元格。 和`n = 10^9`，涉及的细胞数量可以接近`10^18`，所以模拟是不可能的。 

有用的观察是我们不需要每时每刻都知道确切的形状。 我们只需要一个函数来回答一个问题：之后覆盖了多少个单元格`t`秒？ 该值是单调的，因为增加`t`只能添加单元格。 一旦我们可以计算出固定的计数`t`，二分查找给出最小有效时间。 

剩下的挑战是计算曼哈顿菱形与方形网格的交点。 钻石可以围绕起始单元分为四个象限。 每个象限都变成一个简单的问题：计算非负偏移量对`(a, b)`在哪里`a + b <= t`并且两个偏移量都保留在网格内。 

对于可能偏移的矩形`0 <= a <= A`和`0 <= b <= B`，包含-排除给出常数时间内的计数。 我们从无限三角形开始并删除超出任一边界的点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(答案²) | O(答案²) | 太慢了|
 | 最佳| O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 定义一个函数，计算固定秒数后覆盖的单元格数量。 该函数只需要算术运算，因为每个覆盖的单元都满足曼哈顿距离条件。 
2. 将起始单元格周围的网格分成四个矩形。 每个矩形代表从源开始的一个方向，源单元属于所有四个矩形。 将四个计数相加并减去起始单元格的额外副本。 
3. 对于一个矩形，计算偏移对`(a, b)`在哪里`a`和`b`是非负的并且`a + b <= t`。 从不受限制的三角形计数开始：$$\frac{(t+1)(t+2)}{2}$$然后删除对，其中`a`太大，删除其中的对`b`太大了，加回删除的对两次。 

1.二分查找时间最小`t`其中覆盖计数至少为`k`。 下限为零，因为初始单元格可能已经满足要求。 上限可以是`2*n`，因为之后肯定会到达整个网格。 

正确性来自两个属性。 首先，曼哈顿距离条件准确地描述了给定秒数后到达的单元格。 其次，覆盖函数是单调的，因此二分查找会找到条件成立的第一次。 矩形计数公式通过包含-排除对每个有效偏移量精确计数一次，因此覆盖检查是准确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def tri(s):
    if s < 0:
        return 0
    return (s + 1) * (s + 2) // 2

def rect_count(a, b, t):
    return (
        tri(t)
        - tri(t - a - 1)
        - tri(t - b - 1)
        + tri(t - a - b - 2)
    )

def solve():
    n, x, y, k = map(int, input().split())

    def covered(t):
        ans = 0
        ans += rect_count(x - 1, y - 1, t)
        ans += rect_count(x - 1, n - y, t)
        ans += rect_count(n - x, y - 1, t)
        ans += rect_count(n - x, n - y, t)
        return ans - 3

    lo, hi = 0, 2 * n
    while lo < hi:
        mid = (lo + hi) // 2
        if covered(mid) >= k:
            hi = mid
        else:
            lo = mid + 1
    print(lo)

if __name__ == "__main__":
    solve()
```这`tri`函数表示无限非负三角形中的点数。 当请求的三角形具有负大小时，它返回零，这避免了单独的边界情况。 

这`rect_count`函数应用包含-排除。 第一项计算每个可能的偏移量。 接下来的两项删除了通过任一侧离开矩形的偏移量。 最后一项恢复违反这两个限制的偏移量。 

四人来电`covered`对应于源周围的四个方向。 每一个都包含源单元，因为两个偏移量都可以为零。 由于源出现在所有四个象限计数中，因此必须删除三个副本。 

二分查找使用`2*n`作为安全上限。 半径为`2*n`大于网格中任何两个单元之间的最大可能曼哈顿距离，因此整个板被覆盖。

 ## 边缘情况

 当起始单元格已经足够时，覆盖公式在时间为零时返回 1。 二分搜索包括零作为可能的答案，因此输入如下：```
5 1 1 1
```正确产生：```
0
```当来源靠近边界时，钻石的某些部分位于城市之外。 象限大小传递给`rect_count`变小，因此包含排除公式自然会删除那些不可能的单元格。 为了：```
5 1 1 3
```四个象限只有网格内可用的单元格，并且零时刻的计数已经达到目标。 

当网格非常大时，算法永远不会构造网格或菱形。 它仅计算涉及坐标和当前二分查找值的公式。 这使得运行时间独立于单元总数。
