 ## 解决方案
 ## 问题理解

 问题集中在 Ilya 的银行账户余额上，它是一个有符号整数。 正值表示储蓄，负值表示债务。 银行允许 Ilya 进行一次性操作：他可以从余额中删除最后一位或倒数第二位数字，以潜在地改善余额。 目标是确定使用此操作可实现的最大余额，或者在产生最佳结果的情况下保持数字不变。 

输入是单个整数`n`在哪里`10 ≤ |n| ≤ 10^9`。 下限确保数字至少有两位数字，这使得删除数字的操作有意义。 上限正好在 32 位整数范围内，因此算术运算是安全的，不需要任意精度处理。 

非明显的边缘情况包括绝对值较小的负数，例如`-10`或者`-11`。 只需删除最后一位数字就可以创建`-1`或者`-1`分别，删除倒数第二个数字可能会产生`0`或者`-1`。 粗心的实现可能会忽略倒数第二个数字选项或错误计算新值，从而产生次优结果。 

## 方法

 暴力方法会尝试删除一位数字或保留数字不变的每种组合。 对于正数，删除数字几乎永远不会增加值，因此强力减少为检查负数的两个操作。 检查的最大数量为三：保留`n`按原样，删除最后一位数字，删除倒数第二位数字。 由于这是每个输入的恒定工作量，因此在实践中，蛮力实际上是可以接受的。 

得出简单最优解的关键观察是，对于正数，什么都不做总是最优的。 对于负数，唯一潜在的改进来自于删除最后一个或倒数第二个数字。 将这些修改后的数字转换为整数并取三个选项中的最大值可以保证正确性。 这一观察结果将问题简化为 O(1) 操作，无需任何循环或递归。

 ## 算法演练

 1.读取整数`n`来自输入。 这代表当前的银行帐户状态。 
2.如果`n`是非负数，打印`n`立即，因为删除数字不能改善正余额。 
3.如果`n`为负数，转换`n`到一个字符串来操作它的数字。 让`s`是的字符串表示形式`n`。 
4.构造两个候选余额：去掉最后一位数字，形成`candidate1`并删除倒数第二个数字以形成`candidate2`。 这是通过对字符串进行切片来完成的：`s[:-1]`对于最后一位数字和`s[:-2] + s[-1]`倒数第二个数字。 将这些字符串转换回整数。 
5. 计算三个值中的最大值：`n`,`candidate1`， 和`candidate2`。 该最大值是最佳的账户余额。 
6. 打印结果。 

正确性依赖于一个不变量，即对于负数，删除数字要么使数字的负数减少，要么保持不变。 没有其他操作需要考虑，因此比较三种可能性是详尽的并且保证了最大结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

if n >= 0:
    print(n)
else:
    s = str(n)
    candidate1 = int(s[:-1])  # remove last digit
    candidate2 = int(s[:-2] + s[-1])  # remove second-to-last digit
    print(max(n, candidate1, candidate2))
```解决方案首先单独处理正数，以避免不必要的字符串操作。 对于负数，字符串切片可确保我们正确删除目标数字。 一个常见的错误是删除倒数第二个数字时索引错误；`s[:-2] + s[-1]`正确保留最后两位之前的数字并附加最后一个数字。

 ## 边缘情况

 对于`n = -10`，删除最后一位数字会产生`-1`但删除倒数第二位数字会产生`0`，这是最大值。 该算法计算`candidate1 = -1`和`candidate2 = 0`，然后返回`max(-10, -1, 0) = 0`，演示了小负数的正确处理。 

为了`n = -11`，两位候选人都产生`-1`。 该算法计算`candidate1 = -1`和`candidate2 = -1`，然后返回`max(-11, -1, -1) = -1`，确认它可以正确处理重复的数字。
