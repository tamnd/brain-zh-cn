 ## 解决方案
 ## 问题理解

 我们有一个网格`n`行和`m`列。 每个单元格都包含一个正值，表示该单元格受到法术影响时获得的奖励。 

我们只选择一个单元格作为攻击的中心。 当攻击被施放时，它会影响一个十字形区域：所选单元格本身，加上其在四个基本方向（上、下、左、右）上的直接邻居（如果这些邻居存在于网格内）。 

任务是选择中心单元格，以使该十字形图案中的值的总和最大化。 

所以对于每个有效的中心`(i, j)`，我们计算：

 的值在`(i, j)`加上值`(i-1, j)`,`(i+1, j)`,`(i, j-1)`,`(i, j+1)`如果它们存在的话。 

输出是所有可能中心的最大总和。 

限制因素`n, m ≤ 100`表示网格最多有 10,000 个单元格。 任何重新计算每个单元恒定工作量的解决方案都足够快，因为在 1 秒限制内，数万次操作可以忽略不计。 任何涉及每个中心重复扫描行或列的操作在这里仍然没问题，但没有必要。 

微妙的边缘情况来自边界单元。 如果我们错误地假设所有四个邻居都存在，我们将访问无效位置或添加垃圾值。 例如，在一个`1 × 4`网格：```
2 1 2 1
```如果我们尝试计算第 1 列的全叉，则左邻居不存在，因此正确的总和为`2 + 1 = 3`对于那个中心。 盲目访问的幼稚实现`j-1`会崩溃或产生错误的总和。 

另一个极端情况是当网格`1 × 1`。 那么唯一有效的中心就只贡献自己的价值。 

## 方法

 暴力方法很简单。 对于每个单元格，我们尝试将其视为十字的中心，并通过检查最多五个单元格来计算总和。 每次检查都是恒定时间，所以这给出`O(nm)`总工作量。 这已经完全符合约束条件。 

一个较慢但仍然可以想象的简单版本是通过迭代固定的邻域窗口或动态扫描行和列来重新计算交叉和。 即使如此，由于网格很小，它仍然会通过，但它引入了不必要的复杂性和更多发生边界错误的机会。 

关键的观察是我们需要的形状是固定的并且非常小。 不同中心之间不存在依赖关系。 每个候选答案都是独立的，因此我们不需要前缀和、BFS 或任何预处理结构。 该问题简化为评估每个网格单元上的恒定尺寸模板。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每个单元重新计算邻居的蛮力 | O(纳米) | O(1) | O(1) | 已接受 |
 | 最优直接邻居和| O(纳米) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将网格读入二维数组。 我们存储所有值，以便可以通过索引安全地访问邻居。 
2. 初始化变量`best = 0`（如果允许负值，则为非常小的数字；这里所有值都是正数，因此零是安全的）。 
3. 迭代每个单元格`(i, j)`在网格中。 每个细胞都是潜在的十字中心。 
4. 对于每个单元格，计算从以下开始的运行总和`grid[i][j]`。 这代表了攻击的中心。 
5.如果`i > 0`， 添加`grid[i-1][j]`。 仅当上面的单元格存在时，它才安全地包含它。 
6.如果`i < n-1`， 添加`grid[i+1][j]`。 这安全地包括下面的单元格。 
7.如果`j > 0`， 添加`grid[i][j-1]`。 当有效时，这包括左邻居。 
8. 如果`j < m-1`， 添加`grid[i][j+1]`。 这包括正确的邻居。 
9. 更新`best`其当前值与计算总和的最大值。 
10.处理完所有cell后，输出`best`。 

实现的关键思想是每个邻居访问都必须受到边界检查的保护。 如果没有这些条件，边缘单元就会破坏正确性。 

### 为什么它有效

 每个有效的攻击区域恰好对应一个中心单元。 该区域的贡献仅取决于该单元及其四个正交邻居。 由于我们枚举了所有可能的中心并计算了它们相应区域的精确值，因此我们对每个可行的攻击都检查一次。 因此，所有计算值的最大值必须等于最佳答案。 

不同中心之间不存在交互，因此不存在重复计算或丢失配置的风险。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
grid = [list(map(int, input().split())) for _ in range(n)]

best = 0

for i in range(n):
    for j in range(m):
        s = grid[i][j]

        if i > 0:
            s += grid[i - 1][j]
        if i < n - 1:
            s += grid[i + 1][j]
        if j > 0:
            s += grid[i][j - 1]
        if j < m - 1:
            s += grid[i][j + 1]

        if s > best:
            best = s

print(best)
```网格直接存储，无需修改。 每个单元都被独立评估。 这四个条件检查确保我们永远不会访问无效索引，这是此问题中最常见的错误来源。 

更新步骤保持简单以避免开销。 由于网格很小，Python 的嵌套循环就足够了。

 ## 边缘情况

 单细胞网格`1 1`是最简单的边界。 该算法评估唯一的单元格，找不到有效的邻居，并正确返回其值，而无需输入任何无效的索引访问。 

在一个`1 × m`网格，垂直邻居永远不存在。 条件检查确保仅添加水平贡献，从而有效地减少了寻找以每个位置为中心的长度为 3 的线段的最大总和的问题。 

在一个`n × 1`网格，同样的对称性适用于垂直方向。 该算法将交叉线减少为垂直线，无需特殊处理。 

边缘和角落上的细胞仅对交叉有部分贡献。 每个边界检查都会自然地处理，因此不需要单独的逻辑路径，从而防止手动处理边界时通常发生的逐一错误。
