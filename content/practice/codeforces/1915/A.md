 ## 解决方案
 ## 问题理解

 我们被赋予了一系列非常小的独立任务。 每个任务都由三位数字组成，并且我们被承诺了一种特定的结构：在这三个值中，两个相同，一个不同。 我们的工作是识别异常值，即在该三元组中仅出现一次的数字。 

尽管每个测试用例的输入大小很小，但该问题旨在测试有关相等模式的清晰推理，而不是任何繁重的计算。 每个测试用例都是独立的，因此没有可利用的共享状态或累积结构。 

约束足够小，每个测​​试解决方案的任何恒定时间就足够了。 由于最多有 270 个测试用例，并且每个用例只有三个整数，即使是进行多重比较或使用简单计数结构的方法在时间限制下也非常快。 真正的约束压力是不存在的； 相反，平等模式的正确性和处理才是重要的。 

唯一的微妙之处来自于假设结构始终有效。 粗心的实现可能会在不考虑逻辑稳定性的情况下尝试进行概括或排序，但由于只有一个值保证是唯一的，因此我们可以直接依赖该不变量。 

边缘情况大多是同一模式的退化形式。 例如，输入如下`5 5 6`,`6 5 5`， 或者`5 6 5`所有这些都需要相同的输出，但如果假设唯一值始终位于固定位置，则天真的位置推理可能会失败。 

## 方法

 一种强力解释是使用频率结构（例如字典或大小为 10 的数组）来计算三元组中每个数字的出现次数。我们为三个值中的每一个值递增计数，然后扫描频率等于 1 的值。 这是正确的，并且每个测试用例都以恒定的时间运行。 超过270个测试用例，总工作量可以忽略不计。 

然而，这种方法做了不必要的工作，因为输入的结构受到高度限制。 我们实际上并不需要完整的频率表； 我们只需要区分这三个位置中哪一个与其他位置不同即可。 关键的观察结果是，只有一个不同元素的三个元素之间的相等性意味着该不同元素必须与其他两个元素中的至少一个不同，而相等的一对必须彼此匹配。 

这允许直接逻辑提取：比较对。 如果`a == b`， 然后`c`就是答案。 否则，如果`a == c`， 然后`b`就是答案。 否则，`a`一定是独一无二的。 这将问题简化为在没有辅助存储的情况下进行恒定数量的比较。

 ## 算法演练

 1.读取测试用例的数量。 这决定了我们将处理多少个独立的三元组。 
2. 对于每个测试用例，读取三位数字`a`,`b`， 和`c`。 
3.比较`a`和`b`。 如果它们相等，则已经识别出重复对，因此第三个值`c`一定是独一无二的。 
4. 如果`a`和`b`不相等，比较`a`和`c`。 如果这些相等，那么`b`是唯一不匹配其对的值，因此它是唯一的数字。 
5. 如果以上条件都不成立，则`b`必须等于`c`， 和`a`是唯一的数字。 

### 为什么它有效

 两个值恰好相等的保证强制将三个元素严格划分为一对和一个单例。 每次比较要么直接识别配对，要么消除候选者。 由于相等性是传递性的，一旦我们找到任何匹配对，剩下的元素就不能等于它们，所以它一定是唯一的。 没有与输入约束一致的替代配置，这保证了条件链的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c = map(int, input().split())
    
    if a == b:
        print(c)
    elif a == c:
        print(b)
    else:
        print(a)
```该解决方案完全依赖于直接比较。 第一个条件检查前两个值是否已经形成重复对，这会立即隔离答案。 仅当第一次比较失败时才达到第二个条件，所以我们知道`a != b`。 此时，检查`a == c`确定是否`a`是重复对的一部分。 如果两个条件都不满足，则唯一剩余的一致结构是`b == c`， 制作`a`独特的元素。 

除了输入解析之外不需要循环或数据结构。 检查的顺序很重要，因为它避免了冗余比较并保证我们始终识别正确的单例。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline
    
    t = int(input())
    out = []
    for _ in range(t):
        a, b, c = map(int, input().split())
        if a == b:
            out.append(str(c))
        elif a == c:
            out.append(str(b))
        else:
            out.append(str(a))
    return "\n".join(out)

 ## 边缘情况

 关键的边缘情况是当相等的对在输入顺序上不相邻时。 例如，在`4 7 4`，这对`(4, 4)`围绕中间位置分开。 该算法通过首先检查来处理这个问题`a == b`，失败，然后检查`a == c`，成功，正确识别`b`作为独特的元素。 

另一种情况是当相等的对出现在前两个位置时，例如`9 9 1`。 这里第一个条件`a == b`立即触发，算法输出`c`无需任何进一步检查。 这证实了提前退出行为是安全的，并且不会跳过任何必要的推理。 

最后，在`7 7 5`，结构相同但具有不同的值。 相同的不变量成立：恰好存在一个等式对，因此第一个匹配比较始终标识三元组的正确分区，确保一致地返回唯一元素。
