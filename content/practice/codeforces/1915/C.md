 ## 解决方案
 ## 问题理解

 我们有几个桶，每个桶包含一定数量的单位正方形。 所有正方形都是相同的并且边长为 1。 

问题很简单：如果我们从每个桶中取出每个方格，它们能否排列成一个更大的方格而不留下任何方格？ 

如果单位方格的总数为$S$，那么当它的面积为$S$。 由于正方形的面积必须是完全平方数，因此任务简化为检查所有桶内容的总和是否是完全平方数。 

约束足够小，我们可以一次性处理每个元素。 在所有测试用例中，值的总数最多为$2 \cdot 10^5$，所以一个$O(n)$每个测试用例的解决方案很容易足够快。 任何重复搜索或迭代相同值的方法都是不必要的。 

一个微妙的一点是，个体值可以大到$10^9$。 由于最多可以有$2 \cdot 10^5$总体而言，总和可能会变得非常大。 在具有固定大小整数类型的语言中，使用太小的类型会溢出。 Python 整数自动增长，所以这不是问题。 

另一个容易犯的错误是使用浮点运算仅检查平方根是否为整数。 大数字可能会遇到精度问题。 例如：```
1
2
1000000000 1000000000
```总和是$2000000000$，这不是一个完美的正方形。 浮点舍入有时会导致对大值进行不正确的比较。 使用整数平方根可以避免这种风险。 

当只有一个存储桶时，会出现一种不同的边缘情况：```
1
1
9
```方格总数为 9，等于$3^2$，所以正确答案是：```
YES
```尝试显式构造维度而不是检查面积的粗心实现可能会使这种情况变得过于复杂。 

## 方法

 最直接的想法是计算单位方格的总数，然后确定该数字是否可以写为$k^2$对于某个整数$k$。 

暴力版本会反复尝试以下值$k$直到$k^2$达到或超过总和。 如果总和是$S$，这需要最多$\sqrt{S}$迭代。 由于总和可能非常大，因此这是不切实际的。 例如，总和接近$2 \cdot 10^{14}$需要大约$1.4 \cdot 10^7$检查。 

关键的观察是正方形的排列并不重要。 只有总数很重要。 一旦我们知道了总面积，问题就变成了完美平方检验。 

我们可以计算总和的整数平方根，而不是手动搜索平方根。 让$$r = \lfloor \sqrt{S} \rfloor.$$如果$r^2 = S$， 然后$S$是一个完全平方数，答案是“是”。 否则，答案是“否”。 

这将问题简化为一次通过输入值加上一次平方根计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n + \sqrt{S})$|$O(1)$| 太慢了 |
 | 最佳 |$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，请阅读$n$以及存储桶内容的数组。 
3. 计算单位方格的总数：$$S = \sum a_i$$由于必须使用每个正方形，因此该总数恰好是最终图形的面积。 
4. 计算整数平方根$r$的$S$。 

整数平方根是平方不超过的最大整数$S$。 
5. 检查是否$r^2 = S$。 

如果平等成立，$S$是一个完全正方形并且可以组成一个正方形。 
6. 输出`"YES"`什么时候$r^2 = S$，否则输出`"NO"`。 

### 为什么它有效

 一个正方形有边长$k$有面积$k^2$。 可用单位方块的总数为$S$，因此由所有块构建的任何正方形都必须具有精确的面积$S$。 

如果$S$是一个完全正方形，选择边长$k = \sqrt{S}$并且施工是可能的。 

如果$S$不是一个完美的正方形，没有整数边长可以产生面积$S$，所以构造一个正方形是不可能的。 

该算法准确地检查了这个必要和充分条件，从而保证了正确性。 

## Python 解决方案```python
import sys
from math import isqrt

input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    total = sum(a)
    root = isqrt(total)

    print("YES" if root * root == total else "NO")
```第一步通过将所有桶内容相加来计算总面积。 

功能`isqrt()`不使用浮点运算返回整数平方根。 这可以避免数字变大时可能出现的精度问题。 

获得后`root`，代码检查是否`root * root`等于原来的总和。 相等意味着总和是完全平方数。 否则就不是。 

该实现仅使用输入数组之外的常量额外内存，并且只处理每个元素一次。

 ## 边缘情况

 考虑最小可能的完全平方情况：```
1
1
1
```总和是$1$。 整数平方根也是$1$， 和$1^2 = 1$。 该算法输出：```
YES
```现在考虑一个计数不是平方的单个桶：```
1
1
2
```总和是$2$。 整数平方根是$1$， 但$1^2 = 1 \neq 2$。 算法正确输出：```
NO
```考虑一个大价值的案例：```
1
2
1000000000 1000000000
```总和是$2000000000$。 整数平方根是$44721$， 和$$44721^2 = 1999967841.$$由于这与总和不同，算法输出：```
NO
```这证实了使用精确的整数平方根可以避免浮点精度问题。 

最后，考虑多个桶的完全平方总分布：```
1
4
2 2 2 3
```总和是$9$。 整数平方根是$3$， 和$3^2 = 9$。 输出是：```
YES
```存储桶之间的分配并不重要。 只有总面积才决定能否组成正方形。
