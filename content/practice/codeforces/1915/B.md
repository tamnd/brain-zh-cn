 ## 解决方案
 ## 问题理解

 给定一个固定的 3 x 3 网格，其中包含字符 A、B 和 C，除了缺少一个单元格之外，其结构为拉丁方格。 这里，有效的拉丁方意味着每一行恰好包含字母 A、B 和 C 中的一个，每列也是如此。 

在每个测试用例中，恰好有一个单元格被替换为问号。 所有其他八个单元格均已正确填充，因此完成拉丁方可以唯一确定丢失的字符。 任务只是恢复那个缺失的角色。 

就测试用例的数量而言，输入大小很大，最多可达$10^8$。 每个测试用例都是持续工作：3 x 3 网格。 这立即意味着任何解决方案都必须在每个测试用例中以恒定的时间运行，并避免不必要的开销，例如回溯或排列模拟。 

由于网格大小是固定的，因此不存在与维度相关的有意义的算法边缘情况。 唯一的边缘条件是缺失字符的位置，它可以位于网格中的任何位置。 一个幼稚的错误是假设问号有一个固定位置并只检查该位置。 例如，如果假设它始终位于中间行或中间列，则在以下输入上将失败：```
?AB
BCA
CAB
```正确答案取决于行和列的全局约束，而不是局部位置。 

另一个微妙的陷阱是尝试通过仅检查行或仅检查列来重建丢失的字母。 单独使用任一方法都是不够的，因为每行和每列必须同时满足排列约束。 

## 方法

 思考该问题的一种强力方法是尝试所有可能的字母作为问号，并验证所得网格是否满足拉丁方约束。 由于只有三个可能的字母，这对于每个测试用例来说已经是持续的工作，但我们可以用更一般的暴力方式来描述它：用 A、B 或 C 填充缺失的单元格，并检查所有行和列。 

验证完整的 3 x 3 网格需要恒定的时间，因为我们只检查 6 行。 因此，即使这种粗暴的方法对于约束来说也是有效的最佳选择。 

然而，我们可以通过利用结构属性来进一步简化：在拉丁方的每个有效行中，三个字母 A、B、C 恰好出现一次。 因此，如果我们知道连续两个字母，则第三个字母是唯一确定的。 这同样适用于列。 

这意味着我们不需要测试所有可能性。 我们可以直接找到包含问号的行或列，并将缺失的字母计算为该行（或列）中不存在的字母。 由于保证每一行总体上恰好包含一个缺失元素，因此两种方法都有效，并且基于行的恢复是最简单的。 

我们计算完整的集合{A，B，C}，从包含“？”的行中删除两个已知字母，剩下的元素就是答案。

 ## 算法演练

 1. 阅读每个测试用例的 3 x 3 网格。 网格很小，我们可以直接处理，不需要预处理。 
2. 找到问号的位置。 我们通过扫描所有 9 个单元格来做到这一点。 由于网格的大小是恒定的，因此该扫描的时间是恒定的。 
3. 找出包含问号的行。 这一行将恰好包含两个已知字母和一个缺失位置。 
4. 收集该行中的字符并将它们与集合 {A, B, C} 进行比较。 
5. 缺失的字符是该行中不存在的字符。 
6. 输出恢复的字符。 

关键的决定是使用包含问号的行，而不是尝试组合行和列信息。 由于在有效完成中每行必须包含所有三个字母一次，因此仅该行就足以重建缺失值。 

### 为什么它有效

 拉丁方的每一行都是 {A, B, C} 的排列。 删除一个条目只会留下两个不同的字母。 剩余的字母被唯一地确定为该对的补码。 由于保证输入在一个位置上与有效的拉丁方不同，因此包含缺失值的行仍以完整形式保留此结构。 因此，识别缺失元素可以简化为计算确定性的集合补集，而不会产生歧义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

ALL = {"A", "B", "C"}

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        grid = [input().strip() for _ in range(3)]

        ans = None

        for r in range(3):
            if "?" in grid[r]:
                s = set(grid[r])
                s.discard("?")
                ans = (ALL - s).pop()
                break

        out.append(ans)

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案扫描每一行以查找包含问号的行。 一旦找到，它就会将该行转换为一个集合，删除占位符，并通过与 {A, B, C} 的集合差异计算丢失的字符。 这`.pop()`是安全的，因为集合差值始终只包含一个元素。 

该实现依赖于这样一个事实：只有一行包含丢失的字符，因此我们可以在处理后立即中断。 这避免了不必要的检查。

 ## 边缘情况

 一种边缘情况是缺失字符出现在行的第一个位置。 例如：```
?BC
CAB
ABC
```该算法将第一行识别为包含问号。 已知字母是 B 和 C，因此与 {A, B, C} 的集合差值产生 A。丢失单元格的位置不会影响计算，因为集合成员资格完全忽略排序。 

另一种情况是缺失的字符位于最后一列：```
ABC
BCA
CA?
```第二行包含问号，已知字母是 C 和 A。补码是 B。该算法不依赖于索引算术，因此列位置没有影响。 

最后的结构边缘情况是除了一行之外的所有行都是完全排列。 该算法仍然只检查不完整的行，因此其他地方完全有效的行不会产生歧义。
