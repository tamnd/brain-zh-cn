 ## 解决方案
 ## 问题理解

 我们被要求分析一个只有一堆的两人游戏`n`石头。 球员们轮流轮流，从谢罗扎开始。 在每一回合中，玩家选择现有的一堆并将其分成至少两堆，形成严格递减序列，连续差值等于 1。 例如，一堆大小为 5 的可以分为`[3, 2]`但不是`[4, 1]`因为 4 和 1 之间的差是 3。当玩家无法移动时，游戏结束，该玩家输。 我们的目标是确定 Serozha 是否能够以最佳发挥保证获胜，如果可以，他在第一步中应将初始堆分成多少堆才能确保胜利。 如果他不能获胜，答案是-1。 

输入是单个整数`n`(1 ≤ n ≤ 10^5)，表示初始堆大小。 由于 n 可以大到 100,000 并且时间限制为 2 秒，因此 O(n^2) 算法可能太慢，而 O(n log n) 或 O(n√n) 是可行的。 对于大 n 来说，递归枚举所有可能序列的简单方法会失败。 

第一个不明显的边缘情况发生在非常小的桩上。 为了`n = 1`，无法分成至少两个递减的连续堆，因此 Serozha 立即失败。 为了`n = 2`，唯一的分裂`[1, 1]`并不是严格递减，所以第一个玩家又输了。 为了`n = 3`，唯一有效的分割是`[2, 1]`，第一个玩家获胜。 如果幼稚的实现没有正确执行递减和差异约束或者无法处理小 n，则可能会错误计算这些值。 

## 方法

 暴力方法将递归计算每个桩大小的格伦迪数（或数字）。 对于给定大小的堆`x`，我们将把所有可能的有效分割生成为严格递减的连续整数序列，递归地计算每个结果堆集的编号，然后应用 XOR 运算来获取当前堆的编号。 Serozha 获胜，如果`n`是非零的。 虽然这种方法在数学上是正确的，但为每个堆大小（最多 100,000）递归生成所有分割将导致太多操作。 例如，递减序列的数量总和为`n`项数大致增长 √n，因此递归调用的总数至少变为 O(n√n)，这在 Python 中是非常慢的。 

关键的见解是要注意有效序列是严格递减的连续数字。 这极大地限制了分裂。 如果一个序列有 k 个桩，则其总和为`k * first - k*(k-1)/2`因为序列是`first, first-1, ..., first-(k-1)`。 求解第一个元素，`first = (sum + k*(k-1)/2)/k`。 这必须是一个整数，并且`first ≥ k`确保最后一个元素至少为 1。我们可以有效地迭代所有可能的 k，因为`k*(k+1)/2 ≤ n`。 这减少了从递归生成所有序列到通过测试可行的 k 值生成候选序列的问题。 

一旦生成候选分割，我们就可以使用动态规划。 让`dp[x]`如果玩家以堆大小移动，则为 True`x`有制胜策略。 我们从 1 到 n 迭代计算 dp。 如果存在分裂，使得所有结果堆的 dp 值的 XOR 为 False（下一个玩家被迫进入失败位置），则该堆获胜。 这确保了我们总共只需要 O(n√n) 次操作，这是可以接受的。

 ## 算法演练

 1.初始化一个数组`dp`尺寸的`n+1`与假。`dp[x]`将指示第一个移动一堆大小为 x 的玩家是否可以强制获胜。 
2. 迭代`pile`从 1 到 n。 对于每个桩，迭代可能的桩数`k`从2开始直到`k*(k+1)/2 > pile`。 这确保了最小的有效递减序列`[k, k-1, ..., 1]`不超过桩尺寸。 
3. 对于每个 k，计算`first = (pile + k*(k-1)//2) // k`。 检查是否`(pile + k*(k-1)//2) % k == 0`确保第一个是整数。 如果第一个 < k，则继续下一个 k，因为最后一个元素将为非正数。 
4. 构建序列`[first, first-1, ..., first-(k-1)]`并计算所有结果堆的 dp 值的 XOR。 如果 XOR 为零，则标记`dp[pile] = True`并将当前 k 存储为候选最小获胜分割。 尽早休息，因为我们只需要最小的 k。 
5. 填充dp[n]后，如果`dp[n]`为 True，输出找到的最小 k。 否则输出-1，表示先手者输。 

为什么有效：DP 数组捕获从 1 到 n 的所有获胜位置。 因为每次拆分都会将堆减少为更小的堆，所以我们只依赖于之前计算的 dp 值。 XOR 条件相当于 Sprague-Grundy 定理。 通过从小到大迭代 k，我们找到保证获胜的最小第一步。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

dp = [False] * (n + 1)
min_k = [-1] * (n + 1)

for pile in range(1, n + 1):
    for k in range(2, pile + 1):
        if k * (k + 1) // 2 > pile:
            break
        s = pile + k * (k - 1) // 2
        if s % k != 0:
            continue
        first = s // k
        if first < k:
            continue
        xor_sum = 0
        for i in range(k):
            xor_sum ^= dp[first - i]
        if not xor_sum:
            dp[pile] = True
            min_k[pile] = k
            break

if dp[n]:
    print(min_k[n])
else:
    print(-1)
```我们首先读取堆大小。 这`dp`数组存储堆大小是否获胜。 这`min_k`数组存储获胜的最小第一次分割。 我们有效地迭代堆大小和可能的 k 值，仅考虑满足总和和正约束的分割。 我们计算每个候选分割的 dp 值的 XOR。 使下一个玩家处于失败状态的第一次分裂决定了最小 k。 早期的中断确保我们捕获最小的 k。

 说明：唯一有效的分割是`[2,1]`。 由此产生的桩`[2,1]`有 dp 值`[False, False]`, XOR = 0. 这使得`dp[3] = True`最小 k = 2。
