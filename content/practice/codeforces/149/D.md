 ## 解决方案
 ## 问题理解

 我们得到了一个有效的括号序列。 每个左括号都有一个独特的匹配右括号，并且各对括号正确嵌套。 

我们想根据两条规则为括号分配颜色。 对于每个匹配对，两个括号中的一个必须着色，而另一个保持未着色。 彩色括号可以是红色或蓝色。 第二条规则禁止相邻的彩色括号共享相同的颜色。 

任务是计算存在多少有效颜色，取模`10^9 + 7`。 

序列长度最多为 700。这立即排除了暴力枚举。 每个括号对都有四种可能的本地状态：

 - 将左括号涂成红色
 - 将左括号涂成蓝色
 - 将右括号涂成红色
 - 将右括号涂成蓝色

 如果字符串有 350 对，则蛮力会检查`4^350`任务，这是完全不可能的。 

700 的限制强烈暗示了 DP 区间。 涉及匹配括号的问题通常会自然分解为嵌套区间，并且`O(n^3)`或者`O(n^4)`对于这个大小，动态规划通常是可以接受的。 

棘手的部分是邻接约束跨越区间边界。 连接时两个独立有效的子区间可能会变得无效，因为接触的括号接收相同的颜色。 

一些边缘情况悄悄地破坏了幼稚的实现。 

考虑最小的有效序列：```
()
```答案是`4`。 

该对可以通过四种方式着色：

 - 左红
 - 左蓝色
 - 右红
 - 右蓝色

 粗心的实现有时会忘记每对中的一个括号必须保持未着色。 

另一个微妙的情况是：```
()()
```中间边界很重要。 如果第一个`)`第二个`(`都被着色为红色，着色无效，因为它们在字符串中相邻。 仅检查间隔内的有效性而忽略串联边界的 DP 将会过度计数。 

嵌套间隔会产生不同的问题：```
(())
```外左括号和内左括号是相邻字符。 如果两者都着色为蓝色，则即使它们属于不同对，着色也是无效的。 任何将外部对与其内部间隔相结合的转换都必须检查此邻接性。 

问题最难的部分是正确跟踪间隔边界处的颜色，以便在合并期间可以验证这些相邻冲突。 

## 方法

 蛮力方法在概念上很简单。 首先使用堆栈计算所有匹配的括号对。 然后，对于每一对，选择四种状态之一：

 - 将左括号涂成红色
 - 将左括号涂成蓝色
 - 将右括号涂成红色
 - 将右括号涂成蓝色

 将状态分配给所有对后，扫描序列并验证没有相邻的彩色括号共享相同的颜色。 

这是有效的，因为约束是局部的。 每个完整的作业都可以在线性时间内检查。 

问题是作业的数量。 长度为 700 的序列包含 350 对，产生`4^350`的可能性。 即使存储这个数字也大得离谱。 

关键的观察是正确的括号序列具有递归结构。 

每个间隔是：

 - 围绕另一个正确序列的单个匹配对
 - 或两个正确序列的串联

 这种递归结构正是区间 DP 所利用的。 

邻接条件仅取决于相邻字符，因此在组合两个间隔时我们只需要知道它们边界上的颜色。 里面的一切都已经被验证了。 

这会导致 DP 超过间隔。 

定义：`dp[l][r][a][b]`在哪里：

-`s[l...r]`是正确的括号子序列
 -`a`是位置的颜色状态`l`-`b`是位置的颜色状态`r`我们使用三种状态：

 -`0`= 无色
 -`1`= 红色
 -`2`= 蓝色

 DP 值存储该间隔的有效着色数。 

为什么边界颜色就足够了？ 

因为合并期间创建的唯一新邻接发生在子区间之间的接触位置。 内部邻接性已经被递归地检查过。 

对于每个匹配对`(l, r)`有两种结构情况。 

如果`l`直接匹配`r`，则该区间是通过在其内部包裹另一个区间而形成的。 我们尝试所有有效的方法来着色`l`或者`r`，然后验证与内部区间边界的邻接性。 

如果该区间是两个平衡区间的串联，我们将它们合并，同时检查左侧部分和右侧部分之间的边界。 

这减少了对多项式 DP 的指数搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(4^(n/2) * n) | O(4^(n/2) * n) | O(n) | 太慢了|
 | 最佳 | O(n^3 * 9) | O(n^3 * 9) | O(n^2 * 9) | O(n^2 * 9) | 已接受 |

 ## 算法演练

 1. 使用堆栈计算匹配的括号位置。 

每当我们看到`'('`，压入其索引。 每当我们看到`')'`，弹出匹配的左括号。 
2、定义DP表：`dp[l][r][a][b]`在哪里`a`和`b`是位置的颜色`l`和`r`。 
3. 使用三种颜色状态：

 -`0`意思是无色的
 -`1`表示红色
 -`2`意味着蓝色
 4.处理最小区间`"()"`。 

如果`l`比赛`r`和`r = l + 1`，正好有四种有效状态：

 - 左红
 - 左蓝色
 - 右红
 - 右蓝色
 5. 通过增加长度来处理间隔。 

由于转换依赖于较小的间隔，因此必须首先解决较短的段。 
6. 对于一个区间，其中`match[l] = r`，将其视为包裹内部区间的外部对。 

外对提供四种可能性：

 - 左红
 - 左蓝色
 - 右红
 - 右蓝色

 对于每个内部状态，检查邻接性：

 -`l`和`l+1`-`r-1`和`r`如果两个相邻的彩色括号共享相同的非零颜色，则丢弃过渡。 
7. 如果间隔是串联，则在每个有效中点处将其拆分。 

假设：

 - 左间隔是`[l, k]`- 右区间是`[k+1, r]`组合两个区间的每个边界状态。 
8. 合并两个区间时，检查中间边界。 

职位`k`和`k+1`在整个序列中变得相邻。 如果两者都使用相同的非零颜色，则合并无效。 
9. 添加所有有效的模转换`10^9 + 7`。 
10. 最终答案是整个区间内所有边界态的总和`[0, n-1]`。 

### 为什么它有效

 每个有效的着色都属于括号序列的一次递归分解。 

DP 存储每个间隔的所有有效着色以及足够的信息，以便稍后将该间隔安全地连接到邻居。 外部需要的唯一信息是边界括号的颜色，因为邻接约束仅涉及相邻位置。 

包装区间时，我们显式验证外部对和内部区间之间新创建的两个邻接关系。 连接间隔时，我们显式验证合并边界处的单个新邻接。 

所有其他邻接关系都已递归验证。 由于每个合法着色都只生成一次并且每个生成的着色都满足所有约束，因此 DP 是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

s = input().strip()
n = len(s)

match = [-1] * n
stack = []

for i, ch in enumerate(s):
    if ch == '(':
        stack.append(i)
    else:
        j = stack.pop()
        match[i] = j
        match[j] = i

# dp[l][r][a][b]
dp = [[[[0] * 3 for _ in range(3)] for _ in range(n)] for _ in range(n)]

for length in range(2, n + 1):
    for l in range(n - length + 1):
        r = l + length - 1

        if match[l] != r:
            continue

        # Base case: "()"
        if l + 1 == r:
            dp[l][r][1][0] = 1
            dp[l][r][2][0] = 1
            dp[l][r][0][1] = 1
            dp[l][r][0][2] = 1
            continue

        # Case 1: outer pair wraps entire interval
        if match[l + 1] == r - 1:
            inner = dp[l + 1][r - 1]

            for a in range(3):
                for b in range(3):
                    val = inner[a][b]
                    if val == 0:
                        continue

                    # color left bracket
                    for c in [1, 2]:
                        if not (c == a and c != 0):
                            dp[l][r][c][0] = (
                                dp[l][r][c][0] + val
                            ) % MOD

                    # color right bracket
                    for c in [1, 2]:
                        if not (c == b and c != 0):
                            dp[l][r][0][c] = (
                                dp[l][r][0][c] + val
                            ) % MOD

        else:
            # General wrapped structure:
            # [l ... m] + [m+1 ... r]
            m = match[l]

            left_dp = dp[l][m]
            right_dp = dp[m + 1][r]

            for a in range(3):
                for b in range(3):
                    left_val = left_dp[a][b]
                    if left_val == 0:
                        continue

                    for c in range(3):
                        for d in range(3):
                            right_val = right_dp[c][d]
                            if right_val == 0:
                                continue

                            if b != 0 and b == c:
                                continue

                            dp[l][r][a][d] = (
                                dp[l][r][a][d]
                                + left_val * right_val
                            ) % MOD

answer = 0

for a in range(3):
    for b in range(3):
        answer = (answer + dp[0][n - 1][a][b]) % MOD

print(answer)
```第一部分使用堆栈计算匹配的括号。 这会将字符串转换为 DP 所依赖的递归区间结构。 

DP 维数足够小，因为只有三种可能的边界态。 间隔计数为`O(n^2)`，每个区间存储`3 * 3 = 9`州。 

最微妙的部分是区分包装和连接。 

如果`match[l] == r`，则整个区间被一对外部对包裹。 内部区间变为`[l+1, r-1]`。 我们尝试为任一外部括号着色并验证与内部边界的邻接性。 

如果外对较早关闭，则序列分解为两个连续的平衡部分。 分割点由下式唯一确定`match[l]`。 

邻接检查很容易出错。 仅当两个相邻括号都着色并且共享相同颜色时我们才会拒绝。 未着色的括号永远不会冲突。 

另一个容易犯的错误是通过迭代任意分割点来重复计算串联。 正确的分解由第一个匹配对唯一确定。

import sys, io

MOD = 10**9 + 7

def solve():
    input = sys.stdin.readline

    s = input().strip()
    n = len(s)

    match = [-1] * n
    stack = []

    for i, ch in enumerate(s):
        if ch == '(':
            stack.append(i)
        else:
            j = stack.pop()
            match[i] = j
            match[j] = i

    dp = [[[[0] * 3 for _ in range(3)] for _ in range(n)] for _ in range(n)]

    for length in range(2, n + 1):
        for l in range(n - length + 1):
            r = l + length - 1

            if match[l] != r:
                continue

            if l + 1 == r:
                dp[l][r][1][0] = 1
                dp[l][r][2][0] = 1
                dp[l][r][0][1] = 1
                dp[l][r][0][2] = 1
                continue

            if match[l + 1] == r - 1:
                inner = dp[l + 1][r - 1]

                for a in range(3):
                    for b in range(3):
                        val = inner[a][b]

                        for c in [1, 2]:
                            if not (c == a and c != 0):
                                dp[l][r][c][0] += val

                        for c in [1, 2]:
                            if not (c == b and c != 0):
                                dp[l][r][0][c] += val

            else:
                m = match[l]

                for a in range(3):
                    for b in range(3):
                        left = dp[l][m][a][b]

                        for c in range(3):
                            for d in range(3):
                                right = dp[m + 1][r][c][d]

                                if b != 0 and b == c:
                                    continue

                                dp[l][r][a][d] += left * right

    ans = 0

    for a in range(3):
        for b in range(3):
            ans += dp[0][n - 1][a][b]

    print(ans % MOD)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    backup = sys.stdout
    sys.stdout = out

    solve()

    sys.stdout = backup
    return out.getvalue().strip()

 ## 边缘情况

 考虑最小的输入：```
()
```DP直接初始化四种状态：

 - 左红
 - 左蓝色
 - 右红
 - 右蓝色

 不需要邻接检查，因为没有相邻的彩色括号。 算法输出`4`。 

现在考虑相邻的平衡块：```
()()
```第一个间隔可以以红色括号结束，而第二间隔可以以红色括号开始。 在串联期间，算法检查：```
if b != 0 and b == c:
    continue
```这会拒绝接触括号共享相同颜色的无效合并。 

嵌套间隔的行为有所不同：```
(())
```如果外部开口支架是蓝色且内部开口支架也是蓝色，则在环绕过渡期间该配置将被拒绝，因为位置`0`和`1`是相邻的。 

同样，如果内部右括号和外部右括号共享一种颜色，则过渡在右边界处被拒绝。 

最后，考虑完全嵌套的输入：```
((()))
```每一层都引入了两个新的邻接检查。 DP 递归地处理这个问题，因为每个区间仅取决于其内部区间的边界颜色。 不需要全局扫描。
