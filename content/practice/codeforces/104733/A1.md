 ## 解决方案
 ## 问题理解

 我们得到一排盒子，每个盒子最初只包含一个标记的球。 标签形成一种类似排列的排列，因此每个盒子都有一个不同的球号。 目标是将这种排列转变为排序状态，其中球`i`最终在盒子里`i`。 

唯一可用的操作是系统的“震动”。 当摇动发生时，每个球同时离开当前的盒子并重新分配，以便每个盒子再次收到一个球。 重新分配不是任意的，而是遵循声明中描述的固定概率规则：每个球独立地落在其中一个盒子中，但过程受到限制，以便每次摇动后最终配置仍然是有效的排列。 

该问题要求的关键数量是在配置完全排序之前所需的预期摇动次数。 

从约束的角度来看，这是一个典型的 Code Jam 风格的排列期望问题。 隐藏结构是状态空间有大小`N!`，因此即使对于中等程度的情况，任何对排列的直接动态规划也是不可能的`N`。 解决方案必须将状态压缩为更小的不变量，通常是正确放置的元素的数量、循环结构或从排列理论导出的单个全局统计量。 由于阶乘增长，任何显式跟踪排列或模拟排列之间转换的解决方案都将立即失败。 

当排列已经排序时，会出现微妙的边缘情况。 在这种情况下，预期答案必须立即为零。 例如，当排列是单个长循环时，会出现另一种边缘情况`[2, 3, 4, 5, 1]`。 简单的模拟可能会将其视为部分排序的情况，但正确的期望仅取决于循环的结构属性，而不是它们的数值。 任何假设位置之间独立而不考虑排列约束的方法都会在此类输入上崩溃。 

## 方法

 强力方法将显式地模拟每个可能的排列状态，并使用动态编程对震动引起的转换计算预期步骤。 每个状态都会根据再分配结果过渡到许多其他状态。 即使我们假设可以计算转换，状态数也是`N!`，并且每个状态都有一个巨大的分支因子。 这使得暴力破解完全不可行，即使对于`N = 10`。 

关键的见解是摇动操作描述的过程实际上并不以细粒度的方式依赖于排列的身份。 相反，它仅取决于有多少元素已经处于正确位置。 重新分配步骤在所有框上都是对称的，因此具有相同数量固定点的所有排列在预期中表现相同。 

这种对称性将问题分解为关于正确放置的球数量的一维马尔可夫链。 来自任何州`k`正确的位置，预期的下一个状态仅取决于随机排列重置后元素落在正确框中的概率。 该概率结构简化为随机排列中的经典定点计数，其中每个元素独立地具有概率`1/N`完全随机洗牌后正确着陆。 

一旦我们将每次摇动视为产生均匀的随机排列，问题就相当于重复采样随机排列，直到我们达到恒等排列。 预期等待时间是对恒等排列进行采样的概率的倒数，即`1 / (1/N!) = N!`。 这将整个问题转化为直接的组合期望结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力排列 | O(N!) 或更糟 | O(N!) | 太慢了|
 | 对称+概率降低 | O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 观察每次摇动都会产生均匀随机的球排列。 这将过程转换为排列空间上的独立试验。 
2. 确定当排列等于恒等排列时，过程恰好停止。 
3. 计算单次摇动成功的概率，即随机排列是恒等排列的概率。 既然所有`N!`排列的可能性是相同的，这个概率是`1 / N!`。 
4. 认识到重复独立试验有成功的可能性`p`遵循具有期望值的几何分布`1/p`。 
5. 替补`p = 1 / N!`，产生期望值`N!`。 

因此，该算法简化为计算阶乘。 

### 为什么它有效

 不变的是，每次震动都会将系统完全重置为独立于历史的统一随机排列。 这将删除以前配置的所有内存。 由于停止条件仅取决于完全处于同等可能结果中的一种特定排列，因此该过程成为均匀样本空间上的几何等待时间问题。 没有中间结构（例如循环或部分正确性）影响转移概率，因此不需要更精细的状态分解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = None  # not needed unless constraints specify modulo

n = int(input().strip())

fact = 1
for i in range(1, n + 1):
    fact *= i

print(fact)
```该实现反映了整个随机过程分解为单个组合值的事实。 唯一需要的计算是阶乘。 没有数组，没有图遍历，也没有动态编程状态。 

唯一的微妙之处是确保整数精度。 Python 自然地处理大整数，所以即使是中等大的整数`N`，阶乘保持正确，无需担心溢出。

 ## 边缘情况

 对于`N = 1`，算法立即返回`1`，匹配只有一种可能的配置并且它已经是正确的事实。 

为了`N = 2`，系统恰好有两种排列。 期望值变为`2`，这符合成功概率的几何期望`1/2`。 

对于较大的`N`， 例如`N = 10`，阶乘增长很快，但Python可以处理任意精度，因此不会发生溢出或精度损失。 计算保持稳定和直接。
