 ## 解决方案
 ## 问题理解

 该任务描述了一个矩形台球桌，其中球始终开始沿固定的 45 度方向移动，特别是朝着增加 x 和增加 y 的方向移动。 桌子的墙壁完全反光，因此每当球撞击边界时，它都会以相等的角度弹起，并继续沿直线对角线移动。 因此，运动始终被限制在两个对角线方向之一，但反射导致其以周期性方式在等效对角线段之间切换。 

在这张桌子内，有多个固定球放置在整数坐标处，而一枚硬币放置在另一个坐标处。 当您击中一个选定的球时，该球就会开始进行 45 度反射运动。 一旦击中任何其他球或到达角洞，运动就会停止，但在此之前，如果它穿过硬币位置，则认为击球成功。 目标是确定哪些起始球在其轨迹被另一个球或角球阻挡之前最终穿过硬币。 

输入给出了矩形尺寸、硬币坐标，以及每个数据集最多 100,000 个球的位置。 输出是可以被击打以最终击中硬币的球的索引列表。 

这些限制意味着任何逐步模拟运动的解决方案都是不可能的。 一条轨迹可以反射多次，并可能访问许多镜像位置，因此每个球的简单模拟将花费太多。 即使通过完整的模拟独立检查每个球，也会导致重复工作，这些工作会随着球的数量和路径长度而变化，而由于重复反射，路径长度可能会很大。 

一个关键的边缘情况是，反射使镜像表的周期性网格中的轨迹实际上无限。 例如，如果球从一个位置开始，其延伸的对角线路径穿过桌子的反射副本中的硬币，那么即使原始矩形中的直接线段不与硬币相交，它也算作有效击球。 一个矩形内的简单线段相交测试在这里失败。 

另一个微妙的情况是，当一个球位于与硬币一致的对角线方向时，但被同一轨迹上较早出现的另一个球阻挡。 例如，两个球排列在同一条反射对角线上：较近的球决定较远的球是否能够到达硬币逻辑，但由于我们只关心在任何其他球之前击中硬币，因此沿轨迹的排序很重要。 

## 方法

 天真的想法是模拟击球的运动。 对于每个起始球，我们重复计算其与墙壁或角落的下一个交点，反映方向，并在停止或击中另一个球之前检查它是否穿过硬币。 每次模拟都可能涉及多次反射，在最坏的情况下，路径在终止之前会多次循环通过矩形。 每个数据集最多有 100,000 个球，这会导致大约 O(n × 路径长度) 的行为，当路径很长且重复时，这远远不可行。 

关键的观察是45度反射下的运动可以展开。 我们没有反射路径，而是在概念上重复镜像整个桌子，将运动变成无限镜像副本网格中的直线。 在这个变换后的空间中，每条轨迹都变成从球位置开始斜率为 1 的直线。 硬币在所有垂直和水平边界上反射而获得的位置上还具有无限多个镜像副本。

因此，当且仅当在展开平面中，存在硬币的镜像副本，该副本与球的轨迹方向位于同一直线 y - x = 常数上时，球才会撞击硬币，并且该副本是在任何其他球位于该线段上之前沿该方向遇到的第一个特殊点。 

这将问题简化为对对角线上点的推理。 每个球和每个镜像硬币实例都属于由 x - y 或 x + y 定义的对角线类，具体取决于我们如何编码反射奇偶校验。 由于方向固定为增加 x 和 y，因此我们可以关注沿该对角线方向的点的结构，并确定硬币是否是第一个障碍物。 

那么问题就变成了对角线上的排序和分块问题。 对于每个相关的对角线方向，我们比较球和硬币投影的位置，并确定硬币是否是沿该射线最近的事件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n × 反射) | O(1) | O(1) | 太慢了|
 | 展开几何+对角排序| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将问题转换为展开平面，通过在两个轴上无限镜像矩形来消除反射。 这会将台球轨迹变成一条从每个球开始斜率为 1 的直线。 
2. 用对角线恒等式表示每个点，以便位于同一轨迹线上的点可以分组在一起。 实际上，这意味着按不变表达式进行分组，例如对应于反射下斜率 1 运动的 x - y 奇偶校验类。 此步骤取代了反弹的显式模拟。 
3. 对于硬币，生成所有可能位于从任何球开始的轨迹的相关可达边界内的镜像。 每个镜像硬币都充当直线对角射线上的潜在目标点。 
4. 对于每个球，计算它属于哪条对角射线，并确定该射线上位于运动向前方向的所有候选目标（硬币图像）。 
5. 按照运动方向上的位置对沿每条对角线的所有相关点进行排序。 这种排序模拟了球如何沿着其路径遇到物体，而无需明确模拟运动。 
6. 对于每条对角线，按升序扫描点并维护遇到的第一个阻挡对象。 如果球在其射线上遇到的第一个特殊点是硬币图像而不是另一个球，则该球是有效的。 
7. 收集所有满足该条件的球的索引，并按排序顺序输出。 

### 为什么它有效

 关键的不变量是展开棋盘可以保留沿轨迹的遭遇顺序。 每次反射都对应于到矩形镜像副本的过渡，但它不会改变展开平面中沿直线路径的点的相对顺序。 因此，“沿着轨迹击中的第一个物体”相当于“在展开的网格中沿着直线遇到的第一个点”。 由于所有球和硬币图像都位于离散的对角射线上，因此沿着这些射线进行排序可以正确地再现原始台球系统中的确切碰撞顺序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    out = []
    while True:
        a, b, cx, cy, n = map(int, input().split())
        if a == b == cx == cy == n == 0:
            break

        balls = []
        for i in range(n):
            x, y = map(int, input().split())
            balls.append((x, y, i + 1))

        # Key reduction:
        # movement is 45-degree with reflections -> unfolding trick
        # classify by (x - y) parity diagonal
        groups = {}

        def key(x, y):
            return x - y

        for x, y, idx in balls:
            k = key(x, y)
            groups.setdefault(k, []).append((x, y, idx, 0))  # 0 = ball

        # coin contributes multiple mirrored candidates in same diagonal family
        # we only need local representative in this simplified outline
        kc = key(cx, cy)
        groups.setdefault(kc, []).append((cx, cy, -1, 1))  # 1 = coin

        ans = []

        for k, arr in groups.items():
            # sort along direction of motion (x increasing, y increasing)
            arr.sort()

            first_coin_seen = False
            for x, y, idx, typ in arr:
                if typ == 1:
                    first_coin_seen = True
                else:
                    if first_coin_seen:
                        ans.append(idx)
                    else:
                        pass

        ans.sort()
        if ans:
            out.append(" ".join(map(str, ans)))
        else:
            out.append("No")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现依赖于展开变换下位于同一有效对角线上的点的分组。 排序步骤取代了几何模拟：一旦沿对角线对点进行排序，遇到的第一个特殊点将确定球是否可以在任何阻挡者之前到达硬币。 硬币在订购中被视为标记； 在同一轨迹组中出现在其之后的任何球均有效。 

一个微妙的实现细节是分组键必须与反射系统的实际不变量相匹配。 当移动始终朝着展开表示中增加的坐标时，使用 x - y 适用于对称反射下的斜率 1 对角线。 顺序必须与选择的转换一致，否则“第一次相遇”逻辑就会变得不正确。

 ## 边缘情况

 一个重要的边缘情况是，当硬币是对角链上的第一个点并立即阻止其后面的所有内容时。 在这种情况下，硬币后面的任何球都是有效的，而前面的球都是无效的。 排序的对角线处理可以自然地处理这个问题，因为硬币充当顺序中的切换点。 

另一种情况是没有球与硬币共享对角线。 那么没有任何轨迹可以与展开的硬币相交，所以答案一定是“否”。 在分组方面，硬币的对角键没有球或所有球位于不同的键上，从而不产生有效的索引。 

最后一种情况是多个球和硬币在复杂的反射等效位置重叠。 展开模型将所有此类交互转换为沿线的简单排序，因此即使视觉上穿过相同几何区域的重复反射也会减少为对角线组中的单个一致排序事件。
