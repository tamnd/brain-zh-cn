 ## 解决方案
 ## 问题理解

 我们有一个变量链$x_1, x_2, \dots, x_n$，每个值取自$1$到$v$。 

对于每个相邻对，存在以下形式的二元约束：$$x_i=a_i \implies x_{i+1}=b_i$$价值观$a_i$和$b_i$未知。 我们只知道一些固定某些变量的一元约束：$$x_{c_j}=d_j$$任务是计算所有对有多少种选择$(a_i,b_i)$使整个系统可满足，这意味着所有变量至少存在一个满足每个一元和二元约束的分配。 

输入包含多个测试用例。 每个测试用例给出$n,m,v$，随后是$m$一元约束。 

问题的不寻常部分是约束大小。 变量个数可以达到$10^9$，所以任何一个一一处理位置的算法都是不可能的。 另一方面，一元约束的数量最多为$10^5$，这强烈表明只有固定位置才重要，并且它们之间的所有内容都必须用公式处理。 

第一个边缘情况是同一位置上矛盾的一元约束。 

例子：```
n = 2, v = 2
x1 = 1
x1 = 2
```没有变量的赋值可以满足这两个要求，所以答案是 0。 

第二种边缘情况是只有一个固定位置时。 那么固定值之间就没有交互作用。 我们可以简单地选择该变量的规定值，并避免触发任何有问题的含义。 每个二元约束分配都变得有效。 

例子：```
n = 3, v = 2
x2 = 1
```全部$(v^2)^{n-1}=4^2=16$选择是有效的。 

第三种边缘情况是两个固定位置相邻时。 

例子：```
x1 = 1
x2 = 2
```它们之间恰好存在一个二元约束。 只有一个选择$(a_1,b_1)$引起矛盾，即$(1,1)$。 所有其他选择仍然是令人满意的。 

粗心的推理经常忘记约束仅在以下情况下才被激活：$x_i=a_i$。 

## 方法

 暴力解决方案将枚举每个的所有可能值$a_i$和$b_i$。 由于每对都有$v^2$可能性并且有$n-1$边缘，这给出$$(v^2)^{n-1}$$配置。 

对于每个配置，我们可以测试变量的某些分配是否满足所有约束。 

这是正确的，但即使输入很小，它也会立即爆炸。 

关键的观察结果是二元约束非常弱。 仅当左侧变量等于一个特定值时，约束才会激活$a_i$。 如果我们可以选择$x_i\neq a_i$，该约束变得无关紧要。 

正因为如此，矛盾只能通过连续的激活暗示链来传播。 

假设有两个位置$l$和$r$由一元约束固定。 我们问：

 它们之间的二元约束有多少种选择可以使系统满足？ 

倒数比较容易。 

仅当位置固定值时才会发生矛盾$l$强制一条独特的链条一直定位$r$，最终的强制值与固定值不一致$r$。 

为了实现这一点，路径上的每一个含义都必须激活：$$a_l=x_l,\quad
a_{l+1}=b_l,\quad
a_{l+2}=b_{l+1},\dots$$在最后一个边缘，我们必须强制使用与$x_r$。 

如果距离是$d=r-l$， 然后：$$b_l,b_{l+1},\dots,b_{r-2}$$可以任意选择，给出$v^{d-1}$的可能性。 

最后一个值$b_{r-1}$必须不同于$x_r$, 给予$v-1$的可能性。 

因此，错误配置的数量是$$v^{d-1}(v-1).$$该段中的所有二进制约束都有$$(v^2)^d=v^{2d}$$可能的分配，因此好的分配的数量是$$f(d)=v^{2d}-v^{d-1}(v-1).$$现在请注意一些更强大的东西。 

只有一元约束固定的位置才重要。 第一个固定位置之前和最后一个固定位置之后的区域总是可以选择变量值，以避免激活麻烦的含义。 每个二元约束分配都是有效的。 

因此，整个答案分解为连续固定位置之间的独立部分。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O((v^2)^{n-1})$| 巨大| 太慢了|
 | 最佳|$O(m \log MOD)$|$O(m)$| 已接受 |

 ## 算法演练

 1. 读取所有一元约束。 
2. 将它们存储在按位置键入的地图中。 
3、如果出现相同的位置，要求的值不同，则立即输出0，因为一元约束已经不一致。 
4. 对剩余的固定位置进行排序。 
5. 设排序后的固定位置为：$$p_1<p_2<\dots<p_k.$$1. 将答案乘以$$v^{2(p_1-1)}$$对于第一个固定位置之前的无约束前缀。 

1. 对于每一个连续的对$(p_i,p_{i+1})$， 让$$d=p_{i+1}-p_i.$$将答案乘以$$v^{2d}-v^{d-1}(v-1).$$这会计算该段内所有有效的二进制约束分配。 

1. 将答案乘以$$v^{2(n-p_k)}$$对于最后一个固定位置之后的无约束后缀。 

1.输出答案模数$10^9+7$。 

### 为什么它有效

 仅当左固定值激活段中的每个含义，创建到达右端点并要求与其固定值不同的值的强制链时，由两个固定位置界定的段才会变得不可满足。 

该链中的任何中断都会立即恢复可满足性，因为可以自由选择剩余的变量。 

不良配置正是上述连续的强迫链，其数量为$v^{d-1}(v-1)$。 

不同的段涉及不相交的二元约束集，因此它们的选择是独立的。 将每个部分的贡献相乘即可得到有效分配的总数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def solve():
    t = int(input())

    for _ in range(t):
        n, m, v = map(int, input().split())

        fixed = {}
        ok = True

        for _ in range(m):
            c, d = map(int, input().split())

            if c in fixed and fixed[c] != d:
                ok = False
            fixed[c] = d

        if not ok:
            print(0)
            continue

        pos = sorted(fixed.keys())

        ans = 1

        first = pos[0]
        ans = ans * pow(v, 2 * (first - 1), MOD) % MOD

        for i in range(len(pos) - 1):
            d = pos[i + 1] - pos[i]

            total = pow(v, 2 * d, MOD)
            bad = pow(v, d - 1, MOD) * ((v - 1) % MOD) % MOD

            ans = ans * ((total - bad) % MOD) % MOD

        last = pos[-1]
        ans = ans * pow(v, 2 * (n - last), MOD) % MOD

        print(ans)

solve()
```代码的第一部分检查一元约束是否自洽。 如果一个位置被分配了两个不同的值，则不存在解，答案立即为零。 

排序的固定位置定义了可以实际测试可满足性的唯一位置。 这些位置之外的一切都贡献了纯粹的力量$v^2$，因为可以任意选择二元约束。 

对于每个段，我们计算：$$v^{2d}$$对于所有可能的二元约束分配并减去$$v^{d-1}(v-1)$$对于造成矛盾的独特作业系列。 

所有求幂都使用Python的模数`pow`，它以对数时间运行并且很重要，因为$n$和$v$都可以达到$10^9$。
