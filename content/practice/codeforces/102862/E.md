 ## 解决方案
 ## 问题理解

 我们有一个表示为二维等腰三角形的蛋卷冰淇淋。 圆锥体有高度`h`其顶部开口有宽度`w`。 圆锥体的下部已经装满了冰淇淋，达到一定高度`l`，创建一个水平表面，必须放置两个相同的圆形冰淇淋勺。 这两个圆必须接触水平冰淇淋表面，适合圆锥体内部，并且可以相互接触，但不能重叠。 任务是找到这两个圆的最大可能半径。 

测试用例的数量可以大到`10^4`，而尺寸可以达到`10^9`。 这排除了任何依赖于所模拟的几何形状的大小或迭代可能的半径的方法。 该解决方案必须为每个测试用例持续工作，因为即使`O(t log C)`当存在直接公式时，大量二分搜索迭代将是不必要的开销。 

棘手的部分是，两个圆同时受到两个不同条件的限制。 一个天真的解决方案可能只考虑锥体壁，而忘记两个勺子也需要彼此相邻。 另一个常见的错误是使用全锥体宽度`w`顶部的宽度而不是放置圆圈的高度的宽度。 

考虑示例输入：```
1
10 8 8
```圆锥体的顶部比冰淇淋表面宽得多。 如果有人使用`w = 8`直接作为圆圈的可用宽度，他们高估了答案。 正确的半径约为：```
1.908131846
```第二种边缘情况是锥体非常窄时。 例如：```
1
100 99 1
```填充物上方的可用空间很小，因为锥体仅比填充物水平稍宽。 假设球总是可以接触顶部开口的解决方案将产生不正确的值。 

最后一个重要的情况是当两个限制相等时。 当每个圆接触圆锥体的一侧并且两个圆彼此接触时，就会发生最佳放置。 忽略圆与圆的限制会产生物理上无法匹配的半径。 

## 方法

 直接的暴力方法将尝试可能的半径并检查是否可以放置两个该大小的圆。 对于固定半径，我们可以计算每个圆必须放置在锥壁上的位置，并测试两个圆是否重叠。 这是可行的，因为放置是由几何形状决定的，但是通过扫描许多候选半径来找到确切的答案太慢了。 尺寸可达`10^9`，尝试足够的精度值将需要对每个`10^4`测试用例。 

关键的观察结果是最终的排列是由相切强制的。 在最佳配置中，进一步增加半径将立即引起碰撞。 这意味着圆必须同时接触锥体侧面并相互接触。 

圆锥体随高度线性扩展。 如果我们观察其中一个圆，它的中心必须恰好位于填充水平上方一个半径处，因为它接触水平表面。 一旦圆接触倾斜的墙壁，其水平位置就确定了。 唯一剩下的条件是两个对称圆必须至少有圆心`2r`分开。 将此距离精确设置为`2r`直接给出最大可能的半径。 

让：```
s = w / (2h)
```这是圆锥体一侧的斜率。 对于半径为圆的圆`r`，其中心位于高度`l + r`。 从中心到圆锥体轴线的水平距离变为：```
x = s(l + r) - r * sqrt(1 + s^2)
```在最大尺寸时，两个圆相互接触，因此中心距正好是一个直径：```
x = r
```求解该方程得出：```
r = s * l / (1 + sqrt(1 + s^2) - s)
```该公式是常数时间并且仅使用浮点运算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(迭代次数 × t) | O(1) | O(1) | 太慢了|
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将圆锥体几何形状转换为斜率。 圆锥体高度的半宽`y`正比于`y`，所以边坡为`s = w / (2h)`。 这让我们可以使用简单的直线方程来描述锥壁。 
2. 假设两个圆围绕圆锥体中心对称。 他们的中心必须在高处`l + r`因为圆圈接触现有冰淇淋的水平表面。 
3. 计算圆心与锥壁相切时的水平位置。 从中心到圆锥体斜边的距离必须等于半径，即：```
x = s(l + r) - r * sqrt(1 + s^2)
```4. 利用以下事实：当圆圈彼此接触时，圆圈尽可能大。 他们的中心被分开`2x`，所以极限情况是：```
x = r
```5. 重新排列方程以直接求解`r`:```
r = s * l / (1 + sqrt(1 + s^2) - s)
```6. 以足够的精度打印所得的半径。 

为什么它有效：

 具有固定半径的圆的放置不是任意的。 为了最大化半径，向外移动圆直到接触锥壁只能增加可用空间，因此最佳圆必须接触锥壁。 两个圆是对称的，如果它们不互相接触，则它们都可以在保持有效的情况下稍微增加。 因此，最大配置具有两侧相切和圆之间的相互相切。 该算法求解的方程准确地描述了这种限制配置，因此其半径是可能的最大半径。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        h, l, w = map(int, input().split())

        s = w / (2.0 * h)
        r = s * l / (1.0 + math.sqrt(1.0 + s * s) - s)

        ans.append(f"{r:.12f}")

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```输入一次处理一个测试用例，因为每个用例都是独立的。 价值`s`使用浮点运算存储锥体侧面的斜率，这是必要的，因为最终答案通常不是整数。 

表达式为`r`直接计算而不是使用二分搜索。 这避免了精确调整并保持运行时间恒定。 这`math.sqrt`call 处理几何距离公式，打印小数点后十二位数字足以满足要求`10^-6`准确性。 

不存在边界索引问题，因为计算仅使用算术值。 Python 的浮点类型在这里也足够了，因为最大的输入值仅是`10^9`，远低于发生溢出的范围。

 ## 边缘情况

 对于第一个边缘情况，请考虑：```
1
10 8 8
```填充高度处的锥体宽度与顶部宽度不同。 该算法从不直接使用顶部宽度。 相反，它使用斜率`w / (2h)`并计算边线的实际几何形状。 这可以防止高估可用空间。 

对于窄锥体情况：```
1
100 99 1
```斜率是：```
s = 1 / 200 = 0.005
```该公式返回的半径约为`0.496261`。 圆圈几乎填满了剩余的高度，但它们的宽度受到窄边的限制。 仅基于垂直空间的方法会错误地返回更大的值。 

对于极限相切情况：```
1
10 8 8
```计算出的半径将每个圆精确地放置在其圆锥边上，并精确地放置在另一个圆上。 增加半径会使中心的距离小于一个直径，从而导致重叠。 算法使用的不变量被保留，因为返回的半径始终表示碰撞前的最后一个有效配置。
