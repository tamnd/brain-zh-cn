 ## 解决方案
 ## 问题理解

 我们得到了从 1 到 n 的数字排列。 任务是将其元素分成两组，同时保留它们在每组内的原始顺序。 每个组必须形成一个递增子序列，并且排列的每个元素必须恰好属于其中一个。 在所有有效的分割中，我们希望两个子序列长度之间的差异尽可能大。 如果不存在这样的分裂，我们必须报告这一情况。 

输入大小可以达到500000个元素。 这立即排除了对位置的动态规划、检查所有子序列选择或任何具有二次行为的方法。 由于一秒的限制，我们需要一个接近线性或 n log n 的解决方案。 排列结构是允许这种减少的原因。 

主要的边缘情况来自这样的事实：仅靠最大递增子序列是不够的。 一个排列可能有一个很长的递增子序列，而其余元素不能形成第二个所需子序列。 

例如：```
Input:
4
4 2 3 1

Output:
-1
```最长递增子序列的长度为 2，例如 2、3。粗心的解决方案可能会假设答案为 0，因为其余两个元素具有相同的大小。 然而，其余元素 4, 1 并没有增加，并且每一种可能的选择都会使一个子序列无效。 

另一个重要的情况是完全递增的排列。```
Input:
5
1 2 3 4 5

Output:
5
```整个排列已经是递增的，因此一个子序列可以包含每个元素，而另一个子序列可以为空。 强制两个子序列都非空的解决方案在这里会失败。 

最终的边界情况是长度为二的递减排列。```
Input:
2
2 1

Output:
0
```可以将每个元素放入其自己的子序列中。 答案不是否定的，并且不需要空子序列。 

## 方法

 一个直接的蛮力想法是尝试将排列的每个可能的划分分为两组。 对于每个分区，我们将检查两个选择的序列是否都在增加并保持最佳差异。 由于每个元素都有两个选择，这需要检查最多 2^n 个分区，即使对于非常小的 n 也是不可能的。 

一种更合理但仍然不够的方法是找到最长的递增子序列。 如果其长度为 L，则剩余的 n-L 个元素是任何递增子序列之外的最小可能元素数。 然而，这个问题需要剩余元素本身不断增加。 示例 4,2,3,1 说明了为什么此条件很重要。 

关键的观察来自增加子序列和减少子序列之间的关系。 当一个排列不包含长度为三的递减子序列时，它可以准确地分为两个递增子序列。 这是根据迪尔沃斯定理得出的，但在这种特殊情况下也可以直接理解：每个长度为 3 的递减子序列都需要三个不同的递增群来分隔其元素。 

一旦我们知道划分是可能的，最佳的较大子序列就是最长递增子序列。 它的补码也必须是递增的，因为否则补码将包含递减对，并且与最长的递增子序列一起，它将与宽度二结构相矛盾。 因此，如果LIS长度为L，则两个尺寸为L和n-L，最大差为L-(n-L)，等于2L-n。 

剩下的任务是检查排列是否具有长度为 3 的递减子序列并计算 LIS 长度。 两者都可以在 O(n log n) 内完成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n * n) | O(2^n * n) | O(n) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算最长递减子序列的长度。 我们可以通过将标准 LIS 算法应用于排列的负值来做到这一点。 如果该长度至少为 3，则排列无法拆分为两个递增子序列，因此答案为 -1。 
2. 计算排列的最长递增子序列的长度L。 耐心排序技术为每个长度的增加子序列保留尽可能小的结束值，从而允许在 O(n log n) 内进行计算。 
3. 利用以下事实：有效分割仅存在于两个递增子序列之间。 较大的子序列的长度可以为 L，另一个子序列的长度为 n-L。 因此最大差值为 L-(n-L)，即 2L-n。 

为什么它有效：

 划分条件由最长递减子序列控制。 如果三个元素按降序出现，则任何两个递增子序列都不能包含它们而不破坏递增性质，因此不可能进行有效划分。 如果最长递减子序列的长度至多为 2，则排列的宽度至多为 2，并且可以分为两个递增子序列。 这种分区的最大可能成员是最长递增子序列。 将其视为较大的部分留下递增的补充，因此从LIS获得的差异是可以实现的。 由于递增子序列不能比 LIS 更长，因此不存在更好的差异。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def lis_length(arr):
    tails = []
    import bisect
    for x in arr:
        pos = bisect.bisect_left(tails, x)
        if pos == len(tails):
            tails.append(x)
        else:
            tails[pos] = x
    return len(tails)

def solve():
    n = int(input())
    p = list(map(int, input().split()))

    if lis_length([-x for x in p]) >= 3:
        print(-1)
        return

    length = lis_length(p)
    print(2 * length - n)

if __name__ == "__main__":
    solve()
```这`lis_length`函数是标准的耐心排序实现。 这`tails[i]`value 表示长度递增子序列的最小可能结束值`i + 1`。 保持这些结尾最少可以为未来的元素提供扩展子序列的最佳机会。 

第一次调用使用负值。 求反数组中的递增子序列对应于原始排列中的递减子序列。 我们只需要知道这样的子序列是否达到长度三，因此这个单一的 LIS 计算足以验证分区条件。 

第二次调用计算实际最长递增子序列长度。 最终的表达`2 * length - n`直接从较大的组大小减去较小的组大小得出。 Python 整数处理可能的值范围而不会溢出。

import sys
import io
import bisect

def solution(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    def lis_length(arr):
        tails = []
        for x in arr:
            pos = bisect.bisect_left(tails, x)
            if pos == len(tails):
                tails.append(x)
            else:
                tails[pos] = x
        return len(tails)

    n = int(input())
    p = list(map(int, input().split()))

    if lis_length([-x for x in p]) >= 3:
        return "-1\n"

    return str(2 * lis_length(p) - n) + "\n"

 ## 边缘情况

 对于不可能的情况：```
Input:
4
4 2 3 1
```求反数组包含一个长度为 3 的递增子序列，对应于原始递减序列 4, 3, 1。由于三个递减元素不能仅放入两个递增子序列中，因此算法立即返回 -1。 

对于完全递增的情况：```
Input:
5
1 2 3 4 5
```最长递减子序列的长度为一，因此划分是有效的。 LIS 长度为 5，给出`2*5-5 = 5`。 这相当于将每个元素放入一个子序列中，而将另一个元素留空。 

对于二元递减情况：```
Input:
2
2 1
```最长递减子序列长度为二，这仍然是允许的。 LIS 长度为 1，所以答案为`2*1-2 = 0`。 唯一可能的分割使两个子序列的长度均为一。
