 ## 解决方案
 # 问题理解

 我们有一系列相同的方形盒子，放置在由两个对角墙制成的存储形状内。 坐标系通过两个索引描述每个框：一个从左壁开始计数层，一个从右壁开始计数层。 由于排列是稳定的，占据的位置形成了一个类似楼梯的形状，其中支撑另一个盒子的每个盒子都已经存在。 

最低的盒子，即接触两面墙壁的盒子，被移除。 它留下的空位置变成了一个洞。 重力使洞向上穿过堆垛：要么一侧紧邻其上方的盒子掉落，要么另一侧紧邻其上方的盒子掉落。 盒子掉落后，洞会移动到盒子之前的位置。 当洞到达没有盒子可以落入其中的位置时，该过程停止。 

任务是计算可能有多少种不同的下降选择序列。 答案必须以模数形式打印$10^9+7$。 

输入最多包含$10^5$盒子，每个坐标最多$n$。 二次模拟是不可能的，因为$10^{10}$在最大的情况下已经需要进行操作。 我们需要一个只处理每个盒子少量次数的解决方案，这指向$O(n)$或者$O(n \log n)$方法。 

主要的边缘情况来自于混淆最终位置和下降序列。 即使洞在同一位置结束，不同的选择也可能导致不同的历史。 例如，考虑：```
5
1 1
1 2
2 1
2 2
3 1
```正确答案是：```
3
```粗心的方法可能只计算最终可能的空单元格。 该洞可以结束于`(2,2)`或者`(3,1)`，它给出了两个最终状态，但是存在三种可能的下降序列，因为孔可以到达`(2,2)`以两种不同的方式。 

另一个极端情况是单个盒子：```
1
1 1
```答案是：```
1
```没有选择可以做。 唯一可能的情况是，移除的盒子留下一个空的储藏室。 

第三种情况是直桩：```
3
1 1
2 1
3 1
```答案是：```
1
```每个孔位置恰好有一个可能的下落框，因此该过程没有分支。 

# 方法

 直接模拟将遵循每一个可能的下降序列。 从移除的底部盒子开始，我们递归地尝试每一个可能的盒子来填充这个洞。 这是正确的，因为每个有效场景都是这些选择的一个序列。 

问题是这个递归可以分支很多次。 在密集的楼梯状堆中，可以存在许多不同的路径，单独探索它们可能需要指数级的时间。 不同的序列会重复到达相同的孔位置，因此蛮力方法会重复工作。 

关键的观察是，任何时刻唯一重要的是洞的当前位置。 如果洞到达某个盒子位置，则到达该位置的方式数量与产生该洞的确切顺序无关。 这使我们能够合并所有等效状态。 

该问题变成了占用单元上的动态编程问题。 一个单元格在下落过程中接收来自其下方单元格的路径总和。 由于孔仅通过增加一个坐标来移动，因此该图没有循环。 我们可以按升序处理细胞`x + y`。 

对于每个单元格，我们存储孔到达那里的方式数量。 如果一个单元格没有可能的下一步行动，它代表一个已完成的场景，因此它的值有助于答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 分支细胞数量呈指数增长 | O(n) 递归深度 | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将每个占用的盒子位置存储在一个集合中，以便检查相邻盒子是否存在需要恒定的时间。 坐标形成有向无环图，因为每次移动都会增加`x`或者`y`。 
2. 按递增对框进行排序`x + y`。 这为动态规划提供了有效的顺序，因为孔只能从较小的坐标和移动到较大的坐标和。 
3.设置到达移除底部位置的方式数`(1,1)`到一。 这代表下降过程的开始。 
4. 按排序顺序访问每个盒子。 对于当前位置`(x,y)`，将其当前的方法数量添加到`(x+1,y)`如果那个盒子存在的话。 这对应于左侧的盒子掉入洞中。 
5.添加当前的路数`(x,y+1)`如果那个盒子存在的话。 这对应于右侧的盒子掉入洞中。 
6. 处理完所有转换后，将每个方向上没有直接位于其下方的框的每个框的值相加。 这些是洞停止的位置，因此每一条结束于此的路径都有一个有效的场景。 

为什么它有效：

 不变的是`dp[x][y]`等于将孔从原始空位置移动到的可能下落序列的数量`(x,y)`。 起始状态有一个空序列。 每当空洞到达一个单元格时，唯一可能的下一个状态是可以落入其中的两个相邻盒子，因此将当前计数添加到这些单元格中就可以将每个可能的延续恰好计算一次。 因为每一个可能的场景都是一条路径`(1,1)`对于终端单元，将所有终端状态相加得出最终答案。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    boxes = []
    box_set = set()

    for _ in range(n):
        x, y = map(int, input().split())
        boxes.append((x, y))
        box_set.add((x, y))

    boxes.sort(key=lambda p: p[0] + p[1])

    dp = {}

    for x, y in boxes:
        dp[(x, y)] = 0

    dp[(1, 1)] = 1

    for x, y in boxes:
        cur = dp[(x, y)]

        if (x + 1, y) in box_set:
            dp[(x + 1, y)] = (dp[(x + 1, y)] + cur) % MOD

        if (x, y + 1) in box_set:
            dp[(x, y + 1)] = (dp[(x, y + 1)] + cur) % MOD

    ans = 0

    for x, y in boxes:
        if (x + 1, y) not in box_set and (x, y + 1) not in box_set:
            ans = (ans + dp[(x, y)]) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```套装`box_set`提供恒定时间的邻居检查。 因为每个位置只有两种可能的移动，所以不需要邻接表。 

排序步骤是隐式图的拓扑排序。 坐标在下降期间总是增加，因此处理更小`x + y`值首先保证所有传入的状态转换在使用之前都已被考虑。 

字典`dp`存储到达每个占用位置的路径数。 Python整数不会溢出，但每次更新都会进行模减$10^9+7$以保持存储的值较小。 

最终状态检查恰好使用从一个位置开始的两种可能的移动。 如果两个邻居都不存在，则该框是停止点。 在 DP 之后检查此项可以避免在转换期间进行任何特殊处理。 

# 工作示例

 对于样本：```
5
1 1
1 2
2 2
3 1
2 1
```排序顺序已经是：

 | 细胞| 目前的方式| 添加`(x+1,y)`| 添加`(x,y+1)`|
 | ---| ---| ---| ---|
 |`(1,1)`| 1 |`(2,1)`得到 1 |`(1,2)`得到 1 |
 |`(1,2)`| 1 |`(2,2)`得到 1 | 无 |
 |`(2,1)`| 1 |`(3,1)`得到 1 |`(2,2)`又得到 1 |
 |`(2,2)`| 2 | 无 | 无 |
 |`(3,1)`| 1 | 无 | 无 |

 终端细胞是`(2,2)`和`(3,1)`。 他们的价值观是`2`和`1`，给出答案`3`。 

此示例说明了为什么仅对终端位置求和是不够的。 通过多次选择可以到达相同的最终空位置。 

直链：```
3
1 1
2 1
3 1
```产生：

 | 细胞| 目前的方式| 下一个单元 |
 | ---| ---| ---|
 |`(1,1)`| 1 |`(2,1)`|
 |`(2,1)`| 1 |`(3,1)`|
 |`(3,1)`| 1 | 停止|

 只有一条路，所以答案是`1`。 

# 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 每个盒子都排序一次并通过两次邻居检查进行处理 |
 | 空间| O(n) | 一组框和 DP 表每个框最多包含一个条目 |

 的约束条件为$10^5$方框意味着线性解决方案很容易符合典型的竞赛限制。 该算法从不探索单个跌倒场景，只探索所有场景共享的状态。

import sys
import io

MOD = 10**9 + 7

def solution(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    try:
        data = sys.stdin.readline
        n = int(data())
        boxes = []
        box_set = set()

        for _ in range(n):
            x, y = map(int, data().split())
            boxes.append((x, y))
            box_set.add((x, y))

        boxes.sort(key=lambda p: p[0] + p[1])

        dp = {p: 0 for p in boxes}
        dp[(1, 1)] = 1

        for x, y in boxes:
            cur = dp[(x, y)]
            if (x + 1, y) in box_set:
                dp[(x + 1, y)] = (dp[(x + 1, y)] + cur) % MOD
            if (x, y + 1) in box_set:
                dp[(x, y + 1)] = (dp[(x, y + 1)] + cur) % MOD

        ans = 0
        for x, y in boxes:
            if (x + 1, y) not in box_set and (x, y + 1) not in box_set:
                ans = (ans + dp[(x, y)]) % MOD

        return str(ans) + "\n"
    finally:
        sys.stdin = old_stdin

 # 边缘情况

 对于单盒情况：```
1
1 1
```DP 从一种方式开始`(1,1)`。 该单元没有邻居，因此被视为最终状态。 答案依然存在`1`。 

对于多条路径到达同一终点的示例：```
5
1 1
1 2
2 1
2 2
3 1
```该算法存储了两种不同的到达方式`(2,2)`通过DP加法分别进行。 当单元格被处理时，它的值为`2`， 不是`1`，所以两条历史都被计算在内。 

对于直桩：```
3
1 1
2 1
3 1
```每个状态都只有一个传出边缘。 DP值保持不变`1`贯穿整个链条，只有最后一个单元格才能得出答案。 这可以防止在没有分支时出现过度计数。
