 ## 解决方案
 # 问题理解

 该问题描述了一个二进制数组，其位置可以视为图的顶点。 每个允许的操作都是一个边：使用该边翻转其端点处的两位。 从全零数组开始，我们需要决定是否可以生成给定的目标位配置。 

输入给出了位置的数量、所需的最终位以及可以一起翻转的位置对的列表。 输出是这些对翻转的某些排序和重复是否可以准确地创建目标数组。 

这些限制足够大，模拟操作是不现实的。 高达$10^5$职位和$10^5$操作，即使是反复尝试可用操作的方法也可以达到$10^{10}$在最坏的情况下工作。 该解决方案需要接近线性，这建议寻找图的结构属性而不是构建操作序列。 

关键的边缘情况来自图形组件。 考虑一个孤立的顶点：```
n = 2
target = [1, 0]
m = 0
```答案是`No`。 第一个位置没有连接到它的边，因此没有任何操作可以将其从零更改。 

第二种情况是所有顶点都已连接但目标具有奇奇偶校验的组件：```
n = 3
target = [1, 1, 1]
m = 2
edges:
1 2
2 3
```答案是`No`。 每个操作都恰好翻转两位，因此该组件内的位数总是以偶数模 2 变化。 该组件以零个开始，因此只能以偶数个结束。 

粗心的实现可能只会检查整个数组是否有偶数个。 当图表有多个组件时，这会失败：```
n = 4
target = [1, 1, 1, 0]
m = 1
edge:
1 2
```答案是`No`。 第一个组件有两个，并且是可能的，但顶点 3 是一个单独的组件，有一个，无法更改。 

# 方法

 蛮力的想法是尝试应用操作并跟踪每个可到达的二进制数组。 由于每个位有两种状态，因此可以有$2^n$可能的数组。 即使是为了$n=40$，这已经太大了，并且给定的限制$10^5$使状态探索变得不可能。 

另一种直接方法是将每个运算视为二进制值的方程。 每条边都表示应用它会切换两个端点，因此最终状态是所选边的异或组合。 使用通用高斯消元法求解完整线性系统在概念上是可行的，但这是不必要的，并且会比图结构所需的更复杂。 

重要的观察是操作永远不会改变连接组件内的奇偶校验数。 边的两个端点属于同一分量，翻转两个位会改变 1 的计数加二、减二或零。 在模二算术中，分量奇偶校验保持不变。 

这个条件也足够了。 在一个连接的组件内，任何一对顶点都可以通过沿着组件中的路径行走来有效地切换在一起。 通过组合这些路径操作，我们可以创建任何具有偶校验的配置。 具有至少一条边的组件可以生成每个偶校验分配，而孤立的顶点永远无法更改。 

该问题简化为查找连接的组件、计算每个组件中目标组件的数量以及检查这些奇偶校验条件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(2^n) | O(2^n) | 太慢了|
 | 最佳 | O(n + m) | O(n) | 已接受 |

 ## 算法演练

 1. 构建一个无向图，其中每个允许的操作都成为其两个位置之间的边。 这些操作仅取决于连接的顶点，因此边的确切顺序并不重要。 
2. 使用DFS 或BFS 查找每个连接的组件。 在访问一个组件时，计算有多少个目标位等于 1，并计算有多少个顶点属于该组件。 
3. 如果一个组件只包含一个顶点并且其目标位为 1，则立即拒绝它。 没有任何操作触及该顶点，因此它必须保持为零。 
4. 对于每个有边缘的组件，检查其内部的数量。 如果该计数为奇数，则拒绝目标，因为组件奇偶校验无法更改。 
5. 如果每个组件都通过了这些检查，则接受目标。 

为什么它有效：每个操作都会翻转来自同一连接组件的两个顶点，因此每个组件中的奇偶校验是一个不变量。 不变量给出了必要条件。 为了充分利用，连接的组件允许我们通过路径移动切换并组合边缘操作，这意味着每个均匀大小的顶点集都可以翻转。 由于每个有效的组件目标都具有偶校验，因此所有此类目标都是可达到的。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    b = list(map(int, input().split()))
    
    m = int(input())
    graph = [[] for _ in range(n)]
    
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        graph[u].append(v)
        graph[v].append(u)

    visited = [False] * n

    for start in range(n):
        if not visited[start]:
            stack = [start]
            visited[start] = True
            ones = 0
            size = 0

            while stack:
                u = stack.pop()
                size += 1
                ones += b[u]

                for v in graph[u]:
                    if not visited[v]:
                        visited[v] = True
                        stack.append(v)

            if size == 1:
                if ones == 1:
                    print("No")
                    return
            else:
                if ones % 2 == 1:
                    print("No")
                    return

    print("Yes")

if __name__ == "__main__":
    solve()
```图的构造直接代表了可用的操作。 边是无向的，因为翻转位置$i$和$j$无论我们如何描述这对，都具有相同的效果。 

DFS 循环一次处理一个连接的组件。 变量`ones`存储重要的奇偶校验信息，同时`size`区分法线组件和孤立顶点。 孤立顶点的情况需要单独处理，因为偶校验会错误地接受包含单个零位的分量，并且仅在计数后才拒绝，但永远不会产生单个零位。 

遍历使用显式堆栈而不是递归。 对于包含长度路径的图来说，Python 递归深度太小$10^5$，因此迭代 DFS 可以避免堆栈溢出。

 # 边缘情况

 对于孤立的顶点，该算法创建一个大小为 1 的组件。 对于输入：```
3
0 1 0
1
1 3
```组件是`{1,3}`和`{2}`。 第二个组件有一个顶点和一个必需的顶点，因此算法返回`No`。 它从不尝试为该顶点发明操作。 

对于奇偶校验连通分量：```
3
1 1 1
2
1 2
2 3
```遍历找到一个包含所有三个顶点的组件。 目标个数为 3，为奇数，因此算法将其拒绝。 每个可用的操作都会翻转两个位置，保持组件奇偶校验不变。 

对于断开连接的图，必须单独检查每个组件：```
4
1 1 1 0
1
1 2
```第一个组件`{1,2}`有两个并且有效。 其余顶点是孤立的，顶点 3 需要一个没有任何关联边的顶点。 该算法会拒绝该组件，从而避免了仅检查总数量的常见错误。
