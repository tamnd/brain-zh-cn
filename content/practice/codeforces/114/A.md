 ## 解决方案
 ## 问题理解

 我们有两个整数，`k`和`l`。 任务是确定是否`l`可以写成一个精确的幂`k`。 

换句话说，我们需要检查是否存在非负整数`n`这样：$l = k^n$如果这样一个`n`存在，我们打印`"YES"`并打印该数字的重要性，这正是`n - 1`在声明的术语中。 例如，`k^1`的出现次数为零`"la"`,`k^2`发生一次，依此类推。 

约束足够小，我们不需要高等数学或对数。 这两个数字都适合 32 位有符号整数，因此重复乘法或除法是完全可行的。 由于权力`k`指数增长，超过之前的步数`l`最多在 31 左右，当`k >= 2`。 

主要危险是正确处理指数计数。 粗心的实现很容易打印错误的重要性值，因为该语句计算了`"la"`词，而不是指数本身。 

考虑这个例子：

 输入：```
5
25
```这里：$25 = 5^2$指数是`2`，但重要的是`1`， 因为`"petricium la petricium"`包含一个`"la"`。 

另一个微妙的边缘情况出现时`l`不能被整除`k`在此过程中。 

输入：```
3
10
```保持乘幂的简单循环可能会超调或使用浮点对数并遇到​​精度问题。 正确答案是`"NO"`因为没有整数幂`3`等于`10`。 

另一个重要的情况是当`l = k`。 

输入：```
7
7
```这对应于：$7 = 7^1$答案应该是：```
YES
0
```因为重要性很重要`"la"`单词，并且在一次幂中没有单词。 

## 方法

 蛮力的想法很简单。 开始于`1`, 反复乘以`k`，并检查我们最终是否达到`l`。 

例如：```
1 -> k -> k^2 -> k^3 -> ...
```这是有效的，因为序列中的每个有效数字都是按升序生成的。 当前值超过的瞬间`l`，我们知道`l`是不可能的。 

尽管这种方法对于给定的约束来说已经足够快了，但还有一种更简洁的方法来思考这个问题。 我们可以减少权力，而不是向上建立权力`l`向下。 

如果`l`确实是一种力量`k`，然后除以`k`反复一定最终达到`1`。 

例如：$125 \to 25 \to 5 \to 1$每一次成功的除法都会消除一个因素`k`。 如果在某个时刻`l`不能被整除`k`，那么表示是不可能的。 

这种基于除法的方法更简单，因为它永远不会有溢出的风险，并且自然地为我们提供指数计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(logₖ l) | O(1) | O(1) | 已接受 |
 | 最佳 | O(logₖ l) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取整数`k`和`l`。 
2. 初始化计数器`cnt = 0`。 该计数器将跟踪我们成功除以的次数`k`。 
3.同时`l`可以整除`k`, 除`l`经过`k`并增加`cnt`。 

每个部门删除一个权力`k`从数字来看。 
4. 循环结束后，检查是否`l == 1`。 

如果我们达到`1`，那么原来的数字正好是`k`。 
5. 如果`l == 1`， 打印`"YES"`并打印`cnt - 1`。 

指数本身是`cnt`，但问题要求的是数量`"la"`的话，就少了一个。 
6. 否则，打印`"NO"`。 

### 为什么它有效

 该算法保持了每次迭代后的不变量，当前值`l`等于原始数除以`k^cnt`。 

如果原来的数字是真的：$l = k^n$然后恰好之后`n`我们必须获得的除法`1`。 

如果在某个时刻除法是不可能的，因为`l % k != 0`，那么至少有一个素因数不属于`k`，所以这个数字不可能是的纯幂`k`。 

因为循环恰好删除了一个因子`k`每次迭代，`cnt`成为指数，并且`cnt - 1`成为所需的重要性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    k = int(input())
    l = int(input())

    cnt = 0

    while l % k == 0:
        l //= k
        cnt += 1

    if l == 1:
        print("YES")
        print(cnt - 1)
    else:
        print("NO")

solve()
```该解决方案反复消除以下因素`k`从`l`。 

循环条件是关键细节：```
while l % k == 0:
```只有当除法准确时我们才进行除法。 这可以防止整数除法会默默丢弃信息的无效状态。 

变量`cnt`商店分裂成功了多少次。 如果原来的号码是`k^n`，那么循环正好运行`n`次。 

最后的减法：```
cnt - 1
```很容易被错过。 该问题不需要指数本身。 它要求提供数量`"la"`短语表示中的连接器。 

不存在溢出问题，因为除法只会减少`l`。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(logₖ l) | 每次迭代都划分`l`经过`k`|
 | 空间| O(1) | O(1) | 仅使用了少数整数变量 |

 自从`l`随着每次除法呈指数递减，对于 32 位整数，循环最多执行约 31 次。 这很容易符合限制。

```这正确地处理了指数和重要性之间的差异。 

现在考虑一个部分因式分解的数字`k`但不完全。 

输入：```

```执行：

 | 当前l | 行动| 碳纳米管|
