 ## 解决方案
 ## 问题理解

 我们需要仅通过奇偶校验来计算有多少个有序序列的长度`N`可以使用中允许的值形成`A`所以他们的总和正好是`S`。 所选数字的顺序很重要，因为序列中的位置不同。 答案不是实际计数，而是该计数是奇数还是偶数。 

困难的部分是`N`和`S`两者都可以大到`10^18`，因此任何迭代序列长度的方法都是不可能的。 甚至迭代到`S`太慢了。 唯一的小参数是`K`，允许值的个数，最多200个。里面的最大值`A`也足够小，可以在推理可以出现多少种不同状态时使用。 

对总和的直接动态规划方法需要大约`N * S`工作，这是完全不可能的，因为两个维度都可能是巨大的。 该解决方案必须利用这样一个事实：答案需要模 2。由于 Frobenius 恒等式，模 2 会极大地改变多项式幂：$$(f(x))^2 = f(x^2)$$在二进制字段上。 

有几种边缘情况如果被忽略，可能会破坏实现。 什么时候`N = 0`递归时出现，答案是`1`只为总和`0`，因为恰好有一个空序列。 例如，如果还原状态达到`N = 0, S = 3`，正确的结果是`0`，而粗心的实现可能会接受它，因为它处理了所有位`N`。 

另一种情况是当一个数字来自`A`当前二进制数字的奇偶校验错误。 对于输入：```
1
1 1
0
```唯一可能的顺序是`[0]`，所以答案是`0`。 在除以二之前不检查奇偶性的转换将错误地创建一个状态`(1 - 0) / 2`并且可以计算无效的金额。 

第三种情况是重复状态取消模 2。例如：```
1
2 2
1 3
```有效序列是`[1,1]`,`[1,3]`,`[3,1]`， 和`[3,3]`。 只有第一个和最后一个的和为 2 或 6，所以对于`S = 2`答案是`1`。 当不同的选择达到相同的减少状态时，它们的贡献必须进行异或，而不是像普通计数一样相加。 

## 方法

 一个简单的方法是使用生成函数$$P(x)=\sum_{a\in A}x^a$$答案是系数`x^S`在`P(x)^N`。 强力多项式乘法将重复组合项并跟踪每个可达到的总和。 这是正确的，因为每次乘法都代表选择序列中的另一个元素。 然而，度数可以变得一样大`N * max(A)`，这是周围`10^23`。 即使存储所有可达到的金额也是不可能的。 

关键的观察结果来自于所有算术都是以 2 为模的事实。在这个领域中，$$P(x)^{2}=P(x^2)$$所以如果我们看一下二进制表示`N`，每个设置位代表一个副本`P(x^{2^i})`。 

查看相同想法的更有用的方法是通过递归归约。 如果`N`是偶数，每个指数由`P(x)^N`是偶数，所以是奇数`S`立即给出零。 如果`N`是偶数并且`S`是偶数，两者`N`和`S`可以除以二。 

如果`N`很奇怪，一份`P(x)`遗迹。 我们选择价值`a`由该副本贡献，剩余部分成为均等力量。 过渡变为：$$F(N,S)=\bigoplus_{a\in A,\ a\equiv S\pmod 2}F(\lfloor N/2\rfloor,(S-a)/2)$$剩下的挑战是州的数量。 我们处理的位`N`从最低有效侧开始，同时存储所有当前减少的总和及其奇偶校验。 移除后`i`位，两种可能的状态仅因在删除的较低位中所做的选择而不同。 由于每个选择的值最多是`100000`，可能差异的区间是有界的。 这使得活动状态的数量易于管理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数为`N`，或者至少与可达总和的数量成正比 | 最坏情况下呈指数增长 | 太慢了|
 | 最佳|`O(60 * K * M)`在哪里`M`是维持状态的数量 |`O(M)`| 已接受 |

 ## 算法演练

 1. 从包含原始总和的一个状态开始`S`具有奇偶性`1`。 存储的奇偶校验表明达到该减少的总和的方式的数量是奇数还是偶数。 
2. 处理二进制数字`N`从最低有效位向上。 在每一步中，处理递归中的一除二。 
3. 如果当前位`N`为零，每一次贡献都是这个水平。 删除总和为奇数的状态，并将所有剩余总和除以二。 这是因为仅包含偶次幂的多项式不能产生奇数和。 
4. 如果当前位`N`是一，删除剩余的一份副本`P(x)`。 对于每个有效金额`s`以及每个允许的值`a`具有相同的奇偶性`s`，添加新状态`(s-a)/2`。 相等状态的奇偶校验与 XOR 相结合，因为所有计数都是模 2。 
5. 毕竟`N`处理完后，剩余指数为零。 答案是存储在状态中的奇偶校验`0`。 

为何有效：加工后`i`的位`N`，每个存储的状态准确地表示为已处理的二进制位置选择值的方法的奇偶性，使得剩余的未处理问题的目标总和等于该存储的值。 这些转变正是特征二中多项式恒等式的两种情况。 由于相等的状态是异或的，因此每一步之后不变量仍然为真。 最后，只有剩余的目标和为零才能满足空多项式幂，因此存储的零值就是所需的答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(N, S, A):
    states = {S: 1}

    bit = 0
    while N:
        if N & 1:
            nxt = {}
            for s, val in states.items():
                if val == 0:
                    continue
                parity = s & 1
                for a in A:
                    if (a & 1) == parity:
                        ns = (s - a) // 2
                        nxt[ns] = nxt.get(ns, 0) ^ val
            states = {k: v for k, v in nxt.items() if v}
        else:
            nxt = {}
            for s, val in states.items():
                if (s & 1) == 0:
                    ns = s // 2
                    nxt[ns] = nxt.get(ns, 0) ^ val
            states = {k: v for k, v in nxt.items() if v}

        N >>= 1
        bit += 1

        if not states:
            return 0

    return states.get(0, 0)

def main():
    T = int(input())
    ans = []
    for _ in range(T):
        N, S, K = map(int, input().split())
        A = list(map(int, input().split()))
        ans.append(str(solve_case(N, S, A)))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```字典`states`只存储仍能得出最终答案的总和。 它的值始终为零或一，因为运算是异或。 删除零条目很有用，因为取消的路径不再影响未来的转换。 

该循环遵循以下二进制表示形式`N`。 偶数情况直接执行除法步骤。 奇怪的情况会尝试最低位与当前目标位匹配的每个允许值。 这种奇偶校验是必要的，因为减去具有错误最低位的值在除以二后不会留下整数。 

Python 整数自然地处理输入大小，因此不存在溢出问题。 循环迭代次数最多为 60 次，因为`N`最多有 60 个二进制数字。

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |`O(60 * K * M)`| 最多有 60 个二进制步骤，每个活动状态都会尝试每个允许的值。 |

import io

def solve_case(N, S, A):
    states = {S: 1}
    while N:
        nxt = {}
        if N & 1:
            for s, v in states.items():
                for a in A:
                    if (a & 1) == (s & 1):
                        nxt[(s - a) // 2] = nxt.get((s - a) // 2, 0) ^ v
        else:
            for s, v in states.items():
                if s % 2 == 0:
                    nxt[s // 2] = nxt.get(s // 2, 0) ^ v

 ## 边缘情况

 对于`N = 0`在所有减少之后，实现不会进一步运行循环，只接受状态`0`。 这与空序列定义匹配并防止计算非零剩余部分。 

对于奇偶校验不匹配，奇数转换仅在以下情况下创建状态：`(s & 1) == (a & 1)`。 例如，与`N=1`,`S=1`， 和`A={0}`，当前状态是`{1:1}`。 唯一的值具有奇偶校验零，因此不会创建下一个状态，并且答案为零。 

对于重复路径取消，字典更新使用 XOR。 如果两个不同的选择产生相同的减少总和，则状态消失而不是被计算两次。 这正是所需的行为，因为只有模 2 的计数才重要。
