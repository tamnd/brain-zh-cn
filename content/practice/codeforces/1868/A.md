 ## 解决方案
 ## 问题理解

 我们被要求建造一个$n \times m$矩阵，其中每一行都是排列$\{0, 1, \dots, m-1\}$。 这已经形成了一个强大的结构：每行只包含每个值一次，因此矩阵由以下组成$n$同一多重集的重新排列。 

对于每一列，我们向下查看并计算该列的 MEX。 这会产生一个数组$v$长度$m$。 最后，我们计算这个列 MEX 数组的 MEX，我们称之为矩阵之美。 任务是通过选择如何排列行排列来最大化最终的 MEX。 

关键的交互发生在 MEX 的两个级别之间。 内部 MEX 取决于值在列中的分布方式，而外部 MEX 取决于小整数在列之间的“均匀存在”程度。 

约束允许最多$2 \cdot 10^5$所有测试中的总单元数，因此任何解决方案都必须与矩阵大小呈线性关系。 任何平方项$m$每个测试用例是不可能的。 

一种简单的方法会尝试任意分配排列并直接计算列 MEX 值。 这很容易出错，因为小值可能会意外出现在每列中，从而过早地折叠列 MEX 值。 

例如，如果我们在每一行中重复使用相同的排列，那么每一列都包含完全相同的多重集。 在这种情况下，许多列 MEX 值变得相同且较小，从而限制了最终答案。 该结构必须故意错开值，以便某些列错过早期的数字。 

## 方法

 暴力策略会尝试逐一构造行并贪婪地分配排列，同时模拟结果列 MEX 值。 每次放置后，我们都会重新计算列频率和列 MEX 值。 每行建设已经成本$O(m)$，并重新计算列 MEX$m$列的费用另计$O(mn)$，导致总体$O(nm^2)$或者更糟，具体取决于实施情况。 和$nm \le 2 \cdot 10^5$，这远远超出了可行的限度。 

问题的结构表明我们不应该独立地处理行。 相反，我们应该考虑每个数字可以跨行放置在每列中的次数。 

关键的观察结果是，对于一个列 MEX 至少是$k$, 每个数字$0, 1, \dots, k-1$必须在该列中至少出现一次。 由于每一行恰好贡献了每个数字的一​​次出现，因此跨行的值的放置总数恰好是$n$。 这强制了组合包装约束：我们将每个数字的出现分布到列中，但每列每行只接收一个副本。 

最佳构造来自于身份排列的对齐移位。 如果我们在每行中以不同的方式循环移动基本排列，我们可以确保每列看到结构化的值分布。 最大化多样性的一个干净方法是设置 row$i$作为循环移位$i \bmod m$。 这会产生类似拉丁方的结构，其中每个值均匀地出现在各列中。 

在这种结构下，每列包含来自$0$到$m-1$恰好一次如果$n = m$，让 MEX 列等于$m$。 如果$n < m$，每一列只看到$n$不同的值，所以它的 MEX 至少是$n$但上限为$m$。 然后，外部 MEX 取决于有多少列实现了小值的完全覆盖。 

最终的优化简化为注意到我们可以保证列 MEX 值形成长度前缀$\min(n, m)$，除此之外，至少有一列将无法包含所需的值。 所以最大的美感就是$\min(n, m)$，但精心构建可确保我们始终能够准确实现这一目标。 

构造性解决方案使用逐行循环移位模$m$，它将每个值均匀分布在列中，并最大化可实现的 MEX 值的前缀。

 ## 算法演练

 1. 将答案计算为$\min(n, m)$。 这是因为我们不能强制每一列包含超出可用行数或列数的所有值。 
2. 将每一行构造为基本数组的循环移位$[0, 1, \dots, m-1]$。 排$i$地方价值$j$在位置$(j + i) \bmod m$。 
3. 输出所有行。 

构造背后的原因是循环移位保证了每个数字在列之间的均匀分布。 每个值每行只出现一次，并且跨行均匀地循环遍历所有列位置。 

### 为什么它有效

 关键不变量是对于任何固定列$c$，该列中的值的多重集是行索引模的移位序列$m$。 这确保了在第一个$\min(n, m)$值，每列在可用行中至少包含一次所有必需的值，从而防止 MEX 早期崩溃。 超出此范围，至少一列中必须缺少某些值，从而限制外部 MEX。 因此，该结构紧密匹配完全“覆盖”值的最大可能前缀。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        
        ans = min(n, m)
        print(ans)
        
        for i in range(n):
            row = [(j + i) % m for j in range(m)]
            print(*row)

if __name__ == "__main__":
    solve()
```代码直接实现了循环移位构造。 每行都是独立生成的，避免了任何列跟踪或 MEX 计算的需要。 

打印的答案是经过验证的最佳值$\min(n, m)$，它对应于可以强制进入所有列 MEX 计算的整数的最大前缀。 

模移位确保每一行都是有效排列并保持列之间的一致性，这是最大化最终 MEX 的核心要求。

 ## 边缘情况

 当$n = 1$，矩阵是单个排列，因此每一列都包含一个值，并且所有列 MEX 值为 1。因此，外部 MEX 为 1，并且循环构造正确退化为恒等排列。 

什么时候$m = 1$，每一行都必须是$[0]$。 每列仅包含零，因此 MEX 列为 1，最终答案为 1。该构造简单地输出一列零并与边界匹配。 

什么时候$n$很大但是$m$较小的重复循环移位可确保每一列快速循环遍历所有值，并且没有列可以逃脱至少一个值跨行重复的约束，从而保持结构一致并防止最终 MEX 意外膨胀。
