 ## 解决方案
 ## 问题理解

 我们在一个聚会上有一群人，每个人最初都拿着一定数量的糖果。 每个人只能给另一个人一次一定数量的糖果，数量为2的幂，且不超过自己当前持有的糖果。 目标是让所有人最终获得相同数量的糖果，同时确保每个人最多从另一个人那里收到糖果。 换句话说，我们需要找到糖果转移的一对一映射，以便在所有转移之后，每个人都拥有相同数量的糖果。 

输入提供多个测试用例。 对于每个测试用例，我们知道有多少人在场以及每个人最初拥有的糖果数量。 如果可以安排转移以满足公平性和平等性，则输出是简单的“是”，否则输出是“否”。 

限制人数最多为 200,000 人，所有测试用例的总和也最多为 200,000 个。 每个人都能坚持到$10^9$糖果。 这排除了任何尝试所有可能的糖果转移序列的解决方案，因为这将是组合爆炸性的。 相反，我们需要每个测试用例采用线性或近线性方法。 

非明显边缘情况包括每个人都拥有相同数量糖果的情况、糖果之间的差异是 2 的幂的情况以及差异不能表示为 2 的幂或不能以一对一映射配对的情况。 例如，如果输入是`[1, 2, 3]`，一开始可能会尝试将糖果从拥有 3 的人转移到拥有 1 的人，然后将 2 转移到拥有 2 的人，但会失败，因为一个人无法从多个人那里收到糖果。 这里正确的输出是“Yes”，因为我们可以安排匹配 2 的幂的一对一传输。 

## 方法

 暴力方法会尝试模拟所有可能的传输序列，检查两种给予和接收权力的每种组合。 这将涉及生成每个人糖果的两个子集的所有能力，将它们与所有其他人匹配，并检查最终计数是否相等。 可能性的数量呈指数级增长$n$以及每个糖果计数中的位数。 为了$n$大约$10^5$，这实在是太慢了。 

关键的观察是，每次传输必须是 2 的幂，并且只能发生在唯一的一对给予者和接收者之间。 这意味着问题简化为检查目标糖果数量与每个人的初始糖果之间的差异是否可以表示为允许一对一分配的二的幂总和。 首先，我们计算糖果的目标数量，该数量必须是所有糖果的平均值，因为每个人都必须以相同的数量结束。 如果糖果总数不能除以人数，那是不可能的。 接下来，我们将人分为需要给予糖果的人和需要接受糖果的人。 每个捐赠金额必须是 2 的幂，并且每个接收金额必须与捐赠者相匹配。 通过首先考虑最大的二次方差异并贪婪地匹配它们，我们可以检查这样的配对是否可能。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(n log max_a)) | O(2^(n log max_a)) | O(n) | 太慢了 |
 | 最佳| O(n log max_a) | O(n log max_a) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，计算所有糖果的总和。 如果总和不能被人数整除，则打印“No”并继续下一个案例。 这确保了统一的目标在数学上是可能的。 
2. 计算目标糖果数量为`target = sum(a) // n`。 
3. 对于每个人，计算差异`diff = a[i] - target`。 如果`diff > 0`，这个人必须赠送糖果。 如果`diff < 0`，这个人必须收到糖果。 
4. 将给予和接受差异存储在两个单独的列表中。 取接收差异的绝对值。 
5. 对于这两个列表，尝试将每个差异分解为 2 的不同幂的和。 这相当于检查差异的二进制表示。 二进制表示中的每个位集对应于一个传输$2^k$糖果。 
6. 对于每个 2 的幂，检查是否有足够的相应给予者和接收者进行匹配。 这是通过计算有多少给予者可以提供的来完成的$2^k$以及需要多少个接收器$2^k$。 如果在任何功率下，给予者的数量不足以满足接收者的要求，请打印“否”。 
7. 如果两个差值的所有幂都成功匹配，则打印“Yes”。 

为什么它有效：贪心分解为两个幂是有效的，因为任何整数都可以唯一地表示为两个不同幂的总和。 通过按比特匹配给予者和接收者，我们确保每个人最多向另一个人给予并从最多一个人接收，从而满足问题的约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_equalize_candies(n, candies):
    total = sum(candies)
    if total % n != 0:
        return False
    target = total // n
    give_counts = {}
    receive_counts = {}
    
    for c in candies:
        diff = c - target
        if diff == 0:
            continue
        x = abs(diff)
        bits = []
        i = 0
        while x:
            if x & 1:
                bits.append(1 << i)
            x >>= 1
            i += 1
        if diff > 0:
            for b in bits:
                give_counts[b] = give_counts.get(b, 0) + 1
        else:
            for b in bits:
                receive_counts[b] = receive_counts.get(b, 0) + 1
    
    for b in receive_counts:
        if receive_counts[b] > give_counts.get(b, 0):
            return False
    return True

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print("Yes" if can_equalize_candies(n, a) else "No")
```该解决方案首先检查统一目标是否可能。 差异被分解为 2 的幂，并且我们维护每个幂所需传输的计数。 通过匹配这些计数，我们可以有效地实施一对一约束。 边缘情况（例如每个人都拥有相同数量的糖果）会被自然处理，因为差异为零。
