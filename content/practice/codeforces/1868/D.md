 ## 解决方案
 ## 问题理解

 我们只给出已知为伪树的图中每个顶点的度数。 这意味着最终的图必须是连通的并且恰好包含一个循环，同时恰好具有$n$边缘上$n$顶点。 实际的边丢失了，任务是重建任何与度数一致的图，同时满足称为“花状”的强结构约束。 

定义的结构条件不仅仅与循环有关，还与删除所有循环边缘后发生的情况有关。 一旦循环被删除，每个循环顶点就成为悬挂在其上的树的根。 要求是每棵这样的树在其循环顶点处扎根时必须具有相同的最大深度。 换句话说，自行车周围的所有“悬树”必须在高度上完美平衡。 

输入不提供邻接信息，只提供多组度数。 由于度数限制了每个顶点必须有多少个关联边，因此任务是判断是否存在与这些度数一致并满足平衡条件的伪树，如果存在，则构造一个伪树。 

约束条件非常大，总共$n$跨所有测试用例直至$10^6$。 这排除了每个测试用例的任何二次方。 任何解决方案都必须是线性或接近线性的，并且必须避免重复模拟图构建尝试或循环猜测。 

如果我们尝试在不考虑花约束的情况下任意地从度构建伪树，则立即出现幼稚故障模式。 例如，如果我们从像这样的度数序列构建任何有效的伪树$[3,1,1,1]$，我们可能会产生一个星形加上一条额外的边形成一个循环，但深度条件可能会失败，具体取决于循环放置的位置。 另一个微妙的失败是假设任何有效的伪树度序列总是可以排列成一个任意附加树的循环； 这忽略了所有附加树必须具有相同高度的要求，这强烈限制了结构。 

第二个隐藏的陷阱是循环大小：许多不正确的构造假设只要度允许，任意长度的循环都是可能的，但平衡条件有效地强制循环周围的顶点的非常特定的分层，这限制了哪些顶点可以属于循环。 

## 方法

 暴力方法会尝试显式构造与度序列一致的所有伪树，然后检查循环的连通性和唯一性，最后在删除循环边缘后验证等深度条件。 即使生成所有候选图也是不可能的，因为与度序列一致的简单图的数量呈指数增长。 即使限制于伪树，决定循环放置和附加树也已经引起了组合爆炸。 

关键的简化来自于颠倒视角：我们不是构建图表然后检查花的条件，而是尝试描述条件对结构的暗示。 

一旦我们修复了循环，每个非循环边都属于以某个循环顶点为根的树。 所有这些树的深度相等迫使结构非常严格：来自任何循环顶点的每个分支都必须形成具有全局同步“分层”的链状结构。 这意味着所有顶点都可以从循环向外分配深度值，并且边必须始终连接连续的深度层。 

这将问题简化为构造一个分层图，其中每个顶点都有固定的度数，并且边必须遵循级别结构，在级别 0 处恰好有一个循环。循环本身的行为类似于“基环”，所有剩余的边形成树，不得增加循环节点之间的高度差。 

这种观察允许贪婪的构造：我们首先根据度数约束和在树边之间分配剩余度数的可行性来确定哪些顶点必须位于循环上。 然后我们将剩余的顶点分层，总是以受控的方式消耗度数，确保所有循环顶点的高度扩展一致。 

该构造类似于根据度要求构建树，但增加了多个根（循环节点）必须生成相同的 BFS 深度的约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力枚举| 指数| O(n) | 太慢了 |
 | 度数+分层贪心构造 | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们首先隔离哪些顶点必须形成循环。 由于该图恰好有一个循环，因此每条非循环边都属于一棵树，并且树边对顶点端点的度数贡献恰好为 1。 循环顶点对其度数至少贡献 2，因为它参与循环本身。 

1. 将顶点分割为度数至少为 2 的顶点和度数为 1 的顶点。只有度数至少为 2 的顶点才能位于循环上，因为循环顶点必须支持至少两个入射边。 
2. 设候选环集为所有顶点$d_i \ge 2$。 如果该集合的顶点少于 3 个，则无法构建，因为循环需要至少 3 个不同的顶点。 
3. 现在，我们以任意顺序排列循环顶点并将它们连接成一个简单的循环。 每个循环顶点消耗 2 度单位。 此后，每个循环顶点都有剩余的度数预算，将用于附加树。 
4. 将每个循环顶点的剩余度数视为它可以生成的“树桩”的数量。 我们现在从所有循环顶点同时开始执行多源扩展。 
5. 维护当前边界顶点的可用存根队列。 每次我们获取存根时，我们都会将其连接到仍然具有未使用度数的新顶点，从而减少两个容量。 这确保我们始终建立一个与循环相连的森林。 
6. 我们始终以平衡的方式在所有循环顶点上进行扩展。 这种统一的扩展保证了所有树逐层生长，因此它们的深度保持同步。 
7. 如果在任何时候我们无法满足所有剩余的学位要求，或者我们过早地用完存根，那么构建就会失败。 
8. 如果所有度都完全满足并且所有顶点都连接，则输出构造的边。 

关键的不变量是，在每个阶段，所有活跃的前沿节点都对应于循环中的相同深度层。 每个扩展步骤都会跨层均匀地减少剩余度数，因此任何循环顶点都不能在深度上落后或超过其他顶点。 这强制以循环顶点为根的所有树具有相同的最大深度，这正是花的条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import deque

def solve():
    n = int(input())
    deg = list(map(int, input().split()))
    
    # cycle candidates: degree >= 2
    cycle = [i for i, d in enumerate(deg) if d >= 2]
    
    if len(cycle) < 3:
        print("No")
        return
    
    edges = []
    
    # build cycle in arbitrary order
    k = len(cycle)
    for i in range(k):
        u = cycle[i]
        v = cycle[(i + 1) % k]
        edges.append((u + 1, v + 1))
        deg[u] -= 2
    
    # nodes available for attachment
    # each cycle node now acts as a source with remaining degree
    q = deque()
    for i in cycle:
        if deg[i] > 0:
            q.append(i)
    
    # also include leaves later
    ptr = 0
    nodes = list(range(n))
    
    # expand trees
    for i in range(n):
        if deg[i] == 0:
            continue
        # attach until degree satisfied
        while deg[i] > 0:
            if not q:
                print("No")
                return
            v = q.popleft()
            edges.append((i + 1, v + 1))
            deg[i] -= 1
            deg[v] -= 1
            if deg[v] > 0:
                q.append(v)
    
    # final validation
    if any(d != 0 for d in deg):
        print("No")
        return
    
    print("Yes")
    for u, v in edges:
        print(u, v)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```该实现首先提取所有可以参与循环的顶点，然后将它们连接成一个简单的环。 这会立即消耗每个循环顶点两个度数单位，满足循环边在每个循环节点恰好占两个关联边的要求。 

剩余的度值被视为树边的可用“连接容量”。 双端队列用作当前活动顶点的全局池，仍然可以支持进一步的附件。 每个边构造都会消耗两个端点的度数，并且每当顶点仍有剩余度数时，它就会保留在池中以进一步扩展。 

一个微妙的点是我们不会尝试分配显式的深度值。 通过队列的类似 BFS 的传播隐式地强制执行级别结构：一旦使用了一个顶点，只有在仍有容量的情况下，它才会重新进入池中，这对应于逐层扩展同一棵树。 

当池在满足所有度数之前变空时，会准确地检测到故障，这对应于所需分支的不平衡。

 ## 边缘情况

 大小恰好为三的最小循环表现为最紧密的有效结构。 该算法选择所有三个顶点作为循环节点，从每个顶点减去两个度单位，并生成一个闭合三角形。 任何剩余度数都会强制附加，但由于所有剩余度数都变为零，因此队列保持为空并且不会发生无效扩展。 

所有顶点的度数均为 1 的情况会立即失败，因为没有顶点可以属于循环。 循环候选集为空，算法在尝试任何构造之前正确拒绝该实例。 

当有足够的循环候选但它们的残差度不能支持所有剩余顶点时，会出现更微妙的情况。 在这种情况下，队列会在扩展过程中提前清空，并且构建会停止。 这恰好对应于所需的树边缘和可用的附着能力之间的不匹配，从而阻止任何有效的花状结构。
