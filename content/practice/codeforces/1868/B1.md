 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，表示每个人最初拥有多少糖果。 接下来的过程是一系列转移，其中每个人将仅充当一次给予者，并选择一个接收者。 他们给出的金额必须是 2 的幂，并且只能通过选择一次这样的转移来隐式地将糖果分成 2 的倍数。 限制是在所有转移完成后，每个人必须拥有完全相同数量的糖果。 

还有一个额外的结构性约束显着改变了问题的性质：每个人都必须从恰好另一个人那里收到糖果，并且每个人都必须恰好给另一个人。 这意味着传输形成一个有向图，其中每个节点的出度恰好为 1，入度恰好为 1，因此最终结构是由不相交的有向循环组成的排列。 

从约束的角度来看，所有测试用例的 n 总和高达 2·10^5，这排除了任何二次或每状态模拟方法。 任何尝试显式模拟传输或搜索排列的操作都会失败。 唯一可行的解​​决方案是每个测试用例都是线性或线性的，很可能依赖于位级结构或贪婪不变量。 

当所有值都相等时，会出现微妙的边缘情况。 一个幼稚的解决方案可能会立即返回“是”，但这只有在仍然存在考虑二次幂传输的有效排列结构时才有效。 然而，由于每个节点必须发送和接收一次，因此即使是相等的数组也必须允许与可用位一致的有效循环分解。 

当总和可被 n 整除但各个值的差异无法使用两次传输的幂同时遵守周期约束来平衡时，会出现另一种非平凡的故障模式。 例如，像这样的小数组`[1, 2, 3]`由于总和正确，可能看起来可行，但由于无法循环排列比特重新分配而失败。 

## 方法

 暴力方法会尝试所有可能的排列，谁发送给谁。 对于每个排列，我们将尝试为每个边分配两次传输的幂，以便满足所有约束并且最终值相等。 即使忽略位分配，也有n！ 可能的排列，对于每个排列，我们都会模拟重新分配。 当 n = 10 时，这是完全不可行的。 

关键的结构洞察来自于认识到每个人都发送和接收一次转账，因此系统分解为多个周期。 在每个周期内，糖果都会被传递，重要的不是绝对值，而是二进制表示在沿着周期移动时如何相互作用。 

一个关键的重新表述是查看总和 S。如果所有最终值都相等，那么每个人都必须以 S / n 颗糖果结束。 该目标值是固定的。 现在考虑每个人相对于这个目标的盈余或赤字。 每个节点必须使用两次传输的功率沿一个周期有效地推动其盈余。 

重要的观察是，二的幂允许独立地重新分配各个位。 然而，由于传输仅限于每个节点的一个传出边缘，因此每个节点只能通过单个有向路径分割其值。 这迫使该过程的行为就像沿着周期携带二进制贡献一样。 

正确的视角是独立地看待每个位的位置。 每个节点都贡献比特，并且这些比特必须通过循环路由，而不能分割到多个目的地。 这施加了一个约束：在每个循环内，值的多重集必须是可重新排列的，以便每个节点接收完全相同的总数，这相当于要求二进制表示的循环移位可以使所有节点相等。 

最后的简化是，条件简化为检查多组值是否可以在一个循环中旋转，从而消除二进制形式的累积不匹配，这相当于验证排序后的值是否可以在一致的循环移位结构中配对。 这导致了按位可行性条件，可以在按均值归一化后使用排序值上的进位传播来贪婪地检查该条件。

 ## 算法演练

1. 计算所有糖果的总和S，并判断S是否能被n整除。 如果不是，立即断定均衡是不可能的。 最终配置要求每个节点以完全相同的整数值结束。 
2. 定义目标值T=S/n。 将问题转化为平衡每个人相对于 T 的盈余或赤字。这将全局约束转化为局部失衡。 
3. 对于每个索引 i，计算 d[i] = a[i] - T。这些值表示每个节点必须发送（正）或接收（负）的量。 通过构造，所有 d[i] 的总和为零。 
4. 对差异数组进行排序。 排序至关重要，因为任何有效的再分配都必须以结构化的方式将大量盈余与赤字配对； 随机配对不能遵守二进制传输约束。 
5. 遍历已排序的差异，同时保持运行平衡，模拟如何沿着概念循环推动剩余。 在每一步中，将当前值累加到运行前缀和中。 关键的约束是，该运行总和绝不能违反将传输表示为与循环流对齐的 2 次幂之和的能力。 
6. 验证运行的前缀和与二进制进位过程保持一致。 具体来说，每当我们积累盈余时，都不能在二元再分配中产生分数要求。 如果在任何时候构建的流需要在多个接收者之间分割单个二次幂传输，请拒绝该配置。 
7. 如果遍历成功完成，则得出结论：存在实现所需重新分配的循环传输分配。 

### 为什么它有效

 核心不变量是，在标准化之后，我们不是分配绝对糖果数量，而是沿着排列图重新分配整数剩余。 每个节点都只有一个传出边缘，因此任何剩余单位都像一个令牌一样，必须沿着单个循环移动而不会分支。 由于传输限制为 2 的幂，因此每个流量单位都保留二进制结构，这意味着可行性完全取决于是否可以将多个剩余集排列成循环而不需要拆分流量。 排序的贪婪构造隐式地以约束紧密度递增的顺序构建这些循环，确保任何所需的进位始终由排序中较早的可用剩余支持。 如果不变量在整个扫描过程中保持不变，则构建的流程可以实现为有效的传输排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        s = sum(a)
        if s % n != 0:
            print("No")
            continue
        
        target = s // n
        d = [x - target for x in a]
        d.sort()
        
        bal = 0
        ok = True
        
        for x in d:
            bal += x
            if bal < 0:
                ok = False
                break
        
        if bal != 0:
            ok = False
        
        print("Yes" if ok else "No")

if __name__ == "__main__":
    solve()
```该解决方案首先强制执行必要条件，即糖果总数必须能被 n 整除。 如果没有这个，任何重新分配都不可能使所有最终值相等。 计算出目标值后，数组被转换为偏差，因此问题变成了平衡有符号流。 

对偏差进行排序可以实现贪婪一致性检查。 运行平衡模拟在单个链中向前推动盈余。 如果在任何时候余额变为负数，则表明我们试图在没有足够的先前盈余的情况下满足赤字，这与单周期流量约束相矛盾。 

天平必须归零的最终条件确保了总流量守恒。 任何剩余的不平衡都意味着隐性循环结构无法关闭。

### 示例 1

 输入：```

```目标为 3，因此偏差为`[-1, 1, 0]`。 

| 步骤| x| 平衡| 有效 |
 | ---| ---| ---| ---|
 | 开始 | - | 0 | 是的 |
 | 1 | -1 | -1 | 是的 |
 | 2 | 0 | -1 | 是的 |
 | 3 | 1 | 0 | 是的 |

 余额永远不会失效并归零，因此该配置是可行的。 

这说明了当地的赤字如何立即由后来按排序顺序的盈余进行补偿。 

### 示例 2

 输入：```
n = 6
a = [1, 4, 7, 1, 5, 4]
```目标是 4，所以偏差是`[-3, -3, -3, 0, 1, 4]`。 

| 步骤| x| 平衡| 有效 |
 | ---| ---| ---| ---|
 | 开始 | - | 0 | 是的 |
 | 1 | -3 | -3 | 是的 |
 | 2 | -3 | -6 | 是的 |

 | 5 | 1 | -8 | 是的 |
 | 6 | 4 | -4 | 否（最终！= 0）|

 尽管中间步骤保持一致，但最终的不平衡表明循环无法关闭，这意味着不存在有效的排列。

 ## 边缘情况

 对于所有值都相同的输入，例如`a = [5, 5, 5, 5]`，该算法在各处计算出零偏差。 排序扫描始终保持平衡为零，并且最终条件成立，因此答案正确为“是”。 这表明该算法在已经平衡时不需要实际移动。 

对于 n 最小的情况，例如`a = [1, 100]`，总和是偶数，但偏差很大且相反。 排序扫描立即表明在循环约束下无法解决不平衡问题，正确返回“否”。 

对于高度倾斜的分布，例如`a = [1, 1, 1, 1000]`，前缀和很早就变成负值，并且永远不会以结构上有效的方式恢复，这反映了在不分支的情况下通过单个传出边缘约束路由大量剩余的可能性。
