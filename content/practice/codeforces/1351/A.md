 ## 解决方案
 ## 问题理解

 该任务要求我们将整数对相加。 每个测试用例由两个整数组成，对于每一对，我们需要计算它们的总和。 输入首先告诉我们有多少对，然后每个后续行都包含一对。 输出是一系列和，每行一个，对应于每一对。 

这些限制很简单，但值得注意。 每个整数都在 -1000 到 1000 之间，这意味着在 Python 中整数溢出不是问题。 测试用例的数量可以多达 10,000 个，这意味着任何迭代所有测试用例一次的解决方案都足够高效，因为 Python 可以在一秒钟内轻松处理 10,000 个简单操作。 负数可能导致总和为零或负数，因此解决方案不得假设输入严格为正数。 

非明显的边缘情况包括其中一个或两个数字都为零的对，其中总和从正到负过零或反之亦然，以及两个数字都处于边界（-1000 或 1000）。 例如，这对`-1000 1000`应该输出`0`。 忽略负数的粗心实施可能会产生错误的信号。 

## 方法

 暴力方法是读取每一行，解析两个整数，计算它们的总和，然后立即打印结果。 这是可行的，因为对两个整数求和是一个 O(1) 操作，并且在 Python 中迭代超过 10,000 个测试用例是高效的。 按顺序读取和处理输入没有隐藏的复杂性。 

没有更优化的渐近方法，因为我们必须处理每个测试用例来计算其总和。 唯一的改进可能是批量输入读取以提高速度`sys.stdin.readline`，这避免了 Python 较慢的默认输入。 这种小的优化确保即使在最大输入大小下，程序也能在时间限制内舒适地运行。

 ## 算法演练

 1.读取测试用例数量`t`。 这告诉我们需要处理多少对。 
2. 迭代`t`次。 在每次迭代中：

 1. 读取包含两个整数的行，`a`和`b`。 
2. 将行转换为整数。 转换是必要的，因为输入是字符串。 
3. 计算总和`a + b`。 
4. 立即打印总数。 
3. 对所有测试用例重复此操作。 

关键的不变量是对于每次迭代，`a`和`b`是约束范围内的有效整数。 对它们求和会产生正确的答案，并且打印会立即保持输出顺序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    print(a + b)
```第一行读取测试用例的数量。 循环完全运行`t`次，读取每一对，转换为整数，求和，然后打印。 使用`sys.stdin.readline`避免对大型测试文件进行缓慢的输入操作。`map(int, input().split())`确保两个值都被正确解析，即使是负值。 在循环内打印可以保留顺序，无需额外存储。

 ## 边缘情况

 对于这对`-1000 1000`，算法读取`a=-1000`,`b=1000`，计算`a+b=0`，并打印`0`。 每个读取数都在界限内的不变量保证不会溢出。 无论符号如何，总和都会被正确处理，证明了算法在输入极端情况下的鲁棒性。 同样，对于`0 0`，总和是`0`，确认最小输入的正确行为。
