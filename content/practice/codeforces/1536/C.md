 ## 解决方案
 ## 问题理解

 我们得到一个仅由字符组成的二进制字符串`D`和`K`。 对于该字符串的每个前缀，我们想要确定如何精细地将该前缀分割成连续的片段，以便每个片段之间具有相同的内部平衡`D`和`K`。 

每件作品都通过一个比率进行总结，描述了有多少`D`沙`K`它包含。 如果两个部分在归一化后比例匹配，则认为它们是兼容的，这意味着它们之间的比例`D`和`K`即使绝对计数不同，也是相同的。 

对于每个以位置结尾的前缀`i`，我们希望可以将其划分为最大数量的段，以便每个段具有相同的比率。 

关键的困难在于，必须对所有前缀进行计算，因此为每个前缀从头开始重新计算分区会太慢。 

这些约束意味着每个测试用例都有一个线性或接近线性的解决方案。 由于所有测试用例的总长度高达 500,000，因此任何重复扫描前缀或尝试每个前缀的所有分割点的解决方案都会超出时间限制。 这立即排除了任何重新启动计算的二次或逐前缀动态规划。 

当字符串均匀时，会出现微妙的边缘情况。 例如，如果字符串是`DDDDD`，每个前缀都可以被分割成单字符段，并且答案线性增长。 试图强制执行有意义的幼稚方法`D:K`比率可能会错误地假设两个字符必须出现在每个段中，这是错误的，因为比率如`a:0`是有效的。 同样，前缀如`DKDK`允许平衡交替分割，但不跟踪全局可行性的贪婪分割可能会错过有效分区。 

另一个棘手的情况是当`K`永远不会出现。 例如，在`DDDD`，每个前缀都应该允许拆分为所有单个字符。 任何假设需要两个字符来定义比率的方法都会在这里失败。 

## 方法

 对于每个前缀，暴力解决方案将尝试所有可能的分区并检查所有段是否共享相同的比率。 对于长度前缀`i`，有指数级的多种分割方式，甚至验证单个分区也需要扫描所有段来比较比率。 即使我们限制自己测试所有可能数量的段并尝试贪婪验证，我们仍然会在每个测试用例中得到大致二次的行为。 

关键的结构见解是，一旦我们决定需要多少个段，有效的分区就完全由整个前缀的比率决定。 如果一个前缀可以分为`k`有效的段，那么每个段必须对应于总段的固定比例`D`和`K`很重要。 这意味着有效的分割完全对应于前缀缩减比率结构的除数。 

我们没有显式地构建分区，而是跟踪前缀的每个标准化状态出现的频率。 每个前缀状态以保留比率等价性的方式编码我们与先前状态的距离。 每当我们重新访问一个状态时，我们实际上是在说前缀可以分为更多具有相同结构的段。 

这将问题简化为维护前缀的标准化表示的计数并使用频率累积来导出每个前缀的一致片段的最大数量。

 ## 算法演练

 我们通过其简化表示来解释每个前缀`D`和`K`平衡。 我们不存储原始计数，而是维护一个唯一标识前缀比率行为的标准化签名。 

1. 我们遍历字符串，同时维护累计计数`D`和`K`。 处理完每个字符后，我们计算这两个计数之间的比率的规范形式。 
2. 为了使比率具有可比性，我们减少`(d, k)`当两者都不为零时，将两者除以最大公约数。 如果其中一个为零，我们将状态表示为一种特殊形式，例如`(1, 0)`或者`(0, 1)`取决于哪个角色占主导地位。 
3.我们维护一个频率图`freq`计算到目前为止每个标准化前缀状态出现的次数。 
4. 对于每个前缀，我们增加其标准化状态的计数`freq`。 
5. 当前前缀的答案就是迄今为止看到的任何状态的最大频率，因为重复相同的标准化状态意味着我们可以在出现的情况之间对齐段。 
6. 我们在迭代时存储运行最大值，因为必须为每个前缀输出答案。 

微妙的想法是，每当相同的标准化前缀状态出现多次时，它就会定义自然的切点，相同的比率段可以在其中开始和结束。 因此，最常见状态的频率直接给出等比段的最大数量。 

### 为什么它有效

 每个前缀状态对前缀的比率结构进行编码直至标准化。 具有相同状态的两个位置意味着它们之间的段具有相同的`D:K`在缩放下进行比较时的比例。 对字符串进行最佳分区相当于对相同状态的出现进行分组，因为任何有效的分段都必须与比率重置为相同配置的边界对齐。 最频繁的状态决定了有多少个这样的一致段可以共存。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import defaultdict

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()

        d = 0
        k = 0
        freq = defaultdict(int)

        ans = []
        best = 0

        for ch in s:
            if ch == 'D':
                d += 1
            else:
                k += 1

            # normalize ratio
            if d == 0:
                key = (0, 1)
            elif k == 0:
                key = (1, 0)
            else:
                import math
                g = math.gcd(d, k)
                key = (d // g, k // g)

            freq[key] += 1
            if freq[key] > best:
                best = freq[key]

            ans.append(str(best))

        print(" ".join(ans))

if __name__ == "__main__":
    solve()
```该代码维护运行计数`D`和`K`同时将每个前缀压缩成缩减比例的形式。 这`gcd`步骤确保比例状态折叠成相同的键，因此结构上等效的前缀映射到相同的标识符。 字典会跟踪每个结构出现的频率，并且答案会随着最频繁结构的增长而变化。 

唯一微妙的实现细节是单独处理零个案例。 如果没有这一点，当其中一个计数为零时，基于 gcd 的归一化计算将会失败，并导致不明确的表示。

 ## 边缘情况

 对于像这样的字符串`KKKK`，每个前缀都保持相同的标准化状态`(0,1)`。 该算法对这种状态的重复出现进行计数，从而产生稳定增加的答案。 这与每个附加字符可以形成另一个有效的单字符段的事实相匹配。 

为了`DKK`，第一个字符创建状态`(1,0)`，第二个创建`(1,1)`，第三个产生`(1,2)`这减少到`(1,2)`再次。 频率机制正确区分结构上不同的前缀，同时仍然允许重复状态在以简化形式重新出现时累积。
