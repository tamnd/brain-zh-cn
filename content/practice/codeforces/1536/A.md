 ## 解决方案
 ## 问题理解

 我们得到一小组不同的整数，并且可以向其中添加新的不同的整数。 目标是构建一个最终集合，使其满足非常强的闭包属性：每当我们从集合中选取任何两个数字时，它们之间的绝对差也必须已经存在于同一集合中。 

这一要求迫使该集合必须非常结构化。 如果两个值相距较远，则它们的间隙必须已作为元素存在于集合内。 然后，新引入的值再次与其他元素交互，可能会造成更多差距，等等。 这种构造不是局部的，因为每一对都通过差异与其他每一对相互作用。 

每个测试用例都会询问是否可以将给定的集合补全为这样一个“差异封闭”集合，同时保持总大小最多为 300，如果可以，我们必须显式构造一个有效的补全。 

约束是适度的：最多 50 个测试用例，并且值最初限制在一个小范围内。 然而，300 个元素的产量限制至关重要。 它告诉我们，任何依赖指数闭包或无限制闭包扩展的解决方案都会失败。 我们需要一种能够快速稳定闭合的结构。 

一个天真的担忧是，重复添加缺失的差异可能会爆炸。 例如，从一个小的不规则集合开始，例如`{0, 4, 10}`会产生`{4, 6, 10}`然后`{2, 4, 6, 8, 10}`等等，看起来它可能会无限期地持续下去或变得太大。 关键的难点是控制这个过程是否稳定在300个元素以内。 

第二种微妙的情况是当输入已经包含多个混合在一起的算术比例时，例如`{1, 4, 6, 10}`。 有些对产生的差异与任何现有结构都不相符，并且尝试修复一对可能会破坏另一对，除非将整个集合嵌入到一致的模式中。 

## 方法

 蛮力观点是重复执行条件。 我们获取当前集合，计算所有成对绝对差，并插入任何缺失的差值。 我们继续下去，直到没有新元素出现或大小超过 300。这在概念上很简单，因为它直接强制执行良好数组的定义。 

问题是每次迭代都涉及检查所有对，即 O(k²)，并且每次插入都会更改结构，可能需要多次迭代。 在最坏的情况下，闭包的行为可能类似于欧几里得算法在许多数字上的扩展，在稳定或超过限制之前生成一个大的中间集。 这使得该过程不可预测并且速度太慢而无法直接依赖。 

关键的观察是，有效集合的行为必须类似于由其元素在减法闭包下生成的格子。 避免不受控制的增长的唯一方法是所有数字都位于一个算术级数中。 如果该集合的形式为`{x, x+d, x+2d, ..., x+kd}`，那么每个差值都是`d`，只要所有中间倍数都存在，就满足闭包。 这立即表明该集合实际上必须是某个缩放坐标系中的连续段。 

因此，问题简化为寻找给定的数字是否可以嵌入到一个算术级数中，该算术级数的步骤除以所有成对的差。 自然的选择是查看所有成对差异的最大公约数。 如果我们计算`g = gcd(|a_i - a_j|)`，那么所有有效数字必须位于步骤网格上`g`。 一旦我们通过将所有内容除以来标准化`g`，问题就变成检查我们是否可以将集合扩展到完整的连续段。 

此时，构造变得简单：我们尝试填充从`min(a)`到`max(a)`有步骤`g`。 该集合保证满足闭包属性，因为每个差异都是`g`，并且每个这样的倍数都作为区间中的一个元素出现。 

当所需的完成超过 300 个元素的限制时，就会出现唯一的障碍。 由于区间大小为`(max - min)/g + 1`，只有当 ≤ 300 时我们才会成功。

 ## 算法演练

 1. 读取数组并计算其最小值和最大值。 这两个值定义可能包含任何有效完成的最小间隔。 任何解决方案都必须至少包含这些端点，因为它们已经是输入的一部分。 
2. 计算最大公约数`g`所有成对差异`|a_i - a_1|`。 这捕获了整个集合中一致的最小步长。 抛锚的原因`a_1`是所有差异在翻译之前都是等效的。 
3.如果`g`为零，意味着所有值都相同，该集合非常好并且不需要扩展。 我们只是输出相同的元素。 
4. 通过生成以下所有值来构造候选集`min(a)`到`max(a)`一步步走过`g`。 这确保我们填充闭包条件可能需要的每个中间格点。 
5. 检查构造的集合大小是否超过300。如果超过，则约束内不存在有效构造，因此输出NO。 
6. 否则输出 YES，后跟构造的序列。 

### 为什么它有效

 The closure condition forces any valid set to be stable under taking differences, which implies all elements must lie in a single additive subgroup of the integers generated by a fixed step size`g`。 一旦确定了该结构，确保封闭的唯一方法就是将每个可到达的点包含在最小值和最大值之间的区间中。 任何缺失的点都会产生集合中不存在的差异，从而破坏条件。 因此，在尺寸范围内，构造既是必要的也是充分的。
