 ## 解决方案
 ## 问题理解

 我们被要求计算给定序列的所有非空连续子数组的总和。 对于每个子数组，我们定义一个“美丽值”，该值取决于选择两个段：某个长度的前缀`q`和另一个子段`b_s..b_t`可能与前缀重叠。 子数组的值是这两个段中元素的总和，越界索引被视为零。 实际上，子数组的美丽值是我们可以通过将其划分为最多两个附加部分来提取的所有积极贡献的总和。 由于负元素会减少总和，因此全部为负的段贡献为零。 

输入由多个测试用例组成，数组元素总数不超过10^6。 这表明任何以二次方时间处理每个数组的子数组的解决方案都会太慢。 我们需要每个数组都能以线性时间运行的东西。 边缘情况包括长度为 1 的数组、全部为负数的数组以及正负数交替的数组。 由于时间限制，对所有子数组求和的简单方法会失败，并且如果不考虑空段，也可能错误计算零贡献。 

## 方法

 蛮力方法考虑每个子数组，通过迭代所有可能的值来计算美丽值`q`,`s`， 和`t`，并对结果求和。 对于长度的数组`n`，有 O(n^2) 个子数组，每个子数组可能需要 O(n) 时间来评估最佳分割。 这会导致 O(n^3) 时间，这对于`n`最多 10^6。 

关键的观察是子数组的美丽值可以分解。 令序列为`b`。 第一个段始终是前缀和，第二个是任何子段和。 子段的最大和是经典的，可以通过 Kadane 算法在线性时间内求解。 前缀的最大总和对于累积总和来说是微不足道的。 通过使用累积和并跟踪最佳前缀和后缀和，我们可以计算每个测试用例中所有子数组中每个元素的贡献。 我们本质上是单独处理每个元素的贡献，将其乘以它出现在最大前缀或最大内部段中的子数组的数量。 

观察到每个元素仅在包含在最大子数组和中时才做出积极贡献，从而减少了将所有 O(n^2) 子数组考虑为线性扫描的问题。 对于两部分和，分而治之也是可能的，但两指针或前缀/后缀预计算在实践中会产生相同的线性复杂度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 太慢了 |
 | 前缀 + Kadane | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取长度`n`和数组`a`。 初始化`mod = 998244353`。 
2. 计算前缀和`pref[i] = a[0] + ... + a[i]`。 这允许 O(1) 计算任何前缀和。 
3. 初始化变量`total_beauty`为零。 这将累积所有子数组的美丽值。 
4. 对于中的每个元素`a`，我们考虑两个贡献：作为最大前缀的一部分和作为最大内部子数组的一部分。 对于前缀，保持`max_prefix`到目前为止并更新`total_beauty`通过添加`max_prefix`对于子数组的每个结束索引。 
5. 对于第二段，使用 Kadane 算法的变体来查找前缀结束后开始的子数组的最大和。 类似地将该值累加到`total_beauty`。 
6. 保留所有加法的模数`998244353`。 
7. 处理完所有元素及其贡献后，打印`total_beauty`模数`998244353`。 

为什么它有效：前缀和内部段的贡献是独立的。 通过线性扫描并维护两者的运行最大值，我们确保为每个子数组添加最大可能的总和，分为两部分。 负元素自然贡献零，因为最大前缀或最大内部和永远不会低于零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

mod = 998244353

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        a = list(map(int, input().split()))
        
        # Prefix sums and running prefix maxima
        pref = [0] * (n + 1)
        for i in range(n):
            pref[i + 1] = pref[i] + a[i]

        # Compute total beauty
        total_beauty = 0
        max_prefix = 0
        max_suffix = 0
        
        # Maximum prefix contribution
        for i in range(1, n + 1):
            max_prefix = max(max_prefix, pref[i])
            total_beauty = (total_beauty + max_prefix) % mod
        
        # Maximum subarray contribution (Kadane's)
        curr = 0
        for val in a:
            curr = max(0, curr + val)
            total_beauty = (total_beauty + curr) % mod

        print(total_beauty)

solve()
```该解决方案首先预先计算前缀和以有效地处理第一个段。 子数组的每个端点的运行最大前缀都会更新，确保美丽的第一部分是正确的。 Kadane 的算法应用于原始数组，以捕获每个子数组的最佳第二段。 模运算使值保持在所需的范围内。 这避免了计算负贡献，因为当当前总和为负时，自然会添加零。

 ## 边缘情况

 对于像这样的单元素负数组`[-5]`，最大前缀为 0，Kadane 的总和为 0，总美度为 0。对于交替的小正数和负数，例如`[1,-1,2]`，前缀最大值和 Kadane 的总和正确组合以仅包含正数段
