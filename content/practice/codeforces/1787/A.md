 ## 问题理解

 我们被要求找到两个整数$x$和$y$介于 1 和$n$包含这样的总和$x^y \cdot y$和$y^x \cdot x$等于$n$。 从概念上讲，我们正在寻找一对，其混合指数项由另一个数字加权，加起来正好等于$n$。 输入由多个测试用例组成，每个测试用例给出不同的$n$，并且每种情况的输出都是有效对$(x,y)$或者$-1$如果不存在这样的对。 

界限告诉我们$n$可以大到$10^9$，并且可能最多有$10^4$测试用例。 检查所有对的暴力方法$(x,y)$最多$n$最多需要$10^9 \times 10^9$在最坏的情况下进行操作，这显然是不可行的。 这意味着我们需要一种方法来极大地限制我们的搜索。 

一种微妙的边缘情况是$x = y$。 在这种情况下，表达式简化为$2 \cdot x^{x+1}$。 例如，如果$n = 31250$， 然后$x = y = 5$有效是因为$2 \cdot 5^6 = 31250$。 另一个边缘情况是较小的值$n$，如 1、2 或 3，其中只有少数极小的对是有效的。 从大量数字开始迭代的幼稚实现可能会错过这些。 最后，还有一些不对称的对，例如$x = 2, y = 3$为了$n = 42$，因此该解决方案必须考虑到$x \neq y$以及。 

## 方法

 最简单的暴力方法是迭代所有整数$x$和$y$从 1 到$n$并检查是否$x^y \cdot y + y^x \cdot x = n$。 如果存在的话，可以保证找到解决方案，但速度太慢了。 例如，即使对于$n = 10^5$，这将涉及到$10^{10}$操作，这超出了允许的时间许多数量级。 

关键的见解是要认识到方程增长得非常快$x$和$y$因为指数。 这意味着只有非常小的值$x$和$y$需要检查。 具体来说，任何解决方案都必须满足$x^y \cdot y \le n$和$y^x \cdot x \le n$，这限制了两者$x$和$y$大致由$\log_2(n)$最多。 根据经验，对于$n$最多$10^9$，尝试一下就足够了$x$和$y$最多 100。因此，我们可以迭代$x$从 1 到 100，并且对于每个$x$, 迭代$y$从 1 到 100，检查方程是否成立。 这为每个测试用例提供了最多 10,000 次操作，这对于$10^4$测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了 |
 | 有界搜索（最优）| O(100^2 * t) = O(10^6) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 这告诉我们需要处理后续数字多少次。 
2. 对于每个测试用例，读取整数$n$。 这是指数方程的目标总和。 
3.循环$x$从 1 到 100。选择这个上限是因为$x^y \cdot y$超过$10^9$快速获得更大的$x$。 
4. for循环内$x$, 循环$y$从 1 到 100。同样的推理也适用； 我们不需要走得更高，因为条款增长得太快了。 
5. 对于每对$(x,y)$, 计算$x^y \cdot y + y^x \cdot x$。 如果这等于$n$， 打印$x$和$y$，然后跳出循环来处理下一个测试用例。 
6. 如果所有迭代后都没有找到对，则打印$-1$。 

正确性来自于任何解决方案都必须有小的事实$x$和$y$由于指数增长。 通过将我们的搜索保守地限制在 100，我们保证捕获所有可行的解决方案$n \le 10^9$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    found = False
    for x in range(1, 101):
        for y in range(1, 101):
            if x**y * y + y**x * x == n:
                print(x, y)
                found = True
                break
        if found:
            break
    if not found:
        print(-1)
```该解决方案首先使用以下方法有效读取所有测试用例`sys.stdin.readline`。 嵌套循环实现有界搜索。 变量`found`确保我们在找到解决方案后退出两个循环。 我们使用整数求幂，在 Python 中它可以处理高达$10^{9}$安全无溢出。 循环次数故意限制为 100，以平衡完整性和效率。
