 ## 解决方案
 ## 问题理解

 我们给出了几个独立的整数。 对于每个整数 x，我们计算其平方根的整数部分，称其为 k = ⌊√x⌋。 任务是确定 x 是否“豪华”，这意味着它可以被 k 整除。 

因此输入是一系列数字，对于每个数字，我们输出一个二元决策：x mod ⌊√x⌋ 是否等于 0。 

结构故意被最小化。 每个查询都是独立的，因此不存在共享状态或累积效应。 输出通常是与输入顺序相同的答案序列。 

此类问题的约束样式通常很大，通常高达 10^5 或 10^6 个数字，其中 x 可能高达 10^18。 这种组合立即排除了任何超出每个数字的常数或对数功的解决方案。 对所有除数进行简单循环会太慢。 

微妙的边缘情况来自完美的正方形和非常小的数字。 

一种极端情况是 x = 1。这里 ⌊√1⌋ = 1，因此条件始终成立，并且答案基本上为真。 

另一种情况是当 x 刚好低于完全平方数时。 例如，x = 15 给出 ⌊√15⌋ = 3，并且 15 可以被 3 整除，因此它是有效的。 但是 x = 14 也给出 ⌊√14⌋ = 3，并且 14 不能被 3 整除，所以它失败。 这些相邻值强调决策边界是由平方根阶跃函数驱动的，而不是 x 本身的大小。 

第三种边缘情况是完全平方，例如 x = 16。这里 ⌊√16⌋ = 4，在某些情况下整除性变得精确（16 有效），但许多完全平方仍然会失败，具体取决于值，因此没有像“所有平方都通过”这样的捷径。 

## 方法

 暴力解释很简单：对于每个数字 x，计算 k = ⌊√x⌋，然后检查 x % k == 0 是否。如果我们通过从 1 向上扫描直到 i² 超过 x 来计算平方根，则每个查询的成本为 O(√x)。 输入过大时，这会变得令人望而却步，在最坏的情况下可能会达到 10^10 次操作。 

关键的观察是我们不需要搜索 k。 值 ⌊√x⌋ 可以使用标准整数平方根例程直接计算，该例程根据实现以常数或对数时间运行。 一旦 k 已知，整除性检查就是常数时间。 

因此，该问题的结构在算法上并不深入，但对正确的整数平方根计算很敏感。 浮点 sqrt 必须小心处理，因为舍入错误可能会错误地生成 k 或 k+1，这会改变接近完美平方的整除结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 强力 sqrt 扫描 | 每个查询 O(√x) | O(1) | O(1) | 太慢了|
 | 整数开方 + 检查 | 每个查询 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每个数字。 

1. 读取整数x。 每个值都是单独处理的，因此不需要预处理。 
2. 计算 k 作为 x 的整数平方根。 这是满足 k² ≤ x 的最大整数。 其余逻辑的正确性取决于 k 是精确的，而不是近似的。 
3. 检查x 是否能被k 整除。 如果 x % k == 0，则将 x 分类为豪华，否则将其分类为非豪华。 
4. 在移至下一个数字之前输出 x 的结果。 

唯一重要的决定是可靠地计算 k。 在许多环境中使用浮点 sqrt 和截断是可以接受的，但更安全的方法是使用整数算术计算 k 或围绕候选值进行调整以正确舍入。

为什么有效：每个数字都仅根据其与 ⌊√x⌋ 的关系进行分类。 数字之间没有交互作用，也没有隐藏状态。 整数平方根将输入空间划分为 k 为常数的区间，并且在每个区间内我们仅测试单个模条件。 这保证了一旦 k 被正确计算，决策就是准确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def solve():
    t = int(input())
    for _ in range(t):
        x = int(input())
        k = math.isqrt(x)
        if x % k == 0:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```该解决方案是围绕`math.isqrt`，这完全避免了浮点精度问题。 一个常见的错误是使用`int(math.sqrt(x))`直接进行，对于大的完美正方形，由于不正确地向下舍入或偶尔在边缘情况下向上舍入，这可能会失败。 整数平方根例程保证 k² ≤ x < (k+1)²。 

其余的实现故意被最小化：每个测试用例都是独立的，并且可分性检查是恒定时间。

import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = []
    input = sys.stdin.readline

    t = int(input())
    for _ in range(t):

 ## 边缘情况

 对于 x = 1，我们得到 k = 1，因此整除条件始终成立。 该算法直接返回 YES，无需任何特殊处理，因为 1 % 1 = 0。 

对于正好低于完全平方数的数字，例如 x = 24，我们得到 k = 4。算法检查 24 % 4 = 0，返回 YES，这与定义匹配。 对于 x = 23，k 仍为 4，但 23 % 4 ≠ 0，返回 NO。 正确性完全取决于使用 ⌊√x⌋ 而不是任何舍入平方根。 

对于像 x = 49、k = 7 和 49 % 7 = 0 这样的完全平方数，因此输出为 YES。 这证实了该算法无需任何调整逻辑即可处理精确的方形边界。 

对于 x = 2，k = 1，这将问题简化为检查整除性 1，始终为真。 该实现自然地处理这个问题而无需分支。
