 ## 解决方案
 ## 问题理解

 我们正在设计一个由几个独立齿轮制成的时钟。 一个齿轮与`x`牙齿每完成一个完整的周期`x`秒，因为它每秒移动一颗牙齿。 所有齿轮在零时间开始对齐并一起移动，因此每个齿轮返回其初始位置的第一时刻是所有齿轮尺寸的最小公倍数。 

任务是选择齿轮尺寸，以便第一次同时返回恰好在`k`秒。 在所有可能的选择中，我们需要齿总数最少的结构。 

输入包含多个值`k`。 对于每一个，输出必须描述一组最佳的齿轮尺寸。 必须打印齿轮的数量和每个齿轮的齿数。 

的价值`k`至多是`100000`，并且最多可以有`10000`测试用例。 这意味着我们无法承担尝试多种齿轮组合的算法。 对可能的因素子集或分区的搜索会增长得太快。 我们需要使用最小公倍数和因式分解的数学结构。 

主要的边缘情况来自这样的事实：最小公倍数只关心出现的每个素数的最大幂。 

例如，如果输入是：```
1
16
```正确的输出是：```
1
16
```粗心的解决方案可能会输出`2 8`， 因为`lcm(2, 8) = 8`，这还不够。 完整的主电源`2^4`一定会出现在某个地方。 

另一种情况是：```
1
12
```正确的构造是：```
2
4 3
```使用`2 2 3`也会使最小公倍数等于`12`，但总齿数更大：`7`而不是`7`在这种特定情况下，它是相关的，而对于其他值，重复因素可能会更糟。 最佳构造必须避免不必要的重复并准确保留所需的素数幂。 

最终的边界情况是素数：```
1
97
```唯一有用的结构是：```
1
97
```将素数分解为更小的齿轮是不可能的，因为没有更小的因素可以在 LCM 中创建素数。 

## 方法

 一个直接的蛮力想法是尝试不同的齿轮集合并检查它们的最小公倍数是否为`k`。 这是正确的，因为有效的构造正是 LCM 与所需返回时间匹配的集合。 问题是可能的集合的数量。 甚至将我们限制为`k`，组合的数量随着因子的数量呈指数增长，因此这种方法变得不可用。 

关键的观察是每个整数都可以写成素数幂的乘积。 认为：`k = p1^a1 * p2^a2 * ... * pm^am`为了使齿轮的 LCM 包含`pi^ai`，至少一个齿轮必须包含准确的最高功率`pi`。 如果每个齿轮包含较小的功率`pi`，LCM 将错过该因素。 另一方面，与将这些主要动力分开相比，添加包含多个主要动力的齿轮只能增加总和。 

例如，不使用单个齿轮`12`，使用齿轮`4`和`3`给出相同的 LCM，但总和更小或相等。 因此，最便宜的结构是为分解中的每个主要动力创建一个齿轮`k`。 

蛮力方法之所以失败，是因为它忽视了主要大国的独立贡献。 一旦我们认识到每个素数幂都可以单独处理，问题就变成了简单的因式分解。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 因素数量呈指数增长 | 取决于搜索深度 | 太慢了|
 | 最佳| 每个测试用例 O(sqrt(k)) | O(素因数的数量) | 已接受 |

 ## 算法演练

 1.因素`k`转化为素数幂。 从尽可能小的除数开始，反复删除因数。 每当找到一个素数因子时，继续将其相乘，直到提取出该素数的全部幂。 

我们保留完整幂的原因是 LCM 需要每个素数的最大指数，而不仅仅是素数本身。 

1. 将每个提取的主功率存储为一个齿轮尺寸。 

例如，`72 = 2^3 * 3^2`，所以提取的值是`8`和`9`。 

1、如果试除后的余值大于1，则为比原数的平方根大的质因数。 将其添加为自己的装备。 
2. 输出提取的素幂数和齿轮尺寸列表。 

为什么它有效：

 因式分解中的每个素数幂`k`出现在至少一个选定的档位中，因此所有选定档位的 LCM 包含`k`。 由于每个选择的齿轮都划分`k`，LCM 不能包含任何额外的东西，所以它恰好是`k`。 

为了实现最优性，请考虑任何有效的构造。 对于每一个素数`p`在`k`，某些齿轮必须包含所需的全部功率`p`，否则 LCM 将失去该电源。 满足每个要求的最便宜的方法是将这些主要动力用作单独的齿轮。 将两个所需的素数组合成一个档位，用它们的乘积替换它们的总和，并且对于大于 1 的整数，乘积永远不会小于此设置中的总和。 因此，独立的主动力结构最大限度地减少了齿的总数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(k):
    ans = []
    x = k
    d = 2
    while d * d <= x:
        if x % d == 0:
            power = 1
            while x % d == 0:
                x //= d
                power *= d
            ans.append(power)
        d += 1 if d == 2 else 2

    if x > 1:
        ans.append(x)

    return ans

def main():
    t = int(input())
    out = []
    for _ in range(t):
        k = int(input())
        ans = solve_case(k)
        out.append(str(len(ans)))
        out.append(" ".join(map(str, ans)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```因式分解循环尝试除数，直到除数的平方超过剩余值。 一旦发生这种情况，任何剩余的值都必须是质数，因为合数的因数不大于其平方根。 

当找到除数时，内部循环将删除该素数的所有副本。 变量`power`累积全部素数幂，例如将 的重复因子转变成`2`进入`8`为了`72`。 

检查后增量甚至会跳过候选人`2`，这避免了不必要的工作。 自从`k`只是`100000`，简单的试除已经足够快了。 

输出始终包含至少一个齿轮，因为`k`至少是`2`。 素数输入将素数留在`x`，最终值由剩余因子检查处理。

 ## 边缘情况

 对于`k = 16`，算法提取因子`2`四次并合并为一档值：```
16 = 2^4
```产生的结构是：```
1
16
```LCM 正是`16`，而使用较小的齿轮将会失败，除非它们的组合 LCM 包含完整的 2 的四次方。 

为了`k = 12`，因式分解为：```
12 = 2^2 * 3
```该算法输出：```
2
4 3
```液晶模组是`12`。 一个结构仅包含`2`和`3`会产生`6`，所以保持满功率`4`是必要的。 

为了`k = 97`，试分割后的剩余价值仍为`97`，所以直接添加：```
1
97
```质数不能由较小的除数组装而成，因此单齿轮是唯一可能的最佳结构。
