 ## 解决方案
 ## 问题理解

 我们得到一个整数数组和交换元素的限制：只有当两个元素的位置相差至少时，我们才能交换两个元素`x`。 任务是确定在此约束下是否可以按非降序对数组进行排序。 每个测试用例指定数组和值`x`。 

第一个观察结果是，如果`x`相对于数组长度来说很大，一些位置被有效地“锁定”。 例如，如果`x = n`，根本不可能进行交换，因此数组必须已经排序。 相反，如果`x = 1`，没有限制，我们可以执行任何交换，这意味着我们总是可以对数组进行排序。 棘手的情况发生在`1 < x < n`，因为只有某些位置可以交互。 

约束条件告诉我们`n`可以达到`10^5`每个测试用例，以及所有测试用例的总和`n`所有测试用例最多`2 * 10^5`。 这意味着任何复杂性比以下更差的解决方案`O(n log n)`每个测试用例可能太慢。 尝试所有交换序列的简单方法将是指数级的并且完全不可行。 

当数组接近排序但最小或最大元素被困在中间时，由于以下原因它们无法移动足够远，就会出现不明显的边缘情况：`x`限制。 例如，考虑`[3, 2, 1]`和`x = 3`。 该数组足够小，不允许交换，因此即使它几乎已排序，答案也是“否”。 另一个棘手的场景是数组，其中`x`只是略小于`n/2`，留下不能与末端相互作用的中间部分。 

## 方法

 暴力方法很简单：尝试每个配置中所有允许的交换，直到数组排序完毕或用尽所有可能性。 这保证了正确性，因为我们最终会探索每一个可达的排列。 然而，交换数量呈指数增长`n`，所以即使对于`n = 20`这变得不切实际。 

关键的观察是，只有位置至少为`x`分开可以互换。 如果`x <= n/2`，那么开头附近的每个元素最终都可以到达结尾附近的每个元素，可能通过一系列交换。 然而，长度中间区域的元素`n - 2*x`受到限制：如果`x > n/2`。 因此，如果数组尚未在这些中间位置排序，则排序是不可能的。 

最佳解决方案通过将数组与其完全排序的版本进行比较来利用这一点。 我们只需要检查每个无法到达末端的元素（“固定”中间段）是否已经处于正确的位置。 如果所有这些元素都与已排序的数组匹配，则可以进行排序； 否则，就不是。 这将问题简化为排序后的简单比较，无需模拟交换。

 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读`n`,`x`，和数组`a`。 
2. 创建数组的排序版本，`sorted_a`。 这代表了目标安排。 
3.如果`x <= n/2`，每个元素最终都可以交换到任何位置。 在这种情况下，请立即返回“YES”。 
4. 否则，对于职位`i`从`n - x`到`x - 1`（无法到达末端的“中间”段），检查是否`a[i] == sorted_a[i]`。 如果任何元素不同，则返回“NO”。 
5. 如果中间段中的所有位置都与已排序的数组匹配，则返回“YES”。 

为什么有效：中间段之外的元素可以自由移动，通过允许的交换到达末端。 中间部分按相对顺序有效固定。 通过对照排序数组检查这些固定位置，我们确定可行性。 这个不变量保证了正确性，而无需模拟交换。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_sort(n, x, a):
    sorted_a = sorted(a)
    if x <= n // 2:
        return "YES"
    for i in range(n - x, x):
        if a[i] != sorted_a[i]:
            return "NO"
    return "YES"

t = int(input())
for _ in range(t):
    n, x = map(int, input().split())
    a = list(map(int, input().split()))
    print(can_sort(n, x, a))
```功能`can_sort`抓住核心逻辑。 我们首先对数组进行排序以了解目标位置。 为了`x <= n//2`，我们可以对任何数组进行排序，因此我们立即返回“YES”。 对于较大的`x`，我们只检查受约束的中间部分。 使用`range(n - x, x)`准确选择无法移动足够远的索引。 对于边缘情况，这里的相差一错误会默默地失败，因此注意包含与排除边界至关重要。

 ## 边缘情况

 当数组长度等于`x`，不可能进行交换。 为了`[3, 2, 1]`和`x = 3`，中间段是完整数组，未排序。 该算法检查所有位置并输出“NO”。 

为了`x <= n//2`， 例如`[5, 1, 2, 3, 4]`和`x = 2`，中间段实际上是空的。 所有元素都可以自由洗牌，因此该函数输出“YES”。 

对于具有重复元素的数组，例如，`[1, 2, 2, 1]`和`x = 3`，算法正确识别中间段位置是否需要调整，避免误报。
