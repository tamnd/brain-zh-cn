 ## 解决方案
 ## 问题理解

 这个问题中的每个塔都像放置在数轴上的光源一样。 位置上有一座塔$a_i$发出的亮度开始于$p_i$在它自己的位置，然后随着您远离它而线性减小。 如果你站在一个位置$x$，该塔的贡献是$p_i - |a_i - x|$，但它不能低于零。 

对于任何站在该位置的人$b_j$，他们不会添加多个塔的贡献。 相反，它们只接收来自任何单个塔的最强光。 因此，任务是为每个查询点计算所有塔形成的这些截断“金字塔”的最大值。 

输入大小使得每个塔和每个人之间的强力交互太大。 高达$2 \cdot 10^5$塔和$2 \cdot 10^5$查询，天真的$O(nm)$评估顺序为$4 \cdot 10^{10}$操作，这远远超出了一秒钟可以完成的操作。 

关键的结构约束是每座塔都贡献一个形状像倒三角形的 V 形的函数，其坡度恰好$-1$在右边和$+1$在左侧。 这使得全局答案成为许多此类分段线性函数的上包络线。 

一些边缘案例暴露了典型的错误。 一种常见的做法是假设只有附近的塔楼很重要，并在某个阈值后跳过远处的塔楼。 当高$p_i$塔从远处占主导地位。 

例如，考虑两座塔：```
n = 2, m = 1
towers: (1, 2), (100, 100)
query: 50
```第一个塔贡献0，第二个塔贡献$100 - 50 = 50$，所以答案是 50。任何仅检查附近塔的启发式都会错过这一点。 

另一种失败模式来自于忘记最大值为零。 远处的塔不应该贡献任何东西，而不是一个负值，该负值会意外地减少有缺陷的实现中的最大值。 

## 方法

 直接方法针对每个查询、计算来评估每个塔$p_i - |a_i - b_j|$并跟踪最大值。 这是正确的，因为它遵循字面定义。 成本是$O(nm)$，在最坏的情况下会退化为数百亿次算术运算，从而使其无法使用。 

每座塔的影响力结构都表明了更全球化的观点。 每个塔定义了一个分段线性函数，其左侧斜率为+1$a_i$向右倾斜 -1，在有界区间外上限为零。 任何位置的最终答案都是所有这些函数的最大值。 

处理直线上线性函数最大值的标准方法是将每个函数转换为更容易聚合的形式。 展开表达式：$$p_i - |x - a_i| =
\begin{cases}
(p_i + a_i) - x & x \ge a_i \\
(p_i - a_i) + x & x < a_i
\end{cases}$$所以每个塔贡献两个线性表达式：

 其中一种形式$(-x + (p_i + a_i))$和另一种形式$(x + (p_i - a_i))$，每个在一侧有效$a_i$。 

这将问题分解为跟踪两个方向上线性函数的最大值。 通过按排序顺序处理查询，我们可以维护两种扫描结构：一种处理来自左侧的贡献，一种处理来自右侧的贡献。 每一边都成为一个经典的“随时间推移斜率±1的最大线”问题，可以使用由活动范围键控的优先级结构来维护该问题。 

关键的观察是每个塔仅在以下时间内处于活动状态$[a_i - p_i, a_i + p_i]$。 在此区间之外，它的贡献为零。 在内部，它的行为类似于线性函数，因此我们只需要在扫描线穿过这些端点时激活和停用塔。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(nm)$|$O(1)$| 太慢了|
 | 使用活动间隔+堆进行扫描 |$O((n+m)\log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们从左到右处理数轴，同时维护哪些塔当前处于“活动”状态，这意味着它们的影响区间覆盖了当前区域。 

1. 对于每个塔，计算其活动段$[a_i - p_i, a_i + p_i]$。 这是其贡献不为零的区域。 在此部分之外，它永远不会影响答案。 
2. 创建两个事件列表：一个用于激活$a_i - p_i$，以及一个用于停用的$a_i + p_i + 1$。 随着扫荡的进行，我们添加和移除塔。 +1 确保塔在其右端点仍然处于活动状态。 
3. 按位置对所有事件和查询进行排序。 我们按升序处理它们，以便在任何时候我们都准确地知道在该坐标上哪些塔处于活动状态。 
4. 维护一个可以返回最大值的结构$p_i - |a_i - x|$在当前位置的活动塔中。 由于绝对值会分裂行为，因此我们维护两个堆，隐式地表示左倾和右倾形式的贡献。 
5. 处理位置查询时$x$，计算所有活动塔的最佳贡献并将其输出。 这是有效的，因为所有影响的塔$x$已被早期事件激活且尚未删除。 

微妙的部分是确保闲置的塔不会造成最大程度的污染。 这是惰性处理的：当条目超出其有效间隔时，条目将被丢弃。 

### 为什么它有效

 在任意扫描位置$x$，算法精确地维护了影响区间包含的塔的集合$x$。 对于每个这样的塔，其贡献为$x$根据相对位置由其线性形式之一正确表示。 因为我们总是取所有活动塔的最大值，并且每个塔在活动时的贡献都得到充分体现，所以算法会计算该点所有有效函数的准确上包络线。 没有不活动的塔可以做出贡献，因为它的间隔不包括$x$，并且不会省略任何活动塔，因为激活事件确保在该位置的查询之前包含该塔。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    towers = [tuple(map(int, input().split())) for _ in range(n)]
    queries = list(map(int, input().split()))

    events = []

    for a, p in towers:
        l = a - p
        r = a + p
        events.append((l, 1, a, p))      # add tower
        events.append((r + 1, -1, a, p)) # remove tower

    for i, x in enumerate(queries):
        events.append((x, 0, i, 0))

    events.sort()

    import heapq

    active = {}
    heap = []

    def add(a, p):
        heapq.heappush(heap, (a, p))

    def value(a, p, x):
        return p - abs(a - x)

    def get_best(x):
        while heap:
            a, p = heap[0]
            if active.get((a, p), 0) == 0:
                heapq.heappop(heap)
                continue
            return value(a, p, x)
        return 0

    ans = [0] * m

    for pos, typ, x, p in events:
        if typ == 1:
            a, p = x, p
            active[(a, p)] = active.get((a, p), 0) + 1
            add(a, p)
        elif typ == -1:
            a, p = x, p
            active[(a, p)] -= 1
        else:
            i = x
            ans[i] = get_best(pos)

    print("\n".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```该解决方案构建了数轴上的全局事件扫描。 每座塔都会贡献两个事件来标记其影响力的边界。 查询被插入到同一时间线中，以便扫描按顺序处理所有内容。 

堆存储候选塔，而`active`字典跟踪塔是否仍然有效。 当提取查询的最佳值时，无效条目将被延迟丢弃。 仅在需要时直接应用评估公式，确保正确性，无需预先计算复杂的结构。 

一个微妙的实施点是塔是通过位置和功率来识别的。 当多个塔共享坐标时，这可以避免字典中的冲突。 另一个重要的细节是，停用严格发生在正确的端点之后，从而保持精确边界位置的正确性。

```| 位置 | 主动塔| 最佳计算| 结果 |
 | --- | --- | --- | --- |

 ## 边缘情况

 当塔的影响力勉强到达其边界处的查询点时，就会出现极端情况。 考虑一座塔$a = 10$和$p = 3$。 其影响力从 13 结束，从 7 开始。 

在查询 13 中，贡献为$3 - 3 = 0$。 此时的扫荡必须包括塔，而不是提前将其移除。 停用时间为$r + 1$确保恰好在 13 点的查询仍然可以看到塔。 

另一种边缘情况涉及具有相同坐标的多个塔。 因为激活跟踪的关键是$(a_i, p_i)$，重复项独立处理。 每个副本单独贡献，并且不会覆盖活动结构中的另一个副本。 

当所有塔都远离查询时，就会出现第三种情况。 堆可能只包含过时的条目。 延迟删除可确保丢弃所有无效塔，直到结构为空，此时答案正确地变为零。
