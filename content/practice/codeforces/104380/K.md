 ## 解决方案
 ## 问题理解

 我们得到一个代表池塘的二进制网格，其中每个单元格要么是水，要么是空地。 在此网格之上，我们考虑每个可能的固定大小的正方形区域$k \times k$。 对于每个这样的正方形，我们计算它包含多少个水细胞，并且要求该计数必须始终是偶数。 如果即使有一个方块违反了这个条件，整个网格都会被拒绝。 

因此，该任务是对网格的所有重叠子方块进行全局一致性检查，而不仅仅是单个单元格的局部属性。 

限制很小：$n, m \le 100$， 和$k \le \min(n, m)$。 这立即告诉我们，$O(n^3)$或者$O(n^2 k^2)$原则上解决方案已经可以接受，但是任何在每个子方块内重复重新计算总和的方法都将是脆弱的。 最多有大约$10^4$网格中的方格，每个方格最多包含$10^4$单元格，因此简单的重新计算将达到$10^8$操作，虽然是边缘操作，但只有经过仔细优化，仍然可能在 Python 中通过。 预期的解决方案更干净，并且完全避免重复工作。 

出现微妙的边缘情况时$k = 1$。 每个方格都是一个单元格，因此每个单元格必须单独包含偶数个水单元格，这意味着每个水单元格实际上必须为 0。因此整个网格必须全为零。 一个朴素的求解器假设$k \ge 2$可能会意外地跳过此步骤或错误地处理单个单元格奇偶校验的解释。 

当出现另一种边缘情况时$k = n = m$。 只有一个方格，答案就简化为检查网格中的总数是否为偶数。 任何滑动窗口逻辑仍然必须正确处理只有一个子方块的情况。 

## 方法

 一种直接的方法是迭代每个可能的左上角$k \times k$平方并从头开始重新计算其单元格的总和。 对于每个这样的位置，我们扫描$k^2$细胞并计算出现的数量。 由于有$(n-k+1)(m-k+1)$这样的正方形，这大致导致$O(nmk^2)$运营。 在所有维度均为 100 的最坏情况下，这大约变为$10^8$细胞访问。 这已经接近 Python 在 1 秒时间限制下的上限，更重要的是，它通过重复求和重叠区域来浪费计算。 

关键的观察是相邻的$k \times k$正方形几乎完全重叠。 当我们将窗口向右或向下移动一步时，只有一小部分单元格发生变化。 我们可以使用前缀和有效地维护每个平方的运行和，而不是重新计算每个和。 2D 前缀和允许我们在线性预处理后在恒定时间内计算任何矩形的总和。 这将问题从重复求和减少为每平方的恒定时间查询。 

那么问题就纯粹是关于检查矩形和的奇偶性，而前缀和正是为此而设计的工具。

 ## 算法演练

 我们将网格预处理为二维前缀和数组，以便可以在恒定时间内检索任何矩形和。 之后，我们扫描所有可能的$k \times k$子平方并验证其奇偶性。 

1.构建前缀和数组`ps`在哪里`ps[i][j]`存储矩形中从左上角 (0,0) 到 (i-1,j-1) 的 1 的数量。 这种索引转变避免了边界问题。 使用前缀和的原因是它将二维范围和转换​​为四个数组查找。 
2. 对于每个单元格，使用递归累积值：$$ps[i][j] = grid[i-1][j-1] + ps[i-1][j] + ps[i][j-1] - ps[i-1][j-1]$$减法纠正了重叠区域的重复计数。 
3. 迭代每个可能的左上角$k \times k$正方形, 意义$i \in [0, n-k]$,$j \in [0, m-k]$。 
4. 使用包含-排除计算该平方和：$$total = ps[i+k][j+k] - ps[i][j+k] - ps[i+k][j] + ps[i][j]$$这正好隔离了$k \times k$恒定时间内的区域。 
5.如果有的话`total % 2 == 1`，立即返回 false，因为违反了条件。 
6. 如果所有方格都通过，则返回 true。 

### 为什么它有效

 前缀和数组保持不变式，即每个条目都表示从原点开始的矩形上的精确累积计数。 因为每一个$k \times k$sum 是根据这些累积计数重建的，无需重新计算各个单元格，每个查询都是精确的且独立于遍历顺序。 正确性来自包含-排除，确保子方格中的每个单元格都被精确计数一次，并且其外部的单元格不会对结果产生影响。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m, k = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]

    ps = [[0] * (m + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        row_sum = 0
        for j in range(1, m + 1):
            row_sum += grid[i - 1][j - 1]
            ps[i][j] = ps[i - 1][j] + row_sum

    for i in range(n - k + 1):
        for j in range(m - k + 1):
            total = (
                ps[i + k][j + k]
                - ps[i][j + k]
                - ps[i + k][j]
                + ps[i][j]
            )
            if total % 2 == 1:
                print("false")
                return

    print("true")

if __name__ == "__main__":
    solve()
```该实现逐行构建前缀和，使用运行行累加器来避免重复添加。 与重新计算相比，这减少了常数因子`ps[i][j-1] + grid[i][j]`反复。 

子平方检查使用直接包含-排除。 索引移位一位，以便前缀和边界情况自然评估为零，无需条件检查。 尽早退出很重要，因为一旦发现单个无效方块，就不需要进一步的计算。

 ## 边缘情况

 当$k = 1$，每个单元格形成自己的正方形。 该算法简化为检查每个单元格值是否为偶数。 由于值只有 0 或 1，因此任何单个 1 都会立即失败。 前缀求和方法仍然有效，因为每个查询只隔离一个单元格。 

什么时候$k = n = m$，仅存在一个正方形。 前缀和查询对整个网格进行一次评估，奇偶校验应用于总和。 这避免了对超出单次评估的迭代逻辑的任何需要。 

当网格全为零时，每个前缀和保持为零，因此每个$k \times k$查询返回零并简单地通过奇偶校验。
