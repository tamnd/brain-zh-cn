 ## 解决方案
 ## 问题理解

 我们得到了一个在无限整数网格上移动的广义骑士棋子。 来自任何单元格$(x,y)$，它可以跳转到通过排列和翻转向量得到的八个对称位置$(p,q)$和$(q,p)$具有独立的符号变化。 这意味着每次移动都保留固定台阶形状的结构，但允许在平面中完全旋转和反射。 

任务是判断是否从原点开始$(0,0)$，我们可以到达目标点$(x,y)$使用任意数量的此类动作。 

约束允许最多$10^4$查询，坐标可达$10^9$在幅度上。 这强烈表明任何解决方案都必须是每个测试用例的恒定时间，因为即使$O(\sqrt{|x|+|y|})$在最坏的情况下，每个查询的推理速度会太慢。 

这个问题的一个微妙的方面是可达性在很大程度上取决于移动向量的算术结构。 与最短路径或 BFS 公式不同，网格是无限且对称的，因此答案完全由数论不变量而不是搜索确定。 

主要的边缘情况出现在以下任一情况下：$p$或者$q$为零，或者当$p = q$，因为移动集在对称性或折叠方向上退化。 例如，如果$p = q = 0$，骑士永远不会移动，所以只有$(0,0)$是可达的。 如果$p = 0$，骑士只能沿着轴对齐的条纹移动，奇偶约束变得决定性的。 

另一个重要的边缘情况是奇偶校验阻塞。 例如，一个$(1,2)$-knight 无法到达每个格点，即使两个坐标都可以被某种类似 gcd 的结构单独整除，因为由坐标奇偶性引起的网格着色在移动过程中得以保留。 

## 方法

 暴力解释将模拟所有可能的步行$(0,0)$，在无限网格上执行 BFS。 每个节点最多扩展为 8 个邻居，因此之后$k$我们探索的步骤$8^k$最坏情况下的状态。 由于坐标可以大到$10^9$，任何有意义的目标都可能需要大量步骤，使得这种方法不可行。 

关键的观察是移动集形成了一个格子$\mathbb{Z}^2$。 每一步都会从集合中添加一个向量$$(\pm p, \pm q), (\pm q, \pm p)$$因此可达点形成这些向量的所有整数线性组合。 这将问题简化为检查是否$(x,y)$位于由这些动作生成的加法子群中。 

我们不是探索路径，而是分析该格的不变量。 出现两个独立的约束：

 首先，每一步都保持整除性$g = \gcd(p,q)$。 每次移动的两个坐标都是$g$，所以任何可达点必须满足$x \equiv 0 \pmod g$和$y \equiv 0 \pmod g$。 

其次，将所有内容除以$g$，我们简化为互质对$(a,b)$和$\gcd(a,b)=1$。 在这个标准化系统中，结构仅取决于奇偶性和简并性：

 如果两者都$a$和$b$非零且不等，生成的格是奇偶条件与可达组合奇偶性匹配的所有整数点。 事实上，可以证明$(x',y')$可达当且仅当$(x'+y') \bmod 2 = 0$，因为每次移动都会以受控的方式改变奇偶性。 

什么时候$a = b$，移动折叠到对角线方向，将可达点限制为线$x' \pm y' = \text{constant}$。 

当其中之一$a,b$为零，运动变为轴对齐，可达性降低为检查沿轴的独立一维整除性。 

最终的解决方案变成了直接基于案例分析$(p,q)$，按其 gcd 缩放。

 ## 算法演练

 1. 计算$g = \gcd(p,q)$。 如果两者都$p$和$q$为零，唯一可到达的点是原点。 任何其他查询都是不可能的。 
2.通过缩放来减少问题：set$p = p/g$,$q = q/g$，并类似地检查$x$和$y$必须能整除$g$。 如果任一坐标不可整除，则返回“No”。 这是因为每一步都保留了整除性$g$。 
3.标准化坐标：定义$x' = x/g$,$y' = y/g$。 从这一点来看，我们只在互质系统中进行推理。 
4. 如果$p = 0$，那么马仅以垂直和水平的步长移动$q$。 这意味着一个坐标以另一方向的步长结构为模保持不变。 可达性减少为检查是否$x'$可以整除$q$和$y'$可以整除$q$，因为运动是轴对齐的。 
5.如果$p = q$，所有移动都简化为形式的对角线步骤$(\pm p, \pm p)$。 这将可达点限制为那些令人满意的点$x' \equiv y' \pmod{2p}$，这简化为要求$x' \equiv y' \pmod 2$。 
6. 如果简并性都不成立，则生成完整的格子。 在这种情况下，奇偶校验成为唯一的障碍：每次移动都会改变总和$x+y$是偶数，所以$x' + y'$必须均匀才能达到可达性。 
7. 如果满足所有条件，则返回“Yes”，否则返回“No”。 

### 为什么它有效

 可达集形成一个加法子群$\mathbb{Z}^2$由衍生自的对称向量生成$(p,q)$。 任何这样的子群都完全由线性可分约束和奇偶不变量来表征。 gcd 缩减隔离了缩放，而其余结构则取决于基向量是否跨越完整整数晶格或具有奇偶校验或对角线限制的子晶格。 由于所有移动都保留这些不变量，并且满足它们的任何点都可以通过整数组合构造，因此条件既是必要的也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from math import gcd

def solve():
    T = int(input())
    for _ in range(T):
        p, q, x, y = map(int, input().split())

        if p == 0 and q == 0:
            print("Yes" if x == 0 and y == 0 else "No")
            continue

        g = gcd(abs(p), abs(q))
        if x % g != 0 or y % g != 0:
            print("No")
            continue

        x //= g
        y //= g
        p //= g
        q //= g

        # normalize absolute structure
        p, q = abs(p), abs(q)

        if p == 0:
            # moves are (0, ±q) and (±q, 0)
            print("Yes" if x % q == 0 and y % q == 0 else "No")
        elif p == q:
            # diagonal lattice
            print("Yes" if (x - y) % 2 == 0 else "No")
        else:
            # general case: parity constraint
            print("Yes" if (x + y) % 2 == 0 else "No")

if __name__ == "__main__":
    solve()
```实现从处理琐碎的不动情况开始。 gcd 减少尽早强制执行全局缩放约束，这可以防止坐标与阶梯点阵不兼容时出现误报。 

案例$p = 0$被单独处理，因为移动集折叠成轴对齐的跳跃，使得可达性纯粹基于整除性。 

什么时候$p = q$，每一步都位于对角线上，因此归一化后不变量变为坐标奇偶校验相等。 

所有其他情况都依赖于这样一个事实：对称移动集跨越满秩格，在可达点上具有单个奇偶校验约束。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import gcd

    def solve():
        T = int(input())
        out = []
        for _ in range(T):
            p, q, x, y = map(int, input().split())
            if p == 0 and q == 0:
                out.append("Yes" if x == 0 and y == 0 else "No")
                continue
            g = gcd(abs(p), abs(q))
            if x % g != 0 or y % g != 0:
                out.append("No")
                continue
            x2, y2 = x // g, y // g
            p2, q2 = abs(p // g), abs(q // g)
            if p2 == 0:
                out.append("Yes" if x2 % q2 == 0 and y2 % q2 == 0 else "No")
            elif p2 == q2:
                out.append("Yes" if (x2 - y2) % 2 == 0 else "No")
            else:
                out.append("Yes" if (x2 + y2) % 2 == 0 else "No")
        return "\n".join(out)

    return solve()

# provided samples
assert run("1\n2 3 0 2\n") == "YES"

# custom cases
assert run("1\n0 0 1 1\n") == "No"
assert run("1\n1 0 2 3\n") == "No"
assert run("1\n2 2 4 4\n") == "Yes"
assert run("1\n1 2 3 5\n") in ["Yes", "No"]

 | 1 1 0 2 3 | 1 1 0 2 3 没有 | 仅轴限制 |

 ## 边缘情况

 当$p = q = 0$，该算法仅立即返回“是”$(0,0)$。 对于任何其他点，所有不变量都会失败，因为根本不可能发生移动。 

什么时候$p = 0$，代码进入轴对齐分支。 例如，使用输入$(0,3)$，达到$(6,9)$成功是因为两个坐标都是 3 的倍数，而$(5,9)$由于 x 不能被 3 整除，因此立即失败。 

当$p = q$， 例如$(2,2)$，移动仅限于对角线。 像这样的一点$(4,4)$自从$x-y=0$， 尽管$(4,5)$失败是因为它在标准化后破坏了奇偶校验对称性。 

一般情况下，比如$(1,3)$，奇偶校验过滤掉不可达点。 为了$(2,4)$，总和是偶数，所以它通过了，而$(1,2)$失败，因为它位于奇偶子晶格之外。
