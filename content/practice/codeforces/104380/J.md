 ## 解决方案
 ## 问题理解

 我们给出一个正整数`x`，并且我们需要严格向下移动以找到避免特定数字限制的最接近的较小整数：它的十进制数字都不能是`7`。 在所有小于的整数中`x`，我们想要满足这一限制的最大的一个。 

该任务从根本上来说是对低于给定界限的整数进行搜索，但使用过滤器排除任何包含该数字的数字`7`。 输出不仅仅是任何有效数字，而是约束下的最大有效数字，这使得这是一个“最接近的有效前驱”问题。 

约束条件`x ≤ 10^4`意味着搜索空间很小。 即使是线性扫描`x - 1`下降到`1`最多执行一万次检查，每次检查只检查几个数字。 这立即排除了任何复杂的数字 DP 或贪婪重建的需要； 即使是幼稚的迭代也能在时间限制内轻松适应。 

边缘情况出现时`x`本身就在禁区之上。 例如，如果`x = 7000`，然后像这样的数字`6999`,`6998`，等等，必须仔细检查，直到出现有效的。 一个粗心的错误是递减一次并假设结果有效，这对于像这样的输入立即失败`x = 70`， 在哪里`69`是有效的，但是`69`如果只采取一步，并不总能找到。 另一个微妙的情况是当答案跨越多个数字边界时，例如`x = 100`，其中答案是`99`， 不是`99`或涉及数字替换逻辑的东西。 

## 方法

 最直接的策略就是从`x - 1`并重复递减，直到找到一个其十进制表示形式不包含该数字的数字`7`。 通过将每个候选者转换为字符串并扫描其字符来检查它。 这是正确的，因为我们按降序探索所有整数，保证遇到的第一个有效数字是下面的最大有效数字`x`。 

仅当禁止的数字导致无效数字的长链时，才会出现效率低下的问题。 在最坏的情况下，我们可能会跳过这样的数字`70, 71, 72, ..., 79`，或更大的图案，如`7000`向下，但即便如此，检查总数仍受限于`10^4`。 每次检查的成本为 O(log x)，因此总工作量可以忽略不计。 

关键的观察是，除了排除之外，不存在连接数字的结构约束`7`。 这就消除了对数字进行组合推理的任何需要。 贪心减量和测试循环完全捕获解空间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（递减+检查）| O(x·log x) | O(x·log x) | O(1) | O(1) | 已接受 |

 在这个问题中，“最佳”解决方案本质上是通过约束证明的暴力解决方案。 

## 算法演练

 1. 从紧接下面的整数开始`x`。 这是最大可能的候选者，并确保我们以正确的顺序向下搜索。 
2. 对于每个候选号码，检查其是否包含数字`7`通过将其转换为字符串并扫描所有字符。 此步骤直接强制执行约束，无需算术数字提取。 
3. 如果号码不包含`7`，立即归还。 因为我们是向下扫描的，所以第一个有效数字保证是最大的有效答案。 
4. 否则，将候选项减一并重复检查。 

循环继续，直到找到有效的数字。 由于域的边界是`x ≤ 10^4`，保证终止。 

### 为什么它有效

 该算法保持了每个大于当前候选且小于的数字的不变性`x`已经考虑并拒绝了。 因为我们只向下移动并且从不跳过值，所以通过数字过滤器的第一个数字必须是下面的最大有效数字`x`。 不可能错过更好的答案，因为所有较大的候选答案都在序列中较早进行了测试。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def has_seven(n: int) -> bool:
    return '7' in str(n)

def solve():
    x = int(input().strip())
    cur = x - 1
    
    while cur > 0:
        if not has_seven(cur):
            print(cur)
            return
        cur -= 1
    
    print(0)

if __name__ == "__main__":
    solve()
```功能`has_seven`隔离数字检查逻辑，使主循环更清晰且不易出错。 循环开始于`x - 1`因为该问题明确需要一个严格较小的数字。 

一个微妙的点是处理不存在大于零的有效数字的情况。 自从`1 ≤ x ≤ 10^4`， 和`0`不包含`7`，循环总是会安全终止，但即使在退化推理中，守卫也能确保正确性。

 ## 边缘情况

 用于输入`x = 7`，算法集`cur = 6`。 支票`'7' in str(6)`立即为 false，因此输出`6`。 当禁止数字恰好位于边界时，这确认了正确的处理。 

用于输入`x = 70`，算法开始于`69`。 自从`69`不包含`7`，立即返回。 该序列从不评估`70`本身，因为严格的不平等是在初始化时强制执行的。 

用于输入`x = 100`，算法评估`99`直接地。 由于这两个数字都不是`7`，输出是`99`，演示了在没有明确数字推理的情况下正确处理类似进位的数字转换。
