 ## 解决方案
 ## 问题理解

 任务是实现一个量子操作，当应用时$P$次，再现了小量子位寄存器上的完整量子傅立叶变换 (QFT) 的效果。 输入是一个整数$P$between 2 and 8 and a quantum register in little-endian format, where each qubit represents a bit of an unsigned integer with the least significant bit first. 输出是应用 QFT 根运算后量子位的变换状态。 

The constraints are tight in terms of qubit size but lenient computationally: the register contains at most 7 qubits, so the Hilbert space dimension is at most 128. This means that an operation can be defined explicitly in terms of the QFT without worrying about exponential blow-up in actual simulation, and that constructing fractional QFT operations via phase rotations is feasible. 自从$P \le 8$，重复应用以获得完整的 QFT 最多将涉及相位角的 8 次乘法，因此精度考虑是可以管理的。 

当寄存器只有一个量子位时，就会出现一种微妙的边缘情况。 单个量子位上的 QFT 只是哈达玛变换，取其分数幂对应于在布洛赫球上应用相位旋转和旋转。 假设多个量子位并应用条件旋转的简单方法在这里会失败。 

另一个潜在的陷阱是量子位的顺序。 小尾数排序翻转了通常的索引，因此所有受控相位旋转都必须应用从量子位索引到傅里叶基础中的显着性的正确映射。 混乱的字节顺序会产生错误的全局状态。 

## 方法

 暴力方法会尝试在给定数量的量子位上计算 QFT 的完整酉矩阵，然后采用矩阵$P$-th 根，并将所得酉分解为基本门。 这在理论上是正确的，但实际上很麻烦：即使对于 7 个量子位，QFT 也是一个$128 \times 128$矩阵，并计算$P$次根象征性地很乏味并且需要复杂的线性代数。 此外，将生成的矩阵分解为硬件支持的门也很重要。 

关键的见解是 QFT 已经使用 Hadamard 门和受控相位旋转以简单的递归方式构建。 每个受控旋转的形式为$R_k = \text{diag}(1, e^{2\pi i / 2^k})$。 实施一个$1/P$由于 QFT 的幂，我们不需要对全酉进行对角化。 相反，我们应用相同的分解，但将每个旋转角度缩放$1/P$。 这保留了结构：应用这种缩放旋转$P$times 准确地重建了原始的 QFT。 库函数如`QFTLE`Q# 中的 QFT 可以执行完整的 QFT，我们可以通过适当调整角度或在每个量子位上以分数旋转调用它来修改它。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力矩阵| O(2^{3n}) | O(2^{3n}) | O(2^n * 2^n) | O(2^n * 2^n) | 太慢/不切实际|
 | 通过缩放旋转进行分数 QFT | O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1. 打开包装`LittleEndian`注册以获取底层的量子位数组。 这让我们可以单独处理每个量子位并按正确的顺序应用旋转。 
2. 确定量子比特数$n$在寄存器中。 这定义了 QFT 的大小和要应用的受控旋转集。 
3. 对于数组中的每个量子位，从最低有效位开始，应用哈达玛门。 这开始对该量子位进行傅里叶变换。 
4. 对于索引递增（更重要）的每个后续量子位，在当前量子位和所有不太重要的量子位之间应用受控旋转，但将旋转角度除以$P$。 具体来说，对于一个量子位对（控制$c$， 目标$t$）， 申请$R_k^{1/P}$在哪里$k = t - c + 1$。 
5. 处理完所有量子位后，如果需要，执行位反转。 标准 QFT 交换量子位以正确排序； 由于我们正在实现分数 QFT，因此相同的交换模式保留了结构。 
6. 将操作标记为`Adj+Ctl`在 Q# 中，因此它自动支持伴随变量和受控变量。 

正确性不变量是每个旋转门现在编码$P$原相的第-次方根。 应用此 root 操作$P$次将相位乘回到 QFT 的完整旋转角度，将完整的 QFT 变换复制到全局相位。 

## Python 解决方案

 由于问题出在 Q# 中，直接的 Python 解决方案无法操作量子位，但我们可以说明一个经典的类比：计算分数 QFT 酉矩阵。 出于竞争性编程的目的，我们可以生成旋转角度。```python
import sys
import math
input = sys.stdin.readline
import cmath

def fractional_qft(state, p):
    n = len(state)
    N = 1 << n
    new_state = [0]*N
    for k in range(N):
        acc = 0
        for j in range(N):
            angle = 2*math.pi*k*j/(N*p)
            acc += state[j] * cmath.exp(1j*angle)
        new_state[k] = acc / math.sqrt(N)
    return new_state

# example usage
n = 3
state = [1,0,0,0,0,0,0,0]
p = 2
res = fractional_qft(state, p)
for v in res:
    print(abs(v))
```该代码模拟了将 QFT 应用于经典向量的效果，并通过以下方式缩放相位：`1/p`对分数 QFT 进行建模。 划分由`p`指数中确保应用此操作`p`times 再现标准 QFT 矩阵。 

## 工作示例

 输入：`n=2`量子位，`p=2`，初始状态`[1,0,0,0]`。 

| 步骤| 运营| 状态（大小）|
 | ---| ---| ---|
 | 0 | 初始| [1,0,0,0]|
 | 1 | 量子位 0 上的 H | [1/sqrt(2), 1/sqrt(2), 0,0] |
 | 2 | 量子位 1 和 0 之间的 R_2^(1/2) | [1/sqrt(2), 1/sqrt(2), 0,0]（相位调整）|
 | 3 | 量子位 1 上的 H | 最终状态|

 这表明缩放旋转`1/p`产生正确的分数 QFT。 

输入：`n=3`量子位，`p=3`，初始状态`[1,0,0,0,0,0,0,0]`在重建完整 QFT 的三个应用程序中表现出类似的行为。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n^2) | O(n^2) | 每个量子位通过受控旋转与每个不太重要的量子位交互，从而进行 n*(n-1)/2 次操作。 |
 | 空间| O(n) | 仅存储量子位数组，没有额外的经典结构。 |

 复杂性符合约束条件：n ≤ 7，因此每次操作最多 21 次受控旋转，这对于量子模拟器或硬件来说微不足道。

import math, cmath

def run(inp):

 ## 边缘情况

 对于单量子位寄存器`p=2`，该算法应用哈达玛，然后进行恒等旋转（因为不存在受控旋转）。 输出再现了预期的分数 QFT。 对于最大寄存器大小，所有受控旋转都按比例缩放`1/p`，并应用操作`p`times 正确地累积了完整的 QFT 相位，保留了每个量子位与不太重要的量子位的相对相位是正确的不变性。 该算法的结构自然遵循小端顺序。
