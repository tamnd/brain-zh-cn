 ## 解决方案
 ## 问题理解

 给定一个作用于单个量子位的量子门，我们知道它要么绕 Z 轴旋转角度 θ，表示为 Rz(θ)，要么绕 Y 轴旋转相同角度 Ry(θ)。 我们的任务是确定我们拥有哪个门，对于 Rz 返回 0，对于 Ry 返回 1。 输入由浮点数 θ（0.01π ≤ θ ≤ 0.99π）和实现任一门的可调用量子操作组成。 我们可以多次使用门本身、它的伴随门（逆）以及它的受控版本。 

这个问题是在量子计算背景下提出的，但从高层次的角度来看，我们试图区分作用于单个量子位的两个矩阵。 Rz(θ) 使 Z 轴上的计算基础状态 |0⟩ 和 |1⟩ 保持不变（除了相位），而 Ry(θ) 实际上沿 Y-Z 平面移动状态，从而改变概率幅度。 这种行为上的差异是区分它们的关键观察结果。 由于 θ 的边界远离 0 和 π，因此我们不会进行简单的旋转，从而使门在测量中看起来相同。 在应用未知门之后在 Z 基础上进行测量的粗心方法对于 Rz(θ) 来说会失败，因为它不会改变 |0⟩ 概率，从而产生不明确的结果。 

## 方法

 暴力方法将尝试通过准备多个输入状态、多次应用门及其伴随物以及执行全量子态断层扫描来重建未知门的完整矩阵。 这在原则上是正确的，因为它最终会产生足够的信息来区分任何单量子位酉。 然而，它的效率极低，需要重复应用和测量，考虑到绕不同轴的旋转之间的简单区别，这是不必要的。 

最佳方法利用了这样一个事实：Rz(θ) 使 |0⟩ 状态在一个阶段内保持不变，而 Ry(θ) 以 sin²(θ/2) 的概率将 |0⟩ 向 |1⟩ 旋转。 因此，准备|0⟩状态并在计算（Z）基础上进行测量立即揭示了差异：如果测量结果是确定性的|0⟩，则门必须是Rz（θ）； 如果有机会观察|1⟩，则门为Ry(θ)。 这将问题简化为具有最小电路深度的单量子位实验。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（全断层扫描）| 每个量子位 O(1) 但多次重复测量 | O(1) | O(1) | 矫枉过正/不必要|
 | 最佳（应用门后测量 | 0⟩）| O(1) | O(1) | O(1) | O(1) |

 ## 算法演练

 1. 在计算基础状态 |0⟩ 下初始化一个量子位。 这个选择至关重要，因为 |0⟩ 是 Rz(θ) 的本征态，而不是 Ry(θ) 的本征态。 在计算基础上进行测量将立即暴露差异。 
2. 将未知的酉门应用于量子位。 我们不需要应用伴随或受控版本，因为可以直接在 |0⟩ 上观察到区别。 
3. 在计算 (Z) 基础上测量量子位。 将测量结果捕获为经典位。 
4. 如果测量结果为0，则返回0，对应门为Rz(θ)；如果测量结果为1，则返回1，对应Ry(θ)。 由于 θ ∈ (0, π)，Ry(θ) 保证测量 |1⟩ 的非零概率。 

为何有效：该算法有效是因为 |0⟩ 是 Rz(θ) 的本征态，因此对于某个相位 φ，Rz(θ)|0⟩ = e^{iφ}|0⟩，这不会影响计算基础上的测量。 Ry(θ)|0⟩ 在 |1⟩ 上产生非零振幅的叠加，这保证了测量量子位有时会产生 1。因此，单次测量足以区分门。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

# This solution is implemented in Q#, but we can show equivalent Python logic
# using a simulator-like interface.

from qiskit import QuantumCircuit, Aer, execute

def solve(theta: float, unitary: str) -> int:
    qc = QuantumCircuit(1,1)
    # prepare |0> state is default
    if unitary == "Rz":
        qc.rz(theta, 0)
    else:
        qc.ry(theta, 0)
    qc.measure(0,0)
    
    sim = Aer.get_backend('aer_simulator')
    result = execute(qc, sim, shots=1).result()
    measured_bit = int(list(result.get_counts().keys())[0])
    
    return measured_bit
```该代码准备 |0⟩ 状态，应用未知的酉（此处模拟为字符串输入），并在 Z 基础上进行测量。 测量结果直接判别闸门。 微妙之处在于知道计算基础上的测量是足够的，并且 θ 是不平凡的，确保 Ry 旋转 |0⟩ 远离 Z 轴。

 ## 边缘情况

 对于非常接近 0.01π 的 θ，Ry(θ) 会稍微向 |1⟩ 方向旋转 |0⟩。 该算法仍然有效，因为任何非零旋转都会给出测量 |1⟩ 的非零概率。 重复测量可以增加置信度，但在这个问题上单次测量就足够了。 类似地，对于接近 0.99π 的 θ，Ry 几乎一直向 |1⟩ 旋转； 测量仍然成功。 对于任一边界附近的 Rz(θ)，全局相位不会影响测量，因此输出正确地保持为 0。
