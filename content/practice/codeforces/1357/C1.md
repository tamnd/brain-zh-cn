 ## 解决方案

 ## 问题理解

 我们从最初处于全零计算基础状态的 N 量子位系统开始。 目标是将此状态转换为基本状态的有限子集上的均匀量子叠加：长度为 N 的所有位串至少包含一个零。 换句话说，除了全一串之外的每个二进制串在最终状态中都必须以相等的幅度出现。 

对于 N = 2，计算基础由 |00⟩、|01⟩、|10⟩ 和 |11⟩ 组成。 目标状态仅排除 |11⟩ 并向其余三个状态分配相等的幅度，从而产生 (|00⟩ + |01⟩ + |10⟩) / √3。 

就量子比特数而言，这些约束隐含地很小，因为 Codeforce 中的量子电路构造问题通常期望短而明确的门序列，而不是渐近缩放参数。 主要的限制是我们只能访问 Clifford 式的操作：泡利门、Hadamard 及其受控变体，以及测量。 这表明我们应该避免任何需要任意旋转或幅度合成的构造。 

一个微妙的一点是，我们没有被要求“计算”经典函数或测量任何东西。 我们必须在物理上准备一个量子态。 这意味着正确性与幅度有关，而不是经典输出。 

一个天真的尝试可能会尝试生成所有基础状态并使用干扰选择性地取消 |11…1⟩。 然而，通过临时干扰构建精确的幅度分布在这里是脆弱且不必要的。 

对于小 N，边缘情况会立即出现。当 N = 1 时，有效状态仅为 |0⟩，因为唯一禁止的字符串是 |1⟩。 输出必须保持 |0⟩ 不变。 当 N = 2 时，构造必须显式删除 |11⟩，同时保持其他一致。 任何盲目地将 Hadamard 应用于所有量子位的方法都会在所有 2^N 状态上产生统一的叠加，这是不正确的，因为它包括禁止的全 1 状态。 

## 方法

 蛮力心智模型是从所有 2^N 基本状态的均匀叠加开始，这可以通过将哈达玛门应用于每个量子位来轻松获得。 这会在所有位串上产生相等的幅度，包括不需要的 |11…1⟩ 状态。 从那时起，问题就简化为“移除”单个基态，同时保持所有其他基态的振幅相等。 

困难在于量子运算是线性且酉的，因此在不干扰归一化和正交性的情况下直接删除一个基向量是不可能的。 强力校正将尝试专门针对|11…1⟩振幅设计相消干扰，同时保持所有其他不变。 原则上，这需要高度定制的多控制相位操作，有选择地仅翻转全1状态的相位，然后重新分配幅度，但在保持均匀性的同时干净地做到这一点比必要的更加复杂。 

关键的观察结果是目标状态非常结构化：它是除一个状态之外的所有状态的统一叠加。 这意味着它与排除的基础状态正交直到简单的反射。 我们可以使用反射技巧来构造它：从所有状态的均匀叠加开始，然后对 |11…1⟩ 状态应用相位翻转，最后反映关于均匀向量的状态。 这本质上是一个两步振幅重新分布，可以在所有非排除状态之间保持对称性。

这个想法将问题简化为标准量子基元：用 Hadamards 准备均匀叠加并应用针对 |11…1⟩ 的多控制 Z 门。 受控 Z 仅翻转该单一基态的相位。 在此相位反转之后，使用哈达玛和反射进行的第二次全局变换将相位差转换为振幅排除，从而有效地从均匀分布中删除该状态。 

这是一种已知的模式：标记单个状态并通过干扰将其转换为幅度抑制。

 ## 算法演练

 我们使用受控相位标记和全局干扰构建所需的状态。 

1. 首先将所有量子位初始化为 |0⟩。 这就是问题所需的计算基础起点。 
2. 将 Hadamard 门应用于所有 N 个量子位，在所有 2^N 基本状态上创建均匀叠加。 在此阶段，每个位串具有相同的幅度 1/√(2^N)。 
3. 应用针对全一基本状态的多控制 Z 门。 该门仅翻转 |11…1⟩ 状态的相位。 其工作原理是受控 Z 门实现条件相位反转而不影响其他基态的幅度。 
4. 再次将 Hadamard 门应用于所有量子位。 此步骤执行全局基础变换，将相位翻转转换为跨所有基础状态的幅度重新分布。 
5. 再次应用相同的多控制 Z 门，以最终完成到与全 1 状态正交的子空间的投影。 这确保了排除状态的幅度恰好为零，而所有其他状态保持相等。 
6. 如果电路约定需要，可选择应用最终的归一化保持 Hadamard 层，尽管在此结构中，对称性已经保证了有效状态的一致性。 

关键思想是，受控相位翻转充当不需要状态的选择性“标记”，周围的哈达玛层将该信息均匀地传播到希尔伯特空间，有效地消除了该状态的幅度。 

### 为什么它有效

 不变的是，每次变换后，所有非目标基态在排列下保持对称，只有全一状态相差一个相位。 由于哈达玛变换将相位差均匀地映射到所有基向量上的幅度差，因此干扰消除了标记状态，同时在所有其他状态中保持相等的幅度。 结构的对称性保证了有效的基态不会与另一个基态区分开，因此它们的振幅在整个过程中保持相同。

 ## 边缘情况

 对于 N = 1，系统从 |0⟩ 启动，唯一的禁止状态是 |1⟩。 该结构仍然适用，但受控 Z 门退化为单量子位 Z，这引入了相位翻转，该相位翻转立即被第二个干扰层撤销。 最终状态仍为 |0⟩，概率为 1，符合要求。 

对于较大的 N，请具体考虑状态 |111…1⟩。 在第一个 Hadamard 层之后，它具有非零幅度。 受控-Z 仅翻转其符号。 由于所有其他状态保持不变，对称性确保在第二次哈达玛变换之后，干涉图样均匀地分布此相位差。 最终的受控 Z 步骤完全消除了剩余贡献，在所有非全 1 状态上留下完美平衡的叠加。
