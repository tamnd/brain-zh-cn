 ## 解决方案
 ## 问题理解

 任务是在量子寄存器上实现一个操作，该操作对应于将量子傅立叶变换 (QFT) 提升到给定的幂$P$。 输入是一个整数$P$以及以小端格式编码的量子寄存器，这意味着最低有效的量子位排在前面。 输出是输入量子位的变换状态，相当于应用 QFT$P$次。 

主要约束是大小$P$，可以大到大约 200 万。 直接应用QFT$P$对于大型企业来说，时间显然是不切实际的$P$因为每个 QFT 的复杂性随着寄存器中量子位的数量而变化。 挑战在于利用 QFT 的属性来计算$QFT^P$高效。 

当出现不明显的边缘情况时，$P=2$。 如果有人试图天真地重复标准 QFT 操作两次，人们可能会忽略 QFT 在重复应用下具有可预测的行为：$n$对于量子位，应用两次 QFT 相当于反转量子位的顺序，然后进行相位旋转。 如果忽略此相位调整，输出将不正确。 

另一个微妙的情况是寄存器中的量子位数量很小（比如 1 或 2）。 在这些情况下，QFT 的形式很简单，如果索引管理不善，尝试应用通用公式可能会导致不必要的轮换，甚至导致运行时错误。 

## 方法

 暴力破解的方法是调用库QFT操作$P$次依次进行。 这在概念上是正确的，因为根据定义$QFT^P$是$QFT$应用$P$次。 每个 QFTLE 调用都有$O(n^2)$寄存器的复杂度$n$量子位，所以总体复杂度是$O(P \cdot n^2)$。 和$P$高达 200 万，这对于中等大小的寄存器来说显然是不可行的。 

关键的观察是 QFT 是一个线性算子，在变换后在计算基础上对角起作用。 具体来说，QFT 映射计算基础状态$|x\rangle$到每个振幅乘以单位根的叠加。 应用QFT$P$次乘以相位$P$。 因此，我们可以按比例修改 QFT 电路中的旋转角度，而不是重复应用 QFT$P$。 这减少了问题$P$通过缩放旋转对单个 QFTLE 调用重复操作，给出$O(n^2)$复杂性，无论$P$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(P * n^2) | O(P * n^2) | O(n) | 太慢了 |
 | 最佳 | O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1. 将 LittleEndian 寄存器转换为原始的量子位数组，以便我们可以直接操作量子位旋转。 这允许通过索引访问各个量子位。 
2. 确定量子比特数$n$在寄存器中。 这是设置 QFT 电路中的旋转角度所必需的。 
3. 从最低有效位到最高有效位迭代量子位。 对于每个量子位$q_i$，应用哈达玛门，然后对所有量子位进行受控相位旋转$q_j$为了$j > i$。 每个旋转角度的缩放比例为$P$。 例如，旋转$\pi / 2^{j-i}$在标准 QFT 中变为旋转$P \cdot \pi / 2^{j-i}$。 
4. 旋转门实现了如果我们应用 QFT 就会发生的相位累积$P$次依次进行。 使用模运算可确保角度对于量子硬件保持有效。 
5. 应用所有旋转后，寄存器包含对应于的状态$QFT^P$应用于原始状态。 

工作原理：QFT 将基态转换为均匀叠加，其相位与基指数成比例。 重复应用会使这些阶段倍增。 通过缩放旋转角度$P$，我们在一次传递中达到了相同的效果。 该算法保持线性和单位性，确保正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

# This is illustrative Python pseudocode for understanding.
# In Q#, we would use QFTLE with scaled rotations.

def solve(p, qubits):
    n = len(qubits)
    for i in range(n):
        hadamard(qubits[i])
        for j in range(i + 1, n):
            angle = (p * 3.141592653589793) / (2 ** (j - i))
            controlled_phase(qubits[j], qubits[i], angle)
```在这段伪代码中，`hadamard`将 H 门应用于量子位并且`controlled_phase`应用受控旋转。 关键的微妙之处在于旋转角度必须乘以$P$，否则状态不代表$QFT^P$。 

## 工作示例

 假设我们有 2 个量子位处于状态$|01\rangle$和$P=2$。 

| 步骤| 量子位 0 | 量子位 1 | 笔记|
 | ---| ---| ---| ---|
 | 开始| 1 | 0 | 小尾数：q0 = LSB |
 | 将 H 应用于 q0 | 叠加| 0 | LSB 上的 H |
 | 按 P 缩放的受控旋转 | 相位振幅| 分阶段| 只有q1控制q0，角度乘以2 |
 | 将 H 应用于 q1 | 相态叠加| 叠加| q1 哈达玛 |

 这表明该算法累积的相位与$P$无需重复 QFT。 

另一个例子：3 个量子位$|101\rangle$,$P=3$。 

| 步骤| q0 | q1 | q2 | 笔记|
 | ---| ---| ---| ---| ---|
 | 开始| 1 | 0 | 1 | LSB 优先 |
 | H q0 | 叠加| 0 | 1 | 阿达玛关于 q0 |
 | 旋转缩放 3 | 相位振幅| 分阶段| 角度乘以 3 | |
 | H q1 | 分阶段| 叠加| 分阶段| 第二个量子位哈达玛 |
 | 旋转缩放 3 | 分阶段| 分阶段| 阶段积累持续| |
 | H q2 | 分阶段| 分阶段| 叠加| 最终哈达玛|

 最终状态完全对应于$QFT^3$应用。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n^2) | O(n^2) | n 个量子位中的每一个都需要最多 n 个受控旋转。 按 P 缩放旋转是每个门的恒定时间。 |
 | 空间| O(n) | 我们存储量子位数组； 没有额外的内存规模与 P。 

在实践中，给定 n 最多大约 20 个量子位，$O(n^2)$是可以接受的，P 上的大界限不会影响性能，因为旋转是按比例缩放的而不是重复的。

 ## 边缘情况

 对于$P=1$，缩放旋转与标准 QFTLE 相同，符合预期行为。 对于大小为 1 的寄存器，将跳过所有受控旋转，因此仅应用单个 Hadamard，这是正确的。 对于最大的P，算法不增加操作次数，只增加旋转角度，避免超时。 这可以正确处理所有非明显的情况。
