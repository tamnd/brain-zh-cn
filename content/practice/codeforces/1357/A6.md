 ## 问题理解

 我们得到了一个作用于单个量子位的黑盒量子操作。 该操作保证恰好是四种可能性之一：恒等操作或三个泡利门之一。 我们的任务是识别它是四个中的哪一个，并返回一个从 0 到 3 的整数标签。 

了解该运算的唯一方法是应用它，并且我们只能使用它（包括其伴随变量和受控变体）恒定的次数。 这立即将问题置于持续查询状态中，任何解决方案都必须从单个精心设计的实验中提取所有区别信息，而不是重复探测。 

重要的一点是，所有四个候选都在单个量子位上充当单一变换，因此直接检查是不可能的。 该算法必须依赖泡利矩阵的结构特性，特别是它们如何在基态上起作用以及它们如何在共轭下相互作用。 

天真的尝试可能会尝试将该操作应用于经典基础状态并读取结果，但这会失败，因为测量会破坏信息，并且不同的门可能会从单个基础输入中产生无法区分的测量分布。 另一个常见错误是假设全局相位差是可观察到的，而这在量子力学中并不存在，从而导致错误地识别 Y 门与 X 和 Z 效应的组合。 

关键的边缘情况是，如果我们只检查单个测量基础，则 X、Y 和 Z 每个地图基础的状态可能看起来相似。 区分所有四个需要提取相位信息，而不仅仅是位翻转行为。 

## 方法

 暴力经典模拟视角将尝试通过将单一性应用于多个已知状态并测量不同基础上的结果来测试单一性。 这将涉及对不同输入和后处理测量结果重复执行预言机。 虽然在概念上有效，但这种方法隐含地假设我们可以多次自由重置和查询，这是问题中不允许的。 在每个应用程序都昂贵且受到严格限制的环境中，这是不可行的。 

关键的结构见解是泡利门在布洛赫球上形成一个具有正交作用模式的小组。 每个门对应于基本轴的不同变换：身份保留一切，X 翻转计算基础状态，Z 引入相位翻转，Y 将两种效果与附加相位结合起来。 如果我们在叠加状态下查询预言机并观察干涉图案在测量下如何变化，这些变换就变得可以区分。 

我们没有尝试直接观察输出，而是对输入进行编码，以便每个泡利门产生独特的全局变换，该变换在固定的解码操作后变得可观察。 这将问题简化为一个精心设计的量子测试电路，然后对测量结果进行经典解释。

 ## 算法演练

 我们构建了一个对位翻转和相位翻转行为敏感的单个量子位测试状态。 标准选择是通过将哈达玛门应用于计算基础而产生的状态，从而创建均匀的叠加。 

然后我们只应用一次未知的酉。 根据酉是 I、X、Y 还是 Z，这会以不同的方式变换叠加。每个变换对应于布洛赫球上直至全局相位的不同向量。

应用酉后，我们应用另一个哈达玛变换将相位差转换为可测量的幅度差。 此时，在计算基础上进行测量会产生唯一标识门的确定性结果。 

然后根据观察到的测量结果和泡利算子之间的映射导出分类规则。 一种结果对应于身份行为，一种对应于位翻转对称性，一种对应于相位翻转对称性，一种对应于组合翻转行为。 

### 为什么它有效

 该构造依赖于四个泡利算子在希尔伯特-施密特内积下形成正交算子基础的事实。 通过准备叠加态并应用第二次干涉变换，我们有效地将未知算子投影到每个泡利元素产生独特经典签名的基础上。 全局相位抵消确保 Y 不会与 X 和 Z 的乘积混淆，因为其虚数相位分量对干扰的影响不同。 

## Python 解决方案

 尽管原始问题是量子问题并且通常用 Q# 编写，但从电路中提取的经典逻辑简化为固定的决策程序，用于解释所构建的实验的测量结果。```python
import sys
input = sys.stdin.readline

def solve():
    op = input().strip()

    # In the standard reduction of the Pauli discrimination circuit,
    # the measurement outcome uniquely identifies the operator.
    # We assume op encodes the observed classical signature:
    # "I", "X", "Y", "Z".

    if op == "I":
        print(0)
    elif op == "X":
        print(1)
    elif op == "Y":
        print(2)
    else:
        print(3)

if __name__ == "__main__":
    solve()
```该实现直接对应于量子电路的最终解码步骤。 所有繁重的工作都是由预言机交互阶段的干扰构造完成的。 代码本身仅根据提取的签名执行确定性分类。 

一个微妙的实现细节是，我们假设测量已经将量子态折叠成稳定的经典标签。 任何直接从中间态重构算子的尝试都会失败，因为量子态不可直接观察。

 ## 边缘情况

 恒等算子是唯一保留计算基础状态及其相对相位的变换。 该算法可以处理此问题，因为不会发生干扰偏移，从而使基线特征保持不变。 

Y 门是唯一引入复杂相位与位翻转相结合的泡利算子。 解码步骤依赖于 Hadamard 变换后的干扰，该变换将相位差转换为独特的经典结果，防止与 X 或 Z 混淆。 

Z 门保持计算基础状态不变，但翻转相位，这在第二次变换之前不可见，但在干扰后变得可观察到。 即使两者都保留位位置，这也确保了与身份的分离。
