 ## 问题理解

 任务是实现一个可逆量子预言机，标记表示可被 3 整除的数字的位串。输入是最多 8 个量子位的寄存器，它以小端顺序编码二进制整数，再加上一个充当目标位的额外量子位。 当且仅当编码整数可被 3 整除时，该操作必须翻转该目标位。 

关键要求是转换必须是单一的，这意味着它不能“计算并覆盖”经典意义上的信息。 相反，对于每个基本状态，系统必须一致地演化，以便保留输入状态，并且仅根据输入的布尔谓词切换输出量子位。 

约束 N ≤ 8 至关重要。 这意味着最多有 2⁸ = 256 个可能的输入基本状态。 这种较小的域大小使得可以通过枚举所有可能的输入来显式构造预言机，而不是导出可被 3 整除的紧凑算术电路。 

这里的一个天真的错误是尝试在没有辅助结构的情况下直接在量子位上使用算术逻辑来解释二进制数并计算整除性。 这很快就会变得不必要的复杂，并且有违反仅允许 X 和受控 X 门的限制的风险。 

另一个微妙的边缘情况是忘记预言机必须正确地处理叠加。 如果我们错误地“分支”测量或假设经典执行，我们就会破坏线性。 例如，在 |3⟩ 和 |4⟩ 的叠加上，输出量子位必须仅在 |3⟩ 分量上翻转，而不是全局翻转。 

## 方法

 一种暴力经典方法是，如果对于每个可能的 x，x mod 3 = 0，则计算函数 f(x) = 1，然后将其编码到可逆电路中。 由于输入空间的大小最多为256，因此我们可以直接构造真值表。 

为了将其转换为量子安全操作，我们需要将该函数表示为输出量子位上的一系列受控非操作。 每个操作都针对一个输入分配。 挑战在于，量子门本质上并不是对位串进行“相等性检查”，但我们可以通过使用多控制 X 门来模拟相等性，其中控制以匹配固定模式的每个输入位为条件。 

关键思想是，对于每个可被 3 整除的有效输入 x，我们临时变换控制基础，以便所有量子位都充当正控制。 如果模式中的某个位为 0，我们会在应用受控操作之前和之后翻转该量子位。 这会将“0 上的控制”转换为 1 上的标准控制。 

这减少了从设计算术电路到枚举一小组有限的基本状态和应用条件翻转的问题。

 ## 算法演练

 我们通过迭代所有可能的位串并针对那些能被 3 整除的位串精确地激活输出翻转来构建预言机。

1. 枚举从 0 到 2^N − 1 的所有整数 x。每个 x 对应于小端形式的输入量子位的基本状态。 这为我们提供了所有可能的量子基础输入的完整描述。 
2. 对于每个 x，检查 x mod 3 是否等于 0。如果它不可整除，我们对此状态不执行任何操作并继续。 这确保我们只在有效状态上构建预言机支持。 
3.对于每个满足整除性的x，我们构建一个针对输出量子位的多控制X门。 这些控件强制输入寄存器与 x 的二进制表示形式完全匹配。 
4. 为了强制与固定位串模式相等，我们单独处理每个量子位。 如果 x 的第 i 位为 1，我们对该量子位使用正控制。 如果它是 0，我们用 X 门暂时翻转该量子位，应用受控操作，然后将其翻转回来。 这有效地将“零控制”转变为标准控制。 
5. 在输出上应用受控 X 后，我们恢复任何翻转的输入量子位，以便整体操作保持可逆并且不会干扰不相关的基础状态。 

### 为什么它有效

 每个基本状态 |x⟩ 恰好激活与其自身相对应的一系列控制。 如果 x 能被 3 整除，则恰好一个受控 X 操作会触发并翻转输出量子位。 如果它不能被 3 整除，则没有构造的门与该配置匹配，因此输出保持不变。 由于该结构在基态上是线性的，因此叠加态可以通过线性扩展正确演化。

import sys
input = sys.stdin.readline

def solve(inputs, output):
    n = len(inputs)

    def apply_controlled_x(bits, target):
        # pseudo-operation: flips target if all bits are 1
        pass

    for mask in range(1 << n):
        if mask % 3 != 0:
            continue

        flipped = []

        for i in range(n):
            # if bit i of mask is 0, we flip qubit i to turn it into control-on-1
            if ((mask >> i) & 1) == 0:
                inputs[i].X()
                flipped.append(i)

        controls = list(inputs)
        apply_controlled_x(controls, output)

        for i in flipped:
            inputs[i].X()
```Q# 中的实际实现将占位符控制的操作替换为通过受控变体提供的多控制 X 门。 基本结构保持不变：准备控件、应用条件翻转、恢复状态。 

微妙之处在于输入量子位永远不会被永久修改。 每个临时 X 在使用后都会立即撤销，从而保持统一性并确保预言机保持可逆性。

 ## 边缘情况

 一种重要的边缘情况是全零状态。 它对应于整数 0，可被 3 整除，因此当输入为 |00…0⟩ 时，无论叠加上下文如何，输出量子位都必须始终翻转。 该构造可以正确处理此问题，因为 mask = 0 包含在可整除集合中。 

另一个边缘情况是多个输入量子位为 0 时。如果我们错误地忘记反转零位的控制，则没有门将匹配此类状态，从而破坏许多有效 x 值的正确性。 临时 X 技巧可确保对称处理 0 和 1 约束，从而保持精确的模式匹配。 

最后的边缘情况是叠加状态，其中只有一些分支满足整除性。 受控X的线性确保只有那些分支触发输出翻转，并且不相关的基态之间不会发生干扰。
