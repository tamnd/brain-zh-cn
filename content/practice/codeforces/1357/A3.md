 ## 问题理解

 我们得到了一个黑盒单量子位量子运算，它保证恰好是两种可能性之一：Hadamard 门或 Pauli-X 门。 我们的任务不是模拟它，而是通过与黑匣子的少量交互来识别它是哪一个。 

与该操作交互的唯一方法是将其应用于我们自己准备的量子位。 我们也可以使用它的伴随版本和受控版本，但是未知操作的使用总数被严格限制为最多两次。 与它交互后，如果隐藏操作是 Hadamard，我们必须确定性地输出 0，如果隐藏操作是 X，则必须确定性地输出 1。 

关键的困难在于，两个门都是单个量子位上的有效酉变换，并且都是对合，这意味着应用它们两次即可给出恒等式。 这立即排除了幼稚的“应用两次并比较”策略。 对两个查询的限制也意味着我们无法进行完整的断层扫描。 

测量随机性产生了一个微妙的问题。 例如，即使门是固定的，将未知门应用于基本状态并进行测量也可以产生概率结果。 任何依赖于单个概率签名的策略都是无效的，因为所需的答案对于每个有效输入门都必须是确定性的，而不仅仅是具有高概率。 

第二个微妙之处是，两个大门都是克利福德运营的，具有相似的结构特性。 它们都将泡利算子映射到共轭下的泡利算子，因此简单的换向测试并不能立即区分，除非我们仔细选择测试的状态或电路结构。 

一种简单的方法会尝试根据将门应用于基础状态并在不同基础上进行测量来进行区分。 然而，所有此类直接测量策略都会失败，因为两个门都可以产生重叠的结果分布，或者随机性阻碍了单次测试的确定性。 

## 方法

 蛮力的观点是尝试部分量子过程断层扫描：准备一组基本状态，多次应用未知门，在不同的基础上进行测量，并重建其矩阵。 原则上这是可行的，因为单量子位酉是由它在两个线性独立状态上的作用决定的。 然而，完整的断层扫描需要对相同输入进行多次独立评估来解决概率结果，远远超出了两个查询的限制。 

关键的观察是我们不需要重建完整的酉。 我们只需要区分两个固定的候选者即可。 这使我们能够设计一个精心选择的电路，其全局状态演化在两种情况下以确定性结构方式不同。 

最有用的技巧是使用未知酉的受控应用来创建两个量子位之间的相关模式。 我们不是考虑单个量子位上的测量概率，而是将结构差异编码为纠缠与可分离。 

我们准备一个简单的两个量子位状态，其中只有一个分支受到未知操作的影响。 然后我们分析每个候选门如何变换计算基向量。 X 门翻转基本状态，而 H 将基本状态映射为叠加。 当我们对控制量子位进行操作，然后检查所得到的联合状态是否因式分解时，这种差异就变得显而易见。 

这种方法将问题从“区分两个酉矩阵”转换为“在一次受控应用后检测纠缠结构”，这可以通过一次额外的受控或伴随调用来确定性地完成。

 ## 算法演练

 我们设计了两个量子位测试状态，并以受控方式应用一次未知的酉。 

1. 准备以下形式的两个量子位状态$|0\rangle|0\rangle + |1\rangle|1\rangle$（非标准化贝尔对的想法）。 这在控制和目标之间创建了相关性，使得仅在目标上应用未知单一会产生结构上可观察的效果。 
2. 应用未知酉的受控版本，使用第一个量子位作为控制，第二个量子位作为目标。 执行此操作后，状态变为$|0\rangle|0\rangle + |1\rangle U|1\rangle$。 
3. 扩大两位候选人的行为。 如果$U = X$， 然后$U|1\rangle = |0\rangle$，所以结果状态变为$|0\rangle|0\rangle + |1\rangle|0\rangle$，它分解为$(|0\rangle + |1\rangle)|0\rangle$，可分离状态。 
4. 如果$U = H$， 然后$U|1\rangle = (|0\rangle - |1\rangle)/\sqrt{2}$，因此状态在两个量子位之间纠缠在一起，并且不能写为乘积状态。 
5. 通过应用伴随或重用酉，使用第二个允许的查询来反转或探测该结构，从而允许我们测试第二个量子位是否处于独立于第一个量子位的固定计算基础状态。 可分离的状态确定性地崩溃为固定的模式，而纠缠的情况会产生可区分的偏差。 
6. 在计算基础上进行测量，并将结果映射到最终答案：可分离行为对应于 X，纠缠行为对应于 H。 

### 为什么它有效

 该算法利用了以下事实：X 在计算基础内映射基础状态，而 H 将基础状态混合成相等的叠加。 当嵌入到受控操作中时，X 保留了两个量子位系统中的经典相关结构，而 H 则引入了阻止因式分解的量子叠加。 这种差异在考虑纠缠的单一后处理下是不变的，因此任何有效的测量方案都可以确定性地区分这两种情况。

    q0 = allocate_qubit()
    q1 = allocate_qubit()

    # prepare entangled-like correlation state
    H(q0)
    CNOT(q0, q1)

    # apply controlled unknown unitary
    controlled_unitary = Controlled(unitary)
    controlled_unitary(q0, q1)

    # second use: apply adjoint-controlled version to probe reversibility structure
    controlled_unitary_adj = Adjoint(controlled_unitary)
    controlled_unitary_adj(q0, q1)

    result = M(q0)

    # interpret deterministically
    return 1 if result == 1 else 0

最微妙的实现细节是确保正确应用伴随控制操作，因为需要反转控制结构。 另一个微妙之处是，仅在两次允许使用单一查询之后才执行测量，尊重双查询约束。

 ## 边缘情况

 一种微妙的情况是，推理错误地假设单次应用后的测量就足够了。 例如，将未知门应用于$|0\rangle$给出 H 的概率结果，但 X 的结果是确定性的，这不是有效的决策规则。 该算法通过不依赖单次测量来避免这种情况。 

另一个问题是误解伴随的角色。 如果不对称地使用伴随控制操作，电路可能无法抵消 X，从而产生错误的纠缠信号。 该构造确保 X 在第二次查询下始终完全反转，而 H 留下无法删除的残留结构。 

第三种边缘情况是全局相位模糊度。 H和X都可能在中间态引入相位，但纠缠结构在全局相位下是不变的，因此区分性质不受影响。
