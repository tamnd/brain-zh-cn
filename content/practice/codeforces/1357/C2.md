 ## 问题理解

 这个问题要求我们准备一个量子态$N$量子位，其中只有具有特定奇偶校验的基态才包含在相等叠加中。 这里，奇偶校验 0 意味着我们包括所有具有偶数个 1 的位串，奇偶校验 1 意味着所有具有奇数个 1 的位串。 我们首先将所有量子位初始化为$|0\rangle$并仅限于使用泡利门（X、Y、Z）、哈达玛门以及这些门的受控版本。 允许测量，但目标是确定性地准备状态。 

输入很简单$N$、量子位的数量以及所需的奇偶校验。 输出是量子位的最终状态，它不能表示为数字，而是必须在模拟器或设备中进行物理准备。 这个问题不涉及经典输出 - 正确性是由量子态定义的，量子态恰好是基态的正确子集上的均匀叠加。 

约束允许大约$N = 30$用于实际模拟的量子位，这意味着任何强力方法都会迭代$2^N$国家是不可行的。 关键是用门操纵量子位来直接准备叠加，而不需要枚举状态的指数数。 边缘情况包括$N = 1$，其中奇偶校验直接决定我们是否翻转量子位，并且像这样的小值$N = 2$，显示奇偶校验条件如何划分基础状态。 

## 方法

 天真的方法是尝试通过将哈达玛门应用于每个量子位来构建叠加，以在所有量子位上创建统一的叠加$2^N$状态，然后以某种方式删除具有错误奇偶性的状态。 This is theoretically possible by using multi-controlled Z gates to invert amplitudes conditionally, but it becomes cumbersome and requires a depth of controlled operations proportional to$N$。 这种方法在概念上是正确的，但实际上效率低下。 

关键的见解是观察到通过有条件地翻转单个量子位，可以将所有状态的统一叠加调整为具有明确的奇偶性。 如果我们应用阿达玛门$N-1$量子位，我们生成所有的叠加$2^{N-1}$这些量子位的位串。 整体的平价$N$-然后可以通过根据第一个量子位的奇偶校验翻转最后一个量子位来设置量子位系统$N-1$量子位。 这使用受控 X 门（或 CNOT）$N-1$控制并保证最终奇偶校验正确。 它将问题简化为门应用的线性序列和单个多控制操作，避免了所有的枚举$2^N$州。

 ## 算法演练

 1. 将 Hadamard 门应用于第一个$N-1$量子位。 这在所有长度的位串上创建了统一的叠加$N-1$。 这是正确的，因为阿达玛$|0\rangle$产生$(|0\rangle + |1\rangle)/\sqrt{2}$，以及张量积$N-1$量子比特平等地给出所有组合。 
2. 应用针对最后一个量子位的多控制 X 门，控制第一个量子位$N-1$量子位。 控制条件是最后一个量子位仅在第一个量子位翻转时翻转$N-1$量子位具有奇偶性，要求最终量子位达到所需的整体奇偶性。 如果奇偶校验参数为 0，则当第一个量子位翻转时，翻转最后一个量子位。$N-1$量子位具有奇校验； 如果奇偶校验为1，则在第一个时翻转它$N-1$量子位具有偶校验性。 这保证了每个结果基础状态都具有正确的奇偶性。 
3. 最终的量子态现在是具有所请求奇偶校验的所有基本态的均匀叠加。 除非奇偶校验需要验证，否则不需要进一步的门或测量。 

为什么它有效：该算法有效是因为任何$N$- 位串可以唯一分解为第一个$N-1$位和最后一位。 通过准备所有$2^{N-1}$第一个的组合$N-1$量子位，然后确定性地设置最后一个量子位以满足奇偶校验要求，我们保证准确地包括所有期望的状态并且不存在不期望的状态。 Hadamard 门创建均匀的振幅，多控制 X 门有条件地翻转最终量子位而不影响振幅。 

## Python 解决方案

 Codeforces 的量子解决方案并未直接在 Python 中实现，但我们可以编写 Q# 式的模拟来理解：```python
from qiskit import QuantumCircuit

def prepare_parity_superposition(N, parity):
    qc = QuantumCircuit(N)
    # Apply Hadamard to first N-1 qubits
    for i in range(N-1):
        qc.h(i)
    # Compute parity of first N-1 qubits and flip last qubit conditionally
    controls = list(range(N-1))
    if parity == 0:
        qc.mcx(controls, N-1)  # flip if first N-1 qubits have odd parity
    else:
        # For odd parity, flip last qubit if first N-1 qubits have even parity
        qc.x(N-1)
        qc.mcx(controls, N-1)
        qc.x(N-1)
    return qc

# Example usage for N=2, parity=0
qc = prepare_parity_superposition(2, 0)
print(qc.draw())
```此代码反映了该算法。 该循环将 Hadamards 应用于第一个$N-1$量子位。 这`mcx`Gate 表示多控制的 X 门。 对于奇偶校验 1，最终的量子位在`mcx`达到相反的控制条件。
