 ## 解决方案
 ## 问题理解

 我们有一个人沿着边长为的正方形的边界行走`n`。 他从左下角开始，立即在那里画了一个十字。 此后，他继续沿圆周顺时针移动，每隔一段时间再放置一个十字。`n + 1`米。 

步行继续，直到他再次到达起始角并在那里放置另一个十字架。 任务是计算总共画了多少个十字，包括起始角的两个十字。 

对于每个测试用例，输入给出一个整数`n`，并且我们必须输出在起始位置重复该过程之前绘制的十字的数量。 

制约因素很大。 边长可以大到`10^9`，并且最多可以有`10^4`测试用例。 任何一步步绕着周界行走的模拟都是危险的，除非证明步数很小。 在最坏的情况下，答案本身可以与`n`，因此模拟可能需要数十亿次迭代，这在时间限制内是不可能的。 该解决方案必须在每个测试用例中以恒定的时间运行。 

棘手的部分是准确了解该过程何时停止。 约翰第一次重新访问之前标记的点时并没有停下来。 直到左下角收到第二个传球时他才停下来。 

一个常见的错误是忘记最初的交叉算作答案。 例如：

 输入：```
1
1
```正方形的周长是`4`，步长为`2`。 访问的职位有：`0 -> 2 -> 0`正确答案是：```
3
```因为起始角球在开始和结束时都被计算在内。 

另一个容易犯的错误是假设答案直接取决于周长。 考虑：

 输入：```
1
4
```周长是`16`，步长为`5`。 答案不是`16 / 5`。 步行访问模数位置`16`:`0 -> 5 -> 10 -> 15 -> 4 -> ... -> 0`循环长度由模运算确定，特别是周长和步长之间的 gcd。 

## 方法

 最直接的方法就是模拟行走。 我们可以将当前位置表示为距起始角沿周边的距离。 最初的位置是`0`。 每一个动作都会增加`n + 1`，我们取模`4n`因为正方形的周长有长度`4n`。 

我们继续直到位置变为`0`再次。 访问位置的数量恰好是交叉的数量。 

这种蛮力的想法是正确的，因为该过程实际上被定义为对周长取模的重复加法。 问题是性能。 认为`n = 10^9`。 步骤的数量也可以是以下的数量级`10^9`，这远远超出了 2 秒的时间。 

关键的观察是这是一个模循环问题。 

我们反复申请：$$x \leftarrow (x + (n+1)) \bmod 4n$$开始于`0`，序列返回到`0`后：$$\frac{4n}{\gcd(4n, n+1)}$$步骤。 

这是模加法的标准属性。 如果我们反复添加`k`模数`m`，周期长度等于：$$\frac{m}{\gcd(m, k)}$$这里：$$m = 4n,\quad k = n+1$$现在我们简化gcd：$$\gcd(4n, n+1)$$自从：$$4n = 4(n+1) - 4$$我们得到：$$\gcd(4n, n+1) = \gcd(4, n+1)$$所以答案就变成了：$$\frac{4n}{\gcd(4, n+1)}$$这已经正确地计算了最终返回起点的次数，因为循环包括初始位置和第一次重复返回。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O（答案）| O(1) | O(1) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取整数`t`，测试用例的数量。 
2. 对于每个测试用例，请阅读`n`。 
3. 计算周长：$$m = 4n$$4. 计算行走步数：$$k = n + 1$$5. 计算：$$g = \gcd(m, k)$$这告诉我们重复添加时会跳过多少个不同的残基类别`k`模数`m`。 
6.返回位置所需的移动次数`0`是：$$\frac{m}{g}$$7. 打印结果。 

### 为什么它有效

 每个十字对应于通过重复添加到达的位置`(n + 1)`模数`4n`。 

访问位置的顺序为：$$0,\ k,\ 2k,\ 3k,\ \dots \pmod{4n}$$当出现以下情况时，步行将返回起点：$$tk \equiv 0 \pmod{4n}$$最小正值`t`满足这个方程的是：$$t = \frac{4n}{\gcd(4n, k)}$$该值恰好是起始角球获得第二次传中之前绘制的传中次数。 

## Python 解决方案```python
import sys
from math import gcd

input = sys.stdin.readline

def solve():
    t = int(input())
    nums = list(map(int, input().split()))

    ans = []

    for n in nums:
        perimeter = 4 * n
        step = n + 1

        ans.append(str(perimeter // gcd(perimeter, step)))

    print("\n".join(ans))

solve()
```实现直接遵循数学推导。 

周长是`4 * n`，因为正方形有四个相等的边。 运动大小始终为`n + 1`。 

关键的一行是：```
perimeter // gcd(perimeter, step)
```这计算重复模加法的循环长度。 

使用 Python 整数可以自动避免溢出，这很重要，因为`4 * 10^9`超出 32 位有符号整数范围。 

另一个微妙之处是正确计算十字。 公式中已经包含了最终返回起始角点的情况，所以不需要手动加减一。 许多不正确的实现都会产生相差一的错误。

# helper: run solution on input string, return output string
import sys
import io
from math import gcd

def solve():
    input = sys.stdin.readline

    t = int(input())
    nums = list(map(int, input().split()))

    ans = []

    for n in nums:
        perimeter = 4 * n
        step = n + 1
        ans.append(str(perimeter // gcd(perimeter, step)))

    print("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output

 ## 边缘情况

 考虑尽可能最小的正方形：

 输入：```
1
1
```我们有：$$m = 4,\quad k = 2$$和：$$\gcd(4, 2) = 2$$所以答案是：$$\frac{4}{2} = 2$$访问过的职位有：$$0 \to 2 \to 0$$粗心的实现可能会错误地打印`3`通过与循环长度分开计算起始角点的两次出现。 模循环公式已经考虑了返回步骤。 

现在考虑：

 输入：```
1
7
```我们得到：$$m = 28,\quad k = 8$$和：$$\gcd(28, 8) = 4$$所以：$$\frac{28}{4} = 7$$这比周长小得多。 步行会跳过许多位置，因为步长与周长共享一个除数。 假设所有周边位置都被访问过的任何实现都会在这里失败。 

最后，考虑一个非常大的值：

 输入：```
1
1000000000
```我们计算：$$m = 4000000000$$这超出了 32 位有符号整数范围。 具有固定大小整数的语言需要 64 位算术。 Python 会自动处理这个问题，因此实现仍然安全。
