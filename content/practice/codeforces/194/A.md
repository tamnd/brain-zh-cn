 ## 解决方案
 ## 问题理解

 作者必须采取`n`考试。 每项考试都会获得 2 到 5 之间的整数分数（含 2 分和 5 分）。 2 分意味着考试未通过，必须重考。 所有成绩的总和必须完全相等`k`。 

在所有可能的成绩分配中，其总和为`k`，我们希望失败考试的数量尽可能少。 由于只有 2 级会导致重考，因此任务变为：最大化 3、4 或 5 级考试的数量，同时仍保持总和等于`k`。 

限制很小。`n`最多 50 并且`k`最多 250，所以即使是蛮力方法也能轻松适应。 尽管如此，这个问题仍然有一个直接的数学观察，可以将整个解决方案简化为单个公式。 

当目标总和已经是最小可能总和时，就会发生第一个微妙的边缘情况。 例如：```
Input:
4 8
```每门考试必须至少有 2 门，因此最低可达到的总成绩为`4 * 2 = 8`。 这迫使每次考试都是 2，所以答案是 4。如果不正确地处理这条基线，试图贪婪地提高成绩，那么粗心的解决方案可能会意外地产生比可能的情况更少的失败。 

当总和非常大时，就会出现另一个容易出现的错误。 考虑：```
Input:
3 15
```最高可能等级为 5，并且`3 * 5 = 15`，所以每次考试都可以得到 5 分。答案是 0。一些不正​​确的实现认为，高于最低分数的每一个额外分数都会消除一次失败的考试，这是错误的，因为单次考试最多可以吸收 3 个额外分数。 

一个更有趣的案例是：```
Input:
4 10
```最低总分是 8。我们需要 2 个额外积分。 一次考试可以从 2 级升级到 4 级，产生成绩`[4,2,2,2]`。 答案仍然是 3 次失败的考试，而不是 2 次。这会捕获错误划分或假设每个额外分数修复不同的失败考试的解决方案。 

## 方法

 暴力方法会尝试所有可能的成绩分配。 由于每次考试都可以采用四个值之一，因此有`4^n`组合。 和`n = 50`，这变得天文数字般巨大并且完全不可行。 

动态编程也是可能的。 我们可以定义`dp[i][s]`作为处理后失败考试的最小数量`i`考试总成绩`s`。 自从`n <= 50`和`k <= 250`，这运行得很快。 状态计数大致为`50 * 250`，每个过渡考虑四个等级。 

问题结构使得事情变得更加简单。 

每次考试都从 2 年级开始。这给出了基线总计`2n`。 任何更高的等级都会增加额外的分数：

 | 等级 | 2以上加分|
 | --- | --- |
 | 2 | 0 |
 | 3 | 1 |
 | 4 | 2 |
 | 5 | 3 |

 假设我们需要最终总和`k`。 我们必须分配的额外分数是：$$k - 2n$$每次未及格的考试最多可以贡献3分，因为最高分是5分。因此，如果我们想最大限度地减少不及格的考试，我们应该在每次及格考试中包含尽可能多的额外分数。 

如果一次通过考试最多可贡献 3 分，则所需通过考试的最少次数为：$$\left\lceil \frac{k - 2n}{3} \right\rceil$$考试总数为`n`，因此失败考试的最小数量变为：$$n - \left\lceil \frac{k - 2n}{3} \right\rceil$$这将问题从搜索问题转变为直接的数学计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(4^n) | O(4^n) | O(n) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`和`k`。 
2. 计算可能的最小总分，即`2 * n`。 这相当于每次考试都获得 2 分。 
3. 计算需要多少个附加点：$$extra = k - 2n$$1、每次通过考试最多可吸收3个加分，即2分变为5分。 
2. 计算所需通过考试的最少数量：$$pass\_exams = \left\lceil \frac{extra}{3} \right\rceil$$在整数算术中，这变成：```
(extra + 2) // 3
```1. 剩下的考试必须停留在2级，所以答案是：```
n - pass_exams
```### 为什么它有效

 每门考试最初贡献2分。 为了达到所需的总数，我们分发`extra`考试中的额外分数。 单次考试最多可额外加分 3 分，因为分数上限为 5 分。 

为了最大程度地减少失败的考试，我们希望尽可能少的考试才能获得所有加分。 将 3 个额外分数打包到一场考试中至少与将它们分散到多个考试中一样好，因为每次升级到 2 以上的考试都不再是失败的考试。 

上限部分计算能够提供所有所需加分的最少考试数量。 任何剩余的考试都保留为 2 级，并算作未通过考试。 没有任何安排可以使用更少的通过考试，因为每次通过考试都有3个加分的硬性能力。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

extra = k - 2 * n
passing = (extra + 2) // 3

print(n - passing)
```实现直接遵循数学推导。 

表达式`k - 2 * n`计算每次考试分配最低 2 分后我们还需要多少分。 由于问题保证存在有效的配置，因此该值永远不会超出公式可以处理的范围。 

天花板划分是唯一微妙的部分。 数学方面：$$\left\lceil \frac{x}{3} \right\rceil$$变成：```
(x + 2) // 3
```对于非负整数。 在整数除法之前加 2 可以正确向上舍入。 

最后减去通过考试的次数`n`给出保留在 2 级的考试数量。 

不需要循环或大型数据结构。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n, k = map(int, input().split())

    extra = k - 2 * n
    passing = (extra + 2) // 3

    print(n - passing)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert run("4 8\n") == "4\n", "sample 1"

# custom cases
assert run("1 2\n") == "1\n", "minimum possible sum"

assert run("3 15\n") == "0\n", "all exams score 5"

 ## 边缘情况

 考虑最小总数的情况：```
Input:
4 8
```该算法计算：```
extra = 8 - 2*4 = 0
passing = (0 + 2) // 3 = 0
answer = 4 - 0 = 4
```不需要额外的分数，因此每次考试都保持 2 级。输出正确为 4。 

现在考虑最大总数的情况：```
Input:
3 15
```该算法计算：```
extra = 15 - 2*3 = 9
passing = (9 + 2) // 3 = 3
answer = 3 - 3 = 0
```所有考试都必须通过考试，特别是 5 级考试。输出正确为 0。 

最后，检查一个上限除法案例：```
Input:
5 11
```总分最少为 10，因此只需加一分：```
extra = 1
passing = (1 + 2) // 3 = 1
answer = 5 - 1 = 4
```一项考试可以成为 3 级，而其余四项考试则保留为 2 级。此处，楼层划分实施会错误地计算零及格考试。
