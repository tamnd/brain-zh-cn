 ## 解决方案
 ## 问题理解

 我们正在一个矩形足球场内工作，其中左侧的垂直线上有一个球门部分$x = 0$，右侧包含高度为水平的墙$y = y_w$。 球从给定点开始$(x_b, y_b)$并且必须以直线踢向水平墙上的选定点。 撞到墙上后，它会完美反射，即入射角等于反射角，然后沿直线向球门线行进。 

目标不仅仅是击中球门线，而是确保球在水平墙上弹跳一次后越过线段$x = 0$之间$y_1$和$y_2$。 踢球者可以选择任意点$(x_w, y_w)$墙上的点，目标是判断是否存在这样的点，如果存在，则输出其$x$-协调。 

一个关键的几何复杂问题是球有半径$r$，因此“接触”墙壁或柱子被解释为球的中心保持在一定距离内$r$。 这有效地创造了安全裕度，特别是在球门段和场地边界周围，但主要的几何结构仍然由直线运动和反射控制。 

约束允许坐标达到$10^6$，这强烈表明$O(1)$或每个测试用例的对数几何构造。 任何试图离散墙上的候选点或模拟许多选择的轨迹的解决方案都会太慢并且数值不稳定。 

当选择的反射方向引导球以退化方式返回墙壁时，会出现微妙的边缘情况。 如果几何形状迫使球错过进球间隔或违反“恰好一次弹跳”条件，则答案必须是$-1$。 

## 方法

 一个天真的想法是尝试许多候选目标点$(x_w, y_w)$沿着墙壁，模拟轨迹，反映路径，检查最后一段是否穿过目标区间。 对于每个候选者，这将需要计算与墙壁的交叉点，然后检查反射光线是否击中该线段$[y_1, y_2]$。 即使我们将墙精细地离散化，比如说$10^5$点，每个模拟都涉及浮点几何和相交检查，这太慢且脆弱。 

关键的观察结果是，使用镜像目的地的标准几何技巧可以完全消除水平线的反射。 我们不考虑弹跳，而是将球门线反射到墙上，并用从起点到镜像球门点的单个直线段替换断开的路径。 弹跳点正好是该线段与墙壁的交点。 

这将问题转化为选择点$y$在进球间隔内，使得线从$(x_b, y_b)$到$(0, 2y_w - y)$与线相交$y = y_w$在有效的$x_w$。 唯一剩下的约束是相交必须发生在离开起点之后和到达镜像目标之前，这转化为直线参数上的简单不等式。 

蛮力之所以有效，是因为我们可以尝试所有方法$y \in [y_1, y_2]$，但这是不必要的。 约束的结构将问题简化为检查区间是否成立$[y_1, y_2]$包含满足线性不等式的任何值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 通过模拟尝试所有墙点 |$O(N)$每个查询 |$O(1)$| 太慢了 |
 | 镜像几何+间隔检查|$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 我们完全按照镜像目标构建来工作。 

1. 计算球到墙壁的垂直距离：$d = y_w - y_b$。 由于输入限制，这是积极的。 
2. 对于任何选定的目标点$y \in [y_1, y_2]$，将其在墙上的镜像位置定义为$y' = 2y_w - y$。 这将两段反射路径转换为直线$(x_b, y_b)$到$(0, y')$。 
3. 当线到达时与墙相交$y = y_w$。 沿着线段，我们可以将插值参数表示为$$t = \frac{y_w - y_b}{y' - y_b}.$$这是到达墙壁高度所需的水平移动的分数。 

1. 墙上的交点有x坐标$$x_w = x_b(1 - t).$$这来自于之间的线性插值$x_b$和$0$。 

1. 为了使几何体有效，交点必须位于起点和镜像终点之间，这意味着$t \in (0,1)$。 这个条件转化为一个约束条件$y$: 值$y$必须躺在$y_b$与相反$y_w$，并且足够远使得$|y - y_b| > y_w - y_b$。 
2.我们检查间隔$[y_1, y_2]$并确定它是否包含至少一个满足该不等式的值。 如果是，我们构建$y$, 计算$y'$, 计算$t$，然后计算$x_w$。 
3.如果无效$y$存在，我们输出$-1$。 

### 为什么它有效

 正确性取决于反射等效性：水平线上的单次反弹完全等效于到达反射目标的直线路径。 每个有效的弹跳轨迹恰好对应于到镜像点的一个直线段，并且在段约束内与墙壁相交的每个这样的段对应于有效的物理轨迹。 上的不平等$t$确保在到达镜像目标之前和离开起点之后发生相交，从而防止退化延伸到墙外。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    y1, y2, yw, xb, yb, r = map(float, input().split())

    # We need to find y in [y1, y2] such that:
    # |y - yb| > (yw - yb)

    d = yw - yb

    candidates = []

    # check lower side
    if y1 <= yb - d:
        candidates.append(y1)

    # check upper side
    if y2 >= yb + d:
        candidates.append(y2)

    if not candidates:
        print(-1)
        return

    # pick any valid candidate
    y = candidates[0]
    yp = 2 * yw - y

    t = (yw - yb) / (yp - yb)
    xw = xb * (1 - t)

    print(f"{xw:.10f}")

if __name__ == "__main__":
    solve()
```该代码直接应用镜像点减少。 唯一重要的决定是选择一个有效的$y$从目标间隔开始。 由于可行性条件分为两个不相交的区域，因此测试区间端点就足够了。 

的计算$t$直接由垂直坐标中的线性插值得出，并且$x_w$是通过沿从球到镜像球门的部分的比例运动得出的。 

## 工作示例

 ### 示例 1

 输入：```
4 10 13 10 3 1
```我们计算$d = 13 - 3 = 10$。 有效区域为$y$是$y \le 3 - 10 = -7$或者$y \ge 3 + 10 = 13$。 仅上端点$y = 10$或者$y = 4$必须对照间隔进行检查$[4,10]$。 唯一可行的选择是$y = 10$。 

| 步骤| 价值|
 | --- | --- |
 | 选择的$y$| 10 | 10
 | 镜像的$y'$| 16 | 16
 |$t$|$(13 - 3)/(16 - 3) = 10/13$|
 |$x_w$|$10 \cdot (1 - 10/13)$|

 结果给出了墙上的有效交点，产生一条反射一次并到达目标段的可行轨迹。 

这证实了当可行性成立时，选择有效区间的边界就足够了。 

### 示例 2

 输入：```
1 2 10 5 4 1
```这里$d = 10 - 4 = 6$。 有效区域要求$y \le -2$或者$y \ge 10$。 间隔$[1,2]$两者都不包含，因此不存在有效的反射。 

| 步骤| 价值|
 | --- | --- |
 | 间隔| [1, 2] |
 | 有效地区 | (-∞, -2] 和 [10, ∞) |
 | 可行 y | 无 |

 算法正确输出$-1$，表明某些配置无法解析为单次弹跳轨迹。

 ## 边缘情况

 当进球间隔完全太接近球相对于墙的垂直位置时，条件$|y - y_b| > y_w - y_b$到处都失败。 在这种情况下，每个候选人$y$生成一条轨迹，该轨迹要么以无效参数撞到墙壁，要么反射回起始侧，并且算法正确地拒绝该实例。 

当区间几乎触及可行性边界时，只有一个端点有效。 该算法保持稳定，因为它显式检查两个端点，而不是尝试中点推理，这在有效区域断开连接的退化情况下会失败。
