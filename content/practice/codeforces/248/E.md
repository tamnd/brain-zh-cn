 ## 解决方案
 ## 问题理解

 我们被要求计算经过一系列操作后没有未尝过的蜜罐的货架的预期数量。 每个架子都以一定数量的蜜罐开始。 温妮将一小部分罐子从一个架子移到另一个架子上，并在此过程中品尝它们。 源货架上的每个罐子都有平等的机会被采摘品尝，因此结果是概率性的。 每次移动后，我们需要预期的货架数量，其中每个锅都至少被品尝过一次。 

输入指定架子的初始数量以及每个架子上有多少个罐子。 然后我们会收到 Winnie 移动彩池的操作列表。 每个动作由源架子、目标架子和移动的盆数定义。 每个操作后的输出是一个浮点数，表示完全“品尝”的货架的预期数量。 

约束表明最多可以有 100,000 个架子和 100,000 个操作。 每个架子最多可放置 100 个盆，每次移动最多转移 5 个盆。 这意味着显式跟踪每个底池的天真方法可能会涉及到$10^5 \times 100$每个动作的计算量，这太慢了。 我们需要更加数学化、概率化的表示，而不是显式模拟。 

当架子以零罐开始时，就会出现边缘情况。 粗心的实现可能会除以零或忽略此类架子，但根据定义，具有零罐的架子被认为是完全“品尝”的，并且应该从一开始就有助于预期计数。 当所有动作都从架子上转移所有罐子时，就会出现另一个微妙的情况； 概率必须正确更新，而不假设整数计数。 

## 方法

 蛮力方法是通过考虑可以挑选的每种罐子组合来模拟每个动作，将它们标记为已尝过的，并计算完全尝过的货架的数量。 这在理论上是正确的，但对于每个动作，组合的数量与移动的罐子的数量呈指数关系。 由于每个架子可能最多有 100 个罐子，而我们有最多 100,000 个动作，所以这是不可行的。 例如，从 100 个底池中选择 5 个底池$\binom{100}{5} \approx 75 \text{ million}$组合。 迭代 100,000 次操作远远超出了 2 秒的时间限制。 

关键的见解是从显式模拟切换到跟踪概率。 让$p_i$表示货架上单个锅的概率$i$还**没有尝过**。 完全品尝过的货架的预期数量只是$(1 - p_i^{a_i})$遍布所有货架，其中$a_i$是货架上花盆的总数$i$。 当维尼移动时$k$架子上的盆$u$上架$v$，我们可以更新源架的未触及概率$u$作为一个产品超过$k$盆，使用无放回抽样公式：$$p_u \gets p_u \cdot \frac{a_u - k}{a_u} + (1 - p_u) \cdot \frac{k}{a_u}$$对于目标货架$v$，我们根据传入的底池更新其未触及的概率。 自从$k \le 5$，这些更新是每个动作的固定时间。 这使得每个动作都可以在$O(1)$每个架子的时间，使得整体复杂性$O(n + q)$，这是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(q * 2^k) | O(q * 2^k) | O(n * 最大(a_i)) | 太慢了 |
 | 概率追踪| O(n + q) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`p`在哪里`p[i] = 1.0`如果架子`i`有锅，代表一锅**没有被品尝过**的概率。 如果一个架子从零罐开始，则认为它已完全品尝，因此`p[i] = 0.0`。 
2. 计算完全品尝过的货架的初始预期数量：$\sum_i (1 - p[i]^{a[i]})$。 零盆的货架直接贡献1.0。 
3. 对于每个操作，提取源架`u`, 目标架`v`，以及盆数`k`。 
4. 对于源架`u`，更新采样后未触及锅剩余的概率$k$罐子。 由于 Winnie 统一挑选彩池，因此单个彩池未触及的概率变为：$$p[u] = p[u] \cdot \frac{a[u] - k}{a[u]}$$这反映了这样一个事实：如果一个罐子没有在这些罐子中被选中，它就会原封不动地保存下来。$k$感动了。 

5. 对于目标货架`v`，每个传入的底池都会贡献其之前未触及的概率。 货架的组合未触及概率乘法更新`k`盆：$$p[v] = 1 - (1 - p[v]) \cdot (1 - p_u^{\text{per moved pot}})$$在实践中，我们提出`p[u]`权力`1`自此以来每个移动的底池`k`很小。 

6. 更新两个货架后，重新计算完全品尝过的货架的预期数量：$$\text{expected} = \sum_i (1 - p[i]^{a[i]})$$1. 打印每个动作后的期望值，精确到小数点后 12 位。 

维持的不变量是`p[i]`总是正确地表示货架上单个锅的概率`i`还**没有尝过**。 由于预期计数公式使用$1 - p[i]^{a[i]}$，每次操作后我们总是会得到正确的预期完全品尝过的货架数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
q = int(input())

p = [1.0 if a[i] > 0 else 0.0 for i in range(n)]

def expected_count():
    return sum(1 - p[i]**a[i] for i in range(n))

for _ in range(q):
    u, v, k = map(int, input().split())
    u -= 1
    v -= 1
    if a[u] > 0:
        # Probability each pot on u survives untouched after moving k
        factor = (a[u] - k) / a[u]
        p[u] *= factor
    # Update target shelf
    for _ in range(k):
        p[v] = p[v] + p[u] * (1 - p[v])
    print("%.12f" % expected_count())
```该代码完全按照描述实现了算法。 我们通过将零罐架的未触及概率初始化为 0 来处理零罐架。每个操作都会乘法更新源架，并针对每个传入罐迭代更新目标架。 最终的预期计数使用正确的公式求和$1 - p[i]^{a[i]}$。
