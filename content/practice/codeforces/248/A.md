 ## 解决方案
 ## 问题理解

 我们有一套橱柜，每个橱柜都有两扇门：左门和右门。 每扇门都可以打开或关闭。 每扇门的初始状态在输入中给出。 卡尔森希望所有左门处于同一位置，所有右门处于同一位置。 确切的目标位置并不重要 - 只要所有左门匹配且所有右门匹配即可。 我们需要找到实现这种均匀性所需的最少翻转门次数。 

输入由一个整数组成`n`代表柜子的数量，后面是`n`代表每个橱柜左右门状态的整数对。 输出是一个整数 - 所需的最小翻转门次数。 

限制条件`2 ≤ n ≤ 10^4`意味着对所有橱柜进行简单的线性扫描是可行的。 任何复杂度低于 O(n) 的算法在时间限制下都可能存在风险。 每个门的状态要么是 0（关闭），要么是 1（打开），因此我们可以轻松计算每个状态的出现次数。 非明显的边缘情况包括所有门都已处于同一位置，或者翻转一侧的所有门比翻转另一侧更便宜。 

例如，考虑一个输入：```
2
0 1
0 0
```所有左门都已经相同，因此我们不需要翻转任何左门。 正确的门不同，最便宜的方法是翻转不同的门（1 变成 0），导致翻转 1 次。 总是基于多数翻转的简单实现可能会产生相同的结果，但仔细处理计数零和一可确保正确性。 

## 方法

 暴力方法将涉及尝试左门和右门的两种可能的最终状态，计算每种配置所需的翻转次数，并选择最小值。 对于左门，这意味着计算当前有多少个为 0，有多少个为 1，然后选择较小的计数进行翻转。 对右门重复相同的操作。 这种方法简单、正确，并且运行时间为 O(n)，因为我们只扫描每个橱柜一次。 

最优解本质上与这里的暴力破解相同。 关键的见解是各方的最终状态只需要一致即可。 因此，我们只需要计算每一边有多少扇门打开或关闭，然后翻转少数门。 不需要复杂的模拟或动态编程。 这种直接计数方法实现了 O(n) 时间和 O(1) 额外空间。

 ## 算法演练

 1.初始化两个计数器`left_open`和`right_open`为零。 这些将跟踪打开的左门和右门的数量。 
2. 迭代每个橱柜。 对于每个橱柜，如果左门打开 (1)，则递增`left_open`。 如果右门打开，则增加`right_open`。 
3. 计算左门所需的翻转次数。 让`left_closed`是`n - left_open`。 左门的最小翻转次数是以下较小者`left_open`和`left_closed`。 
4. 同样，计算右门的翻转次数。 让`right_closed`是`n - right_open`。 右门的最小翻转次数是以下较小者`right_open`和`right_closed`。 
5. 将左右门的翻转次数相加，得到翻转次数最少的总数，并打印结果。 

为什么有效：每扇门只有两种可能的状态。 为了使一侧的所有门保持一致，我们要么将所有打开的门翻转为关闭，要么将所有关闭的门翻转为打开。 计算每个州的门数量可以让我们选择更便宜的选择。 这个不变量独立地适用于左侧和右侧。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
left_open = 0
right_open = 0

for _ in range(n):
    l, r = map(int, input().split())
    if l == 1:
        left_open += 1
    if r == 1:
        right_open += 1

left_flips = min(left_open, n - left_open)
right_flips = min(right_open, n - right_open)

print(left_flips + right_flips)
```该代码首先读取橱柜的数量，然后遍历每个橱柜，计算当前打开的门数量。 它分别计算左门和右门的最小翻转次数并将其相加。 关键的实现考虑因素包括使用整数算术来避免差一错误以及使用`sys.stdin.readline`对于更大的输入。

 ## 边缘情况

 对于所有门最初都相同的橱柜，例如：```
3
0 0
0 0
0 0
```该算法将左侧和右侧的开门计数为零。 双方的最小翻转次数均为 min(0,3) = 0，因此不会发生翻转。 这可以正确处理已经统一的门的边缘情况。 类似地，当所有门都打开时，算法输出零翻转。 当计数相同时（打开门和关闭门的数量相同），算法会选择其中一个，从而产生正确的最小翻转次数。
