 ## 解决方案
 ## 问题理解

 我们有几棵灌木，每棵都有两堆独立的浆果：红色和蓝色。 从这些来源中，我们希望形成尽可能多的篮子，其中每个篮子必须准确包含$k$浆果。 

只有当浆果遵守一个结构限制时，篮子才允许混合浆果：要么所有浆果都来自单一灌木，要么所有浆果具有相同的颜色。 这意味着每个有效的篮子都同时沿着两个轴（灌木标识和颜色标识）受到限制，并且我们可以在填充篮子时使用任一轴作为分组规则。 

关键的困难是浆果没有预先分配到篮子里。 我们可以将灌木的贡献分配到多个篮子中，并且只要遵守“相同颜色”规则，我们也可以合并不同灌木的贡献。 

目标是最大化装满篮子的数量。 

限制因素$n, k \le 500$足够小，二次甚至三次转变都是可以接受的。 然而，浆果很重要$a_i, b_i$上升到$10^9$，这立即排除了任何试图模拟逐个浆果操作的方法。 该解决方案必须仅对每个灌木的总数量起作用。 

天真的解释可能意味着贪婪地贪婪地获取每种灌木或每种颜色的完整篮子。 但这种做法失败了，因为一株灌木中的单一决定会影响随后将全球剩余物组合起来的效率。 

当部分使用很重要时，就会出现微妙的故障情况。 

考虑：```
n = 2, k = 4
(5, 2), (2, 1)
```如果我们贪婪地拿走每个灌木的完整篮子，我们可能会吃掉第一个灌木中的 4 个红色浆果，留下无法最佳组合的零碎剩余物。 正确的解决方案是使用剩余的红色浆果进行跨灌木重新分配来完成篮子，因此局部贪婪决策是不够的。 

正确的方法必须跟踪部分群体如何为未来的完成做出贡献。 

## 方法

 一个直接的蛮力想法是采用各种可能的方法，将每种灌木中的浆果分成篮子，然后尝试将剩余的灌木和颜色结合起来。 这很快就会变成一个组合分配问题：每个灌木都贡献$a_i + b_i$项目，但每个项目必须分配到尺寸组$k$取决于我们是留在灌木丛中还是在颜色中。 

即使我们简化并思考“每个灌木为共享池贡献了多少浆果”，我们仍然需要考虑剩下多少浆果模$k$本地任务完成后。 尝试所有方法来分配每个灌木的余数会导致粗略的结果$O(k^n)$的可能性，即使对于$n = 30$。 

关键的结构见解是每个篮子要么是“水平的”（相同的灌木），要么是“垂直的”（相同的颜色）。 水平篮子是本地的并且每个灌木都是独立的，但垂直篮子通过颜色总数将所有灌木耦合在一起。 这建议将决策分为两层：每个灌木首先在当地消耗多少浆果，以及剩下多少浆果形成全球基于颜色的篮子。 

问题归结为决定，对于每种灌木，我们在当地采摘多少浆果的倍数$k$，以及还有多少剩余物需要按颜色合并。 每个灌木唯一有意义的状态是余数模$k$，因为完整的块大小$k$始终立即形成篮子。 

这将问题简化为灌木上的动态规划，跟踪当前总红色和蓝色余数模$k$尚未装入彩色篮子的产品。 每个灌木根据它在本地贡献的完整篮子数量以及它如何改变残留物状态来贡献转换。 

DP状态空间为$O(n \cdot k^2)$，因为每个残基的边界为$k$。 这足够小$n, k \le 500$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了 |
 | DP 余数 |$O(nk^2)$|$O(k^2)$| 已接受 |

 ## 算法演练

 我们一一处理灌木，保持对可能剩余的红色和蓝色浆果取模的 DP$k$尚未转换成全彩篮子。 

1.定义一个DP表，其中`dp[r][b]`表示处理一些灌木前缀后到目前为止形成的完整篮子的最大数量，留下$r$红色和$b$蓝色浆果作为剩菜，仍然可以在基于颜色的篮子中使用。 

这种状态很重要，因为只有剩余物才能在灌木之间相互作用。 
2. 初始化`dp[0][0] = 0`，因为在加工任何东西之前，我们没有浆果，也没有篮子。 
3. 对于每个具有值的灌木$(a_i, b_i)$，我们计算一个新的 DP 表。 

我们首先考虑在这棵灌木丛中我们可以形成多少个完整的篮子。 如果我们采取$x$红色和$y$当地的蓝莓，我们必须确保$x + y$被分成完整的大小组$k$。 形成尽可能多的本地篮子后的剩余部分成为候选剩余物。 
4. 对于每个现有的 DP 状态$(r, b)$，我们尝试了使用当前灌木中的浆果的所有方法。 我们不会选择任意的分割，而是只关心在灌木丛中形成完整的篮子后还剩下多少浆果。 这减少了迭代可能的红色余数的过渡$r'$和蓝色余数$b'$由该灌木产生，限制条件是$r' \le a_i$,$b' \le b_i$， 和$(r' + b') \bmod k$确定本地创建了多少个完整的篮子。 
5. 对于每个转换，我们结合：

 之前的剩菜$(r, b)$,

 加上这棵灌木的新剩余物，

 并使用以下方法分别从红色和蓝色转换尽可能多的完整颜色篮：$$\left\lfloor \frac{r + r'}{k} \right\rfloor + \left\lfloor \frac{b + b'}{k} \right\rfloor$$剩余的余数被存储为下一个 DP 状态。 

此步骤是正确的，因为基于颜色的篮子仅取决于每种颜色的总数，而不取决于灌木起源。 
6. 处理完所有灌木后，我们取所有 DP 状态的最大值。 

### 为什么它有效

 在每一步中，DP 将所有历史决策压缩为仅剩余的模数$k$。 任意一组$k$相同颜色的浆果会立即固定在篮子中，并且不会影响以后的决定。 由于混合只允许在颜色或灌木内进行，因此未来的操作不取决于这些完成的篮子是如何形成的。 这确保了所有相关信息都被剩余状态单独捕获，使得 DP 既充分又无损。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    shrubs = [tuple(map(int, input().split())) for _ in range(n)]

    dp = [[-1] * k for _ in range(k)]
    dp[0][0] = 0

    for a, b in shrubs:
        ndp = [[-1] * k for _ in range(k)]

        for r in range(k):
            for bl in range(k):
                if dp[r][bl] < 0:
                    continue
                base = dp[r][bl]

                for take_r in range(min(k, a + 1)):
                    for take_b in range(min(k, b + 1)):
                        total_taken = take_r + take_b
                        if total_taken == 0:
                            continue
                        if total_taken > k:
                            continue

                        # local baskets formed in this shrub
                        local = total_taken // k

                        nr = (r + take_r) % k
                        nb = (bl + take_b) % k

                        # compute full color baskets from leftovers + current picks
                        extra = (r + take_r) // k + (bl + take_b) // k

                        ndp[nr][nb] = max(ndp[nr][nb], base + local + extra)

        dp = ndp

    ans = 0
    for r in range(k):
        for b in range(k):
            ans = max(ans, dp[r][b])

    print(ans)

if __name__ == "__main__":
    solve()
```DP表被初始化以表示在处理灌木之前没有剩余物。 每棵灌木都通过尝试所有可行的方法来创造转变，将浆果带到$k$，因为任何超出$k$立即为完整的篮子做出贡献，并且不会以有意义的方式改变剩余状态。 

这种转变仔细地将贡献分为当地灌木丛和全球颜色完成。 模更新仅保留每个颜色流的未解析部分。 

最终答案是所有剩余状态中可实现的最佳配置。

 ## 边缘情况

 当灌木的最佳贡献不是最大化当地篮子而是保留与未来灌木一致的剩余部分时，就会出现一种边缘情况。 例如，采取$k$在灌木丛中贪婪地种植浆果可能会阻碍以后形成更好的基于颜色的全局篮子的可能性。 DP 明确保留这些剩余部分，允许后来的灌木将它们补充为完整的组。 

当一种颜色在全球占主导地位但在灌木丛中分散时，就会出现另一种边缘情况。 天真的贪婪的每灌木丛方法会丢弃小碎片，但 DP 将它们保持在该状态，直到发生足够的积累以形成完整的篮子。
