 ## 解决方案
 ## 问题理解

 我们被要求确定将线性生成的数组转换为从 0 到 n−1 的整数排列需要多少次操作。 该数组由三个数字 n、b 和 c 定义，并遵循公式 a_i = b * (i - 1) + c，其中 1 ≤ i ≤ n。 在每次操作中，我们用数组中缺失的最小非负整数替换数组中最大的元素，称为 MEX。 如果有多个最大元素，则替换最左边的元素。 我们需要找到将数组转换为有效排列的最少操作数，否则报告这是不可能的。 

输入约束是极端的：n、b 和 c 最多可达 10^18，并且最多可能有 10^5 个测试用例。 由于内存和时间限制，显式构造数组是不可行的。 任何解决方案都必须依赖于对数字模式的推理，而不是迭代每个元素。 

非明显的边缘情况包括所有元素都相同的数组、已经作为排列开始的数组以及可以进入无限替换循环的数组。 例如，当 n = 3、b = 0、c = 0 时，数组为 [0,0,0]。 MEX 为 1，我们将最左边的 max (0) 替换为 1，得到 [1,0,0]。 下一个 MEX 是 2，我们替换最大值 1 得到 [2,0,0]。 MEX 再次变为 1，无限地重复该循环。 在这里，答案是-1。 简单的模拟将永远循环而不会检测到此循环。 

## 方法

 强力方法是显式模拟替换过程。 对于每个操作，计算最大值，计算 MEX，替换最大值，然后重复，直到数组成为排列。 此方法适用于较小的 n，但对于高达 10^18 的 n 不可行，因为它需要不可能数量的操作和存储。 

关键的见解是对数组进行数学推理。 该数组是一个从 c 开始、差值 b 的算术序列。 其最大元素为 c + b * (n-1)，最小元素为 c。 如果 b = 0，则所有元素都相等。 如果常量元素在[0,n-1]之外或者等于0，我们可以直接判断是否可以进行有效排列或者是否会进入循环。 如果 b ≠ 0，则序列严格递增，并且每个元素相差 b。 用 MEX 替换最大值的过程最终会填补从 0 到 n−1 的缺失值。 所需操作的数量由 c 相对于 0..n−1 范围模 b 的起始位置确定。 

这一观察结果使我们能够计算每个测试用例在恒定时间内的操作数量，而无需模拟每次替换。 例如，如果 b = 0，则 c 必须在 0..n−1 中，数组才能成为排列，否则这是不可能的。 如果 b ≠ 0，数组将产生一系列唯一值，我们可以计算最小索引 i，使得 c + b*i ≥ n； 这告诉我们顺序插入缺失数字直到达到排列的操作数。

 ## 算法演练

 1. 读取测试用例 t 的数量并迭代每个用例。 
2. 对于每种情况，读出 n、b、c。 
3. 如果 b = 0：

 - 如果 c ≥ n，则数组由 0..n−1 之外的单个重复元素组成。 排列是不可能的，输出-1。 
- 否则，所有元素都是相同的。 如果 c = 0 且 n = 1，则该数组已经是一个排列； 输出 0。如果 c = 0 且 n > 1，则数组循环进行 MEX 替换，但不会达到排列； 输出-1。 如果 c > 0，则 MEX 为 0，并且每次替换都会递增前一个最大值，直到填充 0..n−1。 操作次数为 n - c。 
4. 如果 b ≠ 0：

- 数组严格递增。 计算最大元素 c + b*(n-1)。 MEX 从 0 开始。替换将按顺序填充所有小于 n 的整数。 如果序列从 1 开始并以 2 递增直到 n（如示例中所示），则操作数为 ⌊max / 2⌋。 
- 一般公式为 max(a) // 2 或更准确地说，是 0..n−1 中缺失元素的数量。 
5. 打印每个案例的操作数。 

为什么有效：对于 b ≠ 0，数组值是不同的，最大替换过程会系统地用最小的缺失值替换最大值。 MEX 始终加一，直到排列完成。 对于 b = 0，该算法会考虑循环场景或直接填充缺失的数字，从而保证所有可能情况下的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    res = []
    for _ in range(t):
        n, b, c = map(int, input().split())
        if b == 0:
            if c >= n:
                res.append(-1)
            else:
                if c == 0:
                    if n == 1:
                        res.append(0)
                    else:
                        res.append(-1)
                else:
                    res.append(n - c)
        else:
            if c >= n:
                # first element already too large, each step reduces max to MEX
                ops = (c + b*(n-1) - n + 1 + b - 1) // b
                res.append(ops)
            else:
                # maximum element
                max_elem = c + b*(n-1)
                ops = (max_elem - n + 1 + b - 1) // b
                res.append(ops)
    print("\n".join(map(str, res)))

if __name__ == "__main__":
    solve()
```解决方案首先要有效地读取输入。 对于 b = 0，我们处理重复元素场景并确定 MEX 替换是否会产生排列。 对于 b ≠ 0，我们计算最大元素，并从相对于 n 的缺失数中推导出替换操作的次数。 所有除法均经过仔细处理以四舍五入，确保最终运算计数正确。
