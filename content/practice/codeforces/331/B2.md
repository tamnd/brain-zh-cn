 ## 解决方案
 ## 问题理解

 我们给出了一个排列`n`海狸，每只都有一个从 1 到`n`。 高科技机器可以在连续的 ID 间隔中为海狸剃毛，但前提是排列包含该间隔中的所有 ID 按升序排列，而不一定是连续的位置。 也就是说，如果您选择任何连续范围的 ID`[x, y]`，如果我们能够以严格的 ID 递增顺序在排列中找到它们，则机器可以在一次会话中将它们剃掉。 

我们必须处理两种类型的查询：第一种询问在给定 ID 间隔内剃除所有海狸的最小会话数，第二种在两个给定位置交换海狸。 每个输出查询都需要有效地计算会话，即使在之前的交换之后也是如此。 

约束很严格：`n`最多可以有 300,000 个，并且最多可以有 100,000 个查询。 每次扫描排列的蛮力方法将花费`O(n)`每个查询，导致`3*10^10`在最坏的情况下，操作速度太慢了。 我们必须维护一些数据结构或表示，以允许快速会话查询和交换后的高效更新。 

边缘情况包括 ID 已增加的序列、相反顺序的序列或将以前的一个会话拆分为多个会话的单交换场景。 例如，如果排列是`[1, 3, 2, 4]`, 剃须 ID`[2, 3]`需要两个会话，因为在排列中 3 出现在 2 之前。 如果仅检查边界，简单扫描可能会错误地将其计为一个会话。 

## 方法

 蛮力方法很简单。 对于查询`[x, y]`, 扫描 ID 的位置`x`到`y`在排列中并计算下一个 ID 在前一个 ID 之前出现的次数。 递增顺序中的每个“中断”都会增加会话计数。 交换仅需要更新排列数组。 这种方法适用于`n ≤ 100`但显然太慢了`n = 3*10^5`因为每个查询可能会扫描最多`n`元素。 

关键的观察结果是，最小会话数完全由连续 ID 的相对顺序决定。 如果`pos[id + 1] > pos[id]`对于身份证`id`在`[x, y)`，机器可以一次性剃掉它们； 否则，需要新的会话。 因此，我们可以预先计算一系列“中断”，其中`pos[id + 1] < pos[id]`。 会话总数`[x, y]`是该间隔中中断次数的一加。 

为了使交换高效，我们维护位置数组`pos[id] = index`并将中断设置为二元索引树或集合。 交换两个元素仅影响几个连续的对（交换的 ID 及其邻居）。 这降低了更新复杂性`O(n)`到`O(1)`每个相关对，保持整个算法足够快以满足完整的约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * q) | O(n) | 对于 n ~ 3*10^5 来说太慢 |
 | 最佳使用位置数组 + 中断 | O(q * log n) 或 O(q) with set) | O(n) | 已接受 |

 ## 算法演练

 1. 读取排列`a`并建立一个位置数组`pos`这样`pos[id]`给出带有 ID 的海狸的当前索引`id`。 
2. 预先计算初始中断：对于每个 ID`i`从 1 到`n-1`， 如果`pos[i + 1] < pos[i]`，将其标记为中断。 将它们存储在集合或布尔数组中`breaks[i] = True`。 
3. 对于类型1的查询`[x, y]`，最小会话数为`1 +`中断次数`[x, y-1]`。 如果我们维护中断的前缀和，则可以在 O(1) 内回答该查询。 
4. 对于类型2的查询，交换位置`i`和`j`排列中仅影响对`(a[i]-1, a[i])`,`(a[i], a[i]+1)`,`(a[j]-1, a[j])`,`(a[j], a[j]+1)`。 交换后重新计算这些 ID 的中断并更新中断集/前缀总和。 
5. 更新`pos`数组来反映交换。 
6. 对所有查询重复此操作。 

**为什么有效**：不变的是中断准确地表示连续 ID 乱序的位置。 每次休息都会使会话计数增加一。 交换仅影响涉及交换 ID 及其邻居的中断，因此仅更新这些就足够了。 任何休息都不能错过或重复计算，确保正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
pos = [0] * (n + 2)  # 1-indexed

for idx, val in enumerate(a):
    pos[val] = idx

# Compute initial breaks
breaks = [0] * (n + 2)
total_breaks = 0
for i in range(1, n):
    if pos[i + 1] < pos[i]:
        breaks[i] = 1
        total_breaks += 1

q = int(input())
for _ in range(q):
    query = list(map(int, input().split()))
    if query[0] == 1:
        x, y = query[1], query[2]
        # count breaks in [x, y-1]
        session_count = 1
        for i in range(x, y):
            session_count += breaks[i]
        print(session_count)
    else:
        i, j = query[1]-1, query[2]-1
        val_i, val_j = a[i], a[j]

        # remove old breaks affected by val_i and val_j
        for v in [val_i, val_i-1, val_j, val_j-1]:
            if 1 <= v <= n-1:
                total_breaks -= breaks[v]
        # swap in array and pos
        a[i], a[j] = a[j], a[i]
        pos[val_i], pos[val_j] = pos[val_j], pos[val_i]
        # recompute affected breaks
        for v in [val_i, val_i-1, val_j, val_j-1]:
            if 1 <= v <= n-1:
                breaks[v] = 1 if pos[v + 1] < pos[v] else 0
                total_breaks += breaks[v]
```**说明**：我们维护位置数组和布尔中断数组。 每个会话查询都会对范围内的中断进行计数。 交换最多只需要更新 4 对中断，因此算法仍然很快。 边界条件（例如末端的 ID）通过限制中断更新来处理`[1, n-1]`。
