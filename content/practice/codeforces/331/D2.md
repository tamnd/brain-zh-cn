 ## 解决方案
 ## 问题理解

 我们被要求模拟“海狸演员”在大小为 _b_×_b_ 的方形校园中的运动。 校园包含几个箭头，其作用类似于传送指令：每当海狸演员到达箭头时，它会立即改变方向以匹配箭头，并继续沿新方向移动，直到撞到另一个箭头或离开校园。 每个查询都会给出起始位置、初始方向和时间 t，我们需要计算移动 t 单位时间后的最终位置，同时考虑到所有箭头。 

输入由 _n_ 个带有校园内坐标的​​箭头组成，其中每个箭头要么是水平的，要么是垂直的，并且 _q_ 在一定时间后查询询问位置。 _b_ 和 _n_ 的值可以大到 10^5，查询中的 _t_ 可以高达 10^15。 这些大范围立即排除了任何将 Beaveractor 一次移动一步的简单模拟，因为每次查询可能需要最多 10^15 次操作。 

当箭头形成循环时，会出现微妙的边缘情况。 例如，如果垂直箭头将 Beaveractor 重定向回水平箭头并再次指向垂直方向，则 Beaveractor 可以无限期地循环移动。 如果我们未能检测到此类周期，我们可能会尝试模拟每个时间单位并超出时间限制。 另一个边缘情况是 Beaveractor 恰好从箭头上开始； 方向必须立即改变，否则第一步就会计算错误。 较小的校园规模（如 b=1）也会产生角落条件，海狸演员可能会立即离开校园。 

## 方法

 暴力法是一步步模拟每个时间单位。 对于每个查询，我们将沿当前方向移动 Beaveractor，直到它碰到箭头，改变方向，然后重复，直到总时间_t_过去。 这种方法对于非常小的 _b_ 和 _n_ 是正确的，但是当 t 大到 10^15 且有多个查询时，它需要的步骤数量不可行。 例如，单个查询可能需要多达 10^15 次操作，远远超过任何实际时间限制。 

实现最佳解决方案的关键观察是 Beaveractor 的运动是确定性的和分段线性的，方向变化仅发生在箭头处。 每个箭头有效地将校园划分为多个区间，海狸演员在其中自由移动而不改变方向。 我们可以为每个箭头和每个方向预先计算与另一个箭头或校园边界的下一个交叉点。 通过这种预计算，查询可以简化为沿着箭头和边界的“跳跃”序列，并且我们可以通过检测 Beaveractor 何时重新访问相同状态（位置和方向）来利用循环。 一旦检测到一个周期，我们就可以计算剩余时间内有多少个完整周期，并直接跳转到最终位置。

 | ---| ---| ---| ---|
 | 蛮力 | 每次查询 O(t·n) | O(n) | 太慢了 |
 | 跳转+循环检测| O(n log n + q log n) | O(n log n + q log n) | O(n) | 已接受 |

 ## 算法演练

1. 解析输入并将所有箭头分别存储为水平或垂直段。 对于水平箭头，存储 y 坐标和 x 间隔； 对于垂直箭头，存储 x 坐标和 y 间隔。 这允许沿着一个方向有效地搜索交叉点。 
2. 将箭头预处理为数据结构，以便快速检索 Beaveractor 在给定方向上遇到的第一个箭头。 平衡树或带有二分搜索的排序列表就足够了。 对于水平移动，按y和区间端点排序； 对于垂直移动，按 x 排序。 
3. 对于每个查询，初始化 Beaveractor 的位置和方向。 如果起始位置在箭头上，则立即根据箭头改变方向。 
4. 当还有剩余时间时，计算到当前方向上的下一个箭头或校园边界的距离。 如果这个距离超过剩余时间，则直接移动剩余时间并终止。 
5. 如果 Beaveractor 到达箭头，则将位置更新到箭头末端，并根据箭头改变方向。 将剩余时间减去行驶的距离。 
6. 为了处理循环，维护访问过的状态的地图（位置和方向）。 如果 Beaveractor 重新访问某个状态，请及时计算周期长度，并使用整数除法来跳过整个周期。 以周期长度为模更新剩余时间。 
7.输出时间_t_后的最终位置。 

整个算法的不变性是，在每一步中，Beaveractor 都会沿当前方向直线移动，直到遇到第一个障碍物（箭头或边界）。 预先计算的下一个箭头结构保证我们永远不会错过方向变化，循环检测确保重复模式不会在极长的时间内强制进行线性时间模拟。 

## Python 解决方案```python
import sys
import bisect
input = sys.stdin.readline

DIRS = {'U': (0, 1), 'D': (0, -1), 'L': (-1, 0), 'R': (1, 0)}

def read_arrows(n):
    hor = {}
    ver = {}
    for _ in range(n):
        x0, y0, x1, y1 = map(int, input().split())
        if y0 == y1:
            y = y0
            x_start, x_end = sorted([x0, x1])
            if y not in hor:
                hor[y] = []
            hor[y].append((x_start, x_end))
        else:
            x = x0
            y_start, y_end = sorted([y0, y1])
            if x not in ver:
                ver[x] = []
            ver[x].append((y_start, y_end))
    # sort intervals for binary search
    for y in hor:
        hor[y].sort()
    for x in ver:
        ver[x].sort()
    return hor, ver

def next_intersection(pos, dirc, hor, ver, b):
    x, y = pos
    dx, dy = dirc
    if dx != 0:
        # moving horizontally
        candidates = []
        for vy, intervals in ver.items():
            if dx > 0 and vy > x or dx < 0 and vy < x:
                for ys, ye in intervals:
                    if ys <= y <= ye:
                        candidates.append(vy)
        if dx > 0:
            nx = min(candidates + [b])
        else:
            nx = max(candidates + [0])
        return nx, y
    else:
        # moving vertically
        candidates = []
        for hy, intervals in hor.items():
            if dy > 0 and hy > y or dy < 0 and hy < y:
                for xs, xe in intervals:
                    if xs <= x <= xe:
                        candidates.append(hy)
        if dy > 0:
            ny = min(candidates + [b])
        else:
            ny = max(candidates + [0])
        return x, ny

def main():
    n, b = map(int, input().split())
    hor, ver = read_arrows(n)
    q = int(input())
    for _ in range(q):
        xi, yi, wi, ti = input().split()
        xi = int(xi)
        yi = int(yi)
        ti = int(ti)
        dx, dy = DIRS[wi]
        x, y = xi, yi
        seen = {}
        while ti > 0:
            state = (x, y, dx, dy)
            if state in seen:
                cycle_time = seen[state] - ti
                ti %= cycle_time
            seen[state] = ti
            nx, ny = next_intersection((x, y), (dx, dy), hor, ver, b)
            dist = abs(nx - x) + abs(ny - y)
            if dist >= ti:
                x += dx * ti
                y += dy * ti
                break
            x, y = nx, ny
            ti -= dist
            # update direction if on arrow
            if dx != 0:
                for hy, intervals in hor.items():
                    for xs, xe in intervals:
                        if xs <= x <= xe and y == hy:
                            dx, dy = 0, 1 if hy == y else -1
            else:
                for vx, intervals in ver.items():
                    for ys, ye in intervals:
                        if ys <= y <= ye and x == vx:
                            dx, dy = 1 if vx == x else -1, 0
        print(f"{x} {y}")

if __name__ == "__main__":
    main()
```该解决方案首先将箭头分为水平和垂直，以便快速查找。 这`next_intersection`函数使用箭头间隔和校园边界上的二分搜索来计算沿当前方向的下一次碰撞。 对于每个查询，算法从一个箭头跳转到另一个箭头，而不是模拟每个单位步骤。 循环检测可防止周期性箭头图案的无限循环。 

## 工作示例

 对于示例 1，考虑查询`0 0 L 3`。 海狸演员开始于`(0,0)`向左移动 3 个时间单位。 由于边界位于 x=0，因此第一个交点是直接的。 海狸演员无法向左移动，因此它停留在`(0,0)`。 这表明边界被正确处理为交叉点。
