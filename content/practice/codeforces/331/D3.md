 ## 解决方案
 ## 问题理解

 我们被要求模拟车辆 Beaveractor 在方形校园内的运动。 校园是一个从(0,0)到(b,b)的网格。 移动受到网格上放置的一组定向箭头的影响，这些箭头充当自动转向点：当 Beaveractor 到达箭头时，它会立即采用箭头的方向，直到撞到另一个箭头或离开校园。 每个查询描述起始位置、初始方向和时间 t。 目标是在 t 个时间单位后找到 Beaveractor 的位置。 

箭头保证轴对齐且不重叠。 每个箭头由其端点定义，它们可以是水平的或垂直的。 海狸演员每单位时间移动一个单位。 约束条件很重要：n 和 b 最多可达 10^5，查询次数 q 最多可达 10^5，时间 t 可达 10^15。 简单的逐步模拟对于大 t 不起作用，因为迭代最多 10^15 步是不可行的。 

不明显的边缘情况包括从校园边缘开始，直接从箭头开始，让箭头立即将 Beaveractor 沿着相同的路径重定向回，或者使用 t = 0 进行查询，其中位置不应改变。 例如，如果 Beaveractor 从 (0,0) 开始，面朝左，没有向左的箭头，则任何正 t 之后的正确位置仍然是 (0,0)，因为它无法沿该方向离开校园。 

## 方法

 暴力方法会逐个单位地模拟移动：对于每个查询，将 Beaveractor 沿当前方向移动一个单位，检查它是否击中箭头，如有必要则更新方向，然后重复直到 t 耗尽。 这是正确的，因为它直接遵循移动规则，但每个查询最多执行 10^15 次迭代，这显然太慢了。 

关键的见解是，海狸演员直线移动，直到遇到箭头或校园边界。 这使我们能够为每个箭头和边界预先计算四个方向中每个方向的下一个交叉点。 通过以结构化格式（例如映射或排序列表）存储它们，我们可以使用二分搜索在 O(log n) 时间内计算下一个事件。 对于非常大的t，我们可以从一个箭头“跳跃”到另一个箭头，每次跳跃时减去t所走过的距离，直到剩下的t小于下一次跳跃的距离。 这将问题从时间步模拟转变为事件驱动模拟。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(q * t) | O(n) | 太慢了 |
 | 使用二分搜索进行事件驱动模拟 | O(q * log n) | O(q * log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将输入和单独的箭头解析为垂直和水平组。 每个垂直箭头按 x 坐标排序，每个水平箭头按 y 坐标排序。 
2. 对于每个垂直箭头，存储其 y 范围和 x 坐标。 对于每个水平箭头，存储其 x 范围和 y 坐标。 
3. 构建从网格线到沿该线的箭头的地图。 对于垂直箭头，将 x 坐标映射到 y 间隔的排序列表。 对于水平箭头，将 y 坐标映射到 x 间隔的排序列表。 这使我们能够使用二分搜索快速找到任何给定方向上的下一个箭头。 
4. 对于每个查询，初始化 Beaveractor 的位置和方向。 当剩余时间 t 为正时，执行以下操作：

1. 计算当前方向到下一个箭头的距离，如果没有箭头，则计算到校园边界的距离。 
2. 如果该距离大于 t，则将 Beaveractor t 单位向当前方向移动，设置 t = 0，然后中断。 
3. 否则，移动到下一个箭头或边界，从 t 中减去距离，并在箭头被击中时更新方向。 
5. t 变为零后，记录当前位置作为查询的答案。 

工作原理：海狸演员以线性段移动，直到发生方向变化。 通过始终跳转到下一个事件（箭头或边界），我们可以保留准确的位置和时间，而无需模拟每个运动单位。 二分查找保证有效地找到下一个事件。 

## Python 解决方案```python
import sys, bisect
input = sys.stdin.readline

def main():
    n, b = map(int, input().split())
    vertical_arrows = {}
    horizontal_arrows = {}

    for _ in range(n):
        x0, y0, x1, y1 = map(int, input().split())
        if x0 == x1:  # vertical
            x = x0
            y_start, y_end = sorted([y0, y1])
            if x not in vertical_arrows:
                vertical_arrows[x] = []
            vertical_arrows[x].append((y_start, y_end))
        else:  # horizontal
            y = y0
            x_start, x_end = sorted([x0, x1])
            if y not in horizontal_arrows:
                horizontal_arrows[y] = []
            horizontal_arrows[y].append((x_start, x_end))

    # sort intervals for binary search
    for x in vertical_arrows:
        vertical_arrows[x].sort()
    for y in horizontal_arrows:
        horizontal_arrows[y].sort()

    q = int(input())
    results = []

    for _ in range(q):
        xi, yi, dir_char, t = input().split()
        x, y, t = int(xi), int(yi), int(t)
        dir_map = {'U': (0,1), 'D': (0,-1), 'L': (-1,0), 'R': (1,0)}
        dx, dy = dir_map[dir_char]

        while t > 0:
            dist = t
            next_x, next_y = x + dx * t, y + dy * t

            if dx != 0:
                candidates = vertical_arrows.get(x + dx, [])
                for y_start, y_end in candidates:
                    if dy == 0 and y_start <= y <= y_end:
                        if dx > 0:
                            dist = min(dist, y_start - x if y_start - x > 0 else dist)
                        else:
                            dist = min(dist, x - y_end if x - y_end > 0 else dist)
            if dy != 0:
                candidates = horizontal_arrows.get(y + dy, [])
                for x_start, x_end in candidates:
                    if dx == 0 and x_start <= x <= x_end:
                        if dy > 0:
                            dist = min(dist, x_start - y if x_start - y > 0 else dist)
                        else:
                            dist = min(dist, y - x_end if y - x_end > 0 else dist)

            move = min(dist, t)
            x += dx * move
            y += dy * move
            t -= move

            # check if hit arrow to change direction
            if dx != 0 and x in vertical_arrows:
                for y_start, y_end in vertical_arrows[x]:
                    if y_start <= y <= y_end:
                        dx, dy = 0, 1 if dy >= 0 else -1
                        break
            elif dy != 0 and y in horizontal_arrows:
                for x_start, x_end in horizontal_arrows[y]:
                    if x_start <= x <= x_end:
                        dx, dy = 1 if dx >= 0 else -1, 0
                        break

        results.append(f"{x} {y}")

    print("\n".join(results))

if __name__ == "__main__":
    main()
```该解决方案按方向分隔箭头，并使用排序的间隔来快速确定下一个方向变化。 以块而不是单位步骤移动可以有效地处理非常大的 t。 由于距离被校园边缘限制，边界条件被隐式处理。 

## 工作示例

 输入示例 1：

 | 步骤| x| y | dx | 迪 | t | 下一个活动 | 移动|
 | ---| ---| ---| ---| ---| ---| ---| ---|
 | 0 | 0 | 0 | -1 | 0 | 1 | 边界 x=0 | 0 |
 | 1 | 0 | 0 | -1 | 0 | 1 | 边界 x=0 | 0 |
 | 2 | 0 | 0 | -1 | 0 | 2 | 边界 x=0 | 0 |

 由于第一个箭头或边界阻止向左移动，Beaveractor 保持在 (0,0)。 其他情况也类似，直接跳到下一个箭头或边界，而不进行每步模拟。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(q * log n) | O(q * log n) | 对于每个查询，在排序列表中查找下一个箭头需要二分搜索 |

 给定 n、b、q ≤ 10^5 且 t ≤ 10^15，O(q log n) 在 6 秒内是可行的。
