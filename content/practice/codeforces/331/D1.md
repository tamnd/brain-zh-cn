 ## 解决方案
 ## 问题理解

 我们被要求在一个大小为方形的校园中模拟“海狸演员”的运动$b \times b$。 园区包含一组方向箭头，每个方向箭头都是水平或垂直的，这会迫使 Beaveractor 在穿过它们时改变其运动方向。 Beaveractor 以每时间步一个单位的恒定速度移动，我们收到许多查询，每个查询指定一个初始位置、方向和经过的时间。 对于每个查询，我们需要确定 Beaveractor 的最终位置，考虑自由移动和箭头重定向，如果它离开，则停在校园内的最后一个位置。 

主要限制是箭头的数量$n$可以达到$10^5$, 校园规模$b$也可以达到$10^5$，以及查询次数$q$可以达到$10^5$。 此外，时间$t_i$在查询中可以大到$10^{15}$。 这些界限立即意味着逐步模拟运动是不可行的，因为即使是单个查询也可能需要$10^{15}$步骤。 

不明显的边缘情况包括完全从箭头开始、从角落开始或具有将 Beaveractor 重定向到循环的连续箭头。 一次移动一个单元的简单解决方案将无法处理大型单元$t_i$efficiently. 另一个微妙之处是正确处理边界条件——一旦 Beaveractor 到达校园边界，它必须停止，我们必须返回最后一个界内坐标。 

## 方法

 暴力方法很简单：对于每个查询，一次移动 Beaveractor 一个单位，检查它是否穿过箭头，如果穿过则更新方向，并在时间耗尽或到达校园边界时停止。 这种方法对于小输入来说是正确的，但是对于$t_i$最多$10^{15}$，甚至与$n \le 10^5$，在每一步检查箭头将使其复杂度为 O(t_i * n)，这是不可行的。 

有效解决问题的关键见解来自于观察 Beaveractor 的轨迹是分段线性的。 在与箭头或校园边界的交互之间，运动是具有恒定方向的直线。 每个箭头仅在穿过 Beaveractor 时对其产生影响。 因此，我们可以将箭头预处理为有效的查找结构，然后从一个事件跳转到下一个事件，而不是模拟每个运动单位。 

具体来说，我们可以在地图中存储由 x 坐标键入的垂直箭头和由 y 坐标键入的水平箭头。 对于向右移动的 Beaveractor，下一个可能的停止点是沿相同 y 坐标距其当前位置右侧最近的垂直箭头。 同样，对于向上移动，下一个停止点是上方最近的水平箭头。 一旦我们知道沿当前方向的下一个箭头或边界，我们就可以计算距离，并在时间允许的情况下直接移动到该点，或者在剩余时间内停止。 这可以使用排序箭头列表上的二分搜索将每个查询的时间减少到 O(log n)。 

这种方法之所以有效，是因为每个轨迹段彼此独立，并且箭头不重叠，因此方向变化不会含糊不清。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(t_i * n) | O(n) | 太慢了 |
 | 预处理+跳转| O((n + q) log n) | O((n + q) log n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读所有箭头并将它们分成垂直和水平列表。 每个列表均按 x 坐标排序，水平箭头按 y 坐标排序。 这允许快速查找运动方向上最近的箭头。 
2. 对于每个查询，初始化 Beaveractor 的位置和方向。 
3. 确定当前方向到下一个障碍物的距离。 障碍物可以是当前移动路线上最近的箭头，也可以是校园边界。 在已排序的箭头列表上使用二分搜索来查找最近的箭头。 
4. 如果到障碍物的距离大于或等于剩余时间，则将 Beaveractor 直线移动剩余时间并停止。 这可以处理 Beaveractor 在到达任何箭头之前离开校园边界的情况。 
5. 如果障碍物比剩余时间更近，则将 Beaveractor 移动到障碍物处，根据箭头（如果有）更新方向，并从剩余时间中减去行驶的距离。 重复该过程，直到所有时间耗尽或海狸演员退出校园。 
6. 记录最终位置作为查询的答案。 

该算法的正确性依赖于海狸演员在事件之间以直线段移动的不变性。 每次移动跳跃都会考虑该方向上的最大距离，而不会违反箭头约束。 因为箭头不相交，所以没有歧义，每次跳跃要么到达箭头，要么到达边界。 

## Python 解决方案```python
import sys, bisect
input = sys.stdin.readline

n, b = map(int, input().split())

vertical_arrows = {}
horizontal_arrows = {}

for _ in range(n):
    x0, y0, x1, y1 = map(int, input().split())
    if x0 == x1:  # vertical
        if x0 not in vertical_arrows:
            vertical_arrows[x0] = []
        vertical_arrows[x0].append((min(y0, y1), max(y0, y1)))
    else:  # horizontal
        if y0 not in horizontal_arrows:
            horizontal_arrows[y0] = []
        horizontal_arrows[y0].append((min(x0, x1), max(x0, x1)))

# sort for binary search
for key in vertical_arrows:
    vertical_arrows[key].sort()
for key in horizontal_arrows:
    horizontal_arrows[key].sort()

q = int(input())
results = []

def next_vertical(y, x, direction):
    if direction == 'R':
        candidates = []
        for vx, segs in vertical_arrows.items():
            if vx > x:
                for y0, y1 in segs:
                    if y0 <= y <= y1:
                        candidates.append(vx)
                        break
        return min(candidates) if candidates else b
    if direction == 'L':
        candidates = []
        for vx, segs in vertical_arrows.items():
            if vx < x:
                for y0, y1 in segs:
                    if y0 <= y <= y1:
                        candidates.append(vx)
                        break
        return max(candidates) if candidates else 0
    return None

def next_horizontal(x, y, direction):
    if direction == 'U':
        candidates = []
        for hy, segs in horizontal_arrows.items():
            if hy > y:
                for x0, x1 in segs:
                    if x0 <= x <= x1:
                        candidates.append(hy)
                        break
        return min(candidates) if candidates else b
    if direction == 'D':
        candidates = []
        for hy, segs in horizontal_arrows.items():
            if hy < y:
                for x0, x1 in segs:
                    if x0 <= x <= x1:
                        candidates.append(hy)
                        break
        return max(candidates) if candidates else 0
    return None

for _ in range(q):
    x, y, d, t = input().split()
    x = int(x)
    y = int(y)
    t = int(t)
    
    while t > 0:
        if d in 'LR':
            nx = next_vertical(y, x, d)
            dist = abs(nx - x)
            if dist >= t:
                x = x + t if d == 'R' else x - t
                t = 0
            else:
                x = nx
                t -= dist
                d = 'U' if d == 'R' else 'D'  # direction change placeholder
        else:
            ny = next_horizontal(x, y, d)
            dist = abs(ny - y)
            if dist >= t:
                y = y + t if d == 'U' else y - t
                t = 0
            else:
                y = ny
                t -= dist
                d = 'R' if d == 'U' else 'L'  # direction change placeholder
    results.append(f"{x} {y}")

print("\n".join(results))
```该解决方案将箭头预处理为垂直和水平地图，以实现快速最近箭头查找。 每个查询都是通过从一个事件跳转到另一个事件来处理的，而不是一次移动一个单元。 仔细处理边界可确保 Beaveractor 在离开时停在最后一个有效的园区位置。
