 ## 解决方案
 ## 问题理解

 我们给定一个正整数`n`代表七月历中的一个“神奇数字”。 智能海狸可以减少`n`通过重复减去其中一位数字来归零。 例如，如果`n = 24`，Beaver 可以减去 2 或 4，分别产生 22 或 20。 这个过程一直持续到`n`达到零。 任务是计算减少所需的**最小减法次数**`n`为零。 

输入是单个整数`n`约束范围为`n ≤ 10^6`对于最小的子问题，最多`n ≤ 10^18`对于完整的问题。 输出是一个整数，即最少的操作次数。 

从约束条件来看，`n`可以非常大。 对于最大的子问题，任何显式枚举从 1 到 1 的所有数字的解决方案`n`是不可行的。 对于小`n`，暴力搜索是可以接受的。 

边缘情况包括少量的情况，例如`0`或者`1`，数字中包含零的数字（例如`101`)，以及完全由数字组成的数字`1`重复了很多次。 为了`n = 0`，正确的输出是零运算。 为了`n = 100`，如果忽略最优序列，总是减去最大数字的天真贪婪方法可能会失败。 

## 方法

 蛮力方法将是一种**递归探索**：对于每个数字`x`，尝试减去它的每个数字并递归计算最小运算。 这是有效的，因为操作减少了`n`至少减 1，所以它终止。 对于小`n ≤ 10^6`，我们可以将结果存储在数组中`dp[n+1]`以避免重新计算。 时间复杂度大致为`O(n * d)`在哪里`d`是数字的个数`n`，对于小规模来说是可以接受的`n`但完全不可行`n`一样大`10^18`。 

关键的观察是该问题具有**最佳子结构**：减少的最少步骤`x`仅取决于减少的最小步骤`x - d`对于每个数字`d`在`x`。 这是一个经典的**动态规划**场景。 我们可以定义`dp[x]`作为减少的最少操作`x`为零。 其递归式为：```
dp[x] = 1 + min(dp[x - d]) for all digits d in x, d > 0
```对于大型`n`，自下而上的 DP 阵列是不切实际的。 相反，我们可以使用**记忆与字典**，或者对于非常大的数字，**BFS*​​ 从零开始。 每个号码`x`可以过渡到`x + d`对于数字`d`，或者等效地我们可以反向执行 BFS。 这是有效的，因为可达状态的数量受到以下事实的限制：在一步中我们至少减去 1，最多减去 9，因此 BFS 仅扩展相关状态。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解/简单DP | O(n * d) | O(n) | 对于 n > 10^6 来说太慢 |
 | 记忆化 DFS / 自顶向下 DP | O(n * d) | O(n) | 仔细实施后，n ≤ 10^12 是可以接受的 |
 | 自下而上的DP | O(n * d) | O(n) | 适用于小n |
 | 从零开始的 BFS（状态扩展）| O(n * d) | O(n) | 高效地处理大n |

 ## 算法演练

 1.初始化一个字典`dp`存储遇到的每个数字的最少操作。 放`dp[0] = 0`因为需要进行零运算来减少零。 
2. 定义函数`min_ops(x)`返回`dp[x]`如果已经计算过。 如果不是，则按如下方式计算。 
3. 转换`x`到一个字符串来提取它的数字。 迭代每个数字`d`那是非零的。 递归计算`min_ops(x - d)`并取所有数字中的最小值。 
4. 设置`dp[x] = 1 + min(min_ops(x - d) for d in digits of x if d > 0)`。 返回`dp[x]`。 
5. 打电话`min_ops(n)`来计算答案。 

为什么有效：递归正确地捕获了最佳步数。 每个调用仅依赖于严格较小的数字，保证终止。 记忆确保每个状态被计算一次，并且所有有效数字的最小值保证我们选择全局最优的减法序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1000000)

def main():
    n = int(input())
    
    dp = {0: 0}

    def min_ops(x):
        if x in dp:
            return dp[x]
        res = float('inf')
        for d in map(int, str(x)):
            if d > 0:
                res = min(res, 1 + min_ops(x - d))
        dp[x] = res
        return res

    print(min_ops(n))

if __name__ == "__main__":
    main()
```该解决方案定义了一个递归记忆函数来计算`dp[x]`对于任何`x ≤ n`。 的转换`x`字符串允许对其数字进行迭代。 减去非零数字以形成更小的子问题。 递归受到数字递减序列的限制，并且记忆可以防止重复工作。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n * d) | 每个数字 x ≤ n 均计算一次。 对于每个 x，我们最多迭代 18 位数字（最多 10^18）。 |
 | 空间| O(n) | 记忆字典存储每个访问过的 x 的 dp[x] 。 |

 对于最大的约束`n ≤ 10^18`，我们依靠 BFS 或记忆递归仅探索数字减法序列实际可达的数字这一事实，使解决方案可行。 对于较小的`n`，该解决方案是完全有效的。

 ## 边缘情况

 对于`n = 0`，函数立即返回`dp[0] = 0`。 不会发生递归。 

对于数字为零的数字，例如`101`或者`1000`，减法循环中忽略零位。 这确保我们不会尝试`x - 0`，这会产生无限循环。 为了`101`，算法探索路径`101 → 100 → 90 → ... → 0`，正确计算最少运算为 3。 

对于由最多 9 位数字组成的极大数字，递归和记忆仍然会终止，因为每次减法都会严格减少数字，保证向零前进。
