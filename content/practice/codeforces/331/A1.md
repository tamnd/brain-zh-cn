 ## 解决方案
 ## 问题理解

 我们得到一个线性的树序列，每个树都带有一个整数值，表示该树的美观程度。 我们可以删除这些树的任何子集，并保持其余树的原始顺序。 拆除后，我们必须保留至少两棵树。 

在删除树的所有有效方法中，我们希望最大化剩余值的总和。 然而，还有一个额外的结构约束：在最终序列中，第一个和最后一个剩余的树必须具有相同的值。 

所以任务不仅仅是最大子序列和问题。 我们实际上被迫选择一个值`x`，保留至少两次出现的`x`，并仅考虑以以下开头和结尾的子序列`x`，最大化它们之间的所有值加上这两个端点的总和。 

输出是在此约束下可实现的最大总和、已删除树的数量以及已删除树的索引。 

这些限制立即变得很重要。 对于最多 3·10^5 的元素，任何尝试所有相等值对并在它们之间进行扫描的解决方案在最坏的情况下都会冒着 O(n²) 行为的风险。 2秒太慢了。 我们需要一种方法来有效地处理事件之间的贡献，最好是在线性时间或近线性时间。 

如果我们试图独立地选择最好的一对相等值并假设它们之间的所有内容总是被采用，就会出现天真的错误。 例如，如果值为`[5, -100, 5]`，最好的端点是两个5，但包括中间是有害的，所以必须考虑。 另一个微妙的失败情况是当一个值出现多次时：选择最佳对不仅仅是距离或端点，而是关于我们包含多少次出现以及我们排除什么。 

真正的困难在于，每个潜在的端点值都定义了不同的候选子序列，我们必须有效地评估所有这些子序列。 

## 方法

 暴力方法从固定一个值开始`x`并选择两个出现的情况`i < j`这样`a[i] = a[j] = x`。 然后我们考虑保留它们之间的所有元素并计算总和。 对所有对重复此操作可以提供正确性，但在最坏的情况下，复杂性是二次的，因为一个值可能出现 O(n) 次。 

关键的观察是，一旦我们固定了端点，区间内的最佳选择就不是以复杂的方式可选的：端点之间的每个元素要么被采用，要么不被采用，并且由于我们必须最大化总和，所以我们总是采用它们之间的所有元素。 这将每个候选简化为一个简单的表达式：sum over`[i, j]`加上端点约束。 

However, enumerating all pairs is still too expensive. 下一个简化是将数组视为前缀和。 对于固定值`x`，假设它出现在位置`p1, p2, ..., pk`。 如果我们选择`pi`和`pj`，分数变为：`prefix[pj] - prefix[pi - 1]`。 

因此，对于每个值，我们希望其出现的两个前缀状态之间的最大差异，但限制是我们至少使用两次出现。 

这将问题减少到扫描按值分组的位置并维护迄今为止为每个值看到的最小前缀。 

我们还需要重建哪些索引被删除。 一旦我们选择了最好的一对`(i, j)`对于某些值，最佳保留集是之间的所有索引`i`和`j`包容性。 外面的一切都被移除。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解对 | O(n²) | O(n) | 太慢了 |
 | 前缀 + 按值扫描 | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将问题重新表述为前缀和，以便可以在 O(1) 内计算任何连续的段和。 

1. 计算前缀和`pref`， 在哪里`pref[i]`存储第一个的总和`i`元素。 这允许快速计算任何段总和：`pref[r] - pref[l-1]`。 
2. 按指数值对指数进行分组。 对于每个不同的值`x`，我们查看所有位置`x`发生。 
3. 对于每个值`x`，从左到右扫描其出现列表，维护迄今为止在先前出现的情况下看到的最小前缀值。 在一个位置`j`，我们计算结束于的最佳片段`j`作为`pref[j] - min_pref_so_far`，这对应于选择最佳的较早出现作为左端点。 
4. 跟踪所有值和所有出现对的全局最佳片段。 储存最好的`(l, r)`间隔。 
5. 找到最佳区间后，通过将所有索引保留在中来构造答案`[l, r]`并删除外面的所有内容。 
6. 输出该区间的总和、删除元素的数量以及删除元素的索引。 

### 为什么它有效

 关键的不变量是每个有效的解决方案完全由其最左边和最右边保留的某个值的出现决定`x`。 任何最优解必须以相等的值开始和结束，因此它对应于一对相等的元素。 对于任何固定对，获取它们之间的所有内容始终是最佳的，因为删除任何内部元素都会减少总和，而无助于满足端点约束。 前缀和变换确保评估每个候选对减少到恒定时间差，并且扫描出现保证考虑所有有效对而不重复。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + a[i]

    pos = {}
    for i, v in enumerate(a, 1):
        pos.setdefault(v, []).append(i)

    best_sum = None
    best_l = best_r = None

    for v, lst in pos.items():
        min_pref = pref[lst[0] - 1]
        min_idx = lst[0]

        for j in lst[1:]:
            cur = pref[j] - min_pref
            if best_sum is None or cur > best_sum:
                best_sum = cur
                best_l = min_idx
                best_r = j

            if pref[j - 1] < min_pref:
                min_pref = pref[j - 1]
                min_idx = j

    kept = [0] * (n + 1)
    for i in range(best_l, best_r + 1):
        kept[i] = 1

            removed.append(i)

    print(best_sum, len(removed))
    print(*removed)

if __name__ == "__main__":
    solve()
```该代码首先构建前缀和，以便可以在恒定时间内计算任何段和。 然后，它按值对索引进行分组，以便我们只比较相同值的出现，因为有效端点必须匹配。 

对于每个值列表，我们跟踪每次出现之前的最小前缀值。 这代表了迄今为止看到的最佳左端点。 每个新的出现都会尝试扩展一个片段并更新最佳答案。 

找到最佳段边界后，我们将内部所有内容标记为保留，并将所有其他索引输出为已删除。 

一个微妙的细节是我们必须仔细跟踪前缀`i-1`对于左端点，因为线段总和取决于排除所选开始之前的所有内容。 

## 工作示例

 ### 示例 1

 输入：```
5
1 2 3 1 2
```我们计算前缀和：`[0, 1, 3, 6, 7, 9]`。 

我们处理价值`1`在职位`[1, 4]`。 段总和为`pref[4] - pref[0] = 7`。 

为了价值`2`在`[2, 5]`，段和为`pref[5] - pref[1] = 8 - 1 = 7`。 

为了价值`3`仅出现一次，忽略。 

最好的是价值`2`有间隔`[2, 5]`。 

| 价值| 左| 对| 总和 |
 | --- | --- | --- | --- |
 | 1 | 1 | 4 | 7 |
 | 2 | 2 | 5 | 7 |

 我们挑选`[2,5]`。 正在删除索引`1`给出输出总和`8`。 

这表明多个候选区间可以并列，并且任何有效的最大值都是可接受的。 

### 示例 2

 输入：```
6
4 -1 4 2 -1 4
```前缀和：`[0,4,3,7,9,8,12]`。 

为了价值`4`在职位`[1,3,6]`：

 -`[1,3]`总和 = 3
 -`[3,6]`总和 = 12 - 3 = 9
 -`[1,6]`总和 = 12

 最好的是`[1,6]`总和为 12。 

| 步骤| 我| r | 总和 |
 | --- | --- | --- | --- |
 | (1,3) | 1 | 3 | 3 |
 | (3,6) | 3 | 6 | 9 |
 | (1,6) | 1 | 6 | 12 | 12

 我们保留所有索引并且不删除任何索引。 

这证实了当端点与出现在极值处的值对齐时，整个阵列可以是最佳的。

 ## 边缘情况

 一种边缘情况是最佳间隔由值的第一次和最后一次出现形成。 对于像这样的输入`4 -1 4`，唯一有效的区间是`[1,3]`。 该算法正确计算前缀差异并选择它，因为它支配任何较小的段。 

另一种情况是值出现多次但只有中间一对是最佳的。 例如`5, -10, 5, -10, 5`，最好的段是位置之间`1`和`5`，因为中间削减减少了总和。 前缀扫描确保我们隐式比较所有对而不枚举它们。 

最后一种情况是所有值都相等。 那么最佳解决方案是保留整个数组，因为任何端点都是有效的，并且删除元素只会减少总和。 该算法自然会选择整个范围，因为前缀差异在出现时不断单调增加。
