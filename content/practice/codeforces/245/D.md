 ## 解决方案
 ## 问题理解

 我们得到一个方表，它最初是由一个隐藏的非负整数数组生成的。 每个非对角线条目都是相应的隐藏值对的按位与，而对角线条目则被人为地替换为-1。 任务是重建任何可能生成该表的有效隐藏数组。 

关键点是，当 i ≠ j 时，每个观测值 b[i][j] 正是对两个未知数 a[i] 和 a[j] 应用按位与的结果。 对角线没有提供任何信息。 我们不需要恢复唯一的原始数组，只需恢复与所有成对约束一致的数组即可。 

约束 n ≤ 100 意味着我们可以根据需要进行三次甚至四次推理，但按位 AND 的结构表明，每位或每个元素的直接重建应该在 O(n²) 或 O(n³) 内就足够了。 任何基于位配置的指数都是不必要的，因为每个值最多为 10⁹，因此我们只处理每个数字 30 位。 

当重建贪婪地分配值而不确保所有对之间的一致性时，就会出现微妙的失败情况。 例如，如果我们尝试仅从单行推导 a[i]，则可能会违反另一行的约束。 另一个问题是假设等式约束以一种简单的方式传递传播，这对于按位 AND 来说是不正确的。 

一个具体的问题场景是，如果我们逐对分配值，则三个索引的交互不一致。 例如，选择太小而无法满足一对数的 a[i] 会迫使其他数出现矛盾，因为 AND 只保留两个数字中都存在的位。 

关键的隐藏结构是每个 a[i] 必须与每一行 i 兼容，这意味着 a[i] 必须是所有 b[i][j] 约束的超集（以位计算），但也不能引入禁止位，否则与其他选定值进行 AND 运算时会产生矛盾。 

## 方法

 暴力方法会尝试从 0 到 10⁹ 独立地分配每个 a[i]，并检查所有成对 AND 结果是否与矩阵匹配。 这立即爆炸到 (10⁹)ⁿ 的可能性，即使对于 n = 100 这也是不可能的。 

我们需要对位约束进行逆向工程。 关键的观察是按位与的行为对于每个位都是独立的。 当且仅当 a[i] 和 a[j] 中都设置了该位时，a[i] 和 a[j] 中才设置该位。 这意味着对于每对 (i, j)，出现在 b[i][j] 中的任何位都必须出现在 a[i] 和 a[j] 中。 

因此，对于每一对 (i, j)，我们可以安全地强制要求 b[i][j] 中设置的所有位都必须出现在两个端点中。 这给出了 a[i] 和 a[j] 的下界约束。 如果我们对所有 j 进行聚合，我们得到 a[i] 必须包含出现在任何 b[i][j] 中的所有位。 

这给出了一个自然的候选结构：将 a[i] 设置为所有 b[i][j] 在 j ≠ i 上的按位或。 这确保了 a[i] 中存在每个所需的位。 剩下的就是验证这种构造不会引入会产生矛盾的额外位。 AND 的结构保证了这一点，因为 a[i] 中设置的任何位都必须至少出现在一个 b[i][j] 中，因此只有在需要时也出现在 a[j] 中时才能持续存在。 

这将问题简化为对矩阵的单次传递。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力分配 | O((10⁹)ⁿ) | O(n²) | 太慢了 |
 | 按位约束构造 | O(n²) | O(n²) | 已接受 |

 ## 算法演练

1. 初始化一个大小为 n 且全为零的数组 a。 这将累积每个索引的所有位约束。 
2. 对于每个索引 i，迭代所有 j ≠ i 并计算 a[i] |= b[i][j]。 此步骤收集 a[i] 中必须出现的每个位，因为每个 b[i][j] 是 a[i] 和 a[j]，因此不能包含 a[i] 中缺少的位。 
3. 填充完所有a[i]后，我们隐式地依赖对称性：如果某个位由于某些b[i][j]而出现在a[i]中，那么只有当它也出现在a[j]中时，它才是一致的。 由于计算 a[j] 时使用了相同的 b[i][j]，因此确保了这种一致性。 
4. 输出结果数组。 

它的工作原理与位独立性有关。 每个位位置的行为就像一个单独的二进制约束系统。 如果 b[i][j] 中出现某个位，则两个端点都必须包含该位。 如果它没有出现，则至少一个端点可能包含也可能不包含它，但绝不会同时包含它，除非得到其他对的支持。 对所有约束进行“或”运算可确保包含每个强制位，并且不会引入会违反任何成对“与”值的不必要的结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    b = [list(map(int, input().split())) for _ in range(n)]

    a = [0] * n

    for i in range(n):
        val = 0
        for j in range(n):
            if i == j:
                continue
            val |= b[i][j]
        a[i] = val

    print(*a)

if __name__ == "__main__":
    solve()
```代码直接翻译了构建思路。 嵌套循环扫描每一行并在所有非对角线条目上累积按位或。 对角线被忽略，因为它不包含有用的信息。 

一个常见的陷阱是忘记对角线条目是 -1 并尝试将它们包含在按位运算中，这会破坏结果。 另一个微妙的问题是意外地使用 AND 而不是 OR； OR 是必需的，因为我们正在累积所需的位，而不是与它们相交。

 ## 边缘情况

 对于 n = 1，根本没有任何约束，因此任何值都是有效的。 该算法产生 0，因为空集的 OR 为 0，这符合非负整数的要求。 

对于某些行仅包含零的情况，例如与其他所有行进行“与”运算的节点为零，算法会分配 a[i] = 0。这是正确的，因为任何正位都会违反至少一对约束。 

对于许多条目共享重叠位的密集矩阵，OR 构造可确保包含所有强制位，而不会出现重复问题。 每个位都由至少一个观察到的对来证明是合理的，因此不会引入虚假位。
