 ## 问题理解

 我们正在模拟正六边形内的台球，其中运动具有完美的弹性：球沿直线行进，并以相等的入射角和反射角从边缘反射。 六边形以原点为中心，方向固定，运动从给定的内部点开始，具有均匀随机的初始方向。 

六个边中的三个是“开放”边界。 如果球击中这些开放边中的任何一个，它会立即离开多边形，并且过程结束。 其余三边表现正常，将球反射回六边形。 

该过程在离散碰撞事件中演变。 每次球击中一侧，我们就算一次碰撞。 任务是计算球在第 N 次碰撞时准确离开六边形的概率，这意味着它在前 N−1 次碰撞中幸存下来而不退出，并在第 N 次碰撞时立即退出。 

输入提供碰撞次数 N 和六边形内的起点。 位置仅对于确定第一个碰撞面的分布很重要，而后续行为取决于台球动力学。 

约束允许 N 最大为 100。这立即排除了对角度或几何形状的任何连续模拟。 模拟随机方向的简单方法是不可能的，因为答案是精确的概率，而不是估计，并且连续角度的状态空间是无限的。 

当 N = 0 时，会出现微妙的边缘情况。球无法在没有任何碰撞的情况下退出，因此除非起点已经位于开放边界上，否则概率为零，而通过保证该点严格位于六边形内部来明确排除这一点。 

另一个重要的微妙之处是，每次反射后，下一次碰撞的分布仅取决于当前边缘，而不取决于完整的历史记录或确切位置。 简单的几何模拟会错误地尝试跟踪连续坐标，这是不必要的并且在数值上不稳定。 

## 方法

 蛮力想法会尝试通过采样方向和跟踪反射来模拟所有可能的轨迹。 每个轨迹都是分段线性路径，我们将检查它是否在第 N 次碰撞时退出。 这在概念上是正确的，但无法精确计算，因为方向空间是连续的。 即使精细地离散角度也会导致计算量爆炸，并且仍然不会产生精确的概率。 

关键的结构观察是，具有弹性反射的正多边形中的台球运动可以展开为平面周期性平铺上的直线运动。 在此展开视图中，每次碰撞都对应于穿过六边形反射副本之间的边界线。 由于六边形是规则的，对称性迫使该过程在每次碰撞后忘记几乎所有几何细节。 剩下的只是哪一侧被击中，而不是发生在哪一侧。 

这将连续系统折叠成有限马尔可夫链。 每个状态对应于当前击中的一侧，并且每次转换对应于以由对称性确定的固定概率从一侧移动到另一侧。 其中三种状态是吸收状态（被移除的侧面），一旦进入，该过程就会停止。 

因此，问题简化为计算马尔可夫链恰好在步骤 N 处进入吸收状态的概率。这可以使用步骤和边上的动态规划来解决。
