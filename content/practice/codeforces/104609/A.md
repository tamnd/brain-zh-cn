 ## 解决方案
 ## 问题理解

 我们在无限六边形网格中得到一组位置，其中每个位置包含一组工蜂。 移动沿着六边形单元格的共享边缘发生，两个单元格之间的成本是在它们之间移动所需的最小移动次数。 我们必须为蚁后选择一个单元格，以便从该单元格到所有工人位置的距离总和最小。 

输入只是 N 个占用的六角形单元的列表。 输出是一个单元格坐标，可最小化从所有工人到女王位置的总行进距离。 

约束 N 高达 100,000 立即排除尝试每个可能的单元或计算所有成对距离的任何解决方案。 即使针对所有工人评估单个候选人职位也是 O(N)，因此对所有候选人的简单搜索将爆炸为 O(N^2)。 我们需要一个目标可以干净地分解为独立组件的结构。 

一个微妙的困难是，这是一个六角网格，而不是标准的曼哈顿网格。 粗心的方法可能会尝试将坐标独立地视为 x 和 y，而不考虑六角几何中的第三个隐式轴。 例如，在方形网格解释中看起来对角对齐的两个点实际上在六角系统中可能具有不同的真实距离。 另一个潜在的错误是假设平均坐标直接像欧几里得几何中一样工作，这在这里是无效的。 

## 方法

 一个蛮力的想法是尝试每个工人细胞作为女王位置的候选人。 对于每个候选者，我们计算到所有工人的十六进制距离之和。 由于计算总和需要 O(N) 距离计算并且有 N 个候选点，这会导致 O(N^2) 操作，这对于 10^5 点来说太慢了。 

关键的观察是六角网格坐标可以转换为 3D 立方体坐标系，其中距离变为三维的曼哈顿距离。 每个六角形单元 (x, y) 都可以映射到 (x, y, z)，约束条件为 x + y + z = 0，通常为 z = -x - y。 在这种表示下，两个六角形单元之间的距离成为三个坐标之间的最大绝对差，相当于跨三个轴的曼哈顿距离结构。 

一旦问题用立方体坐标表示，任务就变成最小化沿约束轴的距离总和。 应用一维优化的标准结果：绝对偏差之和在中值处最小化。 尽管完整的六角距离使用 max 结构，但它可以分解为三个线性投影，并且最优解在约束下与每个轴的中位数对齐。 

因此，我们不是搜索网格，而是将所有点转换为立方坐标，沿 x 和 y 计算中值，并隐式重建 z。 任何满足约束的坐标都会产生最佳单元。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N^2) | O(N^2) | O(1) | O(1) | 太慢了 |
 | 最优（立方+中位数）| O(N log N) | O(N log N) | O(N) | 已接受 |

 ## 算法演练

1. 将每个输入六角坐标 (x, y) 转换为立方坐标，将其视为 (x, y, z)，其中 z 源自 z = -x - y。 这种转换以一种更容易优化的方式保留了距离。 
2. 将所有 x 值和所有 y 值存储在单独的数组中。 我们并不明确需要 z，因为它是由约束确定的，一旦 x 和 y 固定，它就会自动对齐。 
3. 对两个数组独立排序。 排序是必要的，因为中位数是使一维绝对偏差之和最小的点。 
4. 选择 x 数组的中值作为候选 x 坐标。 如果 N 为偶数，则两个中间元素中的任何一个都会起作用，因为两者都同等地最小化绝对偏差。 
5. 以类似方式选择 y 数组的中值。 
6. 如果需要验证，则将 z 隐式计算为 -x - y，但输出只需要原始的 2D 十六进制坐标，因此我们直接输出选择的 (x, y)。 
7. 返回该坐标作为皇后的位置。 

我们可以独立处理 x 和 y 的原因是，六角距离结构一旦转换为立方坐标，就会分解为沿轴的加性贡献，并且每个轴都通过其中值独立最小化。 

### 为什么它有效

 在一维中，函数 sum |xi - c| 当 c 是 xi 值的中值时，最小化。 在立方体坐标中，每次移动都会导致沿约束轴的变化，并且总成本的行为就像这些轴上的绝对偏差的组合。 任一坐标中与中位数的任何偏差都会增加总成本，因为它会增加分布至少一侧的不平衡。 这确保选择中位数会在变换空间中产生全局最佳点，该点对应于原始网格中的最佳六角形单元。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    xs = []
    ys = []
    
    for _ in range(n):
        x, y = map(int, input().split())
        xs.append(x)
        ys.append(y)
    
    xs.sort()
    ys.sort()
    
    x_ans = xs[n // 2]
    y_ans = ys[n // 2]
    
    print(x_ans, y_ans)

if __name__ == "__main__":
    solve()
```该解决方案将坐标分成两个独立的数组，并使用排序来提取中位数。 关键的实现细节是使用 n // 2，它可以正确处理奇数和偶数情况，因为中心范围内的任何中位数都是有效的。 

一个常见的错误是试图平均坐标而不是取中位数。 这在平方欧几里得距离中有效，但在绝对距离目标下失败。 另一个错误是尝试直接模拟六角形距离，这是不必要的而且太慢。

 ## 边缘情况

 对于单个工人来说，最佳位置通常是同一个单元格，因为任何移动都会增加距离。 中值规则仍然返回两个数组中的唯一元素，因此算法自然地处理它而无需特殊的大小写。 

对于所有工人都位于同一垂直或水平线上的情况，问题会简化为一维中值问题。 该算法独立地减少了正确的轴，同时保持另一个轴固定，因此它仍然产生正确的平衡点。 

对于偶数 N，有两个有效中位数。 任何一个都是可以接受的，因为在中值区间内移动不会改变总的绝对偏差。 该算法使用 n // 2 隐式选择其中之一，这足以满足正确性要求。
