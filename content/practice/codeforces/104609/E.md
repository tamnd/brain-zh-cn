 ## 解决方案
 ## 问题理解

 我们以逆时针顺序给出严格凸多边形的顶点。 从这些顶点中，我们可以选择任意三个不同的顶点并形成一个三角形。 在所有这些三角形中，我们想要面积最大的三角形，并且我们必须输出该面积的两倍。 

几何图形是完全离散的：我们不是选择边上或多边形内部的任意点，而是选择给定的顶点。 因为多边形是凸的并且顶点已经排序，所以我们可以将该结构视为循环序列，其中沿着索引向前移动对应于绕边界行走。 

约束是关键信号。 顶点数量可以多达20,000个，并且有多个测试用例。 任何尝试所有顶点三元组的解决方案都会立即变得不可行，因为这将需要大约 n3 次操作，这是一个天文数字。 即使是 O(n²) 方法（在最坏的情况下已经涉及大约 4×10⁸ 检查）在 Python 中也太慢，并且即使在多个测试用例下优化的 C++ 中也非常紧。 

正确的解决方案必须大量利用凸性并避免重复重新考虑相同的几何比较。 

还有一个微妙的几何要求：输出是面积的两倍，并保证是整数。 这意味着我们可以通过叉积安全地使用整数运算，而不会出现浮点精度问题。 

一些边缘情况在概念上很重要。 当多边形本身是三角形时，只有一个有效答案。 幼稚的实现可能仍会尝试搜索并意外覆盖正确的结果或错误处理环绕索引。 

另一个有问题的情况是当多边形非常大但几乎平坦时，其中许多候选三角形具有非常相似的面积。 任何错误地假设局部选择是独立的算法都可能在这里失败，因为最佳三角形可能涉及沿船体相距较远的顶点，而不是相邻的顶点。 

## 方法

 最直接的想法就是尝试每一个三元组的顶点。 对于每个三元组 i、j、k，我们使用叉积公式计算三角形面积并保留最大值。 这是正确的，因为它评估了所有可能性，但每个测试用例花费 O(n3) 时间。 当n达到20000时，这是完全无法使用的。 

一个自然的改进是固定两个顶点并尝试最佳地选择第三个顶点。 对于固定的 i 和 j，三角形 (i, j, k) 的面积在凸包周围的角度排序方面与 k 线性相关，这表明当我们沿着多边形向前移动 k 时，面积首先增大然后减小。 这种单峰行为是凸性给我们提供的核心几何结构。 

一旦我们接受对于固定对 (i, j)，可以通过向前移动直到面积停止增加来找到最佳 k，我们就得到了两个指针的想法。 然而，如果我们对每对 (i, j) 独立地重新开始搜索，我们仍然会得到 O(n²) 次转换，这太大了。 

最终的改进来自于全局单调性：当我们沿着凸包向前移动 i 时，最优的 j 和 k 位置也向前移动，并且永远不需要向后移动。 这允许我们使用旋转卡钳式扫描，其三个指针仅前进，因此每个索引在整个扫描中最多前进恒定的次数。 这将摊余复杂度压缩为每个测试用例的线性时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解三倍 | O(n3) | O(1) | O(1) | 太慢了 |
 | 每对两指针 | O(n²) | O(1) | O(1) | 太慢了 |
 | 旋转卡尺（3 指针）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

我们依赖这样一个事实：三角形 (a, b, c) 的面积可以通过向量 (b − a) 和 (c − a) 的叉积来计算，并且该值与有符号面积成正比。 

1. 我们将多边形视为循环，因此索引围绕模 n 进行环绕，有效地处理双倍数组。 这可以避免当指针移过末尾时显式处理换行情况。 
2. 我们固定起始顶点 i 并尝试以循环顺序找到最佳对 (j, k)，其中 i < j < k，从而最大化三角形面积。 我们不是重新开始搜索每个 i，而是从先前的位置向前移动指针。 
3. 我们初始化 j = i + 1 和 k = i + 2。它们形成底边从 i 开始的最小可能三角形。 
4. 对于当前(i, j)，我们将k向前移动，同时三角形(i, j, k + 1)的面积严格大于(i, j, k)的面积。 这是有效的，因为对于固定基边 (i, j)，凸多边形上的 k 函数在循环顺序中是单峰的。 
5. 一旦 k 对于 (i, j) 是局部最优的，我们就使用三角形 (i, j, k) 更新全局答案。 
6. 然后我们将 j 前进一步并确保 k 始终领先于 j。 如果需要，我们进一步增加 k 以使 j < k 成立。 
7. 我们对所有 i 重复该过程，确保 j 和 k 只沿着船体向前移动，而不会向后重置。 

这种方法起作用的关键结构原因是，在严格凸多边形中，当基顶点 i 向前移动时，最佳支撑顶点的方向沿着船体单调移动。 这可以防止最优 j 或 k “向后跳跃”，而这正是允许摊销线性行为的原因。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def area2(a, b, c):
    return abs(cross(b[0] - a[0], b[1] - a[1],
                     c[0] - a[0], c[1] - a[1]))

def solve(poly):
    n = len(poly)
    if n == 3:
        a, b, c = poly
        return area2(a, b, c)

    ans = 0

    for i in range(n):
        j = (i + 1) % n
        k = (i + 2) % n

        for _ in range(n - 1):
            while True:
                nk = (k + 1) % n
                if nk == i:
                    break
                if area2(poly[i], poly[j], poly[nk]) >= area2(poly[i], poly[j], poly[k]):
                    k = nk
                else:
                    break

            ans = max(ans, area2(poly[i], poly[j], poly[k]))

            nj = (j + 1) % n
            if nj == i:
                break
            j = nj
            if k == j:
                k = (k + 1) % n

    return ans

def main():
    data = sys.stdin.read().strip().split()
    idx = 0
    out = []
    while idx < len(data):
        n = int(data[idx])
        idx += 1
        if n == 0:
            break
        poly = []
        for _ in range(n):
            x = int(data[idx]); y = int(data[idx + 1])
            idx += 2
            poly.append((x, y))
        out.append(str(solve(poly)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```该解决方案是围绕维护在凸包上向前移动的三个索引而构建的。 这`area2`函数使用叉积计算两倍的三角形面积，这完全避免了浮点运算。 

内循环在哪里`k`先进的是旋转卡钳步骤。 只要三角形面积增加，它就会尝试将第三个顶点向前推动。 由于凸性，一旦这个条件失败，对于同一个固定对来说，它不会再次变得更好`(i, j)`。 

的外运动`j`确保我们从顶点探索所有候选碱基`i`。 关键的实施约束是维持循环有效性并防止`k`从落后`j`，这会破坏三角形结构。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    def cross(ax, ay, bx, by):
        return ax * by - ay * bx

    def area2(a, b, c):

        n = len(poly)
        ans = 0
        for i in range(n):
            for j in range(i+1, n):
                for k in range(j+1, n):

            idx += 2
            poly.append((x,y))
        outs.append(str(solve(poly)))
    return "\n".join(outs)

 ## 边缘情况

 关键的边缘情况是多边形恰好具有三个顶点。 该算法不得尝试指针移动，而应直接返回三角形区域。 在这种情况下，初始化已经将 i、j、k 设置为唯一有效的三元组，并且改进循环不会改变任何内容。 

另一个微妙的情况是当多个连续顶点为 k 产生相等面积的过渡时。 因为多边形是严格凸的并且没有三点共线，所以仅由于整数算术对称性才发生相等，并且算法仍然正确地进行，因为它允许 k 的非递减移动。 

最后的边缘情况是当 i 接近数组末尾时的环绕行为。 循环索引确保 j 和 k 正确地继续到数组的开头而不破坏顺序，并且终止条件保证我们永远不会重用三角形中的顶点 i，从而保持有效性。
