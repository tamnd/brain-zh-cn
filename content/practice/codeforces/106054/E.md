 ## 解决方案
 ## 问题理解

 我们有一棵以节点 1 为根的树。除根之外的每个节点都以放置在其上的一定数量的士兵开始。 时间以离散的轮流演变。 在每一回合，胡安都有一个决定：要么立即停止并攻击单个节点，要么什么也不做，让所有士兵沿着树中唯一的路径向根移动一步。 

如果胡安在某个时刻发起攻击，游戏就会结束，他会收集当前坐在所选节点上的所有士兵。 根无法被攻击，因此它只与移动的士兵最终聚集的水槽相关。 

关键是士兵不是一成不变的。 每转一圈，每个士兵都会向根部移动一条边。 因此，从某个节点开始的士兵逐渐向上爬，直到到达根部，然后停留在那里。 

Juan 想要选择一个节点和一个停止时间，以便在该确切时间坐在该节点上的士兵数量最大化。 在尽可能多地收集士兵的所有方法中，他希望尽量减少攻击前等待的回合数。 

这些约束允许最多二十万个节点，这会立即排除任何随着时间的推移模拟过程或在二次时间内重新计算每个查询的贡献的解决方案。 任何试图分别重新计算每个可能的时间步或每个节点的完整状态的方法都会超出时间限制几个数量级。 该解决方案必须在单次传递中聚合对树结构的贡献，或者每个节点的开销接近线性。 

当多个节点在不同时间产生相同的最大士兵数量时，就会出现微妙的失败情况。 一种仅跟踪每个节点的最佳总和而不跟踪时间维度的天真的贪婪方法很容易错误地选择稍后的时间。 

另一个常见的错误是假设对节点做出贡献的士兵仅来自零时刻的子树。 这是不正确的，因为移动取决于到根的距离，而不是相对于目标节点的子树成员资格。 

例如，如果节点 v 的深度为 3 并且我们等待两轮，那么我们不仅仅考虑 v 的子树。 我们必须考虑所有节点，其原始位置允许它们在两次向上移动后精确落在 v 处，这是一个非常具体的深度对齐条件。 

## 方法

 强力解释是随着时间的推移模拟该过程。 对于每个时间 t，我们计算 t 次移动后每个士兵的位置，然后尝试攻击每个节点并计算当前有多少士兵。 这需要重新计算每个时间步的所有士兵的所有位置。 由于每个士兵每回合向上移动一条边，模拟 T 个步骤的成本为 O(NT)，并且在最坏的情况下 T 也可以是 O(N)，从而给出 O(N^2) 行为，这对于 2 × 10^5 节点来说远远超出了可接受的范围。 

关键的结构观察是，运动是确定性的，并且纯粹基于深度，朝向根部。 从节点 u 开始的士兵将在 t 圈后沿着到根的路径到达距离 t 处的祖先。 这意味着我们不用模拟运动，而是可以逆向推理：固定一个节点v和时间t，然后询问当时哪些原始节点为v贡献了士兵。 

来自节点 u 的士兵在时间 t 对 v 做出贡献，此时 v 位于从 u 到根的路径上并且从 u 到 v 的距离等于 t。 这转化为一个干净的深度关系：如果深度（v）是d，那么u必须位于v的子树中并且具有深度d + t。 因此，贡献仅取决于对按深度分组的子树中的节点进行计数。 

这将问题简化为计算每个节点 v 的深度 d(v) + k 处 v 子树中所有士兵的所有深度偏移量 k 的最佳总和。 该对的答案对应于在时间 k 的攻击。

这种结构非常适合基于 DFS 的子树聚合，其中我们维护深度频率表并使用从小到大的技术组合子节点，以便每个节点有效地为合并结构做出贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 随着时间的推移暴力模拟| O(N^2) | O(N^2) | O(N) | 太慢了 |
 | DFS+从小到大深度聚合 | O(N log N) | O(N log N) | O(N log N) | O(N log N) | 已接受 |

 ## 算法演练

 我们以节点 1 为树的根，并使用 DFS 计算每个节点的深度。 这个深度是关键坐标，因为每个士兵的运动都可以表示为距根的距离的函数。 

然后，我们执行第二个 DFS，其中每个节点维护一个结构，将深度映射到其子树中该深度的士兵总数。 

1. 我们从根目录启动DFS。 对于每个节点，我们首先递归处理所有子节点，以便我们已经知道它们的深度分布。 这确保了我们总是将较小的计算结构合并为较大的计算结构，从而使复杂性保持接近线性。 
2.对于每个节点v，我们用它的直接贡献来初始化它自己的结构：最初放置在v处的士兵对深度深度(v)做出贡献。 这形成了合并的基本情况。 
3. 对于 v 的每个子 c，我们将 c 的深度图合并到 v 中。合并时，代表 c 子树中深度 d 处的某个节点 u 的每个条目都将移位到 v 的坐标系中，但由于深度从根开始是全局的，因此除了索引一致性之外不需要显式移位。 我们简单地合并计数。 
4. 合并时，对于 v 的当前子树结构中存在的每个深度 d，我们将其视为候选时间偏移 k = d − 深度(v)。 这对应于在 k 回合后攻击 v。 我们累积该配置的士兵总数并更新 v 的最佳答案。 
5. 处理完所有子节点后，v 处的结构完全表示其子树中按深度分组的所有节点。 我们从所有深度级别中提取最佳对（士兵总数，最短时间）。 

全局答案是所有节点中最好的。 

### 为什么它有效

 在任何固定节点 v 处，士兵在 k 移动后到达 v 的唯一方式是，它从某个后代 u 开始，该后代 u 到根的路径经过 v，并且其向上距离恰好等于 k。 此条件迫使 u 位于 v 的子树中，并具有相对于 v 的固定深度。因此，每个有效贡献在子树深度直方图中仅捕获一次。 由于每个子树都是独立处理和合并的，不会丢失多重性，因此该算法保留了所有可能时间的精确计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

N = int(input())
T = [0] + list(map(int, input().split()))

g = [[] for _ in range(N + 1)]
for _ in range(N - 1):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)

depth = [0] * (N + 1)

def dfs_depth(u, p):
    for v in g[u]:
        if v == p:
            continue
        depth[v] = depth[u] + 1
        dfs_depth(v, u)

dfs_depth(1, 0)

ans_val = 0
ans_time = 0

from collections import defaultdict

def dfs(u, p):
    global ans_val, ans_time
    mp = defaultdict(int)

    mp[depth[u]] += T[u]

    for v in g[u]:
        if v == p:
            continue
        child_mp = dfs(v, u)

        if len(child_mp) > len(mp):
            mp, child_mp = child_mp, mp

        for d, val in child_mp.items():
            mp[d] += val

    best_local = {}
    for d, val in mp.items():
        k = d - depth[u]
        if k < 0:
            continue
        if val > ans_val or (val == ans_val and k < ans_time):
            ans_val = val
            ans_time = k

    return mp

dfs(1, 0)

print(ans_val, ans_time)
```第一个 DFS 计算根距离，以便每个节点的位置都在一致的坐标系中表示。 第二个 DFS 为每个子树构建聚合深度图。 每个地图条目代表该子树内特定深度的总士兵数，它直接对应于经过一定次数的转弯后该节点可能到达的配置。 

当子映射大于当前映射时，从小到大的合并策略隐含在交换字典中。 当将大型结构反复合并为小型结构时，这可以防止二次爆炸。 

每个节点内的更新步骤使用 k = d − 深度[u] 将深度值转换为候选时间，该候选时间与这些士兵到达节点 u 所需的向上移动次数相匹配。 

## 工作示例

 考虑一个由三个节点组成的简单链：1 连接到 2，连接到 3，节点 2 和 3 上都有士兵。 

在节点 3 处，其子树中的深度值仅包括其自身。 所以立即进攻只会产生自己的士兵。 如果我们等待一回合，节点 2 的士兵就会移动到节点 3，从而增加其总数。 下表显示了贡献如何演变。 

| 节点| 深度 | 最初的士兵| 0 圈后 | 1回合后|
 | --- | --- | --- | --- | --- |
 | 3 | 2 | 1 | 1 | 3 |
 | 2 | 1 | 2 | 2 | 2 |

 在节点 3 处，最好是在一圈之后。 

现在考虑一个分支情况，其中节点 2 有两个具有不同深度和士兵数量的子节点。 

| 节点| 深度 | 士兵|
 | --- | --- | --- |
 | 2 | 1 | 2 |
 | 3 | 2 | 3 |
 | 4 | 2 | 4 |

 在节点 2 处，零圈后仅节点 2 做出贡献。 一圈后，节点 3 和 4 起作用，但仅限于深度正确对齐的节点。 该算法在基于深度的分组下正确聚合了这两种贡献。 

这些示例表明，时序纯粹以深度差异进行编码，并且子树聚合足以重建所有可能的到达状态。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N log N) | O(N log N) | 每个节点的深度图都使用从小到大的方式进行合并，因此每个元素都会移动对数次 |
 | 空间| O(N) | 每个节点通过递归对全局聚合结构贡献一次|

 复杂性完全符合 2 × 10^5 节点的限制，因为每个合并操作都会分摊，并且没有节点的处理次数超过对数次数。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    from collections import defaultdict

    input = _sys.stdin.readline
    N = int(input())
    T = [0] + list(map(int, input().split()))

    g = [[] for _ in range(N + 1)]
    for _ in range(N - 1):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    depth = [0] * (N + 1)

    def dfs_depth(u, p):
        for v in g[u]:
            if v == p:
                continue
            depth[v] = depth[u] + 1
            dfs_depth(v, u)

    dfs_depth(1, 0)

    ans_val = 0
    ans_time = 0

    def dfs(u, p):
        nonlocal ans_val, ans_time
        mp = defaultdict(int)
        mp[depth[u]] += T[u]

        for v in g[u]:
            if v == p:
                continue
            child = dfs(v, u)
            if len(child) > len(mp):
                mp, child = child, mp
            for d, val in child.items():
                mp[d] += val

        for d, val in mp.items():
            k = d - depth[u]
            if k < 0:
                continue
            if val > ans_val or (val == ans_val and k < ans_time):
                ans_val = val
                ans_time = k

        return mp

    dfs(1, 0)
    return str(ans_val) + " " + str(ans_time)

 ## 边缘情况

 当最佳答案出现在时间零时，就会出现关键的边缘情况。 在这种情况下，不需要移动，最佳节点就是在其自身深度的子树中已经包含最大和的节点。 该算法处理此问题是因为当 d 等于深度[v] 时 k = d − 深度[v] 变为零，因此初始状态自然包含在候选检查中。 

当多个节点在不同时间产生相同的最大士兵数量时，会出现另一种边缘情况。 打破平局的规则要求选择最短的时间。 由于我们仅在找到严格较大的值或该值相等且时间较小时进行更新，因此较早出现的情况会被正确保留。 

最后，在倾斜的树中，深度图变成深链。 如果没有从小到大的合并，这将退化为二次行为。 交换步骤确保较小的映射始终合并为较大的映射，从而保证每个键仅以对数方式移动多次。
