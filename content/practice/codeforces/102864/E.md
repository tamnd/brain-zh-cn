 ## 解决方案
 ## 问题理解

 我们在平面上有一组整数坐标点。 没有三点位于同一条线上。 我们需要选择其中两个点，以便穿过它们的线将所有其他点分为可能大小相等的两组。 更准确地说，如果所选线路离开`n - 2`剩余的点，线的每一边必须恰好包含`floor((n - 2) / 2)`点。 

输出仅是两个选定点的索引。 如果不存在这样的对，我们应该输出`-1 -1`。 

约束条件`n <= 100000`改变我们思考问题的方式。 检查每对点已经给出了`10^10`候选线，远远超出了一秒的限制。 即使通过对剩余点的线性扫描来检查所有对也需要大约`10^15`运营。 解必须接近线性或`O(n log n)`，这意味着我们需要避免搜索对，而是直接找到有保证的好对。 

一个常见的错误是假设答案必须涉及特殊的几何结构，例如凸包。 所选线可以是通过两个输入点的任意线，平衡条件仅取决于每侧出现多少个点。 关键是利用围绕单个点的方向的循环排序。 

有一些边界情况可能会破坏粗心的实现。 

为了`n = 2`，没有剩余积分。 通过两点的任何直线都满足条件，因此答案应该是两点索引。 假设角度数组中必须存在中点的解决方案在这里可能会失败。 

例如：```
2
0 0
1 1
```正确的输出是：```
1 2
```尝试访问其他点列表的中间元素的解决方案将访问空列表。 

另一个边缘情况是当`n`很奇怪。 双方不需要有相同的点数，因为`floor((n - 2) / 2)`故意忽略额外的分数。 

例如：```
5
0 0
1 0
2 0
3 1
4 2
```不是有效输入，因为三个点共线，但它说明了错误推理相等一半的危险。 在有效的五点配置中，所选线仅需要一侧包含`1`点和另一侧包含`2`点。 仅搜索完全相等的分割的粗心实现会错误地拒绝有效答案。 

大坐标是另一个实现细节。 坐标可以达到`10^9`，所以叉积可以达到大约`10^18`。 Python 整数可以安全地处理这个问题，而固定宽度整数实现需要 64 位类型。 

## 方法

 直接方法会尝试每对可能的点。 对于每一对，我们可以使用叉积来计算有多少个其他点位于该线的左侧和右侧。 这是正确的，因为条件正是关于这两个计数的陈述。 然而，有`O(n^2)`可能的对，并且每对都需要`O(n)`检查，导致`O(n^3)`工作。 和`n = 100000`，这是不可能的。 

重要的观察是我们实际上不需要在所有对之间进行搜索。 选取任意点作为枢轴。 查看来自该枢轴的所有其他点，并按它们围绕枢轴的极角对它们进行排序。 对于从枢轴到这些点之一的射线，按循环顺序出现在它前面的每个点都位于相应线的一侧，而它之后的每个点都位于另一侧。 

由于输入保证没有三个点共线，因此没有其他点可以完全位于所选线上。 这意味着角序中点的位置直接告诉我们线一侧的点数。 

如果其他点按角度递增顺序存储，则选择索引处的点`floor((n - 2) / 2)`准确给出了它之前所需的点数。 因此，从枢轴到该点的线始终是有效答案。 

暴力解决方案之所以有效，是因为它明确地检查了所需的平衡条件，但因为它多次重复相同的几何计数而失败。 角度排序观察消除了逐一测试候选者的需要，并将问题转化为一个排序操作。

 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 选择任意输入点作为枢轴。 如果`n = 2`，立即输出两个点，因为每边所需的点数为零。 
2. 构建从枢轴到所有其他点的向量。 每个向量都保留原始点索引，因为最终答案需要索引而不是坐标。 
3. 根据这些向量绕枢轴的方向对这些向量进行排序。 排序是使用叉积而不是浮点角度来完成的。 半平面分割将向量按一致的循环顺序放置，叉积决定同一半平面内的顺序。 
4.让`k = floor((n - 2) / 2)`。 选择位置处的点`k`在排序后的向量列表中。 

这个立场之所以正确，是因为`k`矢量出现在它之前。 这些向量准确地表示`k`从枢轴到选定点的线一侧的点。 

1. 输出枢轴索引和所选点索引。 

为什么它有效：

 角度排序为每个其他点提供了围绕枢轴的唯一位置，因为没有三个点共线。 对于由枢轴和排序位置处的点形成的线`k`，顺序中每个较早的点的方向都在正参考方向和所选方向之间，因此它们都位于同一侧。 后面的每个点都位于相反的一侧。 正好有`k`前面的几点，以及`k = floor((n - 2) / 2)`，这样就达到了所需要的划分。 

## Python 解决方案```python
import sys
from functools import cmp_to_key

input = sys.stdin.readline

def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    n = int(data[0])
    points = []
    ptr = 1
    for i in range(n):
        x = int(data[ptr])
        y = int(data[ptr + 1])
        ptr += 2
        points.append((x, y))

    if n == 2:
        print(1, 2)
        return

    px, py = points[0]
    vectors = []

    for i in range(1, n):
        x, y = points[i]
        vectors.append((x - px, y - py, i))

    def half(x, y):
        if y > 0 or (y == 0 and x >= 0):
            return 0
        return 1

    def cmp(a, b):
        ax, ay, _ = a
        bx, by, _ = b

        ha = half(ax, ay)
        hb = half(bx, by)

        if ha != hb:
            return -1 if ha < hb else 1

        cross = ax * by - ay * bx
        if cross > 0:
            return -1
        if cross < 0:
            return 1
        return 0

    vectors.sort(key=cmp_to_key(cmp))

    k = (n - 2) // 2
    answer = vectors[k][2] + 1
    print(1, answer)

if __name__ == "__main__":
    solve()
```代码将枢轴固定为第一个点，这已经足够了，因为该参数适用于任何枢轴。 矢量存储相对于该枢轴的坐标，因此叉积的符号直接描述两个方向的方向。 

比较器避免`atan2`因为浮点角度是不必要的并且可能会引入精度问题。 半平面分割使循环顺序从正 x 方向开始，并防止相反方向的矢量混合在一起。 然后，叉积给出每一半内的精确排序。 

指数计算采用`(n - 2) // 2`。 向量数组包含`n - 1`点，因为枢轴被移除，所以索引`k`始终有效。 决赛`+ 1`将存储的从零开始的索引转换回问题所需的从一开始的索引。 

Python整数是任意精度的，因此坐标附近引起的大叉积`10^9`不要溢出。

 ## 边缘情况

 对于两个点，该算法从不尝试创建角度排序。 它立即返回唯一可能的行。 这可以避免访问空列表并符合零点必须出现在两侧的事实。 

对于奇数个点，选择的索引基于整数除法。 例如，与`n = 5`，目标边数为`floor(3 / 2) = 1`。 该算法选择角度顺序中的第二个点，在其前面留下一个点，在其后面留下两个点。 两侧允许有不同的尺寸，因此这是有效的分割。 

对于最大范围内的坐标，叉积可以约为`4 * 10^18`。 该实现使用 Python 整数，因此比较保持准确，并且没有精度损失改变排序。 

对于任意点分布，包括枢轴位于凸包内部或外部的情况，证明仍然适用。 该解决方案从不依赖于特殊的枢轴。 它仅使用围绕该枢轴的方向的循环顺序，当没有三个点共线时，这种顺序始终存在。
