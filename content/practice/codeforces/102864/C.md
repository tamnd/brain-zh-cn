 ## 解决方案
 ## 问题理解

 我们有一个初始数组`A`具有唯一值和目标数组`B`，也具有独特的价值观。 操作选择一个位置并将其当前值替换为另一个整数，但数组必须在每次操作后保持所有值不同。 任务是输出变化的最短操作序列`A`进入`B`。 

一个值已经正确的位置永远不需要被触及。 困难来自于需要当前存储在其他地方的值的位置。 如果需要的值被占用，我们不能直接写入它，因为过程中禁止重复值。 

所有数组的总大小可以达到 200 万个元素，因此具有二次行为的方法是不可能的。 即使是具有十万个位置的单个测试用例也排除了重复搜索数组或模拟许多可能的选择的可能性。 我们需要一个接近线性时间的解决方案。 

有少数情况很容易处理不当。 如果每个位置都已经正确，则答案是零操作。 例如：```
A = [5, 7]
B = [5, 7]
```正确的输出是一个空序列。 总是为循环创建辅助操作的解决方案在这里是错误的。 

一个更微妙的情况是闭环：```
A = [1, 2]
B = [2, 1]
```答案不可能是两次操作。 将第一个位置更改为`2`是非法的，因为`2`仍然存在。 需要一个临时值，因此最少需要 3 次操作。 

另一个重要的案例是链条：```
A = [1, 2, 3]
B = [2, 3, 4]
```正确的最小值是三个操作。 最后的位置可以变成`4`首先，释放`3`，那么之前的位置就可以变成`3`，最后第一个位置可以变成`2`。 以相反的顺序处理该链将会失败。 

## 方法

 直接方法会重复找到一个已经可以更改为其最终值的位置并执行该操作。 如果不存在这样的位置，我们可以搜索临时值并打破依赖关系。 这个想法是正确的，因为每个操作要么永久地赋予价值，要么为未来的操作创造空间。 

问题在于，幼稚的实现会不断寻找可用的位置。 在最坏的情况下，长度较长的依赖链`n`可以多次强制扫描几乎整个阵列。 和`n = 100000`，这可以逼近`O(n^2)`工作，远远超出了允许的范围。 

关键的观察结果是，不正确的位置形成了依赖关系图。 每个错误位置从其当前值到其所需值都有一个优势。 由于两个数组中的所有值都是唯一的，因此每个值最多有一个传出边缘和最多一个传入边缘。 每个组件要么是一条路径，要么是一个循环。 

路径有一个端点，另一个错误位置当前不需要该端点的目标值。 我们可以从最后向后解析这样的组件。 循环没有自由值，因此需要一个额外的临时值来打破它。 每一个错误的位置都需要至少一次操作，而每个循环正好需要一次额外的操作，因此这种结构是最优的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 根据中的每个值构建映射`A`到它的位置。 对于每个位置`A[i]`不同于`B[i]`，创建对当前持有位置的依赖`B[i]`如果这个立场也错了。 

该依赖图准确地描述了哪些值相互阻塞。 
2. 计算每个错误位置的进入度。 传入度数为零的位置是链的起点。 

这些是当前缺少某些所需值的组件，因此不需要临时值。 
3. 对于每个链的开始，遵循依赖指针并按顺序存储位置。 沿着链以相反的顺序输出操作。 

链中的最后一个元素是唯一可以立即更改的元素。 先前的每个操作在其所需的值被释放后才变得可能。 
4、处理完链后，剩余的每一个未访问过的错误位置都属于一个循环。 

选择初始数组中不存在的值作为临时值。 对于一个循环，将第一个位置移动到临时值，将所有其他值旋转到其最终位置，然后将临时值移动到剩余的最终位置。 
5. 输出这些步骤创建的所有操作。 

为什么有效：每个错误位置至少更改一次，因此任何解决方案都不能使用少于错误位置的数量作为基础。 由于链包含自由端，因此每个位置只需一次操作即可精确求解链。 如果不引入新值，则无法解决循环，因为每个目标值都在循环内被占用。 该算法为每个这样的循环恰好添加一个额外操作，并且不会产生不必要的更改，因此操作数量最少。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans_all = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        pos = {x: i for i, x in enumerate(a)}

        wrong = [False] * n
        for i in range(n):
            if a[i] != b[i]:
                wrong[i] = True

        nxt = [-1] * n
        indeg = [0] * n

        for i in range(n):
            if wrong[i] and b[i] in pos and wrong[pos[b[i]]]:
                nxt[i] = pos[b[i]]
                indeg[nxt[i]] += 1

        ops = []
        visited = [False] * n

        for i in range(n):
            if wrong[i] and indeg[i] == 0:
                cur = i
                path = []
                while cur != -1 and not visited[cur]:
                    visited[cur] = True
                    path.append(cur)
                    cur = nxt[cur]

                for x in reversed(path):
                    ops.append((x + 1, b[x]))

        temp = 1000000000
        used = set(a)
        while temp in used:
            temp -= 1

        for i in range(n):
            if wrong[i] and not visited[i]:
                cycle = []
                cur = i
                while not visited[cur]:
                    visited[cur] = True
                    cycle.append(cur)
                    cur = nxt[cur]

                ops.append((cycle[0] + 1, temp))

                for j in range(len(cycle) - 1, 0, -1):
                    ops.append((cycle[j] + 1, a[cycle[j - 1]]))

                ops.append((cycle[0] + 1, b[cycle[0]]))

        ans_all.append(str(len(ops)))
        for x, y in ops:
            ans_all.append(f"{x} {y}")

    sys.stdout.write("\n".join(ans_all))

if __name__ == "__main__":
    solve()
```字典`pos`为任何值的所有者提供恒定的时间访问权限。 依赖数组`nxt`仅在不正确的位置之间构建，因为正确的位置已经包含其最终值并且永远不需要移动。 

第一次遍历处理路径。 相反的顺序是关键细节：更改最后一个位置会释放前一个位置所需的值。 

循环处理使用原始值之外的一个临时值。 第一步从数组中删除循环的起始值，使轮换合法。 最后一步将临时价值持有者恢复到目的地。 

仅当存储在答案中时，实现中的所有索引才会从从零转换为从一。 该算法永远不需要修改实际的数组，因为依赖结构已经捕获了整个转换。 

## 工作示例

 对于：```
A = [1, 2]
B = [2, 1]
```依赖循环为：

 | 步骤| 当前组件 | 运营|
 | ---| ---| ---|
 | 1 | 1 -> 2, 2 -> 1 | 1 -> 2, 2 -> 1 | 位置 1 成为临时 |
 | 2 | 值 1 是免费的 | 位置 2 变为 1 |
 | 3 | 临时保留原件 1 | 位置 1 变为 2 |

 出现额外操作是因为没有空闲端点。 轨迹证实了循环规则。 

为了：```
A = [1, 2, 3]
B = [2, 3, 4]
```依赖链是：

 | 步骤| 已处理职位 | 运营|
 | ---| ---| ---|
 | 1 | 位置 3 | 3 变成 4 |
 | 2 | 位置 2 | 2 变成 3 |
 | 3 | 位置 1 | 1 变成 2 |

 该跟踪显示了为什么路径被向后处理。 每个操作都会创建下一个位置所需的值。

 ## 边缘情况

 对于已经解出的数组，例如`A=[5,7]`和`B=[5,7]`，每个位置都被标记为正确。 没有创建图形边，答案仍为空。 

对于循环`A=[1,2]`,`B=[2,1]`，两个位置都有传入和传出边缘，因此不存在链起点。 剩余的组件被检测为一个周期并恰好接收一个临时操作。 

对于链条`A=[1,2,3]`,`B=[2,3,4]`，最后一个位置没有传入边，因为`4`不存在。 它成为链的起点，并且反转收集的路径会产生唯一合法的操作顺序。 

对于临时候选值已经存在的情况，例如包含的数组`1000000000`，该实现会减少候选数，直到找到未使用的整数。 这使临时搬迁保持合法。
