 ## 解决方案
 ## 问题理解

 我们得到以原点为中心的圆内的点。 每个点代表一个顶部并且具有可以是正数或负数的数值。 我们可以选择由从原点开始的两条射线定义的披萨片，这意味着我们选择一个角度间隔，并选取从原点开始的方向位于该间隔内的每个配料。 边界上的一切都包括在内。 

切片具有几何约束：其面积不能超过给定的限制。 由于切片是一个扇形，因此它的面积与其角度成正比。 这将约束变成了我们可以选择的角度间隔的上限。 

对于任何有效的切片，我们将其内所有点的值相加。 切片的分数就是这个总和的绝对值。 任务是选择满足面积约束的最佳可能角度间隔并最大化该绝对和。 

输入大小很大，所有测试用例最多有 3×10^5 个点。 这立即排除了作为角度边界的点对的任何二次枚举。 任何尝试测试所有光线对或从头开始为每个候选间隔重新计算总和的解决方案都会太慢。 

主要的微妙之处在于，我们不是在具有固定端点的线段上最大化简单的总和，而是在圆形域上最大化。 区间可以围绕角度 0 方向，这使得朴素的线性滑动窗口推理不完整，除非我们仔细处理圆形性质。 

典型的失败案例来自于忽略环绕。 假设两个高值簇位于角度 0.01 和 6.27 弧度附近。 对排序角度进行简单的线性扫描会将它们视为相距很远，即使跨越 2π 边界的小切片可以包括两者。 任何不复制或以其他方式模拟循环连续性的解决方案都将错过此类最佳切片。 

另一个常见的错误是忽略绝对值。 如果仅跟踪最大和子阵列，则负重区域将被忽略，即使强负切片可以产生比任何正切片更大的绝对值。 

## 方法

 强力方法会选择每对顶部作为潜在的边界射线，计算它们定义的角度间隔，然后对位于内部的所有点求和。 即使我们预先计算角度并使用前缀和，我们仍然需要测试 O(n^2) 间隔，并且在最坏的情况下检查循环结构中每个间隔的有效性仍然需要线性时间。 如果直接执行，这会导致大约 O(n^3) 行为，或者优化范围查询会导致 O(n^2) 行为，两者都远远超出了限制。 

关键的观察结果是只有角度顺序很重要。 一旦按角度对点进行排序，任何有效切片都对应于该循环排序上的连续段，并附加一个约束，即角宽度不超过从区域限制导出的固定阈值。 

这将问题简化为在圆形数组上查找最大绝对和子数组，并附加了子数组长度是根据角距离而不是索引距离定义的额外约束。 一旦角度被排序，角度距离就会沿着数组变得单调，从而允许两个指针滑动窗口。 

然后，我们通过复制圆形数组将其转换为线性数组。 这使得环绕间隔成为双倍数组中的标准间隔。 在这个结构内部，我们维护一个始终满足角宽度约束的滑动窗口。 对于每个右端点，我们根据需要推进左端点并维护运行总和。 答案是任何有效窗口总和的最大绝对值，因此我们跟踪最大和最小总和。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 log n) 或更糟 | O(n) | 太慢了|
 | 最优滑动窗口| 每次测试 O(n log n) | O(n) | 已接受 |

 ## 算法演练

 ### 步骤 1：将面积约束转换为角度限制

 半径为 r、角度为 θ 的扇形面积为 (1/2) r^2 θ。 由此我们计算 θmax = 2A / r^2。 任何有效切片的角宽度不得超过 θmax。 

### 步骤2：计算所有点的极角

 对于每个顶部，使用 atan2(y, x) 计算其角度。 这将每个点放置在区间 [0, 2π) 上。 

此步骤至关重要，因为切片约束仅取决于距原点的方向，而不取决于距离。 

### 步骤 3：按角度对点进行排序

 我们按极角对所有点进行排序。 排序后，任何没有回绕的有效切片都对应于此排序中的连续段。 

排序是将几何图形转换为一维结构，使窗口化成为可能。 

### 步骤 4：复制数组以处理循环换行

 我们再次附加每个点，角度增加 2π。 这会将圆形间隔转换为线性间隔：任何环绕切片都成为此扩展数组中的正常段。 

此步骤确保我们不会错过穿过 0 角度边界的切片。 

### 步骤 5：使用两指针窗口强制角宽度

 我们维护一个左指针和一个运行总和。 对于每个右指针，我们移动左指针，直到左右之间的角度差至多为 θmax。 就切片区域而言，窗口始终有效。 

这是可行的，因为排序的角度保证了单调性，因此一旦窗口变得无效，增加左指针可以恢复有效性。 

### 步骤 6：跟踪最大和最小窗口总和

 我们维护窗口内的值的总和。 对于每个有效窗口，我们更新最大总和和最小总和。 

最终的答案是这两个极值的绝对值的最大值。 

我们需要两者，因为最佳切片可能主要包含负值，并且其绝对值主导任何正切片。 

### 为什么它有效

 每个有效切片对应一个连续的角度间隔。 排序使这些间隔成为连续的段。 复制确保环绕间隔也是连续的。 双指针过程仅枚举每个最大有效段一次，因为对于每个右端点，我们维护最小的有效左端点。 这保证了每个可行的切片总和都被视为窗口总和，并且取最大值和最小值覆盖了绝对目标。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, r, A = map(int, input().split())
        
        pts = []
        for _ in range(n):
            x, y, v = map(int, input().split())
            ang = math.atan2(y, x)
            if ang < 0:
                ang += 2 * math.pi
            pts.append((ang, v))
        
        if n == 0:
            print(0)
            continue
        
        theta = (2.0 * A) / (r * r)
        if theta >= 2 * math.pi:
            total = sum(v for _, v in pts)
            print(abs(total))
            continue
        
        pts.sort()
        
        ext = pts + [(a + 2 * math.pi, v) for a, v in pts]
        
        left = 0
        cur_sum = 0
        ans = 0
        
        for right in range(len(ext)):
            cur_sum += ext[right][1]
            
            while ext[right][0] - ext[left][0] > theta:
                cur_sum -= ext[left][1]
                left += 1
            
            ans = max(ans, abs(cur_sum))
        
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先使用 atan2 将几何图形转换为角度，确保所有方向都标准化为单个圆形比例。 使用扇形面积公式将面积约束转换为最大角宽度。 

按角度对点进行排序会创建一个结构，其中有效切片对应于连续的段。 复制步骤允许将环绕切片与正常间隔进行相同的处理。 

滑动窗口保持运行总和，并在角宽度超过允许限制时调整左边界。 仅在更新答案时应用绝对值，因为内部和必须保持有符号才能正确跟踪正极端值和负极端值。 

## 工作示例

 考虑一个简单的情况，有四个点放置在四分之一圈处，其值为 10、-20、30、-5。 假设角度限制最多允许半圆。 

转换为角度后，点按循环顺序排序。 滑动窗口首先扩展，直到达到角度限制，累积值。 当它移动时，它可能会捕获像 [10, -20, 30] 这样总和为 20 的段，以及 [30, -5] 和总和为 25 的段。 

| 右索引| 左索引 | 窗口值| 总和|
 | --- | --- | --- | --- |
 | 0 | 0 | 10 | 10 10 | 10
 | 1 | 0 | 10、-20 | -10 |
 | 2 | 0 | 10、-20、30 | 20 |
 | 3 | 1 | -20, 30, -5 | 5 |

 该跟踪显示了如何在维持有效窗口的同时自然地处理负贡献。 

现在考虑一个环绕示例，其中两个高值点位于角度 0 和 2π 附近。 复制后，它们在扩展数组中变得相邻，从而允许窗口在不破坏连续性的情况下包含两者。 

| 右索引| 左索引| 窗口值| 总和 |
 | --- | --- | --- | --- |
 | 0 | 0 | 100 | 100 100 | 100
 | 1 | 0 | 100、90 | 190 | 190

 这证实了为什么重复是必要的：没有它，这些点就会显得相距甚远，永远不会被组合在一起。

 ## 边缘情况

 关键的边缘情况是允许的角宽度超过整圆。 在这种情况下，约束不再有意义，每个点都可以包含在单个切片中。 该算法通过直接返回所有值的绝对和来处理此问题，因为唯一有效的切片是完整的集合。 

另一个边缘情况是最佳值来自高度负的集群。 该算法显式跟踪最小窗口和，确保不会丢失大的负和。 例如，如果切片包含值 [-50, -40]，则总和为 -90，答案变为 90，仅最大和方法会错过这一点。 

第三种边缘情况是环绕优势。 如果两个高值点位于角度 0 和 2π 附近，则它们在原始排序中是分开的，但在复制后会变得相邻。 然后，滑动窗口正确地将它们合并成单个有效切片，产生比任何线性段更高的分数。
