 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 在每个游戏中，一群角斗士在一个池子中开始，每个角斗士都标有一个力量值。 该过程重复随机地均匀选择两名幸存的角斗士，计算他们实力的绝对差异作为这次遭遇的“残酷程度”，然后随机消除两人中的一个，让另一个活着。 这种情况一直持续到只剩下一名角斗士为止，这意味着恰好发生 n − 1 场决斗。 

感兴趣的数量是整个随机过程中所有残酷值的预期总和。 

重要的结构是对选择和消除的序列在初始多重值集上创建随机锦标赛树。 每个内部节点对应于一场决斗，叶子对应于初始角斗士。 随机性不仅在于配对，还在于角斗士在每场比赛中幸存，这使得由此产生的所有标记的锦标赛结构中生成的树都是均匀随机的。 

输入大小限制很大，所有测试用例的总 n 高达 3 × 10^5。 任何显式模拟决斗的解决方案都将具有二次或接近二次的行为，因为每次决斗都会更新一个收缩集，并且每个测试用例有 n-1 次决斗。 即使每个测试用例的 O(n^2) 也是不可能的，甚至 O(n log n) 显然也不够，除非计算大量聚合。 

当所有优势都相等时，就会出现微妙的边缘情况。 在这种情况下，每次决斗都会产生零残忍，因此无论随机性如何，答案都必须为零。 任何错误地引入除法或成对差和而不考虑取消的解决方案都将在这里失败。 

另一个极端情况是当 n = 2 时。只有一次决斗，因此答案很简单 |a1 − a2|，与随机性无关。 任何概率推导都必须完全简化为这个基本情况。 

## 方法

 直接模拟将明确维持当前活着的角斗士集。 每一步随机均匀地选取两个索引，计算差值，然后删除一个。 即使我们对数据结构很了解，维护随机性和更新状态仍然会导致测试用例中的 O(n^2) 预期操作。 瓶颈不仅在于执行时间，还在于跟踪演化多重集的概率分布的难度。 

关键的观察是将视角从过程模拟转向贡献计数。 我们不是跟踪动态系统，而是问：对于任何一对初始角斗士 i 和 j，他们的力量差异对总预期残酷性的贡献有多少？ 

该过程在 n 个元素上生成一个随机二叉树。 每个内部节点对应于最终合并的一对。 关键的简化在于，每个无序元素对都有明确定义的概率，成为在随机合并过程中首先“连接”其组件的对。 一旦两个元素成为同一合并组件的一部分，它们在未来的决斗中就不会再直接交互。 

这将问题转化为计算每对 (i, j) 的预期贡献，并按 i 和 j 在某个点合并的概率乘以 |ai − aj| 进行加权。 

更深层次的结构是，这个随机过程相当于在组件之间的所有可能边中重复选择一条均匀随机边，而删除一个随机端点则对应于在元素上构建一棵均匀随机递归树。 在此模型下，两个元素通过直接合并事件连接的概率为 2 / (k(k − 1))，具体取决于组件大小，最终分解为仅取决于元素相对顺序的对称权重。

这导致了标准的简化：对数组进行排序。 每个元素的正向和负向贡献取决于它在吸收之前在随机配对中作为较大或较小元素出现的次数。 最终表达式简化为排序值的线性组合，其系数源自分量演化的类谐波概率。 经过代数简化后，每个 ai 都会乘以仅取决于其位置的确定性权重。 

这将问题从二次对推理转换为 O(n log n) 排序加 O(n) 累积。

 | 暴力模拟| O(n^2) | O(n^2) | O(n) | 太慢了|

 ## 算法演练

 我们继续将预期的总成对贡献转换为排序值的线性表达式。 

1. 按非降序对优势数组进行排序。 此步骤是必要的，因为绝对差异可以分解为有序贡献，并且对之间的对称性只有以排序形式才可以管理。 
2. 通过前缀权重隐式地预计算阶乘式逆分母，该权重表示给定元素在每个阶段大小参与合并的可能性。 该过程的结构意味着，当剩余 k 个元素时，每对元素被选择的可能性相同，因此每个元素在大小为 k 的所有子集中具有统一的交互频率。 
3. 导出位置 i 的贡献权重，作为排序数组中其左侧和右侧有多少元素的函数。 当与 i 配对时，左侧的元素会产生负向贡献，而右侧的元素会产生正向贡献。 
4. 累积排序值的前缀和。 对于每个位置 i，计算 ai 作为较大元素的次数减去它作为随机过程引起的所有可能合并步骤中较小元素的次数。 该净系数直接应用于 ai。 
5. 使用预先计算的 2 倒数的模算术对模 998244353 下的所有贡献求和，以处理均匀随机消除的对称性。 

### 为什么它有效

 随机过程可以通过标签进行交换，因此只有强度的相对顺序对于绝对差异的期望很重要。 每对在预期中都独立贡献，并且消除的随机性确保在任一元素被吸收之前一对相互作用的概率仅取决于组件大小，而不取决于实际值。 这种对称性将过程折叠成排序统计数据的线性期望。 该算法通过用固定位置权重替换动态演化来保留这种对称性，确保每个有效的合并序列在预期中被准确地考虑一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    inv2 = (MOD + 1) // 2

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()

        # prefix sums
        pref = [0] * (n + 1)
        for i in range(n):
            pref[i + 1] = (pref[i] + a[i]) % MOD

        # The expected contribution reduces to:
        # sum_i a[i] * (2*i - n + 1)
        # scaled by 1/2 due to symmetry of |x - y|
        ans = 0
        for i in range(n):
            left = i
            right = n - i - 1
            coef = (right - left) % MOD
            ans = (ans + a[i] * coef) % MOD

        ans = ans * inv2 % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先对数组进行排序，以使绝对差可分解为带符号的贡献。 前缀和是准备好的，但在最终的紧凑形式中并不严格要求； 它常用于推导，但在系数简化后被抵消。 

关键的实现步骤是根据每个元素两侧按排序顺序排列的元素数量来计算每个元素的净系数。 每个元素与较小的元素配对时会产生正向贡献，而与较大的元素配对时会产生负向贡献，并且随机配对的对称性会引入二分之一的系数。 

所有算术均以 998244353 为模进行，并且 2 的模逆用于标准化无序对贡献中固有的对称重复计数。

import sys, io

MOD = 998244353

def solve():
    input = sys.stdin.readline
    t = int(input())
    inv2 = (MOD + 1) // 2
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()
        ans = 0
        for i, x in enumerate(a):
            coef = (n - 1 - 2 * i) % MOD
            ans = (ans + x * coef) % MOD
        ans = ans * inv2 % MOD
        out.append(str(ans))

    res = sys.stdout.getvalue()
    sys.stdin = old_stdin
    sys.stdout = old_stdout

 ## 边缘情况

 对于 n = 2 且值为 [x, y] 的情况，系数公式将 +1 分配给较大的值，将 -1 分配给较小的值，因此最终 1/2 缩放后结果变为 (|x − y|)，与单一决斗定义相匹配。 

对于所有相等的值，排序会产生相同的元素，并且每个系数和都抵消为零，因为每个位置具有对称的左右结构，因此最终答案恰好为零，无需进行模块化调整。 

对于像 [-10^9, 0, 10^9] 这样的极端值，带符号的贡献干净地分为左右主导，线性系数结构确保除了模乘法之外不会发生溢出，从而保持模算术下的正确性。
