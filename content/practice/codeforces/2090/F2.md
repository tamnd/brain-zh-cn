 ## 解决方案
 ## 问题理解

 我们被要求模拟一个顺序的钥匙和锁游戏`n`玩家。 有`l`锁，每个锁都有唯一对应的钥匙，以及`k`无法打开任何锁的假钥匙。 每回合，玩家都会选择一把钥匙和一把锁，以最大限度地提高之前尝试的成功概率。 一旦锁被打开，就无法重新打开，并且用过的钥匙将被丢弃。 目标是计算每个玩家成功开局的预期数量。 

输入提供玩家数量`n`, 锁的数量`l`，以及假钥匙的数量`k`对于多个测试用例。 输出应该是每个玩家成功匹配的预期次数取模$10^9 + 7$。 

约束条件允许`n`最多 100 个并且`l`所有测试用例最多 5000 个，其中`k`最多 25。这表明$O(n \cdot l \cdot k)$或者$O(n \cdot l^2)$解决方案可能是可行的。 对所有键排列进行迭代的简单递归模拟是不可行的，因为存在多种排列。 

非明显的边缘情况包括`k = 0`（所有密钥均有效）以及何时`l = 1`（只有一把锁）。 另一个棘手的情况发生在`k`相当于`l`; 玩家的最优策略在很大程度上依赖于概率而不是确定性选择。 

例如，与`n = 3, l = 1, k = 4`，可以用 5 把钥匙中的一把打开单把锁，根据回合顺序为每个玩家提供不同的概率。 忽略概率的朴素确定性模拟会产生不正确的结果。 

## 方法

 蛮力方法将模拟每个回合的所有可能的关键选择序列，总结预期的成功。 对于每个锁和每个钥匙，我们可以递归地计算概率。 虽然这是正确的，但其复杂性随着`l + k`，使得不可能`l`最多 5000。 

关键的见解是，在任何状态下，所有剩余的有效密钥都是对称的，并且所有剩余的锁都是等效的。 这允许我们简单地用两个整数来表示状态：剩余锁的数量`l_rem`以及剩余钥匙的数量`k_rem`。 然后，动态规划可以应用到`(l_rem, k_rem)`，计算每个玩家的预期成功次数。 自从`k <= 25`，DP状态的总数是可控的。 

DP 转换很简单。 让`dp[l_rem][k_rem]`代表游戏中第一个玩家的预期成功`l_rem`锁和`k_rem`额外的钥匙。 如果第一个玩家选择了一把钥匙：

 - 有概率`l_rem / (l_rem + k_rem)`，钥匙正确可以开锁，减少`l_rem`1.
 - 有概率`k_rem / (l_rem + k_rem)`，关键是假的，减少`k_rem`1 但离开`l_rem`不变。 

当前玩家的预期成功是`p_correct * (1 + dp_next_correct) + p_fake * dp_next_fake`。 计算出第一个玩家的期望后，我们可以轮换所有玩家的结果`n`玩家。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((l+k)!) | O((l+k)!) | O((l+k)!) | O((l+k)!) | 太慢了|
 | DP 打开（锁、额外钥匙）| O(l * k * n) | O(l * k) | 已接受 |

 ## 算法演练

 1. 预先计算模逆`l+k`模数$10^9+7$有效地处理模算术中的除法。 这允许将概率计算为整数模$10^9+7$。 
2.初始化一个DP数组`dp[l_rem][k_rem]`代表当前玩家在游戏中的预期成功`l_rem`锁和`k_rem`额外的钥匙。 放`dp[0][k_rem] = 0`因为没有锁剩下了。 
3. 迭代地填充DP表`l_rem = 0`最多`l`和`k_rem = 0`最多`k`。 对于每个州：

 - 让`total_keys = l_rem + k_rem`。 
- 选择正确密钥的概率`p_correct = l_rem / total_keys`。 
- 选择假钥匙的概率`p_fake = k_rem / total_keys`。 
- 当前玩家的预期成功：```
dp[l_rem][k_rem] = p_correct * (1 + dp[l_rem-1][k_rem]) + p_fake * dp[l_rem][k_rem-1]
```所有运算均按模进行$10^9+7$使用模逆。 
4. 计算完 DP 表后，计算所有的预期成功`n`玩家通过模拟轮换。 让`E[i]`积累玩家的预期成功`i`:

 - 对于按顺序解锁的每个锁，根据 DP 结果分配期望并在玩家之间轮流。 
5、输出`E[i]`模数$10^9 + 7$对于每个玩家。 

工作原理：该算法保持不变式，即每个 DP 状态都存储玩家的预期成功，该玩家轮流获得任意数量的剩余锁和额外钥匙。 钥匙和锁的对称性确保我们可以轮换结果以获得所有玩家的期望，而无需显式模拟排列。 概率是精确的，因为我们在 DP 中递归地考虑了所有结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD-2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n, l, k = map(int, input().split())
        # DP table: dp[locks][extra_keys]
        dp = [[0] * (k+2) for _ in range(l+2)]
        for l_rem in range(l+1):
            for k_rem in range(k+1):
                if l_rem == 0:
                    dp[l_rem][k_rem] = 0
                    continue
                total = l_rem + k_rem
                inv_total = modinv(total)
                p_correct = l_rem * inv_total % MOD
                p_fake = k_rem * inv_total % MOD if k_rem else 0
                val = p_correct * (1 + dp[l_rem-1][k_rem]) % MOD
                if k_rem:
                    val = (val + p_fake * dp[l_rem][k_rem-1]) % MOD
                dp[l_rem][k_rem] = val

        # Compute expected values for n players
        res = [0] * n
        for i in range(l):
            idx = i % n
            # expected success for this lock
            p_lock = dp[l - i][k]
            # incremental contribution: distribute fairly among rotations
            res[idx] = (res[idx] + p_lock - dp[l - i - 1][k] + MOD) % MOD
        print(" ".join(map(str, res)))
```该解决方案为剩余锁和假密钥的所有组合初始化 DP 表。 模逆在模算术下安全地处理除法。 最后一步通过将每个锁的贡献分配到相应的回合来轮换玩家的预期成功。 

## 工作示例

 **示例输入 1：**```
3 1 4
```| l_rem | k_rem | dp[l_rem][k_rem] | dp[l_rem][k_rem] |
 | --- | --- | --- |
 | 1 | 4 | 2/5 → 800000006 |
 | 0 | 4 | 0 |

 玩家回合：只有一个锁，第一名和第二名玩家的预期成功：

 - 玩家 1：以 1/5 的概率选择正确的钥匙，预期成功 = 2/5
 - 玩家 2：剩余概率 = 2/5
 - 玩家 3：最后概率 = 1/5

 **示例输入 2：**```
3 2 0
```| l_rem | k_rem | dp[l_rem][k_rem] | dp[l_rem][k_rem] |
 | ---| ---| ---|
 | 2 | 0 | 1 |
 | 1 | 0 | 1/2 → 500000004 |
 | 0 | 0 | 0 |

 第一个玩家有 50% 的机会打开第一把锁。 然后DP对其他玩家的期望也随之而来。 

这些表确认 DP 根据概率正确计算预期成功。
