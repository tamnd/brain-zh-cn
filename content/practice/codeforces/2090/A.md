 ## 解决方案
 ## 问题理解

 我们被要求确定谁将在小 B 和小 K 两个人之间首先挖掘埋藏的宝藏。宝藏埋在一个分数深度`a.5`米，这是关键：这意味着阈值始终是`.5`超出整数米`a`。 小B挖`x`Little K 每天都会挖几米`y`米在她的，他们从小B开始交替。对于每个测试用例，我们要打印`NO`如果小B先挖到宝藏，并且`YES`如果小K这样做的话。 

输入由多个测试用例组成，每个测试用例提供整数`x`,`y`， 和`a`。 每个值可以大到10^9，并且最多可以有1000个测试用例。 这些限制排除了模拟日常挖掘的可能性，因为在最坏的情况下，直接模拟可能需要数十亿次迭代，这超过了 1 秒的限制。 这个问题本质上是数学问题，关键是用代数方式推理累积深度和轮次顺序。 

当两个挖掘量相等时，就会出现微妙的边缘情况。 例如，如果`x = y = 2`和`a = 1`，宝藏位于`1.5`米。 小B第一天挖了2米，立刻就超过了1.5。 假设交替日期而不考虑部分阈值的天真方法可能表明 K 的轮次很重要，但实际上，第一次挖掘就足够了。 当一个挖掘量远大于另一个时，会出现另一种边缘情况，这可能会将结果转移到第一人身上，而不管结果如何`a`。 

## 方法

 暴力方法将模拟日复一日的挖掘过程。 初始化总深度计数器。 每天添加`x`或者`y`取决于轮到谁了。 每次添加后，检查累计深度是否超过`a.5`。 这可以正常工作，但对于大输入来说效率低下。 每个测试用例可能需要最多`a/x + a/y`迭代次数，最坏情况下可达 10^9 次。 这显然超过了时间限制。 

最佳方法源于观察到我们只关心**哪一天的累积深度超过`a.5`**，不是确切的每日进度。 如果我们将宝藏深度标准化为`2a + 1`为了避免分数，问题简化为依次比较第一和第二挖掘机的缩放总和。 关键的见解是宝藏深度与`x + y`决定结果。 从数学上来说，如果`a // (x + y)`B 和 K 的完整循环仍然留下大于`x`，那么小B在下一个回合就挖过了宝藏； 否则，小K就这么做。 这将每个测试用例减少为几个整数运算，时间复杂度为 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(a / 分钟(x, y)) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 增加宝藏深度`a.5`除以 2 以获得整数阈值`threshold = 2 * a + 1`。 这避免了分数，从而简化了比较和算术。 
2.将小B每天的挖掘量乘以2得到`b2 = 2 * x`。 将小K每天的挖掘量乘以2得到`k2 = 2 * y`。 这使得他们的挖掘金额与阈值处于同一规模。 
3. 将交替转弯视为重复循环`b2 + k2`。 通过整数除法计算有多少个完整周期适合阈值：`cycles = threshold // (b2 + k2)`。 
4. 计算这些完整循环后的剩余深度：`remainder = threshold - cycles * (b2 + k2)`。 这个余数小于`b2 + k2`并代表最后不完整的一天。 
5. 将余数与`b2`。 如果`remainder <= b2`，说明小B在下一回合就超过了阈值，所以答案是`NO`。 否则，小K先到达，答案是`YES`。 

为什么有效：将所有内容缩放 2 将小数阈值转换为整数问题，同时保留日顺序。 不变的是，在两个挖掘机的每个完整循环之后，剩余深度始终由最后一轮处理，并将其与 B 的挖掘量进行比较，准确确定谁先跨过阈值。 不存在歧义或相差一的错误，因为比例考虑了`.5`米明确。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    x, y, a = map(int, input().split())
    threshold = 2 * a + 1
    b2 = 2 * x
    k2 = 2 * y
    remainder = threshold % (b2 + k2)
    if remainder <= b2:
        print("NO")
    else:
        print("YES")
```该代码使用有效地读取输入`sys.stdin.readline`对于多个测试用例。 阈值缩放 2 来处理`.5`自然。 我们仅在完整循环后计算余数，以确定第一个超过它的挖掘者。 比较`<= b2`直接检查小B是否先到达宝藏。 

微妙之处在于整数缩放和隔离最后一个不完整回合的模数运算。 省略会导致小数阈值结果不正确或非常大`a`。

```| 步骤| 门槛| b2 | k2| 剩余| 比较| 结果 |

 | 计算| 2*4 +1 = 9 | 2*4 +1 = 9 2 | 4 | 9% (2+4) = 9% 6 = 3 | 3 <= 2？ 否 | 是 |

 小B挖1米，K挖2米，如此重复。 按比例缩放 2，阈值变为 9，B = 2，K = 4。经过一个完整周期 (B+K=6)，余数为 3。由于 3 > 2，K 首先跨越阈值。 

输入示例 2：```

```| 步骤| 门槛| b2 | k2| 剩余| 比较| 结果 |
 | ---| ---| ---| ---| ---| ---| ---|

 这里，B 每天挖的东西比 K 多。第一个完整循环后的余数是 3，即 <= B 的挖东西，所以 B 先到达宝藏。 

这些痕迹确认算法正确地缩放、减少周期并处理谁首先超过阈值。
