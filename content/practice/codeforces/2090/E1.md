 ## 解决方案
 ## 问题理解

 我们有两个整数序列，`a`和`b`, 两者的长度`n`。 目标是减少所有元素`a`通过执行称为_round_的重复操作来归零。 每轮由三个步骤组成：首先，我们减去元素方面的最小值`a`和`b`来自两个数组； 其次，我们移动所有元素`a`向右一步（带环绕）； 第三，我们重复一遍。 在此简单版本中，没有进行任何初始更改`a`被允许（`k=0`）。 任务是找到使所有元素都需要的最少轮数`a`零。 

约束告诉我们`n`每个测试用例最多可达 200,000 个，总和`n`所有测试用例的数量也以 200,000 个为界。 这意味着`O(n log n)`解决方案是可以接受的，但是任何尝试天真地模拟回合的解决方案都可能会运行到`10^9`操作，这太慢了。 

当某些元素出现时，就会出现边缘情况`a`明显大于相应的`b`值，或者当元素`a`较小，但旋转后的分布会延迟归零。 例如，如果`a = [10, 1]`和`b = [1, 10]`，不考虑轮换的简单方法会低估所需的轮数，因为`a[0]`转移到之后才缓慢减少`a[1]`。 

## 方法

 蛮力方法明确地模拟回合。 对于每一轮，计算`t = min(a_i, b_i)`对于每一个`i`, 减去`t`来自两个数组，然后旋转`a`。 重复直到所有元素`a`变为零。 这是正确的，但太慢了，因为每一轮都是`O(n)`我们可能需要最多`max(a)`轮，这可能是`10^9`在最坏的情况下。 

关键的见解是要注意，最小轮数是由每个轮数决定的`a_i`被序列“覆盖”`b`通过轮换值。 每个`a_i`将看到来自的贡献`b_i, b_{i+1}, ..., b_{i+n-1}`作为`a`旋转。 因此，问题简化为寻找，对于每个`i`, 最小轮数`r`使得总和`b`遇到的值`a_i`在`r`旋转次数至少为`a_i`。 

这使我们能够计算所有的最小轮次`a_i`独立。 我们可以滑动一个长度的窗口`n`在双倍数组上`b`处理旋转，并且对于每个`a_i`，对所需的轮数执行二分搜索。 总体复杂度为`O(n log n)`，符合约束条件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * 最大(a_i)) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，请阅读`n`和`k`（始终为零），数组`a`，和数组`b`。 
2.双倍`b`数组到`b2 = b + b`。 这允许我们将旋转模拟为连续的子数组，而不是执行显式旋转。 
3. 计算前缀和`pref`的`b2`， 以便`pref[i]`包含第一个的总和`i`元素。 这允许快速计算任何连续范围内的总和。 
4. 对于每个索引`i`在`a`，对轮数进行二分查找`r`需要这样的总和`b`元素`b[i], b[i+1], ..., b[i+r-1]`至少是`a[i]`。 使用前缀和在恒定时间内计算这些和。 
5、测试用例所需的轮数为最大`r`全面的`i`，因为所有`a_i`必须变为零。 
6. 打印结果。 

关键的不变量是每个`a_i`只减少相应的`b`当前旋转中的值，并且旋转确保每个`a_i`最终与每个一致`b_j`。 通过使用前缀和和二分搜索，我们准确地捕获了每个`a_i`完全被序列覆盖`b`价值观。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        b2 = b + b
        pref = [0] * (2 * n + 1)
        for i in range(2 * n):
            pref[i+1] = pref[i] + b2[i]
        
        res = 0
        for i in range(n):
            lo, hi = 1, n
            while lo < hi:
                mid = (lo + hi) // 2
                total = pref[i+mid] - pref[i]
                if total >= a[i]:
                    hi = mid
                else:
                    lo = mid + 1
            res = max(res, lo)
        print(res)

if __name__ == "__main__":
    solve()
```代码首先构造了双倍数组`b2`有效地模拟旋转。 前缀和允许在任何窗口上进行恒定时间的求和计算。 对于每个`a_i`，二分查找找到所需的最少轮数，并且测试用例结果是所有轮数中最大的`a_i`。 二分查找可防止迭代`n`天真地循环，这对于大的来说太慢了`a_i`。

 **示例输入 1：**```

```| 我| a_i | 前缀窗口总和 | 二分查找结果 r |

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n log n) | O(n log n) | 前缀和为 O(n)，每个 a_i 的二分查找为 O(log n)，总体 O(n log n) |
 | 空间| O(n) | 存储 b2 和前缀和需要 O(2n) = O(n) |

 给定`n <= 2 * 10^5`和总计`n`跨测试用例 <=`2 * 10^5`，算法在 2 秒限制内运行良好。
