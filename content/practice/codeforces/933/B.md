 ## 解决方案
 ## 问题理解

 我们被要求构造一个多项式，其系数是严格小于给定基数的非负整数$k$，这样当该多项式除以$x + k$，余数正是常数多项式$p$。 

除以$x + k$意味着如果我们评估多项式$x = -k$，该值必须等于$p$，因为余数定理告诉我们除以的余数$x + k$是$f(-k)$。 所以这个任务相当于构建一个有限的数字序列$a_0, a_1, \dots, a_{d-1}$在基地$k$-like 约束，每个数字位于$[0, k-1]$，以及它们的带符号加权和$$f(-k) = a_0 - a_1 k + a_2 k^2 - a_3 k^3 + \dots$$必须等于$p$。 

系数不允许为负数，因此我们不能直接表示交替基数$k$的扩展$p$无需携带。 挑战在于模拟带符号的基本表示，同时将每个数字保留在$[0, k-1]$。 

约束非常严格：$p \le 10^{18}$和$k \le 2000$。 任何解决方案在产生的位数上都必须基本上是线性的，因为即使$O(\log p)$是可以接受的，但数字构造中的任何二次方仍然可以通过。 真正的困难不是计算复杂性，而是确保有效的数字系统而不违反系数界限。 

一个天真的尝试是扩大$p$在基地$k$直接贪婪地分配系数。 由于评估引起的交替符号而失败$-k$。 例如，将数字从最低有效位向上设置为$p \bmod k$忽略了更高的幂是减法而不是加法，这会立即破坏正确性。 

当没有跨交替符号对称地处理进位时，会出现第二种故障模式。 例如，在奇数位置处打算作为负贡献的数字不能简单地设置为零或局部减少而不影响更高的项。 

## 方法

 蛮力方法会尝试一一构造系数，并保持在以下位置评估的多项式的精确值：$-k$。 在每个位置，我们都会尝试所有可能的数字$0$到$k-1$并递归调整剩余目标值。 这很快就变得不可行，因为分支因子是$k$，深度可达$O(\log_k p)$，导致指数爆炸。 

关键的观察结果是多项式评估$-k$其行为类似于具有交替符号的混合基数系统。 这表明我们可以从最低级向上贪婪地构建数字，但我们必须仔细管理吸收符号交替的运行“进位”。 

在步骤$i$，我们决定系数$a_i$。 其对价值的贡献为$a_i \cdot (-k)^i$。 我们不直接使用交替符号，而是维护当前余数并通过以下方式强制整除$k$每一步，但当位置奇偶校验翻转符号时调整余数。 

最重要的一点是，选择之后$a_i$，剩余目标必须保持为整数倍$k$，因为更高的幂$x$对应于更高的幂$k$在幅度上。 这强制执行类似于基数转换的确定性数字提取过程，不同之处在于，在奇数位置，我们通过有效添加完整的数字来​​纠正负贡献。$k$-划分之前的块。 

这将问题转化为有符号基础系统中的受控数字构造。

 | 最佳| O(log_k p) | O(log_k p) | 已接受 |

 ## 算法演练

 我们从 0 度向上构建系数，同时保持当前剩余值，该剩余值表示仍必须与更高度项匹配的内容。 

1. 从当前值开始$p$和一个空的系数列表。 

我们将此值解释为仍需要由多项式表示的值。 
2. 对于每个位置$i = 0, 1, 2, \dots$，确定系数$a_i$。 

在偶数位置，贡献为正； 在奇数位置，它是负数。 这种符号交替决定了我们如何提取数字。 
3.如果$i$是偶数，我们设$$a_i = p \bmod k$$因为这个位置对基础有积极贡献$k$式扩张。 
4.如果$i$是奇数，我们必须补偿负号。 我们计算$$a_i = (k - (p \bmod k)) \bmod k$$这确保了减去之后$a_i \cdot k^i$，余数可被除以$k$以一致的方式。 
5. 通过减去所选数字贡献并除以来更新剩余值$k$，仔细调整符号。 
6. 重复直到剩余值变为零。 
7. 删除系数列表中的尾随零，确保最高系数非零。 

该过程终止的原因是每一步都会将剩余值的大小大致减少一个因子$k$，类似于标准基数转换，但具有交替校正。 

### 为什么它有效

 在每一步中，我们强制减去所选系数后的残差值可除以$k$。 这保证了高阶系数可以表示剩余值而没有分数干扰。 交替校正确保奇数索引处的负贡献始终在数字范围内得到补偿$[0, k-1]$，因此不会产生无效系数。 保持的不变性是剩余值总是与更高阶项必须编码在有效的有符号基数中的内容完全对应。$k$表示。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    p, k = map(int, input().split())

    coeffs = []

    x = p
    i = 0

    while x != 0:
        if i % 2 == 0:
            a = x % k
            x = (x - a) // k
        else:
            # adjust so that remainder division works with negative sign
            a = (-x) % k
            x = (x + a) // k

        coeffs.append(a)
        i += 1

    if not coeffs:
        print(-1)
        return

    while len(coeffs) > 1 and coeffs[-1] == 0:
        coeffs.pop()

    print(len(coeffs))
    print(*coeffs)

if __name__ == "__main__":
    solve()
```该实现直接遵循交替数字提取。 关键的微妙之处在于奇数索引的处理，其中我们将残差转换为可被整除的形式$k$调整负贡献后。 通过构建所选系数，整数除法是精确的，因此不会出现浮点问题。 

修剪步骤确保我们不会输出不必要的前导零，因为最高阶系数必须非零。

 ## 边缘情况

 当出现一种边缘情况时$p$已经为零。 在这种情况下，算法永远不会进入循环，并且会输出空系数列表。 正确的解释是除了零多项式之外不需要多项式，但问题需要具有非零最高系数的有效表示。 该实现通过打印来处理这个问题$-1$用于空建筑。 

当重复进位由于小而传播到多个级别时，会出现另一种边缘情况。$k$， 例如$k = 2$。 例如，二的大幂$p$创建长交替调整。 该算法仍然对每个位只处理一次，并且不变量$x$可以被整除$k$每个步骤之后确保不会发生无限循环或精度问题。
