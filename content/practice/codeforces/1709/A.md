 ## 问题理解

 我们有三扇门，每扇门都有一个从 1 到 3 的唯一锁号。我们手里还拿着一把钥匙，每扇门后面可能有另一把钥匙，也可能什么都没有。 两把钥匙藏在门后，一把钥匙在我们手里。 每把钥匙都可以准确地打开对应号码的门。 任务是确定从手中的钥匙开始，我们是否可以依次打开所有三扇门，并沿途取回剩余的钥匙。 

输入由许多测试用例组成。 对于每个测试用例，我们都会收到手中钥匙上的编号以及分别代表 1、2 和 3 号门后面钥匙的三个整数的列表。 零表示该门后面没有钥匙。 手中恰好有一个钥匙号码出现，其余两个钥匙号码在门后，而第三扇门没有钥匙。 

约束非常小：最多 18 个测试用例，键限制为 1 到 3。这立即排除了对性能的任何担忧。 这个问题纯粹是逻辑性的：解决方案只需要正确地模拟解锁门和检索钥匙的过程。 

当手中的钥匙不能直接打开包含我们需要的第二把钥匙的门时，就会出现边缘情况。 例如，如果我们从钥匙 2 开始，门后的钥匙是`[1, 3, 0]`，那么我们就无法到达钥匙 1，因为门 1 需要钥匙 1 才能打开，从而造成死锁。 在这种情况下，正确的输出是“NO”。 幼稚的方法可能会忽略这种依赖性，并错误地假设所有门都可以打开。 

## 方法

 最简单的方法是蛮力：使用手中的钥匙和检索到的任何钥匙尝试解锁门的每个序列。 由于只有三扇门，序列的数量很少（3！= 6），因此暴力模拟是可行的，但它太过分了并且模糊了逻辑。 

关键的见解是，问题可以简化为两步检查：首先，使用手中的钥匙打开相应的门。 然后拿起那扇门后面的钥匙（如果有的话），看看它是否可以打开剩下的一扇门。 如果第一把钥匙打开包含第二​​把钥匙的门，我们总是可以用第二把钥匙打开剩下的门。 否则，如果剩余的钥匙在我们拥有的钥匙无法打开的门后面，我们可能会陷入困境。 

我们可以将其形式化为一个简单的序列：`current_key`成为手中的钥匙。 用号码开门`current_key`。 如果该门后面有一把钥匙（非零），则设置`current_key`到那把钥匙并用该号码打开门。 如果在任何时候我们试图打开一扇需要我们没有钥匙的门，答案是“不”。 如果我们成功打开两扇门并取回最后一把钥匙，那么剩下的门总是可以用最后一把钥匙打开。

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，阅读手中的密钥`x`和清单`[a, b, c]`代表 1、2、3 号门后面的钥匙。 
3. 将门和钥匙视为从门号到其后面的钥匙的映射。 换句话说，1号门有钥匙`a`, 2号门有钥匙`b`, 3号门有钥匙`c`。 
4. 从手中的钥匙开始`current_key`。 用那个号码检查门。 如果后面的钥匙是0，那么剩下的未打开的门一定有最后一把钥匙，这也是我们已经有了的。 打印“是”。 
5. 如果门后面有一把钥匙（非零），则拿起该钥匙并检查与该钥匙对应的门。 如果那扇门包含 0（没有钥匙），我们仍然可以打开它。 如果里面有钥匙，那一定是最后一扇门。 验证这是否与最后剩余的密钥匹配。 
6. 如果在任何时候我们需要的钥匙在我们手拿钥匙无法打开的门后面，请打印“NO”。 否则，打印“YES”。 

为什么有效：不变的是，在每一步中，手中的钥匙要么可以打开为我们提供下一把钥匙的门，要么可以打开没有钥匙的门。 由于只有三扇门，并且钥匙的分布使得门后恰好缺少一把钥匙，因此这种两步模拟足以确定是否所有门都可以进入。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    x = int(input())
    a, b, c = map(int, input().split())
    doors = {1: a, 2: b, 3: c}

    current_key = x
    first_door_key = doors[current_key]

    if first_door_key == 0:
        print("NO")
    else:
        second_door_key = doors[first_door_key]
        if second_door_key == 0:
            print("YES")
        else:
            print("NO")
```该解决方案读取测试用例并将门表示为从门号到其后面的钥匙的字典映射。 从手中的钥匙开始，它模拟打开相应的门。 如果门有钥匙，它会尝试用该钥匙打开下一扇门。 如果第二扇门后面没有钥匙，则所有门都可以打开，因此我们打印“YES”。 否则，我们就会陷入困境，答案是否定的。

                print("NO")
