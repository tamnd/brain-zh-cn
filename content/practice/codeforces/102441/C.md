 ## 解决方案
 ## 问题理解

 我们从一个 (n \times m) 二进制矩阵 (A_0) 开始。 一个操作将每个单元格替换为从左上角到该单元格的矩形的奇偶校验。 重复应用该运算会产生 (A_1,A_2,\ldots)，并且我们需要最小的正数运算，之后当前矩阵再次恰好变为 (A_0)。 官方问题给出了(1\le n,m\le 10^6)和(nm\le 10^6)，时间限制为1秒，内存限制为256MB。 

乘积界限是关键约束。 我们可以对所有（nm）单元进行线性传递，但我们无法模拟整个矩阵的许多变换。 一次变换的成本已经是(\Theta(nm))，而答案可以在(10^6)左右，因此重复构造矩阵将远远超出限制。 该解决方案必须基本上处理输入一次。 

在某些情况下，仅基于矩阵维度的实现会给出错误的结果。 例如，对于全零矩阵，```
2 3
000
000
```正确答案是（1），因为一次部分和运算使矩阵保持不变。 始终搜索足够大以覆盖维度的 2 的幂的解决方案可能会错误地返回 (4)。 

一维矩阵的周期可能比其长度所暗示的小得多。 为了```
1 4
0001
```正确答案是（1）。 唯一的非零单元格已经位于最右侧，因此对前缀和取模 (2) 不会更改该行。 假设答案必须至少为 (m) 的粗心解决方案将返回 (4)。 

第一个非零单元格的位置在另一个方向上也很重要。 为了```
1 4
0100
```正确答案是（4）。 包含 (1) 的第一个单元格是第 (2) 列，较小的 2 次方不会将所需的边界推到足够远的右侧。 只看 a (1) 的存在，而不考虑它的位置，就会丢失决定答案的信息。 

## 方法

 直接的方法是构造(A_1)，然后构造(A_2)，依此类推，直到其中一个等于(A_0)。 通过维护当前行前缀、列前缀和先前对角贡献（全部以 (2) 为模），可以在 (O(nm)) 时间内执行单个二维前缀和变换。 该方法是正确的，因为它准确地计算了操作的定义。 

问题在于变换的数量。 考虑长度为 (d) 的向量上的一维前缀和运算符。 以 (2) 为模，它的阶数是 2 的幂，并且一旦该幂至少达到 (d)，它就成为恒等式。 如果 (d=10^6)，则 2 的下一个幂是 (2^{20}=1,048,576)。 因此，强力模拟可能需要大约 (1,048,576) 次完整矩阵传递。 对于 (nm=10^6)，在最坏的情况下，这大约是 (1.05\times10^{12}) 单元操作。 

消除这个巨大因素的观察结果来自于将前缀和视为具有两个元素的域上的线性运算符。 令 (S) 为移位运算符，它将每个元素向下移动一位并在开头插入零。 前缀和是

 [
 P=I+S+S^2+\cdots。 
]

 对于 2 的幂 (q=2^t)，特征 (2) 给出

 [
 P^q=(I+S)^q=I+S^q。 
]

 所有中间二项式系数对模 (2) 都消失。 相同的恒等式独立地适用于行和列。 

完整的二维变换是可分离的，所以经过(q)次运算后，

 [
 A_q=(I+R^q)A_0(I+C^q),
 ]

 其中 (R) 移动行，(C) 移动列。 因此，对于每个细胞，

 A[i,j]
 \oplus A[i-q,j]
 \oplus A[i,j-q]
 \oplus A[i-q,j-q],
 ]

 其中矩阵外部的索引贡献为零。 

还有另一个重要的结构事实。 任何特定矩阵的周期必须是 2 的幂，因为完整变换具有 2 的幂次方。 因此，我们不需要检查每个可能的 (k)，而只需要了解 2 的幂。 

假设 (q<\min(n,m)) 和 (A_q=A)。 对于 (i>q) 和 (j\le q)，涉及 (j-q) 的移位项消失，给出 (A[i-q,j]=0)。 对于 (i>q,j>q)，定义

 [
 B[i,j]=A[i,j]\o加上A[i-q,j]。 
]

 等式 (A_q=A) 给出

 [
 B[i,j]=B[i,j-q]。 
]

 前面的边界条件表明 (B) 的前 (q) 列为零，因此等式传播到每一列，并且 (B) 完全为零。 因此，每一行都以周期 (q) 重复。 

由于下面的行中的前 (q) 列为零，并且行以句点 (q) 重复，因此这些列实际上到处都为零。 对称边界条件表示前 (q) 行的前 (m-q) 列为零。 因为 (q<m)，这两个区域覆盖前 (q) 行的每一列。 因此，前 (q) 行为零，行周期性使整个矩阵为零。 

因此，非零矩阵只能在满足 2 的幂 (q) 后返回

 [
 q\ge\min(n,m)。 
]

 这就留下了一个非常简单的一维条件。 

如果(n\le m)，每个相关的(q)都满足(q\ge n)，所以行移位(R^q)已经为零。 仅保留列转换。 当从 (1) 到 (m-q) 的每一列都为零时，矩阵完全不变。 如果包含 (1) 的第一列是 (c)，则相当于

 [
 m-q<c,
 ]

 或

 [
 q\ge m-c+1。 
]

 因此所需的二的幂至少是二的最小幂

 [
 \max(n,m-c+1)。 
]

 情况 (m<n) 是对称的。 我们找到包含 (1) 的第一行，例如 (r)，并且所需的 2 的幂至少是 2 的最小幂

 [
 \max(m,n-r+1)。 
]

 蛮力法遵循字面上的定义，但二元幂恒等式将整个问题转化为仅找到一个边界位置。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(nm\cdot 2^{\lceil\log_2\max(n,m)\rceil})) | (O(nm)) | 太慢了|
 | 最佳 | (O(nm)) | (O(1)) 额外 | 已接受 |

 ## 算法演练

 1. 读取矩阵维度并确定哪个维度较小。 我们只需要较大维度的信息，因为较小的维度告诉我们第一个可能的二次幂周期。 
2. 如果(n\le m)，则扫描每一行并记录包含(1)的最小列。 将此列称为 (c)。 我们不需要存储矩阵，因为最终条件仅取决于这个最早的非零列。 
3. 如果不存在(1)，则输出(1)。 零矩阵由每个前缀和运算固定。 
4. 对于 (n\le m)，计算最小数值阈值

 [
 L=\max(n,m-c+1)。 
]

 任何有效周期必须至少为 2 的幂 (n)，并且第一个非零列还需要 (q\ge m-c+1)。 

1. 如果(m<n)，则对包含(1)的第一行(r)执行对称扫描，然后设置

 [
 L=\max(m,n-r+1)。 
]

 1. 从(1)开始，重复将候选值加倍，直到至少为(L)。 结果值就是答案，因为每个可能的非零周期都是 2 的幂。 

### 为什么它有效

 该算法背后的不变性是每个非零返回时间都是 2 的幂。 对于 2 (q) 的幂，(q) 折叠前缀运算只是恒等式加上每个维度中 (q) 的移位。 如果 (q<\min(n,m))，则边界项强制每一行和每一列重复，同时强制边界区域为零，这仅适用于零矩阵。 因此每个非零矩阵都需要 (q\ge\min(n,m))。 

一旦(q\ge n)，当(n\le m)时，行移完全消失。 唯一剩下的变化是将每个单元格与其左侧的单元格 (q) 位置进行比较。 当 (c) 之前的所有列距离该边界足够远时，矩阵完全不变，给出 (q\ge m-c+1)。 与行句柄相同的参数 (m<n)。 因此，取满足两个下限的最小二乘方就是最小有效值 (k)。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    first = None

    if n <= m:
        for _ in range(n):
            row = input().strip()
            pos = row.find('1')
            if pos != -1:
                col = pos + 1
                if first is None or col < first:
                    first = col

        if first is None:
            print(1)
            return

        need = max(n, m - first + 1)

    else:
        for i in range(1, n + 1):
            row = input().strip()
            if first is None and '1' in row:
                first = i

        if first is None:
            print(1)
            return

        need = max(m, n - first + 1)

    ans = 1
    while ans < need:
        ans <<= 1

    print(ans)

if __name__ == "__main__":
    solve()
```输入是逐行处理的，因此程序永远不会分配 (n\times m) 矩阵。 当 (n\le m) 时，`row.find('1')`直接给出当前行的第一个非零列。 对所有行取最小值给出包含任意 (1) 的第一列。 

当 (m<n) 时，只有包含 (1) 的第一行重要，因此代码第一次记录当前行索引`'1' in row`成功了。 其余行仍然需要读取，因为它们是输入流的一部分。 

表达式`m - first + 1`和`n - first + 1`是上面导出的边界距离。 这`+1`是必不可少的。 如果第一个 (1) 位于最后一列，则 (m-c+1=1)，这正确地允许句点 (1)。 省略`+1`会错误地产生零作为阈值。 

Python 中不存在整数溢出问题，事实上答案最多是上面 2 的下一个幂 (10^6)，即 (1,048,576)。 因此，加倍循环仅执行大约二十次。

 ## 边缘情况

 全零矩阵是非零矩阵至少需要一个周期 (\min(n,m)) 的陈述的特例。 为了```
2 3
000
000
```没有第一个非零列或行。 该算法检测到这一点并立即返回 (1)。 对零应用前缀运算会产生零，因此最小正周期实际上是 (1)。 

(1\times m) 矩阵根本没有行交互作用。 考虑```
1 4
0001
```第一个非零列是 (4)，所以

 [
 L=\max(1,4-4+1)=1。 
]

 答案是（1）。 的前缀和`0001`模 (2) 仍为`0001`。 

现在考虑```
1 4
0100
```第一个非零列是 (2)，给出

 [
 L=\max(1,4-2+1)=3。 
]

 下面(3)的两个幂分别是(1)和(2)，所以答案是(4)。 (m-c+1) 中额外的 (+1) 使边界计算更加精确。 

同样的推理也适用于垂直方向。 为了```
4 1
1
0
0
0
```第一个非零行是 (1)，所以

 [
 L=\max(1,4-1+1)=4。 
]

 答案是（4）。 一列矩阵顶部的单个（1）会不断向下累加，因此直到移位长度达到整个维度时才会回到原来的位置。 

最后，考虑一个非零矩阵，其维度都足够大，以至于 2 的小幂可能看起来很诱人。 对于任何 (q<\min(n,m))，二次幂恒等式强制周期性为 (q)，而边界单元强制相应的初始条带为零。 这两个属性会一直传播，直到每个单元都为零。 因此，非零矩阵不能将 (q) 作为其周期。 这就是为什么该算法永远不需要检查较小维度以下的二的幂。
