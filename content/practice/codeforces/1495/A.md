 ## 解决方案
 ## 问题理解

 我们在平面上有两组点。 一组包含矿工，并且所有矿工都严格位于垂直轴上，因此每个矿工都有以下形式的坐标$(0, y)$。 另一组包含钻石矿，它们都严格位于水平轴上，因此每个矿都有以下形式的坐标$(x, 0)$。 每个点都属于这两个集合中的一个，并且矿工和矿井的数量相等。 

每个矿工必须被分配到一个矿场，形成两组矿场的完美匹配。 配对矿工的成本为$(0, y)$有一个地雷$(x, 0)$是欧几里得距离$\sqrt{x^2 + y^2}$。 任务是选择最小化这些距离总和的配对。 

输入大小可达$n = 10^5$每个测试用例，所有测试用例的总和$n$跨测试用例也受$10^5$。 这立即排除了任何尝试所有匹配的方法，因为阶乘数的分配是不可能的。 甚至$O(n^2)$解决方案太慢了，因为它们需要大约$10^{10}$最坏情况下的操作。 

一个微妙的困难来自于坐标可以是正数或负数，并且距离取决于平方值。 诸如匹配最小绝对值或独立地通过坐标符号匹配之类的天真的贪婪想法可能会失败。 例如，如果矿工处于$(0, 1)$,$(0, 100)$和地雷$(1, 0)$,$(2, 0)$，按绝对值排序顺序配对似乎合理，但忽略了交叉配对可以更有效地减少大距离。 

另一个重要的边缘情况是许多点共享相同的坐标大小但符号不同。 由于距离取决于平方，对称性并不立即意味着简单的配对，除非我们正确地推理平方根函数在正参数上的单调性。 

## 方法

 暴力方法会尝试矿工和矿场之间的所有可能的双射并计算总成本。 这是正确的，因为它评估所有分配，但双射的数量是$n!$，即使对于$n = 10^5$。 即使我们限制在较小的情况下，计算仍然是不可行的。 

更结构化的方法来自于观察每个成本仅由配对决定$(|x|, |y|)$，因为距离是$\sqrt{x^2 + y^2}$。 关键思想是，我们实际上并不关心出于排序目的的符号，只关心大小。 一旦我们按照矿工的绝对值对矿工进行排序$y$- 坐标和地雷的绝对值$x$- 坐标，我们可以证明，按排序顺序将它们配对可以最小化由平方和的平方根引起的凸成本之和。 

直觉类似于交换论证：如果两对在排序上“交叉”，交换它们不会增加总成本，因为函数$f(x, y) = \sqrt{x^2 + y^2}$对于两个参数而言，以对称凸方式表现出单调性。 这将最佳匹配推向排序对齐。 

因此，问题简化为按绝对值对两个列表进行排序并将相应元素配对。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n!)$|$O(n)$| 太慢了|
 | 最佳|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们将矿工和矿井分开，提取它们的绝对坐标，并对两个数组进行排序。 然后我们逐个索引将它们配对。 

1.读取所有点并将其分成两个数组：矿工和地雷。 我们使用绝对值，因为距离仅取决于平方，并且符号不影响排序决策。 
2.收集所有矿工$y$-将坐标放入一个列表和所有我的列表中$x$- 坐标到另一个列表中。 
3. 按非降序对两个列表进行排序。 这会将最小的量值排列在一起，并将最大的量值与最大的量值对齐。 
4. 从左到右迭代并计算$\sqrt{x_i^2 + y_i^2}$对于每一对，累加总和。 
5. 高精度输出最终总和。 

重要的步骤是排序和配对规则。 正确性来自于以下事实：由于距离函数在独立绝对值上的对称凸性质，配对中的任何反转都可以交换以减少或维持总成本。 

### 为什么它有效

 考虑两个具有规模的矿工$a \le b$以及两座规模巨大的地雷$c \le d$。 有两种可能的配对：$(a, c), (b, d)$和$(a, d), (b, c)$。 最优结构由不等式表示$$\sqrt{a^2 + c^2} + \sqrt{b^2 + d^2} \le \sqrt{a^2 + d^2} + \sqrt{b^2 + c^2}.$$这是成立的，因为配对震级之间不断增加的不平衡会增加总欧几里得成本。 重复应用此交换参数会删除所有反转，从而导致排序配对达到最佳状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

t = int(input())
out_lines = []

for _ in range(t):
    n = int(input())
    miners = []
    mines = []

    for _ in range(2 * n):
        x, y = map(int, input().split())
        if x == 0:
            miners.append(abs(y))
        else:
            mines.append(abs(x))

    miners.sort()
    mines.sort()

    total = 0.0
    for i in range(n):
        total += math.sqrt(miners[i] * miners[i] + mines[i] * mines[i])

    out_lines.append(str(total))

print("\n".join(out_lines))
```该代码首先根据轴成员资格分离输入。 这避免了混合角色，这是至关重要的，因为配对仅在两个组之间有效。 取绝对值可确保大小比较的一致性。 

对两个列表进行排序是强制执行最佳配对的结构步骤。 最后的循环直接对每个匹配对应用欧几里德距离公式。 浮点运算在这里是安全的，因为该问题允许非常小的误差容限，而Python的双精度就足够了。 

一个常见的实施错误是忘记严格区分矿工和矿场，或者尝试对包括符号在内的原始坐标进行排序，这会破坏单调配对参数。 另一个微妙的问题是对中间值使用整数运算； 由于距离涉及平方根，因此一切都必须以浮点计算。

 ## 边缘情况

 当所有矿工和矿井以重复的绝对值对称放置时，例如距原点距离相同的多个点，排序仍然会产生有效的配对，因为相等元素内的任何排列都会保留总成本。 该算法不依赖于平局决胜。 

当一方极度不平衡时，例如矿工$[1, 1, 1]$和地雷$[1, 100, 100]$，该算法确保小值首先与小值配对，最后留下大值与大值配对，这可以防止不必要的中间成本膨胀。 

在所有值都相同的情况下，每个配对都会产生相同的总成本，并且排序退化为任意匹配而不影响正确性。
