 ## 解决方案
 ## 问题理解

 我们被要求计算在非常有限的结构信息下有多少种不同的阿霍-科拉西克自动机可以产生某种最终形状。 

此设置中的阿霍-科拉西克自动机是由两个交织在一起的对象构建的。 第一个是由一些未知的字符串集在大小的字母表上形成的特里树$m$，其中每个字符串的长度最多$d$。 trie 是最小的，因为它每个不同的前缀只包含一个节点。 trie 的每条边都由一个字符标记，并且任何节点都不能有两条具有相同标签的出边。 

第二个对象是故障结构。 每个节点都有一个失败链接，该链接指向与仍然存在于 trie 中的其字符串的最长正确后缀相对应的节点。 这些故障链接在同一组节点上形成有根树。 

最终的自动机只是 trie 边和故障边的并集。 我们没有得到字符串，甚至没有特里树或自动机本身。 我们只知道最终的结构有$n$节点，使用大小的字母表$m$，并且所有原始字符串的长度最多$d$。 任务是计算有多少不同的自动机可以满足这些约束。 

如果存在保留根并保留边的存在和标签、忽略节点身份的节点重新标记，则两个自动机被认为是相同的。 

限制条件$n, m, d \le 100$表明我们处于纯组合计数状态。 任何尝试显式枚举图结构而无需在仔细压缩的状态上进行动态编程的解决方案都会立即太大。 即使存储完整的标记图也已经是二次的，并且尝试或树的简单枚举呈指数增长$n$。 

一个微妙的点是，故障结构不是任意的。 失败链接总是从一个节点到另一个节点，其字符串是适当的后缀，这意味着它必须对应于严格较短的字符串，因此特里树中的深度严格较小。 这引入了一个隐藏的全局排序约束，该约束稍后将控制如何选择故障链接。 

第二个微妙点是深度的界限是$d$。 这使得特里树最多成为一棵高度为有根的树$d$，这是实现基于层的动态规划方法的主要结构限制。 

## 方法

 直接方法会尝试构建所有可能的尝试$n$带有大小字母表边缘标签的节点$m$，然后为每个 trie 构造与后缀关系一致的所有有效失败树。 即使对于单独的 trie，这也已经是指数级的：每个节点都可以将子节点分配给$m$标签并将剩余节点划分为子树，从而产生超指数数量的形状。 

甚至忽略故障链接，计算标记的尝试大小$n$有高度限制$d$需要一个非平凡的树 DP。 天真地添加故障链接会使可能性大约增加$O(n!)$在最坏的情况下，因为每个节点可以在许多候选者中选择一个有效的后缀祖先。 

一旦我们了解了实际影响每个部分的因素，关键的简化就是将问题分成两个独立的结构层。 

trie 确定每个节点的深度以及每个深度级别的节点数。 一旦这些深度计数被固定，有效故障链接的数量就纯粹是这些计数的前缀和的函数：深度的节点$k$只能指向深度的一个节点$0$通过$k-1$。 因此，故障链接的贡献会影响深度级别。 

trie 本身可以使用有根树 DP 独立生成，其中每个节点选择多个子节点，最多可达$m$，为传出边分配不同的标签，并将剩余节点分配到子树中。 这是带有标记边缘选择的标准组合树结构。 

剩下的困难是将这两个部分耦合起来：每个特里树形状都会产生特定的深度分布，并且每个深度分布都会从故障链接选择中贡献一个乘法因子。 这使得问题成为树结构上的 DP，同时跟踪每个深度出现的节点数量。

 ## 算法演练

 我们围绕有根 DP 构建解决方案，该 DP 构建 trie，同时记录深度信息并累积故障链接贡献。 

### 1. 将 trie 解释为带有标记边的有根有序结构

 每个节点选择$k \le m$孩子们。 传出边上的标签必须是不同的，因此选择子项相当于选择子树的标签的有序分配。 对于固定的$k$，标签分配的数量是$P(m, k)$, 分配方式的数量$k$不同的标签$m$到$k$孩子们。 

剩下的问题是在这些子树之间分配子树大小，因为子树是独立的。 

### 2. 定义子树大小和高度的 DP

 我们定义一个函数$F(s, h)$作为构建大小为 trie 子树的方法数$s$最多有高度$h$。 这样一棵子树的根消耗一个节点，剩余的$s-1$节点在子节点之间分配。 

对于每个节点，我们尝试所有可能的$k$子级、分配标签和分区$s-1$进入$k$正数部分代表子树大小。 每个部分都使用递归求解$F(\cdot, h-1)$。 

这个 DP 单独计算所有有效尝试，深度范围为$d$。 

### 3.追踪节点深度分布

 计算时$F$，我们还需要知道每个深度有多少个节点，因为故障链接取决于它。 我们改进了 DP，使每个状态隐式地携带跨深度的节点分布。 我们没有显式地存储完整向量，而是逐个深度地处理深度。 

构造子树时，子子树中的所有节点的深度都会移动 1。 这使我们能够维护一个全局结构，在该结构中我们逐步处理级别。 

### 4. 根据深度计数计算故障链接贡献

 一旦修复了 trie，让$cnt_k$是深度的节点数$k$。 定义前缀和$pref_k = cnt_0 + \cdots + cnt_k$。 

深度节点$k$可以在深度严格小于的任何节点中选择其故障父节点$k$，所以它正好有$pref_{k-1}$选择。 

因此，固定特里树的故障链接配置总数为$$\prod_{k=1}^{d} (pref_{k-1})^{cnt_k}.$$该因素仅取决于深度计数，而不取决于内部树形状。 

### 5. 将 trie DP 与失败贡献合并

 在 DP 期间，每个部分构造都保持当前的深度分布。 当组合子树时，我们更新分布并乘以每个深度的节点贡献的相应故障链接因子。 

根不提供失败选择。 每次我们在深度上完成一个节点$k$，我们乘以较浅节点的当前前缀大小，再乘以该深度的节点数。 

### 6. 所有有效结构的最终 DP

 我们迭代所有可能的方法来构建大小字典树$n$直至深度$d$，总结 trie 结构和故障链接分配的贡献。 

答案是总累加值模$998244353$。 

### 为什么它有效

 正确性来自于结构的干净因式分解。 trie 唯一确定节点的深度和父子关系的约束。 给定深度，故障链接成为仅受深度排序约束的独立选择，并且每个节点的选择仅取决于较早深度节点的计数。 因为每个有效的自动机恰好对应于一个特里树和一个有效的故障分配，并且这两个组件在 DP 中只计数一次，所以结果既不会被多计数，也不会少计数。

## 工作示例

 由于语句摘录不包括完整的示例解释或输出，因此在最小构造案例上说明机制比提供的示例更有用。 

考虑$n = 3, m = 2, d = 2$。 有一根。 一种可能的 trie 形状是具有两个子元素的根。 两个孩子都在深度 1，所以$cnt_0 = 1, cnt_1 = 2$。 

失败贡献为：$$pref_0^{cnt_1} = 1^2 = 1.$$因此对于这种形状，失败链接是强制的：两个深度为 1 的节点只能指向根。 

另一种 trie 形状是长度为 3 的链。然后$cnt_0 = 1, cnt_1 = 1, cnt_2 = 1$。 失败贡献变为：$$pref_0^1 \cdot pref_1^1 = 1^1 \cdot 2^1 = 2.$$深度 2 节点可以选择根节点或深度 1 节点作为其故障父节点，这与公式匹配。 

这些痕迹表明，一旦深度计数已知，故障链接就可以通过组合方式完全确定，并且与子树结构无关。

 ## 边缘情况

 最小输入$n=1$仅包含根。 特里树没有边，也没有可供选择的失败链接。 该算法准确地返回一种结构，因为 trie DP 和故障贡献都减少为空乘积。 

退化的字母大小写$m=1$强制每个节点最多有一个子节点。 trie变成了链，DP只统计线性结构。 然后，故障链路仅依赖于前缀计数，并且 DP 自然地简化为单个路径构造。 

最大高度案例$d = n - 1$允许完全倾斜的特里树。 在这种情况下，深度计数变得稀疏，并且故障链接在更深的节点处获得最大的灵活性。 随着深度的增长，前缀乘积公式正确地增加了贡献，因为每个更深的节点都有更多可能的后缀祖先。
