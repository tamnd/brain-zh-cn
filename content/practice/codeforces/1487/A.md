 ## 解决方案
 ## 问题理解

 我们拥有一系列英雄，每个英雄都有初始强度或等级。 他们两两对战，每当两个不同等级的英雄相遇时，强者获胜并变得更强。 如果他们的水平相同，那么战斗就是平局，没有人会得到任何好处。 我们被要求找出如果我们可以任意选择战斗顺序，有多少英雄有机会成为最终冠军。 换句话说，如果存在一系列战斗，并且该英雄最终赢得了天文数字般的大量决斗，则该英雄可能是胜利者。 

输入提供英雄的数量及其初始等级。 输出是在某些战斗序列下可能获胜的英雄数量。 和$n$最多$100$和水平上限为$100$，我们可以单独考虑每个英雄并推理相对级别。 对所有可能的序列进行强力模拟是不切实际的，因为序列的数量呈爆炸式增长。 

一个微妙的边缘情况是所有英雄都具有相同的等级。 在这种情况下，每场战斗都是平局，因此没有英雄可以积累胜利。 例如，有级别`[5, 5]`，答案是`0`。 当只有一个英雄严格强于其他英雄时，就会出现另一种边缘情况； 只有那个英雄才能获胜。 为了`[3, 2, 2]`，只有最强的英雄才有可能获胜。 幼稚的方法可能会错误地将第二高等级的英雄视为获胜者，因为他们可以赢得小规模的战斗，但实际上，他们永远无法在针对最终获胜者优化的序列中超越最强的英雄。 

## 方法

 暴力方法会尝试模拟所有的战斗序列。 对于每个英雄，我们可以尝试每一种可能的对决并取得胜利。 这在原理上是正确的，但所需的战斗次数是天文数字（`100^500`），因此任何实际模拟都是不可能的。 即使对于`n = 100`，使其不可行。 

关键的观察是，只有当英雄的等级不严格小于最终能够超越他们的潜在对手的最小等级时，英雄才有可能成为获胜者。 具体来说，最低等级的英雄永远无法阻止更强的英雄获胜，而等级低于最高等级的英雄也无法阻止最高等级的英雄最终获胜。 因此，我们只需要考虑等级最低的英雄即可。 如果英雄的等级大于或等于数组中的最低等级，则该英雄可能成为获胜者。 

这种见解将问题简化为找到最小等级并计算等级大于的英雄`min_level`。 If all heroes are tied at the minimum level, no one can win, which matches the edge case discussed above.

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，处理以下步骤。 
2. 阅读`n`，英雄的数量，以及他们的等级数组`a`。 
3.确定所有英雄的最低等级。 该级别代表可以参与获胜序列的“最弱”可能英雄。 
4. 统计所有等级严格高于此最小值的英雄。 这些英雄之所以成为候选，是因为他们总是能够压倒最低等级的英雄，直到最后。 
5. 打印当前测试用例的计数。 

为什么有效：如果存在严格更强的英雄，那么英雄就不可能成为可能的获胜者，因为最终该英雄总是会在胜利中超越他们。 相反，任何等级高于最低等级的英雄都可以在一定的战斗序列中淘汰较弱的英雄或保持领先地位，并积累所需的胜利。 这将问题简化为与最低水平的简单比较。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    min_level = min(a)
    count = sum(1 for x in a if x > min_level)
    print(count)
```该解决方案首先读取测试用例的数量。 对于每个测试用例，它都会读取英雄级别并计算最小值。 然后，我们严格计算英雄的强度，使其强于最低限度。 使用生成器表达式可以避免不必要的中间列表。 这确保了每个测试用例的处理时间为 O(n)，在给定约束的情况下这是高效的。

 所有英雄都有相同的等级。 最小值是`5`并且没有哪个英雄是严格意义上更强的，所以计数是`0`。

 最小值为`1`。 三个英雄严格来说更强，所以答案是`3`。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        min_level = min(a)
        count = sum(1 for x in a if x > min_level)
        print(count)
    return output.getvalue().strip()

 ## 边缘情况

 如果所有英雄的等级相同，则最低等级等于所有等级，并且没有严格意义上的英雄更强。 算法正确返回`0`。 对于拥有一名特强英雄和多名弱英雄的英雄，算法仅将强英雄视为可能的获胜者。 对于小数组（`n = 2`），该算法可以正确处理相等和不相等的值。 该实现也适用于最大允许级别（`100`）和最大英雄数量（`100`）没有溢出或低效率。
