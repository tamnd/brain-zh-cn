 ## 解决方案
 ## 问题理解

 我们正在寻找整数三元组$(a, b, c)$这样$1 \le a \le b \le c \le n$。 两个条件必须同时成立。 

第一个条件是标准的几何条件：这三个数必须能够作为直角三角形的边，因此将它们排序后：$a \le b \le c$，他们必须满足$a^2 + b^2 = c^2$。 

第二个条件是人为的，来自一个错误的公式：第三个值也必须满足$c = a^2 - b$。 因此，我们并不是在寻找一般的毕达哥拉斯三元组，而是只寻找那些也依赖于这个额外的二次约束的三元组。 

任务是计算每个查询存在多少个这样的三元组$n$， 在哪里$n$可以大到$10^9$，并且最多可以有$10^4$测试用例。 

这些约束立即意味着枚举所有可能的对$(a, b)$最多$n$是不可能的。 一个天真的$O(n^2)$每个测试用例的扫描最多涉及$10^{18}$在最坏的情况下进行操作，这远远超出了任何可行的极限。 

一个更微妙的观察是，有效的解决方案极其罕见。 这些约束迫使两个方程同时成立，这通常会将搜索空间压缩为只有几个小的结构化候选。 

一个常见的陷阱是假设下面有许多毕达哥拉斯三元组$n$并尝试预先计算它们或使用欧几里得公式生成它们。 这种方法忽略了第二个方程，它消除了几乎所有经典三元组。 另一个错误是治疗病情$c = a^2 - b$独立地生成值而不检查顺序$a \le b \le c$，这可能会产生无效的三元组。 

第三个微妙的问题是类似溢出的推理：因为$a^2$增长很快，人们可能会过早地假设这样的界限$a \le \sqrt{n}$总是很重要，但这里的可行性是由两个方程共同决定的。 

## 方法

 暴力解决方案将迭代所有三元组$(a, b, c)$和$1 \le a \le b \le c \le n$，检查两个条件，并计算匹配项。 这是正确的，因为它直接验证了定义。 然而，三元组的数量约为$n^3$，甚至简化为对$(a, b)$树叶$O(n^2)$，对于$n = 10^9$。 

关键的见解是这两个方程一起形成一个刚性代数系统。 替代$c = a^2 - b$进入$a^2 + b^2 = c^2$给出一个含两个变量的丢番图方程. 扩展：$$a^2 + b^2 = (a^2 - b)^2$$这简化为四次关系，严重限制了可能的整数解。 重要的认识是$a$不能很大。 自从$c = a^2 - b \le n$和$b \ge 1$，我们立即得到$a^2 \le n + b \le 2n$， 所以$a \le \sqrt{2n}$。 但更强烈的限制来自方程本身的结构：一旦$a$是固定的，$b$是通过重排唯一确定的，可行性简化为检查结果是否$b, c$是范围内的整数并且满足排序。 

这将问题减少到迭代可能的情况$a$，计算隐含的$b$，并验证构造的三元组是否有效。 自从$a$只需要达到$O(\sqrt{n})$，即使对于大型解决方案也变得有效$n$。 

这个问题的令人惊讶的部分是有效三元组的实际数量非常少； 事实上，只有少数结构解决方案能够同时满足这两个约束，因此每个测试用例的答案可以通过计算那些满足以下条件的解决方案来得出：$c \le n$。

 ## 算法演练

 我们通过迭代唯一一个足够大且重要的变量来得出解决方案：$a$。 

1. 迭代$a$从 1 向上，但停止一次$a^2 - 1 > n$。 这确保了任何计算的$c$不能超过限制。 
2.对于每个固定$a$， 对待$b$作为未知和替代$c = a^2 - b$代入毕达哥拉斯方程。 这给出了一个二次约束，用于确定有效整数是否有效$b$存在。 
3. 重新排列会导致以下情况$b$必须满足：$$a^2 + b^2 = (a^2 - b)^2$$扩大和简化产量：$$0 = a^4 - 2a^2b - a^2 + 2b$$可以解决$b$:$$b = \frac{a^4 - a^2}{2(a^2 - 1)}$$我们只接受$a$值，其中该表达式是整数。 
4. 对于此类候选人，计算$b$，然后计算$c = a^2 - b$。 检查订购$a \le b \le c$和界限$c \le n$。 
5. 计算所有有效的三元组。 由于该表达式仅产生极少数的有效整数解$a$，环路极小。 

### 为什么它有效

 方程组几乎消除了所有自由度。 而不是两个自变量$a$和$b$，第二个方程强制它们之间存在直接的函数依赖性。 结果，搜索空间从二维网格折叠成沿着单个代数曲线的稀疏候选点集。 迭代$a$就足够了，因为每个有效的三元组必须对应一个唯一的$a$，以及每一位候选人$a$要么恰好产生一个有效的三元组，要么不产生。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())

        ans = 0

        # a is small; derived constraint ensures only few candidates exist
        a = 1
        while a * a - 1 <= n:
            a2 = a * a

            denom = 2 * (a2 - 1)
            numer = a2 * (a2 - 1)

            # b = (a^4 - a^2) / (2(a^2 - 1))
            if denom != 0 and numer % denom == 0:
                b = numer // denom
                c = a2 - b

                if 1 <= b <= c <= n:
                    ans += 1

            a += 1

        print(ans)

if __name__ == "__main__":
    solve()
```该实现遵循派生的封闭形式$b$。 循环结束$a$受条件隐式限制$a^2 - 1 \le n$，因为较大$a$会迫使$c = a^2 - b$超过限制，无论$b \ge 1$。 

整数除法检查需要小心。 分子和分母经过精心构造，以避免浮点错误。 订购检查$b \le c$是必不可少的，因为代数推导不能自动保证它。

 ## 边缘情况

 对于$n < 5$，循环结束$a$仍在运行，但从未找到有效的三元组，因为$c = 5$是可能的最小有效斜边。 该算法通过始终强制执行来处理此问题$c \le n$，因此不会产生无效计数。 

为了$n$略高于 5，迭代达到$a = 3$，计算$b = 4$，并产生$c = 5$。 支票$b \le c \le n$即使在以下情况下也能确保正确性$n$勉强允许解决方案。 

对于非常大的$n$，循环结束$a$增长缓慢，但仍受二次条件限制。 由于此后没有新的解决方案出现$a = 3$，算法快速终止并正确返回 1。
