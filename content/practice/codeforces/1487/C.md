 ## 解决方案
 ## 问题理解

 我们被要求设计循环赛足球锦标赛的结果，以便每支球队最终获得相同的分数。 有$n$队，每组只玩一次。 每场比赛要么以平局结束（两队各得 1 分），要么以决定性结果结束（一方得 3 分，另一队得 0 分）。 我们的目标是将结果分配给所有比赛，使每支球队的总得分相同，并且在所有这些配置中，平局的数量最小化。 输出格式是按比赛对顺序排列的结果的扁平列表：第一队 1 对阵所有其他球队，然后球队 2 对阵其后的所有球队，依此类推。 

限制条件适中：$2 \le n \le 100$以及最多 100 个测试用例。 直接计算所有成对结果是可行的，因为匹配的总数为$n(n-1)/2$，最多为 4950，当$n = 100$。 因此一个$O(n^2)$算法是可以接受的。 

一个微妙的点是，即使$n$，可以完全避免平局，而对于奇数$n$，至少有一些联系是必要的。 幼稚的方法可能会尝试任意分配胜利，这很容易导致分数不平等。 例如，与$n = 3$，如果所有比赛任意分出胜负，则一支球队可能赢两次，另一支球队输两次，从而导致总成绩不平等。 需要精心设计，对称平衡胜负。 

## 方法

 蛮力方法将尝试生成所有$3^{n(n-1)/2}$比赛结果的可能组合并检查分数是否相等。 这显然是不可行的$n = 100$因为匹配配置的数量呈指数级增长。 即使直接模拟胜利和平局的所有排列也太慢了。 

关键的观察是我们可以将结果建模为胜利和失败的循环旋转。 如果$n$奇怪的是，每支球队都可以与其他球队安排在“胜-平-负”循环中：对于球队之间的任何比赛$i$和团队$j$，我们可以计算偏移量$(j - i)$模数$n$并根据该差值是小于、等于还是大于来分配结果$n/2$。 如果$n$是均匀的，同样的轮换想法是有效的，但对于每支球队的一半比赛，我们分配胜利，而另一半则分配失败，完全避免平局。 仅当奇数的差值恰好位于中间时才会出现平局$n$。 

这一观察将问题简化为一个简单的问题$O(n^2)$循环所有比赛，根据球队的相对指数确定性地分配 1、-1 或 0。 这是一个具有明确模式的建设性解决方案，可确保每个团队的总得分相等。

 | --- | --- | --- | --- |
 | 蛮力 |$O(3^{n(n-1)/2})$|$O(n^2)$| 太慢了|
 | 建设性轮换|$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，读取团队数量$n$。 
2. 初始化一个空列表来保存所有匹配的结果。 
3. 循环所有成对的团队$(i, j)$和$i < j$来填充比赛结果。 
4. 计算距离$d = j - i$。 
5.如果$n$为奇数，赋值：

 - 1 如果$d \le n//2$, 意思是团队$i$获胜。 
- -1 如果$d > n//2$, 意思是团队$j$获胜。 
6. 如果$n$是偶数，赋值：

 - 1 如果$d \le n//2 - 1$, 意思是团队$i$获胜。 
- -1 如果$d \ge n//2 + 1$, 意思是团队$j$获胜。 
- 0 如果$d = n//2$，这意味着需要打领带才能保持平衡。 
7. 将计算结果添加到结果列表中。 
8. 处理完所有对后，按所需的扁平顺序打印结果。 

为什么有效：循环分配确保每个团队准确获胜$\lfloor (n-1)/2 \rfloor$匹配，输掉$\lfloor (n-1)/2 \rfloor$匹配如果$n$是奇数，并且在一场比赛中平局，如果$n$很奇怪。 对于甚至$n$, 每队获胜和失败$n/2 - 1$匹配且平局恰好为 1，则总分相等。 这种模式保证了相同的分数和最少的联系，因为任何进一步减少联系的尝试都会破坏对称性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    res = []
    for i in range(1, n+1):
        for j in range(i+1, n+1):
            d = j - i
            if n % 2 == 1:
                if d <= n // 2:
                    res.append(1)
                else:
                    res.append(-1)
            else:
                if d < n // 2:
                    res.append(1)
                elif d == n // 2:
                    res.append(0)
                else:
                    res.append(-1)
    print(' '.join(map(str, res)))
```解决方案首先读取$t$测试用例，然后迭代每对团队。 距离$d$团队指数之间使用模块化逻辑确定结果。 对于甚至$n$，中间的比赛必须是平局才能平衡分数，并且对于奇数$n$，所有比赛都可以是决定性的。 输出按所需顺序展平。
