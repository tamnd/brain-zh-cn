 ## 解决方案
 ## 问题理解

 我们有一张长方形的桌子，上面有尺寸`a × b`以及无限量供应相同半径的圆板`r`。 两名玩家轮流将盘子放在桌子上。 每个板块必须完全位于矩形内，板块可以接触但不能重叠。 

当当前玩家无法放置另一个盘子时，游戏结束。 两名玩家都发挥最佳，我们必须确定第一名还是第二名玩家获胜。 

几何形状比乍一看要简单得多。 半径为一盘`r`仅当其中心至少保持在桌子内部时才适合`r`远离每个边界的单位。 这意味着中心必须位于尺寸较小的矩形内`(a - 2r) × (b - 2r)`。 

约束很小，每个值最多`100`，因此即使是强力几何模拟在技术上也符合限制。 真正的挑战是正确识别游戏结构并简化几何图形。 

关键的边缘情况是恰好适合一块板的情况。 例如：```
5 5 2
```正确答案是`"First"`因为可以将一个盘子放在中心，然后游戏结束。 

粗心的方法可能会错误地认为可以放置更多位置，因为剩余的未覆盖区域很大。 实际的限制来自圆圈重叠，而不是未使用的区域。 

另一个微妙的情况是根本没有适合的板：```
3 3 2
```直径为`4`，比两个桌子的尺寸都大，所以即使是一个盘子也不能放置。 正确答案是`"Second"`因为第一个玩家没有动作。 

一个常见的错误是检查`a >= r`和`b >= r`而不是需要整个直径的空间。 正确的条件是`a >= 2r`和`b >= 2r`。 

还有一个触及边界的案例：```
4 7 2
```板直径正好等于工作台高度。 这仍然有效，因为允许触摸边界。 一块板适合，所以答案是`"First"`。 

使用严格不等式而不是非严格不等式的实现在这里会失败。 

## 方法

 暴力解释是对游戏进行几何建模。 人们可以尝试生成每个有效的板放置，检查与先前放置的圆圈的重叠，并使用极小极大递归地评估获胜和失败状态。 

这种方法原则上是正确的，因为游戏是有限的和确定性的。 问题是状态空间立即爆炸。 即使在离散化位置之后，配置的数量也会变得巨大，因为板中心可以连续变化。 完整的几何游戏搜索是完全不切实际的。 

突破性的观察是，棋盘上永远不能包含多于一个的棋盘。 

一块板有直径`2r`。 如果将两个盘子放在桌子上，它们的中心至少需要`2r`分开。 但任何有效的中心必须保留在矩形内：```
[r, a-r] × [r, b-r]
```如果两者都`a < 4r`或者`b < 4r`，没有足够的空间来分隔两个中心的距离`2r`。 

更直接地说，原始的 Codeforces 技巧甚至更简单。 由于两个板必须完全适合桌子内部，因此放置两个半径不重叠的圆`r`要求至少一个表尺寸至少为`4r`。 在问题约束和几何形状下，唯一重要的是至少一块板是否适合。 

如果没有合适的盘子，则第一个玩家立即失败。 

如果至少有一个盘子适合，则第一个玩家放置它并获胜，因为不存在第二步。 

所以游戏简化为一个条件：```
a >= 2r and b >= 2r
```如果为真，则打印`"First"`。 否则打印`"Second"`。

 ## 算法演练

 1. 阅读表格尺寸`a`和`b`，以及板半径`r`。 
2. 检查一张盘子是否能放在桌子上。 

板仅适合其直径`2r`不超过任一表格尺寸。 这给出了条件：$a \ge 2r \text{ and } b \ge 2r$3. 如果条件为真，则打印`"First"`。 

第一个玩家放置了唯一可能的棋盘，并且没有留下任何合法的棋步。 
4. 否则，打印`"Second"`。 

根本无法放置任何盘子，因此第一个玩家立即失败。 

### 为什么它有效

 整个游戏取决于是否存在合法的第一步。 半径为一盘`r`需要一个正方形的边`2r`只是为了适合桌子里面。 如果任一表尺寸小于`2r`，不存在任何移动。 

如果确实存在移动，第一个玩家总是可以放置一个盘子。 此后，由于没有足够的剩余空间来容纳第二个相同半径的圆，因此无法在不重叠的情况下添加另一个板。 游戏总是持续零步或一步，因此获胜者完全取决于第一步的存在。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b, r = map(int, input().split())

    if a >= 2 * r and b >= 2 * r:
        print("First")
    else:
        print("Second")

solve()
```该实现直接反映了演练中的数学观察结果。 

表达式`2 * r`是板直径。 仅当桌子的两个尺寸至少都那么大时，盘子才适合。 

比较必须使用`>=`而不是`>`。 该问题明确允许触摸边框，因此直径与桌子尺寸完全匹配的板仍然有效。 

不需要循环或额外的内存，因为结果取决于单个几何检查。

import sys, io

def solve():
    input = sys.stdin.readline

    a, b, r = map(int, input().split())

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output

 ## 边缘情况

 考虑输入：```
4 7 2
```直径为`4`。 桌子的高度也正好`4`，因此圆同时接触顶部和底部边框。 

该算法检查：```
4 >= 4  -> True
7 >= 4  -> True
```和打印`"First"`。 

这证实了该实现正确地处理了非严格不平等。 

现在考虑：```
3 3 2
```直径为`4`，大于两个尺寸。 支票变成：```
3 >= 4  -> False
3 >= 4  -> False
```算法打印`"Second"`因为不存在合法安置。 

最后，考虑一种混合情况：```
10 3 2
```宽度足够大，但高度不够：```
10 >= 4 -> True
3 >= 4  -> False
```算法仍然打印`"Second"`因为板必须在两个尺寸上完全贴合。 一种常见的错误解决方案仅检查一个维度或使用基于区域的推理，这两种方法都失败了。
