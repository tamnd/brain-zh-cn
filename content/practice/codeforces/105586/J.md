 ## 解决方案
 ## 问题理解

 我们进行了重复的实验，其中每次试验都独立地以概率获胜$\frac{p}{q}$和概率损失$1 - \frac{p}{q}$。 我们从零胜零负开始，一直玩下去，直到达到两个停止条件之一。 如果我们获得，则该过程成功停止$n$在我们积累之前就获胜$n$损失。 如果损失达到则失败$n$第一的。 

任务是计算在此停止规则下成功的概率，并将其模输出$10^9 + 7$。 

重新解释该过程的一个有用方法是将其视为一维行走。 每次胜利都会让我们+1，每次失败都会让我们-1。 我们从位置 0 开始。当我们击中任一位置时，该过程结束$+n$（成功）或$-n$（失败）。 问题变成：有偏随机游走命中的概率是多少$+n$前$-n$？ 

约束允许最多$10^4$测试用例和总共$5 \cdot 10^6$跨越所有$n$。 这排除了每个测试用例所有状态上的任何模拟或 DP。 任何解决方案都必须将每个测试用例简化为对数或恒定时间模幂。 

模拟步行的简单方法在吸收之前需要指数时间的预期时间，并且立即是不可能的。 甚至是状态的动态规划解决方案$-n$到$n$每个测试用例将是$O(n^2)$或者充其量$O(n)$，这对于全局约束来说太慢了。 

出现微妙的边缘情况时$\frac{p}{q} = \frac{1}{2}$。 在这种对称情况下，随机游走没有漂移，对称性意味着到达的概率$+n$前$-n$正是$\frac{1}{2}$，独立于$n$。 基于公式的盲目除法实现$1 - r^{2n}$仍然可以工作，但如果处理不当，可能会出现模块不稳定的情况。 

## 方法

 暴力思想是将过程建模为表示当前净得分的状态上的马尔可夫链，并使用动态编程计算吸收概率。 让$dp[i]$是最终到达的概率$+n$从状态开始$i$。 我们将设置边界条件$dp[n] = 1$和$dp[-n] = 0$，然后求解线性递推。 然而，每个状态都依赖于两个邻居，并且求解所有状态的该系统需要在三对角系统上进行迭代松弛或高斯消去。 即使进行了优化，考虑到总的测试用例独立执行此操作也太慢了$n$最多$5 \cdot 10^6$。 

关键的观察是，这是一个具有对称吸收边界的经典赌徒破产问题。 这样的过程允许一个封闭形式的解，该解仅取决于步骤概率之间的比率，而不取决于 DP 图的绝对结构。 一旦我们用比率来表达系统$r = \frac{q-p}{p}$，概率分解为通过求解递推关系导出的简单几何表达式。 

这将每个测试用例减少为计算一些模幂和模逆。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |

 | 最佳闭合形式|$O(\log n)$每次测试 |$O(1)$| 已接受 |

 ## 算法演练

 我们将概率模型转换为具有吸收边界的有偏随机游走，然后评估已知的封闭形式。 

1. 将成功概率转换为模算术形式。 一步获胜的概率为$\frac{p}{q}$，所以我们使用模逆来表示下面的分数$10^9 + 7$。 
2. 定义失效概率为$\frac{q-p}{q}$。 这使我们能够使用失败与成功的比率来表达步行的偏差。 
3. 构建漂移比$r = \frac{q-p}{p}$。 这个比率反映了我们单步向下移动的可能性比向上移动的可能性有多大，与共同分母无关$q$。 
4. 计算$r^n$和$r^{2n}$使用模数下的快速求幂。 这些值对应于到达吸收边界的路径的概率加权贡献。 
5.如果$r = 1$，这发生在当$q = 2p$,直接输出$\frac{1}{2}$模数$10^9 + 7$，因为步行是对称的。 
6. 否则使用封闭形式计算最终概率：$$\frac{1 - r^n}{1 - r^{2n}}$$在模运算下，用模逆乘法代替除法。 

正确性来自于求解有界偏置随机游走中吸收概率的递归。 概率函数满足具有常数系数的二阶线性递推。 其通解是以下幂的线性组合$r$，以及边界条件$-n$和$+n$唯一地确定系数，准确地产生所述公式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    T = int(input())
    inv2 = (MOD + 1) // 2

    for _ in range(T):
        n, p, q = map(int, input().split())

        if 2 * p == q:
            print(inv2)
            continue

        # r = (q-p)/p
        r = (q - p) * pow(p, MOD - 2, MOD) % MOD

        rn = mod_pow(r, n)
        r2n = rn * rn % MOD

        numerator = (1 - rn) % MOD
        denominator = (1 - r2n) % MOD

        ans = numerator * pow(denominator, MOD - 2, MOD) % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```该实现首先将概率转换为消除公分母的比率$q$。 这很重要，因为保持$q$在求幂内部是不必要的并且速度较慢。 

快速求幂用于$r^n$因为$n$可以大到$10^5$，并且有很多测试用例。 模逆仅在最后的除法步骤中应用，避免了重复的逆。 

对称情况单独处理以避免表达式中被零除$1 - r^{2n}$，否则当$r = 1$。 

## 工作示例

 考虑一个简单的案例$n = 1, p = 1, q = 2$。 这里$r = 1$，所以我们立即落入对称分支。 答案是$\frac{1}{2}$。 

| 步骤| r | r^n | r^{2n} | r^{2n} | 结果 |
 | --- | --- | --- | --- | --- |
 | 初始化| 1 | 1 | 1 | 对称情况|

 这证实了当成功和失败的可能性相同时，第一步决定一切。 

现在考虑$n = 2, p = 1, q = 3$。 那么成功的概率就是$1/3$，失败是$2/3$， 所以$r = 2$。 

| 步骤| r | r^2 | r^2 r^4 | r^4 分子| 分母|
 | --- | --- | --- | --- | --- | --- |
 | 计算| 2 | 4 | 16 | 16$1-4$|$1-16$|

 最终概率变为：$$\frac{-3}{-15} = \frac{1}{5}$$这与该过程偏向于失败的直觉相符，因此在两次失败之前取得两次成功的可能性相对较小。

 ## 边缘情况

 最微妙的情况是当$q = 2p$。 在这种情况下，比率$r = \frac{q-p}{p} = 1$，这使得分母$1 - r^{2n}$变为零。 幼稚的实现会尝试零的模块化反转并崩溃​​或产生垃圾。 显式对称处理通过短路来完全避免这种情况$\frac{1}{2}$。 

另一个微妙的情况是当$n = 1$。 该过程在一步后结束，因此答案一定是第一次尝试获胜的概率，即$\frac{p}{q}$。 代入公式：$$\frac{1 - r}{1 - r^2} = \frac{1}{1 + r} = \frac{p}{q}$$这证实了一致性。 

最后，当概率很大并且重复计算模逆时，忘记减少中间值可能会导致溢出或不正确的模运算。 保持所有中间值取模$10^9 + 7$确保整个计算过程的稳定性。
