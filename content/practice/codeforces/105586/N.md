 ## 解决方案
 ## 问题理解

 我们在总统选举中得到了一小部分候选人名单，每个候选人都有一个名字和一个代表他们有多少支持者的数字。 任务是确定哪位候选人拥有最多的支持者并输出该候选人的名字。 

输入由单个整数组成$n$， 其次是$n$线。 每行描述一位候选人，使用字符串作为名称，使用整数作为支持者数量。 所有名字都不同且所有支持者数量不同的保证消除了任何有关关系的歧义，因此总是只有一个唯一的获胜者。 

从计算的角度来看，$n \le 10$，这是非常小的。 即使是天真的$O(n^2)$或者更糟糕的方法会非常快，但问题的结构表明直接线性扫描就足够了。 唯一有意义的约束是输入的解析必须正确并且我们正确地维护最大值。 

不存在涉及重复的棘手结构边缘情况，因为名称和值都保证是唯一的。 唯一微妙的故障模式是错误地初始化最大跟踪器或错误处理第一个元素，这可能会导致当所有值都为负或很小时丢失真正的最大值，尽管这里的值为正。 

典型的边缘情况是：

 输入：```
3
A 10
B 20
C 15
```正确的输出是`B`。 粗心的方法可能会错误地将最大支持者计数初始化为 0，并且如果变体问题中的所有值均为负数，则会失败，但这里的值至少为 1，因此该特定错误是无害的，但仍然是类似问题中的常见模式问题。 

## 方法

 最直接的策略是逐一阅读每个候选者，跟踪迄今为止看到的最佳候选者。 对于每个条目，我们将其支持者计数与当前最大值进行比较。 如果超过当前最佳值，我们将更新最大值和存储的名称。 

一种强力的解释是，对于每个候选人，扫描所有其他候选人以检查是否有更多的支持者。 这将涉及$O(n^2)$比较，这仍然完全没问题$n \le 10$，但它引入了不必要的重复工作和更复杂的代码，没有任何好处。 

关键的观察结果是，该问题是一个经典的单遍最大选择问题。 由于我们只需要一小部分对的全局最大值，因此我们不需要任何排序或重复比较。 一次遍历就足以保持正确性，因为当出现更大的值时，前缀的最大值总是可以增量更新。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 已接受但没有必要 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们按顺序处理候选人并保留迄今为止最好的候选人。 

1.读取考生人数$n$。 这告诉我们将在扫描中执行多少次更新。 
2. 读取第一个候选者并使用该值初始化当前最佳名称和最佳支持者计数。 这避免了必须发明哨兵值并保证正确性，即使所有值都很小。 
3. 对于剩下的每位候选人，读出其姓名和支持者人数。 
4. 将支持者数量与当前最佳值进行比较。 如果更大，则替换存储的最佳值和关联的名称。 这确保了最佳候选者始终对应于迄今为止看到的最大值。 
5. 处理完所有候选者后，输出存储的最佳名称。 

### 为什么它有效

 在扫描期间的任何时刻，算法都保持不变，即存储的对是迄今为止处理的所有候选者中的最大值。 每个新的候选者要么保留这个不变量（如果它不更大），要么通过用严格更大的支持者计数替换存储的对来恢复它。 由于每个候选都只处理一次，因此最终不变式扩展到整个输入，这意味着存储的候选是全局最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input().strip())

best_name = ""
best_count = -1

for i in range(n):
    name, cnt = input().split()
    cnt = int(cnt)
    
    if i == 0 or cnt > best_count:
        best_count = cnt
        best_name = name

print(best_name)
```该实现依赖于简单的线性扫描。 我们使用第一个元素或计数设置为 -1 的哨兵对来初始化最佳跟踪器。 这保证了任何有效的输入值将在需要时立即替换它。 

有条件的`i == 0`确保我们始终从实际数据正确初始化，而不是纯粹依赖哨兵逻辑。 比较`cnt > best_count`强制执行严格的最大跟踪，这是安全的，因为所有计数都是不同的。

 ## 边缘情况

 由于约束保证至少有一个候选者，唯一的结构边缘情况是处理$n = 1$。 在这种情况下，从第一个元素进行初始化会立即使其成为第一个和最佳候选元素，并且循环不会修改它。 

例如：```
1
Solo 42
```算法集`best_name = Solo`,`best_count = 42`，并跳过所有更新。 输出保持不变`Solo`，根据定义这是正确的。 

没有其他边缘情况影响正确性，因为没有联系，也没有缺失值，因此每次比较都是严格确定性的。
