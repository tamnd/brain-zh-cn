 ## 解决方案
 ## 问题理解

 我们有一个袋子，里面装着白老鼠和黑老鼠。 公主先移动，然后是龙，然后是公主，依此类推。 谁抽到白老鼠就获胜。 如果有人抽到黑色老鼠，游戏继续。 

在龙的回合中​​有一项额外的规则。 龙抽到一只老鼠后，另一只随机的老鼠从袋子里跳出来，因为剩下的老鼠惊慌失措。 跳起来的老鼠不算被任何人抽到，所以不能直接决定胜负。 

输入给出小白鼠的初始数量`w`和黑老鼠`b`。 如果每个随机选择都是均匀的，我们必须计算公主最终获胜的概率。 

该约束允许最多 1000 只白鼠和 1000 只黑鼠。 对所有可能的游戏序列的暴力模拟会呈指数级爆炸，因为每一步都会分支到几个未来状态。 即使没有记忆的递归搜索也会重新访问相同的内容`(w, b)`多次声明。 只有大约一百万个不同的状态，动态规划是可行的，但任何指数规划都是不可行的。 

这个问题最危险的部分是正确地模拟龙轮中的事件顺序。 粗心的实现通常会将多个概率步骤合并为一个，并意外地计算出不可能的转换。 

考虑输入：```
1 1
```公主先画。 她立即​​以概率获胜`1/2`。 如果她抽到了黑老鼠，龙就得到了唯一剩下的白老鼠并获胜。 正确答案是：```
0.5
```忽略回合顺序的错误重复可能会错误地产生`1`。 

另一个微妙的情况是：```
0 5
```根本没有白老鼠，所以公主永远不可能赢。 答案一定是：```
0
```一些递归解决方案在这里意外地被零除，因为它们试图计算涉及不存在的小白鼠的概率。 

第三个棘手的情况是：```
2 0
```公主立即以概率抽出一只白老鼠`1`，所以答案是：```
1
```涉及龙的转换永远不应该在这种状态下进行评估，因为游戏在公主迈出第一步时就已经结束了。 

## 方法

 暴力方法是递归地模拟每个可能的绘制和跳跃序列。 来自一个州`(w, b)`，我们根据公主画的是白色还是黑色进行分支，然后再次根据龙的绘制进行分支，然后再次根据跳开的老鼠进行分支。 

这种递归过程在数学上是正确的，因为每个游戏结果都对应于递归树中的一条路径。 问题在于路径的数量。 在最坏的情况下，每个回合会创建多个分支，游戏长度最多可达 2000 个事件。 在没有记忆的情况下访问的状态数量变得巨大，远远超出了 2 秒内所能容纳的范围。 

关键的观察是，未来只取决于剩下多少白鼠和黑鼠。 确切的历史并不重要。 如果两个不同的序列导致相同的结果`(w, b)`轮到公主的配置，从那时起最终获胜的概率是相同的。 

这使得这是一个经典的状态动态规划问题。 

定义`dp[w][b]`作为轮到公主且袋子当前包含公主时获胜的概率`w`白老鼠和`b`黑老鼠。 

从这个状态来看，只有几种可能。 

如果公主立即抽到一只白老鼠，她就赢了。 

如果她画了一只黑老鼠，那么接下来就是龙。 为了让公主在龙的回合中​​生存下来，龙还必须画出一只黑老鼠。 之后，另外一只老鼠跳走了。 根据跳跃的鼠标是白色还是黑色，我们转换到另一个较小的状态。 

每次转换都会严格减少老鼠的总数，因此我们可以自下而上地计算状态。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数递归树| 太慢了|
 | 最优动态规划| O(w × b) | O(w × b) | 已接受 |

 ## 算法演练

 1. 定义`dp[i][j]`作为轮到公主时获胜的概率`i`白老鼠和`j`剩下的黑老鼠。 
2. 初始化基本案例。 

如果没有白老鼠，公主就永远无法获胜：```
dp[0][j] = 0
```如果没有黑老鼠，公主肯定会立即画白：```
dp[i][0] = 1
```3. 迭代所有状态`(i, j)`和`i >= 1`和`j >= 1`。 
4. 计算公主在自己的抽牌中立即获胜的概率。 

她在所有老鼠中进行统一挑选，因此：```
win_now = i / (i + j)
```5. 计算公主首先画出黑色老鼠的概率。```
princess_black = j / (i + j)
```6. 公主拿走一只黑老鼠后，龙对一个袋子采取行动，里面装着`i`白色和`j - 1`黑老鼠。 

为了让公主还有机会，龙必须画出一只黑老鼠。 如果龙抽到白色，则龙立即获胜。 

龙画黑的概率为：```
dragon_black = (j - 1) / (i + j - 1)
```7. 龙画黑后，又跳出一只老鼠。 

此刻，袋子里装的是`i`白色和`j - 2`黑老鼠。 

有两种可能性。 

如果一只白色的老鼠跳出来：```
probability = i / (i + j - 2)
next state = dp[i - 1][j - 2]
```如果一只黑老鼠跳出来：```
probability = (j - 2) / (i + j - 2)
next state = dp[i][j - 3]
```8. 将所有有效的转换添加在一起。 

完整的递归变为：```
dp[i][j] =
    i / (i + j)
    +
    (j / (i + j))
    × ((j - 1) / (i + j - 1))
    × (
        (i / (i + j - 2)) × dp[i - 1][j - 2]
        +
        ((j - 2) / (i + j - 2)) × dp[i][j - 3]
      )
```1. 在访问以下状态之前仔细检查边界`j - 2`或者`j - 3`。 

### 为什么它有效

 递归详尽地划分了状态的所有可能结果`(i, j)`。 

公主要么画白色立即获胜，要么画黑色。 在第二种情况下，唯一幸存的路径是龙也画成黑色的路径。 之后，跳跃的鼠标决定下一个缩小状态。 

每个转移概率都乘以到达该转移的概率，并对所有不相交的可能性进行求和。 由于每一步都会严格减少老鼠的数量，DP 最终达到答案已知的基础状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

w, b = map(int, input().split())

dp = [[0.0] * (b + 1) for _ in range(w + 1)]

for i in range(1, w + 1):
    dp[i][0] = 1.0

for i in range(1, w + 1):
    for j in range(1, b + 1):
        total = i + j

        # Princess draws white immediately
        ans = i / total

        # Princess draws black
        if j >= 1:
            princess_black = j / total

            # Dragon draws black
            if j >= 2:
                dragon_black = (j - 1) / (total - 1)

                survive_prob = princess_black * dragon_black

                remaining = total - 2

                # A white mouse jumps out
                if i >= 1:
                    ans += (
                        survive_prob
                        * (i / remaining)
                        * dp[i - 1][j - 2]
                    )

                # A black mouse jumps out
                if j >= 3:
                    ans += (
                        survive_prob
                        * ((j - 2) / remaining)
                        * dp[i][j - 3]
                    )

        dp[i][j] = ans

print("{:.9f}".format(dp[w][b]))
```DP 表存储每个可达状态的概率。 由于每次转换都会减少小鼠的总数，因此在较大的状态需要它们之前就已经计算了较小的状态。 

第一个基本案例集`dp[i][0] = 1`因为如果只剩下小白鼠，那么轮到公主时就会立即获胜。 

重现直接反映了游戏过程。 最微妙的部分是龙的回合。 公主拿走一只黑老鼠后，分母发生了变化，因为袋子的尺寸减小了。 当龙消灭了另一只黑鼠后，在恐慌跳跃发生之前，分母再次发生变化。 

许多错误的解决方案意外地在所有阶段重复使用相同的分母。 这会产生不正确的概率，因为每次事件后袋子的大小都会发生变化。 

另一个微妙的实现细节是在访问之前检查边界`dp[i][j - 3]`或者`dp[i - 1][j - 2]`。 仅当剩余足够多的黑鼠时，这些状态才会存在。 

浮点精度就足够了，因为问题只需要以下误差`1e-9`。 

## 工作示例

 ### 示例 1

 输入：```
1 3
```DP 转换轨迹：

 | 步骤| 活动 | 概率 | 下一个状态 |
 | --- | --- | --- | --- |
 | 1 | 公主画白色| 1/4 | 1/4 赢 |
 | 2 | 公主画黑色| 3/4 | 继续 |
 | 3 | 龙画黑| 2/3 | 继续 |
 | 4 | 白老鼠跳出来| 1/2 | 1/2 dp[0][1] = 0 |
 | 5 | 黑老鼠跳出来 | 1/2 | 1/2 dp[1][0] = 1 |

 现在计算：```
dp[1][3]
= 1/4 + (3/4)*(2/3)*((1/2)*0 + (1/2)*1)
= 1/4 + 1/4
= 1/2
```这个例子说明了为什么跳跃的鼠标很重要。 如果白老鼠跳走了，公主就失去了以后所有的机会。 

### 示例 2

 输入：```
2 1
```DP 转换轨迹：

 | 步骤| 活动 | 概率 | 下一个状态 |
 | --- | --- | --- | --- |
 | 1 | 公主画白色| 2/3 | 赢 |
 | 2 | 公主画黑色| 1/3 | 1/3 继续 |
 | 3 | 龙画白| 1 | 龙胜|

 计算：```
dp[2][1] = 2/3
```这个例子说明，有时龙抽牌后递归会立即停止，因为龙可以通过抽白直接获胜。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(w × b) | 每个 DP 状态均通过持续工作计算一次 |
 | 空间| O(w × b) | DP 表为每个状态存储一个值 |

 最大表大小大致为`1001 × 1001`，大约有一百万个州。 每个状态仅执行少量算术运算，因此该解决方案很容易满足时间限制和内存限制。 

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    w, b = map(int, input().split())

    dp = [[0.0] * (b + 1) for _ in range(w + 1)]

    for i in range(1, w + 1):
        dp[i][0] = 1.0

    for i in range(1, w + 1):
        for j in range(1, b + 1):
            total = i + j

            ans = i / total

            if j >= 2:
                survive = (j / total) * ((j - 1) / (total - 1))
                remaining = total - 2

                ans += survive * (i / remaining) * dp[i - 1][j - 2]

                if j >= 3:
                    ans += survive * ((j - 2) / remaining) * dp[i][j - 3]

            dp[i][j] = ans

    print("{:.9f}".format(dp[w][b]))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

# provided sample
assert run("1 3\n") == "0.500000000", "sample 1"

# minimum size, no white mice
assert run("0 5\n") == "0.000000000", "no possible win"

# only white mice
assert run("5 0\n") == "1.000000000", "immediate win"

# small mixed case
assert abs(float(run("1 1\n")) - 0.5) < 1e-9, "balanced small case"

# another small case
assert abs(float(run("2 1\n")) - (2/3)) < 1e-9, "dragon immediately wins after black"

# larger boundary-style case
res = float(run("1000 1000\n"))
assert 0.0 <= res <= 1.0, "probability range"

 ## 边缘情况

 考虑输入：```
0 5
```DP 立即使用基本情况：```
dp[0][5] = 0
```由于袋子中不存在白鼠，因此没有要评估的过渡。 公主不可能赢。 

现在考虑：```
2 0
```该算法设定：```
dp[2][0] = 1
```龙的回合从不被考虑，因为公主总是在第一手棋时抓白。 

最后，考虑：```
1 2
```公主以概率立即获胜`1/3`。 

如果她先抽黑色，龙就会从一只白色和一只黑色的老鼠中抽出。 只有当他也画黑时，龙才能生存，概率`1/2`。 然后剩下的唯一一只白色的老鼠跳走了，没有给公主留下任何白色的老鼠。 

递归计算：```
dp[1][2]
= 1/3 + (2/3)*(1/2)*dp[0][0]
= 1/3
```这个案例检查了恐慌跳转删除了最后一只小白鼠的微妙情况。
