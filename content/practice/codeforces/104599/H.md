 ## 解决方案
 ## 问题理解

 所描述的结构是嵌入在数组形式中的有根二叉树。 每个节点都标记为$1$到$N$，每个节点最多可以指向两个子节点，一个左子节点和一个右子节点。 值为$0$表示对应的孩子不存在。 节点$1$附加到左侧的根源，并且节点$2$附着在右侧，因此这两个是该结构的初始分支。 

只有没有子节点的节点才被视为有意义的端点。 每个这样的端点都有一个深度，定义为从根源到该节点的边数。 该深度被转换为字母表中的字母，$1 \mapsto A$,$2 \mapsto B$， 等等。 

最终输出是通过按严格的遍历顺序列出所有端点节点而形成的。 遍历不是标准的前序或中序； 相反，每个左子树首先贡献其所有叶子，然后右子树贡献其所有叶子，并且在每个子树内递归地重复相同的规则。 

约束允许最多$10^5$节点。 这迫使采用线性或接近线性的解决方案，因为遍历或重复子树重新计算的任何二次模拟都会超出时间限制几个数量级。 

如果尝试使用从根开始的重复 DFS 独立计算每个叶子的深度，就会出现一个微妙的问题。 该方法反复重新计算路径并退化为$O(N^2)$在倾斜的树上。 

当假设叶子的有序遍历与所需的顺序匹配时，就会出现另一种失败情况。 左右子树的排序约束不对称； 它是每个节点上严格的“所有左叶都在任何右叶之前”规则，这比标准的有序行为更强。 

## 方法

 直接解释构建树并从根执行 DFS，携带深度。 每次到达叶子时，当前深度都会转换为字符并附加到结果中。 这是正确的，因为深度是沿着从根到叶的独特路径累积的。 通过始终在探索右孩子之前探索左孩子，可以自然地强制执行遍历顺序。 

仅当实现重新计算深度或重复扫描子树时，才会出现效率低下的情况。 正确的 DFS 会访问每个节点一次，因此总工作量是线性的。 

关键的观察是，所需的排序正是前序遍历，其约束是输出仅发生在叶子处。 这消除了任何后处理或排序的需要。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 重新计算每片叶子的深度 |$O(N^2)$|$O(N)$| 太慢了|
 | 单次DFS遍历|$O(N)$|$O(N)$| 已接受 |

 ## 算法演练

 1. 构建一个邻接表示，其中每个节点存储其左子节点和右子节点。 这直接匹配输入结构并允许恒定时间导航。 
2. 将根隐式识别为节点$1$因为它被定义为电源的入口点。 
3. 从节点开始深度优先遍历$1$具有初始深度$1$，因为从根开始的第一条边贡献了向下一级的深度。 
4、访问节点时，首先递归遍历其左子节点（如果存在）。 这强制执行所需的排序约束，即左子树中的所有叶子必须出现在右子树中的任何叶子之前。 
5. 完成左子树后，递归遍历右子树（如果存在）。 这确保了输出序列按遍历顺序（而不是字母顺序）正确的字典结构。 
6. 如果节点没有子节点，则将其视为叶子并将与其深度对应的字符附加到输出字符串。 
7.使用ASCII偏移、映射将深度转换为字符$1$到“A”，$2$到“B”，等等。 

### 为什么它有效

 在尊重子树排序的递归定义的遍历中，每个节点仅被访问一次。 因为每片叶子都是从根部通过一条路径到达的，所以它的深度在访问时是唯一确定的。 强制的左前右递归可确保串联顺序与问题的读取叶子的定义相匹配。 不需要重新排序或全局排序，因此遍历输出既完整又排序正确。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(200000)

N = int(input())
left = [0] * (N + 1)
right = [0] * (N + 1)

for i in range(1, N + 1):
    l, r = map(int, input().split())
    left[i] = l
    right[i] = r

res = []

def dfs(node, depth):
    if node == 0:
        return
    if left[node] == 0 and right[node] == 0:
        res.append(chr(ord('A') + depth - 1))
        return
    dfs(left[node], depth + 1)
    dfs(right[node], depth + 1)

dfs(1, 1)

print("".join(res))
```该实现直接反映了遍历结构。 数组`left`和`right`存储子项，以便每个递归调用都是恒定时间。 递归深度对应于树的高度，并且`sys.setrecursionlimit`防止最坏情况的倾斜链中的堆栈溢出。 叶子检测是通过检查两个子节点是否存在来完成的，确保只有终端节点贡献字符。

 ## 边缘情况

 完全倾斜的树强调递归深度。 DFS 仍然访问每个节点一次并产生正确的深度，因为深度沿着单个链递增。 

仅存在右子树的树验证即使不存在左子树，遍历仍然遵循排序规则。 递归只是跳过空的左分支，而不影响输出序列。 

单节点树确保基本情况是正确的，因为根同时也是叶子，并且必须立即生成字符而无需递归。
