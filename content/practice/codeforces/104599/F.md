 ## 解决方案
 ## 问题理解

 我们有一个圆形轨道$n$标记的位置。 三个标记从位置开始$a$,$b$， 和$c$。 在一步操作中，我们精确地选取一个标记，并将其沿着圆圈顺时针或逆时针移动一步。 

目标是使用尽可能少的移动次数使所有三个标记最终到达同一位置。 由于每个令牌的移动都是独立的，并且仅取决于圆形距离，因此问题实际上在于选择交汇点并测量每个令牌到达该交汇点的成本。 

输出是一个整数：对齐所有三个标记所需的最小单位移动总数。 

约束条件$n \le 10^9$意味着我们无法模拟运动。 任何迭代位置或在圆上执行 BFS 的方法都是不可能的。 一切都必须在恒定时间内使用直接距离公式进行计算。 

当点环绕圆时，会出现微妙的边缘情况。 例如，与$n = 5$，移动自$1$到$5$是一个距离$1$， 不是$4$。 除非我们明确取顺时针和逆时针距离的最小值，否则线性距离公式将是不正确的。 

另一种不明显的情况是两个或多个标记已经重合。 例如，$(1, 1, 5)$看起来很简陋，但如果最佳会面点不是共享位置，仍然可能需要移动。 

## 方法

 暴力解决方案尝试每一个可能的交汇点$x \in [1, n]$。 对于每个$x$，计算圆距离的总和$a$,$b$， 和$c$到$x$，然后取所有最小值$x$。 每次评估花费常数时间，因此总工作量为$O(n)$。 和$n$最多$10^9$，这是完全不可行的。 

关键的观察结果是，成本函数纯粹基于圆距离，对于圆上的三个点，最佳交汇点必须位于由这些点确定的弧之一上。 我们不需要扫描所有位置，而只需要考虑沿圆的候选中位数。 

在一条线上，最小化距离总和的最佳交汇点是中位数。 在一个圆上，我们可以在每个可能的间隙处“切割”圆，并将其简化为线性排列。 对于三点，唯一有意义的结构是它们的循环顺序的排列，这将问题简化为检查恒定数量的配置。 

通过对三个位置进行排序并推理弧长，解决方案变为常数时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对所有点进行蛮力 |$O(n)$|$O(1)$| 太慢了|
 | 循环中位数推理|$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 对三个位置进行排序，以便我们能够一致地推断出它们的循环顺序。 这消除了排列引起的歧义。 
2. 计算沿圆的点之间的三个连续的圆形间隙。 如果我们将排序位置标记为$x_1 \le x_2 \le x_3$，那么间隙是$x_2 - x_1$,$x_3 - x_2$，以及环绕间隙$(n - x_3 + x_1)$。 
3. 找出最大的差距。 这代表了如果我们选择最佳交汇点就不需要遍历的“空弧”。 
4. 最小总移动量是所有间隙之和减去最大间隙。 直观上，我们遍历较短的两条弧并避开最大的空弧。 

### 为什么它有效

 将交汇点放置在最大间隙内可确保没有令牌需要跨越该弧线。 每一步都可以被视为缩小将所有点聚集在一起所需的总周长。 任何解决方案都必须覆盖除一个弧之外的所有弧，因为合并所有三个点需要消除两个间隔，并且避免最大间隔可以最大限度地减少总行程。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a, b, c = map(int, input().split())

    x = sorted([a, b, c])

    d1 = x[1] - x[0]
    d2 = x[2] - x[1]
    d3 = n - x[2] + x[0]

    print(d1 + d2 + d3 - max(d1, d2, d3))

if __name__ == "__main__":
    solve()
```解决方案首先对三个位置进行排序，从而标准化圆上的几何形状。 计算出的三个间隙与这些点形成的三个弧完全对应。 环绕术语可确保正确处理循环性。 减去最大间隙会删除我们选择不交叉的弧，从而产生最佳对齐成本。 

一个常见的错误是忘记环绕距离或将圆视为一条线，当最佳路径穿过之间的边界时，这种错误就会失败$n$和$1$。

 ### 示例 1

 输入：```

```排序位置：$[1, 3, 5]$| 步骤| 价值观 |
 | ---| ---|
 | d1 | 3 - 1 = 2 |
 | d2 | 5 - 3 = 2 | 5 - 3 = 2
 | d3 | 6 - 5 + 1 = 2 |
 | 总和| 6 |
 | 最大间隙| 2 |
 | 结果 | 6 - 2 = 4 | 6 - 2 = 4

 这显示了对称配置，其中任何电弧去除都会给出相同的结果，从而确认了正确性。

```排序位置：$[1, 1, 5]$| 步骤| 价值观 |

 | 总和| 5 |
 | 最大间隙| 4 |
 | 结果 | 1 |

 这演示了重复位置和环绕优势的处理。 最佳策略是将 5 处的点移向 1 处，花费 1 步。

 ## 边缘情况

 当所有三个标记已经处于同一位置时，所有间隙都为零，因此公式自然返回零。 不需要移动，算法无需特殊分支即可处理此问题。 

当两个标记重合时，一个间隙变为零，解决方案简化为沿最短弧移动第三个标记。 排序间隙公式仍然正确地将最大弧识别为与簇相对的弧。 

当最优配置跨越两者之间的边界时$n$和$1$，环绕间隙成为关键候选者之一。 该算法通过以下方式明确包含这种情况$n - x_3 + x_1$，确保正确处理，无需额外逻辑。
