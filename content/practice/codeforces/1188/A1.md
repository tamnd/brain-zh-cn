 ## 解决方案
 ## 问题理解

 我们有一棵树$n$最初每条边的值为 0 的节点。我们可以执行选择任意两个不同叶节点并添加实数的操作$x$沿着连接这两片叶子的独特路径的每个边缘。 问题是，对于任何所需的实数到边缘的分配，是否可以使用这些操作的有限序列来实现该配置。 

树的输入指定为$n-1$边缘连接$n$节点。 如果可以实现任何配置，则输出仅为“YES”；如果无法达到某些配置，则输出为“NO”。 

限制条件$2 \le n \le 10^5$意味着任何解最多必须是线性的$n$,$O(n)$或者$O(n \log n)$，因为二次方法的表现大致如下$10^{10}$操作并超过时间限制。 该问题允许任何实数，因此整数溢出不是问题，但树结构引入了微妙的限制，因为操作仅影响叶子之间的路径。 试图模拟所有可能的叶子配对的简单方法会太慢而且没有必要。 

当节点的度数为 2 时，会出现不明显的边缘情况。考虑由三个节点组成的链$1-2-3$。 节点 2 不是叶子，度为 2。唯一的叶子是节点 1 和 3。任何操作都会影响从 1 到 3 的路径，其中包括边$1-2$和$2-3$一起。 如果我们尝试设置边缘$1-2$到 1 和边缘$2-3$到 2 时，单个操作无法实现此目的，因为两个边缘的变化量相同。 因此，如果要实现任意配置，树不得包含 2 度内部节点。 

## 方法

 蛮力方法会考虑每对叶子，选择一些值$x$，并更新其路径上的所有边。 我们可以尝试通过选择合适的叶子对来系统地求解每条边，但叶子对的数量最多可达$\binom{n}{2}$， 大致$5 \cdot 10^9$为了$n=10^5$。 这太慢而且不切实际。 

关键的观察是每个操作都会修改沿着连接两个叶子的路径的边缘。 如果一个节点的度数恰好为 2，则它恰好位于连接两个叶子的一条路径上。 该节点无法独立控制，因此无法为与其相邻的边分配任意独立值。 相反，如果每个内部节点的度数至少为 3 或者是叶子，则任何边都可以表示为叶子之间路径的组合。 这使我们能够通过将任何所需的边缘分配分解为叶到叶路径的贡献来“求解”所有边缘上的值。 

换句话说，度为 2 的内部节点的存在引入了相邻边之间的线性依赖性，从而防止任意分配。 如果没有 2 度内部节点，则叶子操作跨越所有边分配的空间，并且可以实现任何配置。 这种见解将问题简化为节点度的简单检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(L^2 * n) 其中 L = #leaves | O(n) | 太慢了 |
 | 基于学位的检查| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取节点数$n$和名单$n-1$边缘。 构建树的邻接表表示。 这允许有效的遍历和度计算。 
2.初始化一个size的数组$n$计算每个节点的度数。 遍历所有边并增加两个端点的度数。 
3. 对于每个节点，检查它是否是内部节点（度 > 1）并且度恰好为 2。如果存在任何这样的节点，则输出“NO”并终止。 这是因为这样的节点不能独立地具有任意边缘值。 
4. 如果不存在2度内部节点，则输出“YES”。 原因是所有边缘值都可以表示为叶到叶路径加法的总和，因为每个内部节点要么具有至少 3 的度（允许独立分解），要么是叶。 

为什么它有效：不变的是树中的每条边都可以表示为某些叶到叶路径的一部分。 2 度内部节点约束两条边在任何操作中始终一起更改。 通过确保没有 2 度内部节点，我们保证所有边都可以通过某种操作组合独立控制。 正确性完全取决于树的组合结构，而不取决于实际数字。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
degree = [0] * (n + 1)

for _ in range(n - 1):
    u, v = map(int, input().split())
    degree[u] += 1
    degree[v] += 1

for i in range(1, n + 1):
    if degree[i] == 2:
        print("NO")
        sys.exit(0)

print("YES")
```该代码使用有效地读取节点和边的数量`sys.stdin.readline`。 它计算每个节点的度数，任何度数恰好为 2 的节点都会触发“NO”输出。 这正确地实现了 2 度内部节点防止任意配置的见解。 度数为 1（叶）或度数 ≥ 3 的节点是可接受的。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 我们遍历所有边一次来计算度数，然后检查所有节点一次。 |
 | 空间| O(n) | 我们存储大小为 n+1 的邻接度数组。 |

 这种复杂性是线性的，并且很好地符合以下限制：$n \le 10^5$以及1秒的时间限制。

 ## 边缘情况

 最小输入情况$n=2$自然处理，因为两个节点都是叶子。 长度 ≥3 的链失败，因为 2 度的内部节点块独立的边分配。 具有一个中心节点和多个叶子的星形树总是输出“YES”，因为中心节点的度数≥3。 该算法使用度检查正确区分这些情况。
