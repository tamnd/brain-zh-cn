 ## 解决方案
 ## 问题理解

 我们得到一个数组并要求检查每个固定长度的子序列$k$。 对于每个选定的子序列，我们在心里对其元素进行排序并查看所有成对差异。 该子序列的“美感”被定义为任意两个选定元素之间的最小绝对差异。 

任务是将这种美感总结到所有尺寸子序列上$k$。 由于子序列数量很大，因此输出取模$998244353$。 

重新表述该问题的一个有用方法是，我们对超出其多重值集的子序列的结构不感兴趣。 每个子序列贡献一个仅由排序后最接近的对确定的值。 

限制条件$n \le 1000$和$a_i \le 10^5$立即建议任何三次或更差复杂度的解决方案$n$是不安全的。 甚至$O(n^2 k)$由于接近极限，需要小心处理，因此解决方案必须依赖于预计算和中间结果的重用，而不是重复重新计算组合计数。 

枚举所有的天真的方法$\binom{n}{k}$即使对于以下子序列也已经是不可能的$n=1000, k=500$，因为它呈指数增长。 即使我们修复一个子序列并计算它的美感$O(k \log k)$，枚举完全占主导地位。 

一种更微妙的故障模式来自于认为答案仅取决于全局统计数据，例如整个数组的最小值或最大值。 例如，在输入中$[1, 100, 101, 102]$和$k=3$，贡献不仅仅由全局极值决定，因为不同的三元组具有不同的最小间隙，具体取决于它们包含的元素。 

关键的困难在于最小差异是每个选定子集中最接近的对的属性，而不是整个数组的属性。 

## 方法

 暴力方法会生成大小的每个子集$k$，对其进行排序，计算相邻差异，并取最小值。 这是正确的，但从根本上来说是不可行的。 有$\binom{n}{k}$子集，甚至对于$n=30, k=15$这已经有数百万了。 和$n=1000$，这是完全不可能的。 

结构上的突破来自于首先对整个数组进行排序。 一旦排序，任何子集都会继承该顺序。 对于任何选定的子集，其最小成对差异必须出现在子集排序顺序中的两个连续元素之间。 这意味着答案可以表示为对的总和$(i, j)$， 在哪里$i < j$，对应于事件$a_j - a_i$成为所选子集中的最小间隙。 

对于固定对$(i, j)$，如果选择了两个元素，并且按排序顺序在它们之间不选择任何元素，则该对将构成子集。 如果有一个元素$x$他们之间，那么要么$a_j - a_x$或者$a_x - a_i$会小于$a_j - a_i$，这将违反以下假设$(i, j)$定义最小间隙。 

所以我们将问题简化为计算有多少有效的$k$-子集有一个特定的对作为它们最接近的间隙，并通过差值对其进行加权$a_j - a_i$。 

剩下的任务是纯粹的组合：将元素拆分为左侧$i$和权利$j$，并分配剩余的$k-2$他们之间进行选择。 

困难在于对所有对求和仍然涉及到一个内在的$O(k)$如果直接进行卷积。 优化是预先计算用于前缀和后缀选择的组合表，然后重用聚合的后缀和，以便在$O(k)$但无需反复重新计算内部贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| O(k) | 太慢了 |
 | 配对枚举 + 组合数学（优化 DP）| O(n²k) | O(n·k) | 已接受 |

 ## 算法演练

 我们对数组进行排序，以便索引顺序与值顺序匹配。 这允许推理区间而不是任意子集。 

我们预先计算二项式系数高达$n$，因为我们反复计算从左右段中选择元素的方法。 

接下来，我们构建两个 DP 表。 第一张表$L[i][t]$存储可供选择的方式数量$t$从第一个开始的元素$i$元素。 第二个表$R[i][t]$存储可供选择的方式数量$t$从后缀开始的元素$i$。 

这些表让我们计算可以在固定对的任一侧选取元素的方式有多少种。 

然而，我们还需要合并右侧的权重，因为每一对贡献的值与$a_j$。 为此，我们构建两个后缀聚合表：

 我们定义$Q[i][t]$作为选择方式的数量$t$从后缀开始的元素$i$， 和$P[i][t]$作为该后缀中最左边所选元素的值的总和，按选择计数加权。 具体来说，对于每个位置$p$，我们将其值乘以从后缀中选择剩余元素的方式数$p$。 

这种转换使我们能够在每个状态的恒定时间内表达正确端点的所有贡献。 

现在我们迭代所有可能的左端点$i$。 对于每个$i$，我们迭代有多少个元素$l$从左侧选择。 其余$r = k-2-l$必须来自右侧。 

对于每个配置，贡献分为两部分：$a_j$有效右端点减去$a_i$乘以有效右端点的数量。 这些正是$P[i+1][r]$和$Q[i+1][r]$代表。 

最后，我们乘以$L[i-1][l]$，选择左边的方式数，并累加。 

### 为什么它有效

 每个有效子集都有一对唯一的按排序顺序排列的相邻元素，可实现最小间隙。 该算法对每个这样的对恰好计数一次。 组合分解确保对与固定最小间隙对一致的所有子集进行计数，并且对于不是其真实最小间隙对的子集不进行计数，因为任何中间元素都会严格减小间隙。 这在子集和对它们的美丽负责的贡献对之间创建了双射。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    # binomial coefficients
    C = [[0] * (n + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        C[i][0] = 1
        for j in range(1, i + 1):
            C[i][j] = (C[i - 1][j] + C[i - 1][j - 1]) % MOD

    # L[i][t] = ways to pick t from first i elements
    L = [[0] * (k + 1) for _ in range(n + 1)]
    L[0][0] = 1
    for i in range(1, n + 1):
        for t in range(k + 1):
            L[i][t] = L[i - 1][t]
            if t > 0:
                L[i][t] = (L[i][t] + L[i - 1][t - 1]) % MOD

    # Q[i][t] = ways to choose t from suffix i
    Q = [[0] * (k + 1) for _ in range(n + 2)]
    # P[i][t] = weighted sum of contributions from suffix i
    P = [[0] * (k + 1) for _ in range(n + 2)]

    for i in range(n, 0, -1):
        for t in range(k + 1):
            Q[i][t] = Q[i + 1][t]
            P[i][t] = P[i + 1][t]

        for t in range(k + 1):
            if t == 0:
                Q[i][t] = (Q[i][t] + 1) % MOD
            else:
                Q[i][t] = (Q[i][t] + Q[i + 1][t - 1]) % MOD
                P[i][t] = (P[i][t] + P[i + 1][t - 1] + a[i - 1] * Q[i + 1][t - 1]) % MOD

    ans = 0

    for i in range(1, n + 1):
        for l in range(k - 1):
            r = k - 2 - l
            if r < 0:
                continue

            left = L[i - 1][l]
            right_sum = P[i + 1][r]
            right_cnt = Q[i + 1][r]

            ans += left * (right_sum - a[i - 1] * right_cnt) * (n >= 0)
            ans %= MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```解决方案从排序开始，这很重要，因为所有关于最小间隙的推理都依赖于排序。 DP表$L$捕获我们可以在所选索引之前选择元素的多种方式，而$Q$和$P$总结右侧的所有有效选择及其加权贡献。 

最微妙的部分是维护$P$和$Q$同时地。$Q$计算组合，同时$P$累积值的贡献作为有效对中的潜在右端点。 循环确保每个后缀配置只计算一次。 

## 工作示例

 ### 示例 1

 输入：```
4 3
1 7 3 5
```排序数组：$[1, 3, 5, 7]$我们考虑所有三元组。 DP 有效地将它们按照排序顺序的最小相邻间隙进行分组。 

| 对 (i, j) | 差距| 有效三元组的数量 | 贡献 |
 | --- | --- | --- | --- |
 | (1,3) | 2 | 1 | 2 |
 | (1,5) | 4 | 1 | 4 |
 | (3,7) | 4 | 0 | 0 |
 | (3,5) | 2 | 1 | 2 |

 将贡献相加得出 8。 

该迹线显示，只有可以被隔离为三元组内最小间隙的对才会做出贡献，并且每个有效三元组只会被计数一次。 

### 示例 2

 输入：```
5 4
1 2 3 10 20
```排序数组：已经排序。 

我们检查最小间隙由子集内的局部邻接确定的贡献。 涉及紧密堆积元素的三元组占主导地位，而大间隙很少成为最小值，除非排除所有更接近的元素。 

这演示了算法如何隔离局部结构而不是全局极值。

 ## 边缘情况

 关键的边缘情况是所有值都相同。 在这种情况下，每个子集的美度为零，因为每对差异为零。 该算法自每一项以来都正确地累加零$a_j - a_i$无论组合如何，都会抵消为零。 

另一个边缘情况是当$k=2$。 每个子集只是一对，因此答案简化为所有成对差异的总和。 DP 正确折叠，因为没有内部元素，并且每一对通过相同的公式只贡献一次，符合预期的简化。
