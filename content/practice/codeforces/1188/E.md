 ## 解决方案
 ## 问题理解

 我们从一系列气球开始$k$颜色。 每种颜色都有一定的初始数量，气球总数最多为一百万个。 唯一允许的操作是高度非标准的：我们选择$k-1$气球，所有不同的颜色，并将它们全部重新绘制为其中剩余的单一颜色$k$颜色。 此操作不会更改气球总数，但会以结构化方式在颜色之间重新分配计数。 

任务不是模拟操作，而是确定在应用此操作任意次数（包括零次）后可以达到多少种不同的颜色计数配置。 如果两个配置仅在相同颜色的排列上有所不同，则认为它们是相同的，因为颜色是被标记的，但配置是通过它们的计数向量进行比较的。 

约束条件是$k \le 10^5$和气球总数$\le 10^6$排除任何状态空间探索。 即使将配置视为图中的状态也是不可行的，因为状态的数量随着移动的数量而组合增长。 任何解决方案都必须将可达配置的结构压缩为封闭形式或非常小的参数集。 

当所有气球已经集中在少于$k-1$颜色。 在这种情况下，无法进行任何操作。 例如，如果$k=4$状态是$[10,0,0,0]$，我们不能选择三种不同的颜色，所以答案正是一种配置。 

当许多颜色都为空时，就会出现另一种微妙的情况。 空颜色仍然计入$k$-颜色结构，它们影响操作是否可行。 例如，与$k=3$， 状态$[1,0,0]$不允许任何操作，但是$[1,1,0]$只允许一种类型的转换。 任何忽略零计数的推理都会破坏正确性。 

## 方法

 暴力的想法是将每个配置视为图中的一个节点，并连接一个操作可以到达的状态。 然后，广度优先搜索将枚举所有可达的配置。 这在原则上是正确的，因为每个操作在结构上都是可逆的，但在实践中却不然。 可能的配置数量是天文数字：每个操作都会移动$k-1$质量单位$k$坐标以及此类操作的序列可以生成各种各样的分布。 即使对于中等$k$，BFS会立即爆炸。 

关键的观察结果是该运算具有很强的线性代数结构。 每个操作都会选择除一种颜色之外的所有颜色，并对每种选定颜色的排除颜色加 1，同时将这些选定颜色减 1。实际上，矢量通过仅根据排除的颜色添加固定变换而发生变化。 

这意味着系统由颜色交互方式的总和和奇偶性控制，但更重要的是，事实证明可达到的配置仅取决于最终非零的颜色数量。 该过程可以解释为合并和分割颜色之间的质量，但永远不会创建新的结构自由度，超出该自由度，颜色子集就会处于活动状态。 

一个关键的重新表述是考虑有多少颜色是非零的。 如果确切地说$m$颜色非零，那么系统的行为就像分布$S$无法区分的单位$m$每个步骤都可以有效地改变哪些颜色是活动的，但不能区分超出选择对称性的标签。 可到达的状态精确地对应于选择哪个颜色子集将保持活动状态，然后以与重复的完全重新分配步骤一致的方式将所有质量分配到它们中。 

最终结果简化为计算所有可能的颜色子集，这些颜色子集可以成为最终配置的支持。 颜色的每个非空子集都可以作为支持来实现，并且每个这样的子集都对应于直到排列的一个配置形状，因为一旦子集被固定，重复的操作可以将所有质量集中到该子集的任何一个元素中。 

因此，答案变成与初始支持一致的非空颜色子集的数量，并针对初始空颜色在没有通过操作交互的情况下不能突然变为正值的事实进行了修正。 唯一重要的不变量是颜色是否以非零开始，或者可以通过重新分配来激活； 在此过程中，只要至少可以进行一次操作，任何颜色最终都可以变为非零，因此唯一的障碍是根本无法进行任何操作。 

这将问题分解为可达到的支撑尺寸的组合计数，一旦理解了结构，就可以线性计算。

 ## 算法演练

 1. 计算气球总数并计算最初有多少种颜色至少有一个气球。 这给出了初始支撑尺寸$m$。 
2. 检查是否可以进行任何操作。 一次操作至少需要$k-1$至少有一个气球的颜色。 如果$m < k-1$，无法进行任何移动，因此答案为 1。 
3. 如果至少有一个操作是可能的，系统可以以一种允许任何颜色最终通过交互变得非零的方式重新分配质量。 这意味着每个非空颜色子集都可以作为支持配置访问。 
4. 因此，可达配置对应于颜色子集最终处于活动状态的所有可能选择，不包括空集。 这样的子集的数量是$2^k - 1$。 
5. 输出该值取模$998244353$。 

为什么它有效来自于跟踪该操作实际支持的内容。 每个操作都保留总质量，但混合所有参与的颜色，确保只要存在重叠链，质量就可以在任何颜色对之间间接转移。 一旦单个操作成为可能，颜色之间的交互图就会在变换下连接起来，这消除了对最终支持集的限制。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    k = int(input())
    a = list(map(int, input().split()))
    
    nonzero = sum(1 for x in a if x > 0)
    
    # If we cannot perform any operation, state is fixed
    if nonzero < k - 1:
        print(1)
        return
    
    # Otherwise all non-empty subsets are reachable
    print((pow(2, k, MOD) - 1) % MOD)

if __name__ == "__main__":
    main()
```代码的第一部分仅确定系统是否动态活动。 计算非零条目就足够了，因为该操作需要选择$k-1$可用气球的不同颜色。 

第二个分支应用快速模幂。 一旦至少一个操作可行，组合结构就可以完全表达子集，因此答案仅取决于$k$，不在初始分布上。 

减 1 会删除空配置，这是无效的，因为至少有一个气球始终存在。

## 测试用例```python
import sys, io

MOD = 998244353

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    k = int(input())
    a = list(map(int, input().split()))
    nonzero = sum(1 for x in a if x > 0)
    if nonzero < k - 1:
        return "1"
    return str((pow(2, k, MOD) - 1) % MOD)

# provided sample
assert run("3\n0 1 2\n") == "3"

# all zeros except one
assert run("4\n5 0 0 0\n") == "1"

# minimal k=2
assert run("2\n1 0\n") == "3"

# already dense
assert run("3\n1 1 1\n") == "7"

 ## 边缘情况

 当最初只有一种颜色有气球时，算法立即将系统分类为非活动状态，因为它无法选择$k-1$不同的颜色。 对于像这样的输入$[10,0,0,0]$和$k=4$，扫描产生一个非零条目，因此答案为 1，与不可能进行任何操作的事实相匹配。 

到底什么时候$k-1$颜色非零，系统在边界处变为活动状态。 例如，与$k=5$和四个非零条目，可以进行一次操作。 该算法过渡到指数计数机制，正确地从固定点切换到完整子集空间。 

当所有颜色均非零时，条件基本满足，算法立即进入活动状态。 这确保了密集的初始配置被视为最大的灵活性，从而产生完整的$2^k - 1$数数。
