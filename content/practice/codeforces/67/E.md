 ## 解决方案
 ## 问题理解

 我们得到一个按顺时针顺序列出的简单多边形。 前两个顶点形成水平边`AB`，并且所有其他顶点都严格位于该边的同一侧。 沿线段`AB`，每个整数坐标点都是瞭望塔的可能位置。 

对于瞭望塔位置`P`在`AB`，多边形内的每个点都必须是可见的`P`。 可见性意味着该段来自`P`到目标点的距离保持在多边形内部，但可能位于端点处。 由于多边形很简单`P`位于边界上，足以确保每个多边形边都可以从`P`。 

任务是计算有多少个整数点`AB`可以看到整个多边形。 

多边形最多有 1000 个顶点。 这个尺寸对于二次几何算法来说足够小，但对于任何具有昂贵浮点运算的三次几何算法来说却不够。 解决方案围绕`O(n^2)`是完全安全的。 甚至`10^6`在极限范围内定向测试是微不足道的。 更困难的部分不是性能，而是几何正确性。 

关键的几何约束是除`A`和`B`躺在同一侧`AB`。 这意味着多边形的行为就像一座悬挂在栅栏下方或上方的“山”。 这种结构消除了许多困难的可见性情况，并将问题转化为直线上的区间交集。 

一些边缘情况很容易被错误处理。 

考虑一个多边形，其中一条边仅从栅栏的单个端点处几乎看不见：```
4
0 0
10 0
9 5
1 5
```上的每一点`AB`在这里起作用，因为多边形是凸的。 使用严格不等式的粗心实现可能会错误地拒绝端点。 

现在考虑一个非凸多边形：```
5
0 0
10 0
10 10
5 3
0 10
```近处向内凹陷`(5,3)`阻挡许多位置的可见性。 对采样点进行简单的“内部多边形”检查会错过可见性失败的情况，因为线段在到达目标之前就穿过了边界。 

当可见性恰好在整数坐标处发生变化时，会出现另一种微妙的情况：```
5
0 0
6 0
6 6
3 1
0 6
```这里的有效区间边界是有理数。 浮点计算的舍入误差可能会将计数移动一位。 整数运算要安全得多。 

最后一个重要的极端情况是根本没有任何意义的情况。 某些多边形包含一个反射顶点，其相邻边阻挡了所有可能的视点`AB`。 正确答案是`0`，并且算法必须干净地检测空区间交点。 

## 方法

 蛮力的想法很简单。 枚举上的每个整数点`AB`。 对于每个候选人职位`P`，测试每个多边形边或每个多边形顶点的可见性。 一段来自`P`如果点除端点外不穿过多边形边界，则该点有效。 

这是有效的，因为可以使用线段相交测试来检查简单多边形中的可见性。 问题是工作量。 如果围栏长度达到`10^6`，那么候选位置可能会超过一百万个。 对于每个位置，检查所有边缘成本的可见性`O(n^2)`在最坏的情况下。 爆炸到周围`10^12`运营。 

瓶颈是独立扫描每个整数点。 几何形状本身暗示了更好的东西：可见性约束沿着栅栏不断变化。 

取一条多边形边`E`。 从哪些位置开始`AB`整个边缘都可见吗？ 由于多边形位于`AB`，阻挡条件仅来自通过边缘端点的光线。 可见位置形成一个间隔`AB`。 

这是至关重要的观察。 我们不是单独检查每个点，而是计算每个多边形边贡献的有效间隔，然后与所有间隔相交。 最终的交点恰好包含可以看到整个多边形的塔位置。 

对于反射顶点，几何体变得特别干净。 凸顶点永远不会产生限制。 反射顶点创建一个以其两个相邻边为边界的可见圆锥。 将这些圆锥体与水平栅栏相交给出了允许的间隔`x`坐标。 

计算全局间隔后`[L, R]`，答案只是其中也属于该段的整数的数量`AB`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(|AB|·n²)|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 ### 几何设置

 假设有栅栏`AB`位于水平线上`y = Y`。 由于所有其他顶点都位于同一侧，因此我们可以调整多边形的方向，使它们都位于栅栏下方。 如果它们位于上方，我们通过将所有坐标相乘来垂直反映坐标`y`值由`-1`。 

有效的了望塔位置是整数`x`之间的坐标`x1`和`x2`。 

### 反射顶点的可见性限制

 凸顶点永远不会阻挡可见性。 只有反射顶点才重要。 

对于反射顶点`V`，设其相邻顶点为`U`和`W`。 任一相邻边错误一侧的任何视点在到达之前都会看到多边形外部`V`。 

可见视点和不可见视点之间的边界恰好是相邻边缘之一的延伸线。 

对于每个相邻边，我们计算其支撑线与栅栏相交的位置`y = Y`。 这给出了一个限制`x`协调在栅栏上。 

根据边缘方向，视点必须保持在该交叉点的左侧或右侧。 

### 检测反射顶点

 由于顶点按顺时针方向列出并且多边形位于栅栏下方，因此反射顶点具有正叉积：```
cross(V-U, W-V) > 0
```凸顶点被忽略。 

### 计算区间约束

 对于每个反射顶点：

 1. 占据优势`(U,V)`。 
2. 延长线直到到达`y = Y`。 
3. 计算对应的`x`。 
4. 决定有效的观点是左还是右。 

对边缘重复`(V,W)`。 

这两个半平面的交集给出了顶点施加的可见性区间`V`。 

将此区间与全局范围相交`[L,R]`。 

### 最终计数

 处理完所有反射顶点后：

 1. 将间隔固定到实际栅栏段。 
2. 计算区间内的整数。 

如果区间为空，则返回`0`。 

### 为什么它有效

 当从视点到某个多边形点的线段退出多边形时，该视点就变得无效。 在所有顶点都在栅栏一侧的简单多边形中，第一个障碍物始终出现在反射顶点处。 

每个反射顶点都会创建一个楔形禁区。 使该楔形与栅栏相交会产生单个间隔约束。 凸顶点永远不会产生障碍物，因为多边形边界局部弯曲远离视点。 

该算法精确计算所有这些区间约束并将它们相交。 当且仅当一个点位于每个反射顶点的可见性楔内时，它才能在交点中幸存下来，这相当于看到整个多边形。 

## Python 解决方案```python
import sys
from fractions import Fraction

input = sys.stdin.readline

def intersect_x(a, b, Y):
    x1, y1 = a
    x2, y2 = b

    if y1 == y2:
        return Fraction(x1, 1)

    return Fraction(x1 * (y2 - Y) + x2 * (Y - y1), y2 - y1)

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def solve():
    n = int(input())
    p = [tuple(map(int, input().split())) for _ in range(n)]

    Y = p[0][1]

    # Make polygon lie below the fence
    if p[2][1] > Y:
        p = [(x, -y) for x, y in p]
        Y = -Y

    x1 = p[0][0]
    x2 = p[1][0]

    if x1 > x2:
        x1, x2 = x2, x1

    L = Fraction(x1, 1)
    R = Fraction(x2, 1)

    for i in range(n):
        u = p[(i - 1) % n]
        v = p[i]
        w = p[(i + 1) % n]

        c = cross(v[0] - u[0], v[1] - u[1],
                  w[0] - v[0], w[1] - v[1])

        # reflex vertex
        if c <= 0:
            continue

        xv1 = intersect_x(u, v, Y)
        xv2 = intersect_x(v, w, Y)

        left = min(xv1, xv2)
        right = max(xv1, xv2)

        L = max(L, left)
        R = min(R, right)

    if L > R:
        print(0)
        return

    lo = (L.numerator + L.denominator - 1) // L.denominator
    hi = R.numerator // R.denominator

    ans = max(0, hi - lo + 1)
    print(ans)

solve()
```第一步标准化多边形方向。 编辑推理假设所有顶点都位于栅栏下方。 垂直反射可以保持每个可见性关系不变，同时简化几何形状。 

这`cross`函数识别反射顶点。 由于多边形是顺时针方向，正叉积意味着内角超过 180 度。 

这`intersect_x`函数计算多边形边与栅栏线相交的位置。 使用`Fraction`避免浮点精度错误。 这很重要，因为最终答案取决于精确的整数边界。 

全局间隔`[L, R]`从整个栅栏开始。 每个反射顶点都会缩小它。 如果间隔变空，则不存在有效的了望塔。 

整数计数步骤必须仔细处理有理端点。 我们需要：```
ceil(L) ≤ x ≤ floor(R)
```使用分数分子和分母可以避免舍入错误。

 ## 边缘情况

 考虑可见性在有理边界处精确变化的情况：```
5
0 0
6 0
6 6
3 1
0 6
```反射后，反射顶点在非整数坐标处创建间隔边界。 假设有效范围变为：```
[2.4, 3.6]
```该算法使用精确分数而不是浮点来计算这些边界。 最终计数使用：```
ceil(2.4) = 3
floor(3.6) = 3
```所以答案是正确的`1`。 

现在考虑一个没有有效视点的多边形：```
5
0 0
8 0
8 8
4 1
0 8
```反射顶点创建一个非常狭窄的间隔，在与栅栏边界相交后可能会塌陷。 加工过程中：```
L > R
```该算法立即检测到空交叉点并打印`0`。 

最后，考虑一个凸多边形：```
4
0 0
5 0
5 5
0 5
```没有反射顶点，因此间隔永远不会缩小`[0,5]`。 每个整数栅栏点都有效，算法返回`6`。 

这些情况正是浮点实现或不完整的可见性检查经常失败的地方。 基于区间的公式和精确的算术可以干净地处理它们。
