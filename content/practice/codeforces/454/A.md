 ## 解决方案
 ## 问题理解

 我们需要打印一个包含菱形形状的奇怪大小的方形网格。 属于菱形的每个单元格都由字符表示`D`，其他每个单元格都由`*`。 

输入包含单个奇数`n`。 输出必须完全包含`n`行，每行恰好包含`n`人物。 菱形位于网格中心，并向中间行扩展，然后对称收缩。 

限制非常小。 最大可能的网格只有`101 × 101`，其中包含 10,201 个单元格。 即使是单独检查每个细胞的算法也很容易在一秒的限制内足够快。 无需高级优化。 

主要挑战不是性能，而是正确构建菱形图案。 

一个容易犯的错误是不正确地处理上半部和下半部之间的过渡。 

例如：

 输入：```
5
```正确输出：```
**D**
*DDD*
DDDDD
*DDD*
**D**
```粗心的实现可能会继续增加中心行之后的宽度，或者过早地开始减少一行。 

另一个常见错误是生成总长度错误的行。 

例如，5 号晶体的第一行必须是：```
**D**
```该行包含 2 颗星，然后是 1 颗星`D`，然后是 2 颗星，总长度为 5。忘记后面的星号会产生：```
**D
```这是无效的，因为每一行都必须准确包含`n`人物。 

最小的有效输入也值得检查。 

输入：```
3
```输出：```
*D*
DDD
*D*
```中心行已经占据了整个宽度，因此当菱形到达两个边缘时，边界计算仍然必须有效。 

## 方法

 解决问题的一个直接方法是检查每个位置`(row, column)`并确定该单元格是否属于菱形。 由于菱形居中，我们可以计算距中心行和中心列的距离并相应地标记单元格。 这种方法是正确的，因为每个单元格都是独立分类的。 它执行`n²`检查，对于给定的约束最多有 10,201 次操作。 

还有一个更简单的观察。 我们实际上不需要逐个单元地做出决定。 如果我们知道有多少`D`字符属于一行，其余位置必须是星星。 

菱形每行增长两个单元格，直到到达中心：```
1, 3, 5, ..., n
```中心行之后，对称收缩：```
..., 5, 3, 1
```对于每一行，一次的数量`D`已知字符，每边的星星数为：```
(n - D_count) / 2
```然后可以直接构建整行：```
stars + Ds + stars
```这避免了考虑单个细胞并与钻石的几何结构相匹配。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 已接受 |
 | 最佳| O(n²) | O(1) | O(1) | 已接受 |

 尽管两种方法具有相同的渐近复杂度，但对于此模式打印任务来说，直接构造行更简单、更自然。 

## 算法演练

 1.读取奇数`n`。 
2. 计算中间行索引为`mid = n // 2`。 
3. 迭代每行索引`i`从`0`到`n - 1`。 
4. 计算距中心行的距离：```
dist = abs(i - mid)
```距中心距离相等的行必须看起来相同，因为钻石是对称的。 
5. 确定数量`D`字符属于这一行：```
d = n - 2 * dist
```每远离中心一步，就会减少一个`D`一个从左侧，一个从右侧。 
6. 计算每边的星星数量：```
stars = (n - d) // 2
```7. 构造行：```
"*" * stars + "D" * d + "*" * stars
```8. 输出行。 

### 为什么它有效

 对于远处的一排`dist`从中心开始，菱形的每一侧都变窄了一个单元格。 这会减少钻石的宽度`2 × dist`, 给予`n - 2 × dist`钻石细胞。 其余位置平均分配在左侧和右侧，因为该图形围绕中心柱对称。 算法生成的每一行都具有正确的星星数量，并且`D`字符，因此生成的网格正是所需的菱形。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

mid = n // 2

for i in range(n):
    dist = abs(i - mid)
    d = n - 2 * dist
    stars = (n - d) // 2
    print("*" * stars + "D" * d + "*" * stars)
```解决方案从找到中间行开始。 每隔一行完全由其与中心的距离来描述。 

价值`d`存储连续的数量`D`当前行中的字符。 在中间一排，`dist = 0`， 所以`d = n`，意味着整行由`D`人物。 移开一排会使宽度减少两倍，这与菱形的形状相匹配。 

价值`stars`是根据未使用的位置计算的。 由于图案是对称的，因此这些位置的一半出现在左侧，一半出现在右侧。 

使用`abs(i - mid)`避免了上半部分和下半部分的单独逻辑。 相同的公式可自动处理钻石的两面，并消除许多常见的差一错误。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n = int(sys.stdin.readline())
    mid = n // 2

    out = []
    for i in range(n):
        dist = abs(i - mid)
        d = n - 2 * dist
        stars = (n - d) // 2
        out.append("*" * stars + "D" * d + "*" * stars)

    return "\n".join(out) + "\n"

# provided sample

 ## 边缘情况

 ### 最小的有效水晶

 输入：```
3
```中间行索引是`1`。 

对于行`0`和`2`，距中心的距离为`1`， 所以`d = 1`和`stars = 1`。 对于行`1`，距离为`0`， 所以`d = 3`和`stars = 0`。 

输出：```
*D*
DDD
*D*
```该公式无需对最小允许尺寸进行任何特殊处理即可发挥作用。 

### 中心行占据整个宽度

 输入：```
5
```在行`2`，这是中心行：```
dist = 0
d = 5
stars = 0
```生成的行是：```

```没有添加星星，因为钻石到达了两个边缘。 计算自然可以处理这种情况。 

### 上半部和下半部之间的对称性

 输入：```
7

dist = 2

```两行都变成：```

```由于该算法仅取决于距中心的绝对距离，因此保证镜像行相同，从而保留所需的菱形形状。
