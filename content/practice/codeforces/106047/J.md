 ## 解决方案
 ## 问题理解

 这座城市可以看作是一个由交叉点组成的三角形网格。 第一行有一个节点，第二行有两个，依此类推，直到第 n 行有 n 个节点。 每个交叉点都由坐标标识$(i, j)$， 在哪里$i$是行并且$j$是该行内的位置。 

从每个节点$(i, j)$为了$i < n$，有 3 条可能的通往下一行的传出路径。 一个直接往下走$(i+1, j)$与长度$a_{i,j}$, 右下到$(i+1, j+1)$与长度$b_{i,j}$，并且在下一行之间还有一个水平边缘$(i+1, j)$和$(i+1, j+1)$与长度$c_{i,j}$。 每三重$(a_{i,j}, b_{i,j}, c_{i,j})$形成一个三角形，这意味着三角形不等式适用于每个这样的三元组。 

我们开始于$(1, 1)$并且必须达到$(n, n)$。 任务是找到一条使总长度最大化且不会多次穿越任何道路的路径。 输出还需要重建访问过的交叉路口的精确序列。 

关键的限制是我们正在研究一个分层图$O(n^2)$节点和$O(n^2)$边缘。 自从$n \le 300$每次测试和总计$n$跨测试最多是$5000$，我们大致可以负担得起$O(n^2)$或者$O(n^2 \log n)$每个测试都有多个解决方案，但是以指数方式重新访问状态或以组合方式单独处理边缘的任何操作都是不可能的。 

一个幼稚的错误是将其视为 DAG 中的通用最长路径，但忽略“无边重用”条件。 例如，如果尝试在假设边独立的情况下简单地最大化节点上的 DP，则可能允许在遍历相邻三角形时隐式重用水平边的配置。 这在小型配置中会出现问题，例如：

 如果$n=2$，我们有节点$(1,1)$,$(2,1)$,$(2,2)$。 有三个边形成一个三角形。 一种幼稚的方法可能会将选择所有三个边缘视为独立的转换，从而产生隐式重新访问边缘的类似循环的路径，这是不允许的。 

所以主要的困难在于每个三角形引入了一个局部结构，其中选择一些边会影响其他边是否可以重用。 

## 方法

 如果我们暂时忽略边重用的约束，则该图是一个分层的 DAG，我们通常会在节点上进行简单的 DP，从$(1,1)$到$(n,n)$。 然而，这忽略了一个事实，即在$(i+1,j)$和$(i+1,j+1)$使用水平边缘$c_{i,j}$，它与上面行的转换交互。 

强力解释是考虑从顶部到底部的所有可能的简单路径，确保没有边缘被使用两次。 这已经是指数级的了，因为在每个三角形上，我们可以决定如何通过其三个边进行路由，并且这些决策会在网格中传播。 在最坏的情况下，有效路径的数量呈指数增长$n$，所以这是不可行的。 

关键的观察是，每个单元实际上表现得像一个局部三角形小工具，并且可以通过将每个三角形视为局部一致的结构来强制执行“没有边被多次使用”的约束：一旦我们决定流如何通过三角形，我们就不需要重新考虑它。 几何保证最佳路径可以分解为跨行一致的方向选择。 

这将问题转化为结构化 DAG 中的最短/最长路径，其中每个节点状态对我们位于三角形边界的左顶点还是右顶点进行编码，并且转换对应于选择三角形边之一或跳过一致的方向。 三角形不等式确保三角形内的迂回永远不会降低最优性，从而使我们能够将问题简化为分层DP，其中每个状态仅依赖于前一行中的相邻状态。 

因此，我们不是对边缘重用进行全局推理，而是将图转换为状态图：$O(n^2)$状态和每个状态的恒定转换。

 ## 算法演练

 我们将每个行转换解释为一组状态，在其中我们决定如何到达行中的每个节点$i$。 关键思想是逐行计算最佳距离，同时跟踪足够的结构以重建路径。 

1. 定义$dp[i][j]$作为有效路径的最大长度$(1,1)$到$(i,j)$。 仅此不足以重建水平使用，因此我们还单独存储前驱信息。 
2. 初始化$dp[1][1] = 0$。 所有其他状态最初都是无法访问的。 这会将路径锚定在起点。 
3. 对于每一行$i$从 1 到$n-1$，从行传播值$i$划船$i+1$使用三种可能的边缘类型。 从$(i,j)$，我们可以去$(i+1,j)$使用$a_{i,j}$或到$(i+1,j+1)$使用$b_{i,j}$。 这些是分层结构中的标准定向过渡。 
4.水平边缘$c_{i,j}$住在行$i+1$并连接$(i+1,j)$和$(i+1,j+1)$。 我们没有将其视为独立边缘，而是在计算行的初始 dp 后放松它$i+1$。 我们在每行内执行从左到右和从右到左的松弛，以便我们可以选择通过使用来改进路径$c_{i,j}$。 这是有效的，因为水平边仅影响同一层中的相邻节点。 
5. 每当 dp 值提高时，我们都会存储父指针，记录我们是来自左上方、上方还是来自水平松弛。 这是重建完整节点序列所必需的。 
6. 处理完所有行后，$dp[n][n]$包含最大路径值。 我们通过回溯存储的父项来重建路径。 

正确性取决于水平边仅连接同一行内的相邻节点，因此它们的影响可以通过该行内的局部松弛来完全解决，而不会创建跨行的循环。 

### 为什么它有效

 各州$(i,j)$表示结束于该交叉点的最佳可实现前缀路径。 从上到下的任何有效路径$(i,j)$必须恰好通过两个传入对角边缘之一进入，或者通过行内水平移动来改进$i$。 由于水平边不连接不同的行，因此它们不能引入跨层依赖循环。 这确保了一旦行$i$已完全处理，所有涉及行的最佳交互$i$已最终确定，不会被后续行改进。 

三角形不等式保证三角形内没有替代绕道可以产生比已经考虑的直接 DP 转换严格更好的配置，因此局部松弛就足够了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        
        a = [None] * n
        b = [None] * n
        c = [None] * n
        
        for i in range(1, n):
            a[i] = list(map(int, input().split()))
        for i in range(1, n):
            b[i] = list(map(int, input().split()))
        for i in range(1, n):
            c[i] = list(map(int, input().split()))
        
        NEG = -10**30
        dp = [[NEG] * (i + 1) for i in range(n + 1)]
        par = [[None] * (i + 1) for i in range(n + 1)]
        
        dp[1][1] = 0
        
        for i in range(1, n):
            # move down
            for j in range(1, i + 1):
                if dp[i][j] == NEG:
                    continue
                
                v = dp[i][j]
                
                # (i,j) -> (i+1,j)
                if v + a[i][j - 1] > dp[i + 1][j]:
                    dp[i + 1][j] = v + a[i][j - 1]
                    par[i + 1][j] = (i, j)
                
                # (i,j) -> (i+1,j+1)
                if v + b[i][j - 1] > dp[i + 1][j + 1]:
                    dp[i + 1][j + 1] = v + b[i][j - 1]
                    par[i + 1][j + 1] = (i, j)
            
            # horizontal relaxations in row i+1
            for j in range(1, i + 1):
                u = dp[i + 1][j]
                v = dp[i + 1][j + 1]
                if u != NEG and v != NEG:
                    if u + c[i][j - 1] > v:
                        dp[i + 1][j + 1] = u + c[i][j - 1]
                        par[i + 1][j + 1] = (i + 1, j)
                    if v + c[i][j - 1] > u:
                        dp[i + 1][j] = v + c[i][j - 1]
                        par[i + 1][j] = (i + 1, j + 1)
        
        path = []
        i, j = n, n
        while True:
            path.append((i, j))
            if (i, j) == (1, 1):
                break
            i, j = par[i][j]
        
        path.reverse()
        
        length = dp[n][n]
        print(length)
        print(len(path))
        print(" ".join(str(x) for p in path for x in p))

if __name__ == "__main__":
    solve()
```DP 数组存储每行中每个节点的最佳已知值。 从行的转换$i$到$i+1$直接考虑对角边$a$和$b$。 之后，我们使用简单的双向扫描来放松新行内的水平边缘，确保任何有益的使用$c$无需重新处理较早的行即可捕获。 

父数组记录如何实现每个最佳状态，无论是从前一行还是从水平松弛。 这是足够的，因为水平移动总是在同一行中的相邻节点之间，因此它们可以表示为本地父链接。

 ## 边缘情况

 一种边缘情况是水平边缘始终主导对角线移动，导致最佳路径在下降之前在一行内振荡。 该算法处理此问题是因为在所有向下转换之后应用水平松弛，从而允许行内改进值的完全传播。 

另一种情况是所有权重都相等。 许多路径都是最优的，并且父重建仍必须产生有效的简单路径。 由于每次更新仅发生在严格的改进上，因此关系不会任意覆盖有效的前任，从而确保一致的重建。 

最后一种情况是当$n=2$，其中仅存在一个三角形。 DP 直接比较两条对角边，然后应用一次水平边，从而产生对所有三个节点的有效遍历，而不重复任何边。
