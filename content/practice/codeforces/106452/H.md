 ## 解决方案
 ## 问题理解

 该问题隐藏在符号后面的一个简单的基数转换任务。 给定值是使用某种基数编写的`i`，目标是打印使用另一个基数编写的相同数字`j`。 

令人困惑的部分是符号`a_i`。 它看起来像`i`- 序列的第一个元素，但它实际上意味着“数字的表示`a`在基地`i`”。较大基数中的表示通常具有较少的数字，这与增加索引使书面值显得更小的观察结果相符。基数`1`不是一个有效的位置数字系统，这解释了为什么第一种情况很特殊。 

输入给出原始基数、目标基数以及原始基数中数字的数字。 输出是以目标基数表示的相同整数。 

设计约束条件是为了使转换后的值适合正常的 64 位整数。 目标基数最多为`10`，因此每个输出数字都可以使用十进制字符打印。 这意味着我们只需要对输入位数进行线性运算。 任何涉及尝试可能的数字或构建大型表格的方法都是不必要的。 

主要的边缘情况来自基础处理。 像这样的数字`0`必须保留`0`转换后。 从基数到自身的转换应返回原始表示形式。 输入表示形式中的前导零不得更改该值。 

例如，如果输入是：```
2 10
1010
```正确的输出是：```
10
```将输入视为十进制数的粗心解决方案会解释`1010`作为一千十而不是二进制表示。 

另一个边缘情况是：```
10 2
0
```正确的输出是：```
0
```删除所有零或假设始终存在非零数字的解决方案在这里将失败。 

## 方法

 直接的方法是模拟数字的含义。 以基数书写的数字`b`可以通过从左到右处理数字来评估。 如果当前累计值为`x`下一个数字是`d`，新值为：`x * b + d`重复此操作会将整个表示形式转换为其实际的整数值。 之后，通过重复对目标基数取余数并除以目标基数，可以将相同的值写入另一个基数中。 

这是有效的，因为位置表示法完全是重复的乘法和加法。 蛮力替代方案是搜索其表示形式与给定数字匹配的数字，但可能的值随着数字的数量呈指数增长，使得该方法无法使用。 

真实值是有界的观察结果使我们能够避免任意精度的技巧并使用普通的整数算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 位数呈指数 | O(1) | O(1) | 太慢了|
 | 基本转换| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.阅读原文基础`i`，目标碱基`j`，以及数字的表示形式。 
2. 从基础转换表示`i`转换为整数值。 从价值开始`0`，并将每个数字的当前值乘以`i`在添加数字之前。 
3. 如果结果值为`0`， 打印`0`立即地。 这处理在正常重复除法期间唯一不产生任何数字的数字。 
4. 重复将该值除以`j`。 每个余数都是目标表示中的下一个数字，从最低有效数字开始。 
5. 反转收集到的数字并打印它们，因为除法是从右到左发现数字的。 

工作原理：第一阶段重建由输入数字表示的唯一整数。 第二阶段使用位置符号的逆过程。 重复除以基数会给出该基数表示形式从最不重要到最重要的数字，因此反转它们会准确产生所需的输出。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    data = input().split()
    if not data:
        return

    src = int(data[0])
    dst = int(data[1])
    s = data[2]

    value = 0
    for ch in s:
        value = value * src + int(ch)

    if value == 0:
        print(0)
        return

    ans = []
    while value > 0:
        ans.append(str(value % dst))
        value //= dst

    print("".join(reversed(ans)))

if __name__ == "__main__":
    solve()
```转换循环直接遵循位置符号公式。 变量`value`始终存储到目前为止处理的前缀的数值。 

需要进行零检查，因为重复除零不会产生任何数字，而零的表示必须包含一位数字。 

在输出转换过程中，余数是向后生成的。 例如，转换十进制`13`到基地`2`产生余数`1`,`0`,`1`,`1`，对应于从右到左读取的表示。 颠倒即可修复顺序。 

不使用索引，因此不存在差一问题。 Python 整数还可以避免溢出问题。

import sys, io

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    data = sys.stdin.readline().split()
    if not data:
        sys.stdin = old_stdin
        return ""

    src = int(data[0])
    dst = int(data[1])
    s = data[2]

    value = 0
    for ch in s:
        value = value * src + int(ch)

    if value == 0:
        result = "0"
    else:
        res = []
        while value:
            res.append(str(value % dst))
            value //= dst
        result = "".join(reversed(res))

    sys.stdin = old_stdin
    return result + "\n"

assert run("2 10\n1010\n") == "10\n", "binary to decimal"
assert run("10 2\n15\n") == "1111\n", "decimal to binary"

assert run("10 10\n00042\n") == "42\n", "leading zeroes"
assert run("8 2\n17\n") == "1111\n", "octal conversion"
assert run("10 10\n0\n") == "0\n", "zero handling"

 ## 边缘情况

 对于输入：```
2 10
1010
```该算法首先将值重建为`10`。 输出基数是十进制，因此除法阶段立即产生个位数`10`。 

对于输入：```
10 2
0
```读取唯一的数字后，累加值仍为零。 该算法使用显式零分支并打印`0`而不是产生一个空字符串。 

对于输入：```
10 10
00042
```转换阶段处理所有数字，但前导零没有任何贡献，因为在第一个非零数字出现之前，将当前值乘以基数会保持该值不变。 最终值为`42`，输出表示也是`42`。
