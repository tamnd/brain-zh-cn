 ## 解决方案
 # 问题理解

 我们有一个连通的加权无向图。 MST 是具有尽可能最小的总边权重的生成树，但几个不同的树可以具有相同的最小成本。 

该问题允许的操作是不寻常的：我们可能只增加边权重，并且每次增加都会花费一次操作。 目标不是找到 MST，而是消除现有 MST 结构中的所有歧义。 我们需要增加最小边数的权重，以便最小生成树成本保持完全相同，并且只有一个可能的 MST。 

输入描述顶点和边。 每条边连接两个顶点并具有正权重。 输出是最小个体数`+1`需要增加体重。 

约束条件大：顶点数和边数都可以达到`2 * 10^5`。 检查每个可能的生成树的算法是不可能的，因为生成树的数量可能是指数级的。 即使在所有边上重复进行图搜索的方法也太慢。 我们需要一个近线性或`O(m log m)`解决方案，它指向使用 Kruskal 算法的结构。 

棘手的部分是处理等权重边组。 权重相等是多个 MST 存在的唯一原因。 例如，考虑：```
3 3
1 2 1
2 3 1
1 3 1
```答案是`1`。 粗心的解决方案可能会认为所有三个边都是必要的，因为它们都具有最小的权重，但只需要两条边来连接三个顶点。 增加任意一侧的重量`2`恰好留下一个 MST。 

另一个边缘情况是相同的权重不能产生任何选择：```
3 3
1 2 1
2 3 2
1 3 3
```答案是`0`。 MST 已经是独一无二的，因为最小的边选择会强制树。 计算每个非 MST 边缘的解决方案将错误地返回`1`或更多。 

最后一种边界情况是具有一个顶点的图：```
1 0
```答案是`0`。 没有需要修改的边，并且单个顶点已经形成了生成树。 假设至少一条边或尝试使用以下命令构建 MST 的代码`n-1`边缘可能会在这里失败。 

# 方法

 直接的方法是构建 MST，然后检查每个替代树。 如果存在多个MST，我们可以尝试逐个增加边并检查MST是否唯一。 这个想法是正确的，因为可以通过MST属性来测试唯一性，但是可能的修改数量太大。 在最坏的情况下，具有许多等权边的密集图将需要重复检查许多 MST 候选对象，这远远超出了限制。 

关键的观察来自克鲁斯卡尔算法。 Kruskal 按权重递增的顺序处理边。 当所有边的权重都小于`w`已经处理完毕，当前的 DSU 组件代表了在考虑重量边缘之前已经强制的所有内容`w`。 

现在只查看具有相同权重的边`w`。 在每个较小权重的 DSU 组件内部，这些边缘不会影响 MST。 剩余的等权边将当前组件连接在一起。 如果这些边包含环，则有多种方式选择MST边的权值`w`。 

对于由这些等权边形成的每个连通分量，我们只需要它们之间的生成树。 该树之外的任何额外边都会创建替代 MST，并且必须增加。 如果临时组件包含`E`边缘和`V`DSU 组件，准确地说`E - (V - 1)`边缘需要升高。 

这可以在处理每个权重组时计算。 我们计算连接当前不同 DSU 组件的等权边，然后计算其中有多少条实际合并组件。 区别在于不必要的边的数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数为`n`| O(n + m) | 太慢了|
 | 最佳| O(m log m) | O(n + m) | 已接受 |

 # 算法演练

 1. 按权重对所有边进行排序。 克鲁斯卡尔算法首先依赖于处理较小的权重，因为在考虑较重的组之前，具有较低权重的边已经被固定。 
2.维护一个包含所有边的DSU，其权重严格小于当前组。 对于具有相同权重的一组边，暂时忽略已连接同一 DSU 组件内的两个顶点的边。 这些边缘永远无法更改 MST，因为更便宜的路径已经连接了它们的端点。 
3. 对于该权重组的剩余边，计算有多少条可以连接不同的 DSU 组件。 这些是可以参与某些 MST 的边。 
4. 合并 DSU 中的这些剩余边。 每次成功的合并都会减少所需的独立连接的数量。 如果合并失败，则该边会在等权重选择之间创建一个循环，这意味着它是导致非唯一性的边。 
5. 将该权重组中失败的合并数量添加到答案中。 这些正是需要增加权重的边。 
6. 继续处理下一个权重组，直到处理完每条边。 

为什么它有效：

 Kruskal 算法告诉我们，每个 MST 都可以通过选择每个权重组内的边来构建，以便它们连接尽可能多的当前独立的组件。 当所有较小的权重都固定后，一组具有环的等权重边连接起来会给出多个有效选择。 删除足够多的边以留下树会删除所有选择，同时保留以相同的总成本构建 MST 的能力。 失败的 DSU 合并恰好是剩余的循环边缘，因此对它们进行计数即可得出所需增加的最小数量。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def unite(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True

def solve():
    n, m = map(int, input().split())
    edges = []

    for _ in range(m):
        u, v, w = map(int, input().split())
        edges.append((w, u - 1, v - 1))

    edges.sort()

    dsu = DSU(n)
    ans = 0
    i = 0

    while i < m:
        j = i
        while j < m and edges[j][0] == edges[i][0]:
            j += 1

        before = 0
        for k in range(i, j):
            _, u, v = edges[k]
            if dsu.find(u) != dsu.find(v):
                before += 1

        merged = 0
        for k in range(i, j):
            _, u, v = edges[k]
            if dsu.unite(u, v):
                merged += 1

        ans += before - merged
        i = j

    print(ans)

if __name__ == "__main__":
    solve()
```DSU 存储由所有已处理的较浅边缘形成的组件。 排序步骤给出的顺序与 Kruskal 使用的顺序相同。 

对于每个重量组，`before`计算仍然有机会出现在 MST 中的等权边的数量。 已经在一个组件内的边将被忽略，因为它们已经可以被更轻的路径替换。 

这`merged`count 记录实际需要多少条边来连接组件。 每一次成功的合并都会为可能的生成森林贡献一条优势。 区别`before - merged`是该权重组中的循环边数。 

该代码使用迭代路径压缩`find`并按大小联合`unite`，保持 DSU 操作几乎恒定的时间。 所有权重都作为整数处理，并且答案适合普通的 Python 整数，无需担心溢出。

 # 边缘情况

 For the equal-weight triangle:```
3 3
1 2 1
2 3 1
1 3 1
```最初，每条边都可以出现在 MST 中。 DSU 从三个独立的组件开始。 前两次合并创建一个生成树。 第三条边连接已经由权重一边连接的顶点，因此形成一个环。 该算法计算一次失败的合并并返回`1`。 

对于已经唯一的 MST：```
3 3
1 2 1
2 3 2
1 3 3
```第一条边连接两个组件。 第二条边连接剩余的顶点。 最后一条边较重，并且永远不会在最小边中进行选择。 没有发生失败的合并，所以答案仍然存在`0`。 

对于单顶点图：```
1 0
```永远不会进入边缘循环。 DSU 已经代表了一个顶点的完整生成树，所以答案仍然是`0`。 

对于多个等权重组：```
5 6
1 2 2
2 3 1
4 5 3
2 4 2
1 4 2
1 5 3
```权重一边是强制的。 在权重二边中，在考虑较便宜的组件后，一条边是冗余的，而在权重三边中出现另一冗余。 该算法计算剩余选择和回报`2`。
