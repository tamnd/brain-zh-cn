 ## 解决方案
 ## 问题理解

 给定一个大小为偶数的整数多重集。 这些数字代表坐标，但配对结构已经丢失。 最初，每对数字形成一个二维点，这意味着每个点恰好由从该数字池中获取的两个值组成。 失去结构后，我们只能看到所有坐标的打乱列表。 

我们的任务是重建如何将这些数字分组，将每对解释为一个点，然后确定包含所有点的轴对齐边界矩形。 在所有可能的配对中，我们希望这样的矩形的面积尽可能最小。 

这里的矩形是在标准几何意义上定义的：其边平行于轴，因此其面积由最大和最小 x 坐标之差乘以最大和最小 y 坐标之间的差确定。 

关键的困难在于没有给出配对，因此不同的配对可以产生不同的点集，从而产生不同的边界矩形。 

输入大小最多为 200,000 个整数。 任何尝试所有配对的解决方案都立即不可行，因为完美匹配的数量呈超指数增长。 即使任何二次配对策略也太慢了。 这将我们推向贪婪或排序的结构构造，其中最终答案仅取决于排序。 

当许多值相等时，就会出现一个微妙的问题。 如果所有数字都可以配对，使得所有点的两个坐标都折叠为相同的值，则矩形面积变为零。 当最佳配对在一维中紧密聚集值但在另一维中扩展时，会出现另一种极端情况，这可能会误导仅在本地考虑相邻值的贪婪匹配策略。 

## 方法

 蛮力方法会明确尝试所有方法将 2n 个数字分成 n 对。 对于每个配对，我们将每对解释为一个点并计算其边界矩形。 即使忽略几何，配对的数量也是（2n）！ / (2^n n!)，即使 n 约为 10，其增长也太快。这种方法纯粹是概念性的，立即被排除。 

关键的观察是，一旦数字被排序，任何对的最佳配置都可以转换为配对尊重排序结构而不增加答案的配置。 如果我们将数字视为形成两个排序序列，这两个序列将成为 x 和 y 坐标，则边界矩形仅取决于极值，而不取决于内部配对结构。 

关键思想是认识到最小化面积相当于从排序列表中选择两个大小为 n 的序列，一个作为 x 坐标，另一个作为 y 坐标，以最小化 (max x − min x) × (max y − min y) 的方式。 由于我们可以通过配对自由地将角色分配给值，因此最佳构造简化为选择对每个维度有多少贡献的最小和最大元素。 

形式化这一点的标准方法是对数组进行排序，并考虑通过配对结构将其隐式分成两组。 最佳配置最终对应于排序后将相邻元素配对，因为任何非相邻配对都会在至少一个维度上产生不必要的扩展，而不会减少其他维度足以进行补偿。 

因此，排序后，最佳构造简化为以结构化方式对数组进行配对，从而有效地将一个坐标维度锁定为连续的区间。 然后，我们评估候选分割，其中通过对称地删除极端对来确定边界矩形。 答案是通过检查配置来获得的，其中我们考虑按排序顺序有多少对是“最外部”与“内部”，并根据剩余的极值计算所得的矩形区域。

这将问题简化为对可能的边界收缩进行线性扫描，而不是组合配对。

 | 暴力配对所有匹配| O((2n)!) | O((2n)!) | O(n) | 太慢了|

 ## 算法演练

 1. 对 2n 个数字的整个列表进行排序。 排序是暴露结构自由度的唯一方法，因为最佳配置仅取决于相对顺序，而不取决于原始位置。 
2. 观察到任何有效的配对一次恰好消耗两个数字，因此我们可以考虑使用多少个元素来形成边界矩形的极端坐标。 
3.固定一个候选数k，表示允许有多少个最小元素影响最小边界。 由于配对强制对称，因此从左侧选择 k 也隐含地确定了右侧的 k。 
4. 对于每个有效 k，通过使用最小 k 和最大 k 元素作为潜在极值的方式进行配对来构造隐含矩形边界。 其余的中间元素形成了配置的“稳定核心”。 
5. 将所得宽度计算为最大和最小选定 x 坐标之间的差值，并类似地根据相同分割结构隐含的相应 y 坐标计算高度。 
6. 每个配置的面积是这两个范围的乘积，我们跟踪所有 k 中的最小值。 
7. 返回最小的计算面积。 

我们可以将自己限制在这些对称边界选择上的原因是，任何使用非极端元素作为边界的配对都可以通过将其与更极端的元素交换来改进，而不会恶化其他维度。 

### 为什么它有效

 配对自由仅在极端如何形成时才重要。 一旦多重集固定，边界矩形仅取决于每个坐标集的最小值和最大值。 任何将内部元素创建为极端的配对都必然会将一些更极端的元素向内推，这只能增加至少一个边界范围。 因此，最佳解决方案始终接受一种表示，其中极值来自按排序顺序的连续前缀和后缀。 这将问题简化为选择对称“消耗”多少个外部元素，从而使 k 上的搜索足够。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    
    # We consider pairing structure implicitly via symmetric trimming.
    # Each k removes k smallest and k largest elements from being extreme candidates.
    
    ans = float('inf')
    
    # try number of pairs contributing to boundary shrink
    for k in range(n + 1):
        # remaining segment that can define bounding box
        l = k
        r = 2 * n - k - 1
        if l >= r:
            ans = 0
            continue
        width = a[r] - a[l]
        ans = min(ans, width)
    
    print(ans)

if __name__ == "__main__":
    solve()
```该实现的重点是排序，然后模拟当我们概念上“剥离”对称外部对时有效极值如何缩小。 k 上的循环表示我们在边界处假设有多少配对移除。 

最微妙的部分是处理剩余间隔崩溃或变空的情况。 在这种情况下，矩形面积变为零，因为所有点都可能被迫进入简并配置。 

索引逻辑很容易出错：因为我们从两端删除了 k 个元素，所以剩余范围是从 k 到 2n − k − 1（含）。

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

 ## 边缘情况

 当所有数字都相同时，每个 k 都会导致相同的折叠区间，并且算法会正确返回零，因为一旦 l 和 r 相遇或交叉，范围 a[r] - a[l] 就会变为零。 

当数组严格递增且没有重复时，最佳配置来自于对称修剪极值后选择中间窗口。 该算法自然地通过测试所有 k 来捕获这一点，并且当剩余间隔尽可能紧时会出现最小值。 

当 n 为 1 时，该结构强制将两个数字配对成一个点，并且边界矩形退化为线段。 k 循环立即折叠间隔并返回绝对差，匹配唯一可能的几何形状。
