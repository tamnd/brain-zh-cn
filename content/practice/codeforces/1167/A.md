 ## 解决方案
 ## 问题理解

 给定一串数字，我们可以自由删除字符，而不改变剩余数字的相对顺序。 任务是决定我们是否可以提取长度正好为 11 的子序列来形成有效的电话号码。 有效的电话号码具有非常特定的结构：长度必须为 11，第一位数字必须为 8。其余 10 位数字可以是任何数字。 

因此，问题简化为检查字符串是否包含长度为 11 的子序列，其中第一个选定的字符是`8`。 

每个测试用例的约束很小，字符串长度最多为100，测试用例最多为100个。 这立即排除了对繁重预处理或高级数据结构的任何需要。 每个测试用例进行线性扫描就足够了。 

一个天真的但常见的错误是假设我们只需要检查字符串是否至少包含一个`8`以及其后至少 10 位数字。 如果不按顺序仔细处理，这很接近，但不正确，因为子序列选择取决于位置。 另一个错误是尝试构建长度为 11 的所有子序列，即使长度为 100，它也会发生组合爆炸，因为有$\binom{100}{11}$的可能性。 

当存在多个时，会出现微妙的边缘情况`8`s。 例如，在`88888888888`，任何位置都可以作为开始，但在字符串中，第一个位置`8`太晚了，之后我们可能没有足够的角色。 贪婪扫描必须正确考虑剩余的可用长度。 

## 方法

 暴力破解的想法很简单：生成长度为 11 的每个子序列，并检查它们中是否有任何一个以`8`。 这是正确的，因为它探索了所有可能的删除。 然而，子序列的数量快速增长。 即使对于单个测试用例$n = 100$，长度为 11 的子序列的数量是天文数字，使得这种方法不可行。 

关键的观察是我们不需要显式地构造子序列。 我们只需要知道是否存在一个位置`8`这样字符串中它后面至少有 10 个字符。 由于删除保留了顺序，一旦我们选择了一个`8`在索引处`i`，我们只需要验证索引后面至少还有10个字符`i`。 这些字符可以是任何东西； 我们只是简单地接受它们出现的样子。 

这将问题简化为扫描有效的起始位置并计算剩余长度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（所有子序列）| O(2^n) | O(2^n) | O(11) | 太慢了|
 | 每 8 个贪婪扫描 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每个测试用例。 

1.读取字符串并扫描该数字所在的所有位置`8`。 每个这样的位置都是电话号码的候选起始位置。 
2. 对于每个索引`i`在哪里`s[i] == '8'`,检查后缀长度是否`n - i`至少为 11。这确保我们可以从此开始选择 11 个字符`8`同时维护秩序。 
3. 如果任何这样的位置满足条件，则立即断定存在有效的子序列。 
4. 如果没有找到有效的起始位置，则输出`NO`。 

步骤 2 背后的原因是，一旦我们将第一个数字固定为`8`，我们只需要在其后添加 10 个字符。 由于我们不受它们的价值观的约束，因此只有它们的可用性才重要。 

### 为什么它有效

 该算法依赖于单调可用性属性：如果`8`出现在索引处`i`，那么它后面的每个字符都有资格成为子序列的一部分，而我们只需要其中的 10 个。 跳过较早的有效时间没有任何好处`8`s 如果后面的一个有效，因为前面的位置总是给出至少同样多的剩余字符。 这保证了检查位置就足够了，而无需构造子序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()

    ok = False
    for i in range(n):
        if s[i] == '8' and n - i >= 11:
            ok = True
            break

    print("YES" if ok else "NO")
```该解决方案迭代每个测试用例并检查数字所在的所有位置`8`。 关键的实现细节是条件`n - i >= 11`，这确保我们可以选择当前的`8`加上至少 10 个以下字符。 一旦找到有效位置，提前退出可以防止不必要的扫描。 

一个常见的错误是忘记所选子序列必须保持顺序，因此只有后缀可用性很重要，而不是全局计数。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        s = input().strip()

        ok = False
        for i in range(n):
            if s[i] == '8' and n - i >= 11:
                ok = True
                break
        out.append("YES" if ok else "NO")

    return "\n".join(out)

# provided samples
assert run("2\n13\n7818005553535\n11\n31415926535\n") == "YES\nNO"

# custom cases
assert run("1\n11\n80000000000\n") == "YES"
assert run("1\n11\n70000000000\n") == "NO"
assert run("1\n12\n888888888888\n") == "YES"
assert run("1\n20\n12345678901234567890\n") == "NO"

 ## 边缘情况

 一个关键的边缘情况是当字符串包含`8`，但似乎太晚了，无法允许剩余 10 个字符。 例如，在`11111111118`，唯一的`8`位于最后一个位置。 即使所需的数字存在，但没有剩余的字符来完成长度 11，因此正确答案是`NO`。 该算法通过显式检查后缀长度来处理此问题，而不仅仅是检查是否存在`8`。 

另一个边缘情况是当多个`8`存在。 第一个有效`8`足以决定成败。 扫描自然会处理这个问题，因为它会停在满足后缀条件的第一个位置。
