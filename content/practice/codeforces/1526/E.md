 ## 解决方案
 ## 问题理解

 我们给出了一个表示某个长度未知字符串的后缀数组的排列$n$超过一个字母表大小$k$。 每个元素$s_i$该数组的 告诉我们哪个起始索引对应于$i$- 字典顺序上最小的后缀。 我们的任务是计算有多少个不同的字符串可以生成这个后缀数组。 

输入给我们两个整数，$n$和$k$，然后是一个数组$s$长度$n$包含排列$[0, n-1]$。 输出是一个整数：有效字符串的数量模$998244353$。 

界限很大：$n$可以达到$2 \times 10^5$。 这意味着任何适用于$O(n^2)$时间会太慢； 我们必须瞄准$O(n \log n)$或者$O(n)$解决方案。 字母大小$k$也可能很大，因此天真地预计算组合可能不可行。 边缘情况包括$n=1$其中唯一的后缀是字符串本身，并且$k=1$其中所有字符必须相等，这使得大多数排列变得不可能。 

一种简单的方法可以尝试生成所有长度的字符串$n$遍历字母表并计算它们的后缀数组，但这在组合上是爆炸性的且不可行。 

当后缀数组中的连续后缀仅相差一个字符时，就会出现一种微妙的边缘情况，这会严格限制字符串的字母。 例如，对于$n=3, k=2$和后缀数组$[0,2,1]$，只有字符串“abb”有效； 任何不小心填写字母而忽略所需顺序的行为都会失败。 

## 方法

 暴力解决方案将尝试枚举所有长度的字符串$n$超过$k$-letter letter 并检查每个字符串是否生成给定的后缀数组。 这需要$O(k^n)$时间，这对于$n$最多$2 \times 10^5$。 它仅在概念上对于非常小的情况是正确的$n$和$k$。 

关键的见解来自于理解后缀数组如何编码字典顺序。 如果我们为每个位置定义一个“等级”数组（已排序后缀数组中后缀的索引），那么我们就可以检查连续后缀的等级差异。 当等级差恰好为 1 时，相应的后缀在第一个尚未确定的字符处必须不同。 对于所有其他后缀，只要不违反排序约束，就允许选择任何字符。 这将问题简化为计算分配字母的方法数量$n$连续后缀之间具有乘法约束的位置，这可以在$O(n)$使用模幂。 

对于后缀数组中的任何连续后缀，所需的“新字母”数量要么是零（如果后缀扩展了前一个字母）要么是 1，这一观察结果允许我们将问题视为选择的产物：每次需要一个新字母时，都有$k-1$选项（因为我们不能在第一个不同位置使用与前一个后缀相同的字母），否则我们只有一个有效的延续。

 | --- | --- | --- | --- |
 | 蛮力 |$O(k^n \cdot n \log n)$|$O(n)$| 太慢了|
 | 最佳 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 构造一个数组`pos`在哪里`pos[i]`给出后缀的位置，起始于`i`在排序后的后缀数组中。 这使我们能够快速检查任意两个后缀的相对顺序。 
2. 初始化计数器`ans`为 1。这将保存有效字符串的总数模$998244353$。 
3. 迭代后缀数组，从索引 1 到$n-1$。 对于每对连续的后缀`s[i-1]`和`s[i]`：

 - 如果后缀始于`s[i]`就原始字符串位置而言，紧邻前一个（`s[i] > s[i-1]`），它可能需要在第一个不同的位置添加一个新字符。 乘`ans`经过`k-1`。 
- 否则，不需要新角色； 乘`ans`1.
 4. 返回`ans`模数$998244353$。 

不变的是，处理完每个后缀后，`ans`正确计算从开始到当前后缀的所有填充位置的方法，尊重字典限制。 每次乘法都会考虑维持后缀数组顺序的下一个位置的有效选择数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n, k = map(int, input().split())
    s = list(map(int, input().split()))
    
    ans = 1
    for i in range(1, n):
        if s[i] > s[i-1]:
            ans = ans * (k - 1) % MOD
        else:
            ans = ans * 1 % MOD
    print(ans)

if __name__ == "__main__":
    main()
```该代码使用有效地读取输入`sys.stdin.readline`。 该循环根据连续后缀的相对顺序实现乘法计数。 边界情况`k=1`自然地处理，因为`k-1=0`正确地使不可能的字符串无效。

 ## 边缘情况

 对于`n=1`，该算法正确返回 1，因为任何长度为 1 的字符串都满足任何后缀数组。 为了`k=1`，连续后缀位置的任何增加都会乘以`k-1=0`，自然产生零个有效字符串，这符合不可能性约束。 交替模式`0 2 1 4 3`在非单调后缀数组上练习该算法，确认每次比较都正确应用了`k-1`仅在需要时才乘数。
