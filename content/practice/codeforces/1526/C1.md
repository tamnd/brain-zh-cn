 ## 解决方案
 ## 问题理解

 我们排列了一系列药水，每种药水都会通过某个整数值改变我们的健康状况，该整数值可以是正数或负数。 我们从零生命值开始，从第一个药水移动到最后一个。 在每一步中，我们都可以选择喝药水或跳过药水，但我们的生命值绝不能低于零。 目标是最大限度地增加我们喝药水的数量。 

因为这个简单版本中的输入大小被限制为$n \le 2000$，我们可以考虑二次解$n$，但任何超过此限制的内容都可能会超出时间限制。 健康值本身可能非常大（高达$10^9$大小），因此我们需要小心累积和，以避免在没有自动大整数的语言中整数溢出，尽管 Python 自然地处理了这个问题。 

一些边缘情况可能会欺骗幼稚的实现。 如果所有药水都是负数，则正确的输出为零，因为饮用任何药水都会立即将生命值降至零以下。 另一个微妙的情况是像这样的序列`[5, -10, 5]`。 总是喝积极药水并跳过消极药水的天真贪婪方法可能会失败，因为有时接受少量消极药水可以让以后喝更多药水。 

## 方法

 暴力解决方案将按顺序尝试每个药水子集，并跟踪健康状况是否保持非负值。 对于每种药水，我们分为两种可能性：接受或跳过。 这给出了$2^n$组合。 即使是为了$n = 20$这已经有超过一百万种可能性了$n = 2000$这是完全不可行的。 蛮力之所以有效，是因为它枚举了所有可能性，但对于大的情况却失败了$n$因为操作次数呈指数增长。 

关键的见解来自于观察，我们只关心维持非负健康并最大化药水数量。 如果我们贪婪地尝试按顺序喝药水，我们只需要跟踪我们已经接受了哪些负药水，并且如果这样做可以保持生命值非负，则可能会用较小的负药水替换较大的负药水。 这可以使用最小堆（优先级队列）有效地实现。 每次我们喝一瓶药水时，我们都会将其价值添加到我们当前的生命值中。 如果总和低于零，我们会删除迄今为止喝下的最具破坏性的药水（堆中的最小值），这会恢复生命值，同时保持该前缀的药水数量最大。 积极药水永远不会降低生命值，并且可以随时添加。 

这一观察结果将解简化为$O(n \log n)$因为每次从堆中插入和删除都会花费$O(\log n)$，并且我们只处理每种药水一次。 这完全在限制范围之内$n = 2000$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 最优（基于堆的贪婪）| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化变量`health = 0`跟踪当前的运行状况和最小堆`taken`存储我们决定喝的药水的值。 
2. 迭代药剂数组。 对于每个药水`a[i]`，将其添加到`health`并将其推入堆中。 我们总是尝试喝掉当前的药水以最大化计数。 
3.添加药水后，检查是否`health`是负数。 如果是，则从堆中弹出最小的部分，并从其中减去它的值`health`。 这有效地丢弃了我们迄今为止喝过的最有害的药水，使健康保持非负数。 
4. 继续，直到处理完所有药水。 最后堆的大小给出了我们在保持非负生命值的情况下可以喝的最大药水数量。 

为什么有效：堆总是保留我们承诺饮用的药水，以增加对健康的影响。 每当我们面临低于零的风险时，通过丢弃最负面的药水，我们可以在不违反健康限制的情况下最大化药水的数量。 阳性药水永远不会被移除，而阴性药水只有在绝对必要时才会被移除，这确保了最终计数是最佳的。 

## Python 解决方案```python
import sys
import heapq
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

health = 0
taken = []

for potion in a:
    health += potion
    heapq.heappush(taken, potion)
    if health < 0:
        smallest = heapq.heappop(taken)
        health -= smallest

print(len(taken))
```解决方案初始化`health`和一个最小堆`taken`。 对于每种药水，我们将其添加到`health`并将其推入堆中。 如果`health`降至零以下，我们从中删除最有害的药水`taken`，恢复非负生命值。 最后堆的长度正好是我们能喝的最大药水数量。 必须小心将负值正确推入堆中，并在从堆中删除时减去它们`health`。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())

    import heapq
    health = 0
    taken = []
    for potion in a:
        health += potion
        heapq.heappush(taken, potion)
        if health < 0:
            health -= heapq.heappop(taken)
