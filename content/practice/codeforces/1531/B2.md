 ## 解决方案
 ## 问题理解

 我们有一组显示器，每个显示器都有宽度和高度，并且我们可以将任何显示器旋转 90 度。 我们的目标是计算不同的无序显示器对的数量，以便在可能旋转其中一个或两个显示器后，它们的高度匹配。 输入给出监视器的数量$n$和尺寸$(w_i, h_i)$每个显示器的。 输出是一个整数，表示合适对的数量。 

约束条件告诉我们$n$可以达到$10^5$，宽度和高度可以大到$10^9$。 有了这么大的$n$，任何显式检查所有可能对的算法，这将需要大致$n^2/2$操作，是不可行的。 我们需要一些更接近线性或$O(n \log n)$在复杂性上。 

不明显的边缘情况包括方形显示器，其中旋转不会改变高度。 例如，与另一个 3x5 显示器配对的 3x3 显示器应算作有效对，因为第二个显示器可以旋转到 5x3，从而产生匹配高度 3。如果具有相同尺寸的显示器出现多次，它们也会贡献多对。 

粗心的方法可能只是简单地比较原始高度或仅比较旋转的高度，缺少需要旋转一台显示器的高度。 

## 方法

 蛮力方法会迭代所有无序的监视器对。 对于每一对，我们考虑所有四种方向组合（都是原始的、第一次旋转的、第二次旋转的、都旋转的）。 如果任何方向产生相同的高度，我们就计算该对。 这在原则上是正确的，但$n \le 10^5$，操作次数大约会达到$5 \cdot 10^9$在最坏的情况下，远远超出了时间限制。 

最佳解决方案的关键在于，对于任何显示器，旋转后的高度可以是其原始高度或宽度。 我们可以将每个监视器表示为一个排序对$(\min(w_i, h_i), \max(w_i, h_i))$。 然后，如果两个显示器在任何方向上共享相同的高度，就会出现一个合适的对，这相当于检查它们排序的高度-宽度对是否在至少一个元素中重叠。 

一种更简单的方法是标准化所有显示器，以便较小尺寸的显示器优先。 然后，我们考虑两个维度，计算每个可能高度的出现次数。 使用每个唯一维度的频率图作为潜在高度，我们可以计算有多少显示器可以提供该高度。 对于每个高度，对数是可以一次获取两个该高度的监视器的组合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取显示器数量$n$以及它们的尺寸列表。 
2. 对于每个监视器，识别较小和较大的维度并将它们存储为元组$(small, large)$。 这确保隐式考虑旋转。 
3. 创建字典`height_count`计算每个高度可以有多少个显示器。 
4. 迭代每个监视器并增加两个尺寸（宽度和高度）的计数作为潜在高度。 
5. 填充后`height_count`，对于每个显示器，确定兼容显示器的数量。 减去自计数以避免监视器自身计数。 
6. 为了正确处理无序对，每对在上一步中都会被计数两次，因此将最终的总和除以 2。 
7. 输出结果整数。 

工作原理：每台显示器都会贡献其所能提供的所有可能的高度。 通过计算每个高度的频率并组合对的计数，我们保证所有有效的对都被精确地计数一次。 除以二可纠正重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
monitors = []

for _ in range(n):
    w, h = map(int, input().split())
    small, large = min(w, h), max(w, h)
    monitors.append((small, large))

from collections import Counter

# Count how many monitors can have each height
height_count = Counter()
for small, large in monitors:
    height_count[small] += 1
    if small != large:
        height_count[large] += 1

# Count total pairs
total_pairs = 0
for small, large in monitors:
    # number of other monitors that can match height small or large
    total_pairs += height_count[small] + height_count[large]
    # subtract self-count if small==large to avoid double-count
    if small == large:
        total_pairs -= 2

# Each pair counted twice
print(total_pairs // 2)
```第一个循环标准化维度，第二个循环构建频率图，第三个循环计算所有可能的配对。 微妙的一点是通过确保我们不会过度计算自对来正确处理方块。 最后除以二可确保每个无序对恰好计数一次。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    monitors = []
    for _ in range(n):
        w, h = map(int, input().split())
        small, large = min(w, h), max(w, h)
        monitors.append((small, large))
    from collections import Counter
    height_count = Counter()
    for small, large in monitors:
        height_count[small] += 1
        if small != large:
            height_count[large] += 1
    total_pairs = 0
    for small, large in monitors:
        total_pairs += height_count[small] + height_count[large]
        if small == large:
            total_pairs -= 2
    return str(total_pairs // 2)

 ## 边缘情况

 方块：输入`2 2 2 2 2 2`从四个相同的监视器产生三对。 该算法对每个监视器的高度频率进行两次计数，减去自计数，然后除以 2，正好得到 6。 

大整数：输入`2 1 1000000000 1000000000 1`测试极端宽度/高度。 由于 Python 的任意整数，高度的计算不会溢出。 

不匹配：输入`2 3 4 5 6`确保高度不兼容的显示器不会错误地生成一对。 该算法正确返回零。
