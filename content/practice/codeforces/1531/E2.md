 ## 问题理解

 我们得到一个由以下内容组成的字符串`0`沙`1`s，它表示在合并排序的合并步骤中对来自以下整数的某些排列做出的决策序列`1`到`n`。 具体来说，一个`0`表示首先取出左半部分的元素，而 a`1`表示首先取出右半部分的元素。 我们的任务是重建任意排列`1`到`n`这样，当我们对它运行合并排序时，我们得到的正是该序列`0`沙`1`是。 
输入字符串`s`编码相对排序决策，但它并没有直接告诉我们`n`。 我们必须推断出一个有效的`n`允许对长度排列进行合并排序`n`准确地产生这个序列。 由于合并排序总是递归地将数组分成两半，因此合并操作的数量是根据 2 的幂来构造的： 长度`n`数组总共产生`n-1`合并过程中的比较 if`n`是二的幂。 

关键的约束是字符串`s`总是可以通过一些长度≤1000的排列来匹配。这意味着对于更大的排列来说，用强力方法来检查所有排列是不可能的`n`，但是我们可以通过考虑合并排序如何消耗来递归地构造一个解决方案`0`沙`1`s。 

边缘情况包括所有的序列`0`或全部`1`s。 对于所有的序列`0`也就是说，数组一定是递增的，因为我们总是先从左边挑选。 对于所有人`1`s，它一定在减少。 任何只输出第一个的幼稚方法`n`如果我们不遵守合并排序对元素的划分，则对于混合序列，按顺序排列的整数可能会失败。 

## 方法

 蛮力方法将生成所有大小的排列`n`并为每个模拟合并排序，看看结果日志是否匹配`s`。 这是可行的，因为合并排序是确定性的，并且比较决策完全由数组定义。 然而，排列的数量呈阶乘增长，`O(n!)`，并模拟每个排列成本的合并排序`O(n log n)`，使得这种方法即使对于`n=10`。 

关键的见解是我们在构造过程中不需要数组中的确切值。 我们只需要一个尊重编码中的比较决策的序列`s`。 归并排序在相同大小的子数组中的顺序方面是稳定的，因此我们可以递归地拆分数组，将连续整数的范围分配给左半部分和右半部分，并使用日志字符串`s`来指导施工。 在每个合并步骤中，下一个字符`s`告诉我们哪一半贡献下一个元素。 这将问题从阶乘搜索减少为线性递归`s`。 

我们递归地构建数组：如果当前段的长度为 1，则它是基本情况。 否则，我们将段分成两半，递归构建左右子数组，然后根据下一个将它们合并`r-l`字符来自`s`。 每个合并步骤正好消耗`r-l`日志中的字符，因此我们可以将指针向前推进`s`当我们重建数组时。 此方法保证我们始终可以生成与日志匹配的有效排列。

 | 递归构造| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.从字符串开始`s`并初始化一个全局指针`ptr`跟踪哪个字符`s`我们已经消费了。 
2. 定义递归函数`build(l, r)`这将构造一个与该段对应的子数组`[l, r)`的最终排列。 如果`r-l == 1`，返回一个单元素数组`[next_available_integer]`并增加下一个可用整数。 
3. 将段分成两半：`m = (l + r) // 2`。 递归构造左半部分`left = build(l, m)`和右半边`right = build(m, r)`。 
4. 合并`left`和`right`根据下一个数组`r-l`的字符`s`。 初始化`i, j = 0, 0`。 为了`k`从`0`到`r-l-1`， 如果`s[ptr]`是`0`， 拿`left[i]`并增加`i`。 如果`s[ptr]`是`1`， 拿`right[j]`并增加`j`。 增量`ptr`。 
5. 消耗完所有合并字符后，附加来自的任何剩余元素`left[i:]`和`right[j:]`到合并的数组。 
6. 返回合并后的数组。 顶层调用将产生完整的排列。 

为什么它起作用：指针`ptr`确保我们完全按照其中出现的方式使用合并日志`s`。 通过将连续整数分配给左半部分和右半部分，我们在满足合并决策的同时保持了有效排列的属性。 归并排序的递归性质保证了每个段的长度和划分与日志一致，因此重建总是产生正确的数组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
ptr = 0
next_val = 1

def build(n):
    global ptr, next_val
    if n == 1:
        val = next_val
        next_val += 1
        return [val]
    m = n // 2
    left = build(m)
    right = build(n - m)
    merged = []
    i = j = 0
    while i < len(left) and j < len(right):
        if s[ptr] == '0':
            merged.append(left[i])
            i += 1
        else:
            merged.append(right[j])
            j += 1
        ptr += 1
    merged.extend(left[i:])
    merged.extend(right[j:])
    return merged

# find minimal n such that n-1 <= len(s)
n = 1
while n*(n-1)//2 < len(s):
    n += 1

a = build(n)
print(n)
print(' '.join(map(str, a)))
```这段代码首先猜测一个最小的`n`这可以产生日志长度。 然后它根据以下递归构建排列`s`。 使用全局指针可以让我们消费`s`按顺序分配整数可确保我们生成有效的排列而不重复。 棘手的部分是在更新时正确合并`ptr`并确保在消耗相关字符后附加所有剩余元素`s`。
