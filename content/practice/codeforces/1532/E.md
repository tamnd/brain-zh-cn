 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，并且允许我们一次删除一个元素。 对于每次删除，我们都会查看剩余的数组并提出一个非常具体的问题：是否存在一个元素完全等于该缩减数组中所有其他元素的总和。 

换句话说，删除位置后$j$，我们想知道剩余的数组是否可以拆分为单个特殊元素和其他所有元素，其中该特殊元素等于所有剩余值的总和。 

输出是索引列表$j$这样就可以去除$a_j$使剩余的数组满足这个条件。 

约束条件$n \le 2 \cdot 10^5$意味着任何重新计算总和或扫描数组以进行每次删除的解决方案都将太慢。 一个天真的$O(n^2)$方法已经太大了，任何更糟糕的事情都立即不可行。 

当值大量重复或删除后数组非常小时，会出现微妙的边缘情况。 例如，如果数组有两个元素，例如$[x, y]$，删除一个元素留下一个元素，并且单个元素数组总是很好，因为该元素等于空集的总和。 粗心的解决方案可能会忘记这种退化的情况仍然很重要。 

另一个重要的情况是，剩余数组中的“特殊元素”可能是最大值，也可能是恰好与总和条件匹配的某个任意元素。 幼稚的方法可能会假设最大的元素始终是候选元素，但这是无法保证的。 

## 方法

 蛮力的想法很简单。 对于每个索引$j$，删除它，计算剩余元素的总和，然后检查剩余数组中的每个位置，看看是否有任何元素等于该总和减去其自身。 这意味着我们正在检查是否存在索引$i \ne j$这样：$$a_i = \text{total\_sum} - a_j - a_i$$重写给出：$$2a_i = \text{total\_sum} - a_j$$因此，对于每次删除，我们都会扫描所有元素并检查此条件。 即使有了前缀和，我们仍然需要对每次删除进行扫描或频率检查，从而导致$O(n^2)$最坏情况下的行为。 和$2 \cdot 10^5$，这太慢了。 

关键的观察是删除后$a_j$，剩余数组的总和为：$$S' = S - a_j$$我们需要找到一个元素$x$在剩余的数组中：$$x = S' - x \Rightarrow 2x = S'$$这样候选值就完全确定了：$$x = \frac{S'}{2}$$这意味着对于每次删除，我们不会任意搜索。 我们只需要检查该值是否$(S - a_j)/2$删除索引后存在于数组中$j$。 这将问题简化为频率计数加上简单的有效性检查。 

我们预先计算总和和频率图。 对于每个索引$j$，我们计算所需的值并检查它是否存在于数组中，并根据所需值等于的情况进行调整$a_j$本身。

 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$|$O(1)$| 太慢了|
 | 最佳 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 计算数组的总和。 这是必要的，以便在删除任何元素后我们可以在恒定时间内计算新的总和。 
2. 构建所有值的频率图。 这允许恒定时间检查数组中是否存在候选值。 
3. 对于每个索引$j$，计算减少的总和$S' = S - a_j$。 这表示删除后数组的总和。 
4. 检查是否$S'$是均匀的。 如果是奇数，就不可能将其分成两等份，所以这种去除是无效的。 
5. 计算目标值$x = S'/2$。 这是唯一可能等于所有其他元素之和的候选元素。 
6. 临时账户删除$a_j$。 如果$x$等于$a_j$，我们要求它在原始数组中至少出现两次。 否则，我们要求它至少出现一次。 
7. 如果条件成立，则标记索引$j$为有效。 

### 为什么它有效

 移除后$a_j$，剩余数组良好的条件迫使一个方程式：一个元素必须等于剩余总和的一半。 除此之外没有任何自由，因为每个有效的配置都会崩溃到单个值约束。 频率结构确保我们正确区分该值是否在删除后仍然存在。 由于我们精确检查每个索引唯一可能的候选者，因此不会错过任何有效案例，并且不会错过任何无效案例可以通过测试。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    total = sum(a)
    freq = {}
    for v in a:
        freq[v] = freq.get(v, 0) + 1
    
    res = []
    
    for i in range(n):
        s = total - a[i]
        if s % 2 != 0:
            continue
        x = s // 2
        
        # check availability of x after removing a[i]
        if x not in freq:
            continue
        
        # if we remove one occurrence of a[i]
        need = freq[x]
        if x == a[i]:
            if freq[x] - 1 > 0:
                res.append(i + 1)
        else:
            if freq[x] > 0:
                res.append(i + 1)
    
    print(len(res))
    if res:
        print(*res)

if __name__ == "__main__":
    solve()
```该解决方案首先预先计算总和和频率字典。 主循环独立测试每个删除。 奇偶校验避免了早期不可能的分裂。 候选值计算直接从特殊元素必须等于所有其他元素之和的条件得出。 当移除的元素与候选值重叠时，频率调整保证了正确性。 

一个微妙的点是处理候选值等于删除元素的情况。 在这种情况下，我们必须确保移除后至少还存在一个事件； 否则“特殊元素”将从数组中消失。

 ## 边缘情况

 像这样的二元素数组$[x, x]$始终生成两个有效索引，因为删除一个元素会留下一个单元素数组，这很容易满足条件。 该算法处理此问题是因为剩余总和等于单个元素，并且频率逻辑确认候选值在删除后仍然存在。 

当所有元素都相同时，任何删除后的候选值仍然等于相同的值，并且每个索引的频率检查总是通过。 该算法正确地计算每个位置。 

当候选元素等于被删除的元素时，会出现更微妙的情况。 在这种情况下，实现显式地将可用计数减少一，从而防止当删除的元素是所需值的唯一出现时出现误报。
