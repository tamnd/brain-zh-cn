 ## 解决方案
 ## 问题理解

 该城市被建模为$n \times n$交叉点网格。 每个路口$(x, y)$位于垂直的街道上$x$和一条水平的街道$y$。 我们需要在一些十字路口放置警卫，每个警卫恰好“覆盖”一条垂直街道和一条水平街道，这意味着每个警卫对该行贡献一次$x$一次到专栏$y$。 

要求是每一行每一列都必须精确$k$在属于它的十字路口放置了警卫。 每个路口最多可以容纳一名警卫，因此我们有效地选择了一个单元格$n \times n$矩阵使得每行总和和每列总和恰好是$k$。 

输出还要求最少可能的警卫数量。 由于每个守卫都贡献了一行和一列，因此计算行贡献可以得出$n \cdot k$总贡献，并且每个守卫对行计数恰好贡献 1。 这已经将答案固定为$m = n \cdot k$，因此任务不是通常意义上的优化，而是使用许多选定的单元构建有效的配置。 

限制条件$n \le 1000$和$k \le n$意味着我们需要一个$O(nk)$或者$O(n^2)$最坏的情况是施工。 任何涉及流量或匹配的事情都有些过头了，但在技术上仍然可行。 该结构强烈暗示了一种直接的组合模式。 

出现微妙的失败情况时$k = 0$。 然后不应放置防护装置，并且在打印零后输出必须为空。 另一个边界情况是$k = n$，其中每行和每列必须包含所有$n$列，迫使整个网格。 

## 方法

 思考这个问题的一种强力方法是将其视为二分图结构：一侧是行，另一侧是列，每个防护都是一条边。 我们需要一个二部图，其中两侧的每个顶点都有精确的度数$k$。 人们可以尝试通过重复添加边和检查约束来搜索这样的图，或者运行每行和每列都有容量的最大流构造$k$。 这是有效的，因为每个有效的解决方案都对应于完美的度数约束二部多重图。 

然而，基于流的构建构建了一个网络$O(n^2)$潜在的边缘和运行至少$O(n^3)$或类似，具体取决于实施。 这是不必要的，因为结构是对称且规则的。 

关键的观察是我们只需要一个$k$- 两个大小相等的分区之间的正则二分图$n$。 此类图具有简单的循环结构：连接每一行$i$到$k$连续的列，环绕模数$n$。 这会自动确保每一行都有准确的$k$通过构造边缘，并且每列也准确接收$k$边缘，因为平移均匀地分布端点。 

这将问题从约束满足问题简化为确定性模式生成任务。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 流量/暴力约束构建|$O(n^3)$|$O(n^2)$| 太慢了|
 | 循环构造|$O(nk)$|$O(1)$额外 | 已接受 |

 ## 算法演练

 在二分图中，我们将行解释为左顶点，将列解释为右顶点。 我们精确构建$k$每行的边缘使用列上的滑动窗口。 

1.修复行索引$i$。 我们准确地分配它$k$列。 
2. 对于每一行$i$，将其连接到列$i, i+1, \dots, i+k-1$，使用模$n$包装。 
3. 每对这样的$(i, j)$相当于在十字路口放置警卫$(i, j)$。 
4. 输出所有构造对。 

换行是必不可少的，因为如果没有模运算，靠近末尾的行将用完列。 循环移位确保所有行的一致性。 

### 为什么它有效

 每行精确产生$k$通过构造不同的列，因此立即满足行约束。 对于列约束，观察该列$j$包含在行中$i$恰好在什么时候$j \in [i, i+k-1]$模数$n$。 在所有行上，此间隔模式均匀移动，因此每一列都被精确覆盖$k$次。 这相当于说该结构在指数循环移位下是不变的，这迫使两侧的度分布均匀。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    
    res = []
    
    for i in range(n):
        for t in range(k):
            j = (i + t) % n
            res.append((i + 1, j + 1))
    
    out = [str(len(res))]
    for x, y in res:
        out.append(f"{x} {y}")
    
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```实现直接遵循循环构造。 行和列在输出时转换为从 1 开始的索引。 嵌套循环结束$n$行和$k$偏移量准确生成$n \cdot k$警卫。 

一个常见的实施错误是忘记取模$n$，这会破坏边界附近行的正确性。 另一个是在基于 0 的内部逻辑和基于 1 的输出格式之间切换时的逐一索引。

 ## 边缘情况

 对于$k = 0$，循环不生成对。 输出列表保持为空，并且程序正确打印零。 这种情况确保了当跳过内部循环时构造不会意外地发出无效坐标。 

为了$k = n$，每一行连接到所有列。 模运算仍然有效，但它变得多余，因为不需要包装。 该算法产生完整的$n^2$网格，每一行和每一列都有精确的$n$按要求看守。
