 ## 解决方案
 ## 问题理解

 维克多有两项他想获得的独立技能，他能读的每一本书要么教他技能 1，要么教他技能 2，要么两者都教，要么不教。 每本书也都有时间成本。 任务是选择一套综合技能涵盖所需技能的书籍，同时最大限度地减少总阅读时间。 

每本书本质上都是一个小“包”：它提供了超过两位的位掩码并且有成本。 我们可以选择书籍的任何子集，但我们只关心所获得技能的结合，而不是顺序或重复。 目标是达到全面罩`11`以最小的总成本。 

测试用例的输入量很大，书籍总数高达 200,000 册。 这立即排除了任何独立尝试每个测试用例的所有子集甚至成对组合的解决方案。 二次或指数方法将无法生存。 

一个微妙的一点是，阅读多本教授重叠技能的书籍是允许的，但如果一本书在技能和成本上严格支配另一本书，则毫无益处。 另一个边缘情况是，即使每个单独的技能单独存在，也没有任何组合可以涵盖这两种技能。 

例如，如果我们有书：```
3 10
4 01
```答案是`7`，但如果两本书都只给出`00`，答案是`-1`即使书籍存在。 

另一个陷阱是假设一本书就足够了。 正确的解决方案必须明确处理一本书已经有的情况`11`。 

## 方法

 直接的暴力方法将尝试书籍的所有子集并计算每个子集的技能并集。 每个子集检查都是 O(n)，并且有 2^n 个子集，即使 n = 30 也是不可能的，更不用说 2e5 了。 

我们可以通过注意到只有四种可能的技能状态来简化结构：`00`,`01`,`10`， 和`11`。 这将问题分解为选择最多两本书，组合起来形成`11`，或者可能是一本已经等于的书`11`。 

关键的观察是我们只需要：

 - 最便宜的书提供`10`- 最便宜的书提供`01`- 最便宜的书提供`11`任何最佳解决方案都必须属于两个类别之一。 要么我们拿一个`11`书，或者我们拿一本`10`书和一`01`书。 没有其他组合可以改善这一点，因为添加额外的书籍只会增加成本，而无法改善覆盖范围`11`。 

因此，问题减少到在扫描一次输入时维持三个最小值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 对子集的暴力破解 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 追踪最佳候选人 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每个测试用例，并将所有书籍缩减为几个有代表性的候选书。 

1.初始化三个变量：`best_01`,`best_10`， 和`best_11`作为无穷大。 这些跟踪提供每种技能模式的书籍中的最低成本。 我们只关心每种类型中最便宜的代表。 
2. 迭代所有书籍。 对于每本书，检查其二进制字符串并将其分类为四种类型之一。 
3.如果书上给出了`11`， 更新`best_11`以最低的成本。 这很重要，因为一本书就可以解决问题。 
4.如果书上给出了`01`， 更新`best_01`。 
5.如果这本书给出了`10`， 更新`best_10`。 
6. 忽略`00`书，因为它们永远不会对最终的技能做出贡献。 
7. 处理完所有书籍后，计算最佳可能答案，作为以下最小值：

 的成本`best_11`，和总和`best_01 + best_10`。 
8. 如果两者都`best_11`是无限的，并且`best_01`或者`best_10`是无限的，那么不可能形成`11`，所以输出`-1`。 

### 为什么它有效

 状态空间完全由这两位捕获。 任何使用两本书以上的解决方案都可以被压缩：如果它使用多本书`10`书，只有最便宜的才重要； 同样对于`01`。 如果它混合了多种类型，最终的组合仍然会简化为单一的`11`或一个`10`加一`01`。 因此，仅跟踪每种类型的最低成本可以保留所有最佳结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**18

t = int(input())
for _ in range(t):
    n = int(input())

    best_01 = INF
    best_10 = INF
    best_11 = INF

    for _ in range(n):
        parts = input().split()
        cost = int(parts[0])
        s = parts[1]

        if s == "11":
            best_11 = min(best_11, cost)
        elif s == "10":
            best_10 = min(best_10, cost)
        elif s == "01":
            best_01 = min(best_01, cost)

    ans = min(best_11, best_01 + best_10)

    if ans >= INF:
        print(-1)
    else:
        print(ans)
```该代码是三候选缩减的直接实现。 每本书都按恒定时间进行分类。 最终的决定仅比较了两种结构可能性。 

一个常见的实施错误是忘记将候选项初始化为一个大值，这将错误地允许缺失的类别贡献为零。 另一个正在治疗`"00"`相关的，这是不必要的，如果处理不当，可能会引入不正确的最小值。

 ## 边缘情况

 当所有的书都`00`，该算法将所有候选者保持在无穷大并正确输出`-1`因为没有任何组合可以改善状态。 

当只有其中之一时`01`或者`10`存在时，总和就变得不可能，因为一项仍然是无穷大，从而防止出现错误的有效答案。 

当存在多个最优候选时，由于连续性，算法始终保留最小成本`min`更新，即使在大量重复或重新排序的情况下也能确保正确性。
