 ## 解决方案
 ## 问题理解

 我们从一堆包含`n`金块。 唯一允许的移动是将现有的一堆堆分成两堆较小的堆，并具有严格的结构：其中一个新堆的大小必须是另一堆的两倍。 如果较小的部分是`x`，分裂产生桩`x`和`2x`，所以原始堆必须有大小`3x`。 

这意味着每次操作都会替换一堆大小`3x`有两堆，其大小之和又回到它，但比例非常有限。 问题是，在对任何中间堆进行任意数量的此类分割之后，我们是否可以获得精确大小的堆`m`。 

这些约束允许最多 1000 个测试用例，桩大小最多为 1000 万个。 任何试图将所有可能的分裂模拟为堆的状态空间的解决方案都会立即爆炸，因为每次分裂都会增加堆的数量，并且分支因子在选择接下来要分裂的堆时实际上是无界的。 一个简单的状态 BFS 会重新访问大量的等效配置。 

关键的边缘情况是结构性的而不是数字性的。 如果`m > n`，在某些情况下，仍然可以通过将大堆分成一个小的和一个大的组件来间接“构建”更大的堆，但前提是结构与重复除以 3 对齐。另一个微妙的情况是当`m = n`，这在不进行任何操作的情况下总是很可能的。 最后，当`n < 3`，根本不可能分裂，所以只有平等才有效。 

粗心的贪婪方法可能会假设，由于我们正在分裂，价值总是减少，因此只会减少`m ≤ n`很重要。 这错过了像这样的情况`9 → 6 + 3`，其中较小的一堆`3`即使存在`m = 4`小于`n`。 

## 方法

 暴力解释将每种桩的配置视为一种状态。 从任何状态，我们选择一堆能被 3 整除的堆，并将其替换为`(x, 2x)`。 我们继续，直到找到一堆大小`m`或耗尽可能性。 

这在概念上是有效的，因为它探索了所有有效的转换。 问题是州的数量增长得非常快。 每次分裂都会使堆的数量增加一，并且如果每个堆可以被3整除，则可以独立分裂，因此状态空间以组合方式增长。 即使对于中等`n`，可达多重集的数量变得巨大。 

结构洞察力就是颠倒视角。 我们不去扩展所有的堆，而是问需要什么才能使堆的大小变大`n`最终产生一堆大小`m`。 每个有效的分割都保留严格的不变量：所有可达的堆大小都是通过重复乘以或除以 3 的幂结构形成的，因为每个操作都替换`3x`和`x`和`2x`。 这意味着每个可达数最终都对应于重复分解`n`转化为类似 3 的分量的幂之和。 更清晰的观察是，该过程相当于以受控方式重复分解 2 和 3 的因子，并且可达性仅取决于我们是否可以分解`n`分成可以重新排列成的块`m`使用重复除以 3。 

更直接、更标准的观察方法是从`m`。 如果`m`可以从以下位置到达`n`，那么我们可以想象逆向操作：合并`x`和`2x`回到`3x`。 所以我们反复尝试去表达`m`作为适合内部的 3 结构的 2 次幂的总和`n`。 这减少了检查我们是否可以分解`n`分成大小的块`m`如果可能的话，重复除以 2 和 3。 实际上，这变成了贪婪归约：我们反复变换`n`当它能被 2 或 3 整除时，跟踪是否`m`出现在可达分解中。 

生成的解决方案在每个测试用例中以对数时间运行。

 ## 算法演练

 我们将问题视为反复简化`n`转化为它可以通过有效的逆向推理生成的所有尺寸，并检查是否`m`适合该结构。 

1.如果`m > n`，我们立即拒绝，因为合并只会减少桩的数量，但不会产生比起始桩更大的总质量。 这是一个严格的不变量：总黄金总是被保留，所以没有堆大于`n`可能会出现。 
2.如果`n == m`，我们立即接受，因为不需要任何操作。 
3.同时`n`能被 2 整除，将它除以 2。这反映了这样一个事实：分裂和合并操作允许我们在可达堆大小的结构中隔离 2 的因子。 
4. 虽然`n`能被3整除，在推理上稍微调整一下就能被3整除：我们模拟重复合并的逆结构`(x, 2x)`进入`3x`，因此删除因子 3 可以使分解标准化。 
5.充分减少后`n`，检查是否`m`可以使用相同的简化结构来表示。 具体来说，我们减少`m`使用相同的过程并比较规范形式。 如果两者都降低到相同的核心价值，那么转型就有可能。 

关键思想是每个号码都可以从`n`共享通过以操作允许的唯一方式剥离因子 2 和 3 获得的规范“减少主干”。 

### 为什么它有效

 每个操作都会保留总和并强制任何转换都可以反转为合并`(x, 2x)`进入`3x`。 这意味着该过程准确地生成了这些分解`n`化为总和，其中每个分量最终在除以 2 和 3 的情况下简化为共享的不可约形式。该算法通过压缩两者来利用这一点`n`和`m`进入它们不可约的表示并进行比较。 如果表示匹配，则可以通过一系列有效的拆分和合并将一个表示转换为另一个表示； 否则，允许的操作的结构会阻止对齐。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def reduce(x):
    # remove factors of 2
    while x % 2 == 0:
        x //= 2
    # remove factors of 3
    while x % 3 == 0:
        x //= 3
    return x

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())

    if m > n:
        print("NO")
        continue

    if n == m:
        print("YES")
        continue

    if reduce(n) == reduce(m):
        print("YES")
    else:
        print("NO")
```该实现通过剥离 2 和 3 的所有因子，将两个数字简化为其规范形式。直觉是，允许的操作仅在 2 和 3 因子之间重新排列质量，而不改变不可约主干。 一旦两个数字共享这个主干，我们就可以模拟一系列分割和合并来对齐它们。 

早期检查`m > n`和`n == m`杜绝不必要的减量工作，明显案件直接处理。

 ## 边缘情况

 当`n = m`，算法在任何归约之前立即返回 YES。 这可以避免错误地拒绝因剥离因素而导致减少量出现偏差的情况。 

什么时候`m > n`，算法会提前拒绝，防止由于将不同量值压缩到同一骨干中而导致误导性的规范相等性。 

对于小数字，例如`n = 3`, 重复减少产量`1`，并且只有可简化为相同基数的目标才会成功。 这可以正确处理不可能拆分的情况，并确保结构不会错误地扩展可达性。
