 ## 解决方案
 ## 问题理解

 我们得到一个数组，其中每个元素都是一个小整数，特别是 6 位值。 从这个数组中，我们可以选择任何非空子序列，这意味着我们在保留顺序的同时选择索引的任何子集，尽管顺序实际上对于按位运算并不重要。 

对于每个选定的子序列，我们计算所有选定值的按位与。 这会产生 0 到 63 之间的另一个数字。然后我们计算有多少个结果 AND 值在其二进制表示中恰好设置了 k 位。 最终答案是有效子序列的数量，而不是不同结果的数量。 

主要困难在于子序列随 n 呈指数增长。 即使 n = 40，暴力破解也已经达到临界点。 这里n可以达到2×10^5，所以任何指数枚举都是不可能的。 我们需要利用值很小且“与”运算受到限制的事实。 

当存在零时，会出现微妙的边缘情况。 任何包含零的子序列都会产生零的 AND 结果，无论其他元素如何。 例如，如果数组为 [0, 7]，则每个包含 0 的子序列 AND = 0，并且只有不包含 0 的子集才能正常运行。 如果 k = 0，这些将变得占主导地位。 将零视为正常值的简单方法常常会错误计数，因为零会消除所有位。 

另一个极端情况是当 k = 0 时。我们正在计算 AND 没有设置位的子序列，这意味着 AND 等于 0。这包括许多由于共享位冲突而崩溃的组合。 统一处理 k = 0 很重要，因为单独的位计数逻辑是不够的； 我们必须跟踪精确的 AND 状态，而不仅仅是构建过程中的位计数。 

## 方法

 直接的方法是枚举所有子序列，计算它们的 AND，并检查位数。 这需要 O(2^n · n) 时间，因为每个子序列 AND 计算最多可以扫描 n 个元素。 即使使用记忆化，子序列的数量也占主导地位，使得超过 n ≈ 25 时不可行。 

关键的观察结果是每个元素都是 6 位掩码，因此每个 AND 结果也在 0 到 63 之间。这将状态空间从指数子集大大减少到只有 64 个可能的 AND 值。 我们不是直接跟踪子集，而是跟踪有多少子序列产生每个可能的 AND 结果。 

我们逐一处理元素并维护一个 DP 数组，其中 dp[mask] 是处理某个前缀后 AND 等于 mask 的子序列的数量。 当我们看到一个新值 x 时，每个现有子序列要么排除 x，要么包含 x。 包含 x 会将现有 AND 值 m 转换为 (m & x)。 排除 x 会使 m 保持不变。 我们还计算仅由 x 组成的新子序列。 

这种转换之所以有效，是因为 AND 相对于位交集而言是关联且单调的：添加元素只会减少或保留位。 因此，我们可以在 64 状态空间中干净地传播计数。 

最后，我们对 popcount 等于 k ​​的所有掩码求和 dp[mask]。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n·n) | O(2^n·n) | O(1) | O(1) | 太慢了 |
 | AND 状态上的位掩码 DP | O(n·64) | 奥(64) | 已接受 |

 ## 算法演练

 我们维护一个包含所有可能的 AND 结果的频率表。

1. 初始化一个大小为 64 且全为零的数组 dp。 这表示生成每个 AND 掩码的子序列的计数。 
2. 迭代数组中的每个数字 x。 
3. 创建一个新数组ndp，初始化为dp 的副本。 这处理“不采用 x”的情况，其中所有先前的子序列保持不变。 
4. 对于从 0 到 63 的每个掩码 m，通过添加 dp[m] 来更新 ndp[m & x]。 这表示通过包含 x 来扩展每个现有子序列，从而更新其 AND 值。 
5. 还通过递增 ndp[x] 来考虑仅由 x 组成的新子序列。 
6. 将 dp 替换为 ndp。 
7. 处理完所有元素后，对 popcount 等于 k ​​的所有掩码求和 dp[mask]。 

首先复制 dp 是必要的原因是每个元素必须在每个子序列状态转换中被恰好考虑一次。 就地混合更新会在单次迭代中错误地多次重复使用同一元素。 

### 为什么它有效

 每个子序列对应于元素包含决策的唯一序列。 DP 状态压缩共享相同结果 AND 值的所有子序列。 该转换保留了正确性，因为每个子序列要么不使用当前元素，要么只使用一次，并且 AND 运算确定性地将旧状态映射到新状态。 由于覆盖了所有可能的转换，并且在单次迭代中不会重复计算任何状态，因此 dp 始终反映已处理前缀的子序列 AND 结果的准确分布。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    dp = [0] * 64
    
    for x in a:
        ndp = dp[:]  # not take x
        
        # take x as a new subsequence
        ndp[x] = (ndp[x] + 1) % MOD
        
        # extend existing subsequences
        for m in range(64):
            if dp[m]:
                ndp[m & x] = (ndp[m & x] + dp[m]) % MOD
        
        dp = ndp
    
    ans = 0
    for m in range(64):
        if bin(m).count("1") == k:
            ans = (ans + dp[m]) % MOD
    
    print(ans)

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```DP 阵列`dp`跟踪有多少子序列产生每个可能的 AND 掩码。 关键的实现细节是我们在处理每个元素之前复制数组，确保我们不会重复使用同一迭代中的更新。 

线路`ndp[m & x] += dp[m]`是唯一的转换：它编码包括当前元素。 明确的`ndp[x] += 1`确保对单个子序列进行计数。 

最后，我们通过等于 k ​​的 popcount 过滤掩码。 由于掩码只有 0 到 63，因此最终扫描每次测试的时间都是恒定的。

 ## 边缘情况

 一个关键的边缘情况是出现许多零。 对于像这样的输入`[0, 0, 0]`，每个非空子序列的 AND 等于 0。该算法自然地处理这个问题，因为涉及 x = 0 的每个转换都会将所有掩码映射到 0，从而在 dp[0] 中正确累积计数。 

另一种情况是所有数字都相同。 每个包含项都会使组合加倍，但保持 AND 不变。 DP 将计数累积到单个掩码中，然后 popcount 过滤根据 k 对所有子序列进行计数或不进行计数。 

当值具有不相交的位（例如 [1, 2, 4, 8]）时，不同元素之间的每个 AND 都变为 0。DP 正确地将所有混合子序列路由到掩码 0，而单个子序列保持不同，匹配位交集的组合结构。
