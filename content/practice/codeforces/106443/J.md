 ## 解决方案
 ## 问题理解

 我们得到了 N 个顶点的圆形排列，标记为从 0 到 N − 1，以及固定的跳跃大小 S。从顶点 0 开始，我们重复向前移动精确的 S 个位置模 N，在这个循环上形成无限确定性行走。 

任务是确定在步行开始重复之前出现多少个不同的顶点。 换句话说，我们想要这个模算术级数中可达状态集的大小。 

约束条件允许 N 和 S 最多为 10^9，因此任何逐步模拟该过程的解决方案都立即不可行。 简单的模拟在重复之前可能需要执行 N 个步骤，这对于 1 秒的限制来说太大了。 这将我们推向数论解释而不是图遍历。 

当 S 大或等于 N 时，会出现微妙的边缘情况。例如，如果 N = 10 且 S = 10，则下一个顶点始终为 (x + 10) mod 10 = x，因此我们永远不会离开顶点 0。正确答案是 1。如果不小心处理取模行为，假设至少有一次移动会更改位置的简单实现会错误地过度计数。 

另一种边缘情况是约束不允许 S = 0，但 S = 1 会在重复之前生成所有顶点的完整遍历。 这有助于巩固对极端情况的直觉。 

## 方法

 移动规则定义了以 N 为模的残数的确定性函数：x → x + S mod N。从 0 开始，我们生成序列 0、S、2S、3S 等，全部以 N 为模。 

暴力方法会重复模拟这个过程，将访问过的顶点存储在哈希集中，直到我们返回到之前看到的顶点。 每个步骤都需要 O(1)，但在最坏的情况下，当 S 和 N 互质时，我们在重复之前访问所有 N 个顶点。 这给出了 O(N) 时间，当 N 达到 10^9 时这是不可能的。 

关键的观察是这是一个经典的模算术轨道问题。 序列 kS mod N 以等于最小正 k 的周期进行循环，使得 kS == 0 (mod N)。 该条件相当于 N 除以 kS。 最小的 k 是 N / gcd(N, S)。 这是因为 S 生成模 N 的加法群的子群，并且轨道大小等于该子群的索引。 

因此，我们不是模拟运动，而是将问题简化为计算最大公约数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(N) | O(N) | 太慢了|
 | 基于 GCD 的公式 | O(log N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们计算从 t = 0 开始，序列 x_t = (t · S) mod N 中出现了多少个不同的顶点。 

1. 读取整数 N 和 S。它们定义了模空间和步长。 
2. 计算 g = gcd(N, S)。 这捕获了与模系统的周期长度均匀对齐的最大步长。 直观上，N 和 S 都可以按其公约数缩小，而不改变可达状态的结构。 
3. 将答案计算为 N // g。 这是因为按 S 步进将 N 个顶点划分为由 gcd 确定的相等长度的循环。 
4. 输出 N // g 作为重复之前访问的不同顶点的数量。 

gcd 出现的原因是，当我们达到 N 的倍数时，S 的重复加法最终会恰好包裹起来。使 kS 能被 N 整除的最小步数是 N / gcd(N, S)，这正是轨道大小。 

### 为什么它有效

 该行走形成由 S 生成的以 N 为模的加法群的子群。每个可到达顶点的形式为 kS mod N。当 (k − k')S 能被 N 整除时，两个值 kS 和 k'S 恰好落在同一顶点上，这意味着 N / gcd(N, S) 是返回到零的最小正步长。 这是序列的周期，因此也是不同访问顶点的数量。

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

def solve():
    n, s = map(int, input().split())
    g = math.gcd(n, s)
    print(n // g)

if __name__ == "__main__":
    solve()
```该解决方案完全依赖于有效计算 gcd。 Python 数学库实现了欧几里得算法，该算法以对数时间运行。 其余的计算是一个除法。 

一个常见的错误是尝试显式模拟运动或忘记循环从 0 开始，这意味着第一个重复的顶点条件是我们再次返回 0 时。 

## 工作示例

 ### 示例 1：N = 14，S = 8

 我们计算 g = gcd(14, 8) = 2，所以答案是 14 / 2 = 7。 

| 步骤| 顶点|
 | --- | --- |
 | 0 | 0 |
 | 1 | 8 模 14 = 8 |
 | 2 | 16 模 14 = 2 |
 | 3 | 10 | 10
 | 4 | 4 |
 | 5 | 12 | 12
 | 6 | 6 |
 | 7 | 0 |

 该表显示，经过 7 个步骤后，我们返回到 0，并且在重复开始之前恰好访问了 7 个不同的顶点。 这证实了公式与周期长度相匹配。 

### 示例 2：N = 2，S = 1

 我们计算 g = gcd(2, 1) = 1，所以答案是 2。 

| 步骤| 顶点|
 | --- | --- |
 | 0 | 0 |
 | 1 | 1 |
 | 2 | 0 |

 我们在返回起点之前访问两个顶点，匹配循环的完整覆盖。

 ## 边缘情况

 ### 情况 N = S

 对于输入 N = 10、S = 10，行走永远保持在 0，因为每次移动都会加 0 模 10。gcd 为 10，因此公式给出 10 / 10 = 1，这与仅访问起始顶点的事实相符。 

### 案例 N 和 S 互质

 对于输入 N = 12、S = 5，gcd 为 1，因此答案为 12。在返回到 0 之前，遍历会循环遍历所有残差，因为没有更小的步长可以将 S 倍数与 N 的倍数对齐。该算法无需模拟即可正确识别完全覆盖。
