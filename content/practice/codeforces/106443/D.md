 ## 解决方案
 ## 问题理解

 我们有一个回合制游戏，从整数集合开始，最初正好是从 2 到 2 的数字$N+1$。 两名玩家轮流进行。 在一轮中，玩家删除当前数字的非空子集，但前提是所选子集中的所有数字共享大于 1 的公约数。删除所选子集后，剩余的数字将被丢弃，然后再次从 2 开始重新创建为新的连续序列，新长度等于旧长度减去删除的数字。 

关键的结果是，每次移动后，数字的实际身份都会被重置。 整个游戏中唯一持续存在的事情是剩下多少数字，而不是它们原来是什么。 然而，移动的合法性取决于重新标记之前的当前值，因此我们仍然需要了解连续范围中可能存在哪些子集。 

任务是确定对于每个初始$N$, whether the first player has a forced win under optimal play.

 约束条件允许$N$最多$5 \cdot 10^5$以及最多 100 个测试用例。 这立即排除了任何显式模拟子集或枚举动作的解决方案。 即使迭代状态的所有子集也是不可能的，因为单个状态已经具有指数分支。 每个测试用例的二次 DP 也会太慢。 每个测试用例的解决方案必须接近线性或更好地摊销。 

微妙的边缘情况来自游戏立即结束的小值。 例如，如果$N=1$，唯一的数字是 2，第一个玩家可以将其移走，立即获胜。 任何假设大型结构而不处理这些退化状态的推理都将在这里失败。 

另一个重要的微妙之处是，尽管数字在每次移动后都会重新标记，但合法性条件仍然取决于连续区间内的整除结构。 幼稚的方法可能会错误地假设只有大小很重要，而没有证明为什么要保留移动结构。 

## 方法

 直接的强力解释将每个状态视为当前的数字多重集，并尝试所有有效的子集。 如果子集的 gcd 大于 1，则子集有效，这意味着所有选定的数字共享某个素因数。 从一组尺寸$m$，这意味着枚举每个整数的所有倍数的所有子集$d \ge 2$。 即使检查 gcd 是有效的，子集的数量也是指数级的$m$，使得这种方法在非常小的情况下立即不可行$N$。 

关键的简化来自于观察到每次移动后，剩余的数字总是重置为从 2 开始的连续间隔。这会破坏除剩余元素的计数之外的所有结构历史。 所以游戏状态完全由一个整数描述$m$，当前的元素数量。 

来自一个州$m$元素，我们选择当前连续范围的子集。 有效的移动要求所有选定的数字共享一个公约数。 如果我们固定一个除数$d$，我们唯一可以安全选择的数字是$d$，并且所有这些数字至少自动具有 gcd$d$。 因此，任何能被同一个数整除的数的子集$d$是有效的。 

此类数字的最大池出现在$d=2$, which gives all even numbers in the range. 有$\lfloor (m+1)/2 \rfloor$甚至在$\{2, 3, \dots, m+1\}$，并且我们可以从中选择任何非空子集。 这意味着我们可以删除任意数量的元素$k$在哪里$1 \le k \le \lfloor (m+1)/2 \rfloor$。 

所以游戏简化为减法游戏：$m$，玩家可以移动到任何$m-k$在哪里$k$介于 1 和$\lfloor (m+1)/2 \rfloor$。 困难在于最大步长取决于$m$，所以我们不能立即使用固定的周期模式。 相反，我们动态计算获胜状态。

 ## 算法演练

 我们定义$dp[m]$当存在时当前玩家是否获胜$m$剩余数量。 

1.我们初始化$dp[0] = \text{false}$由于没有剩下的数字，当前玩家无法移动并立即失败。 这是向上传播获胜头寸的基础状态。 
2. 对于每个$m \ge 1$，我们计算一次移动可以删除的元素的最大数量，即$k_{\max} = \lfloor (m+1)/2 \rfloor$。 这是因为选择当前范围内所有 2 的倍数。 
3. 来自州$m$，玩家可以移动到任意状态$m-k$在哪里$1 \le k \le k_{\max}$。 这形成了可到达状态的连续区间$L = m - k_{\max}$最多$R = m - 1$。 
4.我们决定$dp[m]$通过检查区间内是否至少有一个状态$[L, R]$下一个玩家输了，这意味着$dp[x] = 0$对于某些人来说$x$在那个范围内。 如果存在这样的状态，我们就可以通过移动到那里来强行获胜。 
5. 为了有效地维护这一点，我们跟踪所有指数$x$这样$dp[x] = 0$在一个结构中。 加工前$m$，我们丢弃任何小于的存储亏损头寸$L$，因为它们不再可达。 
6. 修剪后，如果结构中仍然存在丢失的位置，则$dp[m] = 1$。 否则，$dp[m] = 0$。 
7. 我们追加$m$仅当$dp[m] = 0$，因此它可以作为未来状态的失败目标。 

### 为什么它有效

 正确性依赖于以下事实：$m$恰好落在先前状态的滑动区间内，并且该区间内至少存在一个失败状态对于获胜动作来说既是必要的也是充分的。 因为所有失败状态都会被跟踪，并且一旦超出范围就会被不断删除，因此该结构始终准确地代表当前相关的反例。 这确保了每一个$dp[m]$是根据完整且正确的可达到结果集计算得出的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    max_n = 0
    ns = []
    for _ in range(T):
        n = int(input())
        ns.append(n)
        max_n = max(max_n, n)

    dp = [0] * (max_n + 1)
    dp[0] = 0

    # store indices i where dp[i] == 0
    zeros = [0]
    head = 0  # pointer into zeros list

    # we maintain zeros as a simple queue, but we also need to discard out of range
    for m in range(1, max_n + 1):
        kmax = (m + 1) // 2
        L = m - kmax
        R = m - 1

        # remove outdated zeros (< L)
        while head < len(zeros) and zeros[head] < L:
            head += 1

        if head < len(zeros):
            dp[m] = 1
        else:
            dp[m] = 0
            zeros.append(m)

    out = []
    for n in ns:
        out.append("mastermei" if dp[n] else "the greatest")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现计算所有 dp 值，直到最大值$N$跨测试用例。 关键的想法是，在归约步骤之后，我们永远不会再次显式计算 gcd 条件，因为游戏的唯一结构效应是在导出的区间转换中捕获的。 

零状态队列被维护为移动窗口，头指针确保每个索引最多被删除一次。 这避免了重复扫描并使复杂性保持线性。 

一个常见的实施错误是忘记了$dp[m]$取决于一个区间，而不仅仅是前一个状态$m-1$。 窗户$[L, R]$是捕获所有合法移动大小的内容，并且缺少下限$L$立即破坏正确性。 

## 工作示例

 考虑$N = 3$。 我们一步步计算。 

| 米 | 最大公里数 左 | 右 | 可达 dp 范围 | dp[米] |
 | --- | --- | --- | --- | --- | --- |
 | 0 | - | - | - | 基地| 0 |
 | 1 | 1 | 0 | 0 | [0] 包含 0 | 1 |
 | 2 | 1 | 1 | 1 | [1] 包含 1 | 0 |
 | 3 | 2 | 1 | 2 | [1,2] 在 2 | 处包含 0 1 |

 为了$m=1$，唯一的移动是进入状态 0，即失败，所以$dp[1]=1$。 为了$m=2$，唯一可达到的状态是 1，即获胜，所以$dp[2]=0$。 为了$m=3$，我们可以到达状态 2，这是失败的，所以$dp[3]=1$。 

现在考虑$N = 5$。 

| 米 | 最大公里数 左 | 右 | 可达零点| dp[米] |
 | --- | --- | --- | --- | --- | --- |
 | 0 | - | - | - | {0} | 0 |
 | 1 | 1 | 0 | 0 | {0} | 1 |
 | 2 | 1 | 1 | 1 | {} | 0 |
 | 3 | 2 | 1 | 2 | {2} | 1 |
 | 4 | 2 | 2 | 3 | {} | 0 |
 | 5 | 3 | 2 | 4 | {2,4} | 1 |

 该轨迹显示了亏损头寸如何充当未来盈利状态的锚点。 一旦出现失败状态，它就可以向前传播，直到掉出滑动区间。

 ## 边缘情况

 对于$N=1$，唯一的状态是$m=1$。 间隔为$L=0, R=0$，并且自从$dp[0]=0$，状态 1 变为获胜。 该算法正确地识别立即移动到零元素。 

为了$N=2$， 在$m=2$，唯一可到达的状态是$1$，这是获胜的，所以$m=2$正在失去。 滑动窗口正确地将移动限制为单个目标。 

对于较大的值，例如$N=5$，第一个失败状态$m=2$向前传播，直到离开有效间隔。 这演示了基于窗口的跟踪如何准确捕获每个失败位置的影响范围，而无需重新计算转换。
