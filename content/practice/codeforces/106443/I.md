 ## 解决方案
 ## 问题理解

 我们得到一个带有加权边的有向图，其中每个节点代表棋盘上的一个位置，每条边代表增加或减少运行分数的移动。 从节点 1 开始，我们重复选择任何传出边缘或保持零增益。 经过大量的移动之后，我们感兴趣的是在恰好 T 个步骤的所有序列上每次移动的最大可能平均增益，其中 T 非常大。 

关键的解释是，一个策略对应于从节点1开始的无限行走，每一步的得分是总权重除以步数。 由于 T 太大，我们实际上正在寻找从该图中的节点 1 可实现的每次移动的最佳长期平均奖励。 

约束将 N 和 M 设为 2000，因此 O(NM) 或 O(N^3) 式解决方案是合理的，但诸如枚举所有路径或模拟长途行走之类的任何操作都是不可能的。 T值很大，直接模拟是没有意义的； 只有循环的渐近行为才重要。 

一个微妙的问题是，允许留在原地，但奖励为零。 这意味着就步骤的可行性而言，每个节点都可以充当权重为0的自循环的接收器，但它不会改变最佳增益的循环结构。 

常见的失败情况是假设答案仅取决于可达到的正循环，而不考虑循环的混合。 例如，如果一个周期的平均值为 5，另一个周期的平均值为 1，那么在它们之间交替比坚持最佳周期更糟糕，但转换可能会在达到良好周期之前造成暂时的损失。 

另一个陷阱是忽略可达性：如果无法从节点 1 到达，则高平均循环是无用的。 

## 方法

 一个天真的想法是模拟长途步行并尝试根据经验最大化权重之和。 但即使我们贪婪地模拟，我们也只能得到一条轨迹，并且可能的轨迹数量随着T呈指数增长。这是完全不可行的，因为T的量级为10^10。 

问题的真正结构来自这样一个事实：经过足够的步骤后，任何最优策略都必须花费几乎所有时间在某个强连接区域内循环。 到该区域的初始路径的贡献在平均值中可以忽略不计。 

这将问题简化为寻找一个循环（或强连接组件内的循环组合），使从节点 1 可到达的每条边的平均权重最大化。这是有向图中的经典最大平均循环问题。 

关键的转换是将“每步平均权重最大化”问题转化为可行性问题：对于候选值x，考虑是否存在平均值至少为x的步行。 如果我们从每个边权重中减去 x，那么我们将检查是否存在总权重非负的循环。 如果存在这样的循环，则意味着我们至少可以达到平均x。 如果不是，则 x 太大。 

这种单调属性允许对 x 进行二分搜索。 每次检查都简化为检测权重修改后的图中是否存在正循环，这可以使用 O(NM) 中的 Bellman-Ford 式松弛来完成。 

由于N和M都达到2000，所以O(NM log precision)是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(T·M) | O(N) | 太慢了|
 | 二分查找+贝尔曼-福特 | O(NM log(1e9)) | O(NM log(1e9)) | O(N + M) | 已接受 |

 ## 算法演练

 我们想要从节点 1 开始每一步可达到的最大平均权重。我们将其转化为决策问题：对于候选值 x，我们询问是否存在平均权重至少为 x 的可达循环。

1. 从 x 的二分搜索范围开始，通常从最小可能的边权重到最大可能的边权重。 这限制了答案，因为任何平均值都必须位于极值范围内。 
2. 对于固定的x，将每个边权重w变换为w − x。 如果该变换后的图中存在总和≥0的环，则原图中包含平均权重至少为x的环。 
3. 要检测从节点 1 可到达的此类循环，请在所有边上运行 Bellman-Ford 松弛 N 次。 我们维护一个距离数组，其中 dist[v] 表示 v 处可实现的最大调整和。 
4. 将 dist[1] = 0 和所有其他节点初始化为非常负数。 这强制了节点 1 的可达性。 
5. 反复放松所有边缘。 如果在 N 次迭代之后任何距离有所改善，则意味着变换后的图中存在正循环，这意味着 x 是可行的。 
6. 如果存在可行环，则将二分查找下界上移； 否则减小上限。 
7. 经过足够精度的迭代（或固定迭代，例如双精度数 60）后，输出找到的最佳值。 

为什么它有效

 任何长途步行都会分解为通往某个循环的简单路径以及该循环的重复遍历。 随着 T 的增长，路径的贡献变得可以忽略不计。 因此，极限平均值完全由循环结构决定。 变换 w − x 将问题转化为检测任意循环是否可以维持非负漂移，这正好相当于平均值至少为 x。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def has_positive_cycle(n, edges, x):
    INF = -10**30
    dist = [INF] * (n + 1)
    dist[1] = 0

    for _ in range(n):
        updated = False
        for u, v, w in edges:
            val = dist[u] + (w - x)
            if val > dist[v]:
                dist[v] = val
                updated = True

    for u, v, w in edges:
        if dist[u] + (w - x) > dist[v]:
            return True

    return False

def main():
    n, m = map(int, input().split())
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        edges.append((u, v, w))

    lo, hi = -1e9, 1e9

    for _ in range(60):
        mid = (lo + hi) / 2
        if has_positive_cycle(n, edges, mid):
            lo = mid
        else:
            hi = mid

    print(f"{lo:.10f}")

if __name__ == "__main__":
    main()
```该实现保留单个距离数组并执行 N 轮贝尔曼-福特松弛。 最后一遍检测是否仍有可能进行任何改进，这标志着转换后的图中出现正循环。 

二分查找使用浮点中点。 六十次迭代对于所需的 1e-6 精度来说绰绰有余。 

一个常见的实现错误是忘记将不可到达的节点初始化为非常负，这将错误地允许从节点 1 不可到达的周期影响答案。 

## 工作示例

 ### 示例 1

 图：

 1 → 2 (2)

 2 → 1 (-1)

 我们对值 x 进行二分查找。 考虑通过减去 x 来变换权重后的状态。 

| 迭代 | 距离[1] | 距离[2] | 重点观察|
 | --- | --- | --- | --- |
 | 初始化| 0 | -inf| 从节点 1 开始 |
 | 放松| 0 | 2-x | 边缘 1→2 |
 | 放松| x-？ | 更新 | 周期开始贡献|

 当x = 0.5时，循环1→2→1的权重为(2 + (-1)) = 1，平均值为0.5，因此变换后的循环总权重为零，使其可行。 

这证实了答案是 0.5，因为唯一有意义的循环的总权重为 1，长度为 2。 

### 示例 2

 周期：

 1 → 2 (-5)

 2 → 3 (5)

 3 → 1 (-5)

 总循环权重为-5，因此任何遍历都会平均减少。 最好的策略是使用零步留在节点 1。 

| 步骤| 距离[1] | 距离[2] | 距离[3] | 评论 |
 | --- | --- | --- | --- | --- |
 | 初始化| 0 | -inf| -inf| 开始 |
 | 放松| 0 | -5-x | -inf| 第一个边缘|
 | 放松| -5-x | ... | -10-x | 周期恶化|

 对于任何 x > 0，不存在正循环，因此答案为 0。 

这表明该算法宁愿什么也不做，也不愿被迫进入负循环。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math

    n, m = map(int, sys.stdin.readline().split())
    edges = []
    for _ in range(m):
        u, v, w = map(int, sys.stdin.readline().split())
        edges.append((u, v, w))

    def has_cycle(x):
        INF = -10**30
        dist = [INF] * (n + 1)
        dist[1] = 0

        for _ in range(n):
            for u, v, w in edges:
                if dist[u] > -10**20:
                    dist[v] = max(dist[v], dist[u] + (w - x))

        for u, v, w in edges:
            if dist[u] > -10**20 and dist[u] + (w - x) > dist[v]:
                return True
        return False

    for _ in range(60):
        mid = (lo + hi) / 2
        if has_cycle(mid):
            lo = mid
        else:
            hi = mid

    return f"{lo:.6f}"

 ## 边缘情况

 一个关键的边缘情况是当存在高值循环但无法从节点 1 到达时。距离的初始化确保此类循环永远不会被激活，因为只有节点 1 以有限值开始。 

另一种情况是只有有效自停留的图。 由于停留贡献为零，因此如果不存在正循环，算法会正确返回零。 

最后，负循环不会欺骗算法错误地减少答案，因为我们正在最大化平均值，并且与保持为零相比，任何负循环都变得没有吸引力。
