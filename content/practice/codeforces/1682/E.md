 ## 解决方案
 ## 问题理解

 我们得到一个整数的排列$1$到$n$和一组$m$交换，保证是对排列进行排序所需的最小交换。 这些互换被任意洗牌。 任务是重建这些交换的顺序，以正确对排列进行排序。 每个交换对数组中的两个位置进行操作，交换它们的值。 输出是索引的排列，指示我们应该执行给定交换的顺序。 

排列大小$n$可以大到$2 \cdot 10^5$和交换次数$m$可以达到$n - 1$。 这意味着任何解决方案都必须大致运行$O(n \log n)$或者$O(n)$时间。 算法与$O(n^2)$行为会超出时间限制。 边缘情况包括已经排序的排列（需要$0$互换，虽然$m \ge 1$），与排序顺序相反的排列（需要最大交换），或仅在周期内移动值的交换。 

例如，忽略排列循环结构的粗心实现可能会以给定的任意顺序应用交换而无法对数组进行排序，或者可能会尝试贪婪地选择交换而不检查它们是否解析循环，从而导致排序序列不完整。 

## 方法

 蛮力方法是尝试所有$m!$交换的排列并每次模拟排序以查看是否会产生排序数组。 从定义上来说这是正确的，但是$m!$阶乘增长，所以即使对于$m = 10$这种做法是不可行的。 模拟每个序列涉及$m \cdot n$操作，这使问题变得更加复杂。 

关键的观察是任何排列都可以分解为不相交的循环，并且对排列进行排序至少需要打破每个循环的长度$k$准确地使用$k-1$互换。 由于我们精确地给出了最小交换次数$m$，每次交换必须对应于在一个周期内移动一个元素。 因此，我们可以将问题建模为一个图，其中位置是顶点，给定的交换是边。 该图的每个连通分量对应于排列中的一个循环。 只要我们精确地使用给定的交换，循环内的排序就可以以任何顺序完成。 这减少了对每个组件执行 DFS（或任何遍历）并以完成时间的相反顺序输出交换以重建有效序列的问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(m! * m * n) | O(n) | 太慢了|
 | 循环上的图形 DFS | O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 创建数组`pos`在哪里`pos[v]`存储当前值的索引`v`在排列中。 这允许 O(1) 访问任何元素的当前位置。 
2. 将给定的互换表示为图表。 每个索引都是一个顶点，每个交换都是连接两个索引的无向边。 
3. 初始化一个大小为visited的数组$n$跟踪已处理的索引。 
4. 对于每个索引`i`从1到n，如果未被访问，则对其连接的组件开始DFS遍历。 该分量代表排列中的一个循环。 
5. 在DFS期间，当访问边（交换）时，将其标记为已使用，并将其添加到后序交换列表中。 这确保我们将以有效的顺序应用交换，从而解决循环中的依赖关系。 
6. 对所有组件完成 DFS 后，按照添加顺序的相反顺序输出交换。 这对应于按照正确排序每个周期的顺序执行交换。 

工作原理：交换图中的每个连接组件对应于排列中的一个循环。 通过遍历组件并使用组件中的所有边，我们保证循环内的所有元素都到达其正确位置。 由于交换次数很少，因此每次交换都是必要的，并且以反向 DFS 顺序执行它们会尊重依赖性。 不变量是组件中的所有顶点都被访问一次，并且组件中的所有交换都被使用一次，从而确保完整性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

n, m = map(int, input().split())
p = list(map(int, input().split()))
edges = []
graph = [[] for _ in range(n)]

for idx in range(m):
    x, y = map(int, input().split())
    x -= 1
    y -= 1
    edges.append((x, y))
    graph[x].append((y, idx))
    graph[y].append((x, idx))

visited = [False] * n
used_edge = [False] * m
res = []

def dfs(u):
    visited[u] = True
    for v, idx in graph[u]:
        if not used_edge[idx]:
            used_edge[idx] = True
            if not visited[v]:
                dfs(v)
            res.append(idx + 1)

for i in range(n):
    if not visited[i]:
        dfs(i)

print(' '.join(map(str, reversed(res))))
```该代码首先构建一个图，其中顶点是位置，边是交换。 我们跟踪访问过的节点和使用过的边。 DFS 确保每个掉期应用一次并访问由掉期连接的所有头寸。 在递归后追加交换并在最后反转它们可以保证依赖关系得到尊重。 输出的索引是从 1 开始的，这就是为什么我们在存储时加 1`res`。
