 ## 解决方案
 ## 问题理解

 迷宫是一棵以房间 1 为根的无向树。Vlad 从房间 1 开始，想要到达房间 1 之外的任何叶节点。叶子是恰好有一个相邻走廊的任何节点。 

同时，几个朋友已经被放置在不同的节点上。 每一秒，Vlad 和所有朋友都可以停留或移动到相邻节点，并且每个人同时移动。 如果 Vlad 曾经降落在一个节点上或穿过一个朋友同时或更早出现的边缘，Vlad 会立即失败。 

问题是弗拉德是否可以选择一种策略，以便无论朋友如何移动，他仍然可以安全地到达一些叶子。 

重要的方面是对抗性的运动：朋友们完美地合作阻止弗拉德，而弗拉德则选择自己的道路。 这就把问题变成了检查弗拉德是否至少有一个“逃生叶”，其到达速度严格来说比任何朋友拦截的速度都快。 

约束足够大，以至于每个测试用例的任何解决方案都必须是线性或接近线性的。 由于所有测试的节点总和最多为 2 × 10^5，因此需要 O(n) 或 O(n log n) 总方法。 任何运动模拟或每条路径检查都会太慢，因为必须计算树上的距离。 

如果我们忽略朋友同时移动，就会出现微妙的失败情况。 

例如，如果 Vlad 看到距离 5 远的一片叶子，而距离 6 远的朋友，则不足以说 Vlad 获胜，因为移动是并行发生的，拦截可能会沿着路径发生，而不仅仅是在端点处。 除非我们仔细建模来自朋友的多源最短路径，否则天真的贪婪的“比较与叶​​子的距离”可能会失败。 

另一种边缘情况是当根与叶子相邻时。 弗拉德可能会尝试立即逃跑，但如果朋友开始足够近，即使他们最初不在叶子本身上，他们也可能会在第一步拦截。 

## 方法

 一个蛮力的想法是在每一步都模拟弗拉德和所有朋友。 我们会为 Vlad 尝试所有可能的动作，为朋友尝试所有可能的反应，从而有效地探索博弈树。 即使进行了修剪，这种情况也会发生爆炸，因为每个节点都按度数分支，并且树的高度可能是 O(n)。 这很快就会呈指数增长。 

关键的观察结果是，朋友们并不是独立地选择各自的最佳策略；而是 相反，我们只关心它们能够以多快的速度共同到达每个节点。 由于所有朋友同时移动，我们可以为每个节点计算任何朋友可以到达该节点的最短时间。 这是一个经典的无权树上的多源最短路径问题，从所有朋友开始通过 BFS 解决。 

一旦我们知道敌人在每个节点的最早到达时间，Vlad 的问题就简化为从节点 1 开始的单源 BFS。Vlad 只能安全地穿过他的到达时间严格小于朋友到达时间的节点。 如果 Vlad 在此约束下到达任何叶节点（不包括节点 1），他就获胜。 

问题变成检查图上时间约束字段下的可达性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解游戏模拟| 指数| 高| 太慢了 |
 | 多源BFS+约束BFS | 每次测试 O(n) | O(n) | 已接受 |

 ## 算法演练

 我们独立处理每个测试用例。 

1. 使用用所有好友位置初始化的 BFS 计算任何好友可以到达每个节点的最早时间。 这给出了一个距离数组`distF`。 

此步骤之所以有效，是因为所有边都具有相同的权重，因此 BFS 可以同时正确计算来自多个源的最短路径。 
2. 从节点 1 为 Vlad 运行 BFS，跟踪他的到达时间`distV[u]`。 
3. 在Vlad的BFS期间，只允许转移到邻居`v`如果`distV[v] < distF[v]`。 

此条件确保 Vlad 在任何朋友可以占领或拦截该节点之前严格到达。 
4. 如果 Vlad 到达任何非节点 1 的叶节点（度数 1），我们立即断定他可以获胜。 
5. 如果 BFS 结束时没有到达这样的叶子，Vlad 不能保证逃脱。 

### 为什么它有效

 关键的不变量是 Vlad 访问的每个节点都严格早于任何朋友到达。 由于朋友会以最佳方式移动来阻止他，因此如果朋友在 Vlad 之前可以到达某个节点，则该节点是不安全的。 BFS 限制对所有可能的对抗策略强制执行全局安全条件，将游戏压缩为到达时间的静态比较。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        line = input().strip()
        while line == "":
            line = input().strip()
        n, k = map(int, line.split())

        friends = list(map(int, input().split()))
        g = [[] for _ in range(n + 1)]

        for _ in range(n - 1):
            u, v = map(int, input().split())
            g[u].append(v)
            g[v].append(u)

        INF = 10**18
        distF = [INF] * (n + 1)
        q = deque()

        for f in friends:
            distF[f] = 0
            q.append(f)

        while q:
            u = q.popleft()
            for v in g[u]:
                if distF[v] == INF:
                    distF[v] = distF[u] + 1
                    q.append(v)

        distV = [-1] * (n + 1)
        q = deque([1])
        distV[1] = 0

        ans = False

        while q:
            u = q.popleft()

            if u != 1 and len(g[u]) == 1:
                ans = True
                break

            for v in g[u]:
                if distV[v] == -1:
                    nd = distV[u] + 1
                    if nd < distF[v]:
                        distV[v] = nd
                        q.append(v)

        print("YES" if ans else "NO")

if __name__ == "__main__":
    solve()
```该解决方案将问题分为两次 BFS 遍历。 第一个计算敌人控制每个节点的速度，第二个检查 Vlad 是否可以严格更早地进入任何叶子。 

一个微妙的实现细节是严格的不平等`nd < distF[v]`。 平等是不安全的，因为与朋友同时到达仍然会导致拦截。 

另一个重要的细节是正确检测树叶。 我们明确排除节点 1，即使它在小树中的度为 1，因为 Vlad 必须到达不同的叶子才能获胜。 

## 工作示例

 ### 示例 1

 输入：```
3 1
2
1 2
2 3
```来自节点 2 的朋友的第一个 BFS 给出：```
distF[2]=0, distF[1]=1, distF[3]=1
```弗拉德 BFS 启动：```
distV[1]=0 → can go to 2 (but 1 < 0 is false, so blocked)
```所以弗拉德无法安全地移动到任何地方。 

| 步骤| 节点| 距离 | 状况 |
 | ---| ---| ---| ---|
 | 开始 | 1 | 0 | 根 |
 | 尝试 2 | 2 | 被封锁 | 1 < 0 假 |

 输出为“否”，因为 Vlad 立即被控制在中心。 

### 示例 2

 输入：```
5 1
5
1 2
2 3
3 4
4 5
```朋友从 5 开始，所以距离：```
distF = [INF, 4, 3, 2, 1, 0]
```弗拉德 BFS：```
1 -> 2 -> 3 -> 4
```他在时间 3 到达节点 4，但 distF[4] = 1，因此被阻塞在那里。 

他无法继续前进。 

这表明，如果朋友距离出口较近，即使很长的路径也是不安全的。

 ## 边缘情况

 一种边缘情况是当朋友开始与节点 1 相邻时。在这种情况下，`distF[1] = 1`，因此 Vlad 无法安全地移动到与好友距离为 1 或更小的任何邻居。 BFS 正确地阻止了所有立即移动，因为严格的不等式在第一层失败了。 

另一种情况是当多个叶子存在于不同深度时。 该算法不喜欢浅叶或深叶； 相反，它自然会找到任何可到达的安全叶子。 简单的叶子最短路径方法在这里会失败，因为“最近的叶子”可能不安全，而稍远的叶子是安全的，并且只有每个节点的安全比较才能捕捉到这种区别。 

最后一个微妙的情况发生在弗拉德和朋友可以通过不同的路径同时到达一个节点时。 严格的不平等阻止接受平等，这可以正确地模拟移动过程中的拦截，而不仅仅是在节点处。
