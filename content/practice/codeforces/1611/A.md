 ## 解决方案
 ## 问题理解

 我们得到一个以十进制形式书写的数字，没有零位。 唯一允许的操作是获取号码的前缀并反转该前缀内的数字顺序。 前缀长度可以是 1 到号码全长之间的任意值。 

目标是使用尽可能少的前缀反转操作将数字转换为偶数。 如果不可能，我们必须报告-1。 

关键的观察结果来自这样一个事实：与偶数相关的唯一属性是最后一位数字。 因此，整个问题归结为控制哪个数字最终到达最后一个位置，以及使用前缀反转将这样的数字移动到那里的成本有多大。 

每个测试用例的约束非常小，因为每个数字都小于 10^9，因此最多有 9 位数字。 即使有多达 10^4 个测试用例，任何直接检查数字或每个用例尝试少量固定推理的解决方案就足够了。 任何模拟任意操作序列或探索数字的多种状态的方法都被排除在外。 

当数字已经是奇数但内部包含多个偶数位时，就会出现微妙的失败情况。 例如，如果我们只查看我们看到的第一个偶数位，我们可能会低估将其放置在末尾的成本。 另一个棘手的情况是根本不存在偶数，例如`3`或者`13579`，其中任何反转序列都不能引入均匀性，因为反转不会改变数字，只会改变它们的位置。 

## 方法

 一个蛮力的想法是将每个数字视为图中的一个状态，其中每个节点都是数字的排列，边对应于前缀反转。 从初始数字直到达到以偶数结尾的状态的 BFS 将给出正确的答案。 这是正确的，因为每个操作都有相同的成本。 

然而，这个状态空间是巨大的。 即使是 9 位数字，也最多有 9 个！ 排列，BFS 将为每个状态分支最多 9 个选择（每个前缀长度一个）。 这使得它完全不可行。 

关键的简化是停止考虑完整的排列，而只关注最后一位数字。 每个操作仅更改最后位置上的数字，但不会更改数字标识。 所以问题就变成了：我们可以把哪个偶数放到最后一个位置，需要多少次前缀反转才能把它放在那里？ 

为了将位置 i（0 索引）处的数字放到末尾，我们最多可以使用两次反转：

 首先反转前缀 i+1 将其置于前面，然后反转整个字符串以将其发送到后面。 这总是可能的，因为前缀反转让我们能够以恒定的步骤将任何元素重新定位到任一端。 

因此最优策略是：

 查找从右侧最接近的偶数。 如果最后一位数字已经是偶数，我们就完成了。 否则，如果存在偶数位，我们可以根据其位置通过一次或两次操作使该数字为偶数。 如果不存在偶数，则不可能。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 BFS 遍历状态 | O(9!·9) | O(9!·9) | O(9!) | 太慢了 |
 | 贪心数字定位 | 每次测试 O(d) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将数字作为字符串读取，这样我们就可以不受数字限制地自由操作数字。 
2. 从右向左扫描，检查最后一位数字是否已经是偶数。 如果是，则立即返回0，因为不需要任何操作。 
3. 如果最后一位数字是奇数，则扫描整个号码以查找偶数数字。 如果不存在，则返回 -1，因为没有操作可以创建偶数位。 
4. 如果第 i 处存在偶数：

 如果 i 是 0 或者 i 已经是最后一个索引，我们可以在一次完全反转中使其成为最后一个，所以答案是 1。 

否则，我们可以通过一次前缀反转将其带到前面，然后通过另一次完全反转将其发送到后面，所以答案是 2。 
5. 输出这些可能性中的最小值。 

为什么这有效来自于前缀反转的结构。 前缀反转可以将选定的数字向前移动或间接地将其移动到靠近末尾的位置，但每个数字移动都可以通过最多两次操作来优化模拟以到达最后位置。 由于只有最后一位数字的奇偶校验很重要，因此除了确保目标偶数位到达末尾之外，我们不需要维护中间配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_one(s: str) -> int:
    n = len(s)
    
    # If already even
    if (ord(s[-1]) - 48) % 2 == 0:
        return 0

    # find any even digit
    for ch in s:
        if (ord(ch) - 48) % 2 == 0:
            break
    else:
        return -1

    # if first digit is even or we can directly reverse whole string
    if (ord(s[0]) - 48) % 2 == 0:
        return 1

    # otherwise need two operations
    return 2

t = int(input())
for _ in range(t):
    s = input().strip()
    print(solve_one(s))
```该解决方案隔离了唯一相关的状态，即最后一位数字是否为偶数。 扫描偶数位可确保可行性。 1 和 2 运算的区别在于我们是否可以立即将偶数放在前面，或者需要首先通过前缀反转来重新排列它。 

该代码避免构造新字符串，因为只有奇偶校验很重要，并且使用 ASCII 算术来提高效率。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    def solve_one(s: str) -> int:
        if int(s[-1]) % 2 == 0:
            return 0
        if not any(int(c) % 2 == 0 for c in s):
            return -1

            return 1

 ## 边缘情况

 一个关键的边缘情况是数字根本没有偶数位。 用于输入`13579`，扫描显示没有可能成为最后一位数字的候选数字。 由于前缀反转仅排列数字，因此永远不会引入奇偶校验，并且算法会正确返回`-1`。 

另一种情况是个位数，例如`8`。 最后一位数字已经是偶数，因此算法立即返回`0`无需尝试任何扫描。 这避免了不必要的逻辑并确认最小输入大小的正确性。 

第三种情况是偶数存在但不在任一边界处，例如`9831`。 最后一位是奇数，但有一个偶数`8`。 由于第一位数字是偶数，我们可以直接执行一次完全反转，将结构变成最后一位数字变为偶数的形式，算法返回`1`。
