 ## 解决方案
 ## 问题理解

 我们被要求确定一个车队可以拥有多少辆公共汽车并给出车轮总数。 每辆公交车都有两种类型之一：四轮两轴公交车和六轮三轴公交车。 输入由多个测试用例组成，每个测试用例指定车轮总数，输出必须是可达到该车轮总数的最小和最大总线数。 如果没有总线组合可以产生该总数，则输出为`-1`。 

这些约束对于算术来说是慷慨的，但对于朴素枚举来说是限制性的。 The number of wheels`n`可以大到 10^18，这意味着任何试图枚举所有总线组合的解决方案都是不可行的。 最多 1,000 个测试用例的 1 秒时间限制意味着每个测试用例需要 O(1) 或 O(log n) 解决方案。 边缘情况包括小总数，例如`1`,`2`， 或者`3`，这是不可能用 4 轮和 6 轮公共汽车形成的，而且总数非常大，必须使用精确的整数算术来处理而不会溢出。 

对于奇数或无法整除 4 和 6 之和的总数，天真的方法可能会失败。 例如，不能组成7个轮子，因为4+4=8超过了它，6+4=10也超过了它。 小输入，例如`4`或者`6`要求算法检测到只有一条总线是可能的，它同时是最小值和最大值。 

## 方法

 蛮力方法尝试了两轴和三轴公共汽车的所有组合，其车轮总和为`n`。 对于每个`a`在`[0, n//4]`，它检查是否`n - 4*a`可被 6 整除。这是正确的，因为它考虑了所有有效分区，但每个测试用例最多需要 n/4 次迭代。 为了`n = 10^18`，这是完全不可行的。 

关键的见解来自简单的整数算术。 让`x`是 2 轴公交车的数量，`y`三轴公交车的数量。 那么我们有线性丢番图方程`4*x + 6*y = n`。 两边同时除以 2 得到`2*x + 3*y = n/2`。 我们现在可以解决`x`和`y`作为非负整数。 当我们最大化时，巴士数量就会达到最少`y`，因为 3 轴公交车每辆公交车有更多的车轮。 这导致`y = floor(n/6)`如果`n`能被 2 整除，然后`x`是剩余的轮子除以 4。当我们最大化时，公共汽车的数量就会达到最大`x`，导致`x = floor(n/4)`和`y`进行相应调整。 如果`n`为奇数，或者除以2后余数不能被2整除，则无解。

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，读取总车轮数`n`。 
2. 检查是否`n`小于4。如果是，则输出`-1`因为公共汽车组合的轮子数量不得少于 4 个。 
3. 乘坐尽可能多的三轴公交车，计算出最少的公交车数量。 放`min_buses = ceil(n/6)`因为每辆 3 轴公交车有 6 个车轮。 如果`n`能被2整除，整数运算就足够了。 
4. 通过乘坐尽可能多的 2 轴公交车来计算公交车的最大数量。 放`max_buses = n // 4`因为每辆 2 轴公交车有 4 个车轮。 
5. 检查是否`n`能被2整除。如果不能被2整除，则打印`-1`因为 4 和 6 都是偶数，所以不可能有奇数。 否则，打印`min_buses`和`max_buses`。 

正确性依赖于以下不变量：四轮和六轮公共汽车的每个有效组合之和必须为偶数。 最大化 3 轴公交车的数量可以最小化公交车总数量，而最大化 2 轴公交车则可以最大化公交车总数量。 下限和上限算法确保我们不会错过可行的整数解。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    if n < 4 or n % 2 != 0:
        print(-1)
        continue
    min_buses = (n + 5) // 6  # ceil(n / 6)
    max_buses = n // 4         # floor(n / 4)
    print(min_buses, max_buses)
```该代码使用有效地读取输入`sys.stdin.readline`。 我们立即过滤掉太小或奇数的总数。 公交车的最小数量采用天花板划分，以保证三轴公交车覆盖足够的车轮。 公交车的最大数量采用楼层划分来最大化2轴公交车。 在 Python 中，两种除法都能正确处理非常大的整数。 

## 工作示例

 用于输入`n = 4`,`(4+5)//6 = 1`对于最小总线和`4//4 = 1`为最大。 输出是`1 1`，符合预期。 为了`n = 24`,`(24+5)//6 = 29//6 = 4`对于最小值和`24//4 = 6`为最大，生产`4 6`，与示例说明相符。

 ## 边缘情况

 当`n`小于4，算法立即返回`-1`。 对于奇数，例如`7`,`5`， 或者`1`，算法返回`-1`因为 4 和 6 的总和不能为奇数。 对于 2 的倍数但不是 4 或 6 的倍数，例如`10`，该算法通过适当分配余数来正确计算最小值和最大值。 对于非常大的数字，Python 处理整数运算时不会溢出，即使在以下情况下也能确保正确性：`n`接近 10^18。
