 ## 解决方案
 ## 问题理解

 我们得到一个整数序列。 在一步操作中，我们选择任何单个元素并将其精确地加二或减二。 我们重复这一过程，直到至少一个元素恰好为零。 目标是尽量减少达到该条件所需的移动次数，或者报告这是不可能的。 

重要的是我们并不试图将整个数组转换成任何特定的东西。 我们只关心让一个位置尽快归零，并且我们可以自由选择在每一步修改哪个索引。 

约束非常大，数量最多为 10^6 个，值的大小最多为 10^9。 这立即排除了任何试图跟踪所有中间值或探索移动序列的模拟。 任何解决方案都必须将问题简化为线性时间内的每个元素或聚合计算。 

一个微妙的点是奇偶性。 由于每个操作都会将数字更改为 2，因此每个元素的奇偶校验永远不会改变。 从奇数开始的数字将始终保持奇数，从偶数开始的数字将始终保持偶数。 由于零是偶数，因此无论应用多少次运算，任何奇数都永远不会变为零。 这已经创造了一整类不可能的情况。 

第二个边缘情况来自负数。 问题陈述允许负值，并且从负值到达零遵循相同的奇偶校验和步长限制。 如果忽略符号无关紧要，只关心绝对距离和奇偶校验，那么假设所有数字都是到零的正距离的天真的方法就会失败。 

例如，如果我们有一个单元素数组`[5]`，我们可能会尝试反复将其减少 2：5 → 3 → 1 → -1 → -3 ...我们从未达到零，因此正确答案是 -1。 一个粗心的解决方案使用`abs(a[i]) // 2`会错误地声称它可以在 2 步内达到零。 

另一个例子是`[4, 3]`。 尽管 4 可以在 2 步内到达 0，但 3 是不可能的，因为它是奇数，所以答案是 -1。 

## 方法

 如果我们专注于单个元素，该过程就会变得简单：我们尝试使用大小为 2 的步骤达到零。 这意味着我们实际上是在步幅为 2 的整数线上行走。 

对于一个值`x`，我们只能得到具有相同奇偶性的数字`x`。 因此，唯一能够达到零的候选数是偶数。 其中，所需的移动次数正是我们需要减去或加2才能达到零的次数，即`|x| / 2`。 

由于我们可以在每一步操作任何索引，因此我们不需要担心元素之间的交互。 每次移动都花费在单个元素上，因此最佳策略是选择需要最少移动达到零的元素。 然而，问题要求的是至少一个元素变为零之前所需的最小移动次数，而不是所有元素的总和。 这意味着我们并没有完成所有转变，只是完成了第一次成功的打击。 

因此，该过程简化为计算每个元素是否可以达到零以及需要移动多少次，然后在所有有效候选元素中取最小值。 

蛮力的想法将模拟所有操作序列，在每一步尝试所有选择。 每一步有N个选择，我们可能需要最多O(max |a_i|)步，这是完全不可行的。 分支因子使得这个时间呈指数级增长。 

关键的观察是每个元素独立演化，达到零仅取决于宇称和距离。 这将问题分解为简单的每个元素计算。

 | ---| ---| ---| ---|
 | 暴力模拟| 指数| O(N) | 太慢了 |

 ## 算法演练

 1.读取数组并初始化变量`answer`无穷大，因为我们希望所有有效元素中所需的移动次数最少。 
2. 对于每个元素`x`，首先检查是否是偶数。 如果`x`如果是奇数，请立即跳过它，因为在 ±2 步的情况下它永远不可能达到零。 
3.如果`x`是偶数，计算达到零所需的移动次数，即`|x| // 2`。 这表示将其幅度减小到零所需的精确的 ±2 步数。 
4. 更新`answer = min(answer, |x| // 2)`。 
5.处理完所有元素后，如果没有找到偶数，含义`answer`仍为无穷大，返回`-1`。 否则，返回`answer`。 

### 为什么它有效

 每个元素在固定步长 2 下独立演化，因此其是否可达零仅取决于零是否位于其可达残差类模 2 中。由于奇偶校验在操作下不变，因此奇数与零永久断开。 对于偶数，每次操作都会将绝对距离减少到零，恰好是 2，并且没有分支结构可以改变这种距离演化。 因此，达到零的最短时间是每个元素完全确定的，并且全局答案只是所有可单独达到的候选者中最好的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    arr = list(map(int, input().split()))
    
    INF = 10**18
    ans = INF
    
    for x in arr:
        if x % 2 != 0:
            continue
        ans = min(ans, abs(x) // 2)
    
    if ans == INF:
        print(-1)
    else:
        print(ans)

if __name__ == "__main__":
    solve()
```该实现直接遵循奇偶校验是唯一阻塞条件的观察。 该循环仅计算偶数值的候选答案。 绝对值的使用确保了负数的正确处理，因为到零的距离是两侧对称的。 

哨兵值`INF`用于检测不存在有效元素的情况。 这是必要的，因为返回零或默认值会错误地表明成功。

 ## 边缘情况

 一个关键的边缘情况是所有数字都是奇数。 在这种情况下，任何操作序列都不会产生零，因为奇偶校验永远不会改变。 该算法自然地处理这个问题，因为`ans`保持无穷大，我们返回`-1`。 

另一个边缘情况是单元素数组。 如果该值是偶数，则答案很简单`|x|/2`，如果是奇数，结果是`-1`。 该算法不需要任何特殊的大小写，因为这两种行为都已编码在奇偶校验中。 

负值的行为与正值相同，因为每个 ±2 运算都会使数字在零周围对称移动。 该算法正确地使用了绝对值，因此`-8`和`8`产生相同的结果，即 4 步。
