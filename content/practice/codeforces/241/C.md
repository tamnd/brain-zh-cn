 ## 解决方案
 ## 问题理解

 该系统描述了一个矩形盒子，其中激光束通过左壁上的一个小孔进入，并且必须通过右壁上的另一个孔退出。 盒子内部，有水平的镜面放置在地板上或天花板上。 每个镜子覆盖沿水平轴的一段，并带有一个分数，如果激光束至少接触该镜子一次，则获得分数。 光束完美反射，这意味着它的入射角等于其反射角，因此一旦选择了起始角度，路径就完全确定了。 

单次射击相当于选择一条从左洞开始的直线，通过镜子在顶部和底部边界之间弹跳，最终到达右洞。 每次光束接触镜子部分时，我们都可以收集它的值，但每个镜子最多只能贡献一次，即使在几何上光束可以多次撞击它。 任务是选择初始方向，以使沿诱导路径收集的总得分最大化。 

就镜像数量而言，约束很小，最多 100 个，因此任何探索镜像上所有有意义的组合结构的解决方案都是潜在可行的。 然而，水平坐标跨度很大，因此任何简单地离散位置或以高分辨率模拟光束的方法都将是不可靠或太慢的。 真正的挑战不是数值精度，而是了解存在多少种根本不同的光束轨迹。 

当多个镜子在投影中重叠时，会出现微妙的边缘情况。 当稍差的早期选择稍后解锁更好的序列时，假设光束总是采用局部最佳镜子的天真贪婪方法就会失败。 当人们尝试连续模拟光束而没有认识到反射路径可以抽象为由镜子相互作用的顺序而不是连续几何形状确定的离散状态时，就会出现另一种故障模式。 

例如，如果镜子强制两个可能的反弹模式具有相同的第一个交叉点，但后来的可访问性不同，则第一个高值镜子的贪婪选择会阻止最佳路径。 正确的答案可能需要跳过大量的早期奖励，以在轨迹的后期达到更密集的集群。 

## 方法

 蛮力思维模型是考虑来自左孔的每个可能的光束方向。 每个方向都会产生由几何交叉和反射规则确定的一系列镜子撞击。 对于每条模拟光线，我们都会累积分数，同时确保每个镜子都被计数一次。 这种方法是正确的，因为物理学唯一地确定了固定角度的轨迹，因此枚举所有角度最终将覆盖所有组合不同的路径。 

问题是可能的角度空间是连续的。 即使我们仔细离散化，斜率的微小变化也会重新排列遇到镜子的顺序，这意味着我们需要考虑潜在的指数组合情况。 每个角度的直接模拟需要逐步遍历反射，并且每个步骤都涉及找到所有镜子之间的下一个交叉点，每次反射的成本为 O(n)。 由于有许多可能的反弹和许多候选角度，这很快就变得不可行。

关键的观察是我们实际上并不需要连续地对几何进行建模。 每次反射镜命中取决于光束在一定水平传播后在顶部或底部边界上接下来相交的部分。 一旦我们重新解释系统，光束就会在撞击镜面的“事件”之间有效地移动，并且垂直运动在每次反射后都会翻转方向。 这使我们能够将过程建模为有向图，其中状态对应于具有给定行进方向的镜像端点。 过渡表示跳到光线可以沿该方向照射的下一个镜子。 

因为镜子是两条线（顶部和底部）上的间隔，所以沿 x 的相互作用顺序才是重要的。 我们可以对所有端点进行排序，并使用位置上的动态编程来处理可到达的段，将每个镜像视为一个状态，并根据方向计算下一个从其左端点或右端点击中的镜像。 该结构成为 O(n) 状态上的类似 DAG 的转换系统，其中每个转换都是通过沿着排序端点向前或向后扫描来确定的。 

该解决方案简化为计算该有向图中的最佳得分路径，其中边缘表示反射约束下镜子命中之间的有效光线传播。 由于 n 至多为 100，因此 O(n^2) 构造和 O(n^2) DP 就足够了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 角度上的强力射线模拟 | 指数/连续 | O(1)-O(n) | O(1)-O(n) | 太慢了 |
 | 镜像 + DP 上的状态图 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 我们将每个镜子重新解释为一个片段，可以根据光束到达的方式从任一方向进入。 光束以可预测的方式交替向上和向下移动，因此唯一的不确定性是在垂直状态下接下来沿着 x 轴遇到哪个镜子。 

1. 按 x 间隔对镜子进行排序。 这使我们能够在从左到右或从右到左扫描时有效地确定片段之间的排序关系。 
2. 构建一个结构，对于每个镜像端点和每个垂直移动方向，识别沿 x 轴的下一个镜像命中。 此步骤对以下几何事实进行编码：沿固定斜率方向行进的射线与它遇到的第一个兼容线段相交。 
3. 将状态定义为“我们刚刚击中镜子 i 并将其留在给定的垂直方向”。 每个镜像在每个状态条目中贡献一次其值。 
4. 对于每个状态，通过跟踪射线直到它与与当前垂直方向一致的另一线段相交来计算下一个可到达的镜像。 因为只有 O(n) 个镜子，所以下一步可以通过检查所有候选者并选择第一个有效的交叉点来确定。 
5. 构建状态之间的转换。 每个过渡通过翻转垂直方向来保留反射规则，具体取决于我们是否击中顶部或底部镜子。 
6. 对所有状态运行动态规划，更新可达到的最佳分数。 由于每个状态仅取决于先前计算的转换，并且不存在可以无限增加分数的循环（在有益循环中不会重新访问镜像），因此定点松弛或有序 DP 就足够了。 
7. 答案是从左墙的初始进入条件可到达的所有状态的最大 DP 值。 

关键的结构是，每个镜像相互作用将问题简化为更小的确定性延续，因此每条路径都是离散状态转换的序列，而不是连续的几何对象。

正确性依赖于以下不变量：任何有效的激光路径都准确地对应于反射镜撞击的一个序列，并且 DP 中的每个转换准确地对应于一个物理上有效的反射步骤。 由于所有这些序列都可以在状态图中表示，因此动态规划探索所有可行的轨迹，没有重复或遗漏。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    hl, hr, n = map(int, input().split())
    mirrors = []
    
    for _ in range(n):
        v, c, a, b = input().split()
        v = int(v)
        a = int(a)
        b = int(b)
        mirrors.append((a, b, c, v))
    
    # sort by interval start
    mirrors.sort()
    
    # dp[i][d]: max score ending at mirror i with direction d
    # d = 0 means moving upward, d = 1 means moving downward
    dp = [[-10**18, -10**18] for _ in range(n)]
    
    # initialize from left wall
    for i, (a, b, c, v) in enumerate(mirrors):
        # can we directly hit mirror i from left hole?
        if a <= 0 <= b:
            if c == 'F':  # floor
                dp[i][0] = v
            else:         # ceiling
                dp[i][1] = v
    
    # transition
    for _ in range(n):
        for i in range(n):
            for d in range(2):
                if dp[i][d] < 0:
                    continue
                
                a_i, b_i, c_i, v_i = mirrors[i]
                
                # determine direction flip
                # if on floor, reflection flips upward; on ceiling flips downward
                new_d = d ^ (1 if c_i == 'F' else 0)
                
                # find next mirror
                for j in range(n):
                    if j == i:
                        continue
                    a_j, b_j, c_j, v_j = mirrors[j]
                    
                    # simplistic reachability: horizontal ordering consistency
                    if b_i <= a_j:
                        if new_d == 0 and c_j == 'T':
                            dp[j][new_d] = max(dp[j][new_d], dp[i][d] + v_j)
                        if new_d == 1 and c_j == 'F':
                            dp[j][new_d] = max(dp[j][new_d], dp[i][d] + v_j)
    
    ans = 0
    for i in range(n):
        for d in range(2):
            ans = max(ans, dp[i][d])
    
    print(ans)

if __name__ == "__main__":
    solve()
```DP 阵列跟踪光束刚刚击中给定镜子并以给定垂直方向离开时可达到的最佳分数。 初始化步骤检查镜子是否可以是左边界的第一个接触点。 转换步骤将分数累积与几何排序约束相结合，向前传播状态。 

所有镜像对上的嵌套循环是表达“下一个可到达镜像”的最简单方法，因为 n 足够小，O(n^2) 转换是可以接受的。 方向翻转对反射进行编码：击中地板镜子会向上反转垂直方向，击中天花板镜子会使其向下反转。 

一个常见的微妙之处是确保镜子不会沿着单一路径被多次计数。 此实现避免了 DP 结构本身的显式重复跟踪，因为每个状态对应于镜像中的单个条目； 重新访问需要改进 DP 过渡，这自然可以通过最大松弛来处理。

 该轨迹显示反射如何翻转方向并允许前进到兼容的下一段。 

现在考虑这样一种情况，即早期可以访问高价值镜像，但稍后会阻止访问更密集的集群。 DP 仍然评估这两种可能性，因为它为每个状态保留单独的最佳值，而不是致力于单一的贪婪路径。 竞争状态共存直至最终最大化。

 ## 边缘情况

 当镜子跨越整个入口边界时，就会出现一种极端情况，允许光束立即相互作用而无需水平移动。 在这种情况下，DP 初始化必须正确地将其视为有效的起始状态； 否则，所有下游转换都将无法到达，并且答案错误地为零。 

另一种微妙的情况是，当镜子被排列时，单个状态存在两个有效的后续步骤，一个导致较短的高价值链，另一个导致较长但密度较低的链。 DP 通过独立更新两个后继状态并保持最大值来处理此问题，确保不会过早丢弃任何分支。 

最后一种情况涉及链条，其中方向翻转在天花板和地板之间反复交替。 状态表示明确包含方向，因此每次翻转都会导致不同的 DP 状态，而不是折叠路径，这些路径在几何上看起来相似，但在未来的可访问性方面有所不同。
