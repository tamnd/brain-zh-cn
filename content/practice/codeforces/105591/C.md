 ## 解决方案
 ## 问题理解

 我们给定一个正整数$n$。 我们想要计算有多少个自然数的有序四元组$(a, b, c, d)$存在使得两对满足相同的总和约束$a + b = n$和$c + d = n$，所有四个数字都严格排序为$a < c < d < b$。 

所以我们可以这样想：我们选择两种不同的分解$n$分为两个积极的部分。 每个分解对应于在 1 和 1 之间选择一个分割点$n-1$。 从一次分解中，我们将较小的元素作为$a$和更大的$b$，从第二次分解中我们得到$c$和$d$，并且我们要求第二对严格位于数轴上的第一对内部。 

输入大小约束是$n \le 10^9$，这立即排除了对所有对的迭代$(a, b)$，因为有$O(n)$其中。 甚至$O(\sqrt{n})$或者$O(n \log n)$方法在这里是不必要的复杂化，因为有效对的结构很简单并且纯粹是组合。 

一个微妙的边缘情况是$n$非常小。 为了$n \le 3$，根本不存在有效的四元组，因为我们无法将四个严格递增的自然数放入固定的和结构中。 例如，当$n = 3$，唯一的分解是$(1, 2)$，因此不可能选择两个不同的对。 

另一种边缘情况是当人们试图治疗时$a, b, c, d$独立。 这会导致过多计算无效配置，因为总和约束将每个选择与互补值紧密耦合。 

## 方法

 每个有效对$(a, b)$和$a + b = n$和$a < b$是通过选择唯一确定的$a$在范围内$1 \le a < \frac{n}{2}$， 自从$b = n - a$必须大于$a$。 这已经给出了一个线性结构：所有有效对对应于点$a$在整数线上。 

现在四元条件需要两个这样的对$(a, b)$和$(c, d)$，严格排序$a < c < d < b$。 替代$b = n - a$和$d = n - c$，排序变为：$$a < c < n - c < n - a$$左右半部是对称的，不等式简化为纯粹的约束$a$和$c$：

从$c < n - c$，我们得到$2c < n$， 所以$c < \frac{n}{2}$。 

从$n - c < n - a$，我们得到$a < c$，这已经是条件的一部分。 

剩下的关键约束是这两对都是有效的分解，因此：$$1 \le a < c < \frac{n}{2}, \quad \text{and} \quad b = n - a > c$$条件$c < n - a$相当于$a + c < n$。 

所以问题归结为计算整数对$(a, c)$这样：$$1 \le a < c, \quad a + c < n, \quad c < \frac{n}{2}$$对于每个固定$c$，有效的$a$值满足：$$1 \le a < c \quad \text{and} \quad a < n - c$$所以：$$a \in [1, \min(c-1, n-c-1)]$$因此对于每个$c$，我们计算有多少个整数落在该范围内，并对所有有效的整数求和$c$。 这将问题转化为分割点上的简单算术求和$c = \frac{n}{2}$。 

蛮力方法将迭代所有$a, c$, 给予$O(n^2)$，这是不可能的$n = 10^9$。 观察到约束崩溃为分段线性边界，我们可以通过在常数时间内分裂来计算答案$c = \frac{n}{2}$。

 ## 算法演练

 我们根据每对中较小的元素重写问题。 每个有效分解对应于选择$a$， 进而$b = n - a$， 和$a < b$。 第二对的定义类似$c$和$d = n - c$。 然后我们强制排序并将所有内容转换为对$a$和$c$。 

### 步骤

 1. 计算$m = \lfloor \frac{n}{2} \rfloor$。 这是任何有效对中较小元素的最大可能值。 任何$a$或者$c$必须位于$[1, m]$。 
2.修复较大的元素阈值$n - c$并观察对于每个$c$， 有效的$a$值是严格小于两者的值$c$和$n - c$。 这确保了排序和求和的可行性。 
3. 对于每个$c \in [1, m]$，计算有效的数量$a$作为$\min(c - 1, n - c - 1)$。 减 1 可确保严格的不平等。 
4. 分割范围$c$取决于是否$c \le n - c$或不。 切换发生在$c = \frac{n}{2}$。 
5. 在第一段中，$c \le \frac{n}{2}$，限制因素是$c - 1$，因此贡献呈线性增长。 
6. 在第二段中，$c > \frac{n}{2}$，限制因素变为$n - c - 1$，产生对称递减序列。 
7. 使用封闭式公式而不是迭代对两个算术序列求和。 

### 为什么它有效

 每个有效的四元组恰好对应一对$(a, c)$满足导出的不等式，并且每一对都唯一地确定$b$和$d$。 转换保留所有约束，而不会引入重复项。 分段分割捕获了瓶颈所在的确切点$\min(c-1, n-c-1)$变化，因此对两个算术级数求和会将每个有效配置恰好计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

m = n // 2

ans = 0

for c in range(1, m + 1):
    ans += min(c - 1, n - c - 1)

print(ans)
```实现遵循直接约简：对于每个有效的第二对较低元素$c$，我们计算有多少种选择$a$保持有效。 循环的编写方式很简单，可以直接反映导出的约束。 

关键的微妙之处在于表达`min(c - 1, n - c - 1)`。 期限`c - 1`强制执行$a < c$， 尽管`n - c - 1`强制执行$a < n - c$，确保$a + c < n$。 缺少任何一个界限都会导致无效四元组的计数过多，其中第二对不能严格适合第一对。

 ## 边缘情况

 对于$n = 1$，没有有效的对$(a, b)$，所以不存在四元组。 算法集$m = 0$，循环永远不会运行，并正确返回 0。 

为了$n = 4$，唯一的一对是$(1,3)$，因此不可能选择两个不同的嵌套对。 循环结束$c$产生零有效贡献，因为$c - 1$在有效范围内始终为 0 或负数。 

为了$n = 5$, 有两对$(1,4), (2,3)$，并且可以精确地嵌套一个。 当以下情况时，循环正确地计算单个有效选择：$c = 2$，其中两个约束$a < c$和$a + c < n$同时变紧。
