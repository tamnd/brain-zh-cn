 ## 解决方案
 ## 问题理解

 问我们是否可以形成一个边长为三个连续自然数且周长等于给定值的三角形$p$。 

此设置中的有效三角形完全由起始整数确定$a$。 那么双方必须是$a$,$a+1$， 和$a+2$。 周长约束固定了它们的总和，所以我们实际上是在检查是否存在一个整数$a \ge 1$这样$$a + (a+1) + (a+2) = p.$$同时，这三个值必须满足三角不等式，这意味着最大的边必须严格小于其他两个的总和。 

输入是单个整数$p$，并且输出是二进制的：如果至少存在一个这样的三元组，则打印 1，否则打印 0。 

尽管这个问题看起来是几何问题，但它完全分解为算术结构。 主要约束不是几何形状，而是简单线性系统是否具有也遵循正性和三角不等式的整数解。 

范围$1 \le p \le 10^9$立即排除任何尝试所有连续整数三元组的尝试。 虽然$a$最多是关于$p/3$，迭代至$10^9$在 1 秒的限制下是不可能的。 该解决方案必须将搜索时间减少到恒定。 

当周长非常小时，会出现微妙的边缘情况。 例如，$p = 1$或者$p = 2$根本不能形成任何三角形，但即使是稍大的值，例如$p = 4$或者$p = 5$也失败，因为最小的连续三元组是$1,2,3$，其周长已经是 6。另一种失败模式是忘记三角不等式，尽管对于连续整数，一旦正性成立，它就会自动满足。 

## 方法

 直接方法会尝试所有可能的起始值$a$，计算三元组$(a, a+1, a+2)$，检查总和是否等于$p$，并验证三角不等式。 这是正确的，但效率低下。 总和条件单独作用力$3a + 3 = p$，所以实际上只有一个候选者$a$对于每个$p$，但天真的方法仍然会在概念上迭代$O(p)$的可能值$a$。 和$p$最多$10^9$，这远远超出了可行的限度。 

关键的观察是侧面的结构完全决定了周长。 一旦我们假设连续的整数，就没有组合选择了。 周长方程修正$a$独特地：$$a = \frac{p - 3}{3}.$$因此，整个问题简化为检查该值是否为整数以及是否至少为 1。三角不等式不会添加新的约束，因为对于任何正数$a$,$$a + (a+1) > a+2$$自动保持。 

因此，问题变成了可分性和下界检查。

 ## 算法演练

 1. 计算$p - 3$。 这对应于消除连续结构中固定偏移的恒定贡献。 
2. 检查是否$p - 3$能被3整除。如果不能，则不是整数$a$存在，因此无法形成有效的三角形。 
3. 如果可整除，计算$a = (p - 3) / 3$。 这是最小边的唯一可能的候选者。 
4. 验证$a \ge 1$。 这可确保边是从 1 或更大的有效自然数。 
5. 如果两个条件都成立，则输出1； 否则输出0。 

该逻辑依赖于这样一个事实：每个有效三角形必须恰好对应于一个长度为 3 的算术级数，因此无需搜索。 

### 为什么它有效

 任何有效的配置都必须采用以下形式$(a, a+1, a+2)$。 周长方程迫使一个独特的$a$。 由于没有选择立场的自由，存在的问题就归结为这种强迫是否存在。$a$位于自然数的有效域内。 三角不等式没有添加额外的限制，因为连续整数总是满足一次$a \ge 1$。 这使得算术条件既是充分必要的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

p = int(input())

# Solve 3a + 3 = p
if (p - 3) % 3 != 0:
    print(0)
else:
    a = (p - 3) // 3
    if a >= 1:
        print(1)
    else:
        print(0)
```该代码直接对导出的方程进行编码。 表达式$3a + 3 = p$来自三个连续整数的总和。 模检查确保完整性$a$。 第二个检查强制序列从至少为 1 的自然数开始，因为该问题需要正整数边长。 

一个常见的陷阱是忘记检查$a \ge 1$，这会错误地接受类似的情况$p = 3$，生产$a = 0$，这是无效的。

这表明大多数值$p$立即被模块化条件拒绝。

 ## 边缘情况

 小周长，例如$p = 6$产生$a = 1$，给出最小三角形$1,2,3$。 该算法计算$(6 - 3) = 3$，可被 3 整除，得到$a = 1$，所以它正确接受。 

为了$p = 5$，计算得出$p - 3 = 2$，它不能被 3 整除。算法立即拒绝它，这与三个连续正整数之和不能等于 5 的事实相匹配。 

对于$p = 3$，我们得到$p - 3 = 0$，可被 3 整除，得到$a = 0$。 最后检查$a \ge 1$拒绝它，防止产生具有非正边的无效三角形。
