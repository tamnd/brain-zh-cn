 ## 解决方案
 ## 问题理解

 我们给出了平面上的一系列点，然后我们查看连续点之间的位移向量。 每个这样的向量捕获我们如何从一个点移动到下一个点。 

任务是选择一个由两个垂直方向组成的新坐标系，称为Ox和Oy，使得每个位移矢量在这个新坐标系中表达时，都位于该坐标系的“右上”方向。 具体来说，每个向量在新基中必须有一个非负的 x 坐标，如果它的 x 坐标为零，那么它的 y 坐标必须严格为正。 

从几何角度来看，这意味着我们尝试旋转和定向轴，以便所有向量都位于以 Ox 为界的单个封闭半平面中，并且没有一个向量落入负 x 侧。 精确落在边界线上的向量必须始终指向正 Oy 方向，而不是向后或平坦。 

每个向量可以被视为单位圆上有方向的点。 该条件本质上是询问是否存在一个方向 Ox，使得所有向量与 Ox 形成至多 90 度的角度，并且那些完全正交的向量在投影到 Oy 上时符号一致。 

从复杂性的角度来看，最多可以有 100000 个点，因此最多有 100000 个方向向量。 任何比较所有向量对或尝试测试所有候选坐标系的解决方案都将是二次的并且速度太慢。 该结构必须从全局几何属性中提取，而不是进行详尽的检查。 

当矢量分布超过半圆时，就会出现微妙的失败情况。 例如，如果我们的方向大致同时指向右、左和下，则任何轴的旋转都无法将它们全部放入一个封闭的半平面中，因此任何假设可行性而不验证的算法都会错误地输出基础。 

当向量几乎共线但其中一个稍微位于边界的另一侧时，就会出现另一种棘手的情况。 如果不强制执行一致性检查，天真的“选择任何极端方向”策略可能会选择无效的边界向量并构造无效的坐标系。 

## 方法

 强力解释是尝试所有可能的方向作为候选 Ox 轴。 对于每个候选向量，我们将旋转坐标系并检查投影后所有向量是否满足所需的符号条件。 即使我们仅将候选方向离散化为输入向量，这仍然会导致根据 O(n) 个向量检查每个 O(n) 个候选方向，从而导致 O(n²) 操作，这对于 100000 个向量来说太慢了。 

关键的观察是我们实际上不需要测试所有方向。 如果存在有效轴，则所有向量必须位于某个半圆内。 这将问题从“找到满足约束的方向”简化为“找到所有向量的最小外接半圆的边界方向”。 

一旦我们接受所有向量都位于半平面上，那么在该集合的边界上就有一个自然的极值向量。 可以使用线性扫描和叉积比较来找到该向量，其行为类似于根据方向选择最顺时针或逆时针方向。 这为我们提供了边界方向的规范候选者。 

一旦找到这样的边界向量 Dm，就可以安全地将 Oy 与其对齐。 推理是，如果所有向量都位于半圆内，则一个极端方向可以作为边界，并将 Oy 沿其放置可确保在选择与 Ox 正交的 Ox 后，所有其他向量非负投影到 Ox 上。 

问题的其余部分简化为验证这个构造的基础是否满足每个向量的约束。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们直接使用位移矢量 Di。 

1. 首先选择第一个向量作为临时候选 Dm。 这代表了一个暂定的边界方向，我们将其细化为真正的极值向量。 
2. 扫描所有向量，并在发现角度顺序更极端的向量时更新 Dm。 这是使用叉积条件 (Dm × Di) > 0 进行测试的，这意味着 Di 在定向角度顺序中位于 Dm 的左侧，因此它成为新的边界候选。 这就保证了扫描后Dm是集合的一致极值方向。 
3. 将 Dm 视为定义 Oy 轴方向。 这种选择是安全的，因为如果所有向量都适合半圆，则该集合的极值向量位于该半圆的边界上。 
4. 将 Ox 构造为与 Dm 垂直的向量。 如果 Dm = (a, b)，则我们取 Ox = (b, -a)。 这保证了正交性，因为它们的点积为零。 
5. 通过固定 Ox 的符号以使 (Dm × Ox) < 0 确保方向一致性。这会选择一致的顺时针方向，防止边界哪一侧被视为正 x 的歧义。 
6. 验证每个向量 Di 满足 (Di · Ox) ≥ 0。如果等式成立，请确保 (Di · Dm) > 0，以便边界向量严格指向正 Oy 方向，而不是向后或平坦。 
7. 如果任何向量违反这些条件，则不存在有效的坐标系。 

正确性依赖于这样一个事实：如果存在有效的基，则所有向量都位于半圆内。 该算法将该半圆的一个端点重建为 Dm，然后构建与其对齐的正交轴系。 每个向量必须位于垂直于 Ox 的线的同一侧； 否则，就违反了原来的半圆假设。 叉积扫描保证 Dm 是一个极端边界方向，因此不会遗漏任何有效配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    # build difference vectors
    d = []
    for i in range(n - 1):
        x1, y1 = pts[i]
        x2, y2 = pts[i + 1]
        d.append((x2 - x1, y2 - y1))

    # pick extreme vector using cross product ordering
    dx, dy = d[0]
    for x, y in d[1:]:
        if dx * y - dy * x > 0:
            dx, dy = x, y

    # Oy = Dm, Ox = perpendicular
    ox_x, ox_y = dy, -dx
    oy_x, oy_y = dx, dy

    # check validity
    for x, y in d:
        dot = x * ox_x + y * ox_y
        if dot < 0:
            print("No solution")
            return
        if dot == 0:
            if x * oy_x + y * oy_y <= 0:
                print("No solution")
                return

    print("Yes")

if __name__ == "__main__":
    solve()
```该实现首先构造差异向量，因为问题简化为推理连续点之间的方向。 极值向量选择使用具有叉积的线性扫描，这是按角度顺序维护边界方向的标准方法。 

垂直向量是通过交换坐标并求反一个分量来构建的，以确保正交性。 最后的验证步骤直接检查两个约束：Ox 上的非负投影和位于边界上时沿 Oy 的严格正投影。 

在平等的情况下必须小心。 恰好位于边界线上的向量（点积为零）必须仍然具有沿 Oy 的正投影，否则它将与所需的严格排序相矛盾。

 输入点：

 (0,0), (1,0), (2,1)

 (1,0), (1,1)

 我们跟踪极值选择：

 最终Dm = (1,1)，因此Oy 为(1,1)，Ox 为(1,-1)。 

检查投影确认两个向量位于正确的一侧。 

现在考虑向量已经对齐的情况：

 输入：

 (0,0), (2,0), (4,0)

 载体：

 (2,0), (2,0)

 | 步骤| 当前DM | 下一个矢量| 叉积| 更新 |
 | --- | --- | --- | --- | --- |
 | 1 | (2,0) | (2,0) | 0 | 没有 |
 | 2 | (2,0) | 结束 | - | - |

 这里 Ox 变为 (0,-2)，并且两个向量恰好位于边界方向上。 次要条件强制沿 Oy 严格为正，该条件成立，因为两个向量相同且指向前方。

 ## 边缘情况

 一个关键的情况是向量跨越超过半圆的情况。 例如，如果一个向量指向右，另一个向量指向左上，另一个向量指向左下，则 Ox 的任何选择都会将至少一个向量放入负半平面。 该算法间接检测到这一点，因为在验证期间没有单个极值 Dm 可以为所有向量生成非负点积。 

另一种边缘情况是多个向量与所选边界向量完全共线。 在这种情况下，多个向量的点积变为零，并且正确性完全取决于使用投影到 Oy 上的二次检查。 该算法通过在满足边界条件时明确要求沿 Oy 的严格正性来处理此问题，从而防止向后共线向量的退化接受。
