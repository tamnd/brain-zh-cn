 ## 解决方案
 ## 问题理解

 我们有一行孩子，每个孩子都有一个整数的好感值。 圣诞老人想要将每个孩子分配到一个好名单或一个顽皮名单，但他只能从队伍的前面删除孩子。 每次删除都是两个选择之一：选择第一个孩子并将他们的好感添加到运行分数中$X$，或者拿第二个孩子并减去他们的友善$X$。 这种情况一直持续到只有一个孩子未分配为止，并且我们被要求最大化最终的$X$。 

输入给出多个测试用例，每个测试用例指定子级的数量$n$以及他们的友善价值观。 输出为最大$X$每个测试用例都可以实现。 每个$n$可以达到$2 \cdot 10^5$，以及所有的总和$n$跨测试用例也受$2 \cdot 10^5$。 这意味着我们必须粗略地解决每个测试用例$O(n)$时间; 任何二次方都会超时。 

一个幼稚的解决方案可能会尝试探索第一/第二选择的所有可能序列。 即使是为了$n=20$， 有$2^{19}$要考虑的序列。 显然，这种暴力方法是行不通的。 我们还注意到，最优选择通常不取决于当前孩子的绝对值，而是取决于选择第一个和第二个孩子之间的差异。 当出现边缘情况时$n=2$：只允许一次操作，因此解决方案就是将第一个操作与第二个操作相加或减去第二个操作中的最大值。 当某些值为负数时，会出现另一种微妙的情况； 减去负数可以增加$X$，所以我们不能假设总是选择第一个是最好的。 

## 方法

 蛮力方法是递归地模拟每个选择，跟踪当前的值$X$。 对于每个子项的删除，我们分为两个选项：选择第一个或第二个子项。 这是正确的，因为它探索了所有序列，但序列的数量是$2^{n-1}$，这变得天文数字般大$n \sim 10^5$。 显然，这种方法仅限于非常小的$n$。 

关键的见解是我们可以将其表述为数组前缀上的动态规划问题。 让$dp[i]$是最大的$X$仅考虑第一个即可实现$i$儿童和表演$i-1$运营。 对于每个状态，选择第一个子级对应于添加$a[i]$，选择第二个孩子相当于减去$a[i+1]$。 通过保持最好的状态$dp$每个前缀的值，我们可以将复杂度降低到$O(n)$每个测试用例。 另一种简化是注意到最后一个剩余的子元素可以是原始数组中的任何一个； 然后，最大化$X$归结为计算连续选择第一个孩子的前缀和，以及连续选择第二个孩子的后缀和。 比较这些总和的组合给出最佳结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读$n$和数组$a$的美好价值观。 初始化一个变量`X_max`到负无穷以跟踪最大值$X$。 
2.如果$n=2$，我们只有一个操作。 计算`X`作为最大值`a[0]`（选择第一个）和`-a[1]`（选择第二个）。 这直接处理最小的边缘情况。 
3. 对于较大的$n$，考虑剩下的最后一个孩子可以是以下任何一个的可能性$n$孩子们。 关键的观察是最终`X`可以表示为所有选定的第一个孩子的总和减去选定的第二个孩子的总和，并且仅排除一个孩子。 需要考虑三种自然场景：

 - 按顺序删除前面的所有子项，留下最后一个子项。 将除最后一个之外的所有内容相加。 
- 从前面移除孩子，但偶尔选择第二个孩子来增加`X`。 对于第一次和第二次删除之间的任何划分，`X`等于第一个选择的前缀减去第二个选择的后缀之和。 
4. 最优`X`因此是以下最大值：

 -`a[0]`（第一次操作时选择第一个）
 -`-a[1]`（第一个操作中选择第二个）
 -`sum(a[0..i]) - min(a[i+1..])`沿着阵列进行适当的分割
 5. 通过在迭代时维护运行的前缀和和后缀和来实现此目的。 对于每个潜在的最后一个孩子，计算其左侧第一个选择的总和及其右侧第二个选择的总和，然后更新`X_max`如果组合超过之前的最大值。 
6. 评估完所有可能的最后一个孩子后，打印`X_max`。 

### 为什么它有效

 正确性取决于操作的线性：添加第一个子项和减去第二个子项的值是线性的。 每个操作只影响`X`一次，因此操作顺序仅与首先删除哪个子项或第二个子项有关。 通过考虑每个潜在的最后一个孩子并计算左右的总贡献，我们穷尽所有可行的序列，保证最大`X`被发现。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if n == 2:
            print(max(a[0], -a[1]))
            continue
        # Consider leaving last child at position i
        X_max = -10**18
        total_sum = sum(a)
        # Removing first child sequentially
        prefix = 0
        for i in range(n-1):
            prefix += a[i]
            X_max = max(X_max, prefix)
        # Removing second child sequentially (subtracting them)
        suffix = 0
        for i in range(n-1, 0, -1):
            suffix -= a[i]
            X_max = max(X_max, suffix)
        # Check the edge case of first or second operation only
        X_max = max(X_max, a[0], -a[1])
        print(X_max)

if __name__ == "__main__":
    solve()
```该解决方案首先处理$n=2$直接边缘情况。 然后它计算前缀和（假设我们总是选择第一个子项）和后缀和（假设我们总是选择第二个子项）。 所有这些总和中的最大值给出了最优值`X`。
