 ## 解决方案
 ## 问题理解

 给定一个单位立方体的两个顶点。 每个顶点由三个坐标描述，每个坐标是`0`或者`1`。 由于每个坐标只能取两个值，因此这些坐标代表立方体的八个角。 

两只苍蝇站在两个不同的顶点。 如果两个顶点都属于立方体的至少一个公共面，则它们可以看到对方。 任务是打印`"YES"`当存在这样的面时，否则打印`"NO"`。 

输入尺寸很小。 我们总共只读取六个整数，因此性能在这里无关紧要。 即使对所有立方体面进行强力几何检查也会立即运行。 挑战在于识别隐藏在坐标中的几何属性。 

关键的观察是立方体面如何用坐标表示。 每一张脸都精确地固定一个坐标。 例如，脸`x = 0`包含第一个坐标为的所有顶点`0`。 如果两个顶点在同一位置至少共享一个坐标值，则它们位于同一个面上。 

有几个容易被忽视的案例。 

考虑相反的顶点：```
0 0 0
1 1 1
```正确答案是`"NO"`。 这些顶点不共享任何面，因为每个坐标都不同。 仅检查欧几里得距离或边缘连通性的粗心方法可能会失败。 

现在考虑仅在面上对角连接的顶点：```
0 0 0
0 1 1
```正确答案是`"YES"`。 这些顶点不与边相邻，但它们仍然属于面`x = 0`。 错误的解决方案可能会假设只有相邻的顶点才能看到彼此。 

另一种微妙的情况是当一个坐标恰好匹配时：```
1 0 1
1 1 0
```答案依然是`"YES"`因为两个点都属于面`x = 1`。 

## 方法

 强力解决方案将显式地对立方体的六个面进行建模。 每个面包含四个顶点。 我们可以生成所有立方体顶点，按面对它们进行分组，然后检查两个给定顶点是否一起出现在任何面中。 

这种方法是正确的，因为可见性的定义正是“共享一张脸”。 立方体只有六个面，因此即使是字面模拟也需要恒定的时间。 

一旦我们使用坐标来描述面，几何形状就会变得简单得多。 每个立方体面固定一个坐标：```
x = 0
x = 1
y = 0
y = 1
z = 0
z = 1
```当至少一个坐标在同一位置匹配时，两个顶点正好位于同一个面上。 如果第一个坐标相等，则两个顶点属于其中一个`x = 0`或者`x = 1`。 同样的逻辑适用于`y`和`z`。 

这将从实现中删除所有几何图形。 我们只需要两两比较坐标即可。

 ## 算法演练

 1.将第一个顶点的坐标读入`(x1, y1, z1)`。 
2.将第二个顶点的坐标读入`(x2, y2, z2)`。 
3. 比较对应的坐标。 

如果`x1 == x2`，两个顶点位于同一点上`x`脸。 

如果`y1 == y2`，两个顶点位于同一点上`y`脸。 

如果`z1 == z2`，两个顶点位于同一点上`z`脸。 
4. 如果至少有一个比较匹配，则打印`"YES"`。 
5. 否则打印`"NO"`。 

### 为什么它有效

 立方体的每个面都是通过固定一个坐标来定义的。 例如，面上的所有顶点`z = 1`第三个坐标等于`1`。 

如果两个顶点在同一位置共享任意坐标值，则它们都属于相应的面。 相反，如果所有三个坐标都不同，则一个顶点与另一个顶点位于立方体的对角处，并且没有面包含这两个点。 

该算法正是检查这个条件，因此它既是必要的也是充分的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

x1, y1, z1 = map(int, input().split())
x2, y2, z2 = map(int, input().split())

if x1 == x2 or y1 == y2 or z1 == z2:
    print("YES")
else:
    print("NO")
```该程序读取两个三元组坐标并独立比较每个坐标。 

条件使用逻辑`or`因为即使共享一个坐标也足以将两个顶点放置在一个公共面上。 

一个常见的错误是需要两个匹配的坐标。 这只会检测到由边连接的顶点，并且会错误地拒绝面对角线，例如`(0,0,0)`和`(0,1,1)`。 

另一个可能的错误是通过曼哈顿距离检查邻接性。 可见性比邻接性更广泛，因此该方法会错过有效案例。

import sys, io

def solve():
    input = sys.stdin.readline

    x1, y1, z1 = map(int, input().split())

 ## 边缘情况

 考虑相反的顶点：```
0 0 0
1 1 1
```该算法将坐标一一比较：```
0 == 1 → false
0 == 1 → false
0 == 1 → false
```没有坐标匹配，因此程序打印`"NO"`。 这正确地表明对角永远不会共用一个面。 

现在考虑面对角线：```
0 0 0
0 1 1
```第一个坐标匹配：```
0 == 0 → true
```该算法立即知道两个顶点都属于该面`x = 0`，所以它打印`"YES"`。 

最后，考虑一种只有一个共享坐标的情况：```
1 0 1
1 1 0
```对比结果为：```
1 == 1 → true
0 == 1 → false
1 == 0 → false
```至少有一个坐标匹配，这足以保证可见性。 输出是`"YES"`。 

这些案例说明了为什么“至少一个相等的坐标”这一条件与立方体面的几何形状完全匹配。
