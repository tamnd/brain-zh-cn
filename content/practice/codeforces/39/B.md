 ## 解决方案
 ## 问题理解

 我们得到一个整数序列，代表一家公司从 2001 年开始的年收入。第一个数字是 2001 年的收入，第二个数字是 2002 年的收入，依此类推。 如果公司当年亏损，这些值可能为负。 Petya想要呈现一个“完美”的增长场景，其中收入每年线性增长10亿：第一年10亿，第二年20亿，第三年30亿，以此类推。 由于实际收入可能不会遵循这个完美的模式，因此他希望提取收入按顺序与 1、2、3、... 完全匹配的年份序列。 

我们的目标是选择最长的子序列。 然后我们输出它的长度和相应的年份（2000 +年份索引）。 

输入约束很小：`n`最多为 100。这意味着具有 O(n^2) 次操作的算法是可行的，因为在 2 秒限制下，即使是 10,000 次操作对于现代处理器来说也是微不足道的。 收入可能为负，因此在第一次不匹配时停止的幼稚方法将会失败。 我们还需要处理没有哪一年能够达到完美增长的可能性，在这种情况下答案为 0。 

非明显的边缘情况包括同一目标值存在多个匹配年份的序列。 例如，在`[1, 1, 2, 2, 3]`，完美的序列可以采用第一个 1 或第二个 1。另一种边缘情况是所有数字均为负数，例如，`[-1, -2, -3]`，产生 0 的输出。粗心的方法可能会返回指数而不检查实际值与预期的完美增长。 

## 方法

 蛮力方法是尝试收入数组的每个子序列，检查其元素是否形成完美增长。 由于长度为 k 的子序列的数量是组合的，因此总操作计数呈指数增长，大约为 O(2^n)。 为了`n = 100`，这是完全不可行的。 

关键的见解是，这个问题相当于找到与给定递增序列匹配的最长子序列`1, 2, 3, …`。 这正是最长递增子序列 (LIS) 问题的变体，但每个元素必须匹配特定的预期值，而不是任意比较。 因为`n`很小，动态规划方法可以有效地工作。 

我们迭代数组，同时维护 DP 数组，其中`dp[i]`是在位置结束的最长完美序列的长度`i`。 对于每个位置，我们检查所有先前的位置，看看是否可以扩展序列。 这将问题从指数减少到 O(n^2)，在给定约束的情况下这是可以接受的。 我们还存储了一个`prev`数组来重建实际的年份序列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 动态规划| O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`dp`长度`n`带零。`dp[i]`将存储以索引结尾的最长完美子序列的长度`i`。 
2.初始化一个数组`prev`长度`n`和`-1`存储序列中的前一个索引以进行重建。 
3. 使用索引循环数组`i`从 0 到 n-1。 对于每个元素`a[i]`，以完美序列计算其目标值：`dp[i] + 1`。 如果`a[i]`等于`dp[i] + 1`它可以扩展任何先前的子序列，更新`dp[i]`到`dp[j] + 1`对于某些人来说`j < i`在哪里`dp[j]`最大化，并记录`prev[i] = j`。 如果没有先前的元素可以扩展它，则设置`dp[i] = 1`。 
4. 灌装后`dp`，找到索引`max_index`与最大的`dp[max_index]`。 这给出了最长完美序列的长度。 
5. 按照以下顺序重建序列`prev`数组来自`max_index`向后。 通过添加 2001 将每个数组索引转换为实际年份。 
6. 打印序列的长度和重建的年份。 如果没有元素与完美增长相匹配，则输出 0。 

为什么它有效：在每一步，`dp[i]`准确地表示最长的完美序列结束于`i`因为它只考虑有效的扩展。 这`prev`数组确保我们可以按顺序重建子序列。 该算法系统地考虑了在每个位置结束完美序列的所有可能性，因此它不会错过最长的一个。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

dp = [0] * n
prev = [-1] * n

for i in range(n):
    if a[i] == 1:
        dp[i] = 1
    for j in range(i):
        if dp[j] > 0 and a[i] == dp[j] + 1:
            if dp[j] + 1 > dp[i]:
                dp[i] = dp[j] + 1
                prev[i] = j

# Find the index of the maximum length
max_len = 0
max_index = -1
for i in range(n):
    if dp[i] > max_len:
        max_len = dp[i]
        max_index = i

if max_len == 0:
    print(0)
else:
    sequence = []
    idx = max_index
    while idx != -1:
        sequence.append(2001 + idx)
        idx = prev[idx]
    sequence.reverse()
    print(max_len)
    print(*sequence)
```我们首先初始化`dp`和`prev`跟踪最长的序列及其重建路径。 我们循环每一对`(j, i)`和`j < i`检查我们是否可以扩展序列。 这就是谨慎处理预期完美增长至关重要的地方。 没有`a[i] == dp[j] + 1`，子序列将无效。 最终重建使用`prev`向后构建序列，然后按时间顺序反转它。
