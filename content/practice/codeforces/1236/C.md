 ## 解决方案
 ## 问题理解

 我们得到从 1 到$n^2$，每个代表一个按高度定位的实验室，其中较小的数字较低，较大的数字较高。 每对实验室之间都有一个定向管道，允许一个单位的流量从编号较高的实验室流向编号较低的实验室。 所以每一对订购的$(u, v)$贡献一单位的可能流量，如果$u > v$。 

我们必须对这些进行分区$n^2$实验室进入$n$组，每个组恰好包含$n$标签。 任意两组之间$A$和$B$，我们定义$f(A, B)$作为有序对的数量$(u, v)$这样$u \in A$,$v \in B$， 和$u > v$。 这只是计算有多少“向下边缘”来自组$A$分组$B$。 

目标是选择分区使得最小的值$f(A, B)$所有不同的组对都尽可能大。 换句话说，我们希望尽可能均匀地平衡所有组与组之间的向下连接，避免出现任何弱组对。 

输入约束$n \le 300$意味着直到$90{,}000$元素。 任何试图评估所有分区的解决方案都是不可能的，因为分区的数量呈超指数增长。 即使简单地检查单个分区也会产生成本$O(n^4)$如果在组和元素上成对完成，这太慢了$n=300$。 

贪婪直觉的一个常见失败案例是将连续的数字组合在一起。 例如，将$\{1,2,3\}$,$\{4,5,6\}$,$\{7,8,9\}$什么时候$n=3$造成极其不平衡的流动：所有从大到小的相互作用都集中在几个方向，而其他方向则很弱。 这违反了最大化最小组间流量的目标。 

另一个陷阱是随机分组或行主分配，它倾向于对可比较的值进行聚类，并减少一个方向上的跨组反转，但在相反方向上不对称，再次降低最小值$f(A,B)$。 

关键的难点在于$f(A,B)$仅取决于值的相对顺序，而不取决于它们的绝对值，这表明结构化排列而不是任意分组。 

## 方法

 暴力方法会尝试所有的分裂方法$n^2$数入$n$大小组$n$，然后计算$f(A,B)$对于每对组。 即使我们只有一个分区，计算所有$f(A,B)$价值成本$O(n^3)$，因为每对组都需要比较$n^2$元素对。 分区的数量使得这完全不可行。 

结构洞察力是解释数字$n \times n$网格并沿对角线分配组。 目标是确保对于任何两个群体，在两个方向上都存在一致且足够多的“从大到小”的关系。 一个好的结构是以循环对角线模式填充网格，以便每个组分布在不同的值范围内。 

该问题中使用的标准结构是将数字逐列放置在矩阵中，每列交替方向。 这确保了每行和每列的交互都是平衡的，并且没有组集中在单一值范围内。 

这种交替的锯齿形柱结构保证了对于任何一对群，在两个方向上都有足够的反转，并且最小$f(A,B)$被最大化。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| O(n²) | 太慢了 |
 | 柱之字形结构 | O(n²) | O(n²) | 已接受 |

 ## 算法演练

 我们构造一个$n \times n$网格，然后将其作为组逐行读取。 

1. 创建一个空的$n \times n$矩阵。 我们将用从 1 到 的数字填充它$n^2$以结构化的方式，使每一行成为一个组。 

该结构确保每一行包含来自不同结构“级别”的数字。 
2. 使用从 1 开始的计数器逐列填充矩阵。 

对于每一列$c$，我们将数字从上到下或从下到上放置，具体取决于是否$c$是偶数还是奇数。 

这种交替方向确保相邻列在各​​行中以不同的方式分布大值和小值，从而防止任何行只偏向大值或只偏向小值。 
3. 填充矩阵后，将每一行视为一组。 

现在每一行都包含$n$不同的值，以及从 1 到$n^2$只使用一次。 
4. 将每一行作为一组输出。 

### 为什么它有效

 交替列填充可确保对于任何固定行，其元素以受控模式分布在高值区域和低值区域。 任意两行至少有一半的列在排序方向上不同，这保证了它们之间稳定的反转数量。 这可以防止任何一对群体的规模异常小$f(A,B)$，因为在太多列中，两个组都没有始终高于或低于另一个组。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

grid = [[0] * n for _ in range(n)]
num = 1

for col in range(n):
    if col % 2 == 0:
        for row in range(n):
            grid[row][col] = num
            num += 1
    else:
        for row in range(n - 1, -1, -1):
            grid[row][col] = num
            num += 1

for row in grid:
    print(*row)
```该结构按列优先顺序填充矩阵，每列方向交替。 这确保了值不会沿行或列单调递增，这是平衡跨组比较的核心要求。 

每行都作为一个组打印，并且由于每个值仅使用一次，因此我们获得了一个有效的分区。 

一个常见的实施错误是交替行而不是列，这会破坏对称性并产生不均匀的分布。 另一个错误是忘记了小组必须在完成分配后而不是在施工期间组建。

## 测试用例```python
import sys, io

def solve():
    n = int(input())
    grid = [[0] * n for _ in range(n)]
    num = 1
    for col in range(n):
        if col % 2 == 0:
            for row in range(n):
                grid[row][col] = num
                num += 1
        else:
            for row in range(n - 1, -1, -1):
                grid[row][col] = num
                num += 1
    for row in grid:
        print(*row)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    out = io.StringIO()
    with redirect_stdout(out):
        solve()
    return out.getvalue().strip()

# samples
assert run("3\n") != "", "sample 1 basic sanity"

# custom cases

 ## 边缘情况

 对于$n=2$，网格变为：```
1 4
2 3
```第 0 行是$\{1,4\}$，第 1 行是$\{2,3\}$。 该结构仍然确保两组之间的两个方向具有平衡的反转，因为最大元素 4 和最小元素 1 是分开的，而中间值交叉两个方向。 

对于较大的$n$，交替的列方向确保没有行累积一致的大或小数字。 偶数列将从低到高的顺序向下推，而奇数列则将其反转，从而保证任意两行在至少一半的列上的反转结构不同。
