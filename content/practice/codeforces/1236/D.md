 ## 解决方案
 ## 问题理解

 我们有一个矩形网格，其中有一些被阻挡的单元格。 从左上角开始，令牌必须穿过网格，以便每个未阻塞的单元格都被访问一次。 移动受到高度限制：令牌始终具有当前方向，它在该方向上向前移动一步，并且在每个单元格允许其方向向右旋转一次，但每个单元格（包括起始单元格）只能旋转一次。 在单元格中右转后，它会继续向新方向移动，并且以后无法再在那里转向。 

这四个方向形成一个固定的循环：右、下、左、上。 因此，该运动是在网格上行走，其中每个单元最多可以充当一次转折点，并且该行走必须是自由单元上的哈密顿路径。 

每个维度的网格尺寸最大可达10^5，障碍物数量最多为10^5。 这立即排除了任何显式模拟遍历所有单元格或构建完整网格表示的方法。 任何正确的解决方案都必须依赖于对障碍物引起的结构的推理，而不是遍历。 

一个关键的微妙之处在于，步行不仅仅是一条只有一个转弯的单调路径。 令牌可以多次在水平和垂直移动之间交替，但前提是这些方向变化发生在不同的单元格中。 这使得天真的贪婪模拟具有误导性。 

当障碍物迫使狭窄的走廊出现多次之字形时，就会出现第一个失败案例。 即使在有效的配置中，始终笔直进行直到被阻止然后贪婪地转向的模拟也可能会陷入困境。 

当障碍物稀疏但创建孤立的单单元格“口袋”时，会发生第二种微妙的情况，这些“口袋”迫使以违反每单元一圈规则的方式重新访问行或列。 这些从局部移动规则中并不明显，需要对行和列中的交叉奇偶性进行全局推理。 

## 方法

 强力解释将模拟所有可能的有效行走，在每一步尝试是向前移动还是向右转，同时确保没有单元格被访问两次。 这有效地搜索了一个有向状态空间，其大小与空闲单元的数量乘以四个方向成正比。 即使修剪掉无效的重访，搜索空间仍保持指数形式，因为每个单元格都可以是转折点，也可以不是转折点，并且访问单元格的顺序很重要。 对于多达 10^5 个空闲单元，这种方法是不可能的。 

关键的观察结果是，运动约束对任何有效的完全遍历施加了非常严格的结构。 由于每个单元只能使用一次并且转弯受到限制，因此该路径的行为就像在水平和垂直扫描之间交替的一系列单调片段。 每个这样的段必须遍历行或列中的整个连续间隔，否则某些单元格将在不违反转弯约束的情况下变得无法到达。 

这将问题从推理各个步骤减少为推理行和列中的无障碍间隔如何连接。 路径被迫蜿蜒穿过网格，唯一的自由度是蛇改变方向的顺序，这完全由阻塞单元的边界结构决定。 

这将问题转化为检查由障碍物引起的隐式走廊结构是否形成从 (1,1) 开始的单个连接的蛇形遍历，该遍历恰好覆盖所有空闲单元一次，而不需要重新访问或非法转弯。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| O(纳米) | 太慢了 |
 | 结构区间模拟 | O(k log k) | O(k log k) | O(k) | 已接受 |

 ## 算法演练

我们将网格重新构建为由障碍物确定的交替的水平和垂直强制分段。 路径始终沿直线移动，直到由于边界或阻碍前进的障碍物而被迫转向。 

1. 将障碍物存储在按行和按列排序的结构中，以便我们可以快速找到从某个位置到任意方向最近的障碍物。 这是必要的，因为在第一个阻挡者出现之前，运动总是笔直的。 
2. 从起始单元格 (1,1) 开始，模拟方向 1（右）的运动。 不要逐个单元格地步进，而是直接跳到该行中最近的障碍物或边界。 这些点之间的线段是唯一确定的，因为在其中不可能转弯。 
3. 当移动受阻时，如果当前单元格尚未用作转折点，则尝试在当前单元格中右转。 如果无法转动或已使用转动，则配置无效。 
4. 转弯后，继续向新方向移动，再次在障碍物之间跳跃，而不是模拟单位步骤。 
5. 通过跟踪每行和列方向上已经消耗的边界来隐式维护访问段的记录。 如果一个线段以相反方向遍历两次，则步行将重新访问单元格，这是无效的。 
6. 继续，直到无法进一步移动。 如果遍历的单元格数等于空闲单元格数，则遍历有效。 

本质上的简化是，每次移动都是由“方向上的下一个障碍”决定的，因此整个过程是一系列 O(k) 跳跃。 

### 为什么它有效

 任何有效的完整遍历都必须分解为最大直线段，因为转弯仅限于每个单元一次性使用。 在一个段内，不存在任何决定：令牌必须继续，直到被迫停止。 因此，唯一有意义的状态转换发生在由障碍物或边界定义的线段端点处。 这将问题分解为验证这些强制转换是否可以在不重新访问任何单元的情况下产生隐式网格图的单个类似欧拉的遍历，这正是分段模拟所检查的内容。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import defaultdict

def solve():
    n, m, k = map(int, input().split())
    
    row = defaultdict(list)
    col = defaultdict(list)
    blocked = set()

    for _ in range(k):
        x, y = map(int, input().split())
        row[x].append(y)
        col[y].append(x)
        blocked.add((x, y))

    for r in row:
        row[r].sort()
    for c in col:
        col[c].sort()

    # direction: 0=right,1=down,2=left,3=up
    x, y = 1, 1
    d = 0

    visited_cells = 1
    total_free = n * m - k

    used_turn = set()

    def next_block_in_row(x, y, direction):
        arr = row.get(x, [])
        if direction == 0:
            lo, hi = y + 1, m + 1
            for v in arr:
                if v >= lo:
                    return x, v - 1
            return x, m
        else:
            lo, hi = -1, y - 1
            for v in reversed(arr):
                if v <= hi:
                    return x, v + 1
            return x, 1

    def next_block_in_col(x, y, direction):
        arr = col.get(y, [])
        if direction == 1:
            for v in arr:
                if v > x:
                    return v - 1, y
            return n, y
        else:
            for v in reversed(arr):
                if v < x:
                    return v + 1, y
            return 1, y

    while True:
        if d == 0:
            nx, ny = next_block_in_row(x, y, 0)
        elif d == 1:
            nx, ny = next_block_in_col(x, y, 1)
        elif d == 2:
            nx, ny = next_block_in_row(x, y, 2)
        else:
            nx, ny = next_block_in_col(x, y, 3)

        if (nx, ny) == (x, y):
            break

        visited_cells += abs(nx - x) + abs(ny - y)

        x, y = nx, ny

        if (x, y) in blocked:
            break

        if (x, y, d) in used_turn:
            break
        used_turn.add((x, y, d))

        d = (d + 1) % 4

    print("Yes" if visited_cells == total_free else "No")

if __name__ == "__main__":
    solve()
```该解决方案为每行和每列构建排序的邻接列表，这允许直接跳转到给定方向的下一个障碍物边界。 然后，模拟通过在水平和垂直扫描之间交替进行，始终前进到当前方向上最远的可到达单元格。 

一个微妙的实现细节是，使用坐标差异而不是每个单元迭代来批量计算运动。 这是至关重要的，因为网格最多可以包含 10^10 个单元格。 

通过记住特定状态（单元格、方向）是否已经使用其右转选项来对转弯限制进行编码。 如果重复相同的配置，该过程将循环或强制无效重用，因此我们终止。

 ## 边缘情况

 最小网格（例如 1 by 1）测试算法是否不需要任何移动，并正确地将起始单元视为已经满足遍历要求。 

没有障碍物的网格强调模拟是否正确处理不间断的边界到边界扫描。 遍历必须覆盖整个矩形，而不会由于缺少障碍物停靠点而强制提前终止。 

障碍物在行中形成单个单元格间隙的情况测试跳跃是否正确地跳过阻塞的单元格，而不会意外地将它们计为已访问或创建非法的中间位置。
