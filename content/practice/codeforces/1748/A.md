 ## 解决方案
 ## 问题理解

 我们得到了一系列矩形木块。 第i个块的高度始终为1，并且其长度根据规则⌈i/2⌉随着i缓慢增长。 因此，块成对具有相等的宽度：索引 1 和 2 的宽度均为 1，索引 3 和 4 的宽度均为 2，索引 5 和 6 的宽度均为 3，依此类推。 

我们可以选择这些块的任何子集并在不旋转的情况下放置它们。 每个块贡献一个高度为 1 和固定宽度的水平条带。 目标是将这些条带组装成大小为 s × s 的实心正方形，以获得最大可能的整数 s。 

关键限制是块不能旋转，因此每个块恰好贡献一个 1×w 矩形。 

输入大小很大：n 最多可达 10^9，并且最多有 10^4 个测试用例。 这立即排除了任何迭代所有块或模拟构造的方法。 任何解决方案都必须仅依赖于 n 并使用封闭式推理。 

当 n 很小时，会出现微妙的边缘情况。 对于 n = 1 或 n = 2，所有块的宽度均为 1，因此只能形成 1 × 1 的正方形。 假设宽度立即从 2 开始增长的天真的方法会错误地高估答案。 另一个陷阱是假设我们需要使用所有块，而实际上我们只选择适合方形包装约束的子集。 

## 方法

 如果我们尝试直接构建方法，我们将模拟构建广场的行。 每行都需要宽度 s，我们会贪婪地选择宽度总和至少为 s 的可用块。 对于每个候选 s，这将需要扫描所有块或维护多组宽度。 

即使检查单个 s 也会花费 O(n)，并且由于 s 可以大到大约 √n，这会导致每个测试用例的结果约为 O(n√n) 或更糟，这对于 n 高达 10^9 来说是不可能的。 

关键的观察结果是块宽度是极其结构化的。 每个整数宽度 w 恰好出现两次，并且所有宽度 ≤ k 在块的前缀中恰好出现 2k 次。 

因此，我们不再考虑单个块，而是按宽度进行聚合。 对于给定的 n，我们可以计算我们有多少个全宽度组。 如果 k = ⌊n/2⌋，那么我们完全包含从 1 到 k 的宽度，每个宽度贡献两个块。 如果 n 是奇数，我们另外还有一个宽度为 k+1 的块。 

这将问题转化为纯粹的计数问题：使用每个宽度 w 最多出现两次（可能除了最后一个部分）的多重集，我们可以形成多大的正方形？ 

现在，下一个见解是几何的：要构建边长为 s 的正方形，我们需要选择总高度至少为 s 的条带（始终正确，因为我们最多可以选择 s 行），更重要的是，我们需要将每行打包为长度 s。 这减少了检查我们可以为每个宽度级别分配多少总水平“单位高度条”。 

一种更简单的看待方法是反转观点：考虑最大可能的 s，而不是组装一个正方形，这样我们就可以为每 s 行分配至少 s 的总宽度。 由于所有行的要求都是相同的，我们实际上是在问宽度的总可用“面积贡献”是否可以支持 s × s。 

所有区块贡献的总面积为：

 sum_{i=1..n} ⌈i/2⌉。 

该总和可以通过配对索引以封闭形式计算。 对于每个 k，我们得到两个宽度为 k 的块，贡献 2k 总面积，直到可能是最后一个不完整的对。 

因此：

 如果 n = 2m，则总面积 = 2(1 + 2 + ... + m) = m(m+1)

 如果 n = 2m + 1，则总面积 = m(m+1) + (m+1) = (m+1)^2

 因此总面积为 m(m+1) 或 (m+1)^2。 由于我们想要适合面积的最大平方 s × s，因此我们怀疑 s 大致为 √(面积)。 然而，单独这样做是不够的，因为结构可能会限制堆积。

关键的最终观察结果是，这种结构是紧密的：宽度不减少并且足够平衡，任何可行的包装仅取决于总面积，并且最佳正方形边长精确地变为：

 s = ⌊√（前 n 个宽度之和）⌋。 

计算此问题将整个问题简化为每个测试用例的恒定时间算术公式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力建设| O(n√n) | O(n√n) | O(n) | 太慢了|
 | 前缀和+平方根公式| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 ### 关键思想

 我们计算前 n 个块所贡献的宽度总和，然后取最大整数 s，使得 s² ≤ sum。 

### 步骤

 1. 通过计算 m = n // 2 将 n 分成索引对。 

这对块 (1,2)、(3,4)、... 进行分组，每对共享相同的宽度。 
2. 计算完整对的总贡献：m(m+1)。 

这来自 2(1 + 2 + ... + m)，因为每个宽度 k 出现两次。 
3. 如果n是奇数，则添加宽度为m+1的最后一个块的贡献。 
4. 令 Total 为计算所得的总和。 
5. 答案是满足 s² ≤ Total 的最大整数 s，即，floor(sqrt(total))。 

### 为什么它有效

 该结构的宽度是单调的，这意味着较大的宽度仅出现在较小的宽度之后，并且总是具有足够的多样性。 这可以防止存在区域但无法排列成正方形的病态包装限制。 由于每个宽度级别都贡献完整的 1 高度条带，因此限制因素纯粹是总可用面积，并且没有额外的组合约束会降低可行性。 因此，最大正方形边由面积边界精确确定。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

t = int(input())
for _ in range(t):
    n = int(input())
    m = n // 2
    total = m * (m + 1)
    if n % 2 == 1:
        total += (m + 1)
    print(int(math.isqrt(total)))
```直接按照推导公式实现。 使用整数平方根来避免浮点精度问题。 总计的计算是使用算术级数公式在 O(1) 内完成的。 

必须注意的是，中间乘​​法 m(m+1) 可能很大，因此 Python 的任意精度整数在这里是合适的。 

## 工作示例

 ### 示例 1：n = 5

 | 步骤| m 值 | 结对贡献 | 额外块| 总计 |
 | --- | --- | --- | --- | --- |
 | 计算| 2 | 2(1+2)=6 | 2(1+2)=6 宽度 3 | 9 |

 现在我们计算 s = ⌊√9⌋ = 3。 

这与宽度为 1,1,2,2,3 的块可以形成 3 × 3 正方形的结构相匹配。 

### 示例 2：n = 2

 | 步骤| m 值 | 结对贡献 | 额外块| 总计 |
 | --- | --- | --- | --- | --- |
 | 计算| 1 | 2(1)=2 | 2(1)=2 | 无 | 2 |

 现在 s = ⌊√2⌋ = 1。 

我们无法形成 2 × 2 的正方形，因为总可用宽度不足，因此结果为 1。 

这些例子表明，正方形的边长完全由聚合宽度总和决定，而不是由单独的块排列决定。

import sys, io, math

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        m = n // 2
        total = m * (m + 1)
        if n % 2 == 1:
            total += (m + 1)
        out.append(str(math.isqrt(total)))

 ## 边缘情况

 对于 n = 1，我们只有一个宽度为 1 的块。该公式给出 m = 0，total = 1，答案为 1。该算法可以正确处理此问题，因为奇数情况加法贡献了单个块。 

当n = 2时，两个块的宽度均为1。我们得到m = 1，总计= 2，平方根为1。即使存在两个块，它们也不能形成边2，因为总面积不足。 

对于大奇数 n，例如 n = 10^9，该算法计算 m = 5×10^8 并安全地计算 Python 整数中的二次表达式。 单调结构确保不会发生溢出或结构填充故障，并且平方根保持正确。
