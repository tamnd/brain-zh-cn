 ## 解决方案
 ## 问题理解

 我们被要求计算将整数数组着色为蓝色或红色的方法的数量，但受到两个约束。 第一个是字典顺序约束：如果我们将蓝色元素提取为一个子序列，将红色元素提取为另一个子序列，则按字典顺序，蓝色序列必须严格小于红色序列。 第二个是局部平衡约束：在任何连续的子数组中，给定值的蓝色元素的数量不能与该值的红色元素的数量相差 2 或更多。 

输入由最多包含的数组组成$2 \cdot 10^5$整数，每个都在相同的范围内。 输出是有效着色的模数计数$998,244,353$。 自从$n$很大，任何明确尝试每种可能的颜色的算法都是不可行的，因为有$2^n$的可能性。 这立即排除了暴力枚举。 

当一个数字在数组中多次出现时，就会出现不明显的边缘情况。 例如，像这样的序列`[1, 1, 2]`受到约束：如果两者`1`s 是蓝色的，没有一个是红色的，包含这两个的子数组`1`s 不平衡。 类似地，如果数组按非降序排序，则字典顺序约束会严重限制着色，因为出现在相同值的红色元素之后的任何蓝色元素都会违反字典顺序。

 字典顺序和局部平衡的结合意味着有效的着色是结构化的：重复值不能任意分割，并且每个值的第一次出现往往主导分配。 任何忽略子数组平衡的幼稚实现都会过多计算颜色。 

## 方法

 蛮力方法是生成所有$2^n$颜色，检查蓝色与红色子序列的字典顺序，然后扫描所有$O(n^2)$不平衡子数组。 这会产生$O(n^2 \cdot 2^n)$工作，这远远超出了可行的范围$n=2\cdot10^5$。 

关键的见解是观察到局部平衡约束迫使每个值以非常受限的方式进行分割。 具体来说，对于每个不同的值，在任何有效的着色中，该值的出现必须分为蓝色和红色块，以便没有子数组包含一种颜色比另一种颜色多于一次的额外出现。 这意味着所有出现的值都可以分为完全蓝色或完全红色的连续段，并且字典顺序确保蓝色值的第一次出现发生在红色值的第一次出现之前。 

这自然暗示了一种不相交集或区间合并方法。 通过对相同值的出现进行分组并链接可能发生不平衡的重叠范围，我们可以识别可以独立选择颜色的独立片段。 有效着色的总数是每个段的选择的乘积，字典序约束将整个数组的选项减少到最多 3 个。

 ## 算法演练

 1. **识别每个值的第一个和最后一个位置。** 对于数组中的每个不同整数，存储其第一次和最后一次出现的索引。 这提供了包含该值的所有出现的最小间隔。 
2. **合并重叠的区间。** 按照第一次出现的顺序遍历区间。 每当某个间隔与当前运行间隔重叠时，请扩展运行间隔以将其包括在内。 每个合并的区间代表一个必须一起考虑的段，因为其中的任何不平衡都会在整个段中传播约束。 
3. **计算独立片段。** 每个合并的间隔可以以 3 种方式着色，同时满足平衡和字典顺序条件：全蓝色、全红色或以与字典顺序一致的最小允许模式分割。 将所有间隔的计数乘以模$998,244,353$。 
4. **返回总计数。** 步骤 3 中的乘积给出了数组的有效着色数。 

正确性依赖于两个不变量。 首先，区间合并确保任何两个可能形成不平衡的位置都包含在同一段中。 其次，在决定颜色顺序时，通过仅考虑每个值的第一次出现，自然地强制执行字典顺序约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

def main():
    n = int(input())
    a = list(map(int, input().split()))
    
    first = {}
    last = {}
    for i, x in enumerate(a):
        if x not in first:
            first[x] = i
        last[x] = i
    
    intervals = sorted([(first[x], last[x]) for x in first])
    
    total = 1
    l, r = -1, -1
    for start, end in intervals:
        if start > r:
            l, r = start, end
            total = total * 3 % MOD
        else:
            r = max(r, end)
    
    print(total)

if __name__ == "__main__":
    main()
```代码的每个部分都反映了算法步骤。 我们首先记录第一个和最后一个索引，然后对间隔进行排序以按顺序处理它们。 重叠区间动态合并，每个独立段将总计数乘以3。边界条件通过初始化处理`l`和`r`到`-1`以便第一个间隔始终触发乘法。
