 ## 解决方案
 ## 问题理解

 我们选择一个值$a_{n+1}$之间$0$和$m$。 之后，每个较早的位置都由以下唯一确定$$a_i = a_{i+1} \bmod i$$为了$i=n,n-1,\dots,1$。 

整个数组是根据单个起始值生成的。 我们必须数一下有多少种选择$a_{n+1}$准确地生产$k$全部中不同的数字$n+1$职位。 

这些限制立即表明我们无法模拟该过程。 两个都$n$和$m$可以达到$10^9$，并且最多有$2\cdot10^4$测试用例。 任何迭代值的解决方案$a_{n+1}$，甚至通过所有位置$1\ldots n$，是不可能的。 

关键的挑战是理解重复模运算生成的序列的结构。 

一些边缘情况很容易被忽略。 

考虑$n=2,m=0,k=1$。 唯一可能的选择是$a_3=0$。 生成的数组是$[0,0,0]$，所以答案是$1$。 任何假设的公式$m\ge1$会在这里失败。 

考虑$n=4,m=6,k=3$。 有效的选择是$5$和$6$，给出答案$2$。 天真的猜测，不同值的数量仅取决于$a_{n+1}$大或小都是不够的。 

考虑$n=265,m=265,k=265$。 答案是$0$。 由于只有$266$位置，获得$265$不同的价值观已经非常具有限制性。 准确理解哪些值$k$能否实现是问题的核心。 

## 方法

 暴力解决方案会尝试所有可能的值$x=a_{n+1}$从$0$到$m$。 对于每一个，我们都会生成$$a_n=x\bmod n,\quad a_{n-1}=a_n\bmod(n-1),\dots$$并计算不同的值。 

这是正确的，因为它直接遵循定义。 不幸的是，它需要$O(mn)$工作。 两个参数都达到$10^9$，这是完全不可行的。 

突破来自于检查重复模运算的实际作用。 

让$x=a_{n+1}$。 

如果$x<n$， 然后$$a_n=x\bmod n=x.$$自从$x<n$，对较小的数应用模可以保持该值，也可以减小该值。 序列中出现的每个值最多$x$。 

如果$x\ge n$， 然后$$a_n=x\bmod n.$$序列的整个剩余部分仅取决于$r=x\bmod n$。 

更重要的是，定位之后$n$, 每个值最多是$n-1$。 

让我们了解出现了多少不同的值。 

如果$x=0$，每个元素都变成$0$。 我们得到了一个明确的值。 

如果$1\le x<n$，那么序列从值开始$x$，每当我们达到模数$x$,$$x\bmod x = 0.$$在此之前该值仍然存在$x$。 在那之后它仍然存在$0$。 

因此该数组恰好包含两个不同的值：$x$和$0$。 

如果$x\ge n$， 写$$r=x\bmod n.$$价值$x$本身出现在位置$n+1$，而所有早期位置仅取决于$r$。 

如果$r=0$，然后位置$1\ldots n$都是$0$。 不同的值是$\{0,x\}$，给出两个不同的值。 

如果$1\le r<n$，然后位置$1\ldots n$仅包含$r$和$0$，同时位置$n+1$包含$x$，大于$n$并且与两者不同。 因此我们得到了三个不同的值：$$\{x,r,0\}.$$这完全说明了问题的特征。 

不同值的唯一可能数量是：

 对于$k=1$， 仅有的$x=0$。 

为了$k=2$， 任何一个$x\in[1,n-1]$或者$x$是一个正倍数$n$。 

为了$k=3$,$x\ge n$和$x\bmod n\neq0$。 

为了$k\ge4$，答案总是$0$。 

一旦知道了这个结构，计数就变成了简单的算术。

 | ---| ---| ---| ---|
 | 蛮力 |$O(mn)$|$O(n)$| 太慢了 |
 | 最佳 |$O(1)$每个测试用例|$O(1)$| 已接受 |

 ## 算法演练

 1.如果$k=1$，唯一有效的选择是$x=0$。 返回$1$因为$0$总是允许的。 
2.如果$k\ge4$， 返回$0$。 该序列永远不能包含超过三个不同的值。 
3.如果$k=2$，统计两组值。 

首先，所有$x$这样$1\le x<n$。 他们每个人都产生准确的值$\{x,0\}$。 

其次，所有正倍数$n$不超过$m$。 这些产生$\{x,0\}$以及。 

计数是$$\min(m,n-1)+\left\lfloor\frac{m}{n}\right\rfloor.$$4. 如果$k=3$, 计算所有值$x\ge n$模数非零余数$n$。 

有$$m-n+1$$区间内的整数$[n,m]$什么时候$m\ge n$。 

他们之中，$$\left\lfloor\frac{m}{n}\right\rfloor$$是的倍数$n$。 

删除那些给予$$(m-n+1)-\left\lfloor\frac{m}{n}\right\rfloor.$$如果$m<n$，答案是$0$。 

### 为什么它有效

 关键的不变量是计算后$a_n=x\bmod n$，每个后续值仅取决于该余数并且永远不会超过$n-1$。 

什么时候$x<n$，值$x$在模数之前保持不变$x$被应用，此时它变成$0$。 不能出现第三个值。 

什么时候$x\ge n$，值$x$本身仅出现在位置$n+1$。 其余位置的行为与从生成的序列完全相同$r=x\bmod n$，其中只能包含$r$和$0$。 因此，整个数组包含两个不同的值$r=0$，或三个不同的值$r\neq0$。 

既然一切可能$x$属于其中一种情况，计数公式是准确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, m, k = map(int, input().split())

        if k == 1:
            ans.append("1")

        elif k == 2:
            res = min(m, n - 1) + m // n
            ans.append(str(res))

        elif k == 3:
            if m < n:
                ans.append("0")
            else:
                res = (m - n + 1) - (m // n)
                ans.append(str(res))

        else:
            ans.append("0")

    sys.stdout.write("\n".join(ans))

solve()
```第一个分支处理唯一值$x=0$，这是获得单个不同数字的唯一方法。 

第二个分支对恰好生成两个不同值的两个类进行计数。 使用`min(m, n - 1)`正确处理间隔的情况$[1,n-1]$超出允许范围$[0,m]$。 

第三个分支计算数字$[n,m]$并减去$n$。 支票`m < n`避免当区间为空时产生负结果。 

所有算术都适合 64 位整数。 Python 整数是无界的，因此不需要特别注意。

 ## 边缘情况

 ### 情况 1：只有零可用

 输入：```
1
2 0 1
```算法输入`k == 1`分支并立即返回`1`。 

唯一可能的值是$x=0$，生产$[0,0,0]$。 只存在一个不同的值。 

### 情况 2：要求四个不同的值

 输入：```
1
5 100 4
```算法返回`0`。 

对于任何选择的$x$，序列最多包含值$x$,$x\bmod n$， 和$0$。 三个不同的值是可能的最大值。 四永远不会发生。 

### 案例 3：$k=3$但$m<n$输入：```
1
10 7 3
```算法检查`m < n`并返回`0`。 

每个有效$x$满足$x<10$。 这些值仅生成$\{x,0\}$或者只是$\{0\}$，从来没有三个不同的值。 

### 情况 4： 的精确倍数$n$输入：```
1
4 8 2
```可能的值为$1,2,3,4,8$。 

为了$x=4$和$x=8$,$$x\bmod4=0,$$所以序列只包含$x$和$0$。 

公式给出$$\min(8,3)+\left\lfloor\frac{8}{4}\right\rfloor =3+2=5,$$与五个有效选项匹配。
