 ## 解决方案
 ## 问题理解

 我们有一棵树，其中一些边已经有固定方向，而一些边仍然无向。 我们必须为剩余边缘选择方向并为每个边缘分配颜色。 

步行可以沿着边缘的方向或逆着它的方向穿过边缘。 沿着该方向移动会将颜色与边缘颜色相同的球推入堆栈。 逆着方向移动会弹出顶部的球。 

如果一次遍历从不尝试从空堆栈中弹出，则该遍历称为可堆栈的。 

如果每次弹出都会删除一个颜色与当前遍历的边缘相匹配的球，则可堆叠行走是球可堆叠的。 

我们的任务是让**每个**可堆叠步行自动可堆叠球。 在所有有效的结构中，我们希望最大化所使用的不同颜色的数量。 

底层图是一棵树，最多有$10^5$顶点。 任何涉及成对顶点检查、模拟行走或任何二次方程的解决方案都是不可能的。 需要线性或近线性解。 

困难在于，该条件对**所有可能的可堆叠行走**进行量化，包括多次重新访问顶点和边的行走。 我们无法推理个人的行走情况。 我们需要对所有可堆叠步道何时正常运行进行结构表征。 

一些微妙的情况很容易被忽视。 

考虑一条路径```
1 -> 2 -> 3
```两个边缘有不同的颜色。 

散步```
1 -> 2 -> 3 -> 2
```推动边缘颜色$(1,2)$，然后是边缘的颜色$(2,3)$，然后使用边缘弹出$(2,3)$。 这很好。 

现在想象一个分支结构```
    2
    |
1 ->3<-4
```如果 3 个传入边缘上的颜色不同，则步行可以通过一个边缘进入，在其他地方徘徊，然后通过另一个边缘。 堆栈机制开始在颜色之间施加相等性。 

关键的挑战是准确地发现哪些平等是被迫的。 

## 方法

 蛮力视图是将每个边缘方向视为推送符号，将每个反向遍历视为匹配的弹出符号。 我们可以尝试枚举行走并导出所有颜色约束。 

这是没有希望的。 即使是一棵树$10^5$顶点允许无限多次行走，因为边可能会被任意多次重新访问。 不存在有限枚举策略。 

突破来自于认识到堆栈行为正是正确嵌套括号的行为。 

每当我们沿其方向穿过边缘时，我们就会推动某物。 每当我们向后遍历它时，我们就会弹出一些东西。 可堆叠行走正是一个序列，其中每次弹出都与之前未匹配的推送相匹配。 

每次弹出都会删除与遍历的边缘颜色相同的球的要求意味着由堆栈顺序强制的每个推入弹出对必须对应于相同的颜色。 

我们不是推理游走，而是推理有向树本身。 

假设我们把树扎根在某个地方。 如果边缘从父节点指向子节点，则向下遍历会产生推动。 向上穿过同一边缘会产生流行音乐。 堆栈的行为就像进入和离开树的区域一样。 

在完成了可能的步行之后，人们发现了一个至关重要的事实：

 当且仅当每个有向边都可以与单个根一致地定向时，才存在有效的构造。 换句话说，选择根后，每条边都必须指向远离根的方向。 混合的取向造成了不可避免的矛盾。 

更准确地说，最终的有向树必须是根植于某个顶点的树状结构。 

然后堆栈行为变得与 DFS 括号相同。 每个弹出都被迫沿着唯一的根路径匹配最近的未匹配的推送。 

这立即确定了颜色限制。 离开同一顶点的所有边必须共享一种颜色。 否则，一次步行可能会推过一个子边缘并弹出另一个子边缘，从而产生不匹配。 

相反，一旦顶点的每个出边都具有相同的颜色，则每个可堆叠的行走都将成为可堆叠的球。 

现在问题转化为：

 1. 确定已经有向边是否承认根，使得每个有向边都指向远离该根的方向。 
2. 如果存在这样的根，则当每个顶点贡献由所有传出边共享的一种颜色时，最大化不同颜色的数量。 

通过为尽可能多的顶点赋予不同的颜色来获得最大数量的颜色。 由于一个顶点的所有出边必须共享一种颜色，因此颜色对应于具有至少一个出边的内部顶点。

 ## 算法演练

 ### 步骤 1

 解释每个固定有向边$u \to v$作为对根的约束。 

如果最终方向必须远离根，则根不能位于包含的组件内部$v$删除该边缘后。 

同样，根必须属于包含$u$。 

### 步骤 2

 任意确定底层树的根，例如在顶点 1 处。 

计算欧拉游览间隔，使每个子树成为一个连续的线段。 

### 步骤 3

 对于每个固定边$u \to v$，确定哪个端点是临时根中另一个端点的祖先。 

如果$u$是的祖先$v$，那么有效根正好在子树之外（$v$）。 

如果$v$是的祖先$u$，那么有效根正好位于子树内部（$u$）。 

这些是欧拉位置的简单范围约束。 

### 步骤 4

 将所有约束与欧拉阶上的差分阵列技术相结合。 

计算每个顶点满足多少个约束。 

任何满足所有约束的顶点都可以作为全局根。 

如果不存在这样的顶点，则输出$-1$。 

### 步骤 5

 选择任何有效的根$r$。 

将每个无向边缘定向为远离$r$。 

已经定向的边缘自动指向远离$r$因为施工的限制。 

### 步骤 6

 指定颜色。 

对于除根之外的每个顶点，考虑将其连接到其父级的边。 

该边的颜色由父顶点决定。 

离开同一父级的所有边都具有相同的颜色。 

### 步骤 7

 将使用的父标签压缩为连续的颜色编号。 

不同颜色的数量等于具有至少一个子节点的顶点数量，这是最大的。 

### 为什么它有效

 根约束正是每个有向边指向远离公共根所需的条件。 如果不存在这样的根，则某些有向边必须指向根，而另一个则指向远离根的方向，从而创建一个允许可堆叠行走的结构，其堆叠匹配无法用局部颜色相等表示。 

当所有边都远离根时，每个可堆叠遍历的行为就像有根树边的正确嵌套遍历一样。 与进入子子树相对应的推送必须通过离开同一子树来匹配。 因此，唯一需要的颜色相等是共享相同父级的边之间的颜色。 

为每个父级分配一种颜色满足所有必需的平等性。 不同的父母可能会收到不同的颜色，从而给出最大可能的颜色数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

edges = []
g = [[] for _ in range(n)]

for i in range(n - 1):
    u, v, t = map(int, input().split())
    u -= 1
    v -= 1
    edges.append((u, v, t))
    g[u].append((v, i))
    g[v].append((u, i))

tin = [0] * n
tout = [0] * n
parent = [-1] * n
depth = [0] * n

timer = 0

stack = [(0, -1, 0)]
while stack:
    v, p, state = stack.pop()

    if state == 0:
        tin[v] = timer
        timer += 1

        stack.append((v, p, 1))

        for to, _ in reversed(g[v]):
            if to == p:
                continue
            parent[to] = v
            depth[to] = depth[v] + 1
            stack.append((to, v, 0))
    else:
        tout[v] = timer - 1

def is_ancestor(a, b):
    return tin[a] <= tin[b] <= tout[a]

diff = [0] * (n + 1)
need = 0

for u, v, t in edges:
    if t == 0:
        continue

    need += 1

    if is_ancestor(u, v):
        l = tin[v]
        r = tout[v]

        diff[0] += 1
        diff[n] -= 1

        diff[l] -= 1
        diff[r + 1] += 1
    else:
        l = tin[u]
        r = tout[u]

        diff[l] += 1
        diff[r + 1] -= 1

cur = 0
root = -1

for v in range(n):
    cur += diff[v]
    if cur == need:
        root = v
        break

if root == -1:
    print(-1)
    sys.exit()

parent = [-1] * n
order = [root]
parent[root] = root

for v in order:
    for to, _ in g[v]:
        if parent[to] != -1:
            continue
        parent[to] = v
        order.append(to)

children_count = [0] * n
for v in range(n):
    if v != root:
        children_count[parent[v]] += 1

color_of_vertex = [-1] * n
color_id = 0

for v in range(n):
    if children_count[v] > 0:
        color_id += 1
        color_of_vertex[v] = color_id

answer = []

for u, v, t in edges:
    if parent[v] == u:
        p, q = u, v
    elif parent[u] == v:
        p, q = v, u
    else:
        raise RuntimeError

    c = color_of_vertex[p]
    answer.append((p + 1, q + 1, c))

print(color_id)
for row in answer:
    print(*row)
```第一个 DFS 计算欧拉区间。 这些间隔允许子树约束表示为差异数组上的范围添加。 

下一阶段处理每个固定有向边。 每条边根据其端点的祖先关系贡献“内部子树”约束或“外部子树”约束。 

累积约束后，任何满足所有约束的顶点都可以作为全局根。 

一旦知道了根，确定树的方向就很简单了。 在有根树中，每条边都从父级指向子级。 

着色阶段是堆栈参数进入的阶段。 每个父顶点接收其所有出边共享的一种颜色。 没有子节点的顶点不会贡献颜色，因为没有边源自它们。

 ## 边缘情况

 考虑```
3
1 2 1
3 2 1
```两条有向边都指向顶点 2。任何远离根的有根方向都要求顶点 2 同时低于 1 和 3，这在树中是不可能的。 约束累积阶段没有留下满足所有约束的顶点，因此算法输出`-1`。 

考虑```
2
1 2 0
```没有固定方向的约束。 每个顶点都是有效的根。 该算法选择一个，将唯一的边缘引离它，分配一种颜色，然后成功。 

考虑```
5
1 2 0
1 3 0
1 4 0
1 5 0
```所有四个边都在根方向上留下相同的父项。 正确性证明表明它们必须共享一种颜色。 该算法为所有四个边缘精确分配一种颜色。 任何在这里使用多种颜色的尝试都会违反堆栈条件，因此该结构已经是最佳的。
