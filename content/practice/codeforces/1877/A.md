 ## 解决方案
 ## 问题理解

 我们有一场循环赛足球锦标赛$n$团队。 每对球队只打一场比赛。 

对于每个团队，其效率定义为：$$\text{goals scored} - \text{goals conceded}$$比赛结束后，计算所有球队的效率。 一个团队的效率损失了，我们得到剩余团队的效率$n-1$团队。 任务是确定缺失的效率。 

限制非常小。 最多有 500 个测试用例，每个测试用例最多有 100 个团队。 甚至一个$O(n^2)$解决方案在这里是微不足道的。 真正的挑战是识别唯一确定缺失值的数学属性。 

一个常见的错误是认为我们需要重建比赛结果。 该声明甚至提供了一种可能的锦标赛，这可能会诱使我们进行模拟比赛。 这是不必要的，因为缺失的效率可以直接从全局不变量中导出。 

考虑一个简单的例子：```
n = 2
known efficiencies = [5]
```只有一场比赛。 如果一支球队有效率$+5$，另一个必须有效率$-5$。 答案是：```
-5
```另一种容易被忽视的情况是效率为负值时：```
n = 3
known efficiencies = [-3, -7]
```正确答案是：```
10
```粗心地采用绝对值或假设效率非负的实现将会失败。 

第三种边缘情况是所有已知效率都为零时：```
n = 4
known efficiencies = [0, 0, 0]
```缺失的效率也为：```
0
```解决方案使用的不变量仍然完美地保持。 

## 方法

 蛮力思维从尝试重建锦标赛开始。 由于每种效率都取决于许多场比赛，因此我们可能会尝试推断满足给定值的分数，然后得出缺失球队的效率。 

这种方法很快就变得不切实际。 循环赛比赛包含$$\frac{n(n-1)}{2}$$比赛，每场比赛可能有多种可能的比分组合。 搜索可能的锦标赛是完全没有必要的。 

关键的观察来自于效率是如何形成的。 

对于任何一场比赛，假设 A 队得分$x$进球数和 B 队得分$y$目标。 

A 队贡献：$$x-y$$以达到其效率。 

B 队贡献：$$y-x$$以达到其效率。 

添加这些贡献可以得出：$$(x-y)+(y-x)=0$$每场比赛对所有球队效率总和的贡献为零。 由于锦标赛只是一场比赛的集合，所有球队的总效率也必定为零。 

如果效率为：$$e_1,e_2,\dots,e_n$$然后$$e_1+e_2+\cdots+e_n=0$$我们被给予$n-1$其中。 如果他们的总和是$S$，那么缺失的效率必定是：$$-S$$这将整个问题简化为对给定数字求和。

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，请阅读$n$。 
3. 阅读$n-1$已知的效率。 
4. 计算它们的总和$S$。 
5、输出$-S$。 

第 5 步有效的原因是锦标赛中所有球队的效率总和始终为零。 缺失值必须完全抵消已知值的总和。 

### 为什么它有效

 每场比赛都会为两支参赛球队贡献相反的价值。 如果一支球队获胜$x-y$，其他收益$y-x$。 该匹配对全局效率总和的总贡献为零。 

由于每场比赛的贡献为零，所以整场比赛结束后所有球队的效率之和也为零。 设缺失效率为$m$。 如果已知效率总和为$S$， 然后：$$S + m = 0$$这意味着：$$m = -S$$该算法精确计算该值，因此它始终是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(-sum(a))
```实现直接遵循数学观察。 

变量`a`存储的$n-1$已知的效率。 它们的总和是用 Python 的内置函数计算的`sum()`功能。 由于所有团队的总效率必须为零，因此缺失的效率只是该总和的负数。 

不存在棘手的边界条件。 负值、正值和零都是自然处理的。 在 Python 中，整数溢出不是问题，即使在固定宽度语言中，在给定的约束下，该值仍然非常小。

def solve():

 ## 边缘情况

 考虑最小规模的锦标赛：```
1
2
5
```该算法计算：```
S = 5
answer = -5
```只有一场比赛，所以两队的效率肯定是相反的。 输出是正确的。 

考虑全零效率：```
1
4
0 0 0
```该算法计算：```

answer = 0
```由于总效率必定为零，因此缺失值也为零。 

考虑负值：```
1
3
-3 -7
```该算法计算：```
S = -10
answer = 10
```不变量不依赖于符号。 缺失的效率只是将总数平衡回零。
