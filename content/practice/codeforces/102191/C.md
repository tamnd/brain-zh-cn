 ## 解决方案
 ## 问题理解

 输入描述了上个月的圆形座位。 数组本身按顺时针顺序向学生提供，因此连续的数组位置是相邻的，并且第一个和最后一个元素也是相邻的。 

我们需要输出另一个包含每个学生一次的循环排序。 对于新圈中每对坐在一起的学生，这对学生在旧圈中一定不相邻。 接受任何有效的安排，并且`-1`当不存在此类安排时需要。 下面的构造遵循该问题的标准解决方案。 

和`n`一样大`3 * 10^5`并且只有一秒可用，解需要是线性或接近线性的。 任何涉及所有排列的事情都是立即不可能的，甚至`O(n^2)`搜索将围绕`9 * 10^10`操作在上限。 有用的结构是旧的安排本身就是一个循环，因此我们可以推断位置而不是学生 ID。 

有两个小值需要特殊处理。 为了`n = 3`，每对学生在旧圈中都是相邻的，因此没有可用于新邻接的学生对。 为了`n = 4`，唯一不相邻的对是两对相对的学生，它们形成两条不相连的边而不是四顶点循环。 因此这两种情况都是不可能的。 

例如，与`n = 3`并输入`1 3 2`，旧圆包含所有三个可能的对，因此正确的输出是`-1`。 如果粗心的实现只检查线性数组中的连续位置而忘记了首尾邻接，则可能会错误地接受排列。 

为了`n = 4`， 考虑```
41 2 3 4
```允许的新邻接仅`(1,3)`和`(2,4)`。 圆形排列需要四个允许边，但这两个允许边不能形成一个循环，所以正确的输出又是`-1`。 

甚至还有一个边界问题`n`。 简单地采用偶数位置的所有元素，然后采用奇数位置的所有元素几乎是可行的，但禁止其最后到第一个边缘。 例如，对于职位`0,1,2,3,4,5`, 顺序`0,2,4,1,3,5`以边缘结束`5 -> 0`，这是原始邻接。 必须交换最后两个元素才能修复该边界。 

输入保证是排列，因此“所有相等值”测试不是有效的问题实例。 一个测试，例如`4 / 1 1 1 1`违反了输入合同，不应用作所提交程序的正确性测试。 

## 方法

 直接的方法是尝试学生的每个排列，并检查其循环相邻对是否都与原始循环相邻对不同。 单个候选人需要`n`邻接性检查，同时有`n!`候选人，放弃`n * n!`在最坏的情况下进行检查。 即使是为了`n = 10`，这大约是`36.3`百万邻接检查。 在`n = 3 * 10^5`，阶乘增长使得这种方法完全无法使用。 

蛮力之所以有效，是因为直接检查候选人很容易。 困难在于找到候选人。 有用的观察是，限制仅取决于旧圈子中的位置。 如果两个旧位置均不相同`1`也不`-1`模数`n`，他们的学生可以安全地彼此相邻放置。 

这表明以更大的固定步长建仓。 对于奇数`n`, 逐步经过`2`模数`n`每个位置都访问一次，因为`2`和`n`是互质的。 新顺序中的每个连续对都被旧循环中的两个位置分隔开，包括最后对，因此每个新邻接都是有效的。 

对于甚至`n`, 逐步经过`2`只访问相同奇偶校验的位置。 我们可以首先将所有偶数位置放入答案中，然后将所有奇数位置放入答案中。 在每个组内，原始圆中的连续位置相差两个，因此这些边是安全的。 只是边界有问题。 当以下情况时，交换奇数位置组的最后两个元素将两个边界边更改为非原始邻接：`n >= 6`。 

这给出了一个简单的`O(n)`建造。 事实上，不存在答案`n < 5`并且该建筑适用于每个人`n >= 5`也反映在已知的参考实现中。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(n · n!)`|`O(n)`| 太慢了 |
 | 最佳 |`O(n)`|`O(n)`| 已接受 |

 ## 算法演练

 1. 读取循环排列`a`。 我们将使用以下位置构建答案`a`，因为禁忌关系完全是由旧职位决定的。 
2.如果`n < 5`， 打印`-1`。 为了`n = 3`和`n = 4`，旧循环的补集不包含哈密顿循环，因此没有循环排列可以满足所有限制。 
3. 追加`a[0], a[2], a[4], ...`到答案。 这些位置在原始圆中相距两个位置，因此允许在该部分内创建的每个邻接。 
4. 追加`a[1], a[3], a[5], ...`到答案。 同样的论点也适用于第二部分，因为它的连续位置也相差两个。 
5.如果`n`很奇怪，停在这里。 该序列正是绕原圆重复移动两个位置所得到的顺序。 因为`gcd(2, n) = 1`，这会访问每个位置一次，并且最后到第一对也是相隔两个位置模`n`。 
6. 如果`n`是偶数，交换构造答案的最后两个元素。 交换之前，最后一个元素是`a[n-1]`，它将与第一个元素相邻`a[0]`在旧圈子里。 交换后，最后一个元素变成`a[n-3]`，它与安全分离`a[0]`什么时候`n >= 6`。 其他受影响的边界也变得安全。 
7. 打印结果排列。 它只包含每个原始元素一次，因为我们只重新排列了原始位置。 

### 为什么它有效

 考虑第一个奇数`n`。 每个答案边连接的位置的差异为`2`模数`n`。 自从`n >= 5`，相差`2`不是一个旧的邻接关系，其唯一可能的区别是`1`和`n - 1`。 因为`2`与奇数互质`n`, 反复添加`2`访问所有位置，因此该构造是一个循环排列。 

对于甚至`n >= 6`，偶数位组内和奇数位组内的所有边都有位置差异`2`。 唯一潜在危险的边是组之间的两个连接以及最后到第一个边。 交换最后两个元素后，这些连接位置`n-2`到`1`,`n-3`到`n-1`， 和`n-3`到`0`。 它们的圆距离至少为`3`或者`2`没有存在`1`或者`n-1`，所以没有一个是旧邻接。 因此，生成的圆中的每条边都是有效的。 

不变的是，连续放置的每一对要么在原圆中相距两个位置，要么是专门修复的跨组边界之一。 这些对都不是原始的相邻对。 

## Python 解决方案```python
Pythonimport sysinput = sys.stdin.readline

def solve():    n = int(input())    a = list(map(int, input().split()))
    if n < 5:        print(-1)        return
    ans = []
    for i in range(0, n, 2):        ans.append(a[i])
    for i in range(1, n, 2):        ans.append(a[i])
    if n % 2 == 0:        ans[-1], ans[-2] = ans[-2], ans[-1]
    print(*ans)

if __name__ == "__main__":    solve()
```第一个循环采用每个偶数索引，而第二个循环采用每个奇数索引。 它们一起包含每个位置一次，因此不会丢失或重复学生。 

对于奇数`n`，不需要其他任何东西。 得到的序列是原始圆的第二步遍历。 例如，有五个位置，位置顺序为`0, 2, 4, 1, 3`，闭合边从`3`回到`0`，再次绕圆两圈的距离。 

对于甚至`n`，最后两组单独离开最后一个原始位置。 自从`a[n-1]`曾毗邻`a[0]`，简单地闭合新圆就会准确地创建我们试图避免的禁边。 交换`ans[-1]`和`ans[-2]`动作`a[n-3]`到最终位置并放置`a[n-1]`就在之前`a[n-3]`。 两个结果边均有效`n >= 6`。 

不存在整数溢出问题，因为该算法仅存储和索引输入中的整数。 该实现还避免了任何昂贵的搜索，因此其运行时间主要是读取和打印`n`价值观。

## 边缘情况

 对于`n = 3`，输入```
31 3 2
```导致算法返回`-1`在建造任何东西之前。 三名学生中的每一对都在旧圆中已经相邻，因此无法合法地形成新的圆边。 

为了`n = 4`， 考虑```
41 2 3 4
```该施工也立即被拒绝。 学生`1`和`3`是相反的，正如`2`和`4`，这是唯一合法的对。 他们无法提供一个四人圈所需的四个边缘。 

对于最小的可解奇数情况，```
51 2 3 4 5
```偶数位置通过产生`1 3 5`，奇数位置传递产生`2 4`, 给予`1 3 5 2 4`。 每个新的相邻对对应于旧圆中的两个位置跳跃，包括`4 -> 1`。 这说明了为什么奇怪`n`无需修正。 

对于最小的可解偶数情况，```
61 2 3 4 5 6
```初始构造是`1 3 5 2 4 6`。 最后的边缘`6 -> 1`被禁止，因为这些学生原本是相邻的。 交换最后两个元素给出`1 3 5 2 6 4`。 圆形边缘现在将原始位置与距离连接起来`2, 2, 3, 4, 2, 3`，其中没有一个是原始邻接。 这是捕获执行奇偶校验分割但忘记最终交换的实现的边界情况。 

对于大的偶数输入，同样的推理不会改变。 该结构从不寻找特殊的学生或重复检查先前构建的边缘。 它只计算奇偶校验组并执行一次交换，因此增加`n`从`6`到`300000`改变线性工作量但不改变逻辑。
