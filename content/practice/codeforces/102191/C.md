 ## 解决方案
 ## 问题理解

 我们对学生进行循环排列，因此第一个和最后一个条目形成的对也是相邻对。 我们需要产生另一个包含完全相同的学生的排列，但新圈中的每个相邻对在旧圈中必须是不相邻的。 实际的学生证对于构建并不重要。 重要的是每个学生在原来圈子中的位置。 

输入包含一个值 (n)，后跟 (1) 到 (n) 的排列 (a)。 我们可以打印任何满足条件的排列，或者当这样的循环排列不存在时打印（-1）。 由于 (n) 可以大到 (3 \times 10^5) 并且时间限制只有一秒，所以 (O(n^2)) 方法已经太慢了。 我们需要在基本上线性的时间内检查和重新安排学生。 存储排列和答案也需要保留 (O(n))。 

第一个小情况是（n=3）。 假设旧的安排是`1 2 3`。 每对学生在一个圆上相邻，因此没有一对学生可用于任何新的邻接。 正确的输出是`-1`。 

情况（n=4）是另一个微妙的不可能。 为了`1 2 3 4`，禁止对是`1-2`,`2-3`,`3-4`， 和`4-1`。 唯一允许的对是`1-3`和`2-4`。 由于新的圆形排列中的每个学生都需要两个邻居，因此这两个允许的对不能形成四顶点循环。 正确的输出是`-1`。 适用于较大 (n) 的构造不得在此盲目应用其最终交换。 

对于偶数 (n)，会出现不同的边缘情况。 为了`1 2 3 4 5 6`，简单地取偶数位置的所有元素，然后取奇数位置的所有元素即可给出`1 3 5 2 4 6`。 最后一对`6-1`被禁止，因为这些学生原本是相邻的。 构造中的最终交换是专门为了删除这个单一的坏边界对而存在的。 

## 方法

 直接的强力解决方案将枚举学生的每个排列并检查其 (n) 个循环相邻对。 对于每个候选者，检查正确性需要 (O(n))，而有 (n!) 个候选者。 因此，最坏情况的工作是 (O(n \cdot n!))。 即使在 (n=10) 时，这也意味着大约 (10 \cdot 10!= 36{,}288{,}000) 次邻接检查，并且实际约束达到 (3 \times 10^5)。 暴力方法仅作为理解定义的一种方式有用，而不是作为一种算法。 

关键的观察结果是学生证是无关紧要的。 假设原始位置编号为 (0,1,\ldots,n-1)。 当两个学生的原始位置相差 (1) 模 (n) 时，禁止他们完全成为邻居。 因此，我们需要构建位置的循环排序，其中连续位置永远不会处于圆形距离 (1) 处。 

自然的第一个尝试是一起采取相同的立场。 对于奇数 (n)，使用位置

 [
 0,2,4,n-1,1,3,5,n-2。 
]

 每个过渡，包括两组之间的过渡以及最终返回到第一个位置的过渡，都有圆形距离 (2)。 因此不会出现禁边。 

对于偶数 (n)，相同的排列有一个问题：最终位置 (n-1) 循环跟随位置 (0)，这是一种禁止的原始邻接。 交换最后两个元素会改变尾部

 [
 \l点,n-3,n-1
 ]

 到

 [
 \l点，n-1，n-3。 
]

 对于 (n\geq5)，所有新创建的过渡都具有与 (1) 不同的圆形距离。 这给出了直接的 (O(n)) 构造。 相同的奇偶校验和交换结构也出现在该问题的现有解决方案中。 

(n=3) 和 (n=4) 的不可能性，以及每个 (n\geq5) 的构造，给出了完整的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(n\cdot n!)) | (O(n)) | (O(n)) | 太慢了 |
 | 最佳 | (O(n)) | (O(n)) | (O(n)) | (O(n)) | 已接受 |

 ## 算法演练

 1. 如果(n<5)，则打印`-1`。 对于 (n=3)，每对都已经是相邻的。 对于(n=4)，原圆邻接图的补集仅由相反的两对组成，不能形成新的圆。 
2. 通过获取位置 (0,2,4,\ldots) 处的元素，然后获取位置 (1,3,5,\ldots) 处的元素来构建答案。 我们对原始圆距离为 (2) 而不是 (1) 的位置进行分组。 
3. 如果 (n) 为奇数，则保持此顺序不变。 在每个奇偶校验组内，连续位置相差 (2)。 边界过渡也具有圆形距离 (2)，因此每个新的相邻对都是安全的。 
4. 如果 (n) 为偶数，则交换构造数组的最后两个元素。 在交换之前，最终到第一次的转换是从位置（n-1）到位置（0），这是禁止的。 交换会删除该过渡，并将其替换为对于 (n\geq5) 来说圆距离至少为 (2) 的过渡。 
5. 打印生成的学生证。 由于该结构仅对现有元素进行重新排序，因此每个学生都只出现一次。 

### 为什么它有效

 不变量是构造的循环序列中每对连续位置的原始循环距离不同于(1)。 对于奇数 (n)，每个这样的距离恰好是 (2)。 对于偶数 (n)，初始奇偶校验结构在位置 (n-1) 和 (0) 之间只有一个禁止跃迁。 交换最后两个位置会删除该过渡，并且四个受影响的边界的距离为 (2)、(n-2)、(2) 和 (n-3)，在 (n\geq5) 时均与 (1) 不同。 由于原始邻接恰好是圆距离 (1)，因此每个新的邻接对都是有效的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    if n < 5:
        print(-1)
        return

    ans = a[::2] + a[1::2]

    if n % 2 == 0:
        ans[-1], ans[-2] = ans[-2], ans[-1]

    print(*ans)

if __name__ == "__main__":
    solve()
```第一片，`a[::2]`, 占据位置`0, 2, 4, ...`， 尽管`a[1::2]`采取立场`1, 3, 5, ...`。 将它们连接起来直接实现奇偶校验构造，无需推理学生 ID。 

对于奇数 (n)，不需要额外的工作。 结果答案的第一个和最后一个元素也位于原始圆形距离 (2) 处，因此圆形边界是安全的。 

对于偶数 (n)，`ans[-1]`和`ans[-2]`是奇偶校验构造的最后两个要素。 交换它们可以修复由未修改的奇偶校验排序造成的唯一错误边界。 支票`n % 2 == 0`在 (n<5) 检查之后执行，因此对于不可能的情况 (n=4) 永远不会尝试交换。 

不存在涉及大于 (n) 的值的算术，因此整数溢出在 Python 中不是问题。 该算法对包含 (n) 个元素的数组执行恒定次数的传递，这适用于 (n\leq3\times10^5)。

 ## 边缘情况

 对于 (n=3)，考虑精确输入```
3
1 3 2
```算法检查`n < 5`在构建任何东西和打印之前`-1`。 这是正确的，因为圆中的三个顶点形成了所有三个可能的对，因此没有任何对可以用作新的邻接。 

对于 (n=4)，考虑```
4
1 2 3 4
```算法再次打印`-1`。 唯一最初不相邻的对是`1-3`和`2-4`。 四人圈需要四个邻接边，但只存在这两个安全边。 一个粗心的实现，简单地应用偶数（n）交换会产生`1 3 4 2`，谁的一对`3-4`仍然是禁止的。 

对于奇数 (n=5)，考虑```
5
1 2 3 4 5
```奇偶校验构造产生`1 3 5 2 4`。 原来的位置序列是`0,2,4,1,3`。 圆形位置差全部为 (2) 模 (5)，包括从位置 (3) 到位置 (0) 的最终过渡。 因此，每个新的邻接都是安全的。 

对于偶数 (n=6)，从```
6
1 2 3 4 5 6
```奇偶校验安排是`1 3 5 2 4 6`，对应位置`0,2,4,1,3,5`。 最后的位置转换`5`回到位置`0`是被禁止的。 交换最后两个元素后，答案变成`1 3 5 2 6 4`，对应位置`0,2,4,1,5,3`。 新的圆形距离为 (2,2,3,4,2,3)，因此不良距离 (1) 消失了。 

对于最大边界尺寸（n=300000），相同的位置结构适用，没有任何特殊情况。 该算法仅构建两个切片并执行一次交换，因为 (n) 是偶数。 不需要搜索、回溯或二次验证，因此即使在最大允许的输入大小下，构造也保持线性。
