 ## 解决方案
 ## 问题理解

 我们有`n`学生围坐一圈。 输入排列给出了他们当前的循环顺序，因此除了数组中的每个连续对之外，最后一个和第一个学生也是邻居。 

我们需要对完全相同的学生进行另一个循环排序，以便每个新的相邻对在旧的排列中都是不相邻的。 由于学生是由排列表示的`1..n`，我们只需要改变现有数组元素的顺序。 

关键的难点是圆形边界。 如果新订单是`b[0], b[1], ..., b[n-1]`，我们必须检查每一对`b[i], b[i+1]`还有`b[n-1], b[0]`。 适用于线性部分但意外地将旧的第一个和最后一个邻居放在一起的构造是无效的。 

界限`n <= 3 * 10^5`排除任何尝试多种排列或执行重复昂贵搜索的情况。 一个`O(n^2)`方法已经需要大约`9 * 10^10`基本对检查的最大尺寸，远远超出一秒的限制。 我们需要一个只处理每个学生固定次数的结构，给出`O(n)`时间。 

天真的模式可能会错误处理三种特别小的情况。 为了`n = 3`，例如，输入`1 2 3`每一对都在原圆中相邻，因此不可能有新圆，正确的输出是`-1`。 为了`n = 4`， 输入`1 2 3 4`也是不可能的：每个学生只有一个可能的非邻居，即与他们相对的学生，因此允许的图由两条不相连的边组成，不能形成一个圆。 再次正确输出`-1`。 

另一个容易犯的错误是忘记了圆形闭合对。 为了`n = 5`有输入`1 2 3 4 5`, 安排`1 3 5 2 4`是有效的。 它在原始位置上的连续差都是二模五，包括最后一对`4,1`。 仅检查打印数组中相邻元素的结构可能会错过这个最终条件。 

## 方法

 最直接的方法是尝试对学生进行排列，直到满足条件为止。 每个排列都可以签入`O(n)`时间，因为正好有`n`要检查的圆形邻居对。 有`n!`排列，因此穷举搜索需要`O(n * n!)`最坏情况下的操作。 在最大约束下，这大约意味着`300000 * 300000!`配对检查，这是遥不可及的。 

有用的观察是实际的学生证并不重要。 重要的是每个学生在旧圈子里的地位。 当两个学生的旧位置不同时，他们将被禁止`1`模数`n`。 因此，我们可以先对旧位置进行排列，然后使用这些位置来获取学生 ID。 

分离禁止邻居的一种非常自然的方法是首先占据所有偶数位置，然后占据所有奇数位置。 在每个组内，连续位置相差两个，因此它们自动是安全的。 对于奇数`n`，两组之间的过渡和最终过渡到位置零也有两个模数的差异`n`，因此施工立即开始。 

对于甚至`n`，相同的结构有一个有问题的圆形边缘。 交换最后两个奇怪的位置可以解决这个问题，同时在其他地方保留安全差异。 这给出了恒定时间决策和线性结构。 

施工也立即解释了原因`n < 5`是不可能的。 为了`n = 3`和`n = 4`，原循环的补集不包含哈密顿循环。 开始于`n = 5`，奇偶校验构造明确地给出了一个。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(n * n!)`|`O(n)`| 太慢了 |
 | 优化施工|`O(n)`|`O(n)`| 已接受 |

 ## 算法演练

 1. 将旧的循环排列读入`a`。 我们使用零基头寸，因为其构建基于头寸平价。 
2.如果`n < 5`， 打印`-1`。 对于三个学生来说，每一对都已经是相邻的，而对于四个学生来说，唯一允许的边连接相对的学生，这不能形成一个包含所有人的循环。 
3. 通过走位构建新的序列`0, 2, 4, ...`首先，其次是职位`1, 3, 5, ...`。 我们故意将相同奇偶校验的位置分开，因为它们原来的圆距离是二而不是一。 
4. 如果`n`是奇数，保持该顺序不变。 偶数位置部分有二的差值，奇数位置部分也有二的差值，从最后一个偶数位置到第一个奇数位置的过渡有圆形距离二，最后奇数位置回到位置零也有圆形距离二。 
5.如果`n`是偶数，交换构造序列的最后两个元素。 在交换之前，唯一危险的边缘是从最终奇数位置开始的圆形连接`n - 1`回到零位置。 交换后，最后两个位置变为`n - 1, n - 3`，新的边界来自`n - 3`到零，其距离为三。 另一个受影响的边的距离为 2，因此两者都有效。 
6. 使用对应的条目将构建的职位转换回学生ID`a`，并按生成的循环顺序打印它们。 

### 为什么它有效

 不变量是构造顺序中的每一对连续位置都有一个不是 1 的原始圆距离。 对于奇数`n`，所有这样的距离都是两个。 对于甚至`n`，普通同奇偶校验转换的距离为二，两个奇偶校验组之间的转换的距离为三，交换对的转换距离为二，最后回到零的转换的距离为三。 由于旧的相邻对的特征是圆距离一，因此这些新的对以前都不是邻居。 每个原始位置都恰好出现一次，因此结果也是所有学生的排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    if n < 5:
        print(-1)
        return

    ans = []

    for i in range(0, n, 2):
        ans.append(a[i])

    for i in range(1, n, 2):
        ans.append(a[i])

    if n % 2 == 0:
        ans[-1], ans[-2] = ans[-2], ans[-1]

    print(*ans)

if __name__ == "__main__":
    solve()
```第一个循环收集每个偶数从零开始的位置。 第二个循环收集每个奇数位置。 它们一起包含每个学生一次，因此不需要单独的访问数组。 

对于奇数`n`，顺序已经正确了。 对于甚至`n`,`ans[-1]`和`ans[-2]`是最后两个奇数位置的学生，所以交换他们正是结构中描述的调整。 

不存在涉及大于的值的算术`n`，而且 Python 整数无论如何也不存在溢出问题。 关键边界由构造隐式表示，因此我们不需要单独的验证过程。 特别是，交换必须在附加两个奇偶校验组之后发生，因为它改变了循环序列的末尾。 

该解决方案不需要区分学生ID和职位。 自从`a`是一个排列，任何有效的位置排序立即成为有效的学生排序。 

## 工作示例

 对于示例 1，输入为：```
8
6 1 3 5 7 8 4 2
```该结构使用零基位置。 自从`n`是偶数，我们首先取所有偶数位置，然后取所有奇数位置，最后交换最后两个元素。 

| 步骤| 偶数职位| 奇怪的位置 | 当前序列|
 | --- | --- | --- | --- |
 | 开始|`[]`|`[]`|`[]`|
 | 添加事件 |`6 3 7 4`|`[]`|`6 3 7 4`|
 | 添加赔率 |`6 3 7 4`|`1 5 8 2`|`6 3 7 4 1 5 8 2`|
 | 交换最后两个 |`6 3 7 4`|`1 5 2 8`|`6 3 7 4 1 5 2 8`|

 最终的安排是`6 3 7 4 1 5 2 8`。 它的旧位置是`0, 2, 4, 6, 1, 3, 7, 5`，并且连续位置之间的每个循环差异都不是`1`也不`7`。 因此，没有新的相邻对是旧的相邻对。 官方示例有不同的有效安排，这是允许的，因为该问题接受任何解决方案。 

对于示例 2，输入为：```
3
1 3 2
```该算法在构建任何东西之前停止，因为学生少于五个。 

| 步骤|`n`| 决定| 输出|
 | --- | --- | --- | --- |
 | 读取输入|`3`|`n < 5`|`-1`|
 | 完成 |`3`| 无法施工 |`-1`|

 对于三个学生，原来的圆圈已经使每一对都相邻。 对于任何新的圆形边缘都没有可用的对，因此拒绝这种情况是正确的。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |`O(n)`| 每个输入位置都会追加一次，偶数情况会执行一次交换。 |
 | 空间|`O(n)`| 输入数组和输出数组各自包含`n`学生证。 |

 在`n = 3 * 10^5`，该算法仅对每个学生执行恒定量的工作，并存储一些线性大小的整数数组。 这完全符合 1 秒和 256 MB 的限制，而阶乘或二次方法无法处理最大输入。 

## 测试用例

 输出不是唯一的，因此测试应该验证生成的排列是一种排列，并且每个新的循环邻居对不是旧的循环邻居对。 将输出与一个固定的有效序列进行比较会错误地拒绝其他正确的解决方案。 

该问题保证输入是一个排列。 因此，“全等值”测试，例如`5 / 1 1 1 1 1`不是有效的 Codeforces 测试用例，不应用于测试提交的解决方案本身。 它只能测试格式错误的输入的行为，这超出了问题契约的范围。```python
import io
import sys

def solve_case(inp: str) -> str:
    data = list(map(int, inp.split()))
    n = data[0]
    a = data[1:]

    if n < 5:
        return "-1"

    ans = []

    for i in range(0, n, 2):
        ans.append(a[i])

    for i in range(1, n, 2):
        ans.append(a[i])

    if n % 2 == 0:
        ans[-1], ans[-2] = ans[-2], ans[-1]

    return " ".join(map(str, ans))

def valid(inp: str, out: str) -> bool:
    data = list(map(int, inp.split()))
    n = data[0]
    a = data[1:]

    result = out.split()

    if n < 5:
        return result == ["-1"]

    if len(result) != n:
        return False

    result = list(map(int, result))

    if sorted(result) != sorted(a):
        return False

    old_pos = {x: i for i, x in enumerate(a)}

    for i in range(n):
        x = old_pos[result[i]]
        y = old_pos[result[(i + 1) % n]]
        diff = (x - y) % n

        if diff == 1 or diff == n - 1:
            return False

    return True

# Provided sample 1
sample1 = """8
6 1 3 5 7 8 4 2
"""
out = solve_case(sample1)
assert valid(sample1, out), "sample 1"

# Provided sample 2
sample2 = """3
1 3 2
"""
assert solve_case(sample2) == "-1", "sample 2"

# Minimum possible n, impossible.
case3 = """4
1 2 3 4
"""
assert solve_case(case3) == "-1", "n=4 must be impossible"

# Smallest possible solvable case.
case4 = """5
1 2 3 4 5
"""
out = solve_case(case4)
assert valid(case4, out), "n=5 construction"

# Even n, catches the special final swap.
case5 = """6
1 2 3 4 5 6
"""
out = solve_case(case5)
assert valid(case5, out), "even n boundary"

# Large valid input, exercising the O(n) construction.
n = 300000
a = list(range(1, n + 1))
case6 = str(n) + "\n" + " ".join(map(str, a)) + "\n"
out = solve_case(case6)
assert valid(case6, out), "maximum n"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 |`3 / 1 3 2`|`-1`| 最小尺寸和完全不可能|
 |`4 / 1 2 3 4`|`-1`| 不太明显的不可能的情况
 |`5 / 1 2 3 4 5`| 任何有效的排列 | 最小可解实例和圆形边界 |
 |`6 / 1 2 3 4 5 6`| 任何有效的排列 | 均匀尺寸结构和最终交换|
 |`300000 / 1 2 ... 300000`| 任何有效的排列 | 最大约束和线性性能|

 ## 边缘情况

 对于`n = 3`， 考虑：```
3
1 3 2
```每对学生在原圈中都是相邻的。 学生`1`旁边是`3`和`2`， 学生`3`旁边是`1`和`2`，和学生`2`旁边是`3`和`1`。 一个新的圆需要三个允许的边，但实际上没有。 该算法检测到`n < 5`立即并打印`-1`。 

为了`n = 4`， 考虑：```
4
1 2 3 4
```唯一的非邻居`1`是`3`，唯一的非邻居`2`是`4`，反之亦然。 因此允许的图仅包含`1-3`和`2-4`。 它不能包含四顶点循环。 同样早`n < 5`检查打印是否正确`-1`。 

对于最小的可解情况，请考虑：```
5
1 2 3 4 5
```偶数位置部分是`1 3 5`，奇数位置部分是`2 4`，给予：```
1 3 5 2 4
```原来的职位是`0, 2, 4, 1, 3`。 圆差为`2, 2, 2, 2, 2`，因此每个新对在旧圆中相距两个位置。 特别是最后一对`4,1`是安全的，它锻炼了圆形边界。 

对于甚至`n`，需要进行特殊调整。 和：```
6
1 2 3 4 5 6
```奇偶校验分组最初给出：```
1 3 5 2 4 6
```决赛`6,1`禁止结对，因为这些学生原本是邻居。 交换最后两个元素后，我们得到：```
1 3 5 2 6 4
```旧职位是`0,2,4,1,5,3`。 圆差为`2,2,3,4,2,3`，其中没有一个是`1`或者`5`。 这种交换恰好改变了结构中否则会失败的部分。 

对于最大输入大小，相同的构造不依赖于学生 ID 的值，仅依赖于它们的位置。 和`n = 300000`，两个奇偶校验循环一起精确处理`300000`头寸，然后进行一次互换。 没有嵌套循环，也没有重复验证，因此即使在允许的最大输入下，运行时间也保持线性。
