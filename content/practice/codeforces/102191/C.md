 ## 解决方案
 ## 问题理解

 我们有一个由排列表示的圆形座位`a`的`1..n`。 学生们`a[i]`和`a[(i+1) mod n]`在旧的安排中是邻居。 我们需要打印相同学生的另一个排列，使得新圈中的每对邻居在旧圈中都不相邻。 打印排列的第一个和最后一个元素也是邻居，因此环绕对必须满足相同的条件。 原来的问题有`3 <= n <= 3 * 10^5`并要求任何有效的安排，或`-1`当不存在时。 引用turn0搜索0

 一旦知道旧的排列，学生证本身就不再重要。 重要的是每个学生在旧圈子里的地位。 如果两个旧位置更不用说阶乘了。 解决方案应该为每个学生做恒定量的工作，这意味着`O(n)`建设是自然的目标。 Python 可以轻松地在线性时间内处理几十万个整数，而尝试排列是完全不可行的。 

有两个不可能的小情况。 为了`n = 3`，每对学生在旧圈子中已经是相邻的，因此在新圈子中没有可以相邻的学生对。 例如，`3 / 1 2 3`具有唯一可能的圆对`{1,2}`,`{2,3}`， 和`{3,1}`，全部禁止，所以答案是`-1`。 为了`n = 4`，旧循环是`1-2-3-4-1`。 它的补集只包含边`1-3`和`2-4`，它们形成两个不相连的对，因此圆形排列是不可能的。 因此`4 / 1 2 3 4`还要求`-1`。 

第二个容易犯的错误是忘记了第一个和最后一个输出元素形成的对。 为了`n = 5`, 安排`1 3 5 2 4`有效：每个连续的对相差两个位置模五，包括`4`和`1`。 仅检查内部连续元素的构造可能会意外地接受无效的最终对。 

甚至值`n`需要单独调整。 为了`n = 6`，简单地采取奇数位置，然后是偶数位置给出`1 3 5 2 4 6`，但最后一对`6,1`由老邻居组成。 修正后的序列`1 3 5 2 6 4`也避免了这一对。 这就是偶数情况不能盲目使用与奇数情况相同的构造的原因。 

## 方法

 直接蛮力方法是生成学生的每个排列并检查其是否`n`循环邻居对都与旧邻居对不同。 这是正确的，因为会考虑所有可能的新座位，并且可以返回第一个有效的座位。 问题在于候选人的数量。 有`n!`排列，并检查一个候选者是否需要`Theta(n)`时间、给予`Theta(n * n!)`最坏情况下的操作。 在`n = 3 * 10^5`，甚至写下表达式`300000 * 300000!`已经描述了一个远远超出程序可以枚举的数字。 

有用的观察结果是我们根本不需要推理学生证。 将旧位置视为`0, 1, ..., n-1`。 当两个位置的圆距离为 时，禁止在答案中连续。`1`。 因此，我们只需要对每个连续对具有不同距离的位置进行排列`1`。 

对于奇数`n`，使用从零开始的索引，获取所有偶数索引位置，然后获取所有奇数索引位置。 在基于一的位置中，这是`1, 3, 5, ..., 2, 4, 6, ...`。 在每个组内，连续位置相差两个。 在组之间的边界处，差异也至少为二模`n`因为`n`很奇怪。 最后一对具有相同的属性。 

对于甚至`n >= 6`，相同的序列恰好有一个有问题的转换，即从最终偶数位置回到第一个位置的环绕。 交换最后两个元素可以修复它。 等价地，对于`n = 6`我们得到`1 3 5 2 6 4`，并且对于`n = 8`我们得到`1 3 5 7 2 8 6 4`。 现在，每个相邻对的旧位置距离至少为 2。 

此构造独立于排列中存储的值。 我们构建所需的旧位置顺序，然后输出占据这些位置的学生。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力 |`O(n * n!)`|`O(n)`| 太慢了|
 | 最佳 |`O(n)`|`O(n)`| 已接受 |

 ## 算法演练

 1. 阅读旧的循环排列`a`。 我们将构建其索引的排序，而不是尝试直接操作学生 ID。 

2.如果`n < 5`， 打印`-1`。 为了`n = 3`每对都是禁止的，而对于`n = 4`唯一允许的对形成两个不相连的边，因此这两种情况都不能形成哈密顿循环。 

3.如果`n`为奇数，收集位置`0, 2, 4, ...`首先，其次是职位`1, 3, 5, ...`。 在基于一的表示法中，这是`1, 3, 5, ..., 2, 4, 6, ...`。 

4. 如果`n`是偶数，构建相同的序列并交换其最后两个位置。 交换消除了由未修改的奇偶排序创建的唯一有问题的环绕转换。 

5. 将构建的职位顺序转换为学生ID，取`a[position]`对于每个选定的位置。 按顺序打印这些 ID。 自从`a`是一个排列，每个学生都只出现一次。 

原理：在奇数位置组和偶数位置组内，连续的旧位置正好相差两倍，因此这些学生以前不是邻居。 对于奇数`n`，两个边界过渡也具有至少二的圆距离。 对于甚至`n`，交换最后两个位置会更改两个受影响的过渡，以便它们的圆形距离也至少为 2。 该结构是所有旧位置的排列，因此不会丢失或重复学生。 因此，每对新的圆形邻居在旧座位上都是不相邻的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve(data=None):
    if data is None:
        n = int(input())
        a = list(map(int, input().split()))
    else:
        it = iter(data.split())
        n = int(next(it))
        a = [int(next(it)) for _ in range(n)]

    if n < 5:
        return "-1\n"

    order = list(range(0, n, 2)) + list(range(1, n, 2))

    if n % 2 == 0:
        order[-1], order[-2] = order[-2], order[-1]

    ans = [a[i] for i in order]
    return " ".join(map(str, ans)) + "\n"

if __name__ == "__main__":
    sys.stdout.write(solve())
```第一个分支立即处理两个不可能的尺寸。 无需检查实际排列，因为可行性`n = 3`和`n = 4`仅取决于圆形结构。 

这`order`表达式创建所有从零开始的偶数位置，后跟所有从零开始的奇数位置。 使用索引而不是值是关键的实现细节。 输入排列可以包含任意顺序的学生，但其位置始终具有相同的邻接结构。 

对于甚至`n`,`order[-1]`和`order[-2]`是构造序列的最后两个元素。 交换这两者正是偶数情况所需的调整。 Python 的负索引使其与实际值无关`n`，以及更早的`n < 5`检查保证这些位置存在。 

最后，`a[i]`将每个旧位置映射回其学生 ID。 自从`a`保证是一个排列，这会产生另一个排列，而不需要访问的数组或集合。 

不需要涉及大乘积的整数运算，因此整数溢出不是问题。 每个学生都会多次接触到构建和最终输出。

## 边缘情况

 对于`n = 3`， 考虑`3 / 1 2 3`。 旧的圆形边缘是`{1,2}`,`{2,3}`， 和`{3,1}`，涵盖了每一对可能的学生。 该算法立即打印`-1`，避免任何构建不可能循环的尝试。 

为了`n = 4`， 考虑`4 / 1 2 3 4`。 唯一的非老邻居对是`1-3`和`2-4`。 新的圆形座椅需要四个允许的边缘，而这两个允许的边缘是断开的，因此不存在解决方案。 这`n < 5`条件正确打印`-1`。 

对于奇数`n = 5`， 考虑`5 / 1 2 3 4 5`。 持仓顺序为`0,2,4,1,3`，对应于`1 3 5 2 4`。 内部差异是两个位置，而环绕对`4,1`还有圆距二。 因此，该结构在处理边界时无需进行任何特殊修正。 

对于甚至`n = 6`，初始奇偶顺序为`1 3 5 2 4 6`。 它的最后一对`6,1`被禁止是因为那些学生是老圈子里的邻居。 交换最后两个位置给出`1 3 5 2 6 4`。 受影响的转换变为`2-6`和`4-1`，其圆形距离分别为 4 和 3，因此环绕违规消失了。 

实际的学生标签可以是完全任意的。 例如，样本排列开始于`6`而不是`1`，但该建筑仍仅在其位置上运行。 这就是为什么不需要按学生值进行排序、映射或搜索 ID 的原因。
