 ## 解决方案
 ## 问题理解

 我们的学生人数是偶数，每两个学生就绑在一起成为一对友谊。 最后一行必须是双调的：对于某些前缀，高度可能保持不变或增加，之后它们可能保持不变或减少。 属于一对的两名学生必须占据连续的位置，但在一对内任何顺序都是允许的。 

对于每个友谊对，对其两个高度进行内部排序，并将其表示为一个区间`[l, r]`， 在哪里`l`是个子矮的学生，并且`r`是个子较高的学生。 任务是对这些间隔进行排序并选择它们的方向，以便生成的序列是双音的。 

关键的观察是，一张有效的图片可以被视为两个独立的间隔链。 一条链放在递增的一侧，每个区间写为`l, r`。 另一条链放置在递减侧，间隔按相反顺序取，并写为`r, l`。 

当第一个间隔在第二个间隔开始之前完成时，两个间隔可以完全属于同一个链。 为了`[l1, r1]`其次是`[l2, r2]`， 这意味着`r1 <= l2`。 平等是允许的，因为图片是非递减或非递增的，而不是严格单调的。 

约束条件`n <= 3 * 10^5`最多给出`150000`友谊对。 二次算法已经执行了大约`2.25 * 10^10`最坏情况下的配对比较，这对于 2 秒的限制来说太长了。 我们需要一个`O(n log n)`解决方案，其中对数因子来自排序。 

有几种容易被忽略的边界情况。 首先，仅接触的间隔是兼容的。 例如，```
3
1 3
3 5
5 7
```可以生产`1 3 3 5 5 7`，因为允许相邻高度相等。 粗心的实现使用`r < l`会错误地拒绝它。 

其次，相同的高度不会造成特别的困难。 为了```
4
3 3
3 3
```答案`3 3 3 3`是有效的。 假设每个间隔都具有正长度的代码将不必要地失败。 

第三，三个相互重叠的对不能仅放入两个单调边。 例如，```
6
1 10
2 9
3 8
```是不可能的，因为每对都与其他对重叠。 贪心算法在处理时必须检测到两条可用链都被阻塞`[3, 8]`。 

## 方法

 蛮力方法将每对友谊对视为一个块，尝试每一个排列`n/2`块，并尝试每个块的两个方向。 有`(n/2)! * 2^(n/2)`块的可能排列及其方向。 检查一项安排需要`O(n)`时间，所以最坏情况下的总工作量是`O(n * (n/2)! * 2^(n/2))`。 在最大输入大小下，这大约意味着`300000 * 150000! * 2^150000`身高比较，这是完全不可行的。 

蛮力之所以有效，是因为它明确地探索了递增部分和递减部分之间的每一种可能的划分。 它失败了，因为可能的大宗订单数量呈阶乘增长。 

有用的结构观察是我们实际上不需要首先确定峰值。 一旦每对都写成一个区间`[l, r]`，考虑将几对放在增加的一侧。 它们的间隔必须从左到右出现且不重叠，因此它们形成满足要求的链`r_previous <= l_current`。 如果我们从峰值到末端读取下降侧，则情况完全相同。 

因此，整个问题变成：将所有区间划分为至多两个不重叠的链。 

找到这样一个分区后，假设有一条链`[l1, r1], [l2, r2], ...`和`r1 <= l2 <= ...`。 我们直接写出来，给`l1, r1, l2, r2, ...`这是非递减的。 

对于另一条链，假设其间隔按升序排列为`[a1, b1], [a2, b2], ...`。 

我们反转链条并反转每一对，给出`b_k, a_k, ..., b2, a2, b1, a1`。 

该序列是非递增的。 在两条链之间的边界处，一个值后面跟着另一个值。 如果左边的值较小，则峰值位于右侧； 如果更大，则峰值位于左侧。 无论哪种方式，完整的序列都是双音的。 

剩下的问题是将间隔有效地划分为两个链。 按左端点对它们进行排序。 处理区间时`[l, r]`，每个链由其最后一个区间的右端点表示。 如果一条链的最后一个右端点最多为`l`。 

如果两条链都可用，我们将新间隔放入最后一个右端点较大的链中。 这为未来的间隔保留了具有较小端点的链，为未来的间隔提供了最大可能的灵活性。 如果只有一条链可用，我们必须使用它。 如果两条链都不可用，则三个区间在当前位置重叠，因此两条链不足并且不存在答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |`O(n * (n/2)! * 2^(n/2))`|`O(n)`| 太慢了 |
 | 最佳|`O(n log n)`|`O(n)`| 已接受 |

 ## 算法演练

 1. 将每对友谊对转换为一个区间`[l, r]`和`l <= r`。 两个学生的原始顺序无关紧要，因此在构建链条时只有较短和较高的高度才重要。 
2. 对所有区间进行递增排序`l`， 使用`r`如果需要，可作为辅助键。 这意味着当`[l, r]`处理后，同一链中可能位于其之前的每个间隔都已被考虑。 
3.维护两条链。 对于每个链，存储其最后一个间隔的右端点。 最初两个端点都是负无穷大，因为任一链都可以接受第一个间隔。 
4. 对于当前间隔`[l, r]`，检查哪些链满足`last_right <= l`。 这样的链可以安全地附加间隔而不破坏单调性。 
5. 如果两条链条都可用，请选择较大的链条`last_right`。 较小的端点对于未来的间隔更有用，因此保持它不变可以为剩余的间隔提供更多的空间。 
6. 如果只有一条链可用，则在此处附加间隔。 没有有用的替代方案，因为将其放入另一个链中会立即产生重叠。 
7. 如果两条链都不可用，则返回`-1`。 两条链都已结束`l`，因此当前区间与每个链中的区间重叠。 三个重叠间隔需要三个链，而有效的图片仅提供峰的两侧。 
8. 存储分配给每个链的区间索引。 分配所有间隔后，按排序顺序输出第一个链：`l, r`对于每个间隔。 
9. 以相反的顺序输出第二条链，将每个区间写为`r, l`。 现在，它的高度在接近图片末尾时逐渐减小。 
10. 连接两个序列。 每个友谊对保持相邻，第一部分不减少，第二部分不增加。 

### 为什么它有效

 不变的是，在处理按以下方式排序的间隔的任何前缀之后`l`，每个维护的链都是有效的非重叠链，并且在所有贪婪选择中，该算法保留尽可能小的可用链端点。 当两个链都可以接受一个间隔时，将其分配给具有较大端点的链，使较小的端点保持不变，这只会使未来的间隔更容易放置。 如果两个链都不能接受该间隔，则每个可能的双链分区必须已经有一个延伸过去的间隔`l`在两个链中，因此当前间隔不能分配到任何地方。 因此，当存在双链分区时，贪婪过程就会成功。 

两链分区也正是有效图片所需要的。 从左到右读取增加的一侧给出一个不重叠的区间链，而从峰值向外读取减少的一侧给出另一个。 相反，两个这样的链总是可以通过一个向前写入另一个向后写入来组合成双调序列。 它们之间的边界可以继续增加或开始减少，因此两个位置之一必然是有效峰值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    m = n // 2

    pairs = []
    for idx in range(m):
        a, b = map(int, input().split())
        if a <= b:
            pairs.append((a, b, idx))
        else:
            pairs.append((b, a, idx))

    pairs.sort()

    chains = [[], []]
    last = [-1, -1]

    for l, r, idx in pairs:
        can0 = last[0] <= l
        can1 = last[1] <= l

        if not can0 and not can1:
            print(-1)
            return

        if can0 and can1:
            if last[0] >= last[1]:
                c = 0
            else:
                c = 1
        elif can0:
            c = 0
        else:
            c = 1

        chains[c].append((l, r))
        last[c] = r

    ans = []

    for l, r in chains[0]:
        ans.append(l)
        ans.append(r)

    for l, r in reversed(chains[1]):
        ans.append(r)
        ans.append(l)

    print(*ans)

if __name__ == "__main__":
    solve()
```输入循环首先对每个友谊对进行标准化。 无需保留原始配对索引，因为输出仅要求身高，而不要求学生身份。 

排序后，`last[0]`和`last[1]`是两条链中最后间隔的右端点。 条件`last[c] <= l`正是非重叠条件。 使用`<=`，而不是`<`，处理接触间隔，例如`[1, 3]`和`[3, 5]`。 

When both chains are available, comparing`last[0]`和`last[1]`选择较大的端点。 这是贪婪的选择，为以后的时间间隔保留较小的端点。 分配存储为实际的归一化间隔，因此重建不需要返回排序的输入。 

第一条链直接发射。 由于其间隔按其左端点排序并且成对不重叠，因此其序列是非递减的。 第二条链向后遍历，每对都以较高然后较短的方式发出。 这使得整个部分不增加。 

Python 整数具有任意精度，因此高度限制`10^9`不需要特殊的整数处理。 

## 工作示例

 对于提供的样本，标准化间隔为`[1, 3]`,`[2, 4]`,`[6, 7]`， 和`[5, 7]`。 它们已经按左端点排序。 

| 间隔 | 链0结束| 链条1端| 选择链条|
 | --- | --- | --- | --- |
 |`[1, 3]`|`-1`|`-1`| 0 |
 |`[2, 4]`|`3`|`-1`| 1 |
 |`[5, 7]`|`3`|`4`| 1 |
 |`[6, 7]`|`3`|`7`| 0 |

 第一条链变为`[[1,3], [6,7]]`, 生产`1 3 6 7`。 第二个变成`[[2,4], [5,7]]`; 反转它并反转每对给出`7 5 4 2`。 组合序列为`1 3 6 7 7 5 4 2`，这是一个有效的答案。 示例输出使用不同的有效分区，同样可以接受。 

对于第二个例子，考虑```
6
1 3
3 5
5 7
```间隔已经不重叠，因此贪心算法可以将所有三个保持在一条链中。 

| 间隔 | 链0结束| 链条1端| 选择链条|
 | --- | --- | --- | --- |
 |`[1,3]`|`-1`|`-1`| 0 |
 |`[3,5]`|`3`|`-1`| 0 |
 |`[5,7]`|`5`|`-1`| 0 |

 结果是`1 3 3 5 5 7`。 每对都保持相邻，并且序列是非递减的。 相等性检查使接触端点有效。 

对于不可能的情况，```
6
1 10
2 9
3 8
```痕迹是：

 | 间隔 | 链0结束| 链条1端| 选择链条|
 | --- | --- | --- | --- |
 |`[1,10]`|`-1`|`-1`| 0 |
 |`[2,9]`|`10`|`-1`| 1 |
 |`[3,8]`|`10`|`9`| 无 |

 在`[3,8]`，之前的两个区间都超出了`3`，所以两个链都不能接受它。 算法打印`-1`。

 至多有`150000`配对、排序`150000`在 Python 中，间隔很容易处于 2 秒限制的预期范围内，而内存使用量保持线性且远低于 256 MB。 

## 测试用例

 下面的测试工具通过函数接口使用相同的算法并验证返回的排列，而不是与一种固定排列进行比较。 这是必要的，因为该问题接受任何有效的图片。```python

import io

def solve_data(inp: str) -> str:
    data = inp.split()
    it = iter(data)

    n = int(next(it))
    m = n // 2

    pairs = []
    for idx in range(m):
        a = int(next(it))
        b = int(next(it))
        if a <= b:
            pairs.append((a, b, idx))
        else:
            pairs.append((b, a, idx))

    pairs.sort()

    chains = [[], []]
    last = [-1, -1]

    for l, r, idx in pairs:
        can0 = last[0] <= l
        can1 = last[1] <= l

        if not can0 and not can1:
            return "-1\n"

        if can0 and can1:
            c = 0 if last[0] >= last[1] else 1
        elif can0:
            c = 0
        else:
            c = 1

        chains[c].append((l, r))
        last[c] = r

    ans = []

    for l, r in chains[0]:
        ans.extend((l, r))

    for l, r in reversed(chains[1]):
        ans.extend((r, l))

    return " ".join(map(str, ans)) + "\n"

def run(inp: str) -> str:
    return solve_data(inp)

def valid_output(inp: str, out: str) -> bool:
    tokens = inp.split()
    n = int(tokens[0])
    vals = list(map(int, tokens[1:]))

    if out.strip() == "-1":
        return False

    ans = list(map(int, out.split()))
    if len(ans) != n:
        return False

    # Check that every input pair appears as adjacent heights.
    pairs = []
    for i in range(n // 2):
        a = vals[2 * i]
        b = vals[2 * i + 1]
        pairs.append(tuple(sorted((a, b))))

    used = [False] * (n // 2)
    for i in range(0, n, 2):
        p = tuple(sorted((ans[i], ans[i + 1])))
        found = False
        for j, q in enumerate(pairs):
            if not used[j] and p == q:
                used[j] = True
                found = True
                break
        if not found:
            return False

    # Check bitonicity.
    direction = 1
    for i in range(1, n):
        if direction == 1:
            if ans[i] < ans[i - 1]:
                direction = -1
        else:
            if ans[i] > ans[i - 1]:
                return False

    return True

 ## 边缘情况

 对于最小尺寸的情况```
2
1000000000 1
```只有一个区间，`[1,1000000000]`。 第一个链最初可用，因此该对被放置在那里并发出为`1 1000000000`。 单个对始终是有效的双调序列。 

对于同等高度，```
8
3 3
3 3
3 3
3 3
```每个区间是`[3,3]`。 每个区间都可以附加到任一链，因为`3 <= 3`。 贪婪过程不断将它们放入可用的链中，结果序列完全由`3`s。 增加和减少条件同时成立。 

对于触摸间隔，```
6
1 3
3 5
5 7
```第一个间隔结束于`3`，这正是第二个的左端点。 条件`last_right <= l`接受它，因此间隔形成一条链。 生成的序列是`1 3 3 5 5 7`，证明了为什么严格的不平等是不正确的。 

对于不可能的情况，```
6
1 10
2 9
3 8
```第一对占据链 0，为其提供端点`10`。 第二对无法容纳链 0，因为`10 > 2`，所以它转到链 1 并给它端点`9`。 什么时候`[3,8]`到达时，两个端点都大于`3`。 两个链都不能接受它，因此算法正确打印`-1`。 

对于最大尺寸的情况，所有`150000`间隔是不相交的，并按其左端点排序。 贪婪传递将它们分配给一条链，最终的构造产生所有`300000`有效单调序列中的高度。 昂贵的部分是排序，这需要`O(n log n)`，而结构本身是线性的。
