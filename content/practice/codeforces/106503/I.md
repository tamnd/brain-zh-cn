 ## 解决方案
 ## 问题理解

 我们得到了一个由黑色和白色单元格组成的二进制网格。 每个测试用例提供一个$n \times m$矩阵，其中每个单元格要么是黑色（`*`）或白色（`.`）。 任务是计算该网格有多少个子矩形形成称为“I”的特殊图案。 

如果子矩形满足严格的结构条件，则它是有效的。 它的高度和宽度都至少为3，宽度为奇数，中间一列是全黑的，顶行和底行都是全黑的。 矩形内的所有其他单元格都无关紧要，并且可以是任一颜色。 

因此，每个有效的“I”都是通过选择一个矩形并检查三个结构约束来确定的：全黑顶行、全黑底行以及与矩形垂直中点对齐的全黑中心列。 

整个测试用例的约束条件很大，总网格大小可达$2 \cdot 10^5$。 这立即排除了任何按矩形检查的方法。 即使迭代所有子矩形也是不可能的，因为一个矩形中的矩形数量$n \times m$网格是$O(n^2 m^2)$，即使对于小网格来说，这也远远超出了限制。 

天真的尝试可能会尝试扩展每个可能的中心列，然后向外扫描有效的顶行和底行。 这已经存在风险$O(nm^2)$或者更糟。 

当一行全黑时，会出现微妙的边缘情况。 例如，在如下网格中：```
*****
*****
*****
```每个以任何列为中心的奇数宽度子矩形都可能形成许多有效的“I”形状，具体取决于垂直对齐方式。 矩形的强力枚举可能会多算或少算，具体取决于检查约束的方式，因为有效性取决于完整的行和列覆盖，而不是局部段。 

另一个棘手的情况是中间的列除了一些间隙之外几乎完全是黑色的。 简单的算法可能会假设局部连续性就足够了，但即使是单个白色单元格也会破坏将其作为中心列的所有矩形。 

关键的困难在于有效性取决于全局行和列属性，而不仅仅是局部子矩阵检查。 

## 方法

 强力解决方案将枚举所有子矩形。 对于每个矩形，我们将检查其宽度是否为奇数且至少为 3、其顶行和底行是否全黑、中间列是否全黑。 检查单个矩形的成本$O(\text{area})$在最坏的情况下，如果直接完成，或者$O(n)$如果使用每行和每列的前缀和进行预处理。 即使经过预处理，也有$O(n^2 m^2)$矩形，这使得总成本不可行。 

关键的观察结果是，有效“I”的结构完全由中心列和两个边界行决定。 一旦我们修复了中心柱$c$，唯一有效的矩形是那些左右边界对称的矩形$c$，其顶行和底行满足全黑约束，而列$c$在该垂直跨度上持续黑色。 

这将问题转化为对每一列进行计数$c$, 有多少对行$(r_1, r_2)$存在使得柱的段$c$它们之间是全黑的，并且两行在相应的水平跨度上都有全黑的覆盖。 我们不考虑矩形，而是反转视角：我们锚定在中心列上并展开有效的垂直线段，然后与行约束相交。 

为了提高效率，我们为每行预先计算包含每个单元格的最长连续黑色段，并为每列预先计算连续的黑色运行。 这使我们能够知道，对于选定的中心列，在保持有效性的同时我们可以向左和向右延伸多远。 

然后我们独立处理每一列。 对于每一列，我们垂直处理连续的黑色段，并使用两指针或前缀计数策略将它们与行约束结合起来。 这将问题从 4D 枚举简化为对列和行的线性扫描。

 ## 算法演练

 我们将网格重组为描述有效扩展可能的位置的结构，然后计算以每列为中心的所有有效“I”形状。 

1. 对于每一行，计算连续的长度`*`段。 这告诉我们，对于任何单元格，在保持在全黑行段内的同时，我们可以向左和向右延伸多远。 这是至关重要的，因为任何有效“I”的顶行和底行在所选矩形宽度上都必须是全黑的。 
2. 对于每一列，计算最大连续垂直线段`*`。 每个这样的段代表使用该列的“I”的所有可能的中心列候选者。 有效的中心列必须在矩形的顶部和底部之间连续保持黑色。 
3. 对于每一列，收集所有垂直段并将每个段解释为可能的中间列跨度池。 一段长度内$L$， 有$\frac{L(L-1)}{2}$顶行和底行的可能选择。 
4. 对于垂直黑色段内的每个候选行对，确定我们可以从中心列向左和向右扩展多远。 这受到行方向黑色游程的限制：矩形宽度必须以两个选定行的最小水平游程长度为界。 
5. 对于固定的中心列，我们将每个有效行转换为允许宽度的区间。 然后我们计算有多少行对产生一致的宽度约束。 这是通过对约束进行排序并扫描可能的宽度来处理的。 
6. 将所有列的贡献相加以获得最终答案。 

### 为什么它有效

 每个有效的“I”都有一个独特的中心列。 一旦该列被固定，有效性就会分解为对垂直连续性（列必须是黑色）和水平完整性（顶部和底部行必须在所选宽度上全黑）的独立约束。 这些约束不会在不同的列之间相互作用，因此每列计数可以划分解决方案空间，而不会重叠或遗漏。 

该算法确保每个计数对恰好对应一个有效矩形，并且每个有效矩形通过其中心列精确计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, m = map(int, input().split())
        g = [input().strip() for _ in range(n)]

        # left/right consecutive stars in each row
        left = [[0]*m for _ in range(n)]
        right = [[0]*m for _ in range(n)]

        for i in range(n):
            for j in range(m):
                if g[i][j] == '*':
                    left[i][j] = left[i][j-1] + 1 if j else 1
            for j in range(m-1, -1, -1):
                if g[i][j] == '*':
                    right[i][j] = right[i][j+1] + 1 if j+1 < m else 1

        # vertical runs in each column
        ans = 0
        for j in range(m):
            i = 0
            while i < n:
                if g[i][j] != '*':
                    i += 1
                    continue
                start = i
                min_width = float('inf')

                while i < n and g[i][j] == '*':
                    min_width = min(min_width, left[i][j] + right[i][j] - 1)
                    i += 1

                length = i - start
                if length >= 3:
                    # count pairs of rows in segment
                    cnt_pairs = length * (length - 1) // 2
                    # each pair contributes based on minimal width constraint
                    ans += cnt_pairs * (min_width // 2 - 1 if min_width >= 3 else 0)

        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先将每一行预处理为两个数组，这两个数组存储黑色段从每个单元向左和向右延伸的距离。 这允许恒定时间查询以给定列为中心的任何行段的最大可能水平宽度。 

然后对每一列进行独立处理。 我们扫描黑色单元格的连续垂直部分。 在每个段内，任何一对行都可以作为潜在“I”的顶部和底部，但前提是该列在整个间隔中保持黑色，这是通过结构保证的。 

对于每个这样的段，我们计算段中行之间的最小允许宽度。 该值限制矩形的宽度，同时仍保持顶行和底行全黑。 然后，我们将行对的数量乘以从此约束导出的有效宽度的数量。 

重要的微妙之处在于，宽度约束源自行式扩展限制，因此我们将段压缩为单个最小值，而不是每对重新计算。

 ### 示例 1

 输入：```
3 5
*****

*****
```我们首先计算行式展开。 第一行和第三行在每个位置允许全宽度 5，而第二行限制可用宽度。 

对于每一列，我们检查垂直段：

 | 专栏 | 分段行| 线段长度 | 最小宽度|
 | ---| ---| ---| ---|
 | 1 | [0..2]| 3 | 5 |
 | 2 | [0..2]| 3 | 5 |
 | 3 | [0..2]| 3 | 3 |
 | 4 | [0..2]| 3 | 5 |
 | 5 | [0..2]| 3 | 5 |

 每个段的产量$\binom{3}{2} = 3$行对。 第 3 列的宽度约束略有不同，但都满足有效“I”形状的最低要求。 将所有列的贡献相加得出最终计数。 

此示例演示了即使网格看起来均匀，多个列如何独立贡献有效的结构。

 ## 边缘情况

 全黑网格是最密集的情况。 每列形成一个垂直长度段$n$，并且每对行都是有效的。 该算法通过将每个段折叠成等于全行宽度的单个最小宽度来处理此问题，从而产生最大贡献而无需每对重新计算。 

具有孤立星星的高度稀疏网格将垂直线段分成许多长度为 1 或长度为 2 的块。 由于有效的“I”要求高度至少为 3，因此这些段将被自动忽略，因为算法在形成行对之前仅对足够长度的段进行计数。 

类似棋盘的图案导致每个列段都很短，并将所有贡献减少到零。 预处理仍然正确地识别出没有垂直段可以满足最小高度约束，从而防止误报。
