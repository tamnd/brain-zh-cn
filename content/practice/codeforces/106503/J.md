 ## 解决方案
 ## 问题理解

 我们给出了一个大小为的矩形网格$n \times m$。 每个单元被视为一个单位正方形，并且每个正方形被分配四个可能的方向之一，对应于网格上的四个方向之一。 这些方向描述了正方形如何通过选定的边“连接”到相邻的单元格。 

通过为所有单元选择方向，我们有效地在网格上构建了一个有向结构，其中仅允许相邻单元之间存在邻接。 一些方向的选择形成封闭循环，包围网格上的区域。 每个闭环对应一个有界区域，这个区域的“面积”就是它包含的晶胞数量。 

任务是为所有单元分配方向，使得所有封闭区域形成的总封闭面积尽可能大。 如果无法形成闭合区域，则答案为零。 

总体而言，约束很严格：虽然最多可以有 1500 个测试用例，但所有测试用例的总和$n \times m$他们之间最多是$10^6$。 这立即表明任何解决方案都必须在每个测试用例的网格大小上是线性的，或者在最坏的情况下在所有测试用例中总体上是线性的。 任何平方项$n \times m$会太慢了。 

一个微妙的点是，我们没有被要求找到单个循环或单个区域，而是要求最大化总封闭面积。 这将问题从局部循环检测转移到一种配置的全局构建，该配置最大化参与至少一个封闭边界结构的细胞数量。 

一些边缘情况阐明了该行为：

 当$n = 1$和$m = 1$，只有一个单元格。 单个节点中不可能存在没有自环的循环，而网格结构不允许这样的构造，所以答案必须是0。 

当$n = 1$和$m = 2$，我们只有一行两个细胞。 任何方向分配只能指向左或右，这不可避免地导致开放端而不是闭环。 如此看来，答案还是0。 

当$n = 2$和$m = 2$，通过排列方向使所有四个单元格围绕周边形成一个环，循环就成为可能。 这会产生区域 4 的单个封闭区域。此示例表明关键阈值是网格是否可以支持循环结构。 

这些例子表明，问题归结为确定我们是否可以嵌入一个覆盖网格的循环，如果可以，它可以有多大。 

## 方法

 直接强力方法将尝试为每个单元分配四个方向之一并模拟生成的有向图结构，然后计算所有周期并测量总封闭面积。 由于有$4^{n \cdot m}$配置，即使对于非常小的网格，这也是完全不可行的。 即使我们限制自己检查单个配置，检测所有封闭区域也需要对整个网格进行图形遍历，即$O(nm)$，因此对所有配置进行暴力破解是没有希望的。 

关键的观察是网格结构是高度规则的，唯一重要的是我们是否可以将单元排列成单个全局循环结构，该结构仅使用每个单元一次。 如果存在这样的结构，那么每个单元都位于一致的封闭系统的边界上，并且实现了最大的封闭面积。 

这将问题简化为经典的图构造问题：我们能否形成一个循环，在网格邻接图中仅访问一次所有单元格？ 这相当于询问网格图是否存在哈密顿环。 

矩形网格的一个众所周知的属性是，当且仅当两个维度都大于 1 时，才存在哈密顿环。如果任一维度为 1，则网格退化为路径，无法形成环。 如果两个维度都至少为 2，我们可以以来回的方式蜿蜒穿过网格，并将两端连接起来形成一个完整的循环。 

一旦存在这样的循环，每个单元都是边界结构的一部分，因此最大封闭面积等于单元总数$n \cdot m$。

 ## 算法演练

 该解决方案简化为对网格尺寸的简单结构检查。 

1. 阅读$n$和$m$对于每个测试用例。 

我们只需要这两个值，因为网格结构完全取决于其形状，而不取决于任何额外的权重或标签。 
2. 检查任一维度是否为 1。 

如果$n = 1$或者$m = 1$，网格是单行或单列，这意味着它形成了线性的单元链。 线性链无法形成任何闭合环，因此无法创建封闭区域。 
3. 如果两者都$n > 1$和$m > 1$， 返回$n \cdot m$。 

在这种情况下，网格包含足够的连接性来嵌入覆盖所有单元的循环。 我们可以构造一个蛇形遍历，它只访问每个单元一次，然后使用网格的邻接结构关闭循环。 
4. 打印每个测试用例的结果。 

### 为什么它有效

 网格可以看作是一个无向图，其中每个单元与其最多四个邻居相连。 一个封闭区域对应于该图结构中的一个环。 最大化封闭面积意味着最大化位于循环内的顶点数量。 最好的情况是每个顶点都是单个循环的一部分。 

当两个维度都超过 1 时，矩形网格恰好支持哈密顿循环。在这种情况下，所有$n \cdot m$顶点可以包含在一个循环中，这意味着每个单元都对封闭结构做出贡献。 当一维为1时，根本不存在环，因此无法形成正区域。 

这个结构性质完全决定了答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    if n == 1 or m == 1:
        print(0)
    else:
        print(n * m)
```该实现直接应用上面导出的尺寸检查。 每个测试用例在恒定时间内独立处理。 

唯一的微妙之处是确保跨多个测试用例的正确解析。 由于总和为$n \cdot m$的边界是$10^6$，即使大量的测试用例在简单的输入处理下仍然保持高效。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        if n == 1 or m == 1:
            out.append("0")
        else:
            out.append(str(n * m))
    return "\n".join(out)

# provided samples (interpreted)
assert run("2\n2 5\n4 4\n") == "10\n16"

# larger rectangle

 ## 边缘情况

 对于 1 x 1 网格，算法立即返回 0，因为循环形成和封闭区域至少需要 2 x 2 结构。 不存在能够闭合环路的邻接结构。 

对于 1 × m 的网格，该算法再次返回 0。即使有多个单元，每个路径都是线性的，并且不能自行闭合。 同样的推理对称地适用于 n x 1 网格。 

对于两个维度都至少为 2 的网格，算法返回 n 乘以 m。 隐式构造依赖于这样的事实：此类网格始终允许对所有单元格进行全周期遍历，从而确保最大的封闭面积。
