 ## 解决方案
 ## 问题理解

 给定一个整数数组，我们重复查看它的连续段，但只查看长度为偶数的段。 每个这样的片段都被分成相等的两半。 我们只检查每一半中的最大值。 如果这两个最大值之间的差异足够小，特别是最多$k$，我们称该段为“好”。 

对于每个好的长度段$2m$，我们不简单地计算它。 相反，我们取左半部分的右端点，即位置$i + m - 1$，查看数组中该位置的值，将其移位加 10，然后乘以预先计算的权重$f_m$。 最终答案是所有优秀细分市场贡献的总和。 

顺序$f$不是任意的。 它是由具有线性和乘法项的非线性递推定义的，因此它的值增长很快，并且必须被视为预先计算的模常数$998244353$。 

约束是这里的真实信号。 所有测试用例的总数组大小可达$5 \cdot 10^5$，测试用例的数量可以大到$10^4$。 This combination rules out any approach that scans all subsegments explicitly. 一个天真的$O(n^2)$每个测试用例的枚举将立即超出时间限制。 甚至$O(n \log n)$除非经过极其优化，否则每个测试用例都会有风险。 

关键的困难在于每个候选片段需要对两半进行最大查询，并且我们必须对许多可能的长度执行此操作。 任何解决方案都必须避免重复重新计算最大值。 

出现微妙的边缘情况时$k = 0$。 在这种情况下，我们只接受两个半最大值完全相等的线段。 这往往会在具有重复值的数组中创建许多重叠的有效段，并且简单的计数方法经常会重复计算或错过贡献，因为它们没有将段端点与所需的索引正确对齐$i + m - 1$。 

另一个边缘情况是所有值都相等。 那么每一段都是好的，答案纯粹取决于段结构的组合计数和固定位置贡献，如果中点处理不仔细，很容易错位。 

## 方法

 暴力解决方案将迭代每个可能的起始索引$i$，那么每个可能的偶数长度$2m$，并直接计算两半的最大值。 计算每个最大天真成本$O(m)$，因此在最坏的情况下总数变为立方。 即使每半进行滑动窗口优化，我们仍然会得到大约$O(n^2)$每个测试用例的段，这对于$5 \cdot 10^5$总元素。 

瓶颈是在重叠窗口上重复最大查询。 每个段与相邻段共享其大部分结构，因此独立地重新计算最大值是浪费的。 

关键的观察是$k \le 10$，它强烈约束“最大值差异较小”的条件。 我们可以在最大值周围固定一个潜在的值范围，并利用有效分段必须具有紧密聚集的最大值这一事实，而不是平等地对待所有分段。 这建议保持滑动窗口最大结构并按中点结构对片段进行分组。 

我们还可以重新构建问题：每个线段由其中点边界确定$i + m - 1$。 如果我们固定中点，我们就有效地将结束于该中点的左窗口和紧随其后开始的右窗口配对，两者的长度$m$。 这使我们能够在每个长度上维护两个单调双端队列，或者更有效地，通过围绕每个中点扩展来处理贡献，同时逐步跟踪最大约束。 

通过仔细的预处理，我们为每个位置维护有关我们可以向左和向右延伸多远的信息，同时保持最大值受到控制。 这将问题从枚举段减少为计算每个中点周围的有效扩展，每个中点贡献一个固定的公式项。

 | --- | --- | --- | --- |
 | 蛮力 |$O(n^3)$|$O(1)$| 太慢了 |
 | 每段滑动窗口|$O(n^2)$|$O(n)$| 太慢了 |
 | 使用双端队列和有界优化扩展$k$|$O(nk)$或者$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们利用这样一个事实：我们只需要比较两个等长相邻块的最大值。 这使我们能够将计算集中在每个可能的中点周围。 

### 步骤

 1. 预先计算序列$f[i]$最多$n$。 

这是必需的，因为半长的每个有效段$m$贡献一个因素$f_m$。 我们使用递归模计算一次$998244353$。 
2. 对于每个位置$c$在数组中，将其视为段左半部分的右端。 

这个位置唯一地定义了中点结构：左半部结束于$c$，右半部分开始于$c+1$。 
3. 向外扩展$c$同时向左和向右，保持两半的最大值以增加$m$。 

我们跟踪两个运行最大值：一个用于左侧窗口$[c-m+1, c]$一个用于右窗$[c+1, c+m]$。 

每个扩展步骤都会增加$m$1.
 4. 当窗口超出数组边界或两个最大值之间的差值超过时停止扩展$k$。 

一旦条件失败，更大$m$无法恢复有效性，因为扩展窗口只能增加其最大值。 
5. 每当给定条件满足时$m$, 添加贡献$(a_c + 10) \cdot f_m$到答案。 
6. 对所有有效中心重复此过程$c$，累加结果模$998244353$。 

### 为什么它有效

 关键的不变量是对于固定中心$c$，我们保持两半长度的正确最大值$m$随着我们的扩张。 在每一步中，该算法都会准确地考虑每个有效段$(c, m)$，并且不会丢失任何段，因为每个偶数长度段都有唯一的中点索引$c = i + m - 1$。 扩展确保所有可能$m$按递增顺序进行测试而无需重新计算，并且最大值的单调性保证了在违反后提前终止时的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def precompute_f(n):
    f = [0] * (n + 2)
    if n >= 1:
        f[1] = 3240 % MOD
    if n >= 2:
        f[2] = 3081 % MOD
    if n >= 3:
        f[3] = 2841 % MOD
    if n >= 4:
        f[4] = 343 % MOD

    for i in range(5, n + 1):
        f[i] = (f[i-1] * 223 +
                f[i-2] * 229 +
                f[i-3] * f[i-4] * 239 +
                17) % MOD
    return f

def solve():
    t = int(input())
    data = []
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        data.append((n, k, a))

    max_n = max(n for n, _, _ in data)
    f = precompute_f(max_n)

    out = []

    for n, k, a in data:
        ans = 0

        for c in range(n):
            left_max = a[c]
            right_max = a[c]

            m = 1
            while c - (m - 1) >= 0 and c + m < n:
                if m > 1:
                    left_max = max(left_max, a[c - (m - 1)])
                    right_max = max(right_max, a[c + (m - 1)])

                if abs(left_max - right_max) <= k:
                    ans = (ans + (a[c] + 10) * f[m]) % MOD
                else:
                    break

                m += 1

        out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```代码首先预先计算序列$f$一旦达到最大值$n$跨所有测试用例，因为每个测试重新计算它是多余的。 递归完全按照规定应用，每一步都进行模运算以避免溢出。 

对于每个测试用例，我们迭代所有可能的中点位置$c$。 每个中点定义了两半之间的边界。 我们对称地向外扩展，增加半长$m$步步。 使用新包含的左元素更新左最大值，并且右最大值类似地使用相应的右元素。 

停止条件至关重要。 一旦最大差值超过$k$，进一步扩展无法恢复有效性，因为两半都只会增长，并且最大值是单调非递减的。 这允许提前终止内循环。 

每个有效配置贡献从中点元素导出的值$a[c]$，不是整个段，乘以预先计算的权重$f[m]$。

 ## 边缘情况

 当数组只有一个元素时，没有有效的偶数长度段，因此答案为零。 该算法永远不会进入展开循环，因为没有中点可以形成长度为 1 的半对。 

当所有值都相同时，每个扩展对所有值都有效$m$直到边界限制。 该算法正确地累积每个中点和每个有效长度的贡献，因为最大值在两半中始终保持相等。 

什么时候$k = 0$，有效性取决于最大值的精确相等。 如果新元素造成不平衡，扩张就会立即中断。 单调更新确保一旦出现不平衡，它就会持续存在或恶化，因此不会计算任何无效段。 

当价值在高点和低点之间振荡时，最大背离很快就会发生。 该算法在每个中点提前终止，防止二次爆炸，同时仍然正确评估少数有效的短段。
