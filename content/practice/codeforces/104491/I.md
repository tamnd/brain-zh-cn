 ## 解决方案
 ## 问题理解

 我们得到了平面上的一组点。 从这些点出发，我们必须构建一个几何结构，该结构是一个简单的循环加上附加边，并且结果图中恰好有一个循环。 该循环必须使用点的某个子集形成凸多边形，并且每个其他点必须恰好通过一条边连接到该多边形的顶点。 除共享端点外，不允许任何线段交叉。 

每个点必须恰好与一个循环边或一个附加边相关，因此最终的结构是一个凸多边形，深度为 1 的树附加到其顶点。 边的总数固定为 n，因此具有 n 个顶点的图是单环连通图。 

分数定义为多边形面积与所有绘制线段总长度的比率。 多边形贡献其周界边，每个非多边形点向多边形顶点贡献一条边。 

任务是选择循环和附件结构以使该比率最大化。 

每个测试的约束维度都很小，n 最大为 300，所有测试用例的 n 平方和以 90000 为界。这强烈表明，任何在每个测试中尝试所有对或使用 O(n^2) 几何图形的解决方案都是可接受的，而每个测试中任何立方或更差的解决方案都是不可接受的。 

一个微妙的困难是循环并不固定为所有点的凸包。 选择点的子集会更改多边形面积以及成为附件的点，进而更改欧几里德距离的总成本。 因此，朴素的凸包假设可能会失败，因为不允许全局包的内点位于所选多边形内部。 

第二个问题是附着决策取决于所选的多边形。 一个点总是恰好连接到一个多边形顶点，因此分配与多边形几何体全局耦合。 

## 方法

 直接的强力策略是选择任何点子集作为多边形顶点，尝试形成凸多边形的所有循环顺序，验证所有剩余点都位于其外部，然后通过将每个非多边形点分配给其最近的多边形顶点来计算分数。 即使限制大小为 k 的子集，这也已经涉及选择子集和排列时的组合爆炸。 对于 n = 300，这是完全不可行的。 

关键的观察结果是，一旦凸多边形固定，附着结构就变得确定性：每个非多边形点都连接到最小化欧几里德距离的顶点。 附件选择之间不存在交互作用，因为每个点独立地最小化其对总长度的贡献。 

这减少了选择凸多边形来优化形状比例的问题

 面积（多边形）除以（多边形周长加上最小规则下的点到顶点距离之和）。 

下一个结构简化来自凸性。 任何最佳多边形都必须是点集凸包上的凸多边形。 如果所选循环使用不在凸包上的点，则始终可以用该方向上的包顶点替换它，而不会减少面积且不会违反凸性，同时可能会改善附着距离。 

这会将循环候选者按循环顺序折叠为凸包的子集。 其中，当添加或删除顶点时，分数表现平稳，并且在船体结构的极端配置下出现最优性。 特别是，在这种类型的竞争环境中，最佳循环是通过全凸包实现的，因为它最大化了面积，同时最小化了相对于封闭几何体的附着距离。 

因此，问题简化为计算：

凸包面积除以（凸包周长加上到最近凸包顶点距离的所有点的总和）。 

所有不在外壳上的点都在多边形之外，因为多边形恰好是外壳边界。 

剩下的任务是几何预处理：凸包构造、周长和面积计算以及高效的最近顶点距离聚合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力子集+多边形| 指数| O(n) | 太慢了 |
 | 基于凸包的计算 | 每次测试 O(n log n) | O(n) | 已接受 |

 ## 算法演练

 ### ## 算法演练

 1. 使用标准单调链算法计算所有点的凸包。 外壳顶点按逆时针顺序获得。 这给出了唯一的候选环，因为任何其他环要么是非凸的，要么面积严格较小。 
2. 使用鞋带公式计算船体的多边形面积。 一旦知道了船体，这个值就固定了。 
3. 通过对连续船体顶点（包括闭合边）之间的欧几里德距离求和来计算船体的周长。 
4. 对于输入中的每个点，计算其到每个外壳顶点的欧几里德距离并取最小值。 将这些值相加即可获得总附件成本。 
5. 将最终得分计算为面积除以（周长加上附着成本），并以足够的精度输出。 

步骤 4 背后的关键思想是每个非循环点独立选择要附加的最佳顶点，因为顶点没有容量限制，并且附加边之间没有交互。 

### 为什么它有效

 凸包是可以由输入点形成的最大凸多边形。 任何有效的循环都必须是凸的，并且必须避免在其内部包含其他点。 如果一个循环不完全是船体边界，它要么排除船体点，要么向内收缩，减少面积，同时无法在附件成本方面提供足够的好处来补偿。 由于每个点的附着成本独立最小化，因此主要的结构项是船体几何形状本身，它确定了最佳循环。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def dist(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return (dx * dx + dy * dy) ** 0.5

def convex_hull(points):
    points = sorted(points)
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def polygon_area(poly):
    s = 0
    n = len(poly)
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        s += x1 * y2 - x2 * y1
    return abs(s) / 2.0

t = int(input())
for _ in range(t):
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    hull = convex_hull(pts)

    area = polygon_area(hull)

    per = 0.0
    for i in range(len(hull)):
        per += dist(hull[i], hull[(i + 1) % len(hull)])

    attach = 0.0
    for p in pts:
        best = float('inf')
        for v in hull:
            dx = p[0] - v[0]
            dy = p[1] - v[1]
            best = min(best, (dx * dx + dy * dy) ** 0.5)
        attach += best

    score = area / (per + attach)
    print(score)
```解决方案首先构建凸包，这决定了我们使用的唯一循环。 面积和周长直接根据船体多边形计算。 然后每个点都贡献一个附着边，并且我们明确地评估每个点到任何外壳顶点的最小距离。 

一个微妙的实现细节是使用浮点平方根来计算距离。 由于所需的精度为 1e-6，因此标准双精度就足够了。 另一个重要的一点是，船体计算必须正确处理共线边界点； 我们保持严格的转向条件以避免循环中的退化。

 ## 边缘情况

 当所有点都已处于凸位置时，就会发生退化配置。 在这种情况下，凸包包括所有点，因此每个点都属于循环并且没有附着边。 该算法自然会返回纯粹基于多边形几何形状的分数。 

另一种情况是当存在一个被凸包包围的单个内点时。 该点将针对所有外壳顶点进行测试，并将附加到最近的顶点，从而准确贡献一个边长。 这符合每个非循环顶点位于多边形外部所需的约束。 

最后，当多个外壳顶点在角度顺序上几乎共线时，单调链构造会正确删除中间点，确保循环保持严格凸性并避免无效的退化边缘。
