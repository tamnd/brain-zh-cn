 ## 解决方案
 ## 问题理解

 两个玩家，爱丽丝和鲍勃，从两根长度相等的字符串开始。 字符串仅包含小写英文字母。 他们重复执行一个游戏的目的是$P$回合。 在每一轮中，Alice 被迫修改 Bob 字符串中的一个字符，Bob 被迫修改 Alice 字符串中的一个字符。 修改意味着选择一个位置并将该字符替换为他们选择的任何其他小写字母。 

毕竟$P$每轮比赛中，每个玩家仅评估自己的字符串。 玩家的得分定义为最终字符串中最常见字符的频率。 得分较高的玩家获胜，平局则为平局。 两位演奏者在充分了解初始琴弦的情况下都能发挥最佳效果。 

关键的困难在于，每个操作在字符串之间都是对抗性的，但在玩家自己的策略中是合作的：爱丽丝只能通过破坏鲍勃的字符串而不是她自己的字符串来提高爱丽丝的最终分数，反之亦然。 优化纯粹是关于如何在固定编辑次数下塑造字母的频率分布。 

限制条件很大$P$, 直至$10^9$， 尽管$N$最多只有 500。这立即排除了任何多轮模拟。 该解决方案必须仅取决于初始频率分布的结构以及每次移动可以实现多少“有效变化”。 

出现微妙的边缘情况时$P = 0$。 不可能进行任何更改，因此答案完全由每个字符串中的初始最大字符频率决定。 另一个特殊情况是当字符串已经统一时。 在这种情况下，根据策略，改变角色可能会减少或增加注意力，但由于两个玩家的行为是对称的，因此净效应仅取决于强制改变的数量以及它们在字母之间的分布方式。 

## 方法

 一种幼稚的方法是模拟游戏。 每一轮，爱丽丝都会尝试在鲍勃的字符串中选择一个位置，以最小化鲍勃的最终最大频率，而鲍勃对爱丽丝做同样的事情。 然而，每次修改后，最优选择取决于字母的当前完整分布，并且重新计算最佳移动将花费$O(N)$每一步。 和$P$最多$10^9$，这是完全不可行的。 即使我们将模拟限制为$P \le 500$，状态空间仍然很复杂，因为每次移动都会动态地改变最佳目标字母。 

关键的观察是，对字符串的最终分数唯一重要的是其最大频率类别的大小。 每个操作都会更改一个字符，因此它要么减少一个频率计数，要么增加另一个频率计数。 从较高的水平来看，每个玩家都希望最大化有多少个字符可以转换为一个占主导地位的字母。 

假设一个字符串有频率数组$f_1, f_2, \dots, f_{26}$。 如果我们想最大化之后出现频率最高的字母$x$变化时，最好的策略始终是选择当前最好的字母作为目标并将所有其他字母转换为目标。 每个操作最多可以将最佳频率增加 1，但只能直到所有其他字符都用完为止。 

因此，之后$x$操作时，最大可能频率变为：$$\min(N, \max(f_i) + x)$$因为每次移动最多只能将主导字母的计数增加 1，并且我们不能超过字符串长度。 

现在，Alice 和 Bob 之间的交互变得对称且解耦：每个玩家都使用他们的$P$在对手的弦上移动，但只有他们自己的最终弦才重要。 所以Alice的得分取决于Alice的原始字符串和Bob减少它的能力，反之亦然。 

然而，由于鲍勃只改变了爱丽丝的字符串，鲍勃实际上是在试图最小化爱丽丝的最大频率。 减少频率类别的最佳方法是首先定位最常见的字母。 仅当每个操作命中该字母时，才会将当前最大值减 1； 否则它就会浪费在非主导字母上。 由于鲍勃总是可以做出最佳选择，因此他总是会攻击爱丽丝字符串中当前的多数字母。 对于爱丽丝来说是对称的。 

因此，每个玩家的最佳结果仅取决于对手是否有足够的操作来“打破”多数集中。 

让$mx_1$是最大频率$S_1$,$mx_2$为了$S_2$。 后$P$从 Bob 到 Alice 的移动，Alice 的最佳最终得分变为：$$\max(1, mx_1 - P)$$因为每次移动最多可以将主频率减少 1，直到达到 1（不能低于 1，因为至少还有一次出现）。 

相似地：$$\max(1, mx_2 - P)$$因此，游戏简化为比较这两个值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力模拟 |$O(P \cdot N)$|$O(N)$| 太慢了 |
 | 降频模型|$O(N)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 统计两个字符串中每个字符的出现频率。 

这给出了每个字符串结构的完整摘要，这已经足够了，因为操作只影响计数，而不影响位置。 
2. 计算$mx_1$和$mx_2$，Alice 和 Bob 的初始字符串中的最大频率。 

分数仅取决于最常见的字符，因此可以忽略其他频率。 
3. 将 Bob 对 Alice 的影响建模为将 Alice 的最大频率降低最多$P$，生产$a = \max(1, mx_1 - P)$。 

每个操作可以消除当前主导字符的一次出现，直到它不再是主导字符。 
4.同样计算$b = \max(1, mx_2 - P)$爱丽丝对鲍勃的影响。 
5. 比较$a$和$b$。 如果$a > b$，爱丽丝获胜。 如果$a < b$，鲍勃获胜。 否则结果是平局。 

### 为什么它有效

 关键的不变量是，在播放过程中不需要显式跟踪字符串中最常见字母的身份。 重要的是它的数量，每一个最佳举措总是针对当前的多数阶层。 这确保了任何策略都不能从对手的分数中每一步减少超过 1 个单位，并且任何策略都不能将自己的分数每一步增加超过 1 个单位。 结果，通过初始最大频率的线性调整来完全捕获该过程。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, p = map(int, input().split())
        s1 = input().strip()
        s2 = input().strip()

        f1 = [0] * 26
        f2 = [0] * 26

        for c in s1:
            f1[ord(c) - 97] += 1
        for c in s2:
            f2[ord(c) - 97] += 1

        mx1 = max(f1)
        mx2 = max(f2)

        a = max(1, mx1 - p)
        b = max(1, mx2 - p)

        if a > b:
            print("Alice")
        elif a < b:
            print("Bob")
        else:
            print("Draw")

if __name__ == "__main__":
    solve()
```该实现将每个字符串压缩为 26 长度的频率数组。 这避免了任何跟踪位置或模拟操作的需要。 

唯一微妙的细节是夹紧`max(1, mx - p)`。 即使$P$大到足以超过当前最大频率，则分数不能降至零，因为某些字母至少出现一次。 该实现直接强制执行该下限。

 ## 边缘情况

 当$P = 0$，算法直接比较初始最大频率。 例如，与`abcd`与`aabc`，两个最大值分别为 1 和 2，因此 Bob 立即获胜。 不应用任何缩减，并且公式正确地保留了原始状态。 

什么时候$P$非常大，比如说$10^9$，无论结构如何，两个字符串的最低分数都会降低到 1。 例如，`aaaaa`与`bbbbb`变成1对1，平局。 钳位确保不会出现负频率或零频率。 

当字符串相同时，两者$mx_1$和$mx_2$是相等的，并且在相同的减少之后，两者保持相等。 即使一个字符串具有更多不同的字母，最大频率也会占主导地位并确保比较的一致性，而不管其他地方的分布如何。
