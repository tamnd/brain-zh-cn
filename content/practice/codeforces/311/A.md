 ## 解决方案
 ## 问题理解

 我们得到了二维平面上的一组点。 最初的几何任务通常是计算所有点对之间的最小欧几里德距离。 然而，该问题不是直接要求该值，而是要求我们构建点的配置，强制特定的强力算法执行超过给定数量的距离检查。 

该算法按 x 坐标对点进行排序，然后对于每个点 i 向前扫描点 j > i。 它计算距离，直到找到一个与 i 的 x 距离至少为当前最佳答案 d 的点，此时它停止扫描该 i。 数量 tot 计算在修剪停止进一步工作之前实际检查了多少 (i, j) 对。 

我们的输出不是计算问题的答案，而是一组坐标。 我们必须证明没有任何构造可以使 tot 超过 k，或者显式构造 n 个不同的整数坐标点（绝对值以 10^9 为界），以便算法严格执行超过 k 对的检查。 

约束 n ≤ 2000 足够小，O(n^2) 行为是可行的，因为 2000² 大约是 400 万次操作。 这是关键：算法在最坏的情况下是二次的，但通过条件提前停止`p[j].x - p[i].x >= d`如果点分布在 x 中，可以大大减少工作量。 

一个微妙的方面是 d 在执行过程中发生变化。 如果早期的对非常接近，则 d 变小，并且中断条件变得更难触发，从而迫使内部循环运行更长时间。 这正是我们要利用的：我们希望尽可能长时间地保持 d 小，以便几乎不会发生提前终止。 

一个天真的误解是假设按 x 排序总是使修剪有效。 仅当点在 x 中充分分布时，这才是正确的。 如果我们将点紧密地聚集在 x 中，那么`p[j].x - p[i].x`仍然很小，中断条件很少触发，算法退化为完整的 O(n²) 扫描。 

## 方法

 蛮力的观点很简单。 排序后，对于每个点 i，我们扫描所有后面的点 j，直到用完点或 x 间隙超过当前最佳距离 d。 如果点的排列使得所有 x 坐标都相同或几乎相同，则条件`p[j].x - p[i].x >= d`除非 d 变得非常大，否则几乎永远不会成立。 但 d 开始时为无穷大，只有当我们找到更接近的对时才会减少，因此早期行为本质上是一个完整的嵌套循环。 

关键的见解是剪枝条件仅取决于 x 差异，而目标距离取决于 x 和 y。 如果我们构造具有相同 x 坐标的点，则永远不会触发中断条件，因为`p[j].x - p[i].x = 0`对于所有对。 这将算法压缩为纯对枚举，并且 tot 恰好变为 n(n−1)/2。 

所以构造问题就变得简单了：我们只需要 tot > k 即可。 由于在这个简并几何中，tot 由 n 固定，因此我们选择 n 使得 n(n−1)/2 超过 k。 然后我们输出共享相同 x 坐标的任意 n 个不同点。 

这是有效的，因为我们故意破坏了算法所依赖的几何修剪结构。

 ## 算法演练

 我们构建最坏情况的配置而不是模拟算法。 

1. 首先，我们确定是否有可能使用n个点进行超过k次操作。 在最坏的情况下，算法会检查所有对，因此最大可能的 tot 为 n(n−1)/2。 如果该值不大于 k，则任何构造都无法强制 TLE。 
2. 如果n(n−1)/2 ≤ k，我们立即输出“无解”。 这是合理的，因为即使在最糟糕的几何配置中，该算法也无法检查所有对。 
3. 否则，我们构建点以使修剪永远不会激活。 我们通过将所有 x 坐标设置为相等来实现此目的，例如所有点的 x = 0。 
4. 我们分配不同的 y 坐标，例如 y = 0, 1, 2, ..., n−1，确保所有点都是不同的且在边界内。 
5. 我们输出这些点。 由于所有 x 差异均为零，因此条件`p[j].x - p[i].x >= d`对于任何有限的 d 总是 false，因此内部循环永远不会提前中断。 
6. 结果，算法计算每对 (i, j)，因此 tot 等于 n(n−1)/2，通过构造严格大于 k。 

### 为什么它有效

 该算法的剪枝完全取决于x坐标分离。 通过将所有点折叠到垂直线上，我们消除了任何水平分隔。 由于中断条件仅基于 x 距离超过 d，并且 x 距离始终为零，因此它永远不会触发。 因此，该算法退化为完全成对枚举，从而最大化 tot。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    
    max_pairs = n * (n - 1) // 2
    if max_pairs <= k:
        print("no solution")
        return

    # construct all points on a vertical line
    for i in range(n):
        print(0, i)

if __name__ == "__main__":
    solve()
```第一部分计算算法可以执行多少对检查的理论上限。 这很重要，因为它可以立即排除不可能的情况，而无需构建任何东西。 

该构造对所有点使用 x = 0 并传播 y 值以确保清晰度。 y 间距保证了有效的几何形状，但更重要的是防止违反约束的意外重复。 

我们不需要模拟该算法，因为一旦所有 x 坐标都相同，最坏情况的行为就完全确定了。

 ## 边缘情况

 关键的边缘情况是 k 已经大于成对评估的最大可能数量。 例如，如果 n = 3 且 k = 10，则即使完整的 O(n²) 扫描也只能产生 3 个评估。 在这种情况下，正确的输出是“无解”。 该算法通过在任何输出之前将 k 与 n(n−1)/2 进行比较来处理此问题。 

另一个边缘情况是最小的 n = 2。这里正好有一对。 如果 k ≥ 1，则不存在解。 如果 k = 0，我们仍然可以产生两个点，并且算法将始终检查单个对，产生 tot = 1 > 0。 

最后一个微妙的情况是确保点的清晰度。 通过固定 x = 0 并使用严格递增的 y 值，我们保证了唯一性，同时保持每对的 x 差异相同。 这在不违反约束的情况下保留了最坏情况的行为。
