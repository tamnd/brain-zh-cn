 ## 解决方案
 ## 问题理解

 我们有一个农场，有一条笔直的道路和几座编号为 1 到 _n_ 的山丘。 每一座山都与前一座山相距已知的距离。 有 _m_ 只猫，每只猫都会在某个时间在特定的山上徘徊，并在那里等待喂食器。 有_p_喂食者，都从 1 号山开始，沿着路走，接走所有等待的猫。 喂食器以速度 1 行驶，可以携带任意数量的猫。 如果喂食器到达晚于猫完成，则每只猫的等待时间是喂食器到达其山的时间与猫完成时间之间的差值；如果喂食器到达较早，则等待时间为零。 我们希望安排所有支线的出发时间，以便最大程度地减少所有等待时间的总和。 

输入给出了山的数量_n_、猫的数量_m_、喂食器_p_、山之间的距离以及每只猫的山和完成时间。 输出是一个整数：最短总等待时间。 

在给定约束的情况下，_n_和_m_可以达到10^5。 这排除了其中任何一个都是二次的算法，因为 10^10 次操作将超过 2 秒。 喂食器的数量_p_很小，最多 100 个，这暗示猫之间的动态规划或凸优化可能是可行的。 边缘情况包括猫在第一个山上完成任务（可能永远不会等待）或多只猫同时在同一座山上完成任务，以及拥有比有猫的山更多的喂食器。 

尝试所有可能的支线出发时间表的简单实施显然是不可能的。 另一个微妙的情况是，多只猫在不同的时间到达同一座山。 如果第一只猫吃完后立即发送一个喂食器，如果没有仔细安排另一个喂食器，可能会让后面的猫等待太久。 

## 方法

 暴力方法会考虑猫到喂食器的每次分配和出发时间，计算每个猫的等待时间，并取最小值。 对于_m_只猫和_p_个喂食器，可能的分区数量以_m_为指数。 即使只是迭代喂食器的所有猫子集也是不可行的，因为 _m_ ≤ 10^5。 

关键的观察结果是，喂食者严格从左向右移动，并且绝不会原路返回。 这使我们能够根据猫需要等待的时间调整距离对猫进行排序，即猫的完成时间减去从山 1 到它的山的距离。 一旦我们对此进行排序，我们就可以将问题视为将调整时间序列分成_p_个连续组，其中每个组由单个馈送器处理。 如果喂食器在该组中最早的猫的调整时间离开，则该组的总等待时间会最小化。 这将问题简化为经典的凸成本划分问题，可以通过分治优化的动态规划来解决。 

如果没有优化，对于 _p_ 个喂食器的 _m_ 只猫的 DP 将为 O(m^2 * p)，这对于 _m_ = 10^5 来说太慢了。 通过使用成本函数的凸性特性，分而治之的 DP 将其降低到 O(m * p log m)，在给定约束的情况下这是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^m) | O(2^m) | O(米) | 太慢了 |
 | 具有凸优化的 DP | O(m * p log m) | O(m * p log m) | O(m * p) | 已接受 |

 ## 算法演练

 1. 计算山之间距离的前缀和，以获得每个山相对于山 1 的准确位置。如果喂食器在时间 0 离开，这允许将猫的山转换为准确的到达时间。 
2. 对于每只猫，计算调整后的完成时间：`adjusted_time = t_i - prefix_distance[h_i]`。 这是喂食者离开 1 号山并在猫吃完时准确到达的最晚时间。 按调整后的时间对猫进行分类可确保我们按照所需的喂食器出发时间的升序来处理它们。 
3.按照调整的时间对猫进行排序。 最佳解决方案永远不需要向后发送喂食器，并且按排序顺序对猫进行分组可确保每个喂食器组内的等待时间最少。 
4.定义DP数组`dp[i][k]`作为第一次的最短等待时间`i`猫使用`k`馈线。 一组连续的猫的成本函数是每只猫的调整时间与该组中的最小调整时间之间的差异之和。 
5. 预先计算调整时间的前缀和，以快速计算单个喂食器为猫提供服务时任何间隔的猫的总等待时间。 
6. 对DP应用分而治之优化：成本函数是凸的，意味着最优分割点为`dp[i][k]`位于最佳分割的左侧`dp[i+1][k]`。 这将每个 DP 状态的内部循环从 O(m) 减少到 O(log m)。 
7. 答案是`dp[m][p]`，代表所有的最小总等待时间`m`猫使用所有`p`馈线。 

保证正确性的不变量是每个喂食器服务于一组连续的排序猫，并且每个组的出发时间是该组内的最小调整时间。 任何其他分配都会增加等待时间，因为如果稍后处理，序列中较早的猫会等待更长时间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, m, p = map(int, input().split())
    d = list(map(int, input().split()))
    
    pos = [0] * n
    for i in range(1, n):
        pos[i] = pos[i-1] + d[i-1]
    
    cats = []
    for _ in range(m):
        h, t = map(int, input().split())
        cats.append(t - pos[h-1])
    
    cats.sort()
    
    prefix = [0] * (m+1)
    for i in range(1, m+1):
        prefix[i] = prefix[i-1] + cats[i-1]
    
    INF = 10**18
    dp = [INF] * (m+1)
    dp_prev = [0] + [INF]*m

    def cost(l, r):
        total = prefix[r] - prefix[l-1]
        count = r - l + 1
        return total - cats[l-1]*count

    for k in range(1, p+1):
        def compute(l, r, optl, optr):
            if l > r:
                return
            mid = (l + r) // 2
            best = (INF, -1)
            start = max(optl, 1)
            end = min(mid, optr)
            for j in range(start, end+1):
                val = dp_prev[j-1] + cost(j, mid)
                if val < best[0]:
                    best = (val, j)
            dp[mid] = best[0]
            opt = best[1]
            compute(l, mid-1, optl, opt)
            compute(mid+1, r, opt, optr)
        
        compute(1, m, 1, m)
        dp_prev, dp = dp, [INF]*(m+1)
    
    print(dp_prev[m])

if __name__ == "__main__":
    main()
```第一部分使用前缀和计算山的位置。 然后，计算每只猫调整后的完成时间。 排序确保我们按照喂食器离开最少的非降序处理猫。 前缀总和允许 O(1) 计算组等待时间。 DP 实现了分而治之的优化，其中`compute`函数递归地找到每个 DP 状态的最佳分割。 

需要注意的点包括为 cats 使用基于 1 的索引来匹配前缀和约定，使用`INF`，并在每次迭代时保持 DP 数组不同，以避免覆盖必要的数据。
