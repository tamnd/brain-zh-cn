 ## 解决方案
 ## 问题理解

 我们得到了一副牌$N$卡，每张都标有一个整数值$1$和$N$。 游戏有$N$回合。 在$i$- 第 轮，我们必须选择两个非空、不相交的牌子集，称为牌组 1 和牌组 2，使得每副牌中值的最大公约数恰好是$i$。 不在任一副牌中的牌将被忽略。 圆形的创意点$i$是$i$乘以选择这两副牌的方式数。 任务是将所有轮次的创造力点相加并取模$998\,244\,353$。 

输入包括$N$其次是$N$整数$A_1$到$A_N$。 输出是一个整数，即总创造力点。 

第一个关键观察结果是$N$最多可达 200,000，这使得任何枚举子集的暴力尝试都不可能实现，因为子集的数量呈指数级增长$N$。 类似地，检查所有子集对将导致$O(3^N)$最坏情况下的操作。 1秒的时间限制意味着我们需要一个大致的算法$O(N \log N)$或者$O(N \sqrt{N})$。 

可能打破简单解决方案的边缘情况包括当所有卡都等于某些卡时$i$。 例如，与$N = 3$和$A = [3, 3, 3]$，只有对应的轮次$i = 3$具有非零的创造力点。 如果解决方案尝试为每个子集计算 GCD，它将超时或错过正确的计数，因为 GCD 是乘法的，并且可以使用计数方法而不是枚举更有效地处理。 

## 方法

 一个天真的方法是尝试每一轮$i$，生成卡片的所有子集，计算它们的 GCD，并计算有效对。 这在原则上是正确的，但需要枚举$2^N$子集，然后比较对，导致$O(4^N)$复杂。 即使是为了$N = 20$，这是不可行的。 

关键的见解是计算可以被倍数整除的卡片$i$并使用组合推理而不是子集枚举。 一轮$i$，仅其值可被整除的卡$i$可以使用，因为 GCD 必须恰好是$i$。 让$c_i$是此类卡片的数量。 对于每个$i$，我们需要分割这些的方法数量$c_i$将卡片分成两个非空、不相交的子集，其中每个子集的 GCD 仍然存在$i$。 

我们可以对倍数使用包含排除原则$i$。 首先，计算所有可被整除的卡片子集$i$。 然后减去 GCD 是以下倍数的较高倍数的子集$i$，递归地。 最后，对于每一轮$i$，分配两个非空牌组的方法数量$f[i]$与 GCD 完全相同的卡牌$i$是$f[i] \times f[i] - f[i]$因为我们可以为牌组 1 选择任何非空子集，为牌组 2 选择任何非空不相交子集，并排除无效配置。 

这将问题简化为迭代除数和倍数，即$O(N \log N)$使用类似筛子的方法。 计算 2 的幂并应用模运算可确保我们保持在限制范围内。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(4^N)$|$O(2^N)$| 太慢了|
 | 倍数上的包含-排除 |$O(N \log N)$|$O(N)$| 已接受 |

 ## 算法演练

 1.初始化一个数组`count`尺寸的$N+1$为零。 迭代卡片值$A_1$到$A_N$并增加`count[val]`对于每张卡的面值。 这会计算每个值有多少张牌。 
2. 对于每个整数$i$从$1$到$N$, 计算`mult[i]`作为卡片总数除以$i$。 迭代多个$i$并求和`count`价值观。 这给出了可以用 GCD 组成牌组的候选卡的总数$i$。 
3.初始化一个数组`f`尺寸的$N+1$为零。 迭代自$N$下降到$1$。 让`total`是$2^{mult[i]} - 1$模数$998244353$，表示可被整除的卡片的所有非空子集$i$。 然后减去`f[j]`对于所有倍数$j = 2*i, 3*i, ..., N$删除 GCD 等于更高倍数的子集$i$。 将结果分配给`f[i]`。 现在`f[i]`表示其 GCD 恰好为的非空牌子集的数量$i$。 
4. 每轮$i$，从中选择两个非空、不相交子集的方法数`f[i]`卡是$f[i] \times f[i] - f[i]$。 这会计算所有有序对减去一个子集为空的情况。 乘以$i$得到本轮的创造力点，然后将其与总模数相加$998244353$。 
5.输出总创意点。 

为什么它有效：在每一步，`f[i]`正确计算 GCD 恰好为的子集$i$因为我们包括所有可被整除的子集$i$并减去计数较高倍数的子集。 有效地使用两个幂来计算所有可能的子集。 计算有序对可确保我们正确捕获所有有效的牌组分配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    N = int(input())
    A = list(map(int, input().split()))
    
    count = [0] * (N + 1)
    for a in A:
        count[a] += 1
    
    mult = [0] * (N + 1)
    for i in range(1, N + 1):
        for j in range(i, N + 1, i):
            mult[i] += count[j]
    
    f = [0] * (N + 1)
    pow2 = [1] * (N + 2)
    for i in range(1, N + 2):
        pow2[i] = (pow2[i-1] * 2) % MOD
    
    for i in range(N, 0, -1):
        total = (pow2[mult[i]] - 1) % MOD
        j = 2 * i
        while j <= N:
            total = (total - f[j]) % MOD
            j += i
        f[i] = total
    
    result = 0
    for i in range(1, N + 1):
        ways = (f[i] * f[i] - f[i]) % MOD
        result = (result + ways * i) % MOD
    
    print(result)

solve()
```代码计算`mult[i]`确定哪些牌可以出现在回合中`i`。 两个句柄子集的幂可以有效地进行计数。 减法`f[j]`倍数确保我们遵守确切的 GCD 要求。 最后，有序对公式计算该轮的有效牌组分配。
