 ## 解决方案
 ## 问题理解

 我们被要求检查在给定循环移位的“幂”序列的情况下是否可能存在丢失的排列。 排列的幂是通过计算前缀最大数组中的不同元素来定义的。 例如，如果排列从最大元素开始，则前缀最大值几乎不会增加，从而给出较小的幂。 相反，如果它从较小的元素开始，然后再击中较大的元素，则威力会增加更多。 

输入由多个测试用例组成。 每个测试用例提供一个整数`n`（排列的大小）和一个数组`c`长度`n`在哪里`c[i]`是的力量`(i-1)`排列的第-次循环移位。 如果存在与该序列一致的排列，我们的输出为“YES”，否则为“NO”。 

约束条件允许`n`达到`10^5`以及所有的总和`n`超过测试用例最多`10^5`。 这排除了任何尝试枚举排列或显式计算循环移位的算法，因为阶乘或`O(n^2)`方法会太慢。 我们需要一种大致有效的方法`O(n)`每个测试用例。 

边缘情况很微妙。 如果连续循环移位之间的幂减少超过 1，则简单的解决方案可能会失败。 例如，如果`c = [3, 1, 2]`，排列不可能存在，因为在移位之间幂的突然下降不能超过 1，因为每个循环移位仅从尾到前移动一个元素。 

## 方法

 蛮力方法是尝试重建排列，生成所有`n`循环移位，并计算每个移位的不同前缀最大值以进行比较`c`。 这在理论上是正确的，但会产生`O(n^2)`每个测试用例的工作量由于`n`每个移位都需要前缀最大扫描，这对于`n`最多`10^5`。 

关键的观察是循环移位的幂数组具有结构。 将排列视为一系列“块”，其中每个新块都以新的最大值开始。 每次循环移位最多可以将功率改变+1或-1。 因此，在连续条目之间`c`，差值必须为 0、1 或 -1。 具体来说，整个数组的减少次数不得超过 1（我们可以将数组视为旋转的）。 

这导致了一种有效的方法：遍历`c`并跟踪增加和减少。 如果任何减少超过 1，或者增加和减少的总和与最大可能功率不一致`n`，我们可以断定不存在排列。 否则，总是可以构造有效的排列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和数组`c`。 
2. 初始化变量`expected`到 1。这代表我们期望一致排列的最小幂。 
3. 迭代数组`c`。 对于每个`i`，检查是否`c[i]`至少是`expected`。 如果`c[i] < expected`，输出“NO”并停止； 该数组无法表示有效的排列。 
4. 增量`expected`每当`c[i]`与之前的值相比有所增加。 这确保了连续幂之间的差异与最多添加一个新的最大值一致。 
5. 如果迭代完成且没有不一致，则输出“YES”。 

为什么有效：该算法之所以有效，是因为有效排列的前缀最大值只能随着新的较大元素的出现而增加。 循环移位将一个元素从末尾移动到前面，这最多可以将前缀最大值增加 1 或保持不变。 因此，连续移位之间幂下降超过 1 的任何序列都不能对应于真正的排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        c = list(map(int, input().split()))
        
        possible = True
        last = 0
        for power in c:
            if power - last > 1:
                possible = False
                break
            last = power
        print("YES" if possible else "NO")

if __name__ == "__main__":
    solve()
```解决方案如下`t`每个测试用例和流程`O(n)`时间。 我们追踪`last`作为先前的幂，并检查与当前幂的差不超过 1。这捕获了每个循环移位不能将前缀最大值增加超过 1 的事实。如果差在所有移位中都有效，则排列可以存在。

 ## 边缘情况

 当`n = 1`，唯一可能的幂是 1。如果`c[0] != 1`，算法正确输出“NO”。 

当第一个元素在`c`大于 1，算法立即输出“NO”，因为任何排列都不能以大于 1 的前缀最大值开始，而不首先看到较小的元素。 

具有连续等幂的序列被正确处理，因为差异`power - last = 0`是有效的。 例如，`c = [2, 2, 2]`通过检查并返回“YES”。
