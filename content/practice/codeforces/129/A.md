 ## 解决方案
 ## 问题理解

 我们得到了几袋饼干，每袋都含有一定数量的饼干。 奥尔加只想偷一个包。 取出袋子后，剩下的饼干总数必须相等，这样两姐妹才能平分。 

任务是计算奥尔加可以选择多少个袋子，以便剩下的总数是偶数。 

输入包括袋子数量和每个袋子中饼干的数量。 输出是一个整数，即可以删除的有效袋子的数量。 

限制非常小。 最多有 100 个袋子，每个袋子最多包含 100 块饼干。 即使是二次解也能立即运行，因为最坏的情况下我们只能执行大约 10,000 次操作。 这意味着我们可以完全专注于清晰度和正确性，而不是优化技巧。 

棘手的部分是了解取出一个袋子后 Parity 的表现如何。 当偶数总数保持偶数时，粗心的实现可能会错误地重新计算总和或产生误解。 

考虑这个例子：```
1
1
```饼干总数为 1。如果奥尔加拿走唯一的一袋，则剩余总数变为 0，即为偶数。 正确答案是：```
1
```有问题的解决方案可能会忘记零是偶数并错误地打印 0。 

另一个容易出错的地方是奇偶逻辑。 考虑：```
3
1 2 3
```总和是 6，是偶数。 移除偶数的袋子使剩余的总和保持偶数，而移除奇数的袋子则使剩余的总和为奇数。 这里只有包含 2 个作品的包，所以答案是：```
1
```如果有人只计算奇数包或只检查原始总奇偶性而不仔细推理，他们可能会得到错误的结果。 

最后一个边缘情况是每个包都具有相同的奇偶性。 例如：```
4
2 2 2 2
```总和是 8。去掉任何一个袋子剩下 6，这是偶数。 答案是 4。如果某个实现意外地检查了已删除包的奇偶校验而不是剩余的总和，则可能会在此默默地失败。 

## 方法

 最直接的解决办法就是暴力破解。 我们首先计算 cookie 的总数。 然后，对于每个袋子，我们想象将其取出并检查剩余的总数是否均匀。 

包袋用`i`，剩余总数为：```
total_sum - a[i]
```如果该值可以被 2 整除，那么这个包就是一个有效的选择。 

这种方法已经足够快了。 对于最多 100 个行李，我们在计算一次总和后最多执行 100 次检查。 

这个问题背后还有一个有用的奇偶观察。 剩余总数的奇偶性仅取决于总和与移除的包的奇偶性。 

如果总和是偶数，则删除偶数袋使结果保持偶数，而删除奇数袋则使结果为奇数。 

如果总和是奇数，那么去掉一个奇数包会使剩余的总和为偶数。 

因此，这个问题也可以看作是对奇偶性与总和奇偶性相匹配的袋子进行计数。 

暴力版本之所以有效，是因为每个候选人包都可以独立检查。 奇偶校验观察解释了为什么这些检查如此简单。

 ## 算法演练

 1. 读取袋子的数量和饼干计数数组。 
2. 计算所有袋子中的 cookie 总数。 
3. 将应答计数器初始化为 0。 
4. 迭代每个包。 
5. 对于当前的包，计算移除后的剩余总数：```
remaining = total_sum - current_bag
```6. 检查是否`remaining`是均匀的。 

如果`remaining % 2 == 0`，增加答案。 
7. 处理完所有袋子后，打印答案。 

### 为什么它有效

 对于每个袋子，算法直接计算移除该袋子后剩下的饼干数量。 当剩余总数为偶数时，即准确计数一袋，与问题要求精确匹配。 

由于每个可能的包都会被检查一次，并且奇偶校验测试在数学上是正确的，因此算法不会错过有效答案或计算出无效答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

total = sum(a)

answer = 0

for x in a:
    if (total - x) % 2 == 0:
        answer += 1

print(answer)
```该解决方案首先读取袋子的数量和饼干的数量。 总和在开始时计算一次，因此我们不会为每个包重复重新计算它。 

循环独立检查每个袋子。 对于装有`x`饼干，去掉叶子`total - x`饼干后面。 如果剩余金额能被 2 整除，则该包贡献一个有效选择。 

由于限制很小，所以实现很简单。 Python 中不存在溢出问题，并且不需要对零进行特殊处理，因为`0 % 2 == 0`自然有效。 

一个微妙的问题是操作的顺序。 在检查奇偶性之前，我们必须减去当前包。 仅检查包本身的奇偶性并不总是正确的，除非我们单独推理总和的奇偶性。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    total = sum(a)

    ans = 0

    for x in a:
        if (total - x) % 2 == 0:
            ans += 1

    print(ans)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    return sys.stdout.getvalue().strip()

# provided sample
assert run("1\n1\n") == "1", "sample 1"

# minimum size, even remaining becomes zero
assert run("1\n7\n") == "1", "single bag"

# all even values

# mixed parity
assert run("4\n1 2 3 4\n") == "2", "only even bags work"

# no valid choices
assert run("2\n2 2\n") == "0", "removing any bag leaves odd total"

# larger case
assert run("5\n2 2 2 2 99\n") == "1", "only odd bag works"

 ## 边缘情况

 考虑尽可能最小的输入：```
1
1
```总和是 1。去掉唯一的袋子叶子：```
1 - 1 = 0
```由于 0 是偶数，因此算法会递增答案并打印 1。这确认了剩余的空 cookie 已正确处理。 

现在考虑每个袋子都是偶数的情况：```
4
2 2 2 2
```总和是 8。去掉任何一个袋子剩下 6，这是偶数。 

该算法检查所有四个包：```
8 - 2 = 6
```每次，所以答案就变成4。 

最后，考虑一种只有一个包可以工作的情况：```
5
2 2 2 2 99
```总和是 107，是奇数。 

去掉任何偶数袋剩下 105，仍然是奇数。 

取出装有 99 片叶子的袋子：```
107 - 99 = 8
```这是偶数。 

该算法正确地计算出了一个有效的选择。
