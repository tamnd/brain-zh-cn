 ## 解决方案
 ## 问题理解

 我们给定一个大整数$N$我们需要构造另一个整数$X$严格小于$N$，而且还满足与重复除以 2 相关的非常具体的结构属性。 

限制不仅仅在于奇怪。 如果我们反复除法，我们还需要$X$2 直到达到 1，每个中间值必须保持奇数。 换句话说，二进制表示$X$在减半过程中绝不能产生偶数，除非达到 1，这是唯一允许的停止点。 

这立即表明二的幂在这里是特殊的。 任何具有 2 因数的数字最终都会在达到 1 之前减少到偶数，因此它违反了条件。 唯一能够被 2 重复除而不变成偶数的数字是那些在除法的每个阶段都已经是奇数的数字，这迫使它们具有以下形式$2^k - 1$，即完全由 1 组成的二进制数。 

所以任务简化为找到表格中的最大数字$2^k - 1$严格小于$N$。 

输入大小使得暴力破解变得不可能。 和$T$最多$2 \cdot 10^5$和$N$最多$10^{18}$，对候选者或位级模拟的任何每次测试迭代都会太慢。 每个查询都需要直接的位操作或数学构造。 

一个常见的失败案例来自于对条件的误解。 例如，如果$N = 10$，一个简单的方法可能会选择 9，因为它是 10 以下的最大奇数。但是 9 是无效的，因为 9 → 4 → 2 → 1 包含偶数，这违反了规则。 正确答案是 7。 

另一个微妙的错误是认为所有奇数都有效。 只有二​​进制形式全为 1 的数字才有效。 这是一个小得多的集合。 

## 方法

 直接的暴力解决方案将尝试从$N-1$向下并通过模拟重复除以 2 来检查每个候选值。每次检查都需要重复除以直到达到 1 并验证所有中间值仍然是奇数。 在最坏的情况下，这需要$O(\log N)$每个号码，我们最多可以扫描$O(N)$候选人，这对于$10^{18}$。 

关键的观察结果是有效性条件强制采用严格的二元结构。 在重复减半的情况下永远不会变成偶数的数字必须在每个中间步骤中避免因数 2。 唯一保持此属性的数字是二进制形式中每位均为 1 的数字。 也就是说，有效数字恰好是$1, 3, 7, 15, 31, \dots$。 

因此，我们不是搜索整数，而是搜索位长度。 对于任何$N$，我们找到表格中最大的数字$2^k - 1$仍然严格小于$N$。 这可以通过取位长度得出$N$并在其下方构建一个候选者。

 ## 算法演练

 1. 转换$N$转换成其二进制表示形式或确定其最高设置位。 这确定了两个不超过的最大幂$N$。 此步骤设置答案的范围。 
2. 计算$k$，位数$N$。 这意味着$2^{k-1} \le N < 2^k$。 我们用它来构建最大的候选者，并用更少的位来构建所有的候选者。 
3. 构建候选者$C = 2^{k-1} - 1$。 这是严格低于二的最高幂的最大全一数$N$。 减 1 的原因是它将单个前导 1 和后面的 0 变成全 1。 
4. 如果$C < N$， 返回$C$。 否则，将位长减一并构造$C = 2^{k-2} - 1$，然后返回它。 这处理以下情况$N$本身正好高于二次方边界。 

### 为什么它有效

 任何有效数字都必须采用以下形式$2^k - 1$，因为重复除以 2 只能干净地删除全 1 数的尾随二进制结构。 这些数字正是其二进制表示形式在任何中间减半步骤中都不会引入零的数字。 因此答案必须是下面最大的数字$N$。 由于这些数字呈指数增长，因此检查位长边界周围最多一两个相邻候选就足够了，确保我们始终落在正确的最大值上。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input().strip())

        # find highest power of two <= n
        k = n.bit_length()

        # candidate with k-1 bits all ones
        cand = (1 << (k - 1)) - 1

        if cand < n:
            print(cand)
        else:
            cand = (1 << (k - 2)) - 1
            print(cand)

if __name__ == "__main__":
    solve()
```该解决方案完全依赖于位长度。 表达式`n.bit_length()`给出最小的$k$这样$n < 2^k$。 由此我们构建下面最大的全一数$2^{k-1}$，这是下面的自然候选者$N$。 如果该候选者不严格小于$N$，我们降低一级。 

减法模式`(1 << x) - 1`是核心转换：它将单个设置位转换为一系列位，这与从问题条件导出的结构要求完全匹配。 

当$k = 1$，但自从$N \ge 2$，这永远不会导致第二个分支中的无效移位。

 ## 边缘情况

 对于$N = 2$，位长度为 2。候选者变为$2^{1} - 1 = 1$，这是有效的并且严格较小。 

为了$N = 3$，第一个候选者是$1$，这是有效的且小于 3，因此不需要回退。 

为了$N = 8$，第一个候选值是 7，这不符合严格的不等式，强制回退到 3。该算法正确地将位长度减少了 1。 

对于附近非常大的值$10^{18}$，只有位长很重要。 由于Python直接处理64位位操作而不会溢出，因此该结构保持稳定。
