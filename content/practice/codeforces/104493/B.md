 ## 解决方案
 ## 问题理解

 我们得到一个整数数组。 全局过程重复运行：在每一步中，我们都会查看当前数组，选择其最大值（如果多个位置相等，我们选择最左边的一个），然后通过将其除以最大素因数来替换该值。 重复此操作，直到数组中的每个元素都变为 1。 

对我们来说重要的不是模拟整个过程，而是回答有关时间的疑问。 每个查询给出一个子数组`[l, r]`，并且当该子数组中的所有元素都已变为 1 时，我们必须确定全局过程中最早的步骤号。 

关键的难点在于该操作是全局和动态的：每一步都取决于整个数组中当前的最大值，因此数组中不同部分的元素通过“最大剩余值”的全局排序相互干扰。 

这些限制表明两者`n`和`q`可以大到约200万。 这立即排除了对每个查询的完整过程的任何模拟，甚至排除了每个查询重新计算任何内容。 任何解决方案都必须在近线性时间内预处理整个演化，并以对数或恒定时间回答每个查询。 

一种简单的方法是显式模拟所有操作，记录每个位置何时变为 1，然后对于每个查询取该范围内的最大值。 然而，即使是模拟也是有问题的，因为数组可能需要许多步骤，更重要的是，每个步骤都需要提取最大值并将其因式分解，这将使复杂性远远超出限制。 

当值重复并且打破平局很重要时，就会出现微妙的边缘情况。 例如，如果最大值出现多次，则始终选择最左边的出现会影响哪个位置首先减少，这反过来会改变未来的最大值排序。 不仔细维护此结构的简单模拟可能会对每个元素完成的时间产生错误的计时。 

另一个边缘情况是当值已经为 1 时。它们应该被视为在时间 0 完成，不涉及任何更新。 如果处理不当，他们可能会错误地延迟查询答案。 

## 方法

 直接模拟将维护数组值的优先级结构，重复提取最大值，将其除以最大素因数，然后重新插入。 每次操作都会花费对数的堆维护和因式分解时间。 由于每个数字`ai`可以多次减少，直到变成 1，并且所有数字的质因数步数之和可能很大，最坏情况下的操作次数与所有元素的质因数删除总数成正比。 当值高达 2e6 时，这仍然可能导致数千万次操作，这是边界，但真正的瓶颈是查询处理：我们仍然需要每个位置的完成时间戳，这需要仔细跟踪，并且仍然不能有效地解决全局依赖关系。 

关键的见解是反转视角：我们观察到每个数字根据其需要的“减少”次数独立演化，而不是逐步模拟该过程，但减少的“顺序”是由当前值全局决定的。 每个数字`x`准确地要求`cnt(x)`对自身进行操作，其中`cnt(x)`是除以它的最大质因数直到它变为 1 的次数。 

因此，每个元素在减少时都会贡献一系列“激活时间”。 全局过程相当于重复地总是选择当前最大的“剩余值”，但这会引起全局的减少排序，这与按当前有效值对所有“减少事件”进行排序是一致的。 

这使我们能够预先计算每个位置减少的确切时间，更重要的是，它达到 1 的时间。一旦我们知道最终完成时间`t[i]`对于每个索引，每个查询都会减少到一个范围最大查询`t[i]`。 

因此问题就变成了：计算`t[i]`对于全局调度过程下的所有索引，然后回答范围最大查询。 

我们可以使用优先级队列有效地模拟该过程，但仅限于“当前值”，同时为每个索引存储剩余减少量的倒计时。 每次选择一个索引时，我们都会递减它的值，如果仍然大于 1，则将其推回原处。总操作数受所有数字的归约步骤之和的限制，该总和很小，因为每一步至少减少一个素因子，并且预先计算最小的素因子可确保每个数字贡献 O(log ai) 步骤。 

最后，在计算完成时间后，我们构建一个线段树或稀疏表以进行快速范围最大查询。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个查询的强力模拟 | O(nq + 重分解) | O(n) | 太慢了|
 | 事件模拟+预处理+RMQ | O(Σ log ai + n log n + q) | O(n) | 已接受 |

 ## 算法演练

 1. 预先计算所有数字的最小素因数 (SPF)`max(ai)`。 这使我们能够通过除掉所有较小的素因子并取出最后剩余的素因子来快速提取最大的素因子。 这样就避免了重复试分割。 
2. 对于每个数组元素，计算它需要多少次操作，直到它变成 1。每个操作都将该数字除以它的最大质因数，因此我们使用基于 SPF 的分解重复减少它，直到它达到 1。这给出了每个元素的“生命周期”。 
3. 将每个指数建模为剩余“工作量”等于其缩减次数。 将所有索引放入以当前值为键的最大堆中，并按索引打破平局（最左边获胜）。 这准确地反映了原始过程。 
4. 重复提取当前最大元素，应用一个归约步骤（除以其最大素因数），如果该元素尚未为 1，则将其推回堆中。 每次有元素变为1时记录全局步数； 这是它的完成时间。 
5. 所有元素完成后，我们就有了一个数组`t[i]`存储位置时的时间`i`变为 1。 
6. 建立一个范围最大的结构`t`。 每个查询`[l, r]`回报`max(t[l..r])`，这是第一次子数组中所有元素都变为 1。 

正确性取决于堆始终模拟精确规则的事实：在每一步，我们选择全局最大当前值，通过最小索引打破联系。 由于每次还原都是原子的和确定性的，因此模拟序列与真实过程完全匹配。 

关键的不变量是，在任何一步，堆都包含每个索引的当前状态，并且提取的元素正是问题定义将选择的元素。 因此，记录的完成时间是原始过程中的真实时间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import heapq

def build_spf(n):
    spf = list(range(n + 1))
    for i in range(2, int(n ** 0.5) + 1):
        if spf[i] == i:
            step = i
            for j in range(i * i, n + 1, i):
                if spf[j] == j:
                    spf[j] = i
    return spf

def largest_prime_factor(x, spf):
    while x > 1:
        p = spf[x]
        if x // p == 1:
            return x
        while x % p == 0:
            x //= p
    return x

def reduce_once(x, spf):
    lp = largest_prime_factor(x, spf)
    return x // lp

def solve():
    n, q = map(int, input().split())
    a = list(map(int, input().split()))
    maxa = max(a)

    spf = build_spf(maxa)

    heap = []
    for i, v in enumerate(a):
        heapq.heappush(heap, (-v, i))

    t = [0] * n
    step = 0

    while heap:
        val, i = heapq.heappop(heap)
        val = -val
        step += 1

        val = reduce_once(val, spf)

        if val == 1:
            t[i] = step
        else:
            heapq.heappush(heap, (-val, i))

    # build RMQ (sparse table)
    LOG = (n).bit_length()
    st = [t[:]]
    j = 1
    while (1 << j) <= n:
        prev = st[j - 1]
        cur = []
        length = len(prev)
        for i in range(length - (1 << (j - 1))):
            cur.append(max(prev[i], prev[i + (1 << (j - 1))]))
        st.append(cur)
        j += 1

    def query(l, r):
        l -= 1
        r -= 1
        length = r - l + 1
        k = length.bit_length() - 1
        return max(st[k][l], st[k][r - (1 << k) + 1])

    out = []
    for _ in range(q):
        l, r = map(int, input().split())
        out.append(str(query(l, r)))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现首先构建一个最小质因数筛，该筛子需要在每次操作的恒定时间内提取最大质因数。 堆存储负值以用 Python 的最小堆模拟最大堆。 

模拟循环是该过程的直接编码：每个弹出对应一个全局操作。 该元素被减少一次，然后重新插入或标记为已完成。 

稀疏表是根据完成时间构建的，因此每个查询都成为一定范围内的恒定时间最大查询。 

一个微妙的细节是终止条件依赖于堆空，这意味着所有元素都已达到 1 并且只被记录一次。

 ## 边缘情况

 一个关键的边缘情况是多个元素共享相同的最大值。 例如，`[5, 5, 5]`。 该算法必须始终首先选择索引 0。 如果忽略平局决胜，则索引 1 和 2 可能会提前减少，从而更改其完成时间并打破查询答案的范围，例如`[2,3]`。 

另一个边缘情况是数组已经包含 1。 用于输入`[1, x, 1]`，值为 1 的索引必须立即具有完成时间 0。基于堆的模拟自然避免在初始化后进一步推动它们。 

最后的边缘情况是像 2e6 这样的高度复合数，其中重复的最大质因数去除可能与朴素因数剥离的行为不同。 即使数字具有重复的质因数，使用 SPF 也能确保每个缩减步骤都是正确的。
