 ## 解决方案
 ## 问题理解

 我们有一条线性河流，分为 n 个部分。 每个部分最初容纳一定数量的鱼。 每个部分还有一个开始关闭的网。 

操作包括选择之前未选择过的部分 i 并打开其网络。 当这种情况发生时，当前位于 i 部分的所有鱼都会向右移动。 它们一直行进，直到到达第一个网仍然关闭的区域，然后在那里停下来，融入该区域的鱼群计数中。 一旦网被打开，它就会永久保持打开状态，因此各个部分逐渐不再充当障碍。 

每次作业后，我们必须报告河流任意一段的最大鱼类数量。 

关键是鱼不能随意重新分配。 它们总是移动到下一个仍关闭的部分，这使得该结构的行为就像由剩余关闭位置定义的段上的动态合并系统。 

在测试中，约束条件达到 n 和 Q，总和为 10^5，因此任何模拟每条鱼或每次操作的运动的解决方案都太慢。 即使 O(nQ) 也立即不可行，因为在最坏的情况下它会达到 10^10。 

一个微妙的边缘情况来自于重复跳过已经打开的部分。 一旦打开一个区域，它就不再直接接收鱼，但它仍然可以作为移动的起点，在着陆之前跳过多个打开的区域。 

例如，考虑：

 n = 5

 a = [1, 2, 3, 4, 5]

 打开第 2 部分

 所有来自第 2 区的鱼都会移动到第 3 区（因为它是第一个位于右侧的区域）。 现在如果我们打开第3部分，鱼从3跳到4，但是之前到达3的鱼也会移动。 不维护聚合状态的简单模拟将错过级联累积。 

主要困难是在动态跟踪值和最大值的同时有效维护“下一个平仓头寸”结构。 

## 方法

 蛮力模拟将显式地维护一组鱼的数量以及一个用于开放或封闭网络的布尔数组。 对于索引 i 处的每个操作，我们将向右扫描，直到找到第一个闭合部分 j，然后将所有鱼从 i 移到 j 中。 最后，我们将重新计算所有部分的最大值。 

这在逻辑上是可行的，但在最坏的情况下每个操作可能需要扫描 O(n) 个位置，并且重新计算最大值也需要 O(n) 的成本。 当 Q 达到 10^5 时，这会导致 O(nQ)，这太慢了。 

关键的观察是每个部分最多打开一次，一旦某个部分打开，它作为着陆点就会永久消失。 这表明“下一个可用平仓头寸”具有不相交集结构。 

如果我们维护一个联合查找（DSU），其中每个位置都指向其右侧的下一个仍然关闭的部分，那么当第 i 个部分打开时，我们可以立即使用查找操作找到其鱼应该落在的位置。 处理完 i 后，我们将 i 合并到 i+1 中，将其标记为不再有效的着陆位置。 这会将所有未来通过 i 直接传递的查询压缩到下一个封闭部分。 

除了 DSU 之外，我们还维护一系列当前鱼类数量和全球最大值。 每个操作仅涉及两次 DSU 查找和一次更新，因此我们避免完全扫描数组。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(nQ) | O(n) | 太慢了|
 | DSU / 下一个指针压缩 | O((n + Q) α(n)) | O((n + Q) α(n)) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`fish`与初始值。 这代表每个部分中当前的鱼。 
2. 构建一个 DSU 结构，其中每个索引 i 最初都指向自身，并且我们也在概念上将 n+1 视为代表“无有效闭合部分”的哨兵。 
3.维护数组`parent`在哪里`parent[i]`表示从 i 开始的下一个候选封闭部分。 最初，所有位置都是它们自己的父级。 
4. 对于第 i 部分的每个操作，首先检查 i 是否已经打开。 如果它已经打开，我们仍然按照给定的方式处理操作，但由于问题保证了不同的选择，这主要是安全性的。 
5. 使用`find(i)`将第一个闭合部分 j 定位在 i 或其右侧的操作。 我的所有鱼都将被转移到这里。 
6. 添加`fish[i]`到`fish[j]`，然后重置`fish[i]`归零，因为它的鱼已经全部转移出去了。 
7. 使用新值更新全局最大值`fish[j]`。 
8. 通过将 i 与 i+1 联合起来将 i 标记为已打开，这意味着将来的搜索将完全跳过 i。 

经过这些步骤后，系统在每次操作后始终反映正确的鱼积累量，并直接跟踪最大值。 

### 为什么它有效

 在任何时刻，DSU 都保持不变量：`find(x)`返回网络仍闭合的最小索引 ≥ x。 一旦打开一个部分，就会通过将其链接到其后继者来将其从有效代表集中删除。 这保证了每次鱼转移始终落在正确的下一个关闭位置。 

由于每个部分仅被删除一次并且仅向前重定向，因此没有鱼会“消失”或跳过有效的着陆点。 这个过程相当于反复收缩开放指数，而 DSU 有效地压缩了这些收缩。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    q = int(input())

    parent = list(range(n + 2))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    fish = a[:]
    max_fish = max(fish)

    for _ in range(q):
        i = int(input())

        j = find(i)

        fish[j] += fish[i]
        fish[i] = 0

        max_fish = max(max_fish, fish[j])

        parent[i] = find(i + 1)

        print(max_fish)

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```DSU 结构`parent`用于直接跳转到下一个可用的关闭部分。 这`find`函数使用路径压缩，因此重复跳转的时间几乎恒定。 

Fish 数组存储每个部分的当前负载。 当从 i 移动鱼时，我们将其添加到 DSU 解析的目的地 j 中。 重置`fish[i]`是安全的，因为一旦处理完毕，我就不再做出进一步的贡献。 

全局最大值是增量更新的，而不是从头开始重新计算，这对于效率至关重要。

 ## 边缘情况

 一种边缘情况是重复打开导致长链跳过索引。 例如，打开连续的段会迫使 DSU 快速压缩长段。 该算法处理这个问题是因为每个打开的索引都立即链接到下一个代表，所以未来`find`调用在分摊常数时间内绕过整个链。 

另一种情况是所有大值都提前移入单个部分。 由于我们增量地维护最大值，因此我们永远不会重新计算整个数组，并且即使主要部分多次更改位置，峰值也保持正确。
