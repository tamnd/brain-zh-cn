 ## 解决方案
 ## 问题理解

 我们得到一个长度的数组$n$其中一些位置包含固定整数，而一些位置被标记为缺失。 所有缺失的位置将用单个选择的值填充$k$。 替换后，我们查看每对相邻元素并测量它们的绝对差异。 目标是选择$k$使得这些相邻差异中的最大者变得尽可能小。 

关键是我们不会为不同的缺失位置分配不同的值。 每个未知槽必须取相同的值，因此选择$k$全局影响至少包含一个缺失元素的每个段。 

约束条件$n \le 10^5$每个测试用例和总计$4 \cdot 10^5$跨测试排除了对所有可能的二次检查$k$。 我们需要一个$O(n)$或者$O(n \log V)$每个测试用例的策略。 

天真的方法会尝试所有$k$从$0$到$10^9$，计算所得的最大相邻差值，并取最佳值。 这是不可能的，因为评估一个$k$已经成本$O(n)$，导致$10^{14}$最坏情况下的操作。 

一个更微妙的错误是只考虑相邻的已知值对，而忽略通过缺失片段进行的交互。 例如，在这样的段中$[10, -1, -1, 20]$，选择$k$靠近任一端点同时控制多个边缘，而不是独立控制。 

另一种常见的失败情况是假设任何丢失的段都可以在本地进行处理。 例如：

 输入：```
3
10 -1 20
```如果我们只独立地最小化每条边，我们可能会选择$k=10$或者$k=20$，但两者的最大差异为$10$，而最优选择是$k=15$, 给予$5$。 

通过单个全局变量耦合约束$k$是核心难点。 

## 方法

 蛮力的想法很简单。 对于每位候选人$k$，我们填充所有缺失的位置，计算所有相邻的差异，并取最大值。 这是有效的，因为它直接模拟了问题的定义。 问题在于规模：$10^9$的可能值$k$次$10^5$每张支票的操作次数远远超出限制。 

关键的观察结果是，最大相邻差值以分段线性方式表现$k$。 唯一受影响的边缘$k$是那些触及缺失位置的。 两个固定值之间的边缘是恒定的，优化时可以忽略$k$。 

对于任何涉及固定值的边$x$和缺失值，贡献变成$|x - k|$。 所以所有的约束都涉及$k$减少以最小化之间的最大距离$k$和一组固定的邻居。 

这意味着问题变成：选择$k$最小化该形式的表达式的最大值$|k - x_i|$。 那就相当于选择了$k$尽可能接近所有相关固定值的“最佳中心”，但有一个重要的转变：我们不是采用全局集，而是由包含缺失值的每个段引起的约束的联合。 

更准确地说，我们处理每个连续的缺失值块。 每个块都以左侧和右侧的已知值（如果存在）为界。 假设一个块位于$L$和$R$。 然后该块中的所有值都变为$k$，因此块内的边没有任何贡献，但边界的边施加了约束：$$|k - L|, \quad |k - R|$$因此，对于每个块，我们提取候选约束，最终答案取决于最小化所有此类约束加上现有固定固定边缘的最大值。 

因此，我们将问题简化为计算：

 - 最大固定-固定相邻差值（常数部分），
 - 以及该形式的所有约束$|k - x|$从块边界。 

最优的$k$位于一个小的候选集中：约束对之间的端点和中点。 在实践中，最优的$k$是在一个边界值或两个边界约束的中点实现的，因此我们可以收集所有相关的边界值并检查恒定数量的候选值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解 k |$O(n \cdot 10^9)$|$O(1)$| 太慢了 |
 | 最优约束减少 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们专注于将问题减少到一小部分约束$k$。 

1. 扫描数组并记录两个值已知的所有相邻对。 计算它们的绝对差。 这给出了一个基线答案，不能通过任何选择来改进$k$。 其中的最大值始终是最终答案的一部分。 
2. 识别缺失值的连续段。 每个段都以左侧和右侧最接近的已知值（如果存在）为界。 
3. 对于每个细分，确定它如何与$k$。 

如果某个段位于两个已知值之间$L$和$R$，然后用$k$引入约束$|k - L|$和$|k - R|$。 这是因为每个边界边都取决于$k$，且内边缘均为零。 
4. 将约束涉及的所有边界值收集到一个列表中。 这些都是固定数字，定义了函数的位置$\max |k - x|$改变斜率。 
5. 为了最小化最大距离，我们考虑候选$k$形成的值：

 所有约束的端点以及约束对之间的中点。 对于两个值$x$和$y$，最佳平衡点在$(x + y) / 2$。 
6. 评估每位候选人$k$通过计算：

 最多：

 - 基线固定差异，
 - 全部$|k - x|$限制。 
7、返回最小达到值及其对应值$k$。 

### 为什么它有效

 我们最小化的函数是一组有限绝对值表达式和常数的最大值。 这样的函数是凸函数并且是分段线性的。 整数上的凸分段线性函数的最小值必须出现在断点处或两个相邻断点之间。 这些断点正是约束中的已知值。 因此，检查端点和中点足以捕获最佳值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        fixed_edges_max = 0
        values = []

        i = 0
        while i < n:
            if a[i] == -1:
                j = i
                while j < n and a[j] == -1:
                    j += 1

                left = a[i - 1] if i > 0 else None
                right = a[j] if j < n else None

                if left is not None:
                    values.append(left)
                if right is not None:
                    values.append(right)

                i = j
            else:
                if i + 1 < n and a[i + 1] != -1:
                    fixed_edges_max = max(fixed_edges_max, abs(a[i] - a[i + 1]))
                i += 1

        if not values:
            print(fixed_edges_max, 0)
            continue

        lo, hi = min(values), max(values)
        k = (lo + hi) // 2

        def eval(k):
            best = fixed_edges_max
            for v in values:
                best = max(best, abs(k - v))
            return best

        best_k = k
        best_m = eval(k)

        for cand in [lo, hi]:
            val = eval(cand)
            if val < best_m:
                best_m = val
                best_k = cand

        print(best_m, best_k)

if __name__ == "__main__":
    solve()
```该代码首先提取来自缺失段边界的所有约束。 它单独计算固定相邻对的贡献，因为它们不受$k$。 候选值$k$是从边界值的跨度导出的，我们测试一小组有意义的点而不是整个范围。 

评估函数通过检查由缺失片段引起的所有约束来计算所得的最大相邻差异。 

一个微妙的点是处理所有元素都丢失的情况。 在这种情况下，没有任何约束，因此最佳答案为零，并且任何$k$作品; 我们回来$k=0$。

```我们收集值 [10, 20]。 

| 步骤| 价值观 | k | 最大差异|

 中点给出最佳结果，将最差偏差最小化为 5。

 ## 边缘情况

 对于缺少所有元素的输入，例如：```
3
-1 -1 -1
```没有固定的边缘，也没有边界约束。 算法产生一个空的约束集，直接返回$m = 0$和$k = 0$。 任何其他值$k$也将是有效的，但实现始终选择零。 

对于缺失值和固定值交替存在的情况：```
5
1 -1 100 -1 1
```收集的边界值为 [1, 100, 1]。 候选区间变为[1, 100]，并选择$k=50$将最大偏差最小化为 49。扫描正确捕获了所有约束，因为每个丢失的块仅贡献一次其相邻的固定值。 

对于没有缺失值的完全固定数组：```
4
1 2 3 4
```没有涉及任何限制$k$，答案就是最大相邻差，即 1。该算法检测是否存在缺失片段并完全绕过候选评估。
