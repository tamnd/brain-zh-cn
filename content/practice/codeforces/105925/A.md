 ## 解决方案
 ## 问题理解

 我们得到一个包含两个二进制信息的系统：盒子是打开还是关闭，以及里面猫的实际内部状态。 

第一个值 C 描述可观测性。 如果盒子是关闭的，从外部就无法观察到猫的状态。 如果盒子打开，状态就变得完全可观察。 

第二个值 G 描述了猫的真实内部状态，无论是活着还是死了。 然而，这个值只有在盒子打开时才对输出有意义，因为只有这样才能直接确认状态。 

任务是决定从外部观察者的角度可以对猫说些什么。 如果盒子关闭，则无论隐藏值如何，两种可能性仍然有效，因此系统仍然不明确。 如果盒子是打开的，观察者可以直接根据G判断猫是活还是死。 

输入大小是恒定的，仅包含两位信息，因此不存在需要在恒定时间评估之外进行优化的算法约束。 任何超出直接案例分析的方法都会产生不必要的开销。 

一个常见的错误是总是相信 G，而不管 C。例如，如果输入是 C = 1 且 G = 0，则可能会错误地输出猫死了。 这是错误的，因为当盒子关闭时，观察者无法访问 G，因此两种结果仍然无法区分。 

另一个错误是完全忽略 G 并且总是输出歧义。 例如，C = 0 且 G = 1 必须产生明确的答案，因为打开盒子会消除不确定性。 

## 方法

 暴力解释是直接模拟可观察性的思想：当盒子关闭时考虑系统的两种可能的解释，而当盒子打开时只考虑一种解释。 当 C = 1 时，我们将把猫同时视为潜在活着和潜在死亡，因为不可能进行观察。 当C = 0时，我们只需读取G并输出相应的状态。 

这种强力推理虽然有效，但在概念上是多余的。 当盒子关闭时，在“可能的现实”上进行分支是不必要的，因为无论 G 如何，两个分支始终保持有效。C 完全控制 G 是否可读的观察结果将问题简化为简单的条件规则。 

一旦我们认识到 C 充当 G 是否重要的​​大门，整个问题就会分解为两种情况的决策。

 ## 算法演练

 1. 读取两个整数C和G。它们分别代表可观察性和隐藏状态。 
2. 检查C是否等于1，即盒子是关闭的。 在这种情况下，无论 G 如何，观察者都无法区分活着和死亡，因此输出必须反映不确定性。 
3. 如果C等于0，则盒子打开，因此隐藏值G变得完全可观察。 在这种情况下，将G直接映射到最终答案：1对应于活着，0对应于死亡。 
4. 打印结果状态字符串。 

### 为什么它有效

 正确性来自于 C 将问题划分为两种信息访问方式根本不同的机制。 当 C = 1 时，任何观察都无法减少不确定性，因此两种状态同时保持有效的解释。 当C = 0时，系统完全揭示G，使输出具有确定性。 除了这种门控行为之外，多个输入之间不存在任何交互，因此不会出现中间状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    C, G = map(int, input().split())
    
    if C == 1:
        print("vivo e morto")
    else:
        if G == 1:
            print("vivo")
        else:
            print("morto")

if __name__ == "__main__":
    solve()
```该实现直接对算法中描述的两种机制进行编码。 第一个分支处理闭盒情况，其中输出是固定的，而与 G 无关。第二个分支处理开盒情况，其中 G 用作最终状态的直接查找。 除了这两个条件之外，没有边缘情况，并且不需要额外的标准化或预处理。

 ## 边缘情况

 唯一有意义的边缘区别是 C 是否在 0 和 1 之间翻转。 

对于输入：```
1 1
```该算法进入闭箱分支并立即输出歧义，完全忽略 G。 这证实了当系统被密封时，即使是明显“活跃”的内部状态也不会影响可观察性。 

对于输入：```
0 0
```算法进入开箱分支，直接读取G。 由于 G 为 0，因此它输出“morto”，这表明一旦 C 允许观察，就不再存在歧义。 

这两种情况都证实了算法正确地将认知条件（C）与物理状态（G）分开，这是问题的核心结构。
