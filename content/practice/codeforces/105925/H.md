 ## 解决方案
 ## 问题理解

 我们得到一个整数$X$。 我们需要找到最大的整数$Y$这样$Y \le X$和二进制表示$Y$是一个回文。 

二进制回文意味着，如果以 2 为基数写入数字且不带前导零，则位序列从左到右和从右到左读取的值相同。 例如，$9 = 1001_2$是有效的，同时$10 = 1010_2$不是。 

输入大小约束$X \le 10^{18}$表示二进制表示最多有 60 位。 这立即排除了任何从每个候选者开始扫描所有整数的暴力破解$X$，因为在最坏的情况下我们会检查$10^{18}$值，甚至每个值进行一次二进制回文检查也会太慢。 

问题的结构表明，与整个范围相比，有效答案很少见，但仍然以非常规则的方式分布，因为二进制回文完全由其前半部分确定。 

一个天真的错误是假设我们可以从$X$并测试回文性。 例如，如果$X = 1000_2$，我们会检查许多值，例如$111, 110, 101, 100$在达到像这样的回文之前$111_2$。 对于大输入来说，这会严重退化。 

另一个微妙的问题是前导位。 像这样的数字$0110_2$被认为无效，因为前导零不是表示的一部分。 任何构造方法都必须确保最高有效位始终为 1。 

## 方法

 蛮力方法很简单。 开始于$X$，我们检查每个数字是否是二进制回文。 支票本身是$O(\log X)$，因为我们转换为二进制并比较字符串的末尾。 在最坏的情况下，如果$X$就在回文的稀疏区域下方，我们可以在找到一个整数之前扫描许多连续的整数。 这可能会退化为$O(X \log X)$，在约束条件下这是不可能的。 

关键的结构观察是二进制回文完全由其前半部分确定。 一旦我们修复了前缀，后缀就会被镜像强制。 因此，我们不是搜索所有整数，而是搜索可能的半前缀，构造候选回文，并将它们与$X$。 

这减少了生成与以下相同位长度的回文的问题$X$，且至多低于其一位长度。 对于每个长度，我们可以通过取前缀来构造最佳回文$X$，镜像它，如果超过则向下调整$X$。 调整是局部的：如果构造的回文太大，我们再次减少前缀和镜像。 

这将问题转化为恒定数量的构造和比较，每次最多 60 位。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(X \log X)$|$O(1)$| 太慢了|
 | 最佳 |$O(\log X)$|$O(\log X)$| 已接受 |

 ## 算法演练

 我们处理二进制长度$X$，因为答案必须具有相同的长度或少一个长度。 

1. 转换$X$转化为它的二进制表示$s$。 让$n$是它的长度。 

答案不能少于$n-1$位，除非没有长度的回文$n$或者$n-1$适合，而这在向下搜索中永远不会发生，因为至少$1$始终有效。 
2. 尝试构造长度最大的回文$n$小于或等于$X$。 

我们采取第一个$\lceil n/2 \rceil$位作为前缀候选。 该前缀通过镜像确定整个回文。 
3. 通过围绕中心反射该前缀来构建回文。 

如果$n$为奇数，中间位共享； 否则它会对称镜像。 
4. 将这个构造的回文与$X$。 

如果小于或等于$X$，它是长度的最佳候选$n$。 
5. 如果大于$X$，将前缀递减为二进制数并再次重建回文。 

这一步至关重要，因为在实践中只需一次递减就足够了：减少前缀严格减少字典顺序中的回文，这与固定长度二进制数的数字顺序相匹配。 
6. 如果调整后仍无效$n$-位回文是可以接受的，重复相同的长度构造$n-1$。 

这保证了正确性，因为每个长度都存在二进制回文，并且最大下限$X$必须位于这两个长度之一。 

### 为什么它有效

 对于固定长度，二进制数按照与其数值相同的方式按字典顺序排序。 通过镜像前缀构造回文可确保我们为该前缀类生成最大可能的候选者。 任何小于给定回文数的数字必须来自较小的前缀或较小的长度。 因此，向下调整前缀会按降序无间隙地探索所有候选者，并切换到$n-1$覆盖剩余的搜索空间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_pal(prefix, n):
    s = bin(prefix)[2:]
    # ensure prefix has enough bits for mirroring
    s = s.zfill((n + 1) // 2)
    if n % 2 == 0:
        return int(s + s[::-1], 2)
    else:
        return int(s + s[-2::-1], 2)

def solve():
    x = int(input().strip())
    s = bin(x)[2:]
    n = len(s)

    def best_for_length(n):
        prefix_len = (n + 1) // 2
        prefix = int(s[:prefix_len], 2)

        while True:
            cand = build_pal(prefix, n)
            if cand <= x:
                return cand
            prefix -= 1

    ans = best_for_length(n)
    if ans == 0:
        ans = best_for_length(n - 1)

    print(ans)

if __name__ == "__main__":
    solve()
```解决方案首先将数字转换为二进制字符串形式，以便前缀提取变成直接切片。 核心例程通过镜像给定的前缀构造回文，仔细地以不同的方式处理奇数和偶数长度。 

当构造的回文数超过时，内部循环仅递减前缀$X$。 这是安全的，因为减少前缀会严格减少生成的回文，因此我们单调地向有效候选移动。 

最后，如果没有相同位长的有效回文，我们切换到$n-1$位，因为它完全覆盖了下面的剩余搜索空间$X$。

 ## 边缘情况

 对于$X = 1$，该算法立即适用于单位回文。 二进制表示是$1$，并且已经有效，所以不需要构建。 

对于像这样的值$X = 2$其中二进制是$10_2$，长度为 2 的回文尝试产生$11_2 = 3$，这超过了$X$，所以我们减少前缀并获得$1$位回文，产生$1$。 这表明了向较短长度的回退。 

对于接近的大值$2^n - 1$，前缀结构往往会产生略高于的候选$X$，在成功之前强制执行一个递减步骤，表明前缀调整循环不会溢出或需要大量搜索。
