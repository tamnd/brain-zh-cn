 ## 解决方案
 ## 问题理解

 我们给定一个长度的时间间隔$T$，并且每秒必须有一个传感器处于活动状态。 每个传感器都会产生一个取决于传感器和时间的值，因此激活传感器$i$在某个时间$j$贡献$c(i, j)$至总分。 

然而，传感器不能任意切换。 一旦传感器打开，它必须在一段连续的时间段内保持活动状态，该时间段的长度介于$L$和$U$，包含在内。 该块结束后，我们可以切换到另一个传感器，开始一个新块，然后继续，直到整个间隔$[1, T]$被完全覆盖。 

任务是将时间线划分为连续的段，其中每个段的长度为$[L, U]$，为每个段分配一个传感器，并最大化所有时间步长的贡献总和。 

输入尺寸在时间上很小（$T \le 100$）但传感器数量大（$N \le 5000$）。 这种不对称性是关键：我们可以承受二次甚至三次工作$T$，但是任何在没有结构的每次 DP 内重复迭代所有传感器的操作都必须仔细优化。 特别是，任何天真地尝试每个部分的所有传感器的解决方案都将接近$O(NT^2)$，这是边界，但如果每个内部计算简单且结构良好，那么仍然可行。 

一个常见的失败案例是假设每个细分市场都进行贪婪的选择，而不考虑未来的可行性。 例如，为第一段选择最佳传感器可能会强制分段无法满足剩余长度约束。 

考虑一下这个小例子，贪婪在精神上失败了。 认为$T=5$,$L=2$,$U=3$。 如果一个传感器表现出色$[1,2]$但后来很糟糕，另一个早期稍差，但在$[3,5]$，选择局部最好的早期分段可以阻止更好的全局分区。 该结构本质上是全局的，因为片段长度限制了剩余时间线的分解方式。 

另一个微妙的问题是每个分段的最佳传感器取决于确切的间隔$[l, r]$，而不仅仅是其长度。 因此，我们无法预先计算每个长度的最佳传感器； 我们必须考虑与时间相关的分数。 

## 方法

 暴力方法尝试所有可能的方法将时间线分割成有效的片段，并为每个片段分配一个传感器。 的分区数量呈指数级增长$T$，即使我们修复了一个分区，为每个段分配最好的传感器仍然需要检查所有$N$段范围内的传感器。 大致与$O(N)$每个分段和指数级多的分段，这太慢了。 

关键的观察结果是该结构纯粹是一维且基于段的。 一旦我们决定一个片段是$[l, r]$，该段传感器的最佳选择独立于所有其他段。 这将传感器选择与分段分离：对于每个间隔，我们可以预先计算可达到的最佳分数。 

这将问题变成了经典的区间动态规划问题。 我们计算每个间隔的最佳分数$[l, r]$，然后随着时间的推移运行 DP，其中每个状态$dp[t]$表示完全覆盖前缀的可达到的最高分数$[1, t]$。 转换尝试所有有效的段长度。 

主要优化是使用每个传感器的前缀和来预先计算间隔最佳值，以便间隔评分变得足够快以适应约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解分区 | 指数| O(1) | O(1) | 太慢了|
 | 带预计算的区间 DP |$O(NT^2 + TU)$|$O(NT)$| 已接受 |

 ## 算法演练

 ### 步骤 1：预先计算每个传感器的前缀和

 对于每个传感器$i$，随着时间的推移构建一个前缀和数组，以便我们可以计算$c(i, l) + \dots + c(i, r)$在恒定的时间内。 这将区间评估从线段长度的线性转换为$O(1)$。 

### 步骤 2：计算每个时间间隔的最佳传感器

 对于每个间隔$[l, r]$，我们计算通过选择最佳传感器可获得的最大分数：$$best[l][r] = \max_i \sum_{j=l}^{r} c(i, j)$$这一步成本高昂但可行，因为$T \le 100$，因此最多有 10,000 个间隔。 对于每个间隔，我们扫描所有$N$传感器。 

### 步骤 3：初始化 DP

 我们定义$dp[t]$作为最高分数恰好覆盖第一个$t$秒。 我们设定$dp[0] = 0$和所有其他状态为负无穷，因为它们最初是无法到达的。 

### 步骤 4：过渡段结尾

 对于每个端点$t$，我们尝试每个有效的段长度$len \in [L, U]$。 该段将开始于$t-len+1$。 如果该开始有效，我们将更新：$$dp[t] = \max(dp[t], dp[t-len] + best[t-len+1][t])$$这强制每个片段都遵守持续时间限制。 

###第五步：输出结果

 答案是$dp[T]$。 如果仍然无法访问，我们输出$-1$。 

### 为什么它有效

 DP 状态将时间线划分为有效的独立段。 每个有效的完整分配恰好对应于一个 DP 转换序列，并且每个 DP 转换对应于具有最佳选择的传感器的有效段。 前缀 DP 确保没有重叠的段和没有间隙，而间隔预计算确保在每个段内我们始终独立于其他选择选择最佳的传感器。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

NEG = -10**18

N, T = map(int, input().split())
c = [list(map(int, input().split())) for _ in range(N)]
L, U = map(int, input().split())

# prefix sums per sensor
pref = [[0] * (T + 1) for _ in range(N)]
for i in range(N):
    for j in range(1, T + 1):
        pref[i][j] = pref[i][j - 1] + c[i][j - 1]

def get_sum(i, l, r):
    return pref[i][r] - pref[i][l - 1]

# best[l][r] = best sensor sum for interval
best = [[NEG] * (T + 1) for _ in range(T + 1)]

for l in range(1, T + 1):
    for r in range(l, T + 1):
        best_val = NEG
        for i in range(N):
            best_val = max(best_val, get_sum(i, l, r))
        best[l][r] = best_val

dp = [NEG] * (T + 1)
dp[0] = 0

for t in range(1, T + 1):
    for length in range(L, U + 1):
        if t - length < 0:
            continue
        l = t - length + 1
        if best[l][t] == NEG:
            continue
        dp[t] = max(dp[t], dp[t - length] + best[l][t])

print(dp[T] if dp[T] > NEG // 2 else -1)
```前缀和是必不可少的，因为如果没有它们，每个区间评估都会花费$O(T)$，进行充分的预计算$O(NT^3)$，这是不必要的。 

DP 循环仔细地遵守段边界。 条件$t - length \ge 0$防止无效前缀，并检查$NEG$确保我们永远不会扩展不可能的状态。 

## 工作示例

 ### 示例 1

 输入：```
3 5
2 3 2 1 2
1 1 5 1 2
1 2 2 1 5

```我们首先隐式计算区间最佳值。 然后DP继续：

 | t | 选定的部分 | 增值 | dp[t] | dp[t] |
 | --- | --- | --- | --- |
 | 0 | - | - | 0 |
 | 1 | [1,1]| 最佳单个传感器 = 2 | 2 |
 | 2 | [1,2]| 最佳间隔 = 5 | 5 |
 | 3 | [1,3]| 最佳间隔 = 7 | 7 |
 | 4 | [1,4]| 最佳间隔 = 8 | 8 |
 | 5 | [1,5]| 最佳间隔 = 11 | 11 | 11

 这显示了无约束的情况$L=1, U=5$折叠成一个覆盖所有内容的部分。 

### 示例 2

 输入：```
3 5
2 3 2 1 2
1 1 5 1 2
1 2 2 1 5
2 3
```现在每个段的长度必须为 2 或 3。 

| t | 细分市场选择 | dp[t] | dp[t] |
 | --- | --- | --- |
 | 0 | - | 0 |
 | 2 | [1,2]| 最佳 = 5 → 5 |
 | 3 | [1,3]| 最佳 = 7 → 7 |
 | 4 | [2,4] 或 [1,2]+[3,4] 最佳组合 | 8 |
 | 5 | 仅有效分割 | 10 | 10

 这演示了 DP 如何强制有效的段长度，同时仍然为每个段选择最佳传感器。

 ## 边缘情况

 紧约束边缘情况发生在$L = U$，强制所有段具有相同的长度。 在这种情况下，DP 的每个状态只有一次有效转换，任何不正确的区间索引都会立即破坏可行性。 该算法仍然有效，因为循环结束了`length`退化为单个固定步骤，并且每个状态要么可达，要么不可达，没有歧义。 

另一种边缘情况发生在$T$无法分解为有效的段长度。 例如，$T=5$,$L=2$,$U=4$。 2-4 个长度段的组合总和不能等于 5，因此除$dp[0]$仍然无法访问。 算法正确输出$-1$因为所有可达状态的转换都无法准确覆盖$T$。
