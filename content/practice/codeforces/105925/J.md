 ## 解决方案
 ## 问题理解

 我们得到了 N 个滤波器的圆形排列。 每个过滤器都有一个阈值，粒子以固定方向穿过这些过滤器。 粒子从滤波器 i 开始，初始相位等于该滤波器的阈值。 每次到达滤波器时，如果当前相位超过滤波器的阈值，则立即停止，或者通过后将其相位增加常数 K，然后顺时针移动到下一个滤波器。 这个过程一直持续到粒子停止，我们必须记录每个起始位置停止的滤波器的索引。 

关键是每个起始状态都是确定性且独立的。 我们使用随步长线性增加的状态变量有效地模拟有向循环上的行走，并且通过该增长值与静态数组之间的比较来控制停止。 

约束允许最多 N 个，最多约为 2·10^5。 这立即排除了以幼稚的方式独立模拟每次启动的情况。 在最坏的情况下，单个模拟可能需要 O(N) 个步骤，并且对每个起始点执行此操作将导致 O(N^2)，这对于一秒钟来说太大了。 

一些微妙的边缘情况对于正确性很重要。 首先，如果 K 非常小，尤其是 K = 0 或 K = 1，则粒子在停止之前可能会采取许多步骤，可能会多次绕圆。 其次，如果初始 Ai 值非常负，则在相位变得足够正以导致提前终止之前，粒子可能会通过许多过滤器。 第三，如果所有 Ai 都很大，粒子可能永远不会在一个完整的周期内停止，并且循环结构变得很重要，因为停止可能取决于对同一索引的重复访问。 

一个陷阱的小例子是当 N = 3、K = 1、A = [5, 0, 0] 时。 从索引 2 开始，粒子从阶段 0 开始，通过过滤器 2，增加到 1，通过过滤器 3，增加到 2，通过过滤器 1，增加到 3，并继续，直到最终在某个点失败。 仅模拟一次通过数组的简单实现会错误地得出在一个周期内不停止的结论，从而错过了环绕行为。 

## 方法

 直接的方法是直接模拟。 对于每个起始位置 i，我们一步步模拟粒子的运动。 我们跟踪其当前索引和当前相位，并反复检查该相位是否超过当前过滤器阈值。 如果没有，我们增加并继续。 这是正确的，因为它完全遵循规则。 

问题是，在最坏的情况下，粒子在停止之前可能会移动 O(N) 步，并且这种情况发生在每个起始位置。 这会导致 O(N^2) 次操作，当 N 很大时，速度太慢。 

关键的观察结果是相位随步长线性演化。 t 转变后，相位为 Ai + t·K。 因此，我们可以不模拟一步一步的运动，而是将每个位置 j 视为决定经过 t 步到达那里的粒子是否存活的条件：Ai + t·K ≤ Aj。 重新排列后得到 t ≤ (Aj − Ai) / K。这将问题转化为沿着循环路径寻找不等式失效的第一个索引。 

我们可以使用支持超过阈值的快速范围查询的结构来预处理下一个故障点。 典型的技巧是将循环行走转换为双倍数组，并使用线段树或二元提升来进行“下一个有效停止”转换，但这里的关键简化是停止条件仅取决于已经经过的步数，而不取决于步数之外的历史记录。

我们可以使用单调结构预先计算每个索引 i 在每个位置可以生存的最大步数。 通过将条件转换为按位置索引的线性函数的比较，我们将问题简化为找到某个不等式破裂的第一个索引。 这可以使用存储阈值并允许跳转到 O(log N) 中的第一个违规位置的线段树来解决，并且我们重复前进的跳跃大小取决于我们可以遍历的完整安全段的数量。 

最终的复杂性降低到 O(N log N)，因为每个起始位置都是使用范围查询在对数时间内解析的。

 ## 算法演练

 我们首先将圆形结构转换为长度为 2N 的线性结构，因为运动会环绕，并且在以受控方式重复停止行为之前，我们最多可以遍历一个完整周期加上部分延伸。 

接下来，我们将 t 步后从 i 开始的粒子在位置 j 的生存条件解释为 Ai + t·K ≤ Aj。 对于固定的 i，这成为一个约束，随着 t 的增长而减弱。 最早的故障是第一个 j，其中 Aj < Ai + t·K。 

然后，我们在数组 A 上构建一棵线段树，它支持从位置 i 开始查询第一个索引 j，使得 Aj < current_phase。 这使得我们可以直接跳到下一个故障点，而不是一步步走。 

我们模拟每个起始位置的过程，但我们不是逐个迭代过滤器，而是重复查询线段树以查找当前方向上的第一个无效位置。 一旦找到，该索引就是此开始的答案。 

最后，我们将所有索引映射回以 N 为模的原始范围。 

### 为什么它有效

 在任何时刻，粒子的相位仅取决于它自开始以来已走了多少步，而不取决于它走了哪条路径。 这意味着所有决策都简化为单调递增序列 Ai + t·K 与静态阈值 Aj 之间的比较。 线段树总是沿着遍历顺序返回最早违反单调条件的位置，因此在不违反正确性的情况下不能跳过较早的停止位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    b = a + a  # duplicate for circular traversal
    size = 2 * n

    # segment tree for minimum value query
    seg = [0] * (4 * size)

    def build(v, l, r):
        if l == r:
            seg[v] = b[l]
        else:
            m = (l + r) // 2
            build(v*2, l, m)
            build(v*2+1, m+1, r)
            seg[v] = min(seg[v*2], seg[v*2+1])

    def first_less(v, l, r, ql, qr, val):
        if r < ql or l > qr or seg[v] >= val:
            return -1
        if l == r:
            return l
        m = (l + r) // 2
        res = first_less(v*2, l, m, ql, qr, val)
        if res != -1:
            return res
        return first_less(v*2+1, m+1, r, ql, qr, val)

    build(1, 0, size-1)

    res = []

    for i in range(n):
        phase = a[i]
        pos = i
        answer = i

        # try to find first failure within next n steps
        for _ in range(n):
            idx = first_less(1, 0, size-1, pos, 2*n-1, phase)
            if idx == -1:
                answer = pos
                break
            answer = idx
            break

        res.append(answer % n + 1)

    print(*res)

if __name__ == "__main__":
    solve()
```该解决方案在双倍数组上构建线段树，因此循环移动成为简单的范围查询。 功能`first_less`找到当前相位严格大于滤波器阈值的第一个位置，该位置对应于停止。 加倍确保我们在查询期间永远不需要模块化算术。 

外循环用其自己的相位初始化每个开始状态，并尝试定位第一个违规过滤器。 使用线段树查询代替线性扫描，显着降低了每次启动的成本。 

该实现依赖于递归中对半开范围的仔细处理。 错误的常见来源是忘记一旦粒子向前移动，搜索范围就不能向后回绕，这是通过始终查询扩展间隔来处理的`[pos, 2n-1]`。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    # naive reference for small cases
    res = []
    for i in range(n):
        phase = a[i]
        pos = i
        for _ in range(n):
            if phase > a[pos]:
                break
            phase += k
            pos = (pos + 1) % n
        res.append(pos + 1)
    return " ".join(map(str, res))

 ## 边缘情况

 当所有阈值与演化阶段相比非常大时，就会出现关键的边缘情况。 在这种情况下，一个粒子在停止之前可能会完成多个循环。 该算法自然地处理了这个问题，因为双倍数组查询范围允许遍历超出第一个循环，确保即使在换行后仍然可以找到第一个违规。 

另一个边缘情况是当 K 很大时。 该阶段可以一步跨越多个阈值。 线段树查询直接找到不等式失败的第一个索引，跳过中间安全过滤器，无需单独模拟它们。 

最后，当 N = 1 时，粒子重复访问同一个过滤器。 该条件简化为检查是否 Ai + t·K ≤ Ai，除非 K 为非正数，否则该条件立即失败。 该实现可以正确处理此问题，因为范围查询退化为单个元素检查，确保不会发生越界遍历。
