 ## 解决方案
 ## 问题理解

 我们得到两个长度相等的字符串，表示量子位集合的状态。 第一个字符串描述“隔离”配置，其中某些位置是稳定位`0`或者`1`，有些位置不确定，标记为`*`，意味着量子位处于叠加状态。 第二个字符串描述了退相干后在现实条件下观察到的情况，其中每个`*`第一个字符串已折叠为`0`或者`1`。 

所有已经存在的位置`0`或者`1`第一个字符串中的内容保证在第二个字符串中保持不变。 仅那些职位`*`可以改变，在这些位置我们比较崩溃是否改变了状态。 

任务是计算一个比率：在所有开始的位置中`*`，我们计算其中有多少个在崩溃后改变了值，然后除以总数`*`职位。 答案必须以小数形式打印，小数点后恰好有两位数。 

约束允许字符串的长度最多为 100,000 左右。 这立即排除了任何在单个线性扫描之外进行每个位置大量计算的方法。 任何二次或涉及字符串嵌套循环的操作都会太慢。 

当没有`*`第一个字符串中的字符。 该声明保证不会发生这种情况，因此除以零不是问题。 另一个边缘情况是当所有`*`位置折叠与第二个字符串相同，除了一个，它应该产生一个非常小的分数，如`0.01`或者`0.00`取决于格式。 

## 方法

 直接的解释是迭代所有索引，并且对于第一个字符串具有的每个位置`*`，比较两个字符串。 我们维护一个计数器来记录存在多少个这样的位置，另一个计数器来记录两个字符串之间有多少个不同的位置。 答案很简单，就是这两个值的比率。 

这种蛮力方法在结构上已经是最佳的，因为每个索引都必须至少检查一次。 位置之间不存在组合爆炸或依赖性，因此不需要高级数据结构或预处理。 唯一需要的操作是单遍比较。 

关键的观察是，问题并不要求任何全球性或相互依存的东西。 每个索引都独立地影响最终比率，因此计算减少为对本地事件进行计数。 

蛮力是线性的，并且在约束范围内工作，因为它对每个字符执行一次恒定时间检查。 任何更复杂的方法都会产生不必要的开销。

 ## 算法演练

 我们并行处理两个字符串并维护两个计数器：一个用于记录总叠加位置，另一个用于记录其中实际更改的位置数量。 

1.初始化两个整数，`total_star`和`changed`，都设置为零。 这些将累加所需比率的分母和分子。 
2. 迭代每个索引`i`从`0`到`N - 1`。 在每个索引处，检查第一个字符串中的字符是否是`*`。 这是唯一有助于计算的情况。 
3.如果`S[i] == '*'`, 增量`total_star`一个。 无论第二个字符串中发生什么，都会将该位置计为分母的一部分。 
4. 还是在同样的条件下，比较一下`S[i]`和`T[i]`。 如果不同，则增加`changed`。 自从`S[i]`总是`*`在这里，这有效地检查折叠值是否与原始未知状态不同。 
5. 完成循环后，计算比率`changed / total_star`作为浮点数。 
6. 打印结果，格式为小数点后精确两位数。 

这样做的原因是每个`*`位置对最终的类概率比有独立的影响。 位置之间没有相互作用，因此汇总局部差异可以直接产生全局度量。 

### 为什么它有效

 每个索引在哪里`S[i]`是`*`定义了一个类似伯努利的事件：崩溃要么与观测值匹配，要么不匹配。 该问题要求所有此类独立事件之间不匹配的比例。 该算法维护总事件空间和失败子集的精确计数。 由于每个有效索引都只计算一次并分类一次，因此最终比率在数学上与语句中的定义相同。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input().strip())
    s = input().strip()
    t = input().strip()

    total_star = 0
    changed = 0

    for i in range(n):
        if s[i] == '*':
            total_star += 1
            if t[i] != s[i]:
                changed += 1

    ans = changed / total_star
    print(f"{ans:.2f}")

if __name__ == "__main__":
    main()
```实现几乎直接遵循算法。 循环是解决方案的核心，它对每个字符执行恒定时间的工作。 The formatting step with`f"{ans:.2f}"`确保所需的精度，无需手动舍入逻辑。 

一个微妙的一点是我们从不试图解释`0`或者`1`在非明星职位上，因为声明中的保证使它们变得无关紧要。 这可以使实现最小化并避免不必要的条件。

 ## 边缘情况

 第一个字符串的最小输入`"*"`，第二个是`"0"`显示了最简单的退相干事件。 该算法处理一个索引，同时递增两个索引`total_star`和`changed`，和输出`1.00`。 

所有字符都为的情况`*`但第二个字符串是相同的，例如`"***"`和`"***"`，表明分子保持为零，而分母最大。 算法正确返回`0.00`因为没有崩溃与原始状态不同。 

完全改变的场景，例如`"***"`到`"000"`确认平等检查`s[i]`就足够了：每个位置都算作自此以来的更改`t[i] != '*'`在所有指数中。
