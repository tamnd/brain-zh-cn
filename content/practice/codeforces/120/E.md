 ## 问题理解

 我们被要求分析 _n × n_ 棋盘上的两人游戏。 佩蒂亚和吉娜轮流放置骑士，使任何骑士都无法威胁其他骑士。 骑士以标准的 L 形动作威胁阵地。 第一个无法放置马的玩家失败，而佩蒂亚总是先发。 输入给出了几种棋盘尺寸，对于每个棋盘，我们必须确定如果双方都发挥最佳，哪位玩家获胜。 如果 Petya 获胜，则输出为“0”；如果 Gena 获胜，则输出为“1”。 

约束表明`1 ≤ n ≤ 10000`直至`T = 100`测试用例。 模拟游戏或尝试所有位置的简单方法需要`O(n^2)`每个板的操作。 和`n`如果最多 10,000 个，则每块板大约需要 1 亿次操作，这对于 100 个测试用例来说太慢了。 我们需要一个`O(1)`或者`O(T)`每个测试用例的解决方案。 

当电路板非常小时，会出现不明显的边缘情况。 例如，对于`n = 1`，Petya 可以放置一名骑士并立即获胜。 为了`n = 2`，Petya 放置了一名马，但棋盘已满，Gena 可以做出反应并最终迫使 Petya 输掉。 小的`n`表明棋盘大小的平衡比明确模拟马的动作更重要。 

## 方法

 蛮力方法试图模拟骑士的每个位置，同时检查没有两个骑士互相威胁。 这在理论上是正确的，但操作计数大致为`O(n^2)`每块板。 为了`n = 10,000`，每个电路板产生约 1 亿次迭代。 通过 100 个测试用例，我们将达到`10^10`的操作，这是不可行的。 

关键的见解是马在空棋盘上的放置遵循已知的数学模式。 _n × n_ 棋盘上的最大非攻击马数为：

 - 如果`n % 2 == 0`，棋盘可以分割成棋盘图案。 一半的方格可以被骑士占领而不会发生冲突。 Petya 排名第一，因为安全方格的数量是`n^2 / 2`，奇偶性决定胜负。 
- 如果`n % 2 == 1`，奇数行/列会添加一个额外的正方形。 最佳游戏仍然减少到平价：如果安全方块的总数是奇数，则开始的玩家将控制最后一个骑士。 

事实证明，在分析小例子并概括之后，游戏结果取决于`n % 4`：

- 如果`n % 4 == 0`或者`n % 4 == 1`, 佩蒂亚获胜 (`0`）
- 如果`n % 4 == 2`或者`n % 4 == 3`, 吉娜获胜 (`1`）

 这一观察将问题压缩为`O(n^2)`模拟每个测试用例的简单模检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每板 O(n^2) | O(n^2) | O(n^2) | 太慢了 |
 | 最佳 | 每板 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`T`。 
2. 迭代每个板尺寸`n`。 
3. 计算`n % 4`。 

- 如果余数为0或1，则输出`0`（佩蒂亚获胜）。 
- 否则，输出`1`（吉娜获胜）。 
4. 继续处理下一块板，直到处理完所有测试用例。 

工作原理：模 4 模式源自骑士放置几何形状。 通过将棋盘上的 2×2 块着色，我们可以看到每个 2×2 块可以恰好包含两个处于非威胁位置的马。 此平铺图案每 4 行/列重复一次。 模 4 分析计算部分填充块中的剩余方格，使我们能够预测哪个玩家将放置最后一个骑士。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

T = int(input())
for _ in range(T):
    n = int(input())
    if n % 4 == 0 or n % 4 == 1:
        print(0)
    else:
        print(1)
```解决方案如下`T`以及每个棋盘尺寸，然后根据模 4 规则打印获胜者。 使用`sys.stdin.readline`确保大数据的快速输入`T`或者`n`。 模运算捕捉了安全马放置的模式。 

## 工作示例

 ### 示例 1

 输入：`n = 2`

`2 % 4 = 2`，所以输出是`1`（吉娜获胜）。 

| 步骤| n | n % 4 | 获胜者 |
 | --- | --- | --- | --- |
 | 1 | 2 | 2 | 吉纳 |

 解释：一块 2×2 的棋盘只能容纳两名骑士，Petya 放置一个，Gena 响应第二个，让 Petya 一动不动。 

### 示例 2

 输入：`n = 1`

`1 % 4 = 1`，所以输出是`0`（佩蒂亚获胜）。 

| 步骤| n | n % 4 | 获胜者 |
 | --- | --- | --- | --- |
 | 1 | 1 | 1 | 彼佳|

 解释：只有一个方格存在，Petya立即占领它，Gena没有任何动作。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    T = int(input())
    for _ in range(T):
        n = int(input())
        if n % 4 == 0 or n % 4 == 1:
            output.append("0")
        else:
            output.append("1")
    return "\n".join(output)

 ## 边缘情况

 对于`n = 1`，模规则输出`0`。 只有一个方格存在，所以 Petya 立即获胜。 为了`n = 2`，模给出`1`，匹配 Petya 放置一名骑士、Gena 放置第二名、Petya 失败的场景。 模 4 模式正确地推广到所有`n`≤ 10,000，避免小板中的差一错误，并充分捕获大板的重复 2×2 平铺图案。
