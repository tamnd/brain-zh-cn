 ## 解决方案
 ## 问题理解

 我们有一个圆桌，分为`n`扇区，每个扇区包含一个测验问题。 有些问题已经被问过，标有`0`，其他仍然可用，标有`1`。 箭头指向扇区`k`，目标是确定下一个要问的问题的数量。 如果箭头所指的扇区已经被问过，则主持人按顺时针顺序选择下一个未回答的问题。 编号从扇区开始环绕`n`返回部门`1`。 

输入由两个整数组成，`n`和`k`，随后是一个列表`n`代表每个扇区状态的整数。 输出是一个整数，表示下一个要问的问题的扇区号。 

限制很小：`n`可以达到 1000。这意味着即使是围绕表进行简单的线性搜索也足够有效，因为在最坏的情况下我们会执行`n`每个查询检查，最多 1000 次操作。 

不明显的边缘情况包括箭头指向最后一个扇区，下一个可用问题绕到开头，或者箭头直接指向可用问题（无需移动）。 例如，如果`n = 5`,`k = 5`，数组是`[0, 1, 0, 1, 0]`，箭头指向已询问的扇区（`0`）。 顺时针下一个未应答的扇区是`2`， 不是`5`， 因为`5`已被使用。 

## 方法

 暴力方法既简单又正确：从箭头指示的部分开始，检查问题是否已经被问过。 如果有，则一次顺时针移动一个扇区，必要时绕一圈，直到找到可用的问题。 最坏情况的复杂度是`O(n)`，这是可以接受的`n ≤ 1000`。 这种方法之所以有效，是因为我们保证至少有一个问题没有得到解答。 

最佳解决方案本质上与暴力破解相同，因为问题的结构 - 一个小的圆形数组 - 允许我们线性搜索而不会受到惩罚。 不需要额外的数据结构，并且可以使用模运算来处理环绕。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(n) | 已接受 |
 | 最佳 | O(n) | O(n) | 已接受 |

 朴素方法和最优方法在这里收敛，因为问题的约束很小并且操作很简单。 

## 算法演练

 1. 阅读`n`和`k`。 调整`k`从零开始的索引更容易访问数组。 
2. 读取问题状态数组。 每个元素是`1`如果问题没有得到解答并且`0`如果已经被问过。 
3. 在索引处开始循环`k-1`并顺时针移动。 对于每次迭代，检查当前扇区是否可用。 
4. 如果当前扇区包含未解答的问题（`1`)，打印其从 1 开始的索引并停止。 
5. 如果已询问当前扇区（`0`)，将索引加一，并使用模`n`如有必要，可以回到开头。 

为什么它有效：不变的是，在每一步，我们要么找到一个未解答的问题，要么继续进入下一个部分。 因为该问题保证至少有一个未解答的问题，所以循环将始终以正确的扇区终止。 模运算确保我们正确处理表格的循环性质。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = list(map(int, input().split()))

# convert to zero-based index
idx = k - 1

while True:
    if a[idx] == 1:
        print(idx + 1)  # output 1-based index
        break
    idx = (idx + 1) % n
```代码从箭头指示的扇区开始，检查是否无人应答，如果需要则顺时针移动。 模数确保经过最后一个扇区后会绕到第一个扇区。 使用从零开始的索引在内部简化了数组访问和算术。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    idx = k - 1
    while True:
        if a[idx] == 1:
            print(idx + 1)
            break
        idx = (idx + 1) % n
    return output.getvalue().strip()

# Provided sample

 ## 边缘情况

 如果箭头指向最后一个扇区并且已经询问了所有先前的扇区，则模数确保搜索从头开始继续。 用于输入`5 5\n0 1 0 1 0`，搜索从索引开始`4`到`0`， 然后`1`，这是第一个可用的扇区，正确输出`2`。 

对于具有未解答问题的单扇区表，`1 1\n1`，循环立即找到可用的问题，无需任何迭代，正确输出`1`。 

该算法通过不变式处理所有边缘情况，即它始终按顺时针顺序检查每个扇区，直到找到未解答的问题，并且模数保证了圆桌的正确环绕。
