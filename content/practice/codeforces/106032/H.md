 ## 解决方案
 ## 问题理解

 我们有一个在非常结构化的有向图上玩的游戏。 顶点不是按层排列，而是按层排列。 每层都是一行节点，在层内您只能从左向右移动。 从一层中的任意节点，还可以跳到下一层的第一个节点。 

游戏从第一层的第一个节点开始，两名玩家交替移动。 移动只是从当前节点选择任何传出边缘并沿其移动令牌。 将令牌移动到最后一层的最后一个节点的玩家立即获胜。 

所以整个游戏是一个在完美信息的 DAG 上的确定性两人游戏。 唯一重要的状态是当前节点，并且每个节点的移动集由层的结构固定。 

输入尺寸很大：最多10^5层，每层尺寸可以大到10^18。 这立即排除了任何图形构建或节点模拟。 即使迭代所有节点也是不可能的，因为节点总数可能是天文数字。 该解决方案必须仅取决于层大小的结构，而不取决于单个节点。 

当人们假设游戏取决于节点总数时，就会出现一种天真的推理的微妙失败案例。 例如，如果除最后一层之外的所有层的大小均为 1，则简单的方法可能会得出结论，答案仅取决于沿着链的移动的奇偶性。 但是，将单个层从大小 1 更改为大小 2 会完全改变分支选项，即使节点数仅略有变化。 例如：

 输入

 n = 3

 a = [1, 1000000000000000000, 1]

 天真的“计数动作”想法可能会说路径本质上仍然是线性的，但实际上第二层提供了巨大的水平逃生空间，改变了最佳游戏的结果。 

另一个隐藏的边缘情况是当层的大小为 1 时。这些层的行为类似于强制过渡，但将它们与大层混合会产生交替的强制和自由选择段。 任何统一处理所有层的解决方案都会在这里失败。 

## 方法

 思考这个游戏的一种强力方法是显式构建图表并运行标准的获胜/失败状态 DP。 从每个节点，我们检查是否存在迫使对手进入失败状态的举动。 这是可行的，因为图是非循环的，所以我们可以从最后向后计算赢/输状态。 

问题是图形大小不可用。 即使我们只考虑转换，每层也最多包含 10^18 个节点。 蛮力方法需要 O(总节点 + 边)，这甚至无法表示。 

关键的观察结果是，在一层内部，移动是完全确定性的：从任何节点，您都可以向右走到该层的末尾。 这意味着层中的所有节点的行为就像单链上的位置一样，除了索引之外具有相同的传出结构。 唯一有意义的“选择点”是玩家是提前停止遍历一层还是继续到最后再跳下去。 

这会将每一层折叠成一个游戏状态，其特征在于您是否位于层的第一个节点或其中的某个位置。 然而，因为每个节点都连接到下一层的第一个节点，所以层内的任何位置实际上都提供了与该层末尾相同的未来选项，除了已经花费了多少步之外。 

这将整个游戏简化为层上的平价式决策：重要的是玩家是否被迫立即进行垂直过渡，或者可以“消耗”层内的额外动作来翻转平价。 简化结构后，每一层贡献一个值：它的长度是奇数还是偶数决定进入它是保留还是翻转当前玩家的优势。

因此，游戏简化为在层奇偶校验上计算简单的类似异或的累积。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解图 DP | O(总节点数) | O(总节点数) | 太慢了 |
 | 层奇偶校验减少| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将每一层视为强制水平移动的一段，然后强制跳转到下一层。 玩家无法跳过该结构，因此每个决定最终都取决于在传递控制之前要消耗多少步。 
2. 观察在一层内，玩家沿着单一定向链交替移动。 如果某个层的长度为偶数，则进入该层会保留离开时该轮到谁。 如果长度为奇数，则退出后转弯会翻转。 
3. 将每一层建模为奇偶校验转换器。 从第一个在第 1 层进行移动的玩家开始。 
4. 迭代第 1 层到第 n 层，维护一个布尔值，表示进入当前层时是否仍然是第一个玩家的回合。 如果当前层长度是奇数，则翻转该布尔值。 
5.处理完所有层后，判断到达最后一层最后一个节点的玩家是否与开始的玩家相同。 如果平局表明第一个玩家做出最后一步，他们就赢了； 否则第二个玩家获胜。 

### 为什么它有效

 不变的是，完成任何一层后，对游戏剩余部分来说唯一重要的信息是轮到哪个玩家了。 层内的内部位置不会影响未来的分支，因为层中的每个节点都通向相同的下一层条目。 一层的唯一影响是在到达下一个决策边界之前消耗了多少步，这正是它的奇偶性。 由于游戏是在单一路径上进行纯粹的移动交替，并且层之间具有确定性的转换，因此将每一层减少到奇偶翻转可以保留完整的游戏状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        # True means first player's turn at current layer entry
        first_turn = True

        for x in a:
            if x % 2 == 1:
                first_turn = not first_turn

        out.append("First" if first_turn else "Second")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现将每一层压缩为单个奇偶校验。 唯一跟踪的状态是遍历一层后转弯是否翻转。 无需对节点或边进行建模。 

这里的一个常见错误是尝试在层内逐步模拟运动，考虑到单个层的大小可达 10^18，这是不可能的。 另一个错误是忘记了层之间的转换总是被强制的，因此唯一可控的因素是奇偶校验，而不是路径选择。

 ## 边缘情况

 单层游戏是最直接的情况：如果层大小是奇数，则第一个玩家在唯一的移动后立即失去控制，因此结果完全取决于奇偶逻辑。 该算法可以处理此问题，因为它在遇到奇数时会应用一次翻转。 

当所有层的大小均为 1 时，每层都会翻转回合。 n层之后，获胜者取决于n是偶数还是奇数。 循环正确地累积这些翻转，无需特殊的外壳。 

当所有层都是偶数时，不会发生翻转，并且第一个玩家保留对整个链条的控制。 该算法正确输出“First”，因为布尔值永远不会改变。
