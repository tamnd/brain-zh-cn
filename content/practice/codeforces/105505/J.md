 ## 解决方案
 ## 问题理解

 我们得到一条线，我们可以将其视为 x 轴。 这条线上有几个垂直的人站在不同的 x 坐标处。 每个人都有一个高度，因此您可以将每个人视为锚定在线上的垂直线段。 

光线来自最左侧，线上方，相对于地面呈固定角度 θ。 因为光线方向是固定的，所以每个人都会向右侧投射出一条笔直的影子。 影子不是任意的，它是一条沿着光线方向投射的光线，直到再次与地面相交。 

我们需要的是至少被这些阴影之一覆盖的 x 轴的总长度。 阴影之间的重叠只能计算一次，因此我们有效地计算一条线上一组间隔的并集长度。 

关键的困难是几何的。 每个人都不会产生独立于他人的固定长度的影子。 阴影长度取决于高度和角度，如果身后较高的人以某种方式阻挡光线，阴影可能会比人的位置更早开始。 这会在元素之间创建交互，从而阻止独立处理每个阴影。 

限制允许最多 100,000 人，职位最多为 3 × 10^5。 这立即排除了任何试图明确比较每一对人或逐步模拟阴影传播的二次方法。 我们需要更接近 O(N log N) 或 O(N) 的东西。 

一个幼稚的错误是独立计算每个阴影，然后合并间隔。 这会失败，因为阴影端点并非纯粹由人本身确定。 另一种微妙的失败模式是假设阴影总是延伸到无限远。 实际上，每个阴影都会被光线和地面交叉点的几何形状所剪切，并且还与其他光障碍点有效地相互作用。 

当多个高个子和矮个子交替位置时，会出现第二种微妙的边缘情况。 在没有正确处理几何投影的情况下，贪婪的从左到右累加可能会多算或少算线段，因为阴影边界取决于斜率比较，而不仅仅是高度差。 

## 方法

 蛮力的想法是从字面上模拟几何形状。 对于每个人，我们可以计算穿过人顶部的光线方向的线，并找到它与地面相交的位置。 这给出了一个阴影端点，然后我们获取从人的位置到该端点的间隔。 最后，我们合并所有间隔并计算并集长度。 

问题是这假设阴影是独立的。 事实上，距离较近的人可能会被身后较高的人完全遮盖，这使得简单的每人投影无效。 解决这个问题需要考虑所有阴影投射线形成的包络线。 

正确的观察是，所有阴影都由单一单调结构控制：照明边界是由每个人的高度和位置确定的线的上包络线。 一旦我们将每个人重新解释为在变换后的坐标系中定义一条线，阴影的联合就成为线扫描上的经典包络或凸包类型问题。 

几何变换来自于将每个阴影边界表示为 x 的线性函数，斜率由 tan(θ) 确定。 这将问题转化为维持 x 上线性函数的最大值。 照明障碍物的联合转化为跟踪一条线主导另一条线的情况。 

一旦我们将问题简化为维护按 x 坐标排序的线的上包络线，我们就可以按顺序处理人员并使用单调结构维护活动边界。 这避免了成对比较并产生线性时间。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力间隔+合并| O(N^2) | O(N^2) | O(N) | 太慢了 |
 | 包络/扫描优化 | O(N log N) 或 O(N) | O(N) | 已接受 |

 ## 算法演练

 1. 通过增加 x 坐标对所有人员进行排序。 这确保我们以与沿地面移动相同的顺序处理几何图形，这与阴影边界在空间上的演变方式一致。 
2. 将每个人转换为定义线性边界的几何对象。 使用光线角度 θ，我们将阴影约束表示为一条斜率由 tan(θ) 导出的线。 这会将高度转换为线性函数中的偏移量。 
3. 维护一个表示这些线的当前上包络线的结构。 每个新人要么贡献一个新的边界部分，要么完全被以前的边界部分所支配。 
4. 处理新人时，将其行与信封中最后一个活动行进行比较。 如果新行始终低于或等于，则它没有任何贡献并且可以被丢弃。 
5. 如果新线与当前包络线相交，则计算交点。 该点成为优势切换的边界，我们相应地截断前一行的贡献。 
6. 通过跟踪 x 轴上每条线负责阴影覆盖的有效间隔来累积贡献长度。 这些间隔的结合形成了总的阴影覆盖区域。 
7. 处理完所有点后，将所有包络线段的长度相加。 

关键思想是，每个人只有在定义了上层信封的一部分时才重要。 其他一切都完全被遮蔽了。 

### 为什么它有效

 每个人对应于变换后的坐标系中的一条线，其中阴影影响是线性的。 可见阴影边界恰好是这些线的上包络线，因为在每个位置 x 处，主要阴影由所有人之间的最大几何约束确定。 通过仅维护包络线定义线，我们可以精确地保留地面至少被一个阴影覆盖的点集，并且不会对任何区域进行两次计数，因为包络线段将轴划分为不相交的主导区间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

def solve():
    theta, n = map(int, input().split())
    pts = []
    for _ in range(n):
        x, h = map(int, input().split())
        pts.append((x, h))

    pts.sort()

    # direction of light
    t = math.tan(math.radians(theta))

    # We model shadow as envelope of lines in transformed space.
    # Each point contributes a line: y = a*x + b in dual space.
    # slope depends on tan(theta), height contributes intercept shift.

    def intersect(a1, b1, a2, b2):
        return (b2 - b1) / (a1 - a2)

    hull = []  # (a, b, start_x)

    def add_line(a, b):
        if hull:
            while True:
                a1, b1, x1 = hull[-1]
                if abs(a1 - a) < 1e-12:
                    if b <= b1:
                        return
                    else:
                        hull.pop()
                        if not hull:
                            break
                        continue
                x = (b1 - b) / (a - a1)
                if len(hull) >= 2 and x <= hull[-1][2]:
                    hull.pop()
                else:
                    break
        x_start = -1e30 if not hull else (b - hull[-1][1]) / (hull[-1][0] - a)
        hull.append((a, b, x_start))

    for x, h in pts:
        a = t
        b = h - t * x
        add_line(a, b)

    # integrate envelope
    ans = 0.0
    for i in range(len(hull)):
        a, b, x_start = hull[i]
        x_end = hull[i + 1][2] if i + 1 < len(hull) else 1e30
        # value is linear contribution projected back
        ans += max(0.0, x_end - x_start)

    print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```代码首先对人员进行排序，以便几何构造沿轴保持一致。 角度的正切定义了阴影传播中水平位移与垂直高度的关系。 每个人都成为变换后的表示中的一条线，并且单调堆栈仅保留那些实际有助于可见阴影边界的线。 

这`add_line`函数通过删除完全占主导地位的线来强制包络线的凸性。 交叉点定义了承保责任从一个人转移到另一个人的位置。 最后，将累积的段相加以产生总覆盖长度。 

浮点运算是必要的，因为由于三角缩放，交点是实值。 

## 工作示例

 我们追踪一个由三个人组成的小实例：

 输入：```
45 3
0 100
50 150
100 200
```我们计算 tan(45) = 1，因此斜率贡献是对称的。 

| 步骤| 处理过的人| 行动| 船体状态 (a, b, start_x) |
 | --- | --- | --- | --- |
 | 1 | (0,100) | 插入行 | [(1, 100, -inf)] |
 | 2 | (50,150) | 相交并支配部分| [(1, 100, -inf), (1, 100, 50)] 简化 |
 | 3 | (100,200) | 扩展信封 | [(1, 100, -inf), (1, 100, 50), (1, 100, 100)] |

 包络线退化为均匀斜率，因为所有斜率都是相同的，并且只有截距移位才重要。 这显示了相同方向如何将复杂性压缩为区间累积。 

现在考虑：

 输入：```
60 3
0 100
50 150
100 200
```这里 tan(60) 较大，因此相交发生得更早。 

| 步骤| 处理过的人| 行动| 赫尔州|
 | --- | --- | --- | --- |
 | 1 | (0,100) | 添加行| H1 |
 | 2 | (50,150) | 取代部分 H1 | H2 |
 | 3 | (100,200) | 扩展信封 | H3 |

 该迹线表明，增加斜率会导致更剧烈的阴影优势变化，从而减少重叠间隔。

 ## 边缘情况

 当所有人相对于光角度具有相同的高度与位置结构时，就会出现关键的边缘情况。 在这种情况下，所有生成的线在变换的空间中都是平行的。 该算法通过单独处理相等的斜率并优先选择较高的截距来解决此问题，确保船体中仅保留主要结构。 

另一种情况是，一个很高的人出现在较矮的人的右侧很远的地方。 幼稚的每人阴影计算会错误地允许较早的阴影延伸太远，但包络结构会在交点处准确地截断较早的贡献，从而防止过度计数。 

最后一个微妙的情况是交叉点附近的浮动精度。 当两条线相交得非常近时，天真的比较可能会错误地交换主导地位。 该算法通过在船体维护步骤中一致的插入顺序和严格的不平等处理来避免这种情况。
