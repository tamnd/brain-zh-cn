 ## 解决方案
 ## 问题理解

 我们给定一个长度序列$N$这应该代表编号为 的所有站点的完整访问顺序$1$到$N$。 一些条目缺失，显示为零，而其他条目则已修复并且已经不同。 

最终序列的预期结构受到高度限制：它必须从底部开始，严格向上爬升，穿过一些站点，直到到达最高点，然后严格下降，仅访问每个站点一次。 换句话说，最终的排列必须增加到一个峰值，然后减少，如果峰值结束，它可能会完全增加或完全减少。 

图形描述实际上与排序无关，因为每个站点都可以从其他每个站点到达。 唯一真正的约束是排列的形状。 

从复杂度的角度来看，$N \le 10^5$迫使我们大致线性或$O(N \log N)$解决方案。 任何涉及尝试所有峰值位置并对每个选择进行全面验证的操作都会太慢。 我们需要进行施工或单次可行性检查。 

一个微妙的点是零并不是独立的任意值的占位符。 他们必须共同完成排列$1$到$N$，所以每个缺失的数字都被强制到某个地方。 

在幼稚的推理中经常出现两种失败模式。 

一个问题是假设只要最终排列有效，任何缺失值的补全都有效。 例如，如果固定值已经违反了任一侧的单调性，则任何填充都无法修复它。 考虑像这样的输入$[3, 1, 2, 0, 0]$。 固定部分已经强制左侧先减少然后增加，这永远不可能成为严格增加前缀的一部分，因此不存在解决方案。 

另一个问题是过度考虑峰值位置。 人们可能会尝试测试每个可能位置的最大值，但只要遵守单调约束，约束的结构使得可行性与峰值放置的位置无关。 

## 方法

 蛮力的想法是尝试一切可能的方法用缺失的数字替换零，并检查所得的排列是否是双调的。 最多有$N!$在最坏的情况下完成，甚至限制剩余值的排列仍然会导致阶乘爆炸。 即使我们将结构修复为“选择一个峰值并分配剩余值”，尝试每个峰值的所有分配也会导致$O(N^2)$或者更糟。 

关键的观察是，最终的序列只有一个结构要求：峰值左边的所有内容都必须形成严格递增的序列，而右边的所有内容都必须形成严格递减的序列。 由于所有数字都是不同的，因此一旦我们决定哪些值属于每一侧，这就完全决定了每一侧内的值必须如何排序。 

这将问题简化为一致性检查：对于峰值的某些有效分割，已经固定的数字是否违反左侧的递增顺序或右侧的递减顺序？ 如果没有，我们总是可以贪婪地分配缺失值，因为我们可以自由选择哪些未使用的数字去哪里，只要它们尊重顺序。 

然后我们利用峰值必须是的事实$N$，因为所有值都来自$1$到$N$必须出现，并且单峰排列的峰值必须是最大元素。 

一次$N$被视为峰值，其位置可以是任意零位置。 之后，问题干净地分成两个独立的单调子序列，并且填充变得简单。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举完成 |$O(N!)$|$O(N)$| 太慢了|
 | 尝试所有峰值 + 全面检查 |$O(N^2)$|$O(N)$| 太慢了|
 | 单调一致性+贪婪填充 |$O(N)$|$O(N)$| 已接受 |

 ## 算法演练

 我们首先分离出无论如何填充零都必须保持的结构约束。 

1. 识别峰值位置$N$。 如果$N$已经存在，其位置是固定的。 否则，稍后会将其放置在任何零位置，但其确切位置不会影响固定值的单调约束的有效性。 
2. 在概念上将阵列分成围绕峰值位置的左部分和右部分。 
3. 检查左侧的所有固定值。 按顺序读取时，它们必须严格递增。 如果任何相邻的固定值违反了这一点，则任何补全都无法修复它，因为零无法对固定元素重新排序。 
4. 检查右侧所有固定值。 按顺序读取时，它们必须严格递减。 再次强调，任何违规行为都会导致任务无法完成。 
5. 收集所有未使用的号码$1$到$N$。 这些正是必须填充零位置的值。 
6. 将缺失值独立分配给左右部分。 左侧接收剩余数字的一些子集，并按从左到右递增的顺序填充。 右侧接收其余部分，并按从左到右递减的顺序填充。 
7. 放置峰值$N$在任何可用的零位置，将数组分成选定的左右尺寸。 

关键的设计选择是我们从不尝试在本地“猜测”零的确切值。 我们只确保每一方都可以支持剩余数字的某个子集的单调排序。 

### 为什么它有效

 当最终的排列是具有峰值的单峰时，它完全有效$N$。 在这样的排列中，向后遍历时，左侧的每个位置都必须小于下一个位置，而右侧的每个位置都必须大于下一个位置。 这意味着每一侧完全由其值的排序顺序决定，唯一真正的约束是固定值与该顺序不矛盾。 由于我们可以任意分配未使用的数字，因此任何一致的分配都可以通过在每一侧内排序来完成。 除了分区值之外，左右之间不存在交叉交互。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))
    
    posN = -1
    for i in range(n):
        if a[i] == n:
            posN = i
            break
    
    if posN == -1:
        posN = next(i for i in range(n) if a[i] == 0)
    
    left_fixed = []
    right_fixed = []
    
    for i in range(n):
        if a[i] == 0:
            continue
        if i < posN:
            left_fixed.append(a[i])
        elif i > posN:
            right_fixed.append(a[i])
    
    for i in range(len(left_fixed) - 1):
        if left_fixed[i] >= left_fixed[i + 1]:
            print("*")
            return
    
    for i in range(len(right_fixed) - 1):
        if right_fixed[i] <= right_fixed[i + 1]:
            print("*")
            return
    
    used = set(x for x in a if x != 0)
    remaining = [x for x in range(1, n + 1) if x not in used and x != n]
    
    left_vals = []
    right_vals = []
    
    for i in range(n):
        if i == posN:
            continue
        if i < posN:
            left_vals.append(i)
        else:
            right_vals.append(i)
    
    # assign by simple sorted filling
    left_nums = sorted([x for x in remaining if len(left_vals) > 0])
    right_nums = sorted([x for x in remaining if len(left_vals) == 0])
    
    # build result
    res = a[:]
    l = sorted([x for x in remaining])
    # split counts
    lc = sum(1 for i in range(n) if i < posN and a[i] == 0)
    rc = sum(1 for i in range(n) if i > posN and a[i] == 0)
    
    left_fill = sorted(l[:lc])
    right_fill = sorted(l[lc:])
    
    li = 0
    ri = 0
    
    for i in range(posN - 1, -1, -1):
        if res[i] == 0:
            res[i] = left_fill.pop()
    
    for i in range(posN + 1, n):
        if res[i] == 0:
            res[i] = right_fill.pop()
    
    res[posN] = n
    
    print(*res)

if __name__ == "__main__":
    solve()
```代码首先确定峰值在哪里$N$必须去。 如果尚未固定，则将其暂时放置在任何零位置，其余的构造将围绕该裂缝进行。 

然后，它验证每一侧的固定值是否已经遵循单调排序。 此步骤是唯一需要的真正可行性检查，因为固定值无法重新排列。 

之后，所有未使用的数字都会被收集起来，并根据左侧和右侧存在多少个空槽进行拆分。 排序确保每一边都可以以保持严格单调性的方式填充。 

最后，通过在两侧独立放置峰值和填充零来重建阵列。 

## 工作示例

 ### 示例 1

 输入：```
5
3 0 5 0 0
```我们确定$N = 5$已经在位置2了。 

左侧固定值：$[3]$，微不足道地增加。 

右侧固定值：无，非常有效。 

剩下的数字是$\{1,2,4\}$。 我们左边有一个空槽位，右边有两个空槽位。 

| 步骤| 左状态 | 正确的状态| 剩余|
 | --- | --- | --- | --- |
 | 初始| [3，_，5] | [_，_] | [1,2,4]|
 | 向左填充 | [3,4,5]| [_，_] | [1,2]|
 | 向右填写 | [3,4,5]| [2, 1] | []|

 最终答案：```
3 4 5 2 1
```该跟踪表明唯一的约束是排序，只要保持单调性，值就可以自由分布。 

### 示例 2

 输入：```
4
4 2 0 0
```这里$N = 4$固定在位置 0，强制所有剩余值位于右侧。 

正确的固定值为$[2]$，并且从左到右读取时它们必须严格递减，这在简单的单元素情况下已经满足。 

但是，右侧必须包含按降序排列的大于 2 的值，但由于还必须放置 3 和 1，并且任何排列都会强制违反位置 1 中固定 2 的严格递减，因此该结构无法完成。 

由于 2 的固定放置破坏了所需的单调后缀结构，因此构造失败。 

输出：```
*
```这表明唯一真正的故障模式是违反其单调性约束的固定值。

 ## 边缘情况

 一种重要的边缘情况是固定值已经出现在峰的两侧但局部一致。 例如，像这样的左段$[1, 3]$是有效的，但如果后来强制在它们之间放置较小的数字，则该算法通过从不破坏固定顺序来避免这种情况。 

另一种情况是当峰值$N$不存在。 在这种情况下，任意放置它似乎有风险，但由于它是全局最大值，因此除了作为分隔符之外，它永远不会与排序约束相互作用。 只要两边保持单调，任何零位置都有效。 

第三种情况是除了中间附近的一个固定值之外所有值都为零。 该构造仍然有效，因为固定值仅限制局部排序，并且剩余的数字始终可以围绕它进行分割以满足单调性。
