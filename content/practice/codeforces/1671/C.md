 ## 解决方案
 ## 问题理解

 我们有一个场景，您想连续几天从几家商店购买糖包，每家商店每天销售一包。 每个商店的包装都有一个初始价格，并且价格每天都会上涨一个。 您每天的预算是固定的，不能将钱结转到第二天。 目标是确定您可以购买的包的总数，直到所有包都超出您的每日预算。 

输入是商店数量`n`, 每日预算`x`，和数组`a`代表每个商店的初始包装价格。 每个测试用例的输出都是一个整数：在没有包可负担之前您可以购买的总包数。 

限制因素很重要。`n`最多可达 2·10^5，`x`和`a_i`最多 10^9，以及`n`所有测试用例的数量≤ 2·10^5。 这意味着对每个商店的每一天进行任何暴力模拟都太慢，因为在极端情况下天数也可能高达 10^9。 我们需要一种避免单独模拟每一天的方法。 

当最便宜的套餐在第一天就已经比您的每日预算贵时，就会出现边缘情况。 例如，如果`x = 5`和最便宜的`a_i = 6`，你不能购买任何包。 当多个便宜的包装允许在很多天内重复购买时，就会出现另一个微妙的情况，例如`a = [1, 1]`拥有庞大的预算`x = 1000`。 简单的日常模拟会不必要地重复数千次。 我们需要一种有效压缩这种重复的方法。 

## 方法

 一种简单的暴力方法会模拟每一天：每天计算每包的当前价格，在预算范围内尽可能多地购买，然后转移到第二天，将所有价格加一。 这是正确的，因为它确实遵循了问题描述。 然而，在最坏的情况下，如果`n = 2·10^5`而且价格非常低且预算很高，模拟可能需要几天内数十亿次迭代，这远远超出了 2 秒的限制。 这使得它不切实际。 

关键的观察是我们不需要日复一日地模拟。 如果我们按初始价格对包进行排序，那么最便宜的包将始终被首先考虑。 在任何一天，如果您可以购买`k`包装在您的预算范围内，您可以继续购买这些产品的天数`k`连续包装而不超出预算可以通过数学计算。 具体来说，如果总和`k`最便宜的套餐加上`k*d`（在哪里`d`是连续天数）剩余≤`x`，那么我们可以购买`k`包用于`d`一次。 这将每日模拟转换为每组计算，从而将问题简化为 O(n log n) 排序和 O(n) 算术运算。 

蛮力之所以有效，是因为它从字面上对问题进行了建模，但由于潜在的数十亿次迭代而失败。 对连续购买的观察使我们能够预先计算可以购买某个排序价格前缀的最大天数，从而将重复计算分解为单个算术步骤。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * 最大天数) | O(n) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`和`x`，然后读取数组`a`。 
3. 对数组进行排序`a`按升序排列。 排序确保我们总是首先尝试购买最便宜的包，从而最大限度地增加购买的包数量。 
4. 初始化`total_packs = 0`。 这将累积所有天购买的所有包。 
5. 迭代数组`a`有索引`i`代表当前前缀中的最后一个包。 对于每个前缀`a[0..i]`，计算总和`prefix_sum`其中`i+1`元素。 该总和表示在第 0 天购买此前缀中的所有包的成本。 
6. 确定连续天数`d`我们可以购买这个前缀而不超过`x`。 使用整数除法：`d = (x - prefix_sum) // (i+1) + 1`。 我们添加 1，因为包含了第 0 天。 如果`d <= 0`，跳过这个前缀。 
7. 增量`total_packs`经过`(i+1) * d`。 这个算买的`i+1`每天打包`d`天。 
8. 减少`x`如果需要的话，用于下一次迭代，但在我们的方法中，我们实际上不需要修改`x`每个前缀，因为每个前缀独立计算天数。 
9.循环结束后，打印`total_packs`对于当前的测试用例。 

为什么有效：排序确保我们始终首先考虑最便宜的包装。 通过以数学方式计算连续天数，我们保证购买尽可能多的商品，而无需模拟每一天。 前缀总和和日计算遵循价格每天恰好增加 1 的不变性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()
        total = 0
        prefix_sum = 0
        for i in range(n):
            prefix_sum += a[i]
            if prefix_sum > x:
                break
            days = (x - prefix_sum) // (i + 1) + 1
            total += days * (i + 1)
        print(total)

if __name__ == "__main__":
    solve()
```该代码使用有效地读取输入`sys.stdin.readline`。 对包的价格进行排序可以保证我们首先购买更便宜的包。`prefix_sum`跟踪当前前缀的累积成本，以及`(x - prefix_sum) // (i + 1) + 1`计算我们可以负担这个前缀的连续天数。 乘以`(i + 1)`给出该前缀的总包数。 一旦循环中断`prefix_sum > x`因为这个前缀的包在第一天是买不起的。
