 ## 解决方案
 ## 问题理解

 我们被要求确定是否有可能构造一个“雪花”图$n$顶点，遵循递归分支规则。 该图从单个顶点开始。 从这个顶点，我们附加$k > 1$新的顶点。 然后，对于作为叶子的每个顶点（恰好连接到另一个顶点），我们附加$k$新的顶点，重复这个过程至少一次。 任务是检查给定的数字$n$,是否存在整数$k > 1$使得雪花恰好具有$n$顶点存在。 

输入由多个测试用例组成，最多$t = 10^4$，每个测试用例给出一个整数$n \le 10^6$。 由于这些限制，任何算法都必须有效地处理大数。 尝试所有可能的暴力解决方案$k$并模拟雪花的生长将超过时间限制，特别是如果它尝试$O(n)$每个候选人的操作$k$。 

对于小型企业来说，会出现不明显的边缘情况$n$。 例如，$n = 1$无法形成雪花，因为该图必须有一个具有多个子节点的顶点。 相似地，$n = 2$和$n = 3$太小而不允许$k > 1$递归扩展的分支。 这些情况应该返回“NO”，而不尝试进一步计算。 

## 方法

 暴力方法会迭代所有整数$k > 1$并模拟雪花的生长。 从单个顶点开始，我们会重复添加$k$子级到每片叶子并计算总顶点数。 如果在任何一步总计等于$n$，我们输出“YES”。 如果总数超过，则模拟停止$n$。 这种方法的问题是对于大的$n$，顶点数量呈指数增长$k$，并检查每个$k$最多$n$导致操作过多，大致$O(n \log n)$每个测试用例在最坏的情况下，这是不切实际的$t = 10^4$和$n = 10^6$。 

关键的见解来自于观察雪花的生长模式。 如果我们让$S_k$是给定生成的顶点总数$k$，我们可以将其表示为几何级数：第一个顶点产生$k$叶子，每片叶子都会产卵$k$新叶等。 正式之后，$m$扩展级别，顶点总数为$$1 + k + k^2 + \dots + k^m = \frac{k^{m+1} - 1}{k - 1}.$$我们需要检查是否存在任何整数$k > 1$和一些整数$m \ge 1$这样$$\frac{k^{m+1} - 1}{k - 1} = n.$$这使我们能够避免模拟整个雪花。 我们可以尝试每一个$k$最多$\sqrt{n}$并迭代计算几何级数，直到达到或超过$n$。 几何增长确保我们只需要$O(\log n)$每步数$k$，并且自从$k$只上升到$\sqrt{n}$，解决方案符合时间限制。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 每个测试用例的 O(n log n) | O(1) | O(1) | 太慢了 |
 | 几何系列检查| 每个测试用例的 O(sqrt(n) * log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，请阅读$n$。 
2. 轻微案件立即处理$n = 1$。 不可能有雪花，输出“NO”。 
3. 迭代$k = 2$最多$\sqrt{n}$。 对于每个$k$, 初始化`total = 1`和`power = 1`。 
4. 重复计算雪花的下一层：乘`power`经过`k`并添加到`total`。 
5. 停止此过程`total`等于或超过$n$。 如果`total == n`，输出“YES”并中断。 
6. 如果没有$k$满足条件，则该测试用例输出“NO”。 
7. 对所有测试用例重复步骤 2-6。 

原理：雪花的顶点数以几何级数的形式增长$k$。 通过检查所有整数基数$\sqrt{n}$，我们涵盖了所有可行的$k$可以准确地生成$n$顶点，因为对于$k > \sqrt{n}$，该系列超过$n$简而言之。 这保证了正确性，而无需模拟整个图。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_form_snowflake(n):
    if n == 1:
        return False
    k = 2
    while k * k <= n:
        total = 1
        power = 1
        while total < n:
            power *= k
            total += power
        if total == n:
            return True
        k += 1
    return False

t = int(input())
for _ in range(t):
    n = int(input())
    print("YES" if can_form_snowflake(n) else "NO")
```我们定义一个辅助函数`can_form_snowflake`封装几何级数检查。 外循环迭代可行的$k$，内部循环计算雪花大小$k$。 我们处理$n = 1$分别进行，避免不必要的计算。 界限`k * k <= n`确保我们不会浪费时间检查不可能的值$k$。 

## 工作示例

 考虑输入`n = 13`。 我们迭代$k = 2, 3, ...$。 为了$k = 3$，我们计算几何级数：`total = 1`→`1+3=4`→`4+9=13`。 总比赛数$n$，所以我们输出“YES”。 这证实了我们的算法可以正确识别少量的可行雪花。 

为了`n = 6`，我们尝试$k = 2$:`total = 1`→`1+2=3`→`3+4=7`，超过 6。下一步$k = 3$:`total = 1`→`1+3=4`→`4+9=13`，也超过 6。没有其他$k$满足条件，所以输出“NO”。
