 ## 解决方案
 ## 问题理解

 我们得到了一幅风格化的图画，由沿垂直线放置的几个相同的三角形“树枝”组成。 每个分支都是一个底长固定的等腰三角形`d`和身高`h`。 所有三角形的方向都相同：它们的底边是水平的，顶点向上，而垂直的树干穿过每个底边的中点。 

每个分支都放置在特定的垂直位置`y_i`，代表其底面的高度。 由于所有三角形都具有相同的形状，唯一改变的是它们垂直堆叠时彼此重叠的程度。 

任务不是计算孤立的各个三角形面积的总和，而是计算它们的并集面积。 重叠的绘制区域应该只计算一次，因为重叠的墨水不需要额外的油漆。 

每个三角形都有面积$$S = \frac{d \cdot h}{2}$$困难来自重叠：如果两个三角形在垂直方向上足够接近，它们会在较小的相似三角形区域中重叠，并且每个相交链必须减去一次该重叠。 

这些约束使这变得有趣：所有测试用例的分支总数最多为`2 · 10^5`，并且坐标可以大到`10^9`。 任何比较所有三角形对的解决方案都会太慢。 

一个关键的微妙情况是当多个三角形传递重叠但并非所有成对重叠都是明显的时。 例如，三角形 A 与 B 重叠，B 与 C 重叠，但 A 和 C 可能直接重叠，也可能不直接重叠。 幼稚的成对并集方法存在重复计算或丢失链式重叠的风险。 

打破天真的推理的边缘情况包括：

 如果`d`非常大并且`h`很小，甚至间距适中`y_i`值导致完全重叠，例如```
n = 3, d = 10, h = 1
y = [1, 2, 3]
```所有三角形都完全重叠，所以答案只是一个三角形区域，而不是三个。 

如果`h`较大且间隙较小，部分重叠连续堆叠，产生单个合并形状。 

这些行为表明，该结构从根本上讲是关于区间的垂直合并，其重叠区域随着高度差线性收缩。 

## 方法

 一种直接的方法是将每个三角形视为一个几何形状，并使用成对交集计算并集面积。 对于每对三角形，我们可以计算它们重叠的垂直跨度并相应地减去重叠面积。 

这很快就会变得昂贵，因为有`O(n^2)`对，并且每个重叠计算都是不平凡的。 和`n`最多`2 · 10^5`，这是不可行的。 

关键的观察结果是，每个三角形的形状在两个方向上都是线性的：当我们从底部向上移动时，水平宽度线性减小。 这意味着两个三角形之间的重叠仅取决于它们底边之间的垂直距离。 

如果我们排序`y_i`，我们可以按升序处理三角形并维护并集当前的“活动合并包络线”。 每个新三角形要么：

 1. 从当前合并顶部上方开始，不重叠，贡献其整个区域，或者
 2、部分重叠，减少有效附加面积。 

重叠条件变成纯一维：对于两个相邻三角形，如果垂直间隙小于`h`。 当存在重叠时，相交区域本身是一个较小的三角形，其高度为`h - gap`，其基数按比例缩放。 

这使我们能够在扫描时维持正在运行的合并贡献并逐步减去重叠贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 强力成对几何| O(n²) | O(1) | O(1) | 太慢了 |
 | 排序扫描+重叠合并| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 按底高对三角形进行排序`y_i`。 这确保我们只将每个三角形与先前合并的结构进行比较，因为重叠只能发生在按排序顺序的附近三角形上。 
2. 将总面积初始化为 0 并维持当前的“活动段”，表示仍影响未来重叠的最后一个三角形。 
3. 对于按顺序排列的每个三角形：

 如果它不与先前的活动三角形重叠（间隙≥h），则添加完整的三角形区域。 

否则，计算重叠高度为`h - gap`并从朴素总和中减去重叠的三角形面积。 
4. 当发生重叠时，通过保留延伸得更高的三角形来更新有效合并的“顶部包络线”。 
5. 继续，直到处理完所有三角形。 

关键的计算是两个垂直移动的相同等腰三角形之间的重叠面积。 由于宽度与高度成线性比例，因此交集是与高度较小的相似三角形`h - gap`，因此它的面积与剩余高度分数的平方成正比。 

### 为什么它有效

 每个三角形在垂直方向上定义了一个线性边界，其宽度均匀收缩。 这些形状沿着一条线的结合减少了在每个高度上保持最高的活动包络线。 由于宽度轮廓是凸形且线性的，因此非相邻三角形之间的重叠完全由排序顺序中的中间三角形主导。 这保证了按顺序处理不会错过交叉点或重复计算未覆盖的区域。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, d, h = map(int, input().split())
        y = list(map(int, input().split()))

        base_area = d * h / 2.0
        ans = base_area

        for i in range(1, n):
            gap = y[i] - y[i - 1]
            if gap >= h:
                ans += base_area
            else:
                # overlapping part is a smaller similar triangle
                overlap_h = h - gap
                ratio = overlap_h / h
                overlap_area = base_area * ratio * ratio
                ans += base_area - overlap_area

        print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```该代码在对由下式给出的隐式结构进行排序后，从左到右递增地计算面积`y_i`。 底三角形面积计算一次。 对于每个连续的对，我们通过垂直间隙确定是否存在重叠。 

如果没有重叠，则添加整个三角形区域。 如果存在重叠，我们使用相似性来计算重叠三角形：重叠高度线性缩小，因此面积二次缩放。 这就是为什么我们乘以`(overlap_h / h)^2`。 

一个微妙的点是我们永远不需要显式地跟踪完整的几何图形。 形状完全由高度差决定，因为所有三角形都是相同且对齐的。

 ## 边缘情况

 第一个边缘情况是当所有`y_i`非常接近。 例如：```
n = 3, d = 4, h = 2
y = [1, 2, 3]
```这里每个连续的间隙是`1`，因此每个新三角形都与前一个三角形严重重叠。 该算法重复应用重叠公式，仅缩小增量贡献。 最终的结果不是三角形面积的三倍，而是通过连续缩小构建的单个合并形状。 

第二个边缘情况是当间隙完全相等时`h`。 在：```
y = [1, 3], h = 2
```三角形只相交于一点。 条件`gap >= h`确保不会发生重叠减法，因此两个完整区域都会被添加。 这可以防止意外删除零区域交叉点，否则会引入浮点噪声。 

第三种情况是当`d`或者`h`足够大以至于浮动精度变得相关。 由于重叠使用平方比，因此中间值必须保留为浮点，但所有操作都保持稳定，因为它们最多涉及有界乘积`1e10`刻度数字，完全在双精度精度范围内。
