 ## 解决方案
 ## 问题理解

 我们在墙上有一组钉子，每个钉子的高度都不同，每个钉子上都绑着一根一定长度的绳子。 所有绳子的另一端都连接到糖果，形成一个悬挂在空中某处的单点。 目标是将糖果降低到地面，我们可以通过一根一根地割断绳子来做到这一点。 每次切割都会减少固定糖果的绳索，如果剩余的绳索不够长，无法将糖果固定在地面上，则可能会降低糖果的高度。 

从数学上讲，每个钉子的高度$a_i$并且有一根长度的绳子$b_i$。 糖果的高度由以下最小值决定$a_i + b_i$覆盖所有仍连接的绳索。 为了让糖果落地，我们需要高度加上绳索长度的最小总和达到零或更低。 问题要求要切割的绳索的最少数量才能达到此目的。 自从$n \le 50$所有操作都是简单的比较，问题主要是排序和计数，而不是复杂的数据结构或优化。 

当一些绳索足够长，可以自行到达地面时，就会出现不明显的边缘情况。 例如，如果存在长度大于其钉子高度的绳子，则糖果已经位于地面或地面以下而无需切割。 另一个微妙之处是，最佳解决方案可能包括首先切断附着在较高钉子上的绳索，而不是最长的绳索，因为糖果的高度是由最短的有效绳索决定的。 

## 方法

 蛮力方法考虑绳子的所有子集，将它们一根一根地切断，并检查糖果是否到达地面。 这有效是因为$n \le 50$， 所以$2^{50}$子集理论上是可能的，但枚举全部是不可行的。 然而，关键的观察简化了这一点：我们只需要知道有多少根绳子相对于糖果的当前高度“太短”。 

我们可以按高度对钉子进行分类，并重点关注超出糖果位置的多余绳子长度。 从最高的钉子开始，如果一根绳子的高度和长度之和没有到达地面，我们就必须把它剪断。 通过按钉子高度递减的顺序考虑绳索，并检查每根绳索是否延伸超出迄今为止切割的绳索数量，我们可以贪婪地计算最小切割。 这将问题简化为排序和单次穿过绳索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最优（贪婪）| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取钉子数量$n$。 对于每个钉子，存储高度$a_i$和绳子长度$b_i$作为一个元组。 
2.按照指甲高度降序排列$a_i$。 这确保我们首先考虑对糖果高度影响最大的绳子。 
3. 初始化计数器`cuts = 0`追踪到目前为止被切断的绳索数量。 
4. 迭代排序的钉子。 对于每个钉子，检查其绳索长度是否$b_i$小于或等于已切断的绳索数量。 如果是这样，请跳过它，因为切割它无助于进一步降低糖果。 否则，增加`cuts`因为需要切断这条绳子才能把糖果放下来。 
5. 继续，直到考虑完所有钉子。 柜台`cuts`最后是需要切割的最少绳索数量。 

原理：通过首先考虑最高的钉子，我们确保每根可以阻止糖果掉落的绳子都被考虑在内。 每次切割都会降低糖果的有效最小高度，并且贪婪标准确保不会计算不必要的切割。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        ropes = [tuple(map(int, input().split())) for _ in range(n)]
        # Sort by nail height descending
        ropes.sort(reverse=True)
        cuts = 0
        for i in range(n):
            height, length = ropes[i]
            # If current rope cannot be the limiting factor, skip
            if length <= cuts:
                continue
            cuts += 1
        print(cuts)

if __name__ == "__main__":
    main()
```该解决方案使用有效地读取输入`sys.stdin.readline`，将每根绳子存储为一个元组，并按降序排序以首先处理最高的钉子。 支票`if length <= cuts`至关重要，因为它可以避免对已经太短而影响糖果下降的绳子进行不必要的切割。 递增`cuts`贪婪地数着必须切断才能到达地面的绳索。

 ## 边缘情况

 如果所有绳索都足够长，可以单独到达地面，则无需切割。 如果绳子都很短，但最高的钉子有最短的绳子，则可能需要多次切割。 按高度排序可确保首先处理最高的指甲，并防止低估必要的切割量。 例如，绑在非常高的钉子上且长度极短的单根绳子必须首先被切断，算法通过排序自然地处理这一点。
