 ## 解决方案
 ## 问题理解

 我们有一个构建过程来构建一种特殊的树状图。 它从单个根顶点开始。 从那里开始，每当一个顶点变成一片叶子时，它就会通过精确地附着来“扩展”`k`它的新顶点，其中`k > 1`。 这种扩展至少执行一次，并且每个新创建的叶子继续以相同的方式扩展。 

这创建了一个完全规则的分支结构：在第一次扩展之后，根具有`k`孩子们，那么每一片叶子都会产生`k`更多的孩子，依此类推，但只有叶子被展开。 该结构是有限完整的`k`- 二叉树，其中每个内部节点都有`k`孩子们。 

问题是：对于给定的数`n`,是否存在某个整数`k > 1`这样通过这个过程构建的雪花恰好具有`n`顶点？ 

约束条件非常大，`n`最多 10^18 和最多 10^4 个测试用例。 这立即排除了对树的任何构建或模拟。 甚至存储中间结构也是不可能的。 任何有效的解决方案都必须将问题简化为算术属性`n`。 

一个微妙的点是构造必须至少发生一次。 这意味着最小的有效雪花不是单个根，而是具有`k`子级，然后是至少一个进一步的扩展层。 所以我们不可以在第一次扩张后立即停止。 

一个常见的错误是假设这只是一个完整的`k`- 一定高度的二叉树，然后尝试匹配公式而不强制执行“至少一次进一步扩展”约束。 另一个错误是只考虑树高度为 2 的情况，但更深的树也是有效的，并且会产生不同的总数。 

例如，如果`k = 2`，该结构必须至少有两轮扩展：

 - 1轮后：`1 + 2 = 3`- 2轮后：`1 + 2 + 4 = 7`- 3轮后：`1 + 2 + 4 + 8 = 15`因此，有效大小是长度至少为 2 的几何级数之和。 

核心任务是决定是否`n - 1`可以表示为某个整数的幂的和`k`，从`k^1`，至少有两项。 

## 方法

 如果我们尝试模拟固定的过程`k`，我们很快就得到了几何级数：$$1 + k + k^2 + \dots + k^h$$对于某些人来说`h ≥ 1`。 

该总和等于：$$\frac{k^{h+1} - 1}{k - 1}$$那么问题就变成了：是否存在`k > 1`和`h ≥ 1`使得这个值等于`n`？ 

蛮力的想法是迭代所有可能的`k`最多`n`，并且对于每个`k`，保持计算能力，直到我们匹配或超过`n`。 这是正确的，但完全不可行，因为`k`最多可以达到 10^18 并且每个模拟都是对数`n`。 最坏情况的复杂性仍然太大。 

关键的见解是扭转观点。 而不是尝试每一个`k`，我们固定高度`h`。 对于固定的`h`，我们问是否存在一个基`k`这样：$$1 + k + k^2 + \dots + k^h = n$$对于固定的`h`，该函数严格递增`k`，所以我们可以二分查找`k`。 最大有意义`h`很小，因为即使`2^60`超过 10^18，所以`h`最多是60左右。 

这将问题简化为尝试所有可能的高度并对底数进行二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解 k | O(n log n) | O(n log n) | O(1) | O(1) | 太慢了 |
 | 固定高度 + 二分查找 k | O(log^2 n) | O(log^2 n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将雪花大小重新表述为几何和：$$S(k, h) = 1 + k + k^2 + \dots + k^h$$我们想检查是否`S(k, h) = n`对于某些人来说`k > 1`和`h ≥ 1`。 

1. 固定候选身高`h`从1开始向上。 

我们只需要达到 60 左右，因为`2^60`已经超过 10^18，所以任何更高的幂都会溢出`n`。 
2. 对于每个`h`，我们寻找一个有效的`k`在范围内使用二分搜索`[2, n]`。 

功能`S(k, h)`增加为`k`增加，所以二分查找有效。 
3. 评估`S(k, h)`，我们迭代计算几何和：

 我们乘以`k`逐步进行，如果总和超过则提前停止`n`。 

这种早期退出对于避免溢出和不必要的计算至关重要。 
4.如果对于任何`h`我们找到一个`k`这样`S(k, h) == n`，我们返回“是”。 
5. 如果没有配对`(k, h)`有效，我们返回“NO”。 

### 为什么它有效

 对于每个固定高度`h`，函数`S(k, h)`严格递增于`k`。 这保证了二分查找找到唯一的可能`k`如果存在的话。 由于每个有效的雪花都精确对应于某对`(k, h)`和`h ≥ 1`，在所有高度上迭代涵盖了所有可能性，没有遗漏或重复。 幂的有限增长确保我们只需要考虑少量的高度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def geom_sum(k, h, limit):
    total = 1
    cur = 1
    for _ in range(h):
        cur *= k
        total += cur
        if total > limit:
            return limit + 1
    return total

def ok(n):
    if n < 3:
        return False

    # maximum height needed is small because 2^60 > 1e18
    for h in range(1, 61):
        lo, hi = 2, n

        while lo <= hi:
            mid = (lo + hi) // 2
            val = geom_sum(mid, h, n)

            if val == n:
                return True
            if val < n:
                lo = mid + 1
            else:
                hi = mid - 1

    return False

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        print("YES" if ok(n) else "NO")

if __name__ == "__main__":
    solve()
```功能`geom_sum`经过精心设计，可通过限制值来避免溢出`n`。 这确保了即使对于较大的中间幂，二分搜索决策也保持正确。 

主循环迭代可能的高度，并对每个高度执行二分搜索`k`。 界限`2`到`n`是安全的，因为`k = 1`无效，任何有效的分支因子不能超过`n`。

 ## 边缘情况

 一个关键的边缘情况是非常小的值`n`。 为了`n = 1`或者`n = 2`，甚至无法形成第一个所需的扩展，因为任何有效的雪花必须至少包含`1 + k + k^2`对于某些人来说`k > 1`。 该算法立即正确地拒绝这些`n < 3`查看。 

另一个边缘情况是导致 64 位算术溢出的大幂。 在几何和计算过程中，中间值如`k^h`可以超过`n`即使最终金额无关紧要。 该实现通过在总和超过时限制总和来避免这种情况`n`，确保二分查找比较的正确性。 

最后，像这样的案例`n = 255`完全对应于完整的二进制展开`1 + 2 + 4 + ... + 128`，当高度循环捕获时`h = 7`。 该算法不假设特定的基础，并且高度搜索保证在没有特殊大小写的情况下找到这种结构化的情况。
