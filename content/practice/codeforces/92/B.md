 ## 解决方案
 ## 问题理解

 任务是获取一个以二进制表示的正整数，并使用简单的迭代过程确定将其减少到 1 需要多少步。 在每一步中，如果数字是奇数，我们将其加 1，如果是偶数，我们将其除以 2。输入是最多 1,000,000 位数字的二进制字符串，因此在 Python 中直接将其转换为本机整数类型可能是可行的，因为 Python 整数可以处理任意大小，但在较低级别的语言中，我们需要直接使用字符串表示形式。 输出是一个整数：达到 1 所需的步数。 

这里的主要限制是数字的大小。 由于数字最多可达一百万位，因此我们需要一种不执行与小数值本身成正比的运算的算法，因为 2^1,000,000 是一个天文数字。 相反，我们必须在二进制级别处理该数字。 如果重复构造非常大的整数，将每次加法和除法模拟为整数运算的简单解决方案可能会很慢。 边缘情况包括最小的输入`1`，这需要零运算，以及全为 1 的数字，例如`1111`，其中频繁的增量触发进位传播。 粗心的方法可能会将二进制字符串视为数值并低效地使用整数运算，这可能会导致不必要的性能问题。 

## 方法

 一种简单的暴力方法是将二进制字符串转换为标准整数并重复应用操作：检查奇数或偶数，然后递增或除以 2。 这是可行的，因为 Python 支持任意精度整数，因此保证了正确性。 然而，问题的大小（高达 1,000,000 个二进制数字）使得这种方法在低级语言中效率低下，因为大数字的每次增量可能涉及内部 O(n) 位操作。 对于像这样的数字来说，最坏的情况是`111…11`（全一）可能会导致每个增量上的多个进位传播，从而有效地使该方法在处理二进制数字方面达到 O(n²) 。 

最佳的见解是我们可以直接处理二进制字符串，而无需将其转换为数字类型。 遵守规则，偶数除以 2 相当于删除最后一个二进制数字。 对于奇数，递增可能会在连续的数字之间传播进位。 通过从最低有效位（最右边）到最高有效位（最左边）遍历字符串，我们可以进行计数操作：对于每一位，如果为 0，则计数加 1（除法），如果为 1，则计数加 2（加 1，然后除），但最高有效位除外，如果为 1，则只需要 1。这种方法将字符串视为位列表，避免重复构造大整数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 最坏情况下的 O(n²) | O(n) | 正确但对于最大输入来说可能太慢 |
 | 最佳| O(n) | O(1) 额外 | 已接受 |

 ## 算法演练

 1. 读取代表数字的二进制字符串。 如果字符串是`"1"`，立即返回0，因为不需要任何操作。 
2. 初始化计数器`steps`为零。 这将跟踪操作总数。 
3. 从最低有效位（字符串最右边的字符）开始并向左移动。 
4. 对于每一位：

 - 如果该位是`'0'`，这代表偶数。 通过递增除以 2`steps`1. 不涉及进位。 
- 如果该位是`'1'`，这代表奇数。 在下一次迭代中将数字加 1 并除以 2。 从概念上讲，这是两种运算：一种用于加法，另一种用于除法。 增量`steps`2.
 5. 处理完除最高有效位之外的所有位后，从`steps`因为当达到最后的1时，最后的加法是不必要的。 
6. 输出`steps`。 

工作原理：每一位对应数字中的 2 的幂。 从右向左遍历使我们能够在正确处理进位传播的同时考虑所有增量和除法。 不变的是，在每次迭代时，我们都根据规则正确地保持减少的数量，并通过调整最终计数，避免对最高有效位的最后一次操作进行过度计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
if s == "1":
    print(0)
    sys.exit()

steps = 0
carry = 0
n = len(s)

for i in range(n - 1, 0, -1):
    bit = int(s[i]) + carry
    if bit % 2 == 0:
        steps += 1
    else:
        steps += 2
        carry = 1

steps += carry
print(steps)
```解决方案首先处理以下简单情况`1`立即地。 主循环迭代除最高有效位之外的所有位。 对于每一位，它都会考虑上一步的进位，确定当前数字是奇数还是偶数，并更新`steps`柜台。 最后添加的是`carry`确保计算最高位的任何剩余增量。 使用进位变量可以避免重复构造大整数并有效地模拟加法。

 | 位| 携带| 运营| 步骤|

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    s = sys.stdin.readline().strip()
    if s == "1":
        return "0"
    steps = 0
    carry = 0
    n = len(s)
    for i in range(n - 1, 0, -1):
        bit = int(s[i]) + carry
        if bit % 2 == 0:
            steps += 1
        else:
            steps += 2
            carry = 1
    steps += carry
    return str(steps)

 ## 边缘情况

 输入`"1"`触发立即返回0，正确处理最小边沿。 对于像这样的输入`"1111"`，该算法在所有位上传播进位，正确增加步数以处理多个连续的位。 对于 2 的幂的输入，例如`"1000000"`，每次除法都有效地减少了数量，而无需额外的添加。 循环正确处理最低有效位，最终进位确保正确计算最高有效位。
