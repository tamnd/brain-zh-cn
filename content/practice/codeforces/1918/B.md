 ## 解决方案
 ## 问题理解

 我们有两种排列`a`和`b`相同长度的。 允许的操作是不寻常的：每当我们交换位置时`i`和`j`，我们必须同时在两个数组中执行相同的交换。 

这意味着我们永远无法分离`a[k]`从`b[k]`。 每个位置的行为都像一个配对对象`(a[k], b[k])`。 我们唯一可以做的就是重新排序这些对。 

对这些对重新排序后，我们获得新的排列`a'`和`b'`。 我们的目标是使总和`inversions(a') + inversions(b')`尽可能小。 

关键的观察结果是该操作不会修改任何对。 它仅更改配对出现的顺序。 

制约因素很大。 全部的总和`n`所有测试用例最多是`2·10^5`，所以有一个解决方案`O(n log n)`每个测试用例很容易足够快。 二次算法大约需要`4·10^10`在最坏的情况下进行操作，这是完全不可行的。 

一个微妙的一点是，我们并不是试图独立地最小化一个排列中的反转。 任何重新排序都会同时影响两个数组。 

考虑：```
a = [1, 2]
b = [2, 1]
```这些对是：```
(1,2), (2,1)
```如果我们保持这个顺序`a`有`0`倒置和`b`有`1`。 

如果我们颠倒顺序，`a`有`1`反转和`b`有`0`。 

无论哪种方式，总数都是`1`。 贪婪地尝试仅对一种排列进行排序会错过真正的目标。 

另一个容易犯的错误是认为我们可以自由地对两个数组进行排序。 例如：```
a = [1, 2]
b = [2, 1]
```无法使两个数组同时排序，因为数组对本身是固定的。 重新排序对无法转换`(1,2)`和`(2,1)`进入`(1,1)`和`(2,2)`。 

## 方法

 暴力解决方案会将每个位置视为一对`(a[i], b[i])`并尝试这些对的所有可能的排序。 由于有`n!`排列，即使对于中等值，这也是不可能的`n`。 

要了解必须优化的内容，请考虑两对：```
(x1, y1)
(x2, y2)
```假设这两对按此顺序出现。 

它们对总反转计数的贡献仅来自两个位置之间的比较。 

有四种可能性。 

如果`x1 < x2`，它们不会产生反转`a`。 

如果`x1 > x2`，他们创建一个反转`a`。 

同样对于`y1`和`y2`在`b`。 

所以这对位置的贡献为：```
[x1 > x2] + [y1 > y2]
```现在假设我们交换两对的顺序。 贡献变为：```
[x2 > x1] + [y2 > y1]
```考虑两对的相对顺序。 

如果两个坐标一致：```
x1 < x2 and y1 < y2
```然后将第 1 对置于第 2 对贡献之前`0`，同时反转它们有助于`2`。 

显然第 1 对应该排在第一位。 

如果两个坐标不一致：```
x1 < x2 and y1 > y2
```那么无论哪一对先出现，都会出现一个反转。 

贡献永远是`1`。 

这是至关重要的观察。 

对于每对对象：```
(a[i], b[i])
(a[j], b[j])
```只有两种情况。 

当它们的顺序在两个坐标上一致时，一种相对排列严格地优于另一种。 

当他们的命令不一致时，两种安排都会给出完全相同的贡献。 

因此，坐标一致的每一对都会施加一个首选顺序：```
a[i] < a[j] and b[i] < b[j]
```意味着对`i`应该出现在pair之前`j`。 

因为`a`和`b`是排列，这些偏好不能形成循环。 他们定义了一个偏序。 

该偏序的自然线性扩展是通过对所有对进行排序来获得的`a`。 

排序后`a`, 每当```
a[i] < a[j]
```成立，较小的对`a`是更早的。 

对于对`b`值也以同样的方式排序，我们实现了更好的贡献`0`。 

对于对`b`值的顺序相反，贡献固定为`1`无论如何，所以他们的相对位置并不重要。 

因此排序依据`a`实现尽可能最小的总反转计数。

 | 方法| 时间复杂度| 空间复杂度| 判决 |

 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 建立配对列表`(a[i], b[i])`。 
2. 按第一个坐标对对进行排序`a[i]`。 

自从`a`是一个排列，所有第一个坐标都是不同的，因此顺序是唯一确定的。 
3. 排序后，重建数组。 

已排序对的第一个坐标成为新的排列`a'`。 

第二个坐标成为新的排列`b'`。 
4. 输出重构后的数组。 

### 为什么它有效

 取任意两对。 

如果他们的订单在`a`和`b`同意，一项相关安排有贡献`0`倒置和相反的排列有助于`2`。 任何最佳解决方案都必须将它们按首选顺序排列。 

排序依据`a`尊重每一个这样的首选关系。 

如果他们的订单在`a`和`b`不同意，两种可能的安排都完全贡献`1`，因此没有任何选择可以改善或恶化答案。 

因此，每对物体都贡献了可达到的最小量。 由于总反转计数是所有无序对的总和，因此所得的排列是全局最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        pairs = list(zip(a, b))
        pairs.sort()  # sort by a

        out.append(" ".join(str(x) for x, _ in pairs))
        out.append(" ".join(str(y) for _, y in pairs))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```直接按照证明进行实现。 

重要的建模步骤是将每个位置视为固定对。 由于该操作总是同时交换两个数组，因此这对数组永远不会被分开。 

对列表对进行排序会自动按第一个坐标进行排序，因为 Python 按字典顺序比较元组。 自从`a`是一个排列，所有第一个坐标都是不同的，因此无需担心平局处理。 

排序后，我们只需将这些对解压缩回两个数组并打印它们。 

不需要反转计数。 证明表明排序顺序已经是最优的。 

## 工作示例

 ### 示例 1

 输入：```
a = [3, 1, 2]
b = [3, 1, 2]
```初始对：

 | 职位| 配对 |
 | --- | --- |
 | 1 | (3,3) |
 | 2 | (1,1) |
 | 3 | (2,2) |

 排序后`a`:

 | 排序位置 | 配对 |
 | --- | --- |
 | 1 | (1,1) |
 | 2 | (2,2) |
 | 3 | (3,3) |

 结果：```
a' = [1,2,3]
b' = [1,2,3]
```两个排列都已排序，因此总反转计数为`0`。 

此示例显示了两个坐标产生完全相同的排序的最佳可能场景。 

### 示例 2

 输入：```
a = [1, 2, 3, 4, 5]
b = [5, 4, 3, 2, 1]
```初始对：

 | 职位| 配对 |
 | --- | --- |
 | 1 | (1,5) |
 | 2 | (2,4) |
 | 3 | (3,3) |
 | 4 | (4,2) |
 | 5 | (5,1) |

 排序依据`a`没有改变任何内容：

 | 排序位置 | 配对 |
 | --- | --- |
 | 1 | (1,5) |
 | 2 | (2,4) |
 | 3 | (3,3) |
 | 4 | (4,2) |
 | 5 | (5,1) |

 结果：```
a' = [1,2,3,4,5]
b' = [5,4,3,2,1]
```每对立场之间都不一致`a`和`b`，因此无论对如何排列，每个无序对都只贡献一次反转。 重新排序无法改善答案。

 ## 边缘情况

 考虑尽可能最小的输入：```
1
1
1
1
```只有一对`(1,1)`。 排序使其保持不变。 两个反转计数均为零。 该算法正确地处理了没有任何比较的情况。 

考虑完全相反的顺序：```
a = [1,2,3]
b = [3,2,1]
```这些对是：```
(1,3), (2,2), (3,1)
```排序依据`a`没有任何改变。 每个无序对在两个坐标之间不一致，因此无论排列如何，每一对都恰好贡献一次反转。 该算法达到了最优，因为没有任何安排可以做得更好。 

考虑相同的排列：```
a = [3,1,2]
b = [3,1,2]
```每对比较的两个坐标都一致。 排序依据`a`产生：```
a' = [1,2,3]
b' = [1,2,3]
```所有的倒转都消失了。 这证明了可以同时满足每个首选排序的情况。 

考虑一个混合示例：```
a = [2,1,3]
b = [1,3,2]
```对：```
(2,1), (1,3), (3,2)
```排序后`a`:```
(1,3), (2,1), (3,2)
```给予```
a' = [1,2,3]
b' = [3,1,2]
```坐标顺序一致的对会被最佳放置，而不同的对无论如何都会贡献固定的数量。 这正是正确性证明中使用的结构。
