 ## 解决方案
 ## 问题理解

 我们正在建设一个完整的$n \times m$使用长而薄的砖块组成的矩形网格，其中每块砖都是一个$1 \times k$剥离与$k \ge 2$。 每块砖必须完全水平或垂直放置，并且网格的每个单元格必须恰好属于一块砖。 

水平砖跨越一行和多列，而垂直砖跨越一列和多行。 瓷砖的“稳定性”定义为水平砖的数量减去垂直砖的数量。 我们希望最大化这个价值。 

因此，问题不在于一般地计算瓷砖的数量，而在于选择划分网格的部分的方向，以便与垂直的砖块相比，水平的砖块尽可能多。 

每个测试用例给出一个网格大小$n$经过$m$，并且我们必须输出尽可能好的稳定性。 

约束允许最多$10^4$测试用例，尺寸可达$10^4$。 这立即排除了任何尝试在网格结构上模拟平铺或 DP 的行为。 必须在每个测试用例的恒定时间内计算答案。 

一个微妙的点是，砖块的长度必须至少为 2，因此我们不能将网格分解为单单元“砖块”。 这迫使每个行或列段都配对成至少长度为 2 的结构，这严重限制了奇偶校验和分组选择。 

当一维为 2 时，会出现边缘情况。例如，如果$n = 2, m = 2$，最优值为 2，通过两个水平方向实现$1 \times 2$砖块垂直堆叠。 A naive idea that “we can always prefer horizontal bricks independently per row” fails when the width is not even, because horizontal segmentation depends on full row partitioning.

 另一个失败案例是假设之间的对称性$n$和$m$毫无道理。 根据行或列是否更有效地“配对”，最佳构造的行为有所不同。 

## 方法

 暴力方法将尝试显式构造所有有效的平铺$n \times m$网格并计算每个的稳定性。 即使限制为每行或每列的决策，划分一行长度的方法数量$m$分成大小至少为 2 的分段，并将其扩展到$n$rows 引入了组合爆炸。 即使对于像这样的小网格，这也很快变得不可行$10 \times 10$。 

关键的观察结果是最优解的结构极其规则。 每个垂直砖占据完整的列段，而水平砖则占据完整的行段。 由于每个单元格必须恰好属于一个砖块，因此我们有效地将网格划分为块中跨越整行的水平条带，或块中跨越整列的垂直条带。 

关键的简化是要注意，最好的策略总是减少到最大化多少$1 \times 2$我们可以安装水平的砖块，因为水平的砖块有积极的贡献，而垂直的砖块会降低分数。 然而，由于较小维度的奇偶校验限制，垂直砖有时是不可避免的。 

如果我们从配对单元的角度考虑，每个水平砖消耗同一行中的 2 个单元，每个垂直砖消耗同一列中的 2 个单元。 为了最大限度地提高稳定性，我们需要尽可能多的水平配对。 限制因素变成有多少不相交的$1 \times 2$在列结构强制垂直配对之前，我们可以沿着行进行放置。 

这导致了一个对称结构，其中答案仅取决于较小的维度。 一个方向上尺寸为 2 的每个“层”限制了在另一方向上可以形成多少水平砖块。 最终的封闭形式变为：$$\text{answer} = \left\lfloor \frac{n \cdot m}{2} \right\rfloor$$但通过方向约束进行调整，进一步简化为：$$\text{answer} = \frac{n \cdot m}{2} \quad \text{when at least one dimension is even}$$当两者都是奇数时，在构造保证下不需要稍微减少，因为最佳平铺总是可以对齐配对以避免损失。 

最终结果简化为：$$\text{answer} = \frac{n \cdot m}{2}$$关键原因是每块砖至少覆盖 2 个单元格，因此网格被精确地划分为$nm/2$任何最佳瓷砖中的砖块都可以最大化水平偏好，并且建筑始终可以在最佳配置中实现所有水平贡献。

 ## 算法演练

 1. 读取整数$n$和$m$。 该问题将每个测试用例简化为计算单个数值。 
2. 计算乘积$n \cdot m$。 这表示网格中的单元总数。 
3. 使用整数除法将乘积除以 2。 这相当于将所有单元格分组为最小尺寸的砖块，因为每个砖块的长度至少为 2，因此至少消耗 2 个单元格。 
4. 输出结果。 

关键思想是任何有效的平铺都会将网格划分为砖块，每个砖块至少消耗 2 个单元。 由于我们正在最大化水平砖块，因此我们始终可以安排分区，以便除了最佳配对单元之外不会损失任何效率。 

### 为什么它有效

 网格有$n \cdot m$单位细胞。 每块砖块，无论方向如何，都至少覆盖 2 个单元格，因此任何有效的平铺最多可使用$\lfloor nm/2 \rfloor$砖头。 稳定性对水平砖块进行正面计数，对垂直砖块进行负面计数，但始终可以对结构进行安排，以便在超出配对限制的情况下不需要垂直砖块。 因此，可实现的最大净贡献与最大化砖块数量相一致，砖块数量受到单元配对的限制，从而给出了始终可实现的严格上限。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        print((n * m) // 2)

if __name__ == "__main__":
    solve()
```代码直接应用导出的封闭式表达式。 唯一重要的细节是使用整数除法来避免浮点问题。 

乘法在 Python 的任意精度整数内是安全的，并且每个测试用例都是独立处理的。

 ## 边缘情况

 当一维非常小时，例如$1 \times m$，公式仍然正确适用：网格变成一条线，最好的平铺就是简单的$m/2$水平砖。 

为了$n = 1, m = 10$，计算得出$10 // 2 = 5$。 该算法并没有对此进行区别对待，并且统一配对的论点仍然成立。 

当两个维度都很大且奇数时，例如$9999 \times 9999$，乘积是奇数，整数除法正确地丢弃了无法形成完整砖块的单个剩余单元。 结果仍然有效，因为每个有效的平铺都必须在配对结构方面恰好留下一个未配对的单元格，这不会改变导出边界下的最佳稳定性。 

这种统一的处理方式证实了在实现过程中任何地方都不需要特殊的外壳。
