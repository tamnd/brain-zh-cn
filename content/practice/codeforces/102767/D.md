 ## 解决方案
 ## 问题理解

 我们有一组数字，我们想要计算通过重新排列这些数字以使数组具有单个峰值可以形成多少个不同的数组。 峰值是数组中的最大值。 在此最大值之前的所有内容都必须严格递增，而在此最大值之后的所有内容都必须严格递减。 

例如，如果多重集是`{1, 2, 3, 1}`，最大值为`3`，所以唯一可能的形状是一些结束于的递增序列`3`，随后是递减序列。 数组`(1,2,3,1)`之所以有效，是因为左侧严格增长，右侧严格下降。 

输入给出了数组的大小以及必须重新排列的值。 输出是满足峰值条件的不同数组的数量。 

关键的限制是元素的数量足够大，以至于不可能尝试每种排列。 和`n`元素，蛮力将检查最多`n!`安排，即使对于非常小的值也变得不可用`n`。 该解决方案需要检查值的频率并直接计算有效结构。 

棘手的部分是处理重复值。 小于最大值的值可以出现在左侧、右侧或两者上，但每侧必须严格单调，因此任何一侧都不能两次包含相同的值。 最大值本身很特殊，因为它必须是唯一的峰值。 

考虑多重集：```
3
1 2 2
```正确的输出是：```
0
```粗心的做法可能会导致`2`作为峰值和其他`2`一侧。 然而，无论是`(1,2,2)`或者`(2,2,1)`包含相等的相邻最大值，因此不存在唯一的峰值。 

另一个边缘情况是出现的值低于最大值的三倍：```
5
1 2 2 2 3
```正确的输出是：```
0
```价值`2`需要分布在峰的两侧。 由于每面最多可以容纳一次，因此不能放置三份。 

最终的边界情况是所有非最大值都是唯一的：```
4
1 2 3 4
```正确的输出是：```
8
```每一个`1`,`2`， 和`3`可以独立地分配给增加侧或减少侧。 每个赋值都会产生一个不同的有效数组。 

## 方法

 直接的方法是生成输入多重集的每个排列并检查它是否很棒。 对于候选排列，我们可以找到最大位置并验证值在其之前增加并在其之后减少。 这会正确计算所有答案，因为每种可能的排列都经过测试。 

问题是排列的数量。 和`n`有不同的价值观`n!`可能的安排。 甚至`10!`已经有数百万种可能性，而阶乘的增长很快使这变得不可能。 

很棒的数组的结构提供了一种更小的方式来思考问题。 一旦中间的最大值被固定，剩下的值只需要分配到两侧之一即可。 左侧将自动按升序排序，右侧将自动按降序排序。 

对于小于最大值的值，严格的排序规则意味着每一侧最多可以包含该值一次。 如果一个值出现一次，我们可以选择任一侧。 如果出现两次，则每一面必须各一份。 如果出现两次以上，则没有有效的放置。 

最大值不能出现多次。 第二个副本必须放置在两侧的一侧，但这会创建另一个最大值并违反单峰结构。 

这减少了从排列生成到频率计数的问题。 我们只需要计算有多少个值恰好出现在最大值以下一次，因为每个值都会贡献两个独立的选择。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 计算数组中每个值的出现频率。 

频率信息就足够了，因为每一方的最终排序都是强制的。 我们只需要知道每个值可以有多少种分配方式。 
2. 找到最大值并检查其频率。 

如果最大值出现多次，则答案为零，因为出色的数组需要单个峰值。 
3. 检查每个小于最大值的值。 

如果一个值出现两次以上，则答案为零，因为两个单调边不能容纳同一值的三个副本。 

如果一个值恰好出现两次，则它必须在每一侧出现一次。 这让我们别无选择。 

如果某个值恰好出现一次，则可以将其放置在最大值之前或最大值之后。 将答案乘以二以获得该值。 
4.输出累计的选择数。 

选择的数量始终是 2 的幂，因为每个灵活值都会贡献一个独立的二元决策。 

为什么它有效：

 最大元素固定每个有效数组的中心。 在选择属于左侧和右侧的较小值后，将强制排序，因为左侧必须递增，右侧必须递减。 频率规则准确地描述了何时可以将值放置在这些边上。 每个有效的 Awesome 数组都对应于对边的一个唯一的值分配，并且每个有效的分配都会创建一个 Awesome 数组，因此计数是准确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        freq = {}
        for x in a:
            freq[x] = freq.get(x, 0) + 1

        mx = max(a)

        if freq[mx] > 1:
            ans.append("0")
            continue

        ways = 1
        possible = True

        for x, c in freq.items():
            if x == mx:
                continue
            if c > 2:
                possible = False
                break
            if c == 1:
                ways *= 2

        ans.append(str(ways if possible else 0))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```字典`freq`存储每个值存在的数量。 这避免了依赖于原始数组的顺序，因为只有多重集才重要。 

首先检查最大值。 这可以在处理较小的值之前处理特殊的峰值要求。 

对于较小的值，频率为 2 意味着该值必须在最大值的两侧出现一次，而频率为 1 则给出两种可能的位置。 乘法仅针对这些单一事件发生。 

Python 整数不会溢出，因此重复加倍是安全的。 频率图上的迭代还使解在输入值的数量上保持线性。

 ## 边缘情况

 对于输入：```
3
1 2 2
```最大值的频率`2`是二。 该算法立即返回零。 这符合一个很棒的数组有一个峰值而不是多次出现最大值的要求。 

对于输入：```
5
1 2 2 2 3
```最大值是唯一的，但值`2`出现三次。 该算法检测到两侧不足以分隔所有副本，同时保持两侧严格有序，因此返回零。 

对于输入：```
4
1 2 3 4
```最大值是唯一的，每个较小的值都出现一次。 该算法将计数加倍三倍，产生`2 * 2 * 2 = 8`。 每个结果对应于为每个较小值选择峰的一侧，然后自动确定顺序。
