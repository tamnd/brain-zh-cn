 ## 解决方案
 ## 问题理解

 我们被要求构造三个排列$a$,$b$， 和$c$长度$n$这样对于每个索引$i$的总和$a[i]$和$b[i]$模数$n$等于$c[i]$模数$n$。 每个排列都包含从 0 到$n-1$一次，输出必须是这样的三倍或$-1$如果不存在解决方案。 

输入由单个整数组成$n$。 这项任务是建设性的，而不仅仅是一个是/否的决定。 自从$n$可以大到$10^5$并且时间限制为 2 秒，任何尝试生成所有排列或检查所有三元组的解决方案都立即不可行。 这些约束意味着我们需要一个线性或线性算数的解决方案$n$。 

当出现不明显的边缘情况时，$n$是均匀的。 例如，如果$n=2$，强力检查很快表明不存在满足模和条件的三元组。 为了$n=1$，解决方案很简单：所有排列都是$[0]$。 任何不考虑奇偶性而统一应用简单公式的粗心尝试对于小偶数都会失败。 

## 方法

 暴力方法会尝试枚举所有长度排列$n$为了$a$和$b$然后计算$c[i] = (a[i] + b[i]) \mod n$。 检查是否$c$是一个有效的排列需要$O(n)$每个候选人。 排列总数为$n!$，使得这种方法完全不切实际$n>5$。 为了$n = 10^5$，这远远超出了任何可行的计算。 

关键的见解是模运算在线性偏移下表现良好。 如果我们定义$a[i] = i$和$b[i] = (k \cdot i) \mod n$对于一些常数$k$，我们可以尝试构建$c[i] = (a[i] + b[i]) \mod n$并检查它是否形成有效的排列。 进一步的研究表明，该公式仅在以下情况下才有效：$n$很奇怪。 对于奇数$n$，一个简单的选择$b[i] = (n-i) \mod n$保证$c[i] = (a[i] + b[i]) \mod n$本身就是一种排列。 如果$n$是均匀的，可以证明碰撞是不可避免的，并且不存在解。 这一观察大大减少了搜索空间并允许线性时间构造。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((n!)^2 * n) | O((n!)^2 * n) | O(n) | 太慢了 |
 | 构造公式| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取输入的整数$n$。 
2. 检查奇偶性$n$。 如果$n$为偶数，输出$-1$并停止，因为在这种情况下不存在排列三元组。 
3. 构造排列$a$作为自然序列$[0, 1, 2, ..., n-1]$。 这确保了$a$包含按顺序排列的所有数字。 
4. 构造排列$b$作为序列$[0, n-1, 1, n-2, 2, n-3, ...]$，从两端交替。 这确保了每个元素$b$是独一无二的并与$a$模数$n$产生另一种排列。 更简单的奇数等价公式$n$是$b[i] = (2*i) \% n$。 
5. 构建$c$使用$c[i] = (a[i] + b[i]) \% n$。 通过建设，$c$保证是奇数的排列$n$。 
6. 打印$a$,$b$， 和$c$为了。 

为什么它有效：关键的不变量是奇数$n$，乘以 2 模$n$是双射。 因此，使用$b[i] = (2*i) \mod n$确保$c[i]$接受从 0 到的所有数字$n-1$恰好一次，保留排列属性。 模运算巧妙地环绕，因为奇数$n$没有偶数除数，避免了冲突。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

if n % 2 == 0:
    print(-1)
else:
    a = list(range(n))
    b = [(2*i) % n for i in range(n)]
    c = [(a[i] + b[i]) % n for i in range(n)]
    
    print(" ".join(map(str, a)))
    print(" ".join(map(str, b)))
    print(" ".join(map(str, c)))
```该解决方案首先检查是否$n$均匀，立即印刷$-1$如果是的话。 然后它构建$a$作为简单的 0 到$n-1$顺序。 排列$b$使用公式$2i \mod n$，这保证了奇数的唯一一组数字$n$。 最后，$c$使用模和公式按元素计算。

**样本 2** (n = 2)

 由于 n 是偶数，该算法打印$-1$。 任何构造排列的尝试都会失败，因为两个模 2 的和无法在不重复的情况下同时涵盖 0 和 1。

 ## 边缘情况

 对于$n=1$，所有排列都是平凡的$[0]$。 算法构造$a=[0]$,$b=[0]$， 和$c=[0]$，满足模和条件。 

为了$n=2$，任何试图形成$b$导致重复模 2 求和。该算法正确识别偶数$n$和输出$-1$。 

对于大奇数$n$，例如 99999，双射性质$b[i] = (2*i) \% n$确保$c$仍然是有效的排列，没有任何冲突。
