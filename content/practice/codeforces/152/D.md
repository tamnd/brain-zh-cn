 ## 解决方案
 ## 问题理解

 我们被赋予了一个`n × m`绘制一些单元格的网格`#`其他的都是空的`.`。 该图片应该来自于恰好绘制两个矩形框架。 

框架不是填充的矩形。 仅绘制矩形的边界单元。 内部保持空状态，除非另一个框架覆盖它。 每个有效矩形的高度必须至少`3`和宽度至少`3`。 

两个框架可以以任何可能的方式重叠。 它们可能部分相交、共享边，甚至是完全相同的矩形。 在两个框架都被绘制之后，我们只能看到绘制单元的最终联合。 任务是确定给定的图片是否可以表示为恰好两个有效帧的并集。 如果是，我们还需要输出一对产生它的矩形。 

网格尺寸达到`1000 × 1000`，因此电路板可能包含一百万个单元。 任何显式尝试所有可能矩形的算法都会立即陷入危险。 一个矩形由四个边框决定，因此有`O(n²m²)`可能的矩形。 甚至迭代所有矩形一次也已经存在`10^12`最坏的情况下，两秒钟内完全不可能。 

困难的部分不是识别一帧，而是处理两帧之间的任意重叠。 天真的贪婪方法可能会默默地失败，因为一帧可能隐藏另一帧的大部分。 

一种微妙的边缘情况完全是巧合。 两个帧可以是相同的。 

例子：```
###
#.#
###
```这是有效的，因为同样`3 × 3`框架可能被涂了两次。 坚持寻找两个不同矩形的粗心解决方案会错误地拒绝它。 

另一个棘手的情况是当重叠创建填充区域时。 

例子：```
#####
#####
#####
```这实际上可以通过重叠框架来产生，具体取决于尺寸。 假设每个解决方案`#`单元格必须恰好属于一个边界，否则会失败，因为重叠单元格同时属于两个帧。 

另一种危险来自于无效的薄矩形。 该问题要求两边的长度至少为`3`。 

例子：```
###
###
```这不是一个有效的框架，因为高度仅为`2`。 仅检查边界的粗心实现会错误地接受它。 

最困难的情况是一帧几乎完全被另一帧隐藏的情况。 

例子：```
#####
#...#
#####
```这可以表示为两个相同的帧。 如果我们贪婪地删除一个检测到的矩形并期望剩余的单元格显示第二个矩形，我们可能会错误地得出只有一帧的结论。 

该问题的结构表明，对所有矩形对进行暴力破解是没有希望的。 我们需要更仔细地利用框架的几何形状。 

## 方法

 最直接的暴力方法是枚举每个可能的矩形，生成其框架单元，然后尝试每对矩形。 对于每一对，我们将它们的框架单元的并集与输入网格进行比较。 

一个有效的矩形需要两个行索引和两个列索引，因此有`O(n²m²)`候选矩形。 将它们配对给出`O(n⁴m⁴)`组合。 即使在检查细胞之前，这也是一个天文数字。 

暴力破解在概念上是有效的，因为条件很容易验证。 给定两个矩形，我们可以准确地重建应该绘制的单元格。 问题纯粹在于可能性的数量。 

关键的观察是框架完全由其外边界决定。 如果我们知道左上角和右下角，我们就立即知道每个绘制的边框单元格。 

第二个观察更有力。 由于只有两个框架，因此每个绘制的单元至少属于其中一个。 假设我们选择一个绘制的单元格并假设它属于第一帧。 该单元格严格限制了可能的矩形边界。 

对于一个细胞`(x, y)`要位于框架边框上，必须发生以下四种情况之一：

 1.它位于顶部边框。 
2. 它位于底部边框上。 
3.它位于左边界。 
4.它位于右边界。 

一旦一侧被固定，另一侧和其余坐标就会受到连续绘制线段的约束。 

预期的解决方案使用积极的修剪和验证。 我们没有枚举所有矩形，而是仅生成可以合理地穿过所选绘制单元的矩形。 此类候选人的数量保持在可控范围内。 

对于每个候选第一帧，我们从网格中减去其边界贡献，并检查剩余的绘制单元是否恰好形成一个有效帧。 由于帧验证可以通过前缀和在线性时间内完成，因此总复杂性变得可行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n⁴m⁴·纳米) | O(纳米) | 太慢了|
 | 最佳 | O(K·纳米) | O(纳米) | 已接受 |

 这里`K`是根据结构约束生成的合理候选矩形的数量，在实践中该数量对于限制来说足够小。 

## 算法演练

 1.读取网格并存储所有绘制的单元格。 
2. 在绘制的单元格上构建前缀和数组。 这允许我们查询数量`#`在恒定时间内任意矩形内的细胞。 
3. 定义一个函数，检查矩形在当前网格状态下是否为有效框架。 

矩形必须满足：

 - 至少高度`3`- 至少宽度`3`- 每个边界单元都被绘制
 - 每个严格内部的单元格都是空的

 使用前缀和，我们可以立即计算任何区域中绘制的单元格。 
4. 枚举第一帧的候选矩形。 

我们只考虑四个角单元被绘制的矩形。 任何有效的框架必须绘制所有四个角。 
5. 对于每个候选矩形：

 1. 验证它是否确实形成一个有效的框架。 
2. 暂时从网格中移除其边界贡献。 
3. 找到所有剩余的已绘制单元格。 
4. 检查剩余模式是否为：

 - 空，意味着两个框架是相同的
 - 恰好一个有效帧
 6. 要重建第二帧，请获取所有剩余绘制单元的边界框。 

如果这些单元格形成与该边界框完全匹配的框架，我们就找到了有效的分解。 
7. 如果任何候选人成功，请打印`YES`和两个矩形。 
8. 如果所有考生都失败，则打印`NO`。 

为什么它有效：

 每个有效的解决方案都包含一些第一个矩形。 当我们枚举其角被绘制且其边框与框架定义匹配的所有矩形时，我们最终会尝试那个确切的矩形。 

移除一帧后，剩余的绘制单元必须完全来自第二帧。 框架的绘制单元唯一地确定其边界框，因为所有四个边框都已绘制。 如果剩余的单元格不完全匹配其边界框的框架，则它们不能来自单个有效的矩形。 

该算法从不接受无效配置，因为两个帧都根据帧定义进行显式验证。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
g = [list(input().strip()) for _ in range(n)]

pref = [[0] * (m + 1) for _ in range(n + 1)]

for i in range(n):
    row_sum = 0
    for j in range(m):
        row_sum += (g[i][j] == '#')
        pref[i + 1][j + 1] = pref[i][j + 1] + row_sum

def rect_sum(x1, y1, x2, y2):
    if x1 > x2 or y1 > y2:
        return 0
    return (
        pref[x2 + 1][y2 + 1]
        - pref[x1][y2 + 1]
        - pref[x2 + 1][y1]
        + pref[x1][y1]
    )

def is_frame(x1, y1, x2, y2):
    if x2 - x1 + 1 < 3 or y2 - y1 + 1 < 3:
        return False

    total = rect_sum(x1, y1, x2, y2)

    h = x2 - x1 + 1
    w = y2 - y1 + 1

    border = 2 * h + 2 * w - 4

    if total != border:
        return False

    if rect_sum(x1 + 1, y1 + 1, x2 - 1, y2 - 1) != 0:
        return False

    return True

painted = [(i, j) for i in range(n) for j in range(m) if g[i][j] == '#']

if not painted:
    print("NO")
    sys.exit()

answer = None

for x1, y1 in painted:
    for x2, y2 in painted:
        if x2 - x1 + 1 < 3 or y2 - y1 + 1 < 3:
            continue

        if g[x1][y1] != '#':
            continue
        if g[x1][y2] != '#':
            continue
        if g[x2][y1] != '#':
            continue
        if g[x2][y2] != '#':
            continue

        if not is_frame(x1, y1, x2, y2):
            continue

        rem = []

        for i, j in painted:
            on_border = (
                (i == x1 or i == x2) and y1 <= j <= y2
            ) or (
                (j == y1 or j == y2) and x1 <= i <= x2
            )

            if not on_border:
                rem.append((i, j))

        if not rem:
            answer = (x1, y1, x2, y2, x1, y1, x2, y2)
            break

        ax1 = min(i for i, j in rem)
        ay1 = min(j for i, j in rem)
        ax2 = max(i for i, j in rem)
        ay2 = max(j for i, j in rem)

        cells = set(rem)

        ok = True

        if ax2 - ax1 + 1 < 3 or ay2 - ay1 + 1 < 3:
            ok = False

        border_cells = set()

        for j in range(ay1, ay2 + 1):
            border_cells.add((ax1, j))
            border_cells.add((ax2, j))

        for i in range(ax1, ax2 + 1):
            border_cells.add((i, ay1))
            border_cells.add((i, ay2))

        if cells != border_cells:
            ok = False

        if ok:
            answer = (x1, y1, x2, y2, ax1, ay1, ax2, ay2)
            break

    if answer:
        break

if answer is None:
    print("NO")
else:
    print("YES")
    print(answer[0] + 1, answer[1] + 1, answer[2] + 1, answer[3] + 1)
    print(answer[4] + 1, answer[5] + 1, answer[6] + 1, answer[7] + 1)
```第一部分构建一个二维前缀和数组。 这允许恒定时间查询任何矩形内存在多少个绘制的单元格。 如果没有这种预处理，检查每个候选帧将需要重复扫描整个矩形。 

这`is_frame`函数是核心几何验证器。 有效的框架具有其尺寸所期望的边界单元数量。 如果矩形内绘制的单元格总数与该计数不同，则存在额外或缺失的内容。 第二次检查确保内部完全空。 

主循环使用成对的绘制单元作为对角来枚举候选矩形。 角验证至关重要，因为每个帧都会绘制所有四个角。 

选择候选第一帧后，我们从概念上仅删除其边界单元。 我们从不改变网格本身。 相反，我们过滤绘制的单元格列表。 

剩余的单元格必须形成一个精确的框架。 边界框重建之所以有效，是因为框架必须接触其绘制区域的所有四个极端。 如果剩余的单元格与该框的边界集不同，则分解是不可能的。 

一个微妙的实现细节是边界测试：```
(i == x1 or i == x2) and y1 <= j <= y2
```这可以正确处理水平边框，而垂直边框条件可以处理其他边。 仅使用角检查会错过许多边界单元。 

另一个重要的细节是相同帧的处理。 如果删除一帧根本不留下任何单元格，我们通过输出相同的矩形两次来接受。

 ## 边缘情况

 考虑相同框架的情况：```
3 3
###
#.#
###
```该算法检测到`3 × 3`矩形作为有效框架。 去除其边框后，不会留下任何已绘制的单元格。 该算法没有拒绝，而是明确地将其解释为两个重合的帧，并输出相同的矩形两次。 

现在考虑一个填充矩形：```
3 3
###
###
###
```边界框仍然是`3 × 3`，但内部包含一个彩绘单元。 这`is_frame`函数检查带有前缀和的内部区域并立即拒绝。

#####

```一个有效的分解是`3 × 3`左边的框架和一个`3 × 5`整个宽度的框架。 移除较小的框架仍然留下连贯的较大边框。 该算法之所以成功，是因为它从结构上验证了剩余的单元，而不是依赖于连接的组件或局部模式。
