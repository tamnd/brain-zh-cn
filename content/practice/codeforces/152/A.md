 ## 解决方案
 ## 问题理解

 我们被要求找出班级中至少一门学科最好的学生人数。 每个学生都有多个科目的成绩，每个成绩都是 1 到 9 之间的个位数。输入将成绩表示为大小为 _n_ × _m_ 的网格，其中每行对应一个学生，每列对应一个科目。 如果学生至少在一栏中的成绩与该科目所有学生的最高成绩相匹配，则该学生被视为成功。 

限制是适度的：学生数量和科目数量最多为 100 个。这意味着对学生和科目进行双循环（最多 10,000 次操作）的解决方案将在 1 秒的时间限制下轻松运行。 我们必须注意的边缘情况包括所有学生成绩相同、每个科目只有一名学生名列前茅，或者某一科目的最高成绩多次出现的情况。 粗心的方法可能仅在某个学生是某一学科中唯一的最大值时才对学生进行计数，这会产生错误的答案。 

## 方法

 一种简单的暴力方法是检查每个学生的每个科目，并跟踪该科目的最高成绩。 一旦达到最大值，我们就会标记所有达到该值的学生。 这涉及迭代每一列以找到最高成绩，然后再次迭代每个学生以检查他们是否符合最高成绩。 正确性得到了保证，因为我们明确地比较了每个科目的每个学生。 

这种蛮力对于这些约束来说已经是最佳的。 关键的见解是我们不需要排序或使用额外的数据结构。 我们可以简单地维护一组成功学生的指数，每当学生达到某一科目的最高成绩时就更新它。 问题结构使得这变得可行，因为网格很小并且每列的最大计算量很便宜。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(n) | 已接受 |
 | 最佳| O(n * m) | O(n) | 已接受 |

 ## 算法演练

 1. 读取学生数 _n_ 和科目数 _m_ 的输入值，然后读取接下来的 _n_ 行作为代表学生成绩的字符串。 每行都转换为一个列表，以便于索引。 
2. 初始化一组来跟踪成功的学生。 使用集合可以避免重复计数并允许高效插入。 
3. 从 0 到 _m-1_ 迭代每个主题索引。 对于每个科目，通过迭代该列的行来查找所有学生的最高成绩。 
4. 确定当前科目的最高成绩后，再次迭代所有学生，并将成绩与该科目最高成绩相匹配的任何学生添加到成功的集合中。 
5. 处理完所有科目后，成功集的大小代表成功学生的总数。 打印该值。 

为什么有效：通过逐列迭代，我们保证检查每个主题的最佳表现者。 该集合确保每个学生只计算一次，无论他们在多少科目中名列前茅。该算法不会错过任何成功的学生，因为每个学生的成绩比较都是明确发生的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
grades = [list(input().strip()) for _ in range(n)]
successful = set()

for col in range(m):
    max_grade = max(grades[row][col] for row in range(n))
    for row in range(n):
        if grades[row][col] == max_grade:
            successful.add(row)

print(len(successful))
```代码首先读取尺寸和等级网格。 每个学生的成绩都存储为字符列表。 主循环迭代每个主题（列）。 对于每一列，使用生成器表达式计算最高成绩，然后另一个循环标记所有达到该成绩的学生。 最后，集合的长度给出了成功学生的数量。 微妙之处在于将成绩作为字符串处理，因为它们是单位数字字符； 这是有效的，因为数字的字符比较给出了与整数比较相同的顺序。 使用集合可以避免重复，而无需额外记账。 

## 工作示例

 **样品1**

 输入：```
3 3
223
232
112
```跟踪表：

 | 上校 | 最大等级 | 成功集 |
 | --- | --- | --- |
 | 0 | 2 | {0, 1} |
 | 1 | 3 | {0, 1} |
 | 2 | 3 | {0, 1} |

 解释：学生 0 在科目 0 中取得最高成绩，学生 1 在科目 1 中取得最高成绩，两者都添加到成功组中。 学生 2 永远不会匹配最大值。 

**样品2**

 输入：```
2 2
99
99
```跟踪表：

 | 上校 | 最大等级 | 成功集 |
 | --- | --- | --- |
 | 0 | 9 | {0, 1} |
 | 1 | 9 | {0, 1} |

 两名学生在两个科目上都取得了成功。 该算法仅正确地对每个计数一次。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n * m) | 每个科目迭代都需要扫描所有学生以找到最大值，并再次标记成功的学生 |
 | 空间| O(n) | 该集合最多存储 n 个学生的索引 |

 当n和m达到100时，总操作最多为10,000次，很容易满足1秒的限制。 与 256 MB 限制相比，内存使用量可以忽略不计。 

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    grades = [list(input().strip()) for _ in range(n)]
    successful = set()
    for col in range(m):
        max_grade = max(grades[row][col] for row in range(n))
        for row in range(n):
            if grades[row][col] == max_grade:
                successful.add(row)
    return str(len(successful))

# Provided samples
assert run("3 3\n223\n232\n112\n") == "2", "sample 1"
assert run("2 2\n99\n99\n") == "2", "sample 2"

# Custom cases
assert run("1 1\n5\n") == "1", "single student and subject"
assert run("3 3\n111\n111\n111\n") == "3", "all equal values"
assert run("2 5\n12345\n54321\n") == "2", "top in multiple subjects"
assert run("4 4\n9123\n1294\n2912\n3219\n") == "4", "multiple winners"
assert run("100 1\n" + "\n".join("9" for _ in range(100)) + "\n") == "100", "maximum n edge case"
```| 测试输入| 预期产出 | 它验证了什么 |

 | 3 3\n111\n111\n111\n | 3 3 3 | 一切平等的价值观|
 | 2 5\n12345\n54321\n | 2 | 多个科目有不同的获奖者 |

 ## 边缘情况

 当所有学生的成绩相同时，每个学生都应该被视为成功。 对于输入：```
3 3
111
111
111
```每个科目的最大值为 1。迭代每一列，每个学生都匹配最大值并添加到集合中。 正如预期的那样，最终计数为 3。 这证实了算法可以正确处理平局情况。 

对于具有多个科目的单个学生：```
1 5
12345
```该学生在所有科目上都取得了不错的成绩。 该集合确保学生被计数一次，产生输出 1。这证实了算法正确处理最小尺寸的边缘情况。
