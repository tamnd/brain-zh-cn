 ## 解决方案
 ## 问题理解

 我们有两个整数来描述一对隐藏的数字。 考虑两个未知值$A$和$B$。 我们不会直接得到它们，而是被告知它们的总和以及它们之间的绝对差。 形式上，一个值等于$A + B$，另一个等于$|A - B|$。 任务是重建任何有效的对$(A, B)$满足这两种关系。 

输出的顺序不唯一，因此打印$(A, B)$或者$(B, A)$只要两个方程成立，则同样有效。 问题陈述保证对于给定的输入至少存在一对有效的输入。 

约束条件达到$10^9$，这立即排除了任何试图暴力对待候选人的方法$A$和$B$。 对所有可能值的天真搜索将需要检查$10^9$可能性，远远超出一秒的时间限制。 这促使我们进行直接的代数重建，而不是任何形式的枚举。 

当出现一个微妙的情况时$A < B$。 在这种情况下，绝对值会翻转符号，因此系统的行为会根据未知数的排序而有所不同。 一个粗心的实现假设$A \ge B$如果不考虑对称情况，仍然经常会通过隐藏测试，但在实际顺序相反的输入上失败。 例如，如果$X = 3$和$Y = 7$，有效解为$(-2, 5)$。 任何迫使$A = (X + Y)/2$和$B = (X - Y)/2$如果不处理符号一致性，将错误地假设两个值都是非负的或以固定方式排序。 

另一种边缘情况发生在$Y = 0$。 这迫使$A = B$，并且两个值必须相等$X/2$。 没有明确考虑这一点的解决方案仍然可以工作，但它强调系统退化为单一自由度。 

## 方法

 一个蛮力的想法是尝试所有可能的整数对$(A, B)$在一个合理的范围内，并检查它们是否满足两个方程。 每次检查的时间都是恒定的，但搜索空间是输入边界大小的二次方。 值高达$10^9$，即使将搜索限制在合理的范围内，仍然会导致$10^{18}$最坏情况下的组合，这是完全不可行的。 

关键的观察结果是方程组很小并且完全确定。 我们有：$$A + B = X$$

$$|A - B| = Y$$我们没有将绝对值视为复杂因素，而是将其分为两种线性情况。 任何一个$A - B = Y$或者$A - B = -Y$。 每种情况都将问题简化为求解 2×2 线性系统。 这将任务从搜索问题变成了简单的代数问题。 

如果我们采取$A - B = Y$，然后将两个方程相加得出$2A = X + Y$，减去得到$2B = X - Y$。 如果相反$A - B = -Y$，角色$A$和$B$对称交换。 由于该问题允许以任意顺序输出，因此我们可以计算一个一致的解决方案并直接打印它。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(10^{18})$|$O(1)$| 太慢了 |
 | 代数系统求解 |$O(1)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 读取数值$X$和$Y$。 这些定义了未知对的总和和绝对差。 
2. 计算候选假设$A \ge B$， 使用$A = (X + Y) / 2$。 这来自于添加$A + B = X$和$A - B = Y$，这隔离了$A$。 
3. 计算对应的$B = X - A$。 这确保了精确满足总和约束，而不会引入舍入不一致。 
4. 输出$(A, B)$。 如果隐藏对想要替代排序，则此输出仍然有效，因为交换不违反任一方程。 

### 为什么它有效

 核心不变量是任何有效的解决方案都必须满足通过选择绝对差的两个可能符号之一而导出的线性系统。 该变换将问题简化为求解确定性线性方程组。 由于两个符号选择之一恰好产生与约束一致的整数解，并且问题保证存在，因此计算出的对必须满足两个原始方程。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    X = int(input().strip())
    Y = int(input().strip())

    A = (X + Y) // 2
    B = X - A

    print(A, B)

if __name__ == "__main__":
    main()
```该实现直接对代数推导进行编码。 整数除法是安全的，因为该问题保证存在有效的整数解，这意味着$X + Y$在有效情况下始终是偶数。 

的建设$B$作为$X - A$避免单独重新计算第二个方程并保证与总和约束的一致性。 无需在绝对差的符号上显式分支，因为输出的对称性允许任一有效排序。

 ## 边缘情况

 当$Y = 0$，系统崩溃为$A = B = X/2$。 对于这样的输入：```
4
0
```计算给出$A = 2$,$B = 2$。 这两个约束都立即得到满足，并且不会出现歧义，因为绝对差不贡献任何附加信息。 

什么时候$X = Y$，其中一个值变为零。 例如：```
10
10
```产生$A = 10$,$B = 0$。 绝对差与求和结构完全匹配，并且无需特殊套管，公式仍然成立。 

什么时候$Y > X$，其中一个值变为负数。 为了：```
3
7
```我们得到$A = 5$,$B = -2$。 这表明假设非负性是不正确的，并且代数推导正确地处理有符号整数。 

在所有这些情况下，相同的构造仍然有效，因为它从不假设超出方程强制执行的顺序或符号约束。
