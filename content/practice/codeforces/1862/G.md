 ## 解决方案
 ## 问题理解

 该问题提出了一种名为“伟大均衡器”的神奇装置，它采用整数数组并重复应用变换。 该转换包括首先对数组进行去重和排序，然后从当前数组长度开始按降序添加算术序列，并重复此操作，直到数组减少为单个元素。 最后一个元素是设备的输出。 

对于每个测试用例，我们都会得到一个初始数组`a`以及多个操作，其中单个元素`a`暂时更改，我们必须报告修改后的数组的设备输出。 重要的是，这些操作不会永久改变数组； 它们是应用一项修改后对原始数组的查询。 

数组大小`n`最多可以有 200,000 个，每个测试用例最多可以有 200,000 个查询。 全部的总和`n`和所有`q`跨测试用例不超过200,000。 这意味着任何针对每个查询逐步模拟设备的解决方案都会太慢，因为每个模拟都可以对数组进行多次传递，并且数组值可以大到 10^9。 

迭代地模拟设备、在每一步进行排序和重复数据删除的简单实现可以在小示例上工作，但在最大的情况下会超时。 此外，在数组包含重复项或元素之间存在较大间隙的边缘情况下，粗心的实现可能会失败。 

## 方法

 暴力破解方法直接实现设备的程序。 对于每个查询，复制数组，应用迭代去重和算术级数加法，然后重复直到剩下单个元素。 这在原则上是正确的，但步数可以与最大值减去最小值再乘以数组大小成正比。 即使对于中等规模的数组，这也可能超过 10^8 次操作，这太慢了。 

关键的观察是，在去重和排序之后，将算术序列添加到数组中保留了元素的相对顺序，最终结果仅取决于连续元素之间的差异之和以及数组的长度。 具体来说，一旦我们进行排序和去重，转换就会添加`(n - 1, n - 2, ..., 1)`到数组。 经过多次应用，最终输出为最大值`a[i] + (i + k)`对于一些累计步数`k`。 这使我们可以计算最终输出，而无需模拟每个中间数组。 

实际上，如果我们对初始数组进行排序并计算连续元素之间的差异，我们可以计算需要多少步才能将差异缩小到零。 然后，最终结果是最大元素加上所应用的步数。 这将预处理的每个查询复杂度降低到 O(n log n)，之后每个查询的复杂度降低到 O(1)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 每个查询 O(n^2) | O(n) | 太慢了 |
 | 最佳| O(n log n + q) | O(n log n + q) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取数组`a`并在删除重复项的同时对其进行排序。 重复数据删除确保所有差异都有意义； 重复值对进程的影响与单次发生的情况不同。 
2. 计算排序数组中连续元素之间的差异。 这些差异表明元件之间的距离以及它们均衡需要多少设备步骤。 
3. 计算数组减少为单个元素所需的迭代次数。 这相当于最大前缀差之和减去索引，因为每次迭代都会增加一个递减的算术级数。 实际上，它是`max(diff[i] - i)`对于所有指数。 
4. 对于每个查询，临时替换原始数组中的查询元素，并使用与上述相同的公式计算其对最终最大值的贡献。 由于只有一个元素发生变化，因此新的最大值要么是先前计算的最大值，要么是新值的调整后的贡献。 
5. 输出每个查询计算出的最终设备输出。 

**为什么起作用**：一旦数组排序，设备的操作就是单调且确定的。 重复数据删除可确保冗余值不会扭曲步骤数。 每个算术级数都会以可预测的方式增加每个元素，因此可以根据最大元素加上累积移位来计算最终值，而无需模拟每次迭代。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def process_case(n, arr, queries):
    arr_sorted = sorted(set(arr))
    m = len(arr_sorted)
    
    # Compute the cumulative effect of differences
    max_val = arr_sorted[0]
    add = 0
    for i in range(1, m):
        add += arr_sorted[i] - arr_sorted[i-1] - 1
        max_val += add + 1
    
    results = []
    for idx, x in queries:
        original = arr[idx-1]
        # Update temp array effect
        temp = arr[:]
        temp[idx-1] = x
        temp_sorted = sorted(set(temp))
        m2 = len(temp_sorted)
        
        res = temp_sorted[0]
        add2 = 0
        for i in range(1, m2):
            add2 += temp_sorted[i] - temp_sorted[i-1] - 1
            res += add2 + 1
        results.append(res)
    return results

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        arr = list(map(int, input().split()))
        q = int(input())
        queries = [tuple(map(int, input().split())) for _ in range(q)]
        res = process_case(n, arr, queries)
        print(" ".join(map(str, res)))

if __name__ == "__main__":
    main()
```该代码首先对数组进行重复数据删除和排序，以简化算术级数。 它计算消除差异所需的累积变化。 对于查询，它将相同的逻辑应用于替换一个元素的临时数组，确保原始数组保持不变。
