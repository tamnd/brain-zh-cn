 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们被要求计算女巫维卡击败一系列怪物所需的最短时间。 每个怪物都有自己的力量，维卡有两种魔法——水和火。 一秒钟内，她会产生固定数量的水和火魔力。 为了击败怪物，无论使用哪种魔法，她都必须在一次法术中花费至少与怪物的力量一样多的法力。 如果她积累了足够的法力，她每秒可以施展多个法术。 该问题要求，对于多个测试用例，找到击败所有怪物所需的最少秒数。 

输入给出了每个测试用例的法力生成率和怪物的强度。 限制很小：每个测试用例的怪物数量最多为 100 个，所有测试用例的总和也最多为 100 个。每个怪物的强度最多为$10^4$，而每秒产生的法力可能非常大，最多可达$10^9$。 这表明我们可以探索怪物数量呈指数级增长的解决方案，因为$2^{100}$太大了，但是巧妙地使用子集和或 DP 超过受总强度限制的和（最多$100 \times 10^4 = 10^6$）是可行的。 

当一种类型的魔法值远大于另一种类型时，就会出现边缘情况。 例如，如果维卡每秒可以产生 1 单位的水，但每秒产生 100 单位的火，并且所有怪物的强度为 50，那么她应该专注于火系法术。 总是平均分配法力或忽略怪物魔法类型的最佳分配的粗心方法将会失败。 另一种边缘情况是当怪物强度总和与法力值的倍数完全匹配时，或者当只有一个怪物时； 这些需要精确的计算而不是近似值。 

## 方法

 暴力解决方案考虑了怪物对水或火法术的所有可能分配。 每个怪物都有两个选择，所以有$2^n$总作业数。 对于每个任务，我们计算所需的总水和火法力，除以每秒生成的法力（向上舍入），然后取最大值。 这保证了正确性，因为它确实检查了两种魔法类型之间分配怪物的每种方式。 然而，随着$n$最多 100 个，$2^{100}$可能性是不可行的。 

关键的观察是，这是一个经典的二维子集和问题。 我们可以专注于水法力分配，因为火会自动确定。 如果我们可以找到分配给水的怪物子集，使得所需的总水法力为$W$，那么剩下的怪物需要$F$法力值，最短时间为$\max(\lceil W / w \rceil, \lceil F / f \rceil)$。 所有怪物实力总和最多为$10^6$，因此我们可以对可实现的水总量进行动态规划。 具体来说，我们维护一个布尔 DP 数组，其中`dp[s]`如果存在水强度总和恰好为的怪物子集，则为真$s$。 一旦我们有了 DP，我们就会迭代所有可实现的总和`s`并将时间计算为$\max(\lceil s / w \rceil, \lceil (total - s) / f \rceil)$，保持最小值。 

这将问题从指数时间减少到伪多项式时间。 最大DP大小是所有怪物强度的总和，最多为$10^6$，对于每个怪物，我们更新 DP 数组。 和$n \le 100$，这是有效的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 子集和上的 DP | O(n * S) 其中 S=强度总和 | O(S)| 已接受 |

 ## 算法演练

 1.计算怪物实力总和。 让`total = sum(s_i)`。 
2.初始化一个大小为boolean DP的数组`total + 1`， 和`dp[0] = True`因为在没有怪物的情况下，总和可以为 0。 
3.针对每个怪物的强度`s_i`，向后迭代 DP 数组`total`下降到`s_i`。 如果`dp[j - s_i]`为 True，则设置`dp[j] = True`。 这会更新所有可实现的水量。 
4. 初始化`ans`作为无穷大。 迭代所有索引`w_sum`在 DP 数组中。 对于每个`w_sum`这是可以实现的（`dp[w_sum] = True`), 计算剩余火力总和`f_sum = total - w_sum`。 计算积累法力的时间：`time = max((w_sum + w - 1) // w, (f_sum + f - 1) // f)`。 更新`ans = min(ans, time)`。 
5、输出`ans`作为所需的最短秒数。 

为什么有效：DP保证我们考虑怪物在水和火之间的每一种可能的分裂。 每个`w_sum`对应于一些怪物对水系法术的有效分配。 补足自动给出火力分配。 的计算`max(ceil(W/w), ceil(F/f))`正确模拟积累两种类型足够法力的时间。 通过迭代所有可实现的水总量，我们确保找到最短的总时间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        w, f = map(int, input().split())
        n = int(input())
        s = list(map(int, input().split()))
        total = sum(s)
        dp = [False] * (total + 1)
        dp[0] = True
        for strength in s:
            for j in range(total, strength - 1, -1):
                if dp[j - strength]:
                    dp[j] = True
        ans = float('inf')
        for w_sum in range(total + 1):
            if dp[w_sum]:
                f_sum = total - w_sum
                time = max((w_sum + w - 1) // w, (f_sum + f - 1) // f)
                if time < ans:
                    ans = time
        print(ans)

if __name__ == "__main__":
    solve()
```DP 部分向后迭代，以防止在同一子集中多次重复计算单个怪物。 计算`(w_sum + w - 1) // w`整数除法向上舍入，相当于`ceil(w_sum / w)`，这确保部分法力积累被计为一整秒。
