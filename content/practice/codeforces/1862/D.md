 ## 解决方案
 ## 问题理解

 我们被要求确定特马需要购买的冰淇淋球的最小数量才能准确制作`n`独特的两球冰淇淋甜筒。 每个圆锥体由两个球组成，这两个球的味道可能相同。 如果两个锥体口味的**多重**不同，则认为它们不同。 例如，锥体`{1,2}`和`{2,1}`是相同的，但是`{1,1}`不同于`{1,2}`。 特马可以根据需要购买任意多种口味，并且如果需要，他可以使用多个相同口味的球。 

输入提供`t`测试用例。 每个测试用例给出一个整数`n`，所需的不同二球锥体数量。 每个测试用例的输出应该是所需的冰淇淋球的最小总数。 

限制条件很大：`n`可以高达`10^18`。 这立即排除了任何试图枚举所有可能锥体的暴力方法。 对于最大的输入，即使是 O(n) 解决方案也是不可行的。 我们需要一个对数解`n`或者使用直接的数学推理。 边缘情况发生时`n`非常小，比如`1`或者`2`，因为我们必须确保有足够的球来形成一个双味甜筒。 

例如，如果`n = 1`，最小的球组是`[1,1]`- 一种口味，两个球 - 生产一个独特的蛋筒。 如果`n = 3`，我们不能用两个球来做到这一点，因为那样只允许一个不同的圆锥体； 我们需要三个球`[1,2,3]`形成三个不同的圆锥体`{1,2}`,`{1,3}`， 和`{2,3}`。 

## 方法

 蛮力方法会尝试模拟所有可能的方式，将球分配给口味并计算所得的两个球锥体，直到我们精确地达到`n`。 虽然概念上很简单，但这种方法非常慢。 组合的数量随着球的数量呈二次方增长，并且`n`最多`10^18`，甚至计算所有组合也是不可能的。 

关键的观察结果是，可以由以下材料制成的不同的双球锥体的数量`k`如果每个球都有独特的风味，那么球的数量就会最大化。 这个数字由组合公式给出`C(k,2) = k*(k-1)/2`。 如果`n`小于下一个三角形数，最好添加现有口味的额外球以准确达到`n`视锥细胞。 一般策略是找到最小的整数`k`这样`k*(k+1)/2 >= n`。 这确保了`k`球，我们至少可以形成`n`独特的双球锥体，要么具有所有独特的口味，要么具有一些重复的口味来填补空白。 

我们可以高效地找到`k`使用从二次不等式导出的封闭式解或二分搜索。 封闭式解决方案涉及求解`k*(k+1)/2 >= n`为了`k`使用二次公式，并向上舍入到最接近的整数。 这种方法非常快，因为它在每个测试用例的恒定时间内计算结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(k^2) | O(k^2) | O(k) | 对于 n > 10^5 来说太慢 |
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`，所需冰淇淋类型的数量。 
2. 观察我们可以制作的不同两球锥体的最大数量`x`球，如果都是唯一的，是`x*(x-1)/2`。 我们至少需要这么多才能达到`n`。 
3. 解决不等式`x*(x-1)/2 >= n`为了`x`。 将其重写为二次方程：`x^2 - x - 2*n >= 0`。 
4.利用二次公式求`x = ceil((1 + sqrt(1 + 8*n))/2)`。 这是所需的最小球数。 
5. 打印结果`x`对于每个测试用例。 

为什么它有效：公式`x*(x-1)/2`计算所有可能的不同球对。 通过求解`x`，我们确保我们有足够的球来生产至少`n`独特的冰淇淋。 使用上限可确保即使二次公式给出小数结果，我们也会向上舍入以获得整数个球。 任何更少的球都会产生严格少于`n`不同的锥体。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    # solve x*(x-1)/2 >= n => x^2 - x - 2n >= 0
    x = math.ceil((1 + math.sqrt(1 + 8*n)) / 2)
    print(x)
```该解决方案读取测试用例的数量，然后对于每个`n`计算最小值`x`使用二次公式。`math.sqrt`对于非常大的人来说是安全的`n`在Python中由于任意精度整数，并且`math.ceil`确保满足不等式的最小整数。 这可以避免在我们使用整数除法或尝试手动舍入时可能发生的差一错误。 

## 工作示例

 输入样本`n = 3`:

 | 步骤| 计算| 说明|
 | ---| ---| ---|
 | 1 | n = 3 | 所需锥体数量 |
 | 2 | 求解 x*(x-1)/2 >= 3 | x*(x-1)/2 = 3 |
 | 3 | 二次：x^2 - x - 6 >= 0 | 重新排列方程 |
 | 4 | x = ceil((1 + sqrt(1 + 24))/2) = ceil((1 + 5)/2) = 3 | 所需最少球数 |
 | 5 | 输出：3 | 球`[1,2,3]`生产锥体`{1,2},{1,3},{2,3}`|

 输入样本`n = 6`:

 | 步骤| 计算| 说明|
 | ---| ---| ---|
 | 1 | n = 6 | 想要的甜筒冰淇淋|
 | 2 | 二次：x^2 - x - 12 >= 0 | 求解 x |
 | 3 | x = ceil((1 + sqrt(1+48))/2) = ceil((1+7)/2) = 4 | 所需最少球数 |
 | 4 | 输出：4 | 球`[1,2,3,4]`产生 6 个锥体：所有对 |

 这些痕迹表明，该公式正确计算了最小球数，即使对于小球也是如此。`n`。

 ## 边缘情况

 对于`n = 1`，算法计算`x = ceil((1 + sqrt(1+8))/2) = 2`。 这正确地输出 2，因为我们需要两个相同口味的球来制作一个圆锥体。 为了`n = 10^18`,`x`大约是 1.34×10^9，Python 的整数运算可以处理这个而不会溢出。 该公式本质上可以处理非常小和非常大的情况`n`，并且不需要额外的边界检查。
