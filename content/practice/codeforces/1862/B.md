 ## 解决方案
 ## 问题理解

 我们被要求重建一个可能的原始序列`a`给定一个序列`b`这是通过简单的过滤规则得出的。 顺序`b`总是从第一个元素开始`a`，然后包括每个元素`a`大于或等于其直接前一个。 换句话说，`b`是通过在我们扫描时保留第一个元素和所有不减少的“峰值”而形成的`a`。 我们的任务不是找到唯一的原始序列而是找到任何有效的序列`a`可以产生给定的`b`。 

约束允许最多`2 * 10^5`中的元素`b`跨所有测试用例。 由于我们可以输出长度可达的序列`2n`对于每个`b`，线性结构就足够了。 这排除了比以下更复杂的事情`O(n)`每个测试用例。 

微妙之处在于两个连续元素之间`b`, 的元素`a`可以自由下降和上升，只要第一个非下降元素到达下一个元素`b`。 例如，如果`b = [4, 6, 3]`，我们可以在之间插入任何序列`4`和`6`不超过`6`前`6`，和之间`6`和`3`，我们可以有一个结束于的递减序列`3`。 边缘情况发生时`b`只有一个元素，或者当连续元素相等时，在这种情况下，重复一次或多次的相同元素的序列仍然有效。 

## 方法

 暴力方法将尝试枚举长度达到的所有序列`2n`看看哪一个简化为`b`，但可能性的数量呈指数级增长，并且是不可行的。 

最佳方法利用了这样的观察：在连续元素之间放置一个中间元素就足够了。`b`允许增加和减少。 具体来说，之间`b[i]`和`b[i+1]`，我们可以插入`b[i]`再次如果`b[i] > b[i+1]`允许下一个值下降。 这确保过滤规则仍然准确地产生`b`。 如果`b[i] <= b[i+1]`，我们只需附加`b[i+1]`直接地。 该方法保证结果序列`a`最多有长度`2n`，尊重过滤规则，并以线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 构造线性| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个空列表`a`。 
2. 追加第一个元素`b`到`a`。 
3. 迭代每对连续元素`(b[i], b[i+1])`:

 1. 追加`b[i+1]`到`a`。 
2.如果`b[i] > b[i+1]`, 附加`b[i]`就在之前`b[i+1]`允许减少，同时保留过滤规则。 这确保了构建时`b`从`a`，非递减滤波器将跳过插入的`b[i]`如果需要的话。 
4.处理完所有对后，输出长度`a`以及序列本身。 

为什么它有效：通过插入`b[i]`前`b[i+1]`每当需要减少时，我们保证过滤规则仍然准确地产生`b`。 第一个元素始终被保留，并且插入的元素不能违反非递减过滤器，因为我们以重复前一个数字或允许下一个元素递减的方式放置它。 长度最多为`2n`因为我们每对最多插入一个元素。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        b = list(map(int, input().split()))
        a = [b[0]]
        for i in range(1, n):
            if b[i-1] > b[i]:
                a.append(b[i-1])
            a.append(b[i])
        print(len(a))
        print(*a)

if __name__ == "__main__":
    solve()
```该解决方案使用有效地读取输入`sys.stdin.readline`并构造序列`a`线性地。 需要注意处理通过再次插入前一个元素来减少连续元素的情况，这对于过滤规则准确产生结果至关重要`b`。

 | ---| ---| ---| ---| ---|
 | 0 | - | 4 | 附录 4 | [4] |

 输出长度：4

 输出序列：`[4, 6, 6, 3]`这个序列准确地产生`b`根据游戏规则进行过滤。

 ## 边缘情况

 关键的边缘情况发生在以下情况：`b`只有一个元素。 例如，`b = [144]`。 算法正确输出`[144]`长度为 1。另一个边缘情况是当连续元素`b`是平等的。 例如，`b = [2, 2, 2]`输出`[2, 2, 2]`，避免不必要的插入，且长度不超过`2n`。 两种边缘情况均由线性插入逻辑处理。
