 ## 解决方案
 ## 问题理解

 关于原始数组唯一重要的是每个相邻比较的符号。 

对于每个位置$i$，定义一条边$a_i$和$a_{i+1}$。 

如果$a_i < a_{i+1}$，称边缘为正。 

如果$a_i > a_{i+1}$, call the edge negative.

 当每个边都为正时，数组已经严格递增。 

操作选择一个连续的段并重写其中的所有值。 关键的限制是，完全在所选段内的每个比较都必须保留其原始符号。 正沿保持正值，负沿保持负值。 

输入尺寸很大。 The total length over all test cases is$2 \cdot 10^5$，因此任何二次算法都会立即被排除。 每个测试用例我们都需要一些线性或接近线性的东西。 

最容易犯的错误是考虑实际值。 该操作不关心大小，只关心比较符号。 

考虑：```
3 2 1
```有两个负边沿。 一个操作只能影响其区间边界上的边缘，因此不能同时删除两个负数。 正确答案是`2`。 

另一个简单的陷阱是假设每对负边总是可以一起删除。```
3 2 1
```两个负边沿是第一个边沿和最后一个边沿。 如果我们尝试用一个区间消除两者，则该区间之外的值必须满足`3 < 1`，这是不可能的。 答案依然存在`2`。 

一个更微妙的例子是：```
-2 -5 5 2
```下降沿位于位置 1 和 3。此处外部值为`-2`和`2`，所以一次操作就足够了。 正确答案是`1`。 

这些示例表明，答案取决于负边沿的位置以及两个边界值之间的单次比较。 

## 方法

 蛮力的观点是将每个操作视为选择一个区间并更改其中的值。 人们可以尝试对所有可能的间隔、所有可能的操作序列进行建模，并搜索最小计数。 

这种方法立即崩溃。 有$O(n^2)$间隔时间长，操作可以重复，状态空间巨大。 

关键的观察结果是操作仅更改接触区间边界的两个边缘。 

假设我们选择$[l,r]$。 

严格位于区间内的每条边在该操作期间永远保持其原始符号。 仅边缘$(l-1,l)$和边缘$(r,r+1)$可能会改变。 

这意味着单个操作最多可以删除两个负边沿。 让$m$是负边的数量。 然后：$$\text{answer} \ge \left\lceil \frac{m}{2} \right\rceil.$$整个问题就变成了：

 我们总能达到这个下限吗？ 

如果$m$很奇怪，答案是肯定的。 

如果$m$是偶数，答案有时是肯定的，有时是更大的。 

剩下的任务是准确描述何时可以达到下限。

 ## 算法演练

 让负边沿位于位置$$d_1 < d_2 < \dots < d_m.$$这里$d_i$方法$a_{d_i} > a_{d_i+1}$。 

### 1. 计算下降沿

 设他们的计数为$m$。 

如果$m=0$，数组已经严格递增，所以答案是`0`。 

### 2. 处理奇怪的情况

 如果$m$很奇怪，答案是$$\frac{m+1}{2}.$$通过在第一个操作中移除一个负边沿，然后一次移除两个剩余的负边沿，可以实现下限。 

### 3. 处理偶数情况

 让$$k = \frac{m}{2}.$$准确地达到$k$操作，每个操作必须恰好删除两个负边沿。 

这迫使第一个负边缘和最后一个负边缘保留为整个结构的两个外部边界。 它们相邻的外部值为$$x = a_{d_1}, \qquad y = a_{d_m+1}.$$这两个值成为任何策略的不变量$k$运营。 

### 4.检查不变量

 如果$$x < y,$$然后它们之间的整个区域可以重建为严格递增的序列，同时将所有负边两两配对。 下界$k$是可以实现的。 

如果$$x \ge y,$$那么这样一个严格递增的桥是不可能的。 需要进行一项额外操作。 

所以：$$\text{answer} = \begin{cases} k, & x < y,\\ k+1, & x \ge y. \end{cases}$$### 为什么它有效

 只有当负边沿成为某些操作的边界边沿时，它才会消失。 由于一次操作只有两个边界，因此最多可以消除两个负边沿。 这给出了下界$\lceil m/2 \rceil$。 

什么时候$m$是奇数，下界总是可以匹配的。 

什么时候$m$是偶数，匹配下界意味着每个操作必须恰好消除两个负数。 在这种情况下，第一个下降沿旁边的左值和最后一个下降沿旁边的右值无法更改。 任何最终的严格递增构造都必须连接这两个固定值。 

如果$a_{d_1} < a_{d_m+1}$，这样的连接存在并且下界是可以达到的。 

如果$a_{d_1} \ge a_{d_m+1}$，没有严格递增序列可以从左值开始并在右值结束，因此多一次操作是不可避免的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        desc = []
        for i in range(n - 1):
            if a[i] > a[i + 1]:
                desc.append(i)

        m = len(desc)

        if m == 0:
            ans.append("0")
            continue

        if m & 1:
            ans.append(str((m + 1) // 2))
        else:
            k = m // 2
            first = desc[0]
            last = desc[-1]

            if a[first] < a[last + 1]:
                ans.append(str(k))
            else:
                ans.append(str(k + 1))

    sys.stdout.write("\n".join(ans))

solve()
```该实现只需要负边沿的位置。`desc`存储每个索引`i`这样`a[i] > a[i+1]`。 

如果计数为奇数，则公式立即生效。 

如果计数为偶数，我们将查看紧邻第一个下降沿左侧的值和紧邻最后一个下降沿右侧的值。 这两个值之间的比较决定是否可以达到下限。 

最容易出错的索引细节是正确的端点。 如果最后一个下降沿位于位置`i`，右边界值为`a[i + 1]`，这变成`a[last + 1]`在从零开始的索引中。

 ## 边缘情况

 考虑：```
3
3 2 1
```有两个负边沿。 下界是`1`，但边界值为`3`和`1`。 自从`3 >= 1`，没有严格递增的序列可以将它们连接起来。 算法返回`2`。 

考虑：```
4
-2 -5 5 2
```再次有两个负边沿，但现在边界值为`-2`和`2`。 自从`-2 < 2`，下界是可以达到的。 算法返回`1`。 

考虑：```
5
1 2 3 4 5
```没有负面边缘。 数组已经严格递增，所以答案是`0`。 

考虑：```
3
3 1 2
```正好有一个负边沿。 任何操作最多删除两个负数，因此一次操作就足够了。 奇数计数公式返回`1`。
