 ## 解决方案
 ## 问题理解

 我们有两个不同尺寸的齿轮`a`和`b`。 我们需要添加相同的非负齿数`x`到两个齿轮。 添加这些牙齿后，第一个新尺寸`a + x`必须能被原来的第二个尺寸整除`b`，以及第二个新尺寸`b + x`必须能被原始第一个尺寸整除`a`。 

任务是找到尽可能小的`x`。 

输入包含两个整数`a`和`b`, 每个最多`10^9`。 这立即排除了搜索可能的值`x`，因为答案可能非常大。 即使是检查数百万候选者的循环也是不可靠的，并且与`a`或者`b`是不可能的。 我们需要将问题简化为一些算术运算。 

主要的边缘情况来自两个数字之间的关系。 如果齿轮已经具有相同的尺寸，则答案为零，因为两个可分性条件都已满足。 例如，输入`123 123`给出输出`0`，而盲目尝试增加这两个值的解决方案可能会错过这一点。 

另一种棘手的情况是一个数字除另一个数字时。 用于输入`8 1`，答案是`7`， 不是`0`，因为新尺寸变为`15`和`8`， 和`15`可以整除`1`尽管`8`可以整除`8`。 一种仅检查一个原始值是否能整除另一个值的粗心方法可能会错误地提前停止。 

当最小公倍数小于两个原始值之和时，就会出现第三种边缘情况。 用于输入`3 4`，最小公倍数是`12`，并且最小有效的最终齿轮尺寸对齐需要添加`5`， 不是`0`或者`1`。 答案是`5`因为最终的尺寸是`8`和`9`，满足所需的整除性。 

## 方法

 直接方法会尝试以下值`x`从零开始并测试这两个条件是否成立。 这是正确的，因为通过测试的第一个值恰好是最小值。 然而，答案可能接近于`10^18`，所以即使检查大量的候选者也是不可能的。 

有用的观察来自于查看最终的齿轮尺寸。 数量`a + x`必须是的倍数`b`， 和`b + x`必须是的倍数`a`。 这意味着两个最终值是相反原始值的倍数，而它们的差异保持固定：`(a + x) - (b + x) = a - b`。 

更简洁的方法是表达第一个条件。 让：`a + x = k * b`。 

然后：`b + x = b + k*b - a = (k + 1)b - a`。 

为了可以被整除`a`，值`(k + 1)b`必须能整除`a`。 构成多个数的最小乘数`b`也兼容多个`a`与最小公倍数有关。 

最终的共同对齐点是`lcm(a, b)`。 由于两个最终值都与原始值相差相同的量，因此通过找到最小公倍数的最小倍数来获得最小可能的附加值，该倍数至少为`a + b`。 

让`L = lcm(a, b)`。 答案是：`smallest_multiple_of_L_not_less_than_(a+b) - a - b`。 

因为`L`至少两者都是`a`和`b`，所需的倍数是`L`或者`2L`，但使用整数上限除法可以直接处理每种情况。

 ## 算法演练

 1. 计算最大公约数`a`和`b`。 最小公倍数可得为`a * b / gcd(a, b)`，并且首先使用 gcd 可以防止整数类型较小的语言中不必要的溢出。 
2.让`L`是两个齿轮尺寸的最小公倍数。 我们需要最小的倍数`L`不小于`a + b`。 
3. 使用上限除法计算乘数：`(a + b + L - 1) // L`。 乘法`L`通过该值给出最小的有效对齐点。 
4. 减法`a + b`从这个对齐点开始。 剩余的数量正是必须添加到两个齿轮的齿数。 

为什么有效：最终值`a + x`和`b + x`必须定位，以便每个都达到另一个的可分结构。 这两个值之间的距离是固定的，并且整除性要求强制对齐发生在`lcm(a, b)`。 该算法选择当前总大小之后的第一个这样的对齐方式`a + b`，因此任何较小的值`x`将在第一个可能的有效位置之前离开齿轮。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    a, b = map(int, input().split())

    g = math.gcd(a, b)
    lcm = a // g * b

    target = ((a + b + lcm - 1) // lcm) * lcm
    print(target - a - b)

if __name__ == "__main__":
    import math
    solve()
```该解决方案首先读取两个齿轮尺寸并计算它们的最大公约数。 gcd 用于构建最小公倍数而不相乘`a`和`b`太早了。 

变量`target`表示最小公倍数的第一个倍数不小于`a + b`。 上限除法公式可避免出现差一错误`a + b`已经是的倍数`lcm`。 

最后的减法消除了两个齿轮的原始贡献。 剩下的就是每个齿轮必须添加的齿数。 

Python 整数自动处理大值，因此用于最小公倍数的乘法不需要特殊处理。

 ## 边缘情况

 对于等速齿轮，例如：```
123 123
```最大公约数是`123`，最小公倍数也是`123`。 总和`a + b`已经是的倍数`lcm`，所以目标仍然是`246`，产生一个答案`0`。 该算法自然会处理这个问题，无需特殊情况。 

对于划分情况：```
8 1
```最小公倍数是`8`。 总和是`9`，所以第一个倍数`8`达到或超过它的是`16`。 答案是`16 - 9 = 7`，给出最终齿轮尺寸`15`和`8`。 第一个可除以`1`，第二个可被整除`8`。 

对于互质对：```
3 4
```最小公倍数是`12`。 当前大小的总和是`7`，所以第一个有效对齐是`12`。 算法返回`5`，生产最终尺寸`8`和`9`， 在哪里`8`可以整除`4`和`9`可以整除`3`。 

对于非常大的值，该算法仅执行 gcd 和算术运算。 它从不迭代可能的答案，因此运行时间相对于所需添加的大小保持不变。
