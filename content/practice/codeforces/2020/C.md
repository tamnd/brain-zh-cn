 ## 解决方案
 ## 问题理解

 给定三个非负整数`b`,`c`， 和`d`。 我们必须构造一个非负整数`a`这样$$(a \mid b) - (a \& c) = d$$在哪里`|`是按位或和`&`是按位与。 

任务不是优化某些值`a`。 任何有效的`a`是可以接受的。 如果不存在这样的值，我们打印`-1`。 

第一个观察来自数字的大小。 每个值可以大到$10^{18}$，这意味着最多大约 60 个二进制位是相关的。 可以有多达$10^5$测试用例，因此每个测试用例花费数千次操作的解决方案都可以，但是任何取决于数字本身大小的操作都是不可能的。 

对可能值的暴力搜索`a`立即被排除。 允许范围达到$2^{61}$，这大约是$2.3 \times 10^{18}$。 

棘手的部分是减法。 许多按位问题可以逐位独立解决，但减法通常会在相邻位之间引入借位。 一般来说，不考虑借用而单独处理每一位的粗心解决方案是不正确的。 

关键的边缘情况来自于强制矛盾的位组合。 

考虑：```
b = 0, c = 0, d = 1
```那么方程就变成了$$a - 0 = 1$$所以答案是`a = 1`。 

无法正确重建位的解决方案`a`会错过这个微不足道的案例。 

另一个重要案例是：```
b = 1, c = 0, d = 0
```对于位 0，`(a|1)`总是`1`， 尽管`(a&0)`总是`0`。 左边总是至少`1`，所以不存在解。 正确的输出是`-1`。 

错误的第三个来源是忘记减法可能会产生借位。 

例如：```
b = 0, c = 1, d = 1
```如果我们选择`a = 1`，那么

 (1|0) - (1&1) = 1 - 1 = 0

 不`1`。 

位之间的关系取决于进入当前位置的借位，因此我们必须显式地跟踪它。 

## 方法

 最直接的想法就是暴力。 尝试每一个可能的值`a`， 评价$$(a|b)-(a\&c)$$并检查它是否等于`d`。 

这显然是正确的，因为它审查了每一位候选人。 问题在于搜索空间。`a`可能大到$2^{61}$，所以最坏的情况需要超过$2 \times 10^{18}$评价。 即使每秒执行十亿次操作，也需要几十年的时间。 

表达式的结构表明采用按位方法。 OR 和 AND 都独立地对每一位进行操作。 耦合不同位位置的唯一操作是减法。 

让$$X = a|b$$和$$Y = a\&c$$方程变为$$X - Y = d.$$执行二进制减法时，从一位流向下一位的唯一信息是借位。 这意味着我们可以从最低有效位到最高有效位处理位，同时保持单一状态：传入借位。 

对于每个位的位置我们知道：

 - 一点`b`- 一点`c`- 一点`d`- 当前借入

 未知是一点点`a`。 

尝试两种可能性（`0`或者`1`）就足够了。 对于每个选择，我们可以计算相应的位`X`和`Y`，执行一步二进制减法，检查产生的位是否与目标位相匹配`d`。 

这将问题变成了一个只有两个借用状态的微小动态过程，`0`和`1`。 由于我们最多处理 61 位，因此每个测试用例的工作量是恒定的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^{61})$|$O(1)$| 太慢了|
 | 最佳 |$O(61)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 初始化`a = 0`和`borrow = 0`。 
2. 处理位位置`0`通过`60`。 
3. 提取当前位：$$b_i,\ c_i,\ d_i$$从`b`,`c`， 和`d`。 
4. 尝试当前位的两个可能值`a`，即`0`和`1`。 
5. 对于候选位`a_i`，计算：$$x_i = a_i \mid b_i$$和$$y_i = a_i \& c_i$$6. 模拟一步二进制减法：$$x_i - y_i - borrow$$如果该值是非负数，则结果位就是该值，下一个借位是`0`。 

否则添加`2`到该值并将下一个借位设置为`1`。 
7. 检查结果位是否等于`d_i`。 

如果匹配，则选择`a_i`与方程一致。 将位存储在答案中，更新借位，然后继续到下一个位置。 
8. 如果两者都不是`a_i = 0`也不`a_i = 1`产生所需的位，不存在解决方案。 输出`-1`。 
9. 处理完所有位后，验证最终借位是否为零。 剩余的借位意味着减法结果不等于`d`。 
10. 输出构造的值`a`。 

### 为什么它有效

 在每个位位置，二进制减法仅取决于三个值：被减数的当前位、减数的当前位以及进入该位置的借位。 

该算法明确列举了未知位的仅有两种可能性`a_i`。 每当一个选择重现所需的位时`d`，它保留了有效全局解决方案的可能性，因为高位所需的所有信息都由传出借位汇总。 

借位充当减法过程的完整状态。 由于每个处理的位都与相应的位匹配`d`，最终借位为零，重构数满足$$(a|b)-(a\&c)=d.$$如果在某个位置没有选择`a_i`可以产生所需的位，则不存在有效的延续，因此报告`-1`是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        b, c, d = map(int, input().split())

        a = 0
        borrow = 0
        ok = True

        for i in range(61):
            bi = (b >> i) & 1
            ci = (c >> i) & 1
            di = (d >> i) & 1

            found = False

            for ai in (0, 1):
                xi = ai | bi
                yi = ai & ci

                cur = xi - yi - borrow

                if cur >= 0:
                    bit = cur
                    nb = 0
                else:
                    bit = cur + 2
                    nb = 1

                if bit == di:
                    found = True
                    borrow = nb

                    if ai:
                        a |= (1 << i)

                    break

            if not found:
                ok = False
                break

        if borrow:
            ok = False

        ans.append(str(a if ok else -1))

    sys.stdout.write("\n".join(ans))

solve()
```解法完全遵循减法过程。 

变量`borrow`存储进入当前位的借位。 对于每个位位置，我们测试两个可能的值`a_i`。 

表达式```
xi = ai | bi
yi = ai & ci
```代表相应的位`(a|b)`和`(a&c)`。 

减法步骤的执行方式与二进制算术完全相同。 如果局部值变成负数，我们借用下一位，加上`2`到当前位置，并记录借出`1`。 

一个微妙的点是加工范围。 该问题保证有效答案位于`[0, 2^61]`，所以检查位`0..60`就足够了。 所有输入如下`2^60`，并且任何需要更高位的借用传播都会被最终检测到`borrow`查看。 

另一个微妙的细节是我们立即承诺第一个有效的选择。 对于每个州`(bit position, incoming borrow)`至多需要一个延续。 借用完全总结了之前的所有决策，因此不需要额外的回溯。
