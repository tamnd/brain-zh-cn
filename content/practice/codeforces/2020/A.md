 ## 解决方案
 ## 问题理解

 我们被要求减少给定的整数`n`通过重复减去第二个整数的幂来归零`k`。 每次减法可以使用以下任意幂`k`（包括`k^0 = 1`），目标是最小化减法次数。 输入由多个测试用例组成，每个测试用例给出值`n`和`k`，并且输出必须指定每个测试用例的最小操作数。 

约束条件允许`n`和`k`最大为 10^9，最多有 10^4 个测试用例。 这排除了任何显式枚举所有减法序列或迭代所有幂的方法`k`以一种天真的方式。 该解决方案的每个测试用例的运行时间必须为 O(log n) 或更好，因为需要表示的操作数量`n`在基地`k`是对数`n`。 边缘情况包括`k = 1`，其中每个运算仅减 1，并且大幂`k`超过`n`立即地。 

一个天真的实现可能会错误地假设我们应该总是减去最大可能的幂`k`。 虽然这适用于`k > 1`， 为了`k = 1`除非单独处理，否则它永远不会正确终止。 

## 方法

 蛮力方法是迭代地减去一些幂`k`从`n`，在每一步尝试所有可能的力量。 这原则上是正确的，因为任何减法序列都会减少`n`为零是有效的，但可能的序列数量呈指数增长，这使得它对于给定的约束完全不可行。 

关键的见解是认识到`k`相当于表达`n`在**基地`k`**。 基数中的每个数字`k`告诉我们相应的幂的多少倍`k`必须减去。 因此，最少的运算次数恰好是`n`当写成基数时`k`。 例如，`n = 5`和`k = 2`给出以 2 为底的表示形式`101`，其中有两个，对应于两个所需的操作。 

什么时候`k = 1`，基本表示是退化的，每次减法只能去掉`1`，所以操作次数等于`n`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每次操作 O(n) | O(1) | O(1) | 对于大 n 来说太慢 |
 | 基 k 数字和 | O(log_k n) | O(log_k n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，读取整数`n`和`k`。 
3.如果`k`等于1，返回`n`作为答案，因为每个运算都恰好减去 1。 
4. 否则，将操作计数器初始化为零。 
5. 虽然`n`大于零：

 - 计算`n % k`，给出当前功率的减法次数`k`需要。 
- 将此余数添加到操作计数器中。 
- 更新`n`到`n // k`处理下一个更高的幂`k`。 
6. 循环结束后，计数器包含最少的操作数。 输出它。 

为什么有效：表达`n`在基地`k`精确捕获每个幂的次数`k`是需要的。 每一步的余数表示要减去当前功率的多少，然后除以`k`移动到下一个幂。 当所有能量耗尽时，该过程终止，保证最少的操作次数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        if k == 1:
            print(n)
            continue
        ans = 0
        while n > 0:
            ans += n % k
            n //= k
        print(ans)

if __name__ == "__main__":
    solve()
```该代码使用快速 I/O 有效地处理多个测试用例。 它区分了特殊情况`k = 1`以避免无限循环并使用整数除法和模来遍历基数`k`表示。 每次循环迭代对应于处理基数中的一位数字`k`，确保对数复杂度。 

## 工作示例

 输入样本`n = 5`,`k = 2`：

 | 步骤| n | n % k | 回答 | n //= k |
 | --- | --- | --- | --- | --- |
 | 初始| 5 | 1 | 1 | 2 |
 | 步骤 2 | 2 | 0 | 1 | 1 |
 | 步骤 3 | 1 | 1 | 2 | 0 |

 操作总数：2。这匹配最小序列`5 - 1 = 4`,`4 - 4 = 0`。 

输入样本`n = 3`,`k = 5`：

 | 步骤| n | n % k | 回答 | n //= k |
 | --- | --- | --- | --- | --- |
 | 初始| 3 | 3 | 3 | 0 |

 总操作数：3，符合预期输出。

 ## 边缘情况

 当`k = 1`，每次减法只能去掉1。例如，`n = 10`和`k = 1`正好需要 10 次操作。 为了`k > n`，以 k 为基数的数字和可以正确处理：`n % k = n`和`n // k = 0`，精确地产生`n`运算，与减法一致`1`反复。 大幂幂`k`不影响正确性，因为基本表示总是考虑每个必要的幂。
