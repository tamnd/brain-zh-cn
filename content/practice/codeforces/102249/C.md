 ## 解决方案
 ## 问题理解

 我们得到一个包含一个变量的有效布尔表达式，`x`，其否定`X`，常数`0`和`1`，以及二元运算符`&`,`|`， 和`^`。 括号确定表达式树。 

单个字符可以被另一个字符替换，但不能插入或删除字符。 在所有修改之后，结果必须仍然是有效的表达式。 目标是使整个表达式的值独立于`x`，使用尽可能少的修改。 

由于只有一个布尔变量，因此每个表达式都代表四种可能的布尔函数之一：`0`，这总是错误的。`1`，这始终是正确的。`x`，这是错误的`x = 0`和真实的`x = 1`。`X`，这对于`x = 0`和假的`x = 1`。 

这立即建议对表达式求值两次，一次使用`x = 0`和一次与`x = 1`。 如果两个结果相等，则表达式已经独立于`x`，所以答案为零。 

有趣的部分是证明，如果两个结果不同，一次修改总是足够的。 该观察消除了对大型动态程序或搜索可能的修改的需要。 

表达式的长度最多为 300，测试用例最多为 500 个。 每个测试用例的线性扫描很容易负担得起。 即使是二次算法通常对于这些界限来说也足够小，但问题的结构让我们做得更好。 更重要的是，对修改后的表达式进行指数搜索是完全不可能的。 表达式字母表包含 9 个可能的字符，因此枚举长度为 300 的所有字符串需要考虑最多 (9^{300})，大致为 (3.4 \times 10^{286}) 个候选字符。 

有几种边缘情况可能会欺骗过快跳转到二进制表达式观察的实现。 

对于单字符表达`x`，值随着变化`x`，所以答案是`1`。 假设每个表达式都有一个根运算符的粗心实现将会失败，因为没有可修改的运算符。 

对于单字符表达`X`，同样的推理也适用。 将其更改为`0`或者`1`只需要进行一次修改，所以答案是`1`。 

为了`0`，表达式已经是常数，所以答案是`0`。 盲目返回的实现`1`每当表达式有长度时，就会出错。 

为了`(x&X)`，表达式已经总是假的，因为`x`和`X`不可能两者都是真的。 它的两个评价都为零，所以答案是`0`。 

为了`(x^X)`，该表达式始终为真，因为恰好其中之一`x`和`X`是真的。 答案又是`0`。 

这些案例说明了为什么我们应该首先确定原始表达式是否已经独立于`x`，而不是立即假设需要进行修改。 

## 方法

 直接的暴力方法将尝试通过更改字符获得的每个可能的字符串，检查结果字符串是否是有效的表达式，评估它的两个值`x`，并保持最少的变动位置数。 这是正确的，因为每个允许的修改序列都对应于一个候选字符串，因此穷举搜索最终会考虑最佳答案。 

问题在于候选人的数量。 表达式字母表中有九个可用字符：`x`,`X`,`0`,`1`,`|`,`&`,`^`,`(`， 和`)`。 如果允许每个位置包含其中任何一个，则有 (9^n) 个长度为 (n) 的字符串。 在最大长度 (n=300) 下，大约是 (3.4 \times 10^{286}) 个字符串。 即使在恒定时间内检查一个候选者也是没有希望的，并且实际上验证和评估候选者的成本为 (O(n))，使得总工作量大致为 (O(n9^n))。 

蛮力之所以有效，是因为答案是由到有效常量表达式的最小汉明距离定义的，但它会失败，因为可能的字符串空间巨大。 关键的观察是我们实际上不需要构造修改后的表达式。 

假设原始表达式已经是常数。 那么答案显然是零。 

现在假设它的值取决于`x`。 只有两种结构可能性。 

如果表达式由单个术语组成，则它必须是`x`或者`X`， 因为`0`和`1`已经是常数。 将该字符更改为`0`或者`1`产生一个常量表达式。 因此，一次修改就足够了。 

如果表达式包含二元运算，请考虑其根。 根具有以下形式`(A op B)`， 在哪里`A`和`B`是有效的表达式。 每个子代代表前面列出的四个布尔函数之一。 

对于一个变量的任意两个布尔函数，至少其中之一`&`,`|`， 和`^`使它们的组合恒定。 我们可以从可能的形式直接看出这一点。 

如果任一操作数是常数`0`，选择`&`使得结果`0`。 

如果任一操作数是常数`1`，选择`|`使得结果`1`。 

如果两个操作数是相同的非常数函数，则选择`^`让他们取消。 例如，`x^x = 0`和`X^X = 0`。 

如果操作数是`x`和`X`，选择`&`给出`0`，在选择时`|`或者`^`给出`1`。 

因此，只要二进制表达式不是恒定的，仅更改其根运算符就足以使其恒定。 我们甚至不必找到应该使用哪个运算符，因为问题只要求最少的修改次数。 

因此，整个问题简化为一个问题：原始表达式是否计算出相同的布尔值`x = 0`和`x = 1`？ 如果是，请回答`0`。 否则请回答`1`。

 ## 算法演练

 1. 解析表达式并计算每个子表达式的两个可能值`x`。 将子表达式的结果表示为一对`(value_when_x_is_0, value_when_x_is_1)`。 例如，`x`是`(0, 1)`,`X`是`(1, 0)`,`0`是`(0, 0)`， 和`1`是`(1, 1)`。 
2.当解析器遇到二进制表达式时`(A op B)`，递归地得到两个结果对`A`和`B`。 对两个坐标独立应用相同的布尔运算符。 这是有效的，因为表达式是独立计算的`x = 0`和`x = 1`。 
3. 解析完整的表达式后，检查结果对。 如果两个坐标相等，则表达式对于两个可能的值具有相同的值`x`，所以它已经是常数，答案是`0`。 
4. 如果坐标不同，则表达式是非常数。 如果表达式是单个字符，则必须是`x`或者`X`，并将其更改为`0`或者`1`使其在一次编辑中保持不变。 
5. 如果表达式是二元表达式，则仅更改其根运算符。 对于两个子函数，至少其中之一`&`,`|`， 和`^`产生一个常数函数，因此一次编辑就足够了。 
6. 由于非常量表达式不能要求零次编辑并且一次编辑总是足够的，因此输出`1`在非常数的情况下。 

### 为什么它有效

 解析器计算每个子表达式所表示的精确布尔函数，并由其值进行编码`x = 0`和`x = 1`。 因此，当原始表达式独立时，根对完全相等`x`。 

如果该对相等，则零修改既足够又最佳。 如果不同，零次修改就无法起作用，因此至少需要进行一次修改。 单字符解决方案始终存在：对于叶子，替换`x`或者`X`有一个常数； 对于二元表达式，将根运算符替换为使两个子函数组合为常量的运算符。 因此，每个非常量表达式的最小答案恰好是一。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def evaluate(expr):
    n = len(expr)
    pos = 0

    def parse():
        nonlocal pos

        c = expr[pos]

        if c == '0':
            pos += 1
            return (0, 0)

        if c == '1':
            pos += 1
            return (1, 1)

        if c == 'x':
            pos += 1
            return (0, 1)

        if c == 'X':
            pos += 1
            return (1, 0)

        # c == '('
        pos += 1

        left = parse()
        op = expr[pos]
        pos += 1
        right = parse()

        pos += 1  # ')'

        a0, a1 = left
        b0, b1 = right

        if op == '&':
            return (a0 & b0, a1 & b1)

        if op == '|':
            return (a0 | b0, a1 | b1)

        return (a0 ^ b0, a1 ^ b1)

    return parse()

def solve():
    t = int(input())
    out = []

    for case in range(1, t + 1):
        expr = input().strip()
        v0, v1 = evaluate(expr)

        if v0 == v1:
            ans = 0
        else:
            ans = 1

        out.append(f"Case #{case}: {ans}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```这`evaluate`函数是一个递归下降解析器。 由于保证输入是有效的表达式，因此解析器永远不需要从格式错误的语法中恢复。 

对于终止字符，该函数将全局位置前进一位并返回其两个布尔值。 对表示使得`x`和`X`特别方便：`x`变成`(0, 1)`和`X`变成`(1, 0)`。 

当解析器看到`(`，它首先解析左边的表达式，然后精确读取一个运算符，然后解析右边的表达式，最后消耗闭运算`)`。 顺序很重要，因为表达式语法完全正确`(left operator right)`。 

这两个子项是逐个坐标组合的。 例如，如果左孩子是`(0, 1)`正确的孩子是`(1, 0)`，那么他们的`&`结果是`(0 & 1, 1 & 0) = (0, 0)`。 

假设修改后无需显式构造表达式。 上面的证明保证了非常量表达式总是可以通过一次编辑变为常量。 因此，代码只需要最后一对，不需要确定实际会更改哪个字符。 

最大嵌套深度受表达式长度限制，最多为 300，因此 Python 的递归限制已经足够了。 没有大整数计算，因此整数溢出是无关紧要的。

 ## 边缘情况

 第一个边缘情况是单个变量，`x`。 解析器返回`(0, 1)`，所以两个坐标不同。 由于表达式不包含二元运算符，因此无需修改根运算符。 改变`x`到`0`在一次编辑中给出一个常量表达式，因此算法返回`1`。 

第二个边缘情况是一个常数，`0`。 解析器返回`(0, 0)`。 两个坐标相等，因此表达式已经忽略`x`答案是`0`。 同样的推理也适用于`1`。 

第三个边缘情况是`(x&X)`。 解析器首先获取`(0, 1)`为了`x`和`(1, 0)`为了`X`。 正在申请`&`给出`(0, 0)`。 虽然两个叶子都依赖于`x`，它们的合取则不然。 算法返回`0`，正确避免不必要的修改。 

第四个边缘情况是`(x^X)`。 它的两个子对又是`(0, 1)`和`(1, 0)`，但异或产生`(1, 1)`。 因此整个表达式始终为真，答案为`0`。 这种情况很有用，因为诸如“两个包含变量的操作数意味着依赖于变量的结果”之类的简单化规则会失败。 

第五个边缘情况是大型嵌套表达式，例如用`&x`。 每个级别仍然评估为`x`，所以最后一对是`(0, 1)`。 该表达式的长度为 297，接近 300 个字符约束下的最大可能有效二进制表达式长度。 解析器处理每个级别一次，检测不同的最终值，然后返回`1`。 

最后的边缘情况是一个重复包裹的大表达式`|0`，从`1`。 每个级别都保留`1`，所以最后一对是`(1, 1)`无论其深度如何。 算法返回`0`。 这证实了答案取决于整个表达式的语义值，而不是其大小或它包含的可变字符的数量。
