 ## 解决方案
 ## 问题理解

 我们得到一棵有根树，它代表一组按层次结构连接的摊位。 我们“访问”这些摊位的方式是通过类似 DFS 的遍历来确定的，并且我们首次进入每个子树的顺序决定了我们如何将每个摊位分配给两个团队之一。 

关键规则是摊位的团队不是独立选择的。 相反，它取决于其首次访问位置在全局遍历顺序中的奇偶性。 当我们进入一个节点的子树时，我们以某种顺序遍历它的子树，每个子子树都会贡献一个已访问节点块，其大小会影响其后所有节点的奇偶校验移位。 

任务是计算在根固定为 Team Potato 的约束下，有多少子子树排序选择的有效全局分配导致整个树中团队分配的一致性。 

输入描述有根树，输出是安排遍历选择的有效方法的数量，以便所有诱导的团队分配都是一致的，模一个大素数。 

约束尺度（对于这种树 DP 问题来说是典型的）意味着需要线性或近线性行为。 任何尝试显式排列子项或模拟所有子树排序的内容都会因阶乘而爆炸。 即使是适度的分支也会导致指数爆炸，因为每个节点的子节点都可以通过多种方式重新排序，并且每种排序都会影响全局奇偶校验传播。 

当节点的子节点的子树大小都是偶数时，就会出现微妙的边缘情况。 在这种情况下，任何子子树的遍历都不会翻转奇偶校验，因此相对顺序不再改变未来的分配。 假设所有孩子行为对称的天真的方法会多算。 当存在多个奇数大小的子树时，会出现另一种边缘情况：交换它们会改变奇偶校验交替结构，但对于每个子树来说并不是独立的，从而导致如果独立处理子树，则很容易忽略组合约束。 

## 方法

 强力解决方案将尝试枚举每个节点处子节点的所有排列，模拟每个排列的完整 DFS 遍历，并计算诱导奇偶校验分配。 这在概念上是正确的，因为它直接对问题中描述的遍历过程进行建模。 然而，如果一个节点有 k 个子节点，那么就有 k 个！ 排序，并且在树上它会迅速倍增。 即使 k 约为 10，阶乘增长也会使这种情况变得不可行，并且当节点数达到 n 时，配置总数将变得非常大。 

关键的观察结果是，我们实际上并不关心所有子节点的确切顺序，只关心子树大小如何影响奇偶校验转换。 每个子树贡献一个块，其大小决定它是否翻转后续子树的奇偶校验。 这将问题从整个结构的排列减少为基于偶数和奇数子树大小的受控组合效应。 

我们定义一个 DP，其中对于每个节点 x，假设 x 被分配给固定团队，我们计算其子树的有效配置数量。 一旦处理完子树，每个子树 y 都会贡献两条信息：内部有效配置 DP[y] 的数量，以及其子树大小是偶数还是奇数，这决定了它在遍历时是否翻转奇偶校验。 

如果所有子子树大小都是偶数，则它们都不会影响奇偶校验传播。 这迫使所有子根一致地对齐，唯一的自由是每个子树的内部安排。 因此，结果是一个针对儿童的简单产品。

如果存在至少一个奇数大小的子树，则当我们按所选顺序遍历奇数子树时，奇偶校验会交替出现。 偶数大小的子树表现不同：它们不翻转奇偶校验，因此可以灵活插入，而不会影响奇数子树之间的交替结构。 组合结构简化为选择每个奇偶校验类中有多少个奇数子树，这会根据奇数子树在交替角色中的划分方式得出二项式系数。 

DP 变得线性，因为每个节点处理其子节点一次并在 O(deg(x)) 时间内组合结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（排列子项 + 模拟 DFS）| 最坏情况 O(n!) | O(n) | 太慢了|
 | 具有奇偶校验分组的树DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们以节点 1 为树的根，并在后序遍历中计算子树大小和 DP 值。 

1. 首先计算子树大小。 对于每个节点 x，我们将 sz[x] 累加为 1 加上所有子节点的大小。 这是必要的，因为奇偶校验行为完全取决于子树的大小是偶数还是奇数。 
2. 假设 x 本身被分配给 Team Potato，则将 DP[x] 定义为以 x 为根的子树的有效配置数。 这种标准化使我们能够避免在全球范围内跟踪绝对奇偶校验状态。 
3. 对于每个节点 x，我们首先处理所有子节点 y 并计算 DP[y] 和 sz[y]。 此时，每个子子树都被完全概括为两个值：其贡献计数和是否翻转奇偶校验。 
4. 将 x 的子级分成两组：sz[y] 为偶数的组和 sz[y] 为奇数的组。 令计数分别为 q 和 p。 
5. 如果 p 等于 0，意味着所有子树的大小都是偶数，则在遍历时没有子树会翻转奇偶校验。 在这种情况下，每个子根必须一致对齐，并且子树之间不存在组合交错效应。 我们将 DP[x] 计算为所有子 y 的 DP[y] 的乘积。 
6. 如果 p 大于零，则每当我们遍历奇数子树时，奇偶校验就会交替。 偶数子树可以在不影响这种交替模式的情况下放置，这意味着它们作为独立块以乘法方式贡献。 
7. 对于奇数大小的子树，它们的根组根据遍历顺序中的位置交替。 只有奇数子树分配到交替的奇偶校验角色才重要，而不是它们的内部顺序。 p 个奇数子树中奇偶角色的有效分配数为二项式系数 C(p, ⌊p/2⌋)。 
8. 将贡献合并为 DP[x] = C(p, ⌊p/2⌋) 乘以所有子项的 DP[y] 的乘积。 
9. 预先计算模 10^9+7 的阶乘和逆阶乘，以在常数时间内计算二项式系数。 

它之所以有效，是因为仅跟踪由子树大小引起的奇偶校验翻转。 每个子树要么贡献奇偶校验翻转（奇数大小），要么贡献无翻转（偶数大小）。 由于遍历顺序仅通过累积奇偶性变化而起作用，因此该结构分解为计算可以为奇数贡献者分配交替角色的方式有多少种，而偶数贡献者则保持中性乘数。 DP 是正确的，因为一旦其奇偶校验贡献固定，每个子树都是完全独立的，并且不相交子树之间的相互作用不会影响超出此奇偶校验状态的内部结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

# factorial precomputation up to n
def build_fact(n):
    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)

    for i in range(2, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact[n] = pow(fact[n], MOD - 2, MOD)
    for i in range(n - 1, -1, -1):
        invfact[i] = invfact[i + 1] * (i + 1) % MOD

    return fact, invfact

def C(n, r, fact, invfact):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

sys.setrecursionlimit(10**7)

n = int(input())
g = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

fact, invfact = build_fact(n)

sz = [0] * n
dp = [1] * n

def dfs(x, p):
    sz[x] = 1
    odd = 0
    even = 0

    for y in g[x]:
        if y == p:
            continue
        dfs(y, x)
        sz[x] += sz[y]

        if sz[y] % 2 == 0:
            even += 1
        else:
            odd += 1

    prod = 1
    for y in g[x]:
        if y == p:
            continue
        prod = prod * dp[y] % MOD

    if odd == 0:
        dp[x] = prod
    else:
        dp[x] = prod * C(odd, odd // 2, fact, invfact) % MOD

dfs(0, -1)

print(dp[0])
```DFS 在一次遍历中计算子树大小和 DP 值。 奇数子树和偶数子树的分离至关重要，因为只有奇数子树才会引入奇偶校验翻转。 产品积累确保独立的内部配置正确地相乘。 

二项式系数是使用阶乘预计算来计算的，避免了重复的对数模幂调用。 一个常见的错误是在没有缓存的情况下重新计算每个节点的组合，这会将复杂性推向 O(n log n)。 另一个微妙的问题是在 DFS 期间忘记分离父边，这会错误地增大子树的大小。 

## 工作示例

 ### 示例 1

 考虑一棵小树，其中根 1 有两个叶子子节点 2 和 3。 

| 节点| 深圳 | 奇怪的孩子| 甚至儿童| DP |
 | --- | --- | --- | --- | --- |
 | 2 | 1 | 0 | 0 | 1 |
 | 3 | 1 | 0 | 0 | 1 |
 | 1 | 3 | 2 | 0 | C(2,1)=2 | C(2,1)=2 |

 在叶子处，DP 一般为 1。在根处，两个子树的大小均为奇数，因此 p = 2。分配交替奇偶校验角色的方法数量为 C(2,1)=2，产生 DP[1]=2。 

这证实了当存在多个奇数子树时，答案反映了它们如何按遍历顺序交替。 

### 示例 2

 现在考虑一个根 1 和一个子节点 2，节点 2 有一个子节点 3。 

| 节点| 深圳 | 奇怪的孩子| 甚至儿童| DP |
 | --- | --- | --- | --- | --- |
 | 3 | 1 | 0 | 0 | 1 |
 | 2 | 2 | 0 | 1 | 1 |
 | 1 | 3 | 1 | 0 | 1 |

 节点 2 的子树大小为偶数，因此它不会向上奇偶翻转。 在节点 1 处，只有一个子节点的大小为奇数，因此 p = 1 且 C(1,0)=1，从而产生 DP[1]=1。 

这显示了大小均匀的子树如何抑制奇偶校验变化并消除组合分支。

 ## 边缘情况

 单节点树是最干净的边界情况。 DFS 分配 sz[1]=1 并且没有子节点，因此 odd=0 且 DP[1]=1。 该算法直接返回 1，匹配唯一可能的分配。 

链结构展示了组合选择的抑制。 除根节点外的每个节点都只有一个子节点，并且子树大小交替奇偶校验。 在每个步骤中，odd 要么为 0，要么为 1，因此二项式系数的计算结果为 1，从而生成整体上的单个有效配置。 

星形树是组合核心出现的地方。 如果所有子树都是叶子，则每个子树的大小都是 1，因此所有子树都是奇数。 在根处，p 等于孩子的数量，DP 变为 C(p, ⌊p/2⌋)。 该实现正确地将所有子项分组为相同的奇数贡献者，并计算交替奇偶分配，而不会过度计算内部结构的排列。
