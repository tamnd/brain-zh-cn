 ## 解决方案
 ## 问题理解

 我们得到了大小的排列$n$，这是一个包含每个整数的数组$1$到$n$按某种顺序恰好一次。 唯一允许的操作是获取任意连续的三个元素并删除其中最大或最小的元素。 我们的任务是，对于排列中的每个元素，确定数组在仍包含该元素的情况下可以具有的最小大小。 

输入代表多个测试用例，每个测试用例都有自己的排列。 每个测试用例的输出是一个长度的数组$n$，其中$i$-th 数字是包含以下内容的数组的最小可实现大小$p_i$。 

限制很小：$n$最多 100 个，最多 500 个测试用例。 这意味着我们可以提供以下解决方案$O(n^2)$每个测试用例的复杂性，无需担心超时。 然而，问题的结构表明我们可以通过仔细观察做得更好。 

边缘情况包括：$n < 3$，因为不可能删除。 例如，与$n=1$，数组不能减少，所以唯一元素的答案是$1$。 另一种微妙的情况是当一个元素位于数组的一端时。 由于该操作需要三个连续的元素，因此永远无法从其一侧删除边界处的元素，这会影响最小可实现的长度。 

## 方法

 暴力方法会尝试所有可能的删除序列，以查看包含每个元素的最小数组。 这可以通过递归或模拟来实现。 对于每个元素，您将尝试长度为 3 的所有子数组并删除最小值或最大值，重复直到无法再删除为止。 虽然这种方法是正确的，但在最坏的情况下，这种方法具有阶乘的可能性，即使对于$n=20$。 

关键的见解是要认识到，对于任何元素，删除只能删除包含它的最小子数组之外的元素，只要可以通过删除 min 或 max 来减少该子数组。 特定元素的最小可实现长度完全取决于其到阵列末端的距离。 具体来说，考虑位置上的元素$i$。 我们可以从左边删除元素，直到$i$靠近左端，从右端直到$i$接近右端，贪婪地使用操作。 结果是包含该元素的最小尺寸数组是到任一端的最大距离加一。 仔细检查发现，如果两边同时删除，还需要考虑左右删除的最少次数。 

因此，位置处元素的最小数组长度$i$是：$$\text{min\_length} = \min(i, n-i-1) + 1$$针对基于 0 或基于 1 的索引进行了适当调整。 这给出了一个简单的$O(n)$每个测试用例的解决方案。

 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，请阅读$n$和排列数组$p$。 
3. 对于每个元素$p_i$在索引处$i$（基于 0 的索引），将可达到的最小长度计算为左侧和右侧元素数量中较大的一个，再加一。 式中：$$\text{min\_length} = \max(i+1, n-i)$$这是有效的，因为您可以贪婪地删除包含以下内容的段之外的元素$p_i$，并且数组长度不能缩小到仍然包含到最远端的距离$p_i$。 
4. 收集测试用例的所有最小长度并打印它们。 

为什么它有效：如果我们适当地选择子数组，每个操作只能删除严格位于目标元素位置之外的元素。 最小长度受到数组距元素最远端的限制，因为删除可以删除三元组中的元素，但不能删除目标本身。 不变的是元素保留在数组中，从边贪婪删除将长度减少到到最远边的距离加一。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    res = []
    for i in range(n):
        # min length is max(distance from left, distance from right) + 1
        min_len = max(i + 1, n - i)
        res.append(str(min_len))
    print(" ".join(res))
```该解决方案读取测试用例的数量并迭代每个测试用例。 对于每个元素，它计算距数组两端的距离。 由于Python使用从0开始的索引，$i + 1$给出到左端的距离，并且$n - i$给出到右端的距离，包括元素本身。 取这两者中的最大值可确保我们计算最远的边，这是最小数组长度的限制因素。

 ## 边缘情况

 对于$n=1$， 输入`[1]`，算法计算`max(0+1,1-0) = 1`。 这会正确返回 1，与最小数组大小匹配，因为不可能进行删除。 

例如，对于末尾的元素`[2,1,3]`， 元素`2`在索引 0 处有`max(0+1, 3-0) = 3`，这反映出即使我们贪婪地从右侧删除，也无法删除第一个元素，直到右侧的所有元素都被处理为三元组。 这证实了边界元素已被处理
