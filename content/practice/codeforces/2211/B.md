 ## 解决方案
 ## 问题理解

 我们被要求使用仅由两种类型的元素构建的数组：`1`和`-1`。 每个测试用例指定我们有多少个测试用例，`x`那些和`y`减号。 该数组可以是这些元素的任意排列。 然后我们定义一个函数`f(a)`它计算将数组拆分为连续子数组的方法数，以使每个子数组具有相同的总和。 我们的目标是构建一个最小化的数组`f(a)`并计算最小值模`676767677`。 

问题很微妙，因为`1`沙`-1`s 直接影响存在多少个等和分区。 例如，相同数字的块通常会增加可能的分区数量，同时交替`1`和`-1`可以减少它。 模数仅在计算后才有意义`f(a)`; 我们不是最小化模数，而是真实的`f(a)`。 

给定约束条件下，每个测试用例的总数组长度可以达到`4 * 10^5`，但对所有测试用例求和，元素数量限制为`2 * 10^5`对于两者`x`和`y`。 这使得算法在每个测试用例中都是有效线性的。 任何显式尝试所有分区的方法都是指数级的并且完全不可行。 

当以下情况之一出现时，就会出现不明显的边缘情况：`x`或者`y`为零。 例如，如果`x=0`和`y=3`，数组是`[-1, -1, -1]`， 和`f(a)`计算将同构数组拆分为总和相等的子数组的方法。 假设数组总是混合的简单方法将会失败。 

## 方法

 蛮力方法将尝试生成所有排列`x`那些和`y`减 1，然后对于每个排列，尝试划分为子数组的所有方法，并仅计算所有子数组总和相等的子数组。 这在原则上是正确的，但完全不切实际。 甚至生成单个长度的数组`4*10^5`具有阶乘很多排列，并且分区计数是指数级的。 显然，暴力破解仅适用于长度为 1 或 2 的数组。 

关键的观察是最小`f(a)`当数组的排列使得不可能有具有相等总和的非平凡子数组分区时，就可以实现。 当数组交替时会发生这种情况`1`和`-1`尽可能均匀。 换句话说，为了最小化`f(a)`，我们应该交错`1`沙`-1`s 使得任何非平凡的前缀和都不同于其他子数组，只留下平凡的全数组分区。 这会产生`f(a) = 1`什么时候`x != y`和`f(a) = 2`当所有元素都相同时。 

如果所有数字都相等，则任何具有相同元素和的连续块的分割都是有效的，这会增加`f(a)`到`length of array`加一。 否则，交错会极大地限制可能的分区。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((x+y)!) | O(x+y) | 太慢了 |
 | 最优（建设性交替）| O(x+y) | O(x+y) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`x`和`y`。 
3.如果`x == 0`或者`y == 0`，所有数字都相同。 放`f(a) = x + y`如果您想要所有可能的分区，但最小保证是`2`对于长度 ≥1 的数组。 将数组构造为`x`后面跟着的`y`减号。 
4. 如果两者都`x`和`y`非零，通过交替排列数组`1`和`-1`尽量。 开始于`1`如果`x >= y`否则从`-1`。 
5. 使用剩余类型的剩余元素填充数组的剩余部分。 
6. 对于同时具有两者的数组`1`和`-1`,`f(a)`变成`1`因为不存在非平凡的等和子数组分割。 
7. 打印最小的`f(a)`模数`676767677`和构造的数组。 

为什么有效：通过交替`1`沙`-1`s，除了端点之外，任何前缀和在数组中都不会重复，从而防止多个等和子数组分区。 这迫使`f(a)`到其最小值，即`1`。 对于同构数组，唯一的方法就是减少`f(a)`是简单的分区：要么采用完整的数组，要么单独分割每个元素，给出`f(a) = 2`。

import sys
input = sys.stdin.readline

MOD = 676767677

def solve():
    t = int(input())
    for _ in range(t):
        x, y = map(int, input().split())
        if x == 0 or y == 0:
            # all identical numbers
            n = x + y
            print(2)
            if x:
                print("1 " * x)
            else:
                print("-1 " * y)
        else:
            # interleave 1s and -1s
            res = []
            ones, negs = x, y
            while ones and negs:
                if ones >= negs:
                    res.append(1)
                    ones -= 1
                else:
                    res.append(-1)
                    negs -= 1
                if ones and negs:
                    if res[-1] == 1:
                        res.append(-1)
                        negs -= 1
                    else:
                        res.append(1)
                        ones -= 1
            res.extend([1]*ones)
            res.extend([-1]*negs)
            print(1)
            print(" ".join(map(str, res)))

if __name__ == "__main__":
    solve()
```该解决方案读取每个测试用例并检查数组是否是同构的。 同质数组打印为`f(a)=2`以及所有相同的元素。 混合数组是通过交替构建的`1`沙`-1`s 防止多个子数组分裂，产生`f(a)=1`。 交替后扩展剩余元素可确保我们包含所有元素`x+y`元素。
