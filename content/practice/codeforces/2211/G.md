 ## 解决方案
 ## 问题理解

 给定一个整数数组，其中每个元素的范围为 0 到 10^6。 我们允许的操作是选择任意两个相邻元素，计算它们的平均值，然后将两个元素设置为该平均值。 问题是我们是否可以使用任意数量的这些操作将数组转换为非递减序列。 

关键的观察结果是，此操作不允许我们自由地重新排列数字。 每个操作都会混合两个相邻的数字，有效地使它们更接近。 如果一个数比它右边的邻居大得多，重复平均只能将其向较小的数减少，而从另一侧重复平均则将较大的数向较小的数减少。 因此，只有当最大的数字相对于较小的数字在序列中出现“太早”时，才能对数组进行排序。 

输入约束允许所有测试用例的总元素数最多为 10^6。 每个测试用例复杂度低于 O(n) 的任何解决方案都会太慢。 例如，平均运算的强力模拟可能需要 O(n^2) 或更糟的时间，这显然是不可行的。 需要注意的边缘情况包括所有元素都相等的序列、已经非递减的序列以及在开始或结束时具有大峰值的序列。 例如，`[10, 0, 0]`不能非减排序，但是`[0, 5, 0]`能。 

## 方法

 暴力方法将重复执行平均操作，直到不再发生任何变化或直到数组已排序。 每个操作的时间复杂度为 O(1)，但每对可能需要 O(n) 次操作才能收敛。 对于 n=10^5，这种方法在最坏的情况下可能需要 10^10 次操作，因此不切实际。 

最佳方法源于分析平均效果。 当我们选择相邻的一对时`(a_i, a_{i+1})`并将两者替换为`(a_i + a_{i+1}) / 2`，我们观察到该对的总和被保留，并且每个元素的值向另一个元素移动。 经过重复操作，任何连续的子数组都会收敛到其元素的平均值。 这意味着我们不能任意交换数字：如果一个大数字位于一个小得多的数字的左侧，则可能会阻止数组排序，因为它无法减少到低于其所属段的最小值。 

关键的见解是，为了使数组变得非递减，除了第一个元素之外的所有元素都可以受到到该点的前缀最大值的限制。 如果任何元素小于第一个元素并且不是最后一个元素，则可以执行逐渐向上移动以满足较大值的操作。 更正式地说，问题简化为检查第一个元素是否小于或等于数组中的最后一个元素。 如果是，则始终可以通过求平均操作使数组不减； 否则，它不能。

 | ---| ---| ---| ---|
 | 暴力模拟| O(n^2) | O(n^2) | O(n) | 太慢了|
 | 前缀/最后检查 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取元素数量`n`和数组`a`。 
2.比较第一个元素`a[0]`与最后一个元素`a[-1]`。 

如果`a[0] > a[-1]`， 输出`"No"`。 这是因为初始大元素无法减少到足以使数组不减的程度。 
3.否则，输出`"Yes"`。 平均操作可以在不违反边界的情况下逐渐将内部元素调整为非递减配置。 
4. 对所有测试用例重复此操作。 

为什么它有效：不变的是每个平均操作不会减少连续前缀的最小值，也不会增加连续后缀的最大值。 如果第一个元素已经大于最后一个元素，则没有任何平均操作序列可以使最后一个元素大于第一个元素，因此排序是不可能的。 相反，如果第一个元素小于或等于最后一个元素，操作可以将值向内“流动”，将每个段平均到单调序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    if a[0] > a[-1]:
        print("No")
    else:
        print("Yes")
```说明：我们首先读取测试用例的数量。 对于每个测试用例，我们读取数组并简单比较第一个和最后一个元素。 不需要模拟任何操作，因为首尾比较就足够了。 使用`sys.stdin.readline`确保解决方案有效地处理大量输入。

 ## 边缘情况

 一个单元素数组，例如`[0]`自动满足不减性质。 算法返回`"Yes"`因为`a[0] <= a[-1]`微不足道。 

对于两个元素相等的数组，例如`[5, 5]`，无需任何操作。 算法仍然正确输出`"Yes"`因为第一个元素不大于最后一个元素。 

对于严格降序排列的数组，例如`[5, 4, 3, 2, 1]`，第一个元素超过最后一个元素。 算法输出`"No"`，确认没有平均序列可以克服此初始配置。 

这篇社论表明，尽管出现了复杂的平均操作，但问题归结为数组的第一个和最后一个元素之间的简单比较。 洞察力来自于对操作的不变属性及其如何与单调性交互的理解。
