 ## 解决方案
 ## 问题理解

 大丽花站在一个固定点 ((x_0,y_0)) 上，可以选择向任何方向发射她的能力。 如果目标距离最远 (R)，则可以将其拉动，但有一个额外的限制：沿着所选方向，Dahlia 到达该射线上的第一个目标。 如果 Dahlia 和所选目标之间有另一个目标，则无法直接选择较远的目标。 

因此，任务不是计算半径 (R) 圆内的每个目标。 位于同一射线上的目标会相互竞争，并且只有该射线上最近的目标才能被拉动。 我们需要计算有多少条来自大丽花的不同光线在距离 (R) 内包含至少一个目标。 

最多可以有 (5\cdot10^5) 个目标。 坐标和 (R) 可以大到 (10^9)，因此比较每对目标的算法在最坏的情况下将执行大约 (2.5\cdot10^{11}) 比较。 这远远超出了 1.5 秒竞技编程限制所能支持的范围。 除了整数 gcd 计算的小对数成本之外，我们需要一种接近 (O(N\log N)) 或最好是 (O(N)) 的方法。 

坐标可以为负，因此方向必须保留其符号。 射线 ((1,2)) 和 ((-1,-2)) 的方向不同，尽管它们位于同一条无限直线上。 同时，((1,2))、((2,4)) 和((-1,-2)) 代表两条不同的射线，而不是三种。 

在精确距离 (R) 处还存在边界问题。 距离平方正好 (R^2) 的目标是可到达的，并且必须被计数。 例如，与```
0 0 5 1
3 4
```答案是`1`，因为距离正好是 (5)。 一个实现使用`< R * R`而不是`<= R * R`会错误地返回`0`。 

当多个目标位于同一射线上时，会出现第二种边缘情况。 例如，```
0 0 10 3
1 0
2 0
3 0
```有答案`1`， 不是`3`。 所有三个目标都在射程内，但向东射击总是命中`(1,0)`第一的。 计算圆圈内的每个目标而不合并方向是错误的。 

相反方向的情况也容易误处理。 为了```
0 0 10 2
3 0
-3 0
```答案是`2`。 两个目标位于相反的光线上，因此 Dahlia 可以选择其中之一。 通过最大公约数对方向进行归一化可以保留符号并使这两个方向保持不同。 

## 方法

 直接的方法是检查半径内的每个目标，并确定同一射线上是否有更近的目标。 对于每个目标，我们可以将其与其他每个目标进行比较，并检查来自 Dahlia 的两个向量是否彼此为正倍数以及另一个目标是否更接近。 这是正确的，因为当没有其他目标阻挡其射线时，目标可以准确选择。 

问题在于比较次数的二次方。 对于 (N=5\cdot10^5)，最坏的情况大约包含 (N(N-1)/2) 或大约 (1.25\cdot10^{11}) 个对。 即使是非常便宜的恒定时间测试也无法实现这一点。 

关键的观察是我们实际上不需要在每条射线上找到最近的目标。 假设一条射线包含一个目标，其与 Dahlia 的距离至多为 (R)。 那条射线上的所有目标中，距离最近的也最多是（R），而那个距离最近的目标正是大丽花能够拉动的目标。 相反，如果光线 (R) 内没有目标，则该光线上的任何物体都无法被拉动。 

所以答案就是距离最大为 (R) 的目标所代表的不同方向的数量。 

方向可以使用整数算术精确表示。 平移每个目标，使 Dahlia 成为原点，给出向量

 [
 (dx,dy)=(x_i-x_0,y_i-y_0)。 
]

 将两个分量除以

 [
 g=\gcd(|dx|,|dy|)。 
]

 得到的结果对

 [
 \left(\frac{dx}{g},\frac{dy}{g}\right)
 ]

 是该射线的唯一原始整数表示。 ((2,6))、((1,3)) 和 ((10,30)) 等点都变成 ((1,3))，而 ((-1,-3)) 仍然不同，因为它指向相反的方向。 

然后我们可以将每个标准化方向插入到一个集合中。 集合中的每一对不同的对都对应于一条可达射线。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(N^2)) | (O(1)) | (O(1)) | 太慢了 |
 | 最佳 | (O(N\log C)) | (O(N)) | 已接受 |

 这里 (C) 是坐标差的大小，最多 (2\cdot10^9)。 对数因子来自欧几里得 gcd 算法。 

## 算法演练

 1. 读取 Dahlia 的位置、最大距离 (R) 和目标数量。 计算 (R^2)，因为比较平方距离可以避免平方根并给出精确的整数比较。 
2. 对于每个目标，计算其相对向量
 [
 dx=x_i-x_0,\qquad dy=y_i-y_0。 
]
 这将问题从围绕任意点的几何形状转变为从原点开始的方向。 
3. 计算
 [
 d^2=dx^2+dy^2。 
]
 如果 (d^2>R^2)，则忽略此目标。 它无法被拉动，并且由于同一射线上的所有其他目标如果位于该目标后面，则距离会更远，因此该目标无法贡献可到达的射线。 
4. 对于通过距离检查的每个目标，计算
 [
 g=\gcd(|dx|,|dy|)
 ]
 并将向量替换为
 [
 (dx/g,dy/g)。 
]
 这会消除矢量的大小，同时保留其精确方向。 
5. 将标准化对插入集合中。 相等的归一化对意味着目标位于同一射线上。 不同的符号保持不同，因此相反的光线不会意外地合并。 
6. 处理完所有目标后，输出集合的大小。 每个存储的方向恰好对应于 Dahlia 可以选择拉动的一个目标，即该射线上最近的目标。 

### 为什么它有效

 考虑距离 (R) 内至少包含一个目标的任何射线。 在这些目标中，有一个最接近的。 由于它的距离最多为 (R)，Dahlia 可以选择该射线并立即拉动这个最近的目标。 因此，每条可达射线都会贡献一个答案。 

现在考虑距离 (R) 内不包含目标的射线。 该射线上的每个目标都离得太远，因此 Dahlia 无法从中拉出任何东西。 因此，没有其他光线对答案有贡献。

归一化向量唯一标识一条射线，因为当一个非零整数向量是另一个原始向量的正整数倍时，两个非零整数向量恰好沿着同一条射线指向。 除以 gcd 会产生原始向量，同时保留区分相反方向的符号。 因此，该集合恰好包含每条射线的一个条目，从该射线至少可以到达一个目标，这正是所需的答案。 

## Python 解决方案```python
import sys
from math import gcd

input = sys.stdin.readline

def solve():
    x0, y0, R, N = map(int, input().split())

    r2 = R * R
    directions = set()

    for _ in range(N):
        x, y = map(int, input().split())

        dx = x - x0
        dy = y - y0

        if dx * dx + dy * dy > r2:
            continue

        g = gcd(abs(dx), abs(dy))
        directions.add((dx // g, dy // g))

    print(len(directions))

if __name__ == "__main__":
    solve()
```第一部分读取固定位置并计算`r2`。 使用平方距离是因为取平方根会增加不必要的浮点工作，并可能引入精度问题。 

对于每一个目标，`dx`和`dy`是相对于大丽花测量的。 距离比较是在归一化之前进行的，因为圆外的目标根本不需要表示。 

致电给`gcd(abs(dx), abs(dy))`产生具有相同方向的最小整数向量。 绝对值传递给`gcd`，但除法时保留了原来的符号，所以`(1, 2)`和`(-1, -2)`保留不同的设置条目。 

不存在被零除的问题，因为该语句保证没有目标占据 Dahlia 的位置。 因此`(dx, dy)`从来没有`(0, 0)`，并且其 gcd 始终为正。 

Python 整数具有任意精度，因此诸如`dx * dx + dy * dy`即使平方坐标差可以达到 (4\cdot10^{18})，也是安全的。 

该集会自动删除所有重复的方向。 它的最终尺寸就是答案。 

## 工作示例

 对于样本 1，Dahlia 位于`(0, 0)`并且可以到达距离`10`。 每个目标都在圆圈内。 

| 目标| 相对向量| 平方距离 | 归一化方向 | 插入后设置|

## 边缘情况

 精确半径的情况通过比较来处理`dx * dx + dy * dy`和`R * R`使用`>`。 为了```
0 0 5 1
3 4
```距离的平方是`25`和`R * R`也是`25`。 条件`25 > 25`是假的，所以方向`(3,4)`被插入，答案是`1`。 一个实现使用`<`因为包含测试会错误地丢弃它。 

当多个目标共享一条射线时，标准化会将它们折叠为一组条目。 为了```
0 0 10 3
1 0
2 0
3 0
```三个向量归一化为`(1,0)`。 因此，该集合仅包含一个方向，给出输出`1`。 最近的目标`(1,0)`是大丽花真正拉的那一个。 

相反的方向保留不同的标志。 为了```
0 0 10 2
3 0
-3 0
```归一化向量是`(1,0)`和`(-1,0)`。 它们是两个独立的集合条目，所以答案是`2`。 使用绝对坐标标准化矢量的解决方案会错误地合并两条射线。 

圈外的目标在进入集合之前将被丢弃。 考虑```
0 0 5 2
1 0
10 0
```第一个目标的距离为平方`1`，而第二个有平方距离`100`。 仅有的`(1,0)`贡献，答案是`1`。 更远的目标无法变得相关，因为同一方向前面已经有一个可到达的目标。 

最后，具有比例坐标的目标必须使用 gcd 进行标准化，而不是通过将斜率与浮点进行比较。 在```
0 0 10 4
1 2
2 4
3 6
-1 -2
```前三个目标均标准化为`(1,2)`，而最后一个标准化为`(-1,-2)`。 该集合恰好有两个方向，因此输出为`2`。 这种整数表示避免了浮点精度问题和垂直线所需的特殊处理。
