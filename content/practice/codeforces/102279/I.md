 ## 解决方案
 ## 问题理解

 我们有`N`非空堆栈，其中堆栈`i`最初包含`Ai`牌。 两名玩家交替移动，洛伊首先移动。 移动恰好有两种形式之一。 玩家可以从单个非空牌堆中移除一张牌，或者，如果每个牌堆都非空，则同时从每个牌堆中移除一张牌。 谁取出最后一张牌，谁就获胜。 

目标不是模拟游戏。 我们需要确定初始位置是否为第一个玩家获胜，`lowie`，或者第一个玩家输了，这意味着`imitater`可以强行获胜。 

对于线性扫描来说约束足够小，但是对于游戏状态枚举来说太大了。 可以有 1000 叠，每叠可以包含 1000 张卡片。 状态由所有堆栈大小来描述，因此直接动态编程方法可能具有大量状态。 即使有记忆，可能的配置数量也与所有堆栈的可能值的乘积成正比，这对于 1000 个堆栈来说是天文数字。 预期的解决方案应该仅检查每个堆栈恒定的次数。 

关键量是卡片总数的奇偶性，以及当堆叠数为偶数时，最小堆叠的奇偶性。 最小筹码很重要，因为当最小筹码为正时，全筹码移动是合法的。 

有几种边缘情况很容易破坏仅基于卡总数的解决方案。 例如，与```
2
1 2
```总计是`3`，这很奇怪，洛伊赢了。 这是第一个样本。 只考虑堆栈数量是否为偶数的解决方案会忽略这一点。 

一个更微妙的情况是```
2
2 2
```总数是偶数，最小值也是偶数，所以正确答案是`imitater`。 如果洛伊从任一叠牌中取出一张牌，则总数变为奇数。 如果 Lowie 从两叠牌中取出一张牌，则位置变为`(1, 1)`，这为下一个玩家获胜。 只看总奇偶性会错误地对待所有偶数总头寸。 

另一个重要案例是```
2
1 3
```这里总共是`4`，但最小值是奇数。 Lowie 可以从两叠牌中取出一张牌并到达`(0, 2)`。 只剩下一堆，包含两张牌，所以模仿者输了，因为洛伊可以连续回合拿走这两张牌。 因此，尽管总数是偶数，但洛伊还是赢得了这个位置。 

## 方法

 直接的博弈论解决方案将递归地检查每一个合法的举动。 从一个位置`N`非空堆栈，最多可以有`N`单栈移动加上全栈移动。 递归是正确的，因为当一个位置至少有一次移动到失败位置时，该位置就获胜，而当每个合法移动都移动到获胜位置时，该位置就失败。 

问题在于状态空间的大小。 如果堆栈`i`可以包含任意值`0`通过`Ai`, 最多可以有

 [
 \prod_{i=1}^{N}(A_i+1)
 ]

 不同的配置。 有了最大值，就变成了`1001^1000`可能的状态。 即使每个状态仅通过记忆评估一次，检查最多`N+1`每个州的移动将给出`O(N * product(Ai + 1))`工作。 如果没有记忆，游戏树会更大。 

有用的观察结果是，每一步都会以非常可预测的量改变纸牌总数。 单次移动使总数减少`1`。 全栈移动将其减少`N`。 

什么时候`N`是奇数，两种可能的举动都会改变总数的奇偶性，因为两者`1`和`N`很奇怪。 由于终端状态总共有`0`，即偶数，能够从奇数总数变为偶数总数的玩家具有获胜平价。 因此，对于奇数`N`，当总数为奇数时，初始位置正好获胜。 

什么时候`N`是偶数，这两个动作表现不同。 单堆栈移动会更改总数的奇偶校验，而全堆栈移动会减去偶数并保留总奇偶校验。 这使得最小堆栈具有相关性，因为只有当最小值保持为正时，才可能重复使用全堆栈移动。 

对于甚至`N`，失败的位置正是那些总筹码为偶数且最小筹码为偶数的位置。 如果总数是奇数，洛伊总是可以移动到偶数总数失败的位置。 如果总数为偶数但最小值为奇数，Lowie 可以执行全栈移动，使最小值为偶数，同时保留总奇偶性。 如果总数和最小值都是奇数，洛伊就会从最小牌堆中取出一张牌，使两个数量都为偶数。 

因此，所得的特征很简单：如果总数为奇数，或者如果`N`是偶数，最小堆栈是奇数。 在所有其他情况下，模仿者都会获胜。 这一特征也可以直接证明，即从失败的位置开始的每一步都会导致获胜的位置，而每一个获胜的位置都有一个失败的位置。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |`O(N * product(Ai + 1))`具有记忆功能|`O(product(Ai + 1))`| 太慢了 |
 | 最佳 |`O(N)`|`O(1)`辅助| 已接受 |

 ## 算法演练

 1.读取所有堆栈大小并计算`sum`，卡片总数，以及`mn`，最小堆栈大小。 这些是最终决策所需的唯一属性。 
2.如果`sum`为奇数，输出`lowie`。 单堆栈移动总是会更改总奇偶校验，并且全堆栈移动也会在以下情况下更改它：`N`很奇怪。 更一般地说，当总数为奇数时，总有一个合法的举动达到了失败的偶数总数位置。 
3.如果`sum`是偶数且`N`为奇数，输出`imitater`。 每一次合法的移动都会将总数从偶数变为奇数，因此洛伊不能直接移动到另一个失败的偶数总数位置。 
4. 如果`N`是偶数且`sum`是否均匀，检查`mn`。 如果`mn`为奇数，输出`lowie`，因为 Lowie 可以从每一叠牌中取出一张牌。 总数保持不变，因为`N`是偶数，而最小值变为偶数。 
5.如果`N`是偶数，`sum`是偶数，并且`mn`为偶数，输出`imitater`。 每个单栈移动都会产生总赔率，而全栈移动则会产生最小赔率。 两个最终的位置都为下一个玩家获胜。 

### 为什么它有效

 考虑卡片总数为偶数的一组位置，并且`N`是奇数或最小堆栈是偶数。 我们声称这些正是亏损头寸。 

从这样的位置开始，单筹码移动使总数为奇数，因此最终的位置获胜。 如果`N`是奇数，全栈移动也使得总奇数。 如果`N`是偶数，全栈移动保留偶数总数，但将最小值减一，使其成为奇数，这为下一个玩家提供了获胜位置。 

现在考虑该集合之外的每个位置。 如果总数为奇数，Lowie 可以在以下情况下选择单栈走法：`N`是奇数，或者根据最小值选择适当的移动`N`是平的，达到了亏损的位置。 如果总数是偶数，`N`必须是偶数，最小值必须是奇数。 然后，全栈移动保留偶数总数并使最小值偶数，从而产生失败位置。 因此，每个获胜位置都会移动到失败位置，从而完成证明。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

total = sum(a)
mn = min(a)

if total % 2 == 1:
    print("lowie")
elif n % 2 == 1:
    print("imitater")
elif mn % 2 == 1:
    print("lowie")
else:
    print("imitater")
```输入仅包含一款游戏，因此不需要测试用例循环。 我们读取数组一次，然后计算其总数和最小值。 

第一个条件立即处理每个奇数位置。 这是在堆叠数之前特意检查的，因为无论是否，奇数总数都足以使该位置获胜。`N`是奇数还是偶数。 

已知总数为偶数后，筹码数为奇数则该位置输。 对于甚至`N`，答案取决于最小堆栈。 奇数最小值使 Lowie 的所有堆栈移动到失败位置，而偶数最小值意味着模仿者可以维持相应的失败结构。 

Python 整数具有任意精度，因此不存在溢出问题。 事实上，最大可能的总数仅为`1000 * 1000 = 1,000,000`，它也适合标准 32 位整数。 

## 工作示例

 ### 示例 1

 输入是：```
2

```重要的价值观是：

 |`N`|`sum`|`min`| 决定|
 | ---| ---| ---| ---|
 | 2 | 3 | 1 |`sum`是奇数 |
 | 2 | 3 | 1 |`lowie`|

 洛伊凭借奇偶特征立即获胜。 一个具体的获胜举措是从第二叠牌中取出一张牌，产生`(1, 1)`。 然后模仿者必须移动，洛伊可以拿走最终游戏中的最后两张牌。 更直接地说，奇数总数意味着洛伊可以在他的移动后强制达到最终的偶数状态。 

### 示例 2

 输入是：```
3
1 4 3
```这些值为：

 |`N`|`sum`|`min`| 决定|
 | ---| ---| ---| ---|
 | 3 | 8 | 1 |`sum`是偶数 |
 | 3 | 8 | 1 |`N`是奇数 |
 | 3 | 8 | 1 |`imitater`|

 由于共有三叠牌，因此每次合法移动都会删除奇数张牌：`1`卡或`3`牌。 从偶数总数开始，Lowie 必然给模仿者一个奇数总数的位置。 总数为奇数的玩家是有优势的玩家，因此模仿者获胜。

def solve():

    n = int(input())

        return "imitater"

    try:

    finally:

 ## 边缘情况

 ### 一堆

 对于```
1
2
```我们有`N = 1`,`sum = 2`， 和`min = 2`。 总数是偶数，因此算法达到`N`奇数分支和返回`imitater`。 对于一堆，两个合法的移动描述实际上是相同的操作，删除一张牌，因此偶数张牌确实丢失了。 

为了```
1
1
```总数是奇数，因此第一个分支返回`lowie`。 洛伊取出唯一的一张牌并立即获胜。 

### 偶数堆栈，总数为偶数，最小值为偶数

 对于```
2
2 2
```我们有`sum = 4`和`min = 2`。 总数是偶数，`N`是偶数，并且最小值是偶数，所以算法返回`imitater`。 

单堆栈移动会产生以下任一结果：`(1, 2)`或者`(2, 1)`，两者总和均为奇数。 全栈移动产生`(1, 1)`，其中最小值为奇数。 因此，每一个可能的举动都会给下一个玩家带来获胜的位置。 

### 偶数堆栈，总数为偶数，最小值为奇数

 对于```
2
1 3
```我们有`sum = 4`和`min = 1`。 算法返回`lowie`因为最小值是奇数。 

Lowie 使用全栈移动，产生`(0, 2)`。 全栈移动不再合法，因为其中一栈是空的，使得普通的一栈游戏只剩下两张牌。 模仿者必须移除一张牌，洛伊移除最后一张牌。 

这种情况说明了为什么仅使用总奇偶校验是不够的`N`是均匀的。 

### 堆栈数量为奇数，总数为偶数

 对于```
3
1 4 3
```总计是`8`，这是偶数，并且`N = 3`很奇怪。 算法返回`imitater`。 

每一步都会移除一张或三张牌，数量均为奇数。 因此，每一步都会翻转总数的平价。 由于起始总数是偶数，洛伊无法在最佳发挥下做出最后一步。 

### 最大输入

 对于 1000 叠卡片，每叠卡片包含 1000 张卡片，总数为`1,000,000`，它是偶数，最小值是`1000`，也甚至。 自从`N`也是均匀的，算法返回`imitater`。 

只需要对 1000 个值进行一次扫描。 游戏本身永远不需要模拟，这正是使该解决方案对于最大允许输入实用的原因。
