 ## 解决方案
 ## 问题理解

 我们得到一个二进制$n \times n$矩阵，我们的任务是构建$n$之间不同的非空整数集$1$和$n$。 每个条目$b_{i,j}$表示是否设置$A_i$是集合的真子集$A_j$; 值为$1$方法$A_i$严格包含在$A_j$， 和$0$意味着它不是。 我们的输出必须生成集合本身，列出它们的大小，后跟元素。 

该矩阵对真子集的有向非循环关系进行编码。 因为每个集合必须是非空的，并且集合受到正确子集关系的约束，所以我们本质上是从其关联矩阵重建一个偏序集合。 自从$n$至多是$100$，以及总和$n$所有测试用例的边界为$1000$，我们可以承受复杂度高达大约$O(n^3)$每个测试用例。 对所有可能子集的强力检查将呈指数级爆炸，因此需要组合或基于图形的构造。 

如果假设任何整数的任意分配都将满足子集关系，则可能会发生天真的失败。 例如，如果矩阵编码$A_1 \subsetneq A_2$和$A_2 \subsetneq A_3$，分配不相交的集合会产生矛盾。 如果一行没有传出，则会出现另一种边缘情况$1$s; 它对应于一个最大集合，该集合必须包含子集结构不禁止的所有元素。 如果我们处理不当，我们可能会意外地产生违反正确子集关系的集合。 

## 方法

 暴力方法将尝试迭代地将元素分配给集合并检查所有对的子集一致性。 这需要生成以下子集$\{1,\dots,n\}$，并且对于每个候选作业，验证所有$n^2$状况。 操作数呈指数增长$n$由于子集生成，使得它不可行$n=100$。 

关键的见解是将矩阵视为描述有向无环图，其中节点表示集合，边从子集指向其超集。 由于真子集关系是传递且反对称的，因此我们可以将矩阵视为 DAG。 按集合所属超集的数量（或等效地，按传出的数量）对集合进行排序$1$矩阵中的 s）给出了自然的层次结构。 较小的集合（更多的外向$1$s）将具有更少的元素和更大的集合（更少的传出$1$s) 将包括它们所包含的所有较小集合中的元素。 这将问题简化为沿着 DAG 的拓扑排序增量构造集合，从而保证满足所有子集约束。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力 | O(2^n * n^2) | O(2^n * n^2) | O(n^2) | O(n^2) | 太慢了|
 | 基于 DAG 的构建 | O(n^2) | O(n^2) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取矩阵并计算每行的出度，即该行中的个数。 该出度对应于当前集合必须是其真子集的集合的数量。 按出度从大到小对集合进行排序允许我们首先开始构造最小的集合。 

2. 初始化一个空集数组。 按出度递增顺序迭代集合。 为每个集合分配一个尚未分配给其任何子集的唯一整数。 这可确保保留正确的子集关系：任何应包含此关系的集合都将自动包含其子集中的所有元素。 

3. 维护迄今为止分配的元素的运行计数器。 每个新集合接收其已识别子集中的所有元素以及一个新的唯一元素。 新元素保证集合保持不同，继承的元素保证保留正确的子集关系。 

4. 通过打印其大小及其元素来输出每个集合。 由于我们以尊重层次结构的方式分配元素，所有$b_{i,j}$条件自动满足。 

不变的是构造集合后$A_i$，它包含每个集合的所有元素$A_k$为此$b_{k,i}=1$，加上一个新的独特元素。 这确保了$A_i$是其所有子集的超集，并且所有集合都保持不同。 通过按出度递减的顺序处理集合，我们保证集合所需的每个子集都已被分配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        b = [list(map(int, input().strip())) for _ in range(n)]
        outdeg = [sum(row) for row in b]
        order = sorted(range(n), key=lambda i: outdeg[i], reverse=True)
        sets = [set() for _ in range(n)]
        next_element = 1
        for idx in order:
            # inherit elements from subsets
            for j in range(n):
                if b[idx][j]:
                    sets[idx] |= sets[j]
            sets[idx].add(next_element)
            next_element += 1
        for s in sets:
            print(len(s), *s)

if __name__ == "__main__":
    solve()
```该代码读取测试用例的数量以及每个用例的矩阵。 它计算出度并对索引进行排序以首先处理最小的集合。 对于每个集合，它会合并其子集中的元素并附加一个新的唯一整数。 最后，它按原始顺序打印集合。 一个微妙的点是使用`set()`正确地进行联合操作以从子集中继承元素。 这`next_element`计数器保证所有集合保持不同且非空。

 ## 边缘情况

 对于单元素矩阵，算法正确地将唯一元素分配给唯一的集合。 对于最大链，集合累积所有先前元素加上新元素，保证正确的子集关系。 对于没有传出集合的断开集合，每个集合都会收到一个新的唯一元素，保持独特性和非空属性。 联合操作可确保继承的元素正确传播，从而防止违反子集约束。 所有边缘条件，包括最大、最小和稀疏子集结构，均由出度排序与增量元素分配相结合来处理。
