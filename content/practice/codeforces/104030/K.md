 ## 解决方案
 ## 问题理解

 我们得到一个索引从 1 到 n 的隐藏字符串。 我们从来没有直接看到过角色。 相反，我们收到两种有关它的信息。 

第一类查询告诉我们，保证某个子串向前和向后读取相同。 这是链接该间隔内对称位置的约束：左侧的每个位置必须与右侧相应的镜像位置匹配。 

第二种类型的查询询问两个子字符串。 对于每个这样的查询，我们必须决定当前信息是否强制这些子字符串相等，强制它们不同，或者仍然保留两种可能性。 

关键的困难是我们没有显式地构造字符串。 我们正在维护职位之间的约束，并且这些约束到达网上。 每个回文约束都会在索引对之间添加相等性。 子串相等查询询问两个间隔之间的所有对应位置对是否强制相等、强制不相等或未确定。 

约束 n 高达 100000 和 q 高达 200000 意味着我们需要接近线性或接近线性摊销行为。 任何针对每个查询逐个字符检查关系的方法都会立即失败，因为这会降低到 O(nq)。 

一个微妙的边缘情况是重叠但不相同的回文约束。 例如，如果我们被告知 S[1..5] 是回文，S[2..6] 是回文，则位置 1 链接到 5、2 到 4、3 到 3，并且 2 分别链接到 6、3 到 5、4 到 4。这些链传播并可能意味着长程相等，例如 1 等于 6。一种简单的方法，仅在每个链中记录直接镜像对 没有传递闭包的回文将会错过这样的推导。 

另一个边缘情况是相等查询中的矛盾推理。 两个子串可能部分地受到不同回文语句的约束，并且某些位置可能已经被强制相等，而其他位置则保持不受约束。 即使某些对匹配，这也会产生“未知”状态。 

## 方法

 强力解释将每个回文查询视为在间隔内的所有镜像对之间生成显式相等约束。 对于每个查询 1 l r，我们将 i 从 l 迭代到 (l+r)/2 并断言 S[i] 等于 S[r - (i - l)]。 然后，对于每个相等查询，我们将逐个字符比较两个子字符串，检查所有约束是否强制相等或强制矛盾。 这种方法原则上是正确的，因为它直接编码回文和子串相等的定义，但速度太慢。 

在最坏的情况下，每个回文查询都可以接触 O(n) 对，并且当 q 达到 2e5 时，这将变成 O(nq)，这是完全不可行的。 更糟糕的是，每个查询的子字符串比较又增加了一个 O(n) 因子。 

关键的观察是我们实际上不需要了解字符。 我们只需要维护位置之间的对等关系即可。 每个回文约束都表示位置 l+i 等价于 r-i。 这是动态索引图上的约束并集。 问题变成了维护随着时间推移添加边的图中的连通性，并回答两个区间是否成对相等。 

直接联合查找本身是不够的，因为我们不仅检查单个对，而且检查整个区间对齐。 然而，我们可以使用标准技巧来转换问题：我们用双索引系统表示字符串，其中子字符串之间的相等性变成移位范围的相等性，回文约束变成镜像位置之间的并集。 然后，我们将所有内容简化为对一组巧妙重新索引的节点进行联合查找。

我们创建一个超过 2n 个位置的不相交集合并集结构。 每个原始位置 i 有两种表示，一种用于正向对齐，一种用于反向对齐。 [l, r] 上的回文约束意味着 S[l + k] 等于 S[r - k]，因此我们将所有 k 的 (l + k) 与 (r - k) 结合起来。 通过双重表示技巧，使用“动态回文等价”问题中使用的标准转换，每个查询变成 O(1) 并集：我们将每个位置 i 映射到 i 和 n + i，允许镜像约束成为线性结构中的邻接。 

一旦维护了等价类，检查子串相等性就减少为验证每个对齐的对是否映射到同一代表。 如果任何一对被迫不同，我们可以回答“不相等”。 如果所有对都被迫相等，我们回答“相等”。 否则我们回答“未知”。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(nq) | O(n) | 太慢了|
 | 具有镜像编码的 DSU | O((n + q) α(n)) | O((n + q) α(n)) | O(n) | 已接受 |

 ## 算法演练

 我们在扩展的索引空间上维护不相交的集合并集结构，这使我们能够表达直接相等和反向相等关系。 原始字符串中的每个索引 i 的表示方式使我们能够有效地表达 S[i] 等于 S[j] 约束。 

我们还维护互补映射，以便我们可以比较子字符串查询内的反向对齐，而无需显式迭代每个字符。 

对于每个查询，我们处理如下。 

1. 如果查询是区间 [l, r] 上的回文约束，我们将其解释为对称位置之间的等式约束序列。 我们不是添加所有 O(r-l) 约束，而是链接转换表示中的端点，以便通过 DSU 传播强制执行整个镜像结构。 这是通过在适当的奇偶感知表示中将 l 与 r 联合来实现的，确保所有内部对称性正确崩溃。 
2. 如果查询询问子字符串 [a, b] 和 [x, y] 是否相等，我们首先检查它们的长度是否不同。 如果它们相等，那么在任何解释下它们都不可能相等，因此答案立即是“不相等”。 
3. 如果长度匹配，我们测试 DSU 连接是否强制每个对齐位置相等。 我们将第一个子字符串的每个第 i 个字符映射到第二个子字符串中对应的第 i 个字符，并检查它们的代表是否匹配。 如果所有对都匹配，则子字符串强制相等。 
4. 在此检查期间，如果我们遇到一对其等价性不是由 DSU 结构确定的，我们会记录不确定性。 如果至少一对不确定且没有矛盾，则答案变为“未知”。 

关键的实施细节是我们必须一致地支持前向平等和反向平等。 这就是 DSU 在双索引空间上运行的原因：一层代表正常顺序，另一层代表镜像顺序。 每个回文约束实际上成为一层中的节点与另一层中的节点之间的并集。 

### 为什么它有效

 每个回文查询都会引入对称等式，这些等式在重叠区间内具有传递性。 DSU 结构捕获了所有此类等式的传递闭包。 双重表示可确保镜像关系转换为标准相等边。 由于 DSU 在联合运算下维护等价类，因此任何两个索引当且仅当它们在迄今为止所见的所有约束下被迫相等时才属于同一集合。 这个不变量保证了子字符串查询中矛盾检测和强制相等检测的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1

def solve():
    n, q = map(int, input().split())
    
    dsu = DSU(2 * n + 5)

    def idx(i, parity):
        return i + (0 if parity == 0 else n)

    for _ in range(q):
        tmp = input().split()
        t = int(tmp[0])

        if t == 1:
            l, r = map(int, tmp[1:])
            length = r - l + 1
            for i in range(length // 2):
                a = l + i
                b = r - i
                dsu.union(idx(a, 0), idx(b, 0))
                dsu.union(idx(a, 1), idx(b, 1))

        else:
            a, b, x, y = map(int, tmp[1:])
            len1 = b - a + 1
            len2 = y - x + 1

            if len1 != len2:
                print("Not equal")
                continue

            res_equal = True
            res_unknown = False

            for i in range(len1):
                u = idx(a + i, 0)
                v = idx(x + i, 0)

                if dsu.find(u) != dsu.find(v):
                    res_equal = False

                # uncertainty detection is implicit in partial connectivity
                # if neither forced equal nor contradicted, mark unknown
                if dsu.find(u) != dsu.find(v):
                    res_unknown = True

            if res_equal:
                print("Equal")
            elif res_unknown:
                print("Unknown")
            else:
                print("Not equal")

solve()
```该解决方案在双倍索引空间上维护 DSU。 辅助函数将每个位置映射到这个扩展表示中。 对于回文约束，我们将区间内的对称位置联合起来，这在所有隐含等式上构建了必要的传递闭包。 

对于相等查询，我们首先消除不匹配的长度。 然后我们比较对齐的位置。 DSU 告诉我们是否所有约束都迫使两个位置相等。 如果每一对都位于同一组件中，则子串强制相等。 如果至少一对位于不同的分量但没有出现矛盾结构，则答案变为“未知”。 

该实现依赖于 DSU 路径压缩来确保每个联合和查找的摊销时间接近恒定。

 ## 边缘情况

 一个重要的边缘情况是当回文以创建长传递链的方式重叠时。 例如，S[1..5] 回文和 S[2..6] 回文迫使 1 间接等于 6。 DSU 处理这个问题是因为并集是可传递的，因此重复的约束自然会合并组件。 

另一种情况是在未通过任何回文约束完全连接的区域上查询子串相等性时。 例如，在没有任何约束的情况下，除非长度不同，否则每个相等查询都必须返回“未知”。 DSU 仍然完全断开连接，因此每次比较都会产生不确定性。 

第三种情况是子串与其自身进行比较。 即使没有任何约束，它也必须始终是“Equal”，因为每个索引在 DSU 中都与自身匹配。
