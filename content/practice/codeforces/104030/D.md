 ## 解决方案
 ## 问题理解

 我们给出一个以平面原点为圆心、半径为$r$。 与原点距离严格大于的每个点$r$被认为是圈外的。 在这个圆之外的所有整数坐标点中，我们需要找到一个到原点的欧几里德距离尽可能小的点。 

换句话说，我们正在搜索所有格点$(x, y) \in \mathbb{Z}^2$这样$x^2 + y^2 > r^2$，我们想要最小化$x^2 + y^2$。 

输入是单个整数半径$r$，可以大到$10^6$。 输出是严格位于圆外且最接近边界的任何整数对。 

该约束立即表明最佳点将非常接近圆边界。 对原点周围大边界框中的所有整数对进行简单扫描是不可能的，因为搜索空间呈二次方增长。 甚至检查坐标高达$r+1$大约会涉及到$O(r^2)$候选人，其顺序为$10^{12}$在最坏的情况下，远远超出可行的限度。 

在推理对称性时会出现一个微妙的问题。 最佳点不一定明显位于轴或对角线上。 例如，对于某些半径，最佳点位于圆边界的“角”附近，例如$(a, b)$其中两个坐标均非零并且严格平衡约束$a^2 + b^2 > r^2$。 天真的贪婪选择，例如挑选$(r+1, 0)$可能远非最佳，因为它的距离是$(r+1)^2$，虽然可能存在这样的点$(r, 1)$具有更小的平方距离。 

关键的难点在于，最佳整数点是由整数晶格如何与圆边界相交来确定的，而不是通过简单的轴对齐来确定。 

## 方法

 暴力策略将枚举所有整数对$(x, y)$在足够大的区域内，测试是否$x^2 + y^2 > r^2$，并跟踪最小值$x^2 + y^2$。 这是正确的，因为它直接评估所有候选人。 然而，搜索区域必须至少延伸至半径$r+1$，并且在二维中这大致导致$(2r+3)^2$点。 和$r \le 10^6$，这是完全不可行的。 

问题的结构允许更清晰的观察。 我们实际上并不是在 2D 区域中搜索所有点；而是在搜索 2D 区域中的所有点。 我们正在寻找严格大于的最小整数半径$r$。 也就是说，我们想要可以表示为的最小整数值$x^2 + y^2$并超过$r^2$。 

我们可以固定一个坐标并导出最佳可能的伴随坐标，而不是探索所有点。 如果我们选择$x$，那么最小的有效值$y$必须满足$y^2 > r^2 - x^2$。 这将问题简化为一维扫描$x$，并且对于每个$x$，我们可以计算最小可行$y$直接使用整数平方根。 

关键的见解是，最佳点将出现在边界附近，其中$x^2 + y^2$只是交叉$r^2$，这意味着我们只需要检查值$x$大约达到$r$，但实际上我们可以限制得更严格：一旦$x^2$超过$r^2$，最好的候选者就是$(x, 0)$。 转变发生在周围的狭窄区域$x \approx r$，所以扫描所有$x \in [0, r+1]$是足够的并且仍然是线性的$r$，太大了，所以我们进一步细化。 

更有效的视角是认识到最优答案必须位于“圆外的第一个格子层”，即上面的最小整数半径$r$。 该半径对应于最小值$x^2 + y^2$超过$r^2$，我们可以通过尝试沿一个轴和近对角点的候选边界交叉来构建它，但最简洁的解决方案是迭代$x$最多$r+1$并计算最小有效值$y$使用平方根。 这将复杂性降低到$O(r)$，但自从$r \le 10^6$，我们通过注意对称性并仅检查来进一步优化$\sqrt{r^2}$，即$O(r)$仍然太大，因此我们利用最佳点必须满足以下任一事实：$x \le r$或者$y \le r$，我们可以通过对称性和单调性将搜索限制在单一维度，仅有效测试$x \in [0, r]$但一旦最好的候选者无法进步，就尽早突破。 

在实践中，出现了标准简化：总是通过迭代找到最佳点$x$从 0 到$r+1$，计算最小有效值$y$，并跟踪最佳总和。 这在约束下就足够了，因为$r$仅取决于$10^6$，但每次迭代都是 O(1)，给出$10^6$运算，这在 Python 中是可以接受的简单算术运算。

 ## 算法演练

 我们将任务重新表述为找到圆外的最小整数点，然后系统地构造候选点。 

1. 我们从 0 开始迭代可能的整数 x 坐标。 原因是对称性：对于任何有效的解决方案，翻转坐标符号不会改变距离，因此在第一象限中搜索并在需要时进行反映就足够了。 
2. 对于每个固定的 x，我们计算最小整数 y，使得$x^2 + y^2 > r^2$。 这是通过重新排列不等式来完成的$y^2 > r^2 - x^2$，并采取$y = \lfloor \sqrt{r^2 - x^2} \rfloor + 1$当内部非负时，否则$y = 0$。 这确保我们以最小的增量跨越边界。 
3.我们计算候选平方距离$x^2 + y^2$并将其与迄今为止找到的最佳答案进行比较。 我们跟踪最佳距离和相应的坐标。 
4. 我们还考虑对称变体，其中 x 和 y 通过循环的对称性隐式交换，但由于我们已经枚举了所有 x，因此这就足够了。 
5. 扫描完成后，输出最小有效平方距离对应的坐标。 

正确性依赖于这样一个事实：对于每个最佳格点，固定其 x 坐标将重现由上述公式计算出的精确 y 坐标，确保其包含在搜索空间中。 

### 为什么它有效

 圆外的每个有效点都对应于某个整数 x，并且对于该 x，仍位于圆外的最小可能 y 是唯一确定的。 任何具有相同 x 但较大 y 的点严格来说更差，任何具有较小 y 的点都在圆内。 因此，搜索空间从二维折叠成每个 x 的单个确定性选择。 由于最佳点必须作为这些最小 y 候选者之一出现，因此扫描所有 x 可以保证我们最终评估最佳对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

import math

r = int(input())
r2 = r * r

best = None
best_val = None

for x in range(0, r + 2):
    x2 = x * x
    if x2 > r2:
        y = 0
    else:
        rem = r2 - x2
        y = int(math.isqrt(rem)) + 1

    val = x2 + y * y

    if best is None or val < best_val:
        best_val = val
        best = (x, y)

    if x > r and y == 0:
        break

x, y = best
print(x, y)
```代码直接实现了跨界的思想。 对于每个 x，它计算脱离圆的最小 y。 使用`math.isqrt`避免浮点精度问题并确保大值的正确性$10^{12}$。 

循环终止条件`if x > r and y == 0`是一个小的优化：一旦 x 已经在其自身轴上的圆之外，进一步增加 x 只会增加距离，因此不会出现更好的解决方案。

import sys, io
import math

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    r = int(input())
    r2 = r * r

    best = None
    best_val = None

    for x in range(0, r + 2):
        x2 = x * x
        if x2 > r2:
            y = 0
        else:

        val = x2 + y * y
        if best is None or val < best_val:
            best_val = val
            best = (x, y)

        if x > r and y == 0:
            break

    return f"{best[0]} {best[1]}"

 ## 边缘情况

 当出现一种边缘情况时$r$非常小，比如$r = 1$。 算法正确评估$x = 0$并立即发现$y = 2$，还检查$x = 1$，其中公式给出$y = 1$，产生更小的有效距离。 这证实了对角点可以主导轴对齐的候选点。 

另一个边缘情况是当$x^2 > r^2$。 例如，与$r = 4$和$x = 5$，代码集$y = 0$，产生一个恰好位于圆外 x 轴上的候选点。 这确保我们不会错误地计算负数的平方根。 

最后一个微妙的案例很大$r$， 例如$10^6$。 在这里，正确性取决于完全避免浮点运算。 使用`math.isqrt`保证精确的整数行为，确保计算跨越边界 y 值时不会出现精度漂移。
