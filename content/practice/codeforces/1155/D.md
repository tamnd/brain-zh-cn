 ## 解决方案
 ## 问题理解

 我们得到一个整数序列，并允许选择恰好一个连续的段并将其中的每个元素乘以一个固定值`x`。 执行此操作后，我们查看结果数组的所有连续子数组，并对这些子数组取最大可能的总和，其中我们还可以选择总和为零的空子数组。 

任务是选择修改的段，或者选择不执行任何操作，以使最佳子数组和尽可能大。 

约束条件`n ≤ 3 · 10^5`立即排除任何尝试所有可能的子数组进行乘法的解决方案。 重新计算每个选择的最大子数组和的三次甚至二次方法将涉及大约`10^10`最坏情况下的操作，远远超出了2秒允许的范围。 这迫使采用线性或近线性动态规划解决方案，其中每个位置都在恒定时间内处理。 

一个微妙的困难是修改后的最佳子数组可能不会以明显的方式与修改后的段对齐。 最佳子数组可以在相乘的段之前开始，在其之后结束，或者完全位于其内部。 诸如“选择最佳子数组，然后决定是否将其相乘”之类的天真的贪婪想法会失败，因为最佳子数组取决于乘法本身。 

另一个常见的失败案例是假设我们应该始终将一个段相乘，并对总和产生积极的影响。 如果`x`为负数或零，乘法可能会破坏之前的正贡献，因此决策必须是全局优化的，而不是局部选择的。 

## 方法

 蛮力的想法很简单：尝试每一个可能的部分`[l, r]`乘法、模拟数组并使用 Kadane 算法计算最大子数组和。 计算 Kadane 的一种配置成本`O(n)`，并且有`O(n^2)`选择`[l, r]`，导致`O(n^3)`总工作量。 即使使用预处理技巧，简单地枚举所有段也已经使其变得不可行。 

关键的观察结果是，问题的结构基本上仍然是一维和连续的。 在每个索引处，我们只需要知道当前是否在乘法段内未使用该操作，或者已经使用完毕。 这将问题转化为类似于 Kadane 算法的三态动态规划系统，但扩展了“一次性转换阶段”。 

我们不是首先考虑选择一个段，而是从左到右处理数组，并在以下三个条件下维护每个位置结束的最佳子数组和：尚未使用乘法、当前位于相乘段内以及已经完成乘法。 这完全避免了枚举段，因为每个可能的段恰好对应于进入和离开“活动乘法”状态的一次转换。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 太慢了 |
 | 最佳 DP（3 个状态）| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们在扫描数组时维护三个运行值。 

第一个表示当我们尚未使用乘法运算时以当前位置结束的最佳子数组和。 

第二个表示当我们位于相乘段内时以当前位置结束的最佳子数组和。 

第三个表示乘法段已经完成后在当前位置结束的最佳子数组和。 

我们还通过将零保留为基线候选来隐式允许空子数组。 

### 步骤

 1. 初始化第一个元素的三个状态。 “无操作”状态要么是全新开始，要么是单独使用该元素。 “内部操作”状态是元素乘以`x`。 “操作后”状态仅从元素本身开始。 
2. 对于每个下一个元素，通过扩展先前的无操作子数组或从当前元素开始刷新来更新“无操作”状态。 这反映了应用任何修改之前的标准 Kadane 逻辑。 
3. 通过三种可能的方式更新“内部操作”状态。 我们可以精确地从当前元素开始操作，从无操作子数组转换到当前元素，或者从先前的相乘段继续相乘。 每个选项对应于选择相乘线段的开始位置。 
4. 通过三种可能的方式更新“操作后”状态。 我们可以继续一个后操作子数组，提前一步结束乘法并现在正常扩展，或者在当前位置开始一个新的后操作子数组。 
5. 跟踪所有三个州和所有职位的最佳价值。 

### 为什么它有效

 在每个索引处，每个状态都表示在是否已使用乘法段的精确约束下以该索引结束的子数组的最佳可能总和。 单个连续相乘段的每个有效选择都恰好对应于一个转换序列：我们进入“内部操作”状态的点和我们离开它的稍后点。 由于考虑了所有此类转换，并且每个状态始终存储以当前索引结束的最佳子结构，因此不会丢失任何有效配置，也不会对无效配置进行计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, x = map(int, input().split())
    a = list(map(int, input().split()))

    NEG = -10**30

    dp0 = 0
    dp1 = NEG
    dp2 = NEG

    ans = 0

    for v in a:
        ndp0 = max(0, dp0 + v)

        ndp1 = max(v * x,
                   dp1 + v * x,
                   dp0 + v * x)

        ndp2 = max(v,
                   dp2 + v,
                   dp1 + v)

        dp0, dp1, dp2 = ndp0, ndp1, ndp2

        ans = max(ans, dp0, dp1, dp2)

    print(ans)

if __name__ == "__main__":
    solve()
```该实现将 DP 压缩为滚动变量而不是数组。`dp0`跟踪此处结束的最佳子数组总和，而不使用该操作。`dp1`轨道位于相乘的段内，并且`dp2`跟踪它的追随者。 转换直接编码我们是否开始、扩展或切换阶段。 变量`ans`确保我们在任何位置捕获最佳值，包括最佳子数组在数组结束之前结束的情况。 

使用大的负常数可以防止在状态尚未初始化时无效转换占主导地位。 零基线是必不可少的，因为空子数组是允许的，并且必须与负和竞争。

 ## 边缘情况

 一个关键的边缘情况是所有元素均为负数。 没有明确零基线的贪婪 Kadane 变体将错误地返回负数，而由于空子数组选项，正确答案为零。 DP 显式前移零，因此算法永远不会提交到有害的子数组。 

另一个微妙的情况是当`x`是负数，这可以使以前不好的部分变得有利。 三态动态规划自然地处理这个问题，因为在任何索引处总是允许进入乘法状态，因此算法可以发现天真的“仅正增益”启发式永远不会选择的最佳段。 

当最佳解决方案根本不使用乘法时，就会出现最终的边缘情况。 这是通过以下事实来处理的：`dp0`总是直接在全局最大值中竞争，确保算法可以在有害的操作时完全忽略它。
