 ## 解决方案
 ## 问题理解

 我们给出了长度的排列$n$，对于任何连续的子数组，我们查看它的最大元素。 对于固定排列，我们计算全局值$G(S)$，这是所有最大值的总和$n(n+1)/2$子数组。 

在所有排列中$1 \ldots n$，我们定义$K$作为该总和的最小可能值。 任务不仅仅是寻找$K$，但是要计算有多少排列具有更强的稳定性：如果我们通过取第一个元素并将其移动到末尾来重复旋转排列，则每次结果旋转仍必须达到该最小值$K$。 

输入由多个测试用例组成，每个测试用例给出一个值$n$。 对于每个$n$，我们必须输出有多少个排列满足这个旋转稳定性条件，模$998244353$。 

约束条件$n \le 10^5$直至$10^5$测试用例迫使任何解决方案本质上是$O(1)$或者$O(\log n)$每个查询。 任何涉及构造排列或直接评估子数组统计数据的事情都是不可能的，因为即使计算$G(S)$曾经是$O(n^2)$。 

一个微妙的问题是条件是循环的。 排列本身是最优的还不够。 每个循环移位也必须是最优的。 这同时在所有位置上创建了全局结构约束，而不仅仅是局部最优。 

一个常见的错误是假设所有最优排列都会自动满足旋转属性。 正如我们将看到的，最优性和旋转闭合是非常不同的条件。 

## 方法

 蛮力方法将枚举所有$n!$排列、计算$G(S)$对于每个使用天真的$O(n^2)$扫描子数组，然后检查所有旋转是否保留相同的值。 这已经超过了$O(n! \cdot n^2)$，这远远超出了任何可行的限制，即使对于$n = 8$。 

因此，我们需要了解什么结构可以最小化$G(S)$。 一个关键的观察结果是，每个元素对子数组的贡献最大。 对于排列，每个值都有一个连续的“影响范围”，由其左侧和右侧最近的较大元素确定。 较大的元素会产生较大的贡献，因此最小化总和需要对元素进行排列，以便较大的值不会产生不必要的宽主导区间。 

处理小案例揭示了一种严格的模式。 为了$n = 3$，最小值是通过四种排列实现的，但它们分为两个循环组。 至关重要的是，在每个循环轮换组中，某些轮换是最佳的，而另一些则不是。 这表明在旋转下不能保留最优性。 

决定性的观察是对于$n \ge 3$，每个循环旋转类的排列都必然包含最优和非最优配置。 发生这种情况是因为循环中某个位置的三个连续元素的任何排列最终都会旋转成引入“谷”结构的配置，从而增加对$G(S)$。 

为了$n = 1$，情况微不足道。 为了$n = 2$，两种排列都表现对称，并且两种旋转都保持最优性。 对于任何$n \ge 3$，没有任何排列可以在所有循环移位下保持最优性。 

这将整个问题分解为每个恒定的答案$n$。

 ## 算法演练

 ### 最优推理步骤

 1.首先确定小对象的行为$n$，因为循环约束通常只会超出阈值。 为了$n = 1$，只有一种排列，因此它简单地满足条件。 
2. 对于$n = 2$，两个排列都是彼此的旋转，直接计算表明它们产生相同的值$G(S)$。 由于每次旋转都保持最优，因此两种排列都满足条件。 
3.为了$n \ge 3$，分析当三个不同元素出现在不同循环位置时子阵列最大贡献的表现。 任何排列都将包含一些元素的三元组，这些元素的相对顺序在一定的旋转后形成局部“谷”。 
4. 该谷结构增加了总和中至少一个元素对子阵列最大值的贡献，破坏了最优性。 由于旋转会排列位置，因此每次排列最终都会在某种旋转下产生这样的配置。 
5. 因此没有长度排列$n \ge 3$可以让所有轮换达到全局最小值$K$。 

### 为什么它有效

 核心不变量是循环旋转不会同时保留所有三元组的相对位置。 虽然排列可以避免一个方向上的局部低效率，但旋转它会将这些低效率转移到其他地方。 为了$n \ge 3$，三个不同值的存在保证了一些旋转会创建一个配置，其中中间元素成为两个较大元素之间的局部最小值，这严格增加了其对子数组最大和的贡献。 这阻止了最优性的完全旋转闭合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        if n == 1:
            print(1)
        elif n == 2:
            print(2)
        else:
            print(0)

if __name__ == "__main__":
    solve()
```该解决方案完全依赖于有效排列的结构分类。 没有计算$G(S)$是需要的。 

唯一重要的实现细节是有效处理多个测试用例。 每个查询都会在恒定时间内得到回答，因此总复杂性仅取决于读取输入。 

## 工作示例

 ### 示例 1

 考虑$n = 2$。 

| 排列| 旋转 | 有效的？ |
 | --- | --- | --- |
 | [1,2]| [1,2], [2,1] | 是的 |
 | [2,1]| [2,1], [1,2] | 是的 |

 两种排列都满足每次旋转都达到相同的最小值$G(S)$。 

这表明对于$n=2$，旋转对称不会引入任何结构不平衡。 

### 示例 2

 考虑$n = 3$。 

| 排列| 旋转 | 在所有旋转中都是最佳的？ |
 | --- | --- | --- |
 | [1,2,3]| 123 → 231 → 312 | 没有 |
 | [1,3,2]| 132 → 321 → 213 | 没有 |
 | [2,1,3]| 213 → 132 → 321 | 没有 |
 | [2,3,1]| 231 → 312 → 123 | 没有 |
 | [3,1,2]| 312 → 123 → 231 | 没有 |
 | [3,2,1]| 321 → 213 → 132 | 没有 |

 即使几个排列单独达到了最小值$K$，每个循环轨道至少包含一个非最优排列。 

这证实了对于$n \ge 3$，没有排列满足旋转闭合要求。

 ## 边缘情况

 对于$n = 1$，唯一的排列没有在旋转下可以破坏的结构，因此它简单地满足条件。 

为了$n = 2$，这两个排列是彼此的旋转，并且都保留相同的子数组最大结构，因此都符合条件。 

为了$n \ge 3$，任何排列都不可避免地包含三个元素，其相对顺序在旋转下变得不稳定，产生至少一个增加的旋转$G(S)$。 这打破了每次旋转都必须保持最佳的要求，迫使所有较大的答案为零$n$。
