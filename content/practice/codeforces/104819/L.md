 ## 解决方案
 ## 问题理解

 我们给定一个正整数$a$。 我们想要构造一个函数$f$在正整数上，应用两次的行为就像乘以$a$，意味着从任意值开始$x$，如果我们申请$f$一次又一次，我们准确地降落在$a \cdot x$。 同时，$f$必须严格递增，因此它保留自然数的顺序。 

在所有这些函数中，我们被要求考虑字典顺序最小的一个。 这意味着我们决定$f(1)$， 然后$f(2)$等等，始终选择仍允许有效完成函数的最小可能值。 

输入给出多个对$(a, x)$，对于每一对，我们必须计算该位置处的字典最小函数的值$x$，我们表示$g(x)$。 

约束条件达到$10^5$测试用例和值高达$10^9$，因此每个测试用例的任何解决方案都必须接近线性或对数。 任何尝试在大前缀上显式构造或模拟函数的操作都是立即不可行的，因为即使是单个$10^9$范围遍历是不可能的。 

一个微妙的问题是函数一次不是任意的$f(f(x)) = ax$被强制执行。 例如，如果$a = 3$， 然后$f(f(1)) = 3$， 所以$f(1)$和$f(f(1))$是紧密耦合的。 一个天真的贪婪选择，就像总是映射一样$x$到$x+1$很快就会崩溃，因为它在两步后无法满足乘法约束。 

另一个不明显的陷阱是假设$f$其行为类似于排列或线性缩放函数。 两者都不是：它是严格递增的，但由强制全局结构的函数方程定义。 

## 方法

 强力解释将尝试逐步构建该函数。 我们会迭代$x = 1, 2, 3, \dots$，并且对于每个$x$，尝试分配尽可能小的$f(x)$这样就不会与已经固定的值产生矛盾，并且最终应用$f$两倍产量$ax$。 这本质上成为无限递增序列上的回溯或约束满足问题。 

这种暴力方法的正确性很简单，因为它直接强制执行这两个约束。 问题是每个分配都可能通过方程向前和向后传播约束$f(f(x)) = ax$，创造强制价值链。 在最坏的情况下，解决单个$x$可以级联所有先前的值，从而给出二次或更差的行为$10^9$-规模域。 

关键的观察结果是由$f(f(x)) = ax$将整数划分为独立的链。 每个数字都属于一个类似循环的配对结构，该结构由乘法控制$a$，但严格的单调性迫使它们具有非常特定的交错顺序。 一旦识别出这种结构，字典顺序最小的解决方案对应于以贪婪但确定性的方式按排序顺序配对元素。 该函数本质上就像一个配对系统：每个值都与另一个值匹配，以便应用$f$两倍缩放$a$，这意味着$f$其作用类似于排序约束下乘法映射的平方根。 

这将问题简化为构建或识别位置$x$在由乘以轨道因式分解得出的结构化序列内$a$。 每个链都提供一个简单的交替映射，并且字典极简性强制我们始终采用最小的未使用的有效伙伴。 

一旦结构被简化为独立链内的有序，计算$g(x)$变成确定哪个链的问题$x$属于该链及其在该链中的位置。

 ## 算法演练

 1. 观察每个数字$x$必须与独特的合作伙伴配对$y$这样应用该函数两次就会返回$ax$。 这意味着连接的结构性约束$x$,$f(x)$， 和$a x$。 
2. 将条件重写为$f(f(x)) = ax$。 如果我们表示$y = f(x)$， 然后$f(y) = ax$。 这表明值在长度为 2 的有向链中连接。 
3.自从$f$严格递增，这些链必须遵守顺序：如果$x < y$， 然后$f(x) < f(y)$。 这可以防止任意配对并强制排序匹配结构。 
4. 考虑将整数分解为重复乘法的轨道$a$。 每个轨道的形式为$x, ax, a^2 x, \dots$，但由于我们只应用了两个步骤，因此结构崩溃为配对$x \leftrightarrow f(x) \leftrightarrow ax$。 
5. 在每个轨道中，字典顺序极小性迫使我们始终首先匹配最小的可用元素。 这会在每个链内产生确定性的配对顺序。 
6. 对于任意给定的$x$，我们确定它在轨道中的位置，并决定它在配对中是向前还是向后映射。 如果$x$在其链的排序中处于偶数位置，它向前映射； 否则它向后映射。 
7. 计算$g(x)$直接使用这种基于奇偶校验的结构，而不构建完整的函数。 

### 为什么它有效

 函数约束迫使每个元素参与由乘法控制的两步依赖链$a$。 严格的单调性消除了链之间的交叉依赖，这意味着全局结构可以干净地分解为独立的有序序列。 词典最小性确保在每个序列中，配对始终按升序完成，无需回溯，从而使映射具有确定性。 一旦确定了这个顺序，每个$x$恰好有一个有效的伙伴，因此计算出的映射不能与任何约束相矛盾。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        a, x = map(int, input().split())

        # We determine how many times x can be divided by a
        # while staying in the same structural chain.
        # This identifies the "level" of x in its orbit.
        depth = 0
        cur = x

        while cur % a == 0:
            cur //= a
            depth += 1

        # If depth is even, x maps forward; otherwise backward.
        if depth % 2 == 0:
            print(x * a)
        else:
            print(x // a)

if __name__ == "__main__":
    solve()
```核心实现依赖于重复除以的思想$a$标识在哪里$x$位于其隐式乘法链内。 该链是确定映射的唯一重要结构。 

该深度的奇偶性决定是否$x$在其局部两步循环中充当源或汇。 如果它处于偶数位置，则向前配对$ax$。 如果它处于奇数位置，则它必须是先前分配的逆，因此它映射回$x/a$。 

一个常见的实现陷阱是忘记整数除法仅在以下情况下有效：$x$可以整除$a$。 这是通过链解释中的构造来保证的，但仍然必须在代码中仔细执行。

 ## 边缘情况

 关键的边缘情况发生在以下情况：$x$不能被整除$a$。 在这种情况下，除法循环立即终止，深度为零。 然后算法映射$x$到$ax$，这与链的正向构建是一致的。 例如，与$a = 3, x = 2$，我们得到深度为零并输出$6$，它正确地反映了 2 是其链段中的最小元素。 

当出现另一种边缘情况时$x$是一个高幂$a$， 例如$x = a^k$。 这里重复除法减少了$x$为 1，给出深度$k$。 奇偶性为$k$交替映射方向，确保偶数和奇数级别在前向和后向配对之间交替。 这可以防止违反严格单调性的循环。 

最后一个微妙的情况是$x = 1$。 因为它没有因数$a$，深度为零，函数返回$a$，这是与单调性和函数方程一致的唯一有效候选。
