 ## 解决方案
 ## 问题理解

 我们得到一组棍子长度，并询问是否可以精确地选取其中 k 个，以便它们可以用作简单多边形的边。 

我们需要关心的唯一几何要求是广义多边形不等式：当且仅当没有单个线段与其他线段相比太长时，一组 k 个线段可以形成非退化简单多边形。 具体来说，如果我们对所选长度进行排序，则条件是最大的所选长度必须严格小于剩余 k − 1 长度的总和。 

输入由 n 个候选棒组成，我们必须决定是否存在满足这个不等式的任何大小为 k 的子集。 我们不是在构建多边形，只是检查可行性。 

约束 n ≤ 3000 意味着二次或接近二次的方法是可接受的，但任何三次或涉及所有子集的枚举是完全不可行的。 关键的困难在于我们是在全局不平等约束下选择一个子集，而不仅仅是检查一个固定的集合。 

一种微妙的边缘情况是，许多棍子都是相同的，或者一根棍子与所有其他棍子相比非常大。 例如，如果 k = 3 并且数组为 [100, 1, 1]，则答案显然是否定的，因为 100 太大了。 仅检查总和而不仔细选择 k 个元素的简单方法很容易忽略子集的选择很重要。 

当 k 很大时，会出现另一种失败情况。 例如，如果大多数木棍都很小，但有一些木棍很大，则决策取决于平衡选择大元素（这会增加最大值）与小元素（这会增加其他元素的总和）。 贪婪的选择是需要的，但必须是有道理的。 

## 方法

 暴力方法会尝试大小为 k 的每个子集，计算其总和，识别其最大元素，并检查最大值的两倍是否小于总和。 这是正确的，因为对于任何候选子集，多边形条件都会减少到 2 * max < 子集之和。 然而，子集的数量是 C(n, k)，它是 n 的指数，即使对于中等的 k，这也是完全不可能的。 

条件的结构表明，只有最大的选定元素与总和之间的关系才重要。 如果我们对所有棒进行排序，则任何有效子集都可以被视为 k 个选定元素，其中最大元素是固定的，满足条件的最佳机会是最大化剩余 k − 1 个元素的总和。 这立即表明，如果我们确定一个候选最大值，我们应该始终将它与比它小的 k − 1 个最大的可能剩余木棒配对。 

这会导致对排序数组进行贪婪扫描：将每个元素视为潜在的最大值，并检查其之前的 k − 1 个最大元素是否足以满足不等式。 通过维护前缀和，我们可以在排序后在恒定时间内评估每个候选者。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力子集 | O(C(n, k) · k) | O(C(n, k) · k) | O(k) | 太慢了|
 | 排序+贪心前缀检查| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 ## 算法演练

1. 按非递减顺序对所有棒长度进行排序。 这使我们能够将任何位置视为潜在的最大值，同时确保其左侧的所有候选位置都较小或相等。 
2. 在排序列表上构建一个前缀和数组，以便我们可以在 O(1) 时间内计算任何段的和。 这是必要的，因为我们重复评估所选子集的总和。 
3. 对于从 k − 1 到 n − 1 的每个索引 i，将 a[i] 视为所选多边形边的最大元素。 
4. 考虑排序数组中紧邻 i 之前的 k − 1 个元素。 这些是与 a[i] 配对的最佳候选者，因为任何较小的选择只会减少总和并使不等式更难以满足。 
5. 使用前缀和数组计算这 k − 1 个元素的总和。 
6. 检查是否 2 * a[i] < sum_of_previous_k_minus_1 + a[i]。 这相当于检查 a[i] < sum_of_previous_k_minus_1 是否为多边形不等式。 
7. 如果有任何索引满足条件，则立即返回Yes。 如果没有索引有效，则返回 No。 

### 为什么它有效

 固定最大的选定元素就足够了，因为任何有效的 k 集都有唯一的最大元素。 对于固定的最大值，最大化满足多边形条件的机会的最佳策略是最大化剩余 k − 1 个元素的总和，这是通过按排序顺序选择其下方的 k − 1 个最大元素来实现的。 这将问题简化为检查每个候选最大值的单个不等式。 由于每个有效子集都对应于排序数组中的某个候选最大位置，因此不会错过任何有效解决方案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    a.sort()
    
    # prefix sums
    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + a[i]
    
    # try each possible maximum position
    for i in range(k - 1, n):
        # sum of k-1 elements before i
        left_sum = pref[i] - pref[i - (k - 1)]
        
        # check polygon condition:
        # largest side a[i] must be < sum of others
        if a[i] < left_sum:
            print("Yes")
            return
    
    print("No")

if __name__ == "__main__":
    solve()
```排序步骤确保我们只考虑按升序排列的最大边的有效候选者。 前缀数组允许我们在常数时间内计算 k − 1 个最佳同伴的总和。 关键的实现细节是窗口`[i - (k - 1), i)`这始终代表着支持球队的最佳选择。 

以最简单的形式检查不等式`a[i] < left_sum`，避免重新计算总和或显式推理整个多边形的需要。

 ## 边缘情况

 常见的边缘情况是最大元素与所有其他元素相比非常大。 用于输入`4 3: 100 1 1 1`，排序给出`[1, 1, 1, 100]`。 唯一的候选最大值是 100，低于它的最佳三元素和是 3。条件`100 < 3`立即失败，因此算法正确返回 No。 

另一种情况是所有元素都相等。 为了`5 4: 10 10 10 10 10`，每个候选最大值都有三个支持元素，总和为 30，所以`10 < 30`成立。 该算法找到有效的 i 并提前返回 Yes。 

一个微妙的情况是当 k 接近 n 时。 该算法仍然有效，因为窗口`[i-(k-1), i)`几乎成为整个前缀。 这确保了即使仅排除一两个元素，仍然可以根据最佳可能子集正确评估不等式。
