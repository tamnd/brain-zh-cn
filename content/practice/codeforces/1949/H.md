 ## 解决方案
 ## 问题理解

 该过程从单个单元格开始`(0, 0)`。 

每当我们分裂一个细胞时`(x, y)`，该细胞消失并产生`(x + 1, y)`和`(x, y + 1)`。 仅当两个孩子目前都不在场时，分割才合法。 

我们给出了一组有限的禁止坐标。 问题是我们是否可以执行一些分裂序列，以便最终的有机体不包含任何这些禁止的细胞。 

使这个问题具有欺骗性的第一个原因是同一坐标在此过程中可能会出现多次。 一个细胞可以被创建、分裂，然后从另一个父细胞重新创建，然后再次分裂。 样本本身就包含这样的情况`(1, 1)`。 

输入尺寸很大。 在所有测试用例中最多可以有`10^6`禁止细胞。 任何试图模拟有机体、搜索状态或探索无限网格的解决方案都是不可能的。 我们需要一些接近线性或`O(n log n)`禁止单元格的数量。 

一个常见的错误想法是独立对待每个禁止单元。 

考虑：```
4
0 0
1 0
0 1
1 1
```正确答案是`YES`。 

每个禁区都可以被分开，游戏之间的相互作用使这成为可能。 

另一个容易陷入的陷阱是假设每个有限的禁区都可以被包围。 

考虑：```
16
0 0
0 1
0 2
0 3
1 0
...
3 3
```正确答案是`NO`。 

尽管禁止集是有限的，但重复娱乐产生的组合压力会迫使一些禁止单元保留下来。 

关键的困难是了解必须重新创建禁区多少次。 

## 方法

 蛮力方法会尝试直接对有机体进行建模。 

状态是当前存在的单元的集合。 我们从每个州尝试每一个法律部门并寻找不受禁止的有机体。 

这在原则上是正确的，因为它完全遵循规则。 问题在于可达状态的数量呈爆炸性增长。 即使经过少量的分裂，也已经存在大量不同的生物体。 随着坐标达到`10^9`，任何状态空间搜索都是完全没有希望的。 

突破来自于忽略当前的生物体，而是计算每个禁止细胞必须被处理的次数。 

假设我们坚持认为禁止细胞永远不会在最终的有机体中存活。 

每次该细胞出现时，它最终都必须被分裂。 

让`cnt(x, y)`表示禁止单元格的次数`(x, y)`被迫分裂。 

一个单元只能由它的两个父单元创建：```
(x - 1, y)
(x, y - 1)
```所以每一次的出现`(x, y)`来自其中一位父母的部门。 

这立即给出了帕斯卡三角递推。 

如果`(x, y)`被禁止，那么每次出现都必须向前转发，所以：```
cnt(x, y)
=
cnt(x - 1, y)
+
cnt(x, y - 1)
```根`(0, 0)`贡献一个初始外观。 

现在是关键的观察。 

只要最多需要两次，就可以安全地消除禁止单元。 

一旦某些禁区被迫出现三次或以上，娱乐就无法再被吸收。 从那时起，该过程必然会永远传播，这意味着避免所有禁止单元变得不可能。 

因此，一旦超过二，我们就不需要精确的计数。 我们只关心是否达到三。 

这将整个问题简化为禁止单元上的路径计数 DP，所有值的上限为`3`。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了|
 | 最佳 |`O(n log n)`|`O(n)`| 已接受 |

 ## 算法演练

 1. 将所有禁止单元存储在哈希表中。 
2. 对禁止单元格进行递增排序`x + y`。 

这保证了当我们处理`(x, y)`，双方潜在父母均已处理完毕。 
3.让`dp[(x, y)]`是该禁区的强制出现次数，上限为`3`。 
4. 对于`(0, 0)`, 从值开始`1`因为生物体最初就含有该细胞。 
5. 对于每个禁止单元格`(x, y)`:

 计算```
dp(x, y)
=
base
+
dp(x - 1, y)
+
dp(x, y - 1)
```在哪里`base = 1`只为`(0, 0)`。 

失踪的父母贡献`0`。 
6. 计算出该值后，将其限制为`3`。 

我们从不需要更大的值，因为只有之间的区别```
0, 1, 2, >=3
```很重要。 
7. 如果任何禁止单元达到`3`， 输出`NO`。 
8.否则输出`YES`。 

### 为什么它有效`dp(x, y)`计算禁止单元格的次数`(x, y)`如果我们试图消除每个禁止单元，则将被迫重新创建。 

每一次娱乐活动都必须来自两个父母之一，因此计数遵循与帕斯卡三角形完全相同的递归方式。 

价值观`0`,`1`， 和`2`是可以管理的。 禁止单元格可以从左父级、下级父级或两者各重新创建一次。 

当强制计数达到`3`，所需的娱乐活动超出了该过程的吸收能力。 到那时，压力无限传播，使得不可能获得避开所有禁入细胞的最终有机体。 

因此，当且仅当每个禁止单元最多有强制计数时，禁止集是可以避免的`2`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    ans = []

    for _ in range(t):
        n = int(input())

        cells = []
        forbidden = set()

        for _ in range(n):
            x, y = map(int, input().split())
            cells.append((x, y))
            forbidden.add((x, y))

        cells.sort(key=lambda p: (p[0] + p[1], p[0]))

        dp = {}
        ok = True

        for x, y in cells:
            cur = 1 if (x, y) == (0, 0) else 0

            cur += dp.get((x - 1, y), 0)
            cur += dp.get((x, y - 1), 0)

            if cur > 3:
                cur = 3

            dp[(x, y)] = cur

            if cur >= 3:
                ok = False
                break

        ans.append("YES" if ok else "NO")

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```该实现仅存储禁止单元的 DP 值。 任何未被禁止的父单元贡献为零，因为只有被禁止的单元才被迫转发娱乐。 

排序依据`x + y`就足够了，因为父母双方总是位于前一个对角线上。 二级排序依据`x`仅用于使排序具有确定性。 

该值的上限为`3`立即地。 这避免了大整数并保持 DP 纯逻辑。 该算法只需要知道计数是否为`0`,`1`,`2`，或者至少`3`。 

当细胞到达的那一刻`3`，答案已经确定。 我们可以提前停止处理该测试用例。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |`O(n log n)`| 禁止细胞分选占主导地位
 | 空间|`O(n)`| DP 值的哈希表 |

 所有测试用例中禁止单元的总数最多为`10^6`， 所以`O(n log n)`很容易符合限制。 内存使用量与禁止单元的数量成线性关系。
