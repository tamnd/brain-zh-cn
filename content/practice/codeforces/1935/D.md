 ## 解决方案
 ## 问题理解

 我们给出了一组固定的禁止整数和两个变量的大范围可能值$x$和$y$， 在哪里$0 \le x \le y \le c$。 对于每个候选对$(x, y)$，我们对导出值施加两个独立的约束：总和$x + y$一定不属于禁止集，并且区别$y - x$也必须不属于禁止集。 任务是计算有多少对满足这两个限制。 

思考这个问题的一种有用方法是，每一对都会产生两个辅助值，一个以和的形式测量距零的“距离”，另一个以差的形式测量“差距”。 禁止集同时去除和空间中的某些对角线和差空间中的某些对角线。 

输入大小迫使人们小心。 总和$n$跨测试用例最多$3 \cdot 10^5$， 尽管$c$可以大到$10^9$。 这立即排除了对所有对的迭代$(x, y)$，因为即使是一个测试用例$c = 10^9$会暗示关于$10^{18}$候选人。 

约束的结构表明我们应该避免使用单独的对，而是沿着派生坐标推理间隔和禁止的“事件”。 

当许多禁止值位于边界附近时，就会出现一个微妙的问题。 例如，如果集合包含来自的所有整数$0$到$c$，则禁止所有可能的和或差，因此即使对的几何空间很大，答案也为零。 相反，如果集合为空，则所有对都有效，答案变为所有三角形对的计数，即$\frac{(c+1)(c+2)}{2}$。 任何正确的解决方案都必须自然地处理两个极端，而无需特殊的外壳。 

另一个重要的边缘行为是由重叠约束引起的：一对可能同时违反这两个条件，并且对级别的朴素包含-排除太慢，除非我们重构问题。 

## 方法

 直接方法枚举每一对$(x, y)$和$0 \le x \le y \le c$，检查是否$x+y$是否在集合中并且是否$y-x$位于集合中，如果两项检查都通过，则增加计数器。 这是正确的，因为它严格按照规定强制执行约束。 然而，对的数量约为$\frac{c^2}{2}$，当$c$达到$10^9$。 即使我们在概念上限制自己$n$，检查哈希集中的成员资格是$O(1)$，但枚举本身完全占主导地位。 

关键的观察是约束不是任意函数$x$和$y$，但仅取决于两个线性形式：$x+y$和$y-x$。 这表明切换坐标。 让$$u = x+y, \quad v = y-x.$$这些变换是可逆的$$x = \frac{u-v}{2}, \quad y = \frac{u+v}{2}.$$条件$0 \le x \le y \le c$成为线性约束$u$和$v$。 尤其，$v \ge 0$,$u \ge v$，以及两者$u$和$v$必须具有相同的奇偶性。 

现在问题变成：计算有效整数点$(u, v)$在旋转晶格区域中，排除任一坐标位于禁止集中的区域。 该结构以一种有用的方式可分离：禁止值独立作用于$u$和$v$，因此我们可以考虑减去每个禁止值引起的无效贡献。 

预期解决方案中使用的关键简化是修复每个禁止值删除结构化对集合的方式。 一个值$s$集合中排除所有对，其中$x+y = s$或者$y-x = s$。 每个这样的条件对应于一条对角线$(x,y)$网格。 我们不是迭代对，而是计算每个对角线上有多少个有效对并将它们相减，同时小心地避免重叠的双重减法。 

这导致了分解：从对的总数开始，然后减去每个禁止对角线引起的贡献，最后纠正两个约束将删除同一对的重叠。 

因为每条对角线以简单的算术级数与三角形区域相交，所以我们可以计算其贡献$O(1)$每个禁止值，导致$O(n)$每个测试用例解决方案。

 ## 算法演练

 1. 无限制地计算有效对的总数。 这是对的数量$(x, y)$和$0 \le x \le y \le c$，等于$\frac{(c+1)(c+2)}{2}$。 这构成了我们减去无效配置的基础。 
2. 将禁止集分为两个概念角色：充当禁止和的值和充当禁止差的值。 实际上，这两个角色都来自同一组，但对称地对待它们可以实现独立计数。 
3. 对于每个禁止值$s$，计算有多少对满足$x+y = s$在有效区域内。 这对应于计算整数解$x \le y$,$x+y=s$，以及范围内$[0,c]$。 有效范围为$x$来自$\max(0, s-c)$到$\lfloor s/2 \rfloor$，它给出了直接计数。 
4.对于同样的$s$，计算有多少对满足$y-x = s$。 这里我们重写为$y = x+s$，所以有效$x$范围从$0$到$c-s$。 每一个这样的$x$准确定义一个有效的$y$，所以这有助于线性计数。 
5. 从总数中减去两项捐款。 然而，满足两者的对$x+y = s$和$y-x = t$对于一些禁止的$s,t$可能被减去两次，所以我们必须考虑交叉点。 
6. 交集条件隐含唯一解：$$x = \frac{s-t}{2}, \quad y = \frac{s+t}{2}$$我们检查这个解是否有效并且在范围内； 如果是这样，我们将其添加回来一次。 
7. 使用哈希集来聚合该集合中的所有贡献以进行成员资格检查，以便可以在恒定时间内测试交集。 

### 为什么它有效

 每个禁止值都精确地消除了有效整数格中位于一条仿射线上的对。$(x,y)$。 该算法将全局计数问题转换为对这些线上的贡献进行求和。 每对仅受与其和和差相对应的禁止约束的影响，因此其包含或排除完全由变换空间中的局部条件决定。 校正步骤确保受两个约束影响的对不会被过度减去。 这保证了对有限的不相交几何结构族的精确包含-排除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, c = map(int, input().split())
        s = list(map(int, input().split()))
        bad = set(s)

        # total pairs 0 <= x <= y <= c
        total = (c + 1) * (c + 2) // 2

        ans = total

        for v in s:
            # remove pairs with x + y = v
            # x ranges so that 0 <= x <= y <= c
            # y = v - x, x <= v - x => x <= v/2
            # also y <= c => v - x <= c => x >= v - c
            l = max(0, v - c)
            r = v // 2
            if r >= l:
                ans -= (r - l + 1)

            # remove pairs with y - x = v
            # y = x + v <= c => x <= c - v
            if v <= c:
                ans -= (c - v + 1)

        # add back double-counted intersections
        for v in s:
            for u in s:
                diff = v - u
                if diff % 2 != 0:
                    continue
                x = diff // 2
                y = (v + u) // 2
                if 0 <= x <= y <= c:
                    ans += 1

        print(ans)

if __name__ == "__main__":
    solve()
```该代码首先计算无约束的对的完整三角形计数。 然后减去位于禁止和对角线上和禁止差对角线上的所有对。 通过将几何条件转换为有界整数范围，在恒定时间内计算每次减法。 

最后的嵌套循环恢复了过度计数的对，其中单个配置被删除了两次。 奇偶校验确保重构$(x, y)$是积分，因为从$(s, u)$回到$(x, y)$需要偶数。 

一个微妙的实现细节是总和约束中边界的处理。 有效区间为$x$同时取决于$y \ge x$和$y \le c$，产生一个下界$v-c$。 缺少该术语会导致计算过多$v$接近于$c$。

 ## 边缘情况

 完全禁止的集合，例如$s = \{0,1,\dots,c\}$强制所有可能的和与差都无效。 该算法减去所有对角线贡献，并且通过求和或求差规则将每一对恰好删除一次。 由于所有有效对都存在交集，因此校正阶段会准确恢复双减的那些，从而根据需要得到零。 

当集合为空时，不会发生减法，并且基本三角形计数保持不变。 该集合上的循环没有任何贡献，因此算法正确返回$\frac{(c+1)(c+2)}{2}$。 

什么时候$s$仅包含附近的大值$c$，由于下界，总和约束可能几乎没有有效的解决方案$v-c$。 该实现明确限制了这个界限，确保可行三角形之外的对角线贡献零而不是负计数。 

当相交步骤中出现奇偶校验不匹配时，算法会跳过它们。 这可以防止分数坐标的无效重建，否则会引入虚假计数。
