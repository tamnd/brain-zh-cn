 ## 解决方案
 ## 问题理解

 我们有多个登录密码，每个团队一个，每个密码只是由数字、大小写字母、下划线和连字符等可打印字符组成的字符串。 系统认为四个字符在登录过程中对人类来说太容易混淆：数字`1`, 小写`i`, 大写`I`，和小写`l`。 对于每个密码，我们必须通过删除这四个字符的每次出现来生成一个干净的版本，并保留所有其他字符的原始顺序。 

输入大小约束是这里的关键结构细节。 所有字符串总共最多有 50,000 个字符，因此任何处理每个字符恒定次数的解决方案都可以。 然而，任何低效地重复重建字符串的行为（例如在没有缓冲的情况下在循环内重复串联），都会因字符串的不可变性而在 Python 中面临二次行为的风险。 

边缘情况很简单，但仍然值得明确说明。 

密码可能完全由可移动字符组成。 例如，输入`1iIl`应该产生一个空行作为输出。 这里的一个天真的错误是根本忘记打印空行，这会改变输出对齐方式。 

另一种边缘情况是没有删除任何字符，例如`abcXYZ_9-`。 输出必须完全匹配。 

第三种微妙的情况是大型输入，其中散布着删除的字符，例如`1a1b1c1d1e`，我们必须只保留字母。 

## 方法

 暴力破解的想法很简单：对于每个字符串，逐个字符扫描并通过仅附加允许的字符来构建新字符串。 如果正确实现每个字符串一个列表缓冲区，这已经是最佳的。 唯一的危险是重复进行字符串连接，例如`res += c`，这使得每个附加 O(当前结果的长度)，在最坏的情况下导致每个字符串的二次时间。 总长度为 5 × 10^4 时，仍然可以通过，但只是勉强通过，并且没有必要在更严格的限制下冒 Python 性能问题的风险。 

关键的观察结果是该操作纯粹是对字符的过滤，位置之间没有依赖性。 每个字符都是独立保留或丢弃的。 这意味着我们可以处理流一次，将结果累积在列表中，并为每个字符串连接一次。 

因此，最佳解决方案只是线性扫描，并针对小型禁止集进行恒定时间成员资格检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解（字符串连接）| 每个字符串的最坏情况为 O(n²) | O(n) | 风险/边缘 |
 | 最优（列表过滤）| 总共 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取密码数量并独立处理每个字符串。 每个字符串都可以单独处理，因为测试用例之间没有交互。 
2. 定义禁止集`{ '1', 'i', 'I', 'l' }`。 我们使用集合是因为​​成员资格检查的平均时间为 O(1)。 
3. 对于每个字符串，创建一个空列表来收集应保留的字符。 我们避免直接构建字符串以防止重复的重新分配成本。 
4. 迭代字符串的每个字符。 对于每个字符，检查它是否属于禁止集。 如果没有，请将其添加到列表中。 
5. 处理整个字符串后，将列表连接成单个字符串并输出。 如果列表为空，连接自然会产生一个空字符串，因此我们仍然打印换行符。 

### 为什么它有效

 字符串中的每个位置只处理一次，并且该位置的决策仅取决于该字符是否在禁止集中。 不存在依赖于邻近角色或未来上下文的转换。 这使得该算法相当于在序列上应用投影函数，其中输出序列保留顺序但独立过滤元素。 因为每个字符都只被考虑一次，并且要么立即保留，要么立即丢弃，所以最终构造的字符串正是原始字符串减去所有禁止的符号。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input().strip())
    banned = {'1', 'i', 'I', 'l'}

    out_lines = []

    for _ in range(n):
        s = input().strip()
        buf = []

        for ch in s:
            if ch not in banned:
                buf.append(ch)

        out_lines.append(''.join(buf))

    sys.stdout.write('\n'.join(out_lines))

if __name__ == "__main__":
    main()
```该解决方案逐行读取输入并独立处理每个密码。 这`banned`set 预先计算一次，因此成员资格检查保持恒定时间。 每个字符都附加到一个列表中，而不是直接连接字符串，这避免了中间字符串的重复复制。 

最终输出是使用单个组件组装的`join`在所有已处理的生产线上，即使存在许多测试用例，也能确保高效的输出构建。 

一个微妙的点是在输入时去除换行符。 由于密码不包含空格，但可能包含其他符号，`strip()`仅安全地删除尾随换行符，而不影响有效内容。

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(所有字符串的总长度) | 每个字符都会根据固定大小的集合检查一次 |
 | 空间| O(输出总长度) | 我们在加入之前存储过滤的字符 |

 ## 边缘情况

 对于完全禁止的字符串，例如`1iIl`，算法迭代每个字符，发现所有字符都在禁止集中，并且不添加任何内容。 缓冲区保持为空，并且连接会生成一个空字符串，该字符串仍会正确打印为空行。 

对于没有禁止字符的字符串，例如`abcXYZ`，每个成员资格检查都会失败，因此会附加每个字符。 输出缓冲区与输入完全匹配，保留顺序而不进行修改。 

对于交替模式，例如`1a1b1c`，每个字符都被独立检查。 禁止的数字将被跳过，而字母将被附加。 生成的缓冲区仅在有效字符上增长，从而确认该算法不依赖于位置或分组。 

对于大量重复输入，每个字符仍被处理一次，并且恒定时间集成员资格确保总运行时间随输入大小线性缩放。
