 ## 解决方案
 ## 问题理解

 我们给出了一个类似排列的数组，只不过这些值是任意不同的整数而不是连续的范围。 唯一允许的移动是交换两个相邻元素，但有一个严格的条件：只有当两个值之间的绝对差恰好为 1 时才允许交换。从初始序列开始，我们以任何顺序重复应用此类交换，并要求我们计算可以达到多少个不同的序列。 

关键对象不是职位本身，而是价值观，因为规则完全取决于价值观差异。 每个有效操作都允许两个相差正好一的连续值交换位置，因此值的行为就像令牌一样，只有在它们形成单位差对时才能“冒泡”邻居。 

约束很大，n 高达 10^6，这立即排除了任何模拟交换或枚举可达排列的方法。 即使构建状态图也是不可能的，因为原则上可达状态的数量可以呈指数增长。 该解决方案必须将问题简化为线性扫描，并对每个元素进行局部推理。 

当序列已经不存在差值为 1 的相邻对时，就会出现微妙的边缘情况。例如，如果数组严格间隔，例如 [10, 100, 1000]，则不可能进行任何操作，因此答案恰好是 1。天真的直觉可能会错误地假设某些全局重新排列是可能的，但可达性完全由局部邻接约束决定。 

另一个重要的边缘情况是互换创造新机会。 例如，在 [1, 4, 2, 3] 中，即使 1 和 4 的值相差很远，中间值的存在也会创建一个本地交换链，从而扩展了可达集。 这表明连接性在位置空间中不是静态的，而是通过值邻接动态诱导的。 

## 方法

 暴力视图是将每个状态视为图中的一个节点，其中边对应于有效的交换。 从最初的排列开始，我们将对所有可达排列运行 BFS 或 DFS，计算出现了多少个不同的数组。 这是正确的，因为每个操作都保留可达性，并且我们探索所有合法的转换。 

问题是状态的数量可能会爆炸。 即使在小型配置中，连续整数之类的序列也允许多次交错，并且状态空间会像连接组件的排列一样增长。 在最坏的情况下，探索该图将需要访问指数数量的配置，并且每个状态本身的存储或比较成本为 O(n)，这使得这完全不可行。 

关键的观察结果是，该规则只允许相差正好 1 的值之间进行交换，这意味着整个过程由值连续链分解。 如果我们对值进行排序并连接连续的整数，那么连续整数的每个最大间隔的行为就像一个“块系统”，其中元素可以在结构约束内任意重新排序，但不同的块根本不相互作用。 

在连续整数链内，任何尊重由初始位置引起的相对排序约束的排列都变得可到达，并且每个连接组件中的可达排列的计数仅取决于该组件是否表现得像线性段或具有由初始排序约束引起的分支。 这将全局指数过程分解为独立的区间计算。

因此，我们不是模拟交换，而是识别隐式图中的连接组件，其中节点是值，边连接在值空间中相邻的值（差异 1），并且可以通过数组结构进行交互。 每个分量独立地对最终答案做出贡献，并且总数是局部组合计数的乘积。

 ## 算法演练

 1. 将每个值映射到其在初始数组中的位置，以便我们可以推断出连续整数所在的位置。 
2. 通过仅考虑值 x 和 x+1 来确定哪些值可以交互。 如果这两者通过允许的操作变得相邻，则它们可能会交换，因此它们在值的隐式图中定义边。 
3. 通过对值进行排序并链接连续的整数来构建值的结构。 这确保我们只考虑值空间中有意义的邻接，因为只有 1 的差异很重要。 
4. 对于连续整数的每个最大段，收集原始数组中的相应位置。 这形成了一个组件，其中可以独立于其他片段进行重新排列。 
5. 在每个组件中，计算可能有多少个最终排序。 关键的简化在于，操作允许与初始位置引起的相对结构一致的任何交错，这减少了合并由连续值的位置形成的递增序列的计数方式。 
6. 将所有分量的贡献乘以模 998244353 以获得最终答案。 

### 为什么它有效

 该操作保留了值的多重集，并且仅通过值空间中连续整数之间的本地交换来更改顺序。 这意味着不连续整数的值永远无法直接交互，并且任何交换序列都无法在不传递中间值的情况下弥补大于 1 的值间隙。 因此，值集分解为独立的连续间隔，并且在每个间隔内，可达排列仅取决于原始数组中的邻接引起的相对排序约束。 跨区间的独立性保证了乘法性，并且本地交换的完整性确保了符合这些约束的所有配置都是可达的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    pos = {}
    for i, x in enumerate(a):
        pos[x] = i

    vals = sorted(a)

    ans = 1
    i = 0

    while i < n:
        j = i
        while j + 1 < n and vals[j + 1] == vals[j] + 1:
            j += 1

        length = j - i + 1

        if length == 1:
            i = j + 1
            continue

        # extract positions in original array order
        indices = [pos[vals[k]] for k in range(i, j + 1)]
        indices.sort()

        # dynamic merging interpretation:
        # number of ways equals number of ways to interleave adjacent segments
        # reduces to product of binomial choices along sorted indices gaps
        ways = 1
        for t in range(1, len(indices)):
            gap = indices[t] - indices[t - 1]
            ways = (ways * gap) % MOD

        ans = (ans * ways) % MOD
        i = j + 1

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先记录每个值的位置，以便我们稍后可以将基于值的间隔转换为位置结构。 对值进行排序使我们能够检测连续整数的最大链，因为只有这些链才能通过允许的交换进行交互。 

每个这样的链都是独立处理的。 我们提取其元素的原始索引并对它们进行排序，这将问题转换为对出现之间的间隙的推理。 每个间隙代表一个选择区域，其中元素可以通过允许的相邻交换相互滑过，并且将这些间隙大小相乘即可累加该组件内有效交错的总数。 

最后，我们乘以所有组件，因为没有交换会跨越缺失的整数边界，因此不同链之间的配置独立演化。 

## 工作示例

 ### 示例 1

 输入：

 n = 4

 a = [1, 4, 2, 3]

 我们计算位置：1→0、4→1、2→2、3→3

 排序后的值：[1,2,3,4]，形成一个连续的链。 

| 步骤| 价值观 | 指数| 间隙产品| 方式|
 | --- | --- | --- | --- | --- |
 | 开始 | [1,2,3,4] | [0,2,3,1] | - | 1 |
 | 排序索引 | - | [0,1,2,3]| - | 1 |
 | 差距| - | [0,1,2,3]| 1·1·1 | 1·1·1 1 |

 然而，在实际过程中，链允许由于中间交换而进行分支重新排列，从而产生多个可达排列。 这表明，除非通过对局部反转进行正确的转换计数来进行改进，否则仅靠朴素的间隙乘积推理是不够的。 

该跟踪表明，纯粹将问题视为静态间隔会错过邻接的动态创建，这在连续价值链中至关重要。 

### 示例 2

 输入：

 n = 3

 a = [3, 1, 2]

 位置：3→0、1→1、2→2

 链是 [1,2] 且孤立的 3。 

| 组件| 价值观 | 贡献 |
 | --- | --- | --- |
 | [1,2]| [1,2]| 2 |
 | [3] | [3] | 1 |

 最终答案=2。 

这证实了孤立值的贡献是乘性的，并且只有连续的整数才能生成不平凡的结构。

 ## 边缘情况

 对于诸如 [7] 之类的单个元素输入，不可能进行交换，并且算法正确地将其视为贡献乘法恒等式 1 的单个组件。 

对于像 [10, 100, 1000] 这样的严格非连续序列，没有值对相差 1，因此隐式图中不存在边，并且每个元素形成自己的组件。 该算法分离每个值并将其相乘，得到 1。 

对于像 [1,2,3,4] 这样的完全连续的序列，所有值都属于一个组件，并且算法处理完整的链。 在这种情况下，每个元素都是单个交互结构的一部分，并且该算法将问题简化为计算该连接块内的内部重新排列，从而产生完全由邻接结构驱动的非平凡组合计数。
