 ## 解决方案
 ## 问题理解

 我们得到一个简单的多边形，由其顶点按逆时针顺序描述。 多边形是非退化的，因此边仅在端点处相交，没有三个连续顶点共线，并且它形成适当的闭合形状。 

在此多边形边界内，考虑位于其中一条边上的任何点。 从这样的点P开始，我们询问多边形边界上是否存在其他点Q，使得线段PQ完全留在多边形内部或边界上，仅在P和Q处接触它。换句话说，如果它们之间的直线段不穿过外部或不穿过多边形内部，则P可以“看到”Q。 

如果多边形边界上的任何地方都没有这样的可见 Q，则点 P 称为盲点。 如果所有此类盲点的集合是有限的，则该多边形被视为“堡垒”。 对于每个多边形，我们必须决定这个条件是否成立。 

关键的困难在于定义是连续的：P 和 Q 沿着边缘分布在无限多个点上。 因此，我们处理的不是顶点上的离散可见性图，而是沿边界的完整几何可见性。 

约束很大：每个测试用例最多有 10^5 个顶点，所有测试总共有 2 × 10^5 个顶点。 这排除了任何对边缘上的任意点对进行推理或连续模拟可见性的方法。 每个多边形的任何二次甚至接近二次都是不可能的。 

一种微妙的边缘情况是沿着边缘具有局部“反射状”结构的多边形，其中整个边缘间隔而不是孤立点的可见性崩溃。 例如，如果一个多边形有一个长的“走廊”形状，阻挡了某些边缘段的每个内部点的可见性，那么盲点会形成一个连续的间隔，因此答案立即为“否”。 

另一个极端情况是凸多边形。 在凸多边形中，每个边界点都能看到其他所有边界点，因此根本不存在盲点。 答案是肯定的。 

真正的挑战是识别盲点何时沿着边缘形成连续的集合，以及何时由于仅有有限多个几何简并而被隔离。 

## 方法

 直接的强力解释将在每条边上选取一个点 P，并尝试确定所有 Q，使得线段 PQ 不会穿过多边形内部。 由于 P 和 Q 连续变化，因此可以通过考虑所有边缘对并检查代表性样本之间的可见性来进行离散化。 即使我们限制为顶点，检查所有对之间的可见性也是 O(n^2)，并且这忽略了问题的连续性，因此它甚至是不正确的。 

蛮力思想在概念上是有效的，因为两个边界点之间的可见性取决于线段是否与任何多边形边相交。 但失败之处在于盲点不是由有限多个采样点决定的。 沿边的整个区间可以被阻塞或解除阻塞，因此采样顶点会失去结构。 

关键的观察是，边界点是否具有可见方向仅取决于多边形边界的局部角度结构。 当我们穿过边界时，可见性仅在组合事件时发生变化：当支撑线与多边形相切或与边延伸对齐时。 这些事件对应于与凸包结构相互作用的边。

这导致了核心简化：多边形的行为就像有向线段链，当存在没有支撑线从该点退出多边形的方向时，盲点就会出现。 这将连续问题分解为检查多边形形状的全局几何属性，结果仅取决于每条边是否在至少一个方向上“从无穷远可见”，这相当于不包含某些创建连续阻塞间隔的平坦反射配置的多边形。 

最终结果简化为检查多边形是否具有至少一对边，其支撑线定义了边界周围的完全方向覆盖。 这相当于验证边缘的向外法线集是否覆盖了整个圆，而不留下未覆盖的方向弧，这反过来又简化为检查所有边缘方向是否位于某个闭合半平面内。 如果这样做，多边形在可见性方面就会退化并产生无限多个盲点； 否则盲点是孤立且有限的。 

因此，该任务变成了对边缘向量的凸包方向样式检查。

 | --- | --- | --- | --- |
 | 暴力可见性采样 | O(n^2) 或更糟 | O(1) | O(1) | 太慢/不正确 |
 | 方向扫描/角度覆盖检查| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将每个多边形边转换为方向向量。 从顶点 i 到 i+1 的每条边都贡献一个向量 vi = (x_{i+1} − x_i, y_{i+1} − y_i)。 

然后我们分析这些向量的角度分布。 

1. 按顺序计算多边形周围的所有边缘方向向量。 这些代表可见性约束可以“阻挡”光线的所有可能的边界方向。 
2. 按角度对每个方向进行归一化，通常使用atan2，因此每个向量对应于[0, 2π)中的一个角度。 
3. 对这些角度进行排序。 
4. 通过向每个角度添加 2π 并附加它来复制排序列表，以模拟循环环绕。 
5. 在这个双阵列上滑动一个窗口，找到连续方向之间的最大角度间隙。 
6. 如果存在严格大于π的间隙，则所有方向都位于某个开放的半圆内，这意味着存在一个支撑半平面，它以连续的方式阻挡可见性，从而产生无限多个盲点。 在这种情况下，输出NO。 
7. 否则，输出YES。 

直觉是，当多边形的边缘方向不限于半圆时，它仅具有有限多个盲边界点。 如果它们受到限制，则存在一个永远“看不到”多边形的全局方向，导致整个边缘间隔以连续的方式变得不可见。 

### 为什么它有效

 仅当存在一个方向，其中来自边界点的每条可见光线都被在方向的单个半平面内对齐的边缘阻挡时，盲点才会形成连续的集合。 当所有边缘方向都位于某个半圆内时，就会发生这种情况，因为此时存在支撑线方向，该支撑线方向会阻止多边形边界周围的可见性传播。 如果边缘方向跨越超过半圆，可见方向必然“环绕”多边形，迫使任何不可见点成为由离散切线而不是间隔确定的孤立事件，因此是有限的。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        pts = [tuple(map(int, input().split())) for _ in range(n)]
        
        ang = []
        for i in range(n):
            x1, y1 = pts[i]
            x2, y2 = pts[(i + 1) % n]
            dx = x2 - x1
            dy = y2 - y1
            ang.append(math.atan2(dy, dx))
        
        ang.sort()
        
        # duplicate for circular sweep
        m = len(ang)
        ang += [a + 2 * math.pi for a in ang]
        
        max_gap = 0.0
        for i in range(m):
            max_gap = max(max_gap, ang[i + 1] - ang[i])
        
        # check wrap gap too
        for i in range(m, 2 * m - 1):
            max_gap = max(max_gap, ang[i + 1] - ang[i])
        
        # if all directions fit in a semicircle, max gap > pi
        if max_gap > math.pi + 1e-12:
            print("NO")
        else:
            print("YES")

if __name__ == "__main__":
    solve()
```该代码首先读取每个多边形并构造边缘方向向量。 每个向量都使用 atan2 转换为角度，它可以正确处理所有象限并避免手动符号处理。 

对角度进行排序后，复制步骤会创建一个圆形表示，以便统一处理环绕间隙。 连续角度之间的最大间隙表示没有边缘方向的最大空角扇区。 

如果这个空扇区超过π，所有方向都包含在半圆中，这会触发病态可见性情况，导致无限多个盲点。 否则，可见性充分分散，盲点无法形成连续的间隔，因此该多边形有资格作为堡垒。 

比较中的 epsilon 处理来自 atan2 的浮点精度。

 ### 示例 1

 考虑一个正方形。

这符合凸多边形没有连续盲区的直觉。

 考虑一个退化的细长形状，其中所有边缘大致指向一个半平面内。 

| 步骤| 角度| 最大间隙|
 | --- | --- | --- |
 | 边缘方向 | 聚集在 [0, 2π/3] | |

 这里，存在一个完全没有边缘的方向范围，这意味着缺失方向的完整半平面。 这会产生沿部分边缘的可见性的连续阻挡，导致无限多个盲点，因此输出为“否”。

 ## 边缘情况

 三角形恰好具有三个边方向。 它们的角展度始终超过任何半圆约束，因此最大间隙始终小于 π，结果为“是”。 该算法只是看到均匀间隔的角度并立即返回“是”。 

完美的凸正方形具有均匀的角间距。 没有间隙超过 π，证实凸多边形始终被接受。 

除小扰动外，其边几乎全部平行的多边形演示了失效模式。 这些角紧密地聚集在一起，产生一个超过 π 的大间隙。 该算法正确地识别出“否”，因为边缘方向被限制在半平面内，该半平面对应于沿边界边缘的连续盲区间。
