 ## 解决方案
 ## 问题理解

 我们有一块尺寸为的长方形板$N \times M$。 每个单元格要么已经是黑色或白色。 我们可以将额外的白色单元涂成黑色，但决不允许我们将黑色单元重新涂回白色。 

最终的配置必须同时满足两个独立的条件。 首先，黑色单元格必须在网格邻接图下形成一个独立的集合，这意味着没有两个黑色单元格可以共享一条边。 其次，最终图案必须具有至少一个对称轴：要么相对于水平中线对称，要么相对于垂直中线对称。 

任务是确定是否可以通过仅添加黑色单元来将初始黑色配置扩展为有效的最终配置，同时保留邻接约束和至少一种对称性。 

限制条件$N, M \le 100$暗示直到$10^4$细胞。 它足够小，我们可以直接推理每个单元及其对称对应单元，而无需任何高级数据结构。 检查每个单元的恒定工作量的解决方案就足够了。 

一个微妙的点是，对称性并不是每个单元都独立可选的。 选择全局对称轴会强制每个单元与一个镜像位置配对，因此决策会耦合到整个网格。 另一个隐藏的困难是，现有的黑色单元格已经对可行性进行了双重限制：它们不能违反邻接性，并且它们还必须与我们选择的对称性兼容。 

一个典型的陷阱是试图通过添加更多黑色单元来贪婪地“修复”违规行为，而不考虑镜像位置可能已经是黑色，或者强制对称性可能会迫使两个相邻的黑色单元出现。 

## 方法

 暴力方法将分别尝试两种可能性：强制水平对称或强制垂直对称。 对于每个选择，我们都会尝试构建一个有效的最终网格。 

固定对称性意味着每个细胞$(i, j)$与特定的伙伴细胞相关联。 对于水平对称性，有$(N-1-i, j)$。 对于垂直对称性，有$(i, M-1-j)$。 无论哪种情况，如果一个细胞是黑色的，那么它的镜子也一定是黑色的。 

一个幼稚的构建策略将通过迭代所有单元并强制对称来进行：每当我们看到一个黑色单元时，我们就把它的镜子漆成黑色。 之后，我们检查是否违反邻接约束。 如果没有违规，我们接受。 

这种方法原则上是正确的，但失败了，因为它忽略了传播效应：强制对称可以创建新的黑黑邻接，而这些邻接无法通过删除单元来解决。 一旦黑色细胞存在，它就永远固定。 

关键的观察结果是，问题不在于构造任意配置，而在于检查由对称性引起的强制等价类的一致性。 每个对称选择将单元格划分为大小为 1 或 2 的轨道。在每个轨道内，两个单元格必须共享相同的颜色决策，但黑色单元格还施加了硬性约束，即相邻轨道对不能同时为黑色。 这将问题简化为检查在初始黑色单元施加的约束下是否存在一致的轨道值分配。 

我们可以简单地独立测试两种对称类型。 对于每个层，我们验证两层的一致性：首先，强制对称性不会与现有的黑色单元相冲突，其次，在强制对称闭包后不会违反邻接约束。

 ## 算法演练

 我们分别测试水平对称性和垂直对称性。 对于每种情况，如果我们在尊重所有现有黑色单元格的同时强制对称性，我们将模拟最终的网格。 

1. 将初始网格复制到所选对称性的工作网格中。 
2. 对于每个细胞$(i, j)$，如果它是黑色的，则通过将其镜像单元也设置为黑色来强制对称性。 这是强制性的，因为我们不能破坏黑细胞，而对称性要求相等。 
3. 所有强制分配完成后，再次扫描网格并检查是否有任何两个相邻单元格都是黑色的。 
4. 如果不存在邻接冲突，则该对称配置有效。 
5. 对另一个对称方向重复相同的过程。 
6. 如果至少一个方向有效，则输出Yes； 否则输出No。 

关键点是步骤 2 必须在检查邻接性之前全局应用。 如果我们在传播对称性时进行本地检查，我们可能会错过级联效应，即强制一对在其他地方引入另一种违规。 

为什么它有效是基于对称约束下的闭包。 每个黑色单元都强制其镜子也为黑色，因此任何有效的解决方案都必须包含初始黑色集的所有对称闭包。 一旦这个闭包被修复，唯一剩下的条件就是这个强制集是否已经违反了独立集约束。 如果没有，我们可以自由地将所有白细胞保持为白色，因为添加更多黑细胞只会带来引入新的邻接冲突的风险，并且对于可行性来说是不必要的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def valid(grid, n, m, horizontal):
    g = [list(row) for row in grid]

    # enforce symmetry closure
    for i in range(n):
        for j in range(m):
            if g[i][j] == 'B':
                if horizontal:
                    ni, nj = n - 1 - i, j
                else:
                    ni, nj = i, m - 1 - j
                g[ni][nj] = 'B'

    # check adjacency constraint
    for i in range(n):
        for j in range(m):
            if g[i][j] == 'B':
                if i + 1 < n and g[i + 1][j] == 'B':
                    return False
                if j + 1 < m and g[i][j + 1] == 'B':
                    return False

    return True

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    if valid(grid, n, m, True) or valid(grid, n, m, False):
        print("Yes")
    else:
        print("No")

if __name__ == "__main__":
    solve()
```该解决方案为每种对称类型构建网格的新副本，并通过扫描所有黑色单元来强制镜像约束。 仅使用右邻接和下邻接检查就足够了，因为每个冲突都会被检测到一次。 水平和垂直对称情况被干净地分开，确保两个检查之间没有相互作用。 

一个常见的错误是尝试在检查邻接性的同时修改网格，这会导致丢失稍后在同一传播过程中引入的违规行为。 在这里，我们首先完全构建对称闭包，然后进行验证。 

## 工作示例

 | 2 | 镜像到 (2,1) | 在 (2,1) | 添加 B
 | 3 | 检查邻接性 | 没有相邻的黑人|

 这种配置在水平对称的情况下有效，所以答案是肯定的。

BB
WW
```| 步骤| 行动| 网格变化|

这些例子表明，即使初始配置看起来很稀疏，仅对称传播也会产生不可避免的冲突。

 ## 边缘情况

 一个关键的边缘情况是，当对称性迫使传播到已经占用的黑色单元时，这可能会悄悄地在对称轴上产生邻接冲突。 例如：```
2 3
BWB
WWW
```在水平对称下，每个黑色单元映射到另一行，产生黑色对的完全垂直对齐。 传播后，每列包含两个垂直堆叠的黑色单元，这立即违反了邻接关系。 该算法处理这个问题是因为它总是在检查任何邻接之前完成完全对称闭合，因此可以检测到这些引发的冲突。 

另一种情况是网格已经有效并且不需要更改。 由于该算法始终在检查中包含原始网格，因此它自然会接受这种情况而不进行修改。
