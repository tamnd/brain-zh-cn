 ## 解决方案
 ## 问题理解

 我们得到了一个集合$N$3 维整数空间中的点。 每个点代表一个具有三个属性的伙伴$(S, F, E)$。 目标是应用运算使所有点变得相同，这意味着每个伙伴都以完全相同的三元组结束。 

操作应用于单个选定的合作伙伴。 对于该合作伙伴，我们选择三个坐标的任何非空子集，然后将所有选定的坐标递增 1 或将所有选定的坐标递减 1。每个此类操作都会花费一个单位。 

任务是最小化使所有点相等所需的操作总数。 

约束允许最多$10^5$值高达$10^5$，因此任何尝试所有目标配置或模拟每个候选目标变换的解决方案都必须是线性或近线性的$N$。 对目标进行三次或二次搜索是立即不可能的，甚至$O(N \log N)$如果候选空间很大，每个候选目标就会太慢。 

问题的一个微妙点是操作与坐标耦合。 我们不调整$S, F, E$独立地：我们可以同时修改一个、两个或全部三个，这会在维度之间产生交互，从而使其与标准 3D 中值问题不同。 

一个天真的错误是假设每个坐标都可以使用中位数独立优化。 另一个错误是独立地对待每个点，而没有认识到所有点都必须收敛到一个共同的目标。 

一个简单的坐标独立性显然无法证明合理的小例子是当点是：$$(0,0,10), (10,0,0)$$每个坐标独立选择一个目标建议$(5,0,5)$，但实际的成本结构取决于关节更新如何减少跨坐标的移动成本。 粗心的求解器可能会忽略耦合并得出关于可行性的错误推理。 

## 方法

 蛮力的想法很简单：猜测最终目标点$(X, Y, Z)$，然后计算需要多少次操作才能将每个点转换为该目标。 对于固定点，我们计算差异向量并尝试使用允许的操作来表达它。 对所有点求和即可得出该目标的成本。 

这是正确的，但无法使用，因为目标空间很大。 每个坐标范围可达$10^5$，所以枚举所有可能的$(X, Y, Z)$需要$10^{15}$候选人。 即使限制于观察到的坐标仍然存在$O(N^3)$的可能性。 

关键的观察结果是，一旦目标固定，每个点的成本就会干净地分解，并且总成本变成绝对坐标差上相同结构函数的总和。 尽管每个点在其三个坐标上都有耦合成本，但耦合不会引入跨点交互。 这使我们能够将优化分离为选择一个最佳目标，以最小化对称绝对偏差表达式的总和。 

允许的操作集允许我们一起更改一个、两个或三个坐标，这实际上意味着运动的行为类似于 3D 规范，它是 L1 距离和分组更新压缩的组合。 这种结构意味着最佳目标的行为就像每个坐标中的中值，因为成本仅取决于绝对偏差并且在每个维度上都是凸的。 

认识到这一点后，问题就简化为计算最佳目标作为坐标中位数并评估总成本。

 ## 算法演练

 ### 关键思想

 我们将问题转化为选择一个最小化成本总和的单个目标点，其中每个成本仅取决于每个坐标的绝对差。 

### 步骤

 1. 提取所有值$S$,$F$， 和$E$到单独的数组中。 

这样做是因为成本函数仅取决于与所选目标的绝对差异，因此每个坐标在聚合中独立贡献，即使每点成本是耦合的。 
2. 对三个数组分别进行排序。 
3. 选择每个数组的中位数作为候选目标坐标：$X$是所有的中位数$S_i$,$Y$是所有的中位数$F_i$， 和$Z$是所有的中位数$E_i$。 

这种选择的动机是在中值处实现最小化绝对偏差之和。 
4. 对于每个点$i$，计算：$$dx = |S_i - X|,\quad dy = |F_i - Y|,\quad dz = |E_i - Z|$$5. 使用以下公式计算该点的成本贡献：$$cost_i = \max(\max(dx, dy, dz), \lceil (dx + dy + dz)/3 \rceil)$$第一项强制要求我们减少坐标的速度不能比每次操作减少一个坐标的速度快。 第二项强制每个操作最多可以影响三个单位的坐标总偏差。 
6. 总和$cost_i$并输出结果。 

### 为什么它有效

 每个点独立地需要最少数量的操作才能达到目标，并受到两个独立下限的约束：最大单坐标偏差和总 L1 偏差分摊到可同时影响最多三个坐标的操作。 该公式紧密地捕获了这两个约束。 

一旦目标确定，总成本就是绝对偏差的凸函数之和。 当每个坐标独立地放置在中位数时，这样的总和会最小化，因为向左或向右移动目标会增加总的绝对偏差。 每个点内部的耦合不会影响交叉点优化，因为它不会在不同点的坐标之间创建交互项。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def cost(dx, dy, dz):
    s = dx + dy + dz
    return max(max(dx, dy, dz), (s + 2) // 3)

n = int(input())
S = []
F = []
E = []

pts = []
for _ in range(n):
    s, f, e = map(int, input().split())
    S.append(s)
    F.append(f)
    E.append(e)
    pts.append((s, f, e))

S.sort()
F.sort()
E.sort()

mx = S[n // 2]
my = F[n // 2]
mz = E[n // 2]

ans = 0
for s, f, e in pts:
    dx = abs(s - mx)
    dy = abs(f - my)
    dz = abs(e - mz)
    ans += cost(dx, dy, dz)

print(ans)
```实施将目标选择与成本评估分开。 使用排序可以有效地获得中位数，并且直接取中间元素，因为任何中位数都会最小化绝对偏差之和。 

成本函数是在恒定时间内计算每个点的。 四舍五入$(s + 2) // 3$正确实施了总偏差三分之一的上限。

 ## 边缘情况

 直接处理与一个合作伙伴的最小配置，因为所有坐标中位数等于点本身，从而实现零偏差和零成本。 由于没有计算差异，该算法自然返回零。 

当所有点都相同时，排序会产生相同的中位数，并且每个偏差都为零，因此每个点的成本函数计算结果为零。 这可以避免整数除法或舍入造成的任何意外计数。 

当坐标高度倾斜时，例如一个坐标较大而其他坐标较小，成本中的最大项可以正确防止低估减少单个坐标所需的操作，而中值选择可以防止目标选择中的系统偏差。 

像这样的案例：$$(0,0,100), (100,0,0), (0,100,0)$$仍然表现正确，因为每个坐标中位数为 0 或 100，具体取决于排序，并且偏差对称分布，确保没有坐标被错误地过度优化而牺牲其他坐标。
