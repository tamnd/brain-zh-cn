 ## 解决方案
 ## 问题理解

 我们得到一个量子系统，包括$n$量子位，并且该系统不是像位串那样的经典状态，而是被描述为大小的复值向量$2^n$。 该向量的每个索引对应一个基本状态，即一个长度的二进制字符串$n$。 索引处存储的值是复振幅，测量后观察到该基本状态的概率是其振幅的平方值。 

测量将整个系统折叠成单一基本状态。 然而，这个问题并没有询问每个完整的概率$n$位结果。 相反，它要求边际视图：对于每个单独的量子位位置，我们想要该量子位在测量后变为 0 的概率以及它变为 1 的概率。 

所以对于每个位位置$j$，我们在概念上根据它们是否$j$-th 位是 0 或 1，并对这些组的概率求和。 

输入尺寸非常小，因为$n \le 8$，意味着向量最多有$2^8 = 256$条目。 这立即排除了任何比状态向量上的线性或近线性扫描更复杂的事情。 甚至$O(2^n \cdot n)$在这里是微不足道的，因为最多大约有 2000 次操作。 

一个微妙的点是每个幅度都是一个复数，而概率来自幅度的平方。 即使分组逻辑是正确的，如果不小心执行，忘记计算幅值的平方或错误地混合实部和虚部，也会产生不正确的结果。 

另一个边缘情况是标准化。 该语句保证总概率约为 1，但由于浮点误差，我们不能依赖精确的标准化。 然而，由于我们只聚合平方幅度，因此不需要重整化步骤。 

一个小的说明性情况是除 1 之外所有振幅均为零时。 在这种情况下，每个量子位的答案是确定性的，任何意外地将概率分布在多个状态之间的解决方案都是错误的。 

## 方法

 最直接的方法是显式计算问题定义所建议的内容。 对于从 0 到$2^n - 1$，我们将其概率计算为其复振幅的平方大小。 然后，对于每个量子位位置，我们检查索引中该位是 0 还是 1，并将概率添加到相应的累加器中。 

这是有效的，因为测量概率是根据每个基本状态定义的，而边际概率只是不相交事件的总和。 

在这种情况下，暴力结构已经是最佳的。 唯一潜在的低效率是以非结构化方式重复重新计算位分解，但即使这样对于$2^8$。 

除了定义本身之外，不需要线性代数技巧或特定于量子的变换。 关键的见解是认识到每个量子位的测量概率纯粹是位模式上的经典概率的分组。

 ## 算法演练

 我们将量子描述转换为位掩码上的经典概率，然后进行聚合。 

1. 阅读$n$，然后阅读$2^n$复振幅。 每个幅度对应于一个基本状态，其索引隐式地是其二进制表示。 这种映射至关重要，因为它允许我们直接解释位位置。 
2.初始化两个size的数组$n$,`p0`和`p1`，都用零填充。 这些将存储每个量子位分别为 0 或 1 的累积概率。 
3.对于每个基状态索引$i$，计算其概率为$a_i^2 + b_i^2$，这是复数的平方大小$a_i + b_i i$。 
4. 对于每个位位置$j$从 0 到$n-1$，检查是否$j$第 位$i$已设置。 如果为1，则添加状态概率$i$到`p1[j]`，否则将其添加到`p0[j]`。 这直接对所有国家实施了边缘化。 
5.处理完所有状态后，输出`p0[j]`和`p1[j]`对于每个量子位$j$。 

关键思想是，每个基础状态将其全部概率质量贡献给每个量子位的两组中的一组，因此不会重复计算或丢失概率。 

### 为什么它有效

 每个基本状态为每个量子位定义一个确定性值。 测量精确地选择一种基态，其概率等于其振幅平方。 因此，量子位的概率$j$等于 1 恰好是二进制表示在位置为 1 的所有基本状态的概率之和$j$。 由于这些事件是不相交的并且覆盖整个概率空间，因此对它们求和可以准确地重建边际分布。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    m = 1 << n
    
    p0 = [0.0] * n
    p1 = [0.0] * n
    
    for i in range(m):
        a, b = map(float, input().split())
        prob = a * a + b * b
        
        for j in range(n):
            if (i >> j) & 1:
                p1[j] += prob
            else:
                p0[j] += prob
    
    for j in range(n):
        print(p0[j], p1[j])

if __name__ == "__main__":
    main()
```代码几乎逐行遵循算法。 唯一的微妙之处在于将概率计算为`a*a + b*b`，它直接实现复数的平方大小，而不使用复数类型。 

位测试`(i >> j) & 1`提取量子位的状态$j$在基础指数中。 索引假设量子位 0 对应于最低有效位，这与此类问题中使用的标准二进制表示形式一致。

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(sys.stdin.readline())
    m = 1 << n
    
    p0 = [0.0] * n
    p1 = [0.0] * n
    
    for i in range(m):
        a, b = map(float, sys.stdin.readline().split())
        prob = a*a + b*b
        for j in range(n):
            if (i >> j) & 1:
                p1[j] += prob
            else:
                p0[j] += prob
    
    out = []
    for j in range(n):
        out.append(f"{p0[j]} {p1[j]}")
    return "\n".join(out)

 ## 边缘情况

 第一种边缘情况是除一个之外所有幅度都为零时。 该算法处理该单个索引，将概率 1 分配给恰好一个基本状态，并且所有量子位都正确反映该索引的位模式。 由于没有其他状态做出贡献，因此不会出现意外的概率扩散。 

另一种情况是振幅均匀分布在所有状态上。 由于每个状态都独立地对位累加器做出贡献，因此对称性确保每个量子位在适当的情况下获得平衡的贡献。 该算法不假设标准化，因此小的浮点偏差不会影响正确性。 

第三种情况是概率总和略高于或低于 1 时的数值精度。由于该算法从不执行归一化并且仅使用加法累加，因此它保留输入中存在的任何精度，这符合问题的容差要求。
