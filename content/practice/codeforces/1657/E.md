 ## 解决方案
 ## 问题理解

 我们有一个完整的图表`n`标记的顶点。 每条边都接收一个整数权重`1`和`k`。 

顶点`1`发挥着特殊的作用。 考虑以顶点为中心的星形`1`，由所有边组成`(1, v)`为了`v > 1`。 这颗恒星的总重量就是这些恒星的总重量`n - 1`边权重。 

当一个图的最小生成树的权重恰好等于该星形的权重时，该图被称为美丽图。 

任务是计算有多少完整的加权图满足这个条件，模`998244353`。 

约束条件是解决方案必须高度组合的第一个暗示。 包含 250 个顶点的完整图包含超过 31,000 条边。 即使写下所有边缘分配也是不可能的。 可能的加权图的数量是$$k^{\binom n2},$$这是一个天文数字。 

既然两者`n`和`k`至多是`250`，一个动态规划解决方案，大致为`O(n^2 k)`或者`O(n^3)`国家是现实的。 任何试图直接推理单个图或 MST 计算的方法都是完全遥不可及的。 

棘手的部分是理解 MST 条件的实际含义。 

考虑三个顶点`1, u, v`。 认为$$w(u,v) < \max(w(1,u), w(1,v)).$$然后在星形中，两条边中较重的一条`(1,u)`和`(1,v)`可以替换为`(u,v)`，生成权重更小的生成树。 这将使恒星变得非最佳。 

例如，如果$$w(1,u)=5,\quad w(1,v)=3,\quad w(u,v)=2,$$明星有贡献`5 + 3`从这两个顶点开始，但替换边`(1,u)`经过`(u,v)`总重量减少`3`。 

粗心的做法可能只会检查恒星本身是否是 MST。 实际情况更严格：MST权重必须等于恒星权重。 由于星形已经是生成树，因此相等意味着星形必须是最小生成树。 

一个有用的小例子是`n = 3`,`k = 2`。 

让$$a=w(1,2),\quad b=w(1,3),\quad c=w(2,3).$$恒星是 MST 的确切时间$$c \ge \max(a,b).$$有效的分配是：

 | 一个 | 乙| 有效的c |
 | ---| ---| ---|
 | 1 | 1 | 1,2 |
 | 1 | 2 | 2 |
 | 2 | 1 | 2 |
 | 2 | 2 | 2 |

 总计 = 5，与示例输出匹配。 

## 方法

 蛮力的想法很简单。 为每条边分配权重，运行 MST 算法，计算星形权重，然后比较两个值。 

问题是作业的数量。 一个完整的图包含$$\binom n2$$边，因此加权图的数量为$$k^{\binom n2}.$$为了`n = 250`，这是完全不可能的。 

关键的观察结果是 MST 条件可以重写为每个非星形边上的局部约束。 

让$$a_i = w(1,i).$$这些是星边权重。 

当且仅当非根顶点之间的每条边满足$$w(i,j) \ge \max(a_i,a_j).$$为什么？ 

如果某些边小于该最大值，我们可以替换较重的星形边并获得较轻的生成树。 

相反，如果每个非星形边缘至少是该最大值，则对于每个边缘`(i,j)`星中的唯一路径包含权重`a_i`和`a_j`，该路径上的最大权重恰好是`max(a_i,a_j)`。 边缘`(i,j)`永远不会比路径上的最大边便宜，这正是循环属性给出的 MST 特征。 那么该恒星就是 MST。 

现在问题变成了计算值的分配`a_i`。 

一旦星权重固定，每条边`(i,j)`有$$k-\max(a_i,a_j)+1$$有效的选择。 

因此答案等于$$\sum_{a_2,\dots,a_n} \prod_{i<j} \bigl(k-\max(a_i,a_j)+1\bigr).$$直接评估仍然是不可能的，因为有`k^(n-1)`明星任务。 

剩下的见解是，只有具有每个星形权重的顶点数量才重要。 

我们处理权重`1`到`k`并构建星边权重已经确定的顶点集。 这导致 DP 超过权重级别和顶点数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(k^{\binom n2})$| 巨大| 太慢了 |
 | 最佳DP |$O(k n^2)$|$O(kn)$| 已接受 |

 ## 算法演练

 让`N = n - 1`。 我们只需要为顶点分配星形权重`2...n`。 

定义：$$dp[w][t]$$作为处理权重值后的路数`1...w`，具体在哪里`t`顶点最多已经收到一个星形权重`w`。 

最初，$$dp[0][0]=1.$$假设我们正在处理重量`w`。 

认为`t`顶点已经被分配了较小的权重。 

选择`x`其星形权重恰好变为的新顶点`w`。 

那么新的计数就变成了$$t+x.$$### 计算边缘贡献

 每个新添加的顶点都有准确的星权重`w`。 

考虑最大星权重等于的对`w`。 

有两种：

 1.旧端点中的一个端点`t`顶点和其中之一`x`新的顶点。 

数数：$$t \cdot x.$$1. 两个端点`x`新的顶点。 

数数：$$\frac{x(x-1)}2.$$全部的：$$E=tx+\frac{x(x-1)}2.$$对于每个这样的对，相应的边`(i,j)`可以取任何值$$[w,k].$$因此每一对都贡献$$k-w+1$$选择。 

总贡献为$$(k-w+1)^E.$$### 计算哪些顶点接收权重`w`剩下的当中`N-t`顶点，选择`x`其中：$$\binom{N-t}{x}.$$因此过渡是$$dp[w][t+x] += dp[w-1][t] \cdot \binom{N-t}{x} \cdot (k-w+1)^E.$$处理完所有权重值后，每个顶点都必须已分配：$$\text{answer}=dp[k][N].$$### 为什么它有效

 DP逐级构造星边权重多重集。 

当体重`w`处理后，所有端点权重较大的顶点对正好是`w`变得完全确定。 每对这样的对都准确地独立贡献`k-w+1`其非明星优势的选择。 

每对计算一次，即当其较大的端点权重第一次出现时。 指数$$tx+\frac{x(x-1)}2$$正是最大星权重等于的对的数量`w`。 

将所有这些独立贡献相乘，将每个漂亮的图恰好计数一次，并且每个计数的图都满足上面的 MST 特征。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n, k = map(int, input().split())

    N = n - 1

    C = [[0] * (N + 1) for _ in range(N + 1)]
    C[0][0] = 1
    for i in range(1, N + 1):
        C[i][0] = C[i][i] = 1
        for j in range(1, i):
            C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD

    max_pairs = N * (N - 1) // 2

    pw = [[1] * (max_pairs + 1) for _ in range(k + 1)]
    for w in range(1, k + 1):
        base = k - w + 1
        for e in range(1, max_pairs + 1):
            pw[w][e] = pw[w][e - 1] * base % MOD

    dp = [[0] * (N + 1) for _ in range(k + 1)]
    dp[0][0] = 1

    for w in range(1, k + 1):
        for t in range(N + 1):
            cur = dp[w - 1][t]
            if cur == 0:
                continue

            rem = N - t

            for x in range(rem + 1):
                nt = t + x

                pairs = t * x + x * (x - 1) // 2

                ways = cur
                ways = ways * C[rem][x] % MOD
                ways = ways * pw[w][pairs] % MOD

                dp[w][nt] = (dp[w][nt] + ways) % MOD

    print(dp[k][N])

if __name__ == "__main__":
    main()
```组合表计算哪些顶点接收特定的星形权重。 自从`N ≤ 249`，一个简单的帕斯卡三角形就足够了。 

过渡指数$$t x + \frac{x(x-1)}2$$是解决方案的核心。 它精确计算最大指定星形权重成为当前权重的顶点对。 

因为相同的碱基出现多次，所以功率值是预先计算的。 如果没有这种预处理，DP 内重复的模幂运算将变得不必要的昂贵。 

国家使用`N = n - 1`因为只有根以外的顶点才需要星形权重分配。 这一小幅减少使配方更加干净。

        for e in range(1, max_pairs + 1):
            pw[w][e] = pw[w][e - 1] * base % MOD

    dp[0][0] = 1

 ## 边缘情况

 考虑：```
2 1
```图中只有一条边。 星号是整个图，也是唯一的生成树。 民主党有`N = 1`，将唯一的顶点分配给权重`1`，并返回`1`。 

考虑：```
2 5
```同样，不存在非星形边缘。 任何重量从`1`到`5`作品。 过渡只是为单独的顶点选择五个级别之一，产生答案`5`。 

考虑：```
3 2
```危险的配置是$$w(1,2)=2,\quad w(1,3)=1,\quad w(2,3)=1.$$简单的计数方法可能会接受它，因为所有权重都在范围内。 我们的特征拒绝它，因为$$1 < \max(2,1).$$DP 从不计算该图，因为最大星权重等于的边`2`只允许来自`[2,2]`。 

考虑：```
3 1
```每个边的权重都被迫为`1`。 明星有重量`2`，每棵生成树都有权重`2`，答案正是`1`。 DP 自然地处理这个问题，因为每个乘法因子都变成`1`。
