 ## 解决方案
 ## 问题理解

 任务是重复从括号字符串中删除“好”前缀。 如果前缀是常规括号序列或长度至少为 2 的回文，则该前缀很好。 我们继续这个过程，直到不存在好的前缀，然后报告我们执行了多少次删除以及剩余了多少字符。 每个测试用例都会给出一个字符串，我们必须高效地处理多个字符串。 

这些约束表明所有字符串的总长度不超过 500,000，这排除了重复检查每个可能的前缀的任何算法，因为这可能会导致 O(n²) 工作。 因此，我们必须在单次线性传递或接近线性传递中处理字符串。 

要考虑的边缘情况包括完全由相同括号组成的序列、以右括号开头的序列、已经规则的序列以及包含小回文前缀的序列。 例如，输入`((((`没有长于 1 的正则前缀，但重复的字符形成长度至少为 2 的回文。 仅检查常规括号序列的粗心解决方案将失败。 

## 方法

 暴力方法会尝试检查字符串的每个可能的前缀，以查看它是常规括号序列还是回文。 验证常规括号序列可以通过维护余额计数器来完成：在“(”上递增，在“)”上递减，检查余额永远不会变为负值并以零结束。 检查回文需要从前缀末尾对称地比较字符。 对所有前缀执行这些检查会导致每个字符串的复杂度为 O(n²)，考虑到约束条件，这太慢了。 

得出最佳方法的关键观察是我们不需要检查任意前缀。 我们只需要**最短的好前缀**。 当我们遍历字符串时，可以贪婪地找到这个前缀。 对于长度为两个或更多的回文，任何两个连续的相同字符形成有效的前缀。 对于常规括号序列，我们保持运行平衡：当余额达到零时，当前前缀是常规的。 因此，我们可以一次性处理该字符串，在识别前缀时删除它们，并计算操作次数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化两个计数器：`operations`删除前缀的数量和`i`为字符串中的当前索引。 
2. 虽然`i`小于字符串长度，尝试找到从以下位置开始的最短的好前缀`i`。 
3. 要查找常规括号序列的前缀，请维护从零开始的平衡计数器。 向前迭代从`i`，“(”加 1，“)”减 1。 如果某个位置余额为零`j`, 前缀`s[i:j+1]`是一个有效的正则序列。 增量`operations`，并设置`i = j + 1`。 
4. 如果没有立即找到正则序列，则检查长度为 2 的回文前缀：if`s[i] == s[i+1]`，删除这两个字符作为前缀。 增量`operations`，并设置`i = i + 2`。 
5. 如果两个条件都不满足，则中断循环，因为没有剩余好的前缀。 
6. 迭代结束后，剩余字符为`n - i`。 报告`operations`和剩余长度。 

### 为什么它有效

 该算法保持了不变性，即在每一步中，我们都会删除可能的最短前缀。 根据定义，任何较长的良好前缀都可以分解为从同一位置开始的多个较短的良好前缀。 使用平衡计数器检查常规括号序列可确保该条件的正确性。 回文检测仅限于长度为 2，因为最短的回文必须至少为两个字符。 这保证了我们删除尽可能多的前缀，而不会丢失任何有效的操作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        operations = 0
        i = 0
        while i < n:
            if i + 1 < n and s[i] == s[i + 1]:
                # Palindrome of length 2
                operations += 1
                i += 2
            else:
                balance = 0
                j = i
                while j < n:
                    if s[j] == '(':
                        balance += 1
                    else:
                        balance -= 1
                    if balance == 0:
                        break
                    j += 1
                if balance == 0:
                    operations += 1
                    i = j + 1
                else:
                    # No good prefix can be found
                    break
        print(operations, n - i)

if __name__ == "__main__":
    solve()
```该解决方案读取多个测试用例。 它迭代每个字符，检查长度为二的回文或保持规则序列的平衡。 指数`i`跟踪有多少字符串已被删除，并且`operations`计算成功删除的数量。 剩下的字符只是`n - i`。 这确保了每个字符串的 O(n) 时间和 O(1) 额外空间。

 ## 边缘情况

 只有一个字符的字符串，例如`"("`或者`")"`，导致零操作，因为不存在长度 ≥ 2 的前缀。 该算法正确地识别出`i`不前进并报告剩余字符。 重复字符长度超过两个的字符串每次都会通过删除第一对来处理，确保始终首先删除最短的回文前缀。 无法形成规则序列或长度 ≥2 的回文的不平衡序列会留下正确计数的剩余字符。
