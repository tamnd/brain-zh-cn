 ## 解决方案
 ## 问题理解

 我们从原点的芯片开始`(0, 0)`并想要达到目标点`(x, y)`。 

只要当前位置和下一个位置之间的欧氏距离是整数，就允许移动。 任务是找到达到目标所需的最少移动次数。 

坐标很小，最多`50`，并且最多有`3000`测试用例。 即使是效率稍低的解决方案也能轻松满足限制。 尽管如此，这个问题仍然有一个简单的数学观察，可以将每个测试用例的所有时间减少到恒定时间。 

关键量是从出发地到目的地的距离：$$d = \sqrt{x^2 + y^2}$$如果这个距离已经是整数，我们可以直接从`(0,0)`到`(x,y)`在一次操作中。 

当目的地本身就是出发地时，会出现一种特殊情况。 如果`(x,y) = (0,0)`，不需要移动，所以答案是`0`。 

主要的微妙之处在于理解当距离不是整数时会发生什么。 粗心的解决方案可能会认为有时可能需要两次以上的移动。 例如：

 输入：```
1
9 15
```距离是$$\sqrt{9^2+15^2}=\sqrt{306}$$这不是一个整数。 直接移动是不可能的，但正确答案仍然是`2`，而不是更大的数字。 

另一个容易犯的错误是忘记了原始情况：

 输入：```
1
0 0
```输出：```
0
```距离是一个整数 (`0`），但最小移动次数不是`1`，因为我们已经到达目的地了。 

## 方法

 思考问题的一种强力方法是寻找中间点。 如果不能直接到达目的地，我们可以尝试每个格子点`(a,b)`并检查两个距离是否$$\sqrt{a^2+b^2}$$和$$\sqrt{(x-a)^2+(y-b)^2}$$是整数。 

因为坐标最多是`50`，这样的搜索实际上在这里已经足够快了。 我们将检查每个测试用例的几千个候选点，并在找到有效的中间点时停止。 

蛮力的想法之所以有效，是因为坐标很小，但它完全忽略了底层结构。 

关键的观察是，每个非原点总是可以在最多两次移动中到达。 

假设目标是`(x,y)`并且它到原点的距离不是整数。 我们不可能一举到达。 

不过，我们可以先从`(0,0)`到`(0,0)`加上距原点整数距离的某个点，例如`(x,0)`如果`x > 0`，或任何其他合适的格点。 更一般地，一个更强的几何事实成立：平面上的每个点都可以表示为两个长度为整数的向量的和。 对于格点，两次移动总是足够的。 

由于当距原点的距离为整数时，一次移动是可能的，否则两次移动就足够了，因此只能出现三个答案：`0`,`1`， 或者`2`。 

这将问题转化为一个简单的分类`x² + y²`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 每个测试用例的 O(C²) | O(1) | O(1) | 已接受但没有必要 |
 | 最佳| 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 这里`C`表示坐标界限。 

## 算法演练

 1.读取目标坐标`(x, y)`。 
2.如果`x == 0`和`y == 0`， 输出`0`。 

我们已经到达目的地了，所以不需要移动。 
3. 计算$$s = x^2 + y^2$$距原点的距离为`√s`。 
4. 检查是否`s`是一个完美的正方形。 

如果是的话，那么`√s`是一个整数，所以直接从`(0,0)`到`(x,y)`是合法的。 
5. 如果`s`是一个完全平方数，输出`1`。 
6. 否则，输出`2`。 

一次移动是不可能的，因为距离不是整数，两次移动总是足够的。 

### 为什么它有效

 答案永远不能超过`2`。 

如果目的地是始发地，则最小值是明确的`0`。 

对于任何其他点，如果`x² + y²`是一个完全平方数，那么距离`(0,0)`到`(x,y)`是一个整数。 存在直接移动，所以答案是`1`。 

如果`x² + y²`不是完全正方形，直接移动是不可能的。 官方解决方案中使用的已知几何特性是，每个格点都可以通过两次整数长度的移动到达。 由于一步不能起作用，而两步总是可以，所以最小值恰好是`2`。 

这三种情况是互斥的并且涵盖了所有输入，因此算法是正确的。 

## Python 解决方案```python
import sys
from math import isqrt

input = sys.stdin.readline

t = int(input())

for _ in range(t):
    x, y = map(int, input().split())

    if x == 0 and y == 0:
        print(0)
        continue

    s = x * x + y * y
    r = isqrt(s)

    if r * r == s:
        print(1)
    else:
        print(2)
```第一个分支处理原点。 没有它，`(0,0)`会被错误地归类为需要一步，因为`0`是一个完美的正方形。 

变量`s`存储平方距离。 使用平方距离完全避免了浮点运算。`isqrt(s)`返回整数下限`√s`。 一个数恰好是完全平方数`isqrt(s)^2 == s`。 

一旦我们知道距离是否为整数，答案就直接从前面描述的三种情况分类中得出。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io
from math import isqrt

def solve():
    input = sys.stdin.readline
    t = int(input())

    ans = []
    for _ in range(t):
        x, y = map(int, input().split())

        if x == 0 and y == 0:
            ans.append("0")
            continue

        s = x * x + y * y
        r = isqrt(s)

        ans.append("1" if r * r == s else "2")

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out

# provided sample
assert run(
"""3
8 6
0 0
9 15
"""
) == "1\n0\n2"

# origin
assert run(
"""1
0 0
"""
) == "0"

# classic Pythagorean triple
assert run(
"""1
3 4
"""
) == "1"

# non-perfect-square distance
assert run(
"""1
1 1
"""
) == "2"

# maximum coordinates
assert run(
"""1
50 50
"""
) == "2"

 ## 边缘情况

 考虑目的地已经是起点。 

输入：```
1
0 0
```算法立即进入特殊情况分支并输出`0`。 这避免了处理距离的常见错误`0`作为普通整数距离并返回`1`。 

考虑一个距离为整数的点。 

输入：```
1
24 7
```距离的平方为$$24^2+7^2=576+49=625$$自从`625 = 25²`，算法输出`1`。 直接移动长度`25`是合法的。 

考虑一个距离不是整数的点。 

输入：```
1
1 1
```距离的平方为`2`，这不是一个完美的正方形。 完全平方检验失败，算法输出`2`。 

这是完全正确的，因为一招是不可能的，而两招总是足够的。 

考虑边界值输入。 

输入：```
1
50 50
```距离的平方为$$50^2+50^2=5000$$

`5000`不是完全平方数，因此算法输出`2`。 坐标的大小不会改变推理，表明该解决方案统一处理整个允许的范围。
