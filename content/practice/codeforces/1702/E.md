 ## 解决方案
 ## 问题理解

 给定一个多米诺骨牌集合，每个多米诺骨牌表示为一对 1 到 n 之间的整数，多米诺骨牌总数 n 是偶数。 任务是将这些多米诺骨牌分成两组，以便在每组中没有数字出现在多于一张多米诺骨牌上。 每张多米诺骨牌必须准确地分配到一组。 每个测试用例的输出是简单的“是”或“否”，具体取决于这种划分是否可能。 

约束足够严格，我们无法尝试所有可能的分区。 对于 n 高达 2·10^5 和高达 10^4 的测试用例，使用简单的 O(2^n) 方法来检查所有划分是完全不可行的。 在最坏的情况下，即使每个测试用例的 O(n^2) 也可能太慢。 这迫使我们用线性或近线性算法来思考。 

当多米诺骨牌包含重复的数字或相同的多米诺骨牌时，就会出现不明显的边缘情况。 例如，如果 n = 2 且多米诺骨牌为 [1,1] 和 [2,2]，则我们无法在其中一组中不重复数字的情况下拆分它们，因此输出必须为 NO。 另一个棘手的情况是当两个多米诺骨牌分别为 [1,2] 和 [2,1] 时。 尽管所有数字在全球范围内都是唯一的，但仍需要仔细分配以避免冲突。 

## 方法

 暴力方法将尝试一切可能的方法将 n 块多米诺骨牌分成两组 n/2 多米诺骨牌。 对于每个部门，我们将检查每个组是否仅包含唯一的数字。 这种方法是正确的，但完全不切实际：分裂 2·10^5 多米诺骨牌大约有 10^60 种可能性，远远超出了计算可行性。 

简化问题的关键观察是将其视为图表。 将每个数字 1 到 n 视为一个节点，将每个多米诺骨牌视为连接其两个数字的边。 为了满足没有组包含重复数字的条件，我们需要分割多米诺骨牌，以使共享节点的两条边不在同一组中。 这相当于检查图是否是**二分图**：我们可以用两种颜色给它的边着色，以便关联到同一节点的边得到不同的颜色吗？ 当且仅当所有连接的分量都是偶数长度或非循环的循环时，二部图的边着色总是可能的，因为奇数长度的循环会产生冲突。 

这种见解使我们能够将问题简化为构建多米诺骨牌连接的邻接列表、检测连接的组件以及检查每个组件是否是二分的。 深度优先搜索 (DFS) 或带有奇偶校验的并查找可以有效地处理此检查。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 通过 DFS 进行图二分 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一个有n个节点的邻接表，每个数字一个。 对于每个多米诺骨牌（a，b），将b添加到a的邻接表中，将a添加到b的邻接表中。 这构造了一个表示数字连接的无向图。 
2. 创建数组`color`大小为 n+1 的初始化为 -1，它将存储每个节点的二分区颜色：0 或 1。 
3. 迭代数字 1 到 n。 如果数字未着色，则从该节点开始执行 DFS，初始颜色为 0。 
4. In the DFS, assign the current node the given color. 然后对于每个邻居，检查它是否是彩色的：

 - 如果未着色，则递归到具有相反颜色的邻居。 
- 如果已经使用与当前节点相同的颜色进行着色，则存在冲突并且该图不是二分图。 
5. 如果DFS期间检测到任何冲突，则针对当前测试用例输出NO； 否则，处理完所有节点后，输出YES。 

这样做的原因是，正确的二分着色可以保证没有节点有两个关联边分配给同一组。 在我们的多米诺骨牌比喻中，这确保了同一组中没有数字出现两次。 每个连接的组件都是单独处理的，并且在 DFS 遍历中本地检测冲突。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n + 1)]
        dominoes = []
        for _ in range(n):
            a, b = map(int, input().split())
            adj[a].append(b)
            adj[b].append(a)
            dominoes.append((a, b))

        color = [-1] * (n + 1)
        possible = True

        def dfs(u, c):
            nonlocal possible
            color[u] = c
            for v in adj[u]:
                if color[v] == -1:
                    dfs(v, 1 - c)
                    if not possible:
                        return
                elif color[v] == c:
                    possible = False
                    return

        for i in range(1, n + 1):
            if color[i] == -1:
                dfs(i, 0)
                if not possible:
                    break
        print("YES" if possible else "NO")

solve()
```邻接列表有效地跟踪哪些数字不能在同一集合中。 DFS 分配颜色以确保每个数字仅出现在一组中而不会发生冲突。 增加了递归限制以处理长链中的深度 DFS。 检查`not possible`内部递归确保我们在冲突发生时尽早退出。

 ## 边缘情况

 两个具有相同数字的多米诺骨牌的最小情况，`[1,1],[2,2]`，立即失败，因为每个数字都需要进入一个单独的集合，但多米诺骨牌本身阻止了这种情况。 DFS 将 1 与 0 着色，2 与 0 着色，但 1 的邻接点指向其自身，从而产生冲突，按预期产生 NO。 

对于像这样的均匀循环`[1,2],[2,3],[3,4],[4,1]`，DFS 交替给节点着色。 每个邻居都会得到相反的颜色，满足所有约束并产生“是”。
