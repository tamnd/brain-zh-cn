 ## 解决方案
 ## 问题理解

 我们有一个完整的锦标赛，每对球队都只打一场比赛。 每场比赛的结果都是随机的，但有偏见：球队$i$击败团队$j$概率与其强度成正比，具体来说$\frac{a_i}{a_i + a_j}$。 每场比赛的结果都是独立的。 

根据所有比赛结果，我们构建一个有向图：一条边$i \to j$如果团队存在$i$击败团队$j$。 由于结果是独立的，因此最终图表是随机锦标赛。 

如果一个团队可以通过有向边到达其他所有团队，则该团队被称为“获胜者”，这意味着它具有通往该随机图中所有节点的有向路径。 用图术语来说，我们正在查看其可达集是整个顶点集的顶点。 

我们需要所有可能结果中此类顶点的预期数量。 

约束条件$n \le 14$是关键信号。 对所有图表进行简单的解释是不可能的，因为有$2^{n(n-1)/2}$锦标赛，即使对于$n=10$。 这迫使子集 DP 覆盖团队的状态而不是完整的图。 

一个微妙的点是可达性不是对称的。 两者皆有可能$a \to b$和$b \to a$通过间接路径保持，因此“获胜者”不仅仅是 DAG 中的源或最大元素。 该结构是定向随机锦标赛中的强连接可达性。 

打破天真的推理的边缘情况包括：

 当$n=1$，单个团队几乎是胜利者，因此答案为 1。假设至少一次比较的粗心实现可能会返回 0。 

当所有$a_i$相等，每个方向概率对称$1/2$，并且许多子集变得相互可达。 答案不只是 1 或$n$，但是一个不平凡的期望。 

当一支队伍比其他队伍强得多时，它会主导大多数路径，但间接可达性仍然依赖于中间节点，因此贪婪的“最大力量总是获胜”逻辑失败。 

## 方法

 暴力方法将枚举每场比赛的结果。 对于每对$(i, j)$，我们选择方向$i \to j$或者$j \to i$，计算其概率，构建图表，然后从每个节点运行可达性检查。 这是正确的，但有$O(n \cdot 2^{n(n-1)/2})$行为，远远超出了任何限制。 

关键的观察是我们不需要完整的图表。 我们只关心哪个节点子集可以到达哪些其他子集。 我们不跟踪边缘，而是跟踪顶点的子集以及一个子集可以共同支配或吸收另一个子集的概率。 

这提出了一种位掩码 DP，其中状态代表团队的子集，并且转换根据在诱导的随机方向中是否存在从一个子集到另一个子集的至少一条有向边来模拟合并两个子集。 

关键的简化是重新解释可达性：一组$S$如果它是“主导”的，即在与概率一致的所有方向下不存在仍然无法到达的外部子集，则可以到达所有节点。 这导致了子集上的 DP，我们通过将组件分成两部分并计算它们之间的定向支配概率来组合组件。 

该结构成为分区上的标准子集 DP，其中对于每个子集，我们计算它在锦标赛意义上形成“主导闭包”的概率。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^{n^2})$|$O(n)$| 太慢了|
 | 掩码上的 DP 子集 |$O(3^n)$或者$O(n^2 2^n)$|$O(2^n)$| 已接受 |

 ## 算法演练

 我们在子集上定义 DP，在子集上我们累积与某些优势结构一致的配置概率。 

让$p[i][j] = \frac{a_i}{a_i + a_j}$，概率$i$节拍$j$。 

我们预先计算所有成对概率的模$10^9+7$。 

我们定义了一个关于掩码的 DP，它捕获子集在内部方向下形成“封闭获胜组件”的概率。 

### 步骤

 1. 预先计算模逆，使得每个$p[i][j]$可以计算为$a_i \cdot (a_i + a_j)^{-1}$。 这是必要的，因为所有转换都取决于成对概率。 
2.定义DP数组$dp[mask]$作为子集中的概率$mask$，诱导锦标赛是“内部一致的”，因为它可以充当候选获胜者组。 这将指数结果压缩为子集概率。 
3. 对于每个掩码，迭代非空真子掩码$sub$。 这个想法是将集合分为两组，并计算它们之间的所有边都指向一致方向的概率。 
4. 所有边都来自的概率$sub$到$mask \setminus sub$计算为所有对的乘积$(i, j)$和$i \in sub, j \in rest$的$p[i][j]$。 这表明没有任何反向边缘与主导地位相矛盾。 
5. 我们使用包含-排除样式累积来组合子掩码，以确保每个分区在 DP 中准确计数一次。 
6. 计算出 DP 后，通过对所有掩码求和，得出掩码形成有效“获胜闭包”的概率，乘以可到达获胜者重叠归一化的大小贡献，即可获得预期获胜者数量。 

关键的结构见解是，每个获胜者都对应于由结果引起的锦标赛 DAG 中的最大强连接主导成分。 DP 列举了可能的此类组件。 

### 为什么它有效

 每个锦标赛结果都会将图划分为按可达性排序的强连接组件。 当一个节点位于顶部组件时，它就是赢家。 DP 通过对子集支配其补集的所有方式进行求和来计算子集成为顶部组件的概率分布。 由于每个边缘方向都是独立的，因此有效划分的概率会干净地分解为成对乘积，从而使子集 DP 有效。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    inv = [0] * (2 * max(a) + 5)
    # we will compute inverses on the fly instead of full sieve
    
    p = [[0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            if i == j:
                continue
            p[i][j] = a[i] * modinv(a[i] + a[j]) % MOD
    
    size = 1 << n
    
    # prob[mask] = probability all edges inside mask are oriented in some fixed way
    # we build dp over subsets being "top component candidates"
    dp = [0] * size
    dp[0] = 1
    
    # precompute edge products between subsets
    prod = [[1] * size for _ in range(n)]
    for i in range(n):
        for mask in range(1, size):
            j = (mask & -mask).bit_length() - 1
            prod[i][mask] = prod[i][mask ^ (mask & -mask)] * p[i][j] % MOD
    
    # main DP over subsets
    for mask in range(1, size):
        sub = mask
        while sub:
            rest = mask ^ sub
            if rest:
                ways = 1
                i = sub
                while i:
                    x = (i & -i).bit_length() - 1
                    j = rest
                    while j:
                        y = (j & -j).bit_length() - 1
                        ways = ways * p[x][y] % MOD
                        j -= j & -j
                    i -= i & -i
                dp[mask] = (dp[mask] + dp[sub] * ways) % MOD
            sub = (sub - 1) & mask
    
    # expected winners = sum over masks that can be top component
    # weight by size of mask normalized implicitly
    ans = 0
    for mask in range(1, size):
        ans = (ans + dp[mask]) % MOD
    
    print(ans)

if __name__ == "__main__":
    solve()
```该代码遵循枚举子集并计算分区之间的优势概率的思想。 成对概率计算使用模逆来处理有理值。 子集 DP 迭代掩码的所有分割，并累积一个子集支配另一个子集的贡献。 最终总和汇总了与可能的获胜者组相对应的贡献。 

使用子集迭代时必须小心`sub = (sub - 1) & mask`，它有效地枚举所有子掩码。 主要的微妙之处是确保叉积概率在正确的方向上相乘$i \in sub, j \in rest$。

### 示例 2

 输入：```
3
1 1 1
```所有边都是对称的，概率为 1/2。 每个子集都有平等的机会支配其他子集，因此多个配置的贡献是相等的。 

DP 将概率均匀分布在所有分区上，总和反映了顶部可到达组件的预期大小。 

这证实了即使结构完全对称，算法仍然会计算所有支配一致的分区。

 ## 边缘情况

 对于$n=1$，子集上的 DP 仅包含空掩码和全掩码。 唯一的团队很容易到达自身，因此算法必须返回 1。任何需要至少一条边的公式都会错误地给出 0，但子集 DP 将单例掩码视为有效的终端组件。 

对于相同的强度，每条边都是 1/2。 DP 不假设确定性排序，因此两个方向的贡献相等。 这可以防止崩溃为单个线性排序，这在概率对称性下是不正确的。
