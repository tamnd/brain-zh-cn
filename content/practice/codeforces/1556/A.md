 ## 解决方案
 ## 问题理解

 我们从两个整数开始，都初始化为零。 我们可以重复应用每次使用自由选择的正步长修改它们的操作。 每次操作都会移动该对$(a, b)$沿三个线性方向之一：均等增加、一个向上移动而另一个向下移动，或者相反。 

目标是确定我们是否可以达到目标对$(c, d)$，如果是的话，所需的最少操作次数是多少。 

每个操作都是灵活的，因为量级$k$是任意的并且每次都是新选择的，因此真正的约束不是大小而是方向。 我们实际上是在问需要多少有符号的基移动来表达向量$(c, d)$开始于$(0, 0)$，其中每个动作贡献$(k, k)$,$(k, -k)$， 或者$(-k, k)$。 

约束条件达到$10^9$，这排除了对值的任何状态探索或动态规划。 该问题完全与二维整数晶格在一组受限矢量方向下的结构可达性有关。 任何正确的解决方案都必须将系统减少到每个测试用例的算术条件数量恒定。 

当两个数字相等时，会出现微妙的边缘情况。 例如，$(c, d) = (6, 6)$通过选择类型 1 可以在一次操作中达到$k = 6$。 另一种边缘情况是当两者都为零时，这需要零运算，即使运算始终使用正数$k$。 假设至少需要一项操作的粗心方法将在这里失败。 

最重要的结构陷阱是假设所有整数对都是可达的。 例如，$(1, 2)$这是不可能的，因为每个操作都以强制坐标之间的线性关系的方式保留对坐标之间差异的奇偶校验约束$a + b$和$a - b$。 

## 方法

 蛮力的想法是模拟所有操作序列和所有可能的选择$k$。 即使我们将自己限制在固定的步骤数内，也可以不断地选择$k$使得这不可能进行有意义的枚举。 搜索空间的大小是无限的，长度是指数级的，因此暴力计算甚至没有明确的定义。 

关键的观察是每个操作都是线性的，因此最终结果仅取决于我们使用每个方向的次数，而不取决于顺序。 如果我们从向量的角度思考，每个操作都会添加三个基向量之一的倍数：$(1, 1)$,$(1, -1)$， 和$(-1, 1)$。 这些向量跨越二维空间，但并非所有组合在最小分解方面都独立表现。 

更有用的视图是变换坐标。 让我们定义：$$x = c + d, \quad y = c - d$$每个操作都会以非常简单的方式影响这些数量：

 - 类型 1 增加$x$经过$2k$和叶子$y$不变。 
- 类型2增加$y$经过$2k$和叶子$x$不变。 
- 3型减少$y$经过$2k$和叶子$x$不变。 

因此，每次移动都会使一个变换后的轴发生均匀的变化。 这将问题简化为使用任意正偶增量独立构造两个值，只不过我们计算的是操作次数，而不是总和。 

这种结构意味着最多需要两次操作，除非目标微不足道或完全位于这些轴之一上。 

如果两者都$c$和$d$为零，我们需要零操作。 如果$c = d$，一次操作就够了。 如果$c = -d$，类似地，一个操作就足够了，但由于两者都是非负的，所以这种情况崩溃为$c = d = 0$。 否则，该对通常需要两次操作，除非由于奇偶校验约束而不可能，这里除了简并约束之外，永远不会阻止可达性$(0,0)$案件。 

暴力方法失败是因为它试图探索序列，而最优解决方案将整个过程压缩为对两个独立线性分量的推理。

 | 蛮力 | 无限/指数 | 高| 不适用 |
 | 最佳| 每次测试 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 检查是否两者$c$和$d$为零。 在这种情况下不需要任何操作，因为我们已经从目标开始。 
2. 检查是否$c = d$。 在这种情况下，单个 type-1 操作$k = c$转变$(0,0)$直接进入$(c,c)$。 
3. 如果以上都不成立，则得出结论：两次操作就足够了。 第一个操作可以对齐一个坐标和或差，第二个操作可以校正剩余的分量。 
4. 返回计算出的最小数。 

步骤 3 背后的原因是任意$k$，我们可以独立调整向量的对称和反对称分量。 一旦我们不在一条对角线上，就需要两个自由度，但两个操作足以表达任何剩余的对。 

### 为什么它有效

 到和差坐标的转换隔离了两个独立的轴。 每个操作仅修改一个轴，同时保持另一个轴不变。 这意味着任何目标最多可以分解为两个独立的需求。 如果两个要求都为零，我们就立即完成。 如果恰好有一个要求非零，则可以一步实现。 如果两者都不为零，则两个步骤就足够了，因为可以使用单独的操作独立地满足每个轴。 

不存在少于最少所需操作的序列，因为每个操作只能影响一个独立组件，因此同时减少两个组件是不可能的，除非它们已经对齐。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    c, d = map(int, input().split())
    
    if c == 0 and d == 0:
        print(0)
    elif c == d:
        print(1)
    else:
        print(2)
```该解决方案直接实现了上面导出的分类。 唯一真正的决定是识别目标是否位于原点、对角线或平面的其他位置。 

对角线情况完全对应于单个类型 1 操作，而每个非对角线可到达点需要两次独立的调整。 

必须注意不要通过模拟或符号推理使逻辑过于复杂，因为$k$消除了任何增量建设的需要。 

## 工作示例

 考虑输入$(c, d) = (6, 6)$。 

| 步骤| c | d | 状况 |
 | --- | --- | --- | --- |
 | 1 | 6 | 6 | c = d |

 这会触发单操作情况，因为一个 type-1 移动$k = 6$直接构建目标。 

现在考虑$(c, d) = (8, 0)$。 

| 步骤| c | d | 状况 |
 | --- | --- | --- | --- |
 | 1 | 8 | 0 | 既不为零也不等于 |

 这属于两次操作类别。 一种可能的解释是首先调整总和，然后通过相反方向的操作纠正不平衡。 

这些例子说明结构仅取决于该对位于对角线上还是位于原点。

import sys, io

def solve():
    import sys
    input = sys.stdin.readline
    t = int(input())
    out = []
    for _ in range(t):
        c, d = map(int, input().split())
        if c == 0 and d == 0:
            out.append("0")
        elif c == d:
            out.append("1")
        else:
            out.append("2")
    return "\n".join(out)

    return solve()

 ## 边缘情况

 起源案例$(0,0)$是唯一不需要操作的情况。 从零开始，算法立即返回 0，与我们已经达到目标的定义相匹配。 

对角线情况例如$(10,10)$由单个操作处理。 选择$k=10$在第一个操作中产生精确的对，确认不需要进一步的调整。 

一般情况如$(7,2)$需要两次操作。 一个操作可以在和或差上创建受控的不平衡，第二个操作完成剩余的自由度。 恒定时间分类无需模拟即可正确捕获这一点。
