 ## 解决方案
 ## 问题理解

 该问题要求我们生成一个简单的文本模式。 我们得到一个整数_n_，它代表我们需要打印的行数。 第一行应包含一个星号，第二行应包含两个星号，依此类推，直到第 _n_ 行包含 _n_ 个星号。 本质上，输出是一个左对齐的星号直角三角形，高度为 _n_。 

输入约束为 1 ≤ _n_ ≤ 50。这告诉我们 _n_ 很小，任何以相对于 _n_ 的线性或二次时间运行的解决方案几乎都会立即执行。 这里不存在达到性能限制的风险，因此我们不需要考虑针对大输入大小的算法优化。 

一种微妙的边缘情况是 _n_ 等于 1 时。正确的输出是带有一个星号的单行。 使用从零或离一逻辑开始的循环的粗心解决方案可能会产生零行或无法打印单个星号。 同样，_n_ = 50 是最大输入，因此最后一行应正确包含 50 个星号。 循环边界中的任何错误计数都可能会截断该行或产生额外的星号。 

## 方法

 天真的方法很简单：从 1 迭代到 _n_，并且对于每次迭代 _i_，打印 _i_ 星号。 这是可行的，因为每行独立地仅依赖于其索引，并且对于小 _n_ 而言，构造重复字符的字符串在 Python 中是一个常量时间操作。 暴力解决方案的时间复杂度与 1 + 2 + … + _n_ 之和成正比，等于 _n_(_n_+1)/2。 对于 _n_ ≤ 50，这最多是 1275 个字符打印，这对于现代计算机来说是微不足道的。 

由于问题规模已经很小，因此不需要进一步优化。 关键的见解是认识到每一行的内容都是单个字符的简单重复，这允许 Python 中的单行使用字符串的乘法运算符。 该问题不需要数据结构或递归。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 已接受 |
 | 最佳 | O(n^2) | O(n^2) | O(n) | 已接受 |

 尽管两种方法具有相同的渐近复杂性，但“最佳”版本利用字符串重复和直接打印来使代码简洁。 

## 算法演练

 1. 从输入中读取整数_n_。 这定义了三角形中的线数。 
2. 迭代从 1 到 _n_（含）的范围。 设循环变量为_i_。 
3. 对于每个_i_，生成一个由_i_ 个星号组成的字符串。 在 Python 中，这是通过以下方式完成的`"*"`乘以_i_。 
4. 打印生成的字符串。 每次迭代打印一行，并自动附加换行符。 

为什么它有效：循环不变性是在迭代 _i_ 时，恰好打印 _i_ 个星号。 这保证了在最终迭代之后，三角形具有正确的形状，并且每行包含与其从 1 开始的索引相对应的准确数量的星号。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

for i in range(1, n + 1):
    print('*' * i)
```该代码首先使用快速 I/O 读取输入。 将输入字符串转换为整数可确保我们有正确的循环界限。 这`for`循环迭代从 1 到 _n_ 的每一行索引，生成具有正确数量的星号的字符串并立即打印它。 在 Python 中将字符串乘以整数会生成一个包含重复字符的新字符串，该字符串与所需模式匹配。 通过使用可以避免相差一错误`range(1, n + 1)`而不是`range(n)`。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n^2) | O(n^2) | 打印的字符总和为 1 + 2 + … + n = n(n+1)/2，即 O(n^2)。 |

 假设 n ≤ 50，该算法会立即执行并且使用的内存可以忽略不计。 

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    n = int(input())
    for i in range(1, n + 1):
        print('*' * i)
    return output.getvalue().strip()

# provided sample
assert run("3\n") == "*\n**\n***", "sample 1"

# custom cases
assert run("1\n") == "*", "minimum input"
assert run("50\n") == '\n'.join('*' * i for i in range(1, 51)), "maximum input"
assert run("2\n") == "*\n**", "small even number"
assert run("5\n") == "*\n**\n***\n****\n*****", "small odd number"
```| 测试输入| 预期产出 | 它验证了什么 |

 ## 边缘情况

 当 _n_ = 1 时，算法运行一次迭代，恰好打印一个星号。 这确认了代码正确处理最小输入。 对于 _n_ = 50，循环运行 50 次，每行包含正确数量的星号。 将字符串乘以循环变量可确保不会发生差一错误。 所有行均按顺序打印，保留所需的顺序。
