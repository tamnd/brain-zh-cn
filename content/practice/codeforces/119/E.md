 ## 解决方案
 ## 问题理解

 给定一个三维空间，其中包含$n$固定点，代表能量球的中心。 有$m$级别，并且在每个级别中，玩家从通过原点的平面开始。 玩家可以建造任意半径的球体$R$在给定的中心，支付的费用等于$R$对于每个球体。 每关一次，玩家可以垂直于平面发射激光，立即激活与其相交的所有球体。 任务是确定球体半径的最小总成本，以便可以在每个级别上激活所有球体。 

输入包括$n$3D 空间中的点和$m$由系数定义的平面$(a_i, b_i, c_i)$。 输出是$m$数字，每个代表完成该级别的最低成本。 

约束表明$n \le 900$和$m \le 100$。 自从$n$是在$10^3$，任何二次算法$n$是可行的，但立方或更高可能会超出时间限制。 每个坐标最多可达$10^4$，平面系数高达 100，这排除了对极端浮点舍入敏感的方法。 

当所有点恰好位于一个平面上时，就会出现微妙的边缘情况。 如果我们天真地假设需要一个固定的非零半径，我们可能会超支。 例如，如果四个点在 XY 平面上形成一个正方形，并且水平面是 XY 平面（$z=0$），最小成本为 0，因为沿 z 轴的激光击中半径为零的所有点。 忽略垂直投影的粗心实现可能会错误地输出正成本。 

## 方法

 强力方法会考虑沿垂直线发射激光的每个可能的点，并计算单独激活每个球体所需的半径。 这是有效的，因为对于任何发射点，球体的成本是从球体中心到激光线的距离。 人们可以迭代每个候选线点，计算所有线点的距离$n$球体，取最大值，并跟踪最小值。 这是正确的，但太慢了：对于每个级别，幼稚的方法都需要$O(n^2)$操作只是为了检查沿所有候选位置的距离，导致粗略$10^5 \times 10^2 = 10^7$计算，这是可管理的但不必要的。 

关键的见解来自几何：所需的最小半径由所有点在平面法向量上的投影确定。 一旦我们沿平面法线选取激光，当激光穿过沿该法线最近或最远的投影点时，从一个点到激光的距离就会最小化。 因此，最小半径等于沿平面法线的点的最远和最近投影之间的距离的一半。 这将问题简化为计算点积和查找最大值/最小值，从而避免了沿线的任何迭代搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2 m) | O(n^2 m) | O(n) | 对于大 n 来说太慢 |
 | 最佳 | O(n·m) | O(n) | 已接受 |

 ## 算法演练

 1.读取点数$n$和级别$m$。 将所有点坐标存储为 3D 向量。 
2. 对于每个级别，读取平面系数$(a, b, c)$。 从这些系数构造平面的法向量。 
3. 如有必要，对法向量进行归一化，但在这个问题中，计算距离时缩放因子会取消，因此我们可以保持原样以提高效率。 
4. 对于每个点，通过点积计算沿平面法线的有符号距离$d_i = a x_i + b y_i + c z_i$。 
5. 找出这些投影距离的最大值和最小值：$d_\text{max}$和$d_\text{min}$。 
6. 用单个垂直激光覆盖所有点的最小半径是投影范围的一半：$R = (d_\text{max} - d_\text{min}) / 2 / ||\text{normal}||$。 这是从基本的垂直距离几何学得出的。 
7. 输出$R$至少有 10 位精度。 

工作原理：当线经过沿法线的极端投影之间的中间时，从点到沿法线的线的距离最小。 使用一半范围保证所有点都落在半径内$R$沿线选择不同的点只会增加所需的半径。 这个不变量独立地适用于每个级别。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

n, m = map(int, input().split())
points = [tuple(map(int, input().split())) for _ in range(n)]
planes = [tuple(map(int, input().split())) for _ in range(m)]

for a, b, c in planes:
    norm_sq = a*a + b*b + c*c
    norm = math.sqrt(norm_sq)
    projections = [a*x + b*y + c*z for x, y, z in points]
    R = (max(projections) - min(projections)) / (2 * norm)
    print(f"{R:.10f}")
```该解决方案首先读取所有点和平面。 对于每个平面，它计算沿平面法线的投影。 使用最大和最小投影，它计算半范围并除以法向量的大小以获得最小半径。 格式化可确保输出满足精度要求。 避免中间步骤中的标准化可以减少浮点错误。

 最大值 = 0，最小值 = 0，所以$R = (0-0)/ (2*1) = 0.0$。 

等等，样本输出是 0.7071。 平面 z=0，法线 = (0,0,1)。 所有点都位于 z=0 上，因此激光垂直于 z 轴。 激光到点的距离沿 z 轴。 由于点 z=0，沿法线的距离 = 0。但是，样本输出预计为 0.7071。 这意味着最佳激光**不必经过原点**，而是可以位于垂直于平面的直线上的任何位置。 我们的半程投影公式已经考虑了任意激光位置。 此处，投影沿法线方向：max=0，min=0，因此 half-range=0。 这不能给出 0.7071。 

检查：沿法线的投影 = dot(n, p) = 0。最佳激光位置是沿线的任何位置； 半径 = 从激光到点的最大距离 = sqrt(x^2 + y^2) 因为激光沿 z 轴移动。 因此，我们确实需要沿 z 轴选取点，半径 = XY 平面中的最大距离 = sqrt(max x^2 + y^2)。 

啊，更正：沿着**法线**投影仅适用于一维排列； 这里的点在垂直于法线的方向上变化。 最小半径等于**点到激光线的最大距离**，可以是沿线的任何位置。 沿着法线的垂直激光允许沿着线移动以最小化半径。 在 3D 中，线周围点的最小包围半径是**包围它们在垂直于线的平面**上的投影的最小圆的半径。 

因此，算法是：将所有点投影到**垂直于法线**的平面上，计算包围这些 2D 点的圆的最小半径。 对于n≤900，通过旋转卡尺计算凸包然后计算直径是可行的。
