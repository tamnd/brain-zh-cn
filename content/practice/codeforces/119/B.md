 ## 解决方案
 ## 问题理解

 我们有`n`定理，每个定理都有一个指定的熟练度值。 考试内容准确无误`k`不同的卡。 每张卡片都包含准确的内容`floor(n / k)`不同的定理，并且没有定理出现在多于一张卡片中。 一些定理可能仍然未被使用，如果`n`不能被整除`k`。 

一些学生已经在他们的卡片上透露了确切的定理集。 这些亮出的卡片保证是有效的，并且相同的卡片可能会出现多次，因为不同的学生可以抽到同一张卡片。 

Vasya 可能会收到以下任何一项`k`牌。 一些牌已经从报告中得知，而其余的牌则未知。 我们必须计算瓦西亚仍然可以收到的所有卡牌中最小和最大可能的平均熟练度，考虑到未知卡牌的每一次有效完成。 

限制非常小。 两个都`n`且举报卡数最多为`100`。 这意味着即使是二次或三次算法也是完全安全的。 对所有定理分区进行穷举搜索仍然是不可能的，因为分区集合的方法数量增长得非常快，但任何基于排序或贪婪分配的东西在限制内都是微不足道的。 

棘手的部分是了解哪些信息真正重要。 我们不知道确切的未知卡，只知道每个定理最多属于一张卡，并且每张卡都有固定的大小。 粗心的实现可能会错误地假设每个未见定理都可以与其他未见定理任意组合。 这是错误的，因为卡必须形成一个分区。 

考虑这个例子：```
6 2
1 2 3 100 100 100
1
1 2 3
```每张卡片都有尺寸`3`。 一张牌是已知的：`{1,2,3}`。 剩余的卡必须包含`{4,5,6}`。 最小值和最大值都是`100`。 如果我们忽略分区结构并尝试任意子集，我们可能会错误地认为平均值如下`(1+2+100)/3`是可能的。 

当报告中重复某些卡片时，会发生另一种微妙的情况：```
4 2
1 2 10 20
2
1 2
2 1
```这两份报告描述了同一张卡。 仍然只有一张已知的牌，而不是两张。 一个有缺陷的解决方案，独立计算两者，会认为没有剩下未知的牌。 

最后一个重要的边缘情况是`n`不能被整除`k`。```
7 3
1 2 3 4 5 6 7
0
```每张卡片的尺寸为`2`，所以只有`6`定理用于卡片中。 有一个定理仍未被使用。 最大化平均值的最佳策略是丢弃最小的定理并从最大的剩余对构建一张卡片。 为了最小化，我们放弃最大定理。 

## 方法

 一个蛮力的想法是将定理的每个有效分区生成到卡片中，然后计算所有可能的卡片平均值。 从概念上讲，这是可行的，因为约束很小，但分区数量会以组合方式爆炸。 均匀劈裂`100`将元素分成大小约为`50`是一个天文数字。 无论进行多少修剪都无法挽救这种方法。 

关键的观察是所有未知卡牌的确切组成并不重要。 我们只关心单张牌的最小和最大可能的平均值。 

假设每张卡片包含`m = floor(n / k)`定理。 有些定理已经被固定，因为它们出现在已知的卡片中。 其余的定理可以以任何有效的方式自由地分布在未知卡中。 

为了最小化 Vasya 的可能平均值，我们希望一张未知卡包含最小的可用定理值。 由于所有未知卡片的大小都相同`m`，未知卡片之间的最小可能平均值就是简单的平均值`m`最小未使用的定理值。 

类似地，未知牌的最大可能平均值是`m`最大未使用的定理值。 

我们还必须与已知的牌进行比较，因为瓦西亚也可能收到其中一张牌。 他们的平均值是固定的并且已经可以实现。 

这将问题简化为简单的簿记：

 1. 识别所有不同的已知卡片。 
2. 将这些卡片中出现的所有定理标记为已使用。 
3. 计算已知牌的平均值。 
4. 对未使用的定理值进行排序。 
5. 从极端贪婪地构建最好和最差的未知牌。 

贪心选择之所以有效，是因为除了不相交之外，未知卡之间没有其他约束。 如果我们希望一张卡尽可能小，那么采用全局最小的可用值始终是最佳选择。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读`n`和`k`，然后计算`m = n // k`，这是每张卡的定理数量。 
2. 将所有定理熟练度值读入数组中。 
3. 处理报告卡。 由于同一张卡片可能会以不同的顺序出现多次，因此对每个卡片表示进行排序并将其存储在一个集合中以仅保留不同的卡片。 
4. 对于每张不同的已知卡：

 1. 计算其平均熟练程度。 
2. 使用该平均值更新全局最小和最大答案。 
3. 将其所有定理标记为已使用。 

这些牌保证是可能的，因为它们被明确观察到。 
5. 将所有未使用的定理值收集到一个单独的数组中并对其进行排序。 
6.让`remaining_cards`是未知牌的数量：`remaining_cards = k - number_of_distinct_known_cards`。 
7. 如果至少有一张未知牌：

 1. 最小可能的未知牌平均值通过取`m`最小未使用值。 
2. 最大可能的未知卡平均值通过取`m`最大未使用值。 
3. 使用这些值更新全局最小和最大答案。 
8. 打印最终的最小值和最大值。 

### 为什么它有效

 已知的卡片是固定的并且必须完全按照观察的方式保持。 每个未使用的定理只属于未知卡，而未知卡的唯一限制是它们将未使用的定理分成不同大小的组`m`。 

为了最小化某些未知卡片的平均值，该卡片中包含的任何定理都应尽可能小。 用较小的未使用定理替换任何选定的定理只能降低平均值。 重复这个交换论证最终会产生由全局最小的卡片组成的卡片`m`未使用的值。 

同样的论点对称地适用于使用最大值的最大值。 

由于将未使用的定理划分为相同大小的组都是有效的，因此这些极值卡始终是可构造的。 因此，该算法计算出精确的可实现的最小和最大平均值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    q = int(input())

    unique_cards = set()

    for _ in range(q):
        card = tuple(sorted(map(int, input().split())))
        unique_cards.add(card)

    m = n // k

    used = [False] * n

    INF = float('inf')
    mn = INF
    mx = -INF

    for card in unique_cards:
        total = 0

        for x in card:
            total += a[x - 1]
            used[x - 1] = True

        avg = total / m

        mn = min(mn, avg)
        mx = max(mx, avg)

    remaining = []

    for i in range(n):
        if not used[i]:
            remaining.append(a[i])

    remaining.sort()

    unknown_cards = k - len(unique_cards)

    if unknown_cards > 0:
        low_avg = sum(remaining[:m]) / m
        high_avg = sum(remaining[-m:]) / m

        mn = min(mn, low_avg)
        mx = max(mx, high_avg)

    print(f"{mn:.10f} {mx:.10f}")

solve()
```第一个重要的细节是重复报告卡的删除。 两个学生可能会收到同一张卡片，并且输入行内的定理顺序是任意的。 对定理索引进行排序并将它们作为元组存储在集合中给出了规范表示。 

第二个微妙点是仅从不同的卡片中标记所使用的定理。 如果我们独立处理重复的报告，我们可能会错误地认为固定的定理比实际固定的定理多。 

剩余未使用的定理值足以表征每张未知卡牌。 由于所有未知卡片的大小都相同，因此最小平均值来自最小的卡片`m`值和最大值中的最大值`m`。 

该算法直接使用浮点除法，因为所需的精度仅为`1e-6`。 蟒蛇的`float`绰绰有余。

```该跟踪表明必须同时考虑已知卡和未知卡。 观察到的卡片中已经存在最好的卡片。

 ## 边缘情况

 ### 重复的卡报告

 输入：```
4 2
1 2 10 20
2
1 2
2 1
```每张卡片的尺寸为`2`。 

两份报告都描述了排序后的同一张卡片。 该算法仅存储一张不同的卡。 

已知卡牌平均值：```
(1 + 2) / 2 = 1.5
```未使用的值：```
10 20
```未知卡平均：```
15
```最终答案：```
1.5000000000 15.0000000000
```如果没有重复数据删除，程序会错误地认为所有卡都是已知的。 

### 剩余未使用的定理

 输入：```
7 3
1 2 3 4 5 6 7
0
```每张卡包含`2`定理，所以只有`6`定理参与卡片。 

该算法对未使用的值进行排序，并仅采用最小或最大的值`2`构建极值卡时的值。 一个定理自然会被忽略，因为它不能属于任何卡牌。 

最低限度：```
(1 + 2) / 2 = 1.5
```最大限度：```
(6 + 7) / 2 = 6.5
```This matches the actual feasible partitions.

 ### All cards already known

 输入：```
6 3
1 2 3 4 5 6
3
1 2
3 4
5 6
```所有三张不同的卡都已修复。 

Their averages are:```
1.5, 3.5, 5.5
```没有剩下未知的牌，因此算法跳过贪婪构建步骤。 

最终答案：```
1.5000000000 5.5000000000
```这证实了该解决方案不会意外地使用不存在的未知卡。
