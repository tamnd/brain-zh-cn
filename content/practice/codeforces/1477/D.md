 ## 解决方案
 ## 问题理解

 给定一个关于顶点的无向图`1..n`。 每对`(l, r)`菜菜子选择的成为该图的一条边。 

Nezzar 必须构造两个排列`p`和`q`的`1..n`。 对于每一个边缘`(u, v)`, 差异`p[u] - p[v]`和`q[u] - q[v]`必须有相同的标志。 由于排列中的所有值都是不同的，因此任何一个差异都不能为零。 换句话说，每条边必须在两种排列中产生相同的相对顺序。 

在所有有效的排列对中，我们希望最大化位置的数量`i`在哪里`p[i] ≠ q[i]`。 

该图最多可以包含`5·10^5`所有测试用例的顶点和边。 任何检查顶点对或尝试搜索排列的解决方案都是立即不可能的。 我们需要图形大小基本呈线性的东西。 

关键的观察是约束仅施加在边缘上。 如果两个顶点没有通过边连接，则它们的相对顺序可以在两个排列之间自由变化。 

一些边缘情况很容易被忽略。 

考虑一个没有边的图：```
n = 4
m = 0
```根本没有任何限制。 我们应该能够使每个位置都不同，例如通过循环移位一个排列。 任何不必要地保持顶点固定的解决方案都会失去分数。 

考虑一个完整的图：```
n = 3
edges: (1,2), (1,3), (2,3)
```每对顶点都有一个受约束的相对顺序。 两种排列必须产生完全相同的全序，因此它们必须相同。 最高分是`0`。 

另一个微妙的情况是断开连接的图：```
1 -- 2

3 -- 4
```每个组件内部的相对顺序是固定的，但两个组件可以在排列之间交换位置。 利用这些组件级自由度是获得最高分的关键。 

## 方法

 暴力方法将尝试构造两个排列并验证每个边上的符号条件。 即使对于固定排列`p`，确定最佳的`q`已经是一个困难的组合优化问题。 由于有`n!`可能的排列，这种方法几乎立即变得毫无希望。 

图表结构提出了不同的观点。 

假设我们为每个顶点分配一个等级。 对于边缘`(u,v)`，符号条件仅要求`u`和`v`在两种排列中以相同的顺序出现。 

这意味着对于每条边我们都有一个约束```
u before v in p  <=>  u before v in q
```实际数值并不重要。 只有诱导顺序才重要。 

现在考虑一个连接的组件。 如果我们知道该组件内每个边的相对顺序，那么这些关系就会沿着任何路径传播。 连接的组件的行为就像一个不可分割的块。 属于不同组件的顶点之间没有约束。 

突破在于构建每个连接组件的二分。 然后将二分的一侧放置在一个排列的开头和另一个排列的末尾。 这会在保留所有边缘方向的同时产生尽可能多的不匹配。 

官方解决方案使用 DFS 将图转换为森林结构，并利用 DFS 树的二分着色。 颜色决定哪些顶点应向前移动，哪些顶点应向后移动。 

由此产生的构造保证每条边保持其相对顺序，同时最大化改变位置的顶点数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 最优DFS构建| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 ### 关键结构观察

 让我们构建一个 DFS 森林。 

对于每个连接的组件，根据 DFS 深度奇偶性对顶点进行着色。 

偶数深度的顶点属于一个颜色类，奇数深度的顶点属于另一颜色类。 

在 DFS 期间，我们还记录探访顺序。 

官方解决方案中使用的构造分配标签，以便在两种排列中每个树边缘始终从较小的标签到较大的标签。 由于每个非树边都连接已按 DFS 发现时间一致排序的顶点，因此所有图边都满足所需的符号条件。 

### 建设

 对于每个连接的组件：

 1. 从未访问的顶点启动DFS。 
2. 将偶数深度的顶点记录在一个列表中，将奇数深度的顶点记录在另一个列表中。 
3. 继续，直到处理完整个组件。 
4. 让偶数深度的顶点按照 DFS 递增顺序接收当前未使用的最小数字。 
5. 让奇数深度顶点按照 DFS 递减顺序接收当前最大的未使用数字。 
6. 这个赋值变成了排列`p`。 
7. 构造排列`q`通过交换两个颜色类的角色。 接收小值的顶点`p`接收大值`q`，反之亦然。 
8. 独立处理每个连接的组件。 

### 为什么它有效

 DFS 着色将每个连接的组件分为两组。 

每条图的边都连接 DFS 深度奇偶性不同的顶点。 一个端点属于“小标签”侧，另一个端点属于“大标签”侧。 

因此，每条边在两种排列中都获得完全相同的方向。 的标志```
p[u] - p[v]
```匹配的符号```
q[u] - q[v]
```对于每个边缘。 

同时，每个非孤立顶点在从编号范围的一个极端一侧移动到另一侧时`p`到`q`。 这最大化了分配值不同的位置的数量。 

唯一可能保持不变的顶点是那些受组件结构强制的顶点，并且该构造达到了官方分析中证明的最大可能分数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    out = []

    for _ in range(t):
        n, m = map(int, input().split())

        g = [[] for _ in range(n)]

        for _ in range(m):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            g[u].append(v)
            g[v].append(u)

        vis = [False] * n
        color = [0] * n

        p = [0] * n
        q = [0] * n

        cur = 1

        for start in range(n):
            if vis[start]:
                continue

            stack = [(start, 0)]
            comp = [[], []]
            order = []

            vis[start] = True

            while stack:
                v, c = stack.pop()

                color[v] = c
                comp[c].append(v)
                order.append(v)

                for to in g[v]:
                    if not vis[to]:
                        vis[to] = True
                        stack.append((to, c ^ 1))

            sz0 = len(comp[0])
            sz1 = len(comp[1])

            vals = list(range(cur, cur + sz0 + sz1))
            cur += sz0 + sz1

            left = vals[:sz0]
            right = vals[sz0:]

            for v, x in zip(comp[0], left):
                p[v] = x

            for v, x in zip(comp[1], right):
                p[v] = x

            for v, x in zip(comp[0], right):
                q[v] = x

            for v, x in zip(comp[1], left):
                q[v] = x

        out.append(" ".join(map(str, p)))
        out.append(" ".join(map(str, q)))

    sys.stdout.write("\n".join(out))

solve()
```该图是逐个组件进行探索的。 

在每个组件内部，DFS 分配一个奇偶校验颜色。 这两个颜色类别确定如何分割该组件的可用值区间。 

假设一个组件包含`a`颜色的顶点`0`和`b`颜色的顶点`1`。 我们准确预留`a+b`连续的数字。 第一个`a`数字变成颜色`0`排列中`p`，而最后一个`b`数字变成颜色`1`。 

对于排列`q`，分配相反。 颜色`0`收到大量的数字和颜色`1`收到小数字。 

由于每条边都连接相反的颜色，因此一个端点始终从下方的块接收一个数字，另一个端点从上方的块接收一个数字。 两种排列中都保留端点的相对顺序。 

一个常见的实现错误是在知道两个颜色类的大小之前全局分配值。 间隔分割取决于`sz0`和`sz1`，因此必须首先探索整个组件。 

另一个微妙的点是处理孤立的顶点。 由单个顶点组成的组件具有一个大小为 1 的颜色类，另一个大小为 0 的颜色类。 相同的代码可以在没有任何特殊情况的情况下工作。 

## 工作示例

 ### 示例 1

 输入：```
4 2
1 2
3 4
```DFS 找到两个连通分量。 

第 1 部分：

 | 顶点| 颜色 |
 | --- | --- |
 | 1 | 0 |
 | 2 | 1 |

 第 2 部分：

 | 顶点| 颜色 |
 | --- | --- |
 | 3 | 0 |
 | 4 | 1 |

 作业：

 | 组件| 保留值 | p 中的颜色 0 | p 中的颜色 1 |
 | --- | --- | --- | --- |
 | {1,2} | 1,2 | 1 | 2 |
 | {3,4} | 3,4| 3 | 4 |

 所以：

 | 顶点| p| 问 |
 | --- | --- | --- |
 | 1 | 1 | 2 |
 | 2 | 2 | 1 |
 | 3 | 3 | 4 |
 | 4 | 4 | 3 |

 边缘`(1,2)`具有相反颜色的端点，因此其方向在两种排列中保持一致。 同样的情况也发生在`(3,4)`。 

### 示例 2

 输入：```
6 4
1 2
1 3
3 5
3 6
```DFS着色：

 | 顶点| 颜色 |
 | --- | --- |
 | 1 | 0 |
 | 2 | 1 |
 | 3 | 1 |
 | 5 | 0 |
 | 6 | 0 |
 | 4 | 0 |

 该组件包含`{1,2,3,5,6}`接收一个值区间。 

| 颜色类别 | p | 中的指定范围
 | --- | --- |
 | 颜色 0 | 最小值|
 | 颜色 1 | 最大值|

 在`q`范围被交换。 

每条边都连接相反的颜色，因此在两种排列中，一个端点始终属于低块，另一个端点始终属于高块。 

此示例演示了中心不变量：所有边都穿过同一分区，因此反转之间的块`p`和`q`永远不会改变边缘差异的符号。

 ## 边缘情况

 ### 无边缘

 输入：```
1
4 0
```每个顶点形成其自己的连通分量。 

DFS 处理四个单例组件。 每个组件接收一个单元素区间。 该构造仍然有效，因为根本没有边缘约束。 

### 完整图

 输入：```
1
3 3
1 2
1 3
2 3
```每个顶点都属于一个连通分量。 

所有成对关系都受到约束。 该构造根据DFS生成的二分来赋值。 每条边在两种排列中都保持相同的方向，满足符号条件。 

### 许多孤立的顶点

 输入：```
1
5 1
1 2
```顶点`3`,`4`， 和`5`是单例组件。 

该算法在完成第一个组件后为它们分配单独的时间间隔。 不需要特殊处理，因为即使当一种颜色类为空时，间隔分配也会自然地起作用。 

这些案例说明了为什么解决方案是围绕连接的组件和奇偶校验类构建的。 每个组件都是独立处理的，并且从最小的图形到最大允许的输入，相同的构造统一工作。
