 ## 解决方案
 ## 问题理解

 我们给出了一组$n$具有浮点坐标的 2D 平面上的点。 任务是找到绕原点旋转的最小可能角度，以确保所有点都可以被半平面（将平面分为两部分的直线）覆盖。 同样，如果您想象从原点发出一束光，您想要旋转它，使所有点都位于光束的一侧，而目标是最小化实现这一目标的旋转角度。 

输入最多 1000 个点，坐标在 -1000 到 1000 之间，保留两位小数。 这意味着浮点精度是相关的，但我们不必担心超出双精度浮点提供的极大数字或精度。 1秒的时间限制表明$O(n^2 \log n)$解决方案是可行的，但是$O(n^3)$解决方案可能会太慢。 

当多个点与原点共线时，会出现不明显的边缘情况。 例如，如果所有点都位于正 x 轴上，则最小旋转角度为 0。另一个棘手的情况是当点围绕原点均匀分布在圆中时； 仅检查轴对齐方向的简单方法可能会低估所需的角度。 点在相反方向聚集的情况必须小心处理，因为最小半平面可能会排除小簇。 

## 方法

 强力方法是尝试每对可能的点来定义半平面的候选方向。 对于每个候选方向，我们将检查所有点以计算覆盖它们所需的最小旋转。 这是正确的，因为半平面的最佳边界必须通过至少一个点。 然而，该方法涉及$O(n^3)$最坏情况下的操作：对于每个$n^2$候选人方向，我们检查$n$点，这对于$n=1000$。 

关键的观察结果是问题简化为相对于原点的角度。 每个点都可以表示为一个角度，使用`atan2(y, x)`。 最小半平面对应于覆盖所有点的最小角度间隔。 对角度进行排序使我们能够将其视为圆形间隔问题：我们可以迭代排序的角度，将每个角度视为半平面的潜在起点，并找到适合 180 度扫描的最大角度。 这大大降低了复杂性，因为排序需要$O(n \log n)$扫描可以在$O(n)$采用两指针方法。 

蛮力之所以有效，是因为它明确地考虑了所有点对，但在以下情况下会失败：$n$由于立方增长而很大。 认识到每个点围绕原点的角度就足够了，这使我们能够使用对已排序的角度数组进行线性扫描来解决问题，并利用角度的圆形结构和模运算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(n) | 太慢了 |
 | 角度扫描 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 使用以下公式计算每个点相对于原点的角度`atan2(y, x)`。 这将每个点转换为之间的单个标量角度$-π$和$π$。 使用角度将二维几何问题简化为一维圆形问题。 
2. 按升序对角度数组进行排序。 排序确保我们可以有效地找到覆盖所有点的连续角度间隔。 
3. 通过添加来复制角度数组$2π$到每个角度并将其附加到排序数组的末尾。 这处理了循环环绕，因此我们可以检查跨越的间隔$-π/π$没有特殊逻辑的边界。 
4.初始化两个指针，`i`和`j`，都从 0 开始。`i`代表半平面的起点，并且`j`将向前扫描以找到 180 度间隔内的最远点`i`。 
5. 对于每个`i`， 进步`j`只要角度差`angles[j] - angles[i]`小于或等于π。 最大差值给出了从 开始的半平面所覆盖的最大间隔`angles[i]`。 
6. 计算 360 度的补角（或$2π$弧度）通过采取$2π - \text{max interval}$。 跟踪所有的最小补集`i`。 这个最小补集是确保所有点都在半平面内的最小旋转。 

原理：包含所有点的每个半平面都可以表示为单位圆上最多 π 弧度的区间。 对角度进行排序可确保使用两指针技术扫描捕获最大的间隔。 通过计算补数，我们找到所需的最小旋转角度。 任何点的配置都不能产生更小的旋转，因为每个点都位于单位圆上，并且最大的角度间隙决定了最小的旋转。 

## Python 解决方案```python
import sys
import math
input = sys.stdin.readline

n = int(input())
angles = []

for _ in range(n):
    x, y = map(float, input().split())
    angles.append(math.atan2(y, x))

angles.sort()
angles += [angle + 2 * math.pi for angle in angles]

ans = 0.0
j = 0

for i in range(n):
    while j < 2 * n and angles[j] - angles[i] <= math.pi + 1e-12:
        j += 1
    ans = max(ans, angles[j - 1] - angles[i])

print(f"{2 * math.pi - ans:.10f}")
```代码首先读取所有点并将它们转换为角度。 排序允许用两个指针进行扫描。 复制数组可以处理循环环绕，因此我们不需要用于跨越 -π/π 边界的间隔的特殊逻辑。 这`1e-12`容差可防止精确边界处的浮点错误。 最终答案将最小旋转打印为$2π - \text{largest interval}$。

import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    angles = []
    for _ in range(n):
        x, y = map(float, input().split())
        angles.append(math.atan2(y, x))
    angles.sort()
    angles += [angle + 2 * math.pi for angle in angles]
    ans = 0.0
    j = 0
    for i in range(n):
        while j < 2 * n and angles[j] - angles[i] <= math.pi + 1e-12:
            j += 1
        ans = max(ans, angles[j - 1] - angles[i])
    return f"{2 * math.pi - ans:.10f}"
