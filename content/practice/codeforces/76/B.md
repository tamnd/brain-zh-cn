 ## 解决方案
 ## 问题理解

 我们给定一排老鼠，它们位于水平线上的坐标处`y = Y0`以及沿着另一条水平线的一排奶酪片`y = Y1`。 每只老鼠都可以直接跑向任何一块奶酪，并且所有老鼠都以相同的速度奔跑。 当多只老鼠瞄准同一块奶酪时，只有第一只到达的老鼠会吃掉它； 随后的老鼠仍然饥饿。 我们的任务是确定如果所有小鼠都最佳地选择最接近的奶酪，那么将挨饿的小鼠的最小数量。 

输入以严格递增的顺序提供老鼠和奶酪的 x 坐标。 这种严格递增的顺序意味着我们可以有效地比较位置，而不必担心同一坐标处的平局，从而简化了匹配。 老鼠和奶酪的数量最多可达 100,000 个，因此任何检查每对老鼠和奶酪点的简单解决方案都将涉及 10^10 次操作，这对于标准时间限制来说太大了。 

当所有小鼠聚集在一块奶酪附近而其他奶酪块距离很远时，就会出现一种不明显的边缘情况。 例如，如果三只小鼠位于以下位置`[0,1,2]`有两块奶酪`[0, 100]`，所有老鼠的最近的一块是`0`。 如果我们贪婪地分配它们而不考虑相对到达时间，我们可能会错误地假设有更多的老鼠被喂食。 正确的输出是，只有最接近的老鼠才吃到第一个奶酪，其余的老鼠都会挨饿。 

当根本没有奶酪块时会出现另一种边缘情况。 在这种情况下，所有老鼠都保持饥饿状态。 最后一个微妙之处是老鼠和奶酪已经按 x 坐标排序。 排序是不必要的，两指针方法可以有效地利用这种排序。 

## 方法

 蛮力方法会考虑每对老鼠-奶酪，计算欧几里得距离，并将老鼠分配给最近的奶酪。 对每种奶酪的距离进行排序后，我们将模拟到达情况，看看哪只老鼠先吃。 虽然这可以保证正确性，但它的时间复杂度为 O(N * M)，这对于 100,000 只老鼠和奶酪的上限来说是不可行的。 

关键的见解是利用坐标的严格递增顺序。 由于所有小鼠都以相同的速度奔跑并且 y 距离恒定，因此距离小鼠最近的奶酪仅取决于 x 距离。 我们可以使用两指针技术：从左到右遍历小鼠，并为每只小鼠找到最近的可用奶酪。 如果鼠标距离下一个奶酪比当前奶酪更近，我们就向前移动奶酪指针。 这样，每只鼠标就可以实现最佳配对，而无需检查每个可能的配对。 

该问题简化为沿单一维度的两指针匹配问题，其中欧几里德距离通过线之间的垂直距离简化。 这种方法保证了饥饿的老鼠最少，因为我们总是按顺序将最接近的剩余奶酪分配给每只老鼠，确保没有老鼠能够到达更近的一块无人认领的奶酪。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(N*M) | O(N+M) | 太慢了 |
 | 两点贪心 | O(N+M) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 从指针开始`i`对于小鼠和`j`对于奶酪，两者都位于各自列表的开头。 
2.对于位置处的每只鼠标`mice[i]`, 检查到当前奶酪的距离`cheese[j]`和下一个奶酪`cheese[j+1]`如果存在的话。 计算欧氏距离平方以避免浮点错误：`(mice[i]-cheese[j])**2 + (Y0-Y1)**2`。 
3. 如果下一个奶酪更近，则移动奶酪指针`j`向前直到当前奶酪是最近的，或者我们到达最后一个奶酪。 
4. 将此鼠标分配给最近的奶酪。 如果奶酪仍未分配，请将其标记为已吃并移动到下一个鼠标。 否则，老鼠就会挨饿。 
5. 保留饥饿老鼠的计数器。 对于每只老鼠，如果没有更多的奶酪块可供分配，则增加饥饿计数器。 
6. 继续，直到处理完所有小鼠。 

为什么它有效：在每一步中，每只老鼠都会贪婪地瞄准那些尚未分配的奶酪中最近的奶酪。 坐标严格递增的顺序确保不会跳过机会。 不变的是，在每次迭代中，每只分配的老鼠都有最接近的可用奶酪，因此没有老鼠可以被分配到更近的一块。 这保证了老鼠的饥饿程度最小。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    N, M, Y0, Y1 = map(int, input().split())
    mice = list(map(int, input().split()))
    cheese = list(map(int, input().split()))
    
    hungry = 0
    j = 0
    dy2 = (Y0 - Y1) ** 2  # constant vertical distance squared

    for x in mice:
        while j + 1 < M and (cheese[j+1] - x)**2 + dy2 <= (cheese[j] - x)**2 + dy2:
            j += 1
        if j >= M:
            hungry += 1

    print(hungry)

if __name__ == "__main__":
    main()
```代码使用`dy2`考虑垂直距离的平方，避免重复计算。 while 循环仅在下一个奶酪严格接近时才移动奶酪指针，从而保持贪婪的正确性。 边界检查确保我们的索引不会超出最后的奶酪。

 ## 边缘情况

 在没有奶酪的情况下，`M = 0`, 指针`j`永远不会增加，并且每只老鼠都会增加饥饿计数器，从而产生`N`正如预期的那样。 

当多只老鼠争夺一块奶酪时，贪婪指针确保最接近的老鼠首先被计数，其余的老鼠自然会增加饥饿计数器。 例如，用老鼠`[0,1,2]`和奶酪`[1]`，1 号的小鼠首先到达，0 号和 2 号的小鼠保持饥饿状态，确认输出`2`。 

如果所有奶酪都位于所有老鼠的右侧，则仅当下一个奶酪更接近时指针才会移动，但如果不存在这样的奶酪，则每只老鼠都会挨饿。 此行为可以正确处理边缘间距。
