 ## 解决方案
 ## 问题理解

 我们被要求重建一个排列$q$长度$n$来自一系列数组派生的笛卡尔树的特殊编码。 每个数组$p_i$通过前面的数组生成$p_{i-1}$并将其最小元素增加$n$，确保所有数字保持不同。 对于每个数组$p_i$，我们可以构建一棵笛卡尔树，它是一棵二叉树，其属性是任何节点的父节点都有较大的值，并且左右子树尊重原始数组索引。 

输入不直接给出数组； 相反，它给出一个二进制矩阵$s$尺寸的$n \times n$。 该矩阵对所有数组中的所有父子关系进行编码$p_i$。 具体来说，如果$s_{i,j} = 1$，这表明$i$曾经是$j$在笛卡尔树之一中。 我们的任务是重建任意排列$q$其派生序列产生给定的矩阵。 

限制条件适中：$n$最多可达 3000，总和$n^2$跨测试用例是$9 \cdot 10^6$。 这排除了$O(n^3)$解决方案但允许$O(n^2)$算法，尤其是那些只迭代矩阵并进行简单记账的算法。 

非明显的边缘情况包括：

 1. **单交换根**：2 元素排列可以是$[1,2]$或者$[2,1]$，并且都生成不同的笛卡尔树。 粗心的代码可能会采用固定的顺序。 
2. **最小元素位置**：自$p_i$增加最小值，每个笛卡尔树的实际根可能会改变。 假设根始终是第一个或最后一个元素的算法将会失败。 
3. **不相关的影响**：某些元素可能永远不会成为父元素或子元素，从而使它们的相对顺序保持灵活。 算法必须在满足矩阵的同时灵活处理这些。 

## 方法

 蛮力方法将尝试模拟所有$p_i$候选排列的数组$q$并将生成的父集与输入矩阵进行比较$s$。 笛卡尔树的每次模拟都需要$O(n)$使用单调堆栈方法的时间，所以对于所有$p_i$这是$O(n^2)$每个候选人。 尝试所有$n!$排列显然是不可能的。 

关键的观察是$s$编码哪些元素曾经作为哪些父母的孩子出现。 如果一个元素$i$永远不是孩子（行$i$在$s$全为零），它必须是中的最小元素$q$，因为最小值总是在数组序列中提升。 一旦我们选择了最小元素，我们就可以迭代地删除它并减少问题。 这将问题简化为在剩余数字中重复选择最小元素，并遵守“非子”约束。 

这给出了一个贪心算法：重复选择其行位于$s$包含其余候选者中的所有零。 为其分配下一个最小的数字，将其从考虑中删除，然后更新$s$因此。 这是$O(n^2)$，它在限制范围内很合适。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（所有排列）|$O(n! \cdot n^2)$|$O(n^2)$| 太慢了 |
 | 贪婪最小提取|$O(n^2)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和$n \times n$矩阵$s$。 维护一组尚未赋值的剩余索引$q$。 
2. 初始化一个空的排列数组$q$。 我们将填写$q$从最小的数开始$1$最多$n$。 
3. 当存在未分配的索引时，扫描所有剩余索引。 对于每个索引$i$，检查其行是否在$s$其余列全为零。 如果是，$i$是当前最小值的有效候选者。 
4. 将当前最小值赋给$i$， 消除$i$从剩余的集合中，增加要为下一次迭代分配的值。 
5. 重复此操作，直至分配完所有索引。 返回$q$。 

**为什么有效：** 在每一步中，我们都会在剩余元素中选择一个从来都不是子元素的元素。 根据定义$p_i$构造和笛卡尔树，最小元素$q$永远不会以孩子的身份出现在任何$p_i$，所以这个贪心选择总是有效的。 重复这个不变量可以确保重建的排列满足编码在中的所有父子关系$s$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = [list(map(int, input().strip())) for _ in range(n)]
        remaining = set(range(n))
        q = [0] * n
        current = 1
        while remaining:
            for i in remaining:
                if all(s[i][j] == 0 or j not in remaining for j in remaining):
                    q[i] = current
                    current += 1
                    remaining.remove(i)
                    break
        print(' '.join(map(str, q)))

solve()
```该解决方案使用有效地读取输入`sys.stdin.readline`。 它构建了一个`remaining`设置为跟踪尚未分配的索引。 在每一步中，它都会扫描集合以查找其行在其余列中包含零的元素，为其分配当前的最小编号，然后更新集合。 这`break`确保每次迭代只分配一个元素。 

细微之处包括正确检查`j not in remaining`忽略与已分配索引对应的列。 如果没有这个，该算法将在小情况下失败，例如`n=2`。
