 ## 解决方案
 ## 问题理解

 我们被要求在有向图上分析两人游戏$n$顶点。 该图几乎是一条链：对于每个顶点$u$从 1 到$n-1$，有一条边$u \to u+1$。 除此之外，还有$m$向前延伸的额外边缘，从$u_i$到$v_i$，它们永远不会相互“交叉”，因为没有两条边满足$u_i < u_j < v_i < v_j$。 此属性意味着额外的边形成嵌套或非重叠结构，本质上是数轴上的一组间隔。 

杰瑞先移动，并被迫沿着向外的边缘移动，而汤姆可以沿着边缘移动或保持静止。 如果他们在回合结束时占据同一个顶点，汤姆就获胜。 如果杰瑞到达顶点，他就获胜$n$而不被抓住。 

功能$f(x, y)$要求：从杰瑞开始$x$和汤姆在$y$，假设双方都采取最佳策略，汤姆必须采取的最少步数是多少才能保证获胜？ 如果汤姆不能保证获胜，$f(x,y) = 0$。 最后的任务是计算总和$f(x, y)$全面的$x \neq y$。 

限制很高：$n$可以达到$2 \cdot 10^5$和总计$n$跨测试用例也是$2 \cdot 10^5$。 这排除了任何$O(n^2)$解决方案。 额外边的关键属性（没有两个交叉间隔）强烈建议采用贪婪或基于间隔的方法，而不是完整的图模拟。 

当 Jerry 开始时，就会出现边缘情况$n$，或者当汤姆最初位于顶点时，杰瑞必须立即通过。 例如，与$n=2$并且没有多余的边缘，$x=1, y=2$，杰瑞移动到2，汤姆可以等待——汤姆不移动就获胜。 幼稚的模拟可能会错误地假设汤姆必须移动，从而产生错误的结果$f(x,y)$。 

## 方法

 天真的方法会模拟所有人的所有游戏$n(n-1)$对。 对于每一对，我们可以尝试两名玩家的所有可能的动作序列，以确保汤姆发挥最佳状态。 这在理论上是正确的，但不切实际：最多有$4 \cdot 10^{10}$单个测试用例的操作$n = 2 \cdot 10^5$，使其完全不可行。 

最佳方法取决于对图结构的理解。 每个顶点在链中都有一个“下一个”顶点，并且嵌套了额外的边。 如果我们定义$r[i]$杰瑞可以到达的最远顶点$i$在不被 Tom 拦截的情况下，我们可以从右到左贪婪地计算它。 汤姆的最佳策略简化为“移动到阻止杰瑞所需的最右边的顶点”，并且由于嵌套的间隔，汤姆对于每个起始顶点的最小移动计数可以使用前缀和或间隔和来聚合。 这降低了复杂性$O(n^2)$到$O(n)$每个测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 解析输入并读取$n, m$以及额外边的列表。 按起始顶点对额外的边进行排序$u_i$因为不交叉的属性保证了间隔是嵌套的，使得后期的处理更加容易。 
2. 构造数组$r[i]$为了$i = 1 \dots n$表示可到达的最远顶点$i$跟随任何链条或额外边缘。 最初，$r[i] = i+1$为所有人$i < n$。 对于每条额外的边$u_i \to v_i$， 更新$r[u_i] = \max(r[u_i], v_i)$。 然后传播$r[i] = \max(r[i], r[i+1])$从$i = n-1$降至 1。这确保了$r[i]$在汤姆不移动的情况下，捕捉杰瑞一回合的最大向前伸展距离。 
3. 计算汤姆在每个位置必须移动的次数$y$阻止杰瑞从$x$。 由于汤姆可以以最佳方式等待或前进，因此对于每个位置$i$，我们计算有多少个位置$x < i$存在使得杰瑞能够到达$i$在到达之前$n$。 Using prefix sums, this counting reduces to$O(n)$。 
4. 总结所有有效的最小移动$x \neq y$以获得测试用例的答案。 
5. 对所有测试用例重复此操作。 

为什么它有效：$r[i]$正确地模拟了 Jerry 在一回合中的最大向前伸展距离，并且非交叉属性确保了没有复杂的重叠路径需要考虑。 这保证了计算 Tom 必须移动以拦截 Jerry 的时间间隔可以准确捕获最小移动次数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        r = [i+1 for i in range(n+2)]  # 1-based indexing, extra slot
        for _ in range(m):
            u, v = map(int, input().split())
            r[u] = max(r[u], v)
        for i in range(n-1, 0, -1):
            r[i] = max(r[i], r[i+1])
        res = 0
        max_r = 0
        for i in range(1, n):
            max_r = max(max_r, r[i])
            res += max_r - i
        print(res)

solve()
```该解决方案初始化最远可达顶点数组，然后向后传播可达性。 总和的计算方法是，对于每个起始顶点，在 Tom 必须移动拦截之前 Jerry 可以走多远。 这`max_r - i`公式准确计算了汤姆必须为杰瑞从该位置开始的最小移动`i`。

 ## 边缘情况

 对于`n=2, m=0, x=1, y=2`，杰瑞立即移动到2。 汤姆可以停留在 2，结果是`f(1,2)=0`。 算法初始化`r[1]=2`，向后传播，`max_r - i`总和为零，正确地捕捉到汤姆不需要移动。
