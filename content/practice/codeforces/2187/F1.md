 ## 解决方案
 ## 问题理解

 我们得到同一组顶点的两次 DFS 前序遍历`{0,1,...,n}`。 

这棵树本身是未知的。 我们唯一知道的是，在两次遍历中，根`0`首先出现，并且对于每个顶点，其子节点在 DFS 期间的顺序是任意的。 

如果存在产生 Tortinita 遍历的某些子顺序选择以及产生 Arietta 遍历的某些子顺序选择，则该树被称为公共树。 

在所有这些常见的树中，我们必须找到最大可能的深度。 

关键的难点在于DFS预序并不能唯一确定一棵树。 许多不同的有根树可以生成相同的遍历。 我们必须准确理解哪些祖先-后代关系是由两种排列所强制的，然后构建尽可能深的公共树。 

输入大小立即排除任何二次方。 全部的总和`n`取决于`10^6`，并且可能有多达`10^4`测试用例。 甚至`O(n√n)`会不舒服。 我们大概需要`O(n log n)`总工作量。 

一个微妙的点是两次遍历使用相同的顶点标签。 我们不是在比较位置，而是在比较不同 DFS 顺序中出现的相同顶点。 

另一个容易犯的错误是假设一个 DFS 顺序中出现的每个区间自动都是一棵子树。 例如：```
a = [1,2,3]
b = [2,1,3]
```该段`{1,2}`在两种排列中都是连续的，但在公共树中，两个顶点都不能是另一个顶点的父节点。 答案只是`1`。 

第二个陷阱是有效子树形成嵌套结构。 两个候选子树区间永远不能部分重叠。 例如，间隔`[1,4]`和`[3,6]`不能都是有效的子树范围。 任何正确的解决方案都必须利用这种层流特性。 

## 方法

 暴力视图是尝试重建每一个可能的公共树并计算其深度。 

为什么这在概念上有效？ 每个子树必须在每个 DFS 预序中占据一个连续的块。 我们可以重复选择区间边界，递归地构建树，并测试一致性。 

问题在于可能的区间分解的数量是巨大的。 即使检查所有间隔也需要`Θ(n²)`候选人，并天真地验证他们会花费另一个因素`n`。 和`n = 10^6`在测试用例中，这是完全不可能的。 

第一个观察结果是，使用两个任意排列是很尴尬的。 我们可以完全消除一种排列。 

让`pos[v]`是顶点的位置`v`按照 Arietta 的 DFS 订单。 替换每个值`a[i]`经过`pos[a[i]]`。 

重新标记后，Arietta 的 DFS 顺序变为：```
0,1,2,...,n
```Tortinita 的顺序变成单一排列`c`。 

现在，Arietta 树中的每个有效子树都对应于一个连续的值区间。 

下一个观察是关键的。 

假设一个段`c[l..r]`代表一个子树。 

它的根必须是该段的第一个元素。 

由于 Arietta 的顺序是恒等排列，因此该子树的顶点必须恰好是连续的值范围。 

这意味着：```
c[l] = min(c[l..r])

max(c[l..r]) - min(c[l..r]) = r - l
```第二个条件表示段内的值形成一个完整的连续区间。 

所以整个问题就变成了：

 对于每个起始位置`l`，找到最大的`r`满足这两个条件。 

生成的有效区间的行为与子树区间完全相同。 它们形成一个层状家族：任何两个要么不相交，要么一个包含另一个。 一旦我们知道从每个位置开始的最大有效区间，恢复最大深度就变成了一个简单的嵌套问题。 

剩下的挑战是有效地找到所有最大的有效区间。 

这篇社论每隔一段时间就使用分而治之的方法。 对于递归段`[L,R]`，我们处理穿过中点的所有有效区间。 

使用左半部分的后缀最小值/最大值和右半部分的前缀最小值/最大值，可以将条件重写为代数等式，从而允许在每个递归级别的线性时间内匹配左端点和右端点。 

这会产生一个`O(n log n)`解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) 或更糟 | O(n²) | 太慢了 |
 | 分而治之+区间重构| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 ### 1. 标准化排列

 构建：```
pos[v] = position of v in b
```并定义```
c[i] = pos[a[i]]
```现在Arietta 的顺序是身份排列。 

### 2. 描述有效子树段的特征

 一段`[l,r]`对应于公共子树 iff：```
c[l] = min(c[l..r])
```和```
max(c[l..r]) - min(c[l..r]) = r - l
```第一个条件表示子树根首先出现。 

第二个条件表示这些值形成一个连续的区间。 

### 3.计算从每个位置开始的最大有效区间

 让`R[l]`表示最大有效右端点。 

使用分而治之的方法。 

对于递归间隔`[L,R]`有中点`mid`，递归求解两半，然后处理穿过中点的区间。 

预计算：```
left suffix minima/maxima
right prefix minima/maxima
```对于每个左端点`i`， 让：```
mn = minimum on [i,mid]
mx = maximum on [i,mid]
```仅位置`c[i]`成为新的最小值可以作为子树的根。 

存在两种情况。 

最后一段的最大值来自左半部分。 

然后：```
j = i + mx - mn
```我们直接验证剩下的条件。 

最大值来自右半部分。 

然后：```
max_right - j = mn - i
```这就变成了左右位置的匹配问题。 

存储按以下分组的正确位置：```
max_right - j
```并使用单调指针来获取最大的可行值`j`。 

这会在线性时间内处理递归节点的所有交叉间隔。 

### 4. 将区间解释为一棵树

 每个有效区间对应一个子树。 

由于有效间隔永远不会交叉，因此从每个位置开始的最大间隔定义了一个嵌套结构。 

从左到右遍历位置。 

维护当前活动间隔的堆栈。 

当间隔结束时，将其删除。 

当位置`i`开始一个有效间隔，推动其右端点。 

堆栈大小等于重建公共树内的当前深度。 

跟踪最大堆栈大小。 

### 5.添加根

 排列不包括顶点`0`。 

如果非根顶点之间的最深嵌套是`d`，那么实际的树深度为：```
d + 1
```这是所需的答案。 

### 为什么它有效

 归一化后，Arietta 树中的每个子树都对应一个连续的值区间。 

DFS 预序属性强制子树根首先出现在其段内，给出最小条件。 

一组连续值的特征如下：```
max - min = length - 1
```这就给出了第二个条件。 

因此，有效段正是公共子树。 

分而治之步骤找到每个最大有效线段，因为每个区间要么完全位于一半，要么穿过中点。 交叉情况由两个导出方程详尽地处理。 

由于子树区间形成层状族，因此区间的嵌套深度等于最深公共树的深度。 堆栈重建精确地计算该嵌套深度。 

因此该算法返回最大可能的深度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())

        a = [0] + list(map(int, input().split()))
        b = [0] + list(map(int, input().split()))

        pos = [0] * (n + 1)
        c = [0] * (n + 1)
        R = [0] * (n + 1)

        for i in range(1, n + 1):
            pos[b[i]] = i

        for i in range(1, n + 1):
            c[i] = pos[a[i]]

        for i in range(1, n + 1):
            pos[c[i]] = i

        mn = [0] * (n + 2)
        mx = [0] * (n + 2)

        buckets = [[] for _ in range(2 * n + 5)]
        ptr = [0] * (2 * n + 5)

        sys.setrecursionlimit(1 << 20)

        def dc(l, r):
            if l >= r:
                return

            mid = (l + r) >> 1

            dc(l, mid)
            dc(mid + 1, r)

            mn[mid] = mx[mid] = c[mid]
            for i in range(mid - 1, l - 1, -1):
                mn[i] = min(mn[i + 1], c[i])
                mx[i] = max(mx[i + 1], c[i])

            mn[mid + 1] = mx[mid + 1] = c[mid + 1]

            buckets[c[mid + 1] - (mid + 1) + n].append((c[mid + 1], mid + 1))

            for i in range(mid + 2, r + 1):
                mn[i] = min(mn[i - 1], c[i])
                mx[i] = max(mx[i - 1], c[i])
                buckets[mx[i] - i + n].append((mn[i], i))

            for i in range(mid, l - 1, -1):
                if mn[i] != mn[i + 1]:

                    j = i + mx[i] - mn[i]

                    if (
                        mid < j <= r
                        and mn[j] > mn[i]
                        and mx[j] < mx[i]
                    ):
                        if j > R[i]:
                            R[i] = j

                    key = mn[i] - i + n

                    vec = buckets[key]

                    while (
                        ptr[key] < len(vec)
                        and vec[ptr[key]][0] > mn[i]
                    ):
                        ptr[key] += 1

                    if ptr[key]:
                        k = vec[ptr[key] - 1][1]

                        if mx[k] > mx[i]:
                            if k > R[i]:
                                R[i] = k

            for i in range(mid + 1, r + 1):
                key = mx[i] - i + n
                buckets[key].clear()
                ptr[key] = 0

        dc(1, n)

        stack = []
        ans = 0

        for i in range(1, n + 1):
            while stack and stack[-1] <= i:
                stack.pop()

            if R[i]:
                stack.append(R[i])
                if len(stack) > ans:
                    ans = len(stack)

        print(ans + 1)

solve()
```第一部分将两个排列标准化为单个排列`c`。 

分而治之例程计算从每个位置开始的最大有效间隔。 数组`mn`和`mx`在当前递归段的左侧保留后缀最小值/最大值，在右侧保留前缀最小值/最大值。 

最微妙的部分是第二个交叉案例。 等式```
max_right - j = min_left - i
```允许按值对右端点进行分组`max_right - j`。 单调指针保证每个递归节点内的线性工作。 

最后，栈重构区间嵌套。 在当前位置之前结束的间隔将被删除，而新打开的间隔将被添加。 最大堆栈大小等于最深的嵌套级别。

 ## 边缘情况

 考虑：```
n = 2
a = [1,2]
b = [2,1]
```标准化后：```
c = [2,1]
```该段`[1,2]`失败，因为第一个元素不是段的最小值。 该算法没有分配有效的区间，堆栈保持为空，答案变成`1`。 

现在考虑：```
n = 5
a = [1,2,3,4,5]
b = [1,2,3,4,5]
```每个前缀间隔都是有效的：```
[1,5]
[2,5]
[3,5]
[4,5]
```它们完美嵌套。 栈深度达到`4`，最终的答案是`5`，对应于根下方长度为 5 的链。 

更微妙的情况是两个候选区间部分重叠。 有效性条件自动防止两者同时存在。 在重建过程中，区间形成层流族，因此堆栈表示保持正确并且永远不会遇到交叉区间。 这正是可以单独使用区间嵌套来计算深度的原因。
