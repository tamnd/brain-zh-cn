 ## 解决方案
 ## 问题理解

 我们有一个序列$n+1$连接的房间$n$门。 每扇门$i$有一个号码$a_i$指示如果未触摸，它将自动打开的确切秒数。 有些房间的开头包含二进制字符串的密钥$s$，其中一个`1`表示该房间中有一把钥匙。 你从房间开始$1$在某个时间$0$，每秒您都可能在当前房间中拿起或放下一把钥匙。 在每一秒结束时，如果门打开或您有钥匙打开它，您可以移动到下一个房间，或者自由地返回到上一个房间。 钥匙是一次性的，您最多可以携带一把。 

目标是计算每扇门$i$, 最早可以到达房间的秒数$i+1$，从房间开始$1$在某个时间$0$。 每扇门都是独立的，因为门的答案$i$并不取决于您稍后是否想要到达更多房间。 

约束条件允许$n$最多$2 \cdot 10^5$，以及总和$n$跨测试用例的上限也为$2 \cdot 10^5$。 每秒进行蛮力模拟会太慢，因为$a_i$可以大到$2 \cdot 10^5$，使得总时间维度巨大。 相反，我们需要一个线性解$n$每个测试用例。 

不明显的边缘情况包括有时打开的门$0$、带有可立即使用的钥匙的房间，以及在您到达之前打开的一系列门。 例如，如果$a_1 = 0$和$s = "1"$，您可以立即选择钥匙并使用它来移动$0$秒，到达房间$2$在某个时间$1$。 如果您没有正确考虑密钥的使用情况，您可能会高估最早可达时间。 

## 方法

 最简单的方法是对每一秒进行完整的 BFS 或模拟。 对于每扇门，跟踪您可以使用或不使用钥匙到达哪些房间，并逐步增加时间，直到到达目标房间。 这是正确的，但复杂性是$O(n \cdot T)$， 在哪里$T = \max(a_i)$。 自从$T$可以是$2 \cdot 10^5$和$n$最多$2 \cdot 10^5$，这大约导致$4 \cdot 10^{10}$操作，这太慢了。 

关键的见解是，在房间中移动实际上取决于三个数量：门最早自动打开的时间（$a_i$)，最左边的键 ($l_i$），以及右侧最近的键（$r_i$）。 因为你一次只能携带一把钥匙，所以你可以预先计算，对于每个房间，左边或右边的钥匙最早可以被拿起并用于开门。 那么最早到达房间的时间$i+1$是等待门自动打开（使用左键或使用右键）的最短时间。 

这一观察结果将问题简化为三个线性遍：一次从左到右，一次从右到左，以及最后一次计算最小值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 秒级暴力破解模拟 | O(n * 最大(a_i)) | O(n) | 太慢了|
 | 预先计算左/右键到达时间 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.解析输入：读取$n$， 大批$a$，和字符串$s$。 
2.初始化两个数组`left`和`right`大小为 $n`, representing the earliest time a key can reach each door from the left and from the right. Initialize `左边`with infinity, and`对`与无穷大。 
3. **从左向右传递**：追踪最后看到的关键时间。 

为了`i`从`0`到`n-1`:

 - 如果房间`i`包含一个键（`s[i] == '1'`）， 放`last_key = 0`因为钥匙可以立即使用。 
- 如果`last_key`被定义，`left[i] = last_key + 1`并增加`last_key`每一步加 1 来说明运动。 

该模型选择一把钥匙并向右移动，每个房间增加一秒。 
4. **从右到左传递**：与左传递对称。 

为了`i`从`n-1`下降到`0`:

 - 如果房间`i`包含一个键（`s[i] == '1'`）， 放`last_key = 0`。 
- 如果`last_key`被定义，`right[i] = last_key + 1`并增加`last_key`每一步加 1 来说明向左移动然后向后移动。 
5. 计算每扇门的最早到达时间：

 对于每个`i`从`0`到`n-1`:

 -`ans[i] = min(a[i], left[i], right[i])`使用左边的钥匙或使用右边的钥匙，这需要最短的等待门自动打开的时间。 
6. 打印结果。 

为什么它有效：不变的是`left[i]`存储密钥从左侧到达的最短时间，`right[i]`从右边。 由于您一次只能拿起一把钥匙，因此朝单一方向移动到目标门始终是最佳选择。 取最小值`a[i]`把手在任何钥匙到达之前自动打开。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        s = input().strip()
        INF = 10**9

        left = [INF] * n
        right = [INF] * n

        # Left to right
        last_key = -INF
        for i in range(n):
            if s[i] == '1':
                last_key = 0
            else:
                if last_key != -INF:
                    last_key += 1
            if last_key != -INF:
                left[i] = last_key

        # Right to left
        last_key = -INF
        for i in range(n-1, -1, -1):
            if s[i] == '1':
                last_key = 0
            else:
                if last_key != -INF:
                    last_key += 1
            if last_key != -INF:
                right[i] = last_key

        ans = []
        for i in range(n):
            ans.append(str(min(a[i], left[i], right[i])))
        print(' '.join(ans))

if __name__ == "__main__":
    solve()
```此代码通过快速 I/O 实现算法，预先计算左右键到达时间。 哨兵`-INF`确保没有任何可用钥匙的房间不会影响计算。 递增`last_key`每一步模拟房间之间的移动。 最终的最低限度是使用钥匙与等待自动门打开进行比较。
