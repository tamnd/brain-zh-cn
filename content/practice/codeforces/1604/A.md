 ## 解决方案
 ## 问题理解

 给定一个整数序列，我们可以在序列中的任何位置插入任意正整数，次数不限。 目标是使序列满足位置处的每个元素的条件`i`至多是`i`。 换句话说，对于每个索引`i`，该位置的值不能超过从 1 开始的索引。 我们想要确定实现此目的所需的最小插入次数。 

序列长度较小，最多 100 个元素，值可以大到 10^9。 由于元素值很大，简单地以强力方式迭代所有可能的插入是不切实际的。 相反，我们必须推理每个元素及其位置之间的差异。 由于元素的最大数量适中，因此每个测试用例的 O(n log n) 或 O(n) 算法是可行的。 

一些边缘情况立即变得清晰。 如果序列已经处于有效状态，则无需执行任何操作。 如果第一个元素非常大，比如`10^9`，我们无法通过修改来修复它； 我们必须在它之前插入许多小数字，以将其“推”到有效位置。 例如，一个序列`[69]`需要插入`68`元素`[1,2,...,68]`在它满足之前`a[69] <= 69`。 

## 方法

 暴力方法会尝试在必要的地方一个接一个地插入元素，并检查每一步的顺序。 虽然原则上是正确的，但它很快就变得不可行，因为元素值可能很大，并且在简单的模拟中我们可能需要最多 10^9 次插入。 这意味着单独模拟每个插入是不可能的。 

关键的观察结果是问题简化为贪婪策略。 对序列进行排序后，最小的元素应占据第一个位置，第二小的元素占据第二个位置，依此类推。 如果元素在位置`i`大于`i`，那么我们需要在它之前插入足够小的数字来将其移动到位置`a[i]`或更少。 本质上，所需的最小插入次数是最大值`a[i] - i`超过所有元素。 这是有效的，因为在开头插入数字会增加后续元素的索引，从而有效地减少差异。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * 最大(a)) | O(n + 最大(a)) | 太慢了 |
 | 贪婪/排序插入 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个测试用例，读取序列长度和序列元素。 
3. 对顺序进行排序。 排序至关重要，因为插入后的最佳序列应该首先具有最小的元素，然后按顺序具有较大的元素。 这最大限度地减少了所需的插入次数。 
4. 初始化计数器`ops`为零。 这将跟踪所需的操作数量。 
5. 使用从 1 开始的索引迭代排序序列`i`。 对于每个元素`a[i]`，计算差值`a[i] - i`。 如果该差值为正，则表示该元素之前需要插入的次数才能使其进入有效位置。 更新`ops`作为最大值`ops`和`a[i] - i`。 
6. 处理完整个序列后，`ops`包含所需的最小插入次数。 打印或存储该值。 
7. 对所有测试用例重复此操作。 

工作原理：排序保证最小的数字占据最小的索引，从而最大限度地减少所需的插入次数。 区别`a[i] - i`精确捕获当前位置之前“丢失”的较小元素的数量。 取最大值可确保所有元素在计算的插入次数后都有效。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    ops = 0
    for i, val in enumerate(a, 1):
        ops = max(ops, val - i)
    print(ops)
```该解决方案首先使用快速 I/O 读取输入。 排序可确保元素按顺序排列，以实现最少的插入。 该循环使用从 1 开始的索引来将元素位置与其所需的限制对齐。`ops`捕获最大差异，这正是所需的插入数量。 使用`max`当后面的元素需要更多插入时，每个步骤都可以避免计数不足。

 输入示例：```

 最大差异为 1，因此我们需要插入一次。 

### 跟踪表`[69]`| 我| 值| val - 我 | 操作|

 我们需要 68 个插入来推送`69`至位置 69。 

这些痕迹证实了贪婪方法正确地识别了操作数量。

 ## 边缘情况

 对于单个元素`[1]`，序列已经有效。 循环计算`val - i = 0`， 所以`ops = 0`。 不需要插入。 

对于一个序列`[1000000000, 1, 1]`, 排序产量`[1, 1, 1000000000]`。 跟踪计算`val - i`作为`0, -1, 999999997`，所以最大差异为`999999997`。 这确保算法正确处理非常大的值，并通过在它们之前插入足够小的数字来定位它们。
