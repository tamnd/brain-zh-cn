 ## 解决方案
 ## 问题理解

 我们得到一个二进制字符串，即一系列 0 和 1，我们的目标是对其进行操作，使所有 1 出现在一个连续的块中。 唯一允许的操作是删除一些 0。 我们需要计算要使该条件成立而必须删除的 0 的最小数量。 

输入由多个测试用例组成，每个测试用例的字符串长度最多为 100。这意味着如果需要，我们可以负担字符串长度为二次的算法，但线性时间解决方案显然更干净、更简单。 因为字符串只能包含 0 和 1，所以我们不必处理任何其他字符。 

当字符串中没有 1（例如“0”或“0000”）时，就会出现不明显的边缘情况。 在这些情况下，1 之间没有需要消除的间隙，因此答案为 0。同样，如果所有字符均为 1，则无需删除。 当存在前导或尾随 0 时，会出现另一种微妙的情况，例如“0011100”，其中需要删除中间的 0，但前导和尾随 0 并不重要。 简单的解决方案可能会错误地计算全 0，或者无法正确识别 1 的子段。 

## 方法

 暴力方法将迭代字符串的每个可能的连续段，并计算该段内有多少个 0。 对于每个以 1 开头和结尾的段，我们将计算这些 1 之间 0 的数量，然后取所有段中的最小值。 这种方法之所以有效，是因为它显式模拟删除 0 以使 1 连续，但它需要检查 O(n^2) 段，并且对于最大字符串长度 100，每个测试用例大约需要 10,000 次操作。 这是可行的，但不必要的复杂。 

得出最佳解决方案的关键观察结果是，唯一重要的 0 严格位于第一次出现和最后一次出现的 1 之间。第一个 1 之前或最后一个 1 之后的任何 0 都不会破坏连续的 1 块，因此不需要删除。 一旦我们知道第一个和最后一个 1 的位置，我们就可以迭代该子字符串并计算 0 的数量。 该计数正是要擦除的最小 0 数。 这一观察结果将问题简化为每个测试用例一次线性扫描，考虑到限制，这更简单且足够快。

 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 已接受但没有必要 |

 ## 算法演练

 1. 对于每个测试用例，读取二进制字符串。 
2. 查找第一次出现“1”的索引。 如果没有“1”，则立即返回 0，因为不需要删除。 
3. 查找最后一次出现“1”的索引。 
4. 迭代从第一个“1”到最后一个“1”的子字符串。 计算这个范围内“0”的数量。 
5. 输出该计数。 这表示要擦除以使所有 1 连续的 0 的最小数量。 

为什么有效：不变的是第一个到最后一个 1 范围之外的任何 0 都是无关的。 仅计算此范围内的 0 可确保在删除它们后，1 形成单个不间断的段。 没有其他配置可以产生更少的删除，因为必须删除范围内的任何 0 以合并分隔的 1。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    s = input().strip()
    if '1' not in s:
        print(0)
        continue
    first = s.index('1')
    last = s.rindex('1')
    count = s[first:last+1].count('0')
    print(count)
```该解决方案首先处理没有 1 的简单情况。 然后它会识别包含所有 1 的子字符串并计算内部 0 的数量。 使用`index`和`rindex`确保正确识别边界，并且从第一个到最后一个对字符串进行切片可确保仅扫描相关部分。 通过包含可以避免相差一错误`last+1`在切片中，这是范围内包含结束的标准 Python 约定。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    res = []
    for _ in range(t):
        s = input().strip()
        if '1' not in s:
            res.append('0')
            continue
        first = s.index('1')
        last = s.rindex('1')
        count = s[first:last+1].count('0')
        res.append(str(count))
    return '\n'.join(res)

# Provided samples
assert run("3\n010011\n0\n1111000\n") == "2\n0\n0", "sample 1"

# Custom test cases
assert run("1\n0000\n") == "0", "all zeros"
assert run("1\n1111\n") == "0", "all ones"
assert run("1\n1010101\n") == "3", "alternating ones and zeros"
assert run("1\n10001\n") == "3", "zeros between first and last ones"
assert run("1\n011110\n") == "0", "zeros outside first and last ones"
```| 测试输入| 预期产出 | 它验证了什么 |

 ## 边缘情况

 对于输入“0000”，算法找不到“1”，立即返回0。 对于“1111”，第一个和最后一个 1 在索引 0 和 3 处，子字符串是完整字符串，并且没有 0，返回 0。对于“10001”，第一个和最后一个 1 在索引 0 和 4 处，子字符串是“10001”，内部零计为 3，符合直觉。 所有涉及不带 1 的字符串、仅包含 1 的字符串以及 1 块之外包含 0 的字符串的边缘情况都会得到正确处理。
