 ## 解决方案
 ## 问题理解

 问题描述了一张纸条`n`必须打孔的等距位置。 冲孔工具总是精确地创建两个孔，并且这两个孔之间的距离由工具固定。 我们需要找到每一个距离`k`这样，仅重复使用该距离的冲头就可以打出所有孔，而不会留下任何未配对的孔。 输入是一个偶数`n`，输出是有效距离的数量，后跟这些距离按升序排列。 

尺寸为`n`取决于`10^9`，因此模拟每个可能的打孔距离`1`到`n`是不可能的。 线性扫描已经需要多达十亿次检查，这在正常竞赛限制下太慢了。 解决方案必须使用问题的数学结构，而不是尝试每一个距离。 

一个常见的错误是假设每个除数`n`作品。 可整性是必要的，但原因更具体：孔根据其位置模数分成组`k`，并且每个这样的组必须包含偶数个孔。 例如，与`n = 8`,`k = 3`无效。 位置分为大小组`3, 3, 2`，并且具有三个孔的组不能完美配对。 该输入的正确输出是：```
3
1 2 4
```另一个边缘情况是`k = n`。 它看起来像是一个有效的距离，因为它划分了整个范围，但打孔器需要两个孔，它们之间的距离是`n`厘米，而最后一个可能的孔仅`n - 1`与第一个相距厘米。 为了`n = 2`，唯一有效的距离是`1`， 不是`2`。 

## 方法

 直接的解决方案将测试所有可能的距离`k`。 对于每个`k`，我们可以查看每对位置`k`拆开并检查所有孔是否能够匹配。 这是可行的，因为固定距离精确地定义了可以连接哪些孔，但是对于`n = 10^9`这太慢了。 即使检查所有候选者也需要数十亿次操作。 

有用的观察来自于按余数对位置进行分组`k`。 具有相同余数的孔通过长度跳跃连接成链`k`。 例如，如果`k = 3`, 职位`1, 4, 7`形成一条链。 当且仅当一条链的长度是偶数时，它才能完全配对。 

认为`n = qk + r`。 其中`k`链条，`r`链条有长度`q + 1`其余的链有长度`q`。 如果`r`不为零，则两种尺寸都会出现。 由于两个连续整数不可能同时为偶数，因此有效距离不能有余数。 因此每个有效的`k`必须划分`n`。 

什么时候`k`划分`n`，每条链都恰好有`n / k`洞。 链条长度必须均匀，所以`n / k`也必须是均匀的。 整个问题简化为求除数`k`的`n`其中相应的商是偶数。 

的最大可能值`n`是`10^9`，因此检查除数直至其平方根就足够了。 检查数量仅为31623张左右。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) 或更糟 | O(1) | O(1) | 太慢了 |
 | 最佳 | O(sqrt(n)) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取孔数`n`。 
2. 迭代所有整数`i`从`1`到`sqrt(n)`。 如果`i`划分`n`， 两个都`i`和`n / i`是除数。 每个除数都被独立检查，因为其中任何一个都可以满足所需的奇偶校验条件。 
3. 对于每个除数`d`，检查是否`n / d`是均匀的。 如果是的话，`d`是一个有效的打孔距离，因为每个模数`d`链条有偶数个孔。 
4. 存储所有有效距离并在打印前对它们进行排序。 除数是成对发现的，因此需要排序来匹配所需的递增顺序。 

为什么有效：对于固定距离`k`，可能的冲孔会创建独立的孔链。 具有奇数个孔的链条总是有一个孔不匹配，而具有偶数个孔的链条可以从一端到另一端配对。 该算法仅接受每个链长度均匀的距离，这正是完整的冲压计划所需的条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    ans = []

    i = 1
    while i * i <= n:
        if n % i == 0:
            if (n // i) % 2 == 0:
                ans.append(i)
            other = n // i
            if other != i and (n // other) % 2 == 0:
                ans.append(other)
        i += 1

    ans.sort()

    print(len(ans))
    print(*ans)

if __name__ == "__main__":
    solve()
```循环仅达到平方根`n`，这避免了迭代不可能的距离。 当除数对`(i, n / i)`找到后，将测试这两个值。 这`other != i`条件防止在以下情况下将平方根除数相加两次`n`是一个完美的正方形。 

条件`(n // d) % 2 == 0`直接表示链长参数。 将孔总数除以链数即可得出每条链内的孔数，并且该数量必须是偶数。 

Python 整数在这里不会溢出，因为最大的乘法是`i * i`， 和`i`限制为约 31623。

## 测试用例```python
import sys
import io

def solve():
    input = sys.stdin.readline
    n = int(input())
    ans = []

    i = 1
    while i * i <= n:
        if n % i == 0:
            if (n // i) % 2 == 0:
                ans.append(i)
            if n // i != i and (n // (n // i)) % 2 == 0:
                ans.append(n // i)
        i += 1

    ans.sort()
    return str(len(ans)) + "\n" + " ".join(map(str, ans)) + "\n"

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    return solve()

assert run("8\n") == "3\n1 2 4\n"
assert run("2\n") == "1\n1\n"
assert run("6\n") == "2\n1 3\n"
assert run("12\n") == "4\n1 2 3 6\n"
assert run("1000000000\n") == "6\n1 2 4 5 8 10\n"

 ## 边缘情况

 对于`n = 8`和`k = 3`，算法不输出`3`因为`3`不是以下的除数`8`。 在需要任何配对模拟之前，数学简化会捕获无效情况。 

为了`n = 2`，算法检查除数`1`和`2`。 除数`1`有商数`2`，这是偶数，而除数`2`有商数`1`，这很奇怪。 结果只是距离`1`。 

为了`n = 12`, 除数`4`即使分裂也被拒绝`12`。 它的商是`3`，这意味着每条链将包含三个孔，在每条链中留下一个不匹配的孔。 

对于较大的值，例如`n = 1000000000`，该算法从不尝试测试十亿个候选者。 它只检查可能的除数`31623`，这是解决方案保持高效的关键原因。
