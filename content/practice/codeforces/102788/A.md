 ## 解决方案
 ## 问题理解

 一个正常的阶幻方`n`是一个`n × n`包含每个数字的排列`1`到`n²`正好一次。 每行、每列和两条主对角线的总和都是相同的值。 任务不是建造广场。 我们只需要这样一个正方形的第一行中的数字之和。 输入是正方形的边长，输出是这个常见的幻数和。 

订单可以大到`1000`，因此构建整个正方形需要存储多达一百万个单元格。 这在某些语言中仍然是可能的，但没有必要。 预期的解决方案应仅使用平方的数学属性并在恒定时间内完成。 任何尝试放置值或验证行和列的模拟都会执行与`n²`，而答案可以直接推导出来。 

主要的边缘情况来自小订单和平价。 为了`n = 1`，正方形仅包含数字`1`，所以答案是`1`。 盲目应用构造公式而不处理这种情况的程序可能会失败。 例如：```
Input:
1

Output:
1
```订单`2`永远不会出现，因为该大小的普通幻方不存在。 一个粗心的实施，假设每一个积极的`n`有效可以尝试构造一个不可能的正方形。 约束排除了这种情况，因此程序只需要读取有效的输入范围。 

## 方法

 一种直接的方法是实际创建一个普通的幻方并计算第一行。 对于奇怪的订单，可以使用暹罗结构，而其他订单则需要更复杂的结构。 构建后`n × n`网格，读取第一行需要另一行`O(n)`运营。 这种方法的问题在于它解决的问题比所需的更难。 最坏的情况是`n = 1000`创建一百万个细胞并执行大量不必要的工作。 

关键的观察结果是第一行与其他所有行的总和相同。 整个正方形包含数字`1`通过`n²`，所以所有单元格的总和就是算术级数：$$1 + 2 + \dots + n^2 = \frac{n^2(n^2+1)}{2}$$正好有`n`行，并且每行都有相同的总和。 将总和除以行数得出幻数：$$\frac{n^2(n^2+1)}{2n} = \frac{n(n^2+1)}{2}$$因此，答案完全由`n`。 正方形的实际排列是无关紧要的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n²) | 太慢而且没必要 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读订单`n`的魔方。 
2. 计算所有数字的总和`1`到`n²`使用等差数列公式：$$\frac{n^2(n^2+1)}{2}$$这是有效的，因为普通的幻方只包含这些数字一次。 

1. 将总和除以`n`，因为正方形有`n`行和所有行具有相同的总和。 
2. 输出结果值，即第一行的和。 

为什么它有效：

 幻方的定义属性是每一行都有相同的总和。 由于所有数字都来自`1`到`n²`出现一次，无论数字如何排列，所有单元格的总和都是固定的。 将这个固定总额平均分配给`n`rows 给出每一行的值，包括第一行。 该公式不能依赖于构造，因为所有有效的正态幻方都具有相同的总数和相同的行数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    print(n * (n * n + 1) // 2)

if __name__ == "__main__":
    solve()
```该程序仅保留以下值`n`，所以它永远不会分配正方形本身。 表达式`n * (n * n + 1) // 2`直接从推导公式得出。 

Python 整数安全地处理中间乘法。 当达到最大值时`n = 1000`，其中结果仍然远低于 Python 的整数限制。 整数除法是精确的，因为对于问题中的有效订单，幻数总和始终是整数。

 ## 边缘情况

 对于`n = 1`，算法计算：$$\frac{1(1^2+1)}{2} = 1$$输出是：```
Input:
1

Output:
1
```该公式有效，因为唯一的行包含正方形中唯一的单元格。 

对于允许的最大订单：```
Input:
1000
```该算法不会尝试创建一百万个单元。 它直接计算：$$\frac{1000(1000^2+1)}{2}=500000500$$和输出：```
500000500
```这证实了为什么需要使用数学属性：即使平方变得非常大，工作量也保持不变。
