 ## 解决方案
 ## 问题理解

 游戏是在一行正整数上进行的。 爱丽丝先行动。 在一轮中，玩家选择两个具有大于 1 的公约数的相邻数字。 通过将两个数字除以其最大公约数来简化所选对。 当没有相邻对共享任何约数时，当前玩家没有合法的举动并失败。 

任务不是找到最终的数组本身，而是找到哪个玩家到达了失败的位置。 输入由行的长度和该行中的初始值组成。 输出是以最佳发挥获胜的玩家的名字。 

数字可以大到$10^9$，但只有 50 个。 直接的游戏搜索是不可能的，因为移动的顺序创建了许多可能的状态。 然而，每个操作都会严格从数组中删除质因数。 最多一个数$10^9$最多包含 29 个具有重数的素因子，因此可能的删除总数很小。 这表明寻找单调过程而不是探索所有游戏状态。 

关键的观察结果是，每次移动都会减少数组中素因子信息的总量。 更准确地说，如果一个移动将两个数字除以它们的 gcd，则删除的每个质因数都会从两个数字中消失。 任何操作都不能在邻居之间引入新的公约数。 由于这种单调的行为，游戏对步数的奇偶性没有战略分支效应。 任何合法的移动序列在经过相同的移动次数后都会达到相同的最终状态。 

一个常见的错误是认为选择不同的对可以改变获胜者。 例如，与：```
3
2 6 3
```选择第一对给出`[1, 3, 3]`，然后可以再移动一步。 选择第二对给出`[2, 2, 1]`，并且还有可能再进行一次移动。 两条路径都需要两次移动，因此鲍勃获胜。 

另一种边缘情况是当所有相邻对已经互质时：```
2
5 7
```答案是`Bob`，因为爱丽丝根本无法移动。 假设至少存在一个操作的解决方案将错误地计算移动。 

最后一个微妙的情况是当一个操作同时删除几个素因子时：```
2
60 30
```gcd为30，所以移动直接创建`[2, 1]`。 只计算一个公共素数而不是完整的 gcd 会高估移动次数。 

## 方法

 暴力方法是将相邻数字的每个可能选择视为博弈树中的一个分支。 对于每个状态，我们递归地尝试每一个合法的动作，并确定是否存在迫使对手进入失败状态的动作。 这对于公正的游戏来说是正确的，但在这里完全不切实际。 即使一个小数组也可以有许多可能的移动顺序，并且状态数量呈指数增长。 

重要的结构是游戏实际上并不需要极小极大。 每一步都只会去除素因子，而不会将它们改变为其他东西。 如果我们将整个过程视为重复应用约简，则约简的顺序不会影响所需约简的数量，直到所有相邻对都成为互质。 

蛮力之所以有效，是因为它遵循最佳游戏的定义，但它失败了，因为它探索了相同减少的许多等效顺序。 观察到该过程是汇合的，我们可以用简单的模拟来代替博弈搜索。 我们可以重复应用任何可用的移动，并且只计算发生了多少次移动。 如果计数为奇数，则爱丽丝走了最后一步。 如果是平局，鲍勃就采取最后一步。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了|
 | 最佳 |$O(n \cdot F)$|$O(1)$| 已接受 |

 这里$F$是最大移动次数。 由于每一步都会从两个数中至少去除一个素因数，并且素因数的总数很小，$F$是有界的。 

## 算法演练

 1. 存储数组并重复搜索gcd大于1的相邻对。 这样的一对代表合法的举动，因为两个数字都可以减少。 
2. 当找到合法对时，将两个数字除以它们的 gcd 并增加移动计数器。 选择的确切对并不重要，因为所有有效的选择都会导致相同的最终移动平价。 
3. 继续，直到没有相邻对的 gcd 大于 1。 此时游戏已经结束，因为下一个玩家没有合法的动作。 
4. 如果移动次数是奇数，则打印`Alice`。 否则打印`Bob`。 

为什么它有效：

 该算法背后的不变性是数组仅丢失素因子。 移动不能创建新的除数关系，因此每个合法操作都是同一归约过程的一部分。 由于最终位置和减少次数的奇偶性与移动顺序无关，因此计算任何有效序列都会给出正确的获胜者。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    moves = 0

    while True:
        changed = False

        for i in range(n - 1):
            g = math.gcd(a[i], a[i + 1])
            if g > 1:
                a[i] //= g
                a[i + 1] //= g
                moves += 1
                changed = True
                break

        if not changed:
            break

    print("Alice" if moves % 2 else "Bob")

if __name__ == "__main__":
    solve()
```该循环一次搜索一个可用的动作。 我们在每次通过第一次成功减少后停止，因为下一个状态才是最重要的，而不是选择了哪个特定的合法动作。 

gcd计算使用Python内置的欧几里德算法，可以轻松处理高达$10^9$。 整数除法是安全的，因为 gcd 总是精确地除两个选定的数字。 

唯一可能的实施错误是忘记 gcd 为 1 不是合法的举动。 除以 1 会产生无限循环，因为状态不会改变。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |$O(n \cdot F)$| 每次迭代都会扫描该行，并且$F$是减少的数量。 |
 | 空间|$O(1)$| 仅存储输入数组和计数器。 |

 最大归约次数很小，因为每次移动都会永久删除素因数。 和$n \le 50$和最多值$10^9$，模拟很容易满足限制。

 ## 边缘情况

 对于这个案例：```
2
5 7
```该算法扫描唯一的相邻对，发现 gcd 等于 1，并且不执行任何移动。 计数器保持为零，因此鲍勃获胜。 

对于这个案例：```
3
2 6 3
```该算法可以选择任一相邻对。 选择`[2,6]`创造`[1,3,3]`，下一次删除最后一对的 gcd。 选择`[6,3]`创造`[2,2,1]`，然后再减少一次。 两条路径具有相同的奇偶校验，因此结果仍然是 Bob。 

对于这个案例：```
2
60 30
```gcd 是 30，而不仅仅是一个素因数。 该操作产生`[2,1]`立即地。 该算法计算一步并正确返回 Alice。
