 ## 解决方案
 ## 问题理解

 我们正在填写一个$2^n \times 2^n$网格中的整数来自$1$到$2^{2n}$，但顺序不是行优先或列优先。 相反，网格是递归构建的。 

在最小的尺度上，一个$2 \times 2$块以固定模式填充：

 左上角为 1，右下角为 2，左下角为 3，右上角为 4。 

对于较大的网格，递归地应用相同的想法。 一个正方形被分成四个相等的象限，这些象限按照固定的顺序填充：首先是左上象限，然后是右下象限，然后是左下象限，然后是右上象限。 每个象限本身都使用相同的规则填充，直到我们达到$2 \times 2$块。 

这定义了坐标之间的双射$(x, y)$和价值观$d$。 每个查询都要求将坐标映射到值或将值映射回坐标。 

尺寸$2^n$可以达到$2^{30}$，这意味着网格最多有$2^{60}$细胞。 显式构造是不可能的。 即使一次完整的遍历也会是天文数字。 唯一可行的方法是通过将网格重复分解为象限，以每次查询的对数时间计算答案。 

打破天真的思维的关键边缘情况是假设象限内的行主顺序或假设象限遍历是字典顺序的。 例如，在一个$2 \times 2$块中，顺序不是按坐标排序的，因此任何假设标准二进制空间填充（如莫顿顺序）而不调整基本模式的坐标到索引转换都会给出错误的结果。 

如果忘记两个查询方向必须与相同的递归顺序一致，则会发生另一种微妙的失败。 仅直接计算一个方向并尝试在不考虑象限结构的情况下“反转”它的解决方案对于大的情况将失败$n$，因为映射不是线性的。 

## 方法

 暴力方法将显式地构建网格。 对于每个级别，我们将递归地填充象限，直到达到大小$2 \times 2$，然后赋值。 这需要访问所有$2^{2n}$细胞，即使对于中等程度的人来说也是不可能的$n$。 在$n = 20$，这已经是$2^{40}$细胞，远远超出任何可行的计算。 

关键的观察结果是，递归在每个级别的象限上使用基于 4 的系统对数字进行编码。 每个单元格的位置可以通过从顶层到底层的一系列象限选择来描述$2 \times 2$基本情况。 类似地，每个数字对应于一系列象限索引，但有一个变化：基数$2 \times 2$模式不是标准顺序，因此我们必须将其视为 4 个叶子的自定义排列。 

因此，我们不构建网格，而是将坐标转换为长度的路径$n$在四叉树中，并类似地将数字转换为这样的路径。 每个步骤贡献 2 位坐标信息和 2 位值偏移。 这将每个查询减少到$O(n)$，最多 30 步。 

我们在象限索引与坐标偏移和值偏移之间保持一致的映射。 唯一重要的部分是叶级别的基本映射，它定义最后两位如何转换为数字，反之亦然。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(2^{2n})$|$O(2^{2n})$| 太慢了|
 | 最佳|$O(n)$每个查询 |$O(1)$| 已接受 |

 ## 算法演练

 我们使用位级别递归独立处理每个查询。 

### 坐标→值查询

 1、从全系列入手$[1, 2^n] \times [1, 2^n]$和值偏移$0$。 

我们将最终答案解释为$1 + \text{offset}$。 
2、在每一层，将当前方块分割成四个大小的象限$2^{k-1} \times 2^{k-1}$。 确定哪个象限$(x, y)$在于检查是否$x$是在上半部还是下半部以及是否$y$位于左半部分或右半部分。 
3. 将此象限转换为填充顺序中的排名。 顺序是：

 左上→0，右下→1，左下→2，右上角→3。 

这种映射是问题的核心，因为它定义了空间位置如何变成以 4 为基数的数字中的数字。 
4.添加`quadrant_index * (4^(remaining_levels-1))`到偏移量。 这将累积当前级别对最终数字的贡献。 
5. 通过更新进入选定的象限$(x, y)$相对于其原点并继续直至到达底部$2 \times 2$案件。 
6. 在基本情况下，使用相同的模式直接将剩余坐标映射到四个值之一：

 (1,1) → 1、(2,2) → 2、(2,1) → 3、(1,2) → 4，并将其添加到累积偏移量中。 

### 值→坐标查询

 1. 转换$d-1$精确地转换成以 4 为基数的表示形式$n$数字，每个数字代表从顶层到底层的一个象限选择。 
2、从全网格开始$(1,1)$到$(2^n,2^n)$。 
3. 在每个级别，获取下一个基数 4 的数字并使用相同的顺序将其映射到象限：

 0 → 左上，1 → 右下，2 → 左下，3 → 右上。 
4. 将当前坐标移动到该象限的原点，并根据我们是向下还是向右累积偏移量。 
5. 在最后一层，涂上底漆$2 \times 2$解码：

 1 → (1,1)、2 → (2,2)、3 → (2,1)、4 → (1,2)。 

### 为什么它有效

 该算法将每个单元编码为通过四叉树的路径，其中每个级别恰好贡献一个 4 进制数字。 递归构造保证每个象限都以相同的相对顺序连续填充，因此保留了空间分解和数值区间之间的映射。 基本情况定义了 2 位坐标和值之间的固定双射，确保叶级的一致性。 由于每个步骤都保留区域和连续值范围之间的一对一映射，因此不会发生冲突或间隙。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

# quadrant order:
# 0 -> TL
# 1 -> BR
# 2 -> BL
# 3 -> TR

def coord_to_val(n, x, y):
    res = 0
    size = 1 << n

    for k in range(n, 1, -1):
        half = 1 << (k - 1)
        block = 1 << (2 * (k - 1))

        if x <= half and y <= half:
            q = 0
        elif x > half and y > half:
            q = 1
            x -= half
            y -= half
        elif x > half and y <= half:
            q = 2
            x -= half
        else:
            q = 3
            y -= half

        res += q * block

    # base 2x2
    if x == 1 and y == 1:
        res += 1
    elif x == 2 and y == 2:
        res += 2
    elif x == 2 and y == 1:
        res += 3
    else:
        res += 4

    return res

def val_to_coord(n, d):
    d -= 1
    x = y = 1
    size = 1 << n

    for k in range(n, 1, -1):
        block = 1 << (2 * (k - 1))
        q = d // block
        d %= block

        half = 1 << (k - 1)

        if q == 0:
            pass
        elif q == 1:
            x += half
            y += half
        elif q == 2:
            x += half
        else:
            y += half

    # last level
    if d == 0:
        return x, y
    elif d == 1:
        return x + 1, y + 1
    elif d == 2:
        return x + 1, y
    else:
        return x, y + 1

t = int(input())
out = []

for _ in range(t):
    n = int(input())
    q = int(input())

    for _ in range(q):
        parts = input().split()
        if parts[0] == "->":
            x = int(parts[1])
            y = int(parts[2])
            out.append(str(coord_to_val(n, x, y)))
        else:
            d = int(parts[1])
            cx, cy = val_to_coord(n, d)
            out.append(f"{cx} {cy}")

sys.stdout.write("\n".join(out))
```坐标到值函数沿着四叉树遍历，从最终索引中减去每个象限的贡献。 值到坐标函数通过使用除以块大小来提取 4 基数字来反转此过程。 

一个微妙的实现细节是显式处理基本情况而不是继续统一递归。 这避免了运行时昂贵的功率计算并确保最终结果的正确性$2 \times 2$映射，不按字典顺序排列。 

使用移位而不是求幂可确保所有计算保持快速且在整数范围内。

 ## 边缘情况

 一种边缘情况是$n = 1$，整个逻辑崩溃为$2 \times 2$基本排列。 该算法仍然运行相同的循环零次并直接应用基本映射，这保证了正确性，而无需在其他地方进行特殊分支。 

另一种情况是最大深度$n = 30$。 在这里，任何基于递归或浮点的幂计算都会溢出或减慢。 基于位移位的块计算确保我们永远不会显式计算大幂，并且所有操作都安全地保持在 32 位或 64 位整数算术范围内。 

第三种情况是在方向之间交替的查询。 由于这两个函数都是纯且无状态的，因此查询之间不会保留中间状态，因此交错不会影响正确性。
