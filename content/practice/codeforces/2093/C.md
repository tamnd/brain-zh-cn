 ## 解决方案
 ## 问题理解

 我们得到一个基本整数`x`和重复次数`k`。 从`x`，我们构造一个新数`y`通过写出十进制表示`x`连续地`k`次而不插入分隔符。 例如，如果`x = 52`和`k = 3`， 然后`y = 525252`。 如果`x = 6`和`k = 7`， 然后`y = 6666666`。 

任务不是显式地构建这个数字并测试它的通常意义上的素性，而是确定这个构建的数字是否`y`是素数。 

这些限制立即表明构建`y`一般情况下是不可能的。 什么时候`x`最多 9 位数字，并且`k`最大为 7，结果数字最多可达 63 位，这已经超出了标准整数类型。 即使将其存储为字符串也可以，但对最多 100 个测试用例的 63 位整数进行素性测试将需要先进的大整数素性技术，并且对于 1000 级问题来说仍然是过大的。 

一个更微妙的问题出现在涉及的边缘情况中`k = 1`和`x = 1`。 如果`x = 1`和`k = 1`， 然后`y = 1`，这不是素数。 如果`k > 1`，即使当`x = 1`，结果是像这样的重聚`111...1`，这可能看起来很特别，但总是复合的`k > 1`在此结构中，因为它可以被分解。 

一个幼稚的错误是从字面上构建字符串并尝试使用试除法进行素性检查。 即使优化到 sqrt(n)，也会由于大小而中断`y`以及重复的测试用例。 

## 方法

 直接暴力解决方案构造`y`并使用除法检查它是否是素数`sqrt(y)`。 这在概念上是正确的，但很快就变得不可行。 数量`y`最多可以有 63 位数字，因此即使是单个素性检查也远远超出了任何合理的确定性试除方法。 

关键的观察是结构性的：重复串联会创建一个具有强代数因式分解性质的数字`k > 1`。 设长度为`x`是`d`。 那么构造的数可以写为：$$y = x \cdot 10^{d(k-1)} + x \cdot 10^{d(k-2)} + \cdots + x$$保理`x`，我们得到：$$y = x \cdot (10^{d(k-1)} + 10^{d(k-2)} + \cdots + 1)$$这表明，每当`k > 1`,`y`是一个产品`x`和另一个大于 1 的整数，这立即使得`y`复合除非`x = 1`我们依赖第二个因素的特殊性。 但即使在这种情况下，第二个因子也大于 1`k > 1`， 所以`y`是复合的。 

因此，我们唯一可能得到素数的时间是`k = 1`，因为那时`y = x`。 问题简化为检查是否`x`本身就是素数。 

所以整个解决方案崩溃为：

 - 如果`k > 1`，答案始终是“否”。 
- 如果`k = 1`，检查素数`x`。 

现在我们只需要一个素性测试`x ≤ 10^9`，这很简单，试除最多`sqrt(x)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力构建+大素性测试| O(k· | x | + sqrt(y)) | O(k· | x | + sqrt(y)) |
 | 因式分解洞察 + 检查 x | 每次测试 O(√x) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`x`和`k`对于每个测试用例。 我们独立处理每种情况，因为没有计算延续。 
2.如果`k`大于1，立即输出“NO”。 这是从重复串联的代数因式分解得出的，它保证了复合性。 
3.如果`k`等于 1，我们将问题简化为检查是否`x`是一个素数。 
4. 测试素性`x`，首先处理小情况：小于2的数字不是质数。 
5. 对于`x ≥ 2`，尝试除以从 2 到 的所有整数`sqrt(x)`。 如果找到任何约数，`x`是复合的； 否则，它是素数。 

### 为什么它有效

 正确性取决于这样一个事实：每当重复发生时，串联就会引入一个非平凡的乘法结构。 为了`k > 1`，构造的数字总是分解为乘积`x`以及 10 次方的几何和，其大小均严格大于 1。 这保证了复合性，无论是否`x`本身就是素数。 什么时候`k = 1`，没有引入结构，数量正好`x`，所以素性被准确地保留。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_prime(n: int) -> bool:
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    i = 3
    while i * i <= n:
        if n % i == 0:
            return False
        i += 2
    return True

t = int(input())
for _ in range(t):
    x, k = map(int, input().split())
    if k > 1:
        print("NO")
    else:
        print("YES" if is_prime(x) else "NO")
```代码首先隔离了结构快捷方式`k > 1`，这避免了构造或推理大重复数的任何需要。 素数检查仅在必要时应用，并且它是安全的，因为`x`的边界是`10^9`。 

素性函数使用标准平方根试除法，通过在处理 2 后跳过偶数进行优化。在给定约束的情况下，这已经足够了。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(t √x) | O(t √x) | 每个测试仅在 k = 1 时检查素数，使用试除法直至 √x |

 ## 边缘情况

 最敏感的边缘情况是`x = 1`。 如果`k = 1`，数字是`1`，它不是质数，因此输出必须为“NO”。 如果`k > 1`，数字变成一串像`111...1`，仍然由`k > 1`规则并立即归类为“否”，无需构建。 

另一个边缘情况是具有重复的小素数，例如`x = 2, k = 2`。 构造的数为`22`，这显然是复合的，并且由于任何素性检查之前的重复规则，算法正确地返回“NO”。 

最后，大素数`k = 1`， 例如`x = 999999937`，纯粹由素性检查循环处理。 该算法仅取决于平方根界限，确保正确性，不会出现溢出或转换问题。
