 ## 解决方案
 ## 问题理解

 我们有一个矩形网格，其中每个单元格要么是空的，要么包含大米。 我们还有$k$鸡。 任务是将整个网格精确地划分为$k$连接区域，每只鸡一个，这样每个细胞都属于一个区域，并且每个区域都是 4 向连接的。 

不同的是，只有水稻细胞对平衡很重要：每只鸡都“收集”其区域内的水稻细胞，我们希望使所有鸡之间的水稻细胞的最大和最小数量之间的差异尽可能小。 

所以真正的问题是一个约束网格划分问题：将网格划分为$k$连接的组件，每个组件都非空，同时在组件之间尽可能均匀地分布水稻​​细胞。 

网格尺寸可达$100 \times 100$， 和$k \le 62$。 在所有测试用例中，单元总数足够小，足以进行每个测试用例的线性扫描。 

一个关键的结构性限制是每个区域都需要连通性。 这立即排除了每个单元的任意贪婪分配，除非我们确保我们永远不会“破坏”连接。 

当水稻细胞稀疏或聚集时，会出现微妙的边缘情况。 例如，如果所有稻米单元格都位于单个类似路径的区域中，如果我们不仔细考虑几何形状，则通过先计算稻米然后分配的天真平衡可能会产生断开的区域。 

另一个边缘情况是当$k$很大，特别是$k = 62$，这正是可用的数字、大写和小写字母形式的不同输出字符的数量。 这强烈暗示每只鸡可以由单个连续的遍历段而不是复杂的形状来表示。 

## 方法

 暴力方法会尝试将每个单元分配给其中一个$k$标签，同时确保连接约束适用于所有标签。 这成为一个具有全局连接约束的图划分问题，通常是指数级的。 即使我们限制自己按顺序分配单元格，我们仍然需要维护$k$增加连接的组件并跟踪每个组件的大米分布，这导致状态空间随着网格大小呈指数增长。 

关键的见解是我们实际上不需要“解决”全局分区问题。 我们可以将网格线性化为遍历顺序，使得访问过的单元格的每个前缀形成一个连通区域。 如果我们随后将这种遍历的连续部分分配给鸡，则每只鸡的区域仍然通过构造连接。 

实现此目的的标准方法是对网格进行 DFS 或 BFS 遍历，列出连接路径中的所有单元格。 一旦我们有了这个排序，问题就简化为将序列分成$k$连续的段，同时尽可能均匀地分配稻米数量。 我们自动确保连接，唯一剩下的问题是平衡段大小，以便大米分布尽可能均匀。 

因为$k \le 62$，我们可以为每只鸡分配至少一个细胞，并贪婪地分配剩余的细胞，同时跟踪每个部分中的稻米数量。

 ## 算法演练

 我们构建网格中所有单元的 DFS 顺序。 然后我们将该序列划分为$k$连续的部分，确保每个部分都非空。 由于我们控制遍历顺序，因此每个前缀保持连接，因此每个段都是连接的。 

1. 在网格上运行 DFS，按访问顺序收集所有单元格。 

该顺序必须尊重邻接性，以便遍历的任何前缀都保持连接。 
2. 令结果列表为`order`与长度$n = r \cdot c$。 
3. 为每只鸡分配至少一个单元格，确保第一个单元格$k-1$每个分段都从订单中的一个单元格开始。 
4.以循环方式将剩余的细胞一只一只地分配给鸡，但有偏差，以便较早的鸡相对于其他鸡不会变得太大。 
5. 为每个段分配一个字符标签：数字、大写字母、小写字母，最多 62 个不同的符号。 
6. 根据作业填写答案。 

关键的平衡步骤是我们确保段大小最多相差 1，这间接保持了 Rice 计数平衡，因为 Rice 单元格沿着相同的遍历顺序分布。 

### 为什么它有效

 DFS 遍历保证排序的每个前缀对应于一组连接的网格单元。 因此，遍历的任何连续段也是相连的。 由于每只鸡只接收一个连续的片段，因此所有连接约束都会自动满足。 

平衡属性来自于我们几乎均匀地分布单元格的事实$k$段。 由于除了遍历中的位置外，每个细胞都被对称处理，因此水稻细胞不能不成比例地集中在一个片段中，超过由至多一个细胞边界移动引起的常数因子差异。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

dirs = [(1,0),(-1,0),(0,1),(0,-1)]

def solve():
    r, c, k = map(int, input().split())
    grid = [list(input().strip()) for _ in range(r)]
    
    visited = [[False]*c for _ in range(r)]
    order = []
    
    def dfs(x, y):
        visited[x][y] = True
        order.append((x, y))
        for dx, dy in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < r and 0 <= ny < c and not visited[nx][ny]:
                dfs(nx, ny)
    
    # run DFS from first cell
    dfs(0, 0)
    
    n = len(order)
    base = n // k
    extra = n % k
    
    ans = [[''] * c for _ in range(r)]
    
    idx = 0
    labels = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ"
    
    for i in range(k):
        size = base + (1 if i < extra else 0)
        for _ in range(size):
            x, y = order[idx]
            ans[x][y] = labels[i]
            idx += 1
    
    for i in range(r):
        print("".join(ans[i]))

solve()
```DFS 构建了网格的全局连接排序。 分割步骤确保每只鸡获得该顺序的连续块，这直接保证了连接的区域。 

选择的标签字符串最多可支持 62 只鸡，与约束完全匹配。 

一个微妙的实现细节是，DFS 必须覆盖整个网格，即使它包含未访问的遍历起点假设的断开区域。 在这个解决方案中，我们假设网格是完全可达的或被有效地视为单次遍历； 实际上，只要发现未访问的单元，就会循环所有单元并启动 DFS，从而连接订单。

 ## 边缘情况

 一个极端的情况是当网格完全装满大米并且$k = rc$。 在这种情况下，每个细胞都必须成为自己的区域。 DFS 排序仍然有效，每个段退化为单个单元，从而轻松地保留了连接性。 

另一种边缘情况是网格高度稀疏时。 即使水稻细胞是孤立的，连接性也是在所有细胞上定义的，而不仅仅是水稻，因此 DFS 仍然会产生有效的遍历。 分割不依赖于大米分布，这避免了脆弱的贪婪决策。 

最后一种边缘情况是网格倾斜，导致 DFS 路径又长又窄。 即使如此，连续的段仍然保持连接，因为沿遍历顺序保留了邻接关系，因此没有段可以“跳跃”跨越断开连接的单元。
