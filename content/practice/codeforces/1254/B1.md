 ## 解决方案
 ## 问题理解

 我们被要求重新排列盒子里的巧克力，这样爱丽丝就会开心。 每个$n$盒子里有零块或一块巧克力，并且至少有一个盒子包含一块巧克力。 如果所有非空盒子都有相同数量的可被某个整数整除的巧克力，爱丽丝会很高兴$k > 1$。 由于所有盒子最多包含一块巧克力，因此唯一可能的$k > 1$是$2$或更高。 在这种情况下，因为$a_i \le 1$，巧克力的总和很小，不能被整除$k > 1$除非我们将所有巧克力合并成连续的块。 

查理只能以一秒的增量将巧克力移至相邻的盒子。 因此，问题简化为用最少的动作将所有巧克力聚集在一起。 每次移动都会将巧克力移动一个位置，最小总距离是到巧克力中间位置的距离之和。 

约束条件告诉我们$n$可以达到$10^5$，所以任意$O(n^2)$或者天真的尝试尝试所有可能的动作会太慢。 自从$a_i \le 1$, 巧克力总数最多为$n$，这意味着线性或近线性算法就足够了。 当所有巧克力已经放在一起、位于边缘或只有一个盒子有巧克力时，就会出现边缘情况。 尝试在不使用中值属性的情况下检查每个可能的集群的简单解决方案将失败。 

## 方法

 暴力解决方案将尝试盒子的每个连续部分，并尝试将巧克力移动到该部分，计算总移动量。 这在原则上是正确的，但需要$O(n^2)$时间：对于每个片段，我们将巧克力到每个位置的距离相加，这超出了时间限制。 

关键的观察结果是点到中位数的距离总和最小化。 如果我们记录包含巧克力的盒子的索引并选择这些索引的中值作为合并中心，则所需的总秒数只是从每个巧克力到该中值的距离之和。 对位置进行排序后，这会将问题减少到线性时间。 

在这个问题中，由于$a_i \le 1$，巧克力的位置可以收集在一个数组中，并将它们移动到围绕中线形成一个连续的块，以确保总距离最小。 中位数向左或向右的任何移动都会增加总移动量，因此中位数是最佳整合点。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化一个空列表来存储所有包含巧克力的盒子的索引。 
2. 遍历数组$a$，附加索引$i$到列表中，如果$a_i = 1$。 这收集了巧克力的所有位置。 
3. 如果巧克力的总数是$1$， 返回`0`因为爱丽丝已经对一块巧克力感到满意了。 
4. 找到位置列表的中值索引。 如果巧克力的数量为偶数，则两个中心巧克力之间的任何中值索引都有效。 中位数最小化距离之和。 
5. 将总秒数计算为每种巧克力指数与中值指数之间的绝对差之和。 这对应于所需的最少移动。 
6. 返回计算出的总数。 

为什么有效：当目标位置是中位数时，绝对差值之和最小。 通过将每块巧克力移动到这个中间位置，我们保证了最小的总距离。 围绕任何其他点进行合并都会严格增加距离总和。 该算法可以处理所有边缘情况，因为即使巧克力位于边界或已经连续，它也能正常工作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

positions = [i for i, val in enumerate(a) if val == 1]

if len(positions) == 1:
    print(0)
else:
    m = len(positions)
    median_index = positions[m // 2]
    total_moves = sum(abs(pos - median_index) for pos in positions)
    print(total_moves)
```该代码首先收集所有巧克力的位置。 中位数由该列表长度的整数除法确定。 绝对差之和计算出最小总移动量。 使用列表理解可以简化位置收集。 由于该问题保证至少有一颗巧克力，因此我们不需要单独处理空数组。 我们使用从零开始的索引来简化距离计算。 

## 工作示例

 输入示例 1：```
3
1 0 1
```巧克力的位置：`[0, 2]`中位指数：`2 // 2 = 1`→ 中间位置是`0`（或者`2`，结果相同）

 总动作：`abs(0-1) + abs(2-1) = 1 + 1 = 2`这与示例输出相匹配。 

自定义输入2：```
5
1 0 0 1 1
```巧克力的位置：`[0, 3, 4]`中位指数：`3 // 2 = 1`→ 中间位置是`3`总动作：`abs(0-3) + abs(3-3) + abs(4-3) = 3 + 0 + 1 = 4`这表明中位数最大限度地减少了总变动，并且围绕任何其他指数进行整合将需要更多的时间。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 迭代数组并对最多 n 块巧克力的距离求和 |
 | 空间| O(n) | 存储所有巧克力的位置 |

 给定$n \le 10^5$，该算法以线性时间运行，并且完全符合 1 秒时间限制和 256 MB 内存限制。

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

 ## 边缘情况

 当只有一块巧克力时，Alice 已经很开心了，所以输出为`0`。 算法正确返回此值。 当巧克力位于数组的末尾时，中值计算可确保最小的总移动次数，而不需要显式处理边界。 该算法还可以自然地处理连续的巧克力，因为如果它们已经是连续的，那么中位数的绝对差之和将为零。
