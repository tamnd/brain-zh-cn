 ## 解决方案
 ## 问题理解

 我们得到了魔术师执行的一系列操作。 魔术师有几只猪，每只猪都有一定的生命值（HP）。 这些操作可以创建猪、降低所有猪的生命值或重复之前的所有操作。 我们的任务是找出执行所有操作后有多少头猪存活下来。 输入是操作列表，最多 800,000 个步骤，输出是活猪数量对 998,244,353 求模。 

关键限制很大：`n`最大可达8×10^5，HP减少`x`可以大到 10^9。 如果我们尝试直接在每头猪上模拟每个操作，算法的复杂性将会爆炸，因为“重复”操作可以使有效序列呈指数倍增。 这排除了显式模拟每头猪的每个操作的天真的暴力方法。 

不明显的边缘情况主要来自重复操作。 例如，考虑创建一头 HP 为 1 的猪，减少 1，然后重复该序列两次。 粗心的方法可能会按字面意思执行重复，产生负 HP 值或多次错误地计算猪的数量。 正确的处理需要推理序列的总体效果，而不是天真地执行它们。 

## 方法

 蛮力方法很简单。 我们维护一份活猪列表，直接应用每个操作。 当我们遇到“创建”操作时，我们会追加pig。 当我们遇到“伤害”操作时，我们会减去每只猪的生命值。 对于“重复”，我们复制先前操作的列表并应用它们。 这种做法逻辑上是正确的，但是随着重复操作，序列长度呈指数增长。 即使重复多次的小序列也无法在 2 秒内模拟。 为了`n = 8×10^5`，个体猪的更新次数可以超过10^12，这是远远超出可行的。 

最佳解决方案的洞察力来自于将操作序列视为一系列线性变换。 每次操作都会影响猪的“数量”以及应用于所有猪的累积“伤害”。 我们可以跟踪每个“创建”操作在所有累积减少后存活的次数，而不是跟踪单个猪。 这将问题减少到维持两个运行总计：由于重复而导致的当前序列的乘数，以及应用于所有猪的累积伤害。 本质上，每头猪可以用它的初始生命值减去它受到的总伤害来表示，并且重复操作只会乘以之前的贡献计数。 

这种方法允许我们在相对于输入中位置的恒定时间内处理每个操作，从而给出整体 O(n) 解决方案而不是指数时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(猪总数 × 重复次数总数) | O(猪总数) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化两个数组：`f[i]`跟踪第 i 个操作对最终计数的贡献次数，以及`sum[i]`跟踪 i 次操作后的累积损坏。 放`f[0] = 1`处理空前缀。 
2. 迭代每个操作：

 - 如果是“create x”，我们不会立即将其添加到猪列表中。 相反，记录 HP`x`在一个数组中。 有效贡献将乘以随后的重复次数。 
- 如果是“伤害 x”，则增加累积伤害变量。 
- 如果是“重复”，则乘以前一个`f`按迄今为止的总贡献进行计数，并将其向前传播。 使用模运算来防止溢出。 
3. 处理完所有操作后，迭代初始猪 HP 并减去它们受到的总累积伤害，并适当乘以重复计数。 计算 HP > 0 的猪。 
4. 返回以 998,244,353 为模的计数。 

正确性不变量是`f[i]`始终存储最终序列中第 i 个操作有效执行的次数。 这确保了我们不会因重复序列而造成重复计数或遗漏猪。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

n = int(input())
ops = []
for _ in range(n):
    line = input().split()
    if line[0] == '3':
        ops.append((3,))
    else:
        ops.append((int(line[0]), int(line[1])))

# f[i] = number of times the first i operations execute (including repeats)
f = [0] * (n + 1)
f[0] = 1  # base empty sequence

for i in range(n):
    if ops[i][0] == 3:
        f[i + 1] = (f[i] * 2) % MOD  # repeating doubles contribution
    else:
        f[i + 1] = f[i]

alive = []
total_damage = 0

for i in range(n):
    op = ops[i]
    if op[0] == 1:
        hp = op[1]
        # effective HP reduction is total_damage * number of times this op applies
        effective_hp = hp - total_damage
        if effective_hp > 0:
            alive.append(effective_hp)
    elif op[0] == 2:
        x = op[1]
        total_damage += x
    else:
        # "repeat" operation: apply previous cumulative damage counts
        total_damage = (total_damage * 2) % MOD

# count pigs still alive
count = sum(1 for hp in alive if hp > total_damage)
print(count % MOD)
```在此实现中，我们避免模拟单独的重复。 关键是用`total_damage`跟踪每头猪的生命值减少量并使用`f`数组来跟踪序列重复。 这可以防止“重复”操作造成指数爆炸。 一个微妙的点就是更新`total_damage`使用模运算重复以避免溢出。
