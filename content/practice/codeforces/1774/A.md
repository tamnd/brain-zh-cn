 ## 解决方案
 ## 问题理解

 我们得到一个二进制字符串，一个序列`0`和`1`，我们想要插入`+`或者`-`在每对连续数字之间进行计算，以使算术表达式结果的绝对值最小化。 从概念上讲，每个`1`或者`0`字符串中的值可以从运行总计中添加或减去，我们的目标是平衡这些选择以使总计尽可能接近于零。 

输入包含多个测试用例。 每个测试用例指定字符串长度和字符串本身。 每个测试用例的输出是一系列`+`和`-`长度符号`n-1`， 在哪里`n`是字符串长度。 

限制是适度的：最多 2,000 个测试用例，字符串长度最多 100。这意味着任何运行在`O(n)`每个测试用例是可行的，因为总操作最多为 200,000 次，完全在 1 秒的限制之内。 暴力枚举所有`2^(n-1)`可能的符号序列是不可能的，因为这将花费天文数字的时间`n=100`。 

值得关注的边缘情况包括完全由以下组成的字符串`0`s，其中所有符号选择都为零，并且字符串以以下开头或结尾`1`，这可能会迫使仔细选择符号以避免不必要的大总数。 交替的字符串`1`沙`0`还可以暴露天真的策略，这些策略总是在不进行调整的情况下进行加法或减法。 

## 方法

 天真的方法是尝试每一种可能的组合`+`和`-`数字之间的符号，计算每个数字的结果值，并跟踪绝对值最小的那个。 这将涉及评估`2^(n-1)`每个测试用例的序列，这对于非常小的情况是可行的`n`但会以指数方式爆炸超出`n=20`。 

关键的观察是我们只需要确定每个的符号`1`。 一个`0`无论符号如何，都没有贡献，所以所有`0`可以安全使用`+`。 为了`1`s，交替符号可以最小化运行总计，因为每个`1`可以增加或减少总和。 一个简单的贪心规则出现了：如果添加了先前的非零值，则减去当前的值`1`; 如果被减去，则添加当前的`1`。 这保证了总和永远不会偏离零太远。 

我们可以在不显式跟踪运行总数的情况下实现这一点。 我们从第一个数字开始，假设`+`，然后交替`+`和`-`对于每个后续的`1`。 全部`0`s 被分配`+`。 这会产生一个有效的最小绝对值序列，因为任何其他序列要么保持相同的总和，要么增加它。

 | --- | --- | --- | --- |
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 贪心交替| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 对于每个测试用例，请阅读`n`和字符串`a`。 
2.初始化一个空列表`signs`来存储序列`+`和`-`。 
3. 追踪最后使用的标志`1`作为`last_sign`，开始于`'+'`。 
4. 迭代字符串中从第二个到最后一个的每个字符：

 a. 如果当前字符是`'0'`, 附加`'+'`到`signs`。 

b. 如果当前字符是`'1'`，附加相反的`last_sign`到`signs`并更新`last_sign`到这个新标志。 
5. 处理完字符串后，加入`signs`list 成字符串并输出。 

为什么有效：每个`1`相对于前一个符号交替`1`，防止连续的正贡献累积并不必要地增加绝对值。`0`s 不影响总和，因此分配它们`+`是安全的。 这始终保持接近于零的运行总和，实现了最小的绝对值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = input().strip()
    signs = []
    last_sign = '+'
    for i in range(1, n):
        if a[i] == '0':
            signs.append('+')
        else:
            # alternate the sign for '1'
            last_sign = '-' if last_sign == '+' else '+'
            signs.append(last_sign)
    print(''.join(signs))
```该解决方案首先使用快速 I/O 读取所有输入值，以高效处理多达 2,000 个测试用例。 这`signs`列表累积输出，并且`last_sign`跟踪前一个非零符号以确保交替。 通过从第二个字符迭代到最后一个字符可以避免差一错误。 每个测试用例的输出都连接成一个字符串。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = input().strip()
        signs = []
        last_sign = '+'
        for i in range(1, n):
            if a[i] == '0':
                signs.append('+')
            else:
                last_sign = '-' if last_sign == '+' else '+'
                signs.append(last_sign)
        out.append(''.join(signs))
    return '\n'.join(out)

 ## 边缘情况

 对于像这样的字符串`0000`，算法分配所有`+`。 运行总和始终为零，这是最佳的。 对于所有的字符串`1`s,`111`，算法交替`+`和`-`标志为`-+`，总共给出`1-1+1 = 1`或者`-1+1-1=-1`取决于初始假设，该假设达到最小绝对值 1。该算法处理交替`1`沙`0`没有特殊检查，因为`0`总是使用`+`并且不要打扰总和。
