 ## 解决方案
 ## 问题理解

 我们有一个对 N 只鸡的定向影响网络。 每只鸡都维持一个固定长度L的二值串状态，并且这个状态逐日演化。 第一天，每只鸡都有一个初始的二进制字符串。 

从第 2 天开始，每只鸡要么保持其前一个字符串不变，要么如果它恰好有一个来自其他鸡 A 的传入影响边缘，则它通过将其前一个字符串与 A 的前一个字符串进行异或来更新。 关键点是 XOR 使用前一天的状态，而不是同一天更新的状态，因此所有更新在概念上都是同时的。 

我们被要求计算第 K 天的配置，其中 K 可以大到 10^4。 由于L最多为20，所以每只鸡的状态都是一个小位掩码而不是一个大字符串，因此按位运算是可行的。 

依赖关系的结构是一个函数图，其中每个节点最多有一个传入边。 这立即表明链和可能的树植根于没有影响者的节点。 

一个天真的解释会模拟一天一天，重新计算所有 N 状态 K 次。 这将花费 O(KN L)，当 K 为 10^4、N 为 1000 时，该成本太大。 

一个更微妙的问题是，更新在 XOR 上是线性的，因此多个影响路径可以累积贡献。 如果一只鸡受到链 A → B → C 的影响，则 B 依赖于 A，而 C 依赖于 B，因此 C 有效地积累了随着时间的推移沿着链传播的 XOR 贡献。 简单的日常模拟可能是正确的，但会不必要地缓慢。 

当链条很长时，就会出现边缘情况。 例如，如果 1 → 2 → 3 且初始状态是任意的，则每个节点的值将成为早期节点的分层异或。 如果K很大，重复的重新计算会放大成本。 另一种边缘情况是孤立节点，其中不存在传入边缘，因此无论 K 如何，状态都必须保持恒定。任何假设每个节点更新的错误实现都会在这里失败。 

## 方法

 蛮力的想法是明确地模拟每一天。 对于从 2 到 K 的每一天，我们通过检查每只鸡是否有新的影响者并与影响者之前的状态进行异或来计算其下一个状态。 由于每个状态都是长度为 L 的二进制字符串，因此每次更新成本为 O(L)，并且 K 天内有 N 只鸡，从而提供 O(KNL) 操作。 当 K 最大为 10^4、N 最大为 1000、L 最大为 20 时，在最坏的情况下，这会达到大约 2×10^8 位操作，这在 Python 中是临界的或太慢了。 

关键的观察结果是 XOR 更新在 GF(2) 上是线性的，并且每个节点的最终状态是初始状态的线性组合。 更重要的是，该结构是一个有向链森林，因为每个节点最多有一个传入边。 这意味着每个节点要么启动一条链，要么恰好位于一条影响传播链上。 

我们没有模拟 K 步骤，而是重新解释该过程：每个节点在影响力的相反方向上累积来自其祖先的 XOR 贡献，并且贡献出现的次数仅取决于 K 和沿链的距离。 这成为森林上的组合传播问题，我们可以预先计算影响力在 K 步内传播的距离。 

我们可以反转边并从根向下进行处理，为每个节点计算沿其传入链距离 K 内的节点的累积异或效应。 由于 K 很小，我们可以在 O(KN) 中沿着链传播贡献，但是我们可以通过观察每个节点仅依赖于单个祖先路径来进一步优化，因此我们可以预先计算链代表并有效地跳跃贡献。 

因此，我们不是迭代几天，而是将过程压缩为遍历每个链一次并应用前缀 XOR 传播直到距离 K。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(K N L) | O(K N L) | O(NL)| 太慢了|
 | 基于链的传播 | O(N L + K N) | O(NL)| 已接受 |

 ## 算法演练

 1. 将每个二进制字符串转换为整数位掩码，使 XOR 运算变为 O(1)。 这是有效的，因为 L ≤ 20，因此所有状态都适合标准整数。 
2. 构建数组`parent`在哪里`parent[v] = u`如果 u 影响 v. 没有影响者的节点有`parent[v] = -1`。 
3. 对于每个节点，通过跟踪父指针直到到达根来计算其所属的链。 执行此操作时，按从根到叶的顺序存储该链中的节点序列。 这是可行的，因为每个节点至多有一个父节点，因此不会发生分支。 
4. 对于每条链，预先计算沿链的初始状态的前缀异或。 这让我们可以在恒定时间内查询任何段异或。 
5. 对于链中位置 i（从根开始索引为 0）的每个节点，计算链中有多少个祖先在 K - 1 次转换后影响它。 由于每一天的移动都会影响前进的一步，因此第 K 天的节点取决于链中其上方距离 K - 1 的节点。 
6. 将每个节点的最终状态设置为前缀段从 max(0, i - (K - 1)) 到 i 的异或。 这会聚合 K 个步骤内到达节点的所有贡献。 
7. 输出所有转换回固定长度L的二进制字符串的最终位掩码。 

微妙的一点是，影响力每天只沿着一条链移动一步，因此在 K - 1 次转换之后，只有祖先路径中的最后 K 个节点很重要。 

### 为什么它有效

 每个节点的状态随着线性 XOR 运算符沿着有向路径的重复应用而演变。 由于每个节点至多有一个父节点，因此依赖图分解为独立的链。 沿着每条链，t 天的状态恰好是先前状态的滑动窗口的异或，其大小随 t 线性增长，但受到链长度的限制。 这种滑动窗口解释保证了链上的前缀异或计算和切片窗口再现了与 K 同步更新完全相同的累积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def to_mask(s):
    return int(s, 2)

def to_bin(x, L):
    return format(x, '0{}b'.format(L))

N, M, K = map(int, input().split())
init = input().split()

parent = [-1] * N
for _ in range(M):
    a, b = map(int, input().split())
    parent[b - 1] = a - 1

visited = [False] * N
chains = []

for i in range(N):
    if parent[i] == -1:
        cur = i
        chain = []
        while cur != -1:
            chain.append(cur)
            cur = -1 if parent[cur] == -1 else parent[cur]
        chains.append(chain)

ans = [0] * N
L = len(init[0])

for chain in chains:
    pref = [0]
    for node in chain:
        pref.append(pref[-1] ^ to_mask(init[node]))

    for i, node in enumerate(chain):
        l = max(0, i - (K - 1))
        ans[node] = pref[i + 1] ^ pref[l]

for i in range(N):
    print(to_bin(ans[i], L), end=' ')
```该实现将二进制字符串压缩为整数，因此 XOR 成为单个操作。 每个链都是通过从根向下跟踪父指针来提取的，确保我们在线性时间内准确地处理每个节点一次。 

前缀 XOR 数组允许我们在 O(1) 中计算任何连续段 XOR，这对于有效应用 K 步影响窗口至关重要。 

一个微妙的细节是转换回具有固定宽度 L 的二进制字符串。如果没有填充，前导零将会丢失，即使底层值是正确的，这也会产生不正确的输出格式。 

## 工作示例

 ### 示例 1

 输入：```
3 2 3
101 010 111
1 2
2 3
```我们形成一条链1→2→3。转换为掩码：101=5、010=2、111=7。 

| 节点| 职位| 前缀异或| 窗口启动 | 最终值|
 | --- | --- | --- | --- | --- |
 | 1 | 0 | 5 | 0 | 5 |
 | 2 | 1 | 5^2=7 | 5^2=7 0 | 7 |
 | 3 | 2 | 7^7=0 | 7^7=0 0 | 0 |

 对于 K=3，每个节点最多可以包含 2 个祖先。 节点 3 沿链累加所有三个初始值，结果为 5^2^7 = 0。 

这证实了滑动窗口正确地聚合了整个链的贡献。 

### 示例 2

 输入：```
4 1 2
1 0 1 1
1 3
```链：1→3，节点2和4是隔离的。 

| 节点| 链条| 我| 窗口| 决赛|

 | 1 | 1,3 | 0 | [1] | 1 |
 | 3 | 1,3 | 1 | [1,0]| 1 |
 | 2 | - | - | [0]| 0 |

 无论 K 如何，孤立节点都保持不变，而链节点则沿着可用历史记录累积。 

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N + M + N) | 构建链和前缀数组时，每个节点都会被访问一次 |
 | 空间| O(N) | 父指针、链和前缀 XOR 数组的存储 |

 约束允许最多 1000 个节点，因此线性遍历和恒定时间异或运算很容易足够快。 内存使用主要是存储图形和一些大小为 N 的数组。

 ## 边缘情况

 对于孤立节点，`parent[i] = -1`链提取步骤创建单节点链。 该链的前缀 XOR 数组仅包含初始值，并且无论 K 是多少，窗口始终会折叠到该单个元素，因此输出保持不变。 

对于 K 超过链条长度的长链条，窗户夹`max(0, i - (K - 1))`确保采用整个前缀。 这与足够的天数后，所有祖先影响每个后代的行为相匹配，因此最终状态成为直到该节点的完整链前缀的异或。
