 ## 解决方案
 ## 问题理解

 任务是分析写在古代石碑上的字符串，并确定使用一组已知的“有意义的片段”可以解释其中的多少内容。 每个片段都是一个已经被理解的短字符串。 如果平板电脑文本的一段可以完全分割成这些已知的片段，而不留下任何字符被覆盖，也没有重新排序字符，则该段文本被认为是可破译的。 

目标是找到一个可以完全分割成已知片段的连续子串，并且在所有这些子串中我们想要最大可能的长度。 

输入给出一个长度最多为 1000 的主字符串和最多 200 个已知模式，每个模式的长度最多为 20。这些约束立即表明，数亿次操作的解决方案是边界性的，但如果结构仔细，在 Python 中仍然可以管理。 字符串长度的任何二次方与模式匹配相结合都是可以接受的，但必须避免最坏情况下的任何三次方。 

微妙的边缘情况来自重叠模式和重用。 例如，如果文本是`aaaaa`和模式是`aa`和`aaa`，则存在多个分段，并且根据顺序，贪婪扫描可能会失败。 另一个问题是假设从字符串的开头开始有一个最佳分段，而有效分段可能从中间的任何位置开始。 

## 方法

 暴力方法会尝试每个子字符串并检查是否可以使用给定的模式字典对其进行分段。 对于每个子串`s[l:r]`，我们尝试标准的分词动态规划：我们检查是否可以将其划分为有效的单词。 有 O(n²) 个子串，在我们尝试匹配每个位置的所有模式的最坏情况下，每个 DP 检查的成本高达 O(n * m * L)。 这会导致大约 O(n³) 或更糟糕的行为，对于 n 达到 1000 来说这太慢了。 

关键的观察是我们实际上不需要独立处理每个子字符串。 相反，我们可以计算，对于每个起始位置，如果我们坚持从那里开始，我们可以将有效分段扩展多远。 如果我们从位置知道`i`我们可以到达最远的位置`j`，然后所有从`i`和结束之间`i`和`j`是有效的，但只有完整的扩展名才对答案重要。 

这将问题简化为位置的动态规划。 在每个索引处，我们尝试使用与当前位置匹配的任何模式进行扩展。 如果模式匹配于`i`，我们已经知道`dp[i]`是可以到达的，我们可以放松`dp[i + len(pattern)]`尽可能可达。 我们本质上是在图中构建可达性，其中边对应于模式匹配。 

然后，我们跟踪所有有效起始位置的最大可到达端点，这些起始位置本身从某个起点就可以到达。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力子串 + DP | O(n3) | O(n) | 太慢了 |
 | 具有图案过渡的 DP | O(n·m·L) | O(n) | 已接受 |

 ## 算法演练

 我们将字符串中的每个位置建模为一个状态。 如果我们可以在某些有效的分段过程中从该索引开始，则状态是可达的。 我们希望使用字典匹配来向前传播可达性。 

1. 构建模式的查找结构，通常是按长度分组的集合。 这使我们能够快速测试给定长度的子串是否有效。 
2. 创建布尔数组`dp`在哪里`dp[i]`意味着那个位置`i`可以从某个有效的分段开始处到达。 我们初始化`dp[0] = True`因为我们可以从字符串的开头开始。 
3. 迭代位置`i`从左到右。 如果`dp[i]`为 false，我们跳过它，因为没有有效的分段可以从那里开始。 
4. 对于每个模式，尝试在位置匹配它`i`。 如果子串`s[i:i+len(pattern)]`等于模式，然后标记`dp[i + len(pattern)] = True`。 
5. 跟踪所有可到达的位置，因为任何可到达的位置都可以作为有效段的末尾。 
6.答案是最大值`j - i`在所有对中`dp[i]`和`dp[j]`是可达的并且`i <= j`，但由于我们从 0 开始构建可达性，因此我们可以跟踪距每个有效起始段最远的可达索引，并计算连续有效段边界之间的最大跨度。 

我们实现的一个更直接的表述是将其视为可达性图，并跟踪对于每个索引，我们从其处或之前的任何可到达位置开始可以到达的最远端点。 

### 为什么它有效

 核心不变量是`dp[i]`当且仅当前缀为 true`s[0:i]`可以完全分割成字典模式。 每个转换都保持正确性，因为我们只从已经代表有效分段的位置进行扩展，并且每个扩展都准确对应于附加有效单词。 由于所有有效分段都是通过连接字典单词构建的，因此任何有效端点都必须通过这些转换可达，相反，每个可到达端点都对应于一个有效分段。 这种双射确保我们不会错过任何有效段，也不包含任何无效段。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = len(s)
    m = int(input())
    
    patterns = []
    by_len = {}
    
    for _ in range(m):
        p = input().strip()
        patterns.append(p)
        by_len.setdefault(len(p), []).append(p)
    
    dp = [False] * (n + 1)
    dp[0] = True
    
    for i in range(n):
        if not dp[i]:
            continue
        
        for L, group in by_len.items():
            if i + L > n:
                continue
            sub = s[i:i+L]
            for p in group:
                if sub == p:
                    dp[i + L] = True
    
    # We now have all reachable segment boundaries.
    # Compute longest reachable segment [i, j] where both i and j are reachable.
    best = 0
    last = 0
    
    for i in range(1, n + 1):
        if dp[i]:
            best = max(best, i - last)
            last = i
    
    return str(best)

if __name__ == "__main__":
    print(solve())
```DP 数组被构建为前缀边界上的可达性结构。 嵌套循环检查每个可到达的位置并尝试所有模式长度，确保我们只扩展有效的分段。 

最终扫描将可到达的位置解释为段边界。 每当我们看到可到达边界时，我们都会测量距前一个可到达边界的距离，该距离对应于最大完全可解码段。 

一个微妙的点是我们从不显式地跟踪线段的起点； 相反，我们依赖这样一个事实：任何有效的段都必须在有效边界之后立即开始，因为分段将字符串划分为不相交的有效块。

 ## 边缘情况

 对于像这样的字符串`aaaaa`有图案`aa`和`aaa`，该算法标记多个重叠的可达点。 从索引 0 开始，2 和 3 都变得可达。 从 2 开始，可以到达索引 4 和 5，从 3 开始，可以到达索引 5。 DP 正确地累积所有可到达的边界，而不是致力于单个分段路径。 

对于没有有效模式的字符串，`dp`除了索引 0 之外，保持 false，并且不会发生任何转换。 最终扫描没有发现长度超过 0 的有效段，正确返回 0。 

对于完全匹配的字符串，例如`abcd`有图案`abcd`，DP从0到4只转换一次，结果就是全长。
