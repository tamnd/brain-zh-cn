 ## 解决方案
 ## 问题理解

 每朵花都有两个实际上相同的属性：花瓣数量和价格。 一朵花与`k`花瓣的成本正好`k`硬币。 

我们可以购买商店中可用的鲜花的任何子集。 仅当任意两朵所选花朵的花瓣数之差最多为 1 时，该花束才有效。 由于在这个简单版本中所有花朵都是单独的对象，因此每朵花都可以被拿走或不拿走。 

目标是最大化花瓣总数，同时花费最多`m`硬币。 

一个有用的观察立即出现：因为成本等于每朵花的花瓣，所以在预算下最大化花瓣与最大化总成本，同时保持总成本最多是完全相同的`m`。 

对花瓣差异的限制使得这个问题变得有趣。 如果花束中含有一朵花`x`花瓣，那么其他所有花都必须有`x`或者`x + 1`花瓣。 任何更大的间隙都会违反该条件。 

全部的总和`n`跨测试用例最多`2 · 10^5`。 这意味着`O(n^2)`解决方案大约需要`4 · 10^10`最坏情况下的操作，远远超出了极限。 对每个测试用例进行排序，然后进行线性处理是完全可行的，因为`O(n log n)`超过`2 · 10^5`元素仅需要几百万次操作。 

一些边缘情况很容易破坏粗心的解决方案。 

考虑：```
n = 3, m = 10
flowers = [2, 2, 2]
```答案是`6`。 总是尝试花费全部预算的解决方案会错误地计算总成本`10`，尽管只有`6`花瓣可用。 

考虑：```
n = 3, m = 7
flowers = [2, 2, 3]
```答案是`7`，使用所有的花。 仅考虑具有一个花瓣值的花朵的解决方案将错过最佳花束。 

考虑：```
n = 4, m = 8
flowers = [1, 3, 3, 3]
```答案是`6`，从两朵有 3 个花瓣的花中获得。 将 1 瓣的花与任何 3 瓣的花放在一起是违法的，因为相差 2。 

这些例子表明，我们必须同时执行预算约束和花瓣差异约束。 

## 方法

 强力解决方案将枚举花朵的每个子集，计算其总成本，检查花瓣值是否最多相差一个，并保留最佳有效答案。 

这是有效的，因为它直接测试有效花束的定义。 不幸的是，有`2^n`子集。 即使是为了`n = 50`这是没有希望的，而实际的极限是`2 · 10^5`。 

关键的观察结果是，在按花瓣数量对花朵进行排序后，每个有效的花束都对应于一个连续的片段，其最小值和最大值最多相差一。 

为什么排序有帮助？ 假设我们对花瓣数量进行排序。 如果某些选择的花只包含值`x`和`x + 1`，然后所有这些花按排序顺序一起出现。 该区域之外的任何花的值都小于`x`或大于`x + 1`。 

现在想想目标。 由于每朵花都有正成本，如果一个片段有效但其总成本超过`m`，我们只能通过去掉左边的花来提高可行性。 这正是滑动窗口（也称为两指针）所擅长的设置。 

我们维护一个窗口`[l, r]`在已排序的数组中。 窗口必须满足两个条件：

 首先，最大值和最小值最多相差一。 

其次，窗口内的值之和不超过`m`。 

每当违反这些条件之一时，我们就会向前移动左指针，直到两者都再次成立。 每个有效窗口代表一束可行的花束，其花瓣总数等于其总和。 

最大有效窗口总和就是答案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了 |
 | 最优两指针 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对花瓣数量进行排序。 
2.初始化两个指针`l = 0`和`r = 0`，以及运行窗口总和。 
3.通过移动来扩展窗口`r`从左到右。 添加`a[r]`到运行总和。 
4. 当窗口无效时，移动`l`向前和减去`a[l]`从运行总和。 
5. 如果出现以下情况，则窗口无效：`a[r] - a[l] > 1`，这意味着花束包含的花瓣数量相差超过一朵。 

运行总和超过`m`，意味着花束成本太高。 
6. 一旦窗口再次有效，用当前窗口总和更新答案。 
7. 继续，直到每个位置都被用作右端点。 
8. 输出找到的最大有效和。 

### 为什么它有效

 每时每刻，窗口都包含排序数组的连续范围。 第一个条件保证窗口内的所有花朵的花瓣数最多相差一个。 第二个条件保证花束符合预算。 

当窗口失效时，移除左边的花是唯一有用的动作。 由于所有花卉成本都是正值，进一步扩大窗口并不能修复过多的金额。 同样，如果花瓣范围太大，则删除最小值正是缩小该范围的原因。 

每个有效的连续段在扫描过程中都显示为窗口，并且算法记录每个可行段的总和。 由于答案是最大可行和，因此该算法是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        
        a.sort()
        
        l = 0
        cur_sum = 0
        ans = 0
        
        for r in range(n):
            cur_sum += a[r]
            
            while l <= r and (a[r] - a[l] > 1 or cur_sum > m):
                cur_sum -= a[l]
                l += 1
            
            ans = max(ans, cur_sum)
        
        print(ans)

if __name__ == "__main__":
    solve()
```第一步是对鲜花进行分类。 排序后，每个有效的花束仅使用值`x`和`x + 1`成为一个连续的段。`cur_sum`存储花瓣总数，这也是当前窗口的总成本。 这允许在恒定时间内检查预算。 

这`while`循环是解决方案的核心。 它不断缩小左侧，直到两个约束同时成立。 使用循环而不是单个循环`if`至关重要，因为一次删除可能不足以恢复有效性。 

答案仅在窗口有效后更新。 由于每个有效窗口仅被考虑一次，因此最大记录总和就是最佳花束值。 

Python 整数自动处理高达`10^18`，因此不需要特殊的溢出处理。

 ## 边缘情况

 考虑：```
1
3 10
2 2 2
```整个数组形成一个有效的窗口。 运行总和变为`6`，永远不会超出预算。 算法返回`6`，正确处理预算大于所有可用鲜花总价值的情况。 

考虑：```
1
3 7
2 2 3
```排序后的数组已经是`[2,2,3]`。 窗口扩展到包含所有三朵花，产生总和`7`。 范围是`1`，所以花束是有效的。 算法返回`7`，正确允许两个相邻的花瓣值。 

考虑：```
1
4 8
1 3 3 3
```排序后，第一次`3`进入窗口范围变为`2`。 收缩环消除了`1`，仅留下`3`是。 最好的可能总和是`6`，算法记录的。 这证实了有不止一个花瓣不同的花朵永远不会放在一起。 

考虑：```
1
4 5
2 2 2 2
```窗口总和最终达到`8`，超出预算。 收缩循环不断地移除花朵，直到总和变为`4`。 算法返回`4`，表明预算约束的执行独立于花瓣差异约束。
