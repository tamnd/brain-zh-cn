 ## 解决方案
 ## 问题理解

 我们给出了一座山，表示为严格递增的高度序列，其中每个高度对应于沿斜坡的一米。 奥姆卡观察这座山，突然发生山体滑坡。 在滑坡过程中，泥土根据一个简单的局部规则从较高的点移动到较低的点：如果较高位置与紧邻其下方的位置之间的差异至少为二，则一单位的泥土会向下移动。 这种情况每分钟在所有位置上同时发生，直到不可能再有任何移动。 任务是确定滑坡稳定后的最终高度。 

输入是一个整数列表`h`长度`n`代表山的轮廓。 输出是山体滑坡完成后的最终高度列表。 

约束条件意味着`n`可达一百万，个人身高可达`10^12`。 暴力模拟会迭代数组并重复应用规则，可能需要最多`10^12`在最坏的情况下进行操作，因为高度差异可能非常大。 这对于 2 秒的时间限制来说是不可行的。 这表明我们必须找到一种更聪明、更直接的方法来计算最终高度，而不是模拟每一分钟。 

不明显的边缘情况包括连续高度之间初始间隙较大的山脉。 例如，`[0, 10]`应该产生`[5, 5]`山体滑坡之后。 简单的逐步模拟需要将 5 个单位的泥土一一移动，这太慢了。 另一个微妙的情况是当高度已经接近时，例如`[1, 2, 3]`。 在这里，滑坡没有任何作用，因为所有差异都小于二，但粗心的实现可能会尝试不必要的更新或错误计算索引。 

## 方法

 蛮力方法很简单。 我们从左到右重复扫描阵列，如果差异至少为 2，则将污垢从每个较高位置移动到其下方的较低位置。 我们重复此操作，直到没有发生任何变化。 每分钟涉及最多`n`检查并移动，如果初始间隙是`d`，我们可能需要`d/2`迭代。 在最坏的情况下，时间复杂度为 O(n * max_diff)，其中`max_diff`可以达到`10^12`。 显然，这太慢了。 

更快解决方案的关键观察是滑坡的行为就像单调流的“瀑布”问题。 每个泥土单位都会向左移动，直到无法再移动为止，并且由于移动是同时发生的，因此每个位置的最终高度仅由该段中的高度总和以及相对位置决定。 我们可以通过尽可能均匀地分布总高度，同时保持连续高度最多相差一的规则来直接计算最终高度。 本质上，我们可以将该问题视为计算高度前缀的整数平均值并正确传播舍入以满足`h_j + 1 >= h_{j-1}`健康）状况。 

这种见解导致了单遍算法，在该算法中，我们维护高度的运行总和，并通过将累积总和除以到目前为止考虑的位置数量并占据地板来分配每个位置的最小可能最终高度。 这保证了高度的降低不会超过允许的范围，并且污垢会以正确的量留下。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * max_diff) | O(n * max_diff) | O(n) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个累加和变量和一个空数组`result`存储最终高度。 累积总和表示截至当前位置的可用污垢总量。 
2. 从左到右遍历原始高度。 在位置`i`， 添加`h[i]`至累计总和。 使用整数除法计算到目前为止每个位置的平均污垢：`avg = cumulative_sum // (i + 1)`。 这表示该位置的最小可能高度`i`将污垢均匀地分布到左侧后。 
3. 追加`avg`到`result`大批。 这确保了任何位置接收的污垢都不会少于所需的污垢，并且多余的污垢可以在不违反最大差异条件的情况下流向左侧。 
4. 继续此过程直到最后一个位置。 得到的数组`result`将包含滑坡后的稳定高度。 

为什么它有效：该算法保持了第一个高度之和的不变性`i`位置在这些位置之间正确地重新分配。 通过在每一步取平均值的下限，我们确保泥土在需要时向左移动，但永远不会超过允许的差异。 原始高度的单调属性保证了这种从左到右的分配正确地模拟了同时的重新分布。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
h = list(map(int, input().split()))

result = []
cumulative_sum = 0

for i in range(n):
    cumulative_sum += h[i]
    avg = cumulative_sum // (i + 1)
    result.append(avg)

print(" ".join(map(str, result)))
```该代码使用有效地读取输入`sys.stdin.readline`可以处理高达一百万的高度。 我们维护一个累积总和来跟踪总污垢并计算每个位置的平均值以正确分配污垢。 使用整数除法自动处理地板，它模拟了除非差值至少为二否则污垢不会移动的规则。 追加到列表可确保每个高度的摊销操作为 O(1)，从而提供总体 O(n) 解决方案。
