 ## 解决方案
 ## 问题理解

 我们正在使用一个最多 25 x 25 的小网格，其中仅使用向右或向下移动即可形成从左上角单元格到右下角单元格的路径。 因此，每条路径总是有精确的$2n-1$访问过的单元格，因为每一步都会增加行或列，并且我们需要精确$n-1$向各个方向移动。 

在任何查询之前，我们可以为每个网格单元分配一个非负权重，每个权重最多为$10^{16}$。 之后，为每个查询固定一个未知的单调路径。 对于每个查询，我们只得到沿着该隐藏路径的权重总和，并且我们必须重建访问单元的精确序列。 

关键的困难在于，我们每次查询只能看到一个数字，但除非仔细构建网格，否则许多不同的路径可能会产生相同的总和。 

限制非常严格$n$，这表明指数结构是可能的。 和$n \le 25$, 最多有$\binom{48}{24}$可能的路径，大约是$10^{13}$，太大而无法直接区分每个查询。 这立即排除了任何尝试独立编码每个路径或动态模拟路径恢复的策略。 

交互性并没有改变核心结构：我们在网格中设计固定的编码，使得每条有效路径产生唯一的和，并且这种编码必须可逆到路径中。 

当考虑对称性时，会出现一种微妙的边缘情况。 许多不同的路径共享长前缀，并且任何仅依赖于行或列计数的编码都将失败，因为右移和下移的不同交错可以产生相同的聚合贡献。 像分配这样幼稚的方法$a_{x,y} = x \cdot n + y$也会失败，因为路径和不能从这种线性编码中唯一地解码，因为访问单元的不同多重集可以在总和上重合。 

真正的要求不仅仅是总和的唯一性，而是总和对路径上的一系列二元决策进行编码。 

## 方法

 强力解释是尝试分配随机或贪婪的权重，并希望所有路径都有不同的总和。 虽然这对于小规模的情况可能很有可能有效$n$，它在对抗性构造下无法提供保证，更重要的是，即使总和是唯一的，解码它们在计算上也是不可行的，因为我们需要在指数级的多个候选路径中进行搜索。 

结构洞察力是每条单调路径$(1,1)$到$(n,n)$正好是一个序列$2n-2$决策：每一步我们要么向右移动，要么向下移动。 这相当于一个二进制字符串$n-1$那些和$n-1$零。 问题归结为使用位置系统将此二进制字符串编码为单个数字。 

这表明将每个步骤的选择视为对总和贡献不同的 2 的幂。 然而，直接的每步编码不起作用，因为我们不直接观察步骤，只观察网格单元上的总和。 因此，我们不是对步骤进行编码，而是以这样的方式对单元进行编码，以便在重建过程中可以隔离每个步骤的贡献。 

关键思想是在精心选择的基础上分配仅依赖于单元的线性索引的权重：与对角线结构对齐的二的幂。 我们希望每个运动决策对应于选择两个不相交的贡献之一，确保总和唯一地确定选择的顺序。 

一种简洁的结构是根据每个单元在对角线上二进制分解中的位置为每个单元分配一个权重，确保以受控方式向右或向下移动恰好切换一位。 这减少了从总和的二进制表示恢复路径的问题，可以通过模拟转换同时检查剩余总和的一致性来贪婪地解码该路径。 

一种更直接的建设性解决方案，也是通常预期的解决方案，是分配权重，以便可以在本地恢复每个步骤的决策：我们对路径进行编码，以便在每个节点，向右和向下之间的差异可以从剩余的总和结构中严格检测到。 这是通过沿一个轴使用指数增长的权重并仔细平衡贡献来实现的，以便前缀决策不会干扰。 

一旦这种编码被固定，解码就变成了确定性行走：在每个单元格，我们检查剩余的总和是否与向右或向下移动一致，并选择唯一有效的方向。

 ## 算法演练

 我们使用与列对齐的二的幂构建网格编码。 具体来说，我们分配每个单元格$(i,j)$一个重量$a_{i,j} = 2^{(i-1)n + (j-1)}$。 这将每个单元变成二进制长度的唯一位位置$n^2$。 

然而，我们不需要所有单元完全独立，只需要每个单调路径和是唯一可解码的。 由于每条路径每步只包含一个单元格并且访问精确$2n-1$单元中，总和只是不同位的子集总和，它唯一可逆到访问集中。 

然后，我们通过模拟运动来贪婪地重建路径$(1,1)$：

 1. 开始于$(1,1)$剩余金额$k$。 始终包含起始单元格，因此减去$a_{1,1}$从$k$。 
2. 在每一步中，考虑向右还是向下移动是否会导致有效的延续。 我们检查两个候选的下一个单元格。 
3. 如果下一个单元格$(x, y+1)$以与二元分解一致的方式，权重不超过剩余总和，我们尝试取它； 否则我们采取$(x+1, y)$。 
4. 移动后，从剩余的总和中减去所选的细胞重量并继续。 
5. 继续直至达到$(n,n)$，始终保持剩余的总和与未访问的未来单元完全对应。 

关键的属性是每个单元都对应于唯一的 2 的幂，因此在任何时候，剩余的总和都准确地编码了哪些未来单元仍在路径上。 由于路径是单调且长度固定的，因此在每一步中，两个可能的移动中的一个恰好保持与剩余位结构的一致性。 

### 为什么它有效

 每个单元格的权重都是不同的 2 的幂，因此任何一组单元格的总和都是唯一的二进制数。 由于每个有效路径对应于固定大小的单元子集，因此从路径到总和的映射是单射的。 在重建过程中，我们有效地解码已知的子集和结构，附加约束是子集必须形成单调路径。 这种结构约束保证在每一步中，两个传出边中的一个恰好会产生与剩余总和一致的有效子集，因此贪婪重建不会发散。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

# assign powers of two to each cell
a = [[0]*n for _ in range(n)]
cur = 0
for i in range(n):
    for j in range(n):
        a[i][j] = 1 << cur
        cur += 1

for row in a:
    print(*row)
sys.stdout.flush()

q = int(input())

for _ in range(q):
    k = int(input())

    x, y = 0, 0
    path = [(x+1, y+1)]
    rem = k - a[0][0]

    while x != n-1 or y != n-1:
        if y + 1 < n:
            if rem & a[x][y+1]:
                y += 1
            else:
                x += 1
        else:
            x += 1

        path.append((x+1, y+1))
        rem -= a[x][y]

    for p in path:
        print(p[0], p[1])
    sys.stdout.flush()
```网格结构为每个单元分配一个唯一的位位置，以便两个子集的总和不会发生冲突。 重建保留运行余数并使用位检查来决定下一步是否必须包括剩余子集中的特定单元。 由于路径是单调的，因此步行不会重新访问单元格，因此减去访问的权重可以保持正确性。 

一个微妙的点是，我们始终依赖于剩余总和与真实路径后缀上未访问的单元格完全对应的不变式。 即使我们没有显式存储完整的子集，这也使得成员资格检查可靠。 

## 工作示例

 考虑$n=2$。 网格是：

 | 细胞| 价值|
 | ---| ---|
 | (1,1) | 1 |
 | (1,2) | 2 |
 | (2,1) | 4 |
 | (2,2) | 8 |

 路径可能是 (1,1) → (1,2) → (2,2)，总和为 1 + 2 + 8 = 11。 

开始时，剩余总和为 11 - 1 = 10。从 (1,1) 开始，我们比较 (1,2) 和 (2,1)。 由于 2 属于求和分解，因此我们向右移动。 剩下的就变成了 10 - 2 = 8。从 (1,2) 来看，由于 8 场比赛，只有 (2,2) 有效。 我们正确地到达了终点。 

现在考虑路径 (1,1) → (2,1) → (2,2)，总和为 1 + 4 + 8 = 13。 

| 步骤| 位置| 剩余金额 | 决定|
 | ---| ---| ---| ---|
 | 0 | (1,1) | 12 | 12 开始 |
 | 1 | 移动| 8 | 向下选择|
 | 2 | (2,1) | 8 | 强行向右|
 | 3 | (2,2) | 0 | 结束 |

 这表明在每一步只有一次移动与剩余的位结构保持一致。

## 测试用例```python
import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = [[0]*n for _ in range(n)]
    cur = 0
    for i in range(n):
        for j in range(n):
            a[i][j] = 1 << cur
            cur += 1

    out = []
    for i in range(n):
        out.append(" ".join(str(x) for x in a[i]))

    q = int(input())
    for _ in range(q):
        k = int(input())
        x, y = 0, 0
        rem = k - a[0][0]
        path = [(1,1)]
        while x != n-1 or y != n-1:
            if y + 1 < n and (rem & a[x][y+1]):
                y += 1
            else:
                x += 1
            path.append((x+1, y+1))
            rem -= a[x][y]
        for p in path:
            out.append(f"{p[0]} {p[1]}")
    return "\n".join(out)

 ## 边缘情况

 最小网格$n=2$暴露编码是否在最小数量的路径下保持唯一性。 由于只有两条可能的路径，系统仍然必须清楚地区分总和。 二进制分配确保始终包含 (1,1)，并且通过第二位是否对应于右或下来解决剩余的决策，这始终是唯一可检测的。 

一种特殊情况是路径总是朝一个方向移动，直到被迫为止，例如总是先向右移动。 在这种情况下，余数按照严格可预测的 2 的幂序列递减，因此在每一步中，恰好有一个相邻位保持设置。 这证实了贪婪重建不依赖于平局打破逻辑，因为平局不能在唯一位编码下发生。
