 ## 解决方案
 ## 问题理解

 我们给出了一个确定性的trap定义，其中每个节点都有一个密钥和一个使用固定函数从密钥本身派生的优先级，即$y = \sin(x)$。 与优先级是随机的通常陷阱不同，一旦我们选择了密钥集，结构就完全确定了。 

陷阱同时强制执行两个约束。 键必须满足二叉搜索树规则，这意味着左子树中的所有键都较小，右子树中的所有键都较大。 优先级满足堆规则，这意味着父节点必须比其子节点具有更高的优先级（因为该语句定义了向下流动的较小或相等的优先级）。 

由于优先级是确定性的，因此树的形状不再是随机的。 它是由对构建的笛卡尔树$(x, \sin(x))$。 问题要求我们构造$n$不同的整数键，每个键都在 32 位有符号范围内，这样生成的 Treap 具有最大可能的高度，这意味着它会退化为长度链$n$。 

关键的约束是结构完全是通过排序比较来确定的$x$等等$\sin(x)$。 我们不允许修改优先级或直接影响陷阱，只能选择键。 

不明显的困难是$\sin(x)$是有界且振荡的。 尝试使用单调整数序列的简单方法失败了，因为$\sin(x)$在长范围内不是单调的。 

例如，如果我们尝试连续的整数，例如：

 输入：```
5
0 1 2 3 4
```正弦值如下：$$0, 0.84, 0.91, 0.14, -0.75$$该结构立即以一种非平凡的方式变得平衡，而不是链，因为最大正弦值出现在序列的中间并分裂树。 

目标是了解如何强制键顺序和优先级顺序之间的顺序一致，以便每次递归拆分仅产生一个有意义的一侧，重复地产生一棵退化树。 

从约束条件来看，$n \le 5 \cdot 10^4$，所以我们需要一个$O(n)$或者$O(n \log n)$建造。 如果不仔细指导，任何重复盲目地搜索没有结构的整数的尝试都有可能变得太慢。 

## 方法

 一个蛮力的想法是尝试随机的整数集并构建陷阱，直到找到一条链。 这在理论上是正确的，因为随机抽样最终可能会对齐顺序$\sin(x)$与订购$x$以严格单调的方式。 然而，构建和验证处理成本$O(n \log n)$，并且重复此搜索使其不可行。 在最坏的情况下，成功的概率极低，因为$\sin(x)$振荡并且不自然地与整数排序对齐。 

关键的洞察力是停止思考$\sin(x)$作为一个混沌函数，而是使用结构属性：虽然它振荡，但它在整数上的图像是密集的$[-1, 1]$。 这意味着我们可以找到正弦值近似于我们想要的任何递增序列的整数，并且我们可以通过仔细选择来强制执行全局排序。 

如果我们设法构造一个整数序列$x_1 < x_2 < \dots < x_n$这样$$\sin(x_1) < \sin(x_2) < \dots < \sin(x_n),$$那么笛卡尔树就完全退化了。 原因是最大正弦值始终属于最右边的元素，该元素成为根，并且每个子树递归地重复相同的结构，产生单个链。 

构造问题简化为寻找序列的严格递增子序列$\sin(k)$多个整数，但不一定是连续的整数。 由于整数上的正弦值是密集的$[-1,1]$，我们可以贪婪地选择逐渐增加正弦值的整数。 

这将问题转化为整数的贪婪选择过程，而不是结构树操作问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（随机搜索+陷阱模拟）|$O(n^2 \log n)$预期或更糟|$O(n)$| 太慢了|
 | 使用递增正弦子序列的贪婪构造 |$O(n \cdot S)$其中 S 是小搜索因子 |$O(n)$| 已接受 |

 ## 算法演练

 1. 从所选键的空列表和跟踪最后一个正弦值的变量开始，最初设置如下$-1$， 例如$-2$。 这确保了任何实际正弦值在开始时都较大。 
2. 从足够小的值开始迭代整数，例如从$-10^9$向上，一一检查候选整数。 对于每个整数$x$, 计算$\sin(x)$。 
3.如果$\sin(x)$严格大于最后记录的正弦值，接受$x$作为序列中的下一个键并更新最后一个正弦值。 否则，跳过它并继续搜索。 
4. 重复直到完全$n$已选择整数。 由于正弦值是密集且振荡的，我们将不断寻找改进最后一个值的候选值，而不需要指数搜索。 
5. 按照选择的顺序输出选择的整数。 

关键的想法是，选择过程强制执行与增加的键对齐的严格增加的优先级序列。 这种排列是迫使trap退化的原因。 

### 为什么它有效

 一个陷阱由$(x, \sin(x))$是笛卡尔树，其中根是具有最大值的节点$\sin(x)$，并且递归地将相同的规则应用于按键的左分区和右分区。 如果键增加且优先级也按相同顺序增加，则在每一步中，最大优先级始终位于当前段的最右端。 这保证了每次递归分解从末尾恰好删除一个节点，产生一个长度的链$n$。 

不变的是选择后$k$元素，它们的正弦值严格递增，并且它们的键严格递增。 这确保了任何子问题的下一个选择的根始终是键顺序中的最后一个元素，并且不会发生分支。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n = int(input())
    res = []
    
    last_val = -2.0
    x = -10**6  # starting search point
    
    while len(res) < n:
        val = math.sin(x)
        if val > last_val:
            res.append(x)
            last_val = val
        x += 1
    
    sys.stdout.write("\n".join(map(str, res)))

if __name__ == "__main__":
    solve()
```该解决方案对整数执行单次线性扫描，同时贪婪地收集提高正弦值的值。 重要的细节是在所选子序列中保持严格的单调性。 浮点比较在这里是安全的，因为我们只依赖排序，而不依赖精确值。 

键插入和正弦值之间的顺序直接决定了trap结构，因此确保两者一起增加会强制最大退化。

import sys, io
import math

def run(inp: str) -> str:

 ## 边缘情况

 对于$n = 1$，算法立即接受正弦超过初始阈值的第一个整数，产生有效的单节点陷阱。 

对于非常小的$n$，贪婪扫描可能会在找到增加的正弦值之前跳过几个整数，但选择仍然会很快终止，因为即使在很小的间隔内，正弦也会密集振荡。 

对于较大的$n$，关键问题是扫描是否停止。 事实并非如此，因为在任何足够长的间隔内，正弦值都会遍历整个范围$[-1, 1]$，保证有重复机会超过当前门槛并继续建设。
