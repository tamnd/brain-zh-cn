 ## 解决方案
 ## 问题理解

 我们有一组放置在平面上的垂直柱子，每个柱子都位于整数坐标处并具有所需的最小高度。 我们想要放置一个四边形的金字塔，其边与坐标轴对齐，并具有固定的几何约束：每边从顶点向下倾斜 45 度。 顶点位于某个整数坐标中心并具有整数高度。 

金字塔定义了平面上的高度函数。 在任何一点，高度取决于该点距切比雪夫意义上的中心的距离，这意味着水平和垂直位移的最大值会线性减小高度。 如果金字塔在该坐标处的高度至少是柱子所需的高度，则该点位于金字塔内部。 

任务是选择金字塔的中心和高度，以便覆盖所有柱子，同时使金字塔的高度尽可能小。 

输入大小足够小，每个候选检查大约有 n log n 或 n log C 的解决方案是可以接受的。 当 n 达到 1000 时，即使是 O(n^2 log C) 结构也会处于边缘，但可能太慢，而 O(n log C) 或 O(n log C) 进行可行性检查是安全的。 

一种简单的方法是尝试受输入坐标影响的所有整数网格点中的每个可能的中心并计算所需的高度。 由于坐标范围最大为 10^8，因此不可能枚举所有候选者。 即使限制输入坐标仍然留下 O(n^2) 个候选，并且每次评估成本为 O(n)，导致 O(n^3)，这太慢了。 

天真的推理的一个微妙的失败案例来自于假设最佳中心必须是方尖碑位置之一。 例如，(0,0,1) 和 (100,100,1) 处的两个点表明围绕 (50,50) 对称，这不是输入点。 任何限制候选人输入坐标的方法都会错过这样的最佳解决方案。 

另一个问题是假设欧几里得距离或曼哈顿距离而不是切比雪夫距离。 斜率约束定义了一个四角锥体，因此正确的度量是 max(|dx|,|dy|)。 使用错误的几何形状会导致系统性地错误的可行性检查。 

## 方法

 关键的困难在于高度约束通过涉及中心高度和方尖碑高度的最大表达式来耦合所有点。 对于固定中心 (x, y)，所需的金字塔高度由最差的方尖碑决定，特别是 hi + max(|xi − x|, |yi − y|) 中所有 i 的最大值。 

暴力策略将迭代边界框中所有可能的整数中心，并计算每个中心的该值。 对于每个候选中心，我们扫描所有方尖碑，计算所需的高度，并取最大值。 这是正确的，但最坏情况下的成本与网格点数乘以 n 成正比，在给定高达 10^8 的坐标范围的情况下这是不可行的。 

关键的观察是，我们可以使用切比雪夫距离的结构重新表述问题，而不是直接搜索 (x, y)。 标准坐标变换后，表达式 max(|xi − x|, |yi − y|) 变为线性。 通过引入 A = x + y 和 B = x − y，切比雪夫距离分解为两个独立轴上的约束。 这将问题转化为在 (A, B) 定义的二维空间中查找重叠间隔，其中每个方尖碑对两个坐标施加独立的约束。 

这种分离将平面上的几何优化问题减少为可行性检查中两个独立的区间相交问题。 一旦可以在线性时间内检查固定高度的可行性，我们就可以二分搜索最小高度。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解中心 | O(R²·n) | O(1) | O(1) | 太慢了 |
 | 二分查找+区间可行性| O(n log C) | O(n log C) | O(n) | 已接受 |

 ## 算法演练

 我们将金字塔约束重新表述为候选高度的可行性条件，然后搜索最小的高度。 

1. 通过为每个方尖碑定义 pi = xi + yi 和 qi = xi − yi 来变换坐标。 这种线性变化将切比雪夫几何形状转换为变换空间中的轴对齐约束。 
2. 对于代表金字塔高度两倍的候选值 T，为每个方尖碑导出边距 di = T − 2hi。 这表示中心在变换后的空间中可以偏离多远，同时仍然覆盖该方尖碑。 
3. 对于每个方尖碑，将其要求转化为 A = x + y 和 B = x − y 上的区间约束。 具体来说，A 必须位于 [pi − di, pi + di] 中，B 必须位于 [qi − di, qi + di] 中。 
4. 对于固定 T，分别计算所有 A 区间和所有 B 区间的交集。 可行性条件是两个交点均非空。 这确保存在一个与高度 T 以下的所有方尖碑一致的中心。 
5、二分查找满足可行性的最小T。 搜索空间从 2·max(hi) 开始，因为任何有效的金字塔必须至少覆盖距离为零的最高方尖碑。 
6. 找到 T 后，通过选择两个交点内的任意整数来重建有效的 A 和 B。 然后使用 x = (A + B) / 2 和 y = (A − B) / 2 恢复 x 和 y。 

唯一微妙的部分是确保 A 和 B 具有相同的奇偶校验，以便 x 和 y 保持整数。 如果最初选择的一对违反奇偶校验，则在交集内最多调整 A 或 B 一步就足够了。 

### 为什么它有效

 每个方尖碑独立地限制金字塔中心在变换后的坐标系中的可能位置。 这些限制在 A 轴和 B 轴上形成凸区间。 当所有这些凸约束同时重叠时，金字塔恰好有效。 二分搜索隔离最小的全局松弛 T，其中该交集保持非空，并且变换保证在分离维度时不会丢失几何信息。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def check(n, pts, T):
    lowA = -10**30
    highA = 10**30
    lowB = -10**30
    highB = 10**30

    for x, y, h in pts:
        d = T - 2 * h
        if d < 0:
            return None
        p = x + y
        q = x - y

        lowA = max(lowA, p - d)
        highA = min(highA, p + d)
        lowB = max(lowB, q - d)
        highB = min(highB, q + d)

    if lowA > highA or lowB > highB:
        return None
    return (lowA, highA, lowB, highB)

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    lo = 2 * max(h for _, _, h in pts)
    hi = 2 * (10**8 + 10**8 + max(h for _, _, h in pts))

    ans = None

    while lo <= hi:
        mid = (lo + hi) // 2
        res = check(n, pts, mid)
        if res is not None:
            ans = (mid, res)
            hi = mid - 1
        else:
            lo = mid + 1

    T, (lowA, highA, lowB, highB) = ans

    A = lowA
    B = lowB

    if (A & 1) != (B & 1):
        if A + 1 <= highA:
            A += 1
        else:
            B += 1

    x = (A + B) // 2
    y = (A - B) // 2
    h = T // 2

    print(x, y, h)

if __name__ == "__main__":
    solve()
```可行性检查维护两个独立的间隔交点，对应于变换后的坐标 A 和 B。每个方尖碑根据其高度调整范围收紧两个间隔。 二分搜索探索最小全局松弛 T，一旦找到，重建就会选择任何一致的点，并进行小的奇偶校验校正，确保原始坐标的整数恢复。 

一个常见的实现陷阱是忘记变换需要 A 和 B 之间的奇偶校验对齐。如果不纠正这一点，即使存在有效的整数解，计算出的 x 和 y 也可能变成半整数。 

## 工作示例

 ### 示例 1

 输入：```
1
0 0 5
```我们从 T = 10 作为最小可能值开始。 转换后的约束给出 p = 0 和 q = 0，以及 d = 10 − 10 = 0。 

| 方尖碑| p，q | d | 一个区间 | B区间|
 | ---| ---| ---| ---| ---|
 | (0,0,5) | (0,0,5) | 0,0 | 0 | [0,0]| [0,0]|

 两个区间相交于一点。 因此 A = 0 且 B = 0，产生 x = 0 且 y = 0，高度 h = 5。 

这显示了金字塔直接倒塌到一根柱子上的退化情况，解决方案简化为身份放置。 

### 示例 2

 输入：```
2
3 3 3
6 6 2
```对于 T = 8，我们计算约束。 

| 方尖碑| p，q | d | 一个区间 | B区间|
 | ---| ---| ---| ---| ---|
 | (3,3,3) | 6,0 | 2 | [4,8]| [-2,2] |
 | (6,6,2) | (6,6,2) | 12,0 | 12,0 4 | [8,16] | [-4,4] |

 A 上的交集是[8,8]，B 上的交集是[0,2]，所以可行。 对于较小的 T，A 间隔不再重叠，因此这是最小的。 

选择 A = 8 且 B = 0 则 x = 4 且 y = 4。 

该迹线显示了最佳中心如何通过平衡两个遥远的约束而出现，即使那里没有输入点，解决方案也会收敛到原始几何形状的中点。

 ## 边缘情况

 任意坐标处的单个方尖碑都可以正确处理，因为二分搜索立即识别出最小金字塔的中心恰好位于该坐标处，高度等于方尖碑高度。 区间构造退化为两个变换轴上的单个点。 

当两个方尖碑相距较远时，可行性检查可确保 T 足够大，以便两个间隔系列重叠。 例如，(0,0,1) 和 (100,100,1) 处的点强制 A 和 B 间隔扩展，直到出现中点区域。 该算法自然地捕获了这一点，而无需猜测中间坐标。 

在间隔交集有效但仅包含固定奇偶校验的整数的情况下，奇偶校验处理至关重要。 调整步骤确保重建的 A 和 B 与整数 x 和 y 保持一致，即使原始相交端点因奇偶校验约束而不同，也能保持正确性。
