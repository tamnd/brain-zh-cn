 ## 解决方案
 ## 问题理解

 在这个问题中，我们被要求操作一个未知的整数$x$达到给定目标$n$使用非常有限数量的操作。 我们不知道初始值$x$，我们只能通过四个命令进行交互：添加一个整数，乘以一个整数，除以一个除数，或者替换$x$及其数字之和。 数位和运算将任何数字减少到更小的数字，通常是戏剧性的，而其他运算则以线性或乘法方式缩放数字。 最终目标是输出之间的精确相等$x$和$n$最多使用四个操作，之后我们可以用感叹号表示完成。 

关键的限制是$x$范围内开始$[1, 10^9]$，命令必须遵守数字限制，并且允许的命令数量极少。 这排除了对潜在值的强力探索或迭代调整。 由于允许进行四次操作，因此我们不能尝试猜测或顺序接近目标。 相反，我们必须仔细选择能够快速压缩解决方案空间的操作，利用数字和运算来减少数字，并利用简单的算术或乘法来达到精确的目标。 

当目标$n$很小，特别是个位数，但是起始$x$很大。 例如，如果$x = 9876$和$n = 5$，仅进行加法或乘法的简单方法无法在有限的步骤内达到目标。 同样，如果$n$很大，比如$n = 10^9$，但最初的$x$很小，我们必须放大$x$有效地不超过允许的范围。 了解“数字”运算对任意数字的影响至关重要，因为它允许在两次运算中将任何数字折叠成最多两位数字。 

## 方法

 暴力方法会尝试所有可能的四个操作序列，检查是否达到目标。 这在理论上是正确的，因为所有路径都被探索过，但计算起来却很困难。 每个操作都有很大的范围，探索所有组合具有组合爆炸性，远远超出了最多 5000 个测试用例的可行时间限制。 

关键的见解是认识到数字求和运算的威力。 重复应用“digit”最多可在三次迭代内将任何数字减少为一位数，因为数字之和严格小于原始数字，除非该数字已经是一位数。 因此，一个最优策略是首先使用“数字”运算来崩溃$x$成一个可管理的数字，然后扩展或添加以达到目标。 如果目标很小（小于10），我们可以在减少一两位数字后最多使用一次“div”或“add”操作直接达到它。 如果目标很大，我们可以通过一次乘法和可选的一次加法来构造它以精确对齐。 

该策略利用了每个数字和运算都会减少的不变性$x$可以预见的是，乘法缩放在以下情况下是精确的：$x$很小，并且遵守四次操作的限制。

 ## 算法演练

 1.读取测试用例数量$t$然后迭代每个目标$n$。 对于每个测试用例，我们的目标是确定一个最多四个命令的短序列$x = n$。 我们假设$x$未知但固定。 
2.如果$n$是个位数，输出命令“digit”即可折叠$x$成小于 10 的数。如有必要，除或加一个小数以精确达到$n$。 这可以处理目标较小的情况并防止超过四个命令的限制。 
3.如果$n$是多位数字，先应用“数字”来减少$x$到一个可管理的数字。 使用“add”得出一个数字，相乘后会产生$n$确切地。 乘法优于重复加法，因为它使用更少的命令并且可以有效地达到大目标。 
4. 在执行每个命令后，检查新值$x$通过互动反馈。 在实现中，我们模拟这个知道确切的初始值$x$用于测试，但在真实交互中，判断者以“1”确认成功。 
5、输出“！” 一次$x$等于$n$确切地。 此命令不计入四个命令的限制。 

关键属性是应用“数字”首先保证$x$变小。 之后的乘法或加法总是可以产生任何整数$n \le 10^9$在一两个进一步的命令中。 最多需要四个命令，因为“数字”加上两个算术运算足以满足所有有效$n$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n < 10:
            print("digit")
            sys.stdout.flush()
            print(f"add {n-1}")
            sys.stdout.flush()
        else:
            print("digit")
            sys.stdout.flush()
            print(f"add 9")
            sys.stdout.flush()
            print(f"mul {n // 10}")
            sys.stdout.flush()
        print("!")
        sys.stdout.flush()

if __name__ == "__main__":
    solve()
```第一部分读取测试用例和目标的数量。 对于个位数目标，我们使用“digit”来折叠任何$x$然后“添加”以准确到达$n$。 对于更大的目标，我们首先减少$x$使用“digit”，用“add”调整它以确保整除，然后“mul”达到$n$。 最后， ”！” 信号完成。
