 ## 解决方案
 ## 问题理解

 我们有一排玩家，每个玩家都与他们的直接邻居决斗，因此玩家 1 与玩家 2 决斗，玩家 2 与玩家 3 决斗，依此类推，直到玩家$n-1$决斗玩家$n$。 毕竟$n-1$决斗时，每位玩家报告他们是否至少赢得了一场决斗。 报告是二元的：如果玩家声称他们没有赢得任何决斗，则为 0；如果他们声称他们至少赢得了一场决斗，则为 1。 

任务是确定至少一份报告是否一定是虚假的。 换句话说，我们必须检查 0 和 1 的顺序是否符合每次决斗中只有一个玩家获胜的规则。 如果存在矛盾——例如，两个连续的玩家都报告 0（都没有赢得决斗），或者两个连续的玩家都报告 1，从而使两人不可能赢得至少一场决斗——那么至少有一个报告是假的。 

限制很小：最多 100 个测试用例，每个测试用例最多有 100 名玩家。 这允许算法$O(n)$每个测试用例都很舒服，甚至$O(n^2)$可能会运行，但我们可以一次性解决这个问题。 

不明显的边缘情况出现在线路的末端。 例如，如果第一名和第二名玩家都是0，这是不可能的，因为第一次决斗必须有胜利者。 同样，如果最后两个玩家都是0，那也是不可能的。 像 0 和 1 交替这样的序列通常是一致的，但任何地方两个连续的 0 立即意味着说谎。 连续两个 1 并不一定意味着是骗子，因为每个人都可能赢得不同的决斗。 

## 方法

 暴力方法会尝试模拟与线路结构一致的所有可能的决斗结果，然后验证每个玩家的报告。 这将涉及生成获胜者的每项分配$n-1$决斗并检查是否与 0/1 报告匹配。 虽然这是正确的，但这是不必要的并且呈指数级增长$n$。 即使是为了$n=100$，这在计算上是不可行的。 

关键的见解是我们不需要模拟每场决斗。 每场决斗只影响其两名参与者，唯一不可能的配置是连续两个玩家都声称 0。这是因为在玩家之间的决斗中$i$和$i+1$，至少有一个必须获胜。 因此，如果$a_i = 0$和$a_{i+1} = 0$，这两个报道不可能都是真的，我们立刻就能断定有骗子。 

所有其他序列都是一致的。 单个 1 保证涉及该玩家的某些决斗获胜，并且由 1 分隔的 0 是可以接受的，因为 1 可以代表相邻决斗之一的胜利。 因此，最佳解决方案减少为扫描数组中的任何一对连续 0。

 | 蛮力 | O(2^(n-1)) | O(2^(n-1)) | O(n) | 太慢了|

 ## 算法演练

 1. 对于每个测试用例，读取玩家数量$n$和一系列报告$a$。 
2. 从第一个玩家到倒数第二个玩家迭代数组。 对于每个索引$i$，检查是否$a[i] = 0$和$a[i+1] = 0$。 
3. 如果找到这样的一对，立即断定至少有一个玩家在说谎并打印“YES”。 
4. 如果迭代完成后没有找到连续的 0，则所有报告都与某些决斗结果一致，因此打印“NO”。 

为什么它有效：不变的是每场决斗都必须产生一个胜利者。 两个连续报告 0 的玩家直接违背了这个不变量。 由于没有其他决斗配置可以违反报告，因此扫描连续的 0 足以检测任何骗子。 在获胜者的某些分配下，所有其他顺序都是可能的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    liar_found = False
    for i in range(n - 1):
        if a[i] == 0 and a[i + 1] == 0:
            liar_found = True
            break
    print("YES" if liar_found else "NO")
```解决方案首先读取测试用例的数量。 对于每个测试用例，我们阅读$n$以及一系列的报告。 然后我们从第一个玩家循环到倒数第二个玩家，检查是否有连续的 0。 如果发现，我们会设置一个标志并尽早中断以避免不必要的检查。 最后，如果存在骗子，我们打印“YES”，否则打印“NO”。 使用快速 I/O 可以避免多个测试用例的时序问题。

 ## 边缘情况

 例如，第一个边缘情况是开头的连续零`0 0 1`。 该算法检查该对`(0,1)`，即`(0,0)`在这里，设置`liar_found = True`，并打印 YES，正确识别骗子。 另一种边缘情况是末尾的连续零，例如`1 0 0`。 算法迭代到最后一对`(0,0)`并且也正确打印 YES。 交替序列如`0 1 0 1`扫描连续的零但没有找到，因此算法打印“否”，正确地允许沿线分配胜利的有效场景。 这些边缘情况证实该解决方案可以正确处理边界。
