 ## 解决方案
 ## 问题理解

 我们有一个代表蛋糕的矩形网格。 有些单元格已经包含大写字母，并且每个字母在整个网格中只出现一次。 其他所有单元格都是空的。 每个字母对应一个人，该人必须收到一块与网格对齐的矩形蛋糕。 分配给字母的矩形必须包含该字母出现的原始单元格，并且网格中的每个单元格必须分配给恰好一个字母。 我们可以将每个字母的区域扩展到空单元格，但不允许移动或复制字母，并且每个字母的最终区域必须是单个实心矩形。 

关键的困难在于我们必须以尊重全局一致性的方式填写所有问号单元格。 扩展一个字母的矩形会影响其他字母的可能矩形，因此除非我们遵循结构化规则，否则局部贪婪决策可能会破坏可行性。 

约束足够小，直接基于二次甚至三次网格的构造就可以了。 对于最多 25 x 25 个单元格，任何重复扫描网格或显式填充矩形的算法都会轻松通过。 这排除了对重型图算法或优化结构的任何需要，但这也意味着我们应该注意正确性而不是效率。 

朴素填充的一个常见失败案例是独立扩展每个字母而不与其他字母协调。 例如，如果两个字母位于同一行，并且我们贪婪地向左和向右扩展，则可能会创建重叠区域或迫使字母丢失其原始单元格。 另一个微妙的问题是处理仅出现在边界位置的字母，因为它们的矩形必须以仍与邻居保持一致的方式延伸。 

## 方法

 蛮力的想法是将每个空单元格分配给现有字母之一，然后检查每个字母是否形成包含其原始单元格的矩形。 这在概念上很简单，但完全不可行，因为多达 625 个单元中的每个单元可能需要多达 26 个选择，从而导致搜索空间巨大。 

问题的结构表明了一种更具确定性的方法。 每个字母必须占据一个矩形，并且每个字母只出现一次。 这强烈暗示，一旦我们决定每个字母如何垂直和水平扩展，最终的解决方案就是唯一确定的。 主要见解是将网格视为逐行分区：一旦我们知道哪些字母应该主导每一行，我们就可以一致地填充连续的水平段。 

一个有用的思考方式是，每个字母都充当种子，我们希望向外扩展它的影响，直到它形成一个包含它“拥有”的所有空单元格的矩形。 由于每个字母只出现一次，因此我们可以首先垂直扩展以确定每个字母的行边界，然后在这些边界内水平填充。 

关键的观察是，在任何有效的解决方案中，如果某个字母出现在某行中，那么其最顶部和最底部出现之间的每一行都必须包含该字母的完全跨越某个间隔的矩形。 这使我们能够以受控的方式向下和向上传播字母。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力分配 | O(26^(RC)) | O(26^(RC)) | O(RC) | 太慢了 |
 | 逐行扩展填充| O(RC) | O(RC) | 已接受 |

 ## 算法演练

 我们分两遍构建解决方案。 首先，我们确定每个字母垂直延伸的距离，然后逐行分配水平覆盖范围。

1. 扫描网格并记录每个字母出现的最小和最大行索引。 这给出了每个字母的垂直间隔。 此步骤有效，因为有效的矩形必须覆盖所有出现的字母。 
2. 对于每一行，确定该行中哪些字母是“活动的”，这意味着该行位于其垂直间隔内。 此时，每一行在概念上都被划分为一些字母子集。 
3. 在一行内，从左到右扫描。 每当我们遇到一个字母时，我们都会将其记住为当前活动的段开头。 我们将该字母向右传播，直到遇到另一个已知字母，以确保连续的段。 如果一行没有字母，我们依赖于相邻行的垂直传播。 
4. 使用最接近的可用字母段结构完全填充每一行。 这确保每一行成为一系列连续的块，每个块属于一个字母。 
5. 填充所有行后，每个字母形成一个连接的矩形，因为它的垂直间隔是连续的，并且在每行内它占据一个连续的线段。 

正确性取决于这样一个事实：一旦在行内分配了字母区域，我们就不会水平分割该字母的区域，并且我们不会将单元格分配给其垂直跨度之外的字母。 

### 为什么它有效

 每个字母定义一个垂直间隔，该间隔必须被其最终矩形完全覆盖。 由于矩形在网格方向上是凸的，一旦指定一个字母来覆盖一行中的连续段，以后就不能在不违反矩形属性的情况下将其破坏。 该构造通过确定性地传播分配来确保行之间的一致性，因此没有行会与先前分配的行引入矛盾。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for tc in range(1, T + 1):
        R, C = map(int, input().split())
        grid = [list(input().strip()) for _ in range(R)]

        first = {}
        last = {}

        for i in range(R):
            for j in range(C):
                ch = grid[i][j]
                if ch != '?':
                    if ch not in first:
                        first[ch] = i
                    last[ch] = i

        res = [row[:] for row in grid]

        for i in range(R):
            # find a letter in this row
            current = None
            for j in range(C):
                if res[i][j] != '?':
                    current = res[i][j]
                    break

            # fill left to right
            if current is not None:
                for j in range(C):
                    if res[i][j] != '?':
                        current = res[i][j]
                    res[i][j] = current

        # fix empty rows by copying nearest filled row
        for i in range(R):
            if all(res[i][j] == '?' for j in range(C)):
                up = i - 1
                while up >= 0 and all(res[up][j] == '?' for j in range(C)):
                    up -= 1
                down = i + 1
                while down < R and all(res[down][j] == '?' for j in range(C)):
                    down += 1

                source = up if up >= 0 else down
                res[i] = res[source][:]

        print(f"Case #{tc}:")
        for row in res:
            print("".join(row))

if __name__ == "__main__":
    solve()
```该实现首先读取网格并存储它。 它计算字母的垂直范围，尽管在此版本中它们隐式地用于证明传播的合理性而不是显式强制执行。 主填充过程独立处理每一行，保留最近已知的字母，以便空白段继承正确的所有者。 不包含字母的行通过从最近的非空行进行复制来处理，这保留了垂直矩形的连续性。 

微妙之处在于，每当遇到新字母时，行内的水平传播必须重置，以确保尊重不同字母之间的边界。 如果不进行此重置，单个字母可能会错误地扩展到属于另一个种子的区域。

这表明，一旦每一行都被一致地填充，垂直一致性就会自然出现。

 ## 边缘情况

 关键的边缘情况是一个字母只出现一次并且被孤立在角落里。 该算法确保它仍然正确扩展，因为行传播会将其扩展到整个行，而垂直复制可确保它到达所有所需的行。 

另一种边缘情况是整行没有字母。 在这种情况下，从最近的有效行复制可确保没有未定义的行，从而保留矩形连续性。 

最后的边缘情况是跨行交替稀疏字母。 传播机制确保一旦为一行分配了字母结构，后续行就不会违反该结构，因为它们继承连续的段而不是独立重新计算。
