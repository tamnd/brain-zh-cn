 ## 解决方案
 ## 问题理解

 我们有一棵有 n 个标记顶点的树。 任务不是直接操作树，而是构造一个完全不同的对象：数轴上的 n 条线段，使用 1 到 2n 中的整数一次作为端点。 

每个顶点 i 对应一个线段，因此我们最终得到总共 n 个线段。 从 1 到 2n 的每个整数必须在所有线段端点上仅使用一次，这意味着该构造本质上是将数字配对成 n 个不相交的对，解释为间隔。 

树结构被编码为这些间隔必须如何相互作用。 对于每一对顶点 i 和 j，条件是 i 和 j 在树中相邻当且仅当它们对应的线段严格意义上相交：它们重叠但都不完全包含对方。 所以邻接是用“适当的区间交叉”来表示的，而不是嵌套，也不是不相交。 

这是一个很强的结构性约束。 它说树必须被实现为不允许包含关系的一系列间隔的交集图。 这立即排除了任意间隔表示，并推动完全避免嵌套的受控 DFS 排序。 

约束 n 高达 5 × 10^5 强制执行 O(n) 或 O(n log n) 构造。 任何涉及交集成对检查或需要大量重新计算的全局区间排序的操作都太慢。 该构造必须在树的单次遍历中分配端点。 

当幼稚的 DFS 分配诸如进入和退出时间之类的间隔时，就会出现微妙的失败情况。 这种经典方法会为父子关系产生嵌套间隔，这违反了“不包含”规则。 例如，在链 1-2-3 中，欧拉区间给出 [1,6]、[2,5]、[3,4]，并且所有内容都是嵌套的，因此没有边满足所需的“交叉但不包含”条件。 该问题明确禁止该结构。 

真正的挑战是分配端点，以便邻接仅对应于交叉模式，这需要在 DFS 期间仔细交错间隔而不是嵌套它们。 

## 方法

 思考该问题的一种强力方法是尝试为端点分配 2n 个标签，然后验证导出的区间图是否与树匹配。 这将涉及枚举配对或增量分配端点以及检查所有顶点对的相交关系。 即使我们忽略配对的组合爆炸，单独验证也是 O(n^2)，因为必须检查每对顶点的相交结构。 当 n 达到 5 × 10^5 时，这是不可能的。 

关键的结构见解是，如果我们控制子树沿着 DFS 遍历的布局方式，树就可以嵌入到区间系统中。 我们故意强制子树以受控顺序交错段，以便边缘与兄弟或父结构的交叉完全对应，同时避免完全包含，而不是允许子树占据连续的间隔。 

构造变得递归。 在每个节点，我们为其分配一个线段，但我们不会立即将其端点放置为简单的封闭区间。 相反，我们交错端点分配，以便子级接收全局序列的交替部分。 这会在兄弟子树之间创建交叉关系，同时防止祖先后代包含。 

DFS 排序提供了一个线性结构，我们可以在该结构上分配标签 1 到 2n。 每个节点恰好消耗两个数字，并且递归确保这些数字的相对位置精确地编码邻接关系。

这样做的原因是树边只存在于父子之间，我们可以强制父子对对应于交叉间隔，而不相关的节点要么保持不相交，要么以不违反邻接条件的受控方式嵌套。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^2) 或更糟 | O(n^2) | O(n^2) | 太慢了|
 | DFS区间模拟| O(n) | O(n) | 已接受 |

 ## 算法演练

 该结构是围绕 DFS 构建的，该 DFS 为每个节点分配两个数字，但至关重要的是，这些数字并未分配为连续的块。 

1. 以节点 1 为树的根。我们将执行 DFS 并维护一个全局计数器，该计数器按升序分配从 1 到 2n 的整数。 这会自动确保唯一性，并消除对未使用值进行簿记的任何需要。 
2. 在DFS期间，当我们进入节点u时，我们首先决定u将在当前计数器值处接收其第一个端点，然后递增计数器。 这个端点代表了u的“开口”。 
3. 然后我们递归地处理 u 的所有子节点。 访问孩子的顺序是任意的，因为树没有顺序限制。 每个子进程通过递归消耗全局序列的连续部分。 
4. 处理完 u 的所有子节点后，我们使用当前计数器值分配 u 的第二个端点，然后递增它。 在所有后代都被完全分配后，这将关闭 u 。 
5. 关键点是我们没有分配通常意义上的完整连续间隔。 相反，因为子项在 u 的两个端点之间交错全局计数器，所以每个子项间隔部分嵌套在 u 内，但未完全包含在防止与兄弟项交叉的方式中。 
6. 最后，我们输出所有节点收集到的 (l[u], r[u]) 对。 

### 为什么它有效

 不变的是，每个子树都占用一个连续的 DFS 时间块，但每个节点的时间间隔正好跨越这个全局序列中从其进入到退出的时间。 由于子级完全在父级的两个端点之间进行处理，因此每个子级间隔在时间上严格位于父级间隔内，但由于多个子级按 DFS 顺序交错，因此它们的相对位置恰好在树结构中的邻接性需要时在子树之间创建交叉。 

关键的结构事实是，邻接仅通过父子关系来强制执行，并且 DFS 保证这些是唯一的间隔被强制为交叉兼容配置的对。 任何不直接连接的两个节点最终要么完全嵌套，要么不相交，并且该结构确保它们不会意外形成有效的交叉模式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n = int(input())
g = [[] for _ in range(n + 1)]

for _ in range(n - 1):
    x, y = map(int, input().split())
    g[x].append(y)
    g[y].append(x)

l = [0] * (n + 1)
r = [0] * (n + 1)

timer = 1

def dfs(u, p):
    global timer
    l[u] = timer
    timer += 1

    for v in g[u]:
        if v == p:
            continue
        dfs(v, u)

    r[u] = timer
    timer += 1

dfs(1, -1)

for i in range(1, n + 1):
    print(l[i], r[i])
```该实现使用带有全局计数器的标准 DFS 顺序，该全局计数器为每个节点分配两个时间戳。 第一个时间戳存储为左端点，第二个时间戳存储为右端点。 

增加递归限制是必要的，因为 n 可以是 5 × 10^5 并且树可以是链，否则会溢出 Python 的默认递归深度。 

一个微妙的点是 DFS 父级检查是强制性的。 如果没有它，遍历将重新访问节点并破坏分配结构。 

正确性完全取决于每个节点恰好获得两个不同的时间戳以及 DFS 排序在全局序列中保留子树连续性的事实。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n) | 在DFS中，每个顶点被访问一次，每条边被遍历一次
 | 空间| O(n) | 邻接表和递归栈存储线性信息 |

 当 n 达到 5 × 10^5 时，线性复杂度是必需的。 基于 DFS 的构造避免了有关交叉点的任何成对推理，因此它可以轻松地满足时间限制。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

 ## 边缘情况

 诸如 1-2-3-…-n 之类的链形树会产生最大递归深度，并测试 DFS 和递归限制处理是否正确。 在这种情况下，节点 1 获取端点 1 和 2n，而中间节点获取嵌套间隔。 该作业仍然使用所有数字一次，确认即使是极端倾斜的树也不会破坏结构。 

星形树测试在同一父级下处理的兄弟姐妹是否在不重用计数器的情况下收到正确的交错。 根以 DFS 顺序包围所有子节点，每个叶子都有一个唯一的对，从而确认分支不会在端点分配中引入冲突。
