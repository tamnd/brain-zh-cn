 ## 解决方案
 ## 问题理解

 我们得到一个整数列表，并且允许我们重复应用以一种非常特定的方式更改数组的操作：在一次操作中，我们选择一个整数值并将其添加到当前非零的每个元素。 在此操作期间零保持不变。 当所有元素同时变为零时，该过程结束，任务是最小化达到该状态所需的操作数量。 

关键是每个操作统一作用于所有非零元素，因此我们不是独立编辑元素。 相反，数组的结构会批量演变，零值的行为就像“固定点”，停止参与未来的更新。 

最大 10^5 的约束 n 强制任何解决方案在线性或接近线性时间内运行。 任何通过许多操作模拟数组的方法，尤其是重复扫描或更新元素的方法，都会面临 O(n^2) 行为的风险，并且不会通过。 

当数组包含许多与非零混合的零时，会出现微妙的边缘情况。 例如，在像这样的数组中`[0, 5, 0, -2]`，零充当永久分隔符，只有非零段会受到影响。 一个天真的想法可能会尝试一次性标准化所有值，但由于更新中排除了零，因此它们会阻止全局同步并强制每个段进行单独推理。 

## 方法

 暴力解释试图直接模拟该过程。 每一秒，我们选择一个值并将其应用于所有非零元素，然后检查所有内容是否都变为零。 如果没有，我们重复。 虽然这很简单，但每个操作仍然需要扫描数组以识别非零元素并更新它们。 在最坏的情况下，我们可能需要与消除所有值所需的不同“阶段”的数量成比例的操作数量，并且每个阶段的成本为 O(n)。 这会导致对抗性情况下的 O(n^2) 行为，这对于 n = 10^5 来说太慢了。 

关键的观察结果是，零根据影响力将数组划分为独立的段。 一旦一个元素变为零，它就永远停止变化。 这意味着数组的演变完全取决于我们需要“完成”由零分隔的非零值的不同连续块的次数。 

每次应用操作时，我们都会有效地一起减少所有活动（非零）值，并且每当一个段包含混合符号或不同大小时，在该段完全崩溃之前需要多次减少。 然而，因为我们每次都可以选择任何整数，所以最佳策略是以独立折叠每个最大连续非零段的方式消除贡献，并且这些段可以跨操作并行处理。 

这将问题简化为结构计数：非零元素的每个最大连续段恰好为答案贡献了一个时间单位。 直觉是，每个分段都需要至少一个不同的“消除阶段”，而这些“消除阶段”不能在单独的分段之间共享，因为零会阻止它们之间的交互。 

因此，答案只是数组中非零元素的连续块的数量。

 ## 算法演练

 我们从左到右扫描数组并计算进入非零段的次数。 

1. 将计数器初始化为零。 这将存储连续非零块的数量。 
2. 从索引 0 到 n − 1 遍历数组。 
3. 当我们发现一个非零元素并且它是第一个元素或前一个元素为零时，我们会增加计数器。 这标识了新段的开始。 
4. 继续扫描而不递增，直到离开该段（即遇到零或到达末尾）。 
5. 遍历完成后，返回计数器。 

步骤 3 背后的原因是，只有从零到非零的转变才标志着新独立组的开始。 段的内部元素并不重要，因为它们都是在相同的操作序列下一起处理的。 

### 为什么它有效

 该操作只能同时影响非零元素，并且零将数组永久分割成孤立的区域。 在非零值的单个连续区域内，所有元素始终一起更新，直到整个区域崩溃。 没有任何操作可以合并两个分离的区域，因为零永远不会改变。 因此，每个连续的非零段的行为就像一个独立的单元，仅需要一个有效的“崩溃阶段”，并且此类阶段的数量正是段的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    ans = 0
    for i in range(n):
        if a[i] != 0 and (i == 0 or a[i-1] == 0):
            ans += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```代码直接遵循遍历逻辑。 条件`a[i] != 0`确保我们只考虑活跃元素，同时`(i == 0 or a[i-1] == 0)`确保我们只计算每个非零块的第一个元素。 这避免了段内的重复计算，并保证每个段只贡献一次。 

该解决方案本质上是完全流式传输的，只需要一次传递和恒定的额外内存。

 ## 边缘情况

 对于像这样的输入`1 0 2 0 3`，扫描在零后的每个非零处检测一个新段。 第一个元素开始一个段，索引 2 在零后开始另一个段，索引 4 开始第三个段。 每个都只计数一次，因为转换条件仅在零到非零边界处触发。 

对于像这样的输入`0 0 0`，没有元素满足`a[i] != 0`，因此计数器始终保持为零。 这与数组已经处于最终状态的事实相匹配。 

对于像这样的全负数组`-5 -4 -3`，符号无关紧要，因为该算法仅跟踪结构分割，而不跟踪值。 整个数组是一个连续的非零块，因此答案是 1。
