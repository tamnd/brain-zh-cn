 ## 解决方案
 ## 问题理解

 我们有四个整数$l, r, x, y$。 任务是计算有序对的数量$(a, b)$使得两个数字都位于区间内$[l, r]$，它们的最大公约数正是$x$而它们的最小公倍数恰好是$y$。 

与其考虑任意整数，不如将条件视为一个非常严格的结构性约束，限制如何$a$和$b$已建成。 GCD 强制两个数字共享一个共同的基本因子，而 LCM 强制它们的组合素数结构完全匹配$y$。 因此，我们不是在区间内自由搜索，而是搜索必须与固定算术模式完美对齐的对。 

界限$l, r \le 10^9$排除任何迭代所有候选对的方法。 如果在没有结构的情况下进行每个测试，即使迭代单个变量也是边缘。 该解决方案必须将搜索空间减少到依赖于除数或分解的程度$y$，而不是间隔大小。 

当出现关键边缘情况时$y$不能被整除$x$。 在这种情况下，不能存在任何对，因为 GCD 必须整除 LCM，并且任何有效的对必须满足$x \mid y$。 另一个微妙的情况是，即使在满足整除性之后，其中一个变换变量在标准化后仍超出允许的区间。 

例如，如果$l = 1, r = 2, x = 2, y = 3$，没有一对，因为$x$不分开$y$，即使两个界限都足够小，暴力仍然可以尝试候选人。 

## 方法

 直接方法尝试所有对$(a, b)$在范围内$[l, r]$并检查他们的 GCD 是否$x$LCM 是$y$。 这是正确的，但有最坏的情况$(r-l+1)^2$检查。 和$r$最多$10^9$，即使缩小了间隔，仍然可能太大而无法枚举。 

关键的观察是首先通过标准化两个数字来消除 GCD 约束。 如果我们设置$a = x \cdot A$和$b = x \cdot B$， 然后$\gcd(A, B) = 1$。 这种转换隔离了公因子并将问题简化为计算互质对。 

代入LCM条件，可得：$$\text{lcm}(a, b) = x \cdot A \cdot B = y$$这意味着：$$A \cdot B = \frac{y}{x} = k$$所以整个问题简化为计算有序因子对$(A, B)$这样$A \cdot B = k$,$\gcd(A, B) = 1$，以及两者$xA, xB$位于$[l, r]$。 

这给出了一个干净的结构：我们只需要枚举$k$，并且对于每个除数$A$， 定义$B = k / A$，然后检查互质性和区间约束。 

暴力破解会失败，因为它在大小为 2D 的空间中进行搜索$O(r^2)$，而变换后的问题仅取决于除数结构，即$O(\sqrt{k})$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O((r-l+1)^2)$|$O(1)$| 太慢了|
 | 最佳|$O(\sqrt{y/x})$|$O(1)$| 已接受 |

 ## 算法演练

 1.首先检查是否$y$可以整除$x$。 如果不是，答案立即为零，因为 GCD 的缩放不能产生非多重 LCM。 这可以避免不必要的工作。 
2. 计算$k = y / x$。 我们现在用因子对来重新解释这个问题$k$，其中每个有效对对应于$(A, B)$。 
3. 迭代所有整数$A$这样$A \cdot A \le k$。 每一个这样的$A$代表一个潜在的除数$k$，我们可以计算$B = k / A$什么时候$A$划分$k$。 
4. 对于每个除数$A$，检查是否$k \bmod A = 0$。 如果不是，请跳过它，因为它无法形成有效的对。 
5.让$B = k / A$。 检查是否$\gcd(A, B) = 1$。 这个条件保证了原始数$xA$和$xB$正好有 GCD$x$，不更大。 
6. 通过验证边界转换回原始域：$l \le xA \le r$和$l \le xB \le r$。 
7. 如果所有条件成立，则计算有序对的数量。 如果$A \ne B$， 两个都$(A, B)$和$(B, A)$有效，所以加 2。如果$A = B$，加1。 

### 为什么它有效

 任何有效对$(a, b)$必须有一个最大公约数$x$，因此将两个数字除以$x$产生整数$A$和$B$是互质的。 LCM 条件迫使他们的产品完全是$y/x$，因此每个有效对都双射对应于$k$。 边界仅过滤这些因式分解中的哪些实际上位于区间内。 由于每个步骤都在两个方向上保持等价性，因此不会丢失有效对，也不会引入无效对。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def solve():
    l, r, x, y = map(int, input().split())
    
    if y % x != 0:
        print(0)
        return
    
    k = y // x
    ans = 0
    
    for a in range(1, int(math.isqrt(k)) + 1):
        if k % a != 0:
            continue
        b = k // a
        
        if math.gcd(a, b) != 1:
            continue
        
        A = x * a
        B = x * b
        
        if l <= A <= r and l <= B <= r:
            if a == b:
                ans += 1
            else:
                ans += 2
    
    print(ans)

if __name__ == "__main__":
    solve()
```该代码首先验证之间必要的整除条件$x$和$y$。 没有它，变换后的方程$A \cdot B = k$甚至都不是积分，因此搜索空间立即崩溃。 

除数循环使用$\sqrt{k}$因为每个除数对都恰好遇到一次$a$和$k/a$。 gcd 检查强制删除后不保留任何额外的公因数$x$，这对于逆变换的正确性至关重要。 

重建原始值后应用边界检查$a = xA$和$b = xB$，因为约束是在原始域而不是标准化域中定义的。

 ## 边缘情况

 一个重要的边缘情况是当$y$不能被整除$x$。 例如，使用输入$l=1, r=100, x=4, y=6$，转换需要$A \cdot B = 1.5$，这是不可能的。 该算法在尝试任何除数搜索之前立即返回零。 

另一个边缘情况是当$A = B$， 意义$k$是一个完美的正方形。 在这种情况下，只存在一种排序而不是两种。 例如，$x=2, y=8$给出$k=4$，以及这对$A=B=2$恰好产生一种有效的配置。 

第三种情况是边界裁剪：即使因子对以标准化形式有效，缩放比例$x$可以把它推到外面$[l, r]$。 例如，$l=10, r=12, x=3, y=12$产生归一化对$(1,4)$， 但$3\cdot4=12$有效，同时$3\cdot1=3$不是，所以在边界过滤后只有一个方向幸存。
