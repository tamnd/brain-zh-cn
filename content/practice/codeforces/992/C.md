 ## 解决方案

 ## 问题理解

 我们从一个装有一定数量物体的容器开始，称之为连衣裙。 最初有`x`连衣裙。 时间以离散的步骤进行，并且有`k + 1`总共步骤。 

在每个第一个`k`步骤，过程在结构上是确定性的，但结果是随机的。 首先，礼服的数量增加了一倍。 在加倍之后，如果衣柜不空，则有一半的可能性会立即移除一件衣服。 最后一步（最后一个月）仅执行对折，之后不再移除衣服。 

任务是计算毕竟衣服的预期数量`k + 1`步骤，并返回结果模`1e9 + 7`。 

关键的困难在于，期望是一个过程，其重复分支的随机性超过了潜在的随机性。`10^18`步骤，所以模拟是不可能的。 任何解决方案都必须将每个步骤的效果压缩为封闭形式的转换。 

这些限制使得暴力破解完全不可行。 甚至迭代`k`步骤太大，因为`k`可以达到`10^18`。 这会立即排除随时间变化的任何每步模拟或 DP。 唯一可行的方向是理解期望如何以代数方式演化。 

出现微妙的边缘情况时`x = 0`。 在这种情况下，该过程永远不会获得任何礼服，因为加倍和删除仍然会导致零。 盲目应用涉及除以 2 的代数递归而不保护零行为的幼稚实现仍然可以工作，但推理必须确认公式正确退化。 

另一个潜在的陷阱是正确解释随机删除。 它发生在加倍之后，而不是之前，并且仅在第一个中发生`k`过渡。 最后一个月没有删除步骤，这会稍微改变最后一步的重复率，这对于正确性至关重要。 

## 方法

 直接模拟方法将在每个月后保持可能衣柜尺寸的准确分布。 每一步之后，每个状态都会分为两种可能性：一种是在加倍后不移除衣服，另一种是在加倍后移除衣服。 随着时间的推移，这会导致状态数量呈指数增长，因为每一步都会使可能结果的数量加倍。 后`k`步骤，就会有`2^k`状态，这远远超出了任何可计算的极限`k`可以是`10^18`。 

关键的观察是我们不需要完整的分布，只需要期望值。 期望是线性的，因此我们可以跟踪期望值在一步下如何变化。 

让`E`是某个月份的预期衣服数量。 翻倍后，该值变为`2E`。 那么以概率`1/2`，我们减去一件衣服。 这个减法有助于`-1`以概率的方式期待`1/2`，所以预期减法是`1/2`。 因此每个第一个`k`转换将期望转变为：`E -> 2E - 1/2`上次转换（月`k+1`) 仅加倍：`E -> 2E`因此整个过程变成了线性变换的重复应用。 这是一个经典的仿射递归：`E_{i+1} = 2E_i - 1/2`为了`i < k`， 和`E_{k+1} = 2E_k`。 

为了消除模运算下的分数，我们将所有值乘以 2。定义`F = 2E`。 然后：`F_{i+1} = 2F_i - 1`为了`i < k`， 和`F_{k+1} = 2F_k`。 

现在一切都是整数算术模`MOD`。 

我们现在需要应用仿射变换`k`次，然后最后一次加倍。 第一次的转变`k`步骤可以使用几何级数以封闭形式求解：

 每一步：`F -> 2F - 1`展开：`F_k = 2^k * x*2 - (2^k - 1)`然后最后一步：`F_{k+1} = 2 * F_k`最后转换回来：`E = F / 2`这产生了一个可计算的封闭式表达式`O(log k)`使用模幂。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟 | O(2^k) | O(2^k) | O(2^k) | O(2^k) | 太慢了|
 | 闭式求幂| O(log k) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将递推式转换为期望形式，认识到只有均值才重要，完全分布是不必要的。 这将问题从概率分支减少为确定性递归。 
2. 将每个非最后一个月之后的更新规则重写为期望的线性变换：将期望乘以 2 倍，随机去除以 1/2 的概率减去 1，得到 1/2 的净减。 
3. 通过缩放状态变量来消除分数。 代替`E`和`F = 2E`，这会将更新变成干净的整数递归`F -> 2F - 1`。 
4. 确定这是该形式的仿射递归`F_{n+1} = aF_n + b`具有常数系数。 这种递归式可以通过分离乘法部分和加法部分来解决。 
5. 展开递归`k`从重复减法项获得几何级数贡献的步骤。 乘数以 2 的幂的形式增长，而常数项以 2 的幂的总和形式累积。 
6. 计算闭合形式：`F_k = F_0 * 2^k - (2^k - 1)`在哪里`F_0 = 2x`。 
7、单独应用最后一步，只是加倍：`F_{k+1} = 2 * F_k`。 
8. 除以 2 模数，转换回期望值`MOD`，相当于乘以 2 的模逆。 

### 为什么它有效

 每个月应用的变换在当前期望中是线性的，因此整个过程形成仿射函数的组合。 仿射函数的复合保持仿射，这保证了在任意数量的步骤之后期望仍然可以表达为`A * x + B`。 上面导出的封闭形式正是重复组合同一个仿射图并通过几何级数对其常数贡献求和的结果。 由于期望是线性的，因此更高的矩不会影响结果，从而使这种减少变得精确。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    x, k = map(int, input().split())
    
    if k == 0:
        print((x * 2) % MOD)
        return

    # compute powers
    p = mod_pow(2, k)
    inv2 = (MOD + 1) // 2

    # F0 = 2x
    F0 = (2 * x) % MOD

    # Fk = F0 * 2^k - (2^k - 1)
    Fk = (F0 * p) % MOD
    Fk = (Fk - (p - 1)) % MOD

    # final doubling
    F = (Fk * 2) % MOD

    # convert back: E = F / 2
    ans = (F * inv2) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```该代码直接实现了封闭式表达式。 模幂计算`2^k`，这是唯一一个对`k`很重要。 递归简化完全避免了迭代几个月。 

特殊情况`k = 0`处理只有最后一个月因此没有删除事件的情况。 

最后使用 2 的倒数将缩放变量转换回模运算下的期望值。

 ## 边缘情况

 当`x = 0`，递推式仍然适用于代数，但所有中间状态的期望值仍为零。 该公式可以正确归约，因为乘法和加法分量在缩放后均计算为零。 

为了`k = 0`，不会发生随机删除。 该过程只是一个确定性加倍步骤。 该算法显式绕过递归并返回`2x`，与流程定义匹配。 

什么时候`k`如果很大，直接迭代会溢出时间限制，但模幂可以确保只完成对数工作。 递归不依赖于中间状态，因此跳过它们不会丢失有关最终期望的信息。
