 ## 解决方案
 ## 问题理解

 我们得到一个整数`n`， 在哪里`n ≥ 12`。 任务是找到任意两个合数，其总和恰好为`n`。 

合数是大于 1 的整数，除了 1 和它本身之外，至少有一个约数。 例如，4、6、8和9是合数，而2、3、5和7是素数。 

输入仅包含一个值，因此无需处理多个测试用例。 上限是`10^6`，它足够小，即使涉及几百万次操作的算法也可以在一秒的时间限制内轻松足够快。 

问题的有趣之处不在于效率，而在于找到有保证的结构。 由于该语句承诺每个至少 12 的整数都可以表示为两个合数之和，因此我们只需要一种始终生成有效对的方法。 

一个常见的错误是专注于素性测试并详尽地搜索有效的分解。 虽然这有效，但没有必要。 

一种边缘情况是最小允许值。 

对于输入：```
12
```有效的答案是：```
4 8
```两个数字都是合数。 任何解决方案都必须正确处理这个下边界。 

另一个微妙的情况是奇数值，例如：```
15
```像这样的分解`4 + 11`无效，因为 11 是质数。 正确的输出可能是：```
6 9
```两个数字都是合数。 

粗心的构造，例如总是打印`4`和`n - 4`奇数失败。 例如，与`n = 15`，它会产生`4 + 11`，这是不允许的。 

## 方法

 最直接的方法就是暴力破解。 我们可以尝试每一个可能的第一个数字`x`从 4 到`n - 4`， 让`y = n - x`，并检查两个数是否是合数。 一个数字最多`10^6`可以粗略地测试复合性`O(√n)`时间。 

这种方法是正确的，因为它显式搜索所有可能的分解并返回第一个有效的分解。 问题是，在最坏的情况下，我们可能会检查近一百万个候选者，并且每个候选者可能需要平方根素性检查。 这将复杂性推向`O(n√n)`，这远远超出了必要的工作量。 

关键的观察来自奇偶校验。 

如果`n`是偶数，那么：```
4 + (n - 4)
```总是有效。 

数字4是合数。 自从`n`是偶数，`n - 4`也是均匀的。 因为`n ≥ 12`，我们有`n - 4 ≥ 8`。 每个大于 2 的偶数都是合数或者至少不是质数？ 更具体地说，每个至少为 4 的偶数都是合数。 因此这两个数都是合数。 

如果`n`是奇数，则：```
9 + (n - 9)
```总是有效。 

数字9是合数。 自从`n`是奇数，`n - 9`是均匀的。 因为`n ≥ 13`对于任何奇数有效输入，我们有`n - 9 ≥ 4`。 每个至少 4 的偶数都是合数，因此第二个数也是合数。 

这一观察消除了所有搜索。 我们可以立即构建答案。

 ## 算法演练

 1.读取整数`n`。 
2. 检查是否`n`是均匀的。 
3.如果`n`为偶数，输出`4`和`n - 4`。 

第一个数字是合数。 第二个数字是至少 8 的偶数，也是合数。 
4. 否则，`n`很奇怪。 输出`9`和`n - 9`。 

第一个数字是合数。 第二个数字是至少为 4 的偶数，是合数。 

### 为什么它有效

 该算法完全依赖于奇偶校验。 

对于甚至`n`，分解`4 + (n - 4)`有效，因为 4 是合数并且`n - 4`是至少 8 的偶数。任何大于 2 的偶数都有除数 2，因此它是合数。 

对于奇数`n`，分解`9 + (n - 9)`有效，因为 9 是合数并且`n - 9`是至少为 4 的偶数。同样，每个大于 2 的偶数都是合数。 

这两种情况之一总是适用，因此该算法总是输出两个合数，其总和恰好为`n`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

if n % 2 == 0:
    print(4, n - 4)
else:
    print(9, n - 9)
```程序首先读取单个输入值。 

奇偶性为`n`决定使用哪种结构。 对于偶数，这对`(4, n - 4)`被生产出来。 对于奇数，一对`(9, n - 9)`被生产出来。 

唯一的边界条件是确保第二个数字保持合数。 约束自动保证了这一点。 对于最小的偶数输入，`n = 12`，第二个值是`8`。 对于最小的奇数输入，`n = 13`，第二个值是`4`。 两者都是复合的。 

不需要循环、素性测试或额外的数据结构。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    n = int(input())

    if n % 2 == 0:

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()
