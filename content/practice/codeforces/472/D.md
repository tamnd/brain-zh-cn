 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$矩阵，其中每个条目$d[i][j]$表示节点之间的距离$i$和$j$。 问题是问是否存在一棵带权树$n$节点，使得任意两个节点之间沿着树的距离与矩阵中的相应条目完全匹配。 所有边权重必须为正整数。 

立即检查的第一个条件是对角线元素必须全部为零，因为节点到其自身的距离为零。 类似地，矩阵必须是对称的，因为距离$i$到$j$等于距离$j$到$i$。 粗心的实现可能会跳过这些检查并尝试从无效输入构建树，从而导致错误的结论。 

问题允许$n$最多 2000，这很重要，因为任何简单地检查所有三元组或尝试所有可能的树结构的算法都将很容易超过$O(n^3)$临界点。 自从$n^3$运算量可以达到 80 亿次，我们需要一种比暴力更聪明的方法来确保解决方案在 2 秒内完成。 

非明显的边缘情况包括违反三角不等式的矩阵。 例如，考虑一个 3×3 矩阵：```
0 1 3
1 0 1
3 1 0
```这里，节点 1 和 3 之间的距离是 3，但距离 1→2 和 2→3 的总和仅为 2。仅使用某种贪婪方法构造边的简单方法将无法检测到这种不一致，但在树的上下文中对三角形不等式进行适当检查可以捕获它。 

## 方法

 暴力方法会尝试生成所有可能的树$n$节点，计算每个节点的距离矩阵，并查看是否有任何与输入匹配。 这是不可行的，因为标记树的数量呈指数增长$n$，具体为$n^{n-2}$根据凯莱公式。 即使是为了$n=10$，搜索空间过亿。 

关键的见解是，在树中，任何两个节点之间都有一条唯一的路径。 这意味着三角形不等式必须完全成立： 对于任意三个节点$i, j, k$，距离$d[i][j]$必须小于或等于$d[i][k] + d[k][j]$，并且某些节点必须相等$k$沿着路径。 此外，距离矩阵可以被认为表示加权图上的最短路径。 如果任何条目违反三角不等式，或者对角线不为零或对称性失败，则不会存在树。 一旦满足这些条件，就可以尝试使用最小生成树方法重建一棵树，其中按权重顺序考虑边缘，确保每个新边缘保留树距离属性。 这将问题从指数搜索减少为$O(n^3)$验证，考虑到限制，这是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（所有树）| O(n^(n)) | O(n^(n)) | O(n^2) | O(n^2) | 太慢了|
 | 三角不等式+MST构建| O(n^3) | O(n^3) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 1. 首先验证距离矩阵的基本性质。 迭代所有节点对并检查对角线元素是否为零且矩阵是否对称。 如果任一检查失败，则立即输出“NO”。 这些是表示树的任何距离矩阵的基本要求。 
2. 接下来，验证每个不同节点三元组的三角形不等式$i, j, k$。 具体来说，检查$d[i][j] \le d[i][k] + d[k][j]$。 如果任何三元组违反此条件，则输出“NO”。 此步骤确保不存在与树中的唯一路径属性相矛盾的不可能距离。 
3. 如果两项检查都通过，我们就可以尝试构建树。 一种方法是考虑所有边缘$(i, j)$有重量$d[i][j]$并尝试以重现距离矩阵的方式连接节点。 更系统的方法是将矩阵解释为按距离加权的完整图，并使用最小生成树算法来优先考虑具有最小权重的边。 这样做时，请确保添加边不会产生循环，并且任何连接的节点之间的距离与原始矩阵匹配。 由于矩阵满足三角形不等式和对称性，因此该过程将成功重建树。 
4. 最后，在树重建之后，可以选择验证在构造的树上计算的距离是否与原始矩阵完全匹配。 如果是，则打印“YES”； 否则，打印“NO”。 

保证正确性的不变量是，对于树的有效距离矩阵，任何距离$d[i][j]$等于沿连接的唯一路径的边权重之和$i$和$j$。 三角形不等式确保不存在替代的较短路径，对称性确保双向一致性，零对角线强制节点到自身距离属性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    d = [list(map(int, input().split())) for _ in range(n)]
    
    # Step 1: check diagonal and symmetry
    for i in range(n):
        if d[i][i] != 0:
            print("NO")
            return
        for j in range(i + 1, n):
            if d[i][j] != d[j][i] or d[i][j] == 0:
                print("NO")
                return
    
    # Step 2: check triangle inequality
    for i in range(n):
        for j in range(n):
            for k in range(n):
                if i != j and j != k and i != k:
                    if d[i][j] > d[i][k] + d[k][j]:
                        print("NO")
                        return
    
    # If all checks pass
    print("YES")

if __name__ == "__main__":
    solve()
```该代码首先读取距离矩阵并验证基本树属性。 然后，它对三角不等式进行三次检查。 注意早期的返回：一旦发现违规，算法就会停止，这避免了不必要的计算。 支票`d[i][j] == 0`对于非对角线元素确保没有零权重边，因为所有边都必须具有正权重。
