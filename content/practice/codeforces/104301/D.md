 ## 解决方案
 ## 问题理解

 我们得到了多个独立的测试用例。 在每个测试用例中，都有一个整数数组和一个阈值$k$。 如果一组值中最大和最小的元素相差最多，我们称该组值“好”$k$。 等价地，集合内的每一对必须最多有差异$k$，它简化为一个条件：$\max(S) - \min(S) \le k$。 

对于每个测试用例，我们必须计算两件事。 首先，可以选择其元素作为满足条件的集合的子数组的数量。 其次，满足相同条件的子序列（不一定是连续的）的数量。 

两者之间的主要区别在于结构。 子数组保留顺序和连续性，因此我们处理间隔。 子序列忽略位置，只关心选择索引。 

限制条件很大：总计$n$跨测试用例最多可达$2 \cdot 10^5$，并且值可以达到$10^{18}$在幅度上。 这立即排除了任何$O(n^2)$每个测试用例方法。 甚至$O(n \log n)$每个测试用例必须小心地呈线性。 

检查所有子数组或所有子序列的简单解决方案是不可能的。 单独子序列的数量是$2^n$，所以直接枚举就不行了。 

出现微妙的边缘情况时$k = 0$。 在这种情况下，有效集必须仅包含相同的值。 任何依赖范围扩展的算法都必须正确处理重复项，因为相等成为唯一允许的关系。 

另一种边缘情况是数组严格增加或减少。 在这里，每个窗口都受到滑动阈值的限制，并且每个索引的简单扩展将多次重新计算重复的工作。 

## 方法

 我们分别对待子数组和子序列，但两者都依赖于相同的结构思想：使用范围约束的有效性可排序性。 

对于子数组，请考虑暴力方法。 对于每个起始索引$i$，我们扩展$j$转发并跟踪当前段中的最小值和最大值。 每次延期费用$O(1)$如果小心维护，那么这会变成$O(n^2)$全面的。 在最坏的情况下，数组的条件适用于大多数对，这会退化为大约$n(n+1)/2$检查，这对于$2 \cdot 10^5$。 

关键的观察结果是，对于固定的左端点，有效的右端点集形成一个连续的区间。 一旦最大最小差值超过$k$，进一步增加右指针不能恢复有效性。 这种单调性允许两指针滑动窗口。 

对于子序列，顺序不再重要，所以我们首先对数组进行排序。 排序后，任何有效子序列必须完全位于一个窗口内，其中最小和最大所选元素之间的差异最多为$k$。 这将问题转化为对排序滑动窗口内的子集进行计数。 

排序后，我们再次使用两指针窗口：对于每个右端点$r$，我们找到最小的$l$这样$a[r] - a[l] \le k$。 然后所有子集完全在内部形成$[l, r]$是有效的，有贡献$2^{(r-l)}$结束于的子序列$r$。 

主要区别在于子数组取决于原始顺序，而子序列则简化为排序值的组合。

 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2)$每次测试 |$O(1)$| 太慢了|
 | 最佳|$O(n \log n)$总体 |$O(n)$| 已接受 |

 ## 算法演练

 我们独立处理每个测试用例。 

### 子数组

 1.初始化两个指针$l = 0$并迭代$r$从左到右，保持当前窗口。 
2. 使用双端队列有效维护当前窗口的最小值和最大值。 
3. 对于每个$r$， 插入$a[r]$进入两个结构并更新当前的最小值和最大值。 
4.当窗户违规时$\max - \min > k$， 移动$l$转发并删除过时的元素。 
5.固定后$l$，所有以$r$并从任意位置开始$[l, r]$是有效的，所以添加$(r - l + 1)$到答案。 

这样做的原因是，一旦窗口失效，再向右扩展并不能缩小范围； 只有左移才能恢复有效性。 

### 子序列

 1. 对数组进行排序。 
2. 预先计算 2 的幂$n$，因为我们将重复计算子集。 
3. 在排序数组上使用两指针窗口。 
4. 对于每个右端点$r$， 进步$l$直到$a[r] - a[l] \le k$。 
5. 由 中的元素形成的所有子集$[l, r]$是选择位置最大元素的有效选择$r$，所以我们添加$2^{(r-l)}$到答案。 

关键思想是，固定有效子序列中的最大元素决定了所有其他元素必须位于其下方的有界区间内。 

### 为什么它有效

 对于子数组，不变的是当前窗口$[l, r]$总是满足条件，并且$l$是保持固定有效性的最小索引$r$。 任何较小的窗口都会违反约束，任何较大的右端点都会破坏单调性，直到$l$已调整。 

对于子序列，排序可确保任何有效集合都是值空间中的区间。 二指针窗口保证计数的每个子集最多有最大值减去最小值$k$，并且当每个子集的最大元素被选为右端点时，它只被计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    max_n = 200000

    # precompute powers once
    pow2 = [1] * (max_n + 1)
    for i in range(1, max_n + 1):
        pow2[i] = (pow2[i - 1] * 2) % MOD

    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        # -------- subarrays --------
        from collections import deque

        min_dq = deque()
        max_dq = deque()

        l = 0
        subarray_ans = 0

        for r in range(n):
            while min_dq and a[min_dq[-1]] >= a[r]:
                min_dq.pop()
            min_dq.append(r)

            while max_dq and a[max_dq[-1]] <= a[r]:
                max_dq.pop()
            max_dq.append(r)

            while a[max_dq[0]] - a[min_dq[0]] > k:
                if min_dq[0] == l:
                    min_dq.popleft()
                if max_dq[0] == l:
                    max_dq.popleft()
                l += 1

            subarray_ans += (r - l + 1)

        # -------- subsequences --------
        b = sorted(a)
        l = 0
        subseq_ans = 0

        for r in range(n):
            while b[r] - b[l] > k:
                l += 1
            subseq_ans = (subseq_ans + pow2[r - l]) % MOD

        print(subarray_ans, subseq_ans % MOD)

if __name__ == "__main__":
    solve()
```子数组部分维护一个滑动窗口，其中两个单调双端队列跟踪最小和最大索引。 仅在这些结构的端点检查条件，避免在窗口内重新计算。 

子序列部分依靠排序将组合约束转换为范围约束。 指数$r - l$计算除了当前最大元素之外还可以选择包含多少个元素。 

一个常见的错误是忘记通过固定最大元素来计算子序列，这可以防止从多个位置重复计算同一子集。 

另一个微妙的问题是模块化指数处理。 预计算能力是必要的，因为每个查询重复求幂会太慢。
