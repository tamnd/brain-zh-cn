 ## 解决方案
 ## 问题理解

 我们收到了许多独立的查询。 每个查询提供一个非负整数$n$，我们必须计算有多少个整数$x$在范围从$0$到$n$可以写成两个整数平方和，意思是$x = a^2 + b^2$对于某些整数$a$和$b$。 两个都$a$和$b$可以是负数或正数，但由于平方消除了符号，因此表示仅取决于它们的绝对值。 

每个查询的输出不是表示的数量，而是不同值的数量$x \le n$承认至少一种这样的表示。 

这些限制促使我们进行预处理。 高达$10^5$查询和$n \le 10^7$，每个查询重新计算答案是不可行的。 任何每个查询方法甚至是线性的$n$将达到$10^{12}$在最坏的情况下进行操作，这远远超出了限制。 这立即表明我们必须计算一个全局结构一次达到最大值$n$，然后在常数时间内回答每个查询。 

一个微妙的边缘情况是$x = 0$。 这是有效的，因为$0 = 0^2 + 0^2$，并且必须包含在内。 另一个经常导致错误的点是重复计数。 例如，$5 = 1^2 + 2^2$还有$5 = 2^2 + 1^2$，但只应计算一次。 输出是关于存在，而不是多重性。 

幼稚的方法通常会尝试测试每个$x$通过扫描所有对$(a, b)$，但是这个双循环立即变得太大，即使对于最大的单个查询也是如此$n$，因为它需要迭代所有对直到$\sqrt{n}$， 大致$10^4$每个维度，或$10^8$每个查询的检查。 

## 方法

 蛮力的想法很简单。 对于每个查询和每个数字$x \le n$，我们尝试所有整数对$(a, b)$这样$a^2 + b^2 = x$。 各候选人的人数$x$正比于$\sqrt{x}$，所以检查所有$x \le n$大致导致$\sum_{x=1}^{n} \sqrt{x}$，其增长顺序为$n^{3/2}$。 和$n = 10^7$，这是完全不可行的。 

关键的观察是我们不需要重新计算每个查询的结构。 属性“可以写成两个平方和”仅取决于$x$，而不是查询本身。 这使我们能够预先计算最大的所有有效值$n$一次。 

我们没有单独测试每个数字，而是翻转视角。 我们枚举可能的正方形$a^2$和$b^2$，并直接标记它们的总和。 自从$a^2 \le 10^7$，我们只需要$a \le 3162$。 这将问题减少到迭代所有对$(a, b)$和$a^2 + b^2 \le \text{maxN}$。 每一对贡献一个可达总和，我们将其标记在布尔数组中。 

标记所有可达和后，我们构建一个前缀和数组，以便每个查询都可以在$O(1)$时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^{3/2})$每个查询 |$O(1)$| 太慢了|
 | 预先计算平方对 |$O(n \sqrt{n})$预处理|$O(n)$| 已接受 |

 ## 算法演练

 我们通过预先计算最大可能查询的所有值，然后使用前缀和回答每个查询来解决该问题。 

1.首先确定最大的$n$跨所有测试用例。 这是必要的，因为我们想要单个全局计算而不是为每个查询重新计算。 如果没有这个，我们就会浪费时间重复相同的工作。 
2. 创建布尔数组`ok`尺寸的`max_n + 1`，最初都是假的。 该数组将存储一个数字是否可以表示为两个平方和。 
3. 迭代所有整数$a$这样$a^2 \le max_n$。 对于每个$a$, 计算$a^2$一次并重复使用。 这样就避免了重复重新计算平方，保证了效率。 
4.对于每个固定$a$，迭代所有整数$b$这样$a^2 + b^2 \le max_n$。 对于每一对，标记`ok[a^2 + b^2] = True`。 我们只枚举有效对，因此除了循环​​条件之外不需要进行边界检查。 
5.处理完所有pair后，构建前缀和数组`pref`在哪里`pref[i]`计算有多少个值$x \le i$满足`ok[x]`。 这将问题从集合成员资格查询转换为范围计数查询。 
6. 对于每个测试用例$n$， 输出`pref[n]`。 

### 为什么它有效

 每个有效的表示$x = a^2 + b^2$正好对应一对非负整数$(a, b)$和$a \le b$或者$b \le a$，但我们不需要对级别的唯一性。 我们只需要确保每个可达总和至少被标记一次。 由于我们系统地枚举了所有对，因此每个可表示的数字都被标记。 然后，前缀和会精确计算具有至少一种有效表示形式的整数，因此答案是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ns = [int(input()) for _ in range(t)]
    max_n = max(ns)

    ok = [False] * (max_n + 1)

    a = 0
    while a * a <= max_n:
        a2 = a * a
        b = 0
        while a2 + b * b <= max_n:
            ok[a2 + b * b] = True
            b += 1
        a += 1

    pref = [0] * (max_n + 1)
    cnt = 0
    for i in range(max_n + 1):
        if ok[i]:
            cnt += 1
        pref[i] = cnt

    out = []
    for n in ns:
        out.append(str(pref[n]))
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```实现的核心思想是双循环$a$和$b$，仅当平方和保持在界限内时才运行。 这确保我们永远不会探索超出最大数量的不必要的对$n$。 布尔数组可防止对不同对中的相同值进行重复计算。 

前缀和构造至关重要，因为它将预先计算的成员资格数组转换为查询应答结构。 如果没有它，每个查询将需要扫描最多$n$，这会太慢。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 |$O(n \sqrt{n})$| 每个$a$迭代$b$最多$\sqrt{n - a^2}$，一次覆盖所有有效对 |

 ## 边缘情况

 ### 案例：$n = 0$输入：```
1
0
```算法初始化`ok[0] = True`因为$0 = 0^2 + 0^2$。 前缀数组开头为`pref[0] = 1`，因此输出为 1。双循环绝不会错过这种情况，因为$a = 0, b = 0$被明确包含在内。 

### 情况：小边界，仅存在很少的和

 输入：```
1
2
```枚举标记：$0 = 0^2 + 0^2$,$1 = 0^2 + 1^2$,$2 = 1^2 + 1^2$。 

因此`ok`具有最多 2 个真值，并且前缀正确返回 3。该结构确保不重复，因为所有三个值都是数组中不同的索引。 

### 案例：较大值周围的稀疏表示

 输入：```
1
8
```标记的值包括0、1、2、4、5和8。前缀计数正确地累加了这六个值。 嵌套循环保证探索直到边界的所有有效对，因此不会错过任何可表示的数字，即使它们不连续。
