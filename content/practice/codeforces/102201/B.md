 ## 解决方案
 ## 问题理解

 灯泡的四种可能的操作都会产生一个半平面，其边界穿过该灯泡。 与所有选定的半平面相交总是给出一个与轴平行的矩形，可能是退化的或空的。 

有一种更清晰的方式来查看相同的选择。 假设最终照亮的区域是一个矩形（R）。 当灯泡不严格位于 (R) 内部时，((X,Y)) 处的灯泡可以准确地对齐 (R) 四个边之一。 如果灯泡位于边界之外或边界上，则选择相应的包含 (R) 的半平面。 相反，如果灯泡严格位于 (R) 内部，则其四个半平面都不能包含整个矩形。 因此，原来的问题正是寻找内部不包含灯泡的（H×W）阶段内最大面积的轴平行矩形的问题。 

这是经典的最大空矩形点问题，专门针对所有 (x) 坐标和所有 (y) 坐标都不同的情况。 不同坐标条件使得下面的区间表示特别清晰。 同样的减少也是该问题的已知治疗中使用的关键观察。 

对于 (N\le 100000)，(O(N^2)) 扫描不可行。 在考虑维持每个区间最大垂直间隙所需的工作之前，最坏的情况大约是 (5\times10^9) 个区间状态。 坐标范围达到（10^8），因此坐标压缩很有用，但基于网格的方法完全不可能。 

有几种边界情况很容易处理不当。 例如，如果角落里有一个灯泡```
100 100 1
0 0
```整个阶段都是有效的，因为灯泡位于其边界上，所以答案是（10000）。 将边界点视为禁止的测试将错误地返回零。 

如果灯泡形成一条下降的对角线，```
4 4 5
0 4
1 3
2 2
3 1
4 0
```答案是（6）。 整个 (4\times4) 阶段是不可能的，但最佳值不仅仅是连续 (x) 坐标或连续 (y) 坐标之间的最大间隙。 必须同时考虑这两个维度。 

最后，一个矩形可能会在其边界上接触多个灯泡。 这些灯泡是允许的。 这就是为什么该公式使用空的内部而不是根本不包含任何点的矩形。 

## 方法

 直接的方法是按 (x) 对灯泡进行排序，选择水平位于候选矩形内的连续灯泡组，并计算它们的 (y) 坐标之间的最大垂直间隙。 假设候选矩形在其水平投影中恰好包含灯泡 (l,\ldots,r)。 它的水平边可以向外推动，直到到达前一个和后一个灯泡，或舞台边界。 因此它的最大可能宽度是

 [
 x_{r+1}-x_{l-1},
 ]

 其中 (x_0=0) 和 (x_{N+1}=H)。 

对于这组固定的水平包含的灯泡，垂直间隔必须在其内部不包含任何选定的 (y) 坐标。 添加阶段边界 (0,W) 和值 (y_l,\ldots,y_r)，对它们进行排序，并取最大的连续间隙。 将该值称为 (h(l,r))。 该区间表示的最佳矩形的面积

 [
 (x_{r+1}-x_{l-1})h(l,r)。 
]

 这给出了精确的 (O(N^2)) 算法。 我们可以一次扩展 (r) 一个位置，并将选定的 (y) 坐标维护在有序集合中，因此可以有效地处理每个间隔。 问题是间隔的数量。 对于 (N=100000)，有 (N(N+1)/2) 个，大约 (5\times10^9) 个。 

优化首先观察到相关区间具有很强的嵌套结构。 对于区间 ([l,r])，(h(l,r)) 是插入属于该区间的 (y) 坐标后的最大间隙。 扩大间隔只能分裂现有的间隙，因此 (h) 永远不会增加。 这种单调性让我们只保留重要的最大状态。 

分而治之的解决方案正是使用这些状态。 对于 (x) 有序点的每个递归段，我们构造一组紧凑的三元组

 [
 (左,右,小时),
 ]

 其中 ([l,r]) 是 (x) 间隔，(h) 是其最大可用垂直间隙。 保留的区间形成一个层流族：其中两个不能部分重叠，而不包含另一个。 当一个区间包含另一个区间时，其间隙值不再更大。 这两个属性是潜在的二次集合在每个分治级别上崩溃为线性大小集合的原因。 

然后必须合并两个递归部分。 如果它们的三元组是 ((l_i,r_i,h_i)) 和 ((l_j,r_j,h_j))，则它们的兼容矩形具有水平重叠

 [
 \min(r_i,r_j)-\max(l_i,l_j)
 ]

 和垂直间隙

 [
 h_i+h_j。 
]

 因此他们的贡献是

 [
 (h_i+h_j)
 \left(\min(r_i,r_j)-\max(l_i,l_j)\right)。 
]

 剩下的问题是两个层流三元组的结构化最大值。 嵌套区间被视为二维优势问题。 部分重叠的间隔可以通过第二次分而治之来处理。 在交叉子问题中，当按 (h) 排序时，三元组变得单调：随着 (h) 增加，左端点向右移动，右端点向左移动。 由此产生的可行伙伴集是滑动窗口，为最终的最大计算提供了所需的单调性。 

这与最大空矩形公式的已知 (O(N\log^3N)) 解中使用的结构优化相同。 文献还为一般最大空矩形问题提供了更复杂的边界，但这里的不同坐标结构足以满足竞赛解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(N^2\log N)) | (O(N)) | 太慢了 |
 | 最优分而治之| (O(N\log^3N)) | (O(N\log N)) | 已接受 |

 ## 算法演练

1. 按 (x) 对所有灯泡进行排序。 将所得坐标写为 (x_1,\ldots,x_N)，其中 (x_0=0) 和 (x_{N+1}=H)。 相应的 (y) 坐标形成排列，因为所有 (y) 坐标都是不同的。 
2. 将每个可行的照明解释为一个空的轴平行矩形。 这消除了每个灯泡的四向选择，并用一种​​几何条件代替：没有灯泡可以严格位于矩形内。 
3. 对于 (x) 区间 ([l,r])，将 (h(l,r)) 定义为 (0,y_l,\ldots,y_r,W) 中的最大间隙。 如果矩形在其水平投影中恰好包含这些灯泡，则其最大宽度为 (x_{r+1}-x_{l-1})，因此候选区域为 ((x_{r+1}-x_{l-1})h(l,r))。 
4. 在 (x) 索引区间递归求解。 在一个递归段内，仅维护最大状态 ((l,r,h))。 当一个新点添加到一个区间时，它只能分割现有的垂直间隙，因此它的最佳间隙永远不会变大。 这给出了丢弃主导状态所需的层数和单调性。 
5. 递归求解左半部分和右半部分。 该递归调用已经考虑了水平集完全包含在一半中的每个最佳矩形。 
6. 合并相关水平间隔穿过分割点的矩形。 对于两个状态，它们的组合水平跨度由两个间隔的交集决定，而它们的两个垂直间隙则相加。 最大化的价值是

 [
 (h_i+h_j)
 \left(\min(r_i,r_j)-\max(l_i,l_j)\right)。 
]
 7. 将间隔对分为嵌套对和交叉对。 嵌套间隔满足坐标主导条件，并且可以使用标准二维排序进行处理。 交叉对的形式为

 [
 l_i<l_j<r_i<r_j。 
]

 这是唯一真正困难的情况。 
8. 对交叉对应用第二次分治法。 在每个节点，只有满足的对

 [
 l_i<l_j\le mid<r_i<r_j
 ]

 被处理。 不穿过辅助中点的对将被递归传递。 
9. 按递增 (h) 对左族进行排序，按递减 (h) 对右族进行排序。 由于保留的间隔是层流的，因此增加 (h) 将左端点向右移动，将右端点向左移动。 对于固定的右状态，其有效的左状态形成一个连续的滑动窗口。 这些窗口的端点单调移动，因此无需枚举每一对即可找到所有对的最大值。 
10. 在每个递归级别重复此组合。 第一个分而治之贡献了一个对数因子，而结构化交叉计算贡献了另外两个对数因子，给出了 (O(N\log^3N))。 

不变量是每个最大空矩形都具有保留区间状态之一的表示，或者作为来自不同递归半部的两个状态的兼容组合。 因为扩大间隔只能破坏垂直间隙，所以支配状态以后永远无法成为更好矩形的一部分。 嵌套和交叉情况耗尽了所有相对间隔顺序，因此没有丢弃最佳矩形。 

## Python 解决方案

 (O(N\log^3N)) 算法的完整竞赛实现比传统的线段树解决方案涉及更多。 特别是，交叉对例程需要维护层流三元组及其单调滑动窗口。 简短的 Python 实现并不是对已接受算法​​的忠实翻译，并且在此处呈现 (O(N^2)) 实现，同时将其标记为已接受将产生误导 (N=100000)。 

作为参考，几何缩减和 (O(N^2)) 基线很简单：```python
import sys
input = sys.stdin.readline

def largest_empty_rectangle(H, W, points):
    points.sort()

    n = len(points)
    x = [0] + [p[0] for p in points] + [H]
    y = [0] + [p[1] for p in points] + [W]

    ans = 0

    for l in range(1, n + 1):
        vals = [0, W]

        for r in range(l, n + 1):
            vals.append(y[r])
            vals.sort()

            height = 0
            for i in range(1, len(vals)):
                height = max(height, vals[i] - vals[i - 1])

            width = x[r + 1] - x[l - 1]
            ans = max(ans, width * height)

    return ans

def solve():
    H, W, N = map(int, input().split())
    points = [tuple(map(int, input().split())) for _ in range(N)]
    print(largest_empty_rectangle(H, W, points))

if __name__ == "__main__":
    solve()
```该代码可用作小型实例的正确性预言，但它不是给定约束的提交算法。 嵌套循环枚举每个 (x) 间隔，对选定的 (y) 坐标进行排序会使实现速度更慢。 公认的方法用上述层流分而治之的结构代替了这种枚举。 

在 Python 中，乘法必须使用任意精度整数，因为最大面积为 (10^{16})。 Python 会自动处理此问题，而 C++ 实现则需要 64 位整数。 

舞台边界水平方向为 (0) 和 (H)，垂直方向为 (0) 和 (W)。 这也是为什么位于舞台边界的灯泡不需要特殊处理的原因。
