 ## 解决方案
 ## 问题理解

 我们需要构建一个递增的序列`n`正整数，使得后面的元素不能被任何前面的元素整除。 

输入包含单个数字`n`。 我们必须输出任意长度的序列`n`满足两个条件。 首先，序列必须是严格递增的。 其次，对于每对位置`i < j`, 位置处的值`j`不得是该位置值的倍数`i`。 

从数学角度来看，这些约束非常慷慨，但从实现角度来看，这些约束却很严格。 我们最多需要`100000`数字，并且每个数字最多只能是`10^7`。 和`n = 100000`，任何显式检查所有对的算法都需要粗略地$$\frac{100000 \cdot 99999}{2} \approx 5 \cdot 10^9$$比较，在一秒钟之内是完全不可能的。 我们需要直接构建。 

最重要的观察结果是，该问题并不要求字典顺序最小的序列或任何最佳序列。 任何有效的构造都被接受。 

一个常见的错误是使用从 1 开始的连续整数。 

例如：```
n = 3
```顺序：```
1 2 3
```无效，因为每个数字都可以被 1 整除。 

另一个诱人的想法是使用从 2 开始的连续整数：```
2 3 4
```这仍然无效，因为`4`可以整除`2`。 

正确的顺序为`n = 3`可能是：```
2 3 5
```没有元素可以分割任何后面的元素。 

另一个微妙的问题是上限`10^7`。 生成非常大数字的构造可能满足整除条件，但违反了允许的范围。 

例如，二的幂：```
2, 4, 8, 16, ...
```已经不满足可分性条件，即使修改，快速增长的结构风险也会超过`10^7`。 

我们需要一种结构，同时保证增加秩序，避免整除性，并保持在极限之内。 

## 方法

 暴力方法将一次构建一个数字的序列。 对于每个候选值，我们将检查它是否可以被任何先前选择的数字整除。 如果它通过了所有检查，我们会将其附加到序列中。 

此方法是正确的，因为它显式验证了所需的属性。 问题是效率。 每个新的候选人可能需要针对许多以前的元素进行测试。 和`n = 100000`，即使是优化版本也会执行太多的整除性检查。 

关键的观察是素数自动满足条件。 

假设我们按升序选择不同的素数：```
p1 < p2 < p3 < ...
```取任意一对`i < j`。 自从`pj`是素数且大于`pi`，唯一的正因数`pj`是`1`和`pj`本身。 自从`pi`不是这些值中的任何一个，`pj`不能被整除`pi`。 

因此，任何不断增加的不同素数列表都会自动成为一个饥饿序列。 

现在的问题变成了寻找`n`素数不超过`10^7`。 

一个众所周知的事实是，远不止`100000`下面的素数`10^7`。 事实上，第 100000 个素数是`1299709`，轻松低于限制。 从而生成第一个`100000`素数就足够了。 

标准工具是埃拉托斯特尼筛法。 运行筛子至约`1.3 × 10^6`容易产生至少`100000`素数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) 或更糟 | O(n) | 太慢了 |
 | 最优（筛子 + 前 n 个素数）| O(M 对数 M) | O(M)| 已接受 |

 这里`M`是筛限，大约`1.3 × 10^6`。 

## 算法演练

 1. 阅读`n`。 
2. 选择足够大的筛限，至少包含`100000`素数。 限制为`1300000`就足够了。 
3. 运行埃拉托色尼筛直至该极限。 
4. 按升序收集所有素数。 
5.输出第一个`n`素数。 

这样做的原因是，当从筛子中收集素数时，素数已经严格递增，并且没有比另一个素数更大的素数可以被它整除。 

### 为什么它有效

 筛子按升序产生素数，因此序列是严格递增的。 

考虑任意两个选定的元素`pi < pj`。 自从`pj`是质数，它唯一的正因数是`1`和`pj`。 数量`pi`不是这两个约数，因为它是一个较小的素数。 因此`pi`不分开`pj`。 

由于该参数适用于每对索引，因此生成的序列满足饥饿序列条件。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    LIMIT = 1300000

    is_prime = [True] * (LIMIT + 1)
    is_prime[0] = is_prime[1] = False

    p = 2
    while p * p <= LIMIT:
        if is_prime[p]:
            for multiple in range(p * p, LIMIT + 1, p):
                is_prime[multiple] = False
        p += 1

    primes = []
    for i in range(2, LIMIT + 1):
        if is_prime[i]:
            primes.append(i)
            if len(primes) == n:
                break

    print(*primes)

if __name__ == "__main__":
    solve()
```第一部分读取所需的序列长度。 

筛子标记合数。 对于每个素数`p`，每个倍数从`p²`被标记为非素数。 开始于`p²`避免了多余的工作，因为较小的倍数已经由较小的素数处理过。 

筛子完成后，我们按升序扫描数字并收集素数。 一旦我们聚集`n`素数，我们立即停止，而不是扫描数组的其余部分。 

输出由第一个组成`n`素数。 它们的递增顺序直接来自扫描顺序。 

一个微妙的实现细节是筛限。 我们需要足够的素数来应对最坏的情况`n = 100000`。 限制为`1300000`安全地含有超过`100000`素数，因此收集循环总是成功。

 ## 边缘情况

 对于最小输入```
1
```算法输出：```
2
```长度为 1 的序列没有对可检查，因此它自动处于饥饿状态。 

对于小输入，例如```
2
```算法输出：```
2 3
```序列不断增加，并且`3 % 2 != 0`，所以条件成立。 

对于最大输入```
100000
```该算法只是简单地取第一个`100000`从筛子中取出素数。 最后选择的素数仍在下面`10^7`，满足值约束。 没有一对违反整除条件，因为所有选定的数字都是不同的素数。 

错误解决方案的常见失败案例是使用连续整数：```
2 3 4
```在哪里`4`可以整除`2`。 

我们的构造完全避免了这种情况，因为每个元素都是素数，并且没有比另一个素数更大的素数可以被它整除。
