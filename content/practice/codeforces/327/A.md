 ## 解决方案
 ## 问题理解

 我们有一个二进制数组，每个元素都是`0`或者`1`。 我们必须精确选择一个连续的段并翻转其中的每个值。 翻转改变`0`到`1`和`1`到`0`。 

执行此单个操作后，我们希望结果数组包含尽可能多的值。 任务是计算该最大数量。 

数组长度最多为100，非常小。 甚至一个$O(n^3)$解决方案仅执行大约一百万次操作，这很容易满足时间限制。 这意味着我们不需要复杂的数据结构。 尽管如此，仍然有一种更简洁的方法来思考这个问题，将其简化为经典的最大子数组计算。 

最容易错过的边缘情况是当数组已经完全由 1 组成时。 

输入：```
3
1 1 1
```输出：```
2
```我们需要精确地执行一次翻转。 任何选定的段至少包含一个`1`，翻转它会减少数量。 允许“不执行任何操作”的粗心解决方案将错误地输出`3`。 

另一个常见的错误是只计算所选段内的零。 

输入：```
5
1 0 1 0 1
```如果我们翻转位置 2 到 4，我们会从 0 中获得两个新的位置，但也会失去一个现有的位置。 净改进仅为`+1`。 任何忽视迷失者的方法都会高估答案。 

第三种边缘情况是长度为一的段。 

输入：```
1
0
```输出：```
1
```唯一有效的移动是翻转单个元素。 意外需要大于 1 的段长度的实现将在此处失败。 

## 方法

 最直接的解决办法就是暴力破解。 我们可以尝试每一个可能的部分`[l, r]`，模拟翻转，数出结果的个数，保留最佳答案。 有$O(n^2)$可能的片段，并计算结果片段需要$O(n)$时间、给予$O(n^3)$整体复杂性。 

为了$n \le 100$，即使这种方法也被接受。 这个问题有趣的部分是认识到一种更简洁的表述。 

假设原始数组包含`base`那些。 

当我们翻转一个段时：

 - 每个`0`段内变为`1`, 贡献`+1`到总数。 
- 每一个`1`段内变为`0`, 贡献`-1`。 

对于每个位置，我们可以分配一个值：

 -`+1`如果该元素是`0`-`-1`如果该元素是`1`翻转线段产生的净变化正是该线段上这些值的总和。 

现在问题变成：

 > 找到总和最大的连续段。 

这正是最大子数组问题，可以用 Kadane 算法在线性时间内解决。 

最终的答案是：$$\text{base ones} + \text{maximum subarray sum}$$全 1 的情况会自动运行。 每个变换后的值都变成`-1`，所以最大子数组和是`-1`，这意味着我们通过翻转单个元素恰好丢失了一个。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n3) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 统计原数组中有多少个。 调用这个值`base`。 
2. 将数组变换为增益数组。 

如果一个元素是`0`， 店铺`+1`因为翻转它会使 1 的数量增加 1。 

如果一个元素是`1`， 店铺`-1`因为翻转它会使 1 的数量减少 1。 
3. 在增益数组上运行 Kadane 算法以找到最大子数组和。 

该值代表单次翻转可获得的最大可能改进。 
4. 将最大增益添加到`base`。 
5. 输出结果。 

### 为什么它有效

 对于任何选定的段，内部的每个 0 在翻转后都会额外贡献一个 1，而内部的每个 1 在翻转之后会少贡献一个 1。 该段的净效果恰好是该段上转换值的总和。 

每个可能的翻转恰好对应于增益数组中的一个连续子数组，并且每个连续子数组恰好对应于一个有效翻转。 最大化最终的个数就相当于最大化这个增益。 Kadane 的算法找到最大子数组总和，因此将该增益添加到原始的个数中会产生最佳答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    base = sum(a)

    cur = -10**9
    best = -10**9

    for x in a:
        gain = 1 if x == 0 else -1

        if cur < 0:
            cur = gain
        else:
            cur += gain

        best = max(best, cur)

    print(base + best)

solve()
```第一步计算原始数量。 这是我们在执行任何翻转之前获得的值。 

然后，循环将每个元素转换为其增益贡献，而无需创建单独的数组。 零贡献`+1`，而一个人贡献`-1`。 

Kadane 的算法维护两个值。`cur`存储以当前位置结束的最佳子数组和，以及`best`存储迄今为止在任何地方看到的最佳子数组总和。 

初始化很重要。 我们不能从零开始，因为这个问题只需要翻转一次。 使用 Kadane 算法的标准非空子数组版本可保证至少选择一个位置。 这就是全一情况产生正确答案的原因。 

最后，`base + best`给出可实现的最大数量。

 | ---| ---| ---| ---| ---|

最终答案：`base + best = 2 + 2 = 4`输出：```
4
```该迹线表明，最佳段是增益总和等于的段`2`。 翻转它会使 1 的数量恰好增加 2。

4

```原始数：`base = 4`增益数组：`[-1, -1, -1, -1]`| 位置 | 价值| 增益| 当前卡丹 | 最佳|
 | ---| ---| ---| ---| ---|

 | 3 | 1 | -1 | -1 | -1 |

最终答案：`4 + (-1) = 3`输出：```

 ## 边缘情况

 ### 所有人

 输入：```
3
1 1 1
```增益数组变为：```
-1 -1 -1
```Kadane 的最大子数组和为`-1`，通过选择任意单个位置获得。 原来的个数是`3`，所以答案是：```
3 + (-1) = 2
```该算法正确地模拟了强制翻转这一事实。 

### 单元素零

 输入：```
1
0
```增益数组为：```
+1
```最大增益为`1`，原来的计数是`0`，所以结果是：```
1
```长度为 1 的段的处理方式与任何其他段完全相同。 

### 收益和损失都很重要的混合价值

 输入：```
5
1 0 1 0 1
```增益数组为：```
-1 +1 -1 +1 -1
```最大子数组和为`1`。 

原来的计数是`3`，给予：```
3 + 1 = 4
```这证实了该算法正确地减去了翻转段内丢失的零，而不是仅计算获得的零。 

### 最佳片段触及边缘

 输入：```
5
0 0 1 1 1
```增益数组为：```
+1 +1 -1 -1 -1
```最大子数组是带有 sum 的前缀`2`。 

原来的计数是`3`，所以答案是：```
3 + 2 = 5
```该算法自然地处理从第一个位置开始或在最后一个位置结束的段，从而避免差一错误。
