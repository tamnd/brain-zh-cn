 ## 解决方案
 # 问题理解

 该运算适用于数字的二进制表示形式。 我们可以选择任意三个连续的位位置并将这三个位反转。 在这三个位中，只有第一和第三位置交换位置，因此一次操作恰好是相距两个位置的两个位之间的交换。 

任务是变换数字`x`进入`y`使用最少数量的此类交换。 可以考虑前导零，这意味着我们在应用操作时可以使用超出最高设置位的位置。 

重要的结构是，一个位永远不能改变其奇偶位置。 位置 0 的位只能移动到位置 2、4、6 等。 位置 1 的位只能移动到位置 3、5、7，以此类推。 该操作将二进制表示分成两个独立的序列，一个包含偶数位置，另一个包含奇数位置。 

的价值观`x`和`y`可以大到`10^18`，因此只有大约 61 个相关位。 对于多达 10000 个测试用例，解决方案必须接近每个用例的恒定时间。 操作模拟是不可行的，因为可能的交换数量可能很大，但处理固定数量的位数很容易足够快。 

一个常见的错误是只比较总数。 例如，改造`1`进入`2`即使两个数字都包含一组位，也是不可能的。 唯一的一点是`1`位于位置 0，而唯一的位`2`位于位置 1，并且没有操作更改奇偶校验。 

另一个边缘情况是前导零很重要。 例如，改造`3`进入`6`有答案`1`。 在二进制中这是`011`到`110`，并且该操作将三位反转。 将数字视为字符串而不考虑位置可能会意外地错过最左边的零是有效位位置。 

最后一种边缘情况是不需要任何操作的情况。 用于输入```
5
5
```意义`x = 5`,`y = 5`，答案是`0`。 仅计算所需交换并忘记已经匹配状态的解决方案可能会产生不必要的肯定答案。 

# 方法

 蛮力方法将重复选择三个位，应用反转，并搜索达到的最短操作序列`y`。 这是正确的，因为每个有效的操作序列都对应于可能的二进制数状态图中的一条路径。 然而，状态数量随着位数呈指数增长。 即使将我们限制在相关的 61 位，也给出了太多的可能性，因此最短路径搜索是不可能的。 

关键的观察是三位反转仅交换位置`i`和`i + 2`。 这意味着该操作不是位的任意排列。 它是具有相同奇偶校验的位置子序列内的相邻交换。 偶数位置形成一个独立数组，奇数位置形成另一个独立数组。 

经过这种转换，问题就变成了经典的最小相邻交换问题。 对于一个奇偶组，我们知道其中所有奇偶组的位置`x`以及所有人的位置`y`。 第一个在`x`必须移动到第一个位置`y`，第二个必须移动到第二个，依此类推。 相邻交换的最小数量是压缩奇偶校验阵列中这些距离的总和。 

蛮力之所以有效，是因为它探索了比特的每一种可能的移动，但它忽略了比特永远不会在奇偶校验组之间交叉的事实。 宇称观察将问题简化为两个独立的一维重排。

 # 算法演练

 1. 提取位`x`和`y`从最低有效位向上。 我们只需要大约 61 个位置，因为这两个值最多都是`10^18`。 高于此范围的位置始终为零。 
2. 根据奇偶校验将设置的位位置分为两组。 对于每个奇偶校验，存储压缩序列中的索引。 例如，职位`0, 2, 4, 6`成为压缩索引`0, 1, 2, 3`。 
3. 比较相应奇偶组中 1 的个数`x`和`y`。 如果它们不同，则转换是不可能的，因为操作永远不会在偶数位置和奇数位置之间移动一点。 
4. 对于每个奇偶组，按顺序匹配。 添加每个源压缩索引和目标压缩索引之间的绝对差。 这是该奇偶校验序列内所需的相邻交换的数量。 
5. 将两个奇偶校验组的成本相加并打印结果。 

为什么它有效：允许的操作正是两个奇偶校验子序列之一中的相邻交换。 相邻交换保留另一个奇​​偶校验的顺序，并且可以将任何位移动到同一奇偶校验组内的任何位置。 对于二进制序列，相邻交换的最小数量是通过将第一个与第一个、第二个与第二个匹配来实现的，依此类推。 如果 1 的数量不同，则任何交换序列都不能创建或删除 1，因此答案是不可能的。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

def solve_case(x, y):
    src = [[], []]
    dst = [[], []]

    for i in range(61):
        if (x >> i) & 1:
            src[i & 1].append(i // 2)
        if (y >> i) & 1:
            dst[i & 1].append(i // 2)

    ans = 0

    for p in range(2):
        if len(src[p]) != len(dst[p]):
            return -1
        for a, b in zip(src[p], dst[p]):
            ans += abs(a - b)

    return ans

def main():
    t = int(input())
    out = []

    for case in range(1, t + 1):
        x, y = map(int, input().split())
        out.append(f"Case {case}: {solve_case(x, y)}")

    print("\n".join(out))

if __name__ == "__main__":
    main()
```该解决方案仅存储设置位的位置，因为不需要显式移动零位。 固定位到位`i`属于奇偶组`i % 2`，其压缩位置为`i // 2`。 这会将原始位置转换为索引，其中相邻元素表示可能的交换。 

在计算距离之前完成不可能的检查。 仅比较 1 的总数是不正确的，因为两个奇偶校验组无法交换位。 

最后一个循环利用了这样一个事实：已排序的位置必须以相同的顺序进行匹配。 不需要动态编程或模拟，因为每次交换仅在其自己的奇偶校验序列内移动一位。

 # 边缘情况

 对于不可能奇偶校验的情况，考虑`x = 1`和`y = 2`。 二进制形式是`...0001`和`...0010`。 唯一设置的位从位置 0 开始，到位置 1 结束。由于每次操作都会交换距离为 2 的位置，因此该位永远不会到达奇数位置。 该算法将源位放入偶数组，将目标位放入奇数组，检测不同的计数，然后返回`-1`。 

对于前导零处理，请考虑`x = 3`和`y = 6`。 相关位是`011`和`110`。 位置 0 处的设置位移至位置 2，这是偶数压缩序列中的一步。 奇数位置保持不变。 该算法计算一次运动并返回`1`。 

对于已经解决的情况，考虑`x = 12`和`y = 12`。 两个奇偶校验组包含完全相同的 1 位置。 每个距离都是零，所以答案也是零。 该算法不会执行不必​​要的交换。 

对于较大的值，请考虑`x = 10^18`和`y = 10^18`。 该算法仅检查 61 个位置，因此它处理上限而不依赖于数值大小本身。 答案仍然为零，因为没有位需要移动。
