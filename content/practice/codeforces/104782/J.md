 ## 解决方案
 ## 问题理解

 我们得到了几个测试用例。 在每个测试用例中都有一组棒长度。 从这个集合中，我们想知道是否可以挑选四根不同的木棍，以便在平面上自由旋转和重新排列它们之后，它们可以使用所有四根木棍作为其边形成平行四边形。 

平行四边形有两对相等的对边。 因此，在选定的四种长度的棍子中，我们必须能够将它们配对成相等的两对。 换句话说，如果我们对所选的四个值进行排序，它们必须看起来像$x, x, y, y$对于一些正长度$x$和$y$。 除了不同的索引之外，输入中的选择顺序并不重要。 

输入规模大：所有测试用例的棒总数可以达到$2 \cdot 10^5$，并且最多有$10^4$测试用例。 这立即排除了任何尝试显式检查所有四元组的解决方案，因为即使是单个测试用例$n = 2 \cdot 10^5$会使$O(n^4)$或者$O(n^3)$不可能的。 

关键的约束是棒的长度受以下限制$n$，这表明基于频率的推理在每个测试用例的线性或接近线性时间内是可能的。 

当许多值相同时，会出现微妙的边缘情况。 例如，如果所有棍子都相等$[1, 1, 1, 1]$，答案显然是 YES，因为我们可以形成一个所有边都相等的平行四边形，这是一种特殊情况。 另一个边缘情况是当有两个不同的值但没有足够的重复时，例如$[1, 1, 2, 3]$，我们可能有一对，但不能形成两个完整的对。 

一个天真的错误是认为“数组中任何位置的任何两对就足够了”，而不确保不同的索引。 例如，如果值为$[1, 1, 2]$，我们可能会错误地认为我们可以形成两对，因为有一对 1，但我们仍然需要另一对，而该对并不存在。 

## 方法

 暴力方法会尝试所有四元组$i < j < k < p$，检查这四个值，并测试它们是否可以分为两个相等的对。 这是正确的，因为它详尽地尝试了四根棍子的所有可能选择。 然而，四元数的个数是$\binom{n}{4}$，其增长为$O(n^4)$。 即使是为了$n = 2000$，这已经太慢了，而这里$n$取决于$2 \cdot 10^5$，使其完全不可行。 

条件的结构简化了问题。 除了确保唯一性之外，我们不关心哪些索引构成对。 唯一重要的是是否存在至少两个不同的值，每个值至少出现两次。 如果我们有一个值出现四次，这也有效，因为它可以形成两对相等长度。 如果我们有两个不同的值，每个值至少出现两次，我们可以为每个值分配一对。 

因此，问题简化为频率问题：我们需要检查是否存在至少两对相等的值，并仔细计算重数。 频率至少为 4 的一个值已经贡献了两对，并且频率至少为 2 的两个值也足够了。 

这将问题简化为扫描频率并计算我们可以提取多少个不相交的对。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n^4)$|$O(1)$| 太慢了|
 | 频率计数 |$O(n)$每次测试 |$O(n)$| 已接受 |

 ## 算法演练

 我们将问题转化为计算棒长度多重集中存在多少对相等的值。 

1. 使用哈希图或数组计算每个棒长度的频率。 

此步骤是必要的，因为配对条件仅取决于每个值存在的数量，而不取决于它们的位置。 
2. 对于每个具有频率的不同值$f$，计算它贡献了多少个不相交对$f // 2$。 

这捕获了我们可以从该值形成的最大对数，而无需重用元素。 
3. 对所有值中的这些对计数求和。 

总数代表我们总共可以形成多少个等长对。 
4. 如果对总数至少为 2，则打印 YES。 否则，打印NO。 

我们至少需要两对，因为平行四边形需要一个长度的两个相对边和另一个长度的两个相对边。 

### 为什么它有效

 任何形成平行四边形的四根木棍的有效选择都必须分成两个相等的对。 每对必须来自相同的值，因此每个有效的解决方案都对应于从频率多重集中选择两个不相交的对。 相反，如果我们可以从多重集中提取两个不相交的对，我们可以将它们指定为平行四边形的相对边。 由于允许旋转和重新排列，因此除了相对边相等之外，没有任何几何约束会影响可行性。 

因此，该问题完全等同于检查可用的相等对的总数是否至少为两个。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        freq = {}
        for x in a:
            freq[x] = freq.get(x, 0) + 1

        pairs = 0
        for v in freq.values():
            pairs += v // 2

        if pairs >= 2:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```该解决方案是围绕直接频率聚合构建的。 字典在线性时间内累积计数。 第二遍通过整数除法将每个频率转换为可用对的数量。 这避免了显式跟踪实际索引或组合的任何需要。 

一个常见的实现陷阱是忘记频率为 4 的单个值贡献两对，这就是为什么`v // 2`是必不可少的，而不仅仅是检查是否`v >= 2`。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = {}
        for x in a:
            freq[x] = freq.get(x, 0) + 1
        pairs = sum(v // 2 for v in freq.values())

 ## 边缘情况

 一种边缘情况是单个值在数组中占主导地位。 对于像这样的输入`1 1 1 1`，频率为 4，从相同的值生成两对。 该算法计算`4 // 2 = 2`，正确返回 YES。 

另一种情况是当对存在但数量不足时，例如`1 1 2 3`。 这里频率产生一对`1`其他人的零，总共一。 算法正确地拒绝了它。 

一个更具欺骗性的案例是`1 1 1 2 2`。 频率是`1:3`和`2:2`。 这产生`1 + 1 = 2`成对，所以答案是肯定的，尽管从视觉上看可能并不明显，四根棍子可以适当排列。 配对抽象确保了正确性，无需进行几何推理。
