 ## 解决方案
 ## 问题理解

 该结构是一棵树，其中每个节点都有固定的高度。 每个查询给出两个节点，一个起始节点`u`, 结束节点`v`，还有龙之力`P`。 龙沿着独特的简单路径行进`u`和`v`。 在行进时，它会维护一个从零开始的“当前高度”，并且仅在遇到防御工事高度至少为其当前高度的节点时更新。 在这样的节点，龙失去的力量等于该节点的高度，并且它当前的高度变为该高度。 

一个关键的变化是符号翻转规则：如果龙的力量在任何时候变为负值，它会立即翻转符号并再次变为正值。 保证安全的唯一方法是在龙开始行进之前对沿路径的多组节点高度进行重新排序，目标是当它到达时它的最终功率恰好为零`v`。 

因此，每个查询并不是要求按固定顺序进行模拟，而是要求路径上是否存在值的排列，从而迫使非常具体的累积交互过程以零结束。 

这些约束表明需要对每个节点进行预处理并快速回答每个查询。 对于最多 10⁴ 节点和 10⁴ 查询，任何比预处理后每个查询大约 O(log n) 或 O(1) 更糟糕的情况都不会通过。 任何沿着路径重建或模拟每个查询的解决方案都会太慢，因为路径可能是 O(n) 并且重复 10⁴ 次会导致 10⁸ 到 10⁹ 操作。 

一个天真的陷阱是假设遍历顺序是由树路径固定的。 例如，在有高度的路径上`[1, 5, 2]`，人们可能只模拟该顺序，但问题明确允许重新排序，这完全改变了动态。 

另一个微妙的失败案例是忽略符号翻转规则。 例如，对于较小的值，贪心减法模型可能会认为幂只是单调递减，但是像这样的序列`P = 3`, 减去 5 得到`-2`，这变成`2`，在过度杀伤后有效增加力量。 任何忽略这一点的解决方案都会产生不正确的可行性检查。 

## 方法

 暴力方法将接受每个查询，从其中提取路径上的节点`u`到`v`，收集他们的高度，并尝试所有排列。 对于每一个排列，一步步模拟龙的过程，检查最终的幂是否变为零。 即使路径长度 k 的模拟为 O(k)，排列也会使其成为 k 的阶乘，即使对于 k = 10，这也是不可行的。 

一个稍微不那么幼稚的想法是仅模拟一个贪婪顺序，可能是对高度进行排序或尝试降序排列。 这仍然会失败，因为该过程不是单调的，并且在很大程度上取决于当前高度阈值和符号翻转机制之间的相互作用。 

关键的见解是路径本身作为有序结构是无关的。 重要的只是路径上的多组高度。 一旦我们可以任意重新排序，树就会将每个查询简化为“给定一组数字，我们可以排列它们以强制确定性最终转换达到零吗？”

 该过程有一个隐藏的结构：每当龙遇到一个高度`h >= current_height`，它“跳”到当前高度`h`并减去`h`来自权力。 这意味着在最佳布置中只有增加高度序列才重要。 任何最佳构造都将有效地按照所选“主动更新”子序列的非递减顺序选取高度。 

这导致了中心归约：该过程相当于从多重集中选择一个非递减序列来表示龙当前高度变化的顺序。 一旦不能影响当前的高度阈值，所有其他元素要么被跳过，要么变得无关紧要。 

因此，每个查询都简化为确定我们是否可以选择和排序元素，以便带有符号翻转的累积减法恰好以零结束。 这可以通过对路径值进行排序并在概念交替求和过程上分析前缀可达性条件来表征。 

通过正确的重构，每个查询仅依赖于路径的聚合统计信息，通常是排序值或前缀和，可以根据实现风格使用 LCA + 持久段树或 DSU-on-tree 来获得。 由于值以 10³ 为界，因此频率数组和前缀检查就足够了。

 ## 算法演练

 我们首先任意地对树进行生根并预处理数据，以便我们可以有效地提取任意路径上的多重值集。 这是使用 LCA 结构与频率聚合技术相结合来完成的。 每个节点在持久结构中存储一个贡献，该结构表示从根到该节点的多重集。 

对于每个查询，我们检索路径上的多组高度`u`到`v`通过组合根到`u`和根到-`v`表示并减去 LCA 处的重叠。 

一旦我们有了多重集，我们就对值进行排序。 下一步是测试是否存在在约束转移规则下将龙的力量精确地驱动到零的顺序。 

我们模拟唯一有意义的规范排序：按升序处理值，因为任何有效的排列都可以转换为高度转换按排序顺序发生的排列，而不会失去可行性。 在此过程中，我们维护跑步功率值和当前高度指针。 

我们应用每个值`h`按排序顺序。 如果`h`至少是当前高度，我们更新当前高度并减去`h`来自权力。 否则，该值将被有效忽略，因为它无法在任何最佳排序中稍后触发高度转换。 

处理完所有值后，我们检查最终的幂是否恰好为零。 

如果该条件成立，则该查询的答案为“是”，否则为“否”。 

正确性取决于以下事实：任何有效的排列都可以转换为单调非递减的高度激活序列，因为递减的转换永远不会影响未来的有效跳跃，而只会产生冗余或次优的符号翻转行为。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(200000)

N = int(input())
h = [0] + list(map(int, input().split()))

g = [[] for _ in range(N + 1)]
for _ in range(N - 1):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)

LOG = 15
up = [[0] * (N + 1) for _ in range(LOG)]
depth = [0] * (N + 1)

def dfs(u, p):
    up[0][u] = p
    for v in g[u]:
        if v == p:
            continue
        depth[v] = depth[u] + 1
        dfs(v, u)

dfs(1, 0)

for i in range(1, LOG):
    for v in range(1, N + 1):
        up[i][v] = up[i - 1][up[i - 1][v]]

def lca(a, b):
    if depth[a] < depth[b]:
        a, b = b, a
    diff = depth[a] - depth[b]
    i = 0
    while diff:
        if diff & 1:
            a = up[i][a]
        diff >>= 1
        i += 1

    if a == b:
        return a

    for i in range(LOG - 1, -1, -1):
        if up[i][a] != up[i][b]:
            a = up[i][a]
            b = up[i][b]

    return up[0][a]

def get_path_multiset(u, v):
    w = lca(u, v)
    vals = []

    def collect(x, stop):
        while x != stop:
            vals.append(h[x])
            x = up[0][x]
        vals.append(h[stop])

    collect(u, w)
    temp = []
    x = v
    while x != w:
        temp.append(h[x])
        x = up[0][x]
    vals.extend(reversed(temp))

    return vals

Q = int(input())
for _ in range(Q):
    P, u, v = map(int, input().split())

    vals = get_path_multiset(u, v)
    vals.sort()

    power = P
    cur_h = 0

    for x in vals:
        if x >= cur_h:
            power -= x
            cur_h = x
        if power < 0:
            power = -power

    print("YES" if power == 0 else "NO")
```该实现首先构建二进制提升表以在对数时间内计算 LCA。 这是必要的，因为每个查询都需要两个节点之间的路径分解。 这`get_path_multiset`函数通过从每个端点步行到 LCA 并沿途收集值来重建路径上的多组高度。 

收集值后，排序会强制执行算法中描述的规范激活顺序。 然后，模拟应用高度更新规则，跟踪当前高度和剩余功率，并在功率变为负值时立即应用符号翻转规则。 

一个微妙的实现细节是确保在合并路径的两半时 LCA 节点不会被重复计算。 这是通过仅将其包含在集合中一次来处理的`u`边。 

## 工作示例

 考虑一条高度为`[2, 1, 3]`和`P = 5`。 

我们收集并排序价值，给予`[1, 2, 3]`。 

| 步骤| x| cur_h | 电源前| 行动| | 之后的 cur_h 电源后|
 | --- | --- | --- | --- | --- | --- | --- |
 | 1 | 1 | 0 | 5 | 采取 | 1 | 4 |
 | 2 | 2 | 1 | 4 | 采取 | 2 | 2 |
 | 3 | 3 | 2 | 2 | 采取 | 3 | -1 → 1 |

 最终功率为`1`，所以答案是`NO`。 这表明，即使使用了所有值，符号翻转也会阻止完全达到零。 

现在考虑`[1, 1, 1]`和`P = 3`。 

| 步骤| x| cur_h | 电源前| 行动| | 之后的 cur_h 电源后|
 | --- | --- | --- | --- | --- | --- | --- |
 | 1 | 1 | 0 | 3 | 采取 | 1 | 2 |

 这展示了干净的单调累积，没有翻转干扰，从而形成有效的配置。

 ## 边缘情况

 一种边缘情况是路径包含单个节点。 在这种情况下，多重集只有一个值，结果仅取决于通过可能的翻转进行重复减法是否可以达到零。 该算法正确地将其简化为单步模拟，其中减法要么直接为零，要么不为零。 

另一种极端情况是所有高度都相同。 排序不改变顺序，模拟重复减去相同的值，同时保持恒定的激活阈值。 翻转规则永远不会改变可行性，因此结果完全取决于是否`P`以允许精确取消的方式整除。 

当树中的路径高度不平衡时，就会出现第三种边缘情况，这使得简单的路径重建成本高昂。 基于 LCA 的重建可确保每次查询仅访问每个节点恒定的次数，即使对于最坏情况的倾斜树也能保持效率。
