 ## 解决方案
 ## 问题理解

 我们得到一个字符串`s`仅由括号组成，我们需要构造一个新字符串`t`长度正好是两倍`s`，使得`t`形成一个有效的括号序列并且`s`没有出现在里面的任何地方`t`作为连续的子字符串。 有效的括号序列意味着每个左括号都有相应的右括号，并且括号正确嵌套。 例如，`()()`和`(())`是有效的，但是`)(`或者`(()`不是。 

输入由多个测试用例组成，每个测试用例都有一个字符串`s`长度在 2 到 50 之间。约束足够小，每个测​​试用例的 O(n) 或 O(n²) 解决方案是可以接受的。 具体来说，由于所有测试用例的最大字符总数为 50,000，因此我们可以在线性时间内检查或构建大小高达 100 的字符串的操作。 

不明显的边缘情况来自统一的字符串，例如`(((`或者`)))`，以及所有括号都嵌套在一侧的字符串。 一种幼稚的方法可能会尝试重复附加括号，同时避免`s`，但如果不考虑简单的模式（例如交替括号或相同括号的块），它可能会失败。 

例如，如果`s = "()"`，我们需要一个长度为 4 且不包含的有效序列`"()"`。 有效1个`t`是`"(())"`。 粗心的方法可能会尝试`"()()"`，其中包括`s`并达不到要求。 

## 方法

 暴力方法将尝试生成所有有效的长度序列`2n`并检查每一个是否存在`s`。 生成所有长度的序列`2n`复杂度大约为加泰罗尼亚数`C_n`，呈指数增长。 为了`n = 50`，这是一个天文数字，使得暴力破解完全不切实际。 即使是为了`n = 10`，这将超过 1,400 个序列。 

关键的见解是我们不需要探索所有有效的序列。 考虑两个最简单的有效长度序列`2n`：一系列`n`左括号后跟`n`右括号，即`"((...))"`，以及交替序列`"()()()..."`。 保证这两个序列之一不包含任何给定的`s`作为子串，除非`s`要么全部`(`或全部`)`。 在这种情况下`s`是均匀的，交替序列可以避免它，反之亦然。 

因此，问题简化为构造这两个序列之一并检查是否`s`出现在其中。 如果`s`不是的子串`"()" repeated n times`或者`"(" repeated n times then ")" repeated n times"`，我们可以将其输出为`t`。 这很容易实现，每个测试用例的运行时间都是线性的，并且能够很好地满足约束条件。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(C_n * n²) | O(C_n * n²) | O(n) | 太慢了 |
 | 建设性的| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取测试用例的数量并循环遍历每个测试用例。 对于每个字符串`s`,确定其长度`n`。 
2. 生成长度简单的有效序列`2n`。 一个序列是`"(" * n + ")" * n"`，这是一个完全嵌套的序列。 另一个是`"()" * n`，完全交替序列。 
3. 检查是否`s`作为第一个序列中的子字符串出现。 如果没有，则打印`"YES"`和这个序列。 否则，检查第二个序列。 如果`s`不会出现在交替序列中，打印`"YES"`和这个序列。 
4. 如果`s`出现在两个序列中，它必须是所有序列的统一序列`(`或全部`)`长于`1`。 在这种情况下，构造一个有效的`t`这避免了`s`不可能，所以打印`"NO"`。 

为什么有效：有效的长度序列`2n`必须准确地`n`开放和`n`右括号。 两个构建的序列涵盖了最简单的结构：完全嵌套或完全交替。 任意字符串`s`不符合这些结构的将不会显示为子字符串。 该方法保证了正确性，因为子字符串检查确保了`s`被避免并且生成的序列通过构造总是有效的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    s = input().strip()
    n = len(s)
    
    seq1 = '(' * n + ')' * n
    seq2 = '()' * n
    
    if s not in seq1:
        print("YES")
        print(seq1)
    elif s not in seq2:
        print("YES")
        print(seq2)
    else:
        print("NO")
```代码首先读取测试用例的数量。 对于每个测试用例，它生成两个候选序列，检查禁止子串`s`，并打印适当的结果。 使用`.strip()`确保我们不包含输入中的换行符。 支票`s not in seq`保证`t`避免`s`完全。

 ## 边缘情况

 对于`s = "((("`，嵌套序列`"((()))"`包含`s`作为子串。 交替序列`"()()()"`没有。 我们的算法选择交替序列，打印`"YES"`和`"()()()"`，这是正确的。 

为了`s = "()"`，嵌套序列`"((()))"`不包含`s`，因此算法选择它。 总是使用的天真尝试`"()()"`在这里会失败，但我们的检查可以防止这种情况发生。 

这证实了统一序列、小交替序列和嵌套序列都得到了正确处理。
