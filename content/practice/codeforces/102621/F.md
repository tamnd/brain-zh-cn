 ## 解决方案
 ## 问题理解

 我们有通过整数 ID 识别的大猩猩。 如果两只大猩猩的 ID 完全不同，则不能将它们放在一起`K`。 任务是计算在每个选定的配对都兼容的情况下可以形成多少个非空大猩猩组。 

输入描述了大猩猩的总数和固定距离`K`这会造成不兼容。 输出是有效非空选择的数量模`10^9 + 7`。 

重要的观察来自于冲突的结构。 如果大猩猩`x`与冲突`x + K`， 然后`x + K`与冲突`x + 2K`， 等等。 每个 ID 都属于一个数字序列，除以后余数相同`K`。 在每个序列中，相邻元素会发生冲突，而非相邻元素则不会发生冲突。 这意味着冲突图不是任意的。 它是路径的集合。 

约束的设计使得构造每个可能的组是不可能的。 如果有`N`大猩猩，可能的子集数为`2^N`，即使对于中等大小的情况也变得无法使用`N`。 检查所有对的二次方法也可能会失败`N`到达周围`10^5`。 我们需要一个只接触每只大猩猩固定次数的解决方案。 

一些边缘情况很容易被忽略。 

考虑一只大猩猩：```
Input:
1 1
```不存在冲突，并且唯一有效的非空组包含该大猩猩，因此答案是：```
1
```仅计算长度至少为 2 的链的解决方案可能会错误地输出零。 

考虑一个链，其中每隔一个大猩猩都可以被选择：```
Input:
5 1
```冲突链为：```
1 - 2 - 3 - 4 - 5
```答案不是`5`。 有效的选择包括`{1,3,5}`,`{1,3}`,`{2,4}`，以及许多其他人。 总是采用尽可能多的大猩猩的贪婪策略将会失败，因为选择一个顶点会改变可用的邻居。 

考虑多个断开的链：```
Input:
6 3
```链条是：```
1 - 4
2 - 5
3 - 6
```每个链的选择都是独立的，因此最终的答案必须结合所有三个链的可能性。 将整个图视为一条路径会产生错误的计数。 

## 方法

 暴力解决方案可以尝试每个大猩猩子集，并检查其中是否出现任何冲突的对。 检查是正确的，因为当子集不包含冲突图中的边时，子集恰好有效。 然而，有`2^N`子集，即使有快速的有效性检查，一旦`N`很大。 

一个稍微好一点的想法是首先构建冲突图。 蛮力方法之所以有效，是因为图形表示准确地告诉我们哪些对重要，但它仍然探索了太多的可能性。 重要的观察结果是该图的形状非常有限。 

每只大猩猩至多有两个相互冲突的邻居，`id - K`和`id + K`。 不可能有循环，因为反复加减`K`始终向一个方向移动 ID，直到它离开有效范围。 因此，每个连接的组件都是一条简单的链。 

剩下的问题是计算链集合中的独立集合。 对于长度的链条`c`， 让`dp[c]`是选择顶点的方法数。 查看一个端点，我们要么不选择它，要么`dp[c-1]`其余的选择，或者我们选择它并且不能选择它的邻居，留下`dp[c-2]`选择。 这正是斐波那契递推。 

由于组件不会相互影响，因此我们增加了每个链的选择数量。 该产品中包含空选择，因此我们在最后减去一。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^N) | O(2^N) | O(N) | 太慢了 |
 | 最佳| O(N) | O(N) | 已接受 |

 ## 算法演练

 1. 预先计算每个可能长度的链的独立集合的数量。 使用递归`ways[i] = ways[i-1] + ways[i-2]`， 和`ways[0] = 1`和`ways[1] = 2`。 第一个值表示从空链中不选择任何内容，第二个值表示选择单个大猩猩或不选择任何内容。 
2. 将每只大猩猩标记为未访问过。 每个未访问的大猩猩代表冲突图中新的连接组件的开始。 
3. 遍历所有大猩猩 ID。 对于每个未访问过的ID，遵循以下顺序`id, id + K, id + 2K, ...`同时 ID 仍然有效。 计算有多少只大猩猩属于这条链。 
4. 将答案乘以`ways[length]`对于这个链条。 乘法之所以有效，是因为不同链内的选择永远不会相互作用。 
5. 处理完所有链后，减一以删除空分组。 

为什么它有效：

 每个有效分组都是冲突图的独立集合，因为所选的对不能共享边。 冲突图是不相交的链的集合。 对于每个链，递归通过决定是否选择第一个顶点来对每个可能的独立集精确计数一次。 将链计数相乘将来自单独组件的所有独立集合组合起来。 删除空集恰好留下非空有效组。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    n, k = data[0], data[1]

    fib = [0] * (n + 2)
    fib[0] = 1
    fib[1] = 2
    for i in range(2, n + 1):
        fib[i] = (fib[i - 1] + fib[i - 2]) % MOD

    seen = [False] * (n + 1)
    ans = 1

    for i in range(1, n + 1):
        if not seen[i]:
            length = 0
            x = i
            while x <= n:
                seen[x] = True
                length += 1
                x += k
            ans = (ans * fib[length]) % MOD

    print((ans - 1) % MOD)

if __name__ == "__main__":
    solve()
```斐波那契数组存储每个可能的链大小的有效选择数。 初始化与通常的斐波那契序列略有不同，因为空链有一个有效选择，而长度为 1 的链有两种选择：选择大猩猩或不选择它。 

主循环搜索连接的组件。 从未访问过的ID开始，重复添加`K`精确访问该链中的顶点。 不需要单独的图构建，因为邻居是直接由 ID 差异确定的。 

乘法在链计数后立即发生。 这避免了存储组件并保持实现的线性。 

Python 中不存在溢出问题，但每次乘法都会减少模数`10^9 + 7`保持存储的值较小并匹配所需的输出。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(N) | 每个大猩猩在发现其链条时都会被访问一次，斐波那契表也被构建一次。 |
 | 空间| O(N) | 访问的数组和斐波那契表都具有线性大小。 |

 该算法符合预期的约束，因为它从不构建所有冲突边，也从不探索子集。 即使大猩猩的数量很多，每个 ID 也只参与固定量的工作。

 ## 边缘情况

 对于单个大猩猩，该算法会创建一条长度为 1 的链。 斐波那契值为`2`，代表空选择和包含该大猩猩的选择。 最后的减法将删除空选项并留下一个有效组。 

对于长链，例如：```
5 1
```该算法不会贪婪地选择交替的顶点。 它通过递归计算每个可能的独立集。 链条贡献`13`包括空的可能性，最终答案是`12`。 

对于多个链，例如：```
6 3
```遍历开始于`1`,`2`， 和`3`发现三个独立的组件。 每个组件独立贡献，因此总数是三个链计数的乘积，而不是一个较大结构的计数。 

对于以下情况`K`比大猩猩的数量还多，比如：```
4 10
```没有ID有冲突的邻居。 每只大猩猩都会形成一条长度为 1 的链，`2^4`总子集。 删除空子集会产生`15`，与算法的结果匹配。
