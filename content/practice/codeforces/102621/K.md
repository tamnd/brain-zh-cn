 ## 解决方案
 ## 问题理解

 我们有一张长方形的纸，上面有尺寸`a × b`和`n`矩形密封件。 每个密封件在放置时都会形成一个矩形，并且可以旋转 90 度。 我们需要选择两个不同的印章并将它们都放在纸上，不要重叠。 两个矩形必须与纸张边缘对齐，目标是最大化总覆盖面积。 

输入描述了纸张尺寸，后跟每个可用密封件的尺寸。 输出是可同时放置的两个密封件的最大可能面积总和。 如果没有一对密封件可以装配在一起，答案是`0`。 

限制很小：`n`,`a`， 和`b`至多是`100`。 这完全改变了策略。 一个`O(n²)`枚举最多执行大约一万对检查，这对于任何正常的时间限制来说都是很小的。 使用动态编程或几何结构的更复杂的方法会增加不必要的复杂性。 

主要陷阱是由旋转和两个矩形不需要仅放置在角排列中这一事实引起的。 它们可以水平或垂直并排放置。 

例如：```
Input:
2 2 2
1 2
2 1

Output:
4
```忽略旋转的粗心解决方案将拒绝第二个密封，即使旋转它使两个密封完全填充纸张。 

另一种边缘情况是，一个密封件单独安装，但没有第二个密封件可以与其共享空间。```
Input:
3 10 10
6 6
7 7
20 5

Output:
0
```第三个密封件无法使用，前两个密封件也无法组合在一起，因为它们的组合尺寸在每种排列中都超过了纸张。 

最后一个常见错误是仅检查纸张的一个方向。 一个长方形的大小`x × y`可以放置为`y × x`，因此每个候选对必须考虑两种轮换。 

## 方法

 最简单的解决方案是尝试每一对密封件。 对于每一对，我们决定如何旋转每个密封件并测试两个矩形是否可以放置在一起。 如果第一个矩形有尺寸`w1 × h1`第二个有尺寸`w2 × h2`，他们可以以两种基本布局共享论文。 它们可以垂直堆叠，需要`w1`和`w2`以适合纸张宽度并`h1 + h2`以适合纸张高度。 它们也可以并排放置，需要`w1 + w2`以适应宽度和两个高度以适应高度。 

这种蛮力的想法已经足以满足约束条件了。 最多有`100 × 100`对，每对仅检查恒定数量的旋转和布局。 总的工作量只有几万次操作。 

有用的观察是没有隐藏的放置选择。 由于两个密封件都是与纸张对齐的矩形，因此每种有效的排列都可以转换为其中一个矩形位于另一个矩形的正上方、下方、左侧或右侧的排列。 纸张内部的位置并不重要，重要的是宽度和高度的组合是否满足限制。 

由于密封件的数量很少，所以蛮力法起作用。 如果有数十万个密封件，它就会失败，因为检查所有密封对将变成二次方。 在这里，相同的想法是预期的解决方案，因为约束允许它。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 已接受 |
 | 最佳| O(n²) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取所有密封尺寸并保存。 
2. 考虑每对不同的密封件。 只有成对才重要，因为最终答案必须恰好包含两个印章。 
3. 对于每一对，尝试第一个密封件的两个方向和第二个密封件的两个方向。 旋转改变尺寸但不改变面积。 
4. 对于每个方向组合，检查两种可能的布局。 第一种布局将密封件垂直放置，因此它们的宽度必须适合，并且它们的高度必须加起来在纸张高度之内。 第二种布局将它们水平放置，因此它们的高度必须适合，并且它们的宽度必须在纸张宽度之内。 
5. 如果排列有效，则用两个矩形面积的总和更新答案。 

这涵盖了所有可能的放置的原因是两个不重叠的轴对齐矩形始终可以沿水平轴或垂直轴分开。 这种分离与算法检查的两个布局完全对应。 

### 为什么它有效

 该算法检查两个密封件的每种可能的选择以及这些密封件的每种可能的旋转。 对于任何有效的放置，两个矩形必须要么一个矩形完全位于另一个矩形的左侧或右侧，要么一个矩形完全位于另一个矩形的上方或下方。 相应的维度检查是直接执行的，因此每个有效对都会被考虑。 由于每个被认为有效的排列都将其面积贡献到最大，而无效的排列则被拒绝，因此最终的答案正是可能的最佳覆盖面积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, a, b = map(int, input().split())
    seals = [tuple(map(int, input().split())) for _ in range(n)]

    ans = 0

    def check(w1, h1, w2, h2):
        if w1 <= a and w2 <= a and h1 + h2 <= b:
            return True
        if h1 <= b and h2 <= b and w1 + w2 <= a:
            return True
        return False

    for i in range(n):
        for j in range(i + 1, n):
            x1, y1 = seals[i]
            x2, y2 = seals[j]

            for w1, h1 in ((x1, y1), (y1, x1)):
                for w2, h2 in ((x2, y2), (y2, x2)):
                    if check(w1, h1, w2, h2):
                        ans = max(ans, x1 * y1 + x2 * y2)

    print(ans)

if __name__ == "__main__":
    solve()
```嵌套循环将每个无序对恰好枚举一次。 使用`i + 1`避免将密封件与自身进行比较，并避免以相反的顺序重复同一对密封件。 

旋转环为每个密封件生成两个可能的方向。 面积计算使用原始尺寸，因为旋转矩形不会改变其面积。 

这`check`函数包含完整的几何条件。 第一个条件代表垂直堆叠，而第二个条件代表水平放置。 将这些检查分开可以避免交换宽度和高度时出现错误。 

对于这些约束，Python 整数不会溢出，因为最大可能面积仅为`100 × 100 + 100 × 100`。

 ## 边缘情况

 当需要旋转时，算法显式地尝试两个方向。 对于输入：```
2 2 2
1 2
2 1
```第二个封印变成`1 × 2`旋转后，让这对占据整张纸。 仅检查给定方向的解决方案将错误地输出`0`。 

当没有配对适合时，每个方向组合都会失败。 为了：```
3 10 10
6 6
7 7
20 5
```前两个密封件由于其宽度或高度之和太大而无法布置，并且无法使用第三个密封件。 答案依然存在`0`。 

当尺寸恰好触及边界时，不等式必须允许相等。 为了：```
2 5 5
5 2
2 5
```密封件可以并排放置或堆叠放置，不留任何未使用的空间。 该算法使用`<=`，所以它正确返回`20`而不是拒绝安排。
