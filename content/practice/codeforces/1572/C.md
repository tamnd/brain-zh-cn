 ## 解决方案
 ## 问题理解

 我们有一个由颜色数组表示的一维图像。 单个操作选择一个连接的单色段并将整个段重新绘制为任何颜色。 

连接性定义有点不寻常。 如果两个相同颜色的位置之间的每个位置也具有相同的颜色，则它们被连接。 在一维数组中，这仅意味着相等值的最大连续块。 一项操作选择一个这样的块并更改整个块的颜色。 

目标是使用最少的操作数使整个数组成为单一颜色。 

直接模拟视点具有误导性，因为重新绘制一个块可能会将其与目标颜色的相邻块合并，从而创建更大的连接组件，稍后可以将其重新绘制在一起。 

所有测试用例的总长度最多为 3000。这是关键约束。 区间上的三次动态规划解是可行的，因为$3000^3$全局范围太大，但每种颜色最多出现 20 次的特殊限制大大减少了有意义的过渡次数。 预期的解决方案利用此限制来避免考虑所有间隔分割。 

最常见的错误是根据坐标压缩后的连续块来思考。 这会丢失重要信息。 

考虑：```
1 2 1
```答案是1。将中间的块从2重新绘制为1，整个数组变成颜色1。 

基于压缩的方法看到三个块，可能会错误地得出需要两次合并的结论。 

另一个微妙的情况是：```
1 2 3 2 1
```答案是2。 

首先将 3 重新绘制为 2：```
1 2 2 2 1
```然后将中央的 2 块重新绘制为 1：```
1 1 1 1 1
```总是扩展最大颜色块的贪婪策略会失败，因为最佳序列取决于在区间两端匹配相同的颜色。 

第三个陷阱是假设最终颜色必须已经存在于区间内的任何地方。 

为了：```
1 2 1 4 2
```答案是3。最佳过程在最终合并之前重复创建更大的区域。 局部决策并不能揭示全局最优值。 

## 方法

 强力方法会将每个图像配置视为一个状态，并对所有可到达的重绘运行 BFS。 该操作很容易模拟：选择一个块并重新着色。 此搜索是正确的，因为每个操作都有单位成本。 

问题在于状态空间。 即使对于适度的值$n$，可能的着色数量呈指数增长。 不可能探索所有可到达的配置。 

关键的观察结果是，重画的行为与间隔合并问题（例如奇怪的打印机）非常相似。 如果两个相同的颜色出现在位置$i$和$j$，我们最终可以使整个区间$[i,j]$合并为单个区域，无需为两个端点单独付费。 

这表明有一个区间 DP。 

让$dp[l][r]$表示创建子数组所需的最少操作$a_l \dots a_r$变成单一颜色。 

假设我们想要位置$l$参与最终的合并颜色。 一种选择是重新喷漆$a_l$独立解决其余问题。 只要有一个位置，就会出现另一种可能性$k$在与颜色相同的区间内$a_l$。 然后是端点$l$和$k$可以合并到同一个最终组件中，减少操作次数。 

每种颜色最多出现 20 次的限制使其变得实用。 对于每个左端点，只有$O(20)$需要考虑的匹配职位。 我们不会尝试每个分割点，而是仅通过相同颜色的出现进行过渡。 

这将间隔 DP 从潜在的立方过渡结构减小到大致$O(n^2 \cdot 20)$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力状态搜索 | 指数| 指数| 太慢了 |
 | 具有等色过渡的间隔 DP |$O(n^2 \cdot 20)$|$O(n^2)$| 已接受 |

 ## 算法演练

 让数组从0开始索引。 

定义$dp[l][r]$作为间隔所需的最少操作数$[l,r]$单色。 

答案将是$dp[0][n-1]$。 

### 复发

 如果$l=r$，区间已经由一种颜色组成。$$dp[l][l]=0$$对于较长的间隔，首先隔离最左边的元素。$$dp[l][r]=1+dp[l+1][r]$$这对应于在位置重新绘制颜色$l$分别求解，然后求解剩余的区间。 

现在考虑每个位置$k$和$$l<k\le r,\qquad a_k=a_l$$如果持仓$l$和$k$颜色相同，则可以参与同一个最终合并区域。 

间隔$(l+1,k-1)$必须首先制成单色，以便$l$和$k$在合并过程中变得相邻。 之后，后缀$[k,r]$独立解决。 

这产生$$dp[l][r] = \min \left( dp[l][r], \, dp[l+1][k-1] + dp[k][r] \right)$$其中空区间贡献 0。 

### 高效枚举

 对于每种颜色，存储它出现的位置列表。 

处理状态时$(l,r)$，仅迭代出现的颜色$a_l$。 因为每种颜色最多出现 20 次，所以每个状态最多执行 20 次这样的转换。 

### 填写订单

 通过增加长度来处理间隔。 

计算时$dp[l][r]$，每个所需的子区间都严格较短，因此其值是已知的。 

### 算法演练

 1. 为每种颜色建立一个位置列表。 
2. 初始化$dp[l][l]=0$对于所有指数。 
3. 处理间隔长度从 2 到$n$。 
4. 对于每个间隔$[l,r]$，从过渡开始$$dp[l][r]=1+dp[l+1][r]$$处理位置$l$独立。 
5. 迭代所有出现的情况$k$颜色的$a_l$满意的$l<k\le r$。 
6. 计算$$cost = dp[l+1][k-1] + dp[k][r]$$其中第一项为 0，当$k=l+1$。 
7. 更新$$dp[l][r]=\min(dp[l][r],cost)$$8.所有区间处理完毕后，输出$dp[0][n-1]$。 

### 为什么它有效

 递归穷尽了最左边位置的所有最佳可能性。 

在任意区间的最优解中$[l,r]$，任一位置$l$与其颜色的每次出现分开处理，给出过渡$1+dp[l+1][r]$，或者最终与第一个匹配位置合并$k$这属于它的最终单色分量。 

什么时候$l$与这样的合并$k$，它们之间的每个元素都必须已经被吸收到兼容区域中。 这样做的成本正是$dp[l+1][k-1]$。 后$l$和$k$是相连的，里面剩下的工作$[k,r]$是独立的并且有成本$dp[k][r]$。 

每个最佳解决方案都属于这些情况之一，并且每个转换都对应于可实现的操作序列。 通过对间隔长度进行归纳，递归计算出每个间隔的真正最优值。 

## Python 解决方案```python
import sys
from collections import defaultdict

input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        pos = defaultdict(list)
        for i, x in enumerate(a):
            pos[x].append(i)

        dp = [[0] * n for _ in range(n)]

        for length in range(2, n + 1):
            for l in range(n - length + 1):
                r = l + length - 1

                dp[l][r] = 1 + dp[l + 1][r]

                for k in pos[a[l]]:
                    if k <= l:
                        continue
                    if k > r:
                        break

                    left_cost = 0
                    if l + 1 <= k - 1:
                        left_cost = dp[l + 1][k - 1]

                    dp[l][r] = min(
                        dp[l][r],
                        left_cost + dp[k][r]
                    )

        ans.append(str(dp[0][n - 1]))

    sys.stdout.write("\n".join(ans))

solve()
```DP 表存储每个区间的答案。 通过增加长度来处理间隔可保证每个引用的子问题都已被计算。 

初始化$dp[l][l]=0$是自动获得的，因为该表以零开头。 

过渡`1 + dp[l + 1][r]`对应于单独处理最左边的元素。 

出现列表是关键的优化。 一个简单的实现会测试每个可能的分割点$k$，生产$O(n^3)$过渡。 这里我们只访问与左端点颜色相同的位置。 由于每种颜色最多出现 20 次，因此每个状态的转换次数保持有限。 

空区间的情况需要小心。 什么时候$k=l+1$, 区间$[l+1,k-1]$不包含任何元素，因此其贡献必定为零。 

## 工作示例

 ### 示例 1

 输入：```
1 2 3 2 1
```主要 DP 状态：

 | 间隔 | 价值|
 | --- | --- |
 | dp[2][2] | dp[2][2] | 0 |
 | dp[1][3] | dp[1][3] | 1 |
 | dp[0][4] | dp[0][4] | 2 |

 对于完整间隔：

 | 步骤| 过渡 | 成本|
 | --- | --- | --- |
 | 初始| 1 + dp[1][4] | dp[1][4] | 3 |
 | 匹配 k=4 | dp[1][3] + dp[4][4] | dp[1][3] + dp[4][4] 1 + 0 = 1 |
 | 最终 dp[0][4] | 1+最佳转场效果| 2 |

 两端的颜色相同使得间隔比单独处理每个端点更容易崩溃。 

### 示例 2

 输入：```
1 1 2 2
```相关州：

 | 间隔 | 价值|
 | --- | --- |
 | dp[0][1] | dp[0][1] | 0 |
 | dp[2][3] | dp[2][3] | 0 |
 | dp[0][3] | dp[0][3] | 1 |

 对于整个区间：

 | 步骤| 过渡 | 成本|
 | --- | --- | --- |
 | 初始| 1 + dp[1][3] | dp[1][3] | 2 |
 | 匹配 k=1 | dp[1][0] + dp[1][3] | dp[1][0] + dp[1][3] 1 |
 | 决赛| 1 | |

 前导的两个 1 已经形成一个合并组件，因此整个图像只需要一次重绘操作。

 ## 边缘情况

 考虑：```
1
1
5
```间隔的长度为一。 DP 基本情况给出`dp[0][0] = 0`。 无需重新绘制，因为图像已经具有单色。 

考虑：```
1
3
1 2 1
```对于间隔`[0,2]`，初始转换给出$$1 + dp[1][2] = 2.$$位置 2 处的匹配出现产生$$dp[1][1] + dp[2][2] = 0.$$这会将状态值减少到 1。算法正确地识别出重新绘制中间元素一次就足够了。 

考虑：```
1
5
1 2 3 2 1
```端点共享相同的颜色。 递归显式检查所有后来出现的颜色 1，包括最终位置。 通过该匹配端点的转换捕获最佳合并序列并产生答案 2。 

考虑：```
1
5
1 1 1 1 1
```每个间隔都会重复查找相同颜色的匹配出现。 DP 值始终保持为零。 对色块进行计数的解决方案会错误地报告一次操作，但间隔 DP 会正确返回零，因为不需要重新绘制。
