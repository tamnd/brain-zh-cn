 ## 解决方案
 ## 问题理解

 我们得到一个 0 和 1 的序列以及一个可以将任意三个连续元素更改为这三个元素的 XOR 的操作。 任务是确定我们是否可以使用最多 n 个操作将整个序列变成全 0，如果可以，则提供完成此操作的操作序列。 每个运算恰好影响三个连续位置，并且 XOR 运算保证应用它的结果仅取决于三元组中 1 的数量的奇偶性。 

输入提供多个测试用例。 每个序列最多可以包含 200,000 个元素，并且所有测试用例的元素总数不超过 200,000 个。 这意味着任何 n 的二次解都会太慢； 我们需要一种与序列长度呈线性或接近线性的方法。 我们还需要处理序列已经全为零的边缘情况、1 和 0 交替的序列、或者 1 的数量为奇数的序列，从而无法将它们全部清除。 

一个微妙之处在于，对总和为奇数的三元组应用 XOR 运算会将所有三个翻转为 1，而两个或零的总和会产生 0。如果不考虑奇偶校验或模式对齐而从左侧贪婪地应用运算，则可能会导致某些操作无法访问的循环，例如在像这样的序列中`[1, 0, 0, 1]`，不能减少到全零。 

## 方法

 最直接的方法是蛮力：重复扫描数组中至少包含一个 1 的三元组，应用该操作，然后继续，直到数组变为全零或无法取得进一步的进展。 原则上这是正确的，因为任何解决方案都存在，但如果我们重复影响重叠的三元组，在最坏的情况下可能需要 O(n^2) 次操作。 给定 n 可以是 2*10^5，这太慢了。 

关键的见解是 XOR 运算既可交换又可结合，并且仅取决于三元组之和的奇偶性。 这使我们能够通过定位第一个 1 并以贪婪的方式（从左到右或从右到左）传播一系列操作来构建解决方案。 具体来说，如果总数为偶数，则始终存在将它们全部清除的操作序列。 该问题简化为通过扫描数组并在允许有效三元组的位置遇到 1 时应用该操作来构建操作序列。 如果总数是奇数并且它们没有对齐，这是不可能的。 

为了处理分散或未对齐的序列，我们可以尝试两次传递：一次从最左边的 1 开始，另一次从最右边的 1 开始。如果任一传递成功产生全零，我们就可以返回该序列。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 贪婪左/右传球| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取测试用例数t。 对于每个测试用例，读取 n 和长度为 n 的数组 a。 初始化一个空列表`operations`存储应用操作的索引。 
2. 检查数组中总奇偶校验数。 如果元素总和模 2 为奇数，则立即输出“NO”，因为不可能将数组变成全零。 
3. 否则，尝试从左到右的贪婪传递。 对于从 0 到 n-3 的每个索引 i，如果`a[i]`为 1，在索引 i 处应用 XOR 运算，转动`a[i], a[i+1], a[i+2]`到他们的异或。 将 i+1 附加到`operations`记录从 1 开始的索引。 这确保了最左边的 1 被消除，而不会在左侧重新引入新的 1。 
4. 从左到右遍历后，检查数组是否全为零。 如果是，则输出“YES”以及记录的操作。 
5. 如果从左到右传递失败，则尝试贪婪的从右到左传递。 从索引 n-3 开始一直到 0，每当`a[i+2]`是 1。这捕获了第一个 1 靠近右端且无法使用从左到右移动向前传播的情况。 
6. 如果两次都失败，则输出“NO”。 
7. 确保操作次数不超过n。 贪心过程保证了这一点，因为每个操作都会消除至少一个 1，而不会向左（或右）引入新的未处理的 1。 

不变的是，每个操作都会以最终覆盖所有位置的方式减少连续操作的数量。 XOR结构确保偶数奇偶校验的配置不可达。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total = sum(a)
        if total % 2 != 0:
            print("NO")
            continue
        
        operations = []
        arr = a[:]
        # left-to-right greedy pass
        for i in range(n-2):
            if arr[i] == 1:
                xor_val = arr[i] ^ arr[i+1] ^ arr[i+2]
                arr[i] = arr[i+1] = arr[i+2] = xor_val
                operations.append(i+1)
        
        if all(x == 0 for x in arr):
            print("YES")
            print(len(operations))
            if operations:
                print(*operations)
            else:
                print()
            continue
        
        # right-to-left greedy pass
        operations = []
        arr = a[:]
        for i in range(n-3, -1, -1):
            if arr[i+2] == 1:
                xor_val = arr[i] ^ arr[i+1] ^ arr[i+2]
                arr[i] = arr[i+1] = arr[i+2] = xor_val
                operations.append(i+1)
        
        if all(x == 0 for x in arr):
            print("YES")
            print(len(operations))
            if operations:
                print(*operations)
            else:
                print()
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```代码首先检查奇偶校验以快速消除不可能的情况。 然后，它执行从左到右和从右到左的两次传递，每当在三元组的起始位置检测到 1 时就应用操作。 我们为每次传递使用数组的副本以避免副作用。 每个操作都以从 1 开始的索引存储。 全零检查确保我们只输出成功的序列。
