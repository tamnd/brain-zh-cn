 ## 解决方案
 ## 问题理解

 我们有两个相同大小的二进制网格。 目标是确定是否可以使用无限数量的特定切换操作将一个网格转换为另一个网格。 每个操作都会选择一个单元格作为中心，并将该单元格的值与其四个对角邻居中的三个一起翻转，形成四种可能的“Y 形”模式之一，具体取决于排除哪个对角角。 

该操作在 3×3 意义上是局部的，但它总是涉及位于相同棋盘颜色的四个单元格，因为对角移动保留了行加列的奇偶性。 这立即将网格分成两个独立的系统：偶校验为 i + j 的单元和奇校验的单元。 操作永远不会混合这两个组。 

因此，该任务相当于检查通过对两个矩阵的相应单元进行异或而获得的差异网格是否可以表示为这些 Y 形切换的组合。 

这些约束意味着网格可以很大，所有测试用例最多可达 1000×1000。 任何尝试模拟操作或构建显式转换的解决方案都太慢，因为即使是单个操作计数在最坏的情况下也可能呈二次方增长。 该解决方案必须将问题简化为每个测试用例的线性时间检查。 

当即使局部模式看起来兼容但无法进行转换时，就会出现微妙的边缘情况。 例如，在 3×3 网格中，单独翻转单个单元是不可能的，因为每个操作都会同时影响四个单元。 a 和 b 之间只有一个单元不同的配置始终是无效的，即使在本地看起来可以修复。 

另一种边缘情况是网格除了靠近边界之外几乎相同。 由于操作要求所有涉及的邻居都存在，因此边界单元降低了灵活性，但它们不会改变控制可解性的全局不变量。 

## 方法

 暴力方法会尝试模拟所有可能的 Y 操作序列。 每次操作都会改变四个单元，可能的中心数量为 O(nm)，因此即使是浅层搜索也很快会爆炸。 即使考虑网格状态上的 BFS 也是不可能的，因为状态空间是 2^(nm)。 

关键的观察结果是我们正在 GF(2) 上的线性系统中工作。 每个操作都是一个恰好翻转四个位置的向量。 任何操作序列都对应于对一组此类向量进行异或。 问题是目标差异网格是否位于这些向量的范围内。 

一旦以这种方式构建，结构就变得更加清晰：每个操作都保留所有受影响单元的奇偶校验（mod 2 sum）。 由于每次操作都会翻转四个单元，因此它始终保留模 2 的 1 总数。这立即给出了一个必要条件：不同单元的总数必须是偶数。 

然而，由于操作仅限于对角邻域，因此网格根据 (i + j) % 2 分成两个独立的组件。每个操作完全保留在一个组件内，因此奇偶校验约束必须分别适用于两种棋盘颜色。 

剩下的就是显示充分性：在每个奇偶校验类中，操作模式足够丰富，可以生成具有偶校验的任何配置。 这可以通过建设性的消除论证来建立：使用适当集中的操作，我们可以通过网格逐行传播校正，始终将剩余的差异向前推进，直到只剩下一个微不足道的配置。 

由于指数状态增长，蛮力会失败，而线性代数视图将一切简化为检查简单的不变量。

 ## 算法演练

 我们使用差异网格 d，其中 d[i][j] = a[i][j] XOR b[i][j]。 

1. 根据 i + j 的奇偶校验将所有单元分成两组。 一组包含所有偶校验单元，另一组包含奇校验单元。 这种分离是有效的，因为每个操作只涉及一个奇偶校验的单元。 
2. 对于每个奇偶校验组，计算该组中 1 的总数。 这代表该独立系统中有多少不匹配的单元需要校正。 
3. 检查两个总数是否相等。 如果任一组的不匹配数为奇数，则立即得出结论：转换是不可能的。 
4. 如果双方的计数均为偶数，则得出变换总是可能的结论。 不需要进一步的结构检查。 

我们只检查奇偶校验的原因是操作集在每个奇偶校验分量上形成一个生成系统，唯一剩下的不变性是奇偶校验的数量。 

### 为什么它有效

 每个操作恰好翻转四个单元，因此它永远不会改变奇偶校验类内的单元数量的奇偶校验。 这使得奇偶校验成为一个硬不变量。 

同时，操作足够灵活，可以在同一奇偶校验类别内跨网格移动差异。 任何具有偶奇偶校验的配置都可以分解为局部 4 单元切换，因为这些切换跨越仅受奇偶校验不变量约束的完整向量空间。 这意味着除了平价之外不存在隐藏的结构性障碍。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        
        a = []
        for _ in range(n):
            a.append(list(map(int, input().split())))
        
        b = []
        for _ in range(n):
            b.append(list(map(int, input().split())))
        
        parity_count = [0, 0]
        
        for i in range(n):
            for j in range(m):
                if a[i][j] != b[i][j]:
                    parity_count[(i + j) & 1] += 1
        
        if parity_count[0] % 2 == 0 and parity_count[1] % 2 == 0:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```该实现直接计算失配网格并分别聚合偶数和奇数单元格的计数。 关键细节是使用 (i + j) & 1 将网格划分为独立的系统。 

正确性取决于每个操作恰好翻转同一奇偶校验类中的四个单元的不变性，这保证了每个类内奇偶校验的保留。

 ## 边缘情况

 关键的边缘情况是 a 和 b 之间只有一个单元格不同。 在这种情况下，算法会计算一个奇偶校验类别中的单个不匹配，这会立即使奇偶校验检查失败。 由于每个操作都会翻转四个单元格，因此无法隔离单个校正，并且算法会正确地拒绝它。 

另一种情况是不匹配均匀分布但仅限于一个奇偶校验类别。 即使模式看起来很复杂，只要计数是偶数，算法就会接受它。 例如，分散在网格上的四个不匹配仍然可以通过，并且始终可以构建一系列 Y 操作来消除它们。 

最后一个微妙的情况是完全没有不匹配的大网格。 两个奇偶校验计数器均为零，即偶数，因此算法正确返回 YES，而无需尝试任何操作。
