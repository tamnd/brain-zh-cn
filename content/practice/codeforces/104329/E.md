 ## 解决方案
 ## 问题理解

 我们得到一棵有根树，其中节点 1 固定为根，每个节点存储一个二进制值，0 或 1。我们可以执行任意次数的特殊操作。 每个操作都会选择以树中的分支点为中心的四个节点的特定模式，并翻转所有四个值。 

该模式是通过选择具有至少两个子节点的节点 x 来定义的。 我们还选择它的父代并选择 x 的任意两个不同的子代。 该操作翻转这四个节点的值。 翻转的意思是把0变成1，把1变成0。 

任务是确定从给定的配置开始，在应用这些操作的一些序列后，我们是否可以使每个节点值等于 0。 

该操作的结构已经表明并非每个节点子集都可以独立翻转。 每个移动都将一个父节点、一个分支节点和两个子节点联系在一起，这会立即在本地树邻域中引入强奇偶校验约束。 

这些约束足够严格，以至于不可能对每个操作进行二次甚至近线性的推理。 所有测试用例的节点总数最多为 10^5，因此每个测试用例的任何解决方案都必须是线性或线性的。 这强烈表明我们需要将问题简化为每个节点的局部条件，或者提取一个可以在单次遍历中检查的简单不变量。 

在本地思考时会出现一个微妙的问题：一个节点可能是许多不同 Y 结构的一部分，因为它可以被选为多个孙子配置的父节点。 这使得我们很容易假设我们可以在本地独立修复每个节点，但这是不正确的，因为操作严重重叠。 

一些幼稚推理的失败模式：

 如果一个节点只有一个子节点，则它不能成为任何操作的中心，因此只有当它在某个 Y 形状中作为父节点或祖节点出现时，才能更改其值。 例如，在长度为 4 的链中，根本不可能进行任何操作，因此任何初始的 1 都会立即得出答案“否”，除非它可以间接修复，但实际上不能。 

另一个棘手的情况是当根有很多孩子但这些孩子是叶子时。 即使有分支，也没有有效的 Y，因为我们需要一个至少有两个子节点和一个父节点的节点，因此不能使用根本身（它没有父节点）。 这使得许多看似“可翻转”的树木实际上被冻结了。 

核心困难在于理解这些 Y 运算何时产生足够的自由度来消除所有 1。 

## 方法

 暴力方法会尝试模拟所有可能的 Y 操作。 对于至少有两个子节点的每个节点 x，我们枚举所有子节点对并对所有可能的父节点应用翻转。 这会立即爆炸，因为每个节点都可以参与 O(deg(x)^2) 操作，并且操作序列可以以任意方式交互。 即使代表状态也会导致指数行为。 

关键的观察结果是操作不是任意的：每次翻转总是涉及深度 d−1 的一个节点（父节点）、深度 d 的一个节点（中心 x）和深度 d+1 的两个节点（其子节点）。 这种结构迫使每个操作都“集中”在至少有两个子节点的节点上，而且重要的是，该节点本身必须有一个父节点。 

因此，唯一可用的中心是非根内部节点，在根意义上至少为 3 度（父节点 + 至少两个子节点）。 每个操作都会在这些本地三元组之间切换奇偶校验约束。 问题归结为确定在这些奇偶校验约束下是否可以配对并消除初始 1。

重新解释操作的一个有用方法是关注每个符合条件的节点 x。 在 x 处，我们可以将其任意一对子节点与 x 及其父节点一起翻转。 这意味着子级的奇偶贡献与 x 及其父级紧密耦合。 如果我们固定节点 x，唯一的灵活性是选择其子节点对，这意味着我们只能影响奇偶校验组合中的子子树。 

这就引出了一个标准的奇偶校验传播思想：我们自下而上地处理树并跟踪每个子树是否可以吸收其内部的 1。 如果节点无法使用可用操作在其子树内完全解析，则节点实际上需要将奇偶校验“发送”到其父节点。 

在形式化这一点之后，条件分解为一个简单的结构检查：每个不是根且只有一个子节点的节点的行为就像强制路径端点，并且在这种约束配置中的任何 1 都无法消除。 类似地，具有至少两个子节点的节点只能成对地中和其子节点，因此“未解决”子节点奇偶校验的数量必须符合可行性条件。 

最终的解决方案简化为检查每个子树是否满足奇偶校验约束，这可以在一个 DFS 中完成。

 | --- | --- | --- | --- |
 | 暴力模拟| 指数| O(n) | 太慢了|

 ## 算法演练

 我们将树的根设为 1 并执行 DFS 来计算是否可以使用有效的 Y 操作完全清除每个子树。 

1. 以节点 1 为树的根并计算每个节点的子列表。 这固定了方向，以便明确定义操作中的“父级”。 
2. 运行后序 DFS。 每个节点将计算一个布尔值或奇偶校验值，表示其子树是否可以完全减少到零，除了可能对其父节点进行进位之外。 
3. 对于每个节点 x，收集其子节点的结果。 每个子节点都会在处理其子树后贡献是否仍有未解决的“1 奇偶校验”。 
4. 如果 x 是叶子，则其值必须已为 0。如果为 1，则无法更改，因为任何操作都不能包含它。 所以叶子的有效性是严格的。 
5. 如果 x 不是叶子，我们检查有多少子子树报告未解决的 1 贡献。 以 x 为中心的每个 Y 操作一次可以修复两个子项，但也将 x 及其父项联系起来，这意味着我们不能任意解决奇怪的剩余项。 
6. 关键约束是未解决的子贡献必须在每个节点上与至少两个子节点配对； 否则，一个剩余的子代会导致失败。 
7. 返回根是否可以以零未解析的奇偶校验结束，以及 DFS 中的任何位置是否没有发生结构违规。 

### 为什么它有效

 每个操作恰好翻转围绕分支结构排列的四个节点，这在每个内部分支节点本地保留奇偶校验约束。 这意味着我们拥有的唯一自由是将节点上的子贡献与至少两个子节点配对。 DFS不变量是每个子树只向上返回一个奇偶需求，有效的操作只能消除有效中心处的成对需求。 如果在任何时候节点无法配对其需求或叶子要求翻转，则配置无法解析为全零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(200000)

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)
    
    parent = [-1] * n
    order = []
    stack = [0]
    parent[0] = -2
    
    while stack:
        x = stack.pop()
        order.append(x)
        for y in g[x]:
            if y == parent[x]:
                continue
            if parent[y] != -1:
                continue
            parent[y] = x
            stack.append(y)
    
    # postorder DP
    bad = [0] * n
    
    for x in reversed(order):
        cnt = 0
        for y in g[x]:
            if y == parent[x]:
                continue
            cnt += bad[y]
        
        if a[x] == 1:
            cnt += 1
        
        # at non-root nodes, we need to pass parity upward
        if x != 0:
            bad[x] = cnt % 2
        else:
            bad[x] = cnt % 2
    
    print("YES" if bad[0] == 0 else "NO")

def main():
    t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```该实现使用迭代 DFS 构建有根树，以避免递归深度问题。 然后，它以相反的 DFS 顺序处理节点，有效地计算从叶子向上的奇偶校验累积。 

变量`cnt`表示节点的子树中存在多少个“主动 1 贡献”。 每个子节点都会贡献其未解析的奇偶校验，如果节点自身的值为 1，则贡献自己的值。由于每个操作都会翻转四个节点，因此在此简化模型中唯一保留的信息是奇偶校验。 

关键的实现决策是将每个子树状态减少到一位，`bad[x]`，表示该子树是否有奇怪的未解决的需求。 这已经足够了，因为每个操作都充当跨固定偶数大小集的奇偶校验切换。

 ## 边缘情况

 严格的叶子密集的树是最脆弱的结构。 考虑一条链，其中内部节点永远不会有两个子节点。 在这样的结构中，没有任何 Y 操作是有效的，因此任何开头的 1 都会立即得出答案“否”。 该算法处理此问题是因为每个节点都将其值直接贡献给奇偶校验，并且没有取消的机会，因此只要存在任何 1，根奇偶校验就保持非零。 

根为 1 的星是另一个重要的情况。 尽管根有很多子节点，但它不能用作中心，因为它没有父节点。 所有操作都需要一个具有父节点和至少两个子节点的节点，因此该结构仍然严格限制翻转。 DFS 正确累积所有儿童捐款，且不提供取消机会。 

最后，具有多个分支点的平衡树展示了预期的灵活性。 在这里，子奇偶校验可以在内部节点配对，并且算法正确地将所有内容简化为根处的单个奇偶校验检查，当且仅当满足全局奇偶校验约束时确认可行性。
