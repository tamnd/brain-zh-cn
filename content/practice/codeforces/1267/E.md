 ## 解决方案
 ## 问题理解

 我们有一个有多个候选人和多个投票站的投票系统。 每个电台都会报告每位候选人获得的选票数。 候选人的最终得分是其在所有仍然有效的电台的投票总和。 

最后一位是代表反对派的特殊候选人。 执政党有权宣布整个投票站无效。 一旦一些电台被删除，剩余的总票数将决定获胜者。 如果反对派候选人的总票数严格超过其他候选人的总票数，则该反对派候选人被视为当选。 

任务是删除尽可能少的站点，以便在删除后，反对派候选人不会严格领先于其他所有人。 同样，我们希望丢弃的站数最少，以便至少一名其他候选人的最终得分大于或等于对手。 

限制很小，最多有 100 名候选人和 100 个投票站。 这立即排除了对站点子集的任何指数搜索，因为最多可以有 2^100 个子集。 站点数量的二次或三次解是可以接受的，但任何涉及完整子集枚举的解都是不可接受的。 

当贪婪地推理时，会出现一个微妙的点：删除反对派支持最多的电台似乎很自然，但这是不正确的。 一个帮助反对派的电视台也可能大力支持另一位候选人，而删除它实际上可能比反对派更伤害该候选人。 该决定必须考虑_相对优势_，而不是绝对反对票。 

另一个极端情况来自领带。 条件很严格：反对派不得严格大于所有其他反对派。 如果反对派与某人有联系，那就已经阻止了选举。 许多不正确的贪婪策略错误地执行了比所需条件更强的条件。 

## 方法

 暴力方法会尝试投票站的每个子集，计算所有候选人的总数，并检查反对派是否不是严格意义上的最大值。 这是正确的，因为它评估了所有可能的结果，但这是不可行的，因为有 2^m 个子集，并且每个评估成本为 O(nm)，从而导致天文数字的运行时间。 

关键的见解是扭转观点。 我们可以考虑保留站点，而不是选择删除站点。 如果我们保留一部分电台，反对派相对于其他候选人的优势仅取决于他们的选票与每个竞争对手的选票之间的总差。 

确定竞争对手候选人 j。 在每个站 i 中，定义一个值：

 di = a[i][n] - a[i][j]

 这衡量了相对于候选人 j 而言，保留 i 站对反对派有多大帮助。 如果 di 较大且为正值，则保持该位置会加强反对派对 j 的领先优势。 如果 di 为负，则该站实际上帮助 j 缩小或扭转了差距。 

为了确保对手不会击败 j，我们希望保持站的 di 总和为非正数。 如果变为正数，则反对派领先于 j。 

现在问题就变成了：对于每个竞争对手j，我们需要选择最少数量的要移除的站点，使得剩余站点的di之和≤0。这相当于选择要保留的站点，以避免给对手太多的相对增益。 

对于固定的 j，最优策略是贪婪的：按 di 以降序对站点进行排序。 我们最初假设我们保留所有站点，然后我们首先逐步删除正 di 最大的站点，因为这些站点最能增加对手的优势。 一旦剩余金额变为非正数，我们就停止。 

我们对每个候选者 j 重复这个过程并取最好的结果。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^m · n · m) | O(2^m · n · m) | O(米) | 太慢了 |
 | 每个候选者的贪婪移除 | O(n·m log m) | O(n·m log m) | O(米) | 已接受 |

 ## 算法演练

 我们迭代每个非反对派候选人 j 并计算必须删除多少个站才能确保反对派不会击败 j。 

1. 通过对 di = a[i][n] - a[i][j] 求和，计算所有站点中反对派相对于候选人 j 的总优势。 这代表了反对党在进行任何罢免之前的领先程度。 
2. 对于每个站 i，计算 di。 按 di 降序对电台进行排序。 具有大正 di 的电台是最有害的，因为它们最能增加反对派的优势。 
3. 从包含的所有站开始并维持当前的 di 总和。 如果该总和已经 ≤ 0，则不需要对该候选进行删除。 
4. 否则，重复删除di最大的站。 删除一个站点后，从运行总和中减去其 di。 每次移除都会尽可能地减少对手在该步骤中的优势。 
5. 一旦运行总和变为 ≤ 0，则停止。记录删除了多少个站以及删除了哪些站。 
6. 对从 1 到 n-1 的所有候选 j 重复此操作，并在所有 j 中取最小移除集。 

输出是与最佳候选 j 相对应的已移除站的集合。 

### 为什么它有效

 对于固定候选人 j，值 di 衡量对反对派领先 j 的贡献。 任何有效的解决方案必须确保保留站的 di 总和为非正数。 删除一个站点相当于从总数中减去它的 di。 

选择首先删除具有最大 di 的站点是最佳选择，因为每次删除都会使每个操作的总和产生最大可能的减少。 任何删除较小 di 同时保留较大 di 的最佳解决方案都将严格更差或等效，但在以相同删除次数减少总和方面永远不会更好。 

因此，贪婪过程产生将总和推至非正数所需的最小移除数，这恰好对应于防止反对派严格击败候选者 j。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = [list(map(int, input().split())) for _ in range(m)]

    best_k = m + 1
    best_remove = None

    for j in range(n - 1):
        diffs = []
        total = 0

        for i in range(m):
            d = a[i][n - 1] - a[i][j]
            diffs.append((d, i))
            total += d

        diffs.sort(reverse=True)

        removed = []
        cur = total

        for d, i in diffs:
            if cur <= 0:
                break
            cur -= d
            removed.append(i + 1)

        if len(removed) < best_k:
            best_k = len(removed)
            best_remove = removed

    print(best_k)
    print(*best_remove)

if __name__ == "__main__":
    solve()
```该代码首先读取所有站点结果。 对于除反对派之外的每个候选人，它都会构建针对该候选人的每站优势差异。 对这些差异进行排序使我们能够优先删除在比较中最强烈支持反对派的电台。 

构建的循环`removed`模拟逐步消除有害电台，直到反对派不再对所选候选人具有绝对优势。 第一次的情况`cur <= 0`如果满意，则由于排序顺序，我们已经实现了该候选者的最小删除次数。 

最后，我们选择最佳候选，它对应于全局最小取消数量。 

一个常见的陷阱是忘记比较是严格的，因此平等已经足以停止。 另一个微妙之处是使用正确的候选索引：候选`n-1`是对立面，差异始终是相对于它计算的。 

## 工作示例

 我们使用样本输入。 

输入：```
5 3
6 3 4 2 8
3 7 5 6 7
5 2 4 7 9
```我们计算候选 1（索引 0）。 每个站的差异 di = 反对派 - 候选人 1 为：

 | 车站| 迪 |
 | ---| ---|
 | 1 | 8 - 6 = 2 | 8 - 6 = 2
 | 2 | 7 - 3 = 4 | 7 - 3 = 4
 | 3 | 9 - 5 = 4 | 9 - 5 = 4

 总计为 10。我们首先删除最大的 di：站 2 或 3（均为 4），然后站 3 或 2，然后站 1。删除两个站后，剩余总和 ≤ 0，因此答案为 2。 

对于候选 2（索引 1），我们得到：

 | 车站| 迪 |
 | ---| ---|
 | 1 | 8 - 3 = 5 | 8 - 3 = 5
 | 2 | 7 - 7 = 0 | 7 - 7 = 0
 | 3 | 9 - 2 = 7 | 9 - 2 = 7 |

 我们首先移除站 3 和 1； 再次删除 2 次就足够了。 

这证实了多个候选者可以产生相同的最佳答案，并且算法正确地选择了最小值。

 ## 边缘情况

 一个重要的边缘情况是反对派最初没有领先任何候选人。 在这种情况下，每个候选者的总差异已经是非正的，或者可以在不删除任何内容的情况下变得非正。 该算法处理这个问题是因为`cur`从总计开始，并在任何删除之前进行检查，因此它立即接受零删除。 

另一种情况是多个站具有相同的 di 值。 排序将它们任意放置在相等的位置，但由于该算法仅依赖于首先删除最大的可用 di，因此关系之间的任何排序都会导致相同的删除次数。 正确性不依赖于排序的稳定性。 

最后一个微妙的情况是删除 di = 0 的站点时。这不会改变运行总和，但如果需要打破某些配置中的严格不平等，仍然可以选择它。 该算法自然会避免不必要的删除，因为一旦 cur ≤ 0，循环就会停止，因此永远不会进行零影响删除，除非它们是完全达到该阈值的一部分。
