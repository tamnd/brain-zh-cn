 ## 解决方案
 ## 问题理解

 我们被赋予了多个独立的场景。 在每个场景中，我们都拥有一组卡牌，其中每张卡牌都有名称、颜色和能量值。 我们必须从这些牌中选择恰好五张牌来组成一副牌，但所有五张选定的牌必须具有不同的名称。 

所选牌组的基本分数就是五张牌的力量值的总和。 然后将该基本分数乘以奖金。 奖金有两种类型。 首先，如果所选卡片的颜色与单一全局奖励颜色相匹配，则每张此类卡片的最终分数都会增加 20%。 其次，如果所选卡牌的名称属于五个全球奖励名称之一，则每张此类卡牌的最终分数都会增加 10%。 这些百分比奖金在各个卡上相加，最终结果在应用总乘数后即为下限。 

因此，对于选定的五张牌，如果我们定义一个奖励系数等于 1 加 0.2 乘以匹配颜色的数量加上 0.1 乘以匹配名称的数量，那么最终得分就是基本总和的下限乘以该系数。 

我们必须在所有有效选择的五张不同名字的卡片上最大化最终得分。 

制约因素很大。 所有测试用例中的卡片总数可能达到 150 万张，因此任何尝试所有 5 张卡片组合的解决方案都是不可能的。 即使每个测试用例独立选择，我们也必须基本上以每个用例的线性或近线性时间进行操作。 这立即排除了任何 O(n^5) 或 O(n^2) 配对方法。 

一个微妙的边缘情况来自于奖金如何相互作用。 由于每张卡的奖励都是累加的，并且在求和力量后应用，因此尝试“本地”选择匹配奖励类型的高力量卡而不考虑五个不同名称的全局选择的天真的方法可能会失败。 另一个陷阱是假设我们应该始终首先拿走所有具有奖励属性的卡牌。 如果稍低的奖励增益被更大的功率值所抵消，那么这不一定是最佳的。 

真正的结构是只选择五张卡，因此决策简化为在小的固定约束下选择大小为五的最佳子集，这允许基于排序的优化。 

## 方法

 暴力方法将枚举五张具有不同名称的卡片的所有组合，计算它们的基本总和和乘数，并取最大值。 组合的数量约为 C(n, 5)，其增长方式为 n^5 / 120。当 n 达到 100000 时，即使对于单个测试用例，这也是完全不可行的。 核心问题是，虽然“不同名称”约束减少了重复，但它并没有减少足以直接枚举的组合爆炸。 

关键的观察结果是，分数仅取决于所选择的五张卡，并且在任何有效的解决方案中，我们只关心它们各自的贡献。 除了通过简单的求和和计数匹配之外，卡之间没有任何交互。 这意味着我们可以独立对待每张卡牌，为其分配一个已经反映其相对于其力量的奖金贡献的值，然后在名称必须不同的约束下选择最好的五张卡牌。 

一旦我们意识到最终分数在基本和和乘法因子上都是单调的，我们就可以重新构建问题。 对于任何一组固定的五个不同名称，同名重复中的最佳选择显然是最大化贡献的那个，因为没有理由选择一张较弱的同名卡。 因此，我们通过只保留每个名字中最好的卡片来压缩问题。

压缩后，我们最多有 100000 个唯一名称候选者。 现在我们计算每张卡的有效贡献系数，并将问题视为选择五个项目来最大化类似乘积的线性表达式。 由于乘数仅取决于两个布尔属性的计数，因此我们可以预先计算每张卡的总乘数贡献，并将问题简化为通过根据其对最终表达式的贡献得出的有效分数进行排序。 

关键的简化在于，由于乘数在计数上是线性的并且统一应用，因此仍然可以通过根据反映功率和奖金贡献的派生分数对卡牌进行排序，然后取前五名来实现最佳选择。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^5) | O(n^5) | O(1) | O(1) | 太慢了|
 | 最佳| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取所有卡牌并按名称对它们进行分组，仅保留每个名称中具有最大功率的单张卡牌。 

这是有效的，因为如果两张牌共用一个名称，则只能选择一张，并且选择更强的一张总是占主导地位。 
2. 对于剩下的每张卡，计算它满足多少奖金。 

一项检查是其颜色是否等于奖励颜色，另一项是其名称是否在五个奖励名称之中。 
3. 将每张卡转换为单个数值，表示其在应用奖金后对最终得分的贡献。 

由于奖金是累加性的并且统一应用，因此我们将每张卡牌的贡献视为按其个人乘数缩放的力量。 
4. 根据该计算值对所有候选卡进行降序排序。 
5. 从此排序列表中取出前五张牌，并使用精确公式计算最终分数：幂总和乘以（1 + 0.2 * 颜色匹配 + 0.1 * 名称匹配），然后发言。 

排序起作用的原因是，一旦每张卡的贡献被标准化为可比较的分数，任何最佳解决方案都必须由五个最高贡献者组成，因为用排名更高的未使用卡替换任何选定的卡可以增加或保留目标。 

### 为什么它有效

 每个有效的解决方案都是一组五个不同的名称，并且在该约束内，每张卡都独立地贡献于基本总和和乘数计数。 由于乘数对于每张卡的指标是线性的，因此目标函数在缩放后可以分解为每张卡贡献的总和。 这就产生了单调选择问题：如果一张卡牌的有效贡献高于另一张卡牌，则用前者替换后者永远不会降低总分。 因此，任何最佳组合都必须包含此排序下的前五张牌。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        
        best = {}
        cards = []
        
        for _ in range(n):
            name, color, p = input().split()
            p = int(p)
            if name not in best or best[name][2] < p:
                best[name] = (color, name, p)
        
        bonus_names = set(input().split())
        bonus_color = input().strip()
        
        arr = []
        for name, (color, _, p) in best.items():
            c_bonus = 1 if color == bonus_color else 0
            n_bonus = 1 if name in bonus_names else 0
            score = p * (1 + 0.2 * c_bonus + 0.1 * n_bonus)
            arr.append((score, p, c_bonus, n_bonus))
        
        arr.sort(reverse=True)
        
        base = 0
        c_cnt = 0
        n_cnt = 0
        
        for i in range(5):
            _, p, c_bonus, n_bonus = arr[i]
            base += p
            c_cnt += c_bonus
            n_cnt += n_bonus
        
        ans = base * (1 + 0.2 * c_cnt + 0.1 * n_cnt)
        print(int(ans))

if __name__ == "__main__":
    solve()
```该实现首先使用字典按名称压缩重复项，确保每个名称中只有最强的卡能够幸存。 这直接强制执行不同名称约束，而无需稍后进行推理。 

然后它会构建一个列表，其中每张卡牌都注释有它是否与奖励颜色匹配以及其名称是否在奖励名称中。 这些标志用于排名和最终计算。 

排序步骤强制执行贪婪选择。 最后的循环使用所选的五张卡重新计算精确的乘数，即使我们使用了近似的排名分数，也确保了正确性。 

我们使用浮点算术计算最终答案，但最后转换为整数，因为问题需要向下取整。

 ## 边缘情况

 一种重要的情况是多张卡具有相同的名称但具有不同的功率值。 该算法只保留最大功率的卡，这确保我们不会在更差的副本上浪费时间。 例如，如果两张名为“A”的牌的幂分别为 10 和 50，则仅保留 50。 否则，输入可能会诱使贪婪的选择同时选择两者，但约束无论如何都禁止它。 

另一种边缘情况是压缩后存在的不同名称少于五个。 该问题保证至少有五个不同的名称，因此始终可以选择五个，并且我们不需要处理候选者不足的情况。 

最后的边缘情况是所有选定卡牌的奖金计数为零。 在这种情况下，乘数正好变为 1，解决方案减少为选择五张最高功率的卡，算法仍然可以正确处理，因为有效分数仅与功率成正比。
