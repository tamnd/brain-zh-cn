 ## 解决方案
 ## 问题理解

 我们给出一个初始大小为零的矩阵$n \times n$。 应用了一系列操作，其中每个操作选择整行或整列，并向该行或列中的每个单元格添加一个正整数。 所有操作完成后，恰好有一个单元格被隐藏，其值被替换为$-1$。 显示最终矩阵，任务是恢复该隐藏单元在被替换之前的原始值。 

最终矩阵中的每个单元格值是影响其行的所有行操作加上影响其列的所有列操作的贡献之和。 隐藏单元在概念上仍然具有相同的加性结构，但我们没有给出它的最终值，只是$-1$。 

约束条件$n \le 1000$意味着一个$O(n^2)$扫描是可以接受的，但任何涉及每个单元重复重建或尝试模拟操作的事情都是不必要的，而且会造成杀伤力过大。 该结构强烈建议跨行和列的全局一致性条件，而不是需要重建完整的操作序列。 

一个微妙的点是，除了一个缺失值之外，矩阵是完全一致的。 如果我们忽略丢失的单元格，则每个其他条目仍然必须遵循相同的加法分解为行和列贡献。 这种一致性是关键杠杆。 

一个幼稚的错误是尝试明确猜测行和列的增量或尝试求解具有太多未知数的系统。 另一个常见的错误想法是假设答案只是行或列的最大值或最小值，这种想法会失败，因为行和列的贡献重叠。 

天真的思维的一个具体失败案例是这样的矩阵：$$\begin{matrix}
5 & 7 \\
6 & -1
\end{matrix}$$错误的假设可能是隐藏值等于行或列极值之间的差，但如果不理解加法分解，当行/列贡献不对称时，这种启发式方法会立即失效。 

## 方法

 每个单元格的值可以表示为$$a_{i,j} = R_i + C_j$$在哪里$R_i$是行操作的总贡献$i$， 和$C_j$是列操作对列的总贡献$j$。 这种分解成立是因为每个操作都统一影响一行或一列。 

如果我们有完整的矩阵，我们可以任意修复$R_1 = 0$并得出所有$C_j$从第 1 行开始，然后恢复所有$R_i$，反之亦然。 该系统是一致的，因为它正是一个 1 阶加法结构。 

复杂之处在于位置处缺少单元格$(x, y)$。 我们不能直接在方程中使用它，但我们可以使用所有其他单元来重建一致的$R$和$C$。 一旦我们有了这些，隐藏的价值就很简单了$R_x + C_y$。 

暴力方法会尝试解决一个系统$2n$变量与$n^2 - 1$方程，可能使用高斯消去法或迭代猜测。 这是不必要的，而且对于$n = 1000$，其中完整的线性求解会太慢且复杂。 

关键的见解是我们不需要所有方程。 选择任何不包含丢失单元格的行可以让我们修复参考并在线性时间内在矩阵中传播值。 

一旦我们选择了一个干净的参考行$r$，对于任意列$j$，我们可以设置$$C_j = a_{r,j} - a_{r,1}$$那么对于任意行$i$和列$1$,$$R_i = a_{i,1} - C_1$$这会重建所有行和列电位。 最后，我们根据行势和列势计算缺失的条目。 

我们只需要确保选择一个不包含的参考行$-1$细胞。

 | ---| ---| ---| ---|
 | 暴力破解（系统解决）|$O(n^3)$|$O(n^2)$| 太慢了|
 | 最优（参考行重建）|$O(n^2)$|$O(n)$| 已接受 |

 ## 算法演练

 1、找准位置$(x, y)$标记的缺失单元格$-1$。 这是必要的，因为它定义了哪些行或列不能用作干净的引用。 
2. 选择参考行$r$那不等于$x$。 这保证了行中的所有值$r$是有效的并且与加法模型一致。 
3. 定义数组$C$尺寸的$n$，并设置$C_j = a_{r,j} - a_{r,0}$。 这修复了相对于第 0 列的所有列贡献，有效地选择$R_r = 0$。 
4. 使用第 0 列作为锚点，计算每行电位$R_i = a_{i,0} - C_0$。 此步骤重建与参考行一致的行贡献。 
5. 将缺失值计算为$R_x + C_y$，因为加法分解适用于每个有效单元并扩展到隐藏单元。 

### 为什么它有效

 每个有效单元格都满足行项和列项的一致分解。 通过固定一个任意参考行，我们消除了系统中的自由度。 所有其他值都是相对于该行确定的。 由于除了一个缺失条目之外，系统是全局一致的，因此从任何有效行进行重建都可以保持正确性。 然后通过相同的分解强制缺失值，因为它仅取决于其行和列电位，这两者都已经被唯一确定。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = []
    mx = 0
    x = y = -1

    for i in range(n):
        row = list(map(int, input().split()))
        for j in range(n):
            if row[j] == -1:
                x, y = i, j
        a.append(row)

    # pick reference row not containing -1
    r = 0 if x != 0 else 1

    # compute column potentials using reference row
    C = [0] * n
    base = a[r][0]
    for j in range(n):
        C[j] = a[r][j] - base

    # compute row potentials
    R = [0] * n
    for i in range(n):
        R[i] = a[i][0] - C[0]

    # answer is reconstruction of missing cell
    print(R[x] + C[y])

if __name__ == "__main__":
    solve()
```该代码首先读取矩阵并找到丢失的单元格。 然后，它选择一个不包含以下内容的安全参考行：$-1$，确保所有计算都使用有效数据。 列势是通过根据其第一个元素标准化参考行而得出的。 然后使用导出的列基线计算行电位。 最后，使用加法模型重建缺失值。 

一个微妙的实现细节是我们从不使用$-1$任何算术中的单元格； 这避免了重建电位的污染。

 ## 边缘情况

 一个边缘情况是缺失的单元格位于第一行或第一列。 该算法通过选择保证不包含的参考行来处理此问题$-1$，因此不会发生无效算术。 

例如：$$\begin{matrix}
-1 & 2 \\
3 & 5
\end{matrix}$$这里参考行变为第 1 行。 

我们计算：$$C_0 = 3 - 3 = 0,\quad C_1 = 5 - 3 = 2$$然后重建：$$R_0 = 2 - 0 = 2$$所以缺失值是：$$R_0 + C_0 = 2$$这表明，即使缺失的条目阻碍了自然锚定，系统仍然是可解的，因为任何有效行仍然完全确定加性结构。
