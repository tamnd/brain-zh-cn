 ## 解决方案
 ## 问题理解

 我们有两个大小相同的正方形网格$n \times m$，每个单元格都包含该网格内的唯一整数。 单个矩阵内的值永远不会重复，但在两个矩阵中，值可能同时出现在两个矩阵中。 

子矩阵是通过选择行和列的连续矩形块来定义的。 我们希望找到以相同结构方式出现在两个矩阵中的子矩阵的最大可能区域，这意味着第一个矩阵中存在一个矩形，其值的模式与第二个矩阵中的矩形完全匹配。 

由于每个矩阵中的所有值都是不同的，因此每个值都充当其位置的唯一标识符。 这是关键的结构简化：我们可以推断两个矩阵中匹配值的位置，而不是比较原始值。 

约束条件允许$n, m \le 1000$，所以网格最多有$10^6$细胞。 任何更接近的解决方案$O(n^2 m^2)$立即不可能，因为它需要以下顺序$10^{12}$比较。 甚至$O(n^2 m)$必须仔细构建，最好使用每行或每列线性或近线性扫描。 

天真的误解通常来自于将其视为二维中的最长公共子串而不使用值的唯一性。 这导致尝试对每个子矩阵进行散列或直接比较所有矩形，这是不可行的。 

当试图纯粹通过值相等来匹配子矩阵而不强制执行一致的相对定位时，就会出现一种微妙的失败情况。 例如，如果我们只检查矩形中的所有值是否出现在另一个矩阵中的某个位置，我们将错误地接受非矩形排列。 

正确的表述需要同时保留行和列方向上的邻接关系。 

## 方法

 暴力方法将枚举第一个网格中的每个可能的子矩阵，并尝试在第二个网格中找到相同的子矩阵。 即使我们使用散列或直接比较来优化检查，子矩阵的数量也是$O(n^2 m^2)$，并且验证每一项都将在区域内花费至少线性时间，使得整个工作完全不可行。 

关键的观察结果来自每个矩阵内值的唯一性。 由于每个数字在每个矩阵中只出现一次，因此每个值都定义一个唯一的坐标。 这使我们能够将问题从比较值的矩形转换为比较坐标差的矩形。 

如果我们将矩阵 A 中的每个值映射到其位置，并对矩阵 B 执行相同的操作，则任何值都将充当参考锚点。 如果两个网格中都存在子矩阵，则选择其左上角元素将为该子矩阵中的所有其他元素提供一致的偏移模式。 这意味着一旦我们固定了一对匹配的锚单元，公共子矩阵的存在就变成了在两个方向上延伸同时保持位置一致性的问题。 

这将问题转化为对齐坐标上的二维最长常见扩展问题，可以使用预先计算的匹配位置逐行检查。 

我们有效地减少了寻找最大矩形的任务，其中连续行保留由值到位置映射引起的相同水平对齐模式。

 | --- | --- | --- | --- |
 | 蛮力 |$O(n^2 m^2 (nm))$|$O(1)$| 太慢了|
 | 最佳 |$O(nm)$|$O(nm)$| 已接受 |

 ## 算法演练

 我们首先为两个矩阵构造一个反向查找，以便对于每个值我们都知道它在该矩阵中的坐标。 这允许从一个矩阵中的值到另一个矩阵中的位置的恒定时间转换。 

然后，我们构建一个辅助网格，对两个矩阵之间的结构对齐进行编码。 对于每个位置$(i, j)$在矩阵 A 中，我们找到它的值出现在矩阵 B 中的位置，给出一个坐标$(x, y)$。 这种坐标配对使我们能够推断 A 中的相邻单元是否在 B 中保持邻接。 

接下来，我们将问题转化为寻找有效对齐的最大矩形。 我们为相邻列对定义一个二元条件：两个矩阵中是否同时保留水平相邻关系。 对于每一行，我们计算一个类似直方图的结构，表示这种水平一致性向右延伸的距离。 

然后我们扫描行，将每一行视为直方图的基础。 对于每一列，我们维护上面有多少连续行也保持水平一致性。 这将问题简化为计算每行直方图中最大的矩形。 

在此过程中找到的最大矩形面积就是答案。 

### 为什么它有效

 任何有效的公共子矩阵都必须保留水平和垂直的邻接关系。 水平邻接确保对于每个单元格，其右邻居与另一个矩阵中对应单元的右邻居匹配。 垂直堆叠可确保这种一致性延伸到多行。 

由于每个值都是唯一的，因此邻接一致性完全确定子矩阵在两个矩阵中是否相同。 这将 2D 模式匹配问题简化为行上的 1D 直方图扩展，其中正确性源自所有约束分解为局部邻接检查的事实。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    A = [list(map(int, input().split())) for _ in range(n)]
    B = [list(map(int, input().split())) for _ in range(n)]

    posB = {}
    for i in range(n):
        for j in range(m):
            posB[B[i][j]] = (i, j)

    match_row = [[0] * m for _ in range(n)]
    match_col = [[0] * m for _ in range(n)]

    for i in range(n):
        for j in range(m):
            x, y = posB[A[i][j]]
            match_row[i][j] = (y == posB[A[i][j+1]][1] if j + 1 < m else 0)
            match_col[i][j] = (x == posB[A[i+1][j]][0] if i + 1 < n else 0)

    # height array for histogram of valid rows
    height = [[0] * m for _ in range(n)]

    for j in range(m):
        height[0][j] = 1

    for i in range(1, n):
        for j in range(m):
            if match_col[i-1][j]:
                height[i][j] = height[i-1][j] + 1
            else:
                height[i][j] = 1

    ans = 1

    # for each row, compute largest rectangle using horizontal validity
    for i in range(n):
        stack = []
        for j in range(m + 1):
            cur = match_row[i][j] if j < m else 0
            while stack and match_row[i][stack[-1]] >= cur:
                idx = stack.pop()
                h = height[i][idx]
                width = j if not stack else j - stack[-1] - 1
                ans = max(ans, h * width)
            stack.append(j)

    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先为矩阵 B 构建一个位置图，以便可以立即将每个值解析为其坐标。 这是无需扫描即可比较邻接关系的结构主干。 

这`match_row`table 检查 A 中的向右移动是否对应于 B 中的向右移动。如果此条件成立，则该单元格的水平结构是一致的。 同样，垂直一致性是通过`height`数组，计算每列有多少连续行保持垂直对齐。 

最后一步是每行的标准单调堆栈直方图计算，其中宽度来自水平一致性，高度来自垂直连续性。 

一个常见的实施陷阱是忘记水平和垂直约束是独立相互作用的。 将它们混合到单个 DP 状态通常会导致计数过多或不正确的矩形扩展。

 ## 边缘情况

 一个关键的边缘情况是矩阵共享值但空间排列完全不同。 在这种情况下，仅值相等就会产生误导，因为不会保留邻接性。 该算法通过强制水平和垂直一致性来避免这种情况`match_row`和`height`。 

另一种情况是仅存在单单元格匹配。 例如，如果每个值在邻接性保留方面都是隔离的，则算法仍然会在各处生成高度 1 和宽度 1，从而正确生成答案 1，而不会尝试无效扩展。 

最后，自然地处理诸如 1×m 或 n×1 之类的退化网格。 水平或垂直过渡崩溃，但直方图结构仍然可以正确计算，因为边界被视为零过渡。
