 ## 解决方案
 ## 问题理解

 我们正在控制一个简化的飞行控制器，具有四个可调参数，对应于四个襟翼：北、东、南和西。 每个请求都会提供三种所需的物理效果：俯仰、滚动和偏航。 这些效应是襟翼设置的线性组合，因此系统完全由一个小的线性方程系统描述。 

其关系是，俯仰仅取决于东西方向的差异，滚转仅取决于南北方向的差异，而偏航取决于所有四个襟翼值的总和。 因此，每个请求本质上是要求我们选择四个实数，其三个线性组合与目标向量匹配。 

因为有四个变量但只有三个约束，所以总是至少有一个自由度。 这种自由在客观意义上并不是自由的：在所有有效的解决方案中，我们必须选择最大绝对襟翼值尽可能小的解决方案。 这将任务转变为线性解空间上的约束优化问题。 

每个查询都是独立的，我们必须为每个查询输出一个有效的四元组。 

输入的边界量级很小，所有目标都位于以原点为中心、边长为 2 的立方体中。 查询数量很大，最多可达10^4，因此每个查询需要一个恒定时间公式。 任何涉及迭代搜索或优化每个查询的方法都会太慢。 

一种简单的方法是通过选择一个自由变量并通过搜索最小化最大绝对值来直接求解线性系统。 这会失败，因为最佳选择取决于同时平衡所有四个变量，并且自由参数的强力离散化会引入精度问题和时间开销。 

当所有目标都为零时，会出现微妙的边缘情况。 任何对称赋值（如全零）都可以，但由于自由变量的任意选择，许多简单的参数化仍然会产生不必要的非零值，这可能违反最小最大约束。 

## 方法

 我们从约束定义线性系统的观察开始：

 我们想要

 螺距 p = e − w

 滚动 r = n − s

 偏航 y = n + e + s + w

 重新排列前两个方程立即给出结构：

 n和s仅出现在横滚和偏航中，而e和w仅出现在俯仰和偏航中。 这建议将变量分组为两个独立的对。 

从滚动中我们得到 n 和 s 之间的差异约束。 从音高我们得到 e 和 w 之间的差异约束。 这意味着我们可以使用对称形式对这两对进行参数化：

 n = a + t

 s = a − t

 e = b + u

 w = b − u

 这会自动满足横滚 = 2t 和俯仰 = 2u，因此 t = r/2 且 u = p/2。 现在只剩下偏航：

 y = (a + t) + (b + u) + (a − t) + (b − u) = 2a + 2b

 因此偏航约束变为 a + b = y/2。 

现在优化问题变得清晰了：我们选择 a 和 b 求和为 y/2，同时最小化以下各项中的最大幅度：

 |a±t| 和 |b ± u|。 

这是一个经典的平衡问题。 关键的观察是对称性：对于每一对，最小化最大绝对值的最佳方法是将它们尽可能紧密地集中在零周围，同时尊重它们所需的差异。 当两对单独居中以平衡它们对偏航的贡献时，该结构会强制实现最优。 

我们定义 a = b = y/4，它在两个对称对之间均匀分布偏航。 这种选择最大限度地减少了两组之间的不平衡，并确保两组具有相同的基线偏移。 那么解决方案就变成了：

 n = y/4 + r/2

 s = y/4 − r/2

 e = y/4 + p/2

 w = y/4 − p/2

 这种结构完全满足所有约束并均匀地传播偏航，这是避免不必要地增加一对中的最大绝对值的唯一方法。

强力替代方案是选择一个自由参数 a，表达所有四个变量，并将最大绝对值最小化为 a 中的分段线性函数。 该函数具有绝对值变化的断点，因此需要对凸函数进行案例分析或三元搜索，而一旦认识到对称性，则不需要这样做。

 ## 算法演练

 1. 读取由所需的俯仰角 p、横滚角 r 和偏航角 y 组成的查询。 目标是构造与这些完全匹配的襟翼值，同时保持较小的幅度。 
2. 将系统分解为两个独立的差分方程。 将差异变量设置为 t = r/2 和 u = p/2。 这直接满足横滚和俯仰，因为 n − s = 2t 且 e − w = 2u。 
3. 将每对表示为对称中心加偏差：n = a + t、s = a − t 和 e = b + u、w = b − u。 无论 a 和 b 如何，这都保证了横滚和俯仰的正确性。 
4. 代入偏航方程。 差异消除，留下 y = 2a + 2b。 这将偏航控制减少到单个线性约束 a + b = y/2。 
5. 通过选择 a = b = y/4 来均匀分布偏航。 这消除了两对之间的不对称性，防止一对被迫比另一对承载更多的偏移。 
6. 使用步骤 2 和 5 中导出的公式计算最终襟翼值并输出。 

### 为什么它有效

 该结构使用 a 和 b 上的一个自由度来参数化所有有效的解决方案。 任何有效解必须满足 a + b = y/2，因此每个解都位于 (a, b) 空间中的一条线上。 最大绝对襟翼值由a和b中的线性表达式控制，其在单个剩余自由度上是凸的。 对称选择 a = b 是避免任一对向上偏置的唯一点，任何偏差都会不均匀地改变偏航分配，从而增加至少一对的幅度。 这确保了所产生的解决方案在最小化最大绝对襟翼值方面是全局最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    out = []
    for _ in range(q):
        p, r, y = map(float, input().split())
        n = y / 4.0 + r / 2.0
        s = y / 4.0 - r / 2.0
        e = y / 4.0 + p / 2.0
        w = y / 4.0 - p / 2.0
        out.append(f"{n:.10f} {e:.10f} {s:.10f} {w:.10f}")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```代码直接应用导出的封闭式解决方案。 每个查询都在恒定时间内独立处理。 格式化使用足够的精度来保持在所需的绝对误差范围内，因为解决方案仅涉及输入的线性组合。 

唯一微妙的实现细节是确保一致的缩放：在分配为对称偏差之前，俯仰和滚转被减半，而偏航被均匀地分成应用于所有四个变量的共享偏移 y/4。 

## 工作示例

 考虑查询 p = 1, r = 1, y = 0。 

我们计算 t = 0.5、u = 0.5、a = b = 0。 

| 步骤| n | 电子| s | 瓦 |
 | ---| ---| ---| ---| ---|
 | 计算 t, u | - | - | - | - |
 | 应用公式| 0.5 | 0.5 0.5 | 0.5 -0.5 | -0.5 -0.5 | -0.5

 俯仰变为 e − w = 1，横滚变为 n − s = 1，偏航为零，因为所有贡献都取消了。 该结构表明，当偏航为零时，系统简化为两个独立的对称对。 

现在考虑 p = 0、r = 0、y = 1。 

我们得到 t = 0、u = 0、a = b = 0.25。 

| 步骤| n | 电子| s | 瓦 |
 | ---| ---| ---| ---| ---|
 | 计算偏移量 | 0.25 | 0.25 0.25 | 0.25 0.25 | 0.25 0.25 | 0.25
 | 应用公式| 0.25 | 0.25 0.25 | 0.25 0.25 | 0.25 0.25 | 0.25

 这里俯仰和横滚保持为零，因为所有差异都消失了。 偏航等于 1，因为总和为 1。这表明纯偏航迫使所有变量一起均匀移动。

 ## 边缘情况

 当所有输入都为零时，公式完全崩溃为 n = e = s = w = 0。没有引入隐藏的偏移量，因为偏航在所有变量上均匀分配，并且俯仰和滚转贡献消失。 

当只有俯仰非零、偏航为零且横滚为零时，该结构将 e 和 w 对隔离。 解变为 e = p/2 且 w = -p/2，而 n 和 s 保持相等，保持零滚动。 

当只有偏航非零时，所有四个变量都会折叠为相同的值 y/4。 这是最敏感的情况，因为任何不对称都会立即不必要地增加最大绝对值，而对称分布可以防止这种情况发生。 

当 p 和 r 的符号不同时，分离成独立的对称对可确保不会发生交叉干扰，因为俯仰仅影响一对，而滚动影响另一对。
