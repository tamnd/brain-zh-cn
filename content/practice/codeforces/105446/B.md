 ## 解决方案
 ## 问题理解

 我们得到一长串配对观察结果。 每个观察值代表一个月，其中一个值是广告支出，另一个值是最终销售额。 根据这些数据，我们反复构建一个简单的预测模型，将支出与销售额进行直线映射。 

对于每个查询，我们仅采用连续的月份部分。 在该段上，我们使用岭回归拟合一条线，这意味着我们选择斜率和截距系数，以最小化平方误差加上两个参数的 L2 惩罚。 该惩罚的强度取决于查询。 一旦找到该细分市场的最佳路线和惩罚，我们就会根据给定的输入支出值对其进行评估并输出预测销售额。 

关键的挑战是每个查询的段边界和正则化参数都会发生变化，并且可能有多达一百万个数据点和一百万个查询。 这排除了每个查询从头开始重新计算回归的情况，因为每次拟合都需要聚合该段的统计信息。 

一种幼稚的方法会重新计算每个查询的所有总和，从而在最坏的情况下导致二次行为。 当n和m达到10^6时，即使O(nm)也是完全不可行的。 

当段中的所有 x 值都相同时，就会出现微妙的数值边缘情况。 在这种情况下，回归矩阵的条件会变得很差，但岭正则化使系统保持可解。 任何解决方案都必须避免在没有正则化的情况下假设可逆性。 

## 方法

 回归问题在两个参数中是线性的，因此最优解来自于求解从一阶最优性条件导出的 2 × 2 线性系统。 

对于固定段，我们定义聚合统计数据：

 令 Sx 为 x 之和，Sy 为 y 之和，Sxx 为 x 平方和，Syy 为 y 平方和，Sxy 为线段上 x 乘以 y 的总和。 

目标函数在 K 和 B 中展开为二次形式。对 K 和 B 求导可得到线性系统：

 (K * Sxx + B * Sx) + λK = Sxy

 (K * Sx + B * n) + λB = Sy

 重写：

 (K(Sxx + λ) + B Sx = Sxy

 (K Sx + B (n + λ) = Sy)

 因此，对于每个查询，一旦我们知道 [L, R] 上的这五个基于前缀的聚合，我们就可以在恒定时间内解决 2×2 系统。 

强力方法通过扫描段来重新计算每个查询的所有总和。 每个查询的成本为 O(段长度)，导致总操作量为 O(nm)。 对于多达 10^6 个元素和查询，这太慢了。 

关键的见解是所有所需的数量都是分段累加的。 这允许前缀和，因此每个查询都减少到 O(1) 算术。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(纳米) | O(1) | O(1) | 太慢了|
 | 前缀和+封闭式 | O(n + m) | O(n) | 已接受 |

 ## 算法演练

 ### 1. 预计算前缀聚合

 我们为 Sx、Sy、Sxx 和 Sxy 构建前缀数组。 每个位置存储直到该索引的累积和。 这允许将任何段总和计算为两个前缀值的差。 

其有效的原因是线性：不相交间隔上的总和在没有相互作用的情况下组合起来。 

### 2.提取每个查询的段统计信息

 对于查询 [L, R]，我们计算：

 n = R − L + 1

 使用前缀差异在该范围内的 Sx、Sy、Sxx、Sxy

 这将回归问题仅隔离到相关的数据子集。 

### 3. 构建岭回归系统

 我们将优化转化为线性方程：

 (Sxx + λ)K + SxB = Sxy

 SxK + (n + λ)B = Sy

 这直接来自将正则化损失的偏导数设置为零。 

### 4. 求解 2×2 系统

 我们使用行列式求解：

 D = (Sxx + λ)(n + λ) − Sx²

 然后：

 K = ((Sxy)(n + λ) − SxSy) / D

 B = ((Sxx + λ)Sy − SxSxy) / D

 这是正规方程的直接代数解。 

### 5.输出预测

对于每个查询，计算 KX + B 并打印它。 

### 为什么它有效

 由于 L2 项，回归目标是 K 和 B 中的严格凸二次函数。 这保证了唯一的全局最小值。 梯度条件产生一个线性系统，其系数仅取决于数据的聚合统计数据。 由于这些统计信息是在时间间隔内累加的，因此前缀和保留了为任何查询段重建系统所需的所有信息。 精确求解系统会产生唯一的最小化器，因此预测是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    Sx = [0.0] * (n + 1)
    Sy = [0.0] * (n + 1)
    Sxx = [0.0] * (n + 1)
    Sxy = [0.0] * (n + 1)

    for i in range(1, n + 1):
        x, y = map(float, input().split())
        Sx[i] = Sx[i - 1] + x
        Sy[i] = Sy[i - 1] + y
        Sxx[i] = Sxx[i - 1] + x * x
        Sxy[i] = Sxy[i - 1] + x * y

    m = int(input())
    out = []

    for _ in range(m):
        L, R, lam, X = input().split()
        L = int(L)
        R = int(R)
        lam = float(lam)
        X = float(X)

        nseg = R - L + 1

        Sx_seg = Sx[R] - Sx[L - 1]
        Sy_seg = Sy[R] - Sy[L - 1]
        Sxx_seg = Sxx[R] - Sxx[L - 1]
        Sxy_seg = Sxy[R] - Sxy[L - 1]

        A = Sxx_seg + lam
        B = Sx_seg
        C = nseg + lam
        D = Sxy_seg
        E = Sy_seg

        det = A * C - B * B

        K = (D * C - B * E) / det
        B0 = (A * E - B * D) / det

        out.append(str(K * X + B0))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```前缀数组存储累积贡献，因此每个查询都成为分段总和的恒定时间提取。 每个回归系统都是根据这些总和构建的，无需重新访问原始数据。 

行列式计算直接实现了2×2正规方程的闭式解。 项的顺序很重要，因为在减去接近值时浮点精度很敏感，因此计算行列式 AC − B² 是稳定且最小的。 

最终的预测只是对拟合线性模型的评估。

 ## 边缘情况

 一种重要的边缘情况是段中的所有 x 值都相同。 在这种情况下，Sxx − Sx²/n 变为零，普通最小二乘法将不确定。 岭项将 λ 添加到对角线上，使行列式严格为正并确保系统保持可解。 例如，如果 x = [2, 2] 且 y = [1, 3]，则回归会减少到惩罚下的平衡截距，并且系统仍然会产生唯一的解决方案。 

另一个边缘情况是 λ = 0，此时系统简化为标准线性回归。 这里，数值稳定性完全取决于数据方差。 行列式变为 AC − B²，如果数据完全位于特征空间中的垂直线上，则系统将是奇异的。 该问题保证非负 λ，但不能保证它是正的，因此实现不能除以 λ 相关的快捷方式，并且必须始终使用完整的行列式形式。
