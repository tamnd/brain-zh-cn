 ## 解决方案
 ## 问题理解

 我们有一排冰球，每个冰球的价格都是正整数，Sage 会挑选出比两个相邻的冰球都便宜的冰球。 两端的球体从来都不便宜，因为它们缺少两个邻居。 我们的任务是对球体重新排序，以最大化廉价球体的数量，并输出实现此最大值的排列。 

输入给我们提供了球体的数量，`n`，以及一系列的价格。 输出必须报告便宜球体的最大数量以及实现该数量的有效排序。 自从`n`可以大到 10^5，价格高达 10^9，运行时间为 O(n^2) 的算法或任何具有嵌套循环的算法`n`会太慢。 我们需要一种 O(n log n) 或 O(n) 的方法来轻松地在 1 秒内运行。 

边缘情况包括许多价格相等的情况。 例如，与价格`[2, 2, 2, 2]`，没有任何球体可以严格地比两个邻居便宜，因此答案必须为零。 另一种情况是当`n`很小，就像`n = 1`或者`n = 2`; 由于便宜的球体需要两个邻居，因此输出自动为零并且数组可以保持不变。 尝试检查所有排列的幼稚方法将默默失败或速度太慢`n = 10^5`。 

## 方法

 强力解决方案将尝试球体的每种排列，然后为每种排列计算廉价的球体。 这在原则上是正确的，因为它探索了所有可能性，但它是不可行的：`n = 10^5`,`n!`是一个天文数字，甚至对于`n = 10`操作次数已超过 300 万次，超出了典型的时间限制。 

导致有效解决方案的关键观察是，只有当廉价球体小于两个邻居时才会出现。 这提出了一种建设性的方法：我们应该将较小的球体放置在被较大球体包围的位置。 首先对数组进行排序允许我们系统地将最小的一半球体放置在“谷”位置（奇数索引，将第一个位置视为索引 0），并将较大的一半放置在“峰值”位置（偶数索引）。 这样，每个山谷都保证有比自己更大的邻居，从而最大限度地增加廉价球体的数量。 

这种模式利用了问题结构：其他所有位置都可能是一个廉价的球体。 如果我们计算不是端点的奇数索引的数量，我们可以准确地放置`floor((n-1)/2)`那里有小球体，给出了廉价球体的最大可能数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最优（排序+放置）| O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 按非降序对价格数组进行排序。 排序给出了全局顺序，因此我们可以有效地选择最小和最大的球体。 
2. 将排序后的数组分成两半。 前半部分包含将位于“谷”的较小价格，后半部分包含将占据“峰”的较大价格。 对于长度的数组`n`，第一个`floor(n/2)`元素进入山谷，其余元素进入高峰。 
3.初始化一个空数组`res`长度`n`存储最终的安排。 
4. 填充奇数索引`res`(1, 3, 5, ...) 包含较小一半的元素。 这些是山谷位置。 从最小的元素开始，保证每个山谷都严格小于其邻居。 
5. 用较大的一半中的元素填充剩余位置（甚至索引 0、2、4...）。 这些是巅峰位置。 使用较大的元素可确保每个山谷都严格小于两个相邻山谷。 
6. 计算廉价球体的数量。 这将恰好是被填充的山谷的数量，即`floor((n-1)/2)`因为第一个和最后一个位置不可能便宜。 

为什么它有效：不变的是每个小元素占据一个谷位置，每个大元素占据一个峰位置。 通过构造，每个山谷都有来自较大一半的两个邻居，保证它严格小于两个邻居。 端点从来都不便宜，所以我们忽略它们。 这种布置可以最大化廉价球体，因为没有其他布置可以在不违反严格较小条件的情况下产生更多山谷。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
a.sort()

res = [0] * n
small = a[:n//2]
large = a[n//2:]

res[1::2] = small
res[0::2] = large

max_cheap = n//2
print(max_cheap)
print(' '.join(map(str, res)))
```解决方案首先对数组进行排序。 然后，我们将其分成较小的一半（代表谷位置）和较大的一半（代表峰值位置）。 填充`res[1::2]`较小的元素保证了山谷，并且`res[0::2]`较大的元素可以保证峰值。 我们计算`max_cheap`作为`n//2`因为谷的数量（如果 n 很小，则排除第一个元素的奇数位置）对应于廉价球体的数量。 

## 工作示例

 对于输入：```
7
1 3 2 2 4 5 4
```排序后：`[1, 2, 2, 3, 4, 4, 5]`分成两半：小=`[1, 2, 2]`, 大 =`[3, 4, 4, 5]`填充山谷（奇数索引）：

 资源[1] = 1，资源[3] = 2，资源[5] = 2

 填充峰值（偶数指数）：

 资源[0] = 3，资源[2] = 4，资源[4] = 4，资源[6] = 5

 最终安排：`[3, 1, 4, 2, 4, 2, 5]`位置 1、3、5 处的山谷有比自身更大的邻居。 廉价球体的数量 = 3。 

对于输入：```
4
2 2 2 2
```排序：`[2, 2, 2, 2]`小=`[2, 2]`, 大 =`[2, 2]`最终安排：`[2, 2, 2, 2]`没有球体严格小于两个邻居，因此廉价计数 = 0。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    res = [0] * n
    small = a[:n//2]
    large = a[n//2:]
    res[1::2] = small
    res[0::2] = large
    max_cheap = n//2
    return f"{max_cheap}\n{' '.join(map(str,res))}"

# Provided sample
assert run("7\n1 3 2 2 4 5 4\n") == "3\n3 1 4 2 4 2 5", "sample 1"

# Custom cases

assert run("1\n5\n") == "0\n5", "single element"
assert run("2\n1 2\n") == "1\n2 1", "two elements"
assert run("5\n1 2 3 4 5\n") == "2\n3 1 4 2 5", "ascending sequence"
assert run("6\n6 1 3 5 2 4\n") == "3\n4 1 5 2 6 3", "mixed sequence"
