 ## 解决方案
 ## 问题理解

 我们获得了不同的冰球价格，并且可以按任何顺序重新排列它们。 仅当球体同时具有左邻居和右邻居时才被认为是便宜的，并且其价格严格小于这两者。 第一个和最后一个位置永远不能做出贡献。 

任务是建立一种安排，最大化有多少位置成为局部最小值，然后打印该最大数量和一个有效的排序。 

输入大小达到$10^5$，这意味着检查每个排列的算法是没有希望的。 甚至$O(n^2)$会在周围表演$10^{10}$最坏的情况下操作，远远超出了时限。 排序，需要花费$O(n \log n)$，对于这个尺寸来说很容易负担得起。 

一些边缘情况很容易被错误处理。 

当元素非常少时，就不可能存在廉价的球体。 例如```
1
7
```必须产生```
0
7
```因为唯一的球体也是端点。 

具有三个值，```
3
1 2 3
```正确答案是```
1
2 1 3
```因为位置 2 变得比两个邻居都小。 尝试放置多个局部最小值是不可能的，因为只存在一个内部位置。 

另一种微妙的情况是长度均匀。 为了```
4
1 2 3 4
```答案是```
1
3 1 4 2
```粗心的交替排列可能会错误地预期两个局部最小值，但位置 2 和 4 不能同时是谷，因为最后一个位置只有一个邻居。 

## 方法

 暴力解决方案将生成每个排列，计算有多少个索引满足```
a[i] < a[i - 1] and a[i] < a[i + 1]
```并保持最佳的安排。 这是有效的，因为它显式地检查每个可能的顺序。 不幸的是有$n!$排列。 即使是为了$n=12$，这已经超过了 4.79 亿个排列，使得该方法无法使用。 

局部最小值的结构给出了更好的想法。 每个便宜的球体必须位于两个较大的球体之间。 由于所有数字都是不同的，因此最小值是谷值的最佳候选值。 

假设我们对数组进行排序。 如果我们将一些较大的值放置在奇数位置并在它们之间插入较小的值，则每个插入的元素会自动变得小于其两个邻居。 唯一的问题是有多少这样的山谷适合。 

如果有$k$山谷，我们需要：```
large small large small ... large
```它使用$k+1$大元素和$k$小元素，总共$2k+1$职位。 因此$$2k+1 \le n$$最大可能值为$$k=\left\lfloor \frac{n-1}{2}\right\rfloor.$$排序后，我们可以简单地将较大的一半放在前面，然后将较小的一半插入到其他位置。 这恰好创建了最大数量的山谷。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n!\cdot n)$|$O(n)$| 太慢了 |
 | 最佳 |$O(n\log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 按升序对数组进行排序。 
2. 计算$$k=\left\lfloor\frac{n-1}{2}\right\rfloor.$$这是可能的最大谷数，因为每个谷需要两个相邻的峰。 
3. 将排序后的数组分成两部分。 

第一部分包含最小的$k$价值观。 这些将成为山谷。 

第二部分包含剩余的值。 这些将充当峰值。 
4. 使用第二部分中的所有值开始答案数组。 

已经存在较大的数字可以保证任何插入的较小的数字将低于其邻居。 
5. 将小值插入答案数组的位置 1、3、5、...。 

每个插入的值都位于两个较大的值之间，因为第二部分完全大于第一部分。 
6. 输出$k$以及由此产生的安排。 

### 为什么它有效

 排序顺序保证了被选为谷的每个元素都小于每个峰元素。 将山谷元素插入到奇数位置后，每个山谷元素在紧邻左侧和紧邻右侧的值都较大。 因此，所有这些位置都是局部最小值。 

任何安排都不能包含超过$\lfloor (n-1)/2 \rfloor$山谷，因为每个山谷都会消耗两个相邻的位置。 该结构恰好达到了该数字，因此是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

a.sort()

k = (n - 1) // 2

small = a[:k]
large = a[k:]

ans = large[:]

for i in range(k):
    ans.insert(2 * i + 1, small[i])

print(k)
print(*ans)
```第一部分对价格进行排序并计算理论最大谷数。 

最小的`k`值存储在`small`，而其余​​的进入`large`。 由于每个元素`large`超过了每一个元素`small`，任何插入的小值都会自动成为局部最小值。 

答案最初包含所有大值。 该循环在位置 1、3、5 等处插入谷候选项。 这些是从零开始的索引，对应于从一开始的索引中的第二、第四、第六个位置。 

一个常见的差一错误是使用`n // 2`而不是`(n - 1) // 2`。 对于偶数长度，这会高估谷的数量。 例如，与`n=4`，至多存在一个局部最小值。
