 ## 解决方案
 ## 问题理解

 我们得到了一套袋子，每个袋子都有最小重量限制。 我们需要定义一组最小的物品重量，以便可以使用无限数量的这些物品来形成袋子可以容纳的任何总重量。 此外，从 1 到给定最大值的每个可能的重量`m`必须以某种组合形式表示为这些项目权重的总和。 本质上，这些物品的作用就像“硬币”，而袋子定义了我们必须能够实现的目标金额，而我们被要求找到一个最小的硬币组，涵盖所有金额`m`并准确达到每件行李的限额。 

输入给我们`n`不同的袋子容量和最大重量`m`。 限制因素`n, m ≤ 10^6`表明任何迭代所有可能的权重子集的解决方案都会太慢。 我们需要一种线性或近线性的方法`m`要有效率。 当第一个袋子的重量为 1 或连续袋子容量之间的差距迫使包含多个不同的重量以满足覆盖要求时，就会出现边缘情况。 例如，如果袋子是`[3, 4]`和`m = 4`，天真的方法可能会忽略权重 1 或 2 是覆盖所有 ≤ 4 的总和所必需的。 

## 方法

 暴力方法会尝试贪婪地挑选物品并验证每个重量最多`m`是否可以形成。 这将涉及迭代每个候选权重的所有可能的总和，这是不可行的，因为`m`可以达到`10^6`。 即使使用带有完整布尔数组的动态编程求和也会花费`O(m * n)`在最坏的情况下，可以达到`10^{12}`运营。 

关键的观察结果是，该问题本质上是硬币找零问题的变体。 每个袋子的重量定义了一个必须可表示的目标总和。 如果我们按升序处理袋子的容量，那么只有当我们遇到一个袋子的重量不能由当前的一组物品组成时，我们才能贪婪地选择一个新的物品重量。 新物品重量的最小选择是该袋子重量与我们目前可以用物品形成的最大重量之间的差异。 这确保了每个新项目的重量根据需要扩展可表示总和的范围，从而产生最小集合。 由此产生的算法本质上是对可实现权重的前缀和的贪婪构造。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(米) | 太慢了 |
 | 贪婪的硬币建设| O(n + m) | O(n) | 已接受 |

 ## 算法演练

 1. 按升序对袋子容量进行排序。 这允许从最小到最大进行处理，确保我们可表示的权重集的增量最小。 
2. 初始化`max_reachable`为 0 和一个空的项目权重列表`p`。`max_reachable`跟踪我们当前可以表示为所选项目权重总和的最大权重。 
3. 迭代每个袋子的重量`a_i`。 如果`a_i`大于`max_reachable + 1`，这意味着我们可以表示的总和存在差距。 添加差异`a_i - max_reachable`作为新物品的重量。 这是我们能够达到的最小重量`a_i`同时最小限度地扩展我们当前的总和范围。 
4. 更新`max_reachable`通过添加新的项目重量，扩大可表示的总和范围。 
5. 继续，直到处理完所有袋子容量。 通过构造，直到最后一个袋子的每个重量都是可表示的，并且每个袋子的重量都是精确命中的。 
6. 输出最终的物品权重列表。 如果在任何时候无法覆盖袋子重量并且没有新的重量可以扩展范围（在此设置中这是不可能的，因为重量是≥1的整数），则打印“NO”。 否则，打印“YES”和物品重量。 

为什么它有效：在每一步，`max_reachable`保持从 1 到 的所有总和的不变量`max_reachable`是可以实现的。 通过在出现间隙时选择最小的新重量，我们保证在满足所有所需金额的同时添加尽可能少的物品重量。 这是一个贪婪的选择，由硬币找零问题的结构证明是合理的，其中获取最少丢失的硬币总是会导致无限硬币设置中的最佳集合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()
    
    p = []
    max_reachable = 0
    for weight in a:
        while max_reachable + 1 < weight:
            new_item = max_reachable + 1
            p.append(new_item)
            max_reachable += new_item
        max_reachable = max(max_reachable, weight)
    
    print("YES")
    print(len(p))
    print(' '.join(map(str, p)))

if __name__ == "__main__":
    solve()
```该代码读取输入并对袋子重量进行排序。`max_reachable`跟踪最大的可表示总和。 每当袋子重量之前存在间隙时，就会添加尽可能小的新物品重量来填补间隙。 处理完所有袋子后，`p`包含所需的最小物品重量。 该算法通过始终选择尽可能小的权重来覆盖间隙，从而保证最小性，从而避免不必要的权重。
