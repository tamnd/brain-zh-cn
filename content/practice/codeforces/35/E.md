 ## 解决方案
 ## 问题理解

 每座摩天大楼都是一个位于地面上的轴对齐的矩形。 具有参数的建筑物`(h, l, r)`占据每个点`l ≤ x ≤ r`和`0 ≤ y ≤ h`。 

我们必须构建一条从地面开始、仅水平或垂直移动、并将所有建筑物与地面一起包围的多段线。 在所有此类折线中，我们首先最小化封闭区域。 如果多条折线达到相同的最小面积，我们选择总长度最小的一条。 

从几何角度来看，这正是矩形联合体的上层天际线。 每当更高的建筑物开始出现时，折线就会上升，在可见高度恒定时保持平坦，并在当前最高的建筑物消失时下降。 

这些约束立即排除了任何二次方法。 和`n ≤ 100000`， 甚至`O(n^2)`通过简单的操作就变成了周围`10^10`在最坏的情况下工作，远远超出了时间限制。 我们需要一些接近的东西`O(n log n)`。 

建筑物可以以任意方式重叠。 如果我们不小心构建天际线，就会出现一些微妙的情况。 

一种危险的情况是多个事件发生在同一个 x 坐标处。 

例子：```
3
5 0 2
3 2 4
7 2 5
```在`x = 2`，一栋建筑结束，另外两栋建筑开始。 天际线必须从高处直接跳跃`5`到高度`7`。 在插入之前处理删除的简单扫描可能会错误地创建一个中间下降`0`或者`3`。 

另一个棘手的情况是嵌套建筑。 

例子：```
3
10 0 10
3 2 4
5 6 8
```较小的建筑物永远不会影响轮廓，因为它们完全隐藏在较高的建筑物下面。 盲目地为每个建筑物发出线段的简单实现会产生冗余顶点并且无法满足最小长度要求。 

不相交的建筑物也很重要。 

例子：```
2
4 0 2
3 5 7
```正确的天际线必须返回建筑物之间的地面：```
0 0
0 4
2 4
2 0
5 0
5 3
7 3
7 0
```如果我们不小心合并了单独的组件，我们就会封闭不必要的区域并违反主要优化标准。 

最后，同等高度需要小心。 

例子：```
2
5 0 2
5 2 4
```正确答案是高度上的一个连续的水平线段`5`，不是两个单独的平台，并且在`x = 2`。 

## 方法

 最直接的想法就是对x轴进行离散化。 我们可以收集所有不同的坐标，将平面分成基本区间，并计算覆盖每个区间的最大建筑物高度。 一旦知道高度轮廓，生成折线就很容易了。 

从概念上讲，这是可行的，因为最佳折线是由每个 x 坐标处的最大可见高度唯一确定的。 任何较低的曲线都会与建筑物相交，任何较高的曲线都会增加封闭面积。 

暴力破解的问题是覆盖率测试。 假设我们将坐标压缩为`m`间隔。 对于每个间隔，我们检查所有建筑物以找到最大高度。 在最坏的情况下，`m`是`2n`，所以这就变成了`O(nm) = O(n^2)`。 

和`100000`建筑物，这大致意味着`10^10`比较。 

关键的观察结果是天际线仅在建筑物边界处发生变化。 在两个连续的事件坐标之间，活动建筑物集永远不会改变，因此那里的可见高度是恒定的。 

这自然暗示了扫掠线。 我们从左到右处理所有建筑物的开始和结束事件，同时维护数据结构中最高的活动建筑物。 

当建筑物开始时，我们插入它的高度。 

当建筑物结束时，我们会删除它的高度。 

处理位置事件后`x`，最大活动高度决定了紧邻右侧的天际线`x`。 

最大堆可以快速访问当前最高的建筑物。 由于 Python 堆是最小堆，因此我们存储负高度。 从堆中删除任意高度很不方便，因此我们使用带有计数器映射的延迟删除。 

扫描过程`2n`事件以及每次插入或移除成本`O(log n)`，给出总复杂度`O(n log n)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.将每座建筑转化为两个活动。 

一座大楼`(h, l, r)`变成：

 - 开始事件`(l, type=0, h)`- 结束事件`(r, type=1, h)`我们在同一坐标处处理结束事件之前的开始事件。 当一栋建筑恰好在另一栋建筑开始处结束时，这可以避免高度暂时下降。 
2. 按 x 坐标和事件类型对所有事件进行排序。 

排序后，从左到右扫描可以保证我们始终知道哪些建筑物当前处于活动状态。 
3. 保持最大堆的活动高度。 

由于Python仅提供最小堆，因此存储负高度。 

最初堆包含`0`，代表地面高度。 
4. 维护一张频率图，用于懒惰删除。 

当建筑物结束时，我们会减少其频率，而不是直接从堆中将其删除。 

在读取当前最大值之前，重复弹出频率为零的堆元素。 
5. 将具有相同x坐标的所有事件一起处理。 

这很关键。 天际线不能在同一 x 坐标处多次更改。 

对于该位置的每个事件`x`：

 - 添加开始事件的高度
 - 删除结束事件的标记高度
 6. 处理完该位置的所有事件后`x`，清理堆。 

删除陈旧的堆条目，直到顶部对应于活动高度。 
7. 将新的最大高度与之前的天际线高度进行比较。 

如果高度从`prev_h`到`cur_h`，天际线必须转向`x`。 

添加两个顶点：

 -`(x, prev_h)`-`(x, cur_h)`这将创建所需的垂直段。 
8. 删除多余的连续重复项。 

某些过渡可能会创建重复点或不必要的共线顶点。 压缩它们可以保证折线的最小长度。 
9. 通过扫描过渡自动添加初始和最终地面点。 

### 为什么它有效

 在每个 x 坐标处，堆恰好包含覆盖紧邻 x 右侧位置的建筑物的高度。 其中的最大值是围护结构的最小可能有效高度，因为任何较小的值都会与建筑物相交。 

仅当最大活动高度发生变化时，天际线才会发生变化。 精确地在这些过渡点发射顶点会产生独特的最小面积包络。 任何额外的垂直或水平线段都会在不改变面积的情况下增加总长度，因此清理后的折线在所有最小面积解决方案中也具有最小长度。 

## Python 解决方案```python
import sys
import heapq
from collections import defaultdict

input = sys.stdin.readline

def solve():
    n = int(input())

    events = []

    for _ in range(n):
        h, l, r = map(int, input().split())

        # start before end at same x
        events.append((l, 0, h))
        events.append((r, 1, h))

    events.sort()

    heap = [0]
    cnt = defaultdict(int)
    cnt[0] = 1

    ans = []

    prev_h = 0

    i = 0
    m = len(events)

    while i < m:
        x = events[i][0]

        while i < m and events[i][0] == x:
            _, typ, h = events[i]

            if typ == 0:
                cnt[h] += 1
                heapq.heappush(heap, -h)
            else:
                cnt[h] -= 1

            i += 1

        while heap and cnt[-heap[0]] == 0:
            heapq.heappop(heap)

        cur_h = -heap[0]

        if cur_h != prev_h:
            ans.append((x, prev_h))
            ans.append((x, cur_h))
            prev_h = cur_h

    # remove redundant consecutive duplicates / collinear points
    res = []

    for p in ans:
        if res and res[-1] == p:
            continue

        while len(res) >= 2:
            x1, y1 = res[-2]
            x2, y2 = res[-1]
            x3, y3 = p

            if (x1 == x2 == x3) or (y1 == y2 == y3):
                res.pop()
            else:
                break

        res.append(p)

    print(len(res))
    for x, y in res:
        print(x, y)

solve()
```扫线是实现的核心。 每栋建筑都会贡献一次插入事件和一次移除事件。 对事件进行排序给出从左到右的遍历顺序。 

堆存储当前可能定义天际线的所有候选高度。 由于从堆中删除任意元素的成本很高，因此代码使用惰性删除。 高度保留在堆中，直到到达顶部。 在那一刻，我们检查频率图是否表明它们仍然处于活动状态。 

一起处理同一 x 坐标处的所有事件可以避免不正确的中间转换。 假设一个高度消失，另一个更高的高度出现在同一坐标处。 如果我们一次发出一个事件的更改，我们可能会意外地创建零宽度的锯齿形。 

最后的清理循环删除多余的共线顶点。 如果没有它，等高平台或重复的垂直转弯可能会产生非最小折线。 

所有坐标和高度都安全地适合 Python 整数，因此不会出现溢出问题。

 ## 边缘情况

 考虑共享相同边界的建筑物：```
3
5 0 2
3 2 4
7 2 5
```在`x = 2`， 高度`5`当高度消失时`3`和`7`出现。 该算法处理所有事件`x = 2`在读取新的最大值之前一起。 堆直接从`5`到`7`，生产：```
0 0
0 5
2 5
2 7
5 7
5 0
```不会出现暂时的下降。 

现在考虑嵌套建筑：```
3
10 0 10
3 2 4
5 6 8
```剩余堆最大值`10`整个扫掠过程中。 较小的建筑物进入和离开堆，但永远不会成为最大值，因此内部的天际线永远不会改变`[0,10]`。 

对于相等的相邻建筑物：```
2
5 0 2
5 2 4
```当第一座建筑结束而第二座建筑开始时`x = 2`，加工前后最大高度保持不变`5`。 自从`cur_h == prev_h`，没有发出新的顶点。 结果成为一个连续的水平线段。 

最后，不相交的建筑物：```
2
4 0 2
3 5 7
```加工后`x = 2`，堆最大值下降到`0`，因此天际线返回到地面。 在`x = 5`，它再次上升到`3`。 这正确地保留了建筑物之间的空白空间，而不是封闭不必要的区域。
