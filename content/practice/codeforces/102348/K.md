 ## 解决方案
 ## 问题理解

 我们需要构造一个 (n \times n) 棋盘，其中如果 (i+j) 为偶数，则单元格 ((i,j)) 必须包含石头，否则为沙子。 值 (n) 是偶数且最多为 (50)。 

困难不在于选择最终的颜色。 困难在于到达单元格的顺序。 仅当空单元格位于边框上或接触已填充的单元格时，才可以单独填充该空单元格。 (2 \times 2) 运算更强大，但该正方形内当前的每个空单元格都会接收相同的颜色。 由于每个（2 × 2）棋盘包含两个石格和两个沙格，因此只有在该方格内的一种颜色的方格已被填充后才能使用方格运算。 

输出是一系列有效操作。 每次操作必须只放置正确的颜色，每个选择的位置必须满足所需的可访问性条件，并且操作总数不得超过（3n^2/4）。 

约束 (n \le 50) 意味着即使是直接的 (O(n^2)) 构造在计算上也很小，因为最多有 (2500) 个单元。 真正的限制是操纵器的使用数量。 单独填充每个单元格需要 (n^2) 次操作，该操作始终大于允许的 (3n^2/4)。 因此，我们需要利用 (2 \times 2) 运算，而不仅仅是找到所有单元格的有效遍历。 

事实上 (n) 是偶数，这正是我们将整面墙分割成不相交的 (2 × 2) 正方形的原因。 There are (n^2/4) such squares, and if each square can be completed in three operations, the total is exactly (3n^2/4), matching the limit.

 有两种小情况通常会破坏粗心的结构。 对于 (n=2)，整面墙是一个 (2 × 2) 正方形。 直接（2 \times 2）操作不能是第一个操作，因为所有四个单元格都是空的，并且它会用一种颜色绘制它们，从而创建不正确的单元格。 例如，使用输入`2`，有效的构造是三个运算：分别填充一条对角线的两个单元格，然后对另一条对角线使用一个平方运算。 

对于内部（2 × 2）正方形，简单地填充一个单元格然后尝试填充其相同颜色的对角线伙伴也会失败。 这两个单元格对角相邻，因此第一个操作不会释放第二个单元格。 构建必须选择两个种子单元，以便每个种子单元都已位于已构建区域的边界上。 

## 方法

 最直接的构造就是独立填充每个单元格。 一旦单元格可到达，就可以选择它，并且从其边界向内部处理墙会给出有效的顺序。 最终的着色显然是正确的，因为每次操作都选择了所需的颜色。 然而，在最坏的情况下，这恰好使用 (n^2) 次操作，而问题仅允许 (3n^2/4) 次操作。 对于 (n=50)，即 (2500) 次操作，而不是允许的最大操作数 (1875)。 问题是操作预算而不是计算运行时间。 

关键的观察结果是墙可以分为 (n^2/4) 个不相交的 (2 \times 2) 正方形。 考虑这样一个具有左上角 ((x,y)) 的正方形，其中 (x) 和 (y) 都是奇数。 它的细胞是

 [
 (x,y),\quad (x,y+1),\quad (x+1,y),\quad (x+1,y+1)。 
]

 单元格 ((x,y+1)) 和 ((x+1,y)) 具有相同的颜色。 更重要的是，当从上到下、从左到右处理 (2 × 2) 方格时，在我们处理它们的方格之前，这两个单元格都是可达的。 第一个位于顶部边框或接触上面完整构建的正方形。 第二个位于左边界或接触左侧完整构建的正方形。 

We can fill those two same-colored cells with two singleton operations. 此时，正方形中剩余的两个单元格具有相反的颜色，因此具有相反颜色的单个（2 \times 2）操作恰好填充了这两个空单元格。 从来没有绘制过错误的单元格。 

因此，每个（2 \times 2）平方正好花费三次操作。 由于有 (n^2/4) 个方格，总数为

 [
 3 \cdot \frac{n^2}{4}=\frac{3n^2}{4},
 ]

 这正是允许的最大值。 

暴力构造之所以有效，是因为单独的操作可以完全控制每个单元，但每个单元只花费一次操作。 观察到每个棋盘（2 × 2）正方形由两条同色对角线组成，我们可以用两个单例种子和一个正方形操作来替换四个单例操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 单独填充每个单元格| (O(n^2)) | (O(n^2)) | 有效但超出操作限制 |
 | 划分为 (2 \times 2) 正方形 | (O(n^2)) | (O(n^2)) 存储操作 | 已接受 |

 ## 算法演练

1. 将墙划分为不相交的 (2 × 2) 个正方形，其左上角为 ((x,y))，其中 (x) 和 (y) 取奇数 (1,3,5,\ldots,n-1)。 每个壁单元恰好属于一个这样的正方形。 
2. 以递增的行顺序处理这些方块，并在每行内以递增的列顺序处理这些方块。 此顺序保证除了接触外边框的方块之外的每个方块在其正上方或正左侧都有一个已完成的方块。 
3. 对于当前的方格，首先单独填充((x,y+1))。 它所需的颜色是沙子，因为 (x+y+1) 是奇数。 该单元格是空闲的，因为 (x=1) 将其放置在顶部边框上，而 (x>1) 则为其上方提供了一个填充的邻居。 
4. 也分别用沙子填充((x+1,y))。 如果 (y=1)，则它位于左边界。 否则，紧邻其左边的正方形已经完成，因此 ((x+1,y)) 有一个填充的邻居。 
5. 对石头在 ((x,y)) 处使用 (2 \times 2) 运算。 前面操作中放置的两个沙格已经被占用，而另外两个格子((x,y))和((x+1,y+1))正是这个棋盘格方块的两个石格。 因此，该操作仅填充正确的单元格。 
6. 继续，直到处理完每个 (2 × 2) 方格。 (x) 有 (n/2) 个选择，(y) 有 (n/2) 个选择，因此有 (n^2/4) 个方格，每个方格恰好有 3 次操作。 

### 为什么它有效

 不变的是，在处理一个方格之前，之前处理过的每个方格都是完全正确的，而当前的方格仍然是空的。 第一个种子 ((x,y+1)) 始终是空闲的，因为它要么在顶部边框上，要么接触上面完整的正方形。 第二个种子 ((x+1,y)) 始终是空闲的，因为它要么位于左边界上，要么接触到左侧完整的正方形。 两种种子都是沙细胞。 它们被放置后，正方形中唯一的空单元格是两个石单元格，因此最终的（2 \times 2）操作可以安全地使用石头。 因此，每个操作都是有效的，并且每个占用的单元格都有其所需的颜色。 由于正方形是不相交的并且覆盖了整个墙壁，因此最终的墙壁正是所需的棋盘。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    ans = []

    for x in range(1, n, 2):
        for y in range(1, n, 2):
            # (x, y + 1) and (x + 1, y) are both sand cells.
            ans.append((1, x, y + 1, 2))
            ans.append((1, x + 1, y, 2))

            # The remaining two cells of this 2x2 square are stone.
            ans.append((2, x, y, 1))

    print(len(ans))
    for t, x, y, b in ans:
        print(t, x, y, b)

if __name__ == "__main__":
    solve()
```外循环选择每个 (2 × 2) 块的顶行。 因为它增加了 2，所以它正好访问行 (1,3,\ldots,n-1)。 内部循环对列执行相同的操作。 

第一个单例操作的目标是 ((x,y+1))。 它的奇偶性是奇数，所以它一定是沙子。 第二个目标 ((x+1,y)) 具有相同的奇偶性，因此也需要沙子。 

平方运算从 ((x,y)) 开始。 它的四个单元都在墙内，因为 (x,y \le n-1)。 两个沙单元已被占用，因此该操作仅填充两个空的石单元。 选择石材作为方形颜色是保证操作安全的原因。 

无需模拟墙壁。 施工订单本身证明所需的单元格是空闲的。 Python 整数也不需要特殊处理，因为所有坐标和操作计数最多为几千。

 由此产生的墙是

 | 位置 | ((1,1)) | ((1,1)) | ((1,2)) | ((1,2)) |

### 示例 2

 对于 (n=4)，有四个不相交的 (2 × 2) 正方形。 

| 平方 ((x,y)) | 一号种子 | 二号种子| 最终平方运算| 总运营|
 | --- | --- | --- | --- | --- |
 | ((1,1)) | ((1,1)) | ((1,2)), 沙 | ((2,1)), 沙 | 石头| 3 |
 | ((1,3)) | ((1,3)) | ((1,4)), 沙 | ((2,3)), 沙 | 石头| 3 |
 | ((3,1)) | ((3,1)) | ((3,2)), 沙 | ((4,1)), 沙 | 石头| 3 |
 | ((3,3)) | ((3,3)) | ((3,4)), 沙 | ((4,3)), 沙 | 石头| 3 |

 第一个正方形完成后，第二个正方形中的单元格 ((2,3)) 与其左侧已完成的正方形相邻。 第三个正方形中的单元格 ((3,2)) 类似地与上面完成的正方形相邻。 这正是行主处理适用于内部正方形的原因。

 [

## 测试用例

 由于输出不是唯一的，因此测试应该验证生成的操作序列，而不是将其与一个特定的有效输出逐字符进行比较。```python
# This test harness validates the construction itself.
# It can be used with the solve() implementation above.

import sys
import io

def build(n):
    ans = []

    for x in range(1, n, 2):
        for y in range(1, n, 2):
            ans.append((1, x, y + 1, 2))
            ans.append((1, x + 1, y, 2))
            ans.append((2, x, y, 1))

    out = [str(len(ans))]
    out.extend(f"{t} {x} {y} {b}" for t, x, y, b in ans)
    return "\n".join(out) + "\n"

def validate(inp: str) -> str:
    n = int(inp.strip())
    output = build(n)

    data = list(map(int, output.split()))
    k = data[0]
    assert 1 <= k <= 3 * n * n // 4

    board = [[0] * n for _ in range(n)]
    p = 1

    def wanted(i, j):
        # i and j are zero-based here.
        return 1 if (i + j) % 2 == 0 else 2

    def free(i, j):
        if board[i][j] != 0:
            return False

        if i == 0 or i == n - 1 or j == 0 or j == n - 1:
            return True

        return (
            board[i - 1][j] != 0
            or board[i + 1][j] != 0
            or board[i][j - 1] != 0
            or board[i][j + 1] != 0
        )

    for _ in range(k):
        t, x, y, b = data[p:p + 4]
        p += 4

        x -= 1
        y -= 1

        if t == 1:
            assert 0 <= x < n
            assert 0 <= y < n
            assert free(x, y)
            assert wanted(x, y) == b
            board[x][y] = b

        else:
            assert t == 2
            assert 0 <= x < n - 1
            assert 0 <= y < n - 1

            cells = [
                (x, y),
                (x, y + 1),
                (x + 1, y),
                (x + 1, y + 1),
            ]

            assert any(free(i, j) for i, j in cells)

            for i, j in cells:
                if board[i][j] == 0:
                    assert wanted(i, j) == b

            for i, j in cells:
                if board[i][j] == 0:
                    board[i][j] = b

    for i in range(n):
        for j in range(n):
            assert board[i][j] == wanted(i, j)

    return output

# Provided sample.
sample1 = validate("2")
assert sample1.startswith("3\n"), "sample 1"

# Minimum size, exercising the single 2x2 square.
case2 = validate("2")
assert case2.splitlines()[0] == "3"

# A small interior case, where reachability depends on previously
# completed squares.
case3 = validate("4")
assert case3.splitlines()[0] == "12"

# Another even size, catching row and column progression errors.
case4 = validate("6")
assert case4.splitlines()[0] == "27"

# Maximum allowed n.
case5 = validate("50")
assert case5.splitlines()[0] == str(3 * 50 * 50 // 4)

 ## 边缘情况

 对于 (n=2)，输入为```
2
```唯一的正方形是((1,1))。 该算法首先用沙子填充 ((1,2))，然后用沙子填充 ((2,1))。 两者都是边界单元，因此两个单例操作都是有效的。 最后的 (2 \times 2) 操作用石头填充 ((1,1)) 和 ((2,2))。 输出正好使用三个操作。 

对于内部正方形，请考虑 (n=4) 和从 ((3,3)) 开始的正方形。 在到达之前，从 ((1,1))、((1,3)) 和 ((3,1)) 开始的方格已经完成。 单元格 ((3,4)) 是空闲的，因为它与上面已完成的正方形相邻，而 ((4,3)) 是空闲的，因为它与左侧已完成的正方形相邻。 两者都是沙池，因此可以单独放置。 剩余的单元格 ((3,3)) 和 ((4,4)) 都是石头，最终的平方运算恰好填充了这些单元格。 

(x=1) 或 (y=1) 的边界情况无需特殊代码即可处理。 如果 (x=1)，第一个种子位于顶部边框。 如果 (y=1)，则第二个种子位于左边界。 一旦建筑进一步向内移动，相应的先前完成的正方形就会提供所需的相邻块。 

最大情况 (n=50) 包含 (25) 个块行和 (25) 个块列，给出 (625) 个不相交的 (2 × 2) 正方形。 每个方格需要 3 次运算，因此构造会产生 (625\cdot3=1875) 次运算，正好等于 (3n^2/4)。 没有操作计数或坐标超过规定的限制。
