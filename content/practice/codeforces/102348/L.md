 ## 解决方案
 ## 问题理解

 我们有两行`n`桌子，每层一排。 一个`1`在位置`i`意味着一个团队占据了该桌子，而`0`表示该表是空闲的。 打印机可以安装在任何桌子上，包括有人使用的桌子。 

假设打印机位于`p`在一个选定的楼层。 同一楼层的团队只能水平行走，因此不便之处在于`|i - p|`。 另一层的团队必须首先从自己的桌子走到楼梯，花费`k`有时候换楼层，然后步行到打印机，给您带来不便`i + k + p`。 

任务是为打印机选择地板和桌子，以便尽可能减少对任何参赛团队的最大不便。 我们输出该最小值以及实现该最小值的一台打印机位置。 

价值`n`至多是`1000`，因此即使是二次算法，每层也只能执行大约一百万次迭代。 具有两个可能的打印机楼层，完全直接枚举所有打印机位置和所有团队最多执行的操作`4n² = 4,000,000`团队位置评估。 对于这些限制来说，这已经足够小了，尽管这是不必要的工作。 不便公式的结构让我们可以将计算减少到线性时间。 

最常见的实施错误来自空楼层以及将输入顺序与楼层号码混淆。 第二个输入字符串描述楼层 2，而第三个输入字符串描述楼层 1。例如，```
1 1
1
0
```唯一的团队在 2 楼，因此将打印机放在 2 楼，表 1 给出了答案`0`， 不是`3`。 假设两个楼层都包含一个团队的粗心实施可能会错误地增加跨楼层成本。 

另一个边界情况是最后一桌的团队。 为了```
4 2
0001
0001
```将打印机放置在 1 楼第 1 号桌子上会带来极大的不便`4 + 2 + 1 = 7`，这是最优的。 另一层的术语使用最大的占用索引，而不是最小的索引，因为`i + k + p`增加与`i`。 使用错误的极端会低估答案。 

第三种情况是所选楼层的所有桌子都被占用时。 为了```
5 3
11111
11111
```如果打印机位于 1 楼第 1 号桌，则对面楼层有贡献`5 + 3 + 1 = 9`。 所选楼层也有团队这一事实不会改变跨楼层表达。 在同一公式内对称地处理两层楼会给出错误的结果。 

最后，在空闲的桌子上可以使用打印机。 为了```
5 7
00000
10001
```最佳打印机位置是 1 楼、第 3 桌，可提供最大同层距离`2`。 将打印机限制在已占用的桌子上会失去最佳效果。 

## 方法

 最直接的解决方案是尝试所有可能的打印机位置。 有`2n`选择，因为打印机可以放置在任一楼层的任何桌子上。 对于每个选择，我们检查每个已占用的桌子，使用同楼层或跨楼层公式计算其不便性，并保留最大值。 这是正确的，因为每个合法打印机的布局都被明确考虑，并且每个团队的贡献都被准确评估。 

成本是`O(n²)`。 在最坏的情况下有`2n`打印机位置最多`2n`占领的队伍，给予`4n²`评价。 在`n = 1000`，最多四百万次评估，因此这种暴力方法在规定的约束下实际上是可行的，尤其是在 C++ 中。 尽管如此，导出线性解还是有用的，因为如果表的数量增加，则需要相同的推理。 

关键的观察是，一旦打印机地板固定好，我们就不需要每个团队的位置。 对于印刷车间的团队来说，最大价值`|i - p|`完全由最左边和最右边占用的表决定。 如果这些职位是`L`和`R`，同层贡献为`max(p - L, R - p)`。 

对于对面楼层的团队，表达式为`i + k + p`，其增长为`i`成长。 因此，只有对面楼层最右边被占用的桌子才重要。 如果那个位置是`M`，整个对面楼层都有贡献`M + k + p`。 

因此对于固定的打印机地板和位置`p`，整组队伍最多折叠为三个数字：所选楼层的最左边和最右边的占据位置，以及另一层的最右边的占据位置。 

我们可以通过扫描每个输入字符串一次来获得这些极值。 之后，可以在恒定时间内评估每个可能的打印机位置。 只有`2n`位置，所以总运行时间是`O(n)`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 接受为`n <= 1000`，但不必要地昂贵|
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读两个楼层描述，并记住第二个输入字符串代表 2 楼，而第三个输入字符串代表 1 楼。打印答案时必须保留此映射。 
2. 对于每个楼层，找出其最左边的占用表、最右边的占用表、以及最右边的总体占用表。 当打印机位于该楼层时，需要前两个。 当该楼层是对面楼层时，需要最右边的位置。 
3.考虑将打印机放在一楼餐桌旁`p`。 如果 1 楼有团队，他们最大的不便是`max(p - L1, R1 - p)`。 如果 1 层是空的，则该贡献为零，因为没有团队可供考虑。 
4. 2楼的队伍都是通过楼梯到达的。 他们的不便在于`i + k + p`，对于第 2 层最右边的团队来说这是最大的。因此他们的贡献是`R2 + k + p`如果第 2 层非空，否则为零。 
5. 取这两个贡献中的最大值。 这给打印机位置带来了最大的不便`(1, p)`。 
6. 对每个重复相同的计算`p`从`1`通过`n`在 2 楼。当打印机位于 2 楼时，同楼层项使用 2 楼的极值，而跨楼层项使用 1 楼最右边的团队。 
7. 保持迄今为止所见的最大程度的不便。 仅当新值严格小于时才更新存储的答案。 由于任何最佳放置都是可以接受的，因此保留第一个达到最小值的放置就足够了。 
8. 打印出最不方便的地方，然后是楼层和桌号。 所有位置都保留为基于 1 的索引，与问题的编号相匹配。 

### 为什么它有效

 对于固定的打印机楼层，每个同一楼层的团队都会贡献一定的距离`p`。 在所有此类团队中，最大距离必须来自两个极端占用的桌子之一，因此整个同层组由其最小和最大位置精确表示。 每个对面楼层的球队都有贡献`i + k + p`，严格增加`i`，因此只有最右边的对面楼层团队才能确定最大值。 因此，为每个候选打印机位置评估的公式正是其真正的最大不便之处。 由于该算法评估每个可能的楼层和每个可能的桌子，因此它记录的最小值是全局最优值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    floor2 = input().strip()
    floor1 = input().strip()

    floors = [floor1, floor2]

    # For each floor:
    # left[i]  = leftmost occupied table, or 0 if empty
    # right[i] = rightmost occupied table, or 0 if empty
    left = [0, 0]
    right = [0, 0]

    for f in range(2):
        for pos, ch in enumerate(floors[f], 1):
            if ch == '1':
                if left[f] == 0:
                    left[f] = pos
                right[f] = pos

    best_value = 10**18
    best_floor = 1
    best_pos = 1

    for f in range(2):
        other = 1 - f

        for p in range(1, n + 1):
            same = 0
            if right[f] != 0:
                same = max(p - left[f], right[f] - p)

            other_floor = 0
            if right[other] != 0:
                other_floor = right[other] + k + p

            cur = max(same, other_floor)

            if cur < best_value:
                best_value = cur
                best_floor = f + 1
                best_pos = p

    print(best_value)
    print(best_floor, best_pos)

if __name__ == "__main__":
    solve()
```两个输入字符串被重新排序为`floors = [floor1, floor2]`这样索引`0`对应输出楼层1和索引`1`对应于输出楼层 2。这可以避免重复记住输入本身首先列出楼层 2。 

第一次扫描记录最左边和最右边占用的表。 当一个`1`第一次遇到，就变成`left[f]`; 每个占用的位置都被分配给`right[f]`，所以扫描后`right[f]`自动是最后占用的表。 

价值`0`用于表示空地板。 由于所有实表索引至少是`1`，它不能与有效的占用位置混淆。 针对零的检查可以防止空场地意外地在零号桌产生假队伍。 

对于候选打印机位置`p`,`same`被初始化为零。 如果所选楼层包含团队，则计算两个极限距离。 这两者中的最大值正是该楼层最严重的不便之处。 

对面楼层的贡献也初始化为零。 如果对面楼层至少有一支球队，则使用其最右边的位置`right[other] + k + p`。 不需要检查任何其他团队，因为每个较小的表索引产生的跨层不便较小。 

循环使用`range(1, n + 1)`， 所以`p`直接表示问题的基于一的表索引。 这可以避免打印答案时的差一转换。 Python 整数也可以轻松处理最大可能值，尽管这里的最大答案仅约为`2n + k`。 

严格比较`cur < best_value`故意保留遇到的第一个最佳位置。 这使得输出具有确定性，并且自然地生成第一个样本的打印机位置在第 1 层，第 1 桌。
