 ## 解决方案
 ## 问题理解

 灯笼以严格递增的坐标给出，因此它们的输入顺序已经是它们沿街道的顺序。 我们需要选择这些坐标中形成算术级数的最大子序列。 如果我们选择坐标 (a_1,a_2,\ldots,a_k)，则每个连续间隙必须相同。 任何选择一两个灯笼都会自动有效，因此有趣的部分从长度三开始。 

坐标可以大到 (10^{18})，这排除了依赖于坐标范围的方法。 然而，我们最多有 (n=3000) 个灯笼，因此 (O(n^2)) 算法是现实的。 当 (n=3000) 时，大约有 (n^2/2=4.5) 万对，这对于二次动态规划来说是合适的工作量。 (O(n^3)) 算法在自然实现中将执行大约 (3000^3/6=4.5) 十亿次内部迭代，远远超出了两秒的限制。 

坐标的严格增加也为我们提供了有用的排序属性。 如果(i<j)，则以(x_i,x_j)结尾的算术级数的公差为(x_j-x_i>0)。 它的前一个坐标（如果存在）必须是

 [
 x_i-(x_j-x_i)=2x_i-x_j。 
]

 因为 (2x_i-x_j<x_i)，前一个坐标必须具有较小的索引。 这使得每个状态仅依赖于已经计算的状态。 

有几种边缘情况可能会暴露出不正确的实现。 具有三个连续的坐标，例如```
3
1 2 3
```答案是 3，因为整个数组的间隙相等。 将每个级数初始化为长度 2 但在中间点存在时忘记扩展它的实现将错误地返回 2。 

第二种情况是```
5
1 2 4 6 7
```其答案是 3。坐标 (1,4,7) 形成算术级数，即使它们在输入中不连续。 仅检查连续灯笼的解决方案将错过这一点并返回 2。 

第三个问题是前任缺席的进展。 例如，```
3
1 2 4
```答案为 2。对于 (2,4) 对，所需的先前坐标将为 (0)，但该坐标不存在。 该对仍然是长度为 2 的有效级数，因此实现不得将丢失的前任视为错误。 

最后，坐标可能非常大。 像 (2x_i-x_j) 这样的表达式可以暂时离开区间 ([0,10^{18}])，因此必须将其作为整数处理，而不是依赖于通过坐标进行数组索引。 Python 整数具有任意精度，这使得这变得简单。 

## 方法

 一种直接的方法是选择一个级数的前两个灯笼，确定它们的差异，然后重复搜索具有相同差异的下一个坐标。 有 (O(n^2)) 个可能的起始对。 如果每对扫描剩余的坐标，最坏情况的迭代次数是

 [
 \sum_{i=0}^{n-1}\sum_{j=i+1}^{n-1}(n-j-1)=O(n^3),
 ]

 大约 (n^3/6) 或 45 亿次迭代 (n=3000)。 哈希集可以使每个单独的搜索时间恒定，但它不会消除第三个因素，因为每个起始对仍然可以生成长扫描。 

蛮力方法之所以有效，是因为一旦前两个坐标固定，整个算术级数就确定了。 问题在于它反复发现相同的后缀。 例如，如果几个不同的起始对最终到达同一对坐标（x_k，x_i），则所有这些都将独立地重做扩展该对所需的工作。 

关键的观察是，一对连续选定的坐标完全描述了我们未来扩展所需的状态。 对于 (i<j)，将 (dp[i][j]) 定义为最后两个选定坐标为 (x_i,x_j) 的算术级数的最大长度。 如果我们想向后扩展这个级数，它之前的坐标必须是(2x_i-x_j)。 这样的灯笼最多只有一个，因为所有坐标都是不同的。 

假设坐标存在于索引 (k<i) 处。 然后，通过将结束于(x_k,x_i)的级数加上(x_j)来获得结束于(x_i,x_j)的级数。 因此

 [
 dp[i][j]=dp[k][i]+1。 
]

 如果(2x_i-x_j)不存在，则(x_i,x_j)对仍然可以开始有效的级数，因此(dp[i][j]=2)。 

一旦坐标映射到索引，递归就会给出 (O(n^2)) 个状态和每个状态的恒定工作量。 通常的二维 Python 列表会浪费大量内存，因为数百万个 Python 整数对象和列表引用非常昂贵。 由于答案最多为 3000，因此每个 DP 值都适合一个无符号 16 位整数。 我们可以将所有三角 DP 状态存储在`array('H')`，将 DP 存储空间减少到大约 9 MB。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(n^3)) | (O(n)) | (O(n)) | 太慢了 |
 | 最佳| (O(n^2)) | (O(n^2)) 打包成 16 位值 | 已接受 |

 ## 算法演练

 1. 按照给定的排序顺序存储坐标，并构建一个字典，将每个坐标映射到其索引。 该字典让我们可以确定所需的前驱 (2x_i-x_j) 是否存在于恒定的预期时间内。 
2. 为每一对 (i<j) 分配一个打包的 DP 条目。 我们只需要三角存储，因为 (i\ge j) 的状态没有意义，每个值最多 (n\le3000)，所以一个无符号 16 位整数就足够了。 
3. 从左到右处理第一个索引 (i)，对于每个 (j>i)，考虑对 (x_i,x_j)。 该对的每个前驱都必须有一个小于 (i) 的索引，因此已经计算了递归所需的状态。 
4. 计算所需的前驱坐标为 (p=2x_i-x_j)。 如果 (p) 存在于索引 (k) 处，则读取已计算的状态 (dp[k][i]) 并设置

 [
 dp[i][j]=dp[k][i]+1。 
]

 这一步背后的算术恒等式正是等间隙条件。 如果从(x_k)到(x_i)的间隙等于从(x_i)到(x_j)的间隙，则(x_k=2x_i-x_j)。 

1. 如果(p)不存在，则设置(dp[i][j]=2)。 任何一对灯笼都是有效的，无论其距离如何，因此每对灯笼都提供至少两个长度的级数。 
2. 用看到的最大 DP 值更新全局答案。 由于 (n\ge3)，答案始终至少为 2，并且如果存在有效的三个或更多级数，则递归记录其完整长度。 

为什么它有效：不变量是在处理一对 (i,j) 之后，`dp[i,j]`正是最长的等差级数，其最后两个坐标为(x_i,x_j)。 如果所需的前驱 (2x_i-x_j) 存在，则每个以 (i,j) 结尾的级数都必须使用该唯一的前级，因此扩展以 (k,i) 结尾的最佳级数会给出最优值。 如果前一个不存在，则至少为 3 的长度级数不能在 (i,j) 处结束，从而使该对本身成为最佳长度 2。由于每个可能的算术级数都有一些最终对，因此在所有对中取最大值即可给出全局最优值。 

## Python 解决方案```python
import sys
from array import array

input = sys.stdin.readline

def solve():
    n = int(input())
    x = list(map(int, input().split()))

    pos = {value: i for i, value in enumerate(x)}

    # For row i, store dp[i][i+1], dp[i][i+2], ..., dp[i][n-1].
    # Number of stored pairs is n * (n - 1) // 2.
    total = n * (n - 1) // 2
    dp = array('H', [0]) * total

    # base[i] is the first position belonging to row i.
    base = [0] * n
    for i in range(1, n):
        base[i] = base[i - 1] + (n - i)

    def index(i, j):
        return base[i] + (j - i - 1)

    ans = 2

    for i in range(n - 1):
        xi = x[i]

        for j in range(i + 1, n):
            previous = 2 * xi - x[j]
            k = pos.get(previous)

            if k is not None:
                length = dp[index(k, i)] + 1
            else:
                length = 2

            dp[index(i, j)] = length

            if length > ans:
                ans = length

    print(ans)

if __name__ == "__main__":
    solve()
```首先构建坐标字典，因此前驱查找不需要对每对进行二分搜索。 由于坐标不同，`pos.get(previous)`返回唯一的前驱索引或`None`。 

三角形的DP布局值得关注。 排`i`仅包含对`(i, i+1)`通过`(i, n-1)`。 它的起始位置是

 [
 \text{base}[i]=\sum_{r=0}^{i-1}(n-r-1)。 
]

 然后递归映射`(i,j)`到`base[i] + (j-i-1)`。 需要减一，因为行中第一个存储的对`i`是`(i,i+1)`。 

重现内容如下`dp[index(k, i)]`， 不是`dp[index(i, k)]`，因为级数是按坐标和 (k<i) 排序的。 只要前驱存在，前驱计算就会自动保证此排序。 

DP 值存储在无符号 16 位数组中。 最大可能的级数长度为 3000，远低于 65535。这避免了数百万个 Python 整数的内存开销。 Python 的整数算术还可以处理 (10^{18}) 附近的坐标而不会溢出。 

三灯笼没有特殊情况。 当所需的前驱存在时，对递归自然地将长度为 2 的状态更改为长度 3，因此样本`1 2 3`产生 3 ，无需单独的逻辑。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | (O(n^2)) | 每对 (i<j) 都会处理一次，并进行恒定的预期时间字典工作。 |
 | 空间| (O(n^2)) | 有 (n(n-1)/2) 个 DP 状态，存储为 16 位整数，加上坐标字典和索引数组。 |

 ## 边缘情况

 第一个边缘情况是最小的可能输入。 和```
3
1 2 3
```这对`(1,2)`初始化为长度2。当算法达到`(2,3)`，它计算 (2\cdot2-3=1)，找到坐标 1，并读取 length-2 状态`(1,2)`。 它产生(2+1=3)，所以最终答案是3。没有特殊处理`n=3`是必须的。 

第二个边缘情况是一对没有前任的情况。 为了```
3
1 2 4
```这对`(2,4)`需要坐标 (2\cdot2-4=0)。 由于 0 不存在，算法将长度 2 分配给该对。 这对`(1,2)`长度也为 2，并且没有状态达到长度 3。输出为 2。 

第三种边缘情况是隐藏在不相关坐标中的进展。 为了```
7
1 2 4 7 10 13 20
```坐标`1, 4, 7, 10`形成有差异的级数 3. 加工时`(7,10)`，前身为 4，因此状态扩展`1,4,7`到`1,4,7,10`。 答案变成 4。这捕获了仅检查相邻输入元素的实现。 

第四种边缘情况使用最大的合法坐标值：```
5
0 250000000000000000 500000000000000000 750000000000000000 1000000000000000000
```每个间隙都是 (250000000000000000)，所以答案是 5。前面的计算重复产生大到 (10^{18}) 的值，Python 会准确处理它们。 

请求的全平等情况，例如```
3
5 5 5
```在有效的测试中不会发生，因为该问题保证严格增加坐标。 字典和 DP 是围绕该保证设计的，因此这种格式错误的输入被故意排除在可执行断言之外，而不是假装它是合法测试。
