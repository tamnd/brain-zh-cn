 ## 解决方案
 ## 问题理解

 我们在一条路上有一个起点，在远离那条路的地方有一个目的地。 起点与终点之间的直线距离为`s`，而从目的地到道路的垂直距离为`h`。 汽车可以沿着道路高速行驶`v`并快速穿过地形`u`。 

预定路线由两部分组成。 首先，汽车行驶一段距离`x`沿着路。 然后它离开道路，直接驶向目的地。 我们需要找到的值`x`从而最大限度地减少总旅行时间。 

输入包含四个整数`s`,`h`,`u`， 和`v`。 这里`s`是从起点到目的地的直接距离，`h`是目的地距道路的垂直距离，`u`是地形速度，并且`v`是道路速度。 输出的是最优距离`x`沿着路行驶。 

所有值都可以大到`10^9`。 这立即排除了依赖于迭代每个可能的整数距离的算法，因为可能有多达十亿个候选者。 时间限制只有0.5秒，即使是几亿次简单的操作也远远超出了合理范围。 我们需要一个恒定时间或对数时间的数学解决方案。 

有几种边界情况很容易破坏粗心的实现。 如果道路速度不比地形快，汽车应立即离开。 例如，与`1 1 10 10`，目的地在道路上的投影位于起点，因此正确答案是`0.0`。 一个盲目除以的公式`sqrt(v^2-u^2)`将除以零。 

当道路速度更快但不足以证明达到垂直投影时，会出现另一种边界情况。 例如，`5000 3000 20 25`给出了正确答案`0.0`。 这里，道路速度恰好处于最佳转弯点为起点的阈值处。 假设内部最优而不检查其位置的公式可能会产生负距离。 

相反的情况是实际的内部优化。 为了`5000 3000 15 25`，直接投影为`4000`距起点米。 最优的转折点是`1750`沿路数米，所以答案是`1750.0`。 这个案例很有用，因为它证实了立即出发或一路行驶到投影位置都不是最佳选择。 

## 方法

 一种简单的方法是考虑每个可能的整数距离`x`从`0`到投影点并计算相应的行程时间。 如果投影几乎`10^9`米远，这意味着大约`10^9`平方根和几个算术运算的评估。 除了对于 0.5 秒的限制来说太慢之外，仅检查整数值也无法满足要求`10^-9`当真正的最优值是非整数时的精度。 

蛮力方法之所以有效，是因为每个候选转折点都可以独立评估。 问题是候选人太多了。 关键的观察是，几何给我们提供了一个非常简单的单变量函数，并且可以通过分析找到其最小值。 

让`a`是沿道路从起点到目的地的垂直投影的距离。 由于直接距离是`s`垂直距离是`h`，直角三角形给出`a = sqrt(s^2 - h^2)`。 

如果汽车行驶`x`米，剩余地形距离为`sqrt((a - x)^2 + h^2)`。 

因此总行程时间为`T(x) = x / v + sqrt((a - x)^2 + h^2) / u`。 

该函数在相关区间上是凸函数，因此最多可以有一个内部最小值。 微分给出`T'(x) = 1/v - (a - x) / (u * sqrt((a - x)^2 + h^2))`。 

对于内部最优，导数必须为零。 解这个方程给出了精确的转折点。 可以根据边界检查结果表达式`x = 0`。 如果计算出的点位于起点之前，则实际的最佳值就是`0`。 

蛮力之所以有效，是因为它评估我们在数学上优化的相同旅行时间函数，但当候选距离的数量变得巨大时，它就会失败。 导数具有封闭形式零的观察结果将整个问题简化为恒定数量的算术运算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 |---|---|---|---|
 | 蛮力 | O(s) | O(1) | O(1) | 太慢了|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算距离`a`从起点到目的地在道路上的垂直投影，使用`a = sqrt(s^2 - h^2)`。 这会将原始几何图形转换为直角三角形，并为我们提供投影的一维坐标。 

2.如果`v <= u`， 输出`0`。 在道路上行驶并不比在地形中行驶快，因此沿着道路远离起点并不能改善路线。 

3.为了`v > u`，求解距离的导数方程`y = a - x`从转折点到投影。 将导数设置为零给出`y / sqrt(y^2 + h^2) = u / v`。 

收益率的平方和重新排列`y = h * u / sqrt(v^2 - u^2)`。 

表达式为正，因为该分支有`v > u`。 

4. 转换`y`使用返回所需的道路距离`x = a - y`。 

5.如果`x < 0`， 输出`0`反而。 这意味着无约束最小值将位于起点之前，因此受约束最小值出现在边界处`x = 0`。 

6.否则输出`x`具有足够的精度。 蟒蛇的`float`足以满足所需`10^-9`这里的绝对或相对误差，打印 15 位小数可以提供足够的输出精度。 

其原理：总行程时间是转弯位置的凸函数。 它的导数是单调的，因此导数为零的内部点是唯一的内部最小值。 如果该点位于允许的区间之外，则凸性意味着最接近的边界是最佳的。 在这个问题中，唯一可以成为最优的相关边界是`x = 0`，而另一个边界`x = a`不能更好，因为稍微远离`a`每当向起点行驶时，都会用更快的道路行驶代替缓慢的地形行驶`v > u`。 因此，该算法要么返回唯一的驻点，要么返回正确的边界点。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    s, h, u, v = map(int, input().split())

    # Distance from the starting point to the perpendicular
    # projection of the destination onto the road.
    a = math.sqrt(float(s) * s - float(h) * h)

    # If the road is not faster than the terrain, leaving immediately
    # is optimal.
    if v <= u:
        print("0.0")
        return

    # y is the distance from the turning point to the projection.
    y = h * u / math.sqrt(float(v) * v - float(u) * u)

    x = a - y

    # The unconstrained minimum can lie before the starting point.
    if x < 0.0:
        x = 0.0

    print("{:.15f}".format(x))

if __name__ == "__main__":
    solve()
```第一个计算获得直角三角形的水平边。 将其写为`float(s) * s - float(h) * h`在将潜在的大平方值转换为浮点之前避免依赖整数运算。 

这`v <= u`分支在涉及的公式之前处理`sqrt(v^2 - u^2)`。 这不仅仅是一个优化。 什么时候`v == u`，平方根为零，驻点公式未定义，而答案直接已知为零。 

为了`v > u`，代码计算`y`，这比更容易导出`x`本身。 从几何角度来说，`y`测量转折点距目的地投影的距离。 从中减去它`a`给出道路上实际行驶的距离。 

这`x < 0`check 处理数学驻点位于可行区间之外的情况。 不需要明确的`x > a`检查，因为公式给出`y > 0`， 所以`x = a - y`总是严格小于`a`。 

最大的中间整数平方大约是`10^18`。 Python 整数本身不会溢出，并且在乘法之前将操作数转换为浮点数使计算保持在正常的双精度范围内。 所需的答案容差与这些输入幅度的双精度兼容。 

## 工作示例

 对于示例 1，输入为`5000 3000 15 25`。 投影距离为`sqrt(5000^2 - 3000^2) = 4000`。 

道路比地形更快，因此可以实现内部优化。

 |---|---:|---:|---:|

 驻点在可行区间内，所以答案为`1750.0`，匹配样本。 该示例演示了真实的室内情况，既不直接穿过地形，也不停留在道路上，直到投影达到最佳状态。 

对于示例 2，输入为`5000 3000 20 25`。 再次，`a = 4000`，但现在速度正好达到阈值。 

| 步骤|`a`|`y`|`x`|

import sys
import io
import math

def solve_data(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    try:
        s, h, u, v = map(int, sys.stdin.readline().split())

        a = math.sqrt(float(s) * s - float(h) * h)

        if v <= u:
            x = 0.0
        else:
            y = h * u / math.sqrt(float(v) * v - float(u) * u)
            x = max(0.0, a - y)

    return solve_data(inp)

 ## 边缘情况

 当`h = s`，垂直投影正好位于起点，因为`sqrt(s^2 - h^2) = 0`。 例如，`1 1 1 1`立即采取`v <= u`分支和返回`0.0`。 即使道路更快，在到达投影之前也不会存在可用的正距离，因此零是唯一可能的最佳道路距离。 

什么时候`v = u`，道路和地形具有相同的速度。 例如，`100 80 50 50`进入`v <= u`分支和返回`0.0`。 粗心的实施评估`sqrt(v^2 - u^2)`尽管最佳答案很简单，但首先会获得零分母。 

什么时候`v > u`but the road advantage is insufficient, the stationary point lies outside the feasible interval. 考虑`5 4 4 5`。 这里`a = 3`， 和`y = 4 * 4 / sqrt(5^2 - 4^2) = 16 / 3`。 

因此`x = 3 - 16/3 < 0`，因此算法将其钳位为零。 无限制函数的数学最优值将位于起点之前，这意味着最佳可行的选择是立即离开道路。 

在零和正答案之间的阈值处，驻点恰好位于`x = 0`。 在样本 2 中，`5000 3000 20 25`给出`a = 4000`和`y = 4000`，精确地产生`x = 0`。 该算法不需要特殊的相等比较，因为正常公式已经给出了零。 

最后，非常大的值，例如`s = 10^9`产生周围的平方距离`10^18`。 Python 的整数表示安全地处理这些值，而最终计算使用双精度。 由于输出本身是一个实数`10^-9`容差，使用标准浮点运算就足以满足所需的精度。
