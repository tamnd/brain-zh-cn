 ## 解决方案
 ## 问题理解

 路线有一个值`k`。 如果乘客想通过`n`经停站，票价为`n`-th`k`- 目标数。 为了`k = 4`，这些是平方数，对于`k = 3`它们是三角形数，并且较大的值`k`描述具有更多边的正多边形图形。 

输入包含两个整数，`n`和`k`。 这里`n`是乘客想要出行的停靠站数量，以及`k`确定路线使用哪个多边形编号序列。 我们需要输出`n`-th`k`- 目标数。 

关键公式为`n`第 - 个多边形数是

 [
 P_k(n)=\frac{(k-2)n^2-(k-4)n}{2}。 
]

 约束条件允许`n`达到 (10^8) 并且`k`达到`100`。 输入仅包含一对值，因此预期的解决方案不应依赖于`n`。 每次停止运行一次的循环已经需要最多 (10^8) 次迭代，这在 0.5 秒限制下是不必要的昂贵。 该公式只需少量算术运算即可给出常数时间解。 

有两种边界情况很容易处理不当。 第一的，`n = 0`必须产生零。 例如，输入`0 4`有输出`0`。 假设多边形编号从以下位置开始的公式或实现`n = 1`并执行一些特殊的初始化可能会意外返回`1`。 

其次，除法必须在分子形成之后进行。 例如，`4 5`给出

 # \frac{48-4}{2}

 1.

 ]

 使用不正确的三角数公式或删除线性项的粗心实现会产生错误的值。 方形情况提供了另一个有用的检查：`4 4`产生 (4^2=16)。 

## 方法

 一种直接的方法是逐层构建多边形图形。 第一个多边形数是`1`，并且每个后续层添加由下式确定的多个点`k`和当前层。 这是正确的，因为多边形数是通过添加连续的几何层来精确定义的。 

问题是这样的模拟需要对每个值进行一次迭代，直到`n`。 和`n = 10^8`，最坏的情况是 (10^8) 次迭代。 在 Python 中，这远远超出了 0.5 秒竞赛限制所能合理允许的范围，即使在更快的语言中，它也能解决具有封闭式表达式的问题。 

有用的观察是层大小形成算术级数。 对于一个`k`- 角序列，从一项到下一项的增加是

 [
 (k-2)n-(k-3)。 
]

 从 (P_k(1)=1) 开始，对这些算术增量求和，给出二次表达式`n`。 对总和进行化简后，我们得到

 [
 P_k(n)=\frac{(k-2)n^2-(k-4)n}{2}。 
]

 蛮力方法之所以有效，是因为它显式执行此求和，但在以下情况下会失败：`n`很大。 封闭形式以代数方式执行相同的求和，将整个计算减少到恒定时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n) | O(1) | O(1) | 太慢了|
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`和`k`。 它们完全确定所请求的多边形数量，因此不需要额外的数据结构。 
2. 计算分子

 [
 (k-2)n^2-(k-4)n。 
]

 这是通过对层大小的算术级数求和而获得的标准闭合形式。 
3. 将分子除以`2`并打印结果。 多边形数是整数，因此除法是精确的。 

### 为什么它有效

 的`k`-gonal序列以(P_k(1)=1)开始，其连续差形成算术级数

 [
 k-2,\ 2(k-2)-(k-4),\ 3(k-2)-(k-4),\ldots
 ]

 这简化为

 [
 (k-2)n-(k-3)。 
]

 总结从第一项到第一项的这些差异`n`- 第一项给出

 # \frac{n((k-2)n-(k-4))}{2}

 \frac{(k-2)n^2-(k-4)n}{2}。 
]

 该算法准确地评估了这个数学定义，因此打印的值是每个有效票价所需的票价`n`和`k`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

answer = ((k - 2) * n * n - (k - 4) * n) // 2
print(answer)
```第一行读取唯一的输入对。 没有可迭代的测试用例，因为该语句恰好提供了一个`n`和一个`k`。 

该表达式直接遵循闭合形式。 计算`n * n`乘以之前`k - 2`保持与公式的对应关系清晰。 Python 整数具有任意精度，因此即使在最大输入大小下也不存在溢出问题。 

这`// 2`操作是安全的，因为整数的分子总是偶数`n`和`k`。 使用整数除法还可以保证输出打印为整数而不是浮点值。 

案例`n = 0`不需要特殊的分支。 分子中的两项都包含`n`，因此表达式的计算结果自然为零。 

## 工作示例

 对于第一个样本，`n = 4`和`k = 4`。 值为`4`表示平方数，因此预期结果为 (4^2=16)。 

| 步骤|`n`|`k`|`(k - 2) * n * n`|`(k - 4) * n`| 分子| 回答 |
 | --- | --- | --- | --- | --- | --- | --- |
 | 1 | 4 | 4 | 32 | 32 0 | 32 | 32 16 | 16

 当以下情况时，公式简化为 (2n^2/2=n^2)`k = 4`，确认一般公式与普通平方一致。 

对于第二个样本，`n = 4`和`k = 5`。 这些是五边形数。 

| 步骤|`n`|`k`|`(k - 2) * n * n`|`(k - 4) * n`| 分子| 回答 |

 | 1 | 4 | 5 | 48 | 48 4 | 44 | 44 22 | 22

 结果是`22`，第四个五边形数。 相同的计算还表明了为什么线性校正项涉及`k - 4`不能省略。
