 ## 问题理解

 给定两个素数 (p) 和 (q)，需要判断是否

 [
 (p+1)^q
 ]

 是一个完美的正方形。 这些数字最多可以包含（1000）个十进制数字，因此它们远远超出了普通机器整数类型。 所需的输出是`YES`当表达式是自然数的平方时，并且`NO`否则。 

决定性的属性是指数 (q)。 由于 (q) 是素数，因此它要么是 (2)，要么是奇素数。 当 (q=2) 时，表达式就是 ((p+1)^2)，它始终是完全平方数。 当 (q) 为奇数时，将数字提高到 (q) 次方不会改变其因式分解中的每个素数指数是否为偶数。 因此，当 (p+1) 本身是一个正方形时，((p+1)^q) 也是一个正方形。 

剩下的问题就简单多了，因为 (p) 也是素数。 假设(p+1=k^2)。 然后

 [
 p=k^2-1=(k-1)(k+1)。 
]

 由于 (p) 是素数，因此该乘积只能有一个因子等于 (1)。 因此(k-1=1)，给出(k=2)和(p=3)。 因此对于每个奇素数 (q)，答案是`YES`恰好在 (p=3) 时。 

(10^{1000}) 的巨大上限完全改变了实现策略。 我们无法将输入转换为 64 位整数，并且构造 ((p+1)^q) 是没有希望的，因为它的位数本身就非常巨大。 即使对该值进行通用的完全平方检验也需要操作一个天文数字般的大整数。 数学归约让我们避免了所有涉及巨大幂的算术。 我们只需要将十进制输入字符串与`2`和`3`，所花费的时间与输入长度成正比。 

有一些边界情况可以仅根据语句的代数来欺骗实现。 例如，与```
3
2
```答案是`YES`，因为 ((3+1)^2=16)。 首先检查 (p+1) 是否为平方的解决方案会错误地拒绝这种情况，因为特殊指数 (q=2) 使每个基数都有效。 

为了```
2
3
```答案是`NO`。 这里 (q) 是奇数，因此 (p+1=3) 本身必须是正方形，但事实并非如此。 将每个奇数指数视为产生平方的解决方案在这里将失败。 

为了```
3
3
```答案是`YES`，因为 (p+1=4) 是一个平方，并且平方的奇次幂仍然是平方。 该案例验证了表征的第二个分支。 

该声明表示输入是质数，因此诸如`0`和`1`尽管出现在数字范围内，但仍在有效的数学域之外。 该解决方案依赖于素数条件，不需要将此类值作为有效测试用例进行处理。 

## 方法

 直接的方法是构造 ((p+1)^q) 并测试结果是否是正方形。 这在数学上是正确的，但它完全忽略了问题的结构。 当输入最多具有 (1000) 个数字时，(q) 可以约为 (10^{1000})。 即使在概念上执行 (q) 乘法也大约需要 (10^{1000}) 次运算，并且得到的数字具有天文数字。 这种方法不仅对于（0.5）秒的限制来说太慢，而且是不可行的。 

稍微不那么直接的暴力方法可以尝试通过枚举可能的根来确定 (p+1) 是否是平方。 在最坏的情况下，(p) 约为 (10^{1000})，因此根约为 (10^{500})，大致给出 (10^{500}) 个候选。 那同样是不可能的。 

有用的观察是指数是素数。 每个素数要么是 (2) 要么是奇数。 情况 (q=2) 立即给出一个正方形。 对于奇数 (q)，考虑 (p+1) 的素因数分解。 如果质因数与指数 (e) 一起出现，则它会与指数 (eq) 一起出现在 ((p+1)^q) 中。 由于 (q) 是奇数，因此当 (e) 是偶数时，(eq) 也是偶数。 因此，当 (p+1) 已经是平方时，幂就是平方。 

现在使用 (p) 是素数这一事实。 如果(p+1=k^2)，则(p=(k-1)(k+1))。 素数不能表示为两个大于 (1) 的整数的乘积，因此 (k-1=1)，这会强制 (p=3)。 

因此，整个问题归结为两个字符串比较。 如果 (q=2)，则打印`YES`。 否则，因为 (q) 是奇素数，所以打印`YES`恰好在 (p=3) 时。

 | 最佳 | (O( | p | + | q | )) | (O( | p | + | q | )) | 已接受 |

 ## 算法演练

 1. 将 (p) 和 (q) 作为字符串读取，而不是将它们转换为普通整数。 它们的值可能包含（1000）位数字，而算法只需将它们与小常数（2）和（3）进行比较。 
2. 检查是否(q=2)。 如果是，则输出`YES`立即因为
 [
 (p+1)^2
 ]
 是每个可能的 (p) 的平方。 
3. 如果 (q\neq2)，则 (q) 是奇素数。 对于奇数指数，当 (p+1) 是平方时，((p+1)^q) 也是平方。 
4. 假设(p+1=k^2)。 由于 (p) 是素数，
 [
 p=k^2-1=(k-1)(k+1)。 
]
 唯一可能的素值出现在 (k=2) 处，给出 (p=3)。 
5.检查是否(p=3)。 如果是，则输出`YES`; 否则输出`NO`。 

关键的不变量是，在第一个分支之后，(q) 已知为奇数，因此 ((p+1)^q) 的平方状态正是 (p+1) 的平方状态。 (p) 的素数将该条件简化为单一可能性 (p=3)。 每个可能的有效输入都属于这两个分支之一，因此没有其他情况可以产生`YES`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    p = input().strip()
    q = input().strip()

    if q == "2" or p == "3":
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```输入保留为字符串，因为此解决方案不需要将千位数字值转换为机器整数。 Python 也可以处理任意大的整数，但使用字符串可以使预期的复杂性变得明确，并避免任何乘法或求幂。 

第一个比较处理异常质数指数 (2)。 此处不需要 (p) 上的条件，因为整个表达式的形式为 (x^2)。 

如果比较失败，则根据问题的保证，(q) 是奇素数。 在这种情况下，导致平方的 (p) 的唯一可能值是 (3)，因此第二个比较就足够了。 

不存在溢出问题，因为程序从不计算 (p+1)、从不计算幂、也从不构造平方根。 最大的操作是比较长度最多为 (1000) 的两个字符串。

 ## 边缘情况

 第一个非显而易见的情况是（q=2）。 用于输入```
2
2
```该算法立即看到`q == "2"`和打印`YES`。 表达式为(3^2=9)。 更一般地，该分支接受每个有效素数 (p)，因此必须在应用奇数指数参数之前对其进行检查。 

第二种情况是 (p=2) 具有奇数质数指数：```
2
3
```这里 (q) 是奇数且 (p+1=3)。 该算法跳过 (q=2) 分支，然后检查`p == "3"`，这是假的，并打印`NO`。 从代数上来说，(3^3=27)，它不是一个正方形。 

第三种情况是奇数 (q) 的唯一正情况：```
3
3
```第一次比较失败，但是`p == "3"`成功了。 算法打印`YES`。 事实上，(p+1=4=2^2) 和 (4^3=64=8^2)。 

最后的边缘情况涉及巨大的数字界限。 假设 (p) 有 (1000) 个数字且 (q=2)。 该程序不计算 (p+1) 或 ((p+1)^2)。 它只比较字符串`q`和`"2"`，所以它可以立即返回`YES`。 同样，对于一个巨大的素数 (p) 和一个奇数 (q)，它只检查 (p) 的完整输入字符串是否恰好是`"3"`。 这避免了直接计算表达式可能导致的溢出、内存增长和运行时间。
