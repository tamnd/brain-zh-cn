 ## 解决方案
 ## 问题理解

 我们得到了一系列金属类型。 每种金属都有一个确定性规则：如果我们拿走一种金属的一个单位，我们就可以摧毁它并获得其他两种金属各一个单位。 这定义了一个有向变换系统，其中每个节点分裂成两个传出边。 

我们还有一些金属的初始库存。 目标是以任意顺序多次应用这些转换规则，并最大限度地提高我们最终可以生产的特定目标金属（通常是“铅”（金属 1））的数量。 

关键的观察结果是，每次操作都会保留总质量，只是重新分配它。 因此，问题不在于累积数量，而在于通过有向系统路由现有单元，直到它们最终到达金属 1 或卡在图表中无法到达的部分。 

Code Jam 类型问题的 D2 版本中的约束通常涉及最多 2×10^5 金属或变换，这会立即排除任何重复变换的模拟。 即使单个单元也可能遍历长链或循环，因此任何逐步传播都太慢。 

一种简单的解释是独立地模拟每个单元，重复应用转换规则，直到不再发生任何变化。 在最坏的情况下，单个单元每次操作可能遍历 O(n) 个状态，并且可能有 O(n) 个单元，从而给出 O(n^2) 或更糟糕的行为，这是不可行的。 

当循环存在时，会出现更微妙的故障情况。 例如，如果金属 A 产生 B 和 C，并且 B 和 C 最终都可以再次产生 A，则除非仔细控制，否则朴素模拟可能会永远循环而不会得出稳定的结论。 

正确的输出是最终可以转化为金属 1 的初始金属总量。 

## 方法

 蛮力的想法是从每个单元开始独立地模拟转换。 每次我们获取一种金属时，我们都会用它的两个输出替换它，并继续，直到达到金属 1 或耗尽可能性。 这在原则上是正确的，因为它探索了所有可能的转换路径。 

然而，每个单元都可以分支，并且对重叠子问题的重复探索会导致指数爆炸。 如果一种金属可以反复转化为另两种金属，那么状态空间就会像二叉树一样增长。 即使有记忆，循环也会破坏简单的递归。 

关键的结构见解是，我们并不关心金属如何变成铅，只关心它是否可以变成铅。 由于每个变换都保留了在可达状态之间任意分割质量的能力，因此问题会分解为有向图中的可达性。 

一旦我们将每个金属解释为一个节点，并将每个变换解释为两个有向边，任务就变成了识别可以到达节点 1 的所有节点。此类节点处的任何初始单元都为最终答案贡献了一个单元。 

循环对于价值传播不再重要，因为可达性在循环下是不变的。 强连接组件可以被压缩，生成的图是一个 DAG，其中可以使用节点 1 的反向 BFS 或 DFS 干净地计算可达性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力模拟 | 指数| O(n) | 太慢了|
 | 图可达性（反向 BFS / SCC）| O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 我们将系统建模为有向图，其中每种金属都指向它产生的两种金属。

1. 构建反向邻接表。 对于每个变换 i → (a, b)，我们在反转图中添加边 a → i 和 b → i。 使用这种反转是因为我们想要计算哪些节点最终可以到达金属 1。 
2. 从反转图中的节点1开始遍历。 我们访问的每个节点都代表一种金属，通过一些操作序列最终可以转变为金属 1。 
3. 使用BFS 或DFS 标记本次遍历期间所有可达节点。 每个被访问的节点都被确认将其全部初始数量贡献给最终答案。 
4. 对所有访问过的节点的初始数量进行求和。 该总和是可实现的最大铅含量。 

我们反转边缘的原因是前向模拟回答“我可以从这里生产什么”，而我们需要“我可以领先结束”。 逆向将问题转换为标准可达性。 

### 为什么它有效

 每次变换仅重新分配一个质量单位而不会造成损失。 因此，如果存在将金属 i 的单元转化为金属 1 的任何转化序列，则无论中间分支如何，该单元都可以完全路由到前导。 相反，如果不存在这样的路径，则任何转换序列都无法从该单元产生铅。 可达性恰好表征了此属性，因此标记可以到达节点 1 的所有节点可以捕获完整的解决方案空间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    
    # initial amounts of each metal (assumed from standard version)
    initial = list(map(int, input().split()))
    
    # each metal i produces (a, b)
    rev = [[] for _ in range(n)]
    
    for i in range(n):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        rev[a].append(i)
        rev[b].append(i)
    
    # BFS from lead (node 0)
    q = deque([0])
    vis = [False] * n
    vis[0] = True
    
    while q:
        u = q.popleft()
        for v in rev[u]:
            if not vis[v]:
                vis[v] = True
                q.append(v)
    
    ans = 0
    for i in range(n):
        if vis[i]:
            ans += initial[i]
    
    print(ans)

if __name__ == "__main__":
    solve()
```该实现直接反映了反向可达性的思想。 唯一微妙的部分是正确构建反转图：对于每个转换，我们反转边缘，以便我们可以向外传播“可以到达领先”信息。 

BFS 确保每个节点都被处理一次，从而防止循环组件中的冗余探索。 

## 工作示例

 ### 示例 1

 假设我们有三种金属，其中金属 1 是铅。 金属2可以转变为1和3，金属3可以转变为2和1。初始量为`[5, 3, 2]`。 

我们构建反向边并从节点 1 开始 BFS。 

| 步骤| 队列| 访问过 |
 | --- | --- | --- |
 | 开始| [1] | {1} |
 | 访问 1 | [2, 3] | {1,2,3} |
 | 访问 2 | [3] | {1,2,3} |
 | 访问 3 | []| {1,2,3} |

 所有节点都是可达的，所以答案是 5 + 3 + 2 = 10。 

这演示了循环如何折叠成单个可达区域。 

### 示例 2

 考虑金属 2 和 3 只在自身之间发生转变而永远不会达到 1 的情况。只有金属 1 是独立的。 

| 步骤| 队列| 访问过 |
 | --- | --- | --- |
 | 开始| [1] | {1} |
 | 结束 | []| {1} |

 只有金属 1 起作用，所以答案只是初始的[1]。 

这表明无论内部循环如何，无法访问的组件都没有任何贡献。

## 边缘情况

 关键的边缘情况是包含金属 1 的完全循环组件。在这种情况下，循环中的每个节点都必须标记为可达，因为它们中的任何一个最终都可以通过重复转换将质量路由到引导中。 

另一种边缘情况是断开的图，其中存在多个组件，但只有一个连接到金属 1。该算法自然会处理此问题，因为来自节点 1 的 BFS 永远不会进入其他组件。 

最后一个微妙的情况是自循环，即一种金属产生自身和另一种金属。 自环不影响可达性； 它们只是强化了节点保留在其自己的可到达组件中的事实。
