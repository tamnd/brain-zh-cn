 ## 解决方案
 ## 问题理解

 我们有一系列球，编号从 1 到$n$，每个都标有一个正整数。 对于每个长度的前缀$i$（$1 \le i \le n$），我们想要确定有多少个位置$j$如果我们根据以下规则重复合并相邻的球对，即较小的数字被较大的数字吸收（或者如果相等，则要么被吸收），并且被吸收的球被移除，则可以作为最后剩下的球生存下来。 硬版本修复$x=1$，所以我们总是从第一个球开始计算。 

主要的挑战在于，如果我们尝试简单地模拟所有操作，合并序列的数量可能会呈指数级增长。 和$n$最多$2 \cdot 10^5$和总和$n$在受相同阶数限制的所有测试用例中，任何比每个测试用例的线性或近线性更差的方法都将超过时间限制。 这立即排除了对所有可能合并的暴力模拟，因为减少的方法数量$i$球到一的组合增长。 

边缘情况包括所有数字都相等、严格递增或严格递减的序列。 例如，如果所有球都被标记为$1,1,1,1$，那么每个位置都有可能幸存，因为我们可以选择在每次合并时移除哪个球。 如果序列是严格递增的$1,2,3,4$，只有最后几个位置有足够的“力量”来生存，而粗心的贪婪实现可能会错误地计算出永远无法获胜的位置。 另一个微妙的情况是，当大量数字提前出现时：如果最左边的球很大，它可以吸收右边的所有东西，从而与均匀分布相比改变幸存位置的数量。 

理解这些模式是从蛮力转向有效方法的关键。 

## 方法

 暴力方法将迭代每个前缀$1 \dots i$，然后模拟所有可能的合并操作并跟踪哪些球可能是最后剩下的。 虽然这在理论上是正确的，但状态的数量$i$球呈指数分布（$O(2^{i})$），所以即使是很小的$i$像30已经是不可能的了。 

关键的观察是，只有当前面所有球的总和至少与该球一样大时，该球才能生存到最后。 更正式地说，当从右向左处理时，球位于位置$j$如果其右侧所有小球的总和不超过，则可以生存$a_j$。 一旦前缀总和超过$a_j$，任何合并序列都不能让它成为最后一个幸存的球。 

这导致从阵列末端向起点进行线性扫描，维持当前“可吸收”总数的运行总和。 任何值大于或等于该总和的球都将添加到可生存位置集中。 当我们添加可生存的球时，前缀和会增加，这体现了大数字可以吸收右侧较小数字的事实。 利用这个观察，我们可以计算$f(i)$为所有人$i$在一次向后传递中，然后将计数分配给每个相应的前缀长度。 这将复杂性从指数降低到线性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和顺序$a$。 自从$x=1$，我们将计算$f(i)$为所有人$i$从 1 到$n$。 
2. 初始化变量`current_sum`为零。 这将跟踪可能吸收先前球的球的累积总数。 
3.初始化一个数组`survivable`长度$n$带零。 这将记录球是否在该位置$j$可以因其前缀而生存。 
4. 从数组末尾（位置$n-1$) 朝向起点（位置 0）。 对于每个球：如果它的值$a[j]$大于或等于`current_sum`，将其标记为可生存（`survivable[j] = 1`）并添加$a[j]$到`current_sum`。 否则，它无法生存。 
5. 填充后`survivable`,初始化一个前缀数组`f`长度$n$带零。 从左到右遍历数组，维护迄今为止看到的存活球的累积计数。 将此计数分配给`f[i]`对于每个前缀$i+1$。 
6. 输出值`f`对于所有从以下位置开始的前缀$x=1$。 

为什么它有效：从右到左迭代可确保每个球只有在能够吸收其右侧可能合并的所有内容时才被认为是可生存的。 累积和不变量保证我们只计算可能最终成为某些合并序列中最后一个幸存元素的球。 一旦球未通过此检查，任何较早的球都无法从中受益，因此向后传球就足够了。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x = map(int, input().split())
    a = list(map(int, input().split()))
    
    survivable = [0] * n
    current_sum = 0
    for i in range(n-1, -1, -1):
        if a[i] >= current_sum:
            survivable[i] = 1
            current_sum += a[i]
    
    f = []
    count = 0
    for i in range(n):
        count += survivable[i]
        f.append(count)
    
    print(' '.join(map(str, f[x-1:])))
```该解决方案首先从右到左标记可生存的球，然后计算每个前缀的累积计数。 使用`current_sum`确保我们正确处理序列早期的大量数字可以吸收多个较小数字的情况。 由于循环从末尾开始，因此自然会处理最后一个球等边界条件。 使用`f[x-1:]`仅输出所需的前缀。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | 每个测试用例 O(n) | 每个数组都会被扫描两次：一次向后扫描用于生存标记，一次向前扫描用于前缀计数。 |
 | 空间| O(n) | 数组`survivable`和`f`长度`n`。 |

 鉴于总和$n$跨测试用例是$2 \cdot 10^5$，这种线性算法很容易适应 4 秒的时间限制和 512 MB 的内存。
