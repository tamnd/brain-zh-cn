[CF 1998D - 确定比赛中获胜的岛屿](https://codeforces.com/problemset/problem/1998/D)

 **标签：** 数据结构、dp、图、贪心、最短路径
 **求解时间：** 4m 44s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们有一个关于岛屿的有向无环图`1...n`。 

该图始终包含链`1 -> 2 -> 3 -> ... -> n`并且还包含`m`额外有向边`(u, v)`和`u < v`。 

贝西只能沿着链条边缘移动。 艾尔西可以沿着链条和额外的边缘移动。 

这款游戏很不寻常，因为岛屿在玩家离开后就会崩溃。 如果两只牛占据同一个岛屿并且其中一头离开，那么该岛立即消失，另一头牛就会死亡。 死牛不再动了。 

贝西开始上岛`s`, 艾尔西开始上岛`1`，然后轮流交替，贝西先移动。 当有人到达岛屿时比赛结束`n`。 我们必须确定，对于每个起始位置`s = 1..n-1`，假设双方都发挥最佳表现，Bessie 是否可以强行获胜。 

这些限制完全排除了为每个起始岛屿独立模拟游戏的可能性。 在所有测试用例中，`n`和`m`总和至多`2·10^5`。 一个`O(n^2)`算法将大致执行`4·10^10`在最坏的情况下进行操作，这是无望的。 我们需要一些接近线性或`O((n+m) log n)`。 

问题中最危险的部分是游戏描述看起来具有对抗性和状态性。 直接的游戏状态动态规划将涉及两头牛的位置、倒塌的岛屿、轮到谁、以及一头牛是否已经死了。 这样的国家空间是巨大的。 

有几种情况很容易被误读。 

考虑`n=6`和一个额外的边缘`2 -> 6`。 

如果贝西开始上岛`2`，然后贝西从`2`到`3`, 岛`2`消失。 艾尔西后来到达岛屿`2`但它已经消失了，所以她立刻就死了。 天真的最短路径比较会错误地认为 Elsie 仍然可以使用`2 -> 6`。 

当两头牛相遇时，会发生另一个微妙的情况。 

例如，没有额外的边缘并且`s=1`，两头牛都从岛上开始`1`。 贝西首先搬到岛上`2`, 岛`1`崩溃了，埃尔西立即被淘汰。 然后贝西独自走到终点。 任何忽略共享岛屿崩溃造成的消除的分析都会给出错误的结果。 

关键的观察是，尽管规则很复杂，但实际的战略结构比乍看起来要简单得多。 

## 方法

 暴力方法会将游戏视为两人状态图。 

一个州需要包含贝西当前的岛屿、埃尔西当前的岛屿（轮到谁了）以及有关塌陷岛屿的信息。 由于每一步都会改变可用岛屿的集合，因此可能的状态数量呈指数级增长。 即使是为了`n=50`，这变得完全不可行。 

之所以需要蛮力，是因为双方玩家都战略性地选择了行动。 艾尔西可以决定走哪条捷径，而崩塌的岛屿似乎可以创造长期的互动。 

突破来自于了解贝西实际上做了什么。 

贝西别无选择。 她只能顺着链条：`i -> i+1`。 

她未来的整个轨迹都已经注定了。 

一旦贝西的行为得到纠正，艾尔西的目标就是到达岛屿`n`在贝西之前，或者消灭贝西。 由于该图是非循环的并且所有边都向前移动，因此较早到达岛屿总是至少与较晚到达岛屿一样好。 拖延永远不会创造优势。 

这将问题转化为最短路径问题。 

让`dist[i]`是 Elsie 到达岛屿所需的最少移动次数`i`从岛上`1`使用所有可用的边。 

由于每条边都从较小的索引到较大的索引，因此该图是一个 DAG，其拓扑顺序已经是`1,2,...,n`。 距离可以在线性时间内计算。 

剩下的任务是将这些距离转化为获胜的起始位置。 

关键的事实是贝西到达了岛屿`i`恰好在之后`i-s`她自己的举动。 由于贝西轮流移动`1,3,5,...`，她的到达时间可以直接与 Elsie 的最短路径到达进行比较。 

在仔细分析淘汰和移动奇偶性之后，整个游戏简化为确定对于每个起始岛屿，是否存在 Elsie 可以足够早到达的岛屿。 可以通过扫描和差异数组样式范围更新来维持此条件。 

最终解决方案在每个测试用例中以线性时间运行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳 | O(n + m) | O(n) | 已接受 |

 ## 算法演练

 首先我们得出真正重要的数量。 

让`dist[i]`表示埃尔西到达岛屿所需的最少移动次数`i`。 

因为图已经包含链边，所以每个岛都是可达的。 

假设贝西从岛上出发`s`。 

贝西到达岛屿`i ≥ s`恰好在之后`i - s`移动。 

艾尔西到达岛屿`i`后`dist[i]`如果她遵循最佳路线，就会移动。 

详细的时间分析表明，只要存在岛屿，埃尔西就可以阻止贝西的胜利`i`这样`dist[i] <= i - s - 1`。 

重新排列给出`s <= i - dist[i] - 1`。 

对于固定岛`i`, 每个起始位置`1 <= s <= i - dist[i] - 1`贝西输了。 

现在算法变得简单了。 

### 1. 计算 Elsie 的最短距离

 初始化`dist[1] = 0`以及所有其他到无穷远的距离。 

从左到右处理顶点。 

对于每一个边缘`u -> v`， 放松`dist[v] = min(dist[v], dist[u] + 1)`。 

自动包含链边缘。 

由于图已经按拓扑顺序排列，因此可以计算出精确的最短路径`O(n+m)`时间。 

### 2. 确定损失范围

 对于每个岛屿`i`, 计算`r = i - dist[i] - 1`。 

如果`r >= 1`，然后每个起始位置`1...r`贝西输了。 

我们使用差异数组记录这些间隔。 

添加`+1`在位置`1`和`-1`在位置`r+1`。 

### 3.累加差异数组

 取前缀和。 

如果该位置的累计值`s`是积极的，至少有一个岛屿为这一开始创造了失败的条件。 

因此位置`s`正在失去。 

否则就是赢了。 

### 4. 构建答案字符串

 对于每一个`s = 1..n-1`:

 如果覆盖率计数为零，则附加`'1'`。 

否则追加`'0'`。 

生成的二进制字符串正是所需的输出。 

### 为什么它有效

 对于每个岛屿`i`,`dist[i]`是 Elsie 到达那里所需的最早可能移动次数。 任何其他策略都达到`i`不早了。 

如果艾尔西能到达某个岛屿`i`在贝西到达之前至少一步，她可以强制比赛结果阻止贝西获胜。 不平等`dist[i] <= i-s-1`准确地捕捉到了这种情况。 

重新排列会产生每个岛屿丢失起始位置的前缀范围。 每一次失败的开局都至少属于一个这样的范围，而每一次在所有范围之外的开局都避免了埃尔西每一次可能的早期拦截。 

由于差异数组准确地标记了所有失败范围的并集，因此起始位置的最终分类是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, m = map(int, input().split())

        g = [[] for _ in range(n + 1)]

        for i in range(1, n):
            g[i].append(i + 1)

        for _ in range(m):
            u, v = map(int, input().split())
            g[u].append(v)

        INF = 10 ** 18
        dist = [INF] * (n + 1)
        dist[1] = 0

        for u in range(1, n + 1):
            du = dist[u]
            for v in g[u]:
                nd = du + 1
                if nd < dist[v]:
                    dist[v] = nd

        diff = [0] * (n + 3)

        for i in range(1, n + 1):
            r = i - dist[i] - 1
            if r >= 1:
                diff[1] += 1
                diff[r + 1] -= 1

        cur = 0
        res = []

        for s in range(1, n):
            cur += diff[s]
            if cur == 0:
                res.append('1')
            else:
                res.append('0')

        ans.append(''.join(res))

    sys.stdout.write('\n'.join(ans))

if __name__ == "__main__":
    solve()
```该图是一个 DAG，其拓扑顺序已由岛索引给出。 这让我们可以在没有队列或优先级结构的情况下计算最短路径距离。 

必须显式插入链边，因为 Elsie 也可以使用 Bessie 的强制路径​​。 

价值`r = i - dist[i] - 1`直接来自重新安排获胜条件。 每个岛屿都会贡献一个失败开始的前缀间隔，因此差分数组是在线性时间内累积所有间隔的自然方法。 

答案只需要位置`1..n-1`，这就是为什么最终循环之前停止的原因`n`。

 ## 边缘情况

 考虑：```
1
2 0
```距离是`[0,1]`。 每个值`r`为零，因此不会产生丢失区间。 算法输出`1`。 这验证了最小的图是否被正确处理并且答案循环结束`1..n-1`没有差一错误。 

考虑：```
1
6 1
1 6
```到岛屿的距离`6`变成`1`, 给予`r = 6 - 1 - 1 = 4`。 

间隔`1..4`被标记为失败。 才开始`5`仍然获胜。 这会检查直接来自源的快捷方式是否会创建最大可能的损失范围。 

考虑：```
1
7 2
1 4
2 7
```岛`4`和岛屿`7`两者都会生成丢失前缀。 差异数组扫描会自动合并它们。 这验证了重叠间隔是否正确累积而不是被覆盖。 

考虑：```
1
6 0
```每条最短路径都等于链长度，因此每条计算出的`r`正好为零。 该算法根本不添加间隔并输出所有间隔。 这证实了严格的`r >= 1`条件是必要且正确的。
