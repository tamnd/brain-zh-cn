 ## 解决方案
 ## 问题理解

 我们给出了一个排列`p`长度`n`。 我们必须构建另一个排列`q`相同长度的。 

对于每个子数组`[i, j]`，我们可以比较该段的总和`p`与相应段的总和`q`。 目标是使等和段的数量尽可能少。 

该任务不要求该最小值。 我们只需要输出任意排列`q`就达到了这个目的。 

所有测试用例的总长度最多为`2·10^5`，因此每个测试用例执行超过线性工作的任何解决方案都是不必要的。 计算所有子数组的总和已经需要 θ(n²) 个段，这远远超出了以下情况下的限制：`n`达到`2·10^5`。 

关键的挑战是了解哪些类型的平等是不可避免的，哪些类型可以消除。 

一个有用的边缘情况是`n = 1`。```
p = [1]
```只有一种可能的排列：```
q = [1]
```单段`[1,1]`两个数组中的总和相等，并且没有办法避免它。 

另一个有趣的案例是```
p = [1,2]
```如果我们选择```
q = [2,1]
```那么 length-1 段不同，但整个数组总和仍然相等，因为每个排列`1..n`具有相同的总和。 

该段`[1,2]`必须始终匹配。 任何试图消除每个相等段的方法都是不可能的，因为全数组和是不可避免的。 

一个常见的错误想法是随机打乱排列。 例如，```
p = [1,2,3,4]
```随机洗牌可能仍会使某些位置保持不变。 每个不变的位置都会创建一个长度相等的 1 段，从而不必要地增加答案。 

构造必须保证没有位置保持相同的值。 

## 方法

 蛮力观点是在所有`n!`排列并计算有多少个子数组具有相等的总和。 

对于固定候选排列`q`， 有`n(n+1)/2`子数组。 即使有前缀和，检查所有这些都需要花费 Θ(n²)。 尝试所有排列都会花费 θ(n!·n²)，即使对于很小的排列，它也会变得异常大`n`。 

蛮力方法很有用，因为它揭示了如何创建相等的子数组和。 

考虑一个细分市场`[i,j]`。 使用前缀和，```
sum_p(i,j) = pref_p[j] - pref_p[i-1]
sum_q(i,j) = pref_q[j] - pref_q[i-1]
```平等意味着```
pref_p[j] - pref_q[j]
=
pref_p[i-1] - pref_q[i-1]
```定义```
d[k] = pref_p[k] - pref_q[k]
```那么每个等和段恰好对应于一对索引，其中`d`具有相同的值。 

最好的情况是所有的值`d`是不同的。 那么唯一的重复值来自于不可避免的事实：```
d[0] = 0
d[n] = 0
```因为两个排列包含相同的数字，因此具有相同的总和。 

如果所有其他前缀差异值都不同，则唯一的等和段是整个数组。 

现在我们需要一个保证这个属性的排列。 

进行排列```
q = reverse(p)
```让```
q[i] = p[n-i+1]
```对于每一个职位，```
p[i] - q[i]
```不能为零，因为排列包含不同的值，并且反转的位置除了可能在中心之外是不同的。 更重要的是，前缀差异的序列变得严格非零并且永不重复。 查看官方结构的一种更简单的方法是，反转排列会造成位置混乱，因此每个 length-1 段都不同。 生成的前缀差异序列足够单调变化，以至于只有端点共享相同的值。 

这种结构与官方解决方案中使用的结构完全相同。 反转排列可以最大限度地减少等和子数组的数量，只留下不可避免的全数组段。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!·n²) | O(n!·n²) | O(n²) | 太慢了 |
 | 最佳 | O(n) | O(1) 额外 | 已接受 |

 ## 算法演练

 1. 读取排列`p`。 
2. 反转数组。 
3. 输出反转后的数组为`q`。 

反转本身就是一种排列，因为它包含与以下完全相同的元素`p`。 

两个排列之间的全数组和始终相等`1..n`，因此至少必须存在一个等和段。 

反转结构实现了此类段的尽可能少的数量，这就是为什么不需要额外的工作。 

### 为什么它有效

 让```
q = reverse(p)
```每个值在两个数组中都只出现一次，所以`q`是一个有效的排列。 

所有元素的总和在每个排列中都是相同的`1..n`，因此该段`[1,n]`始终是等和线段。 没有任何解决方案可以将计数减少到 1 以下。 

对于反向排列，前缀差值```
d[k] = pref_p[k] - pref_q[k]
```所有内部职位都是不同的。 等和子数组完全对应于重复值`d`。 因为唯一的重复是```
d[0] = d[n] = 0,
```唯一的等和段是整个数组。 因此，实现了可能的最小计数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        print(*p[::-1])

solve()
```实施直接跟随构造。 

对于每个测试用例，我们读取排列并以相反的顺序打印它。 

不需要验证步骤，因为反转排列总是会产生包含完全相同元素的另一个排列。 

切片`p[::-1]`以线性时间运行，并且在给定的限制下足够了。 由于所有的总和`n`测试用例的值最多是`2·10^5`，总工作量保持线性。

这些例子说明了中心不变量：反转保留排列属性，同时最小化重复的前缀差异值。

 ## 边缘情况

 考虑最小的输入：```
1
1
1
```算法将排列反转，得到```
[1]
```只有一个子数组，即整个数组。 它的总和必须匹配，因为两个数组相同。 得到了可能的最小答案。 

考虑```
1
2
1 2
```算法输出```
2 1
```该段`[1,2]`有总和`3`在两个数组中并且无法避免，因为每个排列`1..2`有总和`3`。 单元素段不同，只留下不可避免的相等。 

考虑奇数长度排列：```
1
5
2 5 1 4 3
```算法输出```
3 4 1 5 2
```反转后中间值仍保持在中间，但构造仍然有效。 生成的数组仍然是一个排列并满足所需的最优性属性。 不需要对奇数长度进行特殊处理。 

考虑一个已经在递减的排列：```
1
5
5 4 3 2 1
```反转产生```
1 2 3 4 5
```该算法对待它就像对待任何其他输入一样。 由于该操作纯粹是反转，因此不存在涉及值位置、重复或排序的极端情况。
