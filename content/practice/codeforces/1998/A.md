 ## 解决方案
 ## 问题理解

 我们给定一个目标中心点$(x_c, y_c)$和一个整数$k$。 任务不是优化任何内容或搜索特殊配置。 我们只需要准确构造$k$算术平均值恰好为的不同整数坐标点$(x_c, y_c)$。 

中心条件意味着：$$\frac{\sum x_i}{k} = x_c, \qquad \frac{\sum y_i}{k} = y_c$$等价地，$$\sum x_i = k \cdot x_c, \qquad \sum y_i = k \cdot y_c.$$每个生成点的坐标必须保持在$[-10^9,10^9]$，但给定的中心坐标仅在$-100$和$100$， 和$k \le 1000$。 与允许的坐标范围相比，这非常小，因此我们在构造点时有很大的自由度。 

所有的总和$k$跨测试用例的值最多是$1000$。 甚至一个$O(k)$每个测试用例的构建绰绰有余。 

主要危险是意外地产生重复点或产生平均值仅近似正确的点。 由于答案是建设性的，因此每个生成的点都必须完全满足中心方程。 

考虑$k=1$。 例如：```
10 10 1
```单个点唯一可能的中心就是该点本身，因此我们必须输出：```
10 10
```总是创建对称对的构造将会失败，因为没有可用的伙伴点。 

另一个微妙的情况很奇怪$k$。 

例如：```
0 0 3
```如果我们只输出一对对称：```
1 0
-1 0
```我们只有两点。 我们需要第三个不同的点，同时保持总和不变。 粗心的施工可能会增加$(0,0)$即使它重复现有点。 

最后，所有点都必须是明确的。 例如：```
0 0 2
```输出```
0 0
0 0
```具有正确的中心，但违反了独特性要求。 

## 方法

 蛮力思维是搜索任意整数点并反复检查它们的平均值是否等于所需的中心。 由于存在无限多个有效配置，因此这样的搜索最终会成功。 问题在于，对于搜索可能花费的时间没有有意义的上限，并且正确性变得难以保证。 

中心公式的结构提供了一种更简洁的方法。 如果两点围绕中心对称放置，$$(x_c-d, y_c)$$和$$(x_c+d, y_c),$$他们对坐标和的贡献是$$2x_c,\quad 2y_c.$$换句话说，该货币对的平均值已经恰好位于中心。 可以组合任意数量的此类对称对而不改变最终中心。 

这一观察立即表明了一种结构。 

如果$k$是偶数，创建$k/2$周围对称对$(x_c,y_c)$。 

如果$k$是奇数，首先放置中心点本身。 它的贡献正是$(x_c,y_c)$。 然后构建$(k-1)/2$围绕它的对称对。 

使用距离$1,2,3,\ldots$保证每个生成的点都是不同的。 

自从$k \le 1000$，我们使用的最大偏移量最多是$500$，因此所有坐标都保持在允许的范围内。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 无界| 无界| 不实用|
 | 最佳 | O(k) | O(1) 不包括输出 | 已接受 |

 ## 算法演练

 1. 阅读$x_c$,$y_c$， 和$k$。 
2. 创建一个空答案列表。 
3.如果$k$为奇数，添加中心点$(x_c,y_c)$到答案。 

该点恰好为总和贡献了中心的一份副本。 
4. 对于每个距离$d = 1,2,\ldots,\lfloor k/2 \rfloor$，添加两点：$$(x_c-d,\ y_c)$$和$$(x_c+d,\ y_c).$$5. 输出所有生成的点。 

### 为什么它有效

 每个生成的对都围绕中心对称。 它们的坐标之和为$$(x_c-d)+(x_c+d)=2x_c,$$和$$y_c+y_c=2y_c.$$因此每对都有平均数$(x_c,y_c)$。 

如果$k$是偶数，我们正好有$k/2$这样的对。 总坐标和变为$$kx_c,\quad ky_c,$$所以中心是正确的。 

如果$k$很奇怪，我们还包括$(x_c,y_c)$。 其余$k-1$点形成对称对，其总贡献为$$(k-1)x_c,\quad (k-1)y_c.$$添加中心点给出$$kx_c,\quad ky_c.$$所有距离都不同，因此没有两个生成的点重合。 因此，建筑总是产生$k$具有所需中心的不同整数坐标点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())

out = []

for _ in range(t):
    xc, yc, k = map(int, input().split())

    if k % 2 == 1:
        out.append(f"{xc} {yc}")

    for d in range(1, k // 2 + 1):
        out.append(f"{xc - d} {yc}")
        out.append(f"{xc + d} {yc}")

sys.stdout.write("\n".join(out))
```实施直接跟随构造。 

对于奇数$k$，首先发射中心点。 这可以处理未匹配的点，同时保留所需的平均值。 

该环路通过增加距中心的距离来生成对称对。 使用不同的距离可以自动保证不同的点。 由于最大距离最多为$500$，每个坐标都远离$\pm 10^9$限制。 

任何地方都没有出现浮点算术。 该证明完全依赖于精确的整数和，消除了任何精度问题。

 ## 边缘情况

 ### 边缘情况 1：$k=1$输入：```
10 10 1
```该算法输入奇数$k$分支和输出：```
10 10
```坐标总和是$(10,10)$，除以一即可得到所需的中心。 不需要对称对。 

### 边缘情况 2：小奇数$k$输入：```
0 0 3
```该算法输出：```
0 0
-1 0
1 0
```总和是：$$0 + (-1) + 1 = 0,$$

$$0 + 0 + 0 = 0.$$中心依然存在$(0,0)$，并且所有点都是不同的。 

### 边缘情况 3：最大值$k$输入：```
-100 100 1000
```使用的最大距离是$500$。 生成的 x 坐标范围为$$-100-500=-600$$到$$-100+500=400.$$这些值远远超出了允许的范围$\pm 10^9$。 由于每个距离都是唯一的，因此保留了独特性。
