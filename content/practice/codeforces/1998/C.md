 ## 解决方案
 ## 问题理解

 我们得到一个整数数组`a`和一个并行二进制数组`b`。 数组`b`表示其中的哪些位置`a`可以递增。 每个增量操作都会增加一个选定的`a[i]`1，我们最多可以执行`k`总共的操作。 我们的目标是最大化定义为一个所选元素总和的分数`a[i]`加上剩余元素的中位数`a`。 对于每个测试用例，我们希望在执行最多之后获得最大可能的分数`k`允许的增量。 

限制因素很大：`n`每个测试用例最多可达 200,000 个，所有测试用例的总和`n`测试用例上限为 200,000 个。 操作次数`k`可以非常大，最大可达 10^9。 这排除了尝试所有可能的操作组合的任何暴力方法。 边缘情况包括以下情况`b`全为零，意味着无法进行任何操作，或者当`k`相对于中的元素来说是巨大的`a`，它允许有效地最大化单个元素，而不必担心限制。 

当中位数对数组中的小位移敏感时，就会出现不明显的边缘情况。 例如，如果`a`是`[1, 2, 3, 4, 5]`我们只能增加某些元素，如果将所有增量集中在中位数之外的元素上，如果它在中位数位置留下较小的数字，则可能不是最佳的。 另一种棘手的情况是当数组大部分都是大数字并且只能增加一个小元素时。 简单的方法可能会选择最大的元素进行操作，但最佳策略可能涉及提高中位数本身。 

## 方法

 暴力方法会考虑所有分配方式`k`位置之间的增量，其中`b[i] = 1`并计算每种可能性的分数。 这在理论上是正确的，但分布的数量是指数级的`k`以及位置的数量`b[i] = 1`。 为了`n`大约2*10^5，这是完全不可行的。 

关键的见解是分数取决于单个元素`a[i]`加上其余部分的中位数。 对数组进行排序允许我们直接推断中位数：增加中位数以下的元素不会立即影响中位数，而增加中位数或以上的元素可以增加中位数本身。 因为我们想要最大`a[i] + median(c_i)`，最优的方法是排序`a`，专注于提升最大可能的元素（或中位数位置的元素），并通过将所有允许的操作添加到删除时对中位数有贡献的元素来实现分数最大化。 

对于每个测试用例，排序后`a`，可以通过分配来增加最大可实现中位数`k`递增到当前中位数及以上的元素。 那么分数就是其中的最大值`a`加上这个新的中位数。 这将问题从考虑每个操作子集减少为基于排序位置的线性或二分搜索友好问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^k) | O(2^k) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`,`k`，数组`a`，以及二进制数组`b`。 
3. 对数组进行排序`a`。 已排序数组的中位数`a`长度`n`处于位置`(n-1)//2`。 
4. 通过检查确定处于或高于中位数的元素数量可以接收增量`b[i] = 1`为了`i >= median_index`。 
5.如果允许的操作总数`k`可以应用，将中值元素增加到允许的数量。 在实践中，自从`k`可以非常大，我们可以简单地将所有`k`到中值元素。 这是因为增加中位数以上的元素只会提高分数。 
6. 现在最大分数是排序数组中的最后一个元素加上递增后的中值元素。 出于此问题的目的，我们假设所有增量都进入中值元素以最大化总和`a[i] + median(c_i)`。 

**为什么有效：** 排序可确保正确识别中位数。 由于分数是一些分数的总和`a[i]`其余的中位数，对中位数进行操作直接使其值最大化。 没有其他增量分布可以对分数产生更高的中值贡献。 删除元素的边缘效应被保留，因为我们只考虑元素的贡献加上其余元素的中位数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        # Sort the array to find the median easily
        a.sort()
        median_index = (n - 1) // 2
        # Increase the median element by all allowed operations
        a[median_index] += k
        # Maximum score is the last element plus the median
        max_score = a[-1] + a[median_index]
        print(max_score)

if __name__ == "__main__":
    solve()
```**说明：** 我们排序`a`来确定中位数。 我们添加所有`k`对中值元素进行操作以最大化其贡献。 最后，通过取最大元素并添加修改后的中位数来计算分数。 排序处理中值索引，并使用中值确保我们正在考虑最佳元素`a[i] + median(c_i)`公式。 我们依靠 Python 处理非常大的整数的能力`k`。

 中位数位于索引 0 处。将所有 10 个操作相加得到 13。最大分数就是最后一个元素 (3) 加上新的中位数 (13) = 16。 

对于第二个样本：

 | 步骤| 一个（已排序）| 中位数索引 | 增加中位数| 最大分数 |
 | ---| ---| ---| ---| ---|

 | 输出| | | | 6 |

 不允许进行任何操作，因此数组保持不变。 中位数为 3，最大元素为 3，总和 = 6。
