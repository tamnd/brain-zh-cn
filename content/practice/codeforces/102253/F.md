 ## 问题理解

 我们有两种排列，`a`在`n`职位和`b`在`m`价值观。 我们想要计算函数`f`分配每个位置`a`一个值来自`0`通过`m - 1`，遵循规则

 [
 f(i)=b(f(a_i))。 
]

 阅读这个方程的有用方法是沿着一个周期移动一次`a`强制的值`f`沿着一个循环移动`b`在相反的方向。 任务是计算每个周期结束时保持一致的所有分配。 答案以模 (10^9+7) 形式报告。 原始问题页面和竞赛社论证实了这种基于周期的表述。 

因为`a`和`b`是排列，它们的函数图完全由不相交的有向循环组成。 这种结构特性使得该问题比一般的函数组合问题容易得多。 

的价值观`n`和`m`每个都可以达到（10^5），并且所有测试用例的总和达到（10^6）。 在一秒的限制下，任何二次方`n`或者`m`在最坏的情况下已经太贵了。 我们需要一个总输入大小接近线性的解决方案。 幸运的是，将排列分解为循环后，剩余的除数枚举也可以线性有界。 

有几种边缘情况可能会导致看似合理的实施失败。 

考虑```
1 2
0
1 0
```唯一的源位置是一个长度周期`1`， 尽管`b`是一个周期长度`2`。 该方程要求选定的目标值由下式确定：`b`，但这两个目标都不是固定的。 正确答案是`0`。 简单地计算所有目标值而不检查周期长度的实现将错误地返回`2`。 

现在考虑```
2 2
1 0
0 1
```这里`a`是一个周期长度`2`， 尽管`b`由两个固定点组成。 任一定点都可以用于整个源周期，所以答案是`2`。 粗心的实现可能只查找长度完全相同的目标周期并返回`0`，但所需条件是目标周期长度除以源周期长度。 

涉及平方除数的边界情况是```
4 4
1 2 3 0
0 1 3 2
```源有一个周期长度`4`。 目标有两个周期长度`1`和一个周期的长度`2`。 所有三个目标循环都有长度除法`4`，贡献 (1+1+2=4) 个可能的起始值。 答案是`4`。 通过检查枚举除数时`d * d <= L`, 除数`2`必须只计算一次，因为它是平方根`4`。 

最后，排列实际上不能使所有条目相等，除非其大小为`1`。 例如，`[0]`是唯一一个其条目全部相等的排列。 对于较大的尺寸，这种应力情况的有意义的版本是所有周期都具有相同的长度。 六个元素分成三个 2 循环是一个有用的示例，因为它测试重复循环长度和同一因子的重复乘法。 

## 方法

 直接暴力方法在概念上很简单。 对于 (m^n) 个可能的函数中的每一个，为每个函数分配一个目标值`n`源位置并检查所有`n`方程。 这是正确的，因为考虑了每个可能的函数，并且只计算满足每个方程的函数。 

问题在于候选人的数量。 在最坏的情况下 (n=m=10^5)，蛮力考虑

 [
 100000^{100000}
 ]

 不同的函数，检查每个候选可能需要 (100000) 次方程评估。 这取决于

 [
 100000\cdot100000^{100000}
 ]

 基本检查，这远远超出了任何可行的限制。 

关键的观察结果是约束不会耦合任意源位置。 他们沿着周期耦合位置`a`。 假设一个周期`a`有长度`L`，从某个位置开始`x`:

 [
 x,\a(x),\a^2(x),\ldots,a^{L-1}(x)。 
]

一次`f(x)`选择，方程确定的值`f`在此周期的所有其他位置。 唯一的问题是当我们返回时分配是否一致`x`。 

在整个循环中应用该方程可得出

 [
 f(x)=b^L(f(x))。 
]

因此`f(x)`必须是一个在恰好之后返回自身的目标值`L`的应用`b`。 如果该目标值位于一个循环中`b`长度`d`，然后 (b^L) 准确地修复它

 [
 d\中L。 
]

 假设`b`包含 (c_d) 个长度的循环`d`。 每一个这样的循环都会做出贡献`d`的可能选择`f(x)`，因为它的任何一个`d`元素满足 (b^L(y)=y)。 因此，源循环长度`L`有

 [
 \sum_{d\mid L} d,c_d
 ]

 有效的作业。 

不同的周期`a`是独立的。 为一个源周期选择一个值不会影响任何其他源周期，因此最终答案是这些量在所有周期中的乘积`a`。 

剩下的任务是有效地计算这些除数和。 我们可以计算周期长度`b`一次。 然后，对于每个源周期长度`L`，在 (O(\sqrt L)) 时间内枚举它的除数。 由于源周期长度总和为`n`，总除数搜索工作的边界为

 [
 \sum_i O(\sqrt{L_i})
 \le O\left(\sqrt{k\sum_i L_i}\right)
 \le O(n),
 ]

 哪里`k`是循环数`a`。 循环分解本身需要(O(n+m))，所以完整的算法是(O(n+m))。 这也是竞赛社论给出的复杂性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(nm^n)) | (O(n)) | (O(n)) | 太慢了 |
 | 最佳| (O(n+m)) | (O(n+m)) | 已接受 |

 ## 算法演练

 1. 分解排列`b`分成不相交的循环并计算每个可能的长度有多少个循环。 让`cnt[d]`是长度的周期数`d`。 

我们只需要每个长度的循环数，而不需要这些循环内的实际元素，因为有效目标循环的每个元素都是同样有效的起始值。 
2. 分解排列`a`分成不相交的循环并记录它们的长度。 

对于一个源循环，所有函数值都是通过仅选择一个位置的图像来确定的。 这减少了分配时的计数问题`n`为每个源周期分配一个起始值的独立值。 
3. 对于长度的源循环`L`, 计算

 [
 方式(L)=\sum_{d\mid L}d\cdot cnt[d]。 
]

 目标周期长度`d`正是在以下情况下可用`d`划分`L`。 它贡献`d`选择，因为它的任何元素都可以是所选源位置的图像。 
4. 枚举除数`L`通过测试整数`d`从`1`通过 (\lfloor\sqrt L\rfloor)。 

什么时候`d`划分`L`， 两个都`d`和`L // d`是除数。 如果它们不同，请将两个贡献相加。 如果`d * d == L`, 仅添加`d`一次。 
5. 乘法`ways(L)`进入每个源周期的答案并减少模（10^9+7）。 

乘法是有效的，因为源周期是独立的。 每个全局函数都唯一对应于每个源循环的一个有效选择。 

### 为什么它有效

 取任意一个循环`a`与长度`L`并选择一个位置`x`在它上面。 定义方程确定该源循环上的所有其他值`f(x)`。 遵循整个源循环后，一致性需要 (b^L(f(x))=f(x))。 目标周期长度中的值`d`恰好满足这个条件`d`划分`L`。 因此，该源循环的选择数量正是 (\sum_{d\mid L}d,cnt[d])。 

每个有效函数都是由它在不同周期上的选择唯一确定的`a`，并且在不同周期做出的选择永远不会相互作用。 因此，将所有源循环的选择数量相乘会将每个有效函数恰好计数一次。
