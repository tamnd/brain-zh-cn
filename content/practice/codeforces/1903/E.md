 ## 解决方案
 ## 问题理解

 我们被要求推理 2D 平面上的两人游戏。 游戏从一个固定点开始，从一组给定的点中逐个选取点。 每次选取一个点时，距先前所选点的欧几里德距离的平方都会添加到运行总和中。 如果游戏结束时总和为偶数，则第一个玩家获胜，否则第二个玩家获胜。 挑战在于决定是先玩还是后玩，以及如何最佳地选取分数以确保胜利。 

输入由多个测试用例组成。 对于每个测试用例，我们都会收到点数、起点坐标和点列表。 输出必须是交互式的：首先我们选择玩家顺序，然后在我们的回合中选择一个点，在对手的回合中我们读取他们选择的点。 约束允许最多$10^5$每个测试用例的分数，但总和$n$所有测试用例最多是$10^5$，因此每个点处理一次的解决方案是可以接受的。 坐标可以非常大，最多$10^9$，但实际距离只需要它们的奇偶性，所以我们不需要担心整数溢出。 

不明显的边缘情况是由于总和仅取决于平方距离的奇偶性这一事实而产生的。 尝试对精确距离求和的幼稚实现会带来大整数算术的风险，并且错过了只有偶数或奇数才重要的简化。 另一个微妙之处是，最佳玩家可能并不总是第一个玩家； 根据点的配置，从第二个开始可以通过匹配或对抗移动来控制奇偶性。 例如，如果距起点的所有距离都是偶数，则第一个玩家不能强制获得奇数总和，而应选择第二个。 

## 方法

 暴力解决方案将尝试模拟所有的移动序列，评估每个序列的最终总和。 这会涉及到计算$n!$点的排列，即使对于中等程度的人来说也是不可能的$n$自从$10^5!$是一个天文数字。 暴力破解之所以有效，是因为游戏规则是确定性的，但它会失败，因为序列的数量呈阶乘增长。 

关键的观察是我们不关心确切的距离，只关心总和的奇偶性。 对整数进行平方可以保留奇偶性：如果数字是偶数，则平方为偶数；如果数字为奇数，则平方为奇数。 点之间的欧几里得距离平方$(x_1, y_1)$和$(x_2, y_2)$是$(x_2-x_1)^2 + (y_2-y_1)^2$。 该表达式的奇偶性仅由坐标差的奇偶性确定。 具体来说，如果两个差都是偶数或都是奇数，则和为偶数； 如果一为奇数，一为偶数，则和为奇数。 

这样，我们就将问题简化为纯粹基于奇偶校验的游戏。 每个点都有一个颜色，具体取决于其坐标模 2 的总和是否与起始点的坐标模 2 匹配。从开始起相同奇偶性的点是“偶数移动”，相反奇偶性的点是“奇数移动”。 第一个玩家如果先开始时的奇数步点数为奇数，或者第二个开始时的奇数步点数为奇数，则可以保证获胜，从而允许他们通过始终选择适当奇偶性的点来控制运行和的奇偶性。 这种见解将问题简化为计数和奇偶校验，即线性时间操作。

 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$,$s_x$,$s_y$，以及点列表。 对于每个点，计算其相对于起点的奇偶性：$(x_i - s_x) \% 2$和$(y_i - s_y) \% 2$。 如果奇偶校验恰好在一个坐标上不同，则平方距离模 2 为 1，否则为 0。 
2. 计算从一开始就选取的、将贡献奇数平方距离的点的数量。 设这个数为`odd_count`。 
3. 决定选手顺序。 如果`odd_count`奇怪，选择先玩。 如果`odd_count`为偶数时，选择第二个打。 这种选择确保了对最终总和奇偶性的控制。 
4. 在游戏过程中，维护一份可用积分列表。 轮到我们时，如果我们需要翻转当前和奇偶校验，则选择贡献奇数平方距离的任何点；如果我们想保留它，则选择偶数点。 这总是可能的，因为奇偶校验计数是预先知道的并且我们交替轮流。 
5. 在对手的回合中，读取他们的动作并将其从可用点列表中删除。 
6. 重复此操作，直至选择所有点。 此时，总和平价将由所选玩家策略控制，确保胜利。 

为什么它有效：不变的是第一个或第二个玩家总是可以选择一个点来控制运行总和的奇偶性。 通过预先计算奇数和偶数贡献并轮流交替，所选玩家可以根据自己的获胜条件确保总和最终为偶数或奇数。 由于平方距离模 2 仅取决于坐标奇偶性，因此该不变量对于实际位置具有鲁棒性，并且适用于任何配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
flush = sys.stdout.flush

def parity(x):
    return x % 2

t = int(input())
for _ in range(t):
    n = int(input())
    sx, sy = map(int, input().split())
    points = [tuple(map(int, input().split())) for _ in range(n)]
    
    odd_points = []
    even_points = []
    for idx, (x, y) in enumerate(points):
        dx = parity(x - sx)
        dy = parity(y - sy)
        if dx ^ dy:
            odd_points.append(idx + 1)
        else:
            even_points.append(idx + 1)
    
    if len(odd_points) % 2 == 1:
        print("First")
        flush()
        my_turn_points = odd_points + even_points
    else:
        print("Second")
        flush()
        my_turn_points = even_points + odd_points

    used = set()
    for turn in range(n):
        if turn % 2 == 0:  # our turn
            for j in my_turn_points:
                if j not in used:
                    print(j)
                    flush()
                    used.add(j)
                    break
        else:  # opponent's turn
            j = int(input())
            if j == -1:
                exit()
            used.add(j)
```我们首先将点分为翻转奇偶校验的点（奇数）和不翻转奇偶校验的点（偶数）。 根据奇数点数选择玩家顺序。 在每个回合中，我们从预先计算的列表中选择一个可用点来保持对奇偶性的控制。 这`used`set 确保我们永远不会选择已经选择的点。 在对手的回合中，我们阅读他们的选择并更新`used`。 这`^`运算符有效地计算 XOR 以确定奇偶校验差异。
