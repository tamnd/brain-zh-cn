 ## 解决方案
 ## 问题理解

 我们一群人一一加入一个俱乐部。 这`i`- 第一个人携带一定数量的气球`1`和`K`。 每次到达后，迄今为止收集的气球总数必须能除以俱乐部当前的人数。 

任务是计算所有前缀有多少可能的贡献序列满足此条件。 如果至少一个人携带不同数量的气球，则两个顺序是不同的。 答案需要模数`998244353`。 问题陈述和限制来自 Codeforces Gym 106178B，其中`N`可以大到`10^9`尽管`K`至多是`2000`。 

第一个挑战是`N`是巨大的。 任何模拟每个人的方法都是不可能的，因为即使`10^8`对于典型的比赛时间限制来说，操作已经太多了，而且这里的人数可能会多出十倍。 小界限`K`是我们应该利用的关键限制。 

考虑每次到达后每人的平均气球数量。 由于每个前缀总数都可以被其长度整除，因此该平均值始终是整数。 由于每项贡献都介于`1`和`K`，每个平均值也介于`1`和`K`。 这给我们只`K`可能的状态，即使步骤的数量可能很大。 

棘手的情况大多与非常小的值以及过程变得稳定的点有关。 

例如，与：```
1 3
```答案是`3`，因为只有一个人可以带`1`,`2`， 或者`3`气球。 从第二人开始转换的解决方案将错误地返回零。 

另一种情况是：```
4 1
```答案是`1`。 每个人必须携带一个气球。 任何仅检查平均值是否可以更改的方法都可能会意外地计算出不可能的更改，因为唯一有效的状态是平均值`1`。 

一个更微妙的情况是：```
5 2
```当有足够多的人加入后，平均值就不能再改变了。 从平均水平的转变`1`平均`2`对人`6`需要第六个人携带`7`气球，这是不可能的。 假设相同的转换永远持续下去的解决方案将会过度计算。 

## 方法

 直接的解决方案是保留当前的气球总数，并为每个人尝试一切可能的贡献。 对于每个人来说，都有`K`选择，所以这就变成了`K^N`的可能性。 这是正确的，因为它从字面上枚举了每个有效序列，但它立即变得不可用。 

一个稍微好一点的尝试是在当前平均水平上进行动态规划。 让之后的状态`i`人们是目前的平均水平`a`。 只有`K`州。 从平均水平的转变`a`达到新的平均水平`b`由下一个贡献决定：$$x = i \cdot b - (i-1)\cdot a$$如果`x`介于`1`和`K`，那么这个转换是有效的。 

对所有平均值对进行强力 DP 检查所有可能的情况`a`和`b`对于每个人。 那成本`O(NK^2)`，这仍然是不可能的，因为`N`可以是`10^9`。 

重要的观察是，当有足够多的人加入后，平均值就不再移动。 假设当前平均值是`a`下一个平均值更大`d`。 下一个贡献变成：$$x = a + i \cdot d$$对于任何积极的改变，贡献都会随着`i`。 因为任何贡献都不能超过`K`，当`i > K`。 同样的论点也适用于降低平均值。 顺便来一趟`d`要求：$$x = a - i \cdot d$$当`i`足够大。 因此之后`K`对于第一个人，平均值被迫永远保持不变，而未来唯一可能的贡献正是当前的平均值。 

我们只需要模拟第一个`K`到达。 其余`N-K`人们每个人贡献一个强制值，因此他们不会改变有效序列的数量。 

还可以有效地生成转换。 来自一个州`a`在步骤`i`，将平均值增加`d`是可能的，同时：$$a+i d \leq K$$并减少`d`是可能的，同时：$$a-i d \geq 1$$所有步骤生成的转换总数约为：$$\sum_{i=1}^{K} \frac{K^2}{i}$$这是周围`K^2 log K`，很容易足够快`K = 2000`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |`O(K^N)`|`O(N)`| 太慢了 |
 | 未经优化的 DP 高于平均水平 |`O(NK^2)`|`O(K)`| 太慢了 |
 | 平均 DP 优化 |`O(K^2 log K)`|`O(K)`| 已接受 |

 ## 算法演练

 1. 如果只有一个人，每一份贡献都来自`1`到`K`是有效的，所以答案是`K`。 
2. 存储一个动态规划数组，其中`dp[a]`是当前人数平均后的有效序列数`a`。 

在第一个人之后，平均值正是他们带来的气球数量，因此每个平均值`1`到`K`有一个有效的序列。 
3. 处理人员到达`2`因人而异`min(N, K)`。 

对于当前步骤`i`，创建一个新的状态数组。 对于每个当前平均值`a`，尝试此步骤中可达到的所有可能的下一个平均值。 
4. 处理平均值保持相等的转变。 

如果平均数保持不变`a`，新的贡献也是`a`，这始终有效。 
5. 处理平均值增加的转变。 

搬家自`a`到`a+d`需要贡献：$$a+i d$$增加`d`而这个值最多是`K`。 
6. 处理平均值下降的转变。 

搬家自`a`到`a-d`要求：$$a-i d$$减少`d`而这个值至少是`1`。 
7、后处理`min(N,K)`人们，总结所有状态。 如果`N`大于`K`，后来的人从每个状态都有一个可能的贡献序列，所以答案不会改变。 

为什么它有效：

 不变量是处理完 person 之后`i`,`dp[a]`精确计算其平均值之后的有效前缀`i`人们是`a`。 每个可能的下一个贡献恰好对应于下一个平均值，并且每个生成的转换都满足整除性要求，因为所得平均值是整数。 转换生成会检查可能存在的每个贡献，因此不会遗漏有效序列，也不会添加无效序列。 一旦人数超过`K`，改变平均值将需要超出允许范围的贡献，只留下自我过渡。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    N, K = map(int, input().split())

    if N == 1:
        print(K % MOD)
        return

    dp = [0] * (K + 1)
    for i in range(1, K + 1):
        dp[i] = 1

    limit = min(N, K)

    for people in range(2, limit + 1):
        ndp = [0] * (K + 1)

        for avg in range(1, K + 1):
            cur = dp[avg]
            if cur == 0:
                continue

            ndp[avg] = (ndp[avg] + cur) % MOD

            increase = 1
            while avg + people * increase <= K:
                ndp[avg + increase] = (ndp[avg + increase] + cur) % MOD
                increase += 1

            decrease = 1
            while avg - people * decrease >= 1:
                ndp[avg - decrease] = (ndp[avg - decrease] + cur) % MOD
                decrease += 1

        dp = ndp

    print(sum(dp) % MOD)

if __name__ == "__main__":
    solve()
```第一部分处理一个人的特殊情况，因为没有以前的平均值可供转换。 

这`dp`数组仅存储平均值，而不存储气球总数。 这就是压缩带来的巨大价值`N`易于管理。 

在循环内部，`people`是新来后的人数。 转换公式取决于该值，因此运算顺序很重要。 我们在替换之前从旧平均值生成新状态`dp`。 

递增和递减循环避免检查所有`K`可能的下一个平均值。 它们只直接生成有效的更改。 边界检查`avg + people * increase <= K`和`avg - people * decrease >= 1`防止无效平均值，并且是通常出现相差一错误的地方。 

Python 整数不会溢出，所有加法都会模数减少`998244353`以保持存储的值较小。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 |`O(K^2 log K)`| 所有处理过的人生成的转换数量受以下调和和的限制：`K^2 / i`。 |
 | 空间|`O(K)`| 仅存储当前和下一个平均分布。 |

 和`K <= 2000`，优化后的DP仅执行数千万次简单操作。 的巨大价值`N`不影响运行时间，因为在第一个之后`K`人们的过程变得确定性。

 ## 边缘情况

 对于`N = 1`，算法立即返回`K`。 除了第一个贡献在允许的范围内之外，没有任何前缀条件，因此每个可能的气球计数都有效。 

为了`K = 1`，每个平均值都被迫为`1`。 转换循环不可能增加或减少，只留下自转换。 这将准确地保留一个有效序列，无论`N`。 

对于大型`N`， 例如`N = 10^9`和`K = 2000`，算法在处理完 person 后停止`2000`。 以后任何改变平均值的尝试都需要添加或删除超过`K`一步膨胀，因此唯一可能的延续永远重复当前的平均值。 最终的状态计数已经是完整的答案。
