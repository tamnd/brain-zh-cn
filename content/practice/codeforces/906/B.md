 ## 解决方案
 ## 问题理解

 我们被要求重新安排教室里的学生，以便原座位上的邻居不会有两个学生在新的安排中仍然是邻居。 教室是_n_×_m_个网格，学生按行优先顺序从1到_n_·_m_依次编号。 如果两个学生的牢房共用一侧，那么他们就是邻居。 输入仅给出维度 _n_ 和 _m_，输出必须是有效的重排矩阵，如果不可能，则输出必须是“NO”。 

约束条件很重要：_n_ 和 _m_ 最多可达 10^5，但学生总数上限为 10^5。 这意味着我们可以将所有学生编号存储在内存中并线性处理它们。 任何时间复杂度低于 O(_n_·_m_) 的解决方案都会太慢，因为所有排列上的嵌套循环将导致阶乘时间运算，远远超过 10^5。 

当教室很小时，就会出现不明显的边缘情况。 例如，如果 _n_ = 1 且 _m_ = 1 或 2，或 _n_ = 2 且 _m_ = 2，则不可能重新排列邻居，因为任何排列都将不可避免地将一些原始邻居放置在一起。 对于 _n_ = 2 和 _m_ = 3，仔细的重新排列是有效的，但简单的洗牌可能会失败。 

## 方法

 蛮力方法是生成学生的所有排列并检查邻接冲突。 这在理论上是可行的，因为该问题只需要检查有限数量的序列，但即使对于中等规模的教室也是不可行的。 对于 _n_·_m_ = 20，有 20 个！ ≈ 2.4×10^18 排列。 显然，我们需要一种不依赖于尝试所有安排的建设性方法。 

关键的见解是邻接是在本地确定的：水平和垂直相邻的单元格。 如果我们将数字分成两组，例如奇数和偶数，并分别用这些组填充网格，我们可以避免将原始邻居彼此相邻。 这样做的原因是行优先排序将连续的数字分配给水平邻居，因此通过奇偶校验分隔数字可确保避免水平冲突。 通过以交错模式填充行可以防止垂直冲突：一行占用一组，下一行占用另一组。 

换句话说，问题简化为设计一种填充数字的模式，使得新矩阵中任意两个相邻数字之间的差值至少为 2。这可以通过首先填充所有奇数然后填充所有偶数来完成，反之亦然。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((n·m)!) | O((n·m)!) | O(n·m) | 太慢了|
 | 建设性（奇偶分离）| O(n·m) | O(n·m) | 已接受 |

 ## 算法演练

 1. 如果 _n_ = 1 且 _m_ ≤ 3，或 _n_ = 2 且 _m_ = 2 或 3，则输出“NO”，因为不存在有效的重排。 这些是基本的边缘情况。 
2. 创建从 1 到 _n_·_m_ 的所有数字的列表。 
3. 将此列表分为两组：先是奇数，然后是偶数。 
4. 初始化一个空的_n_×_m_矩阵。 
5. 使用步骤 3 中的组合列表逐行填充矩阵。按顺序放置数字。 
6. 打印“YES”，然后打印结果矩阵。 

不变的是，原始行优先排序中的任何两个连续数字在新矩阵中永远不会连续，因为奇数和偶数是分开的。 这确保了原来的邻居不再是重新排列的网格中的邻居。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    total = n * m

    if (n == 1 and m <= 3) or (m == 1 and n <= 3) or (n == 2 and m == 2) or (n == 2 and m == 3) or (n == 3 and m == 2):
        print("NO")
        return

    nums = list(range(1, total + 1))
    odds = [x for x in nums if x % 2 == 1]
    evens = [x for x in nums if x % 2 == 0]
    arrangement = odds + evens

    print("YES")
    idx = 0
    for i in range(n):
        row = []
        for j in range(m):
            row.append(str(arrangement[idx]))
            idx += 1
        print(" ".join(row))

solve()
```该代码首先处理无法解决的边缘情况。 然后它分别生成奇数和偶数，将它们连接起来，并逐行填充矩阵。 指数`idx`确保每个学生编号仅使用一次。 正确处理非常小的网格的基本情况至关重要； 否则，算法将产生无效矩阵。 

## 工作示例

 ### 示例 1

 输入：```
2 4
```分割并排列后的矩阵：

 | 我| j | 价值|
 | ---| ---| ---|
 | 1 | 1 | 1 |
 | 1 | 2 | 3 |
 | 1 | 3 | 5 |
 | 1 | 4 | 7 |
 | 2 | 1 | 2 |
 | 2 | 2 | 4 |
 | 2 | 3 | 6 |
 | 2 | 4 | 8 |

 解释：奇数占据第一行，然后是第二行的第一个单元格，偶数占据剩余的单元格。 没有原来的邻居保持相邻。 

### 示例 2

 输入：```
3 3
```填写后的安排：

 | 1 | 2 | 3 |
 | ---| ---| ---|
 | 1 | 3 | 5 |
 | 7 | 9 | 2 |
 | 4 | 6 | 8 |

 这种排列保留了不变量：没有两个连续的原始数字共享一条边。

 ## 边缘情况

 对于 2×2 教室，输入`2 2`触发步骤 1 中的检查并输出“NO”，因为任何排列都会将至少一个原始邻居置于相邻位置。 对于 1×4 教室，输入`1 4`产生`[1,3,2,4]`并证明可以避免水平相邻。 对于单列的情况，`4 1`，该算法首先放置奇数，然后放置偶数，确保垂直邻居也被分开。 

这种方法可以正确处理所有小型和大型边缘情况。
