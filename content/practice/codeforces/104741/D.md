 ## 解决方案
 ## 问题理解

 我们在平面上得到一组 N 个不同的点，每个点代表一个村庄。 我们想要选择一条正好穿过其中两个村庄的直线。 这条线用作两个区域之间的边界。 

严格位于该线一侧的所有村庄都属于一个国家，而位于另一侧的所有村庄都属于另一国。 正好位于线上的村庄被认为是双方共享的，但其中只有线的两个选定端点被视为“端口”，因此线总是由一对有序的不同点定义。 

要求是，画出这样一条线后，所得的两个国家必须包含相同数量的村庄。 我们必须计算两个定义村庄的无序选择产生了有效的平衡分区。 如果所选的一对村庄不同，则无论几何对称性或方向如何，两个选择都被视为不同。 

约束为 N 到 2000，坐标的大小最大为 10^9。 这立即排除了任何尝试以简单的三重嵌套方式显式评估所有几何分离的方法。 三次 O(N^3) 方法会尝试对每条候选线对所有其他点进行分类，这在最坏的情况下会导致大约 8×10^9 次操作，远远超出限制。 即使 O(N^2 log N) 也需要仔细处理，但可能是可以接受的，因为 N^2 约为 4×10^6。 

一个微妙的点是处理共线性。 如果多个点位于同一条线上，则对于恰好在线上的点，“边”的定义变得不明确。 简单地使用叉积而不仔细处理零情况的简单方法可能会重复计算或错误分类点。 

当许多点对称或位于凸位置时，会出现另一种边缘情况。 例如，如果所有点都是凸多边形的顶点，则每对点都以可预测的方式定义有效的分界线，但内部简并性消失。 相反，当许多点共线时，每条候选线都包含许多点，并且简单地计算“左/右”必须避免重复计算线上的点。 

## 方法

 暴力方法首先选择每对无序点作为候选线。 对于每一对，我们通过计算相对于有向线的方向（叉积符号）对所有其他点进行分类。 这告诉我们一个点是位于左侧、右侧还是正好位于直线上。 

对于每一对，我们计算每一侧有多少个点。 如果排除 k 个共线点（其中 k 包括两个端点和任何其他共线点）后两侧恰好包含 (N - k) / 2 点，我们检查所得分区是否满足平衡条件。 每对需要 O(N) 次工作，总复杂度为 O(N^3)。 

瓶颈显然是重复扫描每对的所有点。 关键的观察是，我们实际上并不需要独立地对每一对进行完全重新计算； 相反，我们可以利用围绕枢轴点的角度排序。 

固定一个点 i。 如果我们按 i 周围的极角对所有其他点进行排序，那么对于任何第二个点 j，直线 ij 将圆分成两个半平面。 该问题简化为计算有多少点落在 180 度角区间内。 通过对圆形数组进行两指针扫描，我们可以在 O(N) 中有效地计算每个 i 的有效相反侧分割。 

这将问题简化为计算，对于每个 i，有多少 j 在有向线 ij 的一侧恰好产生 (N - 2) / 2 个点。 角度扫描自然地处理所有方向并避免从头开始重新计算几何形状。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(N^3) | O(N^3) | O(1) | O(1) | 太慢了|
 | 每个枢轴的角度扫掠| O(N^2 log N) | O(N^2 log N) | O(N) | 已接受 |

 ## 算法演练

 我们将每个点 i 固定为锚点并分析源自该点的所有线。 

1. 对于固定点 i，计算从 i 到每隔一个点 j 的向量。 每个向量代表平面中的一个方向。 
2. 按极角对这些向量进行排序。 这使我们能够将 i 周围的循环排序视为线性数组，同时仍然尊重几何形状。 
3. 通过再次附加相同的向量（角度移动 2π）来复制排序列表。 这避免了在循环顺序上滑动窗口时的模运算。 
4. 对于原始列表中的每个 j，我们想要找到有多少个点位于由线 ij 定义的半平面内。 我们使用两指针技术：前进指针 k 直到角度差超过 π。 
5. 该角度顺序中 j 和 k 之间的点数对应于线 ij 一侧的点。 
6. 我们检查该计数是否恰好等于 (N - 2) / 2。如果是，则 (i, j) 对形成有效分区。 

当 i 固定且 j 被视为排序顺序的前半部分时，每个有效对都会计数一次。 

### 为什么它有效

 固定一个端点 i 将几何条件转化为循环排序问题。 通过 i 的任何直线将其余点分为两个半平面，这些半平面与围绕 i 的角度顺序的连续弧完全对应。 两指针窗口保证我们能够准确地计算出从 ij 方向旋转 180 度范围内的点。 由于每个有效行恰好有两个端点，因此每个端点都会发现一次，并且限制枚举可以防止重复计算，同时保持正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    if n % 2 == 1:
        print(0)
        return

    ans = 0

    for i in range(n):
        x0, y0 = pts[i]
        vec = []
        for j in range(n):
            if i == j:
                continue
            x, y = pts[j]
            vec.append((x - x0, y - y0))

        def half(v):
            x, y = v
            return (y < 0) or (y == 0 and x < 0)

        vec.sort(key=lambda v: (half(v), v[0] * v[0] + v[1] * v[1]))

        m = len(vec)
        vec2 = vec + vec

        target = (n - 2) // 2
        j = 0

        for k in range(m):
            if j < k:
                j = k
            while j < k + m:
                dx1, dy1 = vec[k]
                dx2, dy2 = vec2[j]
                cross = dx1 * dy2 - dy1 * dx2
                if cross > 0:
                    j += 1
                else:
                    break

            cnt = j - k - 1
            if cnt == target:
                ans += 1

    print(ans // 2)

if __name__ == "__main__":
    solve()
```实现的核心是每个枢轴点的角度扫描。 这`half`函数定义了向量的一致排序，而不使用浮点角度，将平面分成两半，因此排序变得正确且稳定。 

双倍数组`vec2`允许我们模拟循环遍历而无需模运算。 两指针窗口不断扩展，直到角度差超过 π（通过叉积符号而不是显式角度计算来测量）。 

条件`ans // 2`是必需的，因为每个有效行从每个端点开始计数一次。 如果没有这种修正，每个解对都将被重复计算。

 ## 边缘情况

 对于奇数 N 的情况，算法立即返回零。 任何具有奇数个点的配置在删除两个端点后都不能分成两个相等的整数半部分，因为 N - 2 变为奇数并且不能形成相等的整数边。 

对于共线配置，来自枢轴的所有向量都位于一条线上。 排序会退化，但仍然有效，因为平局打破可以确保稳定的顺序。 两指针窗口永远不会错误地计算相对的半平面，因为叉积比较始终评估为零或仅一侧，从而防止错误的有效分割。
