 ## 解决方案
 ## 问题理解

 给定一个两行n列的网格，因此有2n个单元格排列成一个矩形。 每个单元格必须为黑色或白色。 唯一的限制是不允许两个黑色单元并排接触，这意味着黑色单元之间不允许水平或垂直相邻。 

对于每个测试用例，我们还给出一个数字 k，并且我们必须计算存在多少个有效着色，以便恰好有 k 个单元格为黑色，同时仍然遵守非邻接规则。 答案以 998244353 为模。 

关键约束是每个测试用例的 n 和 k 可以大到 100000，测试用例最多为 100000 个，所有测试的 k 总和以 5×10^5 为界。 这立即告诉我们，任何独立于每个测试用例 k 的解决方案，或任何 n 的二次方，都是不可能的。 即使每个测试用例的 O(nk) 也会太慢，因为 k 可能很大并且在测试中重复很多次。 

一个微妙的边缘情况来自这样一个事实：相邻是在网格中，而不是在一条线上。 同一列中的两个垂直邻居不能同时为黑色，同一行内相邻列中的两个水平邻居不能同时为黑色。 例如，在单个列中，两个单元格不能同时为黑色。 

一个小的说明性情况是 n = 1，k = 2。确实有一种方法可以将两个单元格都涂成黑色，但它是无效的，因为它们垂直相邻，因此答案为 0。仅禁止水平相邻的简单组合方法会错误地计算此值。 

另一个例子是 n = 2，k = 2。一种有效的配置是将黑色单元放置在（第 1 行，第 1 列）和（第 2 行，第 2 列）处，但禁止将两个黑色单元放置在同一列或水平相邻的配置。 除非在全局范围内强制执行邻接约束，否则天真的“选择任意 k 个单元”方法会严重计算过多。 

关键的困难在于约束耦合了行和列，因此每个单元格的局部独立性不成立。 

## 方法

 暴力方法会考虑 2n 个单元格的每种颜色，并检查它是否满足邻接条件并且恰好有 k 个黑色单元格。 这样的着色有 2^(2n) 种，甚至检查每一种都需要 O(n)，这是完全不可行的。 

一种稍微结构化的暴力方法是独立处理每个单元格，并尝试从 2n 个单元格中选择 k 个单元格，但减去包含相邻对的那些选择。 这变成了 2×n 网格图中邻接边的包含-排除，这仍然导致指数复杂性，因为邻接约束形成了密集的依赖结构。 

关键的观察结果是黑色单元格在 2×n 网格图中形成独立的集合。 我们在此图中计算大小为 k 的独立集合。 2×n 网格的结构很特殊，因为它本质上是一个梯形图，它具有众所周知的列状态分解。 

我们没有考虑单个单元格，而是根据每列包含的黑色单元格数量对每一列进行分类。 由于垂直邻接禁止一列中的两个单元都是黑色的，因此每一列最多可以贡献一个黑色单元。 因此，每个有效的配置都相当于选择一些列并将每个选定的列分配给顶部或底部单元格。 

现在唯一剩下的限制是水平邻接：如果第 i 列第 1 行中的单元格是黑色，则第 i+1 列第 1 行也不能是黑色； 与第 2 行类似。这成为两条独立的路径（顶行和底行），但由于每一列最多可以容纳一个黑色单元这一事实而耦合。 

这导致每列具有三种状态的标准 DP：空、顶部选定、底部选定。

我们将 dp[i][j] 定义为使用 j 个黑色单元处理前 i 列的方法数，跟踪第 i 列是否为空、顶部或底部，同时确保每行内没有水平邻接。 

转换是局部的：从第 i-1 列状态到第 i 列状态，我们只需要确保不会将顶部放置在顶部之后或将底部放置在底部之后。 

这个 DP 的运行时间复杂度为 O(nk)，但在最坏的情况下仍然太慢。 

最终的优化来自于注意到列之间的转换是相同的，因此我们可以将其建模为类似卷积的过程。 每列贡献一个小的固定传输矩阵，我们正在有效地计算重复多项式变换的第 k 个系数。 这简化为组合封闭形式：每个选定的黑色单元格放置在顶部或底部，但同一行中不允许有两个相邻的选择，因此每行中的选择相当于在长度为 n 的路径中选择不相邻的位置。 

因此，问题分解为为顶行黑色单元选择 t 列，为底行黑色单元选择 k-t 列，其中两个选择都是长度为 n 的路径上的独立独立集选择，附加约束是同一列不能使用两次。 

这导致了 t 上的卷积，每行都是一个标准组合“无相邻选择”选择计数：C(n - t + 1, t)。 

所以最终的答案是 t 的总和：

 C(n - t + 1, t) * C(n - (k - t) + 1, k - t),

 具有确保非负参数的有效性约束。 

这将网格约束干净地折叠为两个独立的一维独立集计数，并通过避免列重叠进行耦合。

 ## 算法演练

 1. 使用模运算预先计算阶乘和逆阶乘，最大可能为 2n。 这是有效评估二项式系数所必需的。 
2. 对于每个测试用例，迭代 t 的所有可能值，其中 t 是在顶行中分配黑色单元格的列数。 此参数控制我们如何在两行之间分割 k 个黑色单元格。 
3. 对于固定的t，将顶行选择解释为在n列中选择t个不相邻的列，这相当于选择之间至少有一个间隙的t个位置。 此类选择的数量计算为 C(n - t + 1, t)。 这种转换来自于用强制间隙压缩每个选定的位置以避免相邻。 
4. 同样，解释分配给底行的 k - t 个黑色单元格，给出 C(n - (k - t) + 1, k - t) 种可能性。 
5. 将这两个计数相乘，因为一旦通过构造处理了列重叠约束，顶行和底行中的选择是独立的。 
6. 对两个二项式参数均为非负的所有有效 t 值求和。 

### 为什么它有效

 每个有效的颜色都可以唯一地分解为两组列：顶行使用的列和底行使用的列。 在每一行中，无邻接约束强制采用标准的“无连续选择”结构，该结构由移位二项式系数公式精确捕获。 通过在顶部和底部选择之间拆分列来强制防止两行选择同一列的耦合约束。 每个有效配置恰好对应一个分割值 t，因此总和不会过度计数或遗漏配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353
MAX = 100000 + 5

fact = [1] * (MAX)
invfact = [1] * (MAX)

for i in range(1, MAX):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAX - 1] = pow(fact[MAX - 1], MOD - 2, MOD)
for i in range(MAX - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

t = int(input())
out = []

for _ in range(t):
    n, k = map(int, input().split())
    if k > 2 * n:
        out.append("0")
        continue

    ans = 0

    for top in range(0, k + 1):
        bottom = k - top
        if top <= n and bottom <= n:
            ways_top = C(n - top + 1, top)
            ways_bottom = C(n - bottom + 1, bottom)
            ans = (ans + ways_top * ways_bottom) % MOD

    out.append(str(ans))

print("\n".join(out))
```阶乘预处理允许在恒定时间内计算每个二项式系数，这是至关重要的，因为每个测试用例最多执行 O(k) 次迭代，但测试中 k 的总和是有界的。 

循环结束`top`直接对应算法中的分解参数t。 支票`top <= n`和`bottom <= n`确保我们不会尝试不可能的独立设置尺寸。 每一项都是使用用于选择非相邻位置的移位二项式公式来计算的。 

最终的累积反映了所有有效分割的卷积。

 ## 边缘情况

 当 k 超过 2n 时，无论邻接约束如何，网格都无法包含足够的黑色单元。 在这种情况下，实现显式返回 0，以防止无效的阶乘查询。 

当k = 0时，仅存在全白网格。 分割循环仅包括 top = 0、bottom = 0，产生 C(n+1,0)^2 = 1。 

当 k = n 或接近 n 时，许多二项式参数变为零或负数，组合函数自然会将它们过滤掉。 这避免了行之间特殊的套管边界分布。 

一种微妙的情况是所有黑色单元格必须排成一行。 例如，n = 5、k = 3、top = 3、bottom = 0 生成 C(3,3) * C(6,0) = 1，正确计算单行中完全分离的放置位置，且不相邻。
