 ## 解决方案
 ## 问题理解

 该问题维护一个大的非负整数数组。 对于任何值，变换`f`是通过取其十进制数字之和并删除其中最小的数字来定义的。 我们必须处理替换一个数组元素的更新以及询问以下问题的查询：对于子数组，我们必须应用的最小次数是多少`f`每个元素，以便所有结果值变得相同。 

这些约束使得不可能对每个查询进行直接模拟。 高达$10^5$元素和$10^5$操作，扫描整个范围以查找每个查询可以达到的方法$10^{10}$运营。 我们需要每次更新和查询来解决对数时间。 

关键的隐藏属性是值很快就会变小。 即使一个数字有 18 位，数字之和也最多为 162，因此经过一次转换后，每个值最多为 162。第二次转换最多使其成为一位数，第三次转换始终使其为零。 这意味着每个元素只有四种相关状态：原始值、一次应用后的值、两次应用后的值以及三次应用后的值。 

一个常见的错误是只存储达到零所需的操作次数。 这会丢失信息，因为两个数字在达到零之前可能会变得相等。 例如，数组`[50, 15]`需要两个应用程序，而不是三个，因为`f(50)=5`和`f(15)=5`。 仅存储到零的距离的解决方案会高估答案。 

另一个边缘情况是所有值都已经相等的范围。 对于输入：```
3
7 7 7
1
2 1 3
```答案是`0`，因为不需要转换。 仅检查第一个变换层将错误地返回正值。 

最终的边缘情况是仅在最后可能的层才变得相等的值。 例如：```
2
999999999999999999 888888888888888888
1
2 1 2
```两个值最终都会变为零，但它们之前的状态不同。 正确答案是`3`，因此算法必须检查所有变换级别。 

## 方法

 最简单的方法是通过查看范围中的每个元素来处理查询。 对于每个值，我们重复应用`f`直到整个范围变得相等。 这是正确的，因为它直接遵循操作的定义。 问题在于操作的数量。 范围可以包含$10^5$元素，并且可以有$10^5$查询，大致给出$10^{10}$元素检查。 

每个数字只有几个有意义的变换状态的观察改变了问题。 我们可以预先计算每个元素的前四个状态，而不是在查询期间重复转换值。 查询只需要知道范围内所有值都相同的最小级别。 

这是一个线段树问题，因为更新影响一个位置，而查询则询问一个范围。 对于四个级别中的每一个，每个线段树节点存储整个线段经过多次变换后是否具有相同的值。 合并两个孩子只需要检查两个孩子在水平上是否一致以及他们的价值观是否匹配。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(nq) | O(1) | O(1) | 太慢了 |
 | 线段树| O((n+q) log n) | O((n+q) log n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个数组元素，在应用 0、1、2 和 3 次之后计算其值`f`。 

四个状态就足够了，因为每个值最多经过三次变换后都会变为零。 

1. 构建一棵线段树，每个节点存储四对。 每对都包含该级别的值以及整个段是否具有相同的值。 

存储该值是必要的，因为只有当两个子项的最终值匹配时才可以合并。 

1. 对于更新，用四个新计算的转换状态替换与更改的索引相对应的叶子。 

树中只有一条路径发生变化，因此更新需要对数时间。 

1. 对于查询，收集请求范围的线段树信息并合并覆盖的节点。 

合并结果告诉我们每个转换级别的整个范围是否相等。 

1. 从零向上扫描四个级别，并返回标记为统一的第一个级别。 

第一个级别是所需的最少申请数量。 

工作原理：线段树维护了一个不变量，即每个节点正确描述其整个线段在每个可能的变换次数后是否相等。 合并操作保留了这一点，因为当两个半段在该级别上相等并且它们的结果值相同时，组合段在该级别上是相等的。 由于每个可能的答案都在四个级别中，因此找到的第一个有效级别就是最佳答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def f(x):
    if x == 0:
        return 0
    digits = []
    y = x
    mn = 10
    s = 0
    while y:
        d = y % 10
        s += d
        if d < mn:
            mn = d
        y //= 10
    return s - mn

def build_value(x):
    res = [x]
    for _ in range(3):
        res.append(f(res[-1]))
    return res

class SegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.tree = [[0] * 8 for _ in range(4 * self.n)]
        self.build(1, 0, self.n - 1, arr)

    def pull(self, node):
        left = node * 2
        right = left + 1
        for i in range(4):
            lv = self.tree[left][2 * i]
            le = self.tree[left][2 * i + 1]
            rv = self.tree[right][2 * i]
            re = self.tree[right][2 * i + 1]
            if le and re and lv == rv:
                self.tree[node][2 * i] = lv
                self.tree[node][2 * i + 1] = 1
            else:
                self.tree[node][2 * i] = 0
                self.tree[node][2 * i + 1] = 0

    def build(self, node, l, r, arr):
        if l == r:
            vals = build_value(arr[l])
            for i in range(4):
                self.tree[node][2 * i] = vals[i]
                self.tree[node][2 * i + 1] = 1
            return
        mid = (l + r) // 2
        self.build(node * 2, l, mid, arr)
        self.build(node * 2 + 1, mid + 1, r, arr)
        self.pull(node)

    def update(self, node, l, r, idx, val):
        if l == r:
            vals = build_value(val)
            for i in range(4):
                self.tree[node][2 * i] = vals[i]
                self.tree[node][2 * i + 1] = 1
            return
        mid = (l + r) // 2
        if idx <= mid:
            self.update(node * 2, l, mid, idx, val)
        else:
            self.update(node * 2 + 1, mid + 1, r, idx, val)
        self.pull(node)

    def query(self, node, l, r, ql, qr):
        if ql <= l and r <= qr:
            return self.tree[node][:]
        mid = (l + r) // 2
        if qr <= mid:
            return self.query(node * 2, l, mid, ql, qr)
        if ql > mid:
            return self.query(node * 2 + 1, mid + 1, r, ql, qr)
        a = self.query(node * 2, l, mid, ql, qr)
        b = self.query(node * 2 + 1, mid + 1, r, ql, qr)
        res = [0] * 8
        for i in range(4):
            if a[2 * i + 1] and b[2 * i + 1] and a[2 * i] == b[2 * i]:
                res[2 * i] = a[2 * i]
                res[2 * i + 1] = 1
        return res

def solve():
    n = int(input())
    arr = list(map(int, input().split()))
    seg = SegTree(arr)
    q = int(input())
    ans = []
    for _ in range(q):
        t, a, b = map(int, input().split())
        if t == 1:
            seg.update(1, 0, n - 1, a - 1, b)
        else:
            res = seg.query(1, 0, n - 1, a - 1, b - 1)
            for i in range(4):
                if res[2 * i + 1]:
                    ans.append(str(i))
                    break
    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```功能`f`通过除法提取数字来仔细实现。 对零的特殊处理避免了将空数字表示视为问题。 

线段树每个节点存储八个值。 对于四个转换级别中的每一个，使用两个位置：一个用于结果值，另一个作为布尔标志，表示该段是统一的。 

在合并期间，仅当两个子节点都是统一的并且它们的值匹配时，该节点才会被标记为统一。 这是整个组合范围均匀所需的精确条件。 

查询函数仅返回覆盖段的信息并合并部分答案。 由于树深度是对数的，因此可以保持运算速度快。

 ## 边缘情况

 对于等值情况：```
3
7 7 7
1
2 1 3
```该树在零层为每个位置存储相同的值，因此查询立即返回`0`。 始终适用的解决方案`f`首先会在这里失败。 

对于早期合并的情况：```
2
50 15
1
2 1 2
```在零级，值不同。 在第一级，两者都变成`5`，所以答案是`1`。 线段树抓住了这一点，因为它存储每个转换层，而不仅仅是最终的零状态。 

对于最大深度的情况：```
2
999999999999999999 888888888888888888
1
2 1 2
```第一次转换产生不同的小数字，第二次转换仍然可以不同。 在第三级，两者都为零，因此查询返回`3`。 这证实了该算法可以处理该过程的全部可能深度。
