 ## 解决方案
 ## 问题理解

 矩阵不是任意的。 每行都有一个隐藏值，每列都有一个隐藏值，每个可见单元格都是这两个值的最小公倍数。 缺少一些单元格，任务是选择可以创建所有可见单元格的行和列值，同时使每个所选值的乘积尽可能小。 

该乘积与最小化所有行和列值的素数指数之和相同。 这是因为对于每个素数，可以独立地查看数字的乘法。 例如，如果素数对一个行值贡献指数 3，则其贡献的因子与将另一个值增加相同指数的因子完全相同。 LCM 条件也可以通过素数独立工作，因为 LCM 中的指数是两个数字中的最大指数。 

维度最多为 500，所有测试的行和列总数均以 500 为界。 这排除了任何接近检查行和列值的每个可能分配的情况。 隐藏值不受限制，因此不可能搜索可能的数字。 该解决方案必须使用 LCM 和素因数的结构。 

缺失的单元格造成了一种容易被忽略的情况。 仅出现在零个单元格中的行或列没有任何限制，并且不应做出任何贡献。 例如，使用输入```
2 2
0 0
0 0
```答案是`1`，因为每个隐藏值都可以选择为 1。从矩阵值初始化每一行和每一列的粗心方法在这里会失败。 

另一个棘手的情况是，并不总是通过从单行或单列中获取值来找到最小值。 例如：```
1 2
6 10
```最小值是`30`， 不是`60`。 行值可以是`1`两列值可以是`6`和`10`, 给予产品`60`，但更好的选择是行值`2`, 列`3`和`5`，提供与产品相同的 LCM`30`。 该解决方案必须推理素数指数，而不是复制可见数字。 

## 方法

 直接的方法是尝试重建隐藏的行和列数组。 因为每个可见的细胞都说`lcm(row[i], col[j]) = b[i][j]`，我们可以尝试矩阵值的不同除数并保持最小的乘积。 这是正确的，因为每个有效答案都必须满足这些方程。 

问题在于可能性的数量。 值高达`10^8`可以有很多除数，最多有 500 个行值和 500 个列值。 快速尝试组合变得不可能。 即使每个职位只考虑几个候选人，也可能导致对巨大状态空间的搜索。 

有用的观察是我们在求解时永远不需要完整的值。 单独考虑一个素数。 让这个素数的指数排成一行`i`是`r[i]`，并在列中`j`是`c[j]`。 具有指数的已知单元格`x`给出条件：```
max(r[i], c[j]) = x
```对于一个顶点，它可以拥有的最大指数是所有相邻已知单元中最小的指数。 如果一行接触带有指数的单元格`2`,`5`， 和`3`，那么它的指数不能超过`2`。 任何更大的值都会使第一个单元格变得不可能。 

现在为每一行和每一列分配这个允许的最大指数。 因为保证原始矩阵有效，所以每个已知单元格至少有一个端点，其最大允许指数恰好是单元格指数。 如果两个端点都没有该指数，则两者都会更小，并且 LCM 永远无法达到所需的值。 

这给出了尽可能小的分配。 将任何顶点增加到超过其最大允许指数是不可能的，并且减少顶点会破坏依赖它的单元。 对每个素数独立应用这个可以得到最小的乘积。

 | --- | --- | --- | --- |
 | 蛮力 | 行数和列数呈指数 | O(纳米) | 太慢了|
 | 最佳| O(nm log A) | O(纳米) | 已接受 |

 ## 算法演练

 1. 对每个非零矩阵条目进行因式分解。 对于每个素数，存储出现在每个已知单元格中的指数。 我们只关心矩阵中实际出现的素数。 

不同质因数的数量很少，因为每个值最多`10^8`。 

1. 对于每个素数，为所有行和列创建尽可能小的指数数组。 用一个大值初始化每一行和每一列，然后用指数处理每个已知的单元格`e`。 更新行和列的上限`e`。 

这将计算每个顶点可能接收的最大指数。 

1. 将这个素数的行和列贡献添加到答案中。 如果一行有最终指数`x`，将答案乘以`p^x`。 对每一列执行相同的操作。 

该乘积可以逐个构建，因为素数幂是独立的。 

1. 忽略没有任何已知单元格的行和列。 它们的上限保持未设置，并且它们的最小可能值为 1。 

为什么它有效：对于每个素数，隐藏矩阵仅取决于两个指数的最大值。 每个顶点都有一个距其入射边的上限。 有效的解决方案不能分配更大的指数。 为所有顶点分配最大允许指数满足每条边，因为原始矩阵保证具有一些有效的分配，因此每条边至少有一个端点能够达到其所需的指数。 任何较小的分配都会减少某些边缘所需的指数。 因此构造的分配恰好是最小分配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def factorize(x):
    res = []
    d = 2
    while d * d <= x:
        if x % d == 0:
            cnt = 0
            while x % d == 0:
                x //= d
                cnt += 1
            res.append((d, cnt))
        d += 1 if d == 2 else 2
    if x > 1:
        res.append((x, 1))
    return res

def solve_case(n, m, a):
    factors = [[[] for _ in range(m)] for _ in range(n)]
    primes = set()

    for i in range(n):
        for j in range(m):
            if a[i][j]:
                f = factorize(a[i][j])
                factors[i][j] = f
                for p, _ in f:
                    primes.add(p)

    ans = 1

    for p in primes:
        row = [-1] * n
        col = [-1] * m

        for i in range(n):
            for j in range(m):
                if a[i][j]:
                    exp = 0
                    for q, e in factors[i][j]:
                        if q == p:
                            exp = e
                            break
                    if row[i] == -1 or exp < row[i]:
                        row[i] = exp
                    if col[j] == -1 or exp < col[j]:
                        col[j] = exp

        for x in row:
            if x > 0:
                ans = ans * pow(p, x, MOD) % MOD

        for x in col:
            if x > 0:
                ans = ans * pow(p, x, MOD) % MOD

    return ans

def main():
    t = int(input())
    out = []

    for _ in range(t):
        n, m = map(int, input().split())
        a = [list(map(int, input().split())) for _ in range(n)]
        out.append(str(solve_case(n, m, a)))

    print("\n".join(out))

if __name__ == "__main__":
    main()
```因式分解阶段存储每个非零单元的素数指数。 存储它们可以避免在处理不同素数时重复分解相同的值。 

主循环一次处理一个素数。 这`row`和`col`数组表示该素数的最小上限。 每个可见单元格只能减小这些界限，因为每个端点都不能大于单元格指数。 

一个常见的错误是使用零作为初始值。 零是实数指数，因此它会错误地强制每一行或每一列都没有贡献。 代码使用`-1`表示该顶点没有已知的事件单元。 

最后的乘法使用模幂，因为所有素数幂的乘积可能非常大。

```这说明了为什么按素数分割会比直接使用可见值找到更小的分配。

## 测试用例```python
import sys, io

MOD = 998244353

def factorize(x):
    res = []
    d = 2
    while d * d <= x:
        if x % d == 0:
            c = 0
            while x % d == 0:
                x //= d
                c += 1
            res.append((d, c))
        d += 1 if d == 2 else 2
    if x > 1:
        res.append((x, 1))
    return res

def solve(inp):
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n, m = map(int, input().split())
        a = [list(map(int, input().split())) for _ in range(n)]
        factors = [[[] for _ in range(m)] for _ in range(n)]
        primes = set()

        for i in range(n):
            for j in range(m):
                if a[i][j]:
                    factors[i][j] = factorize(a[i][j])
                    for p, _ in factors[i][j]:
                        primes.add(p)

        cur = 1
        for p in primes:
            row = [-1] * n
            col = [-1] * m
            for i in range(n):
                for j in range(m):
                    if a[i][j]:
                        e = 0
                        for q, v in factors[i][j]:
                            if q == p:
                                e = v
                                break
                        row[i] = e if row[i] == -1 else min(row[i], e)
                        col[j] = e if col[j] == -1 else min(col[j], e)
            for x in row + col:
                if x > 0:
                    cur = cur * pow(p, x, MOD) % MOD
        ans.append(str(cur))

    return "\n".join(ans)

 ## 边缘情况

 对于全零矩阵：```
2 2
0 0
0 0
```每行每列都没有事件约束。 该算法从不分配素数指数，因此所有隐藏值仍为 1。乘积为`1`。 

对于稀疏矩阵：```
2 3
0 6 0
0 0 10
```主要因素是独立处理的。 对于素数 2，第一个已知值在其行或列上强制指数 1，对于值 10 的素数 5 和素数 3 也会发生同样的情况。通过在可能的情况下仅分配一次必要的指数来获得最小乘积。 

对于相等的值：```
2 2
6 6
6 6
```每条边都需要素数 2 和 3 的指数。行和列边界变为相同的值，但算法选择最小的总贡献，产生`36`而不是将所有可见单元格相乘。
