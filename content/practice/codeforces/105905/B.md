 ## 解决方案
 ## 问题理解

 我们得到一个小写字符串。 在一项操作中，我们可以删除相对于当前字符串末尾镜像的两个字符。 换句话说，如果一个字符是从左边算起的第 k 个字符，则另一个字符一定是从右边算起的第 k 个字符。 仅当这两个字符相等时才允许该操作。 

取下该对后，将绳子的其余部分粘在一起。 我们可以执行任意数量的操作，并希望最终长度尽可能最小。 

字符串长度可以大到$10^5$，这会立即排除任何重复重建字符串或探索不同操作顺序的模拟。 一个$O(n^2)$解决方案已经太慢了，所以我们应该瞄准单次线性扫描。 

一个微妙的点是，删除一个镜像对会更改当前字符串，因此很容易认为稍后可能会出现新的删除机会。 粗心的实现可能会尝试动态模拟操作并最终导致不必要的复杂性。 

考虑字符串：```
abba
```镜像对是`(a,a)`和`(b,b)`。 这两对都可以删除，所以答案是：```
0
```现在考虑：```
abca
```外对`(a,a)`可以删除，但是`(b,c)`不能。 最小长度为：```
2
```另一个重要的例子是：```
abcde
```每个镜像对都包含不同的字母，因此无法进行任何操作，答案是：```
5
```关键的观察结果是，操作永远不会改变彼此对应的原始镜像位置。 这完全决定了解决方案。 

## 方法

 一种暴力的想法是重复搜索可移动镜像对，删除其中一个，重建字符串，然后继续。 由于每次删除都会更改索引，因此我们需要显式维护当前字符串。 在最坏的情况下，每次操作后重建字符串都会导致二次行为。 

突破来自于将字符串视为镜像对的集合。 

对于每个职位`i`左半部分正好有一个镜像位置`n - 1 - i`在右半部分。 让我们称其为镜像对。 

假设镜像对包含相同的字符。 然后该对最终可以被删除。 

假设镜像对包含不同的字符。 任何操作都无法删除其中任何一个。 原因是每次操作都会删除一对完整的镜像。 删除其他一些镜像对并不会改变这两个角色仍然彼此配对的事实。 

这意味着每个镜像对都是完全独立的：

 如果两个字符相等，则两者都会消失。 

如果两个角色不同，则两者都将永远存在。 

对于奇数长度的字符串，中间的字符没有伙伴，并且永远不能被删除。 

所以答案很简单：```
2 × (number of mismatched mirrored pairs)
+ (1 if the length is odd else 0)
```| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n²) 或更糟 | O(n) | 太慢了 |
 | 计数镜像不匹配 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取字符串并设其长度为`n`。 
2. 初始化计数器`bad = 0`。 
3. 对于每个索引`i`从`0`到`n // 2 - 1`， 比较：```
s[i]
s[n - 1 - i]
```4. 如果字符不同，则递增`bad`。 

每个这样的镜像对都无法删除，因此这两个字符必须保留在最终字符串中。 
5. 处理完所有镜像对后，计算：```
answer = 2 * bad + (n % 2)
```期限`2 * bad`计算属于不匹配镜像对的所有字符。 

期限`n % 2`当长度为奇数时，占中心字符。 
6. 输出答案。 

### 为什么它有效

 每个操作都会删除一对字符相同的镜像。 

删除镜像对不会改变其余镜像对的配对关系。 一对最初是`(x, y)`保持配对直到最后。 

因此，每个镜像对都可以独立分析。 

相同的镜像对可以完全删除。 

不平等的镜像对永远无法删除。 

奇数长度字符串的中间字符永远不会有伙伴，因此它始终会幸存。 

该算法精确计算所有可能的删除后必须保留的字符，这是可实现的最小长度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s = input().strip()
n = len(s)

bad = 0

for i in range(n // 2):
    if s[i] != s[n - 1 - i]:
        bad += 1

print(2 * bad + (n % 2))
```实现直接遵循数学观察。 

循环仅访问字符串的左半部分。 对于每个位置，它都会将该角色与其右侧的镜像伙伴进行比较。 

每个不匹配都会为答案贡献两个不可避免的字符。 每个匹配对的贡献为零，因为两个字符都可以被删除。 

表达式`n % 2`自动处理中心字符。 对于偶数长度，它贡献零，而对于奇数长度，它贡献一。 

不存在相差一的问题，因为循环恰好在镜像对上运行并且从不触及中心位置。

 ## 边缘情况

 考虑：```
a
```根本不存在镜像对。 该算法发现`bad = 0`，并且由于长度是奇数：```
answer = 0 + 1 = 1
```唯一的字符仍然存在，这是正确的。 

考虑：```
ab
```唯一的镜像对是`(a,b)`，这是不同的。 

该算法计算一个不匹配：```
bad = 1
answer = 2
```这两个字符都无法被删除，因此结果是正确的。 

考虑：```
aabaa
```两个镜像对都匹配并且可以删除。 中心人物没有伙伴。 

该算法计算：```
bad = 0
answer = 1
```与最佳删除顺序相匹配。 

考虑：```

```两个镜像对都不匹配，中心幸存：```
(a,e) -> mismatch
(b,d) -> mismatch
center = c
```该算法返回：```

```无法进行任何操作，因此保留整个字符串。 这证实了不匹配计数解释的正确性。
