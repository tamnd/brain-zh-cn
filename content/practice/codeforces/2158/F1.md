 ## 解决方案
 ## 问题理解

 我们被要求构造一个长度的序列$n$，其中每个元素都是一个大的正整数，目标是控制连续元素之间最大公约数的结构。 

对于每一个相邻的对$(a_i, a_{i+1})$，我们计算$\gcd(a_i, a_{i+1})$。 在整个阵列中，这些$n-1$价值观必须都是不同的。 同时，在所有有效的构造中，我们希望最小化序列本身中出现的不同值的数量。 

因此，问题不仅在于使相邻的 GCD 唯一，还在于积极地重用数组值以保持不同数字的集合较小。 

约束条件很小，对于$n$（最多 700），但值本身可能非常大，最多可达$10^{18}$。 这立即表明该构造必须依赖于数论结构，而不是对值的搜索或动态规划。 

当两个相邻的 GCD 发生碰撞时，天真的尝试会尝试分配任意数字并修复冲突。 这种方法失败了，因为 GCD 约束是全局的：更改一个元素会同时影响两个相邻的边，并且碰撞会不可预测地传播。 

当尝试从一个小集合中进行随机分配时，会出现更微妙的失败情况，例如$\{1, 2, 3\}$。 例如，与$n = 5$，选择交替值，例如$[1,2,1,2,1]$给出重复的相邻 GCD 到处都等于 1，这立即违反了要求。 这表明仅仅减少不同值的数量而不控制可分结构是不够的。 

关键的困难在于每条边必须“携带”一个独特的 gcd 签名，这建议通过精心选择的可分链对边进行编码。 

## 方法

 暴力方法会尝试增量分配值并维护边的可见 gcd 集。 对于每个位置，我们将尝试选择一个最多$10^{18}$与前一个元素生成一个新的 gcd。 这需要针对所有先前的边检查整除性和 gcd 条件。 

在最坏的情况下，在位置$i$，我们可能会扫描许多候选值并用前一个元素计算 gcd，从而给出很容易退化为的复杂性$O(n \cdot 10^{18})$或者充其量$O(n^2 \sqrt{10^{18}})$如果我们限制候选人。 这远远超出了可行的限度。 

关键的见解是反转视角：我们不是通过任意数字间接控制 gcd，而是直接分配我们想要出现在边缘上的 gcd 值。 一旦我们决定了边的gcd$i$，我们可以构造两个相邻的数组值来实现它，同时保留先前的结构。 

强制执行不同 gcd 的一种简洁方法是为每条边分配一个唯一的整数$g_i$，然后构造数组值，以便$\gcd(a_i, a_{i+1}) = g_i$。 为了避免边之间的干扰，我们使每条边使用新的基于素数的结构或仔细分层的乘法结构，其中每个 gcd 被迫通过独特的因素隔离。 

在简单版本中工作的构造依赖于为每条边分配一个不同的数字，并将其嵌入到连续的数组元素中，以便每个相邻对的 gcd 准确地提取该数字，而以前的 gcd 由于缺乏共享质因子而无法重复。 

自从$n \le 700$，我们可以安全地使用第一个$n$素数或具有受控互素性的连续整数，缩放它们以避免碰撞并确保 gcd 提取的唯一性。 

一个标准的结构是让每个边缘$i$使用新鲜的底漆$p_i$，并定义：$$a_i = p_i \cdot p_{i+1}$$进行边界调整，使每个相邻的 gcd 恰好成为共享素数。 这会创建一条干净的链，其中每条边都有唯一的素数交点，保证不同的 gcd。 

因为每个数字至多是两个小素数的乘积，所以值保持在$10^{18}$。

 ## 算法演练

 我们构造一个序列，其中每个相邻的 gcd 被迫对应于唯一的素数标识符。 

1.生成第一个$n$素数。 每个质数都将作为边缘的独特“签名”。 
2. 构建数组$a$长度$n$，其中每个位置都是使用相邻素数定义的，以便每条边恰好共享一个素数因子。 
3. 对于每条边$i$，确保$a_i$和$a_{i+1}$两者都包含素数$p_i$，但它们之间不共享其他先前使用过的素数。 
4、具体构造为：$$a_i = p_i \cdot p_{i+1}$$为了$1 \le i < n$，端点调整为：$$a_1 = p_1 \cdot p_2,\quad a_n = p_{n-1} \cdot p_n$$5. 输出构建的序列。 

每一步都确保相邻对在一个受控素数因子中重叠，因此每个 gcd 正是该素数。 

### 为什么它有效

 每条边$(a_i, a_{i+1})$恰好共享一个素因数$p_{i+1}$，并且所有其他因素都是不相交的，因为每个素数都用于结构化的局部模式。 所以：$$\gcd(a_i, a_{i+1}) = p_{i+1}$$由于每$p_i$是不同的，所有相邻的 gcd 都是不同的。 该结构还确保每个数字最多用于两个位置，从而使不同值的数量保持最少并受到控制。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXP = 5000

def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    primes = []
    for i in range(2, n + 1):
        if is_prime[i]:
            primes.append(i)
            for j in range(i * i, n + 1, i):
                is_prime[j] = False
    return primes

primes = sieve(6000)

t = int(input())
for _ in range(t):
    n = int(input())
    
    # take first n primes
    p = primes[:n]
    
    a = [0] * n
    
    # construct chain
    for i in range(n - 1):
        a[i] = p[i] * p[i + 1]
    
    # last element
    a[n - 1] = p[n - 2] * p[n - 1]
    
    print(*a)
```该代码首先使用筛子生成素数，这是必要的，因为每条边都依赖于唯一的素数标识符。 对于每个测试用例，我们取第一个$n$素数，并为每个相邻对分配连续素数的乘积。 这确保了重叠结构在整个序列中保持一致。 

选择最后一个元素是为了与前一对保持一致； 它与其邻居恰好共享一个素数，从而保留了链结构。 

一个微妙的实现细节是，我们从不重复使用非相邻边上的素数，这可以防止意外的 gcd 冲突。

 ## 边缘情况

 对于$n = 2$，该构造退化为单边，只要 gcd 是唯一的，任何数字对都可以工作。 该算法仍然会产生两个共享同一个质因数的数字，因此 gcd 条件不成立。 

为最大$n = 700$，我们依靠足够的素数来分配唯一标识符。 由于该范围内素数丰富，因此筛子保证了可用性，并且每条边都保持隔离。 

对于小型连锁店，例如$n = 3$，重叠结构最小但仍然一致：每条边引入一个新素数，确保即使在最短的非平凡情况下，gcd 值也不会重复。
