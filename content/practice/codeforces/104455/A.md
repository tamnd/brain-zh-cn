 ## 解决方案
 ## 问题理解

 两名玩家独立地将一对统一的整数“骰子间隔”掷两次，然后将两次结果相加。 Alice 使用间隔$[l_1, r_1]$和鲍勃使用$[l_2, r_2]$。 每次滚动在区间内的整数上都是均匀的，因此每个总和是两个独立均匀变量的总和。 

任务不是计算精确的概率，而是决定哪个玩家有更高的概率获得更大的总和。 由于两个玩家的结果都是独立均匀范围的对称和，因此比较简化为比较两个离散的总和分布。 

输入包含许多测试用例，因此解决方案必须独立且高效地处理每对区间。 约束条件达到$10^5$测试用例，值可以大到$10^9$，这排除了任何结果的枚举。 任何正确的解决方案都必须减少与每个测试用例的恒定时间公式的比较。 

一个简单的模拟会尝试枚举所有$(r_1 - l_1 + 1)^2 (r_2 - l_2 + 1)^2$结果，即使对于中等范围也是完全不可行的，因为范围可能很大并且平方组合会爆炸。 即使计算每个测试用例的分布的完整卷积也会太慢。 

关键的困难在于，虽然每个总和分布都是三角形的，但我们只需要比较两个这样的分布，而不是它们的完整形状。 

## 方法

 强力方法会枚举 Alice 和 Bob 所有可能的结果对，计算它们的总和，并计算 Alice 的总和较大的频率。 这正确地捕获了概率，但需要迭代四个独立随机变量的所有组合，这在约束下是不可能的。 

关键的观察结果是，每个玩家的总和分布是两个均匀分布的卷积，形成对称三角形分布。 我们不需要显式地计算概率，而只需比较两个这样的分布之间的排序期望。 

对于均匀整数区间$[l, r]$，两次独立抽取的总和具有一个分布，其排序完全由其均值和方差结构决定。 更具体地说，爱丽丝击败鲍勃的概率仅取决于它们在数轴上的间隔的相对位置及其宽度。 这将问题简化为比较爱丽丝的分布与鲍勃的随机支配意义上的分布是否“向右移动”。 

因为两者都是相同独立均匀分布的和，所以分布是单峰且对称的，因此比较简化为比较区间的中点：$(l + r)$。 两次独立抽取的总和具有预期值$l + r$，所以爱丽丝的总期望和是$2(l_1 + r_1)/2 = l_1 + r_1$，对于鲍勃来说也是如此。 

因此，在以下情况下，爱丽丝有更高的获胜概率：$$l_1 + r_1 > l_2 + r_2$$与不利于爱丽丝的关系。 

这将每个测试用例减少为常数时间算术。

 ## 算法演练

 1.读取测试用例的数量。 每个测试用例都是独立的，因此它们之间不传递任何状态。 
2. 对于每个测试用例，读取两个区间$[l_1, r_1]$和$[l_2, r_2]$。 这些定义了爱丽丝和鲍勃的单个骰子掷骰的分布。 
3. 将 Alice 的得分计算为$l_1 + r_1$，它代表她的总和分布的中心。 
4. 将 Bob 的得分计算为$l_2 + r_2$，它代表他的总和分布的中心。 
5. 比较两个分数。 如果Alice的值严格大于，则输出“Yes”，否则输出“No”。 

这种比较是严格的，因为相等的中心意味着分布相同的对称性，因此两个玩家都没有严格更高的获胜概率。 

### 为什么它有效

 每个玩家的总和是一个区间内两个独立统一变量的总和。 这种分布是对称的，并且完全由其端点决定。 一个总和超过另一总和的概率仅取决于这些对称分布的相对位移。 由于两个分布具有相同的形状族，因此通过比较它们的中心来保留它们的顺序。 因此，比较$l + r$足以确定哪个分布随机支配另一个分布。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        l1, r1 = map(int, input().split())
        l2, r2 = map(int, input().split())

        a = l1 + r1
        b = l2 + r2

        if a > b:
            out.append("Yes")
        else:
            out.append("No")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案独立处理每个测试用例，并且仅执行恒定时间算术。 使用`sys.stdin.readline`确保快速输入处理$10^5$案例。 结果被缓冲以避免缓慢的重复打印。 

一个微妙的点是我们从不明确计算概率。 这将需要分布的卷积，这是不必要的，因为排序减少到比较区间中心。

 ## 边缘情况

 当两个区间相同时，两个玩家的分布相同，因此条件$l_1 + r_1 > l_2 + r_2$失败并且输出正确为“No”。 

当Alice有严格更宽的间隔但向左移动时，例如$[1, 100]$与$[50, 51]$，鲍勃仍然获胜，因为他的中锋更大。 该算法正确地捕获了这一点，因为只有端点总和很重要。 

当两个间隔都极大时（最多$10^9$），Python 中不会发生溢出，整数加法仍然安全，保持了正确性。
