 ## 解决方案
 ## 问题理解

 我们正在处理一个三角形，其三个边长不是直接给出的，而是通过它们之间的三个比率来约束。 具体来说，边长$AB$,$BC$， 和$CA$必须满足三个比例关系，这意味着一旦一侧固定，其他两侧就被迫成固定比例。 

所以输入并没有描述一个灵活的三角形。 它描述了一种严格的“形状直至缩放”。 所有有效的三角形（如果存在）都只是单个基础比例三角形的缩放版本。 

第二个要求是三角形必须是非退化的，这意味着它必须满足严格的三角形不等式，以便具有正面积。 最后一个要求是关于周长的：在这个三角形的所有有效缩放版本中，我们必须确定是否可以使周长为整数，如果可以，找到最小的整数周长。 

对这六个数字的限制很小，但这不是这里最重要的。 关键的观察结果是，问题的结构将所有几何体分解为单个一致性检查和缩放问题，因此任何解决方案都必须在恒定时间内运行。 

一个微妙的失败案例来自于忽视比率之间的一致性。 例如，如果比率意味着矛盾的缩放，例如强制$AB > BC$同时也逼着$BC > AB$，则根本不存在三角形。 另一个失败的情况是假设对于任何正比率总是存在三角形，这是错误的，因为隐含的比例边可能违反三角形不等式。 

## 方法

 蛮力视角首先想象我们可以为一侧分配一个值，例如$AB = x$，然后使用给定的比率导出另外两侧。 从$AB/BC = a/b$，我们得到之间的关系$AB$和$BC$。 从$BC/CA = c/d$，我们链接另一对，并且从$CA/AB = e/f$，我们关闭循环。 一种天真的方法会尝试任意值$x$，计算生成的三角形，测试有效性，然后检查哪个缩放比例使周长为整数。 

这种方法的问题在于它引入了对所有实际缩放的连续搜索。 由于扩展不受限制，暴力变得毫无意义：有无限多个候选者。 

关键的观察结果是，比率完全决定了三角形的形状，直至单个乘法因子。 一旦我们检查比率是否一致，每个有效的三角形都只是一个固定三倍边比例的缩放副本。 这将问题简化为检查比例三元组是否形成有效的三角形，然后了解在缩放下周长可以取什么值。 

一旦我们达到这一点，“整数周长”约束就不再是组合性的，而是成为一个关于缩放固定有理数和的纯数论问题。

 ## 算法演练

 ### 步骤 1：将比率转换为代数约束

 我们对待$AB = x$,$BC = y$,$CA = z$。 每个比率都成为连接这些变量的方程式。 这将几何问题变成了比例约束系统。 

### 步骤2：检查比例是否一致

 我们结合三个比率方程。 将它们乘以循环会强制取消：$$\frac{AB}{BC} \cdot \frac{BC}{CA} \cdot \frac{CA}{AB} = 1$$所以输入必须满足：$$\frac{a}{b} \cdot \frac{c}{d} \cdot \frac{e}{f} = 1$$这相当于：$$ace = bdf$$如果失败，则没有三角形可以同时满足所有约束，因为系统会强制进行矛盾的缩放。 

### 步骤 3：恢复侧面比例

 假设一致性成立，我们用单个参数来表达所有方面$t$。 例如，采取$CA = t$。 然后：$$BC = \frac{c}{d} t, \quad AB = \frac{a}{b} \cdot \frac{c}{d} t$$所以三角形在缩放之前就完全确定了。 

### 步骤 4：检查三角形有效性

 我们在比例形式上测试严格的三角不等式。 如果不等式失败，则任何缩放都无法修复它们，因为缩放会保留所有比较。 

### 步骤 5：处理整数周长条件

 周长变为：$$P = AB + BC + CA = t \cdot S$$在哪里$S$是由比率确定的固定正有理数。 

自从$t$是一个自由正实参数，我们可以选择它来使$P$我们想要的任何正的实际值。 特别地，我们可以选择$t = 1/S$，这使得周长精确$1$。 如果满足三角形不等式，则此缩放仍然有效。 

因此，如果存在有效的三角形，则最小整数周长就是$1$。 

### 为什么它有效

 整个结构折叠成一个方向向量$\mathbb{R}^3$代表侧面比例。 这些比率唯一地固定该方向直至缩放。 三角形的有效性仅取决于方向，而不取决于大小。 一旦有效性成立，缩放自由度允许我们达到任何正周长值，因此整数约束不会施加超出存在的限制。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ok(a, b, c, d, e, f):
    # consistency of ratios: a/b * c/d * e/f = 1
    return a * c * e == b * d * f

def valid(x, y, z):
    return x + y > z and x + z > y and y + z > x

def solve():
    a = int(input())
    b = int(input())
    c = int(input())
    d = int(input())
    e = int(input())
    f = int(input())

    if not ok(a, b, c, d, e, f):
        print(-1)
        return

    # construct proportional sides
    # CA = 1
    z = 1
    y = c / d
    x = (a / b) * y

    if not valid(x, y, z):
        print(-1)
        return

    print(1)

if __name__ == "__main__":
    solve()
```该代码首先强制执行循环一致性条件，这是三个比率可以同时描述真实三角形的唯一方法。 然后，它使用任意归一化重建代表性三角形$CA = 1$，因为只有比例才重要。 

直接对这些归一化值执行三角不等式检查。 由于缩放不会影响不等式方向，因此检查一次就足够了。 

最后，输出是$1$，因为任何有效的比例三角形都可以缩放为周长恰好为一个整数值。

 ## 边缘情况

 最重要的边缘情况是比率单独有效但全局不一致。 在这种情况下，产品条件立即失败，并且算法会拒绝而不尝试几何重建。 

另一种边缘情况是当比率定义退化三角形时。 即使循环一致性成立，导出的比例也可能满足相等而不是严格的不等式，从而产生零面积。 该算法在三角不等式步骤中正确地拒绝了这些情况。 

最后一种边缘情况是比率极度扭曲，其中一侧占主导地位。 归一化步骤仍然有效，因为它准确地保留了相对比较，确保三角形的有效性纯粹由比例而不是大小决定。
