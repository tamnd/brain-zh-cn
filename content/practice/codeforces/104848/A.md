 ## 解决方案
 ## 问题理解

 我们得到一个整数数组。 我们必须将一个元素恰好加 1，然后检查结果数组是否**不是**回文。 任务是决定是否存在这样的立场选择。 

当每个元素都与其镜像对应项匹配时，数组就是回文数组。 增加一个值只会改变一个位置，因此只有涉及该位置及其镜像的相等性才能改变。 

数组长度最多为 1000。即使是尝试每个位置并每次检查整个数组的算法也最多执行大约一百万个元素比较，这很容易满足限制。 不需要复杂的数据结构或预处理。 

一些边缘情况值得关注。 

考虑一个已经不是回文的数组。```
3
1
2
3
```正确的输出是：```
1
```无论增加哪个元素，数组都不会突然变成回文。 仅检查回文数组的粗心解决方案会错误地回答`0`。 

尽可能小的数组也需要特殊处理。```
1
7
```正确的输出是：```
0
```增加唯一元素后，数组仍然包含一个元素，并且每个长度一个数组都是回文。 

奇数长度回文需要小心，因为中间元素没有明显的镜像伙伴。```
3
1
2
1
```正确的输出是：```
1
```增加中间元素会产生`[1, 3, 1]`，这仍然是一个回文。 正确的做法是增加任一端，产生`[2, 2, 1]`或者`[1, 2, 2]`，两者都是非回文。 假设每个位置都有效是不正确的。 

元素全部相同的数组是另一个有用的示例。```
4
5
5
5
5
```正确的输出是：```
1
```增加任何位置都会立即打破与其镜像元素的相等性。 

## 方法

 最直接的解决办法就是尝试所有可能的位置。 对于每个位置，暂时将该元素加一，测试结果数组是否是回文，然后恢复原始值。 如果任何尝试产生一个非回文数组，答案是`1`。 否则答案是`0`。 

这个方法是正确的，因为它明确地检查每一个合法的修改。 其运行时间为`O(n^2)`，因为有`n`候选位置和每个回文检查扫描数组一次。 和`n ≤ 1000`，这最多大约一百万次比较，这很容易足够快。 

更仔细地观察增加一种元素的效果揭示了一个更简单的观察结果。 

If the original array is already not a palindrome, increasing one element cannot repair every mismatched pair. The changed position participates in only one mirrored comparison, so every other mismatch remains. 答案是立即`1`。 

If the original array is a palindrome, only two situations are possible.

 如果`n = 1`，单个元素也是中间元素，因此更改它会使数组成为回文。 

如果`n > 1`，选择不是唯一中间元素的任何位置都会更改镜像对的一侧，同时保持另一侧不变。 由于值只会增加，因此相等性会立即被打破，产生一个非回文数组。 

这将问题简化为检查数组最初是否是回文以及其长度是否为 1。

 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 已接受 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取数组。 
2. 通过将每个元素与其镜像对应项进行比较来检查数组是否为回文。 
3. 如果数组已经不是回文，则打印`1`。 任何与修改位置无关的现有不匹配保持不变，因此数组不能变成回文。 
4. 如果数组是回文数组，长度为`1`， 打印`0`。 只有一个元素，因此每一种可能的修改仍然会产生回文。 
5. 否则，打印`1`。 由于长度大于 1，因此选择非奇数长度数组中心的任意位置。 增加该值会破坏与其镜像的相等性，使数组成为非回文数组。 

### 为什么它有效

 关键属性是增加一个元素仅影响一对镜像。 如果原始数组已包含不匹配，则每次可能的修改后至少有一个不匹配存在，因此该数组仍然是非回文。 如果原始数组是回文数组并且具有多个元素，则始终存在具有不同镜像的位置。 Increasing exactly one side of that pair makes the two values different, destroying the palindrome. 唯一不可能的情况是长度为 1 的数组，其唯一元素镜像自身。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
a = [int(input()) for _ in range(n)]

pal = True
for i in range(n // 2):
    if a[i] != a[n - 1 - i]:
        pal = False
        break

if not pal:
    print(1)
elif n == 1:
    print(0)
else:
    print(1)
```该程序首先读取数组并通过比较对称位置来执行标准回文检查。 循环只需要检查前半部分，因为每次比较都涵盖镜像对。 

一旦知道回文状态，剩下的逻辑就直接从证明中得出。 非回文数组立即产生`1`。 长度为一的回文是唯一不可能的情况并且产生`0`。 其他所有情况都是回文，至少具有一对不同位置的镜像，因此增加一个端点会破坏这种相等性。 

该实现通过使用避免了一个错误`n - 1 - i`作为镜像索引。 对于奇数长度，中间元素永远不会与自身进行比较，因为循环在`n // 2`迭代。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline
    n = int(input())
    a = [int(input()) for _ in range(n)]

    pal = True
    for i in range(n // 2):
        if a[i] != a[n - 1 - i]:
            pal = False
            break

    if not pal:
        print(1)
    elif n == 1:
        print(0)
    else:
        print(1)

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()
    solve()
    out = sys.stdout.getvalue()
    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return out

# custom cases
assert run("1\n5\n") == "0\n", "single element"
assert run("2\n1\n1\n") == "1\n", "two equal elements"
assert run("3\n1\n2\n3\n") == "1\n", "already non-palindromic"
assert run("4\n7\n7\n7\n7\n") == "1\n", "all equal"
assert run("5\n1\n2\n3\n2\n1\n") == "1\n", "odd palindrome"
assert run("1000\n" + "1\n" * 1000) == "1\n", "maximum size"
```| 测试输入| 预期产出 | 它验证了什么 |
 | ---| ---| ---|
 |`1, [5]`|`0`| 最小尺寸，不可能的情况 |
 |`2, [1,1]`|`1`| 最小的非平凡回文 |
 |`3, [1,2,3]`|`1`| 已经是非回文数组 |
 |`4, [7,7,7,7]`|`1`| 所有相同的值 |
 |`5, [1,2,3,2,1]`|`1`| 具有中心元素的奇数长度回文 |
 |`1000`相同的值|`1`| 最大允许输入|

 ## 边缘情况

 单元素情况是答案的唯一输入`0`。```
1
7
```回文检查成功，因为没有镜像对可供比较。 然后算法检测到`n == 1`和打印`0`。 更改唯一元素不能生成非回文数组，因为每个长度的数组都是回文数组。 

考虑一个已经是非回文的数组。```
3
1
2
3
```第一个比较发现`1 != 3`，因此回文标志变为 false。 该算法立即打印`1`。 仅增加一个元素后，现有的不匹配不可能全部消失。 

现在考虑一个奇数长度的回文。```
3
1
2
1
```回文检查成功。 由于长度大于 1，因此算法打印`1`。 尽管修改中心使数组保持回文，但修改任一端都会破坏唯一的镜像对，因此有效的移动始终存在。 

最后，考虑具有相同值的偶数长度回文。```
4
5
5
5
5
```回文检查成功，长度超过1。 算法打印`1`。 增加任何位置都会改变镜像对的一侧，而另一侧保持不变`5`，立即销毁回文。
