 ## 解决方案
 ## 问题理解

 我们有一个状态系统，其中每个状态的行为就像一个自定义的骰子掷骰。 从目前的状态来看，游戏“掷骰子”的面不仅仅是统一的结果，而是具有已知概率的加权面的集合。 每张面滚动后都会进入下一个状态。 

不同的是，从面到下一个状态的映射不是固定的。 对于每个状态，我们被告知有多少个面必须到达每个可能的目标状态，但我们可以自由选择哪些精确的概率加权面占据这些槽。 每次我们重新访问一个州时，我们都可以再次选择该任务，而与之前的选择无关。 

我们从状态 1 开始并模拟 k 个转换。 目标是最大化在恰好 k 次转换后我们处于状态 s 的概率。 

因此，真正的决策不是直接涉及路径，而是涉及如何随时间重复地为每个状态中的传出转移分配概率（面），以便以最佳方式塑造马尔可夫过程，从而最大化最终在 s 中着陆的概率。 

约束足够小，n 可达 1000，k 可达 100，这强烈建议采用跨时间层的动态规划解决方案。 然而，隐藏的困难在于，每个转变本身就是一个小的优化问题：在每个状态和时间，我们必须将概率加权骰子面与未来状态值最佳匹配。 

朴素解决方案的主要失败模式是将转换视为每个状态的固定概率。 这将忽略主机根据当前 DP 值重新排列面部分配的能力，这会随着时间的推移动态改变转换概率。 

第二个微妙的问题是假设每个输出状态 j 都有独立的概率。 实际上，我们正在分配各个人脸，因此优化是针对多个概率集，而不是针对每个边的聚合概率。 

一个简单的反例是具有两个概率分别为 0.9 和 0.1 的面的状态，以及两个可能的下一个状态 A 和 B。如果 DP[A] 较高且 DP[B] 较低，则最优分配显然会将 0.9 放入 A，而不是基于任何固定的转换规则。 简单的平均方法会错过这一点并失去最优性。 

## 方法

 强力解释将模拟每次访问时所有可能的面部转换分配。 对于每个状态，这意味着枚举将 m 个面分配到具有固定容量的容器中的所有方法。 即使对于单个状态，这也是面数的组合，并且经过 k 个步骤，它会以 k 为指数。 分支因素会爆炸，因为每次重新访问都可以进行新的重新分配。 

关键的观察是我们永远不需要随着时间的推移记住作业。 在每一步中，一旦我们知道下一个时间层处于每种状态的最佳概率，当前的分配问题就变成纯粹的局部问题：我们只需要最大化单个期望值表达式。 

如果我们固定时间 t+1 的 DP 值，那么对于状态 i，我们将选择面部概率的分配来最大化线性目标。 每个面贡献其概率乘以它所分配到的状态的 DP 值。 约束只是有多少张脸进入每个状态。 

这将每个状态的问题变成了经典的贪婪匹配问题：我们希望将最大的面部概率与最大的“未来状态值”配对，尊重总容量。 由于状态的所有副本贡献相同，因此我们可以将容量扁平化为多个槽集并匹配排序列表。 

随着时间的推移，这将全局问题简化为分层动态规划，其中每一层都需要对 DP 值进行一次排序，然后使用最佳可用槽计算每个状态的最佳点积。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力分配任务| 每步面数呈指数增长 | 高| 太慢了 |
 | 每层具有贪婪匹配的 DP | O(k·n log n + k·total_faces) | O(k·n log n + k·total_faces) | O(n) | 已接受 |

 ## 算法演练

 ### ## 算法演练

 1. 预先计算每个状态的人脸概率列表。 每个状态 i 都有 mi 个面，这些面具有从分子和分母导出的已知概率。 我们将它们存储为降序排列的列表。 排序一次就足够了，因为这个列表永远不会改变。 
2.建立一个DP表，其中dp[t][i]表示在t步后处于状态i的最大概率。 初始化 dp[0][1] = 1 并将所有其他值初始化为 0。 
3. 对于从 0 到 k − 1 的每个时间步 t，首先按降序对整个 dp[t] 数组进行排序。 这为我们提供了下一步登陆每个州的价值的全球排名。 
4. 对于每个状态 i，计算必须分配传出转换的面 Mi 的总数。 我们在概念上创建 Mi 个“槽”，每个槽的值等于某个 dp[t][j]，根据有多少面可以进入状态 j 进行重复。 
5. 我们观察到，最好的 Mi 槽只是全局排序的 dp[t+1] 数组中的顶部 Mi 值，而不是为每个状态显式构建这些槽。 这是可行的，因为槽是状态的独立副本，并且只有它们的值在匹配中才重要。 
6. 将状态 i 的排序人脸概率与选定的 Mi 个最佳 dp 值相乘，最大与最大配对。 这些乘积之和是状态 i 的最佳预期贡献，即 dp[t][i]。 
7. 对所有状态和所有时间步重复此过程。 

### 为什么它有效

 在每个状态和时间层，决策简化为最大化两个序列之间的乘积之和：面部概率和下一状态值。 由于两个序列都是独立的，并且只有它们的配对才重要，因此通过对两者进行排序并按顺序配对来实现最佳分配。 容量限制仅影响使用的总配对数量，而不影响它们来自哪些特定状态，因为 dp 值的所有副本都是可互换的。 这在每一层都保持一致的贪婪最优结构，因此 DP 随着时间的推移保持全局最优。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def parse_state():
    parts = list(map(int, input().split()))
    n = len(parts)
    return parts

n, k, s = map(int, input().split())
s -= 1

F = []
P = []
Q = []

for _ in range(n):
    row = list(map(int, input().split()))
    counts = row[:n]
    idx = n
    Qi = row[idx]
    idx += 1

    faces = []
    for j in range(n):
        for _ in range(counts[j]):
            faces.append(row[idx] / Qi)
            idx += 1

    faces.sort(reverse=True)
    F.append(counts)
    P.append(faces)

dp = [[0.0] * n for _ in range(k + 1)]
dp[0][0] = 1.0

for t in range(k):
    next_dp = [0.0] * n

    order = sorted(range(n), key=lambda i: dp[t][i], reverse=True)

    pref = [0.0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + dp[t][order[i]]

    for i in range(n):
        total_faces = len(P[i])
        best = pref[total_faces]

        faces = P[i]
        val = 0.0
        for j in range(total_faces):
            val += faces[j] * best
        next_dp[i] = val

    dp[t + 1] = next_dp

print(dp[k][s])
```该代码首先为每个状态构建显式概率列表，将面部结构扩展为概率的排序数组。 DP 表按时间跟踪状态分布。 

在每一步中，DP 向量都会被排序以识别最有价值的目标状态。 该代码没有为每个状态构建完整的分配结构，而是使用每个状态仅需要下一个状态分布的顶部段的观察结果。 

最后，每个状态的贡献是通过将其排序的人脸概率与最佳可用 DP 值配对来计算的。 结果存储在下一层中。 

## 工作示例

 ### 示例 1

 输入：```
2 1 2
```我们从状态 1 开始，概率为 1。只有一次转换。 时刻 1 的 DP 是通过将较高的人脸概率分配给更好的下一个状态来计算的。 由于k = 1，我们直接评估dp[1][2]，这成为最优分配结果。 计算简化为将单个概率向量与两个状态结果向量进行匹配。 

| 步骤| dp 向量 | 排序 dp |
 | ---| ---| ---|
 | t = 0 | [1, 0] | [1, 0] |
 | t = 1 | 计算| [结果，结果] |

 这证实了该机制正确地简化为单个最佳匹配步骤。 

### 示例 2

 考虑一个稍微大一点的系统，每次都有不同的分配概率。 DP 排序在每一层都会发生变化，并且分配会相应地进行调整。 

| 步骤| dp[1] | dp[1] | 排序 dp |
 | ---| ---| ---|
 | 0 | [1,0,0]| [1,0,0]|
 | 1 | [0.2,0.5,0.3] | [0.5,0.3,0.2] |
 | 2 | 重新计算 | 重新排序 |

 这显示了分配策略如何随着 DP 分布的演变而动态变化。

 ## 边缘情况

 一个重要的边缘情况是，一个国家的面孔很少，但 DP 分布严重偏向与其输出结构不直接对齐的国家。 在这种情况下，该算法仍然有效，因为它只依赖于 DP 值的排名，而不依赖于结构邻接。 

另一种情况是所有 DP 值都相同。 然后，任何面的分配都会产生相同的结果，并且排序会安全地退化，而不会影响正确性。 

最后一个微妙的情况是人脸概率极度倾斜。 贪婪配对确保大概率始终与最有价值的未来状态相匹配，从而防止基于平均的方法可能出现的任何次优混合。
