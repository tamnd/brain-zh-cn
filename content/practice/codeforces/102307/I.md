 ## 解决方案
 ## 问题理解

 我们得到一个没有空格的文本字符串。 任务是找到字符全部为十进制数字的字符串的最长前缀。 前缀必须非空。 如果第一个字符不是数字，则不存在有效的前缀，我们打印`-1`。 

例如，在`23082019UNAL`, 初始字符`23082019`是数字，而下一个字符`U`不是。 答案是`23082019`。 在`ABC123`，第一个字符已经打破了仅限数字的条件，所以答案是`-1`。 

该字符串最多包含`2 * 10^5`人物。 该大小足够大，以至于二次算法不合适，尤其是在一秒的时间限制下。 解决方案的性能大致如下`n^2`字符检查可以达到大约`4 * 10^10`最大长度的操作，远远超出了所能容纳的极限。 我们基本上需要检查字符串一次，给出一个`O(n)`解决方案。 

有一些边界情况可能会导致原本简单的实现失败。 如果输入是`7`，整个字符串是有效的数字前缀，因此输出为`7`。 期望非数字终止符的实现会错误地错过这种情况。 

如果输入是`A123`，正确的输出是`-1`，因为有效的前缀必须从第一个字符开始。 搜索任何数字串的粗心解决方案可能会错误地返回`123`。 

如果输入是`123A456`，答案是`123`， 不是`123456`。 一旦出现第一个非数字，后面的字符就不能属于所需的前缀。 

如果输入是`0000X`，答案是`0000`。 前缀是字符串，而不是整数，因此必须保留前导零。 在打印之前将前缀转换为整数会错误地产生`0`。 

## 方法

 直接的暴力方法可以考虑每个可能的前缀，并检查该前缀内的每个字符是否都是数字。 对于一个长度的字符串`n`， 有`n`可能的非空前缀。 如果我们检查以位置结尾的前缀`i`从每次开始，字符检查的总数为`1 + 2 + 3 + ... + n = n(n + 1)/2`。 

在`n = 200000`，这是关于`2 * 10^10`检查。 暴力方法在逻辑上是正确的，因为它显式验证有效前缀的定义，但它重复检查已知是数字的字符。 

问题的结构为我们提供了更简单的观察。 当从头开始遇到的每个字符都是数字时，前缀完全有效。 第一个非数字字符永久结束答案。 没有理由在到达较早的字符后重新考虑它，因为前缀不能跳过字符。 

这让我们可以从左到右扫描一次。 在每个位置，如果字符是数字，我们继续。 在第一个非数字处，我们停止并输出该位置之前的所有内容。 如果扫描到达末尾，则整个字符串就是答案。 这将工作从二次减少为线性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取完整的输入字符串并删除尾随换行符。 我们将其保留为字符串而不是将其转换为数字，因为前导零是所需输出的一部分。 
2. 从第一个字符开始向字符串末尾扫描。 扫描代表迄今为止已确认仅包含数字的最长前缀。 
3. 当前字符为数字时，继续扫描。 当前位置之前的每个字符都已被验证，因此通过另一个数字扩展前缀仍然有效。 
4、当前字符不是数字时，立即停止并打印该位置之前的子字符串。 这是最长的可能答案，因为每个较长的前缀都将包含相同的非数字字符。 
5. 如果扫描到达末尾而没有找到非数字，则打印整个字符串。 每个字符都被验证为数字，因此完整的字符串是最长的有效前缀。 
6. 如果第一个字符是非数字，则停止位置为零且其前面的前缀为空。 由于问题需要非空前缀，因此打印`-1`反而。 

### 为什么它有效

 保持之前位置的不变性`i`, 前缀中的每个字符`T[0:i]`是一个数字。 如果`T[i]`也是一个数字，扩展前缀可以保留不变式。 如果`T[i]`不是数字，每个前缀都长于`T[0:i]`包含`T[i]`，因此这些前缀都无效。 因此，第一个非数字位置唯一确定最长的数字前缀。 如果不存在这样的位置，则每个字符都是一个数字，整个字符串就是答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()

    for i, ch in enumerate(s):
        if not ch.isdigit():
            if i == 0:
                print(-1)
            else:
                print(s[:i])
            return

    print(s)

if __name__ == "__main__":
    solve()
```输入行被读取一次，并且`strip()`删除标准输入添加的换行符。 字符串本身永远不会转换为整数，它保留前导零，例如`000123`。 

该循环按原始顺序检查字符。 立刻`isdigit()`返回 false，循环已找到数字前缀和文本其余部分之间的精确边界。 切片`s[:i]`精确包含该边界之前的字符。 

这`i == 0`check 处理非空要求。 如果第一个字符不是数字，`s[:0]`将是一个空字符串，因此所需的输出是`-1`反而。 

该解决方案中没有整数运算，因此整数溢出无关紧要。 唯一重要的边界是第一个无效字符是否出现在索引零处、中间的某个位置，或者根本不出现。

 ## 边缘情况

 对于`A123`，算法检查索引`0`，看到`A`不是数字，立即返回`-1`。 它从不搜索后面的数字段，因为所需的对象是从第一个字符开始的前缀。 

为了`123A456`, 指数`0`,`1`， 和`2`被接受。 在索引处`3`, 字符`A`数字测试失败，因此算法返回`s[:3]`，即`123`。 后缀`456`被故意忽略，因为前缀无法跳过`A`。 

为了`0000X`，每个零都通过数字测试，并且扫描仅在`X`。 返回的子串是`0000`，保留所有四个零。 将答案视为整数会丢失问题要求我们打印的信息。 

为了`7`，循环永远不会遇到非数字。 它到达末尾并返回完整的字符串`7`。 这处理没有终止非数字字符的情况。 

对于一个长度的字符串`200000`完全由数字组成，每个字符都被处理一次并返回完整的字符串。 该算法不需要特殊的最大长度分支，因此上约束是自然处理的。 

对于第一个字符为非数字且其余字符的字符串`199999`字符是数字，算法仍然在一个字符后停止并返回`-1`。 这说明了为什么答案仅取决于第一个不间断的数字，而不取决于文本中后面数字的存在。
