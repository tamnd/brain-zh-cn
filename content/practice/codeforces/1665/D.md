 ## 解决方案
 ## 问题理解

 我们被要求找到一个隐藏的正整数$x$介于 1 和$10^9$。 而不是观察$x$直接，我们可以查询两个数字移位后的最大公约数$x$。 具体来说，对于任意两个正整数$a$和$b$，交互器返回$\gcd(x + a, x + b)$。 任务是确定$x$最多使用 30 个此类查询。 

挑战在于推论$x$间接地通过它与我们选择的对的算术交互。 这些界限表明我们无法对所有内容进行强力搜索$10^9$的可能性。 必须选择每个查询以提取最大信息。 由于我们只得到 GCD，它将多种可能性折叠成一个除数，因此仔细选择$a$和$b$很关键。 

当出现幼稚的边缘情况时$x$非常小或非常大。 例如，如果$x = 1$，查询小值，例如$a = 1$和$b = 2$产量$\gcd(2, 3) = 1$，提供最少的信息。 如果$x = 10^9$，查询大值同样可以将许多可能性压缩为 1，因此该策略必须是自适应的。 

另一个微妙的情况出现时$x + a$和$x + b$是某个除数的连续倍数。 在这种情况下，即使 GCD 为 1$x$本身就很大。 因此，了解可分结构$x$至关重要。 

## 方法

 蛮力方法将迭代所有可能的$x$值，模拟$\gcd(x + a, x + b)$对于某些查询，并检查一致性。 这是不可行的，因为每个测试用例可能需要最多$10^9$检查，我们有多达 1000 个测试用例。 操作次数远远超出合理限度。 

关键洞察来自财产$\gcd(x + a, x + b) = \gcd(a - b, x + b)$。 这将问题转化为理解$x$对各种差值取模。 通过仔细选择差异所在的查询序列$b - a$已知并且相对素数或结构化，我们可以确定$x$对越来越大的数取模。 本质上，这是中国剩余定理的交互式应用：每个 GCD 都给出了一个同余约束$x$，我们将它们结合起来以确定$x$。 

因此，最佳方法是有建设性的。 我们选择查询，使得差异形成二的幂。 这使我们能够提取二进制表示$x$一点一点。 每个 GCD 都会揭示是否设置了某个特定位，并且在 30 次查询后，我们可以重建$x$完全。 2 的幂的使用至关重要，因为它保证每个查询隔离一位，避免重叠和歧义。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每次查询 O(10^9) | O(1) | O(1) | 太慢了 |
 | 最佳 | 每个查询 O(1)，30 个查询 | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化变量`x_guess`为零。 这将保持我们的重构值$x$正如我们推断的那样。 
2. 对于从 0 到 29 的每个位位置，构造一个查询`a = 2^bit`和`b = 0`。 这确保了差异$a - b = 2^bit$，隔离当前位。 
3、查询`? a b`并阅读回复`g`。 计算`g % 2^(bit+1)`。 如果`g`可以整除$2^{bit+1}$，当前位$x$为0，否则为1。更新`x_guess`因此。 
4. 重复直到处理完所有 30 位。 打印最终结果`x_guess`作为隐藏号码。 

工作原理：每个查询都会隔离一个位，因为差异为 2 的幂的 GCD 仅对较低位敏感。 通过采取`g % 2^(bit+1)`，我们检测是否$x$该位置有一个 1。 2 的幂在二进制表示中是成对独立的，确保位不会干扰。 30 次查询后，所有位达到$2^{29}$确定，覆盖整个范围$1 \le x \le 10^9$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
import math

def solve():
    t = int(input())
    for _ in range(t):
        x_guess = 0
        for bit in range(30):
            a = 1 << bit
            b = 0
            print(f"? {a} {b}")
            sys.stdout.flush()
            g = int(input())
            if g % (1 << (bit + 1)) != 0:
                x_guess |= (1 << bit)
        print(f"! {x_guess}")
        sys.stdout.flush()

solve()
```该解决方案首先读取测试用例的数量。 对于每个测试用例，它会迭代 30 多个位位置。 查询隔离位，响应用于重建`x_guess`。 冲洗是必要的，因为这是交互式的。 使用`1 << bit`保证对位选择的精确控制。

 ## 边缘情况

 对于`x = 1`, 查询`a = 1`和`b = 0`产生 GCD 1，指示位 0 已设置，正在重建`x_guess = 1`。 为了`x = 10^9`，查询 2 的大幂可以正确隔离每个位。 该算法正确处理允许范围的两端，并避免差一错误，因为每个查询都使用`1 << bit`模运算精确匹配隔离位的大小。
