 ## 解决方案
 ## 问题理解

 我们有一个固定的 C60 富勒烯，它的 60 个碳原子是截角二十面体（我们熟悉的足球多面体）的顶点。 每个顶点可以保持不变或接收 n 个原子类型之一。 因此，每个顶点都有 n + 1 种可能的状态：空、类型 1、类型 2 等等。 任务是计算分子物理旋转所产生的顶点着色。 每个测试用例的输入包含一个非负整数 n，直到 EOF，每个输出都是不同分子的数量以 1000000007 为模。官方声明确认只有旋转才能识别两个导数，因此镜像保持不同。 

n 的值可以是任何非负有符号 32 位整数，因此它可以大到 2147483647。顶点数固定为 60，这意味着不需要依赖于可变图大小的算法。 挑战在于，可能的颜色数量是 60 的指数级，而 n 本身可能是数十亿。 任何明确考虑所有颜色的一小部分的方法都是不可能的。 我们需要一个仅包含常数个模幂的公式。 

有三种边缘情况很容易被误处理。 首先，n = 0 意味着只有未修改的分子，因此答案必须为 1。将 n 解释为状态数而不是原子类型数的方法将错误地返回 0 或错误地处理空状态。 

其次，不得包含反射。 完整的二十面体对称群有 120 个元素，但只有 60 个保持方向的元素是旋转。 在伯恩赛德引理中使用 120 可以通过镜像识别手性分子并解决不同的问题。 二十面体对称物体的旋转群的阶数为 60。 

第三，除以 60 必须使用 60 的模逆以 1000000007 为模来执行。单独减少每一项后执行整数除法是无效的。 由于 60 和 1000000007 互质，因此乘以 60^-1 模 1000000007 就可以得到所需的结果。 

例如，最小的输入是```
0
```正确的输出是```
1
```恰好存在一种可能的分子，因为不存在原子类型并且每个顶点必须保持为空。 

对于另一个小案例，```
1
```每个顶点有两种状态：空或单原子类型。 Burnside 的公式给出 544393230 模 1000000007。使用 n 而不是 n + 1 作为顶点状态数的粗心实现将只计算一种着色并返回 1。 

## 方法

 直接的方法是将 n + 1 个状态之一分配给 60 个顶点中的每一个。 这恰好创建了 (n + 1)^60 个标记颜色。 对于每种颜色，我们可以生成所有 60 次旋转，选择一个规范代表，并将该代表插入到一个集合中。 这是正确的，因为当一种颜色是另一种颜色的旋转时，两种标记的颜色恰好属于同一分子。 

问题在于着色的数量。 在最坏的情况下，n = 2147483647，因此暴力搜索包含 2147483648^60 个分配，大约为 10^558。 即使每个作业仅仅接触一次也是不可能的。 更一般地说，如果我们检查每种颜色的每次旋转，则简单的枚举需要 θ(60(n + 1)^60) 工作。 

关键的观察是我们实际上不需要构建着色。 对于伯恩赛德引理来说，重要的是每次旋转有多少颜色保持不变。 

伯恩赛德引理指出，轨道数是每个群元素固定的平均着色数。 对于 60 个顶点的排列由 c 个独立循环组成的旋转，当每个循环中的每个顶点接收相同的状态时，着色将精确固定。 每个循环可以独立选择 n + 1 个状态之一，以便旋转固定 (n + 1)^c 个着色。 

截角二十面体具有二十面体的旋转对称群，旋转次数为60。 它的非同一性旋转只有三种可能的顺序。 有 15 个 2 阶旋转、20 个 3 阶旋转和 24 个 5 阶旋转。这些计数也可以从几何角度来看：有 15 个二重轴、10 个三重轴（每个轴上有两个非同一性旋转）和 6 个五重轴（每个轴上有 4 个非同一性旋转）。 截角二十面体本身有 60 个顶点、90 条边、12 个五边形和 20 个六边形。 

非恒等旋转没有固定的顶点。 因此，2 阶旋转将 60 个顶点划分为 30 个长度为 2 的循环，3 阶旋转将它们划分为 20 个长度为 3 的循环，5 阶旋转将它们划分为 12 个长度为 5 的循环。因此，整个计算崩溃为

 [
 \frac{(n+1)^{60}+15(n+1)^{30}+20(n+1)^{20}+24(n+1)^{12}}{60}。 
]

 蛮力方法之所以有效，是因为它显式地构造了每个等价类。 它失败了，因为标记的颜色数量多得天文数字。 Burnside 引理让我们可以间接计算这些类，固定数量的顶点意味着每个测试用例只需要四个模幂。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(60(n + 1)^60) | O(60(n + 1)^60) | O((n + 1)^60) | O((n + 1)^60) | 太慢了|
 | 伯恩赛德引理 | O(log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取 n 并定义 q = n + 1。额外的状态表示碳原子不被修改，而其他 n 状态表示可用的原子类型。 
2. 考虑截角二十面体的 60 个旋转对称性。 恒等旋转有 60 个一顶点循环，15 旋转有 30 个二顶点循环，20 旋转有 20 个三顶点循环，24 旋转有 12 个五顶点循环。 
3. 对于恒等性，每个顶点都可以独立选择，因此固定着色数为q^60。 
4. 对于 2 阶旋转，一个循环中的每对顶点必须接收相同的状态。 有30个循环，所以固定着色数为q^30。 
5. 对于 3 阶旋转，有 20 个循环，给出 q^20 固定着色。 
6. 对于 5 阶旋转，有 12 个循环，给出 q^12 固定着色。 
7. 对所有 60 次旋转应用 Burnside 引理和平均值：

[
 答案=
 (q^{60}+15q^{30}+20q^{20}+24q^{12})/60。 
]
 8. 使用 Python 的模幂计算以 1000000007 为模的所有幂。 乘以 60 的模逆数取代了最后的除法。 

计算背后的不变性是，由旋转固定的着色在该旋转的每个周期中必须保持不变。 相反，为每个循环独立分配任意状态总是会产生由该旋转固定的着色。 因此，具有 c 个循环的排列精确地修复了 q^c 着色。 然后，在对固定着色计数进行平均后，Burnside 对每个旋转等价类精确计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1000000007
INV60 = 616666671

def solve(n):
    q = (n + 1) % MOD

    p60 = pow(q, 60, MOD)
    p30 = pow(q, 30, MOD)
    p20 = pow(q, 20, MOD)
    p12 = pow(q, 12, MOD)

    total = (
        p60
        + 15 * p30
        + 20 * p20
        + 24 * p12
    ) % MOD

    return total * INV60 % MOD

def main():
    out = []
    for line in sys.stdin:
        line = line.strip()
        if line:
            out.append(str(solve(int(line))))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```顶部的常数包含模数和 60 的模倒数。倒数为 616666671，因为

 [
 60 \cdot 616666671 \equiv 1 \pmod {1000000007}。 
]

这`solve`函数首先将原子类型的数量转换为每个顶点可能状态的数量。 服用`n + 1`在减少模数之前，模数是安全的，因为模幂保留了所需的余数。 

每次致电`pow(q, exponent, MOD)`通过平方执行求幂，因此指数值 60、30、20 和 12 仅需要常数次乘法。 Python 整数也避免了溢出，尽管模幂中的每个中间值仍然受到模数的限制。 

系数 15、20 和 24 必须应用于相应的周期计数。 交换这些系数是错误答案的常见原因，因为指数是由循环数决定的，而不是由旋转顺序本身决定的。 

输入循环故意读取直到 EOF。 最初的问题不提供测试用例计数，因此每个非空输入行读取一个整数可以处理官方格式和一个文件中的多个测试用例。 

## 工作示例

 官方样本包含单个测试用例n = 10，其答案为130650357。 

对于第二条迹线，请考虑 n = 0。 

| n | 问 | q^60 | q^30 | q^20 | q^12 | 伯恩赛德分子 | 回答 |
 | ---| ---| ---| ---| ---| ---| ---| ---|
 | 0 | 1 | 1 | 1 | 1 | 1 | 1 + 15 + 20 + 24 = 60 | 1 |

 每一次旋转都会固定唯一可能的颜色，因此固定颜色的总和为 60。除以 60 次旋转得到一个轨道。 这证实了空导数被正确计算。 

对于 n = 1，每个顶点有两种状态。 

| n | 问 | q^60 模 M | q^30 模 M | q^20 模 M | q^12 模 M | 分子 mod M | 回答 |
 | ---| ---| ---| ---| ---| ---| ---| ---|
 | 1 | 2 | 536396504 | 73741817 | 1048576 | 4096 | 663593576 | 544393230 |

 恒等贡献 2^60，而每次非恒等旋转都会迫使同一周期内的顶点一致。 四个固定颜色贡献与系数 1、15、20 和 24 相结合，然后乘以 60 的倒数。 

对于提供的样本 n = 10，q = 11。计算公式为

 [
 \frac{11^{60}+15\cdot11^{30}+20\cdot11^{20}+24\cdot11^{12}}{60}
 \pmod {1000000007}，
 ]

 产生130650357。 

该轨迹表明算法永远不需要知道 60 个顶点的实际位置。 只有每个对称类的循环结构很重要。 

## 复杂度分析

 | 测量| 复杂性 | 说明|

 实际指数固定为 60、30、20 和 12，因此从技术上讲，相对于 n 而言，运行时间为 O(1)。 将其描述为 O(log n) 反映了模幂运算的标准复杂性并且仍然有效。 n 的巨大上限对所需的工作量没有影响。 该解决方案使用恒定内存，可以轻松满足规定的 1 秒和 256 MB 限制。

 ## 边缘情况

 对于 n = 0，输入为```
0
```q = 1。每次旋转都会修复单一的全空着色。 这四项是 1、15、20 和 24，Burnside 分子为 60，答案为 1。算法自然地处理这个问题，无需特殊分支。 

对于 n = 1，输入为```
1
```q = 2。恒等式固定 2^60 种颜色，2 阶旋转固定 2^30，3 阶旋转固定 2^20，5 阶旋转固定 2^12。 应用重数 15、20 和 24 并除以 60 模 1000000007 后，结果为 544393230。这捕获了忘记未修改状态的常见错误。 

对于手性配置，该算法恰好使用 60 次旋转，而不是 120 次空间对称性。 反射不允许识别两个导数，因此必须排除完整二十面体对称群的方向反转一半。 这就是 Burnside 分母为 60 以及系数总和为 60 为 1 + 15 + 20 + 24 的原因。 

对于最大输入，```
2147483647
```我们有 q = 2147483648。该算法从不将 q^60 构造为普通整数。 使用模幂对每个幂进行模 1000000007 减少，因此较大的 n 值不会导致溢出或性能问题。 最后乘以 INV60 执行模域中所需的除法。 

最后，当多个测试用例包含相同的 n 时，每个用例都会被独立评估。 没有依赖于先前情况的可变图或预先计算的状态，因此重复的输入必须产生相同的输出。 基于 EOF 的输入循环还意味着空的最后行或尾随空格不会创建虚假的测试用例。
