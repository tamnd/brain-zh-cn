 ## 解决方案
 ## 问题理解

 我们得到了笛卡尔平面上两棵不同树的坐标，并且我们知道花园形成了一个与轴对齐的完美正方形。 正方形的每个顶点都有一棵树，所以正好有四棵树。 任务是确定另外两棵树的坐标。 如果不存在满足这些条件的方格，我们必须输出-1。 

输入由四个整数组成，代表两棵已知树的 x 和 y 坐标。 每个坐标的范围是-100到100，输出坐标允许大到±1000。 因为输入大小是固定的（只有两个点），所以除了简单的算术运算之外，我们不需要担心效率。 任何仅涉及少量恒定时间检查的解决方案都可以在时间和内存限制内轻松运行。 

边缘情况很微妙。 如果两棵树的 x 坐标相同，则正方形是垂直的； 如果它们共享相同的 y 坐标，则它是水平的。 如果两个坐标都不匹配，则树必须位于正方形的对角顶点，并且沿 x 的距离必须等于沿 y 的距离。 如果这个条件失败，则无法形成正方形。 幼稚的实现可能会忽略这些条件并尝试构建不可能的点。 

例如，输入`0 0 1 2`无法形成与轴对齐的正方形，因为水平和垂直距离不同，因此正确的输出为 -1。 同样，输入`0 0 0 1`表示正方形的垂直边，其他两个顶点的 x 坐标必须移动垂直距离 (1)，得到`(1, 0)`和`(1, 1)`。 

## 方法

 暴力方法将尝试在给定前两点的情况下生成所有可能的正方形，并检查哪种配置形成边平行于轴的有效正方形。 这将涉及水平、垂直和对角线放置的多个条件分支，并检查剩余两点的所有排列。 它之所以有效，是因为正方形受到高度约束，但它引入了不必要的复杂性。 

最佳方法是对两个给定点之间的关系进行分类。 如果它们位于同一条垂直线上，则正方形的边是垂直的，另外两个顶点水平移动垂直距离。 如果它们位于同一水平线上，则该边是水平的，其余顶点垂直移动。 如果它们形成正方形的对角线，则水平和垂直距离必须相等，并且另外两个顶点位于`(x1, y2)`和`(x2, y1)`。 如果这些情况都不成立，则没有有效的正方形。 

这一观察结果将问题简化为三个恒定时间检查和简单算术，确保了 O(1) 时间和空间。

 ## 算法演练

 1.读取坐标`(x1, y1)`和`(x2, y2)`。 
2. 检查两点是否在同一条垂直线上（`x1 == x2`）。 如果是这样，计算水平距离为`d = abs(y2 - y1)`。 其余的顶点是`(x1 + d, y1)`和`(x2 + d, y2)`。 打印这些并退出。 
3. 如果两点在同一水平线上（`y1 == y2`），计算垂直距离`d = abs(x2 - x1)`。 其他顶点是`(x1, y1 + d)`和`(x2, y2 + d)`。 打印并退出。 
4. 如果绝对水平距离等于绝对垂直距离（`abs(x2 - x1) == abs(y2 - y1)`），这些点形成对角线。 其他顶点是`(x1, y2)`和`(x2, y1)`。 打印并退出。 
5. 如果以上条件均不成立，则输出 -1，因为无法形成有效的正方形。 

为什么它有效：在每种情况下，我们都利用正方形的轴对齐属性。 垂直和水平侧边情况依赖于沿垂直轴平移正确的边长。 对角线情况之所以有效，是因为在正方形中，x 坐标之差等于对角相对顶点的 y 坐标之差。 这三项检查涵盖了轴对齐正方形上两个顶点的所有可能放置，保证了正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

x1, y1, x2, y2 = map(int, input().split())

if x1 == x2:
    d = abs(y2 - y1)
    print(x1 + d, y1, x2 + d, y2)
elif y1 == y2:
    d = abs(x2 - x1)
    print(x1, y1 + d, x2, y2 + d)
elif abs(x2 - x1) == abs(y2 - y1):
    print(x1, y2, x2, y1)
else:
    print(-1)
```该代码直接实现了算法中确定的三种情况。 检查的顺序很重要：我们首先检查垂直对齐，然后是水平对齐，最后是对角线对齐。 这`abs`确保边长为正，并且打印顺序符合问题要求以任何顺序输出坐标。
