 ## 解决方案
 ## 问题理解

 我们被赋予的美丽价值观`n`花朵。 我们必须恰好选择两朵花。 

在所有可能的配对中，我们只对美貌差异尽可能大的配对感兴趣。 任务是输出两个值：

 首先，两种所选花的美丽之间的最大可能差异。 

其次，达到最大差异的不同花对的数量。 花是根据位置来区分的，所以两朵同样美丽的花，如果来自不同的指数，仍然是不同的选择。 

制约因素很大。 最多可以有`2 * 10^5`花，美丽值可以大到`10^9`。 检查每一对的二次算法大约需要$$\frac{n(n-1)}{2}$$比较。 为了`n = 200000`，也就是大约200亿对，在一秒之内是完全不可能的。 

美的价值本身就很大，但我们只需要比较和计数就可以了。 不需要动态编程或复杂的数据结构。 

当所有的花都具有相同的美丽时，就会出现微妙的边缘情况。 

输入：```
5
7 7 7 7 7
```每对都有差异`0`，这自动是最大差值。 答案是：```
0 10
```因为有$$\binom{5}{2}=10$$不同的对。 一个粗心的解决方案，只计算最小美丽花朵乘以最大美丽花朵，会错误地产生`25`。 

另一个重要的情况是最小值和最大值多次出现。 

输入：```
5
1 3 1 5 5
```最大差异为`5 - 1 = 4`。 

有两朵花很美丽`1`和两朵美丽的花`5`，因此最优对的数量为：$$2 \times 2 = 4$$正确的输出是：```
4 4
```仅找到一个最小值和一个最大出现次数的解决方案将错误地返回`1`。 

最终的极端情况是尽可能小的输入。 

输入：```
2
100 1
```只有一对存在，所以答案一定是：```
99 1
```无论值如何，都只有一个有效的选择。 

## 方法

 最直接的方法是检查每一对花。 对于每一对，计算美丽差异，跟踪迄今为止看到的最大差异，并计算有多少对实现了这一差异。 

这种暴力方法是正确的，因为它明确地检查每个可能的对。 问题是它的运行时间。 和`n = 200000`，对的数量大约为200亿，这远远超出了可以处理的极限。 

关键的观察是最大可能的差异必须来自最小的美丽值和最大的美丽值。 

假设整个数组中最小的美度是`mn`而最大的美感就是`mx`。 

任何一对的差异不能大于`mx - mn`，因为每一种美都介于这两个极端之间。 同时，选择一朵美丽的花`mn`另一个美丽的`mx`正是实现了这种差异。 

这立即给出了最大差异：$$mx - mn$$剩下的问题是有多少对实现了这一目标。 

如果`mn != mx`，每个最优对必须包含一朵最小值花和一朵最大值花。 任何其他美丽值都会减少差异。 

如果出现最小值`cnt_min`次数并出现最大值`cnt_max`次，那么每个最小花都可以与每个最大花配对：$$cnt\_min \times cnt\_max$$最优对。 

如果`mn == mx`，那么所有的花都具有相同的美丽。 每对都实现差异`0`，所以我们必须计算所有无序对：$$\binom{n}{2} = \frac{n(n-1)}{2}$$这将问题简化为寻找最小值、最大值及其频率。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取花朵的数量及其美丽值。 
2. 求最小美观值`mn`。 
3.寻找最大的美丽值`mx`。 
4. 计算最大差值：`mx - mn`。 
5. 如果`mn == mx`，所有的花都有同样的美丽。 

最大差异为`0`，并且每个无序对都是最优的。 计算：$$\frac{n(n-1)}{2}$$6.不然，数数有多少朵花有美丽`mn`。 打电话给这个`cnt_min`。 
7.数一数有多少朵花是美丽的`mx`。 打电话给这个`cnt_max`。 
8. 最优对的数量为：$$cnt\_min \times cnt\_max$$9.输出最大差异和最优对的数量。 

### 为什么它有效

 任何一对可获得的最大美感差异不能超过全局最大值和全局最小值之间的差异。 由于选择最小值花和最大值花恰好实现了该差异，因此最佳差异唯一确定为`mx - mn`。 

什么时候`mn != mx`，每个最佳对必须使用每个极端的一朵花。 用任何中等美丽的花替换任何一朵花都会减少差异。 因此，最优对的总数恰好是选择最小花和最大花的方法数。 

什么时候`mn == mx`，每朵花都有相同的美丽，所以每一对都会产生差异`0`。 计算所有无序对即可得出正确答案。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    mn = min(a)
    mx = max(a)

    diff = mx - mn

    if mn == mx:
        ways = n * (n - 1) // 2
    else:
        cnt_min = a.count(mn)
        cnt_max = a.count(mx)
        ways = cnt_min * cnt_max

    print(diff, ways)

solve()
```第一步是找到最小和最大的美丽值。 这两个值完全决定了可实现的最大差异。 

计算差异后，实现分为两种情况。 

如果最小值和最大值相等，则每朵花都具有相同的美感。 最优对的数量是其中无序对的数量`n`花，用组合公式计算`n * (n - 1) // 2`。 

否则，唯一的最佳对是由一朵最小值花和一朵最大值花形成的花对。 该代码计算两个值的出现次数并将计数相乘。 

一个容易被忽视的细节是答案的大小。 和`n = 200000`，配对数量可达近200亿。 具有固定大小 32 位整数的语言会溢出。 Python 整数自动增长，因此不需要特殊处理。

 ## 边缘情况

 考虑所有花朵都具有相同美丽的情况：```
5
7 7 7 7 7
```该算法发现`mn = mx = 7`，因此进入特殊分支。 区别在于`0`，最优对的数量变为：$$\frac{5 \cdot 4}{2} = 10$$输出：```
0 10
```这避免了常见的计算错误`5 × 5 = 25`，它计算无效的自配对和重复计数对。 

考虑一个重复出现极端情况的情况：```
5
1 3 1 5 5
```该算法发现`mn = 1`,`mx = 5`,`cnt_min = 2`， 和`cnt_max = 2`。 

最优对的数量为：$$2 \times 2 = 4$$输出：```
4 4
```每对最佳组合都包含一朵美丽的花`1`和一朵美丽的花`5`。 花与美没有一对`3`可以达到最大的差异。 

考虑最小的有效输入：```
2
100 1
```该算法计算`mn = 1`,`mx = 100`，并计算每个出现的次数。 答案变成：```
99 1
```只有一对存在，计数公式自然会产生正确的结果。
