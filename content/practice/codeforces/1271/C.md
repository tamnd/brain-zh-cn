 ## 解决方案
 ## 问题理解

 我们正在研究一个网格，其中移动仅限于四个方向，因此两点之间的距离是使用曼哈顿距离来测量的。 一所学校固定在一个坐标上，每个学生都生活在同一个无限网格上的另一个坐标上。 每个学生都沿着曼哈顿最短的路径从学校步行到家，这意味着他们只能沿着轴线对齐的步骤移动，从不绕行。 

我们可以在除学校之外的任何整数网格点放置一个信息亭。 如果从学校到学生家的至少一条最短路径经过信息亭位置，则该学生被视为买家。 由于曼哈顿几何中可能存在多条最短路径，因此单个学生可能有多条有效路线，而我们只需要其中一条与信息亭相交。 

任务是选择信息亭位置，使其位于尽可能多的学生的最短路径上，并报告最大计数和一个有效的最佳位置。 

约束条件很大，学生人数高达 200,000，坐标高达 10^9。 这立即排除了对所有网格点的任何每个候选人的模拟或每个学生的路径枚举。 任何二次方甚至“尝试所有学生对并计算一些东西”都会失败。 

一个关键的微妙之处是曼哈顿最短路径并不是唯一的。 对于 (x, y) 处的学生，任何首先调整 x 坐标然后调整 y 坐标（反之亦然）或在保持单调进度的同时混合它们的路径都是有效的。 这种灵活性允许多种最佳的自助服务终端放置。 

打破天真的直觉的边缘情况通常来自于忽略路径的多重性。 例如，如果学校、信息亭和学生在曼哈顿意义上是共线的，则简单的实现可能会假设仅存在一条路径并错过有效的包含项。 

另一个特殊情况是许多学生共享同一个房屋坐标。 这不会改变他们的贡献逻辑，但会增加计数，因此将相同的点分组很重要。 

## 方法

 一个蛮力的想法是将每个网格点视为候选信息亭位置，并且对于每个学生，检查是否存在从学校到该学生经过该点的最短路径。 对于固定的学生，可以通过检查曼哈顿距离是否可加分解来验证一个点是否位于任何最短路径上：当且仅当该路径经过 P

 距离（s，P）+距离（P，学生）=距离（s，学生）。 

此检查对于每个学生来说都是恒定的时间，因此评估一名候选人需要 O(n)。 然而，网格非常巨大，可能的位置多达 10^9 x 10^9。 即使将候选者限制在学生地点（这是一种自然的简化），仍然会留下多达 200,000 个候选者，在最坏的情况下会产生 O(n^2) 行为，这太慢了。 

结构见解是，上述条件不依赖于任意几何形状，而仅依赖于相对于学校的坐标比较。 扩大平等表明，如果信息亭在 x 和 y 方向上单调地位于学校和学生之间，则学生做出贡献。 更准确地说，信息亭必须位于学校和学生形成的轴对齐矩形内，并且与一致的行进方向对齐。 

这将问题简化为定向计数问题。 每个学生都会产生一个锚定在学校的矩形，我们希望一个点被尽可能多的这样的矩形覆盖。 我们不是扫描平面，而是观察到最佳点必须在四个基本方向之一上与学校相邻，因为在象限内移动候选人永远不会减少覆盖范围，并且总是可以被推向学校旁边的边界，而不会失去任何满意的学生。

因此，我们只需要测试四个候选位置：从学校向右、向左、向上或向下一步，并选择使 x 或 y 坐标相对于学校位于正确一侧的学生数量最多的方向。 

这将问题变成了对所有学生的简单计数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解网格/候选人 | O(n²) 或更糟 | O(1) | O(1) | 太慢了|
 | 从学校出发的方向计数 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将决策简化为学校周围的四个规范候选点：在每个基本方向上移动一个单元。 对于每个方向，我们计算有多少学生可以通过该相邻单元格的最短路径。 

1. 考虑从学校出发的四个方向：右（增加 x）、左（减少 x）、上（增加 y）、下（减少 y）。 每个方向对应于选择与学校相邻的候选单元格。 这种限制之所以有效，是因为任何最佳解决方案都可以向学校转移，直到它到达这些边界相邻位置之一，而不会失去其已经服务的任何学生的有效性。 
2. 对于每个学生，确定从学校到该学生的最短路径可以通过第一步的哪些方向。 这纯粹是通过坐标比较来决定的。 如果学生位于学校的右侧 (x_i > s_x)，则从学校向右移动可能是通往该学生的最短路径的第一步。 类似地，如果 x_i < s_x，则 left 有效。 相同的逻辑独立适用于 y。 
3. 维护四个计数器，对应于从学校每个方向可联系到的学生数量。 对于每个学生，根据他们是否位于不同的相对象限，精确地增加一个或两个计数器。 
4. 选择计数器最大的方向。 如果多个方向相同，则任何一个都可以接受。 
5. 输出选择的计数和对应的相邻坐标。 

关键思想是曼哈顿最短路径在 x 和 y 上独立地是单调的，因此离开学校的第一个动作决定了哪组学生可能将该单元格包含在他们的最短路径中。 

### 为什么它有效

 对于任何学生来说，从学校到学生的最短路径必须首先沿着每个轴朝或远离每个轴移动，之后不能反转方向。 因此，如果信息亭放置在紧邻学校的位置，方向与学生的相对位置一致，我们总是可以构建一条经过第一步的最短路径。 同一方向上任何较远的点都不会提高覆盖范围，因为它排除了一些本来能够到达较近点的学生。 这使得最佳解决方案可简化为测试四个边界相邻位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, sx, sy = map(int, input().split())

right = left = up = down = 0

for _ in range(n):
    x, y = map(int, input().split())
    
    if x > sx:
        right += 1
    if x < sx:
        left += 1
    if y > sy:
        up += 1
    if y < sy:
        down += 1

best = max(right, left, up, down)

if best == right:
    print(best)
    print(sx + 1, sy)
elif best == left:
    print(best)
    print(sx - 1, sy)
elif best == up:
    print(best)
    print(sx, sy + 1)
else:
    print(best)
    print(sx, sy - 1)
```该解决方案扫描每个学生一次，并沿 x 和 y 轴相对于学校对他们进行分类。 每个分类都直接影响方向计数。 最终选择选择最佳方向并输出有效的相邻坐标。 不需要路径的几何重建，因为曼哈顿最优路径沿轴独立分解。 

一个微妙的实现细节是学生独立地对水平和垂直计数器做出贡献。 这是故意的，因为最短路径可以构造为通过轴优先或 y 轴优先移动，因此两个维度都提供有效的路径选择。 

当学校位于坐标 0 或 10^9 时，边界处理很重要。 该问题保证所选点必须保持在边界内，并且由于至少一个方向始终有效（除非在边界处，在这种情况下相反的方向有效），因此邻接逻辑仍然安全。

 ## 边缘情况

 一个重要的边缘情况是所有学生都恰好躺在学校的一侧。 例如，如果所有学生都满足 x > s_x，则算法始终选择正确的方向并将信息亭放置在 (s_x + 1, s_y)。 每个学生仍然有一条穿过该单元的最短路径，因为所有最佳路径都是从向右移动开始的。 

另一个边缘情况是学生均匀分布在所有四个方向。 在这种情况下，多个方向并列。 该算法选择任何最大值，这是有效的，因为该问题允许任意平局打破。 

最后一种微妙的情况是，许多学生在一个轴上共享相同的坐标，但在另一个轴上共享的坐标却不同。 例如，所有 x = s_x 但 y 不同。 水平计数器保持为零，解决方案完全取决于垂直分布。 该算法自然地处理这个问题，因为它干净地分离了轴比较，并且不假设两个轴必须同时做出贡献。
