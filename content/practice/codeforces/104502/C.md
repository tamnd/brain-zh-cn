 ## 解决方案
 ## 问题理解

 我们正在模拟 Teadose 在一系列比赛中的评分。 每场比赛都有两个属性：表现值和分区旗帜。 从初始评级开始，我们按顺序处理比赛，根据当前的评级范围和比赛类别更新评级。 

关键的复杂性是，除非当前评级位于特定区间内，否则大多数比赛都是“不活跃的”。 当比赛进行时，评级会根据表现和当前评级之间的差异进行小幅调整，除以四并截断为零。 否则，评级保持不变。 

除了这个模拟之外，我们最多可以完全忽略一场比赛。 目标是选择是不跳过一场比赛还是跳过一场比赛，以使最终评分尽可能大，因为最小化“传奇掉落”相当于最大化最终评分。 

输入大小高达十万个竞赛，因此任何尝试为每个可能跳过的位置重新计算完整过程的解决方案都太慢。 二次方法需要大约$10^{10}$在最坏的情况下进行操作，这远远超出了可行的限度。 

此模拟中的一个微妙问题是，跳过比赛会改变评分轨迹，进而影响后续比赛是活跃还是不活跃。 这种依赖性使得本地推理变得棘手。 

当跳过比赛改变评级足以改变未来的激活条件时，就会出现常见的失败情况。 例如，考虑这样一种情况：跳过的比赛使评分保持在 2100 以下，从而允许许多未来的 div2 更新，否则这些更新将处于非活动状态。 天真的“删除并重新模拟”每个索引的方法可能会意外地假设独立性并错过这些级联效应。 

## 方法

 蛮力的想法很简单：尝试跳过所有可能的比赛（或不跳过任何比赛），每次模拟完整的过程，并获得最佳结果。 每次模拟费用$O(n)$，并这样做是为了$n$选择导致$O(n^2)$，这对于$10^5$。 

关键的观察结果是，一旦跳过决策固定，该过程就是连续的和确定性的。 在任何时候，未来仅取决于当前的评级以及料斗是否已被使用。 我们不需要记住跳过了哪一场比赛，只需要记住将来是否仍然可以选择跳过一场比赛。 

这将问题简化为一个动态过程，每个竞赛索引有两种状态：一种是我们尚未使用跳过，另一种是我们已经使用过它。 每个状态仅存储单个整数评级，而不是完整的历史记录。 直接从上一步应用转换。 

我们通过单次向前传播这两个状态来避免重新计算完整的模拟。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（跳过每个索引+模拟）|$O(n^2)$|$O(1)$| 太慢了|
 | 前缀上的两态 DP |$O(n)$|$O(1)$| 已接受 |

 ## 算法演练

 我们在从左到右扫描比赛时保持两个运行值。 

1. 我们初始化两个评级：一种是不跳过任何比赛的情况，另一种是允许我们最多跳过一场比赛的情况。 
2. 对于每场比赛，我们首先计算自然过渡（如果我们接受）。 此更新取决于当前评级和比赛类型。 如果评级超出该部门的有效区间，则评级不会更改。 否则，我们应用基于的截断更新$(p_i - r) / 4$。 
3. 我们通过直接应用转换来更新“未使用跳过”状态，因为该状态没有灵活性。 
4. 对于“允许跳过”状态，我们考虑两种可能性。 我们要么进行比赛并从之前的跳过状态进行转换，要么跳过本次比赛，这仅在尚未使用跳过时才有效。 如果我们在这里跳过，评级将保持等于之前未使用跳过的状态，因为跳过会消耗单个允许的删除并保留之前的评级。 
5. 我们选择这两种可能性中较好的一个作为跳跃状态。 
6. 处理完所有比赛后，我们比较两个州的最终评分并取较大的一个。 

### 为什么它有效

 关键的特性是，在每个指数中，国家都充分捕获了与未来决策相关的所有内容。 未来唯一重要的信息是当前评级以及料斗是否已被使用。 任何两个以相同评级和相同跳过状态结束的历史对于所有未来的转换都是可以互换的，因为未来的比赛仅取决于这两个值。 这使得 DP 最优子结构有效，因为未来的演化与我们如何达到状态无关。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def apply(r, p, d):
    if d == 0:
        if r >= 2100:
            return r
    else:
        if r < 1900:
            return r

    diff = (p - r) // 4
    return r + diff

n, k = map(int, input().split())
p = list(map(int, input().split()))
d = list(map(int, input().split()))

dp0 = k
dp1 = k

for i in range(n):
    ni = apply(dp0, p[i], d[i])
    new_dp1_take = apply(dp1, p[i], d[i])

    new_dp1_skip = dp0

    dp0 = ni
    dp1 = max(new_dp1_take, new_dp1_skip)

ans = max(dp0, dp1)
print(k - ans)
```这`apply`函数完全按照规定对竞赛规则进行编码。 它首先检查比赛在当前等级下是否处于活动状态； 如果不是，则返回不变的评级。 否则，它使用下限除法应用整数截断除法规则，其符号行为与此范围内向零的截断一致。 

我们维持`dp0`作为未使用跳跃时的评级，并且`dp1`作为迄今为止最多使用一个料斗时的最佳评级。 该转换仔细区分了在当前比赛中消耗跳过和继续而不使用它。 

一个常见的错误是允许`dp1`即使比赛之前已经使用过跳过，也可以跳过比赛。 这将错误地允许多次删除。 另一个微妙的问题是跳跃时混合状态：跳跃必须始终来自尚未使用跳跃的状态，即`dp0`， 不是`dp1`。

def solve():
    import sys
    input = sys.stdin.readline

    def apply(r, p, d):

                return r
        else:
            if r < 1900:

 ## 边缘情况

 当跳过改变未来比赛是否活跃时，就会出现棘手的情况。 例如，跳过早期比赛可能会使评级保持在 2100 以下，从而使以后的 div2 收益得以实现，否则这些收益将被阻止。 DP 正确地处理了这个问题，因为两个州都明确将当前的评级向前推进，并且每个未来的决定都是根据该确切的评级而不是任何推断的历史来计算的。 

另一个边缘情况是最优策略从不使用跳过。 这是自然处理的，因为`dp1`始终包含完全忽略跳过并遵循与以下相同的转换的选项`dp0`，确保最后比较两种可能性。
