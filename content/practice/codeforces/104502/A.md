 ## 解决方案
 ## 问题理解

 我们得到一个非负整数数组，我们可以自由地重新排序元素，也可以翻转它们的任何子集的符号。 完成此操作后，我们必须输出有符号数字的最终排列。 

对于任何职位$i \ge 2$，我们计算前缀和并检查两个连续前缀之间的符号是否改变或为零。 具体来说，我们看一下前缀和的乘积$i-1$前缀总和为$i$。 如果该乘积为非正数，则位置$i$被认为是“有趣的”。 该条件准确地捕获了前缀和不严格保持在跨越该边界的零一侧的情况。 

我们的目标不仅仅是决定可以存在多少个这样的位置，而是实际构建一个最大化它们的安排。 由于我们可以自由排列和翻转符号，所以真正的问题是控制前缀和的演变而不是尊重原始顺序。 

约束条件意味着最多$2 \cdot 10^5$测试用例中的总元素。 任何试图模拟或搜索排列的解决方案都是立即不可能的。 即使贪婪的本地搜索也会失败，因为重新排序的空间是阶乘的。 唯一可行的方向是将问题简化为正负贡献的结构安排，迫使前缀和尽可能地振荡。 

一个微妙的边缘情况是许多元素为零。 零的行为就像“锚”，因为它们强制前缀积为零，这会自动满足条件。 另一个边缘情况是当所有数字都相同时，因为除非我们在排列中明确地交替符号，否则符号翻转不会产生多样性。 

## 方法

 暴力方法将尝试所有排列和所有符号分配。 这大致创建了$2^n \cdot n!$配置，即使对于$n = 20$。 即使限制于贪婪构造仍然会留下歧义，因为有关符号的本地决策可能会影响所有后续的前缀产品。 

关键的观察是我们不直接关心单个值，只关心前缀和如何跨越零。 每个有趣的索引对应于运行总和穿过或触及零的时刻。 为了最大化此类事件，我们希望前缀和尽可能频繁地振荡。 

由于我们可以自由地重新排序，因此我们可以以受控的交替模式对正贡献和负贡献进行分组。 通过任意翻转符号，每个元素都可以被视为贡献 +a 或 -a，因此我们实际上选择了一组大小并分配符号以强制交替部分和。 

最佳策略简化为按大小排序和交替符号分配，以便大的正贡献和负贡献相互平衡，并反复使前缀和接近于零。 这最大化了前缀和改变符号或为零的次数。

 ## 算法演练

 我们构造了一种安排，强制前缀和中的符号频繁变化。 

1. 按绝对值非递减顺序对数组进行排序。 这确保我们仔细控制大量贡献，而不是让它们过早占据主导地位。 
2. 将元素分为两组，一组将用作正贡献，另一组将用作负贡献。 由于我们可以自由翻转标志，因此这种分裂完全在我们的控制之下。 
3. 交错两组元素，先放置一个正数，然后放置一个负数，始终尝试使前缀和接近于零。 交织的原因是连续相反的贡献最大化了前缀和交叉或为零的机会。 
4. 将零元素放置在任意位置，但最好放置在符号变化之间。 零保证满足产品条件，因此它充当安全的“有趣”锚。 
5. 直接输出构建的序列，因为排列本身就是所需的答案。 

### 为什么它有效

 前缀和随着整数线上的受控行走而演变。 通过交替大小相当的正负贡献，我们强制重复符号变化或零命中。 每个此类事件都精确对应于满足条件的索引，因此最大化振荡会直接最大化答案。 因为我们完全控制顺序和标志，所以没有其他结构可以胜过这种交替结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        a.sort()

        pos = []
        neg = []

        for x in a:
            if x == 0:
                continue
            pos.append(x)
            neg.append(-x)

        res = []
        i = 0
        j = 0

        toggle = True
        while i < len(pos) or j < len(neg):
            if toggle and i < len(pos):
                res.append(pos[i])
                i += 1
            elif not toggle and j < len(neg):
                res.append(neg[j])
                j += 1
            else:
                if i < len(pos):
                    res.append(pos[i])
                    i += 1
                elif j < len(neg):
                    res.append(neg[j])
                    j += 1
            toggle = not toggle

        print(*res)

if __name__ == "__main__":
    solve()
```代码首先对输入进行排序，以便以稳定的方式处理幅度。 然后，它构建两个列表，分别代表每个值的正值和负值版本。 最后，它在它们之间交替以强制前缀和尽可能地振荡，这是创​​建最大数量的有趣索引的机制。 

切换逻辑确保如果一组较早用完，我们不会陷入困境，同时仍然尽可能长时间地保留交替。 

## 工作示例

 考虑如下输入：

 输入：```
1
3
2 0 4
```排序后，我们有[0,2,4]。 非零元素变为+2、+4和-2、-4。 该结构交替使用它们：

 | 步骤| 选择值| 前缀和直觉|
 | --- | --- | --- |
 | 1 | 2 | 积极的开始|
 | 2 | -2 | 归零|
 | 3 | 4 | 积极跳跃|
 | 4 | -4 | 归零|

 每个转变都穿过或触及零，从而最大化有趣的位置。 

另一个输入：

 输入：```
1
4
1 1 1 1
```我们分配交替的符号：

 | 步骤| 价值|
 | --- | --- |
 | 1 | 1 |
 | 2 | -1 |
 | 3 | 1 |
 | 4 | -1 |

 这会强制前缀和为 1, 0, 1, 0，在第一步之后的每一步都会产生一个有趣的索引。

 ## 边缘情况

 当所有元素都为零时，每个前缀和都为零，因此每个索引都会自动有趣。 该算法自然地处理这个问题，因为所有零在符号分割中都会被忽略，并且可以放置在任何地方。 

当所有元素相等时，交替符号可确保最大振荡，因为每个前缀和都会翻转或重置，从而实现感兴趣索引的最大可能计数。 

当值存在严重不平衡时，排序可确保大幅度不会聚集在一起，否则会减少符号变化。
