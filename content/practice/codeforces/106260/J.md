 ## 解决方案
 ## 问题理解

 我们正在构建长度的字符串$n$正好使用四个字符：$y, u, k, o$。 该限制是局部的：如果您查看任何 5 个字符的连续块，该块一定不能是由单词“yuuko”的字母形成的多重集的排列。 

“yuuko”一词包含以下字符$y, u, u, k, o$，所以任何禁止块都是一个长度为 5 的窗口，其中包含一个$y$， 二$u$的, 一$k$，和一个$o$，以任意顺序。 任务是统计有多少个长度有效的字符串$n$在此约束下存在，模$998244353$。 

关键的困难在于限制不是关于精确的子串，而是关于滑动窗口上的多重集条件。 这使得简单的子串匹配技术变得无效，因为没有固定的模式来逐个位置匹配； 只计算物质。 

约束条件$n \le 10^{18}$立即排除长度上的任何线性或多项式 DP。 任何解决方案都必须压缩状态，以便可以使用幂或其他对数方法迭代转换。 唯一可行的方向是将过程建模为有限自动机，其状态仅取决于字符串的有限历史。 

当多个重叠窗口同时违反该条件时，会出现微妙的边缘情况。 例如，字符串可能在位置处无效$i$，但还包含另一个以以下结尾的无效窗口$i+1$。 任何正确的方法都必须确保每个窗口在形成时都得到准确的检查，而不是追溯。 

## 方法

 暴力方法将生成所有$4^n$字符串并检查每一个是否有禁止的窗口。 即使是为了$n=20$，这已经变得不可行了，并且对于$n$最多$10^{18}$，这是完全不可能的。 稍微好一点的暴力方法是在前缀上使用动态编程，显式存储最后 4 个字符。 这将状态转换减少到可管理的大小，但仍然与$n$，太大了。 

关键的观察结果是禁止条件仅取决于最后 5 个字符。 当我们追加一个新字符时，只有在该位置结束的窗口才会重新变得无效。 这建议维持长度为 4 的滑动窗口作为状态。 下一个字符完成了一个大小为 5 的窗口，我们可以直接测试该窗口是否与禁止的多重集匹配。 

这将问题简化为有限状态机$4^4 = 256$可能的状态（长度最多为 4 个字符以上 4 个字符的所有可能序列）。 转换是通过附加一个字符并移动窗口来确定的。 自从$n$是巨大的，我们计算长度的数量-$n$使用矩阵求幂在该自动机中行走。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举 |$O(4^n)$|$O(n)$| 不可能|
 | DP 前缀长度 |$O(n \cdot 4^4)$|$O(4^4)$| 太慢了|
 | 自动机 + 矩阵求幂 |$O(256^3 \log n)$|$O(256^2)$| 已接受 |

 ## 算法演练

 1. 将状态定义为字符串的最后最多 4 个字符。 由于每个位置有4个选择，所以最多有$4^4 = 256$州。 我们将每个状态表示为长度为 4 的 base-4 编码。 
2. 对于每个状态和每个可能的下一个字符，我们模拟附加该字符并形成一个新的 5 字符窗口，该窗口由前 4 个字符加上新字符组成。 我们计算该窗口中的字符数。 
3. 如果这5个字符的多重集完全匹配$\{y, u, u, k, o\}$，我们将此转换标记为无效并丢弃它。 否则，我们添加从当前状态到通过左移并附加新字符获得的新状态的定向转换。 
4. 这给出了最多 256 个节点的有向图，其中每个节点最多有 4 个传出转换。 我们将其转换为转移矩阵$T$， 在哪里$T[i][j]$计算状态的有效转换$i$陈述$j$。 
5. 我们初始化一个表示所有有效起始状态的向量。 由于短于 4 个字符的字符串不会违反条件，因此允许所有初始状态。 
6.我们计算$T^n$使用快速求幂。 每个乘法对应于在保持有效性的同时扩展字符串的组合方式。 
7. 最后，我们将结果向量的所有条目相加，以获得长度为有效的字符串总数$n$。 

正确性取决于每个 DP 状态都完全捕获确定添加一个字符是否会创建禁止的 5 长度窗口所需的所有信息的不变量。 因为任何违规都会在出现时被准确检测到，所以不会有任何无效字符串对 DP 产生影响。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

# map characters to indices
mp = {'y': 0, 'u': 1, 'k': 2, 'o': 3}

def encode(s):
    x = 0
    for c in s:
        x = x * 4 + c
    while len(s) < 4:
        x *= 4
        s += [0]
    return x

def decode(x):
    s = []
    for _ in range(4):
        s.append(x % 4)
        x //= 4
    return tuple(reversed(s))

# forbidden multiset: y, u, u, k, o
forbidden = [0, 1, 1, 2, 3]

def is_bad(window):
    cnt = [0] * 4
    for c in window:
        cnt[c] += 1
    return cnt == [1, 2, 1, 1]

# build transitions
N = 256
T = [[0] * N for _ in range(N)]

for s in range(N):
    cur = decode(s)
    for c in range(4):
        window = list(cur) + [c]
        if is_bad(window):
            continue
        ns = tuple(list(cur[1:]) + [c])
        ns_id = 0
        for v in ns:
            ns_id = ns_id * 4 + v
        T[s][ns_id] += 1

def matmul(A, B):
    n = len(A)
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        Ai = A[i]
        for k in range(n):
            if Ai[k]:
                Bik = B[k]
                aik = Ai[k]
                for j in range(n):
                    res[i][j] = (res[i][j] + aik * Bik[j]) % MOD
    return res

def matpow(M, e):
    n = len(M)
    res = [[0]*n for _ in range(n)]
    for i in range(n):
        res[i][i] = 1
    while e:
        if e & 1:
            res = matmul(res, M)
        M = matmul(M, M)
        e >>= 1
    return res

# initial vector: all states allowed
# we start from length 4 padding-free states, so treat all as 1
init = [1] * N

def solve(n):
    if n == 0:
        return 1
    if n <= 4:
        return pow(4, n, MOD)

    P = matpow(T, n - 4)

    ans = 0
    for i in range(N):
        for j in range(N):
            ans = (ans + P[i][j] * init[i]) % MOD
    return ans

n = int(input())
print(solve(n))
```该代码在所有长度为 4 的历史上显式构造自动机。 每个转换都会检查添加新字符是否会在生成的 5 长度窗口中创建禁止的多重集。 然后矩阵求幂计算所有有效长度序列$n$在对数时间内。 

一个微妙的实现细节是$n \le 4$，根本不存在长度为 5 的窗口，因此每个字符串都是有效的，答案很简单$4^n$。

### 示例 2：$n = 6$现在存在两个重叠的窗口：位置$[1..5]$和$[2..6]$。 字符串可能违反任一窗口中的条件。

这表明重叠违规可以自然处理，无需显式重新检查。
