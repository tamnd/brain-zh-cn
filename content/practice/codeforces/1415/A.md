 ## 解决方案
 ## 问题理解

 我们有一个长方形的监狱$n$行和$m$列。 每个牢房只容纳一名囚犯，并且位于第 1 排的牢房内有一个出口隧道$r$和列$c$。 每个囚犯都可以在一秒钟内移动到任何相邻的牢房（上、下、左、右），或者留在原地。 目标是确定如果所有囚犯都以最佳方式移动，最后一名囚犯到达逃生隧道需要多长时间。 结果是所有囚犯可以在出口聚集的最短秒数。 

输入提供了多个测试用例，每个测试用例都给出了监狱的大小和隧道的位置。 每个测试用例的输出是一个整数，表示所有囚犯到达隧道所需的最短时间。 

限制条件非常大：$n$和$m$可以达到$10^9$，以及测试用例的数量$t$可以达到$10^4$。 这立即排除了对所有单元的任何模拟或迭代。 我们无法单独计算每个囚犯的距离，也无法存储完整的距离$n \times m$内存中的矩阵。 解决方案必须是直接计算最大距离的公式。 

非明显的边缘情况涉及位于角落或边缘的隧道。 例如，如果隧道位于某个区域的左上角$1 \times 1$监狱，答案是 0。如果隧道位于$(1, 1)$在一个$10 \times 10$监狱，最远的囚犯在对面的角落$(10, 10)$，时间是$18$。 假设隧道靠近中心或平均距离的粗心方法会在这里产生错误的答案。 

## 方法

 蛮力方法是将每个囚犯想象为网格中的一个点，并计算其到隧道的曼哈顿距离。 对于每个囚犯$(i, j)$，距离为$|i - r| + |j - c|$。 所有囚犯到达隧道的最短秒数就是所有牢房的最大距离。 这在概念上是可行的，但是会迭代一个单元格中的每个单元格$n \times m$网格对于大来说是不可能的$n$和$m$。 对于最坏的情况，与$n = m = 10^9$，这需要$10^{18}$的操作，这是完全不可行的。 

关键的见解是我们只需要距离隧道最远的囚犯。 在矩形网格中，距给定单元最远的单元始终是四个角之一。 因此，我们可以计算从隧道到每个拐角的距离并取最大值。 这将问题从迭代数十亿个单元格简化为简单地计算四个表达式。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n*m) | O(1) | O(1) | 太慢了 |
 | 最佳 | 每个测试用例 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量，$t$。 
2. 对于每个测试用例，阅读尺寸$n$和$m$和隧道位置$(r, c)$。 
3. 识别网格的四个角：$(1, 1)$,$(1, m)$,$(n, 1)$， 和$(n, m)$。 
4. 计算从隧道到每个角的曼哈顿距离：$|r - 1| + |c - 1|$,$|r - 1| + |c - m|$,$|r - n| + |c - 1|$， 和$|r - n| + |c - m|$。 
5. 取这四个距离中的最大值。 这代表最远的囚犯到达隧道所需的最短秒数。 
6. 打印每个测试用例的最大距离。 

工作原理：曼哈顿距离准确地表示当移动仅限于基本方向时网格中所需的最小移动次数。 距离隧道最远的囚犯必须在其中一个角落，因为网格内的任何点都比至少一个角落更靠近隧道。 采取最大距离可确保所有囚犯（包括最远的囚犯）都能到达隧道。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m, r, c = map(int, input().split())
    dist1 = abs(r - 1) + abs(c - 1)
    dist2 = abs(r - 1) + abs(c - m)
    dist3 = abs(r - n) + abs(c - 1)
    dist4 = abs(r - n) + abs(c - m)
    print(max(dist1, dist2, dist3, dist4))
```该解决方案首先读取测试用例的数量。 对于每个测试用例，它读取代表监狱大小和隧道坐标的四个整数。 使用绝对差计算到四个角的距离，这直接实现了曼哈顿距离。 打印这四个值中的最大值。 使用`abs`保证负差不会导致错误，并且独立计算每个距离可以避免差一错误。

这些示例表明，最大距离始终来自其中一个角，并且算法可以正确识别它。

 ## 边缘情况

 对于一个$1 \times 1$监狱里，隧道是唯一的牢房。 该算法计算到单个角点的距离$(1,1)$，即 0。输出正确为 0。 

对于隧道位于拐角处的最大尺寸网格，$(1,1)$在一个$10^9 \times 10^9$监狱，最远的囚犯在$(10^9,10^9)$。 该算法计算`abs(1-10^9) + abs(1-10^9) = 1999999998`，符合预期。 

当隧道位于中心时，到拐角的距离会有所不同。 该算法正确地选择最大值，确保在不迭代所有单元的情况下考虑最远的囚犯
