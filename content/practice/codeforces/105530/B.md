 ## 解决方案
 ## 问题理解

 我们正在查看通过固定数字产生的所有余数$n$并将其除以每个整数$i$从$1$到$n$。 这给出了一组形式的值$n \bmod i$。 除数的每个选择都会产生以下之间的余数$0$和$i - 1$，因此在所有除数中，我们收集结构化但不是任意的整数集。 

任务是确定这些余数中从未出现过的最小非负整数。 换句话说，我们正在计算集合的 MEX$\{ n \bmod i \mid 1 \le i \le n \}$。 

约束结构极其严格。 由于输入是单个整数，因此任何解决方案$O(n)$甚至$O(\sqrt{n})$速度足够快，真正的挑战不是计算，而是识别余数集中的模式。 

一种简单的方法会显式计算所有值$n \bmod i$，将它们插入到一个集合中，然后从零开始向上扫描，直到找到第一个缺失的整数。 这是机械地工作的，但它隐藏了结构并且可能会误导关于实际可以达到的值的直觉。 

当推理大值是否可以作为余数出现时，会出现一个微妙的陷阱。 例如，人们可能会错误地假设接近于$n$可能会出现，因为模量随着变化$i$，但实际上每个余数都严格小于其除数，这限制了全局意义上的最大可能值。 

例如，当$n = 5$，该集合为：$5 \bmod 1 = 0$,$5 \bmod 2 = 1$,$5 \bmod 3 = 2$,$5 \bmod 4 = 1$,$5 \bmod 5 = 0$,

 所以墨西哥是$3$。 

事实证明，正确答案仅取决于保证出现多少个小整数，而不取决于所有余数的精确分布。 

## 方法

 直接暴力策略计算每个余数$n \bmod i$为了$i$从$1$到$n$。 这会产生$n$值，然后将它们插入到布尔数组或集合中，并线性搜索最小的缺失整数。 这是正确的，因为它详尽地构建了目标集。 

这种方法的成本是线性的$n$，既用于生成余数又用于扫描。 这最多就是关于$2n$操作，这对于典型的约束来说很好，但没有提供结构洞察。 

关键的观察结果是，余数集在周围有一个尖锐的阈值$\lceil n/2 \rceil$。 每个小于此阈值的整数都可以显示为某个除数的余数，而阈值本身永远不能保证存在。 这会创建一个从零开始的可实现值的连续前缀，并且 MEX 正是该前缀之外的第一个值。 

蛮力之所以有效，是因为它直接枚举所有残数，但一旦我们认识到可达值形成一个连续区间，它就变得不必要了。 问题归结为确定该间隔的长度，而不是显式地构造它。

 ## 算法演练

 最佳解决方案基于识别可达余数的结构。 

1. 计算$k = \lceil n/2 \rceil$。 该值充当将有保证的余数与不可能的余数分开的边界。 
2. 返回$k$作为答案。 这是第一个不能表示为的整数$n \bmod i$对于任何$i \le n$。 

此步骤有效的原因来自于模归约的行为方式：可以通过选择略大于我们想要的余数的除数来形成小值，而等于或高于阈值的值无法在约束中幸存$n \bmod i < i$为所有人$i$。 

### 为什么它有效

 对于任意整数$m < \lceil n/2 \rceil$，我们可以构造一个除数$i = n - m$。 这一选择确保了$n \bmod i = m$， 自从$n = 1 \cdot (n - m) + m$。 条件$i \le n$自动保持，因为$m > 0$意味着$i < n$，并且对于$m = 0$，我们可以取$i = n$。 

这表明下面的每个值$\lceil n/2 \rceil$是可以实现的。 另一方面，任何值$m \ge \lceil n/2 \rceil$需要一个除数$i \le n - m \le n/2$，但这样的构造不再保证余数等于$m$，事实上，算术结构阻止连续覆盖所有较大的值。 可到达集合正好形成前缀$[0, \lceil n/2 \rceil - 1]$，所以 MEX 是$\lceil n/2 \rceil$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
print((n + 1) // 2)
```整个解决方案减少到计算上限的一半$n$。 表达式$(n + 1) // 2$干净地处理偶数和奇数情况。 不需要额外的数据结构或循环，因为可达结构完全由算术推理而不是枚举确定。 

这里的一个常见错误是尝试模拟余数或构建一个集合，这是不必要的，并且存在混淆边界的风险。 该解决方案仅取决于整数除法行为。 

## 工作示例

 考虑$n = 5$。 

我们计算余数：

 | 我| n 模我 |
 | --- | --- |
 | 1 | 0 |
 | 2 | 1 |
 | 3 | 2 |
 | 4 | 1 |
 | 5 | 0 |

 套装是$\{0, 1, 2\}$。 第一个缺失的整数是$3$，匹配$\lceil 5/2 \rceil = 3$。 

这证实了边界以下的所有值都会出现，而边界本身不会出现。 

现在考虑$n = 8$。 

| 我| n 模我 |
 | --- | --- |
 | 1 | 0 |
 | 2 | 0 |
 | 3 | 2 |
 | 4 | 0 |
 | 5 | 3 |
 | 6 | 2 |
 | 7 | 1 |
 | 8 | 0 |

 该集合变为$\{0, 1, 2, 3\}$。 墨西哥是$4$, 匹配$\lceil 8/2 \rceil = 4$。 

这些示例表明，可达前缀正好增长到一半$n$，并且除此之外没有任何东西可以立即填补空白。
