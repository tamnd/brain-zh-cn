 ## 解决方案
 ## 问题理解

 我们得到了二维网格上的点的集合，其中每个点都可以被认为是具有整数坐标的单元格。 对于每个点，我们想要确定它与最远的其他点的距离，其中距离是使用曼哈顿距离来测量的。 两点之间的曼哈顿距离是它们的 x 和 y 坐标的绝对差之和。 

任务是计算每个点到集合中任何其他点的最大曼哈顿距离，并输出这些最大值。 

约束结构使得这变得有趣。 如果最多有 n 个点，则直接成对比较意味着检查所有对，这会导致 n 平方行为。 对于 n 大约 200,000 甚至 2000（具体取决于版本），n 平方已经不可行，因为它会涉及数十亿或数万亿次运算。 这立即排除了任何明确将每个点与其他点进行比较的解决方案。 

幼稚的实现也可能会偶然发现绝对值。 例如，尝试通过独立地按 x 或 y 对点进行排序来直接优化并不能直接解决曼哈顿距离，因为两个坐标是相互作用的。 

当所有点都相同或位于一条线上时，就会出现微妙的边缘情况。 如果所有点都相同，则每个点的正确答案都是零。 如果所有点都位于像 (i, i) 这样的对角线上，则曼哈顿距离将与索引差异完全成正比，并且独立处理 x 和 y 的不正确简化可能仍然适用于此类结构化输入，但在一般情况下失败。 

例如，考虑点 (0, 0)、(1, 2)、(3, 1)。 单独到 x 或 y 上的朴素投影并不能捕获最远点取决于组合表达式，而不是独立的最大值。 

## 方法

 主要困难在于曼哈顿距离公式中的绝对值。 对于两个点 (x, y) 和 (a, b)，距离为 |x − a| + |y − b|。 蛮力方法直接计算每对的该值并跟踪每个点的最大值。 这是正确的，因为它完全遵循定义，但每次常数时间都会花费 O(n²) 距离计算，当 n 很大时，这太慢了。 

关键的观察是，绝对值表达式可以根据符号选择扩展到一组有限的线性形式。 对于单个绝对差，|x − a| 可以重写为 max(x − a, a − x)。 扩展这个想法，曼哈顿距离成为四个线性表达式中的最大值，每个线性表达式对应于 x 和 y 差异的符号选择。 这将非线性度量转换为一组线性函数。 

一旦以这种形式重写，问题就会发生根本性的变化。 我们不需要直接比较每对点，而是只需要计算所有点上少量固定数量的线性表达式。 对于每个表达式，我们可以预先计算所有点的最大值。 然后，对于每个点，我们评估其在每个表达式下的贡献，并将其与预先计算的全局最大值相结合。 

这是有效的，因为每个曼哈顿距离实例恰好对应于这些符号配置之一，并且所有点的最大值必须以这些线性形式之一出现。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将每个点转换为不同符号模式下的贡献，然后使用全局极值在每个点的恒定时间内回答查询。

1. 对于每个点 (x, y)，计算对应于符号组合的四个变换值：x + y、x − y、−x + y 和 −x − y。 每个表达式代表绝对值在展开时解析的一种方式。 
2. 对于这四个表达式中的每一个，扫描所有点并计算最大值。 这些代表了每个标志配置下可能的最佳合作伙伴积分贡献。 此步骤隔离了全局结构，因此我们稍后不需要进行成对比较。 
3. 对于每个点 (x, y)，计算该点的四个表达式中每一个的值。 
4. 对于每个表达式，通过从该表达式的预先计算的最大值中减去点本身的值来计算候选答案。 这模拟了将该点与最佳的异号伙伴配对。 
5. 从四位候选人中选出最大值。 这给出了该点的最远曼哈顿距离。 

出现减法的原因是每个线性形式有效地将距离编码为两个变换点值之间的差异，因此配对减少到最大化该差异。 

### 为什么它有效

 曼哈顿距离分解为一组固定线性函数的最大值，这些线性函数源自 x 和 y 差异的独立符号选择。 每对点都在其中一种形式下贡献其距离。 通过预先计算全局每种形式的最大值，我们确保对于任何固定点，每种形式下的最佳可能合作伙伴都是已知的。 取跨形式的最大值可以重建真实的最大距离，因为每个有效对都恰好被其中一种形式覆盖。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    INF = 10**18
    max1 = -INF  # x + y
    max2 = -INF  # x - y
    max3 = -INF  # -x + y
    max4 = -INF  # -x - y

    for x, y in pts:
        max1 = max(max1, x + y)
        max2 = max(max2, x - y)
        max3 = max(max3, -x + y)
        max4 = max(max4, -x - y)

    for x, y in pts:
        ans = 0
        ans = max(ans, max1 - (x + y))
        ans = max(ans, max2 - (x - y))
        ans = max(ans, max3 - (-x + y))
        ans = max(ans, max4 - (-x - y))
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案首先聚合四个变换坐标系的全局极值。 这些极值中的每一个都对应于固定符号配置下的最佳可能端点。 

在第二遍中，每个点通过减去自己的贡献来计算它在每个变换系统中可以延伸的距离。 减法至关重要，因为它将绝对对选择转换为差异最大化问题。 

一个常见的实现错误是在迭代答案时重新计算最大值，这会意外地允许点与自身配对，从而在极端情况下扭曲推理。 预计算可确保所有查询的一致性。 

另一个微妙的问题是忘记了四种转换就足够了； 添加更多或更少的表达式会破坏绝对值分解的完整性。 

## 工作示例

 考虑点 (0, 0)、(2, 3)、(5, 1)。 

我们计算转换后的值：

 | 点| x+y | x−y | -x+y | −x−y |
 | --- | --- | --- | --- | --- |
 | (0,0) | (0,0) | 0 | 0 | 0 | 0 |
 | (2,3) | 5 | -1 | 1 | -5 |
 | (5,1) | 6 | 4 | -4 | -6 |

 全局最大值为 max1 = 6、max2 = 4、max3 = 1、max4 = 0。 

现在计算答案：

 | 点| 最大 1-(x+y) | max2-(x−y) | max2-(x−y) | max2-(x−y) | max3-(-x+y) | max3-(-x+y) | max4-(-x−y) | max4-(-x−y) | max4-(-x−y) 回答 |
 | --- | --- | --- | --- | --- | --- |
 | (0,0) | (0,0) | 6 | 4 | 1 | 0 | 6 |
 | (2,3) | 1 | 5 | 0 | 5 | 5 |
 | (5,1) | 0 | 0 | 5 | 6 | 6 |

 这证实了每个点都找到了最远的伙伴，而无需显式的对枚举。 

具有对称结构的第二个示例：(1,1)、(1,1)、(1,1)。 所有变换后的值都是相同的，因此每个 max 减去 self 都是零。 输出正确地变为全零，确认简并输入的正确性。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n) | 两次线性通过点，每点做功恒定 |
 | 空间| O(1) | O(1) | 仅存储了一些运行最大值 |

 该算法非常适合大型坐标集的典型约束，因为它完全避免了成对距离计算。 即使 n 高达 200,000，该解决方案也仅对每个点执行一些简单的算术运算。

def run(inp: str) -> str:

 ## 边缘情况

 对于像 (10, 10) 这样的单点输入，算法将所有变换后的最大值分别计算为 20, 0, 0, -20。 当减去点本身的贡献时，每个表达式的计算结果为零，从而产生正确的答案。 

对于所有相同的点，每个变换后的值都是相同的，因此每个最大值等于每个点的值。 减法完全取消，保证零距离并确认不会出现自配对问题。 

对于排列在对角线上的点，例如 (0,0)、(1,1)、(2,2)，变换简化为简单的线性偏移。 该算法仍然正确地捕获最大扩展，因为每个符号配置一致地折叠，并且全局最大值正确地表示线的端点。
