 ## 解决方案
 ## 问题理解

 我们得到了大小的排列$n$，表示每个数字$1$到$n$只出现一次，但在各个位置上以任意顺序出现$1$到$n$。 任务是将这个排列转换为排序顺序，其中值$i$坐在位置$i$。 

唯一允许的操作是涉及元素的交换$1$。 在每一步中，我们都可以交换$1$我们选择的任何位置。 使用这种受限交换操作，我们需要达到恒等排列。 

关键的结构性限制是我们不具备任意位置之间的一般交换能力。 每次重新排列都必须经过当前持有该值的位置$1$，其行为类似于临时缓冲区。 

从复杂性的角度来看，排列的大小足够大，以至于任何基于重复扫描或朴素冒泡的二次方法都太慢。 解决方案必须在线性或接近线性的时间内运行，因为我们可能需要处理最多$10^5$或更多元素。 

当元素出现时会出现微妙的边缘情况$1$最初未就位$1$。 一种天真的贪婪方法，忽略了运动$1$可以打破我们一直需要的不变量$1$可作为交换中心。 例如，如果排列是$[2, 1, 3]$，一种尝试直接放置的方法$2$或者$3$无需先处理位置$1$除非它明确地将交换路由到当前位置，否则可能会被卡住$1$。 

## 方法

 一个蛮力的想法是通过重复扫描数组并使用相邻交换将任何放错位置的元素交换到正确的位置来模拟排序。 这类似于冒泡排序或选择排序行为，但交换的限制必须涉及元素$1$使得这更加不灵活。 即使我们模拟有效的操作，我们最终也可能会重复搜索位置并执行长交换链。 在最坏的情况下，每次放置都会花费线性时间，从而导致$O(n^2)$操作，速度太慢。 

关键的观察结果是元素$1$充当通用中介。 如果我们可以移动$1$到任何位置，那么我们可以使用两次交换在两个任意位置之间有效地交换值：首先将一个值放入位置$1$，然后使用$1$将其移动到目标位置。 这将问题转化为将每个值路由到其正确索引的受控路由。 

如果我们保持每个值的当前位置，结构就会变得特别干净。 然后，每当我们想要放置值时$i$就位$i$，我们可以通过暂时替换当前涉及的任何内容，在不断的操作中做到这一点$1$，然后完成交换链。 

暴力破解会失败，因为它会在本地反复搜索和移动元素，而最优解则使用固定的值“枢纽”结构$1$在恒定时间内重新定位任何元素。

 | --- | --- | --- | --- |
 | 暴力模拟|$O(n^2)$|$O(n)$| 太慢了 |
 | 基于集线器的交换 1 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 我们维护两个结构：当前排列数组和跟踪每个值所在位置的逆位置数组。 这使我们能够在恒定时间内找到任何值。 

我们还跟踪值的位置$1$目前坐着，因为每个操作都必须经过它。 

### 步骤

 1. 构建数组`pos`这样`pos[x]`给出当前的价值指数$x$。 

这允许我们直接跳转到任何数字当前所在的位置，而不是扫描数组。 
2.迭代值$i$从$1$到$n$。 对于每个$i$，我们想要价值$i$最终到达索引$i$。 

此时，假设所有值都小于$i$已经被正确修复。 
3.如果$i$已经就位$i$，不执行任何操作并移至下一个值。 

这可以避免不必要的交换并保留已经正确的位置。 
4.否则，定位值所在位置$i$目前是，比如说在位置$p$。 我们现在要把它放到适当的位置$i$，但我们不能直接交换。 
5.首先交换position处的值$p$位置的值为$1$。 

这会改变价值$i$进入的位置$1$，同时推动任何东西$1$就位$p$。 

我们相应地更新排列数组和位置图。 
6. 现在交换位置处的值$1$当前位置的值$i$。 

这个地方$i$进入正确的最终位置$i$，并将位移值移回原位$1$。 
7. 每次交换后更新所有受影响值的位置。 继续，直到所有位置都固定。 

关键思想是每个放错位置的值都可以通过位置路由$1$，并且每次这样的修正最多需要两次交换。 

### 为什么它有效

 该算法保持了这样的不变性：到目前为止处理的所有值都固定在其正确的索引处，并且该值$1$始终在其当前位置正确跟踪。 每个操作仅影响恒定数量的位置，并且不会干扰已经固定的值，除非暂时通过位置$1$，立即更正。 由于每个不正确的元素都会在恒定时间内直接移动到其目标位置，因此在正确放置后不会重新访问任何元素。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))

    pos = [0] * (n + 1)
    for i in range(n):
        pos[a[i]] = i

    ops = []

    def swap(i, j):
        a[i], a[j] = a[j], a[i]
        pos[a[i]] = i
        pos[a[j]] = j
        ops.append((i + 1, j + 1))

    for i in range(1, n + 1):
        if a[i - 1] == i:
            continue

        p = pos[i]

        if p != pos[1]:
            swap(p, pos[1])

        swap(i - 1, pos[1])

    print(len(ops))
    for x, y in ops:
        print(x, y)

if __name__ == "__main__":
    solve()
```该实现维护从值到索引的直接映射，这避免了放置期间的任何扫描。 每次交换都会被记录并立即反映在数组和逆位置数组中，确保未来操作的正确性。 

一个微妙的点是我们总是通过重新计算位置`pos`，所以我们从不依赖过时的索引。 这是至关重要的，因为该元素$1$频繁移动并充当动态缓冲区。

 ## 边缘情况

 一个重要的边缘情况是当值$1$不在位置$1$最初。 该算法使用逆映射显式跟踪其位置，因此即使$1$从中间开始，每个交换都会正确更新其位置。 例如，使用输入$[2, 1, 3]$，第一个操作确保$1$在尝试放置之前移动到受控位置$2$，防止无效交换。 

另一种边缘情况是当值已经位于正确位置时。 该算法会立即跳过它，从而防止对已经固定的段进行不必要的干扰。 例如，在$[1, 3, 2]$， 价值$1$未受影响，并且仅使用集线器机制纠正错位的对，确保早期放置不会回归。
