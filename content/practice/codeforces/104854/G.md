 ## 解决方案
 ## 问题理解

 我们得到一个整数$d$，我们被告知两个人独立计算了以下形式的三角和$1 + 2 + \dots + n$和$1 + 2 + \dots + m$， 在哪里$m > n$。 我们仍然掌握的唯一信息是这两个总和之间的差值，它等于$d$。 任务是重建所有可能的整数对$(n, m)$这可能会产生这种差异。 

关键数量是三角数$T(x) = \frac{x(x+1)}{2}$。 条件变为$$T(m) - T(n) = d, \quad m > n.$$扩展这给出$$\frac{m(m+1) - n(n+1)}{2} = d.$$因此，每个有效对都对应于二次丢番图方程的整数解。 

约束条件$d \le 10^{12}$立即排除任何二次方$d$比如迭代所有$n, m$对。 即使是单个循环$10^6$或者$10^7$是可以接受的，但任何接近的东西$\sqrt{d}$必须仔细论证。 

一个微妙的点是有效对的数量保证最多为$10^4$，所以输出本身很小，但搜索空间却不小。 

主要的陷阱是尝试迭代$n$并计算$m$直接从二次方程得出，无需控制完整性或界限。 另一个问题是忘记了$m$必须严格超过$n$，这会影响重新排列方程时的边界处理。 

## 方法

 一个蛮力的想法就能解决$n$, 计算$T(n)$，然后尝试求解$T(m) = T(n) + d$通过扫描全部$m > n$。 这立即变得不可行，因为$T(m)$呈二次方增长，并且对于$d$最多$10^{12}$， 两个都$n$和$m$可以大到大约$10^6$。 双循环会导致周围$10^{12}$最坏情况下的操作。 

更好的方法来自于重写方程：$$m(m+1) - n(n+1) = 2d.$$我们可以将其分解为$$(m-n)(m+n+1) = 2d.$$这是关键的结构见解：三角数之差转化为两个整数的乘积。 让$$a = m - n, \quad b = m + n + 1.$$那么我们必须有$$a \cdot b = 2d,$$和$a > 0$,$b > 0$，并根据定义：$$m = \frac{a + b - 1}{2}, \quad n = \frac{b - a - 1}{2}.$$所以每个解对应一个因子对$2d$，奇偶校验约束确保$m, n$是整数。 

这将问题减少到迭代除数$2d$，其效率高达$\sqrt{d}$。 对于每个除数$a$，我们设置$b = \frac{2d}{a}$并检查是否导出$n, m$是整数并且满足$m > n$。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对 n、m 进行暴力破解 |$O(d)$到$O(d^{1.5})$|$O(1)$| 太慢了|
 | 二维因式分解 |$O(\sqrt{d})$|$O(1)$| 已接受 |

 ## 算法演练

 我们现在使用因子枚举系统地构建所有有效对。 

1. 计算$x = 2d$。 

这从三角数中删除了分母，因此我们可以纯粹使用整数。 
2. 迭代所有整数$a$从$1$到$\lfloor \sqrt{x} \rfloor$。 

对于每个$a$，检查是否可除$x$。 这确保我们只考虑有效的因子对。 
3. 对于每个除数$a$, 计算$b = x / a$。 

我们现在解读$a = m - n$和$b = m + n + 1$，这唯一地决定了$m$和$n$如果有效。 
4. 重建候选值：$$m = \frac{a + b - 1}{2}, \quad n = \frac{b - a - 1}{2}.$$这些公式直接来自求解线性系统$m$和$n$。 
5. 检查有效性条件：

 两者$m$和$n$必须是整数，因此两个分子必须是偶数，另外$m > n$。 
6. 存储所有有效对并输出它们。 

### 为什么它有效

 每个有效的解决方案都对应于因式分解$2d$进入$a \cdot b$， 在哪里$a = m - n$和$b = m + n + 1$。 该映射是双射的：给定一个解决方案$(n, m)$，我们独特地恢复$(a, b)$，并且给定满足奇偶约束的有效因子对，我们准确地重建一个有效因子$(n, m)$。 由于枚举了所有可能的因子对，因此不会丢失任何解，并且每个生成的因子对都通过构造满足原始方程。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

d = int(input().strip())
x = 2 * d

ans = []

i = 1
while i * i <= x:
    if x % i == 0:
        a = i
        b = x // i

        # case 1
        if (a + b - 1) % 2 == 0:
            m = (a + b - 1) // 2
            n = (b - a - 1) // 2
            if m > n and n >= 1:
                ans.append((n, m))

        # case 2 (swap factors)
        if a != b and (b + a - 1) % 2 == 0:
            m = (b + a - 1) // 2
            n = (a - b - 1) // 2
            if m > n and n >= 1:
                ans.append((n, m))

    i += 1

ans = list(set(ans))
print(len(ans))
for n, m in ans:
    print(n, m)
```该实现仅迭代至$\sqrt{2d}$，这已经足够了，因为每个有效因子对必须至少包含该范围内的一个因子。 

奇偶校验至关重要，因为以下公式$m$和$n$要求整数结果。 没有它，整数除法会默默地引入无效的候选者。 

我们还使用集合对结果进行重复数据删除，因为不同的除数方向可以产生相同的对。

 ## 边缘情况

 一个重要的边缘情况是当$2d$是素数。 在这种情况下，唯一的因子对是$(1, 2d)$和$(2d, 1)$，其中之一失败奇偶校验或产生无效的负数$n$。 该算法自然地通过整数和不等式检查过滤掉这些，确保不会报告无效对。 

另一种边缘情况发生在$a = b$， 意义$2d$是一个完美的正方形。 在这种情况下，因子对是对称的，必须处理一次以避免重复。 实施明确检查$a \neq b$生成交换案例时，防止重复计算。 

重建时出现第三种边缘情况$n$变为零或负数。 由于原始问题假设从 1 开始的正整数，因此必须丢弃这种情况。 条件$n \ge 1$强制执行此约束并防止满足代数但不满足问题定义的虚假解。
