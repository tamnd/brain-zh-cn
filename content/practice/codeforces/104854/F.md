 ## 问题理解

 我们得到一个整数$x$。 我们的任务是找到最大的数$y$不超过$x$，同时具有两个属性。 第一的，$y$必须是质数。 第二，$y$还必须可以表示为某个整数的阶乘，这意味着存在一个正整数$z$这样$y = z!$。 

所以我们正在寻找以下形式的数字$1!, 2!, 3!, \dots$也是质数，并且我们想要其中最大的一个$x$。 如果不存在这样的数字，我们输出$-1$。 

约束条件$x \le 10^5$对于竞争性编程标准来说非常小，这立即表明我们不需要任何高级数据结构或渐近优化的数论机制。 如果候选集很小，即使是恒定大小的预计算也足够了。 

一个关键的微妙之处在于理解阶乘增长。 阶乘增长得非常快，因此只有非常小的值$z$将产生输入范围内的结果。 这极大地限制了搜索空间。 

一个潜在的错误是将问题解释为搜索素数直到$x$具有一些隐藏的阶乘表示。 这是不正确的，因为阶乘值本身非常稀疏，而且我们一般不会过滤素数，而只会过滤阶乘数。 

用例子来说明这一点，如果$x = 10$，那么阶乘是$1, 2, 6, 24, \dots$。 其中，素数是$2$仅有的。 所以答案是$2$。 如果$x = 1$，没有一个阶乘在有意义的意义上既是素数又有效，所以答案是$-1$。 

## 方法

 直接的暴力方法将依次生成阶乘：从$1! = 1$，然后计算$2!, 3!, \dots$直到该值超过$x$。 对于每个阶乘值，我们检查它是否是质数。 最大有效值不超过$x$成为答案。 

这是可行的，因为阶乘增长得足够快，即使在上限，我们也只评估少数值$10^5$。 实际上，$5! = 120$已经超过限制了，所以只能$1!$通过$5!$都是相关的。 

天真的心态的瓶颈是认为我们需要测试所有数字的素性$x$，这将是$O(x \sqrt{x})$或者更糟。 这是不必要的，因为阶乘值并不密集； 我们最多只检查五名候选人。 

关键的观察是阶乘超出$5!$由于大小而无关，并且在小阶乘中，素性很容易通过检查或直接检查来验证。 

现在我们明确列出阶乘值及其素数：$1! = 1$，不是素数$2! = 2$， 主要的$3! = 6$，不是素数$4! = 24$，不是素数$5! = 120$，不是素数

 除此之外，所有阶乘都是偶数且大于 2，因此它们不可能是素数。 这完全将问题简化为检查一组恒定的候选者。 

所以唯一可能的有效值是$2$， 假如$x \ge 2$。 否则，不存在解决方案。

 ## 算法演练

 1. 识别在约束范围内或可能接近约束范围的所有阶乘值。 我们从 1 开始计算阶乘，直到值超过$x$，但我们很快注意到几步之后序列就变得无关紧要了。 此步骤确保我们不会在未经验证的情况下对结构做出过多假设。 
2. 检查这些阶乘值中哪些是质数。 这是中央过滤步骤，我们同时执行问题的两个条件。 
3. 跟踪既是素数又是素数的最大阶乘值$\le x$。 由于阶乘不断增加，这自然是遇到的最后一个有效阶乘。 
4. 如果存在则输出该值，否则输出$-1$。 这处理了没有阶乘满足素性的情况。 

对这些步骤的更直接的改进是认识到只有$2! = 2$在过滤过程中幸存下来。 

### 为什么它有效

 阶乘单调增长，并且素性施加了非常严格的约束：除了 2 之外，每个阶乘$n!$为了$n \ge 3$能被 2 和另一个整数整除，成为合数。 这意味着阶乘集合和素数集合的交集最多包含一个元素。 一旦我们识别出该元素，就不需要进一步搜索。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_prime(n: int) -> bool:
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    d = 3
    while d * d <= n:
        if n % d == 0:
            return False
        d += 2
    return True

def solve():
    x = int(input().strip())

    fact = 1
    best = -1
    z = 1

    while fact <= x:
        if is_prime(fact):
            best = fact
        z += 1
        fact *= z

    print(best)

if __name__ == "__main__":
    solve()
```该解决方案使用正在运行的产品逐步构建阶乘。 循环条件确保我们永远不会考虑超过的值$x$，这使计算保持有界。 每个阶乘都经过素性测试，尽管实际上只是$2$通过。 

素数检查是在标准中编写的$O(\sqrt{n})$形式。 尽管对于如此小的值来说有点过大，但它保持了推理的一般性并避免了硬编码假设。 

一个微妙的实现细节是更新的顺序：我们先递增后相乘$z$，确保我们正确生成$2!, 3!, 4!$，等等，而不跳过值。

 ## 边缘情况

 ### 情况：x = 1

 对于$x = 1$，我们从$1! = 1$。 该算法对其进行评估，发现它不是素数，并在确认没有有效候选者后立即终止循环。 输出保持不变$-1$，满足不存在低于或等于 1 的阶乘素数的要求。 

### 情况：x ≥ 2

 对于任何$x \ge 2$，算法生成$1! = 1$， 然后$2! = 2$。 在$2$，素性得到确认，best更新为2。即使后来生成阶乘，它们也很快超过2并且不是素数。 该算法保留 2 作为最终答案，这表明无论输入大小如何，唯一幸存的候选者都会被一致选择。
