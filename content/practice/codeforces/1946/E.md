 ## 解决方案
 ## 问题理解

 我们得到了大小的排列$n$，这意味着它包含来自的所有整数$1$到$n$恰好一次，以某种未知的顺序。 我们不是直接看到排列，而是被告知其前缀最大值和后缀最大值的位置。 位置处的前缀最大值$i$意味着该元素位于$i$比它之前的所有元素都大。 类似地，后缀最大值位于$i$比它之后的所有元素都大。 

任务是计算有多少不同的排列与这些给定的位置一致。 因为答案可能很大，所以我们将其取模输出$10^9 + 7$。 

约束条件告诉我们$n$可以大到$2 \cdot 10^5$，并且最多可以有$10^4$测试用例。 穷举排列的方法是不可能的，因为$n!$增长得太快了。 这意味着解必须是线性的或接近线性的$n$，理想情况下$O(n)$每个测试用例。 

当前缀和后缀最大值重叠或它们的位置不兼容时，会出现不明显的边缘情况。 例如，如果一个位置被声明为前缀最大值，但在后缀最大值中前面有一个更大的元素，则没有排列可以满足这两个约束。 另一个棘手的情况是$n=1$; 唯一的排列是微不足道的，但是假设至少两个元素的代码可能会失败。 

## 方法

 暴力方法将尝试生成所有大小的排列$n$并检查前缀和后缀最大值位置的一致性。 这在原则上是正确的，但不可行。 为了$n = 20$， 有$20! \approx 2.4 \cdot 10^{18}$排列，这远远超出了计算极限。 

关键的见解是要认识到该问题相当于填充从最大元素到最小元素的排列。 如果存在最大元素，则最大元素必须位于既是前缀最大值又是后缀最大值的位置，否则最大元素具有受最大值位置约束的自由范围。 一旦我们放置了最大的元素，问题就会递归地减少到用下一个最大的数字填充剩余的位置。 

更具体地说，每个位置属于三类之一：固定为前缀最大值、固定为后缀最大值或不受约束。 不受约束的位置可以自由分配，但不能违反前缀或后缀规则。 使用这个推理，我们可以迭代位置并维护每个元素的有效选择数量，将这些计数乘以模$10^9+7$。 这是一个$O(n)$每个测试用例的方法。

 ## 算法演练

 1. 预处理前缀最大值和后缀最大值位置。 为了方便起见，将它们转换为从零开始的索引。 初始化一个数组`perm`尺寸的$n$充满`-1`标记未知位置。 
2.放置最大的元素，$n$，如果它的位置是唯一确定的。 如果某个位置既是第一个前缀最大值又是最后一个后缀最大值，则最大的元素必须位于该位置。 如果不存在这样的位置，则放置必须满足给定最大值定义的范围。 
3. 对于每个元素$n-1$下降到$1$，确定它可以占据的有效位置。 如果一个位置不与其左侧大于当前元素的前缀最大值或右侧的后缀最大值不冲突，则该位置有效。 计算每个元素的有效位置数。 
4. 乘以每个元素的选择数即可得到排列总数。 保留所有计算的模数$10^9 + 7$。 
5. 如果在任何步骤中元素的有效位置为零，则配置是不可能的，我们为此测试用例输出零。 

为什么它有效：我们保持所有放置的元素都遵循前缀和后缀最大值约束的不变性。 通过从最大到最小考虑元素，我们确保分配的每个位置不会因稍后放置更大的元素而失效。 将可用选择的数量相乘即可考虑所有组合可能性，而无需重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, m1, m2 = map(int, input().split())
        prefix = list(map(int, input().split()))
        suffix = list(map(int, input().split()))
        
        pos = [-1]*n
        for i, p in enumerate(prefix):
            pos[p-1] = n - m1 + i + 1  # assign relative values
        for i, s in enumerate(suffix):
            val = n - m2 + i + 1
            if pos[s-1] != -1 and pos[s-1] != val:
                print(0)
                break
            pos[s-1] = val
        else:
            free = 0
            result = 1
            for v in pos:
                if v == -1:
                    result = result * (free + 1) % MOD
                    free += 1
                else:
                    free = max(free, v - 1)
            print(result % MOD)

solve()
```该解决方案有效地读取所有输入，然后使用相对排名为前缀和后缀最大值分配已知位置。 立即检测到冲突。 自由位置以组合方式计数，在迭代时增加可能性。 该算法避免了递归，以线性时间运行，并仔细处理模运算。
