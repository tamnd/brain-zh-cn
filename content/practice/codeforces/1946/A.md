 ## 解决方案
 ## 问题理解

 给定一个整数数组，并要求我们确定增加数组中位数所需的最小增量操作数。 增量操作包括选取任意元素并向其加一。 中位数定义为数组排序后位于中间的元素； 如果数组长度为偶数，则中位数为位置处的元素$\lceil n/2 \rceil$，使用从 1 开始的索引。 

例如，对于数组`[2, 2, 8]`，中位数是`2`。 对第一个元素应用一个增量会产生`[3, 2, 8]`。 排序后，就变成了`[2, 3, 8]`，新的中位数是`3`，有所增加。 任务是找到此类操作的最少数量，以确保中位数严格增加。 

这些限制意味着我们需要一种有效的方法。 每个数组最多可以有$10^5$元素，所有测试用例的总和是$2 \cdot 10^5$。 这排除了模拟每种可能操作的强力方法，因为逐个递增元素并重新排序会太慢，尤其是对于大量元素。 

大小为 1 的数组会出现一种微妙的边缘情况。 例如，如果数组是`[1000000000]`，中位数是`1000000000`。 该单个元素加一会立即增加中位数。 另一个边缘情况是所有元素都相等。 例如，`[5, 5, 5, 5]`需要对数组的后半部分进行操作以增加中位数。 总是针对前半部分的粗心方法可能会误算所需的增量。 

## 方法

 暴力方法很简单：重复增加数组中的元素并每次重新计算中位数，直到它增加。 这是有效的，因为增加任何大于或等于中位数的元素都会影响中位数的值。 然而，这需要在每次操作后重复对数组进行排序，即$O(n \log n)$每次操作。 对于大型阵列或较大的中值间隙，这可能会导致最多$O(n^2 \log n)$操作，这太慢了。 

最佳解决方案的关键见解是中位数仅取决于排序数组的中半部分和上半部分。 中位数之前元素的任何增量都没有帮助。 一旦数组排序完毕，如果我们将中位数和右侧的元素作为目标，我们可以直接递增它们以达到该一半中的下一个更大的数字。 通过计算将中位数提高到已排序上半部分中的下一个元素所需的增量总数，我们可以有效地确定最少的操作。 

我们不需要单独模拟每个增量。 我们可以对数组进行一次排序，确定中位数位置，然后从中位数开始将目标值与当前元素之间的差异求和，直到中位数增加。 这种方法与排序后上半部分的大小是线性的，即$O(n)$一旦数组排序后，每个测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2 log n) | O(n^2 log n) | O(n) | 太慢了 |
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量，$t$。 对于每个测试用例，请阅读$n$和数组$a$。 
2. 对数组进行排序$a$按非递减顺序。 排序确保我们可以直接识别中位数并处理影响它的元素。 
3. 计算中位数的指数为$m = n // 2$在从 0 开始的索引中。 这对应于$\lceil n/2 \rceil$从 1 开始的索引中的第 -th 元素。 
4. 初始化变量`operations`为零。 这将累积所需增量的总数。 
5. 迭代索引中的元素$m$到$n-1$，它覆盖了中位数及其右侧的所有元素。 对于每个元素，计算所选目标值与当前元素之间的差异。 目标值是所有增量后超过当前中值的最小值。 
6. 总结这些差异。 总和给出了所需增量的最小数量，因为任何增量都必须针对中位数或高于中位数的元素才能影响其值。 
7. 输出总和作为当前测试用例的结果。 

为什么有效：排序后，中位数是位置上的元素$m$。 要增加中位数，至少必须增加中位数元素。 将中位数提高到任意值的操作次数$x$是所有元素增量的总和$m$从下面开始$x$。 由于我们始终针对正确的元素并对精确的差异求和，这确保了严格增加中位数的最少操作。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()
    median_idx = n // 2
    target = a[median_idx]
    operations = 0
    # Increment the median and right half until median increases
    for i in range(median_idx, n):
        operations += max(0, a[i] - target + 1)
        target = a[i] + 1
    print(operations)
```该代码使用快速 I/O 有效地读取测试用例和数组。 排序允许直接访问中位数。 我们计算中位数或高于中位数的元素所需的增量并将其累加。 微妙之处在于每一步更新目标，以确保我们始终递增到影响中位数的下一个可能值。
