 ## 解决方案
 ## 问题理解

 我们从一个整数数组开始。 每个操作都允许我们选择任何连续的子数组（包括空子数组），计算其总和，并将该总和作为新元素插入到数组中的任何位置。 

关键的观察是插入一个值会改变数组的总和。 如果所选子数组有和`x`，然后插入后`x`，数组总和正好增加`x`。 

任务是准确执行`k`操作并最大化最终的数组和。 由于答案可能变得巨大，我们将其模输出`10^9 + 7`。 

约束足够大，我们需要一个接近线性的解决方案。 在所有测试用例中，总价值`n + k`至多是`2·10^5`，这排除了任何重复模拟子数组或探索操作序列的方法。 我们周围需要一些东西`O(n)`或者`O(n log n)`每个测试用例。 

一些边缘情况很容易被错误处理。 

考虑一个数组，其每个子数组的和均为非正数：```
n = 2, k = 2
a = [-4, -7]
```最好的选择是空子数组，其总和为`0`。 任何非空子数组都会减少最终答案。 正确的结果是`-11`，这变成`999999996`模数`10^9+7`。 

考虑一个具有正最大子数组的数组：```
n = 3, k = 2
a = [2, 2, 8]
```最大子数组和为`12`。 插入后`12`，该新元素可以成为更大子数组的一部分。 一个解决方案添加了`12`两次将获得`36`，但最优过程产生`12 + 24`，给出最终总和`48`。 

另一个微妙的情况是当总数组和为负但存在正子数组时：```
n = 3, k = 1
a = [100, -200, 150]
```总和是`50`，但最好的操作是插入最大子数组和`150`，产生`200`。 只看总和就忽略了收益的真正来源。 

## 方法

 暴力的观点是将每个操作视为所有子数组中的一个选择。 有`O(n²)`每一步都有子数组，并且每次插入后数组长度都会增加。 即使对于一项手术来说，这也是昂贵的，并且对于最多`2·10^5`操作变得完全不可行。 

暴力破解的想法是正确的，因为每个操作都将所选子数组的总和贡献给全局总数。 困难在于确定哪种选择序列可以最大化累积收益。 

突破来自于理解我们插入正数后会发生什么。 

假设原数组的最大子数组和为`M`。 

如果`M ≤ 0`，没有非空子数组值得采用。 由于允许空子数组，因此每个操作都可以贡献`0`。 答案就是原始数组的和。 

现在假设`M > 0`。 

在第一个操作中，我们插入一个等于`M`。 由于该值现在存在于数组中，因此我们可以选择一个包含原始最大和段和新插入的子数组`M`。 其总和变为`2M`。 

插入后`2M`，我们可以重复同样的想法并得到`4M`， 然后`8M`， 等等。 

增益的顺序是```
M, 2M, 4M, ..., 2^(k-1)M
```其总贡献为```
M(2^k - 1)
```没有任何策略可以做得更好，因为每个插入的值最终都源于迄今为止可用的最大子数组和，并且这种加倍策略总是实现最大可能的增长。 

因此，问题简化为两个量：```
S = sum of all array elements
M = maximum subarray sum, but at least 0
```最终的答案是```
S + M(2^k - 1)
```计算模数`10^9 + 7`。 

利用Kadane算法在线性时间内获得最大子阵列和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数/低于 O(k·n²) | O(n) | 太慢了 |
 | 最佳 | 每个测试用例 O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算数组总和`S`。 
2. 运行 Kadane 算法来查找最大子数组和。 
3. 将该值替换为`max(0, maximum_subarray_sum)`。 

如果每个子数组都是负数，我们总是可以选择空子数组并获得`0`。 
4. 计算`pow2 = 2^k mod MOD`。 
5. 计算额外贡献：```
M(2^k - 1)
```模数`MOD`。 
6. 转换原始总和`S`成模形式。 

自从`S`可能为负数，使用Python的模运算。 
7. 将两部分模相加`MOD`并输出结果。 

### 为什么它有效

 让`M`是当前可实现的最大非负子数组和。 

插入一个等于后的值`M`，该插入值可以放置在生成的段附近`M`。 下一个可实现的最大子数组和变为`2M`。 重复这个论证表明最优增益形成序列```
M, 2M, 4M, ..., 2^(k-1)M.
```他们的总和正好是`M(2^k-1)`。 

任何插入的值都源自某个子数组和。 没有子数组可以超过当前最大可实现的子数组总和，因此没有操作可以获得超过该步骤的加倍策略收益的收益。 由于该策略每次都能获得最大可能的收益，因此它是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def solve():
    t = int(input())

    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        total = sum(a)

        best = 0
        cur = 0

        for x in a:
            cur = max(0, cur + x)
            best = max(best, cur)

        extra = best * ((pow(2, k, MOD) - 1) % MOD)
        ans = (total % MOD + extra) % MOD

        print(ans)

solve()
```变量`total`存储原始数组和。 

Kadane 算法的实现使用`cur`和`best`。 表达式```
cur = max(0, cur + x)
```维护以当前位置结束的最大子数组总和，同时允许空子数组。 因此，`best`自动变成`max(0, maximum_subarray_sum)`。 

价值`2^k`可能很大，因此需要模幂。 Python 的内置`pow(2, k, MOD)`计算它在`O(log k)`时间。 

一个常见的错误是忘记了`total`可能是负数。 使用```
total % MOD
```在添加额外贡献之前将其转换为正确的模块化表示。
