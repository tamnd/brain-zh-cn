 ## 解决方案
 ## 问题理解

 我们有一棵树$n$顶点，这是一个没有循环的连通图。 任务是准确删除$k$这棵树的边并确定最大整数$x$这样每个产生的连接组件至少有$x$顶点。 简单来说，我们将树划分为$k+1$尺寸大致平衡的组件，同时最大化最小的组件。 

输入由多个测试用例组成。 对于每个测试用例，我们阅读$n$和$k$， 其次是$n-1$描述树的边。 每个测试用例的输出都是一个整数，即最大可行的整数$x$。 

约束条件允许$n$最多$10^5$每个测试用例，以及总和$n$所有测试用例的边界为$10^5$。 这限制了我们的算法大致是$O(n \log n)$或更快，因为$O(n^2)$方法会导致$10^{10}$在最坏的情况下，操作速度太慢。 每个测试用例都是独立的，所以我们可以一一处理。 

当发生微妙的边缘情况时$k$相对于非常小或非常大$n$。 例如，如果$k = 1$和$n = 3$有一棵树$1-2-3$，我们可以删除一条边，但是所得的两个分量的大小$1$和$2$。 最大$x$那么就是$1$，即使平均大小是$1.5$。 计算平均值或假设均匀分布的简单方法将返回$2$，这是不正确的。 

另一个边缘情况是星形树。 如果中心连接到所有叶子并且$k = n-1$，删除任何边可能会隔离单个节点。 该算法必须考虑到最小组件大小受最小分支限制，而不是受理想划分限制。 

## 方法

 暴力方法会枚举所有集合$k$要删除的边缘，计算每个结果组件的大小，并跟踪每个配置的最小大小。 这是正确的，但是对于每棵树，都有$\binom{n-1}{k}$去除边缘的方法，这对于$n$最多$10^5$。 

关键的见解是考虑候选人的规模$x$并确定是否可以将树分成至少大小的组件$x$通过删除$k$边缘。 如果我们可以有效地检查给定的$x$，我们可以执行二分查找$x$在范围内$1 \dots n$。 每个人的决定$x$是可行的$O(n)$使用深度优先搜索（DFS）方法。 对于每个节点，我们计算其子树的大小并决定是否可以形成完整的组件。 如果子树足够大，我们将其计入我们的$k$边缘去除。 否则，我们向上传播它的大小。 这种贪婪的 DFS 保证我们形成的任何组件至少具有大小$x$。 

蛮力方法是不可行的，因为边缘组合的数量以组合方式增长。 使用 DFS 的二分搜索是最佳的，因为树结构允许我们以自下而上的方式聚合大小，在本地决定要切割的边。 检查候选人$x$在$O(n)$给出总复杂度$O(n \log n)$，这在时间限制下很合适。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O( (n 选择 k) * n ) | O(n) | 太慢了 |
 | 二分查找+DFS | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化二分查找$l = 1$和$r = n$。 答案就在这个范围内。 我们将通过测试候选值来缩小范围$x$。 
2. 定义辅助函数`can_cut(x)`决定是否可以精确删除$k$边使得每个结果组件至少有$x$顶点。 
3. 在`can_cut(x)`，从任意节点（通常是节点）执行 DFS$1$。 对于每个节点，计算当前子树（包括所有子节点）的大小。 
4.对于每个子树的大小至少$x$，增加代表潜在削减的计数器。 对于较小的子树，累积大小并将其传播到父树。 
5. 在每个节点，如果未分配节点的大小累计达到$x$，增加潜在切割计数器并将累积大小重置为零。 这确保了形成的每个组件都满足最小尺寸。 
6. DFS之后，检查潜在切割的数量是否至少为$k$。 如果是，`x`是可行的； 否则，它太大了。 
7. 使用二分查找：if`can_cut(mid)`为真，设定`l = mid`尝试更大的值； 否则，设置`r = mid - 1`。 继续直到`l`等于`r`。 
8.返回最大可行值$x$。 

关键的不变量是 DFS 总是聚合子树大小，从下到上贪婪地形成组件。 计入切割的每个组件均满足尺寸要求，确保不会发生违规情况。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(200000)

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        tree = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            tree[u - 1].append(v - 1)
            tree[v - 1].append(u - 1)

        def can_cut(x):
            cuts = 0
            def dfs(u, parent):
                nonlocal cuts
                total = 1
                for v in tree[u]:
                    if v == parent:
                        continue
                    subtotal = dfs(v, u)
                    if subtotal >= x:
                        cuts += 1
                    else:
                        total += subtotal
                return total
            dfs(0, -1)
            return cuts >= k

        l, r = 1, n
        while l < r:
            mid = (l + r + 1) // 2
            if can_cut(mid):
                l = mid
            else:
                r = mid - 1
        print(l)

if __name__ == "__main__":
    solve()
```DFS 累积子树大小。 达到或超过候选值的子树`x`形成切口，而较小的切口向上传播。 二分搜索测试每个中点，保证对数步长。 使用`sys.setrecursionlimit`避免大树的堆栈溢出。 索引从基于 1 的输入调整为基于 0 的 Python 列表。 

## 工作示例

 **示例输入 1：**```
5 1
1 2
1 3
3 4
3 5
```| 节点| 子树大小 | 削减|
 | --- | --- | --- |
 | 2 | 1 | 0 |
 | 4 | 1 | 0 |
 | 5 | 1 | 0 |
 | 3 | 1+1+1=3 | 1 (3>=2) | 1 (3>=2) |
 | 1 | 1+1+3=5 | 1 |

 二分查找确定`x=2`是最大可行值。 尝试`x=3`失败，因为只能进行一次切割。 

**示例输入 2：**```
6 2
1 2
2 3
1 4
4 5
5 6
```二分搜索评估候选人`x=2`并找到两种可能的切割：一种是在以`2`，一个位于根于的子树`4`。`x=3`失败是因为在两次切割后剩余的子树无法达到大小 3。 输出是`2`。
