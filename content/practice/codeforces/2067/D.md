 ## 解决方案
 ## 问题理解

 我们得到一个数组`x`长度`n`整数从 1 到`n`，和一个隐藏数组`y`相同长度的。 每对`(x_i, y_i)`是独一无二的并且`x_i ≠ y_i`。 挑战在于识别隐藏对象是否是有边的有向图`x_i → y_i`（对象 A）或具有坐标的平面上的点`(x_i, y_i)`（对象B）。 

我们只允许进行两次以下形式的查询`(i, j)`。 如果隐藏对象是图，则查询返回顶点之间的最短路径长度`i`和`j`（如果无法访问则为 0）。 如果是一组点，则查询返回点之间的曼哈顿距离`i`和`j`。 最多两次查询后，我们必须自信地识别对象类型。 

约束条件允许`n`最多`2·10^5`以及多达 1000 个测试用例。 这排除了任何尝试重建整个图或计算所有距离的算法，因为 O(n²) 运算太慢。 我们需要一个针对每个测试用例使用持续查询的解决方案。 

当点或边缘可以被排列为使得距离或路径在某些小示例中重合时，就会出现边缘情况，这可能会误导简单地查看响应大小而不考虑结构的简单算法。 

## 方法

 暴力解决方案将尝试通过查询许多对来重建图或点坐标`(i, j)`并分析回应。 在最坏的情况下，这可能涉及 O(n²) 次查询，考虑到两个查询的限制，这是不可能的。 

关键的见解是这两种对象类型具有根本不同的度量属性。 在对象 A（图）中，距离是离散的并且受下式限制：`n-1`（沿路径的边数），并且不可达对返回 0。在对象 B（平面）中，对于不同点，曼哈顿距离始终为正，因为`x_i ≠ y_i`为所有人`i`，并且绝对差之和至少为 2，当`n ≥ 3`并且所有坐标都是唯一的。 

这意味着即使是一个精心选择的查询也通常可以区分该对象。 为了稳健性，我们选择两个任意索引`i ≠ j`。 如果响应为 0，则对象必须是图，因为点的曼哈顿距离不能为零（所有坐标都是不同的）。 否则，响应至少是2。如果我们反向查询`(j, i)`，曼哈顿距离是对称的，而在有向图中，从`i → j`和`j → i`可以不同。 响应的差异会立即向对象 A 发出信号。如果响应相等且非零，则我们正在处理对象 B。 

这种方法将问题减少到固定数量的查询，而不需要复杂的重建。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳 | 每个测试用例 O(1) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读`n`和数组`x`。 
2. 选择两个索引`i`和`j`这样`i ≠ j`。 通常`i = 1`和`j = 2`作品。 
3、查询`(i, j)`并存储响应`d1`。 该值是曼哈顿距离或最短路径长度。 
4、查询`(j, i)`并存储响应`d2`。 
5. 比较`d1`和`d2`。 如果它们不同，则该对象是有向图（对象 A），因为有向图中的最短路径通常是不对称的。 
6. 如果`d1`等于`d2`和`d1 > 0`，该对象是一组点（对象 B），因为曼哈顿距离是对称的且始终为正。 
7. 输出识别出的物体。 

为什么它有效：不变的是距离响应编码有向路径的结构不对称性。 对于图表来说，`dist(i, j) ≠ dist(j, i)`在存在循环或有向链的情况下。 对于点来说，曼哈顿距离对称性保证了相等，而由于坐标不同，零是不可能的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        x = list(map(int, input().split()))
        
        # Pick two indices
        i, j = 1, 2
        
        print(f"? {i} {j}")
        sys.stdout.flush()
        d1 = int(input())
        
        print(f"? {j} {i}")
        sys.stdout.flush()
        d2 = int(input())
        
        if d1 != d2:
            print("! A")
        else:
            print("! B")
        sys.stdout.flush()

if __name__ == "__main__":
    main()
```该解决方案读取每个测试用例的输入并进行两次查询。 我们任意选择指数 1 和 2，因为只有不对称性才重要。 微妙之处在于确保`flush()`在每个查询后调用以保持交互正确性。

 ## 边缘情况

 如果第一个查询意外命中图中的零（即，顶点断开连接），则第二个查询`(j, i)`保证不同于零，给出正确的不对称信号。 如果`n = 3`并且所有坐标正好相差 1，曼哈顿距离查询仍然返回正值，因此算法正确识别对象 B。索引 1 和 2 的选择是安全的，因为`x_1 ≠ y_1`和`x_2 ≠ y_2`受约束。
