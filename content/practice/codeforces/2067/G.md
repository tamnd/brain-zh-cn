 ## 解决方案
 ## 问题理解

 我们得到了一堆桶，每个桶里都装有一定量的水，其中一个桶里含有微量的毒药。 毒药使木桶的重量不知不觉地增加了 0.179 公斤。 我们不能接触装有毒药的桶，但只要不接触有毒的桶，我们就可以安全地在桶之间倒水。 我们获得的唯一信息来自比较秤，它告诉我们对于任何两个桶，它们的重量是否相等或者哪一个更重。 

任务是确定是否可以保证在不接触有毒桶的情况下识别有毒桶，并且即使通过一系列查询添加或删除桶也能维持这种保证。 

问题规模很大：多达 200,000 个桶和 200,000 个查询。 这排除了任何需要显式比较所有桶对或模拟每个可能的倾倒序列的解决方案，因为每个查询将花费 O(n^2) 时间。 每个桶的重量以百万为界，但桶的数量才是真正的限制。 由于我们需要在线处理查询，因此我们需要一个动态策略，允许高效地插入、删除和识别毒桶。 

一个不明显的边缘情况是所有桶中的水量相同。 在这种情况下，有毒的桶是最重的，只是稍微重一些，但无法安全地区分它，因为从无毒的桶中倒出的任何液体只会使其他桶的重量相等，而不会暴露有毒物质。 另一种微妙的情况发生在恰好有两个不同的重量并且较重的重量由多个桶承载时。 在这种情况下，有毒的桶可能是其中任何一个，而我们无法触摸任何一个来安全地识别它。 

## 方法

 强力解决方案将模拟所有浇注和规模比较。 人们可以想象挑选两个桶，比较它们，从较轻的倒到较重的，一直持续到只剩下一个候选人。 虽然概念上是正确的，但这需要仔细跟踪所有成对比较和倾倒，在最坏的情况下为 O(n^2)，并且无法有效处理 2×10^5 桶。 

关键的观察是我们永远不需要模拟实际浇筑。 安全倾倒的能力意味着我们可以使多个桶的重量相同，只要我们不碰毒桶。 如果我们可以将所有无毒的桶减少到相同的重量，那么任何剩余的具有不同重量的桶一定是有毒的。 因此，最佳方法减少为跟踪多组桶水量。 如果存在唯一的最重的桶，就可以安全地识别出有毒的桶。 如果最大值出现多次，则无法保证无风险识别。 

这一观察使我们能够有效地处理查询。 添加桶会更新该水量的频率。 移除桶会降低频率。 在每一步中，我们只需要检查当前最大值是否出现一次。 如果我们使用平衡映射来维护计数，那么每个查询的问题就会减少到 O(log n)，或者对于给定的水量范围，使用频率数组来维护每个查询的 O(1) 问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了 |
 | 最佳 | 使用计数 O(n + q) | O(10^6) | O(10^6) | 已接受 |

 ## 算法演练

1. 建立所有当前水量的频率表。 这允许在添加或删除桶时进行恒定时间更新。 使用长度为 10^6 + 1 的固定大小数组就足够了，因为所有水量都是有限的。 
2. 确定当前最大水量及其在表中的计数。 如果最大值的计数为1，则有毒桶唯一最重，所以答案为“是”。 如果最大值出现多次，则答案为“否”。 
3. 处理每个查询。 如果添加了桶，则增加其水量的频率。 如果移除了桶，则减少频率。 动态更新最大值及其计数。 每次查询后，检查最大值是否出现一次，并输出“Yes”或“No”。 
4. 更新最大值时，请注意：如果移除的桶是当前最大值并且其计数降至零，则向下扫描下一个最大水量。 添加桶时，如果其重量超过当前最大值，则更新最大值。 

为什么有效：该算法保证所有无毒桶都可以安全地平等。 有毒桶必须始终具有明显的重量才能识别。 因此，跟踪最大值及其多重性足以正确回答问题，而无需模拟实际浇注。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import defaultdict

n, q = map(int, input().split())
a = list(map(int, input().split()))

freq = defaultdict(int)
for x in a:
    freq[x] += 1

max_weight = max(freq.keys())
def output():
    print("Yes" if freq[max_weight] == 1 else "No")

output()

for _ in range(q):
    line = input()
    op, val = line.split()
    val = int(val)
    if op == '+':
        freq[val] += 1
        if val > max_weight:
            max_weight = val
    else:
        freq[val] -= 1
        if freq[val] == 0:
            del freq[val]
            if val == max_weight:
                if freq:
                    max_weight = max(freq.keys())
                else:
                    max_weight = 0
        elif val == max_weight:
            pass
    output()
```该解决方案首先构建所有桶水量的频率图。 辅助函数`output`检查当前最大值是否出现一次。 每个查询都会增加或减少频率图。 如果最大桶被完全删除，算法将扫描下一个最大值。 使用`defaultdict`确保我们不需要显式检查丢失的密钥。 

微妙的部分正在正确更新`max_weight`拆卸桶时。 仅当先前的最大值已没有剩余桶时，我们才必须扫描新的最大值。 当添加比当前最大值更重的桶时，我们只需替换最大值即可。
