 ## 解决方案
 ## 问题理解

 我们有一组学生参加了包含多个问题的数学测试。 每个学生回答了一些问题，有些是正确的，有些是错误的。 每个问题都有一个隐藏分值，这些分值形成从 1 到问题总数的数字排列。 每个学生还有一个预期的测试总分。 我们的任务是以这样一种方式为问题分配分值，即使总“惊喜”（每个学生的预期分数与他们通过我们的作业获得的实际分数之间的绝对差异之和）最大化。 

输入为每个学生提供一个二进制字符串，表示他们正确回答了哪些问题以及预期分数。 输出是从 1 到最大化总惊喜的问题数量的整数排列。 

约束条件表明学生人数较少（最多 10 人），但问题数量可能很大（最多 10,000 个），并且所有测试用例的问题总数限制为 10,000 个。 这意味着我们可以在嵌套循环中迭代学生，但任何随问题数量呈二次方或更糟的算法都会太慢。 由于分值形成严格的排列，因此我们必须仔细选择哪些问题获得最大或最小值。 

当学生期望的分数已经非常高或非常低时，就会出现微妙的边缘情况。 例如，如果学生正确回答所有问题并期望获得尽可能多的分数，则给他们高值会符合期望并带来较低的惊喜，而给他们低值则会最大化惊喜。 简单地按照正确答案数量的顺序分配分数的简单方法可能无法最大化总惊喜。 

## 方法

 暴力方法是尝试点值的所有排列并计算每个排列的总惊喜。 对于单个测试用例$m$问题，这涉及到$m!$的排列，这对于$m = 10,000$。 即使尝试只将最大值分配给一个问题，将第二大值分配给另一个问题，等等，也需要检查指数数量的分配。 

关键在于关注正确回答每个问题的学生数量。 每个问题对总惊喜的贡献与其价值与学生期望的差异成正比。 如果我们想要最大化总绝对差值，我们应该将最高分值分配给大多数期望低于其潜在分数的学生正确回答的问题，并将最低分值分配给正确答案较少的问题。 从本质上讲，问题对于最大化惊喜的“重要性”在于有多少学生正确回答了该问题，无论他们的确切预期分数如何。 

这将问题简化为贪婪方法：计算所有学生中每个问题的正确答案数量，按此计数对问题进行排序，并将最大的可用分值分配给计数最高的问题。 这是有效的，因为绝对差函数是单调的 - 增加分配给许多学生正确回答的问题的分值会增加绝对差的总和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(米！) | O(米) | 太慢了 |
 | 贪婪的正确答案计数 | O(m log m + n*m) | O(m log m + n*m) | O(m + n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，读取学生人数$n$和问题$m$、学生的预期分数以及他们的二进制答案字符串。 
2.初始化一个数组`counts`长度$m$为零。 对于每个问题，该数组将存储有多少学生回答正确。 
3. 循环浏览每个学生和每个问题。 如果学生正确回答了问题（用“1”表示），则增加`counts[j]`。 在这个循环之后，`counts[j]`代表有问题的学生总数$j$正确的。 
4. 将每个问题索引与其计数配对，并按计数对这些对进行排序。 这根据问题对带来惊喜的“重要性”进行了排名。 
5. 指定从 1 到$m$到已排序的问题。 将最高分值分配给计数最高的问题，将第二高的分值分配给下一个问题，依此类推。 这最大化了所有学生的绝对差异之和。 
6. 按照原题顺序输出分配的分值。 

为什么有效：在每一步中，答案最正确的问题将获得最大分，确保最大数量的学生放大预期分数和实际分数之间的差异。 绝对差函数保证了这种贪婪分配最大化总惊喜。 按计数排序可确保绝对差值之和全局最大化，而不是局部最大化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        x = list(map(int, input().split()))
        answers = [input().strip() for _ in range(n)]
        
        counts = [0] * m
        for i in range(n):
            for j in range(m):
                if answers[i][j] == '1':
                    counts[j] += 1
        
        indexed_counts = list(enumerate(counts))
        indexed_counts.sort(key=lambda x: x[1])
        
        result = [0] * m
        for val, (idx, _) in enumerate(indexed_counts, 1):
            result[idx] = val
        
        print(' '.join(map(str, result)))

if __name__ == "__main__":
    solve()
```第一部分有效地读取大量问题的输入。 计算学生的正确答案非常简单，并使用固定数组进行存储。 按计数排序可确保对惊喜贡献最大的问题获得最大分。 最后的分配步骤要小心地映射回原始问题顺序。 这种基于计数的排序自然会处理边缘情况，例如答案字符串中的全零或全一。

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n*m + m log m) | O(n*m + m log m) | 计算正确答案的时间复杂度为 O(n*m)。 对 m 个问题进行排序的时间复杂度为 O(m log m)。 赋值的时间复杂度为 O(m)。 |
