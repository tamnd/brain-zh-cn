 ## 解决方案
 ## 问题理解

 给我们三根整数长度的木棍，并且允许我们将一根木棍切成两个正整数长度的碎片。 经过这次切割，我们总共将有四根棍子。 目标是确定这四根棍子是否可以形成一个相对边相等的矩形。 正方形被视为有效的矩形。 

输入由多个测试用例组成。 每个测试用例都给出了三根棍子的长度。 如果一次切割后可以形成矩形，则输出为“YES”，否则输出为“NO”。 

因为测试用例的数量可以达到 10,000 个，并且棒的长度可以达到$10^8$，我们的解决方案必须在每个测试用例的线性时间内运行。 我们无法承受一根棍子所有可能的分割的嵌套循环，因为在最坏的情况下，将一根棍子分割成所有可能的对可能会导致数百万次操作。 

一个重要的边缘情况是，两根棍子已经具有相同的长度，并且第三根棍子可以分成与该长度匹配的两块。 例如，对于长度$2, 4, 2$，将 4 分成两个 2 可以形成一个矩形。 另一个棘手的情况是最大的棍子恰好等于其他两根棍子的总和，例如$1, 5, 6$; 在这里，将 6 分成 1 和 5 创建一个矩形。 

## 方法

 简单的方法是考虑每根棍子并尝试将其分成所有可能的整数对。 对于每次分割，检查四根所得的木棍是否可以形成一个矩形。 对于一根长度的棍子$L$， 有$L-1$劈开，用三根棍子，这可以变成$O(L)$每个测试用例。 自从$L$可以是$10^8$，这显然是不可行的。 

最佳方法观察到矩形只需要两对相等长度。 这极大地限制了可能性。 要么一根棍子等于另外两根棍子的总和（我们把它切成另外两根棍子的长度），要么两根棍子相等，剩下的棍子可以分成相等的两半以匹配它们。 正式来说，我们需要检查的条件是：

 1. 两根棍子相等，剩下的棍子是偶数（我们将其分成两半以匹配另外两根）。 
2. 两根木棍的总和等于第三根（我们将最大的木棍分开以匹配其他两根）。 

这些检查每个测试用例只需要恒定的时间，这对于多达 10,000 个测试用例来说已经足够快了。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(最大(l_i)) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取三个棒的长度，并按非递减顺序排序。 排序可确保最大的木棍易于识别。 
2. 检查最小的两根木棍是否相等。 如果是，检查最大的木棍是否均匀。 如果两个条件都成立，将最大的木棍分成相等的两半会得到一个矩形。 
3. 检查最小的两根木棍的总和是否等于最大的木棍。 如果为 true，则将最大的木棍分成与其他两根木棍相匹配的两块，得到一个矩形。 
4. 如果以上任一条件成立，则打印“YES”； 否则，打印“NO”。 

这是可行的，因为形成一个矩形需要恰好两对相等的长度。 对木棍进行排序可以减少我们需要考虑的情况数量，并使比较变得简单。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    sticks = list(map(int, input().split()))
    sticks.sort()
    a, b, c = sticks
    if (a == b and c % 2 == 0) or (a + b == c):
        print("YES")
    else:
        print("NO")
```该解决方案首先读取测试用例的数量。 对于每个测试用例，读取三个棒长度并对其进行排序。 排序可确保比较简单：前两根棍子最小，第三根棍子最大。 第一个条件处理可以通过将最大的棍子分成两等份来形成矩形的情况。 第二个条件处理最大的木棍可以被分割以匹配其他两根木棍的情况。 根据这些检查直接打印。 排序是安全的，因为我们只处理三个元素。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        sticks = list(map(int, input().split()))
        sticks.sort()
        a, b, c = sticks
        if (a == b and c % 2 == 0) or (a + b == c):
            output.append("YES")
        else:
            output.append("NO")
    return "\n".join(output)

# provided samples
assert run("4\n6 1 5\n2 5 2\n2 4 2\n5 5 4\n") == "YES\nNO\nYES\nYES"

# custom cases

assert run("2\n1 100000000 100000000\n100000000 100000000 200000000\n") == "NO\nYES", "large values"
assert run("2\n5 5 5\n2 2 2\n") == "NO\nYES", "all equal"

 ## 边缘情况

 对于`3 3 3`，木棍都是平等的。 劈开任何一根棍子都会产生两块，例如，将 3 劈成 1 和 2，结果是`[3,3,2,1]`，不能形成两个相等的对。 该算法正确地打印“NO”。 

为了`2 2 2`，将一根棍子分成`1,1`结果`[2,2,1,1]`。 排序给出`[1,1,2,2]`，满足第一个条件`(a == b and c % 2 == 0)`间接地，因为最大的分割是 2（偶数）。 该算法打印“YES”。 

为了`100000000 100000000 200000000`，将最大的 200000000 根棍子分成两根 100000000 根，产生`[100000000,100000000,100000000,100000000]`，形成一个完美的矩形。 该算法打印“YES”。 这确认了最大尺寸输入的正确处理。
