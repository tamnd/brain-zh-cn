 ## 解决方案
 ## 问题理解

 我们被要求对满足一系列嵌套 MEX 条件的非负整数数组进行计数。 具体来说，我们得到一个数组`a`长度`n`。 对于每个位置`i`在数组中，我们必须确保`(n-i+1)`-th 前缀的 MEX`[b_1, ..., b_i]`等于`a[i]`。 在这里，`k`集合中的第 -th MEX 是`k`- 集合中不存在的最小非负整数。 每个`b[i]`必须满足`0 <= b[i] <= n`。 输出是有效数组的数量模$10^9 + 7$。 

这些限制使得暴力方法变得不可行。 总和`n`所有测试用例最多可达`2 * 10^5`，所以一个`O(n^2)`算法将大致执行`4 * 10^{10}`超过时间限制的操作。 我们需要一个每个测试用例都有效线性或接近线性的解决方案。 边缘情况包括具有重复或递减 MEX 值的数组，或者不可能提供所需 MEX 的序列。 例如，`a = [2, 1, 3]`由于 MEX 约束冲突，因此无解。 

## 方法

 暴力方法会尝试生成所有可能的数组`b`并验证 MEX 条件。 这在原则上是正确的，但显然太慢了。 构建所有序列`b`长度`n`产量$(n+1)^n$的可能性，这是指数级的大。 评估每个前缀`k`-MEX 为每个候选数组添加另一个因子`n`，使得这不可行。 

关键的见解是注意由`(n-i+1)`-th MEX 约束。 我们可以从数组末尾开始向后计算`a`，推理哪些值是允许的`b[i]`以满足未来 MEX 的条件。 通过维护每个 MEX 级别的“可用数字”计数，我们可以增加每个步骤的选择数量，从而有效地执行组合计数而不是枚举。 该问题简化为计算保留 MEX 顺序的整数的有效位置，同时跟踪每个整数可以出现的次数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((n+1)^n * n) | O((n+1)^n * n) | O(n) | 太慢了|
 | 最佳计数 | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 反转数组`a`以匹配前缀的自然顺序。 让`a_rev[i] = a[n-i]`。 这使我们能够处理来自第一个元素的约束`b`到最后，与前缀逻辑对齐。 
2. 追踪`count[x]`对于每个可能的值`x`从`0`到`n`。 最初，所有计数均为零。 每个`count[x]`代表我们还可以放置多少次`x`在数组中`b`不违反所需的 MEX。 
3. 初始化变量`total_ways`到 1。该变量累加每个选项的选择数量的乘积`b[i]`。 
4. 迭代`i = 0`到`n-1`超过`a_rev`。 在步骤`i`, MEX 要求`a_rev[i]`规定所有小于的整数`a_rev[i]`前缀中必须至少出现一次`[b_1, ..., b_i]`。 因此，可用选项的数量`b[i]`是`count[a_rev[i]]`，表示该值已经出现并且可以重用的次数。 
5. 乘法`total_ways`经过`count[a_rev[i]]`模数$10^9 + 7$。 放置后`b[i] = a_rev[i]`, 增量`count[a_rev[i]]`以反映该值已被再次使用。 
6. 如果在任何一步`count[a_rev[i]]`为零，则无法满足 MEX 要求。 放`total_ways`归零并尽早突破。 
7. 处理完所有位置后，`total_ways`包含数组总数`b`满足所有条件。 

不变的是每一步`i`,`count[x]`正确反映了该值的多少倍`x`仍然可以在不违反 MEX 要求的情况下放置。 这保证了乘法`count[a_rev[i]]`累积所有有效配置，不会过量计数或遗漏任何配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b_rev = a[::-1]
        count = [0] * (n + 2)
        total_ways = 1
        for x in b_rev:
            if x > n:
                total_ways = 0
                break
            total_ways = total_ways * max(1, count[x]) % MOD
            count[x] += 1
        print(total_ways)

if __name__ == "__main__":
    solve()
```该解决方案有效地读取输入，反转数组以自然地处理前缀，并使用计数数组来跟踪可用的位置。 这`max(1, count[x])`确保在第一次出现某个值时，我们仍然考虑一个有效的位置。 每次乘法都应用模运算以防止溢出。

 ## 边缘情况

 对于数组，其中`a[i]`超过`n`，算法立即检测到这一点并设置`total_ways`为零。 例如，`a = [5]`和`n = 3`无法产生有效的`b`因为在 size-1 数组中 MEX 不能为 5。 类似地，具有重复大值的序列由计数数组处理，该数组在每个步骤中正确地乘以选择。 该解决方案自然可以处理长度为 1 的序列、全等值以及严格递减或递增的 MEX 序列，无需特殊情况。
