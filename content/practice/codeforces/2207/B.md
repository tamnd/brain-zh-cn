 ## 解决方案
 ## 问题理解

 我们被要求在危险管理方面模拟费斯熊弗莱迪披萨店的一个夜晚。 每个电子动画每秒都会积累危险，夜晚会持续固定的秒数。 玩家在预定时间可以进行有限数量的“手电筒动作”，每个动作都可以将电子动画设备的危险重置为零。 目标是找到最小的最大危险级别`x`这样，无论电子动画如何分配攻击，最佳地使用手电筒都会将最终的危险级别保持在或以下`x`。 

输入描述了多个测试用例，每个测试用例给出了手电筒的使用次数、电子动画的数量、夜晚的长度以及手电筒可以使用的时间。 每个测试用例的输出是一个整数 - 最小值`x`保证安全。 

该问题有严格的界限。 所有测试用例中的总秒数乘以电子动画数量限制为 2×10^5，这排除了任何尝试直接模拟每个电子动画每秒的解决方案。 这立即排除了幼稚的每秒模拟。 我们必须使用基于计数或间隔的策略，而不是逐步模拟。 

边缘情况包括手电筒动作数量非常少，可能少于电子动画数量的情况，或者夜间长度极短或极长的情况。 例如，在最后使用一个电子玩具和一个手电筒，最终的危险完全取决于最后一个手电筒后的秒数。 如果不考虑这一点，天真的方法可能会错误地认为危险被过早重置。 

## 方法

 暴力方法将每秒跟踪每个电子动画的危险级别，并在适当的时间应用手电筒动作。 这在原则上是正确的，但是当`m * ℓ`达到2×10^5。 

关键的观察结果是，我们最终面临的最大危险仅取决于连续使用手电筒之间的秒数以及存在的电子动画设备的数量。 手电筒可以被认为是将夜晚分成多个间隔。 在每个间隔内，电子动画可以选择贪婪地增加单个电子动画的危险。 因此，一段时间间隔后的最终危险`t`和`m`电子动画是天花板`t/m`- 我们总是可以尽可能均匀地分配危险的增长。 

因此，问题简化为计算闪光之间这些间隔的最大长度，将其除以电子动画的数量，向上舍入，然后取所有间隔的最大值。 初始间隔从时间零开始，最后一个间隔从最后一次手电筒照射到夜晚结束。 这种基于间隔的贪婪方法消除了每秒模拟的需要，并且每个测试用例的工作时间为 O(n)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(m * ℓ) | O(米) | 太慢了|
 | 区间/贪心| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化变量`max_interval`存储连续手电筒使用之间的最大间隙。 从第一个间隔开始`a[0]`（从开始到第一次闪烁的秒数）。 
2. 迭代手电筒时间。 对于每个连续的对`(a[i-1], a[i])`，计算区间长度为`a[i] - a[i-1] - 1`。 更新`max_interval`如果这个间隔更大。 
3.处理完所有闪光后，处理从最后一次闪光到夜晚结束的最后间隔：`ℓ - a[-1]`。 更新`max_interval`如果需要的话。 
4. 最小保证最大危险`x`的上限是`max_interval / m`。 这使得危险增长尽可能均匀地分布在所有电子动画中。 由于 Python 整数支持上限除法`(a + b - 1) // b`，这一步很简单。 
5. 输出计算结果`x`。 

工作原理：该算法保持了不变式，即重置之间的最大间隙决定了任何单个电子动画的最坏情况累积。 通过尽可能均匀地分割总间隔增长，我们保证电子动画不会超过计算的危险。 上限划分确保如果间隔不能均匀划分，则剩余部分对于某些电子动画设备来说仍然会被视为额外危险。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n, m, l = map(int, input().split())
        a = list(map(int, input().split()))
        max_interval = a[0] - 0
        for i in range(1, n):
            max_interval = max(max_interval, a[i] - a[i-1] - 1)
        max_interval = max(max_interval, l - a[-1])
        result = (max_interval + m - 1) // m
        print(result)

if __name__ == "__main__":
    main()
```代码首先读取测试用例的数量。 对于每个测试用例，它会读取闪光灯的数量、电子动画的数量、夜间长度和手电筒时间。 这`max_interval`计算正确地捕获了危险可以在不重置的情况下累积的最大时间间隔。 最后的危险是通过将这个间隔除以电子动画并向上舍入来获得的。 

微妙之处包括使用`a[i] - a[i-1] - 1`正确计算连续闪烁之间的间隔并分别处理开始和结束间隔。 

## 工作示例

 **示例1：**`n=1, m=2, l=10, a=[10]`| 间隔 | 计算| 最大间隔 |
 | ---| ---| ---|
 | 开始 | 10-0=10 | 10-0=10 10 | 10
 | 结束 | 10-10=0 | 10-10=0 10 | 10
 | x = ceil(10/2) | 5 | 5 |

 唯一的闪光发生在最后一秒，因此第一个电子动画可以累积最多 5 个危险，闪光会重置，留下最终的危险 5。 

**示例2：**`n=2, m=3, l=40, a=[13,37]`| 间隔 | 计算| 最大间隔 |
 | ---| ---| ---|
 | 开始 | 13-0=13 | 13-0=13 13 |
 | 闪烁之间| 37-13-1=23 | 37-13-1=23 23 | 23
 | 结束 | 40-37=3 | 23 | 23
 | x = ceil(23/3) | 8 | 8 |

 最差的间隔是闪光 13 和 37 之间。将 23 秒划分为 3 个电子动画，得到上限 8，这是最小最大危险。

 ## 边缘情况

 当所有闪光都发生在最后时，第一个间隔可能会很长。 例如，`n=1, m=2, l=10, a=[10]`结果 max_interval = 10。除以 2 电子动画得到 5，这与直觉相符。 当闪光均匀分布但不能被电子动画设备的数量整除时，上限除法可确保没有电子动画设备超过计算的危险。 该算法正确处理这些边界条件。
