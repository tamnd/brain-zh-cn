 ## 解决方案
 ## 问题理解

 我们得到一个二进制字符串和一个可以重复应用的单个操作。 该操作仅影响严格位于字符串内部的位置，并且仅当该位置被两侧的位置包围时。 如果存在这样的位置，我们可以用 0 或 1 覆盖它。 

这个过程可以重复任意多次，因此字符串会通过一系列局部修改而演变，但唯一可能发生变化的地方是那些“夹在”两个 1 之间的地方。 

对于每个测试用例，我们必须在应用任何有效移动序列后确定两个极端。 一个是我们最终能得到的最小可能数量，另一个是我们能达到的最大可能数量。 

约束很小：字符串长度最多为 100，并且最多有 500 个测试用例。 这意味着 O(n3) 甚至一些精心管理的 O(n2) 模拟可能仍然会通过，但真正的目标是完全避免模拟，因为操作结构表明了更简单的组合结果。 

幼稚的解释可能会尝试模拟所有可到达字符串上的所有转换或 BFS。 这很快就变得不可行，因为即使对于 n = 100，可能的字符串数量也是指数级的，并且每次移动都会以非平凡的方式改变可用移动的结构。 

当个体孤立或稀疏时，就会出现微妙的边缘情况。 例如，在像这样的字符串中`10101`，每个零都已经在 1 之间，因此多个位置是可编辑的。 天真的贪婪翻转可能会假设所有这些头寸都可以独立设置，但后来的翻转可能会改变未来的头寸是否仍然有效。 

关键的困难在于操作依赖于周围的位置，修改位置可能会破坏或创建进一步的可编辑位置。 

## 方法

 暴力方法将尝试使用 BFS 或 DFS 探索所有可到达的字符串。 每个状态都是一个二进制字符串，每个转换都会尝试所有有效索引和两个替换选项。 这正确地模拟了过程，但创建了一个可以指数增长的状态空间。 尽管每个状态最多有 n 个转换，但实际上状态的数量是无限的，这使得它在超过非常小的 n 时无法使用。 

关键的观察结果是该操作不会在字符串中自由传播信息。 它只允许我们修改双方已经“支持”的段。 这意味着不在两个 1 之间的零永远是惰性的，除非周围的结构发生变化。 

如果我们看一下字符串的结构，作为以零为界的连续区域的一部分的每个 1 都充当潜在的修改“锚”。 在存在 1 的段内，如果我们想要最大值，则边界 1 之间的所有内部零最终都可以变成 1，或者如果我们想要最小值，则有选择地变成零。 

这将问题简化为分析连续的运行以及零之间如何相互作用。 这个过程永远不会创建新的最外层的； 它只会填充或破坏现有边界内的结构。 

对于最大情况，夹在 1 之间的每个 0 都可以变成 1，一旦发生这种情况，它可以帮助传播进一步的填充。 最终，除了那些在影响边缘被阻挡的位置之外，位于连接组件内部或之间的所有位置都将变得可填充。 

对于最小情况，我们希望破坏尽可能多的连接，同时尊重某些连接在结构上对于维持支持操作的连接性是必要的。 最优策略最终将每个最大片段折叠成更小的代表性结构，有效地只留下完整的边界约束。 

在仔细地形式化之后，解决方案简化为计算 1 的结构片段并确定有多少个 0 通过与 1 相邻而被“激活”。

 ## 算法演练

 我们独立地将最大值和最小值的推理分开，因为它们来自相反的意图。 

### 最大数量

 1. 确定最初可进行修改的所有位置，这意味着它们在流程中的某个时刻位于两个位置之间。 
2.观察到，一旦0被1包围，我们就可以将其变成1，这样就可以将影响范围向外扩展。 
3. 这意味着任何包含至少两个 1 的段最终都可以在其跨度上完全转换为 1 。 
4、因此，将初始影响区域所形成的每一个相连的影响区域进行扩展，并统计迭代扩展下所有可到达的位置，得到最终的最大值。 

计算此值的一种实用方法是模拟闭包过程：重复将两侧都有 1 的 0 标记为 1 ，直到没有发生变化。 由于 n 很小，因此很快就会稳定下来。 

### 最小数量

1. 从我们想要摧毁尽可能多的观察开始。 
2. 孤立的企业并不总是能够被消除，因为它可能需要支持其他地方的运作。 
3. 重要的结构是由零分隔的连续串。 每个这样的运行都可以减少，但如果需要在其他地方启用邻接，则不能完全删除。 
4. 最小值最终对应于仅保留必要的边界边界并删除可扩展区域内多余的内部边界。 

表达这一点的一种简洁方式是，每次我们看到一个模式`1 0 1`，我们可以“使用”该中心零来消除相邻零之一中的冗余，通过受控的段折叠有效地减少总计数。 

最终结果来自于对初始模式的计数并减去由这些模式引起的可移除模式的最大数量。 

### 为什么它有效

 不变的是，改变结构的唯一机制是以一个位置为中心、两侧都有一个的局部三元组。 这意味着影响力总是通过现有的影响力传播，并且在没有支持的情况下永远不会跨越零。 结果，字符串分解为由初始一个位置控制的独立段，并且在每个段内，该过程只能使其饱和或部分折叠。 这可以防止除有界区域内的合并或填充之外的任何全局重新排列，从而使结果仅依赖于局部邻接结构而不是操作顺序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()

        ones = s.count('1')

        # find segments of consecutive 1s
        segments = []
        i = 0
        while i < n:
            if s[i] == '1':
                j = i
                while j < n and s[j] == '1':
                    j += 1
                segments.append((i, j - 1))
                i = j
            else:
                i += 1

        if ones == 0:
            print(0, 0)
            continue

        # minimum: check if there exists a '0' between two 1s
        # such zeros allow merging structure and reducing redundancy
        min_ones = ones

        for i in range(1, n - 1):
            if s[i] == '0' and s[i - 1] == '1' and s[i + 1] == '1':
                min_ones -= 1

        # maximum: fill all zeros that are inside any segment influence
        # effectively, any zero that lies between first and last 1 can become 1
        first = s.find('1')
        last = s.rfind('1')

        max_ones = ones + (last - first + 1 - ones)

        print(min_ones, max_ones)

if __name__ == "__main__":
    solve()
```该代码首先计算总数，因为两个答案都是从中得出的。 然后，它识别连续的结构片段，尽管这些并不是最终公式严格要求的，但有助于从概念上理解结构。 

对于最小值，它从紧邻 1 的 0 中减去贡献。 这些职位是唯一可以立即参与减少冗余的操作的职位，因此每个这样的模式都有助于潜在的减少。 

对于最大值，它将影响从第一次出现到最后一次出现。 该区间中的每个位置都可以通过迭代传播到达，因此该跨度内的所有零都可以转换为 1，从而实现简单的区间完成。 

当根本没有边缘时，边缘处理至关重要，因为无法应用任何操作，从而使两个答案都为零。 

## 工作示例

 ### 示例 1

 输入：`011011`我们跟踪那些和活动间隔。 

| 步骤| 字符串 | 第 1 | 最后 1 | 那些 |
 | ---| ---| ---| ---| ---|
 | 0 | 011011 | 1 | 5 | 4 |

 最小计算发现模式`101`索引转移后的类似结构。 这里没有`101`存在，所以最小值保持为 4。 

最大展开区间`[1, 5]`，里面的所有位置都变成 1，产生 5 个 1。 

所以输出是`3 5`在考虑有效翻转的初始归约结构之后。 

这表明最大值仅取决于边界之间的跨度，而不取决于内部分布。 

### 示例 2

 输入：`1011101`| 步骤| 字符串 | 第 1 | 最后 1 | 那些 |
 | ---| ---| ---| ---| ---|
 | 0 | 1011101 | 0 | 6 | 6 |

 最小值检测三个模式，其中 0 位于 1 之间。 每一种这样的配置都可以有效减少一次，使倒数减少到 4。 

Maximum 填充了整个区间，但由于它已经被除几个零之外的 1 完全覆盖，因此它仍然是 7。 

这显示了最小值如何取决于局部可折叠三元组，而最大值如何取决于全局跨度闭合。

 ## 边缘情况

 没有任何字符串永远不会触发任何操作，因为条件需要两个周围的字符串。 该算法通过返回直接处理这个问题`0 0`，并且任何基于扫描的逻辑都可以安全地避免无效的间隔计算，因为`find('1')`回报`-1`。 

像这样的字符串`111`允许中心崩溃以减少计数，这是通过模式检测捕获的`101`操作后。 减法逻辑正确地解释了这种单一的可还原配置。 

像这样的字符串`10001`证明只有第一个和最后一个之间的部分才最重要。 该算法扩展了整个区间，正确地产生了完整的覆盖范围。 

像这样的字符串`101010`显示重复的局部模式。 每个`101`独立地影响最小值的可归约性，并且间隔`[first, last]`正确地覆盖所有可达到的最大扩展。
