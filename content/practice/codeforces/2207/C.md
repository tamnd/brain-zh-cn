 ## 解决方案
 ## 问题理解

 如果我们忽略 2D 图片并单独关注每一列，则可以更简单地理解网格。 栏内`i`， 有`a_i`底部的污垢瓷砖以及其上方的所有瓷砖的高度`h`是水。 所以列中水瓦片的数量`i`是`h - a_i`。 

放置在水瓷砖上的排水管会激活洪水填充区域：从该起始瓷砖开始，水仅通过相邻的水瓷砖扩散，但移动仅限于向左、向右和向下。 因为向上移动是不可能的，所以每个相连的水区域都有一个非常特定的结构：一旦你选择了一个起始水块，整个可到达的区域正是下面没有被污垢堵塞的最大水“盆地”。 

排水管的主要作用是，它将所有水收集在连续的水平柱段中，其中水柱“在某种程度上连接”。 如果从高度角度考虑，每根柱子都会贡献一段垂直的水，而连通性取决于相邻柱子是否具有重叠的水高度。 

任务是放置最多两个这样的排水沟，每个排水沟选择一个连接的水组件，并最大化收集的不同水瓷砖的总数。 如果两个排水沟覆盖了重叠的水，则这些瓷砖仅计算一次。 

这些限制使得对所有漏极位置对进行暴力破解是不可能的。 每个测试总共最多可以有 2000 列，因此每个测试解决方案的任何二次或更差的列都必须仔细控制，并且任何涉及从头开始重新计算洪水填充的操作都太慢。 

一个微妙的问题是过度计算重叠。 放置在重叠或嵌套区域的两个排水沟可以共享大片水域。 仅选择两个最佳独立段而不对交集进行建模的简单方法会高估答案。 

例如，如果所有列都有`a_i = 1`，每一列都几乎满了水。 任何排水管基本上都会到达整个网格，因此放置两个排水管除了一个之外不会带来额外的好处。 贪婪的“取两个最佳片段”方法会错误地重复计算。 

## 方法

 强力方法会尝试所有可能的排水位置。 排水位置是任何水块，但由于每个位置都定义了一个连接的水域，因此我们可以考虑选择任何起始单元并通过洪水填充计算其可到达的水域。 对每个单元格执行此操作已经太大了：有`O(nh)`可能的起点，并且每次洪水填充可以采取`O(nh)`在最坏的情况下，给出明显不可行的`O(n^2 h^2)`行为。 

即使我们将自己限制为每列中的“最上面的水细胞”，我们仍然面临这样的问题：每个组件的形状取决于通过不同高度的水平传播，这将全局耦合列。 

关键的结构观察是，每个排水沟本质上对应于选择柱子的水平间隔，并且在该间隔内，限制因素是其上的最小“水高度剖面”。 如果我们在列中定义水高度`i`作为`b_i = h - a_i`，那么从排水管可到达的任何连接区域的行为就像一个段，其中有效水深由最小值控制`b_i`在那个部分。 这将问题转化为对区间进行推理并将两个区间与并集重叠相结合。 

因此，问题减少为最多选择两个区间，其中每个区间的值由其内部最小高度的函数确定，并最大化总并集贡献。 这是一个经典的设置，其中分而治之或区间 DP 与单调堆栈结构相结合提供了有效的解决方案。 

我们以结构化的方式计算每个间隔的最佳单漏贡献，然后组合两个间隔，同时仔细减去重叠。 重叠处理是核心困难，它是通过确保我们仅使用前缀/后缀最佳值和预先计算的间隔增益来组合不相交或正确合并的贡献来解决的。

 | ---| ---| ---| ---|
 | 暴力洪水填充 | O(n²h) 或更糟 | O(nh) | 太慢了|
 | 区间DP/分而治之优化| O(n log n) 或 O(n) | O(n) | 已接受 |

 ## 算法演练

 我们切换到补充视图：每一列都有贡献`b_i = h - a_i`水的单位。 

1. 预先计算水位高度`b_i`。 这将问题完全转化为一维数组，其中值代表每列的水容量。 
2. 计算最佳单漏答案。 单个漏极有效地捕获最大连接区域，这对应于选择一个段，其中贡献由该段中的最小值乘以其宽度确定。 这相当于在定义的直方图下找到最佳矩形`b_i`。 
3. 使用单调堆栈计算每个位置的最大线段，其中`b_i`是最小值。 对于每个`i`，我们确定值保持高于或等于的左右边界`b_i`。 这给出了列的最大间隔`i`控制水的高度。 
4. 使用以下方法计算每个此类间隔的最佳矩形值`b_i * (r - l + 1)`。 跟踪最大值； 这是一次排水的最佳结果。 
5. 现在我们需要两个排水管。 我们将数组分为左右部分，并计算所有前缀和后缀的最佳可能单漏答案。 让`left_best[i]`仅使用列即可获得最佳答案`[1..i]`， 和`right_best[i]`同样对于`[i..n]`。 
6. 最佳的双漏极配置要么将两个漏极完全放置在不相交的区域中，要么最佳解决方案使用在某些边界处有效分裂的结构。 所以我们评估`left_best[i] + right_best[i+1]`全面的`i`。 
7. 返回最佳单漏答案和所有分割组合中的最大值。 

### 为什么它有效

 每个排出对应于在变换后的数组中选择最大直方图矩形`b_i`。 任何具有两个排水沟的最佳解决方案都可以分解为两个区域，其并集是最佳的，并且任何重叠只会减少边际增益，因为重叠的图块只计算一次。 因此，最佳配置始终可以重新排列为两个不相交的贡献区间，而不会降低结果，这证明了在边界处分割数组并组合前缀和后缀最佳值的合理性。 

单调堆栈保证每个最大矩形仅被考虑一次，从而确保单漏计算的正确性，而前缀-后缀DP确保覆盖所有有效的双漏分区。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, h = map(int, input().split())
        a = list(map(int, input().split()))
        b = [h - x for x in a]

        # monotonic stack for largest rectangle histogram
        left = [0] * n
        right = [0] * n

        stack = []
        for i in range(n):
            while stack and b[stack[-1]] >= b[i]:
                stack.pop()
            left[i] = stack[-1] + 1 if stack else 0
            stack.append(i)

        stack = []
        for i in range(n - 1, -1, -1):
            while stack and b[stack[-1]] > b[i]:
                stack.pop()
            right[i] = stack[-1] - 1 if stack else n - 1
            stack.append(i)

        best_single = 0
        for i in range(n):
            area = b[i] * (right[i] - left[i] + 1)
            if area > best_single:
                best_single = area

        # prefix best
        pref = [0] * (n + 1)
        for i in range(1, n + 1):
            pref[i] = max(pref[i - 1], b[i - 1] * (i - left[i - 1] + 1) if i - 1 >= 0 else 0)

        # suffix best
        suf = [0] * (n + 2)
        for i in range(n - 1, -1, -1):
            suf[i] = max(suf[i + 1], b[i] * (right[i] - i + 1))

        ans = best_single
        for i in range(n + 1):
            ans = max(ans, pref[i] + suf[i])

        print(ans)

if __name__ == "__main__":
    solve()
