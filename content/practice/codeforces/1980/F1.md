 ## 解决方案
 ## 问题理解

 我们被要求划分一个大小为的矩形区域$n \times m$爱丽丝和鲍勃之间。 该字段包含$k$喷泉在不同的单元格中，爱丽丝想要选择一条单调路径（仅向右或向下移动）从顶部或左侧到底部或右侧，以便最大化她可以要求的单元格数量。 爱丽丝的情节必须包括左下角的单元格$(n, 1)$，而 Bob 的绘图必须包含右上角的单元格$(1, m)$。 

在这个问题的简单版本中，我们只需要确定每个喷泉给爱丽丝是否会增加她的最大可能面积。 我们不需要计算实际面积。 

关键制约因素很大$n$和$m$最多$10^9$， 和$k$最多$2 \cdot 10^5$。 这立即排除了任何迭代整个网格的解决方案。 该解决方案必须仅在喷泉本身上运行。 总和$k$所有测试用例仅限于$2 \cdot 10^5$，这表明了一个线性解$k$每个测试用例是可以接受的。 

当喷泉位于角落时，会出现微妙的边缘情况。 如果喷泉位于右上角或左下角附近，它可以立即限制爱丽丝的最大路径。 例如，如果$n = m = 2$喷泉位于$(1, 2)$和$(2, 2)$，Alice 无法声明右上角的单元格，但仍然可以声明左下角的单元格。 错误地识别哪些喷泉对增加她的面积很重要是一个常见的错误。 

## 方法

 暴力方法会尝试从顶部或左侧边界上的所有有效起始单元开始的每条单调路径，计算爱丽丝的结果面积，然后模拟向她提供每个喷泉以查看面积是否增加。 甚至忽略$10^9 \times 10^9$网格大小，路径数量呈指数增长$n + m$，所以这种方法不可行。 

关键的观察是，只有沿对角线极端位置的喷泉才重要。 爱丽丝的情节受到她从上/左到下/右的路径的限制。 任何比爱丽丝左下角起始位置“更靠上或靠右”的喷泉都可能会减少她的最大可到达区域。 具体来说，爱丽丝在没有喷泉的情况下可以占据的最大面积是由具有最大行或最大列的喷泉决定的，因为它们挡住了她的路径。 让`max_r`是喷泉中的最大排并且`max_c`最大列。 那么，Alice 可以主张的最大单元格数是以下较小者$(n - min_r + 1) * (m - min_c + 1)$沿着她单调的路径，但在简单版本中我们只需要非零指示器。 

如果喷泉严格超出当前阻挡她的最大行或最大列，则给爱丽丝一个喷泉会增加她的可到达区域。 因此，对于每个喷泉，我们只需检查它是否位于限制 Alice 的最大行或最大列。 这一观察结果将解决方案简化为$O(k)$通过每个测试用例。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^(n+m)) | O(2^(n+m)) | O(n*m) | 太慢了 |
 | 最佳 | O(k) | O(k) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$,$m$， 和$k$。 然后读取所有喷泉的坐标。 
2. 初始化变量以跟踪最大行（`max_r`）和最大列（`max_c`）在喷泉之间。 
3. 遍历一次喷泉列表并更新`max_r`和`max_c`找到最大的行和列值。 
4. 爱丽丝在不获取任何喷泉的情况下可以占据的最大面积对应于避开以下位置的喷泉`max_r`和`max_c`。 在简易版本中，只需输出`1`如果有任何区域是可能的（即，该区域没有被起始行或列处的喷泉完全阻挡），否则`0`。 通常这将是`1`因为$n, m \ge 2$和$k \le n*m - 1$。 
5. 对于每个喷泉，输出`1`如果喷泉的行数等于`max_r`或一列等于`max_c`-这表明将这个喷泉交给爱丽丝会增加她的可达范围。 否则，输出`0`。 
6. 对所有测试用例重复上述操作。 

关键的不变量是爱丽丝的最大可能图仅受行和列方向上“最远”喷泉的约束。 任何不在这些极端的喷泉都不会改变最大可达面积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        fountains = [tuple(map(int, input().split())) for _ in range(k)]
        
        # Determine limiting fountains
        max_r = max(r for r, c in fountains)
        max_c = max(c for r, c in fountains)
        
        # In the easy version, Alice can always claim at least one cell
        print(1)
        
        result = []
        for r, c in fountains:
            if r == max_r or c == max_c:
                result.append("1")
            else:
                result.append("0")
        print(" ".join(result))

if __name__ == "__main__":
    solve()
```该代码使用有效地读取输入`sys.stdin.readline`。 它计算喷泉之间的最大行和列，以确定爱丽丝区域的极值约束。 然后检查每个喷泉，看看它是否可以扩大爱丽丝的区域。 输出采用每个测试用例所需的格式。
