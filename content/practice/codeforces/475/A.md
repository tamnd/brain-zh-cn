 ## 解决方案
 ## 问题理解

 巴士布局是固定的，并且已经为我们绘制好了。 共有34个乘客座位。 乘客总是以非常特定的顺序占据座位：他们从最后一排开始，从左到右填满，然后逐排向上移动。 当当前排有多个座位时，将选择最左边的空闲座位。 

输入包含单个整数`k`，当前公交车上的乘客数量。 我们必须打印六行 ASCII-art 总线图并准确标记第一个`k`已占用的登机顺序中的座位（`O`）。 每个剩余的乘客座位都空着（`#`）。 

限制非常小。 乘客人数最多为34人，正好是座位数。 即使是单独检查每个座位的强力模拟也只能执行几十次操作。 运行时在这里无关紧要，挑战是准确地再现所需的输出格式。 

最常见的错误来源是误解登机顺序。 乘客不会从前排往下挤满巴士。 他们从特殊的四排座位开始，然后继续穿过其余的排。 

考虑`k = 1`。 占用的座位必须是最后一排的第一个座位：```
+------------------------+
|O.#.#.#.#.#.#.#.#.#.#.|D|)
|#.#.#.#.#.#.#.#.#.#.#.|.|
|#.......................|
|#.#.#.#.#.#.#.#.#.#.#.|.|)
+------------------------+
```从左上角开始填充座位的解决方案会将乘客放置在错误的位置。 

另一个容易出现的错误是`k = 34`。 每个乘客座位都必须被占用。 任何忘记四排座位中额外座位的实施都只能填补 33 个位置。 

最后的边缘情况是`k = 0`。 任何座位均不应包含`O`。 一些实现意外地强制至少有一个已占用的座位，因为它们在检查是否还有座位之前会减少乘客计数器。 

## 方法

 最直接的想法就是按照乘客占用的顺序列出每个座位。 然后我们从头开始处理该列表并标记第一个`k`所占据的位置。 由于只有 34 个席位，因此该模拟最多执行 34 次更新。 

尽管这已经足够快了，但它有助于了解总线的结构。 公交车图是固定的。 仅座位字符发生变化。 我们可以构建最终的 ASCII 模板，并根据登机顺序一一替换座位位置，而不是模拟乘客在排中移动。 

关键的观察结果是，登机顺序与按预定顺序扫描座位位置完全一致。 一旦我们知道了这 34 个坐标，问题就变成了简单的字符串操作。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力乘客模拟 | O(34) | O(34) | 已接受 |
 | 最佳模板填充| O(34) | O(34) | 已接受 |

 由于座位数量是固定的，因此两种方法都具有恒定的复杂性。 模板填充版本更清晰，并直接映射到所需的输出。 

## 算法演练

 1. 将总线存储为表示所需空布局的字符串列表。 
2. 将每个字符串转换为可变字符列表，以便可以修改各个座位位置。 
3. 创建一个包含按登机顺序排列的所有 34 个座位坐标的列表。 
4. 前四个坐标对应有四个座位的特殊排。 
5. 剩余的坐标对应于其他行，从上到下、从左到右完全按照乘客占据的位置进行扫描。 
6. 迭代第一个`k`该列表的坐标并将每个位置的座位字符替换为`O`。 
7. 将所有剩余座位位置保留为`#`。 
8. 将每个字符列表转换回字符串并打印六行。 

### 为什么它有效

 坐标列表的构建顺序与乘客选择座位的顺序完全相同。 第一个坐标代表第一个可用座位，第二个坐标代表第二个可用座位，依此类推，直到列出所有 34 个座位。 标记第一个`k`占用的坐标相当于模拟到达`k`乘客。 由于每个座位在列表中只出现一次，因此不会跳过任何座位或计算两次，从而产生唯一正确的最终配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    k = int(input())

    bus = [
        list("+------------------------+"),
        list("|#.#.#.#.#.#.#.#.#.#.#.|D|)"),
        list("|#.#.#.#.#.#.#.#.#.#.#.|.|"),
        list("|#.......................|"),
        list("|#.#.#.#.#.#.#.#.#.#.#.|.|)"),
        list("+------------------------+")
    ]

    seats = []

    seats.append((3, 1))

    for c in range(1, 22, 2):
        seats.append((1, c))

    for c in range(1, 22, 2):
        seats.append((2, c))

    for c in range(1, 22, 2):
        seats.append((4, c))

    for r, c in seats[:k]:
        bus[r][c] = 'O'

    print("\n".join("".join(row) for row in bus))

if __name__ == "__main__":
    solve()
```巴士模板的存储方式与声明中显示的完全相同，只是每个座位最初都标记为`#`。 

座位表对登机顺序进行编码。 图中第3排第1列的座位是四排座位中唯一的额外座位，因此排在第一位。 之后，三个常规乘客排各提供 11 个座位，从而提供`1 + 11 + 11 + 11 = 34`总持仓量。 

循环`for r, c in seats[:k]`自然地避免了相差一的错误。 如果`k = 0`，切片为空，并且没有座位被修改。 如果`k = 34`，每个坐标都被访问一次。

 ## 边缘情况

 当`k = 0`, 切片`seats[:0]`是空的。 没有修改坐标，因此每个座位都保留`#`。 这符合公交车上没有乘客的要求。 

什么时候`k = 1`，只有第一个坐标`(3, 1)`被选中。 该坐标对应于四排座位中的特殊座位。 该算法不会意外地开始填充上面的行，因为登机顺序直接编码在坐标列表中。 

什么时候`k = 34`，循环访问存储在的每个坐标`seats`。 由于该列表恰好包含 34 个唯一的座位位置，因此每个乘客座位都会被占用，并且不会对任何座位进行两次处理。 

微妙的边界出现在`k = 12`。 第一个坐标填充特殊座位，接下来的十一个坐标填充整个上部常规行。 下一位乘客将从中间排开始。 由于坐标列表的排序正确，因此行之间的转换会自动发生，无需任何特殊情况逻辑。
