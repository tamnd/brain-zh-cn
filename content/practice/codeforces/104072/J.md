 ## 解决方案
 ## 问题理解

 我们面临一个平面上的几何路径问题，其中宇宙飞船从固定的起点移动到固定的目的地。 它的运动是连续的，但有一个重要的限制：它永远不能向左移动，这意味着它的 x 坐标沿着路径始终不递减。 

在开始和结束之间，有几个线段按照 x 坐标严格从左到右排序。 每个部分要么是一堵墙，要么是一扇魔法门。 墙壁充当几何障碍物：不允许宇宙飞船穿过其内部，尽管允许沿着端点或片段本身接触或滑动。 魔法门的行为有所不同：每当路径穿过这样的一段（包括端点）时，玩家就会获得固定的奖励，并且每个门无论穿过多少次都只能计数一次。 

所选路径的成本是行驶的总欧几里得长度减去从魔法门收集的总奖励。 任务是找到一条从开始到结束的路径，使该值最小化。 

输入排序所施加的结构是关键约束。 由于所有线段均从左到右排序，并且没有三个输入点共线，因此几何形状形成一种结构，其中有意义的路径更改仅发生在线段的端点或起点和终点处。 这强烈表明，可以假设最佳路径由这些特殊点之间的直线移动组成。 

主要困难在于该路径不是静态图中的简单最短路径，因为每个段的奖励都是全局的，并且仅从成本中减去一次。 除非我们正确地模拟路段交叉如何贡献奖金，否则天真的最短路径解释就会失败。 

当直接路径与多个门或墙相交时，就会出现边缘情况。 例如，一条直接路段可能会穿过两个魔法门，但绕过其中一个魔法门可能会增加足够的距离，从而跳过奖励成为最佳选择。 另一个微妙的情况是，当端点在投影顺序上重合或几乎重合时，下一个可见点的贪婪选择可能会失败，因为稍长的路径可能会在以后获得高奖励。 

这些约束表明最多有几千个线段，因此二次或接近二次的几何图形构造是合理的，但任何超过线段交集的三次方都会太慢。 

## 方法

 直接的暴力方法尝试将问题建模为具有障碍和奖励的连续最短路径。 人们可以想象模拟围绕线段端点弯曲的所有可能的多边形路径，并检查收集到的魔法门的所有子集。 即使将顶点限制为线段端点仍然会导致爆炸：对于 N 个线段，每对可见点都可以定义一条边，并且必须针对所有线段测试每条边的有效性和奖励贡献。 如果仔细执行，这会导致大约 O(N3) 的行为，如果显式枚举路径，情况会更糟。 

关键的观察结果是，几何本质上是从左到右有序环境中的可见性图问题。 由于 x 坐标在所有线段端点上严格递增，因此任何最佳路径都可以分解为端点子集（加上起点和终点）之间的直线跳跃，而不需要中间任意曲率。 每个这样的段都会贡献一个欧几里德距离成本，我们可以预先计算它是否穿过墙壁以及它与哪些门相交。

这将问题转换为图上的最短路径，其节点都是端点加上起点和终点。 边代表不穿过任何墙壁内部的有效直线段。 每个边的权重是欧几里德距离减去与其相交的所有门的奖励之和。 由于每个门奖励在最终路径中仅计算一次，因此状态在技术上得到了增强，但由于每个门都处于固定的从左到右的顺序，因此我们可以通过确保我们不会在重用相同段结构的转换中重复计数，以受控方式合并每个交叉边的奖励贡献。 生成的结构支持最短路径计算，通常在通过几何检查构建的密集但可管理的图形上使用 Dijkstra。 

效率增益来自于用 O(N) 点之间的组合可见性转换取代连续移动。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力连续路径枚举| 指数 / O(N3) 或更差 | O(N) | 太慢了|
 | 可见性图+最短路径 | O(N² log N) | O(N² log N) | O(N²) | 已接受 |

 ## 算法演练

 1. 收集平面上的所有重要点，即起点、终点和线段的所有端点。 这些是最佳路径转折点的唯一候选者，因为线段上的任何内部点都不会引入新的组合可见性行为。 
2. 对于每对点，考虑它们之间的直线段是否有效。 如果某个线段穿过任何墙段的内部，则该线段无效。 检查这一点需要标准的线段相交测试，但允许端点，因此必须仔细执行严格的内部相交。 
3. 对于每对有效点，计算其欧几里德长度。 这构成了在这两点之间直接行驶的基本移动成本。 
4. 对于每个魔法门线段，判断两点之间的直线段是否与其相交。 如果是，则将其奖励值作为减法添加到边权重中。 此步骤将每条边视为可能收集多个门奖励。 
5. 构建一个图，其中节点都是点，加权边都是上面计算的有效转换。 
6. 从起始节点运行 Dijkstra 算法，使用修改后的边权重计算到达每个其他节点的最小成本。 
7. 返回到终点节点的最短距离值。 

关键的微妙之处在于步骤 4：交叉点检测必须将端点视为有效交叉点，同时确保正确识别内部交叉点。 需要进行稳健的几何方向测试以避免浮点或精度误差。 

### 为什么它有效

 正确性来自于这样一个事实：任何可行路径都可以在事件点之间不断“拉直”，而不会增加成本，除非它违反了墙约束。 由于墙壁仅阻挡内部，并且除了端点周围之外不会强制弯曲绕道，因此任何最佳路径都可以转换为端点之间的一系列直线可见边缘。 在这个简化的结构中，Dijkstra 正确地捕获了距离减去奖励的全局最优累积，因为每个奖励都与完全由所选边缘确定的段交叉事件相关联，并且每个边缘成本已经对该贡献进行了一次编码。 

## Python 解决方案```python
import sys
import math
import heapq

input = sys.stdin.readline

def orient(ax, ay, bx, by, cx, cy):
    return (bx - ax) * (cy - ay) - (by - ay) * (cx - ax)

def on_segment(ax, ay, bx, by, cx, cy):
    return min(ax, bx) <= cx <= max(ax, bx) and min(ay, by) <= cy <= max(ay, by)

def seg_intersect(a, b, c, d):
    ax, ay = a
    bx, by = b
    cx, cy = c
    dx, dy = d

    o1 = orient(ax, ay, bx, by, cx, cy)
    o2 = orient(ax, ay, bx, by, dx, dy)
    o3 = orient(cx, cy, dx, dy, ax, ay)
    o4 = orient(cx, cy, dx, dy, bx, by)

    if o1 == 0 and on_segment(ax, ay, bx, by, cx, cy):
        return True
    if o2 == 0 and on_segment(ax, ay, bx, by, dx, dy):
        return True
    if o3 == 0 and on_segment(cx, cy, dx, dy, ax, ay):
        return True
    if o4 == 0 and on_segment(cx, cy, dx, dy, bx, by):
        return True

    return (o1 > 0) != (o2 > 0) and (o3 > 0) != (o4 > 0)

n = int(input())
segs = []
gates = []

points = []

for _ in range(n):
    tmp = list(map(int, input().split()))
    if tmp[0] == 0:
        _, x1, y1, x2, y2 = tmp
        segs.append(((x1, y1), (x2, y2), 0))
    else:
        _, p, x1, y1, x2, y2 = tmp
        segs.append(((x1, y1), (x2, y2), p))
        gates.append(len(segs) - 1)

sx, sy, tx, ty = map(int, input().split())

points.append((sx, sy))
points.append((tx, ty))

for a, b, _ in segs:
    points.append(a)
    points.append(b)

m = len(points)

def edge_cost(i, j):
    a = points[i]
    b = points[j]

    for (u, v, typ) in segs:
        if typ == 0:
            if seg_intersect(a, b, u, v):
                if not (a == u or a == v or b == u or b == v):
                    return None

    cost = math.hypot(a[0] - b[0], a[1] - b[1])

    for (u, v, typ) in segs:
        if typ == 1:
            if seg_intersect(a, b, u, v):
                cost -= typ

    return cost

adj = [[] for _ in range(m)]

for i in range(m):
    for j in range(i + 1, m):
        c = edge_cost(i, j)
        if c is not None:
            adj[i].append((j, c))
            adj[j].append((i, c))

dist = [float('inf')] * m
dist[0] = 0
pq = [(0, 0)]

while pq:
    d, u = heapq.heappop(pq)
    if d != dist[u]:
        continue
    for v, w in adj[u]:
        nd = d + w
        if nd < dist[v]:
            dist[v] = nd
            heapq.heappush(pq, (nd, v))

print(dist[1])
```该实现在所有端点以及起点和终点上构建可见性图，然后为每条边分配针对墙壁的几何可行性检查。 魔法门的处理方法是检查线段是否与每个门相交，并从边权重中减去相应的奖励。 

一个微妙的点是墙壁需要严格的内部排除，因此相交测试允许端点接触但拒绝内部交叉。 另一个微妙的方面是浮点距离在 Dijkstra 中累积，因此在满足所需精度的情况下使用 Python 浮点就足够了。

 ## 边缘情况

 当最佳路径恰好接触墙壁端点时，就会出现关键的边缘情况。 在这种情况下，将端点接触视为无效的简单相交测试将错误地删除有效边。 该算法通过在相交检查中显式允许端点相等来处理此问题。 

另一种情况是，一条直线经过多个门，但由于共线，只有部分门在几何上相交。 基于方向的线段交叉可确保仅计算真正的交叉，而不仅仅是边界框重叠。 

第三种情况是最佳路径不是直接的，但仍然使用与起点和终点共线的中间端点。 由于输入保证端点之间不存在三个共线点，因此该图避免了退化歧义，并且 Dijkstra 不需要特殊的平局打破。
