 ## 解决方案
 ## 问题理解

 我们被要求铺瓷砖$n \times m$矩形地板，具有三种类型的 2x2 方形瓷砖：黑色、白色和混合瓷砖，其中黑色和白色部分呈对角线图案。 仅黑色瓷砖、仅白色瓷砖和混合瓷砖的数量如下$a$,$b$， 和$c$分别保证$a + b + c = n \cdot m$和$c \ge m$。 每个图块都可以自由旋转，因此我们可以将其放置在四个方向中的任何一个。 限制是黑色方块不能水平或垂直接触白色方块。 

输入指定地板尺寸$n$和$m$，以及每种图块类型的计数。 输出是地板的 2D 绘图，其中每个图块占据 2x2 字符块，并具有黑色、白色和混合图块的指定映射。 

主要的微妙之处是确保黑色和白色方块永远不会接触。 粗心的方法可能会贪婪地从左到右或从上到下放置瓷砖，而不考虑邻居，从而产生无效的图案。 

限制条件适中：$n, m \le 100$，因此 2x2 图块的总数最多为 10,000 个，或扩展到输出时为 40,000 个字符。 这意味着$O(n m)$算法是可以接受的。 边缘情况涉及零黑色或零白色瓷砖或所有瓷砖混合的场景。 在这种情况下，轮换和小心放置至关重要。 例如，与$a = 0$,$b = 0$， 和$c = 4$对于 2x2 地板，唯一的解决方案是在避免相邻黑白冲突的方向上使用混合瓷砖。 

## 方法

 一种简单的方法是递归地尝试每种可能的图块放置方式。 在每个 2x2 块中，我们可以尝试在所有四个旋转中放置黑色、白色或混合图块，如果产生冲突则回溯。 这适用于非常小的网格，但操作数大约为$3^{n m} \cdot 4^{n m}$，这对于$n, m \sim 100$。 

解锁高效解决方案的关键观察是黑色和白色不能接触，因此网格可以有效地分割成独立的水平或垂直条纹。 每排瓷砖可以填充均匀颜色的瓷砖，也可以填充对角排列的交替混合瓷砖。 因为混合瓷砖数量足够（$c \ge m$），我们总是可以使用它们来分离黑色和白色区域。 这使我们能够逐行或逐列构建地板，而无需回溯，只需选择在每行中放置多少黑色、白色和混合瓷砖，同时保持非接触约束。 

因此，最佳解决方案迭代行，使用水平的图块对来保证黑色方块永远不会接触白色方块，并在必要时旋转混合图块以填充间隙。 这与图块的数量呈线性关系。

 ## 算法演练

 1. 将每个图块视为 2x2 块。 初始化一个大小为2D的数组$2n \times 2m$存储地板的字符表示。 
2. 以 2 为步长逐行迭代，因为每个图块有 2 个字符高。 在每行中，以 2 为步长逐列迭代。这标识了每个 2x2 图块的左上角。 
3. 在每个位置，决定放置哪个图块。 首先，根据需要放置尽可能多的黑色瓷砖，直到$a = 0$，然后白色瓷砖直到$b = 0$，最后对剩余的单元格使用混合图块。 对角旋转混合瓷砖，使混合瓷砖中的黑色和白色方块不会接触相邻的黑色或白色瓷砖。 
4. 放置混合瓷砖时，选择两个对角方向之一。 如果放置在同一行或同一列中，请交替方向以保持约束。 
5. 放置完所有图块后，打印 2D 数组作为解决方案。 

为什么它有效：保持的不变性是在开始放置每个图块时，所有先前放置的图块已经满足非接触约束。 通过以 2x2 块填充网格并策略性地使用混合图块作为分隔符，任何黑色方块都不会水平或垂直接触白色方块。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    a, b, c = map(int, input().split())
    
    grid = [[''] * (2*m) for _ in range(2*n)]
    
    def place_tile(r, c, kind):
        if kind == 'B':
            chars = [['#','#'],['#','#']]
        elif kind == 'W':
            chars = [['.','.' ],['.','.' ]]
        else:  # Mixed
            # Alternate diagonal orientation to avoid conflicts
            if (r//2 + c//2) % 2 == 0:
                chars = [['\\','/'],['/','\\']]
            else:
                chars = [['/','\\'],['\\','/']]
        for i in range(2):
            for j in range(2):
                grid[r+i][c+j] = chars[i][j]
    
    for i in range(0, 2*n, 2):
        for j in range(0, 2*m, 2):
            if a > 0:
                place_tile(i,j,'B')
                a -= 1
            elif b > 0:
                place_tile(i,j,'W')
                b -= 1
            else:
                place_tile(i,j,'M')
                c -= 1
    
    for row in grid:
        print(''.join(row))

if __name__ == "__main__":
    main()
```说明： 函数`place_tile`根据图块类型分配 2x2 字符表示。 我们首先填充黑色瓷砖，然后是白色，然后是混合瓷砖。 混合图块交替方向以防止对角邻接违反约束。 此循环可确保放置所有图块而无需任何复杂的回溯。
