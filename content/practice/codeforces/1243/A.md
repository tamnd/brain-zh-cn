 ## 解决方案
 ## 问题理解

 我们得到了几个测试用例，每个测试用例都包含一个木板高度列表。 每块木板的宽度为 1，高度为某个整数。 我们可以选择这些木板的任何子集，并以任何顺序并排重新排列它们，形成一个类似天际线的形状，其中每个选定的木板都贡献一个垂直的柱子。 

一旦木板排列好，我们就可以切出一个正方形，其边与轴对齐。 正方形必须完全位于组合形状内。 目标是最大化这样一个正方形的边长。 

问题的关键自由在于我们可以选择任何木板子集并任意排列它们。 这消除了原始阵列中的任何位置约束，并将结构简化为纯粹的多重高度集。 

约束限制很小，每个测​​试用例最多 1000 个 Plank，最多 10 个测试用例。 这允许二次或 O(n log n) 的解决方案，但任何三次或涉及重复繁重模拟的解决方案都是不必要的。 线性扫描或基于频率的推理就足够了。 

当仅关注最大高度或总和时，就会出现幼稚推理的微妙失败案例。 例如，有高度`[5, 1, 1, 1, 1]`，人们很容易认为 5×5 的正方形是可能的，因为存在 5。但是，只有一根柱子的高度至少为 5，因此我们无法形成 5 宽的正方形。 正确答案是 1。 

另一个误导性的情况是存在许多高木板但数量不够。 为了`[4, 4, 4, 1, 1]`，人们可能期望一个 4×4 的正方形，但只有三块木板的高度至少为 4，因此宽度 4 是不可能的。 

这些示例表明必须同时满足高度和数量约束。 

## 方法

 蛮力的想法是尝试每一个可能的正方形大小 k。 对于每个 k，我们检查是否可以选择至少 k 个高度至少为 k 的木板。 如果是，那么将这k块高的木板连续排列就可以形成一个k×k的正方形。 

检查单个 k 需要 O(n)，尝试所有 k 直到 n 会导致每个测试用例的 O(n²)。 当 n 达到 1000 时，这是可以接受的，但没有必要。 

关键的观察结果是，对于固定的 k，只有高度 ≥ k 的木板才重要。 如果至少有 k 个这样的木板，我们总是可以选择其中 k 个并将它们并排放置。 排列自由度消除了所有几何复杂性； 问题归结为计数条件。 

我们可以计算频率或对数组进行排序，并计算每个可能的 k 有多少个元素 ≥ k，而不是独立检查所有 k 值。 答案是满足这个条件的最大的k。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解 k | O(n²) | O(1) | O(1) | 已接受 |
 | 排序/频率计数 | O(n log n) 或 O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将几何问题转化为高度的计数问题。 

1. 对于固定的候选边长 k，我们将要求解释为需要 k 个高度至少为 k 的木板。 这是因为边长为 k 的正方形必须有 k 列，每列的高度至少为 k。 
2. 计算有多少块木板满足高度≥ k。 如果该计数至少为 k，则大小为 k 的正方形是可行的。 
3. 尝试从 1 到 n 的所有可能的 k 并跟踪最大可行值。 
4. 要有效地计算计数，请对数组进行排序或构建频率数组。 排序使我们能够使用索引位置快速确定有多少元素高于阈值。 
5. 返回满足可行性条件的最大k。 

我们可以安全地忽略排列细节的原因是，一旦我们选择了 k 个有效的木板，我们总是可以连续放置它们。 间距或顺序没有限制，因此可行性仅取决于数量，而不取决于结构。 

### 为什么它有效

 该算法依赖于这样一个事实：k×k 正方形需要 k 个高度至少为 k 的独立垂直支撑。 由于木板可以自由地重新排列，因此任何选定的子集都可以是连续的。 这消除了空间限制并减少了验证阈值和计数之间的简单不等式的问题。 一旦满足此条件，就不存在违反此条件的配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    k = int(input())
    for _ in range(k):
        n = int(input())
        a = list(map(int, input().split()))
        
        a.sort()
        
        ans = 0
        for i in range(1, n + 1):
            # number of elements >= i
            # in sorted array, this is n - first index where a[idx] >= i
            lo, hi = 0, n
            while lo < hi:
                mid = (lo + hi) // 2
                if a[mid] >= i:
                    hi = mid
                else:
                    lo = mid + 1
            cnt = n - lo
            if cnt >= i:
                ans = i
        
        print(ans)

if __name__ == "__main__":
    solve()
```该解决方案对木板高度进行排序，以便我们可以有效地计算有多少值超过每个候选阈值。 对于每个潜在的正方形边 i，我们二分搜索高度至少为 i 的第一个位置，并从该位置导出计数。 

主要的微妙之处在于正确解释条件：我们不是直接构建几何正方形，而是验证是否存在足够高的木板来支撑它。 

## 工作示例

 ### 示例 1

 输入：`[4, 3, 1, 4, 5]`我们评估可能的 k 值：

 | k | a[i] ≥ k 的计数 | 可行|
 | ---| ---| ---|
 | 1 | 5 | 是的 |
 | 2 | 4 | 是的 |
 | 3 | 4 | 是的 |
 | 4 | 3 | 没有|
 | 5 | 1 | 没有|

 最大可行值为 3。 

这表明，即使存在高度 5，它也不会主导答案，因为宽度需要多个高木板。 

### 示例 2

 输入：`[4, 4, 4, 4]`| k | a[i] ≥ k 的计数 | 可行|
 | ---| ---| ---|
 | 1 | 4 | 是的 |
 | 2 | 4 | 是的 |
 | 3 | 4 | 是的 |
 | 4 | 4 | 是的 |

 答案是 4，因为所有木板都足够高，可以支撑任何尺寸不超过 4 的正方形。 

这证明了统一高度可以最大化结果的情况。

 ## 边缘情况

 常见的边缘情况是许多小木板中存在一块非常大的木板。 例如，`[100, 1, 1, 1, 1]`应返回 1，因为只有一块木板可以支撑高度 100。 

另一种极端情况是所有木板都相同。 为了`[3, 3, 3]`，答案是 3，因为高度和计数约束在每个阈值（最高为 3）处都完美对齐。
