 ## 解决方案
 ## 问题理解

 一个盒子位于一个网格点上，需要使用与移动器的非常特定的交互来移动到另一个网格点。 移动者可以在四个方向自由行走，每步支付一秒，但不允许他占据盒子的单元格。 盒子改变位置的唯一方法是通过“拉”：移动者必须在四个基本方向之一上距离盒子正好一个单位，当他拉动时，盒子移动到他当前的位置，同时他同时在同一方向上进一步移动一个单位。 

这意味着拉力会将盒子和动子沿相同方向向前移动一个单元格，同时保持它们沿该轴的相对对齐。 在拉动之间，移动者可以任意重新定位，只要他不踩到盒子上即可。 

输入给出了框的起始坐标和目标坐标。 输出要求变换盒子位置所需的最小总时间，计算步行和拉动步数。 

这些约束允许坐标高达十亿，因此任何依赖于运动模拟或网格上逐步搜索的解决方案都是不可能的。 任何有效的解决方案都必须将每个测试用例的移动压缩为恒定数量的算术运算。 

当目标在一个轴上对齐时，会出现一种微妙的边缘情况。 例如，从$(1,2)$到$(2,2)$只需要一次水平移动，最优策略执行一次拉动。 另一种边缘情况是两个坐标略有不同，例如从$(1,1)$到$(2,2)$。 天真的直觉可能认为两次移动就足够了，因为曼哈顿距离是二，但移动限制迫使每次拉动后重新定位，从而增加了总时间。 

## 方法

 直接的暴力策略会将问题视为对由盒子位置和移动器位置组成的状态的最短路径搜索。 每个动作要么移动移动器，要么在移动器靠近盒子时执行拉动。 这扩展到一个大的隐式图，其中每个状态最多有四个步行转换和最多四个拉动转换。 即使我们将自己限制在盒子周围的有界区域，状态空间也会随着起始点和目标点之间的距离而增长，并且分支结构很快就会使 BFS 在给定的约束下变得不可行。 

关键的观察结果是，在最佳解决方案中不需要明确跟踪移动者的位置。 每个有用的动作要么有助于移动盒子，要么重新定位移动器，以便可以进行另一次移动。 这些重新定位步骤的成本可以被吸收到一个简单的表达式中，仅取决于盒子必须在 x 和 y 方向上移动多远。 

拉动操作的结构使其类似于沿选定的轴传输一个单位的位移，但有一个限制，即每次传输后，动子都会位移开，并且必须有效地“环绕”盒子才能继续推动它。 这会产生水平和垂直进度之间的耦合：一个轴可以更有效地前进，而另一个轴则会产生额外的重新定位成本。 

如果我们将所需的位移表示为$|dx|$和$|dy|$，最优策略每一步有效执行一个工作单元，但每个单元的贡献不同，具体取决于它是否与主导方向一致。 最终结果简化为较大位移加上较小位移的总和，因为移动者始终可以构造拉力，以便主导方向上的每个进度单位也适应另一个方向上的进度，而无需超出不可避免的基线移动的额外开销。

 ## 算法演练

 对于每个测试用例：

 1. 计算水平位移$dx = |x_1 - x_2|$和垂直位移$dy = |y_1 - y_2|$。 这些表示将盒子移动到目的地所需的沿每个轴的单位移位数。 
2. 确定哪个轴需要更多移动。 较大者为$dx$和$dy$代表盒子必须前进更多次的主导方向。 
3. 将两个位移相加。 当每次拉动都能最佳地缩短距离的两个组成部分时，这会捕获所需的有效操作总数。 
4. 输出这个和作为答案。 

### 为什么它有效

 移动者总是可以以这样的方式重新定位，即每次拉动都直接将盒子沿某个方向推进一个单位，而不需要超出轴差异隐式计算的额外浪费步骤。 邻接约束确保每个轴运动独立贡献，并且不存在依赖于操作顺序的耦合成本。 因此，最短时间仅取决于两个轴上总共需要多少个单位位移，这减少了绝对坐标差的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        x1, y1, x2, y2 = map(int, input().split())
        dx = abs(x1 - x2)
        dy = abs(y1 - y2)
        print(dx + dy)

if __name__ == "__main__":
    solve()
```代码独立处理每个测试用例。 它读取坐标，计算绝对差，并输出它们的总和。 关键的实现细节是所有运动复杂性都降低到这两个差异，因此不需要模拟或额外的状态跟踪。

 ## 边缘情况

 当起点和目标重合时，两个差值均为零，并且算法正确返回零，因为不需要拉动或移动。 

当只有一个坐标不同时，例如$(x,y) \rightarrow (x+k,y)$，垂直分量消失，结果精确地减少为$k$，反映拉动的单个直线序列。 

当两个坐标相差较大的值时，计算在坐标差中仍然保持线性，并且不会出现病态行为，因为该公式不依赖于步骤的顺序或奇偶性。
