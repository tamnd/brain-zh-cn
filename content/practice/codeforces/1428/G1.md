 ## 解决方案
 ## 问题理解

 我们被要求帮助一只羊最大化它所写的一组数字的“财富”。 羊必须准确地写出$k$总和为目标的非负整数$n$。 每个数字的每个数字都有一个相关的命运，在数字表中给出$0$通过$5$。 一个数字的财富是其数字财富的总和，其中每个数字根据其价值和位置做出贡献。 目标是选择数字总和最大的数字。 

输入给出$k$, 财富清单$F_0$通过$F_5$, 羊的数量$q = 1$，和一个数字$n$代表总和$k$数字。 输出是一个整数，即该羊的最大总财富。 

约束使得暴力破解变得不可行。 最大$n$和$k$靠近$10^6$，因此迭代所有可能的分割$n$进入$k$数字是不可能的。 我们必须依靠一种更加结构化的方法，利用数字和模算术的特性。 不明显的边缘情况包括最好的运气需要使用初始范围之外的数字或在数字之间不均匀地分配余数的情况。 

粗心的方法可能会尝试始终将最大可能的数字分配给第一个数字，并将其余数字除以其他数字。 例如，如果$k = 3$,$n = 57$，而命运的最佳分配是$9 + 9 + 39$，一个天真的贪婪者可能会选择$57$对于第一个数字，这违反了恰好三个数字的约束。 

## 方法

 暴力方法会枚举所有$k$-非负整数的元组总和为$n$。 对于每个元组，我们将通过将每个数字分解为数字并根据财富表求和来计算财富。 这在理论上是有效的，但是元组的数量与$n$和$k$，轻松超过$10^{11}$最大输入的操作，远远超出了3秒的限制。 

关键的见解是，数字的命运取决于它的数字，而数字是有界的。 每个数字都可以以 10 为基数来思考，而我们只关心数字$0$通过$5$因为命运表就停在那里。 我们可以将问题简化为数字级动态规划问题。 具体来说，我们可以使用 DP 数组，其中`dp[remaining_sum]`存储在一定的剩余金额和固定数量的剩余数字下可实现的最大财富。 通过考虑数字的最后一位数字以及对财富的贡献，我们可以有效地传播最佳值。 由于数字之和最多为$999999$和$k \le 999999$，我们可以通过巧妙地处理进位和模运算来解决这个问题。 

该转换依赖于计算给定数字数量和剩余总和的最佳最后一位数字贡献，这可以使用“数字 DP”表或每个模类中的贪婪分配来预先计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((n+k 选择 k)) | O(n*k) | 太慢了|
 | 最佳| 使用模块化技巧 O(n * k) 或 O(n * log n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读$k$, 财富值$F_0$到$F_5$，和总和$n$。 
2. 使用给定的财富表计算数字 0-9 的“最佳个位数财富”数组。 5 以上的数字可以忽略，因为输入只给出 0-5 的运气，我们将它们视为零。 
3. 初始化动态编程数组`dp`尺寸的`n+1`存储每个可能的总和可实现的最大财富`n`。 
4. 设置`dp[0] = 0`因为零之和产生零财富。 
5. 迭代从 1 到`n`。 对于每个总和，考虑添加一个数字$d$从 0 到 9 的数字之一。 更新`dp[sum]`作为最大值`dp[sum - d] + F[d mod 6]`，表示将总和减去该数字并加上该数字的财富。 这实际上是一个逐位贪婪DP。 
6. 填充DP数组后，羊的结果是`dp[n]`。 

工作原理：在每一步中，DP 数组都会维护以下不变量：`dp[s]`是使用某种数字组合可获得的最大财富，总和为`s`。 通过考虑当前总和的所有可能的最后一位数字，我们保证捕获最大值，并且传播到所有总和`n`确保准确的总和`n`包括在内。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

k = int(input())
F = list(map(int, input().split()))
q = int(input())
n = int(input())

# Prepare maximum fortune for each remainder modulo 6
max_digit_fortune = [0]*10
for d in range(10):
    max_digit_fortune[d] = F[d%6]

# Initialize DP array
dp = [-1]*(n+1)
dp[0] = 0

for s in range(1, n+1):
    for d in range(10):
        if s - d >= 0 and dp[s-d] != -1:
            dp[s] = max(dp[s], dp[s-d] + max_digit_fortune[d])

print(dp[n])
```第一部分读取输入并构造以 6 为模的数字数组。 DP 数组初始化为 -1，除了`dp[0] = 0`因为零总和贡献零财富。 嵌套循环更新`dp[s]`通过考虑总和的所有可能的最后一位数字`s`。 最终的答案是`dp[n]`。
