 ## 解决方案
 ## 问题理解

 我们被要求解锁一个圆形锁`n`轮子。 每个轮子都有一个编号`0`到`m-1`。 该锁具有隐藏的目标组合，我们可以使用建议的轮位置序列来查询该锁。 锁会告诉我们从每个轮子到正确目标的最小顺时针旋转距离。 目标是使用尽可能少的查询来确定完整的组合。 

正式来说，对于一个有价值的轮子`x`和目标`t`，响应为`(t - x + m) % m`。 我们可以重复查询，并且必须仅使用此反馈来重建隐藏数组。 该问题是交互式的，这意味着每个查询都取决于先前的响应。 

限制条件很大：`n`可以达到`10^5`， 和`m`可以达到`10^9`。 这排除了任何查询每种可能组合的暴力策略，因为组合的总空间是天文数字。 挑战在于最大限度地减少查询数量，同时使用锁的结构来推断正确的数字。 

边缘情况包括`n = 1`，其中单个查询就足够了，并且`m = 1`，其中所有轮子都是平凡的`0`。 另一个微妙的情况是，当多个轮子具有相同的目标值时，这可能会混淆假设每个轮子都是唯一的幼稚策略。 

## 方法

 暴力方法会尝试所有可能的组合。 对于每个查询，我们都会收到每个轮子的旋转距离。 虽然这在概念上可行，但复杂性是`O(m^n)`，即使对于很小的情况也是不可行的`n`或中等`m`。 

最佳方法利用**每个轮子上独立的二分搜索**。 对于单轮，锁的响应给出精确的偏移模数`m`。 通过仔细选择查询并解释返回的距离，我们每次都可以将搜索空间减半。 由于车轮的反馈是独立的，因此我们可以通过巧妙的编码方案同时查询所有车轮，该方案仍然允许每个车轮缩小自己的范围。 

关键的见解是，查询每个车轮位置是一个简单偏移的序列，可以让响应直接对应于每个车轮距目标的距离。 使用响应的算术，我们可以对每个轮子执行二分搜索`O(log m)`查询。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(m^n) | O(m^n) | O(n) | 太慢了|
 | 每轮二分搜索 | O(n log m) | O(n log m) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`lo`长度`n`全部为零并且`hi`长度`n`与所有`m-1`。 这些代表每个车轮的当前搜索范围。 
2. 重复直到所有轮子都收敛（`lo[i] == hi[i]`为所有人`i`）：

 a. 对于每个轮子，选择其当前范围的中点：`mid[i] = (lo[i] + hi[i]) // 2`。 使用所有这些中点构建查询。 

b. 将查询发送到锁。 接收旋转距离数组。 每个距离表示猜测距离目标模数有多远`m`。 

c. 对于每个轮子，更新其搜索范围。 如果返回的距离表明目标已顺时针过去`mid[i]`， 放`lo[i] = mid[i] + 1`; 否则，设置`hi[i] = mid[i]`。 
3. 当所有轮子都收敛后，数组`lo`包含精确的目标组合。 

**为什么有效：** 每个查询都会将每个轮子的可能值减少大约一半。 轮子的响应相对于圆形模空间中的猜测值是单调的，因此二分查找是有效的。 这个不变量保证了收敛`O(log m)`每个轮子的查询。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    lo = [0] * n
    hi = [m-1] * n
    
    while True:
        mid = [(lo[i] + hi[i]) // 2 for i in range(n)]
        print("?", *mid, flush=True)
        resp = list(map(int, input().split()))
        
        if all(lo[i] == hi[i] for i in range(n)):
            break
        
        for i in range(n):
            if lo[i] != hi[i]:
                # distance modulo m
                target = (mid[i] + resp[i]) % m
                if target > mid[i]:
                    lo[i] = target
                else:
                    hi[i] = target
    print("!", *lo, flush=True)

if __name__ == "__main__":
    solve()
```在这个实现中，`mid[i]`选择作为当前范围的中点。 回应`resp[i]`代表`(target[i] - mid[i]) % m`。 更新中`lo`和`hi`根据目标是否是顺时针方向保证二分查找不变。 使用flush可以确保交互式反馈得到正确处理。

 ## 边缘情况

 对于`n=1, m=1`，算法立即设置`lo=hi=0`。 查询返回`0`距离，确认目标。 对于重复的目标轮，每个轮独立收敛。 对于非常大的`m`，二分查找仍然收敛于`O(log m)`步骤，确保我们永远不会超出查询限制。 循环性质可以通过模算术正确处理`(mid + resp) % m`。 

这种方法稳健、交互安全，并且可以扩展到最大限制。
