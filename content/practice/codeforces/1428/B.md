 ## 解决方案
 ## 问题理解

 房间形成一个循环。 每对连续的房间之间都有一条传送带，每条传送带都可以顺时针方向移动（`>`），逆时针方向（`<`），或可双向使用（`-`）。 

如果从该房间开始的蛇可以离开该房间并随后按照允许的传送带方向返回该房间，则该房间被称为可返回的。 

一种有用的图解释是将每个房间视为有向图的顶点。 每条带提供一个定向边缘或两个定向边缘。 我们必须计算有多少个顶点属于某个有向环，因为当存在有向环穿过其房间时，蛇可以准确地离开并随后返回。 

所有测试用例的房间总数最多为 300,000 个。 这立即排除了任何从每个房间执行图形搜索的算法。 一个简单的方法大约需要$O(n^2)$在最坏的情况下工作，这变得大约$9 \times 10^{10}$操作时$n = 300000$。 我们需要一个线性解。 

有几种情况很容易误判。 

考虑：```
1
5
>>>>>
```正确答案是：```
5
```乍一看，该图看起来完全是单向的，但每个房间都属于围绕圆的同一有向循环。 从任何房间开始，蛇都可以绕一圈然后返回。 

考虑：```
1
2
<>
```正确答案是：```
0
```房间 0 只能移动到房间 1，房间 1 只能移动到房间 0。两个房间都没有任何传出路径可以让它离开并稍后返回。 该图不包含有向环。 

另一个微妙的情况是：```
1
3
<--
```正确答案是：```
3
```粗心的解决方案可能只关注全球周期方向。 这里有两个`-`皮带产生局部双向运动，每个房间都可以参与一个循环。 

## 方法

 最直接的解决方案是构建有向图并独立测试每个房间。 对于每个房间，我们可以运行 DFS 或 BFS 来确定我们是否可以离开房间并最终返回。 这是正确的，因为它明确检查了可返回性的定义。 

问题是成本。 图搜索需要$O(n)$时间，并为所有人重复$n$房间需要$O(n^2)$。 和$n$达到三十万，这已经远远超出了极限。 

为了更快地找到某些东西，我们应该检查图的结构，而不是将其视为任意有向图。 

关键的观察是只有两种全球情况是可能的。 

如果所有定向带都指向相同的圆形方向，则意味着绳子不包含`<`或不包含`>`，那么整个圆本身就是一个有向循环。 每个房间都可以退货。 

否则，两者`<`和`>`出现在某处。 在这种情况下，就不存在围绕圆的全局循环。 唯一肯定属于循环的房间是与循环相邻的房间。`-`腰带。 

为什么？ 一个`-`皮带在两个相邻房间之间产生双向运动。 这两个房间立即形成一个长度为 2 的有向循环。任何接触这样一条带的房间都是可返回的。 

当两者`<`和`>`存在，每个不属于`-`皮带参与了全球不一致的方向。 该图不能包含任何更大的循环。 唯一的有向循环来自这些双向边缘。 

这将问题简化为对至少一个端点的房间进行计数`-`皮带，除非整个圆圈的方向一致。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取皮带配置字符串。 
2. 检查字符串中是否包含`>`人物。 
3. 检查字符串中是否包含`<`人物。 
4. 如果这些方向中至少有一个缺失，则整个圆可以绕环沿单一方向遍历。 每个房间都属于同一个有向循环，所以输出`n`。 
5. 否则，创建一个数组`good`长度`n`，最初都是假的。 
6. 对于每个皮带位置`i`， 如果`s[i] == '-'`, 标记房间`i`和房间`(i + 1) mod n`一样好。 
7. 计算有多少个房间被标记为良好并输出计数。 

第 6 步有效的原因是`-`传送带允许在其两个端点房间之间双向移动。 这些房间可以移走并立即返回，这满足了定义。 

### 为什么它有效

 如果圆仅包含一个定向，则所有带实际上都是顺时针方向，或者所有带实际上都是逆时针方向。 沿着圆圈最终返回起始房间，因此每个房间都是可返回的。 

现在假设两者`<`和`>`出现。 任何定向循环都必须遵循房间的循环顺序。 一个比两个房间长的循环需要在环周围始终保持一致的方向，这是不可能的，因为两个方向都会出现。 唯一剩下的循环是由以下创建的两个循环的长度`-`腰带。 每条这样的传送带在两个方向上连接两个相邻的房间，使两个端点都可返回。 没有房间不碰`-`皮带可以属于任何循环。 

因此，该算法准确地计算了可归还的房间。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        s = input().strip()

        has_left = '<' in s
        has_right = '>' in s

        if not has_left or not has_right:
            print(n)
            continue

        good = [False] * n

        for i, ch in enumerate(s):
            if ch == '-':
                good[i] = True
                good[(i + 1) % n] = True

        print(sum(good))

solve()
```第一部分检查两个定向是否存在。 如果缺少一个方向，则立即计算每个房间。 

第二部分处理混合方向的情况。 数组`good`记录房间是否与某个双向带相邻。 

表达式`(i + 1) % n`这是至关重要的，因为房间形成一个圆圈。 什么时候`i = n - 1`，下一个房间是房间`0`。 

使用布尔数组可以避免重复计算。 一个房间可能接触两个不同的`-`腰带，但它应该只对最终答案贡献一次。

 ## 边缘情况

 考虑：```
1
2
<>
```两个方向都出现了，所以算法进入第二个分支。 没有`-`皮带，所以没有房间被标记。 答案是 0。这符合两个房间都不能离开并稍后返回的事实。 

考虑：```
1
5
>>>>>
```该字符串不包含`<`。 第4步立即返回`n = 5`。 整个环是一个有向循环，所以每个房间都是可返回的。 

考虑：```
1
3
<--
```两个方向都不存在，因为没有`>`。 算法立即输出 3。 事实上，蛇可以绕圈移动并从每个房间返回。 

考虑：```
1
5
><-><
```两个都`<`和`>`出现，所以只有房间接触`-`被计算在内。 这`-`传送带位于位置 2，连接房间 2 和 3。这两个房间被标记，产生答案 2。不存在更大的循环，因为圆圈包含冲突的方向。
