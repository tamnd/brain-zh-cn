 ## 解决方案
 ## 问题理解

 我们得到一个表示为二进制字符串的水果序列，其中`1`代表一个苹果和`0`一个橙子。 目标是在所有可能的连续子串上计算该子串中最长连续苹果的长度并对这些值求和。 例如，如果子字符串是`01110`，最长的连续苹果是`3`，这有助于`3`至总和。 

限制很重要：字符串长度`n`最多可达50万。 这意味着任何单独检查所有子字符串的简单方法都是不切实际的。 大致有$n(n+1)/2$子串，对于$n = 5 \cdot 10^5$放弃$10^{11}$子串。 即使对每个子串进行线性扫描也需要$O(n^3)$最坏情况下的操作，在2秒的时间限制下是不可行的。 我们需要一种更接近线性或线性算数时间的方法。 

边缘情况包括全是苹果或全是橙子的序列。 如果字符串全是1，则每个子串的最大序列等于其长度，必须避免错误的重复计算。 相反，如果字符串仅包含零，则每个子字符串都贡献零，并且算法不得崩溃或错误计算。 

## 方法

 暴力解决方案很简单。 我们迭代所有可能的起始索引`l`和结束索引`r`，提取子字符串，然后扫描它以找到最长的连续串。 虽然正确，但这需要$O(n^3)$操作，因为有$O(n^2)$子串和每次扫描可以采取$O(n)$时间。 这明显超出了时间限制$n = 5 \cdot 10^5$。 

更快解决方案的关键在于处理**连续块**。 观察到每个最大的 1 运行都以结构化方式贡献多个子字符串。 对于一块`k`连续的，它全部或部分出现在许多子串中。 通过使用组合学直接计算每个块的贡献而不是检查每个子串，我们可以实现线性时间。 

我们将字符串视为零和一的交替序列。 对于每个连续的长度块`k`，我们可以计算包含它的所有子串的贡献总和。 具体来说，对于每个可能的子长度`i`（从 1 到`k`)，该块准确贡献的子串数量`i`是`(k - i + 1)`乘以向左和向右延伸越过相邻零的方式的数量。 通过迭代块，我们可以将总和累加到`O(n)`时间。

 | --- | --- | --- | --- |
 | 蛮力 | O(n^3) | O(n^3) | O(1) | O(1) | 太慢了|
 | 区块贡献计数 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.初始化一个总和变量`ans`为零。 这将累积所有子字符串的最大总和。 
2. 从左到右扫描字符串一次，以识别连续的 1 块。 维护一个柜台`count`遇到 1 时增加，遇到 0 时重置为零。 每当遇到零时，如果非零，则记录前一个块的长度。 
3. 对于每个长度连续的块`k`，计算其对所有子串的总贡献。 贡献可以作为第一个的总和得出`k`正整数：$1 + 2 + \dots + k = k(k+1)/2$。 这个公式的出现是因为长度的块`k`可以生成`k`长度为1的子串，`k-1`长度为 2 的子串，下至长度为 1 的子串`k`，每个都完全由 1 组成。 
4. 将区块贡献添加到总和中`ans`。 继续扫描直到字符串末尾以捕获所有块。 
5. 处理完最后一个字符后，如果字符串以 1 结尾，请确保考虑到最后一个块。 
6. 打印总和`ans`。 

为什么它有效：每个连续的块对总和的贡献与至少包含该块的一部分的子串数量一样多。 通过仅考虑块并使用算术和公式，我们可以避免枚举每个子字符串，同时仍然对每个贡献精确计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
s = input().strip()

ans = 0
count = 0

for ch in s:
    if ch == '1':
        count += 1
    else:
        ans += count * (count + 1) // 2
        count = 0

# add the last block if the string ends with ones
ans += count * (count + 1) // 2

print(ans)
```此代码扫描字符串一次。 每次找到零时，它都会完成前一个块并添加其贡献。 算术和公式用于有效计算块内所有可能的连续长度的长度总和。 循环后的最后一个添加处理字符串以一个块结尾的情况。

 ## 边缘情况

 对于全为一串，例如`11111`，算法识别长度为 5 的单个块并计算总和$5*6/2 = 15$。 这与所有子字符串的总和相匹配，其中包括长度为 1 到 5 的子字符串的贡献。 

对于全零的字符串，例如`0000`，每个块长度都为零，因此该算法不累积任何内容，导致总和为零，正确反映没有子串包含连续的子串。 

对于单字符字符串，可以是`1`或者`0`，算法正确计数`1`如果角色是 1 并且`0`否则，展示对最小输入的正确处理。
