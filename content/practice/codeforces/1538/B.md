 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，表示每个人最初拥有多少糖果。 在一次操作中，我们可以选择一部分人，拿走他们的所有糖果，然后将这些糖果自由地重新分配给每个人。 

目标是在这个单一的重新分配步骤之后使所有值相等。 然而，有一个限制：我们不能免费挑选所有人。 我们关心的成本是被选择的人的数量，我们希望最小化我们必须选择的人的数量，以便他们的组合糖果足以实现完全相等的最终配置。 

重新构建任务的一个有用方法是考虑相对于目标值的赤字和盈余，如果存在解决方案，则目标值必须是数组的平均值。 重新分配步骤完全不受限制，只是我们只从选定的索引中收集糖果，因此唯一的限制是所选子集是否包含足够的总“可调整质量”来纠正与平均值的所有偏差。 

对输入大小的限制适中，测试用例最多为一万个，数组总长度最多为二十万。 这排除了每个测试解决方案的任何二次方，但允许每个测试进行排序或线性传递。 这些值本身足够小，可以直接处理，关键的困难不是算术幅度而是子集结构。 

当总和不能被 n 整除时，就会出现微妙的边缘情况。 在这种情况下，无论我们选择多少元素，重新分配都无法产生相同的值。 当所有值都相等时会出现另一种极端情况，在这种情况下选择零个元素就足够了。 第三种情况是只有一个元素与均值的偏差不为零； 然后仅选择该元素就足够了，即使它很大，因为它的删除可以准确地修复不平衡。 

## 方法

 强力解释会尝试索引的所有子集。 对于每个子集，我们计算所选值的总和，并检查删除它们是否留下可以均匀分布的总数。 这原则上是正确的，因为它直接匹配允许操作的定义，但它立即变成 n 的指数。 当 n 次测试达到 20 万时，甚至存储子集也是不可能的，并且候选数量会增长 2^n。 

关键的观察是最终配置是固定的：每个元素必须以平均值结束，因此总和决定一切。 这将问题转化为决定我们必须“修复”哪些元素，以便它们的总贡献可以平衡偏差。 我们不考虑重新分配序列，只关心所选子集是否可以解释总的过剩或赤字。 

一旦我们确定了目标均值，每个元素都会产生与目标均值的偏差。 任务变成选择总偏差与总不平衡相匹配的最小数量的元素。 由于正偏差和负偏差必须全局抵消，因此最佳策略是优先考虑绝对偏差最大的元素，因为它们为每个所选指标提供最大的“校正能力”。 

因此，我们按绝对值对偏差进行排序，并贪婪地累积，直到达到所需的校正。 当我们达到零残余不平衡时，所选元素的数量是最佳的，因为任何较小量值元素的替换都将需要更多的选择。

 ## 算法演练

1. 计算数组的总和并检查它是否能被n整除。 如果它不可整除，则不可能进行均衡，因此答案为 -1。 这是因为重新分配保留了总和。 
2. 将总和除以 n 来计算目标值。 每个最终配置都必须将该值准确分配给每个位置。 
3. 对于每个元素，计算其与目标的偏差。 正偏差表示盈余，负偏差表示赤字。 这些偏差代表了每个指标对不平衡的贡献程度。 
4. 观察到所有偏差的总和为零，因此任务简化为使用偏差被“激活”的索引子集来消除不平衡。 
5. 按绝对偏差降序对元素进行排序。 大偏差更有效，因为每个选定的指标对纠正不平衡的贡献更大。 
6. 遍历排序列表，累积偏差贡献，直到运行校正的不平衡达到零。 计算使用了多少个元素。 
7. 返回此计数作为所选好友的最小数量。 

### 为什么它有效

 每个选定的指标都会消除其与系统的偏差，目标是使用最少数量的此类消除来消除总体不平衡。 由于每次去除都会线性地影响其偏差值，因此选择较大的幅度首先可以最大限度地减少消除总不平衡所需的步骤数。 任何使用较小偏差同时跳过较大偏差的解决方案都可以通过交换它们来改进，减少或保留所选元素的数量，同时增加校正能力，从而保证贪婪最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        s = sum(a)
        if s % n != 0:
            out.append("-1")
            continue

        target = s // n

        dev = [x - target for x in a]

        dev.sort(key=lambda x: abs(x), reverse=True)

        need = 0
        cnt = 0

        for d in dev:
            if need == 0:
                break
            need += d
            cnt += 1

        out.append(str(cnt))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该解决方案首先通过总和的整除性验证可行性，因为重新分配不能改变全局总和。 然后，它将问题转化为与目标值的偏差，从而隔离出必须解决的确切不平衡问题。 

按绝对偏差排序可确保我们始终首先考虑最有影响力的修正。 该循环模拟获取元素直到不平衡消失，并且计数器跟踪需要多少元素。 

一个微妙的点是，停止条件是当累积偏差抵消总不平衡时，而不是当所有元素都被处理完时。 这反映出我们只需要足够的选定指数来解决全球差异，而不是全部。 

## 工作示例

 ### 示例 1

 输入：```
n = 4
a = [4, 5, 2, 5]
```目标是 4。Dev = [0, 1, -2, 1]

 按绝对值排序：[-2, 1, 1, 0]

 | 步骤| 选择| 运行总和|
 | --- | --- | --- |
 | 1 | -2 | -2 |
 | 2 | +1 | -1 |
 | 3 | +1 | 0 |

 我们在 3 个选择后停止，这意味着三个元素足以平衡系统。 这表明必须首先纠正较大的负偏差，然后通过较小的正偏差完成平衡。 

### 示例 2

 输入：```
n = 2
a = [0, 4]
```目标为 2。Dev = [-2, 2]

 已排序：[2, -2]

 | 步骤| 选择| 运行总和|
 | --- | --- | --- |
 | 1 | 2 | 2 |
 | 2 | -2 | 0 |

 这两个元素都是必需的，因此答案为 2。这证实了当偏差对称且大小相等时，必须选择两个元素。

 ## 边缘情况

 当所有元素都已经相等时，偏差数组全为零，因此循环立即终止并返回零，而不选择任何内容。 

当总和不能被 n 整除时，算法会提前停止并输出 -1，因为不存在目标均值，因此无论子集选择如何，都无法进行重新分配。 

当只有一个元素时，它总是已经等于自身，因此答案为零，因为不需要校正。
