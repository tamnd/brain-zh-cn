 ## 解决方案
 ## 问题理解

 我们给出了几个独立的场景。 每一个都有一个产品价格列表，每个价格最多可以调整`k`向任一方向，但我们不允许多次调整。 经过这些调整后，我们希望所有产品最终的整数价格完全相同`B`。 

选定值的条件`B`简单但严格：每一个原价`a_i`必须能够移动到`B`不超过允许的变化，即绝对差异`|a_i - B|`不得超过`k`。 如果连一种产品都达不到`B`，那么该值`B`无效。 

在所有有效整数值中`B`，我们需要找到最大的那个。 如果没有整数满足所有元素的条件，我们输出`-1`。 

每个查询都是独立的，因此每次都会使用新数组重新启动该过程。 

限制很小：`n ≤ 100`,`q ≤ 100`。 这立即排除了对每个查询的线性或对数线性工作之外的高级数据结构或优化的任何需要。 即使每个查询使用 O(n^2) 方法也能轻松通过。 

当不同元素定义的间隔根本不重叠时，就会出现微妙的边缘情况。 例如，如果我们有`a = [1, 100]`和`k = 10`，那么有效范围是`[−9, 11]`和`[90, 110]`，它们不相交，因此无效`B`存在。 

另一种边缘情况是交集有效但最大边界不直观。 例如，如果所有间隔都严重重叠，则答案就是交点的最右边点。 

## 方法

 暴力方法会尝试所有可能的整数`B`从`1`最多`max(a_i) + k`，并检查每个元素是否满足`|a_i - B| ≤ k`。 对于每位候选人`B`，我们扫描数组，因此复杂度变为 O(M·n)，其中 M 是可能值的范围。 自从`a_i`可以达到`10^8`, M 也可能很大，使得这种方法在最坏的情况下完全不可行。 

关键的观察是每个元素`a_i`不允许任意值`B`，而是将其限制在一个区间内`[a_i - k, a_i + k]`。 “所有乘积都可以等于 B”这一条件相当于要求 B 位于所有这些区间的交集内。 一旦我们以这种方式解释问题，它就会简化为标准区间交集问题。 

许多区间的交集本身就是一个区间`[L, R]`， 在哪里`L`是所有左端点的最大值，并且`R`是所有正确端点的最小值。 如果`L > R`，交集为空且不存在解。 否则，中的每个整数`[L, R]`是有效的，并且因为我们想要最大可能的`B`，我们只需选择`R`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n·max(a_i + k)) | O(n·max(a_i + k)) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个查询，读取价格数组和值`k`。 

我们独立处理每个场景，因此不共享任何状态。 
2. 每个价格`a_i`，计算有效最终值的区间：`[a_i - k, a_i + k]`。 

这直接对约束进行编码`|a_i - B| ≤ k`。 
3.维护两个变量：`L`初始化为一个非常小的数字，并且`R`初始化为一个非常大的数字。 

这些代表迄今为止处理的所有间隔的交集。 
4. 对于每个间隔`[l, r]`， 更新：`L = max(L, l)`和`R = min(R, r)`。 

这仅保留以下值`B`这对于迄今为止看到的所有元素都有效。 
5.处理完所有元素后，检查是否`L > R`。 

如果发生这种情况，则交集内没有整数，所以答案是`-1`。 
6. 否则，输出`R`，因为它是满足所有约束的最大整数。 

### 为什么它有效

 每个元素独立地限制`B`到有效值的闭区间。 值为`B`仅当它同时满足每个元素的约束时才对整个数组有效，这正是属于所有区间的交集的定义。 该算法增量地维护此交集，并且在任何步骤中它都不会丢弃仍然可以满足所有已处理约束的任何值。 因此，如果一个值存活到末尾，则它对所有元素都有效，如果交集变空，则不存在有效值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

q = int(input())
for _ in range(q):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    L = -10**18
    R = 10**18

    for x in a:
        L = max(L, x - k)
        R = min(R, x + k)

    if L > R:
        print(-1)
    else:
        print(R)
```该解决方案将每个价格转换为允许的区间并保持它们相交。 唯一微妙的实现细节是选择足够大的初始边界`L`和`R`，因为价格可能会上涨到`10^8`和`k`最多`10^8`，因此得到的区间可能会超出原始范围。

 ## 边缘情况

 一个重要的边缘情况是当`k = 0`。 在这种情况下，每个区间都会折叠为`[a_i, a_i]`，所以唯一可能的解决方案是所有元素都已经相等。 该算法自然地处理这个问题，因为只有当所有值完全匹配时，交集才会存在。 

另一个边缘情况是当`n = 1`。 答案很简单`a_1 + k`，因为单个区间是`[a_1 - k, a_1 + k]`我们选择最大有效值。 

当值很大并且`k`也很大，可能会超出原始输入范围。 在实现中使用宽整数边界可确保不会溢出或剪裁影响正确性，因为 Python 整数是无界的并且逻辑仅取决于比较。 

最后，交叉点提前缩小到单个点的情况得到了正确处理，因为算法不断收紧两端，永远不会丢失仍能满足所有约束的有效候选点。
