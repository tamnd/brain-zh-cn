 ## 解决方案
 ## 问题理解

 我们有一条街`n`建设职位。 每个位置可以包含一个高度为以下整数的房子`0`和`h`。 

高层房子的利润`a`是`a²`，所以房子越高越好。 该市强行规定`m`分区规则。 每条规则涵盖一段仓位`[l, r]`并表示该段内最高的房子不能超过某个值`x`。 

任务是为每个仓位选择一个高度，以满足所有限制，并且总利润（所有高度的平方和）尽可能大。 

限制非常小。 两个都`n`和`m`至多是`50`。 即使是执行与每个位置的每个限制时间成比例的工作的算法也是完全安全的。 一个`O(nm)`或者`O(n²m)`解决方案立即运行。 

主要挑战是了解范围限制如何影响个别房屋。 限制规定范围内的最大高度不能超过`x`。 这意味着该范围内的每栋房屋也最多必须`x`。 如果连一栋房子比`x`，范围的最大值将超过`x`并且该限制将被违反。 

一个常见的错误是将限制视为仅适用于一个职位。 

考虑：```
3 10 1
1 3 5
```每栋房屋都位于限制范围内，因此每栋房屋的高度不得超过`5`。 

最佳高度是：```
[5, 5, 5]
```利润：```
25 + 25 + 25 = 75
```粗心的解释可能会允许这样的高度`[10, 10, 10]`，这显然违反了限制。 

另一个容易犯的错误是忘记多个限制可以重叠。 

例子：```
3 10 2
1 2 7
2 3 4
```位置`2`属于这两个范围。 它的高度必须满足这两个限制，因此它的有效最大值为：```
min(7, 4) = 4
```最佳高度变为：```
[7, 4, 4]
```忽略其中一项限制将产生无效答案。 

最后一个微妙的一点是，某些职位可能永远不会出现在任何限制中。 

例子：```
3 10 1
2 2 3
```位置`1`和位置`3`除全局限制外不受限制`h = 10`，所以他们应该保持在高度`10`。 

最佳高度是：```
[10, 3, 10]
```利润：```
100 + 9 + 100 = 209
```## 方法

 一种蛮力的想法是尝试每一种可能的高度分配并保留最佳的有效分配。 每个位置最多有`h + 1`选择，所以有`(h + 1)^n`可能的配置。 

和`n = 50`和`h = 50`，这大致是：```
51^50
```这是一个天文数字，完全不可能。 

关键的观察结果是，每个限制都直接转化为各个位置的上限。 

假设一个限制说：```
l = 2, r = 5, x = 7
```由于该区间内的最大高度不得超过`7`，每个位置从`2`通过`5`最多只能是`7`。 

这意味着我们可以独立思考每个位置。 首先假设每个位置都能达到高度`h`。 然后处理每个限制并将每个覆盖位置的允许高度减少为：```
current_limit = min(current_limit, x)
```所有限制处理完毕后，每个位置都有一个有效的最大高度。 

现在考虑目标函数。 一个仓位贡献的利润为：```
a²
```这严格增加为`a`非负高度增加。 

由于位置不再相互作用，因此每个位置的最佳选择就是其最大允许高度。 

整个问题归结为计算每个位置允许的最终最大高度并对它们的平方求和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O((h+1)^n) | O((h+1)^n) | O(n) | 太慢了 |
 | 最佳 | O(纳米) | O(n) | 已接受 |

 ## 算法演练

 1. 创建数组`height`长度`n`并将每个条目初始化为`h`。 
2. 处理每个限制`(l, r, x)`。 
3. 对于区间内的每个位置`[l, r]`，将其当前限制替换为：```
min(current_limit, x)
```这会累积影响该职位的所有限制。 
4. 处理完所有限制后，每个条目`height`存储该位置的最大合法高度。 
5. 计算：```
answer = Σ height[i]²
```6. 输出结果总和。 

### 为什么它有效

 对范围的限制表示该范围内的任何房屋都不得超过`x`。 正在申请`min(current_limit, x)`每个涵盖的职位都准确记录了这一要求。 

处理完所有限制后，为某个位置存储的值是覆盖该位置的任何限制对其施加的最小上限，或者`h`如果没有人覆盖它。 

利润函数随着高度增加，因为所有高度都是非负的并且利润等于`a²`。 建造房子永远不会减少利润。 因此，对于每个位置，最佳选择是其最大合法高度。 选择较小的值只会降低利润，并且无助于满足任何额外的约束，因为所有约束都已被编码到每个位置的限制中。 

因此，该算法构建了独特的利润最大化配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, h, m = map(int, input().split())

height = [h] * n

for _ in range(m):
    l, r, x = map(int, input().split())
    for i in range(l - 1, r):
        height[i] = min(height[i], x)

answer = sum(v * v for v in height)
print(answer)
```数组`height`存储每个位置的当前最大允许高度。 

最初每个位置都能达到高度`h`，所以数组充满了`h`。 

每个限制都会立即处理。 由于输入使用从一开始的索引，而 Python 列表使用从零开始的索引，因此间隔`[l, r]`变成：```
range(l - 1, r)
```对于每个涵盖的头寸，我们保留迄今为止看到的最低限额。 

应用所有限制后，每个位置都已包含其最佳高度。 最后的循环计算平方和。 

重叠间隔不需要特殊处理，因为重复`min`操作自然地结合了所有限制。 整数溢出也无关紧要，因为最大可能的答案是：```
50 × 50² = 125000
```它很容易适合 Python 整数。

 ## 边缘情况

 ### 重叠限制

 输入：```
3 10 2
1 2 7
2 3 4
```处理给出：```
[10,10,10]
→ [7,7,10]
→ [7,4,4]
```位置`2`接受两个限制并保留较小的值`4`。 最终利润为：```
49 + 16 + 16 = 81
```该算法通过重复自动处理这个问题`min`运营。 

### 覆盖整条街道的限制

 输入：```
3 10 1
1 3 5
```处理给出：```
[10,10,10]
→ [5,5,5]
```利润：```
25 + 25 + 25 = 75
```每个仓位都属于限制区间，因此每个仓位都有相同的上限。 

### 职位不受限制

 输入：```
3 10 1
2 2 3
```处理给出：```
[10,10,10]
→ [10,3,10]
```职位`1`和`3`从未出现在任何区间中，因此它们保留其原始限制`h = 10`。 

利润：```
100 + 9 + 100 = 209
```初始化与`h`保证不受限制的位置自动获得最大可能的合法高度。
