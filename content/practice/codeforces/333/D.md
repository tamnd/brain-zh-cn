 ## 解决方案
 ## 问题理解

 我们有一个矩形的数字网格$n$行和$m$列。 每个单元格包含一个非负整数。 表格的“属性”被定义为四个角单元中的最小值。 杰拉德希望通过可能从四个侧面中的任何一个裁剪桌子来最大化此属性。 裁剪可以从顶部和底部删除零个或更多行，从左侧和右侧删除零个或更多列，但必须保留至少两行和两列。 

任务是计算任何遵守 2×2 最小尺寸约束的子矩形的最大可能属性。 换句话说，在所有大小至少为 2×2 的子矩形中，四个角数中最大可能的最小值是多少？ 

输入限制适中但并不小：$n$和$m$最大可达 1000。考虑每个可能的子矩形的简单暴力方法需要粗略地迭代$\frac{n(n+1)}{2} \times \frac{m(m+1)}{2}$矩形，在最坏的情况下可能需要大约 2.5 亿次操作。 这超出了典型的时间限制，因此我们需要一种更聪明的方法。 

需要观察的边缘情况包括正好 2×2 的网格，其中不可能进行裁剪。 在这种情况下，该属性只是所有四个单元格中的最小值。 另一个微妙的情况是当最佳矩形使用极端的行或列时，例如，当最大的属性来自于仅忽略一行和一列时。 

## 方法

 强力方法将枚举子矩形的所有左上角和右下角坐标对。 对于每个角，计算四个角，取最小值，并跟踪全局最大值。 这种方法原则上是正确的，但需要迭代$O(n^2 m^2)$对于最坏情况的 1000×1000 网格来说，它大约需要十亿次操作，这太慢了。 

关键的见解来自于注意到只有矩形的四个角很重要。 因此，我们不需要计算整个矩形甚至内部单元格的最小值。 这让我们在选择矩形边框时可以关注四个角值的最大值。 另一个观察结果是，该问题具有单调属性：如果新行具有较大的角点候选，则向内移动顶行或底行只会增加角点的最小值。 因此，我们只需要考虑以某种方式接触四个原始角之一的矩形。 

通过分析对称性，我们可以将候选矩形减少到最大化最小角的四个选项：采用左上角和右下角、右上角和左下角，或者只从每一侧删除一行或一列的矩形。 具体来说，最优值是以下各项中的最大值：

 - 四个最外角的最小值，
 - 前两行和最后两行与前两列和最后两列的最小值。 

这将问题减少到评估少数候选值而不是每个子矩形。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²·平方米) | O(1) | O(1) | 太慢了 |
 | 最佳 | O(n + m) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将输入网格读入二维整数列表。 这允许快速访问任何单元。 
2. 识别整个网格四个角的值：左上、右上、左下、右下。 
3. 初始化变量`best`到这四个角的最小值。 这表示未经裁剪的整个表格的属性。 
4. 考虑前两行和最后两行。 对于每一行，考虑最左边和最右边的值。 计算这四个候选者中的最小值。 如果这个最小值超过`best`， 更新`best`。 
5. 同样，考虑前两列和最后两列。 对于每一列，考虑最上面和最下面的值。 计算这四个候选者中的最小值。 更新`best`如果有改善的话。 
6.检查完这些对称组合后，`best`包含通过裁剪同时保留至少 2 行和 2 列可获得的最大可能属性。 

这样做的原因是任何小于完整网格但至少 2×2 的矩形都将包含最外面两行或两列的某种组合。 因此，通过仅检查这些候选边界，我们可以保证捕获裁剪矩形的最佳角点。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
grid = [list(map(int, input().split())) for _ in range(n)]

# Start with the property of the full table
best = min(grid[0][0], grid[0][m-1], grid[n-1][0], grid[n-1][m-1])

# Check first two rows and last two rows for corner combinations
candidates = [
    min(grid[0][0], grid[0][m-1], grid[1][0], grid[1][m-1]),
    min(grid[n-2][0], grid[n-2][m-1], grid[n-1][0], grid[n-1][m-1]),
    min(grid[0][0], grid[1][0], grid[n-2][0], grid[n-1][0]),
    min(grid[0][m-2], grid[1][m-2], grid[n-2][m-1], grid[n-1][m-1])
]

best = max([best] + candidates)

print(best)
```该解决方案读取网格，从整个表中初始化最佳值，然后检查边界附近的对称 2×2 子矩形。 使用`min`和`max`这样可以确保我们捕获所有潜在的最佳裁剪配置，同时尊重最小 2×2 尺寸约束。 这可以避免处理最后一行或最后一列时出现差一错误。

 | 测量| 复杂性 | 说明|
