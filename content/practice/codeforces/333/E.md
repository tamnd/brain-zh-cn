 ## 解决方案
 ## 问题理解

 我们在平面上得到一组候选点，我们必须恰好选择其中的三个作为三个相同圆的中心。 所有三个圆必须具有相同的半径，并且允许它们接触但内部不能重叠。 半径不是预先固定的； 相反，我们试图使其尽可能大，同时仍然能够将圆放置在三个选定的中心而不相交。 

如果我们选择三个中心，半径将受到这三个点中最近的一对的约束。 当且仅当两个半径相等的圆心之间的距离至少是半径的两倍时，它们才不会重叠。 因此，对于选定的三元组，限制因素是三个点之间的最小成对距离。 该三元组的最佳半径是该最小距离的一半。 

因此，该任务相当于选择三个点来最大化最小成对距离，然后将该值除以二。 

输入大小最多为 3000 点。 超过三倍的立方或接近立方的解决方案已经是临界点，因为 3000 立方 大约是 270 亿次操作。 即使对所有对进行二次扫描也可以，但我们需要小心如何从成对信息中提取最佳三元组。 

当多个点位于一个圆上或形成近乎退化的配置时，就会出现一个微妙的问题。 例如，如果除了一个遥远的异常值之外，许多点都非常接近，则仅考虑全局最佳对的简单方法可能会错过第三个点破坏候选对的情况。 

典型的故障模式是选择最远的一对点并假设任何第三点都有效。 例如，如果两个点相距极远，但第三个点靠近其中一个点，则半径实际上会因第三点而变小。 所以我们必须联合考虑三元组，而不是独立地考虑对。 

## 方法

 暴力解决方案将枚举每个三重点。 对于每个三元组，计算所有三个成对距离并取最小值。 这是正确的，但要付出代价$O(n^3)$，对于$n = 3000$。 

关键的观察是对于一对固定的点$A$和$B$，第三个点可以限制半径的唯一方法是它距离比$AB$到任一$A$或者$B$。 因此，如果我们修复一个候选对，我们需要第三个点距离两个端点尽可能远，从某种意义上说，我们关心最大化其到该对的距离的最小值。 

我们不是直接在几何中推理三元组，而是反转问题。 假设我们猜测最优答案有价值$R$。 然后我们只需要检查是否存在一个三元组，其中所有成对距离至少为$2R$。 这成为图上的可行性问题：连接距离至少为$2R$，我们想知道该图中是否存在三角形。 

如果天真地这样做，直接在所有边上检查三角形仍然是昂贵的。 但是，我们可以使用这样的结构$n \le 3000$。 对于每对$(i, j)$，我们可以预先计算所有有效的邻居$i$，并维护邻接集。 然后对于每条边$(i, j)$，我们需要检查是否存在共同邻居$k$使得两条边都存在。 使用位集，相交检查变得更快。 

这自然会导致对答案进行二分搜索：我们对所有成对距离进行排序，或者直接对半径进行二分搜索，并使用位集交集检查可行性。 每张支票的运行时间约为$O(n^2 / 64)$，这是可以接受的。 

更直接的观点避免了显式的二分搜索。 我们计算所有成对距离，对它们进行排序，并隐式考虑阈值，但二分搜索更容易推理。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（三倍）|$O(n^3)$|$O(1)$| 太慢了 |
 | 二分查找+位集三角检查|$O(n^2 \log n / 64)$|$O(n^2 / 64)$| 已接受 |

 ## 算法演练

 1. 预先计算所有点对之间的平方距离。 这避免了比较期间的浮点错误，并让我们可以在大部分逻辑中使用整数。 
2. 收集所有唯一距离（或使用 0 到最大距离之间的二分搜索界限）。 答案单调取决于半径，因为增加半径只会使约束更加严格。 
3. 对于候选半径$r$，将其转化为阈值$d = (2r)^2$。 我们只允许平方距离至少为的点对之间的边$d$。 
4. 隐式构建一个图，其中边意味着“这两点可以同时作为半径的中心”$r$”。
 5. 对于每个节点$i$，将其邻接存储为所有节点上的位集。 这种表示允许在邻居集之间进行快速交叉检查。 
6. 要检查是否存在有效的三元组，请迭代所有边$(i, j)$。 如果它们相连，则计算邻接集的交集$i$和$j$。 如果在交点处设置了任何位，则第三个点$k$存在形成一个有效的三角形。 
7. 如果存在任何三角形，则半径$r$是可行的； 否则就不是。 使用它作为二分搜索中的谓词。 

### 为什么它有效

 任何有效的解决方案都是由三组点定义的，这些点的成对距离都超过$2r$。 这正是阈值图中的一个三角形。 位集相交步骤确保我们不仅找到两个独立的兼容边，而且找到一个完全共享的邻居，这是完成三角形的第三个顶点。 由于所有三元组都是通过边对及其公共邻居隐式检查的，因此不会遗漏任何有效配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    dist2 = [[0] * n for _ in range(n)]
    max_d = 0

    for i in range(n):
        x1, y1 = pts[i]
        for j in range(i + 1, n):
            x2, y2 = pts[j]
            dx = x1 - x2
            dy = y1 - y2
            d = dx * dx + dy * dy
            dist2[i][j] = dist2[j][i] = d
            if d > max_d:
                max_d = d

    # bitset adjacency for threshold graph
    bit = [0] * n

    def check(threshold):
        nonlocal bit
        for i in range(n):
            bit[i] = 0

        for i in range(n):
            for j in range(n):
                if i != j and dist2[i][j] >= threshold:
                    bit[i] |= (1 << j)

        for i in range(n):
            for j in range(i + 1, n):
                if bit[i] & bit[j] & (1 << i | 1 << j):
                    continue
                if bit[i] & bit[j]:
                    return True
        return False

    # binary search on squared diameter
    lo, hi = 0, max_d

    for _ in range(60):
        mid = (lo + hi) // 2
        if check(mid):
            lo = mid
        else:
            hi = mid

    radius2 = lo / 4.0
    print((lo ** 0.5) / 2.0)

if __name__ == "__main__":
    solve()
```该实现首先计算所有平方成对距离，因为所有几何比较都简化为距离比较，并且平方避免了可行性检查期间的浮点不稳定。 

这`check`函数构造候选平方距离的阈值图。 为每个节点构建邻接位掩码。 有效三元组的条件是存在两个节点$i, j$这样它们都连接到某个第三个节点$k$，这是通过它们的位掩码的交集来检测的。 

二分搜索在平方距离上运行，最终半径是最佳可行平方阈值平方根的一半。 

一个微妙的问题是确保最多 3000 个节点的位操作保持正确。 Python 整数处理任意位长度，因此这是安全的，但实际上性能依赖于稀疏交集。

    sys.stdin = io.StringIO(inp)
    from math import sqrt

    data = inp.strip().split()
    n = int(data[0])
    pts = [(int(data[i]), int(data[i+1])) for i in range(1, 2*n, 2)]

        for j in range(n):

 ## 边缘情况

 当所有点几乎共线时，就会出现关键的边缘情况。 在这种情况下，最佳三元组是通过选择两个远端点和一个最小化瓶颈距离的中间点来形成的。 该算法仍然有效，因为阈值图只会连接足够远的对，并且除非存在三个相互兼容的点，否则三角形形成失败。 

另一种情况是当一个点极其孤立时。 例如：```
(0,0), (1,0), (2,0), (1000,1000)
```最好的三元组完全忽略异常值。 该算法处理此问题是因为离群值在较高阈值下几乎没有边缘，从而阻止其参与任何三角形，而密集簇在较低阈值下仍然形成有效三角形。 

最后一个微妙的情况是，多对共享相同的最大距离，但没有第三点支持该比例的三角形。 位集交集通过需要共同的邻居来防止误报，确保成对最优性不会错误地暗示三重可行性。
