 ## 解决方案
 ## 问题理解

 每个建筑物都是一个轴对齐的矩形，位于同一水平基线上。 建筑物由其左坐标（L_i）、右坐标（R_i）和高度（H_i）来描述，因此它占据从（L_i）到（R_i）的区间并上升到高度（H_i）。 

装饰必须覆盖城市的整个可见正面，但建筑物的重叠部分只需覆盖一次。 因此，在水平坐标 (x) 处，所需高度就是最高建筑物覆盖物的高度 (x)。 如果我们将该高度称为 (f(x))，则所需面积是整个城市 (f(x)) 的积分。 

输入最多包含 (10^5) 座建筑物。 坐标可以达到(10^9)，所以我们不能创建一个由每个可能的坐标索引的数组。 更重要的是，(O(N^2)) 算法在最坏的情况下将执行大约 (10^{10}) 次操作，远远超出一秒限制所能支持的范围。 我们需要一个 (O(N\log N)) 或类似的有效解决方案。 

坐标是整数，但建筑物代表连续的矩形。 这会产生几个容易出错的地方。 

首先，重叠的建筑物必须仅贡献其最大高度。 例如，```
2
0 4 3
1 2 5
```面积 (3\cdot1+5\cdot1+3\cdot2=16)。 将两个矩形区域相加得到 (12+5=17)，因为重叠部分将被计算两次。 

其次，接触的建筑物不重叠。 例如，```
2
0 2 4
2 5 6
```面积 (2\cdot4+3\cdot6=26)。 该点 (x=2) 的宽度为零，因此它不贡献面积。 将区间端点视为单位宽度单元格可以引入额外的贡献。 

第三，多个建筑物可以具有相同的最大高度。 例如，```
2
0 3 5
0 3 5
```面积 (3\cdot5=15)。 当一栋建筑物结束时，高度 (5) 必须保持活动状态，因为另一栋建筑物仍在覆盖该间隔。 简单地删除最大值而不跟踪多重性的数据结构会错误地缩小天际线。 

第四，建筑物之间的间隙必须为零面积。 例如，```
2
0 2 3
5 7 4
```面积 (2\cdot3+2\cdot4=14)。 在从 (2) 到 (5) 的空白区间中携带先前最大值的扫描实现将添加不存在的区域。 

## 方法

 直接方法首先观察天际线只能在建筑物端点发生变化。 我们可以收集每个左坐标和右坐标，对它们进行排序，并考虑每个连续的坐标对。 在这样的间隔内，没有建筑物开始或结束，因此活动建筑物的集合是固定的并且所需的高度是恒定的。 我们可以检查每个间隔的每座建筑物，并获取该间隔内建筑物中最大的高度。 

这是正确的，因为整个连续的 x 轴已被划分为天际线不发生变化的区间。 然而，可能有几乎 (2N) 个不同的端点，产生最多 (2N-1) 个基本区间。 检查所有 (N) 栋建筑物中的每一栋需要花费

 [
 (2N-1)N
 ]

 建筑物检查。 对于 (N=10^5)，这是 (19,999,900,000)，大约 (2\cdot10^{10}) 个检查，这太慢了。 

暴力破解之所以有效，是因为连续端点之间的每个间隔都有一个固定的答案。 问题在于它会从头开始重复重新计算最大值。 关键的观察结果是，当我们从一个端点移动到下一个端点时，只有以该坐标开始或结束的建筑物才会更改活动集。 没有理由再次检查所有其他建筑物。 

我们可以从左向右扫。 在清扫时，我们维护所有当前活动的建筑物高度，并需要查询它们的最大值。 当插入建筑物时，最大堆在 (O(\log N)) 中精确地给出了该操作。 

剩下的困难就是删除。 Python 的标准堆不支持有效删除任意元素。 我们可以通过延迟删除来解决这个问题。 对于每个高度，我们存储有多少当前活跃的建筑物具有该高度。 当建筑物结束时，我们会减少其计数，但保留其堆条目。 每当堆的顶部高度计数为零时，我们就会删除该过时的条目。 每个堆条目插入一次，最多删除一次，因此总工作量仍为 (O(N\log N))。 

面积计算特别简单。 假设前一个事件坐标为(x_{\text{prev}})，当前坐标为(x)，当前最大高度为(h)。 整个区间 ([x_{\text{prev}},x)) 中的天际线恰好为 (h)，因此其面积贡献为

 [
 (x-x_{\text{prev}})h。 
]

 添加此贡献后，我们处理所有以 (x) 开始或结束的建筑物，并且生成的活动集确定下一个间隔的高度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(N^2)) | (O(N)) | 太慢了|
 | 最佳扫掠线 | (O(N\log N)) | (O(N)) | 已接受 |

 ## 算法演练

1. 阅读每座建筑并将其变成两个事件。 在 (L_i) 处，高度 (H_i) 变为活动状态。 在 (R_i) 处，高度 (H_i) 停止活动。 右端点被视为终点，因为建筑物占据直到 (R_i) 的连续区间，并且单个端点的面积为零。 
2. 按 x 坐标对所有 (2N) 个事件进行排序。 排序后，扫描会遇到天际线从左到右顺序发生变化的所有可能位置。 
3. 维护一个最大堆，其中包含已开始但尚未结束的建筑物的高度。 由于Python提供了最小堆，将高度存储为负值，因此最小的堆元素代表最大的实际高度。 
4. 维护一个字典，其中包含每个高度的当前活动建筑物的数量。 这为我们提供了多重信息，当两个或多个活动建筑物具有相同高度时，这是必要的。 
5. 在第一个事件的 x 坐标处开始扫描。 在处理第一个事件之前，没有覆盖区域，因此初始累积面积为零。 
6. 在每个不同的事件坐标 (x) 处，首先添加前一个坐标和 (x) 之间的区域。 活动集在此区间内的任何位置都没有改变，因此当前的最大高度在那里是恒定的。 
7. 处理 (x) 处的每个事件。 开始事件会增加其高度的计数并将该高度推入堆中。 结束事件会减少计数。 我们在向右移动之前处理同一坐标处的所有事件，因为它们在某一点的精确排序不会影响区域，而组合结果必须描述紧随该坐标之后的活动集。 
8. 当堆顶的活动计数为零时，删除陈旧的堆条目。 这些条目代表已经结束的建筑物。 延迟删除避免了昂贵的任意堆删除的需要。 
9. 将前一个坐标设置为 (x) 并继续，直到处理完每个事件。 在最后的右端点之后没有活动建筑物，因此没有额外的区域。 

### 为什么它有效

 中心不变量是，在处理坐标 (x) 处的所有事件后，堆立即准确地表示覆盖紧邻 (x) 右侧的每个点的建筑物的高度，其中重数由活动计数字典考虑。 

在两个连续的事件坐标之间，没有建筑物开始或结束。 因此，活动集是不变的，因此最高的活动建筑决定了整个区间的天际线高度。 将高度乘以间隔宽度即可精确计算出天际线该部分的面积。 由于 x 轴的每一部分都恰好被一个这样的间隔覆盖，因此所有贡献的总和正是覆盖城市前视图所需的最小面积。 

## Python 解决方案```python
import sys
import heapq

input = sys.stdin.readline

def solve():
    n = int(input())

    events = []

    for _ in range(n):
        l, r, h = map(int, input().split())
        events.append((l, 1, h))
        events.append((r, -1, h))

    events.sort()

    heap = []
    count = {}

    area = 0
    prev_x = events[0][0]
    i = 0
    m = len(events)

    while i < m:
        x = events[i][0]

        if heap:
            area += (x - prev_x) * (-heap[0])

        while i < m and events[i][0] == x:
            _, delta, h = events[i]

            if delta == 1:
                count[h] = count.get(h, 0) + 1
                heapq.heappush(heap, -h)
            else:
                count[h] -= 1

            i += 1

        while heap and count.get(-heap[0], 0) == 0:
            heapq.heappop(heap)

        prev_x = x

    print(area)

if __name__ == "__main__":
    solve()
```事件构造是将每个矩形直接转换为活动天际线的两个变化。 左端点添加高度，而右端点删除高度。 

排序步骤的成本为 (O(N\log N))，因为正好有 (2N) 个事件。 排序后，扫描会处理每个事件一次。 堆插入成本 (O(\log N))，尽管过时的条目可以暂时保留，但每个条目只能从堆中删除一次。 因此，所有堆操作总共需要 (O(N\log N))。 

表达式`-heap[0]`给出当前最高的活动建筑物，因为堆存储负高度。 在处理当前坐标处的事件之前计算面积。 这种排序是经过深思熟虑的：间隔`prev_x`到`x`使用到达之前存在的活动集`x`。 活动于`x`只影响其右边的区间。 

将所有事件分组到同一坐标也使得边界行为变得明确。 假设一栋建筑以相同的 x 坐标结束，另一栋建筑以相同的 x 坐标开始。 这两个事件之间不存在任何区域，因此它们可以一起处理，之后只有它们组合的活动集才重要。 

需要字典是因为堆值不是唯一标识符。 如果三座活动建筑物的高度为 (7)，则移除其中一栋不得使高度 (7) 从最大值消失。 该计数准确记录了仍有多少副本处于活动状态。 

Python 整数具有任意精度，因此可以在不溢出的情况下处理最大可能区域，大致为 (10^9\cdot10^6=10^{15})。

 ## 边缘情况

 第一个边缘情况是不同高度的建筑物重叠。```
2
0 4 3
1 2 5
```在 (x=0) 处，高度 (3) 变为活动状态。 从 (0) 到 (1)，天际线为 (3)，贡献 (3)。 在 (x=1) 处，高度 (5) 开始，因此从 (1) 到 (2) 的天际线为 (5)，贡献 (5)。 在 (x=2) 处，高度 (5) 结束，将天际线返回到 (3)，从而从 (2) 到 (4) 贡献 (6)。 总数为（3+5+6=14）。 

此计算揭示了粗心的矩形联合计算可能会错过的修正。 正确的总数实际上是 (14)，而不是 (16)，因为第一个间隔的宽度为 (1)，重叠的宽度为 (1)，最后一个间隔的宽度为 (2)。 扫描正好计算这三个部分。 因此，问题讨论中前面的示例可以用作警告：添加矩形区域是错误的，并且必须始终执行精确的天际线计算。 

第二个边缘情况是两座建筑物在一个端点相接触。```
2
0 2 4
2 5 6
```第一个建筑物贡献 (2\cdot4=8)，第二个建筑物贡献 (3\cdot6=18)。 在 (x=2) 处，移除第一座建筑物并添加第二座建筑物。 由于单个点的宽度为零，因此不会添加任何额外的内容。 答案是（26）。 

第三种边缘情况是重复的最大高度。```
2
0 3 5
0 3 5
```两座建筑物均从 (x=0) 开始，因此高度 (5) 的活动计数变为 (2)。 两座建筑物都以 (x=3) 结束，将计数减少到零。 在整个区间内，堆最大值为 (5)，给出面积 (3\cdot5=15)。 该计数可防止第一次删除在第二个建筑物仍处于活动状态时错误地删除高度。 

第四种边缘情况是间隙。```
2
0 2 3
5 7 4
```从 (0) 到 (2)，活动最大值为 (3)，贡献 (6)。 从（2）到（5），堆变空，因此贡献为零。 从(5)到(7)，最大值为(4)，贡献为(8)。 最终答案为(14)。 空堆正是实现中表示未覆盖区域的方式，因此没有任何区域会意外地穿过间隙。 

坐标为 (0) 和 (10^9) 的边界情况的处理无需任何特殊逻辑。 例如，```
1
0 1000000000 1000000
```面积 (10^9\cdot10^6=10^{15})。 无论坐标范围有多大，该算法都只执行两个事件，并且 Python 的整数算术直接处理结果值。
