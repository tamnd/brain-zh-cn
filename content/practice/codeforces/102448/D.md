 ## 解决方案
 ## 问题理解

 我们有一个放置魔环的固定点 ((x,y))。 每个普通环都有一个中心 ((X_i,Y_i)) 和半径 (R_i)。 魔法环以一定的半径（r）开始，每当它吸收一个普通环时，它的半径就会以该环的半径增加。 

假设魔法环当前的半径为（C）。 普通环 (i) 可以在两个圆相交或接触时恰好被吸收，相当于

 [
 \sqrt{(X_i-x)^2+(Y_i-y)^2}\le C+R_i。 
]

 吸收后，当前半径变为(C+R_i)。 任务是选择尽可能小的初始值（r），使每个环都以某种顺序被吸收。 

关键的困难在于吸收环会改变半径，因此不能简单地单独处理环。 最初无法到达的环在吸收几个较容易的环后可能会变得可以到达。 

环的数量最多为 (10^5) 个，而坐标的大小可以接近 (10^9)。 这排除了 (N) 中的任何二次方，因为 (10^{10}) 运算远远超出了两秒的限制。 我们需要一个 (O(N\log N)) 解决方案，或者相当有效的解决方案。 坐标范围也均方距离大约可以达到(8\cdot10^{18})，因此距离计算需要足够的整数精度才能取平方根。 

有几种边缘情况，粗心的实现可能会处理不当。 首先，所需的初始半径实际上可以为零。 例如，```
1 0 0
0 0 2
```有答案`0.0000000000`。 即使半径为零，魔法环也已经与普通环相交了，因为它们的中心之间的距离为零。 将答案初始化为第一个所需半径但不允许为零的实现可能会错误地打印正值。 

相切是另一种边界情况。 考虑```
1 0 0
3 0 2
```中心之间的距离恰好为 (3)，半径之和为 (3)，因此允许环接触和吸收。 答案是```
1.0000000000
```使用严格的`<`而不是`<=`会拒绝这种有效的吸收。 

吸收的顺序也很重要。 考虑```
2 0 0
100 0 99
3 0 1
```对于第一环，所需的电流半径为（100-99=1）。 对于第二个，它是（3-1=2）。 第一个环应首先被吸收。 从半径（1）开始，魔法环吸收半径（99）环并增长到半径（100），之后第二环就容易了。 正确答案是`1.0000000000`。 相反，按中心距离排序会首先处理距离 (3) 环，并错误地得出需要半径 (2) 的结论。 

## 方法

 直接的暴力方法是考虑每一个可能的吸收顺序。 对于固定阶数，所需的最小初始半径很容易计算。 在吸收环 (i) 之前，我们知道所有先前吸收环的半径之和，因此我们可以准确确定初始半径必须有多大才能实现该步骤。 取整个订单的最大值即可得出该订单所需的起始半径。 

问题是订单数量。 有 (N!) 种排列，评估一种排列需要 (O(N)) 时间，需要 (O(N\cdot N!)) 工作。 即使 (N=20) 也已经需要大约 (20\cdot20!)，大约 (4.9\cdot10^{19}) 环检查。 对于 (N=10^5)，穷举排序是完全不可能的。 

如果我们重写吸收条件，结构就会变得简单得多。 让

 [
 d_i=\sqrt{(X_i-x)^2+(Y_i-y)^2}
 ]

 是从魔法环中心到环 (i) 中心的距离。 环 (i) 是可吸收的，当

 [
 d_i\le C+R_i,
 ]

 或同等地，

 [
 d_i-R_i\le C.
 ]

 定义

 [
 A_i=d_i-R_i。 
]

 现在，每个环只是一个对象，一旦当前魔法半径达到其阈值（A_i），该对象就变得可用。 吸收它会将 (R_i) 添加到当前半径。 

所有奖励 (R_i) 都是正的。 这完全改变了排序问题。 如果两个环都有阈值（A_i\le A_j），且阈值（A_j）的环当前可用，则阈值（A_i）的环也可用。 首先吸收较小阈值的环不会造成伤害，因为它只会在考虑其他环之前增加当前半径。 

这意味着我们可以按 (A_i) 对所有环进行排序。 一旦排序，就无需模拟复杂的选择。 在这个顺序中的第（i）个环之前，当前半径已经获得了之前所有环的半径。 如果它们的总半径是（S），那么我们需要

 [
 r+S\ge A_i,
 ]

 所以

 [
 r\ge A_i-S。 
]

 因此，最小初始半径是这些要求的最大值，并且为零，因为半径不能为负。 

暴力破解之所以有效，是因为完整的订单可以让我们测试每一个可能的序列。 它失败了，因为存在多个阶乘序列。 观察到环可以按照它们在可达之前所需的半径大小进行排序，从而将整个问题简化为排序和一个前缀和。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | (O(N\cdot N!)) | (O(N)) | 太慢了 |
 | 最佳 | (O(N\log N)) | (O(N)) | 已接受 |

 ## 算法演练

 1. 对于每个普通环，计算其到固定魔环中心的距离：

 [
 d_i=\sqrt{(X_i-x)^2+(Y_i-y)^2}。 
]

 然后计算其所需的当前半径

 [
 A_i=d_i-R_i。 
]

 该值是允许环 (i) 立即被吸收的最小魔环半径。 

1. 将每个环存储为对 ((A_i,R_i))，然后按 (A_i) 对所有对进行排序。 

排序顺序是有效的，因为具有较小阈值的环永远不会比具有较大阈值的环更难吸收。 如果有一个较大阈值的环可用，那么每个较小阈值的环也都可用，吸收较小的环只会增加半径。 

1. 设置`added = 0`，表示从已吸收的环获得的总半径，并设置`answer = 0`。 

在处理环之前，魔环当前的半径为`answer + added`只是概念上的。 更直接地说，`answer`代表我们试图使其足够的初始半径，而`added`表示先前吸收后获得的半径。 

1. 对于每个排序对 ((A_i,R_i))，计算

 [
 A_i-添加。 
]

 初始半径必须至少为该值，因为之前的环已经将魔法环的半径增加了`added`。 使用当前值和此要求中的最大值更新答案。 

1. 将 (R_i) 添加到`added`并继续。 

每个环只有在成功到达后才会贡献其半径，这正是真正的吸收过程的行为方式。 

1. 以足够的小数精度打印所得的最大值。 

距离计算在取平方根之前使用整数差，因此平方距离本身在 Python 中是精确计算的。 

### 为什么它有效

 不变的是，在按排序阈值顺序处理前 (i) 个环之后，`added`正是它们的半径之和，并且`answer`是使每个处理的吸收成为可能的最小初始半径。 

对于下一个环，其阈值是(A_i)。 之前的戒指已经将魔法半径增加了`added`，所以下一次吸收恰好在

 [
 回答+添加\ge A_i。 
]

 因此，该算法必须强制执行（答案\ge A_i-补充）。 取所有已处理环的最大值满足每个这样的条件。 

剩下的问题是为什么排序阈值顺序就足够了。 假设某个可行的吸收阶包含两个具有阈值的连续环（A_j>A_i），其中（j）在（i）之前被吸收。 由于 (j) 可达，因此当前半径至少为 (A_j)，因此也至少为 (A_i)。 我们可以交换它们，首先吸收（i），获得其正半径，并且仍然有足够的半径来吸收（j）。 重复删除此类反转可将任何可行的阶数转换为非递减阈值阶数，而不增加所需的初始半径。 因此，排序顺序包含最优解。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n, x, y = map(int, input().split())

    rings = []

    for _ in range(n):
        X, Y, R = map(int, input().split())

        dx = X - x
        dy = Y - y

        distance = math.hypot(dx, dy)
        need = distance - R

        rings.append((need, R))

    rings.sort()

    answer = 0.0
    added = 0

    for need, radius in rings:
        answer = max(answer, need - added)
        added += radius

    print(f"{answer:.10f}")

if __name__ == "__main__":
    solve()
```输入循环首先将每个圆转换为对贪婪算法重要的对。 计算距离后不再需要原来的中心坐标。`math.hypot(dx, dy)`计算 (\sqrt{dx^2+dy^2})。 坐标差是整数，Python整数具有任意精度，因此内部形成平方距离时不会出现整数溢出。 

减法`distance - R`是在排序之前故意完成的。 排序依据`distance`单独使用是不正确的，因为当半径较大时，大环比较小环更容易吸收。 相关数量始终`distance - radius`。 

循环保持`added`作为整数。 这很有用，因为最多 (10^5) 个半径的总和最多为 (10^{10})，这在 Python 中是精确的。 只有几何阈值包含平方根并且需要浮点运算。 

更新发生在添加当前环的半径之前。 这种顺序与物理过程相匹配：当前环在被吸收之前无法贡献其半径。 首先添加会引入一步错误，并且可能使最初无法到达的环看起来可以到达。 

数学条件下的比较是非严格的。 相切环可以被吸收，因此当当前半径恰好等于`need`。 该公式自然地处理相等而不需要特殊情况。 

最后，`answer`从零开始，因为所需的半径可能为非正数。 如果每个环在考虑其自身半径后已经与零半径魔法环相交，则不需要正的起始半径。 

## 工作示例

 对于样本 1，魔法中心是 ((1,1))。 两个普通环位于半径为 (3) 的 ((1,7)) 和半径为 (3) 的 ((5,1)) 处。 

他们的距离和阈值是：

 | 戒指| 距离 | 半径| (A_i=d_i-R_i) |`added`之前| 所需的初始半径|
 | ---| ---| ---| ---| ---| ---|
 | ((5,1)) | ((5,1)) | 4 | 3 | 1 | 0 | 1 |
 | ((1,7)) | ((1,7)) | 6 | 3 | 3 | 3 | 0 |

 排序顺序从第二个输入环开始，因为它的阈值仅为 (1)。 从半径（1）开始，魔环可以吸收它并增长到半径（4）。 另一个环只需要半径 (3)，因此它会立即被吸收。 

所需的最大初始半径为 (1)，产生样本输出。 

对于示例 2，四个阈值大约为：

 | 戒指| 距离 | 半径| (A_i=d_i-R_i) |`added`之前| 所需的初始半径|
 | ---| ---| ---| ---| ---| ---|
 | 3 | 160.015625 | 41 | 41 119.015625 | 0 | 119.015625 |
 | 4 | 245.943083 | 78 | 78 167.943083 | 41 | 41 126.943083 |
 | 1 | 836.244584 | 6 | 830.244584 | 119 | 119 711.244584 |
 | 2 | 1025.353110 | 30| 995.353110 | 125 | 125 870.353110 |

 第三个输入环最容易到达，因此它首先被吸收并增加魔法半径（41）。 然后，第四个环变得可达，并添加另一个环 (78)。 经过这两次吸收，魔环​​已经获得了（119）的半径。 

考虑到这些 (119) 个单位后，第一环仅需要约 (711.245) 的初始贡献。 最后一环才是真正的瓶颈。 当考虑时，已经获得了(125)半径，但其阈值约为(995.353110)，因此初始半径必须至少为

 [
 995.353110-125=870.353110。 
]

 这给出了样本输出`870.3531099090`。

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | (O(N\log N)) | 计算所有距离需要 (O(N))，排序 (N) 个阈值需要 (O(N\log N))。 |
 | 空间| (O(N)) | 每个环的阈值和半径对在排序之前被存储。 |

 使用 (N\le10^5)，在两秒限制内对 (10^5) 个元素进行排序很容易实现。 该算法在排序后仅执行一次线性传递，其内存使用量与环数成正比，在 256 MB 以内。

 ## 边缘情况

 处理零半径情况是因为答案从`0.0`并且每个要求都是相对于该值来考虑的。 为了```
1 0 0
0 0 2
```距离为(0)，因此阈值为(0-2=-2)。 因此，所需的初始半径为 (-2)，但物理半径不能为负，因此为零的最大值仍为 (0)。 戒指可以立即被吸收，算法打印`0.0000000000`。 

相切情况直接使用相等。 为了```
1 0 0
3 0 2
```阈值是（3-2=1）。 初始半径正好为 (1)，两个圆的中心距为 (3)，组合半径为 (1+2=3)，因此它们相接触。 条件完全满足，答案为`1.0000000000`。 不需要 epsilon 调整或严格比较。 

排序边缘情况说明了为什么阈值包括环自身的半径。 为了```
2 0 0
100 0 99
3 0 1
```阈值分别为 (1) 和 (2)。 排序顺序首先采用半径 (99) 环。 从半径（1）开始，魔环精确地到达它，吸收它，并增长到半径（100）。 然后第二个环就可以轻松到达。 算法记录了要求（1）和（2-99=-97），所以最终答案仍然是（1）。 按中心距离排序会颠倒顺序并产生错误的答案。 

大坐标不会导致 Python 中的整数溢出。 例如，边界情况使用 ((-10^9,10^9)) 附近的中心和 ((10^9,-10^9)) 附近的环。 坐标差接近 (2\cdot10^9)，因此平方距离约为 (8\cdot10^{18})。 Python 恰好在之前计算该整数`math.hypot`将几何图形转换为浮点数。 产生的浮点误差远低于最终答案所需的 (10^{-6}) 容差。 

最后，许多环可以具有完全相同的阈值。 排序使它们保持相邻，并且它们的相对顺序并不重要，因为所有的都已经在相同的当前半径下变得可达。 由于每个半径都是正数，吸收其中任何一个只能使其余环更容易到达。 (10^5) 个相同环的最大尺寸测试验证了这种情况，同时还确认 (O(N\log N)) 实现可扩展到输入限制。
