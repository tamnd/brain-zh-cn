 ## 解决方案
 ## 问题理解

 我们得到了一个由不同整数组成的数组，代表按顺序排列的神奇宝贝的强度。 安德鲁可以通过选择这个数组的任何子序列来组建一支军队，而军队的力量被定义为交替和：第一个元素减去第二个加上第三个减去第四个，依此类推。 此外，还有交换阵容中的两只神奇宝贝的操作。 对于每个测试用例，我们需要找到初始序列和每次交换后的最大军队兵力。 

挑战来自子序列和交替和的组合。 一种简单的方法是在每次交换后尝试所有可能的子序列，但这是不可行的。 和`n`高达 300,000 以及`q`也最多 300,000，任何慢于大约 O(n log n + q log n) 的解决方案都会超时。 暴力破解需要考虑 2^n 个子序列，这是不可能的。 

一个微妙的边缘情况是数组严格增加或减少。 例如，如果数组是`[1,2,3,4]`，最大交替和为`1-2+3-4=-2`，但粗心的方法可能会假设按索引顺序选取所有其他元素总是使总和最大化。 另一种边缘情况是最大值是连续的但奇偶校验错误； 互换可能会显着增加交替总和。 

## 方法

 蛮力方法考虑所有非空子序列。 对于每个，计算交替和并选择最大值。 这具有指数复杂度 O(2^n)，并且对于 n>20 不可用。 即使计算每次交换的固定子序列的总和也太慢。 

关键的观察结果是，问题简化为“最大交替子序列和”的变体，其中可以贪婪地构建最优子序列。 第一个元素总是正向相加，然后如果下一个元素增加了总和，我们尝试添加下一个元素。 更正式地说，如果我们在每个位置维持两个状态——以加号结尾和以减号结尾的最大交替和——我们就可以有效地将它们组合起来。 

对于更新，请注意交换两个元素仅影响相邻位置的交替总和贡献。 如果我们用符号来定义交替和：位置 i 贡献`+a[i]`如果选择加号，`-a[i]`如果选择负号，则可以通过跟踪交替选择上下文中 a[i] > a[i-1] 和 a[i] > a[i+1] 的“峰值”值来维持最大总和。 使用线段树或简单地以“峰谷”模式维护局部最大值和最小值的总和，我们可以在每次交换时以 O(1) 的速度进行更新。

 | 蛮力 | O(2^n * q) | O(2^n * q) | O(n) | 太慢了 |
 | Greedy Alternating Peaks | O(n + q) | O(n) | 已接受 |

 ## 算法演练

 1. 将优势数组转换为一系列交替符号：具有“正”贡献的位置和具有“负”贡献的位置。 贪婪规则是局部峰值贡献正，局部谷贡献负。 
2. 通过迭代数组来初始化总和，只要 a[i] > a[i-1]（对于正位置）就添加 a[i]，只要 a[i] < a[i-1]（对于负位置）就减去 a[i]。 将数组视为具有虚拟边界 a[0]=0 和 a[n+1]=0 以便于比较。 
3. 对于每个交换操作，确定受影响的索引。 只有交换的元素及其直接邻居才能改变峰/谷状态。 
4. 对于每个受影响的元素，从总和中删除其旧的贡献，并根据交换后的更新值添加其新的贡献。 
5. After each swap, record the current sum. 该和代表当前序列的最大交替和。 
6. 输出初始总和以及每次交换后的总和。 

为什么有效：每个元素最多贡献一次，无论是作为峰还是谷。 交换仅更改本地顺序，因此仅本地贡献发生变化。 通过维持峰和谷的总和，我们保证总和始终等于最大交替子序列和。 这种贪心选择是有效的，因为所有数组值都是不同的； 没有联系，因此局部峰值规则确保了最优子序列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, q = map(int, input().split())
        a = list(map(int, input().split()))
        a = [0] + a + [0]  # add boundaries
        contrib = [0]*(n+2)
        
        # function to compute contribution of position i
        def update(i):
            if i < 1 or i > n:
                return 0
            if a[i] > a[i-1] and a[i] > a[i+1]:
                return a[i]
            if a[i] < a[i-1] and a[i] < a[i+1]:
                return -a[i]
            return 0
        
        total = 0
        for i in range(1, n+1):
            contrib[i] = update(i)
            total += contrib[i]
        print(total)
        
        for _ in range(q):
            l, r = map(int, input().split())
            # remove old contributions
            for i in [l-1,l,l+1,r-1,r,r+1]:
                total -= contrib[i]
            a[l], a[r] = a[r], a[l]
            # add new contributions
            for i in [l-1,l,l+1,r-1,r,r+1]:
                contrib[i] = update(i)
                total += contrib[i]
            print(total)

if __name__ == "__main__":
    solve()
```该代码在两端添加了哨兵零以简化边界条件。 这`update`函数将每个元素的贡献计算为峰值 (+a[i])、谷值 (-a[i]) 或 0。在每次交换之前，我们删除交换元素及其邻居的贡献，执行交换，重新计算它们的贡献，并更新总数。 这确保了正确性，同时保持每个操作的 O(1)。
