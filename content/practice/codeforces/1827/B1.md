 ## 解决方案
 ## 问题理解

 我们被要求计算给定不同整数数组的所有子数组的“美观”度量。 子数组的优点在于使用范围排序操作对其进行排序所需的总时间最少。 每个范围排序都是通过选择子数组的一个子段并在等于其长度减一的时间对其进行排序来定义的。 由于数组元素是不同的，因此任何长度为 1 的子数组都已经以美感零排序。 长度为 2 或以上的子数组可能需要一次或多次操作，但最小总时间始终等于相邻元素之间的反转次数：如果子数组已经排序，则美观为零； 如果没有，我们总是可以在覆盖未排序部分的单个操作中对其进行排序，时间等于长度减一。 

这些约束为我们在所有测试用例中提供了最多 5000 个元素，这排除了对每个子数组的所有操作的简单枚举。 直接枚举所有子数组并模拟排序会太慢，因为子数组的数量是 O(n²)。 需要仔细观察问题的结构以减少计算量。 

严格递减的子数组会出现微妙的边缘情况。 例如，`[3,2,1]`有美丽`2`因为对整个子数组进行排序需要`r - l = 3 - 1 = 2`。 任何假设每次反转一次操作的简单方法都会过度计数。 同样，长度为一的子数组或已排序的子数组必须产生零美感，否则总和将会膨胀。 

## 方法

 暴力方法枚举所有子数组，并且对于每个子数组，显式模拟范围排序操作的最小数量。 对于长度为 k 的子数组，您可以想象尝试所有对`(l,r)`确定如何在最短的总时间内排序。 即使没有递归，直接计算美度也需要检查反转并可能对每个子数组执行 O(k) 操作。 对 O(n²) 个子数组进行求和会导致大约 O(n³) 次运算，这对于 n 高达 5000 的情况是不可行的。 

关键的见解是要注意子数组的最小美感完全由其最小和最大元素的位置决定。 如果我们从左到右处理数组，我们可以在扩展子数组时跟踪当前的最小值和最大值。 子数组的美度等于最小值和最大值之间的元素个数减一，即`max - min`。 这是因为覆盖整个未排序段的单个操作总是能实现最小的总时间。 因此，我们不需要模拟范围排序，只需要计算`max - min`对于每个子数组。 

这导致了 O(n²) 解决方案。 我们迭代所有起始位置，然后一次扩展子数组一个元素，保持当前的最小值和最大值。 每一步都会更新当前子数组的美度并将其累加到总和中。 不需要复杂的数据结构，操作次数也可以接受，因为n² = 25×10^6，在1秒之内。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(n) | 太慢了 |
 | 最小-最大跟踪 | O(n²) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取长度`n`数组和数组元素`a`。 
2. 初始化变量`total_beauty`为零。 这将累加所有子数组的总和。 
3. 迭代所有可能的起始索引`i`从 0 到 n-1。 这标记了子数组的左端点。 
4. 初始化`current_min`和`current_max`到`a[i]`。 它们代表当前子数组的最小值和最大值。 
5. 通过迭代右端点来扩展子数组`j`从`i`至n-1。 在每次迭代中更新`current_min = min(current_min, a[j])`和`current_max = max(current_max, a[j])`。 
6. 如果`j > i`，子数组之美`a[i..j]`是`(current_max - current_min)`。 将此值添加到`total_beauty`。 
7. 处理完所有从`i`，继续下一个起始索引。 
8. 打印`total_beauty`对于当前的测试用例。 

这样做的原因是，范围排序操作的最小数量始终是通过覆盖从最小到最大元素的未排序范围的单个排序来实现的。 由于元素是不同的，因此每个扩展要么扩大未排序的范围，要么保持其不变。 通过保持运行最小值和最大值，我们正确地捕获了未排序元素的跨度，从而获得了最小的美感。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    total_beauty = 0
    for i in range(n):
        current_min = a[i]
        current_max = a[i]
        for j in range(i, n):
            current_min = min(current_min, a[j])
            current_max = max(current_max, a[j])
            if j > i:
                total_beauty += current_max - current_min
    print(total_beauty)
```外层循环选择起始索引，而内层循环将子数组向右扩展。 这`current_min`和`current_max`跟踪必要的端点来确定美感，而无需执行任何显式排序。 只有当子数组长度至少为 2 时，我们才会积累美丽，这与美丽的定义一致。 该算法通过调节来避免相差一错误`j > i`。
