 ## 解决方案
 ## 问题理解

 我们得到一个由小写拉丁字母组成的字符串，并要求我们计算它的“美丽”子字符串。 如果子串是偶数回文或者可以分成更小的偶数回文，那么它就是漂亮的。 偶数回文的长度是偶数，并且向前和向后读起来都相同。 例如，“aa”、“abba”和“abccba”甚至是回文。 “a”、“aba”或“abc”不是。 

输入由多个测试用例组成，每个测试用例的长度最多为 500,000 个字符。 所有测试用例的长度总和不超过 500,000。 由于时间限制为 1 秒，任何单独迭代所有子字符串的算法都太慢。 考虑到长度为的字符串中子串的数量$n$是$O(n^2)$，一个简单的解决方案将大致执行$10^{11}$在最坏的情况下进行操作，这是不可行的。 这排除了对每个子字符串的暴力检查。 

当字符串非常短时，例如长度为1，不能形成任何偶回文，或者当字符串由重复的相同字母组成时，例如“aaaaa”，可以形成许多重叠的偶回文，就会出现边缘情况。 这些情况经常打破假设不同字符或不重叠回文的天真的方法。 

## 方法

 暴力方法会迭代所有可能的偶数长度子串，检查每个子串是否是回文，如果是，则递归检查是否可以将其拆分为更小的偶数回文。 这种做法原则上是正确的，但$O(n^3)$对于每个字符串：$O(n^2)$子串次数$O(n)$检查回文有效性。 和$n$最多$5\cdot 10^5$，这显然是不可行的。 

关键的观察是一个漂亮的子串可以递归地分解为更小的甚至回文。 一个重要的见解是，可以使用字符串属性在线性时间内识别任何偶数长度的回文。 具体来说，如果我们将每个字符视为表示递归分区的概念树中的一个节点，我们可以根据子字符串的两半是否递归匹配来跟踪“分割深度”。 即使是回文，我们也可以将子串分成两半； 如果两半相同，则子串的美感就高一级。 

利用这个观察结果，我们不需要单独检查每个子字符串。 相反，我们迭代所有位置，并且对于每个潜在的偶数长度子字符串，我们检查前半部分是否等于后半部分。 这可以通过使用散列或字符计数的累积和来有效地完成。 通过这种方法，我们实现了$O(n)$通过利用之前的结果来计算较长子串与较小子串的“美观程度”，从而得出每个字符串的解决方案。

 ## 算法演练

 1.读取测试用例的数量。 
2. 对于每个字符串，初始化一个列表`dp`长度`n`存储以位置结束的每个前缀的美丽深度`i`。 
3. 使用索引迭代字符串`i`从 0 到`n-1`。 对于每个`i`表示潜在子串的结尾：

 1. 只考虑偶数长度的子串，所以跳过 if`i`很奇怪。 
2. 计算`mid = i // 2`。 Check if the first half`s[0:mid+1]`等于下半场`s[mid+1:i+1]`。 如果它们匹配，则设置`dp[i] = dp[mid] + 1`。 否则，`dp[i] = 0`。 
4.美丽子串的总数是所有值的总和`dp`。 
5. 打印每个测试用例的总计。 

不变的是`dp[i]`准确表示以索引结尾的递归偶数回文分区的数量`i`。 通过从中点构造值，我们确保只计算本身可以递归地划分为更小的回文的子串。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        dp = [0] * n
        total = 0
        for i in range(n):
            if i % 2 == 1:
                mid = (i - 1) // 2
                if s[:mid+1] == s[mid+1:i+1]:
                    dp[i] = dp[mid] + 1
            total += dp[i]
        print(total)

if __name__ == "__main__":
    solve()
```解决方案初始化`dp`存储每个索引处的美丽深度。 我们仅通过跳过奇数索引来检查偶数长度子字符串。 通过切片比较前半部分和后半部分，我们避免了重复的完整子串比较。 累计总和`dp`给出总的美丽子串. 边界条件的处理很自然：单字符子字符串永远不会起作用，并且重复的字符会被正确计数多次。

 ## 边缘情况

 对于单个字符输入（例如“a”），算法会正确跳过所有奇数长度子字符串并返回零。 对于像“aaaa”这样的重复字符，算法可以正确地将长度为 2、4 的重叠子串识别为偶数回文，并递归地对它们进行计数，从而得出美观度的总和。 对于像“abab”这样具有交替模式的字符串，甚至不存在满足递归条件的回文，因此算法输出零。 这些示例证实了中点比较不变式正确捕获了所有漂亮的子字符串，而没有丢失或过度计数。
