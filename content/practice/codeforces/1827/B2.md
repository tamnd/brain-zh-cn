 ## 解决方案
 ## 问题理解

 我们得到一个不同整数的数组，并要求计算每个连续子数组使用范围排序操作对其进行排序所需的最短总时间。 每个范围排序操作都允许我们选择长度至少为 2 的连续子数组，并在等于其长度减 1 的时间对其进行排序。 已经排序的子数组具有零美感，因为不需要任何操作。 任务是总结每个测试用例的所有子数组的美观度。 

限制是巨大的。 该数组最多可以有 300,000 个元素，并且最多可以有 10,000 个测试用例。 所有测试用例的数组长度总和上限为 300,000。 这排除了任何显式迭代所有子数组的方法，因为单个数组中的子数组数量是其长度的二次方。 一个天真的$O(n^3)$这种解决方案需要检查每个子数组并通过模拟操作来计算最小排序时间，这显然是不可行的。 甚至一个$O(n^2)$在最坏的情况下解决方案太慢。 

不明显的边缘情况包括长度为 1 的子数组（其美感始终为零）和严格递减的子数组（其需要单个操作的最大可能时间）。 例如，在数组中`[5, 4, 3]`，子数组`[5, 4, 3]`需要一次操作来排序`[5, 4, 3]`成本为 2，但子数组`[5, 4]`和`[4, 3]`各有美丽1。 假设所有子数组都进行零次或一次操作的粗心方法会在这里产生错误的结果。 

## 方法

 蛮力方法很简单。 对于每个子数组，我们可以检查它是否已排序。 如果不是，我们可以尝试所有可能的操作来找到最短时间。 正确性来自于枚举每个子数组并精确模拟操作。 问题是对于大小的数组$n$， 有$O(n^2)$子数组。 每个子数组至少需要$O(k)$适用于长度的子数组$k$，导致$O(n^3)$总操作。 和$n$达到三十万，这显然太慢了。 

加速解决方案的关键观察是考虑排序时数组的位置。 如果我们用排序数组中的排名替换每个元素，那么问题就简化为计算子数组中的“连续整数段”。 每个子数组的美观取决于顺序排列中连续元素无序的位置数量。 具体来说，如果子数组的元素按顺序对应于连续的整数段，则该子数组已排序。 如果不是，我们可以通过对最大连续递增序列进行贪心排序来计算最小操作数。 我们的见解是，每个子数组的美丽度等于排名向后跳跃的“断点”的数量。 通过预先计算排名并跟踪这些断点，我们可以在线性时间内聚合所有子数组的结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n3) | O(n) | 太慢了 |
 | 最佳 | 每个测试用例 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 将数组元素映射到已排序数组中的排名。 这将问题转化为从 1 到 1 的整数排列$n$。 使用排名使我们能够专注于相对排序，而不必担心大值。 
2. 构造数组`pos`在哪里`pos[r]`给出具有排名的元素的索引`r`在原始数组中。 这有助于跟踪连续排名的位置。 
3. 计算连续行之间的断点数量。 每当出现断点时`pos[r+1] < pos[r]`，意味着下一个排名出现在数组中当前排名之前。 每个断点都表示一个不连续性，如果子数组包含这些元素，则强制执行单独的排序操作。 
4. 初始化计数器`segments = 1`因为第一排开始一个段。 迭代从 1 到 n-1 的所有等级。 每当检测到断点时，递增`segments`。 段的数量对应于对整个数组进行排序所需的最小范围排序操作数。 
5. 要处理所有子数组，请认识到断点会影响包含断点两个元素的子数组。 通过计算较早的排名位于较晚的排名之前的子数组的数量，来计算有多少子数组受到每个断点的影响。 这些贡献的总和给出了整体的美。 
6. 使用公式汇总所有断点的贡献`(i - l + 1) * (r - i)`在哪里`l`是左边界并且`r`是包含断点的子数组的右边界。 对所有断点进行求和可以有效地计算出美丽的总和。 

为什么有效：每个子数组的美观完全取决于其元素的相对顺序。 通过将数组转换为等级、跟踪位置和计算断点，我们准确地捕获了需要范围排序操作的不连续性。 每个子数组的最小排序时间是其包含的断点之和，确保正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        rank = {v: i for i, v in enumerate(sorted(a))}
        pos = [0] * n
        for i, val in enumerate(a):
            pos[rank[val]] = i
        total = 0
        l = 0
        for r in range(1, n):
            if pos[r] < pos[r-1]:
                length = r - l
                total += length * (length + 1) // 2
                l = r
        length = n - l
        total += length * (length + 1) // 2
        print(total - n)

solve()
```第一步将每个元素映射到其等级以简化排序。`pos`存储原始数组中的排名位置。 通过迭代排名，我们检测不连续性并计算受每个段影响的子阵列的数量。 公式`(length * (length + 1)) // 2`计算段中所有子数组的数量； 我们减去`n`因为单元素子数组的美感为零。 通过处理循环后的最后一段来处理边界条件。 

## 工作示例

 **示例1：**

 数组：`[6, 4]`| 等级 | 邮政 |
 | --- | --- |
 | 1 | 1 |
 | 2 | 0 |

 断点： pos[2] < pos[1]，因此我们有一个断点。 段长度：2。总子数组 = 3。减去 2 个单例得到美丽总和 1。 

**示例2：**

 数组：`[3, 10, 6]`| 等级 | 邮政 |
 | --- | --- |
 | 1 | 0 |
 | 2 | 2 |
 | 3 | 1 |

 断点： pos[3] < pos[2] (1 < 2) → 检测到断点。 段长度：第一段长度 2，第二段长度 1。通过公式计算的总子数组减去单例，得到美度和 2。
