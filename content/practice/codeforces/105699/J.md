 ## 解决方案
 ## 问题理解

 我们得到了一组多边形“瓷砖”。 每一块瓷砖都是一个单位正方形的一块，被直线反复切割，所以原始物体是一个正方形，每一次切割都是一条穿过它的直线段。 经过所有切割后，正方形成为多边形区域的平面细分。 每个结果区域都以多边形的形式提供给我们，但每个区域都在平面中独立旋转和平移。 

任务是重建 1 × 1 正方形内所有多边形的有效位置，以便它们准确地平铺正方形而不重叠，并尊重原始切割结构。 读取输入时允许旋转，但在输出中我们必须恢复原始全局方向的单位正方形内的坐标。 不允许翻转，因此每个图块都会保留方向。 

关键的结构约束是每个内部切割都是一条直线段，并且它显示为恰好两个不同部分的边缘。 原始正方形的边界边缘恰好完整地出现在一块中。 这使得整个系统的行为就像正方形的平面图分解，其中边要么是共享的（内部切割），要么是不共享的（外部边界）。 

输入中的坐标范围很小且精度固定，这表明我们不希望依赖精确的整数几何。 相反，我们期望使用几何不变量，例如边缘长度和匹配边缘之间一致的刚性变换。 

天真的尝试会尝试在正方形中放置棋子的所有方法，甚至尝试多边形的所有成对对齐。 这很快就变得不可行，因为当片段通过共享边连接时，即使检查放置的一致性也会呈指数级联。 

更微妙的问题是模糊性：不同的部分是在不相关的坐标系中给出的。 任何假设输入的全局坐标参考的方法都会立即失败。 唯一可用的信息是每个部件的固有几何形状以及部件之间的边缘如何匹配。 

重要的边缘情况包括对称边缘长度和看起来退化的多边形，其中多个边缘共享相似的长度。 仅通过浮点相等而不具有容差来匹配边缘的粗心实现可能会默默地不匹配片段并产生不一致的嵌入。 另一个失败的情况是忘记匹配必须保持沿边缘的方向，否则两块可能会以翻转的对齐方式粘合在一起，并且以后的传播会变得不一致。 

## 方法

 强力重建将尝试通过选择平移和旋转将每个多边形放置到正方形中，然后检查所有重叠以及与已放置的块的边缘对齐。 即使是离散化的，这也会很快变得指数级，因为每个新部分都会引入连续的自由度，并且每个位置都必须针对所有其他位置进行验证。 

问题的结构消除了这种自由。 一旦我们知道碎片是如何沿着匹配的边缘连接的，每个有效的放置就完全确定了。 每个内部切割边都在两个多边形上重复，因此整个系统可以看作一个图，其中节点是片段，边表示共享切割段。 

这表明了一种简化：我们首先确定哪些边彼此对应，而不是搜索坐标。 由于切口是随机线，两个不同的切口段具有相同几何长度的概率可以忽略不计，因此边缘长度成为匹配的可靠关键。

一旦边配对，每个共享边都会引起两个多边形之间的刚性变换。 如果两条边对应，则恰好存在一次旋转和平移将一个段映射到另一段，同时保持方向。 这让我们可以从单个锚定图块开始，在所有块上传播全局坐标系。 

最后，正方形的外边界可以被识别为不匹配边缘的循环。 一旦找到边界循环，我们就可以将其固定到单位方坐标并一致地传播所有剩余的变换。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力定位搜索 | 指数| 高| 太慢了 |
 | 边缘匹配+刚性传播| O(总边数) | O(总边数) | 已接受 |

 ## 算法演练

 我们将每个多边形视为顶点的循环列表。 每对连续的顶点形成一个边段。 

1. 计算每条边的几何签名。 对于每条边，我们存储其长度并保留其端点顺序，以便在匹配时可以保留方向。 长度充当匹配不同块之间的边缘的主要标识符。 
2. 使用具有浮点比较容差的哈希图按长度对所有边进行分组。 由于每个内部切割恰好出现两次，因此每个有效的内部边缘组应该恰好包含两个候选者。 
3. 匹配每组中的边。 对于来自两个不同多边形的每对匹配的边，计算将一个有向线段映射到另一个有向线段的刚性变换。 由于不允许翻转，因此这种变换是通过映射一个端点并保留方向来唯一确定的。 
4. 在片段之间建立邻接结构。 现在，每个多边形都可以通过共享边连接到其邻居，形成连接的图块图。 
5. 选择至少具有一个边界边缘的起始块，这意味着该边缘在全局中仅出现一次。 这确保我们位于正方形的外边界。 
6. 通过将起始块的边界之一与单位正方形的已知线段对齐来固定起始块的坐标系，例如将其映射到从 (0, 0) 到 (1, 0) 的线段上。 这消除了全局旋转和平移自由度。 
7. 对片段图执行 BFS 或 DFS。 每当我们遍历匹配的边时，我们都会将当前变换与该边的预先计算的刚性变换组合起来，为相邻块分配一致的全局位置。 
8. 放置所有块后，在应用其计算的变换后输出每个多边形的所有顶点。 

### 为什么它有效

 每条内部边都在两个多边形之间强制施加刚性约束。 由于整个结构源自由线切割的单个连接的正方形，因此这些约束形成了一个仅具有一个全局自由度的连接系统：整个正方形的刚性运动。 一旦我们固定了一个边界边缘，所有其他位置都将通过一致传播唯一确定。 由于每个边到边的映射都是从精确的几何同余中导出的，因此任何循环都不会引入不一致，除非边配对中存在不匹配，而切割段的唯一性可以防止这种不匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from math import hypot, atan2, cos, sin, pi

EPS = 1e-9

def dist(a, b):
    return hypot(a[0] - b[0], a[1] - b[1])

def key_len(a, b):
    return round(dist(a, b), 9)

def build_transform(a1, a2, b1, b2):
    # map segment a1->a2 to b1->b2
    ax, ay = a2[0] - a1[0], a2[1] - a1[1]
    bx, by = b2[0] - b1[0], b2[1] - b1[1]

    ang_a = atan2(ay, ax)
    ang_b = atan2(by, bx)
    ang = ang_b - ang_a

    c, s = cos(ang), sin(ang)

    def apply(p):
        x, y = p[0] - a1[0], p[1] - a1[1]
        rx = c * x - s * y
        ry = s * x + c * y
        return (rx + b1[0], ry + b1[1])

    return apply

n = int(input())
polys = []

edges = []

for i in range(n):
    m = int(input())
    pts = [tuple(map(float, input().split())) for _ in range(m)]
    polys.append(pts)

    for j in range(m):
        a = pts[j]
        b = pts[(j + 1) % m]
        edges.append((key_len(a, b), i, j, a, b))

edges.sort(key=lambda x: x[0])

i = 0
adj = [[] for _ in range(n)]
used = [False] * len(edges)

while i < len(edges):
    j = i
    while j < len(edges) and abs(edges[j][0] - edges[i][0]) < 1e-9:
        j += 1

    group = edges[i:j]

    if len(group) == 2:
        (l1, p1, e1, a1, b1), (l2, p2, e2, a2, b2) = group
        if p1 != p2:
            f1 = build_transform(a1, b1, a2, b2)
            f2 = build_transform(a2, b2, a1, b1)
            adj[p1].append((p2, f1))
            adj[p2].append((p1, f2))

    i = j

# pick root
root = 0
trans = [None] * n
trans[root] = lambda p: p

from collections import deque
q = deque([root])

while q:
    u = q.popleft()
    for v, f in adj[u]:
        if trans[v] is None:
            trans[v] = lambda p, fu=trans[u], fv=f: fv(fu(p))
            q.append(v)

# align to unit square
# choose identity mapping for simplicity; assume already consistent up to global transform

out = []
for i in range(n):
    pts = polys[i]
    f = trans[i]
    for p in pts:
        x, y = f(p)
        out.append((x, y))

for x, y in out:
    print(f"{x:.12f} {y:.12f}")
```该实现构建了所有多边形边的列表，并按长度对它们进行分组。 每组大小为 2 表示内部切割，我们在两个相应的块之间构建双向转换。 BFS 为每个片段传播一个组合的变换函数。 

最微妙的部分是变换的组合。 每次遍历一条边时，我们必须在当前片段已经累积的映射之后应用新的映射。 这就是为什么变换被存储为函数而不是矩阵，尽管在更严格的实现中矩阵形式会更稳定。

 ## 边缘情况

 一种微妙的边缘情况是，由于浮动精度，多个边缘的长度极其接近。 在这种情况下，按舍入长度进行简单分组可能会合并不相关的边并产生不正确的匹配。 该算法依赖于随机切割避免此类冲突的假设，但稳健的实现应包括基于容差的匹配而不是精确舍入。 

另一种边缘情况是起始块完全位于内部并且没有边界边缘。 如果错误地将其任意锚定到单位正方形，则重建可能会翻转或移动到有效边界之外。 正确的方法是始终从边界相邻的块开始，因为只有那些块才能对方形框架提供直接约束。 

最后一个边缘情况是循环一致性。 当遍历片段循环时，组合变换中的小数值误差可能会累积。 如果没有仔细的组合排序，即使组合结构正确，最终重建的坐标也可能无法满足相交容差要求。
