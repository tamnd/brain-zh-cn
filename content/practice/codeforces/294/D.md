 ## 问题理解

 我们的厨房地板有 _n_×_m_ 块瓷砖，最初都是白色的。 机器人站在坐标为 (_x_s_, _y_s_) 的边界块上，面向四个对角线方向之一。 每次机器人移动到一块瓷砖时，它都会把它涂成黑色。 如果它撞到墙上，就会像台球一样反射。 机器人的目标是绘制瓷砖，直到地板变成棋盘，其中没有两个相邻的瓷砖具有相同的颜色。 我们将计算黑色瓷砖的总数，直到满足此条件为止，如果从未发生，则计算 -1。 

机器人立即绘制起始图块。 反射规则意味着当机器人撞击水平或垂直墙壁时，其水平或垂直运动分量会反转。 如果它撞到角落，两个组件都会反转。 

约束很大：_n_、_m_ 最多可达 10^5。 逐个移动机器人块的简单模拟可能需要多达 10^10 次操作，远远超出 2 秒的时间限制。 因此，我们需要一种更具分析性或数学性的方法。 

当机器人可能在没有覆盖棋盘格的正确瓷砖的情况下进入一个循环时，就会出现微妙的边缘情况。 例如，在从角落开始的 2×3 矩形中，机器人可能只是在三个图块之间重复振荡。 无限期模拟的粗心实现将永远不会终止，并且永远不会满足棋盘条件。 

## 方法

 暴力方法将模拟机器人一次移动一个图块，更新图块颜色并在每次移动后检查棋盘状况。 这是正确的，因为它直接实现了问题陈述，但对于大型网格来说是不可行的，因为每次移动都需要恒定的时间，并且在多次反射重复的单个对角路径中最多可以访问 O(n*m) 个唯一的图块。 

关键的观察是机器人沿对角线移动，并且其移动模式周期性重复。 如果我们同时跟踪在两个方向上到达下一面墙的移动次数，我们可以直接跳到下一个反射点，而不是模拟每个瓷砖。 具体来说，从位置（_x_，_y_）开始以增量（_dx_，_dy_）移动，机器人将在`t = min((dx>0?n-x:x-1)//abs(dx), (dy>0?m-y:y-1)//abs(dy))`步骤。 在这样的一次跳跃中，它描绘了`t`新瓷砖。 撞到墙上后，方向分量反转，然后重复。 这最多将操作次数减少到 O(n + m)，因为每次反射都会缩短到墙壁的距离，并且机器人只能访问边界有限次。 

我们还跟踪图块坐标模 2 的奇偶性。如果所有具有偶数和坐标的图块都被绘制并且所有具有奇数和坐标的图块都被绘制，则地板是棋盘。 如果机器人从与棋盘奇偶校验相匹配的一块瓷砖开始，它最终将覆盖沿其路径的所有奇偶校验瓷砖。 如果机器人进入循环而没有接触相反奇偶校验的图块，则算法可以使用由以下组成的访问状态集来检测它：`(x, y, dx, dy)`元组。 如果机器人重复一个状态，我们知道它陷入了一个循环并且永远不会完成，因此输出为 -1。

 ## 算法演练

 1. 读取网格尺寸_n_、_m_、起始坐标（_x_s_、_y_s_）和初始方向。 将“UL”等方向转换为增量`dx`,`dy`在哪里`dx = ±1`用于行移动和`dy = ±1`用于柱的移动。 
2. 初始化`painted = 1`因为起始瓷砖会立即被涂漆。 
3. 跟踪机器人当前位置`(x, y)`和方向`(dx, dy)`。 
4.使用一套`visited_states`追踪`(x, y, dx, dy)`来检测循环。 如果机器人再次访问相同的状态，则以 -1 终止。 
5. 虽然棋盘不完整：

 a. 计算两个方向上到下一堵墙的最大步数：`tx = (n-x) if dx>0 else (x-1)`

`ty = (m-y) if dy>0 else (y-1)`

`t = min(tx, ty)`b. 移动机器人`t`对角线步骤：`x += dx*t`,`y += dy*t`。 

c. 增加`painted`经过`t`。 

d. 如果机器人撞到垂直的墙壁，则反向`dy`。 如果撞到水平墙壁，则反向`dx`。 如果撞到角落，则将两者反转。 
6. 检查奇偶校验是否`(x_s + y_s) % 2`匹配所有涂漆瓷砖的奇偶性。 如果最终双方都被覆盖，则终止并输出`painted`。 
7. 重复此操作，直到每个奇偶校验的所有图块均已绘制或检测到环路。 

**工作原理：** 机器人沿对角线移动，在边界处反射。 它的路径是周期性的，仅取决于其当前位置和方向。 通过跳转到反射点并计算步数，我们可以准确地计算访问过的图块数量。 奇偶校验确保棋盘可以完成，环路检测保证在无法完成时终止。
