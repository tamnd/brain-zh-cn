 ## 解决方案
 ## 问题理解

 我们得到了一系列水平线，每条线上都栖息着一些鸟。 电线从上到下编号，每根电线上的鸟从左到右排列。 沙斯一只一只地射杀鸟。 当特定电线上的一只小鸟被射杀时，其左侧的所有小鸟都会飞到上面的电线（如果上面没有电线，则消失），而右侧的所有小鸟会飞到下面的电线（如果下面没有电线，则消失）。 被射中的鸟本身就消失了。 我们被要求计算所有射击后每根电线上的鸟的最终数量。 

输入给出了电线的数量`n`，每根电线的鸟数列表，射击次数`m`，以及每个镜头的电线编号以及小鸟在该电线上的位置。 位置从左到右从 1 开始。 输出只是所有射击后每根电线上的鸟的数量。 

限制很小：`n`≤ 100，`m`≤ 100，鸟数≤ 100。这意味着我们可以直接模拟该过程，因为在最坏的情况下，我们最多执行 100 次操作，每次操作都涉及对长度为 100 的数组进行一些算术运算。任何 O(n * m) 解决方案都是可以接受的。 

当射击发生在电线上的第一个或最后一个位置时，会出现微妙的边缘情况。 如果第一只鸟被射中，它的左边就没有鸟了，所以没有东西飞起来； 如果最后一只鸟被射中，就没有东西飞下来。 同样，在顶部或底部的电线上射击小鸟意味着一些小鸟可能会飞走，因为上方或下方没有电线。 粗心的实现可能会尝试在数组外部建立索引。 

## 方法

 蛮力方法是直接模拟：对于每次射击，计算射击左侧和右侧的鸟的数量，将它们移动到适当的相邻电线，然后移除射击的鸟。 这种方法之所以有效，是因为问题规模很小，而且我们只需要简单的数组操作。 天真的解决方案中的失败点通常是当鸟类飞离顶部或底部电线时索引超出数组范围，或者在计算左/右鸟类时出现差一错误。 

最优方法本质上与该问题中的暴力破解相同，因为约束条件允许。 关键的见解是我们不需要跟踪单个鸟类的位置；我们只需跟踪它们的位置即可。 我们只需要每根电线上的鸟的数量。 对于每个镜头，如果`y`是被射中的鸟的位置，那么`y - 1`鸟儿飞起来，然后`ai - y`鸟儿飞下来。 我们可以相应地更新鸟类计数数组。 这避免了任何不必要的循环或对鸟类位置的详细跟踪，使模拟简洁高效。

 | ---| ---| ---| ---|
 | 暴力模拟| O(n * m) | O(n) | 已接受 |
 | 基于最佳计数的仿真 | O(米) | O(n) | 已接受 |

 ## 算法演练

 1.读取线数`n`和清单`birds`代表每根电线上鸟的初始数量。 
2. 读取拍摄次数`m`。 
3. 对于每次射击，读取线索引`x`（从 1 开始）和鸟的位置`y`（基于 1）。 转变`x`为基于 0 的数组索引。 
4. 计算飞起来的鸟的数量（`left = y - 1`）和飞下来的鸟的数量（`right = birds[x] - y`）。 
5. 如果上面有一根电线（`x > 0`）， 添加`left`鸟到它。 如果下面有一根电线（`x < n - 1`）， 添加`right`鸟到它。 
6. 设置`birds[x] = 0`考虑到被射中的鸟和所有其他鸟的转移。 
7. 处理完所有镜头后，打印每根电线上的鸟的数量。 

为什么有效：每次射击仅影响当前电线，最多影响相邻电线。 通过转移计数而不是单个鸡只，我们可以保持准确的总数。 通过检查是否存在相邻导线来处理边界条件。 不变的是，每次射击后，每根线上的小鸟总数正确地代表了当前状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
birds = list(map(int, input().split()))
m = int(input())

for _ in range(m):
    x, y = map(int, input().split())
    x -= 1  # convert to 0-based index
    left = y - 1
    right = birds[x] - y
    if x > 0:
        birds[x - 1] += left
    if x < n - 1:
        birds[x + 1] += right
    birds[x] = 0

for count in birds:
    print(count)
```该解决方案首先使用有效地读取输入`sys.stdin.readline`。 每个镜头都通过计算有多少只鸟上下飞行来处理，并进行仔细的边界检查以避免在数组之外进行索引。 的更新`birds`为了清晰和高效，数组就地完成。
