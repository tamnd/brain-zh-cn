 ## 解决方案
 ## 问题理解

 我们有一排`n`灯。 一些位置已经打开，而所有其他位置都关闭。 

移动包括选择一盏关闭的灯，该灯至少有一个相邻的灯已打开，然后将其打开。 我们继续，直到每盏灯都亮起来。 

任务是计算存在多少种不同的有效移动序列。 如果两个序列在​​某个步骤切换到不同的位置，则认为它们是不同的。 答案必须以模计算`1000000007`。 

输入给出了最初打开的位置。 自从`n ≤ 1000`，我们正在处理相对较小的尺寸。 具有指数行为的算法是不可能的，因为关闭灯的数量可能接近 1000 个。`O(n³)`解决方案是不必要的。 该约束强烈建议采用预先计算阶乘和模算术的组合计数解决方案。 

问题的微妙之处在于，移动的合法性仅取决于与已激活的灯的邻近程度。 这会在每个初始关闭灯块内的位置之间创建依赖关系。 

一些边缘情况很容易被错误处理。 

考虑：```
5 2
2 4
```关闭位置形成三个间隙：```
1 | 3 | 5
```每个间隙的大小为 1。每个间隙都可以独立贡献位置，答案并不简单`3! = 6`。 我们必须考虑每个差距的内部限制。 

另一个重要的情况是内部差距：```
7 2
2 6
```位置 2 和 6 之间的间隙包含：```
3 4 5
```该块可以从任意一端填充。 位置 4 无法首先激活。 如果一个简单的解决方案将这三个位置的每个排序都视为有效，那么就会过度计算。 

当所有灯都亮起时，会出现最后一个极端情况：```
4 4
1 2 3 4
```没有要执行的动作。 正确答案是：```
1
```恰好有一个空序列。 

## 方法

 暴力解决方案将模拟所有可能的有效移动序列。 在每个状态下，我们都会找到每个当前可切换的灯，递归地尝试每个选择，并继续，直到所有灯都打开。 

这是正确的，因为它明确枚举了每个合法序列。 问题在于州的数量。 如果只有一盏灯亮起，其余 999 盏灯都熄灭，则有效序列的数量是巨大的。 穷举搜索变得完全不可行。 

关键的观察结果是，该行自然地分成最初打开的灯之间的独立间隙。 

假设初始位置已排序。 在每对连续的亮灯之间都有一个关灯间隙。 在第一个亮灯之前和最后一个亮灯之后也可能存在间隙。 

边界间隙的行为与内部间隙不同。 

对于边界间隙，激活只能从一侧扩展。 如果间隙包含`k`头寸，该缺口内的订单完全是被迫的。 

例如：```
111000
```最右边的三个位置必须从左到右激活。 

内部差距更有趣。 假设间隙长度为`k`。```
1 0 0 0 1
```两端都与活动灯相邻。 每一步我们都可能采取最左边的剩余位置或最右边的剩余位置。 该过程一直持续到间隙消失。 

对于长度间隙`k`，有效内部订单数量为：```
2^(k-1)
```为什么？ 第一个`k-1`每个激活都有两个选择，左端或右端。 最终的立场是被迫的。 

在计算每个间隙内的有效订单后，我们必须合并来自不同间隙的动作。 如果间隙大小为：```
g1, g2, ..., gt
```那么可以选择来自不同间隙的移动的相对顺序$$\frac{(g_1+g_2+\cdots+g_t)!}{g_1!g_2!\cdots g_t!}$$方式，这是一个多项式系数。 

整个答案变成：$$\text{multinomial} \times \prod_{\text{internal gaps}} 2^{k-1}$$这将问题转化为纯组合问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最佳 | 阶乘预计算后的 O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取初始位置并对其进行排序。 
2. 计算每个间隙长度。 

第一个亮灯之前的间隙有长度`a[0]-1`。 

最后一次亮灯后的间隙有长度`n-a[m-1]`。 

连续亮灯之间`a[i]`和`a[i+1]`，内部间隙长度为：$$a[i+1]-a[i]-1$$3.让`off = n - m`，仍需要激活的灯总数。 
4. 开始：$$ans = off!$$这会计算在考虑间隙约束之前安排未来激活的所有方法。 
5. 对于每个长度的间隙`k`, 除以`k!`。 

这转换`off!`进入多项式系数，该系数计算来自不同间隙的激活如何交错。 
6. 对于每个正长度的内部间隙`k`，乘以：$$2^{k-1}$$因为差距可以从任何一方缩小，直到只剩下一个位置。 
7. 执行所有除法`10^9+7`使用模逆。 
8. 输出最终结果。 

### 为什么它有效

 每个关闭位置都属于一个间隙。 

在边界间隙内，激活顺序是唯一确定的，因为生长只能从与已亮灯相邻的一侧进行。 

在内部间隙内，唯一可用的选择始终是剩余间隔的两个边界位置。 反复选择向左或向右完全决定了激活顺序。 长度差距`k`因此准确贡献`2^(k-1)`有效的内部订单。 

除了通过全球时间线之外，不同的差距不会相互作用。 一旦每个间隙的有效内部顺序被固定，唯一剩下的自由就是来自不同间隙的移动如何交错。 多项式系数精确地计算这些交错。 

由于答案将有效内部顺序的数量乘以有效交错的数量，因此每个合法的全局序列只被计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def main():
    n, m = map(int, input().split())
    a = sorted(map(int, input().split()))

    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    inv_fact = [1] * (n + 1)
    inv_fact[n] = pow(fact[n], MOD - 2, MOD)
    for i in range(n, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD

    gaps = []

    left_gap = a[0] - 1
    gaps.append(left_gap)

    ans = 1

    for i in range(m - 1):
        k = a[i + 1] - a[i] - 1
        gaps.append(k)
        if k > 0:
            ans = ans * pow(2, k - 1, MOD) % MOD

    right_gap = n - a[-1]
    gaps.append(right_gap)

    off = n - m
    ans = ans * fact[off] % MOD

    for k in gaps:
        ans = ans * inv_fact[k] % MOD

    print(ans)

if __name__ == "__main__":
    main()
```阶乘和反阶乘数组允许在每个间隙的恒定时间内计算多项系数。 

变量`ans`首先积累内部缺口的贡献。 之后我们乘以`off!`，它代表全局时间线中未来激活的所有可能位置。 

除以`k!`对于每个间隙都乘以`inv_fact[k]`。 由于模数是素数，费马小定理给出了模逆：$$x^{-1} \equiv x^{MOD-2} \pmod{MOD}$$一个常见的错误是乘以`2^k`而不是`2^(k-1)`用于内部间隙。 最后剩下的位置没有选择，所以只有第一个`k-1`激活贡献二元决策。 

另一个常见的错误是将二次方因子应用于边界间隙。 边界间隙仅从一侧扩展并恰好贡献一种内部排序。

 ## 边缘情况

 考虑：```
4 4
1 2 3 4
```没有间隙并且`off = 0`。 

该算法计算：```
0! = 1
```没有出现两个因子的幂。 答案依然存在`1`，对应于唯一的空序列。 

考虑：```
4 2
1 4
```中间的间隙有长度`2`。 

该算法计算：```
2! / 2! × 2^(2-1)
= 2
```两个有效的激活命令是：```
2,3
3,2
```这证实了内部差距有助于二元选择。 

考虑：```
5 1
3
```差距是：```
2 and 2
```两者都是边界间隙。 

答案变成：```
4! / (2!2!) = 6
```没有添加二次幂因子，因为两个间隙都不是内部的。 对每个间隙进行相同处理的解决方案将错误地乘以额外的 2 次方并导致计数过多。
