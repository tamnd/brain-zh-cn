 ## 解决方案
 # 问题理解

 任务是将方形城市地图分为两个国家。 每个单元格要么包含一个城市，要么是空的。 整个地图的城市数量是偶数，两国获得的城市数量必须完全相同。 边界必须遵循小区边缘，并且在每个国家/地区内，每个小区必须仅使用该国家/地区的小区与其他每个小区保持可达性。 

输入描述了一个`N x N`网格在哪里`C`标记一个城市和`D`标记一个空单元格。 输出是另一个相同大小的网格，其中每个单元格都分配给两个国家之一。 

主要的困难不是计算城市数量，而是建立一个使双方保持联系的划分。 和`N`最多 50 个，网格最多有 2500 个单元格。 这对于线性或二次算法来说足够小，但是尝试许多可能的边界或对所有分区执行昂贵的搜索的方法是不可能的，因为可能的划分数量呈指数增长。 

一些边缘情况需要注意。 只有两个城市的网格仍然有效。 例如：```
2
CD
DC
```正确的输出可以是：```
11
22
```尝试将完整的行或列放入一个国家/地区的方法可能会失败，因为城市可能不会沿着任何直线保持平衡。 

另一种情况是城市集中在地图的一端：```
3
CCC
DDD
DDD
```正确的输出是：```
111
222
222
```如果粗心的解决方案只检查单元格数量是否平衡而不检查城市数量，则会产生无效答案。 

最后一个棘手的情况是行内的切口。 例如：```
3
DDD
CDC
DDD
```有效的输出是：```
111
122
222
```两国不需要包含相同数量的细胞。 只有城市的数量才重要，因此强制面积相等会造成不必要的限制。 

## 方法

 直接的蛮力想法是尝试每个可能的连通区域，并检查其补充区域是否也连通并包含一半的城市。 正确性很容易看出，因为它检查了每一个可能的答案。 然而，即使对于 10 x 10 的网格，可能的子集数量也已经是巨大的。 对于 50 x 50 网格，有`2^2500`可能的分配，因此穷举搜索不是一个选项。 

有用的观察是我们不需要搜索任意形状。 我们只需要一种形状，在移动边界时保证两侧保持连接。 网格的蛇形遍历恰好具有此属性。 

想象一下逐行访问单元格。 在第一行中，我们从左到右移动，在第二行中，我们从右到左移动，然后交替方向。 该顺序的每个前缀都是连接的，因为它由几个完整的行加上当前行的一段组成。 每个后缀都出于相同的原因而连接。 这为我们提供了一个一维排序，其中每个可能的切割都会创建一个有效的划分。 

然后我们可以沿着这条蛇的顺序行走，并在收集完所有城市的一半后立即停下来。 访问过的小区成为第一国家，其余小区成为第二国家。 由于停靠点是按城市数量选择的，因此两个国家都会收到所需的城市数量。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(N*N)) | O(2^(N*N)) | O(N*N) | 太慢了|
 | 最佳| O(N*N) | O(N*N) | 已接受 |

 ## 算法演练

 1. 统计网格上的城市总数，并计算每个国家必须接收多少个城市。 目标是总数的一半，因为声明保证城市总数是偶数。 
2. 按照蛇的顺序生成单元格。 对于偶数行，从左到右访问列。 对于奇数行，从右到左访问列。 选择此顺序是因为每个前缀和后缀都保持连接。 
3. 遍历蛇序并记录分配给第一个国家的城市的运行计数。 将单元格标记为属于第一个国家/地区，直到计数达到目标城市数。 
4. 将所有剩余单元格分配给第二个国家/地区。 剪切位置已经有效，因此不需要额外的连接检查。 

其原理：不变性是在处理蛇阶的任何前缀后，处理后的单元形成一个连通分量。 对于未处理的后缀也是如此。 当遍历停止时，第一个国家就是这样的前缀，第二个国家就是这样的后缀。 由于当第一个国家接收所有城市的一半时发生停止，因此第二个国家自动接收另一半。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    grid = [input().strip() for _ in range(n)]

    total = sum(row.count('C') for row in grid)
    need = total // 2

    ans = [['2'] * n for _ in range(n)]

    got = 0
    done = False

    for i in range(n):
        cols = range(n) if i % 2 == 0 else range(n - 1, -1, -1)
        for j in cols:
            if done:
                break
            ans[i][j] = '1'
            if grid[i][j] == 'C':
                got += 1
                if got == need:
                    done = True
        if done:
            break

    print('\n'.join(''.join(row) for row in ans))

if __name__ == "__main__":
    solve()
```该代码首先对城市进行计数以确定第一个国家/地区所需的数量。 答案网格从分配给第二个国家的每个单元格开始，这意味着遍历只需将前缀单元格标记为`1`。 

嵌套循环实现了蛇形路径。 方向根据行奇偶校验而变化，这是保持连接性的关键细节。 达到目标城市数量后，循环立即停止，因为其余单元格已经有了正确的分配。 

不需要进行索引调整，因为网格内部使用基于零的坐标。 Python 整数对于所有可能的计数器来说也足够大，因为网格最多包含 2500 个单元格。 

## 工作示例

 考虑：```
3
DDD
DDC
DDC
```蛇的顺序是`(0,0) ... (0,2), (1,2) ... (1,0), (2,0) ... (2,2)`。 有两个城市，所以第一个国家需要一个城市。 

| 步骤| 细胞| 国家 1 的城市数量 | 作业 |
 | --- | --- | --- | --- |
 | 1 | (0,0) | (0,0) | 0 | 1 |
 | 2 | (0,1)| 0 | 1 |
 | 3 | (0,2) | 0 | 1 |
 | 4 | (1,2) | 1 | 1 |
 | 5 | 剩余细胞| 1 | 2 |

 由此产生的分裂给每个国家一个城市。 第一个国家/地区是顶行加上第一个城市单元格，其余单元格保持连接。 

另一个例子：```
3
CCC
DDD
DDD
```同样，蛇的顺序是从左上角开始的。 有三个城市，所以第一个国家需要两个。 

| 步骤| 细胞| 国家 1 的城市数量 | 作业 |
 | --- | --- | --- | --- |
 | 1 | (0,0) | (0,0) | 1 | 1 |
 | 2 | (0,1)| 2 | 1 |
 | 3 | 剩余细胞| 2 | 2 |

 剪切发生在第一行内部。 这说明了为什么蛇排序很有用：第一个国家可以在一行的中间结束，同时两个部分保持连接。

 ## 边缘情况

 当只有两个城市时，算法在蛇序遇到第一个城市后停止。 前缀仅包含一个城市，后缀包含另一个城市。 连接属性来自蛇序，因此不需要特殊处理。 

当所有城市都出现在遍历开始附近时，边界可能会很早就出现。 该算法仍然有效，因为第一个国家可能只包含少量单元格。 相同的城市数量并不需要相同的领土面积。 

当所需的分割发生在行的中间时，算法仅将该行的一部分分配给第一个国家/地区。 它之前的完整行连接到该段，其余的段连接到它之后的行。 这正是基于行或列的简单切割失败而蛇排序成功的情况。
