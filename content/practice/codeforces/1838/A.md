 ## 解决方案
 ## 问题理解

 我们得到了一个最终的整数列表，这些整数是通过在黑板上从两个未知数字开始并重复写下已经存在的任何两个数字的绝对差而产生的。 执行此操作足够多次后，总计达到$n$数字，名单被打乱了。 任务是恢复原始两个数字中的至少一个。 输入给出多个测试用例，每个测试用例指定最终列表的大小和列表本身。 

理解这个问题的关键是操作保留了最大数。 如果我们将原来的两个数字表示为$x$和$y$，那么写入的第一个数字将是$|x-y|$，后续差异不能超过$\max(x, y)$。 这意味着最终列表中最大的数字必须是原始数字之一。 同样，列表中的最小数字要么为零（如果存在重复项），要么为原始数字的绝对差。 因为$n$可以大到 100，任何迭代检查所有成对差异的算法都是$O(n^3)$而且太慢了。 相反，我们可以推理集合的属性来直接找到初始数字之一。 

边缘情况包括所有数字都相同的列表，例如`[0,0,0]`。 尝试盲目配对数字的简单实现可能无法选择正确的初始数字。 另一种情况是列表中最大的数字重复。 必须注意始终选择最大的元素作为候选初始数。 

## 方法

 暴力方法会尝试猜测每对数字，模拟所有可能的差异运算，并检查生成的多重集是否与给定列表匹配。 这是可行的，因为该过程是确定性的，但对于$n=100$, 大致有$O(n^2)$可能的起始对和$O(n^2)$每对操作，产生$O(n^4)$复杂。 这对于输入约束来说是不可行的。 

最佳方法依赖于这样的观察：最终列表中的最大数字必须是原始数字之一。 一旦我们确定最大的数字作为候选，列表中的任何其他数字都可以作为第二个初始数字，并且取绝对差的操作将产生列表中所有较小的数字。 这将问题减少到选择最大元素，从而保证了正确性并适用于$O(n)$每个测试用例的时间。 我们的见解是，任何操作都不能产生大于初始对最大值的数字，因此选择最大元素始终是安全的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^4) | O(n^4) | O(n) | 太慢了 |
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量$t$。 
2. 对于每个测试用例，读取整数$n$和名单$n$整数。 
3. 使用线性扫描识别列表中最大的数字。 该号码保证是原始号码之一。 
4. 打印最大的数字作为该测试用例的答案。 

为什么它有效：关键的不变量是绝对差序列中的任何操作都不能生成大于初始两个数字中的最大值的数字。 因此，最终列表中的最大数字必须是两个起始数字之一。 由于该问题保证可以通过所描述的过程生成列表，因此只需输出最大数即可满足要求。 重复项、负数或零不会影响此属性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(max(a))

if __name__ == "__main__":
    solve()
```该解决方案使用快速 I/O 读取输入，并将整数列表转换为 Python 整数。 使用`max(a)`正确识别列表中的最大数字，通过问题构造，保证该数字是原始数字之一。 不需要排序或额外的内存。 

## 工作示例

 ### 示例 1

 输入列表：`[9, 2, 7]`。 最大值为`9`。 这是一个有效的原始号码，因为其他原始号码可能是`2`，生产`|9-2|=7`。 输出是`9`。 

| 步骤| 列表 | 最大| 选择初始号码 |
 | ---| ---| ---| ---|
 | 1 | [9,2,7]| 9 | 9 |

 ### 示例 2

 输入列表：`[15, -4, 11]`。 最大值为`15`。 我们可以选择第二个原始数字作为`-4`，生产`|15-(-4)|=19`，但由于列表是有保证的，所以选择`11`因为答案也有效，因为它是另一个初始数字。 我们的算法选择最大的，即`15`。 

| 步骤| 列表 | 最大| 选择初始号码 |
 | ---| ---| ---| ---|
 | 1 | [15,-4,11] | 15 | 15 15 | 15

 这些痕迹证实，选取最大值满足它是初始数字之一的不变量。

 ## 边缘情况

 如果所有数字都相等，则算法会正确返回该数字作为原始数字之一。 为了`[0,0,0]`，最大值为`0`，这是有效的。 如果列表同时包含正数和负数，则始终选择最大元素，满足不变量。 对于具有两个相同最大值的列表，选择任一实例都有效，因为问题只需要一个原始数字。 这种方法可以处理由问题约束决定的每个极端情况。
