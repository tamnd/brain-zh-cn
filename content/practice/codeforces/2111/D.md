 ## 解决方案
 ## 问题理解

 我们的任务是为教师制定一个课程表，每个小组第一天正好有六节课。 有$n$学生团体和$m$教室。 每节课在各组中同时发生，因此所有组的第一节课同时发生，所有组的第二节课接下来发生，依此类推。 每个教室一次最多可接待一组学生。 目标是将教室分配给班级，以便学生尽可能在楼层之间移动。 楼层在教室编号中进行编码：除了最后两位之外的所有数字都代表楼层，因此 479 位于四楼，31415 位于 314 楼。 

从输入中，我们得到多个测试用例。 每个测试用例提供组数$n$, 教室数量$m$，以及课堂索引列表。 输出必须是每个组的时间表：每组有六个教室编号，这样就不会出现两个组同时占用同一教室的情况。 楼层之间的总移动量应最大化。 

约束意味着$n$和$m$可以达到$10^5$，总和为$m$所有测试用例不超过$10^5$。 这排除了任何比以下更糟糕的算法$O(m \log m)$每个测试用例。 边缘情况包括只有一组或一间教室的场景，或者教室已经位于同一楼层的场景，其中天真的调度可能会失败或在可能出现非零移动时产生零移动。 

尝试所有六个时期的所有教室排列的幼稚方法显然是不可行的。 另一个微妙的陷阱是未能尊重不同群体的教室在每个时期的排他性。 例如，与$n = 2$团体和$m = 2$如果教室位于同一楼层，简单地为两组学生重复使用同一教室就会违反限制。 

## 方法

 暴力解决方案将生成所有可能的教室分组和时段分配，然后计算总地板运动。 这是可行的，因为理论上我们可以测量最大运动的每个排列，但是$m$和$n$一样大$10^5$，这会导致阶乘时间复杂度大得不可思议。 

关键的观察结果是楼层移动仅取决于分配给每个组的楼层顺序。 当学生在可用的最低楼层和最高楼层之间交替时，就会发生最大的移动。 按楼层对教室进行排序并交错排列，使每个小组在每一步都能体验到最大可能的楼层差异。 排序后，我们可以以循环方式分配教室：第一个$n$排序列表中的教室在第一节课中分组，在下一节课中分组$n$第二期，依此类推。 通过每隔一段时间翻转一次分配顺序，我们可以确保最大程度的来回移动。 

贪婪方法是正确的，因为该问题不会对每个时段每个教室一组之外施加任何额外的约束。 排序保证了楼层之间的极值差异被利用，而循环分配保证了没有冲突。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O((m!)^6) | O((m!)^6) | O(米) | 太慢了|
 | 最佳| O(m log m) | O(米) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和$m$和教室名单。 通过整数除以 100 来提取每个教室的楼层。 
2. 按楼层对教室进行排序，将教室按楼层升序分组。 这使我们能够在交替分配任务时最大化差异。 
3. 初始化一个2D数组`schedule`尺寸的$n \times 6$存储每个时段分配给每个小组的教室。 
4. 对于前三个时段，从分组排序列表的开头到结尾顺序分配教室。 对于第四至第六时段，按相反顺序分配。 这种交替可以最大化地板的运动。 
5. 对于每个时期，迭代所有组。 循环分配教室：分组$i$接收索引处的教室`(i + offset) % m`，确保没有两个小组同时共用一个教室。 
6. 在一行上以六个整数的形式输出每组的时间表。 

不变的是，在任何时期，每个教室最多由一组人使用。 排序可确保捕获最大楼层差异，而交替分配方向可确保连续相似楼层不会使移动最小化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    
    # Sort classrooms by floor
    a.sort()
    
    # Initialize schedule
    schedule = [[0]*6 for _ in range(n)]
    
    # We will assign classrooms to maximize floor differences
    idx = 0
    for day in range(6):
        if day % 2 == 0:
            # forward assignment
            for i in range(n):
                schedule[i][day] = a[idx]
                idx += 1
        else:
            # backward assignment
            for i in range(n-1, -1, -1):
                schedule[i][day] = a[idx]
                idx += 1
        if idx >= m:
            idx = 0  # wrap around if needed
    
    for row in schedule:
        print(" ".join(map(str, row)))
```第一步对教室进行读取和排序，这确保我们可以分配极值楼层以实现最大的移动。 前后分配在每个周期交替方向，形成锯齿形模式，最大限度地提高地板运动。 环绕式`idx`确保即使当`m`不是的倍数`n`，所有期间的分配都没有冲突。

 ## 边缘情况

 当只有一个教室时，算法会将其分配给单个组的所有时段，从而产生零移动。 由于有两个小组和多个教室，前后之字形确保每个小组在楼层之间移动，并且教室永远不会被重复预订。 对于比教室更多的小组，环绕逻辑可以防止索引越界错误，同时仍然生成有效的作业。
