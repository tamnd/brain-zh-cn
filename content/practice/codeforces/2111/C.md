 ## 解决方案
 ## 问题理解

 我们得到一个整数数组，并允许重复地将所选元素的值“广播”到其左侧的所有内容或右侧的所有内容。 每个广播的成本与被覆盖的元素数量乘以传播的值成正比。 目标是使整个数组由单个值组成，同时支付尽可能少的费用。 

重新解释操作的一个有用方法是，每次移动都会选择一个位置，并通过前缀或后缀扩展该位置的值，为每个新受影响的索引付出代价。 由于元素可以被覆盖多次，因此该过程并不单调：我们不只是绘制一次，稍后我们可能会用更便宜的值重新绘制区域。 

约束很大，测试用例中的总数组大小高达 5×10^5。 这立即排除了每个测试用例的任何二次方。 任何解必须本质上是线性的或线性算数的。 这表明答案必须可以从局部结构计算出来，通常依赖于相等值的邻接或最佳分割。 

一些微妙的情况打破了天真的推理。 一个常见的错误是假设我们可以从两端贪婪地独立地“修复”左侧和右侧。 例如，在像这样的数组中`[3, 1, 3]`，尝试从最小或从端点扩展的贪婪策略可能会错过最优策略使用中间值以便宜的方式覆盖两侧。 

另一个问题是认为每个值都是独立贡献的。 事实上，操作重叠严重：一个操作可以取代一个大区域，而该区域随后可能被重新用作另一个操作的基础，从而使本地决策产生误导。 

## 方法

 暴力的观点是考虑我们希望数组成为的最终值。 假设我们固定一个值`x`。 然后我们需要将整个数组转换为`x`使用复制操作`x`从选定的事件向外`x`。 如果我们选择多个位置`x`作为源，每个源向左或向右扩展，并且它们覆盖的片段合并。 一个简单的策略会尝试每个值的位置的所有子集并模拟所有可能的扩展序列。 出现次数呈指数级增长，甚至单个模拟也是线性的，使得这种方法不可行。 

关键的观察是对于固定的目标值`x`，我们永远不会从使用非`x`价值观作为来源。 任何操作都会传播单个选定的值，因此最终每个操作都与某个值的出现相关联，并且使用不同的值只会增加成本，因为较高的值每单位长度的成本更高。 

更重要的是，如果我们观察以下情况的发生`x`，两次连续出现之间的数组`x`可以从左侧出现的位置或右侧出现的位置进行填充。 这创建了一个本地决策：连续的之间的每个间隙`x`仓位必须一次性“支付”，成本取决于我们是从左延伸还是从右延伸。 

这将问题简化为：对于每个值`x`，考虑所有位置`a[i] = x`。 这些位置将数组分成段，并且连续出现之间的每个段都可以从任一侧覆盖。 间隙所带来的成本仅取决于其长度和`x`。 我们计算覆盖所有差距的最佳方法，这变成了对局部结构确定的最小贡献求和。 

最后，我们评估每个不同值的成本并取最小值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(2^n·n) | O(2^n·n) | O(n) | 太慢了|
 | 每个值的差距优化 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，按索引值对索引进行分组。 

我们需要这些位置，因为只有出现的值才能充当该值的来源。 
2. 对于每个不同的值`x`，提取排序后的位置列表，其中`a[i] = x`。 

这些位置定义了我们可以“锚定”扩展的位置`x`。 
3. 使用以下方法计算填充所有内容所需的成本`x`作为最终值。 

我们从概念上将数组分成连续出现的段`x`。 
4. For each gap between consecutive occurrences`p[i]`和`p[i+1]`，计算它的长度`len = p[i+1] - p[i] - 1`。 

这是必须通过从任一侧扩展来覆盖的元素数量。 
5. 每个这样的差距都会产生与以下成比例的成本：`len * x`，因为有效填充该区域需要传播值`x`跨越这些职位。 
6. 总价值成本`x`是所有间隙的总和加上处理第一次出现之前的前缀和最后一次出现之后的后缀的成本，这些后缀被视为距最近出现的间隙。 
7. 取所有不同值的最小成本。 

### 为什么它有效

 关键的不变量是，在任何以固定值为目标的最优策略中`x`，每个位置最终都会被源自最接近的出现的扩展所填充`x`在最优计划中首先达到它。 由于操作总是传播一个恒定值，并且成本与新覆盖头寸的数量成线性关系，因此将覆盖范围分割为发生之间的独立间隔是无损的：没有任何操作可以减少所需覆盖头寸的总数，只能重新分配它们的支付方式。 因此，每个缺口只支付一次，并选择`x`本地决定所有成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        pos = {}
        for i, v in enumerate(a):
            pos.setdefault(v, []).append(i)

        ans = float('inf')

        for v, p in pos.items():
            cost = 0

            # left boundary gap
            if p[0] > 0:
                cost += (p[0]) * v

            # internal gaps
            for i in range(len(p) - 1):
                gap = p[i + 1] - p[i] - 1
                cost += gap * v

            # right boundary gap
            if p[-1] < n - 1:
                cost += (n - 1 - p[-1]) * v

            ans = min(ans, cost)

        print(ans)

if __name__ == "__main__":
    solve()
```代码首先按值对索引进行分组，以便可以独立评估每个候选最终值。 对于每个值`v`，它将数组视为围绕出现的段`v`。 每个位置不等于`v`必须通过从某些发生的扩展来覆盖`v`，并且此类位置的总数被分为左边界、内部间隙和右边界。 将这些计数乘以`v`反映运营成本定义，其中每个单位的扩展成本`v`。 

一个微妙的点是我们从不显式地模拟操作。 相反，我们依赖这样一个事实：最优策略永远不会从交错不同的值中受益，因此独立评估每个值就足够了。

 ## 边缘情况

 一种边缘情况是最佳值仅出现一次。 对于像这样的输入`3 1 3`，选择`1`因为即使目标没有内部结构，它仍然可能是最优的。 该算法处理此问题是因为位置列表具有单个元素，因此内部间隙和边界贡献都正确地考虑了从该单个源传播的全部成本。 

另一个边缘情况是所有元素都相等。 在这种情况下，位置列表具有完全覆盖，并且两个边界检查的计算结果为零。 计算成本为零，无需特殊外壳。 

最后一个微妙的情况是交替值，例如`1 2 1 2 1`。 每个值单独出现多次，算法仅正确测量出现次数之间的间隙，确保重叠影响不会错误地重复计算区域。
