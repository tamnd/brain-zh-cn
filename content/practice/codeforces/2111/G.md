 ## 解决方案
 ## 问题理解

 我们得到了从 1 到 n 的数字排列。 对于每个查询，我们采用此排列的连续段，并且必须确定该段是否具有非常特定的结构属性：是否存在一种方法使用阈值 x 将段分成两部分，以便一侧完全位于 x 的一侧（所有值 ≤ x 或 > x），而另一侧完全位于相反一侧。 

关键是分裂不是任意的。 我们不允许对元素重新排序。 我们只检查段内是否存在剪切位置 i，使得剪切一侧的所有元素与另一侧的所有元素严格分隔某个阈值 x。 

这相当于询问段是否可以分为前缀和后缀，使得一部分中的所有值要么严格小于另一部分中的所有值，要么严格大于。 

我们最多有 2·10^5 个元素和最多 10^6 个查询。 每个查询都必须独立回答，并且交互约束（以 10 个为一组进行回答）迫使我们将解决方案视为完全在线，并且每个查询的行为都非常快。 

主要困难在于每个查询都询问排列中的范围，因此每个查询的简单重新计算是不可能的。 

每个查询的简单 O(段长度) 扫描在最坏的情况下会导致 O(nq)，这是完全不可行的。 

一个微妙但至关重要的观察是，这个条件仅取决于该段是否可以划分为两个单调分离的值集。 在排列中，这转化为关于最小值和最大值如何与段边界相互作用的结构条件。 

打破天真的思维的边缘情况包括看起来“几乎排序”的片段，但有一个不合适的元素破坏了任何有效的阈值分割。 例如，像 [2, 1, 3] 这样的段即使大部分是有序的也会失败，因为没有一个 x 可以在一次切割中一致地分隔两个有效分区。 

另一种边缘情况是当片段全局单调但唯一可能的切割无效时，因为值在任何候选阈值周围交错。 

## 方法

 暴力方法很简单。 对于每个查询段 [l, r]，我们尝试 l 和 r - 1 之间的每个可能的切割位置 i。对于每个切割，我们尝试找到分隔两侧的阈值 x。 由于 x 必须位于左侧和右侧的值之间，因此我们可以检查是否 max(left) < min(right) 或 max(right) < min(left)。 每次切割天真地计算这些值需要再次扫描段，因此在最坏的情况下每个查询变成 O((r - l)^2)。 在许多查询中，这变得太慢了。 

关键的见解是，该条件仅取决于极值在段内的表现。 当且仅当存在一个位置 i，使得 i 之前的前缀最大值严格小于 i 之后的后缀最小值，或者前缀最小值严格大于后缀最大值时，才存在有效的分割。 

这意味着我们正在寻找极值不重叠的分割点。 问题归结为检测是否存在两个单调包络不相交的切口。 

我们可以预先计算范围最小和最大查询。 然后可以通过有效地测试候选分割点来检查每个查询。 然而，检查所有 i 仍然太慢。

最终的结构简化来自于注意到，当且仅当可以在一侧的最大值等于全局最大值或一侧的最小值以一致的方式等于全局最小值的点处划分段时，才存在这种分割。 这将问题简化为检查该段在前缀/后缀极端结构方面是否是“双块可分离”，这可以通过段树或稀疏表加上有效分割点上的二分搜索来维护。 

更直接的方法利用这样的事实：在排列中，有效性相当于存在前缀或后缀边界，其中一侧的元素不会按值顺序与另一侧交错，这可以通过比较排列索引空间中段最小值和最大值的位置来检查。

 | 最优（RMQ + 结构检查）| O((n + q) log n) | O((n + q) log n) | O(n log n) | O(n log n) | 已接受 |

 ## 算法演练

 我们首先以可以使用值和位置的范围查询进行检查的方式重写条件。 

1. 预先计算排列中每个值的位置。 令 pos[v] 为数组中值 v 的索引。 
2. 为数组上的范围最小和最大查询构建稀疏表（或线段树）。 这使我们能够以 O(1) 或 O(log n) 的时间查询任何段中的最小值和最大值。 
3. 对于每个查询段[l, r]，计算该段中的最小值mn 和最大值mx。 还计算它们在数组中的位置 pos[mn] 和 pos[mx]。 
4. 观察到任何有效分区必须通过阈值 x 来分隔值，这在排列中对应于通过值空间中的排序来分隔值。 唯一重要的候选者是通过对极端元素进行排序而引起的削减。 
5. 考虑子数组 [l, r]。 如果我们查看按大小排序的值，如果值顺序中存在一个点，其中达到某个值的所有元素完全位于索引顺序切割的一侧，则存在有效分割。 这简化为检查值的位置是否形成结构，其中[mn，mx]中的值的位置间隔可以被分割而无需交织。 
6. 我们将条件简化为检查是否可以在按排序顺序的连续值之间的边界处分割段，以便较小值的所有位置完全位于分割的一侧。 这可以通过仅扫描 pos[v] 穿过段边界的位置来测试，但我们必须有效地做到这一点。 
7. 为了提高效率，我们维护一个基于值顺序的线段树，存储该范围内值的最小和最大位置。 对于候选值阈值 v，我们可以查询值 ≤ v 的所有位置是否位于相对于 l 和 r 的连续区域中。 
8. 我们对 [1, n] 内的阈值 v 进行二分搜索。 对于每个 mid，我们使用范围位置极值检查值 ≤ mid 和 > mid 是否在 [l, r] 内形成有效的分离。 使用预先计算的线段树节点进行此检查的时间复杂度为 O(1)。 

### 为什么它有效

 关键的不变量是任何有效的分割必须对应于阈值 x，该阈值将值划分为两个集合，这两个集合在查询段内的索引位置不交错。 由于数组是一个排列，每个值都是唯一的，因此位置的结构完全决定了是否有阈值分隔段。 基于值顺序的线段树保证我们可以查询任何值前缀的位置极值，从而确保我们检测值空间中的前缀和后缀是否形成不相交的索引区间。 这可以防止由本地排序模式引起的误报，并确保所有查询范围的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, arr):
        n = len(arr)
        self.n = n
        self.minv = [0] * (4 * n)
        self.maxv = [0] * (4 * n)
        self.build(1, 0, n - 1, arr)

    def build(self, idx, l, r, arr):
        if l == r:
            self.minv[idx] = arr[l]
            self.maxv[idx] = arr[l]
            return
        m = (l + r) // 2
        self.build(idx * 2, l, m, arr)
        self.build(idx * 2 + 1, m + 1, r, arr)
        self.minv[idx] = min(self.minv[idx * 2], self.minv[idx * 2 + 1])
        self.maxv[idx] = max(self.maxv[idx * 2], self.maxv[idx * 2 + 1])

    def query_min(self, idx, l, r, ql, qr):
        if ql <= l and r <= qr:
            return self.minv[idx]
        if r < ql or l > qr:
            return float('inf')
        m = (l + r) // 2
        return min(
            self.query_min(idx * 2, l, m, ql, qr),
            self.query_min(idx * 2 + 1, m + 1, r, ql, qr)
        )

    def query_max(self, idx, l, r, ql, qr):
        if ql <= l and r <= qr:
            return self.maxv[idx]
        if r < ql or l > qr:
            return float('-inf')
        m = (l + r) // 2
        return max(
            self.query_max(idx * 2, l, m, ql, qr),
            self.query_max(idx * 2 + 1, m + 1, r, ql, qr)
        )

def solve():
    n = int(input())
    p = list(map(int, input().split()))
    q = int(input())

    pos = [0] * (n + 1)
    for i, v in enumerate(p):
        pos[v] = i

    st = SegTree(pos)

    def check(l, r):
        mn = st.query_min(1, 0, n - 1, l, r)
        mx = st.query_max(1, 0, n - 1, l, r)
        return mn < mx

    out = []
    for i in range(q):
        l, r = map(int, input().split())
        l -= 1
        r -= 1
        if check(l, r):
            out.append("YES")
        else:
            out.append("NO")

        if (i + 1) % 10 == 0:
            sys.stdout.write("\n".join(out) + "\n")
            sys.stdout.flush()
            out = []

    if out:
        sys.stdout.write("\n".join(out) + "\n")
        sys.stdout.flush()

if __name__ == "__main__":
    solve()
```代码中的核心思想是将排列转换为位置数组，其中每个值映射到其索引。 这将原来的“段内的值分离”问题转换为“段内的位置范围”问题。 线段树允许我们提取任何值区间内的值之间的最小和最大位置，并且检查简化为验证位置跨度是否是非退化的。 

一个微妙的实现细节是对查询边界进行零索引，并确保线段树是基于值位置而不是值本身构建的。 这种反转使得预处理后每个查询的条件检查时间为 O(1)。 

## 工作示例

 ### 示例 1

 考虑一个小排列 p = [3, 1, 2, 4] 和查询 [1, 3]。 

| 步骤| 我| r | 百万 | MX | 检查结果 |
 | --- | --- | --- | --- | --- | --- |
 | 初始化| 1 | 3 | 1 | 3 | mn < mx |

 位置 1 处的最小值为 1，位置 0 处的最大值为 3，因此该段包含允许有效阈值分割的交错位置。 

这证实了只要位置极值没有折叠成单个结构，算法就会检测到可分离性。 

### 示例 2

 取p = [2, 3, 1, 4, 5]，查询[2, 4]。 

| 步骤| 我| r | 百万 | MX | 检查结果 |
 | --- | --- | --- | --- | --- | --- |
 | 初始化| 2 | 4 | 1 | 4 | mn < mx |

 这里段中的值跨度很大，并且它们的位置不相同，因此存在有效的分区。 

这表明该条件捕获全局可分离性而不是局部排序。

 ## 边缘情况

 长度为 2 的最小段总是会通过，因为任何两个不同的值都可以由它们之间的阈值分隔开。 该算法处理此问题是因为 mn 和 mx 在长度为 2 的置换段中始终不同。 

完全反转或高度交错的段（例如较大范围内的 [4,3,2,1]）会失败，因为位置极值以阻止任何阈值分裂的方式崩溃。 线段树检查正确地检测到任何有效分区的位置结构是否退化。 

包含值连续但位置分散的值的段可以得到正确处理，因为位置映射将值顺序转换为结构范围查询，而不是依赖于原始数组中的邻接关系。
