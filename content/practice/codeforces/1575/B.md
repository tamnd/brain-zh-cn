 ## 解决方案
 ## 问题理解

 我们想要放置一个圆形游乐园，使其接触原点。 如果公园有半径$r$，那么它的中心必须恰好位于$r$距原点的单位，因为原点位于公园的边界上。 

每个鸟类栖息地都是平面上的一个点。 如果栖息地位于所选圆圈的内部或边界上，则该栖息地被视为被覆盖。 在所有接触原点的圆中，我们需要最小的半径，使得至少$k$要覆盖的栖息地。 

输入最多包含$10^5$栖息地。 任何比较所有点对或显式搜索所有可能的圆心的算法都将立即被排除。 甚至一个$O(n^2)$程序将需要大约$10^{10}$最坏情况下的操作。 目标复杂度必须接近$O(n \log n)$每个主要阶段。 

几何约束是有趣的部分。 中心不是任意的。 对于固定半径$r$，圆心限制为以原点为圆心、半径为半径的圆$r$。 这将问题转换为一维角度问题。 

一些边缘情况很容易被错误处理。 

考虑原点的栖息地：```
1 1
0 0
```正确答案是$0$。 什么时候$r=0$，唯一可能的中心也是原点，栖息地被覆盖。 盲目除以的决策程序$r$会崩溃或产生 NaN。 

考虑精确距离的栖息地$2r$从原点。 例如：```
1 1
2 0
```最小半径为$1$。 相应的角度间隔折叠为单个角度。 使用严格的不平等而不是包容性的不平等会错误地拒绝这种情况。 

考虑跨过的区间$0$-角边界。 假设一个栖息地生成一个区间$350^\circ$到$10^\circ$。 将角度视为普通线段会丢失包裹部分并减少重叠部分。 

## 方法

 蛮力的观点是固定半径$r$，枚举候选中心，计算覆盖了多少个栖息地，然后对$r$。 困难在于，中心可能是连续圆上的任意点，因此有无限多个候选点。 即使我们积极地离散化，结果也不会准确。 

关键的观察是对于固定半径$r$，中心被限制在圆内$$|C| = r.$$取一处栖息地$P$。 我们询问哪些职位$C$盖住它。 条件是$$|P - C| \le r.$$自从$C$已经位于圆上$|C|=r$，有效中心在该圆上形成一条弧。 每个栖息地贡献一个角间隔。 我们只需要知道某个角是否至少包含在$k$间隔。 

这将几何问题转化为经典的圆上最大重叠问题。 

固定半径要么可行，要么不可行。 如果半径$r$有效，每个更大的半径也有效。 这种单调性允许对答案进行二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解中心搜索 | 指数/连续状态 | 大| 不可能|
 | 二分查找+区间扫描 |$O(\log A \cdot n \log n)$|$O(n)$| 已接受 |

 这里$A$是半径的搜索范围。 

## 算法演练

 ### 一个栖息地的几何形状

 让栖息地成为$P=(x,y)$，并让$$d = |P|.$$对于固定半径$r>0$，中心是$$C = r(\cos\phi,\sin\phi).$$当栖息地被覆盖时$$|P-C| \le r.$$两边平方：$$d^2 + r^2 - 2rd\cos(\phi-a) \le r^2,$$在哪里$a$是极角$P$。 

化简后：$$\cos(\phi-a) \ge \frac{d}{2r}.$$如果$d>2r$，没有角度满足这个不等式。 

否则，$$|\phi-a| \le \arccos\!\left(\frac{d}{2r}\right).$$所以栖息地贡献了一个以角度为中心的角度间隔$a$。 

### 二分查找可行性检查

 1.如果$r=0$，计算有多少个栖息地正好位于原点。 半径是可行的当且仅当计数至少为$k$。 
2. 对于每个栖息地，计算$d=\sqrt{x^2+y^2}$。 
3.如果$d>2r$，这个栖息地永远无法被覆盖，也没有任何贡献。 
4. 如果$d=0$，区间覆盖整个圆。 增加全局基础计数器。 
5. 否则计算$$\alpha=\arccos\!\left(\frac{d}{2r}\right).$$有效的中心角是$$[a-\alpha,\ a+\alpha].$$1. 将每个循环间隔转换为扫描事件。 间隔交叉$0$弧度分为两个普通间隔。 
2. 按角度对所有事件进行排序。 在以相同角度发生结束事件之前处理开始事件。 
3. 扫描期间，保持当前重叠计数加上整圆间隔数。 如果最大重叠达到$k$， 半径$r$是可行的。 
4.二分查找最小可行半径。 

### 为什么它有效

 对于固定半径$r$，每个栖息地与覆盖它的中心位置集完全对应。 上面的推导将该集合转换为圆上的角度间隔$|C|=r$。 中心角至少覆盖$k$栖息地当且仅当该角度至少属于$k$间隔。 扫描精确计算最大间隔重叠。 

可行性谓词是单调的。 增加半径会扩大每组可行的中心位置，而不会缩小它。 因此二分查找$r$找到最小可行半径。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    twopi = 2.0 * math.pi
    eps = 1e-12

    def check(r):
        if r < eps:
            cnt = 0
            for x, y in pts:
                if x == 0 and y == 0:
                    cnt += 1
            return cnt >= k

        base = 0
        events = []

        for x, y in pts:
            d = math.hypot(x, y)

            if d > 2.0 * r + 1e-10:
                continue

            if d < 1e-12:
                base += 1
                continue

            ratio = d / (2.0 * r)
            if ratio > 1.0:
                ratio = 1.0

            alpha = math.acos(ratio)
            a = math.atan2(y, x)

            l = a - alpha
            rr = a + alpha

            l %= twopi
            rr %= twopi

            if l <= rr:
                events.append((l, 1))
                events.append((rr, -1))
            else:
                events.append((0.0, 1))
                events.append((rr, -1))
                events.append((l, 1))
                events.append((twopi, -1))

        events.sort(key=lambda e: (e[0], -e[1]))

        cur = base
        best = cur

        for _, typ in events:
            cur += typ
            if cur > best:
                best = cur

        return best >= k

    lo = 0.0
    hi = 200000.0

    for _ in range(50):
        mid = (lo + hi) / 2.0
        if check(mid):
            hi = mid
        else:
            lo = mid

    print("{:.10f}".format(hi))

solve()
```二分查找维护一个包含最佳半径的区间。 五十次迭代足以实现以下误差$10^{-4}$。 

功能`check(r)`实现几何缩减。 每个栖息地都成为一个有角度的间隔。 栖息地远于$2r$从原点无法做出贡献，因为圆$|C|=r$永远不会进入他们的半径-$r$覆盖盘。 

最微妙的实现细节是处理环绕的间隔$0$弧度。 这些间隔在扫描之前被分成两个普通间隔。 另一个微妙之处是事件顺序。 开始事件在结束事件之前以相同的角度处理，这可以正确处理端点重合的间隔。

 ## 边缘情况

 ### 半径零

 输入：```
3 2
0 0
0 0
5 0
```唯一可能的中心是原点。 两个栖息地已经被覆盖，所以答案是准确的$0$。 

该算法在内部的特殊分支中处理这个问题`check(r)`。 不执行三角计算。 

### 栖息地恰好在远处$2r$输入：```
1 1
10 0
```对于半径$5$，我们得到$$\frac{d}{2r} = 1, \qquad \alpha = \arccos(1) = 0.$$该间隔折叠成一个角度。 扫描仍会正确计数，因为开始事件是在结束事件之前处理的。 

### 跨越角度边界的间隔

 输入：```
2 1
100 1
100 -1
```其中一个点的有效角度间隔可能与附近的角度相交$2\pi$回到附近的角度$0$。 该算法将这些间隔分为$$[l, 2\pi]$$和$$[0, r].$$然后扫描会看到正确的重叠结构。 边界处不会丢失覆盖范围。
