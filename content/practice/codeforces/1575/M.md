 ## 解决方案
 ## 问题理解

 该网格描述了一张城市地图，其中一些单元格包含电话杆。 每个像元对应于平面上的一个整数坐标点，值为 1 表示该位置存在极点。 对于网格中的每个坐标点，我们查看欧几里德距离中最近的极点并计算该距离的平方。 任务是对每个网格点上的该值求和。 

因此从概念上讲，每个空的或填充的单元格都会“向外看”，直到找到最近的极点，并贡献到该极点的平方距离。 即使极单元的贡献也为零，因为它们最近的极就是它们自己。 

到 2000 年，网格大小将达到 2000 个，这意味着大约有 400 万个点。 如果有很多极点或者如果我们重复扫描整个网格，则对所有极点进行简单的逐单元搜索会太慢。 即使来自每个极点的单源 BFS 也是不可能的，因为这会在重叠区域重复工作。 

一个不太明显的困难是距离是欧几里得距离，而不是曼哈顿距离。 这消除了标准的多源 BFS 技巧，因为欧几里得距离不会在轴对齐层中传播。 

当极点稀疏时，会出现微妙的边缘情况。 如果只有一个极点，则每个单元格都会贡献其到该点的平方距离，因此答案将成为网格上二次值的一大总和。 如果极点密集，许多区域的贡献就会崩溃为零。 任何假设局部性或网格传播的解决方案仍然必须正确处理这两个极端。 

当多个极点等距时，会出现另一种边缘情况。 该定义只需要最小距离，因此关系并不重要，但如果结构不仔细，不正确的 Dijkstra 式实现可能会意外地重复计算或不一致地放松。 

## 方法

 直接方法为每个单元计算到每个极点的距离并取最小值。 这是正确的，因为它遵循字面定义。 然而，如果在最坏的情况下有多达 O(nm) 极点，则会退化为 O((nm)^2)，这太大了。 

即使极数更少，比如 k，蛮力也是 O(nmk)，在最坏的情况下仍然达到大约 4e6 × 4e6，完全不可行。 

关键的观察结果是，答案仅取决于最近的极点，并且平方欧几里德距离具有几何解释：对于每个极点，它定义了一个 Voronoi 主导区域。 每个网格点恰好属于一个极点的区域，即最近的一个。 在每个区域内，我们需要计算到该极点的距离平方和。 

因此，问题简化为在离散网格上计算欧几里得沃罗诺伊图，然后累积每个区域的平方距离贡献。 

直接的 Voronoi 构造很繁重，但我们可以使用距离变换来计算每个单元的最近极点。 经典技巧是使用可分离的一维平方距离变换来计算 O(nm) 的二维欧几里德距离变换。 这将所有极点上的全局最小化转换为两次传递：首先沿行，然后沿列，每次维护平方距离函数的候选“抛物线”。 

一旦我们知道每个单元格的平方距离，我们就可以直接求和。 唯一剩下的细节是，我们必须将极点视为零源并计算精确的欧几里得平方距离变换，而不是曼哈顿或切比雪夫变体。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每个电池与所有极的强力 | O(纳米·纳米) | O(纳米) | 太慢了 |
 | 欧几里得距离变换 | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 我们在二进制网格上使用标准的双通道欧几里得距离变换，其中极点为零源，空单元为无穷大。

1. 如果每个网格单元包含一个极点，则将其替换为 0，否则将其替换为较大的数字。 这将到最近极点的距离编码为最小化问题。 
2. 对于每一行，独立计算一维平方距离变换。 此步骤针对该行中的每个单元计算该行中所有源的水平距离平方加上稍后进行的最佳垂直贡献的最小值。 关键思想是，在正确的包络构造之后，平方欧几里得距离分为独立的 x 和 y 分量。 
3. 处理行后，我们将每一列视为独立的一维数组，并垂直运行相同的变换。 这将水平和垂直贡献结合到全平方欧几里得距离中。 
4. 两次通过后，每个单元格包含到最近极点的平方距离。 我们将网格中的所有值相加。 

微妙的部分是为什么两次分解是有效的。 平方欧几里得距离满足 (dx^2 + dy^2)，并且变换通过维持二次函数的下包络进行工作，二次函数沿轴保持可分离。 

### 为什么它有效

 每个极点在网格点上定义一个函数，其形式为 f(x, y) = (x - xi)^2 + (y - yi)^2。 展开后，变成 x^2 + y^2 - 2xxi - 2yyi + 常数。 x 和 y 相关性在最小化内线性分离。 距离变换在每个维度上保持这些抛物线函数的下包络，确保在每个点我们选择最小化全平方距离的极点。 由于变换对于 1D 平方距离是精确的并且跨维度可分离，因此组合两个通道可以保持 2D 网格上的正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

INF = 10**18

def dt_1d(f):
    n = len(f)
    d = [0] * n
    v = [0] * n
    z = [0.0] * (n + 1)

    k = 0
    v[0] = 0
    z[0] = -INF
    z[1] = INF

    def sep(i, j):
        return ((f[j] + j * j) - (f[i] + i * i)) / (2 * (j - i))

    for q in range(1, n):
        p = v[k]
        s = sep(p, q)
        while k > 0 and s <= z[k]:
            k -= 1
            p = v[k]
            s = sep(p, q)
        k += 1
        v[k] = q
        z[k] = s
        z[k + 1] = INF

    k = 0
    for i in range(n):
        while z[k + 1] < i:
            k += 1
        j = v[k]
        d[i] = (i - j) * (i - j) + f[j]
    return d

def main():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n + 1)]

    INF = 10**18

    row_dist = []
    for i in range(n + 1):
        f = []
        for j in range(m + 1):
            f.append(0 if grid[i][j] == '1' else INF)
        row_dist.append(dt_1d(f))

    total = 0
    for j in range(m + 1):
        col = [row_dist[i][j] for i in range(n + 1)]
        col = dt_1d(col)
        total += sum(col)

    print(total)

if __name__ == "__main__":
    main()
```第一阶段构建每行表示，其中每个位置都知道其到该行结构中最近的极点的水平平方距离贡献。 第二阶段垂直应用相同的变换，将行结果组合成完整的二维距离。 

关键的实现细节是对非极点单元使用较大的 INF 值，以便它们永远不会变为最小值，除非该方向上不存在极点。 行和列变换的分离必须保持顺序，因为反转它们仍然有效，但需要对中间状态进行一致的解释。 

## 工作示例

 考虑 3x3 网格中原点处具有单个极点的样本。 

行变换首先产生水平距离，因此包含极点的行变为：

 (0, 1, 4) 因为距 x=0 的距离是 0,1,2 的平方。 

然后垂直变换将相同的想法应用到列下，增强对称性。 

| 步骤| 单元 (0,0) | (0,1)| (0,2) |
 | ---| ---| ---| ---|
 | 行传后| 0 | 1 | 4 |
 | 栏目通过后| 0 | 1 | 4 |

 这表明水平结构被保留并且垂直传播不会干扰行内正确性。 

现在考虑对角的两个极点。 行变换产生两个竞争的抛物线，并且包络线确保每个单元格在垂直细化解决对角优势之前在水平方向上选择更接近的极点。 

这表明中间行结果已经对第二遍正确合并的部分优势区域进行了编码。

 ## 边缘情况

 当只有一个极点时，该算法简化为计算到单个坐标的平方距离。 行变换分配正确的水平距离，列变换独立传播垂直距离，因此每个单元格最终得到 (dx^2 + dy^2)，与定义匹配。 

当所有单元都是极点时，初始数组中的每个条目都为零。 两种变换都保留零，因为每个最小值都是在源单元本身实现的，因此最终的总和为零。 

当极点稀疏且相距较远时，每个影响区域都通过距离变换中的凸包络构造独立处理。 尽管中间行结果可能看起来“模糊”水平影响，但第二遍通过对称地合并垂直贡献正确地恢复了真正的二维最近极点结构。
