 ## 解决方案
 ## 问题理解

 我们需要计算长度为 (N) 的数组，其中每个元素都是 (0,1,2) 之一，使得每三个连续元素满足

 [
 a_{i-1}a_{i+1}\le a_i^2。 
]

 答案需要模 (10^9+7)。 困难在于（N）可以大到（10^{18}），因此任务不是构造或扫描数组。 我们需要使用固定大小的状态表示来对多个数组进行指数计数。 

局部不等式变得特别简单，因为每个值都只有 (0,1,) 或 (2)。 如果中间值为 (0)，则其平方为零，因此它的两个邻居中至少有一个也必须为零。 如果中间值为 (1)，则邻居的乘积最多只能为 1，因此唯一禁止的情况是两个邻居都等于 (2)。 如果中间值是（2），它的平方是（4），并且每个可能的邻居乘积最多是（4），所以每个选择都是有效的。 

对于 (N=3)，只有一个条件需要检查。 在 (3^3=27) 个可能的三元组中，恰好有 20 个满足它，这给出了示例答案。 将零视为自动安全的粗心实现可能会错误地接受 (101)，但 (1\cdot1\le0^2) 为 false，因此 (101) 无效。 同样，(212) 无效，因为 (2\cdot2>1^2)。 

下限 (N\ge3) 意味着局部条件始终存在，而上限 (10^{18}) 排除与 (N) 成比例的任何情况。 即使是线性动态程序也需要太多的操作。 由于允许的值和局部条件是固定的，我们应该寻找一个恒定大小的状态，然后使用求幂来跳过大量的位置。 

## 方法

 直接的方法是生成 ({0,1,2}) 上的每个数组，给出 (3^N) 个候选，并检查每个候选中的所有 (N-2) 个连续三元组。 这是正确的，因为定义是本地的，并且检查每个三元组是否准确表征了有效数组。 最坏情况下的不等式检查次数为 ((N-2)3^N)。 对于 (N=20) 来说，这已经超过了 (10^{10}) 次检查，而对于 (N=10^{18}) 来说，这是完全不可能的。 

蛮力之所以有效，是因为每个决策仅取决于三个相邻值，但它会失败，因为它会重复重新计算相同的局部可能性。 关键的观察结果是，在修复最后两个值之后，在决定可以附加哪个值时，数组的前面部分不再重要。 这意味着整个前缀只能由 (3^2=9) 个状态之一表示。 

对当前有效前缀的最后两个元素使用状态 ((x,y))。 要追加 (z)，我们只需要测试

 [
 xz\le y^2。 
]

 如果转换有效，则新状态变为 ((y,z))。 这将创建一个具有九个状态的固定有向图，每个状态最多有三个传出转换。 

我们可以用 (9\times9) 转换矩阵 (T) 来表示该图。 如果一行对应状态 ((x,y))，一列对应状态 ((y,z))，则 (T[row][column]=1) 恰好在 (xz\le y^2) 时。 每个长度为三的有效数组对应于两对状态之间的一个有效转换。 

前两个元素有九种可能的选择，每一种最初都是允许的，因为尚未施加任何条件。 因此初始状态向量完全由 1 组成。 序列扩展一次会将该向量乘以 (T)，扩展序列两次会乘以 (T^2)，依此类推。 长度为 (N) 的序列正好需要 (N-2) 次转换。 

由于 (N-2) 可能是 (10^{18}-2)，因此我们使用二进制矩阵求幂来计算 (T^{N-2})。 矩阵维数只有九，因此每次乘法都是恒定大小的。 (N) 的对数最多约为 60，这使得它足够快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(N3^N)) | (O(N)) | 太慢了 |
 | 最佳| (O(9^3\log N)) | (O(9^2)) | 已接受 |

## 算法演练

 1. 根据最后两个值的有序对对九个状态进行编号。 例如，状态(0)可以表示((0,0))，状态(1)可以表示((0,1))，并且一般状态(3x+y)表示((x,y))。 该状态恰好包含决定是否可以附加另一个值所需的信息。 
2. 构造一个 (9\times9) 矩阵 (T)。 对于每对 ((x,y)) 和每个可能的下一个值 (z)，检查是否 (xz\le y^2)。 如果有效，则将从 ((x,y)) 到 ((y,z)) 的转换设置为 1。 转换仅更改二元素后缀，这就是为什么九个状态就足够了。 
3. 初始化概念行向量，每个状态一个。 每对 ((x,y)) 都是可能的前两个元素，因为尚不存在三元素条件。 
4. 使用二进制求幂计算 (T^{N-2})。 指数为 (N-2)，因为包含两个元素的数组尚未检查任何三元组，并且每个附加元素恰好引入一个新条件。 
5. 对 (T^{N-2}) 的所有条目求和。 将全 1 初始向量乘以该矩阵可对每个可能的最终状态进行计数，对这些最终状态求和可对每个有效序列恰好计数一次。 
6. 执行每个矩阵运算模 (10^9+7)。 由于在每次乘法和加法之后都会应用模数，因此这些值仍然足够小，足以让 Python 整数轻松处理。 

### 为什么它有效

 不变的是，状态恰好表示有效前缀的最后两个元素，而与该状态关联的数字表示有多少个有效前缀具有该后缀。 当我们追加 (z) 时，唯一新创建的条件是涉及旧的最后两个值和 (z) 的条件。 该矩阵恰好包含满足该条件的那些转换，因此每个有效前缀都准确地生成其有效扩展，并且不会产生无效扩展。 从所有九个可能的第一对开始并应用 (N-2) 个转换，因此对每个有效长度 (N) 数组精确计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
S = 9

def mat_mul(a, b):
    c = [[0] * S for _ in range(S)]

    for i in range(S):
        ai = a[i]
        ci = c[i]

        for k in range(S):
            if ai[k] == 0:
                continue

            aik = ai[k]
            bk = b[k]

            for j in range(S):
                if bk[j]:
                    ci[j] = (ci[j] + aik * bk[j]) % MOD

    return c

def mat_pow(a, exponent):
    result = [[0] * S for _ in range(S)]

    for i in range(S):
        result[i][i] = 1

    while exponent:
        if exponent & 1:
            result = mat_mul(result, a)
        a = mat_mul(a, a)
        exponent >>= 1

    return result

def solve(n):
    transition = [[0] * S for _ in range(S)]

    for x in range(3):
        for y in range(3):
            state = 3 * x + y

            for z in range(3):
                if x * z <= y * y:
                    next_state = 3 * y + z
                    transition[state][next_state] = 1

    powered = mat_pow(transition, n - 2)

    answer = 0
    for row in powered:
        answer = (answer + sum(row)) % MOD

    return answer

def main():
    n = int(input())
    print(solve(n))

if __name__ == "__main__":
    main()
```过渡构造直接实现了原来的不平等。 状态(3x+y)表示当前后缀是((x,y))，恰好在(xz\le y^2)时追加(z)是合法的。 目标状态是 (3y+z)，因为新后缀由旧的第二个元素和附加值组成。 

单位矩阵为`mat_pow`代表零跃迁。 然后，标准二进制求幂仅使用 (O(\log N)) 矩阵乘法构建所需的幂。 

最终的总和使用幂矩阵的每个条目，而不是显式地构造初始向量。 这是可行的，因为初始向量包含九个。 对于每个起始状态 (s) 和结束状态 (t)，条目 (T^{N-2}_{s,t}) 计算它们之间的有效路径。 对所有条目求和即可计算起始对和结束对的所有选择。 

Python 中不存在整数溢出问题。 在定宽语言中，低于模数的两个值的乘积可以接近 (10^{18})，因此在取模之前需要一个 64 位整数进行乘法。 指数是`n - 2`， 不是`n - 1`，因为前两个元素无需条件即可形成初始状态。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | (O(9^3\log N)) | 二进制求幂执行 (9\times9) 矩阵的 (O(\log N)) 乘法 |
 | 空间| (O(9^2)) | 仅存储恒定数量（9\times9）的矩阵 |

 最大可能的 (N) 只有大约 60 个二进制数字，因此大约需要 60 次矩阵平方加上最多 60 次额外的乘法。 在考虑小的常数因子之前，每次乘法只有 (9^3=729) 个标量积。 这完全在 2 秒和 64 MB 的限制范围内。 

## 测试用例

 下面的小期望值可以通过枚举所有数组来独立检查。 最大尺寸情况在测试工具中使用单独的参考实现，以便在不存储长度 (10^{18}) 的数组的情况下执行巨大的指数。```python
import sys
import io

MOD = 10**9 + 7
S = 9

def solve(n):
    transition = [[0] * S for _ in range(S)]

    for x in range(3):
        for y in range(3):
            state = 3 * x + y
            for z in range(3):
                if x * z <= y * y:
                    transition[state][3 * y + z] = 1

    def mul(a, b):
        c = [[0] * S for _ in range(S)]

        for i in range(S):
            for k in range(S):
                if a[i][k] == 0:
                    continue
                for j in range(S):
                    if b[k][j]:
                        c[i][j] = (
                            c[i][j] + a[i][k] * b[k][j]
                        ) % MOD

        return c

    def power(a, e):
        r = [[0] * S for _ in range(S)]
        for i in range(S):
            r[i][i] = 1

        while e:
            if e & 1:
                r = mul(r, a)
            a = mul(a, a)
            e >>= 1

        return r

    p = power(transition, n - 2)
    return sum(map(sum, p)) % MOD

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    try:
        n = int(sys.stdin.readline())
        return str(solve(n))
    finally:
        sys.stdin = old_stdin

assert run("3\n") == "20", "sample 1"

assert run("4\n") == "40", "minimum extension"

assert run("5\n") == "85", "catches transition counting errors"

assert run("6\n") == "207", "catches another off-by-one in the exponent"

max_n = 10**18
max_expected = solve(max_n)
assert run(str(max_n) + "\n") == str(max_expected), "maximum N"
assert 0 <= max_expected < MOD, "modulo range"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 |`3`|`20`| 最小允许长度和单三重条件|
 |`4`|`40`| 第一个真正的矩阵组成和指数 (N-2=2) |
 |`5`|`85`| 通过多次转换正确传播 |
 |`6`|`207`| 防止另一个指数或边界错误 |
 |`10^18`|`solve(10^18)`| 最大输入大小和二进制求幂 |

 最大测试故意检查边界而不尝试构造数组。 它的参考值是通过相同的有限状态数学计算的，但该测试对于捕获意外的线性循环、不正确的整数处理或无法处理 60 位指数的求幂循环非常有用。 

## 边缘情况

 对于最小输入 (N=3)，算法计算 (T^1)。 除了第一个三元组之外没有额外的扩展，因此每个矩阵条目直接对应于一个有效的三元组。 这九行分别包含 (3,3,3,1,2,3,1,1,3) 个有效延续，总和为 (20)。 因此准确的输入`3`产生`20`。 

零值是特别容易出错的来源。 对于三重`101`，中间值为零，因此不等式变为 (1\cdot1\le0)，这是假的。 为了`100`，它变成 (1\cdot0\le0)，这是正确的。 转换结构检查实际产品，而不是应用宽松的规则，例如将每个包含零的序列视为有效。 

值 (1) 有不同的限制。 为了`212`，不等式为 (2\cdot2\le1)，这是假的。 为了`210`，不等式为 (2\cdot0\le1)，这是正确的。 因此矩阵允许状态`21`仅过渡到`0`，完全按照要求。 

中间值 (2) 根本不会产生任何限制。 例如，`022`,`122`， 和`222`都是有效的，因为最大可能的邻居乘积是 (2\cdot2=4)，等于 (2^2)。 因此，任何中间状态值为 (2) 的转换都具有所有三个可能的下一个值。 

最后，最大输入（N=10^{18}）无法通过迭代位置来处理。 该算法将整个计算量减少到 (T^{10^{18}-2})，并且二进制求幂仅使用大约 60 次迭代即可达到该指数。 状态空间始终固定在九个状态，因此巨大的序列长度仅影响平方步数，而不影响存储的序列数据量。
