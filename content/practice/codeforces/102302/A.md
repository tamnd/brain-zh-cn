 ## 解决方案
 ## 问题理解

 我们有一排 (N) 栋建筑物，其中建筑物 (i) 的高度为 (h_i)。 拉里奥从一栋选定的建筑物开始，并精确地跳跃一跳。 如果他从建筑物 (i) 开始，跳跃最多可以向右覆盖 (h_i) 个位置，因此如果没有障碍，他的目的地将是

 [
 \min(i+h_i,N)
 ]

 使用基于 1 的索引。 

在穿过该间隔时，拉里奥撞上了第一座建筑物，其高度严格大于他的起始建筑物的高度。 如果那座较高的建筑物位于位置 (j)，他无法到达并降落在 (j-1)。 所需的输出是行驶的距离，而不是目的地的索引。 因此，如果在预定目的地之前没有更高的建筑物，则答案是预定目的地减去 (i)。 如果第一座较高的建筑物位于 (j)，则答案为 (j-i-1)。 

例如，高度为 (5,2,2,3,6,2)，从建筑物 1 开始，最大目的地为建筑物 6。建筑物 5 的高度为 6，比起始高度 5 更高，因此 Lario 降落在建筑物 4 上。距离为 (4-1=3)，这是样本输出的第一个值。 

约束 (N\le 10^5) 排除了重复扫描数组的大部分以查找每个起始位置的算法。 当 (N=10^5) 时，二次算法可以在最坏情况下执行大约 (N(N-1)/2)，大致为 (5\cdot10^9) 的比较。 这远远超出了 2 秒的限制所能容纳的范围。 我们需要一个接近线性时间的解决方案。 

有几种边缘情况可能会使看似合理的实现变得不正确。 第一个是等高。 相同的建筑物不会引起碰撞，因为障碍物必须严格更高。 用于输入`2 2 2`，正确的输出是`2 1 0`。 搜索使用`>=`而不是`>`会错误地停在下一栋大楼。 

第二种极端情况是较高的建筑物正是预期的目的地。 用于输入```
2
1 2
```第一栋建筑可以尝试到达 2 号建筑，但 2 号建筑更高，因此 Lario 降落在 1 号建筑上。正确的输出是`0 0`。 粗心的实现仅严格搜索目的地之前的位置会错误地报告`1`对于第一座建筑。 

第三种情况发生在存在更高的建筑物，但位于跳跃范围之外时。 用于输入```
4
2 1 1 3
```从建筑物 1 开始只允许跳跃到建筑物 3。必须忽略位置 4 处较高的建筑物，因此第一个答案是`2`。 正确的输出是`2 1 0 0`。 搜索下一个更高的建筑物而不检查它是否位于允许的范围内会给出错误的结果。 

最终的边界情况是单个建筑物。 为了```
1
7
```无处可移动，所以输出是`0`。 这也是一个有用的检查，以确保目标计算和堆栈查找正确处理最终位置。 

## 方法

 直接的解决方案是独立处理每个起始位置。 对于构建 (i)，首先计算跳跃可以到达的最远位置。 然后按顺序检查建筑物 (i+1,i+2,\ldots)，直到找到严格更高的建筑物或达到跳跃限制。 如果第一座较高的建筑物位于 (j)，则返回 (j-i-1)。 否则返回完整的可能跳跃距离。 

这种蛮力方法是正确的，因为游戏仅取决于跳跃路径上遇到的第一个较高的建筑物。 从左到右扫描可以准确地找到该建筑物，并在跳跃限制处正确停止，从而忽略本次跳跃期间无法到达的障碍物。 

问题在于重复工作量。 考虑 (N=10^5) 座具有相同高度和足够大跳跃范围的建筑物。 没有发生碰撞，因此对第一座建筑物的扫描几乎检查整个后缀，对第二座建筑物的扫描几乎检查整个剩余后缀，依此类推。 检查位置数量可达

 [
 1+2+\cdots +(N-1)=\frac{N(N-1)}2=4,999,950,000。 
]

 蛮力之所以有效，是因为每个答案都是由第一个更高的建筑物决定的，但是当许多起始位置询问关于重叠后缀的基本相同的问题时，它就会失败。 

关键的观察是，对于每个建筑物，我们实际上不需要搜索其整个跳跃间隔。 我们只需要右边最近的、严格意义上更高的建筑物。 将此位置称为下一个更大的元素。 如果最近的较高建筑物已经超出了跳跃限制，则所有其他较高建筑物的距离甚至更远，因此跳跃内不会发生碰撞。 如果在限制范围内，则自动为第一次碰撞。 

这将问题转换为标准的下一个更大的元素计算。 单调堆栈可以在 (O(N)) 时间内为每个位置找到最近的严格更大的建筑物。 我们从右到左处理数组。 该堆栈包含右侧的候选位置，其高度尚未被更近的建筑物消除。 

假设我们正在处理建筑物 (i)。 高度小于或等于 (h_i) 的任何堆栈位置都不能是 (i) 的下一个更大的建筑物，因为建筑物 (i) 本身至少同样高，并且更接近左侧的任何位置。 这样的职位被弹出。 删除所有此类位置后，堆栈顶部（如果存在）是距离右侧最近且高度严格大于 (h_i) 的位置。 

比较的是`<=`， 不是`<`，因为等高不是碰撞。 这是使堆栈代表严格更高的建筑物的细节。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | (O(N^2)) | (O(1)) 辅助 | 太慢了|
 | 最佳| (O(N)) | (O(N)) | 已接受 |

 ## 算法演练

 1. 读取建筑物的数量和高度。 我们在内部使用基于零的索引，因为 Python 数组自然使用它们，而最终距离可以直接根据索引差异计算。 
2. 创建数组`next_greater`在哪里`next_greater[i]`将包含右侧最近建筑物的索引，其高度严格大于`h[i]`。 使用`-1`当不存在这样的建筑物时。 
3. 从右向左扫描建筑物，同时维护一堆候选索引。 加工前位置`i`，当高度小于或等于时，重复移除栈顶`h[i]`。 

被拆除的建筑永远不能解决位置问题`i`。 如果其高度较小，则不能成为障碍物。 如果它的高度相等，它也不能成为障碍物，因为只有严格较高的建筑物才会导致碰撞。 在之后，它也不再需要作为更左的候选人`i`已被处理，因为`i`更接近并且至少一样高。 
4. 在弹出步骤之后，如果堆栈非空，则堆栈顶部是右侧最近的严格更高的建筑物。 将该索引存储在`next_greater[i]`，然后推`i`入栈，以便它可以成为更左边位置的候选者。 
5. 对于每个起始位置`i`，在不考虑碰撞的情况下计算跳跃可以到达的最远建筑物。 使用从零开始的索引，这是

 [
 目标=\min(i+h_i,N-1)。 
]

 不发生碰撞的最大距离为`target - i`。 
6.看`j = next_greater[i]`。 如果`j != -1`和`j <= target`，那么第一座较高的建筑物位于跳跃范围内。 拉里奥撞上大楼`j`并降落在`j-1`，所以答案是

 [
 j-i-1。 
]
 7. 如果没有下一个更大的建筑物，或者下一个更大的建筑物超出了`target`，在这次跳跃过程中没有发生碰撞。 答案很简单`target - i`。 

### 为什么它有效

 对于每个位置 (i)，堆栈计算都会给出最近的位置 (j>i) 和 (h_j>h_i)，或者报告不存在。 这正是无限向右方向上第一次可能的碰撞。 如果 (j) 在允许的跳跃范围内，则根据最近更大的定义，在 (j) 之前不会出现更高的建筑物，因此降落在 (j-1) 是正确的。 如果 (j) 超出允许的范围，则每个较高的建筑物也在该范围之外，因此跳跃到达其预期目的地。 因此，每个答案都被正确确定。 

堆栈本身是线性的，因为每个索引只被压入一次，最多弹出一次。 该算法永远不需要重新访问已被淘汰的候选者。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    h = list(map(int, input().split()))

    next_greater = [-1] * n
    stack = []

    for i in range(n - 1, -1, -1):
        while stack and h[stack[-1]] <= h[i]:
            stack.pop()

        if stack:
            next_greater[i] = stack[-1]

        stack.append(i)

    ans = [0] * n

    for i in range(n):
        target = min(i + h[i], n - 1)
        j = next_greater[i]

        if j != -1 and j <= target:
            ans[i] = j - i - 1
        else:
            ans[i] = target - i

    print(*ans)

if __name__ == "__main__":
    solve()
```第一个循环构造下一个更大的数组。 从右到左的处理使得堆栈变得有用，因为每个可能的障碍`i`时已经考虑过`i`已达到。 

条件`h[stack[-1]] <= h[i]`移除较短且相等的建筑物。 仅使用`<`会错误地将相同高度视为障碍。 

目的地使用`n - 1`因为实现是零基础的。 原来的问题是`n`因此，第 3 栋建筑对应于索引`n - 1`。 

碰撞条件为`j <= target`， 不是`j < target`。 恰好位于预定目的地的较高建筑物仍然会导致碰撞。 在这种情况下`j - i - 1`正确地成​​为到障碍物前面的建筑物的距离。 

Python 中不存在整数溢出问题。 最大的相关索引表达式的量级为(10^5)，Python整数直接处理它。 

决赛`print(*ans)`产生所需的空格分隔输出。 该问题包含单个测试用例，因此不需要测试用例循环。

 ## 边缘情况

 单体建筑案例为```
1
7
```当处理位置 0 时，堆栈最初不包含任何内容，因此`next_greater[0]`是`-1`。 目标是`min(0+7,0)=0`, 给予`target-i=0`。 输出是`0`。 

对于相同的高度，请考虑```
3
2 2 2
```在位置 2 处，堆栈为空。 在位置 1 处，位置 2 处的建筑物的高度为 2，等于当前高度，因此`<=`条件弹出它。 因此，位置 1 没有下一个更大的建筑物。 位置 0 也会发生同样的情况。跳跃距离为 2、1 和 0，产生```
2 1 0
```这证实了平等绝不能被视为冲突。 

对于位于目的地的较高建筑物，请使用```
2
1 2
```对于位置 0，目标是位置 1，下一个更大的位置也是 1。`j <= target`，发生碰撞。 拉里奥降落在`j-1=0`，所以答案是`1-0-1=0`。 位置 1 已经是最终的建筑物，所以它的答案也是 0。输出是```
0 0
```边界条件通过非严格比较来处理`target`。 

对于超出允许范围的障碍物，使用```
4
2 1 1 3
```在位置 0 处，下一个更大的建筑物是位置 3，但其目标仅为位置 2，因为起始高度为 2。`3 > 2`，障碍物不能干扰这次跳跃。 算法返回`2-0=2`。 在位置 2 处，起始高度为 1，目标高度为位置 3，因此位置 3 处较高的建筑物在范围内，答案为`3-2-1=0`。 最终输出是```
2 1 0 0
```这说明了为什么仅计算下一个更大的位置是不够的。 在将该建筑物视为障碍之前，仍必须检查跳跃限制。
