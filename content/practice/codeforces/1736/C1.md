 ## 解决方案
 ## 问题理解

 我们被要求计算给定数组的所有连续子数组，其中每个元素至少与其在子数组中的位置一样大。 更具体地说，如果子数组从索引开始`l`并以索引结束`r`，该子数组的第一个元素必须至少为 1，第二个元素至少为 2，第三个元素至少为 3，依此类推。 这将原始数组转换为一种“高度要求”：子数组中的元素越多，每个元素就必须越大。 

输入由多个测试用例组成，每个测试用例包含最多 200,000 个元素的数组，并且所有测试用例的所有数组长度之和不超过 200,000。 这立即排除了任何数组长度呈二次方的解决方案。 单独检查所有子数组的暴力方法大约需要$n^2/2$每个数组的检查，可以达到$2 \cdot 10^{10}$最坏情况下的操作。 这在一秒的时间限制内远远超出了可行的范围。 因此我们需要一种线性或近线性的方法。 

当元素完全等于其子数组位置或元素小于其子数组位置时，会出现微妙的边缘情况。 例如，数组`[1,1,1]`只允许单元素子数组。 如果仅检查第一个或最后一个元素，简单的算法可能会错误地将较长的子数组视为有效，因此仔细注意位置相对要求至关重要。 

## 方法

 蛮力方法很简单：迭代所有可能的起始索引`l`，然后迭代所有可能的结束索引`r >= l`，并检查每个元素是否`a[l..r]`满足`a[l + i] >= i + 1`。 这种方法是正确的，因为它显式地检查每个子数组。 每个测试用例的复杂度为 O(n^2)，对于大型数组来说，速度慢得令人无法接受。 例如，与`n = 2 * 10^5`，我们会大致执行$2 \cdot 10^10$检查。 

更快解决方案的关键见解来自于将子数组条件转换为更简单的数字条件。 对于从以下位置开始的子数组`l`,定义一个新数组`c[i] = a[i] - (i - l + 1)`。 子数组是好的当且仅当所有元素`c[i]`是非负的。 当我们从左向右扩展子数组时，我们只需要跟踪最小的`c[i]`到目前为止所看到的。 什么时候`c[i]`变为负数，我们知道子数组不能超出这一点。 这相当于两指针或滑动窗口技术：从`l`， 延长`r`尽可能直到条件满足，然后计算从以下位置开始的所有子数组`l`并在转折点之前结束。 然后我们就可以移动`l`前进并继续，而不重新检查保证满足条件的元素。 

此观察将每个数组的复杂性从 O(n^2) 降低到 O(n)，因为每个索引最多被考虑两次：扩展时一次`r`还有一次在前进时`l`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(1) | O(1) | 太慢了|
 | 最佳| O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，读取数组长度`n`和数组`a`。 
2. 初始化变量`ans`到 0 来累积好的子数组的数量。 
3.使用两个指针`l`和`r`维持滑动窗口。 开始于`l = 0`和`r = 0`。 
4. 虽然`l < n`, 增量`r`只要`a[r] >= r - l + 1`。 这确保当前窗口中的每个元素都满足“基于位置”的要求。 
5. 添加`r - l`到`ans`，因为所有子数组都从`l`并在之前结束`r`是有效的。 区别`r - l`准确计算有多少个子数组源自`l`。 
6. 增量`l`。 如果`r < l`， 放`r = l`因为窗口不能缩小超过左指针。 
7. 继续，直到考虑了所有起始索引。 
8. 输出`ans`对于测试用例。 

为什么它有效：不变量是在算法中的任何一点，所有子数组`[l, r-1]`都很好，并且`r`是子数组不满足要求的第一个索引。 这保证了我们计算所有且仅有效的子数组。 每个元素最多评估两次，给出线性时间复杂度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    ans = 0
    r = 0
    for l in range(n):
        if r < l:
            r = l
        while r < n and a[r] >= r - l + 1:
            r += 1
        ans += r - l
    print(ans)
```我们初始化`r = 0`外循环结束`l`这样我们就可以有效地扩展正确的边界。 条件`if r < l: r = l`确保窗口永远不会变得无效`l`进步。 这`while`循环贪婪地扩展右边界，直到子数组不再满足位置条件。 最后，添加`r - l`计算从以下位置开始的所有子数组`l`每个起始索引的复杂度为 O(1)。
