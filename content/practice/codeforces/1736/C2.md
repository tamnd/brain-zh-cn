 ## 解决方案
 ## 问题理解

 我们被要求分析一个正整数数组并计算满足特定属性的子数组：子数组中的每个元素至少与其在该子数组中从 1 开始的位置一样大。 例如，在长度为 3 的子数组中，第一个元素必须至少为 1，第二个元素至少为 2，第三个元素至少为 3。 每个查询都会修改数组的单个元素，我们必须确定修改后有多少个子数组满足此条件。 在查询之间恢复原始数组。 

约束告诉我们数组长度和查询次数都可以达到20万。 检查每个查询的每个子数组的简单方法需要粗略地检查$n^2 / 2 \approx 2 \cdot 10^{10}$最坏情况下的子数组。 这远远超出了 3 秒时间预算的任何实际限制，这意味着我们无法显式地迭代子数组。 相反，我们需要一种方法来计算相对于线性或近线性时间的计数$n$。 

边缘情况包括所有元素均为最小或最大的数组。 例如，如果数组全为 1 并且$n > 1$，大多数长于一个元素的子数组将无法通过良好子数组测试。 粗心的实现可能会误算，因为假设任何包含 1 的子数组都自动是好的。 当查询用较小的值替换元素时，会出现另一种棘手的情况，这会破坏先前有效子数组的长链。 

## 方法

 暴力解决方案将迭代每个查询的每个子数组，逐个元素检查条件，并在所有元素满足要求时增加计数器。 这在理论上可行，但具有时间复杂度$O(q \cdot n^2)$，这对于问题约束是不可接受的。 

关键的观察是，当且仅当序列的最小值$a_i - i$子数组上的值是非负的。 如果我们通过从每个元素中减去位置索引来转换数组，问题就简化为计算非负数的连续段。 一旦我们意识到这一点，问题就变成了有效计算连续非负线段长度的问题，这可以通过一次线性扫描来完成。 对于每段长度$L$，它贡献的子数组的数量是$L \cdot (L + 1) / 2$。 

这种方法独立处理每个查询。 我们只需要为了查询而临时修改数组，执行线性扫描来统计好的子数组，并恢复原始元素。 这将每个查询的时间复杂度降低到$O(n)$，给出总复杂度$O(n \cdot q)$，考虑到运算是简单的算术并且常数很低，这是可以接受的。

 | --- | --- | --- | --- |
 | 蛮力 |$O(q \cdot n^2)$|$O(n)$| 太慢了|

 ## 算法演练

 1.对于每个查询，临时设置$a[p] = x$。 
2. 将数组变换为$b[i] = a[i] - i$对于基于 1 的索引。 这将子数组条件简化为非负性检查。 
3. 初始化计数器`count`和长度追踪器`length = 0`。 
4. 迭代数组。 如果$b[i] \ge 0$, 增量`length`。 如果$b[i] < 0$， 添加`length * (length + 1) // 2`到`count`并重置`length`为零。 
5. 迭代结束后，如果`length > 0`， 添加`length * (length + 1) // 2`到`count`。 
6. 打印查询结果并恢复原始元素。 

为何有效：转型$b[i] = a[i] - i$捕获子数组中每个位置的确切阈值。 连续的非负段对应于最大的好子数组。 使用算术级数公式对每个段内的子数组进行计数可确保我们对每个有效子数组恰好进行一次计算。 由于每个查询都是独立的，因此恢复原始数组可以保持正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def count_good_subarrays(a):
    n = len(a)
    count = 0
    length = 0
    for i in range(n):
        if a[i] >= i + 1:
            length += 1
        else:
            count += length * (length + 1) // 2
            length = 0
    count += length * (length + 1) // 2
    return count

def main():
    n = int(input())
    a = list(map(int, input().split()))
    q = int(input())
    for _ in range(q):
        p, x = map(int, input().split())
        original = a[p - 1]
        a[p - 1] = x
        print(count_good_subarrays(a))
        a[p - 1] = original

if __name__ == "__main__":
    main()
```这`count_good_subarrays`函数通过比较将数组隐式转换为有效阈值检查$a[i] \ge i + 1$。 我们累加连续有效元素的长度，并应用算术级数公式一次性对子数组进行计数。 主函数通过临时更改数组、调用计数函数并恢复原始值来处理查询，以确保查询的独立性。

 ## 边缘情况

 对于所有元素都等于 1 的数组，例如`a=[1,1,1]`，任何超过一个元素的子数组都是不好的。 该算法正确地将每个单元素子数组计数为有效。 当查询用更大的值替换一个元素时，例如`a[2]=3`，它会暂时扩展有效段的长度并正确更新计数。 对于最后一个元素被更改的边缘情况，长度跟踪器确保在循环后对任何尾随有效段进行计数，因此不会丢失任何子数组。 对前导段和尾随段的仔细处理可以防止差一错误并保证所有配置的正确性。
