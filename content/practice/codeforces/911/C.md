 ## 解决方案
 ## 问题理解

 我们被要求决定是否可以打开三个周期性花环，以便从最后一个花环打开的那一刻起，至少其中一个始终点亮。 每个花环都有固定的周期，这意味着一旦打开，它就会每隔 _k_ 秒点亮一次。 输入由代表这些周期的三个整数组成。 输出是简单的“是”或“否”，具体取决于计划是否存在。 

这里的关键约束是周期最多为 1500。这是相对较小的，这暗示我们可以考虑探索所有可能性的解决方案，直至这些周期的某个倍数。 我们没有给出任何时间上限，因此我们只需要确保在最新激活时刻之后的亮秒内没有“间隙”。 如果我们允许任意大的数字，那么简单的模拟可能会令人望而却步，但小限制允许仔细的暴力技术。 

一个微妙的点是花环不必同时开始。 例如，周期为 2 的两个花环可以错开一秒以覆盖所有偶数秒和奇数秒。 总是假设同时启动的粗心方法可能会错误地得出“否”的可行时间表。 类似地，如果所有三个周期都是奇数且相等，则无法以交错开始的方式覆盖所有秒，因为它们的总和无法覆盖以 2 为模的每个整数。 

## 方法

 一种自然的暴力方法是在合理范围内尝试每个花环的所有可能的开始时间，然后检查最大开始时间之后的每一秒是否至少有一个点亮的花环。 由于每个周期最多为 1500，因此我们可以模拟所有秒数，最多为最大周期的几倍。 这是可行的，因为问题简化为检查以周期为模的覆盖率。 

暴力方法之所以有效，是因为我们只需要确保覆盖周期的最小公倍数 (LCM)。 一旦达到 LCM 秒，该模式就会重复。 但迭代所有三倍的起始时间最多需要 1500^3 次迭代，这大约是 33 亿次检查。 那就超过了时间限制。 我们的见解是，我们不需要尝试所有开始时间：问题可以简化为检查第一个 LCM 周期中的所有秒数，并确保没有第二个时间未被覆盖。 

关键的观察是，如果任何一秒都不能表示为具有整数偏移量 (mod LCM) 的周期的线性组合，那么该秒仍然是黑暗的。 在实践中，这简化为至多 LCM(k1, k2, k3) ≤ 1500^3 的有界模拟，但我们可以通过仅考虑最多 2 × max(k1, k2, k3) 的秒数来进一步修剪，这足以检测间隙。 或者，可以使用递归搜索来尝试所有三个偏移量，但一旦发现未覆盖的第二个偏移量就提前停止。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对所有开始时间进行暴力破解 | O(k1_k2_k3 * 最大值(k1,k2,k3)) | O(最大(k1,k2,k3)) | 太慢了 |
 | 有界搜索/递归模拟| O(k1_k2_k3) | O(k1_k2_k3) | O(最大(k1,k2,k3)) | 已接受 |

 ## 算法演练

1. 读取三个花环周期并将它们存储在列表 k = [k1, k2, k3] 中。 按非降序对它们进行排序。 排序有助于识别最大周期并限制模拟范围。 
2. 定义一个递归函数，尝试所有可能的偏移量 x1, x2, x3 直至 2 × max(k1, k2, k3)。 对于每个三元组，模拟 max(x1, x2, x3) 之后的前几秒，以检查每一秒是否至少被一个花环覆盖。 
3. 要模拟给定起始三元组的覆盖范围，请从 max(x1, x2, x3) 迭代到 max(x1, x2, x3) + 2 × max(k1, k2, k3) 的第二个 t。 对于每个 t，检查任何花环 i 是否 (t - xi) % ki == 0。 如果第二个 t 未被覆盖，则丢弃该三元组。 
4. 如果任何三元组覆盖了范围内的所有秒数，则立即返回 YES。 如果所有三元组都失败，则返回 NO。 

工作原理：一旦找到可行的三元组，亮秒的模式就会以周期 k1、k2、k3 无限重复。 由于我们模拟了足够的秒数来检测间隙（最大周期的两倍就足够了），因此我们可以保证后面的每一秒都不会保持不亮状态。 模拟确保每秒都以周期为模进行检查，这相当于检查所有时间的覆盖范围。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def can_cover(k):
    max_k = max(k)
    limit = 2 * max_k  # simulate enough seconds to detect any gaps
    for x1 in range(1, k[0]+1):
        for x2 in range(1, k[1]+1):
            for x3 in range(1, k[2]+1):
                start = max(x1, x2, x3)
                ok = True
                for t in range(start, start + limit):
                    if ((t - x1) % k[0] != 0 and
                        (t - x2) % k[1] != 0 and
                        (t - x3) % k[2] != 0):
                        ok = False
                        break
                if ok:
                    return True
    return False

def main():
    k = list(map(int, input().split()))
    if can_cover(k):
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    main()
```该解决方案定义`can_cover`，它系统地尝试所有合理的开始时间。 我们只检查从最大开始时刻开始的秒数，上限确保检测到任何间隙。 x1、x2、x3 上的嵌套循环利用 1500 的小约束，并且模检查确保正确的周期覆盖。 选择`range(1, ki+1)`for offsets 避免了微小的零索引错误，并确保每个花环在有效时刻开始。
