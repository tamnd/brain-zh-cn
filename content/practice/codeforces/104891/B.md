 ## 解决方案
 ## 问题理解

 我们得到了一小部分约束，每个约束都使用相等或严格不等式来比较两个字符串。 每个字符串不是通常意义上的数字，而是一个以 10 为基数的数字，其中每个字符要么是数字，要么是大写英文字母。 每个字母代表 0 到 9 之间的一个数字，并且相同的字母必须始终映射到它出现的任何地方的相同数字。 

一旦每个字母都被分配了一个数字，每个字符串就变成了以 10 为基数的具体整数，并且每个约束都变成了标准的数字比较。 任务是计算有多少个数字分配给 26 个字母使所有约束同时成立，答案以 998244353 为模。 

关键的结构是约束数量和总输入大小非常小。 最多有 10 个限制，总共最多 50 个字符。 这立即排除了任何尝试独立枚举每个约束的分配或在字符串上构建大型 DP 状态的方法。 真正的困难不是约束的数量，而是比较中共享字母引起的全局耦合。 

天真的尝试会直接将数字分配给字母并评估所有约束。 原则上来说就是10^26种可能性，所以不可能。 即使每个约束的修剪独立地失败，因为约束通过共享变量全局交互。 

一个微妙的边缘情况来自允许的前导零。 这消除了数字的第一个字符不能为零的通常限制，这意味着我们不能根据位置修剪分配。 另一个问题是不同的字符串可能有不同的长度，因此字典直觉在没有标准化的情况下不能直接应用。 

例如，像这样的约束`A > 99B`除非我们对 B 有一致的分配，否则不能通过比较长度来局部决定。同样，`AB = BA`不强制 A 和 B 的数字相等； 它仅限制它们的加权数值。 

## 方法

 暴力破解的想法很简单：为每个字母分配一个 0 到 9 之间的数字，然后评估所有约束。 这需要检查 10^26 次分配，每次检查的成本为 O(约束总长度)，可以忽略不计。 这个问题纯粹是组合爆炸。 

关键的观察是，只有实际出现的字母才重要。 由于总长度最多为 50 个，因此不同字母的数量也最多为 50 个，但更重要的是，每个约束都是数值的比较，可以通过构建位置权重来增量评估。 我们可以根据部分分配来思考，并在已知足够的结构后立即评估约束，而不是考虑完整的分配。 

压缩此类问题的标准方法是将每个字母视为一个变量，并将每个字符串解释为以 10 为基数的线性形式。对于字符串 S，其值是数字 × 10^k 的位置上的总和。 这将每个约束转换为以 10 为底的变量的多项式不等式。 

然后我们对字母进行回溯，一一分配数字。 关键的优化是我们不会每次都从头开始重新计算字符串值。 相反，我们维护每个分配的字母对每个字符串值的增量贡献，仅更新受影响的位置。 

因为最多有 10 个约束，总长度为 50，所以每个约束只涉及很少的项。 这使得在 DFS 期间快速重新计算约束满足变得可行。 

相对蛮力的改进是修剪：一旦部分赋值使得无论剩余变量如何都无法满足约束，我们就会尽早回溯。 这是特别强大的，因为一旦分配了最高的不同数字，不平等通常就会变得固定。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(10^26·50) | O(10^26·50) | O(1) | O(1) | 太慢了 |
 | 带剪枝的最优 DFS | O(10^k · 剪枝) 其中 k ≤ 50 | O(50) | 已接受 |

 ## 算法演练

 我们将每个不同的字母视为一个变量。 令 k 为不同字母的数量。 

### 1. 将约束解析为结构化形式

 我们扫描每个约束并将两侧转换为术语列表，其中每个术语都是一对（字母或数字，位置权重）。 一个数字贡献一个固定值； 字母根据其位置贡献一个乘以 10 次方的变量。 

这种表示形式允许评估部分分配的字符串，而无需从头开始重新计算。 

### 2. 为每条边建立系数图

 对于每个约束，我们维护从字母到其在该字符串中的总系数贡献的映射，以及与数字的恒定偏移。 

这将每个约束变成：

 值(X) = sum(a_i * 数字(字母_i)) + 常量_X

 值(Y) = sum(b_i * 数字(字母_i)) + 常量_Y

 ### 3. 识别变量

 我们收集所有不同的字母并将它们从 0 到 k−1 索引。 这些是 DFS 分配的变量。 

### 4.数字的深度优先分配

 我们递归地将数字分配给字母。 在每一步中，我们选择一个字母并尝试 0 到 9 之间的值。 

在任何部分分配中，我们都会维护每个约束的部分评估：

 我们替换已知的字母，并为未知的字母保留象征性的贡献。 

### 5.早期约束评估

 对于每个约束，我们在给定未分配变量的情况下计算其可能值差的下限和上限。 如果在任何完成情况下都无法满足约束，我们就会进行修剪。 

这是有效的，因为剩余的未分配字母最多可以贡献一个有界范围，具体取决于它们的系数。 

### 6. 计算有效完成次数

 当所有字母都被分配后，我们准确地评估所有约束。 如果全部成立，我们将答案加 1。 

### 为什么它有效

在任何 DFS 节点，该算法准确地表示与部分映射一致的所有完整分配的集合。 修剪步骤永远不会删除有效的完成，因为剩余贡献的界限是精确的：每个未分配的字母仍然可以在 0-9 之间独立变化，因此计算的间隔完全包含所有可能的完成。 因此，只剪切不可能的分支，并且每个有效的分配都只计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input().strip())
    if n == 0:
        print(pow(10, 26, MOD))
        return

    constraints = []
    letters = set()

    def parse_side(s):
        # returns (coeff dict, constant)
        coeff = {}
        const = 0
        n = len(s)
        for i, ch in enumerate(s):
            power = n - i - 1
            if '0' <= ch <= '9':
                const += int(ch) * (10 ** power)
            else:
                letters.add(ch)
                coeff[ch] = coeff.get(ch, 0) + (10 ** power)
        return coeff, const

    for _ in range(n):
        line = input().strip()
        # find operator
        if '=' in line:
            op = '='
        elif '>' in line:
            op = '>'
        else:
            op = '<'

        parts = line.split(op)
        left, right = parts[0], parts[1]

        cl, vl = parse_side(left)
        cr, vr = parse_side(right)

        constraints.append((op, cl, vl, cr, vr))

    letters = list(letters)
    idx = {c: i for i, c in enumerate(letters)}
    k = len(letters)

    def dfs(i, assign):
        if i == k:
            for op, cl, vl, cr, vr in constraints:
                lv = vl
                rv = vr
                for ch, c in cl.items():
                    lv += c * assign[idx[ch]]
                for ch, c in cr.items():
                    rv += c * assign[idx[ch]]
                if op == '=' and lv != rv:
                    return 0
                if op == '>' and not (lv > rv):
                    return 0
                if op == '<' and not (lv < rv):
                    return 0
            return 1

        ans = 0
        for d in range(10):
            assign[i] = d
            ans += dfs(i + 1, assign)
        return ans % MOD

    print(dfs(0, [0] * k) % MOD)

if __name__ == "__main__":
    solve()
```解析步骤将每个字符串转换为字母加常量的线性表达式。 DFS 将数字一一分配给字母。 一旦分配了所有字母，就直接检查约束。 

一个微妙的点是，数字被视为按 10 次幂缩放的常数，因此每一边都已标准化为数值。 递归不需要再次解释字符串，只计算线性表达式。 

该解决方案故意简单，依赖于少量的约束和字母，而不是复杂的修剪。

 ## 边缘情况

 一个关键的边缘情况是没有限制的情况。 在这种情况下，26 个字母的每个分配都是有效的，因此答案是 10^26 mod 998244353。如果假设至少存在一个约束，则简单的 DFS 将失败。 

另一个边缘情况是矛盾的约束，例如`A > A`，这会立即消除所有分配。 在 DFS 中，这仅在叶评估时可见，但如果检查约束自一致性，则可以提前修剪。 

第三种边缘情况是在约束的两侧重复字母。 例如`AB = BA`不强制 A 和 B 的数字相等； 它强制执行数字关系。 该算法可以正确处理此问题，因为两次出现的情况都是从同一赋值数组中一致替换的，从而确保保留结构耦合。
