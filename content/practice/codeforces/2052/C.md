 ## 解决方案
 ## 问题理解

 该问题为您提供了一个无向图$n$节点和$m$并要求您构造一个具有相同数量的节点和边的“仙人掌”图，条件是生成的仙人掌没有任何桥。 仙人掌是一种图，其中每条边最多属于一个简单循环。 换句话说，每个环都是孤立的，并且任何两个环最多共享一个顶点。 桥是一条边，移除它会增加连接组件的数量。 我们需要创建一个仙人掌，其中每个边缘都是某个​​循环的一部分，因此没有桥梁。 

输入提供两个整数$n$和$m$，表示节点和边的数量。 输出应该是满足约束的构造仙人掌的边列表。 除了仙人掌属性和无桥条件之外，不需要特定的顶点标签或循环。 

约束条件允许$n$最多$10^5$和$m$最多$2 \cdot 10^5$。 这意味着任何迭代所有节点对或尝试所有生成树的解决方案都是不可行的。 线性或近线性方法$n + m$是必须的。 

当发生微妙的边缘情况时$m < n$，其中不可能避免桥，因为边少于节点的连通图必须至少有一个树边。 例如，$n=4, m=3$需要一棵树，它必然有桥。 粗心的实现可能会尝试盲目地为每个边生成循环并生成断开连接或无效的图。 

另一个边缘情况是当$m$正是$n$，它允许覆盖所有节点的最简单循环。 同样，当$m$非常大（接近$2n$），我们需要创建多个共享节点的小环，而不需要引入桥。 这些需要仔细构建重叠循环。 

## 方法

 蛮力方法是尝试循环和边的所有组合。 对于每条边，检查添加它是否保留仙人掌属性并避免桥接。 这是可行的，因为仙人掌的定义是局部的：每条边最多只能属于一个周期。 然而，这种方法需要$O(\binom{n}{2})$在最坏的情况下检查在每对节点之间添加边，导致粗略$5 \cdot 10^9$操作时$n=10^5$，这太慢了。 

关键的观察是没有桥梁的仙人掌可以系统地建造。 任何至少三个节点的简单循环都不包含桥。 如果我们通过共享顶点来链接这些循环，我们就可以生产更大的仙人掌，而无需创建桥梁。 而且，边的总数最多为$2n - 2$在没有桥梁的仙人掌中。 如果$m > 2n - 2$，施工是不可能的。 否则，我们可以从一个简单的长度循环开始$n$然后在节点之间添加额外的和弦以达到$m$边缘，小心避免多个周期共享同一边缘。 

最佳结构采用星型和循环混合方法。 从连接到节点 2 的中心节点（节点 1）开始$n$。 这确保了连接性。 然后在非中心节点之间添加边，迭代形成循环，直到达到$m$边缘。 这是有效的，因为每个新边都会添加一个新循环，并且现有的边不会成为桥梁，因为它是某个循环的一部分。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n+m) | 太慢了|
 | 最佳 | O(n + m) | O(n + m) | 已接受 |

 ## 算法演练

 1. 检查是否$m < n$或者$m > 2n - 2$。 如果任一条件为真，则输出 -1 或失败，因为连接的无桥仙人掌至少需要$n$边缘和至多$2n - 2$边缘。 
2. 用简单的长度循环初始化图$n$：连接节点 1 到 2、2 到 3、...、$n-1$到$n$， 和$n$回到 1。这给出$n$边并保证没有桥，因为所有边都属于循环。 
3. 保留一个计数器以添加额外的边缘。 虽然当前边数小于$m$，迭代所有节点对 (i, j)$i < j$，跳过已经存在的边。 
4. 对于每个候选边，将其添加到边列表中。 每条添加的边都会通过连接现有循环中的两个节点来创建一个新的简单循环。 一旦总数达到则停止添加边$m$。 没有边缘会成为桥梁，因为每个边缘都是至少一个周期的一部分。 
5. 输出边列表。 

其工作原理：初始周期可确保无需桥接即可实现完全连接。 每条新边都会创建一个额外的循环，并且不会删除任何现有的循环，从而保留了无桥属性。 不变的是图中的每条边在每一步都至少属于一个循环。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    if m < n or m > 2 * n - 2:
        print(-1)
        return
    
    edges = []
    # Step 2: create initial cycle
    for i in range(1, n):
        edges.append((i, i + 1))
    edges.append((n, 1))  # close the cycle
    
    extra_edges = m - n
    # Step 3: add extra edges between non-adjacent nodes
    for i in range(1, n + 1):
        for j in range(i + 2, n + 1):
            if i == 1 and j == n:
                continue  # skip edge that closes the main cycle again
            if extra_edges == 0:
                break
            edges.append((i, j))
            extra_edges -= 1
        if extra_edges == 0:
            break
    
    # Output
    for u, v in edges:
        print(u, v)

t = int(input())
for _ in range(t):
    solve()
```每个部分都直接对应于算法演练中的步骤。 主要的微妙之处在于避免两次从 1 到 n 的边缘，这会创建重复的循环。 嵌套循环确保我们系统地填充和弦，而不会破坏仙人掌属性。

## 复杂度分析

 | 测量 | 复杂性 | 说明|
 | --- | --- | --- |
 | 时间 | O(n + m) | 我们在 O(n) 中生成初始循环，并在嵌套循环中生成最多 O(m) 个额外边 |
 | 空间| O(n + m) | 我们显式存储所有边 |

 这符合约束条件$n \le 10^5$,$m \le 2 \cdot 10^5$。 嵌套循环永远不会超过 O(m) 次迭代，因为一旦添加了足够的边，我们就会中断。
