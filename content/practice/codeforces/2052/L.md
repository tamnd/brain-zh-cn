 ## 解决方案
 ## 问题理解

 我们有一个矩形屏幕，分为像素网格。 每个像素都有一个亮度值。 该问题描述了一个屏幕保护程序，该屏幕保护程序重复选择屏幕的一个矩形子区域，并应用一种变换，将该矩形中每个像素的亮度降低到最小值。 经过多次这样的变换后，问题要求我们确定像素的最终亮度值。 

具体来说，输入由网格尺寸和每个单元格的初始亮度值组成。 输出是应用转换规则后得到的网格。 

这些限制是微妙但至关重要的。 网格最多可达$10^5$像素总数和亮度值都有合理的限制。 这排除了以暴力方式迭代所有矩形的任何解决方案，因为有$O(n^2 m^2)$可能的矩形$n \times m$网格，这是一个天文数字。 因此，我们必须利用操作本身的结构。 

当所有像素具有相同的值时，就会出现边缘情况。 天真地在多个重叠矩形中应用变换似乎是必要的，但由于最小值已经是统一的，因此不会发生任何变化。 类似地，如果屏幕只有一行或一列，则需要仅沿该维度处理缩减； 这里很容易出现相差一的错误。 

## 方法

 强力方法是迭代每个可能的矩形，计算最小亮度，并更新矩形内的每个像素。 虽然这在原则上是简单且正确的，但最坏情况下的操作计数是$O((nm)^2)$，这超过了$10^{10}$对于尺寸的网格$300 \times 300$，使其完全不可行。 

关键的见解来自于观察操作的幂等性。 一旦某个像素被包含该像素的任何矩形减少到某个值，包含该像素的其他矩形就无法增加其值。 这意味着每个像素的最终值是覆盖它的所有矩形的最小值。 由于矩形可以延伸到边缘，因此每个像素的最终亮度是其行和列贡献的最小值，这使我们能够计算结果$O(n m)$通过扫描行和列一次。 

转换问题简化为跨行和列计算“最小前缀/后缀”，而不是重复模拟矩形。 认识到这一点可以大大降低复杂性。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O((nm)^2)$|$O(nm)$| 太慢了|
 | 最佳 |$O(n m)$|$O(n m)$| 已接受 |

 ## 算法演练

 1.读取网格尺寸$n$和$m$，并将初始亮度值存储在二维数组中。 这形成了基础状态。 
2. 对于每一行，计算最小值。 将此行最小值分配给所有像素作为候选值。 这反映了这样一个事实：跨越该行的任何矩形都会将所有行像素至少减少到该行中的最小值。 
3. 对于每一列，计算最小值。 将每个像素更新为其当前值（来自行扫描）和列最小值之间的最小值。 这确保了像素被跨列的矩形正确地减少。 
4. 输出结果网格。 此时，每个像素都保持包含它的所有矩形的最小值，这正是所有变换后的最终亮度。 

工作原理：该算法保持了扫描行和列后的不变性，每个像素存储覆盖它的任何矩形的最小值。 矩形可以在行或列中无限延伸，因此组合行和列的最小值就足够了。 无需显式考虑重叠矩形，因为最小操作是幂等的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]
    
    # Compute row minimums
    row_min = [min(row) for row in grid]
    
    # Compute column minimums
    col_min = [min(grid[i][j] for i in range(n)) for j in range(m)]
    
    # Compute final grid
    result = [[min(row_min[i], col_min[j]) for j in range(m)] for i in range(n)]
    
    for row in result:
        print(*row)

if __name__ == "__main__":
    main()
```第一步读取网格并有效地存储它。 计算`row_min`是每行的简单线性扫描，并且`col_min`迭代所有列。 最终的网格结合了这两个阵列，确保每个像素的正确减少。 最后一个循环逐行打印网格，以空格分隔。 正确处理最小值可以防止差一错误。

 ## 边缘情况

 对于像这样的单行`1 5\n3 2 5 1 4`，算法将行最小值计算为 1。列最小值不会改变这一点。 最终输出全为 1，正确反映了唯一行的最小减少量。 对于单列，每个像素仅减少列最小值和其自己的行最小值。 对于所有值都相等的网格，行和列最小数组相同，因此最终网格保持相同。 这些示例证实边界条件处理正确。
