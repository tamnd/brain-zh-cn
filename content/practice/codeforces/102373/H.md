 ## 解决方案
 ## 问题理解

 网格是一种图，其顶点都是非壁单元，单元之间的边共享一条边。 朋友们开始于`s`并且需要达到`f`。 

每次水平移动都会改变温度`-1`，无论移动是向左还是向右。 每次垂直移动都会改变它`+1`，无论走势是上升还是下降。 因此，对于包含`H`水平移动和`V`垂直移动时，最终温度与初始温度相差

 [
 V-H。 
]

 小伙伴们可以任意多次重访单元格和边。 我们需要尽可能小的值

 [
 |V-H|。 
]

如果`f`无法从以下位置到达`s`，答案是`-1`。 

网格最多可包含 (10^6) 个单元格。 这立即排除了任何为每个可能的路径长度或温度值存储大状态的情况。 我们只需要检查每个单元和每个局部邻接点恒定的次数，给出一个 (O(nm)) 目标。 使用线性内存进行遍历也很自然，因为只有 (O(nm)) 个可到达的单元格。 

在很多情况下，看似合理的捷径却给出了错误的结果。 

考虑一个单一的水平走廊。```
1 3
s.f
```唯一有用的路径有两个水平移动，因此温度变化`-2`答案是`2`。 假设答案始终仅由路径长度的奇偶校验确定的解决方案将错误地返回`0`，因为该组件没有垂直边缘来补偿水平移动。 

垂直模拟也有同样的问题。```
3 1
s
.
f
```每次移动都是垂直的，因此最短路径会改变温度`+2`。 正确答案是`2`。 

断开连接的出口也必须单独处理。```
1 3
s#f
```没有步行距离`s`到`f`，所以答案是`-1`。 对坐标进行计算`s`和`f`不检查连接性会默默地产生一个有限值。 

最后，同时具有水平和垂直边缘并不意味着答案始终为零。 考虑```
2 2
sf
..
```随着温度变化存在直接的水平路径`-1`。 因为该组件包含两种边缘，所以我们可以将任何行走的温度变化改变为`2`，但我们永远无法改变它的奇偶性。 由于每`s`到`f`这里的步行长度为奇数，温度变化也总是奇数。 正确答案是`1`。 

## 方法

 直接的暴力方法将枚举从`s`并跟踪它们的累积温度变化。 这在概念上是正确的，因为每一次可能的行走都对应于一个可能的最终温度。 问题是步行可能会重新访问单元格，因此有无限多次步行。 即使我们人为地将搜索限制为长度最多为 (L) 的游走，网格顶点在每一步最多可以有四个选择，在最坏的情况下给出 (O(4^L)) 候选游走。 增加 (L) 并不能彻底解决问题，因为有效的最优行走可能故意包含重复。 

尝试仅枚举简单路径并不是有效的替代方法。 该声明明确允许重新访问细胞，而这些重复正是让我们补偿温度变化的原因。 

关键的观察结果来自于观察一条经过两次的边。 如果边缘是水平的，穿过它并立即返回会产生成本`-2`。 如果边缘是垂直的，穿过它并立即返回会产生成本`+2`。 由于朋友们可以在有效步行的任何地方插入这样的往返行程，因此水平边缘的存在使我们可以将总数减少`2`每当我们想要的时候，而垂直边缘的存在让我们可以将总数增加`2`每当我们想要的时候。 

假设连通分量包含`s`和`f`具有水平边缘和垂直边缘。 从任意开始`s`到`f`其温度变化为(W)的路径。 通过重复插入水平往返，我们可以将 (W) 替换为 (W-2k)，通过重复插入垂直往返，我们可以将其替换为 (W+2k)。 因此，与(W)具有相同奇偶校验的每个整数都是可以实现的。 

(W)的奇偶校验特别简单。 每一步都会使路径长度改变一，并且

 [
 V-H=(V+H)-2H。 
]

 因此(V-H)与总步数具有相同的奇偶性。 每条路径从`s`到`f`具有相同的长度奇偶性，因为更改网格坐标的奇偶性需要一次移动。 因此，当两种边类型都存在时，答案是`0`对于均匀的路径长度和`1`对于奇数路径长度。 

有一种特殊情况。 如果组件仅包含水平边缘，则每次可能的行走都只有水平移动，因此其温度变化恰好是其长度的负值。 然后通过最短路径获得最小的绝对值`s`到`f`。 如果元件仅包含垂直边缘，则同样的推理适用，只不过温度变化是正路径长度。 

单个 BFS 即可为我们提供所需的一切。 它找到到的最短距离`f`, 判断是否`f`是可达的，并且在遍历组件时，它告诉我们是否存在至少一个水平边缘和至少一个垂直边缘。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 无界，(O(4^L)) 对于长度 (L) 的步行 | 搜索深度无限 | 太慢了|
 | 最佳 | (O(nm)) | (O(nm)) | 已接受 |

 ## 算法演练

 1.读取网格并找到起始单元格`s`并退出单元格`f`。 对待每个角色，除了`#`作为可遍历的。 
2. 运行 BFS`s`。 存储最短距离`s`到每个访问过的单元格。 BFS 是合适的，因为每个网格移动都有单位长度，因此第一次到达某个单元格时会给出其最短路径长度。 
3. 在检查单元及其每个可到达的邻居时，对相应的边进行分类。 如果行发生变化，则组件包含垂直边缘。 如果该列发生变化，则它包含水平边缘。 我们只需要两个布尔标志。 
4. 如果`f`从未访问过，输出`-1`。 朋友们根本无法到达出口。 
5. 如果组件同时包含水平和垂直边缘，则输出`dist[f] % 2`。 最短路径长度决定了每个可能的温度变化的奇偶性，并且变化的两个迹象`2`可以通过边缘往返获得。 因此，偶校验允许精确抵消，而奇校验则留下最小绝对差`1`。 
6. 如果组件只有水平边缘，则输出`dist[f]`。 每一次可能的步行的温度变化都等于其长度的负值，因此最短的路径是最佳的。 
7. 如果组件只有垂直边缘，则输出`dist[f]`以及。 每一次可能的步行都有与其长度相等的温度变化，因此最短的路径也是最佳的。 

### 为什么它有效

 中心不变量是插入水平边缘往返将温度精确地改变`-2`，当插入垂直边缘往返时，它会精确地改变`+2`。 如果两种边类型都出现在连接的组件中，则任何路径的温度变化都可以移动任何偶数整数。 奇偶性不能改变，因为温度变化（V-H）与移动次数具有相同的奇偶性，并且每个`s`到`f`walk 具有相同的端点奇偶性。 因此最接近零的可实现值恰好是`0`对于偶校验和`1`为奇校验。 

如果仅存在一种边缘类型，则每次行走都有固定的温度变化符号，并且其大小等于其长度。 因此，最短路径使绝对温差最小化。 BFS 精确地计算出最短长度。 

## Python 解决方案```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    start = None
    finish = None

    for r in range(n):
        for c in range(m):
            if grid[r][c] == 's':
                start = (r, c)
            elif grid[r][c] == 'f':
                finish = (r, c)

    sr, sc = start
    fr, fc = finish

    dist = [[-1] * m for _ in range(n)]
    dist[sr][sc] = 0

    q = deque([(sr, sc)])

    has_horizontal = False
    has_vertical = False

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while q:
        r, c = q.popleft()

        for dr, dc in directions:
            nr = r + dr
            nc = c + dc

            if nr < 0 or nr >= n or nc < 0 or nc >= m:
                continue
            if grid[nr][nc] == '#':
                continue

            if dr == 0:
                has_horizontal = True
            else:
                has_vertical = True

            if dist[nr][nc] != -1:
                continue

            dist[nr][nc] = dist[r][c] + 1
            q.append((nr, nc))

    d = dist[fr][fc]

    if d == -1:
        print(-1)
        return

    if has_horizontal and has_vertical:
        print(d & 1)
    else:
        print(d)

if __name__ == "__main__":
    solve()
```网格存储为字符串列表，因此检查单元格是否是墙是一个常数时间操作。 这两个特殊单元位于初始扫描中。 

BFS距离数组使用`-1`对于未访问的单元格和`0`首先。 由于每一次合法行动都要花费一步，`dist[f]`是可到达出口时的最短路径长度。 

仅针对有效的非墙邻居更新边类型标志。 水平邻接通过以下方式检测`dr == 0`，而垂直邻接有`dr != 0`。 两个端点可能会遇到相同的边，但设置布尔值两次没有效果。 

边界检查必须在索引网格之前进行。 这可以避免意外地将负 Python 索引视为有效单元，这是网格 BFS 中特别容易引入的错误。 

Python 中不存在整数溢出问题。 即使在 C++ 实现中，最大最短距离也仅为 (O(nm))，因此标准整数类型就足够了。 

最终的决定故意使用 BFS 距离而不是该路径的实际温度变化。 一旦两种边缘类型都存在，只有其奇偶性很重要。 当缺少一种类型时，距离本身就是可能的最小绝对变化。 

## 工作示例

 ### 示例 1

 网格是```
4 3
..f
..#
s##
...
```开始于`(2,0)`，BFS可以达到`(1,0)`， 然后`(0,0)`，然后退出`(0,2)`。 该组件包含垂直和水平边缘。 

| 当前单元格| 距离 | 新细胞 | 边缘型| 新距离|
 | ---| ---| ---| ---| ---|
 |`(2,0)`| 0 |`(1,0)`| 垂直| 1 |
 |`(1,0)`| 1 |`(0,0)`| 垂直| 2 |
 |`(0,0)`| 2 |`(0,1)`| 卧式| 3 |
 |`(0,1)`| 3 |`(0,2)`| 卧式| 4 |

 最短距离`f`是`4`，这是偶数。 因为该组件具有两种边缘类型，所以答案是`4 % 2 = 0`。 

直接路径本身已经有两个垂直和两个水平移动，从而产生温度变化`2 - 2 = 0`。 BFS 奇偶校验论证证实了精确取消是可能的。 

### 自定义示例 2

 考虑一条单排走廊。```
1 3
s.f
```没有垂直边缘。 

| 当前单元格| 距离 | 新细胞 | 边缘型| 新距离|
 | ---| ---| ---| ---| ---|
 |`(0,0)`| 0 |`(0,1)`| 卧式| 1 |
 |`(0,1)`| 1 |`(0,2)`| 卧式| 2 |

 出口有距离`2`，并且该组件仅包含水平边缘。 每一次可能的步行的温度变化都等于其长度的负值。 最短的可能长度是`2`，所以答案是`2`。 

此示例演示了为什么必须检查两种边缘类型的存在，而不是简单地返回最短路径的奇偶校验。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | (O(nm)) | 每个单元最多插入 BFS 一次，每个访问的单元最多检查四个邻居。 |
 | 空间| (O(nm)) | 网格、距离数组和 BFS 队列使用单元数量的线性空间。 |

 对于 (n,m \le 1000)，最多有 (10^6) 个单元格。 该算法仅对每个单元和邻接执行恒定量的工作，因此它与整个网格而不是与可能的行走数量线性缩放。 内存消耗也是线性的，并且对于百万单元网格来说仍然实用。

 ## 边缘情况

 对于仅水平的情况```
1 3
s.f
```BFS远距离到达出口`2`。 在遍历过程中它设置`has_horizontal`到`True`， 但`has_vertical`遗迹`False`。 因此，该算法采用单向分支并输出`2`。 重复遍历一条可用的水平边只能添加另一条`-2`适应温度的变化，因此不走弯路可以提高最短路径。 

对于仅垂直的情况```
3 1
s
.
f
```BFS再次获取距离`2`，但只有这一次`has_vertical`成为现实。 每次步行的温度变化等于其长度，因此其绝对变化至少为`2`。 算法输出`2`。 

对于包含两种边缘类型的组件，```
2 2
sf
..
```第一次水平移动到达`f`有距离`1`。 BFS 还会在组件的其他地方遇到垂直边缘，因此两个标志都为 true。 算法输出`1 & 1 = 1`。 垂直往返可以添加`+2`，并且水平往返可以添加`-2`，但是这两个操作都不会改变奇校验，因此零是不可能的。 

对于断开连接的情况，```
1 3
s#f
```BFS 仅访问起始单元，因为中间单元是墙。`dist[f]`遗迹`-1`，算法立即输出`-1`。 对于不存在的路径，不会尝试进行温度计算。 

对于最大尺寸的情况，完全开放的（1000×1000）网格具有水平和垂直边缘。 如果`s`位于`(0,0)`和`f`位于`(999,999)`，最短距离是`1998`，这是偶数。 因此该算法返回`0`。 尽管最短路径本身很长，但 BFS 仅处理最多一百万个单元中的每个单元一次，从而保留了 (O(nm)) 界限。
