 ## 解决方案
 ## 问题理解

 我们有一个矩形板，分为`n × m`单位细胞。 比尔仅沿着网格线切割并遵循固定的右转螺旋线。 切割从远离左边界的一个单元开始，然后向上进行，直到将其延伸另一个单元将断开剩余的图形。 方向按顺时针方向变化，每次转动后都应用相同的规则。 我们需要整个过程中每个单位段切割的总长度。 

尺寸可以大到`10^9`。 这会立即排除任何显式构造该工作表的内容，因为该工作表最多可以包含`10^18`细胞。 即使是为每个单元执行持续工作的算法也需要大约`10^18`操作，远远超出了两秒的限制。 该解决方案必须使用螺旋的几何形状，而不是模拟它。 

最危险的边缘情况是薄矩形。 为了`2 × 2`，答案是`1`， 不是`2`或者`4`，因为在剩余图形无法再延伸之前只能切割一个单位。 为了`2 × 3`，答案是`2`，因为公式给出`(2 - 1)(3 - 1) = 2`。 基于计算完整匝数的模拟在这里很容易出现相差一的错误，因为最后一匝比前面的匝短。 官方分析证实，准确答案是`(n - 1)(m - 1)`。 

另一个有用的边缘情况是正方形，例如`3 × 3`。 螺旋是对称的，但答案是`4`，而不是周长或细胞数量。 相关量是下述几何变换后的切割所表示的内部位置的数量。 

## 方法

 直接解决方案可以逐个单元地模拟片材。 我们可以维护当前的矩形，沿着螺旋线，并为切割的每个单位段的答案加一。 这是正确的，因为每次切割都由单位网格段组成，因此明确遵循螺旋最终会准确计算所需的长度。 

问题在于操作次数。 总长度本身可以是`(n - 1)(m - 1)`，这对于`n = m = 10^9`等于`999999998000000001`。 因此，模拟需要的顺序是`10^18`最坏情况下的迭代。 存储网格显然是不可能的，因为它需要最多`10^18`细胞。 

有用的观察是停止将切割视为线条，而是从其双重角度看待平面网格。 用相应的网格边界替换原始单元格，并在保留邻接性的同时用单元格替换原始边界。 在此变换下，原始切割的每个单位段恰好对应于变换后的矩形中的一个非边界单元。 

变换后的矩形与原始尺寸相比多了一行和一列。 其边界单元对应于原始板材的外边界，不能进行切割。 剩下的是一个`(n - 1) × (m - 1)`内部矩形。 

原来的右转螺旋变成了所有这些内部细胞的普通螺旋遍历。 每个内部单元都被访问一次，并且每个被访问的单元代表原始切割的一个单元。 因此，总切割长度就是内部单元的数量，`(n - 1)(m - 1)`。 这正是官方教程中使用的几何论证。

 ## 算法演练

 1. 阅读尺寸`n`和`m`原始矩形片材。 
2. 通过双网格解释螺旋。 原始板材的外边界成为变换后的矩形的边界层，因此这些位置不能对应于切割。 
3. 不考虑该边界层。 由于变换后的矩形具有尺寸`(n + 1) × (m + 1)`，从叶子的每一侧去除一个细胞`(n - 1) × (m - 1)`内部细胞。 
4. 计算内部细胞的数量。 每一条双射对应于原始螺旋切口的一个单位线段，因此所需的总长度为`(n - 1) × (m - 1)`。 
5. 打印产品。 

### 为什么它有效

 关键的不变量是原始网格中的单位切割段与双网格中的内部单元之间的对应关系。 螺旋运算保留了这种对应关系，因为原始切割的相邻部分成为变换后表示中的相邻单元。 转弯处的停止规则正是防止螺旋进入边界层或断开其余图形的原因。 因此，变换后的螺旋会访问每个有效的内部单元一次且仅一次。 正好有`(n - 1)(m - 1)`这样的细胞，所以相同的数字就是原始切割的总长度。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    print((n - 1) * (m - 1))

if __name__ == "__main__":
    solve()
```输入由一对整数组成，因此不存在测试用例循环。 表达式`(n - 1) * (m - 1)`直接实现从双网格参数获得的结果。 

减法必须在乘法之前进行。 使用`n * m - 1`或者`(n - 1) * m`会计算与切割不对应的边界位置，即使在小矩形上也会产生错误的答案。 

Python 整数具有任意精度，因此处理最大乘积无需任何特别注意。 在具有固定宽度整数类型的语言中，64 位有符号整数在这里就足够了，因为最大答案如下`10^18`，但 Python 不需要显式类型选择。

 四个内部单元对应于螺旋的四个单位段。 因此总切割长度为`4`，匹配样本。

 对于一个`3 × 4`工作表，变换后的矩形有尺寸`4 × 5`。 去除其边界层后，有`2 × 3`相关的内部细胞。 

|`n`|`m`| 内部行| 室内柱| 回答 |
 | ---| ---| ---| ---| ---|
 | 3 | 4 | 2 | 3 | 6 |

 螺旋线访问所有六个内部位置，因此切割了六个单位长度。 这给出了`(3 - 1)(4 - 1) = 6`，再次匹配样本。

 ## 边缘情况

 对于`2 × 2`，公式给出`(2 - 1)(2 - 1) = 1`。 变换后的矩形有一个`1 × 1`内部，因此一个内部单元恰好对应于一个切割单元。 假设每个方向始终至少获得一个完整的附加线段的模拟可能会错误地计数多个线段。 

为了`2 × 3`，结果是`(2 - 1)(3 - 1) = 2`。 变换后的矩形有一个`1 × 2`内部的。 螺旋可以访问两个有效位置，但在最后一圈之后没有第三个位置。 这是在逐回合模拟中暴露逐一错误的典型情况。 

为了`3 × 3`，结果是`(3 - 1)(3 - 1) = 4`。 变换后的矩形有一个`2 × 2`内部，因此四个位置对应于切割段。 这证实了答案计算的是内部双重位置而不是原始纸单元或周长。 

为了`1000000000 × 1000000000`，答案是`999999999 × 999999999 = 999999998000000001`。 结果很大，但仍然可以用 Python 的整数类型精确表示。 该算法从不分配网格并执行与分配网格相同的恒定工作量。`2 × 2`输入。
