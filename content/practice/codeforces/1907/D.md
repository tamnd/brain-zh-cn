 ## 解决方案
 ## 问题理解

 我们在数轴上得到一系列间隔，然后模拟它们之间的受约束运动过程。 玩家从位置 0 开始。对于按顺序的每个间隔，玩家进行一次移动，在该移动之后，他们必须落在相应的间隔内。 移动规则规定每一步最多允许跳跃距离`k`，我们被要求选择最小的这样`k`这使得可以顺序满足所有间隔约束。 

因此，与其考虑单独的分数，不如考虑玩家在每一步之后可能所处的位置。 在处理第一个间隔之后，有一组可达位置，并且在每个后续间隔之后，该集合基于两个约束而演变：先前的可达范围最多扩展`k`，然后它被剪切到当前间隔。 

输出是最小整数`k`这样这个过程永远不会产生空集，这意味着每个段之后总是至少有一个有效位置。 

约束条件很大，总共`n`跨最多 2e5 的测试用例。 这排除了尝试多个候选值的任何模拟`k`并从头开始重新计算可达性。 二分查找`k`会将线性检查乘以对数因子，这是临界但不必要的。 问题的结构允许在每个测试用例的线性时间内进行直接贪婪计算。 

一个幼稚的错误是模拟固定的过程`k`但仅跟踪单个位置而不是范围。 例如，如果间隔是`[1,5]`然后`[10,12]`，单一位置方法可能会尝试贪婪地从 1 跳到 10，并且无法识别内部的多个选择`[1,5]`事情。 另一种常见的失败是忘记在每一步之后，整个可到达的间隔都很重要，而不仅仅是一个端点。 

## 方法

 一个蛮力的想法是修复一个候选人`k`并模拟所有可能的位置。 在每个分段之后，从每个可到达的位置我们可以跳到距离内的任何点`k`，然后与下一个区间相交。 这相当于维护一个连续的可达段，但如果天真地作为状态集或状态列表来完成，它会呈指数爆炸，因为每个步骤都会分支成无限多个点。 

关键的观察是可达集始终是连续的区间。 如果在步骤`i`我们可以站在任何地方`[L, R]`，然后在有限制的一步之后`k`，我们可以精确地达到`[L-k, R+k]`。 与下一段相交`[l_i, r_i]`再次保持一个间隔。 所以我们每一步只跟踪一个间隔。 

这减少了维持给定区间传播的问题`k`。 剩下的任务就是找到最小的`k`这可以防止此间隔在任何步骤变空。 

而不是二分查找`k`，我们可以直接推导出来。 在每一步中，我们都会检查需要多少扩展才能将先前的可达区间连接到当前段。 如果当前段与扩展的先前间隔重叠，则不需要额外成本。 否则，间隙决定所需的最小跳跃。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 状态的残酷模拟 | 指数| 大| 太慢了 |
 | 具有固定 k 的区间传播 | O(n) | O(1) | O(1) | 每张支票均已接受 |
 | 直接贪心计算 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们维持当前的可行区间`[L, R]`，表示处理每个片段后玩家可以处于的所有位置。 

1. 初始化间隔为`[0, 0]`。 这代表任何运动之前的起点。 
2. 对于第一段`[l1, r1]`，我们必须从 0 开始到达。所需的最小跳转取决于 0 距该段的距离。 如果 0 位于其内部，则不需要移动； 否则我们必须跳到最近的边界。 
3. 对于每个下一段`[li, ri]`，我们考虑当前区间是否`[L, R]`已经重叠了。 如果是这样，那么我们可以通过在交叉点中选择合适的点来保持在重叠范围内，因此不需要新的距离。 
4. 如果没有重叠，则存在间隙。 如果`R < li`，最近可达点是`R`我们必须跳到`li`，至少需要`li - R`。 如果`ri < L`，我们必须向下跳要求`L - ri`。 
5. 我们累积所有步骤所需的最大跳跃，因为`k`必须支持最坏的转变。 
6. 考虑移动约束后，我们通过将扩展范围与当前段相交来更新可达间隔。 
7、最终的答案就是这个过程中遇到的最大差距。 

关键思想是每个步骤都会限制大小`k`必须是弥合连续可行间隔之间的距离。 

### 为什么它有效

 在每一步中，可达集都由连续间隔完整描述。 阻碍进步的唯一障碍是两个连续的间隔被间隙隔开。 该间隙的大小正是一次移动连接它们所需的最小跳跃，因为前一个间隔内的任何中间点到当前段边界的距离都是相等的。 由于后面的步骤只会进一步限制可行性，但不会减少已经满足的转换的要求，因此所有转换之间的最大间隙是最小有效的`k`。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        
        l0, r0 = map(int, input().split())
        L, R = l0, r0
        
        # distance needed from start 0
        if 0 < L:
            ans = L
        elif 0 > R:
            ans = -R
        else:
            ans = 0
        
        for _ in range(1, n):
            l, r = map(int, input().split())
            
            if R < l:
                ans = max(ans, l - R)
            elif r < L:
                ans = max(ans, L - r)
            
            L = max(L, l)
            R = min(R, r)
            
            if L > R:
                L, R = l, r
        
        print(ans)

if __name__ == "__main__":
    solve()
```代码跟踪当前的可行区间`[L, R]`。 读取每个片段后，它首先计算当前间隔与下一个片段之间的间隙。 如果它们不重叠，则该间隙将答案更新为候选下界`k`。 

更新内容`L = max(L, l)`和`R = min(R, r)`表示将可行性限制在可达位置与当前段的交集上。 如果该交集变空，则代码将重置为当前段，这反映了玩家在进行足够大小的有效跳跃后始终可以降落在段中的任何位置。 

一个微妙的点是将第一段与其余段分开处理，因为起始位置固定为 0。

 ## 边缘情况

 关键的边缘情况是第一个间隔已包含 0 时。在这种情况下，初始要求为零，因为不需要跳跃来着陆在第一个段内。 

另一种情况是间隔严格递增且不相交。 例如`[0,1] → [100,101] → [0,1]`。 该算法正确记录了从转换时发生的最大间隙`[0,1]`到`[100,101]`，生产`99`。 

一种微妙的情况是间隔部分重叠但仍然在一侧产生间隙。 例如`[0,10] → [20,30] → [15,25]`。 可达区间缩小并移动，使用边界计算间隙`R`反对`20`，产生正确的所需跳跃`10`。
