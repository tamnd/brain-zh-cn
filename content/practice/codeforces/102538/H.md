 ## 解决方案
 ## 问题理解

 我们有一个左右顶点数相同的二部图。 正确的顶点是有序的，并且`i`-第一个左侧顶点连接到第一个顶点`a[i]`右顶点。 任务是计算该图中存在多少个不同的顶点简单循环，其中当两个循环的边集不同时，它们被认为是不同的。 答案需要模数`998244353`。 

约束条件允许`n`最多 5000 个。直接枚举循环是不可能的，因为即使是结构化二分图也可能包含指数数量的循环。 一个`O(n^3)`解决方案已经太大了，而`O(n^2)`动态编程方法非常适合，因为在仔细实现的情况下，在 C++ 和 Python 中可以实现 2500 万次转换。 

主要困难在于循环不是独立的对象。 当我们以适当的顺序扫描顶点时，部分构建的循环可以分成多个路径。 该算法只需记住存在多少条这样的开放路径，而不是它们的确切端点。 丢失此信息会导致计数错误。 

具有一个左顶点和一个右顶点的小图是一种有用的边界情况。 输入```
1
1
```包含一条边但没有环，所以答案是`0`。 如果粗心的解决方案将任何重复连接计为一个循环，则会错误地返回`1`。 

另一个重要的情况是二乘二完全二部图：```
2
2 2
```恰好有一个循环使用所有四个顶点。 答案是`1`。 计算有向遍历而不是边缘集的解决方案对同一循环进行两次计数，每个方向各一次。 

最后一个棘手的情况是许多顶点具有相同的邻域。 例如：```
3
3 3 2
```有七个周期。 重复的前缀会产生许多重叠的可能性，因此独立处理每个左顶点会错过稍后合并的链的组合。 

## 方法

 暴力方法将生成顶点子集，检查每个子集是否形成一个简单循环，并计算有效的循环。 检查本身是多项式的，但子集的数量是指数的。 和`2n`顶点，搜索空间大致为`2^(2n)`，即使对于较小的值也变得不可用`n`。 

图结构提供了一种更好的方式来思考问题。 左侧顶点仅连接到右侧的前缀，因此如果我们按自然构造顺序对所有顶点重新排序，则每个左侧顶点都会连接到所有先前的右侧顶点。 这正是原来施工流程所描述的情况。 

在扫描顶点时，想象一下仅保留未来循环的选定边缘。 在循环闭合之前，所选边形成多个不相交的链。 由于有序性，所有这些链都具有相同的交替形状。 它们的确切顶点并不重要，重要的是它们的数量。 

让`dp[j]`是处理当前顶点前缀并获得的方法数`j`打开链条。 右顶点可以不被使用或者开始一个新的链。 左顶点可以连接两个现有的链末端并合并两条链，也可以关闭唯一剩余的链并创建一个完整的循环。 

蛮力方法之所以有效，是因为它直接探索每个可能的循环。 由于循环次数太大而失败。 通过观察所有未完成的结构具有相同的形状，我们可以将整个状态压缩为多个链，从而将问题简化为二次动态规划。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了|
 | 最佳| O(n²) | O(n) | 已接受 |

 ## 算法演练

 1. 对值进行排序`a[i]`并将该图视为一个序列`2n`事件。 在连续的左顶点之间，插入可用的右顶点。 在此变换之后，每个左顶点都连接到出现在它之前的所有右顶点。 
2. 维护`dp[j]`, 处理当前前缀并完全离开的方式数量`j`打开链条。 最初没有链条，所以`dp[0] = 1`。 
3. 处理右顶点时，要么忽略它，要么包含它。 包含它会创建一个新的开链，因为以前的顶点都无法连接到这个新的右顶点。 
4. 当处理左顶点时，它可以合并两个现有的链。 如果有`j`添加顶点之前的链，有`j * (j - 1)`有序选择要连接的两个链端。 状态从`j`链至`j - 1`链。 
5. 左顶点也可以闭合单个剩余链。 每当添加顶点之前当前链数为1时，新的循环完成，因此添加`dp[1]`到答案。 
6. 动态规划计数将循环的两个方向视为不同。 它还包括长度为二的循环，它们只是单个边对的平行遍历。 删除长度为二的贡献并将剩余计数除以二。 

为什么有效：处理完任何前缀后，每个未完成的循环组件都是一个交替链。 继续构建所需的唯一属性是存在多少条链，因为所有链在未来的顶点下都具有相同的行为。 延长或关闭这些链的每一种可能的方式都由一个转换来表示。 最后的划分消除了通过将链存储为有序对象而引入的人为方向。 

## Python 解决方案```python
import sys

input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    dp = [0] * (n + 3)
    dp[0] = 1

    ans = 0

    # Remove length-two cycles during the final normalization.
    for x in a:
        ans = (ans - x) % MOD

    prev = 0

    for x in a:
        # Insert right vertices that appear before this left vertex.
        for _ in range(prev + 1, x + 1):
            for j in range(n, 0, -1):
                dp[j] += dp[j - 1]
                if dp[j] >= MOD:
                    dp[j] -= MOD

        # Close a single chain.
        ans += dp[1]
        if ans >= MOD:
            ans -= MOD

        # Merge two chains using the current left vertex.
        for j in range(1, n + 1):
            add = dp[j] * j * (j - 1)
            add %= MOD
            dp[j - 1] += add
            if dp[j - 1] >= MOD:
                dp[j - 1] -= MOD

        prev = x

    ans %= MOD
    ans = ans * ((MOD + 1) // 2) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```排序后的数组表示新的右顶点在每个左顶点之前变得可见的时刻。 变量`prev`存储先前的前缀长度，因此仅处理新出现的右顶点。 

数组`dp`添加右顶点时以相反的顺序更新。 这可以防止一个新添加的顶点在同一转换中被多次使用。 

合并过渡使用`j * (j - 1)`因为必须选择两个不同的链。 在计算链端点时顺序很重要，这就是为什么该因子不仅仅是一个组合值。 

开始时的答案调整删除了两顶点封闭结构。 最终乘以 2 的模逆，消除了由每个实际循环的两个可能方向引起的重复计数。 

## 工作示例

 对于```

```处理过程如下所示：

 | 步骤| 加工对象| 之前开链 | 主要动作 | | 之后打开链 回答 |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 右顶点 | 0 | 开始连锁 | 1 | 0 |

为了```
3
3 3 2
```重要的状态是：

 | 步骤| 对象| dp[0] | dp[0] | dp[1] | dp[1] | dp[2] | dp[2] | 回答 |

## 测试用例```python
import sys
import io

MOD = 998244353

def solution(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    dp = [0] * (n + 3)
    dp[0] = 1
    ans = 0

    for x in a:
        ans = (ans - x) % MOD

    prev = 0
    for x in a:
        for _ in range(prev + 1, x + 1):
            for j in range(n, 0, -1):
                dp[j] = (dp[j] + dp[j - 1]) % MOD

        ans = (ans + dp[1]) % MOD

        for j in range(1, n + 1):
            dp[j - 1] = (dp[j - 1] + dp[j] * j * (j - 1)) % MOD

        prev = x

    return str(ans * ((MOD + 1) // 2) % MOD)

assert solution("1\n1\n") == "0"
assert solution("2\n2 2\n") == "1"
assert solution("3\n3 3 2\n") == "7"
assert solution("4\n1 1 1 1\n") == "0"
assert solution("5\n5 5 5 5 5\n") == "101"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 |`1 / 1`|`0`| 无循环的最小图 |
 |`2 / 2 2`|`1`| 基本四顶点循环和方向校正 |
 |`3 / 3 3 2`|`7`| 多个重叠周期|

 ## 边缘情况

 对于最小图：```
1
1
```该算法创建一个右顶点和一个左顶点。 右侧顶点创建一条开放链，但左侧顶点只能闭合一条包含足够循环边的链。 归一化后，结果仍然存在`0`。 

对于完整的二乘二图：```
2
2 2
```动态规划在第一个左顶点之前创建两条链。 第一个左侧顶点将它们合并，留下一条链。 左第二个顶点将其闭合并添加一个循环。 最后的除法去掉重复的方向，留下正确的答案`1`。 

对于重复的邻域：```
3
3 3 2
```相同的前缀连接出现多次。 状态压缩处理这个问题，因为每个左顶点只关心存在多少个未完成的链，而不关心哪些右顶点创建了它们。 合并转换计算所有可能的端点选择，产生完整的答案`7`。
