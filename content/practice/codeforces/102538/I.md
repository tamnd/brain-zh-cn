 # 问题理解

 我们得到一个整数数组。 每个整数代表一组启用的位。 对于每一个可能的面具`x`含有`k`位，我们需要找到第一个数组位置，其值至少包含一个缺失的位`x`。 如果每个数组值都是子掩码`x`，该位置被视为零。 任务是将这个值添加到所有`2^k`可能的面具。 

口罩的数量呈指数级增长`k`， 和`k`可以大到 60。对所有掩码的直接迭代将需要超过`10^18`操作，因此解决方案必须完全避免访问掩模。 数组长度只有100，这意味着操作正比于`n * k`很容易负担得起，而任何事情都取决于`2^k`是不可能的。 

棘手的情况来自于从未出现过的位以及首次出现在同一数组位置的多个位。 从未出现过的位不能使任何值无效，因此它不能提供虚假位置。 例如：```
Input:
2 2
0 1
```第一次出现的位置是位置 2 处的位 0，而位 1 从未出现。 只有位 0 很重要。 将丢失的位视为位置 0 或位置 1 会错误地增加答案。 

另一种情况是重复第一个位置：```
Input:
2 2
3 3
```两个位首先出现在位置 1。对于`x = 0`，答案是 1，因为两位都丢失了。 为了`x = 1`，位 1 丢失，答案仍然是 1。对位置进行排序并盲目地将 2 的幂分别分配给相等值的解决方案会过度计数。 同等位置必须组合在一起。 

# 方法

 暴力法直接遵循定义。 对于每一个面膜`x`从`0`到`2^k - 1`，我们从左到右扫描数组，直到找到第一个不是子掩码的值`x`。 单一价值的支票很便宜，但有`2^k`面具和最多`n`每个人的位置。 和`k = 60`, 这是周围`100 * 2^60`检查，这远远超出了可用时间。 

关键的观察结果是，口罩`x`仅通过它不包含的位才有趣。 对于每一位，找到该位出现的最早的数组位置。 如果`x`错过了一点`b`，那么第一个无效数组元素的出现必须不晚于第一次出现`b`。 事实上，答案是`x`是所有缺失位中的最小第一次出现`x`。 

现在问题变成了位位置的计数问题，而不是所有掩码的计数问题。 假设所有出现的位的第一次出现都已排序。 如果某个值是最小缺失出现次数，则每个较小的出现次数必须属于出现在`x`，并且所选的出现必须属于不存在的位。 剩余的较大位是免费的。 对相同的出现进行分组可以处理同时成为候选的多个位。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^k * n) | O(2^k * n) | O(1) | O(1) | 太慢了|
 | 最佳| O(nk + k log k) | O(nk + k log k) | O(k) | 已接受 |

 # 算法演练

 1. 对于每一位`0`到`k - 1`，找到包含该位的第一个数组索引。 忽略从未出现的位，因为它们永远不会使掩码失败。 
2. 收集所有现有的第一位置并对其进行排序。 相同的位置必须保持分组，因为多个位可能同时成为第一个丢失的位。 
3. 处理每组相等的位置。 假设一个组包含`cnt`位，有`smaller`具有较小第一位置的位，以及`larger`具有较大第一位置的位。 
4. 为了让这组人确定答案，所有`smaller`位必须存在于`x`。 当前组中，至少有一位必须缺失。 该组内的选择数为`2^cnt - 1`，并且所有较大的位都不受限制，给出`2^larger`的可能性。 
5. 添加```
position * (2^cnt - 1) * 2^larger
```对答案取模`998244353`。 

为什么它有效：

 每个面膜`x`在其中缺失的位中具有唯一的最小首次出现。 该算法精确计算属于每个组的最小丢失位的掩码。 不能缺少较小的群体，因为这会产生更早的答案。 当前的群体不能完全存在，因为那样它就不会做出贡献。 较大的组不会影响最小值并且可以自由选择。 这些箱子恰好覆盖了所有可能的面具一次。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    first = [n + 1] * k

    for i, x in enumerate(a, 1):
        for b in range(k):
            if (x >> b) & 1 and first[b] == n + 1:
                first[b] = i

    vals = [x for x in first if x != n + 1]
    vals.sort()

    pow2 = [1] * (len(vals) + 1)
    for i in range(1, len(pow2)):
        pow2[i] = (pow2[i - 1] * 2) % MOD

    ans = 0
    i = 0
    m = len(vals)

    while i < m:
        j = i
        while j < m and vals[j] == vals[i]:
            j += 1

        cnt = j - i
        larger = m - j

        ways = (pow2[cnt] - 1) * pow2[larger] % MOD
        ans = (ans + vals[i] * ways) % MOD

        i = j

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```第一个数组存储每个位的最早位置。 位置是从一开始的，因为所需的值是数组索引，而不是从零开始的偏移量。 

名单`vals`仅包含实际发生的位。 对它进行排序允许从左到右计算最小缺失位。 

分组循环是重要的部分。 如果多个位共享相同的首次出现，则算法会将它们一起处理。 表达式`2^cnt - 1`计算组中至少丢失一位的所有方式，同时`2^larger`考虑稍后出现的位。 

Python 整数不会溢出，但所有乘法都会减少模数`998244353`以匹配所需的输出格式。

 对于：```

为了：```
2 2
2 1
```第一个位置是：

 | 位| 第一名 |
 | --- | --- |
 | 0 | 2 |
 | 1 | 1 |

| 集团立场| 位数 | 更大的位| 贡献 |
 | --- | --- | --- | --- |

 答案是4。四个掩码产生值`1, 1, 2, 0`。

 # 边缘情况

 当某个位从未出现时，它不应该参与排序列表。 例如：```
2 2
0 1
```只有位 0 在位置 2 处首次出现。该算法完全忽略位 1 并生成 2。为位 1 添加假值会错误地计算掩码。 

当几个位第一次一起出现时，它们必须算作一组。 为了：```
2 2
3 3
```两个位的第一个位置都是 1。存在三个掩码，其中至少有一个位丢失，并且所有这些位都贡献值 1。贡献为`1 * (2^2 - 1) = 3`从这些掩模中，剩余的掩模贡献为零。 该算法的分组公式直接捕捉到了这一点。
