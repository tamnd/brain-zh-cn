 ## 解决方案
 ## 问题理解

 该问题描述了一棵树，并要求我们可以对其执行所需操作的最大次数。 树由其顶点数和每个顶点的度数表示。 度数为 1 的顶点是叶子，而度数大于 1 的顶点是内部顶点。 答案仅取决于存在多少个内部顶点以及树中的顶点总数。 

关键的观察结果是，每个操作都需要一对顶点，这些顶点可以组合成新的结构，同时保留形成有效树的可能性。 可能的操作数量受到两种不同资源的限制。 具有 n 个顶点的树最多只能包含一半数量的不相交对，并且叶顶点不能重复提供有用的对，除非在最小的可能树中。 因此，最终的答案是一半顶点与内部顶点数之间较小的值。 

约束的设计使得必须直接处理度数。 如果 n 约为 10^5，则任何尝试每个可能的顶点对的方法都会变得太慢，因为它需要大约 10^10 次检查。 线性扫描就足够了，因为解决方案只需要计算满足简单度数条件的顶点。 

在一些边缘情况下，如果不小心实施，直接公式可能会失败。 最小的树是第一棵。 对于有两个顶点的树，两个顶点都是叶子，因此内部顶点的数量为零。 然而，答案是一个，因为仍然可以选择唯一可能的一对。 

例如，考虑输入：```
2
1 1
```正确的输出是：```
1
```始终返回内部顶点数的解决方案将错误地输出零。 

另一个边界情况是星形树。 考虑：```
5
4 1 1 1 1
```只有一个内部顶点，所以答案是 1。 n / 2 值较大，但没有足够的内部顶点来创建更多有效操作。 仅考虑顶点数量的解决方案会高估答案。 

路径还会检查相反的边界。 为了：```
6
1 2 2 2 2 1
```有四个内部顶点，n/2 等于 3，所以答案是 3。 仅计算内部顶点将错误地返回 4。 

## 方法

 一种简单的方法是尝试模拟合并过程。 我们可以重复搜索合适的顶点对，更新树，并计算可能的操作次数。 这是正确的，因为它直接遵循流程的定义。 然而，它需要维护树的变化结构并反复寻找候选者。 在最坏的情况下，检查所有可能的对需要 O(n²) 工作，这远远超出了大树的合理范围。 

蛮力之所以有效，是因为每个有效操作都被显式探索，但当树变大时，它就会失败。 观察到答案仅由内部顶点的数量和不相交对的最大数量控制，这让我们可以避免完全构建操作。 

设 x 为度数大于 1 的顶点数。 答案不能超过 x，因为每个有用的操作都需要一个内部顶点。 它也不能超过 n/2，因为每个操作消耗两个顶点。 剩下的任务是证明这个上限总是可以实现的。 

证明背后的构造是重复组合具有最小度数的顶点和具有最大度数的顶点。 执行此 min(n / 2, x) 次留下足够的结构来将合并对表示为较小的有效树。 重要的结果是，仅度信息就足够了，因此实际的树边是不必要的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 读取顶点数并检查每个顶点的度数。 计算有多少个顶点的度数大于 1。 这些是唯一可以得出答案的顶点。 
2. 如果树恰好包含两个顶点，则立即返回一个。 这处理了没有内部顶点但仍可以进行一项操作的特殊情况。 
3. 根据两个独立的限制计算最大可能的操作数。 第一个限制是内部顶点的数量。 第二个限制是所有顶点可以形成的对的数量，即floor(n / 2)。 
4. 输出这两个值中较小的一个。 该值是可以实现的，因为合并参数表明始终可以形成足够的有效对。 

为什么它有效：

 答案不能大于内部顶点的数量，因为在具有两个以上顶点的树中，两个叶子不能形成有用的对。 它也不能超过可用顶点对的数量。 重复连接最小度数顶点与最大度数顶点的构造证明了这些可能的操作中的每一个实际上都可以实现。 在执行所需次数的合并之后，剩余的结构仍然具有有效的树度，因此上限也是下限。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    data = list(map(int, sys.stdin.read().split()))
    if not data:
        return

    n = data[0]
    degrees = data[1:]

    if n == 2:
        print(1)
        return

    internal = 0
    for d in degrees:
        if d > 1:
            internal += 1

    print(min(n // 2, internal))

if __name__ == "__main__":
    solve()
```该程序只需要学位序列。 它首先处理特殊的二顶点树，因为通用公式会错误地返回零。 

对于所有其他情况，循环都会对度数大于 1 的顶点进行计数。 变量`internal`表示证明中的 x 值。 最终表达式使用整数除法，因为只有完整的顶点对才重要。 

Python 中不存在溢出问题，因为整数值是任意精度的，并且最大存储值只是顶点的数量。 运算顺序也很重要：在应用通用公式之前必须检查特殊情况。

import sys
import io

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    data = list(map(int, sys.stdin.read().split()))
    if data:
        n = data[0]
        degrees = data[1:]

        if n == 2:
            print(1)
        else:
            internal = sum(1 for d in degrees if d > 1)
            print(min(n // 2, internal))

    return result

 ## 边缘情况

 两个顶点树是该公式需要例外的唯一情况。 为了：```
2
1 1
```该算法立即返回 1。 如果没有此检查，内部顶点的计数为零，并且答案将是错误的。 

对于星树：```
5
4 1 1 1 1
```该算法仅计算一个内部顶点。 然后它将 1 与 Floor(5 / 2)（即 2）进行比较，并返回 1。 这遵循以下不变式：当叶子支配树时，内部顶点是限制资源。 

对于路径：```
6
1 2 2 2 2 1
```该算法计算四个内部顶点。 由于六个顶点中仅存在三个不相交对，因此它返回三个。 这验证了第二个限制是否正确应用。 

该算法不需要知道顶点之间的实际连接。 度数序列恰好包含所需的信息，因为证明表明具有相同相关度数的每棵树都具有相同的最大答案。
