 ## 解决方案
 ## 问题理解

 我们有一个无向图。 每条边必须从一组以 5 为模的余数中接收一个值，这意味着可能的值是`0, 1, 2, 3, 4`。 当每个顶点都有其总和可被 5 整除的入射边值时，标记有效。 

任务是计算存在多少个有效的边缘标签。 答案以模数形式打印`998244353`。 

输入由多个图形实例组成。 每个实例给出顶点和边的数量，后面是每条边连接的顶点对。 该图可以断开连接，因此每个连接的组件必须独立处理。 

这些约束使得线性或几乎线性的解决方案成为必要。 所有测试用例的顶点和边的总数是有界的，因此图的遍历是可以承受的。 任何试图枚举分配的方法都没有机会，因为每条边都有五个选择，给出`5^m`的可能性。 即使是中等大小的图表也会使其变得天文数字般大。 

主要隐藏的困难是理解独立约束的数量。 一个常见的错误是假设每个顶点条件都会删除一个自由度。 这是错误的，因为顶点方程并不总是独立的。 一棵树和一个奇数循环的行为不同，并且断开的组件会增加它们的贡献。 

例如，单个孤立的顶点没有边。```
1 0
```只有一项空作业，所以答案是`1`。 假设每个连接的组件都贡献一个循环自由度的解决方案会错误地在此处添加一些内容。 

三角形是另一个重要的情况。```
3 3
1 2
2 3
3 1
```答案是`1`。 三个顶点方程在模五上是独立的，因为周期是奇数。 将每个循环视为添加一个自由变量会错误地产生`5`。 

正方形显示相反的行为。```
4 4
1 2
2 3
3 4
4 1
```答案是`5`。 围绕偶数循环的交替赋值创建一个自由变量。 如果方法只检查图形是否包含循环，而不检查它是奇数还是偶数，则会错过这一点。 

## 方法

 直接的解决方案将尝试每种可能的边值分配并测试顶点和。 这是正确的，因为每个可能的标签都会被检查，并且只计算有效的标签。 然而，随着`m`这需要边缘`5^m`作业。 对于具有数十万条边的图来说这是不可能的。 

有用的观察来自于将问题视为场模五的线性系统。 每条边都是一个变量。 每个顶点给出一个方程，要求相邻边变量的总和为零。 如果有`m`变量和系统有等级`r`，解的数量为：`5^(m-r)`整个问题变成了求图的类关联矩阵的秩。 

对于连接的组件`n`顶点，等级仅取决于组件是否是二分的。 如果该分量是二部的，则顶点方程具有一个依赖性，因此秩为`n-1`。 如果组件不是二分的，则奇数循环会消除该依赖性，并且排名变为`n`。 

蛮力法之所以有效，是因为方程完全描述了有效的分配，但它却失败了，因为它忽略了线性系统的结构。 只有排名重要的观察结果让我们可以用图遍历代替指数枚举。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(5^m · (n+m)) | O(5^m · (n+m)) | O(n+m) | 太慢了|
 | 最佳| O(n+m) | O(n+m) | 已接受 |

 ## 算法演练

 1. 构建图的邻接表。 每条边都在两个方向上存储，因为稍后我们需要遍历连接的组件并测试二分性。 
2. 从每个未访问的顶点运行广度优先搜索或深度优先搜索。 在遍历过程中，为每个顶点分配两种颜色之一。 如果一条边连接两个具有相同颜色的顶点，则该分量不是二分的。 
3. 计算当前连接组件内的顶点和边的数量。 如果该组件是二分组件，则添加`vertices - 1`到总排名。 否则，添加`vertices`到总排名。 

不需要直接使用边数的原因是每个组件根据其顶点数和奇偶校验结构做出贡献。 边数仅出现在指数的后面。 

1. 处理完所有分量后，将答案计算为：`5^(total_edges - total_rank)`使用模幂。 

为什么它有效：

 图方程形成一个模五的线性系统。 齐次线性系统的解数`m`变量和等级`r`正是`5^(m-r)`，因为每个自由变量都可以独立地取五个值之一。 

对于连接的二分组件，所有具有交替符号的顶点方程的总和会抵消每条边，从而创建一个依赖关系。 因此，等级比顶点数少一。 对于非二分组件，奇数循环可以防止这种依赖性，因此等级等于顶点数。 将这些连接组件的等级相加就得到了整个系统的等级，这使得最终的指数是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    it = iter(data)
    t = int(next(it))
    ans = []

    for _ in range(t):
        n = int(next(it))
        m = int(next(it))

        g = [[] for _ in range(n)]
        for _ in range(m):
            a = int(next(it)) - 1
            b = int(next(it)) - 1
            g[a].append(b)
            g[b].append(a)

        color = [-1] * n
        rank = 0

        for start in range(n):
            if color[start] != -1:
                continue

            color[start] = 0
            stack = [start]
            vertices = 0
            bipartite = True

            while stack:
                v = stack.pop()
                vertices += 1

                for u in g[v]:
                    if color[u] == -1:
                        color[u] = color[v] ^ 1
                        stack.append(u)
                    elif color[u] == color[v]:
                        bipartite = False

            if bipartite:
                rank += vertices - 1
            else:
                rank += vertices

        ans.append(str(pow(5, m - rank, MOD)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```邻接表构造对应于算法的第一个步骤。 每条边出现两次，但这仅影响遍历时间，而不影响数学计数。 

DFS 堆栈维护当前连接的组件。 数组`color`存储两种着色的尝试。 当先前访问过的邻居具有相同的颜色时，该分量包含奇数循环，因此它不是二分的。 

变量`rank`存储所有组件的总排名贡献。 最后的调用`pow`使用Python的模幂运算，避免构造巨大的值`5^(m-rank)`直接地。 

不存在溢出问题，因为 Python 整数是任意精度的，并且模幂可以控制中间值。 指数永远不会是负数，因为系统的秩不能超过边缘变量的数量。 

## 工作示例

 对于三角形：```
3 3
1 2
2 3
3 1
```遍历的行为如下。 

| 当前组件 | 找到顶点 | 两方| 排名贡献| 指数|
 | --- | --- | --- | --- | --- |
 | 三角形| 3 | 没有| 3 | 3 - 3 = 0 | 3 - 3 = 0

 三角形有奇数圈，因此不存在自由变量。 答案是`5^0 = 1`。 

对于正方形：```
4 4
1 2
2 3
3 4
4 1
```遍历给出：

 | 当前组件 | 找到顶点 | 两方| 排名贡献| 指数|
 | --- | --- | --- | --- | --- |
 | 方形| 4 | 是的 | 3 | 4 - 3 = 1 | 4 - 3 = 1

 偶数循环创造了一个自由度。 答案是`5^1 = 5`。

import sys
import io

MOD = 998244353

def solution(inp):
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    res = []

    for _ in range(t):
        n, m = map(int, input().split())
        g = [[] for _ in range(n)]

        for _ in range(m):
            a, b = map(int, input().split())
            a -= 1
            b -= 1
            g[a].append(b)
            g[b].append(a)

        color = [-1] * n
        rank = 0

        for i in range(n):
            if color[i] != -1:
                continue

            stack = [i]
            color[i] = 0
            cnt = 0
            ok = True

            while stack:
                v = stack.pop()
                cnt += 1
                for u in g[v]:
                    if color[u] == -1:
                        color[u] = color[v] ^ 1
                        stack.append(u)
                    elif color[u] == color[v]:
                        ok = False

            rank += cnt - 1 if ok else cnt

        res.append(str(pow(5, m - rank, MOD)))

    return "\n".join(res)

 ## 边缘情况

 对于孤立顶点：```
1 0
```该组件包含一个顶点且没有边。 它是二分的，所以它的排名贡献是`1-1=0`。 指数是`0-0=0`, 给予`1`。 该算法不会错误地删除不存在的自由度。 

对于一棵树：```
5 4
1 2
2 3
3 4
4 5
```该图是二分图。 组件等级为`5-1=4`，匹配边数。 指数为零，因此每个边缘值都被强制，并且仅保留全零分配。 

对于奇数周期：```
3 3
1 2
2 3
3 1
```当最后一条边连接两个颜色相同的顶点时，着色尝试检测到冲突。 组件等级变为`3`而不是`2`。 指数变为零，这正确地只给出了一个有效的赋值。 

对于偶数循环：```
4 4
1 2
2 3
3 4
4 1
```着色成功。 排名贡献为`3`，留下一个自由边变量。 指数为 1，因此该组件提供五个解。 该算法无需显式构建循环即可捕获额外的自由度。
