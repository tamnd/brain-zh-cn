 **求解时间：** 1m 18s

 ## 解决方案
 ## 问题理解

 办公室表示为矩形网格。 每个大写字母代表桌子的一部分，所有具有相同字母的单元格都属于同一个矩形桌子。 总统的办公桌颜色为`c`。 

副手是指与总统办公桌的至少一个单元共用一侧的任何办公桌。 对角线接触不算数。 空单元格标记为`.`也不算。 任务是计算总统办公桌旁边有多少张不同颜色的桌子。 

网格尺寸最多为`100 × 100`，所以整个网格最多包含`10,000`细胞。 这个值足够小，多次扫描整个网格是完全安全的。 甚至一个`O(n * m * 4)`解决方案仅执行大约`40,000`邻居检查。 

主要困难不是性能，而是避免重复计算和正确处理邻接关系。 

一个容易犯的错误是多次计算相同的相邻颜色。 考虑这个网格：```
3 3 A
BBB
BAB
BBB
```正确答案是`1`，因为只有颜色`B`触摸总统的办公桌。 一种粗心的实现，每次看到相邻的值时都会增加答案`B`会错误输出`4`。 

另一个微妙的情况是意外地计算空单元格：```
2 3 A
.A.
...
```正确答案是`0`。 总统的办公桌周围只有空地，这不能算在内。 

第三个常见错误是将总统自己的肤色算作副手。 例如：```
3 4 A
AAAA
ABBA
AAAA
```正确答案是`1`。 虽然每`A`细胞接触其他细胞`A`牢房，这些仍然是总统办公桌的一部分，必须被忽略。 

边界处理也很重要。 如果总统的办公桌触及网格边缘，邻居检查可能会超出范围：```
2 2 A
AB
..
```正确答案是`1`。 任何盲目检查四个方向而不验证坐标的实现都有访问无效索引的风险。 

## 方法

 一个蛮力的想法是检查网格中的每个单元格。 每当我们找到总统牢房时，我们都会检查所有四个相邻位置并记录我们看到的任何不同的办公桌颜色。 

对于给定的约束，这种方法已经足够快了。 网格最多有`10,000`单元，每个单元最多执行四次邻居检查。 那只是周围`40,000`运营。 

唯一剩下的问题是重复计数。 相邻的办公桌可能在很多地方与总统的办公桌接触。 使用列表并重复搜索它在这里仍然有效，但是集合更干净并且自动保证唯一性。 

关键的观察是我们实际上并不关心存在多少相邻单元格。 我们只关心总统办公桌旁边出现了多少种不同的颜色。 一旦看到某种颜色，出现其他颜色就不再重要了。 

这将问题简化为使用一组收集有效相邻颜色的简单网格遍历。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解重复计数 | O(n × m × k) | O(n × m × k) | O(k) | 不必要的混乱|
 | 最佳使用一套| O(n × m) | O(k) | 已接受 |

 这里，`k`是不同相邻颜色的数量，最多是`26`。 

## 算法演练

 1. 阅读网格尺寸和总统办公桌颜色。 
2. 将网格存储为字符串列表，以便可以使用以下命令访问每个单元格`grid[row][col]`。 
3. 创建一个空集，名为`neighbors`。 

该套件将存储与总统办公桌相邻的每种不同颜色的办公桌。 
4. 遍历网格中的每个单元格。 

每当当前单元格包含总统的颜色时，检查其四个相邻位置。 
5. 对于四个方向中的每一个，计算相邻坐标。 

方向是：`(1, 0)`,`(-1, 0)`,`(0, 1)`,`(0, -1)`。 
6. 忽略不在网格内的邻居。 

当总统的办公桌接触边界时，这可以防止无效索引。 
7. 读出相邻的字符。 

如果是：

 -`.`，忽略它，因为空单元不是桌子。 
- 与总统颜色相同，忽略它，因为是同一张桌子。 
- 否则，将其插入集合中。 
8. 处理完整个网格后，打印集合的尺寸。 

### 为什么它有效

 每个副办公桌必须与至少一个主席办公室共用一侧。 该算法检查每个总统单元格的所有四个边相邻邻居，因此发现每个有效的副总统颜色。 

即使同一张桌子上的许多单元格接触到总统的桌子，这套装置也能保证每种颜色都被精确计数一次。 

任何空的或属于总统的单元格都会被明确忽略，因此该集合恰好包含不同的副办公桌颜色。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m, c = input().split()
n = int(n)
m = int(m)

grid = [input().strip() for _ in range(n)]

neighbors = set()

directions = [
    (1, 0),
    (-1, 0),
    (0, 1),
    (0, -1)
]

for i in range(n):
    for j in range(m):
        if grid[i][j] == c:
            for dx, dy in directions:
                ni = i + dx
                nj = j + dy

                if 0 <= ni < n and 0 <= nj < m:
                    ch = grid[ni][nj]

                    if ch != '.' and ch != c:
                        neighbors.add(ch)

print(len(neighbors))
```该程序首先读取总统办公桌的尺寸和颜色。 由于第一个输入行包含整数和字符，因此这些值最初会作为字符串读取，然后在需要时进行转换。 

网格完全按照给定的方式存储。 因为字符串支持索引，`grid[i][j]`可以直接访问任何单元格。 

这`neighbors`set 是解决方案的中心思想。 相邻的桌子颜色可能会在总统办公桌周围多次出现，但一组会自动删除重复项。 

嵌套循环扫描整个网格。 每当找到总统单元格时，代码都会使用以下命令检查四个边相邻的位置：`directions`大批。 这避免了重复的代码并使逻辑更容易验证。 

边界检查在访问网格之前发生。 如果没有它们，边缘上的单元格将导致索引错误。 

条件：```
if ch != '.' and ch != c:
```过滤掉无效的邻居。 空单元格将被忽略，总统自己的办公桌颜色也将被忽略。 

最后，答案只是该集合中存储的唯一颜色的数量。

 最大网格尺寸仅为`10,000`细胞，因此线性扫描在 2 秒限制内非常快。 内存使用量可以忽略不计，因为辅助集仅包含桌面颜色。

import io

def solve():

    n, m, c = input().split()

    m = int(m)

    grid = [input().strip() for _ in range(n)]

    neighbors = set()

    directions = [
        (1, 0),
        (-1, 0),
        (0, 1),
        (0, -1)

 ## 边缘情况

 考虑同一张相邻桌子在多个地方接触总统的情况：```
3 3 A
BBB
BAB
BBB
```算法访问中心`A`细胞并检查所有四个邻居。 每个邻居都是`B`， 所以`B`被插入集合四次。 由于集合仅保留唯一值，因此最终集合仍然存在`{B}`并且输出正确`1`。 

现在考虑空单元格：```
2 3 A
.A.
...
```总统牢房位于`(0,1)`。 它的邻居都是`.`或在网格之外。 条件：```
if ch != '.' and ch != c:
```拒绝每个空单元格，因此集合保持为空并且算法打印`0`。 

接下来，考虑总统自己的办公桌碰自己的情况：```
3 4 A
AAAA
ABBA
AAAA
```许多`A`细胞与其他细胞相邻`A`细胞。 在邻居检查期间，条件`ch != c`防止将总统自己的颜色添加到集合中。 仅有的`B`已插入，所以答案是`1`。 

最后，考虑边界处理：```
2 2 A
AB
..
```当检查邻居时`(0,0)`，两个方向产生无效坐标，例如`(-1,0)`和`(0,-1)`。 边界条件：```
0 <= ni < n and 0 <= nj < m
```在对网格进行索引之前将其过滤掉。 剩余的有效邻居被正常处理，产生正确的答案`1`。
