 ## 解决方案
 ## 问题理解

 我们被要求模拟将编号的足球按照特定顺序放入一排篮子的过程。 每个新球必须放入当前包含球最少的篮子中。 如果多个篮子中的球数量最少，我们会选择最靠近该行中心的一个。 如果仍然平局，我们选择指数较小的篮子。 

输入给出两个整数：球的总数`n`以及篮子总数`m`。 输出是一个长度序列`n`，其中`i`-第一个数字是接球篮的索引`i`。 必须按照添加球的顺序计算序列，因为每个新球都取决于当前的篮子配置。 

限制因素很大。 两个都`n`和`m`最大可达 100,000。 一种简单的方法是扫描所有篮子中的每个球，这需要`n*m`操作，在最坏的情况下可以达到 10^10——太大而无法在 2 秒内执行。 这意味着我们需要一种避免全面扫描并利用选择规则的可预测结构的策略。 

当球的数量小于篮子的数量时，会出现微妙的边缘情况。 例如，如果`n = 2`和`m = 5`，第一个球应该进入中心篮（`3`），第二个球应该进入距离中心最近的下一个篮子（`2`或者`4`）。 如果粗心地假设所有篮子总是至少被装满一次，那么在这种稀疏的情况下将会失败。 

## 方法

 暴力解决方案很简单。 我们可以维护一个长度的数组`m`代表每个篮子里的球的数量。 对于每个球，我们将扫描数组以找到数量最少的篮子，然后首先按到中心的距离，然后按索引来打破平局。 这种方法可以正常工作，但需要`O(n * m)`操作，这对于大量输入来说是不切实际的。 为了`n = m = 10^5`，这将涉及大约 100 亿次操作。 

关键的见解是选择标准产生了一个非常结构化的序列。 第一个球总是进入中心篮筐。 第二个球进入紧邻中心的两个篮筐之一。 第三个球传到中心的另一侧。 继续这种锯齿形模式可以保证我们随时将下一个球放入空篮或球最少且最靠近中心的篮子中。 因为放置顺序并不取决于确切的球号，而只取决于篮子的图案，所以我们可以预先计算篮子的顺序`O(m)`时间，然后反复迭代以分配所有`n`球。 

这将复杂性降低到`O(n)`与一个小`O(m)`预处理步骤，对于给定的约束来说足够快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n*m) | O(米) | 太慢了 |
 | 最佳 | O(n) | O(米) | 已接受 |

 ## 算法演练

 1. 计算篮子行的中心为`(m + 1) // 2`。 根据问题定义，这是最接近中间的篮子。 
2. 生成一系列篮子指数，从中心开始，左右交替，向外扩展。 如果我们根据规则一次装满一个球，这给出了将接收球的篮子的确切顺序。 模式为：center、center-1、center+1、center-2、center+2 等。 
3. 初始化一个数组来存储球分配结果。 
4. 迭代从 1 到 1 的所有球`n`。 按照预先计算的顺序将每个球分配到下一个篮子。 如果我们到达序列的末尾（发生在`n > m`），继续循环执行该序列，因为每个篮子现在将有多个球。 
5. 按照分配的顺序打印每个球的篮子索引。 

为什么它有效：这里的不变性是预先计算的序列总是选择球数最少且最靠近中心的篮子。 通过循环执行这个序列，我们完全复制了 Valeric 的方案。 因为每个篮子都会以正确的顺序重新访问，所以平局会自动处理，并且通过生成围绕中心从左到右的序列，也可以自然地满足最小索引的平局打破者。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

center = (m + 1) // 2
order = [center]

# expand left and right alternately
for d in range(1, m):
    if center - d >= 1:
        order.append(center - d)
    if center + d <= m:
        order.append(center + d)

# assign balls
res = []
for i in range(n):
    res.append(str(order[i % m]))

print("\n".join(res))
```该代码首先计算中心篮子，然后构建一个向外扩展的预先计算的篮子序列。 循环`for i in range(n)`依次分配每个球，当球的数量超过篮子的数量时，循环执行序列。 通过使用包容性检查可以避免差一错误`>= 1`和`<= m`。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    center = (m + 1) // 2
    order = [center]
    for d in range(1, m):
        if center - d >= 1:
            order.append(center - d)
        if center + d <= m:
            order.append(center + d)
    res = []
    for i in range(n):
        res.append(str(order[i % m]))
    return "\n".join(res)

# provided samples

 ## 边缘情况

 当`n < m`， 例如`n = 2, m = 5`，算法将第一个球分配给中心（`3`）和第二个最接近的篮子（`2`）。 其余的篮子将被忽略，因为没有足够的球到达它们。 预先计算的序列可确保通过接近中心和索引顺序自动打破最少球的平局。 这避免了任何手动最小计数扫描，这是幼稚实现中微妙错误的常见来源
