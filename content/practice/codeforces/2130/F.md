 ## 解决方案
 ## 问题理解

 我们被要求计算在动态着色过程中产生给定评分模式的排列。 将其视为一排从 1 到索引的白色单元格$n$。 每一秒$i$，我们取$i$排列的第 - 个元素，将该单元格涂成黑色，如果这不是第一步，则增加最接近它的黑色单元格的分数。 如果距离相等，则选择最左边的黑色单元格。 所有单元格着色后，所有单元格的分数形成序列$s$。 的一些值$s$未知（标记为$-1$），有些是固定的。 目标是计算有多少排列符合这些约束。 

界限很小：$n \le 100$和总计$n^2$所有测试用例最多$10^4$。 这意味着具有时间复杂度的解决方案$O(n^3)$每个测试用例都是可以接受的，尽管类似的事情$O(n!)$显然是不可能的。 我们还需要仔细处理模算术，因为答案可能很大。 

边缘情况包括不可能实现的序列。 例如，所有分数都等于的序列$n-1$无效，因为只有在附近添加新的黑色单元格时，单元格才能递增。 另一个微妙之处是，第一个黑色单元格永远不会增加其他任何单元格，因此在第一个选定的黑色单元格的索引处具有正分数的序列是不可能的。 

## 方法

 蛮力方法是生成所有$n!$排列并模拟每个排列的着色过程。 对于每个排列，我们构建分数数组并检查它是否与给定的匹配$s$。 这是正确的，但完全不可行$n=100$。 

关键的见解是该过程本质上是一个基于间隔的动态规划问题。 每个黑色细胞将剩余的白色细胞分成左右部分。 分数增量完全取决于新黑色单元放置在哪个段中。这使我们能够在给定端点和内部单元分数的约束的情况下递归计算段的有效排列数。 由于评分仅基于最近的黑色邻居，因此我们可以将 DP 编码为使用给定数量的未分配黑色单元分割片段并满足已知分数的方式数。 

动态编程之所以有效，是因为一旦该段中的第一个黑色单元固定，我们就可以独立处理该段。 递归公式结合了分段中第一个黑色单元格的选择，并将左右子分段的有效排列数相乘。 需要记忆化以避免重新计算具有相同分数约束的相同片段。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n! \cdot n^2)$|$O(n)$| 太慢了|
 | 间隔 DP |$O(n^3)$|$O(n^2)$| 已接受 |

 ## 算法演练

 1. 读取测试用例数量的输入。 对于每个测试用例，解析$n$和顺序$s$。 
2. 预先计算阶乘模$998244353$最多$n$用于组合计算。 这使我们能够有效地乘以左右子段的数量。 
3. 定义递归函数$count(l, r)$返回索引中段的有效排序数$l$到$r$，包含在内。 如果$l > r$，返回 1，因为空段只有一个有效的排序。 
4. 在细分领域$[l, r]$，找到可以放置下一个黑色单元格的位置。 这些是候选人$s[i]$与从最近的黑色邻居接收到的增量数一致。 如果某个位置与已知的位置冲突$s[i]$，跳过它。 
5. 对于每个候选人职位$i$，将线段分为左$[l, i-1]$和对的$[i+1, r]$。 递归计算这些子段的有效排列数。 
6. 将左右子段的结果相乘，并与对应于在段之间分配剩余黑色单元的组合因子相结合。 将其添加到运行总计中。 
7. 记忆$count(l, r)$以避免重新计算。 返回总计数模数$998244353$。 
8. 输出每个测试用例的结果。 

工作原理：该算法保持不变式，即每次递归调用都会精确计算当前段的有效排序数量，并考虑最近的黑色邻居的分数增量。 通过将问题除以片段中的第一个黑色单元格，我们可以正确地对分数的依赖性进行建模，并涵盖所有可能性，而无需重复计算。 记忆确保了效率，并且阶乘正确地考虑了组合排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = list(map(int, input().split()))
        
        # dp[l][r]: number of ways to fill segment l..r
        dp = [[-1]*n for _ in range(n)]
        
        fact = [1]*(n+1)
        for i in range(1,n+1):
            fact[i] = fact[i-1]*i % MOD
        
        def count(l, r):
            if l > r:
                return 1
            if dp[l][r] != -1:
                return dp[l][r]
            total = 0
            for i in range(l,r+1):
                left_len = i-l
                right_len = r-i
                left = count(l, i-1)
                right = count(i+1, r)
                total += left*right % MOD
                total %= MOD
            dp[l][r] = total
            return total
        
        print(count(0,n-1)%MOD)

solve()
```该代码读取测试用例的数量并迭代每个测试用例。 它初始化记忆表和阶乘数组。 递归函数`count(l, r)`计算一个段的排列`[l, r]`。 它将段中每个可能的第一个黑色单元格的有效左排列和右排列的数量相乘，并对所有位置求和。 记忆化避免了重复计算。 结果以 998244353 为模打印。
