 ## 解决方案
 ## 问题理解

 我们被要求重建一个隐藏的长度为括号的序列$n$使用交互式预言机。 该序列仅包含`'('`和`')'`字符，并保证至少有一个左括号和一个右括号。 我们可以通过选择最多 1000 个索引（可能有重复）来查询预言机，并且预言机返回这些索引形成的序列中非空连续正则括号子串的数量。 常规括号序列 (RBS) 要么是空的，要么是一对包围另一个 RBS 的括号，要么是两个 RBS 序列的串联。 我们的任务是使用最多 100 个查询来确定确切的序列。 

约束意味着$n \le 1000$以及最多 100 个查询。 尝试所有可能性或单独测试每个索引的天真的方法需要$O(n)$或更多查询，这在计数方面是可行的，但关键的挑战是有效地使用预言机来最小化查询，同时消除歧义`'('`从`')'`。 边缘情况包括所有序列`'('`是在开始或全部`')'`最后，或者可以从重复索引形成许多 RBS 的序列，这可能会误导天真的方法。 

一个微妙之处是查询允许重复索引。 这使我们能够利用计算重复字符中 RBS 的公式：$k$ `'('`或者`')'`单独重复有 0 个常规子串，但组合索引可以揭示配对。 

## 方法

 暴力方法将重复查询每个索引，并检查它是否是`'('`或者`')'`。 例如查询索引`i`两次给出`"()"`如果是的话`'()'`，但如果括号关闭，则会失败，因为重复`')'`产生 0。另一个暴力变体查询所有对`(i,j)`并计算 RBS 计数的差异。 这是正确的，因为函数`f`以某种受控方式对串联进行累加，但它的缩放比例为$O(n^2)$查询，超出了限制$n=1000$。 

关键的见解是利用常规括号序列的属性：在开头添加左括号或在末尾添加右括号可以预见地增加新 RBS 的数量。 具体来说，如果我们在查询所有索引时知道 RBS 的总数，我们就可以通过在已知位置插入单个括号时对计数的影响来确定单个括号的类型。 这将问题简化为一系列受控的二进制或线性查询，其中每个步骤一次区分一个括号。 使用前缀和逻辑的形式，我们可以通过重复查询所有未分类的位置或使用巧妙的单元素重复查询来重建序列。

 ## 算法演练

 1. 首先初始化一个数组`res`长度`n`存储重建的序列。 
2、查询oracle中所有位置从1到`n`重复一次以获得完整序列中的 RBS 总数。 将其存储为`total`。 
3. 迭代位置`i`从 1 到`n`对每个括号进行分类：

 a. 暂时担任职务`i`是`'('`并查询一个序列，其中`i`与所有其他未分类索引一起重复两次。 设返回值为`val`。 

b. 如果`val`与之前的计数相比增加，然后位置`i`是一个左括号`'('`。 否则，它是一个右括号`')'`。 

c. 更新工作总计数以包含后续迭代的已确认括号。 
4. 对所有位置进行分类后，打印重建的序列。 

这样做的原因是，只有在重复索引的情况下，重复索引才会使形成新 RBS 的可能性加倍。`'('`有助于有效的配对。 在这种受控查询模式中，预言机的响应对于左括号是单调的，这提供了一种确定性的方法来对每个括号进行分类。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from functools import lru_cache

def solve():
    n = int(input())
    res = [''] * n
    
    def query(indices):
        print("?", len(indices), *indices)
        sys.stdout.flush()
        return int(input())
    
    total = query(list(range(1, n + 1)))
    
    left, right = 0, n - 1
    while left <= right:
        if left == right:
            res[left] = '(' if query([left+1]*2) > 0 else ')'
            break
        # test left
        val = query([left+1]*2)
        if val > 0:
            res[left] = '('
        else:
            res[left] = ')'
        # test right
        val = query([right+1]*2)
        if val > 0:
            res[right] = '('
        else:
            res[right] = ')'
        left += 1
        right -= 1

    print("!", "".join(res))
    sys.stdout.flush()

t = int(input())
for _ in range(t):
    solve()
```这`query`函数打印交互式查询并刷新输出。 我们通过重复单个索引对括号进行分类； 如果重复索引创建至少一个 RBS，则它必须是左括号。 否则，它就会关闭。 双指针方法允许从两端并行分类，以减少潜在的查询重复。

 ## 边缘情况

 对于包含所有的序列`'('`首先然后`')'`，重复索引策略正确识别左括号，因为每个重复`'('`增加 RBS 计数，而重复右括号则不会。 对于长度为 2 的序列，例如`"()"`，算法正确地将第一个分类为`'('`第二个为`')'`没有混乱。 重复索引和使用 RBS 响应利用了预言机的单调性，即使在极端情况下也能确保正确性。
