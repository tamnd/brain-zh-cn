 ## 解决方案
 ## 问题理解

 我们给出的时间表是`n`步骤，以及`m`猫，每只都由间隔定义`[l_i, r_i]`其间出现。 在每一步中，我们都可以喂饱在场的所有猫，但是多次喂养一只猫就会造成损失。 我们的任务是选择一些喂猫的步骤，这样就不会喂猫两次，并且我们最大化喂猫的总数。 

输入描述了多个测试用例。 每个测试用例提供`n`和`m`其次是`m`间隔。 每个测试用例的输出是一个整数：可以喂食的猫的最大数量。 

约束条件允许`n`最多`10^6`和`m`最多`2*10^5`每个测试用例，但所有测试的总和是有限的。 这表明算法`O(n * m)`复杂度太慢； 我们需要更接近的东西`O(m log m)`或者`O(n + m)`。 每个间隔至少有一步长，因此像这样的琐碎情况`l_i = r_i`必须处理。 

非明显边缘情况包括完全重叠的多个间隔、长度为一的间隔以及非常大的间隔`n`间隔稀疏。 根据每个间隔检查每个步骤的幼稚方法将会失败。 例如，如果两只猫出现在完全相同的台阶上`[1, 5]`和`[1, 5]`，如果一只猫选择了步骤，粗心的贪婪喂养策略可能会喂得过多`1`对于两者。 在这种情况下正确的输出是`1`，在其中一个台阶处只喂一只猫。 

## 方法

 蛮力方法是考虑以下步骤的所有子集`1`到`n`并计算有多少个区间被覆盖而没有重叠。 这在理论上是正确的，但不可行，因为它需要检查`2^n`子集。 即使迭代所有间隔的所有步骤也会导致`O(n*m)`操作，对于最大约束来说太慢了（`10^6 * 2*10^5`）。 

关键的见解是，在猫的时间间隔内只喂一次就足够了。 因此，我们可以将其建模为区间调度问题：选择点以使每个区间最多包含一个点。 如果我们按照区间的右端点对区间进行排序，并贪婪地选择最早的可能步骤进行馈送，那么我们就可以最大化覆盖的区间数量，而不会发生冲突。 这是有效的，因为尽早喂食可以最大限度地减少未来与重叠间隔发生冲突的可能性。 

贪婪的选择是按区间的右端点对区间进行排序`r_i`并迭代它们，跟踪我们提供的最后一步。 对于每个间隔`[l_i, r_i]`，如果最后一次喂食步骤超出了间隔，我们可以在`r_i`。 否则，我们跳过它。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * m) | O(n + m) | 太慢了 |
 | 通过区间排序贪心| O(m log m) | O(米) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读`n`和`m`。 初始化一个空的间隔列表。 
2. 阅读`m`间隔`[l_i, r_i]`并将它们存储在列表中。 
3. 按区间的右端点排序`r_i`。 排序确保我们首先考虑喂养最早离开的猫。 
4. 初始化变量`last_fed = -1`追踪我们喂猫的最后一步。 
5. 初始化`count = 0`跟踪喂食的猫的数量。 
6. 迭代排序间隔`[l_i, r_i]`：

- 如果`last_fed < l_i`，这意味着最后一个进料步骤与该间隔不冲突。 
- 步进进给`r_i`并设置`last_fed = r_i`。 
- 增量`count`。 
- 如果`last_fed >= l_i`，跳过这个时间间隔，因为现在喂食会使猫吃得过多。 
7.处理完所有区间后，打印`count`对于这个测试用例。 

为什么有效：按正确的端点排序可确保我们始终做出局部贪婪选择，从而最大化未来的喂养机会。 一旦我们喂食`r_i`，没有任何先前或重叠的间隔可以使选择无效，并且没有猫会被喂两次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def feed_cats():
    t = int(input())
    results = []
    for _ in range(t):
        n, m = map(int, input().split())
        intervals = []
        for _ in range(m):
            l, r = map(int, input().split())
            intervals.append((l, r))
        # Sort by right endpoint
        intervals.sort(key=lambda x: x[1])
        last_fed = -1
        count = 0
        for l, r in intervals:
            if last_fed < l:
                last_fed = r
                count += 1
        results.append(str(count))
    print("\n".join(results))

if __name__ == "__main__":
    feed_cats()
```这段代码完全遵循算法。 排序依据`r_i`确保贪心选择有效。`last_fed`跟踪最后的喂食步骤。 条件`last_fed < l`保证没有猫被喂两次。 使用`sys.stdin.readline`确保大型测试用例的快速输入。

 ## 边缘情况

 如果所有间隔完全重叠，算法仍然只选择不冲突的喂食点。 用于输入`[1,3],[1,3],[2,3]`，它在第一个间隔的第 3 步喂食，如果 last_fed 冲突，则跳过第二个和第三个间隔，从而以最佳方式喂两只猫。 长度为 1 的间隔被同等对待； 条件`last_fed < l`正确防止过量喂食。 稀疏间隔不会造成额外的步骤； 该算法自然地跳转到下一个有效的进料步骤。
