 ## 解决方案
 ## 问题理解

 猴子通过重复按固定键盘上的随机键来输入字符。 每次按键都是独立的，并且遵循可用字母的已知概率分布。 我们还得到了一个特定的目标单词，以及猴子将进行的固定击键次数。 

对于每个测试用例，我们需要推理从这个随机打字过程中得出的两个量。 首先，目标单词预计在结果字符串中作为连续子字符串出现多少次。 其次，假设我们在计算上限时可以按照对我们有利的方式来安排打字顺序，那么目标在最佳可能结果中出现的最大次数是多少。 

每个测试用例的输出是这两个值之间的差值，解释为您必须携带但最终不会平均支付的“香蕉”数量。 直观上，它衡量的是在为最坏情况发生做准备时，单词的随机性和重叠结构在多大程度上导致了不可避免的高估。 

关键输入元素是键盘分布、目标单词和生成字符串的长度。 键盘决定字母概率，目标定义我们正在搜索的模式，长度控制存在多少个潜在的起始位置。 

这些限制意味着我们无法模拟猴子的打字。 即使对于像 10^5 这样的中等长度，生成所有字符串也是不可能的，因为状态空间呈指数增长。 相反，我们必须依赖子串对齐的概率和组合学。 任何对位置进行二次模拟或显式字符串生成的解决方案都将在时间限制下立即失败。 

一些边缘情况很容易被忽略。 

如果键盘不包含来自目标的至少一个字符，则形成目标的概率为零，并且预期出现次数和最大出现次数都为零。 

如果目标具有很强的自我重叠，例如“AAA”，则简单的计数将低估最大可能发生的次数。 例如，在长度为 4 的字符串中，由于重叠，“AAA”可能会出现两次：“AAAA”。 

如果目标根本不能与自身重叠，例如“ABCD”，则每次出现都会消耗长度为 L 的完整块并移位 L。 

## 方法

 暴力破解的想法是模拟猴子生成的每个可能的长度为 S 的字符串，并计算目标在每个字符串中出现的次数。 我们将计算每个字符串的概率和总贡献。 这在概念上是正确的，但可能的字符串数量在 S 中呈指数关系，特别是 K^S，其中 K 是键盘字母的数量。 即使 S = 100，这也是完全不可行的。 

一种更结构化的暴力改进是通过扫描每个位置并检查子字符串是否与目标匹配来计算预期发生的情况。 这给出了 O(S·L) 的期望时间，并且仍然忽略了重叠结构。 为了获得最大的出现次数，我们可以贪婪地滑动单词并尝试所有位置，但这仍然需要重复匹配，并且对于大 S 来说效率很低。 

关键的观察是期望不需要模拟。 每个起始位置独立地贡献于预期计数。 位置准确地贡献了从该位置开始的子串等于目标的概率。 该概率只是从键盘分布导出的单个字符概率的乘积。 这完全消除了期望位置之间的依赖。

对于最大值，该结构是纯组合的。 我们希望将尽可能多的目标副本放置在长度为 S 的字符串中，并允许重叠。 这简化为找到保留前缀后缀重叠的最小移位，这由前缀函数（KMP 故障数组）精确捕获。 一旦我们知道在仍然有效重叠的情况下可以将模式移动多远，我们就可以贪婪地平铺字符串并计算有多少完整副本适合。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(K^S·S·L) | O(K^S·S·L) | O(S)| 太慢了|
 | 概率 + KMP 重叠 | O(K + L) | O(K + L) | 已接受 |

 ## 算法演练

 ### 预期发生的情况

 1. 根据键盘频率计算每个字符出现在猴子打字序列中的概率。 这给出了字母表上的分布。 
2. 对于从 0 到 S − L 的每个位置 i，计算从 i 开始的子串与目标完全匹配的概率。 

这是通过乘以目标中每个字符的概率来完成的。 
3. 将所有有效起始位置的概率相加。 该总和是预期出现的次数。 

每个位置都被独立处理，因为即使子串重叠，期望也是线性的。 

### 最大出现次数

 1. 使用前缀函数（KMP 失败数组）计算目标的最长正确前缀（同时也是后缀）。 设该值为b。 
2. 计算连续重叠出现之间的偏移：shift = L − b。 

这是我们可以移动图案同时仍允许重叠一致性的最小步骤。 
3. 如果目标根本不能与自身重叠，则 b = 0，shift = L。 
4. 将最大出现次数计算为 1 + (S − L) // 移位。 

###最终答案

 1. 结果是最大出现次数减去预期出现次数。 

### 为什么它有效

 期望值分解依赖于期望的线性。 尽管事件重叠且不独立，但每个起始位置都会贡献独立于其他位置的固定概率，因此对所有起始位置求和会给出正确的期望。 

最大构造取决于目标中的自重叠结构。 前缀函数准确地确定将一个出现位置移至下一个出现位置时可以重用多少字符串。 任何更密集的包装都会违反前缀后缀一致性，因此这种转变是最佳的，并且任何排列都会减少重复这种重叠模式。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def prefix_function(s):
    n = len(s)
    pi = [0] * n
    j = 0
    for i in range(1, n):
        while j > 0 and s[i] != s[j]:
            j = pi[j - 1]
        if s[i] == s[j]:
            j += 1
            pi[i] = j
    return pi

def solve():
    T = int(input())
    for tc in range(1, T + 1):
        K, L, S = map(int, input().split())
        keyboard = input().strip()
        target = input().strip()

        freq = {}
        for c in keyboard:
            freq[c] = freq.get(c, 0) + 1

        prob = 1.0
        possible = True
        for c in target:
            if c not in freq:
                possible = False
                break
            prob *= freq[c] / K

        expected = 0.0
        if possible:
            expected = (S - L + 1) * prob if S >= L else 0.0

        pi = prefix_function(target)
        overlap = pi[-1]
        shift = L - overlap

        if S < L:
            maximum = 0
        else:
            maximum = 1 + (S - L) // shift

        print(f"Case #{tc}: {maximum - expected:.10f}")

if __name__ == "__main__":
    solve()
```该解决方案首先构建键盘字符的频率图，用于计算在任意固定位置生成目标字符串的概率。 目标字符之间的乘法直接反映了击键的独立性。 

prefix 函数计算目标字符串的最长边界。 该边界决定了连续发生的事件之间可能有多少重叠。 从它派生的移位定义了最大化出现次数的字符串平铺。 

最后，以高精度打印最大值和预期之间的差异，以避免浮点截断问题。 

## 工作示例

 ### 示例 1

 考虑一个小情况，其中键盘是平衡的并且目标很短，因此很容易看到重叠。 

设 S = 4，目标 =“AA”，键盘 =“AB”。 

预期发生的情况：

 | 我| 子串开始 | 概率匹配 |
 | --- | --- | --- |
 | 0 | AA | 1/4 | 1/4
 | 1 | AA | 1/4 | 1/4
 | 2 | AA | 1/4 | 1/4

 每个“A”的概率为 1/2，因此每个“AA”的概率为 1/4。 求和得出预期 = 3/4。 

最大出现次数：

 目标“AA”与移位 1 自身重叠，因此在长度 4 中，我们可以将出现次数设置为“AAAA”，从而产生 3 次出现。 

差值 = 3 − 0.75 = 2.25。 

### 示例 2

 令 S = 5，目标 =“ABC”，键盘 =“ABC”。 

预期中只存在一个有效字符串，其中所有字符都确定性匹配，因此预期出现 3 个子字符串：“ABCABC”出现 2 次，但由于 S = 5，实际字符串会有所不同。 期望值来自位置概率，而最大值来自移位 3 的无重叠平铺。 

这表明期望仅取决于局部概率，而最大值取决于结构重叠。

 ## 边缘情况

 当目标包含键盘中不存在的字符时，每个位置与其匹配的概率为零。 期望立即变为零，因为所有贡献都消失了。 最大值也为零，因为根本无法形成有效的出现。 

当目标具有最大自重叠（例如“AAAAA”）时，前缀函数会产生较大的边界。 这会将移位减少到 1，这意味着出现的次数可以密集地堆叠。 该算法正确地将其视为整个字符串中近乎连续的放置。 

当目标没有重叠时，例如“ABCDE”，前缀函数返回零边框，使移位等于全长。 然后，该算法将出现的事件不相交地放置，符合直觉，即匹配之间不可能重用。
