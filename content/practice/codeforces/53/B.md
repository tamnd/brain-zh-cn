 ## 解决方案
 ## 问题理解

 我们得到上传照片的尺寸、高度`h`和宽度`w`。 我们想从中切出一个更小的矩形。 切出的矩形必须满足三个条件。 

首先，它的维度必须是整数。 

其次，其长宽比必须保持在允许的范围内：$0.8 \leq \frac{H}{W} \leq 1.25$第三，矩形的至少一条边必须是 2 的精确幂。 

在所有有效的矩形中，我们选择面积最大的一个。 如果几个矩形的面积相同，我们会选择高度较大的一个。 

原始照片可以大到`10^9 × 10^9`。 这立即排除了任何迭代所有可能的高度和宽度的方法。 维度上的双循环需要大约`10^18`在最坏的情况下进行检查，这是完全不可行的。 即使单独迭代每个可能的高度也已经太慢了。 

从约束中观察到的关键是，2 的幂呈指数增长。 最多`10^9`，大约只有 31 种不同的 2 的幂。 正是这个微小的搜索空间使问题变得易于管理。 

有几种边缘情况可能会悄悄破坏粗心的实现。 

考虑输入：```
2 1
```原图像的比例为`2`，超出了允许的范围。 我们无法保留整个形象。 最好的有效矩形是`1 × 1`。 总是保持一侧不变的贪婪方法在这里会失败。 

考虑：```
100 3
```与高度相比，宽度非常小。 如果我们强制高度为 2 的幂，大多数选择都会产生无效的比率。 最佳答案受到比率要求的约束，而不是直接受原始尺寸的约束。 

另一个棘手的情况是多个矩形具有相同的面积。 例如：```
8 10
```两个都`8 × 8`和`4 × 10`有面积`64`和`40`分别，因此较大的面积获胜。 但也有出现面积相等的情况，这时我们就必须选择高度较大的矩形。 缺少这条平局规则会导致隐藏测试的错误答案。 

另一个微妙的问题来自整数除法。 比率范围是包容性的，浮点比较可能会引入精度问题。 使用不等式如$4H \geq 5W \quad \text{and} \quad 5H \leq 4W$完全避免了精度。 

## 方法

 蛮力的想法很简单。 我们尝试每一个可能的矩形`(H, W)`这样`1 ≤ H ≤ h`和`1 ≤ W ≤ w`。 对于每个矩形，我们检查比率是否有效以及是否至少有一条边是 2 的幂。 在所有有效候选者中，我们保留面积最大的候选者。 

这是合乎逻辑的，因为搜索是详尽的。 每一种可能的切割都会被检查，因此最好的切割不会被错过。 

问题在于规模。 如果两个维度都是`10^9`，矩形的数量大致为`10^18`。 即使将其减少到单个高度的循环，仍然会留下多达十亿次迭代，远远超出了 2 秒的时间。 

二次幂条件的结构改变了一切。 至少一侧必须属于这个小集合，而不是任意维度：```
1, 2, 4, 8, 16, ...
```最多`10^9`，这样的数字只有31个。 

这意味着我们可以迭代每一个可能的二次方并直接导出最大的兼容对边。 

假设我们固定高度`H`作为二的幂。 那么宽度必须满足：$0.8 \leq \frac{H}{W} \leq 1.25$重新排列给出：$\frac{4H}{5} \leq W \leq \frac{5H}{4}$为了最大化这个固定高度的面积，我们显然希望在该范围内和原始图像边界内获得最大可能的宽度。 

我们重复相同的过程，宽度固定为 2 的幂。 

现在整个搜索仅检查大约 62 个候选者，这实际上是常数时间。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(高 × 宽) | O(1) | O(1) | 太慢了|
 | 最佳 | O(log(最大(h, w))) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.生成不超过2的每一个幂`max(h, w)`。 

这样的值大约只有 31 个，因为 2 的幂呈指数增长。 
2. 将 2 的每个幂视为可能的高度。 

令这个固定高度为`ph`。 
3. 计算比率条件允许的最大宽度。 

从$\frac{ph}{W} \geq 0.8$我们得到：$W \leq \frac{5ph}{4}$所以最大可行宽度为：```
min(w, floor(5 * ph / 4))
```4. 验证该宽度是否也满足比率下限。 

我们需要：$\frac{ph}{W} \leq 1.25$变成：$4ph \leq 5W$如果条件失败，则不存在此固定高度的有效矩形。 
5. 计算面积并更新最佳答案。 

我们首先最大化面积。 如果面积相等，我们更喜欢高度较大的矩形。 
6. 重复相同的过程，宽度固定为 2 的幂。 

这种对称传递保证我们不会错过只有宽度是 2 的幂的情况。 

### 为什么它有效

 对于固定的二次方高度，每个有效矩形的宽度都在连续区间内。 由于该地区是`height × width`，且高度固定，面积随宽度单调增加。 这意味着该高度的最佳选择始终是最大可行宽度。 

固定宽度时也适用相同的论点。 

由于每个有效矩形必须至少有一个边等于 2 的幂，因此该算法会检查每个可能的有效矩形类别。 在每个类中，它都会选择最好的区域。 在所有类别中，它保持全局最优。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def better(h1, w1, h2, w2):
    a1 = h1 * w1
    a2 = h2 * w2

    if a1 != a2:
        return a1 > a2

    return h1 > h2

def solve():
    h, w = map(int, input().split())

    best_h = 1
    best_w = 1

    p = 1
    while p <= max(h, w):
        # Fix height = p
        if p <= h:
            max_w = min(w, (5 * p) // 4)

            if 4 * p <= 5 * max_w:
                if better(p, max_w, best_h, best_w):
                    best_h = p
                    best_w = max_w

        # Fix width = p
        if p <= w:
            max_h = min(h, (5 * p) // 4)

            if 4 * max_h >= 5 * p:
                if better(max_h, p, best_h, best_w):
                    best_h = max_h
                    best_w = p

        p *= 2

    print(best_h, best_w)

solve()
```辅助函数`better`集中比较逻辑。 该问题使用两个标准，首先是最大面积，其次是最大高度，因此将此逻辑保留在一个地方可以避免重复的条件。 

该循环通过重复乘以 2 来迭代 2 的幂。这比使用对数或浮点运算安全得多，因为不存在舍入问题。 

当高度固定为`p`，我们选择原始图像和比例约束允许的最大宽度。 由于面积随着宽度而增长，因此没有理由测试更小的宽度。 

比率检查仅使用整数算术：$4H \leq 5W \quad \text{and} \quad 4H \geq 5W$这可以避免边界附近的浮点精度错误`0.8`和`1.25`。 

该算法是对称的。 一次将高度固定为 2 的幂，另一次将宽度固定。 缺少任何一半都会失去有效的最佳矩形。

 ## 边缘情况

 考虑输入：```
2 1
```算法测试能力`1`和`2`。 

为了`p = 2`作为高度，候选矩形变为`(2, 1)`。 比例检查：$4 \cdot 2 \leq 5 \cdot 1$失败是因为`8 ≤ 5`是假的。 矩形被正确拒绝。 

剩下的有效候选人是`(1, 1)`，这成为答案。 

现在考虑：```
100 3
```尝试`p = 64`因为高度产生的最大宽度为：```
floor(5 × 64 / 4) = 80
```但实际图像宽度仅为`3`，因此候选宽度变为`3`。 比率条件立即失败，因为矩形仍然太高。 

最终算法达到`p = 2`和`p = 1`，但最佳有效矩形变为`(3, 3)`从固定宽度`3`。 正方形满足所有条件并使面积最大化。 

最后，考虑一个打破平局的情况：```
10 13
```该算法找到了两者`(8, 10)`和`(10, 8)`, 每个都有面积`80`。 

比较函数首先检查面积，然后检查高度。 由于区域匹配，`(10, 8)`因为身高而获胜`10`大于`8`。 这完全符合问题的要求。
