 ## 解决方案
 ## 问题理解

 我们有`n`土堆放置在一条直线上的位置`1, 2, ..., n`。 青蛙想要访问每个土墩一次，因此我们必须输出这些位置的排列。 

有趣的限制是跳跃。 如果青蛙按顺序访问土堆`p1, p2, ..., pn`，则跳跃长度为：$$|p_1 - p_2|,\ |p_2 - p_3|,\ \dots,\ |p_{n-1} - p_n|$$所有这些距离必须不同。 

输入仅包含一个整数，`n`，我们需要构建任何有效的访问顺序。 

限制非常小。 甚至一个`O(n^2)`验证步骤很容易符合限制，因为`n ≤ 10^4`。 重要的是找到一种始终有效的建设性模式。 对排列进行穷举搜索是完全不可能的，因为`n!`爆发式增长。 即使是为了`n = 12`，已经有数亿种排列。 

棘手的部分是，一条路由可能在本地看起来有效，但在全局上却失败，因为某些跳转长度稍后会重复。 

例如，考虑：```
1 3 2 4
```跳跃长度为：```
2, 1, 2
```距离`2`出现两次，所以该路由无效。 

另一个容易犯的错误是假设连续增加的距离会自动起作用。 为了`n = 5`，序列：```
1 5 2 4 3
```产生跳跃：```
4, 3, 2, 1
```这是有效的，但是小的变化会立即破坏它。 例如：```
1 4 2 5 3
```给出：```
3, 2, 3, 2
```出现两个重复的距离。 

最小值也值得关注。 

为了`n = 1`，根本没有跳跃，所以任何单个土墩都可以。 

为了`n = 2`，正好有一个跳转，它自动是唯一的。 

建设性算法必须自然地处理这些边界情况，而无需特殊处理。 

## 方法

 暴力方法会产生排列`1..n`并测试所有跳跃长度是否不同。 

正确性是显而易见的。 如果我们最终找到一个连续绝对差都不同的排列，那么它就直接满足问题。 

问题在于搜索空间。 有`n!`排列。 即使检查一种排列只需要`O(n)`，总复杂度变为：$$O(n \cdot n!)$$这几乎立即变得无法使用。 为了`n = 15`，排列的数量已经超过一万亿。 

关键的观察是跳跃长度必须不同，并且恰好有`n - 1`跳跃。 唯一可能的不同跳跃长度是：$$1, 2, 3, \dots, n-1$$因此，有效的构造必须仅使用每个可能的距离一次。 

这强烈建议构建序列，以便跳跃以受控方式减少：$$n-1,\ n-2,\ n-3,\ \dots,\ 1$$实现此目的的一种非常自然的方法是在最小未使用位置和最大未使用位置之间交替。 

例如，与`n = 7`：```
1 7 2 6 3 5 4
```跳跃长度变为：```
6, 5, 4, 3, 2, 1
```每个距离都只出现一次。 

为什么这种交替模式会起作用？ 因为每次我们从剩余区间的一端移动到另一端时，区间都会缩小一。 第一次跳跃几乎跨越整个数组，下一次跳跃则少跨越一个数组，依此类推。 

这将问题从不可能的排列搜索转变为直接的建设性解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(n \cdot n!)$|$O(n)$| 太慢了|
 | 最佳 |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 从两个指针开始：`left = 1`和`right = n`。 

这些代表最小和最大的未使用的土墩位置。 
2. 创建一个空的答案数组。 
3.同时`left <= right`，以交替顺序附加位置。 

首先追加`left`，然后增加`left`。 

之后，如果还有未使用的位置，则追加`right`，然后减少`right`。 
4. 继续，直到所有位置都被恰好使用一次。 

例如，当`n = 6`：

 1.添加`1`2.添加`6`3. 添加`2`4. 添加`5`5. 添加`3`6. 添加`4`序列变为：```
1 6 2 5 3 4
```跳跃长度为：```
5, 4, 3, 2, 1
```每一次跳跃都比前一次小一倍。 

### 为什么它有效

 在每一步中，序列都会在剩余未使用间隔的两端之间跳转。 

假设剩余间隔为`[L, R]`。 

当我们从一侧移动到另一侧时，跳跃长度为：$$R - L$$使用一个端点后，间隔缩小一，因此下一跳变为：$$(R - L) - 1$$这种情况一直持续到区间崩溃为止。 

产生的跳跃长度恰好是：$$n-1,\ n-2,\ \dots,\ 1$$所有的土墩都是不同的，并且每个土墩只使用一次，因为每个位置在添加后立即从考虑中删除。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())

left = 1
right = n

ans = []

while left <= right:
    ans.append(left)
    left += 1

    if left <= right:
        ans.append(right)
        right -= 1

print(*ans)
```实施直接跟随构造。`left`跟踪最小的未使用土堆并`right`追踪最大的未使用土堆。 每次迭代都会从左侧添加一个值，从右侧添加一个值。 

条件`if left <= right`当`n`很奇怪。 如果没有它，中间的元素将被添加两次。 

例如，与`n = 5`，插入后：```
1 5 2 4
```两个指针都变成`3`。 我们应该附加`3`正好一次。 

该算法永远不需要显式计算跳跃长度，因为该结构通过设计保证了正确性。

import sys, io

def solve():
    input = sys.stdin.readline

    n = int(input())

    left = 1
    right = n

    ans = []

    while left <= right:
        ans.append(left)
        left += 1

        if left <= right:
            ans.append(right)
            right -= 1

    print(*ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

 ## 边缘情况

 对于`n = 1`，输入为：```
1
```该算法开始于`left = right = 1`。 

它附加`1`, 增量`left`到`2`，并停止，因为`left > right`。 

输出是：```
1
```没有跳跃，因此唯一性条件得到了满足。 

为了`n = 2`，算法产生：```
1 2
```唯一的跳跃长度是：```
|1 - 2| = 1
```不可能有重复，因为只有一次跳转。 

对于奇数，例如`n = 5`，中间位置是危险部位。 

该构造给出：```
1 5 2 4 3
```跳跃是：```
4, 3, 2, 1
```中心值`3`由于以下条件，只出现一次：```
if left <= right:
```如果没有这个条件，中间元素将被插入两次，从而破坏排列要求。 

对于更大的偶数值，例如`n = 8`，算法输出：```
1 8 2 7 3 6 4 5
```跳跃是：```
7, 6, 5, 4, 3, 2, 1
```这证实了每一次新的跳跃都会减少一的不变量。
