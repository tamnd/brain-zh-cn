 ## 解决方案
 ## 问题理解

 棋盘开始时，从 1 到 n 的每个整数都只写一次。 操作删除两个现有数字 a 和 b 并用其平均值的上限替换它们。 重复此操作 n - 1 次后，只剩下一个数字。 任务是使最终数字尽可能小，并打印实现该数字的所选对的序列。 

n 的值可以大到 200000，因此任何重复搜索所有当前棋盘值或模拟许多可能选择的方法都是不可能的。 解决方案每个操作只需执行恒定量的工作，因为已经有 n - 1 个操作必须打印。 这排除了具有二次行为的方法，例如尝试每一个可能的对。 

一个常见的错误是假设始终组合两个最小值是最佳的。 该操作不是普通的平均，因为结果向上舍入，并且构造需要控制哪些值保留，而不仅仅是减少当前最小值。 例如，当n = 3时，输入​​为：```
3
```粗心的贪婪策略可能会先将 1 和 2 组合起来，产生 2，然后将 2 和 3 组合起来，产生 3。最终值变成 3，但最优输出留下 2。正确的顺序是先组合 2 和 3，产生 3，然后组合 1 和 3，产生 2。 

另一个边缘情况是 n = 2。没有空间创建重复值或执行多步骤构造。 唯一可能的操作是将 1 和 2 组合起来，得到 2，因此任何假设始终可以使用重复值的算法都会失败。 

## 方法

 暴力解决方案会尝试不同的对来发现尽可能小的最终数字。 这是正确的，因为每个有效的操作序列都可以表示为成对选择树，并且探索所有树最终会找到最佳值。 问题是可能的选择数量增长得非常快。 即使第一个操作也有大约 n² 个可能的对，并且有 n - 1 个操作，使得详尽的探索远远超出了可用的限制。 

关键的观察结果是，最小可能答案始终为 2。该操作在最后永远不会产生小于 2 的值，因为最后一个操作组合了两个正整数，并且归约后可用的最小可能对无法创建 1。剩下的挑战是构造达到 2 的操作。 

该构造通过反复创建受控大值并将其向下移动来进行。 首先，将 n 和 n - 2 组合起来。结果是 n - 1，因为这两个数字的平均值恰好是 n - 1。然后将 n - 1 与其自身组合，再次产生 n - 1。 此后，相同的想法可以应用于剩余的较低数字：将 i 与 i + 2 组合以减少 i 。 每项操作都会删除一个未使用的数字，同时保留重要的值可用。 最终剩下的数字就只剩下2了。 

蛮力之所以有效，是因为它探索了所有可能的约简，但当 n 增长时，它会失败，因为搜索空间巨大。 通过观察该操作可以保留精心选择的值，我们可以用直接构造来代替搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(可能的操作树的数量) | O(n) | 太慢了 |
 | 最佳 | O(n) | 除了输出 | O(1) 已接受 |

 ## 算法演练

 1. 打印 2 作为最小最终值。 下面的结构总是留下这个数字。 
2. 如果n等于2，则直接组合1和2。 它们的四舍五入平均值是 2，这是唯一可能的答案。 
3. 如果 n 大于 2，则将 n 和 n - 2 合并。生成的值为 n - 1，因为 ceil((n + n - 2) / 2) 等于 n - 1。 
4. 将n - 1 与n - 1 合并。这将保持n - 1 不变并删除原始n - 1 值。 
5. 对于从n - 3 到1 的每一个i，将i 和i + 2 合并。此阶段当前棋盘包含i + 2，操作创建i + 1，它成为下一步所需的值。 

该结构向下移动 1 的原因是每个操作都会将两个距离为 2 的数字转换为中间的数字。 这使我们能够消除所有大值，同时维持最终达到 2 的单个链。 

为什么它有效：

 不变量是在处理数字 i 后，所有大于 i + 1 的值都已被删除，并且棋盘仍然包含值 i + 1。前两个操作为最大值建立了这个不变量。 接下来的每个操作都会保留它，因为组合 i 和 i + 2 会创建 i + 1。当 i 达到 1 时，最后一个操作组合 1 和 3，产生 2。由于最终值不可能低于 2，因此该构造是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    ans = ["2"]

    if n == 2:
        ans.append("1 2")
    else:
        ans.append(f"{n - 2} {n}")
        ans.append(f"{n - 1} {n - 1}")
        for i in range(n - 3, 0, -1):
            ans.append(f"{i} {i + 2}")

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```该程序存储输出行而不是在每次操作后打印。 这避免了不必要的输出开销，同时仍然仅使用线性内存来生成答案。 

特殊情况 n = 2 单独处理，因为一般构造需要数字 n - 2 和 n - 1 存在。 对于较大的 n，第一个操作使用 n 和 n - 2，它们始终是有效值。 该循环从 n - 3 处开始，在 1 处停止，在前两个操作之后恰好产生 n - 3 个附加操作，总共 n - 1 个操作。 

所有算术都保持在正常整数限制内，因为涉及的最大值是 n，最多为 200000。

 | 步骤| 运营| 由此产生的重要价值|

 该迹线显示了如何保持不变量。 前两次操作后，剩余的大值逐一减少，直到只剩下2。 

## 复杂度分析

 | 测量| 复杂性 | 说明|

 这些限制需要线性解，因为 n 可以达到 200000。该算法为每个操作执行少量固定工作，因此很容易满足时间限制。

 ## 边缘情况

 对于 n = 2，棋盘仅包含 1 和 2。算法立即打印唯一可能的操作，`1 2`。 结果值为 ceil(3 / 2)，等于 2。 

对于 n = 3，该算法不使用特殊情况。 它首先将1和3组合起来，创建2，然后将2和2组合起来，保留2。最终值仍然是2，并且构造避免了先减少最小数的错误策略。 

对于较大的 n，该算法从不显式存储棋盘。 它只打印一个序列，其值在使用时保证存在。 即使 n 达到 200000，递减循环也保证不会请求无效对。
