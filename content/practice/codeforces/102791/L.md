 ## 解决方案
 ## 问题理解

 我们有一个有向无环图。 每条边都从分配值较大的顶点到分配值较小的顶点。 如果一条边从`x`到`y`，其贡献为`w * (a[x] - a[y])`。 任务是将整数值分配给顶点，以便每个边差异都是正的，并且总的加权贡献尽可能小。 

该图最多有 18 个顶点。 这个小值是主要线索。 一个指数解`n`可以工作，但是尝试每一个可能的值分配之类的任何事情都行不通，因为分配数量的增长速度比`2^n`。 

第一个有用的转变是重写目标。 

对于每个顶点，收集其值的系数。 顶点通过传出边贡献正值，通过传入边贡献负值。```
sum(w * (a[x] - a[y])) = sum(c[v] * a[v])
```在哪里`c[v]`是传出边的总权重减去传入边的总权重。 

约束变成排序约束：对于每条边`x -> y`,`a[x] > a[y]`。 

一个微妙的点是，向每个添加相同的常数`a[v]`没有任何改变，因为系数之和为零。 我们可以移动整个解决方案，使最小指定值为零。 

这些值永远不需要超过`n - 1`。 如果两个连续的值层为空，则较高层上的每个顶点都可以减一，而不会破坏任何边缘约束，从而改进答案。 因此，最优解总是可以用最多来表示`n`层。 

一个简单的错误是仅使用最长路径长度来分配值。 这满足了不等式，但可能不会最小化加权和。 例如：```
3 3
1 2 100
2 3 1
1 3 1
```最长路径分配给出值`2 1 0`，但第一个边缘上的较大权重意味着减少该边缘上的间隙更为重要。 最佳分层取决于通过系数的所有边缘权重。 

## 方法

 蛮力的想法是尝试每一种可能的价值分配。 由于每个顶点最多可以有`n`可能的层数，这大约需要`n^n`作业，这对于`n = 18`。 

有用的观察是，解决方案实际上是将顶点划分为层。 较高层中的顶点具有较大的值。 如果我们知道哪些顶点至少有价值`k`，该集合必须包含其顶点的每个前趋。 换句话说，每个层边界对应于在传入边下闭合的顶点子集。 

问题变成选择有效层，同时最小化系数乘以层数的总和。 由于只有`2^18`子集，我们可以使用子集动态规划。 

方便的实现一层一层地进行。 对于一个子集`S`，将值精确分配给中的顶点后存储最小成本`S`。 要创建下一个图层，请选择可以接收下一个值的剩余顶点的有效子集。 天真地枚举所有转换给出`O(3^n)`，这太高了。 

相反，我们使用按拓扑顺序选择顶点的子集 DP 来构建层。 当考虑当前层的顶点时，只有当它指向的所有顶点都已放置在较低层中时，才可以将其放置在那里。 这删除了子集枚举并给出了`O(n^2 2^n)`解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n^n) | O(n^n) | O(n) | 太慢了|
 | 层子集 DP | O(n^2 2^n) | O(n^2 2^n) | O(n 2^n) | O(n 2^n) | 已接受 |

 ## 算法演练

 1. 计算`c[v]`对于每个顶点。 将边权重添加到源系数并从目标系数中减去它。 原来的边缘目标现在相当于最小化`sum(c[v] * a[v])`。 
2. 对图进行拓扑排序。 通过排序，我们可以通过仅检查必须已经位于其下方的顶点来决定顶点是否可以加入层。 
3. 对子集运行动态规划。 在处理一些顶点并决定其中哪些属于已经完成的较低层之后，状态存储最佳成本。 
4. 对于拓扑顺序中的每个顶点，尝试两种选择。 跳过当前层的顶点，或者如果所有传出邻居已经在下层子集中，则将其放入当前层。 
5. 将顶点放入图层时`k`， 添加`c[v] * k`到当前成本。 存储父信息，以便可以重建所选层。 
6. 从父指针中恢复所选层并输出每个顶点的指定值。 

为什么有效：每个有效的分配都定义了相等值的层。 DP正是考虑了这些可能的层构造，因为只有在所有具有较小值的顶点被固定之后，顶点才能进入层。 每个过渡都会准确地添加放置在该层的顶点的贡献。 由于每条有效分配对应一条DP路径，并且每条DP路径对应一条有效分配，因此最小DP值正是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    coef = [0] * n
    out = [0] * n

    for _ in range(m):
        x, y, w = map(int, input().split())
        x -= 1
        y -= 1
        coef[x] += w
        coef[y] -= w
        out[x] |= 1 << y

    order = []
    indeg = [0] * n
    for i in range(n):
        for j in range(n):
            if (out[i] >> j) & 1:
                indeg[j] += 1

    q = [i for i in range(n) if indeg[i] == 0]
    while q:
        v = q.pop()
        order.append(v)
        for u in range(n):
            if (out[v] >> u) & 1:
                indeg[u] -= 1
                if indeg[u] == 0:
                    q.append(u)

    N = 1 << n
    INF = 10**30

    dp = [INF] * N
    dp[0] = 0
    parent = [(-1, -1)] * N

    for layer in range(n):
        ndp = dp[:]
        npar = parent[:]

        for mask in range(N):
            if dp[mask] == INF:
                continue
            for v in order:
                if (mask >> v) & 1:
                    continue
                if out[v] & ~mask:
                    continue
                nm = mask | (1 << v)
                val = dp[mask] + coef[v] * layer
                if val < ndp[nm]:
                    ndp[nm] = val
                    npar[nm] = (mask, v)

        dp = ndp
        parent = npar

    ans = [0] * n
    mask = N - 1
    layer = n - 1

    while mask:
        pm, v = parent[mask]
        if pm == -1:
            break
        ans[v] = layer
        mask = pm
        if mask == 0:
            break

    print(*ans)

if __name__ == "__main__":
    solve()
```系数计算完全消除了边缘变量。 拓扑排序仅用于保证当为层选择顶点时，已经考虑了所有所需的较低顶点。 

DP 子集使用位掩码，因为`n`只有 18。 转换条件`out[v] & ~mask == 0`意味着每个传出的邻居`v`已经在下层里面了。 这正是要求`a[v]`必须比所有的都大。 

重建过程通过存储的父项向后进行。 每个选定的转换都会记录进入一层的一个顶点，因此将当前层编号分配给该顶点会重建最佳分配。 

## 工作示例

 对于第一个样本：```
3 2
2 1 4
1 3 2
```系数为：

 | 顶点| 系数|
 | ---| ---|
 | 1 | -2 |
 | 2 | 4 |
 | 3 | -2 |

 有效的最佳分层是：

 | 顶点| 指定值|
 | ---| ---|
 | 2 | 2 |
 | 1 | 1 |
 | 3 | 0 |

 顶点 2 的较大正系数使得将其放置在较高位置是不可避免的，而将顶点 1 和 3 放置在较低位置则成本较低。 

对于第三个样本：```
5 5
1 2 1
2 3 1
3 4 1
1 5 1
5 4 10
```最佳层是：

 | 顶点| 指定值|
 | ---| ---|
 | 1 | 4 |
 | 2 | 3 |
 | 3 | 2 |
 | 4 | 1 |
 | 5 | 2 |

 DP 更喜欢增加顶点 5 的值，因为边`5 -> 4`具有最大的权重。

 ## 边缘情况

 没有边的图没有排序限制。 每个顶点的系数为零，因此每个顶点可以接收零值。 DP 从空子集开始，可以以同一层中的所有顶点结束。 

断开连接的组件是独立处理的。 如果两组顶点之间没有边，它们的相对垂直位置不会影响可行性，并且系数变换正确捕获唯一重要的事情，即目标值。 

由非常大的权重连接的顶点不得不必要地分开。 DP 不仅仅优化层数，它还优化加权系数和，因此昂贵的边缘会影响所选的排列。 

多个顶点可以共享相同的值，只要没有边以错误的方向连接它们即可。 子集转换允许任何兼容的顶点集占据一层，这是该解决方案比简单分配最长路径深度更好的主要原因。
