 ## 解决方案
 ## 问题理解

 我们有一把带弹匣的枪，可以装弹匣`k`子弹。 有`n`独立的怪物波。 时间一波出现`l_i`，包含`a_i`怪物，并且该波中的所有怪物必须在规定时间内被杀死`r_i`。 尽管一波可能恰好在下一波开始时结束，但这些波已经排序并且永远不会重叠。 

射击是瞬时的，所以唯一消耗时间的动作就是装弹。 重新装弹需要一个时间单位，并将当前弹匣替换为完整的弹匣，并扔掉所有剩余的子弹。 目标不仅是尽量减少击中怪物的子弹，还要尽量减少装弹时损失的子弹。 我们需要在成功完成过程中离开库存的子弹总数最少。 

波数最多只有2000波，而次数和怪物数量可以高达`10^9`。 这立即排除了模拟每个时刻，因为单个间隔可以跨越数十亿个时刻。 一个`O(n^2)`解决方案是可以接受的，因为`n`足够小，可以管理大约 400 万次转换。 解决方案取决于尺寸`l_i`或者`r_i`不可行。 

有几个细节会导致错误的解决方案失败。 一个常见的错误是认为重新装弹总是好的，因为它可以提供完整的弹匣。 例如：```
1 10
5 6 6
```答案是`6`。 在射击前几个怪物后立即重新加载的贪婪方法可能会扔掉有用的子弹并花费`10`或更多子弹。 

另一个陷阱是忘记了波浪可以接触。 考虑：```
2 3
2 3 6
3 4 3
```答案是`9`。 第二波在第一波结束的同时开始，所以时间`3`可用于完成旧怪物并准备下一次重新加载。 将间隔视为严格分隔会失去有效操作。 

第三个边缘情况是最终杂志。 例如：```
1 10
100 111 1
```答案是`1`。 最后一个弹匣中剩余的子弹在战斗结束后并没有被丢弃，因此最后的重新装弹不应算作废子弹。 

## 方法

 直接的方法是决定每一个可能的重新加载时间表。 对于每一波，我们可以尝试所有可能的重新加载次数和每个可能的时间点来执行它们。 可能的次数是巨大的，因为间隔可以包含高达`10^9`，因此这种方法甚至无法有效地表示。 

有用的观察是我们不关心波之间间隙内的确切时刻。 重要的是一波完全处理后和下一波开始之前的状态。 如果我们知道我们到达一波弹匣已满，我们就可以贪婪地模拟如果处理该波和一些后续波而无需在它们之间进行不必要的重新加载，会发生什么。 

蛮力之所以有效，是因为固定的重装决策序列完全决定了所花费的子弹数量，但它会失败，因为可能的序列数量巨大。 关键的见解是`n`很小，所以我们可以尝试一个段的每一个可能的起始波。 对于每个起点，我们都会向前延伸该段并模拟最佳的生存方式，直到稍后的浪潮。 这将问题简化为波边界上的动态规划。 

让`dp[i]`是清除第一个后消耗的最少子弹`i`波浪并在下一波之前准备好完整的杂志。 来自州`i`，我们尝试清除波浪`i`通过`j`连续进行，无需在波前强制重新加载`j`开始。 在此模拟过程中，我们跟踪剩余的子弹数量以及已经用掉的子弹数量。 当弹匣不足时，我们会计算需要重新装填多少次以及可用时间是否允许。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 重新加载计划的数量呈指数级增长| O(1) | O(1) | 太慢了|
 | 最优动态规划| O(n²) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化`dp[0] = 0`。 这意味着在第一波攻击之前我们还没有用完子弹并且我们的初始弹匣已满。 
2. 对于每一个可能的起始波`i`，尝试将当前段扩展到后面的每个波`j`。 波前状态`i`已经保证弹匣已满，因此这为我们提供了有效的模拟起点。 
3. 延长弹段的同时，保持当前弹匣内剩余的子弹。 如果当前弹匣里的子弹足够一波`j`，用掉这些子弹并继续。 无需重新加载即可完成该波。 
4.如果当前弹匣不够，则计算击杀剩余怪物所需的装弹次数。 每次重新加载都会添加`k`子弹，但每次装弹也消耗一个单位时间。 重新加载计数必须适合该波的时间间隔。 
5. 清波后`j`，如果在下一波之前有足够的时间再次拥有完整的杂志，则更新下一个动态编程状态。 过渡存储到目前为止用过的子弹以及准备下一个完整弹匣时丢弃的所有子弹。 
6. 处理完所有可能的转换后，`dp[n]`包含所有波次后消耗的最少子弹。 如果达不到，波浪就无法清除。 

为什么它有效：不变的是每个可达的`dp[i]`描述了一个真实的情况，其中第一个`i`波浪已结束，杂志在下一波之前已满。 每个最佳解决方案都有最后一个点，即弹匣在挥手之前已满，因此它显示为动态规划考虑的转换之一。 过渡内的模拟始终使用该固定段所需的最小可能重新加载次数，因为额外的重新加载只会丢弃子弹并增加成本。 因此，每个候选者都是有效的，并且所有候选者中的最小值是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    waves = [tuple(map(int, input().split())) for _ in range(n)]

    INF = 10**30
    dp = [INF] * (n + 1)
    dp[0] = 0

    for i in range(n):
        if dp[i] == INF:
            continue

        spent = dp[i]
        bullets = k

        for j in range(i, n):
            l, r, a = waves[j]
            extra = 0

            if a <= bullets:
                bullets -= a
                finish = l
            else:
                need = a - bullets
                reloads = (need + k - 1) // k
                if reloads > r - l:
                    break

                extra = reloads * k
                finish = l + reloads
                bullets = (k - need % k) % k

            spent += a + extra

            if j == n - 1:
                dp[n] = min(dp[n], spent)
            elif finish <= waves[j + 1][0]:
                dp[j + 1] = min(dp[j + 1], spent + bullets)

    print(-1 if dp[n] == INF else dp[n])

if __name__ == "__main__":
    solve()
```外循环选择在开始之前可用完整杂志的波次。 内循环尝试当前连续段的所有可能的端点。 这与上述动态编程转换相匹配。 

在模拟中，`bullets`代表处理该段中所有先前波次后的当前杂志。 如果当前的一波无法完成，代码会计算上限划分所需的最小重新加载次数。 条件`reloads > r - l`检查这些重新加载是否适合在波次截止日期之前。 

表达式`(k - need % k) % k`计算最后一次重新装弹后剩余的子弹。 额外的模处理最后一个弹匣完全空的情况。 完成一个片段后，添加`bullets`到下一个状态代表在下一波之前重新装弹会损失的子弹。 

所有计算都使用 Python 整数，因此接近最大可能答案的值是安全的。

 第一波结束时，四颗子弹被丢弃，然后需要下一个装满的弹匣。 第二波也出现同样的模式，总共`30`。 

## 复杂度分析

 | 测量| 复杂性 | 说明|
 | ---| ---| ---|
 | 时间 | O(n²) | Every starting wave tries every possible ending wave, and each transition is simulated in constant time. |
 | 空间| O(n) | The algorithm stores the wave list and one dynamic programming array. |

 和`n <= 2000`，转换次数约为四百万，这很容易在限制之内。 大的时间值不会影响复杂性，因为算法永远不会在某个时刻进行迭代。

 ## 边缘情况

 对于触摸波情况：```
2 3
2 3 6
3 4 3
```该算法从三个项目符号开始。 它会在第一波中立即使用它们，检测到还需要三颗子弹，并使用一次重新装填。 重新加载完成时间`3`，这是允许的，因为下一波也开始于`3`。 第二波完全使用新弹匣，产生`9`。 

对于最终杂志案例：```
1 10
100 111 1
```第一个弹匣已经装有足够的子弹。 模拟花费了一颗子弹并留下九颗子弹未使用。 由于没有下一波，代码不会将那些剩余的子弹添加为废弃成本，从而给出正确的答案`1`。 

对于不可能的最后期限：```
5 42
42 42 42
42 43 42
43 44 42
44 45 42
45 45 1
```该算法尝试模拟第一波。 每次所需的重新加载都会消耗一个单位时间，而后面的波浪没有为所有必要的重新加载留下足够的时间。 转换失败，因为所需的重新加载次数超过了可用的间隔长度，因此最终状态仍然无法到达，答案是`-1`。
