 ## 解决方案
 ## 问题理解

 房间被建模为一棵树，每个人都是一个顶点，如果虱子可以在一天的训练中直接在两个人之间移动，那么两个人就被连接起来。 经过训练后`d`天，虱子可以在树距最大为的任意两个顶点之间跳跃`d`。 目标是选择一个起始人员和一个顺序，以访问每个人一次，同时最小化所需的跳跃距离。 

输入给出了几个独立的树。 对于每棵树，我们需要最小值`d`允许这样的访问顺序。 输出是每个测试用例的最短训练时间。 

所有测试用例的顶点总数最多为的约束`10^6`意味着解必须接近线性。 任何尝试多种可能路径、排列或重复图搜索的方法都会太慢。 我们需要提取树的结构属性，并仅通过边缘几次就可以确定答案。 

主要的边缘情况来自于将短遍历的存在与普通深度优先搜索顺序混淆。 DFS 顺序可能会强制从长分支的末尾跳转到另一个远程分支，即使不同的顺序也有效。 

以星树为例：```
3
1 2
1 3
```正确的输出是：```
2
```粗心的解决方案可能会认为每棵树都可以仅使用边来行走，因为每个顶点都是连接的。 然而，访问完一片叶子并通过中心返回后，将无法再次访问该中心。 必须跳跃距离 2 才能到达第二个叶子。 

路径树则不同：```
4
1 2
2 3
3 4
```正确的输出是：```
1
```可以按顺序访问顶点`1 -> 2 -> 3 -> 4`，仅使用现有的边。 总是打印 2 的解决方案会忽略路径的特殊性。 

另一个常见错误是仅检查直径。 一棵直径较大的树仍然可以得到答案 2，因为虱子不需要跟随直径。 他们只需要图中的一条哈密顿路径，其中每对距离最多为 2 的顶点都相连。 

## 方法

 直接方法将尝试为每个可能的跳跃距离构建访问顺序。 对于固定距离，我们可以搜索允许该长度跳跃形成的图，并检查它是否包含哈密顿路径。 这是正确的，因为问题准确地要求这样的路径，但哈密顿路径搜索通常是指数的。 即使在一棵树上，尝试推理所有可能的顺序也很快变得不可行。 

关键的观察是树有一个非常强大的属性：每棵树的平方都是哈密顿量。 树的平方是每个顶点与距离最多为 2 的所有顶点相连的图。这意味着通过两天的训练，可以访问每棵树。 

现在只剩下一天足够的情况了。 经过一天的训练，每次跳跃都必须沿着原来的树边。 仅当树本身是简单路径时，树才能具有使用其自己的边访问所有顶点的路径。 在树中，当每个顶点的度数最多为 2 时，就会发生这种情况。 

暴力破解之所以会失败，是因为它把访问顺序作为主要对象。 结构观察将整个问题简化为检查树的最大度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 指数| O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取树并计算每个顶点的度数。 唯一需要的信息是某个顶点是否分支到三个或更多方向。 
2. 求所有顶点的最大度数。 如果每个度数最多为 2，则树是一条路径，因此可以沿着边缘行走，答案为 1。 
3. 如果某个顶点的度数至少为 3，则该树不是路径。 一日跳跃无法访问每个顶点，而两天跳跃总是足够的，因为树的正方形总是有哈密顿路径。 答案是2。 

为什么它有效：

 最大度数最多为 2 的树不能分支，因此它恰好是一个顶点链。 跟随链访问每个顶点，跳跃距离为 1。 

如果最大度大于2，则树包含分支点。 仅使用树边的路径无法在不重新访问分支点的情况下进入多个分支，因此距离 1 是不可能的。 允许距离 2 将每个顶点连接到其父顶点、子顶点和同级顶点，这足以将所有顶点排列成一个有效的访问序列。 

该算法背后的不变性是唯一可能的答案是 1 和 2。度检查准确地区分获得较小值的树。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    t = data[0]
    idx = 1
    ans = []

    for _ in range(t):
        n = data[idx]
        idx += 1

        deg = [0] * n

        for _ in range(n - 1):
            u = data[idx] - 1
            v = data[idx + 1] - 1
            idx += 2
            deg[u] += 1
            deg[v] += 1

        if max(deg) <= 2:
            ans.append("1")
        else:
            ans.append("2")

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```输入解析器使用`sys.stdin.buffer.read()`因为顶点总数可以达到一百万，一次读取整个输入可以避免许多小顶点的开销`input()`来电。 

对于每个测试用例，代码仅存储度数组。 每条边都会增加两个端点的度数，因此无需构建邻接表。 

条件`max(deg) <= 2`是整个决策步骤。 树不能包含循环，因此每个顶点度数最多为 2 会强制它成为单条路径。 对于所有其他树，答案恰好是 2。 

没有距离计算或遍历，这避免了不必要的工作。 对于普通的 Python 整数来说，这些值足够小，并且最大可能的次数仅为`n - 1`。

 ## 边缘情况

 对于路径形树：```
5
1 2
2 3
3 4
4 5
```学位是`[1, 2, 2, 2, 1]`。 最大度为 2，因此算法返回 1。访问顺序可以简单地遵循链从一端到另一端。 

对于分支树：```
5
1 2
1 3
1 4
1 5
```学位是`[4, 1, 1, 1, 1]`。 该中心的等级为4级，因此不可能一日步行。 该算法返回 2，这与叶子可以通过距离 2 的跳跃从其他叶子到达的事实相匹配。 

对于大型平衡树，许多顶点的度数为3，但算法不需要模拟跳跃。 它仅检查分支顶点是否存在并立即返回 2。树方的哈密顿属性可以处理所有此类情况。
