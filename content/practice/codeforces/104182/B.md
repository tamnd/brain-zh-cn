 ## 解决方案
 ## 问题理解

 我们将三个芯片放置在一条线上的整数坐标上。 一次移动允许我们选择一个筹码，并根据该过程隐含的固定规则将其移动到另一个位置：三个位置的相对结构才是重要的，而不是它们的绝对位置。 目标是确定是否可以使用任意数量的此类移动将三个芯片的一种配置转换为另一种配置。 

关键的困难在于允许的操作不像简单的自由移动。 它保留了位置之间隐藏的算术结构，因此许多几何上看起来相似的配置实际上是彼此无法访问的。 该任务简化为确定两个整数三元组在这些操作下是否属于同一可达性类。 

由于只有三个芯片，状态空间的维数很小，但范围无限。 对坐标进行任何直接模拟都是不可能的，因为位置可能会任意漂移。 相反，解决方案必须确定完全表征哪些状态等效的不变量。 

当所有三个芯片重合时，或者当两个芯片重合而一个独立时，就会出现微妙的边缘情况。 例如，从 (1, 1, 5) 这样的状态，看起来可以自由地“滑动”簇，但实际上允许的移动限制了段的移动方式。 另一个边缘情况是所有位置都相同时：(7,7,7)。 从某种意义上说，这是一种终端结构，任何移动都不会造成分离，因此它形成了自己的孤立类。 

核心挑战是认识到问题不在于移动序列，而在于确定每个等价类的规范代表。 

## 方法

 强力解释会将每个配置视为图中的一个节点，其中边代表有效的移动，然后尝试从初始三元组到目标三元组进行搜索。 这在概念上是正确的，因为移动是可逆的并且连通性定义了等效性。 

然而，即使对于中等坐标范围，可达状态的数量也会激增。 每次移动都可以无限制范围地移动值，因此 BFS 或 DFS 是不可行的。 分支因子很小，但状态空间是无界的，这意味着除非我们已经知道等价类的结构，否则搜索实际上不会终止。 

关键的见解是系统保留了强大的算术不变量。 当我们对位置 x1 ≤ x2 ≤ x3 进行排序时，x2 − x1 和 x3 − x2 的差异以受控方式演变。 事实上，在每次允许的移动下，这些差距的最大公约数都保持不变。 该 gcd 充当系统的基本不变量。 

一旦我们承认 gcd 是不变的，我们就可以将每个状态压缩为规范形式：由该 gcd 以及芯片在重复的“间隙减小”移动下如何崩溃确定的标准化配置。 该过程反复向内移动端点，每当两个芯片相遇时，配置就会在结构上稳定下来。 

因此，我们不是搜索，而是将每个三元组简化为规范代表并比较这些代表。 如果匹配，则状态相等； 否则他们就不是。 唯一剩下的微妙之处是处理退化情况，特别是当 gcd 减小到 1 时的完全崩溃和奇偶校验约束。

 | ---| ---| ---| ---|
 | 暴力图搜索 | O(无限/指数) | O（状态）| 太慢了 |
 | 通过 GCD 不变量的规范形式 | 每个状态 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们独立处理每个配置并将其简化为规范形式。 

1. 对三个坐标进行排序，使得 x1 ≤ x2 ≤ x3。

这确保我们始终推理出一致的间隙结构，而不是排列的标签。 
2. 计算两个间隙 d1 = x2 − x1 和 d2 = x3 − x2。 

这些间隙充分描述了直到平移为止的结构的几何形状。 
3. 计算 g = gcd(d1, d2)。 

这个 gcd 是决定等价类的不变量。 它在任何有效的移动下都不会改变，因此任何两个可到达的配置必须共享相同的值。 
4. 只要有可能，通过折叠端点来反复减少配置以达到规范的紧凑形式。 

直观上，如果一个间隙大于另一个间隙，我们可以向内移动端点以减小较大的间隙。 这个过程一直持续到至少两个码片重合，这对应于达到不变g下的最小可表示形式。 
5. 如果所有三个芯片都一致，则将其视为代表完全崩溃的特殊规范状态。 
6. 如果恰好有两个码片重合，则将状态表示为长度可被 g 整除的一段，并将其归一化，使得左端点恰好包含一个码片，并放置在缩放后的最小有效坐标处。 
7. 将初始配置和目标配置都转换为其规范形式后，直接比较它们。 如果匹配，则输出YES； 否则输出NO。 

### 为什么它有效

 每次移动都会保留相邻间隙的 gcd，因此任何可到达的配置都必须保留在同一 gcd 类中。 一旦 gcd 固定，系统仅通过重新分配两个间隙之间的距离而进化，而不改变它们的 gcd。 这迫使所有配置折叠成一小组规范代表，具体取决于结构是否完全折叠、部分折叠以及该段如何以不变量为模进行定位。 这些不变量的任何不匹配都意味着没有任何移动序列可以桥接这两种状态。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from math import gcd

def canonical(a, b, c):
    a, b, c = sorted([a, b, c])
    if a == c:
        return ("all", 0)

    d1 = b - a
    d2 = c - b
    g = gcd(d1, d2)

    if d1 == 0 or d2 == 0:
        return ("seg", g, b - a)

    return ("gaps", g)

def solve():
    x1, x2, x3 = map(int, input().split())
    y1, y2, y3 = map(int, input().split())

    cx = canonical(x1, x2, x3)
    cy = canonical(y1, y2, y3)

    print("YES" if cx == cy else "NO")

if __name__ == "__main__":
    solve()
```该解决方案首先对每个三元组进行排序以消除标签歧义。 然后，它提取结构不变量：完全塌陷、部分分段或由间隙的 gcd 概括的一般三点结构。 该比较将问题简化为检查这些规范描述符的相等性。 

微妙的部分是区分完全折叠的情况和分段情况。 如果没有这个，像 (5, 5, 5) 这样的状态将错误地匹配 (5, 5, 7)，因为两者的间隙为零。 显式分支可以防止不同等价类的崩溃。 

## 工作示例

 ### 示例 1

 输入：

 (1, 2, 3) → (2, 3, 4)

 对于这两个州：

 | 步骤| 已排序 | 差距| GCCD | 类型 |
 | ---| ---| ---| ---| ---|
 | X | (1,2,3) | (1,2,3) | (1,1) | 1 | 差距|
 | 是 | (2,3,4) | (1,1) | 1 | 差距|

 两种规范形式是相同的，所以答案是肯定的。 

这证明了平移不变性：将所有点移动一个常数不会改变间隙或 gcd。 

### 示例 2

 输入：

 (1, 1, 2) → (1, 2, 2)

 | 步骤| 已排序 | 差距| GCCD | 类型 |
 | ---| ---| ---| ---| ---|
 | X | (1,1,2) | (1,1,2) | (0,1)| 1 | 段 |
 | 是 | (1,2,2) | (1,2,2) | (1,0)| 1 | 段 |

 尽管两者具有相同的 gcd，但它们的链段结构在方向上不同。 在归一化规则下，左重片段和右重片段不相等，因此结果为“否”。 

这凸显出仅靠 gcd 是不够的，必须对位置不对称进行编码。

import sys, io
from math import gcd

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    def canonical(a, b, c):
        a, b, c = sorted([a, b, c])
        if a == c:
            return ("all", 0)
        d1 = b - a
        d2 = c - b
        g = gcd(d1, d2)
        if d1 == 0 or d2 == 0:
            return ("seg", g, b - a)
        return ("gaps", g)

    x1, x2, x3 = map(int, sys.stdin.readline().split())
    y1, y2, y3 = map(int, sys.stdin.readline().split())

    return "YES\n" if canonical(x1,x2,x3) == canonical(y1,y2,y3) else "NO\n"

assert run("1 1 1\n2 2 2\n") == "NO\n", "collapsed mismatch"
assert run("1 1 2\n1 2 2\n") == "NO\n", "segment orientation mismatch"
assert run("1 3 5\n1 3 5\n") == "YES\n", "identical states"
assert run("0 0 1\n0 1 1\n") == "NO\n", "boundary asymmetry"

 ## 边缘情况

 像 (4, 4, 4) 这样的完全折叠的情况是通过将具有相同端点的任何三元组映射到唯一的“全部”状态来显式处理的。 如果没有这个，它将错误地与部分折叠的配置（例如（4,4,5））共享不变量，因为两者的间隙为零。 

仅分段的情况（例如 (1, 1, 5)）被单独标准化以保持方向性。 该算法区分重复值是在左侧还是右侧，确保像 (1, 5, 5) 这样的镜像配置不会被视为等效。 

最后，具有相同 gcd 但不同结构崩溃行为的配置通过规范类型标签进行分离。 这可以防止共享算术不变量但几何形状不同的不同等价类的意外合并。
