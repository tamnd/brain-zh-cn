 ## 解决方案
 ## 问题理解

 我们得到了一个二进制字符串的集合，并且我们可以选择反转其中的一些。 这样做之后，我们希望将所有字符串排列在一个序列中，使得每个相邻的字符串对都是兼容的：单词的最后一个字符必须与下一个单词的第一个字符匹配。 目标是使这样的完整排序成为可能，同时反转尽可能少的字符串。 如果即使在最佳逆转之后也不可能，我们必须报告失败。 

考虑这个问题的一个有用方法是将每个单词压缩到它的端点中。 每个字符串在其第一个字符和最后一个字符之间提供有向连接。 字可以是 0 到 1 边缘、1 到 0 边缘或循环（0 到 0 或 1 到 1）。 反转单词会交换其端点，因此 0 到 1 的边缘会变成 1 到 0，反之亦然，而循环保持不变。 

问题变成了这些端点计数的全局一致性任务。 我们尝试定向每个非循环边（选择是否反转它），以便所有边都可以放置在两个节点 {0,1} 上的单个欧拉路径中，同时最小化翻转的边数。 

约束很大，最多有 2⋅10^5 个单词，总长度最多为 4⋅10^6，因此任何解决方案都必须在单词的线性时间内运行，忽略超出端点提取的字符串长度。 这立即排除了任何尝试模拟排列或图形构造超出每个字符串的恒定工作的尝试。 

当端点不平衡无法协调时，就会出现主要的边缘情况。 例如，如果所有单词都以 0 开头和结尾，除了一个强制不平衡（例如单个 0→1 而没有匹配的 1→0 结构），我们可能会被迫陷入不可能的奇偶校验条件。 另一个微妙的情况是，当最佳解决方案需要精确翻转那些与全局多数方向“不对齐”的边时，但天真贪婪的每节点平衡可能会意外打破唯一性约束或无法最小化翻转。 

## 方法

 如果我们忽略反转，则每个字符串都会贡献一条从其第一个字符到最后一个字符的有向边。 对所有单词进行排序的核心要求是生成的节点 {0,1} 上的有向多重图具有仅使用一次所有边的欧拉路径。 

对于具有欧拉路径的有向图，入度和出度必须满足非常严格的条件：所有节点都必须是平衡的，除了可能的两个节点，一个出度比入度大一的节点（起始节点）和一个入度比出度大一的节点（结束节点）。 由于我们只有两个节点，因此条件简化为确保可以纠正总不平衡。 

逆转边缘会翻转其对不平衡的贡献。 每条边要么在其开始处为 (out−in) 贡献 +1，要么在其结束处贡献 -1。 对于节点 0，我们跟踪所有按其原始方向处理的单词引起的净不平衡。 每个颠倒的单词都会翻转其贡献，以可预测的量改变不平衡。 问题变成选择要翻转的边的子集，以便最终的不平衡满足欧拉条件，同时最小化翻转。 

暴力方法会尝试反转单词的所有子集，这是 2^n 种可能性。 即使检查每个排序的有效性也是 O(n)，导致 O(n2^n)，完全不可行。 

关键的观察结果是该图只有两个节点，因此不平衡是一维的。 每个单词根据其方向对不平衡贡献+1或-1（0→1为节点0的出入差异贡献+1，1→0贡献-1，循环贡献0）。 反转一个单词会翻转它的贡献，有效地将+1更改为-1，反之亦然。

因此，每个非循环字都是贡献±1的二元选择，我们希望最终的总和尽可能接近零，正如欧拉可行性所要求的那样。 该结构崩溃为具有全局约束的符号分配问题，并且最小化反转等同于最大化与所选目标方向的对齐。 我们尝试两个可能的欧拉方向（从 0 开始或从 1 开始），计算所需的不平衡性，并贪婪地决定必须翻转哪些边才能以最小的成本实现可行性。 该决策简化为根据边缘是否已与目标方向对齐来对边缘进行排序。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们将每个单词视为其第一个和最后一个字符之间的边缘。 

1.根据端点将单词分为四类：00、11、01和10。00和11单词不会影响方向性，为了可行性可以忽略； 它们不会帮助或损害不平衡，但它们仍然在最终排序中占据位置。 
2. 统计有多少个单词是类型01，有多少个单词是类型10。这些是唯一影响全局方向一致性的单词。 
3. 如果 01 和 10 计数都为零，则所有字都是循环。 任何排序都有效，所以答案是零反转。 
4. 如果两种类型中的一种为零而另一种非零，则所有非循环字仅指向一个方向。 在这种情况下，仅当所有单词已经与可以形成链的单个方向一致时，才存在有效的欧拉路径。 我们只需要确保我们选择的起点与终点一致即可； 不需要逆转。 
5. 否则两种类型都存在。 我们必须选择一个全局方向：要么我们将这条链解释为主要从 0 到 1，要么从 1 到 0。 
6. 计算两个选择的不平衡性。 对于选定的方向，将 (01,10) 之一视为“正确”，将另一个视为“不正确”。 反转错误的单词可以修复它，成本为 1。 
7. 选择需要翻转次数较少的方向，并输出必须翻转的单词索引。 

### 为什么它有效

 因为只有两个节点，所以每个有效的欧拉排列仅取决于 0 和 1 之间的转换数量是否可以与单个全局方向一致。 每一次逆转都恰好翻转了对全球平衡的一个贡献。 该问题简化为为±1值的多重集选择符号分配以满足单个全局约束，同时最小化翻转，一旦目标方向固定，翻转就会独立地分解每个边缘。 由于只有两种可能的方向，因此评估这两种方向并选择更好的方向可以保证最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        n = int(input())
        
        zero_zero = []
        one_one = []
        zero_one = []
        one_zero = []
        
        words = []
        
        for i in range(n):
            s = input().strip()
            a, b = s[0], s[-1]
            words.append((a, b))
            
            if a == '0' and b == '0':
                zero_zero.append(i + 1)
            elif a == '1' and b == '1':
                one_one.append(i + 1)
            elif a == '0' and b == '1':
                zero_one.append(i + 1)
            else:
                one_zero.append(i + 1)
        
        if not zero_one and not one_zero:
            out.append("0")
            continue
        
        # Try making direction 0->1 dominant
        flip_A = len(one_zero)
        ans_A = list(one_zero)
        
        # Try making direction 1->0 dominant
        flip_B = len(zero_one)
        ans_B = list(zero_one)
        
        if flip_A <= flip_B:
            out.append(str(flip_A))
            if flip_A > 0:
                out.append(" ".join(map(str, ans_A)))
            else:
                out.append("")
        else:
            out.append(str(flip_B))
            if flip_B > 0:
                out.append(" ".join(map(str, ans_B)))
            else:
                out.append("")
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```该实现仅检查每个字符串的第一个和最后一个字符，这已经足够了，因为内部结构永远不会影响邻接规则。 我们按端点类型对索引进行存储，然后比较两个可能的全局方向。 每个方向准确地确定了必须翻转的类别，而成本只是该类别的大小。 

当需要零翻转时，必须注意输出格式，因为根据平台解释，第二行可以省略或打印为空。 该解决方案在零成本情况下始终打印空行以保持一致性。

 ## 边缘情况

 一种边缘情况是所有字符串都是循环，例如`000`,`111`，或混合`000`和`111`。 该算法将所有这些都放入被忽略的类别中，产生零翻转并正确地得出任何排序都有效的结论，因为没有邻接约束依赖于转换。 

另一种情况是 01 和 10 边缘达到完美平衡。 用于输入`01, 01, 10, 10`，两个方向都需要恰好两次翻转。 该算法始终选择一方，但任一答案都是有效的。 关键点是，一旦全局方向固定，每条边都会独立地对成本做出贡献，因此关系不会影响正确性。 

例如，当只有一个非循环边时，就会出现一种微妙的情况`01`有很多循环。 该算法正确识别任一方向都有效，但只有一个方向不需要翻转，因此它输出零变化并保留可行性。
