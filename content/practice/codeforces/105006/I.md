 ## 解决方案
 ## 问题理解

 我们得到了一组柯基犬，每只柯基犬都被分配了一个 22 位整数性格值。 如果我们选择这些柯基犬的任何一个子集，该子集中的每一对柯基犬都会贡献一个“幸福”，其值等于它们个性的按位与。 子集的总幸福度是这些成对 AND 值的总和。 任务是对柯基犬的每个可能子集的数量进行求和。 

解释这一点的直接方法是，每对索引都会贡献多次：对于包含该对的两个元素的每个子集一次。 与其首先考虑子集，不如考虑固定对在所有子集中出现的频率更有用。 

约束条件很大，元素多达 200000 个，值高达 2²²。 如果每对都需要繁重的工作，这会立即排除任何直接迭代子集甚至所有对的解决方案。 大约有 2×10^10 个子集，并且所有子集中也有 2×10^10 对，因此任何子集枚举都是不可能的。 对于 n = 2×10^5 来说，即使 O(n²) 也太大了。 

一种简单的方法会计算每个子集的内部对和，从而导致指数时间。 即使对所有对求和然后乘以固定因子也会忽略子集结构并失败，因为除非我们仔细考虑组合学，否则每个对在子集中都不会被平等地计数。 

一个微妙的陷阱是假设子集呈线性而不跟踪多重性。 例如，对于值 [1, 2]，只有当两者都被选择时，对 (1,2) 才会起作用，这种情况恰好发生在一个子集中，而不是在包含任一元素的所有子集中。 

## 方法

 关键思想是颠倒求和的顺序。 我们不是先对子集求和，而是先对对求和，然后为每对确定有多少个子集包含它。 

修复两个索引 i < j。 (i, j) 恰好出现在包含这两个元素的子集中，而其余 n − 2 个元素是任意的。 因此，每对贡献其 AND 值乘以 2^(n−2)。 这将整个问题简化为计算：

 对所有对 (p_i & p_j) 求和，然后乘以 2^(n−2)。 

现在的问题是计算所有对的按位与之和。 这是一个经典的位分解技巧。 每个位都可以独立处理。 对于每个位 b，我们计算有多少个数字设置了该位。 如果 cnt[b] 元素设置了位 b，则有 cnt[b] 选择 2 对贡献该位，并且每个这样的对为 AND 和贡献 2^b。 

因此总的两两 AND 之和为：

 对 b 求和： (cnt[b] * (cnt[b] − 1) / 2) * 2^b

 最后乘以 2^(n−2)。 

这将问题简化为计数位。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 对子集的暴力破解 | O(n·2^n) | O(n·2^n) | O(1) | O(1) | 太慢了|
 | 配对计数与位分解 | O(n·22) | O(22) | 已接受 |

 ## 算法演练

 1. 计算从 0 到 21 的每一位在所有值中出现的次数。 这隔离了每一位的贡献，因为 AND 独立地对每一位进行操作。 
2. 对于每个位 b，计算 cnt[b] * (cnt[b] − 1) // 2. 这给出了两个数字都设置了位 b 的无序对的数量。 这样做的原因是，只有当两个端点都具有该位时，才会对 AND 产生影响。 
3. 将每对计数乘以 2^b 以计算最终总和中该位的值。 
4. 将所有位上的这些贡献相加，以获得所有无序对上 p_i 和 p_j 的总和。 
5. 将结果乘以 2^(n−2)，因为每个固定对正好出现在 2^(n−2) 个子集中。 包含两个端点的每个子集都可以自由选择任何剩余元素。 
6. 返回对 998244353 取模的结果。 

### 为什么它有效

正确性取决于两个独立的分解。 首先，每对对所有子集的贡献是统一的，并且仅取决于有多少子集包含两个端点，即 2^(n−2)。 其次，按位与是对位进行加法，这意味着可以单独计算每个位的贡献，而不会受到其他位的干扰。 由于两种变换都保留了精确的总贡献，因此最终的公式与原始定义相匹配。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n = int(input())
a = list(map(int, input().split()))

B = 22
cnt = [0] * B

for x in a:
    for b in range(B):
        if x & (1 << b):
            cnt[b] += 1

pair_and_sum = 0
for b in range(B):
    c = cnt[b]
    pair_and_sum += (c * (c - 1) // 2) % MOD * ((1 << b) % MOD)
    pair_and_sum %= MOD

if n >= 2:
    pair_and_sum *= modpow(2, n - 2)
    pair_and_sum %= MOD
else:
    pair_and_sum = 0

print(pair_and_sum)
```该实现首先将所有信息压缩为位数，避免任何对枚举。 模幂有效地计算子集重数因子 2^(n−2)。 乘法被推迟到成对求和之后，以避免重复模运算。 

一个微妙的细节是处理 n < 2，其中不存在对并且结果必须为零。 另一个方法是将所有中间值保持在模 998244353 之下，同时仍然使用整数算术进行组合，因为 cnt[b] 选择 2 在归约之前可以安全地适合 Python 整数。
