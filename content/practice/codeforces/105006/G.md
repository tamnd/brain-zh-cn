 ## 解决方案
 ## 问题理解

 我们正在一个矩形公园内工作，可以将其视为从左下角开始的连续二维平面$(0,0)$到右上角$(N,M)$。 柯基犬开始于$(0,0)$并想要达到$(N,M)$。 柯基犬可以自由地向任何方向连续移动，但存在以家庭成员为中心的圆形“危险区域”。 如果柯基犬进入其中一个圆圈，它就会立即被抓住。 

我们不需要使用所有家庭成员。 相反，我们可以选择其中的一个子集来激活。 只有激活的圈子才重要。 目标是选择尽可能少的圆圈，这样柯基犬就不会从$(0,0)$到$(N,M)$避免所有选定的圆圈。 

所以真正的问题不在于在网格上一步步移动。 它与几何有关：我们选择最小数量的圆盘，以便它们的并集阻挡矩形两个对角之间的每条可能的连续路径。 

这些约束说明了为什么需要进行几何简化。 坐标达到$10^9$，所以我们不能将平面离散成网格。 圈数$K$至多是$10^3$，这强烈表明$O(K^2)$或者$O(K^2 \log K)$旨在基于图形的解决方案。 任何涉及平面路径枚举或几何采样的事情都是不可能的。 

当本地思考时，会出现一个微妙的失败案例。 像“首先选择最大半径的圆圈”这样的贪婪想法是行不通的，因为棋盘中间的大圆圈可能是无关紧要的，而边界附近的一串小重叠圆圈可能会完全阻止逃跑。 

另一个陷阱是假设单个圆可以独立分隔起点和终点。 圆形仅在连接或有助于从矩形的一侧跨越到另一侧的连接障碍时才有帮助。 隔离还不够； 连接性很重要。 

## 方法

 关键的转变是停止思考柯基犬的运动，而是思考阻止所有可能的路径意味着什么。 在平面拓扑中，一组障碍物只有在创建将起始角与结束角分隔开的连续障碍时才能防止逃生。 

每个圆圈都是一个障碍物区域。 如果我们激活一组圆圈，柯基犬将被禁止进入他们的联盟。 当这些禁区形成一个连接的结构，以一种分离的方式触及边界时，逃脱就变得不可能了$(0,0)$从$(N,M)$。 

这将问题转化为图形构造。 每个圆圈成为一个节点。 如果两个节点的圆重叠或接触，则它们被连接，因为重叠的圆就像连续的障碍物组件。 我们还需要对边界进行建模。 接触左边界或下边界的圆圈可能会阻止从起始侧进入。 同样，接触顶部或右边界的圆圈可能会阻碍进入出口侧。 

我们引入两个虚拟节点。 一个代表“起始侧”（底部和左侧边界区域），另一个代表“结束侧”（顶部和右侧边界区域）。 每个与起始边界相交的圆都连接到起始节点，每个与结束边界相交的圆都连接到结束节点。 

现在问题变成：找到图中连接起始节点和结束节点所需的最少圆数。 由于选择每个圆的成本为 1，因此这是未加权图上的最短路径问题。 

蛮力方法将尝试圆的每个子集，检查它们是否阻塞连续平面中的所有路径，并最小化尺寸。 这是指数级的$K$， 大致$O(2^K)$，甚至变得不可能$K=40$。 

图形洞察力将问题简化为最短路径$K+2$节点，与$O(K^2)$边缘。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 尝试所有子集 |$O(2^K \cdot K)$|$O(K)$| 太慢了|
 | 图+最短路径|$O(K^2)$|$O(K^2)$| 已接受 |

 ## 算法演练

 1. 将每个家庭成员视为图中的一个节点。 如果两个节点的圆重叠或接触，则它们是连接的，这意味着中心之间的距离最多为它们半径的总和。 这体现了柯基犬不能在重叠的危险区域之间滑动的想法。 
2. 添加两个特殊节点：一个表示底部边界和左侧边界并集的起始节点，一个表示顶部边界和右侧边界并集的结束节点。 
3. 如果圆形节点的圆盘与底部边缘相交，则将其连接到起始节点$y=0$或左边缘$x=0$。 该模型表明这样的圆圈可以阻止来自源端的访问。 
4. 如果圆形节点的圆盘与顶部边缘相交，则将其连接到末端节点$y=M$或右边缘$x=N$。 该模型表明这样的圆可能有助于阻挡出口区域。 
5. 从起始节点到终止节点运行最短路径算法，其中每条边的权重为 1。最短距离对应于形成连续阻塞结构所需的最小圆数。 
6. 如果端节点不可达，则输出$-1$。 否则输出最短距离。 

关键思想是任何有效的阻塞配置都必须包含桥接边界分离的连接的圆链。 如果图中不存在这样的链，则任何子集都不能形成连续的几何障碍。 

### 为什么它有效

 任何有效的解决方案都对应于接触两个边界区域的所选圆的连通分量。 连接性至关重要，因为断开的障碍物留下了可以利用的连续路径的间隙。 相反，图中从开始到结束的任何路径都描述了一系列重叠的圆圈，形成了连续的障碍，并且准确选择这些圆圈可以保证分离。 因为每个环都有相同的成本，所以最佳障碍是最短的链。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    N, M, K = map(int, input().split())
    
    x = []
    y = []
    r = []
    
    for _ in range(K):
        xi, yi, ri = map(int, input().split())
        x.append(xi)
        y.append(yi)
        r.append(ri)

    S = K
    T = K + 1

    adj = [[] for _ in range(K + 2)]

    def touch_boundary(i):
        xi, yi, ri = x[i], y[i], r[i]
        if xi - ri <= 0 or yi - ri <= 0:
            adj[S].append(i)
            adj[i].append(S)
        if xi + ri >= N or yi + ri >= M:
            adj[T].append(i)
            adj[i].append(T)

    for i in range(K):
        touch_boundary(i)

    for i in range(K):
        for j in range(i + 1, K):
            dx = x[i] - x[j]
            dy = y[i] - y[j]
            rr = r[i] + r[j]
            if dx * dx + dy * dy <= rr * rr:
                adj[i].append(j)
                adj[j].append(i)

    dist = [-1] * (K + 2)
    dist[S] = 0
    q = deque([S])

    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)

    print(dist[T])

if __name__ == "__main__":
    solve()
```该代码首先使用邻接列表显式构建图。 通过检查圆是否与矩形的任何边相交来计算边界连接。 使用标准平方距离测试添加圆到圆边缘以避免浮点运算。 

使用 BFS 代替 Dijkstra 是因为每条边都代表再选择一个圆，因此所有边都具有相同的权重。 距离数组直接统计链中使用了多少个圆。 

一个微妙的一点是，我们并不试图推理柯基犬的实际运动。 整个几何复杂性都被吸收到该图中的连通性中，这就是为什么即使对于大坐标，该解决方案仍然有效。 

## 工作示例

 ### 示例 1

 我们跟踪组件如何将边界连接到边界。 

| 步骤| 行动| 关键国家|
 | --- | --- | --- |
 | 1 | 构建重叠边缘 | 一些圆圈形成小簇 |
 | 2 | 添加边界链接 | 某些圆圈连接到开始/结束边 |
 | 3 | 从起始节点开始的 BFS | 探索互联组件 |
 | 4 | 到达结束节点 | 距离 = 3 |

 这表明三个圆圈形成一条连接链，将起始侧边界桥接至出口侧边界。 如果没有这三者，链条就会断裂，逃跑就有可能。

 | 步骤| 行动| 关键国家|

 这演示了一种退化情况，其中单个大圆圈独立地阻止逃逸。

 ## 边缘情况

 当圆圈看起来只是形成障碍但并未连接时，就会出现一种棘手的情况。 例如，两个大圆可能都接触矩形的相对侧但不重叠。 在这种情况下，柯基犬可以从它们之间的缝隙中溜过去，正确答案不是 2。图模型处理这个问题是因为这两个节点之间没有路径，因此 BFS 无法形成连接的首尾链。 

另一种边缘情况是同时接触开始和结束边界区域的圆。 当一个大圆跨越整个矩形时就会发生这种情况。 该图通过单个节点立即连接起点和终点，无需任何其他推理即可生成答案 1。 

最后一种微妙的情况是，只接触一个边界的圆，但形成一条链，通向另一个接触边界的圆。 该算法正确地计算了整个链，因为 BFS 会累积沿路径选择的圆的数量，确保只有完全连接的障碍结构才能得出答案。
