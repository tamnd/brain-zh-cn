 ## 解决方案
 ## 问题理解

 给定一个严格递增的数组`a`长度`n`元素来自`1`到`k`，以及询问子数组的多个查询。 对于每个查询，由索引定义`l`和`r`，我们需要计算有多少个数组`b`存在与子数组“k-相似”的`a[l..r]`。 如果两个数组严格递增且长度相同，则它们是 k 相似的，它们的元素位于`[1, k]`，并且它们恰好在一个位置上不同。 

输入大小很重要：`n`和`q`最多可达 100,000，同时`k`可以大到 10^9。 这排除了任何显式枚举候选数组的方法。 尝试对子数组进行所有可能的修改的朴素算法的执行次数可达`(r-l+1) * k`每个查询的操作数，这对于最大范围显然是不可行的。 因此，我们每个查询都需要 O(1) 或 O(子数组长度) 方法，利用严格递增序列的结构。 

非明显的边缘情况包括位于数组边界的子数组。 例如，如果我们尝试减少第一个元素或增加最后一个元素超过 1 或`k`，我们必须限制可能的值。 另一个微妙之处出现在长度为 1 的非常短的子数组中； 即使没有“中间元素”需要考虑，选项的数量也必须考虑到双方的限制。 

## 方法

 暴力方法将迭代查询子数组中的每个位置，并尝试其中的每个整数`1`到`k`，计算有多少个保持严格增加并且在该位置处不同。 对于长度为的子数组`m`，这将需要 O(m * k) 次操作。 即使与`m`达到100,000，这是不可能的`k`最多 10^9。 

关键的见解是，对于严格递增的数组，更改给定元素的有效范围受到其邻居的限制。 认为`b`不同于`a`在位置`i`。 然后`b[i]`可以采用任何严格大于前一个元素的值`a[i-1]`（或 0，如果`i`是第一个）并且严格小于下一个元素`a[i+1]`（或者`k+1`如果`i`是最后一个）。 这立即将每个位置的候选者数量减少为简单的算术计算：之间的整数计数`a[i-1]+1`和`a[i+1]-1`，减1以排除原始值。 

对于第一个和最后一个元素，我们简单调整一下边界：第一个元素不能低于1，最后一个元素不能超过`k`。 对于中间的元素，有效范围以它们的直接邻居为界。 对查询子数组中所有位置的这些计数求和即可得出该子数组的 k 相似数组总数。 由于这只需要每个元素进行简单的算术运算，因此每个查询的复杂度为 O(m)，考虑到这一点，这已经足够高效了`n`和`q`是 10^5，所有查询的总工作量仍然可行。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 每个查询 O(m * k) | O(1) | O(1) | 太慢了|
 | 最佳 | 每次查询 O(m) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取输入值`n`,`q`， 和`k`和数组`a`。 确保`a`为 1 索引，以便更容易进行边界计算。 
2. 对于每个查询，提取子数组索引`l`和`r`。 确定长度`m = r-l+1`。 
3. 初始化计数器`count`为零。 这将存储有效数组的总数。 
4. 对于每个位置`i`在子数组中，计算可能的替换范围：

 - 如果`i`为第一个元素，下界为1； 否则，就是`a[i-1] + 1`。 
- 如果`i`是最后一个元素，上限是`k`; 否则，就是`a[i+1] - 1`。 
- 该位置的有效替换数为`(upper_bound - lower_bound + 1) - 1`。 减一以排除当前值。 
5.将此号码添加到`count`。 
6.处理完所有位置后，输出`count`。 

工作原理：通过构造，子数组中的每个元素只能取邻居设置的严格范围内的值，从而保证生成的数组保持严格递增。 减一排除原始元素以满足“仅在一个位置不同”条件。 对所有位置求和就可以一次性解释所有可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, q, k = map(int, input().split())
a = list(map(int, input().split()))

# pad array for easier indexing
a = [0] + a + [k+1]

for _ in range(q):
    l, r = map(int, input().split())
    count = 0
    for i in range(l, r+1):
        lower = a[i-1] + 1
        upper = a[i+1] - 1
        count += max(0, upper - lower)
    print(count)
```这段代码首先在数组的开头填充 0，在末尾填充 k+1，以便边界计算是统一的。 对于每个查询，它会迭代相关子数组并计算每个元素的有效替换数。`max(0, upper - lower)`确保正确处理负范围（无有效替换）。
