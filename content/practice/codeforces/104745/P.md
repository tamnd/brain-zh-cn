 ## 解决方案
 ## 问题理解

 我们得到一个表示滑雪道的有向无环图，加上少量表示滑雪缆车的附加有向边。 每条边缘，无论是滑雪道还是升降机，都只需一分钟即可完成。 滑雪者从给定的节点开始，必须连续沿着边缘移动而无需等待，从而构建一条恰好为 x 分钟的行进路径。 一旦总时间达到x，他就可以在任何节点停止。 

我们关心的特殊数量是沿着这样的路径使用了多少个滑雪缆车。 在从给定起始节点开始的所有可能的有效行走中，我们希望最小化提升边的数量，同时确保行走恰好持续 x 步。 

关键结构是滑雪道图是 DAG，但滑雪缆车可以在组合图中引入循环。 然而，电梯有一个很大的限制：如果有从 a 到 b 的电梯，那么只能使用滑雪道从 b 到达 a。 这创建了一个反向可达性结构，可以防止任意的提升周期，并且对于排序状态将变得至关重要。 

约束表明 n 和 m 在测试中总和为 10^5，并且每个测试套件的 k 总数最多为 100。 这立即表明解决方案必须接近滑雪道图中的线性或线性算数，同时允许对小升力集进行一些较重的处理。 长度为 x 的时间扩展图上的朴素最短路径是不可能的，因为 x 最大可达 10^9，排除任何 O(x) 或 O(nx) 构造。 

当 x 较大但图形较小时，会出现微妙的边缘情况。 显式跟踪步骤的朴素 BFS 会尝试扩展到 x 层。 例如，如果 x 是 10^9 并且该图具有单个路径，则这种方法将尝试模拟所有转换，这显然是不可行的。 

另一个陷阱是忽略升力限制。 如果没有它，电梯可能会产生任意循环，并使问题相当于权重为 1 和特殊成本维度的一般最短路径。 可达性条件确保提升端点之间的偏序，从而防止病态的无限改进链。 

## 方法

 暴力方法会尝试计算每个节点和每个可能的时间 t 到 x，在 t 步内到达该节点所需的最小提升次数。 这是在时间扩展图上的经典动态规划，其中状态为（节点，时间）。 每次转换都遵循滑雪道边缘或升力边缘，时间加 1，并可能增加升力计数。 

这是正确的，因为它明确地探索了所有有效的行走。 然而，它的状态空间大小为O(n x)，在最坏的情况下变成10^14，这使得它完全不可行。 

关键的观察是，我们实际上不需要区分具有不同历史的同时到达同一节点的路径，除了它们的提升次数之外，甚至该结构也可以被压缩。 由于每次移动都花费一个单位时间，因此该问题变成了分层图最短路径问题，其中时间是层索引。 唯一的区别是提升边缘在目标中会带来 1 的额外成本。 

因为电梯很少并且满足可达性约束，所以我们可以将它们视为 DAG 结构定义的组件之间的“特殊跳跃”。 仅在滑雪道图中，随着时间的推移，到达所有节点都是纯粹的 DAG 可达性扩展，这可以使用 BFS 层或类似 DAG 结构中的最短路径来概括。 然后，电梯充当捷径，可以减少剩余时间，同时增加电梯次数。

这提出了一个两级最短路径：首先计算滑雪道 DAG 中的最小到达时间结构，然后使用升降机连接状态，同时间接跟踪剩余时间。 可达性条件确保应用升降机始终移动到可以通过滑雪道向前“重新扩展”的节点，这意味着升降机永远不会使我们陷入在不消耗结构的情况下提高时间的循环中。 

我们有效地将问题简化为状态图中的最短路径，其节点是图顶点，但具有剩余时间的附加隐式维度，我们通过分层松弛和 DAG 结构的重用来贪婪地处理它。

 | --- | --- | --- | --- |
 | 暴力破解时间扩展 DP | O(n·x) | O(n·x) | O(n·x) | O(n·x) | 太慢了 |

 ## 算法演练

 我们将问题重新解释为：在从 y 开始、长度恰好为 x 的所有路径中找到最小化电梯使用率的路径。 由于每条边花费 1 个时间单位，因此我们将“时间可行性”的概念与“提升成本最小化”分开。 

我们按如下方式进行。 

## 算法演练

 1. 首先计算滑雪道 DAG 的拓扑顺序。 这提供了一个结构，在该结构中我们可以在没有循环的情况下向前传播可达性。 这很重要的原因是，任何仅由滑雪道组成的路径都是非循环的，因此时间距离的表现就像 DAG 中的最短路径。 
2. 仅使用滑雪道边缘计算从起始节点 y 到每个其他节点的最短时间（以边缘数量计）。 由于所有边的成本均为 1，因此这是 DAG 上的简单 BFS。 这给出了无需电梯即可到达每个节点所需的最短时间。 
3. 观察到任何长度为 x 的有效行走都必须在某个节点 u 处结束，但只要我们尊重精确的长度，我们就可以自由地插入绕路。 因此，我们不是尽早修复端点，而是考虑“t 个步骤后可到达的配置”。 
4. 引入第二种结构：每个滑雪缆车（a→b）都是可用的，尽管它违背了滑雪道可达性方向的限制，但我们知道b可以通过滑雪道到达a。 这意味着在使用了lift之后，我们总是可以从b开始在DAG结构中向前“重新扩展”。 
5. 在电梯端点上构建一个压缩图，其中每个状态表示在经过一定数量的仅滑雪道扩展后处于某个节点。 在这种状态下，我们可以沿着滑雪道边缘继续前进或使用升降机。 电梯将电梯计数增加 1，但允许重新定位到 DAG 结构上游的节点，之后恢复滑雪道扩展。 
6. 在这个压缩状态空间上运行一条最短路径，其成本是提升次数。 在此提升图中，通过滑雪道边缘的转换成本为 0，因为它们只消耗时间，不消耗电梯，而电梯边缘的成本为 1。 
7. k ≤ 100 的约束确保有意义的“提升相互作用状态”的数量很少。 我们只需要考虑电梯端点和起点周围的状态，因为所有其他节点都是通过 DAG 传播隐式处理的。 
8. 在计算到达任何节点的最小电梯使用量后，我们仅过滤那些可以成为恰好 x 步步行的一部分的节点。 这是通过以下事实进行检查的：我们可以从任何节点将 DAG 中的向前路径延伸到其最大深度，因此可行性简化为检查 x 是否至少是最小到达时间并与剩余松弛一致。 

### 为什么它有效

该算法之所以有效，是因为滑雪道图定义了一个偏序，其中时间仅沿边缘增加，并且电梯仅以尊重反向可达性的方式连接节点。 这可以防止不一致的循环，在这种循环中，提升可能会无限期地增加和减少有效进度。 每个状态转换要么保留 DAG 可达性结构，要么沿着可以“吸收”回 DAG 扩展的提升移动。 因此，提升计数上的最短路径是明确定义的，并且不依赖于探索指数级的时间显式路径。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import deque
import heapq

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        
        g = [[] for _ in range(n + 1)]
        indeg = [0] * (n + 1)

        for _ in range(m):
            u, v = map(int, input().split())
            g[u].append(v)
            indeg[v] += 1

        lifts = []
        for _ in range(k):
            a, b = map(int, input().split())
            lifts.append((a, b))

        x, y = map(int, input().split())

        dist = [10**18] * (n + 1)
        dist[y] = 0
        q = deque([y])

        while q:
            u = q.popleft()
            for v in g[u]:
                if dist[v] > dist[u] + 1:
                    dist[v] = dist[u] + 1
                    q.append(v)

        # DP over lift graph (small k)
        nodes = set([y])
        for a, b in lifts:
            nodes.add(a)
            nodes.add(b)

        nodes = list(nodes)
        idx = {v:i for i, v in enumerate(nodes)}
        L = len(nodes)

        INF = 10**18
        dp = [INF] * L
        dp[idx[y]] = 0

        pq = [(0, idx[y])]

        while pq:
            c, i = heapq.heappop(pq)
            if c != dp[i]:
                continue
            u = nodes[i]

            for a, b in lifts:
                if u == a:
                    j = idx[b]
                    if dp[j] > c + 1:
                        dp[j] = c + 1
                        heapq.heappush(pq, (dp[j], j))

        ans = min(dp[i] for i, v in enumerate(nodes) if dist[v] <= x)

        print(ans if ans < INF else -1)

if __name__ == "__main__":
    solve()
