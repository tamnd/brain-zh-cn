 ## 解决方案
 ## 问题理解

 我们收到一系列银行支票，每张都有固定的货币价值。 从这个序列中，我们最多可以选择`k`一天的支票，我们的目标是最大化所选支票的总价值。 除了我们可以接受的支票数量的限制之外，我们对选择哪些支票没有任何限制。 

输入描述了两件事：可用检查的数量`n`，以及最大数量`k`是可以赎回的。 然后是一个数组`n`代表每张支票的值的整数。 输出是一个数字，我们可以通过选择不超过的数字来获得最大可能的总和`k`数组中的元素。 

约束条件`n ≤ 10^4`意味着即使是二次解（例如检查所有子集或模拟组合）也会太慢。 一个`O(n^2)`该方法已经面临大约 10^8 次操作的风险，这在 Python 中对于严格的 1 秒限制来说是边界。 任何指数级的事情都是立即不可能的。 

问题的结构没有隐藏任何排序要求。 我们不需要选择连续的检查或保留堆栈顺序。 大小的任何子集可达`k`是有效的，这将问题简化为纯粹的选择任务。 

主要的边缘情况来自对短语“最多 k 检查”的理解。 例如，如果`k = n`，我们必须获取所有元素。 如果`k = 1`，我们只需选择最大单个值。 

考虑以下场景：

 输入：```
5 1
3 10 2 8 7
```输出：```
10
```幼稚的方法可能会尝试组合，但正确的答案只是最大元素。 

输入：```
4 4
1 2 3 4
```输出：```
10
```在这里，我们必须采取一切，因为限制允许所有元素。 

任何不正确的方法通常都源于对选择是受位置还是顺序限制的误解。 在这个问题中，它是纯粹的组合问题。 

## 方法

 暴力解释将尝试最多的每个子集`k`元素，计算其总和，并跟踪最佳结果。 这是正确的，因为它直接匹配任务的定义，但子集的数量是巨大的。 甚至严格限制为`k`元素给出$\binom{n}{k}$，增长速度太快，无法一一列举`n`甚至达到几十个。 

关键的观察是元素的顺序是无关的。 任何选定子集的总和仅取决于包含哪些值，而不取决于它们的位置。 这减少了选择最大的任务`k`数组中的值。 任何最佳解决方案都必须包含最大的元素，因为用较大的未使用元素替换较小的选定元素总是会改善或保持总数。 

这将问题转化为经典的选择问题：要么对数组进行排序，然后取顶部`k`值，或维护一个跟踪的运行结构`k`最大的元素。 

排序是最简单、最直接的方法。 按降序排序后，答案就是第一个的总和`k`元素。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了|
 | 排序前 k | O(n log n) | O(n log n) | O(1) 或 O(n) | 已接受 |

 ## 算法演练

 我们通过关注只有最大值才有助于最优选择这一事实来解决这个问题。 

1. 阅读`n`和`k`，然后读取检查值列表。 这定义了我们可以选择的完整候选人库。 
2. 按降序对列表进行排序，以便最大值首先出现。 此步骤可确保最好的候选人位于最前面，从而使选择变得微不足道。 
3. 拿第一个`k`已排序列表中的元素。 这些对应于可用的最高可能值。 
4. 计算这些的总和`k`元素并将其作为答案输出。 

每一步都降低了问题的复杂性：我们不再对子集进行推理，而是将其简化为排序和切片，这在排序后是确定性的。 

### 为什么它有效

 正确性来自于一个简单的交换论证。 假设最优选择包含一些元素`a`同时排除较大的元素`b`不在选择范围内。 更换`a`和`b`在不违反最多选择约束的情况下增加总和`k`元素。 重复这个替换过程可以确保任何最优解都可以转化为完全由`k`最大值。 因此，选择顶部`k`排序后总是最优的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    arr = list(map(int, input().split()))
    arr.sort(reverse=True)
    print(sum(arr[:k]))

if __name__ == "__main__":
    solve()
```该解决方案使用快速 I/O 读取输入，因为 Python 的默认输入对于大型数组可能很慢。 排序步骤首先放置较大的值。 切片`arr[:k]`准确提取允许的检查数量，并将它们相加得出最佳总数。 

一个微妙的细节是确保我们不会意外地包含超过`k`元素。 由于切片不包含边界并且即使在`k = n`，这完全避免了边缘情况处理。

 ## 边缘情况

 一个关键的边缘情况是当`k`等于`n`。 该算法对数组进行排序并获取所有元素。 由于切片不会超出范围截断，因此总和自然包括每个值。 

对于输入：```
4 4
3 1 4 2
```排序后：`[4, 3, 2, 1]`我们采用全部 4 个元素：

 总和 = 10

 这符合要求，因为最多选择`k`允许使用整套。 

另一个边缘情况是当`k = 1`。 该算法简化为选择最大元素。 排序保证它位于零位置。 

对于输入：```
5 1
2 9 1 8 3
```排序：`[9, 8, 3, 2, 1]`我们只取第一个元素，生成 9，根据定义这是最佳的，因为任何其他选择都会更小。
