 ## 解决方案
 ## 问题理解

 安希望通过在几天内开采和销售狗狗币来实现利润最大化。 她每天开采一枚硬币，而硬币的价格每天都会根据给定的列表而变化。 对于多个计划中的每一个，由开始日期定义`l`和结束日`r`，她必须每天在间歇期挖矿`[l, r]`并每天出售所有硬币`r`。 每个计划的输出是她在指定时间间隔内出售开采的代币可以获得的最大总利润。 

输入提供`n`，天数，后面是每天的一系列代币价格。 然后还有`q`计划，每个计划指定一个采矿间隔`[l, r]`。 约束表明两者`n`和`q`最多可达 200,000，这意味着任何在每个查询的时间间隔上进行迭代的简单解决方案都需要最多`O(n * q)`运营。 最坏的情况大约是`4*10^10`对于 2 秒的时间限制来说，这太慢了，因此我们需要一种预先计算数据的方法来有效地回答每个查询。 

天真的方法可能会忽略这样一个事实：安可以选择出售每种开采的代币的最佳日期，如果她只是按照开采当天的价格出售代币，就会导致利润不佳。 当价格波动时，就会出现边缘情况，例如：如果价格是`[1, 100, 1]`她开采了三天，天真的每日销售方法总共给出了`1 + 100 + 1 = 102`，而以最高价格出售当天的所有币`100`产量`1 + 1 + 1`硬币时代`100 = 300`。 另一种边缘情况是间隔仅包含一天； 在这种情况下，最大利润就是当天的币价。 

## 方法

 暴力解决方案独立考虑每个计划，并模拟在该时间间隔内每天出售硬币。 它将跟踪迄今为止开采的代币数量，并始终以当天的价格出售它们。 这是正确的，但它会在每个查询间隔中迭代每一天，从而导致`O(n*q)`复杂性，这对于最大约束是不可接受的。 为了`n = 200,000`和`q = 200,000`，这将需要大约 400 亿次操作。 

关键的观察是，由于 Ann 可以在任何一天出售任意数量的代币，因此她总是希望在挖矿间隔内价格最高的那一天出售代币。 一段时间内的总利润`[l, r]`只是顶部的总和`k`她每天可以出售的价格，其中`k`硬币白天可用`r`。 由于她每天只开采一枚硬币，因此将会有`r - l + 1`卖出的币种，最优策略是卖出当天最高价的所有币种`[l, r]`。 这将问题简化为计算间隔内最大前缀和的总和。 

有效实现此目的的一个简单方法是使用价格的前缀和数组和线段树或稀疏表来计算任意区间内的最大值`O(1)`（对于稀疏表）或`O(log n)`（对于线段树）每次查询的时间。 稀疏表在这里特别有效，因为数组是静态的； 不会发生更新，只会发生查询。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n*q) | O(n*q) | O(1) | O(1) | 太慢了|
 | 范围最大值的稀疏表/线段树 | O(n log n + q) | O(n log n + q) | O(n log n) | O(n log n) | 已接受 |

 ## 算法演练

 1.读取天数`n`和价格数组`c`。 这将设置我们将在其上执行间隔查询的数组。 
2. 构建稀疏表`c`可以返回任意区间内的最高价格`[l, r]`在`O(1)`时间。 使用标准稀疏表结构预先计算日志和表行。 
3.读取查询数量`q`以及采矿计划清单。 对于每个查询`[l, r]`，将索引转换为从零开始以便于数组访问。 
4. 对于每个计划，计算价格总和：`l`到`r`。 然后使用稀疏表查找该区间内的最高价格。 最大利润是通过开采的硬币数量相乘获得的`(r - l + 1)`按该区间内的最高价格。 
5.输出每次​​查询的最大利润。 

为什么有效：通过始终在时间间隔内价格最高的那一天出售代币，安可以实现收入最大化。 稀疏表保证我们可以在每次查询后的恒定时间内找到这个最大值`O(n log n)`预处理。 由于所有硬币都是相同的，并且她必须在最后一天之前出售所有硬币，因此该策略是最佳的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_sparse_table(arr):
    import math
    n = len(arr)
    K = n.bit_length()
    st = [[0] * n for _ in range(K)]
    st[0] = arr[:]
    for k in range(1, K):
        for i in range(n - (1 << k) + 1):
            st[k][i] = max(st[k-1][i], st[k-1][i + (1 << (k-1))])
    return st

def query_max(st, l, r):
    import math
    k = (r - l + 1).bit_length() - 1
    return max(st[k][l], st[k][r - (1 << k) + 1])

def main():
    n = int(input())
    c = list(map(int, input().split()))
    st = build_sparse_table(c)
    q = int(input())
    res = []
    for _ in range(q):
        l, r = map(int, input().split())
        l -= 1
        r -= 1
        num_coins = r - l + 1
        max_price = query_max(st, l, r)
        res.append(num_coins * max_price)
    print(" ".join(map(str, res)))

if __name__ == "__main__":
    main()
```稀疏表构造构建`K`层，其中每层存储长度间隔内的最大值`2^k`。 查询时，取两个拟合的最大幂`[l, r]`确定要考虑哪两个重叠间隔。 将基于 1 的索引转换为基于 0 的索引可确保正确性。 将硬币数量乘以最高价格直接得出最大利润。
