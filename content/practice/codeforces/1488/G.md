 ## 问题理解

 我们给出了一组`n`不同的整数，每个从 1 到`n`。 任务是为每个数字分配一种颜色，红色或蓝色，以便准确地`k`数字是红色的。 着色的成本是通过计算所有对来定义的`(x, y)`在哪里`x`是蓝色的，`y`是红色的，并且`y`可以整除`x`。 目标是计算每个的最大成本`k`从 1 到`n`。 

输入是单个整数`n`，它决定了集合的大小和其中值的范围。 输出是一个序列`n`整数，其中`k`-th 整数表示恰好时的最大成本`k`数字是红色的。 

约束条件意味着`n`最多可以达到 100,000，并且采用一种简单的方法来检查每个可能的大小子集`k`需要组合时间，这是天文数字般的缓慢。 任何算法都必须大致在线性或近线性时间内运行。 主要挑战是成本取决于可除性关系，这种关系形成了一个密集的网络：每个数字都可以除以多个其他数字，从而创建大量潜在的对。 

微妙的边缘情况发生在边界处`k`。 如果`k = n`，所有数字都是红色的，因此没有蓝色数字可以形成有效对，并且成本必须为零。 同样，如果`k = 0`，所有数字都是蓝色的，再次产生零成本。 任何不明确处理这些极端情况的解决方案都有可能产生错误的值。 

## 方法

 蛮力方法将迭代大小的所有子集`k`，将它们标记为红色，并根据剩余的蓝色数字计算所有可整除的对。 每个子集需要`O(n^2)`检查是因为每个红色数字都可能与每个蓝色数字相互作用。 和`n`达到100,000时，这种方法是完全行不通的。 

最佳解决方案的关键见解是使用可分结构将其视为贪婪问题。 较大的数字往往可以被更多较小的数字整除，因此将较大的数字涂成红色，将较小的数字涂成蓝色往往会最大化计数。 形式上，对于每个数字`x`, 红色的倍数`x`确定其贡献如果`x`是蓝色的。 准确地最大化成本`k`红色数字，我们要选择`k`最大的数字为红色，因为每个小数字可以贡献最大数量的可整除对。 

通过有效地预先计算每个数字的除数并使用前缀和来跟踪计数，我们可以计算所有数字的最大成本`k`在`O(n log n)`时间。 这种方法避免了单独检查所有子集，并利用了从 1 到 1 的整数的有序结构。`n`。

 ## 算法演练

 1.初始化一个数组`red_count`尺寸的`n+1`为零。 该数组将跟踪可被每个整数整除的红色数字的数量。 
2. 对于`k`从 1 到`n`，选择`k`最大的数为红色。 由于数字是从 1 到`n`，这就是简单的集合`{n, n-1, ..., n-k+1}`。 
3. 对于每个红色数字`y`，迭代它的除数`x`小于`y`。 对于每个除数，递增`red_count[x]`除以 1。这跟踪有多少个红色数字可以被每个潜在的蓝色数字整除。 
4. 对于给定的`k`，将总成本计算为`red_count[x]`对于所有数字`x`未选择为红色的。 这会计算所有有效的`(blue, red)`对。 
5. 对所有对象重复该过程`k`从 1 到`n`，将结果存储在输出数组中。 

为什么有效：在每一步中，通过选择最大的数字作为红色，我们可以最大化每个小数字（潜在的蓝色）可以交互的红色倍数的数量。 预计算除数保证我们对每个有效对恰好计数一次。 不变的是`red_count[x]`总是等于红色数字的数量可以被`x`对于当前的`k`，因此对蓝色数字求和会产生最大成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    result = [0] * n

    # Track counts of red multiples for each number
    red_count = [0] * (n + 1)

    # Generate cost for each k
    for k in range(1, n + 1):
        # The new red number is n - k + 1
        y = n - k + 1
        # Update divisors
        for x in range(1, int(y**0.5) + 1):
            if y % x == 0:
                red_count[x] += 1
                if x != y // x:
                    red_count[y // x] += 1
        # Calculate cost: sum over blue numbers (numbers < n-k+1)
        cost = sum(red_count[1:n-k+1])
        result[k-1] = cost

    print(" ".join(map(str, result)))

if __name__ == "__main__":
    main()
```该代码使用快速 I/O，并避免所有红蓝对上的嵌套循环。 使用平方根循环计算除数以保持高效。 仅对蓝色数字求和可保证我们仅计算有效对。
