 ## 解决方案
 ## 问题理解

 我们有两个长度相等的二进制字符串。 每个字符要么是`'0'`或者`'1'`。 对于每个位置，我们都会比较两个字符串中的字符。 

如果两个字符不同，则结果字符串为`'1'`在那个位置。 如果它们相同，则结果字符串为`'0'`。 

这个运算正是逐位应用的二进制异或运算。 

例如，如果一个字符串有`'1'`另一个有`'0'`，输出变为`'1'`。 如果两者都是`'1'`或者两者都是`'0'`，输出变为`'0'`。 

字符串的长度最多为 100，这是非常小的。 即使是对字符串进行简单的线性扫描也足够快。 任何时间复杂度与字符串长度成正比的算法都将在限制内立即完成。 

这个问题的主要危险不是性能而是正确性。 小的实现错误可能会默默地产生错误的二进制字符串。 

一个容易犯的错误是忘记保留前导零。 考虑：```
Input:
001
001
```正确的输出是：```
000
```如果有人将字符串转换为整数并返回，他们可能会意外地打印`0`，这是错误的，因为该问题需要保留所有位置。 

另一个常见错误是将运算误解为二进制加法而不是异或。 例如：```
Input:
1
1
```正确输出：```
0
```不正确地使用加法模 2 或处理进位位的粗心实现可能会产生错误的结果。 

第三种微妙的情况是交替模式，其中每次比较都会发生变化：```
Input:
1010
0101
```正确输出：```
1111
```这会检查实现是否独立比较每个位置，而不是尝试将字符串解释为完整的二进制数。 

## 方法

 最直接的方法是逐个字符地处理字符串。 对于每个索引，比较两个字符。 如果不同，请追加`'1'`到答案。 否则追加`'0'`。 

这已经有效地解决了问题，因为最大长度只有 100。即使我们对字符串进行多次传递，运行时间仍然很小。 

更简单的版本会使用字符串连接重复构建答案：```
ans += '1'
```循环内。 在 Python 中，对于非常大的输入，重复的字符串连接可能会变得低效，因为字符串是不可变的。 每次连接都会创建一个新字符串。 对于长度 100，这仍然工作得很好，但在更大的问题中，这种模式可能会变成二次型。 

更简洁的方法是收集列表中的字符并在最后将它们加入一次。 关键的观察是每个输出数字仅取决于相应的输入数字对。 任何位置都不影响任何其他位置。 这意味着我们永远不需要进位、预处理或高级数据结构。 

整个任务简化为简单的线性比较。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力字符串连接| 理论上 O(n²) | O(n) | 已接受 |
 | 最佳的逐个角色构建 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 读取两个二进制字符串。 

保证两个字符串具有相同的长度，因此我们可以安全地逐个索引地处理它们。 
2. 创建一个空列表来存储答案字符。 

使用列表可以避免在构造过程中重复的字符串重新分配。 
3. 迭代每个位置`0`到`n - 1`。 

每个位置都是独立于其他位置的。 
4. 比较当前索引处的字符。 

如果字符不同，请追加`'1'`到答案列表。 否则追加`'0'`。 

这直接匹配问题中的 XOR 定义。 
5. 将所有收集到的字符连接成一个字符串。 

最终字符串保留每个位置，包括前导零。 
6. 打印结果。 

### 为什么它有效

 对于每个索引`i`，问题完全从这对中定义答案数字`(a[i], b[i])`。 

该算法在每个位置完全独立地应用此规则：

 - 产生的数字相等`'0'`- 不同的数字产生`'1'`由于每个位置都被正确且独立地处理，因此完整的结果字符串是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a = input().strip()
b = input().strip()

ans = []

for x, y in zip(a, b):
    if x != y:
        ans.append('1')
    else:
        ans.append('0')

print(''.join(ans))
```前两行读取二进制字符串并删除尾随换行符`strip()`。 

答案存储在列表中，因为附加到列表是高效的。 处理完所有位置后，`''.join(ans)`在一次操作中创建最终字符串。 

循环使用`zip(a, b)`同时迭代两个字符串中的匹配位置。 由于该问题保证长度相等，因此每个字符对都正确对齐。 

比较`x != y`与语句中的 XOR 条件完全匹配。 不需要整数转换，这可以避免涉及前导零或二进制算术的错误。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    a = input().strip()
    b = input().strip()

    ans = []

    for x, y in zip(a, b):
        if x != y:
            ans.append('1')
        else:
            ans.append('0')

    print(''.join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output

# provided sample
assert run("1010100\n0100101\n") == "1110001\n", "sample 1"

# minimum size

# all equal values

# alternating pattern
assert run("1010\n0101\n") == "1111\n", "every position differs"

# leading zeros preserved
assert run("0011\n0011\n") == "0000\n", "leading zeros must remain"

# maximum-style repeated pattern

b = "10" * 50
expected = "11" * 50 + "\n"
assert run(f"{a}\n{b}\n") == expected, "length 100 case"

 ## 边缘情况

 考虑两个字符串相同且以零开头的情况：```
Input:
001
001
```该算法比较每对数字：

 -`0`与`0`→`0`-`0`与`0`→`0`-`1`与`1`→`0`产生的答案是：```
000
```由于该解决方案直接使用字符串而不是整数，因此前导零保持不变。 

现在考虑最小可能的不同输入：```
Input:
1
0
```该算法处理唯一的位置：

 -`1`与`0`→`1`输出：```
1
```这证实了 XOR 规则已正确实施。 

最后，考虑每个位置都不同的情况：```
Input:
1010
0101
```逐步比较：

 -`1`与`0`→`1`-`0`与`1`→`1`-`1`与`0`→`1`-`0`与`1`→`1`输出：```
1111
```这验证了该算法独立地处理位置，而不是执行带进位的二进制算术。
