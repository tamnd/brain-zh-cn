 ## 解决方案
 ## 问题理解

 我们得到了几个独立的测试用例。 在每个测试用例中，我们都从一个正整数数组开始。 我们可以重复选择两个不同的位置，并将乘法因子从一个值移动到另一个值，但该因子必须是第一个选择值的除数。 具体来说，我们通过将一个数字除以某个除数并将该除数通过乘法推入另一个元素来将其分成两部分。 

目标是确定我们是否可以在数组中重新分配质因数，以便所有元素最终变得相同。 

解释该运算的一个有用方法是它永远不会改变所有数字的总乘积。 当我们将一个元素除以 x 并将另一个元素乘以 x 时，全局乘积保持不变。 因此，我们唯一的自由就是重新安排素因数在元素之间的分配方式。 

每个元素都可以分解为素数，并且该操作允许在任意分组块中的元素之间移动素数因子（因为允许任何除数，而不仅仅是单独的素数）。 

约束足够小，对于每个测试用例，我们都可以进行大致线性或线性算术分解。 所有 n 的总和最多为 10^4，并且值最高可达 10^6，因此通过筛子或预先计算的 SPF 进行素因数分解是合适的。 对于每个测试用例来说，n 中的任何二次方都已经是安全的，但是任何直接依赖于值的东西都太慢了。 

当考虑平均值或类似 gcd 的不变量时，会出现一个微妙的问题。 一个天真的想法是，均衡可能仅取决于总和或 gcd，但两者都不会以直接表征最终状态的方式保留。 不变量是乘法而不是加法。 

当所有数字都相等时会出现边缘情况，应立即返回 YES。 另一个问题是当数字互质时，会阻止在所有元素上均匀地重新分配质数指数。 例如，如果我们有 [2, 3, 5]，我们可以移动素数，但无法创建每个元素结尾相同的匹配分布，因为素数的总指数计数必须能被 n 整除。 

## 方法

 暴力破解的想法是模拟操作。 我们尝试所有索引对、所选元素的所有除数，并递归地或使用 BFS 应用转换。 每个状态都是一个数组配置。 这立即爆炸：每个数字可能有许多除数，并且配置的数量呈指数增长，因为素数因子可以通过多种方式重新分配。 即使 n = 10，这也是不可行的。 

关键的观察结果是该操作不会更改整个数组中的素数指数多重集。 每个质因数在所有元素中贡献一个固定的总指数，我们只是在 n 个容器中重新分配这些指数。 最终状态要求每个数字都相同，这意味着每个元素必须包含每个素数的完全相同的指数。 

因此，对于每个素数 p，如果其在数组中的总指数为 S，则在最终配置中每个元素必须包含 p 的 S / n 个副本。 这意味着对于每个素数，S 必须可以被 n 整除。 这个条件既是必要的也是充分的，因为我们总是可以使用允许的操作在元素之间移动素数幂。 

因此，问题简化为对所有数字进行因式分解、对每个质数的指数求和以及检查是否能被 n 整除。

 ## 算法演练

1. 预先计算 10^6 以内的所有整数的最小质因数。 这允许快速分解每个数字。 原因是我们需要在所有测试用例中有效地将值重复分解为素数。 
2. 对于每个测试用例，初始化一个字典或数组，用于跟踪整个数组中的总素数指数。 这代表了主要因素的全球库存。 
3. 对于每个元素 a[i]，使用 SPF 表将其分解，并将其素数指数添加到全局计数中。 此步骤是有效的，因为因式分解唯一地表示乘法结构。 
4. 处理完所有元素后，迭代所有记录的素数并检查每个总指数是否能被n整除。 这是必需的，因为在最终状态下，每个元素必须具有完全相同的每个素数份额。 
5. 如果所有素数都满足整除性，则输出YES。 否则输出NO。 

### 为什么它有效

 该操作保留数组中每个素数的总指数。 由于我们可以在元素之间移动任何除数，因此我们可以在任意块中移动素数幂，这实际上意味着我们可以跨位置独立地重新分配每个素数。 使所有元素相等的唯一障碍是每个素数的总指数是否可以均匀地分布在 n 个元素上。 如果这一点成立，则存在建设性的再分配； 如果不是，则至少有一个元素需要小数指数，这是不可能的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXA = 10**6

spf = list(range(MAXA + 1))
for i in range(2, int(MAXA ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, MAXA + 1, step):
            if spf[j] == j:
                spf[j] = i

def factorize(x, acc):
    while x > 1:
        p = spf[x]
        cnt = 0
        while x % p == 0:
            x //= p
            cnt += 1
        acc[p] = acc.get(p, 0) + cnt

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    total = {}
    for v in a:
        factorize(v, total)
    
    ok = True
    for p, cnt in total.items():
        if cnt % n != 0:
            ok = False
            break
    
    print("YES" if ok else "NO")
```SPF 筛构建了一个最小的质因数数组，以便可以在相对于其值的对数时间内对最大 10^6 的每个数字进行因式分解。 每次分解都会将素数计数累积到共享字典中。 

正确性检查仅验证指数和能否被 n 整除。 这已经足够了，因为最终配置中的每个元素必须准确接收每个素数的 cnt / n 副本。 

一个常见的错误是只检查 gcd 或乘积整除性，但约束是针对每个素数的，并且在素数之间是独立的。 

## 工作示例

 ### 示例 1

 输入：```
n = 3
a = [8, 2, 4]
```因式分解：

 8 = 2^3

 2 = 2^1

 4 = 2^2

 2 的总指数是 6。 

| 步骤| 行动| 2 的总指数 | n | 检查 |
 | --- | --- | --- | --- | --- |
 | 1 | 流程 8 | 3 | 3 | - |
 | 2 | 流程2 | 4 | 3 | - |
 | 3 | 流程 4 | 6 | 3 | 6 % 3 == 0 |

 由于 6 可被 3 整除，因此每个元素的指数为 2，生成 [4, 4, 4]。 这证实了当指数总数均匀分布时，重新分配有效。 

### 示例 2

 输入：```
n = 3
a = [2, 3, 5]
```每个质数出现一次，因此总数为：

 2：1、3：1、5：1

 | 总理| 总指数 | n | 可分割|
 | --- | --- | --- | --- |
 | 2 | 1 | 3 | 没有 |
 | 3 | 1 | 3 | 没有 |
 | 5 | 1 | 3 | 没有 |

 由于没有一个可以被 3 整除，因此不存在均等分布。 每个最终元素都需要小数素数指数，这是不可能的。

 ## 边缘情况

 对于像[100]这样的单元素数组，算法对100进行因式分解，发现每个素数指数都能被1整除。检查总是通过并返回YES，与不需要任何操作的事实相符。 

对于已经均匀的数组，例如 [7,7,7,7]，所有素数指数总和都是 n 的倍数。 每个素数计数是单个元素中指数的 4 倍，因此整除性成立，并且算法在没有任何重新分配推理的情况下确认“是”。 

对于总指数不可整除的数组，例如 [2,3,5]，每个素数的总指数为 1，而 n 为 3。在检查过程中，每个素数都无法整除，并且算法正确返回 NO，而无需尝试任何转换。
