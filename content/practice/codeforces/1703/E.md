 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$其单元格仅包含`0`或者`1`。 我们可以翻转任何单元格，改变`0`到`1`或者`1`到`0`，每次翻转花费一次操作。 

目标是使网格在旋转后看起来相同$90^\circ$,$180^\circ$， 或者$270^\circ$。 换句话说，每次旋转都必须产生与原始网格完全相同的网格。 

输入由多个测试用例组成。 对于每个测试用例，我们收到方形网格的大小，然后收到网格本身。 我们必须输出实现旋转对称所需的最小单元翻转次数。 

约束足够小，多次检查每个单元是完全可行的。 最大的网格有$100 \times 100 = 10{,}000$cells，最多有100个测试用例。 一个$O(n^2)$每个测试用例的解决方案很容易符合限制，而任何涉及翻转组合的指数搜索都是不可能的。 

棘手的部分是了解哪些细胞通过旋转对称性连接在一起。 即使旋转网格会强制多个位置始终包含相同的值，粗心的实现也可能会独立处理单元格。 

考虑这个网格：```
2
10
00
```涉及轮换的四个位置是：```
(0,0) -> (0,1) -> (1,1) -> (1,0)
```他们的价值观是：```
1 0 0 0
```为了使所有四个都相等，翻转一次就足够了。 翻转孤独`1`给出四个零。 单独对待职位就会错过这种关系。 

另一个微妙的情况是奇数尺寸网格的中心单元：```
3
000
010
000
```每次旋转时中心单元都会映射到自身。 不需要任何操作。 试图强制每个组的尺寸为四的解决方案可能会意外地计算出额外的翻转次数。 

第三个常见错误是重复计算轮换组。 例如：```
3
010
110
010
```角单元形成一个旋转组，边缘中间单元形成另一个旋转组。 如果我们迭代所有单元格并重复处理每个组，答案就会变得大四倍。 

## 方法

 强力的观点是考虑通过旋转连接的每组单元。 对于每一组，我们可以尝试所有可能的最终作业并选择最便宜的一个。 

旋转由$90^\circ$发送位置$(i,j)$到：$$(j,\ n-1-i)$$重复应用此操作最多会产生四个不同的位置：$$(i,j) \rightarrow (j,n-1-i) \rightarrow (n-1-i,n-1-j) \rightarrow (n-1-j,i)$$为了使最终网格在旋转后保持不变，该轨道中的所有单元格必须包含相同的值。 

蛮力的想法之所以有效，是因为每个轨道都是独立的。 一旦我们知道了属于一个轨道的细胞，我们只需要决定它们是否都变成`0`或全部变成`1`。 如果一个轨道包含$k$，那么：```
cost to make all 0 = k
cost to make all 1 = size - k
```我们取较小的值。 

唯一剩下的挑战是避免重复处理同一轨道。 如果我们从每个单元开始，每个大小为 4 的轨道都会出现四次。 相反，我们只对每个轨道处理一次。 

关键的观察结果是每个轨道都与左上象限相交一次。 如果我们只迭代：```
0 <= i < n/2
0 <= j < (n+1)/2
```那么每个轮换组都被访问一次。 我们收集它的四个细胞，数一下有多少个`1`，并添加所需的最少翻转次数。 

这将问题转化为一个简单的问题$O(n^2)$扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 重复轨道处理的暴力破解 |$O(n^2)$但容易出现重复计算|$O(1)$| 错误|
 | 基于最佳轨道的处理 |$O(n^2)$|$O(1)$| 已接受 |

 ## 算法演练

 1. 读取网格。 
2. 迭代左上角代表区域中的单元格：$$0 \le i < \frac{n}{2}$$

$$0 \le j < \frac{n+1}{2}$$每个旋转轨道在该区域中恰好出现一次。 
3. 对于每个选定的位置$(i,j)$，计算其四个旋转等效单元：$$(i,j)$$

$$(j,n-1-i)$$

$$(n-1-i,n-1-j)$$

$$(n-1-j,i)$$4. 计算这四个单元格中有多少个`1`。 
5. 如果计数为`ones`，那么零的数量是`4 - ones`。 
6. 要使所有四个单元格相等，请将所有 1 翻转为零或将所有 0 翻转为 1。 添加：$$\min(\text{ones},\ 4-\text{ones})$$到答案。 
7.处理完所有代表单元格后，输出累积答案。 

### 为什么它有效

 旋转对称性要求每个单元格与通过重复应用一个单元格而获得的所有单元格的值相匹配$90^\circ$旋转。 这些位置形成一个轨道。 不同的轨道永远不会相互作用，因此可以独立计算每个轨道的最优解，然后求和。 

在一个轨道内，最终值必须全为零或全一。 最便宜的选择是需要较少翻转的那个，即$\min(\text{ones}, \text{zeros})$。 由于每个轨道都只处理一次，因此每个所需的修改都只计算一次，从而产生最少的操作总数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        g = [input().strip() for _ in range(n)]

        ans = 0

        for i in range(n // 2):
            for j in range((n + 1) // 2):
                cells = [
                    g[i][j],
                    g[j][n - 1 - i],
                    g[n - 1 - i][n - 1 - j],
                    g[n - 1 - j][i]
                ]

                ones = sum(c == '1' for c in cells)
                ans += min(ones, 4 - ones)

        print(ans)

solve()
```外循环恰好枚举每个旋转轨道的一个代表。 边界是实现中最微妙的部分。 使用`n // 2`行和`(n + 1) // 2`列恰好覆盖所有组一次，并且自然地跳过中心单元格`n`很奇怪。 

对于每个代表位置，代码计算通过连续获得的四个位置$90^\circ$轮换。 这些坐标直接从旋转公式导出。 

1 的数量决定了该轨道的最佳成本。 如果一个轨道包含三个 1 和 1 个 0，则更改单个 0 需要执行一次操作，而更改三个 1 则需要执行 3 次操作。 取最小值给出最佳局部贡献。 

由于轨道是独立的，因此将这些成本相加即可得出全局最优值。

 输入：```

```四个角单元形成一个轨道：```
