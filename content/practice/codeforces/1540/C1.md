 ## 解决方案
 ## 问题理解

 该操作作用于相邻对。 让$$d_i=a_{i+1}-a_i.$$如果$d_i\ge b_i$，该操作没有任何改变。 如果$d_i<b_i$，两个值都被替换为具有相同和且差值完全相同的数字$b_i$。 

查看该过程的一个有用方法是减去累积的$b$-价值观。 

定义$$p_1=0,\qquad p_i=\sum_{j=1}^{i-1} b_j,$$和$$y_i=a_i-p_i.$$然后$$a_{i+1}-a_i\ge b_i$$变成$$y_{i+1}\ge y_i.$$当一对违规的$y_i>y_{i+1}$选择后，两个值都将替换为其平均值。 这正是在应该变为非递减的序列上等渗回归中使用的局部操作。 极限值$F(a,b)$是等张投影的第一个坐标。 等渗回归的标准属性是第一个投影值等于原始序列的最小前缀平均值。 将其应用到$y$给出$$F(a,b)=\min_{k\ge1} \frac{\sum_{i=1}^{k}(a_i-p_i)}{k}.$$限制很小。 我们有$n\le100$和每一个$c_i\le100$，所以所有数组元素的总可能和最多为$10000$。 这立即暗示了一种基于前缀和的动态规划解决方案。 

一个常见的错误是模拟收敛过程。 极限包含小数值，过程是无限的，甚至确定何时停止也不清楚。 真正的解决方案永远不会模拟操作。 

另一个微妙的情况出现时$x$非常大。 如果某个前缀平均值所需的下限超过最大可能的前缀和，则答案自动为零。 DP 会自然地处理这个问题，因为所有状态都会变得无效。 

考虑```
n = 2
c = [0, 0]
b = [100]
x = 1
```唯一可能的数组是$[0,0]$， 和$F(a,b)\le0$，所以答案是$0$。 任何忽略前缀平均特征的解决方案都很容易错过这一点。 

在另一个极端，```
n = 2
c = [0, 0]
b = [100]
x = -100000
```每个好的数组都满足条件，所以答案是$1$。 大型否定查询不得破坏 DP 状态空间。 

## 方法

 最直接的想法就是枚举每一个好的数组$a$，运行收敛过程，计算$F(a,b)$，并统计有效的。 

数组的数量是$$\prod_{i=1}^{n}(c_i+1).$$和$n=100$和$c_i=100$，这是一个天文数字。 即使在考虑收敛模拟之前，枚举也是不可能的。 

关键的观察是收敛过程具有封闭形式的描述。 改造后$$y_i=a_i-p_i,$$该过程成为序列上的等渗回归，该序列必须变为非递减。 限制的第一个值等于最小前缀平均值：$$F(a,b)=\min_k \frac{\sum_{i=1}^{k}(a_i-p_i)}{k}.$$现在的情况$F(a,b)\ge x$变成$$\frac{\sum_{i=1}^{k}(a_i-p_i)}{k}\ge x$$对于每个前缀$k$。 

乘以$k$,$$\sum_{i=1}^{k} a_i \ge \sum_{i=1}^{k}(p_i+x).$$问题不再是收敛问题。 它变成：

 对数组进行计数$0\le a_i\le c_i$其前缀和满足下界的集合。 

由于所有可能的总和$a_i$至多是$10000$，基于前缀和的 DP 是完全可行的。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力枚举和模拟| 指数| 指数| 太慢了|
 | 前缀和 DP |$O(n \cdot S)$|$O(S)$| 已接受 |

 这里$S=\sum c_i\le10000$。 

## 算法演练

 1. 计算累积数组$$p_1=0,\qquad p_i=\sum_{j=1}^{i-1} b_j.$$2.对于每个前缀长度$k$，计算所需的下界$$R_k=\sum_{i=1}^{k}(p_i+x).$$条件$F(a,b)\ge x$相当于要求每个前缀和$a$至少是$R_k$。 
3.让$S=\sum c_i$。 使用 DP 的地方$dp[s]$是选择已处理元素的方式数，使得它们当前的前缀和等于$s$。 
4. 最初，$dp[0]=1$。 
5. 从左到右处理位置。 
6.假设我们正在处理位置$i$。 我们可以添加任何价值$0$到$c_i$。 

过渡是$$ndp[s] = \sum_{t=s-c_i}^{s} dp[t].$$这是有界背包过渡。 
7. 使用 DP 数组的前缀和来计算所有这些范围和$O(1)$每个。 
8. 完成位置后$i$，删除前缀和小于的每个状态$R_i$。 

这些状态已经违反了所需的前缀不等式之一，并且以后永远不会有效。 
9. 处理完所有位置后，对所有剩余的 DP 状态求和。 
10. 输出结果取模$10^9+7$。 

### 为什么它有效

 等渗回归表征告诉我们$$F(a,b)\ge x$$当且仅当每个前缀平均值$a_i-p_i$至少是$x$。 

重写这些不等式给出$$\sum_{i=1}^{k} a_i \ge R_k$$对于每个前缀$k$。 

DP 精确枚举所有满足值边界的数组$0\le a_i\le c_i$。 在每个位置之后，它会删除当前前缀和违反相应下限的每个状态。 在步骤中删除的状态$k$以后永远无法修复，因为该情况涉及已经固定的前缀。 

每个有效数组仅贡献一条通过 DP 的路径，并且每个幸存的 DP 路径都对应于一个有效数组。 因此最终的计数是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

n = int(input())
c = list(map(int, input().split()))
b = list(map(int, input().split()))
q = int(input())
x = int(input().split()[0])

p = [0] * n
for i in range(1, n):
    p[i] = p[i - 1] + b[i - 1]

need = [0] * n
cur = 0
for i in range(n):
    cur += p[i] + x
    need[i] = cur

tot = sum(c)

dp = [0] * (tot + 1)
dp[0] = 1

for i in range(n):
    pref = [0] * (tot + 2)
    for s in range(tot + 1):
        pref[s + 1] = (pref[s] + dp[s]) % MOD

    ndp = [0] * (tot + 1)

    lim = c[i]
    for s in range(tot + 1):
        l = max(0, s - lim)
        ndp[s] = (pref[s + 1] - pref[l]) % MOD

    bound = need[i]
    if bound > 0:
        upto = min(tot, bound - 1)
        for s in range(upto + 1):
            ndp[s] = 0

    dp = ndp

print(sum(dp) % MOD)
```第一个块计算变换后的偏移量$p_i$。 这些是累计总和$b$-数组并表示从等渗回归视图中每个位置减去的量。 

数组`need`存储下限$R_k$对于每个前缀。 在 DP 期间，以下任何前缀和`need[i]`无效。 

转换是标准的有界背包循环。 对于每个目标总和`s`，我们可以来自区间内任何先前的总和$$[s-c_i,\, s].$$使用前缀和数组`dp`，每个转换都成为单个范围和查询。 

修剪步骤至关重要。 加工后位置`i`，前缀和小于的所有状态`need[i]`立即被删除。 延迟此检查将对已经违反所需不等式之一的数组进行计数。

        cur += p[i] + x
        need[i] = cur

    tot = sum(c)

    dp = [0] * (tot + 1)
    dp[0] = 1

        pref = [0] * (tot + 2)
        for s in range(tot + 1):

 考虑```
2
0 0
0
1
0
```唯一可能的数组是$[0,0]$。 我们得到$R=[0,0]$。 DP 从 sum 开始$0$，从不违反约束，并返回$1$。 

现在考虑```
2
1 1
0
1
2
```这里$R=[2,4]$。 处理完第一个位置后，最大可能的前缀和仅为$1$。 每个状态立即删除，留下答案$0$。 

最后，```

0
1

```我们得到$R=[-100,-200]$。 每个前缀条件都会自动满足。 DP 算所有的$(1+1)^2=4$数组和返回值$4$。
