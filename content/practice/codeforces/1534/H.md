 ## 解决方案
 ## 设置和假设

 考虑一个固定体积的封闭容器$V$含有理想气体，其整体温度为$T_1$。 容器壁保持在一定温度$T$， 和$T$不需要相等$T_1$。 该问题要求当气体和壁不处于热平衡时气体施加在壁上的瞬时压力。 

要点是到达壁的分子来自气体并且具有对应于的速度分布$T_1$，而分子在适应壁温后离开壁的速度分布对应于$T$。 由于压力是动量传递到壁的速率，因此两个温度都需要计算。 

假设墙体完全热调节。 撞击壁的分子以温度为特征$T_1$，从壁重新发射的分子以温度为特征$T$。 气体足够稀薄，可以在壁上局部使用分子通量的动力学理论表达式。 

由于容器是封闭的，机械平衡的建立速度比热平衡快得多，因此压力$P$是整个气体中的单一量。 邻近壁的分子密度不是外部规定的常数； 它会进行调整，使容器中的各处都有相同的压力。 下面的计算确定了之间的关系$P$,$T$，以及壁密度$n$。 

## 物理原理

 墙壁上的压力等于每单位面积和每单位时间传递到该墙壁的法向动量。 

让$n$是邻近壁的分子数密度。 对于温度为麦克斯韦气体$T_1$，每单位时间撞击单位面积壁的分子通量为$$\Phi_{\rm in}=n\sqrt{\frac{k_B T_1}{2\pi m}},$$在哪里$m$是分子质量。 

入射分子携带的平均法向动量为$$\langle p_x\rangle_{\rm in} = \frac{\displaystyle\int_0^\infty m v_x^2 e^{-m v_x^2/(2k_B T_1)}\,dv_x} {\displaystyle\int_0^\infty v_x e^{-m v_x^2/(2k_B T_1)}\,dv_x} = \sqrt{\frac{\pi m k_B T_1}{2}}.$$将入射通量乘以每个入射分子的平均动量得出$$J_{\rm in} = n\sqrt{\frac{k_B T_1}{2\pi m}} \sqrt{\frac{\pi m k_B T_1}{2}} = \frac12 n k_B T_1.$$离开壁的分子有温度$T$。 设它们发射时的数密度为$n_w$。 对发射的麦克斯韦重复相同的计算给出$$J_{\rm out} = \frac12 n_w k_B T.$$壁上的压力是传入和传出动量通量大小的总和：$$P=J_{\rm in}+J_{\rm out}.$$静止的墙壁无法积聚分子。 每单位面积和单位时间内到达壁的分子数必须等于离开壁的分子数。 因此$$n\sqrt{\frac{k_B T_1}{2\pi m}} = n_w\sqrt{\frac{k_B T}{2\pi m}},$$这产生$$n_w=n\sqrt{\frac{T_1}{T}}.$$## 推导

 替代$$n_w=n\sqrt{\frac{T_1}{T}}$$代入输出动量通量的表达式可得出$$J_{\rm out} = \frac12 n\sqrt{\frac{T_1}{T}}\,k_B T = \frac12 n k_B\sqrt{T_1T}.$$输入通量保持不变$$J_{\rm in} = \frac12 n k_B T_1.$$因此$$P = \frac12 n k_B T_1 + \frac12 n k_B\sqrt{T_1T} = \frac12 n k_B\left(T_1+\sqrt{T_1T}\right).$$现阶段$n$是邻近墙的密度。 由于封闭容器中的压力是唯一的机械压力，因此可以求解壁密度的关系式：$$n = \frac{2P} {k_B\left(T_1+\sqrt{T_1T}\right)}.$$对于固定压力$P$和固定气体温度$T_1$，根据该公式，增加壁温会降低壁密度。 壁密度可精确调节，以保持相同的压力。 

表达式为$P$因此，上面得出的结果并不是压力变化时的预测$T$变化。 这是之间的关系$P$和局部密度$n$。 自从$n$没有独立固定在密闭容器中，无法通过处理来比较不同壁温下的压力$n$作为常数。 

压力由容器中气体的状态决定，而壁温会改变与壁相邻的克努森层的密度。 

## 结果

 动力学理论计算给出$$P = \frac12 n k_B\left(T_1+\sqrt{T_1T}\right),$$在哪里$n$是邻近壁的分子密度。 

在密闭容器中，$n$不固定时$T$变化。 反而，$$n = \frac{2P} {k_B\left(T_1+\sqrt{T_1T}\right)}$$调整以使整个容器存在相同的机械压力。 

因此，计算不支持压力更大的说法$T>T_1$或更小$T<T_1$。 当近壁密度发生变化时，压力可以保持不变。 从问题中给出的信息来看，不等式$$P(T>T_1)>P(T<T_1)$$也不$$P(T>T_1)<P(T<T_1)$$成立。 

动力学理论分析的正确结论是，较热的壁对应于较低的壁相邻密度，较冷的壁对应于较高的壁相邻密度，而压力本身不仅仅由壁温度决定。 

## 健全性检查

 当$T=T_1$,$$P = \frac12 n k_B(T_1+T_1) = n k_B T_1,$$这是标准理想气体压力。 

解决$n$给出$$n=\frac{P}{k_B T_1},$$再次再现平衡理想气体关系。 

什么时候$T\to0$,$$P = \frac12 n k_B T_1,$$因此$$n=\frac{2P}{k_B T_1}.$$壁密度是维持相同压力所需的平衡值的两倍。 

什么时候$T\gg T_1$,$$P \sim \frac12 n k_B\sqrt{T_1T},$$所以$$n \sim \frac{2P}{k_B\sqrt{T_1T}}.$$壁密度减小为$T^{-1/2}$而压力仍然是有限的。 

这些限制情况与壁温改变紧邻壁的密度而不是直接确定密闭容器的压力的解释是一致的。
