 ## 解决方案

 ## 问题理解

 我们在数轴上给出了几个不同的点。 他们的立场是任意的、未经排序的。 任务是插入最少数量的附加点，以便在对所有原始点和插入点进行排序后，每对连续的点具有完全相同的距离。 

换句话说，我们希望通过仅添加新点而不移动现有点，将一组分散的坐标转换为完美均匀间隔的算术级数。 最后一组必须形成如下序列$a, a + d, a + 2d, \dots$每个原始点都出现在这个进程中的某个地方。 

关键约束是$n \le 100{,}000$，这立即排除了点对上的任何二次策略。 任何尝试将所有点对作为间距候选然后模拟完整构造的操作都必须小心地减少，因为简单的重建可能需要$O(n^2)$或者在最坏的情况下更糟。 

一个微妙的困难是原始点没有排序。 如果我们忘记先对它们进行排序，我们就根本无法推理出“相邻”距离。 另一种故障模式来自于假设全局间距是由输入顺序中的相邻差异决定的，这是任意的。 

当点已经均匀分布时，就会出现一个小但重要的边缘情况。 例如，输入：```
3
0 2 4
```这里不应该添加任何点。 任何总是试图“填补空白”而不首先检查间距一致性的方法都会错误地插入点。 

另一个案例：```
3
-5 10 5
```排序给出$-5, 5, 10$。 自然的步长是 5，但是 5 到 10 的差距是 5，而 -5 到 5 的差距也是 10，因此我们必须引入 0。仅考虑最小值和最大值的幼稚策略可能会错误地假设步骤 7.5 或类似的步骤并失败。 

## 方法

 蛮力观点首先选择两个现有点作为最终算术级数的潜在连续元素。 如果我们假设这两个在最终排列中是邻居，那么它们的差异定义了候选步长。 对于每个这样的候选点，我们尝试生成涵盖从最小值到最大值区间的完整算术级数，并计算其中缺少多少个原始点。 

这是有效的，因为任何有效的最终配置都必须是包含所有原始点的算术级数，因此其步骤必须与排序的最终序列中连续点之间的差异对齐。 然而，尝试所有对给出$O(n^2)$候选人，对于每个我们可以扫描最多$O(n)$点来验证覆盖范围，从而导致$O(n^3)$至少在最坏的解释中$O(n^2)$使用哈希，这对于$10^5$。 

关键的观察是我们不需要所有对。 如果我们对数组进行排序，正确的步长必须除以最终级数中相邻元素之间的所有差异。 这意味着步长必须是排序数组中所有相邻差异的最大公约数。 一旦我们计算出这个全局步骤$d$，最终的结构就完全确定了：它是步长从最小到最大的算术级数$d$。 

然后，我们可以通过迭代排序数组并对连续元素之间跳过的步骤进行求和来计算现有点之间缺少多少个整数。

 | 最佳 |$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 ### 最优策略

 1. 按升序对所有坐标进行排序。 这使得“邻近点”的概念在最终目标结构中得到了明确的定义。 如果不进行排序，差异就没有结构意义。 
2. 计算排序数组中每个连续对之间的差异。 这些差异表示当前配置中点之间的距离，任何有效的最终间距都必须将它们全部分开。 
3. 计算所有这些差异的最大公约数。 该值成为最大可能的统一步长，仍然允许所有原始点位于网格上。 较小的步长仍然有效，但需要插入更多点，因此 gcd 步骤是最佳的。 
4.设这个gcd为$d$。 最终目标级数从最小到最大值，步长$d$。 
5. 遍历排序后的数组，对于每个相邻的对$x[i], x[i+1]$, 计算$(x[i+1] - x[i]) // d - 1$。 这计算了在完美的算术级数中它们之间缺少多少个中间点。 
6. 将所有这些计数相加并输出结果。 

### 为什么它有效

 一旦我们修复了排序数组，任何有效的最终配置都必须将所有点对齐到统一的网格上。 最终序列中任何两个连续原始点之间的间距必须是排序输入中所有观察到的间隙的公约数。 最大公约数是最大的此类步长，并且使用它可以最大限度地减少所需插入点的数量，因为较大的步长对应于较少的中间位置。 然后，每个间隙都被精确地分解为大小相等的段$d$，因此计算缺失点变得确定性和间隙局部性，从而确保整条线的一致性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from math import gcd

n = int(input())
a = list(map(int, input().split()))
a.sort()

d = 0
for i in range(1, n):
    d = gcd(d, a[i] - a[i - 1])

if d == 0:
    print(0)
    sys.exit()

ans = 0
for i in range(n - 1):
    ans += (a[i + 1] - a[i]) // d - 1

print(ans)
```该解决方案首先对坐标进行排序，以便所有结构推理都按一致的顺序执行。 gcd 累积步骤逐步将所有局部差异合并为单个全局步长。 对零的检查处理所有点都重合的退化情况，尽管该问题保证了不同的值，因此它主要是防御性的。 

最后的循环重建每个相邻对之间必须有多少个均匀间隔的点。 表达式$(a[i+1] - a[i]) // d - 1$直接计算由step定义的算术级数上两个已知位置之间缺失的格点$d$。

 ## 边缘情况

 对于已经均匀分布的点，例如：```
5
1 4 7 10 13
```排序后的差异均为 3，因此 gcd 仍为 3。每个间隙满足$(a[i+1] - a[i]) // 3 - 1 = 0$，产生正确的输出 0。 

对于初始排序不均匀的情况：```
3
10 0 5
```排序给出$[0, 5, 10]$。 gcd 为 5，不需要插入，因为该算法完全忽略输入顺序并根据排序的几何结构重建结构。 

对于间隙较大的情况，例如：```
2
0 1000000000
```gcd 等于差值本身，因此不需要中间点。 该算法正确地避免了插入完整的密集网格，因为在所有原始点必须位于级数上的约束下步长被最大化。
