 ## 解决方案

 ## 问题理解

 我们有一天会无限重复，以 24 小时为一个周期。 每个闹钟每天只占用一分钟的时间，这些闹钟时刻是固定的，每天在时钟上的相同位置重复。 在这几分钟里，波利卡普无法入睡，闹钟一响，他就醒着，直到那一分钟结束。 

任务是考虑到时间的循环性质，找到没有警报响起的最长连续时间间隔。 该间隔可以在午夜结束，这意味着它可以在一天结束时开始，并持续到第二天开始。 

思考这个问题的一个有用方法是将所有闹钟时间放在 1440 分钟的圆圈上。 每个警报都会阻挡该圆上的一个点，并且我们希望顺时针移动时连续阻挡点之间的间隙最大。 

约束 n ≤ 100 意味着我们可以轻松地提供 O(n²) 甚至 O(n log n) 的解决方案。 在这里，排序在任何最优情况中都占主导地位，甚至在排序后对所有对进行暴力破解仍然是微不足道的。 

微妙的边缘情况来自于一天的循环性质。 如果我们只考虑连续排序的警报之间的差异而不处理环绕，我们就会错过当天的最后一个警报与第二天的第一个警报之间的间隙。 例如，如果 05:43 只有一个警报，则简单的差异计算可能会错误地返回 0，而不是识别完整的 23:59 间隙。 

当警报非常接近时，会出现另一种边缘情况。 例如，如果闹钟在 00:00 和 00:01，则​​正确答案是 00:58 或 23:58，具体取决于对包含分钟的解释，并且粗心地处理“一分钟响铃间隔”可能会使结果偏移一分钟。 

## 方法

 暴力破解的想法首先将所有闹钟时间转换为自午夜以来的分钟数，然后对于每对可能的闹钟，计算它们之间的圆周时间间隔。 对于每一对 (i, j)，我们测量从警报 i 到警报​​ j 向前移动的时间，必要时环绕日边界，并取最大值。 

这是有效的，因为任何最大睡眠间隔必须在某个警报结束后立即开始，并在另一个警报开始时结束，因此其端点与警报​​边界一致。 对于 n 个警报，有 O(n²) 个候选对，计算每个间隙的时间为 O(1)，导致总工作量为 O(n²)，在 n ≤ 100 时仍然没问题。 

改进来自于我们注意到我们不需要所有的对。 一旦对时间进行排序，最佳间隙必须出现在按循环顺序的连续警报之间。 如果存在跨越多个中间警报的较大间隙，则这些中间警报将位于该间隔内并与最大值相矛盾。 这减少了扫描排序圆形数组中相邻差异的问题。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(1) | O(1) | 已接受 |
 | 最优（排序+相邻间隙）| O(n log n) | O(n log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 将每个闹钟时间从“hh:mm”转换为从 00:00 开始的总分钟数。 这给出了循环日的线性表示。 
2. 将所有转换后的时间按升序排序，以便连续的元素代表时钟上连续的报警事件。 
3. 计算排序列表中每个相邻对之间的间隙。 对于两个连续的闹钟 a[i] 和 a[i+1]，它们之间的空闲时间为 a[i+1] - a[i] - 1，因为两个端点都被闹钟占用。 
4. 还计算午夜从最后一个警报到第一个警报的环绕间隙。 这是 (1440 - a[last]) + a[0] - 1。 
5. 取所有计算间隙中的最大值。 
6. 将此最大免费分钟数转换回“hh:mm”格式。

在每个间隙中减 1 是必要的，因为每个警报占用了其完整的分钟间隔。 如果在t时刻发生闹钟，则[t,t+1)分钟被阻塞，因此睡眠只能在t+1开始，同样必须在下一个闹钟分钟开始之前结束。 

### 为什么它有效

 排序后，任何最大睡眠间隔必须位于按循环顺序连续的两个闹钟开始时间之间。 如果间隔跨越中间闹钟，则该闹钟占用的分钟将破坏睡眠的连续性。 因此，每个有效的最大间隔恰好对应于圆上连续警报时间之间的间隙之一。 检查所有这些间隙，包括环绕边界，会耗尽所有候选者，而不会遗漏或重复。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def to_minutes(s):
    h, m = map(int, s.split(":"))
    return h * 60 + m

n = int(input())
a = [to_minutes(input().strip()) for _ in range(n)]
a.sort()

best = 0

for i in range(n - 1):
    gap = a[i + 1] - a[i] - 1
    best = max(best, gap)

wrap_gap = (1440 - a[-1]) + a[0] - 1
best = max(best, wrap_gap)

h = best // 60
m = best % 60
print(f"{h:02d}:{m:02d}")
```转换步骤确保所有比较都在统一的线性范围内完成。 排序按时间顺序放置警报，因此相邻的差异是有意义的。 相邻对上的循环捕获所有内部间隙，而环绕计算处理时间的循环性质。 减去一分钟至关重要，因为间隙的两个端点都对应于闹钟分钟，而这些分钟不可用于睡眠。 

最后的格式化步骤确保分钟数保持在 [0, 59] 范围内，与所需的输出格式匹配。

 ## 边缘情况

 单个警报突出了循环解释。 有输入`05:43`，排序产生一个元素，算法会跳过内部间隙。 换行计算得出 (1440 - 343 - 1) = 1096 分钟，正好对应于 23:59。 该算法正确地将这一天视为在午夜前后连续。 

两个相邻的警报位于`00:00`和`00:01`测试逐一逻辑。 转换后，内部间隙为 0 - 1 = -1，被 max 钳位为 0。换行间隙变为 (1440 - 1) + 0 - 1 = 1438 分钟，即 23:58。 这证实了排除两个警报分钟的处理正确，并且回绕计算与线性间隙保持一致。
