 ## 解决方案

 ## 问题理解

 我们的教室布局固定，有 6 排，每排 3 个课桌组。 每一行都写成一个字符串，其中每个办公桌组包含两个座位位置（左侧和右侧），在视觉上用破折号分隔。 单元格可以是空的或已被占用。 

Petya 想要选择一个空座位并将其标记为已占用。 座位的好坏取决于它的“便利性”，便利性取决于它离黑板的距离以及在柱子之间的中心位置。 靠近顶部的行更好，并且在一行内，中心列比左侧或右侧更方便。 

任务是找到任何达到最大可能便利分数的空座位，并将其替换为角色`P`，保持其他一切不变。 

尽管网格很小并且大小固定，但结构仍然很重要：我们必须同时正确解释行优先级和列优先级。 忽略排序或误解座位位置的简单扫描很容易选择次优位置。 

由于输入只有 6 条长度为 8 的行，因此对所有单元格进行暴力破解是微不足道的。 关键的困难不是性能，而是正确地将布局映射到一致的座位需求排名。 

边缘案例主要源于关系。 多个座位可以共享相同的最大便利性，其中任何一个都有效。 另一个微妙的问题是正确处理每排的三个座位块； 混合两个席位分组可能会导致错误的索引和错误的比较。 

例如，如果我们错误地将字符串视为 8 个独立字符，我们可能会错误地将破折号位置视为有效座位。 这些必须完全被忽略。 

## 方法

 强力解决方案评估每个有效座位，并根据其行和列为其分配便利分数。 对于每个位置，我们检查它是否为空，计算其分数，并跟踪最佳位置。 由于网格大小固定（6×3个座位组，每个座位2个），因此最多有36个位置，因此即使重复计算也可以忽略不计。 

关键的观察是我们不需要任何高级结构：网格很小，并且排名是按字典顺序排列的。 座位越高排越好； 如果行数相等，则座位越靠中央越好。 这意味着我们可以从上到下、从左到右（或使用自定义顺序）扫描，并简单地保留与全局最大值匹配的第一个座位。 

最可靠的方法是将列首选项显式编码为固定优先级数组。 在每一行中，我们按需求顺序检查座位，并选择包含至少一个空闲座位的最佳行中的第一个有效座位。

 | ---| ---| ---| ---|
 | 蛮力 | O(36) | O(1) | O(1) | 已接受 |
 | 最佳 | O(36) | O(1) | O(1) | 已接受 |

 ## 算法演练

 我们将教室转换为可以清晰索引的结构：对于每一行，我们在字符串中的固定位置识别三个座位对。 

1. 将优先级的列顺序定义为首先是中心组，然后是左组，然后是右组。 这反映了问题的观点，即中央座位更方便。 
2. 从上到下扫描行，因为前面的行比后面的行更方便。 
3. 对于每一行，按预定义的列顺序检查座位组。 
4. 在每个组内，首先检查左侧座位，然后检查右侧座位，因为两个座位在该组内的位置相同。 
5. 一旦我们找到座位`.`（空），我们将其替换为`P`并立即输出完整的网格。 
6. 标记一个座位后停止，因为任何进一步的选择都会不太方便或同样方便，并且该问题允许任何最佳解决方案。 

### 为什么它有效

 该算法依赖于严格的座位字典顺序：行索引是主键，列组是辅助键。 通过按优先级降序扫描并停在第一个有效位置，我们确保始终在此排序下选择全局最大元素。 由于后面的座位不可能有更好的排，并且在同一排中我们按从最好到最差的顺序进行探索，所以正确性来自于对总顺序的贪婪选择。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

grid = [list(input().strip()) for _ in range(6)]

# column groups: (row_string indices of seats)
groups = [
    (0, 1),  # left desk
    (3, 4),  # center desk
    (6, 7)   # right desk
]

placed = False

for i in range(6):  # top to bottom
    for a, b in groups:
        if grid[i][a] == '.':
            grid[i][a] = 'P'
            placed = True
            break
        if grid[i][b] == '.':
            grid[i][b] = 'P'
            placed = True
            break
    if placed:
        break

for row in grid:
    print(''.join(row))
```该解决方案首先将固定大小的网格读取到可变的字符数组列表中。 它使用硬编码索引定义办公桌组的映射，因为输入格式保证了固定位置。 

外循环从上到下处理行，通过靠近黑板确保优先级。 内循环按中心优先的顺序检查办公桌组。 在每组中，我们先检查左边的座位，然后检查右边的座位。 

一旦找到有效的座位，我们立即对其进行标记并打破两个循环。 这保证了我们永远不会覆盖或考虑次优的展示位置。 

一个常见的陷阱是尝试计算数字分数而不是使用直接排序。 这在这里是不必要的，只会增加打破平局错误的风险。

 ## 边缘情况

 一个重要的边缘情况是唯一可用的座位位于最后一排。 在这种情况下，算法仍然扫描所有行并且仅扫描位置`P`在最后。 例如：

 输入：```
**-**-**
**-**-**
**-**-**
**-**-**
**-**-**
..-**-**
```扫描完全跳过前五行。 在第 5 行，选择团体顺序中遇到的第一个空闲座位。 该算法保证了正确性，因为它不会过早地假设存在更高的行。 

另一种极端情况是同一排的多个座位都是空的。 组排序确保我们选择中心优先，即使 left 出现在字符串的前面。 这避免了在不考虑办公桌分组的情况下逐个字符扫描的常见错误。
