 ## 解决方案
 ## 问题理解

 我们得到一个字符串`s`其中包含`0`,`1`， 和`?`。 问号代表灵活的位置：我们可以替换每个`?`独立地与任一`0`或者`1`。 我们的目标是生成一个与该模式匹配的完全二进制字符串，以便最大限度地降低排序成本。 这里，成本被定义为使字符串不递减所需的连续子串反转的最小次数。 

例如，如果`s`是`??01?`，一个替代品可能是`00011`。 这个字符串已经排序了，所以它的成本是0。如果我们选择`11010`，成本会更高，因为我们需要多次反转才能对其进行排序。 

输入大小允许字符串最多 300,000 个字符和最多 30,000 个测试用例，所有测试用例的总字符数最多为 300,000 个。 这意味着任何算法都必须以相对于每个测试用例的字符串长度的线性时间运行。 二次方法，例如测试所有组合`?`替换或模拟所有逆转都是不可行的。 

一个微妙的边缘情况是当一个模式拥有所有`?`人物。 幼稚的方法可能会任意填充它们，例如全部`0`或全部`1`s，但这可能不会产生最小的成本。 例如，`???`理想情况下应该成为`000`或者`111`以避免不必要的逆转，而`010`将迫使至少发生一次逆转。 同样，像这样的模式`?1?0?`需要仔细填充现有的`0`沙`1`避免创建增加成本的递减序列。 

## 方法

 暴力方法会枚举所有可能的替代品`?`，生成所有匹配字符串，并计算每个字符串的反转成本。 排序二进制字符串的成本可以通过计算连续的“块”来计算`1`s 在最后一个之后`0`反之亦然。 对于一个长度的字符串`n`, 最多有`2^k`的替代品`k`问号。 在最坏的情况下，`k`可能是`3*10^5`，所以这是完全不可行的。 

关键的见解是成本取决于从`1`到`0`在最后的字符串中。 每个连续的块`1`s 后面跟着一个`0`需要一次反转才能排序。 因此，为了最大限度地降低成本，我们应该避免创建`1`随后是一个`0`只要有可能。 这立即表明了一种贪婪的方法：传播`0`s 向左并且`1`尽可能向右。 具体来说，任意`?`之间`0`和一个`1`可以选择匹配其邻居以避免创建额外的转换。 如果一个`?`只被包围`?`s，它可以安全地变成`0`或者`1`而不增加成本。 

贪婪传播分两遍进行：一次向前传递来处理`0`s 和一次向后传递来处理`1`s。 这确保了每一个`?`以不会产生不必要的方式填充`1->0`过渡。 该算法与字符串长度呈线性关系。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(2^k * n) | O(2^k * n) | O(n) | 太慢了 |
 | 贪婪传播 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 转换输入字符串`s`到字符列表中以允许就地修改。 
2. 从左向右向前传球。 跟踪最后一次看到的内容`0`。 每当一个`?`遵循一个`0`，将其替换为`0`。 这确保没有新的`1->0`转换是在 a 之后立即创建的`0`。 
3. 从右向左向后传递。 跟踪最后一次看到的内容`1`。 每当一个`?`在一个之前`1`，将其替换为`1`。 这避免了新的转换`1`到`0`相反。 
4. 经过这两遍之后，剩余的`?`可以安全地替换为`0`（或者`1`）因为它们是孤立的并且不会创建额外的转换。 
5. 将列表重新连接成字符串并打印。 

为什么有效：每个`1->0`二进制字符串中的转换会增加成本。 贪心传播确保没有`?`填补介绍一个新的`1->0`过渡。 两遍系统保证所有位置均受现有影响`0`或`1`采用不会增加成本的值。 任何剩余的隔离`?`s 要么位于边缘，要么被统一的字符包围，因此它们的选择不会影响成本。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        s = list(input().strip())
        n = len(s)

        # Forward pass: propagate 0s
        last_zero = -1
        for i in range(n):
            if s[i] == '0':
                last_zero = i
            elif s[i] == '?' and last_zero != -1:
                s[i] = '0'

        # Backward pass: propagate 1s
        last_one = -1
        for i in reversed(range(n)):
            if s[i] == '1':
                last_one = i
            elif s[i] == '?' and last_one != -1:
                s[i] = '1'

        # Replace remaining '?'
        for i in range(n):
            if s[i] == '?':
                s[i] = '0'

        print("".join(s))

if __name__ == "__main__":
    solve()
```前向传递确保所有`?`继一个`0`变得`0`，防止新的转变。 向后传递的作用相同`1`s 相反。 任何剩余的`?`s，孤立的或在边缘，充满了`0`s 生成有效的二进制字符串。 这种方法避免了任何相差一的错误，因为只有最后看到的字符存在时才会发生替换。
