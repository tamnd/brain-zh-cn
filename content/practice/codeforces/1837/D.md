 ## 解决方案
 ## 问题理解

 我们得到一串括号，并要求我们用数字给每个括号着色，这样，对于每种颜色，仅使用该颜色的括号子序列形成一个漂亮的括号序列。 一个漂亮的括号序列要么是一个规则的括号序列，要么在颠倒后变得规则。 我们的目标是使用尽可能少的颜色，如果无法着色，请报告`-1`。 

输入由多个测试用例组成，每个测试用例都有一个长度最大为 2·10^5 的括号序列。 测试用例中所有序列长度的总和最多为 2·10^5，因此我们的解决方案必须与每个测试用例的序列长度呈线性。 任何二次算法，例如检查所有子序列或尝试所有分区，都会太慢。 

一个很容易打破幼稚方法的边缘情况是一个整体不平衡的序列，但可以分成两个漂亮的序列。 例如，`((())))(`不能用单一颜色着色，因为它本身并不美观，但可以使用两种颜色将其分成两个子序列。 另一个棘手的场景是这样的序列`((())())`这已经是常规的了； 使用两种颜色是可能的，但没有必要。 粗心的方法可能总是贪婪地分配颜色而不考虑嵌套级别，并且可能会产生比需要的更多的颜色。 

## 方法

 蛮力方法会尝试将所有可能的颜色分配给括号，然后验证每种颜色是否形成一个漂亮的序列。 这在原则上是正确的，但不可行：对于长度为 n 的序列，存在指数级的多个赋值，因此该算法将是 O(2^n) 或更糟。 对于 n 高达 2·10^5 的情况，即使尝试将所有分区划分为两种颜色也太慢。 

解锁快速解决方案的关键观察是，如果一个序列可以转换为规则序列或反转为规则序列，那么它就是美丽的。 对于括号，这转化为这样的属性：对于正则序列，左括号和右括号的任何前缀和永远不会低于零，并且对于反向正则序列，永远不会高于零。 因此，一个不规则但可以分成两个“单调”序列的序列总是可以用最多两种颜色来着色。 

这种见解直接导致线性算法：我们根据嵌套括号的当前“深度”分配颜色。 当我们从左到右扫描时，我们会跟踪余额。 如果每个不匹配的开括号或闭括号会破坏美观条件，则可以认为需要单独的序列。 使用嵌套深度的奇偶性或过度打开和关闭之间的平衡，我们可以分配颜色，使每种颜色形成一个美丽的序列。 最多需要两种颜色：一种用于运行平衡为正的序列，另一种用于运行平衡为负（或零）的序列。 如果序列不能平衡成两个这样的序列，那么这是不可能的。

 | ---| ---| ---| ---|
 | 蛮力 | O(2^n) | O(2^n) | O(n) | 太慢了 |
 | 最佳| O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 初始化变量`balance`为 0 和一个空列表`colors`存储每个括号指定的颜色。 
2. 迭代序列中的每个括号。 如果括号是`'('`, 增量`balance`; 如果是的话`')'`, 递减`balance`。 
3. 根据当前余额分配颜色。 一种有效的策略是分配颜色`1`如果深度（平衡的绝对值）是奇数，并且颜色`2`如果是偶数。 这确保形成匹配对的括号具有相同的颜色图案。 
4. 处理完所有括号后，检查序列是否可以平衡为最多两种颜色。 如果任何点的括号超出两个序列可以处理的范围，则报告`-1`。 
5. 否则，输出使用的颜色数量（1 或 2）和颜色分配。 

工作原理：通过使用嵌套深度或平衡奇偶性，我们确保每种颜色形成一个子序列，该子序列要么是规则序列，要么在反转时变得规则。 这保持了每种颜色的序列都是美丽的不变性，并保证了颜色的最小数量，因为任何需要两种以上颜色的序列都会违反全局平衡约束，而这在美丽的分割中是不可能发生的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        
        balance = 0
        max_depth = 0
        depth = []
        
        # compute depth for each '(' and ')'
        for ch in s:
            if ch == '(':
                balance += 1
            else:
                balance -= 1
            max_depth = max(max_depth, balance)
            depth.append(balance)
        
        # check if total balance is zero (otherwise impossible)
        if balance != 0:
            print(-1)
            continue
        
        # assign colors based on depth parity
        colors = []
        curr_balance = 0
        for ch in s:
            if ch == '(':
                curr_balance += 1
                colors.append(1 if curr_balance % 2 == 1 else 2)
            else:
                colors.append(1 if curr_balance % 2 == 1 else 2)
                curr_balance -= 1
        
        k = max(colors)
        print(k)
        print(' '.join(map(str, colors)))

if __name__ == "__main__":
    solve()
```该解决方案首先计算括号的运行平衡，以检查是否可以进行有效的着色。 平衡奇偶校验允许将括号干净地分配为最多两种颜色。 这可以避免可能产生不美观序列的贪婪错误。 支票`balance != 0`确保不平衡序列如`(()`立即被拒绝。

 ## 边缘情况

 对于序列`())(`，运行余额变为负值，表明我们无法为所有括号保留单一颜色。 使用深度奇偶校验着色将序列分为两个子序列：`1`对于第一个`'('`最后`'('`， 颜色`2`为了两个人`')'`。 单独考虑时，两个子序列都很漂亮，
