 ## 解决方案
 ## 问题理解

 给定一个正整数数组，我们希望所有元素共享相同的奇偶校验——要么都是偶数，要么都是奇数。 唯一允许的操作是选择两个具有不同奇偶校验的元素并将较大的数字添加到较小的数字。 每一个这样的操作都会修改一个数字，从而可能改变其奇偶校验。 

输入由多个测试用例组成。 对于每个测试用例，我们都会得到数组的大小和数组本身。 每个测试用例的输出是一个数字，表示使所有元素具有相同奇偶校验所需的最少操作数。 

这些约束足够严格，足以排除任何强力模拟。 所有测试用例中包含多达 200,000 个元素，数量高达$10^9$，重复模拟成对运算将需要太多步骤。 1 秒的时间限制意味着我们需要一个相对于线性或接近线性时间运行的解决方案$n$每个测试用例。 

当数组已经具有相同奇偶校验的所有元素时，会出现非明显的边缘情况，这需要零次操作，或者当只有一个少数奇偶校验元素时，这很容易通过单个操作统一。 另一个微妙的情况是，当数组具有两个奇偶校验的多个元素，但其中一些比其他元素大得多时 - 关键的见解是实际值并不重要，只有它们的奇偶校验。 

例如，一个数组`[2, 3, 4]`有两个偶数和一个奇数。 最少运算次数为 2：我们必须通过与偶数元素交互来将奇数变为偶数，然后所有数字都具有相同的奇偶性。 尝试按顺序模拟总和的简单方法可能会使此操作过于复杂并导致计数过多。 

## 方法

 暴力方法将尝试模拟每一种可能的操作。 对于每对具有不同奇偶校验的索引，我们将执行求和运算并重复，直到所有数字共享相同的奇偶校验。 虽然正确，但这种方法可能需要许多操作，可能$O(n^2)$每个测试用例，因为每个操作只会将一个奇偶校验的计数减少 1。 对于最大的数组，这意味着最多$2 \cdot 10^10$的操作，这是不可行的。 

关键的观察是实际金额是无关紧要的； 只有平价才重要。 每个操作都会将少数奇偶校验的计数减一，因为较小数字的奇偶校验保证会更改以匹配较大数字的奇偶校验。 因此，最小操作数只是当前位于少数奇偶校验组中的元素的计数。 我们不需要模拟总和或跟踪实际数字； 计算奇数和偶数元素就足够了。 

这一观察结果将问题转化为一个简单的计数问题。 对于每个测试用例，我们计算奇数和偶数元素的数量，并取两个计数中较小的一个。 这给出了所需的确切最小操作数。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 暴力模拟| O(n^2) | O(n^2) | O(n) | 太慢了|
 | 计算奇偶校验 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取整数$n$和数组$a$尺寸的$n$。 
2.初始化两个计数器，`odd_count`和`even_count`，都设置为零。 
3. 迭代数组。 对于每个元素，递增`odd_count`如果元素是奇数，否则递增`even_count`。 
4. 计算最小值`odd_count`和`even_count`。 该值表示使所有元素共享相同奇偶校验的最少操作次数。 
5. 打印当前测试用例的计算最小值并对所有测试用例重复。 

这样做的原因是每次操作总是从少数奇偶校验组中消除一个元素。 因此，将少数计数减少到零可以保证所有数字共享相同的奇偶校验，这正是我们计算的操作数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    odd_count = sum(1 for x in a if x % 2)
    even_count = n - odd_count
    
    print(min(odd_count, even_count))
```该解决方案首先读取测试用例的数量。 对于每个测试用例，它读取数组并计算奇数。 偶数计数是通过从总数中减去奇数计数来推断的。 取两个计数中的最小值即可得出答案。 生成器表达式确保线性时间迭代并避免不必要的存储。 对于边缘情况不需要特殊处理，因为当所有数字共享相同的奇偶校验时，最小函数自然返回零。

 ## 边缘情况

 如果数组的奇偶校验已经是统一的，比如`[4, 4, 4, 4]`,`odd_count`为零，所以`min(odd_count, even_count)`返回零。 该算法可以正确处理这个问题，没有任何特殊情况。 

对于只有一个元素少数奇偶校验的数组，例如`[2, 3, 4]`,`odd_count`是 1 并且`even_count`是 2，最少进行 1 次操作。 该算法并不试图模拟操作； 数一下就够了。
