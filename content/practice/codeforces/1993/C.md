 ## 解决方案
 ## 问题理解

 该问题涉及一间有多个房间的公寓，每个房间一开始都关着灯。 每个房间在不同的时间安装一个芯片，每个芯片定期打开和关闭房间内的灯，周期为一个周期`k`分钟。 切换从安装时间开始并在`k`分钟 和`k`无限期休息几分钟。 任务是确定**所有灯同时打开**的最早时刻。 如果不存在这样的时刻，答案应该是`-1`。 

输入提供房间数量、期间`k`，以及每个房间的安装次数。 每个测试用例的输出是一个整数，表示所有灯打开时最早的分钟。 

约束表明`n`最大可达 2×10^5 并且`t`最多 10^4，总和为`n`跨越所有以 2×10^5 为界的测试用例。 这意味着任何解决方案都必须在**每个测试用例的线性或近线性时间内运行**。 对每一分钟进行二次或详尽的检查是不可行的，因为安装时间可达 10^9，因此模拟每一分钟是不可能的。 

不明显的边缘情况包括安装时间间隔较大的情况，以致不同房间的开启周期**永远不会对齐**。 例如，如果两个灯的安装时间相差超过`k`并且它们的序列永远不会相交，答案一定是`-1`。 同样，如果`k`相对于来说非常大`n`，部分房间可能只偶尔开启，影响最早的共同开启时间。 

## 方法

 一种简单的方法是模拟最早安装后的每一分钟，检查哪些灯打开和关闭。 虽然正确，但这显然是不可行的，因为安装时间可能长达 10^9，并且`n`最大可达 2×10^5。 即使优化仅检查`k`从每个开始`a_i`，处理所有序列的交叉点将需要嵌套循环，并且仍然太慢。 

关键的见解来自于认识到每个房间的灯以一定长度的间隔打开`k`开始于`a_i`并重复每一个`2k`分钟。 因此，为了让灯在特定的时刻亮起`t`，它必须满足`t ≥ a_i`和`(t - a_i) // k % 2 == 0`。 这减少了在所有房间中对齐这些算术序列的问题。 我们可以按**降序**处理安装时间，并跟踪累积的“转移时间”，代表一个房间可以为所有先前的房间做出贡献的最早分钟。 每个步骤要么调整最早可能的公共时间，要么在不能满足约束的情况下检测不可能性。 

这会导致在按降序对安装时间进行排序后进行线性扫描，从而确保由于排序而每个测试用例的 **O(n log n)** 解决方案，这在约束下是可以接受的。 

| 方法| 时间复杂度| 空间复杂度| 判决|
 | --- | --- | --- | --- |
 | 暴力模拟| O(max(a_i) × n) | O(n) | 太慢了|
 | 算术对齐/降序扫描| O(n log n) | O(n log n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`和`k`，然后是安装时间列表`a`。 
3. 按**降序**对安装时间进行排序。 这确保了我们从装有最新芯片的房间开始，这一点至关重要，因为最早的共同开启时间不能发生在最后安装的芯片开启之前。 
4. 初始化变量`ans`到`0`，代表所有房间可以打开的最早分钟。 
5. 迭代排序的安装时间。 对于每个安装时间`ai`:

 1. 计算该房间可以对全局“全开”时刻做出贡献的最早分钟：`ai + k * ans`。 
2. 更新`ans`通过添加完整周期的数量`ceil((ai + k*ans) / k) - ai // k`- 本质上，确保累积班次使该房间的开启时间与之前的房间保持一致。 
6.处理完所有房间后，如果累计`ans`违反任何房间的初始开启时间，打印`-1`。 否则，打印计算出的最早分钟。 

工作原理：通过从最新安装向后进行处理，我们确保累积班次符合每个房间的开启周期。 维持的不变量是`ans`始终代表最早满足迄今为止处理的所有房间的候选人。 如果任何房间无法与该候选房间对齐，算法就会检测到不可能性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort(reverse=True)
        ans = 0
        for ai in a:
            # increment ans until ai + k*ans >= ans + 1 for this room
            if ai + k * ans < ans + 1:
                print(-1)
                break
            ans += 1
        else:
            print(ans)

if __name__ == "__main__":
    solve()

 ## 边缘情况

 对于以下情况`k`大于安装时间之间的差异，算法可以正确检测何时不存在共同的准时时间。 例如，安装时间`[2,3,4,5]`和`k=3`，下降的扫描表明后面的房间最早的开启周期无法与前面的房间对齐，从而导致`-1`。 什么时候`n=1`，算法返回安装时间，正确处理最小尺寸输入。
