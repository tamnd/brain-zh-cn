 ## 解决方案
 ## 问题理解

 我们需要计算大小的方格`n × n`充满数字`0..9`。 

网格必须满足两个结构规则。 

第一条规则规定任何两个边缘相邻的单元最多相差`1`。 

第二条规则说，每个`2 × 2`块具有相等的对角线和。 如果一个块是$$\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}$$那么我们必须有`a + d = b + c`。 

在所有这些网格中，我们只想要那些每个坏矩形面积最多的网格`k`。 

对于一个矩形，让`mx`和`mn`是里面的最大值和最小值。 自从$$\text{next}=mx+1,\qquad \text{prev}=mn-1,$$条件$$\text{next}-\text{prev}=l+b$$相当于$$mx-mn=l+b-2.$$因此，当矩形的值范围达到矩形尺寸的最大可能值时，矩形就是坏的`l × b`。 

约束条件`n ≤ 500`立即排除任何对实际网格进行推理的方法。 一个网格包含`250000`细胞，并且可能的填充物的数量是天文数字。 该解决方案必须利用谐波条件所施加的强代数结构。 

当模式在选择起始数字之前达到数字范围之外的值时，会出现微妙的边缘情况。 

例如，行模式可能会访问`-5`和`4`。 这仍然有效，因为稍后我们可以通过选择合适的起始数字来向上移动整个网格。 过早拒绝此类模式将失去有效的解决方案。 

另一个容易犯的错误是认为最大的坏矩形取决于行模式的总变化。 考虑顺序```
0 1 2 1 2
```其总范围为`2`，但其最长的严格单调性`±1`条纹有长度`3`。 坏矩形是由这些条纹控制的，而不是由整体范围控制的。 

## 方法

 蛮力的想法是生成每个网格并测试条件。 即使是为了`n = 3`， 有`10^9`可能的网格。 搜索空间在真正的极限之前就已经爆炸了。 

关键的观察来自对角线和条件。 让`h[i][j]`是网格值。 

从$$h[i][j] + h[i+1][j+1]
=
h[i][j+1] + h[i+1][j]$$对于每一个`2 × 2`块，网格在加性意义上具有排名第一：$$h[i][j] = s + r_i + c_j.$$这里`s`是起始值，`r_i`描述行偏移，以及`c_j`描述列偏移。 

邻接条件现在变得极其简单。 连续行偏移量最多相差`1`，并且连续的列偏移量最多相差`1`。 

因此，我们不需要构建整个网格，而只需要两个一维模式。 

下一步是了解坏矩形。 

对于跨越的矩形`l`行和`b`列，$$mx-mn
=
(\max r-\min r)
+
(\max c-\min c).$$因为连续的差异是`{-1,0,1}`，行贡献最多为`l-1`，列贡献最多为`b-1`。 

当两个贡献都达到各自的最大值时，矩形就会变得很糟糕。 仅当相应的行段是纯行段时才会发生这种情况`+1,+1,+1,...`条纹或纯`-1,-1,-1,...`条纹，柱段也是如此。 

如果最长的行条纹有长度`S1`最长的柱状条纹的长度为`S2`，那么最大的坏矩形的面积$$S_1 \cdot S_2.$$因此，条件“没有面积大于的坏矩形”`k`” 变成$$S_1S_2 \le k.$$现在问题简化为计算长度的一维模式`n`。 

每个图案开始于`0`, 移动经过`-1`,`0`， 或者`1`，我们需要知道：

 - 达到的最大值，
 - 达到的最小值，
 - 最长的单调`±1`条纹。 

由于最终的网格使用数字`0..9`，仅总范围保持在以下范围内的模式`9`可以参与有效的回答。 这允许紧凑的动态编程状态。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解网格 | 指数| 指数| 太慢了|
 | 行/列模式上的 DP |`O(n · 20 · 10 · 10 · 20 · 10)`| 与状态计数相同的顺序 | 已接受 |

 ## 算法演练

 ### 1. 用两个一维模式表示每个谐波网格

 将第一个单元格值修复为移位`s`。 

让行偏移和列偏移从`0`。 

那么每个单元格都可以写成$$h[i][j]=s+r_i+c_j.$$连续偏移量的不同之处在于`-1`,`0`， 或者`1`。 

### 2.在一维模式上构建DP

 我们生成一个长度的模式`n`开始于`0`。 

DP商店：

 - 当前位置，
 - 当前偏移量，
 - 达到最大偏移量，
 - 达到最小偏移量，
 - 目前的连胜纪录，
 - 有史以来达到的最大条纹长度。 

目前的连续性为正值`+1`移动，连续负数`-1`移动，最后移动时为零`0`。 

### 3. 三种可能的动作的过渡

 从当前的偏移量我们可以：

 - 增加`1`,
 - 保持不变，
 - 减少`1`。 

在此过程中，我们更新：

 - 当前偏移量，
 - 全局最大值，
 - 全局最小值，
 - 当前的连胜，
 - 最大连胜。 

偏移量限制为`[-9,9]`，因为较大的偏移永远无法容纳在数字网格内。 

### 4. 聚合模式计数

 加工后长度`n`， 收集$$cnt[mx][mn][streak]$$在哪里：

-`mx`是达到的最大偏移量，
 -`mn`是达到的最小负偏移量的大小，
 -`streak`是最长的单调条纹长度。 

### 5. 组合两种模式

 一种图案成为行图案，另一种图案成为列图案。 

起始数字`s`有效时$$s+mx_1+mx_2 < 10$$和$$s-mn_1-mn_2 \ge 0.$$同样，所有网格值都保留在内部`0..9`。 

### 6. 强制执行坏矩形限制

 如果最长的条纹长度是`st1`和`st2`，那么最大的坏矩形的面积$$st1 \cdot st2.$$只保留令人满意的配对$$st1 \cdot st2 \le k.$$### 7. 对所有有效组合求模求和`10^9+7`每对有效的模式和每个有效的起始数字都有助于得出答案。 

### 为什么它有效

 对角线和条件强制网格可表示为独立行分量和列分量的总和。 一旦网格以这种方式编写，每个矩形范围都会分解为行范围和列范围。 

只有当矩形的行段和列段都达到各自的理论最大值时，矩形才达到最大可能范围。 因为每一步最多改变`1`，这恰好发生在不间断的情况下`+1`或者`-1`条纹。 最长的条纹完全决定了该维度中可能的最大坏矩形。 

DP 将每个可接受的一维模式精确地枚举一次，并精确记录稍后所需的信息：值范围和最长条纹。 组合两个模式可以准确地重建每个谐波网格一次，因此最终计数是正确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def solve():
    n, k = map(int, input().split())

    # dp[pos][mx][mn][streak][best]
    # rolled over current offset dimension as in the official solution idea

    dp = [[[[[0] * 10 for _ in range(19)] for _ in range(10)]
            for _ in range(10)] for _ in range(19)]

    dp[9][0][0][9][0] = 1

    for _ in range(1, n):
        ndp = [[[[[0] * 10 for _ in range(19)] for _ in range(10)]
                 for _ in range(10)] for _ in range(19)]

        for cur in range(-9, 10):
            curi = cur + 9

            for mx in range(10):
                for mn in range(10):
                    for streak in range(-9, 10):
                        sti = streak + 9

                        row_dp = dp[curi][mx][mn][sti]

                        for best in range(10):
                            val = row_dp[best]
                            if not val:
                                continue

                            if cur < 9 and streak < 9:
                                ncur = cur + 1
                                nmx = max(mx, ncur)

                                nstreak = max(1, streak + 1)
                                nbest = max(best, nstreak)

                                ndp[ncur + 9][nmx][mn][nstreak + 9][nbest] = (
                                    ndp[ncur + 9][nmx][mn][nstreak + 9][nbest]
                                    + val
                                ) % MOD

                            ndp[cur + 9][mx][mn][9][best] = (
                                ndp[cur + 9][mx][mn][9][best] + val
                            ) % MOD

                            if cur > -9 and streak > -9:
                                ncur = cur - 1

                                nmn = max(mn, -ncur)

                                nstreak = min(-1, streak - 1)
                                nbest = max(best, abs(nstreak))

                                ndp[ncur + 9][mx][nmn][nstreak + 9][nbest] = (
                                    ndp[ncur + 9][mx][nmn][nstreak + 9][nbest]
                                    + val
                                ) % MOD

        dp = ndp

    cnt = [[[0] * 10 for _ in range(10)] for _ in range(10)]

    for cur in range(19):
        for mx in range(10):
            for mn in range(10):
                for streak in range(19):
                    arr = dp[cur][mx][mn][streak]
                    for best in range(10):
                        cnt[mx][mn][best] = (
                            cnt[mx][mn][best] + arr[best]
                        ) % MOD

    ans = 0

    for s in range(10):
        for mx1 in range(10):
            for mx2 in range(10):
                for mn1 in range(10):
                    for mn2 in range(10):

                        if s + mx1 + mx2 >= 10:
                            continue

                        if s - mn1 - mn2 < 0:
                            continue

                        for st1 in range(1, 11):
                            lim = min(10, k // st1)

                            for st2 in range(1, lim + 1):
                                ans = (
                                    ans
                                    + cnt[mx1][mn1][st1 - 1]
                                    * cnt[mx2][mn2][st2 - 1]
                                ) % MOD

    print(ans)

solve()
```DP内部仅存储偏移量`[-9,9]`。 任何离开此间隔的模式都需要比数字所能容纳的范围更大的范围`0..9`，所以这些状态是无关紧要的。 

最小值存储为非负值。 如果步行到达`-4`，我们存储`4`。 这使得索引紧凑并避免负数组索引。 

条纹状态已签名。 正值表示当前连胜包括`+1`移动，负值意味着`-1`移动，零表示最后移动是`0`。 这让我们能够正确地延长或重置条纹。

 ## 边缘情况

 考虑：```
1 1
```一个`1 × 1`网格包含一个数字。 每个数字`0..9`是有效的。 DP 从偏移量开始`0`，没有达到正值或负值，并且恰好产生十个有效班次。 答案是`10`。 

考虑访问正偏移和负偏移的模式：```
0 1 0 -1
```其最大值为`1`其最小值为`-1`。 DP 将其存储为`mx = 1`,`mn = 1`。 有效的起始数字必须满足$$s-1 \ge 0,\qquad s+1 < 10.$$所以只有`s = 1..8`工作。 该算法精确计算这些班次。 

考虑一个长单调序列：```
0 1 2 3 4
```最长的条纹长度是`4`。 使用此模式的任何矩形都可以获得最大可能的行范围。 如果柱状图案也具有最长的条纹长度`3`，那么最大的坏矩形的面积`12`。 条件变为`12 ≤ k`。 DP 仅存储最长的条纹，这正是本次检查所需的数量。
