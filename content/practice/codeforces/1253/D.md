 ## 解决方案
 ## 问题理解

 我们得到一个顶点标记为 1 到 n 的无向图，并且允许我们添加边。 目标是使图满足非常具体的可达性约束，该约束取决于顶点的自然顺序。 

该条件表示，每当顶点 l 可以使用现有边到达顶点 r 时，则其标签严格位于 l 和 r 之间的每个顶点也必须可以从 l 到达。 换句话说，从 l 到 r 的连接不能“跳过”中间标签。 如果 l 可以到达 r，则数值区间 [l, r] 中的所有顶点都必须位于 l 的连通区域内。 

这不是标准的连接要求，因为可达性与节点的顺序相互作用。 允许使用连通分量，但它在数轴上的投影必须表现得像一个连续的区间，否则我们必须添加边来修复“洞”。 

最大 200,000 的约束 n、m 迫使我们远离对节点对或每个查询的朴素 BFS 进行任何二次推理。 任何解决方案都必须接近线性或线性算数。 不相交的集合结构或对排序边的贪婪扫描变得自然，因为我们反复推理有序轴上的连接间隔。 

当组件跨越较宽的数值范围但缺少内部节点时，就会出现微妙的边缘情况。 例如，如果 1 连接到 5，但从 1 无法到达 3，则该图无效并且必须修复，即使在通常意义上存在连通性也是如此。 另一个边缘情况是当多个组件在其数值范围内重叠但实际上并未连接时，这可能会隐藏违规行为，除非我们仔细跟踪可达性。 

## 方法

 一个蛮力的想法是显式检查每对顶点 l 和 r 的条件。 对于每个 l，我们可以运行 DFS 或 BFS 来查找所有可达节点，然后验证对于每个可达 r，所有中间节点也是可达的。 这立即变得昂贵。 每个节点单个 DFS 的复杂度为 O(n + m)，对所有节点执行该操作会导致 O(n(n + m))，这远远超出了限制。 

关键的观察结果是，该条件从根本上讲是关于连接的组件，而不是单独的路径。 如果我们看一个连接的组件，规则要求如果它的最小标签是l并且最大标签是r，那么l和r之间的每个节点必须属于同一个组件。 否则，存在违反条件的间隙。 

这将问题转化为强制每个连通分量在数轴上成为“区间完备”。 如果一个组件从 l 到 r，那么该范围内的所有节点都必须在其中。 如果 [l, r] 中的某个节点在外部，我们必须将其连接进去。 

这建议在按升序扫描节点时对边进行排序或使用 DSU。 我们维护组件并确保每当我们观察到组件范围内的间隙时，我们都会通过添加边缘来合并或“填充”它。 标准解决方案是以递增顺序处理节点，同时保持每个组件的最远可达边界。 每当我们检测到一个节点位于先前看到的组件的跨度内但未连接时，我们必须连接它，增加答案并相应地合并组件。 

DSU 结构有效地维护组件，同时我们跟踪迄今为止遇到的任何组件的最大右端点。 当从左到右扫描时，如果一个节点位于活动区间内但未连接，我们可以有效地桥接它。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力破解（多次 BFS/DFS 检查）| O(n(n + m)) | O(n(n + m)) | O(n + m) | 太慢了|
 | DSU + 贪婪扫描排序结构 | O((n + m) α(n)) | O((n + m) α(n)) | O(n) | 已接受 |

 ## 算法演练

我们以递增的顺序处理节点，并使用不相交的集合并结构来维护连接的组件。 

1. 在所有 n 个节点上初始化 DSU。 这表示给定边的当前连接性。 
2. 迭代从 1 到 n 的节点，将每个节点视为组件的潜在左边界。 我们维护一个指针或边界来跟踪当前组件可到达的最大索引。 最初，这只是节点本身。 
3. 对于每个节点 i，我们使用 DSU 计算其当前连接组件的最右端点。 这告诉我们这个组件在数值上已经延伸了多远。 
4. 我们扫描从 i 到最右边端点的所有节点。 如果我们发现该区间内的节点 j 属于不同的 DSU 组件，则必须连接它。 我们在当前组件的代表和 j 之间添加一条边，增加答案，并将它们合并到 DSU 中。 

这样做的原因是，区间内任何缺失的节点都代表违反了“可达性无间隙”规则。 
5. 每次合并组件时，我们都会重新计算最远的右边界，因为合并可以扩大间隔。 
6. 继续，直到扫描达到稳定，这意味着该间隔中的所有节点都属于同一 DSU 组件。 

### 为什么它有效

 不变量是，处理完一个节点前缀后，与该前缀相交的每个连通分量都形成相对于节点标签的连续区间。 每当我们检测到当前区间内尚未连接的节点时，我们都会显式地合并它，从而消除间隙。 由于我们仅在发现间隙时添加边缘，因此我们添加消除所有不连续性所需的最小数量的边缘。 DSU 确保一旦节点被合并，它们就会始终被视为单个间隔，从而防止冗余或冲突的合并。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))
        self.size = [1] * (n + 1)

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True

def solve():
    n, m = map(int, input().split())
    dsu = DSU(n)

    for _ in range(m):
        u, v = map(int, input().split())
        dsu.union(u, v)

    ans = 0

    i = 1
    while i <= n:
        root = dsu.find(i)
        r = i

        # expand interval of this component
        for j in range(i, n + 1):
            if dsu.find(j) == root:
                r = j

        # fill gaps inside [i, r]
        j = i
        while j <= r:
            if dsu.find(j) != root:
                ans += 1
                dsu.union(root, j)
                root = dsu.find(root)
                r = max(r, j)
            j += 1

        i += 1

    print(ans)

if __name__ == "__main__":
    solve()
```DSU 用于维护与原始边缘的连接。 外循环选择一个起点 i 并通过向前扫描来识别当前组件的跨度。 内部循环检查该跨度内是否有缺失的节点，并在发现间隙时强制进行并集。 每个并集对应于添加一条边，这直接贡献于答案。 

关键的实现细节是，每次并集之后，代表可能会发生变化，因此我们重新计算根并可能延长间隔。 未能正确更新根会导致低估可达性并丢失所需的边。

 ## 边缘情况

 一个关键的边缘情况是连接跨越较大的数字区间但跳过内部节点时。 例如，如果边通过路径连接 1 到 10，但节点 5 是孤立的，则算法将检测到 5 位于区间 [1, 10] 内并强制进行并集。 这可以防止存在可达性但间隔连续性被破坏的静默违规。 

另一个边缘情况是完全断开的图。 在这种情况下，每个节点都会形成自己的组件，扫描将重复检测缺失的覆盖范围并添加边缘以将它们合并为单个间隔状结构。 该算法自然地根据条件的要求构建单个连通区间分量。
