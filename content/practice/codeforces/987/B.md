 ## 解决方案
 ## 问题理解

 给定两个正整数$x$和$y$，我们被要求比较两个指数的值：$x^y$和$y^x$。 任务不是直接计算这些值，因为即使输入适度，它们也可能变得天文数字般大，而是确定哪个值更大或者它们是否相等。 

输入代表两个碱基。 每个基数都计算另一个基数的幂，我们必须决定结果值的顺序。 输出是一个比较符号，指示第一个表达式是否小于、大于或等于第二个表达式。 

约束条件$1 \le x, y \le 10^9$立即排除任何直接的幂计算。 即使对于像这样的小值$x = y = 10^9$，所涉及的数字远远超出了任何数值类型。 任何正确的解决方案都必须避免构建$x^y$或者$y^x$明确地，而是使用代数推理来比较它们。 

出现微妙的边缘情况时，$x = 1$或者$y = 1$。 如果$x = 1$， 然后$x^y = 1$， 尽管$y^x = y$。 这使得比较变得微不足道，除非$y = 1$以及。 当值接近或对数变换中一侧变为零时，尝试使用浮点对数的简单方法也可能会因精度问题而失败。 

另一个极端情况是当$x = y$。 在这种情况下，两个表达式相同，因此答案必须相等。 任何变换方法都必须保持这种精确的对称性。 

## 方法

 强力解释将直接计算两个幂，但甚至存储中间结果也是不可能的。 每次求幂涉及将数字乘以$10^9$倍，因此运行时间随着输入大小呈指数增长，并且完全不可行。 

关键的观察是避免计算指数，而是比较它们的对数。 由于对数函数是严格递增的，我们可以比较：$$x^y \quad \text{and} \quad y^x$$通过比较：$$y \cdot \ln x \quad \text{and} \quad x \cdot \ln y$$这种转换将问题简化为每个测试用例的恒定时间算术运算。 然而，当值非常接近时，浮点比较可能会带来不稳定。 更稳健的方法通过单独处理结构情况来完全避免浮点。 

我们分析一下函数$f(x) = \frac{\ln x}{x}$。 比较$x^y$与$y^x$相当于比较$\frac{\ln x}{x}$和$\frac{\ln y}{y}$。 该函数减少了$x \ge 3$，特殊小案例位于$1$和$2$。 这种单调性结构允许进行干净的基于案例的比较。 

对于较大的值，排序主要取决于其中一个数字是否是$1$或者$2$，因为这些打破了单调的模式。 

边缘推理产生完整的规则：

 如果$x = y$，答案是平等。 

如果$x = 1$，它总是较小，除非$y = 1$。 

如果$y = 1$，它总是更大，除非$x = 1$。 

如果两者都不是$1$，使用已知的排序进行比较：$2^3 = 8$和$3^2 = 9$给出$2^3 < 3^2$，同时对于$x, y \ge 3$，函数$\ln x / x$正在减少，因此较大的基数在特定方向上占主导地位。 

这导致无需浮点运算的直接比较逻辑。

 ## 算法演练

 1. 读取整数$x$和$y$。 比较是对称的，因此交换参数不应改变正确性。 
2.如果$x = y$，立即输出 '='，因为两个表达式相同。 
3.如果$x = 1$, 输出 '<' 除非$y = 1$。 这是从$1^y = 1$和$y^1 = y$。 
4.如果$y = 1$，输出 '>' 因为$x^1 = x$和$1^x = 1$， 和$x \ge 1$。 
5. 对于所有剩余的情况，比较$x$和$y$。 如果$x > y$，输出'>'，否则输出'<'。 

最后一步有效，因为对于大于 1 的整数，该函数$x^y$指数中的增长速度比基数中的增长速度更快，并且在变换下保留了这种顺序$x^y \leftrightarrow y^x$，除前面处理过的特殊情况外。 

### 为什么它有效

 比较简化为按函数排序$g(x) = \frac{\ln x}{x}$，这是严格递减的$x \ge 3$。 因此，对于所有足够大的值，之间的不等式$x^y$和$y^x$仅取决于是否$g(x)$大于$g(y)$。 唯一违反单调性的情况发生在$x = 1$和$x = 2$，这是明确处理的。 这保证了总排序的一致性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

x, y = map(int, input().split())

if x == y:
    print("=")
elif x == 1:
    print("<")
elif y == 1:
    print(">")
else:
    if x > y:
        print(">")
    else:
        print("<")
```该实现反映了结构案例分析。 首先进行相等性检查，以避免将相同的输入错误地分类为特殊情况。 处理$x = 1$和$y = 1$接下来隔离了求幂塌陷为常数值的唯一情况。 最终的比较使用简单的整数排序，这是安全的，因为所有病理情况都已被删除。 

不使用浮点运算，防止精度误差，保证极值下的正确性。

 ## 边缘情况

 对于输入$1, 1$，算法立即进行相等性检查并返回“=”，而不输入任何特殊情况逻辑，匹配两个表达式都等于 1 的事实。 

对于$1, y$与大$y$, 支票`x == 1`触发并输出 '<'，正确反映$1^y = 1 < y = y^1$。 相反的情况$x, 1$触发对称分支并输出“>”，匹配$x^1 = x > 1$。
