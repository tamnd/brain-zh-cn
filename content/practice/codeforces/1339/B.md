 ## 解决方案
 ## 问题理解

 我们给定了几个独立的数组，对于每个数组，我们必须将其元素重新排序为一个序列，其中相邻元素之间的绝对差异随着我们从左向右移动而永远不会减少。 换句话说，一旦我们开始将数字排成一行，连续数字之间的间隙应该形成一个非递减的序列。 

输出并不是要保留任何原始结构。 我们可以随意排列数组，并且只需要生成一个有效的排序来满足相邻差异的单调性条件。 

所有测试用例的总输入大小的限制意味着每个测试用例超过线性或接近线性的任何解决方案都将失败。 尝试所有排列或重复检查所有交换对的天真尝试将导致组合或二次爆炸。 预期的解决方案必须在每个测试用例的 O(n log n) 或 O(n) 时间内处理每个数组。 

当从局部结构贪婪地思考时，会出现一种微妙的故障模式。 如果我们尝试通过重复将最接近的可用数字附加到最后选择的元素来构建序列，我们很容易陷入这样的配置：早期的小差异迫使后来的大跳跃破坏单调性。 例如，从中间值开始并贪婪地向外扩展可以在稍后留下更接近的未使用元素时产生减小的间隙。 这说明局部贪婪邻接是不可靠的； 该结构必须在全球范围内强制执行。 

## 方法

 暴力方法将尝试数组的所有排列，并检查候选排序是否满足非递减相邻差异属性。 即使检查单个排列也会花费 O(n)，而且有 n 个！ 排列，使得即使 n 约为 10 时也完全不可行。 

第二个天真的想法是生成一个序列并在维持条件的位置重复插入元素。 然而，每次插入可能需要扫描整个序列以验证差异的单调性，并且不能保证早期的决策不会使未来的插入无效。 这会导致每个测试用例的 O(n²) 或更糟糕的行为。 

关键的观察是，我们实际上并没有试图独立控制差异的值。 相反，我们可以通过从中值向外构建序列来强制形成非常结构化的差异模式。 如果我们对数组进行排序，彼此接近的值自然会产生较小的差异，而相距较远的值会产生较大的差异。 如果我们从中心向外交错元素，我们可以确保早期差异很小，而随着远离中间区域，后期差异会增大。 

标准的构造是对数组进行排序，选择一个中心元素作为起点，然后交替扩展到排序顺序的右侧和左侧。 这会产生一个序列，我们首先在围绕中位数的紧密簇内移动，然后才引入极值，这保证了绝对差异不会减少。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n) | 太慢了|
 | 最佳 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

1. 对数组进行非降序排序。 这会组织值，以便索引中的接近度对应于值中的接近度。 差异结构将由指数走势控制。 
2. 选择靠近排序数组中心的起点。 一个方便的选择是中间索引，因为它可以最小化到两个极端的初始距离。 
3. 通过从此中心向外扩展来构建结果序列，在排序数组中左右方向交替。 这创造了对不断增加的价值差距的平衡探索。 
4. 按照访问顺序将每个选定元素附加到结果中。 前几步保持在狭窄的数字区域内，因此差异仍然很小。 
5. 继续，直到使用所有元素，确保按排序顺序远离中心的元素仅在序列中稍后引入。 

### 为什么它有效

 该结构保证早期相邻差异来自排序顺序接近的元素，因此绝对值较小。 随着遍历向外扩展，每个新引入的元素按排序顺序都距离前一个区域更远，这只能维持或增加间隙大小。 由于我们在向外移动后永远不会回到之前跳过的极端，因此我们避免在较大的差异之后引入较小的差异，这强制了所需的单调性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()

        l = (n - 1) // 2
        r = l + 1

        res = [a[l]]
        toggle = True

        while l > 0 or r < n:
            if toggle:
                if r < n:
                    res.append(a[r])
                    r += 1
                else:
                    l -= 1
                    res.append(a[l])
            else:
                if l > 0:
                    l -= 1
                    res.append(a[l])
                else:
                    res.append(a[r])
                    r += 1
            toggle = not toggle

        print(*res)

if __name__ == "__main__":
    solve()
```该代码首先对每个测试用例数组进行排序，以便数值上的接近性变成结构上的邻接性。 然后它选择一个中心索引并以交替方向向外扩展。 交替的指针移动确保我们永远不会重复从同一极端拉取值，这可能会在大跳跃后产生微小差异。 

关键的实现细节是当任一指针到达数组末尾时仔细处理边界。 此时，算法仅在剩余方向上继续。 

## 工作示例

 ### 示例 1

 输入数组：`[5, -2, 4, 8, 6, 5]`排序后的数组变为：`[-2, 4, 5, 5, 6, 8]`我们从中间附近的索引 2 或 3（0 索引）开始。 以索引 2 为中心：

 | 步骤| 左索引 | 右索引 | 选择| 结果 |
 | ---| ---| ---| ---| ---|
 | 1 | 2 | 3 | 5 | [5]|
 | 2 | 2 | 4 | 5 | [5, 5] |
 | 3 | 1 | 4 | 4 | [5,5,4]|
 | 4 | 1 | 5 | 6 | [5,5,4,6]|
 | 5 | 0 | 5 | -2 | [5, 5, 4, 6, -2] |
 | 6 | 0 | 6（完）| 8 | [5, 5, 4, 6, -2, 8] |

 差异为 0、1、2、8、10，均为非递减。 

该迹线显示了如何在密集的中间区域内首先创建小的局部差异，而极值仅在稍后出现，从而产生更大的跳跃。 

### 示例 2

 输入数组：`[8, 1, 4, 2]`排序数组：`[1, 2, 4, 8]`从索引 1（值 2）开始：

 | 步骤| 左索引 | 右索引 | 选择| 结果 |
 | ---| ---| ---| ---| ---|
 | 1 | 1 | 2 | 2 | [2] |
 | 2 | 1 | 3 | 4 | [2, 4] |
 | 3 | 0 | 3 | 1 | [2,4,1]|
 | 4 | 0 | 4（完）| 8 | [2, 4, 1, 8] |

 差异为 2, 3, 3，仍然不减少。 

这个例子演示了交替如何确保我们不会立即在极端之间跳跃，而是从中心逐渐向外扩展。
