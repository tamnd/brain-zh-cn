 ## 解决方案
 ## 问题理解

 詹有很多水果，他想使用具有两个约束的搅拌机尽快混合所有水果。 每一秒，他最多可以将固定数量的水果放入搅拌机中，而搅拌机每秒可以处理的水果数量也是最大的。 搅拌机内已有的任何水果都会被加工至搅拌机的极限，其余的则保留下一秒。 输入给出了水果的数量、搅拌机每秒的容量以及 Zhan 每秒可以喂入的水果数量。 输出是完成混合所有水果所需的最短秒数。 

约束条件很大：最多$10^9$每秒的水果和操作。 这意味着我们无法模拟每一秒或迭代单个水果； 该解决方案必须通过简单的算术运算来计算所需的时间。 

边缘情况包括当 Zhan 添加的水果多于搅拌机在一秒钟内可以处理的水果时、当搅拌机容量超过 Zhan 可以添加的水果时以及当与限制相比水果很少时。 例如，如果只有一种水果，并且 x 和 y 都很大，则答案为 1。粗心的解决方案可能会多算或少算，因为它们混合了搅拌机容量和插入率，而没有正确考虑它们之间的最小值。 

## 方法

 暴力方法会模拟每一秒，总计为$y$将水果放入搅拌机中，然后搅拌$\min(x, c)$水果。 虽然正确，但这需要迭代最多$n$水果，这是不可能的$n$最多$10^9$。 

关键的观察结果是，所需的秒数取决于两个速率中较快的一个：搅拌机的容量$x$和插入率$y$。 每一秒，有效加工的水果数量是可以放入和取出的最大数量。 这将问题简化为使用上限的简单算术计算$n$除以最大值$x$和$y$，同时还处理混合器和 Zhan 都无法在一步中保持系统完全饱和的情况。 通过考虑较大的$x$和$y$，我们可以计算出常数时间内需要的秒数。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| O(n) | O(1) | O(1) | 太慢了|
 | 算术计算| 每次测试 O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，读取水果的数量$n$, 搅拌机容量$x$，和插入限制$y$。 
2.如果$n$为零，答案是零秒，因为没有什么可以混合。 
3. 确定两个比率中较大的一个，$max\_rate = \max(x, y)$。 这代表了我们每秒可以有效处理的最大水果数量，因为放入的水果数量超过搅拌机的处理能力就会被浪费，而较小的搅拌机容量会限制有效吞吐量。 
4. 计算最小秒数为$\lceil n / max\_rate \rceil$。 使用整数运算，这是$(n + max\_rate - 1) // max\_rate$。 此公式可确保任何不完整的秒都算作完整的秒。 
5. 输出计算出的秒数。 

正确性来自于以下不变量：我们每秒处理尽可能多的水果（在较快的速度允许的情况下），并且任何剩余的水果都会在下一秒进行计数。 天花板确保没有未经加工的水果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        x, y = map(int, input().split())
        
        if n == 0:
            print(0)
            continue
        
        max_rate = max(x, y)
        seconds = (n + max_rate - 1) // max_rate
        print(seconds)

if __name__ == "__main__":
    solve()
```该代码读取测试用例的数量并依次处理每个测试用例。 我们使用快速 I/O 和整数算术来有效地处理大输入。 公式`(n + max_rate - 1) // max_rate`正确处理向上舍入到最接近的整数。 特殊情况如`n=0`明确处理以避免分裂问题。 

## 工作示例

 样品输入：5个水果，搅拌机可加工3个，詹可添加4个。 

| 步骤| 剩余水果 | 行动| 混合|
 | --- | --- | --- | --- |
 | 1 | 5 | 插入 min(4,5)=4 | min(3,4)=3 混合，剩余 1 |
 | 2 | 1 | 插入 min(4,1)=1 | min(3,2)=2 混合，剩余 0 |

 秒：2

 又如：100个水果，搅拌机容量4，詹加3。`max_rate = max(4,3)=4`→ 秒 = (100 + 4 - 1) // 4 = 103 // 4 = 25。这可以正确计算上限除法。

 ## 边缘情况

 对于`n=0`，搅拌机不执行任何操作。 该公式仍然有效，但显式检查返回 0 秒以避免不必要的计算。 为了`n`比两者都小`x`和`y`，该公式产生 1 秒，这是正确的。 对于非常大的`n`，整数运算避免了浮点错误并确保精确的上限除法。 部分最后一秒混合正确计算`+ max_rate - 1`诡计。
