 ## 解决方案
 ## 问题理解

 我们看到一群人在排队等候购买电影票。 每人持有面额为25、50或100卢布的钞票，每张门票为25卢布。 售票员一开始没有钱，必须按照排队的确切顺序出售门票，并在必要时提供正确的零钱。 任务是确定店员能否成功地为每个人服务。 

输入提供人数$n$以及代表每个人持有的账单的整数序列。 如果每个人都可以用正确的零钱购买车票，则输出为“YES”，否则输出为“NO”。 

和$n$最多$10^5$和 2 秒限制，我们需要一个线性或接近线性的解决方案。 任何反复搜索当前持有现金的方法都会面临风险$O(n^2)$复杂性，可能会超出时间限制。 

不明显的边缘情况包括大额钞票过早出现而没有足够的小额钞票来提供找零的序列。 例如，如果该行是`[50, 25]`，店员不能给第一个人找零，因为他一开始就没有钱。 另一个棘手的情况是`[25, 25, 50, 100]`相对`[25, 50, 25, 100]`，在找 100 卢布纸币时需要小心处理可用的纸币。 

## 方法

 暴力方法会模拟队列，并为每个人尝试所有可用账单的组合以提供准确的零钱。 对于 100 卢布的钞票，这可能涉及检查之前收集的 25 卢布和 50 卢布的多个子集。 虽然原则上是正确的，但最坏情况的复杂性会迅速增长：对于每个$n$人，最多$O(n)$可能需要进行操作才能发现变化，给出$O(n^2)$。 为了$n = 10^5$，这太慢了。 

关键的观察结果是，我们永远不需要存储所有账单，只需要存储 25 和 50 的账单。 50 卢布的纸币总是需要一张 25 的零钱，而 100 卢布的纸币则需要一张 50 和一张 25，或者三张 25。 这将问题简化为贪婪策略：始终使用尽可能大的钞票来找零。 这是有效的，因为较小的账单无法以更便宜的组合替代较大的账单，因此优先考虑较大的账单永远不会阻碍有效的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化两个计数器：`c25`25 卢布纸币和`c50`50卢布的钞票。 两者都从零开始。 这些记录可以跟踪店员在任何时刻有多少张账单。 
2. 遍历队列中的每个人，检查他们持有的账单。 
3. 如果此人有 25 卢布的钞票，则增加`c25`减一，因为不需要改变。 这增加了店员用于未来交易的可用现金。 
4. 如果此人有 50 卢布的钞票，请检查是否`c25`至少为一。 如果是，则递减`c25`加一并递增`c50`一个。 如果没有，店员无法找零，因此输出“NO”并终止。 
5. 如果此人有 100 卢布的钞票，请首先尝试使用一张 50 卢布和一张 25 卢布找零，因为这样使用的 25 卢布较少。 如果`c50 >= 1`和`c25 >= 1`，相应地减少两者。 否则，检查是否`c25 >= 3`给三个25作为零钱。 如果这两个选项都不可能，则输出“NO”并终止。 
6. 如果循环完成且没有失败，则输出“YES”。 

工作原理：在每一步中，25 和 50 卢布钞票的计数都可以完全捕捉到店员的状态。 通过始终使用尽可能大的钞票进行找零，我们永远不会阻止未来的交易。 不变的是，店员的现金组合总是允许所有先前的交易，并且如果贪婪的选择失败，则没有其他组合可以成功。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
bills = list(map(int, input().split()))

c25 = 0
c50 = 0

for bill in bills:
    if bill == 25:
        c25 += 1
    elif bill == 50:
        if c25 == 0:
            print("NO")
            sys.exit(0)
        c25 -= 1
        c50 += 1
    else:  # bill == 100
        if c50 >= 1 and c25 >= 1:
            c50 -= 1
            c25 -= 1
        elif c25 >= 3:
            c25 -= 3
        else:
            print("NO")
            sys.exit(0)

print("YES")
```该代码准确地反映了算法步骤。 初始化计数器可确保我们随时了解店员的资源。 100 卢布纸币的贪婪选择是明确的，优先使用 50 卢布纸币，以尽量减少 25 卢布纸币的消耗。 使用`sys.exit(0)`当无法提供变更时允许立即终止。
