 ## 解决方案
 # 问题理解

 该问题描述了一系列电影。 每部电影都有发行年份、导演姓名和评级。 我们需要通过选择一些电影并按时间顺序排列它们来构建尽可能长的电影马拉松。 

有效的马拉松比赛有三个限制。 上映年份不能减少，评分必须严格从一部电影到下一部电影，连续两部电影不能由同一位导演担任。 任务是找到在这样的序列中可以出现的最大电影数量。 

输入给出电影数量，后跟每部电影的数据。 输出是表示最大有效马拉松长度的单个整数。 

电影的数量最多为 3000。这立即排除了尝试每个子集的算法，因为可能的子集的数量呈指数增长。 具有二次转换次数的动态规划解决方案是现实的，因为$3000^2 = 9 \times 10^6$，对于编译语言来说足够小，并且在Python中仍然可以接受，操作简单。 

棘手的部分不是输入的大小，而是正确处理排序规则。 一个常见的错误是仅按年份排序并假设每部较早的电影都可以是前作。 评分条件严格，评分相同或更低的电影无法延续马拉松。 

考虑这些情况：```
3
2000 A 50
2001 A 60
2002 B 70
```正确的输出是：```
2
```粗心的解决方案可能会选择全部三部电影，因为年数会增加，但前两部电影是同一导演并且连续出现，这是被禁止的。 

另一个例子：```
3
2000 A 50
2001 B 50
2002 C 60
```正确的输出是：```
2
```前两部电影不能连续，因为它们的收视率相同。 使用非递减评级而不是严格递增评级的解决方案将错误地返回 3。 

最后的边界情况是没有电影可以跟随另一部电影：```
2
2000 A 90
2001 B 80
```正确的输出是：```
1
```每部电影都已经是长度为一的有效马拉松，因此答案永远不会为零。 

# 方法

 直接的做法是尝试每一种可能的电影排序，检查是否满足条件。 这是正确的，因为每一个可能的马拉松最终都会被考虑。 然而，单独可能的子集的数量是$2^N$，并与$N=3000$这是不可能的。 

更合理的暴力想法是按年份对电影进行排序并使用动态编程转换。 即便如此，对所有选择的简单递归搜索仍然会探索太多分支，因为许多不同的选择会导致相同的剩余状态。 

关键的观察结果是，在按时间对电影进行排序后，有关部分马拉松所需的唯一信息是最后选择的电影。 如果我们知道上一部电影，我们就知道当前的年份、评级和导演，这些正是决定是否可以附加另一部电影所需的值。 

让`dp[i]`代表以电影结束的最长有效马拉松`i`。 对于之前的每一部电影`j`，我们检查是否`j`可以紧接在之前`i`。 如果那一年`j`不大于年份`i`，评级为`j`小于额定值`i`，并且董事们意见不同，那么`dp[i]`可以更新自`dp[j]`。 

排序步骤使转换变得简单。 我们按年份排序，然后进行评级。 排序后，列表中每个可能的前任都出现在其后继者之前，因为后任者必须具有至少同样大的年份和更大的评级。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 |$O(2^N)$|$O(N)$| 太慢了 |
 | 排序后的动态规划 |$O(N^2)$|$O(N)$| 已接受 |

 # 算法演练

 1. 读取所有电影并将每部电影存储为包含年份、导演和评级的元组。 首先按年份对电影进行排序，然后按评级排序。 

排序顺序创建了一个时间线，其中有效的前一部电影只能出现在当前电影之前。 同一年内的评级排序还可以防止因评级相同或较小而导致的不可能的转换。 

1. 创建数组`dp`在哪里`dp[i]`从 1 开始，因为每部电影本身都可以构成一场马拉松。 

此初始化处理电影之前不能放置其他电影的情况。 

1. 对于每部电影`i`，检查每一部早期的电影`j`。 

电影`j`可以延长结束于`j`如果它的年份不在之后`i`，其评级小于`i`的评价，以及导演的不同。 

1. 当存在有效转换时，更新：$$dp[i] = \max(dp[i], dp[j] + 1)$$这部新电影是在已经结束的最佳马拉松比赛之后添加的`j`。 

1.答案是最大值`dp`。 

最长的马拉松可能会在任何电影中结束，因此我们不能只检查排序后的最后一个元素。 

## 为什么它有效

 动态规划数组的不变量是`dp[i]`总是存储最好的马拉松，其最终电影正是电影`i`。 

在考虑电影时`i`，每个可能的先前电影都出现在较早的索引中。 如果之前的电影可以合法连接到`i`，过渡考虑到那里结束的最佳马拉松并将其延长一。 由于检查了所有可能的最终前任，因此没有有效的马拉松结束于`i`被错过了。 对所有结局取最大值即可得到全局最优值。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    movies = []

    for _ in range(n):
        y, director, p = input().split()
        movies.append((int(y), int(p), director))

    movies.sort()

    dp = [1] * n
    ans = 1

    for i in range(n):
        year_i, score_i, director_i = movies[i]

        for j in range(i):
            year_j, score_j, director_j = movies[j]

            if year_j <= year_i and score_j < score_i and director_j != director_i:
                dp[i] = max(dp[i], dp[j] + 1)

        ans = max(ans, dp[i])

    print(ans)

if __name__ == "__main__":
    solve()
```输入被转换为包含年份和分数的数值的元组，因此比较是直接的。 导演仍然是一个字符串，因为只需要相等性检查。 

排序用途`(year, score, director)`订购。 导演仅作为最终的决胜局，不会影响正确性，因为转换仍然明确检查所有三个马拉松条件。 

嵌套循环实现动态编程转换。 条件`score_j < score_i`之所以严格，是因为收视率必须提高。 导演条件禁止同一导演连续拍摄电影。 

不需要特殊的整数处理，因为答案最多为 3000。

 # 边缘情况

 对于同一董事的情况：```
3
2000 A 50
2001 A 60
2002 B 70
```该算法按时间顺序对电影进行排序。 在处理第二部电影时，它发现第一部电影具有有效的年份和评级关系，但导演相同，因此转换被拒绝。 第三部电影可以延长任一单电影马拉松，答案为 2。 

对于同等评级：```
3
2000 A 50
2001 B 50
2002 C 60
```前两部电影无法连接，因为分数没有增加。 最后一部电影可以在任一电影之后，因为 50 小于 60。算法返回 2。 

对于每次转换都失败的情况：```
2
2000 A 90
2001 B 80
```第二部电影的年份较晚，但收视率较低，因此无法延续第一部电影。 两个都`dp`值仍为 1，答案为 1。
