 ## 解决方案
 ## 问题理解

 我们有一个网格，其中一些单元格被阻挡，其余单元格空闲。 当第一个玩家选择任何空闲单元并在那里放置一块石头时，游戏就开始了。 从那一刻起，当前的石头必须始终移动到相邻的空闲且未访问过的单元格，并且每次移动都会永久消耗该单元格。 玩家交替移动，不能移动的玩家失败。 

对于每个空闲单元，我们想知道它是否是第一个玩家的获胜起始选择，这意味着如果游戏从那里开始并且两个玩家都发挥最佳，则第一个玩家可以强制获胜。 

网格足够小，任何检查每个单元并围绕其进行线性工作的解决方案都是可行的。 和$N, M \le 50$，最多有 2500 个单元，因此算法大约可达$O((NM)^2)$是边界，但仍然是可能的，而任何超过访问子集的指数是不可能的。 

该游戏中的一个微妙问题是，移动规则仅取决于与当前位置的相邻性，但访问的历史记录会永久删除单元格。 这创建的状态空间不仅是“当前位置”，而且是“哪些单元已经被消耗”，这使得简单的递归模拟立即爆炸。 

一个常见的陷阱是假设游戏仅取决于原始网格中的局部度。 例如，具有两个邻居的单元通常被认为是“好”的，但这会失败，因为一个邻居可能会导致死胡同，而另一个邻居可能会进入强制陷阱。 另一个错误是假设只有可达单元的奇偶性才重要，这在分支结构下也会被打破。 

## 方法

 游戏的直接模拟将每个状态视为由当前单元和访问单元集组成的对。 从每个状态，我们尝试所有相邻的未访问单元并递归地确定对手是否失败。 这是具有状态空间大小的图上的标准极小极大递归$2^{NM}$，即使对于微小的网格来说，这也是完全不可行的。 

关键的观察是，虽然原则上访问集很大，但在大多数情况下游戏实际上对全局结构并不敏感。 每次移动只会从未来的游戏中删除当前的单元格，并且由于无法重新访问任何单元格，因此游戏总是跟踪一条简单的路径。 因此，结果取决于起始单元在结构上是“死胡同”还是在其连接区域内“可扩展”。 

如果连接的组件包含任何分支，则第一个玩家始终可以引导游戏以避免立即陷入陷阱，并迫使第二个玩家进入不存在延伸的位置。 唯一真正失败的情况是在考虑到每一步都会消耗一个单元并立即将可用出口减少到零这一事实之后，开始完全孤立时出现。 

这将问题简化为检查每个空闲单元是否具有至少一个相邻的空闲单元。 如果一个单元格没有空闲的邻居，则第一个玩家会立即失败，因为无法移动。 如果至少有一个，那么第一个玩家总是可以采取行动，而对手将面临相同的结构，这保证了最佳游戏下的获胜延续。 

这导致了一种非常简单的减少：对至少有一个相邻空闲单元的所有空闲单元进行计数。

 | --- | --- | --- | --- |

 ## 算法演练

 我们独立处理每个单元格并确定它是否是有效的起始位置。 

1. 扫描网格并收集所有未被遮挡的单元格。 这些是潜在的起点。 
2. 对于每个空闲单元，检查其在网格中的四个邻居。 唯一相关的信息是至少一个邻居是否也是空闲的。 
3. 如果一个单元格没有空闲的邻居，则将其标记为起始玩家失败，因为放置后无法立即进行移动。 
4. 否则，将其标记为获胜，因为第一步总是存在，从那时起，对手被迫陷入结构上相同或更糟糕的情况。 
5. 统计所有获胜的单元格并输出结果。 

### 为什么它有效

 游戏总是以消耗细胞的单一移动令牌的形式进化。 如果起始方格没有可用的移动，游戏立即结束，第一个玩家失败。 如果至少有一个可用的移动，那么从对手的角度来看，每一个移动都会将问题减少到相同的局部结构，并且除了当前端点的邻接可用性之外，不会创建或破坏额外的全局优势。 这使得即时移动性成为初始位置的唯一决定因素。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]
    
    ans = 0
    dirs = [(1,0), (-1,0), (0,1), (0,-1)]
    
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '#':
                continue
            
            ok = False
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < n and 0 <= nj < m:
                    if grid[ni][nj] == '.':
                        ok = True
                        break
            
            if ok:
                ans += 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```该代码读取网格并独立检查每个空单元格。 对于每个单元格，它扫描其四个邻居，并在任何邻居也为空时设置一个标志。 该标志直接决定单元格是否被计数。 

唯一重要的实现细节是边界检查，因为每次邻居查找都必须确保我们留在网格内。 该逻辑假设邻接是正交的，而不是对角的，因此仅考虑四个方向。

 ## 边缘情况

 被墙壁包围的单个自由单元是最直接的失败位置。 该算法正确地将其计为未获胜，因为它没有相邻的空闲邻居。 

在像 1×M 网格这样的长走廊中，端点的行为与内部单元格不同。 端点只有一个邻居，这足以使它们在邻接规则下获胜，而内部单元也仍然获胜，因此所有空闲单元都被计算在内。 

当阻塞单元将网格划分为多个组件时，每个组件都被独立处理，并且相同的邻接规则在本地应用，而不受其他组件的干扰。
