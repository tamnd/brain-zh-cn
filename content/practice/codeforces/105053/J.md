 ## 解决方案
 ## 问题理解

 每种资源都有两种相互竞争的生产技术，每个村庄使用一种技术。 对于资源$i$, 阿波连卡花费$A_i$每单位人时，而布德尔斯多夫花费$B_i$。 每个村庄最初每种资源生产固定数量的单位，$U_i$和$W_i$分别，所以资源总产出$i$固定在$T_i = U_i + W_i$。 

关键的自由度是这个最终总数$T_i$不需要像最初给出的那样进行拆分。 村庄可以在它们之间任意重新分配生产，同时保持每种资源的总产量不变。 改变的只是谁生产了多少。 

如果 Apolyanka 产生$x_i$资源单位$i$，然后 Büddelsdorf 产生$T_i - x_i$，总成本变为$$\sum_i (A_i x_i + B_i (T_i - x_i)).$$我们想要选择$x_i$来最小化这个总成本。 

约束允许最多$10^5$资源，因此任何解决方案都必须是线性或近线性的$N$。 任何平方项$N$或者涉及大范围内的重排序嵌套结构是可以接受的，但是任何试图枚举全局分布或执行每单元模拟的操作都会立即变得太慢。 

天真的想法的一个微妙的失败案例是假设每个村庄独立优化生产。 这将忽略一种资源在村庄之间转移生产会线性且独立地改变每种资源的成本，因此耦合永远不存在。 另一个陷阱是将问题解释为需要整数分配； 明确允许分数分配，因此解决方案是持续优化而不是组合分配。 

## 方法

 直接公式分配一个变量$x_i$资源单位$i$到阿波连卡。 资源成本贡献$i$是$$A_i x_i + B_i (T_i - x_i) = B_i T_i + (A_i - B_i)x_i.$$第一学期$B_i T_i$是恒定的。 唯一的决定是线性项$(A_i - B_i)x_i$， 在哪里$x_i \in [0, T_i]$。 

对于每个资源，我们独立地最小化一个区间内的线性函数。 如果$A_i > B_i$，系数为正，因此增加$x_i$增加成本，这意味着我们应该设置$x_i = 0$。 如果$A_i < B_i$，系数为负，所以我们最大化$x_i$， 意义$x_i = T_i$。 如果它们相等，则任何分割都有效。 

这完全解决了问题：每种资源都是根据哪个村庄更有效率来独立决定的。 

蛮力解释将尝试每个资源的所有可能的分割，但由于每个$x_i$连续于$[0, T_i]$，那已经是无穷大了。 即使离散化，它也会组合爆炸：$O(\prod T_i)$，这是不可能的。 

关键的观察是可分离性：总成本是每个独立线性函数的总和$x_i$。 不同资源之间的耦合没有约束，因此每个资源都可以单独优化。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（尝试分配）| 指数| O(1) | O(1) | 太慢了|
 | 最优（每个资源贪婪）| O(N) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取所有值$A_i, B_i, U_i, W_i$。 计算$T_i = U_i + W_i$。 这固定了每种资源的总产量，这是唯一的全局约束。 
2. 初始化累加器`answer = 0`。 这将收集最小的总成本。 
3. 对于每种资源$i$，计算 Büddelsdorf 生产所有产品的基准成本：$$base_i = B_i \cdot T_i.$$4. 计算如果我们将一个单位的生产从 Büddelsdorf 转移到 Apolyanka 的成本差异：$$delta_i = A_i - B_i.$$5. 决定分配：

 如果$delta_i < 0$，将生产转移到 Apolyanka 可以降低成本，因此我们从 Apolyanka 获取所有生产，贡献$A_i \cdot T_i$。 

如果$delta_i \ge 0$, Büddelsdorf 没有更差或更好，所以我们将一切保留在 Büddelsdorf 身上，做出贡献$B_i \cdot T_i$。 
6. 将所选贡献添加到总答案中。 

每个资源都是独立处理的，因为成本函数分解为每个资源线性函数的总和，因此跨资源调整无法改善结果。 

### 为什么它有效

 总成本是函数的总和$f_i(x_i) = B_i T_i + (A_i - B_i)x_i$，每个都定义在单独的间隔上。 由于不同的连接之间没有任何约束$x_i$，可行区域是独立区间的乘积。 凸区间上的线性函数在端点处达到最小值，因此每个$x_i$必须是$0$或者$T_i$。 的标志$A_i - B_i$确定哪个端点是最佳的，确保局部决策的全局最优性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    ans = 0.0

    for _ in range(n):
        a, u, b, w = map(int, input().split())
        t = u + w

        if a < b:
            ans += a * t
        else:
            ans += b * t

    print(f"{ans:.10f}")

if __name__ == "__main__":
    main()
```该代码直接实现每个资源的端点决策。 重要的实现细节是避免构建任何中间的每单位生产表示，因为$T_i$可以很大并且分数推理是隐含的。 使用浮点累加是安全的，因为最终答案符合所需的精度，并且所有运算都是整数的线性组合。 

分支条件`a < b`编码线性成本函数的导数测试。 平等自然属于任一分支，而不影响正确性。

 ## 边缘情况

 一个极端的情况是，两个村庄对于资源的效率相同，$A_i = B_i$。 例如，输入`1 5 1 5`给出$T=10$。 任一分配都会产生成本 50，并且算法始终将其分配给 Büddelsdorf，因为`else`分支，保持正确性。 

另一种情况是极端不对称，例如$A_i \ll B_i$。 为了`1 1000 1000 1`，我们有$T=1001$。 该算法将所有内容分配给 Apolyanka，产生成本$1001$，而涉及 Büddelsdorf 的任何拆分都会增加成本，因为其单位费用较高。 

最后一种情况是，某个村庄在所有资源方面总是较差。 该算法自然会完全忽略该村庄，将系统折叠为单生产者模型，该模型与独立线性最小化导出的最优解结构相匹配。
