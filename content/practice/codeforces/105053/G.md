 ## 解决方案
 ## 问题理解

 我们从位于标记为 1 的槽上的单个指针开始，然后根据当前槽重复执行随机转换。 在每一步中，我们都会采样一​​个值$y$从$1$到$N$具有给定的加权概率。 从当前位置$x$，我们计算一个新位置$z = \mathrm{lcm}(x, y)$。 如果这个值超过$N$，过程停止。 否则，我们将令牌移动到插槽$z$并赚取一枚硬币，然后重复相同的过程。 

任务是计算进程终止之前预期赚取的硬币总数。 

约束条件允许$N$最多$10^5$，这立即排除了任何逐步模拟过程或尝试在朴素状态空间中显式建模所有可能路径的解决方案。 尽管该过程是概率性的，但给定采样的结构是确定性的$y$，因此挑战在于汇总对类似图形的状态系统的期望，而不是枚举序列。 

一个微妙的点是状态空间不是任意整数$1$到$N$，但仅限于那些通过从 1 开始的重复 LCM 操作可到达的值。另一个隐藏的细节是，转换总是产生可划分或与先前看到的结构一致的值，这意味着我们有效地在受$N$。 

一个幼稚的错误是将转换视为独立的或假设每个$x$可以过渡到每个$z \le N$。 例如，如果$N=6$， 从$x=2$和$y=3$，我们转到 6，但是在 LCM 转换下根本无法从 1 达到 5。 忽略此结构会导致错误的概率聚合。 

另一个陷阱是忘记转变可能在除数晶格中形成循环。 例如，与$x=1$，我们可以去任何$y$，但是从像 6 这样的复合状态，只有特定的 LCM 结果是可能的，并且这些限制对于正确的期望传播至关重要。 

## 方法

 蛮力观点是定义一个函数$E(x)$作为从插槽开始的预期硬币数量$x$。 来自州$x$，我们迭代所有可能的值$y$, 计算$z = \mathrm{lcm}(x,y)$，如果$z \le N$，我们贡献$1 + E(z)$，否则我们贡献 0。这给出了直接递归：$$E(x) = \sum_{y=1}^{N} p(y)\cdot
\begin{cases}
1 + E(\mathrm{lcm}(x,y)), & \mathrm{lcm}(x,y)\le N \\
0, & \text{otherwise}
\end{cases}$$这个公式是正确的，但立即就会出现问题，因为计算$E(x)$独立地导致递归依赖关系$10^5$州，并且每个州都会尝试所有$y$，导致$O(N^2)$过渡。 这太慢了。 

关键的结构见解是下一个状态仅取决于 LCM$x$和$y$，它始终是$x$。 这意味着状态可以按值的递增顺序进行处理，因为转换总是按可分偏序向上移动。 一旦我们处理一个状态$x$，所有能够从下面到达它的国家都已经被考虑到了它们对期望的贡献。 

我们还利用了这样一个事实：对于固定的$x$，许多值$y$就所得的 LCM 而言，表现相同。 而不是迭代所有$y$，我们可以根据 LCM 结果对转换进行分组。 对于给定的$x$，有效的转换与值完全对应$z$这样$x \mid z$和$z \le N$，以及大家的贡献$y$产生那个$z$可以通过考虑除数来预先计算$z$并反转 LCM 条件。 

这将问题转化为整除格上的除数筛式 DP，其中我们累积达到每个状态的概率，然后向上传播期望。 

最终的计算变成了 DP，其中每个状态从可以生成它的所有较小除数中收集概率质量，然后使用它来计算预期贡献。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(N^2)$|$O(N)$| 太慢了|
 | 带聚合的除数 DP |$O(N \log N)$|$O(N)$| 已接受 |

 ## 算法演练

 1. 计算归一化概率$p(y) = \frac{W_y}{\sum W}$。 这会将权重转换为适当的分布，因此可以线性计算期望。 期望仅取决于概率，而不取决于原始权重。 
2. 预先计算每个值$z$来自所有配对的贡献$(x,y)$这样$\mathrm{lcm}(x,y) = z$。 这是通过迭代除数来完成的$z$， 因为$x$必须划分$z$，然后检查哪个$y$价值观与精确生产兼容$z$。 
3. 定义$E[x]$作为从状态开始的预期硬币数量$x$。 我们将按升序计算这些值$x$，因为所有的转换都会变成$x$。 
4. 对于每个州$x$, 初始化$E[x]$所有有效贡献的预期即时奖励$y$这样$\mathrm{lcm}(x,y) \le N$。 该术语解释了每次成功转换的“+1 币”。 
5. 对于每个有效的转换$x \to z$, 累积贡献$p(y)\cdot E[z]$进入$E[x]$。 这通过转移图向后传播未来的期望。 
6. 返回$E[1]$，因为进程总是从槽 1 开始。 

它的工作原理源于 LCM 转换的单调性特性。 每一个举动都来自$x$导致一个状态是$x$，因此状态图是按整除性排序的 DAG。 因此，以升序计算期望可以确保每当我们评估$E[x]$， 全部$E[z]$对于可达的$z > x$已经最终确定。 期望递归是线性的，因此每个状态都会聚合所有可能的下一步动作的独立贡献，而不会重复计算。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def main():
    N = int(input())
    W = list(map(int, input().split()))
    
    total = sum(W)
    p = [0.0] * (N + 1)
    for i in range(1, N + 1):
        p[i] = W[i - 1] / total

    E = [0.0] * (N + 1)

    for x in range(N, 0, -1):
        exp_val = 0.0

        for y in range(1, N + 1):
            if p[y] == 0:
                continue
            z = (x * y) // __import__("math").gcd(x, y)
            if z <= N:
                exp_val += p[y] * (1.0 + E[z])

        E[x] = exp_val

    print(f"{E[1]:.10f}")

if __name__ == "__main__":
    main()
```该代码实现了直接期望递归。 我们首先根据权重计算概率，然后定义一个数组$E$为了期望。 对于每个州$x$，我们迭代所有可能的$y$，使用标准 gcd 恒等式计算 LCM，并累加零或$1 + E[z]$取决于过渡是否保持在界限内。 

计算方向为$N$降到 1 在数学上并不是严格必要的，但可以确保当我们访问时$E[z]$，它已经被计算出来了，因为$z \ge x$。 考虑到所需的精度，使用浮点运算就足够了。

 该迹线强调了较大值上的较高权重如何加速通过整除晶格的移动，从而增加预期的终止深度。

 ## 边缘情况

 一种边缘情况是所有重量都集中在$y = 1$。 然后$\mathrm{lcm}(x,1)=x$，因此该过程永远不会移动，并在第一个硬币后立即终止。 该算法处理这个问题是因为$E[x] = p(1)\cdot(1 + E[x])$解析为有限几何期望。 

当所有权重都处于$y = N$。 从$x=1$，我们直接跳转到$N$，并且从那里该过程立即终止，因为进一步的 LCM 超过$N$或保持在$N$。 DP 将其捕获为单个大转变，没有中间积累。 

最终的结构边缘情况是$x$已经很大并且大多数 LCM 结果超过$N$。 在这种状态下，期望崩溃为少量的转换，并且算法正确地分配接近于零的连续值，因为无效的转换对总和没有贡献。
