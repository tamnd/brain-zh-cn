 ## 解决方案
 ## 问题理解

 我们给出一个有向图，在同一对顶点之间可能有多个边，并且还有自循环。 每个有向边代表城市之间的单步移动。 对于任意一对城市$u$和$v$，以及任意长度$k \ge 1$，我们定义$f(u, v, k)$作为确切的不同行走的数量$k$边缘开始于$u$并结束于$v$。 如果存在所选边缘不同的位置，则两次行走是不同的。 

问题不是计算这些值，而是确定是否存在至少一对城市$u, v$这样序列$f(u, v, k)$不会稳定到恒定值，因为$k$成长。 换句话说，我们检查是否存在一对，其长度为-$k$行走经常无限变化，并且在某个阈值之后永远不会固定。 

图形大小达到$5 \times 10^5$顶点和边，因此任何依赖于枚举路径、动态规划的解决方案$k$，或者整个图上的矩阵求幂是立即不可行的。 即使每个值的线性时间$k$解释是不可能的，因为$k$是无界的。 

当图是非循环时，会出现微妙的边缘情况。 在此类图中，所有行走最终都会停止增加，因为最大可能的路径长度是有限的。 例如，在一个简单的链中$1 \to 2 \to 3$， 全部$f(u,v,k)$足够大时变为零$k$，因此每对都稳定。 仅检查周期而不考虑奇偶性或周期性的粗心方法在这里仍然是正确的，但在存在周期但不会导致特定对之间的变化的图表中，它可能会失败。 

另一个重要的边缘情况是单向循环。 例如，$1 \to 2 \to 3 \to 1$。 这里，$f(1,1,k)$是 1 如果$k \bmod 3 = 0$，否则为 0。这永远不会稳定，因此答案必须是“是”。 假设“每个节点在强连接组件中具有唯一的最终行为”的解决方案将错误地返回“否”。 

最后，具有多个循环通过共享顶点交互的图是不稳定的真正根源。 例如，如果从一个节点可以到达两个不同长度的周期，则行走计数就会变成不同周期性贡献的组合，从而阻止稳定。 

## 方法

 暴力解释是根据邻接矩阵幂来思考。 让$A$是图的邻接矩阵，那么$A^k[u][v] = f(u, v, k)$。 直接方法是计算连续幂或重复乘法，同时检查条目是否稳定。 即使我们只尝试检测变化，每次乘法都是$O(n^3)$以密集形式或$O(nm)$以稀疏形式，我们需要达到任意大$k$，这是不可能的。 

关键的结构观察是步行计数的稳定性完全由定向循环引入的周期性控制。 如果组件仅包含非循环结构，则行走计数最终会变为零。 如果强连通分量至少包含一个有向循环，则行走计数由循环长度控制，并且组合循环的能力会在路径计数中产生算术周期性。 

真正的区别在于该图是否包含至少一个强连通分量，该分量不是“平凡意义上的非周期性”，这意味着它允许两个可以组合的不同循环长度，或者等效地，它具有一种循环结构，对于所有可达对来说，该循环结构不会减少为单个固定周期行为。 实际上，这简化为检查凝聚 DAG 是否包含具有多个出射边缘的分量，形成的循环结构不是具有均匀结构的简单有向循环。 

一种更有用的重新表述是，当且仅当存在一个可在时间步长内以多种方式从自身到达的有向循环时，才存在不稳定性，这在无向直觉中对应于从某处可到达的至少一个有向循环的存在，因为单个循环已经为至少一对产生了非收敛行为。 

因此，问题就简化为检测图是否包含任何有向环。 如果存在环，我们可以在其上选取一个节点并选择$u = v$在那个周期； 然后$f(u,u,k)$周期性地振荡并且永远不会稳定。 如果不存在循环，则该图是一个 DAG，并且每次行走的长度都是有界的，因此对于任何对$u, v$,$f(u,v,k) = 0$对于所有足够大的$k$，意味着收敛成立。 

因此，整个问题归结为有向图中的循环检测。

 | 通过 DP over k 进行暴力破解 | O(n^2k) | O(n^2k) | O(n^2) | O(n^2) | 太慢了 |

 ## 算法演练

 我们只需判断有向图是否包含环即可。 

1. 从输入边构建有向图的邻接表。 这种表示允许线性时间遍历每个顶点的所有传出边。 
2. 使用三态 DFS 着色系统或 Kahn 拓扑排序方法运行定向循环检测。 目标是区分图是否是 DAG。 DFS 方法将节点标记为未访问、正在访问或已完全处理。 如果在遍历过程中遇到当前处于访问状态的节点，则存在环路。 
3. 迭代所有节点，对于每个未访问过的节点，启动DFS。 如果任何 DFS 调用检测到访问节点的后沿，则立即得出循环存在的结论并返回 Yes。 
4. 如果所有节点都处理完毕而没有遇到后边，则该图是非循环的，因此返回No。 

DFS 足够的原因是有向循环正是拓扑排序的障碍。 如果存在循环，DFS必然会遇到递归栈重访。 

### 为什么它有效

 如果图没有有向环，则它是 DAG。 在 DAG 中，每次行走都有有限长度，因为顶点不能重复。 因此，对于任意一对$u, v$，存在最大路径长度，在此之后不存在新的路径，所以$f(u,v,k)$对于所有足够大的情况都变为零$k$，给出收敛性。 

如果该图至少包含一个有向环，则取该环上的任意节点。 从该节点到其自身，我们可以多次遍历该循环，从而为无限多个值生成至少一次有效的行走$k$。 事实上，根据循环结构，行走次数会周期性地振荡或增长，因此无法稳定为常数。 这保证了具有非收敛行为的对的存在。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n, m = map(int, input().split())
g = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    g[u].append(v)

state = [0] * (n + 1)
has_cycle = False

def dfs(u):
    global has_cycle
    state[u] = 1
    for v in g[u]:
        if state[v] == 0:
            dfs(v)
            if has_cycle:
                return
        elif state[v] == 1:
            has_cycle = True
            return
    state[u] = 2

for i in range(1, n + 1):
    if state[i] == 0:
        dfs(i)
        if has_cycle:
            break

print("Yes" if has_cycle else "No")
```邻接表存储所有有向边而不进行任何变换。 DFS 使用标准的递归堆栈标记方法：状态 1 表示当前处于递归状态，状态 2 表示已完全处理。 当我们看到一条边指向状态1节点时，我们就找到了一条后边，这正是一个有向循环。 

一旦检测到循环，提前退出标志就可以防止不必要的遍历，这在最大约束下很重要。 

## 工作示例

 ### 示例 1

 输入图：$1 \to 2 \to 3 \to 1$| 步骤| 节点| 状态变化 | 检测到循环 |
 | --- | --- | --- | --- |
 | 1 | 1 | 1 | 没有 |
 | 2 | 2 | 1 | 没有 |
 | 3 | 3 | 1 | 没有 |
 | 4 | 1 | 重新访问堆栈 | 是的 |

 节点 1 的 DFS 最终返回到 1，同时它在递归堆栈中仍然处于活动状态。 这确认了循环存在，因此输出为 Yes。 这符合围绕 3 个周期重复遍历会产生不稳定路径计数的直觉。 

### 示例 2

 输入图：$1 \to 2 \to 3$| 步骤| 节点| 状态变化 | 检测到循环 |
 | --- | --- | --- | --- |
 | 1 | 1 | 1 | 没有 |
 | 2 | 2 | 1 | 没有 |
 | 3 | 3 | 1 然后 2 | 没有 |

 没有遇到后沿，因此该图是非循环的。 长度超过 2 后，任何对之间都不存在游走，因此所有$f(u,v,k)$变为零并稳定。

 ## 边缘情况

 单个自循环是可能的最小循环。 对于具有一个节点和一条边的输入$1 \to 1$，DFS立即将节点1标记为正在访问，然后再次看到它，产生一个循环。 该算法输出 Yes，符合以下事实：$f(1,1,k)=1$为所有人$k$，它不会稳定为零或所有对的任何最终恒定行为。 

长定向链表现出相反的行为。 DFS 按顺序访问节点，不会遇到任何后缘，并且每个节点都得到充分处理。 由于不存在循环，所有步行计数最终都为零，因此输出为 No。 

包含多个循环但成分不相连的图会被统一处理。 DFS 独立地探索每个组件，一旦发现任何循环，全局标志就会触发终止。 这确保我们不会错过第一个探索的组件之外的周期。
