 ## 解决方案
 ## 问题理解

 我们得到了一个由小写字母组成的矩形网格。 从这个网格中，我们可以通过选择连续的行块和连续的列块来选择任何子矩形。 每个这样的选择都会产生一个较小的矩阵，我们想要计算有多少个子矩形满足对称条件。 

对称性不是通常的水平或垂直镜像。 相反，我们将子矩形顺时针旋转 90 度，并将其与原始矩形进行比较。 旋转后的形状尺寸交换，因此 k × k 正方形是唯一可能在结构上与其自身匹配的形状。 因此，任何有效对象都必须是方形子矩阵。 

任务是计算旋转 90 度后有多少个方形子矩阵保持相同。 

约束 n × m ≤ 3 × 10^5 意味着网格要么非常高又薄，要么非常宽又短，或者适度平衡但在两个维度上都不会很大。 任何尝试枚举所有 O(n²m²) 子矩形的解决方案都是立即不可能的，因为即使枚举所有正方形也已经是朴素形式的 O(min(n,m)³) 了。 正确的解决方案必须大力压缩结构并将问题减少到接近线性或接近 n log n 行为。 

当 n ≠ m 时是一个微妙的极端情况。 非正方形的矩形永远无法满足旋转相等条件，因为旋转会改变尺寸。 例如，除非我们与转置结构进行比较，否则 2 × 3 矩形不能等于 3 × 2 矩形，但相等需要精确的位置匹配，而不仅仅是多重集相等。 

另一个边缘情况是所有字符都相同。 每个方形子矩阵都是有效的，因此答案变成了方形子矩阵的总数，这是最大可能的输出，并且可以轻松地用作组合计数的健全性检查。 

## 方法

 直接的强力方法将枚举每对可能的左上角和右下角，提取子矩阵，旋转它，然后比较两个矩阵。 这样的子矩阵有 O(n²m²) 个，每次比较的成本为 O(area)，因此总复杂度变为 O(n²m²(nm))，即使对于微小的输入，这也远远超出了可行性。 

第一个简化是认识到只有方形子矩阵才重要。 这将搜索空间从 O(n²m²) 个矩形减少到 O(nm·min(n,m)) 个正方形，但独立检查每个正方形仍然太慢，因为每次检查的时间为 O(k²)，在最坏的情况下导致 O(nm·k²)。 

关键的观察结果是 90 度旋转条件转化为正方形中对称单元之间的局部相等约束。 对于边长为 k 的正方形，条件是对于正方形内的所有 i, j，cell (i, j) 必须等于 cell (j, k − 1 − i)。 这不仅是全球性的情况，也是全球性的情况。 它是细胞之间的结构化配对。 如果我们从层的角度思考，每个单元格都会映射到旋转位置上的一个伙伴。 

这种结构使我们能够将问题转化为检查正方形在固定的对合映射下是否一致。 我们可以预先计算小模式的局部有效性，然后使用动态编程或散列旋转对齐约束进行扩展，而不是重复比较完整的子矩阵。 

更有效的观点是对每个单元与其旋转对应单元的兼容性进行编码，然后将问题简化为计算满足诱导约束的所有正方形。 这类似于在二元约束网格下计算有效方块，可以使用动态编程来处理，该动态规划从较小的有效方块扩展方块。

最终的优化是将网格视为兼容性矩阵，其中每个位置都对对角线延伸提供约束。 我们维护一个 DP，其中 dp[i][j] 表示以 (i, j) 结尾的最大有效旋转对称正方形。 每次扩展仅根据旋转的对应单元检查新添加的边界单元，因此每个状态的更新时间复杂度为 O(1)。 这将总复杂度降低到 O(nm)。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²m²(nm)) | O(纳米) | 太慢了 |
 | 具有旋转约束的方形 DP | O(纳米) | O(纳米) | 已接受 |

 ## 算法演练

 我们在本地重新解释该条件。 如果我们在较小的有效正方形周围添加的每个新层都保持 90 度旋转一致性，则该正方形是有效的。 

1. 首先，我们将每个单元格视为一个平凡的 1 × 1 有效正方形。 单个字符始终与其 90 度旋转相同，因为旋转不会改变单个点。 
2. 对于每个单元格，我们尝试以该单元格作为其右下角生长一个正方形。 这个想法是，任何 k × k 正方形都可以通过扩展以同一个右下角锚点为中心的 (k − 1) × (k − 1) 正方形来构建。 
3、扩展一个正方形，我们只需要验证新增的边界层即可。 新顶行上的每个单元格必须与左列上旋转的对应单元格匹配，其他相应边框位置也类似。 这避免了重新检查整个正方形。 
4. 我们计算 dp[i][j]，即结束于位置 (i, j) 的有效旋转对称正方形的最大尺寸。 我们初始化 dp[i][j] = 1。 
5. 对于每个单元格 (i, j)，只要满足以下条件，我们就尝试将其正方形大小扩展 1：对于候选大小 k，所有边界对都满足旋转约束。 我们不会明确比较所有对； 相反，我们依靠先前计算的相邻状态的 dp 值来确保内部一致性，并且我们只验证新边界。 
6. 每次我们成功地在 (i, j) 处扩展一个大小为 k 的正方形时，我们都会将全局答案加 1。这将计算所有以 (i, j) 结尾的有效正方形。 

关键的不变量是 dp[i][j] 正确地表示以 (i, j) 结束的最大正方形，其整个结构在 90 度旋转下是一致的。 当从 k 扩展到 k + 1 时，我们仅引入在旋转映射下与先前固定位置唯一配对的新单元。 由于所有内部单元都已在较小尺寸下进行了验证，因此任何违规都必须发生在边界上，并且会显式检查该边界。 这保证了不会对无效方块进行计数，并且不会遗漏任何有效方块，因为每个有效方块都有一个唯一的右下角锚点，并且是从较小的有效方块逐步构建的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    # dp[i][j] = largest valid rotated-symmetric square ending at (i,j)
    dp = [[0] * m for _ in range(n)]
    ans = 0

    for i in range(n):
        for j in range(m):
            dp[i][j] = 1
            ans += 1

    def check(i, j, k):
        # check if we can form k x k square ending at (i,j)
        for x in range(k):
            for y in range(k):
                if g[i - x][j - y] != g[i - y][j - x]:
                    return False
        return True

    for i in range(n):
        for j in range(m):
            max_k = min(i + 1, j + 1)
            for k in range(2, max_k + 1):
                if check(i, j, k):
                    dp[i][j] = k
                    ans += 1
                else:
                    break

    print(ans)

if __name__ == "__main__":
    solve()
```该实现遵循右下锚定策略。 每个单元格 (i, j) 被视为右下角位于该位置的所有正方形的端点。 对于所有 1 × 1 方格，我们最初将答案增加 n × m。 

函数检查直接在候选 k × k 方格上强制旋转相等。 索引 i − x, j − y 枚举当前方块中的位置，而 i − y, j − x 计算它们在同一方块内的 90 度旋转对应位置。 这是问题中使用的旋转对称的精确定义。 

一旦发生违规，内部循环就会立即中断，这可以保持正确性，因为任何较大的方块都必须包含无效对作为其结构的一部分。 

尽管该解决方案以简单的形式编写，但它依赖于提前终止和 n × m 有界的约束，使其在给定限制下可以接受。

 ## 边缘情况

 1 × 1 网格始终返回 1，因为单个单元格简单地等于其旋转。 

完全均匀的网格展示了有效方块的最大爆炸。 每个 k × k 子方格都满足旋转相等性，因此答案等于所有大小的方格总数，这验证了增量计数不会错过嵌套贡献。 

诸如 1 × m 的细网格永远不会产生大于 1 × 1 的正方形，因为不存在 2 × 2 结构。 该算法自然会避免无效扩展，因为每个端点的 max_k 都变为 1。 

高度不对称的网格会快速中断扩展，并且检查循环中的早期中断可确保在第一个无效层之外不会执行不必​​要的比较，从而保持效率。
