 ## 解决方案
 ## 问题理解

 我们有一个敌方单位阵容，每个单位都有一个整数攻击值。 在应用所有修改后，一张特殊效果卡会移除所有攻击力为奇数的单位。 在使用这张卡之前，我们可以施展一系列一次性法术。 每个法术都会为选定的一个单位的攻击力增加一个固定值，并且每个法术最多可以使用一次。 

以任何方式将法术分配给单位后，我们应用移除效果并删除所有最终攻击值为奇数的单位。 目标是最小化剩余单位（即最终值为偶数的单位）的攻击值总和。 

关键的相互作用是法术会影响奇偶校验。 只有一个值是奇数还是偶数对生存很重要，但实际数值对幸存单位的最终总和很重要。 这就产生了一种紧张：我们希望将大的偶值单位转换为奇数单位，以便将它们删除，但这样做会消耗咒语，并且可能会对可能进行的此类转换次数施加结构性限制。 

约束最多为 100,000 个单位和 100,000 个咒语，这排除了任何尝试所有咒语分布或执行每次分配模拟的解决方案。 任何超出线性或线性时间且具有较小常数因子的时间都是可接受的，但对分配的指数或二次推理则不可接受。 

当考虑法术如何与奇偶校验相互作用时，会出现一个微妙的边缘情况。 偶值法术根本不会改变平价，但仍然会增加攻击值。 如果用在幸存的单位上，它们会直接增加最终的答案，所以它们对幸存者来说永远没有好处。 然而，它们可以安全地“倾倒”到将被移除的单元上，因为移除的单元不计入最终总和。 忽视这一点的幼稚方法可能会错误地认为所有咒语都必须有意义地使用。 

另一个边缘情况来自奇偶校验的可行性。 如果我们决定将某些偶值单位转换为奇数单位，则每次此类转换都需要一个奇值咒语。 如果我们使用的转换次数少于可用咒语，则剩余的奇怪咒语仍必须成对使用或以保留同等可行性的方式浪费。 在某些情况下，忽略这一点会导致无效的构造，其中转换次数与奇数咒语总数的奇偶校验不匹配。 

例如，如果所有单位值都是偶数，并且我们有一个奇数咒语，则我们不能将其闲置或以一种保持一致性的方式应用它而不考虑奇偶校验约束。 正确的输出必须尊重我们在所有单位之间翻转奇偶校验次数的全局奇偶校验可行性。 

## 方法

 暴力解释会尝试所有方法将每个咒语分配给每个单元。 对于每个作业，我们计算最终值，删除奇数，并评估剩余的总和。 这立即爆炸：m个咒语中的每一个都有n个选择，导致$n^m$可能性，这远远超出了任何可行的计算。 

即使我们忽略单个法术身份并仅跟踪每个单位收到的法术数量，我们仍然面临巨大的组合分配问题。 关键的观察是，只有分配给每个单位的奇数咒语数量的奇偶性很重要，而不是确切的计数。 分配给同一单位的两个奇怪法术会取消其平价效果，同时浪费容量。 

这减少了决定哪些单元的奇偶校验翻转的问题。 一旦采用这种观点，结构就变得简单：每个单元要么保持其原始奇偶性，要么翻转，而翻转会为每个受影响的元素消耗一个奇数咒语“预算单位”。 

从这里开始，问题就变成选择偶值单位的子集来转换为奇值单位（因此它们被删除），同时尊重我们可以执行的此类转换次数的限制以及我们总体使用的翻转次数的奇偶校验约束。 

贪婪结构的出现是因为移除一个单元会贡献其全部价值作为节省的成本。 因此，如果我们决定删除一些偶数单位，我们应该优先考虑最大的单位。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力破解咒语分配 | 指数| O(n + m) | 太慢了|
 | 基于奇偶校验的贪婪选择 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 ### 1. 按奇偶校验分隔单元

 我们迭代所有单位并将它们分组为奇值和偶值列表。 无论法术如何，所有奇数值单位始终会被最终效果移除，因此它们对最终答案没有贡献。 

### 2. 计算基线答案

 我们从所有偶数单位的总和开始。 这代表了如果我们不使用任何法术来改善这种情况的成本。 任何改进都必须来自于删除其中一些偶数单位。 

### 3. 确定要移除的候选单位

 只有偶数单位才是有用的转换候选单位。 如果我们将偶数单位转换为奇数单位，它将被删除并且其值从最终总和中消失。 每一次这样的转变都需要花费一个奇数咒语。 

### 4. 按优势对候选人进行排序

 我们按降序对偶数单位进行排序。 转换较大的值会进一步减少最终答案，因此一旦处理了可行性约束，贪婪选择就是最佳选择。 

### 5. 选择我们可以执行的转换次数

 令 k 为奇数咒语的数量。 我们考虑选择 t 次转换，其中每次转换都使用一个应用于不同偶数单位的奇数咒语。 

然而，并非所有 t 值都有效。 我们必须满足这样的约束：剩余的奇数咒语可以配对或浪费，而不影响奇偶校验的可行性。 这导致 t 必须满足的条件：

 t 的翻转次数不能超过 k，并且 k − t 必须是偶数，相当于 t 与 k 具有相同的奇偶性。 

### 6. 尝试所有有效的 t 直到 k

 对于每个有效 t，我们取最大 t 偶值单位的总和。 这表示删除这些单位。 我们将所得的剩余总和计算为基线总和减去该增益。 

### 7. 选择最佳配置

 我们取所有有效 t 值的最小结果总和。 

### 为什么它有效

 该过程由一个不变量控制：咒语唯一有意义的效果是每个偶值单位是否被翻转奇数次。 任何额外的奇数咒语对都会抵消而不影响奇偶校验，因此只有翻转单元的数量很重要，而不是确切的分配结构。 

一旦进行了这种减少，问题就变成在基数和奇偶校验约束下选择偶值单元的子集，以最大化总去除权重。 由于贡献是独立且相加的，因此排序保证任何最佳解决方案都必须包含固定大小的已排序偶数值的前缀。 奇偶校验约束仅限制允许的前缀长度，但不会改变最佳排序。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    m = int(input())
    b = list(map(int, input().split()))

    total_even = 0
    evens = []

    for x in a:
        if x % 2 == 0:
            total_even += x
            evens.append(x)

    evens.sort(reverse=True)

    k = m  # number of spells; only parity matters

    # prefix sums of even values
    prefix = [0]
    for v in evens:
        prefix.append(prefix[-1] + v)

    ans = total_even

    # try all valid counts t
    for t in range(0, min(k, len(evens)) + 1):
        if t % 2 != k % 2:
            continue
        ans = min(ans, total_even - prefix[t])

    print(ans)

if __name__ == "__main__":
    solve()
```该实现首先隔离偶值单元并计算它们的总和作为起始基线。 然后，它对这些值进行排序，以便任何前缀都对应于最有益的删除。 

变量 k 仅通过其奇偶性进行处理，因为未使用的奇数咒语可以在不影响可行性的情况下进行配对。 t 上的循环检查满足可用性界限和奇偶校验约束的所有有效删除数量。 对于每个有效 t，我们减去最佳可能增益，即最大 t 偶数值的总和。 

一个常见的陷阱是尝试直接使用所有法术或尝试将它们贪婪地分配给单位而不考虑奇偶约束。 正确的方法永远不会跟踪单个咒语的使用情况，除非它是否有助于翻转。 

## 工作示例

 ### 示例 1

 输入：```
n = 3
a = [4, 5, 3]
m = 1
b = [1]
```我们分别处理偶数和奇数。 

| 步骤| 偶数单位| k | 有效 t | 最佳前缀和| 剩余金额 |
 | --- | --- | --- | --- | --- | --- |
 | 初始| [4] | 1 | 1 | 4 | 0 |

 只有有效的 t 为 1，因为 t 必须与 k 的奇偶校验匹配。 删除 4 会将其转换为奇数，因此在最终效果后它会消失。 

这证实了一次翻转可以完全消除唯一的偶数贡献者。 

### 示例 2

 输入：```
n = 4
a = [3, 3, 3, 3]
m = 2
b = [1, 1]
```所有单位都已经是奇数了。 

| 步骤| 偶数单位| k | 有效 t | 结果 |
 | --- | --- | --- | --- | --- |
 | 初始| []| 2 | 0 | 0 |

 甚至没有需要改进的单位。 任何咒语都与最终结果无关，因为无论如何，所有单位都会被移除。 

这表明当不存在偶数单位时，法术无效。

 ## 边缘情况

 当没有偶值单位时，算法立即返回零，因为基线总和为零并且不可能进行改进。 即使有很多法术存在，也无法改变施加效果后所有单位都会被移除的事实。 

当奇数拼写的数量很大但与有用的删除数量不兼容的奇偶校验时，算法会正确地跳过无效的前缀长度并仅考虑那些匹配的奇偶校验，从而防止删除的过度计数。 

当所有单位均等并且法术充足时，最佳策略是在奇偶性允许的情况下将其全部移除； 否则，该解决方案将根据奇偶校验对齐删除除一个之外的所有内容，这由前缀选择规则自然处理。
