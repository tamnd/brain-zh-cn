 ## 解决方案
 ## 问题理解

 我们正在构建长度序列$n$，其中每个位置都有一个值$1$到$m$。 不同的是，我们得到了越来越多的区间约束。 处理完第一条后$k$约束，每个区间$[l_i, r_i]$其中要求其内部的所有位置必须包含成对不同的值。 

因此，每个间隔的行为就像一个“局部唯一性规则”：如果您只查看该段内部，则不允许任何值重复。 随着添加更多间隔，这些唯一性要求会累积，我们必须计算有多少序列仍然满足所有活动规则。 

输出不是单个计数而是前缀流：在每个添加的间隔之后，我们重新计算有效序列的数量模$998244353$。 

约束足够大，任何显式检查区间内对的解决方案都是不可能的。 单个长度区间$n$已经诱发$O(n^2)$成对限制，并且最多$3 \cdot 10^5$间隔这立即变得不可行。 即使维护明确的禁止对或每个前缀从头开始重新计算也将远远超出时间限制。 

约束的结构也很微妙：间隔重叠，重叠对位置产生了共享限制。 “每个区间独立地减少选择”的天真的直觉失败了，因为两个区间可以以耦合的方式对同一对位置施加约束。 

一些边缘案例暴露了幼稚推理的陷阱。 

如果我们有一个区间$[1, n]$，答案很简单$m \cdot (m-1) \cdot \dots \cdot (m-n+1)$。 相反，乘以独立的每个位置选择的幼稚实现将错误地返回$m^n$。 

如果区间不相交，例如$[1,2]$和$[5,6]$，它们不相互作用。 但如果它们重叠，例如$[1,4]$和$[3,6]$，则位置 3 和 4 同时受到两个间隔的约束，并且每个间隔乘法双倍计数限制。 

核心困难在于约束形成了“必须不同”关系的全局图，而不是独立的部分。 

## 方法

 蛮力视角是在每个前缀之后构建完整的约束图。 每个区间$[l, r]$贡献其内部每对位置之间的边，因为内部的所有值必须是不同的。 加工后$k$间隔，我们会有一个图表$n$顶点，我们需要使用正确的着色数量$m$颜色。 

该图最多可以包含$O(n^2)$在密集情况下的边缘，因此即使构建它也已经太昂贵了。 计算一般图的着色数相当于评估其色多项式，这在一般图中是不可行的。 

关键的结构观察是，虽然图看起来很密集，但它并不是任意的。 约束图是区间上的团的并集，这种结构产生弦图。 弦图有一个非常强大的属性：它们承认完美的消除顺序，其中当您处理一个顶点时，它的早期邻居会形成一个派系。 

这完全改变了计数问题。 在完美消除顺序中，每个顶点贡献一个简单的乘法因子，等于其先前邻居未使用的颜色数量。 因为较早的邻居形成了一个派系，所以它们必须在任何有效的颜色中都具有不同的颜色，因此它们的数量正是它们的大小。 

这将整个问题简化为每个位置的计算$j$，有多少早期位置被迫与其不同。 事实证明，这个数字仅取决于最左边的区间覆盖$j$以精确的方式。 

简化区间结构后，各位置$j$有一个价值$L_j$，存在覆盖两者的活动区间的最小索引$L_j$和$j$。 所有职位位于$[L_j, j-1]$变得彼此相邻$j$并且还形成一个派系，这意味着它们在任何有效的分配中都是不同的。 所以步骤中禁止颜色的数量$j$正是$j - L_j$。 

最终答案成为每个位置独立选择的产物：$$\prod_{j=1}^{n} (m - (j - L_j))$$剩下的挑战是维持$L_j$随着间隔的添加而动态变化。

 ## 算法演练

 我们增量处理间隔，维护每个前缀$k$价值观$L_j^{(k)}$，表示影响位置的左边界$j$在第一个之后$k$间隔。 

### 1. 维持每个位置的区间影响力

 每个区间$[l, r]$断言对于每一个$j \in [l, r]$， 位置$j$可能有其$L_j$减少到$l$，因为这个间隔提供了一种连接方式$j$返回到较早的位置，开始于$l$。 

因此每个间隔执行一次范围更新：对于所有$j \in [l, r]$,$$L_j \leftarrow \min(L_j, l)$$这意味着我们维持一个范围最小分配结构$L_j$。 

### 2. 使用线段树节拍进行范围 chmin

 我们储存$L_j$在支持范围“chmin”更新的线段树中。 每次新的间隔到来时，我们都会应用范围更新$[l, r] \to \min(l, \cdot)$。 这正是经典的线段树节拍操作。 

我们还在每个节点中维护足够的信息，以便仅在段实际改进时传播更改，从而避免每个元素更新。 

### 3. 转换$L_j$转化为贡献因素

 对于每个位置$j$， 一次$L_j$已知，早期禁止位置的个数为：$$j - L_j$$所以选择的数量为$a_j$是：$$m - (j - L_j)$$我们维持这些贡献的乘积$j$。 

### 4. 更新细分市场变化下的产品

 每当一个片段$[l, r]$有它的$L_j$值减少，每个受影响的位置的因子都会从以下位置更改：$$(m - (j - oldL_j)) \to (m - (j - newL_j))$$我们通过删除旧的贡献并乘以新的贡献来更新全局乘积。 这是在线段树内延迟完成的，因此仅重新计算受影响的线段。 

### 5. 每个前缀的答案

 处理完每个区间后$k$，我们输出当前的产品。 

### 为什么它有效

 关键的不变量是对于每个前缀$k$，值$L_j$精确描述连接位置的最小区间锚点$j$在所有主动约束下到较早的位置。 在这种结构下，每个的早期邻居$j$形成一个派系，这意味着所有这些位置必须在每个有效序列中占据不同的值。 这迫使位置上禁止的颜色数量$j$仅取决于该派系的规模，即$j - L_j$。 由于每个有效序列在每个步骤中都独立地尊重该局部结构，因此序列总数分解为独立的每个位置选择的乘积。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

class SegTree:
    def __init__(self, n):
        self.n = n
        self.mn = [0] * (4 * n)
        self.lz = [10**18] * (4 * n)

    def push(self, v):
        if self.lz[v] != 10**18:
            for u in (v * 2, v * 2 + 1):
                self.apply(u, self.lz[v])
            self.lz[v] = 10**18

    def apply(self, v, val):
        self.mn[v] = min(self.mn[v], val)
        self.lz[v] = min(self.lz[v], val)

    def range_chmin(self, v, tl, tr, l, r, val):
        if l > r:
            return
        if l <= tl and tr <= r:
            self.apply(v, val)
            return
        self.push(v)
        tm = (tl + tr) // 2
        if l <= tm:
            self.range_chmin(v * 2, tl, tm, l, r, val)
        if r > tm:
            self.range_chmin(v * 2 + 1, tm + 1, tr, l, r, val)

    def collect(self, v, tl, tr, res):
        if tl == tr:
            res[tl] = self.mn[v]
            return
        self.push(v)
        tm = (tl + tr) // 2
        self.collect(v * 2, tl, tm, res)
        self.collect(v * 2 + 1, tm + 1, tr, res)

def solve():
    t = int(input())
    for _ in range(t):
        n, m, q = map(int, input().split())
        seg = SegTree(n)

        ans = 1
        L = [0] * (n + 1)

        intervals = []
        for _ in range(q):
            l, r = map(int, input().split())
            intervals.append((l, r))

        for k in range(q):
            l, r = intervals[k]
            seg.range_chmin(1, 1, n, l, r, l)

            seg.collect(1, 1, n, L)

            ans = 1
            for j in range(1, n + 1):
                forbidden = j - L[j]
                val = m - forbidden
                if val <= 0:
                    ans = 0
                    break
                ans = (ans * val) % MOD

            print(ans)

if __name__ == "__main__":
    solve()
```线段树存储当前最好的$L_j$对于每个位置。 每个间隔应用范围 chmin 更新。 在每个前缀之后，我们重建数组并直接重新计算乘积。 这不是内存优化程度最高的实现，但与概念模型直接匹配：maintain$L_j$，导出每个位置的禁止计数，并乘以贡献。 

一个微妙的点是使用$\min(l, \cdot)$更新。 一旦位置收到较小的左边界，它就不会再增加，这允许线段树内的单调传播逻辑。

 ## 边缘情况

 当没有间隔时，每个序列都不受限制，答案很简单$m^n$。 在这种情况下，所有$L_j = j$，因此禁止计数在任何地方都为零，并且产品变为$m^n$，匹配直接解释。 

当单个区间覆盖整个数组时，$L_j = 1$为所有人$j$，所以每个位置都严格禁止$j-1$颜色。 该产品减少到$m \cdot (m-1) \cdot \dots$，匹配预期的排列计数。 

当区间严重重叠时（例如嵌套区间），最小左边界会迅速崩溃，从而产生强约束。 该算法通过传播更小的$L_j$通过重复范围 chmin 操作来计算值，确保禁止计数只会减少，不会增加，从而保持乘法结构的正确性。
