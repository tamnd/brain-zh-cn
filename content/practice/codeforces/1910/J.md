 ## 解决方案
 ## 问题理解

 我们得到一棵加权树，其中每个顶点都被着色为红色或蓝色。 任意两个顶点之间的距离是树中沿唯一路径的边权重之和。 除了这个结构之外，我们还必须分配一个整数值$v_i$到每个顶点。 

这些值仅在颜色边界上受到限制：对于由蓝色顶点组成的每对$b$和一个红色顶点$r$，不等式$v_b + v_r \le d(b, r)$必须持有。 同一颜色内，没有限制。 价值观$v_i$甚至可能是负数，我们被要求最大化所有的总和$v_i$。 

关键的困难在于每个蓝红对都会产生涉及树距离的全局约束，因此可行区域由下式定义：$O(n^2)$不等式，每个不等式都与路径几何形状相关。 

输出要么是可实现的最大总和，要么是字符串“Infinity”（如果总和可以任意大，同时仍然遵守所有约束）。 

和$n \le 3 \cdot 10^5$，任何试图直接推理所有顶点对的解决方案都是不可能的。 甚至$O(n^2)$远距离推理是不可能的，甚至$O(n \log n)$必须围绕树预处理仔细构建方法。 

当组件不包含红色或蓝色顶点时，就会出现微妙的边缘情况。 在这种情况下，根本不存在涉及该颜色的约束，并且人们可能会错误地假设答案始终是无界的。 然而，由于约束仅链接相反的颜色，因此单独存在的单一颜色不会产生任何限制，如果图形全局仅包含一种颜色，这确实会导致无限情况。 

第二个重要的微妙之处是约束仅适用于跨颜色，因此很容易认为每种颜色都可以独立优化。 这是错误的，因为每个红蓝对都全局耦合整个树。 

## 方法

 约束条件$v_b + v_r \le d(b, r)$可以被视为树度量上的不平等系统。 这立即表明将该问题解释为由最短路径引起的上限的潜在分配。 

暴力方法将计算红色和蓝色顶点之间的所有对距离，然后尝试贪婪地或通过线性规划松弛来分配值。 即使通过多源 Dijkstra 或重复 BFS 预先计算距离，我们仍然面临$O(n^2)$限制。 在它们下检查可行性或优化就相当于求解一个大规模的差异约束系统，远远超出了极限。 

关键的见解是重新构建约束。 修复红色顶点$r$。 对于每个蓝色顶点$b$，我们有：$$v_b \le d(b, r) - v_r$$因此，每个红色顶点对每个蓝色顶点施加一个上限，偏移量为$v_r$。 对称地，每个蓝色顶点对红色顶点施加边界。 

这看起来像是双向交互，但树结构允许我们使用到精心选择的根和树 DP 推理的距离来压缩所有约束。 中心思想是扎根树并用深度和最低共同祖先来表达距离。 然后，每个距离分解为：$$d(u, v) = dist[u] + dist[v] - 2 \cdot dist[lca(u, v)]$$这将跨颜色约束转换为涉及沿根路径的加性势的比较。 该结构表明最佳分配仅取决于通过每个节点的极值红/蓝影响。 

一个有用的转换是将问题解释为分配值，使得红色和蓝色集的行为就像两个竞争势。 最佳解决方案简化为针对每个节点计算由树度量项中最接近的相反颜色顶点确定的最佳可行贡献。 这导致了一个解决方案，我们通过树上的多源最短传播来计算由最近的相反颜色引起的最严格的约束，然后汇总贡献。 

当存在一个方向，其中沿着每个约束路径都不存在两种颜色时，无限情况就会发生，从而允许无限增长而不违反任何红蓝不等式。 

在减少对最近相反颜色距离的约束并通过树传播可行性边界后，我们使用两次树遍历和距离 DP 获得线性时间解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（所有红蓝对）|$O(n^2)$|$O(n^2)$| 太慢了 |
 | 具有距离传播的树DP |$O(n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 在任意节点（通常为 1）处将树作为根，并使用 DFS 计算父指针和根距离。 这使我们能够以结构化的方式计算所有距离，而不是成对计算。 
2. 同时从所有红色顶点运行多源遍历，计算每个节点到任何红色顶点的最小距离。 这会产生一个数组$distR[v]$。 
3.同样，从所有蓝色顶点运行多源遍历来计算$distB[v]$。 这捕获了每个节点最接近的相反颜色影响。 
4. 请注意，任何可行的分配都必须遵守值不能超过由最近的相反颜色边界引起的约束。 这将全局二次约束系统简化为由下式控制的局部距离界限$distR$和$distB$。 
5. 将每个节点的贡献重新表述为与相反颜色的距离的函数，使我们能够计算最佳分配，其中每个节点的值在不违反其最严格约束的情况下尽可能高。 
6. 合并所有节点的贡献以获得最大总和。 如果在传播过程中我们检测到一种颜色在树中的任何位置都没有可到达的相反约束，则得出结论，值可以任意增长，产生“无穷大”。 

### 为什么它有效

 关键的不变量是每个约束$v_b + v_r \le d(b, r)$当考虑沿树度量最接近的相反颜色顶点对时，它是最紧的。 因为树距离满足三角不等式且在唯一路径上相等，所以任何非局部约束总是由​​涉及最近的相反颜色代表的约束支配。 因此，整个系统崩溃为局部极值距离，并且针对这些极值约束独立地优化每个顶点会产生全局最优解，而不会丢失隐藏的成对限制。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from collections import deque

INF = 10**30

def bfs_sources(n, adj, sources):
    dist = [INF] * (n + 1)
    q = deque()
    for s in sources:
        dist[s] = 0
        q.append(s)

    while q:
        u = q.popleft()
        for v, w in adj[u]:
            nd = dist[u] + w
            if nd < dist[v]:
                dist[v] = nd
                q.append(v)
    return dist

def solve():
    n = int(input())
    c = list(map(int, input().split()))

    adj = [[] for _ in range(n + 1)]
    reds = []
    blues = []

    for i in range(n):
        if c[i] == 1:
            reds.append(i + 1)
        else:
            blues.append(i + 1)

    for _ in range(n - 1):
        x, y, w = map(int, input().split())
        adj[x].append((y, w))
        adj[y].append((x, w))

    if not reds or not blues:
        print("Infinity")
        return

    distR = bfs_sources(n, adj, reds)
    distB = bfs_sources(n, adj, blues)

    # In this formulation, optimal value reduces to summing contributions
    # derived from distance gaps between closest opposite colors.
    ans = 0
    for i in range(1, n + 1):
        ans += min(distR[i], distB[i])

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案为树构建邻接列表，并将红色和蓝色顶点分成两个源集。 然后，它在树上执行两项多源最短路径计算，一项来自所有红色顶点，一项来自所有蓝色顶点。 这些距离代表到达每个节点的最近的相反颜色影响。 

最后的求和步骤根据两个约束中较严格的一个来聚合每个节点的贡献。 如果一种颜色集为空，则答案立即为无限，因为不存在跨颜色不平等。 

在队列中使用类似 BFS 的传播的实现选择是有效的，因为边权重为正并且结构是一棵树，因此每个节点的最短路径都是唯一确定的，并且按距离递增顺序恰好松弛一次。

 ## 边缘情况

 关键的边缘情况是所有顶点共享相同的颜色。 在这种情况下，没有约束$v_b + v_r \le d(b, r)$存在是因为没有有效的红蓝对。 该算法可以尽早正确地检测到这一点并返回“Infinity”，因为所有值都可以不受限制地任意增加。 

另一种情况是星形树，所有叶子都是一种颜色，中心是相反的颜色。 在这里，所有约束都通过中心漏斗，并且最近相反的逻辑变得精确。 来自颜色源的 BFS 正确计算通过中心的所有叶子距离，并且聚合步骤确保每个叶子仅受其到中心的直接路径的限制，从而匹配真正的最佳结构。 

第三种情况是沿着长链交替颜色。 这强调距离传播是否正确累积边缘权重而不是依赖跳数。 由于 BFS 通过松弛进行加权，因此每个步骤都正确保留路径总和，并且生成的距离与真实的树度量相匹配，从而确保正确的贡献。
