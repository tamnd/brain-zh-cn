 ## 解决方案
 ## 问题理解

 我们有一个沼泽，表示为$2 \times n$网格。 在每一列中，只有一个睡莲叶，用星号标记，以及一个空单元格，用点标记。 每片睡莲叶上都栖息着一只青蛙。 每只青蛙必须一次性跳到相邻的单元格（左、右、上、下）。 青蛙不能移动到网格之外，不能与另一只青蛙落在同一睡莲叶上，也不能通过交换同一列中的位置来相互交叉。 青蛙只有落在睡莲叶上才能生存。 任务是确定在我们选择跳跃方向的情况下可以生存的最大青蛙数量。 

输入由多个测试用例组成，每个测试用例都有$n$列。$n$可以达到$2 \cdot 10^5$，以及总和$n$所有测试用例最多也$2 \cdot 10^5$，这意味着我们必须粗略地解决每个测试用例$O(n)$时间。 任何检查青蛙跳跃的所有排列的方法都是指数级的并且显然不可行。 

当多个青蛙可能尝试进入同一个相邻单元格或当青蛙无法进行任何安全跳跃时，就会出现不明显的边缘情况。 For example, consider a single column:```
*
.
```在这里，青蛙没有相邻的睡莲叶可供跳跃，因此答案为零。 另一个边缘情况是连续的列，其中睡莲垫在顶行和底行之间交替，例如：```
*.*.*
.*.*.
```幼稚的左右贪婪分配可能会错误地计算出比可能数量更多的青蛙，因为移动一只青蛙可能会阻挡另一只青蛙。 

## 方法

 蛮力方法会尝试每只青蛙的所有可能方向。 由于每只青蛙最多有三种选择（上/下、左、右），因此可能性的总数为$O(3^n)$每个测试用例。 这是正确的，但不可行$n$最多$2 \cdot 10^5$。 

关键的见解是生存仅取决于相邻的睡莲叶。 每列的顶行或底行都有一只青蛙。 如果青蛙的邻近细胞中有睡莲叶，青蛙就能生存。 如果我们将网格表示为一串 0 和 1，其中 1 是顶行中的青蛙，0 是底行中的青蛙，那么问题就简化为计算转换，其中青蛙可以安全地跳到相邻列而不会发生冲突。 

最佳方法将网格视为一系列列，每个列的顶部或底部都有一只青蛙。 我们从左到右迭代。 如果顶行的青蛙在同一列中底行为空，则它无法通过垂直移动生存，因此只有当下一列包含底行的青蛙时才能生存，允许对角线移动。 我们保持“结转”状态，以确保不会有两只青蛙跳到同一个睡莲叶上。 这将问题减少到$O(n)$每个测试用例，因为每列都会检查一次。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(3^n) | O(3^n) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.初始化一个计数器`survivors = 0`。 这将容纳能够生存的青蛙数量。 
2. 从左到右迭代列。 对于每一列，检查顶行和底行中睡莲的位置。 
3. 如果两行都包含一只青蛙，则青蛙无法在该列中生存，因为它们没有相邻的睡莲叶可供跳跃。 移至下一列。 
4. 如果一排有一只青蛙，另一排是空的，那么青蛙就有可能生存。 检查下一列，看看青蛙是否可以在没有冲突的情况下跳到那里。 
5. 如果青蛙有一个对角或水平相邻的睡莲叶可以跳到而不发生冲突，则增加`survivors`并将该单元格标记为此移动已占用。 
6. 重复此操作，直至处理完所有列。 
7. 输出`survivors`对于测试用例。 

为什么有效：每只青蛙最多有两种可能的移动（垂直或水平）。 通过从左到右扫描并标记占据的目标单元，我们确保没有两只青蛙移动到同一个睡莲叶，尊重所有约束。 将青蛙移动到可用的相邻睡莲叶的贪婪选择可以最大化幸存者的数量，因为后面的青蛙无法在不发生冲突的情况下取代它。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    top = input().strip()
    bottom = input().strip()
    survivors = 0
    i = 0
    while i < n:
        if top[i] == '*' and bottom[i] == '*':
            i += 1
            continue
        if top[i] == '*' and bottom[i] == '.':
            if i+1 < n and bottom[i+1] == '*':
                survivors += 1
                i += 2
            else:
                i += 1
        elif top[i] == '.' and bottom[i] == '*':
            if i+1 < n and top[i+1] == '*':
                survivors += 1
                i += 2
            else:
                i += 1
    print(survivors)
```该解决方案遍历列。 如果青蛙位于单行中，并且相邻列允许跳跃而不会发生冲突，则我们会增加幸存者计数。 这`i += 2`确保我们跳过下一列（如果它用于容纳青蛙）。

 ## 边缘情况

 一列两行都有青蛙：```
**
..
```没有青蛙能够生存，算法正确地跳过了对这一列的计数。 

相邻行为空但被下一列阻挡的青蛙：```
*.
.*
```该算法检测到对角线跳跃是可能的，并将幸存者增加 1，然后跳过下一列以防止重复计数。 

最后一列有一只青蛙：```
..*
..
```右侧没有列。 青蛙没有相邻的睡莲叶可供跳跃并死亡，算法正确处理了这一点。
