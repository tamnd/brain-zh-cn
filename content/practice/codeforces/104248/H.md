 ## 解决方案
 ## 问题理解

 我们给出了三个数字，它们应该表示在固定三角形内部或边界上绘制的闭合多段线的三段长度。 折线正好有三段，并且该折线的每个顶点都必须位于三角形的一条边上。 此外，三角形的每一边必须至少包含这些顶点之一，因此折线被迫“接触”三角形的所有边。 

在所有这些有效的折线中，我们首先最小化所有三个线段的总长度。 如果多种结构达到相同的最小总长度，我们就会选择使线段长度的乘积最小化的结构。 该任务并不要求我们构建任何东西。 相反，我们只询问是否存在某个三角形，其生成的最佳折线的线段长度恰好等于给定的三元组 a、b、c。 

输入约束非常小，每个值都在负一千到一千之间。 这立即表明对三角形进行强力几何搜索是不可能的，但也表明答案可能是由三个数字的简单代数条件而不是任何显式几何决定的。 

一个关键的微妙之处是输入中允许负值。 由于几何中的线段长度始终为非负，因此任何有效的配置都必须具有非负的 a、b、c。 仅此一点就已经消除了许多情况。 

另一个隐藏的边缘情况是支撑该结构的三角形的简并性。 尽管要求原始三角形是非退化的，但折线约束只关心位于其两侧的点，并且优化有效地简化为关于三角形边界上的三个点如何连接成最短闭合链的推理。 许多幼稚的解释错误地假设任意几何形状，但答案实际上崩溃到一个更简单的条件。 

粗心的方法可能会尝试枚举三角形或顶点位置，但这将是不必要的且具有误导性，因为唯一有意义的自由度在最小化步骤之后消失。 

## 方法

 蛮力的想法是考虑一个带有坐标的三角形，在其边上放置三个点，以所有可能的循环顺序连接它们，并计算所得的折线长度，同时强制每条边至少被触摸一次。 对于每个三角形形状和位置，我们将测试最佳配置是否产生线段长度 a、b、c。 

这种方法理论上是正确的，但很快就会失败，因为三角形的空间是连续的。 即使我们离散化坐标，配置的数量也会以组合方式增长。 三边上三个点的每个放置都已经具有连续的自由度，并且最小化所有这些放置会导致不可数的搜索空间。 

关键的观察结果是，在最小化总长度后，最佳折线总是退化为仅取决于每条边在展开边界表示中“用作”直线段的次数的配置。 事实上，几何约束迫使折线表现得像由三角形边形成的树状结构上的最短闭合链。 这将问题简化为纯粹的代数条件：在适当的排序后，三个线段长度必须能够在不等式意义上形成一个有效的三角形，并且它们必须都是非负的。

直观上，最小化步骤消除了对实际三角形形状的依赖。 剩下的配置相当于以最短循环顺序连接凸边界上的三个点，这总是通过直线段来实现，直线段的行为类似于沿着平坦边界的欧几里德距离。 这导致了经典条件：排序后三元组必须满足三角形不等式。 

因此，整个几何设置崩溃为检查 a、b、c 是否可以解释为非简并三角形的边长，并附加所有必须为正的附加约束。

 ## 算法演练

 我们想要确定是否存在一种配置可以产生恰好等于 a、b、c 的段长度。 由于这些代表长度，因此第一个约束是非负性。 

第二个约束来自最小闭三段循环的结构：任何这样的循环在优化后都必须表现得像欧几里得空间中的三角形，因此段长度必须能够形成有效的三角形。 

### 步骤

 1. 读取三个整数a、b、c。 这些是折线的候选线段长度。 
2. 检查a、b、c 是否有一个为负数。 如果至少有一项是否定的，则立即断定该配置是不可能的。 负长度不能表示任何几何线段。 
3. 对值进行排序，使得 x ≤ y ≤ z。 排序允许我们用单个不等式表达所有必要条件，而不是检查排列。 
4. 验证 x + y ≥ z 是否成立。 这是三角形不等式条件，可确保三个线段可以闭合成一个循环，而不会强制“中断”或不可能的几何形状。 
5. 如果非负性和三角不等式都成立，则输出“Yes”。 否则输出“否”。 

### 为什么它有效

 原始构造中的优化迫使折线表现得像连接凸形状的三个边界点的最短闭合路径。 这样的路径不能有阻止闭合的“赤字角”，这正是通过违反三角不等式来捕获的。 如果最大的线段比其他两个线段的总和长，则任何几何实现都无法在不增加总长度超出最优性的情况下闭合环路，这与极小性相矛盾。 相反，只要三角形不等式成立，我们就可以将这些线段解释为形成有效的三角形边界配置，并且在实现这些精确线段长度的某些三角形上存在退化嵌入。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

a, b, c = map(int, input().split())

# all lengths must be nonnegative
if a < 0 or b < 0 or c < 0:
    print("No")
    sys.exit()

x, y, z = sorted([a, b, c])

# triangle inequality
if x + y >= z:
    print("Yes")
else:
    print("No")
```该解决方案首先过滤无效的负输入，因为几何形状禁止负段长度。 然后，它将条件简化为单个排序的不等式检查。 排序确保我们只需要测试三角不等式的一种情况，而不是所有排列。 

关键的实现细节是使用`>=`而不是`>`。 允许相等是因为在问题的最小化规则下，退化三角形仍然对应于有效的限制配置。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    a, b, c = map(int, input().split())

    if a < 0 or b < 0 or c < 0:

assert run("2 3 4\n") == "Yes"
assert run("-1 -1 -1\n") == "No"

 ## 边缘情况

 对于负输入，例如`-1 5 5`，算法在进行任何排序之前立即拒绝它们。 这可以避免在订购后将它们错误地解释为几何长度。 

对于像这样的退化情况`0 0 0`, 排序产生`(0, 0, 0)`和不平等`0 + 0 ≥ 0`成立，因此输出正确为“Yes”。 这符合折叠三角形仍然满足最小长度条件的解释。 

对于边界相等，例如`1 2 3`，排序给出`(1, 2, 3)`并且不等式完全成立。 这证实了在闭包条件下相等是可以接受的，这与简并三角形的实现是一致的。 

对于强烈不平衡的输入，例如`10 1 1`，排序给出`(1, 1, 10)`并且不平等失败了。 这正确地反映了没有任何配置可以闭合一个环，其中一个片段比其他两个片段的总和长，这将迫使总长度增加超过假定的最佳结构。
