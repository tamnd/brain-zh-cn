 ## 解决方案
 ## 问题理解

 我们得到一个非常大的整数区间$A$到$B$，我们从概念上计算该区间内每个整数的平方和。 因此，如果间隔很小，我们实际上会评估$$A^2 + (A+1)^2 + \dots + B^2$$然后取出所得数字并重复将其数字相加，直到只剩下一位数字。 最后一位数字就是答案。 

关键的困难不在于数根本身，而在于$A$和$B$可以大到$10^{10}$在幅度上。 这使得直接迭代完全不可能。 尺寸范围$10^{10}$已经需要$10^{10}$操作只是为了枚举值，这远远超出了任何合理的时间限制。 即使每个操作都非常便宜，规模也迫使我们用封闭形式或周期性推理代替迭代。 

另一个微妙的方面是间隔可能包含负数。 平方消除了符号，因此负值与正值表现对称，但这种对称性仅在我们正确构建总和时才有帮助。 当间隔跨越或完全低于零时，仅假设正范围的简单实现将默默地失败。 

边缘情况以三种典型形式出现。 首先，当$A = B$，答案就是简单的数字根$A^2$，并且任何假设非空扩展的范围处理逻辑可能仍然有效，但如果端点处理不一致，则很容易错误处理。 其次，当范围过零时，例如$[-2, 3]$，必须同时包括负方和正方的贡献； 忘记了$0^2 = 0$是无害的，但通常表明逻辑分裂不完整。 第三，当两个端点都为负时，例如$[-5, -2]$，在没有正确转换边界的情况下天真地使用“从 1 到 n 的总和”公式将产生不正确的减法顺序。 

最终的输出不是和本身，而是它的数字根，它仅取决于模 9 的值。一旦有效计算了平方和，该观察结果就成为主要的简化。 

## 方法

 蛮力方法将迭代自$A$到$B$, 积累$k^2$，然后重复计算数字和，直到剩下一个数字。 这在原则上是正确的，因为它直接遵循定义。 然而，范围长度可以达到$2 \cdot 10^{10}$，所以即使仅第一阶段也是不可行的。 与求和的成本相比，数根阶段可以忽略不计。 

关键的见解是我们永远不需要完整的数字。 某个区间上的平方和具有使用前缀平方和的标准公式的封闭式表达式：$$1^2 + 2^2 + \dots + n^2 = \frac{n(n+1)(2n+1)}{6}$$如果我们能够有效地计算前缀和，任何区间和都会减少为两个前缀值的减法。 唯一的复杂之处是正确处理负索引，这是通过分割零附近的范围并将负平方映射到正对应项来解决的。 

一旦知道了总和，就可以使用模 9 算术在恒定时间内计算出数字根。 由于数字根保留模 9 的等价类（通常调整为零），因此我们不需要计算超出确定模 9 余数所需的完整整数。

 ## 算法演练

 我们希望在不迭代的情况下计算可能为负区间的平方和。 

### 1. 定义正整数的前缀和函数

 我们定义一个函数$S(n)$这代表：$$S(n) = 1^2 + 2^2 + \dots + n^2$$为了$n \le 0$，我们定义$S(n) = 0$，这符合空和约定。 

这为我们通过分解处理所有范围提供了一个安全的基础。 

### 2. 将任意区间转换为正前缀和的组合

 我们处理区间$[A, B]$分三种情况。 

如果两个端点都是非负的，我们计算：$$S(B) - S(A-1)$$如果间隔过零，我们将其分为负数和非负数部分。 消极的部分$[A, -1]$使用对称性进行变换：$$k^2 = (-k)^2$$所以它变成了标准的正前缀和。 

如果两个端点都是负数，我们使用绝对值将段映射到反向正范围：$$[A, B] \rightarrow [-B, -A]$$并将其计算为前缀和的差值。 

### 3. 结合双方的贡献

 我们小心地添加负数侧和非负数侧的贡献，确保零在范围内时只包含一次。 

### 4. 计算数字根

 一旦总和$N$得到，我们计算：$$N \bmod 9$$规则是结果 0 对应于数字根 0（而不是 9），因为该问题使用标准迭代数字求和。 

### 为什么它有效

 正确性来自两个不变量。 首先，区间分解通过直接包含在正前缀和中或通过镜像负到正变换将每个整数保留一次。 其次，前缀和恒等式保证任何连续段都可以表示为两个前缀评估的差异，而没有重叠或遗漏。 由于平方消除了符号依赖性，因此从负索引的变换不会引入除索引反转之外的失真，这可以通过前缀减法完全补偿。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def S(n):
    if n <= 0:
        return 0
    return n * (n + 1) * (2 * n + 1) // 6

def range_sum_sq(a, b):
    if a > b:
        return 0
    return S(b) - S(a - 1)

def solve():
    A, B = map(int, input().split())

    total = 0

    if A <= 0 <= B:
        total += range_sum_sq(1, B)
        total += range_sum_sq(A, -1)
    elif B < 0:
        total += range_sum_sq(-B, -A)
    else:
        total += range_sum_sq(A, B)

    if total == 0:
        print(0)
        return

    print((total - 1) % 9 + 1)

if __name__ == "__main__":
    solve()
```该实现是围绕正方形的单个前缀函数构建的。 功能`S(n)`仅针对非负整数定义，这消除了求和逻辑中对任何特殊情况代数的需要。 每个间隔都减少为直接正范围或负范围的镜像版本。 

区间符号上的分支确保我们永远不会错误地混合变换。 过零情况明确区分负贡献和正贡献，以便两侧使用相同的前缀机制进行计算。 最终的数字根计算使用标准变换$(n-1) \bmod 9 + 1$，对零进行显式保护以避免将其映射到 9。

 ## 边缘情况

 对于像这样的单点区间$[3, 3]$，算法直接简化为$S(3) - S(2)$，生产$9$。 符号处理不存在歧义，因为不会触发过零逻辑。 

对于纯负范围，例如$[-5, -2]$，变换将它们映射到正区间$[2, 5]$。 前缀减法正确地重建了反转段，平方的对称性保证了正确性。 

对于跨越零的范围，例如$[-2, 2]$，两个分支独立贡献。 消极的一面有所贡献$1^2 + 2^2$，并且积极的一面贡献$1^2 + 2^2$，而零则没有任何贡献。 这种分割确保了没有重叠和没有遗漏，保留了精确的总和。
