 ## 解决方案
 ## 问题理解

 我们收到一系列讲座，每个讲座提供一些由整数值表示的知识。 对于每一次讲座，你都会做出两层决定：是否参加，以及是否在参加之前应用特殊的“冥想”效果。 

冥想状态会改变你从当前讲座中获得的知识量，但它也限制了连续使用它的频率。 如果你正常地参加讲座，你就会获得它的全部价值。 如果您在冥想下参加，您将获得双倍的价值，但冥想不能在连续的讲座中连续两次应用。 

任务是在尊重这一约束的同时最大化所有讲座的总知识，然后重建一个实现这一最大化的最佳决策序列。 

输入是讲座值列表。 输出是最大可能的总知识和实现它的有效选择序列。 

关键的难点在于，每次讲座的决定不仅取决于当前值，还取决于上一讲座是否使用冥想。 这会产生一种依赖关系，阻止贪婪选择的正确性，因为局部最优决策可能会阻止更好的未来配置。 

从约束的角度来看，预期的解决方案与讲座的数量呈线性关系。 随着每次讲座引入具有状态依赖性的分支决策，任何探索所有子集或模拟选择而无需记忆的方法都会呈指数增长。 对于大输入，即使是二次行为也会太慢，因为此类问题的典型限制最多允许大约 100000 个讲座。 

当所有讲座值为零或负数时，会出现微妙的边缘情况。 在这种情况下，人们会倾向于避免参加冥想或错误地过度使用冥想。 然而，由于每个讲座仍然是序列的一部分并且基于状态做出贡献，因此即使所有增益都是非正的，DP 仍然必须正确处理转换。 当交替高值和低值使得冥想仅对特定指数有用时，就会出现另一个边缘情况，这迫使仔细的状态跟踪而不是贪婪的交替。 

## 方法

 暴力解决方案将尝试所有可能的方法来为每个讲座分配正常出勤、冥想出勤或跳过冥想效果。 由于每个讲座都取决于先前的状态，因此这实际上变成了状态爆炸，其中每个位置都根据先前的选择进行分支。 在最坏的情况下，每个讲座都会导致多个有效的转换，从而产生指数数量的可能序列。 即使进行了修剪，依赖结构也意味着我们仍然会重复访问相同的前缀状态。 

问题的结构表明，讲座 i 的决策仅取决于讲座 i 的最佳结果减去两种可能状态下的 1。 这是小型有限状态空间上动态规划的经典标志。 我们没有跟踪完整的历史记录，而是将所有相关信息压缩为每个索引的两个值：如果上一讲没有经过冥想则为最佳结果，如果经过则为最佳结果。 

这减少了维护两个运行状态的问题。 每次转换都是在上一步的恒定时间内计算的，这将指数探索折叠为对数组的线性扫描。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| O(n) 递归深度 | 太慢了|
 | 最佳DP | O(n) | O(n) | 已接受 |

 ## 算法演练

 我们定义了两个由讲座位置 i 索引的 DP 数组。 一个代表如果我们在 i 处没有冥想，则在 i 之前可达到的最佳得分，另一个代表如果我们在 i 处冥想则可达到的最佳得分。

1. 将零位置处的两个状态初始化为零，因为没有处理任何讲座并且没有获得任何知识。 这奠定了复发的基础。 
2. 对于从 1 到 n 的每个讲座 i，通过考虑 i 减一时的两个先前状态来计算非冥想状态的最佳值。 我们取两者的最大值并添加当前的讲座值。 这反映出无论之前的行动如何，我们都可以正常参加，并且我们选择之前的状态会导致更好的累积结果。 
3. 对于i处的冥想状态，我们只能从i处的非冥想状态减一到达。 因此，我们从 i 减一中获取最佳非冥想结果，并加上当前讲座值的两倍。 这强制了冥想不能连续发生两次的约束。 
4. 将两个状态填充到 n 后，答案是两个最终状态中的最大值，因为最后一讲可能会也可能不会使用冥想。 
5. 为了重建序列，我们从在 n 处产生最佳答案的状态开始。 我们向后移动，通过比较 DP 值并遵循唯一有效的前驱关系，在每一步中决定状态是来自冥想还是非冥想转换。 

重建步骤依赖于跟踪必须使用哪个转换来实现最优值，从而有效地反转 DP 过程。 

它之所以有效，是因为在每个索引 i 处，两个 DP 状态都代表各自约束的最佳解决方案，与之前如何达到这些解决方案无关。 每个转换仅取决于 i 减一，因此一旦这些状态正确，扩展它们就可以保持最优性。 这创建了一个一致的最佳子结构，其中每个前缀都得到最佳解决，而无需重新考虑之前的决策。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))

    if n == 0:
        print(0)
        return

    dpO = [0] * (n + 1)
    dpM = [0] * (n + 1)

    for i in range(1, n + 1):
        dpO[i] = max(dpO[i - 1], dpM[i - 1]) + a[i - 1]
        dpM[i] = dpO[i - 1] + 2 * a[i - 1]

    if dpO[n] >= dpM[n]:
        state = "O"
        best = dpO[n]
    else:
        state = "M"
        best = dpM[n]

    print(best)

    res = []
    i = n
    cur = state

    while i > 0:
        if cur == "M":
            res.append("M")
            cur = "O"
            i -= 1
        else:
            if dpO[i - 1] >= dpM[i - 1]:
                res.append("O")
                cur = "O"
            else:
                res.append("O")
                cur = "M"
            i -= 1

    print(" ".join(reversed(res)))

if __name__ == "__main__":
    solve()
```该实现保持两个数组存储每个前缀的每个状态的最佳可能值。 转换逻辑直接反映了递归：非冥想状态采用先前状态的最佳状态加上当前值，而冥想状态仅强制从非冥想状态进行转换并使增益加倍。 

重建是向后进行的，利用这样一个事实，即冥想状态必须来自非冥想状态，而非冥想状态则选择两个可能的前身中更好的一个。 最后的逆转恢复了时间顺序。 

一个常见的实现陷阱是忘记 dpO 转换可以来自 dpM，这会错误地减少解决方案空间。 另一个微妙的问题是当 dpO[i - 1] 等于 dpM[i - 1] 时不正确的回溯，其中任一选择都是有效的，但必须与前向 DP 保持一致。 

## 工作示例

 考虑一个包含三个讲座的简单案例：3、1、2。 

转发DP：

 | 我| dpO| dpM | 解释|
 | --- | --- | --- | --- |
 | 1 | 3 | 6 | O = 0+3，M = 0+6 |
 | 2 | 7 | 8 | O = 最大(3,6)+1，M = 6+2 |
 | 3 | 10 | 10 14 | 14 O = 最大(7,8)+2，M = 8+4 |

 最好的结果是 14，最终状态为 M。回溯表明最后一步是冥想，在 i = 2 时强制先前的状态 O，依此类推。 

现在考虑 2、5、1。 

| 我| dpO| dpM | 解释|
 | --- | --- | --- | --- |
 | 1 | 2 | 4 | 基础转换|
 | 2 | 9 | 10 | 10 O = 最大(2,4)+5，M = 4+10 |
 | 3 | 11 | 11 18 | 18 O = 最大值(9,10)+1，M = 10+2 |

 这里的最优值是 18，是通过在最后一步使用冥想来实现的，它向后传播约束，并显示即使早期增益得到平衡，局部加倍也可以占据主导地位。 

这些痕迹证实每个状态在其约束下正确捕获最佳前缀值，并且只能通过状态传播而不是贪婪选择来验证最佳选择。

 ## 边缘情况

 对于值为 5 的单个讲座，DP 将 dpO1 初始化为 5，将 dpM1 初始化为 10。算法立即选择两者中较好的一个，从而使用冥想。 回溯正确地识别出这个状态一定来自于不存在的先前状态O0，这与初始化是一致的。 

对于像 0 0 0 这样的情况，两个转换总是产生零，但 DP 仍然传播有效状态。 dpO 和 dpM 之间的最终选择在值上保持任意，但在结构上保持一致，并且重建仍然产生有效的 O 状态交替序列，导致可选的 M 状态而不违反约束。 

对于像 1 100 1 这样的交替值，第二讲强烈支持冥想，这迫使 dpM2 占据主导地位。 DP 正确锁定了这一选择，并且向后重建强制第一讲必须处于 O 状态，从而演示了单个高值峰值如何通过状态依赖性来控制早期决策。
