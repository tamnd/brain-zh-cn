 ## 解决方案
 ## 问题理解

 系统的每个维度的行为就像一个独立的一维随机游走。 船从位置开始$a_i$在维度上$i$，虽然系统在该维度上不稳定（意味着坐标至少为 1），但它以概率向右移动一步$p_i$并有概率还剩下一步$q_i = 1 - p_i$。 当坐标严格小于 1 时，该维度就被视为恢复并停止演化。 

任务是从初始位置向量开始，计算每个维度最终至少达到“恢复”状态一次的概率。 

由于每个维度独立演化，全局事件是独立事件的交集。 这立即表明答案会影响到每维概率的乘积，每个概率都是从$a_i$曾经达到0。 

这些限制使得直接模拟变得不可能。 每个坐标最多可达 1000，概率是具有大分子和分母的分数，最大可达$10^9$，因此任何朴素的蒙特卡罗或逐步模拟都不会及时收敛。 该结构强烈建议每个维度进行封闭形式的概率计算。 

当行走完全偏向右侧时，会出现微妙的边缘情况，这意味着$p_i = 1$。 在这种情况下，步行永远不会减少，因此任何起始位置$a_i > 0$使恢复变得不可能。 相反，如果行走偏左或足够不偏，恢复就一定会发生。 正确处理这些边界情况至关重要，因为当概率为 0 或 1 时，涉及除法的直接公式可能会失效。 

## 方法

 蛮力方法将多次独立地模拟每个维度的随机游走，并估计它是否达到零。 即使我们尝试通过状态动态规划来计算精确的概率$[0, 1000]$，可以对转换进行建模，但问题是概念性的而不是计算性的：如果我们允许无限制地向上移动，则状态空间是无限的，并且截断会引入错误。 即使每个维度限制为 2000 个状态，整体复杂性也变为$O(n \cdot m^2)$，对于$n = 1000$。 

关键的观察结果是，每个维度都是无限半线上的经典赌徒破产问题。 我们只关心从 开始达到 0 的概率$a_i$。 对于有偏随机游走：

 如果$p_i \le q_i$，行走的偏向足够左，以至于它会以 1 的概率到达 0。如果$p_i > q_i$，向右漂移，并且达到 0 的概率变为$(q_i / p_i)^{a_i}$。 这来自解决马尔可夫链中命中概率的标准递归。 

一旦每个维度都减少到一个封闭形式的值，最终的答案就是所有维度的乘积。

 | 模拟/DP | O(n·S²) | O(n·S²) | O(S)| 太慢了|
 | 每个维度的闭合形式 | O(n log MOD) | O(n log MOD) | O(1) | O(1) | 已接受 |

 ## 算法演练

 ### 1.将每个概率转换为分数形式

 对于每个维度，请阅读$p_i = \frac{s_i}{t_i}$并计算$q_i = \frac{t_i - s_i}{t_i}$。 

这提供了一个干净的表示，其中可以精确地以整数进行比较和比率。 

### 2.判断吸收是否确定

 如果$p_i \le q_i$, 等价地$2s_i \le t_i$，那么步行最终以 1 的概率到达 0。 

这是因为没有漂移将过程推离 0。 

### 3. 处理完全右偏的情况

 如果$s_i = 0$， 然后$p_i = 0$，所以行走总是向左移动并且吸收是确定的。 

如果$s_i = t_i$， 然后$p_i = 1$，所以行走永远不会向左移动并且吸收是不可能的，除非$a_i = 0$，它被约束排除。 

### 4. 计算正确漂移情况下的击中概率

 如果$p_i > q_i$，使用公式：$$\left(\frac{q_i}{p_i}\right)^{a_i}
= \left(\frac{t_i - s_i}{s_i}\right)^{a_i}$$我们使用模幂和模逆来计算模数。 

### 5. 将所有维度概率相乘

 由于维度是独立的，因此将所有每维度概率乘以模$10^9+7$。 

### 为什么它有效

 每个维度作为马尔可夫链独立演化，其吸收事件为“命中0”。 吸收的概率仅由漂移方向决定。 当漂移为非正值时，复发保证最终吸收。 当漂移为正时，求解击中概率的重现会在起始位置产生指数衰减。 维度独立将联合事件转化为标量概率的乘积，而模运算准确地保留了这种结构。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modexp(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n = int(input())
a = list(map(int, input().split()))

ans = 1

for i in range(n):
    s, t = map(int, input().split())

    if s == 0:
        continue

    if s * 2 <= t:
        continue

    q = t - s

    ratio = q * pow(s, MOD - 2, MOD) % MOD
    ans = ans * modexp(ratio, a[i]) % MOD

print(ans)
```该解决方案独立读取每个维度，并立即将其减少为标量概率贡献。 的模逆$s$用于形成$q/p$在模运算下。 快速求幂处理功率$a_i$，最大可达 1000，使解保持在限制范围内。 

比较时一定要注意$2s \le t$，这完全避免了除法并防止精度问题。 案例$s = 0$提前分离是因为模逆会被破坏。

 ## 边缘情况

 一个关键的边缘情况是当$s_i = 0$。 在这种情况下，步行总是向左移动，因此无论什么情况它都会立即达到 0$a_i$。 该算法完全绕过模求逆，直接将 1 贡献给乘积。 

另一个边缘情况是当$s_i = t_i$。 步行永远不会向左移动，所以如果$a_i > 0$，概率为 0。条件$2s_i > t_i$正确地触发几何公式，但因为$t_i - s_i = 0$，比率变为 0，并且任何正指数都会产生 0，这符合正确的行为。 

最后是阈值情况$2s_i = t_i$表示对称随机游走。 该算法将其分类为概率 1，它与非负整数上的无偏随机游走的递归性质相匹配，其中 0 处的吸收是确定的。
