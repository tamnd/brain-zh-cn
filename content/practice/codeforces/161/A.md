 ## 解决方案
 ## 问题理解

 我们的任务是为尽可能多的士兵配备防弹背心。 每个士兵都有自己偏好的背心尺寸，但他们愿意容忍给定范围内的偏差。 具体来说，第 i 个士兵可以穿尺寸介于`a[i] - x`和`a[i] + y`。 可用的背心有固定的尺寸，每件背心只能分配给一名士兵。 目标是输出最大数量的可装备士兵，并为士兵分配背心。 

输入规模很大：多达 100,000 名士兵和 100,000 件背心。 一个简单的解决方案是检查每个士兵的每件背心，最多需要 10^10 次比较，这对于 3 秒的时间限制来说远远超出了可接受的范围。 因此，我们需要一个在线性或接近线性时间内工作的解决方案，理想情况下`O(n + m)`或者`O(n log n + m log m)`。 

当多名士兵都穿着同一件背心时，就会出现微妙的边缘情况。 例如，如果两名士兵都接受 3 号尺寸，并且可用背心仅包括一件 3 号背心，则算法必须选择首先分配哪个士兵。 粗心的实施可能会错过可能的任务或尝试重复使用相同的背心。 

另一个极端情况是士兵的可接受范围超出了所有可用的背心。 例如，如果一个士兵的可接受范围是 1-100，但所有背心的尺寸都是 101 或更大，则无法分配任何背心，并且算法必须正确跳过该士兵。 

## 方法

 暴力方法很简单：对于每个士兵，扫描所有可用的背心，看看是否有任何落入其可接受的范围内。 如果找到兼容的背心，请将其标记为已使用并继续。 这种方法原则上是正确的，因为它检查了每一种可能性，但效率极低。 对于最大约束，可能需要最多 10^10 次比较，这太慢了。 

关键的观察是士兵和背心都是按非递减顺序给出的。 这种结构允许采用两指针方法，其中我们维护一个用于士兵的指针和一个用于背心的指针。 在每一步中，我们都会检查当前的背心是否适合当前的士兵。 如果是，我们分配它并推进两个指针。 如果背心对于士兵来说太小，我们会将背心指针提前。 如果背心太大，我们就将士兵指针提前。 这种贪婪策略之所以有效，是因为士兵和背心是排序的：一旦背心对于当前士兵来说太大，它就无法适合任何先前的士兵，而一旦背心太小，它就无法适合任何后来的士兵。 

这将时间复杂度从 O(n * m) 降低到 O(n + m)，并且只需要线性额外空间来存储分配。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * m) | O(1) | O(1) | 太慢了 |
 | 两点贪心 | O(n + m) | O(min(n, m)) | 已接受 |

 ## 算法演练

 1.初始化两个指针，`i`对于士兵和`j`对于背心，都从 0 开始。另外，初始化一个空列表`assignments`存储最终的对。 
2. 当两个指针都在范围内时，检查当前背心尺寸`b[j]`反对当前士兵的可接受范围`[a[i] - x, a[i] + y]`。 
3.如果`b[j]`小于`a[i] - x`，前进马甲指针`j`因为这件背心不适合这位或任何后来需要至少`a[i] - x`。 
4.如果`b[j]`大于`a[i] + y`, 推进士兵指针`i`因为没有剩余的背心可以容纳这个士兵。 
5.如果`b[j]`是在`[a[i] - x, a[i] + y]`，通过附加将这件背心分配给该士兵`(i + 1, j + 1)`到`assignments`，然后前进两个指针。 
6. 继续，直到其中一个指针到达其各自列表的末尾。 
7.输出长度`assignments`其次是成对的。 

这样做的原因是，贪婪地选择最小的兼容背心可以确保后来的士兵有最好的机会找到背心。 保持不变的是所有分配的背心都是兼容的并且只能使用一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m, x, y = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

i = j = 0
assignments = []

while i < n and j < m:
    if b[j] < a[i] - x:
        j += 1
    elif b[j] > a[i] + y:
        i += 1
    else:
        assignments.append((i + 1, j + 1))
        i += 1
        j += 1

print(len(assignments))
for soldier, vest in assignments:
    print(soldier, vest)
```该代码遵循两指针算法。 我们根据士兵的可接受范围仔细检查每件背心，并根据比较增加正确的指针。 通过在附加到时将基于 0 的索引转换为基于 1 的索引，可以避免差一错误`assignments`。 使用`sys.stdin.readline`确保大型数据集的快速输入。

## 测试用例```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m, x, y = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    i = j = 0
    assignments = []
    while i < n and j < m:
        if b[j] < a[i] - x:
            j += 1
        elif b[j] > a[i] + y:
            i += 1
        else:
            assignments.append((i + 1, j + 1))
            i += 1
            j += 1
    out = [str(len(assignments))] + [f"{s} {v}" for s,v in assignments]
    return "\n".join(out)

# provided samples
