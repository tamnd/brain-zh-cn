 ## 解决方案
 ## 问题理解

 我们有一系列在超市出售的物品。 每个项目都有价格和类型。 类型`1`表示该物品是凳子，类型`2`意味着它是一支铅笔。 

波利卡帕斯 (Polycarpus) 完全拥有`k`购物车，每个购物车必须至少包含一件商品。 商店促销活动称，如果推车中至少包含一个凳子，则推车中最便宜的商品可享受 50% 的折扣。 

任务不仅仅是计算可能的最低总价。 我们还必须将有效的物品分配输出到购物车中，以达到这一最小值。 

主要的困难是折扣适用于每辆购物车，而不是每张凳子。 一辆有十个凳子的购物车仍然只能享受一次折扣，即该购物车中最便宜的商品。 这立即表明，将凳子分布在多个推车上可能是有用的，因为每个这样的推车都会创建另一个折扣商品。 

约束足够小`O(n log n)`甚至`O(n^2)`解决方案是完全安全的。 这里`n ≤ 1000`，所以排序无论如何都会主导运行时。 然而，彻底的分区是不可能的，因为将物品分配到购物车的方式数量呈指数级增长。 

一些边缘情况很容易处理不当。 

假设所有物品都是铅笔。```
3 2
5 2
7 2
1 2
```没有购物车可以享受折扣，因为折扣需要凳子。 最佳答案就是所有价格的总和。 假设每辆购物车都获得折扣的粗心实现会减少太多。 

当粪便数量小于`k`。```
4 3
10 1
9 2
8 2
7 2
```凳子只有一张，最多一辆推车可以激活促销。 剩余的手推车仍然必须是非空的，这迫使我们将铅笔单独放在一些手推车中。 

相反的情况也很有趣。```
5 2
100 1
90 1
1 2
1 2
1 2
```一个幼稚的策略可能会将所有凳子放在一起。 这只提供一次折扣。 更好的策略是将凳子分开推车，这样两辆推车都能获得折扣。 

最后，打折商品始终是购物车中最便宜的商品。 当将项目分组在一起时，这一点很重要。```
3 1
10 1
100 2
1 2
```如果所有商品都放入一个购物车，则折扣适用于铅笔价格`1`，不是凳子价`10`。 任何假设凳子本身会打折的推理都是不正确的。 

## 方法

 蛮力的想法是尝试将所有可能的项目分配到`k`购物车，计算最终的总价格，并保持最佳排列。 

这是有效的，因为评分规则很容易评估。 对于每辆推车，我们都会检查其中是否装有凳子。 如果是这样，我们会减去该购物车中最低价格的一半。 

问题是作业的数量。 每个`n`项目可以进入其中之一`k`购物车，大致给出`k^n`的可能性。 和`n = 1000`，这是完全不可能的。 

为了更快地设计东西，我们需要了解真正创造价值的东西。 

仅当存在凳子时才会触发折扣。 由于每辆推车最多可获得一次折扣，因此我们希望尽可能多的推车带有凳子。 更具体地说，如果我们可以将凳子隔离在其自己的购物车中，那么该购物车中最便宜的商品正是该凳子，因此我们可以节省其价格的一半。 

这一观察完全改变了问题。 

假设我们有`s`凳子。 那么至多`min(s, k)`购物车可以享受折扣。 为了最大化总折扣，我们应该选择最昂贵的凳子单独放在单独的推车中，因为每个单独的凳子都贡献`price / 2`节省。 

为什么凳子贵？ 因为一旦凳子单独存在，它本身的价格就变成了折扣金额。 一张凳子的价格`100`给予折扣`50`，而凳子的价格`2`只给出`1`。 

这会导致贪婪的构造。 

我们按价格降序对凳子进行排序。 然后我们使用最昂贵的凳子制作单人推车，最多`k - 1`推车。 最后一个购物车接收所有剩余的物品。 

为什么只有`k - 1`单人推车？ 因为每辆购物车都必须是非空的，而剩余的物品需要有地方去。 

最后的推车可能仍然含有粪便。 如果是这样，它也会获得一次折扣，但仅限于最便宜的商品。 这会自动发生。 

整个问题变成了一个建设性的贪婪安排加上仔细计算折扣。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数| 指数| 太慢了 |
 | 最优贪心 + 排序 | O(n log n) | O(n log n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读所有项目并将其分成凳子和铅笔，同时保留其原始索引。 
2. 计算所有价格的总和。 我们将从总数中减去折扣。 
3. 按价格降序对凳子进行排序。 
4. 创建最多`min(number_of_stools, k - 1)`推车，每辆推车只包含一张凳子，从最昂贵的凳子开始。 

每辆这样的购物车保证折扣相当于该凳子价格的一半。 隔离昂贵的粪便可以最大限度地节省数量。 
5. 将所有剩余物品放入最终购物车中。 

这包括所有铅笔和之前未隔离的任何凳子。 
6. 如果最终购物车包含至少一个凳子，请找到该购物车内的最低价格，并应用等于该最低价格一半的最终折扣。 

商店规则只对装有凳子的购物车中最便宜的商品进行折扣。 
7. 打印最小总价和购物车内容。 

### 为什么它有效

 关键的不变量是每辆带有凳子的购物车最多只能贡献一件折扣商品。 如果一辆购物车只包含一张凳子，那么该凳子本身就成为打折商品。 由于折扣与商品价格成正比，因此将最昂贵的凳子分配到单独的购物车中可以最大限度地减少总折扣。 

任何将两个昂贵的凳子组合到同一个推车中的安排都会浪费一个潜在的折扣。 将其中一张凳子移到另一辆推车中只会增加或保持总节省。 

最后的购物车是不可避免的，因为所有剩余的物品都必须放置在某个地方。 它的折扣完全由里面价格最低的商品决定，所以一旦昂贵的凳子已经被隔离出来，就不需要进一步的优化。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())

    items = []
    stools = []
    pencils = []

    total = 0

    for i in range(1, n + 1):
        c, t = map(int, input().split())

        items.append((c, t, i))
        total += c

        if t == 1:
            stools.append((c, i))
        else:
            pencils.append((c, i))

    stools.sort(reverse=True)

    carts = []

    used = set()

    single_cnt = min(len(stools), k - 1)

    discount = 0.0

    for i in range(single_cnt):
        price, idx = stools[i]

        carts.append([idx])
        used.add(idx)

        discount += price / 2.0

    last_cart = []

    last_has_stool = False
    last_min_price = float('inf')

    for c, t, idx in items:
        if idx in used:
            continue

        last_cart.append(idx)

        if t == 1:
            last_has_stool = True

        last_min_price = min(last_min_price, c)

    if last_has_stool:
        discount += last_min_price / 2.0

    carts.append(last_cart)

    answer = total - discount

    print(f"{answer:.1f}")

    for cart in carts:
        print(len(cart), *cart)

solve()
```解决方案首先将物品分成凳子和铅笔，同时保留原始索引。 输出中需要这些索引，因此在排序过程中丢失它们将使重建变得困难。 

贪婪部分依赖于按降序对凳子进行排序。 最昂贵的凳子首先被提取，因为孤立的推车将凳子本身变成了折扣商品。 

变量`single_cnt`值得关注。 我们最多创造`k - 1`单个推车，因为一辆推车必须可用于存放所有剩余物品。 如果我们创建了`k`虽然物品仍然存在，但有些物品将无处可去。 

最终的购物车收集了所有未使用的物品。 在此过程中，代码还会跟踪购物车是否包含凳子及其最低价格是多少。 这是必要的，因为折扣适用于购物车中最便宜的商品，无论类型如何。 

答案保持为浮点，因为折扣将价格除以二。 该语句要求小数点后正好一位数字，因此最终打印使用`:.1f`。

 ## 边缘情况

 考虑没有凳子存在的情况。```
3 2
5 2
7 2
1 2
```该算法创建零个单例凳子车，因为凳子列表为空。 每件商品都会进入最终购物车。 由于最后一辆推车也没有凳子，因此不适用折扣。 The answer becomes`5 + 7 + 1 = 13`。 

现在考虑一下凳子比手推车少。```
4 3
10 1
9 2
8 2
7 2
```只有一张凳子，因此只有一辆购物车可以激活促销。 该算法将凳子隔离到自己的购物车中，从而产生折扣`5`。 剩余的商品占据最后一个购物车并且没有折扣。 总成本变为`34 - 5 = 29`。 

当混合购物车中最便宜的物品是铅笔时，就会出现另一种微妙的情况。```
3 1
10 1
100 2
1 2
```所有物品必须放入一辆推车中。 由于购物车包含凳子，因此最便宜的商品可以获得折扣。 最便宜的商品是铅笔价格`1`，不是凳子价`10`。 该算法正确跟踪购物车内的最低价格并仅减去`0.5`。 

最后，考虑许多价格不同的凳子。```
5 3
100 1
90 1
5 1
1 2
1 2
```该算法隔离了定价的粪便`100`和`90`，创造折扣`50`和`45`。 剩余凳子定价`5`与铅笔一起进入最后的购物车，从而获得额外的折扣`0.5`。 任何将昂贵的凳子组合在一起的安排都会失去一个大折扣并产生更糟糕的结果。
