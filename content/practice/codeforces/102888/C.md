 ## 解决方案
 ## 问题理解

 显示屏由以下部分组成`n`七段数字，但只有数字`0`,`2`,`5`,`6`,`8`， 和`9`可能会出现，因为其他部分已损坏。 

将整个显示屏旋转 180 度后，会同时发生两件事。 数字的顺序颠倒过来，每个数字按照旋转进行变换。 有效的映射是：`0 ↔ 0`,`2 ↔ 2`,`5 ↔ 5`,`8 ↔ 8`,`6 ↔ 9`。 

旋转之前和之后都允许使用前导零。 

任务是计算有多少长度`n`此轮换后数字字符串保持完全相同。 自从`n`最多可以有`10^10`十进制表示中的数字？ 不。该声明的意思是`n < 10^10`， 所以`n`其本身的规模就可以达到百亿左右。 对于任何单独处理每个位置的算法来说，这样的值太大了。 任何复杂度与`n`是不可能的。 答案必须从直接的数学公式中获得，并使用快速求幂来计算。 

一个容易犯的错误是忘记旋转会颠倒数字的顺序。 例如，当`n = 2`, 字符串`69`是有效的，因为它变成了`69`反转并交换后再次`6`和`9`。 在每个位置独立处理映射会错误地拒绝它。 

另一个微妙的情况是奇数位数。 用于输入```
1
```唯一有效的数字是`0`,`2`,`5`， 和`8`，所以正确答案是`4`。 粗心的实施也可能会导致`6`或者`9`，即使它们在旋转后变成了另一个。 

第三种边缘情况是前导零。 用于输入```
2
```字符串`00`是完全有效的并且必须被计算在内。 拒绝前导零会产生错误的答案。 

## 方法

 最直接的解决办法就是枚举每一个可能的长度`n`字符串覆盖六个可用数字，旋转它，并将结果与​​原始字符串进行比较。 这是正确的，因为每个候选人都经过明确检查。 不幸的是有`6^n`候选人，这是完全不可行的。 甚至`n = 30`已经需要超过`2 × 10^23`检查。 

关键的观察结果是每个位置仅与其镜像位置相互作用。 如果位置`i`包含数字`x`，然后定位`n - 1 - i`被迫包含旋转形式`x`。 

对于每个镜像对，正好有六个有效分配：`(0,0)`,`(2,2)`,`(5,5)`,`(8,8)`,`(6,9)`,`(9,6)`。 

每对都独立于其他对，所以如果有`⌊n/2⌋`成对，他们贡献`6^(⌊n/2⌋)`的可能性。 

如果`n`为奇数，中间保留一位数字。 由于反转不会移动它，因此它必须向自身旋转。 仅有的`0`,`2`,`5`， 和`8`满足这个条件，给出四种选择。 

答案很简单`6^(n/2)`什么时候`n`是偶数，

 和`6^(n/2) × 4`什么时候`n`很奇怪。 

自从`n`非常大，指数是用二进制求幂模计算的`998244353`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(6^n)$|$O(n)$| 太慢了 |
 | 最佳|$O(\log n)$|$O(1)$| 已接受 |

 ## 算法演练

 1.读取整数`n`。 
2. 计算`pairs = n // 2`。 每个镜像对都可以独立选择。 
3. 计算`ans = 6^pairs mod 998244353`使用快速模幂。 
4.如果`n`是奇数，相乘`ans`经过`4`模数`998244353`，因为中心数字必须是其中之一`0`,`2`,`5`， 或者`8`。 
5、输出`ans`。 

### 为什么它有效

 对于每个镜像对，选择左边的数字通过旋转映射唯一地确定右边的数字。 一对的选择不会影响任何其他对，因此有效字符串的总数是每对选择数量的乘积。 当长度为奇数时，中间位置映射到自身，因此只允许自旋转数字。 这是唯一的限制，因此计数公式是准确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

n = int(input())

ans = pow(6, n // 2, MOD)
if n % 2:
    ans = ans * 4 % MOD

print(ans)
```该程序首先计算存在多少个镜像对。 Python 内置的`pow(base, exp, mod)`执行二进制求幂`O(log exp)`时间，这是至关重要的，因为`n`可能非常大。 

唯一剩下的情况是奇数长度显示。 中心位置在倒车后不会改变其位置，因此它必须包含一个自旋转数字。 乘以四就可以解释这些可能性。 

不需要对前导零进行特殊处理，因为计数参数已经自然地包含它们。

 六个有效字符串是`00`,`22`,`55`,`69`,`88`， 和`96`。 该跟踪显示每个镜像对恰好有六个合法分配。

## 测试用例```python
# helper: run solution on input string, return output string
import sys
import io

MOD = 998244353

def solve():
    input = sys.stdin.readline
    n = int(input())
    ans = pow(6, n // 2, MOD)
    if n % 2:
        ans = ans * 4 % MOD
    print(ans)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()
    solve()
    out = sys.stdout.getvalue()
    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return out

# basic cases
assert run("1\n") == "4\n", "length 1"
assert run("2\n") == "6\n", "length 2"

# custom cases
assert run("3\n") == "24\n", "odd length"
assert run("4\n") == "36\n", "two mirrored pairs"
assert run("5\n") == "144\n", "odd with two pairs"
assert run("10000000000\n") == str(pow(6, 5000000000, MOD)) + "\n", "very large n"
```| 测试输入| 预期产出 | 它验证了什么 |
 | --- | --- | --- |
 |`3`|`24`| 中心数字处理。 |
 |`4`|`36`| 多个独立的镜像对。 |
 |`5`|`144`| 配对计数与中心数字相结合。 |
 |`10000000000`|`6^5000000000 mod 998244353`| 有效处理极大指数。 |

 ## 边缘情况

 用于输入```

```该算法计算零镜像对，给出`6^0 = 1`。 因为长度是奇数，所以乘以四并返回`4`。 数字`6`和`9`被排除，因为旋转后两者都没有改变。 

用于输入```
2
```该算法计算一对镜像并返回`6`。 这六种可能性之一是`00`，表明无需任何特殊逻辑即可正确计算前导零。 

用于输入```
2
```有效对`(6,9)`贡献六个选择之一。 由于该算法计算镜像分配而不是独立检查位置，因此诸如`69`和`96`只包含一次。
