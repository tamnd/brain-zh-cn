 ## 解决方案
 ## 问题理解

 三角形始终是直角三角形，其直角为$(x_0, y_0)$。 它的另外两个顶点是$(x_0 + a, y_0)$和$(x_0, y_0 + b)$。 我们必须选择一条垂直线$x = c$， 在哪里$x_0 \le c \le x_0 + a$，使得线左边的三角形部分和右边的部分具有完全相同的面积。 

输入给出三角形的位置及其尺寸。 输出是单个浮点值$c$。 任何在所需浮点容差范围内的答案都被接受。 

界限非常小。 每个坐标的大小最多为 1000，两侧长度最多为 1000。由于只有一个三角形，即使是迭代数值方法也能轻松满足限制。 即便如此，几何形状仍具有封闭式解，因此可以在恒定时间内解决问题，而无需任何迭代。 

主要困难在于左侧区域不随切割位置线性增长。 假设沿底部的中点也将面积减半是不正确的。 

考虑输入```
0 0 1 1
```正确答案大约是```
0.292893218...
```切割于$x = 0.5$在左侧留下更大的区域，因为当我们向右移动时，三角形会变得更短。 

另一个容易犯的错误是忘记三角形可能不是从原点开始的。 

例如，```
100 200 4 5
```答案不是直接从区间计算出来的$[0,4]$。 在局部坐标中求解后，必须通过添加将结果移回$x_0$。 

第三个常见错误是使用整数运算。 

例如，```
0 0 3 2
```答案是不合理的。 整数除法或过早截断会产生明显不正确的剪切位置。 

## 方法

 直接数值方法是对切割位置进行二分查找。 对于任何候选人$c$，我们计算左侧的面积，将其与总面积的一半进行比较，并调整搜索间隔。 由于随着剪切向右移动，左侧区域不断增加，因此二分查找是正确的。 大约六十次迭代已经给出了远远高于所需的精度，因此这种方法在恒定时间内运行。 

有趣的部分是推导面积公式。 让$$t = c - x_0,$$以便$t$测量距三角形左侧的水平距离。 

斜边连接$(0,b)$和$(a,0)$在局部坐标系中，所以其方程为$$y = b\left(1-\frac{x}{a}\right).$$三角形左边的部分$x=t$是一个梯形，其平行边有高度$$b,\qquad b\left(1-\frac{t}{a}\right).$$其面积为$$S_{\text{left}}
=
\frac{
b+b\left(1-\frac{t}{a}\right)
}{2}
\cdot t
=
bt-\frac{bt^2}{2a}.$$三角形总面积为$$\frac{ab}{2},$$因此将左侧面积设置为总面积的一半即可得到$$bt-\frac{bt^2}{2a}
=
\frac{ab}{4}.$$除以$b$并重新排列，$$2t-\frac{t^2}{a}
=
\frac{a}{2},$$或者$$t^2-2at+\frac{a^2}{2}=0.$$区间内的有效根$[0,a]$是$$t=a\left(1-\frac{1}{\sqrt2}\right).$$最后，$$c=x_0+t.$$这会立即产生答案。

 ## 算法演练

 1. 阅读$x_0$,$y_0$,$a$， 和$b$。 仅有的$x_0$和$a$影响答案，因为每个垂直横截面都与$b$。 
2. 计算水平偏移$$t=a\left(1-\frac{1}{\sqrt2}\right).$$这是通过求解二次方程得到的，使左侧面积正好是总面积的一半。 
3. 计算$$c=x_0+t.$$这会将局部坐标转换回原始坐标系。 
4. 将结果打印为浮点数。 

### 为什么它有效

 三角形的高度从左到右线性减小，因此累加面积是一次函数的积分，是一个二次表达式。 求解总面积的一半的二次方程给出了区间内的唯一解$[0,a]$。 由于每次推导都是精确的，计算值总是将三角形分为两个等面积的区域。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

x0, y0, a, b = map(int, input().split())

c = x0 + a * (1.0 - 1.0 / math.sqrt(2.0))

print(c)
```程序首先读取四个整数。 尽管输入包括坐标和两侧长度，但最终公式中仅出现水平位置和水平长度。 

计算使用从面积方程导出的封闭式表达式。 使用`math.sqrt`保持浮点计算，这很容易满足所需的误差容限。 

最后，程序直接打印答案。 不需要特殊的格式，因为 Python 的默认浮点输出已经提供了足够的精度。

import io
import math
import sys

def solve():
    input = sys.stdin.readline
    x0, y0, a, b = map(int, input().split())

def run(inp: str) -> str:
    backup_stdin = sys.stdin

    solve()
    sys.stdin = backup_stdin

 ## 边缘情况

 考虑可能的最小三角形：```
0 0 1 1
```该算法计算$$t=1-\frac1{\sqrt2},$$所以答案大约是`0.2928932188`。 这与精确的等面积切割相匹配，而不是与不正确的中点相匹配`0.5`。 

现在考虑一个平移的三角形：```
100 200 4 5
```本地解决方案是$$4\left(1-\frac1{\sqrt2}\right)\approx1.171572875.$$添加水平偏移量得出```
101.171572875...
```平移仅影响最终的添加，使几何形状保持不变。 

最后，考虑一个答案不合理的情况：```
0 0 3 2
```该算法计算$$3\left(1-\frac1{\sqrt2}\right)\approx0.878679656.$$使用浮点运算可以保留所需的精度，而整数运算会错误地舍入结果并使判断失败。
