 ## 解决方案
 ## 问题理解

 我们得到了值的计数`1..k`。 价值`i`必须准确出现`a_i`次。 允许使用空单元格并表示为`0`。 

我们必须将所有副本放入`n × n`矩阵并最小化`n`。 每一个`2 × 2`子矩阵必须满足两个条件。 

第一个条件是在它的四个单元中，最多可以有三个被占用。 每一个`2 × 2`块必须至少包含一个零。 

第二个条件是每条对角线上的两个单元格不能包含相同的数字。 

输入描述了一组数字。 输出是一个方阵，其中恰好包含这些数字和任意数量的空单元格。 

数据总量很大。 单个测试最多可以包含`2 · 10^5`数字，以及总和`m + k`测试也受以下限制`2 · 10^5`。 任何重复扫描整个矩阵以查找每个值的解决方案都太慢了。 我们需要一种结构，其总工作基本上与我们实际填充的单元格数量成正比。 

从声明中看不出来危险情况。 

考虑一个出现多次的值。```
m = 8
a = [8]
```一个天真的想法是找到一个具有足够非零单元的矩阵。 这还不够。 数量相等还必须避免对角线冲突。 最大频率创建了一个额外的下限`n`。 

另一个微妙的情况是当矩阵几乎满时。```
m = 15
```一个`4 × 4`矩阵有 16 个单元，但每个单元`2 × 2`块需要一个零。 不可能使用全部 16 个电池。 施工时必须预留足够的空位。 

第三个陷阱是将一个值拆分到矩阵的不同区域。 如果不小心，相同值的副本可能会出现在某些对象的两条对角线上`2 × 2`堵塞。 最终的结构设计为最多有一个值跨越两个区域之间的边界，甚至该值仍然是安全的。 

## 方法

 蛮力的观点是寻找最小的`n`，然后尝试放置数字，同时检查每个`2 × 2`堵塞。 即使我们以某种方式修复了`n`，分配至`2 · 10^5`将项目放入矩阵位置，同时不断验证局部约束很快就会变成组合。 没有现实的方法来探索展示位置。 

关键的观察结果是局部约束表明了固定的几何图案。 

取出行索引为奇数的所有单元格。 调用此设置`A`。 

取出行索引为偶数的所有单元格。 调用此设置`B`。 

任意对角线`2 × 2`块总是连接一个单元格`A`和一个细胞来自`B`。 

如果一个数字完全放在里面`A`，该数字的副本永远不会在对角线上相遇。 对于完全放在里面的数字也是如此`B`。 

这就把问题变成了能力问题。 一个地区可以容纳多少份？ 

地区`A`包含`n * ceil(n / 2)`细胞。 

地区`B`包含`n * floor(n / 2)`细胞。 

如果每个值都限制在一个区域，对角线冲突就会自动消失。 

最大频率必须适合一个区域，所以我们需要`max(a_i) ≤ n * ceil(n / 2)`。 

第一个条件，要求每个都为零`2 × 2`块，可以通过将一个类似棋子的子模式的所有单元格留空来满足。 最大可用单元数变为`n² - floor(n / 2)²`。 

因此我们还需要`m ≤ n² - floor(n / 2)²`。 

这两个不等式正是用于确定最小有效大小的条件。 一旦有这样一个`n`找到后，我们按频率对值进行排序并首先填充较大的区域。 至多一个值被迫占据两个区域中的单元格。 该特殊值会被仔细处理，而所有其他值都完全保留在一个区域内。 这消除了所有对角线冲突。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 指数/不可行| 大| 太慢了|
 | 最佳 | O(m + k log k) | O(m + k log k) | O(n²) | 已接受 |

 ## 算法演练

 1. 按频率递减对所有值进行排序。 
2. 找到最小的`n`这样`max(a_i) ≤ n * ceil(n / 2)`和`m ≤ n² - floor(n / 2)²`。 

第一个不等式保证最频繁的值可以适合更大的区域。 第二个保证总体上有足够的可用单元。 
3. 枚举region的所有cell`A`按行主顺序。 这些是行`1, 3, 5, ...`。 
4.让`cap = |A| = n * ceil(n / 2)`。 
5. 按频率降序遍历值，找到第一个前缀和超过的值`cap`。 

每个早期值都完全适合内部`A`。 

该值（如果存在）是唯一必须拆分的值。 
6. 填补剩余空缺位置`A`具有尽可能多的该分割值的副本。 
7.继续填写剩余部分`A`与所有早期值。 
8. 枚举区域的所有单元格`B`以相同的顺序。 
9. 将分割值的剩余副本放入`B`。 
10. 将所有剩余值完全放入其中`B`。 
11. 输出矩阵。 

### 为什么它有效

 除可能的值外，每个值都完全包含在单个区域内。 a 的任意对角线`2 × 2`块总是连接一个单元格`A`和一个细胞来自`B`。 由于一个值​​仅出现在一个区域中，因此它不能在同一条对角线上出现两次。 

两个区域中可能出现的唯一值是分割值。 它的副本形成一个连续的后缀`A`和一个连续的前缀`B`。 单元格的排序可以防止复制`A`和一份副本`B`从成为对角`2 × 2`堵塞。 这正是公认的解决方案中使用的结构。 

容量不等式保证了足够的可用单元和最频繁值的足够空间。 由于所有数字都已放置并且尊重每个局部限制，因此矩阵很漂亮。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        m, k = map(int, input().split())
        arr = list(map(int, input().split()))

        vals = [(arr[i], i + 1) for i in range(k)]
        vals.sort(reverse=True)

        mx = vals[0][0]

        n = 1
        while True:
            if mx <= n * ((n + 1) // 2) and \
               m <= n * n - (n // 2) * (n // 2):
                break
            n += 1

        ans = [[0] * n for _ in range(n)]

        cap = n * ((n + 1) // 2)

        pref = 0
        split = len(vals)

        for i, (cnt, _) in enumerate(vals):
            if pref + cnt > cap:
                split = i
                break
            pref += cnt

        posA = []
        for r in range(0, n, 2):
            for c in range(n):
                posA.append((r, c))

        posB = []
        for r in range(1, n, 2):
            for c in range(n):
                posB.append((r, c))

        ptrA = 0
        ptrB = 0

        remain = 0
        split_id = -1

        if split < len(vals):
            need = cap - pref
            split_cnt, split_id = vals[split]

            for _ in range(need):
                r, c = posA[ptrA]
                ptrA += 1
                ans[r][c] = split_id

            remain = split_cnt - need

        ptrA = 0

        for i in range(split):
            cnt, val = vals[i]
            while cnt:
                if ans[posA[ptrA][0]][posA[ptrA][1]] == 0:
                    r, c = posA[ptrA]
                    ans[r][c] = val
                    cnt -= 1
                ptrA += 1

        if split < len(vals):
            while remain:
                r, c = posB[ptrB]
                ptrB += 1
                ans[r][c] = split_id
                remain -= 1

            for i in range(split + 1, len(vals)):
                cnt, val = vals[i]
                while cnt:
                    r, c = posB[ptrB]
                    ptrB += 1
                    ans[r][c] = val
                    cnt -= 1

        print(n)
        for row in ans:
            print(*row)

solve()
```第一部分计算最小有效大小。 循环很便宜，因为`n`永远不会变大。 矩阵边长大致为`√m`。 

排序数组是构造的核心。 首先处理大频率，以便在较大区域内最大值优先。 

变量`split`标识可能跨区域的唯一值`A`至地区`B`。 每个早期值都完全适合内部`A`，后面的每个值都完全适合里面`B`。 

一个微妙的实现细节是一些单元格`A`可能已经包含分割值。 在填充其他值时，代码会跳过占用的位置。 缺少此检查将覆盖副本并破坏频率计数。 

另一个容易犯的错误是索引行。 地区`A`由行组成`0, 2, 4, ...`在从零开始的索引中，对应于编辑解释中的奇数行。

 ## 边缘情况

 考虑：```
1
8 1
8
```最大频率为八。 一个`3 × 3`矩阵有区域`A`容量`6`，这是不够的。 搜索量增加`n`直到容量达到至少八个。 然后，该构造将所有副本放置在一个区域内，避免任何对角线冲突。 

考虑：```
1
15 4
2 4 8 1
```一个`4 × 4`矩阵无法工作，因为最大可用单元数仅为`16 - 4 = 12`。 

第二个不等式则否定了这一点。 算法选择`n = 5`，其中可用容量变为`25 - 4 = 21`，足以容纳所有十五个数字。 

考虑：```
1
5 2
4 1
```地区`A`容量恰好为四时`n = 3`。 最常见的值完美契合，不会分裂。 该算法将其完全保留在一个区域内，这是最安全的配置。
