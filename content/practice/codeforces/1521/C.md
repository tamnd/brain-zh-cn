 ## 解决方案
 ## 问题理解

 我们被要求重建一个隐藏的长度排列`n`包含来自的所有整数`1`到`n`使用交互式查询机制。 对于每个查询，我们选择两个不同的索引`i`和`j`, 一个类型`t`（1 或 2）和阈值`x`。 Nastia 响应一个基于排列元素计算的值`i`和`j`和`x`，遵循两个规则：类型 1 返回最小值中的最大值，类型 2 返回最大值中的最小值。 

输入由多个测试用例组成。 对于每个，我们都有长度`n`，并且我们必须最多粗略地确定隐藏的排列`1.5 * n + 30`查询。 输出是每个测试用例的完整排列。 

约束条件意味着`n`最多可以达到 10,000 个，所有测试用例的总和上限为 20,000 个。 这大致允许`O(n)`每个测试用例的操作，但排除二次方法。 朴素的蛮力策略，尝试每对索引，尽一切可能`x`将很快超出查询预算。 

边缘情况涉及排列，其中最大`n`处于极端位置，例如，`p = [1, 2, 3, ..., n]`或者`p = [n, 1, 2, ..., n-1]`。 粗心的方法可能会假设索引之间是对称的，或者依赖于仅比较相邻元素，如果最大或最小元素位于第一个或最后一个位置，则可能会失败。 

## 方法

 蛮力方法是查询每一对`(i, j)`为了所有可能的`x`来确定每个`p_i`。 这是有效的，因为通过使用不同的查询类型 1`x`，我们可以隔离`p_i`相对于`p_j`。 然而，查询数量随着`O(n^2)`，这太多了`n = 10^4`，超出时间和查询限制。 

最佳方法源于注意到可以有效地识别排列中的最大元素。 输入 2 查询`x = n-1`返回最小值`max(x, p_i)`和`max(x+1, p_j)`; 自从`x+1 = n`，其中一个查询将返回`n`如果其中之一`p_i`或者`p_j`等于`n`。 通过系统地比较，我们可以找到指数`n`使用`n-1`查询。 一旦我们知道了最大元素的位置，我们就可以通过查询类型 1 来确定剩余元素`x`设置为最大元素减一，将最大元素索引与其他索引进行比较。 这保证了正确的结果`2n - 2`查询，安全在限制之内。 

关键的见解是，交互是围绕最小-最大运算构建的，它让我们“围绕”最大元素，然后推断出与其相关的所有其他值。 这将问题从二次复杂度降低为线性复杂度。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1.初始化一个数组`p`大小的`n`来存储排列。 
2.查找最大元素的索引`n`。 从第一个索引作为候选开始，然后迭代索引`1..n-1`。 对于每个索引`i`，执行类型 2 查询`x = n-1`比较候选人和`i`。 如果响应是`n`，将候选索引更新为当前索引。 经过所有迭代后，候选索引保持不变`n`。 
3. 一旦我们知道了索引`n`，通过迭代所有其他索引来填充剩余元素。 对于每个索引`i != max_index`，执行类型 1 查询`x = n-1`比较`i`和`max_index`。 返回值为`p[i]`因为`max_index`是最大的元素并主导最小-最大评估。 
4.输出数组`p`。 

为什么它有效：类型 2 查询`x = n-1`保证查询涉及的两个索引之一将返回`n`如果它包含最大值。 这允许线性扫描找到`n`。 一次`n`众所周知，类型 1 查询利用其优势来独立确定彼此的元素。 每个查询仅显示一个元素或更新最大值的候选元素，并且我们永远不会超过`2n - 2`查询。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ask(t, i, j, x):
    print(f"? {t} {i+1} {j+1} {x}")
    sys.stdout.flush()
    return int(input())

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = [0] * n
        
        max_idx = 0
        for i in range(1, n):
            res = ask(2, max_idx, i, n-1)
            if res == n:
                max_idx = i
        
        p[max_idx] = n
        for i in range(n):
            if i == max_idx:
                continue
            p[i] = ask(1, i, max_idx, n-1)
        
        print("! " + " ".join(map(str, p)))
        sys.stdout.flush()

solve()
```我们首先定义一个辅助函数`ask`用于发送查询和接收响应。 然后我们扫描所有索引以找到最大值。 类型 2 查询确保我们检测到`n`。 之后，使用以下命令键入 1 查询`n-1`有效地提供所有剩余值。 交互中需要仔细注意基于 1 的索引。 每个查询都会立即刷新以避免交互问题。
