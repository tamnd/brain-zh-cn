 ## 解决方案
 ## 问题理解

 我们有两个由英文字母组成的字符串。 两个字符串具有相同的长度，但字母可以以大写或小写形式出现。 任务是按字典顺序比较两个字符串，同时完全忽略字母大小写。 

忽略大小写意味着`'A'`和`'a'`必须被视为相同的字符。 比较后，我们打印：

 -`-1`如果第一个字符串按字典顺序较小
 -`1`如果第一个字符串按字典顺序更大
 -`0`如果两个字符串相等

 字符串非常小，长度最多为 100。即使是低效的逐字符解决方案也很容易满足限制。 真正的挑战不是性能，而是在比较之前正确处理大小写转换。 

一个常见的错误是直接比较原始字符串。 Python 使用 ASCII 值来比较大小写字母，其中大写字母位于小写字母之前。 这会产生该问题的错误答案。 

考虑这个输入：```
aaaa
aaaA
```正确的输出是：```
0
```不转换大小写的直接比较会错误地处理`'a'`和`'A'`一样不同。 

另一个容易犯的错误是只将一个字符串转换为小写。 

例子：```
aBc
ABC
```正确的输出是：```
0
```如果只转换第一个字符串，则比较变为`"abc"`与`"ABC"`，这仍然失败，因为大写和小写 ASCII 值不同。 

当字符串仅在末尾处不同时，会出现另一种边缘情况。 

例子：```
abcz
abca
```正确的输出是：```
1
```过早停止或仅比较前缀的粗心实现会错过最终的不同字符。 

## 方法

 最直接的解决方案是逐个字符地比较字符串。 对于每个位置，我们可以手动将两个字符转换为相同的大小写，然后决定哪个字符串更大。 第一个不同的位置决定了答案。 

这种蛮力方法已经足够快了。 每个字符串最多有 100 个字符，因此我们最多执行 100 次比较。 这实际上是即时的。 

我们可以通过观察Python已经支持字典字符串比较来进一步简化实现。 唯一的问题是区分大小写。 一旦两个字符串完全转换为小写，内置比较的行为将完全按照要求进行。 

暴力版本之所以有效，是因为字典顺序仅取决于第一个不同的字符。 更干净的解决方案之所以有效，是因为将两个字符串转换为相同的大小写可以保留它们的相对字母顺序，同时完全消除大小写差异。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n) | O(1) | O(1) | 已接受 |
 | 最佳| O(n) | O(n) | 已接受 |

 这里，`n`是字符串长度。 

## 算法演练

 1. 读取输入中的第一个字符串。 
2. 从输入中读取第二个字符串。 
3. 将两个字符串转换为小写。 

这消除了仅由大写字母和小写字母引起的所有差异。 
4. 按字典顺序比较小写字符串。 
5. 如果第一个字符串较小，则打印`-1`。 
6. 如果第一个字符串较大，则打印`1`。 
7. 否则，打印`0`。 

### 为什么它有效

 词典比较取决于字符从左到右的相对顺序。 将两个字符串转换为小写可以保留字母顺序，同时使同一字母的大写和小写版本相同。 转换后，正常的字符串比较会准确产生所需的结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

s1 = input().strip().lower()
s2 = input().strip().lower()

if s1 < s2:
    print(-1)
elif s1 > s2:
    print(1)
else:
    print(0)
```第一步读取两个字符串并立即使用以下命令将它们转换为小写`.lower()`。 尽早进行转换可以使其余逻辑变得简单，并避免以后重复的字符处理。 

使用`.strip()`很重要，因为`input()`包括尾随换行符。 如果不删除它，比较将包括`'\n'`，产生不正确的结果。 

Python 已经正确执行字典字符串比较。 它从左到右比较字符，并在第一个不匹配处停止。 这与问题所需的确切定义相匹配。 

三个比较分支直接映射到所需的输出。 不需要手动循环，因为 Python 在内部处理比较。

## 测试用例```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    s1 = input().strip().lower()
    s2 = input().strip().lower()

    if s1 < s2:
        print(-1)
    elif s1 > s2:
        print(1)
    else:
        print(0)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    return sys.stdout.getvalue()

# provided sample
assert run("aaaa\naaaA\n") == "0\n", "sample 1"

# custom cases
assert run("a\nb\n") == "-1\n", "single character smaller"
assert run("Z\na\n") == "1\n", "uppercase handling"
assert run("Codeforces\ncodeforces\n") == "0\n", "all equal ignoring case"
assert run("abcz\nabca\n") == "1\n", "difference at last character"

# maximum-size style case
s1 = "A" * 100
s2 = "a" * 100
assert run(f"{s1}\n{s2}\n") == "0\n", "maximum equal strings"
```| 测试输入| 预期产出 | 它验证了什么 |
 | ---| ---| ---|
 |`a / b`|`-1`| 最小尺寸比较 |
 |`Z / a`|`1`| 正确的大写标准化 |
 |`Codeforces / codeforces`|`0`| 忽略大小写的平等 |
 |`abcz / abca`|`1`| 最终位置差异|
 | 100 个大小写相同的字母 |`0`| 最大长度处理 |

 ## 边缘情况

 考虑仅大小写不同的字符串。 

输入：```
ABC
abc
```该算法将两个字符串转换为小写：```
abc
abc
```字符串变得相同，因此输出为：```
0
```如果没有标准化，ASCII 比较将错误地以不同方式处理大写字母。 

现在考虑最终字符的不匹配。 

输入：```
abcy
abcz
```转换后：```
abcy
abcz
```前三个位置匹配。 在最后的位置上，`'y' < 'z'`，所以算法打印：```
-1
```这确认了比较会继续，直到出现第一个实际差异。 

最后，考虑单字符字符串。 

输入：```
B
a
```小写转换后：```
b
a
```自从`'b' > 'a'`，输出变为：```
1
```这验证了即使对于最小输入大小，算法也能正常工作。
