 ## 解决方案
 ## 问题理解

 我们被要求实现一个量子预言机来检查给定的位串是否是周期性的。 实际上，假设我们有一系列$N$量子位，每个代表一个位，以及一个单独的输出量子位。 目标是当且仅当位串具有某个周期时翻转输出量子位$P$和$1 \le P \le N - 1$，这意味着字符串每次都会重复$P$职位。 正式地，对于所有$i$在$0$到$N-P-1$, 位置上的位$i$等于位置处的位$i+P$。 

限制因素$2 \le N \le 7$足够小，我们有能力尝试所有可能的周期并彻底检查它们。 由于该操作是量子的，因此我们无法在计算过程中测量量子位。 我们仅使用幺正运算来操作它们，并且输入寄存器必须保持不变。 

当周期未均匀划分字符串长度时，会出现微妙的边缘情况。 例如，字符串`01010`长度为 5 但具有周期性$P=2$。 一种简单的方法，只检查除数$N$会错误地将其标记为非周期性的。 另一个边缘情况是一串所有相同的位，从技术上讲，它对于每个$P$从 1 到$N-1$。 我们的实现必须正确检测这些。 

## 方法

 蛮力方法很简单。 对于每个可能的时期$P$从 1 到$N-1$，检查每一对$(x_i, x_{i+P})$看看它们是否匹配。 如果我们找到一个$P$如果所有比较都成立，则该字符串是周期性的。 这种方法是正确的，因为周期性的定义明确地成对相等地移动了$P$。 其最坏情况的复杂度是$O(N^2)$因为我们可以有$N-1$期间及直至$N-P$每个的比较。 和$N$最多7个，这是完全可行的。 

优化的关键洞察是对于如此小的$N$，暴力检查在实践中已经是最佳的。 相反，量子特定的要求——保持输入寄存器不变并且不执行测量——指导我们的实现。 我们将经典检查转化为可逆量子操作：对于必须在候选周期内匹配的每对量子位$P$，我们将它们异或为辅助量子位。 如果对某些进行所有异或运算$P$为 0，则该字符串具有该句点。 最后，我们将所有周期测试合并到一个输出翻转中。

 ## 算法演练

 1. 对于每个候选期$P$从 1 到$N-1$，初始化辅助量子位以跟踪不匹配。 
2. 比较每一位$x_i$和$x_{i+P}$为所有人$i$在$0$到$N-P-1$。 对于每个不匹配，使用 CNOT 门翻转辅助量子位。 辅助结束了`1`如果有任何不匹配并且`0`如果期限成立。 
3.检查一段时间内所有仓位后$P$，将结果异或到输出量子位中。 如果辅助为0，则输出量子位翻转； 否则，它保持不变。 
4. 在每个周期检查后将辅助量子位重置为 0 以保持可逆性。 这确保了输入寄存器保持不变并且操作是单一的。 
5. 对所有周期重复$P$。 最后，当且仅当位串在某个周期内具有周期性时，输出量子位才会翻转。 

工作原理：每个辅助量子位都会跟踪候选周期是否失败。 异或`success`（辅助为 0）到输出中可以保证输出在至少一个周期成功时准确翻转。 由于所有操作都是可逆的（XOR 和 CNOT），因此输入寄存器不受影响，满足预言机约束。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def is_periodic(s):
    n = len(s)
    for p in range(1, n):
        match = True
        for i in range(n - p):
            if s[i] != s[i + p]:
                match = False
                break
        if match:
            return True
    return False

def main():
    t = int(input())
    for _ in range(t):
        s = input().strip()
        print("YES" if is_periodic(s) else "NO")

if __name__ == "__main__":
    main()
```解释：`is_periodic`函数实现算法演练中描述的经典检查。 它迭代所有候选周期并验证所有相关对。 早期的`break`不匹配可确保效率。 这`main`函数读取多个测试用例并应用检查。 使用`.strip()`处理输入字符串中的尾随换行符。

 ## 边缘情况

 该算法正确处理未均匀划分字符串长度的句点。 为了`01010`，它检查$P=2$并找到所有相关的比较匹配，翻转输出。 对于统一的字符串`1111`，它检测到$P=1$为有效，适当设置输出。 最小的输入如`01`或者`00`处理正确，因为周期内的循环自然停止于$N-1 = 1$。 早期的`break`不匹配可以防止不必要的比较并保持正确性。
