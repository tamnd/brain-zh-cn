 ## 解决方案
 ## 问题理解

 我们得到了一个用于编码位串的小量子位寄存器和一个充当输出累加器的附加单个量子位。 任务是实现在位串上计算布尔函数的可逆变换：当且仅当输入寄存器中 1 的数量可被 3 整除时，我们需要翻转输出量子位。关键约束是输入寄存器必须保持不变，并且操作必须是酉的，这意味着它必须是可逆的，并且不能依赖于测量或经典分支。 

更具体地说，我们正在构建一个映射基本状态的量子预言机$|x\rangle|y\rangle$到$|x\rangle|y \oplus f(x)\rangle$， 在哪里$f(x)$仅取决于汉明权重$x$模 3。输入大小非常小，最多 9 个量子位，这强烈暗示我们不希望进行渐近优化，而是使用标准量子门构建直接可逆电路。 

这些限制意味着我们可以自由地使用涉及所有量子位的受控操作，因为寄存器很小。 任何指数或组合构造$2^N$状态在概念上也是可行的，但就量子电路而言，我们仍然需要一个干净的可逆结构，而不是显式的真值表编码。 

一个微妙的边缘情况源于这样一个事实：该函数仅取决于 1 的计数，而不取决于它们的位置。 天真的经典直觉可能会建议对位求和并检查整除性，但在量子计算中，我们不能破坏性地“计算和覆盖”总和。 另一个常见的陷阱是尝试测量中间奇偶校验信息，这是被禁止的。 最后，由于函数是对称的，任何非对称处理量子位的解决方案仍然需要保持可逆性，否则它将违反输入寄存器保持不变的要求。 

## 方法

 思考这个问题的一种暴力方式是枚举所有$2^N$基础状态，计算每个基础状态的汉明权重，并有条件地翻转输出量子位。 从概念上讲，这是可行的，因为每个输入状态都是独立的，并且我们可以显式定义映射。 然而，这不是电路级解决方案，从量子角度来看，它对应于指数级大的受控操作，该操作无法以结构化方式有效构建。 

关键的观察是我们不需要区分各个位串。 我们只需要跟踪汉明权重模 3。这将整个问题简化为以可逆的方式维护一个小的三态计数器。 每个量子位都会向该计数器贡献 0 或 1，我们可以使用模算术增量更新计数器。 

这导致了标准的可逆结构：我们使用相位累加或受控旋转来维护当前和模 3 的 2 量子位无辅助编码，或者更简单地，我们使用编码条件“和模 3 等于 0”的受控操作直接计算奇偶校验贡献到输出量子位中。 由于 N 至多为 9，我们还可以通过枚举所有大小 mod 3 为零的子集，使用多控 Toffoli 式逻辑直接实现可逆分解。 

然而，最简洁的结构来自于将函数分解为对称多项式形式。 汉明权重可被 3 整除的指标可以表示为基本对称和的 XOR 上的布尔函数，这可以通过可逆电路中的受控多量子位门来实现。 在这种小 N 机制中，我们可以简单地将总和计算到暂存阶段，然后根据总和模 3 是否等于 0 来调节输出翻转，然后取消计算以恢复输入量子位。 

暴力法和最优构造之间的本质区别在于，暴力法直接对输入进行推理，而最优方法则对紧凑的统计量（汉明权重模 3）进行推理。

 ## 算法演练

 我们构建了一个可逆计算，使用受控操作将汉明权重模 3 编码为输出量子位的相位信息。 

1. 通过确保我们仅有条件地作用于输出量子位来进行初始化，使所有输入量子位始终保持不变。 这是预言机定义所要求的，因此每个操作对于输入寄存器都必须是可逆的。 
2. 对于每个输入量子位$x_i$，我们应用有助于模块化计数结构的受控操作。 我们没有存储经典的和，而是将贡献编码到受控相位翻转中，累积总汉明权重模 3 的签名。 
3. 我们使用这样的恒等式：仅依赖于汉明权重模 3 的函数可以通过应用与单位根相对应的相位贡献来实现。 每个量子位贡献一个相位旋转，使得组合的相位编码$\omega^{\text{weight}(x)}$， 在哪里$\omega = e^{2\pi i/3}$。 
4. 累加该相位后，我们通过使用受控反射将相位指示器转换为输出量子位上的可计算布尔标志，仅当累加相位对应于可被 3 整除的权重时才翻转输出。 
5. 最后，我们通过取消计算任何辅助相位编码来确保可逆性，以便所有输入量子位完全返回到其原始状态。 

### 为什么它有效

 不变量是，在处理前 k 个量子位之后，量子态累积了一个仅取决于这 k 个量子位模 3 的汉明权重的相位。这个不变量之所以成立，是因为每个量子位独立且乘法地对相位编码做出贡献，并且单位立方根的乘法恰好对应于指数中模 3 的加法。 当 k = N 时，相位完全编码 1 的总数是否与 0 模 3 同余。最终的受控操作只是将此相位信息转换为输出量子位上的翻转，从而完成预言。

 ## 边缘情况

 一种重要的边缘情况是输入寄存器全为零时。 在这种情况下，汉明权重为 0，可被 3 整除，因此输出必须翻转。 预言机在叠加上的行为仍然必须相同，这意味着即使系统处于全零和非零状态的均匀叠加，变换仍然保持线性和一致。 

另一种边缘情况是正好三个量子位设置为 1。例如，在 9 量子位系统中输入 |111000000⟩。 该电路必须正确累积所有三个活动量子位的贡献，而不受非活动量子位的干扰。 可逆结构确保了这一点，因为每个量子位都独立地参与模 3 相编码，因此只有计数重要，而不是位置。 

最后一个微妙的情况是叠加输入，其中幅度对应于具有不同汉明权重的状态。 预言机必须将正确的相位条件翻转独立地应用于每个基础组件，这是通过纯粹从单一控制门而不是任何经典分支逻辑构造操作来保证的。
