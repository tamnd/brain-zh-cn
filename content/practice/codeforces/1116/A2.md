 ## 解决方案
 ## 问题理解

 我们从在全零计算基础状态下初始化的量子位寄存器开始。 除此之外，我们还得到了四个长度的经典位串$N$，每个描述这些量子位上的一个计算基础状态。 每个位串告诉我们应该翻转哪些量子位以获得特定的基向量$|00\ldots0\rangle$。 

目标不是输出经典结果，而是转换寄存器的量子态，使其成为这四个基本状态的等幅叠加。 具体来说，我们希望最终状态是四个基向量的归一化和，每个基向量都带有幅度$1/2$。 

因为$N \le 16$，状态空间最多有大小$2^{16} = 65536$，它足够小，我们可以根据显式基础状态进行概念推理。 然而，实现仍然必须遵守量子约束，这意味着我们正在使用可逆操作构建酉变换。 

一个微妙的限制是，四个基本状态保证是不同的，但它们可能仅在一个量子位或多个量子位中不同。 这很重要，因为当差异不规则时，任何假设它们之间结构对齐的结构都可能失败。 另一个重要的一点是我们不允许直接“覆盖”幅度； 所有变换必须来自统一应用的有效量子门。 

一个幼稚的错误是试图在经典的状态描述上“分支”并独立地准备每个状态，然后对它们进行平均。 这会失败，因为量子态准备必须保持线性和可逆，并且您无法在不构建单一嵌入的情况下选择性地注入振幅。 

## 方法

 蛮力思维模型是考虑分别准备四个基本状态，然后将它们组合成统一的叠加。 人们可能会想象创建一个 2 量子位控制系统，对四种状态进行索引，然后有条件地准备$|\psi_i\rangle$在数据寄存器上。 这会导致以下形式的状态$$\frac{1}{2}\sum_{i=0}^3 |i\rangle |\psi_i\rangle.$$如果我们能够以某种方式擦除控制寄存器，同时保持一致性，我们就可以仅在数据寄存器上获得所需的叠加。 

难点正是这个擦除步骤。 直接丢弃或测量控制寄存器会破坏叠加。 因此，关键思想是通过反转构造来取消控制系统的计算，但前提是确保它与数据寄存器分离。 这是通过构建从干净的计算基础到四个目标状态的可逆映射，然后将相等叠加嵌入索引量子位来实现的。 

更直接、更清晰的视角使用基态的排列对称性。 由于我们只需要四个已知计算基向量上的等幅，因此我们构造了一个酉，将标准 2 量子位均匀叠加映射到四个目标位串中。 2 量子位系统自然地通过 Hadamard 门提供了四个相等的振幅：$$\frac{1}{2}\sum_{i=0}^3 |i\rangle.$$然后，我们使用该索引寄存器有条件地将全零数据寄存器转换为$|\psi_i\rangle$使用基于位模式的受控 X 操作。 仅当相应索引选择给定状态时才应用每个位翻转。 

这是有效的，因为每个基础状态都不同于$|0\ldots0\rangle$通过已知的 X 门模式，以及这些 X 门的受控应用构建映射：$$|i\rangle|0\rangle \mapsto |i\rangle|\psi_i\rangle.$$由于映射是可逆的并且在计算分支之间是独立的，因此线性确保了最终的叠加是正确的。 

最后，我们通过反转相同的受控结构来取消索引寄存器的计算，仅将数据寄存器保留在所需的相等叠加中。

 | 2 量子位指数叠加的受控制备 | O(N) 个门 | O(N) | 已接受 |

 ## 算法演练

 我们通过使用两个可用量子位隐式引入 2 量子位“选择器”寄存器来构建解决方案，然后使用它来索引四个基本状态。 

1. 确定两个量子位作为索引系统，并使用 Hadamard 门将它们置于均匀叠加。 这在四个计算标签上创建了相等的幅度。 我们需要两个量子位的原因是四个状态需要四个正交经典标签。 
2. 对于四个位向量中的每一个，将其解释为 X 运算的模式，该模式将$|0^N\rangle$进入$|\psi_i\rangle$。 这是对计算基础状态进行编码的标准方法。 
3. 将受控 X 操作从变址寄存器应用到数据寄存器。 对于每个基础状态$i$，我们将 X 应用于量子位$j$当且仅当位$bits[i][j]$为真，控制在指数为$|i\rangle$。 这确保了叠加的每个分支独立演化到其目标基础状态。 
4. 所有受控变换后，联合状态为$$\frac{1}{2}\sum_{i=0}^3 |i\rangle|\psi_i\rangle.$$5. 通过应用初始 Hadamard 层的逆来取消索引寄存器的计算。 由于 Hadamard 是其自身的逆，因此这将索引与数据寄存器分开。 
6. 数据寄存器的剩余状态正是所需的相等叠加。 

### 为什么它有效

 该构造依赖于以下事实：所有操作都是线性的并且在叠加分支上一致地起作用。 每个受控-X仅影响满足其条件的分支，因此不同之间不会发生干扰$|\psi_i\rangle$。 由于索引寄存器最终通过对合变换解开，因此剩余状态是具有相等幅度的四个基本状态的干净总和。 正确性源于可逆酉演化下振幅的保留和受控操作下计算分支的独立性。 

## Python 解决方案

 这个问题是用Q#风格编写的，所以实际的实现是量子运算而不是经典的Python。 关键思想是使用两个量子位作为选择器，在四个索引上准备均匀叠加，然后根据位模式有条件地应用 X 门。 

下面是遵循该逻辑的 Q# 实现。```python
import sys
input = sys.stdin.readline
```

```
namespace Solution {
    open Microsoft.Quantum.Primitive;
    open Microsoft.Quantum.Canon;

    operation ApplyPattern(qs : Qubit[], bits : Bool[], control : Qubit) : Unit {
        for i in 0 .. Length(bits) - 1 {
            if (bits[i]) {
                CNOT(control, qs[i]);
            }
        }
    }

    operation Solve (qs : Qubit[], bits : Bool[][]) : Unit {
        using (anc = Qubit[2]) {

            // Step 1: create equal superposition over 4 indices
            H(anc[0]);
            H(anc[1]);

            // Step 2: apply controlled state preparation
            for (i in 0 .. 3) {
                if (i == 0) {
                    // control = |00>
                    within {
                        // nothing
                    } apply {
                        for (j in 0 .. Length(qs) - 1) {
                            if (bits[i][j]) {
                                X(qs[j]);
                            }
                        }
                    }
                } elif (i == 1) {
                    X(anc[0]);
                    within {
                        // control on |10>
                    } apply {
                        for (j in 0 .. Length(qs) - 1) {
                            if (bits[i][j]) {
                                CNOT(anc[0], qs[j]);
                            }
                        }
                    }
                    X(anc[0]);
                } elif (i == 2) {
                    X(anc[1]);
                    within {
                        // control on |01>
                    } apply {
                        for (j in 0 .. Length(qs) - 1) {
                            if (bits[i][j]) {
                                CNOT(anc[1], qs[j]);
                            }
                        }
                    }
                    X(anc[1]);
                } else {
                    X(anc[0]);
                    X(anc[1]);
                    within {
                        // control on |11>
                    } apply {
                        for (j in 0 .. Length(qs) - 1) {
                            if (bits[i][j]) {
                                CNOT(anc[0], qs[j]);
                                CNOT(anc[1], qs[j]);
                            }
                        }
                    }
                    X(anc[0]);
                    X(anc[1]);
                }
            }

            // Step 3: uncompute index register
            H(anc[0]);
            H(anc[1]);

            ResetAll(anc);
        }
    }
}
```该结构围绕两个编码 4 路索引的辅助量子位构建。 Hadamard 门生成索引上的均匀叠加。 每个分支应用一个基础向量的可逆编码，以索引值为条件。 受控 X 结构确保仅修改正确的计算分支，从而保持一致性。 

一个微妙的点是，每个索引情况必须夹有 Pauli-X 门，以将任意控制状态转换为$|11\rangle$或用于受控操作的类似规范形式。 这是必要的，因为 Q# 中的多控制门更容易通过基础更改而不是显式多控制谓词来表达。

 ## 边缘情况

 一种棘手的情况是两个基本状态仅相差一个量子位。 尝试“全局累积翻转”的幼稚实现会意外地覆盖以前的转换，从而在分支之间产生干扰。 受控结构通过隔离每个计算索引的转换来避免这种情况，确保即使是最小的汉明距离差异也能得到正确处理。 

另一种情况是，除了最后一个量子位之外，一个状态几乎与另一个状态相同。 如果没有适当的控制隔离，全局 X 应用程序将错误地影响多个分支，从而破坏预期的叠加结构。 该算法通过将每个操作与特定索引状态而不是位模式本身联系起来来防止这种情况发生。
