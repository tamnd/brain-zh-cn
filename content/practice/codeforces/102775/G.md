 ## 解决方案
 ## 问题理解

 任务是分割给定的自然数`N`化为几个正整数。 分割的每个部分必须具有完全相同的十进制数字总和。 零件数量必须至少为两个，不能达到`N`本身，并且不能超过一百万。 如果存在这种拆分，我们将打印零件数量和零件本身。 否则，我们打印`-1`。 

极限`N <= 10^18`立即排除尝试可能的加数或搜索分区。 甚至迭代所有值直到`N`这是不可能的，因为输入可以包含大约五千万亿的数字。 有用的观察结果只取决于位数，因为`N`最多有 19 位小数。 

困难的情况不是大值，而是可能分解很少的值。 例如，`N = 1`无法拆分，因为无法创建至少两个正被加数。 在这种情况下，总是将十进制数字打印为十的幂的粗心实现将输出一个被加数。 

为了`N = 10`，十进制数字分解仅给出一个被加数，`10`，这是无效的。 正确的输出是`2`其次是`5 5`，因为两个被加数都有数字和`5`。 如果不小心实现，只计算十进制数字，就会错过 10 的所有幂。 

为了`N = 2`，分解为数字值副本工作正常：`1 + 1`。 两个数字都有数字和`1`，且被加数的个数有效。 

## 方法

 直接方法会尝试找到一些数字和`S`, 生成具有数字和的数字`S`，并搜索总计为`N`。 这是正确的，因为任何有效答案都必须使用具有一个公共数字和的数字。 然而，搜索空间是巨大的。 甚至生成以下所有候选者`10^18`这是不可能的，分区搜索的可能性远远超过一秒钟所能处理的。 

十进制表示的结构给出了一条更简单的路线。 任意数字`d`在位置`10^k`可以看作`d`号码的副本`10^k`。 每个这样的副本都有数字和`1`。 例如，`352`变成`3 * 100 + 5 * 10 + 2 * 1`，可以写成十位数字和一的数字：`100, 100, 100, 10, 10, 10, 10, 10, 1, 1`每个被加数具有相同的数字和，因此只要十进制数字和为`N`至少是两个。 产生的项数正好是数字的总和`N`，这最多是`171`对于给定的限制。 

当数字和为 1 时，此构造唯一的失败发生。 这些数字正好是十的幂。 为了`N = 1`，不存在答案。 对于任何其他 10 的幂，将其分成相等的两半都是可行的。 数量`10^k / 2`有数字和`5`，所以两半总是满足要求。 

蛮力之所以有效，是因为它搜索我们利用的相同属性，即等位数和，但它试图发现十进制表示形式已经给我们提供的结构。 十的幂自然地具有数字和一的观察让我们立即构造出几乎每个答案。

 | --- | --- | --- | --- |
 | 蛮力 | O(可能的分区数) | O(候选人数量) | 太慢了 |
 | 最佳 | O(位数 + 答案大小) | O(答案大小) | 已接受 |

 ## 算法演练

 1. 计算小数点后位数之和`N`。 这告诉我们简单的数字分解是否包含一个或多个被加数。 
2.如果`N`是`1`， 打印`-1`。 无法创建两个总和为的正数`1`。 
3. 如果数字和`N`是`1`，打印两份`N / 2`。 唯一这样的值是十的幂，并且每一个大于一的十的幂都是偶数。 每一半都有数字和`5`。 
4. 否则，扫描小数位`N`从右到左。 对于每个数字`d`在位置`10^k`， 添加`d`的副本`10^k`到答案。 

这样做的原因是每个生成的值只有一个非零数字，因此每个生成的值都有数字和`1`。 添加副本可以准确地重建原始十进制数。 
5. 打印生成的被加数的数量以及被加数本身。 

该结构背后的不变量是每个产生的被加数具有相同的数字和。 唯一的特殊情况是自然数字分解包含一个被加数，这种情况恰好发生在 10 的幂上。 这些数字的单独处理保留了相同的不变量，同时满足至少有两个部分的要求。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def digit_sum(x):
    return sum(map(int, str(x)))

def solve():
    n = int(input())

    if n == 1:
        print(-1)
        return

    if digit_sum(n) == 1:
        print(2)
        print(n // 2, n // 2)
        return

    ans = []
    x = n
    power = 1

    while x > 0:
        digit = x % 10
        for _ in range(digit):
            ans.append(power)
        power *= 10
        x //= 10

    print(len(ans))
    print(*ans)

if __name__ == "__main__":
    solve()
```第一个分支处理唯一不可能的输入。 在十的幂情况之前检查条件，因为`1`也有数字和一，但将其除以两个正整数是不可能的。 

第二个分支处理所有大于一的十的幂。 除法是精确的，因为这些数字是偶数，并且所得的两半具有相等的数字和。 

主循环从右到左提取数字。`power`始终存储当前的小数位值。 如果当前数字是`d`, 附加`d`的副本`power`贡献的金额与原始数字中贡献的数字完全相同。 答案大小保持很小，因为此输入范围的最大可能的十进制数字总和是`171`。 

Python 整数不会溢出，所以一半`10^18`并且所有中间值都是安全的。 该循环还避免了将数字转换为数字列表，从而使实现保持直接。

import sys
import io

def solve_case(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    def digit_sum(x):
        return sum(map(int, str(x)))

    n = int(sys.stdin.readline())

    if n == 1:
        return "-1"

    if digit_sum(n) == 1:
        return f"2\n{n // 2} {n // 2}"

    ans = []
    x = n
    power = 1
    while x > 0:
        d = x % 10
        for _ in range(d):
            ans.append(power)
        power *= 10
        x //= 10

    return str(len(ans)) + "\n" + " ".join(map(str, ans))

def check(inp):
    out = solve_case(inp)
    if out == "-1":
        return out

    lines = out.splitlines()
    m = int(lines[0])
    values = list(map(int, lines[1].split()))

    assert len(values) == m
    assert 2 <= m
    assert all(v > 0 for v in values)
    assert sum(values) == int(inp)
    assert len({sum(map(int, str(v))) for v in values}) == 1
    return out

 ## 边缘情况

 对于`N = 1`，算法达到第一个条件并打印`-1`。 不存在可以使用两次且总和等于 1 的正值。 

为了`N = 10`，普通的数字分解只会错误地给出`[10]`。 该算法检测到数字和为一，使用特殊情况，并输出`5 5`。 两个数字的数字和为 5，合在一起形成 10。 

为了`N = 2`，数字和为 2，因此分解会创建两个副本`1`。 输出包含两个数字和为 1 的被加数，它们的和正是原数。 

为了`N = 10^18`，数字和为 1，因此算法不会尝试创建单个被加数。 它输出两个副本`500000000000000000`，它满足所有限制，同时避免无效的单元素答案。
