 ## 解决方案
 ## 问题理解

 我们有一组玩家，每组玩家都玩一个国际象棋游戏。 对于每场比赛，我们必须决定三种结果之一：一名球员获胜，另一名球员失败，或者双方平局。 每对玩家的最终结果必须一致，与可能的中立边形成完整的有向关系。 

每个球员在所有比赛中的行为方式都受到限制。 有些玩家很严格：他们不能输掉任何游戏。 其他人则雄心勃勃：他们必须赢得至少一场比赛。 

任务是构造一个同时满足两种约束的完整锦标赛结果矩阵，或者确定不存在这样的分配。 

限制很小，每个测​​试用例最多 50 名玩家，最多 200 个测试用例。 这立即表明每个测试用例的 O(n²) 构造是完全安全的，因为即使在最坏的情况下，我们每次测试也只填充 50 x 50 矩阵，这是可以忽略不计的。 

唯一不平凡的紧张来自两种玩家类型之间的互动。 一个不能输的玩家从他们的角度来看只能得到胜利或平局的结果。 必须赢得至少一场比赛的玩家必须在最终定向结构中至少有一个向外的获胜优势。 困难在于确保这些要求在全球范围内不会发生冲突。 

当所有玩家都是“不能输”类型时，就会出现微妙的失败案例。 如果每个人都拒绝失败，那么就根本不允许定向获胜，这使得任何玩家都无法满足“必须获胜”的要求（如果存在的话）。 另一个有问题的情况是，当只有“不能输”的玩家中恰好有一个“必须赢”的玩家时，因为该玩家没有安全的输给，但仍然必须获得胜利。 

例如，如果所有玩家都是类型 1，比如`111`，每场比赛都必须避免损失，迫使所有比赛都是平局，但是如果存在类型 2 玩家，则没有人能赢得任何东西，这与这里无关，但说明了类型 1 的限制性。 

真正的结构性问题是，第 2 类玩家必须在彼此之间形成有向的胜利循环，以保证每个人在不违反第 1 类约束的情况下至少获得一场胜利。 

## 方法

 暴力解决方案将尝试为每对玩家分配一个结果，然后验证所有约束。 由于存在 O(n²) 次匹配，并且每个匹配都有三种可能的结果，因此搜索空间是指数级的，大约为 3^(n²)，即使对于 n = 10，这也是完全不可行的。 

关键的观察是我们根本不需要搜索。 有效解决方案的结构极其严格。 1 类玩家绝不能输，因此彼此之间只能打平。 必须安排 2 类玩家，使每人至少获胜一次，但也不得迫使 1 类玩家处于失败位置。 这表明将 2 类玩家隔离为定向胜利的唯一来源。 

如果没有类型 2 的玩家，答案就是平局。 如果只有一个类型 2 玩家，他们就无法战胜类型 1 玩家，因为这会迫使类型 1 玩家输掉比赛，而且他们也无法战胜自己。 所以他们想要至少赢一次的唯一方法是不可能的。 

如果至少有两个类型 2 玩家，我们可以将他们排列成一个简单的循环：玩家 i 击败玩家 i+1，最后一个击败第一个。 这保证了每个类型 2 玩家只有一场胜利。 所有其他涉及类型 1 玩家的比赛均设置为平局，除非涉及类型 2 玩家，其中类型 2 可以根据循环方向安全地获胜或失败，但类型 1 永远不会输。 

这将问题简化为简单的构造，而不是任何搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(3^(n²)) | O(3^(n²)) | O(n²) | 太慢了 |
 | 循环建设| O(n²) | O(n²) | 已接受 |

 ## 算法演练

 我们直接构造矩阵。 

1. 根据类型字符串将玩家分为两组：不能输的组和必须至少赢一次的组。 这种分类决定了以后的所有决定。 
2. 如果类型2的玩家恰好有1或2个，则立即输出NO。 在只有一名玩家的情况下，没有对手可以获胜。 对于两名玩家，如果双方都是类型 1 或无法确保双方以一致的方式安全获胜，则任何获胜分配都会强制失败，从而打破类型 1 约束。 
3. 使用默认绘制初始化一个 n × n 矩阵，这意味着每个非对角线条目都以`=`。 这是安全的，因为平局永远不会违反“无损失”条件。 
4. 将对角线条目设置为`X`因为玩家不玩自己。 
5. 如果没有类型 2 玩家，我们就已经有了有效的配置，因为没有人要求获胜。 我们可以输出全绘制矩阵。 
6. 如果至少有三个 2 类玩家，则按顺序获取他们的索引并创建一个有向循环：每个 2 类玩家 i 击败列表中的下一个 2 类玩家，最后一个击败第一个。 这保证了每个类型 2 玩家都获得一场胜利。 
7. 将所有其他条目保留为平局，因为类型 1 玩家既不需要胜利也不能承受损失。 任何涉及 1 类玩家的互动都保持中立。 

### 为什么它有效

 该结构确保每个类型 1 玩家只参与平局或获胜，而不会参与失败。 唯一分配的损失是在其周期内分配给 2 类玩家，但这些损失由胜利来平衡，确保每个 2 类玩家满足至少一场胜利的要求。 该循环保证每个类型 2 玩家都恰好有一个输出获胜优势，因此条件得到统一满足，而不会影响类型 1 玩家。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()

    twos = [i for i, c in enumerate(s) if c == '2']

    if len(twos) == 1:
        print("NO")
        continue

    # initialize matrix with draws
    ans = [['=' for _ in range(n)] for _ in range(n)]
    for i in range(n):
        ans[i][i] = 'X'

    if len(twos) == 0:
        print("YES")
        for row in ans:
            print(''.join(row))
        continue

    # build cycle among type-2 players
    k = len(twos)
    for i in range(k):
        u = twos[i]
        v = twos[(i + 1) % k]
        ans[u][v] = '+'
        ans[v][u] = '-'

    print("YES")
    for row in ans:
        print(''.join(row))
```解决方案首先将 2 类参与者分开，因为他们是唯一需要结构性强制执行的参与者。 矩阵完全通过绘图进行初始化，以便自动满足类型 1 约束。 对角线充满了`X`以满足格式要求。 

关键的构建步骤是针对 2 类参与者的定向循环。 每条边`u -> v`为 u 分配一次胜利，为 v 分配一次失败，这保证了每个类型 2 玩家至少获得一次出局胜利。 模索引确保循环干净地环绕。 

NO 情况仅在只有一个类型 2 玩家时发生，因为没有任何自我对弈或外部结构可以在不引入无效损失的情况下提供胜利。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        s = input().strip()

        twos = [i for i, c in enumerate(s) if c == '2']

        if len(twos) == 1:
            out.append("NO")
            continue

        ans = [['=' for _ in range(n)] for _ in range(n)]
        for i in range(n):
            ans[i][i] = 'X'

        if len(twos) == 0:
            out.append("YES")
            out.extend(''.join(row) for row in ans)
            continue

        k = len(twos)
        for i in range(k):
            u = twos[i]
            v = twos[(i + 1) % k]
            ans[u][v] = '+'
            ans[v][u] = '-'

        out.append("YES")
        out.extend(''.join(row) for row in ans)

    return "\n".join(out)

 ## 边缘情况

 单一的 2 型玩家暴露了核心的不可能性：没有对手提供胜利，并且不存在自我对战。 该算法在任何矩阵构造之前立即捕捉到这一点，并返回“否”。 

完全的 1 型群体会产生退化但有效的解决方案，其中每场比赛都是平局。 该结构通过从不插入任何胜利来处理这个问题，使初始矩阵保持完整。 

当类型 2 玩家存在但数量很少时，尤其是两名玩家，任何分配胜利的尝试都会破坏对称性约束或违反“类型 1 不损失”条件。 该算法通过要求至少三个节点形成一个循环来避免这种情况，确保每个类型 2 玩家都有明显的输出获胜优势，而不会在其他地方强制出现矛盾。
