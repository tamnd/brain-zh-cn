 ## 解决方案
 ## 问题理解

 考虑到评审团成员如何展示自己的任务，我们被要求计算“好”的评审团成员排列数量。 Each jury member$i$有$a_i$任务，并且它们根据排列顺序讲述任务。 如果没有评审团成员连续提出两项任务，那么排列是很好的。 

关键的见解是，演示顺序实际上是一个循环赛：在每一轮中，每个有剩余任务的评审团成员都会演示一个任务。 如果某个成员最终连续讲述多个任务，则排列失败。 

从结构的角度来看，唯一可能导致排列无效的情况是，如果有一个成员的任务数量**相对于其他成员来说太大**，那么在所有其他成员都呈现一次之后，该成员仍然有一个任务剩余，并且必须连续呈现两次。 

这立即给了我们一个具体的条件：让$\text{max}_a$是最大的$a_i$和$\text{sum}_a$所有的总和$a_i$。 如果最大的排列是**不可能**的$a_i$超过其他的总和$a_i$加一。 否则，总有办法交错任务以避免连续演示。 

当所有陪审团成员都有相同数量的任务时，就会出现边缘情况。 例如，如果每个$a_i = 1$，那么**所有排列都会自动很好**，因为没有人可以连续出现两次。 同样，如果$n = 2$并且任务是相等的，只有一种很好的排列。 

约束条件很大（$n$最多$2 \cdot 10^5$和$a_i$最多$10^9$），这排除了任何显式模拟演示过程的方法。 我们需要一个**组合公式**来直接计算排列。 

## 方法

 暴力方法是生成所有排列并模拟任务共享过程。 对于每个排列，跟踪每个陪审团成员的剩余任务并检查是否有人连续出现。 这是正确但不可行的：$n!$当以下情况时，排列太大$n$达到$10^5$。 

关键的观察结果是，唯一的限制来自具有最大任务数的成员。 让$\text{max}_a$出现$c$次在数组中。 如果$\text{max}_a - \text{second\_max}_a > 1$，那么如果没有某个最大成员连续出现两次，就不可能交错任务。 否则，我们可以通过首先选择“第二高”成员的位置，然后自由排列其余成员来计算排列。 

组合推理可以分解为：

 1. 如果有多个最大值，则所有排列均有效，除非最大值超出其他排列超过 1。 
2、如果最大的出现了一次，我们必须避免它出现在相对于第二大的最后一个位置； 坏排列的数量可以组合计算。 

这导致了一个有效的$O(n \log n)$使用阶乘和模运算的解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(n!)$|$O(n)$| 太慢了 |
 | 组合计数|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 1. 阅读$t$测试用例。 
2. 对于每个测试用例，请阅读$n$和数组$a$。 
3. 计算$\text{max}_a = \max(a)$并数数$c$它发生的次数。 
4. 计算$\text{second\_max}_a$作为下一个最大值$a$。 
5.如果$\text{max}_a - \text{second\_max}_a > 1$，打印 0，因为不可能交错任务。 
6. 否则，计算阶乘直至$n$模数$998244353$用于排列计数。 
7. 如果多次出现$\text{max}_a$，所有排列都是有效的，所以答案是$n!$。 
8. 如果存在单个最大值，则使用组合公式计算单个最大值放置“太早”的排列数，然后从$n!$，并打印结果模$998244353$。 

**为什么有效**：正确性依赖于循环属性。 最大值不能连续放置； 通过仅控制相对于第二个最大值的最大值，我们保证没有其他成员会连续出现两次。 这将问题简化为计算这些最大任务的有效位置排列。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    t = int(input())
    fact = [1] * (2*10**5 + 10)
    for i in range(1, len(fact)):
        fact[i] = fact[i-1] * i % MOD
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        mx = max(a)
        c = a.count(mx)
        if c > 1:
            print(fact[n])
            continue
        sec = max(x for x in a if x != mx)
        if mx - sec > 1:
            print(0)
            continue
        cnt = a.count(sec)
        # Number of bad permutations
        bad = fact[n] * modinv(cnt + 1) % MOD
        print((fact[n] - bad + MOD) % MOD)

solve()
```**解释**：我们预先计算阶乘模$998244353$。 如果存在多个最大值，则所有排列均有效。 否则，我们会计算“坏”排列，其中单个最大值相对于第二个最大值出现得太早，使用模逆来有效地除阶乘。

 ## 边缘情况

 如果最大成员的任务超过其他成员的总和超过 1，则交错不会避免连续演示。 例如，`n=3, a=[1,1,4]`。 我们的算法检测到`4 - 1 > 1`并立即返回`0`。 

如果所有成员都有相同的任务，则任何排列都是有效的。 我们的阶乘预计算可确保有效处理这些情况。 

这捕获了问题中的所有非明显约束，而无需模拟每个排列。
