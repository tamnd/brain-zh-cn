 ## 解决方案
 ## 问题理解

 我们得到了一组具有整数坐标的轴对齐矩形，并且允许我们选择它们的任何子集。 目标是确定我们是否可以选择一些子集，其并集恰好形成一个实心正方形区域，没有丢失的部分，并且在该正方形之外没有额外的覆盖。 

关键要求是区域严格相等：正方形内的每个点必须至少被一个选定的矩形覆盖，并且正方形之外的任何点都不能被选定的矩形覆盖。 由于矩形内部不重叠，因此并集的行为就像将区域划分为不相交的轴对齐块。 

约束立即塑造解决方案空间。 对于多达 100,000 个矩形和以 3000 为边界的坐标，任何检查所有子集的方法都是不可能的，因为 2^n 远远超出了可行的限制。 即使矩形之间的二次交互（大约 10^10 次运算）也不会通过。 这促使我们利用小坐标范围而不是大量矩形。 

一个微妙的点是矩形可能会接触边缘而不重叠。 这允许多个矩形形成较大形状的完美平铺的配置，并且正方形可能由排列成网格状结构的许多小块组成。 

当尝试对边界覆盖进行贪婪推理时，会出现常见的失败情况。 例如，挑选单独“看起来像正方形”的矩形可能会失败，因为内部孔仍未被覆盖。 另一种故障模式是假设匹配极端坐标就足够了。 两个矩形可能定义一个方形边界，但内部可能仍然包含未覆盖的间隙。 

例如，考虑形成正方形边界的对角的两个矩形。 它们的边界框是正方形的，但内部是空的，所以答案一定是否定的。 幼稚的边界框检查会错误地接受此类情况。 

## 方法

 暴力策略会尝试选择矩形的子集并测试它们的并集是否形成正方形。 即使我们避免枚举所有子集，我们也可以尝试从每个矩形开始并向外扩展，检查组合。 然而，联合检查本身需要几何合并，这可能会很昂贵。 即使在排序后合并 k 个矩形也至少需要 O(k log k) 或 O(k)，并且对于许多候选者来说这样做很快就变得不可行。 

关键的结构观察是坐标很小，每个维度最多 3000 个。 这表明我们可以将平面作为网格进行推理，而不是对矩形进行推理。 每个点 (x, y) 都可以被视为一个矩形或空白空间的一部分。 由于矩形不重叠，网格中的每个单位单元最多属于一个矩形。 

这就将问题转化为覆盖问题：我们能否在这个网格中找到一个正方形区域，使其内部的所有单元格都属于我们选择的矩形，并且不包括外部的单元格？ 一旦我们确定了一个候选正方形，我们只需要验证哪些矩形完全位于其中以及它们的并集是否与该正方形完全匹配。 

利用这一点的直接方法是考虑由 x 坐标对定义的所有可能的正方形并强制执行相等的边长。 由于坐标很小，我们可以枚举方形边界并使用预先计算的结构来有效地测试覆盖范围。 重要的见解是，我们不是尝试所有子集，而是反转观点：我们固定一个正方形并询问与其相交的矩形是否形成完美的分区。 

这导致在坐标网格上进行动态编程或基于扫描的重建，利用前缀和来快速测试覆盖一致性。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力子集 | O(2^n·n) | O(2^n·n) | O(n) | 太慢了 |
 | 网格+坐标DP| O(C^2 + n)，其中 C ≤ 3000 | O(C^2) | O(C^2) | 已接受 |

 ## 算法演练

 1. 使用所有坐标都位于 [0, 3000] 中的事实隐式压缩坐标空间，将平面视为大小最多为 3000 x 3000 的离散网格。 
2. 构建 2D 覆盖表示，其中每个单元存储哪个矩形覆盖它。 由于矩形不重叠，因此每个单元最多属于一个矩形。 这使我们能够将覆盖率视为确定性标签而不是多重集。 
3. 在网格上构造一个 2D 前缀结构，指示单元格是否被任何矩形覆盖，并另外存储每个单元格的矩形标识符。 这允许对矩形区域进行恒定时间查询。 
4. 使用 x 坐标对作为左边界和右边界，枚举可能的正方形候选对象。 对于每个左边界 x1 和每个可能的 x2，定义边长 s = x2 − x1。 
5. 对于每个这样的对，检查是否存在 y 间隔 [y1, y1 + s] 使得该区域被完全覆盖。 这是通过在 y 上滑动窗口并检查 x 间隔中所有单元格的完全覆盖来完成的。 
6. 对于固定的候选正方形，收集与其内部相交的所有矩形。 因为矩形是不相交的，所以我们可以标记哪些矩形在正方形内提供覆盖范围。 
7. 验证两个条件：所选矩形的并集覆盖正方形中的每个单元格，并且没有矩形延伸到正方形边界之外。 第一个确保完整性，第二个确保平等。 
8. 如果两个条件都成立，则输出所选子集的矩形索引。 

### 为什么它有效

 正确性取决于矩形形成空间划分且没有重叠的事实。 这使得覆盖范围可以简化为单元格联合检查。 任何有效的正方形必须与矩形边缘引起的网格边界对齐。 由于所有坐标都是整数且有界，因此每个有效解都可以表示为网格对齐单位单元的并集。 该算法详尽地检查该离散空间中所有可能的方形边界，并使用基于前缀的查询验证精确覆盖范围，确保不会遗漏任何有效配置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    rects = []
    xs = set()
    ys = set()

    for i in range(n):
        x1, y1, x2, y2 = map(int, input().split())
        rects.append((x1, y1, x2, y2, i + 1))
        xs.add(x1); xs.add(x2)
        ys.add(y1); ys.add(y2)

    xs = sorted(xs)
    ys = sorted(ys)

    xi = {x:i for i, x in enumerate(xs)}
    yi = {y:i for i, y in enumerate(ys)}

    w, h = len(xs), len(ys)

    grid = [[0] * h for _ in range(w)]

    # mark rectangles on compressed grid
    owner = [[-1] * h for _ in range(w)]

    for x1, y1, x2, y2, idx in rects:
        for x in range(xi[x1], xi[x2]):
            for y in range(yi[y1], yi[y2]):
                owner[x][y] = idx
                grid[x][y] = 1

    # prefix sum for coverage
    pref = [[0] * (h + 1) for _ in range(w + 1)]
    for i in range(w):
        for j in range(h):
            pref[i+1][j+1] = pref[i][j+1] + pref[i+1][j] - pref[i][j] + grid[i][j]

    def sum_region(x1, y1, x2, y2):
        return pref[x2][y2] - pref[x1][y2] - pref[x2][y1] + pref[x1][y1]

    # try all squares
    for i in range(w):
        for j in range(i+1, w):
            side = xs[j] - xs[i]
            # find y interval with same length
            for k in range(h):
                y2 = ys[k]
                y1_val = y2 - side
                if y1_val not in yi:
                    continue
                y1 = yi[y1_val]

                if y1 < 0 or y1 >= h:
                    continue

                if sum_region(i, y1, j, k) != (xs[j]-xs[i]) * (ys[k]-ys[y1]):
                    continue

                used = set()
                ok = True

                for x in range(i, j):
                    for y in range(y1, k):
                        if owner[x][y] == -1:
                            ok = False
                            break
                        used.add(owner[x][y])
                    if not ok:
                        break

                if ok:
                    print("YES", len(used))
                    print(*used)
                    return

    print("NO")

if __name__ == "__main__":
    solve()
```该解决方案首先压缩坐标，使几何形状成为有限网格，其中每个单位单元对应于一个基本矩形切片。 每个矩形都扩展到网格中，并记录每个单元格的所有权。 这一步至关重要，因为它将几何并集转化为离散覆盖问题。 

2D 前缀和允许快速检查候选区域是否被完全覆盖。 这避免了重复扫描每个单元格以进行有效性检查。 候选正方形的枚举是通过固定两个 x 边界并从边长匹配导出所需的 y 边界来完成的。 

当候选方块通过覆盖测试时，我们明确收集对其有贡献的所有矩形并验证不存在间隙。

 ## 边缘情况

 一种边缘情况是矩形恰好形成正方形的边界，但内部留空。 在这种情况下，前缀和检查会失败，因为覆盖单元格的总和小于候选正方形的面积，从而防止误报。 

当矩形完美对齐但在正方形内创建多个断开连接的组件时，会出现另一种边缘情况。 该算法仍然收集所有贡献的矩形，但覆盖检查确保不存在内部间隙，因此只要完全覆盖该区域，断开连接的平铺仍然会被接受。 

第三种情况是矩形超出候选正方形边界时。 显式所有权检查可确保正方形之外的任何贡献单元格的矩形都会使该候选无效，从而防止过度覆盖错误。
