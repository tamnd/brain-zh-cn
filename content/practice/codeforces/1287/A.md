 ## 解决方案

 ## 问题理解

 我们有几行独立的学生，每行由一个仅包含两个字符的字符串描述。 一个角色代表一名已经愤怒的学生，另一个角色代表一名冷静的学生。 该行排列成单行，时间以离散的步长演变。 每一步，每个当前愤怒的学生都试图将愤怒传播到他们面前的学生。 如果那个邻居在那一刻仍然平静，他们就会生气。 

关键是这个过程以波浪形式重复。 一旦学生生气，他们就会立即开始参与下一步传播愤怒的活动。 任务不是无限期地模拟整个过程，而是确定学生从平静过渡到愤怒的最后时刻。 

约束非常小：每行最多有 100 名学生，最多有 100 个测试用例。 这意味着在最坏的情况下，对时间和位置的直接模拟已经是可行的，因为即使是二次或稍微三次的行为也很容易在限制范围内。 然而，该过程的结构足够好，我们可以将其简化为每个测试用例一次线性扫描。 

一些微妙的情况值得牢记。 如果根本没有愤怒的学生，那么什么都不会改变，答案为零。 如果所有学生都已经生气了，那么在零时间之后什么也不会发生。 当愤怒的学生被平静的街区隔开时，会出现更有趣的情况。 例如，在类似的模式中`A P P A`，最右边的愤怒学生向左传播，而左边的愤怒学生向右传播，中间区域从两侧受到感染。 一种只关注一个方向的天真的方法会错过收敛效应。 

## 方法

 思考该过程的一个直接方法是逐分钟地模拟它。 在每一步中，我们都会扫描字符串并根据当前配置标记每个应该生气的学生。 我们重复直到没有变化发生。 这是正确的，因为它完全遵循定义：每分钟只有当前愤怒的学生影响他们的邻居。 

当弦完全平静时，除了一名接近末端的愤怒学生外，这种模拟的问题就变得显而易见。 在最坏的情况下，一端的一个愤怒的学生将采取 O(n) 步到达另一端，并且每一步都会扫描整个字符串。 这导致每个测试用例的复杂度为 O(n²)。 对于 100 名学生，这仍然是可以接受的，但它变成了不必要的开销，并且在概念上无法扩展。 

重要的观察是愤怒不会任意传播。 每个位置只关心它距离左边或右边最近的已经生气的学生有多远，具体取决于方向。 我们可以计算每个冷静的学生需要多长时间才能被愤怒的波浪袭击，而不是模拟时间演变。 答案就是这些到达时间中的最大值。 

这将问题简化为在两个方向上查找到最近的初始“A”的距离。 从左到右一次、从右到左一次就足以计算这些距离，而最后的激活时间是所有最初平静的位置中的最大值。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 逐步模拟 | O(n²) | O(n) | 已接受但没有必要 |
 | 双向传播| O(n) | O(n) | 已接受 |

 ## 算法演练

 我们独立处理每个测试用例，并计算愤怒到达每个位置的速度。 

1. 将字符串转换为数值数组，其中愤怒的学生被标记为时间 0 源，平静的学生最初未知。 这使我们能够根据距离而不是状态进行推理。 
2. 从左向右扫动，记录最近看到愤怒学生的位置。 当我们遇到一个冷静的学生时，我们可以计算出他距离最后一个愤怒的学生有多少步。 这给出了候选人从左侧到达的时间。 
3. 从右向左扫动，重复相同的逻辑。 这次我们跟踪右侧最近的愤怒学生，从右侧生成候选人到达时间。 
4、对于每个位置，其实际发怒的时间是其左侧到达时间和右侧到达时间中的最小值。 这反映了这样一个事实：更快的波决定了它何时改变状态。 
5. 最终答案是所有最初保持冷静的学生的每个位置时间的最大值，因为我们被要求在发生任何变化的最后一刻。 

其核心思想是，来自任一方向的最早的浪潮能够到达每个学生。 一旦本地知道到达时间，全局答案就是最慢的到达时间。 

不变的是，每次扫描之后，每个位置都知道来自一侧的最佳可能影响时间，并且结合两次扫描捕获所有可能的传播路径。 由于愤怒每单位时间仅传播到相邻位置，因此任何影响路径都必须源自某个初始“A”，并且最短的此类路径始终沿着该一维布局中的直线。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()

        INF = 10**9
        left = [INF] * n
        right = [INF] * n

        last = -1
        for i in range(n):
            if s[i] == 'A':
                last = i
                left[i] = 0
            elif last != -1:
                left[i] = i - last

        last = -1
        for i in range(n - 1, -1, -1):
            if s[i] == 'A':
                last = i
                right[i] = 0
            elif last != -1:
                right[i] = last - i

        ans = 0
        for i in range(n):
            if s[i] == 'P':
                t_arrive = min(left[i], right[i])
                ans = max(ans, t_arrive)

        print(ans)

if __name__ == "__main__":
    solve()
```该实现使用两个辅助数组来存储距每一侧最近的初始愤怒学生的距离。 从左到右的传递填充了愤怒从左侧到达每个位置的速度，而从右到左的传递则对相反的方向执行相同的操作。 只有当我们已经看到至少一个“A”时，我们才会更新距离，因为否则还没有源。 

最后一个循环忽略已经生气的学生，因为他们从零时间开始并且对最后一个激活时刻没有贡献。 对于冷静的学生，我们计算最早到达时间并跟踪所有位置的最大值。

 ## 边缘情况

 对于像这样的字符串`PPPPP`，没有最初的愤怒来源。 两次扫描都将所有距离保持为无穷远，并且最终答案仍然为零，因为没有发生状态变化。 

对于像这样的字符串`AAAA`，每个学生在零时间就已经处于活跃状态。 初始状态后不会发生任何转换，因此新感染学生的最大激活时间也为零。 

对于像这样的配置`PPAPP`，单个中心源产生对称扩展。 左扫和右扫都正确计算出相邻位置的距离1和最左边位置的距离2，并且新激活的学生中的最大值为1，符合单步传播规则。
