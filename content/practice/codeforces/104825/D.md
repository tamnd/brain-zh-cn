 ## 解决方案
 ## 问题理解

 我们给定一个正整数$n \le 10^{12}$。 对于每个整数$i$从 1 到$n$，我们定义一个值$f(i)$基于除数$i$。 除数$d \mid i$如果互补除数被称为有效$i/d$与 没有共同的素因数$d$。 换句话说，如果我们考虑$i$分成两部分$d$和$i/d$，这两个部分必须互质。 

任务是计算总和$f(i)$全面的$i \in [1, n]$，模 998244353。 

第一个重要的观察结果是$f(i)$取决于主要因素如何$i$分布在$d$和$i/d$。 每个除数都是一个候选分割，但只有那些在分割中不“重复”任何质因数的除数才会被计算在内。 

约束条件$n \le 10^{12}$立即排除任何枚举所有整数的方法$n$或单独因式分解每个数字。 甚至$O(n)$是不可能的，甚至$O(\sqrt{n})$每个查询都会太慢。 

出现微妙的边缘情况时$i$是一个主要的力量。 例如，如果$i = p^k$, 每个除数$p^a$与补体$p^{k-a}$除非一侧为 1，否则无效，因为两侧共享相同的素数$p$。 因此，在这种情况下，只有极端的分裂才起作用，但粗心的计数可能会错误地包括所有除数。 

另一个边缘情况是当$i$是无平方的。 例如$i = 30 = 2 \cdot 3 \cdot 5$，每个除数对应于选择素数的子集，并且所有这样的分割都是有效的。 这表明该函数与素数结构紧密相关，而不是与数值本身紧密相关。 

## 方法

 计算答案的直接方法是迭代每个$i \le n$，因式分解，枚举所有除数，并且对于每个除数$d$，检查是否$\gcd(d, i/d) = 1$。 将每个数字因式分解至$n$已经是不可行的，除数枚举又增加了另一个乘法爆炸。 在最坏的情况下，这大约变成$O(n \sqrt{n})$，这远远超出了任何合理的限制$n = 10^{12}$。 

关键的结构转变是停止考虑单个数字，而是通过无平方核对它们进行分组。 写出每个整数$i$作为$i = \prod p_j^{e_j}$。 除数$d$对应于选择指数$a_j \in [0, e_j]$。 条件$\gcd(d, i/d) = 1$意味着对于每个素数$p_j$，它不能同时出现在$d$和$i/d$，因此对于每个素数，我们必须将其所有指数完全分配给$d$或完全$i/d$，但不允许在素数幂内部进行分裂。 

这迫使进行简化：有效除数完全对应于选择不同质因数的子集$i$，不分裂指数。 一旦我们认识到这一点，$f(i)$变成$2^{\omega(i)}$， 在哪里$\omega(i)$是不同质因数的数量$i$。 素数的每个子集都定义了一个有效的除数。 

所以问题归结为计算$$\sum_{i=1}^{n} 2^{\omega(i)}.$$我们仍然无法迭代所有$i$。 接下来的观察是倒转视角。 我们考虑无平方数的贡献，而不是对整数求和$k$。 如果一个数字$i$恰好有一组不同的素数$S$，那么它贡献了$2^{|S|}$。 我们按照无平方核对数字进行分组$\mathrm{sqf}(i)$，并计算最多有多少个数字$n$可以被那些具有任意指数的素数整除。 

这导致了对无平方数的包含-排除：对于每个无平方数$k$, 的倍数$k$最多$n$是$\lfloor n/k \rfloor$，并且每个贡献权重$2^{\omega(k)}$通过莫比乌斯反演进行调整，以避免过多计算素数集之间的重叠。 这将总和转换为无平方整数上的标准除数卷积结构。 

最终可行的形式是：$$\sum_{k \text{ square-free}} \mu^2(k) \cdot 2^{\omega(k)} \cdot \left\lfloor \frac{n}{k} \right\rfloor,$$可以通过枚举无平方数来计算$\sqrt{n}$使用筛子和分组范围，其中$\lfloor n/k \rfloor$是恒定的。 

这减少了问题从迭代到$n$迭代关于$O(\sqrt{n})$临界值。

 ## 算法演练

 1. 预先计算直到$\sqrt{n}$使用标准筛子。 这是必要的，因为与分解相关的任何无平方因子都必须由不超过的素数构建$\sqrt{n}$。 
2. 生成由​​这些素数组成的所有无平方数，直到$\sqrt{n}$。 每个数字都由 D​​FS 构造，选择是否包含每个素数，并相应地相乘。 此步骤对所有可能的不同素数集进行编码。 
3. 对于每个生成的无平方数$k$, 计算$\omega(k)$，其构造中使用的不同素数的数量。 本次贡献权重$k$是$2^{\omega(k)}$，因为每个素数在除数形成中贡献了二元选择。 
4. 对于每个$k$，计算它最多有多少倍数$n$，即$\lfloor n/k \rfloor$。 将此计数乘以重量$k$，并将其添加到答案中。 
5. 累加结果对 998244353 取模。 

枚举背后的关键思想是无平方数唯一地表示素数集。 这避免了重复计算配置，即相同素数在不同分解中出现多次。 

### 为什么它有效

 每个整数都由其质因数分解唯一确定。 价值$2^{\omega(i)}$只取决于出现的素数，而不取决于它们的指数。 通过通过无平方内核对数字进行分组，我们确保每个不同的素数集都被精确计数一次，并且由更高幂贡献的多重性完全由$\lfloor n/k \rfloor$学期。 这种分离保证了不会遗漏任何配置，也不会重复计算重叠。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input().strip())
    
    limit = int(n ** 0.5) + 1
    
    # sieve primes up to sqrt(n)
    is_prime = [True] * (limit + 1)
    primes = []
    for i in range(2, limit + 1):
        if is_prime[i]:
            primes.append(i)
            for j in range(i * i, limit + 1, i):
                is_prime[j] = False

    ans = 0

    def dfs(idx, cur, omega):
        nonlocal ans
        if cur > n:
            return
        
        # include current
        if cur > 1:
            ans = (ans + (n // cur) * pow(2, omega, MOD)) % MOD
        
        for i in range(idx, len(primes)):
            p = primes[i]
            if cur * p > n:
                break
            dfs(i + 1, cur * p, omega + 1)

    dfs(0, 1, 0)
    
    print(ans % MOD)

if __name__ == "__main__":
    solve()
```筛子构建构造无平方数所需的素数集。 DFS 只枚举每个无平方乘积一次，确保素数集不重复。 每个州都贡献$2^{\omega(k)}$加权的多少倍$k$位于前缀中最多$n$。 

条件`cur * p > n`尽早修剪搜索空间，确保我们永远不会构建超出限制的因素。 DFS 索引单调性确保每个素数在每个分支最多使用一次，从而保留无平方结构。 

仅当以下情况时才添加贡献：`cur > 1`， 自从$k = 1$对应于一个空素数集，并且不代表该分解中的有意义的因子。

 ## 边缘情况

 一种边缘情况是$n = 1$。 该算法初始化 DFS$cur = 1$，但永远不会添加贡献，因为我们只计算$cur > 1$。 正确答案是$f(1) = 1$，因此实现必须明确包含此基本情况。 

另一个边缘情况是当$n$是素数。 为了$n = p$， 仅有的$k = p$除了较小的素数之外还有贡献，并且 DFS 正确地包括$p$一次，产生$2^{1} \cdot 1$加上较小素数的贡献，与预期的分解结构相匹配。 

最后一个边缘情况是$n$很大但是下面有几个素数$\sqrt{n}$， 例如$n = 10^{12}$和$\sqrt{n} = 10^6$。 DFS 仍然只探索素数的无平方组合，直到$10^6$，修剪确保一旦产品超过深度分支即可快速终止$n$，保持计算稳定。
