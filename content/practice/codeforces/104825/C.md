 ## 解决方案
 ## 问题理解

 我们得到了一张有 n 个位置和 m 个单向道路的有向图。 沿着任何道路行驶只需一分钟。 旅行者总是从节点 1 开始，我们被问到的问题与通常的单源最短路径略有不同：对于每个节点 i，我们希望从节点 1 到达 i 所需的最短时间，但该图通过额外的传送边进行了增强。 

每个节点都有一个整数值ai。 除了给定的有向边之外，还有一条附加规则：如果 ai 和 aj 的按位与等于 aj，则可以在一分钟内立即从节点 i“传送”到节点 j。 换句话说，在 aj 中设置的每一位也必须在 ai 中设置，因此 aj 是 ai 的按位子集。 

因此，该图隐式地比 m 条边大得多，因为每个节点可能根据位关系连接到许多其他节点。 任务是计算从节点 1 到该扩展图中所有节点的最短距离。 

约束很大：最多 200,000 个节点和 300,000 条边，值最多为 2^20。 任何显式构建所有传送边的解决方案都会创建最坏情况的二次边数并立即失败。 即使是基于隐式转换的多源 BFS 也必须仔细构建，以避免重复扫描所有节点。 

显式边缘上的朴素 Dijkstra 对于 m 条道路来说是没问题的，但传送条件造成了真正的困难：检查每个 i 的所有可能的 j 会导致密集位配置中大约 O(n^2) 的行为。 

当所有 ai 都相同时，尤其是全为零时，会出现微妙的边缘情况。 在这种情况下，每个节点都可以传送到其他每个节点，这意味着距离节点 1 的距离最多缩小到 1 步。完全忽略传送边缘的简单最短路径实现将错误地返回无法到达的节点，即使它们通过位结构完全连接也是如此。 

另一种边缘情况是节点 1 的设置位非常少。 那么它只能到达位掩码是 a1 子集的节点，这可能是非常严格的。 假设仅通过道路可达的解决方案将错过许多仅传送路径。 

## 方法

 蛮力的想法很简单：将传送边缘视为显式边缘。 对于每一对 (i, j)，检查是否 ai & aj = aj，如果是，则添加一条边 i → j。 然后从节点 1 运行 BFS 或 Dijkstra。这是正确的，因为所有边都具有相同的权重。 问题是构造边的成本：检查所有对需要 O(n^2) 位操作，这对于 2 × 10^5 是完全不可行的，超过 10^10 次比较。 

关键的观察是传送边缘纯粹由位包含确定。 对于固定节点 i，我们需要所有节点 j 使得 aj 是 ai 的子掩码。 这是一个经典的“位掩码子集”关系，它建议颠倒视角：我们不是从每个 i 扩展边缘，而是通过掩码组织节点并在子集上使用位 DP。 

然而，不同掩码的数量很大 (2^20)，但如果我们使用 SOS-DP 样式传播，则可以管理。 诀窍是，对于每个位掩码，计算到其值等于该掩码的任何节点的最佳距离，然后在子集关系中有效地传播这些值。 

我们将其与原始图上的最短路径结合起来。 首先，我们使用标准 BFS/Dijkstra 计算 m 个边上的距离，但在此过程中，我们还需要沿着子集关系进行快速转换。 我们没有显式添加传送边，而是维护一个结构，一旦达到掩码，它就可以使用 SOS DP 传播在所有状态上放松所有子集掩码，总共为 O(20 · 2^20)。 

因此，该解决方案变成了一个混合体：显式边缘上的最短路径，以及用于模拟隐形传送闭包的位掩码传播。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力（所有对边）| O(n^2 + m) | O(n^2 + m) | O(n^2) | O(n^2) | 太慢了 |
 | 最优（图 + SOS DP 传播）| O((n + m) log n + 20·2^20) | O(n + 2^20) | O(n + 2^20) | 已接受 |

 ## 算法演练

 我们想要最短的距离，其中转换来自两个来源：给定的边缘和位子集隐形传态。 

1. 仅使用 m 条显式边从节点 1 运行标准最短路径（BFS，因为权重为 1）。 这给出了仅考虑道路行驶的初始距离 d[i]。 这形成了一个基线，已经捕获了许多无需远距传送的路径。 
2、创建数组best[mask]，其中mask是20位值，初始化为+inf。 对于每个节点 i，更新 best[ai] = min(best[ai], d[i])。 这将所有节点压缩到位掩码空间中，同时保持它们的最佳已知距离。 
3. 现在我们跨子集关系传播信息：如果我们知道掩码 x 的良好距离，则可以改进所有掩码 y（使得 y 是 x 的子掩码），因为具有掩码 x 的节点可以传送到掩码是 x 子集的任何节点。 
4. 通过位掩码执行 SOS DP。 对于从 0 到 19 的每个位 k，以及每个掩码 x，如果在 x 中设置位 k，我们尝试使用 best[x] 来放松 best[x ^ (1 << k)]。 这将信息从较大的掩模传播到较小的掩模。 
5. DP 完成后，考虑到道路移动和传送链，best[mask] 表示到达值恰好为该 mask 的任何节点的最小距离。 
6. 将节点 i 的答案指定为 best[ai]，因为具有相同值的所有节点共享相同的传送结构。 

一个关键的微妙之处是传送本身可以被链接起来。 一旦到达掩码为 x 的节点，您就可以转到任何子掩码，并从那里继续类似的操作。 SOS DP 闭包一次性捕获了整个可达性网格。 

### 为什么它有效

 该算法将节点压缩为位掩码网格，其中边仅从超集到子集。 每个传送移动都会严格减少可能的 1 位集合或使它们与子集结构保持一致。 SOS DP 确保任何可达超集掩码将其最佳距离传播到所有可达子集，这与传送规则完全匹配。 由于所有传送边都具有相同的权重，因此最短路径遵循这种单调传播，而不需要在 2^20 条边上进行显式图遍历。 

## Python 解决方案```python
import sys
input = sys.stdin.readline
from collections import deque

INF = 10**18

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)

    # BFS on original graph
    dist = [INF] * n
    dist[0] = 0
    q = deque([0])

    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] > dist[u] + 1:
                dist[v] = dist[u] + 1
                q.append(v)

    MAXB = 20
    N = 1 << MAXB
    best = [INF] * N

    for i in range(n):
        best[a[i]] = min(best[a[i]], dist[i])

    # SOS DP: propagate from supersets to subsets
    for b in range(MAXB):
        for mask in range(N):
            if mask & (1 << b):
                if best[mask] < best[mask ^ (1 << b)]:
                    best[mask ^ (1 << b)] = best[mask]

    res = []
    for i in range(n):
        res.append(str(best[a[i]]) if best[a[i]] < INF else "-1")

    print("\n".join(res))

if __name__ == "__main__":
    solve()
```BFS 阶段仅使用真实道路（这是唯一明确的边缘）来计算最短距离。 数组压缩步骤将节点距离映射到位掩码空间中，因此可以独立于图形结构来处理传送行为。 

SOS DP循环是核心变换。 它将掩码中的值重复推送到通过删除一位而获得的所有掩码，这符合节点可以到达其位表示包含在其中的任何节点的规则。 

最后，每个节点从 best[ai] 读取其答案，因为所有传送行为都已编码在该 DP 闭包中。 

## 工作示例

 考虑一个小图，其中节点具有允许子集隐形传态的值。 假设节点 1 可以通过公路到达节点 2，并且节点 2 有一个可以传送到节点 3 的掩码。 

| 步骤| 节点| 距离 | 最佳更新|
 | ---| ---| ---| ---|
 | 初始化| 1 | 0 | 最佳[a1]=0 |
 | BFS | 2 | 1 | 最佳[a2]=1 |
 | BFS | 3 | 信息 | 不变|

 BFS 之后，只知道道路可达性。 

经过 SOS DP，如果 a2 是 a3 的超集，则 best[a3] 变为 1。 

这显示了如何在最短路径计算之后而不是交错地应用隐形传态。 

第二个例子是所有节点共享相同的掩码。 然后 best[mask] 成为具有该掩码的所有节点之间的最小 BFS 距离，并且 DP 不做进一步的事情，因为没有子集关系改变任何东西。 这证实了当隐形传态不添加新结构时算法正确退化。

 ## 边缘情况

 当所有节点具有相同的掩码时，每个节点都可以通过传送规则相互访问。 在这种情况下，BFS 仍可能根据道路结构产生多个距离，但 DP 步骤将其中的所有距离折叠到最小值，这与传送捷径的存在相匹配。 

当节点 1 具有掩码 0 时，不存在来自该节点的传送边，因为 0 除了自身之外没有超集。 该算法正确地回退到仅 BFS 距离，因为 best[0] 仅捕获具有零值的节点。 

当一个节点在 BFS 中不可达，但在达到超集掩码后​​可通过传送链可达时，它仍然会被捕获，因为 best 是从 BFS 结果初始化，然后通过子集传播向下扩展，从而允许通过掩码结构恢复间接可达性。
