 ## 解决方案
 ## 问题理解

 我们得到一条一维线$n$最初担任职位的人$1$通过$n$，以及每个位置$i$有一个价值$a_i$。 我们可以将“景点”放置在整数位置，每个景点都会让所有人朝它移动一步：左边的人向右移动，右边的人向左移动，景点上的人保持原样。 重复此操作任意多次，就会生成多种可能的人员最终配置。 任务是计算所有不同配置的分数总和，其中配置的分数是$a_i$对于每个职位的人$i$。 

因为$n$可以达到$2 \cdot 10^5$每个测试用例和所有测试用例的总和不超过$2 \cdot 10^5$，任何超过每个测试用例线性时间的解决方案都是不可行的。 暴力枚举所有位置数组是不可能的，因为配置的数量呈指数增长$n$。 最终答案必须以模计算$998,244,353$，这意味着中间和可以溢出 32 位整数，并且所有算术都应该以该素数为模进行。 

边缘情况很微妙。 如果所有值$a_i$人人平等，无论最终地位如何，每个人的贡献都是相同的。 如果$n = 1$，无法进行任何移动。 如果$a_i$值变化很大，最终的总和对所有可能的吸引力序列之后每个位置可以占据多少人很敏感。 简单地计算“谁可以到达哪里”可能会错误地计算重复项，因此我们必须对可能的重叠进行组合推理。 

## 方法

 暴力方法是生成所有景点序列，模拟移动，记录结果位置数组，并对它们的分数求和。 这是正确的，因为它直接遵循规则，但显然是不可行的。 为了$n = 20$, 已经有超过$2^{20}$可能的配置，远远超出了我们在 2 秒内可以计算的范围。 

关键的见解是独立对待每个人。 每个人都从一个独特的位置开始，每个吸引力要么增加、减少，要么保持其位置。 这个问题可以重构为计算每个人在重复应用吸引力的情况下可以到达的不同位置的数量。 当多个人一起考虑时，由于移动的单调性，可到达的位置形成连续的区间：一旦一个人移动超过某个点，他们就无法返回超过该点，除非在另一侧放置另一个吸引力。 

从数学上讲，一组方法的数量$n$任意景点对应于整数计数序列后，人们可以分布在不同的位置上$1 \le p_1 \le p_2 \le \dots \le p_n \le n$，其中每个人$p_i$可以占据受初始位置限制的区间内的位置。 这相当于计算弱增加序列$[1, n]$开始于$p_i = i$。 然后分数的总和成为所有序列的总和$a_{p_1} + \dots + a_{p_n}$，可以使用动态规划通过在利用前缀和的同时迭代地添加贡献来有效地计算。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n * 2^n) | O(n * 2^n) | O(2^n) | O(2^n) | 太慢了 |
 | 最优（带前缀和的 DP）| O(n^2) | O(n^2) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个测试用例，请阅读$n$和数组$a$。 初始化DP数组`dp`尺寸的`n + 1`， 在哪里`dp[i]`表示以位置结束的序列的分数总和`i`。 
2. 初始化`dp[0] = 0`作为基本案例。 计算前缀和`a`以允许快速范围查询。 
3. 从左到右遍历每个人。 对于人$i$， 更新`dp[i]`作为所有的总和`dp[j] + a[i]`为了$j \le i$。 这表示在位置或之前结束的延伸序列$i$通过添加人员$i$在位置$i$。 
4. 使用累积前缀和来避免重复重新计算和。 让`pref[i]`存储总和`dp[0..i]`。 然后`dp[i] = pref[i-1] + a[i]`, 取模$998,244,353$。 
5.处理完所有人员后，将所有人员求和`dp[i]`获得此测试用例的分数总和。 打印取模结果$998,244,353$。 

关键的不变量是在每一步中，`dp[i]`正确解释所有以位置结束的序列`i`，前缀和保证先前序列的所有扩展都只包含一次。 通过从左到右移动并使用前缀和，我们对每个不同位置数组精确计数一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    dp = [0] * n
    pref = [0] * n
    
    dp[0] = a[0]
    pref[0] = dp[0]
    
    for i in range(1, n):
        dp[i] = (pref[i - 1] + a[i]) % MOD
        pref[i] = (pref[i - 1] + dp[i]) % MOD
    
    print(pref[-1])
```DP 阵列`dp[i]`保存以该位置的人结尾的序列的分数总和`i`。 前缀数组`pref[i]`允许我们有效地计算所有先前序列的总和。 在每一步都应用模数以防止溢出。 通过使用基于 0 的索引并在以下位置开始循环可以避免差一错误`i = 1`。
