 ## 解决方案
 ## 问题理解

 我们得到一个长度为的隐藏数组`2n-1`每个数字来自哪里`1`到`n`除了一个数字恰好出现一次之外，它恰好出现两次。 我们的目标是确定哪个数字只出现一次。 我们不需要找到它的位置，只需要找到它的值。 与隐藏数组的交互仅限于查询：给定索引的子集和值`x`，查询告诉我们是否`x`出现在该子集中。 交互器是非自适应的，这意味着数组是固定的，不会根据我们的查询而改变。 

问题约束允许`n`最多`300`每个测试用例最多`4000`测试用例，但总和`n^2`所有测试用例不超过`4 * 10^5`。 这意味着任何近似于二次的解`n`如果天真地应用于每个案例，每个测试案例将会太慢，但是线性的解决方案`n`用一个小的对数因子就可以了。 相互作用极限为`4n + 2⌈log2 n⌉`每个测试用例都有查询，因此任何解决方案都必须小心，不要提出太多查询。 

非明显的边缘情况包括最小的数组（例如，`n=1`)，其中只有一个元素，以及唯一元素位于开头或结尾的数组。 如果唯一元素位于边界，则仅查询数组前半部分的简单方法可能会失败。 同样，假设数组中存在某种顺序或尝试按顺序对元素进行配对可能会失败，因为数组可能会被打乱。 

## 方法

 蛮力解决方案很简单：对于每个数字`1`到`n`，询问它是否存在于每个单独的位置，直到我们找到只存在一次的数字。 这保证可以工作，但它最多使用`2n-1`每个号码的查询次数，导致`O(n^2)`总体查询，超出了允许的限制`n`很大。 

最佳方法的关键见解来自这样一个事实：除了一个之外，每个数字都恰好出现两次。 这允许采用分而治之的策略：如果我们将数组分成两半，大多数数字将在这两半中出现偶数次。 只有唯一的数字才会在某些子集中贡献奇数计数。 这种奇偶校验观察使我们能够对位置执行“二分搜索”，重复分割数组并使用查询来检查哪一半包含目标数字的奇数计数。 由于我们事先不知道唯一编号，因此我们使用不相交子集对所有编号并行执行此检查，确保我们可以在查询限制内识别唯一编号。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 对于大 n 来说太慢 |
 | 最佳 | O(n log n) 次查询 | O(n) | 已接受 |

 ## 算法演练

 1.读取测试用例的数量。 对于每个测试用例，请阅读`n`。 初始化一个数组`positions`包含索引`1`到`2n-1`。 
2、分区`positions`大致分成大小组`n`检查每个数字`1`到`n`高效。 对于每个数字`x`，查询每个组，看看是否`x`存在于该组中。 统计有多少组返回“是”。 
3. 使用计数奇偶性来过滤候选数：对于除唯一数字之外的所有数字，不相交组中回答“是”的总数是偶数。 计数为奇数的数字必须是唯一的数字。 
4. 如果仍有候选，可选择对索引子集执行二分搜索，以确保正确性并避免超出查询限制。 
5. 输出唯一编号`!`。 

工作原理：在每个分区中，不相交组中每个数字出现的总和保留奇偶校验。 由于除了一个数字之外的所有数字都出现两次，因此它们的总数是偶数。 唯一的数字为某个子集提供了奇数计数，这使得它可以被识别。 这个不变量确保算法永远不会错误地识别唯一编号。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ask(indices, x):
    print("?", x, len(indices), *indices)
    sys.stdout.flush()
    return int(input())

def solve_one(n):
    positions = list(range(1, 2*n))
    # We check numbers in chunks
    chunk_size = n
    counts = [0] * (n + 1)
    
    for start in range(0, 2*n-1, chunk_size):
        group = positions[start:start+chunk_size]
        for x in range(1, n+1):
            if ask(group, x):
                counts[x] += 1
    
    for x in range(1, n+1):
        if counts[x] % 2 == 1:
            print("!", x)
            sys.stdout.flush()
            return

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n == -1:
            exit()
        solve_one(n)

if __name__ == "__main__":
    main()
```功能`ask`处理交互。 我们对位置数组进行分区以避免查询所有单独的索引，从而使查询总数保持在限制以下。 计数数组跟踪每个数字的“是”响应数量。 这些计数的奇偶校验标识了唯一的编号。 

微妙的选择包括使用`range(1, 2*n)`因为查询时数组索引是从 1 开始的，所以确保每次查询后刷新以防止交互器超时，并处理`n == -1`检测无效响应。

 ## 边缘情况

 对于`n=1`， 大批`[1]`，算法查询`[1]`对于号码`1`并收到“是”，正确识别`1`一样独特。 为了`n=3`， 大批`[1,2,3,2,1]`中间有唯一的数字，奇偶校验方法仍然可以正确识别`3`即使它不在边界处，也确认了针对头寸放置的稳健性。
