 ## 解决方案
 ## 问题理解

 我们被要求模拟一家限量版商店，爱丽丝和鲍勃轮流挑选商品，但有一点不同：我们不控制谁先走或按什么顺序进入。 根据我们的说法，每个项目都有一个值，而爱丽丝和鲍勃每个人都有一个项目的个人排名。 这个问题问的是，对于爱丽丝来说，在所有可能的购买方式中，她最终能获得的最大价值总和是多少。 

每个测试用例提供一个项目值数组`v`, Alice 的偏好`a`，以及鲍勃的偏好`b`。 我们必须考虑到，在每个回合中，无论谁行动，都会获得他们当前最喜欢的可用物品。 我们不知道回合的顺序，因此我们需要推理爱丽丝可以购买的所有可能的集合。 答案是这些可能集合的最大总和。 

限制因素很重要：`n`可以达到200,000个，所有测试用例的总和也达到200,000个。 这立即排除了对每个回合顺序的简单模拟，在最坏的情况下这将是 O(n!)。 相反，考虑到鲍勃总是会选择他最喜欢的剩余项目，我们需要一种方法来有效地推理爱丽丝可以获得哪些项目。 

边缘情况包括负值，因为爱丽丝可能会避免拿走会减少她总数的物品，以及根据我们的说法，鲍勃的最高偏好与爱丽丝最有价值的物品发生冲突的情况。 例如，如果爱丽丝的所有高价值物品也是鲍勃的最爱，那么她最终可能只会得到低价值或负的物品。 一个幼稚的实现可能会在不考虑 Bob 干扰的情况下对 Alice 的所有顶级项目求和，从而给出不正确的最大值。 

## 方法

 暴力方法是枚举 Alice 和 Bob 的所有可能的选择序列，模拟每个序列，并跟踪 Alice 的总和。 这是正确的，但在计算上是不可能的`n > 10`因为它需要 O(n!) 次操作。 暴力破解原则上是有效的，因为它会检查每个可行的序列，确保 Alice 的总和最大化。 当 n 很大时，它会失败，因为阶乘增长很快超出了可行的计算。 

关键的见解是要认识到选择的顺序仅与谁首先获得每个项目有关。 鲍勃总是会选择他最喜欢的可用项目，而爱丽丝也会对她的项目做同样的事情。 因此，如果 Alice 比 Bob 更喜欢某件物品并且能够先于 Bob 拿到该物品，那么 Alice 就可以得到该物品的保证。 我们可以使用“回合顺序优势”的概念来形式化这一点。 

具体来说，对于每个项目，我们可以计算它在 Alice 的偏好和 Bob 的偏好中的排名。 如果爱丽丝的排名高于鲍勃的排名，她有可能在鲍勃之前获得它，具体取决于已拿走的物品数量。 相反，如果鲍勃的等级更好，他总是可以阻止爱丽丝获得它。 这将问题简化为针对偏好前缀的动态编程，或者等效的贪婪方法：按照 Alice 的顺序迭代项目，并仅选择她可以声明的项目，跳过 Bob 之前会采取的项目。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n!) | O(n) | 太慢了 |
 | 基于排名的贪婪 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 对于每个项目，计算其在 Alice 和 Bob 的偏好数组中的位置。 这些位置定义了两者的“优先级分数”。 Alice 的位置数组`posA[item]`是项目出现在列表中的索引，对于 Bob 来说类似`posB[item]`。 
2. 初始化列表`alice_items`跟踪爱丽丝可能保护的物品。 按照 Alice 的偏好顺序迭代项目。 
3. 对于 Alice 偏好中的每个项目，检查 Alice 的位置是否优于 Bob 的位置。 如果`posA[item] < posB[item]`，Alice 可以在 Bob 之前到达它，我们认为它可用。 
4. 根据这条规则，将Alice可以领取的所有物品的价值相加。 这个总和是她可以获得的最大可能总和，因为它捕捉到了这样的场景：她总是在鲍勃之前选择一个项目，并尊重他们的回合限制。 
5. 输出测试用例的总和。 

为什么它有效：该算法之所以有效，是因为我们有效地计算了爱丽丝可以拿走的一组“安全”物品，假设鲍勃总是以最佳方式阻止她。 通过比较偏好位置，我们保证不会高估：如果 Alice 的排名不更高，则 Bob 排名较低的任何项目都可以被阻止。 因此，将爱丽丝可以按照她的偏好顺序获得的物品相加，就可以得到可达到的最大总价值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        v = list(map(int, input().split()))
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        posA = [0] * (n + 1)
        posB = [0] * (n + 1)
        for idx, item in enumerate(a):
            posA[item] = idx
        for idx, item in enumerate(b):
            posB[item] = idx

        result = 0
        for item in a:
            if posA[item] < posB[item]:
                result += v[item - 1]
        print(result)

if __name__ == "__main__":
    solve()
```第一部分读取输入并为 Alice 和 Bob 构建位置数组。 循环结束`a`确保我们考虑 Alice 订单中的项目。 条件`posA[item] < posB[item]`保证爱丽丝可以在鲍勃之前选择它。 使用输入中从 1 开始的索引，我们可以通过以下方式访问值`v[item-1]`。 打印累积和给出每个测试用例的答案。
