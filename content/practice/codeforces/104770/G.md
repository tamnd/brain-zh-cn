 ## 解决方案
 ## 问题理解

 电梯显示屏上写着我们的楼层号。 Katya 并不直接阅读它；而是直接阅读它。 她在面板前面的镜子中看到了它。 镜子同时进行两种变换。 首先，数字的顺序颠倒了，因为左右交换了。 其次，每个数字本身都被垂直反射后的样子所取代。 一些数字在反射后仍然有效并成为不同的数字，而其他数字则无法匹配任何有效的数字形状并被认为没有变化。 

因此，任务是模拟数字在七段式显示器上书写并在镜子中查看时如何变换：反转数字顺序，然后如果存在映射，则将每个数字替换为镜像对应的数字，否则将其保留原样。 

输入是最大 10^18 的单个整数 k，这意味着该数字最多有 18 位。 这立即排除了对大整数算术或超出位数线性工作的字符串处理的任何需要。 任何以 O(d) 运行的解决方案（其中 d 是位数）都足够快。 

一个微妙的问题是，并非所有数字在反射下都表现得干净利落。 像 0、1、2、5、6、8、9 这样的数字通常被考虑在此类问题的镜像变换中，但只有其中一些对应于有效的镜像数字，而其他数字要么映射到不同的数字，要么保持不变，具体取决于是否存在有效的反射。 如果数字没有清晰地映射，则问题表明它在反射后被感知为本身，这可以防止丢失信息，但会造成不对称。 

边缘情况来自反转后反射如何与前导零相互作用。 例如，反转 250 会得到 052，并且必须在输出中删除前导零。 构造反转字符串并直接打印它的简单方法可能会意外输出前导零或将它们不一致地视为整数。 

另一个边缘情况是没有有效镜像对应项的数字。 粗心的实现可能会假设数字的固定双射，但该问题明确允许回退行为，这意味着某些数字在反射后保持不变。 这打破了镜像映射完全对称的常见假设，并强制应用数字规则。 

## 方法

 暴力解释很简单。 将整数转换为字符串，反转它，然后对每个字符应用数字转换规则。 这是正确的，因为镜像效果纯粹是位置加上每位变换，因此模拟与过程完全匹配。 

这种方法的成本与位数成正比，最多为 18。即使我们将其视为 n 位数字的一般问题，复杂度也将是 O(n)，这在输入大小方面已经是最佳的。 暴力想法有时在类似任务中失败的唯一原因是当转换涉及嵌套操作或每个数字的重复重新计算时，但这里的情况并非如此。 

关键的观察结果是，除了反转之外，数字之间不存在全局依赖性。 每个数字反转后独立变换。 这将整个问题简化为简单的映射加上字符串反转。 不需要动态规划，不需要图形推理，也不需要算术分解。

 ## 算法演练

 我们将数字视为字符串，以便数字操作直接且安全。

1. 将整数 k 转换为其字符串表示形式。 这避免了任何数字的算术提取并保持明确的排序。 
2. 反转字符串。 这模拟了镜子水平翻转整个显示器。 首先这样做的原因是反射先于数字身份作用于空间位置。 
3. 定义反射的数字转换规则。 对于每个数字，确定卡蒂亚在镜子后看到的内容。 如果一个数字映射到有效的镜像数字，我们就会相应地替换它。 如果没有，我们保持该数字不变。 
4. 迭代反转的字符串并将转换规则独立地应用于每个字符。 这是有效的，因为反射不会引入交叉数字效应。 
5. 将转换后的数字连接成一个字符串。 
6. 通过转换为整数或手动修剪来去除前导零。 这可确保输出与正常的数字格式匹配。 

### 为什么它有效

 正确性来自于将镜像操作分解为两个独立的动作：位置排列和局部数字变换。 反转步骤完全捕获了镜子引起的位置排列。 数字映射步骤捕获每个字形在反射下如何变化。 由于这两个步骤都不依赖于相邻数字，因此它们的组合足以对整个视觉变换进行一次精确建模，无需迭代或校正。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    k = input().strip()
    if not k:
        return

    # reverse digit order
    k = k[::-1]

    # mirror transformation for digits
    mp = {
        '0': '0',
        '1': '1',
        '2': '2',
        '5': '5',
        '6': '9',
        '8': '8',
        '9': '6'
    }

    res = []
    for ch in k:
        if ch in mp:
            res.append(mp[ch])
        else:
            res.append(ch)

    ans = ''.join(res)

    # remove leading zeros
    ans = ans.lstrip('0')
    if not ans:
        ans = '0'

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案将数字读取为字符串以避免任何数字溢出问题，即使约束允许整数存储。 立即进行反转以模拟镜子的几何效果。 映射字典对数字反射行为进行编码，包括对称数字和交换对，如 6 和 9。 

映射中不存在的数字保持不变，这符合问题的后备规则。 最后，删除前导零，因为像 250 这样的反转数字自然会生成以零开头的字符串，这在标准数字输出中无效。

 ## 边缘情况

 一种重要的边缘情况是反转后产生前导零的输入。 用于输入`10`, 反转给出`01`。 如果没有标准化，一个幼稚的实现将输出`01`，这是无效的。 该算法通过在构造转换后的字符串后去除前导零来处理此问题，产生`1`。 

另一种情况是在反射下保持不变的数字，例如`8`。 用于输入`808`, 反转产生`808`，并且映射使所有数字保持不变。 该算法保留了对称性，因为每个数字都是独立处理的，因此不会发生位置损坏。 

第三种情况涉及映射到不同数字的数字，例如`6`和`9`。 用于输入`609`, 逆转收益率`906`，并且映射可以正确保留交换。 由于每个数字在反转后都会进行转换，因此交换不会干扰位置正确性，并且最终输出与镜像读数保持一致。
