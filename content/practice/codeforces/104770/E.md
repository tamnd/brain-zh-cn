 ## 解决方案
 ## 问题理解

 我们收到一份酒店日志中记录的货币费用清单。 每个条目对应于谢尔盖入住期间提供的一些服务，包括房间本身。 数据变得混乱的是，我们不再知道哪个条目对应于哪个服务类型，只剩下原始成本。 

关键的结构规则是每种服务类型在整个住宿期间都有固定价格。 这意味着，如果一项服务在日志中多次出现，则所有这些出现都具有相同的值，但我们无法将它们与具有相同成本的其他服务区分开来。 一项特别的服务是房间，据悉谢尔盖正好住过`n`天，所以客房服务的费用一定是准确的`n`总共次数。 

任务是确定可以代表每日客房费用的所有可能值，这与我们可以将每条记录分配给某种服务类型的想法一致，并且客房服务必须准确考虑`n`的`m`记录。 

输入数据量较大，可达30万条记录。 这立即排除了任何对成对的二次推理或对每个候选者的整个数组进行重复重新扫描的情况。 任何检查每个值的可行性的解决方案都必须在总体线性或近线性时间内完成。 

一个微妙的陷阱是假设房间成本必须准确显示`n`次。 这不是必需的； 它只需要至少出现`n`多重集中的时间，以便我们可以选择`n`其中发生的事件代​​表了房间内几天的情况。 额外的事件可以简单地解释为碰巧花费相同费用的其他服务。 

另一个潜在的混乱源于认为服务是按天分组的。 除了每天发生的服务数量之外，没有任何限制`n`总共天数，房间每天出现一次。 

## 方法

 直接的方法是尝试每个不同的成本值作为房价的候选值。 对于每个候选值`x`，我们计算它在列表中出现的次数，并检查它是否至少出现`n`次。 如果是这样，我们可以分配`n`将这些事件发送给客房服务，并将其余事件解释为相同类型的其他服务。 这是正确的，因为没有什么可以阻止服务类型用于多个不同的日记帐分录。 

这种暴力的想法是正确的，但是对所有内容进行重新扫描`m`每个不同值的条目都会导致最坏的情况`O(m^2)`当所有值都不同时，这对于`m = 3 × 10^5`。 

关键的观察是我们不需要重复扫描。 一个值的可行性仅取决于它的频率。 一旦我们一次性计算出所有值的频率，我们就可以直接过滤那些频率至少为`n`。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 每个值的强力 | O(m^2) | O(米) | 太慢了|
 | 频率计数 | O(米) | O(米) | 已接受 |

 ## 算法演练

 1. 阅读`n`,`m`，以及费用清单。 目标是了解每种成本出现的频率。 
2. 构建列表中所有值的频率图。 这捕获了每个可能的服务价格在日志中出现的次数。 
3. 迭代频率图中的所有不同值。 
4. 对于每个值`x`，检查其频率是否至少为`n`。 如果是，请包括`x`在答案集中。 推理是我们可以分配`n`这些事件的客房服务`n`天。 
5. 以任意顺序输出有效候选者的数量和列表本身。 

### 为什么它有效

 每个不同的成本值对应于一种潜在的服务类型，因为相同值的所有出现都可以被视为具有固定价格的一项服务。 代表房间的值的唯一限制是我们必须能够每天准确地分配一个房间条目`n`天，这至少需要`n`发生。 不存在进一步的结构约束，因为未使用的事件始终可以解释为相同类型的附加服务记录。 这使得频率成为唯一的决定因素。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    c = list(map(int, input().split()))
    
    freq = {}
    for x in c:
        freq[x] = freq.get(x, 0) + 1
    
    res = []
    for x, f in freq.items():
        if f >= n:
            res.append(x)
    
    print(len(res))
    print(*res)

if __name__ == "__main__":
    solve()
```该实现完全依赖于单次构建的频率字典。 这避免了任何重复扫描。 最终的过滤步骤与不同值的数量呈线性关系，最多为`m`。 

一个常见的错误是试图模拟每天的作业或建立明确的分组。 这是不必要的，因为唯一的全局约束是总发生次数，而不是每日结构。

 ## 边缘情况

 当`n = 1`，每个值都是有效的，因为任何单个值都可以作为当天的房费。 该算法自然地处理这个问题，因为每个频率至少是一个，所以所有的键都被包括在内。 

当所有值都相同时，频率等于`m`，并且算法正确返回该值，如果`m ≥ n`。 分组解释仍然成立，因为我们可以准确分配`n`房间里发生的事情。 

当值大部分是唯一的且只有一个值重复足够多次时，只有该重复值通过频率阈值。 基于字典的计数确保我们不会错误地将单个事件视为有效候选者。
