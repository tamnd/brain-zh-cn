 ## 解决方案
 ## 问题理解

 我们有一个小的水平单元格条，每个单元格可以是黑色或白色。 我们的目标是通过重新绘制单个连续片段来使每个单元格变白。 重绘操作将该段中的每个黑色单元变成白色，而白色单元保持不变。 面临的挑战是确定保证整个条带变白的段的最小长度。 输入指定多个测试用例，每个测试用例给出单元格数量和初始颜色作为“B”和“W”字符串。 每个测试用例的输出是一个整数，表示所需的最小段长度。 

限制非常小：任何条带中的单元数量最多为 10 个，并且最多可以有 10,000 个测试用例。 小条带长度使我们能够考虑检查所有可能的连续段的解决方案，而无需考虑性能问题。 当黑色细胞位于边界或聚集在极端时，就会出现边缘情况。 例如，如果单个黑色单元位于最左或最右位置，则最小线段必须覆盖它； 如果黑色单元分散，则最小段必须从第一个黑色单元跨越到最后一个黑色单元。 

粗心的实现可能只是简单地计算黑色单元的数量，或者假设左侧的第一个黑色单元确定段长度，当黑色单元被白色分隔时，这可能会失败。 例如，在条带“BWWB”中，正确的段从第一个黑色单元格跨越到最后一个黑色单元格，长度为 4，而不仅仅是 1 或 2。 

## 方法

 暴力方法将枚举每个可能的连续片段，并检查绘制该片段是否会使所有单元格变白。 由于最大条带长度为 10，因此每个测试用例最多涉及 55 个段（1 到 n 的总和），这是完全可以接受的。 每次检查在 n 中都是线性的，因此每个测试用例产生大约 550 次操作，并且在 10,000 个测试用例中产生大约 550 万次操作，这已经足够快了。 这种方法是正确的，因为它明确地考虑了所有可能的段，但对于这样一个简单的问题来说，它的繁重是不必要的。 

最佳方法利用了只有最左边和最右边的黑色单元格这一观察结果。 任何比第一个和最后一个黑色单元之间的距离短的线段都不能覆盖所有黑色单元。 因此，最小段必须在最左边的黑色处或之前开始，并在最右边的黑色处或之后结束。 最佳长度是最后一个黑色的索引减去第一个黑色的索引加一。 这种贪婪的洞察力将问题简化为一次查找第一个和最后一个黑色单元格，为每个测试用例提供 O(n) 解决方案，在给定 n ≤ 10 的情况下，速度非常快。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(1) | O(1) | 由于 n 小而被接受 |
 | 贪婪（第一个倒数的黑色）| O(n) | O(1) | O(1) | 已接受，最佳 |

 ## 算法演练

 1. 对于每个测试用例，读取单元格数量 n 和代表颜色的字符串 s。 
2.初始化两个变量，`left`和`right`，跟踪最左边和最右边黑色单元的索引。 开始`left`在 n 和`right`设置为 -1 以保证它们将被覆盖。 
3. 从左到右循环字符串。 当在索引 i 处发现黑色单元格时，更新`left`到`min(left, i)`和`right`到`max(right, i)`。 
4. 循环结束后，`left`保存第一个黑色单元格的索引，并且`right`保存最后一个黑色单元格的索引。 覆盖所有黑色单元格的最小线段的长度`right - left + 1`。 
5. 输出测试用例的计算长度。 

该算法之所以有效，是因为任何比第一个和最后一个黑色单元之间的距离短的线段都会留下至少一个黑色未被覆盖。 精确覆盖从第一个到最后一个黑色单元可确保包含所有黑色单元，并避免对段外已有的白色单元进行不必要的重新绘制。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        left = n
        right = -1
        for i, c in enumerate(s):
            if c == 'B':
                left = min(left, i)
                right = max(right, i)
        print(right - left + 1)
```该解决方案读取测试用例的数量，然后迭代每个条带。 最左边和最右边的黑色单元通过对字符串的一次遍历来识别。 最小段长度是通过减去索引并加一来计算的。 使用`strip()`确保任何尾随换行符`input()`不干扰索引。 

## 工作示例

 **示例1：**“WBBWBW”

 | 索引 | 0 | 1 | 2 | 3 | 4 | 5 |
 | ---| ---| ---| ---| ---| ---| ---|
 | 细胞| 西 | 乙| 乙| 西 | 乙| 西 |
 | 左| 1 | 1 | 1 | 1 | 1 | 1 |
 | 对| 1 | 2 | 2 | 2 | 4 | 4 |

 第一个黑色位于索引 1，最后一个黑色位于索引 4，因此最小线段长度 = 4 - 1 + 1 = 4。 

**示例 2：** “BWWB”

 | 索引 | 0 | 1 | 2 | 3 |
 | ---| ---| ---| ---| ---|
 | 细胞| 乙| 西 | 西 | 乙|
 | 左| 0 | 0 | 0 | 0 |
 | 对| 0 | 0 | 0 | 3 |

 段长度 = 3 - 0 + 1 = 4。 

这些痕迹证实贪婪方法正确识别了覆盖所有黑色单元格的跨度。

 ## 边缘情况

 当黑色单元格被白色单元格分开时，就会出现关键的边缘情况。 例如，“BWWB”在索引 0 和 3 处有黑色。仅计算黑色单元数量的简单方法会错误地建议长度为 2 的片段。算法正确地将最小片段计算为 3 - 0 + 1 = 4。另一种边缘情况是条带中的单个黑色单元，例如“WBBW”。 该算法计算`left = right = 2`，产生段长度 1，这是正确的。 这种方法可以正确处理黑色单元的所有位置和间距。
