 ## 解决方案
 ## 问题理解

 我们在平面上有两个圆形“威胁区”。 每个都由中心点和半径定义。 中心是一座城市，半径描述了敌方环从该城市延伸多远。 

我们可以在飞机的任何地方放置一个雷达。 该雷达可检测半径范围内的任何物体$r$以雷达位置为中心。 如果在攻击开始的那一刻，雷达能够检测到两个敌方圆圈中的每一个至少一个点，则认为雷达成功。 用几何术语来说，雷达盘必须与两个给定的圆相交。 

任务是选择雷达位置及其半径，使之成为可能，同时最小化半径。 

输入大小是恒定的，只给出两个圆，因此任何涉及少量固定几何计算量的解决方案都很容易足够快。 不需要渐近优化技巧，但精度和正确的案例处理至关重要。 

一个幼稚但危险的错误是假设最佳雷达位置必须位于几个明显的位置之一，例如圆心或中心中点。 这会失败，因为最佳点可能位于平面上的任何位置，通常沿着中心之间的线段，但不一定位于离散候选点处。 

另一个常见的陷阱是忽视收容案例。 如果一个圆完全位于另一个圆内部，或者它们严重重叠，则最佳半径的行为与不相交情况下的行为不同。 

例如，如果两个圆重合，答案就是较小的半径，因为将雷达放置在中心已经保证在等于该半径的距离处检测到两个边界。 任何仅考虑中心之间距离的方法都会错误地返回零。 

## 方法

 我们想要一个点$P$最小化到达两个圆边界所需的最大距离。 

对于固定雷达位置$P$，所需的最小半径为：$$\max(d(P, C_1) - r_1,\; d(P, C_2) - r_2,\; 0)$$在哪里$C_i$是圆心$i$， 和$r_i$是它的半径。 我们减去$r_i$因为我们只需要触及圆的边界，而不需要到达它的中心。 

从几何角度来说，这意味着每个圆都会产生一个“距离约束”区域：我们必须在距离内$r + r_i$中心的$C_i$。 所以对于一个固定的$r$，可行性变成：是否存在一个点$P$位于半径的两个圆盘内$r + r_1$大约$C_1$和半径$r + r_2$大约$C_2$。 

这将问题简化为寻找最小的$r$使得两个圆盘相交。 

关键的观察是单调性：如果半径$r$有效，任何更大的半径也有效。 这允许二分搜索$r$。 

测试给定的可行性$r$，我们检查两个圆是否相交：$$d(C_1, C_2) \le (r + r_1) + (r + r_2)$$简化为：$$d(C_1, C_2) \le 2r + r_1 + r_2$$所以：$$r \ge \frac{d(C_1, C_2) - r_1 - r_2}{2}$$自从$r \ge 0$，答案是：$$\max\left(0, \frac{d - r_1 - r_2}{2}\right)$$问题归结为计算中心之间的欧几里德距离并应用该公式。 

强力解释将尝试所有可能的雷达位置，这在连续空间上是不可能的。 即使离散化平面也无济于事，因为最佳位置并不限于网格。 

我们的见解是，约束完全由单个标量值决定：中心之间的距离。

 ## 算法演练

 1. 阅读两个圆的描述，每个圆都包含坐标和半径。 它们定义了问题中唯一的几何对象，因此所有进一步的推理都取决于它们的相对位置。 
2. 计算两个中心之间的欧氏距离：$$d = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$这个距离充分捕捉了两个威胁区域之间的空间关系。 
3. 计算有效重叠赤字：$$d - (r_1 + r_2)$$这测量了圆圈距离已经接触或重叠的距离。 
4. 如果该值为负数或零，则两个圆已经相交或一个包含另一个。 在这种情况下，放置在交叉口区域的雷达可以在没有任何额外半径的情况下接触到两者，因此答案为 0。 
5. 否则，将超出的距离除以 2。这表示雷达必须向外延伸多少才能同时“桥接”到两个圆圈的间隙。 
6. 以足够的浮点精度输出结果值。 

### 为什么它有效

 最小化所需半径的雷达位置始终位于连接两个中心的线段上。 对于这条线以外的任何候选点，将其投影到线段上不会以改善最大约束的方式增加到任一中心的距离。 这将优化从 2D 连续搜索减少到 1D 距离平衡问题。 一旦限制在该结构中，最小半径恰好是扩展圆之间未覆盖间隙的一半，如果它们已经重叠，则为零。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

x1, y1, r1 = map(int, input().split())
x2, y2, r2 = map(int, input().split())

dx = x1 - x2
dy = y1 - y2

d = (dx * dx + dy * dy) ** 0.5

ans = (d - r1 - r2) / 2.0
if ans < 0:
    ans = 0.0

print(ans)
```该实现直接计算之前导出的几何缩减。 唯一微妙的一点是确保浮点精度足够； 考虑到限制，使用 Python 的双精度浮点就足够了。 

减法步骤必须在除以二之前进行，因为负值表示必须钳位为零的重叠情况。 跳过这个限制会导致错误的否定答案。

## 测试用例```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    x1, y1, r1 = map(int, input().split())
    x2, y2, r2 = map(int, input().split())

    dx = x1 - x2
    dy = y1 - y2
    d = math.sqrt(dx * dx + dy * dy)

    ans = (d - r1 - r2) / 2.0
    if ans < 0:
        ans = 0.0

    return f"{ans:.10f}"

# provided sample
assert abs(float(run("0 0 1\n6 0 3\n")) - 1.0) < 1e-9

# identical circles
assert abs(float(run("0 0 5\n0 0 5\n")) - 0.0) < 1e-9

# one inside another
assert abs(float(run("0 0 10\n1 1 1\n")) - 0.0) < 1e-9

# far apart
assert abs(float(run("0 0 1\n100 0 1\n")) - 49.0) < 1e-9

# tangent case
assert abs(float(run("0 0 1\n2 0 1\n")) - 0.0) < 1e-9
```| 测试输入| 预期产出 | 它验证了什么 |

 ## 边缘情况

 一个关键的边缘情况是一个圆完全包含另一个圆。 对于输入：```
0 0 10
1 0 1
```该算法计算$d \approx 1$， 和$r_1 + r_2 = 11$，因此间隙为负。 夹紧力为零。 从几何角度来看，大圆内的任何一点都已经保证与小圆相交，因此不需要额外的雷达半径。 

另一个边缘情况是相切：```
0 0 1
2 0 1
```这里$d = 2$， 和$r_1 + r_2 = 2$，给出零间隙。 该算法正确地返回零，与圆圈已经接触的事实相匹配，因此放置在接触点的雷达会立即检测到两者。 

第三种微妙的情况是半径很小的大分离：```
0 0 1
100 0 1
```差距是 98，所以答案是 49。这反映了对称性：最佳雷达位于圆圈“膨胀边界”的中间，平衡了两侧所需的到达范围。
