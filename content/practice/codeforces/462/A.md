 ## 解决方案
 ## 问题理解

 我们有一个 _n_×_n_ 板，其中每个单元格包含一个“x”或一个“o”。 任务是检查每个单元格的局部属性：包含“o”的正交相邻单元格的数量是否为偶数。 如果两个单元格共享一条边，则它们是相邻的，因此每个内部单元格最多有四个邻居，边缘单元格有三个或两个，而角单元格有两个。 如果所有单元格都满足此属性，则输出为“YES”，否则输出为“NO”。 

输入大小约束很小，_n_ ≤ 100。这很重要，因为它意味着我们可以直接检查每个单元及其邻居，而不必担心性能。 即使在 100×100 板的最坏情况下，我们也最多执行 100×100×4 = 40,000 次操作，这对于 1 秒的时间限制来说可以忽略不计。 

不明显的边缘情况包括没有邻居的非常小的板 (n=1)，以及只有边界单元具有“o”的配置。 例如，带有单个“o”的 1×1 板应该输出“YES”，因为它有零个邻居，这是偶数。 另一个边缘情况是所有单元格都包含“o”； 每个内部单元有四个邻居，这是偶数，但角单元只有两个邻居，仍然是偶数，因此棋盘有效。 

## 方法

 蛮力方法很简单：迭代每个单元格并计算其邻居中“o”的数量。 如果任何单元格计数为奇数，我们立即返回“NO”。 否则，在检查所有单元格后，我们返回“YES”。 这是可行的，因为该板足够小，可以直接进行邻居检查。 

我们可以形式化暴力破解：对于单元格 (i,j)，检查 (i-1,j)、(i+1,j)、(i,j-1)、(i,j+1) 是否存在。 计算每个单元格的邻居的时间复杂度为 O(1)，并且有 n² 个单元格，因此总时间为 O(n²)。 这在这里是可以接受的。 不需要更快的渐近方法； 问题的约束使得暴力破解既正确又有效。 关键的见解是认识到邻接是严格局部的，因此我们永远不需要做任何全局的事情，比如图遍历。

 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n²) | 已接受 |
 | 最佳| O(n²) | O(n²) | 已接受 |

 ## 算法演练

 1.读取整数n，然后将n行n个字符读入表示棋盘的2D列表中。 这允许通过行和列索引直接访问任何单元格。 
2. 使用行和列的两个嵌套循环迭代面板中的每个单元格。 
3. 对于位置 (i,j) 处的每个单元格，将计数器初始化为零。 该计数器将跟踪四个可能的邻居中有多少包含“o”。 
4. 检查每个邻居：上方 (i-1,j)、下方 (i+1,j)、左侧 (i,j-1) 和右侧 (i,j+1)。 仅当索引位于棋盘范围内时才检查邻居。 如果邻居包含“o”，则增加计数器。 
5. 对当前单元格的邻居进行计数后，检查计数器是否为奇数。 如果是奇数，则打印“NO”并终止。 这是有效的，因为一次违规就足以使整个董事会失效。 
6. 如果循环完成后没有找到任何具有奇数计数的单元格，则打印“YES”。 每个单元都满足均匀邻接条件。 

工作原理：该算法对每个细胞精确地检查一次，并仅使用其直接邻居来评估感兴趣的属性。 由于问题是局部的，并且所有相关信息都位于单元格的相邻位置，因此不存在隐藏的交互。 任何具有奇数个“o”邻居的单元格都会立即被检测到，以确保正确性。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n = int(input())
board = [input().strip() for _ in range(n)]

for i in range(n):
    for j in range(n):
        count = 0
        if i > 0 and board[i-1][j] == 'o':
            count += 1
        if i < n-1 and board[i+1][j] == 'o':
            count += 1
        if j > 0 and board[i][j-1] == 'o':
            count += 1
        if j < n-1 and board[i][j+1] == 'o':
            count += 1
        if count % 2 != 0:
            print("NO")
            sys.exit()
print("YES")
```该解决方案可以有效地读取电路板`sys.stdin.readline`以避免开销`input()`。 它在访问邻居之前显式检查边界以防止索引错误。 使用`sys.exit()`一旦发现违规就停止计算，这比循环后检查标志稍微高效一些。 直接计算邻居数量可以避免额外的数据结构，从而将空间复杂度保持在最低限度。
