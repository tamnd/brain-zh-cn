 ## 解决方案
 ## 问题理解

 伊戈尔有`n`墙壁。 每面墙高3米，`i`第-墙有宽度`a_i`。 

店里卖的壁纸卷也是3米高，高度绝不会造成浪费。 每卷都精确覆盖`k`米宽。 

对于宽度的墙`a_i`，伊戈尔以一种非常具体的方式将其贴上壁纸。 他使用尽可能多的全幅卷筒。 如果某个宽度小于`k`剩下的，他从新卷上切下所需的部分，并立即丢弃该卷的其余部分。 一堵墙的剩余物不能重新用于另一堵墙。 

任务是确定必须购买的卷筒总数。 

约束足够大，我们无法模拟任何复杂的东西。 我们最多有`10^6`墙，每个宽度可以大到`10^9`。 任何解决方案都必须在恒定时间内独立处理每面墙。 对墙壁进行线性扫描是完全安全的，而任何二次扫描都是不可能的。 

错误的主要来源是解释部分滚动的工作原理。 

考虑：```
n = 1, k = 5
a = [13]
```墙壁需要两卷完整的 10 米卷，并额外卷一卷剩余的 3 米。 答案是`3`， 不是`2`，因为最后一卷剩下的 2 米不能重复使用。 

当墙的宽度已经被整除时，就会出现另一个容易的错误`k`。```
n = 1, k = 5
a = [10]
```答案是`2`， 不是`3`。 不需要额外的卷，因为没有未覆盖的剩余部分。 

最后的边缘情况是`k = 1`。```
n = 1, k = 1
a = [7]
```每卷恰好覆盖一米，所以答案是`7`。 由于每个宽度都可以被 1 整除，因此永远不会有任何部分使用的卷。 

一堵墙所需的卷筒数量恰好是`a_i / k`。 

## 方法

 思考单面墙最直接的方法就是反复减去`k`从它的宽度直到什么都没有留下。 每次减法对应一卷。 这是正确的，因为每卷贡献最多`k`米宽。 

对于宽度的墙`a_i`，这大约需要`a_i / k`迭代。 自从`a_i`可能大到`10^9`，一堵墙可能已经需要十亿次操作。 高达`10^6`墙，这种做法是完全行不通的。 

观察结果是，重复减法只是计算上限除法。 

如果墙的宽度是`a_i`， 然后：```
rolls = ceil(a_i / k)
```什么时候`a_i`可以整除`k`，每一卷都充分利用。 

什么时候`a_i`留下余数，所有完整的宽度块`k`使用整卷，剩余部分需要额外一卷。 

所以答案就变成了：```
sum(ceil(a_i / k))
```使用整数运算：```
ceil(a_i / k) = (a_i + k - 1) // k
```我们对每面墙评估这个公式并累积结果。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(Σ(a_i / k)) | O(Σ(a_i / k)) | O(1) | O(1) | 太慢了|
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`和`k`。 
2. 读取所有墙壁宽度。 
3. 初始化`answer = 0`。 
4. 对于每个墙宽`a`:

 计算```
rolls = (a + k - 1) // k
```这是整数形式`ceil(a / k)`。 
5. 添加`rolls`到`answer`。 
6. 处理完所有墙壁后，打印`answer`。 

### 为什么它有效

 适用于任何墙宽`a`， 写：```
a = qk + r
```在哪里`0 ≤ r < k`。 

如果`r = 0`， 确切地`q`满满的卷铺满了墙壁。 

如果`r > 0`,`q`全卷封面`qk`宽度，并且需要额外的一卷来覆盖剩余的`r`宽度。 

所以卷数为：```
q            if r = 0
q + 1        if r > 0
```这正是`ceil(a / k)`。 

由于墙壁是独立的，并且剩余物不能在墙壁之间重复使用，因此总答案是所有墙壁上这些值的总和。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = map(int, input().split())

ans = 0
for x in a:
    ans += (x + k - 1) // k

print(ans)
```该程序执行一次穿过墙壁宽度的操作。 

表达式`(x + k - 1) // k`仅使用整数实现上限除法。 这避免了浮点运算，即使对于非常大的值也能正常工作。 

答案可以变得大于`10^9`，因为可能最多有`10^6`墙壁。 Python 整数会自动安全地处理此类值。 

除了输入本身之外，不需要额外的数组或数据结构，因此内存使用量保持不变。

 ## 边缘情况

 考虑：```
1 5
10
```该算法计算：```
(10 + 4) // 5 = 2
```没有剩余，所以没有额外添加卷。 输出是：```
2
```这是正确的。 

现在考虑：```
1 5
13
```该算法计算：```
(13 + 4) // 5 = 3
```两卷覆盖 10 米，第三卷覆盖剩余的 3 米。 输出是：```
3
```这符合语句的限制，即部分使用的卷不能重复使用。 

最后：```
1 1
7
```该算法计算：```
(7 + 0) // 1 = 7
```每卷恰好覆盖一米，因此需要七卷。 输出是：```
7
```这证实了上限划分公式也可以正确处理最小可能的卷宽度。
