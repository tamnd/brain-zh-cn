 ## 解决方案
 ## 问题理解

 我们得到了位置的线性序列，每个位置要么是陆地，要么是水域，以陆地开始和结束。 您从第一个位置开始，需要到达最后一个位置。 您可以免费移动到相邻的土地位置，或者从任何土地到任何后来的土地每次跳跃一次，支付等于跳跃距离的硬币。 任务是计算到达最后一块土地所需的最少硬币。 

输入提供多个测试用例。 每个测试用例给出了位置的数量$n$以及代表水和土地的 0 和 1 序列。 每个测试用例的输出是一个整数，代表最小的硬币成本。 

限制很小：$n$最多 100 个，最多可以有 100 个测试用例。 这意味着任何$O(n^2)$算法可行，而且更简单$O(n)$线性传递将非常快。 我们不需要担心高性能数据结构或复杂的图算法。 

当所有中间位置都是水时，会出现不明显的边缘情况。 例如，对于输入`1 0 0 0 1`，最佳跳跃必须跨越所有水域，花费 4 个硬币，因为一步一步移动是不可能的。 另一个微妙的情况是存在连续的地时。 用于输入`1 1 1 1`，最佳策略是永远不支付硬币，因为所有相邻的移动都是免费的，即使可以从第一个位置“跳”到最后一个位置，获得 2 个硬币。 总是在第一块土地和最后一块土地之间跳转的幼稚实现会付出过高的代价。 

## 方法

 蛮力方法是模拟从第一个到最后一个陆地位置的每条可能的路径，同时考虑自由相邻移动和支付跳过水面的费用。 人们可以递归地实现这一点，计算所有可到达的位置并存储最小的成本。 最坏情况下的复杂度为$O(n^2)$对于每个测试用例，因为每个土地都可能跳转到其他所有土地，并且有$n$地点。 虽然对于这个问题大小来说是可行的，但对于简单序列来说，递归是不必要的并且容易出错。 

关键的见解来自于观察，成本完全取决于土地之间连续水段的长度。 在相邻陆地之间移动不需要任何成本，而跳过连续的水域则需要花费与跳过的位置数量相同的成本。 因此，我们可以忽略自由移动，只将必须使用硬币跳跃穿过的连续水段的长度相加。 这将问题简化为简单的线性扫描：迭代数组，计算 1 之间的 0，并对这些计数求和。 我们永远不需要考虑复杂的分支图或邻接图。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n^2) | O(n^2) | O(n) | 有效但没有必要 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 初始化变量`coins`为零。 这将累积强制跳过水面的总成本。 
2. 初始化索引`i`在 0 时。`i < n`， 进步`i`直到一块地砖（`1`）被发现。 此步骤处理开始时的土地序列。 
3. 一旦到达陆地板块，向前扫描，数连续的水板块（`0`）直到到达下一个地块。 让`gap`是两块土地之间的水格数量。 
4.添加`gap`到`coins`。 这代表跳过该段所需的最少硬币。 
5. 移动索引`i`到下一块土地并重复步骤 3-4，直到到达最后一块瓷砖。 
6. 输出`coins`作为此测试用例的答案。 

这样做的原因是，两块土地之间的任何连续水域都必须被跳过，而成本正是水格的数量。 陆地上的免费相邻移动不会影响成本，因此忽略它们不会改变总数。 这个不变量保证了正确性：每个零对于它所属的强制跳转只计算一次。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    coins = 0
    i = 0
    while i < n:
        if a[i] == 1:
            j = i + 1
            while j < n and a[j] == 0:
                j += 1
            if j < n:
                coins += j - i - 1
            i = j
        else:
            i += 1
    print(coins)
```我们首先读取测试用例的数量，然后迭代每个测试用例。 对于每个数组`a`，我们从左到右扫描。 每当我们击中一块土地时，我们都会测量到下一块土地的距离，只计算中间的水块，并将其添加到`coins`。 在继续之前，我们完全跳过计数的段。 边界处理是隐式的，因为最后一个位置是有保证的土地。

 ## 边缘情况

 用于输入`1 0 0 0 1`，算法集`i=0`在陆地上，发现`j=4`在下一块土地上，计算`gap = 4-0-1 = 3`并添加到硬币中。 指数`i`移动到 4，即数组末尾。 输出3正确。 

对于连续的土地，例如`1 1 1 1`，第一个着陆点为`i=0`导致`j=1`（下一个陆地），`gap=0`添加了硬币。 然后`i=1`，下一个着陆点为`j=2`,`gap=0`。 最后`i=2`，下一个着陆点为`j=3`,`gap=0`。 总硬币 = 0，正确地忽略自由移动。
