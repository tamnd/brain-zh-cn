 ## 解决方案
 # 问题理解

 该问题描述了一个具有尺寸的矩形储藏室`X × Y × Z`。 四堵墙必须铺壁纸，但相对的墙必须始终使用相同类型的壁纸。 有两种壁纸类型可用。 第一种类型有`S1`可用平方米和成本`C1`每平方米，而第二种类型有`S2`可用平方米和成本`C2`每平方米。 一扇大小的门`A × B`可以正好放置在一面墙上，门区域不需要壁纸。 任务是决定是否可以覆盖墙壁，如果可以，则找到可能的最低成本。 

尺寸限制为`10000`，因此任何面积计算都可以达到大约`10^8`。 壁纸数量及价格可达`10^8`，这意味着最终成本可能约为`10^16`。 尽管 Python 自然地处理这些值，但解决方案必须避免具有固定大小整数的语言中的整数溢出。 由于只有一个房间和两种壁纸选择，因此需要线性或恒定时间解决方案。 任何尝试将壁纸分配到可用库存的所有可能数量的方法都会太慢，因为库存大小可达`10^8`。 

主要的边缘情况来自几何。 一扇门可能根本不适合任何墙壁。 例如：```
5 5 4
100 1 100 1
2 5
```输出是：```
-1
```门的高度大于房间的高度，所以无法放置。 粗心的解决方案可能只是从总墙壁面积中减去门面积并接受它，即使门无法实际放置。 

另一个棘手的情况是当壁纸总面积足够时，但对相对墙壁的要求使得分配无法进行：```
10 10 10
150 5 150 5
1 2
```输出是：```
-1
```每对相对的墙都有面积`200`，因此用于一对的任何壁纸类型都必须为两面墙提供足够的壁纸。 两种类型都没有足够的库存一对，并且总数量`300`没有帮助，因为壁纸不能任意分割。 

# 方法

 一种简单的方法是尝试一切可能的方法来选择相对的墙壁对获得第一种壁纸类型。 选择好门的位置后，剩下的墙壁自然就分成了两对。 强力解决方案可以检查所有三个可能的门方向，并针对每个门方向尝试将壁纸类型分配给两对墙。 这是有效的，因为只有很少的结构选择。 

问题不在于方向的数量，而在于需要仔细考虑墙壁区域。 房间尺寸足够小，可以直接计算，但糟糕的实现可能会尝试尽可能多的壁纸使用量或在平方米上进行迭代。 库存高达`10^8`，这样的循环将执行数亿次迭代。 

关键的观察结果是，相对壁条件将问题简化为只有两个独立的壁组。 一旦门位置固定，两对墙就有固定的面积。 只有两个有意义的决定：哪对接收壁纸类型一，哪对接收壁纸类型二。 无需搜索数量，因为所选墙壁对的每平方米都必须使用相同的类型。 

对于每个可能的门位置，我们计算所需的两个壁纸数量。 然后我们检查这两个作业。 如果分配适合可用库存，我们会计算其价格并保留最低价格。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | 如果迭代库存 | O(S1 + S2) 或更糟 O(1) | O(1) | 太慢了|
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 # 算法演练

 1. 阅读房间尺寸、壁纸信息和门尺寸。 使用 64 位样式算术，因为面积和成本可能会变得很大。 
2.考虑将门放置在大小合适的墙壁上`X × Z`。 如果门适合的话`A <= X`和`B <= Z`，或者如果门旋转并且`A <= Z`和`B <= X`。 当合适时，从墙壁对计算中减去门面积。 包含门的两个相对的墙壁形成一组，其总壁纸需求量减少了门面积。 
3. 对于每个有效的门放置，计算两个相对墙组所需的面积。 如果门位于`X × Z`墙，第一组需要`2 * X * Z - A * B`壁纸和第二组需求`2 * Y * Z`。 同样的想法适用于其他墙壁方向。 
4. 尝试将壁纸类型一分配给第一组，将壁纸类型二分配给第二组。 检查两个所需区域是否在可用库存内，然后计算总成本。 
5. 也尝试相反的作业。 这很重要，因为较便宜的壁纸可能没有足够的库存，因此较昂贵的壁纸可能需要覆盖不同的墙壁对。 
6. 在所有有效分配中，输出最小成本。 如果没有分配成功，则输出`-1`。 

该算法背后的不变性是，每种可能的最终排列都由一个已检查的案例来表示。 门只能占据三个墙壁方向之一，选择该方向后，两对墙壁必须各自接收单一壁纸类型。 由于这些选择的所有组合都会被评估，因此不会发生缺失的有效排列。 

# Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    X, Y, Z = map(int, input().split())
    S1, C1, S2, C2 = map(int, input().split())
    A, B = map(int, input().split())

    ans = float('inf')

    def try_case(pair1, pair2, door_area):
        nonlocal ans

        need1 = pair1 - door_area
        need2 = pair2

        if need1 < 0:
            return

        if need1 <= S1 and need2 <= S2:
            ans = min(ans, need1 * C1 + need2 * C2)

        if need1 <= S2 and need2 <= S1:
            ans = min(ans, need1 * C2 + need2 * C1)

    door_area = A * B

    if (A <= X and B <= Z) or (B <= X and A <= Z):
        try_case(2 * X * Z, 2 * Y * Z, door_area)

    if (A <= Y and B <= Z) or (B <= Y and A <= Z):
        try_case(2 * Y * Z, 2 * X * Z, door_area)

    if ans == float('inf'):
        print(-1)
    else:
        print(ans)

if __name__ == "__main__":
    solve()
```功能`try_case`代表一种可能的门方向。 第一对墙是包含门的墙，因此仅从该组中减去门面积。 第二对墙未受影响。 

显式检查这两个分配。 第一个检查将壁纸类型 1 分配给第一对，将类型 2 分配给第二对。 第二次检查将它们交换。 这是仅有的两种可能的选择，因为相对的墙壁必须匹配。 

所有乘法都是直接使用 Python 整数完成的，因此较大的值，例如`area * cost`不要溢出。 安装门的条件写有两个方向，防止将门视为不可旋转的常见错误。 

# 工作示例

 对于第一个样本：```
6 5 10
300 10 10 1
2 3
```门可以放在`5 × 10`墙。 

| 步骤| 门位| 第一墙对需要 | 第二面墙一对需要 | 最佳成本 |
 | --- | --- | --- | --- | --- |
 | 1 |`Y × Z`墙|`100 - 6 = 94`|`120`|`94*10 + 120*10 = 2140`|

 第一种壁纸类型用于两个墙壁对，因为第二种类型仅具有`10`平方米。 该算法找到相同的最小成本。 

对于第二个样本：```
6 5 10
200 10 95 1
2 3
```可能的安排是不同的。 

| 步骤| 门位| 第一墙对需要 | 第二面墙一对需要 | 最佳成本 |
 | --- | --- | --- | --- | --- |
 | 1 |`Y × Z`墙|`100 - 6 = 94`|`120`|`94*10 + 120*1 = 1060`|
 | 2 |`X × Z`墙|`120 - 6 = 114`|`100`|`114*10 + 100*1 = 1240`|

 最便宜的有效分配在较大的墙壁对上使用更便宜的壁纸，给出所需的最低限度。

# 测试用例```python
import sys, io

def solve_case(inp):
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    X, Y, Z = map(int, input().split())
    S1, C1, S2, C2 = map(int, input().split())
    A, B = map(int, input().split())

    ans = float('inf')

    def check(a, b, d):
        nonlocal ans
        x = a - d
        y = b
        if x < 0:
            return
        if x <= S1 and y <= S2:
            ans = min(ans, x * C1 + y * C2)
        if x <= S2 and y <= S1:
            ans = min(ans, x * C2 + y * C1)

    door = A * B

    if (A <= X and B <= Z) or (B <= X and A <= Z):
        check(2 * X * Z, 2 * Y * Z, door)
    if (A <= Y and B <= Z) or (B <= Y and A <= Z):
        check(2 * Y * Z, 2 * X * Z, door)

    return str(-1 if ans == float('inf') else ans)

 # 边缘情况

 对于门物理上不合适的情况：```
5 5 4
100 1 100 1
2 5
```该算法检查两个墙的方向。 房间高度为`4`，而门的高度为`5`，所以两者都不是`X × Z`也不`Y × Z`可以容纳门。 没有测试任何配置，答案仍然是不可能的，所以输出是`-1`。 

对于壁纸不能跨对面墙壁分割的情况：```
10 10 10
150 5 150 5
1 2
```门是可以的，但是每对墙都需要周围`200`平方米。 每种壁纸类型只有`150`，因此两项分配都未通过库存检查。 该算法从不依赖于壁纸总面积，因为对面墙的限制是实际的限制因素。 输出是`-1`。
