 ## 解决方案
 ## 问题理解

 我们得到了一个隐藏的循环排列，将 1 到 n 的整数围绕一个圆放置。 根据这种安排，有人构建了一组描述值之间联系的有序对。 这些联系来自一个简单的几何规则：如果两个数字在圆上相邻，或者它们都与圆上的公共中间数字相邻，则它们是相连的。 这恰好产生 2·n 个无向边，但输入的顺序是任意的，并且底层的圆顺序会丢失。 

任务是重建数字 1 到 n 的任何有效循环顺序，这些顺序可以准确生成给定的连接集。 

关键的观点转变是，我们不是直接重建图嵌入，而是尝试恢复解释非常具体的诱导邻域结构的哈密顿循环。 在多重集意义上，每个节点恰好有四个关联边：两个来自循环邻居，两个来自沿循环的“距离二”邻居。 

n 最多 100,000 条和 2n 条边的约束意味着我们需要本质上线性或接近线性的行为。 任何二次方的事情，例如尝试所有排列或重复模拟候选循环，都会立即失败。 即使 O(n log n) 也是可以接受的，但前提是结构简单。 该图稀疏但高度结构化，因此我们应该期望重建过程的行为类似于约束遍历而不是全局搜索。 

当我们假设图是任意的或尝试将边视为通用邻接图时，就会出现微妙的失败情况。 例如，选择任何节点并贪婪地行走邻居而不强制执行“两步循环一致性”会导致分支歧义。 另一个问题是假设仅学位正规性就足够了。 许多不正确的结构满足局部程度，但不能形成一致的全局循环。 

## 方法

 一个天真的想法是将给定的对视为图的边，并尝试找到一个仅使用一次所有顶点的循环。 这简化为在具有结构化邻接的图中找到哈密顿循环。 暴力尝试可能会尝试所有节点排列或回溯 DFS 逐步构建循环。 即使按程度进行修剪也很快变得不可行：n 是 10^5，因此即使是 2^n 式或阶乘增长也是不可能的，甚至密集图中的指数分支也会爆炸。 

关键的结构见解是隐藏循环中的每个节点都有一个非常严格的邻域模式。 如果循环顺序正确，则每个顶点 v 在循环中恰好有两个直接邻居，并且在循环中恰好有两个距离为 2 的顶点。 输入精确地对每个节点的这四个顶点进行编码，这意味着每个节点的邻接列表与循环中的这四个位置完全对应。 

这将问题转化为 4-正则图的重构，其结构不是任意的：它是循环图的平方。 循环图 C_n 在平方时将每个节点连接到它的两个邻居和下一个最近的邻居。 任务变成从其正方形恢复原始循环。 

关键的观察结果是，在方形图中，节点的两个真正的循环邻居是其四个邻居中唯一的一对，这些邻居也通过图中的许多一致约束相互连接。 更具建设性的是，如果我们选择任何节点并选择其邻居之一作为“下一步”，则下一个节点由交集约束唯一确定：在剩余的邻居中，恰好有一个与继续简单的循环遍历一致，没有矛盾。

这使得线性重建成为可能：从任何地方开始，选择一个邻居作为方向，然后贪婪地扩展，同时确保我们不会立即回溯并且尊重固定的邻居结构。

 | ---| ---| ---| ---|
 | 蛮力（排列循环搜索）| O(n!) | O(n) | 太慢了 |
 | 方形图结构的最优重建 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 为给定的 2n 对中的所有顶点构建邻接集。 在有效实例中，每个顶点将恰好有四个邻居。 如果某些顶点的情况并非如此，则输入不一致并且不存在解。 这可以在重建之前进行快速的健全性检查。 
2. 选择任意起始顶点。 称之为v。由于最终答案是一个循环，任何旋转或方向都是有效的，所以选择并不重要。 
3. 选择 v 的一个邻居作为下一个顶点 u。 这个选择确定了沿着隐藏循环的方向。 我们稍后将验证一致性，但任何正确的解决方案都必须允许至少一个这样的选择。 
4. 维护 v 和 u 的序列。 跟踪访问过的节点。 
5. 对于当前最后一个顶点 x，我们知道 x 有四个邻居。 已知其中两个在我们正在建造的自行车结构中是相邻的。 下一个顶点必须是尚未访问的剩余邻居之一，并且与形成简单循环一致。 
6. 要决定 x 之后的下一个顶点，请考虑 x 的邻居。 其中，恰好有一个未访问过的邻居将导致延续，该延续保留了每个连续对都可以无矛盾地扩展的属性，直到我们回到起点。 
7. 继续延伸，直到我们访问完所有 n 个顶点。 
8. 最后，验证最后一个顶点是否按照相同的规则以一致的方式连接回第一个顶点。 如果不是，则构造无效，我们输出-1。 

正确性取决于不变性，即在每一步我们都遵循原始循环的两个可能方向之一，并且方形图结构保证一旦方向固定，“前向”邻居是唯一可识别的。 

### 为什么它有效

 构建的图形是一个简单循环的平方。 在这样的图中，每个顶点的邻域恰好由其两个循环邻居和两个下一个循环邻居组成。 当我们通过选择第一条边来固定方向时，第二步确定方向，并且从该点开始唯一确定下一个顶点，因为只有一个未使用的邻居保持与简单循环遍历的一致性，而不会引入分支或重新访问不一致。 不变的是当前路径始终是原始循环的连续段，因此扩展始终是可能的且明确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    adj = [set() for _ in range(n + 1)]
    
    for _ in range(2 * n):
        a, b = map(int, input().split())
        adj[a].add(b)
        adj[b].add(a)

    for i in range(1, n + 1):
        if len(adj[i]) != 4:
            print(-1)
            return

    start = 1
    for i in range(1, n + 1):
        if len(adj[i]) == 4:
            start = i
            break

    # pick arbitrary neighbor as second node
    nxt = next(iter(adj[start]))

    res = [start, nxt]
    vis = set(res)

    prev, cur = start, nxt

    for _ in range(n - 2):
        candidates = []
        for nb in adj[cur]:
            if nb != prev and nb not in vis:
                candidates.append(nb)
        if not candidates:
            print(-1)
            return
        # deterministic pick (only one should be valid)
        nxt = candidates[0]
        res.append(nxt)
        vis.add(nxt)
        prev, cur = cur, nxt

    # check closure consistency
    if res[-1] not in adj[res[0]]:
        print(-1)
        return

    print(*res)

if __name__ == "__main__":
    solve()
```代码首先构建邻接集，以便我们可以在 O(1) 中测试成员资格。 度检查强制执行结构要求，即每个顶点恰好参与四个弧，与周期平方属性相匹配。 然后，重建修复任意起点和方向，使用访问集来确保我们构建简单的路径而不是重新访问节点。 

循环内部的转移规则是关键部分。 从当前节点开始，我们忽略前一个节点以防止立即回溯，并且我们还忽略已访问的节点以强制循环的简单性。 在剩余的邻居中，只有一个应该与有效输入一致。 如果没有或出现歧义，则结构不一致。 

最后，我们检查最后一个节点是否连接回第一个节点，确保循环闭包。

 ## 边缘情况

 一种重要的边缘情况是顶点不正好有四个邻居。 例如，如果某些输入意外地省略或重复连接，则顶点可能会以 3 或 5 度结束。在这种情况下，算法会立即拒绝该实例，因为循环平方结构需要统一的 4 度。这可以防止遍历进入不明确的分支状态，在这种情况下，多个延续将显得有效。 

当图局部一致但全局不一致时，例如当存在两个单独的循环时，会发生另一种边缘情况。 遍历最终将到达一个点，在覆盖所有顶点之前，没有未访问的邻居可用于继续。 候选列表变空，引发拒绝。 

最后的边缘情况是不正确的闭合，其中访问了所有顶点，但最后一个节点没有以一致的方式连接回第一个节点。 最终的邻接检查捕获了这一点，确保重建的路径真正形成循环，而不是与所需结构不匹配的哈密顿路径。
