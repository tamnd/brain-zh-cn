 ## 问题理解

 У нас есть две строки длины`n`。 斯托卡`s`описывает текущую стопку коробок сверху вниз, а`t`описывает предыдущую стопку。 Разрешено выполнить над`s`Коперации с общими параметрами: циклически сдвинуть все буквы на одну и ту же величину по алфавиту и циклически повернуть саму строку。 Нужно определить, можно ли получить ровно`t`, и если можно, вывести величину поворота`k`斯德维加`d`。 

下一篇`k`означает, что первые`k`西姆沃洛夫`s`перемещаются в конец。 例如，`abcdef`普里`k = 2`превращается в`cdefab`。 После этого каждый символ дополнительно сдвигается назад на`d`позиций по циклическому алфавиту。 埃斯利`d = 3`、 、`f`превращается в`c`。 

普里`n`Д`200000`перебрать все`n`возможных поворотов и для каждого сравнить все`n`символов нельзя。 В худшем случае это потребует порядка`n² = 4 * 10^10`сравнений，что слишком много для обычного лимита времени。 Нам нужен линейный или близкий к линейному алгоритм.

 Есть несколько краевых случаев, на которых легко ошибиться。 Первый связан с циклическим переходом между последним 和 первым символом。 Например, для```

## 方法

 Самый прямой способ перебрать все варианты поворота。 Для каждого`k`斯图罗伊姆·斯图罗库`s[k:] + s[:k]`。 Затем пытаемся подобрать один общий сдвиг`d`。 Если первый символ после поворота должен перейти в`t[0]`, значение`d`уже определяется однозначно。 После этого остаётся проверить все остальные позиции。 

Такой алгоритм корректен, потому что для фиксированного поворота значение`d`действительно определяется первым символом, затем вся строка проверяется непосредственно。 Но для каждого из`n`поворотов мы можем просмотреть`n`西姆沃洛夫。 В худшем случае это`n²`операций, то есть около`4 * 10^10`普里`n = 200000`。 Такой подход слишком медленный。 

凯撒·凯撒 (Caesar-сдвиг одинаков для всех символов) Рассмотрим не сами символы, а разности между соседними символами по модулю`26`。 

Для строки`abcde`эти разности равны`1, 1, 1, 1`。 Если каждый символ сдвинуть на одно и то же значение, например превратить строку в`defgh`, разности останутся`1, 1, 1, 1`。 凯撒大帝是凯撒大帝的儿子，他的名字叫凯撒大帝。 

Нужно также учитывать циклическую структуру。 Для строки`abcd`разности должны быть`b - a`,`c - b`,`d - c`,`a - d`。 

Получается массив из ровно`n`разностей，последняя из которых соединяет конец строки с её началом。 

Теперь исходная задача превращается в более простую. Нужно найти такое циклическое положение массива разностей`s`, которое совпадает с массивом разностей`t`。 凯撒·西泽·凯撒 (Caesar-сдвигом) Этот сдвиг затем легко восстанавливается по одному символу。 

Осталось быстро найти один массив внутри циклического массива другого. Для этого построим`diff_s + diff_s`и найдём в нём`diff_t`алгоритмом Кнута, Морриса и Пратта. Любое совпадение, начинающееся в позиции от`0`Д`n - 1`, соответствует некоторому циклическому повороту`s`。 

Таким образом、задача о двух параметрах、повороте и Caesar-сдвиге、сначала сводится к задаче о совпадении циклических 马斯西沃夫 разностей， затем один параметр восстанавливается напрямую。

 ## 算法演练

 1. Представим каждую букву числом от`0`Д`25`。 Для строки`x`построим циклический массив разностей`diff_x`, 哥德```
diff_x[i] = (x[(i + 1) mod n] - x[i]) mod 26.
```Так мы сохраняем относительное расположение букв，но полностью убираем общий Caesar-сдвиг。 

1. 歌曲`diff_s + diff_s`。 Вторая копия нужна потому, что любой циклический поворот`diff_s`теперь появляется как обычный непрерывный отрезок этой удвоенной последовательности。 
2. Найдём`diff_t`维努特里`diff_s + diff_s`KMP。 Если первое совпадение начинается в позиции`k < n`, то именно`k`является нужным поворотом исходной строки`s`。 
3. Если совпадения нет, выведем`Impossible`。 Отсутствие совпадения означает, что никакой поворот не может сделать циклические разности двух строк одинаковыи, 凯撒·西泽·凯撒 (Caesar-сдвиг уже не поможет)
 4. Если совпадение найдено, вычислим значение`d`по первым символам。 После поворота символ на позиции`0`拉文`s[k]`。 Нам нужно получить`t[0]`, поэтому```
s[k] - d ≡ t[0] (mod 26),
```奥特库达```
d ≡ s[k] - t[0] (mod 26).
```Можно вывести остаток от`0`Д`25`, потому что весь этот диапазон удовлетворяет условию`-26 < d < 26`。 

1. Для`n = 1`массив разностей состоит из одного нуля。 KMP 位于 обработает этот случай， но о отдельно рассматривать его не требуется。 Найденный поворот будет`k = 0`, a`d`восстановится из единственной пары символов。 

主演： 凯撒-斯达维格 прибавляет одну и ту же величину ко всем символам, поэтому при вычитании соседних символов эта величина сокращается。 Следовательно, если некоторое преобразование переводит`s`�`t`, их циклические массивы разностей обязательно совпадают после соответствующего поворота. Обратно, если два таких массива разностей совпадают, то после выбранного поворота разность между соответствующими символами`s`и`t`одинакова на каждой позиции。 Значит, существует один общий Caesar-сдвиг, переводящий всю повернутую`s`�`t`。 Алгоритм находит ровно такие повороты 和 затем восстанавливает этот общий сдвиг по первой позиции.

 ## Python 解决方案```python
import sys
input = sys.stdin.readline

def build_diff(s):
    n = len(s)
    a = [ord(c) - ord('a') for c in s]
    return [(a[(i + 1) % n] - a[i]) % 26 for i in range(n)]

def kmp_search(pattern, text, limit):
    m = len(pattern)

    pi = [0] * m
    j = 0
    for i in range(1, m):
        while j > 0 and pattern[i] != pattern[j]:
            j = pi[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        pi[i] = j

    j = 0
    for i, value in enumerate(text):
        while j > 0 and value != pattern[j]:
            j = pi[j - 1]

        if value == pattern[j]:
            j += 1

        if j == m:
            start = i - m + 1
            if start < limit:
                return start
            j = pi[j - 1]

    return -1

def solve():
    n = int(input())
    t = input().strip()
    s = input().strip()

    diff_t = build_diff(t)
    diff_s = build_diff(s)

    text = diff_s + diff_s
    k = kmp_search(diff_t, text, n)

    if k == -1:
        return "Impossible\n"

    s_first = ord(s[k]) - ord('a')
    t_first = ord(t[0]) - ord('a')

    d = (s_first - t_first) % 26

    return f"Success\n{k} {d}\n"

if __name__ == "__main__":
    sys.stdout.write(solve())
```

`build_diff`переводит строку в числа и вычисляет циклические разности. Индекс`(i + 1) % n`специально замыкает строку，поэтому последняя разность сравнивает последний символ с первым。 Это необходимо для коректного определения циклического поворота。 

⑨`kmp_search`сначала строится префиксная функция для`diff_t`。 Затем шаблон ищется в удвоенном`diff_s`。 帕拉梅特`limit = n`запрещает использовать совпадение, начинающееся в позиции`n`和 позже、поскольку такие позиции не соответствуют различным поворотам исходной строки。 

После совпадения значение`k`уже является индексом первого символа повернутой строки。 Формула для`d`использует именно`s[k]`, 一个`s[0]`。 Это частая причина ошибки на задаче: поворот выполняется до Caesar-сдвига, поэтому первым символом после поворота является`s[k]`。 

Вычисления выполняются по модулю`26`, поэтому переходы вроде`z -> a`обрабатываются обычным остатком。 Python 是一个Python 语言，它是一个Python 语言，它是Python 语言的一部分。
