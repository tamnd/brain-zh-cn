 ## 问题理解

 网格描述了组件的物理布局，其行为类似于计算树中的节点。 每个非空单元格包含一个单元，并且每个单元仅与其正交相邻的邻居连接。 这些连接不是任意的：整个结构形成一棵以一个特殊单元（打印机）为根的树。 

每个单位都有固定的行为。 数字单位产生恒定的整数值。 连接器单元简单地转发它接收到的任何值。 运算符单元恰好接受两个输入值，并输出使用加法、较大值减去较小值的减法、乘法或较大值除以较小值的整数除法计算得出的单个值。 打印机只有一个输入并显示最终的计算值。 

关键的结构保证是单元形成的邻接图已经是与终端计数一致的有效树。 这意味着每个连接都完全对应于输入或输出端子，因此不存在歧义或额外接线。 该计算纯粹是一个树评估问题，其中值从叶子流向打印机。 

网格大小最多为 50 x 50，因此最多有 2500 个节点。 这使得结构上的线性遍历变得可行。 任何访问每个单元恒定次数的解决方案都将在限制范围内舒适地运行。 任何涉及每个节点重复重新计算的事情仍然可能会通过，但不需要不必要的复杂性，例如重复图重建或指数状态跟踪。 

一些边缘情况很容易被错误处理。 

第一个微妙的情况是减法和除法不是按输入方向排序的。 例如，如果节点接收值 2 和 10，则无论哪个邻居提供哪个值，减法都会产生 8。 假设网格中的左右顺序固定的简单实现很容易出错。 

第二种情况是分裂行为。 该问题需要将较大的值除以较小的值，而不是在固定方向上进行整除。 例如，输入 3 和 10 应生成 3，因为 10 除以 3 在交换较大值和较小值后会被截断。 

第三种情况是连接器不是结构叶片。 它们可以位于链的中间，并且必须正确地传播价值。 将它们视为叶子会断开树的某些部分。 

## 方法

 一种直接的方法是模拟来自每个节点的价值传播。 人们可以尝试重复扫描网格并更新输入已知的任何节点，类似于树上的拓扑松弛。 虽然正确性很简单，但这可能会退化为反复重新访问节点直到收敛。 在最坏的情况下，每次更新都会传播一步，导致节点数量呈二次方行为，大约需要 2500 次平方运算，这是不必要的开销。 

输入的结构消除了真正的困难。 连接已经形成一棵树，并且每个节点都有正确数量的关联边来匹配其终端。 这意味着一旦我们识别了打印机的根，价值流向就不会出现循环，也不会出现歧义。 该问题简化为评估隐式存储在网格中的表达式树。 

一旦以这种方式查看，来自打印机的单个深度优先搜索就足够了。 每个节点在从除父节点之外的邻居处递归获取值后计算其值。 叶节点立即返回常量，内部节点根据其运算符类型组合其子节点。 

关键的简化是认识到邻接定义了无向树，而计算定义了朝向打印机的有向流。 DFS 自然地通过携带父指针来强制执行此方向。

 | 重复传播模拟| O(N²) | O(N) | 太慢了|
 | 来自打印机的 DFS | O(N) | O(N) | 已接受 |

 ## 算法演练

 ## 算法演练

 1. 解析网格并定位打印机单元，该单元充当计算树的根。 这是唯一必须完成评估的节点，因此它成为 DFS 的起点。 
2. 通过将每个像元连接到其非空的有效正交邻居来建立邻接关系。 这构建了值流动的隐式树结构。 
3. 在携带父节点的同时从打印机运行深度优先搜索，以避免重新访问前一个节点。 这会在无向结构上强制执行有根方向。 
4. 对于每个节点，递归计算除父节点之外的所有相邻节点的值。 问题约束保证此类子节点的数量与节点的预期输入计数相匹配。 
5. 如果节点是数字，则立即返回其整数值。 这代表表达式树中的一片叶子。 
6. 如果该节点是连接器，则返回其单个子节点的值不变。 这保留了流量而无需计算。 
7. 如果该节点是运算符，则根据运算符规则组合两个子值。 对于减法和除法，首先比较两个值，然后以较大的值作为第一个操作数进行运算。 
8. 将计算值向上返回给父调用，直至到达打印机，其计算结果为最终答案。 

### 为什么它有效

 DFS 强制对树进行有根遍历，因此每个节点在其所有依赖项都得到解析后只会被评估一次。 因为该结构是一棵树，除了根之外的每个节点都只有一个父节点，并且不存在循环，因此不可能重新计算不一致的部分值。 每个运算符仅在计算了其所需的两个输入后才进行评估，以匹配电路描述的语义。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n, m = map(int, input().split())
grid = [list(input().strip()) for _ in range(n)]

dirs = [(1,0), (-1,0), (0,1), (0,-1)]

# find printer
root = None
for i in range(n):
    for j in range(m):
        if grid[i][j] == 'P':
            root = (i, j)

def inside(x, y):
    return 0 <= x < n and 0 <= y < m

def dfs(x, y, px, py):
    c = grid[x][y]

    # digit
    if '0' <= c <= '9':
        return int(c)

    # collect children
    vals = []
    for dx, dy in dirs:
        nx, ny = x + dx, y + dy
        if not inside(nx, ny):
            continue
        if grid[nx][ny] == '.':
            continue
        if nx == px and ny == py:
            continue
        vals.append(dfs(nx, ny, x, y))

    # connector
    if c == '#':
        return vals[0]

    # printer (or fallback single-input node)
    if c == 'P':
        return vals[0]

    # operators
    a, b = vals

    if c == '+':
        return a + b
    if c == '*':
        return a * b
    if c == '-':
        return abs(a - b)
    if c == '/':
        return max(a, b) // min(a, b)

    return 0

print(dfs(root[0], root[1], -1, -1))
```该实现将概念性 DFS 镜像到隐式树上。 网格解析首先识别根，因为所有计算都锚定在打印机上。 DFS 使用父坐标来防止返回到前一个节点，这很重要，因为邻接是无向的。 

每个节点收集除父单元和空单元之外的所有有效邻居。 由于输入保证了结构一致性，因此收集的子节点数量始终与节点类型的预期数量匹配，因此访问`vals[0]`或解压到`a, b`是安全的。 

运算符处理遵循问题的非标准算术规则，特别是对于减法和除法，其中顺序由大小而不是位置决定。

 ## 边缘情况

 一种边缘情况是一长串连接器节点。 在这种情况下，DFS会经过多个`#`到达数字之前的节点。 由于连接器只是转发值，因此递归不能提前停止。 实施正确对待`#`由于返回其单子值，所以链自然崩溃。 

另一个边缘情况是当减法或除法出现在树的深处时，子级以不同的遍历顺序到达。 DFS 不依赖于左右定位，仅依赖于收集的值，因此排序纯粹是通过大小来解决的。 例如，接收 10 和 3 的节点始终分别计算 7 或 3，无论遍历方向如何。 

最后的边缘情况是深度接近网格限制的倾斜树。 递归深度仍然以最多 2500 个节点为界，这在增加递归限制的情况下是安全的，并且每个节点都被访问一次，防止重复遍历导致堆栈爆炸。
