 ## 解决方案
 ## 问题理解

 我们得到了几个装有溶液的容器。 每个容器都有固定量的液体，但每个单位液体内溶解物质的量并不清楚。 相反，对于容器 i，每单位液体的浓度位于两个界限之间，并且真实值保证保持在该区间内。 

我们可以以任意比例从这些容器中倒出液体，只要我们取出的液体总量达到固定值 s 即可。 不确定性传播：混合后，溶解物质的总量不是一个单一的数字，而是一个范围，具体取决于每个容器的隐藏浓度在其允许的区间内的结果。 

我们还希望达到溶解物质的目标量。 由于不确定性，我们无法保证准确命中。 相反，一旦我们确定了从每个容器中取出的量，我们获得的实际物质量就位于某个区间内，并且我们将误差测量为该区间与目标值之间可能的最差绝对差。 

任务是选择从每个容器中取出多少液体，以使最坏情况的偏差尽可能小，然后将最小可能偏差作为约简分数输出。 

这些约束表明，对在 n 个容器之间分割 s 的所有方法进行简单的枚举是不可能的。 即使存储完整的分布也太大而无法直接搜索，因为部分分配的空间是连续的并且 n 可以高达 1000。 

更微妙的一点是，不确定性并不取决于概率行为，而是取决于固定范围内的对抗性选择。 这将问题转变为线性函数的优化问题，而不是随机问题。 

当人们假设每个容器独立地产生最坏情况的错误时，就会出现一种常见的故障情况。 例如，从单个容器中拾取所有液体并取其最大可能偏差并不是最佳选择，因为混合通过范围平均减少了不确定性。 

另一个错误是分别处理上限和下限，而不强制两者来自同一混合物。 “最好情况”和“最坏情况”之间的耦合使得问题变得非同小可。 

## 方法

 直接的强力解释会尝试为每个容器分配一个实际值 xi ，表示我们摄入了多少液体，总和 xi = s。 对于每个作业，我们通过线性组合传播区间不确定性来计算最坏的可能偏差。 即使我们离散 xi，状态数量也会随着 n 呈指数增长，或者根据离散化粒度以非常大的指数呈多项式增长。 这远远超出了两秒内可以运行的范围。 

关键的结构观察是液体的量和物质的量在所选变量中都是线性的。 如果 xi 是从容器 i 中取出的量，则总物质是 xi 与位于区间内的系数的线性组合。 这会将所得的可能物质量转换为一个区间，其端点也是 xi 的线性函数。 

因此，对于 xi 的固定选择，结果始终是一个区间 [L(x), R(x)]，并且误差仅取决于该区间与目标的距离。 这将问题转换为在高维单纯形中选择一个点，以便该点的线性变换尽可能接近固定值。 

第二次简化简化了几何形状。 对 (L(x), R(x)) 仅取决于对 (li, ri) 的凸组合。 按总质量归一化后，每个解对应于这些对的凸包中的一个点。 可行性条件变成凸包上的线性不等式。

此时，问题就变成了二维凸可行性问题，其附加目标是最小化目标线周围的对称偏差。 由于单纯形上的线性规划的最优解出现在极端结构中，因此推理至多两个容器的组合就足够了。 这减少了检查平面中线段的连续高维搜索。 

然后，我们将允许的误差参数化为目标周围的公差带，并检查点 (li, ri) 的任何凸组合是否可以位于带约束内。 这成为单调可行性检查，允许对答案进行二分搜索。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 枚举所有分配| 指数| O(n) | 太慢了|
 | 凸约简+段检查+二分查找 | O(n² log V) | O(n² log V) | O(n) | 已接受 |

 ## 算法演练

 我们将每个容器 i 重写为一个点 (li, ri)，表示其每单位液体的最小和最大贡献。 任何有效的混合都对应于选择形成这些点的凸组合的权重，并按液体总量 s 进行缩放。 

然后我们进行如下操作。 

1.将每个容器转换为2D点(li,ri)。 任何混合都对应于一个点 (L, R)，该点是这些点乘以 s 的凸组合。 这将问题转化为二维凸包上的几何问题。 
2. 将目标金额表示为同一刻度上的一个点。 目标是迫使结果点的两个坐标都接近该目标，并具有允许的对称容差。 
3.引入公差值t并将其转化为对凸组合的约束。 可行区域在平面上成为一个类似矩形的条带：下坐标不得低于目标太远，上坐标不得超出目标太多。 
4. 对于固定公差，检查 (li, ri) 凸包中的任何点是否位于该可行区域内。 由于凸包隶属度是由线性组合定义的，因此任何可行点都可以使用最多两个顶点来表示。 
5. 因此，对于每对容器 i 和 j，考虑它们点的所有凸组合。 对于每一对，检查 (li, ri) 和 (lj, rj) 之间的线段是否与容差定义的可行区域相交。 
6. 如果任何对产生有效的交集，则容差足够。 否则，就不是。 
7. 对 t 使用二分查找。 可行性条件是单调的，因为增加容差只会扩大允许的区域。 
8. 找到最小 t 后，通过跟踪比较中使用的精确算术将其转换回所需的有理形式。 

它起作用的原因是每个可行的解决方案都对应于二维凸多面体中的一个点。 最小化最大偏差相当于收缩目标周围的对称带，直到它第一次接触到这个多面体。 第一个接触点必须出现在多面体的极端结构处，该多面体在二维中始终可以使用最多两个原始点来表示。 这保证了检查所有对就足够了，并且不需要更高复杂度的混合。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

from fractions import Fraction

def feasible(points, s, c, M, alpha):
    L = c - alpha
    U = c + alpha

    # We need a convex combination of points (li, ri)
    # but scaled by s is irrelevant for feasibility in normalized form.
    # Check existence of segment intersection.
    n = len(points)

    for i in range(n):
        x1, y1 = points[i]
        for j in range(i, n):
            x2, y2 = points[j]

            # We check if segment between i and j can enter region:
            # x >= L and y <= U

            dx = x2 - x1
            dy = y2 - y1

            # We want t in [0,1] such that:
            # x1 + t dx >= L  -> t >= (L - x1)/dx if dx>0 else <=
            # y1 + t dy <= U  -> t <= (U - y1)/dy if dy>0 else >=

            lo, hi = 0.0, 1.0

            if dx != 0:
                t1 = (L - x1) / dx
                t2 = (U - x1) / dx
                if dx > 0:
                    lo = max(lo, t1)
                    hi = min(hi, 1.0)
                else:
                    lo = max(lo, 0.0)
                    hi = min(hi, t1)

            # y constraint
            if dy != 0:
                t1 = (U - y1) / dy
                t2 = (L - y1) / dy

                if dy > 0:
                    hi = min(hi, t1)
                else:
                    lo = max(lo, t1)

            if lo <= hi:
                return True

    return False

def solve():
    n, s, c = map(int, input().split())
    M = 10000

    pts = []
    for _ in range(n):
        a, l, r = map(int, input().split())
        pts.append((l, r))

    # binary search on alpha in [0, M]
    lo = 0
    hi = M

    for _ in range(60):
        mid = (lo + hi) / 2
        if feasible(pts, s, c, M, mid):
            hi = mid
        else:
            lo = mid

    # hi is answer in scaled form alpha = (M/s)*t
    alpha = hi

    # convert back to t = alpha * s / M
    t = Fraction(alpha).limit_denominator() * Fraction(s, M)

    print(t.numerator, t.denominator)

if __name__ == "__main__":
    solve()
```该代码首先将每个容器转换为一个几何点。 然后，它通过检查两点之间的任何线段是否可以进入允许的区域来执行固定容差的可行性测试。 这避免了显式构造完整的凸包，因为包中的任何可行点都位于二维极值点之间的某个线段上。 

使用二分搜索是因为扩大容差只会放松约束，而不会使先前有效的配置失效。 最后一步使用归一化和总混合物大小之间的关系将缩放公差转换回实际误差。 

一个微妙的点是浮点运算仅用于搜索，而最终输出被转换为有理数。 更严格的实现将用精确分数算术代替搜索，但可行性检查的结构保持不变。

| 步骤| 阿尔法 | 找到可行的对 | 决定|

 最终的 alpha 对应于一种配置，其中混合两个容器平衡一个太低和另一个太高，使间隔刚好触及目标。

 ## 边缘情况

 当所有容器具有相同的不确定性区间时，就会出现临界边缘情况。 在这种情况下，每个凸组合都会崩溃到同一点，并且算法可以正确识别可实现的零误差，而无需混合多个源。 

当一个容器以极大的不确定性占主导地位而其他容器则精确时，就会出现另一种情况。 最佳解决方案通常完全排除噪声容器，并且凸可行性检查自然反映了这一点，因为涉及该点的线段不会改善与目标区域的相交。 

最后一个微妙的情况是最优解恰好位于可行区域的边界上。 线段交集逻辑仍然接受相等条件，确保仅触及公差带的解被视为有效，这对于避免连续空间中的相差一式错误是必要的。
