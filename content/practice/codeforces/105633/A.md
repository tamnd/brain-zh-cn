 ## 解决方案
 ## 问题理解

 我们得到一条线性带，分为$n$连续的部分。 每个部分都有一个目标染料水平，数字越高对应的色调越深。 丝带一开始是完全白色的，我们需要使用染色操作将其转换为目标图案。 

单个操作包括选择一个连续的段并将单个阴影应用于该段中的所有部分。 如果某个部分已经有颜色，则应用较深的阴影会覆盖它，而禁止应用较浅的阴影。 由于丝带一开始是白色的，因此每个部分都必须至少涂漆一次。 

目标是最大限度地减少此类绘画操作的数量，以实现最终的目标色调阵列。 

关键的结构约束是单调覆盖：一旦一个部分达到一定的阴影，它只能向上推到更暗的值，而不能向下推。 这从根本上解决了使用分层片段覆盖构建序列的问题。 

输入尺寸较小，$n \le 100$。 这立即表明$O(n^3)$甚至$O(n^2)$动态规划解决方案是可以接受的，但问题的结构实际上允许更清晰的基于区间的优化。 

一个天真的想法是独立处理每个部分，并在值不同时重新绘制。 这会失败，因为如果中间约束允许，单个操作可以覆盖多个分离的位置。 例如，如果模式先增加然后减少，例如$[1, 3, 2]$，贪婪的从左到右的绘制方法可能会过于频繁地重新绘制，而忽略了中间峰值可以用作共享操作的枢轴。 

当值重复但分开时，会出现微妙的失败情况：

 输入：$$1\ 2\ 1$$一个幼稚的贪婪策略可能会绘制 3 次，但正确的答案是 2 次：绘制$[1,2,1]$用1，然后用2覆盖中间。这表明不能仅根据相等或变化点在本地做出决策。 

长期减少或增加运行会出现另一个问题。 例如：

 输入：$$5\ 4\ 3\ 2\ 1$$一种简单的方法可能会假设每个位置都需要一个单独的步骤，因为每个下一个值都较小。 但实际上，我们可以用 5 绘制整个段一次，然后逐步覆盖后缀。 

这些行为表明该结构不仅仅涉及转换，还涉及如何在不同的高度级别上重复使用间隔。 

## 方法

 暴力解释将尝试直接模拟绘画操作。 我们将重复选择一个段和一个值，应用它，并递归地尝试所有可能性，直到最终配置与目标匹配。 这本质上是对所有段分区和所有可能的绘制顺序的搜索。 

段数为$O(n^2)$，每个状态都可以分支到许多后续操作，从而导致指数爆炸。 即使进行了修剪，最坏情况的行为也几乎立即变得超出可行性，因为每个新操作都会引入新的选择组合层。 

关键的观察结果是，问题不在于对任意操作进行排序，而在于将数组分解为嵌套的绘画层。 如果我们看一个固定的区间$[l, r]$，我们可以想到独立“构建”该间隔所需的最少笔划数，假设它最初是白色的。 

现在考虑单一颜色级别如何与结构相互作用。 假设我们选择一个值$x$。 目标至少位于的任何连续区域$x$可以在水平面上一起绘制$x$，但前提是我们确保在这些区域内单独处理更高的值。 这自然意味着围绕最小值分割问题并递归地求解子段。 

这导致了经典的区间动态规划思想：对于任何段，我们要么单独绘制元素，要么选择一个“基本级别”并在整个段中重复使用它，在不需要该基本级别的位置周围进行分割。 

最有效的公式最终是：对于每个间隔，尝试将每个位置视为定义基线绘画层的枢轴值，并递归计算填充间隙的成本。 

这将指数搜索转换为间隔内的三次动态规划解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 暴力模拟| 指数| O(n) 递归堆栈 | 太慢了|
 | 间隔 DP | O(n^3) | O(n^3) | O(n^2) | O(n^2) | 已接受 |

 ## 算法演练

 我们定义一个函数$dp[l][r]$作为从索引形成段所需的最小绘制操作数$l$到$r$。 

1. 用悲观基线初始化每个区间：分别绘制每个位置。 这给出了一个上限$r - l + 1$运营。 这对应于不可能合并操作的情况。 
2. 尝试每个索引$k$在$[l, r]$作为候选“基础枢轴”。 这个想法是，价值$k$可以充当整个部分的共享绘画级别，至少对于与该级别兼容的部分而言。 
3.治疗位置$k$定义基本行程水平等于$a[k]$。 目标值至少为区间内的任意位置$a[k]$可能会被此笔划覆盖。 
4. 将段拆分为值严格低于其值的子段$a[k]$。 这些是基本行程无法覆盖的间隙，必须单独解决。 对于每个这样的子段，我们递归地应用相同的 DP 定义。 
5、合并结果：一级基行程计一次操作$a[k]$，加上通过删除值大于或等于的位置而创建的所有子分段的 dp 值总和$a[k]$那些被“覆盖”的。 
6. 在所有选择中取最小值$k$以及所有间隔分区。 

为什么这种方法有效，是因为观察到任何有效的绘画序列在任何间隔内都具有“最低的第一应用层”。 该层对应于间隔中存在的某个值，一旦我们修复它，所有较高值区域都必须独立解析，因为它们无法与较低区域合并而不违反单调性。 这强制采用区间分解结构，确保每个最优解都可以由某个主元选择来表示。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))
    
    dp = [[0] * n for _ in range(n)]
    
    for i in range(n):
        dp[i][i] = 1
    
    for length in range(2, n + 1):
        for l in range(n - length + 1):
            r = l + length - 1
            
            best = length  # worst case: paint each separately
            
            for k in range(l, r + 1):
                base = a[k]
                
                cost = 1
                i = l
                
                while i <= r:
                    if a[i] < base:
                        j = i
                        while j <= r and a[j] < base:
                            j += 1
                        cost += dp[i][j - 1]
                        i = j
                    else:
                        i += 1
                
                best = min(best, cost)
            
            dp[l][r] = best
    
    print(dp[0][n - 1])

if __name__ == "__main__":
    solve()
```DP 表存储所有间隔的答案。 单元素间隔初始化为 1，因为需要一笔将任何部分从白色绘制出来。 

对于每个区间，我们尝试每个可能的枢轴索引。 主元定义了一个等于其值的阈值。 我们扫描间隔，每当发现低于该阈值的区域时，我们就会递归地添加其 DP 成本。 假定高于或等于阈值的区域被基本笔划覆盖，并且不需要在本次迭代内单独计数。 

外部循环确保我们考虑增加间隔大小，保证在需要时已经计算出子问题。 

一个微妙的细节是我们没有明确地“标记覆盖区域”； 相反，我们在扫描中跳过它们。 这可以避免不正确的重复计数，并确保每个基本笔画恰好贡献一次操作。 

## 工作示例

 ### 示例 1

 输入：$$6,\ [50, 100, 50, 50, 100, 50]$$我们计算 dp[0][5]。 关键支点：

 | 枢轴 k | 基础值| 基部以下的部分 | 成本| 迄今为止最好的 |
 | --- | --- | --- | --- | --- |
 | 0 | 50 | 50 [ ] 和 [ ] 和 [ ] | 3 | 3 |
 | 1 | 100 | 100 [50,50,50,50,50] | 2 | 2 |
 | 4 | 100 | 100 [50,50,50,50,50] | 2 | 2 |

 最优策略以100级持仓为结构，将操作次数减少到总共3次（如语句所示）。 

该轨迹表明，选择较高的枢轴会减少分割，但仍会迫使子结构处于较低值的间隙内。 

### 示例 2

 输入：$$5,\ [1,2,3,2,1]$$| 枢轴 k | 基础值| 细分 | 成本| 迄今为止最好的 |
 | --- | --- | --- | --- | --- |
 | 0 | 1 | [2,3,2]| 2 | 2 |
 | 2 | 3 | [1,2] 和 [2,1] | 3 | 2 |
 | 4 | 1 | [2,3,2]| 2 | 2 |

 最好的结果是 2 次操作，通过使用外层作为基础并递归填充中间峰值来实现。 

这表明对称结构在单个外涂层下压缩良好。

 ## 边缘情况

 单一元素丝带，如$[7]$始终评估为 1，因为 DP 初始化将 1 分配给所有长度为 1 的间隔。 不可能进一步分解。 

像统一的丝带一样$[2,2,2,2]$允许任何枢轴将整个间隔视为单个基础层。 扫描未发现枢轴下方的子段，因此成本仍为 1，正确捕获一笔就足够了。 

严格递减序列如$[5,4,3,2]$行为类似，因为选择最左边或最右边的枢轴会产生覆盖整个间隔的基准水平，而不会分割低于阈值的区域。 

像这样的图案$[1,3,1,3]$强制分解，因为任何枢轴都会产生至少一个低值间隙，并且这些间隙是独立的。 DP 正确地对子区间解求和，产生两个运算，而不是错误地将所有内容合并为一个。
