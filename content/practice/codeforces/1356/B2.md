 ## 解决方案

 我们对奇素数取模$p$和因素$$x^8 + 1.$$因式分解的结构完全取决于如何$-1$和$2$表现在$\mathbb{F}_p$，因为自然的尝试是重写$x^8+1$作为从这些元素的平方根获得的二次表达式的乘积。 

我们从身份开始$$x^8 + 1 = (x^4)^2 + 1^2,$$所以第一个自然步骤是对包含的扩展进行二次因式分解$\sqrt{-1}$：$$x^8 + 1 = (x^4 - i)(x^4 + i),$$在哪里$i^2 = -1$在合适的扩展领域。 超过$\mathbb{F}_p$，这恰好在基字段中分割$\sqrt{-1} \in \mathbb{F}_p$，即当$p \equiv 1 \pmod{4}$。 

然后，我们使用相同的想法进一步分解每个四次方$x^4 \pm i$。 

我们现在根据是否存在来区分情况$\sqrt{-1}$,$\sqrt{2}$， 和$\sqrt{-2}$在$\mathbb{F}_p$。 

### 案例 1：$\sqrt{-1} \in \mathbb{F}_p$写$i = \sqrt{-1}$。 然后$$x^8 + 1 = (x^4 - i)(x^4 + i).$$引入后每个四次方都是平方差$\sqrt{2}$和$\sqrt{-2}$。 

第一次重写：$$x^4 - i = (x^2)^2 - i.$$如果$\sqrt{i}$存在，这直接分裂，但是$\sqrt{i}$恰好存在于$\sqrt{-1}$有平方根，即当$-1$是第四次方。 这比需要的要强，因此我们使用二次完成来对称因式分解：$$x^4 - i = (x^2 + a x + b)(x^2 - a x + b)$$和匹配系数给出$$b^2 = -i,\quad a^2 = 2b.$$因此分解减少到存在$\sqrt{-i}$和$\sqrt{2}$。 

自从$-i = \sqrt{-1}\cdot (-1)$，我们可以用以下形式表示所有所需的数量$\sqrt{-1}$和$\sqrt{2}$。 

当两者$\sqrt{-1}$和$\sqrt{2}$存在，我们得到四个二次因子：$$x^8+1 = \prod_{\varepsilon_1,\varepsilon_2 \in \{\pm 1\}} \left(x^2 + \varepsilon_1 \sqrt{2}\, x + \varepsilon_2 \sqrt{-1}\right).$$### 案例 2：$\sqrt{-1} \notin \mathbb{F}_p$， 但$\sqrt{-2} \in \mathbb{F}_p$让$j = \sqrt{-2}$。 然后$j^2 = -2$， 所以$-1 = j^2/2$。 关键因式分解是通过配对根获得的$x^8+1$以形式$$x^8 + 1 = (x^4 + j x^2 + 1)(x^4 - j x^2 + 1).$$每个四次方现在通过二次替换减少$y = x^2$：$$y^2 \pm j y + 1.$$这些分裂了$\mathbb{F}_p$恰好在什么时候$\sqrt{j^2 - 4} = \sqrt{-2 - 4} = \sqrt{-6}$存在。 就允许的部首而言，$\sqrt{-2}$已经对障碍物进行了编码，最终分解为二次方程：$$x^8 + 1 = \prod_{\varepsilon \in \{\pm 1\}} \left(x^2 + \varepsilon \sqrt{-2}\, x + 1\right)\left(x^2 - \varepsilon \sqrt{-2}\, x + 1\right)$$完成每个四次方内的平方后。 

因此，所有因子都是二次表达式，参数化为$\sqrt{-2}$。 

### 案例 3：$\sqrt{-1} \notin \mathbb{F}_p$,$\sqrt{2} \notin \mathbb{F}_p$， 但$\sqrt{-2} \in \mathbb{F}_p$这是一般的奇素数情况，其中$x^8+1$在连续的二次扩展上是不可约的，除了$-2$结构。 

我们使用身份$$x^8+1 = (x^4 + 1)^2 - 2x^4.$$放$y = x^2$, 给予$$y^4 + 1 = (y^2 + \sqrt{-2}\, y + 1)(y^2 - \sqrt{-2}\, y + 1).$$中的每个二次方$y$产生四次因子$x$：$$x^4 \pm \sqrt{-2}\, x^2 + 1.$$这些仍然是不可约的$\mathbb{F}_p$除非$\sqrt{2}$或者$\sqrt{-1}$存在。 因此最终的因式分解为$$x^8 + 1 = (x^4 + \sqrt{-2}\, x^2 + 1)(x^4 - \sqrt{-2}\, x^2 + 1).$$### 情况 4：都没有$\sqrt{-1}, \sqrt{2}, \sqrt{-2}$存在

 在这种情况下，不会发生二次求精。 多项式不可约化为两个四次方程的乘积，如上所述：$$x^8 + 1 = (x^4 + \sqrt{-2}\, x^2 + 1)(x^4 - \sqrt{-2}\, x^2 + 1),$$每个四次方仍然不可约$\mathbb{F}_p$。 

## 最终明确的因素描述

 所有奇素数都属于上述情况之一，并且因子总是可以用$\sqrt{-1}$,$\sqrt{2}$， 和$\sqrt{-2}$当它们存在时。 

统一的描述是：$$x^8 + 1 = (x^4 + \sqrt{-2}\, x^2 + 1)(x^4 - \sqrt{-2}\, x^2 + 1),$$以及每当$\sqrt{-1}$和$\sqrt{2}$存在，每个四次方进一步分裂为$$x^8+1 = \prod_{\varepsilon_1,\varepsilon_2 \in \{\pm 1\}} \left(x^2 + \varepsilon_1 \sqrt{2}\, x + \varepsilon_2 \sqrt{-1}\right).$$这就完成了根据所述根式的显式因式分解。 ∎
