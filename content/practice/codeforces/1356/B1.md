 ## 问题理解

 我们被要求实现一个可逆量子运算，递增存储在寄存器中的 N 位二进制数。 该寄存器以小端格式给出，这意味着第一个量子位代表最低有效位，最后一个量子位代表最高有效位。 

该运算必须像经典的 1 模加法一样$2^N$，但应用于量子态。 如果输入是二进制值的叠加，则变换必须同时向每个基本状态加 1，同时保留幅度和可逆性。 例如，混合状态$|3\rangle$和$|1\rangle$必须成为叠加$|0\rangle$和$|2\rangle$当以 4 为模递增时。 

这些限制很微妙但很重要：我们不允许使用测量或任意旋转。 我们仅限于 X 门及其受控变体。 这将我们带入了使用量子门实现的经典可逆逻辑领域。 

寄存器大小 N 没有以影响经典意义上的复杂性问题的方式明确限制。 相反，主要的约束是结构性的：我们必须构建一个适用于任何 N 且保持可逆的酉，因此我们不能依赖算术捷径或不可逆运算。 

天真的经典思维方式会建议将寄存器转换为整数，加一，然后写回。 这会立即失败，因为测量会破坏状态并被禁止。 另一个诱人的错误是尝试“翻转所有位并添加一个”，而不以可逆的方式正确处理进位传播。 这会破坏像全一输入这样的边界情况。 

粗心逻辑失败的一个最小例子是状态$|11\rangle$对于 N = 2。以 4 为模递增应该产生$|00\rangle$。 如果我们只翻转最低有效位，我们得到$|10\rangle$，这是不正确的。 如果我们翻转所有位，我们得到$|00\rangle$，但是这意外地仅适用于最大值，并且不能正确地概括可逆电路中的中间状态，除非使用进位正确构造。 

关键的困难是仅使用可逆的位操作来实现二进制增量。 

## 方法

 暴力经典解释将模拟整数值，加一，然后重写二进制表示。 从概念上讲，其工作原理是读取所有位、计算整数、执行加法并将结果写回。 然而，在量子环境中这是不可能的，因为读取状态需要测量，这会破坏叠加性。 即使我们想象一个经典的模拟器，这种方法的成本$O(2^N)$每个幅度配置，从根本上不符合统一要求。 

正确的方法来自于认识到二进制增量只是 1 的纹波进位加法。在经典的可逆逻辑中，加法是使用从最低有效位向上传播进位的受控 NOT 运算来实现的。 仅当所有较低有效位均为 1 时，每个位才会翻转，这可以使用多控制 X 操作链来表示。 

问题的结构使得这个问题变得特别清晰：加 1 意味着第一个 0 位停止进位链，并且所有尾随 1 位翻转为 0。这可以使用一系列受控 X 门来实现，其中每个位的翻转条件是所有先前位均为 1。 

关键的见解是我们永远不需要将进位显式计算为存储值。 相反，我们使用控制结构对其进行隐式编码。

 ## 算法演练

 我们使用级联受控 X 门构建增量运算。 

1. 我们将该操作解释为从索引 0 处的最低有效位开始向二进制数加 1。 

最低有效位总是翻转，因为无论输入状态如何，加 1 总是会翻转它。 
2. 我们对第一个量子位应用 X 门。 这实现了加法的第一步：切换位 0。 
3. 对于从 1 到 N-1 的每个后续位 i，仅当从 0 到 i-1 的所有位都等于 1 时，我们才翻转位 i。 

该条件恰好对应于进位到达位置 i。 
4. 我们使用多控制 X 门来实现此条件：所有先前的量子位都充当控制，而量子位 i 是目标。 
5. 我们按顺序应用这些受控翻转，以便按顺序保留进位传播。 
6. 结果是与二进制增量模匹配的可逆变换$2^N$。 

### 为什么它有效

 不变的是，处理完位 i 后，所有比 i 低位的位都正确表示加 1 模的结果$2^{i+1}$。 当翻转前所有低位均为 1 时，位置 i 的进位恰好为 1，并且受控 X 结构确保位 i 在该条件下精确翻转。 由于每个步骤都是可逆的，并且仅依赖于已经建立的控制，因此不会丢失任何信息，并且全局转换保持统一。 

## Python 解决方案

 在 Q# 中，该结构是使用 X 和受控 X 操作来实现的。 由于受控 X 足以通过 Adj+Ctl 机制构建所有多受控版本，因此我们可以依赖重复的应用模式。```python

```
namespace Solution {
    open Microsoft.Quantum.Arithmetic;
    open Microsoft.Quantum.Intrinsic;

    operation Solve (register : LittleEndian) : Unit is Adj+Ctl {
        let qubits = register!;
        let n = Length(qubits);

        // Flip least significant bit
        X(qubits[0]);

        // Propagate carry
        mutable controls = new Qubit[0];

        for i in 1 .. n - 1 {
            // Apply multi-controlled X using all previous bits as controls
            Controlled X(qubits[0..i-1], qubits[i]);
        }
    }
}
```在最低有效位上的初始 X 门之后，每个受控 X 确保仅当所有较低位均为 1 时，位 i 才会翻转，这正是二进制进位条件。 切片`qubits[0..i-1]`自然地捕获小端结构，确保正确的排序。 

一个微妙的点是我们从不显式存储进位位。 控制结构本身对进位逻辑进行编码，从而保留了可逆性。 

## 工作示例

 我们跟踪两个输入的执行情况。 

第一个示例是从基础状态开始的 2 量子位系统$|01\rangle$，它代表数字 2？ 否，采用小端编码$|01\rangle = 2$是不正确的； 它实际上代表位 0 = 1，位 1 = 0，因此值为 1。 

增量后：

 | 步骤| 位 0 | 位 1 | 行动|
 | --- | --- | --- | --- |
 | 开始| 1 | 0 | 初始状态|
 | X(0) | X(0) | 0 | 0 | 位 0 翻转 |
 | 受控 X(0→1) | 0 | 1 | 没有进位，因为翻转后位 0 为 0 |

 最终状态是$|10\rangle$，代表2。 

这证实了从 1 到 2 的加法正确。 

第二个例子是$|11\rangle$，代表 2 位系统中的 3。 

| 步骤| 位 0 | 位 1 | 行动|
 | --- | --- | --- | --- |
 | 开始| 1 | 1 | 初始|
 | X(0) | X(0) | 0 | 1 | 位 0 翻转 |
 | 受控 X(0→1) | 0 | 1→0？ | 翻转前满足控制条件|

 最终状态变为$|00\rangle$，代表 0 模 4。 

这显示了正确的环绕行为。

 ## 边缘情况

 一种重要的边缘情况是全一寄存器。 对于 N = 3，输入$|111\rangle$必须映射到$|000\rangle$。 该算法将 X 应用于位 0，产生$|011\rangle$，然后通过受控操作传播进位。 每个高位在控制时看到所有低位都为1，因此它们依次翻转。 这会产生正确的环绕而不失去可逆性。 

另一种边缘情况是单个零埋在 1 中，例如$|11011\rangle$。 进位传播直到到达第一个零，此时该位翻转并且所有较低位重置为零。 受控结构确保传播自然停止，因为一旦前缀中出现零，控制条件就会失败，因此较高位保持不变。
