[CF 1356A5 - 区分 Z 和 -Z](https://codeforces.com/problemset/problem/1356/A5)

 **评级：** -
 **标签：** *特别
 **求解时间：** 1m 25s
 **已验证：** 是的

 ## 解决方案
 ## 问题理解

 我们得到了作用于单个量子位的量子操作。 该操作可以是 Z 门，它使量子位的 |1⟩ 分量保持不变并翻转 |0⟩ 的相位，也可以是 -Z 门，它翻转 |0⟩ 的相位并向 |0⟩ 项全局添加一个额外的负号。 我们的目标是使用操作或其伴随/受控变体的单次调用来区分这两种可能性。 

输入不是经典数据，而是具有已知接口的量子操作：我们可以在量子位上调用它并随后测量量子位。 输出是一个整数：如果操作是 Z，则为 0；如果是 -Z，则为 1。 

从约束的角度来看，每个变体只有一个查询，因此重复应用该操作的简单方法是不可能的。 当忽略全局阶段时，就会出现边缘情况：Z 和 -Z 在计算基础状态 |0⟩ 和 |1⟩ 上的行为相同，直到全局阶段。 计算基础上的粗心测量总是会产生相同的结果，没有任何区别。 例如，将 Z 或 -Z 应用于 |0⟩ 并立即测量将肯定给出 0。 正确的输出需要暴露相对相位的基础变化，例如哈达玛基础。 

## 方法

 暴力法是尝试对 |0⟩ 或 |1⟩ 进行运算并在计算基础上进行测量。 这总是会失败，因为 Z 和 -Z 都保持 |1⟩ 不变，并通过测量中不可观察到的全局相位翻转 |0⟩。 操作次数很少，但该方法在逻辑上不够充分； 输出总是无法区分，因此朴素的解决方案会产生随机结果。 

关键的见解是在哈达玛基础而不是计算基础上进行测量。 哈达马门映射 |0⟩ → |+⟩ = (|0⟩ + |1⟩)/√2 和 |1⟩ → |−⟩ = (|0⟩ − |1⟩)/√2。 在此基础上，Z 门保持 |+⟩ 不变，但 -Z 将 |+⟩ 翻转为 |−⟩。 应用 Hadamard 后在计算基础上进行测量，将这种区别转化为可观察的结果：Z 产生 0，-Z 产生 1。Hadamard 的单次应用，然后是未知操作，然后再次是 Hadamard，足以区分两个门。

 | 蛮力 | O(1) | O(1) | O(1) | O(1) | 逻辑上失败 |

 ## 算法演练

 1. 分配单个量子位。 该量子位将成为确定门类型的探针。 
2. 将 Hadamard 门应用于量子位。 这会将 |0⟩ 转换为 |+⟩。 稍后在哈达玛基础上进行测量将使我们能够检测全局相位翻转。 
3. 应用未知幺正运算。 如果是 Z，|+⟩ 仍然是 |+⟩。 如果是-Z，则|+⟩变为|−⟩。 
4. 应用另一个 Hadamard 浇口。 这映射 |+⟩ → |0⟩ 和 |−⟩ → |1⟩，将相位信息转换为可测量的计算基础状态。 
5. 测量量子位。 返回测量的整数。 结果0对应于Z，结果1对应于-Z。 

**为什么有效：** 该算法之所以有效，是因为 Hadamard 将相位信息转换为计算基础。 不变量是，在第一个 Hadamard 之后，量子位状态对未知门引入的相位差进行编码。 应用第二个 Hadamard 将此阶段确定性地转换为 0 或 1 测量。 由于全局相位在计算基础中是不可见的，因此基础旋转是必不可少的。 无论应用哪个门，该序列都保证了唯一的测量结果。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

# Quantum simulation using Qiskit for illustration
from qiskit import QuantumCircuit, Aer, execute

def solve(unitary: QuantumCircuit) -> int:
    qc = QuantumCircuit(1, 1)
    qc.h(0)
    qc.append(unitary.to_instruction(), [0])
    qc.h(0)
    qc.measure(0, 0)
    backend = Aer.get_backend('qasm_simulator')
    result = execute(qc, backend, shots=1).result()
    counts = result.get_counts()
    return int(list(counts.keys())[0])
```该代码初始化一个量子位，应用 Hadamard 输入 +/- 基，应用未知运算，然后再次使用 Hadamard。 测量映射 |+⟩ → 0 和 |−⟩ → 1。我们使用一次，因为该过程是确定性的。

 ## 边缘情况

 直接应用计算基础会失败：对于 |0⟩ 中的量子位，在 Z 或 -Z 之后测量会产生 0。通过哈达玛旋转，相位翻转变得可观察到。 负全局相位的边缘情况是相同的，因为 |+⟩ → |−⟩ 或 |−⟩ → |+⟩ 映射在全局相位下是不变的； 对于 -Z，无论符号如何，Hadamard 后的测量都会返回 1。 该算法确定性地处理这个问题。
