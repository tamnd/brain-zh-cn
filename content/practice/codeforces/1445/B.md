 ## 解决方案
 ## 问题理解

 我们被要求计算奥林匹克淘汰赛阶段的最小可能截止总分。 每个参赛者参加两场比赛，评审团只记住部分信息：每场比赛的第 100 名得分以及前 100 名参赛者在另一场比赛中得分的下限。 具体来说，第一场比赛，第100名得分`a`，并且所有前 100 名参与者至少有`b`第二场比赛的积分。 同样，在第二场比赛中，第 100 名得分`c`，并且所有前 100 名参与者至少有`d`在第一场比赛中得分。 我们将确定总分排名第100名的参赛者的最低总分。 

输入由多个测试用例组成。 每种情况都是四个整数`a, b, c, d`有限制`0 ≤ a, b, c, d ≤ 9`,`d ≤ a`和`b ≤ c`。 约束很小，每个测​​试用例允许 O(1) 次操作。 主要挑战不是效率，而是推理如何将分数组合起来以产生尽可能小的截止值。 

一个简单的解决方案可能会尝试模拟所有参与者的分数，但这很快就会变得不切实际，特别是因为参与者的确切数量未指定。 边缘情况涉及这样的情况：第一次比赛的第 100 名的分数低于第二次比赛的前 100 名的最低分数，反之亦然。 例如，如果`a = 0, b = 0, c = 0, d = 0`，最低总分显然为 0。粗心的方法可能会忽略这样一个事实：我们只需要考虑前 100 名中最坏情况的分数组合，而不是完整的参与者列表。 

## 方法

 暴力方法将尝试枚举遵守给定界限的参与者的所有可能分数分布，并找到第 100 个总分。 每个参与者都可以在限制范围内取任何值，从而导致组合爆炸。 如果有 100 名参与者，即使分数为 0-9，操作次数也会过多，尽管由于界限较小，理论上在这里是可行的。 

关键的见解是我们不需要模拟所有参与者。 我们只对第 100 个总分感兴趣。 为了最小化截止值，我们可以假设所有其他可能将截止值推高的参与者都被分配与给定数据一致的最低允许分数。 因此，当我们选择总和中的最大值时，就获得了最小的总分`a + b`和`c + d`。`a + b`代表第一场比赛中第 100 名参赛者在第二场比赛中取得最低分数的总成绩，并且`c + d`代表第二场比赛中第 100 名参赛者的总分（如果他们在第一场比赛中取得最低分数）。 截止值不能低于其中任何一个，因为每场比赛的第 100 名必须至少具有另一场比赛的给定分数。 

这一观察将问题分解为一个简单的问题`max(a + b, c + d)`每个测试用例的计算，使每个测试用例的解决方案为 O(1)。

 | 蛮力 | O(100^2) | O(100^2) | O(100) | 矫枉过正|

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，读取整数`a, b, c, d`。 
3、计算第一场比赛第100名得分与第二场比赛前100名中最低得分之和，即：`sum1 = a + b`。 
4. 计算第二场比赛第100名得分与前100名中最低第一场比赛得分之和，即：`sum2 = c + d`。 
5. 取最大值`sum1`和`sum2`。 这代表第 100 名参与者在不违反给定限制的情况下可以获得的最小总分。 
6. 打印该最大值。 

为什么有效：任何总分低于的假设场景`max(a + b, c + d)`将违反至少一场比赛中第 100 名的条件。`a + b`确保竞赛 1 中的第 100 位参与者满足竞赛 2 的最低要求，并且`c + d`确保竞赛 2 中的第 100 个参与者满足竞赛 1 的最低要求。采取最大限度保证所有约束都得到尊重，同时最小化总数。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b, c, d = map(int, input().split())
    print(max(a + b, c + d))
```此代码读取测试用例的数量并迭代每个测试用例。 对于每组四个整数，它计算第 100 位的两个可能的总分并打印它们的最大值。 使用`sys.stdin.readline`确保许多测试用例的快速 I/O。 这`map(int, input().split())`有效地将四个值转换为整数。

 ## 边缘情况

 如果`a = d = 0`和`b = c = 9`， 然后`a + b = 0 + 9 = 9`和`c + d = 9 + 0 = 9`。 最大值为 9，正确给出了第 100 名的最低总分。 该算法可以正确处理第一场比赛的最小值与第二场比赛的最小值相结合的情况，无论哪一方占主导地位。
