 ## 解决方案
 ## 问题理解

 我们得到了四个数字，代表桌子腿的当前长度。 只有当所有四个腿最终具有完全相同的长度时，桌子才是稳定的。 还有一个固定长度的垫子，最多可以连接到一条腿上，从而增加该腿的长度，或者可以完全忽略它。 

任务是确定在将这个垫选择性地应用到四个腿中的一个上之后，是否有可能所有四个腿的长度变得相等。 

约束非常小，每个值最多为 100。这立即排除了任何繁重计算的需要。 即使直接检查所有可能性也是微不足道的，因为只有五种有意义的状态：无操作，或将垫应用到四个腿之一。 

不存在隐藏的性能问题。 主要困难是逻辑完整性，确保我们正确考虑“已经平坦”的情况和“需要调整”的情况。 

当多个腿已经共享最大值并且焊盘被错误地使用而导致超调时，会出现微妙的边缘情况。 例如，如果腿已经相等，任何不必要的垫的使用都会破坏平等，但由于我们被允许不使用它，所以正确的答案仍然是可能的。 

另一个角落情况是，即使之前没有原始值的子集相等，应用 pad 也会产生相等。 例如，改造较小的腿以匹配当前的最大值。 

## 方法

 暴力方法明确地尝试每一个可能的动作。 我们要么什么都不做，要么选择四个腿之一并将垫长度添加到其中。 对于每个结果配置，我们检查所有四个值是否相等。 由于总共只有五种配置，因此这是一个恒定的时间工作。 

暴力破解的正确性来自于穷举性。 每个有效的解决方案都必须恰好对应于这五种状态之一。 

然而，“尝试所有操作”的思考有点间接。 更清晰的观察是，在操作之后，最终值必须是某个共同的目标值。 该目标要么是原始最大值（如果我们不增加任何超出它的值），要么是通过增加较小的腿之一以匹配较高的腿而形成的值。 

因此，我们可以推断达到单个统一值的可行性，而不是枚举操作。 唯一值得检查的候选者是当前最大值以及通过将每条边增加 b 形成的值。

 ## 算法演练

 我们将问题简化为检查在对单个元素应用最多一次增量操作后是否可以使所有四个数字相等。 

1. 读取四条腿长和垫长。 为了方便起见，我们将它们保留为一个小列表。 
2. 计算四条腿中的最大值。 如果所有的腿已经相等，那么这个最大值就是最终目标，我们可以立即返回成功，而无需使用 pad。 
3. 首先尝试“无操作”情况。 如果所有四个值都相等，我们立即返回成功。 这避免了对修改进行不必要的推理。 
4. 现在考虑在四个腿上逐个使用垫子。 对于每个索引，临时将焊盘长度添加到该腿，并检查所有四个值是否相等。 
5. 如果这四个修改中的任何一个在所有腿上产生平等，我们就可以返回成功。 
6. 如果五种配置都不起作用，则得出结论：不可能使桌子变平。 

### 为什么它有效

任何有效的最终配置都必须来自于不执行任何操作或仅将垫应用到一条腿上。 不允许进行其他变换，因此解空间完全被这五种状态覆盖。 由于我们显式检查每个状态，因此我们不会错过有效的构造，并且由于我们每次都直接验证相等性，因此我们不能接受无效的构造。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def ok(a):
    return a[0] == a[1] == a[2] == a[3]

a = [int(input()) for _ in range(4)]
b = int(input())

if ok(a):
    print(1)
    sys.exit(0)

for i in range(4):
    brr = a[:]
    brr[i] += b
    if ok(brr):
        print(1)
        sys.exit(0)

print(0)
```该实现反映了直接状态枚举。 辅助函数检查所有四个分支的相等性，这是成功所需的唯一条件。 

我们首先显式测试未更改的配置，这是必要的，因为使用 pad 是可选的。 然后我们模拟将垫子独立地应用到每条腿上。 每次复制数组可确保我们不会意外累积多个应用程序，否则会违反“单焊盘”约束。 

由于输入大小是恒定的，因此简单性比微优化更有价值。

 ## 边缘情况

 一种边缘情况是桌子已经平坦。 对于像这样的输入`3 3 3 3`，算法立即返回成功，而无需尝试不必要的修改。 在任何模拟之前，相等性检查都会捕获这一点。 

另一种情况是，如果将垫应用到错误的腿上，则会超出相等性。 为了`2 2 2 2`和`b = 1`，将垫应用到任何一条腿上都会产生不匹配，但由于我们还首先检查“不执行任何操作”的情况，因此我们仍然正确地返回成功。 

第三种情况是加垫后只有一条腿较小且与其他腿完全匹配，例如`4 4 4 1`和`b = 3`。 该循环正确测试每个索引，并在应用于最后一段时找到有效的转换，确认单操作覆盖范围足够。
