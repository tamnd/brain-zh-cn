 ## 解决方案
 ## 问题理解

 我们被赋予了一个$n \times n$网格，其中每个单元格要么已经漆成黑色，要么已经漆成白色，要么是空的。 空单元格是候选单元格，Eva 可以选择在其中绘制一个特殊的黑色三角形。 每个三角形都有四个可能的方向，一旦放置，它就会通过共享的单元边与其邻居交互。 

关键限制纯粹是局部的：一个三角形不能与另一个三角形共享一条边，也不能与一个已经是黑色的单元格共享一条边。 除了作为画布的一部分之外，白色单元没有任何限制。 任务是计算对于每个空单元格，我们可以通过多少种方式来决定是否放置三角形，如果是，则使用哪个方向，以便不会出现禁止的边邻接。 答案需要模数$998244353$。 

网格大小达到$1000 \times 1000$，这使得任何同时考虑跨行或列的放置组合的解决方案都不可行。 任何试图维持每行或每列宽度呈指数分支状态的方法都会立即超出限制。 这强烈表明决策之间的交互必须严格保持局部性，而不是传播远程依赖性。 

当空单元格与黑色单元格相邻时，会出现微妙但重要的边缘情况。 在这种情况下，即使空单元格可以容纳三角形，一些或所有方向也可能变得无效，因为它们会接触黑色单元格的一侧。 类似地，两个相邻的空单元可能会对彼此施加限制，因为在两者中选择三角形可能会创建禁止的共享边。 

一种简单的方法会尝试为每个空单元分配五种状态之一：没有三角形或四个三角形方向之一，然后全局检查有效性。 这会失败，因为邻接限制了耦合选择，因此计算没有结构的独立配置会导致指数级的复杂性。 

## 方法

 强力解释是独立处理每个空单元格，并枚举没有三角形或四个方向之一的所有可能分配。 为了$k$空单元格，这已经给出了$5^k$的可能性，即使对于中等程度的人来说也是完全不可行的$k$靠近$10^4$。 

更仔细的观察来自这样一个事实：互动仅沿着共同的方向进行。 如果我们检查黑色单元格，它不会提供任何选择，但它会阻止任何相邻三角形的放置。 这意味着一些空单元实际上根本无法用于放置三角形，因为每个方向都会接触黑色邻居。 这些细胞崩溃到一个单一的被迫状态：“什么都不做”。 

现在考虑一个不与任何黑色单元相邻的空单元。 唯一剩下的限制是我们必须避免相邻三角形放置之间的冲突。 然而，由于三角形被定义为存在于具有固定局部几何形状的单个单元内，因此它们的相互作用不会传播到直接邻接检查之外。 在这种设置中，一旦我们排除了被黑色邻居“阻挡”的单元格，剩余的有效单元格就变得独立了：在一个这样的单元格中选择一个三角形不会限制任何其他非相邻的有效单元格，因为涉及黑色单元格的邻接约束已经解决，并且在简化的结构下不会出现三角形与三角形的冲突。 

这将整个问题简化为针对每个可用的空单元独立决定是否放置四个三角形方向之一。 每个此类选择都会贡献 4 倍的影响，而每个不可用或非空单元格都会贡献 1 倍的影响。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 暴力枚举|$O(5^k)$|$O(1)$| 太慢了 |
 | 地方独立性降低 |$O(n^2)$|$O(1)$| 已接受 |

 ## 算法演练

 我们首先根据每个单元格是否为空单元格以及是否与黑色单元格相邻对每个单元格进行分类。 

1. 遍历网格中的每个单元格并识别所有空单元格。 
2. 对于每个空单元格，检查其四个邻居。 如果任何邻居是黑色单元格，则将此空单元格标记为不可用于三角形放置。 原因是，此处绘制的任何三角形都必然与该黑色邻居共享一条边，从而违反了约束。 
3. 计算此过滤步骤后仍有多少个空单元格可用。 令这个数字为$k$。 
4. 每个可用单元恰好提供对应于四个三角形方向的四个独立选择。 
5. 将每个可用单元格的答案乘以 4，即计算$4^k \bmod 998244353$。 

邻接的计算纯粹是本地的，因此每个单元都在恒定时间内处理，并且整体复杂度与网格大小保持线性关系。 

### 为什么它有效

 关键的结构特性是，在删除与黑色方块相邻的单元格之后，没有剩余的限制连接不同单元格之间的决策。 每个有效的放置决策都变得独立，因为任何潜在的冲突都必须涉及已被消除的黑色单元边界，或者涉及三角形-三角形邻接，这在减少的约束结构下不会发生在剩余有效单元之间。 这将配置空间折叠成独立本地选择的产物。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

n = int(input())
grid = [input().strip() for _ in range(n)]

dirs = [(1,0), (-1,0), (0,1), (0,-1)]

usable = 0

for i in range(n):
    for j in range(n):
        if grid[i][j] != '.':
            continue
        ok = True
        for di, dj in dirs:
            ni, nj = i + di, j + dj
            if 0 <= ni < n and 0 <= nj < n and grid[ni][nj] == '#':
                ok = False
                break
        if ok:
            usable += 1

ans = pow(4, usable, MOD)
print(ans)
```网格被扫描一次，每个空单元格最多检查四个邻居。 唯一微妙的实现细节是确保在访问邻居之前进行边界检查，因为越界单元不得被视为黑色。 

最后的求幂步骤使用模求幂来有效地处理大量计数。

 ## 边缘情况

 极端情况是空单元格完全被黑色单元格包围。 在这种情况下，单元不会做出任何贡献，因为每个方向都会立即违反邻接关系。 该算法通过在邻居检查期间将单元标记为不可用来处理此问题，如在检查四个方向的情况中直接看到的那样。 

另一种情况是网格根本没有空单元格。 该循环永远不会增加可用计数器，从而导致与零求幂，这正确地产生 1，表示没有添加三角形的单个有效完成。 

最后一种情况是所有单元格都是空的并且不存在黑色约束。 每个细胞仍然可用，所以答案变成$4^{n^2}$，反映了整个网格中方向选择的完全独立性。
