 ## 解决方案
 ## 问题理解

 我们从一排开始$n$位置，每个位置包含一个不同的元素。 一个指针$p$也给出了，最初介于$0$和$n$，包含在内。 我们反复从当前行中删除元素，直到没有任何内容为止。 每一步都会选择一个均匀随机的剩余位置，删除该元素，并移动其离开后的所有内容以填补空白。 指数$p$仅当我们严格删除右侧的某些内容时才会移动：在这种情况下$p$减少一。 如果我们在以下位置或左侧删除$p$，指针相对于其余结构保持不变。 

毕竟$n$删除，结构为空，只有最终值$p$遗迹。 任务是计算最终的期望值$p$，对于每个可能的初始值$p = 0, 1, \dots, n$。 

约束条件$n \le 1000$立即排除对删除排列的任何模拟，因为有$n!$可能的删除命令。 即使每个状态的二次或三次动态过程也是可以接受的，但是涉及枚举排列或维护所有中间配置的完整分布的任何事情都太慢了。 

一个微妙的边缘情况是边界行为$p = 0$或者$p = n$。 如果$p = 0$，它永远不会进一步减少，因为没有任何索引可以大于零，不会对其产生负面影响。 如果$p = n$，每次删除都可能会影响它，并且早期删除可以显着移动它。 任何正确的配方都必须一致地对待这些终点； 假设所有指数都对称的朴素概率论通常在这里失效。 

## 方法

 暴力的观点是将过程建模为生成随机排列$n$元素，因为每个删除序列正是随机统一选择的排列。 然后我们模拟如何$p$沿着该排列演变：对于排列顺序中的每个元素，我们决定它是否位于当前位置的右侧$p$，并进行相应更新。 

这个模拟很简单：对于每个起始$p$，生成所有排列，计算最终的$p$，和平均值。 正确性是立即的，因为删除过程相当于统一的随机排序。 问题是有$n!$排列，甚至对于$n = 12$，这已经变得不可行了。 

我们需要完全避免跟踪排列，而是观察对称性：重要的不是元素的确切身份，而是删除的相对顺序。 每个元素的命运仅取决于有多少最初位于右侧的元素在消失之前被删除，但全局过程统一混合了所有内容。 

一个关键的观察是向后重新解释该过程。 想象一下通过以相反的顺序插入元素来构建最终的排列，而不是删除元素。 当结构为空时，我们在均匀随机的位置一一插入元素。 指针$p$根据插入发生在其右侧还是左侧而演变。 这反转了依赖关系：而不是删除推送$p$向左，插入以受控方式将其向右推。 

在这个逆过程下，我们可以表达出最终的结果$p$作为独立贡献的总和。 对于每个元素，我们只需要知道它是否有助于减少$p$，并且由于对称性，随机插入位于固定位置右侧的预期次数变为其当前预期排名的线性函数。 

这导致了位置和剩余元素上的 DP，但我们可以进一步压缩它。 让$E(p, k)$是从指针开始的预期最终值$p$和$k$剩余元素。 从随机位置删除一个元素时的转换$i \in [1, k]$是：$$E(p, k) = \frac{1}{k} \sum_{i=1}^k E(p - [i > p], k - 1)$$我们将案例分开：对于$i \le p$,$p$不改变； 为了$i > p$，它减少 1。这给出：$$E(p, k) = \frac{p}{k} E(p, k-1) + \frac{k-p}{k} E(p-1, k-1)$$这个递归就是核心结构。 它表明期望仅取决于三角形 DP 中较小的状态，可以计算所有$p$和$k$在$O(n^2)$。

 ## 算法演练

 我们定义一个表，其中$dp[p][k]$是预期的最终值$p$什么时候$k$元素仍然保留，当前指针是$p$。 目标是$dp[p][n]$。 

1. 初始化基本案例$k = 0$。 当没有剩余元素时，过程结束，并且值$p$是固定的，所以$dp[p][0] = p$。 这锚定了所有计算。 
2. 迭代剩余元素的数量$k$从$1$到$n$。 我们使用较小的子问题构建较大子问题的答案，因为删除元素会减少$k$。 
3. 对于每个$k$，迭代所有有效的指针位置$p \in [0, k]$。 超出此范围的状态无效，因为指针不能超过剩余元素的数量。 
4. 使用由删除的索引引起的分割来计算转换。 如果删除的索引位于第一个索引内$p$位置，指针保持不变； 否则减一。 这将创建两个组，其大小为$p$和$k-p$。 
5. 应用期望公式：$$dp[p][k] = \frac{p}{k} dp[p][k-1] + \frac{k-p}{k} dp[p-1][k-1]$$什么时候$p = 0$，第二项被视为零，因为$dp[-1][*]$不存在。 

DP 的结构确保每个状态仅依赖于先前计算的值，并且不会重新计算任何状态。 

### 为什么它有效

 关键的不变量是$dp[p][k]$表示所有随机删除序列的确切期望值仅限于$k$剩余元素和当前指针$p$。 在每个步骤中，第一个删除的条件根据所选索引将所有有效序列划分为不相交的情况。 每个案例都会缩减为具有正确概率权重的较小实例$p/k$和$(k-p)/k$。 由于这些情况涵盖了所有结果并保留了剩余缺失的分布，因此递归在每一层都准确地保留了期望。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    dp = [[0.0] * (n + 1) for _ in range(n + 1)]
    
    for p in range(n + 1):
        dp[p][0] = float(p)
    
    for k in range(1, n + 1):
        for p in range(0, k + 1):
            if p == 0:
                dp[p][k] = 0.0
            else:
                dp[p][k] = (p / k) * dp[p][k - 1] + ((k - p) / k) * dp[p - 1][k - 1]
    
    res = dp[n][:]
    print(" ".join(f"{x:.10f}" for x in res))

if __name__ == "__main__":
    solve()
```DP 表是根据剩余元素的数量自下而上构建的。 每个转换直接编码删除当前指针段内部或外部之间的概率划分。 浮点运算就足够了，因为所需的精度是$10^{-6}$。 

一个常见的错误是迭代$p$一直到$n$对于每一个$k$。 有效范围缩小$k$，并且使用无效状态会引入垃圾值。 另一个微妙的问题是处理$p = 0$，其中引用$dp[-1]$必须明确避免。 

## 工作示例

 ### 示例 1

 考虑$n = 2$。 我们计算状态$k = 0$向上。 

| k | p| dp[p][k] | dp[p][k] | 说明|
 | --- | --- | --- | --- |
 | 0 | 0 | 0 | 基地|
 | 0 | 1 | 1 | 基地|
 | 1 | 0 | 0 | 仅无效或为零 |
 | 1 | 1 | 1/1 * dp[1][0] = 1 | 单元素|

 在$k = 2$， 为了$p = 1$，一半的时间我们删除左侧和一半的右侧，从而产生保持期望居中的对称性。 

为了$p = 2$，右侧的删除更有可能提前，因此预期值相对于较小的值会增加$p$。 

这证实了递归自然地捕获了指针位置引入的偏差。 

### 示例 2

 让$n = 3$,$p = 2$。 我们专注于转变：

 在$k = 3$,$p = 2$，我们结合：$2/3$删除位于前两个位置的机会，保持$p$， 和$1/3$它位于位置 3 的机会，减少$p$至 1。 

这混合了状态$dp[2][2]$和$dp[1][2]$，显示期望如何通过 DP 结构向后传播。 

跟踪证实较大$p$随着删除的积累，值逐渐将概率质量变成更小的状态。

 ## 边缘情况

 当$p = 0$，指针永远不会减少，因为不存在严格大于零的索引。 DP 正确地强制所有转换进入$p = 0$分支，因为该术语涉及$p-1$被跳过。 

为了$p = n$，除第一次之外的每次删除都有非零的机会影响指针。 DP 处理这个问题是因为$k = n$,全系列$p$是活跃的，并且循环自然地允许重复向下过渡到更小的状态。 

最后一个微妙的情况是$p$方法$k$。 在该边界处，概率分裂严重偏向于递减$p$，DP 通过加权来反映这一点$dp[p-1][k-1]$术语更加强烈。 这确保了预期值不会错误地保持在高位稳定$p$价值观。
