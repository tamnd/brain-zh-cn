 ## 解决方案
 ## 问题理解

 我们得到一个整数，代表滚动标准六面骰子两次所需的总分数。 每次掷骰都会产生 1 到 6 之间的值（含 1 和 6），最终结果是两个结果的总和。 任务是决定是否存在使用两个这样的掷骰来获得给定目标总和的方法。 

尽管输入规模极小，但问题的结构是一个经典的有界和可行性问题。 每个变量都有一个固定的域，因此整个状态空间是有限且微小的。 这立即意味着任何枚举所有结果的解决方案都已经足够快，甚至可能的总和的直接数学表征就足够了。 

一个常见的错误来自于误读了允许的总和范围。 由于每个骰子至少显示 1，最多显示 6，因此最小可能的总和为 2，最大为 12。无论骰子如何滚动，任何超出此范围的值都是不可能的。 

两种具体的边缘情况暴露了典型的推理错误。 如果目标是 1，“任何小数字都可能达到”的天真假设就会失败，因为最小和已经是 2，所以正确答案是“否”。如果目标是 12，有些人可能会错误地认为它很罕见或特殊，但实际上可以通过 (6, 6) 实现，所以正确答案是“是”。 

## 方法

 直接暴力法考虑每一个可能的有序骰子对结果。 第一卷有 6 种选择，第二卷有 6 种选择，总共产生 36 种组合。 对于每一对，我们计算总和并将其与目标值进行比较。 这种做法是正确的，因为它检查了整个样本空间，没有遗漏。 它的成本相对于输入大小是恒定的，因为结果的数量永远不会改变。 

尽管暴力在这里已经足够有效，但我们可以通过观察根本不需要枚举结果来进一步简化。 两个有界整数的和仅取决于它们的极值。 可实现的最小总和是 1 + 1，最大总和是 6 + 6。之间的每个整数都是可以实现的，因为两个骰子的总和分布在该区间内是连续的。 这将问题简化为简单的间隔检查。

 ## 算法演练

 1. 读取代表目标总和的整数x。 这是我们想要根据骰子总和的可达范围来验证的值。 
2. 确定两个骰子的最小和最大可能总和。 最小值来自两个骰子都显示 1，最大值来自两个骰子都显示 6。 
3. 检查 x 是否位于 2 到 12 的闭区间内。如果是，则必须存在一对有效的骰子结果来产生它。 
4. 如果 x 在区间内，则输出“Yes”。 否则输出“否”。 

### 为什么它有效

 每个有效结果对应于一对 (a, b)，其中两个值都限制在固定的整数区间内。 所有可能和的集合正是笛卡尔乘积在加法下的图像。 由于两个域都是连续的整数范围，因此所得总和集的最小值和最大值之间没有间隙。 因此，可达集合中的成员资格相当于简单的边界检查。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    x = int(input().strip())
    if 2 <= x <= 12:
        print("Yes")
    else:
        print("No")

if __name__ == "__main__":
    solve()
```该解决方案读取输入一次，然后直接将其与预先计算的可行性区间进行比较。 没有循环或附加数据结构。 边界条件是关键细节：端点 2 和 12 都包含在内，因为它们对应于有效的骰子配置 (1,1) 和 (6,6)。

 ## 边缘情况

 对于下限情况，考虑输入 x = 2。算法检查 2 ≤ x ≤ 12，这成立。 这与骰子结果 (1,1) 完全一致，确认了边界的正确性。 

对于上限情况，考虑 x = 12。检查也通过，这对应于 (6,6)。 尽管它是单个配置，但它仍然位于可达集合内，因此算法正确地接受它。 

对于低于范围的值（例如 x = 1），下界检查会立即失败，因为 1 < 2。这反映了不可能获得小于两个独立正整数且每个至少为一的总和。
