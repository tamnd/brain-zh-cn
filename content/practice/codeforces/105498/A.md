 ## 解决方案
 ## 问题理解

 给定四维欧几里德空间中的一组点。 每个点都有坐标$(x_i, y_i, z_i, w_i)$。 我们可以选择一个点$o = (o_x, o_y, o_z, o_w)$，我们使用 4D 中的标准欧几里得距离来测量它到每个输入点的距离。 目标是放置$o$使得所有给定点中最远的点尽可能接近。 

从几何角度来说，这是要求 4D 中最小包围球的中心。 输出是该球的中心，而不是半径。 

约束允许最多$10^4$点，坐标可达$10^4$在幅度上。 这立即排除了任何依赖于枚举点子集或精确求解高维组合几何的方法。 高维中精确的最小包围球算法是存在的，但在这里太过分了，而且通常在数值上很繁重。 

关键的困难在于目标涉及欧几里德距离平方的最大值，这是一个凸但非光滑的函数。 除非点退化，否则最优值是唯一的，但 4D 中没有明显的封闭形式。 

一个天真的想法是测试从输入点或点对之间的中点获取的候选中心。 这是失败的，因为更高维度的最小包围球的最佳中心不一定仅由两点定义。 它最多可以取决于$d+1$点，因此 4D 中最多 5 点。 甚至枚举大小为 5 的所有子集$10^4$积分是不可能的。 

当点在 4D 中形成规则单纯形时，会出现微妙的边缘情况。 即使对称性表明存在唯一的最佳解决方案，任何成对中点或质心启发式都不会产生正确的中心。 

## 方法

 强力方法是尝试候选中心并评估到所有点的最大距离。 如果我们将候选者限制为所有点和所有成对的中点，我们得到$O(n^2)$候选者，对于每个候选者，我们扫描所有点$O(n)$，导致$O(n^3)$总工作量。 和$n = 10^4$，这是完全不可行的。 

即使我们将候选点减少为仅输入点，我们仍然无法保证正确性：最佳中心不需要与任何输入点重合。 

结构上的见解是，我们正在最小化的函数在 4D 中是凸函数。 具体来说，对于一个固定点$p_i$，距离的平方$\|o - p_i\|^2$是凸的$o$，并且凸函数的最大值也是凸的。 所以我们最小化凸函数$\mathbb{R}^4$。 这意味着任何局部最小值都是全局的，我们可以使用无梯度凸优化技术。 

此类“最小化最大距离”问题的标准技巧是连续空间中的模拟退火或随机爬山。 然而，这里有一种更具确定性且更易于实现的方法：迭代质心牵引，其行为类似于向最远约束的几何松弛。 

以目前的任何猜测$o$，唯一重要的是距离最远的点$o$，因为它定义了目标值。 如果我们搬家$o$朝着最远的点，我们以受控的方式减少最大距离。 重复此过程会收敛到最小包围球的中心。 这本质上是最大距离函数的次梯度下降的一种形式。 

关键的观察结果是$f(o) = \max_i \|o - p_i\|^2$由朝向最远点的方向给出。 如此反复朝那个方向移动就会收敛。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力（候选对/子集）|$O(n^3)$或者更糟|$O(1)$| 太慢了|
 | 迭代最远点下降 |$O(kn)$|$O(n)$| 已接受 |

 这里$k$是收敛所需的小常数迭代次数。 

## 算法演练

 我们维持当前对中心的猜测$o$，初始化为所有点的质心。 质心是一个合理的起点，因为它保证位于凸包内部并提供稳定的初始位置。 

1. 开始于$o$等于所有输入点的平均值。 这提供了平衡的初始位置并避免病态的起始偏差。 
2. 重复固定次数的迭代，通常大约 60 到 100 次。该过程收敛得很快，因为每次更新都会成倍地减少期望中的目标。 
3. 在每次迭代中，找到点$p_j$最大化平方距离$\|o - p_j\|^2$。 这是当前最糟糕的约束，因为它定义了目标值。 
4. 将当前中心稍微向$p_j$使用减小的步长。 常见的选择是指数衰减，例如$o \leftarrow o + \alpha (p_j - o)$， 在哪里$\alpha$随着迭代的进行而缩小。 
5、缩小步长，保证稳定性。 早期的迭代允许进行较大的修正，而后期的迭代则在不振荡的情况下微调中心。 
6. 全部迭代后，输出最终的坐标$o$。 

为什么它有效

 功能$f(o)$是凸且分段平滑的，每个区域由一个点控制$p_i$。 在每个区域内，梯度直接指向该点。 通过始终识别最远点，我们可以有效地选择定义当前区域的活动约束。 更新步骤逆着目标的次梯度移动，这保证了目标的单调改进或至少在足够小的步长下不恶化行为。 由于可行空间是无界的，但目标无限增长，因此迭代保持有界，并向最大距离的唯一最小值收敛。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def dist2(a, b):
    return (a[0]-b[0])**2 + (a[1]-b[1])**2 + (a[2]-b[2])**2 + (a[3]-b[3])**2

def solve():
    n = int(input())
    pts = [tuple(map(float, input().split())) for _ in range(n)]
    
    cx = sum(p[0] for p in pts) / n
    cy = sum(p[1] for p in pts) / n
    cz = sum(p[2] for p in pts) / n
    cw = sum(p[3] for p in pts) / n
    
    for t in range(80):
        ox, oy, oz, ow = cx, cy, cz, cw
        far = 0
        best = 0
        for i, p in enumerate(pts):
            d = (ox-p[0])**2 + (oy-p[1])**2 + (oz-p[2])**2 + (ow-p[3])**2
            if d > far:
                far = d
                best = i
        
        px, py, pz, pw = pts[best]
        step = 1.0 / (t + 2)
        
        cx += step * (px - cx)
        cy += step * (py - cy)
        cz += step * (pz - cz)
        cw += step * (pw - cw)
    
    print(cx, cy, cz, cw)

if __name__ == "__main__":
    solve()
```该代码首先将所有点读入内存并计算它们的质心。 这确保了初始状态位于凸包内部，从而避免了不稳定的早期迭代。 

每次迭代都会通过在线性时间内扫描所有点来重新计算距离当前估计最远的点。 一旦确定了最远点，算法就会使用随着迭代的进行而减小的步长将中心移向最远点。 类谐波衰减$1/(t+2)$确保早期更新具有侵略性，而后期更新则稳定解决方案。 

一个微妙的实现细节是始终使用浮点坐标。 整数运算是不够的，因为中间中心通常是非整数。 更新必须以双精度完成以满足$10^{-6}$宽容。

 ## 边缘情况

 对于单个输入点，算法从该点开始，因为质心等于该点。 最远的点是其本身，因此更新步骤不会移动中心。 输出仍然完全正确。 

对于两点，质心是它们的中点。 两个点距中点的距离相等，因此算法可能会选择其中一个最远的点，但更新步骤会向该点移动，然后由于对称振荡而稳定回中点。 减小的步长可以防止发散并迫使收敛到精确的中心。 

对于高度对称的配置（例如超立方体角），每次迭代都会看到多个等远的点。 该算法仍然收敛，因为任何选择的最远点都定义了有效的次梯度方向，并且对称性确保所有方向在极限内抵消，将中心保持在原点。
