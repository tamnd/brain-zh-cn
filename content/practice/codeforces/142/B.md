 ## 解决方案
 ## 问题理解

 我们有一个`n × m`像棋盘一样的网格，我们希望放置尽可能多的士兵。 如果两个士兵的细胞之间的欧几里德距离的平方恰好是`5`。 

唯一平方距离等于的整数对`5`是`(1, 2)`和`(2, 1)`最多可以签名。 换句话说，士兵之间互相攻击就像国际象棋中的骑士一样。 这个任务实际上是要求一个阵中非攻击骑士的最大数量。`n × m`木板。 

板的尺寸最多为`1000 × 1000`，所以细胞总数可以达到一百万。 这立即排除了任何指数搜索或回溯。 即使是尝试探索子集或在所有单元上运行重型图算法的算法也会遇到困难。 我们需要直接的建设性或数学观察。 

如果我们直接跳到棋盘模式，一些边缘情况很容易处理不当。 

考虑单行：

 输入：```
1 7
```正确输出：```
7
```骑士需要水平和垂直偏移来攻击。 上一个`1 × 7`棋盘上，没有两个单元互相攻击，因此每个方格都可以被占领。 粗心的棋盘解决方案会错误地返回`4`。 

这`2 × m`案件才是真正的陷阱。 

输入：```
2 4
```正确输出：```
4
```标准棋盘只给出`4`，这在这里恰好是正确的，但是对于：

 输入：```
2 5
```正确输出：```
6
```简单的交替着色给出`5`，这不是最佳的。 在一维等于的板上`2`，骑士可以被包装在四列的重复块中。 

另一个微妙的例子：

 输入：```
2 2
```正确输出：```
4
```不可能有骑士攻击，因为经过`(1,2)`或者`(2,1)`不适合板内。 每个牢房都可能包含一名士兵。 任何盲目使用一半单元格的公式都会失败。 

## 方法

 蛮力解释很简单。 将每个单元格视为图中的顶点，如果骑士互相攻击，则连接两个单元格，并搜索最大独立集。 这保证了正确性，因为独立的集合正是一组不冲突的士兵。 

问题是最大独立集一般是指数的。 即使只有 40 个单元，暴力破解也变得不切实际。 我们的主板可能包含多达一百万个单元，所以这个方向是没有希望的。 

骑士运动的结构改变了一切。 骑士总是从棋盘的一种颜色跳到另一种颜色。 这意味着攻击图是二分的。 在大多数棋盘上，将马放在全黑方格或全白方格上会立即获得大约一半的单元格，事实上，这对于两个尺寸至少都为的棋盘来说是最佳的`3`。 

唯一的例外是当一维非常小时。 

如果任一维度等于`1`，骑士根本无法攻击。 每个方块都可以使用。 

如果任一维度等于`2`，图案变得特别。 骑士只能在四个连续列的组内互动。 在每个这样的四块中，我们可以安全地放置四名骑士。 任何剩余的纵队每对纵队最多贡献两个额外的骑士。 

对于所有较大的棋盘，简单的棋盘布置是最佳的，给出：```
ceil(n * m / 2)
```整个问题归结为仔细处理这三种结构情况。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(2^(nm)) | O(2^(nm)) | O(纳米) | 太慢了|
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 阅读`n`和`m`。 
2. 标准化尺寸，使得`n <= m`。 

这简化了特殊情况的处理，因为我们只需要检查较小的值`n`。 
3.如果`n == 1`， 输出`m`。 

骑士需要在两个方向上移动。 在单行上，不可能进行任何攻击。 
4. 如果`n == 2`，以四列为一组的块处理棋盘。 

在每四列的块中，我们可以使用重复模式安全地放置四名骑士。 
5. 计算：```
blocks = m // 4
rem = m % 4
```6. 添加`blocks * 4`完整方块的骑士。 
7. 对于其余列：

 - 如果`rem == 0`， 添加`0`- 如果`rem == 1`， 添加`2`- 如果`rem >= 2`， 添加`4`剩下的纵队最多可以贡献四名额外的骑士。 
8. 否则，当`n >= 3`， 输出：```
(n * m + 1) // 2
```这是棋盘着色中较大颜色的单元格数量。 

### 为什么它有效

 当两个维度都至少为`3`，每一个骑士的举动都会改变棋盘的颜色。 仅将骑士放置在一种颜色上可以保证不会发生冲突，并且任何排列都不能超过二部图的较大分区大小。 

这`1 × m`案件根本没有合法的骑士行动，所以每个方格都是安全的。 

这`2 × m`情况的表现有所不同，因为骑士只能在非常有限的结构中进行交互。 最佳排列每四列重复一次。 在每个四柱部分内，可以安全地放置所有四名骑士。 任何不完整的部分最多为每个剩余的列对贡献两个骑士。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

if n > m:
    n, m = m, n

if n == 1:
    print(m)

elif n == 2:
    blocks = m // 4
    rem = m % 4

    ans = blocks * 4

    if rem == 1:
        ans += 2
    elif rem > 1:
        ans += 4

    print(ans)

else:
    print((n * m + 1) // 2)
```第一步交换尺寸，以便`n`始终是较小的那个。 这使得所有特殊处理都可以集中于`n == 1`和`n == 2`。 

这`n == 1`分支是直接的。 骑士无法攻击，因为每次攻击都需要跨越两个维度的移动。 

这`n == 2`逻辑是唯一棘手的部分。 重复图案跨越四列。 每个完整的团体都贡献了四名骑士。 余数处理很微妙：

 对于额外的一列，我们可以再放置两名骑士。 

对于额外的两列或三列，我们可以再放置四名骑士。 

一个常见的错误是使用：```
ans += rem * 2
```当`rem == 3`。 

最后一个分支使用棋盘公式处理所有较大的棋盘。 表达式：```
(n * m + 1) // 2
```计算一半单元格的上限。 

Python 整数可以轻松处理这里的最大乘积，但即使在具有固定宽度整数的语言中，`1000 × 1000`是完全安全的。

# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n, m = map(int, input().split())

    if n > m:
        n, m = m, n

    if n == 1:
        print(m)

    elif n == 2:
        blocks = m // 4
        rem = m % 4

        ans = blocks * 4

        if rem == 1:
            ans += 2
        elif rem > 1:
            ans += 4

        print(ans)

    else:
        print((n * m + 1) // 2)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

# provided sample
assert run("2 4\n") == "4", "sample 1"

# custom cases
assert run("1 1\n") == "1", "minimum board"
assert run("1 7\n") == "7", "single row"

assert run("1000 1000\n") == "500000", "maximum size"

 ## 边缘情况

 考虑输入：```
1 7
```该算法标准化维度并输入`n == 1`分支。 它立即返回`7`。 

任何骑士移动都不可能存在，因为垂直移动是不可能的。 该算法正确地避免了棋盘公式，该公式会错误地给出`4`。 

现在考虑：```
2 5
```计算变为：

 | 变量| 价值|
 | --- | --- |
 |`blocks`|`1`|
 |`rem`|`1`|
 | 基地|`4`|
 | 额外 |`2`|
 | 回答 |`6`|

 剩下的单列恰好贡献了两名额外的骑士。 这会捕获错误地仅添加一个的实现。 

最后：```
2 2
```我们得到：

 | 变量| 价值|
 | --- | --- |
 |`blocks`|`0`|
 |`rem`|`2`|
 | 基地|`0`|
 | 额外 |`4`|
 | 回答 |`4`|

 尽管棋盘很小，但里面不适合骑士攻击。 正确的特殊处理可以让每个方格都被占领。
