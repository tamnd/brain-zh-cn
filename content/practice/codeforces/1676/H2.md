 ## 解决方案
 ## 问题理解

 我们得到了一组电线，每个索引一根，其中电线`i`从位置开始`i`在上导轨上并结束于位置`a[i]`在下导轨上。 一旦其端点固定在两个导轨上，每根电线都是直段，但我们可以自由选择每个线段内的确切附着点，只要我们尊重线段顺序并且不要将端点精确地放置在线段边界上即可。 

唯一重要的是每条轨道上端点的相对顺序。 两条线之间的交叉取决于它们的顶部端点和底部端点是否以相反的顺序出现。 如果是电线`i`从电线左侧开始`j`在顶部导轨上但在其右侧结束于底部导轨上，可以将两根电线拉成交叉。 如果两个订单一致，我们就可以避免它们之间的交叉。 

任务是通过选择最佳几何布局来最大化所有线对上的此类交叉数量。 这将问题简化为计算在一致嵌入下可以使多少对在顶序和底序之间“反转”。 

这些限制迫使我们走向`O(n log n)`或者`O(n)`每个测试用例的解决方案。 自从总共`n`所有测试用例最多`2 × 10^5`，任何直接比较所有对的二次方法都太慢，因为它需要大约`4 × 10^10`最坏情况下的操作。 

一个微妙的点是重复`a`事情。 如果多根电线终止于同一较低位置，则它们在底侧的相对顺序不会以自动避免交叉的方式固定。 如果假设端点严格排序而没有正确处理相等值，则仅计算标准意义上的反转的天真贪婪可能会失败。 

例如，如果所有`a[i]`相等，每对电线共享相同的底部端点。 顶部的任何排序都会在所有对之间产生交叉，但正确的答案不是“无结构”，而是相同端点之间的对总数，这仍然是完全确定的。 

## 方法

 如果我们用几何术语思考，每对电线要么贡献一个交叉，要么贡献零交叉，具体取决于我们是否可以使它们的端点在顺序上不一致。 因此，这个问题相当于选择一种排序解释，使两个序列之间的反转次数最大化：固定顶序`1..n`以及受等值约束的灵活底部布置。 

一个蛮力的想法是尝试共享相同底部端点的电线如何排序的所有排列。 对于每个选择，我们可以计算顶部和底部位置之间的反转计数。 这立即变得不可行，因为即使出现单个值`k`时代贡献`k!`内部排列，总组合呈指数爆炸。 

关键的结构观察是最高顺序已经固定为`1, 2, ..., n`。 所以每一对`(i, j)`和`i < j`要么贡献一个交叉如果`a[i] > a[j]`，或者可以安排避免它，如果`a[i] ≤ a[j]`。 因此，最优策略是最大化多集序列中的反转数量`a`，但重要的是相同的元素也有助于交叉，因为我们可以在底部轨道上任意排列它们的端点以最大化交互。 

这导致了一个经过修改的标准反转计数问题：我们必须计算所有对`(i, j)`在哪里`i < j`和`a[i] ≥ a[j]`从最好的安排意义上来说。 对此进行建模的简洁方法是从左到右处理元素，同时保持有多少先前元素严格大于或等于，但由于值受以下限制`n`，我们可以使用频率结构或芬威克树来计算贡献。 

我们没有考虑安排端点，而是将问题重新解释如下：每对端点都会产生交叉，除非我们强迫它们不交叉。 避免交叉的唯一方法是保持两侧的相对顺序一致，这种情况发生在`a[i] < a[j]`我们选择一致的排序。 为了最大化交叉，我们希望最小化这种“非交叉兼容”对，这导致计算所有对减去由排序结构确定的最小结构`a`。 

编辑解决方案中使用的更直接和标准的见解是按以下方式对索引进行排序`a[i]`，并观察最佳交叉对应于计算按值排序后有多少对处于相反顺序，但也考虑了等值贡献。 干净的实现简化为对数组中的反转进行计数，其中通过分组或使用具有频率计数的 Fenwick 树来仔细处理重复项。 

## 算法演练

 1. 独立处理每个测试用例，因为约束是附加的并且没有共享状态。 
2. 将问题解释为根据中的值计算指数对之间的贡献`a`。 我们将计算通过利用排序灵活性可以强制交叉多少对。 
3. 从左到右遍历数组，同时在值上维护芬威克树（或频率数组）`1..n`。 该结构存储每个值有多少个元素已经被看到。 
4. 对于每个位置`i`，我们想要计算有多少先前的元素必然有助于与`a[i]`。 由于我们的目标是最大交叉，因此每个值大于或等于的先前元素`a[i]`可以配对以在最佳位置下产生杂交。 所以我们查询之前有值的元素的个数`≥ a[i]`。 
5. 将这个计数添加到每个的答案中`i`，然后插入`a[i]`进入芬威克树。 
6.处理完所有元素后，输出累加结果。 

### 为什么它有效

 关键的不变量是，在扫描中的任何点，芬威克树代表已经按固定顺序放置在顶侧的所有电线。 对于以价值结尾的新线`x`，任何先前见过的至少具有底部端点的电线`x`可以进行排列，使得它们的底部排序相对于顶部排序相反，从而保证交叉。 贪婪累积对每对精确计数一次，因为在处理后面的索引时对每对进行计数，并且 Fenwick 查询准确捕获可以强制进行交叉配置的早期索引集。 

这将全局几何优化简化为前缀状态上的局部计数过程，其中每次插入仅取决于聚合的频率信息。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, i, v):
        while i <= self.n:
            self.bit[i] += v
            i += i & -i

    def sum(self, i):
        s = 0
        while i > 0:
            s += self.bit[i]
            i -= i & -i
        return s

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    fw = Fenwick(n)
    ans = 0

    for i, x in enumerate(a):
        seen = i
        less = fw.sum(x - 1)
        ans += seen - less
        fw.add(x, 1)

    print(ans)
```芬威克树维护迄今为止看到的值的频率计数。 对于每个元素`x`,`fw.sum(x - 1)`计算有多少个先前的值严格小于，因此从中减去`seen`给出有多少个先前值大于或等于。 这些正是有助于以最佳排列进行交叉的对。 

微妙之处在于正确处理平等。 使用`≥`而不是`>`是至关重要的，因为相等的值仍然会在最佳放置下生成交叉，并且 Fenwick 查询结构自然地通过以下方式捕获这一点：`seen - less`。

 ## 边缘情况

 对于单线，该算法初始化一个空的 Fenwick 树，并且不会累积任何贡献，从而按预期产生零交叉。 

对于具有所有相等值的数组，每个新元素都会将所有先前元素视为贡献，因为`i - less`等于`i`。 这正确地产生`n(n-1)/2`，匹配所有对都可以交叉的事实。 

对于严格递增数组，每个`a[i]`没有看到任何先前的值大于或等于，因此每个贡献为零，最终答案也为零，这与最佳放置下没有强制反转一致。
