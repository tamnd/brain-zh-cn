 ## 解决方案
 ## 问题理解

 我们有两行平行的线段，顶部和底部，长度均为$n$。 顶行的每个段都有一条电线将其连接到底行的特定段，由数组定义$a$， 在哪里$a_i$是连接到顶部段的底部段$i$。 电线是直线，我们被要求最大限度地增加电线之间的交叉数量。 当两条线共享一个点时，就会发生交叉，当一条线从较小的顶部索引到较大的底部索引，而另一条线从较大的顶部索引到较小的底部索引时，就会发生交叉。 

输入给出多个测试用例，每个测试用例指定$n$和数组$a$。 我们的输出是每个测试用例的最大交叉数。 

限制条件适中：$n \leq 1000$和总和$n$所有测试用例的数量也最多为 1000。这使得算法可以大致$O(n^2)$单个测试用例的复杂性。 边缘情况包括$n=1$在无法穿越的地方，所有$a_i$等于产生$\binom{k}{2}$重复值的交叉，以及严格增加或减少的数组，其中交叉的数量很容易推断。 

一种简单的方法可能会迭代所有对$(i,j)$并检查是否$i < j$和$a_i > a_j$，将每个算作一个交叉点。 考虑到我们的限制，这是简单且正确的，但我们需要形式化为什么它计算最大值。 当每对出现最大值时$i < j$，如果可能的话，电线交叉，这恰好发生在$a_i > a_j$。 不允许重新排列线段上的端点，因此数组中索引的顺序完全决定了交叉点。 

## 方法

 蛮力方法是考虑每对电线。 对于指数$i < j$，我们检查是否$a_i > a_j$。 如果是这样，这两根线就会交叉。 这计算了每一个可能的交叉点。 该算法执行$\binom{n}{2}$比较，即$O(n^2)$。 为了$n \leq 1000$，这最多是$500,000$每个测试用例的比较，考虑到我们的限制是可以接受的。 

关键的见解是，我们不需要任何复杂的数据结构，因为每根线的位置都是固定在顶部和底部的，因此交叉仅取决于顶部索引与底部索引的相对顺序。 由于我们每段只能使用一根导线并且无法调整端点，因此对线对进行迭代可以保证我们考虑到所有潜在的交叉。 对于较大的$n$这可以通过芬威克树或合并排序计数反转来改进，但对于这个版本来说这是不必要的。

 ## 算法演练

 1.读取测试用例数量$t$。 对于每个测试用例，请阅读$n$和数组$a$。 这将使用已确定的电线设置问题实例。 
2. 将交叉计数器初始化为零。 
3. 循环所有索引对$i$和$j$这样$i < j$。 这确保我们只考虑每对电线一次。 
4. 对于每一对，检查是否$a_i > a_j$。 如果为 true，则增加交叉计数器。 这会检查电线是否交叉：顶部索引按升序排列，底部索引按降序排列，这是交叉的条件。 
5. 检查所有对后，打印或存储计数器作为测试用例的最大交叉数。 

为什么它有效：不变的是每对电线都被只考虑一次，并且仅在发生交叉时才递增。 由于不可能重新排列，因此会计算所有可能的交叉。 没有一对被遗漏，并且没有交叉被计算两次。 因此，所得计数器是精确的最大值。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    crossings = 0
    for i in range(n):
        for j in range(i+1, n):
            if a[i] > a[j]:
                crossings += 1
    print(crossings)
```外循环迭代每个测试用例。 对于每个测试用例，我们读取大小$n$和数组$a$。 然后我们使用两个嵌套循环来计算交叉次数。 内循环从$i+1$以避免重复计数或将电线与其自身进行比较。 仅当以下情况时才增加计数器$a[i] > a[j]$精确模拟交叉条件。 最后打印计数器完成每个测试用例。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    res = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        crossings = 0
        for i in range(n):
            for j in range(i+1, n):
                if a[i] > a[j]:
                    crossings += 1
        res.append(str(crossings))
    return "\n".join(res)
