 ## 解决方案
 ## 问题理解

 我们得到一串括号，最初只包含“(”和“)”，并且要求我们支持两种类型的查询。 第一种类型将特定匹配的括号更改为点。 第二种类型计算给定段内形成简单规则括号序列的连续子字符串的数量。 简单的 RBS 是一种不为空且不以点开头或结尾的 RBS。 每次更新后，未来的查询必须反映修改后的字符串。 关键的挑战是字符串最多可以有 300,000 个字符，并且最多可以有 300,000 个查询。 这排除了任何枚举所有可能的子字符串或单独检查每个子字符串的方法，因为这将需要每个查询进行 O(n²) 次操作。 

主要的边缘情况包括在删除查询后部分变为点状的段。 例如，如果字符串是“(()())”，并且我们删除最外面的一对，则内部子字符串可能仍然有效的RBS，但外部子字符串不再简单。 影响重叠段的连续删除查询会出现另一个微妙之处 - 我们无法全局预先计算计数，因为结构会动态变化。 查询还可以请求已经是简单 RBS 但在先前删除后包含内部点的段。 忽略这些点将导致错误的计数。 

## 方法

 暴力方法将检查每个类型 2 查询的查询段中的每个子字符串。 我们可以迭代所有可能的 (i, j) 对并检查是否`s[i..j]`通过模拟去除过程或计算平衡数组形成一个简单的RBS。 这原则上是正确的，但每个查询需要 O(n²)，而考虑到 n 和 q 高达 3×10⁵，这是令人望而却步的。 例如，对 10⁵ 长度的段进行一次查询将需要大约 10^10 次检查，远远超出了时间限制。 

关键的观察结果是，简单的 RBS 可以通过其括号前缀和的结构来表征。 如果我们保持括号的平衡和有效匹配的数量，我们就可以在相对于段长度的线性时间内计算简单的 RBS 子串的数量。 当发生删除查询时，仅需要更新受影响的位置。 线段树或二叉索引树可以有效地跟踪余额并按时间间隔进行计数，从而实现对数时间更新和查询。 本质上，问题简化为对括号余额的动态范围查询，其中每次更新将一对标记为点，并且每个查询计算与简单 RBS 相对应的有效范围。 

蛮力方法在概念上很简单，但行不通。 使用存储了余额信息的线段树使我们能够有效地计算计数并动态应用更新。 通过存储开括号和闭括号的数量、完整对的数量以及点的前缀/后缀信息，每次查询和更新都可以在 O(log n) 时间内完成。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | 每次查询 O(n²) | O(n) | 太慢了 |
 | 具有平衡跟踪功能的线段树 | 每次查询/更新 O(log n) | O(n) | 已接受 |

 ## 算法演练

 1. 将字符串表示为节点数组，其中每个节点存储它是左括号、右括号还是点。 每个节点还会维护辅助值：开括号和闭括号的数量，以及其区间内完整的简单RBS的数量。 
2. 在此数组上构造一棵线段树。 每个段存储：其内完整的RBS总数、左端不匹配的开括号的数量、以及右端不匹配的闭括号的数量。 两个段之间的合并操作组合了完整的 RBS 计数，并通过将左段的左括号与右段的右括号匹配来调整不匹配的计数。 
3.对于类型1查询（移除），将两个具体位置更新为点。 这涉及将线段树中的相应节点设置为零括号和零完整 RBS，然后沿到根的路径更新父节点以保持正确的计数。 
4. 对于类型2查询（计数），在线段树中查询区间。 结果将是该段中完整的简单 RBS 的总数。 由于在任何删除之前该段保证是一个简单的 RBS，因此所有内部计数都是有效的，并且树合并逻辑确保点得到尊重。 
5. 由于线段树的高度，每次更新或查询操作都需要 O(log n) 时间。 这允许有效地处理所有查询。 

工作原理：线段树保持不变式，即每个节点准确反映其区间内完整的简单 RBS 的数量，并考虑到删除的括号（点）。 合并两个段时，不匹配的括号会正确传播，确保计数保持一致。 更新是本地化的，因此将来的查询始终在当前状态上运行。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

class Node:
    __slots__ = ['open', 'close', 'total']
    def __init__(self, c):
        if c == '(':
            self.open = 1
            self.close = 0
        elif c == ')':
            self.open = 0
            self.close = 1
        else:
            self.open = 0
            self.close = 0
        self.total = 0

def merge(left, right):
    matched = min(left.open, right.close)
    total = left.total + right.total + matched
    open_br = left.open + right.open - matched
    close_br = left.close + right.close - matched
    res = Node('.')
    res.open = open_br
    res.close = close_br
    res.total = total
    return res

class SegmentTree:
    def __init__(self, s):
        self.n = len(s)
        self.size = 1
        while self.size < self.n:
            self.size <<= 1
        self.tree = [Node('.') for _ in range(2*self.size)]
        for i in range(self.n):
            self.tree[self.size+i] = Node(s[i])
        for i in range(self.size-1, 0, -1):
            self.tree[i] = merge(self.tree[2*i], self.tree[2*i+1])
    
    def update(self, pos):
        pos += self.size
        self.tree[pos] = Node('.')
        while pos > 1:
            pos >>= 1
            self.tree[pos] = merge(self.tree[2*pos], self.tree[2*pos+1])
    
    def query(self, l, r):
        l += self.size
        r += self.size
        left_res = Node('.')
        right_res = Node('.')
        while l <= r:
            if l % 2 == 1:
                left_res = merge(left_res, self.tree[l])
                l += 1
            if r % 2 == 0:
                right_res = merge(self.tree[r], right_res)
                r -= 1
            l >>= 1
            r >>= 1
        return merge(left_res, right_res).total

n, q = map(int, input().split())
s = input().strip()
st = SegmentTree(s)

for _ in range(q):
    t, l, r = map(int, input().split())
    l -= 1
    r -= 1
    if t == 1:
        st.update(l)
        st.update(r)
    else:
        print(st.query(l, r))
```该解决方案在初始字符串上构造一棵线段树，每个节点代表一个字符。 merge 函数计算有多少对括号可以在两个段之间形成简单的 RBS，并传播不匹配的括号。 更新将括号变成点并向上传播更改。 查询有效地计算任何段中简单 RBS 子串的总数。
