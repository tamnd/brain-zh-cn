 ## 解决方案
 ## 问题理解

 每辆无轨电车在固定的发车时间从车站出发。 一切从速度开始`0`, 最多可以加速`a`，并且永远不能超过自己的速度限制`v[i]`。 目的地是`d`米远。 制动不受限制，因此无轨电车可以在需要时立即降低速度。 

如果是无轨电车`i`赶上无轨电车`i-1`，超车是不可能的。 从那一刻起，两人一起移动，无轨电车`i`不能早于无轨电车到达`i-1`。 

对于每辆无轨电车，我们必须计算最早可能到达终点站的时间，同时遵守加速度限制、速度限制和禁止超车规则。 

约束完全决定了预期的复杂性。 最多有`10^5`无轨电车，因此任何连续模拟运动或比较每对无轨电车的解决方案都太慢。 一个`O(n^2)`解决方案大约需要`10^10`最坏情况下的操作，远远超出了极限。 我们需要一种线性或近线性的方法。 

物理部分也很重要。 无轨电车并不总是以最高速度行驶。 有时距离太短，无法到达`v[i]`。 粗心的实施假设每辆无轨电车都加速到`v[i]`首先会产生错误的时间。 

考虑这个输入：```
1 10 5
0 100
```无轨电车只需要行驶`5`米。 到达速度`100`在那个距离内是不可能的。 正确的运动是纯加速度：```
distance = 1/2 * a * t^2
5 = 5 * t^2
t = 1
```所以答案是：```
1.0000000000
```另一个容易犯的错误是忘记了后来的无轨电车不能比前面的电车更早到达。 

例子：```
2 1 10
0 1
1 100
```第一辆无轨电车需要：```
10 seconds
```如果轨道空着，第二辆无轨电车可能会提前到达，但禁止超车。 正确答案是：```
10.0000000000
10.0000000000
```独立计算每个手推车的幼稚实现会错误地打印接近于`5.47`为第二辆无轨电车。 

当一辆无轨电车恰好在目的地赶上另一辆无轨电车时，就会发生第三种微妙的情况。 这仍然算作同时到达。 

例子：```
2 1 1
0 1
1 100
```第一趟无轨电车准时到达`1.5`。 第二辆无轨电车也恰好在`1.5`。 正确的输出是：```
1.5000000000
1.5000000000
```在比较逻辑中使用严格的不等式可能会在此边界上失败。 

## 方法

 蛮力的想法很简单。 对于每辆无轨电车，根据物理约束计算其不受限制的最早到达时间。 然后将其与之前所有的无轨电车进行比较，以确定是否能在到达目的地之前赶上其中的任何一辆。 

这是有效的，因为无轨电车按顺序行驶并且不能超车。 如果是无轨电车`i`会比无轨电车早到达`j`，那么在某个时刻它必须赶上。 

问题在于规模。 检查每对之间的相互作用需要`O(n^2)`比较。 和`10^5`无轨电车，变得慢得令人绝望。 

关键的观察是我们实际上不需要模拟追赶发生的位置。 

假设无轨电车`i`能独立准时到达`T[i]`。 如果`T[i]`小于前一趟无轨电车的实际到达时间，则无轨电车`i`最终必须在目的地之前赶上它。 由于无法超车，无轨电车`i`被迫在完全相同的时间到达。 

这意味着真正的到达时间很简单：```
answer[i] = max(answer[i-1], independent_time[i])
```一切都归结为计算单辆无轨电车物理上可能的最早到达时间。 

只有两种运动模式。 

如果无轨电车在到达目的地之前达到最大速度，则：

 1.它加速自`0`到`v`。 
2. 以恒定速度继续进行。 

如果目的地太近，那么它只会全程加速。 

转变点来自加速距离公式：```
v^2 = 2ad
```如果`v^2 <= 2ad`，无轨电车在到达目的地之前达到最大速度。 

否则它永远不会到达`v`。 

这给出了一个完整的`O(n)`解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n²) | O(n) | 太慢了|
 | 最佳 | O(n) | O(n) | 已接受 |

 ## 算法演练

 1. 阅读`n`,`a`， 和`d`。 
2. 对于每辆无轨电车，假设轨道是空的，计算其最快可能到达时间。 
3. 确定无轨电车在行驶距离前是否能够达到其限速`d`。 

加速所需的距离`0`到`v`是：$s = \frac{v^2}{2a}$如果这个值最多是`d`，然后无轨电车达到全速。 
4. 如果无轨电车达到全速：

 1.计算加速时间：$t = \frac{v}{a}$2.计算加速距离：$s = \frac{v^2}{2a}$3. 以匀速行驶剩余距离。 
4.添加出发时间`t[i]`。 
5. 否则，无轨电车将在整个行程中加速。 

使用：$d = \frac{1}{2}at^2$这给出：$t = \sqrt{\frac{2d}{a}}$6. 令该计算值为`independent`。 
7. 实际到达时间不能早于前一趟无轨电车的到达时间。 

放：```
answer[i] = max(answer[i-1], independent)
```8.输出所有答案。 

### 为什么它有效

 不变量很简单：处理无轨电车后`i`,`answer[i]`等于物理上可实现的最早到达时间，同时遵守所有禁止超车限制。 

独立的运动计算是最佳的，因为每辆无轨电车总是在允许的范围内积极加速，除非被迫，否则永远不会减速。 

如果`independent[i] >= answer[i-1]`，然后是无轨电车`i`永远不会赶上前面的无轨电车，因此它可以保持最佳时间表。 

如果`independent[i] < answer[i-1]`，然后是无轨电车`i`会比无轨电车更早到达目的地`i-1`。 由于超车是不可能的，因此必须在目的地之前或正好在目的地进行追赶。 从那一刻起，他们一起移动，迫使无轨电车`i`到达`answer[i-1]`。 

因此，采用跑步最大值可以准确地模拟物理限制。 

## Python 解决方案```python
import sys
import math

input = sys.stdin.readline

def solve():
    n, a, d = map(int, input().split())

    ans = []

    for _ in range(n):
        t, v = map(int, input().split())

        accel_dist = v * v / (2.0 * a)

        if accel_dist >= d:
            travel_time = math.sqrt(2.0 * d / a)
        else:
            accel_time = v / a
            remaining = d - accel_dist
            travel_time = accel_time + remaining / v

        arrival = t + travel_time

        if ans:
            arrival = max(arrival, ans[-1])

        ans.append(arrival)

    print("\n".join(f"{x:.10f}" for x in ans))

solve()
```第一部分计算一辆无轨电车的无限制最佳行驶时间。 

表达式：```
accel_dist = v * v / (2.0 * a)
```代表加速所需的距离`0`到`v`。 

如果这个距离大于或等于`d`，那么无轨电车在到达目的地之前永远不会达到最大速度。 整个行程都是加速运动，所以我们求解：```
d = 1/2 * a * t^2
```使用平方根公式。 

否则，无轨电车首先加速至`v`，然后匀速移动。 旅行时间变为：```
time_to_accelerate + time_at_constant_speed
```最重要的实现细节是最后一行：```
arrival = max(arrival, ans[-1])
```如果没有这一点，后面的无轨电车可能会非法超越前面的无轨电车。 

另一个微妙之处是到处都使用浮点运算。 这些公式涉及平方根和除法，因此整数运算会截断值并破坏精度。 

条件：```
if accel_dist >= d:
```必须包括平等。 如果无轨电车恰好在目的地达到最大速度，则没有巡航阶段。

 ## 边缘情况

 ### 无轨电车永远不会达到最高速度

 输入：```
1 10 5
0 100
```达到速度所需的加速距离`100`是：```
100^2 / (2 * 10) = 500
```但目的地只是`5`米远。 

算法进入平方根分支：```
t = sqrt(2 * 5 / 10) = 1
```输出：```
1.0000000000
```一个总是加速的有缺陷的实现`v`首先会产生一个非常错误的答案。 

### 更快的无轨电车稍后开始

 输入：```
2 1 10
0 1
1 100
```第二辆无轨电车独立抵达`5.47`，但是第一辆无轨电车到达`10.5`。 

该算法计算：```
answer[1] = max(5.47, 10.5) = 10.5
```这正确地模拟了追赶事件。 

### 准确地到达目的地

 输入：```
2 1 1
0 1
1 100
```第一趟无轨电车抵达`1.5`。 

第二辆无轨电车也独立到达目的地`1.5`。 

该算法保持：```
answer[1] = max(1.5, 1.5) = 1.5
```使用严格的不等式代替`max`由于浮点比较，逻辑可能会错误地分离答案。
