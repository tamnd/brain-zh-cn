 ## 解决方案

 ## 问题理解

 我们有一个非常大的网格`n`行和`m`列。 角色从左上角的单元格开始，并以固定的确定性模式精确地遍历每个单元格一次。 首先，她直接沿着第一列一直走到左下角。 从那里开始，她开始蛇形遍历剩余的网格：她移动穿过一行，在边界处向上移动一个单元格，以相反的方向返回穿过下一行，并继续交替方向，直到访问完所有单元格。 

我们被问到的问题与直接模拟步行不同。 而不是全部执行`k`移动后，我们必须确定准确之后所占据的确切单元格`k`从头开始的步骤。 

这些限制使得暴力破解变得不可能。 两个维度都可以大到10^9，步数可以达到接近10^18。 任何逐步模拟运动的方法都需要多达 10^18 次转换，这远远超出了可行的限制。 即使存储网格也是不可能的，因为它需要 10^18 内存。 

一个微妙但重要的结构细节是路径不是任意的。 它分解为简单的几何阶段：第一列中的直线垂直下降，然后是剩余矩形中完全规则的锯齿形图案。 

边缘情况主要出现在相变周围。 例如，当`k`正好降落在`(n, 1)`，或者当它恰好落在锯齿形区域的第一个单元格时`(n, 2)`。 简单的模拟可能会错误地计算方向翻转是发生在进入一行之前还是之后，从而导致相差一的错误。 

## 方法

 蛮力策略实际上会模拟每次移动，更新当前位置和方向。 这是可行的，因为每一步仅取决于本地邻接规则。 然而，它需要`k`迭代，并且自从`k`可以大到 10^18，这立即变得不可行。 即使每秒 10^8 次操作，这也需要数年时间。 

关键的观察结果是该运动具有高度结构化的分解。 第一个`n-1`移动是确定性的：路径直接从第 1 列开始`(1,1)`到`(n,1)`。 之后，剩下的路径是在大小网格上的完美蛇形遍历`n × (m-1)`，开始于`(n,2)`。 

一旦我们隔离了这个结构，问题就简化为将矩形的蛇形遍历中的索引映射到其坐标。 在这样的遍历中，每个列对贡献恰好一行的垂直移位，并且方向每列交替。 

因此，我们不模拟运动，而是直接计算是否`k`位于初始垂直段或之字形段中，然后使用除法和奇偶校验逻辑将剩余偏移量转换为行/列坐标。

 | --- | --- | --- | --- |
 | 蛮力 | O(k) | O(1) | O(1) | 太慢了 |
 | 最佳| O(1) | O(1) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1. 计算需要多少步才能到达`(n,1)`。 这正是`n - 1`。 如果`k`比这个小，答案就在第一列，我们直接返回`(1 + k, 1)`。 这是可行的，因为运动在第 1 列中严格向下，没有分支。 
2.如果`k`大于或等于`n - 1`, 减去`n - 1`从`k`。 这将我们的视角转向蛇形区域的起点`(n,2)`。 
3. 现在我们处于一个大小的网格内`n × (m - 1)`从该子网格的左下角开始按蛇形顺序遍历。 我们将剩余的步骤解释为该遍历中的索引。 
4. 计算列组索引为`col = k // n`。 每列的高度`n`对应于蛇形遍历中的一次垂直扫描。 
5. 计算该列内的行偏移量：`row = k % n`。 
6. 根据奇偶性确定方向`col`。 如果`col`是偶数，则从下到上遍历该列； 否则，从上到下。 转变`(row, col)`相应地转换为实际的网格坐标。 
7. 将列索引移动基于 2 的偏移量，因为之字形区域从第 2 列开始。 

### 为什么它有效

 关键的不变量是离开后`(n,1)`，路径总是占据长度的单列段`n`在切换列之前，方向随着每次列的变化而确定地交替。 这确保了剩余遍历中的每一步都可以唯一地映射到一对`(column segment index, offset within column)`，段索引的奇偶性完全决定了方向。 不需要超出这两个值的状态，因此重建是无损的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

n, m, k = map(int, input().split())

# Phase 1: vertical descent in first column
if k < n:
    print(k + 1, 1)
    sys.exit()

k -= n

# Now we are in the (n x (m-1)) snake region
col_block = k // n
row_in_block = k % n

col = 2 + col_block

if col_block % 2 == 0:
    row = n - row_in_block
else:
    row = 1 + row_in_block

print(row, col)
```第一个条件隔离垂直列遍历，确保我们不会将其与锯齿形逻辑混合。 

减去后`n`，其余索引的行为类似于对列的线性扫描，每个索引都准确贡献`n`步骤。 该部门`k // n`标识我们位于哪个列块，而`k % n`给出该列内的位置.

 奇偶校验控制方向。 偶数块向上移动，奇数块向下移动，匹配交替的蛇图案。 

最后一列移位`2`是必需的，因为第 1 列被排除在锯齿形区域之外。

 ## 边缘情况

 一种边缘情况恰好发生在边界处`k = n - 1`，其中位置是`(n,1)`。 该算法干净地处理这个问题，因为它包含所有值`k < n`在第一阶段，所以垂直下降的最后一步仍然计算为`(n,1)`无需进入蛇逻辑。 

另一个边缘情况是在转换之后立即发生，当`k = n`。 这对应于`(n,2)`，之字形区域的第一个单元格。 减去后`n`，我们得到`k = 0`，映射到`col_block = 0`和`row_in_block = 0`。 奇偶校验会触发向上移动，但由于我们位于块的第一个元素，因此计算出的行是`n`, 匹配`(n,2)`。 

最后一个微妙的情况是`m = 2`，其中之字形区域退化为单列。 该算法仍然有效，因为`col_block`所有剩余步骤都变为零，并且奇偶校验正确地在该单列内交替方向，而不需要额外的结构变化。
