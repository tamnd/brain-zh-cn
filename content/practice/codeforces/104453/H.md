 ## 解决方案
 ## 问题理解

 我们在平面上得到一组线，每条线都由以下形式的方程描述$y = A x + B$。 没有两条线是相同的，因此每对线要么平行，要么恰好相交一次。 

任务是选择与其他线相交最少的线，并输出最少的交点数。 

更具体地说，将每条线视为一条无段的无限直线轨道。 每当两条轨道不平行时，它们就会恰好在一点交叉。 对于每个轨道，我们计算它穿过的其他轨道的数量，并且我们希望所有轨道中的此类计数最小。 

输入大小可达$N = 10^5$。 对所有对进行直接成对比较将需要大约$10^{10}$检查，这远远超出了几秒钟的时间限制内可行的范围。 这立即排除了二次方法。 

一个关键的结构观察是相交仅取决于坡度。 两条线$A_1 x + B_1$和$A_2 x + B_2$相交当且仅当$A_1 \ne A_2$。 如果斜率相等，则直线平行且永不相交。 

所以对于任何有斜率的线$A$，它的交点数量恰好是$N - \text{count of lines with slope } A$。 

当许多线具有相同的斜率时，就会出现边缘情况。 例如，如果所有行都具有相同的$A$，则不会发生交集，答案为零。 如果斜率都不同，则每条线都与所有其他线相交，答案是$N - 1$。 忽略多重性的幼稚方法会错误地假设每对都相交。 

## 方法

 强力解决方案会检查每对线，并在斜率不同时增加计数器。 这是正确的，因为它直接模拟了交集的定义。 然而，它执行$N(N-1)/2$比较，当$N = 10^5$，这是不可行的。 

关键的简化来自于将几何与计数分开。 交点根本不取决于截距，只取决于斜率是否匹配。 我们不需要检查对，只需知道每个斜率出现了多少次。 

一旦我们按斜率对线进行分组，我们就可以在恒定时间内计算每组的相交计数：组外的所有线都与组内的每条线相交。 所以对于斜率值$A$，交集数为$N - f(A)$， 在哪里$f(A)$是它的频率。 

这将问题转化为整数的频率计数任务。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 |$O(N^2)$|$O(1)$| 太慢了|
 | 最优（频率计数）|$O(N)$|$O(N)$| 已接受 |

 ## 算法演练

 ### 最优策略

 1.读取所有直线并提取它们的斜率$A$。 拦截$B$无关紧要，因为它不影响两条线是否相交。 
2. 使用哈希图或字典计算每个斜率出现的次数。 此步骤将几何形状压缩为频率信息。 
3. 对于每个斜率组，计算该组中直线的交点数量，如下所示$N - f(A)$。 这是因为只有具有相同斜率的线才不会相交。 
4. 跟踪所有坡度组中这些值的最小值。 
5. 输出该最小值。 

### 为什么它有效

 每条线只能与具有相同斜率的线相交。 由于所有其他坡度都保证只有一个交点，因此坡度等级中的每条线都具有相同的交点数。 因此，最小化直线上的值相当于最小化斜率组上的值，并且表达式$N - f(A)$正确捕获所有非并行交互。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    freq = {}

    for _ in range(n):
        a, b = map(int, input().split())
        freq[a] = freq.get(a, 0) + 1

    ans = n
    for cnt in freq.values():
        ans = min(ans, n - cnt)

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案读取每一行并立即丢弃截距，因为它在交叉点中不起作用。 字典`freq`存储有多少条线共享每个斜率。 

处理输入后，我们迭代斜率组。 对于每组大小`cnt`，我们计算`n - cnt`，表示有多少条线具有不同的斜率，因此与该组相交。 所有组中的最小值给出了所需的答案。 

一个微妙的点是初始化`ans`作为`n`。 这是安全的，因为任何线的最大可能交叉点是$n - 1$，并且初始化更高或等于不影响正确性。

 ## 边缘情况

 当所有斜率相同时，频率图包含一个带有值的键$N$。 对于输入如：```
3
1 5
1 2
1 9
```该算法计算`n - cnt = 3 - 3 = 0`，正确反映没有发生相交。 

当所有斜率不同时，每个频率为 1。对于：```
3
1 0
2 0
3 0
```每组产量`3 - 1 = 2`，所以答案是 2。这符合每条线都与所有其他线相交的事实。 

当存在主导斜率组时，例如：```
6
1 0
1 1
1 2
2 0
3 0
4 0
```最大的组大小为 3，给出`6 - 3 = 3`。 该算法正确地识别出最密集斜坡组中的线最小化交叉点，因为它们避免了最平行的冲突。
