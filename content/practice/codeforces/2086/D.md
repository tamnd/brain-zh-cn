 ## 解决方案
 ## 问题理解

 我们被要求计算根据给定的字母计数可以构建多少个字符串，以便相同的字母始终占据相同奇偶校验的位置。 这意味着如果一个字母出现多次，则其所有出现都必须在偶数索引或奇数索引中（使用基于 1 的索引）。 每个测试用例给出一个由 26 个整数组成的数组，表示每个小写拉丁字母在字符串中必须出现的确切次数。 字符串总长度是所有这些计数的总和。 目标是确定满足奇偶校验条件的不同字符串的数量，以 998244353 为模。 

第一个观察结果是，计数总和（即字符串长度）可能非常大，在所有测试用例中最多可达 500,000。 这立即排除了任何生成所有排列的暴力方法。 如果简单地使用阶乘乘法来计算没有奇偶校验约束的不同排列，其成本也会很高。 另一个微妙的点是，字母仅重复一次的字符串很容易满足条件，但字母重复次数大于 1 的奇数次并不总是适合单个奇偶校验，除非我们仔细分配它们。 例如，如果字符串总长度为奇数，并且一个字母出现了 3 次，我们需要确保它完全适合奇数或偶数位置，这可能会也可能不会，具体取决于其他字母的排列。 忽略奇偶校验的幼稚实现将默默地过度计数或失败。 

边缘情况包括某些字母出现超过字符串长度一半的字符串。 例如，如果长度为 4 的字符串需要出现 3 个“a”，则我们不能将所有三个“a”放在相同奇偶校验的位置（我们只有两个偶数位置和两个奇数位置），因此答案为零。 另一种情况是所有字母都只出现一次。 那么任何排列都是有效的，因为奇偶校验条件自动满足，并且答案是字符串长度的阶乘。 

## 方法

 暴力方法枚举字母多集的所有排列并检查每个排列的奇偶校验条件。 这是可行的，因为奇偶校验约束很容易签入字符串。 然而，500,000 的阶乘是一个天文数字，使得这种方法不可行。 甚至存储所有排列或显式计算它们也是不可能的。 复杂度将超过 O(n!) 并且无法适应内存或时间限制。 

关键的见解来自奇偶校验约束本身。 相同奇偶校验的位置是独立的：偶数位置的字母可以与奇数位置的字母分开选择。 设字符串长度为n，n_even和n_odd分别代表偶数和奇数位置的个数。 每个具有计数 c_i 的字母必须完全放置在偶数或奇数位置。 这相当于将字母多重集划分为两组，使得它们的总计数匹配 n_even 和 n_odd。 一旦分区，每个奇偶校验组内的字母可以自由排列。 计算将字母分配给奇偶校验组的方式的数量可以简化为类似于子集和的组合问题，并且可以使用多项系数来计算每个组内的排列。 

形式上，对于每个测试用例，我们需要计算将字母划分为两个集合的方法数，总和为 n_even 和 n_odd，然后乘以每个奇偶校验内计数的阶乘。 对和进行动态规划是有效的，因为总长度高达 500,000。 DP 中的每个状态代表将前 k 个字母分配到偶数位置的方法数，总和为特定总数。 构建 DP 表后，我们将 DP 计数乘以多项系数以获得不同字符串的数量。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n!) | O(n!) | 太慢了 |
 | 最佳 | O(n * L) | O(n) | 已接受 |

 这里 n 是字符串总长度，L = 26 是字母数。 因为 L 很小，所以 DP 求和是有效的。 

## 算法演练

 1. 通过对所有计数求和来计算总字符串长度 n。 计算 n_even = n // 2 和 n_odd = n - n_even，表示偶数和奇数位置的数量。 
2. 检查是否有字母数超过 n_even 或 n_odd。 如果任何字母 c_i > max(n_even, n_odd)，则返回 0，因为该字母不能完全适合单个奇偶校验的位置。 
3. 使用动态规划来计算将字母分配到偶数位置的方式的数量。 使用 dp[0] = 1 初始化大小为 n_even + 1 的 DP 数组。迭代每个字母计数。 对于每个现有的总和 s，更新 dp[s + c_i] += dp[s]。 这会跟踪可以填充偶数位置的所有可能的字母计数总和。 处理完所有字母后，dp[n_even] 给出偶数和奇数位置的有效分区数。 
4. 预先计算以 998244353 为模至 n 的阶乘和逆阶乘，以有效地处理多项系数。 
5. 对于每个有效分区，分别计算偶数和奇数位置的多项式系数。 将奇偶校验组中总字母的阶乘乘以单个字母计数阶乘的模逆。 对 998244353 求模的乘积给出了该分区的排列数。 
6. 将DP计数乘以偶数组和奇数组的多项式系数，得到有效字符串总数模998244353。 

### 为什么它有效

 关键属性是字母的所有出现都必须占据相同奇偶校验的位置。 通过将问题简化为偶数和奇数位置之间的字母划分，我们确保满足奇偶校验条件。 动态编程正确地对所有此类分区进行计数，并且乘以多项系数对每个奇偶校验组内的排列进行计数，而不会过度计数。 无法计算无效字符串，因为任何 DP 状态都表示将字母有效分配到偶数位置，并自动修复奇数位置。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def prepare_factorials(n):
    fac = [1] * (n + 1)
    invfac = [1] * (n + 1)
    for i in range(1, n + 1):
        fac[i] = fac[i - 1] * i % MOD
    invfac[n] = modinv(fac[n])
    for i in range(n - 1, -1, -1):
        invfac[i] = invfac[i + 1] * (i + 1) % MOD
    return fac, invfac

def solve_case(c):
    n = sum(c)
    n_even = n // 2
    n_odd = n - n_even
    if any(ci > max(n_even, n_odd) for ci in c):
        return 0

    dp = [0] * (n_even + 1)
    dp[0] = 1
    for ci in c:
        if ci == 0:
            continue
        for s in range(n_even, ci - 1, -1):
            dp[s] = (dp[s] + dp[s - ci]) % MOD
    ways_partition = dp[n_even]

    fac, invfac = prepare_factorials(n)
    perm_even = fac[n_even]
    perm_odd = fac[n_odd]
    for ci in c:
        if ci > 0:
            perm_even = perm_even * invfac[min(ci, n_even)] % MOD
            perm_odd = perm_odd * invfac[max(0, ci - n_even)] % MOD

    return ways_partition * perm_even % MOD * perm_odd % MOD

def main():
    t = int(input())
    for _ in range(t):
        c = list(map(int, input().split()))
        print(solve_case(c))

if __name__ == "__main__":
    main()
```该代码首先准备阶乘和逆阶乘，以有效计算多项系数。 DP 步骤计算字母可以分配到偶数位置的方式数量。 乘法组合步骤确保偶数和奇数位置的字母排列分别计算，而不违反奇偶校验约束。 处理零计数的字母可以避免不必要的迭代。 始终使用模运算确保值不会超出限制。
