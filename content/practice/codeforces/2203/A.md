 ## 解决方案
 ## 问题理解

 单果树有`n`相同的盒子，每个盒子的重量`m`单位并能够支持多达`d`单位在顶部。 他希望将所有箱子堆成塔，同时尊重耐用性：没有哪个箱子可以支撑比`d`。 任务是确定使用所有盒子所需的最小塔数。 

输入由多个测试用例组成。 每个测试用例给出`n`,`m`， 和`d`。 每个测试用例的输出是一个整数：塔的最小数量。 每个塔必须至少包含一个盒子，并且必须放置所有盒子。 

因为最大`n`,`m`， 和`d`50个，并且最多可以有10,000个测试用例，任何对每个测试用例执行简单算术计算的解决方案都是可行的。 在检查重量约束的同时迭代堆叠箱子的简单模拟可能有效，但没有必要。 边缘情况包括以下情况`m > d`，使得不可能将两个盒子放在一起，并且情况`d`相对于`m`，允许所有盒子位于一个塔中。 例如，如果`n = 5`,`m = 3`,`d = 2`，无法堆叠，因此每个盒子形成自己的塔，即 5 个塔。 如果不检查每个箱子的重量限制，粗心的方法会错误地尝试堆叠箱子并少算塔的数量。 

## 方法

 蛮力方法是模拟堆叠：从一个空塔开始，添加盒子，直到下一个盒子违反耐久性约束，然后启动一个新塔。 重复此操作，直到放置完所有盒子。 这是可行的，因为它直接强制执行权重条件，但需要循环`n`每个测试用例的框。 和`n`最多 50 个并且`t`最多 10,000 个，这是可以管理的，但有点过分了。 

最佳方法观察到，在一座塔中`k`盒子，底部的盒子支撑`(k-1) * m`重量。 为了避免破裂，`(k-1) * m <= d`。 解决`k`给出`k <= d // m + 1`。 塔的最小数量就是塔的上限`n`除以每座塔的最大可能高度：`ceil(n / ((d // m) + 1))`。 这将问题简化为每个测试用例的简单算术计算。 

观察依赖于盒子的均匀性。 由于每个盒子都有相同的重量和耐用性，因此我们只需要找到最高的安全塔即可。 然后将所有盒子分配到这个高度的塔中，以保证塔的数量最少。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | ---| ---| ---| ---|
 | 蛮力 | O(n * t) | O(1) | O(1) | 可以接受但没有必要 |
 | 最佳 | O(t) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.读取测试用例数量`t`。 
2. 对于每个测试用例，请阅读`n`,`m`， 和`d`。 
3. 计算在不破坏盒子的情况下单个塔可以达到的最大高度：`max_height = d // m + 1`。 这来自解决`(k-1) * m <= d`为了`k`。 
4. 计算所需塔的最小数量：`ceil(n / max_height)`。 在整数运算中，这是`(n + max_height - 1) // max_height`。 
5. 打印每个测试用例的结果。 

为什么它有效：`max_height`确保没有盒子超过其耐用性。 将盒子总数除以`max_height`向上取整可以保证所有盒子都被使用，同时最小化塔。 盒子的均匀性使得这个不变量在整个塔分布中有效。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m, d = map(int, input().split())
    max_height = d // m + 1
    towers = (n + max_height - 1) // max_height
    print(towers)
```代码首先读取`t`，然后循环每个测试用例。`max_height`根据耐久性和重量计算，整数除法和四舍五入得出塔的数量。 公式`(n + max_height - 1) // max_height`避免浮点运算。 通过使用上限公式而不是尝试手动舍入可以避免相差一的错误。

 ## 边缘情况

 如果`d < m`, 最大高度`d // m + 1`变为 1。这确保每个盒子都放置在自己的塔中。 例如，与`n = 4`,`m = 5`,`d = 2`,`max_height = 1`，算法计算`(4 + 1 - 1) // 1 = 4`，正确输出4塔。 该算法自然地处理这种情况，无需任何特殊的外壳。 如果`d`是一个很大的倍数`m`， 说`d = 100`,`m = 2`,`n = 10`,`max_height = 51`， 然后`(10 + 51 - 1) // 51 = 1`，将所有盒子放在一个塔中，这是正确的。
