 ## 解决方案
 ## 问题理解

 我们从一个包含从 1 到 n 的数字（按升序排列）的数组开始。 然后我们选择两个位置 i 和 j 并交换这些位置的元素，从而在一个完美排序的序列中创建一个干扰。 

交换之后，我们对从 1 到 n 的每个值 x 运行标准二分搜索。 对于每个 x，我们检查二分查找是否仍然能够在这个稍微损坏的数组中成功找到 x。 交换 (i, j) 的“美感”是二分查找仍然成功的值 x 的数量。 

任务不是评估单个交换，而是考虑 i < j 的每对 (i, j)，计算其美感，然后计算有多少次交换产生每个可能的美感值。 

输入大小最多可达 500 万。 这立即排除了每个交换甚至每个元素的任何二次方。 输出是所有对的直方图，因此最终答案必须来自交换如何影响全局二分搜索的结构特征，而不是通过模拟。 

一个微妙的点是，这里的二分搜索不是检查排序结构中的成员资格，而是在可能未排序的数组上执行。 如果沿其搜索路径的所有比较都表现得“好像”数组已排序，则该算法对于某些 x 仍可能成功。 失败情况完全取决于交换的元素如何扭曲访问中点处的比较。 

一个天真的陷阱是假设只有 x 等于交换值才重要。 这是错误的，因为二分搜索路径依赖于中间索引的比较，因此交换的元素可能会误导不相关值的搜索。 

## 方法

 蛮力方法在概念上很简单。 对于每一对 (i, j)，我们在交换位置 i 和 j 后模拟对数组上从 1 到 n 的每个 x 进行二分搜索。 每次模拟的成本为 O(log n)，因此每对成本为 O(n log n)，并且有 O(n^2) 对。 当 n = 5e6 时，这将变得非常大。 

关键的观察是二分搜索遵循索引上的确定性决策树，与值无关。 对于每个 x，只要比较行为与给定区间内的 x 一致，算法就会访问固定的中点序列。 

在原始排序数组中，每个比较 a[m] < x 都按照索引顺序完美运行。 交换 i 和 j 后，只有位置 i 和 j 的比较会变得不一致。 因此，当且仅当其二分搜索路径在交换值导致相对于 x 的方向出错的时刻访问 i 或 j 时，值 x 才会失败。 

我们不模拟值，而是反转视角：修复一对 (i, j)，并询问哪些搜索路径受到影响。 二分搜索根据搜索区间是否包含特定递归深度的 i 或 j 来对值进行划分。 每个索引都参与二叉搜索递归树中一组明确定义的“决策间隔”。 

这导致了经典的减少：每个索引都参与隐式二叉搜索树的 O(log n) 段，并且交换 (i, j) 仅影响其路径与 O(log n) 决策节点之一相交的值，其中 i 和 j 与中位数进行比较。 

该结构允许我们通过索引上的隐式二叉搜索树中 i 和 j 的最低公共祖先对交换进行分类。 一旦编码完成，就可以使用有效 x 间隔的组合计数在范围内聚合贡献，根据实现产生 O(n) 或 O(n log n) 解决方案。

解决方案中使用的更直接的组合视图是，每对 (i, j) 贡献 x 值的缺陷范围，其二分搜索路径以特定方式跨越 i 和 j 之间的段，并且可以通过扫描从二分搜索递归边界导出的结构阈值来对这些范围进行计数。 

该问题简化为计算有多少交换产生给定数量的不受影响的目标，其中不受影响的目标是那些搜索间隔从未“看到”由交换引起的反转的目标。

 ## 算法演练

 核心思想是将二分搜索重新解释为索引区间上的固定二叉树。 原始数组中的每个值 x 都对应于一个确定性搜索路径，该路径仅依赖于与索引的比较，而不依赖于值。 

1. 在索引 [1, n] 上构造隐式二叉搜索树，其中每个节点 m 将区间分割为 [l, m−1] 和 [m+1, r]。 每个 x 都有一条从根开始的唯一路径，该路径是通过与 m 值的比较确定的。 
2. 观察交换位置 i 和 j 仅改变搜索间隔包含 i 或 j 的节点处的比较。 在这些访问的中点之外，所有比较都与排序后的情况相同，因此会自动保留正确性。 
3. 对于固定对 (i, j)，确定 x 的搜索何时受到影响。 当 x 的搜索路径访问中点 m 时，就会发生这种情况，从而由于 i 和 j 相对于预期顺序交换而导致子树决策反转。 
4. 关键的观察是，交换的效果仅取决于二叉搜索树分解中 i 和 j 的相对位置。 树结构将索引划分为与递归深度相对应的不相交区间。 
5. 对于每个递归深度，区间边界定义了连续的索引段。 当且仅当 x 位于其路径与在某个递归级别上分隔 i 和 j 的段相交的区域时，交换才会影响 x。 
6. 对于每对 (i, j)，通过计算二分搜索分解将它们分开的层数来预先计算受影响的 x 值的数量。 那么美丽就是 n 减去这个受影响的计数。 
7. 不要迭代对，而是反转计数：对于每个可能的“损坏级别”d，通过计算 i 和 j 在每个深度位于相同或不同子树中的频率来计算有多少对 (i, j) 精确地产生 d 受影响的值。 
8.使用二分搜索分割引起的间隔大小上的前缀和来聚合所有级别的贡献。 

### 为什么它有效

 二分搜索将索引确定性地划分为分层区间。 交换只会干扰沿与该层次结构中交换元素之间的边界相交的路径进行的比较。 因为每个索引恰好参与 O(log n) 个分层段，所以一对 (i, j) 贡献的总扰动仅取决于它们在这些段中的相对位置，而不是单独取决于 x。 这使得贡献可以纯粹从区间结构中计数，确保每个 x 都被正确分类为一致可达或中断。
