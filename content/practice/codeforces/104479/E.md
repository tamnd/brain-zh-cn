 ## 解决方案
 ## 问题理解

 我们得到一个整数序列，并且允许我们通过删除它们并将它们的乘积插回到序列中来重复合并任意两个选定的元素。 每次合并都会将序列的长度减少一，但也会更改替换值的素因子结构。 

如果一个数在因式分解后至少包含两个不同的质因数，则该数被称为有效数。 对于每个查询，我们采用一个连续的子序列，并希望知道所需的最小合并次数，以便该子序列中的每个剩余元素都变得有效。 如果不可能，则答案为-1。 

关键点是合并不会改变素数因子的总多重集，它只是将它们重新分配到更少的数字上。 每个最终元素对应一组原始元素，其素性结构是该组内所有素因子的并集。 

约束意味着数组大小和查询数量都可以达到 200,000，而值最多为 10^7。 任何针对每个查询重新计算因式分解或从头开始重新计算答案的解决方案都将失败。 即使每个查询的 O(n√V) 也太大了。 该结构建议预处理因式分解，然后使用支持快速范围聚合的查询技术。 

当子序列仅包含具有单个重复素因数的数字时，就会出现微妙的失败情况。 例如，[2,4,8]。 每个元素都只有素数2，所以无论我们如何合并，每个乘积仍然只有一个素数因子。 正确的答案是 -1，但是天真的贪婪合并可能会错误地认为重复乘法有帮助。 

另一个重要的边缘情况是子序列仅包含 1 时。 由于 1 没有质因数，因此合并它们永远不会创建有效的数字。 像 [1, 1, 1] 这样的序列也必须返回 -1。 

## 方法

 直接模拟将尝试重复选择两个元素，合并它们，并检查所有元素是否都有效。 这在原则上是正确的，因为每个操作都是精确定义的。 然而，每个查询可能需要最多线性甚至二次模拟合并，并且对于最多 200,000 个查询，这变得不可行。 

结构转变来自于观察到最终配置仅取决于元素的分组方式。 每个元素都属于一个组，并且每个组都成为一个等于其成员的乘积的数字。 当且仅当其元素之间的素数因子的并集包含至少两个不同的素数时，群才是有效的。 

所以问题就变成了：给定一个元素的多重集，将其划分为最大数量的有效组，因为每个组对应一个最终元素，最小化合并相当于最大化最终组。 

所有已经包含至少两个不同素数的元素不需要合并并立即形成有效的单例组。 其余元素是唯一需要结构的元素。 每个这样的元素恰好贡献一个素因数（或者在 1 的情况下无贡献）。 必须对它们进行分组，以便每个组总体上至少包含两个不同的素数。 

这将问题简化为针对素数类型频率计数的每个查询组合问题。 我们需要知道有多少个元素具有每个素数因子，以及存在多少个元素，以及分布是否允许不同素数之间的完全配对。 

强力方法将重新计算每个查询的这些频率，但每个范围的因式分解和计数会太慢。 相反，我们将每个元素预处理为一个小状态，并使用 Mo 算法等技术回答范围查询，该算法支持元素的动态插入和删除，同时保持频率统计。

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 每个查询的暴力破解 | O(n√V) 或更差 | O(n) | 太慢了 |
 | Mo 的频率维护算法 | O((n + q) √n) | O((n + q) √n) | O(n) | 已接受 |

 ## 算法演练

 ### 关键预处理步骤

 我们首先对每个数字进行因式分解，并将其简化为三种形式之一：有效（至少两个不同的素数）、单素数（恰好一个不同的素数）或中性（1）。 对于单素数值，我们只存储它们的素数标识符，因为这对于分组来说才是最重要的。 

### 查询处理结构

 我们在数组上使用滑动窗口，以便在查询之间移动时可以有效地维护当前段的统计信息。 

### 1.预先计算最小质因数并对每个元素进行分类

 我们构建一个筛子来分解最多 10^7 的数字，并为每个数组元素确定其不同的素数集大小。 这允许在查询更新期间进行恒定时间分类。 

### 2. 定义段的状态变量

 对于当前段，我们维护已有效元素的数量、1 的数量以及单素数元素的素数频率图。 我们还保持这些素数中的最大频率。 

这个最大频率至关重要，因为它决定了单素数元素是否可以在不同素数之间配对，而不会留下无法匹配的余数。 

### 3.使用Mo的算法维护段

 我们按 Mo 顺序对查询进行排序并移动滑动窗口。 当元素进入或离开窗口时，我们更新其对相关计数器的贡献并调整频率统计数据。 

### 4. 计算单素数元素的可行性

 设S为当前范围内单素数元素的总数，mx为其中任意素数的最大频率。 当且仅当 mx ≤ S/2 时，我们才能将这些元素完全划分为有效组。 否则，一个素数占主导地位太大，并迫使产生不可配对的余数。 

如果可行，由单素数元素形成的群的最大数量为 S - mx。 

### 5. 处理那些

 等于 1 的元素不贡献素数，并且不能单独形成有效的群。 它们只能插入到已经有效的组或已经具有至少两个不同素数的组中。 如果不存在这样的群体，而存在这样的群体，那么答案是不可能的。 

### 6. 合并所有贡献

 每个已经有效的元素贡献一组。 来自单素数元素的每个可行组贡献另一个组。 答案是总元素减去形成的总组。 

### 为什么它有效

 每个最终元素完全对应于一个分区组。 合并操作仅更改分组，而不更改基础的质因数多重集。 当一个群包含至少两个不同的素数时，它才是有效的。 这降低了对集合分区的约束的有效性。 频率条件 mx ≤ S/2 确保没有素数垄断超过一半的单素数元素，这正是跨不同素数配对元素且没有剩余单色障碍的条件。 一旦这些组被固定，所有剩余的结构都将被强制，并且任何替代分组都不能增加有效组的数量。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MAXV = 10**7

spf = list(range(MAXV + 1))
for i in range(2, int(MAXV ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, MAXV + 1, step):
            if spf[j] == j:
                spf[j] = i

def factor_type(x):
    if x == 1:
        return (0, 0)
    primes = set()
    while x > 1:
        p = spf[x]
        primes.add(p)
        while x % p == 0:
            x //= p
        if len(primes) > 2:
            break
    if len(primes) >= 2:
        return (2, 0)
    return (1, next(iter(primes)) if primes else 0)

n, q = map(int, input().split())
a = list(map(int, input().split()))

tp = [None] * n
for i, x in enumerate(a):
    tp[i] = factor_type(x)

import math

B = int(n ** 0.5) + 1

queries = []
for idx in range(q):
    l, r = map(int, input().split())
    l -= 1
    r -= 1
    queries.append((l, r, idx))

queries.sort(key=lambda x: (x[0] // B, x[1] if (x[0] // B) % 2 == 0 else -x[1]))

cnt_prime = {}
freq = {}
curL, curR = 0, -1

bad = 0
ones = 0
good = 0

def add(i):
    global bad, ones, good
    t, v = tp[i]
    if t == 2:
        good += 1
    elif t == 0:
        ones += 1
    else:
        bad += 1
        old = cnt_prime.get(v, 0)
        new = old + 1
        cnt_prime[v] = new

        freq[old] = freq.get(old, 0) - 1
        if freq[old] == 0:
            freq.pop(old, None)
        freq[new] = freq.get(new, 0) + 1

def remove(i):
    global bad, ones, good
    t, v = tp[i]
    if t == 2:
        good -= 1
    elif t == 0:
        ones -= 1
    else:
        bad -= 1
        old = cnt_prime[v]
        new = old - 1

        cnt_prime[v] = new

        freq[old] -= 1
        if freq[old] == 0:
            freq.pop(old)
        if new > 0:
            freq[new] = freq.get(new, 0) + 1
        else:
            cnt_prime.pop(v)

def current_max_freq():
    if not freq:
        return 0
    return max(freq.keys())

res = [0] * q

for l, r, idx in queries:
    while curL > l:
        curL -= 1
        add(curL)
    while curR < r:
        curR += 1
        add(curR)
    while curL < l:
        remove(curL)
        curL += 1
    while curR > r:
        remove(curR)
        curR -= 1

    S = bad
    mx = current_max_freq()

    groups_bad = 0
    if S > 0:
        if mx > S // 2:
            res[idx] = -1
            continue
        groups_bad = S - mx

    if S == 0:
        if ones > 0:
            res[idx] = -1
            continue
        groups_bad = 0

    total_groups = good + groups_bad
    res[idx] = (r - l + 1) - total_groups

print("\n".join(map(str, res)))
```该实现围绕维护单素数的素数类别的动态频率图进行。 关键的微妙之处在于跟踪每个质数的计数以及这些计数的分布，因为可行性条件取决于每个时刻的最大频率。 

因式分解步骤确保每个数字仅提供恒定信息，这使得 Mo 的算法可行。 

## 工作示例

 考虑一小部分`[2, 3, 4, 6]`。 

分类后，`2`和`3`是单素数，`4`是单素数 (2)，并且`6`已经很好了。 该段已包含一个有效元素（`6`）。 对于单素数元素，我们有计数`{2:2, 3:1}`因此 S = 3 且 mx = 2。由于 2 ≤ 3/2 为假，因此不可能配对，并且答案变为 -1 以保证完全有效。 

现在考虑`[2, 3, 5, 1, 6]`。 

这里`6`已经很好了，`1`是中性的，并且`{2,3,5}`是单素数。 S = 3，mx = 1，因此分组是可行的，我们可以从单素数元素组成 1 个组。 这些可以放入已经有效的组中。 最终答案变成总元素减去有效组。 

| 步骤| 坏分子| 素数计数| MX | S | 团体坏 |
 | --- | --- | --- | --- | --- | --- |
 | 初始| 3 | {2:1,3:1,5:1} | 1 | 3 | 2 |
 | 决赛| - | - | - | - | 2 |

 这表明平衡分布允许完全配对并最大化有效的群体形成。

 ## 边缘情况

 仅包含 1 的子序列证明了假设合并总是会提高素性的失败。 每次合并仍会产生一个，因此不会出现有效元素，并且正确的输出始终为 -1。 

由单个素数支配的子序列，例如`[2, 4, 8, 16]`，说明了为什么最大频率的条件是必要的。 尽管可以进行多次合并，但每个结果仍然是 2 的幂，因此没有任何分组可以满足两个不同素数的要求，从而强制为 -1。 

平衡子序列如`[2, 3, 5, 7]`显示了相反的极端，其中所有单素数元素可以在不同素数之间完美配对，从而最大化有效组的数量并最小化所需操作的数量。
