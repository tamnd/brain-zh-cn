 ## 解决方案
 ## 问题理解

 我们正在处理一个隐藏的整数$n$它在开始时是固定的，位于 1 到 10,000 之间。 获取有关它的信息的唯一方法是提出“是”形式的整除问题$n$可除以$x$？“， 在哪里$x$是 1 到 10,000 之间的任意整数。 每个查询都会返回一个简单的是或否答案，经过足够的推理后，我们必须输出的准确值$n$。 

这不是一个标准输入问题，而是一个交互式问题。 该程序是根据它在与外部法官对话期间的行为来判断的，因此正确性取决于询问信息丰富的查询并最终承诺准确的值。 

约束条件$n \le 10^4$是关键的结构限制。 这意味着$n$当以重数计算时，最多有大约四个质因数，并且每个质因数最多为 100。这立即排除了对随机测试或大型预计算等繁重技术的需要。 在 1500 次查询限制下，任何能在大约几百次查询中工作的内容都是安全的。 

一个幼稚但诱人的错误是尝试猜测$n$直接或通过查询是否扫描所有候选者$n$可以被候选值整除。 这种方法失败了，因为整除性检查不能唯一地区分倍数。 例如，如果$n = 36$，那么查询 6, 12, 18, 24, 30 都会以不同的方式返回 yes，但在没有结构化分解的情况下不会唯一地隔离 36。 

真正的困难在于整除性是质因数分解的投影$n$，我们需要重建完整的因式分解而不是数字本身。 

## 方法

 蛮力策略会尝试每一个候选人$x$从 1 到 10,000 并尝试确定是否匹配$n$使用整除性查询。 然而，仅靠整除性不足以以这种方式唯一地标识一个数字。 即使我们试图通过测试是否淘汰候选人$n$可以被精心选择的值整除，我们仍然需要区分共享许多约数的数字。 在最坏的情况下，这会退化为一个大型候选集，无法在查询预算下可靠地解决。 

关键的结构观察是，每个 10,000 以内的整数完全由其素因子分解决定，并且所有素因子最多为 100。而不是试图识别$n$直接地，我们可以独立地重建每个素数的指数。 

对于固定素数$p$，我们可以确定有多少次$p$划分$n$通过反复询问是否$n$可以整除$p, p^2, p^3, \dots$。 一旦答案变为“否”，我们就知道了确切的指数$p$在因式分解中。 对 100 以内的所有素数重复此操作完全确定$n$。 

这将问题从全局识别转化为对素数的独立局部测量，这正是它符合查询预算的原因。

 ## 算法演练

 ### 步骤 1：生成 100 以内的所有素数

 我们首先使用简单的筛子或预先计算的常量列表列出 100 以内的所有素数。 这已经足够了，因为任何 10,000 以内的整数如果本身不是素数，则不能有大于 100 的素因数，并且任何这样的素数都会被直接检测到。 

### 步骤 2：对于每个素数，确定其指数$n$对于每个素数$p$，我们首先询问是否$n$可以整除$p$。 如果答案是“否”，那么$p$对因式分解没有贡献，我们继续。 

如果答案是“是”，我们尝试更高的幂：$p^2, p^3, p^4$，每次发出查询时。 当答案变成“否”时我们就停下来。 最后一次成功的幂给出了精确的指数$p$在$n$。 

每一步都有效，因为整除$p^k$直接对应于至少有$k$的副本$p$在因式分解中。 

### 第 3 步：重构数字

 一旦知道了所有指数，我们就可以重建$n$通过乘法$p^{e_p}$跨越所有素数。 由于范围很小，因此该产品可以安全地安装在范围内。 

### 第四步：输出答案

 最后，我们以所需的格式打印重建的值。 

### 为什么它有效

 该算法依赖于在任意点，对于每个素数的不变量$p$，我们正确判断了是否$p^k \mid n$对于所有测试的$k$。 由于整除性是单调的$k$，一旦查询返回“No”，所有更高的幂也无效。 这确保了我们准确地恢复每个指数，并且由于素因数分解是唯一的，因此重建的数字必须等于$n$。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

# Precompute primes up to 100
def sieve(n=100):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    primes = []
    for i in range(2, n + 1):
        if is_prime[i]:
            primes.append(i)
            for j in range(i * i, n + 1, i):
                is_prime[j] = False
    return primes

primes = sieve()

def ask(x):
    print("?", x)
    sys.stdout.flush()
    return input().strip()

def main():
    factors = {}

    for p in primes:
        if p > 10000:
            break

        # check first power
        if ask(p) == "No":
            continue

        exp = 1
        power = p

        # try higher powers
        while True:
            if power > 10000 // p:
                break
            power *= p
            if ask(power) == "Yes":
                exp += 1
            else:
                break

        factors[p] = exp

    # reconstruct n
    n = 1
    for p, e in factors.items():
        for _ in range(e):
            n *= p

    print("!", n)
    sys.stdout.flush()

if __name__ == "__main__":
    main()
```筛子构建最多 100 个候选素数集。`ask`函数包装交互并确保每次查询后刷新，这在交互问题中是强制性的。 

主循环独立地隔离每个素因子。 指数检测使用相同素数的重复平方，但要小心限制以避免超过 10,000。 这可以防止不必要的查询，同时确保正确性。 

重建步骤是简单的乘法，因为界限保证不会溢出超出 Python 的整数容量。

 ## 边缘情况

 对于$n = 1$，每个可整性查询都返回“No”。 该算法从不记录任何质因数，并将乘积重建为 1，这是正确的。 

对于像这样的素数$n = 97$，只有一个查询返回“Yes”，所有其他查询立即失败。 该算法正确分配指数 1 并重建数字，而无需尝试更高的幂。 

对于最大值，例如$n = 10000$，等于$2^4 \cdot 5^4$，两个素数都被测试到它们的完整指数链。 每个更高功率的查询都保持在范围内，因为我们在超过 10,000 之前仔细限制了乘法。
