 ## 解决方案
 ## 问题理解

 我们正在维护一片随着时间的推移而生长的森林。 最初有 n 个孤立的顶点。 类型 1 的每次更新都会连接两个先前断开连接的顶点，因此每个组件始终保持一棵树。 

在这个不断发展的森林之上，我们反复玩概率游戏查询。 对于给定的起始顶点 x，Alice 最多可以沿着边行走 m 步，在看到图表之后但在了解 Bob 的选择之前选择最佳行走方式。 Bob 独立地随机均匀地选择 k 个不同的顶点并将它们标记为特殊的。 如果任何特殊顶点位于爱丽丝在步行过程中访问的至少一个顶点上，则爱丽丝获胜。 由于如果 x 本身特殊，Alice 会立即获胜，因此访问集始终包含 x。 

任务是在每次查询后回答爱丽丝获胜的概率（假设最优玩法）。 

约束很大：最多 2·10^5 个顶点和 5·10^5 个查询，其中 m 高达 10^9。 这立即排除了任何模拟步行、每次查询探索邻域或从头开始重新计算树结构的方法。 预处理后，每个查询必须在大致对数或常数时间内得到答复，并且更新必须接近摊余常数。 

关键的困难在于，该图是动态的，但只能以森林的形式生长，并且概率取决于爱丽丝可以强迫自己以最佳行走方式访问多少个不同的顶点。 

如果假设爱丽丝的行走探索了一个围绕 x 半径为 m 的“球”，就会出现一个微妙的陷阱。 步行不是树遍历：它是可以重新访问节点的单个路径，因此它不能分支。 例如，在以 x 为中心且 m=2 的星中，Alice 无法访问 x 的所有邻居，只能访问一个邻居加上 x 再加上一步。 将其视为 BFS 层会高估可达覆盖范围并产生不正确的概率。 

另一个问题是假设随机性与局部结构相互作用。 概率仅取决于爱丽丝在她的行走中可以包含多少个不同的顶点，而不取决于它们的排列。 

## 方法

 如果我们忽略最佳游戏，简单的模拟将尝试从 x 枚举长度最多为 m 的所有路径，计算每个路径的已访问顶点的并集，并采取最佳路径。 即使在一棵树中，这也会呈指数爆炸，因为分支因子可能很大并且 m 可以是 10^9，这使得它立即不可行。 

我们可以通过观察 Alice 实际上试图最大化什么来简化问题。 对于固定的访问顶点集 S，Bob 的选择仅通过它是否与 S 相交来影响。如果 Bob 从 n 中均匀随机选择 k 个顶点，则获胜概率仅取决于 |S|：

 Alice 失败的概率是所有 k 个选定顶点位于 S 的补集内的概率，即 C(n−|S|, k) / C(n, k)。 

因此，最大化爱丽丝的获胜概率相当于最大化她可以包含在有效行走中的不同顶点的数量。 

现在，树中行走的结构很重要。 由于重新访问顶点没有帮助，因此任何最佳策略都是一条从 x 开始、长度最多为 m 的简单路径。 因此，爱丽丝从 x 中选择一条路径，并希望最大化她在一个方向上可以延伸的距离。 

这将问题简化为计算每个节点 x 到其连接组件中的任何节点的最大距离。 这正是 x 在其树中的偏心率。 然而，Alice 不一定能够使用全部偏心率，因为她的步数被限制为 m 步。 因此，不同访问顶点的数量变为 min(m+1, ecc(x)+1)。 

剩下的就是在动态生长的森林中保持偏心率。 每个查询都会在两个先前断开连接的组件之间添加一条边。 我们需要支持距离查询并在联合操作下有效地维护直径。

一个众所周知的树事实解锁了解决方案：在任何树中，节点的偏心率等于从该节点到树直径任一端点的最大距离。 因此，如果我们维护每个组件的直径端点，我们可以仅使用两个距离查询来计算 x 的偏心率。 

剩下的任务是在联合行动下的动态森林中保持距离。 由于边仅在组件之间添加，因此我们可以维护每个组件的根表示并存储带有边权重的父指针。 合并两个组件时，我们将一个根附加到另一个组件中的节点下并传播距离偏移。 这支持使用带权重的 DSU 式路径压缩在任意两个节点之间进行快速距离查询。

 ## 算法演练

 1. 维护一个不相交集结构，其中每个组件都是一棵具有选定根的树，每个节点存储其父节点以及到其父节点的距离。 当使用路径压缩跟随父指针时，累积距离给出了到组件根的距离。 这种结构允许在接近恒定的时间内查询同一组件中的节点之间的距离。 
2. 当添加类型 1 边 (u, v) 时，找到两个分量的根。 假设我们将第二个根 Rb 连接到第一个组件中的节点 u 下。 我们设置parent[Rb] = u并分配边缘权重，以便第二个组件内部的距离在附着后保持一致。 这在连接两棵树的同时保留了所有现有的内部距离。 
3. 对于每个组件，保持其直径端点 (a, b)。 当两个组件合并时，我们必须重新计算直径。 新直径是两个部件的旧直径中的最大值以及一个部件的任意端点与另一个部件的任意端点之间的距离。 由于每个组件仅贡献两个候选者，因此我们使用 DSU 距离函数评估四个交叉距离。 
4. 对于每个节点 x，其偏心率计算为 max(dist(x, a), dist(x, b))，其中 a 和 b 是其组件的直径端点。 
5. 对于查询 (x, m, k)，计算 Alice 可以访问的最大不同顶点数：s = min(m + 1, ecc(x) + 1)。 
6. 将其转换为概率。 Bob 从 n 中统一选择 k 个顶点。 仅当所有 k 个顶点都位于 S 之外时，Alice 才会失败。路径数量为 C(n − s, k)，因此获胜概率为 1 − C(n − s, k) / C(n, k)。 使用阶乘和模逆来计算模 998244353。 

### 为什么它有效

 关键的不变性是每个组件始终是一棵树，具有与存储的父指针一致的明确定义的距离度量。 加权 DSU 确保任何路径压缩操作都能保留精确的距离。 直径端点对于当前树始终有效，并且任何偏心率查询都会简化为比较到这些端点的距离，因为在树中距离 x 最远的节点必须是直径端点之一。 由于 Alice 的最优策略总是简化为最大化从 x 开始的单个简单路径的大小，并且树中的任何简单路径都受到偏心率的限制，因此计算出的 s 正是最优的。 概率公式仅取决于集合大小，因此一旦 s 正确，答案就是准确的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

MAXN = 200000 + 5

fact = [1] * MAXN
invfact = [1] * MAXN

for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN - 1] = pow(fact[MAXN - 1], MOD - 2, MOD)
for i in range(MAXN - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

parent = list(range(MAXN))
dist = [0] * MAXN  # distance to parent

def find(x):
    if parent[x] == x:
        return x
    p = parent[x]
    root = find(p)
    dist[x] += dist[p]
    parent[x] = root
    return root

def get_dist(x, y):
    find(x)
    find(y)
    return dist[x] - dist[y]

diam_a = list(range(MAXN))
diam_b = list(range(MAXN))

def union(u, v):
    ru = find(u)
    rv = find(v)
    if ru == rv:
        return

    du_a = diam_a[ru]
    du_b = diam_b[ru]
    dv_a = diam_a[rv]
    dv_b = diam_b[rv]

    best_a = du_a
    best_b = du_b
    best_d = 0

    candidates = [(du_a, dv_a), (du_a, dv_b), (du_b, dv_a), (du_b, dv_b)]
    for x, y in candidates:
        d = abs(get_dist(x, y))
        if d > best_d:
            best_d = d
            best_a, best_b = x, y

    parent[rv] = ru
    dist[rv] = 1

    da = abs(get_dist(u, best_a))
    db = abs(get_dist(u, best_b))

    if da > db:
        diam_a[ru], diam_b[ru] = u, best_a
    else:
        diam_a[ru], diam_b[ru] = u, best_b

q = int(input())
n = 200000

last = 0

for _ in range(q):
    tmp = list(map(int, input().split()))
    t = tmp[0]

    if t == 1:
        u = tmp[1] ^ last
        v = tmp[2] ^ last
        union(u, v)

    else:
        x = tmp[1] ^ last
        m = tmp[2] ^ last
        k = tmp[3] ^ last

        rx = find(x)
        a = diam_a[rx]
        b = diam_b[rx]

        ecc = max(abs(get_dist(x, a)), abs(get_dist(x, b)))
        s = min(m + 1, ecc + 1)

        ans = (1 - C(n - s, k) * pow(C(n, k), MOD - 2, MOD)) % MOD
        if ans < 0:
            ans += MOD

        print(ans)
        last = ans
```DSU 结构存储每棵树的有根表示。 这`dist`数组累积边权重，以便在路径压缩后每个节点与其代表的距离保持正确。 这一点至关重要，因为任意节点之间的距离查询取决于一致的累积。 

直径维护利用了这样一个事实：任何新直径都必须来自现有直径的端点的组合，因此我们在合并组件时仅测试四个候选对。 

最终的概率计算通过使用预先计算的阶乘和模逆来仔细处理模除法。

 ## 边缘情况

 临界边缘情况是 m 大于组件中的任何路径。 在第 1-2-3-4 行中，使用非常大的 m 查询 x = 2 会使 Alice 有效地覆盖整个偏心率受限区域，并且解决方案必须使用 ecc(x) 而不是 m 进行限制。 

另一个边缘情况是新连接的节点，其中直径端点发生变化。 如果我们错误地重用旧端点而不通过交叉对重新计算，我们可能会错过跨越两个组件的较长直径。 并集步骤显式检查所有端点组合，即使两个组件都是单节点或高度不平衡的树，也能确保正确性。
