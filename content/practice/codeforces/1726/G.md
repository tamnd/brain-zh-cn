 ## 解决方案
 ## 问题理解

 我们被赋予了一组$n$人，每个人都从幸福值开始$a_i$和一个二元人格标志$b_i$。 我们选择一个排列，它代表他们说话的顺序。 

当一个人说话时，他们会查看其他人当前的幸福值，并计算有多少人严格意义上不如他们幸福，如果$b_i = 0$，或者严格来说比他们更快乐，如果$b_i = 1$。 然后这个计数就会被添加到他们自己的幸福中。 此时只有说话者的值发生变化。 

该过程是连续的，因此较早的说话者可以在以后的比较发生之前更改其值，这使得系统动态而不是静态。 毕竟$n$人们说过，我们希望所有最终的幸福值都是平等的。 任务是计算有多少说话者的排列达到了这个条件。 

关键的困难在于每次更新都取决于不断变化的多重值集，而不仅仅是初始数组。 独立对待每个人的天真解释是失败的，因为一旦某人的幸福感增加，他们就会影响以后的所有比较。 

约束条件$n \le 2 \cdot 10^5$立即排除任何对排列的模拟或任何根据排序动态跟踪成对相互作用的解决方案。 甚至$O(n^2)$已经太大了，因此解决方案必须将问题简化为对结构化配置进行排序和计数，可能在贪婪不变量之上使用组合数学。 

当许多人分享相同的最初幸福时，就会出现微妙的边缘情况。 在这种情况下，严格不等式的表现会有所不同，因为关系永远不会导致增量，但在更新后，相等的值可以分开。 如果假设顺序仅取决于排序依据，则会出现第二种故障模式$a_i$。 与的互动$b_i$打破了这种天真的单调假设。 

## 方法

 暴力方法会尝试人员的每种排列，模拟该过程，并检查最终值是否匹配。 这正确地模拟了规则，但成本$O(n! \cdot n)$，因为每个排列都需要完整模拟$n$步骤，并且每个步骤都会扫描所有其他步骤。 即使对于$n = 10$。 

核心困难在于每个人的增量取决于动态变化的值排序。 然而，一个关键的结构观察简化了系统：最终状态迫使所有值收敛到一个数字$T$。 这意味着每个人都准确地积累了$T - a_i$，并且这个总增量必须通过与其他轮次的比较来充分解释。 

关键的简化来自于认识到重要的不是每次比较的确切时间，而是每对如何$(i, j)$有助于所有有效排列的增量。 一旦我们确定了有效的最终配置，每个有效的排序都必须遵循一致的支配结构：初始值较小的人无法以打破最终平等约束的方式“超越”初始值较大的人。 

这将动态过程分解为静态排序问题：我们排序$a_i$，并且在相等范围内$a_i$, 个性$b_i$确定在任何有效的排序中，一个人是否必须相对于具有相同值的其他人出现得早一些或晚一些。 一旦强制执行此约束，有效排列的计数就减少为与这些强制相对顺序一致的交错计数，这成为组上的组合乘积。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力排列 |$O(n! \cdot n)$|$O(n)$| 太慢了|
 | 排序+约束排序+组合|$O(n \log n)$|$O(n)$| 已接受 |

 ## 算法演练

 ### 第 1 步：按初始幸福感排序

 我们首先对所有人进行排序$a_i$。 这是合理的，因为任何有效的流程都必须保持一个人可以获得的收益与其相对基线值之间的全局兼容性。 一旦我们修复了这个顺序，所有的结构约束就变成局部的。 

### 步骤 2：对相等的值进行分组

 我们将排序后的数组分成连续的块，其中所有$a_i$是平等的。 在这样的块内，与其他块的比较是严格确定的，因此只有内部排序很重要。 

### 步骤 3：将个性解释为排序约束

 在每个等于$a$块，行为$b_i$确定有效排列的方向性。 人与$b_i = 1$必须以任何有效的顺序放置在其块的前面，因为它们的增量依赖于在系统演化中看到“更大”的值。 反过来，$b_i = 0$必须稍后出现，因为它们的贡献取决于对“较小”值的计数，只有当本地排序一致时，“较小”值才会正确稳定。 

这将每个块变成具有固定偏序的约束排列问题：所有$b=1$元素先于所有元素$b=0$元素。 

### 步骤 4：计算每个块的有效排列

 在一个大小的块内$k$，假设有$x$元素与$b=1$和$k-x$元素与$b=0$。 内部的有效安排完全是通过选择位置来确定的。$x$块中的元素，同时保留它们的相对分组约束，这给出了组合因子$\binom{k}{x}$。 

### 步骤 5：跨块合并

 区块是独立的，因为不同区块之间严格不平等$a$-levels 防止交错约束发生冲突。 因此，最终的答案是每个区块贡献的乘积，乘以模$998244353$。 

### 为什么它有效

 不变的是，一旦我们修复了排序依据-$a_i$在结构中，任何有效的过程都必须遵循一致的影响方向：没有任何操作可以逆转严格比较所施加的相对可行性。 这迫使所有有效排列分解为等值组内的独立选择，而跨组排序是固定的。 由于每个成对相互作用在该结构内只被考虑一次，因此该形式之外的任何排列都不能保持最终值的相等。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    people = sorted(zip(a, b))
    
    # precompute factorials
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    inv_fact = [1] * (n + 1)
    inv_fact[n] = modinv(fact[n])
    for i in range(n, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD

    def C(n, r):
        if r < 0 or r > n:
            return 0
        return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

    ans = 1
    i = 0
    while i < n:
        j = i
        ones = 0
        while j < n and people[j][0] == people[i][0]:
            ones += people[j][1]
            j += 1

        k = j - i
        ans = ans * C(k, ones) % MOD
        i = j

    print(ans)

if __name__ == "__main__":
    solve()
```该解决方案预先计算阶乘和模逆，以有效地评估二项式系数。 排序后$a_i$，它独立地处理每个等值块。 对于每个区块，它会计算有多少参与者$b_i = 1$，然后将答案乘以保留所需结构的有效内部排列的数量。 

关键的实现细节是所有组合计算都是模数完成的$998244353$，阶乘预计算可确保排序后解保持线性。

 ## 边缘情况

 当所有$a_i$相等，整个问题就会分解为一个组合块。 在这种情况下，答案仅取决于有多少$b=1$和$b=0$值存在，并且该算法简化为单个二项式系数，分组步骤直接处理该系数。 

当所有$b_i$是相同的，要么全为 1，要么全为 0，每个块仅贡献一种配置。 该算法正确地为每个块返回 1，这表明内部重新排列不会改变有效性。 

当价值严格增加时，每个人都会形成一个单例块。 每个块贡献 1，因此答案是 1。这与在不断增加的约束下排序完全严格的事实相匹配。
