 ## 解决方案
 ## 问题理解

 给定一个非负整数数组，我们需要通过执行最少数量的操作来使它“好”。 如果对于长度至少为 2 的每个子数组，偶数索引处的元素之和（从原始数组中的 1 开始计数）至少与奇数索引处的元素之和一样大，则该数组是好的。 单个操作包括将任何元素减一，只要它保持非负数即可。 

输入由多个测试用例组成，每个测试用例都有一个数组，最多可达$2 \cdot 10^5$元素。 所有测试用例的元素总数受下式限制$2 \cdot 10^5$，每个元素可以大到$10^9$。 由于 2 秒的时间限制，这排除了任何检查所有子数组的暴力解决方案，因为一个子数组的数量$n$-元素数组是$\frac{n(n+1)}{2}$，可以达到$2 \cdot 10^{10}$在最坏的情况下。 我们需要一个线性或线性算数的解$n$每个测试用例。 

当子数组违反条件时，就会出现关键边缘情况，因为奇数索引元素大于周围的偶数索引元素。 例如，数组$[0,2,4,1]$不好，因为子数组$[2,4,1]$具有偶数索引和$2+1=3$和奇数索引和$4$。 仅查看相邻对的简单方法会错误地将该数组报告为良好，因为前两个元素满足条件。 

另一个微妙之处是，多个大的奇数索引元素可以通过它们之前的偶数索引元素的累积和进行缓冲，因此我们需要一种方法来有效地传播这些约束，而无需显式迭代每个子数组。 

## 方法

 强力方法是检查长度至少为 2 的每个子数组，并且每当奇数索引元素的总和超过偶数索引元素的总和时，递减奇数位置中的元素，直到满足条件。 虽然这在原则上是正确的，但子数组的数量呈二次方增长，这对于大型数组来说完全不切实际。$n$。 
得出最佳解决方案的见解是分别关注偶数和奇数索引的数组的_前缀和_。 让`even[i]`和`odd[i]`是直到索引的偶数和奇数位置的元素的前缀和`i`。 The condition for a subarray$[l, r]$那么就是`even[r] - even[l-1] >= odd[r] - odd[l-1]`。 重新排列给出`odd[r] - even[r] <= odd[l-1] - even[l-1]`。 这表明我们只需要跟踪奇数减偶数前缀和的最大差值，每当当前差值超过该最大值时，我们就需要执行足够的减量来将其降低。 

因此，最佳解决方案减少为对数组进行一次迭代，同时保持累积和的差异，并在当前差异超过最小允许差异时更新操作数。 这为每个测试用例提供了 O(n) 解决方案。 

| 方法| 时间复杂度| 空间复杂度| 判决 |
 | --- | --- | --- | --- |
 | 蛮力 | O(n²) | O(n) | 太慢了 |
 | 最佳 | O(n) | O(1) | O(1) | 已接受 |

 ## 算法演练

 1.初始化两个变量，`even_sum`和`odd_sum`，在遍历数组时跟踪偶数和奇数索引处的累积和。 同时初始化`min_ops`为零，这将累积所需的总操作数。 
2. 按索引迭代数组。 如果索引为偶数（从 1 开始索引），则将该元素添加到`even_sum`。 否则，将其添加到`odd_sum`。 
3. 在每一步，计算当前差值`odd_sum - even_sum`。 这表示到目前为止奇数元素的总和超过偶数元素的总和的程度。 
4. 如果`odd_sum - even_sum > 0`，它违反了从头开始的子数组的“良好”条件。 增量`min_ops`通过这个差异并调整`odd_sum`减去相同的量。 这模拟减少奇数索引元素刚好足以恢复条件。 
5. 继续迭代数组直至结束。 循环结束后，`min_ops`包含使数组良好所需的最小减量数。 
6. 输出`min_ops`对于当前的测试用例。 

为什么它有效：关键的不变量是每次迭代后，数组的所有前缀都满足“良好”条件。 通过仅向前传播必要的调整，我们保证以当前索引结尾的每个子数组都是有效的。 因为我们总是减少恢复不变量所需的最小量，所以解是最小的。 

## Python 解决方案```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        min_ops = 0
        even_sum = 0
        odd_sum = 0
        for i in range(n):
            if (i+1) % 2 == 0:
                even_sum += a[i]
            else:
                odd_sum += a[i]
            diff = odd_sum - even_sum
            if diff > 0:
                min_ops += diff
                odd_sum -= diff
        print(min_ops)

if __name__ == "__main__":
    solve()
```在这个解决方案中，`even_sum`和`odd_sum`根据从1开始的索引规则累加前缀和。 变量`diff`测量奇数总和超过偶数总和的程度。 每当`diff`是正数，我们将其添加到`min_ops`并减少`odd_sum`保持不变性。 使用前缀和可以避免检查所有子数组的二次成本。
